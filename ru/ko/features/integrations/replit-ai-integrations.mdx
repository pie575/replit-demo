Интеграции Replit AI позволяют легко создавать приложения на базе ИИ. Начните работать с моделями OpenAI, Anthropic, Google и OpenRouter прямо сейчас. Не нужно настраивать аккаунт разработчика или управлять ключами API — Replit берёт всё на себя.

<div id="replit-ai">
  ## Что такое интеграция Replit AI?
</div>

Интеграция Replit AI даёт управляемый доступ к моделям ИИ от ведущих провайдеров. Создавайте чат-приложения, генераторы контента и инструменты на базе ИИ, не покидая Replit. Не нужно заводить учётные записи разработчика у сторонних сервисов, искать учётные данные API или оплачивать отдельные счета.

При работе с интеграцией Replit AI учётными данными провайдеров управляет сам Replit, а оплата идёт по публичным ценам API. Использование списывается в кредитах Replit, детализируется по каждому Replit App и отображается на [странице Usage](/ru/ko/billing/managing-spend).

<Note>
  Для интеграции Replit AI требуется платный тариф (Core, Pro или Enterprise). На [тарифе Starter](/ru/ko/billing/plans/starter-plan) можно создавать приложения с ИИ, используя собственный ключ API. См. раздел [Доступность по тарифам](#plan-availability).
</Note>

<div id="section">
  ## Возможности
</div>

Интеграция Replit AI упрощает разработку с ИИ благодаря встроенному доступу и прозрачному выставлению счетов:

* **Без настройки**: чтобы начать, не нужны ни учётная запись разработчика, ни ключи API
* **Управляемые учётные данные**: Replit берёт на себя аутентификацию у провайдеров и управление учётными данными
* **Прозрачное выставление счетов**: вы платите по публичным ценам API, списание идёт кредитами Replit
* **Отслеживание использования**: смотрите расход по каждому Replit App на странице Usage
* **Поддержка любого стека**: работает со всеми языками программирования и фреймворками
* **Опциональный BYOK**: если хотите использовать собственные учётные данные, можно подключить свои ключи API

<div id="section-2">
  ## Начало работы
</div>

<div id="replit">
  ### Использование управляемых учетных данных Replit
</div>

Если упомянуть в запросе функции ИИ или конкретного провайдера (OpenAI, Anthropic, Google или OpenRouter), Agent по умолчанию использует интеграцию Replit AI:

<AiPrompt>
  Создайте веб-приложение, которое использует OpenAI для краткого изложения статей
</AiPrompt>

В ответе на начальный запрос найдите **&quot;OpenAI (Replit managed)&quot;**, **&quot;Anthropic (Replit managed)&quot;**, **&quot;Google (Replit managed)&quot;** или **&quot;OpenRouter (Replit managed)&quot;**, чтобы узнать, какая интеграция используется. Это означает, что Agent будет использовать учетные данные Replit вместо запроса вашего API-ключа.

**При первоначальном создании приложения**: когда вы отправляете начальный запрос на создание нового приложения с функциями ИИ, интеграция Replit AI подбирается автоматически. Agent сразу начинает создание приложения с управляемыми учетными данными Replit.

**Для существующих Replit App**: если Agent обнаружит, что вы пытаетесь добавить функции ИИ в существующее Replit App, он явно сообщит в редакторе проекта, что запрашивает использование интеграции Replit AI вместо вашего API-ключа. Появится запрос на подтверждение:

Нажмите «Одобрить», чтобы продолжить с управляемыми учетными данными Replit, или «Отклонить», чтобы использовать собственный API-ключ.

Использование отслеживается автоматически, а плата списывается с вашей учетной записи Replit по публичным тарифам API.

<div id="api">
  ### Использование собственного API-ключа
</div>

Если вместо интеграции с Replit AI вы хотите использовать собственные учётные данные OpenAI, Anthropic, Google или другого провайдера, у вас есть несколько вариантов:

**Для первоначальной сборки**: укажите в промпте, что хотите использовать собственный API-ключ:

<AiPrompt>
  Create a web app that uses OpenAI to summarize articles. Use my own OpenAI API key.
</AiPrompt>

Если в ответе указано только название провайдера без пометки «Replit managed», это значит, что Agent запросит у вас API-ключ.

**Для существующих Replit App**: когда Agent попытается использовать интеграцию с Replit AI и покажет запрос на подтверждение, нажмите «Отключить» вместо «Одобрить».

В обоих случаях Agent доводит сборку до первого чекпоинта и только затем запрашивает API-ключ. Так Agent сначала выстраивает структуру проекта, а потом делает паузу, чтобы получить от вас учётные данные.

При использовании собственного API-ключа оплата идёт напрямую провайдеру, а не за счёт кредитов Replit.

<div id="section-4">
  ## Поддерживаемые провайдеры
</div>

Интеграции Replit AI сейчас поддерживают следующих провайдеров:

* **OpenAI**: мультимодальные модели для генерации текста, рассуждений и работы с аудио. Поддерживаются чат-комплишены, ответы, генерация изображений, транскрибация аудио (`gpt-4o-transcribe`, `gpt-4o-mini-transcribe`) и аудиовывод (`gpt-audio`, `gpt-audio-mini`).
* **Anthropic**: мультимодальные модели для рассуждений, написания текстов и программирования. Поддерживаются Messages API и взаимодействие с веб-поиском.
* **Google (Gemini)**: мультимодальные модели для генерации текста и рассуждений. Поддерживаются генерация текста и изображений.
* **OpenRouter**: предоставляет доступ к моделям таких провайдеров, как Microsoft (серия Phi), Meta (серия Llama), Mistral, Qwen, DeepSeek, Nvidia и Amazon.

<Note>
  Интеграции Replit AI поддерживают **текстовый, графический и аудиовывод**. Видеовывод не поддерживается. Если вам нужна генерация видео, используйте собственный API-ключ провайдера, который её поддерживает.
</Note>

<div id="openrouter-2">
  ## Конфиденциальность и доступность OpenRouter
</div>

При использовании OpenRouter через интеграцию с Replit AI запросы отправляются с определёнными настройками конфиденциальности, которые защищают ваши данные. Эти настройки могут влиять на набор доступных моделей, поэтому важно понимать, как они работают.

<div id="section-6">
  ### Настройки конфиденциальности для пользователей самообслуживания
</div>

Для индивидуальных пользователей и команд Replit настраивает запросы к OpenRouter со следующими параметрами конфиденциальности по умолчанию:

* **Обучение на платных эндпоинтах отключено**: поставщики платных моделей не используют данные для обучения
* **Обучение на бесплатных эндпоинтах включено**: поставщики бесплатных моделей могут обучаться на промптах и ответах
* **Публикация на бесплатных эндпоинтах включена**: бесплатные поставщики могут публиковать промпты и ответы в общедоступных наборах данных
* **Логирование ввода/вывода отключено**: OpenRouter не записывает запросы и ответы, что даёт скидку 1% на оплату
* **Аналитические файлы cookie отключены**: аналитические файлы cookie не используются

Эти настройки ставят конфиденциальность на первое место, сохраняя при этом доступ к максимально широкому набору моделей. Однако, если вам нужны настройки конфиденциальности, отличные от указанных выше, **некоторые модели могут быть недоступны**.

<div id="enterprise">
  ### Настройки конфиденциальности в Enterprise
</div>

Для организаций Enterprise компания Replit применяет более строгие меры защиты конфиденциальности:

* **Только конечные точки с нулевым хранением данных (ZDR)**: доступны только модели с политикой нулевого хранения данных
* Также действуют все перечисленные выше настройки конфиденциальности для пользователей самообслуживания
* Благодаря этому запросы Enterprise направляются только к конечным точкам, которые не сохраняют данные

Поскольку в Enterprise используются только конечные точки ZDR, **выбор доступных моделей более ограничен, чем у пользователей самообслуживания**. Такой компромисс обеспечивает высочайший уровень конфиденциальности данных для корпоративных рабочих нагрузок.

<div id="section-7">
  ## Доступность по тарифам
</div>

Для интеграций Replit AI требуется платный тариф. Способ доступа зависит от тарифа.

<div id="starter">
  ### Starter (бесплатный)
</div>

На тарифе Starter интеграция с Replit AI отключена. Вы можете создавать приложения с ИИ, используя собственный ключ API. См. [Использование собственного ключа API](#bringing-your-own-api-key).

<div id="core">
  ### Core
</div>

На тарифе Core вы можете создавать ИИ-приложения с помощью интеграции Replit AI, используя учётные данные под управлением Replit. Управлять ключами API не нужно.

<div id="pro-enterprise">
  ### Pro и Enterprise
</div>

Для организаций Pro и Enterprise доступ к интеграции Replit AI по умолчанию отключён. Администраторы организации могут управлять доступом на странице настроек организации:

1. Перейдите в настройки организации
2. Найдите раздел интеграции Replit AI
3. Включите или отключите доступ для организации

После включения участники организации смогут использовать интеграцию Replit AI в своих приложениях. Всё потребление отслеживается и списывается со счёта организации. Если интеграция отключена, участникам потребуется указать собственные ключи API для работы с провайдерами моделей ИИ.

<div id="section-8">
  ## Сценарии использования
</div>

Создавайте мощные приложения с ИИ на любом стеке:

* **Генерация контента**: краткие пересказы статей, создание описаний, написание текстов
* **Анализ и инсайты**: извлечение ключевой информации, анализ тональности, классификация текстов
* **Диалоговые интерфейсы**: создание чат-ботов и ИИ-ассистентов
* **Преобразование текста**: перевод, переписывание и изменение формата контента
* **Помощь с кодом**: генерация фрагментов кода, объяснение алгоритмов, ревью кода
