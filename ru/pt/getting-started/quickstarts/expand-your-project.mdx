⏰ *Примерное время: 5 минут* · Продолжение [Создайте своё первое приложение](/ru/pt/getting-started/quickstarts/ask-ai)

Вы создали веб-приложение. Теперь расширьте его: добавьте мобильное приложение, презентацию или что-то ещё — всё в рамках одного проекта. Все компоненты используют одни и те же данные и бэкенд, поэтому не нужно начинать с нуля.

<div id="antes-de-comear">
  ## Прежде чем начать
</div>

Вам понадобится существующий проект в Replit: из предыдущего руководства по быстрому началу или любой проект, созданный вами.

<div id="seu-projeto-pode-fazer-mais-de-uma-coisa">
  ## Ваш проект может больше
</div>

Когда вы создали своё первое приложение, вы создали веб-приложение. Но проект в Replit не ограничивается одним результатом. Вы можете добавить **мобильное приложение** для телефонов, **презентацию**, чтобы представить свою идею, **анимированное видео** и многое другое — всё в рамках одного проекта.

Всё это называется **артефактами**. Каждый артефакт можно публиковать отдельно, но все они используют общий код и данные. Создайте один раз — публикуйте где угодно.

<div id="adicione-um-aplicativo-mobile">
  ## Добавьте мобильное приложение
</div>

<Steps>
  <Step title="Попросите Agent создать мобильную версию">
    Скажите Agent, что вам нужно:

    ```
    Добавьте мобильную версию этого приложения
    ```

    Также можно нажать кнопку **+** на панели предварительного просмотра, чтобы добавить новый артефакт.

    <Frame>
      <video autoPlay muted loop playsInline src="/assets/mirror/design_mobile_app_canvas-a67a35b27fd4.mp4" />
    </Frame>

    Agent создаст мобильное приложение с тем же бэкендом, что и у вашего веб-приложения: все уже созданные данные и логика будут перенесены автоматически.
  </Step>

  <Step title="Просмотрите приложение в симуляторе телефона">
    Когда Agent завершит работу, на панели предварительного просмотра появится мобильное приложение, запущенное в симуляторе телефона. Нажимайте на элементы и тестируйте его так же, как на настоящем телефоне.
  </Step>

  <Step title="Переключайтесь между приложениями">
    Используйте раскрывающееся меню на **панели предварительного просмотра**, чтобы переключаться между веб- и мобильным приложениями.

    <Frame>
      <video autoPlay muted loop playsInline src="/assets/mirror/switch_artifacts-bc0ae3999898.mp4" />
    </Frame>

    Также можно попросить Agent:

    ```
    Покажите веб-приложение
    ```
  </Step>
</Steps>

<div id="adicione-ainda-mais-ao-seu-projeto">
  ## Добавьте в свой проект ещё больше
</div>

Ваш проект не ограничивается веб- и мобильными приложениями. Вы также можете попросить Agent создать другие типы артефактов:

* **Презентации** — &quot;Создай презентацию для этого приложения&quot;
* **Анимированные видео** — &quot;Создай короткое поясняющее видео для этого приложения&quot;
* **Визуализации данных** — &quot;Создай панель со статистикой использования&quot;
* **Документы** — &quot;Напиши краткое описание этого приложения&quot;

Каждый из них становится новым артефактом в вашем проекте, которым можно поделиться по собственной URL-адресу.

<div id="publique-seu-projeto">
  ## Опубликуйте свой проект
</div>

Когда вы нажмёте **Publish**, все артефакты проекта будут опубликованы одновременно. Веб-приложение, мобильное приложение и презентация получат собственные URL-адреса и останутся подключёнными к одному бэкенду.

Подробнее — в разделе [Публикация приложения](/ru/pt/getting-started/quickstarts/publish).
