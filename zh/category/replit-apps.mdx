<div id="what-is-a-replit-app">
  ## 什么是 Replit App？
</div>

Replit Apps 是托管在云端的项目，包含代码、数据和资源。
你可以在安全、隔离的环境中创建、运行和发布它们。

Replit Apps 与 Project Editor 中的以下工具集成，为你提供
流畅的开发体验：

* **AI 驱动工具**：使用 Agent 创建、调试和解释代码。
* **协作**：与他人实时协作，共同开发同一个应用。
* **发布**：一键将应用发布到云端。

<div id="key-features">
  ## 主要功能
</div>

Replit Apps 提供以下功能：

* **无需设置：**无需安装或配置，直接在 Replit.com 上创建应用或编写代码。
* **自动保存：**你的项目会持续将更改保存到云端，让你可以通过任何 Web 浏览器继续编写代码
* **版本控制：**通过 Replit 的版本控制系统，无需任何配置即可跟踪更改、查看文件历史记录并同步文件
* **公开/私密可见性控制：**通过隐私设置控制谁可以查看、运行或创建你应用的 Remix
* **发布：**无需进行复杂配置，即可将代码发布到云端
* **自定义应用 URL：**为你的应用获取专属 URL，或绑定自定义域名，打造更专业的形象

<Info>
  上传到项目文件系统的文件仅在开发期间可用，
  已发布的应用或其他构建者无法访问。请使用 [对象
  存储](/zh/features/data-and-storage/object-storage) 来处理
  构建者上传的文件和提供文件，并使用 [Replit
  Database](/zh/features/data-and-storage/sql-database) 为你的应用和用户存储及
  检索数据。
</Info>

如需详细了解可简化 Replit App 创建流程的 Project Editor 工具，请参阅 [Project Editor 概览](/zh/learn/projects-and-artifacts/project-editor/)。

<div id="how-it-works">
  ## 工作原理
</div>

创建 Replit App 后，Replit 会在云端为你的项目设置专属的私有空间。
当你为应用添加功能或进行修改时，Replit 会自动保存更改，
方便你通过任何网页浏览器继续编辑。

Replit 提供包含所有必需组件的预配置环境。
这样，你无需担心服务器配置、数据库设置或环境管理，
即可立即开始创建应用。

Replit 会自动为每个 Replit App 分配一个唯一的网址，供你在
开发过程中预览应用。准备好分享你的
作品后，只需点击几下即可将其发布，让它全天候可用。

<div id="storage-overview">
  ## 存储概览
</div>

Replit 提供四种主要存储类型，满足应用的数据需求。每种存储类型适用于不同的使用场景，并根据你的套餐设有相应限制。

<Info>
  存储限制包括应用存储的所有数据，其中包括已安装的软件包和依赖项。
</Info>

| 存储类型                                                            | 描述           | 使用场景            | 持久性         | 套餐限制                                                                                                                                                 |
| --------------------------------------------------------------- | ------------ | --------------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **文件存储**                                                        | project 中的文件 | 应用代码、静态资源、配置文件  | 发布后保留，重启时重置 | Starter: {StarterWorkspaceStorage}<br />Core: {CoreWorkspaceStorage}<br />Pro: {TeamsWorkspaceStorage}<br />Enterprise: {EnterpriseWorkspaceStorage} |
| **[数据库](/zh/features/data-and-storage/sql-database/)**             | 结构化数据存储      | 用户资料、游戏分数、产品目录  | 跨会话完全持久化    | 每个开发数据库 20GB<br />生产数据库按计算时间和存储空间计费                                                                                                                  |
| **[App Storage](/zh/features/data-and-storage/object-storage/)**   | 非结构化数据和媒体    | 图片、视频、PDF、文档    | 跨会话完全持久化    | 按用量付费<br />按存储空间和带宽计费                                                                                                                                |
| **[Secrets](/zh/core-concepts/project-editor/app-setup/secrets/)** | 加密的敏感数据      | API 密钥、凭据、连接字符串 | 完全持久化且经过加密  | 无特定限制<br />所有套餐均包含                                                                                                                                   |
