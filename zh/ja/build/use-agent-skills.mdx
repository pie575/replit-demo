技能可让 Agent 学习新能力：你偏好的模式、库的使用细节、设计系统规则，或已解决问题的解决方案。你可以将其随消息附上、安装到项目中，或用作新项目的起点。

<div id="section">
  ## 在聊天中使用技能
</div>

试用技能最简单的方式是将其添加到单条消息中，无需安装。

<Frame>
  <img src="/assets/mirror/agent-skills-picker-ee4058454475.png" alt="通过聊天输入框旁的 + 按钮打开的技能选择器，显示了 Ad Creative、AI Recruiter、AI SDR 和 AI Secretary 等技能列表" width="723" height="529" data-path="images/replitai/agent-skills-picker.png" />
</Frame>

<Steps>
  <Step title="打开技能选择器">
    点击聊天输入框旁的**+**按钮，然后选择**使用技能**。
  </Step>

  <Step title="查找并选择技能">
    在业务与财务、创意、研究与分析等类别中浏览技能。选择一个或多个技能并将其添加到消息中。
  </Step>

  <Step title="发送消息">
    输入并发送请求。Agent只会针对这条消息使用所选技能。消息中会显示技能标签，方便你确认哪些技能已启用。
  </Step>
</Steps>

例如，你可以添加**Stock Analyzer**，让Agent创建股票研究报告；也可以添加**Deep Research**，让Agent针对某个主题开展研究并提供结构化的研究结果。

<Tip>
  添加到聊天中的技能不会在项目中安装任何内容。你可以立即在所有项目中使用它们。
</Tip>

<div id="section-2">
  ## 从技能开始创建项目
</div>

创建新项目时，你可以选择经过预先审核的技能作为起点。Agent 会根据技能中的指令创建项目框架。

<Steps>
  <Step title="打开起点选择器">
    在新建项目界面中，点击 **+**，然后选择**使用技能**。
  </Step>

  <Step title="选择技能">
    浏览 **AI SDR**、**SEO Auditor**、**Ad Creative**、**Programmatic SEO** 等精选技能，选择符合你要创建的应用类型的技能。
  </Step>

  <Step title="描述你的应用">
    告诉 Agent 你想创建什么。Agent 会从一开始就采用该技能的模式和惯例来构建项目。
  </Step>
</Steps>

<div id="section-3">
  ## 在项目中安装技能
</div>

如果希望 Agent 在项目的所有对话中都始终应用某个技能，可以将其安装到项目中。已安装的技能会保存在项目的 `/.agents/skills` 目录下，并在多个聊天会话之间持续保留。

<div id="section-4">
  ### 通过技能面板安装
</div>

打开项目编辑器中的**技能面板**，选择 **Discover** 标签页，浏览社区提供的技能。找到想要使用的技能后，点击**安装**，该技能会自动添加到项目中。

<Frame>
  <img src="/assets/mirror/agent-skills-discover-732b2b0c488a.png" alt="Discover 技能标签页，显示可搜索的社区技能和安装按钮" width="2542" height="1850" data-path="images/replitai/agent-skills-discover.png" />
</Frame>

例如，构建包含高级动画的作品集网站时，你可以安装：

* **GSAP React** — 教 Agent 使用滚动触发动画、文本揭示和 SVG 路径绘制
* **Tailwind design system** — 为 Agent 提供用于排版、间距和视图过渡的 Tailwind CSS 模式
* **Find skills** — 教 Agent 如何代你查找并安装新技能

<Tip>
  你也可以通过 [npx skills CLI](https://github.com/vercel-labs/skills) 安装技能：

  ```bash theme={null}
  npx skills <skill> -a replit
  ```
</Tip>

<div id="section-5">
  ### 通过对话创建技能
</div>

创建技能最自然的方式是与 Agent 对话。在共同解决问题或调研新库后，可以让 Agent 记录所学内容：

<AiPrompt>
  请调研 GSAP 与 React 集成的最佳实践，并为此项目创建一个技能。
</AiPrompt>

Agent 会利用整个对话的上下文创建详细的技能文件。在调试过程中逐步形成对问题的共同理解后，这种方式尤为有效。

<div id="section-6">
  ### 编写自定义技能
</div>

对于高级用例，可以按照 [Agent Skills 规范](https://agentskills.io/specification)直接编写技能。在文件侧边栏中打开**显示隐藏文件**开关，进入 `/.agents/skills/` 并新建一个 Markdown 文件。这样你就能完全掌控 Agent 知道哪些内容、以及它如何运作。
