# Skills directory

> Replit과 파트너가 만든 스킬을 둘러보고, 프로젝트나 워크스페이스에 설치하는 방법을 알아보세요.

Skills directory는 즉시 설치하고 사용할 수 있는 완성된 스킬 카탈로그입니다 — Replit과 파트너들이 만들었습니다. 하나를 설치하고 사용해 본 다음, 팀이 실제로 일하는 방식에 맞게 수정하세요.

스킬이 무엇이고 Agent가 어떻게 불러오는지는 [Agent Skills](/ko/features/agent/skills)를 참고하세요. 스킬을 워크스페이스 전체에서 사용할 수 있게 만드는 방법은 [Agent Customization](/ko/features/agent/agent-customization)을 참고하세요.

## 스킬 설치하기

디렉터리에서 스킬을 추가하는 방법에는 몇 가지가 있습니다:

* **채팅에서** — 채팅 입력창 옆의 **+** 버튼을 클릭하고 **스킬 사용**을 선택한 다음 하나를 고르세요. 이 스킬은 해당 메시지에만 적용되며 프로젝트에는 아무것도 설치되지 않습니다.
* **프로젝트에서** — Project Editor에서 **Skills 패널**을 열고 **Discover** 탭을 선택한 다음 스킬을 찾아 **Install**을 클릭하세요. 설치된 스킬은 프로젝트의 `/.agents/skills` 디렉터리에 저장되어 여러 채팅에서 계속 유지됩니다.
* **명령줄에서** — [skills CLI](https://github.com/vercel-labs/skills)로 스킬을 설치하세요:

  ```bash theme={null}
  npx skills <skill> -a replit
  ```

<Warning>
  Replit 스킬 선택기에 있는 스킬은 안전성 검토를 거쳤습니다. 외부 소스에서 설치한 스킬은 그렇지 않습니다. 스킬은 Agent가 따르는 지침이므로, 설치하기 전에 항상 외부 스킬을 검토하세요 — 확인해야 할 사항은 [Agent skills](/ko/learn/agent-skills)를 참고하세요.
</Warning>

## Replit 스킬

Replit은 채팅의 **스킬 사용** 선택기와 새 프로젝트 시작 지점 선택기에서 사용할 수 있는 사전 정의된 스킬을 제공합니다. 이 스킬들은 설치 없이 모든 프로젝트에서 작동합니다. 선택기를 열면 설명이 바로 표시됩니다.

| 카테고리        | 스킬                                                                                                            |
| ----------- | ------------------------------------------------------------------------------------------------------------- |
| 영업 & 마케팅    | Ad Creative, AI SDR, SEO Auditor, Programmatic SEO, GEO, Content Machine, Storyboard                          |
| 커리어         | AI Recruiter, Resume Maker, Interview Prep                                                                    |
| 리서치 & 분석    | Competitive Analysis, Deep Research, GitHub Solution Finder, Supplier Research                                |
| 비즈니스 & 재무   | Stock Analyzer, Excel Generator, Invoice Generator, Tax Reviewer                                              |
| 문서 & 도구     | Website Cloner, File Converter, Flashcard Generator, Legal Contract, Infographic Builder, Recreate Screenshot |
| 창작          | Photo Editor, Podcast Generator, Podcast Marketing, Branding Generator, Video Editing                         |
| 생산성         | AI Secretary, Product Manager, Design Thinker, Skill Finder, Skill Creator                                    |
| 개인          | Travel Assistant                                                                                              |
| 보안 & 컴플라이언스 | Secrets, Sensitive Data, Input Validation, AI Security, Dependency Vetting, License Check                     |
| 품질 & 안정성    | Accessibility, Responsive UI, Observability, Resilience, Ship Review                                          |

<Note>
  워크스페이스 내에서는 선택기가 프로젝트의 `.local/secondary_skills/` 디렉터리에 설치된 추가 스킬도 찾아냅니다.
</Note>

## 파트너 스킬

Replit의 파트너들은 자사 제품으로 빌드하는 방법을 Agent에게 가르치는 스킬을 게시합니다. 하나를 설치하면 Agent가 해당 서비스의 패턴과 관례를 익힐 수 있습니다.

| 파트너              | Agent에게 가르치는 것                  |
| ---------------- | ------------------------------- |
| Stripe           | 결제 및 요금 청구 통합 패턴                |
| PayPal           | 결제 통합 패턴                        |
| RevenueCat       | 구독 및 인앱 결제 패턴                   |
| Mixpanel         | 분석 및 추적 구현                      |
| BigQuery         | 데이터 웨어하우스 쿼리 패턴                 |
| Resend           | 트랜잭션 이메일 통합                     |
| Google Workspace | Gmail, Drive, Docs, Calendar 통합 |
| Atlassian        | Jira와 Confluence 이슈 및 페이지 워크플로  |
| Google Maps      | 지도, 장소, 경로, 지오코딩 통합             |

## 커뮤니티 스킬

Replit과 파트너 스킬 외에도 커뮤니티가 게시한 설치 가능한 스킬이 있습니다. [skills.sh](https://skills.sh)에서 둘러보고, 직접 스킬을 작성하려면 [Agent Skills specification](https://agentskills.io/specification)을 읽어보세요.
