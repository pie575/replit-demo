<div id="pro-plan-launch">
  ## Pro 套餐发布
</div>

Replit Pro 现已推出，Core 的性价比也进一步提升。我们让套餐更清晰，也更贴合不同需求：

* **Replit Pro**：面向专业构建者——Turbo Mode (Agent 速度提升 2.5 倍，可单独开启) 、可结转的分级积分、最多 15 名构建者且无需按席位付费、优先支持，以及 4 倍的数据保留期。[了解 Pro](/zh/billing/plans/replit-pro)。
* **Core**：无需额外付费即可邀请最多 5 名协作者。请参阅[定价页面](https://replit.com/pricing)了解当前的 Core 定价。
* **Teams 套餐停用**：Teams 将由 Pro 取代。现有 Teams 客户将在剩余订阅期内免费升级至 Pro。迁移将于 {TeamsMigrationDate} 开始。[详细信息和时间线](https://blog.replit.com/pro-plan)。
* **Agent 模式**：可选择 **Economy** (成本优化) 或 **Power** (性能优先) ；**Turbo** 是单独的开关 (仅限 Pro/Enterprise，速度提升 2.5 倍) 。[Agent 模式指南](/zh/core-concepts/agent/agent-modes)。
* **Fast Mode 现更名为 Lite Mode**：同样支持闪电般快速、范围明确的更改——产品和文档中均已更新名称。[Lite 模式](/zh/core-concepts/agent/agent-modes)。
* **Code Optimizations**：控制 Agent 如何审查自身代码的设置 (原名为 Autonomy Level) 现已更名为 Code Optimizations。[代码审查](/zh/features/agent/agent-modes)。
* **协作**：所有付费套餐均可享受更好的协作体验——无限 Workspace、简化的共享方式、统一设置，以及按 Workspace 跟踪使用情况。Core：5 名协作者；Pro：15 名构建者。

<div id="background-memory-compression">
  ### 后台记忆压缩
</div>

Agent 不再为优化记忆而中断你的工作流程。此前，你会看到“已优化 Agent 记忆”消息，导致工作停滞 30 秒以上。现在，优化会在后台无缝完成，因此 Agent 会在你工作时始终保持响应。
