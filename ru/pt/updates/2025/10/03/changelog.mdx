<div id="integrao-de-importao-do-vercel">
  ### Интеграция импорта из Vercel
</div>

Переносите свои приложения из Vercel в Replit одним кликом! Новый процесс импорта позволяет легко перенести в Replit приложения на Next.js и другие проекты, размещённые на Vercel. Отличная возможность для разработчиков, которые ищут альтернативу Vercel. Подробнее — в [кратком руководстве «Импорт из Vercel»](/ru/pt/getting-started/quickstarts/import-from-vercel) и в [руководстве «Импорт в Replit»](/ru/pt/core-concepts/project-editor/app-setup/import).

<div id="melhorias-no-controle-de-verso-git">
  ### Улучшения в контроле версий Git
</div>

Обновлённая интеграция с Git делает управление удалёнными репозиториями удобнее и добавляет гибкости в работе с рабочими пространствами. Подключайте и создавайте удалённые репозитории Git через улучшенный интерфейс, легко переключайтесь между личными и организационными рабочими пространствами и следите за тем, чтобы перед публикацией код всегда был актуальным. Подробнее — в разделе [Использование панели Git](/ru/pt/core-concepts/project-editor/version-control/git-interface).

<div id="lanamento-da-plataforma-connectors">
  ### Запуск платформы Connectors
</div>

Создавайте приложения быстрее с 24 готовыми интеграциями! Подключайте свои проекты Replit к популярным сервисам, таким как Stripe, Figma и многим другим, через нашу новую платформу Connectors. Каждый коннектор работает на базе MCP (Model Context Protocol), обеспечивая бесшовную разработку с помощью ИИ. См. [Интеграции Agent](/ru/replitai/integrations) и [Управление коннекторами](/ru/pt/replitai/managing-connectors).

<div id="melhorias-de-fontes-nos-temas-de-app">
  ### Улучшения шрифтов в темах App
</div>

Оформляйте свои приложения с помощью 19 дополнительных шрифтов Google Fonts, включая такие популярные варианты, как Crimson, EB Garamond, Figtree и Source Sans Pro. Теперь в выборе шрифтов каждый шрифт отображается своим собственным начертанием, поэтому оценить варианты оформления стало проще. Шрифты сгруппированы по категориям (с засечками, без засечек, моноширинные), а полезные подсказки поясняют каждый тип. Подробнее — в разделе [Темы App](/ru/replitai/app-themes).

<div id="gerenciamento-de-conectores-para-admins">
  ### Управление коннекторами для администраторов
</div>

Корпоративные клиенты получают расширенные возможности управления коннекторами: ролевую модель доступа к общим ключам API и полностью настраиваемую конфигурацию OAuth-клиента. Коннекторы подключаются на уровне организации по желанию, поэтому администраторы полностью контролируют, какие интеграции доступны участникам команды. См. [Управление коннекторами](/ru/pt/replitai/managing-connectors).
