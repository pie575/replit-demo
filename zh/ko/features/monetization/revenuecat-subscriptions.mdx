<div id="revenuecat">
  ## 什么是 RevenueCat？
</div>

借助 RevenueCat，您可以为[原生移动应用](/zh/ko/features/artifact-types/building-mobile-apps)添加应用内订阅。要开始使用，只需让 Agent 设置订阅并关联您的 RevenueCat 账户，Agent 就会处理相关逻辑并提供测试环境。

<div id="section">
  ## 前提条件
</div>

开始前，您需要：

* 一个通过**移动应用**创建的 Replit 项目
* 一个 [RevenueCat](https://www.revenuecat.com) 账户 (只需电子邮件和密码，无需银行账户或额外设置)

<Note>
  请使用 [replit.com](https://replit.com) 上的项目编辑器开发原生移动应用。若支持此功能，您也可以在 Replit Android 应用中开发原生移动应用。如果您使用 Replit iOS 应用，请在 replit.com 上打开项目。
</Note>

<div id="section-2">
  ## 开始使用
</div>

<Steps>
  <Step title="请求 Agent 添加订阅">
    说明您想添加的订阅。Agent 会规划集成、安装软件包并配置 RevenueCat。

    <AiPrompt>为我的应用添加 $5.99/月的订阅</AiPrompt>

    <Frame>
      <img src="/assets/mirror/revenuecat-prompt-a230068ba884.png" alt="显示 Agent 正在响应添加订阅提示词的 Replit 项目编辑器" width="1957" height="1133" data-path="images/replitai/revenuecat-prompt.png" />
    </Frame>
  </Step>

  <Step title="连接 RevenueCat 账户">
    Agent 会请求连接到 RevenueCat。选择 **连接 RevenueCat** 以开始认证流程。

    <Frame>
      <img src="/assets/mirror/revenuecat-connect-1463c331a55f.png" alt="显示带有连接按钮的 RevenueCat 连接横幅的 Agent 聊天" width="1957" height="1133" data-path="images/replitai/revenuecat-connect.png" />
    </Frame>

    模态框会确认正在连接到 RevenueCat。选择 **继续前往 RevenueCat** 以继续。

    <Frame>
      <img src="/assets/mirror/revenuecat-connect-modal-34362346bf1d.png" alt="显示隐私和安全信息的 RevenueCat 连接模态框" width="1957" height="1133" data-path="images/replitai/revenuecat-connect-modal.png" />
    </Frame>
  </Step>

  <Step title="授权 Replit">
    在 RevenueCat 认证页面中，选择 **读取和写入** 权限，然后选择 **授权**，允许 Replit 访问您的 RevenueCat 账户。

    <Frame>
      <img src="/assets/mirror/revenuecat-authorize-cbab817ca1ae.png" alt="已选择读取和写入权限的 RevenueCat OAuth 认证页面" width="683" height="897" data-path="images/replitai/revenuecat-authorize.png" />
    </Frame>
  </Step>

  <Step title="让 Agent 构建订阅功能">
    完成认证后，Agent 会创建 RevenueCat 项目、配置商品和权益、构建付费墙界面，并在整个应用中接入订阅逻辑。

    <Frame>
      <img src="/assets/mirror/revenuecat-agent-summary-d015a344dcac.png" alt="显示订阅功能和定价的付费墙界面的 Agent 摘要" width="1957" height="1133" data-path="images/replitai/revenuecat-agent-summary.png" />
    </Frame>

    <Frame>
      <img src="/assets/mirror/revenuecat-app-home-ea0d4a05b26e.png" alt="显示订阅内容高级徽章的移动应用首页" width="1957" height="1133" data-path="images/replitai/revenuecat-app-home.png" />
    </Frame>
  </Step>
</Steps>

<div id="section-3">
  ## 测试订阅
</div>

Replit 预览使用 RevenueCat 的**测试模式**。在 Expo Go 中测试购买时，系统会显示测试购买对话框，而不会进入实际支付流程。不会产生任何费用。

<Frame>
  <img src="/assets/mirror/revenuecat-test-purchase-8414145a112e.png" alt="移动设备上的测试购买对话框，显示套餐详情和测试按钮" width="683" height="1253" data-path="images/replitai/revenuecat-test-purchase.png" />
</Frame>

<Tip>
  测试购买可在开发期间安全使用。你可以在不产生实际费用的情况下测试购买成功和失败的流程。
</Tip>

<Warning>
  Apple 批准你的 App 在 App Store 上发布后，购买将使用真实货币。
  在提交应用审核之前，请确认 RevenueCat 商品和价格设置正确。
</Warning>

<div id="app-store-connect">
  ## 与 App Store Connect 同步
</div>

要让应用内购买在 TestFlight 和 Apple App Store 中正常运行，您必须[接受 Apple 的付费应用协议并关联银行账户](https://developer.apple.com/help/app-store-connect/manage-agreements/sign-and-update-agreements/)。
这些操作均需通过 App Store Connect 完成。在向 App Store 提交应用之前，您需要拥有付费的 Apple 开发者账户。

随后，您可以通过 Replit 将 RevenueCat 中的应用内购买配置直接同步到 App Store Connect。

<Steps>
  <Step title="前往发布管理窗口">
    您会看到将 RevenueCat 同步到 App Store Connect 的按钮。

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-sync-btn-46a2e4e696df.png" alt="将 RevenueCat 同步到 App Store Connect 的按钮" width="1476" height="604" data-path="images/replitai/revenuecat-asc-sync-btn.png" />
    </Frame>

    <Tip>
      此部分仅在您将应用提交到 TestFlight 后显示。
    </Tip>
  </Step>

  <Step title="提供 App Store Connect API 密钥">
    要提供此密钥，您需要前往 App Store Connect。

    在 [App Store Connect](https://appstoreconnect.apple.com/access/integrations/api) 中，前往 **用户和访问权限**，然后选择 **集成** 选项卡。在侧边栏中选择 **App Store Connect API**。

    创建密钥时，必须授予“App Manager”权限。

    请立即下载 .p8 文件，该文件只能下载一次。文件名以 `AuthKey_` 开头，以 `.p8` 结尾。

    复制此页面上显示的 **密钥 ID** 和 **发行者 ID**。

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-create-c54be8304d7c.png" alt="App Store Connect 的“用户和访问权限”页面，显示“集成”选项卡、App Store Connect API 侧边栏链接，以及用于创建新 API 密钥的加号按钮" width="2390" height="752" data-path="images/replitai/revenuecat-asc-create.png" />
    </Frame>

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-app-manager-93996acd8561.png" alt="App Store Connect 的 API 密钥创建对话框，名称为 RevenueCat，权限设置为 App Manager" width="1116" height="560" data-path="images/replitai/revenuecat-asc-app-manager.png" />
    </Frame>

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-copy-07a95e1be9af.png" alt="App Store Connect API 密钥页面，箭头指向“复制发行者 ID”链接和“密钥 ID”列" width="2330" height="780" data-path="images/replitai/revenuecat-asc-copy.png" />
    </Frame>
  </Step>

  <Step title="创建应用内购买 API 密钥">
    对应用内购买 API 密钥重复上述步骤。
    在侧边栏中选择 **应用内购买**，然后使用 **App Manager** 权限创建 API 密钥。
    下载 .p8 密钥 (文件名以 `SubscriptionKey_` 开头，以 `.p8` 结尾) ，并复制 **密钥 ID** 和 **发行者 ID**。

<div id="section-5">
  ## 常见问题
</div>

<AccordionGroup>
  <Accordion title="使用 RevenueCat 需要银行账户吗？">
    不需要。创建 RevenueCat 账户只需电子邮件和密码。准备好通过 App Store 或 Google Play 收款时，需另行通过 Apple 或 Google 设置银行账户。
  </Accordion>

  <Accordion title="测试购买会收费吗？">
    不会。开发期间，Replit 预览会使用 RevenueCat 的测试模式。
    购买仅为模拟操作，不会产生实际费用。只有在 Apple 应用审核通过后，才会收取实际费用。
  </Accordion>

  <Accordion title="可以在 Web 应用中使用 RevenueCat 吗？">
    RevenueCat 专为原生移动应用设计。若要为 Web 应用添加订阅，请改用 [Stripe 集成](/zh/ko/features/monetization/stripe-payments)。
  </Accordion>

  <Accordion title="可以使用 RevenueCat 配置什么？">
    您可以设置月度或年度订阅、配置价格、管理权限并构建付费墙。只需向 Agent 提出更改请求，它就会同时处理 RevenueCat 配置和应用代码。
  </Accordion>
</AccordionGroup>
