<div id="follow-up-task-suggestions">
  ## Предложения дальнейших задач
</div>

После того как вы примените задачу, Agent анализирует контекст вашего project и предлагает **дальнейшие задачи**, которые вы, возможно, захотите выполнить следующими. Диалог **Suggested next tasks** показывает главную рекомендацию прямо в переписке, поэтому вы можете продолжать работу, не покидая основную ветку.

</Frame>

Предложения дальнейших задач могут включать:

* **Новые функции для реализации**: возможности, которые органично дополняют то, что вы только что выпустили
* **Улучшения производительности**: оптимизации, которые Agent заметил во время работы над задачей
* **Улучшения пользовательского опыта**: доработки и штрихи, завершающие функцию

Нажмите **Start** в предложении, чтобы отправить его в фоновый режим, или **View plan**, чтобы сначала изучить предлагаемую работу. Чтобы увидеть все предложения, нажмите **View more in the task board**. Предложенные дальнейшие задачи отображаются в разделе **Suggested** в колонке **Drafts**.

<Frame>
  <img src="/assets/mirror/follow-up-tasks-kanban-21087e0210b6.png" alt="Доска задач с множеством предложений дальнейших задач в разделе Suggested в колонке Drafts" width="980" height="627" data-path="images/agent/follow-up-tasks-kanban.png" />
</Frame>

Если закрыть диалог **Suggested next tasks**, предложения отменяются. В основной версии Agent не показывает этот диалог, если там уже ожидает предложенный план, — так два запроса не конкурируют за ваше внимание.

<div id="managing-many-suggestions-at-once">
  ## Массовое управление предложениями
</div>

Если в проекте накопилось много предложений по дальнейшим задачам, откройте доску задач и нажмите **Edit** в столбце **Drafts**. В режиме редактирования рядом с каждой предложенной задачей появляется флажок. Отметьте нужные задачи и нажмите **Start** или **Cancel**, чтобы применить действие сразу ко всем выбранным. Чтобы выйти из режима редактирования, нажмите **Done**.
