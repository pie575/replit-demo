Replit 的 AI 集成让构建 AI 应用变得轻而易举。你可以立即上手使用 OpenAI、Anthropic、Google 和 OpenRouter 的模型——无需配置开发者账户，也无需管理 API 密钥。这一切，Replit 都替你搞定。

<div id="o-que-so-as-integraes-de-ia-do-replit">
  ## 什么是 Replit AI 集成？
</div>

Replit AI 集成提供对各大主流提供商 AI 模型的托管访问。无需离开 Replit，你就能构建聊天应用、内容生成器和 AI 工具，不必注册外部开发者账户、查找 API 凭证，也不必单独管理账单。

使用 Replit AI 集成时，由 Replit 管理提供商凭证，并按 API 公开费率计费。相关用量会从你的 Replit 积分中扣除，并显示在[用量页面](/zh/pt/billing/managing-spend)上，按现有 Replit App 分项列出。

<Note>
  Replit AI 集成需要付费方案 (Core、Pro 或 Enterprise) 。在 [Starter 方案](/zh/pt/billing/plans/starter-plan)下，你仍可使用自己的 API 密钥构建 AI 应用。参见[方案可用性](#plan-availability)。
</Note>

<div id="recursos">
  ## 功能
</div>

Replit AI 集成通过内置访问和透明计费简化 AI 开发：

* **零配置**：无需开发者账户或 API 密钥即可上手
* **凭证托管**：Replit 负责处理身份验证和提供商凭证管理
* **透明计费**：按 API 公开价格付费，从您的 Replit 积分中扣除
* **用量追踪**：在用量页面查看各个 Replit App 的用量情况
* **多技术栈支持**：适用于各种编程语言和框架
* **可选 BYOK**：如果您更希望使用自己的凭证，也可自带 API 密钥

<div id="primeiros-passos">
  ## 入门指南
</div>

<div id="usando-credenciais-gerenciadas-pelo-replit">
  ### 使用由 Replit 管理的凭证
</div>

在付费方案下，当你在 prompt 中提到 AI 功能或特定提供商 (OpenAI、Anthropic、Google 或 OpenRouter) 时，Agent 默认会使用 Replit 的 AI 集成：

<AiPrompt>
  Create a web app that uses OpenAI to summarize articles
</AiPrompt>

你可以在 prompt 的首次回复中查看是否出现 **“OpenAI (由 Replit 管理) ”**、**“Anthropic (由 Replit 管理) ”**、**“Google (由 Replit 管理) ”** 或 **“OpenRouter (由 Replit 管理) ”**，以确认当前使用的是哪个集成。这表示 Agent 将使用 Replit 的凭证，而无需你提供自己的 API 密钥。

**首次构建时**：当你发送初始 prompt 创建一个带 AI 功能的新应用时，系统会自动关联 Replit 的 AI 集成，Agent 会立即使用 Replit 的托管凭证开始构建。

**对于已有的 Replit App**：当 Agent 检测到你想为现有 Replit App 添加 AI 功能时，它会在 Project Editor 中明确告知你，它请求使用 Replit 的 AI 集成，而非你自己的 API 密钥。你会看到一条确认提示：

<Frame>
  <img src="/assets/mirror/replit-ai-integrations-confirmation-msg-9440681ad7d3.png" alt="OpenAI 集成确认对话框，显示关于使用 Replit 托管服务添加 OpenAI 的消息，无需 API 密钥，并带有“忽略”和“批准”按钮" width="924" height="294" data-path="images/replitai/replit-ai-integrations-confirmation-msg.png" />
</Frame>

点击“批准”即可继续使用由 Replit 管理的凭证；如果你更愿意使用自己的 API 密钥，则点击“忽略”。

你的用量会被自动记录，并按 API 公开价格计入你的 Replit 账户账单。

<div id="trazendo-sua-prpria-chave-de-api">
  ### 自带 API 密钥
</div>

如果你更愿意使用自己的 OpenAI、Anthropic、Google 或其他提供商的凭证，而不是 Replit 的 AI 集成，可以有以下几种做法：

**首次构建时**：在 prompt 中说明你要使用自己的 API 密钥：

<AiPrompt>
  Create a web app that uses OpenAI to summarize articles. Use my own OpenAI API key.
</AiPrompt>

你会在回复中看到提供商的名称 (不带&quot;由 Replit 管理&quot;字样) ，这表示 Agent 会向你索取 API 密钥。

**对于已有的 Replit App**：当 Agent 提示它要使用 Replit 的 AI 集成并弹出确认提示时，点击&quot;忽略&quot;而不是&quot;批准&quot;。

这两种情况下，Agent 都会先构建到第一个 checkpoint，然后再向你索取 API 密钥。这样 Agent 可以先把项目结构搭建好，再暂停下来收集你的凭证。

使用自己的 API 密钥时，费用由提供商直接向你收取，不会消耗 Replit 积分。

<div id="visualizando-seu-uso">
  ## 查看用量
</div>

所有 Replit AI 集成的用量都会显示在你的[用量页面](/zh/pt/billing/managing-spend)上，与你的其他 Replit 用量一并呈现。用量会按各个 Replit App 分项列出，让你清楚了解 AI 支出的具体去向。

<div id="provedores-suportados">
  ## 支持的提供商
</div>

Replit AI 集成目前支持:

* **OpenAI**:用于文本生成、推理和音频的多模态模型。支持 chat completions、responses、图像生成、音频转录(`gpt-4o-transcribe`、`gpt-4o-mini-transcribe`)以及音频输出(`gpt-audio`、`gpt-audio-mini`)。
* **Anthropic**:用于推理、写作和编程的多模态模型。支持 Messages API 和网页搜索交互。
* **Google (Gemini)**:用于文本生成和推理的多模态模型。支持文本和图像生成。
* **OpenRouter**:可访问 Microsoft(Phi 系列)、Meta(Llama 系列)、Mistral、Qwen、DeepSeek、Nvidia、Amazon 等提供商的模型。

<Note>
  Replit AI 集成支持**文本、图像和音频输出**,不支持视频输出。如果你需要视频生成功能,则需要自备支持该功能的提供商的 API 密钥。
</Note>

<div id="privacidade-e-disponibilidade-do-openrouter">
  ## OpenRouter 的隐私与可用性
</div>

当你通过 Replit AI 集成使用 OpenRouter 时，请求会以特定的隐私设置发送，以保护你的数据。了解这些设置很重要，因为它们会影响你能使用哪些模型。

<div id="configuraes-de-privacidade-para-usurios-self-serve">
  ### 自助服务用户的隐私设置
</div>

对于个人用户和团队用户，Replit 会按以下隐私默认值配置 OpenRouter 请求：

* **付费端点训练已关闭**：付费模型提供方不会将您的数据用于训练
* **免费端点训练已开启**：免费模型提供方可以使用您的 prompt 和补全内容进行训练
* **免费端点发布已开启**：免费提供方可以将您的 prompt 和补全内容发布到公开数据集中
* **输入/输出日志记录已关闭**：OpenRouter 不会为享受 1% 账单折扣而记录您的请求和响应
* **分析 Cookie 已关闭**：不使用分析 Cookie

这些设置在优先保护您隐私的同时，仍让您能使用尽可能广泛的模型。不过，如果某些模型要求的隐私设置与上述配置不同，则**这些模型可能无法使用**。

<div id="configuraes-de-privacidade-para-enterprise">
  ### Enterprise 隐私设置
</div>

对于 Enterprise 组织，Replit 会实施更严格的隐私控制：

* **仅限零数据保留 (ZDR) 端点**：仅提供采用零数据保留政策的模型
* 上述面向自助服务用户的所有隐私设置同样适用
* 这可确保 Enterprise 请求仅路由至不保留任何数据的端点

由于 Enterprise 仅允许使用 ZDR 端点，与自助服务用户相比，**可选模型的范围更为有限**。这一取舍为企业工作负载提供了最高级别的数据隐私保护。

<div id="disponibilidade-do-plano">
  ## 方案可用性
</div>

Replit AI 集成需要付费方案。访问权限的具体方式取决于你所使用的方案。

<div id="starter-gratuito">
  ### Starter (免费)
</div>

在 Starter 方案中，Replit AI 集成已被禁用。你仍然可以使用自己的 API 密钥来构建 AI 应用。请参阅[使用你自己的 API 密钥](#bringing-your-own-api-key)。

<div id="core">
  ### Core
</div>

在 Core 方案中，你可以使用 Replit AI 集成构建 AI 应用，凭据由 Replit 统一管理——无需自行管理 API 密钥。

<div id="pro-e-enterprise">
  ### Pro 和 Enterprise
</div>

对于 Pro 和 Enterprise 组织，Replit AI 集成的访问权限默认处于关闭状态。组织管理员可以在组织设置页面中控制访问权限：

1. 进入组织设置
2. 找到 Replit AI 集成部分
3. 为组织启用或禁用访问权限

启用后，组织成员即可在自己的应用中使用 Replit AI 集成，所有用量都会被记录并计入组织账户的账单。禁用后，成员需自行提供 API 密钥才能使用 AI 模型提供商。

<div id="casos-de-uso">
  ## 使用场景
</div>

在任意技术栈上构建强大的 AI 应用：

* **内容生成**：总结文章、生成描述、创作内容
* **分析与洞察**：提取关键信息、分析情感倾向、对文本分类
* **对话式界面**：构建聊天机器人和 AI 助手
* **文本转换**：翻译、改写或格式化内容
* **代码辅助**：生成代码片段、讲解算法、审查代码

  </Accordion>
