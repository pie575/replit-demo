Une fois cette étape terminée, Velocity sera publiée sur `velocityrentals.com` plutôt que sur `velocity.replit.app`.

<YouTubeEmbed videoId="rGYdyb58wJY" />

Vous avez ajouté à Velocity une fonctionnalité de connexion, une base de données, des paiements et une intégration de calendrier. Configurons maintenant une URL digne d’une véritable marque de location. Dans ce guide, vous allez migrer Velocity vers `velocityrentals.com` — remplacez-le par un domaine qui vous appartient.

<div id="velocityreplit-url">
  ## Vérifiez d’abord que Velocity fonctionne correctement sur l’URL Replit
</div>

Avant de modifier les paramètres DNS, vérifiez que l’URL publiée `velocity.replit.app` fonctionne correctement. Ouvrez-la dans un nouvel onglet du navigateur et vérifiez les points suivants :

* La page de la flotte se charge.
* Les clients peuvent se connecter, réserver une voiture et consulter leur réservation après avoir actualisé la page.
* Le tunnel de paiement de l’acompte Stripe s’ouvre et la réservation est confirmée avec une carte de test.
* L’événement Google Agenda apparaît dans l’agenda du client ayant effectué la réservation.

Si l’un de ces éléments ne fonctionne pas, corrigez-le avant de modifier les paramètres DNS. Consultez le [dépannage de la publication](/fr/ja/build/troubleshooting).

<div id="replitvelocityrentalscom">
  ## Connecter velocityrentals.com à Replit
</div>

Ouvrez les paramètres de Publishing de Velocity et ajoutez `velocityrentals.com` comme domaine personnalisé. Replit affichera deux enregistrements DNS : copiez-les exactement tels qu’ils apparaissent.

<Frame>
  <img src="/assets/mirror/dns-records-d64f183fa655.png" alt="Boîte de dialogue Replit des domaines personnalisés dans les paramètres de Publishing de Velocity. velocityrentals.com est saisi et deux enregistrements DNS copiables sont affichés (un enregistrement A et un enregistrement TXT de vérification)" width="1280" height="720" data-path="images/velocity/add-custom-domain/dns-records.png" />
</Frame>

Ensuite, ouvrez le tableau de bord de votre fournisseur de domaine (Namecheap, Cloudflare, Google Domains, GoDaddy, etc.) et ajoutez ces enregistrements exactement comme indiqué. Si vous souhaitez qu’Agent vous guide pour un fournisseur spécifique :

<AiPrompt>
  Je déplace Velocity de velocity.replit.app vers velocityrentals.com. Mon domaine est enregistré chez [nom de votre fournisseur de domaine].<br />
  Indique-moi exactement quels enregistrements DNS ajouter et dans quel ordre.<br />
  Utilise les valeurs affichées dans Replit — n’invente pas de valeurs d’enregistrement.<br />
  Explique-moi comment vérifier que le domaine est connecté avant de m’attendre à ce qu’il fonctionne.
</AiPrompt>

La propagation des modifications DNS peut prendre de quelques minutes à quelques heures. Lorsque Replit aura vérifié les enregistrements, « Verified » s’affichera à côté de `velocityrentals.com`.

<div id="velocityrentalscomvelocity">
  ## Tester Velocity sur velocityrentals.com
</div>

Lorsque Replit indique que le domaine est vérifié :

1. Ouvrez `https://velocityrentals.com` dans un nouvel onglet de navigateur. Un cadenas vert devrait s’afficher : HTTPS est activé automatiquement.
2. Connectez-vous en tant que client. La connexion devrait toujours fonctionner (Replit Auth gère automatiquement le nouveau domaine).
3. Réservez une voiture, puis actualisez la page pour vérifier que les informations de réservation sont conservées.
4. Ouvrez le tunnel de paiement de l’acompte Stripe. La page devrait afficher `velocityrentals.com` comme URL du marchand.
5. Confirmez la réservation et vérifiez que l’événement Google Agenda apparaît toujours dans l’agenda du client.

Si vous rencontrez des problèmes de connexion, de tunnel de paiement ou d’intégration d’agenda uniquement sur `velocityrentals.com`, décrivez précisément le symptôme à Agent :

<AiPrompt>
  Velocity fonctionne sur velocity.replit.app, mais [décrivez ce qui ne fonctionne pas] sur velocityrentals.com.<br />
  Indique-moi si le correctif se trouve dans le DNS, dans les paramètres de Replit ou dans les paramètres d’un fournisseur tiers (comme Stripe ou Google).<br />
  Indique-moi la prochaine vérification la plus sûre.
</AiPrompt>

Velocity est maintenant publié sous une véritable URL de marque de location. Partagez `velocityrentals.com` avec vos clients : « replit.app » n’apparaît nulle part.

<div id="section-2">
  ## Si vous avez besoin d’aide supplémentaire
</div>

* **`velocityrentals.com` ne se charge pas immédiatement :** la propagation des modifications DNS peut prendre quelques heures. Patientez un moment, puis vérifiez à nouveau avant de modifier davantage les paramètres.
* **L’URL Replit fonctionne, mais pas le domaine personnalisé :** vérifiez que vos enregistrements DNS correspondent exactement à ceux affichés dans Replit. Les erreurs courantes incluent les points finaux, les sous-domaines supplémentaires ou les anciens enregistrements.
* **Le tunnel de paiement Stripe affiche encore `velocity.replit.app` :** demandez à Agent de mettre à jour l’URL de redirection Stripe vers `velocityrentals.com`.
* **Vous ne possédez pas encore de domaine :** achetez-en un via Replit — consultez [Acheter un domaine](/fr/ja/build/domain-purchasing).
