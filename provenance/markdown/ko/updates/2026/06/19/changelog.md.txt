## 통합

### Claude에서 Replit 사용하기

Replit이 이제 Claude의 커넥터로 사용 가능합니다. 한 번 연결하면 Claude와의 대화에서 직접 Replit 앱을 생성하고, 업데이트하고, 질문할 수 있습니다. Claude Design에서 바로 Replit으로 디자인을 전송할 수도 있습니다. 실행 가능한 앱으로 열리고 Agent가 완성된 제품으로 만들 계획을 세웁니다.

### 새 MCP 서버: Apollo와 Black Forest Labs

두 개의 새 서버가 원클릭 MCP 카탈로그에 추가됩니다. **Apollo**를 연결하여 Agent와의 대화에서 계정과 연락처를 조사하고 아웃바운드 목록을 구축하세요. **Black Forest Labs**를 연결하여 프로젝트를 떠나지 않고 FLUX 이미지를 생성하고 편집하세요.

[MCP 목록](/ko/features/mcp/overview)에서 더 알아보세요.

## Agent

### Voice Mode

이제 소리로 구축하고 싶은 것을 설명할 수 있습니다. Agent 채팅창의 마이크를 탭하고, 프롬프트를 말하면 Replit이 음성을 편집 가능한 텍스트로 변환합니다. 텍스트를 검토하고 필요하면 편집한 후 다른 메시지처럼 전송하세요. Voice Mode는 모든 Replit 플랜에서 사용 가능합니다.

## 팀 및 Enterprise

### Enterprise 워크스페이스에 외부 게스트 초대하기

Enterprise 관리자는 이제 ID 공급업체를 거치지 않고 외부 협업자를 Guest로 워크스페이스에 초대할 수 있습니다. 외부 이메일과 단일 앱을 공유하면 해당 사람이 해당 앱에만 액세스 권한이 있는 Guest로 참여합니다. Guest는 전용 테이블에 표시되어 어떤 앱에 액세스할 수 있는지 확인하고 언제든지 액세스를 취소할 수 있습니다.
