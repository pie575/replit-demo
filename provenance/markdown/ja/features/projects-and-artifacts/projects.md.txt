## プロジェクトとは？

プロジェクトはReplitで構築するすべてのコンテナです。コード、データ、作成するすべてのアーティファクト（Webアプリ、モバイルアプリ、スライドデッキ、データダッシュボード、動画）を保持します。Agentに何を望むかを伝えると、プロジェクトを設定してその中にアーティファクトを構築します。

プロジェクトを机の上のワークスペースのように考えてください。すべてが一か所にあり、同じ情報を共有できますが、それぞれの部品は異なる目的を果たします。

例えば、Agentにフィットネストラッキングアプリの構築を依頼すると、モバイルアプリのアーティファクトと、それが機能するために必要なバックエンド、データベース、ストレージを含むプロジェクトが作成されます。

<ArtifactGrid />

主要な概念：

* **プロジェクト**：すべてを保持するコンテナ — コード、データ、すべてのアーティファクト
* **アーティファクト**：プロジェクト内の公開可能な成果物（Webアプリ、スライドデッキ、動画など）
* **リソース**：すべてのアーティファクトがバックエンド、データベース、ファイルストレージに自動的にアクセスできる — セットアップ不要

<Note>
  公開するとプロジェクト全体が一度にデプロイされます。すべてのアーティファクトが同時に公開されるため、常に同期しています。
</Note>

## 構築できるもの

| タイプ                                                             | 説明                                   | 例                             |
| --------------------------------------------------------------- | ------------------------------------ | ----------------------------- |
| **[Webアプリ](/ja/features/artifact-types/web-apps)**              | ブラウザでアクセスするウェブサイトやWebアプリケーション        | オンラインストア、予約ツール、ポートフォリオサイト     |
| **[モバイルアプリ](/ja/features/artifact-types/building-mobile-apps)** | スマートフォンにインストールするネイティブアプリ             | フィットネストラッカー、レストラン注文アプリ        |
| **[データビジュアライゼーション](/ja/features/artifact-types/data-apps)**     | チャート、フィルター、ライブデータを持つインタラクティブなダッシュボード | 売上レポート、メトリクストラッカー、分析ビュー       |
| **[スライドデッキ](/ja/features/artifact-types/slide-decks)**          | プレゼンテーションやエクスポートができるスライド             | ピッチデッキ、チームアップデート、製品概要         |
| **[アニメーション](/ja/features/artifact-types/animated-videos)**      | MP4としてエクスポートできるモーショングラフィクス動画         | 製品ローンチ動画、説明動画、ソーシャルメディアコンテンツ  |
| **3Dゲーム**                                                       | 3Dゲーム、シミュレーション、インタラクティブな体験           | パズルゲーム、物理シミュレーション、インタラクティブな体験 |
| **[デザイン](/ja/design/canvas)**                                   | デザインキャンバスで探索するビジュアルの方向性とプロトタイプ       | ムードボード、モックアップ、デザイン探索          |

一つのプロジェクトで複数のアーティファクトを保持できます。例えば、顧客向けのWebアプリ、チーム向けのモバイルアプリ、投資家向けのスライドデッキをすべて同じプロジェクトに構築できます。同じプロジェクト内のアーティファクトは自動的に同じデータとバックエンドロジックを共有します。詳しくは[アーティファクト](/ja/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project)を参照してください。

## プロジェクトを管理する

プロジェクトページには、作成したまたは招待されたすべてのプロジェクトが一覧表示されます。最近の作業にすばやく戻り、忙しいワークスペースで適切なプロジェクトを見つけるための最も速い方法です。

### 各プロジェクトの中身を一目で確認する

すべてのプロジェクトカードには、それが含むアーティファクト（Webアプリ、モバイルアプリ、スライドデッキ、データビジュアライゼーション、アニメーションごと）の小さなアイコンが表示されます。アイコンにホバーすると、カード上でそのアーティファクトのスクリーンショットをプレビューできるため、プロジェクトを開かずに区別できます。

### アーティファクトでフィルター

プロジェクトページの上部にある**ビルドタイプ**ドロップダウンを使用して、アーティファクトでリストをフィルタリングします。一つを選択すると、そのタイプのアーティファクトを含むプロジェクトのみが表示されます：

* **Web** — Webアプリを含むプロジェクト
* **モバイル** — モバイルアプリを含むプロジェクト
* **データ** — データビジュアライゼーションを含むプロジェクト
* **スライド** — スライドデッキを含むプロジェクト
* **デザイン** — デザインモードのプロジェクト
* **3Dゲーム**、**エージェント＆オートメーション**など

**すべてのビルドタイプ**を選択してフィルターをクリアします。

### 最後に開いた順に並べ替える

プロジェクトページはデフォルトで**あなたが最後に開いた順**に並べられています — 最近作業したプロジェクトが一番上に表示されます。これはチームワークスペースで特に便利で、他のメンバーの最近の編集によって現在の作業が埋もれることがありません。

別の列ヘッダー（例：**最終更新**や**名前**）を選択して並べ替えを変更できます。

### よく使うプロジェクトをピン留めする

プロジェクトをリストの一番上に固定するためにピン留めします。ピンは**あなた個人のもの** — チームワークスペースでプロジェクトをピン留めしても、他のメンバーが見るものは変わりません。

プロジェクトをピン留めするには、プロジェクトカードのオーバーフローメニュー（三点ドット）を開いて**ピン留め**を選択します。ピンを解除するには同じメニューから**ピンを外す**を選択します。
