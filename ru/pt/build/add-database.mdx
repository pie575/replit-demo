Вы добавили вход в Velocity в разделе [Добавление входа](/ru/pt/build/add-login). Но автомобили в автопарке и бронирования клиентов по-прежнему исчезают при обновлении страницы — они существуют только в браузере. Добавьте базу данных, чтобы всё сохранялось.

<div id="pea-ao-agent-para-salvar-os-dados">
  ## Попросите Agent сохранять данные
</div>

Для Velocity используйте Neon — управляемую базу данных Postgres от Replit. Neon корректно обрабатывает одновременные бронирования, масштабируется вместе с реальным клиентским трафиком, а Agent автоматически создаст её с отдельными средами разработки и продакшена. Не нужно регистрироваться в панели Neon или вставлять какие-либо ключи.

<AiPrompt>
  Сохраните данные Velocity в базе данных, чтобы автомобили, их доступность и бронирования не исчезали при обновлении.<br />
  Используйте Neon (Postgres).<br />
  Сохраните: каждый автомобиль (марка, модель, год, стоимость в сутки, фото, местоположение), календарь доступности каждого автомобиля и каждое бронирование (дата получения, дата возврата, автомобиль, клиент).<br />
  Свяжите каждое бронирование с вошедшим в систему клиентом, чтобы каждый пользователь видел только свои бронирования.<br />
  Не допускайте бронирования одного автомобиля на пересекающиеся даты.<br />
  Скажите, что нужно протестировать после внесения изменений.
</AiPrompt>

Agent создаст базу данных Neon, перенесёт в неё автопарк и бронирования из памяти и добавит проверку пересечений, чтобы одну и ту же Lamborghini нельзя было забронировать дважды.

<div id="teste-que-tudo-persiste">
  ## Проверьте, что всё сохраняется
</div>

1. Откройте Velocity в Preview и забронируйте автомобиль на ближайшую субботу.
2. Обновите страницу. Бронирование по-прежнему должно отображаться в разделе «Мои бронирования».
3. Перезапустите App через Chat с Agent. Автопарк и бронирование должны остаться на месте.
4. Попробуйте забронировать тот же автомобиль на ту же субботу из второй учётной записи. Velocity должна сообщить, что автомобиль недоступен, и предложить другую дату или другой автомобиль.
5. Выйдите из учётной записи и войдите снова. Ваше бронирование должно сохраниться.

Если бронирование исчезнет на каком-либо этапе, вставьте точное описание проблемы в Agent:

<AiPrompt>
  Я забронировал автомобиль в Velocity, но после обновления бронирование исчезает.<br />
  Проверьте, сохраняется ли бронирование в базе данных или хранится только на странице.<br />
  Исправьте минимально необходимое и скажите, как это проверить.
</AiPrompt>

Вы также можете попросить Agent создать простую административную страницу, чтобы посмотреть, что хранится в базе данных:

<AiPrompt>
  Покажите мне простую административную страницу в Velocity со списком всех автомобилей и всех бронирований в базе данных, сгруппированных по автомобилям.<br />
  Показывайте её только мне как владельцу проекта.
</AiPrompt>

<div id="publicar-e-confirmar-na-url-pblica">
  ## Опубликуйте и проверьте приложение по общедоступному URL
</div>

Настройка Neon через Agent с самого начала предоставляет Velocity отдельные среды разработки и продакшена. Снова опубликуйте Velocity через чат с Agent или плитку публикации, затем откройте общедоступный URL в новой вкладке. Replit автоматически подключает учётные данные Neon для продакшена к опубликованному развёртыванию — создайте бронирование по общедоступному URL, обновите страницу и убедитесь, что оно сохранилось.

Теперь Velocity запоминает каждый автомобиль, каждую доступную дату и каждое бронирование. Следующее обновление не приведёт к потере бронирований.

<div id="precisa-de-mais-ajuda">
  ## Нужна дополнительная помощь?
</div>

* **Бронирования сохраняются в Preview, но не на публичном URL:** попросите Agent подтвердить, что учётные данные Neon для продакшена подключены к опубликованному развёртыванию.
* **Данные сложно просматривать:** попросите Agent добавить простую административную страницу со списком всех данных в базе.
* **Вы хотите предварительно заполнить автопарк:** попросите Agent добавить одноразовый скрипт, который загрузит ваши реальные автомобили в базу данных.
* **Вам нужна база данных без настройки для быстрого прототипа:** используйте [Replit Database](/ru/pt/features/data-and-storage/sql-database) — она встроена в каждый Repl и не требует отдельного выделения ресурсов.
