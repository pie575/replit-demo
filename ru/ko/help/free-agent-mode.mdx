title: "Бесплатный режим Agent"
description: "Узнайте, как бесплатный режим дает подписчикам Starter, Core и Pro возможность использовать Agent бесплатно."
---

<Note>
  Некоторые детали, касающиеся лимитов, могут измениться до момента выпуска.
</Note>

Бесплатный режим позволяет подписчикам Starter, Core и Pro использовать Agent без дополнительной платы. В план Starter бесплатный режим входит в рамках существующих ограничений. В планы Core и Pro включен лимит бесплатного режима. Начните диалог, чтобы изучить возможности, спланировать или создать что-либо либо попросить о помощи. Если для вашего запроса требуется платный режим или платная операция, Replit четко сообщит об этом до начала действий, за которые взимается плата.

<div id="section">
  ## Чем это удобно
</div>

* Вы начинаете сразу с диалога, а не с настройки.
* Можно проверить идею и продвинуться в работе, прежде чем решать, нужны ли дополнительные возможности.
* Вы сохраняете контроль даже в тех запросах, которые требуют платных операций.
* Работа, выполненная в бесплатном режиме, отмечается понятной меткой **Free**.

<div id="section-2">
  ## Как это работает
</div>

1. Новые сессии Starter, Core и Pro запускаются в бесплатном режиме.
2. Задачи, которые укладываются в рамки бесплатного режима, выполняются без уведомлений о платных операциях.
3. Если платный режим справится с запросом лучше, Agent сообщит об этом и предложит варианты.
4. Вы можете разрешить платный режим только для этого запроса или попросить Agent продолжить в бесплатном режиме.
5. После разового перехода на платный режим система снова возвращается к бесплатному.

  ## Три режима Agent
</div>

<CardGroup cols={3}>
  <Card title="Free">
    Бесплатные задачи Agent для подписчиков Starter, Core и Pro.
  </Card>

  <Card title="Power">
    Платный режим среднего уровня по доступной цене — для задач, где нужно больше возможностей.
  </Card>

  <Card title="Max">
    Платный режим высшего уровня для самых сложных задач с лучшими передовыми моделями.
  </Card>
</CardGroup>

Бесплатный режим доступен подписчикам Starter, Core и Pro. В Starter бесплатный режим действует в рамках существующих лимитов. В Core и Pro предусмотрен лимит бесплатного режима, причём у Pro недельный лимит выше. Если нужно больше возможностей, можно выбрать платные режимы Agent.

<Note>
  **Если вы достигли лимита:** в Starter бесплатный режим действует в рамках существующих лимитов. В Core и Pro лимит бесплатного режима обновляется каждые 5 часов и ограничен недельным лимитом. Текущее состояние можно посмотреть в разделе **Settings → Usage**. Replit заранее предупредит о приближении к лимиту. Если лимит исчерпан, переключитесь на платный режим или дождитесь обновления квоты.
</Note>

<div id="section-3">
  ## Часто задаваемые вопросы
</div>

<AccordionGroup>
  <Accordion title="Действительно ли бесплатный режим бесплатен? Теперь Replit бесплатный?">
    Бесплатный режим включён в подписки Starter, Core и Pro. В Starter он доступен с текущими лимитами. В Core и Pro предусмотрен лимит бесплатного режима. Это не отдельный бесплатный тариф.
  </Accordion>

  <Accordion title="Это то же самое, что платные режимы Agent?">
    Нет. Бесплатный режим позволяет использовать Agent бесплатно в пределах лимита. Power и Max — платные режимы для задач, требующих больше возможностей.
  </Accordion>

  <Accordion title="Что случилось с Economy и Power? Режимы изменились?">
    Названия платных режимов изменились. Economy теперь называется Power — это режим среднего уровня с мощными моделями по разумной цене. Режим, ранее называвшийся Power, теперь называется Max и является режимом высшего уровня. Текущие настройки режимов сохраняются под новыми названиями.
  </Accordion>

  <Accordion title="Какой режим лучше?">
    Max. Power — платный режим среднего уровня, предлагающий больше возможностей по разумной цене. Max — платный режим высшего уровня для самых сложных задач.
  </Accordion>

  <Accordion title="Что произойдёт, если для запроса потребуется платная операция?">
    Agent объяснит, что для выполнения запроса требуется платный режим или функция, и попросит подтверждение перед продолжением. Вы можете одобрить платный вариант только для этого запроса или продолжить в бесплатном режиме.
  </Accordion>

  <Accordion title="Если Agent предлагает перейти на платный режим, плата взимается автоматически?">
    Нет. Перед началом платного запроса требуется ваше подтверждение.
  </Accordion>

  <Accordion title="Можно ли отказаться от платной опции?">
    Да. Вы можете продолжить работу в бесплатном режиме.
  </Accordion>

  <Accordion title="Что произойдёт после одобрения перехода на платный режим?">
    Одобрение действует только для этого запроса. После этого Agent вернётся в бесплатный режим.
  </Accordion>

  <Accordion title="Почему я достиг лимита? Когда он сбросится?">
    В Starter бесплатный режим доступен с текущими лимитами. В Core и Pro лимит бесплатного режима сбрасывается каждые 5 часов и имеет недельное ограничение. Проверьте текущий статус в **Settings → Usage**. Когда лимит будет достигнут, переключитесь на платный режим или дождитесь сброса, чтобы продолжить.
  </Accordion>

  <Accordion title="Можно ли использовать бесплатный режим в Enterprise?">
    На момент запуска это недоступно. Рабочие пространства Enterprise вскоре получат отдельный опыт работы с Agent. За подробностями обратитесь к администратору.
  </Accordion>
</AccordionGroup>

<div id="section-4">
  ## Подробнее о бесплатном режиме
</div>

<AccordionGroup>
  <Accordion title="Бесплатный режим — это то же, что Lite?">
    Для пользователей Starter режим, ранее называвшийся Lite, теперь стал бесплатным. Если вы использовали Lite для доступа к более доступным моделям, можно вручную выбрать эти модели в режиме Power, отключив Auto.
  </Accordion>

  <Accordion title="Можно ли создать полноценное приложение в бесплатном режиме?">
    Да. В бесплатном режиме можно создать полноценное приложение и постоянно его улучшать.
  </Accordion>

  <Accordion title="Чем отличаются Free, Power и Max?">
    Бесплатный режим предоставляет подписчикам Starter, Core и Pro бесплатный доступ к Agent для повседневных задач. Для Starter бесплатный режим доступен в рамках существующих лимитов. Core и Pro включают лимит бесплатного режима. Power — это платный режим среднего уровня с расширенными возможностями по разумной цене. Max — платный режим высшего уровня для самых сложных задач.
  </Accordion>

  <Accordion title="Когда следует перейти с бесплатного режима?">
    Используйте бесплатный режим для повседневных задач. Переключайтесь, если для сложных задач вам нужны более качественные результаты или возможности, недоступные в бесплатном режиме.
  </Accordion>

  <Accordion title="Можно ли создавать видео в бесплатном режиме?">
    Нет. Создание видео — функция платных режимов, недоступная в бесплатном режиме.
  </Accordion>

  <Accordion title="Что такое новый интерфейс Conversations?">
    Чат и возможности создания остаются в одном месте. В рамках одного разговора можно исследовать идеи, планировать работу или начать проект.
  </Accordion>

  <Accordion title="Становится ли отдельный чат частью опубликованного приложения?">
    Нет. Разговоры остаются отдельными, пока вы не создадите или не измените проект.
  </Accordion>

  <Accordion title="Можно ли работать над существующими проектами в бесплатном режиме?">
    Да. Он поддерживает повседневное обслуживание и внесение изменений в существующие проекты.
  </Accordion>
</AccordionGroup>
