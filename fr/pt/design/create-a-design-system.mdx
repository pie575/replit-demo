Il existe deux façons de créer un design system, selon l’état actuel de votre marque.

<div id="do-zero-pea-na-home-page">
  ## Partir de zéro : faites votre demande depuis la page d’accueil
</div>

Commencez ici si le système existe déjà dans votre tête (ou dans les directives de votre marque), mais n’a encore été concrétisé dans aucun design.

<Steps>
  <Step title="Faites votre demande dans le champ de création">
    Sur la page d’accueil de Replit, décrivez le design system souhaité dans le champ de prompt — par exemple : *&quot;Créez un design system pour Velocity, une marque haut de gamme de location de supercars.&quot;*

    <Frame>
      <img src="/assets/mirror/ds-home-create-7f04110e1f71.png" alt="Le champ de prompt de la page d’accueil avec un prompt de création de design system" width="800" height="240" data-path="images/design/replit-design/ds-home-create.png" />
    </Frame>
  </Step>

  <Step title="Répondez aux questions">
    Agent vous pose quelques questions sur votre système — personnalité de la marque, couleurs et préférences typographiques. Vous pouvez également lui indiquer une source : une URL Figma, un site web, du code, des images de référence, des assets de marque ou un fichier DESIGN.md existant.
  </Step>
</Steps>

<div id="a-partir-de-um-mockup-extraia-o-design-system">
  ## À partir d’une maquette : extraire le design system
</div>

Commencez ici si vous avez déjà un design que vous adorez — un frame généré, un template autonome — et souhaitez que tout le reste s’y harmonise.

<Steps>
  <Step title="Sélectionnez la maquette">
    Sur le Canvas, cliquez sur la maquette dont vous souhaitez reprendre le style visuel.
  </Step>

  <Step title="Extrayez-le via le menu à trois points">
    Ouvrez le menu **⋯** (trois points) du frame et choisissez **Extract design system**. Agent extrait les tokens, les couleurs et la typographie de la maquette pour créer un guide de style vivant, puis l’applique à l’ensemble du design.

    <Frame>
      <img src="/assets/mirror/ds-extract-menu-3efbe8bb497e.png" alt="Détail de la barre d’actions d’un frame sélectionné avec le menu d’options supplémentaires ouvert, affichant Apply design system et Extract design system" width="958" height="320" data-path="images/design/replit-design/ds-extract-menu.png" />
    </Frame>
  </Step>
</Steps>

<div id="revise-e-salve">
  ## Révisez et enregistrez
</div>

Quoi qu’il en soit, vérifiez ce qui a été généré : un guide de style vivant avec vos couleurs (par fonction — principale, d’accentuation, neutre…), votre échelle typographique et vos tokens (stockés dans `tokens.json`, qui alimente les variables CSS). Sélectionnez ensuite **Save design system** pour le conserver dans votre workspace.
