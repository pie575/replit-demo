Voice Mode로 만들고 싶은 것을 소리 내어 설명해 보세요. Agent 채팅 입력창에서 마이크를 누르고 prompt를 말하면 Replit이 음성을 편집 가능한 텍스트로 전사합니다. 텍스트를 검토하고 필요한 부분을 수정한 뒤 다른 메시지와 똑같이 전송하면 됩니다.

Voice Mode는 타이핑이 느리거나 번거로울 때 유용합니다. 특히 모바일에서는 긴 prompt를 엄지로 입력하는 것보다 말로 전달하는 편이 훨씬 빠릅니다.

<Note>
  Voice Mode는 음성을 채팅 입력창의 텍스트로 변환합니다. Agent의 응답을 소리 내어
  읽어 주지는 않습니다. 메시지는 그대로 텍스트로 전송되며, Agent도 평소처럼
  chat에서 답변합니다.
</Note>

<div id="how-it-works">
  ## 작동 방식
</div>

Voice Mode는 음성을 녹음해 텍스트로 전사한 뒤, 보내기 전에 검토할 수 있도록 그 결과를 채팅 입력창에 넣어 줍니다.

1. Agent를 열고 채팅 입력창에서 마이크를 선택합니다.
2. 브라우저나 기기에서 권한을 요청하면 마이크 접근을 허용합니다.
3. prompt를 말합니다. Agent가 녹음 중이면 파형이 표시됩니다.
4. 말을 마쳤으면 녹음을 중지합니다. 잠시 말을 멈추거나 다른 탭으로 전환해도 녹음이 자동으로 중지됩니다.
5. 음성이 전사되는 동안 잠시 기다립니다.
6. 전사된 텍스트를 검토하고 필요하면 수정한 다음 메시지를 보냅니다.

전사 결과가 채팅 입력창에 일반 텍스트로 표시되므로 음성과 타이핑을 자유롭게 섞어 쓸 수 있습니다. prompt의 일부를 말로 입력한 뒤 나머지를 타이핑하거나, 보내기 전에 단어를 고칠 수도 있습니다.

<Tip>
  자연스럽게 말하세요. Voice Mode는 모든 단어를 그대로 받아쓰기보다 의도를 파악하는 데
  초점을 맞추므로, &quot;음&quot;, &quot;어&quot; 같은 군더더기 표현은 결과에 포함되지 않습니다.
</Tip>

<div id="where-you-can-use-it">
  ## 사용 가능한 위치
</div>

Voice Mode는 Agent 채팅 입력창에서 사용할 수 있습니다.

* **Project Editor**에서 Agent와 함께 앱을 작업할 때
* 홈 화면의 Agent prompt에서 **새 앱을 만들 때**

Voice Mode는 데스크톱 웹, 모바일 웹, Replit 모바일 앱에서 사용할 수 있습니다.

<div id="good-to-know">
  ## 알아두면 좋은 사항
</div>

Voice Mode를 사용할 때 다음 사항을 염두에 두세요:

| 세부 사항     | 예상되는 동작                                                                                  |
| --------- | ---------------------------------------------------------------------------------------- |
| 녹음 길이     | 한 번에 최대 6분까지 녹음할 수 있습니다. 한도에 도달하기 직전에 경고가 표시됩니다.                                         |
| 자동 중지     | 약 30초 동안 아무 소리가 없거나, 탭을 전환하거나 앱을 백그라운드로 보내면 녹음이 자동으로 중지됩니다.                              |
| 전송 전 검토   | 전사된 텍스트가 채팅 입력창에 입력되므로 전송하기 전에 읽고 수정할 수 있습니다. 자동으로 전송되는 내용은 없습니다.                        |
| 마이크 접근 권한 | Voice Mode를 사용하려면 마이크 사용 권한이 필요합니다. 녹음이 시작되지 않으면 브라우저와 기기에서 Replit의 마이크 접근을 허용했는지 확인하세요. |

<div id="availability">
  ## 사용 가능 여부
</div>

Voice Mode는 모든 Replit plan에서 사용할 수 있습니다. 오디오 녹음을 지원하는 브라우저와 기기에서는 Agent 채팅 입력창에 마이크가 표시되며, 처음 녹음할 때 마이크 권한을 요청하는 메시지가 나타납니다.
