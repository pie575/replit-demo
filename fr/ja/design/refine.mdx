Explorez largement, puis affinez en profondeur. Lorsqu’une frame se rapproche de ce que vous recherchez, peaufinez-la à l’aide de deux outils adaptés à votre façon de travailler.

* Échangez avec Agent dans vos propres mots, qu’il s’agisse de l’ensemble de la frame ou d’un seul élément
* Ajustez directement les éléments dans l’éditeur visuel — les modifications simples sont appliquées instantanément et ne consomment aucun crédit

<div id="section">
  ## Chat
</div>

Donnez des instructions à Agent comme si vous briefiez un designer en train de revoir votre projet. Sélectionnez un frame et décrivez les modifications dans le chat principal (*« Des couleurs plus chaleureuses »*, *« La section hero manque d’impact »*), ou choisissez l’outil **Chat** dans la barre d’outils, cliquez sur un élément et concentrez votre message sur cette partie.

<div id="section-2">
  ## Éditeur visuel
</div>

Si vous savez exactement ce que vous voulez, faites l&#39;économie du prompt. Dans la barre d&#39;outils, sélectionnez l&#39;outil **Edit**, puis cliquez sur n&#39;importe quel élément : l&#39;éditeur visuel s&#39;ouvre et affiche les propriétés modifiables de cet élément (contenu, disposition, couleurs, bordures, etc.). Les modifications simples, comme changer un texte, choisir une couleur ou ajuster les espacements, sont répercutées instantanément dans le code source, sans consommer de crédits.

<Frame caption="L'éditeur visuel avec l'outil Edit activé, un élément sélectionné et ses propriétés modifiables.">
  <img src="/assets/mirror/visual-editor-edit-tool-71d03803471f.png" alt="L'outil Edit est activé et un élément est sélectionné dans le frame du configurateur de voiture de sport. À droite s'affiche le panneau de l'éditeur visuel, avec les sections Layout, Color et Border, ainsi que les boutons Discard et Save edits" width="2000" height="1250" data-path="images/replitai/visual-editor-edit-tool.png" />
</Frame>

Pour une référence complète des contrôles, consultez [Éditeur visuel](/fr/ja/design/visual-editor).

<div id="section-3">
  ## Lequel utiliser
</div>

| Ce que vous voulez faire                                                                                       | Outil à utiliser |
| -------------------------------------------------------------------------------------------------------------- | ---------------- |
| Décrire le résultat et laisser Agent s&#39;occuper des détails                                                 | Chat             |
| Modifier le texte, la couleur, l&#39;espacement ou les images d&#39;un élément précis avec des valeurs connues | Éditeur visuel   |
| Repenser la structure ou le comportement d&#39;une section                                                     | Chat             |
| Faire des ajustements rapides sans consommer de crédits                                                        | Éditeur visuel   |

Les deux se complètent naturellement. Commencez par définir la direction dans le chat, puis peaufinez les détails en quelques clics dans l&#39;éditeur visuel.

<div id="section-5">
  ## Étapes suivantes
</div>

Une fois vos frames peaufinés, cessez de les affiner et passez à la réalisation concrète.

* [Construire votre design](/fr/ja/design/build-your-design) : transformez vos frames en une application fonctionnelle.
