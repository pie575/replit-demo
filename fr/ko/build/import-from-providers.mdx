Grâce à la fonctionnalité d’importation, vous pouvez intégrer du code ou des designs existants dans des Replit Apps et poursuivre le développement avec Agent.

<div id="section">
  ## Sources prises en charge
</div>

| Source                       | Contenu fourni                                     | Cas d&#39;usage idéal                                            |
| ---------------------------- | -------------------------------------------------- | ---------------------------------------------------------------- |
| GitHub                       | URL du dépôt ou sélecteur de dépôt                 | Importer des dépôts publics et privés                            |
| Bitbucket                    | URL du dépôt ou sélecteur de dépôt                 | Importer des dépôts hébergés sur Bitbucket                       |
| Vercel                       | Dépôt GitHub sous-jacent au projet Vercel          | Migrer des applications Vercel                                   |
| Figma                        | URL de la frame                                    | Convertir des designs en applications React                      |
| Claude                       | Designs envoyés depuis Claude                      | Convertir des designs Claude en applications interactives        |
| Bolt                         | Dépôt GitHub exporté depuis Bolt                   | Migrer des projets Bolt                                          |
| Lovable                      | Dépôt GitHub exporté depuis Lovable                | Migrer des projets Lovable                                       |
| Base44                       | Dépôt GitHub exporté depuis Base44                 | Migrer des projets Base44                                        |
| ZIP                          | Téléversement d&#39;un fichier `.zip`              | Importer des archives de projets locaux                          |
| Feuille de calcul            | Fichiers `.xlsx`, `.csv` ou URL Google Sheets      | Créer des applications à partir de données de feuilles de calcul |
| Export d&#39;un ancien Agent | Dépôt GitHub exporté depuis une ancienne App Agent | Réimporter d&#39;anciennes Apps Agent                            |
| Projet vide                  | Aucun                                              | Utilisateurs avancés souhaitant un projet vide, sans Agent       |

<Note>Replit vérifie la compatibilité avant de lancer l&#39;importation.</Note>

Pour les designs Figma, consultez [Importer des designs Figma dans Replit Design](/fr/ko/design/import-figma-designs-into-replit-design).

Pour les designs envoyés depuis Claude, consultez [Importer des designs Claude dans Replit Design](/fr/ko/design/import-claude-designs-into-replit-design).

    ⏰ *Durée estimée : 4 minutes*

    Exportez votre projet Lovable vers GitHub, puis importez ce dépôt dans Replit.

    * Un projet Lovable exportable

    6. Sélectionnez **Import**.

Une reconnexion uniquement dans Connected Services ne résout pas le problème du flux d&#39;importation.

    <Steps>
      <Step title="Reconnectez GitHub dans Git Providers">
        Ouvrez la section **Git Providers** des paramètres de votre compte Replit, déconnectez GitHub, puis reconnectez-le depuis le même écran. Vos dépôts personnels devraient ensuite apparaître dans le menu déroulant d&#39;importation.

Si vous n&#39;êtes pas propriétaire de l&#39;organisation, un administrateur de l&#39;organisation devra peut-être effectuer cette étape.
      </Step>

<div id="section-3">
  ## Autres sources
</div>

<div id="bitbucket">
  ### Bitbucket
</div>

* Collez l’URL d’un dépôt Bitbucket ou connectez votre compte Bitbucket pour rechercher des dépôts.
* Lors de l’importation, la prise en charge par Agent peut être plus limitée que pour les projets hébergés sur GitHub.

<div id="section-4">
  ### Feuilles de calcul
</div>

* Importez un fichier Excel (`.xlsx`) ou CSV, ou collez l&#39;URL d&#39;une Google Sheet publique.
* Agent lit la structure de la feuille de calcul et crée une application full-stack, accompagnée d&#39;une base de données pré-remplie avec vos données.
* Une UI permettant de consulter, rechercher et gérer les enregistrements est incluse.

<div id="agent">
  ### Exportations précédentes d’Agent
</div>

* Réimportez une App Agent créée avec Agent et précédemment exportée depuis un dépôt GitHub.
* Replit préserve la structure spécifique à Agent (code, schéma de base de données et fonctionnalités backend).
* Les valeurs de la base de données et les secrets ne sont pas importés.

<div id="section-5">
  ### Projet vide
</div>

* Démarrez avec un projet entièrement vide, sans Agent, sans choix de framework ni structure générée.
* Idéal pour les utilisateurs avancés qui souhaitent contrôler entièrement la configuration du projet.

<div id="section-6">
  ## Limitations
</div>

* Les données des bases de données existantes ne sont pas migrées.
* Les importations ZIP sont limitées à 200 Mo.
* Certaines dépendances complexes ou propriétaires peuvent nécessiter une configuration manuelle.
* Le traitement des grands projets peut prendre plus de temps.

<div id="section-7">
  ## Bonnes pratiques
</div>

* Supprimez les identifiants sensibles avant l’importation.
* Veillez à ce que la structure du projet source reste claire.
* Vérifiez les dépendances et les commandes d’exécution après l’importation.
* Testez les principaux parcours avant la publication.

<div id="section-8">
  ## Dépannage
</div>

Si l’importation échoue, vérifiez d’abord les points suivants :

* **Erreurs de compatibilité** : vérifiez les fichiers de projet requis et les frameworks pris en charge.
* **Erreurs d’accès** : vérifiez les autorisations du dépôt ou de la source.
* **Erreurs de traitement** : simplifiez la structure du projet ou réduisez sa taille, puis réessayez.

Si le problème persiste, consultez le [Replit Community Hub](https://replit.com/community) ou [contactez l’assistance](https://replit.com/support).

<div id="section-9">
  ## Facturation
</div>

Les importations nécessitant une migration par Agent peuvent consommer des crédits. Le nombre de crédits consommés dépend de la complexité du projet.
