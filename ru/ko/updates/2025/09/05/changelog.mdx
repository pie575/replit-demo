  ## Платформа

<div id="general-agent">
  ### General Agent
</div>

<Frame>
  <img src="/assets/mirror/general-agent-240ff289e711.png" alt="Обложка General Agent" width="1040" height="572" data-path="images/replitai/general-agent.png" />
</Frame>

Replit Agent теперь работает с кодовыми базами на любом языке или фреймворке, которые запускаются в NixOS! Раньше он был ограничен определёнными шаблонами, а теперь поддерживает фреймворки для разработчиков, импорт из GitHub и любые пользовательские конфигурации проекта. Это масштабное расширение даёт полноценную поддержку ИИ-кодинга в сценариях Enterprise и рабочих процессах опытных пользователей.

Подробнее о General Agent читайте [здесь](/ru/core-concepts/agent/general-agent).

<div id="section-3">
  ### Режим планирования
</div>

<Frame>
  <img src="/assets/mirror/plan-mode-overview-8077807c63b9.png" alt="Интерфейс чата Agent в режиме планирования" width="916" height="362" data-path="images/replitai/plan-mode-overview.png" />
</Frame>

Режим планирования — это новый формат общения с Replit Agent, рассчитанный на вопросы, обсуждение идей и планирование задач. С его помощью можно попросить Agent составить список задач на будущее, а затем запустить длительные задачи в режиме сборки.

Подробнее о режиме планирования читайте [здесь](/ru/core-concepts/agent/plan-mode).

  ## Enterprise
</div>

<div id="gcp">
  ### Интеграция с GCP Marketplace
</div>

Корпоративные клиенты Enterprise теперь могут приобретать Replit напрямую через Google Cloud Platform Marketplace и оплачивать покупку имеющимися кредитами GCP. Это упрощает процесс закупки и позволяет организациям с бюджетом в GCP проще внедрять Replit в свои рабочие процессы разработки.
