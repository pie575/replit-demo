<div id="o-que-o-agent-geral">
  ## 什么是 Agent Geral？
</div>

Agent Geral 是使用 Replit Agent 最灵活的方式。你无需预先选择产物类型，也不必一开始就确定要构建什么。只需开始对话——创建 CSV、生成 PDF、研究某个主题，或在准备就绪后构建完整应用。

关键概念：

* **无需预先选择**：无需提前选择产物类型即可开始工作
* **任何输出**：生成文件 (CSV、PDF、文档) 、开展研究或构建应用
* **连接器**：读取和写入 BigQuery、Linear、Slack、Notion、Amplitude、Segment、Hex 等外部服务中的数据
* **渐进式披露**：从轻量聊天开始，自然扩展到完整的应用构建

<div id="como-acessar-o-agent-geral">
  ## 如何使用 Agent Geral
</div>

您可以通过以下几种方式使用 Agent Geral：

1. **在 Replit 首页输入提示词前选择“Geral”**
2. **打开任意现有项目**，直接开始与 Agent 对话
3. **选择任意[开发者框架](https://replit.com/templates)** — 所有开发者框架都会自动包含 Agent Geral
4. **从 GitHub [导入](/zh/pt/core-concepts/project-editor/app-setup/import)** — 从 GitHub 导入的项目会自动启用 Agent Geral

<div id="como-usar-o-agent-geral">
  ## 如何使用 Agent Geral
</div>

<div id="apenas-comece-a-conversar">
  ### 直接开始对话
</div>

打开一个项目，直接说出你的想法。你无需事先确定要构建什么具体内容——Agent 会结合你当前项目的上下文来工作，处理你提出的各种需求。

**提示词示例：**

* “总结这份文档的要点”
* “生成一份按收入排名前 100 的公司 CSV 表格”
* “我在 Linear 上最重要的五个工单是哪些？”
* “搭建一个使用 TypeScript 的 Vue.js 项目”

Agent 可以处理会话期间创建的文件、生成单文件输出，并在推理过程中执行代码——这些都无需你事先决定要构建什么。

<div id="conectando-servios-externos">
  ### 连接外部服务
</div>

连接你的工具，让 Agent 能够直接读取和写入数据：

1. 前往项目设置中的**连接器**
2. 连接你的服务 (BigQuery、Linear、Slack、Notion、Amplitude、Segment、Hex 等)
3. 让 Agent 通过这些服务读取或写入数据

**使用连接器的提示词示例：**

* “Linear 中有哪些未处理的工单？”
* “总结 Slack 中 #工程频道今天的消息”
* “从 BigQuery 获取上个月的销售数据”
* “显示我日历中即将举行的活动”
* “在 Linear 中为集成 bug 创建一个新工单”
* “在 Slack 的 #工程频道发送摘要”

<div id="do-chat-ao-aplicativo-completo">
  ### 从聊天到完整应用
</div>

准备开始构建时，直接告诉 Agent 即可。Agent 会从轻量聊天无缝切换到应用构建，无需重新开始或切换上下文。

* “将其转变为 Web 应用”
* “基于这些数据构建应用”
* “为这些指标创建仪表板”
* “用 Rust 配置 CLI 工具”

你可以轻松地开始——研究某个主题、生成报告、探索一些数据——并在合适的时机扩展为完整的应用构建。

<div id="o-que-voc-pode-construir">
  ## 你可以构建什么
</div>

* **知识工作**：无需构建应用即可进行研究、总结和分析
* **单文件输出**：CSV、PDF、文档、数据导出和格式化报告
* **数据应用**：查询已连接的服务，并在仪表板中可视化展示结果
* **任意框架或语言**：Angular、Vue、Svelte、Rust、Go、C#、Python tkinter、Godot 游戏、CLI 工具等
* **full-stack 应用**：准备就绪后，可基于聊天中的上下文构建完整的应用

<div id="o-que-esperar">
  ## 预期效果
</div>

Agent Geral 更强大、更灵活，但随之也会带来一些不确定性：

* **一次配置到位**：有时 Agent 能一次性完成全部配置
* **迭代式协作**：复杂的配置可能需要多轮打磨
* **技术限制**：某些技术在 Nix 环境中可能无法获得完整支持

<Note>
  与环境已预先配置好的标准 Agent 不同，Agent Geral 会自行搭建环境，并根据你的请求执行命令。当你准备好上线时，可能需要让它来配置部署。
</Note>

<div id="perguntas-frequentes">
  ## 常见问题
</div>

<Accordion title="Agent 能看到我的其他项目吗？">
  不能。每个聊天都仅属于一个项目。你无法让项目 A 与项目 B 相互沟通。
</Accordion>

<Accordion title="为什么它仍无法访问我的外部工具？">
  你需要先通过连接器连接服务。连接后，Agent 可以读取和写入这些服务中的内容，但默认并不具备访问权限。
</Accordion>

<Accordion title="有哪些可用的连接器？">
  目前支持 BigQuery、Linear、Slack、Notion、Amplitude、Segment、Hex 等。我们会定期添加更多连接器。
</Accordion>

<Accordion title="使用 Agent Geral 需要连接器吗？">
  不需要。连接器为可选项。无需连接任何外部服务，你也可以使用 Agent Geral 进行知识工作、生成文件和构建应用。
</Accordion>
