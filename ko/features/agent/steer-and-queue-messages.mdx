Agent가 작업 중일 때 follow-up 메시지는 Agent가 현재 수행 중인 작업, 즉 active **turn**을 바꾸거나,
해당 turn이 끝날 때까지 대기할 수 있습니다.

* **Steer**는 메시지를 active turn으로 전달합니다. Agent는 작업을 이어가면서 새로운 context를 반영합니다.
* **Queue**는 메시지를 다음 turn으로 저장해 둡니다. Agent는 active turn이 끝난 뒤에 해당 메시지를 처리합니다.

</div>

<div id="choose-how-replit-sends-follow-ups">
  ## Replit이 follow-up을 전송하는 방식 선택
</div>

Conversations와 Projects에 각각 다른 send behavior를 설정할 수 있습니다.

1. **Settings** &gt; **Personalization**을 엽니다.
2. **Agent**를 펼칩니다.
3. **Conversation send behavior**와 **Project send behavior**를 **Steer** 또는 **Queue**로 설정합니다.

<Frame caption="Agent 섹션의 Conversation 및 Project send behavior 설정.">
  <img src="/assets/mirror/agent-follow-ups-settings-98a4c5ca399e.png" alt="Steer 및 Queue 옵션과 함께 Conversation 및 Project send behavior를 보여주는 Agent 설정" width="3048" height="1372" data-path="images/replitai/agent-follow-ups-settings.png" />
</Frame>

<Info>
  Design 모드에서는 follow-up 메시지가 항상 steer됩니다. Conversation 및 Project send
  behavior 설정은 Design 모드에 적용되지 않습니다.
</Info>

설정한 방식과 반대로 메시지를 한 번만 보내려면
`Cmd+Enter`(Mac) 또는 `Ctrl+Enter`(Windows 및 Linux)를 누르세요.

<div id="work-with-queued-messages">
  ## 대기 중인 메시지 다루기
</div>

follow-up 메시지를 대기열에 추가하면 채팅 입력창 위에 Message Queue가 drawer 형태로
나타납니다. Agent는 active turn이 끝난 뒤 대기 중인 메시지를 순서대로 처리하며,
대기 중인 메시지를 모두 처리하면 drawer가 닫힙니다.

[Visual Editor](/ko/design/visual-editor)와 파일 첨부를 포함한 모든 메시지 옵션을
Queue에서 사용할 수 있습니다.

<Info>
  Agent는 데스크톱이나 모바일에서 활성 Project Editor session이 연결되어 있는
  동안에만 대기 중인 메시지를 자동으로 처리합니다.
</Info>

<div id="manage-the-queue">
  ### 대기열 관리
</div>

대기열 drawer가 열려 있을 때 다음 작업을 할 수 있습니다.

* **Steer now**: 대기 중인 메시지를 active turn으로 이동합니다.
* **메시지 편집**: Agent가 처리하기 전에 대기 중인 메시지를 수정합니다.
* **메시지 삭제**: 더 이상 필요 없는 메시지를 삭제합니다.
* **메시지 순서 변경**: 메시지를 끌어다 놓아 처리 순서를 바꿉니다.
* **메시지 추가**: 대기열에 follow-up 메시지를 추가로 보냅니다.

<div id="stop-the-active-turn">
  ## active turn 중지
</div>

상태 표시줄에서 **Stop**을 선택하면 현재 turn에서 진행 중인 Replit의 작업을 중단할 수 있습니다. 이후 Agent가 turn을 완료하거나 대기 중인 메시지를 처리할 때까지 기다리지 않고 바로 새 메시지를 보낼 수 있습니다.
