你可以统一管理连接器，让团队以一致、安全的方式使用各类集成。具体可用功能取决于你的计划：

* **Core 和 Pro**：**协作 workspace** 中支持连接器管理。由账户管理员为该 workspace 配置和管理连接，开发者可在该 workspace 内的应用中使用这些连接。
* **Enterprise**：面向整个组织的连接器管理，并提供高级控制能力——自定义 OAuth 客户端、API 密钥访问控制，以及使用你自己的密钥。

<div id="principais-recursos">
  ## 核心功能
</div>

* **集中管理**：管理员只需配置一次服务，开发者即可在该 workspace 的各个应用中使用。
* **可见性与审计**：查看哪些应用和成员正在使用哪些服务。
* **按应用授权与撤销**：无需改动代码即可撤销或轮换访问权限。

**仅限 Enterprise：**

* **基于角色的访问控制**：为 API 密钥提供最小权限和访问控制。
* **使用你自己的 OAuth**：使用组织自有的 OAuth 客户端并自定义作用域。
* **使用你自己的 OpenAI 密钥**：使用你自己的 OpenAI API 密钥，而非 Replit 的默认基础设施。

<div id="como-funciona">
  ## 工作原理
</div>

<Steps>
  <Step title="管理员配置服务">
    管理员使用凭证一次性完成服务配置。
  </Step>

  <Step title="管理员批准访问权限">
    管理员批准哪些群组可以使用该连接器 (Enterprise) ，或将其开放给协作 workspace (Core/Pro) 。
  </Step>

  <Step title="开发者使用连接器">
    成员只需在 workspace 或组织内的应用中向 Agent 提出需求，即可基于该服务进行构建。
  </Step>

  <Step title="管理员监控使用情况">
    管理员可以监控哪些成员和应用使用了哪些服务。
  </Step>
</Steps>

<div id="segurana-e-governana">
  ## 安全与治理
</div>

* 凭证和 token 由平台统一管理，不会存储在各个应用中。
* 集中撤销与轮换，无需改动代码。
* Enterprise：采用最小权限原则的范围化访问，并可选配置自定义 OAuth。

<div id="configurao-e-gerenciamento">
  ## 配置与管理
</div>

<div id="ativar-novos-conectores">
  ### 启用新连接器
</div>

<Steps>
  <Step title="进入集成页面">
    在协作 workspace (Core/Pro) 或组织主页 (Enterprise) 中，打开 **集成** 页面。
  </Step>

  <Step title="启用新连接器">
    选择右上角的 **启用新连接器**。
  </Step>

  <Step title="选择服务">
    选择要启用的服务 (例如 Notion、GitHub、Google、Outlook、Dropbox、Salesforce) 。
  </Step>

  <Step title="配置连接器">
    使用默认配置启用该连接器。仅 **Enterprise** 支持创建自定义 OAuth 连接器 (例如 Drive 作用域 `.../auth/drive.file`、`.../auth/drive.install`) 。
  </Step>

  <Step title="提交">
    选择 **提交**。
  </Step>
</Steps>

<div id="configurar-acesso-enterprise">
  ### 配置访问权限 (Enterprise)
</div>

1. 启用连接器后，选择**管理**。
2. 根据需要向特定群组授予访问权限。

<div id="modificar-conectores">
  ### 修改连接器
</div>

* 启用连接器后，选择**管理**。
* 删除连接器后，该 workspace (Core/Pro) 或组织 (Enterprise) 中的所有开发者都将无法再使用它。
* 在 Enterprise 中，你可以编辑自定义 OAuth 连接器的作用域。

<div id="comparao-de-planos">
  ## 计划对比
</div>

| 功能              | Core (协作 workspace)  | Pro (协作 workspace)  | Enterprise |
| --------------- | -------------------- | ------------------- | ---------- |
| 启用并管理连接器        | ✓                    | ✓                   | ✓          |
| 适用范围            | Workspace            | Workspace           | 组织         |
| 创建自定义 OAuth 客户端 | —                    | —                   | ✓          |
| 为 API 密钥设置访问控制  | —                    | —                   | ✓          |
| 使用自有 OpenAI 密钥  | —                    | —                   | ✓          |

<div id="use-sua-prpria-chave-openai-enterprise">
  ### 使用您自己的 OpenAI 密钥 (Enterprise)
</div>

Enterprise 客户可以通过连接器接入自己的 OpenAI API 密钥，而不使用 Replit 默认的 AI 基础设施。这样您就能沿用与 OpenAI 的现有协议，并通过自己的账户管理 AI 使用情况。
