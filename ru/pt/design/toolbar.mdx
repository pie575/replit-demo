Панель инструментов Canvas — это плавающая панель в нижней центральной части фрейма. На ней доступны инструменты для навигации, рисования, редактирования и добавления контента. Панель инструментов отображается в режиме Canvas.

<div id="ferramentas">
  ## Инструменты
</div>

При выборе инструмента он становится активным. Активный инструмент выделяется заливкой. Крайняя левая группа предназначена для навигации (Interact, Pan). Остальные инструменты используются для работы с содержимым и разметки. Инструменты взаимоисключающие: при выборе одного остальные отключаются.

<div id="interact">
  ### Interact
</div>

**Interact** — стандартный инструмент. Используйте его для выбора и перетаскивания фреймов, а также для взаимодействия с активным Artifact как с работающим приложением. Когда Interact активен, щелчок по фрейму выделяет его и отображает [панель действий для фрейма](/ru/pt/design/frames#per-frame-action-bar).

<Frame>
  <img src="/assets/mirror/canvas-interact-4472dae3de09.png" alt="Canvas с выбранным Artifact Website с помощью инструмента Interact — фрейм обведён маркерами выделения, а над ним отображается панель действий для фрейма. Инструмент Interact выделен на плавающей панели инструментов внизу." width="3450" height="2000" data-path="images/replitai/canvas-interact.png" />
</Frame>

**Сочетание клавиш:** `V`. **Доступность:** всегда активен.

<div id="pan">
  ### Pan
</div>

**Pan** превращает курсор в инструмент для перетаскивания, позволяя перемещаться по холсту. Когда Pan активен, щелчок и перетаскивание перемещают область просмотра вместо выбора frame. Вы также можете перемещаться по холсту из любого другого инструмента: удерживайте пробел и перетаскивайте или перетаскивайте средней кнопкой мыши.

<Frame>
  <img src="/assets/mirror/canvas-pan-9f07d3bf72a3.png" alt="Canvas с активным инструментом Pan — на холсте видны artifact Website (Velocity — Supercar Rental) и макет Design (Velocity — Home (Mockup)), а инструмент Pan (курсор в виде руки) выделен на плавающей панели инструментов внизу." width="1725" height="1041" data-path="images/replitai/canvas-pan.png" />
</Frame>

**Сочетание клавиш:** `H`. **Доступность:** всегда активен.

<div id="chat">
  ### Chat
</div>

**Chat** добавляет небольшое поле чата прямо на холст, чтобы вы могли отправлять промпты Agent, не покидая Canvas. Выбранные элементы и фреймы остаются прикреплёнными к сообщению в виде снимков — так же, как при отправке через боковую панель чата Agent.

<Frame>
  <img src="/assets/mirror/canvas-chat-d28e2d8f216a.png" alt="Canvas в режиме Chat: остальная часть холста затемнена, а встроенное поле чата наложено на artifact Website. Метка 'div' в поле чата указывает на выбранный элемент, а промпт гласит: 'suggest three alternatives to this image'. Инструмент Chat выделен на плавающей панели инструментов внизу." width="3450" height="2000" data-path="images/replitai/canvas-chat.png" />
</Frame>

**Доступность:** инструмент Chat (только на настольных устройствах).

<div id="draw">
  ### Draw
</div>

**Draw** включает инструменты разметки: произвольное рисование, стрелки, стикеры и фигуры. С их помощью можно рисовать поверх фреймов или добавлять пометки на холст. Обводите проблемные места, указывайте элементы, которые хотите изменить, или оставляйте текстовые заметки рядом с фреймами.

Когда Draw активен, над плавающей панелью инструментов появляется панель **Shape properties** с настройками цвета, обводки и заливки для выбранного инструмента разметки. Она автоматически скрывается при переключении на Interact или Pan.

<Frame>
  <img src="/assets/mirror/canvas-draw-d2d9b6556cde.png" alt="Canvas с активным инструментом Draw — нарисованный прямоугольник «Widget» и фиолетовый стикер «Add a widget» расположены рядом с фреймом. Панель Shape properties (инструменты карандаша, текста, прямоугольника, стрелки и стикера, а также образцы цветов и элемент управления размером текста Aa) отображается над плавающей панелью инструментов, при этом Draw выделен." width="1725" height="1041" data-path="images/replitai/canvas-draw.png" />
</Frame>

**Доступность:** всегда активна.

<div id="edit">
  ### Edit
</div>

**Edit** — инструмент визуального выбора элементов. Когда Edit активен, щёлкните внутри активного Artifact, чтобы выбрать элемент (кнопку, заголовок, изображение). При выборе элемента открывается **Visual Editor** — панель управления справа (Layout, Color, Border и другие) и встроенный prompt, в котором можно попросить Agent изменить только этот элемент. Полное описание процесса см. в разделах [Elements](/ru/pt/design/elements) и [Visual Editor](/ru/pt/design/visual-editor).

<Frame>
  <img src="/assets/mirror/canvas-edit-67fe5ee02fbe.png" alt="Активный инструмент Edit на сайте аренды суперкаров: выбран элемент div, а на панели Visual Editor отображаются элементы управления Text, Layout, Color и Border, а также кнопки Discard и Save edits" width="2000" height="1269" data-path="images/replitai/canvas-edit.png" />
</Frame>

**Доступность:** всегда активен (на компьютере). Отключён, пока не создан хотя бы один frame; отображается подсказка *&quot;Создайте artifact или сгенерируйте дизайн, чтобы редактировать.&quot;* На мобильных устройствах скрыт.

<div id="generate">
  ### Generate
</div>

**Generate** открывает всплывающее окно **Generate media** для изображений, видео и векторной графики. Выберите тип, напишите промпт, и Agent добавит результат на Canvas как новый фрейм.

<Frame>
  <img src="/assets/mirror/canvas-add-menu-5d97d9c813e1.png" alt="Открыто меню + Add в Canvas с четырьмя вертикально расположенными вариантами: Design ('Mock up interfaces and visual concepts'), Image ('Generate and edit images'), Video ('Generate motion clips and animations') и Vector Graphic ('Generate vector illustrations and SVGs'). Область Generate на плавающей панели инструментов внизу теперь показывает '+ Generate'." width="1102" height="702" data-path="images/replitai/canvas-add-menu.png" />
</Frame>

Во всплывающем окне сверху есть четыре вкладки:

* **Design**
  — **Image**
* **Video**
* **Vector Graphic**

Некоторые элементы управления доступны для всех типов, другие зависят от типа.

**Общие элементы управления (для всех типов):**

* **Model**: модель генерации. Доступные модели зависят от типа (см. таблицу ниже).
* **Prompt**: описание на естественном языке того, что вы хотите, чтобы сгенерировал Agent.
* **Generate**: отправляет запрос и резервирует фрейм-заполнитель в позиции курсора. Как только ассет будет готов, заполнитель превратится в активный фрейм; если генерация завершится ошибкой, заполнитель будет удалён, а на панели Chat появится сообщение об ошибке.

**Модели и элементы управления по типам:**

| Тип         | Лучше всего подходит для                                                               | Текущие модели                                                  | Элементы управления для конкретного типа                                                                 |
| ----------- | -------------------------------------------------------------------------------------- | --------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| **Image**   | Растровый результат (PNG / JPG); изображения для мудбордов, ключевых фото и референсов | Nano Banana, Nano Banana 2, Nano Banana Pro, ChatGPT Images 2.0 | Соотношение сторон (`1:1`, `16:9`, `9:16`, `4:3`, `3:4`) · Размер (`1K`, `2K`, `4K`)                     |
| **Video**   | Короткие видео и анимации                                                              | Veo 3.1, Seedance 2.0                                           | Соотношение сторон · Разрешение (например, `720p`) · Длительность (например, `4s`) · Переключатель аудио |
| **Graphic** | Векторный результат SVG; значки, логотипы, диаграммы, стилизованные иллюстрации        | Claude 4.6 Opus, Gemini 3.1 Pro Preview                         | Переключатель анимации                                                                                   |

<Note>
  Список моделей часто меняется. В таблице указано то, что доступно сейчас; проверьте раскрывающийся список в интерфейсе продукта, чтобы узнать, что сегодня доступно для вашей учётной записи.
</Note>

Чтобы узнать, что представляет собой каждый тип фрейма и что можно делать с ним после создания, см. [Фреймы](/ru/pt/design/frames).

<div id="anexe-referncias-visuais">
  #### Прикрепите визуальные референсы
</div>

Перед генерацией вы можете прикрепить элементы, уже находящиеся на Canvas, в качестве визуальных референсов. Agent использует их, чтобы результат соответствовал стилю вашего проекта. Откройте меню **+** в форме **Generate media** и выберите один из вариантов:

* **Upload file**: загрузите изображение с компьютера, чтобы использовать его в качестве референса.
* **Select canvas elements**: выберите существующие элементы на Canvas. Фреймы добавляются в виде скриншотов, а текстовые фигуры и заметки — в виде текстовых сводок.

Каждый референс отображается в форме как чип. Добавьте нужное количество референсов, напишите промпт и выберите **Generate**. Чтобы удалить референс, выберите соответствующий чип.

<Frame caption="Форма Generate media с открытым меню +, в котором показаны Upload file и Select canvas elements.">
  <img src="/assets/mirror/canvas-generate-media-references-ac0cb4340acb.png" alt="Форма Generate media на Canvas с открытым меню «плюс», в котором показаны параметры Upload file и Select canvas elements, а в раскрывающемся меню модели выбран Nano Banana Pro" width="1134" height="662" data-path="images/replitai/canvas-generate-media-references.png" />
</Frame>

<Note>
  ChatGPT Images 2.0 сейчас не поддерживает загрузку файлов. Чтобы прикрепить визуальные референсы, смените модель, например на Nano Banana Pro.
</Note>

Когда включено **Add menu**, кнопка Generate заменяется меню **+**, объединяющим типы всплывающих окон наряду с **Design** (отдельным визуальным макетом, не влияющим на активный код):

**Доступность:** генерация изображений. Для **Vector Graphic** требуется генерация векторной графики, а для **Video** — генерация видео. Для меню **+** требуется Add menu, которому, в свою очередь, нужна генерация изображений.

<div id="navegao-no-quadro">
  ## Навигация по доске
</div>

Панорамирование, масштабирование, жесты выделения и соответствующие им сочетания клавиш относятся к функциям доски, а не к инструментам на панели инструментов. Подробнее см. в разделе [«Навигация по доске»](/ru/pt/design/canvas#navigate-the-board) на странице Canvas.
