**Элемент** — это отдельная часть, которую отрисовывает фрейм: заголовок, кнопка, изображение, поле формы и так далее. Если нужно изменить лишь фрагмент, не пересоздавая весь фрейм, работайте именно с элементом.

<div id="section">
  ## Выбор элементов
</div>

Используйте [инструмент Edit](/ru/ja/design/toolbar#edit) на панели инструментов. Когда режим Edit включён, щёлкните внутри активного фрейма — будет выбран элемент под курсором. Выбранный элемент подсветится контуром, и рядом появится небольшой встроенный запрос, через который можно попросить Agent внести изменения.

<Note>
  Edit недоступен, пока на Canvas нет хотя бы одного фрейма. Кроме того, он работает только на компьютере.
</Note>

<div id="visual-editor">
  ## Visual Editor
</div>

При выборе элемента справа открывается панель **Visual Editor**, дополняющая встроенный запрос. Все элементы управления в ней сгруппированы по понятным разделам, чтобы вы быстрее находили нужное: **Text**, **Layout**, **Color** и **Border**. (Если выбрать изображение, появится ещё и раздел **Image**.)

<div id="layout">
  ### Layout
</div>

В разделе **Layout** можно настроить расположение дочерних элементов внутри контейнера, не обращаясь к Agent. Выберите flex-контейнер и разверните Layout — вы увидите следующие пункты:

* **Alignment**: сетка 3×3 из точек, которая задаёт положение элементов по обеим осям внутри контейнера.
* **Direction**: две кнопки со стрелками, выстраивающие дочерние элементы в строку или в столбец.
* **Gap**: расстояние между элементами в пикселях. Значок рядом с полем Gap меняется в зависимости от текущего значения Direction, поэтому всегда понятно, какой отступ вы настраиваете — горизонтальный или вертикальный. Соседний значок со стрелками включает **распределение пространства между элементами (Distribute space between items)**, раздвигая дочерние элементы к краям контейнера.
* **Outer space**: поля для настройки внешних отступов элемента по сторонам (по одному на каждую сторону, с переключателем связи, который блокирует все четыре стороны сразу).
* **Inner space**: поля для настройки внутренних отступов элемента по каждой оси, с переключателем связи, блокирующим обе оси сразу.

Раздел Layout отображается только в том случае, если к выбранному элементу применим хотя бы один элемент управления раскладкой. Для обычных текстовых узлов, у которых нет свойств отступов и раскладки, этот раздел скрывается полностью, благодаря чему редактор остаётся компактным.

О разделах **Text**, **Color**, **Border** и **Image** читайте в [руководстве по Visual Editor](/ru/ja/design/visual-editor).
