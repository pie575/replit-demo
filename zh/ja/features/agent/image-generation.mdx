<div id="section">
  ## 功能
</div>

使用 Agent 的图像生成功能，打造更具视觉吸引力的应用。无需再为基本视觉内容使用图库照片、外部设计工具或聘请设计师。无论是创建作品集网站、开发游戏，还是设计移动应用界面，图像生成都能为你的项目提供量身定制的视觉素材。

Agent 可执行以下图像生成操作：

* **创建自定义图像**：根据详细描述和要求生成图像
* **风格适配**：创建从写实到卡通等多种艺术风格的图像
* **透明背景**：将图像生成为透明 PNG，或移除现有图像的背景 — 非常适合徽标、图标、贴纸和产品抠图
* **项目集成**：将生成的图像直接无缝添加到应用代码库中
* **迭代优化**：根据反馈修改和优化图像

<div id="section-2">
  ## 使用方法
</div>

图像生成功能已内置于 Agent 中——无需开启任何设置。打开任意已启用 Agent 的 Replit 应用，直接告诉 Agent 你需要什么视觉素材即可。Agent 会根据你的需求自动判断何时生成图像，并创建符合你要求的定制图像。

<div id="section-3">
  ### 图像生成最佳实践
</div>

要通过 Agent 生成图像获得最佳效果，请遵循以下指南：

**具体且详细**

* 提供有关风格、颜色、构图和氛围的详细描述
* 视需要指定尺寸或宽高比
* 明确说明用途 (如图标、背景或插图)
* 如果需要将抠出的图像叠加在徽标、图标、贴纸或其他内容上，请要求使用透明背景

**迭代优化**

* 从基本描述开始，并根据生成结果逐步优化
* 请 Agent 修改生成图像中的特定部分
* 请求不同变体，探索多种创意方向

**考虑项目风格**

* 在整个应用中保持视觉一致性
* 指定与品牌或设计系统相符的风格偏好
* 请求能够与现有视觉元素相协调的图像

<div id="section-5">
  ### 项目集成
</div>

Agent 会将生成的图像无缝集成到代码库中：

* **自动创建文件**：生成的图像会直接保存到项目文件中
* **更新代码**：Agent 会更新代码以引用新的图像文件
* **整理资源**：图像会被放入项目结构中合理的目录下

借助这一高效的工作流，你无需离开开发环境即可生成并应用视觉内容。

<Note>
  Replit 的图像生成由 [Google Imagen 4](https://deepmind.google/models/imagen/) 提供支持，这是一款先进的文生图模型，擅长生成高质量、照片级真实感的图像，并具备精细的文本渲染能力。
</Note>
