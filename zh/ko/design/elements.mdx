**Element**(元素)指框架渲染出的每一个独立组成部分,例如标题、按钮、图片、表单字段等。当你只想修改框架中的某一部分,而不想重新生成整个框架时,元素就是你要选中的对象。

<div id="section">
  ## 选择元素
</div>

使用工具栏中的 [Edit 工具](/zh/ko/design/toolbar#edit)。启用 Edit 后，点击运行中的框架内部，即可选中光标所指的元素。选中的元素会显示高亮轮廓，并弹出一个小的内联提示词输入框，可直接让 Agent 进行修改。

<Note>
  如果 Canvas 中没有任何框架，Edit 将不可用；该功能仅支持桌面端。
</Note>

<div id="section-2">
  ## 对选中的元素进行操作
</div>

<div id="agent">
  ### 请求 Agent 进行更改
</div>

使用内联提示词，让 Agent 更新元素的文本、颜色、布局、间距和行为。

<Frame>
  <img src="/assets/mirror/canvas-ask-element-53f7468a07d3.png" alt="Canvas 中所选元素的内联提示词放大视图：“img”标签后是“Ask about selected element…”提示文本和发送按钮" width="1500" height="500" data-path="images/replitai/canvas-ask-element.png" />
</Frame>

<div id="section-3">
  ### 直接替换图片
</div>

选择图片元素后，Visual Editor 的 **Image** 部分会显示源路径和 **Upload Image** 按钮，无需编写提示词即可替换文件。

<div id="visual-editor">
  ## Visual Editor
</div>

选中元素后，会打开内联提示词以及右侧的 **Visual Editor** 面板。该面板将所有控件划分为清晰的几个区块，方便你更快找到所需选项：**Text**、**Layout**、**Color**、**Border**。 (选中图片元素时，还会出现 **Image** 区块。)

<Frame>
  <img src="/assets/mirror/canvas-element-panel-c8972fab0448.png" alt="选中 div 元素（McLaren 预订侧边栏）的 Canvas。右侧 Visual Editor 面板显示 Text（Font size 16、Font weight Regular、Alignment）、Layout（底部值为 24px 的 Outer space、带链接切换的 Inner space 20/20）、Color（Text #e4e4e7、Background #0f0f12）等区块" width="2000" height="1252" data-path="images/replitai/canvas-element-panel.png" />
</Frame>

<div id="layout">
  ### Layout
</div>

在 **Layout** 部分，你无需借助 Agent 即可调整容器内子元素的排布方式。选中一个弹性容器并展开 Layout 后，你会看到以下内容：

* **Alignment**：3×3 的点阵选择器，用于确定项目在容器内两个轴向上的位置。
* **Direction**：两个箭头按钮，用于将子元素按行或按列排列。
* **Gap**：表示项目间距的像素值。Gap 输入框旁的图标会随当前方向变化，因此你随时都清楚自己调整的是水平间距还是垂直间距。其旁边的箭头图标用于切换 **Distribute space between items**，该选项会将子元素推向容器两端。
* **Outer space**：用于设置元素外侧空间的各边输入框 (每边一个，并带有可一次性锁定四边的链接开关) 。
* **Inner space**：用于按各轴向设置元素内侧空间的输入框，并带有可一次性锁定两个轴向的链接开关。

只有当所选元素至少适用一项布局控件时，Layout 部分才会出现。没有间距或布局属性的纯文本节点会完全隐藏该部分，从而让编辑器保持简洁。

关于 **Text**、**Color**、**Border**、**Image** 部分，请参阅 [Visual Editor 指南](/zh/ko/design/visual-editor)。
