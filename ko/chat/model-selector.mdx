intelligent model routing을 사용하면 Replit이 작업에 맞는 모델을 자동으로 선택합니다. 직접 선택하려면 prompt box에서 **Agent Mode**를 선택하고 **Power** 또는 **Max**를 고른 다음, **Primary 모델** 섹션에서 모델을 선택하세요.

Free Mode는 항상 intelligent model routing을 사용합니다. Core와 Pro를 사용하는 builder는 Power Mode 또는 Max Mode에서 사용 가능한 모델을 선택할 수 있습니다. 사용 가능한 모델은 달라질 수 있으므로, Replit에 표시되는 모델 목록이 내 Account의 source of truth입니다.

<div id="set-effort-for-the-model">
  ## 모델의 Effort 설정
</div>

Effort는 선택한 모델이 응답을 생성할 때 추론에 얼마나 많은 자원을 들일지 제어합니다. 별도의 모드가 아니라 모델별로 적용되는 설정입니다. 지원되는 수준은 **Low**부터 **Max**까지이며, 모델마다 권장 설정이 표시됩니다.

더 깊은 추론이 필요한 task에만 높은 Effort를 사용하세요. 설정을 높이면 복잡한 작업에서 시간이 더 오래 걸리고 비용도 더 들 수 있습니다.
