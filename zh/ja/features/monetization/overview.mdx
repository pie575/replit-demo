title: "变现"

---

把你的应用变成一门生意。Replit 已集成支付服务商，你可以收取付款、销售订阅，为网页和移动应用实现变现。

<div id="section">
  ## 工作原理
</div>

只需告诉 Agent 你想通过什么收费，其余工作都会由它完成：连接支付服务商、构建结账或付费墙 UI，以及接入支付逻辑。你可以在发布前安全地测试所有功能。

Replit 支持适用于 Web 应用和原生移动应用的多种变现集成：

* **[Whop Payments](/zh/ja/features/monetization/whop-payments)** (Web 应用) ：以最少步骤销售数字产品、会员资格和订阅。Agent 会为你创建 Whop 账户，无需额外设置或 API 密钥，即可快速获得第一笔收入。
* **[Stripe Payments](/zh/ja/features/monetization/stripe-payments)** (Web 应用) ：接受一次性付款、销售订阅，或构建完整的在线店面。Agent 可以连接 Stripe 沙盒，让你在发布前测试结账流程。
* **[RevenueCat Subscriptions](/zh/ja/features/monetization/revenuecat-subscriptions)** (移动应用) ：为原生移动应用添加应用内订阅。Agent 会设置 RevenueCat、构建付费墙界面，并配置测试模式，以便在开发期间模拟购买。

如果你想销售实体商品，并提供库存管理和配送功能，请参阅 [Shopify 集成](/zh/ja/features/integrations/shopify)。

<div id="section-2">
  ## 选择合适的集成
</div>

|           | Whop            | Stripe              | Shopify            | RevenueCat                     |
| --------- | :-------------- | :------------------ | :----------------- | :----------------------------- |
| **最适用场景** | 步骤最少，最快实现首笔销售   | Web 的灵活性与可扩展性       | 实体商品               | 原生移动应用                       |
| **支付类型**  | 数字商品、会员资格、订阅    | 一次性付款、订阅、在线店面         | 需要库存和配送的实体商品       | App 内订阅                        |
| **外部设置**  | 初期无需设置          | 初期无需设置 (Stripe 沙盒)  | 初期无需设置             | 初期无需设置 (测试模式)                  |
| **发布**    | 提现需要身份验证 (KYC)  | 连接到正式 Stripe 账户     | 申请 Shopify 商店      | 提交至 App Store 或 Google Play 审核 |
| **所需账户**  | Whop 账户 (自动创建)  | Stripe 账户           | Shopify 商店 (自动配置)  | RevenueCat 账户                  |

<div id="section-3">
  ## 开始使用
</div>

最快的上手方式就是直接问 Agent：

* **快速销售数字商品**：“添加 Whop 支付，让我可以销售会员资格” — 参见 [Whop Payments](/zh/ja/features/monetization/whop-payments)
* **Web 应用**：“为我的应用添加 Stripe 支付” — 参见 [Stripe Payments](/zh/ja/features/monetization/stripe-payments)
* **移动应用**：“为我的应用添加每月 5.99 美元的订阅” — 参见 [RevenueCat Subscriptions](/zh/ja/features/monetization/revenuecat-subscriptions)

Agent 会接入集成、构建界面并搭建好测试环境，让你可以立即试用。
