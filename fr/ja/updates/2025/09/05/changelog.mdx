<div id="section-2">
  ## Plateforme
</div>

<div id="general-agent">
  ### Agent général
</div>

<Frame>
  <img src="/assets/mirror/general-agent-240ff289e711.png" alt="Illustration principale d’Agent général" width="1040" height="572" data-path="images/replitai/general-agent.png" />
</Frame>

Replit Agent fonctionne désormais avec des bases de code écrites dans n’importe quel langage ou framework et exécutées sur NixOS ! Auparavant limité à certains modèles, Agent peut désormais vous aider avec les frameworks de développement, les importations GitHub et toute configuration de projet personnalisée. Cette extension majeure offre une assistance complète au codage par IA pour les flux de travail Enterprise et les utilisateurs avancés.

Pour en savoir plus sur Agent général, consultez [cette page](/fr/core-concepts/agent/general-agent).

<div id="section-3">
  ### Mode Plan
</div>

<Frame>
  <img src="/assets/mirror/plan-mode-overview-8077807c63b9.png" alt="Interface de chat d’Agent en mode Plan" width="916" height="362" data-path="images/replitai/plan-mode-overview.png" />
</Frame>

Le mode Plan propose une nouvelle façon d’interagir avec Replit Agent, axée sur les questions, le brainstorming et la planification du travail. En mode Plan, vous pouvez utiliser Agent pour créer une liste de tâches pour les travaux à venir, puis exécuter des tâches de longue durée en mode Build.

Pour en savoir plus sur le mode Plan, consultez [cette page](/fr/core-concepts/agent/plan-mode).

<div id="enterprise">
  ## Enterprise
</div>

<div id="gcp">
  ### Intégration à GCP Marketplace
</div>

Les clients Enterprise peuvent désormais acheter Replit directement sur Google Cloud Platform Marketplace et utiliser leurs crédits GCP existants pour régler leurs achats. Cela simplifie le processus d’approvisionnement et permet aux organisations disposant d’un budget GCP d’adopter plus facilement Replit dans leurs flux de travail de développement.
