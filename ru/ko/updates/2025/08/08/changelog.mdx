<div id="section-3">
  ### Улучшенный поиск по файловой системе
</div>

Agent теперь ищет файлы по всей кодовой базе умнее и интуитивнее. Благодаря продвинутому ИИ с поддержкой длинного контекста Agent понимает структуру и содержимое проекта, дает более глубокий контекст и более релевантные развернутые ответы — так найти нужное становится проще.

<div id="object-storage-agent">
  ### Интеграция Object Storage с Agent
</div>

Легко создавайте функции загрузки файлов с помощью новых возможностей [Object Storage](/ru/ko/features/data-and-storage/object-storage) в [Agent](/ru/core-concepts/agent)! Теперь ИИ-ассистент может настроить Object Storage, проверить конфигурацию и сгенерировать полноценный код бэкенда и фронтенда с продвинутыми функциями, такими как аутентификация и контроль доступа.

Узнайте больше об [Object Storage](/ru/ko/features/data-and-storage/object-storage) и ознакомьтесь со всеми доступными [интеграциями Agent](/ru/replitai/integrations#data-storage--management).

<div id="section-4">
  ### Улучшенный фокус в визуальном редакторе
</div>

Не теряйте рабочий ритм при работе с [визуальным редактором](/ru/learn/projects-and-artifacts/visual-editor)! После выбора элемента для редактирования фокус автоматически возвращается в поле ввода чата, поэтому вы можете сразу же ввести следующий промпт, не прерываясь.

  ### Предложения по откату и переключение формата даты

<div id="ios">
  ### Live Activities в iOS
</div>

Оставайтесь на связи с [рабочим пространством](/ru/ko/learn/projects-and-artifacts/project-editor), даже когда вы не за компьютером! Функция Live Activities в iOS позволяет следить за запущенными проектами и одним касанием возвращаться в рабочее пространство прямо с экрана блокировки или из центра уведомлений.

<div id="replit">
  ### Перенос Replit App в организацию
</div>

Легко переносите личные проекты в команду! С помощью нового действия «Перенести в организацию» вы можете без лишних шагов перенести личное [Replit App](/ru/ko/category/replit-apps) в организацию, в которой состоите, и совместно работать над уже существующими проектами.

<div id="mx">
  ### Поддержка MX-записей для доменов
</div>

Подключайте почтовых провайдеров без лишних хлопот! Теперь для [доменов, купленных через Replit](/ru/ko/features/publishing/custom-domains), можно создавать MX-записи, чтобы подключить почтового провайдера и управлять собственным почтовым сервисом проекта.

  ## Enterprise
</div>

<div id="scim">
  ### Улучшения удобства работы со SCIM
</div>

Упростите управление командой с помощью расширенных возможностей [SCIM](/ru/ko/teams/identity-and-access-management/scim)! Организации Enterprise теперь могут настраивать SCIM самостоятельно, без обращения в поддержку, а также сразу назначать пользователям роль Guest — это упрощает предоставление доступа подрядчикам.
