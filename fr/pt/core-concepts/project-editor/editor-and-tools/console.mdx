La Console vous permet de surveiller et de consulter en temps réel les logs générés par votre application Replit en cours d&#39;exécution.
Vous pouvez utiliser les informations des exécutions en cours et précédentes pour comprendre le comportement de votre app,
résoudre les erreurs et optimiser les performances.

<Tip>
  Lors du débogage avec Agent, incluez les logs de la console dans votre prompt afin de fournir davantage de contexte.
</Tip>

<div id="recursos">
  ## Ressources
</div>

La console propose les outils suivants pour vous aider à comprendre le comportement de votre App :

* **Logs en temps réel** : visualisez la sortie de votre App au fur et à mesure de son exécution
* **Assistance IA** : recevez des suggestions pour corriger les erreurs signalées dans les logs
* **Historique des exécutions** : consultez les logs des exécutions précédentes pour suivre les modifications

<div id="uso">
  ## Utilisation
</div>

Vous pouvez accéder à l’outil Console directement dans votre Éditeur de projets.

<Accordion title="Accéder à la Console">
  Dans le **dock d’outils** à gauche :

  1. Sélectionnez <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Icône Tous les outils" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **Tous les outils** pour afficher la liste des outils de l’Éditeur de projets.
  2. Sélectionnez <img class="icon-svg" src="/assets/mirror/console-8a41ac90789c.svg" alt="Icône Console" width="16" height="16" data-path="images/icons/console.svg" /> **Console**.

  Dans la **barre de recherche** :

  1. Sélectionnez l’<img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="icône de loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> icône de loupe en haut pour ouvrir l’outil de recherche.
  2. Saisissez « Console » pour localiser l’outil, puis sélectionnez-le dans les résultats.
</Accordion>

Chaque fois que vous utilisez le bouton **Exécuter** dans votre application Replit, la Console affiche une nouvelle entrée contenant les informations suivantes :

* La commande qui exécute votre code
* La date et l’heure
* Les logs de sortie standard et d’erreur

La capture d’écran suivante montre la commande `npm run dev` utilisée pour démarrer l’application, ainsi que les messages de log générés lors de l’exécution :

<div id="depurao-com-ia">
  ### Débogage avec l’IA
</div>

Lorsque vous rencontrez des erreurs ou d’autres informations dans les logs que vous souhaitez comprendre, cliquez sur le
bouton **Demander à l’IA** en haut de l’entrée. L’onglet **Agent** s’ouvre automatiquement et
le contenu du log est envoyé pour analyse.

<div id="comandos-de-entrada-de-log">
  ### Commandes des entrées de log
</div>

La console fournit les outils suivants pour gérer vos logs :

* **Afficher uniquement la plus récente** : activez cette option pour n’afficher que l’exécution la plus récente.
* **Réduire l’entrée** : sélectionnez la <img class="icon-svg" src="/assets/mirror/down-arrow-9c1cf9fd152e.svg" alt="icône de flèche vers le bas" height="16" width="16" data-path="images/icons/down-arrow.svg" /> flèche vers le bas à gauche du nom de la commande pour masquer les logs.
* **Effacer les exécutions précédentes** : sélectionnez cette option pour supprimer les logs des exécutions précédentes. Cette action est irréversible.

<div id="disponibilidade-de-rede">
  ### Disponibilité réseau
</div>

Vous pouvez contrôler la disponibilité en ligne de la version de développement de votre application.

Pour ne plus répondre aux requêtes adressées à l’URL de développement, sélectionnez l’icône <img class="icon-svg" src="/assets/mirror/network-off-5bdca8a4fe4e.svg" alt="icône de réseau désactivé" height="16" width="16" data-path="images/icons/network-off.svg" /> représentant un globe barré
à droite de la ligne d’informations réseau.

Pour l’activer, sélectionnez l’icône <img class="icon-svg" src="/assets/mirror/network-on-15be2e5fb4f5.svg" alt="icône de réseau activé" height="16" width="16" data-path="images/icons/network-on.svg" /> représentant un globe.

Pour afficher votre URL de développement, sélectionnez le texte `{...}.replit.dev` dans la barre d’adresse.

<Frame>
  <img src="/assets/mirror/preview-dev-url-b36770b33769.png" alt="Emplacement de l’URL de développement dans Preview" width="1222" height="824" data-path="images/workspace/preview-dev-url.png" />
</Frame>

<Note>
  Votre application reste accessible dans l’outil Preview, même lorsqu’elle est configurée pour ne plus répondre aux requêtes adressées à l’URL de développement.
</Note>

<div id="parar-um-comando-de-workflow">
  ### Arrêter une commande de workflow
</div>

Vous pouvez arrêter une commande de workflow en cours d’exécution depuis l’outil Console de l’éditeur de projets.

Sélectionnez le bouton carré à droite de la ligne contenant la commande d’exécution de votre application Replit pour l’arrêter.

Pour redémarrer l’app, utilisez le bouton **Exécuter** du workflow en haut de l’éditeur de projets.
