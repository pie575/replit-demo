<div id="agent">
  ## Agent
</div>

<div id="escolha-o-modelo-principal-do-agent">
  ### 选择 Agent 的主模型
</div>

现在，您可以选择 Agent 执行任务时使用的主模型。选择 Lite、Economy 或 Power，然后从该模式提供的模型中选择。现在，无论您在何处使用 Agent，包括移动应用，都可以使用 Lite。可用模型会因组织、权限和 Turbo 访问权限而异。

</Frame>

详细了解[模型选择器](/zh/pt/features/agent/model-selector)。

<div id="conecte-mais-servidores-mcp">
  ### 连接更多 MCP 服务器
</div>

符合条件的 workspace 可通过预先列出的 MCP 服务器目录连接 Supabase、Statsig 和 Calendly。Replit 还会识别 Braintrust 的官方 MCP 端点；手动添加该端点时，会启动 OAuth 登录流程。

  <img src="/assets/mirror/integrations-4cb26ed8a654.png" alt="集成设置页面，列出了 GitHub、GitLab、AWS 和 Calendly 等连接器" width="3124" height="1636" data-path="images/changelog/2026-07-31/integrations.png" />
</Frame>

详细了解 [MCP 服务器](/zh/pt/features/mcp/overview)。
