---

让你的应用成为一门生意。Replit 已集成各类支付服务商，助你收取付款、销售订阅，为网页和移动应用实现变现。

<div id="como-funciona">
  ## 工作原理
</div>

告诉 Agent 你想对什么收费，其余的交给它：连接支付服务商、构建结账界面或付费墙，并配置支付逻辑。正式上线前，你可以放心地测试各个环节。

Replit 支持在网页应用和原生移动应用中使用多种变现集成：

* **[Whop 支付](/zh/pt/features/monetization/whop-payments)** (网页应用) ：以最少的步骤销售数字产品、会员和订阅。Agent 会为你创建 Whop 账户——无需外部配置，也无需 API 密钥——让你快速达成第一笔销售。
* **[Stripe 支付](/zh/pt/features/monetization/stripe-payments)** (网页应用) ：接受一次性付款、销售订阅，或搭建完整的商店。Agent 会连接 Stripe 沙盒，让你在正式上线前测试结账流程。
* **[RevenueCat 订阅](/zh/pt/features/monetization/revenuecat-subscriptions)** (移动应用) ：为你的原生移动应用添加应用内订阅。Agent 会配置 RevenueCat、构建付费墙页面并开启测试模式，使开发期间的购买均为模拟交易。

如果你想销售实体商品并管理库存和配送物流，请参阅 [Shopify 集成](/zh/pt/features/integrations/shopify)。

<div id="escolha-a-integrao-certa">
  ## 选择合适的集成方式
</div>

|             | Whop              | Stripe                | Shopify             | RevenueCat                     |
| ----------- | :---------------- | :-------------------- | :------------------ | :----------------------------- |
| **最适合**     | 步骤更少，更快开卖         | 网页端的灵活性与规模扩展          | 实体商品                | 原生移动应用                         |
| **支付类型**    | 数字产品、会员、订阅        | 一次性付款、订阅、完整店铺         | 需库存和配送物流的实体商品       | 应用内订阅                          |
| **外部配置**    | 起步无需任何配置          | 起步无需任何配置 (Stripe 沙盒)  | 起步无需任何配置            | 起步无需任何配置 (测试模式)                |
| **上线到生产环境** | 完成身份验证 (KYC) 后可提现 | 连接正式的 Stripe 账户       | 认领你的 Shopify 店铺     | 提交至 App Store 或 Google Play 审核 |
| **所需账户**    | Whop 账户 (已为你创建)   | Stripe 账户             | Shopify 店铺 (已为你开通)  | RevenueCat 账户                  |

<div id="como-comear">
  ## 如何开始
</div>

最快的上手方式是直接向 Agent 提出需求：

* **快速销售数字产品**：“添加 Whop 支付，让我可以销售订阅” — 参见 [Whop 支付](/zh/pt/features/monetization/whop-payments)
* **网页应用**：“为我的应用添加 Stripe 支付” — 参见 [Stripe 支付](/zh/pt/features/monetization/stripe-payments)
* **移动应用**：“为我的应用添加每月 $5.99 的订阅” — 参见 [RevenueCat 订阅](/zh/pt/features/monetization/revenuecat-subscriptions)

Agent 会接入相应集成、搭建界面并配置测试环境，让你可以立即试用。
