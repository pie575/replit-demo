<div id="vercel-import-integration">
  ### Vercel 가져오기 통합
</div>

클릭 한 번으로 Vercel 앱을 Replit으로 옮기세요! 새로워진 import flow 덕분에 Next.js를 비롯한 Vercel 호스팅 애플리케이션을 Replit으로 매끄럽게 이전할 수 있습니다. Vercel 대안을 찾고 있는 개발자에게는 더없이 좋은 기회입니다. 자세한 내용은 [Vercel에서 가져오기 quickstart](/ko/build/import-from-vercel)와 [Replit으로 가져오기 가이드](/ko/references/workspace/import)에서 확인하세요.

<div id="git-source-control-enhancements">
  ### Git source control 개선 사항
</div>

Git integration이 강화되어 remote 관리와 workspace 활용이 한층 유연해졌습니다. 개선된 UX로 Git remote를 연결하고 생성할 수 있으며, 개인 workspace와 organization workspace를 손쉽게 전환하고, deployment 전에 코드가 항상 최신 상태인지 확인할 수 있습니다. 자세한 내용은 [Git pane 사용하기](/ko/references/version-control/git-interface)를 참고하세요.

<div id="connectors-platform-launch">
  ### Connectors 플랫폼 출시
</div>

미리 구축된 24개의 앱 integration으로 더 빠르게 빌드하세요! 새로운 Connectors 플랫폼을 통해 Replit project를 Stripe, Figma 등 인기 서비스에 연결할 수 있습니다. 각 connector는 MCP(Model Context Protocol) 기반으로 동작해 AI 지원 개발을 매끄럽게 지원합니다. [Agent integrations](/ko/replitai/integrations)와 [Managing your connectors](/ko/replitai/managing-connectors)를 참고하세요.

<div id="app-themes-font-improvements">
  ### App Themes 글꼴 개선
</div>

Crimson, EB Garamond, Figtree, Source Sans Pro 등 인기 있는 Google Fonts 19종이 추가되어 앱을 더욱 다양하게 꾸밀 수 있습니다. 이제 글꼴 선택기가 각 글꼴을 실제 서체로 보여 주므로 디자인을 한눈에 비교해 볼 수 있습니다. 글꼴은 카테고리별(Serif, Sans-Serif, Monospace)로 정리되어 있으며, 각 유형을 설명하는 툴팁도 제공됩니다. 자세한 내용은 [App Themes](/ko/replitai/app-themes)에서 확인하세요.

<div id="connectors-admin-management">
  ### Connectors admin management
</div>

Enterprise 고객은 공유 API key에 대한 역할 기반 access controls와 완전한 맞춤형 OAuth 클라이언트 구성을 지원하는 고급 connector 관리 기능을 사용할 수 있습니다. Connectors는 Organization 수준에서 옵트인 방식으로 활성화되므로, 관리자는 팀원이 사용할 수 있는 integrations를 완벽하게 제어할 수 있습니다. 자세한 내용은 [Managing your connectors](/ko/replitai/managing-connectors)를 참조하세요.
