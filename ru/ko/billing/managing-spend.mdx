Контролируйте расходы в Replit: используйте встроенные инструменты управления бюджетом, оптимизируйте работу с [AI Agent](/ru/ko/features/agent/overview), приобретайте пакеты кредитов и отслеживайте использование. Подробнее о [тарификации AI](/ru/ko/billing/ai-billing).

<div id="section">
  ## Просмотр Usage
</div>

Используйте [страницу Usage](https://replit.com/usage), чтобы узнать, на что расходуются кредиты в вашей личной учетной записи или во всем рабочем пространстве. Фильтруйте данные по дате, ресурсу, проекту, рабочему пространству, группе или участнику, чтобы выявить причины расхода.

Данные Usage обновляются почти в реальном времени, поэтому вы можете отслеживать недавнюю активность, не дожидаясь ежедневных отчетов.

<div id="ai">
  ## Оптимизация расходов на ИИ
</div>

ИИ-инструменты, такие как [Agent](/ru/ko/features/agent/overview), очень эффективны, но при грамотном использовании позволяют контролировать расходы и получать максимальную отдачу. Ниже — действенные способы сократить расходы на ИИ.

<div id="plan-mode">
  ### Использование Plan Mode для экономичной совместной работы
</div>

[Plan Mode](/ru/ko/features/agent/plan-mode) — один из самых эффективных способов сократить расходы на ИИ. При активации Plan Mode Agent создаёт подробный план, не изменяя код. Такой подход даёт несколько преимуществ:

* **Обсуждение перед выполнением**: обсуждайте и уточняйте подход с Agent до начала работы
* **Меньшие затраты токенов**: обсуждения плана используют меньше токенов, чем генерация и редактирование кода
* **Точная фокусировка**: просматривайте и корректируйте план, чтобы Agent работал только над важными задачами
* **Итеративное уточнение**: правильно определяйте объём работы до расходования токенов на реализацию

Используйте [Plan Mode](/ru/ko/features/agent/plan-mode), когда хотите изучить решение, уточнить требования или понять подход до начала реализации.

<div id="agent">
  ### Управляйте расходами с режимами Agent
</div>

[Режимы Agent](/ru/ko/features/agent/agent-modes) позволяют выбрать оптимальный баланс между стоимостью и производительностью:

* **Free Mode**: бесплатные повседневные задачи Agent в пределах лимита для подписчиков Core и Pro.
* **Power**: повышенная производительность по разумной цене.
* **Max**: самые передовые модели для наиболее требовательных задач.
* **Turbo**: дополнительный переключатель, доступный в Max.

В процессе работы Agent автоматически проверяет собственный код, обнаруживает ошибки и сокращает объём дорогостоящих доработок — эту функцию нельзя включить или отключить. Чтобы лучше контролировать расходы, сначала определите объём работы в Plan Mode:

* **Проверка перед выполнением**: просмотрите план до того, как Agent внесёт изменения.
* **Выборочное одобрение**: утверждайте только изменения, соответствующие вашим целям, а остальные пропускайте.

<Tip>
  Для повседневных задач начните с [Free Mode](/ru/ko/features/agent/agent-modes). Если вам нужна повышенная производительность по разумной цене, выберите [режим Power](/ru/ko/features/agent/agent-modes). Сначала составьте план и утверждайте изменения поэтапно.
</Tip>

<div id="section-2">
  ## Покупка пакета кредитов
</div>

Если вы используете тариф Core или Pro и вам нужны дополнительные кредиты сверх ежемесячного лимита подписки, вы можете приобрести пакет кредитов в разделе **Настройки** → **Usage аккаунта** → **Credits** → **Purchase credit pack**. При покупке нескольких пакетов кредитов предоставляется скидка, поэтому они идеально подходят для покрытия временных скачков Usage или подготовки к более крупным проектам.

<div id="section-4">
  ### Как работают пакеты кредитов
</div>

* **Где купить**: доступно для клиентов тарифов Core и Pro: **Настройки** → **Usage аккаунта** → **Credits** → **Purchase credit pack**
* **Срок действия**: срок действия пакетов кредитов истекает через 6 месяцев с даты покупки
* **Без автоматического продления**: пакеты кредитов не продлеваются автоматически
* **Без переноса**: неиспользованные кредиты из пакета не переносятся после окончания срока действия
* **Автоматическое использование**: кредиты автоматически расходуются из пакета с ближайшим сроком действия, чтобы максимально эффективно использовать покупку
* **Автопополнение**: включите автопополнение, чтобы при низком балансе автоматически покупать *новый* пакет кредитов и не прерывать работу над проектом
* **Управление в любое время**: включайте, настраивайте или отключайте автопополнение в разделе **Настройки** → **Оплата**

<Note>
  Лимиты использования и бюджеты применяются к использованию после расходования кредитов из приобретённого пакета. Чтобы ограничить использование только кредитами из приобретённого пакета, установите лимит $0.01.
</Note>

<div id="section-5">
  ### Просмотр платёжных квитанций
</div>

Если вы пополняете баланс учётной записи, откройте **Настройки** → **Оплата** и найдите раздел **Платёжные квитанции**, чтобы просмотреть успешные разовые и автоматические платежи за пополнение. В каждой строке указаны дата платежа, тип покупки, сумма и статус возврата. Выберите **Просмотреть квитанцию**, чтобы открыть квитанцию у платёжного провайдера.

<div id="section-6">
  ## Настройка лимитов и бюджетов
</div>

Устанавливайте ежемесячные лимиты использования и бюджеты для всех сервисов с оплатой по факту использования, чтобы отслеживать и контролировать расходы.

<div id="section-7">
  ### Лимит использования
</div>

Лимит использования ограничивает расходы сверх ежемесячных кредитов. При достижении лимита сервисы с оплатой по мере использования будут недоступны до начала следующего расчетного периода или увеличения лимита.

Для аккаунтов Core откройте **Настройки** → **Аккаунт** → **Оплата**, чтобы установить лимит использования. Для организаций лимит использования можно установить, выбрав **Управление** под пунктом **Общее использование** на [странице Usage](https://replit.com/usage).

<div id="section-8">
  ### Лимит отключения сервиса
</div>

При достижении этого лимита сервис будет отключён, пока вы не увеличите бюджет или не начнётся следующий расчётный период. Это поможет избежать дополнительных расходов.

Если у вас тариф Core, откройте **Настройки** → **Аккаунт** → **Оплата**, чтобы установить лимит отключения сервиса.

<div id="section-9">
  ### Бюджет организации
</div>

Для организации можно установить бюджет использования на [странице настроек](https://replit.com/t/replit/settings/billing). Бюджет необходимо задавать с шагом {OrganizationBudgetIncrement}.

<Note>Чтобы включить ежемесячный лимит использования, необходимы права администратора или владельца организации. Если у вас нет доступа, обратитесь к владельцу организации.</Note>

<div id="section-10">
  ### Лимиты расходов для отдельных пользователей
</div>

Администраторы Enterprise могут устанавливать для отдельных участников лимиты расходов, отличающиеся от значений по умолчанию для рабочего пространства. Это позволяет повысить лимиты для активных пользователей или ограничить расходы конкретных участников, не изменяя настройки остального рабочего пространства.

<Steps>
  <Step title="Откройте страницу Usage рабочего пространства">
    В рабочем пространстве Enterprise откройте [страницу Usage](https://replit.com/usage). В таблице **Пользователи Agent** перечислены все участники рабочего пространства и их текущее использование.
  </Step>

  <Step title="Измените лимит участника">
    Найдите нужного участника и выберите значок редактирования в столбце **Лимит использования**. В диалоговом окне отображаются значение по умолчанию для рабочего пространства, применимые групповые лимиты и поле для нового индивидуального лимита.

    <Frame>
      <img src="/assets/mirror/edit-usage-limit-87127319c809.png" alt="Диалоговое окно редактирования лимита использования участника рабочего пространства, показывающее значение по умолчанию для рабочего пространства, текущий индивидуальный лимит, применимые групповые лимиты и поле ввода пользовательского порога со значением $5" width="1202" height="916" data-path="images/billing/edit-usage-limit.png" />
    </Frame>
  </Step>

  <Step title="Сохраните переопределение">
    Введите новый лимит и выберите **Сохранить**. Переопределение применяется сразу, а новое значение отображается в столбце **Лимит использования**. Чтобы позднее удалить переопределение, очистите поле и сохраните изменения. После этого для участника будет применяться наиболее конкретный групповой лимит или лимит рабочего пространства.
  </Step>
</Steps>

<Note>Лимиты расходов для отдельных пользователей доступны в тарифе Enterprise. Участники, назначенные в [пользовательские группы](/ru/ko/teams/identity-and-access-management/groups-and-permissions), наследуют лимит своей группы, если для них не задано индивидуальное переопределение. Индивидуальные переопределения всегда имеют приоритет над групповыми лимитами и значениями по умолчанию для рабочего пространства.</Note>

<div id="section-11">
  ### Управление для администраторов организации
</div>

Администраторы организации могут управлять доступом к AI-моделям и интеграциям в [настройках оплаты организации](https://replit.com/t/replit/settings/billing).

**Отключение интеграций с внешними AI-моделями**

При включении этого параметра пользователи организации не смогут использовать интеграции с внешними AI-моделями, такими как OpenAI, Anthropic, xAI и Perplexity, через управляемые коннекторы Replit.

При включении этого параметра пользователи организации не смогут использовать управляемые AI-интеграции Replit.
