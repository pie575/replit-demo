Ces réponses portent sur la connexion et le dépannage des domaines personnalisés. Pour la référence complète, consultez [Ajouter un domaine personnalisé](/fr/build/add-custom-domain) et [Domaines personnalisés](/fr/features/publishing/custom-domains).

<AccordionGroup>
  <Accordion title="Comment connecter un domaine personnalisé à mon Replit App ?">
    Si vous avez acheté votre domaine via Replit, les enregistrements DNS sont gérés pour vous : ouvrez **Publishing → Domains** et suivez la configuration proposée dans le produit. Consultez [Achat de domaine](/fr/build/domain-purchasing).

    Pour connecter un domaine provenant d&#39;un registraire externe :

    1. Ouvrez votre project et accédez à **Publishing → Domains**.
    2. Sélectionnez **Connect your own domain**, saisissez votre domaine, puis continuez.
    3. Replit affiche un enregistrement A et un enregistrement TXT : copiez les deux.
    4. Ajoutez ces deux enregistrements chez votre fournisseur DNS.
    5. Revenez dans Replit et lancez la vérification.

    Quelques points importants :

    * Un enregistrement A et un enregistrement TXT sont tous deux requis pour le SSL. Les CNAME à l&#39;apex (racine) ne sont pas pris en charge : utilisez un enregistrement A pour votre domaine racine.
    * Les certificats génériques (`*.example.com`) ne sont pas pris en charge ; connectez chaque sous-domaine individuellement.
    * Sur Cloudflare, réglez votre enregistrement A sur **DNS only** (nuage gris) afin que le mode proxy ne bloque pas la configuration SSL.
    * La propagation des modifications DNS peut prendre jusqu&#39;à 48 heures.

    Consultez [Domaines personnalisés](/fr/features/publishing/custom-domains) pour la référence complète.
  </Accordion>

  <Accordion title="Mon domaine n'est pas vérifié ou le SSL n'est pas provisionné : comment résoudre le problème ?">
    Effectuez ces vérifications dans l&#39;ordre : la plupart des problèmes viennent de l&#39;une d&#39;entre elles.

    1. **Attendez la propagation DNS.** Les modifications peuvent prendre jusqu&#39;à 48 heures. Vérifiez que vos enregistrements sont visibles partout dans le monde à l&#39;aide d&#39;un outil de recherche DNS.
    2. **Supprimez les enregistrements AAAA.** Les enregistrements IPv6 (AAAA) placés sur le même nom d&#39;hôte que votre enregistrement A peuvent bloquer le SSL.
    3. **Supprimez les enregistrements A obsolètes ou en conflit.** Ne conservez qu&#39;un seul enregistrement A pointant vers Replit sur votre domaine racine.
    4. **Réglez Cloudflare sur DNS only.** Le nuage orange (mode proxy) interfère avec le provisionnement du SSL.
    5. **Déconnectez puis reconnectez le domaine** dans **Publishing → Domains → Manage** pour forcer l&#39;émission d&#39;un nouveau certificat, puis patientez quelques minutes et rechargez la page.
    6. **Vérifiez les enregistrements CAA.** Si vous en avez, au moins l&#39;un d&#39;eux doit autoriser Let&#39;s Encrypt comme émetteur, car Replit émet ses certificats par son intermédiaire.

    Ces vérifications s&#39;appliquent aux domaines enregistrés en externe. Si vous avez acheté votre domaine via Replit, [contactez l&#39;assistance Replit](https://replit.com/support). Consultez [Domaines personnalisés](/fr/features/publishing/custom-domains).
  </Accordion>

  <Accordion title="Comment configurer l'authentification Clerk sur un domaine personnalisé ?">
    Quelques problèmes reviennent fréquemment lors de l&#39;utilisation de l&#39;[authentification Clerk](/fr/features/auth-and-identity/clerk-auth) sur un domaine personnalisé :

    * **Avertissement « Clerk CNAME records required ».** Il s&#39;agit d&#39;une exigence de l&#39;integration Clerk, qui ne bloque ni la vérification de votre domaine ni le SSL. Ouvrez **Publishing → Domains**, sélectionnez **Manage**, repérez la section de configuration DNS de l&#39;authentication, puis ajoutez à l&#39;identique chaque enregistrement CNAME indiqué chez votre fournisseur DNS. Si la section n&#39;apparaît pas, déconnectez puis reconnectez le domaine.
    * **Domaine bloqué sur Verifying après une utilisation antérieure de Clerk.** Si le domaine était rattaché à une autre application Clerk, supprimez-le depuis votre [tableau de bord Clerk](https://dashboard.clerk.com), puis déconnectez et reconnectez le domaine dans Replit.
    * **Migration vers votre propre instance Clerk.** Passer d&#39;un Clerk géré par Replit à votre propre instance nécessite une étape manuelle : [contactez l&#39;assistance Replit](https://replit.com/support). Consultez [Puis-je utiliser ma propre application Clerk ?](/fr/features/auth-and-identity/clerk-auth#can-i-bring-my-own-clerk-app-instead-of-using-the-replit-managed-one)

    Si le problème persiste, [contactez l&#39;assistance Replit](https://replit.com/support) en indiquant votre nom de domaine, le nom de votre project et les solutions déjà essayées.
  </Accordion>
