O Replit Agent se conecta a ferramentas e fontes de dados externas através do [Model Context Protocol (MCP)](https://modelcontextprotocol.io), um padrão aberto para integrações de IA. Cada servidor abaixo se instala com um único clique — o Agent então carrega automaticamente suas ferramentas e as usa quando apropriado.

Para o conceito, veja [Model Context Protocol](/pt/learn/model-context-protocol). Para o guia prático, veja [Conectar via MCP](/pt/build/connect-via-mcp). Para conectar um servidor que não está listado aqui, veja [Adicionar um servidor MCP personalizado](/pt/build/connect-via-mcp#add-a-custom-mcp-server).

<Info>
  Selecione **Add to Replit** para instalar qualquer servidor. Você será solicitado a autorizar a conexão no Editor de Projeto.
</Info>

## Proteções de segurança

Todo o tráfego MCP passa pelo scanner de segurança do Replit. O scanner avalia as definições de ferramentas e as execuções planejadas, bloqueando ferramentas suspeitas ou inseguras antes que sejam executadas. Se uma ferramenta for rejeitada, o Agent vai te informar sobre isso.

## Opções de autenticação

* **Registro dinâmico de cliente OAuth** — se o servidor suportar OAuth DCR, o Replit detecta e registra automaticamente o cliente para você. A maioria dos servidores pré-listados usa esse fluxo.
* **Cabeçalhos personalizados** — defina um ou mais pares de nome/valor de cabeçalho (por exemplo, `X-API-Key`). O Replit inclui esses cabeçalhos em cada solicitação MCP para que seu servidor possa verificar quem está chamando. Use isso ao adicionar um servidor personalizado que autentica via tokens estáticos.

## Compartilhe seu próprio link de instalação

Links de instalação adicionam seu servidor MCP ao Replit com um único clique. Gere um com o formulário em [Conectar via MCP](/pt/build/connect-via-mcp#share-an-install-link), ou crie o seu: codifique um payload JSON em base64 e adicione-o a `https://replit.com/integrations?mcp=`.

```json theme={null}
{
  "displayName": "My MCP Server",
  "baseUrl": "https://example.com/mcp",
  "headers": [{ "key": "Authorization", "value": "Bearer your-token" }]
}
```

* **displayName** — o nome exibido durante a instalação
* **baseUrl** — o endpoint HTTPS do seu servidor MCP
* **headers** — cabeçalhos de autenticação opcionais
