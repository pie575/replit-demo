---

Lorsque vous publiez votre application, vous contrôlez qui peut l'ouvrir. Choisissez une option sous **Qui peut accéder à votre application** dans les paramètres de publication. Replit gère l'écran de connexion et les vérifications d'accès pour vous, sans aucune modification de code requise.

Restreindre l'accès est utile pour des applications comme :

* Les outils internes
* Les applications en phase de bêta-test
* Les applications accédant à des informations sensibles

## Options d'accès

* **Public** : Toute personne sur internet disposant de l'URL peut utiliser votre application.
* **Protégé par mot de passe** : Toute personne sur internet disposant du mot de passe peut utiliser votre application. Les visiteurs saisissent un mot de passe partagé. Ils n'ont pas besoin de compte Replit.
* **Espace de travail uniquement** : Tous les administrateurs, membres et spectateurs de votre espace de travail. Replit marque cette option comme **Privé**.
* **Sur invitation uniquement** : Seulement vous, les administrateurs, les groupes invités et les utilisateurs invités. Replit marque cette option comme **Privé**. Il s'agit de l'option la plus restrictive.

La valeur par défaut dépend de l'endroit où vous développez : les applications de votre espace de travail personnel sont définies par défaut sur **Public**, et les applications d'un espace de travail d'organisation sont définies par défaut sur une option privée.

<Note>
  Avec les deux options **Privé**, les visiteurs sans accès sont invités à se connecter via Replit avant de pouvoir consulter l'application. Dans un espace de travail personnel où vous êtes le seul membre, **Espace de travail uniquement** et **Sur invitation uniquement** se comportent de la même manière. La distinction devient importante lorsque vous travaillez dans un espace de travail partagé avec des collaborateurs.
</Note>

## Choisir l'accès lors de la publication

1. Sélectionnez **Publier** en haut à droite de l'Éditeur de projet, ou ouvrez **Publication** sous **Replit Cloud** dans le panneau **Outils**.
2. Sous **Qui peut accéder à votre application**, sélectionnez **Public**, **Protégé par mot de passe**, **Espace de travail uniquement** ou **Sur invitation uniquement**.
3. Sélectionnez **Publier**.

<Info>
  Les déploiements planifiés n'ont pas d'options d'accès car ils ne servent pas de page web.
</Info>

## Modifier l'accès d'une application en ligne

<Note>
  Modifier l'accès nécessite de dépublier votre application au préalable. Dépubliez-la depuis l'outil Publication, choisissez une autre option sous **Qui peut accéder à votre application**, puis republiez.
</Note>

## Gérer les personnes invitées

Avec **Sur invitation uniquement**, vous accordez l'accès à des utilisateurs individuels ou à des groupes depuis la gestion des accès de votre espace de travail. Les administrateurs de l'espace de travail ont toujours accès. En savoir plus sur la [gestion des accès](/fr/teams/identity-and-access-management/repl-access-management).

<Note>
  Les administrateurs de l'espace de travail peuvent restreindre les options d'accès pour leur organisation, y compris désactiver la publication protégée par mot de passe.
</Note>
