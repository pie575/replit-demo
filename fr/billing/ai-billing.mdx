Les fonctionnalités d’IA de Replit reposent sur une facturation à l’usage, basée sur ce que vous créez et votre utilisation de nos outils optimisés par l’IA. Vous ne payez ainsi que pour la valeur apportée par Agent.

<div id="getting-started">
  ## Premiers pas
</div>

**Tous les abonnés** bénéficient de checkpoints Agent gratuits à usage unique.

Des crédits mensuels supplémentaires sont automatiquement appliqués à l’utilisation de l’IA :

* **Abonnés Core** : crédits mensuels (voir les [tarifs](https://replit.com/pricing))
* **Abonnés Pro** : crédits mensuels progressifs, reportables pendant {ProCreditRolloverPeriod}. Consultez [Replit Pro](/fr/billing/plans/replit-pro).

Ces crédits couvrent Agent et d’autres services cloud de Replit, tels que les apps publiées, le stockage et les bases de données. Commencez avec Free Mode pour travailler sans frais. Dans [Power ou Max](/fr/features/agent/agent-modes), sélectionnez Auto afin de laisser Replit choisir un modèle pour les tâches payantes.

<div id="agent-billing">
  ## Facturation d’Agent
</div>

<Frame>
  <img src="/assets/mirror/checkpoint-f0cc3c49b9a5.png" alt="Interface de Replit Agent montrant le Chat et le système de checkpoints" width="1999" height="1242" data-path="images/billing/checkpoint.png" />

Free Mode permet aux abonnés Core et Pro d’effectuer gratuitement leurs tâches quotidiennes avec Agent, dans la limite de leur allocation. Les modes payants et les tâches payantes confirmées font l’objet d’une tarification basée sur l’effort, en fonction de la complexité de la demande. Replit demande une confirmation avant de lancer une action payante.

<div id="how-effort-based-pricing-works">
  ### Fonctionnement de la tarification basée sur l’effort
</div>

Lorsque vous échangez avec Agent en « Mode Build », il crée des **checkpoints** qui enregistrent le travail réalisé pour répondre à votre demande :

* Les **demandes simples** (comme les corrections de bugs ou les petites modifications) coûtent généralement moins cher que les développements complexes
* Les **développements complexes** (comme des fonctionnalités complètes ou des intégrations) sont regroupés dans un seul checkpoint, qui peut coûter plus cher qu’une demande simple, car il reflète l’effort total requis
* **Un checkpoint par demande** élimine les checkpoints intermédiaires et réduit le bruit dans la facturation
* Une **tarification transparente** vous indique exactement ce que vous payez pour chaque tâche terminée

<Info>
  Un checkpoint est créé lorsqu’Agent termine le travail sur votre demande et implémente
  la fonctionnalité demandée dans votre code.
</Info>

Dans le cadre d’une offre payante, Plan Mode peut effectuer un raisonnement facturable même sans modifier le code.

Pour en savoir plus sur le contenu des checkpoints et leur fonctionnement, consultez [Checkpoints et restaurations](/fr/features/version-control/checkpoints-and-rollbacks).

<div id="agent-services-billing">
  ### Facturation des services Agent
</div>

Certaines fonctionnalités d’Agent utilisent en arrière-plan des API tierces payantes (comme Claude, ChatGPT et Nano Banana / Gemini). Agent gère automatiquement ces intégrations : aucune clé API ni configuration n’est requise. Vous êtes facturé au tarif public de l’API du fournisseur, prélevé sur vos crédits Replit. Ces coûts apparaissent avec le reste de votre utilisation dans le [tableau de bord d’utilisation](/fr/billing/managing-spend).

Pour connaître le coût des applications d’exemple, consultez notre [démo interactive simple](https://agent-pricing.replit.app/).

<div id="track-your-usage">
  ### Suivez votre utilisation
</div>

Vous pouvez suivre vos dépenses Agent en temps réel :

1. **Onglet Agent** : consultez le coût de chaque checkpoint en survolant l’icône d’utilisation
2. **Tableau de bord d’utilisation** : consultez les informations de facturation détaillées pour la période en cours
3. **Paramètres** : configurez des alertes et des budgets dans **Compte** → **Facturation** pour maîtriser vos dépenses

<Tip>
  Les données d’utilisation peuvent mettre jusqu’à 30 minutes à apparaître dans votre tableau de bord d’utilisation.
</Tip>

<div id="managing-your-spend">
  ## Gérer vos dépenses
</div>

Gardez le contrôle de vos dépenses d&#39;IA grâce aux outils de gestion du budget intégrés à Replit :

* **Alertes d&#39;utilisation** : recevez une notification lorsque vous atteignez certains seuils de dépenses
* **Limites de budget** : définissez des plafonds stricts pour éviter les frais imprévus
* **Suivi en temps réel** : surveillez les coûts au fur et à mesure que vous développez
* **Packs de crédits** : achetez des crédits supplémentaires avec des remises sur les achats importants. Consultez [Gérer vos dépenses](/fr/billing/managing-spend) pour en savoir plus.
