<div id="what-is-a-remix">
  ## Remix란
</div>

**Remix**는 현재 접근 권한이 있는 앱을 기반으로 새로 만드는 Replit App입니다. 공개 앱이나 template을 remix하면 직접 사용해 보고 반복적으로 개선할 수 있는 나만의 사본이 생성됩니다. Remix에서 변경한 내용은 원본 앱에 영향을 주지 않습니다.

Remix에는 출처가 표시됩니다. 원본으로 연결되는 **Remixed from** 링크가 표시되고, 원본의 빌드 prompt가 cover page에 나타납니다.

<div id="what-your-remix-includes">
  ## Remix에 포함되는 항목
</div>

Remix는 원본과 완전히 분리된, 그대로 동작하는 복사본입니다.

* **모든 파일과 설정**이 복사되므로 앱이 원본과 똑같이 실행됩니다.
* **원본의 checkpoint 기록**도 함께 넘어오며, 원본 앱에서 가져온 기록으로 표시됩니다. 이 checkpoint 중 원하는 지점으로 roll back할 수 있으며, 해당 checkpoint를 만든 대화는 원본에 그대로 남습니다.
* **완전히 새로운 Agent.** Remix는 새 Agent로 시작하며, 이전 채팅 기록을 물려받지 않습니다.
* **secret은 값이 아닌 이름만.** 앱에서 secret(예: API key)을 사용하는 경우, 어떤 값을 입력해야 하는지 알 수 있도록 Remix에 이름이 값 없이 나열됩니다. 값은 본인의 앱을 remix할 때만 복사됩니다.
* **새 database.** Remix는 원본의 database에 절대 연결되지 않습니다. 원본에서 지원하는 경우 **원본 App에서 데이터 복사** 옵션으로 데이터 자체를 복사할 수 있으며, 이때도 변경 사항이 원본에 영향을 주는 일은 없습니다.
* Replit Auth를 사용하는 앱이라면 **로그인 설정도 새로 구성**됩니다.

복사되지 않는 항목: deployment, 도메인, connector 설정은 본인의 복사본에서 직접 구성해야 합니다. 또한 Remix는 Private 상태로 시작하므로, 직접 publish하기 전까지는 아무것도 공유되지 않습니다.

<div id="build-on-your-remix">
  ## Remix를 기반으로 빌드하기
</div>

Remix가 workspace에서 열리면 Agent로 앱을 수정하고 확장할 수 있습니다. **Agent** 탭에 추가하려는 기능을 설명하는 prompt를 입력하세요.

Agent가 적용한 변경 사항을 되돌리려면 변경 후 생성된 checkpoint에서 **Rollback to here**를 선택하세요. 자세한 내용은 [checkpoint 및 롤백](/ko/features/version-control/checkpoints-and-rollbacks)을 참조하세요.

<div id="remix-or-build-from-a-prompt">
  ## Remix할까요, prompt로 만들까요?
</div>

두 방식 모두 도착점은 같습니다. Agent와 함께 발전시켜 나가는 나만의 앱이죠. 다만 출발점이 다릅니다.

|             | Remix               | prompt로 만들기              |
| ----------- | ------------------- | ------------------------ |
| 출발점         | 그대로 복사한, 작동하는 앱     | 설명을 바탕으로 Agent가 만든 앱     |
| 첫 결과물       | 즉시 나오며 원본과 동일함      | 시간이 더 걸리고 결과물이 매번 다름     |
| Agent의 첫 동작 | 사용자의 direction을 기다림 | prompt를 바탕으로 계획하고 build함 |

원하는 것에 가까운 앱이 이미 있다면 remix하세요. Agent가 첫 turn부터 백지가 아니라 실제로 작동하는 앱을 대상으로 작업할 수 있습니다. 어디서도 비슷한 것을 찾을 수 없는 아이디어라면 prompt로 만들어 보세요.
