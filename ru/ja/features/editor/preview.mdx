Preview показывает вывод веб-приложения и предоставляет браузерные инструменты разработчика и возможности отладки.

Когда вы запускаете веб-приложение кнопкой **Запустить**, Replit присваивает ему временный URL, доступный в интернете. Инструмент Preview отображает страницу точно так же, как она выглядела бы в браузере. Кроме того, он включает инструменты разработчика, аналогичные тем, что есть в популярных браузерах.

<Note>
  Preview — это новое название Webview.
</Note>

<div id="section">
  ## Возможности
</div>

Preview включает следующие возможности для удобного тестирования и отладки веб-приложений:

* **Живой просмотр в браузере**: просматривайте приложение и взаимодействуйте с ним, не покидая вкладку браузера
* **Инструменты разработчика**: быстро диагностируйте проблемы с помощью встроенных инструментов
* **Проверка адаптивности**: просматривайте приложение при разных размерах экранов мобильных устройств

<div id="section-2">
  ## Использование
</div>

Инструмент Preview открывается автоматически при запуске веб-приложения.
Это поведение можно отключить или включить в настройке **Automatic Preview** инструмента **User Settings**.

Ниже описано, как открыть Preview.

<Accordion title="Как получить доступ к Preview">
  Из **дока инструментов** слева:

  1. Выберите <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Иконка «Все инструменты»" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **Все инструменты**, чтобы открыть список инструментов редактора проекта.
  2. Выберите <img class="icon-svg" src="/assets/mirror/preview-icon-6d37238e8cc2.svg" alt="Иконка Preview" width="16" height="16" data-path="images/icons/preview-icon.svg" /> **Preview**.

  Через **строку поиска**:

  1. Нажмите на <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="Иконка лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" />лупу вверху, чтобы открыть инструмент поиска
  2. Введите «Preview», чтобы найти инструмент, и выберите его в результатах.
</Accordion>

<div id="section-3">
  ## Адресная строка
</div>

Адресная строка в верхней части вкладки **Preview** содержит следующие инструменты:

* **Кнопка «Назад»**: переход к предыдущей странице в истории просмотров
* **Кнопка «Вперёд»**: переход к следующей странице в истории просмотров
* **Домен приложения**: выберите `{...}.replit.dev`, чтобы посмотреть информацию о временном URL вашего Replit App
* **Поле адреса**: показывает текущий путь URL и позволяет ввести новый

<div id="section-4">
  ## Инструменты браузера
</div>

Инструменты браузера справа от адресной строки включают следующие возможности:

* **Размер экрана**: выберите один из готовых размеров экрана для разных устройств, чтобы проверить адаптивность дизайна
* **Инструменты разработчика**: показать или скрыть панель [инструментов разработчика](#Developer_tools)
* **Новая вкладка**: открыть URL веб-приложения в новой вкладке браузера

<Note>
  **Создаёте мобильное приложение?** Панель Preview также поддерживает предпросмотр в **симуляторе iOS** и **эмуляторе Android**. Подробнее см. в разделе [Нативные мобильные приложения](/ru/ja/features/artifact-types/building-mobile-apps#preview-on-a-simulator-or-emulator).
</Note>

<div id="section-5">
  ## Инструменты разработчика
</div>

Инструменты разработчика, работающие на основе проекта с открытым исходным кодом <a href="https://github.com/liriliri/eruda" target="_blank">Eruda</a>, позволяют выполнять следующие задачи:

* просматривать консоль JavaScript в контексте приложения и работать с ней
* проверять элементы DOM
* отслеживать сетевые запросы
* настраивать параметры отображения и поведения

Чтобы открыть инструменты разработчика, нажмите кнопку <img class="icon-svg" src="/assets/mirror/wrench-7cee9d1168da.svg" alt="Значок гаечного ключа" width="16" height="16" data-path="images/icons/wrench.svg" /> **Инструменты разработчика**
в верхней части вкладки **Preview** — она работает как переключатель.

В следующих разделах описано, какие действия можно выполнять на каждой вкладке инструментов разработчика.

<div id="console">
  ### Console
</div>

На вкладке **Console** отображаются логи JavaScript, создаваемые вашим приложением.
На этой вкладке доступны следующие действия:

* **Очистка вывода**: нажмите значок перечёркнутого круга <img class="icon-svg" src="/assets/mirror/clear-bd1bf1847597.svg" height="16" width="16" alt="значок очистки" data-path="images/icons/clear.svg" />, чтобы удалить весь вывод консоли.
* **Фильтрация вывода**: отфильтруйте вывод консоли по типу (все, Info, Warning, Error).
* **Фильтр по тексту**: нажмите значок фильтра <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="значок фильтра" data-path="images/icons/filter.svg" /> и введите текст, чтобы показать совпадающие строки вывода.
* **Копирование вывода**: нажмите кнопку копирования <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="значок копирования" data-path="images/icons/copy.svg" />, чтобы скопировать выбранные сообщения консоли.
* **Выполнение кода JavaScript**: нажмите значок угловой скобки вправо <img class="icon-svg" src="/assets/mirror/arrow-right-2859a6e6bdeb.svg" height="16" width="16" alt="значок стрелки вправо" data-path="images/icons/arrow-right.svg" />, чтобы выполнить код JavaScript в контексте вашего приложения. Введите выражение и нажмите **Выполнить**.

<div id="elements">
  ### Elements
</div>

На вкладке **Elements** можно изучать и изменять структуру DOM веб-страницы.

* **Просмотр сведений об элементе**: показывает подробную информацию об элементе DOM и его расположение в HTML-коде
* **Копирование вывода**: нажмите кнопку копирования <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="Значок копирования" data-path="images/icons/copy.svg" />, чтобы скопировать выбранное сообщение консоли.

Используйте стрелку выбора <img class="icon-svg" src="/assets/mirror/select-1165d9548c39.svg" height="16" width="16" alt="Значок выбора" data-path="images/icons/select.svg" />, чтобы включить или выключить режим выбора. Перейдя в режим выбора, выберите элемент на веб-странице.
HTML и CSS этого элемента отобразятся на вкладке Elements.

<div id="network">
  ### Network
</div>

Вкладка **Network** позволяет отслеживать запросы, инициированные веб-страницей.
На этой вкладке доступны следующие действия:

* **Отслеживание запросов**: просмотр всех сетевых запросов, отправленных приложением. Выберите запрос, чтобы увидеть подробности.
* **Фильтрация**: нажмите значок воронки <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="Значок фильтра" data-path="images/icons/filter.svg" /> и введите текст, чтобы отобразить подходящие результаты. Очистите поле, чтобы сбросить фильтр.
* **Копирование**: нажмите кнопку копирования <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="Значок копирования" data-path="images/icons/copy.svg" />, чтобы скопировать информацию о хранилище.

<div id="resources">
  ### Resources
</div>

На вкладке **Resources** отображаются ресурсы, загруженные страницей, а также браузерные хранилища — cookie, локальное хранилище и другие.
Здесь можно просматривать и обновлять списки ресурсов следующих типов:

* Файлы JavaScript
* Таблицы стилей
* Iframe
* Изображения

На этой вкладке доступны следующие действия:

* **Просмотр хранилища**: проверьте локальное хранилище, хранилище сеанса и cookie.
* **Фильтрация**: нажмите значок воронки <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="Значок фильтра" data-path="images/icons/filter.svg" /> и введите текст, чтобы увидеть подходящие результаты. Чтобы сбросить фильтр, очистите поле.
* **Очистка**: нажмите кнопку очистки <img class="icon-svg" src="/assets/mirror/clear-bd1bf1847597.svg" height="16" width="16" alt="Значок очистки" data-path="images/icons/clear.svg" />, чтобы удалить все данные этого типа хранилища.
* **Удаление выбранного элемента**: нажмите значок «X» <img class="icon-svg" src="/assets/mirror/delete-a21eb49cac3c.svg" height="16" width="16" alt="Значок удаления" data-path="images/icons/delete.svg" />, чтобы удалить элемент хранилища.
* **Копирование**: нажмите кнопку копирования <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="Значок копирования" data-path="images/icons/copy.svg" />, чтобы скопировать информацию о хранилище.

<div id="settings">
  ### Settings
</div>

На вкладке **Settings** можно настроить внешний вид и поведение инструментов разработчика.
Вкладка содержит следующие параметры:

* **Настройки инструментов**: настройка параметров, применяемых к каждой вкладке инструментов
* **Управление JavaScript**: выбор параметров работы JavaScript — например, отключение JavaScript для проверки поведения приложения
* **Параметры отображения**: изменение темы инструментов разработчика, размера панелей, прозрачности и других аспектов поведения
