Cette technologie de diffusion vous permet d&#39;utiliser des applications anciennes dans votre navigateur, depuis n&#39;importe quel appareil ! Par exemple, vous pouvez exécuter directement sur votre téléphone ou votre tablette un jeu Python conçu pour ordinateur, sans apporter la moindre modification au code sous-jacent.

<div id="como-posso-usar-o-vnc">
  ## Comment utiliser VNC ?
</div>

Toute App Replit, quel que soit le langage utilisé, peut utiliser un bureau virtuel. Aucune modification n’est nécessaire pour exécuter des programmes graphiques natifs sur Replit. Le panneau VNC s’affiche lorsqu’une application tente d’ouvrir une fenêtre de bureau native.

<div id="protegendo-seu-app-no-replit">
  ## Protéger votre App Replit
</div>

Par défaut, votre connexion VNC n&#39;est pas protégée par mot de passe et n&#39;est accessible que depuis [https://replit.com](https://replit.com), car elle repose sur la même authentification que le WebSocket. Si vous devez accéder à votre App Replit via le client externe [noVNC](https://novnc.com), vous pouvez définir un mot de passe VNC.

Définissez un mot de passe dans les [Secrets](/fr/pt/core-concepts/project-editor/app-setup/secrets) de votre App Replit. `Secrets` est un emplacement sécurisé qui vous permet de stocker des mots de passe sans risquer que d&#39;autres utilisateurs y accèdent. La définition de `VNC_PASSWORD` renforce la sécurité lors des connexions à distance.

<div id="como-posso-usar-o-vnc-em-tela-cheia">
  ## Comment utiliser VNC en plein écran ?
</div>

Vous devez avoir sécurisé votre App Replit conformément aux instructions ci-dessus avant de suivre ces étapes.

1. Exécutez la commande suivante dans l’onglet « Shell » :
   ```sh theme={null}
   echo $REPL_ID
   ```

<Frame>
  <img src="/assets/mirror/replid-6508492b1e8b.png" alt="image montrant la commande echo" width="628" height="174" data-path="images/vnc/replid.png" />
</Frame>

2. Créez votre URL de connexion en remplaçant `REPL_ID` par la sortie de la commande ci-dessus : `<\REPL_ID\>.id.repl.co`
3. Ouvrez le [client noVNC](https://novnc.com/noVNC/vnc.html) dans un autre onglet du navigateur.
4. Ouvrez les paramètres de connexion.

<Frame>
  <img src="/assets/mirror/settings-3e0e0c4fd198.png" alt="ouvrir les paramètres de connexion" width="126" height="302" data-path="images/vnc/settings.png" />
</Frame>

5. Développez la section WebSockets. Saisissez votre URL de connexion (`\<REPL_ID\>.id.repl.co`) dans le champ `host` et laissez le champ `path` vide.

<Frame>
  <img src="/assets/mirror/host-31b5c99194b2.png" alt="hôte" width="214" height="230" data-path="images/vnc/host.png" />
</Frame>

6. Remplacez `Scaling Mode` par `Remote Resizing` :

<Frame>
  <img src="/assets/mirror/scaling-0ffe9aae34bb.png" alt="mise à l’échelle" width="147" height="74" data-path="images/vnc/scaling.png" />
</Frame>

7. Utilisez le nom d’utilisateur `runner` et le mot de passe configuré ci-dessus lorsque vos identifiants vous sont demandés.
