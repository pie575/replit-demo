<div id="agent-inbox">
  ### Agent Inbox
</div>

<Frame>
  <img src="/assets/mirror/screenshot-2026-01-30-at-13-03-55-2x_5c6685214c0a-b56f0ba8976e.png" alt="Interface Agent Inbox affichant les retours des visiteurs" width="1448" height="1278" data-path="images/changelog/2026-02-06/screenshot-2026-01-30-at-13-03-55-2x_5c6685214c0a.png" />
</Frame>

Les visiteurs peuvent laisser des retours directement dans [Agent Inbox](/fr/ja/build/enable-feedback) depuis les [applications publiées](/fr/cloud-services/deployments/about-deployments). Lorsqu’un visiteur utilise le widget de retours d’une application publiée, vous pouvez utiliser [Agent](/fr/core-concepts/agent) pour mettre en œuvre sa suggestion. Disponible pour tous les utilisateurs payants.

<div id="replit-gemini-cli">
  ### Extension Replit + Gemini CLI
</div>

Vous pouvez créer et gérer des projets via Gemini CLI. L’extension Replit est disponible dans le répertoire des extensions Gemini CLI, aux côtés de plus de 300 autres extensions pour développeurs.

<div id="replit-learn57">
  ### Leçons 5 à 7 de Replit Learn
</div>

Les leçons 5 à 7 sont désormais disponibles sur [Replit Learn](https://learn.replit.com), complétant ainsi le module AI Foundations. À travers des projets pratiques, découvrez ce qu&#39;est une « application », comment fonctionne l&#39;IA et ce qu&#39;est le vibe coding. Idéal pour les créateurs qui débutent avec l&#39;IA et Replit.

  ### Prise en charge des clés OpenAI personnalisées
</div>

Vous pouvez utiliser votre propre clé OpenAI dans les [intégrations IA](/fr/replitai/replit-ai-integrations) à la place du fournisseur de modèles par défaut. Disponible pour les clients Teams.
