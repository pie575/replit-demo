  ## Agent

<div id="security-scan-while-you-build">
  ### Analyse de sécurité pendant la création
</div>

Agent vérifie désormais les fichiers qu&#39;il modifie afin d&#39;y détecter les problèmes de sécurité courants, dans le cadre de sa revue de code. Cette analyse Semgrep automatique repère les schémas à risque et les secrets codés en dur, ce qui permet à Agent de traiter les constats probables avant de terminer la tâche.

En savoir plus sur l&#39;[analyse de sécurité pendant la création](/fr/features/security/project-security-center#security-scan-while-you-build).

<div id="regenerate-production-database-credentials">
  ### Régénérer les identifiants de la base de données de production
</div>

Vous pouvez désormais régénérer les identifiants d&#39;une base de données de production éligible depuis l&#39;outil **Database**. Replit met à jour les identifiants et, si votre app dispose d&#39;un déploiement actif pris en charge, lance un redéploiement afin qu&#39;elle puisse continuer à utiliser les nouveaux identifiants. Pensez à mettre à jour tous les outils externes qui utilisent l&#39;ancienne chaîne de connexion.

<div id="teams-and-enterprise">
  ## Teams et Enterprise
</div>

<div id="build-with-sso">
  ### Build avec SSO
</div>

Les créateurs Pro peuvent désormais configurer le SSO d’entreprise pour une Replit App utilisant [Clerk Auth](/fr/features/auth-and-identity/clerk-auth). Demandez à Agent la modification d’authentification dont vous avez besoin : il vous redirigera vers le tableau de bord Clerk. Vous pourrez ensuite y connecter Okta ou Microsoft Entra ID via OIDC ou SAML. Les connexions SSO d’entreprise sont gratuites jusqu’au 1er octobre 2026. Par la suite, la tarification Clerk pass-through s’applique. Enterprise sera bientôt disponible.

<div id="move-projects-between-workspaces">
  ### Déplacer des projets entre workspaces
</div>

Vous pouvez désormais déplacer un projet d&#39;un workspace d&#39;équipe à un autre au sein du même compte de facturation, depuis la liste **Projects**. Le transfert s&#39;exécute en arrière-plan et est irréversible. Les Secrets de compte liés ne suivent pas le projet : vous devez donc les relier dans le workspace de destination.

</Frame>

En savoir plus sur le [transfert de projets entre workspaces d&#39;équipe](/fr/teams/identity-and-access-management/transfer-app-to-teams#transfer-between-team-workspaces).
