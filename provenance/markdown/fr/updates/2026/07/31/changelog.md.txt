## Espace de travail

### Replit Design est disponible

Replit Design est désormais disponible. Décrivez ce que vous souhaitez créer, explorez des maquettes interactives et affinez la direction. Lorsqu'un frame est prêt, les utilisateurs Core et Pro peuvent le transformer en application fonctionnelle dans le même projet.

## Agent

### Choisissez le modèle principal d'Agent

Vous pouvez désormais choisir le modèle principal qu'Agent utilise pour une tâche. Sélectionnez Lite, Economy ou Power, puis choisissez parmi les modèles disponibles pour ce mode. Lite est maintenant disponible partout où vous pouvez utiliser Agent, y compris dans les applications mobiles. Les modèles disponibles varient selon l'organisation, l'autorisation et l'accès Turbo.

### Connectez davantage de serveurs MCP

Les espaces de travail éligibles peuvent se connecter à Supabase, Statsig et Calendly depuis le catalogue de serveurs MCP prélistés. Replit reconnaît également le point de terminaison MCP officiel de Braintrust et lance son flux de connexion OAuth lorsque vous l'ajoutez manuellement.

## Facturation

### Une page d'utilisation repensée

La page Utilisation repensée est déployée auprès de comptes entreprise sélectionnés et de nouveaux clients. Filtrez l'utilisation par date, ressource, projet, espace de travail, groupe ou membre.

## Équipes et Enterprise

### Restez connecté plus longtemps

Les sessions Replit durent désormais plus longtemps avant que vous n'ayez besoin de vous reconnecter. Les administrateurs Enterprise peuvent configurer les préréglages du délai d'expiration de session.
