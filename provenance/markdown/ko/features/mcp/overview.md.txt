Replit Agent는 AI 연동의 개방형 표준인 [Model Context Protocol(MCP)](https://modelcontextprotocol.io)을 통해 외부 도구 및 데이터 소스에 연결합니다. 아래의 각 서버는 원클릭으로 설치할 수 있으며, Agent는 설치 후 자동으로 해당 도구를 로드하고 적절한 상황에서 사용합니다.

개념에 대한 설명은 [Model Context Protocol](/ko/learn/model-context-protocol)을 참조하세요. 실습 가이드는 [MCP로 연결하기](/ko/build/connect-via-mcp)를 참조하세요. 여기에 나열되지 않은 서버를 연결하려면 [커스텀 MCP 서버 추가](/ko/build/connect-via-mcp#add-a-custom-mcp-server)를 참조하세요.

<Info>
  서버를 설치하려면 **Add to Replit**을 선택하세요. 프로젝트 편집기에서 연결 승인 요청이 표시됩니다.
</Info>

## 보안 보호

모든 MCP 트래픽은 Replit의 보안 스캐너를 통과합니다. 스캐너는 도구 정의와 계획된 실행을 평가하여 의심스럽거나 안전하지 않은 도구가 실행되기 전에 차단합니다. 도구가 거부되면 Agent가 이를 알려줍니다.

## 인증 옵션

* **OAuth 동적 클라이언트 등록** — 서버가 OAuth DCR을 지원하는 경우 Replit이 자동으로 감지하여 클라이언트를 등록합니다. 사전 등록된 대부분의 서버는 이 방식을 사용합니다.
* **커스텀 헤더** — 하나 이상의 헤더 이름/값 쌍(예: `X-API-Key`)을 정의합니다. Replit은 모든 MCP 요청에 이 헤더를 포함하므로 서버가 호출자를 확인할 수 있습니다. 정적 토큰으로 인증하는 커스텀 서버를 추가할 때 사용합니다.

## 자신의 설치 링크 공유하기

설치 링크를 사용하면 클릭 한 번으로 MCP 서버를 Replit에 추가할 수 있습니다. [MCP로 연결하기](/ko/build/connect-via-mcp#share-an-install-link)의 양식으로 생성하거나, 직접 만들 수도 있습니다: JSON 페이로드를 base64로 인코딩하여 `https://replit.com/integrations?mcp=`에 붙입니다.

```json theme={null}
{
  "displayName": "My MCP Server",
  "baseUrl": "https://example.com/mcp",
  "headers": [{ "key": "Authorization", "value": "Bearer your-token" }]
}
```

* **displayName** — 설치 중에 표시되는 이름
* **baseUrl** — MCP 서버의 HTTPS 엔드포인트
* **headers** — 선택적 인증 헤더
