## Les modèles de frameworks pour développeurs ont été supprimés

Les modèles de démarrage par langage et framework (anciennement appelés « frameworks pour développeurs ») ne sont plus disponibles sur Replit. Les pages `replit.com/templates` et `replit.com/developer-frameworks` redirigent désormais vers la [Galerie Replit](https://replit.com/gallery).

Pour démarrer un nouveau projet, utilisez plutôt l'une des options suivantes :

* **Démarrer avec Replit Agent** — Décrivez ce que vous voulez créer depuis la [page d'accueil](https://replit.com/) et laissez Agent construire la structure du projet pour vous.
* **[Importer depuis GitHub, GitLab ou Bitbucket](/fr/build/import-from-providers)** — Apportez une base de code existante ou une pile de démarrage en tant que nouvelle application Replit.
* **[Remixer une application publiée](https://replit.com/gallery)** — Parcourez la Galerie Replit pour découvrir des applications communautaires que vous pouvez consulter et remixer comme point de départ.

## Modèles personnalisés pour entreprises

Les organisations Enterprise peuvent créer des [modèles personnalisés](/fr/teams/custom-templates) qui apparaissent comme options sélectionnables dans la zone de saisie de l'Agent pour tous les membres de l'organisation. Les modèles personnalisés vont au-delà des frameworks pour développeurs en incluant des instructions Agent spécifiques à l'entreprise, des compétences et un contexte de projet préconfiguré. Consultez le [guide des modèles personnalisés](/fr/teams/custom-templates) pour plus de détails.
