<div id="free-mode">
  ### 使用 Free Mode
</div>

借助 Free Mode，你无需消耗 Power 模式或 Max 模式的额度，即可进行聊天、构思、创作和构建。Free Mode 使用 Auto 来选择模型，其用量上限因套餐而异。可在 **Settings** &gt; **Usage** 中查看剩余可用量和重置时间。

<Frame caption="在 Agent 模式面板中选择“Free”。">
  <img src="/assets/mirror/free-mode-agent-modes-selector-sanitized-b4b896fb13ab.png" width="1784" height="882" data-path="images/chat/free-mode-agent-modes-selector-sanitized.png" />
</Frame>

了解[如何充分利用 Free Mode](/zh/ja/chat/free-mode)。

<div id="conversations">
  ### 从 Conversations 开始
</div>

先从一个私密的 Conversation 起步，你可以在其中提问、查找信息、附加上下文、运行 Routine，或描述你想要的结果。当工作逐渐成型后，让 Replit 把 Conversation 转换为 Project，上下文和文件都会原样保留。

  <img src="/assets/mirror/start-new-conversation-home-sanitized-neutral-874efff00786.jpg" alt="经过脱敏处理的 Replit 工作区主页，显示 Projects、Conversations、Routines、推荐提示词以及 Conversation 消息框" width="1451" height="1084" data-path="images/chat/start-new-conversation-home-sanitized-neutral.jpg" />
</Frame>

进一步了解 [Conversations](/zh/ja/chat/conversations)。

<div id="routines">
  ### 使用 Routines 自动化日常工作
</div>

让 Replit 定期执行 Conversation 中重复性的工作。每次运行的结果都会返回到同一个 Conversation，你可以在其中查看结果并继续推进工作。Routines 在 Power 模式或 Max 模式下运行，每次运行都需要消耗预算。

<Frame caption="在同一处查看活跃的 Routine、调度计划和运行历史。">
  <img src="/assets/mirror/routines-management-page-c8d8f51156d4.png" alt="Routines 页面，列出 Slack 上活跃的每日日历摘要及其调度计划" width="2738" height="782" data-path="images/chat/routines-management-page.png" />
</Frame>

进一步了解 [Routines](/zh/ja/chat/routines)。

<div id="agent-2">
  ### 引导正在工作的 Agent
</div>

在 Agent 工作期间发送后续消息，可以为进行中的轮次补充新的上下文。Steer 是 Conversations 和 Projects 的默认行为，你可以在 **Settings** &gt; **Personalization** 中分别将其改为 Queue。如果只想让某一条消息采用相反的行为，请在 Mac 上按 Cmd+Enter，在 Windows 和 Linux 上按 Ctrl+Enter。

<Frame caption="你可以分别为 Conversations 和 Projects 选择 Steer 或 Queue。">
  <img src="/assets/mirror/agent-follow-ups-settings-98a4c5ca399e.png" alt="展示 Conversation 与 Project 发送行为的 Agent 设置，包含 Steer 与 Queue 选项" width="3048" height="1372" data-path="images/replitai/agent-follow-ups-settings.png" />
</Frame>

进一步了解[引导与排队消息](/zh/ja/features/agent/steer-and-queue-messages)。

<div id="githubskills">
  ### 从 GitHub 导入 Skills
</div>

你可以从公开的 GitHub 仓库、文件夹或文件 URL 导入 skills，并在添加前预览 skill 文件。已保存的 Project skills 还支持将成员访问级别设置为 **Required**、**Available** 或 **No access**。

<Frame caption="打开 Workspace skills，查找并使用共享或导入的 skills。">

</Frame>

进一步了解[如何共享和导入 Agent skills](/zh/ja/features/agent/skills#share-project-skills)。

<div id="agent-3">
  ### 跨 工作区 管理 Agent 模型
</div>

Enterprise 账户管理员现在可以针对不同模型身份提供方设置账户策略，并选择各个 工作区 可使用的模型。请根据组织策略使用 **Enable all**、**Enable selected** 或 **Disabled**。

</Frame>

<div id="section-4">
  ### 执行黑盒渗透测试
</div>

运行 Level 3 安全扫描，该扫描包含三项检查：免费的依赖项和软件包检查、Agent 对源代码的静态分析，以及针对运行中 Preview 的外部黑盒测试。Replit 会并行执行源代码审查和外部测试。

</Frame>
