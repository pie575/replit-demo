Auth는 **authentication**(인증)의 줄임말로, 앱에 &quot;사용자&quot;라는 개념을 부여하는 기능입니다. 인증이 없으면 모든 방문자는 익명이 되고, 앱은 누가 누구인지 구분할 수 없습니다. 인증을 적용하면 방문자가 각자 로그인하고, 앱은 그 사람이 누구인지 알 수 있으며, 예약 내역, 저장한 차량, 환경설정, 진행 상황처럼 사용자별 데이터를 저장할 수 있습니다.

인증을 연결하고 나면 다음과 같은 일이 가능합니다.

* 사용자별 데이터 저장 — 예약, 설정, 콘텐츠, 기록.
* 로그인한 사용자만 쓸 수 있도록 기능 제한(결제, 프로필 페이지, 관리자 패널 등).
* 이름, 역할, 요금제, 과거 활동에 맞춘 경험 개인화.
* 세션 단위가 아닌 개인 단위의 활동 및 사용량 추적.

<div id="how-auth-works-in-a-replit-app">
  ## Replit 앱에서 인증이 작동하는 방식
</div>

Replit은 두 가지 기본 제공 인증 옵션을 제공합니다. 두 옵션 모두 Agent가 프로비저닝하므로 별도의 대시보드 가입이나 OAuth 키 복사·붙여넣기가 필요 없습니다.

* **[Replit Auth](/ko/features/auth-and-identity/authentication)** — 사용자가 기존 **Replit 계정**으로 로그인합니다. 로그인 페이지에는 Replit 브랜딩이 적용됩니다. Agent에게 추가해 달라고 요청하는 것 외에 별도의 설정이 필요 없습니다.
* **[Clerk Auth](/ko/features/auth-and-identity/clerk-auth)** — 앱마다 전용 **Clerk 테넌트**가 생성됩니다. 사용자는 Replit이 아니라 *여러분의* 앱 안에서 계정을 만듭니다. 브랜딩, 로그인 방식, 로그인 화면의 디자인을 직접 제어할 수 있습니다.

두 옵션 모두 로그인 페이지, 세션, 안전한 비밀번호 처리, 소셜 로그인 등 번거로운 작업을 대신 처리해 주므로, 앱 코드는 &quot;로그인한 사용자가 누구인가?&quot;만 확인하면 됩니다.

<div id="replit-auth-vs-clerk-auth">
  ## Replit Auth vs. Clerk Auth
</div>

|                  | Replit Auth                     | Clerk Auth                            |
| ---------------- | ------------------------------- | ------------------------------------- |
| **사용자 계정**       | 사용자가 Replit 계정으로 로그인        | 사용자가 앱 내에서 계정을 생성(Replit 계정 불필요) |
| **브랜딩**          | Replit 브랜드가 적용된 login 페이지       | 완전한 맞춤 설정 가능 — 앱 이름, icon, 색상         |
| **SSO 자격 증명**    | Replit의 공용 OAuth app 사용         | provider별로 직접 준비한 OAuth 자격 증명 사용      |
| **Environments** | 단일 환경                           | Development와 Production 환경 분리         |
| **적합한 경우**       | 빠른 설정, 프로토타입, Replit 브랜딩이 무방한 앱 | 브랜드가 있는 앱, 전문적·상업적 제품                 |

프로토타입이나 내부용 도구를 만든다면 Replit Auth가 가장 빠른 방법입니다. 고유한 브랜드 정체성을 갖춘 앱, 특히 고객용이거나 상업적인 앱을 만든다면 Clerk Auth가 더 적합합니다.

<div id="add-auth-to-your-app">
  ## 앱에 인증 추가하기
</div>

처음부터 정해둘 필요는 없습니다. 하나로 시작한 뒤 나중에 마이그레이션해도 됩니다. 가장 빠른 방법은 Agent에게 어떤 것을 사용할지 알려주는 것입니다.

* *&quot;내 앱에 로그인을 추가해 줘. Replit Auth를 사용해.&quot;*
* *&quot;내 앱에 로그인을 추가해 줘. Clerk Auth를 사용해.&quot;*
