<div id="documentao-replitmd">
  ### Документация replit.md
</div>

Настройте поведение Agent с помощью `replit.md` — специального файла конфигурации, который помогает Agent разобраться в ваших предпочтениях, стиле написания кода и архитектуре проекта. Agent создаёт этот файл автоматически, опираясь на проверенные практики, а затем использует его, чтобы создавать приложения, в точности соответствующие вашим требованиям. Передайте Agent контекст проекта, задайте стандарты написания кода, укажите предпочитаемый технологический stack и настройте предпочтения по общению — всё в одном месте.

<div id="indicadores-de-privacidade-de-implantao">
  ### Индикаторы приватности деплоя
</div>

Новые визуальные индикаторы на панели деплоев позволяют быстро понять, какие деплои публичные, а какие приватные. Это улучшение помогает избежать путаницы: вы всегда будете точно знать, кто имеет доступ к вашим развёрнутым приложениям.

<div id="atualizao-de-chamada-de-mltiplas-ferramentas-do-agent">
  ### Улучшение множественных вызовов инструментов в Agent
</div>

Экономьте 15% на расходах на Agent и получайте результаты на 30% быстрее благодаря улучшенной системе вызова нескольких инструментов. Теперь Agent эффективнее группирует операции и разумнее обрабатывает ошибки инструментов, обеспечивая тот же уровень качества при меньшем расходе ресурсов.
