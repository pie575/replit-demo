Фрейм дизайна — не просто изображение, а спецификация будущего приложения. Если фрейм вам понравился, поручите работу Agent: выберите фрейм, нажмите **Build…** на панели действий, а затем выберите один из вариантов:

* Создать новое приложение по дизайну в том же проекте
* Применить дизайн к уже существующему приложению
* В любом случае можно безопасно отменить изменения: перед началом работы Agent создаст чекпоинт

<div id="section">
  ## От фрейма к приложению: два пути
</div>

Меню **Build…** выбранного фрейма Design предлагает два варианта:

<div id="section-2">
  ### Создание приложения на основе дизайна
</div>

При выборе **Build this design** на основе этого фрейма создается новый артефакт. Agent реализует макет, стили и ресурсы, добавляя работающее приложение в список артефактов проекта.

<div id="section-3">
  ### Применение к существующему приложению
</div>

В этом меню также отображаются все артефакты проекта. Выберите один из них, чтобы применить дизайн к соответствующему приложению: Agent перепишет код артефакта в соответствии с фреймом, а фрейм Design останется на холсте в качестве ориентира. Так можно обновить стиль уже созданного приложения, не создавая его заново с нуля.

<div id="section-4">
  ## Порядок действий
</div>

<Steps>
  <Step title="Выберите дизайн для Build">
    Выберите фрейм для публикации. Сначала сравните варианты на холсте. После Build текущий этап работы будет завершён, но Agent создаст чекпоинт, к которому можно вернуться в любой момент.
  </Step>

  <Step title="Поручите работу Agent">
    Выберите фрейм, нажмите **Build…** на панели действий и укажите, что нужно сделать: создать новый артефакт или применить дизайн к существующему. Agent реализует дизайн, макет, стили и ресурсы и будет сообщать о ходе работы в чате.
  </Step>

  <Step title="Проверьте результат Build">
    Agent сообщит о внесённых изменениях и создаст чекпоинт. Откройте результат, чтобы проверить, как дизайн работает на практике, и при необходимости продолжайте дорабатывать его в чате.
  </Step>
</Steps>

<Note>
  Для создания нового приложения из фрейма Design необходим тариф Core или Pro. Все остальные функции Replit Design, включая применение дизайна, доступны на всех тарифах. Подробнее о тарифах см. в разделе [Биллинг](/ru/ko/billing/ai-billing).
</Note>

<div id="section-5">
  ## После сборки: создайте настоящее приложение
</div>

Собрав фрейм, вы получите работающее приложение с готовым дизайном. Макет лишь создавал видимость работы, но теперь Agent может добавить реальные функции. Просто попросите об этом в чате:

* **Добавить вход в систему**: добавьте учётные записи пользователей с помощью [Replit Auth](/ru/ko/features/auth-and-identity/authentication), чтобы они могли входить через свои учётные записи Replit без дополнительной настройки или подключать другого поставщика по своему выбору.
* **Сохранять реальные данные**: сохраняйте и загружайте заказы, сообщения и настройки с помощью встроенной [Database](/ru/ko/features/data-and-storage/sql-database).
* **Принимать платежи**: добавьте возможность принимать платежи и оформлять подписки с помощью интеграции [Monetization](/ru/ko/features/monetization/overview).
* **Подключаться к другим сервисам**: Agent автоматически включает [интеграции](/ru/ko/features/integrations/overview) — от электронной почты до Slack и сервисов Google — в зависимости от содержания промпта.

<div id="section-6">
  ## Запуск и развитие
</div>

Когда приложение будет работать как надо, покажите его пользователям и продолжайте улучшать:

* **Опубликуйте приложение**: Опубликуйте его с помощью [Publishing](/ru/ko/features/publishing/overview), а затем ознакомьтесь с тем, как обновлять работающее приложение, в разделе [После публикации](/ru/ko/features/publishing/after-you-publish).
* **Настройте собственный адрес**: Купите или подключите [пользовательский домен](/ru/ko/features/publishing/custom-domains).
* **Сделайте приложение легко находимым**: Запустите [SEO Agent](/ru/ko/features/publishing/seo-agent), чтобы провести технический аудит и исправить проблемы в один клик.
* **Собирайте отзывы посетителей**: Добавьте [виджет обратной связи](/ru/ko/features/publishing/feedback-widget), чтобы пользователи могли сообщать о проблемах и идеях, а вы — сразу передавать их Agent.
* **Поддерживайте работоспособность**: Отслеживайте состояние, производительность и время безотказной работы с помощью [мониторинга опубликованного приложения](/ru/ko/features/publishing/monitoring-a-deployment).
