在 Replit 上发布 Web 应用时，系统会自动对已上线的 URL 运行搜索引擎优化 (SEO) 审计，并在 Publishing 工具中显示 SEO 评分。如果评分还有提升空间，只需一键即可将具体问题转交给 Agent，几秒钟内即可修复。

对大多数创作者而言，完整流程就是：发布应用，看一眼评分，然后让 Agent &quot;优化我的 SEO&quot;。本页将介绍其背后的运作原理，以及如何充分利用这项功能。

<div id="o-que-seo-e-por-que-importa">
  ## 什么是 SEO，它为何重要
</div>

搜索引擎优化 (SEO) 是指通过合理构建网站，让 Google 等搜索引擎能够发现、理解并对其进行排名。SEO 做得好，意味着当人们搜索你所提供的内容时，你的 App 就会出现在搜索结果中——而且无需投放广告。

真正决定 SEO 效果的其实就那么几件事：清晰的页面标题和描述、语义化的 HTML、快速的加载速度、适配移动设备的布局、图片上具有描述性的替代文本，以及可被抓取的站点结构。搜索引擎青睐那些对人和机器都易于阅读的网站。

无论你要发布的是落地页、营销网站、博客、目录站，还是任何其他看重曝光度的项目，SEO 都是你在早期能做出的最具回报的投入之一。

<div id="como-o-replit-melhora-o-seu-seo-por-padro">
  ## Replit 如何默认优化你的 SEO
</div>

Replit 已为你打理好大量 SEO 基础工作，让你专注于内容和产品：

* **快速的全球分布式托管**：Replit Deployments 依托为速度优化的基础设施来提供你的 App，你还可以通过[项目地理位置](/zh/pt/features/publishing/project-geography)选择 App 的运行区域。
* **默认启用 HTTPS**：每个已部署的 App 都会获得由 Replit 托管的 TLS 证书，这是搜索引擎的一项基础排名信号。
* **自定义域名**：接入你自己的域名，建立品牌信任与权威。参见 [Custom Domains](/zh/pt/features/publishing/custom-domains)。
* **面向内容站点的 Static Deployments**：对于营销页面、博客和文档，[Static Deployments](/zh/pt/features/publishing/deployment-types#static) 提供预渲染的 HTML，便于搜索引擎抓取。
* **Agent 编写兼顾 SEO 的代码**：Agent 构建页面时，默认生成语义化 HTML、无障碍标记和 meta 标签——正是 SEO 工具会检查的那些内容。
* **SEO 评分**：每次发布后自动进行一次审计，让你随时了解现状，还能一键转交给 Agent 修复发现的问题。

<div id="onde-encontrar">
  ### 在哪里查看
</div>

在已发布的 app 中打开 **Publishing** 工具。SEO 评分会与其他构建详情一起显示在 deployment 概览中。将鼠标悬停在评分上，即可查看 Lighthouse 在各个页面上发现的具体待办事项。

<Note>
  如果没有看到 SEO 评分，可能是因为你的 app 是私有的，或者最近没有发布过。该评分仅对已发布的面向 web 的公开 app 显示。
</Note>

<div id="como-interpretar-sua-classificao">
  ### 如何解读你的评级
</div>

Replit 会根据 Lighthouse 审计结果显示以下三种评级之一：

| 评级         | 含义                              |
| :--------- | :------------------------------ |
| Healthy    | 你的 App 符合 SEO 最佳实践。有重大改动后请注意复查。 |
| Needs Work | 存在若干问题，影响了搜索引擎理解该 App 的能力。      |
| Weak       | 缺少基础的 SEO 要素。修复这些问题通常只需几分钟。     |

如果你的 App 包含多个页面，徽章会显示 Replit 抓取到的所有 URL 中**最低**的评级，这样表现最差的页面会优先呈现，而不会被平均值掩盖。

<div id="quando-a-classificao-calculada">
  ### 评分何时计算
</div>

每次成功发布后都会自动运行审计。评分通常在 deployment 上线后的一到两分钟内出现，Publishing 工具会在结果返回时立即更新该徽章。

<div id="tipos-de-deployment-compatveis">
  ### 支持的 deployment 类型
</div>

SEO 评分仅针对面向网络的公开 deployment 计算，即搜索引擎能够抓取其 URL 的 deployment：

* [Autoscale Deployments](/zh/pt/features/publishing/deployment-types#autoscale)
* [Reserved VM Deployments](/zh/pt/features/publishing/deployment-types#reserved-vm)
* [Static Deployments](/zh/pt/features/publishing/deployment-types#static)

Scheduled deployment 和私有 deployment 不会生成 SEO 评分，因为它们不承载公开的网络流量。

<div id="otimizar-seo-com-o-agent">
  ## 使用 Agent 优化 SEO
</div>

评分旁边会出现一个 **Optimize SEO with Agent** 按钮。点击后会在 Growth 面板中打开 [SEO Agent](/zh/pt/features/publishing/seo-agent)，你可以在其中运行技术性 SEO 审计、查看发现的问题，并一键应用修复。

<Tip>
  你也可以完全不用这个按钮。直接打开 Agent，输入 **&quot;optimize my SEO&quot;**——Agent 会读取你最新的检测结果并着手处理。
</Tip>

Agent 完成修改后，请重新发布你的 App。SEO 评分会基于新的构建重新计算，徽章也会自动更新。

Agent 通常会应用的修复包括：

* 添加或重写缺失、过于笼统的 `<title>` 标签，让每个页面都有独特且具描述性的标题
* 为每个页面添加元描述
* 为图片添加描述性的 `alt` 文本
* 在 `<html>` 元素上设置 `lang` 属性
* 确保链接具有可识别的文本 (不使用“点击这里”或空锚文本)
* 添加 `robots.txt` 和 `sitemap.xml`
* 添加 viewport meta 标签，以适配移动设备渲染
* 改善未通过无障碍检查的文本的颜色对比度
* 添加 Open Graph 和 Twitter 卡片 meta 标签，让你的 App 链接在社交平台上正确显示预览

<div id="melhores-prticas-para-um-site-otimizado-para-seo-no-replit">
  ## 在 Replit 上打造 SEO 优化网站的最佳实践
</div>

无论是让 Agent 处理这些任务，还是自行开发，以下是在 Replit 上构建 App 时最值得优先做好的事项：

* **为每个页面设置唯一的标题和元描述。** 标题尽量控制在 60 个字符以内，描述控制在约 150 至 160 个字符。
* **使用语义化 HTML。** 使用 `<main>`、`<header>`、`<nav>` 和 `<footer>` 组织页面布局。每页仅使用一次 `<h1>`，并按顺序使用各级标题。
* **为每张图片添加 alt 文本。** 描述图片呈现的内容，而不只是图片的类型。
* **生成 `sitemap.xml` 和 `robots.txt`。** 请 Agent 创建这两个文件，让搜索引擎了解应抓取哪些内容。
* **添加 Open Graph 标签和 Twitter 卡片。** 控制 App 在社交媒体上分享时的显示方式。
* **使用自定义域名。** 品牌域名能提升访客和搜索引擎的信任度。请参阅[Custom Domains](/zh/pt/features/publishing/custom-domains)。
* **选择合适的 deployment 类型。** 对于内容较多的网站，[Static Deployments](/zh/pt/features/publishing/deployment-types#static)可提供预渲染 HTML，让搜索引擎即时解析。
* **添加结构化数据。** JSON-LD 标记可帮助搜索引擎为产品、文章、常见问题和活动展示富媒体搜索结果。
* **保持 App 快速响应。** 优化图片，避免使用阻塞渲染的脚本，并利用 Replit 托管服务缩短响应时间。

一次性应用大部分优化的简单方法：

<AiPrompt>
  审核我的网站是否符合 SEO 最佳实践，并进行修复。添加 sitemap、robots.txt、Open Graph 标签、适用的结构化数据，并确保每个页面都有唯一的标题和元描述。
</AiPrompt>
