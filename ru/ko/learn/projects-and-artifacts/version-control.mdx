Контроль версий в Replit позволяет уверенно отслеживать изменения в кодовой базе, управлять ею и работать над ней совместно. Благодаря встроенной интеграции с Git и подключению к GitHub вы можете:

* отслеживать изменения в коде и вести историю разработки;
* работать вместе с участниками команды без конфликтов в коде и потери наработок;
* импортировать, изменять и отправлять код между Replit и GitHub;
* безопасно экспериментировать с новыми функциями в отдельных ветках.

<div id="section">
  ## Что такое контроль версий?
</div>

Контроль версий — это система, которая фиксирует изменения в файлах с течением времени и позволяет позже вернуться к любой нужной версии. В Replit контроль версий построен на Git — отраслевом стандарте для отслеживания изменений в коде — и предлагает удобный визуальный интерфейс, для работы с которым не нужно знать командную строку.

<div id="replit">
  ### Как работает контроль версий в Replit
</div>

Все четыре варианта контроля версий работают с одним и тем же базовым репозиторием Git:

1. **Чекпоинты Agent** автоматически создают коммиты на ключевых этапах работы с [Replit Agent](/ru/ko/features/agent/overview). [Подробнее о чекпоинтах и откатах](/ru/ko/features/version-control/checkpoints-and-rollbacks).
2. **Панель Git** даёт визуальный доступ к полноценному репозиторию Git.
3. **Git CLI** предоставляет доступ ко всем возможностям Git из командной строки.
4. **История файлов** отслеживает детальные изменения внутри отдельных файлов.

Выбирайте интерфейс под свои задачи — в любом случае в основе лежит мощная система контроля версий Git.

| Возможность                | Чекпоинты Agent                  | Коммиты Git                         | История файлов               |
| -------------------------- | -------------------------------- | ----------------------------------- | ---------------------------- |
| **Создание**               | автоматически в логичные моменты | вручную или по расписанию           | автоматически                |
| **Детализация**            | изменения на уровне функций      | изменения любого размера            | изменения на уровне символов |
| **Описание**               | сводка, созданная ИИ             | сообщение, написанное пользователем | автоматическая метка времени |
| **Откат**                  | восстановление в один клик       | нужны знания Git                    | восстановление в один клик   |
| **Возможности Git**        | все возможности Git              | все возможности Git                 | возможностей Git нет         |
| **Синхронизация с GitHub** | полная синхронизация с GitHub    | полная синхронизация с GitHub       | синхронизации с GitHub нет   |

<div id="section-2">
  ## Начало работы
</div>

Добавьте инструмент Git в Project Editor своего Replit App, чтобы получить доступ к контролю версий:

1. Перейдите в раздел Tools в Replit App.
2. Нажмите значок **+**, чтобы добавить новый инструмент.
3. Выберите **Git** в списке доступных инструментов.

Чтобы импортировать существующий project из GitHub, см. [Импорт из GitHub](/ru/ko/build/import-from-providers).

<div id="section-4">
  ### Автоматический контроль версий
</div>

<Accordion title="Чекпоинты Agent">
  Автоматические снимки, создаваемые в ходе разработки с помощью ИИ при использовании [Replit Agent](/ru/ko/features/agent/overview).

  **Лучше всего подходит для**: разработки вместе с Replit Agent

  **Основные возможности**:

  * Автоматическое создание на логических вехах
  * Откат в один клик
  * Снимки на уровне функций
  * Отслеживание прогресса
  * Не требует настройки
  * Наглядная временная шкала хода разработки

  Чекпоинты Agent хранятся в Git, и доступ к ним можно получить через панель Git или Git CLI. Кроме того, все чекпоинты можно наглядно просмотреть с помощью функции History, которая предоставляет:

  * Хронологическую визуализацию чекпоинтов
  * Подробные описания чекпоинтов
  * Прямой доступ к состоянию чекпоинта
  * Откат к любому чекпоинту в один клик
</Accordion>

<Accordion title="История файлов">
  Отслеживание версий по каждому файлу с автосохранением изменений, внесённых напрямую в редакторе, а не через Agent.

  **Лучше всего подходит для**: быстрого восстановления недавних изменений в файлах

  **Основные возможности**:

  * Фокус на одном файле
  * Изменения на уровне символов
  * Наглядное сравнение
  * История за 30 дней
  * Воспроизведение изменений

  У истории файлов есть собственный интерфейс, но лежащие в её основе изменения являются частью истории Git. Подробнее об [истории файлов](/ru/ko/features/version-control/file-history).
</Accordion>

<div id="git">
  ### Интерфейсы на основе Git
</div>

<Accordion title="Панель Git">
  Визуальный интерфейс для работы с Git, который делает контроль версий доступным без знания командной строки.

  **Лучше всего подходит для**: большинства проектов, где нужна интеграция с GitHub и визуальный рабочий процесс

  **Основные возможности**:

  * Полное отслеживание репозитория
  * Управление ветками
  * Визуальный просмотр различий (diff)
  * Синхронизация с GitHub в один клик
  * Командная работа

  Подробные инструкции по работе с панелью Git см. в разделе [Использование панели Git](/ru/ko/features/workspace-tools/git-interface).
</Accordion>

<Accordion title="Git CLI">
  Предоставляет полный доступ к Git из командной строки через [Shell](/ru/ko/features/workspace-tools/shell) для продвинутых операций.

  **Лучше всего подходит для**: опытных пользователей, которым нужны все возможности Git

  **Основные возможности**:

  * Полный набор команд Git
  * Продвинутые стратегии ветвления
  * Собственные рабочие процессы
  * Автоматизация с помощью скриптов
  * Полный контроль над репозиторием

  Распространённые команды Git и примеры их применения см. в разделе [Использование панели Git](/ru/ko/features/workspace-tools/git-interface#using-git-commands-in-shell).
</Accordion>

<div id="section-5">
  ## Основные возможности
</div>

* **Визуальный интерфейс Git**: управление репозиториями, коммитами и ветками без ввода Git-команд
* **Интеграция с GitHub**: подключайте репозитории GitHub для резервного копирования и совместной работы
* **Импорт из GitHub**: [превратите репозиторий GitHub в Replit App](/ru/ko/build/import-from-providers) за пару кликов
* **Управление ветками**: создавайте, переключайте и сливайте ветки прямо в Project Editor
* **Разрешение конфликтов**: находите и устраняйте конфликты слияния с помощью визуальных подсказок

<div id="section-6">
  ## Варианты использования
</div>

**Отслеживание личных проектов**

Отслеживайте изменения в коде во время разработки, чтобы при необходимости вернуться к предыдущей версии. [Панель Git](/ru/ko/features/workspace-tools/git-interface) наглядно показывает изменения, позволяя легко создавать коммиты с содержательными обновлениями.

**Совместная работа в команде**

Несколько разработчиков могут работать с одной кодовой базой, не перезаписывая изменения друг друга. Создайте ветку для новой функции, а затем объедините её, когда всё будет готово. Подробнее — в разделе [Приглашение участников команды](/ru/ko/build/invite-teammates).

<div id="agent">
  ## Чекпоинты Agent
</div>

Когда вы создаёте приложение с помощью [Replit Agent](/ru/ko/features/agent/overview), чекпоинты дают дополнительный уровень контроля версий. В ключевые моменты разработки с ИИ они автоматически сохраняют полное состояние проекта — его содержимое, контекст диалога с ИИ и подключённые базы данных.

<div id="section-7">
  ### Как работают чекпоинты
</div>

Чекпоинты Agent — это исчерпывающие снимки всего состояния Replit App:

* **Автоматическое создание**: Agent создаёт чекпоинты в логических точках процесса разработки.
* **Полное сохранение состояния**: каждый чекпоинт сохраняет содержимое проекта, память ИИ и состояние базы данных.
* **План реализации**: прежде чем вносить изменения, Agent представляет план на рассмотрение.
* **Отслеживание сложных задач**: для крупных задач может создаваться несколько чекпоинтов.

<div id="ai">
  ### Преимущества разработки с помощью ИИ
</div>

Чекпоинты Agent дают уникальные преимущества при разработке с ИИ:

* **Подстраховка**: экспериментируйте уверенно, зная, что предыдущее состояние всей среды разработки можно легко восстановить.
* **Отслеживание прогресса**: вы видите, как именно Agent шаг за шагом собирал ваше приложение.
* **Логические вехи**: чекпоинты отражают завершённые функции, а не произвольные точки сохранения.
* **Мгновенный откат**: возвращайтесь к любому предыдущему состоянию одним кликом, включая восстановление базы данных и контекста ИИ.

<Info>
  Подробнее о том, что именно фиксируют чекпоинты, и о полных возможностях отката читайте в разделе [Чекпоинты и откаты](/ru/ko/features/version-control/checkpoints-and-rollbacks).
</Info>

<Tip>
  Чекпоинты Agent — мощный инструмент при разработке с ИИ, но для долгосрочного отслеживания версий и совместной работы, особенно с внешними репозиториями, стоит использовать коммиты Git.
</Tip>
