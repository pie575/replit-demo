connector를 관리하면 팀이 일관되고 안전한 방식으로 integration을 사용할 수 있습니다. 사용할 수 있는 기능은 plan에 따라 다릅니다.

* **Core 및 Pro**: connector 관리는 **협업 workspace**에서 사용할 수 있습니다. account admin이 해당 workspace의 연결을 설정하고 관리하며, builder는 해당 workspace 내의 앱에서 이를 사용할 수 있습니다.
* **Enterprise**: 사용자 지정 OAuth 클라이언트, API key access control, 자체 키 사용(BYOK) 등 고급 제어 기능을 갖춘 Organization 전체 connector 관리를 제공합니다.

<div id="key-capabilities">
  ## 주요 기능
</div>

* **중앙 집중식 관리**: 관리자가 서비스를 한 번만 설정하면 builders가 해당 workspace의 모든 앱에서 사용할 수 있습니다.
* **가시성 및 audit**: 어떤 앱과 멤버가 어떤 서비스를 사용하는지 확인할 수 있습니다.
* **앱별 동의 및 해제**: 코드를 변경하지 않고도 접근 권한을 해제하거나 갱신할 수 있습니다.

**Enterprise 전용:**

* **역할 기반 access controls**: API keys에 최소 권한 원칙에 따라 범위를 지정한 permissions와 access controls를 적용합니다.
* **자체 OAuth 사용**: 사용자 지정 scopes를 적용한 조직 소유의 OAuth 클라이언트를 사용합니다.
* **자체 OpenAI 키 사용**: Replit의 기본 키 대신 직접 보유한 OpenAI API 키를 사용합니다.

<div id="how-it-works">
  ## 작동 방식
</div>

<Steps>
  <Step title="관리자가 서비스를 설정합니다">
    관리자가 자격 증명을 사용해 서비스를 한 번만 설정합니다.
  </Step>

  <Step title="관리자가 액세스를 승인합니다">
    관리자는 어떤 그룹이 connector를 사용할 수 있는지 승인하거나(Enterprise), 협업 workspace에서 사용할 수 있도록 제공합니다(Core/Pro).
  </Step>

  <Step title="Builder가 connector를 사용합니다">
    멤버는 workspace 또는 조직 내 앱에서 Agent에게 요청해 해당 서비스로 앱을 빌드합니다.
  </Step>

  <Step title="관리자가 사용량을 모니터링합니다">
    관리자는 어떤 멤버와 앱이 어떤 서비스를 사용하는지 모니터링할 수 있습니다.
  </Step>
</Steps>

<div id="security-and-governance">
  ## 보안 및 거버넌스
</div>

* 자격 증명과 token은 개별 앱에 저장되지 않고 플랫폼에서 관리됩니다.
* 코드 변경 없이 중앙에서 해제하고 교체할 수 있습니다.
* Enterprise: 최소 권한 원칙에 따른 scope 기반 접근과 선택적 사용자 지정 OAuth 구성을 제공합니다.

<div id="setup-and-management">
  ## 설정 및 관리
</div>

<div id="enable-new-connectors">
  ### 새 connector 활성화
</div>

<Steps>
  <Step title="Integrations로 이동">
    협업 workspace(Core/Pro) 또는 조직 홈(Enterprise)에서 **Integrations** 페이지를 엽니다.
  </Step>

  <Step title="새 connector 활성화">
    오른쪽 상단의 **Enable new connector**를 선택합니다.
  </Step>

  <Step title="서비스 선택">
    활성화할 서비스를 선택합니다(예: Notion, GitHub, Google, Outlook, Dropbox, Salesforce).
  </Step>

  <Step title="connector 구성">
    기본 구성 그대로 connector를 활성화합니다. **Enterprise**에서만 사용자 지정 OAuth connector를 만들 수 있습니다(예: Drive scope `.../auth/drive.file`, `.../auth/drive.install`).
  </Step>

  <Step title="제출">
    **Submit**을 선택합니다.
  </Step>
</Steps>

<div id="configure-access-enterprise">
  ### 액세스 구성(Enterprise)
</div>

1. connector를 활성화한 후 **Manage**를 선택합니다.
2. 필요에 따라 특정 groups에 액세스 권한을 부여합니다.

<div id="modify-connectors">
  ### connector 수정
</div>

* connector를 활성화한 후 **Manage**를 선택합니다.
* connector를 삭제하면 해당 workspace(Core/Pro) 또는 조직(Enterprise)에 속한 모든 builder에 대해 제거됩니다.
* Enterprise에서는 사용자 지정 OAuth connector의 scope를 편집할 수 있습니다.

<div id="bring-your-own-openai-key-enterprise">
  ### 자체 OpenAI 키 사용(Enterprise)
</div>

Enterprise 고객은 Connectors를 사용해 Replit의 기본 AI 인프라 대신 자체 OpenAI API key를 사용할 수 있습니다. 이를 통해 기존 OpenAI 계약을 그대로 활용하고, 자체 Account에서 AI 사용량을 관리할 수 있습니다.
