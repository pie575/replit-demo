CLUI（Command Line User Interface）は、メニューをナビゲートせずにさまざまなアクションをすばやく実行できるReplitのインタラクティブなコマンドバーです。コマンドラインの効率性とグラフィカルインターフェースを組み合わせています。

## 機能

CLUIはReplit内の3つの異なるコンテキストで強力なコマンド駆動のインタラクションを提供します：

* **Settings管理**：設定を管理し、警告を確認し、削除されたReplitアプリを復元します
* **クイックナビゲーション**：Replitアプリ間を移動し、ショートカットで共通機能にアクセスします
* **Workspace操作**：開発環境内でファイルの検索、コードの検索、ツールへのアクセスが可能です

## 使い方

### アカウントCLUI

アカウントCLUIは、設定、チーム、削除されたReplitアプリの管理に役立ちます。

**アクセス方法**：[CLUIページ](https://replit.com/~/cli)に移動し、入力ボックスにコマンドを入力して検索し、Enterを押して実行します。

<Accordion title="アカウントコマンド">
  `account`と入力して設定を管理します：

  * **view-warns**：受けた警告を表示します
  * **change-username**：ユーザー名を変更します（一度のみ可能）
</Accordion>

<Accordion title="ゴミ箱コマンド">
  `trash`と入力して削除されたReplitアプリを管理します：

  * **restore \<title>**：タイトルで削除されたReplitアプリを復元します（同じ名前が複数ある場合は最近削除されたものを復元します）
  * **view**：最近削除されたReplitアプリを表示します
</Accordion>

<Accordion title="チームコマンド">
  `team`と入力してチームを管理します：

  * **view**：所属するチームのメンバーをユーザー名で表示します
  * **fork-repl-to-project**：既存のReplitアプリをフォークしてチームプロジェクトを作成します
</Accordion>

<Accordion title="クリアコマンド">
  `clear`と入力して実行したすべての過去のコマンドの画面をクリアします
</Accordion>

### ショートカットCLUI

ショートカットCLUIは、任意のページからReplitの共通機能へのすばやいアクセスを提供します。

<Frame>
  <img src="/assets/mirror/shortcuts-clui-768d49b44785.png" alt="ショートカットCLUI" width="689" height="291" data-path="images/getting-started/shortcuts-clui.png" />
</Frame>

**アクセス方法**：**CMD/CTRL + K**を押すか、ほとんどのReplitページの上部ナビゲーションバーの検索アイコンをクリックします。

<Accordion title="利用可能なコマンド">
  * **Search**：ReplitアプリやTemplates、Code、Peopleなどを検索します
  * **New**：新しいReplitアプリを作成します
  * **My Replit Apps**：Replitアプリを閲覧してナビゲートします
  * **My Code**：すべてのReplitアプリのコードを検索します
</Accordion>

### ワークスペースCLUI

ワークスペースCLUIは、Replitアプリで作業中に操作の実行、ツールへのアクセス、ファイルの検索、コードの検索に役立ちます。

<Frame>
  <img src="/assets/mirror/ws-clui-81764b3d111b.png" alt="ワークスペースCLUI" width="429" height="202" data-path="images/getting-started/ws-clui.png" />
</Frame>

**アクセス方法**：Workspace内で**CMD/CTRL + K**を押すか、左上角の検索アイコンをクリックします。

<Accordion title="一般的な操作">
  * **ファイルを見つける**：プロジェクト内のファイルをすばやく見つけます
  * **コードを検索する**：ファイル全体で特定のコードスニペットを見つけます
  * **ツールにアクセスする**：Workspaceで利用可能な任意のツールやパネルを開きます
  * **コマンドを実行する**：Workspace固有のコマンドを実行します
</Accordion>
