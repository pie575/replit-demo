Project Analytics 可以展示用户如何找到并使用你已发布的 Web 应用。打开 **Growth** 面板，即可分析访客趋势、流量来源和自定义事件。

Replit 会为受支持的已发布应用收集标准流量指标。在付费计划中，Agent 可以添加自定义事件，并回答与分析数据相关的问题。

<div id="antes-de-comear">
  ## 开始之前
</div>

使用 Project Analytics 需满足以下条件：

* **已发布的网站。** Analytics 仅支持网站类型的 [artifact](/zh/pt/features/projects-and-artifacts/artifacts)，不会收集移动应用或其他类型 artifact 的事件。
* **受支持的 deployment。** Project Analytics 支持 [Autoscale](/zh/pt/features/publishing/deployment-types#autoscale)、[Reserved VM](/zh/pt/features/publishing/deployment-types#reserved-vm) 和 [Static](/zh/pt/features/publishing/deployment-types#static) 三种类型的 deployment。
* **付费计划 (用于高级分析) 。** 自定义事件和使用 Agent 进行分析查询仅在付费计划中提供。
* **在下次发布时启用 Analytics。** 只有在你开启 **Enable analytics** 并发布或重新发布应用后，Replit 才会开始收集事件。

<div id="abra-o-project-analytics">
  ## 打开 Project Analytics
</div>

1. 在 Project Editor 中打开你的项目。
2. 选择 **Tools**。
3. 在 **Replit Cloud** 下,选择 **Growth**。

<Note>
  在你发布应用之前,**Growth** 面板会一直处于锁定状态,并提示你 **Go to Publishing**。
</Note>

只有当你发布的应用产生流量后,分析数据才会出现。新应用在有人访问之前,图表可能是空的。

<div id="analise-as-mtricas-padro">
  ## 分析默认指标
</div>

默认指标使用 IP 流量数据展示以下内容：

* **Visitors**：所选时间段内独立访客的大致数量。
* **Visitors over time (hour)** 或 **Visitors over time (day)**：访客活动在所选时间段内的变化趋势。
* **Top Pages**：流量最高的页面。
* **Top Referrers**：为你的应用带来流量的网站。
* **Top Countries**：访客所在的大致国家/地区。
* **Top Browsers**：访客使用的浏览器。
* **Top Devices**：访客使用的设备类型。

使用时间范围菜单可查看六小时至 30 天的各类时间段。访客总数会将每个时间段与前一个等长时间段进行对比。

如果你的应用使用了 [Replit Auth](/zh/pt/features/auth-and-identity/authentication)，面板还会显示所选时间段内的 **Unique Logged in Users**。

<Note>
  访客数量为近似值。这些数据来自网络和浏览器信息，同一个人在不同设备或不同日历月份中可能会被统计为多个访客。
</Note>

<div id="adicione-eventos-personalizados-com-o-agent">
  ## 使用 Agent 添加自定义事件
</div>

自定义事件用于衡量对你的应用而言重要的用户行为，例如完成注册、选择套餐、提交表单和完成购买。

<Steps>
  <Step title="使用 Agent 添加指标">
    打开 **Growth**。在 **Advanced analytics** 中，选择 **Add metrics with
    Agent**。告诉 Agent 你想衡量哪些行为，Agent 会在应用的相关位置添加
    事件跟踪。
  </Step>

  <Step title="启用分析并发布">
    打开 **Publishing**，开始一次新的发布或重新发布。在
    **Suggested add-ons** 中，开启 **Enable analytics**，然后发布
    应用。从该版本开始，Replit 会收集页面浏览量和自定义事件。
  </Step>
</Steps>

<Tip>
  你也可以直接在 Chat 中让 Agent 配置分析。当应用或衡量目标发生变化时，
  随时可以让 Agent 添加或更新事件。
</Tip>

Replit 会自动将分析跟踪器添加到已发布的应用中，你无需添加跟踪脚本、站点 ID 或分析相关的环境变量。

<Warning>
  请勿在自定义事件的名称或属性中包含密钥、个人数据或访客自由输入的内容。
</Warning>

<div id="pergunte-ao-agent-sobre-suas-anlises">
  ## 向 Agent 询问你的分析数据
</div>

当你的应用开始收集数据后，可以使用 **Advanced analytics** 中的快捷选项：

* **Summarize my analytics**：Agent 会汇总你的 项目 在过去七天的分析数据。
* **Suggest project improvements**：Agent 会分析你的指标，并针对 项目 提出改进建议。

你也可以向 Agent 提出具体问题。

<AiPrompt>
  对比过去七天的访客数和完成注册数。
  展示每日趋势，并找出转化率最高的页面。
</AiPrompt>

Agent 可以分析页面浏览量、流量来源、自定义事件、事件属性和转化漏斗，它会基于你 项目 的分析数据返回聚合结果。
