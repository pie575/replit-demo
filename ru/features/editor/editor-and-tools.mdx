Project Editor включает управление раскладкой и встроенные инструменты, на которых строится вся работа над приложением.
Каждая из этих возможностей Project Editor отвечает за свой аспект процесса разработки, позволяя вам
сосредоточиться на创 создании, а не на настройке.

<div id="customizable-project-editor-layout">
  ## Настраиваемая раскладка Project Editor
</div>

Инструменты управления раскладкой Project Editor позволяют настроить компоненты среды разработки.
Она состоит из следующих типов элементов интерфейса:

| Элемент     | Описание                                                                                   | Возможности                                                                                                                                                                  | Сценарии использования                                                                                                        |
| ----------- | ------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| **Окна**    | Вкладки браузера, содержащие одну или несколько панелей                                    | <ul><li>Можно распределять по нескольким экранам</li></ul>                                                                                                                   | <ul><li>Размещение Project Editor на нескольких экранах</li><li> Одновременная работа над разными projects</li></ul>          |
| **Панели**  | Части окна, содержащие одну или несколько вкладок                                          | <ul><li>Поддерживают горизонтальное и вертикальное разделение</li><li>Можно изменять в размерах и переставлять</li><li>Можно сделать плавающей панелью внутри окна</li></ul> | <ul><li>Просмотр кода и предпросмотра бок о бок</li><li>Создание собственных раскладок под разные задачи разработки</li></ul> |
| **Вкладки** | Содержат ровно один инструмент Project Editor, например редактор файлов, Preview или Agent | <ul><li>Можно перемещать между панелями и менять их порядок внутри панели</li><li>Позволяют переключаться между файлами и инструментами одним щелчком</li></ul>              | <ul><li>Открытие нужных инструментов или файлов в нужный момент</li></ul>                                                     |

<div id="file-tree">
  ## Дерево файлов
</div>

В дереве файлов отображаются все файлы и каталоги вашего Replit App.

<Accordion title="Как открыть дерево файлов">
  Нажмите значок папки <img class="icon-svg" src="/assets/mirror/files-icon-f66bf1b04572.svg" alt="значок папки со стрелками" width="16" height="16" data-path="images/icons/files-icon.svg" /> слева, чтобы показать
  или скрыть дерево файлов.
</Accordion>

В дереве файлов доступны следующие действия:

* Выберите папку, чтобы отобразить её содержимое
* Выберите файл или перетащите его на панель, чтобы открыть в редакторе файлов
* Выполняйте операции с файлами: дублирование, переименование, перемещение, скачивание или удаление

<div id="run-button">
  ## Кнопка Run
</div>

Кнопка **Run** запускает выбранный рабочий процесс Replit App.

<Accordion title="Как найти кнопку запуска">
  Кнопка **Run** находится в верхней части экрана Project Editor. Нажмите её, чтобы запустить рабочий процесс.

  Пока Replit App работает, надпись на кнопке меняется на **Stop**. Нажмите её, чтобы остановить приложение.
</Accordion>

О том, как выбирать, просматривать и настраивать рабочие процессы, читайте в разделе [Рабочие процессы](/ru/features/workspace-tools/workflows/).

<div id="options-menu">
  ## Меню параметров
</div>

Меню параметров позволяет выполнять следующие действия с раскладкой:

* **Управление окнами**: открыть Project Editor для Replit App в новом окне
* **Управление панелями**: добавить панели, переместить панель, развернуть панель и переключаться между плавающим и фиксированным положением
* **Управление вкладками**: открыть или выбрать другие вкладки, переместить вкладку в другую панель и закрыть вкладку

<Accordion title="Как открыть меню параметров">
  Нажмите на <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="vertical dots icon" height="16" width="16" data-path="images/icons/vertical-dots.svg" /> три вертикальные точки
  в правом верхнем углу активной вкладки, чтобы открыть меню параметров.
</Accordion>

На следующем снимке экрана показано всплывающее меню параметров в левой панели:

<div id="resources-panel">
  ## Панель ресурсов
</div>

Панель ресурсов отображает вычислительные ресурсы вашей среды разработки и их использование: оперативную память, процессор и хранилище.
Эта информация поможет оценить и оптимизировать требования вашего Replit App к публикации.

<Accordion title="Как открыть панель ресурсов">
  1. Нажмите значок ресурсов <img class="icon-svg" src="/assets/mirror/resources-237893692826.svg" alt="значок стопки компьютеров" width="16" height="16" data-path="images/icons/resources.svg" /> рядом с названием приложения, чтобы открыть или закрыть панель.
  2. Наведите курсор на строки **Compute** или **Storage**, чтобы увидеть подробности.
</Accordion>

На следующем снимке экрана показана панель ресурсов:
