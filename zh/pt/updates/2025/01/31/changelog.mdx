<div id="atualizaes-da-plataforma">
  ## 平台更新
</div>

<div id="repl-app">
  ### Repl -&gt; App
</div>

Repl 现在改称为“App”。一切从简，才是关键。

<div id="notificaes-aprimoradas">
  ### 通知优化
</div>

我们改进了付款失败和账单相关的通知。现在，App 被暂停前会有 24 小时的宽限期，整个过程也更加透明。

此次更新有助于避免你在使用 Replit 时遇到服务中断。

<div id="melhorias-no-object-storage">
  ### Object Storage 改进
</div>

Object Storage 面板新增了搜索和分页功能，让你更轻松地浏览文件。

<div id="diffs-mais-limpos">
  ### 更清晰的差异对比
</div>

Assistant 修改文件时现在会打开临时的差异面板，让你更方便地查看改动，也不会让工作区堆满没完没了的标签页。

应用更改后，这些面板会自动关闭。

<div id="agent-mais-rpido-na-sia">
  ### 亚洲地区 Agent 响应更快
</div>

我们针对亚洲地区的 Agent 创作者优化了云服务。你会明显感受到响应更迅速、使用体验更流畅。

<div id="login-com-x">
  ### 使用 X 登录
</div>

现在，你可以通过 X 注册并登录 Replit。欢迎来到未来。

<div id="importao-rpida-de-repositrio">
  ### 快速导入仓库
</div>

想把你喜欢的 GitHub 仓库导入 Replit 吗？

现在可以一键搞定。

只需在浏览器中输入 `replit.com/你的仓库URL`，例如：

`https://replit.com/github.com/mattppal/magnetic-feel`
