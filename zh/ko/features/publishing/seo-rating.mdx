在 Replit 上发布 Web 应用后，系统会自动对实际 URL 运行搜索引擎优化 (SEO) 审核，并在 Publishing 工具中显示 SEO 评分。如果评分仍有提升空间，只需点击一下，即可将具体问题交给 Agent，并在几秒内解决。

对大多数构建者来说，整个工作流如下：发布应用、查看评分，然后让 Agent“优化 SEO”。本页面将说明其中的运作方式，以及如何充分利用这项功能。

<div id="seo">
  ## 什么是 SEO，为什么它很重要
</div>

搜索引擎优化 (SEO) 是指通过构建网站，使 Google 等搜索引擎能够发现、理解并为其排名。良好的 SEO 能让用户在搜索你提供的内容时，无需投放广告也能找到你的应用。

决定 SEO 成效的主要因素包括：清晰的页面标题和描述、语义化 HTML、快速加载、适配移动设备的布局、图片的描述性替代文本，以及可供爬虫抓取的网站结构。搜索引擎会青睐人和机器都易于阅读的网站。

如果你要上线着陆页、营销网站、博客、目录，或其他依赖搜索曝光的内容，SEO 是最值得尽早投入的事项之一。

<div id="replit-seo">
  ## Replit 默认如何优化 SEO
</div>

Replit 会为您处理许多 SEO 基础工作，让您能够专注于内容和产品。

* **快速、全球分布式托管**：Replit 部署通过针对速度优化的基础设施提供应用，您还可以通过[项目地理位置](/zh/ko/features/publishing/project-geography)选择应用的运行位置。
* **内置 HTTPS**：所有已发布的应用都会获得由 Replit 管理的 TLS 证书，这是搜索引擎的基本排名信号。
* **自定义域名**：连接您自己的域名，建立信任并提升品牌权威。请参阅[自定义域名](/zh/ko/features/publishing/custom-domains)。
* **适用于内容网站的静态部署**：对于营销页面、博客和文档，[静态部署](/zh/ko/features/publishing/deployment-types#static)可提供便于搜索引擎抓取的预渲染 HTML。
* **以 SEO 为导向编写代码的 Agent**：Agent 在构建页面时，默认会生成语义化 HTML、无障碍标记和元标签。这些正是 SEO 工具会检查的元素。
* **SEO 评分**：通过发布后自动运行的审核，您可以随时了解当前状况，并可一键将发现的问题交给 Agent 修复。

<div id="section">
  ### 查看位置
</div>

在已发布的应用中打开 **Publishing** 工具。SEO 评分会在部署概览中与其他构建详情一同显示。将鼠标悬停在评分上，即可查看 Lighthouse 针对各页面列出的具体改进项。

<Note>
  如果看不到 SEO 评分，应用可能处于私密状态，或者最近未发布。评分仅显示在已发布的公开 Web 应用中。
</Note>

<div id="section-2">
  ### 如何解读评分
</div>

Replit 会根据 Lighthouse 审核结果显示以下三个评分之一。

| 评分         | 含义                           |
| :--------- | :--------------------------- |
| Healthy    | 应用遵循 SEO 最佳实践。完成重大更改后，请继续关注。 |
| Needs Work | 多个问题导致搜索引擎难以正确理解应用。          |
| Weak       | 缺少重要的 SEO 基础要素。通常可在几分钟内修复。   |

如果应用包含多个页面，徽章会显示 Replit 抓取的所有 URL 中**最低**的评分，因此不会被平均值掩盖，问题最严重的页面会优先显示。

<div id="section-3">
  ### 评分计算时间
</div>

每次成功发布后，系统都会自动进行审核。部署上线后，评分通常会在 1~2 分钟内显示；结果一出来，Publishing 工具就会刷新徽章。

<div id="section-4">
  ### 支持的部署类型
</div>

仅针对搜索引擎可抓取 URL 的公开 Web 部署计算 SEO 评分。

* [自动扩缩容部署](/zh/ko/features/publishing/deployment-types#autoscale)
* [保留 VM 部署](/zh/ko/features/publishing/deployment-types#reserved-vm)
* [静态部署](/zh/ko/features/publishing/deployment-types#static)

由于定时部署和私有部署不处理公开 Web 流量，因此不会生成 SEO 评分。

<div id="agent-seo">
  ## 使用 Agent 优化 SEO
</div>

评分旁会显示 **Optimize SEO with Agent** 按钮。点击此按钮会在 Growth 面板中打开 [SEO Agent](/zh/ko/features/publishing/seo-agent)，你可以在此进行技术 SEO 审核、查看发现的问题，并一键应用修复。

<Tip>
  你也可以不通过按钮直接开始。打开 Agent 并说 **&quot;帮我优化 SEO&quot;**，Agent 就会获取最新结果，并开始逐一解决问题。
</Tip>

Agent 完成更改后，请重新 Publish 应用。系统会根据新构建重新计算 SEO 评分，并自动更新徽章。

Agent 常见的修复包括：

* 添加或重写缺失或过于笼统的 `<title>` 标签，为每个页面提供独特且描述性的标题
* 为所有页面添加元描述
* 为图片添加描述性的 `alt` 文本
* 为 `<html>` 元素设置 `lang` 属性
* 确保链接包含可识别的文本 (避免使用“点击这里”或空锚点)
* 添加 `robots.txt` 和 `sitemap.xml`
* 添加用于移动端渲染的视口元标签
* 改善未通过无障碍检查的文本颜色对比度
* 添加 Open Graph 和 Twitter 卡片元标签，让应用链接在社交平台上获得良好展示

<div id="replit-seo-2">
  ## 在 Replit 中构建 SEO 优化网站的最佳实践
</div>

无论是让 Agent 完成这些工作，还是自行操作，想让 Replit 应用发挥最佳效果，都应遵循以下做法：

* **为每个页面设置唯一的标题和元描述。** 标题应控制在 60 个字符以内，描述建议控制在 150~160 个字符。
* **使用语义化 HTML。** 使用 `<main>`、`<header>`、`<nav>` 和 `<footer>` 组织页面布局。每个页面只使用一次 `<h1>`，并按顺序设置标题层级。
* **为所有图片添加替代文本。** 描述图片展示的内容，而非图片本身。
* **创建 `sitemap.xml` 和 `robots.txt`。** 请 Agent 创建这两个文件，让搜索引擎了解应抓取哪些内容。
* **添加 Open Graph 和 Twitter 卡片标签。** 这样可以控制应用在社交媒体上分享时的显示效果。
* **使用自定义域名。** 品牌域名能提升访客和搜索引擎对网站的信任度。请参阅 [自定义域名](/zh/ko/features/publishing/custom-domains)。
* **选择合适的部署类型。** 对于内容丰富的网站，[静态部署](/zh/ko/features/publishing/deployment-types#static) 可提供预渲染的 HTML，供搜索引擎立即解析。
* **添加结构化数据。** JSON-LD 标记可帮助搜索引擎为产品、文章、FAQ 和活动显示富媒体结果。
* **保持应用快速运行。** 优化图片，避免使用阻塞渲染的脚本，并利用 Replit 托管服务保持较低的响应时间。

以下是一种可一次性应用大多数这些做法的简单方法：
