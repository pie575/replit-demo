<div id="what-is-general-agent">
  ## 什么是 General Agent？
</div>

General Agent 是使用 Replit Agent 最灵活的方式。你无需预先选择 artifact 类型，也不必一开始就确定要构建什么。直接开始对话即可——创建 CSV、生成 PDF、调研某个主题，或者在准备好时构建一个完整的应用。

核心概念：

* **无需预选**：不必事先选定 artifact 类型即可开始工作
* **任意输出**：生成文件 (CSV、PDF、文档) 、开展调研或构建应用
* **Connectors**：读写 BigQuery、Linear、Slack、Notion、Amplitude、Segment、Hex 等外部服务
* **渐进式展开**：从轻量的 Chat 开始，自然过渡到完整的应用构建

<div id="how-to-access-general-agent">
  ## 如何使用 General Agent
</div>

你可以通过以下几种方式使用 General Agent：

1. 在 Replit 主页上，**编写 prompt 前先选择「General」**
2. **打开任意已有的 project**，直接与 Agent 对话
3. **从 GitHub [导入](/zh/build/import-from-providers)** —— 从 GitHub 导入的 project 会自动使用 General Agent

<div id="how-to-use-general-agent">
  ## 如何使用 General Agent
</div>

<div id="just-start-chatting">
  ### 直接开始对话
</div>

打开一个 project，直接开始交流。你不必一开始就明确要构建什么——Agent 会在你当前的 project 上下文中工作，无论你提出什么需求它都能应对。

**示例 prompt：**

* “总结这份文档的要点”
* “生成一份按营收排名前 100 的公司 CSV 列表”
* “我的前五个 Linear 工单是什么？”
* “搭建一个使用 TypeScript 的 Vue.js 项目”

Agent 可以处理会话期间创建的文件、生成单文件输出，并在推理过程中执行代码——这一切都发生在你决定构建任何东西之前。

<div id="connecting-external-services">
  ### 连接外部服务
</div>

连接你的工具，让 Agent 直接读写数据：

1. 前往项目设置中的 **Connectors**
2. 连接你的服务 (BigQuery、Linear、Slack、Notion、Amplitude、Segment、Hex 等)
3. 让 Agent 通过它们读取或写入数据

**使用 connector 的 prompt 示例：**

* “Linear 中有哪些未处理的工单？”
* “总结今天 #engineering 频道的 Slack 消息”
* “从 BigQuery 拉取上个月的销售数据”
* “显示我日历中即将到来的日程”
* “在 Linear 中为这个新手引导缺陷创建一个工单”
* “把摘要发送到 Slack 的 #engineering 频道”

<div id="from-chat-to-full-app">
  ### 从对话到完整应用
</div>

当你准备好开始构建时，直接说一声即可。Agent 会从轻量对话无缝转入应用构建——无需从头再来，也不用切换上下文。

* “把这个做成一个 web app”
* “基于这些数据构建一个应用”
* “为这些指标创建一个仪表板”
* “搭建一个 Rust CLI 工具”

你可以先随意聊聊——研究一个主题、生成一份报告、探索一些数据——等时机成熟，再升级为完整的应用构建。

<div id="what-you-can-build">
  ## 你可以构建什么
</div>

* **知识工作**：无需构建应用，即可完成研究、总结和分析
* **单文件输出**：CSV、PDF、文档、数据导出和格式化报告
* **数据应用**：查询已连接的服务，并在仪表板中可视化呈现结果
* **任意框架或语言**：Angular、Vue、Svelte、Rust、Go、C#、Python tkinter、Godot 游戏、CLI 工具等
* **full-stack 应用**：准备好之后，直接基于 Chat 上下文构建一个完整的应用

<div id="what-to-expect">
  ## 预期效果
</div>

General Agent 提供更强的能力和灵活性，但也会带来一定的不确定性：

* **一次成型**：有时 Agent 能一次性完成全部配置
* **迭代协作**：复杂的配置可能需要多轮打磨
* **技术限制**：某些技术在 Nix 环境中可能无法获得完整支持

<Note>
  与使用预配置环境的标准 Agent 不同，General Agent 会根据你的请求自行搭建环境并设置运行命令。当你准备好部署时，可能需要主动让它配置 Publishing。
</Note>

<div id="frequently-asked-questions">
  ## 常见问题
</div>

<Accordion title="Agent 能看到我的其他 project 吗？">
  不能。每个 Chat 都局限在单个 project 内，Project A 和 Project B 之间无法互通。
</Accordion>

<Accordion title="为什么它还无法访问我的外部工具？">
  你需要先通过 Connectors 连接相应服务。连接之后，Agent 才能读写这些服务；默认情况下它没有访问权限。
</Accordion>

<Accordion title="有哪些 connector 可用？">
  目前支持：BigQuery、Linear、Slack、Notion、Amplitude、Segment、Hex 等。我们还会定期新增更多 connector。
</Accordion>

<Accordion title="使用 General Agent 需要 connector 吗？">
  不需要，Connectors 是可选的。即使不建立任何外部连接，你也可以使用 General Agent 完成知识工作、生成文件和构建应用。
</Accordion>
