export const InvoiceThresholdMax = '$250';

export const InvoiceThresholdStart = '$50';

Replit 的计费系统设计得简单且可预测。订阅 Replit 套餐后，您将获得订阅费用中包含的每月积分。

<CardGroup cols={3}>
  <Card title="Starter 套餐" icon="gift">
    有限的每日 Agent 积分和每月云积分
  </Card>

  <Card title="Core 套餐" icon="user">
    每月或每年积分，最多可邀请 5 位协作者
  </Card>

  <Card title="Pro 套餐" icon="users">
    分级积分、最多 15 位构建者、Turbo 模式，不按席位收费
  </Card>
</CardGroup>

这意味着，每月积分限额内的使用量已包含在订阅中，无需额外付费。只有超出每月积分限额时，才会对额外使用量收费。

这些积分涵盖您在 Replit 平台上的使用量，包括 Agent 等 AI 功能、发布和数据库操作等。订阅积分会在每月重置，为您提供新的限额，用于构建和发布项目。

除积分系统外，Replit 还提供全面的计费工具，帮助您监控支出情况、设置每月预算限额，以及通过使用限额控制支出。您可以设置限额和预算，以避免意外收费，并在需要时留出时间提高预算。

<div id="section">
  ## 开始使用
</div>

借助以下各节介绍的工具，访问 Replit 的账单功能，控制支出并优化开发工作流程。

<div id="section-2">
  ### 设置中的账单
</div>

在一个位置查看套餐详情、账单信息、使用限额和预算设置。

<Accordion title="如何访问账单">
  1. 选择右上角的个人资料图标，打开下拉菜单。
  2. 选择**设置**。
  3. 在**账户**下选择**账单**，查看当前套餐、本月使用量、通知设置和预算限额。
</Accordion>

<div id="section-3">
  ### 用量仪表板
</div>

按服务类别查看当前计费周期内的详细资源用量和费用。使用此仪表板了解积分的使用情况，并发现优化机会。

<Accordion title="访问用量仪表板">
  打开**设置**，然后在**账户**下选择**账户用量**，即可查看当前计费周期内的详细资源用量和费用。
</Accordion>

<div id="section-4">
  ### 发票
</div>

查看订阅费用和按用量计费的历史用量及账单，跟踪开发成本的变化。

<Accordion title="如何访问发票">
  打开**设置**，然后在**账户**下选择**账单**或**账户用量**。接着，选择**查看历史账单** (或类似选项) ，打开 Replit 第三方服务提供商的账单门户。
</Accordion>

<div id="section-5">
  ### 发票阈值
</div>

对于 **Core** 和 **Pro** 订阅，用量费用会累积至超过发票阈值后再开具发票，而非针对每笔小额费用单独开具发票。这样可以减少发票开具频率，并降低因付款导致服务中断的可能性。

* 新账户的阈值从 **{InvoiceThresholdStart}** 起。
* 阈值可能会根据账户状态 (例如持续按时付款) 随时间提高，最高可达 **{InvoiceThresholdMax}**。

即使未达到阈值，系统仍会在常规月度计费周期结束时收费。要查看历史发票和即将开具的发票，请参阅上方的[发票](#청구서)。

<div id="section-6">
  ## 主要功能
</div>

* **包含的积分**：Starter 套餐用户可获得用于 Agent 的每日积分 (受月度限额限制) 以及每月云积分。Core 和 Pro 均包含每月积分。Pro 套餐中，未使用的积分可在 {ProCreditRolloverPeriod} 内结转。Core 最多可邀请 5 名协作者；Pro 则支持最多 15 名构建者，提供共享积分且不按席位收费。
* **可购买积分包**：Core 和 Pro 套餐可购买额外积分，批量购买可享折扣。有关详细信息，请参阅[管理支出](/zh/ko/billing/managing-spend)。
* **包含的 AI 功能**：可在积分限额内使用 Agent
* **实时使用量跟踪**：在 **设置** → **账户** → **账单** 和 **账户用量** 中查看当前套餐和使用量
* **智能限额和预算**：设置自定义使用限额和预算，以管理费用并避免意外收费。有关详细信息，请参阅[管理支出](/zh/ko/billing/managing-spend)。
* **详细使用量洞察**：在 **用量仪表板** 中跟踪当前计费周期内的资源消耗和费用
* **完整发票历史记录**：在 **用量仪表板** 中，通过关联的发票门户查看和下载当前及历史费用

<div id="section-7">
  ## 使用场景
</div>

以下示例说明如何使用 Replit 的账单功能，在构建和扩展项目时控制开发成本。

<div id="section-8">
  ### 应用扩展时保护预算
</div>

自动扩缩容部署出现突发增长时，可使用以下功能控制成本：

* 创建使用限额，将支出限制在自定义阈值内
* 设置预算限额，达到限额时停止应用
* 达到月度限额后，增加预算并重启应用，以恢复可用性

<div id="section-9">
  ### 跟踪并优化开发成本
</div>

利用**使用量**和**发票**页面中的数据，为开发支出做出明智决策：

* 通过可导出的发票简化费用报表
* 下载或查看明细报告，用于会计核算和预算规划
* 查看不同服务的使用趋势，发现成本优化机会
