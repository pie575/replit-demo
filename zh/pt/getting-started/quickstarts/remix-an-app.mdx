想换一种方式在 Replit 上开始创作？**Remix** 可让您以社区创建的现有应用为基础开始创作。它比从零开始构建更快，也是通过可运行的代码学习的绝佳方式。

</Tip>

  ## 创建你的 Remix
</div>

⏰ *预计用时：5 分钟*

按照本指南的步骤，为交互式数字钢琴应用创建一个 Remix：

  </Step>

  <Step title="填写应用详情">

<div id="aprimore-seu-remix">
  ## 完善你的 Remix
</div>

现在你已经有了一个可运行的应用，可以使用 Agent 对它进行修改和扩展。以下部分提供了一些完善 Remix 的实用示例。

<div id="adicione-um-recurso-usando-o-agent">
  ### 使用 Agent 添加功能
</div>

使用 Agent 为您的 Remix 添加复杂功能：

<Steps>
  <Step title="创建 prompt">
    前往 **Agent** 标签页。

    在文本区域中输入以下 prompt：

    <AiPrompt>
      添加一个教程模式，教用户弹奏简单的歌曲。教程模式启用后，高亮显示接下来需要弹奏的琴键，等待您按下正确的琴键后再继续，并在顶部显示歌曲名称。添加一个用于启动教程的按钮，并预加载至少两首简单歌曲，例如“Mary Had a Little Lamb”或“Twinkle Twinkle Little Star”。
    </AiPrompt>

    发送 prompt 后，Agent 可能会暂停并要求您提供更多说明或确认。请在文本区域中回复。
  </Step>

  <Step title="测试功能">
    前往 **预览** 标签页，查看 Agent 对钢琴做出的更新。

    尝试启动教程模式，并按照高亮显示的琴键进行弹奏。

    <Frame>
      <video autoPlay muted loop playsInline src="/assets/mirror/quickstart-remix-piano-play-3be628756ae7.mp4" />
    </Frame>

    由于初始 prompt 未包含视觉设计方面的具体细节，结果可能不会完全符合您的预期。
  </Step>

  <Step title="完善功能">
    如果该功能与您的预期不符，请在 **Agent** 的文本区域中输入后续 prompt，继续对话。
    例如：

    <AiPrompt>
      让高亮显示的琴键通过脉冲动画发光，并添加一个进度指示器，显示我已完成歌曲的多少进度。
    </AiPrompt>

    要撤销这些更改，请在 **Agent** 标签页中开始规划此次更改后立即创建的 checkpoint 中选择 **还原到此处**。

    详细了解 [checkpoint 和回滚](/zh/pt/core-concepts/agent/checkpoints-and-rollbacks)。
  </Step>
</Steps>

<div id="adicione-um-recurso-usando-o-modo-lite">
  ### 使用 Lite 模式添加功能
</div>

按照以下步骤，使用 [Lite 模式](/zh/pt/core-concepts/agent/agent-modes) 快速改进您的 Remix：

<Steps>
  <Step title="创建 prompt">
    切换到 [Lite 模式](/zh/pt/core-concepts/agent/agent-modes)，然后输入以下 prompt：

    <AiPrompt>
      添加录制和播放按钮，用于录制和重放钢琴演奏。
    </AiPrompt>

    发送 prompt 后，Agent 会说明计划进行的更改，并允许您在继续前查看代码变更。
    选择 **查看代码变更**，即可对比当前代码与更新后的代码。
  </Step>

  <Step title="测试功能">
    选择 **应用全部**，然后确认后续提示以继续。

    前往 **预览** 选项卡查看结果。现在，您应该会看到录制和播放按钮，可用于录制和重放您的演奏。

    要撤销这些更改，请使用 **Agent** 选项卡中的还原功能。
  </Step>
</Steps>
