export const YouTubeEmbed = ({videoId, title = "YouTube 동영상", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

  ### Replit Agent 4 소개

<YouTubeEmbed videoId="bAUVQfz_SIY" title="Introducing Replit Agent 4" />

Agent 4가 출시되었습니다. 창작을 위해 만들어진 Agent는 여러분의 AI 창작 파트너로서, 평범한 일상 언어만으로 아이디어를 앱, 디자인, 슬라이드 등으로 만들어 줍니다. 코딩은 필요 없습니다.

Agent 4에서는 다음과 같은 작업이 가능합니다:

* **무엇이든 만들기**: 웹 앱, 모바일 앱, 데이터 대시보드, AI 기반 도구 등을 제작합니다
* **만들기 전에 디자인하기**: 코드로 옮기기 전에 [Design Canvas](/ko/learn/projects-and-artifacts/canvas)에서 목업을 살펴봅니다
* **프로젝트 계획하기**: [Plan mode](/ko/core-concepts/agent/plan-mode)로 코드를 작성하기 전에 빌드 과정을 설계합니다
* **작업을 병렬로 실행하기**: Agent가 여러 task를 동시에 처리해 작업 속도를 높입니다
* **팀원과 협업하기**: 다른 사람을 project에 초대해 함께 만들어 갑니다
* **도구 연결하기**: BigQuery, Linear, Slack, Notion 등의 데이터를 Chat에서 바로 가져옵니다
