使用 Replit Agent 创作专业级动画视频。只需用日常语言描述你想要的视频，Agent 就会生成可导出、可分享的 motion graphics——无需视频剪辑技能，也不必花钱聘请专业团队。

<div id="overview">
  ## 概览
</div>

Replit Animation 让你完全通过与 Agent 对话来创作精致的 motion graphics。它们是用 React 构建的程序化动画——并未使用 Remotion，而是依靠网页动画库与自定义 Agent skills 的组合来生成动画视频。这与 Runway 或 Sora 那类 AI 生成视频不同。你的视频可以包含文字叠加、流畅的转场、AI 生成的图像等内容。

视频会在窗格中自动循环播放，你也可以像构建其他应用一样，通过与 Agent 对话不断迭代。

**所有创作者均可使用**，包括免费方案用户。

<div id="creating-an-animated-video">
  ## 创建动画视频
</div>

在 Replit 首页，你可以通过以下两种方式开始创建动画视频：

<div id="option-1-type-a-prompt">
  ### 方式一：输入 prompt
</div>

在主页上选择 **App** 标签页，输入一段 prompt 描述你想要的视频。Agent 会自动识别与视频相关的 prompt，并选择 Animated Video 技术栈。

prompt 示例：

* “为我的新气泡水品牌制作一个宣传视频”
* “创建一个 30 秒的讲解视频，介绍大语言模型的工作原理”
* “为得克萨斯州奥斯汀市制作一个具有电影质感的宣传视频”

</Frame>

<div id="option-2-select-from-the-dropdown">
  ### 方式 2：从下拉菜单中选择
</div>

1. 在主页上进入 **App** 标签页。
2. 打开应用类型下拉菜单。
3. 选择 **Animation**。
4. 输入你想创建的视频的描述。

<Frame>
  <img src="/assets/mirror/animation-entry-point-b22d4942db44.png" alt="App type dropdown showing Animation selected among options including Web app, Mobile app, Data Visualization, 3D Game, and Automation" width="1200" height="675" data-path="images/replitai/animation-entry-point.png" />
</Frame>

Agent 开始构建后，会生成动画并显示在预览窗格中。视频会自动循环播放，你可以一边观看，一边继续通过 Chat 提出修改。

<div id="iterating-on-your-video">
  ## 迭代优化你的视频
</div>

Agent 生成第一版之后，你可以通过对话不断打磨。以下几种方式效果不错：

* **使用 Chat 输入框中的 Enhance Prompt 按钮**，它专门针对视频 prompt 做过调优。
* **直接要求改进**——看过第一版后，说一句「做得更好一些」或「在各个场景中加入更复杂的动画，更有创意一些」，往往就能得到不错的效果。
* **明确说明**你想修改的地方——例如「让转场更流畅」「把配色改成深蓝配金色」或「在结尾加一段 logo 亮相」。

多提交几个不同的 prompt，你多半会对其中至少一个结果感到满意。

<div id="exporting-your-video">
  ## 导出视频
</div>

视频效果满意后，你可以将其导出为 MP4 文件。

1. 在 Preview 窗格右上角找到 **Export** 按钮。
2. 选择所需的质量设置：
   * **Resolution**：720p 或 1080p
   * **Frame rate**：30fps 或 60fps
3. 选择 **Export**。渲染时间取决于视频的复杂程度，可能需要几分钟。
4. 渲染完成后，MP4 文件会自动下载。

<Frame>
  <img src="/assets/mirror/animation-export-dialog-cf4d777fca06.png" alt="导出视频对话框，显示 Name 字段、设置为 1080p 60fps 的 Quality 下拉菜单以及 Render 按钮" style={{maxWidth: "350px"}} width="662" height="495" data-path="images/replitai/animation-export-dialog.png" />

你也可以选择 **Publish**，分享视频链接。

**导出时间**：较长或较复杂的视频可能需要几分钟才能渲染完成。导出在服务器端进行，因此处理期间你可以继续工作。

<div id="use-cases">
  ## 使用场景
</div>

动画视频适用于多种创意和专业需求：

* **产品发布视频** —— 用精致的宣传片发布新应用、新功能或新产品。
* **品牌与电影感视频** —— 为公司、城市、高校或活动打造视觉effect丰富的视频。
* **讲解视频** —— 用 30 到 60 秒讲清楚某个产品、功能或概念的运作原理。
* **社交媒体内容** —— 为 Twitter/X、LinkedIn、Instagram 或 TikTok 制作让人停下滑动的 motion graphics。
* **落地页视频** —— 为网站添加动画首屏区块或背景视频。
* **融资与投资人动态** —— 为重要里程碑制作专业的公告视频。

<div id="video-specifications">
  ## 视频规格
</div>

| 属性      | 详情                                                    |
| ------- | ----------------------------------------------------- |
| **格式**  | MP4                                                   |
| **分辨率** | 720p 或 1080p                                          |
| **帧率**  | 30fps 或 60fps                                         |
| **宽高比** | 16:9 (默认)                                             |
| **渲染**  | 服务器端渲染；使用动画库 (通常用于网站) 并结合自定义 Agent skills，而非 Remotion |
| **播放**  | 在 Preview 窗格中自动循环播放                                   |

<div id="common-questions">
  ## 常见问题
</div>

* **可以暂停或播放视频吗？** Preview 不提供内置的暂停/播放控件，视频始终以 loop 方式自动播放。如果你希望视频具备暂停/播放 (或场景选择) 功能，可以让 Agent 添加——不过添加这些控件有时会影响设计效果，因此保留默认的 loop 可能更好。
* **有场景选择功能吗？** Preview 中没有内置的场景选择器。如需使用，可以让 Agent 添加场景选择或其他控件；同样需要权衡上述取舍。

<div id="limitations">
  ## 限制
</div>

动画视频是一项新功能，目前存在一些需要注意的限制：

* **仅支持程序化动画**：视频是基于 React 的 motion graphics，而非 AI 生成的视频 (如 Runway 或 Sora) ——不过它可以生成视频素材并在代码中使用。
* **渲染时间**：复杂动画的导出可能需要几分钟，较简单的视频渲染更快。
* **可能需要多次迭代**：虽然许多 prompt 一次就能得到不错的效果，但你可能需要迭代 2–3 个版本才能达到理想效果。建议对初始 prompt 使用 Enhance Prompt 按钮，并在第一个 checkpoint 后给出反馈，这会很有帮助。
