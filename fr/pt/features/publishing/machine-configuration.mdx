title: "Configuration de la machine"
description: "Définissez la puissance et le coût des serveurs qui exécutent votre app publiée : processeur, mémoire et nombre maximal de machines."
---

La configuration de la machine détermine la puissance des serveurs qui exécutent votre app publiée. Replit retient une valeur par défaut adaptée, si bien que la plupart des créateurs n&#39;ont jamais besoin de la modifier. Envisagez une configuration plus puissante si votre app devient lente en cas de forte charge ou si elle traite de gros volumes de données en mémoire.

Pour la modifier, ouvrez l&#39;outil Publishing, sélectionnez **Adjust settings**, puis **Edit** en regard de **Machine configuration**.

<div id="as-configuraes">
  ## Les configurations
</div>

* **CPU** : la quantité de travail simultané que chaque serveur peut traiter. Un nombre de vCPU plus élevé est utile lorsque de nombreuses personnes utilisent votre app en même temps.
* **Memory (RAM)** : la quantité de données que votre app peut conserver en mémoire. Davantage de RAM aide pour les fichiers volumineux, les médias ou les traitements de données lourds.
* **Max machines** : Autoscale uniquement. Le nombre maximal de serveurs que Replit peut ajouter lorsque votre app est très sollicitée. Votre app ne dépasse jamais ce nombre, ce qui plafonne votre coût maximal.

<div id="quanto-custa">
  ## Quel est le coût
</div>

Le panneau affiche deux chiffres au fil de la configuration :

* **Per machine** : le coût horaire d&#39;un serveur selon la configuration choisie.
* **At max traffic** : le coût horaire si votre app est suffisamment sollicitée pour mobiliser toutes les machines jusqu&#39;à votre maximum.

Les coûts sont mesurés en unités de calcul, une unité de calcul cloud fondée sur le processeur et la mémoire que vous choisissez. Pour connaître les tarifs actuels et le mode de facturation de l&#39;utilisation, consultez la [facturation basée sur l&#39;utilisation](/fr/pt/billing/about-usage-based-billing#2-compute-units).

<div id="como-a-cobrana-varia-por-tipo-de-deployment">
  ## Comment la facturation varie selon le type de deployment
</div>

La même configuration est facturée différemment selon votre [type de deployment](/fr/pt/features/publishing/deployment-types) :

* **Autoscale** : vous payez uniquement pendant le traitement des requêtes. Lorsque votre app est inactive, elle se réduit à zéro et son fonctionnement ne coûte rien.
* **Reserved VM** : votre serveur est toujours actif, vous payez donc un coût mensuel fixe pour la configuration choisie.
* **Static** : aucune machine n&#39;exécute votre site, la configuration de machine ne s&#39;applique donc pas.
* **Scheduled** : vous payez la machine pendant chaque exécution planifiée.

<div id="aplique-suas-alteraes">
  ## Appliquez vos modifications
</div>

Republiez votre app après avoir modifié la configuration. Les nouveaux paramètres de machine prennent effet avec le nouveau deployment.
