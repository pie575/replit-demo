Le répertoire des compétences est un catalogue de compétences prêtes à l’emploi, créées par Replit et ses partenaires, que vous pouvez installer et utiliser immédiatement. Installez-les, essayez-les, puis modifiez-les pour les adapter aux méthodes de travail de votre équipe.

Pour en savoir plus sur les compétences et sur la manière dont Agent les charge, consultez [Compétences Agent](/fr/ja/features/agent/skills). Pour rendre les compétences accessibles dans l’ensemble de votre espace de travail, consultez [Personnalisation d’Agent](/fr/ja/features/agent/agent-customization).

<div id="section">
  ## Installer des compétences
</div>

Vous pouvez ajouter des compétences depuis le répertoire de plusieurs façons :

* **Dans le chat** — Cliquez sur le bouton **+** à côté du champ de saisie, puis sélectionnez **Utiliser une compétence** pour en choisir une. La compétence s’applique uniquement à ce message et rien n’est installé dans le projet.
* **Dans un projet** — Ouvrez le volet Skills dans Project Editor, sélectionnez l’onglet **Découvrir**, recherchez une compétence, puis cliquez sur **Installer**. Les compétences installées se trouvent dans le répertoire `/.agents/skills` du projet et sont conservées d’un chat à l’autre.
* **Depuis la ligne de commande** — Installez une compétence à l’aide de la [CLI skills](https://github.com/vercel-labs/skills) :

  ```bash theme={null}
  npx skills <skill> -a replit
  ```

<Warning>
  Les compétences proposées dans le sélecteur de compétences de Replit font l’objet d’un examen de sécurité. Celles installées depuis des sources externes ne sont pas examinées. Comme les compétences contiennent des instructions suivies par Agent, vérifiez toujours les compétences externes avant de les installer. Consultez [Compétences Agent](/fr/ja/learn/agent-skills) pour savoir ce qu’il faut vérifier.
</Warning>

<div id="replit">
  ## Compétences Replit
</div>

Replit propose des compétences prédéfinies accessibles depuis le sélecteur **Utiliser une compétence** du chat et depuis le sélecteur de point de départ d&#39;un nouveau projet. Elles fonctionnent dans tous les projets, sans installation. Une description s&#39;affiche en ligne à l&#39;ouverture du sélecteur.

| Catégorie              | Compétences                                                                                                   |
| ---------------------- | ------------------------------------------------------------------------------------------------------------- |
| Ventes et marketing    | Ad Creative, AI SDR, SEO Auditor, Programmatic SEO, GEO, Content Machine, Storyboard                          |
| Carrière               | AI Recruiter, Resume Maker, Interview Prep                                                                    |
| Recherche et analyse   | Competitive Analysis, Deep Research, GitHub Solution Finder, Supplier Research                                |
| Entreprise et finance  | Stock Analyzer, Excel Generator, Invoice Generator, Tax Reviewer                                              |
| Documents et outils    | Website Cloner, File Converter, Flashcard Generator, Legal Contract, Infographic Builder, Recreate Screenshot |
| Création               | Photo Editor, Podcast Generator, Podcast Marketing, Branding Generator, Video Editing                         |
| Productivité           | AI Secretary, Product Manager, Design Thinker, Skill Finder, Skill Creator                                    |
| Personnel              | Travel Assistant                                                                                              |
| Sécurité et conformité | Secrets, Sensitive Data, Input Validation, AI Security, Dependency Vetting, License Check                     |
| Qualité et fiabilité   | Accessibility, Responsive UI, Observability, Resilience, Ship Review                                          |

<Note>
  Dans l&#39;espace de travail, le sélecteur détecte également les compétences supplémentaires installées dans le répertoire `.local/secondary_skills/` du projet.
</Note>

<div id="section-2">
  ## Compétences partenaires
</div>

Les partenaires de Replit publient des compétences qui apprennent à Agent à créer avec leurs produits. Une fois installées, elles fournissent à Agent les modèles et les règles propres à chaque service.

| Partenaire       | Ce qu&#39;ils apprennent à Agent                             |
| ---------------- | ------------------------------------------------------------ |
| Stripe           | Modèles d&#39;intégration des paiements et de la facturation |
| PayPal           | Modèles d&#39;intégration des paiements                      |
| RevenueCat       | Modèles d&#39;abonnement et d&#39;achat intégré              |
| Mixpanel         | Mise en œuvre de l&#39;analytique et du suivi                |
| BigQuery         | Modèles de requêtes d&#39;entrepôt de données                |
| Resend           | Intégration des e-mails transactionnels                      |
| Google Workspace | Intégration de Gmail, Drive, Docs et Calendar                |
| Atlassian        | Flux de travail des tickets et des pages Jira et Confluence  |
| Google Maps      | Intégration des cartes, lieux, itinéraires et géocodage      |

<div id="section-3">
  ## Compétences de la communauté
</div>

En plus des compétences de Replit et de ses partenaires, vous pouvez installer des compétences publiées par la communauté. Explorez-les sur [skills.sh](https://skills.sh) et, si vous souhaitez créer les vôtres, consultez la [spécification Compétences Agent](https://agentskills.io/specification).
