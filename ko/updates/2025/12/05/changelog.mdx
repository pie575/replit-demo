<div id="build-full-stack-mobile-apps-with-agent">
  ### Agent로 full-stack 모바일 앱 만들기
</div>

<Frame>
  <img src="/assets/mirror/cleanshot-2025-12-05-at-12-27-22-2x_273f89390642-dc03158b7d7f.png" width="1082" height="504" data-path="images/changelog/2025-12-05/cleanshot-2025-12-05-at-12-27-22-2x_273f89390642.png" />
</Frame>

이제 Agent가 완전한 backend 서버를 갖춘 [모바일 앱](/ko/features/artifact-types/building-mobile-apps)을 만들 수 있습니다. 이를 통해 [AI Integrations](/ko/replitai/integrations), [Database](/ko/features/data-and-storage/sql-database), [Object Storage](/ko/features/data-and-storage/object-storage), connector 등 production 수준의 모바일 개발에 필요한 모든 기능을 사용할 수 있습니다.

<div id="database-now-generally-available">
  ### Database 정식 출시
</div>

새로운 [Database](/ko/features/data-and-storage/sql-database)가 이제 모든 신규 Replit App의 기본 데이터베이스로 적용됩니다. 이번 업그레이드로 안정성과 인프라 제어 기능이 강화되었으며, project의 성능이 향상되고 데이터 관리도 한층 간편해졌습니다.

<div id="fast-mode-handles-more-autonomously">
  ### Fast Mode가 더 많은 작업을 자율적으로 처리합니다
</div>

<Frame>
  <img src="/assets/mirror/image_4f661377d428-8454460e1cca.png" width="720" height="212" data-path="images/changelog/2025-12-05/image_4f661377d428.png" />
</Frame>

이제 [Lite 모드](/ko/core-concepts/agent/agent-modes)(이전 명칭 Fast Mode)가 더 많은 task를 스스로 처리하며, 규모가 큰 changes는 Agent에 맡기도록 안내합니다. 빠른 반복 작업과 매끄러운 handoff로 더 신속하게 빌드하세요.

<div id="connect-third-party-services-faster">
  ### 서드파티 서비스를 더 빠르게 연결하세요
</div>

connector 지원이 개선되어 서드파티 서비스를 더 빠르게 연결할 수 있습니다. 대부분의 API key 기반 서비스는 설정 정보만 입력하면 추가되므로 복잡한 설정 과정이 필요 없습니다. 여기에 다중 키 configurations과 확장된 상태 점검이 더해져 [integrations](/ko/replitai/integrations)의 안정성이 한층 높아졌습니다.
