Import vous permet d&#39;intégrer du code ou des designs existants à vos Replit Apps et de poursuivre le développement avec Agent.

<div id="supported-sources">
  ## Sources prises en charge
</div>

| Source                       | Ce que vous fournissez                                  | Idéal pour                                                       |
| ---------------------------- | ------------------------------------------------------- | ---------------------------------------------------------------- |
| GitHub                       | URL du dépôt ou sélecteur de dépôt                      | Importer des dépôts publics et privés                            |
| Bitbucket                    | URL du dépôt ou sélecteur de dépôt                      | Importer des dépôts hébergés sur Bitbucket                       |
| Vercel                       | Dépôt GitHub associé à votre projet Vercel              | Migrer des applications Vercel                                   |
| Figma                        | URL d’une frame                                         | Transformer des designs en applications React                    |
| Claude                       | Design envoyé depuis Claude                             | Transformer un design Claude en application interactive          |
| Bolt                         | Dépôt GitHub exporté depuis Bolt                        | Migrer des projets Bolt                                          |
| Lovable                      | Dépôt GitHub exporté depuis Lovable                     | Migrer des projets Lovable                                       |
| Base44                       | Dépôt GitHub exporté depuis Base44                      | Migrer des projets Base44                                        |
| ZIP                          | Téléversement d’un fichier `.zip`                       | Importer des archives de projets locaux                          |
| Feuille de calcul            | Fichier `.xlsx`, `.csv` ou URL Google Sheets            | Créer une application à partir de données de feuille de calcul   |
| Exportation Agent précédente | Dépôt GitHub exporté d’une application Agent précédente | Réimporter une application Agent précédente                      |
| Vide                         | Rien                                                    | Utilisateurs expérimentés souhaitant un projet vierge sans Agent |

<Note>Replit vérifie la compatibilité avant le début de l’importation.</Note>

Pour les designs Figma, consultez [Importer des designs Figma dans Replit Design](/fr/design/import-figma-designs-into-replit-design).

Pour les designs envoyés depuis Claude, consultez [Importer des designs Claude dans Replit Design](/fr/design/import-claude-designs-into-replit-design).

  <Tab title="Lovable">
    ⏰ *Durée estimée : quatre minutes*

    Importez un projet Lovable dans Replit en l’exportant vers GitHub, puis en important ce dépôt.

    **Avant de commencer**

    * Un projet Lovable que vous pouvez exporter
    * Un compte GitHub connecté à Lovable
    * Un compte Replit

    **Étapes**

    1. Exportez votre projet Lovable vers GitHub.
    2. Ouvrez [replit.com/import](https://replit.com/import).
    3. Sélectionnez **Lovable**.
    4. Connectez votre compte GitHub.
    5. Sélectionnez le dépôt Lovable exporté.
    6. Sélectionnez **Importer**.

    <div id="what-gets-imported">
      ## Éléments importés
    </div>

    Replit importe les éléments suivants de votre projet {platform_6} :

    * **Code :** Logique de l’application et fichiers source

    * **Ressources :** Images, icônes et fichiers statiques
    * **Logique backend :** Fonctionnalités côté serveur, le cas échéant
    * **Schéma de base de données :** Structure des tables, le cas échéant

    Utilisez Agent pour recréer les fonctionnalités manquantes, ajouter des secrets et recréer les données de la base de données.

  <Tab title="GitHub">
    ⏰ *Temps estimé : deux minutes*

    Importez un dépôt GitHub dans Replit pour exécuter, tester et publier votre application plus rapidement.

    **Avant de commencer**

    * Une URL de dépôt GitHub
    * L&#39;accès au dépôt (public ou privé)
    * Un compte Replit

    **Première option : import rapide**

    L&#39;import rapide fonctionne pour les dépôts publics.

    1. Copiez le chemin du dépôt après `github.com/`.
    2. Ouvrez `https://replit.com/github.com/<owner>/<repo>`.
    3. Appuyez sur Entrée pour lancer l&#39;importation.

    *Exemple*

    * URL GitHub : `https://github.com/exampleUser/my-app`
    * URL d&#39;importation Replit : `https://replit.com/github.com/exampleUser/my-app`

    **Deuxième option : import guidé**

    L&#39;import guidé prend en charge les dépôts publics et privés.

    1. Ouvrez [replit.com/import](https://replit.com/import).
    2. Sélectionnez **GitHub**.
    3. Connectez votre compte GitHub.
    4. Choisissez un dépôt.
    5. Sélectionnez **Importer**.

    **Éléments importés**

    * Les fichiers et dossiers du dépôt
    * Les fichiers de dépendances
    * Les configurations courantes d&#39;exécution et de build

    **Éléments non importés**

    * Les valeurs existantes des Secrets et des variables d&#39;environnement
    * Les services propres à certaines plateformes qui ne s&#39;exécutent pas par défaut dans Replit

    **Résolution des problèmes de connexion à GitHub**

    Si le message `Failed to get repository, please re-authenticate with GitHub` s&#39;affiche ou si la liste déroulante des dépôts indique `No repositories found`, le flux d&#39;import GitHub utilise une connexion distincte de celle de votre page **Compte → Services connectés**. Se reconnecter uniquement dans Services connectés ne résoudra pas le problème du flux d&#39;importation.

    <Steps>
      <Step title="Reconnecter GitHub depuis Fournisseurs Git">
        Ouvrez la section **Fournisseurs Git** dans les paramètres de votre compte Replit, déconnectez GitHub, puis reconnectez-le depuis le même écran. Vos dépôts personnels devraient ensuite apparaître dans la liste déroulante d&#39;importation.
      </Step>

      <Step title="Approuver l’application Replit pour votre organisation GitHub">
        Si le dépôt appartient à une organisation GitHub, ouvrez [https://github.com/settings/applications](https://github.com/settings/applications), trouvez l&#39;application OAuth Replit et accordez-lui l&#39;accès à l&#39;organisation dans les paramètres d&#39;accès des applications tierces. Les administrateurs de l&#39;organisation devront peut-être effectuer cette étape si vous n&#39;en êtes pas propriétaire.
      </Step>

      <Step title="Réessayer l’importation">
        Ouvrez [replit.com/import](https://replit.com/import) et réessayez l&#39;importation, depuis la liste déroulante des dépôts ou en collant l&#39;URL du dépôt.
      </Step>
    </Steps>

  <Tab title="ZIP">
    ⏰ *Durée estimée : trois minutes*

    Importez un projet local en téléversant un fichier `.zip`.

    **Avant de commencer**

    * Un fichier `.zip` contenant votre projet et ne dépassant pas 200 Mo
    * Un dossier racine de projet clairement identifié dans l’archive
    * Un compte Replit

    Si votre fichier zip dépasse 200 Mo, le formulaire d’importation le refuse. Excluez les dossiers de dépendances et de build tels que `node_modules`, `.venv` ou `build` afin d’en réduire la taille. Replit réinstalle les dépendances lors de l’importation.

    **Étapes**

    1. Ouvrez [replit.com/import](https://replit.com/import).
    2. Sélectionnez **ZIP**.
    3. Téléversez votre fichier `.zip`.
    4. Ajoutez les secrets et variables d’environnement demandés.
    5. Sélectionnez **Import**.

    **Éléments importés**

    * Fichiers du projet et structure des répertoires
    * Fichiers de dépendances
    * Paramètres d’exécution et de build par défaut de Replit

    **Éléments non importés**

    * Valeurs existantes des variables d’environnement
    * Domaines personnalisés
    * Services spécifiques à la plateforme nécessitant une configuration manuelle
    * Données existantes de la base de données
    * Configuration existante des connecteurs tiers

<div id="other-sources">
  ## Autres sources
</div>

<div id="bitbucket">
  ### Bitbucket
</div>

* Collez l’URL d’un dépôt Bitbucket ou connectez votre compte Bitbucket pour rechercher vos dépôts.
* L’assistance d’Agent lors de l’importation peut être limitée par rapport aux projets hébergés sur GitHub.

<div id="spreadsheet">
  ### Feuille de calcul
</div>

* Téléversez un fichier Excel (`.xlsx`) ou CSV, ou collez l’URL publique d’une feuille Google Sheets.
* Agent analyse la structure de votre feuille de calcul et crée une app full-stack avec une base de données alimentée par vos données.
* Une UI permet d’afficher, de rechercher et de gérer vos enregistrements.

<div id="previous-agent-export">
  ### Exportation Agent précédente
</div>

* Réimportez une application Agent déjà exportée depuis un dépôt GitHub.
* Replit préserve la structure propre à Agent (code, schéma de base de données, fonctionnalités backend).
* Les données de la base de données et les valeurs secrètes ne sont pas importées.

<div id="empty">
  ### Vide
</div>

* Commencez avec un projet entièrement vide : sans Agent, sans sélection de framework ni code de démarrage.
* Idéal pour les utilisateurs avancés qui souhaitent contrôler entièrement la configuration du projet.

<div id="limitations">
  ## Limitations
</div>

* Les données existantes de la base de données ne sont pas migrées.
* Les téléversements de fichiers ZIP sont limités à 200 Mo.
* Certaines dépendances complexes ou propriétaires peuvent nécessiter une configuration manuelle.
* Le traitement des projets volumineux peut prendre plus de temps.

<div id="best-practices">
  ## Bonnes pratiques
</div>

* Supprimez les identifiants sensibles avant l’importation.
* Maintenez une structure claire dans votre projet source.
* Vérifiez les dépendances et les commandes d’exécution après l’importation.
* Testez les principaux parcours avant de publier.

<div id="troubleshooting">
  ## Dépannage
</div>

Si l’importation échoue, vérifiez d’abord les points suivants :

* **Erreurs de compatibilité** : vérifiez les fichiers requis du projet et les frameworks pris en charge.
* **Erreurs d’accès** : vérifiez les autorisations du dépôt ou de la source.
* **Erreurs de traitement** : réessayez après avoir simplifié la structure du projet ou réduit sa taille.

Si les problèmes persistent, consultez le [Replit Community Hub](https://replit.com/community) ou [contactez l’assistance](https://replit.com/support).

<div id="billing">
  ## Facturation
</div>

Les importations nécessitant une migration par Agent peuvent consommer des crédits. L’utilisation des crédits dépend de la complexité du projet.
