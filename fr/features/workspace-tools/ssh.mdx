<div id="what-is-ssh">
  ## Qu’est-ce que SSH ?
</div>

SSH, qui signifie Secure Shell, est un protocole sécurisé qui permet d’accéder à distance à l’interface en ligne de commande de votre application Replit. Avec SSH, vous pouvez facilement transférer des fichiers et utiliser votre environnement de développement intégré (IDE) local préféré pour modifier du code sur Replit, ce qui améliore la collaboration et la productivité dans votre processus de développement.

La fonctionnalité SSH est disponible avec Core, Pro et tous les autres plans payants.

Voici un aperçu du processus :

* Générez une paire de clés SSH sur votre machine locale
* Ajoutez cette clé SSH au volet **SSH** de n’importe quelle application Replit
* Connectez-vous à l’aide d’un client SSH ou d’un éditeur compatible SSH (comme [VSCode](https://code.visualstudio.com/) ou [Cursor](https://www.cursor.com/))

<Note>
  Les clés SSH sont associées à votre compte, et non à une application Replit en particulier. Vous ne devez donc ajouter une clé publique qu’une seule fois, puis vous pouvez vous connecter à n’importe quelle application Replit à laquelle vous avez accès.
</Note>

<div id="why-use-ssh">
  ## Pourquoi utiliser SSH ?
</div>

* **Mises à jour automatiques entre application Replit et l’éditeur** : toutes les modifications apportées dans application Replit sont instantanément répercutées dans votre éditeur, et inversement. Cette synchronisation fluide garantit que votre base de code est toujours à jour sur toutes les plateformes.

* **Synchronisation de la gestion des fichiers** : que vous ajoutiez, supprimiez ou mettiez à jour des fichiers, ces modifications sont synchronisées en temps réel entre votre éditeur et application Replit. Cette fonctionnalité garantit que la structure de votre projet reste cohérente, quel que soit l’endroit où les modifications sont effectuées.

* **Gestion des dossiers et déplacement des fichiers** : le déplacement de fichiers entre les dossiers est également synchronisé entre vos éditeurs et application Replit. Ainsi, les changements d’organisation effectués dans un environnement sont fidèlement répercutés dans l’autre, tout en préservant l’intégrité et la structure de votre projet.

<div id="find-or-create-a-keypair">
  ## Trouver ou créer une paire de clés
</div>

Pour configurer SSH pour votre compte, vous aurez besoin de votre clé publique SSH.

<div id="figuring-out-if-you-already-have-a-keypair">
  ### Vérifier si vous disposez déjà d’une paire de clés
</div>

Vous pouvez vérifier si vous disposez déjà d’une clé publique en exécutant la commande suivante dans un terminal sur votre ordinateur local :

<Tabs>
  <Tab title="Mac/Linux">
    ```sh theme={null}
    ls -l ~/.ssh
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    dir %HOMEPATH%\.ssh
    ```
  </Tab>
</Tabs>

Si vous obtenez une erreur, ce n’est pas grave : passez à [Générer une nouvelle paire de clés](#generating-a-new-keypair).
Si vous voyez un fichier nommé `replit.pub`, passez à [Obtenir le contenu de votre clé publique](#get-the-contents-of-your-public-key).

<div id="generating-a-new-keypair">
  ### Générer une nouvelle paire de clés
</div>

Sur votre ordinateur, ouvrez une fenêtre de terminal (ou d’invite de commandes) et collez la commande suivante :

<Tabs>
  <Tab title="Mac/Linux">
    ```bash theme={null}
    ssh-keygen -t ed25519 -f ~/.ssh/replit -q -N ""
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    ssh-keygen -t ed25519 -f %HOMEPATH%\.ssh\replit -q -N ""
    ```
  </Tab>
</Tabs>

Cette commande vérifie si un fichier de clé publique SSH spécifique existe déjà. Si ce n’est pas le cas, elle crée une clé SSH avec des paramètres adaptés.

<div id="get-the-contents-of-your-public-key">
  ### Récupérer le contenu de votre clé publique
</div>

Après avoir vérifié que vous disposez d’une paire de clés ou en avoir créé une, affichez le contenu de la clé publique (l’un des deux fichiers aux noms similaires, portant le suffixe `.pub`), car vous en aurez besoin plus loin.

<Tabs>
  <Tab title="Mac/Linux">
    ```sh theme={null}
    cat ~/.ssh/replit.pub
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    notepad %HOMEPATH%\.ssh\replit.pub
    ```
  </Tab>
</Tabs>

Enregistrez le contenu de `replit.pub` pour l’utiliser plus loin dans cet article, puis passez à [l’ajout de la clé SSH à votre compte](#add-the-ssh-key-to-your-account).

<div id="add-the-ssh-key-to-your-account">
  ## Ajoutez la clé SSH à votre compte
</div>

<div id="add-the-public-key-directly-in-a-replit-app-using-the-ssh-pane">
  ### Ajouter directement la clé publique dans une application Replit à l’aide du volet SSH
</div>

1. Dans votre application Replit, depuis n’importe quelle fenêtre, sélectionnez le bouton **+**, puis recherchez **SSH**.

<Frame>
  <img src="/assets/mirror/ssh-tool-2db02c6a83d0.png" alt="Bouton de l’outil SSH dans l’interface Replit" width="846" height="328" data-path="images/ssh-vscode/ssh-tool.png" />
</Frame>

2. Accédez à l’onglet **Keys** et sélectionnez **New SSH key**.
3. Dans la fenêtre contextuelle, saisissez un **Label** pour votre clé (par ex., my-ssh-key), puis collez la clé publique que vous avez copiée dans la section **Key**.
   Sélectionnez le bouton **Add SSH Key**. Votre clé est alors ajoutée et autorisée à être utilisée.

<Frame>
  <img src="/assets/mirror/add-ssh-key-with-values-5d6f440e56ba.png" alt="Boîte de dialogue d’ajout d’une clé SSH avec les champs d’étiquette et de clé remplis" width="500" height="511" data-path="images/ssh-vscode/add-ssh-key-with-values.png" />
</Frame>

<div id="add-the-public-key-directly-in-settings">
  ### Ajouter directement la clé publique dans les paramètres
</div>

Vous pouvez également ajouter une clé SSH en ouvrant **paramètres** puis, dans **compte**, en sélectionnant **avancé** (ou l’option **Clés SSH**). Sélectionnez **Ajouter une clé SSH**, puis collez le contenu de `replit.pub` indiqué dans la section précédente, [Trouver ou créer une paire de clés](#find-or-create-a-keypair).

<Note>
  Si votre machine comporte plusieurs clés publiques, veillez à utiliser la bonne combinaison de clés privée et publique pour votre configuration SSH.
</Note>

<div id="connecting-to-your-replit-app">
  ## Connexion à votre application Replit
</div>

<div id="configure-your-ssh-config">
  ### Configurez votre fichier de configuration SSH
</div>

1. Dans un terminal, vérifiez que le répertoire `~/.ssh` et le fichier `~/.ssh/config` existent :

<Tabs>
  <Tab title="Mac/Linux">
    ```sh theme={null}
    mkdir -p ~/.ssh && chmod 700 ~/.ssh && touch ~/.ssh/config && chmod 600 ~/.ssh/config
    open -a 'TextEdit' ~/.ssh/config || nano ~/.ssh/config
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    if not exist %HOMEPATH%\.ssh mkdir %HOMEPATH%\.ssh && type \NUL > %HOMEPATH%\.ssh\config
    notepad %HOMEPATH%\.ssh\config
    ```
  </Tab>
</Tabs>

2. Ajoutez un bloc de configuration afin d’utiliser la paire de clés `replit` pour tous les domaines *.replit.dev :

<Tabs>
  <Tab title="Mac/Linux/Windows">
    ```
    Host *.replit.dev
        Port 22
        IdentityFile ~/.ssh/replit
        StrictHostKeyChecking accept-new
    ```
  </Tab>
</Tabs>

<div id="connect-from-vscode-or-cursor">
  ### Se connecter depuis VSCode ou Cursor
</div>

1. Depuis une application Replit, ouvrez le volet **SSH**.

2. Dans le volet SSH, accédez à l’onglet **Connect**, puis sélectionnez **Launch VS Code**.

<Tabs>
  <Tab title="Se connecter avec VSCode">
    <img src="/assets/mirror/ssh-connect-439a3c150846.png" alt="Onglet SSH Connect affichant l’option Launch VS Code" width="788" height="482" data-path="images/ssh-vscode/ssh-connect.png" />
  </Tab>
</Tabs>

3. Si vous êtes invité à renseigner `~/.ssh/config`, saisissez ce qui suit :

   ```
   Host *.replit.dev
       Port 22
       IdentityFile ~/.ssh/replit
       StrictHostKeyChecking accept-new
   ```

   <Note>
     La configuration SSH n’est demandée que lors de votre première tentative de connexion à VS Code ou à un autre éditeur. Pour revenir au fichier de configuration, sélectionnez **Configure SSH Hosts...**.
   </Note>

4. Si un avertissement concernant une application externe s’affiche, sélectionnez **Yes** pour confirmer que vous souhaitez ouvrir votre projet dans l’éditeur de votre choix ou dans VS Code.

5. Il peut vous être demandé d’installer ou de mettre à jour périodiquement des extensions SSH. Replit s’efforcera de rester compatible avec les dernières versions de ces IDE, qui peuvent également inclure d’importantes mises à jour de sécurité.

<div id="connect-manually">
  ### Se connecter manuellement
</div>

Au bas de l’onglet &quot;Connect&quot; du volet **SSH**, vous trouverez l’option &quot;Se connecter manuellement&quot;.

Copiez cette commande et collez-la dans un Terminal local (Mac ou Linux) ou une Invite de commandes locale (Windows) pour vous connecter directement.

C’est également un bon moyen de résoudre les problèmes de connexion avec les IDE et de recueillir de précieuses informations détaillées sur la connexion lorsque vous signalez des bugs au support Replit.

<div id="connect-via-a-tool-not-listed-here">
  ### Connectez-vous à l’aide d’un outil qui n’est pas répertorié ici
</div>

De nombreux clients SSH sont disponibles pour diverses plateformes et systèmes d’exploitation, et offrent différentes fonctionnalités ou intégrations.

Vous pouvez décomposer la commande affichée dans &quot;Se connecter manuellement&quot; en ses différents éléments afin de déterminer comment configurer chaque client :

```sh theme={null}
ssh -i ~/.ssh/replit -p 22  c96b6ade-d5e4-4f7a-bc5b-52334509b2a3@c96b6ade-d5e4-4f7a-bc5b-52334509b2a3-00-16nh2hskw3ql8.riker.replit.dev
       ^-----v-----^    ^^  ^-----------------v----------------^ ^------------------------------v-------------------------------------^
        Private Key   Port                   User               @                           Hostname
```

**Nom d’hôte** : `<your_hostname>.<cluster>.replit.dev`
**Port** : `<port_number>`
**Utilisateur** : `Username`
**Clé privée** : Chemin d’accès au fichier de clé privée sur votre ordinateur, généralement situé à côté de `replit.pub`.
