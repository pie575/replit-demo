Assistant 已于本周上线。这是一款全新的 AI 工具，可编辑多个文件并直接应用更改。

<Note>
  **更新 (2025 年 12 月) ：** Assistant 已停止支持。如需快速局部编辑，请使用 [Agent 的 Lite 模式](/zh/core-concepts/agent/agent-modes)；如需讨论和规划，请使用 [Agent 的 Plan 模式](/zh/core-concepts/agent/plan-mode)。
</Note>

Assistant 专为聊天和快速编辑而优化。典型工作流是先使用 Agent 创建 MVP，再使用 Assistant 快速编辑。

Assistant 的主要功能包括：

* **轻量：** Assistant 专为聊天和快速编辑而优化，现在可编辑多个文件并直接应用更改。
* **提及和截图：** 在提示词中提及文件或 URL。Assistant 会抓取 URL 或为您截取屏幕截图。
* **回滚：** Assistant 会自动创建检查点，让您可以轻松以差异对比的形式预览编辑内容，并一键回滚。
* **灵活性：** Assistant 适用于所有 Replit 应用，不受技术栈限制。您可以导入现有项目，或使用 Agent 从头开始。
* **更精美的应用：** 改进了对响应式 React 应用的支持，助您打造更出色的应用。
* **计费更新：** 已取消 Agent 的所有用量上限，并增加了订阅包含的积分。

<div id="assistant">
  ### Assistant 功能
</div>

Replit Assistant 是一款用于聊天和快速编辑的轻量级 AI 工具，可同时编辑多个文件并直接应用更改。

为 Assistant 提供上下文时效果最佳。提供具体功能、文件 (通过 `@file` 提及) 和 URL (直接粘贴) ，能获得更好的效果。

Assistant 可帮助你更快迭代，所用积分约为 Agent 的五分之一。

<div id="section-5">
  ### 快速抓取 / 截图
</div>

使用 **Assistant** 或 **Agent**，你可以截取任意网站的截图，或抓取其内容并直接添加到提示词中。

粘贴 URL 后，Replit 会建议你截取截图或抓取页面内容。

你可以随时在提示词中附加图片，或使用 `@file` 提及文件。
