title: "Résoudre l'erreur « This app is blocked » avec les connecteurs Google"
description: "Corriger l'erreur « This app is blocked » qui apparaît lorsque vous essayez d'utiliser les connecteurs Google Drive, Docs, Sheets, Calendar et Gmail dans Replit."
---

<div id="section">
  ## Vue d&#39;ensemble
</div>

Si le message d&#39;erreur **« This app is blocked »** s&#39;affiche lorsque vous tentez de vous connecter à un service Google Workspace (Drive, Docs, Sheets, Calendar ou Gmail) via les [connecteurs](/fr/ja/features/integrations/overview#connectors), la cause est généralement une mauvaise configuration d&#39;OAuth Google dans le Google Workspace de votre organisation.

Ce guide décrit la marche à suivre pour résoudre le problème et connecter les services Google à votre Replit App.

<Frame>
  <img src="/assets/mirror/app-is-blocked-837b32f44f72.png" alt="Boîte de dialogue d'erreur Google affichant le message « This app is blocked » qui bloque l'accès OAuth" width="1279" height="502" data-path="images/replitai/debugging-google-connectors/app-is-blocked.png" />
</Frame>

<Warning>
  Ces étapes s&#39;appliquent uniquement aux comptes **Google Workspace** (comptes administrés par une organisation). Si vous utilisez un compte Google personnel associé à une adresse `@gmail.com` et que le connecteur Replit est bloqué, vous ne pouvez pas modifier vous-même les politiques OAuth : contactez l&#39;administrateur de votre Google Workspace ou utilisez un autre compte.
</Warning>

<div id="section-2">
  ## Étapes de dépannage
</div>

<div id="1">
  ### Étape 1 : essayer le mode navigation privée
</div>

Les extensions de navigateur ou les données mises en cache peuvent perturber le flux OAuth. Le mode navigation privée permet d&#39;éviter ces problèmes.

<Steps>
  <Step title="Ouvrir le mode navigation privée">
    Ouvrez une nouvelle fenêtre de **navigation privée** (Chrome) ou **privée** (Firefox/Safari) dans votre navigateur.
  </Step>

  <Step title="Se connecter à Replit">
    Connectez-vous à votre compte Replit sur [replit.com](https://replit.com).
  </Step>

  <Step title="Réessayer la connexion">
    Ouvrez votre app dans le Project Editor, accédez à **Connectors** dans la barre latérale, puis réessayez de vous connecter au service Google.
  </Step>
</Steps>

Si l&#39;erreur persiste, passez à l&#39;étape 2.

<div id="2-google-workspaceoauth">
  ### Étape 2 : vérifier la configuration OAuth de Google Workspace
</div>

<Note>
  Cette étape nécessite un accès à la **console d&#39;administration Google** de votre organisation. Si vous ne disposez pas des droits d&#39;administrateur, contactez votre équipe informatique.
</Note>

<Steps>
  <Step title="Ouvrir la console d'administration Google">
    Connectez-vous à la [console d&#39;administration Google](https://admin.google.com) de votre organisation.
  </Step>

  <Step title="Vérifier l'existence de l'utilisateur">
    Accédez à la section **Users** et vérifiez que le compte qui tente de se connecter à Replit figure bien dans la liste.

    <Frame>
      <img src="/assets/mirror/google-workspace-users-c21d8fd43f71.png" alt="Section Users de la console d'administration Google affichant les comptes utilisateurs" width="1104" height="596" data-path="images/replitai/debugging-google-connectors/google-workspace-users.png" />
    </Frame>
  </Step>

  <Step title="Accéder aux contrôles des API">
    Accédez à **Security &gt; Access and data control &gt; API controls**.

    <Frame>
      <img src="/assets/mirror/google-workspace-api-controls-b811709315cf.png" alt="Console d'administration Google affichant le chemin de navigation Security > API Controls" data-og-width="1140" width="1140" data-og-height="631" height="631" data-path="images/replitai/debugging-google-connectors/google-workspace-api-controls.png" data-optimize="true" data-opv="3" srcset="/assets/mirror/google-workspace-api-controls-a27d4577aee8.png 280w, /assets/mirror/google-workspace-api-controls-d681943c082d.png 560w, /assets/mirror/google-workspace-api-controls-8f1b1659e60a.png 840w, /assets/mirror/google-workspace-api-controls-795bc698b885.png 1100w, /assets/mirror/google-workspace-api-controls-c122b9eb493f.png 1650w, /assets/mirror/google-workspace-api-controls-2415c93b4f41.png 2500w" />
    </Frame>
  </Step>

  <Step title="Ouvrir l'accès aux applications tierces">
    Sélectionnez **Manage third-party app access**.

    <Frame>
      <img src="/assets/mirror/third-party-app-access-eb5c94107497.png" alt="Page des contrôles des API de la console d'administration Google avec le bouton Manage third-party app access mis en évidence" width="1686" height="468" data-path="images/replitai/debugging-google-connectors/third-party-app-access.png" />
    </Frame>
  </Step>

  <Step title="Vérifier l'accès OAuth">
    Vérifiez que l&#39;accès OAuth est activé pour les utilisateurs de votre Google Workspace. S&#39;il est restreint, accordez les autorisations nécessaires pour que Replit puisse mener à bien le flux OAuth.
  </Step>
</Steps>

Si la connexion échoue toujours, passez à l&#39;étape 3.

<div id="3-replitoauth">
  ### Étape 3 : ajouter Replit comme client OAuth approuvé
</div>

Si votre organisation restreint par défaut l&#39;accès des applications tierces, vous devez explicitement approuver Replit.

<Steps>
  <Step title="Ouvrir la console d'administration Google">
    Connectez-vous à la [console d&#39;administration Google](https://admin.google.com) de votre organisation.
  </Step>

  <Step title="Accéder aux contrôles d'API">
    Accédez à **Security &gt; Access and data control &gt; API controls**.
  </Step>

  <Step title="Ouvrir l'accès des applications tierces">
    Sous **App access control**, sélectionnez **Manage third-party app access**.
  </Step>

  <Step title="Ajouter une nouvelle application">
    Sélectionnez le bouton **Add app**, puis choisissez **OAuth App Name or Client ID** dans le menu déroulant.
  </Step>

  <Step title="Rechercher Replit">
    Saisissez le Client ID de Replit :

    ```
    1012035106355-2dhot2e6o0malvog2ofss7akj2nsp8nq.apps.googleusercontent.com
    ```

    Sélectionnez **Search**. Lorsque l&#39;application Replit apparaît dans les résultats, sélectionnez-la.
  </Step>

  <Step title="Définir le niveau d'accès">
    Définissez le niveau d&#39;accès sur **Trusted**.
  </Step>

  <Step title="Enregistrer">
    Sélectionnez **Save**.
  </Step>
</Steps>

<Tip>
  La prise en compte des modifications apportées aux règles Google Workspace peut prendre quelques minutes. Après l&#39;enregistrement, patientez 5 à 10 minutes avant de réessayer la connexion aux services Google depuis Replit.
</Tip>

<div id="section-3">
  ## Si le blocage persiste
</div>

Si l&#39;erreur persiste après avoir effectué les trois étapes :

* **Vérifiez à nouveau l&#39;unité organisationnelle (UO)** : les règles Google Workspace peuvent s&#39;appliquer à une UO spécifique. Assurez-vous que les paramètres OAuth et d&#39;applications approuvées s&#39;appliquent bien à l&#39;UO dont fait partie l&#39;utilisateur qui tente de se connecter.
* **Consultez les alertes Google Workspace** : dans la console d&#39;administration, ouvrez **Reporting &gt; Audit and investigation &gt; OAuth log events** pour repérer d&#39;éventuelles requêtes refusées liées à Replit.
* **Contactez l&#39;assistance Replit** : si le problème ne vient pas de Google Workspace, contactez l&#39;[assistance Replit](https://replit.com/support).
