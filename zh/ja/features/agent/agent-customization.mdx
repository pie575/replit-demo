---
title: "Agent 自定义"
description: "通过适用于整个工作区的自定义指令和技能，向 Agent 传授团队规范，并在 Workspace 设置中集中管理。"
---

Agent 自定义从第一条提示词开始，就为 Agent 提供所需的上下文，使其能够按照你和团队的工作方式开展工作。无需在每个项目中重复说明规则，只需在工作区中定义一次，Agent 就会在各处应用这些规则。

包含两项功能：

* **自定义指令**：始终生效、适用于工作区内所有项目的指导原则。
* **技能**：仅在遇到相关任务时由 Agent 加载的可复用指令。

两者均可在 **Workspace 设置 → 自定义** 中管理。

<div id="section">
  ## 自定义指令与技能的区别
</div>

自定义指令会在每条消息中加载。技能仅在 Agent 判断其与任务相关时才会加载。对于始终适用的指导原则，请使用自定义指令；对于特定的工作流程、规则和参考资料，请使用技能。

如需了解这种划分背后的原因——上下文预算、内容应放在哪里，以及如何有效创建技能——请参阅 [Agent 技能](/zh/ja/learn/agent-skills)。如需了解技能的结构以及 Agent 如何加载技能，请参阅 [Agent Skills](/zh/ja/features/agent/skills)。

<div id="section-2">
  ## 自定义指令
</div>

自定义指令是始终生效的指南，会在用户输入提示词前注入 Agent 在所有项目和会话中的上下文。只需在 Workspace 设置中编写一次，Agent 就会在整个工作区中应用这些指令。它们特别适合用于始终适用的指南，例如安全与合规要求、经批准的库和框架，以及数据处理政策。

请保持简短。重点明确、具体的指令更容易被准确遵循，也能为 Agent 实际执行任务留出更多空间。

<Warning>
  自定义指令可能会影响 Agent 的性能。虽然 Agent 会被引导遵循这些指令，但无法保证严格满足要求。简短且具体的指南更能被可靠地遵循。
</Warning>

<Note>
  工作区自定义指令不同于项目中的 `custom_instruction/instructions.md` 文件。工作区自定义指令只需在 Workspace 设置中配置一次，便会应用于所有项目。项目级文件仅适用于单个项目——有关此模式，请参阅[创建自定义设计系统](/zh/ja/teams/custom-design-system)。
</Note>

<div id="section-3">
  ## 技能
</div>

技能是一组可复用的指令，Agent 仅会在遇到相关任务时加载它们。工作区技能会显示在工作区内所有项目的 **+** 菜单顶部，因此整个团队可以共享同一套技能。

您可以通过三种方式创建技能：

* **上传** — 上传现有技能文件夹。
* **创建** — 直接在表单中编写新技能。
* **让 Agent 创建** — 请 Agent 起草技能，然后再进行完善。

<Note>
  您可以让 Agent 为 Workspace 技能创建上传包。请 Agent 下载技能。Agent 会将技能打包为可下载的 `.zip` 归档文件，并显示 **下载文件** 按钮 (如下图所示) 。下载 zip 文件后，通过 **Workspace 设置 → 自定义 → 技能** 中的 **创建技能 → 选择文件或文件夹** 上传，即可在整个工作区中共享。
</Note>

<Frame>
  <img src="/assets/mirror/agent-customization-download-skill-3727b188c5a8.png" alt="Agent 将工作区技能打包为可下载的 ux-designer-skill.zip 归档文件，并显示“下载文件”按钮" width="1716" height="864" data-path="images/replitai/agent-customization-download-skill.png" />
</Frame>

有关技能的完整结构 (`SKILL.md`、支持文件和开放标准) ，请参阅 [Agent Skills](/zh/ja/features/agent/skills)。要浏览 Replit 及其合作伙伴已构建的技能，请参阅 [技能目录](/zh/ja/features/agent/skills-directory)。

<Note>
  请谨慎使用技能。Agent 会针对每项任务读取所有技能的名称和描述。技能过多或重复会分散其注意力，使 Agent 更难选择合适的技能。请明确每项技能的适用范围，并删除不再需要的技能。
</Note>

<div id="section-4">
  ## 可用套餐和权限
</div>

| 功能    | 可用套餐             | 可管理的用户                            |
| ----- | ---------------- | --------------------------------- |
| 自定义指令 | Pro 和 Enterprise | Enterprise：管理员。Pro：所有工作区成员        |
| 技能    | 所有付费套餐           | Enterprise：管理员。Core 和 Pro：所有工作区成员 |

在 Enterprise 工作区中，只有管理员可以创建、编辑和删除自定义指令和技能。在 Pro 工作区中，所有工作区成员都可以执行这些操作。在 Core 工作区中，所有成员都可以管理技能——Core 不支持自定义指令。无论使用哪种套餐，工作区的所有成员都可以使用已创建的技能。

<div id="section-5">
  ## 创建自定义指令
</div>

<Steps>
  <Step title="打开 Workspace 设置">
    前往 **Workspace 设置 → 自定义**。

    <Frame>
      <img src="/assets/mirror/agent-customization-tab-930af2e8ed74.png" alt="Workspace 设置中的自定义选项卡，显示 技能 和自定义指令子选项卡" width="1065" height="394" data-path="images/replitai/agent-customization-tab.png" />
    </Frame>
  </Step>

  <Step title="编写指令">
    在 **自定义指令** 部分，编写希望 Agent 在所有项目中遵循的指南。
  </Step>

  <Step title="保存">
    保存更改。指令将应用于工作区中的新项目。
  </Step>
</Steps>

<div id="section-6">
  ## 创建技能
</div>

<Steps>
  <Step title="打开 Workspace 设置">
    前往 **Workspace 设置 → 自定义**。
  </Step>

  <Step title="创建技能">
    在 **技能** 部分点击 **创建技能**，然后上传技能文件夹、编写指令，或让 Agent 起草。

    <Frame>
      <img src="/assets/mirror/agent-customization-create-skill-fcb794e6de4e.png" alt="Workspace 设置中的自定义选项卡，显示 技能 和自定义指令子选项卡，并已打开创建技能表单" width="2168" height="1350" data-path="images/replitai/agent-customization-create-skill.png" />
    </Frame>
  </Step>

  <Step title="编写清晰的说明">
    添加清晰的说明，明确该技能应在何时使用，以及何时不应使用。这是 Agent 决定是否应用该技能时会参考的内容。
  </Step>

  <Step title="保存">
    保存技能。随后可在工作区内所有项目的 **+** 菜单中使用。
  </Step>
</Steps>

<div id="section-7">
  ## 在项目中使用工作区技能
</div>

技能说明清晰明确非常重要。Agent 会读取所有工作区技能的说明；如果提示词与技能用途大致匹配，它会自动加载该技能，因此你可能无需手动选择技能。如果想确保某项技能被应用，也可以手动选择。

要手动选择：

<Steps>
  <Step title="打开技能选择器">
    在项目中，点击聊天输入框旁的 **+** 按钮。工作区技能会集中显示在顶部。

    <Frame>
      <img src="/assets/mirror/agent-customization-skill-picker-4643f3a453c7.png" alt="通过 + 按钮打开的技能选择器，Workspace skills 组显示在 Replit skills 上方" width="1668" height="1170" data-path="images/replitai/agent-customization-skill-picker.png" />
    </Frame>
  </Step>

  <Step title="选择技能">
    选择要使用的技能。你也可以在 `/` 后输入技能名称，直接调用该技能。
  </Step>

  <Step title="继续输入提示词">
    像平常一样继续操作。如果任务与技能说明匹配，Agent 会使用该技能。
  </Step>
</Steps>

<div id="section-8">
  ## 管理指令和技能
</div>

所有管理操作均在 **Workspace 设置 → 自定义** 中完成。你可以在此编辑自定义指令，以及编辑、禁用或删除技能。更改将应用于后续聊天，但不会应用于正在进行的聊天。
