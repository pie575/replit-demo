<div id="agent">
  ## Agent
</div>

<div id="choose-agents-primary-model">
  ### Выберите основную модель Agent
</div>

Теперь вы можете выбрать основную модель, которую Agent будет использовать для задачи. Выберите Lite, Economy или Power, а затем — одну из доступных моделей для этого режима. Lite теперь доступен везде, где можно использовать Agent, в том числе в мобильных приложениях. Доступность моделей зависит от организации, разрешений и доступа к Turbo.

Подробнее см. в разделе [Выбор модели](/ru/features/agent/model-selector).

<div id="connect-more-mcp-servers">
  ### Подключайте больше MCP-серверов
</div>

В соответствующих требованиям Workspace можно подключать Supabase, Statsig и Calendly из каталога доступных MCP-серверов. Replit также распознаёт официальный MCP-эндпоинт Braintrust и запускает вход через OAuth при его ручном добавлении.
