<div id="conversations-vs-projects">
  ## Conversations와 Projects 비교
</div>

Conversation은 질문, 탐색, Routine을 위한 단일 thread입니다. [Project](/ko/features/projects-and-artifacts/projects)는 여러 artifact를 포함한 본격적인 빌드 및 디자인 작업에 적합한 심화 workspace입니다.

먼저 Conversation에서 시작하세요. 작업이 본격적인 빌드나 디자인으로 발전하면 Conversation을 Project로 전환할 수 있습니다.

사이드바에서 Conversations는 말풍선 icon으로, Projects는 4칸 격자 icon으로 표시됩니다.

<Frame>
  <img src="/assets/mirror/conversation-and-project-icons-025a17613daa.png" alt="4칸 격자 아이콘의 Project와 말풍선 아이콘의 Conversation이 표시된 Replit 사이드바" width="466" height="290" data-path="images/chat/conversation-and-project-icons.png" />
</Frame>

| 영역           | Conversations   | Projects                                           |
| ------------ | --------------- | -------------------------------------------------- |
| 적합한 용도       | 질문, 탐색, Routine | 앱, slides, dashboard, 여러 artifact 등 심화 빌드 및 디자인 작업 |
| 백그라운드 task   | **사용 불가**       | **병렬 실행 가능**                                       |
| Routines     | **사용 가능**       | **사용 불가**                                          |
| Integrations | 사용 가능           | 사용 가능                                              |
| 구조           | 단일 thread       | 여러 artifact를 담은 project workspace                  |
