O Console permite monitorar e revisar os logs impressos pelo seu Replit App em execução em tempo real.
Você pode usar as informações de execuções atuais e anteriores para entender o comportamento do seu app,
solucionar erros e otimizar o desempenho.

<Tip>
  Ao depurar usando o Agent, inclua os logs do console no seu prompt para fornecer contexto.
</Tip>

## Recursos

O Console fornece as seguintes ferramentas para ajudá-lo a entender o comportamento do seu app:

* **Registro em tempo real**: Visualize a saída do seu app conforme ela acontece
* **Assistência de IA**: Receba sugestões para corrigir erros relatados nos logs
* **Histórico de execuções**: Exiba logs de execuções anteriores para acompanhar as alterações

## Uso

Você pode acessar a ferramenta Console diretamente no seu Editor de Projetos.

<Accordion title="Como acessar o Console">
  No **dock de ferramentas** à esquerda:

  1. Selecione <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Ícone de Todas as ferramentas" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **Todas as ferramentas** para ver a lista de ferramentas do Editor de Projetos.
  2. Selecione <img class="icon-svg" src="/assets/mirror/console-8a41ac90789c.svg" alt="Ícone do Console" width="16" height="16" data-path="images/icons/console.svg" /> **Console**.

  Na **barra de pesquisa**:

  1. Selecione a <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="ícone de lupa" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> lupa na parte superior para abrir a ferramenta de pesquisa
  2. Digite "Console" para localizar a ferramenta e selecione-a nos resultados.
</Accordion>

Cada vez que você usa o botão **Executar** no seu Replit App, o Console exibe uma nova entrada que inclui as seguintes informações:

* O comando que executou seu código
* Informações de data e hora
* Logs de saída padrão e de erros

A captura de tela a seguir mostra o comando `npm run dev` usado para iniciar o app e as mensagens de log da execução:

### Depuração com IA

Quando você encontrar erros ou outras informações nos logs que queira entender, selecione o
botão **Perguntar à IA** na parte superior da entrada. Isso abre automaticamente a aba do **Agent** e
envia o conteúdo do log para análise.

### Comandos de entrada de log

O Console fornece as seguintes ferramentas para gerenciar seus logs:

* **Mostrar somente o mais recente**: Ative este controle para exibir apenas a execução mais recente.
* **Recolher entrada**: Selecione a <img class="icon-svg" src="/assets/mirror/down-arrow-9c1cf9fd152e.svg" alt="ícone de seta para baixo" height="16" width="16" data-path="images/icons/down-arrow.svg" /> seta para baixo à esquerda do nome do comando para ocultar os logs.
* **Limpar execuções anteriores**: Selecione para excluir os logs de execuções anteriores. Esta ação é irreversível.

### Disponibilidade de rede

Você pode controlar a disponibilidade online da versão de desenvolvimento do seu app.

Para parar de atender requisições à URL de desenvolvimento, selecione o ícone <img class="icon-svg" src="/assets/mirror/network-off-5bdca8a4fe4e.svg" alt="ícone de rede desativada" height="16" width="16" data-path="images/icons/network-off.svg" /> globo com barra
no lado direito da linha de informações de rede.

Para ativá-la, selecione o ícone <img class="icon-svg" src="/assets/mirror/network-on-15be2e5fb4f5.svg" alt="ícone de rede ativada" height="16" width="16" data-path="images/icons/network-on.svg" /> globo.

Para ver sua URL de desenvolvimento, selecione o texto `{...}.replit.dev` na barra de localização.

  <img src="/assets/mirror/preview-dev-url-b36770b33769.png" alt="Localização da URL de desenvolvimento no Preview" width="1222" height="824" data-path="images/workspace/preview-dev-url.png" />

<Note>
  Seu app permanece acessível na ferramenta Preview mesmo quando configurado para parar de atender requisições à URL de desenvolvimento.

### Parar um comando de workflow

Você pode parar um comando de workflow em execução a partir da ferramenta Console do Editor de Projetos.

Selecione o botão quadrado no lado direito da linha que contém o comando de execução do seu Replit App para encerrá-lo.

Para reiniciar o app, use o botão **Executar** do workflow na parte superior do Editor de Projetos.
