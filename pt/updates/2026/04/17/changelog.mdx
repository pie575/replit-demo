## Agent

### Claude Opus 4.7 alimenta o modo Power

O modo Power agora funciona com o Claude Opus 4.7 da Anthropic. Selecione **Power** no menu suspenso de modos do Agent e o Agent encaminha sua solicitação para o novo modelo automaticamente.

### Novo menu suspenso de modos do Agent

O seletor de modos do Agent na entrada do chat agora é um controle segmentado mais simples. Escolha entre Lite, Economy e Power diretamente na barra de ferramentas, e acesse o Turbo por meio das Configurações avançadas quando precisar.

Novidades:

* **Controle segmentado na barra de ferramentas.** Lite, Economy e Power ficam lado a lado, deixando óbvio em qual modo você está e como alternar.
* **Atalho de teclado.** Pressione **⌘+Shift+I** (Ctrl+Shift+I no Windows) para alternar entre modos sem usar o mouse.
* **Turbo destacado em laranja.** O Turbo é o modo mais rápido, mas custa mais, por isso se destaca na interface para manter a diferença de custo visível.
* **Configurações avançadas recolhidas por padrão.** Os controles de teste, revisão de código e Turbo ficam atrás de **Configurações avançadas** para manter a visualização principal limpa.
* **O modo Max foi descontinuado.** Use Power para as compilações mais capazes, ou ative o Turbo nas Configurações avançadas quando quiser a resposta mais rápida.

### Agent sugere tarefas de acompanhamento

<Frame>
  <video autoPlay muted loop playsInline src="/assets/mirror/replit-suggested-tasks-b27620d93fd2.mp4" />
</Frame>

O Agent agora propõe **tarefas de acompanhamento** após concluir o trabalho, usando o contexto completo do seu projeto para sugerir o que construir a seguir. Três tipos de sugestões aparecem sob cada tarefa concluída:

* **Novos recursos para construir** — funcionalidades que combinam naturalmente com o que você acabou de lançar
* **Melhorias de desempenho** — otimizações que o Agent notou ao trabalhar na tarefa
* **Melhorias de experiência do usuário** — refinamentos que completam o recurso

Revise cada sugestão, selecione **Aceitar** nas que deseja e o Agent as executa em segundo plano enquanto você continua construindo. Oculte sugestões desnecessárias com **Ocultar tarefas sugeridas** na coluna Concluído, e traga-as de volta a qualquer momento.

Saiba mais sobre [sugestões de tarefas de acompanhamento](/pt/core-concepts/agent/task-system/follow-up-tasks).

## Workspace

### Melhorias na página de Projetos

Três melhorias de qualidade de vida chegaram à página de Projetos:

* **Prévias de artifacts em cada cartão.** Cada cartão de projeto agora mostra ícones pequenos para cada artifact dentro. Passe o mouse sobre qualquer ícone para visualizar a captura de tela desse artifact sem abrir o projeto.
* **Ordenação padrão por último aberto por você.** A página agora coloca os projetos em que *você* trabalhou mais recentemente no topo, para que seu trabalho atual permaneça em destaque em workspaces de equipe movimentados.
* **Fixação pessoal.** Fixe os projetos aos quais você retorna com frequência. As fixações são privadas para você e não afetam o que outros membros do seu workspace veem.

## Equipes e Enterprise

### Grupos personalizados para organizações SCIM

Organizações com provisionamento SCIM habilitado agora podem criar grupos personalizados no Replit junto com seus grupos sincronizados pelo IdP. Use grupos personalizados para acesso baseado em projetos, concessões de permissão pontuais ou qualquer estrutura que não esteja espelhada no seu provedor de identidade.

Os grupos sincronizados por SCIM permanecem gerenciados pelo seu provedor de identidade — os grupos personalizados são gerenciados diretamente no Replit pelos administradores da organização.

Saiba mais sobre [SCIM](/pt/teams/identity-and-access-management/scim#creating-custom-groups-alongside-scim).
