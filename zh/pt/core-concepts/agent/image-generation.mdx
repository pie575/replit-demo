<div id="recursos">
  ## 功能
</div>

使用 Agent 的图像生成功能，打造视觉效果出色的应用。无需再使用图库照片、外部设计工具，或聘请设计师制作基础视觉内容。无论是创建作品集网站、开发游戏，还是设计移动应用界面，图像生成均可提供为你的项目量身定制的视觉素材。

Agent 可以执行以下图像生成操作：

* **创建自定义图像**：根据详细描述和规格生成图像
* **风格适配**：创建多种艺术风格的图像，从写实到卡通
* **项目集成**：将生成的图像直接无缝添加到应用的代码库中
* **迭代优化**：根据你的反馈修改和改进图像

<div id="uso">
  ## 使用
</div>

图像生成功能已集成到 Agent，无需额外启用。打开任意已启用 Agent 的 Replit App，让 Agent 创建你需要的视觉内容。Agent 会根据你的请求自动判断何时生成图像，并创建符合你要求的自定义图像。

<div id="melhores-prticas-para-gerao-de-imagens">
  ### 图像生成最佳实践
</div>

请遵循以下指南，以通过 Agent 获得最佳图像生成效果：

**具体且描述详尽**

* 包含风格、颜色、构图和氛围等细节
* 在适用时指定尺寸或比例
* 说明预期用途 (图标、背景、插图等)

**迭代优化**

* 从基本描述开始，并根据生成结果逐步优化
* 请 Agent 修改生成图像的特定部分
* 请求不同变体，探索不同的创意方向

**考虑项目风格**

* 在整个应用中保持视觉一致性
* 指定符合品牌或设计系统的风格偏好
* 请求能与现有视觉元素相得益彰的图像

<div id="integrao-ao-projeto">
  ### 与项目集成
</div>

Agent 可将生成的图像无缝集成到您的 代码库 中：

* **自动创建文件**：生成的图像会直接保存为项目文件
* **更新代码**：Agent 会更新您的代码，以引用新的图像文件
* **资源整理**：图像会存放在项目结构中的合理目录内

借助这一简化的工作流程，您无需离开开发环境，即可生成并使用视觉内容。
