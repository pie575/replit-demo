В итоге ваше опубликованное приложение будет ранжироваться выше в поисковых системах — и SEO Rating в инструменте Publishing это покажет.

После каждой успешной публикации Replit проводит SEO-аудит и показывает SEO Rating. Если рейтингу есть куда расти, одним кликом можно передать конкретные проблемы Agent. Для большинства разработчиков процесс сводится к следующему: **опубликовать → взглянуть на рейтинг → попросить Agent всё оптимизировать**.

Подробнее о том, как рассчитывается рейтинг (аудит Lighthouse, что означает каждое значение рейтинга, поддерживаемые развёртывания), см. в разделе [SEO Rating](/ru/features/publishing/seo-rating).

<div id="optimize-with-seo-agent">
  ## Оптимизация с помощью SEO Agent
</div>

[SEO Agent](/ru/features/publishing/seo-agent) проводит технический SEO-аудит вашего опубликованного приложения и превращает каждую найденную проблему в исправление в один клик. Он находится на панели **Growth** в Project Editor и доступен разработчикам на платном тарифе. Выполните эти шаги, чтобы просканировать приложение и применить исправления.

<Steps>
  <Step title="Опубликуйте приложение, чтобы открыть Growth">
    SEO Agent работает только с опубликованным приложением. Пока публикации нет, панель **Growth** заблокирована и предлагает перейти по кнопке **Go to Publishing**. Опубликуйте приложение из чата с Agent или через инструмент **Publishing**, затем вернитесь на панель Growth.

    <Frame caption="До публикации панель Growth заблокирована и предлагает перейти по кнопке Go to Publishing">
      <img src="/assets/mirror/01-growth-locked-b05c24711f10.png" alt="Панель Growth в заблокированном состоянии с заголовком Publish your app to unlock Growth tools и кнопкой Go to Publishing" width="1657" height="947" data-path="images/deployments/seo-agent/01-growth-locked.png" />
    </Frame>
  </Step>

  <Step title="Запустите сканирование с Agent">
    Откройте панель **Growth** и найдите карточку **SEO Rating**. Нажмите **Run scan with Agent**, чтобы запустить технический SEO-аудит вашего проекта. Сканирование обычно занимает несколько минут.

    <Frame caption="Нажмите Run scan with Agent в карточке SEO Rating, чтобы запустить аудит">
      <img src="/assets/mirror/02-run-scan-94a2b8918fe9.png" alt="Увеличенный вид карточки SEO Rating с красным прямоугольником, выделяющим кнопку Run scan with Agent" width="1656" height="946" data-path="images/deployments/seo-agent/02-run-scan.png" />
    </Frame>
  </Step>

  <Step title="Fix with Agent или Fix all with Agent">
    После завершения сканирования проблемы отображаются в таблице со столбцами **Severity** (Low, Medium или High) и **Status** (Unresolved) и сгруппированы по категориям: **AI Readiness**, **Crawlability &amp; Discovery**, **Landing Page Rendering &amp; Metadata**, **Performance Proxies** и другим. Разверните любую проблему, чтобы прочитать, что обнаружил SEO Agent.

    Применяйте исправления с любой степенью детализации:

    * **Fix with Agent** у отдельной проблемы передаёт Agent только этот пункт.
    * **Fix with Agent** у категории исправляет все проблемы этой группы.
    * **Fix all with Agent** отправляет Agent сразу все проблемы. Кнопка **Fix all issues** в чате делает то же самое.

    <Frame caption="После сканирования исправляйте проблемы по отдельности, по категориям или все сразу с помощью Fix all with Agent">
      <img src="/assets/mirror/03-fix-with-agent-c5b9e642818e.png" alt="Таблица результатов сканирования, сгруппированная по категориям, со столбцами severity и status, красным прямоугольником, выделяющим кнопку Fix all with Agent, и кнопками Fix with Agent для каждой категории" width="1657" height="947" data-path="images/deployments/seo-agent/03-fix-with-agent.png" />
    </Frame>
  </Step>

  <Step title="Agent прорабатывает исправления">
    Agent создаёт задачу на исправление для каждой проблемы и выполняет их в фоне, так что вы можете продолжать работу. Строки меняют статус на **Fix in progress**, а ссылка **Go to task** позволяет открыть любую задачу и следить за ходом работы.

    <Frame caption="Agent создаёт задачи на исправление; строки проблем показывают Fix in progress со ссылкой Go to task">
      <img src="/assets/mirror/04-fixes-in-progress-e05dd10c05b3.png" alt="Таблица результатов сканирования, где строки проблем теперь показывают статус Fix in progress и ссылки Go to task, пока Agent работает" width="1657" height="947" data-path="images/deployments/seo-agent/04-fixes-in-progress.png" />
    </Frame>
  </Step>

  <Step title="Применение изменений к основной версии">
    Когда исправление готово, задача переходит в состояние **Ready for review**. Просмотрите изменения и нажмите зелёную кнопку **Apply changes to main version**, чтобы внести исправление в приложение. Опубликуйте приложение заново, чтобы обновить SEO Rating для новой сборки.

    <Frame caption="Проверьте каждое исправление и нажмите Apply changes to main version, чтобы применить его">
      <img src="/assets/mirror/05-apply-changes-7d167b6bb93a.png" alt="Увеличенный вид нижней части задачи в состоянии Ready for review с красным прямоугольником, выделяющим зелёную кнопку Apply changes to main version" width="1656" height="946" data-path="images/deployments/seo-agent/05-apply-changes.png" />
    </Frame>
  </Step>
</Steps>

<Tip>
  Можно вообще обойтись без интерфейса сканирования. Откройте Agent и напишите **«оптимизируй
  мой SEO»** — Agent подхватит ваши последние результаты и начнёт их
  прорабатывать.
</Tip>

Типичные исправления, которые внесёт Agent:

* Добавит или перепишет отсутствующие либо шаблонные теги `<title>`, чтобы у каждой страницы был уникальный, содержательный заголовок.
* Добавит метаописание на каждую страницу.
* Добавит описательный alt-текст к изображениям.
* Задаст атрибут `lang` у элемента `<html>`.
* Проследит, чтобы у ссылок был понятный текст (без «click here» и пустых якорей).
* Добавит `robots.txt` и `sitemap.xml`.
* Добавит meta tag viewport для корректного отображения на мобильных устройствах.
* Улучшит контрастность текста, который не проходит проверки accessibility.
* Добавит meta tags Open Graph и Twitter card, чтобы ссылки на ваш App хорошо выглядели в социальных сетях.

<div id="best-practices-for-an-seo-optimized-app">
  ## Лучшие практики для приложения, оптимизированного под SEO
</div>

Независимо от того, поручите ли вы это Agent или напишете сами, вот что важнее всего сделать правильно:

* **Задайте каждой странице уникальный заголовок и метаописание.** Старайтесь укладывать заголовки в 60 символов, а описания — в 150–160 символов.
* **Используйте семантический HTML.** Оберните раскладку в `<main>`, `<header>`, `<nav>` и `<footer>`. Используйте `<h1>` один раз на страницу и не нарушайте порядок уровней заголовков.
* **Добавьте alt-текст к каждому изображению.** Опишите, что показано на изображении, а не просто что это такое.
* **Создайте `sitemap.xml` и `robots.txt`.** Попросите Agent создать оба файла, чтобы поисковые системы знали, что индексировать.
* **Добавьте теги Open Graph и Twitter card.** Так вы будете управлять тем, как ваше приложение выглядит при публикации в социальных сетях.
* **Используйте пользовательский домен.** Брендированный домен вызывает доверие и у посетителей, и у поисковых систем. См. [Добавление пользовательского домена](/ru/build/add-custom-domain).
* **Выберите подходящее развёртывание.** Для сайтов с большим объёмом контента [статические развёртывания](/ru/features/publishing/deployment-types#static) отдают заранее отрендеренный HTML, который поисковые системы разбирают мгновенно.
* **Добавьте структурированные данные.** Разметка JSON-LD помогает поисковым системам показывать расширенные результаты для продуктов, статей, FAQ и событий.
* **Следите за скоростью приложения.** Оптимизируйте изображения, избегайте скриптов, блокирующих отрисовку, и положитесь на хостинг Replit, чтобы время отклика оставалось低 низким.

Простой способ применить большинство этих рекомендаций за один раз:

<AiPrompt>
  Проведи аудит моего сайта на соответствие лучшим практикам SEO и внеси
  исправления. Добавь sitemap, robots.txt, теги Open Graph, структурированные
  данные там, где это уместно, и убедись, что у каждой страницы есть уникальный
  заголовок и метаописание.
</AiPrompt>

<div id="need-further-help">
  ## Нужна дополнительная помощь?
</div>

* **Оценка не обновилась после republish:** подождите минуту-другую — audit выполняется асинхронно, уже после того как развёртывание становится доступным, и значок обновляется по мере поступления результатов.
* **Оценка не изменилась после правок Agent:** спросите у Agent, какие именно пункты Lighthouse он исправил, а затем посмотрите во всплывающей подсказке значка, какие пункты всё ещё отмечены.
* **У некоторых страниц оценка ниже, чем у других:** значок показывает самую низкую оценку среди всех просканированных URL. Попросите Agent заняться конкретной страницей, которую отметил Lighthouse.
* **У published app нет оценки:** SEO rating рассчитывается только для публичных веб-развёртываний (Autoscale, Reserved VM, Static). Запланированные и приватные развёртывания оценку не получают.
