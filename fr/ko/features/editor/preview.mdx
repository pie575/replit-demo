title: "Preview"
description: "Découvrez comment utiliser Preview pour consulter votre application web et interagir avec elle pendant que vous la créez."
---

Preview affiche le résultat de votre application web et propose des outils de développement du navigateur ainsi que des fonctionnalités de débogage.

Lorsque vous lancez votre application web à l’aide du bouton **Run**, Replit attribue une URL temporaire
accessible sur Internet. L’outil Preview affiche la page
exactement comme elle s’affiche dans un navigateur. Il comprend également des
outils de développement similaires à ceux d’un navigateur classique.

<Note>
  Preview est le nouveau nom de Webview.
</Note>

<div id="section">
  ## Fonctionnalités
</div>

Preview propose les fonctionnalités suivantes pour tester et déboguer facilement votre application web.

* **Aperçu web en direct** : afficher votre application et interagir avec elle sans quitter l’onglet du navigateur
* **Outils de développement** : diagnostiquer rapidement les problèmes grâce aux outils intégrés
* **Tests d’affichage adaptatif** : afficher votre application dans différentes tailles d’écran d’appareils mobiles

<div id="section-2">
  ## Utilisation
</div>

L’outil Preview s’ouvre automatiquement lorsque vous exécutez une application web.
Vous pouvez activer ou désactiver ce comportement dans le paramètre **Automatic Preview** de l’outil **Paramètres utilisateur**.

Les instructions suivantes expliquent comment ouvrir Preview.

<Accordion title="Comment accéder à Preview">
  Dans le **volet d’outils** de gauche :

  1. <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Icône All tools" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> Sélectionnez **All tools** pour afficher la liste des outils du Project Editor.
  2. <img class="icon-svg" src="/assets/mirror/preview-icon-6d37238e8cc2.svg" alt="Icône Preview" width="16" height="16" data-path="images/icons/preview-icon.svg" /> Sélectionnez **Preview**.

  Dans la **barre de recherche** :

  1. Sélectionnez l’icône <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="Icône de loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> de loupe en haut pour ouvrir l’outil de recherche.
  2. Saisissez « Preview » pour trouver l’outil, puis sélectionnez-le dans les résultats de recherche.
</Accordion>

<div id="section-3">
  ## Barre d’adresse
</div>

La barre d’adresse située en haut de l’onglet **Preview** comprend les outils suivants.

* **Bouton Retour :** revenez à la page précédente dans l’historique de navigation
* **Bouton Suivant :** accédez à la page suivante dans l’historique de navigation
* **Domaine de l’application :** sélectionnez `{...}.replit.dev` pour consulter les informations sur l’URL temporaire de la Replit App
* **Champ d’adresse :** consultez le chemin d’URL actuel ou saisissez-en un nouveau

<div id="section-4">
  ## Outils du navigateur
</div>

Les outils du navigateur, situés à droite de la barre d’adresse, proposent les fonctionnalités suivantes :

* **Taille d’écran** : sélectionnez des préréglages correspondant à différentes tailles d’écran pour tester le design responsive
* **Devtools** : affichez ou masquez le panneau des [outils de développement](#Developer_tools)
* **Nouvel onglet** : ouvrez l’URL de l’application web dans un nouvel onglet du navigateur

<Note>
  **Vous créez une application mobile ?** Le panneau Preview prend également en charge les aperçus dans **iOS Simulator** ou **Android Emulator**. Pour en savoir plus, consultez [Native Mobile Apps](/fr/ko/features/artifact-types/building-mobile-apps#preview-on-a-simulator-or-emulator).
</Note>

<div id="section-5">
  ## Outils de développement
</div>

Propulsés par le projet open source <a href="https://github.com/liriliri/eruda" target="_blank">Eruda</a>, les outils de développement vous permettent d’effectuer les tâches suivantes :

* Consulter la console JavaScript et interagir avec elle dans le contexte de l’application
* Inspecter les éléments DOM
* Surveiller les requêtes réseau
* Configurer les préférences d’affichage et de comportement

Pour accéder aux outils de développement, sélectionnez le bouton <img class="icon-svg" src="/assets/mirror/wrench-7cee9d1168da.svg" alt="icône de clé" width="16" height="16" data-path="images/icons/wrench.svg" /> **Devtools**
en haut de l’onglet **Preview** pour les activer ou les désactiver.

Les sections suivantes décrivent ce que vous pouvez faire dans chaque onglet des outils de développement.

<div id="console">
  ### Console
</div>

L’onglet **Console** affiche les journaux JavaScript générés par votre application.
Dans cet onglet, vous pouvez effectuer les actions suivantes :

* **Effacer la sortie** : sélectionnez l’icône de cercle barré <img class="icon-svg" src="/assets/mirror/clear-bd1bf1847597.svg" height="16" width="16" alt="icône effacer" data-path="images/icons/clear.svg" /> pour effacer toute la sortie de la console.
* **Filtrer la sortie** : affichez la sortie de la console filtrée par type (All, Info, Warning, Error).
* **Filtrer les textes correspondants** : sélectionnez l’icône de filtre <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="icône de filtre" data-path="images/icons/filter.svg" /> et saisissez du texte pour afficher les sorties correspondantes.
* **Copier la sortie** : sélectionnez le bouton Copier <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="icône copier" data-path="images/icons/copy.svg" /> pour copier le message de console sélectionné.
* **Exécuter du code JavaScript** : sélectionnez le chevron droit <img class="icon-svg" src="/assets/mirror/arrow-right-2859a6e6bdeb.svg" height="16" width="16" alt="icône de flèche droite" data-path="images/icons/arrow-right.svg" /> pour exécuter du code JavaScript dans le contexte de l’application. Saisissez une expression, puis sélectionnez **Execute**.

<div id="elements">
  ### Elements
</div>

L’onglet **Elements** vous permet d’inspecter et de modifier la structure DOM d’une page web.

* **Afficher les détails de l’élément** : affichez les détails des éléments DOM et leur emplacement dans le code HTML
* **Copier la sortie** : sélectionnez le bouton Copier <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="icône de copie" data-path="images/icons/copy.svg" /> pour copier le message de console sélectionné.

Utilisez l’outil de sélection <img class="icon-svg" src="/assets/mirror/select-1165d9548c39.svg" height="16" width="16" alt="icône de sélection" data-path="images/icons/select.svg" /> pour passer en mode sélection.
Une fois en mode sélection, choisissez un élément sur la page web.
Le code HTML et le CSS de cet élément s’affichent dans l’onglet Elements.

<div id="network">
  ### Network
</div>

L’onglet **Network** surveille les requêtes effectuées depuis la page web.
Cet onglet permet d’effectuer les actions suivantes :

* **Suivi des requêtes** : affichez toutes les requêtes réseau effectuées par l’application. Sélectionnez une requête pour consulter ses détails.
* **Filtre** : <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="icône de filtre" data-path="images/icons/filter.svg" /> sélectionnez l’icône de filtre pour afficher les résultats correspondant au texte. Laissez le filtre vide pour le réinitialiser.
* **Copier** : <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="icône de copie" data-path="images/icons/copy.svg" /> sélectionnez le bouton Copier pour copier les informations du dépôt.

<div id="resources">
  ### Ressources
</div>

L’onglet **Ressources** affiche les ressources chargées sur la page, ainsi que le stockage du navigateur, notamment les cookies et le stockage local.
Vous pouvez consulter et actualiser la liste des types de ressources suivants :

* Fichiers JavaScript
* Feuilles de style
* Iframes
* Images

Dans cet onglet, vous pouvez effectuer les actions suivantes :

* **Afficher le stockage :** examinez le stockage local, le stockage de session et les cookies.
* **Filtrer :** <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="icône de filtre" data-path="images/icons/filter.svg" /> sélectionnez l’icône de filtre pour afficher les résultats correspondant au texte. Videz le filtre pour le réinitialiser.
* **Effacer :** <img class="icon-svg" src="/assets/mirror/clear-bd1bf1847597.svg" height="16" width="16" alt="icône d’effacement" data-path="images/icons/clear.svg" /> sélectionnez le bouton Effacer pour supprimer toutes les données de ce type de stockage.
* **Supprimer l’élément sélectionné :** <img class="icon-svg" src="/assets/mirror/delete-a21eb49cac3c.svg" height="16" width="16" alt="icône de suppression" data-path="images/icons/delete.svg" /> sélectionnez l’icône « X » pour supprimer l’élément de stockage.
* **Copier :** <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="icône de copie" data-path="images/icons/copy.svg" /> sélectionnez le bouton Copier pour copier les informations de stockage.

<div id="settings">
  ### Paramètres
</div>

L’onglet **Paramètres** permet de personnaliser l’apparence et le comportement des outils de développement.
Il comprend des options de personnalisation pour les éléments suivants :

* **Paramètres des outils** : personnaliser les options appliquées à chaque onglet d’outil
* **Contrôles JavaScript** : définir les options de comportement de JavaScript, par exemple le désactiver pour tester le fonctionnement de l’application sans JavaScript
* **Préférences d’affichage** : modifier le thème, la taille des panneaux, la transparence et d’autres comportements des outils de développement
