<div id="verificao-de-segurana-enquanto-voc-constri">
  ### Проверка безопасности во время разработки
</div>

Теперь Agent проверяет изменяемые файлы на типичные проблемы безопасности в рамках code review. Эта автоматическая проверка на базе Semgrep выявляет опасные паттерны и секреты, зашитые прямо в код, чтобы Agent мог устранить наиболее вероятные проблемы ещё до завершения задачи.

Подробнее — в разделе [Проверка безопасности во время разработки](/ru/pt/features/security/project-security-center#security-scan-while-you-build).

<div id="regenere-as-credenciais-do-banco-de-dados-de-produo">
  ### Перевыпуск учётных данных production-базы данных
</div>

Теперь учётные данные подходящей production-базы данных можно перевыпустить прямо в инструменте **Database**. Replit обновит учётные данные и, если у приложения есть активное поддерживаемое развёртывание, запустит новое развёртывание, чтобы приложение продолжило работать с новыми данными. Не забудьте обновить все внешние инструменты, которые используют прежнюю строку подключения.

<div id="construa-com-sso">
  ### Создавайте с SSO
</div>

Теперь создатели на плане Pro могут настроить корпоративный SSO для Replit App с [Clerk Auth](/ru/pt/features/auth-and-identity/clerk-auth). Попросите Agent внести нужные изменения в аутентификацию — и он направит вас в Clerk Dashboard. Там подключите Okta или Microsoft Entra ID по OIDC или SAML. Подключения корпоративного SSO бесплатны до 1 октября 2026 года. После этой даты будет применяться тариф Clerk без наценки. Поддержка для Enterprise появится в ближайшее время.

<div id="mova-projetos-entre-workspaces">
  ### Перемещение проектов между workspace
</div>

Теперь проект можно переместить из одного командного workspace в другой в рамках одной платёжной учётной записи — прямо из списка **Projects**. Перенос выполняется в фоновом режиме, отменить его нельзя. Linked Account Secrets не переносятся вместе с проектом, поэтому свяжите их заново в целевом workspace.
