export const YouTubeEmbed = ({videoId, title = "Vidéo YouTube", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

<div id="agent-3-launch">
  ## Lancement d’Agent 3
</div>

Cette semaine, nous avons lancé Agent 3.

<YouTubeEmbed videoId="4FxNXFOdt6w" title="Diffusion en direct du lancement d’Agent 3" />

Agent 3 apporte des améliorations majeures en matière d’autonomie, de fiabilité et de rapidité :

* **App Testing** : Agent teste lui-même l’application dans un navigateur réel, détecte les problèmes et les corrige dans une boucle de réflexion. Consultez [App Testing](/fr/core-concepts/agent/app-testing).
* **Durée d’exécution prolongée** : Agent peut travailler de manière autonome pendant jusqu’à 200 minutes avec Live Monitoring, ce qui est idéal pour les projets de plus grande envergure. Pour en savoir plus, consultez [Agent](/fr/core-concepts/agent#max-autonomy).
* **Génération d’agents** : créez des agents et des automatisations qui s’exécutent selon une planification ou s’intègrent à Slack et Telegram. Consultez [Agents et automatisations](/fr/core-concepts/agent/agents-and-automations).

<div id="app-connectors-and-integrations">
  ## Connecteurs et intégrations pour les apps
</div>

Déployez plus rapidement grâce aux intégrations et connecteurs intégrés :

* **Gérées par Replit** : des intégrations intégrées qui fonctionnent automatiquement dans vos apps.
* **Connectors** : des intégrations propriétaires auxquelles vous pouvez vous connecter une seule fois et réutiliser dans toutes vos apps.
* **Intégrations externes** : des services tiers de confiance configurés par Agent à l’aide de vos clés API.

<div id="agents-automations-beta">
  ## Agents et automatisations (bêta)
</div>

Créez des agents intelligents, des chatbots et des workflows automatisés avec Agent 3 :

* **Agent Slack** : créez des bots Slack pour la recherche, les questions-réponses et l’automatisation
* **Agent Telegram** : créez des bots pour la planification, l’assistance et bien plus encore
* **Automatisation planifiée** : exécutez des workflows selon une fréquence définie
