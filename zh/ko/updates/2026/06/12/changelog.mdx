<div id="agent-2">
  ### 使用工作区指令和技能自定义 Agent
</div>

现在，只需向 Agent 说明一次团队的工作方式，即可在所有场景中生效。你可以设置 Agent 在所有项目中都会遵循的**自定义指令**，并创建可复用的**技能**，供 Agent 在处理特定任务时按需加载。两者均在**工作区设置** &gt; **自定义**中管理。

<div id="package-firewall">
  ### 使用 Package Firewall 拦截恶意软件包
</div>

Replit 现在会在恶意或已被污染的软件包进入应用之前将其拦截。Package Firewall 会检查通过常见包管理器进行的所有安装，并自动阻止有害依赖项。该功能默认启用；当某个软件包被拦截时，Agent 会调整方案，改用更安全的替代方案。

</Frame>

<div id="section-4">
  ### 幻灯片导入与导出更快了
</div>

PowerPoint 和 Google Slides 导出速度提升了 3~10 倍，图片较多的大型演示文稿不再生成体积过大的 PDF 文件，只需点选一次即可直接进入 Google Slides 导出。

<div id="canvas">
  ### 在 Canvas 中生成媒体时添加视觉参考
</div>

在 Canvas 中生成图像、视频或矢量图形时，现在可以将画板上已有的内容附加为视觉参考。选中 frame、便签或图像后，Agent 会据此引导生成结果，让生成的媒体与项目的视觉风格保持一致。

<Frame caption="打开媒体生成表单中的 + 菜单，上传文件或选择画布元素。">
  <img src="/assets/mirror/canvas-generate-media-references-ac0cb4340acb.png" alt="Canvas 的媒体生成表单中打开了加号菜单，显示上传文件和选择画布元素的选项，以及设置为 Nano Banana Pro 的模型下拉菜单" width="1134" height="662" data-path="images/replitai/canvas-generate-media-references.png" />
</Frame>

<Note>
  ChatGPT Images 2.0 目前不支持上传。如需附加视觉参考，请切换模型，例如改用 Nano Banana Pro。
</Note>

详细了解[在 Canvas 中生成媒体](/zh/ko/design/toolbar#generate)。

  ## 安全

<div id="section-6">
  ### 选择哪些生产提醒进入你的收件箱
</div>

现在,你可以单独控制生产提醒,不再与其他邮件混在一起。新增的**生产提醒**设置决定 Replit 是否就服务中断事件、依赖项中的安全漏洞以及语言模型更新向你发送邮件。如果已发布的应用使用了过时的模型,Replit 还会预先准备好草稿任务,让你只需一次审核即可完成升级。

<Frame caption="在“设置 → 个人设置 → 邮件”中找到生产提醒。">
  <img src="/assets/mirror/production-alerts-settings-333bb4ee8a61.png" alt="通知设置中的生产提醒部分,其中生产提醒邮件开关已开启,安全提醒严重程度下拉菜单处于展开状态" width="2000" height="899" data-path="images/editor/production-alerts-settings.png" />
</Frame>

进一步了解[通知设置](/zh/ko/features/editor/user-settings#notifications)。
