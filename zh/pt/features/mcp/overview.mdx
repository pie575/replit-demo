Replit Agent 通过 [Model Context Protocol (MCP)](https://modelcontextprotocol.io) (一种面向 AI 集成的开放标准) 连接外部工具和数据源。下列每个服务器均可一键安装——安装后，Agent 会自动加载其中的工具，并在合适的时机调用。

如需了解相关概念，请参阅 [Model Context Protocol](/zh/pt/learn/model-context-protocol)。如需实操指南，请参阅[通过 MCP 连接](/zh/pt/build/connect-via-mcp)。若要连接此处未列出的服务器，请参阅[添加自定义 MCP 服务器](/zh/pt/build/connect-via-mcp#add-a-custom-mcp-server)。

<Info>
  选择 **Add to Replit** 即可安装任意服务器。系统会提示你在项目编辑器中授权此连接。
</Info>

<div id="protees-de-segurana">
  ## 安全防护
</div>

所有 MCP 流量都会经过 Replit 的安全扫描器。扫描器会评估工具定义和计划执行的操作，在可疑或不安全的工具运行前将其拦截。如果某个工具被拒绝，Agent 会告知你。

<div id="opes-de-autenticao">
  ## 身份验证选项
</div>

* **OAuth 动态客户端注册** — 如果服务器支持 OAuth DCR，Replit 会自动检测并为你完成客户端注册。大多数预置服务器都采用此流程。
* **自定义标头** — 设置一个或多个标头名称/值对 (例如 `X-API-Key`) 。Replit 会在每个 MCP 请求中带上这些标头，以便你的服务器验证调用方身份。如果你添加的自定义服务器通过静态令牌进行身份验证，请使用此方式。

<div id="compartilhe-seu-prprio-link-de-instalao">
  ## 分享你自己的安装链接
</div>

安装链接可让用户一键将你的 MCP 服务器添加到 Replit。你可以用[通过 MCP 连接](/zh/pt/build/connect-via-mcp#share-an-install-link)中的表单生成一个，也可以自行创建：将 JSON 负载进行 base64 编码，然后附加到 `https://replit.com/integrations?mcp=` 后面。

```json theme={null}
{
  "displayName": "My MCP Server",
  "baseUrl": "https://example.com/mcp",
  "headers": [{ "key": "Authorization", "value": "Bearer your-token" }]
}
```

* **displayName** — 安装过程中显示的名称
* **baseUrl** — MCP 服务器的 HTTPS 端点
* **headers** — 可选的身份验证请求头
