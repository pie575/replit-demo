项目编辑器中的用户设置工具可让你自定义账户的外观、行为和键盘快捷键。

<Frame>
  <img src="/assets/mirror/user-settings-tool-faae3afb911b.png" alt="用户设置工具截图" width="4152" height="1894" data-path="images/workspace/user-settings-tool.png" />
</Frame>

<div id="funcionalidades">
  ## 功能
</div>

您可以通过以下设置类别自定义 Replit App 构建体验：

* **主题自定义**：为项目编辑器选择浅色或深色主题
* **代码智能**：配置可提升应用构建体验的 AI 功能
* **编辑器偏好设置**：调整文件编辑器的行为和显示方式
* **通知控制**：管理提醒偏好设置
* **无障碍选项**：让 Replit 更好地满足有特定需求的用户
* **键盘快捷键**：设置按键组合，以执行常用操作并在界面中导航

<div id="uso">
  ## 使用
</div>

<Accordion title="如何访问用户设置">
  在左侧的**工具栏**中：

  1. 选择 <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="所有工具图标" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **所有工具**，查看项目编辑器的工具列表。
  2. 选择 <img class="icon-svg" src="/assets/mirror/settings-icon-c2664c3691bf.svg" alt="设置图标" width="16" height="16" data-path="images/icons/settings-icon.svg" /> **用户设置**。

  在**搜索栏**中：

  1. 选择顶部的 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 放大镜图标，打开搜索工具。
  2. 输入“User Settings”查找该工具，然后从搜索结果中选择它。
</Accordion>

<div id="aparncia">
  ### 外观
</div>

自定义以下与项目编辑器外观相关的设置：

* **选择主题**：可从预设的浅色和深色主题、<a href="https://replit.com/themes" target="_blank">社区主题</a>或自定义主题中选择
* **自定义主题**：使用[主题](/zh/pt/core-concepts/project-editor/editor-and-tools/themes)编辑器创建自定义配色方案

<div id="preferncias-do-editor-de-arquivos">
  ### 文件编辑器偏好设置
</div>

使用以下设置控制文件编辑器的外观和行为：

* **字体大小**：调整文本大小以提高可读性
* **自动闭合括号**：输入左括号时自动插入右括号
* **缩进检测**：打开文件时自动检测缩进设置
* **格式化粘贴文本的缩进**：重新格式化粘贴的代码，使其遵循正确的缩进
* **缩进字符**：选择使用空格还是制表符缩进代码
* **缩进大小**：设置每个缩进级别的列数
* **自动换行**：配置自动换行行为
* **代码缩略图**：在侧边栏中显示可导航的代码概览
* **多选修饰键**：设置用于选择多个文件的键盘修饰键
* **文件树中的 Git 状态**：在文件树中显示 Git 状态指示器

<div id="inteligncia-de-cdigo">
  ### 代码智能
</div>

使用以下设置配置 AI 工具：

* **语义令牌**：使用语言服务器增强的语法高亮
* **AI 代码补全**：在您输入时提供内联代码建议
* **输入确认字符时接受建议**：输入特定字符时自动接受代码建议

<div id="preferncias-de-shell-e-preview">
  ### Shell 和 Preview 偏好设置
</div>

自定义 Shell 和 Preview 工具的行为：

* **Shell 声音提示**：当 Shell 工具遇到问题时播放提示音
* **自动打开 Preview**：服务器可用时自动打开 Preview 标签页
* **自动转发开放端口**：配置如何处理新检测到的端口

<div id="notificaes">
  ### 通知
</div>

管理以下通知设置：

* **Agent 声音通知**：当 Agent 请求反馈时播放提示音
* **Agent 推送通知**：当 Agent 请求反馈时在手机上接收推送通知

<div id="acessibilidade">
  ### 无障碍功能
</div>

您可以自定义以下无障碍设置：

* **无障碍终端输出**：为 Shell 和控制台启用屏幕阅读器支持

<div id="atalhos-de-teclado">
  ### 键盘快捷键
</div>

要访问键盘快捷键偏好设置，请在“用户设置”工具中选择 **键盘快捷键** 选项卡。

您可以通过以下方式搜索按键组合：

* **名称**：在搜索框中输入键盘快捷键的名称或描述
* **按键组合**：选择 <img class="icon-svg" src="/assets/mirror/keyboard-7ba19771b671.svg" alt="键盘图标" width="16" height="16" data-path="images/icons/keyboard.svg" /> 并输入按键组合

使用以下操作管理快捷键：

* **添加**：选择 **添加快捷键**
* **更新**：选择 <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="铅笔图标" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> 铅笔图标
* **移除**：选择 <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="垃圾桶图标" width="16" height="16" data-path="images/icons/trash-icon.svg" /> 垃圾桶图标
