Les connecteurs d'entrepôt permettent à Replit Agent d'interroger en toute sécurité les entrepôts de données de votre organisation. Les créateurs utilisent le langage naturel pour créer des tableaux de bord, des outils de reporting et des applications de données — aucune expertise SQL requise. Les administrateurs conservent un contrôle centralisé grâce aux accès basés sur les rôles.

## Entrepôts pris en charge

Les connecteurs d'entrepôt sont disponibles sur les plans **Enterprise**.

| Entrepôt         | Guide de configuration                                                                                                   |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------ |
| BigQuery         | Disponible dès maintenant — guide de configuration en cours                                                              |
| Databricks       | [Connecter Databricks](/fr/connectors/warehouses/databricks)                                                             |
| Microsoft Fabric | [Créer des applications de données sur Microsoft Fabric](/fr/connectors/warehouses/microsoft-fabric) (préversion privée) |
| Snowflake        | [Connecter Snowflake](/fr/connectors/warehouses/snowflake)                                                               |

Chaque entrepôt possède son propre flux de configuration car l'intégration OAuth, le modèle d'identité et le format des identifiants diffèrent. Choisissez l'entrepôt que vous utilisez et suivez son guide dédié.

## Plateformes d'analyse et de données

Les connecteurs d'analyse sont disponibles sur les plans Core et Pro ainsi que Enterprise. Connectez vos outils d'analyse pour qu'Agent puisse lire et travailler avec les données de votre produit :

* **Segment** — Données clients, flux d'événements et segments d'audience depuis votre CDP
* **Amplitude** — Analyse produit, données comportementales des utilisateurs et métriques d'engagement
* **Hex** — Notebooks de données collaboratifs et résultats de requêtes

Gérez-les de la même manière que les autres connecteurs Replit. Consultez [Gestion de vos connecteurs](/fr/replitai/managing-connectors).

## Fonctionnement des connecteurs d'entrepôt

La configuration est un processus unique impliquant trois rôles :

1. **Administrateur d'entrepôt** — Crée une intégration OAuth ou une identité de service dans l'entrepôt
2. **Administrateur d'organisation Replit** — Ajoute les identifiants à Replit et configure l'accès
3. **Créateur** — Se connecte et commence à créer avec Agent

Une fois configuré, les créateurs demandent à Agent d'utiliser l'entrepôt et Agent écrit et exécute du SQL contre celui-ci.

### Créer avec des données d'entrepôt

Après la connexion, vous pouvez demander à Agent de créer des applications qui utilisent vos données. Agent peut :

* Créer des outils internes qui récupèrent et affichent des données en direct
* Créer des tableaux de bord avec des graphiques et des visualisations alimentés par votre entrepôt
* Générer des requêtes SQL pour alimenter le backend de votre application
* Expliquer les structures de schéma et de table pour vous aider à comprendre quoi créer

<Note>
  Bien qu'Agent puisse répondre à des questions ponctuelles sur vos données, l'objectif principal des connecteurs d'entrepôt est de permettre à Agent de créer des applications fonctionnelles qui exploitent les données de votre organisation. Les requêtes d'entrepôt sont exécutées directement sur votre instance, assurez-vous donc que vos portées OAuth et les permissions de votre utilisateur de base de données permettent les opérations de lecture et d'écriture nécessaires.
</Note>
