Выберите, где размещается инфраструктура вашего workspace и опубликованного App, чтобы обеспечить резидентность данных и снизить задержки. Replit предлагает раздельные настройки географии, поэтому расположением среды разработки и опубликованного App можно управлять независимо друг от друга.

<div id="compare-a-geografia-do-workspace-e-a-de-publicao">
  ## Сравнение географии workspace и региона публикации
</div>

| Аспект                    | География workspace                         | Регион публикации                                      |
| :------------------------ | :------------------------------------------ | :----------------------------------------------------- |
| **Что определяет**        | Ресурсы разработки в workspace              | Вычисления и хранилище опубликованного App             |
| **Задаётся при**          | Создании workspace                          | Публикации проекта                                     |
| **Влияние на размещение** | Задаёт регион для новых проектов и ресурсов | Размещает все опубликованные артефакты в одном регионе |
| **Можно изменить позже**  | Нет                                         | Нет                                                    |

География workspace и регион публикации не обязаны совпадать.

Подробнее о выборе региона разработки при создании Workspace см. в разделе [География workspace](/ru/pt/features/collaboration/workspace-geography).

<div id="geografia-de-publicao">
  ## Регион публикации
</div>

Указывайте регион публикации при публикации проекта. По умолчанию Replit рекомендует ближайший к вам регион. Это помогает снизить задержку для посетителей вашего App и соблюсти требования к резидентности данных.

При выборе региона все опубликованные артефакты проекта (вычислительные ресурсы, база данных, Object Storage) автоматически размещаются в этом же регионе. Кроме того, снизить задержку для посетителей вашего App помогает прокси, привязанный к выбранному региону.

<div id="selecione-uma-geografia-de-publicao">
  ### Выберите регион публикации
</div>

Чтобы выбрать регион, отличный от рекомендованного:

<Steps>
  <Step>
    Откройте инструмент **Publishing** в своём проекте Replit.
  </Step>

  <Step>
    Разверните настройки **Advanced**.
  </Step>

  <Step>
    Выберите нужный регион в выпадающем меню **Geography**.
  </Step>

  <Step>
    Нажмите **Publish**, чтобы опубликовать проект в выбранном регионе.
  </Step>
</Steps>

<div id="imponha-uma-geografia-em-projetos-publicados">
  ### Установите обязательный регион публикации для проектов
</div>

Администраторы Enterprise могут задать обязательный регион публикации для всех проектов организации. Когда такая политика задана, разработчики организации публикуют проекты в указанном регионе. Политика применяется только к проектам, которые ещё не были опубликованы: проекты, уже опубликованные в другом регионе, она не затрагивает.

<Note>
  Обязательный регион публикации — это возможность Enterprise. Подробнее о тарифах Enterprise см. на странице [Цены](https://replit.com/pricing/).
</Note>

<Steps>
  <Step>
    Откройте свои **Account settings**.
  </Step>

  <Step>
    Выберите **Advanced**.
  </Step>

  <Step>
    Выберите регион, который будут использовать все проекты при первой публикации.
  </Step>
</Steps>

<div id="limitaes-da-geografia-de-publicao">
  ### Ограничения региона публикации
</div>

Прежде чем выбрать регион публикации, учтите следующие ограничения:

* **После публикации регион изменить нельзя.** Как только проект опубликован в определённом регионе, этот выбор становится окончательным. Перенести опубликованный проект в другой регион невозможно.
* **Регионы разработки и публикации могут различаться.** Такие ресурсы, как Object Storage, могут быть созданы до публикации и не совпадать с вашим регионом публикации.

<div id="geografias-disponveis">
  ## Доступные регионы
</div>

Для workspace и публикаций доступны разные регионы:

| География            | Выбор в workspace | Выбор при публикации |
| :------------------- | :---------------- | :------------------- |
| **Северная Америка** | Да                | Да                   |
| **Европа (ЕС)**      | Да                | Да                   |
| **Азия**             | Да                | Да                   |
| **Южная Америка**    | Нет               | Да                   |
| **Австралия**        | Нет               | Да                   |

<Note>
  Выбор географии workspace доступен только клиентам Pro.
  Выбор региона публикации доступен клиентам Core, Pro и Enterprise.
  Клиенты Free по умолчанию публикуют приложения в Северной Америке.
</Note>
