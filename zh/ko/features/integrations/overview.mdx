Agent 支持四类集成，助您快速将创意变成应用。

* **Replit 托管**：自动运行的内置集成。创建应用后，Agent 可立即使用。
* **Connectors**：由 Replit 支持的第一方集成。您只需登录一次。Agent 可以直接在聊天中读取和写入这些服务的数据，例如获取数据、创建记录和发送消息，并利用这些服务构建多个应用。
* **外部集成 (External integrations)&#x20;**：可协同构建的可信第三方服务。让 Agent 进行设置，然后提供您的 API 密钥。
* **Agent 服务 (Agent services)&#x20;**：Agent 在后台使用的付费第三方 API，无需 API 密钥。费用将从您的 Replit 积分中扣除。

<Note>
  **各套餐的可用性**：大多数连接器需要 Core、Pro 或 Enterprise 订阅，部分也可在 Free 套餐中使用。您可以在工作区的连接器目录中查看当前套餐可用的连接器。Free 套餐的构建者可随时使用数据库、身份验证等 Replit 托管集成。
</Note>

<div id="section">
  ## 开始使用
</div>

要使用集成功能，只需说明你需要的服务或功能即可。例如：

<AiPrompt>
  帮我创建一个网页应用，用 Stripe 收款，并通过 SendGrid 发送确认邮件
</AiPrompt>

Agent 会自动识别这些关键词，并实现相应的代码和配置。

<div id="agent">
  ### 让 Agent 推荐连接器
</div>

有时候，保存文件或发送邮件等操作可以由多个服务来完成。如果你在请求某项功能时没有指定提供商，Agent 会简要列出适用的连接器，你从中选择需要的即可。

选择提供商后，只需登录一次即可关联账户。Agent 会在构建过程中使用你选定的服务。如果想跳过选择列表，也可以直接指定某个服务的名称。

</div>

<div id="replit-oauth">
  ### 在 Replit 中配置 OAuth 应用
</div>

<Note>
  **Enterprise 专属**：配置自定义 OAuth 应用需要 Enterprise 订阅。
</Note>

在 Enterprise 套餐中，你可以为连接器自带 OAuth 应用，而不使用 Replit 的默认配置。这样，组织便可自行持有 OAuth 客户端、在授权页面上展示自有品牌，并精确控制构建者可请求的作用域。

要使用自有 OAuth 应用配置连接器，你需要从提供商获取三样内容：**Client ID**、**Client Secret**，以及你希望授权的**作用域 (scopes) **。此外，还需在提供商处注册 Replit 的回调 URL，才能完成认证。

<Frame>
  <img src="/assets/mirror/connector-oauth-configuration-100911ce0c48.png" alt="连接器 OAuth 配置对话框，包含 Client ID、Client Secret、Connector Scopes 输入框，以及设置为 https://replit.com/connectors/oauth/callback 的 Redirect URL" width="1112" height="1218" data-path="images/replitai/connector-oauth-configuration.png" />
</Frame>

<Steps>
  <Step title="在提供商处创建 OAuth 应用">
    登录提供商的开发者控制台或管理员设置，创建一个新的 OAuth 2.0 应用。不同提供商对该步骤的叫法各不相同 —— 请查找类似 **Create OAuth app**、**Register application**、**Create client credentials** 的选项。
  </Step>

  <Step title="设置重定向 URL">
    当提供商要求填写 **Authorized redirect URI** (有时也称为 **Callback URL** 或 **Redirect URL**) 时，请输入以下内容。

    ```
    https://replit.com/connectors/oauth/callback
    ```

    构建者授权应用后，提供商会通过该 URL 将其送回 Replit。此地址必须完全一致 —— 尾部斜杠、协议、子域名都不能有出入。如果你添加了多个重定向 URI，务必包含此 URL。
  </Step>

  <Step title="复制 Client ID 和 Client Secret">
    创建应用后，提供商会显示 **Client ID** 和 **Client Secret**。

    * **Client ID**：OAuth 应用的公开标识符，可以安全地出现在 URL 或客户端代码中。
    * **Client Secret**：用于证明请求来自你的应用的机密值。请像对待密码一样对待它 —— 切勿提交到代码仓库或公开分享。Replit 会安全地存储它。

    部分提供商只在创建时显示一次客户端密钥。请立即复制，并妥善保管，直到粘贴到 Replit 中为止。
  </Step>

  <Step title="选择作用域">
    **作用域 (Scopes) **用于定义 OAuth 应用可以代表构建者读取或写入的权限范围。各提供商都会在其 API 文档中公布自己的作用域列表。

    在 Replit 中配置连接器时填写的作用域，必须与你在提供商处注册的作用域**完全一致** (逐字符一致，包括 URL 前缀) 。导致不匹配错误的常见原因如下。

    * 缺少完整的 URL 前缀 (例如使用 `drive.file` 而非 `https://www.googleapis.com/auth/drive.file`) 。
    * 多余的空格或尾部逗号。
    * 在 Replit 中请求了未在提供商应用中启用的作用域。

    建议先从构建者所需的最小作用域开始，之后按需添加 —— 大多数提供商都允许在不重新创建应用的情况下更新作用域。
  </Step>

  <Step title="在 Replit 中配置连接器">
    在组织的 **Connectors** 页面选择 **Add new integration**，选定服务后，粘贴你从提供商获取的 **Client ID**、**Client Secret** 和 **Scopes**，然后选择 **Configure** 保存。
  </Step>
</Steps>

<Note>
  如果配置后认证失败，请再次检查提供商的重定向 URL 是否与 `https://replit.com/connectors/oauth/callback` 完全一致，并确认你在 Replit 中填写的所有作用域也已在提供商的应用中获得授权。
</Note>

  ## 重新连接集成

<div id="section-10">
  ## 连接器调试
</div>

连接服务时遇到问题？以下指南介绍了常见错误及其解决方法。

<AccordionGroup>
  <Accordion title="Google Workspace: &#x22;此应用被阻止&#x22;">
    连接 Google Drive、Docs、Sheets、Calendar 或 Gmail 时，如果显示 **&quot;This app is blocked&quot;**，很可能是您组织的 Google Workspace 限制了第三方 OAuth 应用。请参阅完整的问题排查指南以解决此问题。

    [解决 Google 连接器的 “This app is blocked” 问题](/zh/ko/features/troubleshooting/debugging-google-connectors)
  </Accordion>

  <Accordion title="Salesforce: &#x22;连接已过期&#x22;">
    如果 Salesforce 连接器因 **&quot;Connection Expired&quot;** 错误而停止工作，很可能是您的 Salesforce 组织将刷新令牌策略配置为在一段时间后使令牌过期。请参阅完整的问题排查指南，了解如何更新 Connected App 设置。

    [解决 Salesforce 连接过期错误](/zh/ko/features/troubleshooting/debugging-salesforce-connectors)
  </Accordion>
