Для публикаций предусмотрено три типа оплаты по факту использования:

1. Передача исходящих данных
2. Вычислительные единицы с автоматическим масштабированием
3. Запросы

Просмотреть использование можно в **Настройках**: **Учётная запись** → **Использование учётной записи**. Плата взимается ежемесячно или при превышении накопленными расходами ежемесячного лимита кредитов. Пользователи Replit Core и Pro получают ежемесячные квоты на эти ресурсы.

Если вам нужны дополнительные кредиты сверх ежемесячной квоты по подписке, вы можете приобрести пакеты кредитов на странице биллинга. Подробнее о пакетах кредитов см. в разделе [Управление расходами](/ru/pt/billing/managing-spend).

<div id="publicao">
  # Публикация
</div>

<div id="1-transferncia-de-dados-de-sada-de-publicao">
  ## 1. Передача исходящих данных при публикации
</div>

Этот тип использования оплачивается за байт, при этом пользователям Replit Core и Pro предоставляются ежемесячные квоты. В квоту засчитывается только исходящий трафик, а за превышение может взиматься дополнительная плата. Входящий трафик, напротив, всегда бесплатен.

| Подписка    | Квота                                                 |
| ----------- | ----------------------------------------------------- |
| Replit Core | 100 GiB                                               |
| Replit Pro  | См. [цены Replit Pro](https://www.replit.com/pricing) |

Квоты распространяются на [статические](/ru/pt/features/publishing/deployment-types#static), [с автомасштабированием](/ru/pt/features/publishing/deployment-types#autoscale), [на выделенной ВМ](/ru/pt/features/publishing/deployment-types#reserved-vm) и [запланированные](/ru/pt/features/publishing/deployment-types#scheduled) развёртывания.

Актуальную стоимость передачи исходящих данных смотрите на [странице цен](https://www.replit.com/pricing).

***

<div id="2-unidades-de-computao">
  ## 2. Вычислительные единицы
</div>

Биллинг за развёртывания с автоматическим масштабированием рассчитывается на основе вычислительных единиц, учитывающих использование CPU и RAM с течением времени.

Биллинг за превышение лимита также рассчитывается на основе вычислительных единиц. Расчёт ведётся с точностью до отдельной вычислительной единицы. Актуальную стоимость вычислительных единиц смотрите на [странице цен](https://www.replit.com/pricing).

Ниже показано, как секунды использования RAM и CPU для развёртывания с автоматическим масштабированием преобразуются в вычислительные единицы:

| Ресурс        | Вычислительные единицы |
| ------------- | ---------------------- |
| 1 секунда RAM | 2 единицы              |
| 1 секунда CPU | 18 единиц              |

Статические развёртывания не потребляют вычислительные единицы. Биллинг за них взимается только за исходящую передачу данных сверх [указанного значения](#).

[Подробнее о развёртываниях с автоматическим масштабированием](/ru/pt/features/publishing/deployment-types#autoscale).

Развёртывания с автоматическим масштабированием также учитывают количество запросов.

<div id="bancos-de-dados">
  # Базы данных
</div>

Replit взимает плату только за использование [production-баз данных](/ru/pt/features/data-and-storage/development-and-production) — базы данных разработки всегда бесплатны и доступны во всех Replit App. Подробнее о базах данных разработки см. в разделе [База данных разработки](/ru/pt/features/data-and-storage/sql-database).

PostgreSQL от Replit — полностью управляемая бессерверная служба, обеспечивающая высокую доступность без лишних усилий и обслуживания. Биллинг production-баз данных основан на фактическом использовании, что позволяет значительно сократить расходы.

Плата за production-базы данных PostgreSQL рассчитывается по двум метрикам использования:

* **[Время вычислений](#compute-time)**: Объём вычислительных ресурсов, потребляемых за час.
* **[хранение данных](#data-storage)**: Общий объём хранимых данных, включая исторические данные.

Текущее использование ресурсов, включая использование production-базы данных, можно посмотреть в разделе **Настройки** → **Учётная запись** → **Использование учётной записи**.

<div id="tempo-de-computao">
  ## Время вычислений
</div>

Время вычислений определяется количеством часов, в течение которых ваша база данных остаётся активной в рамках расчётного периода. Базы данных считаются активными, когда получают запросы, а также в течение 5 минут после последнего запроса. Если база данных не получает запросов в течение 5 минут, она приостанавливается и переходит в неактивное состояние.

<div id="armazenamento-de-dados">
  ## Хранение данных
</div>

Хранение данных — это общий объём данных во всех базах данных вашей учётной записи, измеряемый в гибибайтах (GiB). Объём хранения рассчитывается как максимальный объём, использованный в течение месяца. Каждая база данных PostgreSQL занимает 33 МБ, даже если не содержит данных. Это стандартный объём хранилища сервера Postgres.

<Note>Общий лимит хранилища для каждой production-базы данных составляет 10 гибибайт (GiB). Для баз данных разработки предоставляется 20 GiB бесплатного хранилища на Replit App.</Note>

<div id="notas-adicionais">
  # Дополнительные примечания
</div>

Если возникнут проблемы с оплатой, мы уведомим вас. Постоянные сбои при оплате могут привести к приостановке работы ваших опубликованных App. В этом случае [обратитесь в службу поддержки](https://replit.com/help) и обновите платёжные данные, чтобы восстановить доступ к нашим сервисам.
