Les thèmes Replit vous permettent de personnaliser l&#39;apparence de l&#39;éditeur de vos projets, des couleurs d&#39;arrière-plan et des éléments d&#39;interface jusqu&#39;à la coloration syntaxique du code. Adaptez votre environnement de développement à vos préférences pour améliorer la lisibilité, réduire la fatigue oculaire et rendre l&#39;expérience de programmation plus agréable.

<div id="section">
  ## Créer un thème personnalisé
</div>

Pour créer et personnaliser votre propre thème, suivez les étapes ci-dessous :

1. Ouvrez les [paramètres](https://replit.com/settings), puis accédez à **Utilisateur** → **Personnalisation** (ou à la section **Thèmes**)
2. Sélectionnez **Créer un nouveau thème**
3. Saisissez un titre, choisissez un schéma de couleurs (clair ou sombre) et ajoutez une description (facultative)
4. Sélectionnez **Créer le thème** pour ouvrir l&#39;éditeur de thème

Les paramètres globaux du thème contrôlent l&#39;apparence générale de l&#39;interface :

* **Arrière-plan** : définit la couleur de base de la plupart des surfaces de l&#39;interface
* **Contour** : contrôle la couleur des bordures et des séparateurs
* **Premier plan** : détermine la couleur du texte et des icônes
* **Primaire** : définit la couleur des boutons et des éléments interactifs
* **Positif** : s&#39;applique aux indicateurs de réussite, comme le bouton **Exécuter**
* **Négatif** : apparaît pour les erreurs et les avertissements liés aux opérations destructrices

Sélectionnez **Appliquer le thème** pour commencer à utiliser immédiatement votre thème personnalisé.

<div id="section-2">
  ## Coloration syntaxique
</div>

Personnalisez l&#39;affichage des différents éléments de code afin d&#39;améliorer la lisibilité et la compréhension.

<Tip>
  Une coloration syntaxique bien choisie permet de parcourir et de comprendre le code d&#39;un coup d&#39;œil. Optez pour des couleurs qui s&#39;harmonisent entre elles et offrent un contraste suffisant avec l&#39;arrière-plan.
</Tip>

<Accordion title="Éléments de la coloration syntaxique">
  | Élément                     | Description                                                                        |
  | --------------------------- | ---------------------------------------------------------------------------------- |
  | **Nom de variable**         | S&#39;applique aux variables déclarées sans mot-clé de déclaration                 |
  | **Définition de variable**  | Colore les noms de variables définies avec des mots-clés comme `const` ou `var`    |
  | **Référence de fonction**   | S&#39;applique lors de l&#39;appel d&#39;une fonction                              |
  | **Définition de fonction**  | Colore le nom de la fonction lors de sa déclaration                                |
  | **Mot-clé**                 | Met en évidence les mots-clés du langage tels que `import`, `function` ou `return` |
  | **Nom de propriété**        | Colore les accès aux propriétés depuis une variable                                |
  | **Définition de propriété** | Utilisé lors de la définition des propriétés d&#39;un objet                        |
  | **Propriété de fonction**   | S&#39;applique lors de l&#39;appel d&#39;une méthode sur un objet                  |
  | **Nom de balise**           | Utilisé pour les balises HTML et JSX                                               |
  | **Nom de type**             | Colore les annotations de type dans les langages typés                             |
  | **Nom de classe**           | S&#39;applique aux déclarations et aux références de classes                       |
  | **Nom d&#39;attribut**      | Met en évidence les attributs HTML et JSX                                          |
  | **Commentaire**             | S&#39;applique à tous les commentaires de code                                     |
  | **Chaîne**                  | Colore les littéraux de chaîne                                                     |
  | **Nombre**                  | Met en évidence les valeurs numériques                                             |
  | **Booléen**                 | Met en forme les valeurs booléennes (`true`/`false`)                               |
  | **Expression régulière**    | Colore les motifs d&#39;expressions régulières                                     |
  | **Opérateur**               | Met en évidence les opérateurs tels que `+`, `-`, `*` ou `/`                       |
  | **Parenthèses**             | Colore les crochets et les chevrons le cas échéant                                 |
</Accordion>

<div id="section-3">
  ## Bonnes pratiques de conception de thèmes
</div>

Suivez les recommandations ci-dessous pour créer des thèmes à la fois esthétiques et fonctionnels :

<div id="section-4">
  ### Couleurs et contraste
</div>

* **Équilibrez le contraste** : veillez à ce que l&#39;arrière-plan et les éléments de premier plan se distinguent suffisamment
* **Créez une palette cohérente** : choisissez des couleurs qui se complètent au lieu de jurer entre elles
* **Maintenez une luminosité constante** : conservez des niveaux de luminosité similaires sur l&#39;ensemble des éléments de syntaxe
* **Concevez en pensant à l&#39;accessibilité** : évitez les combinaisons à faible contraste afin de tenir compte des utilisateurs ayant une déficience visuelle

<Warning>
  Évitez les écueils courants de la conception de thèmes :

  * Des écarts de luminosité excessifs entre les éléments de syntaxe
  * Des combinaisons de couleurs créant une dissonance visuelle
  * Un contraste insuffisant entre le code et l&#39;arrière-plan
</Warning>

<div id="section-5">
  ## Gestion des thèmes
</div>

Dans les [paramètres](https://replit.com/settings), sous **Utilisateur** → **Personnalisation** (ou la section **Thèmes**), vous pouvez consulter et gérer tous les thèmes installés.

<div id="section-6">
  ### Changer de thème
</div>

Sélectionnez le bouton situé à côté du titre du thème pour l&#39;activer en tant que thème actuel.

<div id="section-7">
  ### Modifier un thème
</div>

Pour modifier un thème personnalisé, sélectionnez le menu à trois points, puis cliquez sur **Modifier**.

<Note>
  Vous pouvez uniquement modifier ou supprimer les thèmes personnalisés que vous avez créés. Les thèmes par défaut et ceux créés par d&#39;autres utilisateurs ne peuvent pas être modifiés.
</Note>

<div id="section-8">
  ### Supprimer un thème
</div>

Pour supprimer un thème personnalisé, sélectionnez **Supprimer** dans le menu à trois points.

<div id="section-9">
  ## Explorer les thèmes de la communauté
</div>

Découvrez les thèmes créés par la communauté Replit sur la [page d&#39;exploration des thèmes](https://replit.com/themes).

<div id="section-10">
  ### Rechercher un thème
</div>

* Recherchez par nom pour trouver un thème précis, comme « Atom One Dark »
* Filtrez par auteur pour explorer les thèmes d&#39;un créateur en particulier
* Parcourez les thèmes par schéma de couleurs pour trouver un thème clair ou sombre
* Recherchez une couleur précise pour trouver un thème adapté à vos préférences

Vous pouvez prévisualiser un thème avant de l&#39;installer afin de voir son rendu dans l&#39;éditeur de votre projet.

<div id="vs-code">
  ## Migration depuis VS Code

Importez vos thèmes VS Code préférés dans Replit en faisant correspondre les couleurs équivalentes lors de la création du thème.

<div id="section-11">
  ## Publier un thème
</div>

Pour partager votre thème personnalisé avec la communauté Replit, suivez les étapes ci-dessous :

1. Ouvrez l&#39;éditeur de thème de votre thème personnalisé
2. Sélectionnez le bouton **Publier**
3. Renseignez les champs Titre et Description
4. Soumettez votre thème

Une fois publié, votre thème apparaît sur la page d&#39;exploration des thèmes, où les autres utilisateurs peuvent le prévisualiser et l&#39;installer.
