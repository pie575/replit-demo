Si vous travaillez déjà sur une application ou un projet, vous pouvez l&#39;importer dans Replit et poursuivre votre travail au sein d&#39;un projet. L&#39;importation diffère de l&#39;ajout de fichiers joints servant de référence ou de contexte à une Conversation.

<div id="section">
  ## Choisir la source adaptée
</div>

La source détermine ce que vous fournissez et la manière dont votre travail existant est importé dans Replit. Les guides d&#39;importation actuels décrivent les parcours suivants.

| Travail existant              | Source adaptée                                                                                                         |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| Dépôts et projets de builders | **GitHub**, **Bitbucket**, **Vercel**, **Bolt**, **Lovable**, **Base44** et **les anciennes exportations d&#39;Agent** |
| Designs                       | **Figma** et **Claude**                                                                                                |
| Fichiers et données locaux    | **ZIP** et **feuilles de calcul** (`.xlsx`, `.csv` ou une URL Google Sheets publiée)                                   |

Les importations depuis certains builders reposent sur un dépôt GitHub exporté depuis le service d&#39;origine. Avant d&#39;importer, consultez le guide propre à chaque source. Les configurations, les secrets, les valeurs de base de données ou les services spécifiques à un fournisseur peuvent nécessiter un paramétrage supplémentaire par la suite.

Depuis le champ de saisie des prompts, ouvrez le menu **Plus**, puis sélectionnez **Importer un projet existant** pour lancer le processus d&#39;importation.

<div id="section-2">
  ## Importer ou joindre ?
</div>

* **Importez un projet** lorsque vous souhaitez poursuivre votre travail à partir de code, de designs ou de projets structurés existants.
* **Téléversez un fichier** lorsqu&#39;un document, une feuille de calcul, une image ou une capture d&#39;écran sert de contexte à une question ou à une tâche dans la Conversation en cours.

Pour ce second cas, consultez [Téléverser et utiliser des fichiers](/fr/ja/chat/upload-and-use-files).
