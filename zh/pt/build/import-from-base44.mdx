<div id="importar-do-base44">
  ## 从 Base44 导入
</div>

⏰ *预计用时：四分钟*

先将 Base44 项目导出到 GitHub，再导入该仓库，即可将项目导入 Replit。

如需了解更全面的导入选项，包括 GitHub、Figma 和 Lovable 等其他平台，请参阅[导入功能文档](/zh/pt/references/workspace/import)。

<div id="antes-de-comear">
  ## 开始前准备
</div>

* 可导出的 Base44 项目
* 已关联 Base44 的 GitHub 帐户
* Replit 帐户

<div id="etapas-de-importao">
  ## 导入步骤
</div>

1. 将项目从 Base44 导出到 GitHub。
2. 打开 [replit.com/import](https://replit.com/import)。
3. 选择 **Base44**。
4. 关联您的 GitHub 帐户。
5. 选择从 Base44 导出的仓库。
6. 选择 **Import**。

<div id="what-gets-imported">
  ## 导入内容
</div>

Replit 会从你的 {platform_1} 项目中导入以下内容：

* **代码**：应用逻辑和源文件
* **设计和样式**：界面组件和样式规则
* **资源**：图片、图标和静态文件
* **后端逻辑**：服务器端功能 (如有)
* **数据库架构**：表结构 (如有)

<div id="what-is-not-imported">
  ## 不会导入的内容
</div>

* **Supabase 数据**：现有数据库记录不会迁移
* **Secrets**：环境变量和 API 密钥需要单独添加

使用 Agent 重建缺失的功能、添加 Secrets，并重新创建数据库数据。
