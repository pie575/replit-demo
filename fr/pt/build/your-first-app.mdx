export const PromptActions = ({prompt = "", campaign = "docs-prompt-actions"}) => {
  const LZ_SRC = "https://cdnjs.cloudflare.com/ajax/libs/lz-string/1.5.0/lz-string.min.js";
  const ensureLZString = () => {
    if (typeof document === "undefined") return;
    if (window.LZString) return;
    if (document.querySelector(`script[src="${LZ_SRC}"]`)) return;
    const s = document.createElement("script");
    s.src = LZ_SRC;
    s.async = true;
    document.head.appendChild(s);
  };
  const handleCopy = async e => {
    const btn = e.currentTarget;
    if (!prompt) return;
    try {
      await navigator.clipboard.writeText(prompt);
    } catch {
      const ta = document.createElement("textarea");
      ta.value = prompt;
      document.body.appendChild(ta);
      ta.select();
      try {
        document.execCommand("copy");
      } catch {}
      document.body.removeChild(ta);
    }
    const original = btn.dataset.label || btn.innerText;
    btn.dataset.label = original;
    btn.innerText = "Copié !";
    setTimeout(() => {
      if (btn.isConnected) btn.innerText = original;
    }, 1500);
  };
  const handleBuild = () => {
    if (!prompt || typeof window === "undefined") return;
    const utm = `utm_source=replit-docs&utm_medium=docs&utm_campaign=${encodeURIComponent(campaign)}&utm_content=prompt-actions`;
    let url;
    if (window.LZString) {
      const encoded = window.LZString.compressToEncodedURIComponent(prompt);
      url = `https://replit.com/?prompt=${encoded}&referrer=replit-docs&${utm}`;
    } else {
      url = `https://replit.com/?prompt=${encodeURIComponent(prompt)}&referrer=replit-docs&${utm}`;
    }
    window.open(url, "_blank", "noopener,noreferrer");
  };
  ensureLZString();
  const baseButtonStyle = {
    display: "inline-flex",
    alignItems: "center",
    gap: "6px",
    padding: "8px 16px",
    borderRadius: "8px",
    fontSize: "14px",
    fontWeight: 500,
    cursor: "pointer",
    lineHeight: 1.2,
    fontFamily: "inherit",
    textDecoration: "none"
  };
  return <div style={{
    display: "flex",
    gap: "12px",
    margin: "16px 0",
    flexWrap: "wrap",
    alignItems: "center"
  }}>
      <button type="button" onClick={handleCopy} style={{
    ...baseButtonStyle,
    background: "transparent",
    color: "inherit",
    border: "1px solid rgba(127,127,127,0.4)"
  }}>
        Copier le prompt
      </button>
      <button type="button" onClick={handleBuild} style={{
    ...baseButtonStyle,
    background: "#F26207",
    color: "#FFFFFF",
    border: "1px solid #F26207"
  }}>
        Build sur Replit ↗
      </button>
    </div>;
};

export const GATHER_PROMPT = `Créez une application responsive de découverte d'ateliers appelée Gather.

Les visiteurs doivent pouvoir parcourir les ateliers à venir, consulter les détails des événements et confirmer leur participation à l'aide de données d'exemple réalistes.

L'application est réussie si la navigation fonctionne, si la confirmation de participation affiche un message clair et si la mise en page s'affiche correctement sur mobile comme sur ordinateur.

N'ajoutez pas encore de connexion, de base de données, de paiements ni d'intégrations externes.`;

⏰ *Durée estimée : 10 minutes*

À la fin de ce guide, vous aurez créé puis amélioré une petite app à partir d&#39;un prompt, en **Free Mode**.

<div id="before-you-start">
  ## Avant de commencer
</div>

Vous avez besoin d&#39;un [compte Replit](https://replit.com). Ce guide utilise le **Free Mode**, qui sélectionne le modèle grâce à un routage intelligent. {FreeModePlanAvailability}

L&#39;objectif est de vous entraîner à une boucle de prompting reproductible :

1. Décrivez un résultat utile.
2. Ajoutez des critères de réussite observables.
3. Définissez ce qu&#39;il ne faut pas encore construire.
4. Testez le résultat dans le Preview.
5. Demandez une seule amélioration ciblée.

<div id="build-the-first-version">
  ## Créer la première version
</div>

<Steps>
  <Step title="Démarrer un nouveau site web">
    Démarrez une nouvelle conversation et choisissez **Website** comme artifact. Vous pouvez le sélectionner dans le menu **New** ou via **Add attachment → Create something new → Website** dans la zone de prompt.

    Ouvrez le sélecteur de mode et choisissez **Free**.

    <Tip>
      Vous pouvez également demander à Replit de créer directement un site web en langage naturel. En sélectionnant d’abord Website, vous précisez l’artifact souhaité et ajoutez une pastille Website au prompt.
    </Tip>
  </Step>

  <Step title="Décrire le résultat attendu et les critères de réussite">
    Utilisez ce prompt :

    <PromptActions prompt={GATHER_PROMPT} campaign="docs-your-first-app" />

    <Frame>
      <img src="/assets/mirror/01-prompt-free-mode-f5c56ce766c8.jpg" alt="Le prompt Gather prêt à être envoyé, avec l’artifact Website sélectionné et Free Mode activé" width="1280" height="720" data-path="images/first-app-gather/01-prompt-free-mode.jpg" />
    </Frame>

    Le prompt commence par un objectif : une application permettant de découvrir des ateliers. Il indique ensuite ce que les visiteurs doivent pouvoir faire, définit des critères de réussite observables et reporte la connexion, les données, les paiements et les intégrations.

    Ces limites permettent de concentrer la première version sur l’essentiel. Vous pourrez ajouter des fonctionnalités de production une fois l’expérience principale opérationnelle.
  </Step>

  <Step title="Laisser Agent créer l'application en Free Mode">
    Envoyez le prompt. Agent planifie l’artifact, crée l’application, la démarre et vérifie le résultat. Suivez la progression dans le Chat et attendez qu’Agent présente un artifact Website et que Preview soit lancé.

    Free Mode peut prendre quelques minutes pour créer une première version complète. Si Replit recommande un mode supérieur pour une demande plus complexe, vous pouvez décider de passer à ce mode ; cette version de Gather est créée avec Free Mode.

    <Frame>
      <img src="/assets/mirror/02-first-version-163a5fb49aac.jpg" alt="Le premier site web Gather fonctionnel dans la disposition Build par défaut, avec le Chat Agent et Preview" width="1393" height="868" data-path="images/first-app-gather/02-first-version.jpg" />
    </Frame>
  </Step>

  <Step title="Tester le résultat dans Preview">
    Utilisez l’application comme le ferait un visiteur. Vérifiez que vous pouvez :

    * Parcourir la liste des ateliers.
    * Ouvrir une page détaillée d’un atelier.
    * Envoyer une inscription.
    * Voir une confirmation claire après l’envoi.
    * Utiliser la navigation principale.
    * Redimensionner Preview à une largeur de téléphone.

    Comparez le résultat aux critères de réussite du prompt. Si quelque chose ne fonctionne pas, décrivez le symptôme à Agent au lieu d’essayer de diagnostiquer vous-même le code.
  </Step>
</Steps>

<div id="improve-the-app-with-a-focused-prompt">
  ## Améliorer l&#39;application avec un prompt ciblé
</div>

Une fois l&#39;expérience de base fonctionnelle, demandez une seule amélioration claire à la fois. Pour Gather, ajoutez une vue des inscriptions envoyées limitée à la session :

> Ajoute une vue My RSVPs et fais en sorte que les ateliers envoyés y apparaissent pour la session en cours. Conserve le style visuel existant et n&#39;ajoute ni connexion ni base de données.
