Диалог — это единая цепочка сообщений, в которой можно задавать вопросы, искать информацию, запускать рутины и описывать желаемый результат. Любая задача в Replit начинается с диалога.

<Note>
  Диалоги приватны: доступ к ним в рабочем пространстве есть только у вас. Если нужна совместная работа, попросите Replit создать проект.
</Note>

<div id="section-3">
  ### Задавайте вопросы
</div>

Replit может находить и анализировать информацию в интернете, подключённых инструментах и загруженных файлах. Задавайте конкретные вопросы или сами укажите контекст, на который Replit должен опираться.

Например, попросите Replit подвести итоги активности в Slack за неделю и отметить сообщения, требующие ответа.

<div id="section-6">
  ## Диалог и проект
</div>

Диалог — это одна ветка для вопросов, исследований и рутин. [Проект](/ru/ja/features/projects-and-artifacts/projects) — более основательное рабочее пространство для полноценной работы по созданию и дизайну с несколькими artifact.

Начните с диалога. Если работа перерастает в полноценную разработку или дизайн, диалог можно превратить в проект.

На боковой панели диалог обозначается значком чат-облачка, а проект — значком сетки из четырёх квадратов.

<Frame>
  <img src="/assets/mirror/conversation-and-project-icons-025a17613daa.png" alt="Боковая панель Replit, где проект обозначен значком сетки из четырёх квадратов, а диалог — значком чат-облачка" width="466" height="290" data-path="images/chat/conversation-and-project-icons.png" />
</Frame>

| Область                  | Диалог                  | Проект                                                                                            |
| ------------------------ | ----------------------------- | -------------------------------------------------------------------------------------------------- |
| Лучше всего подходит для | Вопросов, исследований, рутин | Более основательной работы по созданию и дизайну: приложения, слайды, дашборды, несколько artifact |
| Фоновые задачи           | **Недоступны**                | **Могут выполняться параллельно**                                                                  |
| Рутины                   | **Доступны**                  | **Недоступны**                                                                                     |
| Интеграции               | Доступны                      | Доступны                                                                                           |
| Структура                | Одна ветка                    | Рабочее пространство проекта с несколькими artifact                                                |
