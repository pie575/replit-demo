借助 Replit 灵活的存储解决方案，您可以快速为应用添加所需的数据存储。对于有以下需求的应用，您可以使用 Replit 数据库或对象存储，Agent 还可自动完成这两种解决方案的设置和集成：

* 需要存储玩家信息 (如游戏进度或最高分) 的游戏
* 需要管理媒体文件的内容平台

<div id="replit">
  ## Replit 的存储和数据库选项
</div>

Replit 提供以下数据存储选项：

* **数据库**：用于存储用户资料、游戏分数和产品目录等结构化数据。
  通过属性及数据点之间的关系存储和查询数据。

* **App Storage**：用于存储图像、视频和文档等非结构化数据。
  可存储和检索大文件及二进制数据。

<div id="section">
  ### App Storage 与数据库对比
</div>

|             | 数据库                     | App Storage                  |
| ----------- | :---------------------- | :-------------------- |
| **适用的数据类型** | 具有关联关系的结构化数据            | 大型文件 (图片、视频、文档)       |
| **数据模型**    | 表、行、列                   | 存储桶、文件                |
| **查询语言**    | SQL                     | REST API              |
| **客户端**     | 兼容 PostgreSQL 的客户端和 ORM | Replit SDK 和 GCS 客户端库 |
| **计费模式**    | 按计算时间和存储空间计费            | 按带宽和存储空间计费            |
