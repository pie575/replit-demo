Construa aplicações com dados atuais e do mundo real usando as capacidades de Web Search <img class="icon-svg" src="/assets/mirror/web-search-1fe8f63b5b88.svg" alt="Ícone de Web Search" width="16" height="16" data-path="images/icons/web-search.svg" /> do Agent.

Esse recurso supera os limites de conhecimento ao acessar as informações mais recentes na web. Quando você pede ao Agent para criar algo que exige informações atualizadas, ele pesquisa na web e busca conteúdo detalhado para tornar seu app mais preciso e útil.

O Web Search é valioso para encontrar os pacotes, ferramentas e informações mais recentes. Isso garante que seus apps usem as melhores práticas atuais e sejam mais precisos.

## Funcionalidades

Construa aplicações com informações atuais usando o Web Search do Agent. Isso elimina a pesquisa manual e a coleta de dados. Seja criando um dashboard com dados financeiros ou construindo um site que mostra os lançamentos recentes de startups, o Web Search garante que seu app reflita a realidade.

O Agent pode realizar as seguintes ações de Web Search:

* **Pesquisa**: Encontre informações atuais, a documentação mais recente e dados em tempo real da internet
* **Busca de conteúdo**: Recupere informações detalhadas de sites e URLs específicos
* **Citações de fontes**: Veja exatamente onde o Agent encontrou as informações para que você possa verificá-las e referenciá-las

## Uso

O Web Search vem integrado ao Agent — não há nada para ativar. Descreva o que você quer construir, e o Agent determina automaticamente quando pesquisar na web por informações atuais. Inclua palavras-chave como "pesquise", "investigue" ou "use o Web Search" no seu prompt para incentivar o Agent a pesquisar explicitamente.

### Como o Web Search melhora seus apps

O Web Search transforma suas aplicações, deixando de usar dados de placeholder para incorporar informações reais e precisas:

| Benefício                     | Descrição                                                                                     |
| ----------------------------- | --------------------------------------------------------------------------------------------- |
| Tecnologia atualizada         | Seus apps usam as informações e pacotes mais recentes, que não estão nos dados de treinamento |
| Melhor seleção de ferramentas | O Agent pesquisa opções para escolher os pacotes ideais                                       |
| Melhores práticas atuais      | Acesso aos padrões de desenvolvimento e práticas de segurança mais recentes                   |
| Superação de limitações       | Supere os limites de conhecimento para usar pacotes lançados após o treinamento               |
| Dados precisos                | Seus apps exibem informações atuais em vez de exemplos desatualizados                         |
| Resultados profissionais      | Aplicações que referenciam empresas reais parecem mais confiáveis                             |
| Economia de tempo             | Evite pesquisar pacotes manualmente e reunir dados                                            |

### Citações de fontes

Quando o Agent usa o Web Search, ele fornece **citações de fontes** que mostram exatamente de onde vieram as informações. Use essas citações para:

* **Verificar informações**: Confira a confiabilidade e a precisão das fontes
* **Saber mais**: Visite as fontes originais para obter mais contexto
* **Referenciar fontes**: Inclua a atribuição adequada nas suas aplicações
* **Rastrear a pesquisa**: Entenda quais informações orientaram o trabalho do Agent

### Busca de conteúdo

O Agent pode buscar conteúdo detalhado de sites específicos para reunir informações completas para o seu projeto. Isso permite que o Agent:

* Leia páginas web inteiras para extrair detalhes relevantes
* Processe documentação e materiais de referência
* Reúna pontos de dados específicos de fontes confiáveis
* Integre informações estruturadas na sua aplicação
