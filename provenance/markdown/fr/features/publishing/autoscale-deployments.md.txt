# Déploiements Autoscale

> Découvrez comment les déploiements Autoscale ajustent automatiquement la capacité en fonction du trafic de votre application.

Les déploiements Autoscale s'exécutent sur des ressources de cloud computing qui augmentent et diminuent pour gérer efficacement
le trafic réseau et la charge de travail de votre application Replit. Lorsque votre application est sollicitée, l'autoscaling ajoute des serveurs pour
gérer la charge. Lorsque votre application est inactive, il réduit leur nombre jusqu'à zéro pour vous faire économiser de l'argent.

Les déploiements Autoscale sont idéaux pour les cas d'utilisation suivants :

* Les applications web qui gèrent des charges de travail et un trafic variables, telles que les sites e-commerce
* Les API et services

## Fonctionnalités

Les déploiements Autoscale incluent les fonctionnalités suivantes :

* **Mise à l'échelle automatique des ressources** : Ajuste automatiquement les ressources en fonction des tendances du trafic pour optimiser les coûts.
* **Domaines personnalisés** : Configurez un domaine personnalisé ou utilisez une URL `<nom-app>.replit.app` pour accéder à votre application.
* **Limites configurables** : Définissez le nombre maximum d'instances vers lesquelles votre application publiée peut évoluer.
* **Puissance machine flexible** : Choisissez la configuration CPU et RAM qui répond aux besoins de votre application.
* **Surveillance** : Consultez les journaux et surveillez le statut de votre application publiée.

## Puissance machine

Sélectionnez **Modifier** pour afficher et définir les options de puissance machine. Utilisez les curseurs pour sélectionner la configuration CPU et RAM
pour chaque instance de serveur d'application publiée.

Consultez le coût en **unités de calcul** pour la configuration dans la ligne **Total par machine**.
Une unité de calcul est une mesure des ressources de cloud computing basée sur la configuration mémoire et CPU de la machine.

Pour en savoir plus sur le calcul du coût en unités de calcul, consultez [Unités de calcul](/fr/billing/about-usage-based-billing#2-compute-units).

## Nombre maximum de machines

Utilisez le curseur pour ajuster le nombre maximum de machines. Ce nombre est la limite supérieure d'instances de serveur
que la fonctionnalité d'autoscaling peut attribuer lorsqu'elle détermine que votre application est sollicitée.

La ligne inférieure affiche l'équivalent en unités de calcul, calculé par la formule suivante :

`Nombre de machines * unités de calcul par machine`
