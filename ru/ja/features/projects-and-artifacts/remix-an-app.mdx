<div id="section">
  ## Что такое ремикс
</div>

**Ремикс** — это новый Replit App, созданный на основе приложения, к которому у вас есть доступ. Когда вы делаете ремикс опубликованного приложения или шаблона, у вас появляется собственная копия: с ней можно работать и постепенно её улучшать. Изменения, внесённые в ремиксе, не затрагивают исходное приложение.

Ремикс явно указывает на исходное приложение: отображается ссылка **Remixed from** на оригинал, а промпт, по которому было создано исходное приложение, показывается на обложке.

<div id="section-2">
  ## Что входит в ремикс
</div>

Ремикс — это полностью рабочая копия, полностью отделённая от исходного приложения.

* **Все файлы и настройки** копируются, поэтому приложение работает точно так же, как исходное.
* **История чекпоинтов исходного приложения** также переносится и помечается как история исходного приложения. Вы можете в любой момент откатиться к этим чекпоинтам, но беседы, в которых они были созданы, остаются в исходном приложении.
* **Совершенно новый Agent**. Ремикс начинается с нового Agent без перенесённой истории чата.
* **Только названия секретов, а не их значения**. Если приложение использует секреты (например, ключи API), в ремиксе будет указан их список, чтобы вы знали, что нужно ввести, но сами значения останутся пустыми. Значения копируются только при создании ремикса собственного приложения.
* **Новая база данных**. Ремикс не подключается к базе данных исходного приложения. Если исходное приложение поддерживает эту возможность, вы можете скопировать сами данные с помощью опции **Copy data from original App**, но изменения не повлияют на исходное приложение.
* Для приложений, использующих Replit Auth, — **новые настройки входа**.

Не копируются развёртывания, домены и настройки коннекторов — настройте их отдельно в своей копии. Кроме того, ремикс изначально приватный, поэтому ничего не будет доступно другим, пока вы не решите сделать его публичным.

<div id="section-5">
  ## Доработка ремикса
</div>

Когда ремикс откроется в рабочем пространстве, используйте Agent, чтобы вносить изменения и расширять проект. Введите на вкладке **Agent** промпт с описанием функции, которую хотите добавить.

Чтобы отменить изменения, внесённые Agent, выберите **Rollback to here** у чекпоинта, созданного после этих изменений. Подробнее см. в разделе [Чекпоинты и откаты](/ru/ja/features/version-control/checkpoints-and-rollbacks).

<div id="section-6">
  ## Что выбрать: ремикс или создание по промпту?
</div>

Оба подхода в итоге приведут вас к одному и тому же: собственному приложению, которое Agent поможет развивать. Различается лишь начало.

|                       | Ремикс                                                 | Создание по промпту                                       |
| --------------------- | ------------------------------------------------------ | --------------------------------------------------------- |
| Отправная точка       | Готовое работающее приложение — точная копия исходного | Приложение, которое Agent создаёт по вашему описанию      |
| Первый результат      | Доступен сразу и идентичен исходному приложению        | Требует больше времени, а результат каждый раз отличается |
| Первое действие Agent | Ожидает ваших указаний                                 | Планирует и создаёт приложение на основе вашего промпта   |

Если уже есть приложение, близкое к тому, что вам нужно, сделайте ремикс. Вместо того чтобы начинать с чистого листа, в первом ходе Agent будет работать с уже готовым приложением. Если вы не нашли ничего похожего на вашу идею, создайте приложение по промпту.
