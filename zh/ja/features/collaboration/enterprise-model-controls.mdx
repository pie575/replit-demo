通过 Enterprise 模型控制，账户管理员可以管理构建者可选择的 Agent 模型。设置账户级策略后，您可以为各个工作区配置不同的模型访问权限。

<Note>
  模型控制仅面向 Enterprise 账户的账户管理员提供。要为您的组织启用此功能，请通过 [sales@replit.com](mailto:sales@replit.com) 联系销售团队。
</Note>

<div id="section">
  ## 使用智能模型路由
</div>

智能模型路由是 Enterprise 工作区中默认的 Agent 使用体验。开启 **Auto 模式**后，Replit 会在兼顾质量与成本的前提下，为每项任务选择最合适的模式和模型。

路由会从账户和工作区策略允许使用的模型池中进行选择，无法选择该模型池之外的模型提供商和模型。构建者可以保持 **Auto 模式**开启，也可以将其关闭并手动选择允许使用的模型。

有关路由机制的更多信息，请参阅[使用智能模型路由](/zh/ja/chat/auto-mode)。

<div id="agent">
  ## 打开 Agent 模型设置
</div>

1. 打开**设置**。
2. 在**账户**下选择**高级**。
3. 展开**Agent 模式与身份提供方**。

<Frame caption="高级设置中的模型提供方策略，以及单独的快速模式模型控件。">
  <img src="/assets/mirror/agent-model-provider-settings-overview-8f82610dab77.jpg" alt="显示模型提供方策略和快速模式模型控件的 Agent 模式与身份提供方设置" width="2000" height="930" data-path="images/workspace/agent-model-provider-settings-overview.jpg" />
</Frame>

<div id="section-2">
  ## 设置模型提供商策略
</div>

<Steps>
  <Step>
    选择要管理的模型提供商。
  </Step>

  <Step>
    在 **Account policy** 下，选择以下选项之一：

    | 选项                  | 结果                   |
    | ------------------- | -------------------- |
    | **Enable all**      | 该模型提供商的所有模型将在所有工作区中可用。 |
    | **Enable selected** | 您可以为每个工作区选择可用的模型。    |
    | **Disabled**        | 所有工作区都无法使用该模型提供商的模型。   |

    <Note>
      必须至少启用 OpenAI、Anthropic 或 Google 中的一种模型。其他模型提供商可以禁用。
    </Note>
  </Step>

  <Step>
    选择 **Update**。
  </Step>
</Steps>

开源模型提供商默认处于禁用状态。要启用它们，请选择 **Enable all** 或 **Enable selected**，然后选择 **Update**。

<div id="section-3">
  ## 设置工作区策略
</div>

如果不同工作区需要不同的模型访问权限，请使用**Enable selected**。

<Frame caption="设置为 Enable selected 的 Anthropic 模型提供商策略，以及各工作区的模型访问权限配置。">
  <img src="/assets/mirror/anthropic-account-policy-workspace-models-38c0f71a609d.jpg" alt="设置为 Enable selected 的 Anthropic 账户策略和工作区模型开关" width="2000" height="930" data-path="images/workspace/anthropic-account-policy-workspace-models.jpg" />
</Frame>

1. 打开模型提供商设置。
2. 将**Account policy**设置为**Enable selected**。
3. 在**Workspace**列表中，选择目标工作区的**Setting**下拉菜单。
4. 为该工作区启用或停用各个模型。
5. 选择**Update**。

选择**Update**之前，您可以选择**Copy to all**，将当前工作区的模型选择应用于账户中的所有工作区。

<div id="section-4">
  ## 限制事项
</div>

* 模型策略适用于工作区。无法为同一工作区中的不同用户群组设置不同策略。
* 智能模型路由不会覆盖账户或工作区策略。你无法选择已禁用的模型提供商或模型。
* **Agent 模式与身份提供方**中的**快速模式模型**开关用于控制该账户下所有工作区对快速模型变体的访问权限。模型提供商策略和智能模型路由不会更改此设置。
