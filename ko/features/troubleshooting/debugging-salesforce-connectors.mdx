<div id="overview">
  ## Overview
</div>

Salesforce connector가 더 이상 작동하지 않고 **&quot;Connection Expired&quot;** 오류가 표시된다면, 대개 Salesforce organization의 refresh token 정책이 일정 기간이 지나면 token을 만료시키도록 설정되어 있기 때문입니다. 이 경우 Replit이 사용자를 대신해 Salesforce에 인증할 수 없으므로 연결을 다시 승인해야 합니다.

이 가이드에서는 refresh token이 명시적으로 취소되기 전까지 유효하게 유지되도록 Salesforce Connected App 설정을 변경하는 방법을 안내합니다.

<Warning>
  이 작업을 진행하려면 **Salesforce 관리자 권한**이 필요합니다. 관리자 권한이 없다면 Salesforce 관리자에게 문의하고 이 가이드를 공유하세요.
</Warning>

<div id="troubleshooting-steps">
  ## 문제 해결 단계
</div>

<div id="step-1-open-your-salesforce-connected-app-settings">
  ### 1단계: Salesforce Connected App 설정 열기
</div>

<Steps>
  <Step title="Salesforce에 로그인">
    관리자 계정으로 Salesforce organization에 로그인합니다.
  </Step>

  <Step title="Connected Apps로 이동">
    **Setup &gt; Apps &gt; Connected Apps &gt; Manage Connected Apps**로 이동합니다.
  </Step>

  <Step title="Replit 앱 찾기">
    목록에서 **Replit** Connected App을 찾아 선택합니다.
  </Step>

  <Step title="정책 편집">
    **Edit Policies**를 선택해 정책 설정 페이지를 엽니다.
  </Step>
</Steps>

<div id="step-2-update-the-refresh-token-policy">
  ### 2단계: refresh token 정책 업데이트
</div>

Salesforce의 기본 refresh token 정책에서는 지정된 일수가 지나거나 일정 기간 사용하지 않으면 token이 만료될 수 있습니다. 연결이 만료되지 않도록 token이 무기한 유효하게 유지되도록 정책을 변경하세요.

<Steps>
  <Step title="Refresh Token Policy 설정 찾기">
    Connected App Edit 페이지에서 **OAuth Policies** 아래의 **Refresh Token Policy** 섹션을 찾습니다.
  </Step>

  <Step title="'Refresh token is valid until revoked' 선택">
    정책을 **Refresh token is valid until revoked**로 변경합니다. 이렇게 하면 token이 자동으로 만료되지 않습니다.

    <Frame>
      <img src="/assets/mirror/refresh-token-policy-e2f92339f33d.png" alt="Refresh Token Policy가 'Refresh token is valid until revoked'로 설정된 Salesforce Connected App Edit 페이지" width="886" height="449" data-path="images/replitai/debugging-salesforce-connectors/refresh-token-policy.png" />
    </Frame>
  </Step>

  <Step title="변경 사항 저장">
    **Save**를 선택해 변경한 정책을 적용합니다.
  </Step>
</Steps>

<Tip>
  정책 변경이 적용되기까지 몇 분이 걸릴 수 있습니다. 저장한 뒤 몇 분 기다렸다가 Replit에서 Salesforce를 다시 연결하세요.
</Tip>

<div id="step-3-reconnect-salesforce-in-replit">
  ### 3단계: Replit에서 Salesforce 다시 연결하기
</div>

refresh token 정책을 업데이트한 후 Replit에서 Salesforce connector를 다시 연결합니다.

<Steps>
  <Step title="Project Editor 열기">
    Project Editor에서 해당 앱으로 이동합니다.
  </Step>

  <Step title="Connectors로 이동">
    사이드바에서 **Connectors** 패널을 엽니다.
  </Step>

  <Step title="Salesforce 다시 연결">
    만료된 Salesforce 연결에서 **Reconnect**를 선택합니다. 안내가 표시되면 OAuth 인증 flow를 완료합니다.
  </Step>
</Steps>

<div id="still-seeing-errors">
  ## 여전히 오류가 발생하나요?
</div>

refresh token 정책을 업데이트했는데도 연결이 계속 만료된다면 다음을 확인하세요.

* **다른 token 정책 옵션 확인**: &quot;Expire refresh token if not used for&quot; 또는 &quot;Expire refresh token after&quot; 같은 다른 만료 옵션이 선택되어 있지 않은지 확인하세요.
* **IP Relaxation 설정 확인**: Salesforce 조직에서 IP 제한을 적용하고 있다면 Connected App의 **IP Relaxation** 설정이 Replit 서버에서 오는 요청을 차단할 수 있습니다. 보안 requirements에 문제가 없다면 **Relax IP restrictions**로 설정하는 것을 고려해 보세요.
* **login 기록 검토**: Salesforce에서 **Setup &gt; Login History**로 이동해 Replit과 관련된 authentication 실패 기록이 있는지 확인하세요.
* **Replit Support 문의**: Salesforce 측 문제가 아니라면 [Replit Support](https://replit.com/support)에 도움을 요청하세요.
