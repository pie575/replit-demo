---
title: "反馈小组件"
description: "在已发布的应用中添加反馈小组件，让访客报告问题和提出想法，并直接发送给 Agent 进行修复。"
---

反馈小组件会在已发布应用的角落添加一个反馈按钮。访客无需离开应用，即可通过此按钮报告问题或提出改进建议，还可将提交的内容直接发送给 Agent 进行修复。

<div id="section">
  ## 启用反馈小组件
</div>

1. 在 **Tools** 面板的 **Replit Cloud** 下选择 **Publishing**，或者选择 Project Editor 右上角的 **Publish**，打开 Publishing 工具。
2. 在 **Engagement tools** 下开启 **Enable feedback widget**。
3. 选择 **Publish**。小组件将显示在已发布的应用中。

<div id="section-2">
  ## 位置和外观
</div>

启用小组件后，将显示两项设置：

* **小组件位置**：选择小组件在 App 中显示的位置：左上角、右上角、左下角或右下角。默认位置为右下角。
* **外观**：上传小组件按钮的图标并选择背景颜色，使其与 App 的设计风格保持一致。

<div id="section-3">
  ## 查看并处理反馈
</div>

访客提交的内容会发送到收件箱 (inbox) 。你可以在这里：

* 阅读每条提交内容，了解访客遇到的问题。
* 将提交内容交给 Agent 修复。Agent 会将反馈作为任务处理，并建议对应用进行修改。

<div id="section-4">
  ## 关闭小组件
</div>

在 Publishing 工具中关闭 **Enable feedback widget**，然后重新发布。已发布的应用中将不再显示小组件。
