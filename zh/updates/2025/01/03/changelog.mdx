<div id="xai-integration">
  ### xAI 集成
</div>

Agent 现在可将 xAI 直接添加到你的 App 中。

<Frame>
  <img src="/assets/mirror/xai-announce-232aa8bf6428.jpeg" alt="xAI 集成公告" width="3840" height="2160" data-path="images/changelog/2025-01-03/xai-announce.jpeg" />
</Frame>

将 Grok 添加到你的项目中，并在几秒钟内发布。只需在提示词中提及“使用 xAI 添加 AI 功能”，或在集成中选择 xAI，Agent 就会通过 API 构建。

<Frame>
  <img src="/assets/mirror/xai-in-product-a0102e19b327.jpeg" alt="产品中的 xAI" width="1120" height="1120" data-path="images/changelog/2025-01-03/xai-in-product.jpeg" />
</Frame>

更多你喜爱的集成即将登陆 Agent。

<div id="custom-domain-error-handling">
  ### 自定义域名错误处理
</div>

现已提供自定义域名验证失败的具体错误信息，帮助你更快排查问题。

<div id="menu-search-feature">
  ### 菜单搜索功能
</div>

现在，你可以在 Replit Apps 的侧边栏中搜索菜单项。

<div id="neon-database-improvements">
  ### Neon 数据库改进
</div>

Neon 数据库集成已优化。现在，使用 Agent 添加的数据库成本更低，性能更佳。

<div id="react-by-default">
  ### 默认使用 React
</div>

新建前端 Replit Apps 现默认使用 React 模板，让你的项目开箱即用，更美观、功能更完善。
