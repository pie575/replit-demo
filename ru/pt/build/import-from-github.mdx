<div id="importar-do-github">
  ## Импорт из GitHub
</div>

⏰ *Примерное время: две минуты*

Импортируйте репозиторий GitHub в Replit, чтобы быстрее запускать, тестировать и публиковать проекты.

Подробнее о расширенных возможностях импорта, включая импорт с других платформ, таких как Figma, Bolt и Lovable, см. в [документации по импорту](/ru/pt/references/workspace/import).

<div id="antes-de-comear">
  ## Перед началом работы
</div>

* URL-адрес репозитория GitHub
* Доступ к репозиторию (публичному или приватному)
* Учётная запись Replit

<div id="opo-um-importao-rpida">
  ## Вариант первый: быстрый импорт
</div>

Быстрый импорт работает с публичными репозиториями.

1. Скопируйте путь к репозиторию, который идёт после `github.com/`.
2. Откройте `https://replit.com/github.com/<owner>/<repo>`.
3. Нажмите Enter, чтобы запустить импорт.

**Пример**

* URL на GitHub: `https://github.com/exampleUser/my-app`
* URL для импорта в Replit: `https://replit.com/github.com/exampleUser/my-app`

<div id="opo-dois-importao-guiada">
  ## Вариант 2: пошаговый импорт
</div>

Пошаговый импорт поддерживает общедоступные и приватные репозитории.

1. Откройте [replit.com/import](https://replit.com/import).
2. Выберите **GitHub**.
3. Подключите учётную запись GitHub.
4. Выберите репозиторий.
5. Выберите **Import**.

<div id="o-que-importado">
  ## Что импортируется
</div>

* Файлы и папки репозитория
* Файлы зависимостей
* Стандартная конфигурация запуска и сборки

<div id="o-que-no-importado">
  ## Что не импортируется
</div>

* Значения существующих secrets и переменных окружения
* Специфичные для платформы сервисы, которые по умолчанию не работают в Replit
