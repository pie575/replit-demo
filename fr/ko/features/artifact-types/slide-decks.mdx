<div id="slide-decks">
  ## Que sont les Slide Decks ?
</div>

Les Slide Decks vous permettent de créer des présentations professionnelles de qualité simplement en discutant avec Agent. Décrivez ce que vous souhaitez et obtenez instantanément une présentation complète et élégante, puis affinez-la par chat, édition visuelle ou en explorant des variantes dans le [Design Canvas](/fr/ko/design/canvas).

Les diapositives sont créées en React, ce qui permet de les exporter en fichiers PPTX, Google Slides ou PDF, avec une précision au pixel près et entièrement modifiables. Vous pouvez également publier votre présentation à l’aide d’une URL partageable en temps réel.

Concepts clés :

* **Génération en une seule fois** : décrivez votre présentation et Agent crée une présentation complète incluant la mise en page, le texte et les visuels
* **Basé sur React** : les diapositives sont de véritables composants React, et non des images statiques, ce qui permet de les exporter proprement dans n’importe quel format
* **Exportez partout** : téléchargez au format PPTX, Google Slides ou PDF, avec une précision au pixel près et une modification complète
* **Publication possible** : publiez votre présentation via une URL en temps réel afin que chacun puisse la consulter ou la présenter dans son navigateur

<div id="slide-decks-2">
  ## Comment utiliser Slide Decks
</div>

<div id="section">
  ### Créer un deck de diapositives
</div>

Il existe deux façons de créer un deck de diapositives depuis la page d&#39;accueil de Replit :

* **Saisir un prompt** : décrivez la présentation que vous souhaitez. Agent détecte les prompts liés aux présentations et sélectionne automatiquement la stack deck de diapositives.
* **Choisir dans le menu déroulant** : ouvrez le menu déroulant du type d&#39;application, sélectionnez **Slides**, puis décrivez votre présentation.

**Exemples de prompts :**

* « Crée un pitch deck pour mon application de fitness basée sur l&#39;IA »
* « Crée une présentation investisseurs de 10 diapositives pour une levée de fonds en série A »
* « Crée un deck de présentation produit pour le séminaire de mon équipe »

<Tip>
  Si vous précisez d&#39;emblée la longueur et le style visuel, Agent crée le deck directement, sans poser de questions de clarification. Essayez par exemple : « Crée un deck minimaliste de 8 diapositives sur le télétravail ».
</Tip>

<div id="section-2">
  ### Commencer avec une charte graphique ou des documents de référence
</div>

Vous pouvez fournir à Agent les éléments de départ suivants :

* **Charte graphique** : importez votre charte graphique pour qu’Agent applique les couleurs, les polices et le style visuel à toutes les diapositives.
* **Fichiers de référence** : importez une présentation ou un document existant comme point de départ. Agent s’en servira pour créer votre diaporama.

<div id="section-3">
  ### Améliorer les diapositives de façon itérative
</div>

Une fois qu&#39;Agent a généré une première version, vous pouvez l&#39;affiner en dialoguant avec lui :

* **Ajuster le contenu** : « Rends la diapositive sur le problème plus concise » ou « Ajoute une diapositive sur le paysage concurrentiel après la section sur la taille du marché. »
* **Changer le style** : « Utilise un thème sombre avec des accents bleus » ou « Agrandis la police et rends le tout plus minimaliste. »
* **Ajouter ou supprimer des diapositives** : « Ajoute deux diapositives supplémentaires sur la feuille de route » ou « Supprime la dernière diapositive. »
* **Ajouter des visuels** : « Ajoute un graphique montrant la croissance prévue » ou « Mets une icône pour chaque fonctionnalité de la diapositive 4. »
* **Réordonner ou restructurer** : « Déplace la diapositive sur l&#39;équipe à la fin » ou « Divise la diapositive des fonctionnalités en deux. »

Au fil de vos itérations, les diapositives s&#39;affichent automatiquement dans le panneau d&#39;aperçu : vous voyez vos modifications immédiatement.

<div id="section-4">
  ### Modifier directement les diapositives
</div>

Vous pouvez aussi les modifier directement, sans passer par le chat :

* **[Visual Editor](/fr/ko/design/visual-editor)** : cliquez sur n’importe quel élément pour modifier directement le texte, les couleurs, les marges et la mise en page — aucun crédit IA n’est utilisé.
* **Dupliquer ou supprimer** : faites un clic droit sur une diapositive pour la dupliquer ou la supprimer.

<Note>
  Le glisser-déposer d’éléments dans les diapositives n’est pas encore pris en charge. Pour déplacer ou réorganiser des éléments, demandez à Agent dans le chat.
</Note>

<div id="design-canvas">
  ### Explorer des variantes avec Design Canvas
</div>

Utilisez le [Design Canvas](/fr/ko/design/canvas) pour explorer des conceptions alternatives de diapositives ou de sections, puis importez la version de votre choix dans le deck principal. Cette fonctionnalité est utile si vous souhaitez comparer plusieurs orientations visuelles avant de vous décider.

<div id="section-5">
  ### Présenter et publier
</div>

Lorsque votre deck de diapositives est prêt :

* **Mode présentateur** : depuis le panneau d’aperçu, passez en mode présentation plein écran pour présenter directement. C’est ce que votre audience verra une fois le deck de diapositives publié.
* **Prise en charge mobile** : les diapositives s’affichent également sur les appareils mobiles, afin que votre audience puisse les consulter sur n’importe quel écran.
* **Publier** : publiez votre deck de diapositives avec une URL de partage en direct. Toute personne disposant du lien peut consulter ou présenter le deck de diapositives dans son navigateur.

<div id="section-6">
  ### Exporter
</div>

Téléchargez vos diapositives pour les utiliser en dehors de Replit :

* **PowerPoint** : ouvrez et modifiez le fichier `.pptx` dans PowerPoint ou Keynote. Les arrière-plans, le texte et les graphiques restent intacts.
* **Google Slides** : ouvrez votre deck directement dans Google Slides. Une fois l&#39;export terminé, sélectionnez **Go to Google Slides** pour l&#39;ouvrir en un clic.
* **PDF** : partagez une version statique, prête à imprimer. Même les decks riches en photos sont exportés dans un format léger, que vous pouvez envoyer par e-mail sans difficulté.

Vous pouvez aussi importer des présentations existantes. À l&#39;import d&#39;un fichier `.pptx`, les arrière-plans, le texte et les graphiques sont repris fidèlement.

<div id="section-7">
  ### Trouver des decks de diapositives
</div>

Les decks de diapositives apparaissent dans la liste Projects avec vos autres applications. Sur la page Projects, ouvrez le menu déroulant **Build type** et sélectionnez **Slides** pour n’afficher que les projets contenant des artefacts de deck de diapositives.

<div id="section-9">
  ## Questions fréquentes
</div>

<Accordion title="Puis-je glisser-déposer des éléments sur une diapositive ?">
  Pas encore. Pour déplacer ou réorganiser des éléments dans une diapositive, demandez à Agent dans le chat. Vous pouvez modifier directement le texte, les couleurs et les marges avec Visual Editor.
</Accordion>

<Accordion title="Quels formats d’exportation sont pris en charge ?">
  Vous pouvez exporter au format PPTX, Google Slides ou PDF. Toutes les exportations sont fidèles au pixel près et entièrement modifiables.
</Accordion>

<Accordion title="Puis-je utiliser la charte graphique de ma marque ?">
  Oui. Lorsque vous créez une présentation, importez la charte graphique de votre marque et Agent harmonisera les couleurs, les polices et le style visuel sur toutes les diapositives.
</Accordion>

<Accordion title="Les diapositives fonctionnent-elles aussi sur mobile ?">
  Oui. Les diapositives sont rendues sur les appareils mobiles, afin que votre audience puisse consulter une présentation publiée ou partagée sur n’importe quel écran.
</Accordion>

<Accordion title="Puis-je publier des diapositives avec une URL en direct ?">
  Oui. Lorsque vous publiez une présentation, elle génère une URL de partage en direct que tout le monde peut consulter ou présenter dans son navigateur.
</Accordion>
