<div id="use-o-replit-pelo-claude">
  ### 通过 Claude 使用 Replit
</div>

Replit 现已作为连接器接入 Claude。只需连接一次，即可直接在 Claude 对话中创建、更新 Replit 应用，或针对应用提问。你还可以将设计从 Claude Design 直接发送到 Replit。设计会以可运行应用的形式打开，Agent 会规划如何将其转化为功能完整的产品。

</Frame>

详细了解[如何通过 Claude 使用 Replit](/zh/pt/features/platforms/claude)。

<div id="novos-servidores-mcp-apollo-e-black-forest-labs">
  ### 新增 MCP 服务器：Apollo 和 Black Forest Labs
</div>

两个新服务器现已加入 MCP 目录，一键即可连接。连接 **Apollo**，即可在与 Agent 的对话中查询账户和联系人，并创建外联名单。连接 **Black Forest Labs**，即可在项目中生成和编辑 FLUX 图像。

前往 [MCP 列表](/zh/pt/features/mcp/overview)了解更多。

<div id="modo-de-voz">
  ### 语音模式
</div>

现在，你可以直接说出想构建的内容。点击 Agent 聊天输入框中的麦克风，说出你的 prompt，Replit 会将语音转录为可编辑的文本。检查文本，进行必要的编辑，然后像发送其他消息一样发送即可。语音模式适用于所有 Replit 套餐。

<div id="equipes-e-enterprise">
  ## 团队与 Enterprise
</div>

<div id="convide-convidados-externos-para-workspaces-enterprise">
  ### 邀请外部访客加入 Enterprise 工作区
</div>

Enterprise 管理员现在可以邀请外部协作者以访客身份加入工作区，无需通过身份提供方。只需与外部邮箱地址共享单个应用，该用户便会以访客身份加入，并且只能访问该应用。访客会显示在专用表格中，您可以查看他们可访问的应用，并随时撤销其访问权限。
