根据网站和 Google Drive 中的品牌文件，为 X、LinkedIn、Instagram、Facebook、TikTok
等指定的社交平台生成头像图标和封面横幅。Agent 会采用各平台当前的尺寸规格和安全区域，
确保人脸、徽标和文字在实际的个人主页上不会被裁切。请保持统一的视觉体系，并导出为 PNG。
如果某个网络需要不同的裁切方式，请单独创建专属画板，不要直接拉伸。

<div id="section-4">
  ## 预期结果
</div>

Agent 会读取你的网站和 Drive 素材，然后按精确的像素尺寸为每个素材各创建一个画板。常见的一套尺寸如下：

* **X：** 头像 400×400，横幅 1500×500
* **LinkedIn：** 头像 400×400，横幅 1584×396
* **Instagram：** 头像 320×320 (如需帖子和快拍封面，另加 1080×1080、1080×1920)
* **Facebook：** 头像 320×320，封面 820×312 (或 2 倍尺寸 1640×624)
* **TikTok：** 头像 200×200，封面 1080×1920

上传前，请检查圆形头像和宽幅横幅的裁切效果。可以先导出一个图标和一个横幅，分别放入圆形头像和宽幅页头中试看，并确认小尺寸下的留白是否合适。

<div id="section-6">
  ## 故障排除
</div>

* **徽标或人脸被裁切：**在圆形头像和宽幅横幅中检查每个素材。留出安全区域；如果需要不同的裁切方式，请让 Agent 创建专用画板。不要拉伸。
* **尺寸不符合社交平台要求：**告知 Agent 所需的社交平台，并让其使用各社交平台当前的官方尺寸。社交平台经常调整这些尺寸，因此请在上传前再次确认。
