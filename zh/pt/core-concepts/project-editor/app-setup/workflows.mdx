它是一组可重复使用、可自定义的步骤，可在你的 Replit App 中运行。它可以像运行 `python main.py` 一样简单，也可以像执行多步骤流程一样复杂。

<div id="tipos-de-tarefas-disponveis">
  ## 可用的任务类型
</div>

目前提供 3 种任务类型：`Execute Shell Command`、`Install Packages` 和 `Run Workflow`。

<div id="execute-shell-command">
  ### 执行 Shell 命令
</div>

`Execute Shell Command` 会保存 shell 命令，并在与 Shell 面板相同的环境中执行。这类任务适用于多种场景，例如执行单个文件：

```text theme={null}
python main.py
```

直至执行复杂的已存储数据库查询命令：

```text theme={null}
psql -h 0.0.0.0 -U your_username -d your_database -c "SELECT * FROM your_table;"
```

<div id="install-packages">
  ### 安装包
</div>

`Install Packages` 使用 Replit 内置的依赖管理系统，自动检测项目依赖项并安装所需的包。有关 UPM 如何在后台检测并安装项目所需包的详细信息，请参阅[依赖管理](/zh/pt/core-concepts/project-editor/app-setup/dependency-management#the-universal-package-manager)。

<div id="run-workflow">
  ### 运行工作流
</div>

`Run Workflow` 可让您从当前工作流中运行另一个工作流。这样，您可以复用工作流，并将它们组合起来创建更复杂的工作流。

使用场景示例：

<Frame>
  <img src="/assets/mirror/example-run-workflow-62f93cd1bf00.webp" alt="图片" width="720" height="678" data-path="images/workflows/example-run-workflow.webp" />
</Frame>

使用此类任务在工作流之间建立依赖关系时，您可以编辑某个工作流，引用它的其他工作流会自动使用最新更改。请注意，深度嵌套的工作流调用存在嵌套深度限制。

<div id="modo-de-execuo-do-workflow">
  ## Workflow 执行模式
</div>

Workflow 提供两种执行模式：顺序执行和并行执行。

<div id="sequencial">
  ### 顺序执行
</div>

顺序执行会按预设顺序运行各项任务，等待每项任务完成后再继续下一步；如果工作流中的某项任务失败，序列执行将停止。

这种模式适合定义逻辑上相互关联的命令，例如使用 Git 命令拉取主分支的最新更改，然后将当前分支变基到主分支：

<Frame>
  <img src="/assets/mirror/example-sequential-workflow-62ae8a64038f.png" alt="image" width="721" height="654" data-path="images/workflows/example-sequential-workflow.png" />
</Frame>

<div id="paralelo">
  ### 并行
</div>

并行执行模式会同时运行各项任务，每项任务都会在工作流中独立启动和执行，不受其他任务影响。某项任务失败不会中断其他任务的执行。

例如，可以使用此模式运行需要同时启动前端和 backend 服务器的全栈项目：

<div id="criando-workflows">
  ## 创建工作流
</div>

你可以在工作流面板中点击 `+ New Workflow` 按钮来创建工作流。首先为工作流设置一个便于识别的名称，选择合适的运行模式，然后开始添加任务。你可以通过拖放任务来调整其顺序。

</Frame>

<div id="atribuir-workflow-ao-boto-run">
  ## 将工作流分配给 Run 按钮
</div>

你也可以为 Run 按钮分配工作流，以替代其默认行为 (请参阅[配置 Replit App](/zh/pt/core-concepts/project-editor/app-setup/configuration)) 。若要保留 `.replit` 中配置的默认 run 命令，请在下拉菜单中选择默认选项“Run Replit App”。

点击 Run 按钮时，将运行其旁边下拉菜单中选择的工作流。要更改 Run 按钮运行的工作流，请在下拉菜单中选择所需的工作流。
