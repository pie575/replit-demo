通过发布功能，你可以用简化的流程将 Replit 应用分享给全世界。

<Note>
  让应用上线的操作称为&quot;发布 (Publishing) &quot;。本页面将介绍可用的各种部署类型。
</Note>

<div id="section">
  ## 什么是发布？
</div>

发布功能会将 Replit 应用的**快照**保存到云端，任何人都可以与之交互。快照会捕获 Replit 应用文件的当前状态。

发布 Replit 应用后会生成**已发布的应用**，即运行在 Replit 云基础设施上的应用实例。这样，应用便可独立于 Project Editor 中的版本，在互联网上稳定可用。

<Info>
  Replit 的基础设施由 Google Cloud Platform (GCP) 提供支持。所有
  已发布的应用均托管在美国。企业客户可以联系
  销售团队，请求将已发布的应用托管在欧盟。

  所有个人、组织和企业客户都会获得专用的
  单租户 GCP 项目来承载已发布的应用。也就是说，已发布
  应用的计算资源、密钥和存储完全隔离，不会与其他客户的应用共享。
</Info>

发布还提供了用于监控已发布应用状态和查看网页分析的工具。

Replit 提供以下部署类型：

<CardGroup>
  <Card title="Autoscale 部署" href="/zh/ko/features/publishing/deployment-types#autoscale" icon="layer-group">
    根据应用使用量自动调整资源。
  </Card>

  <Card title="静态部署" href="/zh/ko/features/publishing/deployment-types#static" icon="files">
    以更低的成本托管不随用户输入变化的网站。
  </Card>

  <Card title="Reserved VM 部署" href="/zh/ko/features/publishing/deployment-types#reserved-vm" icon="server">
    为持续运行的应用提供恒定的计算资源。
  </Card>

  <Card title="计划部署" href="/zh/ko/features/publishing/deployment-types#scheduled" icon="clock">
    在你选择的预定时间运行应用。
  </Card>
</CardGroup>

<div id="section-2">
  ## 开始使用
</div>

要发布 Replit 应用，请按以下步骤操作：

1. 在 Project Editor 顶部，选择 <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="发布图标" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publish**。
2. 在 **Publishing** 标签页中选择发布选项。
3. 如果显示 **添加付款方式**，请按提示添加付款方式。

Replit 会根据项目类型和需求，自动为你的应用选择最合适的发布选项。

如果要选择其他部署类型，请参阅以下信息。

<div id="section-4">
  ## 主要功能
</div>

发布功能提供以下便捷特性：

* **多种发布选项**：只需点击几下，即可选择或更新符合需求的部署类型。
* **自定义域名**：在您自己的域名上托管应用。
* **分析**：跟踪已发布应用的访客数据及其他指标。
* **监控工具**：查看已发布应用的状态和配置。
* **访问控制**：一键控制谁可以查看您的应用。仅 **Pro** 和 **Enterprise** 成员可用。
* **徽章设置**：Core 用户可在 Publishing 设置中管理 &quot;Made with Replit&quot; 徽章。如果您在 Starter 计划下发布了带徽章的应用，升级后可能需要几分钟徽章才会移除。
* **收集反馈**：在已发布的应用中启用反馈功能，收集用户的使用洞察。

<div id="section-5">
  ## 工作原理
</div>

发布 Replit 应用时，Replit 会为应用的文件和依赖项创建快照。
该快照会传输到 Replit 的云基础设施，并作为应用的独立实例运行。
若要让已发布的应用包含最新更改，请重新发布以创建新的快照。

<Warning>
  请勿将数据写入已发布应用的文件系统并依赖其保存。如需保存数据，请使用 Replit 的[存储与数据库](/zh/ko/learn/projects-and-artifacts/storage-and-databases)等存储或数据库方案。
</Warning>

<div id="section-6">
  ## 使用场景
</div>

以下示例展示了不同类型的已发布应用。

<div id="autoscale">
  ### Autoscale 部署：打字速度测评应用
</div>

用户进行打字测试时自动扩容，闲置时自动缩容，充分发挥云的弹性优势。

<div id="static">
  ### 静态部署：太阳系模拟
</div>

通过网页版太阳系可视化应用了解各大行星。
该可视化在浏览器中渲染，不会向服务器发送任何用户输入。

<div id="reserved-vm-discord">
  ### Reserved VM 部署：Discord 机器人
</div>

运行 Discord 机器人，协助管理成员并引导新成员加入。
价格和性能可预测，机器人始终在线，随时与用户聊天并响应命令。

<div id="scheduled">
  ### 计划部署：家庭自动化触发器
</div>

安排 API 调用，在指定的日期和时间启动或停止智能家居设备。
