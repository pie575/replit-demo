Project Security Center — это единый центр для поиска и устранения уязвимостей, связанных с безопасностью и конфиденциальностью, в Replit App. На панели **Tools** вашего проекта выберите **Security Center**, чтобы запустить сканирование, просмотреть результаты и отправить принятые проблемы Agent для исправления.

</Note>

<div id="verificaes-automticas-de-dependncias">
  ## Автоматические проверки зависимостей
</div>

Автоматические проверки зависимостей сопоставляют пакеты проекта с общедоступными реестрами уязвимостей. Эти проверки бесплатны и выполняются автоматически. Когда публикуется новая запись в базе Common Vulnerabilities and Exposures (CVE), Replit сопоставляет её с зависимостями вашего проекта и показывает совпадения на панели **Security** — без необходимости запускать повторную ручную проверку.

Проверка зависимостей поддерживает Node.js/npm, Python, Go, Rust, PHP и Ruby.

Автоматическое устранение проблем с зависимостями пока доступно только для Node.js/npm.

<div id="auto-protect">
  ### Auto-Protect
</div>

Auto-Protect расширяет возможности автоматической проверки зависимостей. Когда Replit обнаруживает соответствующую уязвимость, Agent подготавливает и тестирует исправление, а затем отправляет вам электронное письмо с прямой ссылкой. Исправление остаётся на панели **Security** в ожидании вашей проверки. После его применения заново опубликуйте приложение, чтобы исправление вошло в рабочую версию.

Auto-Protect охватывает только CVE в зависимостях. Используйте [проверку безопасности Agent](/ru/pt/features/security/agent-security-scans), чтобы проверить код приложения.

Две настройки Auto-Protect по умолчанию отключены:

<Steps>
  <Step title="Включить подготовку исправлений">
    Администратор Workspace открывает **Settings** &gt; **Account** &gt;
    **Advanced** и выбирает минимальный уровень серьёзности (низкий, средний, высокий или
    критический), при котором Replit должен подготавливать исправления.
  </Step>

  <Step title="Включить уведомления о безопасности по электронной почте">
    Откройте **Settings** &gt; **Personalization** &gt; **Email Notifications** и
    выберите минимальный уровень серьёзности, при котором вы хотите получать
    уведомления.
  </Step>
</Steps>

Для каждой новой уязвимости Replit отправляет не более одного электронного письма для каждого Workspace со сводкой по всем затронутым проектам. Выберите **Go to Task**, чтобы проверить подготовленное Agent исправление перед его применением. После применения исправления уязвимость отображается как **pending republish**, пока вы не опубликуете новую версию.

<Note>
  Исправления, подготовленные Agent, оплачиваются как любая другая работа
  Agent, даже если Auto-Protect подготовил их заранее.
</Note>

<div id="revisar-achados">
  ## Проверка результатов
</div>

Результаты проверки безопасности отображаются на панели **Security** и группируются по уровню серьёзности:

| Серьёзность             | Рекомендации                                                                                   |
| ----------------------- | ---------------------------------------------------------------------------------------------- |
| Критическая             | Риски, которые необходимо устранить до публикации                                              |
| Высокая                 | Серьёзные проблемы, которые при определённых условиях могут быть использованы злоумышленниками |
| Средняя                 | Потенциальные риски с меньшей вероятностью эксплуатации                                        |
| Низкая / Информационная | Незначительные проблемы и рекомендации по передовым практикам                                  |

Проверьте каждый результат, прежде чем принять, перепроверить или отклонить его. Отправьте принятые проблемы в Agent для исправления, а затем после внесения исправлений повторно запустите соответствующую проверку.

<div id="verificaes-de-segurana-durante-o-desenvolvimento-e-a-publicao">
  ## Проверки безопасности при разработке и публикации
</div>

<div id="verificao-de-segurana-enquanto-voc-constri">
  ### Проверка безопасности во время разработки
</div>

Когда вы работаете с Agent, Replit автоматически проверяет изменённые им файлы на распространённые небезопасные паттерны и секреты, жёстко прописанные в коде. Это первоначальная облегчённая проверка в рабочем процессе Agent, а не комплексная проверка всей кодовой базы. Результаты не отображаются отдельным отчётом на панели **Security**.

<div id="verificaes-de-publicao">
  ### Проверки при публикации
</div>

Replit также выполняет проверку безопасности перед публикацией. Настройка **Block publishing of critical vulnerabilities** определяет, что произойдёт, если проверка обнаружит критическую проблему:

* **Включено**: публикация блокируется, пока проблема не будет устранена или отклонена.
* **Выключено**: публикация продолжается, а результат остаётся доступным для проверки.

Организации Enterprise могут сделать эту настройку обязательной для всех приложений.

Эти проверки дополняют, но не заменяют полную [проверку безопасности Agent](/ru/pt/features/security/agent-security-scans) или [проверку уровня 3](/ru/pt/features/security/black-box-pen-tests).
