<div id="section">
  ## Que sont les compétences ?
</div>

Une compétence est un dossier. Il contient un fichier nommé `SKILL.md`, qui renferme les instructions qu’Agent suit, ainsi que des fichiers d’assistance supplémentaires que vous souhaitez lui fournir comme référence. Les compétences se trouvent dans le répertoire `/.agents/skills` du projet et suivent la norme ouverte [Agent Skills specification](https://agentskills.io/specification), utilisée par les agents en général.

Agent peut voir le nom et la description de toutes les compétences installées, mais ne charge leur contenu complet que lorsqu’elles sont pertinentes pour la tâche en cours. Les compétences utilisent ainsi efficacement le contexte, ce qui vous permet d’en installer un grand nombre sans nuire à la qualité des résultats d’Agent.

<div id="section-2">
  ## Compétences prédéfinies
</div>

Replit propose des compétences prédéfinies disponibles dans le sélecteur **Utiliser des compétences** du chat et dans le sélecteur du point de départ d’un nouveau projet. Ces compétences fonctionnent dans tous les projets sans installation. Consultez le [répertoire des compétences](/fr/ko/features/agent/skills-directory) pour découvrir le catalogue complet, les compétences partenaires et les instructions d’installation.

Pour ajouter une compétence prédéfinie, ouvrez le sélecteur **Utiliser des compétences** dans le champ de saisie du chat et sélectionnez une compétence, ou demandez à Agent de charger la compétence concernée.

<div id="section-3">
  ## Portée des compétences
</div>

Les compétences peuvent être définies à plusieurs niveaux :

| Portée                  | Disponibilité                                  | Emplacement de stockage                                                                                                           |
| ----------------------- | ---------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| **Niveau du projet**    | Limitée à un seul projet                       | Versionnées avec les fichiers dans `/.agents/skills`                                                                              |
| **Niveau de l’espace de travail** | Disponibles pour tous les membres de l’espace de travail | Gérées de manière centralisée dans les paramètres de l’espace de travail                                                                    |
| **Enterprise**          | Normes à l’échelle de l’entreprise             | Incluses dans les [templates personnalisés](/fr/ko/teams/custom-templates) et le [système de design](/fr/ko/teams/custom-design-system) |

Pour les compétences au niveau de l’espace de travail, consultez [Agent Customization](/fr/ko/features/agent/agent-customization) pour savoir comment configurer les compétences de l’espace de travail et les instructions personnalisées de votre équipe.

<div id="agent">
  ## Comment Agent charge les compétences
</div>

Dans chaque chat, Agent lit les métadonnées (nom et description) de toutes les compétences installées. Le contenu complet d’une compétence n’est chargé que lorsqu’Agent le juge pertinent pour la tâche en cours. Ainsi, le contenu des compétences n’entre dans la fenêtre de contexte que lorsque cela est nécessaire.

Les compétences installées restent dans le projet d’une session Agent à l’autre et peuvent être validées dans un système de contrôle de version afin d’être partagées avec les Teams.

<div id="ai">
  ## Utilisation avec d&#39;autres outils de programmation IA
</div>

<Accordion title="Importer des compétences depuis d'autres outils de programmation IA">
  Si vous utilisez plusieurs outils de programmation IA, [rulesync](https://github.com/dyoshikawa/rulesync) prend en charge Replit pour vous aider à maintenir une configuration cohérente.

  Vous pouvez importer des compétences depuis d&#39;autres assistants de programmation IA :

  ```bash theme={null}
  npx rulesync init
  npx rulesync import --targets claudecode --features skills
  npx rulesync generate --targets replit --features skills
  ```

  Cela vous permet de conserver un ensemble unique de compétences utilisable dans plusieurs environnements de développement.
</Accordion>
