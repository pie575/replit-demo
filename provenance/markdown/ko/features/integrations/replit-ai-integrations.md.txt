Replit AI 연동은 AI 기반 애플리케이션을 쉽게 빌드할 수 있게 해줍니다. OpenAI, Anthropic, Google, OpenRouter의 모델을 즉시 시작하세요. 개발자 계정 설정이나 API 키 관리가 필요하지 않습니다. Replit이 모든 것을 처리합니다.

## Replit AI 연동이란 무엇인가요?

Replit AI 연동은 주요 프로바이더의 AI 모델에 대한 관리형 접근을 제공합니다. Replit을 벗어나지 않고 채팅 앱, 콘텐츠 생성기, AI 기반 도구를 빌드하세요. 외부 개발자 계정을 만들거나 API 자격 증명을 찾거나 별도의 청구를 관리할 필요가 없습니다.

Replit AI 연동을 사용하면 Replit이 프로바이더 자격 증명을 관리하고 공개 API 가격으로 청구합니다. 사용량은 Replit 크레딧으로 청구되며 기존 Replit 앱별로 분류되어 [사용 페이지](/ko/billing/managing-spend)에 나타납니다.

<Note>
  Replit AI 연동은 유료 플랜(Core, Pro, 또는 Enterprise)이 필요합니다. [Starter 플랜](/ko/billing/plans/starter-plan)에서는 자체 API 키로 AI 앱을 빌드할 수 있습니다. [플랜 가용성](#plan-availability)을 참조하세요.
</Note>

## 기능

Replit AI 연동은 내장 접근과 투명한 청구로 AI 개발을 간소화합니다:

* **설정 불필요**: 시작하는 데 개발자 계정이나 API 키가 필요하지 않습니다
* **관리형 자격 증명**: Replit이 프로바이더 인증과 자격 증명 관리를 처리합니다
* **투명한 청구**: 공개 API 가격 지불, Replit 크레딧으로 청구됩니다
* **사용량 추적**: 사용 페이지에서 기존 Replit 앱별 사용량을 확인하세요
* **크로스 스택 지원**: 모든 프로그래밍 언어와 프레임워크에서 작동합니다
* **선택적 BYOK**: 자체 자격 증명을 사용하려면 자체 API 키를 가져올 수 있습니다

## 시작하기

### Replit 관리형 자격 증명 사용하기

프롬프트에서 AI 기능이나 특정 프로바이더(OpenAI, Anthropic, Google, 또는 OpenRouter)를 언급하면 Agent가 기본적으로 Replit AI 연동을 사용합니다:

<AiPrompt>
  Create a web app that uses OpenAI to summarize articles
</AiPrompt>

초기 프롬프트 응답에서 **"OpenAI (Replit managed)"**, **"Anthropic (Replit managed)"**, **"Google (Replit managed)"**, 또는 \*\*"OpenRouter (Replit managed)"\*\*을 찾으면 어떤 연동이 사용되는지 알 수 있습니다. 이는 Agent가 자체 API 키를 요구하는 대신 Replit의 자격 증명을 사용할 것임을 나타냅니다.

**초기 빌드의 경우**: AI 기능이 포함된 새 앱을 만들기 위한 초기 프롬프트를 제출하면 Replit AI 연동이 자동으로 매칭됩니다. Agent가 즉시 Replit의 관리형 자격 증명으로 빌드를 시작합니다.

**기존 Replit 앱의 경우**: Agent가 기존 Replit 앱에 AI 기능을 추가하려고 감지하면 프로젝트 편집기에서 자체 API 키 대신 Replit AI 연동 사용을 요청한다고 명시적으로 알려줍니다. 확인 프롬프트가 표시됩니다:

Replit 관리형 자격 증명으로 계속하려면 "승인"을 클릭하고, 자체 API 키를 사용하려면 "해제"를 클릭하세요.

사용량은 자동으로 추적되며 공개 API 가격으로 Replit 계정에 청구됩니다.

### 자체 API 키 사용하기

Replit AI 연동 대신 OpenAI, Anthropic, Google, 또는 다른 프로바이더의 자체 자격 증명을 사용하려면 몇 가지 옵션이 있습니다:

**초기 빌드의 경우**: 프롬프트에 자체 API 키를 사용하고 싶다고 포함하세요:

<AiPrompt>
  Create a web app that uses OpenAI to summarize articles. Use my own OpenAI API key.
</AiPrompt>

응답에서 "Replit managed" 없이 프로바이더 이름만 표시되면 Agent가 API 키를 요청할 것임을 나타냅니다.

**기존 Replit 앱의 경우**: Agent가 Replit AI 연동을 사용하려 하고 확인 프롬프트를 표시할 때 "승인" 대신 "해제"를 클릭하세요.

두 경우 모두 Agent가 API 키를 요청하기 전에 첫 번째 체크포인트까지 빌드합니다. 이를 통해 Agent가 먼저 프로젝트 구조를 설정한 다음 자격 증명을 수집하기 위해 일시 정지할 수 있습니다.

자체 API 키를 사용하면 Replit 크레딧이 아닌 프로바이더에게 직접 청구됩니다.

## 사용량 보기

모든 Replit AI 연동 사용량은 다른 Replit 사용량과 함께 [사용 페이지](/ko/billing/managing-spend)에 나타납니다. 사용량은 기존 Replit 앱별로 분류되므로 AI 지출이 어디로 가는지 정확하게 알 수 있습니다.

## 지원되는 프로바이더

Replit AI 연동은 현재 다음을 지원합니다:

* **OpenAI**: 텍스트 생성, 추론, 오디오를 위한 멀티모달 모델. 채팅 완성, 응답, 이미지 생성, 오디오 전사(`gpt-4o-transcribe`, `gpt-4o-mini-transcribe`), 오디오 출력(`gpt-audio`, `gpt-audio-mini`)을 지원합니다.
* **Anthropic**: 추론, 글쓰기, 코딩을 위한 멀티모달 모델. Messages API와 웹 검색 상호작용을 지원합니다.
* **Google (Gemini)**: 텍스트 생성 및 추론을 위한 멀티모달 모델. 텍스트와 이미지 생성을 지원합니다.
* **OpenRouter**: Microsoft(Phi 시리즈), Meta(Llama 시리즈), Mistral, Qwen, DeepSeek, Nvidia, Amazon 등의 프로바이더 모델에 접근합니다.

<Note>
  Replit AI 연동은 **텍스트, 이미지, 오디오 출력**을 지원합니다. 동영상 출력은 지원되지 않습니다. 동영상 생성 기능이 필요하면 이를 제공하는 프로바이더에서 자체 API 키를 사용해야 합니다.
</Note>

## OpenRouter 개인 정보 보호 및 사용 가능 여부

Replit AI 연동을 통해 OpenRouter를 사용할 때 데이터를 보호하기 위한 특정 개인 정보 보호 설정으로 요청이 전송됩니다. 이러한 설정은 사용 가능한 모델에 영향을 미칠 수 있으므로 이해하는 것이 중요합니다.

### 셀프 서브 사용자의 개인 정보 보호 설정

개인 및 팀 사용자의 경우 Replit은 다음 기본 개인 정보 보호 설정으로 OpenRouter 요청을 구성합니다:

* **유료 엔드포인트 훈련 비활성화**: 유료 모델 프로바이더가 데이터를 훈련에 사용하지 않습니다
* **무료 엔드포인트 훈련 활성화**: 무료 모델 프로바이더가 프롬프트와 완성에 대해 훈련할 수 있습니다
* **무료 엔드포인트 게시 활성화**: 무료 프로바이더가 프롬프트와 완성을 공개 데이터셋에 게시할 수 있습니다
* **입력/출력 로깅 비활성화**: 1% 청구 할인을 위해 OpenRouter가 요청과 응답을 기록하지 않습니다
* **분석 쿠키 비활성화**: 분석 쿠키가 사용되지 않습니다

이러한 설정은 가장 넓은 범위의 모델에 접근할 수 있도록 하면서 개인 정보를 우선시합니다. 그러나 위에서 구성된 것과 다른 개인 정보 보호 설정이 필요한 경우 **일부 모델을 사용할 수 없을 수 있습니다**.

### Enterprise의 개인 정보 보호 설정

Enterprise 조직의 경우 Replit이 더 엄격한 개인 정보 보호 제어를 적용합니다:

* **제로 데이터 보존(ZDR) 엔드포인트만**: 제로 데이터 보존 정책이 있는 모델만 사용 가능합니다
* 셀프 서브 사용자에 대한 위의 모든 개인 정보 보호 설정도 적용됩니다
* 이를 통해 Enterprise 요청이 데이터를 보존하지 않는 엔드포인트로만 라우팅됩니다

Enterprise는 ZDR 엔드포인트만 적용하므로 **사용 가능한 모델 선택이 셀프 서브 사용자보다 더 제한적**입니다. 이 트레이드오프는 엔터프라이즈 워크로드에 대한 최고 수준의 데이터 개인 정보 보호를 보장합니다.

## 플랜 가용성

Replit AI 연동은 유료 플랜이 필요합니다. 접근 방식은 플랜에 따라 다릅니다.

### Starter (무료)

Starter 플랜에서는 Replit AI 연동이 비활성화됩니다. 자체 API 키로 AI 앱을 빌드할 수 있습니다. [자체 API 키 사용하기](#bringing-your-own-api-key)를 참조하세요.

### Core

Core 플랜에서는 Replit 관리형 자격 증명으로 Replit AI 연동을 사용하여 AI 앱을 빌드할 수 있습니다. API 키 관리가 필요하지 않습니다.

### Pro 및 Enterprise

Pro 및 Enterprise 조직의 경우 Replit AI 연동 접근이 기본적으로 비활성화됩니다. 조직 관리자는 조직 설정 페이지에서 접근을 제어할 수 있습니다:

1. 조직 설정으로 이동하세요
2. Replit AI 연동 섹션을 찾으세요
3. 조직에 대해 접근을 켜거나 끄세요

활성화하면 조직 구성원이 앱에서 Replit AI 연동을 사용할 수 있습니다. 모든 사용량이 추적되어 조직 계정에 청구됩니다. 비활성화하면 구성원이 AI 모델 프로바이더를 사용하기 위해 자체 API 키를 제공해야 합니다.

## 사용 사례

모든 스택에서 강력한 AI 애플리케이션을 빌드하세요:

* **콘텐츠 생성**: 기사 요약, 설명 생성, 콘텐츠 작성
* **분석 및 인사이트**: 핵심 정보 추출, 감정 분석, 텍스트 분류
* **대화형 인터페이스**: 챗봇과 AI 어시스턴트 빌드
* **텍스트 변환**: 콘텐츠 번역, 재작성, 형식 변환
* **코드 지원**: 코드 스니펫 생성, 알고리즘 설명, 코드 리뷰

  </Accordion>

  <Accordion title="자체 API 키를 사용할 수 있나요?">
    네. Replit 시크릿을 사용하여 자체 API 키를 제공할 수 있습니다. 자체 키를 사용하면 Replit을 통하지 않고 프로바이더에게 직접 청구됩니다.
  </Accordion>

  <Accordion title="모든 프로그래밍 언어에서 작동하나요?">
    네. Replit AI 연동은 Replit에서 지원하는 모든 스택과 프로그래밍 언어에서 작동합니다.
  </Accordion>

  <Accordion title="내 계정이나 조직에서 이 기능을 사용할 수 없는 이유는 무엇인가요?">
    Starter 플랜에서는 Replit AI 연동이 비활성화됩니다. Core로 업그레이드하면 사용하거나, 자체 API 키로 빌드할 수 있습니다. Pro 및 Enterprise의 경우 보안과 제어를 위해 접근이 기본적으로 비활성화되며, 조직 관리자가 조직 설정 페이지에서 활성화할 수 있습니다.
  </Accordion>

  <Accordion title="Replit AI 연동을 사용하고 있는지 어떻게 알 수 있나요?">
    Agent의 응답에서 "OpenAI (Replit managed)", "Anthropic (Replit managed)", "Google (Replit managed)", 또는 "OpenRouter (Replit managed)"를 찾으세요. 이는 Replit AI 연동을 사용하고 있음을 나타냅니다. "Replit managed" 없이 프로바이더 이름만 표시되면 Agent가 자체 API 키를 요청할 것입니다.
  </Accordion>

  <Accordion title="Replit AI 연동을 사용하면 어떻게 되나요?">
    AI 기능이나 특정 프로바이더(OpenAI, Anthropic, Google, 또는 OpenRouter)를 언급하면 Agent가 기본적으로 Replit AI 연동을 사용합니다. 새 앱의 경우 Agent가 즉시 Replit의 자격 증명으로 빌드를 시작합니다. 기존 Replit 앱의 경우 Agent가 프로젝트 편집기에서 Replit AI 연동 사용을 요청하고 확인 프롬프트를 표시합니다. 어느 경우든 앱이 프로바이더에 API 호출을 할 수 있으며 사용량이 추적되어 Replit 계정에 청구됩니다.
  </Accordion>

  <Accordion title="확인 프롬프트는 언제 표시되나요?">
    기존 Replit 앱에 Replit AI 연동을 추가할 때 확인 프롬프트가 표시됩니다. Agent가 자체 API 키 대신 Replit AI 연동 사용을 요청한다고 명시적으로 알려줍니다. 새 앱을 만들기 위한 초기 빌드의 경우 팝업 없이 Replit AI 연동이 자동으로 매칭됩니다.
  </Accordion>

  <Accordion title="자체 API 키를 사용하려면 Agent가 언제 요청하나요?">
    Agent가 첫 번째 체크포인트까지 빌드한 다음 API 키를 요청합니다. 이를 통해 Agent가 먼저 프로젝트 구조를 설정한 다음 자격 증명을 수집하기 위해 일시 정지하고 계속할 수 있습니다.
  </Accordion>

  <Accordion title="어떤 유형의 모델 및 출력이 지원되나요?">
    Replit AI 연동은 텍스트, 이미지, 오디오 출력을 지원합니다. 오디오 기능에는 `gpt-4o-transcribe` 및 `gpt-4o-mini-transcribe`를 통한 전사(음성-텍스트 변환)와 `gpt-audio` 및 `gpt-audio-mini`를 통한 오디오 생성이 포함됩니다. 동영상 출력은 지원되지 않습니다. 애플리케이션에 동영상 생성 기능이 필요하면 Agent가 해당 기능을 제공하는 프로바이더에서 자체 API 키를 사용하도록 안내합니다.
  </Accordion>
</AccordionGroup>
