Seu Projeto é visível apenas para pessoas e grupos que você convidar explicitamente. Se quiser compartilhar seu projeto publicamente, publique-o como público para compartilhar a versão publicada com qualquer pessoa que tenha o URL.

Para espaços de trabalho de organização, o [gerenciamento de acesso](/pt/teams/identity-and-access-management/repl-access-management) e as configurações de administrador também se aplicam.

## Visibilidade ao criar um Projeto

Quando você cria um Projeto em um espaço de trabalho, os membros desse espaço de trabalho terão acesso a ele. Adicione colaboradores e ajuste quem pode ver o projeto em **Acesso** e compartilhamento.

Para o conjunto completo de controles da organização, consulte [Gerenciamento de acesso](/pt/teams/identity-and-access-management/repl-access-management) e [grupos e permissões](/pt/teams/identity-and-access-management/groups-and-permissions).
