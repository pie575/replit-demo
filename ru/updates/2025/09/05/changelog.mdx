<div id="general-agent">
  ### General Agent
</div>

<Frame>
  <img src="/assets/mirror/general-agent-240ff289e711.png" alt="Обложка General Agent" width="1040" height="572" data-path="images/replitai/general-agent.png" />
</Frame>

Replit Agent теперь работает с любым codebase на любом языке или фреймворке, который запускается на NixOS! Раньше Agent был ограничен определёнными шаблонами, а теперь он может помогать с фреймворками для разработчиков, импортом из GitHub и любой пользовательской конфигурацией project. Благодаря этому масштабному расширению полноценная помощь ИИ в написании кода становится доступной в корпоративных сценариях и рабочих процессах опытных пользователей.

Подробнее о General Agent читайте [здесь](/ru/core-concepts/agent/general-agent).

<div id="plan-mode">
  ### Режим Plan
</div>

<Frame>
  <img src="/assets/mirror/plan-mode-overview-8077807c63b9.png" alt="Интерфейс чата с Agent в режиме Plan" width="916" height="362" data-path="images/replitai/plan-mode-overview.png" />
</Frame>

Режим Plan — это новый способ общения с Replit Agent, ориентированный на вопросы, генерацию идей и планирование работы. В режиме Plan вы можете попросить Agent составить список задач на будущее, а затем выполнить длительные задачи в режиме Build.

Подробнее о режиме Plan читайте [здесь](/ru/core-concepts/agent/plan-mode).

  ## Enterprise

<div id="gcp-marketplace-integration">
  ### Интеграция с GCP Marketplace
</div>

Клиенты Enterprise теперь могут приобрести Replit напрямую через Google Cloud Platform Marketplace и оплатить покупку имеющимися кредитами GCP. Это упрощает процесс закупки и позволяет организациям с бюджетом в GCP быстрее внедрить Replit в свои процессы разработки.
