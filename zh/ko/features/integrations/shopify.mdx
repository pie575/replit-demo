借助 Shopify 连接器，Agent 可以预配 Shopify 商店、构建自定义店面，并在一次 Conversation 中管理商品和库存，无需 API 密钥。只要说明你要销售实体商品，Agent 就会推荐 Shopify；仅在准备上线时才需访问 Shopify。从第一个提示词到真实订单，整个过程约需 10 分钟。

<Note>
  有关分步指南，请参阅[构建 Shopify 店面](/zh/ko/build/ecommerce-store)。
</Note>

<div id="section">
  ## 可构建的内容
</div>

* 面向实体产品的定制化设计店面
* 品牌周边及服装商店
* 支持购物车和支付功能的 D2C 电商网站
* 基于 Shopify 商店的商品目录和库存管理工具
* 用于销售单一主打商品的产品着陆页

<div id="section-3">
  ## 工作方式
</div>

<Steps>
  <Step title="描述你的商店">
    告诉 Agent 你想卖什么。即使未指定名称，对于实体产品，Agent 也会推荐 Shopify。

    <Frame>
      <img src="/assets/mirror/describe-your-store-b5d724daee99.png" alt="Replit 提示词框中已输入蜡烛商店提示词" width="1440" height="900" data-path="images/replitai/shopify/describe-your-store.png" />
    </Frame>
  </Step>

  <Step title="Agent 预配商店">
    系统会在 Replit 的 Shopify Partner 账户下创建开发商店 (约需 10 秒) ，并安装 Replit Sales Channel 应用来连接商店。无需 API 密钥。每个应用对应一个商店。在认领前，商店会受到密码保护。

    <Frame>
      <img src="/assets/mirror/connect-shopify-store-7f36389f976f.png" alt="Replit Agent 通过 Shopify 技能交接，并显示带有 Connect Shopify 按钮的“Connect to Shopify”卡片" width="3452" height="1984" data-path="images/replitai/shopify/connect-shopify-store.png" />
    </Frame>
  </Step>

  <Step title="Agent 构建和管理">
    Agent 会设计无头店面，并管理产品、选项、库存、商品系列和折扣。

    <Frame>
      <img src="/assets/mirror/add-product-8b098e606340.png" alt="店面商品网格中显示带有名称和价格的蜡烛产品" width="3452" height="1978" data-path="images/replitai/shopify/add-product.png" />
    </Frame>
  </Step>

  <Step title="在 Shopify 上线">
    准备好销售后，认领商店、选择套餐、设置付款，然后上线。

    <Frame>
      <img src="/assets/mirror/claim-store-4facb8c8b10c.png" alt="Replit 的“Claim your store”界面，其中包含“Claim store”按钮" width="3452" height="1978" data-path="images/replitai/shopify/claim-store.png" />
    </Frame>
  </Step>
</Steps>

<div id="agent">
  ## Agent 可管理的内容
</div>

您可以通过聊天编辑店面和商品目录中的所有内容。

| 区域    | Agent 可执行的操作                                                                                                                               |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 设计    | 根据您的指示创建无头前端 (不使用 Liquid 主题或模板库) 。您可以通过聊天编辑文案、布局、导航、动效和产品页面，并使用 [Canvas](/zh/ko/design/canvas) 变体探索不同方向。这是一个真正的 Replit 项目，因此还可以扩展为博客、心愿单或着陆页。 |
| 产品    | 创建、修改和删除产品及选项。字段包括：标题、描述、类型、供应商、标签、SKU、价格、重量、选项 (尺寸、颜色) 、图片和可用性。                                                                           |
| 库存    | 按选项设置和调整库存。                                                                                                                                |
| 系列    | 将产品归入系列。                                                                                                                                   |
| 折扣    | 创建价格规则和可用代码。                                                                                                                               |
| 发布和同步 | 新产品会自动发布到店面。双向同步：在 Shopify 管理后台所做的修改会反映在 Replit 预览中，Agent 所做的更改会反映在 Shopify 管理后台。                                                          |

<div id="replit-shopify">
  ## Replit 与 Shopify：职责分工
</div>

| Replit 负责              | Shopify 负责          |
| ---------------------- | ------------------- |
| 店面的设计和构建             | 托管式结账               |
| 通过聊天管理商品目录 (产品、库存、折扣)  | 产品、库存、购物车和订单的记录系统   |
| 店面的托管和部署             | 收款、身份验证 (KYC) 和款项支付 |
| Canvas 设计变体            | 税务、配送和履约            |
| 应用扩展 (博客、着陆页等)         | 多渠道销售               |

订单、退款、款项支付和履约均在 Shopify 管理后台中处理，而非由 Agent 处理。

<div id="section-4">
  ## 连接范围
</div>

* 所有应用的创建者都可以通过 Conversation 建立连接，无需 API 密钥或在 Connectors 面板中进行设置。
* 每个应用一个作用域：每个应用都有专属的 Shopify 商店。
* 在认领前，商店属于 Replit 的开发商店。系统会与 Shopify 共享您的电子邮箱，以便您之后认领商店。
* 您随时可以在 Shopify 管理后台移除 Replit 应用。

<div id="shopify">
  ## 在 Shopify 上线
</div>

上线流程在 Shopify 中完成，而非 Replit。请 Agent 启动 Go Live 流程后，在 Shopify 管理后台完成以下需由商家操作的步骤：

* **认领商店**：通过聊天中的链接或 Shopify 发送的电子邮件认领商店。链接将在 7 天后失效。认领后将开始免费试用。
* **选择套餐**：要处理真实订单，需订阅[付费套餐](https://www.shopify.com/pricing)。
* **支付设置**：启用 [Shopify Payments](https://help.shopify.com/en/manual/payments/shopify-payments) 或其他服务商，并完成身份验证 (KYC)。认领账户完成 KYC 后，即可接受真实付款。
* **设置[配送](https://help.shopify.com/en/manual/shipping)和[税费](https://help.shopify.com/en/manual/taxes)。**
* **[连接自定义域名](/zh/ko/build/add-custom-domain)** (可选) ，然后移除商店密码，向买家开放商店。

结账时始终会重定向到 Shopify 托管的结账页面，因此买家将在 Shopify 完成付款。

<Note>
  支付、身份验证、税费、配送和欺诈检查均由 Shopify 处理。Replit 不会收集商家的银行信息、税务 ID 或其他敏感信息。
</Note>

<div id="section-5">
  ## 故障排查
</div>

<AccordionGroup>
  <Accordion title="设置 Shopify 商店需要一些时间">
    预配过程中需要调用多个 Shopify API，因此可能需要一些时间。Agent 完成设置后，请让它构建店面。
  </Accordion>

  <Accordion title="开发期间结账时显示密码页面">
    开发商店在上线前受密码保护，因此结账预览可能会跳转至密码页面。这是预期行为，但购物车仍可正常使用。仅在发布时才在 Shopify 中移除密码。
  </Accordion>

  <Accordion title="无法在结账时完成实际付款">
    实际付款需要已认领的 Shopify 账户完成付款设置和 KYC。在此之前，结账会重定向至 Shopify，但无法完成付款。请完成 KYC，或使用已设置付款的账户。
  </Accordion>

  <Accordion title="Agent 表示此应用未连接 Shopify">
    每个商店只能关联一个应用。如果你在其他应用中连接了 Shopify，请让 Agent 在当前应用中设置 Shopify 商店。
  </Accordion>

  <Accordion title="店面中未显示产品">
    产品仅在启用并发布后才会显示。Agent 创建的产品会自动发布。如果有产品未显示，请让 Agent 将其发布，然后刷新预览。
  </Accordion>

  <Accordion title="迁移后需要重新连接">
    认领或迁移商店后，Shopify 可能会要求重新验证连接。请让 Agent 重新连接 Shopify，即可在不丢失商店数据的情况下恢复访问权限。
  </Accordion>
</AccordionGroup>
