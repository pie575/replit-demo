  ### 支持 Claude Opus 4.5
</div>

AI Integrations 现已支持 Claude Opus 4.5，让你能够使用 Anthropic 专为编码和智能体场景优化的最新 AI 能力。

<div id="replit">
  ### “在 Replit 中打开”按钮 (Beta) 
</div>

有了全新的“在 Replit 中打开”按钮，你现在可以直接在 Replit 中处理 Linear 工单。该 Beta 功能需要在偏好设置中启用，启用后会自动将 issue 详情填入提示词。团队正在与 Linear 合作，进一步完善该集成。

<div id="agent-sql">
  ### Agent 访问生产环境 SQL 数据库
</div>

Agent 现在可以以只读模式查看和查询生产环境 SQL 数据库，让你能够基于真实的生产数据开展工作，而无需担心意外修改数据的风险。

<div id="section-3">
  ### 连接稳定性改进
</div>

为提升集成体验带来的多项改进：

* 优化后台重连流程，降低连接令牌过期的概率
* 连接处于异常/错误状态时给出明确提示
* 支持在错误状态下直接重新连接集成

<div id="section-5">
  ### 用户/群组级预算
</div>

预算管理功能现已面向所有企业版客户开放：

* 企业版团队管理员可为全体成员设置默认用量预算
* 管理员可为特定群组 (如管理员/成员及自定义群组) 设置预算
* 即将推出：管理员可为单个用户设置覆盖预算
