<div id="replit">
  ## Qu&#39;est-ce qu&#39;une application Replit ?
</div>

Une application Replit est un projet hébergé dans le cloud qui regroupe le code, les données et les ressources.
Vous pouvez créer, exécuter et publier vos applications dans un environnement sécurisé et isolé.

Les applications Replit s&#39;intègrent aux outils suivants de l&#39;éditeur de projet
pour offrir une expérience de développement fluide :

* **Outils basés sur l&#39;IA** : utilisez Agent pour créer, déboguer et expliquer votre code.
* **Collaboration** : travaillez à plusieurs sur la même application en temps réel.
* **Publication** : publiez votre application dans le cloud en un seul clic.

<div id="section-2">
  ## Fonctionnalités principales
</div>

Les applications Replit offrent les fonctionnalités suivantes :

* **Aucune configuration requise :** créez des applications ou écrivez du code directement sur Replit.com, sans installation ni configuration.
* **Enregistrement automatique :** votre projet enregistre vos modifications en continu dans le cloud, ce qui vous permet de reprendre le développement depuis n&#39;importe quel navigateur web.
* **Gestion de versions :** suivez vos modifications, parcourez l&#39;historique des fichiers et synchronisez-les grâce au système de gestion de versions de Replit, sans configuration supplémentaire.
* **Contrôle de la visibilité publique/privée :** définissez qui peut consulter, exécuter ou remixer votre application grâce aux paramètres de confidentialité.
* **Publication :** publiez votre code dans le cloud sans changements de configuration complexes.
* **URL d&#39;application personnalisée :** obtenez une URL unique pour votre application ou associez-lui un domaine personnalisé pour une présence professionnelle.

<Info>
  Les fichiers téléversés dans le système de fichiers du projet ne sont disponibles que pendant le développement
  et ne sont accessibles ni aux applications publiées ni aux autres builders. Pour gérer les téléversements des builders et servir des fichiers, utilisez [Object
  Storage](/fr/ko/features/data-and-storage/object-storage) ; pour stocker et récupérer les données de votre application et de vos utilisateurs, utilisez [Replit
  Database](/fr/ko/features/data-and-storage/sql-database).
</Info>

Pour en savoir plus sur les outils de l&#39;éditeur de projet qui simplifient la création d&#39;applications Replit, consultez la [présentation de l&#39;éditeur de projet](/fr/ko/learn/projects-and-artifacts/project-editor/).

<div id="section-3">
  ## Comment ça fonctionne
</div>

Lorsque vous créez une application Replit, Replit configure un espace privé dans le cloud pour votre projet.
À mesure que vous ajoutez des fonctionnalités et apportez des modifications à votre application, Replit enregistre automatiquement vos changements afin que vous puissiez
reprendre vos modifications depuis n’importe quel navigateur web.

Replit fournit un environnement préconfiguré comprenant tous les composants nécessaires.
Vous pouvez donc commencer immédiatement à créer votre application sans vous soucier de la configuration du serveur, de la mise en place de la base de données
ni de la gestion de l’environnement.

Replit attribue automatiquement à chaque application Replit une adresse web unique qui vous permet de prévisualiser votre application
pendant que vous y travaillez. Lorsque vous êtes prêt à la partager, vous pouvez
la publier en quelques clics pour la rendre accessible 24 h/24 et 7 j/7.

<div id="section-4">
  ## Présentation du stockage
</div>

Replit propose quatre principaux types de stockage pour répondre aux besoins en données de votre application. Chaque type de stockage prend en charge différents cas d’utilisation et est soumis à des limites spécifiques selon votre forfait.

<Info>
  Les limites de stockage incluent toutes les données stockées par votre application, y compris les packages et dépendances installés.
</Info>

| Type de stockage                                                            | Description                      | Cas d’utilisation                                                      | Persistance                                                  | Limites du forfait                                                                                                                                   |
| --------------------------------------------------------------------------- | -------------------------------- | ---------------------------------------------------------------------- | ------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Stockage de fichiers**                                                    | Fichiers du projet               | Code de l’application, ressources statiques, fichiers de configuration | Conservé lors de la publication, réinitialisé au redémarrage | Starter: {StarterWorkspaceStorage}<br />Core: {CoreWorkspaceStorage}<br />Pro: {TeamsWorkspaceStorage}<br />Enterprise: {EnterpriseWorkspaceStorage} |
| **[Base de données](/fr/ko/features/data-and-storage/sql-database/)**          | Stockage de données structurées  | Profils utilisateur, scores de jeu, catalogues de produits             | Entièrement persistant entre les sessions                    | 20 Go par base de données de développement<br />Les bases de données de production sont facturées en fonction du temps de calcul et du stockage      |
| **[Stockage d’application](/fr/ko/features/data-and-storage/object-storage/)** | Données et médias non structurés | Images, vidéos, PDF, documents                                         | Entièrement persistant entre les sessions                    | Modèle basé sur l’utilisation<br />Facturé en fonction du stockage et de la bande passante                                                           |
| **[Secrets](/fr/ko/core-concepts/project-editor/app-setup/secrets/)**          | Données sensibles chiffrées      | Clés API, identifiants, chaînes de connexion                           | Entièrement persistant et chiffré                            | Aucune limite spécifique<br />Inclus dans tous les forfaits                                                                                          |
