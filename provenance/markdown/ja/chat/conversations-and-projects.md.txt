Replitを使うとき、あなたはConversationで作業しているか、プロジェクトを構築しているかのどちらかです。Conversationsは質問、探索、フォローアップ、Routines向けです。Projectsはアプリケーションの構築や、スライド・デザインの作成向けです。

[Conversationをプロジェクトに変える方法を学ぶ。](/ja/chat/continue-or-create-a-project)

## 両者の違い

ConversationsとProjectsは関連していますが、目的が異なります。両者の違いは次のとおりです。

| 項目          | Conversations        | Projects                                                                                            |
| ----------- | -------------------- | --------------------------------------------------------------------------------------------------- |
| 最適な用途       | 質問、探索、Routines       | アプリ、スライド、ダッシュボード、複数のアーティファクトなど、より本格的な構築・デザイン作業                                                      |
| 構造          | 単一のスレッド              | 複数のアーティファクトを持つプロジェクトワークスペース                                                                         |
| バックグラウンドタスク | 利用不可                 | 並行して実行可能                                                                                            |
| Routines    | 利用可能                 | 利用不可                                                                                                |
| インテグレーション   | 利用可能                 | 利用可能                                                                                                |
| 作成できるもの     | ドキュメント、画像、シートなどのアセット | ドキュメント、画像、シートなどのアセットに加え、スライド、アプリ、Webサイトなどの[アーティファクト](/ja/features/projects-and-artifacts/artifacts) |
| 公開          | 公開できない               | 公開して一般に開放できる                                                                                        |
