探索拓展可能性，细化打磨细节。当 frame 已接近你想要的效果时，可根据自己的工作方式使用以下两种工具进一步完善：

* 用自己的话与 Agent 沟通，调整整个 frame 或单个元素
* 通过 Visual Editor 直接调整元素，简单编辑即时生效，且不消耗积分

<div id="chat">
  ## Chat
</div>

像在评审时对设计师讲解那样,把想法告诉 Agent。选中一个 frame,在主 Chat 中描述你想要的改动(*&quot;配色再暖一些&quot;*、*&quot;首屏看起来有点空&quot;*),或者在工具栏中选择 **Chat** 工具,再点击某个元素,把这条消息的范围限定在该部分。

<Frame caption="选中的 frame 会以标签形式附加到主 Chat 中。">
  <img src="/assets/mirror/chatbox-9baff03cb443.png" alt="Canvas 上选中的一个 Design frame(Configurator First),左侧为主 Chat 面板,其消息框显示 'Describe what you want to design…',并附有一个 Configurator First 标签" width="2000" height="1250" data-path="images/design/replit-design/chatbox.png" />
</Frame>

关于这两种入口,请参阅 [Chat](/zh/pt/design/chat-about-your-design)。

<div id="visual-editor">
  ## Visual Editor
</div>

当你已经清楚知道自己想要什么时，就不必再写 prompt 了。在工具栏中选择 **Edit** 工具，然后点击任意元素，Visual Editor 便会打开并显示该元素可编辑的属性，例如内容、布局、颜色和边框。修改文本、选择颜色、调整间距这类简单编辑会即时应用到源代码中，且不消耗积分。

<Frame caption="Edit 工具已启用并选中了一个元素，Visual Editor 显示其可编辑属性。">
  <img src="/assets/mirror/visual-editor-edit-tool-71d03803471f.png" alt="一个超级跑车配置器 frame，Edit 工具已启用并选中了一个元素，右侧显示 Visual Editor 面板，其中包含 Layout、Color 和 Border 部分，以及 Discard 和 Save edits 按钮" width="2000" height="1250" data-path="images/replitai/visual-editor-edit-tool.png" />
</Frame>

完整的控件参考请查看 [Visual Editor](/zh/pt/design/visual-editor)。

<div id="qual-ferramenta-usar">
  ## 该使用哪个工具
</div>

| 你想……                    | 使用            |
| ----------------------- | ------------- |
| 描述想要的效果，让 Agent 搞定细节    | Chat          |
| 把某个元素的文本、颜色、间距或图片改成确定的值 | Visual Editor |
| 重构某个板块的结构或行为            | Chat          |
| 做一次快速且不消耗积分的微调          | Visual Editor |

这两个工具天然互补：先用对话定下方向，再用 Visual Editor 点选打磨细节。
