SEO Agent проводит технический SEO-аудит всего вашего проекта и выявляет проблемы, из-за которых поисковым системам и ИИ-краулерам трудно найти и понять ваше приложение. Каждая找 находка превращается в исправление в один клик, которое вы можете просмотреть и применить с помощью Agent.

Он находится на панели **Growth** в Project Editor и работает с приложениями, которые вы уже опубликовали. У большинства авторов порядок работы такой: опубликуйте приложение, откройте SEO Agent, запустите проверку, просмотрите результаты и примените исправления.

<div id="o-que-o-seo-agent-faz">
  ## Что делает SEO Agent
</div>

SEO Agent занимается **техническим SEO** — структурными и машиночитаемыми частями вашего приложения, от которых зависит, насколько легко поисковые системы и ИИ-краулеры смогут его найти, проиндексировать и понять.

Он анализирует ваш проект и предлагает исправления для таких проблем, как:

* **Сканируемость и индексация**: `robots.txt`, `sitemap.xml` и доступная для сканирования структура ссылок и страниц.
* **Метаданные страниц**: уникальные и информативные теги `<title>` и meta description на всех страницах.
* **Структурированные данные**: разметка JSON-LD, которая помогает поисковым системам показывать расширенные результаты.
* **Open Graph и социальные теги**: метаданные, определяющие, как выглядят предпросмотры ваших ссылок при публикации.
* **Семантическая разметка**: правильный порядок заголовков, элементы-ориентиры и описательный текст `alt` у изображений.

<Note>
  SEO Agent следит за тем, чтобы созданное вами приложение было технически готово к поиску,
  но он не пишет контент и не выстраивает за вас тематический авторитет.
</Note>

<div id="antes-de-comear">
  ## Прежде чем начать
</div>

Для работы SEO Agent необходимо:

* **Опубликованное приложение.** SEO Agent проверяет активный публичный веб-deployment, поэтому сначала опубликуйте приложение, если вы ещё этого не сделали. О типах deployment с поддержкой SEO читайте в разделе [SEO Rating](/ru/pt/features/publishing/seo-rating).
* **Платный тариф.** SEO Agent доступен создателям на платном тарифе. Если вы используете бесплатный тариф, в панели Growth появится предложение перейти на платный.

Открыть SEO Agent можно двумя способами: перейти в панель **Growth** прямо в Project Editor или выбрать **Optimize SEO with Agent** рядом с SEO-оценкой в инструменте **Publishing** — откроется панель Growth, готовая к проверке.

<Tip>
  Чтобы управлять тем, как ваше приложение выглядит в предпросмотре при публикации в соцсетях, подключите
  [собственный домен](/ru/pt/build/add-custom-domain) и опубликуйте приложение заново. Предпросмотры в соцсетях и для ссылок
  используют публичный продакшен-URL вашего приложения, поэтому опубликованный собственный домен
  гарантирует корректный предпросмотр.
</Tip>

<div id="o-seo-agent-e-sua-classificao-de-seo">
  ## SEO Agent и ваша SEO-оценка
</div>

**SEO-оценка**, отображаемая рядом с SEO Agent, формируется по результатам [автоматического аудита Lighthouse](/ru/pt/features/publishing/seo-rating), который запускается после каждой публикации и относит ваше приложение к категории Healthy, Needs Work или Weak. Оценка показывает, *на каком уровне находится ваше приложение*.
SEO Agent помогает *улучшить его*: он находит проблемы и применяет исправления. После повторной публикации оценка обновляется.

Можно и вовсе не открывать интерфейс проверки, а просто попросить Agent напрямую:

<AiPrompt>
  Audit my site for SEO best practices and apply the fixes. Add a sitemap,
  robots.txt, Open Graph tags, structured data where it makes sense, and make
  sure every page has a unique title and meta description.
</AiPrompt>
