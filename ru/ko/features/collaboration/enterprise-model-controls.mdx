Управление моделями в Enterprise позволяет администраторам аккаунта определять, какие модели Agent доступны разработчикам. Задайте политику на уровне аккаунта, а затем настройте отдельный доступ к моделям для каждого рабочего пространства.

<Note>
  Управление моделями доступно только администраторам аккаунтов Enterprise. Чтобы подключить эту возможность для вашей организации, обратитесь в отдел продаж ([sales@replit.com](mailto:sales@replit.com)).
</Note>

<div id="section">
  ## Использование интеллектуальной маршрутизации моделей
</div>

Интеллектуальная маршрутизация моделей — стандартная среда Agent для рабочих пространств Enterprise. Когда включён **Auto mode**, Replit подбирает оптимальные режим и модель для каждой задачи, обеспечивая баланс между качеством и стоимостью.

Маршрутизация выполняется среди моделей из пула, одобренного политиками аккаунта и рабочего пространства. Поставщиков и модели, не входящие в этот пул, выбрать нельзя. Разработчики могут оставить **Auto mode** включённым либо отключить его и вручную выбрать одобренную модель.

Подробнее о принципах маршрутизации см. в разделе [Использование интеллектуальной маршрутизации моделей](/ru/ko/chat/auto-mode).

<div id="agent">
  ## Открытие настроек модели Agent
</div>

1. Откройте **Settings**.
2. В разделе **Account** выберите **Advanced**.
3. Разверните раздел **Agent modes and model providers**.

<Frame caption="Политика провайдеров моделей и отдельный элемент управления Fast mode models в настройках Advanced.">
  <img src="/assets/mirror/agent-model-provider-settings-overview-8f82610dab77.jpg" alt="Настройки Agent modes and model providers с политикой провайдеров и элементом управления Fast mode models" width="2000" height="930" data-path="images/workspace/agent-model-provider-settings-overview.jpg" />

<div id="section-2">
  ## Настройка политики поставщика
</div>

<Steps>
  <Step>
    Выберите поставщика моделей, которым хотите управлять.
  </Step>

  <Step>
    В разделе **Account policy** выберите один из вариантов:

    | Вариант             | Результат                                                                   |
    | ------------------- | --------------------------------------------------------------------------- |
    | **Enable all**      | Все модели этого поставщика доступны во всех рабочих пространствах.         |
    | **Enable selected** | Вы вручную выбираете доступные модели для каждого рабочего пространства.    |
    | **Disabled**        | Ни одно рабочее пространство не может использовать модели этого поставщика. |

    <Note>
      Хотя бы одна модель из OpenAI, Anthropic или Google должна оставаться включённой. Остальных поставщиков можно отключить.
    </Note>
  </Step>

  <Step>
    Выберите **Update**.
  </Step>
</Steps>

Поставщики моделей с открытым исходным кодом отключены по умолчанию. Чтобы включить их, выберите **Enable all** или **Enable selected**, а затем — **Update**.

<div id="section-3">
  ## Настройка политик рабочего пространства
</div>

Если для разных рабочих пространств требуется разный доступ к моделям, используйте **Enable selected**.

<Frame caption="Политика поставщика Anthropic с настройкой Enable selected и доступ к моделям, настроенный для каждого рабочего пространства.">
  <img src="/assets/mirror/anthropic-account-policy-workspace-models-38c0f71a609d.jpg" alt="Политика аккаунта Anthropic с настройкой Enable selected и переключатели моделей в рабочем пространстве" width="2000" height="930" data-path="images/workspace/anthropic-account-policy-workspace-models.jpg" />
</Frame>

1. Откройте настройки поставщика.
2. Установите для **Account policy** значение **Enable selected**.
3. В списке **Workspace** выберите раскрывающееся меню **Setting** нужного рабочего пространства.
4. Включите или отключите каждую модель для этого рабочего пространства.
5. Выберите **Update**.

Перед выбором **Update** можно выбрать **Copy to all**, чтобы применить выбор моделей текущего рабочего пространства ко всем рабочим пространствам аккаунта.

<div id="section-4">
  ## Ограничения
</div>

* Политики моделей применяются на уровне рабочего пространства. Задать разные политики для отдельных групп пользователей в рамках одного рабочего пространства нельзя.
* Интеллектуальная маршрутизация моделей не отменяет политики аккаунта или рабочего пространства. Отключённые поставщики и модели выбрать нельзя.
* Переключатель **Fast mode models** в разделе **Agent modes and model providers** управляет доступом к быстрым вариантам моделей во всех рабочих пространствах аккаунта. Политики поставщиков и интеллектуальная маршрутизация моделей на этот параметр не влияют.
