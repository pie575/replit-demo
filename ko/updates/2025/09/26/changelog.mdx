<div id="security-scan-in-deployment">
  ### 배포 시 보안 스캔
</div>

새로운 게시 전 보안 스캔으로 애플리케이션을 보호하세요. apps를 배포하기 전에 스캔을 켜거나 꺼서 악성 파일과 보안 취약점을 잡아낼 수 있습니다. 신뢰도 높은 보안 규칙이 잠재적 위협을 라이브 전에 찾아내 코드를 안전하게 지켜줍니다.

<div id="agent-playground-testing-improvements">
  ### Agent playground 테스트 기능 개선
</div>

향상된 playground 기능으로 AI 에이전트와 자동화를 더 효과적으로 테스트하세요. 이제 Slack 및 Telegram 에이전트를 테스트할 때 도구 호출이 시각적으로 렌더링되고, 시간 기반 workflow 자동화의 실시간 테스트 결과도 확인할 수 있습니다. 배포(deployment) 전에 에이전트의 동작을 더 명확하게 확인해 보세요.

  ### Enterprise를 위한 보안 스캔 적용
</div>

이제 Enterprise 관리자는 팀의 모든 배포에 보안 스캔을 강제할 수 있습니다. 게시된 모든 앱에 보안 스캔을 의무화하여 조직 전반에 일관된 보안 표준을 확립하고, 팀의 보안 상태를 완벽하게 통제하세요
