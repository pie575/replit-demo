<div id="general-agent">
  ## Что такое General Agent?
</div>

General Agent — это самый гибкий способ работы с Replit Agent. Не нужно заранее выбирать тип артефакта или решать, что именно вы собираетесь создать. Просто начните диалог — сделайте CSV, сформируйте PDF, изучите тему или, когда будете готовы, соберите полноценное приложение.

Ключевые идеи:

* **Без предварительного выбора**: приступайте к работе сразу, не выбирая тип артефакта заранее
* **Любой результат**: создавайте файлы (CSV, PDF, документы), проводите исследования или собирайте приложения
* **Коннекторы**: читайте и записывайте данные во внешних сервисах — BigQuery, Linear, Slack, Notion, Amplitude, Segment, Hex и других
* **Постепенное развитие**: начните с обычной переписки и естественно перейдите к созданию полноценного приложения

<div id="general-agent-2">
  ## Способы доступа к General Agent
</div>

Получить доступ к General Agent можно несколькими способами:

1. **Выберите «General» перед вводом промпта** — на главной странице Replit
2. **Откройте существующий проект** и сразу начните диалог с Agent
3. **[Импортируйте](/ru/ko/build/import-from-providers) из GitHub** — проекты, импортированные из GitHub, автоматически используют General Agent

<div id="general-agent-3">
  ## Как использовать General Agent
</div>

<div id="section">
  ### Просто начните разговор
</div>

Откройте проект и начните общение. Не нужно заранее решать, что именно вы хотите создать — Agent работает в контексте текущего проекта и справится с любой задачей.

**Примеры промптов:**

* «Кратко изложи суть этого документа»
* «Составь CSV со 100 крупнейшими компаниями по выручке»
* «Какие пять моих тикетов в Linear самые важные?»
* «Настрой проект на Vue.js с TypeScript»

Agent может работать с файлами, созданными в ходе сессии, формировать результат в виде отдельных файлов и выполнять код в процессе рассуждения — ещё до того, как вы решите что-то билдить.

<div id="section-2">
  ### Подключение внешних сервисов
</div>

Подключите инструменты, чтобы Agent мог напрямую читать и записывать данные:

1. В настройках проекта перейдите в раздел **Коннекторы**
2. Подключите сервис (BigQuery, Linear, Slack, Notion, Amplitude, Segment, Hex и другие)
3. Попросите Agent прочитать или записать данные через этот сервис

**Примеры промптов с использованием коннекторов:**

* «Какие тикеты открыты в Linear?»
* «Сделай сводку сегодняшних сообщений в канале #engineering в Slack»
* «Выгрузи из BigQuery данные о продажах за прошлый месяц»
* «Покажи предстоящие события в моём календаре»
* «Создай в Linear новый тикет о баге в онбординге»
* «Отправь сводку в канал #engineering в Slack»

<div id="section-3">
  ### От чата к готовому приложению
</div>

Когда будете готовы приступить к разработке, просто скажите об этом. Agent плавно переходит от обычной беседы к созданию приложения — не нужно начинать с нуля или переключать контекст.

* «Сделай из этого веб-приложение»
* «Создай приложение на основе этих данных»
* «Построй дашборд для этих показателей»
* «Настрой CLI-инструмент на Rust»

Можно начать с малого — изучить тему, сформировать отчёт или исследовать данные — и в нужный момент перейти к созданию полноценного приложения.

<div id="section-4">
  ## Что можно создать
</div>

* **Работа со знаниями**: исследование, обобщение и анализ без создания приложения
* **Отдельные файлы на выходе**: CSV, PDF, документы, экспорт данных, оформленные отчёты
* **Приложения для работы с данными**: запросы к подключённым сервисам и визуализация результатов в виде дашборда
* **Любой фреймворк или язык**: Angular, Vue, Svelte, Rust, Go, C#, Python tkinter, игры на Godot, инструменты командной строки и многое другое
* **Полнофункциональные приложения**: когда всё будет готово, Agent соберёт полноценное приложение на основе контекста чата

<div id="section-5">
  ## Чего ожидать
</div>

General Agent даёт больше возможностей и гибкости, но вместе с этим и некоторую непредсказуемость:

* **Настройка с первого раза**: иногда Agent настраивает всё за один подход
* **Совместная работа в несколько итераций**: сложные конфигурации могут потребовать нескольких раундов доработки
* **Технические ограничения**: некоторые технологии могут поддерживаться в среде Nix не полностью

<Note>
  В отличие от стандартного Agent, который работает в преднастроенной среде, General Agent сам настраивает свою среду и выполняет команды по запросу. Когда всё будет готово к деплою, возможно, придётся отдельно попросить его настроить публикацию (publishing).
</Note>

<div id="section-6">
  ## Часто задаваемые вопросы
</div>

<Accordion title="Может ли Agent видеть мои другие проекты?">
  Нет. Каждый чат ограничен одним проектом. Сделать так, чтобы проект A и проект B «общались» друг с другом, нельзя.
</Accordion>

<Accordion title="Почему у меня до сих пор нет доступа к внешним инструментам?">
  Сначала нужно подключить сервис через коннектор. После подключения Agent сможет читать данные из сервиса и записывать их, но по умолчанию доступа у него нет.
</Accordion>

<Accordion title="Какие коннекторы доступны?">
  Сейчас поддерживаются коннекторы: BigQuery, Linear, Slack, Notion, Amplitude, Segment, Hex и другие. Новые коннекторы добавляются регулярно.
</Accordion>

<Accordion title="Нужен ли коннектор для работы с General Agent?">
  Нет, коннекторы подключаются по желанию. General Agent можно использовать для работы со знаниями, создания файлов и разработки приложений и без внешних подключений.
</Accordion>
