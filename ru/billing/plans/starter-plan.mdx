<div id="what-you-get">
  ## Что вы получаете
</div>

Тариф Starter предоставляет всё необходимое, чтобы начать создавать приложения в Replit. Создавайте приложения и публикуйте свой первый проект — совершенно бесплатно.

<div id="daily-credits-for-agent">
  ### Ежедневные кредиты для Agent
</div>

Пользователи тарифа Starter получают ежедневные кредиты для использования Agent в пределах месячного лимита. Эти кредиты обновляются ежедневно, предоставляя новый лимит для работы с Agent.

<div id="monthly-credits-for-cloud-usage">
  ### Ежемесячные кредиты на использование облачных сервисов
</div>

Вы также получаете ежемесячные кредиты, которые можно использовать для:

* [Баз данных (Production)](/ru/features/data-and-storage/development-and-production)
* [Object Storage](/ru/features/data-and-storage/object-storage)
* [Publishing (Autoscale, static)](/ru/learn/projects-and-artifacts/replit-deployments)

Эти кредиты обновляются каждый месяц.

<div id="lite-build">
  ### Lite build
</div>

Доступ к [Lite build](/ru/features/agent/agent-modes) — быстрому и целенаправленному режиму разработки для оперативных правок и точечных изменений с Agent.

<div id="one-free-published-app">
  ### Одно бесплатное опубликованное приложение
</div>

Получите {FreeDeployments} бесплатное опубликованное приложение независимо от того, используете ли вы Lite build или Design Canvas. Эта ссылка перестанет работать через 30 дней.

В ваше опубликованное приложение будет добавлен значок «Made with Replit» с уникальной реферальной ссылкой. Если другой пользователь зарегистрируется по ссылке с вашего значка, после перехода на платный тариф вы получите реферальные кредиты.

<div id="limitations">
  ## Ограничения
</div>

Для использования следующих функций необходимо перейти на тариф Core:

<div id="full-build">
  ### Полная сборка
</div>

[Полная сборка](/ru/features/agent/overview/) позволяет Agent работать самостоятельно, с большей мощностью и автономностью. Разработчикам на тарифе Starter доступна только [Lite build](/ru/features/agent/agent-modes). Для полной сборки требуется тариф Core или Pro.

<div id="converting-a-design-to-an-artifact">
  ### Преобразование дизайна в артефакт
</div>

Для преобразования дизайна из Design Canvas в полноценный артефакт требуется тариф Core. Разработчики на тарифе Starter могут создавать и публиковать дизайны, но для преобразования дизайна в артефакт с бэкендом необходимо перейти на более высокий тариф. Если вы хотите создать приложение с бэкендом, попробуйте начать с [Lite build](/ru/features/agent/agent-modes).

<div id="third-party-connectors">
  ### Сторонние коннекторы
</div>

Для использования внешних коннекторов требуется Core. К ним относятся интеграции с такими сервисами, как Google, Stripe и другие сторонние API (подробнее [здесь](https://docs.replit.com/features/integrations/overview#connectors)).

<div id="replit-ai-integrations">
  ### Интеграции Replit AI
</div>

Для [интеграций Replit AI](/ru/features/integrations/replit-ai-integrations) требуется Core.

<div id="remove-made-with-replit-badge">
  ### Удаление значка «Made with Replit»
</div>

Чтобы удалить значок «Made with Replit» из опубликованных приложений, требуется тариф Core. В развёртываниях пользователей тарифа Starter этот значок отображается.

<div id="additional-published-apps">
  ### Дополнительные опубликованные приложения
</div>

Пользователям тарифа Starter доступно {FreeDeployments} бесплатное опубликованное приложение. Для публикации дополнительных приложений требуется тариф Core или Pro.

<div id="plan-mode">
  ### Режим Plan
</div>

Для использования режима Plan требуется тариф Core. В режиме Plan можно обсуждать идеи, планировать работу и взаимодействовать с Replit Agent, не изменяя код или данные приложения.

<div id="all-artifact-types">
  ### Все типы артефактов
</div>

Для создания артефактов, кроме веб- и мобильных приложений, требуется Core. Доступны различные типы артефактов: визуализации данных, слайд-презентации, анимированные видео и другие. См. [Projects](/ru/features/projects-and-artifacts/projects).

<div id="upgrading-to-core">
  ## Переход на Core
</div>

Хотите больше возможностей? Перейдите на Core и получите:

* **Больше хранилища и ежемесячных кредитов**, а также возможность оплаты по мере использования
* **Неограниченное количество опубликованных приложений** помимо первого бесплатного
* **Полная сборка** для автономной разработки
* **Сторонние коннекторы** для подключения к внешним сервисам
* **Интеграции Replit AI**, чтобы использовать модели ИИ без необходимости управлять собственными API-ключами
* **Режим Plan**, чтобы планировать задачи перед переходом к Build.
* **Удаление значка Replit** для профессионального оформления
* И многое другое
