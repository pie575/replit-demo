Replit App настраивается с помощью двух файлов: `.replit` и `replit.nix`. Они влияют на работу Replit App — от запуска кода до используемых инструментов разработки и языков программирования.

По умолчанию эти файлы конфигурации скрыты. Чтобы отобразить их в Replit App, выберите «Show hidden files» в меню дерева файлов.

<div id="arquivo-replitnix">
  ## Файл `replit.nix`
</div>

Replit использует `Nix` для управления пакетами и средами. Файл `replit.nix` используется для:

**Указания системных зависимостей:** Точно определите, какие программные пакеты нужны вашему Replit App. Управление ими осуществляет Nix — менеджер пакетов.

**Создания воспроизводимых сред:** Обеспечьте единообразие и воспроизводимость среды разработки — это особенно полезно для совместных проектов и тестирования на нескольких системах.

Управлять пакетами Nix в визуальном интерфейсе можно с помощью инструмента `Dependencies`. Подробнее см. в руководстве [Системные зависимости](/ru/pt/references/workspace/dependency-management#system-dependencies).

Чтобы настроить пакеты с помощью файла `replit.nix`, укажите [пакеты Nix](https://search.nixos.org/packages) в массиве `deps`, добавив префикс `pkgs.`. Все изменения будут синхронизированы после перезагрузки Shell.

```nix theme={null}
{ pkgs }: {
  deps = [
    pkgs.nodejs-19_x
    pkgs.nodePackages.typescript-language-server
    pkgs.yarn
    pkgs.replitPackages.jest
  ];
}
```

<div id="arquivo-replit">
  ## Файл `.replit`
</div>

Файл `.replit` определяет поведение вашего Replit App. В нём используется [формат конфигурации](https://toml.io/en/) `toml`. Вот некоторые основные параметры, которые можно настроить:

**Команда Run:** Укажите команду, которая выполняется при нажатии кнопки Run. В каждом шаблоне есть команда run по умолчанию, позволяющая сразу запустить код. Для более специализированных и сложных приложений используйте [Workflows](/ru/pt/references/workspace/workflows).

**Language Server Protocol (LSP)**: Предоставляет такие возможности, как автодополнение, навигация по коду, подсветка синтаксиса, линтинг и отображение ошибок в реальном времени.

**Переменные окружения:** Определяйте необходимые переменные окружения и управляйте ими, чтобы ваши приложения работали корректно.

**Зависимости и пакеты:** Управляйте установкой пакетов и конфигурацией непосредственно через файл `.replit`, чтобы при запуске в вашем Replit App были доступны все необходимые инструменты. Вы также можете визуально управлять зависимостями с помощью инструмента `Dependencies`. Подробнее см. в руководстве по [системным модулям](/ru/pt/references/workspace/dependency-management#advanced-configuration).

Для приложений Python файл `.replit` по умолчанию выглядит так:

```toml theme={null}
entrypoint = "main.py"
modules = ["python-3.10:v18-20230807-322e88b"]

[nix]
channel = "stable-23_05"

[unitTest]
language = "python3"

[gitHubImport]
requiredFiles = [".replit", "replit.nix"]

[deployment]
run = ["python3", "main.py"]
deploymentTarget = "cloudrun"
```

| ----------------------------------------------- | -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |

| <a name="modules" />`modules`                   | `["python-3.10:v18-20230807-322e88b"]` | Определяет конкретные версии языков программирования или других основных зависимостей, поддерживаемых Replit.                                                                                          |
| <a name="nix" />`[nix]`                         |                                        | Указывает настройки использования Nix — менеджера пакетов для управления системными зависимостями. Подробнее см. в разделе [Управление зависимостями](/ru/pt/references/workspace/dependency-management). |
| <a name="channel" />`channel`                   | `stable-23_05`                         | Указывает используемый канал Nix, который влияет на версии доступных системных зависимостей.                                                                                                           |

| <a name="gitHubImport" />`[gitHubImport]`       |                                        | Настройки, влияющие на импорт проектов из GitHub, в частности на включаемые файлы.                                                                                                                     |
| <a name="requiredFiles" />`requiredFiles`       | `[".replit", "replit.nix"]`            | Перечисляет файлы, которые должны присутствовать при импорте проекта, чтобы он работал корректно.                                                                                                      |
| <a name="deployment" />`[deployment]`           |                                        | Содержит настройки для развёртывания приложения Replit App в рабочей среде.                                                                                                                            |
| <a name="run" />`run`                           | `["python3", "main.py"]`               | Команда, выполняемая для запуска приложения во время развёртывания.                                                                                                                                    |
| <a name="deploymentTarget" />`deploymentTarget` | `cloudrun`                             | Указывает целевую платформу развёртывания для размещения приложения.                                                                                                                                   |

Теперь, когда вы знакомы со стандартными настройками файла `.replit`, перейдите к следующим разделам, чтобы узнать, как настроить основные и расширенные параметры вашего Replit App.

<div id="configurando-definies-bsicas">
  ## Настройка основных параметров
</div>

<div id="entrypoint">
  ### Точка входа
</div>

Это основной файл вашего проекта. Если не указать свойство `run`, точкой входа будет файл, который выполняет среда выполнения.

```toml theme={null}
entrypoint = "<nome-do-arquivo>.py"
```

<div id="comando-run">
  ### Команда `Run`
</div>

Свойство `run` в файле `.replit` определяет начальную команду или последовательность команд, которые выполняются при нажатии кнопки `Run` в среде Replit. Команду `Run` можно указать в виде строки с выполняемой командой или массива строк, содержащего команду и отдельные аргументы для неё.

Несколько распространённых способов настройки команды `Run`:

* **Одна команда:**
  В этом примере показано, как передать одну команду для непосредственного выполнения в Replit App. Если добавить её в файл `.replit`, при нажатии кнопки `Run` в панели `Console` появится приветствие:
  **Пример:** `run = "echo 'Hello, Replit!'"`

* **Явные аргументы:**
  В некоторых случаях удобнее явно указать аргументы, чтобы не разбирать кавычки или правила интерполяции Shell. Вы можете переписать приведённый выше пример, разделив аргументы.
  Обратите внимание, что `'` и `"` больше не нужны, поскольку приветствие явно передаётся как первый и единственный аргумент для `echo`:
  **Пример:** `run = ["echo", "Hello, Replit!"]`

* **Несколько команд:**
  В этом примере показано, как одновременно запустить несколько процессов, например фронтенд и бэкенд. Это может быть полезно при разработке бэкенда на Python и фронтенда на TypeScript, когда каждый сервер привязан к отдельному порту:
  **Пример:** `run = "python -m app & npm run start & wait"`

<div id="gerenciamento-de-processos">
  #### Управление процессами
</div>

Хотя с помощью `&` можно одновременно запускать несколько команд, для удобного различения логов разных сервисов может понадобиться более подходящее решение. Для более эффективной оркестрации нескольких процессов можно [добавить системные зависимости](/ru/pt/references/workspace/dependency-management#system-dependencies), например [`process-compose`](https://github.com/F1bonacc1/process-compose).

<div id="fase-build">
  #### Фаза `Build`
</div>

Для некоторых языков или сред выполнения перед `запуском` кода требуется отдельный этап компиляции. Он нужен как для компилируемых языков, таких как TypeScript, Golang или Java, так и для задания команды, которая позволяет переопределить среду, данные или конфигурацию перед следующим вызовом `run`.

* **Компиляция:**
  В репозитории TypeScript перед запуском кода может потребоваться выполнить `tsc`.
  **Пример:**

```toml theme={null}
build = "tsc app.ts"
run = "node app.js"
```

<div id="incluindo-variveis-de-ambiente">
  #### Добавление переменных окружения
</div>

Чтобы передать переменные окружения сервису перед запуском, можно преобразовать свойство `run` в [таблицу](https://toml.io/en/v1.0.0#table).

Это более сложное изменение, и, вероятно, вам потребуется переместить свойство `run = "..."` в файле `.replit`.

Следующий diff показывает, как задать команду с помощью `args` в `[run]`, а также переменную `NAME` в `[run.env]`:

```diff theme={null}
-run = ["bash", "-c", "echo \"Hello, $NAME!\""]

 modules = ["nodejs-20"]

 hidden = [".pythonlibs"]

+# Нам нужно переместить наш новый [run] ниже всех
+# свойств верхнего уровня, которые не начинаются с `[`!
+[run]
+args = ["bash", "-c", "echo \"Hello, $NAME!\""]
+
+[run.env]
+NAME="Replit"

 [nix]
 channel = "stable-23_11"
```

<div id="interatividade">
  #### Интерактивность
</div>

Интерактивные программы также можно запускать кнопкой `Run`, благодаря чему среда разработки отделена от терминала, в котором выполняется программа.
Рассмотрим следующий скрипт подсчёта:

**Пример**

```toml theme={null}
[run]
args = ["bash", "-c", """
count=0
while read -p "$PROMPT" -r next && [ -n "$next" ]; do
    count=$((count+next))
done
echo "The numbers you entered sum to $count!"
"""]

[run.env]
PROMPT = "Next number ([Enter] to end): "
```

<div id="opes-de-configurao-avanadas">
  ## Расширенные параметры конфигурации
</div>

Ознакомьтесь с подробными параметрами конфигурации вашего Replit App. Вы можете настроить среду разработки, управлять командами `run`, интегрировать языковые сервисы и зависимостями.

| **Конфигурация** | **Ключ**                            | **Значение/пример**                         | **Описание**                                                                                   |
| ---------------- | ----------------------------------- | ------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| onBoot           | <a name="onBoot" />`onBoot`         | `onBoot = "npm install"`                    | Команда, выполняемая при запуске Replit App.                                                   |
| compile          | <a name="compile" />`compile`       | (Пример по умолчанию отсутствует)           | Команда, выполняемая перед командой `run`; используется в компилируемых языках, таких как C++. |
| language         | <a name="language" />`language`     | `language = "javascript"`                   | Указывает язык при импорте из GitHub или создании Replit App.                                  |
| точка входа      | <a name="entrypoint" />`entrypoint` | `entrypoint = "index.js"`                   | Точка входа, запускаемая и отображаемая при открытии редактора.                                |
| hidden           | <a name="hidden" />`hidden`         | `hidden = [".config", "package-lock.json"]` | Файлы или папки, которые по умолчанию скрываются в боковом дереве файлов.                      |
| audio            | <a name="audio" />`audio`           | `audio = true`                              | Включает системный звук, если задано значение `true`.                                          |

<div id="notas-sobre-udio-em-todo-o-sistema">
  ### Примечания о системном аудио
</div>

Если в файле `.replit` установить `audio = true`, может потребоваться выполнить `kill 1` в Shell, чтобы новая конфигурация вступила в силу.

При запуске графического приложения в правом нижнем углу панели `Output` появится значок наушников с флажком.
Из-за ограничений браузера его нужно будет включать после каждого обновления.

```toml theme={null}
# Убедитесь, что эта строка находится в начале файла `.replit`, вне разделов в квадратных скобках `[`
audio = true
```

<div id="configurao-do-packager">
  ## Настройка packager
</div>

| **Настройка**    | **Ключ**                                          | **Значение/пример**                           | **Описание**                                                                         |
| ---------------- | ------------------------------------------------- | --------------------------------------------- | ------------------------------------------------------------------------------------ |
| packager         | <a name="language" />`language`                   | `packager.language = "python3"`               | Язык, используемый для работы с пакетами.                                            |
| функции packager | <a name="guessImports" />`guessImports`           | `packager.features.guessImports = true`       | Автоматически определяет пакеты, которые нужно установить перед запуском Replit App. |
| функции packager | <a name="packageSearch" />`packageSearch`         | `packager.features.packageSearch = true`      | Включает поддержку packager при значении `true`.                                     |
| функции packager | <a name="enabledForHosting" />`enabledForHosting` | `packager.features.enabledForHosting = false` | Определяет, требуется ли установить пакеты для хостинга Replit App.                  |
| packager         | <a name="afterInstall" />`afterInstall`           | `afterInstall = "echo 'package installed'"`   | Команда, выполняемая после установки нового пакета через packager.                   |
| packager         | <a name="ignoredPaths" />`ignoredPaths`           | `ignoredPaths = [".git"]`                     | Пути, игнорируемые при определении пакетов.                                          |
| packager         | <a name="ignoredPackages" />`ignoredPackages`     | `ignoredPackages = ["twitter", "discord"]`    | Модули, для которых не следует пытаться определить пакет при установке.              |

<div id="exemplo-de-configurao-replit-para-configurao-do-packager">
  ### Пример конфигурации `.replit` для packager
</div>

```toml theme={null}
# Укажите язык для Replit App
packager.language = "python3"

# Включите функции автоматического управления пакетами
[packager.features]
guessImports = true
packageSearch = true
enabledForHosting = false

# Команда, выполняемая после установки каждого пакета
packager.afterInstall = "echo 'Package installed successfully'"

# Укажите пути и пакеты, которые менеджер пакетов должен игнорировать
packager.ignoredPaths = [".git", "node_modules"]
packager.ignoredPackages = ["twitter", "discord"]

# Дополнительные настройки развертывания
[deployment]
run = ["python3", "app.py"]
```

<div id="configurao-de-deployment">
  ## Конфигурация развёртывания
</div>

| **Конфигурация** | **Ключ**                              | **Значение/пример**                  | **Описание**                                                                 |
| ---------------- | ------------------------------------- | ------------------------------------ | ---------------------------------------------------------------------------- |
| развёртывание    | <a name="run" />`run`                 | `deployment.run = "npm start"`       | Команда, выполняемая при запуске контейнера развёртывания.                  |
| развёртывание    | <a name="build" />`build`             | `deployment.build = "npm run build"` | Команда, выполняемая перед запуском развёртывания.                          |
| развёртывание    | <a name="ignorePorts" />`ignorePorts` | `deployment.ignorePorts = true`      | Если `true`, для успешного развёртывания не требуется проверка открытого порта. |

<div id="exemplo-de-configurao-replit-para-configurao-de-deployment">
  ### Пример конфигурации `.replit` для развёртывания
</div>

```toml theme={null}

# Указывает основной файл запуска проекта
entrypoint = "app.js"

# Настройки развёртывания приложения
[deployment]
run = "npm start"
build = "npm run build"
ignorePorts = true
```

<Note>
  **Настройка Interpreter** устарела и больше недоступна в Replit. Вместо неё используйте команды `Run`, чтобы настроить запуск скриптов и приложений в среде Replit App.
</Note>

<div id="acessando-metadados-do-ambiente-do-replit-app">
  ## Доступ к метаданным окружения Replit App
</div>

<div id="nodejs">
  ### Node.js
</div>

Чтобы получить доступ ко всем переменным окружения:

`console.log(process.env);`

Чтобы получить доступ к отдельной переменной (REPL&#95;SLUG):

`console.log(process.env.REPL_SLUG);`

<div id="python">
  ### Python
</div>

Чтобы получить доступ ко всем переменным окружения:

```python theme={null}
import os
print(os.environ)
```

Чтобы получить значение отдельной переменной (REPL&#95;SLUG):

```python theme={null}
import os
variable = os.environ.get('REPL_SLUG')
print(variable)
```

<div id="rust">
  ### Rust
</div>

Чтобы получить доступ ко всем переменным окружения:

```rust theme={null}
use std::env;
fn main() {
    for (key, value) in env::vars() {
        println!("{}: {}", key, value);
    }
}
```

Чтобы получить значение отдельной переменной (REPL&#95;SLUG):

```rust theme={null}
use std::env;
fn main() {
    let variable = env::var("REPL_SLUG").unwrap();
    println!("{}", variable);
}
```

<div id="variveis-de-ambiente">
  ## Переменные окружения
</div>

Ниже перечислены переменные окружения, доступные в вашем Replit App:

| ключ                                              | описание                                                                                                                                                                                            |
