**元素**是 frame 中的单个部分，例如标题、按钮、图片、表单字段，或该 frame 渲染的其他任何组件。当你想修改 frame 的某个部分，而不重新生成整个 frame 时，就需要选中元素。

<div id="selecting-an-element">
  ## 选择元素
</div>

使用工具栏中的[编辑工具](/zh/design/toolbar#edit)。启用编辑后，点击实时 frame 中的元素，即可选中光标所在位置的元素。选中的元素会显示高亮边框，并附带一个小型内联 prompt，你可以让 Agent 对其进行修改。

<Note>
  Canvas 上至少有一个 frame 后才能使用编辑功能，且该功能仅支持桌面端。
</Note>

<div id="acting-on-a-selected-element">
  ## 对所选元素执行操作
</div>

<div id="ask-agent-to-change-it">
  ### 让 Agent 进行修改
</div>

通过内联 prompt 请 Agent 更新元素的文案、颜色、布局、间距或行为。

</Frame>

<div id="swap-an-image-directly">
  ### 直接替换图片
</div>

选中图片元素后，Visual Editor 的 **图片** 部分会显示源路径和 **上传图片** 按钮，让你无需编写 prompt 即可替换图片文件。

<div id="visual-editor">
  ## Visual Editor
</div>

选择元素后，会打开 **Visual Editor**——位于右侧、与内联 prompt 搭配使用的面板。面板将各项控件清晰地分组，方便你更快找到所需控件：**文本**、**布局**、**颜色**和**边框**。 (选择图片元素时，还会显示**图片**分区。)

<Frame>
  <img src="/assets/mirror/canvas-element-panel-c8972fab0448.png" alt="Canvas 中选中了一个 div 元素（McLaren 预订侧边栏）。右侧的 Visual Editor 面板显示文本（字号 16、字重常规、对齐）、布局（外部间距的底部值为 24px，内部间距为 20/20，并带有关联切换按钮）和颜色（文本 #e4e4e7、背景 #0f0f12）分区。" width="2000" height="1252" data-path="images/replitai/canvas-element-panel.png" />
</Frame>

<div id="layout">
  ### 布局
</div>

在 **布局** 部分，无需通过 Agent，你即可调整子元素在容器内的排列方式。选择一个弹性容器并展开“布局”，即可看到：

* **对齐方式**：一个 3×3 点阵选择器，用于设置项目在容器内沿两个轴的位置。
* **方向**：两个箭头按钮，用于将子元素按行或按列排列。
* **间距**：项目之间间隔的像素值。“间距”输入框旁的图标会随当前方向变化，让你始终清楚调整的是水平还是垂直间距。旁边的箭头图标可切换 **在项目之间分配空间**，将子元素推向容器相对的边缘。
* **外部间距**：用于设置元素外部空间的各边输入框 (每边一个输入框，并提供链接切换按钮以一次锁定四边) 。
* **内部间距**：用于设置元素沿各轴内部空间的输入框，并提供链接切换按钮以同时锁定两个轴。

仅当所选元素至少适用一个布局控件时，才会显示“布局”部分。没有间距或布局属性的纯文本节点会完全隐藏该部分，让编辑器保持简洁。

有关 **文本**、**颜色**、**边框** 和 **图片** 部分，请参阅 [Visual Editor 指南](/zh/design/visual-editor)。
