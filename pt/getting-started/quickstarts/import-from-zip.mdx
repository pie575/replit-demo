## Importar de ZIP

⏰ *Tempo estimado: três minutos*

Importe um projeto local enviando um arquivo `.zip`.

Para opções de importação abrangentes, incluindo outras plataformas como GitHub, Figma, Bolt, Lovable e Vercel, consulte a [documentação do recurso de Importação](/pt/core-concepts/project-editor/app-setup/import).

## Antes de começar

* Um arquivo `.zip` contendo seu projeto
* Uma pasta raiz de projeto clara no arquivo compactado
* Uma conta no Replit

## Passos de importação

1. Abra [replit.com/import](https://replit.com/import).
2. Selecione **ZIP**.
3. Envie seu arquivo `.zip`.
4. Adicione quaisquer segredos e variáveis de ambiente solicitados.
5. Selecione **Importar**.

## O que é importado

* Arquivos do projeto e estrutura de diretórios
* Arquivos de dependências
* Padrões de execução e build para o Replit

## O que não é importado

* Valores existentes de variáveis de ambiente
* Domínios personalizados
* Serviços específicos de plataforma que precisam de configuração manual
* Dados de banco de dados existentes
* Configuração de conectores de terceiros existentes
