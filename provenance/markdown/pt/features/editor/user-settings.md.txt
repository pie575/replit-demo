# Configurações do Usuário

> Aprenda a personalizar o Editor de Projeto com configurações de usuário que se aplicam a todos os seus apps.

A ferramenta Configurações do Usuário do Editor de Projeto oferece opções para personalizar a aparência, o comportamento e os
atalhos de teclado da sua conta.

## Recursos

Você pode personalizar sua experiência de criação de Replit Apps com estas categorias de configurações:

* **Personalização de tema**: Escolha entre temas claros e escuros para o Editor de Projeto
* **Inteligência de código**: Configure recursos com IA que melhoram sua experiência de criação de apps
* **Preferências do editor**: Ajuste como o editor de arquivos se comporta e aparece
* **Controles de notificação**: Gerencie as preferências de alertas
* **Opções de acessibilidade**: Torne o Replit mais adequado para usuários com necessidades específicas
* **Atalhos de teclado**: Defina combinações de teclas para executar ações comuns e navegar pela interface

### Aparência

Personalize as seguintes configurações relacionadas à aparência do Editor de Projeto:

* **Seleção de tema**: Escolha entre predefinições de tema claro e escuro, <a href="https://replit.com/themes" target="_blank">temas da comunidade</a> ou seu tema personalizado
* **Temas personalizados**: Crie esquemas de cores personalizados usando o editor de [Themes](/pt/features/editor/themes)

### Preferências do editor de arquivos

Controle a aparência e o comportamento do editor de arquivos usando as seguintes configurações:

* **Tamanho da fonte**: Ajuste o tamanho do texto para melhor legibilidade
* **Fechamento automático de colchetes**: Insira automaticamente o colchete de fechamento ao digitar um colchete de abertura
* **Detecção de indentação**: Detecte automaticamente as configurações de indentação ao abrir um arquivo
* **Formatar indentação do texto colado**: Reformate o código colado para seguir a indentação correta
* **Caractere de indentação**: Escolha entre espaços e tabulações para indentar o código
* **Tamanho da indentação**: Defina o número de colunas para cada nível de indentação
* **Quebra de linha (Wrapping)**: Configure o comportamento de quebra de linha
* **Minimapa**: Inclua uma visão geral navegável do código em uma barra lateral
* **Tecla modificadora de seleção múltipla**: Defina a tecla modificadora do teclado para seleção de múltiplos arquivos
* **Status do Git na árvore de arquivos**: Exiba indicadores de status do Git na árvore de arquivos

### Inteligência de código

Configure ferramentas com IA usando as seguintes configurações:

* **Tokens semânticos**: Use realce de sintaxe avançado, com tecnologia de language servers
* **Conclusão de código com IA**: Adicione sugestões de código embutidas enquanto você digita
* **Aceitar sugestão com caractere de confirmação**: Aceite automaticamente sugestões de código ao digitar determinados caracteres

### Preferências de Shell e Preview

Personalize o comportamento das ferramentas Shell e Preview:

* **Indicador sonoro do Shell (bell)**: Reproduza sons quando a ferramenta Shell encontrar problemas
* **Preview automático**: Abra a aba Preview automaticamente quando um servidor ficar disponível
* **Encaminhar portas abertas automaticamente**: Configure o tratamento de portas recém-detectadas

### Notificações

Gerencie as seguintes configurações de notificação:

* **Notificação sonora do Agent**: Reproduza sons quando o Agent solicitar feedback
* **Notificação push do Agent**: Receba notificações push no celular quando o Agent solicitar feedback

#### Alertas de produção

**Alertas de Produção** é uma configuração de notificação por e-mail separada que mantém você informado sobre a saúde dos seus apps publicados. É independente dos e-mails de produto e marketing, então você fica atualizado sobre o que importa sem ruído extra.

Ative **Alertas de Produção** para receber e-mails sobre o seguinte:

* **Incidentes de uptime**: Seja notificado quando um app publicado ficar fora do ar ou tiver problemas para permanecer online.
* **Vulnerabilidades de segurança**: Seja notificado sobre falhas encontradas no software do qual seu app depende, para que você possa corrigi-las antes que causem problemas.
* **Atualizações de modelo**: Seja notificado quando um modelo de linguagem usado pelo seu app for alterado ou precisar da sua atenção.

Para encontrar essa configuração:

1. Abra **Configurações** no menu da sua conta.
2. Selecione a aba **Personalização**.
3. Role até a seção **Notificações por e-mail** para encontrar **Alertas de Produção**.

Quando um app publicado usa um modelo de linguagem desatualizado, o Replit prepara uma tarefa (draft task) para atualizá-lo para um modelo suportado. Você recebe um e-mail com um link para a tarefa, para que possa concluir a atualização com uma única revisão.

### Acessibilidade

Você pode personalizar a seguinte configuração de acessibilidade:

* **Saída de terminal acessível**: Ative a compatibilidade com leitores de tela para as ferramentas Shell e Console

### Atalhos de teclado

Para acessar as preferências de atalhos de teclado, selecione a aba **Atalhos de teclado** na ferramenta Configurações do Usuário.

Você pode pesquisar combinações de teclas usando os seguintes métodos:

* **Nome**: Digite o nome ou a descrição do atalho de teclado no campo de pesquisa
* **Combinação de teclas**: Selecione o ícone <img class="icon-svg" src="https://mintcdn.com/replit/rJldsgYVucXB_6kW/images/icons/keyboard.svg?fit=max&auto=format&n=rJldsgYVucXB_6kW&q=85&s=81adf8d47b1ee530465dc80bccd074b5" alt="ícone de teclado" width="16" height="16" data-path="images/icons/keyboard.svg" /> e insira a combinação de teclas

Use as seguintes ações para gerenciar atalhos:

* **Adicionar**: Selecione **Adicionar atalho**
* **Atualizar**: Selecione o ícone <img class="icon-svg" src="https://mintcdn.com/replit/rJldsgYVucXB_6kW/images/icons/pencil-icon.svg?fit=max&auto=format&n=rJldsgYVucXB_6kW&q=85&s=09de925e41efd3d1cfa199737639b5a6" alt="ícone de lápis" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> de lápis
* **Remover**: Selecione o ícone <img class="icon-svg" src="https://mintcdn.com/replit/X_IP1EeHGm0cA2VA/images/icons/trash-icon.svg?fit=max&auto=format&n=X_IP1EeHGm0cA2VA&q=85&s=031a29f126332bebd5b6a74de4f16e40" alt="ícone de lixeira" width="16" height="16" data-path="images/icons/trash-icon.svg" /> de lixeira
