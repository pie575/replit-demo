## Aprimore seu Remix

Agora que você tem um aplicativo funcionando, use o Agent para modificá-lo e estendê-lo. As seções a seguir mostram exemplos práticos de como aprimorar seu Remix.

### Adicione um recurso usando o Agent

Use o Agent para adicionar recursos complexos ao seu Remix:

<Steps>
  <Step title="Crie um prompt">
    Navegue até a aba **Agent**.

    Digite o seguinte prompt na área de texto:

    <AiPrompt>
      Adicione um modo tutorial que ensina como tocar músicas simples. Quando o modo tutorial estiver ativo, destaque a próxima tecla que deve ser tocada, espere você pressionar a tecla correta antes de continuar e exiba o nome da música no topo. Inclua um botão para iniciar o tutorial e pré-carregue pelo menos duas músicas simples como "Mary Had a Little Lamb" ou "Twinkle Twinkle Little Star."
    </AiPrompt>

    Após enviar o prompt, o Agent pode pausar e pedir esclarecimentos ou confirmação. Responda na área de texto.
  </Step>

  <Step title="Teste o recurso">
    Navegue até a aba **Visualização** para ver as atualizações do Agent no piano.

    Tente iniciar o modo tutorial e acompanhe conforme as teclas são destacadas.

    <Frame>
      <video autoPlay muted loop playsInline src="/assets/mirror/quickstart-remix-piano-play-3be628756ae7.mp4" />
    </Frame>

    Como o prompt inicial não incluiu detalhes específicos sobre o design visual, o resultado pode não corresponder exatamente às suas expectativas.
  </Step>

  <Step title="Refine o recurso">
    Se o recurso diferir das suas expectativas, continue a conversa digitando um prompt de acompanhamento
    na área de texto do **Agent**. Por exemplo:

    <AiPrompt>
      Faça a tecla destacada brilhar com uma animação pulsante e adicione um indicador de progresso mostrando o quanto já avancei na música.
    </AiPrompt>

    Para desfazer essas alterações, selecione **Reverter para aqui** no Checkpoint criado imediatamente
    após iniciar o plano para a alteração na aba **Agent**.

    Saiba mais sobre [Checkpoints e Reversões](/pt/core-concepts/agent/checkpoints-and-rollbacks).
  </Step>
</Steps>

### Adicione um recurso usando o modo Lite

Siga estes passos para adicionar uma melhoria rápida ao seu Remix usando o [modo Lite](/pt/core-concepts/agent/agent-modes):

<Steps>
  <Step title="Crie um prompt">
    Mude para o [modo Lite](/pt/core-concepts/agent/agent-modes) e digite o seguinte prompt:

    <AiPrompt>
      Adicione botões de gravação e reprodução para capturar e repetir performances no piano.
    </AiPrompt>

    Após enviar o prompt, o Agent descreve as alterações que deseja fazer e permite que você revise as mudanças no código antes de continuar.
    Selecione **Visualizar alterações no código** para ver uma comparação do código atual com as atualizações.
  </Step>

  <Step title="Teste o recurso">
    Selecione **Aplicar tudo** e aprove as confirmações seguintes para continuar.

    Navegue até a aba **Visualização** para verificar o resultado. Agora você deve ver botões de gravação e reprodução que permitem capturar e repetir o que você toca.

    Para desfazer essas alterações, use o recurso Reverter na aba **Agent**.
  </Step>
</Steps>
