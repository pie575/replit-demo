## Suggestions de tâches de suivi

Après avoir appliqué une tâche, Agent examine le contexte de votre projet et suggère des **tâches de suivi** que vous pourriez vouloir construire ensuite. La boîte de dialogue **Prochaines tâches suggérées** affiche la recommandation principale en ligne, afin que vous puissiez continuer sans quitter le fil principal.

Les suggestions de suivi peuvent inclure :

* **Nouvelles fonctionnalités à construire** : des capacités qui s'associent naturellement à ce que vous venez de livrer
* **Améliorations de performance** : des optimisations qu'Agent a remarquées en travaillant sur la tâche
* **Améliorations de l'expérience utilisateur** : des finitions et des raffinements qui complètent la fonctionnalité

Sélectionnez **Démarrer** sur une suggestion pour l'envoyer en arrière-plan, ou sélectionnez **Voir le plan** pour inspecter le travail proposé en premier. Pour voir toutes les suggestions, sélectionnez **Voir plus dans le tableau des tâches**. Les suivis suggérés apparaissent sous **Suggéré** dans la colonne **Brouillons**.

<Frame>
  <img src="/assets/mirror/follow-up-tasks-kanban-21087e0210b6.png" alt="Tableau des tâches affichant de nombreuses suggestions de tâches de suivi sous Suggéré dans la colonne Brouillons" width="980" height="627" data-path="images/agent/follow-up-tasks-kanban.png" />
</Frame>

La fermeture de la boîte de dialogue **Prochaines tâches suggérées** annule les suggestions. Agent n'affiche pas la boîte de dialogue sur la version principale lorsqu'un plan proposé y attend déjà, afin que les deux invites ne se concurrencent pas pour votre attention.

## Gérer plusieurs suggestions à la fois

Pour les projets avec de nombreuses suggestions de suivi, ouvrez le tableau des tâches et sélectionnez **Modifier** dans la colonne **Brouillons**. En mode modification, chaque tâche suggérée obtient une case à cocher. Sélectionnez les tâches souhaitées, puis utilisez **Démarrer** ou **Annuler** pour appliquer cette action à chaque tâche sélectionnée. Sélectionnez **Terminé** pour quitter le mode modification.
