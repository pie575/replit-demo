<div id="o-que-so-artefatos">
  ## 什么是 artifact？
</div>

artifact 是指你可以在 Replit 上发布的成果，例如：网页应用、移动应用、幻灯片、动画、数据应用、3D 游戏和 Design。每个 artifact 都是完整且独立的产出，发布后都会获得专属的可分享 URL。

项目中的其他所有内容——文件、图片、CSV、代码——都是为 artifact 服务的，无法单独发布。

  ## 你可以创建什么
</div>

| 类型                                                           | 说明                            |
| ------------------------------------------------------------ | ----------------------------- |
| **[Web 应用](/zh/pt/features/artifact-types/web-apps)**           | 精美而强大的网站，可管理用户、数据库等。          |
| **[移动应用](/zh/pt/features/artifact-types/building-mobile-apps)** | 适用于 iPhone 和 Android 手机的原生应用。 |
| **[幻灯片](/zh/pt/features/artifact-types/slide-decks)**           | 可现场演示或导出的演示文稿。                |
| **[动画](/zh/pt/features/artifact-types/animated-videos)**        | 动态图形和动画视频，可导出为 MP4。           |
| **[数据可视化](/zh/pt/features/artifact-types/data-apps)**           | 交互式仪表板与可视化，用于探索数据、生成图表。       |
| **3D 游戏**                                                    | 3D 游戏、模拟和交互式体验。               |
| **[Design](/zh/pt/design/canvas)**                              | 在设计 Canvas 上探索视觉方向、快速验证创意原型。  |

各类型在不同套餐中的可用情况，请查看对应的专属页面。

<div id="primeiros-passos">
  ## 快速开始
</div>

在 Replit 首页上，有两种创建方式：

* **描述需求**：直接输入你想要的东西——&quot;帮我做一个食谱应用&quot;或&quot;为我的初创公司做一份路演演示文稿&quot;。Agent 会自动判断适合的类型并动手构建。
* **选择类型**：在描述你的想法之前，先选好要创建的产物类型——网页应用、移动应用、数据可视化、动画、3D 游戏或其他受支持的类型。

你也可以随时在 Chat 中向 Agent 提出需求，或点击预览面板中的 **+** 按钮，为现有项目添加更多内容。

<div id="alternando-entre-artefatos">
  ## 在制品之间切换
</div>

当一个项目中有多个制品时，你可以在**预览面板**或**库侧边栏**中进行切换。你也可以直接告诉 Agent——“给我看看移动应用”或“切换到幻灯片”。

<div id="vrios-artefatos-em-um-projeto">
  ## 一个项目中的多个 artifact
</div>

单个项目最多可包含 **7 个 artifact**，其中每个项目最多只能有 **1 个移动应用**。例如，你可以在同一个项目中构建面向客户的 Web 应用、面向团队的移动应用，以及面向投资人的幻灯片演示——全部都在同一个项目里完成。

<div id="adicionando-artefatos-a-um-projeto">
  ### 向项目中添加工件
</div>

有三种方式可以将工件添加到现有项目中：

* **Chat**：向 Agent 提出要求——“为这个项目添加一个移动应用”或“为投资人路演制作一份幻灯片”
* **添加按钮**：点击预览面板中的 **+** 按钮，选择你想构建的内容
* **资源库侧边栏**：浏览你已有的工件、图片和其他资源，并从中添加新的工件

<div id="dados-e-backend-compartilhados">
  ### 共享数据与后端
</div>

当多个产物同处一个项目中时，它们会自动共享相同的数据和后端逻辑。如果客户通过你的 Web 应用下单，你的移动应用和数据看板同样能看到这笔订单。你无需配置任何连接，也不用复制代码——一切开箱即用。

<Note>
  发布会一次性部署你的整个项目。所有产物会同时上线，因此始终保持同步。
</Note>

<div id="exemplos-de-combinaes">
  ### 组合示例
</div>

* **网页应用 + 移动应用**：一家餐厅既有面向顾客的网页应用，又有供员工使用的移动应用——两者连接同一个 API 和数据库
* **应用 + 管理后台**：主产品搭配一个内部管理面板，用于管理内容、用户或设置
* **应用 + 幻灯片演示**：把产品和路演演示文稿放在同一个项目中，让幻灯片始终反映最新版本
* **数据看板 + 视频**：实时数据可视化搭配一段动画视频，带观众快速了解重点内容

<div id="publicao">
  ## 发布
</div>

应用、幻灯片和视频均可发布和分享。发布后，每一项都会获得专属的分享链接。

非工件类的文件和资源 (如 CSV、图片或 Markdown 文件) 无法单独发布。若要分享，请将其添加到某个应用中，或新建一个工件。

<div id="perguntas-frequentes">
  ## 常见问题
</div>

<Accordion title="一个 project 中可以有多个 artifact 吗？">
  可以。单个 project 最多可包含 **7 个 artifact**，且**每个 project 限 1 个移动应用**。project 中的所有 artifact 会自动共享同一套后端和数据。

  如果已达到移动应用上限，但还想再构建一个移动应用，请在新的 project 中创建。如果已达到 7 个 artifact 的上限，请先删除一个现有 artifact 再添加新的，或将工作拆分到多个 project 中。
</Accordion>

<Accordion title="开始之前必须先选择类型吗？">
  不需要。只需描述你想要的内容，Agent 就会为你选择合适的类型。如果你愿意，也可以在下拉菜单中手动选择类型。
</Accordion>

<Accordion title="我可以只发布 project 中的某一个 artifact 吗？">
  目前不行。发布时会将整个 project 一起部署，以保证所有 artifact 保持同步。如果需要独立发布，请使用彼此独立的 project。
</Accordion>

<Accordion title="artifact 之间会共享数据吗？">
  会。同一 project 中的所有 artifact 共享同一个数据库和后端服务。如果你的 Web 应用写入了数据，移动应用和数据看板可以立即读取到这些数据。
</Accordion>

<Accordion title="artifact 和文件有什么区别？">
  artifact 是可以发布的内容——应用、幻灯片和视频。而文件 (例如 CSV、图片或代码) 是 project 内部用于支撑 artifact 的资源，无法单独发布。
</Accordion>

<Accordion title="我的移动应用缺少 Web 应用中的一些功能。这是怎么回事？">
  当 Agent 在不同 artifact 类型之间转换功能时，有些内容可能无法完美迁移——尤其是在不同平台上表现方式不同的交互或布局。你可以在 Chat 中继续追问，把缺失的部分补齐。
</Accordion>

如需了解可构建内容的完整列表，请参阅 [Projects 概览](/zh/pt/features/projects-and-artifacts/projects)。
