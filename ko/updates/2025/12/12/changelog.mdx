<div id="agent-now-supports-custom-mcp-servers">
  ### Agent가 이제 custom MCP 서버를 지원합니다
</div>

이제 Agent가 원격 Model Context Protocol(MCP) 서버에 연결할 수 있어, 간단한 설정만으로 새로운 기능과 도구를 사용할 수 있습니다. 이를 통해 Agent가 외부 도구를 호출하고 원격 시스템에서 context를 가져올 수 있습니다.

custom MCP 서버를 사용하면 다음과 같은 작업이 가능합니다:

* 외부 도구에서 context를 가져오고 작업을 실행하는 원격 서버에 연결
* MCP 개방형 표준을 통해 수백 가지 도구와 데이터 소스에 접근
* 각 서버가 제공하는 도구를 자동으로 로드

파트너는 MCP 서버를 공개하는 것만으로 자사 서비스를 Agent와 연동할 수 있으며, 별도의 integration 작업은 필요하지 않습니다.

  ## Teams 및 Enterprise

<div id="plaid-connector-for-enterprise">
  ### Enterprise용 Plaid Connector
</div>

이제 Enterprise 고객은 Plaid Connector를 활성화하여 은행 계좌를 연결하고 핀테크 기본 요소를 활용한 앱을 만들 수 있습니다. 이 connector는 현재 활발히 개발 중이며, 고객 feedback을 바탕으로 새로운 기능과 개선 사항이 계속 추가되고 있습니다.

Plaid Connector로 다음을 할 수 있습니다.

* 애플리케이션에 은행 계좌 연결
* 금융 기능 구축에 필요한 핀테크 기본 요소 사용
* admin dashboard에서 connector를 중앙 집중식으로 관리
