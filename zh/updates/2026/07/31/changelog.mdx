<div id="replit-design-is-live">
  ### Replit Design 正式上线
</div>

Replit Design 现已上线。描述你想创建的内容，浏览交互式原型，并不断打磨设计方向。当某个 frame 准备就绪后，Core 和 Pro 用户可以在同一个 project 中将其转化为可运行的应用。

<div id="agent">
  ## Agent
</div>

<div id="choose-agents-primary-model">
  ### 选择 Agent 的主模型
</div>

现在，你可以为任务指定 Agent 使用的主模型：先选择 Lite、Economy 或 Power，再从该模式下的可用模型中挑选。Lite 现已覆盖所有可使用 Agent 的场景，包括移动应用。可用模型因组织、授权和 Turbo 使用权限而异。

<Frame caption="截图取自 Replit Design；同样的控件也出现在 Agent 设置下拉菜单中。">
  <img src="/assets/mirror/agent-model-selector-873f18bc6147.png" width="1432" height="786" data-path="images/changelog/2026-07-31/agent-model-selector.png" />
</Frame>

进一步了解[模型选择器](/zh/features/agent/model-selector)。

<div id="connect-more-mcp-servers">
  ### 连接更多 MCP 服务器
</div>

符合条件的 workspace 可从预置的 MCP 服务器目录中连接 Supabase、Statsig 和 Calendly。Replit 还能识别官方的 Braintrust MCP 端点，手动添加时会自动启动 OAuth 登录流程。

  <img src="/assets/mirror/integrations-4cb26ed8a654.png" alt="Integrations 设置页面，列出了 GitHub、GitLab、AWS 和 Calendly 等 connector" width="3124" height="1636" data-path="images/changelog/2026-07-31/integrations.png" />
</Frame>

进一步了解 [MCP 服务器](/zh/features/mcp/overview)。

<div id="teams-and-enterprise">
  ## Teams 与 Enterprise
</div>

<div id="stay-signed-in-longer">
  ### 登录状态保持更久
</div>

Replit 会话的有效时长已延长，你无需那么频繁地重新登录。Enterprise 管理员可以配置会话超时预设值。
