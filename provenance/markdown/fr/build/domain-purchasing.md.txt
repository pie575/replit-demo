# Acheter un domaine

> Découvrez comment acheter un domaine et le connecter à votre application publiée directement depuis Replit.

Transformez vos applications en sites web professionnels et accessibles grâce à des noms de domaine personnalisés.

L'achat de domaine vous permet de rechercher, acheter et connecter des domaines pour vos applications publiées sur Replit — le tout depuis la plateforme. Passez d'une application publiée à une présence web professionnelle en quelques minutes.

Cela signifie que vous pouvez acheter un site, comme `mon-app.com`, et qu'il pointe automatiquement vers votre application.

## Fonctionnalités

L'achat de domaine simplifie le processus de donner à vos applications des adresses web professionnelles. Au lieu de jongler avec plusieurs services, vous pouvez compléter toute la configuration de votre présence web dans Replit.

<Frame>
  <img src="https://mintcdn.com/replit/jSmYU1wBTvl8UMyc/images/deployments/custom-domains/replit-domains.png?fit=max&auto=format&n=jSmYU1wBTvl8UMyc&q=85&s=af1ea8f250c6ab83ff016fc2fe075851" alt="Interface de gestion des domaines affichant les domaines achetés et leur statut de connexion" width="3176" height="1556" data-path="images/deployments/custom-domains/replit-domains.png" />
</Frame>

Les fonctionnalités clés incluent :

* **Recherche et disponibilité de domaines** : vérifiez la disponibilité des domaines avec les extensions populaires comme `.com`, `.ai` et plus encore
* **Achat en un clic** : achetez des domaines directement via Replit en utilisant le moyen de paiement par défaut de votre compte
* **Configuration automatique** : votre domaine pointe instantanément vers votre application Replit sans configuration DNS manuelle
* **Protection de la vie privée WHOIS** : vos informations personnelles restent privées dans les enregistrements de domaine publics — incluse par défaut avec chaque achat de domaine
* **Enregistrements DNS personnalisés** : ajoutez des enregistrements A, TXT et MX personnalisés pour configurer des fournisseurs d'e-mail et d'autres services
* **Publication instantanée** : votre application devient accessible à votre domaine personnalisé immédiatement après l'achat
* **Renouvellements automatiques** : les domaines se renouvellent automatiquement pour que vos applications restent publiées sans interruption

## Utilisation

### Acheter des domaines

1. Publiez votre application et accédez à l'onglet <img class="icon-svg" src="https://mintcdn.com/replit/rJldsgYVucXB_6kW/images/icons/deploy-icon.svg?fit=max&auto=format&n=rJldsgYVucXB_6kW&q=85&s=853c5ef39a8a7ac3648b3a2ce182fcb8" alt="Icône de publication" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publication**
2. Sélectionnez l'onglet **Domaines**
3. Choisissez **Acheter un domaine** pour lancer le processus de recherche
4. Saisissez le nom de domaine souhaité dans la barre de recherche
5. Consultez les options disponibles selon différentes extensions
6. Sélectionnez votre domaine préféré et finalisez l'achat

Lorsque vous achetez un domaine, il se configure automatiquement pour pointer vers votre application Replit. Votre application devient instantanément accessible au domaine personnalisé, sans configuration supplémentaire requise.

Vous serez facturé pour l'achat du domaine via votre compte Replit, déduit de votre solde puis appliqué à votre utilisation.

### Gérer les domaines achetés

Vos domaines s'intègrent parfaitement à vos applications publiées :

* **Renouvellements automatiques** : les domaines se renouvellent automatiquement pour que vos applications restent publiées
* **Facturation intégrée** : les coûts des domaines apparaissent sur votre facture Replit avec les autres services
* **Support de transfert** : déplacez des domaines entre comptes Replit ou vers des registraires externes si nécessaire

### Enregistrements DNS personnalisés

Pour les domaines achetés via Replit, vous pouvez ajouter des enregistrements DNS personnalisés pour configurer des services supplémentaires comme les fournisseurs d'e-mail. Les types d'enregistrements DNS suivants sont pris en charge :

* **Enregistrements A** : pointez votre domaine ou sous-domaine vers une adresse IP spécifique
* **Enregistrements TXT** : ajoutez des enregistrements de vérification textuels pour des services comme l'authentification par e-mail (SPF, DKIM, DMARC)
* **Enregistrements MX** : les enregistrements MX (Mail Exchange) indiquent aux serveurs de messagerie où livrer les e-mails pour votre domaine. La configuration des enregistrements MX vous permet d'utiliser votre domaine personnalisé pour des adresses e-mail comme `bonjour@votredomaine.com`.

Pour gérer les enregistrements DNS de votre domaine acheté :

1. Accédez à l'onglet **Domaines** dans votre publication <img class="icon-svg" src="https://mintcdn.com/replit/rJldsgYVucXB_6kW/images/icons/deploy-icon.svg?fit=max&auto=format&n=rJldsgYVucXB_6kW&q=85&s=853c5ef39a8a7ac3648b3a2ce182fcb8" alt="Icône de publication" width="16" height="16" data-path="images/icons/deploy-icon.svg" />
2. Trouvez le domaine que vous souhaitez configurer
3. Sélectionnez l'icône **Modifier** <img class="icon-svg" src="https://mintcdn.com/replit/rJldsgYVucXB_6kW/images/icons/pencil-icon.svg?fit=max&auto=format&n=rJldsgYVucXB_6kW&q=85&s=09de925e41efd3d1cfa199737639b5a6" alt="Icône de crayon" width="16" height="16" data-path="images/icons/pencil-icon.svg" />
4. Choisissez **Ajouter un enregistrement DNS**
5. Saisissez le type d'enregistrement, le nom, la valeur et le TTL tels que requis par votre fournisseur de services

Cette courte vidéo vous guide pour trouver la page de gestion des enregistrements DNS de votre domaine :

  Les modifications DNS peuvent prendre jusqu'à 48 heures pour se propager mondialement. Votre application continuera de fonctionner normalement pendant cette période de propagation.

## FAQ

<AccordionGroup>
  <Accordion title="Combien ça coûte ?">
    L'achat de domaine comprend deux coûts :

    * **Frais d'enregistrement** : le coût initial pour un an de propriété du domaine (deux ans pour les domaines `.ai`)
    * **Prix de renouvellement** : facturé automatiquement après la période d'enregistrement initiale

    Replit ne facture pas de frais supplémentaires pour les achats de domaine. Les frais d'enregistrement de domaine ne sont pas remboursables.
  </Accordion>

  <Accordion title="Comment renouveler mon domaine ?">
    Replit renouvelle automatiquement votre domaine pour que votre application reste accessible. Pour arrêter le renouvellement automatique, ouvrez l'onglet **Domaines** dans l'outil Publication, sélectionnez votre domaine et désactivez le bouton **Renouvellement automatique**. La même vue affiche la date de renouvellement et le prix de renouvellement de votre domaine.
  </Accordion>

  <Accordion title="Que faire si je veux quitter Replit ?">
    Vous pouvez transférer votre domaine vers un autre registraire en contactant le support Replit. Les règles ICANN exigent une période d'attente de 60 jours après l'achat avant que les domaines puissent être transférés vers des registraires externes.
  </Accordion>

  <Accordion title="Puis-je transférer des domaines entre comptes Replit ?">
    Oui, contactez le support Replit pour transférer des domaines entre comptes Replit. Ce processus ne nécessite pas la période d'attente de 60 jours.
  </Accordion>

  <Accordion title="Puis-je acheter des domaines pour mon organisation ?">
    L'achat de domaine pour les plans Replit Pro et Enterprise sera disponible après la période bêta initiale.
  </Accordion>

  <Accordion title="Puis-je ajouter des enregistrements DNS personnalisés à mon domaine ?">
    Oui ! Vous pouvez ajouter des enregistrements DNS personnalisés aux domaines achetés via Replit. Les types d'enregistrements actuellement pris en charge incluent :

    * **Enregistrements A** : pointez votre domaine ou sous-domaine vers des adresses IP spécifiques
    * **Enregistrements TXT** : ajoutez des enregistrements de vérification textuels pour l'authentification par e-mail et d'autres services
    * **Enregistrements MX** : configurez des serveurs de messagerie pour gérer les e-mails de votre domaine

    Accédez à l'onglet Domaines dans votre publication pour configurer ces enregistrements. Pour des instructions détaillées sur la configuration des enregistrements MX pour l'e-mail, consultez la section [Enregistrements DNS personnalisés](#custom-dns-records) ci-dessus.
  </Accordion>

  <Accordion title="Quelles extensions de domaine sont prises en charge ?">
    Nous prenons en charge tous les domaines de premier niveau (TLD) courants. Nous ne pouvons pas prendre en charge les TLD avec des restrictions géographiques spéciales ou d'autres restrictions.
  </Accordion>

  <Accordion title="Qu'est-ce que la protection de la vie privée WHOIS ?">
    Lorsque vous enregistrez un domaine, vos informations de contact (nom, adresse, numéro de téléphone et e-mail) sont normalement publiées dans une base de données publique appelée WHOIS que tout le monde peut consulter. La protection de la vie privée WHOIS remplace vos informations personnelles par des informations génériques du registraire, gardant vos informations privées tout en respectant les exigences légales.

    Tous les domaines achetés via Replit incluent la protection de la vie privée WHOIS par défaut sans frais supplémentaires. Cela signifie que vos informations personnelles restent cachées des spammeurs, des marketeurs et de toute autre personne qui pourrait rechercher les informations du propriétaire du domaine.
  </Accordion>

  <Accordion title="Que faire si j'ai déjà un domaine ?">
    Pour connecter un domaine existant à votre application Replit, consultez notre documentation sur les [Domaines personnalisés](/fr/features/publishing/custom-domains).
  </Accordion>
</AccordionGroup>
