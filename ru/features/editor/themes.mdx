Темы в Replit позволяют настроить внешний вид Project Editor — от цветов фона и элементов интерфейса до подсветки синтаксиса кода. Персонализируйте среду разработки, чтобы улучшить читаемость, снизить нагрузку на глаза и сделать работу с кодом приятнее.

<div id="creating-a-custom-theme">
  ## Создание пользовательской темы
</div>

Выполните следующие шаги, чтобы создать и настроить пользовательскую тему:

1. Откройте [Settings](https://replit.com/settings) и перейдите в **User** → **Personalization** (или в раздел **Themes**)
2. Выберите **Create new theme**
3. Введите название, выберите цветовую схему (светлую или тёмную) и при желании добавьте описание
4. Нажмите **Create Theme**, чтобы открыть редактор тем

Глобальные настройки темы определяют общий вид интерфейса:

* **Background**: задаёт базовый цвет для большинства элементов интерфейса
* **Outline**: управляет цветом границ и разделителей
* **Foreground**: определяет цвет текста и значков
* **Primary**: задаёт цвет кнопок и интерактивных элементов
* **Positive**: применяется к индикаторам успеха, например к кнопке **Run**
* **Negative**: отображается для ошибок и предупреждений о необратимых действиях

Нажмите **Apply Theme**, чтобы сразу начать использовать свою тему.

<div id="syntax-highlighting">
  ## Подсветка синтаксиса
</div>

Настройте внешний вид различных элементов кода, чтобы улучшить читаемость и восприятие.

<Tip>
  Правильная подсветка синтаксиса позволяет быстрее просматривать и понимать код. Выбирайте цвета, которые хорошо сочетаются друг с другом и достаточно контрастны по отношению к фону.
</Tip>

<Accordion title="Элементы подсветки синтаксиса">
  | Элемент                    | Описание                                                                         |
  | -------------------------- | -------------------------------------------------------------------------------- |
  | **Имена переменных**       | Применяется к переменным, объявленным без ключевого слова                        |
  | **Определения переменных** | Задаёт цвет имён переменных при объявлении с ключевыми словами `const` или `var` |
  | **Ссылки на функции**      | Применяется при вызове функций                                                   |
  | **Определения функций**    | Задаёт цвет имён функций при их объявлении                                       |
  | **Ключевые слова**         | Подсвечивает ключевые слова языка, такие как `import`, `function` и `return`     |
  | **Имена свойств**          | Задаёт цвет обращений к свойствам переменных                                     |
  | **Определения свойств**    | Используется при определении свойств объектов                                    |
  | **Свойства-функции**       | Применяется при вызове методов объектов                                          |
  | **Имена тегов**            | Используется для тегов HTML и JSX                                                |
  | **Имена типов**            | Задаёт цвет аннотаций типов в типизированных языках                              |
  | **Имена классов**          | Применяется к объявлениям классов и ссылкам на них                               |
  | **Имена атрибутов**        | Подсвечивает атрибуты HTML и JSX                                                 |
  | **Комментарии**            | Применяется ко всем комментариям в коде                                          |
  | **Строки**                 | Задаёт цвет строковых литералов                                                  |
  | **Числа**                  | Подсвечивает числовые значения                                                   |
  | **Логические значения**    | Оформляет логические значения (`true`/`false`)                                   |
  | **Регулярные выражения**   | Задаёт цвет шаблонов регулярных выражений                                        |
  | **Операторы**              | Подсвечивает операторы, такие как `+`, `-`, `*` и `/`                            |
  | **Скобки**                 | Задаёт цвет квадратных и угловых скобок, где это уместно                         |
</Accordion>

<div id="theme-design-best-practices">
  ## Рекомендации по оформлению тем
</div>

Создавайте визуально привлекательные и удобные темы, следуя этим рекомендациям:

<div id="color-and-contrast">
  ### Цвет и контраст
</div>

* **Соблюдайте баланс контраста**: обеспечьте достаточную разницу между фоном и элементами переднего плана
* **Создавайте гармоничные палитры**: выбирайте цвета, которые дополняют друг друга, а не спорят между собой
* **Поддерживайте одинаковую яркость**: сохраняйте схожий уровень яркости для всех элементов синтаксиса
* **Учитывайте доступность**: избегайте низкоконтрастных сочетаний, чтобы тема подходила пользователям с нарушениями зрения

<Warning>
  Типичные ошибки при создании темы:

  * Слишком большая разница в яркости между элементами синтаксиса
  * Плохо сочетающиеся цвета, создающие визуальный диссонанс
  * Недостаточный контраст между кодом и фоном
</Warning>

<div id="managing-your-themes">
  ## Управление темами
</div>

Просматривайте установленные темы и управляйте ими в разделе [Settings](https://replit.com/settings), перейдя в **User** → **Personalization** (или в раздел **Themes**).

<div id="switching-themes">
  ### Переключение тем
</div>

Нажмите кнопку рядом с названием темы, чтобы сделать её текущей.

<div id="editing-themes">
  ### Редактирование тем
</div>

Чтобы изменить свою пользовательскую тему, откройте меню с тремя точками и выберите **Edit**.

<Note>
  Редактировать и удалять можно только созданные вами пользовательские темы. Темы по умолчанию и темы, созданные другими пользователями, изменить нельзя.
</Note>

<div id="deleting-themes">
  ### Удаление тем
</div>

Чтобы удалить пользовательскую тему, откройте меню с тремя точками и выберите **Delete**.

<div id="exploring-community-themes">
  ## Знакомство с темами сообщества
</div>

Ознакомьтесь с темами, созданными сообществом Replit, на [странице обзора тем](https://replit.com/themes).

<div id="finding-themes">
  ### Поиск тем
</div>

* Ищите по названию, чтобы найти конкретные темы, например «Atom One Dark»
* Фильтруйте по автору, чтобы посмотреть темы определённых создателей
* Просматривайте по цветовой схеме, чтобы найти светлые или тёмные темы
* Ищите по конкретным цветам, чтобы подобрать тему под свои предпочтения

Перед установкой любую тему можно предварительно просмотреть и оценить, как она будет выглядеть в Project Editor.

<div id="publishing-your-theme">
  ## Публикация темы
</div>

Поделитесь своими пользовательскими темами с сообществом Replit, выполнив следующие шаги:

1. Откройте редактор тем (Themes Editor) для своей пользовательской темы
2. Нажмите кнопку **Publish**
3. Заполните поля названия и описания
4. Отправьте тему на публикацию

После публикации ваша тема появится на странице обзора тем, где другие пользователи смогут её просмотреть и установить.
