export const YouTubeEmbed = ({videoId, title = "Видео на YouTube", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

Agent 3 значительно повышает автономность, надежность и скорость:

* **Тестирование приложений**: Agent самостоятельно тестирует приложение в реальном браузере, выявляет проблемы и исправляет их в цикле рефлексии. Подробнее см. [Тестирование приложений](/ru/core-concepts/agent/app-testing).
* **Более длительное время работы**: Agent может автономно работать до 200 минут благодаря Live Monitoring — идеально для крупных проектов. Подробнее см. [Agent](/ru/core-concepts/agent#max-autonomy).
* **Создание Agent**: Создавайте агентов и автоматизации, запускаемые по расписанию или интегрируемые со Slack и Telegram. Подробнее см. [Agents &amp; Automations](/ru/core-concepts/agent/agents-and-automations).

<div id="section">
  ## Коннекторы и интеграции приложений
</div>

Выпускайте продукт быстрее благодаря встроенным интеграциям и коннекторам:

* **Replit managed**: встроенные интеграции, которые работают в приложении автоматически.
* **Коннекторы**: собственные интеграции Replit — войдите один раз и используйте подключение во всех приложениях.
* **Внешние интеграции**: доверенные сторонние сервисы, которые Agent настраивает с помощью API-ключей.

  ## Agents &amp; Automations (бета)
</div>

В рамках Agent 3 вы можете создавать интеллектуальных агентов, чат-ботов и автоматизированные рабочие процессы:

* **Slack Agent**: создавайте Slack-ботов для исследований, ответов на вопросы и автоматизации
* **Telegram Agent**: создавайте ботов для планирования, поддержки и других задач
* **Автоматизация по расписанию**: запускайте рабочие процессы по расписанию
