<div id="share-and-manage-workspace-skills">
  ### workspace skill 공유 및 관리
</div>

이제 workspace 멤버라면 누구나 skill을 만들어 비공개로 사용하거나 workspace에 공유할 수 있습니다. 공유된 skill은 다른 멤버에게 기본적으로 꺼진 상태로 표시되며, 각자 필요한 skill을 골라 활성화하면 됩니다. Admin은 workspace의 모든 skill을 관리하고, 특정 skill을 workspace 필수 항목으로 지정할 수 있습니다. 새롭게 디자인된 Skills Library에서 skill을 더 쉽게 찾고 관리해 보세요.

자세한 내용은 [Agent skills](/ko/features/agent/skills)에서 확인하세요.

<div id="teams-and-enterprise">
  ## Teams 및 Enterprise
</div>

<div id="admin-api-available-in-beta">
  ### Admin API 베타 제공
</div>

이제 Enterprise account admin은 Settings의 새로운 **Developer** 탭에서 API key를 생성하고, Admin API로 다음 작업을 수행할 수 있습니다.

* workspace, member, user group, project, deployment 조회
* 원하는 기간을 지정해 member, project, workspace의 usage 조회
* workspace, user group, 개별 member의 예산 조회 및 수정

자세한 내용은 [Admin API 문서](/ko/teams/admin-api)와 [API 레퍼런스](https://api.replit.com/docs)에서 확인하세요.
