Replit MCP utilise le [Model Context Protocol](https://modelcontextprotocol.io/) pour vous permettre de créer, rechercher, consulter, mettre à jour et publier des applications Replit depuis les outils d’IA que vous utilisez déjà.

<div id="mcp">
  ## Connecter directement un client MCP
</div>

Utilisez une connexion directe si votre client MCP ne bénéficie pas d’une intégration native à Replit.

| Propriété            | Valeur                                         |
| -------------------- | ---------------------------------------------- |
| **URL**              | `https://replit-mcp.com/server/mcp`            |
| **Transport**        | Streamable HTTP                                |
| **Authentification** | OAuth avec découverte des ressources protégées |

Ajoutez l’URL du serveur à un client MCP compatible avec Streamable HTTP et l’autorisation OAuth. Le client lit les métadonnées des ressources protégées de Replit, puis vous invite à vous connecter à Replit.

Ne créez pas de serveur OAuth personnalisé. Le serveur Replit MCP fournit au client les métadonnées OAuth nécessaires.

Vous pouvez créer de nouvelles applications ou travailler sur des applications pour lesquelles vous disposez de droits de modification, y compris des applications partagées.

<div id="replit-mcp">
  ### Configurer Replit MCP
</div>

Codex et Claude Code ne sont que des exemples. Vous pouvez ajouter Replit MCP à n’importe quel client MCP compatible.

<Tabs>
  <Tab title="Codex">
    <Steps>
      <Step title="Ouvrir la liste des MCP">
        Dans Codex, ouvrez **Settings** → **Plugins** → **MCPs**.
      </Step>

      <Step title="Ajouter Replit">
        Ajoutez un MCP personnalisé. Utilisez un nom facile à reconnaître, comme `Replit`. Sélectionnez **Streamable HTTP**. Saisissez `https://replit-mcp.com/server/mcp`, puis enregistrez. N’ajoutez ni jeton bearer ni en-tête personnalisé.

        </Frame>
      </Step>

      <Step title="S’authentifier auprès de Replit">
        Dans la liste des MCP, activez **Replit**, puis sélectionnez **Authenticate**. Sélectionnez le Workspace Replit à connecter, puis **Allow**.

        <Frame>

<div id="section">
  ## Outils
</div>

| Outil                     | Entrées requises              | Entrées facultatives                                                      | Utilisation                                                                                                                                                                                                                                                                                                                                                        |
| ------------------------- | ----------------------------- | ------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `create_app_from_prompt`  | `appDescription`, `app_stack` | `userSpecifiedAppName`, `userQuotes`, `attachmentSummary`, `sourceReplId` | Crée une application. `app_stack` peut être défini sur l’une des valeurs suivantes : `react_website`, `mobile_app`, `design`, `slides`, `animation`, `data_visualization`, `3d_game`, `document`, `spreadsheet`. Si vous définissez `sourceReplId`, la nouvelle application est créée comme copie privée d’une application existante plutôt que comme projet vide. |
| `search_apps`             | Aucune                        | `query`, `url`, `updatedAfter`, `updatedBefore`, `limit`                  | Recherche des applications par mots-clés dans le titre, URL ou date de dernière mise à jour. `limit` est compris entre 1 et 50.                                                                                                                                                                                                                                    |
| `resolve_app_by_name`     | `name`                        | Aucune                                                                    | Recherche une application par son titre exact.                                                                                                                                                                                                                                                                                                                     |
| `list_apps`               | Aucune                        | `query`, `limit`                                                          | Répertorie les applications modifiables par activité récente. La limite par défaut est de 25 et la limite maximale est de 50.                                                                                                                                                                                                                                      |
| `ask_question`            | `replId`, `question`          | Aucune                                                                    | Pose une question à Agent au sujet d’une application sans la modifier.                                                                                                                                                                                                                                                                                             |
| `update_app_using_prompt` | `replId`, `changeDescription` | `userQuotes`, `attachmentSummary`                                         | Lance une mise à jour par Agent pour une application existante.                                                                                                                                                                                                                                                                                                    |
| `publish_app`             | `replId`                      | Aucune                                                                    | Publie une application ou republie les dernières modifications.                                                                                                                                                                                                                                                                                                    |
| `get_publish_status`      | `replId`                      | Aucune                                                                    | Vérifie si l’application est publiée, son état de publication actuel et son URL publique.                                                                                                                                                                                                                                                                          |

<div id="section-2">
  ## Résolution des problèmes
</div>

| Problème                                                                      | Solution                                                                                                                                                                            |
| ----------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Replit demande une authentification                                           | Terminez à nouveau le flux de connexion OAuth dans le client MCP.                                                                                                                   |
| Impossible de trouver l’application                                           | Vérifiez que vous pouvez modifier cette application. Recherchez-la ensuite à l’aide de son URL ou utilisez `list_apps` pour la sélectionner parmi les applications correspondantes. |
| Une demande de création, de mise à jour ou de publication est encore en cours | Attendez avant de réessayer. Pour une publication, vérifiez l’état actuel avec `get_publish_status`.                                                                                |
