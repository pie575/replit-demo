<div id="o-que-so-slide-decks">
  ## 什么是 Slide Decks？
</div>

Slide Decks 让你只需与 Agent 对话，就能创建专业、精美的演示文稿。描述你的需求，即刻获得一份完整而美观的演示文稿——随后可以继续对话、直接可视化编辑，或在 [Design Canvas](/zh/pt/design/canvas) 中探索不同版本，不断迭代。

幻灯片底层使用 React 构建，因此可以导出为格式无损、完全可编辑的 PPTX、Google Slides 或 PDF 文件。你还可以将演示文稿发布为可分享的在线链接。

关键概念：

* **一步生成**：描述你想要的演示文稿，Agent 就会生成完整成品——版式、文本和视觉元素一应俱全
* **基于 React**：幻灯片是真正的 React 组件，而非静态图片，因此导出为任意格式都干净利落
* **随处导出**：下载为 PPTX、Google Slides 或 PDF——格式无损、完全可编辑
* **可部署**：将演示文稿发布为在线链接，任何人都能在浏览器中查看或直接演示

<div id="como-usar-o-slide-decks">
  ## 如何使用 Slide Decks
</div>

<div id="criando-uma-apresentao-de-slides">
  ### 创建幻灯片演示文稿
</div>

在 Replit 首页，有两种方式创建幻灯片演示文稿：

* **输入 prompt**：描述你想要的演示文稿。Agent 会识别与演示文稿相关的 prompt，并自动选择 Slide deck 技术栈。
* **从下拉菜单中选择**：打开应用类型下拉菜单，选择 **Slides**，然后描述你的演示文稿。

**prompt 示例：**

* “为我的 AI 健身应用创建一份路演演示文稿”
* “制作一份面向 A 轮投资人的 10 页幻灯片演示”
* “为我们团队的外出团建活动做一份产品概览演示文稿”

<Tip>
  提前说明篇幅和视觉风格，Agent 就会直接开始制作演示文稿，不再追问细节。例如，可以试试“制作一份关于远程办公的 8 页极简风格演示文稿”。
</Tip>

<div id="comeando-com-diretrizes-de-marca-ou-uma-referncia">
  ### 从品牌指南或参考文件开始
</div>

你可以为 Agent 提供一个起点：

* **品牌指南**：上传你的品牌指南，让 Agent 在所有幻灯片中沿用你的配色、字体和视觉风格。
* **参考文件**：上传现有的演示文稿或文档作为起点，Agent 会以此为基础继续构建。

<div id="iterando-sobre-os-seus-slides">
  ### 迭代你的幻灯片
</div>

Agent 生成第一版之后，你可以通过对话不断完善：

* **调整内容**：“让问题描述那一页更简洁”或“在市场规模部分后面加一页竞争格局。”
* **更改样式**：“使用深色主题，搭配蓝色点缀”或“把字体放大，风格更极简。”
* **添加或删除幻灯片**：“再加两页介绍我们的路线图”或“删除最后一页。”
* **添加视觉元素**：“添加一张展示预期增长的图表”或“为第 4 页的每项功能配上图标。”
* **重新排序或重组**：“把团队介绍那一页移到最后”或“把功能那一页拆成两页。”

迭代过程中，幻灯片会自动在预览面板中渲染，改动效果即时可见。

<div id="editando-slides-diretamente">
  ### 直接编辑幻灯片
</div>

无需通过 Chat，你也可以直接动手编辑：

* **[可视化编辑器](/zh/pt/design/visual-editor)**：点击任意元素，即可直接调整文本、颜色、间距和布局——不消耗 AI 额度。
* **复制或删除**：右键点击任意幻灯片，即可复制或删除该幻灯片。

<Note>
  暂不支持在幻灯片内拖放元素。如需移动或重新排列元素，请在 Chat 中告知 Agent。
</Note>

<div id="usando-o-design-canvas-para-variaes">
  ### 使用 Design Canvas 探索变体
</div>

你可以使用 [Design Canvas](/zh/pt/design/canvas) 为单张幻灯片或某个部分探索不同的设计方案，再将满意的版本应用回主演示文稿。如果你想在确定方向之前比较多种视觉思路，这种方式会很有帮助。

<div id="apresentando-e-publicando">
  ### 演示与发布
</div>

演示文稿准备就绪后：

* **演讲者模式**：进入全屏演示模式，直接在预览面板中演示。这与发布后观众看到的效果完全一致。
* **移动端支持**：幻灯片同样适配移动设备，观众可以在任意屏幕上查看。
* **发布**：将幻灯片演示文稿发布为可分享的在线 URL。任何拥有该链接的人都可以在浏览器中查看或演示这份文稿。

<div id="exportando">
  ### 导出
</div>

下载幻灯片，在 Replit 之外使用：

* **PowerPoint**：在 PowerPoint 或 Keynote 中打开并编辑 `.pptx` 文件，背景、文本和图表都能完整保留。
* **Google Slides**：直接在 Google Slides 中打开演示文稿。导出完成后，选择 **Go to Google Slides**，一步即可打开。
* **PDF**：分享可直接打印的静态版本。图片较多的演示文稿导出后文件体积依然很小，可以轻松通过邮件发送。

你还可以导入已有的演示文稿。导入 `.pptx` 文件后，其中的背景、文本和图表都能完整保留。

<div id="encontrando-suas-apresentaes-de-slides">
  ### 查找你的幻灯片演示文稿
</div>

你的幻灯片演示文稿会和其他应用一起显示在 Projects 列表中。在 Projects 页面打开 **Build type** 下拉菜单并选择 **Slides**，即可只列出包含幻灯片演示文稿工件的 project。

<div id="perguntas-frequentes">
  ## 常见问题
</div>

<Accordion title="我可以在幻灯片中拖放元素吗？">
  暂时还不行。若要在幻灯片内移动或重新排列元素，请在 Chat 中告诉 Agent。你可以使用可视化编辑器直接编辑文本、颜色和间距。
</Accordion>

<Accordion title="支持哪些导出格式？">
  你可以导出为 PPTX、Google Slides 或 PDF。所有导出文件均保持原有效果，且完全可编辑。
</Accordion>

<Accordion title="我可以使用自己的品牌规范吗？">
  可以。创建演示文稿时上传你的品牌规范，Agent 会在所有幻灯片中沿用你的配色、字体和视觉风格。
</Accordion>

<Accordion title="幻灯片在移动端可用吗？">
  可以。幻灯片能在移动设备上正常显示，因此你的观众可以在任何屏幕上查看已发布或已分享的演示文稿。
</Accordion>

<Accordion title="我可以将幻灯片发布为在线链接吗？">
  可以。发布演示文稿后，它会变成一个可分享的在线链接，任何人都可以在浏览器中查看或直接放映。
</Accordion>
