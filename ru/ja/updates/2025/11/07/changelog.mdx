<div id="agent">
  ### Анимированный значок Agent
</div>

Значок Agent теперь анимируется во время работы, поэтому сразу понятно, что Agent активно занят задачей. Это улучшение повышает воспринимаемую скорость и позволяет легче следить за действиями Agent — особенно на этапе начального планирования, когда в центральной раскладке чата отклик появляется ближе к самому запросу.

<div id="agent-2">
  ### Выпадающий список инструментов Agent в процессе планирования
</div>

Выпадающий список инструментов Agent теперь доступен в процессе первоначального планирования и подтверждения списка задач. Благодаря этому вы можете задать нужные настройки Agent, включая уровень автономности и другие параметры, уже в начале разработки.

<div id="agentat">
  ### Поддержка имён файлов с символом @ в Agent
</div>

Agent теперь поддерживает упоминания файлов через `@` — в дополнение к командам `/`, что делает его привычным для пользователей популярных инструментов разработки. Эту возможность активно запрашивали клиенты Enterprise и опытные пользователи, привыкшие к рабочим процессам в стиле Cursor.

<div id="section-3">
  ### Поддержка connector при ремиксе
</div>

Раньше при ремиксе приложения Replit, использующего connector, интеграция ломалась: для полученного ремикса не выдавалось автоматическое разрешение на использование connector. Мы обновили процесс ремикса, чтобы connector обрабатывались корректно:

* Теперь при ремиксе пользователю предлагается настроить необходимые connector
* В ходе ремикса наглядно показывается, какие интеграции нужно настроить
* После ремикса интеграции больше не ломаются

Подробнее читайте в разделах [Интеграции Agent](/ru/replitai/integrations) и [Управление connector](/ru/ja/replitai/managing-connectors).

<div id="enterprise-2">
  ### Панель аналитики для администраторов Enterprise
</div>

Администраторам Enterprise теперь доступна полноценная панель аналитики — одна из самых востребованных функций среди Enterprise-пользователей, включая Meta и Atlassian. Панель позволяет:

* **Следить за активностью пользователей**: отслеживать вовлечённость и совместную работу в масштабах всей организации
* **Отслеживать использование ресурсов**: контролировать расходы по каждому пользователю и Replit App
* **Наблюдать за деплоями**: видеть активность деплоев
* **Управлять затратами**: обеспечивать прозрачность потребления ресурсов и расходов
