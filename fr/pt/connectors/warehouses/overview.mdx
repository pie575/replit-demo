Les connecteurs d’entrepôts de données permettent à Replit Agent d’interroger en toute sécurité les entrepôts de données de votre organisation. Les développeurs utilisent le langage naturel pour créer des tableaux de bord, des outils de reporting et des applications basées sur les données, sans connaissances en SQL. Les administrateurs conservent un contrôle centralisé grâce à un accès basé sur les rôles.

<div id="warehouses-suportados">
  ## Entrepôts de données pris en charge
</div>

Les connecteurs d’entrepôt de données sont disponibles avec les formules **Enterprise**.

| Entrepôt de données | Guide de configuration                                                                                               |
| ------------------- | -------------------------------------------------------------------------------------------------------------------- |
| BigQuery            | Disponible dès maintenant — guide de configuration en cours d’élaboration                                            |
| Databricks          | [Connecter Databricks](/fr/pt/connectors/warehouses/databricks)                                                         |
| Microsoft Fabric    | [Créer des applications de données dans Microsoft Fabric](/fr/pt/connectors/warehouses/microsoft-fabric) (aperçu privé) |
| Snowflake           | [Connecter Snowflake](/fr/pt/connectors/warehouses/snowflake)                                                           |

Chaque entrepôt de données possède son propre processus de configuration, car l’intégration OAuth, le modèle d’identité et le format des identifiants diffèrent. Choisissez l’entrepôt de données que vous utilisez et suivez le guide correspondant.

<div id="plataformas-de-anlise-e-dados">
  ## Plateformes d’analyse et de données
</div>

Les connecteurs d’analyse sont disponibles avec les formules Core et Pro, ainsi qu’avec Enterprise. Connectez vos outils d’analyse pour permettre à Agent de lire et d’exploiter les données de votre produit :

* **Segment** — Données clients, flux d’événements et segments d’audience de votre CDP
* **Amplitude** — Analyses de produit, données sur le comportement des utilisateurs et métriques d’engagement
* **Hex** — Notebooks de données collaboratifs et résultats de requêtes

Gérez-les comme les autres connecteurs Replit. Consultez [Gérer vos connecteurs](/fr/pt/replitai/managing-connectors).

<div id="como-funcionam-os-conectores-de-warehouse">
  ## Comment fonctionnent les connecteurs d’entrepôt de données
</div>

La configuration est une opération ponctuelle qui implique trois rôles :

1. **Administrateur de l’entrepôt de données** — Crée une intégration OAuth ou une identité de service dans l’entrepôt de données
2. **Administrateur de l’organisation Replit** — Ajoute les identifiants à Replit et configure l’accès
3. **Développeur** — Se connecte et commence à créer avec Agent

Une fois la configuration terminée, les développeurs demandent à Agent d’utiliser l’entrepôt de données, et Agent y écrit et exécute des requêtes SQL.

<div id="criando-com-dados-de-warehouse">
  ### Créer avec des données d’entrepôt de données
</div>

Après avoir établi la connexion, vous pouvez demander à Agent de créer des applications qui utilisent vos données. Agent peut :

* Créer des outils internes qui récupèrent et affichent des données en temps réel
* Créer des tableaux de bord avec des graphiques et des visualisations basés sur votre entrepôt de données
* Générer des requêtes SQL pour alimenter le backend de votre application
* Expliquer la structure des schémas et des tables pour vous aider à déterminer ce que vous pouvez créer

<Note>
  Bien qu’Agent puisse répondre à des questions ponctuelles sur vos données, l’objectif principal des connecteurs d’entrepôt de données est de permettre à Agent de créer des applications fonctionnelles qui exploitent les données de votre organisation. Les requêtes sont exécutées directement sur votre instance d’entrepôt de données. Assurez-vous donc que vos portées OAuth et les autorisations de votre utilisateur de base de données permettent les opérations de lecture et d’écriture nécessaires.
</Note>
