<div id="section">
  ## Что такое визуализация данных?
</div>

Визуализация данных — это интерактивная панель мониторинга или инструмент для создания отчётов, который создаётся в диалоге с Agent. Опишите, что вы хотите визуализировать и где находятся данные, — Agent автоматически подберёт подходящие KPI, типы диаграмм и макет, создав готовую панель мониторинга по одному промпту.

Основные возможности:

* **Создание за один запрос**: опишите цель и источник данных, и Agent создаст полноценную панель мониторинга с подходящими диаграммами и показателями
* **Подключённые источники данных**: импортируйте данные из баз данных, [коннекторов хранилищ данных](/ru/ko/connectors/warehouses/overview), внешних API и загруженных файлов
* **Встроенные функции**: каждая панель мониторинга включает ручное и автоматическое обновление, экспорт в PDF, экспорт диаграмм в CSV и светлую/тёмную тему
* **Аналитические сводки**: Agent формирует выводы на основе запроса и полученных данных
* **Несколько артефактов**: визуализация данных может использовать тот же бэкенд и базу данных, что и другие артефакты в [том же проекте](/ru/ko/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project)

<div id="data-visualization">
  ## Использование визуализации данных
</div>

<div id="section-2">
  ### Создание с помощью промпта
</div>

На главной странице выберите вкладку **App** и опишите нужный дашборд. Agent распознает промпты, связанные с данными, и выберет стек визуализации данных.

**Примеры промптов:**

* &quot;Создай дашборд для анализа продаж с отслеживанием выручки по регионам&quot;
* &quot;Создай инструмент для подготовки отчетов с визуализацией ежемесячных показателей&quot;
* &quot;Создай дашборд, показывающий наиболее эффективные продукты на основе наших данных о продажах в BigQuery&quot;
* &quot;Подключись к Snowflake и создай дашборд для анализа оттока клиентов&quot;

<div id="section-3">
  ### Создание через раскрывающийся список
</div>

1. На главной странице перейдите на вкладку **App**.
2. Откройте раскрывающийся список типов приложений.
3. Выберите **визуализация данных**.
4. Опишите панель управления или инструмент для работы с данными, который хотите создать.

<div id="section-4">
  ### Подключение хранилища данных
</div>

Подключите визуализацию данных к BigQuery, Databricks или Snowflake с помощью [коннектора хранилища данных](/ru/ko/connectors/warehouses/overview) и создавайте дашборды на основе существующих наборов данных.

При запросе данных из хранилища Agent использует параллельный поиск с несколькими агентами, чтобы изучать схемы и наборы данных. Это ускоряет поиск и помогает Agent выбирать подходящие для дашборда таблицы и поля.

Чтобы начать, настройте коннектор хранилища данных в разделе [Интеграции](/ru/ko/features/integrations/overview) вашего проекта, а затем сообщите Agent, что вы хотите визуализировать.

<div id="section-5">
  ### Добавление фильтров и интерактивных элементов
</div>

После создания дашборда с помощью Agent вы можете отправлять ему промпты для добавления фильтров, детализации и других интерактивных элементов. Например, попросите Agent добавить фильтр по диапазону дат, выбор региона или строку поиска.

<div id="section-6">
  ### Экспорт и обмен
</div>

* **Экспорт в PDF**: экспортируйте всю панель мониторинга в PDF, чтобы поделиться ею или просмотреть офлайн.
* **Экспорт диаграмм в CSV**: скачивайте данные отдельных диаграмм в формате CSV для дальнейшего анализа в электронных таблицах или других инструментах.
* **Аналитический документ**: попросите Agent подготовить подробный аналитический документ на основе данных панели мониторинга.

<div id="section-7">
  ## Что можно создать
</div>

* **Аналитические панели**: отслеживайте ключевые показатели, такие как выручка, регистрации и вовлечённость, за разные периоды
* **Инструменты отчётности**: создавайте внутренние отчёты, которые заинтересованные стороны могут фильтровать и изучать без прямого доступа к базе данных
* **Интерфейсы для исследования данных**: изучайте наборы данных и выполняйте по ним запросы с визуальной обратной связью
* **Панели мониторинга**: отображайте данные в реальном или почти реальном времени из API, баз данных и внешних сервисов

<div id="section-8">
  ## Часто задаваемые вопросы
</div>

<Accordion title="Какие источники данных можно подключить?">
  Вы можете получать данные из Replit Database проекта, коннекторов хранилищ данных (BigQuery, Databricks, Snowflake), внешних API и загруженных файлов, например CSV. Настройте подключение к хранилищу данных через [интеграции](/ru/ko/features/integrations/overview).
</Accordion>

<Accordion title="Можно ли настроить дизайн и внешний вид?">
  Да. В диалоге можно настраивать цвета, макет и типографику — попросите Agent адаптировать дизайн под ваш бренд или внести изменения. Дашборды также поддерживают светлую и тёмную темы.
</Accordion>

<Accordion title="Будет ли Agent анализировать данные за меня?">
  После создания дашборда Agent формирует сводку анализа на основе запроса и полученных данных. Вы также можете запросить более подробный аналитический отчёт.
</Accordion>

<Accordion title="Можно ли объединить визуализацию данных с другими типами артефактов?">
  Да. В [одном проекте](/ru/ko/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project) вы можете объединить визуализацию данных с [веб-приложениями](/ru/ko/features/artifact-types/web-apps), [презентациями](/ru/ko/features/artifact-types/slide-decks) и другими типами артефактов. Они используют общий бэкенд и базу данных.
</Accordion>
