# Frames

> 프레임 종류, 프레임별 액션 바, Canvas의 Build 및 Focus 액션.

Canvas의 모든 타일은 \*\*프레임(frame)\*\*입니다. 프레임은 여러분이 선택하고 드래그하고 작업하는 대상입니다. 이 페이지에서는 프레임 종류, 선택 시 나타나는 프레임별 액션 바, 그리고 여기서 실행할 수 있는 기능인 Build와 Focus를 다룹니다.

## 프레임 종류

주요 두 종류는 **Artifacts**(실행 중인, 앱에 연결된 화면)와 **Designs**(목업)입니다. 프레임 좌측 상단 헤더에서 어느 종류인지 확인할 수 있습니다.

| 종류              | 헤더 레이블                    | 기반          | 실행 중인 앱처럼 상호작용 가능? | 실제 앱으로 전환 가능?                                       |
| --------------- | ------------------------- | ----------- | ------------------ | --------------------------------------------------- |
| Artifact        | **Website**, **Slides** 등 | 실행 중인 아티팩트  | 예                  | 이미 앱임.                                              |
| Mobile artifact | **Mobile app**            | 실행 중인 아티팩트  | 예(시뮬레이터에서)         | 이미 앱임.                                              |
| Design          | **Design**                | 정적/대화형 목업   | 대화형 프레임만           | 예 — 프레임별 **Build…** 메뉴를 통해. [Build](#build)를 참고하세요. |
| Image           | **Image**                 | 생성된 PNG/JPG | 아니요                | 아니요 — 참고 자료로 사용.                                    |
| Video           | **Video**                 | 생성된 영상      | 아니요                | 아니요.                                                |
| Vector graphic  | **Graphic**               | 생성된 SVG     | 아니요                | 아니요 — 실제 앱에 임베드.                                    |

<Note>
  Design 프레임이 정적 이미지처럼 동작하는지, 대화형 프로토타입처럼 동작하는지는 **Interactive frames** 기능에 따라 달라집니다. 이 기능이 활성화되어 있으면 Design 프레임은 실제 페이지처럼 클릭과 폼 입력에 반응합니다. 그렇지 않으면 반복 작업은 가능하지만 클릭해서 넘어갈 수는 없는 스냅샷으로 렌더링됩니다.
</Note>

## 다양한 기기에서 미리보기

디자인이 다양한 화면 크기에서 어떻게 보이는지 확인하세요. Agent에게 모바일, 태블릿, 또는 데스크톱 버전을 보여달라고 요청하세요. 예를 들어 "이 페이지의 모바일 버전을 보여줘"라고 하면 Agent가 해당 크기로 프레임을 렌더링합니다.

* **모바일**: 390 × 844
* **태블릿**: 768 × 1024
* **데스크톱**: 1280 × 720

## 프레임별 액션 바

프레임을 선택하면 액션 바가 표시됩니다. 액션은 프레임의 종류에 따라 달라집니다.

### Artifact 및 Design 프레임

Artifact(Website, Slides 등) 및 Design 프레임의 경우, 액션 바가 프레임 상단을 가로질러 표시됩니다.

<Frame caption="Design 프레임의 액션 바: Build…, Focus, 그리고 추가 옵션.">
  <img src="https://mintcdn.com/replit/OIImiKPshhawqFXK/images/replitai/canvas-frame-action-bar.png?fit=max&auto=format&n=OIImiKPshhawqFXK&q=85&s=c767372a08966097abccb48bf11591c7" alt="APEX X1 Design 프레임이 선택된 Canvas. 상단에 종류 레이블과 Build, Focus, 추가 옵션 액션이 있는 프레임별 액션 바가 표시되고, 채팅 프롬프트 입력란에 해당 프레임이 칩으로 첨부되어 있음" width="2000" height="1290" data-path="images/replitai/canvas-frame-action-bar.png" />
</Frame>

액션 클러스터는 좁은 너비에서는 아이콘으로 압축되고, 프레임이 넓어지면 레이블이 나타납니다. 좌측부터 순서대로 전체 목록은 다음과 같습니다.

| 액션       | 기능                                                                                                                                              |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| Export   | 프레임을 PNG로 다운로드합니다. [프레임을 PNG로 내보내기](/ko/design/canvas#export-a-frame-as-png)를 참고하세요.                                                            |
| Build…   | 프로젝트 내 모든 Artifact를 나열하는 메뉴를 엽니다 — 디자인을 적용할 하나를 선택하거나, **Build this design**을 선택해 새 Artifact를 만드세요. Design 프레임에만 해당됩니다. [Build](#build)를 참고하세요. |
| Focus    | 프레임을 메인 화면으로 확장하는 포커스 모드로 진입합니다.                                                                                                                |
| More (…) | 추가 프레임 액션입니다. 복사, 복제, 순서 변경, 내보내기는 보드의 [우클릭 메뉴](/ko/design/canvas#right-click-menu)에서도 사용할 수 있습니다.                                              |

앱 프레임(Website, Slides, Mobile app)은 Focus와 추가 옵션을 보여주고, Design 프레임은 그 앞에 Build…를 추가로 보여줍니다. 선택한 프레임에서 새로운 방향으로 뻗어나가려면 해당 프레임의 [제안](/ko/design/explore-suggestions)을 따라가세요.

프레임을 선택하면 다음 Agent 채팅 메시지에도 스냅샷으로 첨부됩니다 — [Canvas에 있는 것들](/ko/design/canvas#what-lives-on-the-canvas)을 참고하세요.

<Note>
  액션 바는 **읽기 전용 모드**를 따릅니다. Canvas가 백그라운드 작업 컨텍스트 안에서 잠겨 있으면 반복 작업 관련 액션은 숨겨지고 Focus만 남습니다.
</Note>

### 미디어 프레임

Image, Video, Vector graphic 프레임은 프레임 위에 작은 플로팅 액션 바를 표시합니다. 세 종류 모두 다음을 공통으로 제공합니다.

* **미디어 교체**: Canvas에서의 위치와 크기를 유지한 채 프레임에 새 파일을 업로드해 교체합니다.
* **다운로드**: 미디어 파일을 컴퓨터에 저장합니다.
* **대체 텍스트**: 접근성을 위해, 그리고 프레임이 참조될 때 Agent가 더 많은 컨텍스트를 갖도록 대체 텍스트를 추가합니다.

<Frame caption="영상 프레임의 액션 바: Replace media, Download, Alt text.">
  <img src="https://mintcdn.com/replit/OIImiKPshhawqFXK/images/replitai/canvas-frame-video-actions.png?fit=max&auto=format&n=OIImiKPshhawqFXK&q=85&s=dde933bc1e78e6cc413a9dd15f73fc2e" alt="Canvas에서 선택된 파란색 슈퍼카 영상 프레임 위에 플로팅 액션 바가 표시되어 있으며, Replace media, Download('Download original' 툴팁 포함), Alt text 컨트롤을 보여줌" width="2000" height="1252" data-path="images/replitai/canvas-frame-video-actions.png" />
</Frame>

Image 프레임에는 두 가지 컨트롤이 더 있습니다.

* **자르기(Crop)**: Canvas에서 바로 이미지를 자릅니다.
* **영상 생성(Generate video)**: 이미지로부터 짧은 영상 클립을 생성합니다.

## 새로운 방향 탐색하기

프레임을 선택하면 옆에 [제안](/ko/design/explore-suggestions)이 나타납니다: 지금 보고 있는 것을 바탕으로 한 원클릭 방향 제시로, 다른 레이아웃, 새로운 분위기, 또는 디자인이 암시하는 페이지 등이 있습니다. 각 제안은 원본 옆에 새로운 프레임으로 생성되므로, 원본은 그대로 유지된 채 비교할 수 있습니다.

## Build

선택한 Design 프레임의 **Build…** 메뉴는 디자인을 실제 작동하는 앱으로 승격시킵니다. 동일한 메뉴로 이미 존재하는 Artifact에 디자인을 적용하는 것도 가능합니다.

<Frame>
  <img src="https://mintcdn.com/replit/OIImiKPshhawqFXK/images/replitai/canvas-build-menu.png?fit=max&auto=format&n=OIImiKPshhawqFXK&q=85&s=494228a2a81e9f943376d78e77b96417" alt="선택된 Design 프레임(APEX X1 Exact Replica)에서 열린 Build 메뉴. 헤더는 'Build or apply your designs'이며, 새 아티팩트를 만드는 'Build this design'과, 프로젝트의 APEX X1 Design System 및 Scroll Hero 웹사이트를 나열하는 'Apply to an existing creation'을 보여줌" width="2000" height="1153" data-path="images/replitai/canvas-build-menu.png" />
</Frame>

### Build this design

메뉴에서 **Build this design**을 선택하면 선택한 Design 프레임으로부터 새 Artifact가 시작됩니다. 새 Artifact는 프로젝트의 아티팩트 목록에 추가되어 실제 작동하는 앱이 됩니다. Build에는 Core 또는 Pro가 필요합니다.

### 기존 Artifact에 적용하기

Build… 메뉴에는 프로젝트 내 모든 Artifact가 나열됩니다. 하나를 선택하면 선택한 Design의 변경 사항이 해당 Artifact에 적용됩니다 — Agent가 디자인에 맞춰 Artifact의 코드를 다시 작성하며, Design 프레임은 참고용으로 Canvas에 남아 있습니다.

    <Frame caption="포커스 모드">
