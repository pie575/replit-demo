Shell позволяет выполнять в проекте такие задачи, как управление файлами, установка пакетов
и запуск скриптов, — так же, как в обычном терминале. Например, вы можете просматривать
файлы проекта или использовать `psql`, если в проекте настроено подключение к базе данных.

<Tip>
  Для более удобного управления рабочими процессами рекомендуем использовать кнопку **Run**
  вместо запуска приложения через Shell. Рабочие процессы, запущенные кнопкой **Run**,
  выводят результат в инструмент Console, который дает структурированный способ
  просматривать логи.
</Tip>

<div id="section">
  ## Возможности
</div>

Shell предоставляет следующие возможности:

* **Запуск нескольких Shell**: открывайте несколько экземпляров Shell, чтобы одновременно выполнять разные задачи
* **Поиск текста**: находите нужный текст в выводе Shell

<div id="shell">
  ### Проверка доступа к Shell
</div>

Чтобы убедиться, что Shell готов к работе, и посмотреть текущее рабочее пространство, выполните:

```sh theme={null}
pwd
```

Shell выводит путь к текущему рабочему пространству.

<Frame caption="Команда pwd выводит путь к текущему рабочему пространству и возвращает к приглашению Shell.">
  <img src="/assets/mirror/shell-pwd-output-2d31a0e0466b.jpg" alt="Вкладка Shell с командой pwd, выводом пути к рабочему пространству и приглашением Shell" width="1280" height="246" data-path="images/workspace/shell-pwd-output.jpg" />
</Frame>

Для проектов с базой данных выберите **Tools** → **Database**, затем
откройте страницу **Development database**. На этой странице доступны
настройки подключения. Храните значения подключения в тайне. Не копируйте
их в документацию, скриншоты, журналы, исходные файлы или сообщения,
которыми делитесь с другими.

<div id="section-3">
  ### Поиск текста
</div>

Ниже описано, как открыть и использовать инструмент поиска текста:

1. Нажмите на значок лупы <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="Значок лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> в правом верхнем углу вкладки Shell, чтобы открыть диалоговое окно поиска.
2. Введите поисковый запрос и нажмите **Next**, чтобы перейти к следующему совпадению.
3. Чтобы вернуться к предыдущему совпадению, используйте **Previous**.
4. Нажмите **Exit** или щёлкните за пределами диалогового окна, чтобы завершить поиск текста.

<div id="shell-2">
  ### Несколько Shell
</div>

Чтобы открыть ещё один Shell:

1. В заголовке панели Shell откройте меню экземпляров Shell.
2. Выберите **New Shell**.

<Frame>
  <img src="/assets/mirror/shell-new-94a280c1230f.png" alt="Меню экземпляров Shell с текущим рабочим пространством и опцией New Shell" width="1280" height="224" data-path="images/workspace/shell-new.png" />
</Frame>

Используйте это же меню для переключения между Shell. Для удобства различения Replit отображает для каждого Shell последнюю выполненную в нём команду.

<Warning>
  При открытии нескольких Shell Replit автоматически закрывает неактивные экземпляры Shell.
  Неактивный Shell — это Shell, который не выбран и в котором не запущены пользовательские процессы.
</Warning>
