<div id="o-que-um-replit-app">
  ## 什么是 Replit App？
</div>

Replit Apps 是托管在云端的项目，包含代码、数据和各类资源。
你可以在安全隔离的环境中创建、运行并部署它们。

Replit Apps 与 Project Editor 中的以下工具集成，为你带来
流畅连贯的开发体验：

* **AI 工具**：使用 Agent 编写、调试和讲解代码。
* **协作**：与他人实时协作开发同一个应用。
* **部署**：一键将应用部署到云端。

<div id="principais-funcionalidades">
  ## 核心功能
</div>

Replit Apps 提供以下功能：

* **零配置：** 直接在 Replit.com 上创建应用或编写代码，无需安装或配置。
* **自动保存：** 项目会持续将更改保存到云端，让你在任意网页浏览器上都能继续编程
* **版本控制：** 借助 Replit 的版本控制系统，无需任何配置即可跟踪更改、查看文件历史并同步文件
* **公开/私有可见性控制：** 通过隐私设置控制谁可以查看、运行或 Remix 你的应用
* **部署：** 无需复杂的配置改动，即可将代码发布到云端
* **自定义 URL：** 为应用获取专属 URL，或绑定自定义域名，打造专业形象

<Info>
  上传到项目文件系统的文件仅在开发过程中可用，
  已部署的应用和其他开发者均无法访问。请使用 [Object
  Storage](/zh/pt/features/data-and-storage/object-storage) 管理
  上传并提供文件服务，使用 [Replit
  Database](/zh/pt/features/data-and-storage/sql-database) 为你的应用和用户存储与
  读取数据。
</Info>

若要进一步了解可简化 Replit Apps 创建流程的 Project Editor 工具，请参阅 [Project Editor 概览](/zh/pt/learn/projects-and-artifacts/project-editor/)。

<div id="como-funciona">
  ## 工作原理
</div>

创建 Replit App 时，Replit 会在云端为您的项目设置一个私有空间。
当您为应用添加功能或进行修改时，Replit 会自动保存更改，
以便您随时通过任意网页浏览器继续编辑。

Replit 提供包含所有必要组件的预配置环境。
您可以立即开始构建应用，无需担心
服务器配置、数据库配置或环境管理。

Replit 会自动为每个 Replit App 分配一个专属网址，您可以通过该网址
在开发过程中预览应用。准备好分享您的
作品后，只需点击几下即可发布，让它全天候可用。

<div id="viso-geral-de-armazenamento">
  ## 存储概览
</div>

Replit 提供四种主要存储类型，满足应用的数据需求。每种存储类型适用于不同的使用场景，并根据你的套餐设有相应限制。

<Info>
  存储限制包括应用存储的所有数据，其中包括已安装的包和依赖项。
</Info>

| 存储类型                                                               | 描述        | 使用场景            | 持久性         | 套餐限制                                                                                                                                                 |
| ------------------------------------------------------------------ | --------- | --------------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **文件存储**                                                           | 项目中的文件    | 应用代码、静态资源、配置文件  | 部署后保留，重启时重置 | Starter: {StarterWorkspaceStorage}<br />Core: {CoreWorkspaceStorage}<br />Pro: {TeamsWorkspaceStorage}<br />Enterprise: {EnterpriseWorkspaceStorage} |
| **[数据库](/zh/pt/features/data-and-storage/sql-database/)**             | 结构化数据存储   | 用户资料、游戏分数、产品目录  | 跨会话完全持久化    | 每个开发数据库 20 GB<br />生产数据库按计算时间和存储空间收费                                                                                                                 |
| **[App Storage](/zh/pt/features/data-and-storage/object-storage/)**   | 非结构化数据和媒体 | 图片、视频、PDF、文档    | 跨会话完全持久化    | 按使用量付费<br />按存储空间和带宽收费                                                                                                                               |
| **[Secrets](/zh/pt/core-concepts/project-editor/app-setup/secrets/)** | 加密敏感数据    | API 密钥、凭据、连接字符串 | 完全持久化且已加密   | 无特定限制<br />所有套餐均包含                                                                                                                                   |
