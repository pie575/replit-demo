<div id="agent-v2">
  ### Agent v2
</div>

<img src="/assets/mirror/agent-web-01b1f9026de7.webp" alt="Agent v2" width="800" height="450" data-path="images/changelog/2025-02-28/agent-web.webp" />

Обновлённый Agent теперь доступен всем разработчикам. Он работает быстрее, точнее и эффективнее предыдущей версии.

Его основа — Claude 3.7 Sonnet, самая продвинутая модель Anthropic.

Присоединяйтесь к программе Explorer и попробуйте сами. Инструкции — [здесь](https://youtu.be/pE_XT2TaXCA).

<div id="section-3">
  ### Улучшения деплоя
</div>

Разработчикам, которые выбирают статический деплой для динамических App, теперь показываются подсказки ИИ, а поведение Agent при обработке запросов на деплой стало лучше.

<div id="claude-37-sonnet">
  ### Выпуск Claude 3.7 Sonnet
</div>

Расширенный режим Assistant обновлён до Claude 3.7 Sonnet для всех разработчиков на платных тарифах. Это повышает точность и производительность при обработке сложных запросов.

<div id="section-4">
  ### Улучшение производительности базы данных
</div>

Операции с базой данных стали быстрее, чем когда-либо: самые расходоёмкие из них теперь выполняются менее чем за 1 мс вместо прежних 200 мс.

<div id="section-5">
  ### Улучшенная документация
</div>

<img src="/assets/mirror/cleanshot-2025-02-27-at-1042282xpng-220848-e5317a7cfb93.png" alt="Редизайн документации" width="3680" height="2382" data-path="images/changelog/2025-02-28/cleanshot-2025-02-27-at-1042282xpng-220848.png" />

Мы полностью переработали документацию: теперь она удобна для LLM, понятнее и проще в использовании.

В документации появилась кнопка «Скопировать страницу» — она копирует всю страницу в формате Markdown. Кроме того, документация проиндексирована в файлах `llms.txt` и `llms-full.txt`, которые можно использовать с собственной LLM.

* [https://docs.replit.com/llms.txt](https://docs.replit.com/llms.txt)
* [https://docs.replit.com/llms-full.txt](https://docs.replit.com/llms-full.txt)
