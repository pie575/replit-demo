Гибкие решения Replit для хранения данных позволяют быстро добавить в App подходящее хранилище. Для App со следующими требованиями можно использовать базу данных или объектное хранилище Replit, а Agent автоматически настроит и интегрирует оба решения:

* Игры, в которых нужно хранить данные об игроках, например прогресс или рекорды
* Контентные платформы для управления медиафайлами

<div id="replit">
  ## Варианты хранилища и баз данных в Replit
</div>

Replit предлагает следующие варианты хранения данных:

* **База данных**: для хранения структурированных данных, таких как профили пользователей, игровые результаты и каталоги продуктов.
  Позволяет хранить и получать данные на основе свойств и связей между ними.

* **Хранилище App**: для хранения неструктурированных данных, таких как изображения, видео и документы.
  Позволяет хранить и получать большие файлы и двоичные данные.

<div id="section">
  ### Сравнение Хранилища App и баз данных
</div>

|                            | База данных                                           | Хранилище App                                      |
| -------------------------- | :---------------------------------------------------- | :------------------------------------------------- |
| **Оптимальный тип данных** | Структурированные взаимосвязанные данные              | Большие файлы (изображения, видео, документы)      |
| **Модель данных**          | Таблицы, строки, столбцы                              | Бакеты, файлы                                      |
| **Язык запросов**          | SQL                                                   | REST API                                           |
| **Клиенты**                | Клиенты, совместимые с PostgreSQL, и ORM              | Replit SDK и клиентская библиотека GCS             |
| **Модель оплаты**          | Зависит от вычислительного времени и объёма хранилища | Зависит от пропускной способности и объёма хранилища |

  ### Инструменты Project Editor

Узнайте подробнее о следующих инструментах Replit для настройки и управления хранилищем данных вашего App:

<CardGroup>
  <Card title="База данных" href="/ru/ko/features/data-and-storage/sql-database" icon="database">
    Идеально подходит для структурированных данных и моделирования связей между ними.
    Работает на полностью управляемой базе данных PostgresSQL, которая масштабируется вместе с вашим App.
  </Card>

  <Card title="Хранилище App" href="/ru/ko/features/data-and-storage/object-storage" icon="bucket">
    Идеально подходит для неструктурированных данных и больших файлов, таких как изображения, видео и документы.
    Работает на базе Google Cloud Storage (GCS), обеспечивая высокую доступность и масштабируемость. Agent может автоматически настроить хранилище App с расширенной аутентификацией и контролем доступа.
  </Card>
</CardGroup>
