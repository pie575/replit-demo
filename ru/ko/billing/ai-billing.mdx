Функции Replit AI оплачиваются по модели на основе Usage: стоимость зависит от того, что вы создаёте, и от объёма Usage инструментов на базе ИИ. Так вы платите только за ценность, которую получаете от Agent.

<div id="section">
  ## Начало работы
</div>

**Все подписчики** получают один бесплатный чекпоинт Agent.

Дополнительные ежемесячные кредиты автоматически применяются к Usage ИИ:

* **Подписчики Core**: ежемесячные кредиты (см. [тарифы](https://replit.com/pricing))
* **Подписчики Pro**: ежемесячные кредиты по уровням с переносом на {ProCreditRolloverPeriod}. См. [Replit Pro](/ru/ko/billing/plans/replit-pro).

Эти кредиты распространяются на Agent и другие облачные сервисы Replit: опубликованные приложения, хранилище и базы данных. Выберите режим [Lite, Economy или Power](/ru/ko/features/agent/agent-modes), чтобы оптимизировать работу Agent по скорости, стоимости или производительности.

Free Mode позволяет подписчикам Core и Pro бесплатно выполнять повседневные задачи в Agent в пределах установленного лимита. Для платных режимов и подтверждённых платных задач применяется тарификация по объёму работы. Replit запрашивает подтверждение перед началом платной задачи.

<div id="section-2">
  ### Как работает тарификация по объёму работы
</div>

Когда вы общаетесь с Agent в режиме Build, создаётся **чекпоинт**, фиксирующий выполненную работу по вашему запросу:

* **Простые запросы** (например, исправление ошибок или небольшие изменения) обычно стоят меньше, чем сложные задачи сборки
* **Сложные задачи сборки** (например, полноценные функции или интеграции) могут объединяться в один чекпоинт и стоить дороже простых запросов, что отражает общий объём работы
* **Один чекпоинт на запрос** исключает промежуточные чекпоинты и уменьшает неопределённость при выставлении счетов
* **Прозрачная тарификация** позволяет точно понимать, за что вы платите по завершении каждой задачи

<Info>
  Чекпоинты создаются, когда Agent завершает работу по вашему запросу и реализует запрошенную функцию в коде.
</Info>

На платных тарифах Plan Mode может выполнять оплачиваемые операции рассуждения, даже если код не изменяется.

Подробнее о том, что фиксируют чекпоинты и как они работают, см. в разделе [Чекпоинты и откаты](/ru/ko/features/version-control/checkpoints-and-rollbacks).

<div id="agent-3">
  ### Оплата сервисов Agent
</div>

Некоторые возможности Agent внутри используют платные сторонние API (Claude, ChatGPT, Nano Banana / Gemini и другие). Agent обрабатывает эти интеграции автоматически, поэтому ключи API и дополнительная настройка не нужны. Оплата рассчитывается по публичным тарифам API поставщиков и списывается с кредитов Replit. Эти расходы отображаются вместе с остальным Usage в [панели Usage](/ru/ko/billing/managing-spend).

Чтобы оценить стоимость на примере приложения, посмотрите простое [интерактивное демо](https://agent-pricing.replit.app/).

<div id="section-3">
  ### Отслеживание Usage
</div>

Вы можете отслеживать расходы Agent в реальном времени:

1. **Вкладка Agent**: наведите курсор на значок Usage, чтобы увидеть стоимость отдельных чекпоинтов
2. **Панель Usage**: просматривайте подробную информацию о начислениях за текущий период
3. **Настройки**: контролируйте расходы с помощью уведомлений и бюджетов в разделе **Аккаунт** → **Счета**

<Tip>
  Данные об Usage могут появиться на панели Usage с задержкой до 30 минут.
</Tip>

<div id="section-4">
  ## Управление расходами
</div>

Контролируйте расходы на ИИ с помощью встроенных инструментов бюджетирования Replit:

* **Уведомления об Usage**: получайте оповещения при достижении заданных порогов расходов
* **Лимиты бюджета**: задавайте жёсткие ограничения, которые уберегут от непредвиденных списаний
* **Отслеживание в реальном времени**: следите за затратами прямо во время разработки
* **Пакеты кредитов**: покупайте дополнительные кредиты со скидкой при оптовой покупке. Подробнее см. в разделе [Управление расходами](/ru/ko/billing/managing-spend).

<div id="section-5">
  ## Дальнейшие шаги
</div>

Готовы начать создавать приложения с помощью ИИ? Вот как получить максимум пользы от кредитов:

* **Сначала попробуйте Agent**: изучите возможности Agent с помощью бесплатных чекпоинтов
* **Начните с малого**: простые запросы помогут понять, как работает тарификация по объёму работы
* **Используйте режим Lite**: для быстрых и точечных правок применяйте [режим Lite](/ru/ko/features/agent/agent-modes)
* **Настройте уведомления**: включите оповещения о расходах, чтобы не превысить лимит кредитов

Узнайте больше об [ИИ-инструментах Replit](/ru/ko/welcome) или ознакомьтесь с [тарифными планами](https://replit.com/pricing).
