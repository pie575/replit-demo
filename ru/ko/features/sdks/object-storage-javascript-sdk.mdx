<div id="client">
  ## Client
</div>

Класс `Client` управляет взаимодействием с Replit App Storage. Он предоставляет методы для выполнения операций с файлами в бакете.

Чтобы импортировать класс из библиотеки, добавьте в свой JavaScript-код следующую строку.

```javascript theme={null}
import { Client } from "@replit/object-storage";
```

С помощью следующего кода создайте экземпляр `Client` для взаимодействия с Replit Object Storage.

```javascript theme={null}
const client = new Client();
```

<div id="section">
  ## Конструктор
</div>

**constructor**

* **new Client**(`options?`): `Client`

Создаёт новый экземпляр Client для работы с Replit App Storage.

**Параметры**

| Имя        | Тип             | Описание                        |
| :--------- | :-------------- | :------------------------------ |
| `options?` | `ClientOptions` | Параметры конфигурации клиента. |

**Возвращаемое значение**

`Client`

<div id="section-2">
  ## Методы
</div>

<div id="copy">
  ### copy
</div>

* **copy**(`objectName`, `destObjectName`): `Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

Копирует объект в пределах одного бакета.
Если по целевому пути объект уже существует, метод перезаписывает его.

**Параметры**

| Имя              | Тип      | Описание                                          |
| :--------------- | :------- | :------------------------------------------------ |
| `objectName`     | `string` | Полный путь к копируемому объекту.                |
| `destObjectName` | `string` | Полный путь, по которому будет скопирован объект. |

**Возвращаемое значение**

`Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

***

<div id="uploadfrombytes">
  ### uploadFromBytes
</div>

* **uploadFromBytes**(`objectName`, `contents`, `options?`): `Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

Загружает объект, используя его байтовое представление в памяти.
Этот метод перезаписывает существующий объект с таким же именем.

**Параметры**

| Имя          | Тип             | Описание                                   |
| :----------- | :-------------- | :----------------------------------------- |
| `objectName` | `string`        | Полный целевой путь объекта.               |
| `contents`   | `Buffer`        | Исходное содержимое объекта в виде байтов. |
| `options?`   | `UploadOptions` | Настройки операции загрузки.               |

**Возвращаемое значение**

`Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

<div id="uploadfromfilename">
  ### uploadFromFilename
</div>

* **uploadFromFilename**(`objectName`, `srcFilename`, `options?`): `Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

Загружает файл из локальной файловой системы в бакет.
Этот метод перезаписывает существующий объект с таким же именем.

**Параметры**

| Имя           | Тип             | Описание                                                |
| :------------ | :-------------- | :------------------------------------------------------ |
| `objectName`  | `string`        | Полный целевой путь объекта.                            |
| `srcFilename` | `string`        | Путь к загружаемому файлу в локальной файловой системе. |
| `options?`    | `UploadOptions` | Настройки операции загрузки.                            |

**Возвращаемое значение**

`Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

<div id="uploadfromstream">
  ### uploadFromStream
</div>

* **uploadFromStream**(`objectName`, `stream`, `options?`): `Promise`&lt;`void`&gt;

Загружает объект, считывая его содержимое из переданного потока.
Поток передаёт ошибки, возникшие во время загрузки. Метод перезаписывает существующий объект с таким же именем.

**Параметры**

| Имя          | Тип             | Описание                                                      |
| :----------- | :-------------- | :------------------------------------------------------------ |
| `objectName` | `string`        | Полный целевой путь объекта.                                  |
| `stream`     | `Readable`      | Поток для чтения, из которого считывается содержимое объекта. |
| `options?`   | `UploadOptions` | Настройки операции загрузки.                                  |

**Возвращаемое значение**

`Promise`&lt;`void`&gt;

</div>
