export const profileImagesPrompt = "将玩家拍摄的头像存储在 App Storage 中，并与其账户关联。";

PixelGames 需要一个地方来存储玩家拍摄的照片。本指南
假设玩家已经能够[登录](/zh/pt/build/mobile-login)，因为存储功能
需要识别上传者的身份。

<AiPrompt>
  {profileImagesPrompt}
</AiPrompt>

Agent 集成了 [App Storage](/zh/pt/features/data-and-storage/object-storage)，并将每次
上传与当前登录的玩家关联。这样，PixelGames 就能显示真实的个人资料：上传的照片
会显示在玩家姓名旁边。

<div id="teste">
  ## 测试
</div>

1. 使用现有账户登录 PixelGames。
2. 拍摄或选择一张头像并上传。
3. 关闭并重新打开 App，确认头像仍在。
4. 在第二部手机上使用同一账户登录，并确认显示的是同一张头像。

<div id="soluo-de-problemas">
  ## 故障排除
</div>

* **已登录但照片未显示：**应用可能连接到了与预期不同的
  存储或身份验证实例。请让 Agent 检查连接。
* **上传失败：**请确认应用在上传前已请求相机和存储
  权限。
