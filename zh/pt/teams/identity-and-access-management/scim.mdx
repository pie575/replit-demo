<div id="introduo">
  ## 简介
</div>

<Note>
  SCIM 仅面向 Enterprise 客户开放。如需为您的组织启用该功能，请通过 [sales@replit.com](mailto:sales@replit.com) 联系我们的销售团队。
</Note>

跨域身份管理系统 ([SCIM](https://en.wikipedia.org/wiki/System_for_Cross-domain_Identity_Management)) 是一种标准化协议，可在企业身份模型提供方 (IdP) 与 Replit 之间自动完成用户的预配与注销。

启用 SCIM 后，您可以直接在 Replit 中管理同步过来的群组和成员如何映射到 Replit 的 workspace 与角色——请参阅[管理 workspace 访问权限](#managing-workspace-access)。

<div id="principais-recursos">
  ## 主要功能
</div>

<CardGroup cols={2}>
  <Card title="自动化成员管理" icon="user-plus">
    根据您的 IdP 目录自动预配和取消预配成员
  </Card>

  <Card title="角色同步" icon="shield">
    让成员的角色和权限与您的组织架构保持同步
  </Card>

  <Card title="批量操作" icon="users">
    通过群组批量操作高效管理大型团队
  </Card>

  <Card title="支持主流 IdP" icon="plug">
    可直接与 Microsoft Entra ID、Okta 及其他领先的身份模型提供方集成
  </Card>
</CardGroup>

<div id="benefcios">
  ## 优势
</div>

SCIM 集成为 Enterprise 团队带来多项优势：

* **安全性更强**：借助现有的身份管理系统，实现严密的访问控制
* **管理更简便**：通过身份模型提供方自动管理团队成员
* **高效开通**：无需人工干预，轻松为大规模团队完成账号预配
* **访问控制一致**：在整个组织内保持统一的访问策略

<div id="primeiros-passos">
  ## 快速开始
</div>

<Steps>
  <Step title="启用 SCIM">
    打开 **设置** &gt; **高级** &gt; **身份与治理**，为你的 Enterprise 组织启用 SCIM。
  </Step>

  <Step title="配置你的 IdP">
    直接在“身份与治理”设置中打开 SCIM 集成门户。该门户会针对你所使用的身份模型提供方提供分步说明，帮助你同步用户目录。
  </Step>

  <Step title="测试集成">
    预配一个测试用户，验证连接是否正常。
  </Step>

  <Step title="投入生产">
    开始使用 SCIM 自动管理成员，然后参照 [通过 SCIM 管理 workspace 访问权限](#managing-workspace-access)，将同步的群组分配到各个 workspace。
  </Step>
</Steps>

<div id="melhores-prticas">
  ## 最佳实践
</div>

* 在启用 SCIM 之前，记录现有 Replit 成员的角色分配情况。
* 设置一个默认 workspace，让每个同步的群组至少在其中获得**查看者**访问权限；如果没有默认 workspace，成员在你将其所属群组分配到某个 workspace 之前将不具备任何角色。
* 先为一小组成员进行预配，以测试配置，然后再启用批量预配。
* 首次同步完成后，根据组织的访问控制需求，检查并为自定义群组配置权限。
* 专门设置角色控制群组来管理已预配成员的访问级别，并使用其他推送群组进行分类和批量权限管理。
* 记录你的 SCIM 配置，以备日后参考。

<div id="sincronizao-de-grupos">
  ## 群组同步
</div>

从你的 IdP 推送的所有群组都会同步到 Replit，并包含 IdP 为该群组预配的成员。例如，当你通过 SCIM 推送“工程”群组时，Replit 会创建一个对应的群组，其中包含这些已预配的成员。

群组成员关系会自动更新，与 IdP 中的成员关系保持一致。你可以利用这些已同步的群组批量编辑成员权限，例如把某个应用共享给“工程”群组中的所有人。

<div id="use-grupos-no-aninhados-com-o-microsoft-entra-id">
  ### 在 Microsoft Entra ID 中使用非嵌套群组
</div>

<Warning>
  Microsoft Entra ID 只会预配显式分配的群组中的直接成员，不会展开嵌套群组。如果某个用户仅属于子群组，则不会被添加到 Replit 中的父群组。除非有另一个已分配的群组直接包含该用户，否则 Microsoft Entra ID 不会预配该用户。
</Warning>

进行 SCIM 预配时，请使用非嵌套群组，并将用户直接添加到你分配给 Replit 的每个群组中。如果必须在 Microsoft Entra ID 中保留嵌套群组，请将所有直接包含用户的群组都分配给 Replit 应用。更多详情，请参阅 [Microsoft 关于基于分配的范围界定的指南](https://learn.microsoft.com/en-us/entra/identity/app-provisioning/how-provisioning-works#assignment-based-scoping)。

<div id="criando-grupos-personalizados-junto-com-o-scim">
  ### 在启用 SCIM 的同时创建自定义群组
</div>

即使启用了 SCIM，你仍然可以在 Replit 中创建自定义群组。你可以用自定义群组按项目工作、临时权限授予或任何未在身份模型提供方中体现的结构来组织成员。

* **SCIM 群组保持锁定状态。** 从 IdP 同步而来的群组只能通过身份模型提供方进行编辑或删除。
* **自定义群组在 Replit 中管理。** 组织管理员可以直接在“群组”页面创建、编辑和删除自定义群组。
* **成员可同时属于两类群组。** 通过 SCIM 预置的成员也可以添加到自定义群组中，且不会影响其由 IdP 管理的角色。

有关群组的详细信息，请参阅[群组与权限](/zh/pt/teams/identity-and-access-management/groups-and-permissions)。

<div id="gerenciando-o-acesso-ao-workspace">
  ## 管理 workspace 访问权限
</div>

启用 SCIM 后，可通过产品内置的管理界面查看并控制已同步的群组如何映射到 workspace 和角色，并指定账户管理员群组。你的 IdP 始终是成员归属和预置的唯一可信来源；此界面仅决定这些已同步的群组和成员如何映射到 Replit 的 workspace 和角色，不会添加、移除或重新预置成员。

<div id="estruture-seus-workspaces">
  ### 规划 workspace 结构
</div>

一般来说，我们建议将成员集中在**同一个 workspace** 中，只有在确有明确理由需要分开时才创建额外的 workspace——例如，不应共享成员、群组或预算的不同业务部门。凡是需要协作的人员，都应处于同一个 workspace 中。

你可以将同步的群组分配给各个 workspace。在 workspace 内，已分配的群组会显示为**自定义群组**，可用于 workspace 级别的管控，例如**按群组设置预算**——比如为营收团队设置 10 万的预算。

<div id="abrir-o-acesso-ao-workspace-via-scim">
  ### 通过 SCIM 开放 workspace 访问权限
</div>

1. 打开 workspace 选择器，选择你的 Enterprise workspace。
2. 打开**设置**，然后选择**高级**。
3. 展开**身份与治理**部分，找到**成员自动预配 (SCIM)** 卡片。
4. 当 SCIM 处于**进行中**状态时，管理界面会直接显示在该卡片内。

<div id="designe-o-grupo-de-administrador-de-conta">
  ### 指定账户管理员群组
</div>

请先完成此项设置。顶部的 **账户管理员群组** 区块会显示由 IdP 同步的哪个群组在你的所有 workspace 中拥有账户管理员角色，并可访问账户级设置，包括 SCIM 管理权限。

选择 **编辑** 即可改选其他已同步的群组。指定群组是一次彻底的转移：新群组将成为账户管理员群组，原有群组的账户管理员角色会被撤销。由于账户管理员权限广泛，此更改需经确认后才会生效。

<Note>
  账户管理员群组的成员管理完全在你的身份提供方中进行。要添加或移除账户管理员，请在 IdP 中调整指定群组的成员构成——此界面仅反映成员关系，无法对其进行编辑。
</Note>

<div id="visualize-e-gerencie-atribuies-de-workspace">
  ### 查看和管理 workspace 分配
</div>

**Workspaces** 标签页会列出组织中的所有 workspace，以及分配给它们的同步群组和每个群组的角色。

**默认 workspace** (带有**默认**标识) 是预配访问权限的基础：每个同步群组都会自动在其中获得至少**查看者**权限，确保成员始终有一个起点。只有管理员设置后，某个 workspace 才会成为默认 workspace；在此之前，成员只能通过您所做的群组分配获得访问权限。

* 使用搜索框按名称筛选 workspace。
* 每一行会以 *群组 · 角色* 格式的标签显示其**群组分配** (例如 *Engineering · 管理员*) 。当某个 workspace 的分配数量超出一行可容纳的范围时，会显示 **+ N 更多**标签来表示其余内容。
* 通过该行的 **⋮** 菜单，可以编辑分配，或将该 workspace 设为组织默认 workspace，也可取消其默认状态。

<div id="atribua-grupos-a-workspaces-e-defina-funes">
  ### 将群组分配到 workspace 并设置角色
</div>

在某个 workspace 所在行的 **⋮** 菜单中选择 **编辑分配**，打开 **编辑 workspace 访问权限** 对话框。在这里，你可以选择哪些已同步的群组可以访问该 workspace，以及每个群组所获得的角色：

* **管理员** — 对 workspace 的设置和资源拥有完整的管理权限。
* **成员** — 可以创建和编辑 Replit App。
* **查看者** — 对应用和部署拥有只读访问权限。
* **访客** — 只能访问他人与其共享的应用。

账户管理员群组的授权处于锁定状态 (显示为锁形图标) ，因为它由账户管理员的指定统一管理，而非按 workspace 分别设置。

<div id="limitaes">
  ## 限制
</div>

* **您的身份模型提供方始终是唯一可信来源。** 添加、移除和预配成员，以及编辑群组归属，都需在身份模型提供方中完成。Replit 只负责为已同步目录中已有的群组*分配* workspace 和角色。
* **Microsoft Entra ID 不会展开嵌套群组。** 请使用非嵌套群组，或将所有直接包含用户的群组分配给 Replit 应用，详见[在 Microsoft Entra ID 中使用非嵌套群组](#use-flat-groups-with-microsoft-entra-id)。
* **账户管理员群组可以更改，但不能移除。** 您可以另行指定一个群组作为账户管理员群组，但无法让组织不设该群组。

<div id="perguntas-frequentes">
  ## 常见问题
</div>

<div id="o-que-acontece-com-membros-que-j-tm-contas-no-replitcom-antes-de-o-scim-ser-configurado">
  ### 在配置 SCIM 之前就已在 replit.com 拥有账户的成员会怎么样？
</div>

启用 SCIM 后，现有成员分两种情况处理：

1. **由 SCIM 预置的成员**：
   * 其角色会更新为与您的 IdP 提供的角色一致。
   * 这些成员只能通过您的 IdP 添加、移除或变更角色。
   * 为保持权限同步，管理员无法再在 Replit 中编辑角色或邀请新成员。
2. **非 SCIM 预置的成员**：
   * 这些成员保持不变，被视为&quot;遗留&quot;成员。
   * 其组织成员身份和角色不会被自动移除，以免误取消预置。
   * 如有需要，组织管理员可通过 Replit 界面移除遗留成员。

<Warning>
  实施 SCIM 后，所有由您的 IdP 预置的成员都必须通过您的身份模型提供方进行管理，才能保持同步。只有遗留成员 (即非 SCIM 预置的成员) 才能直接在 Replit 中取消预置。
</Warning>

<div id="quais-funes-podem-ser-provisionadas-com-o-scim">
  ### SCIM 可以预配哪些角色？
</div>

SCIM 用户可以被分配以下四种角色：

* **管理员**：对组织设置和资源拥有完全访问权限
* **成员**：可创建和编辑 Replit Apps 的标准访问权限
* **访客**：面向外部协作者的受限访问权限，仅能编辑明确共享给他们的应用
* **查看者**：对已部署应用拥有只读访问权限

你可以在[通过 SCIM 管理 workspace 访问权限](#managing-workspace-access)中按 workspace 配置 IdP 群组与 Replit 角色之间的映射。例如，你可以让&quot;Engineering&quot;群组在某个 workspace 中拥有成员角色，而在另一个 workspace 中仅为查看者角色。

<div id="posso-adicionar-ou-remover-membros-pelo-acesso-ao-workspace-via-scim">
  ### 我可以在 SCIM 的 workspace 访问设置中添加或移除成员吗？
</div>

不可以。成员归属和预配由您的身份模型提供方管理。此界面仅用于管理同步过来的群组和成员如何映射到 workspace 及角色。若要在 SCIM 之外进行日常成员管理，请参阅[管理成员](/zh/pt/teams/identity-and-access-management/managing-members)。

<div id="como-as-funes-diferem-dos-grupos">
  ### 角色与群组有何区别？
</div>

群组从您的 IdP 同步而来。角色 (Admin、成员、visualizador、访客) 用于描述某个群组在特定 workspace 中可以执行哪些操作。同一个群组在不同 workspace 中可以拥有不同的角色——例如，在某个 workspace 中是**成员**，而在另一个 workspace 中是 **visualizador**。

<div id="alterar-o-grupo-de-administrador-de-conta-afeta-outras-funes">
  ### 更改账户管理员组会影响其他角色吗？
</div>

指定新的账户管理员组只会更改整个组织范围内的账户管理员角色，workspace 的其他组分配及相应角色不受影响。有关账户管理员角色的详细说明，请参阅[账户管理员和 Workspace 管理员](/zh/pt/teams/identity-and-access-management/account-and-workspace-admins)。
