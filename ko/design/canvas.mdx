Canvas는 Replit Design이 frame을 표시하는 공간으로, 자유롭게 이동하고 확대·축소할 수 있는 무한한 작업 공간입니다. 여러분이 디자인하는 모든 것이 이곳에 담깁니다. frame을 생성하고, 원하는 위치로 끌어다 놓고, 세부 사항을 확대해 보면서 마음에 드는 결과가 나올 때까지 다듬어 보세요.

<div id="open-the-canvas">
  ## Canvas 열기
</div>

Replit Design에 들어가면 가장 먼저 보이는 것이 Canvas입니다. 프로젝트에서 헤더의 **Design**을 선택하면 Canvas가 pane을 가득 채우고, **Build**를 선택하면 실행 중인 앱으로 다시 돌아갑니다.

<Frame>
  <img src="/assets/mirror/canvas-design-button-ffa50447cefb.png" alt="Design이 선택된 Design/Build 토글이 있는 프로젝트 헤더 확대 화면과 그 아래 Canvas의 frame들" width="987" height="619" data-path="images/replitai/canvas-design-button.png" />
</Frame>

[replit.com/design](https://replit.com/design)에서 새로 시작하면 새 design을 만들라는 안내가 표시되고, 만든 design은 Canvas에서 열립니다. 각 화면을 언제 사용하면 좋은지는 [Design vs. Build](/ko/design/design-vs-build)를 참고하세요.

<div id="what-lives-on-the-canvas">
  ## Canvas에 놓이는 요소
</div>

* **Frames**: board 위의 모든 타일입니다. frame은 design mockup, web app, mobile app, slides, 이미지, 동영상, 벡터 그래픽 중 무엇이든 될 수 있습니다. Chat prompt, 툴바의 [Generate 메뉴](/ko/design/toolbar#generate), [library panel](/ko/design/library-panel)에서 생성할 수 있습니다. Build, Focus, suggestions 등 frame에 대한 모든 작업은 frame 자체를 통해 이루어집니다. [Frames](/ko/design/frames)를 참조하세요.
* **드로잉과 노트**: [Draw 도구](/ko/design/toolbar#draw)로 추가하는 마크업으로, 스케치, 화살표, 도형, 스티커 노트 등이 있습니다. Agent가 이 마크업을 읽기 때문에 문제가 되는 부분에 동그라미를 치고 변경을 요청할 수 있습니다.
* **Chat 패널**: Canvas 옆에 고정된 Agent chat입니다. 메시지를 보내기 전에 frame을 선택하면 snapshots으로 첨부되어 Agent가 시각적 context를 파악할 수 있습니다.

각 구성 요소가 무엇이고 서로 어떻게 어우러지는지는 [구성 요소 개요](/ko/design/core-components)를 참조하세요.

<div id="navigate-the-board">
  ## board 탐색하기
</div>

별도로 명시된 경우를 제외하면, 어떤 도구를 사용 중이든 pan, 확대/축소, 선택을 할 수 있습니다.

**Pan 하기:**

* 트랙패드: 두 손가락 드래그.
* 마우스: 가운데 버튼 클릭 후 드래그, 또는 스페이스바를 누른 채 왼쪽 버튼 클릭 후 드래그.
* [Pan 도구](/ko/design/toolbar#pan): 왼쪽 마우스 버튼으로 클릭 후 드래그.

**확대/축소:**

* 트랙패드: 핀치 동작.
* 마우스: `Ctrl`(macOS에서는 `Cmd`) + 스크롤 휠.
* 키보드: 확대는 `Cmd`/`Ctrl` + `+`, 축소는 `Cmd`/`Ctrl` + `-`, 확대/축소 초기화는 `Cmd`/`Ctrl` + `0`.

확대/축소는 커서를 기준점으로 삼기 때문에, 커서 아래에 있는 지점은 제자리에 고정되고 board의 나머지 부분이 그 주위로 scale됩니다.

**선택하기:**

* 단일 frame: [Interact 도구](/ko/design/toolbar#interact)로 클릭합니다.
* 다중 선택: `Shift`를 누른 채 각 frame을 클릭하거나, board 위에서 사각형 영역을 드래그합니다.
* 선택 해제: 빈 영역을 클릭하거나 `Escape`를 누릅니다.

frame을 하나 이상 선택하면 [per-frame action bar](/ko/design/frames#per-frame-action-bar)가 나타나고, 선택한 frame이 snapshots 형태로 다음 Agent 메시지에 첨부됩니다.

<div id="keyboard-shortcuts">
  ### 키보드 단축키
</div>

| 단축키                            | 동작                 |
| ------------------------------ | ------------------ |
| `V`                            | Interact 도구 활성화    |
| `H`                            | Pan 도구 활성화         |
| `Space` 누른 채 드래그               | 어떤 도구에서든 화면 이동     |
| `Cmd` / `Ctrl` + 스크롤           | 확대/축소              |
| `Cmd` / `Ctrl` + `+`           | 확대                 |
| `Cmd` / `Ctrl` + `-`           | 축소                 |
| `Cmd` / `Ctrl` + `0`           | 확대/축소 초기화          |
| `Shift` + 클릭                   | 현재 선택 항목에 frame 추가 |
| `Cmd` / `Ctrl` + `Shift` + `C` | 선택한 frame을 PNG로 복사 |
| `Escape`                       | 선택 해제              |

<div id="right-click-menu">
  ## 우클릭 메뉴
</div>

board의 아무 곳이나 우클릭하면 컨텍스트 메뉴가 열립니다. 이 메뉴는 상황에 따라 달라져서 커서 아래에 있는 대상에 맞는 동작이 표시됩니다. frame 위에서는 frame 관련 동작이, 빈 Canvas에서는 board 수준의 동작이 나타나며, 앱 frame에서는 **Refresh artifact**가 추가됩니다.

frame을 선택한 상태에서는 메뉴에 다음 항목이 포함됩니다.

| 동작                             | 단축키                           | 기능                                                        |
| ------------------------------ | ----------------------------- | --------------------------------------------------------- |
| Edit                           |                               | Edit tool로 전환하여 frame 내부의 요소를 선택합니다.                      |
| Chat                           |                               | frame에 대해 Agent와 Chat합니다.                                 |
| Focus                          |                               | 해당 frame의 [focus mode](/ko/design/frames#focus-mode)로 전환합니다. |
| Cursor chat                    | `/`                           | 커서 위치에서 빠른 채팅을 시작합니다.                                     |
| Reorder                        |                               | 겹침 순서에서 frame을 앞이나 뒤로 이동합니다.                              |
| Copy, Paste, Duplicate, Delete | `⌘C`, `⌘V`, `⌘D`, `Backspace` | 표준 클립보드 및 frame 관리 기능입니다.                                 |
| Export as…                     |                               | frame을 파일로 내보냅니다.                                         |
| Select all                     | `⌘A`                          | board의 모든 frame을 선택합니다.                                   |

<div id="export-a-frame-as-png">
  ### frame을 PNG로 내보내기
</div>

artifact나 design frame을 PNG 이미지로 저장할 수 있습니다. 문서나 채팅으로 미리 보기를 공유하거나, 추가 작업에 들어가기 전에 snapshot을 남기거나, 팀원에게 스크린샷을 보낼 때 유용합니다.

<Steps>
  <Step title="frame 선택">
    내보낼 artifact 또는 design frame을 선택한 다음, 로딩이 끝날 때까지 기다립니다.
  </Step>

  <Step title="Export 선택">
    frame의 per-frame action bar에서 **Export**를 선택합니다. frame을 마우스 오른쪽 버튼으로 클릭한 다음 **Export as…** &gt; **PNG**를 선택해도 됩니다. 이미지는 frame 이름을 딴 파일명으로 컴퓨터에 다운로드됩니다.
  </Step>
</Steps>

선택한 frame을 다운로드하지 않고 PNG로 복사하려면 `Cmd+Shift+C`(Windows 및 Linux에서는 `Ctrl+Shift+C`)를 누르세요.

<Note>내보낸 PNG는 Canvas에 현재 표시된 frame 화면 그대로입니다. 앱이나 design이 아직 로딩 중이라면 완전히 렌더링된 후에 내보내세요.</Note>

<div id="the-canvas-and-the-live-app">
  ## Canvas와 live app
</div>

Canvas와 live app 미리보기는 같은 pane을 공유하며, 다음 몇 가지 모드가 이 둘을 이어줍니다:

* **Focus mode**: 선택한 frame에서 **Focus** 액션을 실행하면 해당 frame이 확대되어 화면 전체를 채웁니다. board 상단의 **Exit focus**를 선택하면 canvas로 돌아갑니다.
* **읽기 전용 모드**: 백그라운드 task context 안에서 canvas가 잠기면 반복 작업 관련 액션은 숨겨지고 Focus만 남습니다.

<Note>
  Design frame에서 새 App을 Build하려면 Core 또는 Pro가 필요하며, 그 외 모든 canvas 기능은 모든 plan에서 사용할 수 있습니다. plan에 대한 자세한 내용은 [Billing](/ko/billing/ai-billing)을 참조하세요.
</Note>
