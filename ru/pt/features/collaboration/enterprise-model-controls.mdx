Управление моделями в Enterprise позволяет администраторам аккаунта определять, какие модели Agent доступны для выбора разработчикам. Задайте политику на уровне аккаунта, а затем настройте отдельные наборы доступных моделей для конкретных рабочих пространств.

<Note>
  Управление моделями доступно исключительно администраторам аккаунтов Enterprise. Чтобы подключить эту возможность для вашей организации, свяжитесь с нашим отделом продаж по адресу [sales@replit.com](mailto:sales@replit.com).
</Note>

<div id="usar-o-roteamento-inteligente-de-modelos">
  ## Использование интеллектуальной маршрутизации моделей
</div>

Интеллектуальная маршрутизация моделей — это стандартный режим работы Agent в рабочих пространствах Enterprise. Когда включён **режим Auto**, Replit подбирает наиболее подходящие режим и модель для каждой задачи, балансируя между качеством и стоимостью.

Маршрутизация выбирает модель из набора, разрешённого политиками аккаунта и рабочего пространства. Провайдеры и модели вне этого набора недоступны для выбора. Разработчики могут оставить **режим Auto** включённым или отключить его и выбирать разрешённую модель вручную.

Подробнее о том, как работает маршрутизация, читайте в разделе [Использование интеллектуальной маршрутизации моделей](/ru/pt/chat/auto-mode).

<div id="abrir-as-configuraes-de-modelo-do-agent">
  ## Открытие настроек моделей Agent
</div>

1. Откройте **Настройки**.
2. В разделе **Аккаунт** выберите **Дополнительно**.
3. Разверните раздел **Режимы Agent и провайдеры моделей**.

<div id="definir-uma-poltica-de-provedor">
  ## Настройка политики провайдера
</div>

<Steps>
  <Step>
    Выберите провайдера моделей, которым хотите управлять.
  </Step>

  <Step>
    В разделе **Account policy** выберите один из вариантов:

    | Вариант             | Результат                                                        |
    | ------------------- | ---------------------------------------------------------------- |
    | **Enable all**      | Все модели провайдера доступны во всех рабочих пространствах.                |
    | **Enable selected** | Вы сами выбираете модели, доступные в каждом рабочем пространстве.          |
    | **Disabled**        | Ни одно рабочее пространство не может использовать модели этого провайдера. |

    <Note>
      Хотя бы одна модель от OpenAI, Anthropic и Google должна оставаться включённой. Остальных провайдеров можно отключить.
    </Note>
  </Step>

  <Step>
    Нажмите **Update**.
  </Step>
</Steps>

Провайдеры моделей с открытым исходным кодом по умолчанию отключены. Чтобы открыть доступ к одному из них, выберите **Enable all** или **Enable selected**, а затем нажмите **Update**.

<div id="definir-uma-poltica-de-workspace">
  ## Настройка политики рабочего пространства
</div>

Используйте **Enable selected**, если разным рабочим пространствам нужен разный доступ к моделям.

<Frame caption="Политика провайдера Anthropic со значением Enable selected и доступом к моделям, настроенным для каждого рабочего пространства.">
  <img src="/assets/mirror/anthropic-account-policy-workspace-models-38c0f71a609d.jpg" alt="Политика аккаунта Anthropic со значением Enable selected и переключателями моделей для рабочего пространства" width="2000" height="930" data-path="images/workspace/anthropic-account-policy-workspace-models.jpg" />
</Frame>

1. Откройте настройки провайдера.
2. Установите для **Account policy** значение **Enable selected**.
3. В списке **рабочее пространство** откройте выпадающее меню **Setting** нужного рабочего пространства.
4. Включите или отключите каждую модель для этого рабочего пространства.
5. Выберите **Update**.

Перед нажатием **Update** можно выбрать **Copy to all**, чтобы применить набор
моделей текущего рабочего пространства ко всем рабочим пространствам в аккаунте.

<div id="limitaes">
  ## Ограничения
</div>

* Политики моделей действуют на уровне рабочего пространства. Задать отдельную политику для группы пользователей внутри одного рабочего пространства нельзя.
* Интеллектуальная маршрутизация моделей не отменяет политики учётной записи или рабочего пространства: она не может выбрать отключённого провайдера или отключённую модель.
* Кнопка **Модели Fast mode** в разделе **Режимы Agent и провайдеры моделей** управляет доступом к быстрым вариантам моделей во всех рабочих пространствах учётной записи. Политики провайдеров и интеллектуальная маршрутизация моделей на эту настройку не влияют.
