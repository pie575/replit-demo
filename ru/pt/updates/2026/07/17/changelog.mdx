<div id="agent-sugere-conectores-quando-vrios-se-encaixam">
  ### Agent предлагает коннекторы, когда подходит сразу несколько
</div>

Когда вы просите Agent подключить сервис и подходящих провайдеров оказывается несколько, Agent теперь показывает короткий список, из которого вы выбираете нужный. Раньше Agent сначала задавал уточняющий вопрос. Выберите провайдера, войдите один раз — и Agent продолжит работу.

<div id="conhea-o-novo-painel-tools">
  ### Знакомьтесь: новая панель Tools
</div>

Всё, что может использовать ваш app, теперь собрано в одном месте в вашем workspace. Новая закреплённая панель Tools объединяет Database, Auth, Domains, Secrets и другие инструменты. Так весь набор инструментов можно найти за секунды. Сами инструменты не изменились — у них просто появилось более понятное место.

</Frame>

Подробнее о [панели Tools](/ru/pt/features/editor/editor-and-tools).

<div id="uma-barra-lateral-de-tarefas-mais-rpida">
  ### Более быстрая боковая панель задач
</div>

Боковая панель задач стала более компактным и удобным для беглого просмотра навигатором по задачам. У каждой задачи появилась своя карточка, которая открывается при наведении и даёт доступ к быстрым действиям и подробностям, у Task Board теперь более понятная точка входа, а задачи остаются на месте и не смещаются при разворачивании или сворачивании панели.
