## 플랫폼

### 보안 스캐너 업데이트

대규모 보안 스캐너 업데이트로 더 빠르고 스마트한 보안 스캔을 경험하세요. 이제 스캔 결과가 캐시되어 코드가 변경될 때만 재실행되므로 이후 스캔이 매우 빠릅니다. 새로운 무시 기능을 사용하면 보고 싶지 않은 보안 문제를 숨기면서도 필요할 때 찾을 수 있습니다.

### Agent 시스템 프롬프트 최적화

최신 시스템 개선으로 더 빠르고 효율적인 Agent 상호작용을 즐기세요. Agent는 이제 동일한 고품질 결과를 유지하면서 액션당 2\~3초 더 빠르게 작업을 완료합니다.

### 새로운 앱 생성 경험

새롭게 디자인된 생성 경험으로 더 나은 앱을 빌드하세요! 이제 빌드하기 전에 앱을 시각화하고 계획하여 개발 계획을 이해하고 디자인 방향을 반복할 수 있습니다. 빠른 빌드 프로세스에 착수하기 전에 Agent가 만들 내용을 정확히 확인하세요.
