<div id="security-agent-reviews-your-whole-codebase">
  ### Security Agent examine l’intégralité de votre base de code
</div>

**Security Agent** est un nouvel outil de révision basé sur l’IA qui audite non seulement vos dépendances, mais l’ensemble de votre projet. Il établit un modèle de menaces, cartographie vos routes et flux de données, exécute une analyse statique avec Semgrep et HoundDog.ai, et utilise un LLM pour déterminer quels constats sont réellement exploitables dans le contexte de votre app. Une fois l’analyse terminée, Security Agent organise les constats retenus en tâches parallèles que Replit Agent peut corriger en une seule passe.

<Frame>
  <img src="/assets/mirror/security-agent-findings-b425392bb98a.png" alt="Volet Security Agent dans le Centre de sécurité du projet affichant une analyse terminée avec cinq constats classés par gravité, chacun avec un statut tel que « Ready for review » ou « Ready for republish », ainsi qu’une section d’analyse automatique des dépendances répertoriant les paquets vulnérables" width="1438" height="808" data-path="images/changelog/2026-04-24/security-agent-findings.png" />
</Frame>

Security Agent est disponible pour tous les créateurs disposant d’une offre payante. Ouvrez le volet **Security** de votre projet et sélectionnez **Run Scan with Agent** pour l’essayer.

En savoir plus sur [Security Agent](/fr/core-concepts/security/project-security-center#agent-security-scans).

<div id="cve-auto-protect-patches-critical-vulnerabilities-automatically">
  ### CVE Auto-Protect corrige automatiquement les vulnérabilités critiques
</div>

Lorsqu&#39;une nouvelle CVE critique est divulguée pour un paquet dont dépend votre app, **CVE Auto-Protect** détecte les projets concernés parmi tous ceux dont vous êtes propriétaire, charge Agent de préparer un correctif dans une tâche en arrière-plan, exécute vos tests pour vérifier que rien ne casse et vous en informe avec un lien pour l&#39;examiner. Vous gardez le contrôle — rien n&#39;est publié tant que vous n&#39;avez pas approuvé le correctif.

Vos apps peuvent ainsi être corrigées quelques minutes seulement après qu&#39;une nouvelle vulnérabilité est rendue publique, sans attendre que vous la remarquiez.

En savoir plus sur [CVE Auto-Protect](/fr/core-concepts/security/project-security-center#auto-protect).

<div id="preview-on-an-ios-simulator-or-android-emulator">
  ### Prévisualiser dans un iOS Simulator ou un Android Emulator
</div>

<Frame>
  <video autoPlay muted loop playsInline src="/assets/mirror/ios-emulator-9013ff1b602f.mp4" />
</Frame>

Lorsque votre projet inclut une application mobile, le panneau Preview peut désormais diffuser un véritable **iOS Simulator** ou **Android Emulator** directement dans votre workspace. Ni Xcode, ni Android Studio, ni appareil physique ne sont nécessaires. Créez une application mobile avec Agent, sélectionnez votre appareil dans le menu déroulant du panneau Preview et utilisez-le comme si vous aviez le téléphone en main. Les modifications sont rechargées à chaud dans le simulateur à mesure qu’Agent les apporte.

Disponible pour les créateurs disposant d’un forfait payant Core, Pro ou Enterprise, sur Chrome, Safari et les navigateurs basés sur Chromium. Firefox n’est pas pris en charge pour les simulateurs mobiles.

Pour en savoir plus, consultez [la prévisualisation sur un simulateur ou un émulateur](/fr/features/artifact-types/building-mobile-apps#preview-on-a-simulator-or-emulator).

<div id="add-a-mobile-app-to-older-projects">
  ### Ajouter une application mobile à d’anciens projets
</div>

<Frame>
  <img src="/assets/mirror/multi-artifact-update-approval-f6fa8b70a100.png" alt="Panneau de Chat Agent affichant la carte d’approbation « Mettre à jour le projet pour créer une application mobile », avec une offre de 5 $ de crédits et les boutons Pas maintenant / Mettre à jour le projet." width="991" height="589" data-path="images/replitai/multi-artifact-update-approval.png" />
</Frame>

Les projets créés avant le lancement d’Agent 4 peuvent désormais être mis à jour pour prendre en charge plusieurs artefacts. Vous pouvez ainsi ajouter une application mobile, un pitch deck ou un autre artefact à un projet qui n’en prenait auparavant en charge qu’un seul. Agent conserve votre URL, vos données, vos Secrets et votre déploiement lors de la réorganisation du projet. Plus de 200 projets ont été migrés au cours des 48 premières heures suivant le déploiement à grande échelle.

En savoir plus sur la [mise à jour d’anciens projets pour prendre en charge plusieurs artefacts](/fr/features/projects-and-artifacts/updating-projects-for-multiple-artifacts).

<div id="plaid-connector-is-live">
  ### Le connecteur Plaid est disponible
</div>

Vous pouvez désormais vous connecter à plus de 12 000 institutions financières grâce au connecteur **Plaid**. Les administrateurs de l&#39;équipe configurent les identifiants une seule fois dans **Intégrations**, et les utilisateurs de votre application authentifient leurs propres comptes bancaires via Plaid Link. Les jetons d&#39;accès sont associés à chaque utilisateur, afin de préserver la confidentialité des données.

Créez un coach financier personnel exploitant des données de transaction réelles, un outil de suivi de portefeuille en temps réel connecté à votre courtier, et bien plus encore. Consultez la [page partenaire Replit x Plaid](https://replit.com/partners/plaid) pour découvrir des démonstrations et les étapes de configuration.

En savoir plus sur la [gestion des connecteurs](/fr/replitai/managing-connectors).
