Secrets 工具用于存储并加密 **secrets**，即 Replit App 的敏感信息，例如 API 密钥、身份验证令牌和数据库连接字符串。

添加 secret 后，该工具会自动加密数据，并以环境变量的形式提供给你的 Replit App。
这样一来，你无需在代码中硬编码 secrets，也就降低了泄露风险。

在以下场景中，将 secrets 硬编码在代码库中可能导致意外泄露：

* 通过公开的 Replit App 或复制粘贴的方式与他人分享代码
* 将代码提交到公开仓库进行版本控制
* 直播或屏幕共享你的代码

使用 Secrets 工具，你可以放心分享代码，不必担心凭据外泄。

<div id="features">
  ## 功能
</div>

Secrets 提供以下功能：

* **端到端加密**：通过静态数据 AES-256 加密和传输中数据 TLS 加密，自动保护您的数据
* **App 级 Secrets**：存储和管理特定于某个 Replit App 的 Secrets
* **账户级 Secrets**：存储和管理可在您所有 Replit Apps 中使用的 Secrets
* **环境变量访问**：通过环境变量在代码中访问 Secrets
* **协作访问**：与协作者和团队成员共享 Secrets

<div id="usage">
  ## 使用方式
</div>

<Note>
  除 Static Deployment 外，所有 deployment 类型均支持 Secrets。
</Note>

你可以在 Project Editor 的 Secrets 工具中管理 Secrets。

<Accordion title="如何打开 Secrets">
  通过左侧的**工具停靠栏**：

  1. 选择 <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="All tools icon" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**，查看 Project Editor 的工具列表。
  2. 选择 <img class="icon-svg" src="/assets/mirror/lock-af402c9618dd.svg" alt="Secrets icon" width="16" height="16" data-path="images/icons/lock.svg" /> **Secrets**。

  通过**搜索栏**：

  1. 点击顶部的 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="magnifying glass icon" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 放大镜图标，打开搜索工具
  2. 输入“Secrets”找到该工具，然后在结果中选择它。
</Accordion>

<div id="manage-app-secrets">
  ### 管理 App Secrets
</div>

你可以在 **Secrets** 面板的 **App Secrets** 选项卡中管理应用级 Secrets。
该选项卡会列出与你的 Replit App 关联的所有 Secrets。

<Accordion title="添加 App Secrets">
  添加 Secret 的步骤：

  1. 选择 **New Secret**。
  2. 输入 **Key** (Secret 的名称) 和 **Value** (Secret 的具体内容) 。
  3. 选择 **Add Secret** 保存该条目。
</Accordion>

<Accordion title="编辑 App Secrets">
  编辑 Secret 的步骤：

  1. 选择该 Secret 旁边的 <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="三个竖点图标" height="16" width="16" data-path="images/icons/vertical-dots.svg" /> 竖点菜单。
  2. 在弹出菜单中选择 **Edit**。
  3. 修改 **Key** 或 **Value** 字段中的文本，然后选择 **Update Secret** 保存更改，或选择 **Cancel** 放弃更改。

  你也可以选择选项卡底部的 **Edit as JSON** 或 **Edit as .env**，一次性修改整个 App Secrets 列表。
</Accordion>

<Accordion title="查看 App Secrets">
  要查看某个 Secret，请选择该 Secret 旁边的 <img class="icon-svg" src="/assets/mirror/eye-8a6472b8a950.svg" alt="眼睛图标" width="16" height="16" data-path="images/icons/eye.svg" /> 眼睛图标。

  要隐藏该 Secret，请选择 <img class="icon-svg" src="/assets/mirror/eye-slash-6b4ded538179.svg" alt="带斜线的眼睛图标" width="16" height="16" data-path="images/icons/eye-slash.svg" /> 带斜线的眼睛图标。
</Accordion>

<Accordion title="删除 App Secrets">
  要删除某个 Secret，请选择该 Secret 旁边的 <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="三个竖点图标" height="16" width="16" data-path="images/icons/vertical-dots.svg" /> 竖点菜单，然后选择 **Delete**。
</Accordion>

<div id="manage-account-secrets">
  ### 管理账户 Secrets
</div>

你可以在 **Secrets** 面板的 **Account Secrets** 选项卡中管理账户级 secrets。
该选项卡仅列出与你的 Replit 账户关联的 secrets。

<Accordion title="添加账户 Secrets">
  添加账户级 secret 的步骤：

  1. 前往 **Account Secrets** 选项卡。
  2. 选择 <img class="icon-svg" src="/assets/mirror/settings-icon-c2664c3691bf.svg" alt="齿轮图标" width="16" height="16" data-path="images/icons/settings-icon.svg" /> 图标以打开 **Settings**，管理账户级 secrets。
  3. 选择 **New Secret** 添加 secret。
  4. 输入 **Key** (secret 的名称) 和 **Value** (secret 本身) 。
  5. 选择 **Save** 保存该条目。
</Accordion>

<Accordion title="编辑账户 Secrets">
  编辑 secret 的步骤：

  1. 选择 secret 旁边的 <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="铅笔图标" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> 铅笔图标。
  2. 修改 **Key** 或 **Value** 字段中的文本，然后选择 **Save** 保存更改，或选择 **Cancel** 放弃更改。
</Accordion>

<Accordion title="查看账户 Secrets">
  要查看 secret，请选择该 secret 旁边的 <img class="icon-svg" src="/assets/mirror/eye-8a6472b8a950.svg" alt="眼睛图标" width="16" height="16" data-path="images/icons/eye.svg" /> 眼睛图标。

  要隐藏 secret，请选择 <img class="icon-svg" src="/assets/mirror/eye-slash-6b4ded538179.svg" alt="带斜线的眼睛图标" width="16" height="16" data-path="images/icons/eye-slash.svg" /> 带斜线的眼睛图标。
</Accordion>

<Accordion title="关联账户 Secrets">
  要在 Replit App 中使用账户级 secret，必须先将其关联到该应用。
  关联账户级 secret 的步骤：

  1. 前往 **App Secrets** 选项卡。
  2. 选中 secret 左侧的复选框。
  3. 选择 **Link to this App**。

  取消关联 secret 的步骤：

  1. 前往 **App Secrets** 选项卡。
  2. 选择 secret 旁边的 <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" width="16" height="16" alt="三个竖点图标" data-path="images/icons/vertical-dots.svg" /> 竖点菜单。
  3. 选择 **Unlink**。
</Accordion>

<Accordion title="删除账户 Secrets">
  1. 选择 secret 旁边的 <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="铅笔图标" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> 铅笔图标。
  2. 选择 **Delete**。
</Accordion>

<div id="managing-secrets-visibility">
  ### 管理 Secrets 的可见性
</div>

Secrets 的可见性取决于您对 Replit App 的访问权限，以及您是否为其创建者。

您可以通过以下任一方式共享 Replit App：

* **多人协作**：邀请 Replit 用户进行实时协作
* **封面页**：展示 Replit App 的预览，并允许他人 remix
* **Remix**：将个人或组织的 Replit App 设为公开，让其他人创建自己的版本

下表列出了不同场景下 Secret 名称和值的可见性：

| 访问方式     | 用户                           | 可查看名称 | 可查看值 |
| -------- | ---------------------------- | ----- | ---- |
| 多人协作     | 多人协作成员                       | ✓     | ✓    |
| 多人协作     | 组织成员 (Owner 角色)              | ✓     | ✓    |
| 多人协作     | 组织成员 (非 Owner 角色)            | ✓     |      |
| 封面页      | 任何访客                         |       |      |
| Remix    | remix 自己 Replit App 的所有者/协作者 | ✓     | ✓    |
| Remix    | remix Replit App 的非所有者/协作者   | ✓     |      |
| Remix    | 通过封面页 remix 的任何人             | ✓     |      |
| 组织 Remix | 拥有 Owner 角色的组织成员             | ✓     | ✓    |
| 组织 Remix | 不具备 Owner 角色的组织成员            | ✓     |      |

<Warning>
  不具备 Owner 角色的组织成员无法查看 Replit App 中的 Secret 值，但可以通过打印环境变量获取这些值。
</Warning>

<div id="database-related-secrets">
  ## 数据库相关的 Secrets
</div>

当你添加 Replit 数据库时，Project Editor 会自动创建以下 secret：

| Secret         | 说明           |
| -------------- | ------------ |
| `DATABASE_URL` | SQL 数据库连接字符串 |

<Info>
  旧版 Neon 开发数据库可能还包含 `PGHOST`、`PGUSER`、`PGPASSWORD`、`PGDATABASE` 和 `PGPORT`。当前的 Replit 开发数据库改用 `DATABASE_URL`。
</Info>

要查看 Replit App 中的所有环境变量，可在 Project Editor 的 Shell 工具中运行 `printenv`，或在代码中将其打印出来。

<div id="predefined-environment-variables">
  ## 预定义环境变量
</div>

Replit 会自动设置以下环境变量，你可以在 App 中访问：

| 环境变量                | 说明                                          |
| ------------------- | ------------------------------------------- |
| `REPLIT_DOMAINS`    | 与你的 Replit App 关联的所有域名，以逗号分隔                |
| `REPLIT_USER`       | 当前编辑者的用户名，在多人协作会话中可能有所不同                    |
| `REPLIT_DEPLOYMENT` | 如果代码在已发布的 App 中运行，则设为 `1`；否则不设置             |
| `REPLIT_DEV_DOMAIN` | `replit.dev` 域名上的开发 URL，与 deployment URL 不同 |

这些变量不会显示在 Secrets 工具中，但你可以通过 `os.environ` 对象在代码中访问它们，或在 Shell 中运行 `printenv`。
