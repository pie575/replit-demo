  ## Agent

<div id="section-2">
  ### Routage intelligent des modèles
</div>

Le routage intelligent des modèles sélectionne automatiquement le modèle et le niveau d&#39;effort les mieux adaptés à la tâche, tout en trouvant le bon équilibre entre qualité et coût. Lorsque vous choisissez **Auto** en mode **Power** ou **Max**, Replit oriente chaque partie de la tâche selon l&#39;évolution de sa complexité. Pour un contrôle plus fin, vous pouvez aussi choisir vous-même un modèle et un niveau d&#39;effort précis.

</Frame>

En savoir plus sur le [Auto Mode](/fr/ko/chat/auto-mode).

  ### Trouver vos premiers clients avec les Growth Skills

<div id="enterprise">
  ### Routage intelligent des modèles pour Enterprise
</div>

Le routage intelligent des modèles devient le mode Agent par défaut dans les workspaces Enterprise. Lorsque le **mode Auto** est activé, Replit sélectionne le mode et le modèle autorisé les mieux adaptés à chaque tâche. Les administrateurs de compte peuvent contrôler la disponibilité des modèles workspace par workspace et désactiver le **mode Auto** pour choisir eux-mêmes un modèle activé. Le menu des modes Agent d&#39;Enterprise propose désormais **Power** et **Max**, et n&#39;inclut plus **Lite**.

<Frame caption="Activez le mode Auto pour laisser Replit choisir le mode et le modèle les mieux adaptés à chaque tâche.">
  <img src="/assets/mirror/enterprise-auto-mode-9365b7d49c0d.png" alt="Paramètres Agent avec le mode Auto activé et le modèle fixé sur Auto" width="558" height="356" data-path="images/changelog/2026-08-28/enterprise-auto-mode.png" />
</Frame>

Pour en savoir plus, consultez [Contrôles des modèles Enterprise](/fr/ko/features/collaboration/enterprise-model-controls).

<div id="section-4">
  ### Personnaliser les connecteurs
</div>

Les organisations Enterprise peuvent désormais utiliser une configuration OAuth personnalisée pour leurs connecteurs. Par exemple, vous pouvez configurer Gmail avec vos propres **Client ID**, **Client Secret** et **scopes** plutôt qu&#39;avec les valeurs par défaut de Replit.

</Frame>

Découvrez comment [configurer une application OAuth personnalisée pour les connecteurs](/fr/ko/features/integrations/overview#configuring-oauth-app-with-replit).
