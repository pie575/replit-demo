키보드 단축키를 사용하면 설정 가능한 키 조합으로 명령을 실행하고, 텍스트를 수정하고,
Project Editor를 탐색할 수 있습니다. Replit.com 웹 앱에서 키보드 단축키를
설정하고 사용할 수 있습니다.

## 키보드 단축키 확인하기

키보드 단축키 설정을 확인하려면 다음 단계를 따르세요.

1. Replit App을 열어 Project Editor로 이동합니다.
2. 도크의 <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="all tools icon" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**에서 <img class="icon-svg" src="/assets/mirror/settings-icon-c2664c3691bf.svg" alt="gear icon" width="16" height="16" data-path="images/icons/settings-icon.svg" /> **User Settings** 탭을 엽니다.
   또는 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="magnifying glass icon" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 돋보기로 "User Settings"를 검색하세요.
3. **Keyboard shortcuts** 탭을 선택해 명령 목록과 할당된 단축키를 확인하세요.

## 키보드 단축키 커스터마이즈하기

키보드 단축키를 추가하거나 수정하려면 다음 단계를 따르세요.

1. 할당되지 않은 명령 옆의 <img class="icon-svg" src="/assets/mirror/create-app-icon-ba218e87fb67.svg" alt="plus icon" width="16" height="16" data-path="images/icons/create-app-icon.svg" />**Add shortcut**을 선택하거나,
   할당된 명령의 경우 <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="pencil icon" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> 연필 아이콘을 선택하세요.
2. 명령 옆에 "Recording..."이 표시되면 할당하고 싶은 키 조합을 누르세요.
   녹화를 취소하려면 탭 내부의 빈 영역을 클릭하세요.
3. 단축키를 되돌리려면 <img class="icon-svg" src="/assets/mirror/rollback-icon-3197ed1b323b.svg" alt="rollback icon" width="12" height="12" data-path="images/icons/rollback-icon.svg" /> 롤백 아이콘을 선택하세요.

## 키보드 단축키 제거하기

키보드 단축키를 제거하려면 명령 옆의 <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="trash icon" width="16" height="16" data-path="images/icons/trash-icon.svg" /> 휴지통 아이콘을 선택하세요.

## 탭 탐색

브라우저의 **Tab** 키 탐색을 사용해 페이지의 대화형 요소 사이를 이동할 수 있습니다.
하지만 File Editor, Console, Shell 도구는 들여쓰기 등의 용도로 **Tab** 키 입력을
가로챕니다.

이러한 도구에서 계속 페이지 요소를 순회하려면 다음 단계를 따르세요.

1. **Esc**를 눌러 도구에서 포커스를 해제하세요
2. **Tab**을 눌러 다음 요소로 이동하세요
