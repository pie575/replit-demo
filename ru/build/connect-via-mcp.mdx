Replit Agent может подключаться к сотням внешних инструментов и источников данных через [Model Context Protocol (MCP)](https://modelcontextprotocol.io) — открытый стандарт для интеграции ИИ-инструментов. Войдите на один из серверов из списка или добавьте любой пользовательский MCP-сервер, которому доверяете.

<div id="connect-a-pre-listed-mcp-server">
  ## Подключение MCP-сервера из готового списка
</div>

В Replit уже есть подобранный список MCP-серверов для популярных сервисов: Stripe, Linear, Notion, Sentry и других. Для подключения достаточно одного клика по кнопке входа.

<Frame>
  <img src="/assets/mirror/mcp-servers-pane-8e1f431ca33c.png" alt="Панель настроек MCP Servers for Replit Agent со списком готовых серверов: Stripe, Linear, Notion, Sentry, Atlassian, Miro, PostHog, Amplitude, Mixpanel, Granola и Razorpay — у каждого есть кнопка входа" width="3452" height="1988" data-path="images/replitai/mcp-servers-pane.png" />
</Frame>

<Steps>
  <Step title="Откройте панель интеграций">
    Перейдите на [replit.com/integrations](https://replit.com/integrations) и прокрутите до раздела **MCP Servers for Replit Agent**.
  </Step>

  <Step title="Выберите сервер">
    Найдите нужный сервис — Stripe, Linear, Notion, Sentry, Atlassian, Miro, PostHog, Amplitude, Mixpanel, Granola, Razorpay и другие.
  </Step>

  <Step title="Войдите в аккаунт">
    Нажмите **Sign in** рядом с сервером. Вы пройдёте процесс OAuth в этом сервисе. После подключения статус соединения обновится, и Agent сможет использовать инструменты этого сервера.
  </Step>
</Steps>

Полный каталог смотрите в [справочнике по MCP-серверам](/ru/features/mcp/overview).

<div id="add-a-custom-mcp-server">
  ## Добавление пользовательского MCP-сервера
</div>

Если нужного сервера нет в каталоге, добавьте его по URL.

<Frame>
  <img src="/assets/mirror/mcp-connect-dialog-5b8f9b0d828e.png" alt="Диалог подключения MCP-сервера с полем отображаемого имени, полем URL MCP-сервера и разворачиваемым разделом дополнительных настроек" width="3452" height="1988" data-path="images/replitai/mcp-connect-dialog.png" />
</Frame>

<Steps>
  <Step title="Откройте диалог добавления сервера">
    На панели настроек MCP Servers нажмите **+ Add MCP server**.
  </Step>

  <Step title="Укажите отображаемое имя">
    Укажите понятное имя — Agent будет использовать его для ссылки на сервер в журналах чата.
  </Step>

  <Step title="Введите URL сервера">
    Вставьте HTTPS-адрес MCP-сервера. Откройте **Advanced settings**, чтобы добавить пользовательские заголовки (например, `X-API-Key`), если серверу требуется аутентификация.
  </Step>

  <Step title="Проверьте и сохраните">
    Нажмите **Test &amp; save**. Replit попробует подключиться и проведёт вас через процесс OAuth, если он требуется серверу. После сохранения подключение появится в разделе MCP Servers с указанием его статуса.
  </Step>
</Steps>

<Warning>
  Подключайте только MCP-серверы, которым доверяете. Подключённый сервер может предоставлять Agent инструменты и данные — перед добавлением незнакомой конечной точки проверьте её источник.
</Warning>

<div id="use-mcp-tools-in-agent">
  ## Использование MCP-инструментов в Agent
</div>

После подключения сервера Agent автоматически получает список его инструментов и делает их доступными во всех ваших проектах. Чтобы задействовать сервер, просто упомяните его в чате:

> Используй MCP-сервер Notion, чтобы найти самые свежие заметки со встречи.

<Frame>
  <img src="/assets/mirror/tool-call-7a53f51a11ae.png" alt="Agent вызывает инструменты пользовательского MCP-сервера в чате" width="571" height="817" data-path="images/replitai/custom-mcp/tool-call.png" />
</Frame>

Agent сам выбирает подходящие инструменты сервера исходя из вашего запроса. Если инструмент требует подтверждения, перед его запуском вы увидите соответствующий запрос.
