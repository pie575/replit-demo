Vous pouvez gérer les connecteurs pour que votre équipe utilise les intégrations de manière cohérente et sécurisée. Les fonctionnalités disponibles varient selon le forfait.

* **Core et Pro** : la gestion des connecteurs est disponible dans les **espaces de travail collaboratifs**. Les administrateurs de compte configurent et gèrent les connexions de cet espace de travail, que les créateurs peuvent utiliser dans les applications de cet espace de travail.
* **Enterprise** : gestion des connecteurs à l’échelle de l’organisation avec des contrôles avancés, notamment des clients OAuth personnalisés, le contrôle d’accès aux clés API et l’utilisation de vos propres clés.

<div id="section">
  ## Fonctionnalités clés
</div>

* **Gestion centralisée :** les administrateurs configurent un service une seule fois, et les créateurs peuvent ensuite l’utiliser dans toutes les applications de cet espace de travail.
* **Visibilité et audit :** identifiez les applications et les membres qui utilisent chaque service.
* **Consentement et révocation par application :** révoquez ou renouvelez les accès sans modifier le code.

**Enterprise uniquement :**

* **Contrôle d’accès basé sur les rôles :** contrôle d’accès à privilège minimal avec des portées pour les clés API.
* **Utilisez votre propre OAuth :** utilisez des clients OAuth appartenant à l’organisation avec des portées personnalisées.
* **Utilisez votre propre clé OpenAI :** utilisez votre propre clé API OpenAI à la place de celle fournie par défaut par Replit.

<div id="section-2">
  ## Fonctionnement
</div>

<Steps>
  <Step title="L’administrateur configure le service">
    L’administrateur configure le service une seule fois à l’aide des identifiants.
  </Step>

  <Step title="L’administrateur autorise l’accès">
    L’administrateur autorise les groupes à utiliser le connecteur (Enterprise) ou le rend disponible dans un espace de travail collaboratif (Core/Pro).
  </Step>

  <Step title="Les créateurs utilisent le connecteur">
    Les membres demandent à Agent de créer une application dans l’espace de travail ou l’organisation à l’aide de ce service.
  </Step>

  <Step title="L’administrateur surveille l’utilisation">
    L’administrateur peut surveiller quels membres et quelles applications utilisent quels services.
  </Step>
</Steps>

<div id="section-3">
  ## Sécurité et gouvernance
</div>

* Les identifiants et les jetons sont gérés par la plateforme et ne sont pas stockés dans les différentes applications.
* Révocation et rotation centralisées, sans modification du code.
* Enterprise : accès limité par portée, fondé sur le principe du moindre privilège, avec une configuration OAuth personnalisée facultative.

<div id="section-4">
  ## Configuration et gestion
</div>

<div id="section-5">
  ### Activer un nouveau connecteur
</div>

<Steps>
  <Step title="Accéder aux intégrations">
    Depuis un espace de travail collaboratif (Core/Pro) ou la page d’accueil de l’organisation (Enterprise), ouvrez la page **Intégrations**.
  </Step>

  <Step title="Activer un nouveau connecteur">
    Sélectionnez **Enable new connector** en haut à droite.
  </Step>

  <Step title="Sélectionner un service">
    Sélectionnez le service à activer (par exemple : Notion, GitHub, Google, Outlook, Dropbox ou Salesforce).
  </Step>

  <Step title="Configurer le connecteur">
    Activez le connecteur avec les paramètres par défaut. Avec **Enterprise**, vous pouvez également créer un connecteur OAuth personnalisé (par exemple, avec les portées Drive `.../auth/drive.file` et `.../auth/drive.install`).
  </Step>

  <Step title="Envoyer">
    Sélectionnez **Submit**.
  </Step>
</Steps>

<div id="enterprise">
  ### Configuration des accès (Enterprise)
</div>

1. Après avoir activé le connecteur, sélectionnez **Manage**.
2. Accordez l’accès à des groupes spécifiques, si nécessaire.

<div id="section-6">
  ### Modifier les connecteurs
</div>

* Après avoir activé un connecteur, sélectionnez **Manage**.
* Lorsque vous supprimez un connecteur, il est supprimé pour tous les créateurs de cet espace de travail (Core/Pro) ou de cette organisation (Enterprise).
* Dans Enterprise, vous pouvez modifier les portées des connecteurs OAuth personnalisés.

<div id="section-7">
  ## Comparaison des forfaits
</div>

| Fonctionnalité                                 | Core (espace de travail collaboratif)  | Pro (espace de travail collaboratif)  | Enterprise   |
| ---------------------------------------------- | -------------------------------------- | ------------------------------------- | ------------ |
| Activation et gestion des connecteurs          | ✓                                      | ✓                                     | ✓            |
| Portée                                         | espace de travail                      | espace de travail                     | organisation |
| Création de clients OAuth personnalisés        | —                                      | —                                     | ✓            |
| Configuration du contrôle d’accès aux clés API | —                                      | —                                     | ✓            |
| Utilisation de votre propre clé OpenAI         | —                                      | —                                     | ✓            |

<div id="openaienterprise">
  ### Utilisez votre propre clé OpenAI (Enterprise)
</div>

Les clients Enterprise peuvent utiliser un connecteur pour fournir leur propre clé API OpenAI au lieu d’utiliser l’infrastructure par défaut de Replit. Ils peuvent ainsi utiliser leur contrat OpenAI existant et gérer l’utilisation de l’IA depuis leur propre compte.

  ## Prochaines étapes
