您可以管理 connector，确保团队以一致且安全的方式使用集成。可用功能取决于您的套餐：

* **Core 和 Pro**：可在**协作 workspace**中管理 connector。账户管理员可为该 workspace 设置和管理连接；构建者可在该 workspace 内的 App 中使用这些连接。
* **Enterprise**：提供组织范围内的 connector 管理和高级控制功能，包括自定义 OAuth 客户端、API 密钥访问控制和自带密钥。

<div id="key-capabilities">
  ## 核心功能
</div>

* **集中管理**：管理员只需配置一次服务，开发者即可在该 workspace 的所有应用中使用。
* **可见性与审计**：查看哪些应用和成员在使用哪些服务。
* **按应用授权与撤销**：无需改动代码即可撤销或轮换访问权限。

**仅限 Enterprise：**

* **基于角色的访问控制**：为 API 密钥提供范围受限、遵循最小权限原则的访问控制。
* **自带 OAuth**：使用组织自有的 OAuth 客户端，并自定义作用域。
* **自带 OpenAI 密钥**：使用你自己的 OpenAI API 密钥，而非 Replit 的默认密钥。

<div id="how-it-works">
  ## 工作原理
</div>

<Steps>
  <Step title="管理员配置服务">
    管理员使用凭据完成一次服务配置。
  </Step>

  <Step title="管理员批准访问权限">
    管理员批准可使用 connector 的群组 (Enterprise) ，或将其开放给协作 workspace 使用 (Core/Pro) 。
  </Step>

  <Step title="构建者使用 connector">
    成员可在 workspace 或组织内的 App 中向 Agent 提问，使用该服务进行构建。
  </Step>

  <Step title="管理员监控使用情况">
    管理员可以监控哪些成员和 App 正在使用哪些服务。
  </Step>
</Steps>

<div id="security-and-governance">
  ## 安全与治理
</div>

* 凭据和令牌由平台统一管理，不会存储在各个 App 中。
* 集中撤销和轮换密钥，无需修改代码。
* Enterprise：遵循最小权限原则的范围化访问，并可选配自定义 OAuth 配置。

<div id="setup-and-management">
  ## 设置与管理
</div>

<div id="enable-new-connectors">
  ### 启用新的 connector
</div>

<Steps>
  <Step title="前往 Integrations">
    在协作 workspace (Core/Pro) 或组织主页 (Enterprise) 中，打开 **Integrations** 页面。
  </Step>

  <Step title="启用新的 connector">
    在右上角选择 **Enable new connector**。
  </Step>

  <Step title="选择服务">
    选择要启用的服务 (例如 Notion、GitHub、Google、Outlook、Dropbox 或 Salesforce) 。
  </Step>

  <Step title="配置 connector">
    使用默认配置启用 connector。仅 **Enterprise** 支持创建自定义 OAuth connector (例如 Drive 权限范围 `.../auth/drive.file`、`.../auth/drive.install`) 。
  </Step>

  <Step title="提交">
    选择 **Submit**。
  </Step>
</Steps>

<div id="configure-access-enterprise">
  ### 配置访问权限 (Enterprise)
</div>

1. 启用 connector 后，选择 **Manage**。
2. 根据需要向特定群组授予访问权限。

<div id="modify-connectors">
  ### 修改 connector
</div>

* 启用 connector 后，选择 **管理**。
* 删除 connector 会将其从该 workspace (Core/Pro) 或组织 (Enterprise) 的所有构建者中移除。
* 在 Enterprise 中，您可以编辑自定义 OAuth connector 的权限范围。

| 为 API 密钥设置访问控制  | —                    | —                   | ✓          |

<div id="bring-your-own-openai-key-enterprise">
  ### 使用自有 OpenAI 密钥 (Enterprise)
</div>

Enterprise 客户可以通过 Connectors 使用自有的 OpenAI API 密钥，而不使用 Replit 的默认 AI 基础设施。这样你就能沿用现有的 OpenAI 协议，并通过自己的账户管理 AI 用量。
