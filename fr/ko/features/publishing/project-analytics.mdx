Analytique du projet montre comment les utilisateurs découvrent et utilisent les applications web publiées. Ouvrez le panneau **Growth** pour consulter l’évolution du nombre de visiteurs, les sources de trafic et les événements personnalisés.

Replit collecte des indicateurs de trafic de base pour les applications publiées prises en charge. Avec les plans payants, Agent peut ajouter des événements personnalisés et répondre aux questions sur les données analytiques.

<div id="section">
  ## Avant de commencer
</div>

Pour utiliser l’Analytique du projet, vous avez besoin des éléments suivants :

* **Un site web publié.** Analytics prend en charge les [artefacts](/fr/ko/features/projects-and-artifacts/artifacts) de sites web. Il ne collecte pas d’événements pour les applications mobiles ni pour d’autres types d’artefacts.
* **Un déploiement pris en charge.** L’Analytique du projet prend en charge les déploiements [Autoscale](/fr/ko/features/publishing/deployment-types#autoscale), [Reserved VM](/fr/ko/features/publishing/deployment-types#reserved-vm) et [Static](/fr/ko/features/publishing/deployment-types#static).
* **Un plan payant pour les analyses avancées.** Les événements personnalisés et les requêtes analytiques avec Agent sont disponibles avec les plans payants.
* **Activez les analyses lors de votre prochaine publication.** Replit collecte les événements après avoir activé **Activer les analyses** et publié ou republié votre application.

<div id="project-analytics">
  ## Ouvrir l’analytique du projet
</div>

1. Ouvrez le projet dans le Project Editor.
2. Sélectionnez **Outils**.
3. Sous **Replit Cloud**, sélectionnez **Growth**.

<Note>
  Le panneau **Growth** reste verrouillé tant que vous n’avez pas publié votre application. Avant la publication, un message vous invite à accéder à **Publishing**.
</Note>

Les données d’analyse s’affichent lorsque votre application publiée commence à recevoir du trafic. Les graphiques des nouvelles applications peuvent rester vides jusqu’à ce qu’elles reçoivent des visites.

<div id="section-2">
  ## Consulter les analyses de base
</div>

Les analyses de base utilisent les données de trafic IP pour afficher les métriques suivantes.

* **Visiteurs :** nombre approximatif de visiteurs uniques sur la période sélectionnée.
* **Visiteurs au fil du temps (heure)** ou **Visiteurs au fil du temps (jour) :** évolution de l&#39;activité des visiteurs sur la période sélectionnée.
* **Pages principales :** pages qui reçoivent le plus de trafic.
* **Principaux sites référents :** sites web qui génèrent du trafic vers l&#39;application.
* **Principaux pays :** pays approximatifs des visiteurs.
* **Principaux navigateurs :** navigateurs utilisés par les visiteurs.
* **Principaux appareils :** types d&#39;appareils utilisés par les visiteurs.

Utilisez le menu des périodes pour consulter des périodes allant de 6 heures à 30 jours. Le total des visiteurs compare chaque période à la période précédente de même durée.

Si votre application utilise [Replit Auth](/fr/ko/features/auth-and-identity/authentication), le panneau affiche également le nombre d&#39;**utilisateurs connectés uniques** pour la période sélectionnée.

<Note>
  Le nombre de visiteurs est approximatif. Comme il repose sur des données réseau et de navigateur, une
  même personne peut apparaître comme plusieurs visiteurs sur plusieurs appareils ou au cours de
  plusieurs mois civils.
</Note>

<div id="agent">
  ## Ajouter des événements personnalisés avec Agent
</div>

Les événements personnalisés permettent de mesurer les actions importantes effectuées dans votre application, telles que les inscriptions finalisées, les forfaits sélectionnés, les formulaires envoyés et les achats effectués.

<Steps>
  <Step title="Ajouter des indicateurs avec Agent">
    Ouvrez **Growth**. Dans **analyses avancées**, sélectionnez **Ajouter des indicateurs avec
    Agent**. Indiquez à Agent l’action que vous souhaitez mesurer. Agent ajoute
    le suivi des événements aux emplacements pertinents de votre application.
  </Step>

  <Step title="Activer les analyses et publier">
    Ouvrez **Publishing**, puis lancez une nouvelle publication ou republiez votre application. Sous **Modules
    complémentaires suggérés**, activez **Activer les analyses**. Publiez ensuite votre
    application. Replit commence à collecter les vues de page et les événements personnalisés
    à compter de cette publication.
  </Step>
</Steps>

<Tip>
  Vous pouvez également demander directement à Agent de configurer les analyses dans le chat. Chaque fois que votre application ou vos objectifs de mesure changent, demandez
  à Agent d’ajouter ou de mettre à jour des événements.
</Tip>

Replit ajoute un outil de suivi analytique à votre application publiée. Vous n’avez pas besoin d’ajouter vous-même le script de suivi, l’identifiant du site web ou les variables d’environnement d’analyse.

<Warning>
  N’incluez pas d’informations confidentielles, de données personnelles ni de contenu libre saisi par les visiteurs
  dans les noms ou propriétés des événements personnalisés.
</Warning>

<div id="agent-2">
  ## Poser des questions à Agent sur les analyses
</div>

Une fois que votre application a collecté des données, utilisez les options d’**analyses avancées**.

* **Résumer mes analyses** : Agent résume les analyses de votre projet des 7 derniers jours.
* **Suggérer des améliorations du projet** : Agent examine les analyses et recommande des améliorations pour votre projet.

Vous pouvez également poser des questions précises à Agent.

<AiPrompt>
  Comparez le nombre de visiteurs et d’inscriptions finalisées au cours des 7 derniers jours.
  Affichez les tendances quotidiennes et indiquez-moi la page avec le taux de conversion le plus élevé.
</AiPrompt>

Agent peut analyser les pages vues, les sources de trafic, les événements personnalisés, les propriétés des événements et les entonnoirs. Il utilise les données d’analyse de votre projet pour renvoyer des résultats agrégés.
