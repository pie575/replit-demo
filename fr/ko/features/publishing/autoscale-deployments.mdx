Le déploiement Autoscale s’exécute sur des ressources de cloud computing qui évoluent pour gérer efficacement le trafic réseau et la charge de travail de votre application Replit. Lorsque votre application est sollicitée, il ajoute des serveurs pour gérer la charge. Lorsqu’elle est inactive, il réduit le nombre de serveurs jusqu’à zéro afin de réduire les coûts.

Le déploiement Autoscale convient aux cas d’utilisation suivants :

* Applications web dont la charge de travail et le trafic varient, comme les sites e-commerce
* API et services

<div id="section">
  ## Fonctionnalités
</div>

Le déploiement Autoscale comprend les fonctionnalités suivantes.

* **Mise à l&#39;échelle automatique des ressources :** ajuste automatiquement les ressources en fonction du trafic afin d&#39;optimiser les coûts.
* **Domaine personnalisé :** configurez un domaine personnalisé ou utilisez l&#39;URL `<app-name>.replit.app` pour accéder à votre application.
* **Limites configurables :** définissez le nombre maximal d&#39;instances auquel votre application publiée peut s&#39;adapter.
* **Performances de machine flexibles :** choisissez la configuration de processeur et de RAM requise par votre application.
* **Surveillance :** consultez les journaux et surveillez l&#39;état de votre application publiée.

<div id="section-2">
  ## Utilisation
</div>

Vous pouvez accéder au déploiement Autoscale depuis l’outil Publier de l’éditeur de projet.

<Accordion title="Accéder au déploiement Autoscale">
  Dans le **volet d’outils** de gauche :

  1. Sélectionnez <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="icône Tous les outils" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **Tous les outils** pour afficher la liste des outils de l’éditeur de projet.
  2. Sélectionnez <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="icône Publier" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publier**.
  3. Sélectionnez l’option **Autoscale**, puis **Configurer l’application publiée**.

  Dans la **barre de recherche** :

  1. Sélectionnez l’<img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="icône de loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> icône de loupe en haut pour ouvrir l’outil de recherche.
  2. Saisissez « Publier » pour trouver l’outil, puis sélectionnez-le dans les résultats de recherche.
  3. Sélectionnez l’option **Autoscale**, puis **Configurer l’application publiée**.
</Accordion>

<div id="section-3">
  ## Performances de la machine
</div>

Sélectionnez **Modifier** pour consulter et définir les options de performances de la machine. Utilisez le curseur pour choisir la configuration du processeur et de la mémoire vive de chaque instance de serveur de votre application publiée.

Consultez le coût de cette configuration en **unités de calcul** dans la ligne **Total par machine**.
Les unités de calcul sont une mesure des ressources de cloud computing basée sur la configuration de la mémoire et du processeur de la machine.

Pour en savoir plus sur le calcul des coûts en fonction des unités de calcul, consultez [Unités de calcul](/fr/ko/billing/about-usage-based-billing#2-compute-units).

<div id="section-4">
  ## Nombre maximal de machines
</div>

Utilisez le curseur pour définir le nombre maximal de machines. Cette valeur correspond au nombre maximal d&#39;instances de serveur que la fonctionnalité de mise à l&#39;échelle automatique peut allouer lorsqu&#39;elle détecte que votre application est sollicitée.

La ligne inférieure affiche la valeur correspondante en unités de calcul, calculée selon la formule suivante :

`nombre de machines * unités de calcul par machine`
