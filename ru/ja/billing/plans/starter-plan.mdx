<div id="section">
  ## Что входит
</div>

План Starter включает всё необходимое, чтобы начать создавать приложения в Replit. Создавайте приложения и публикуйте свой первый проект — всё бесплатно.

<div id="agent">
  ### Ежедневные кредиты для Agent
</div>

Пользователи плана Starter получают ежедневные кредиты для работы с Agent в рамках месячного лимита. Эти кредиты обновляются каждый день, предоставляя новый дневной лимит для работы с Agent.

<div id="section-2">
  ### Ежемесячные кредиты на облачные сервисы
</div>

Вы также получаете ежемесячные кредиты, которые можно использовать для:

* [Базы данных (продакшен)](/ru/ja/features/data-and-storage/development-and-production)
* [Объектного хранилища](/ru/ja/features/data-and-storage/object-storage)
* [Публикации (Autoscale, Static)](/ru/ja/learn/projects-and-artifacts/replit-deployments)

Эти кредиты сбрасываются каждый месяц.

<div id="lite">
  ### Liteビルド
</div>

Доступ к [Liteビルド](/ru/ja/features/agent/agent-modes) — быстрому и сфокусированному режиму разработки для оперативных правок и точечных изменений с помощью Agent.

<div id="1">
  ### Одно бесплатное опубликованное приложение
</div>

Независимо от того, используете ли вы Lite-сборку или Canvas для дизайна, вам доступно {FreeDeployments} бесплатное опубликованное приложение. Срок действия этой публичной ссылки автоматически истекает через 30 дней.

В опубликованных приложениях отображается значок «Made with Replit» с вашей уникальной реферальной ссылкой. После перехода на платный план вы будете получать реферальные кредиты, когда другие пользователи зарегистрируются по ссылке на значке.

<div id="section-3">
  ## Ограничения
</div>

Для доступа к следующим функциям необходимо перейти на тариф Core:

<div id="section-4">
  ### Полная сборка
</div>

[Полная сборка](/ru/ja/features/agent/overview/) позволяет Agent работать самостоятельно, с большей производительностью и автономностью. Пользователям плана Starter доступна только [Lite-сборка](/ru/ja/features/agent/agent-modes). Для полной сборки необходим план Core или Pro.

<div id="section-5">
  ### Преобразование дизайна в артефакт
</div>

Для преобразования дизайна из Canvas в полноценный артефакт требуется Core. Пользователи плана Starter могут создавать и публиковать дизайны, но для преобразования в артефакт с серверной частью необходимо перейти на другой план. Если вы хотите создать приложение с серверной частью, начните с [Lite Build](/ru/ja/features/agent/agent-modes).

<div id="section-6">
  ### Сторонние коннекторы
</div>

Для использования внешних коннекторов требуется Core. Они включают интеграции с Google, Stripe и другими сторонними API (подробнее [здесь](https://docs.replit.com/features/integrations/overview#connectors)).

<div id="replit-ai">
  ### Интеграции Replit AI
</div>

Для [интеграций Replit AI](/ru/ja/features/integrations/replit-ai-integrations) требуется подписка Core.

<div id="made-with-replit">
  ### Удаление значка «Made with Replit»
</div>

Для удаления значка «Made with Replit» из опубликованного приложения требуется подписка Core. В деплоях пользователей плана Starter этот значок отображается.

<div id="section-7">
  ### Дополнительные опубликованные приложения
</div>

Пользователям плана Starter доступно {FreeDeployments} бесплатных опубликованных приложений. Для публикации дополнительных приложений требуется Core или Pro.

<div id="plan">
  ### Режим Plan
</div>

Для использования режима Plan требуется тариф Core. В режиме Plan вы можете обсуждать идеи с Replit Agent, планировать работу и сотрудничать, не изменяя код или данные приложения.

<div id="section-8">
  ### Все типы артефактов
</div>

Для создания артефактов, помимо веб- и мобильных приложений, требуется Core. Вы можете выбрать один из различных типов, включая визуализации данных, презентации и анимационные видео. Подробнее см. в разделе [Project](/ru/ja/features/projects-and-artifacts/projects).

<div id="core">
  ## Переход на Core
</div>

Нужно больше? Перейдите на Core и получите:

* **Больше хранилища и ежемесячных кредитов**, а также возможность оплаты по мере использования
* **Неограниченное число опубликованных приложений** сверх первого бесплатного
* **Полный цикл разработки** для самостоятельной работы
* **Сторонние коннекторы** для подключения к внешним сервисам
* **Интеграции Replit AI** для использования моделей ИИ без необходимости управлять собственными API-ключами
* **Режим Plan** для планирования задач перед началом разработки
* **Удаление значка Replit** для более профессионального вида
* И многое другое
