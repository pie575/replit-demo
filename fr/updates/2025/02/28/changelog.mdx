<div id="agent-v2">
  ### Agent v2
</div>

<img src="/assets/mirror/agent-web-01b1f9026de7.webp" alt="Agent v2" width="800" height="450" data-path="images/changelog/2025-02-28/agent-web.webp" />

Une nouvelle expérience Agent est désormais accessible à tous les créateurs. Ce nouvel Agent est plus rapide, plus précis et plus performant que la version précédente.

Il fonctionne désormais avec Claude 3.7 Sonnet, le modèle le plus avancé d’Anthropic à ce jour.

Vous pouvez l’essayer en rejoignant le programme Explorer. Consultez les instructions [ici](https://youtu.be/pE_XT2TaXCA).

<div id="deployment-improvements">
  ### Améliorations des déploiements
</div>

Des suggestions d’IA s’affichent désormais lorsque les créateurs sélectionnent un déploiement statique pour des applications dynamiques, améliorant ainsi le comportement d’Agent lors du traitement des demandes de déploiement.

<img src="/assets/mirror/deployments-debugger-will-now---non-static-app-220824-748b5209b50c.png" alt="Améliorations du débogueur de déploiement" width="1604" height="1244" data-path="images/changelog/2025-02-28/deployments-debugger-will-now---non-static-app-220824.png" />

<div id="claude-37-sonnet-release">
  ### Lancement de Claude 3.7 Sonnet
</div>

Le mode Assistant avancé a été mis à jour avec Claude 3.7 Sonnet pour tous les créateurs disposant d’un abonnement payant. Vous bénéficiez ainsi d’une précision et de capacités accrues pour les demandes complexes.

<img src="/assets/mirror/50526c4ea4d114b4cd8268425398dd4ed3c2d736_bc521d9780846c35d990a72459794dd81370515f_twitter-fb2c893cd78a.jpeg" alt="Interface de Claude 3.7" width="1200" height="674" data-path="images/changelog/2025-02-28/50526c4ea4d114b4cd8268425398dd4ed3c2d736_bc521d9780846c35d990a72459794dd81370515f_twitter.jpeg" />

<div id="database-performance-improvement">
  ### Amélioration des performances de la base de données
</div>

Les opérations de base de données sont désormais plus rapides que jamais, l’opération la plus coûteuse passant de 200 ms à moins de 1 ms.

<div id="better-documentation">
  ### Une documentation améliorée
</div>

<img src="/assets/mirror/cleanshot-2025-02-27-at-1042282xpng-220848-e5317a7cfb93.png" alt="Refonte de la documentation" width="3680" height="2382" data-path="images/changelog/2025-02-28/cleanshot-2025-02-27-at-1042282xpng-220848.png" />

La documentation a été repensée pour être plus facile à comprendre et à utiliser, et entièrement compatible avec les LLM.

Elle propose désormais un bouton « Copy Page » qui vous permet de copier la page entière au format Markdown. Vous pouvez également indexer la documentation à l’aide de `llms.txt` et de `llms-full.txt` pour les utiliser avec vos propres LLM.

* [https://docs.replit.com/llms.txt](https://docs.replit.com/llms.txt)
* [https://docs.replit.com/llms-full.txt](https://docs.replit.com/llms-full.txt)
