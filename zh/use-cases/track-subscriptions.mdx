<div id="before-you-start">
  ## 开始之前
</div>

连接 Gmail 和一个 Google 表格 (也可以让 Agent 新建一个) ，并告诉 Agent 需要搜索哪个收件箱或标签。

<div id="prompt-the-agent">
  ## 向 Agent 发出 prompt
</div>

<AiPrompt>
  创建一个 Routine，每周一 9:00 运行。扫描 Gmail 中的订阅和收据邮件，识别定期付款，
  提取商家、金额和计费周期，并生成一份计算每月费用的 Google 表格。
  标记出所有看起来像是被遗忘的试用订阅。
</AiPrompt>

<div id="what-to-expect">
  ## 预期效果
</div>

Agent 会生成一张表格，包含商家、金额、计费周期和每月总额。请抽查其中几行，与原始邮件核对。首次运行时，主题中不含 &quot;subscription&quot; 字样的商家会被遗漏；补上相应标签后重新运行即可。挑选三个你熟悉的商家，打开 Gmail 中的收据，确认金额和计费周期无误后，再采信每月总额。

<AiPrompt>

<div id="troubleshooting">
  ## 疑难排解
</div>

* **表格中缺少你已知的订阅：** 告诉 Agent 使用哪个 Gmail 标签或搜索条件，并把主题中不含 “subscription” 字样的商家也包含进来。抽查几行，与原始邮件逐一核对。
* **金额或计费周期不对：** 收据中往往包含税费、抵扣或其他币种。让 Agent 沿用邮件中的单项金额和计费周期，并标注出属于推断得出的行。
* **同一商家出现两次：** 让 Agent 按商家名称合并、保留最新的收据，然后重新计算每月总额。
