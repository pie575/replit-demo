## プラットフォーム

### Agentユーザー向けオートメーションプレビュー

<Frame>
  <video src="https://cdn.replit.com/sanity/changelog-01-09-2026.mp4" controls />
</Frame>

オートメーションプレビューがすべてのAgentビルダーに提供されました。視覚的な進捗を確認するのに数分待つ代わりに、数秒でオートメーションステップグラフのプレビューを確認できます。

### 無料アカウントのプライベートApps

無料アカウントのビルダーがプライベートAppsを作成できるようになりました。作成できるAppsの数については、無料プランの制限が引き続き適用されます。

### 「Made with Replit」バッジ

<Frame>
  <img src="https://replit.com/badge?caption=Made%20with%20Replit" alt="Made with Replit バッジ" noZoom />
</Frame>

無料の公開アプリには「Made with Replit」バッジが表示されるようになりました。Replit Coreにアップグレードすることでバッジを削除できます。バッジを選択するとReplitの詳細を確認できます。

### ShellのAIコマンド

<Frame>
  <img src="https://mintcdn.com/replit/kUWF7BqlJ2NZzoTt/images/changelog/2026-01-09/screenshot-2026-01-08-at-18-12-51_c5b98b748839.png?fit=max&auto=format&n=kUWF7BqlJ2NZzoTt&q=85&s=9e7072b22a38b8d48022cf41ee0ee07e" alt="replit aiコマンドの出力を表示するShell" width="1244" height="412" data-path="images/changelog/2026-01-09/screenshot-2026-01-08-at-18-12-51_c5b98b748839.png" />

`replit ai`コマンドを使用してShellでLLMと対話できます。これはShellへの直接アクセスとAgentのワークフローの両方で機能します。

### インテグレーションの新しいAIモデル

AIインテグレーションで新たにリリースされたAIモデルがサポートされるようになりました：

| モデル                          | 説明                                                                                  |
| ---------------------------- | ----------------------------------------------------------------------------------- |
| `gpt-5.2`                    | プロフェッショナルな知識作業向けOpenAIの最も高性能なモデル。ARC-AGI-1で90%以上を達成した最初のモデルで、400Kのコンテキストウィンドウを持ちます。 |
| `claude-opus-4.5`            | コーディング、エージェント、コンピューター使用に最適化されたAnthropicのフラッグシップモデル。SWE-bench Verifiedで80.9%を達成。     |
| `gemini-3-flash-preview`     | 1Mトークンコンテキストを持つエージェントワークフロー向けGoogleの高速モデル。Proレベルに近い推論能力を低レイテンシかつ低コストで実現。            |
| `gemini-3-pro-preview`       | 最先端の推論と実世界の知識を持つGoogleの高度なマルチモーダルモデル。                                               |
| `gemini-3-pro-image-preview` | 正確なテキストレンダリングで高品質な画像生成と編集を行うGoogleのNano Banana Proモデル。                              |
