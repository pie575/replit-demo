Il existe trois types de facturation à l&#39;usage pour les publications :

1. Transfert de données sortantes
2. Unités de calcul Autoscale
3. Requêtes

Vous pouvez consulter votre utilisation dans **Paramètres**, sous **Compte** → **Utilisation du compte**. La facturation intervient chaque mois, ou dès que le coût cumulé dépasse vos crédits mensuels. Les utilisateurs Replit Core et Pro disposent d&#39;une limite mensuelle pour ces ressources.

Si vous avez besoin de crédits supplémentaires au-delà de la limite de votre abonnement mensuel, vous pouvez acheter des packs de crédits depuis la page de facturation. Pour en savoir plus sur les packs de crédits, consultez [Gestion des dépenses](/fr/ja/billing/managing-spend).

<div id="section">
  # Publication
</div>

<div id="1">
  ## 1. Transfert de données sortantes pour la publication
</div>

Ce type d’utilisation est facturé à l’octet et soumis à une limite mensuelle pour les utilisateurs de Replit Core et Pro. Seules les données sortantes (egress) sont comptabilisées dans cette limite, et des dépassements sont possibles. À l’inverse, les données entrantes (ingress) sont toujours gratuites.

| Abonnement  | Limite                                                                    |
| ----------- | ------------------------------------------------------------------------- |
| Replit Core | 100 GiB                                                                   |
| Replit Pro  | Consultez la [tarification de Replit Pro](https://www.replit.com/pricing) |

La limite s’applique aux déploiements [statiques](/fr/ja/features/publishing/deployment-types#static), [Autoscale](/fr/ja/features/publishing/deployment-types#autoscale), [sur VM réservées](/fr/ja/features/publishing/deployment-types#reserved-vm) et [planifiés](/fr/ja/features/publishing/deployment-types#scheduled).

Consultez la [page de tarification](https://www.replit.com/pricing) pour connaître les tarifs actuels du transfert de données sortantes.

***

<div id="2">
  ## 2. Unités de calcul
</div>

Les déploiements Autoscale sont facturés en unités de calcul, qui tiennent compte de l’utilisation du processeur et de la RAM au fil du temps.

Les dépassements sont facturés en unités de calcul. La facturation est calculée à l’unité de calcul près. Consultez la [page de tarification](https://www.replit.com/pricing) pour connaître le tarif actuel des unités de calcul.

Voici la répartition de la conversion des secondes de RAM et de processeur des déploiements Autoscale en unités de calcul :

| Ressource               | Unités de calcul |
| ----------------------- | ---------------- |
| 1 seconde de RAM        | 2 unités         |
| 1 seconde de processeur | 18 unités        |

Les déploiements statiques ne consomment pas d’unités de calcul. Ils sont facturés uniquement pour les transferts de données sortants dépassant la [quantité spécifiée](#).

[En savoir plus sur les déploiements Autoscale](/fr/ja/features/publishing/deployment-types#autoscale).

***

<div id="3">
  ## 3. Requêtes
</div>

Les déploiements Autoscale prennent également en compte le nombre de requêtes.

Pour connaître le tarif actuel des requêtes, consultez la [page de tarification](https://www.replit.com/pricing).

<div id="section-2">
  # Bases de données
</div>

Replit facture uniquement l’utilisation des [bases de données de production](/fr/ja/features/data-and-storage/development-and-production) — les bases de données de développement sont toujours gratuites et incluses avec toutes les applications Replit. Pour en savoir plus sur les bases de données de développement, consultez [Bases de données de développement](/fr/ja/features/data-and-storage/sql-database).

Replit PostgreSQL est entièrement géré et sans serveur. Il offre une haute disponibilité sans contrainte et ne nécessite aucune maintenance. La facturation des bases de données de production est basée sur l’utilisation réelle, ce qui peut permettre de réaliser des économies substantielles.

Les bases de données PostgreSQL de production sont facturées selon deux indicateurs d’utilisation :

* **[Temps de calcul](#compute-time)** : quantité de ressources de calcul consommées par heure.
* **[Stockage de données](#data-storage)** : quantité totale de données stockées, y compris les données historiques.

Vous pouvez consulter votre utilisation actuelle des ressources, y compris celle des bases de données de production, dans **Paramètres** → **Compte** → **Utilisation du compte**.

<div id="section-3">
  ## Temps de calcul
</div>

Le temps de calcul dépend du nombre d’heures pendant lesquelles votre base de données reste active au cours de la période de facturation spécifiée. Une base de données est considérée comme active dès qu’elle reçoit une requête, puis pendant les cinq minutes qui suivent la dernière requête. Si elle reste inactive pendant cinq minutes, elle est suspendue.

<div id="section-4">
  ## Stockage de données
</div>

Le stockage de données correspond au volume total de données conservées dans l&#39;ensemble des bases de données de votre compte, mesuré en gibioctets (Gio). Il est calculé sur la base du volume maximal utilisé au cours du mois. Chaque base de données PostgreSQL consomme 33 Mo de stockage, même lorsqu&#39;elle ne contient aucune donnée : il s&#39;agit de l&#39;empreinte de stockage par défaut d&#39;un serveur Postgres.

<Note>La limite de stockage totale de chaque base de données de production est de 10 gibioctets (Gio). Les bases de données de développement incluent 20 Gio de stockage gratuit par application Replit.</Note>

<div id="section-5">
  # Informations complémentaires
</div>

Nous vous informerons en cas de problème avec votre mode de paiement. Si les échecs de paiement persistent, vos applications publiées risquent d’être interrompues. Dans ce cas, [contactez l’assistance](https://replit.com/help) et mettez à jour vos informations de paiement afin de rétablir l’accès au service.
