<div id="agent-2">
  ### Выбор модели по умолчанию для Agent
</div>

Теперь вы можете выбрать модель, которую Agent будет использовать по умолчанию. Сначала выберите режим — Lite, Economy или Power, — а затем конкретную модель, доступную в этом режиме. Режим Lite теперь доступен везде, где можно работать с Agent, включая мобильное приложение. Набор доступных моделей зависит от организации, прав доступа и наличия доступа к Turbo.

<div id="mcp">
  ### Подключение большего числа MCP-серверов
</div>

Подходящие рабочие пространства могут подключаться к Supabase, Statsig и Calendly из каталога предварительно зарегистрированных MCP-серверов. Кроме того, Replit распознаёт официальную конечную точку Braintrust MCP: при её добавлении вручную запускается вход через OAuth на этом сервере.
