      <Accordion title="在哪里可以获得代码层面的帮助？">
        获取代码帮助的最佳方式是使用 [Replit AI](/zh/welcome)。在 Project Editor 中，打开一个新标签页并搜索 **AI**。Replit AI 可以帮助你设置新项目、解答有关代码的问题，并协助你梳理思路。如需进一步帮助，还可以查看我们的 [Community Hub](https://replit.com/community)，获取更多资源。
      </Accordion>

      <Accordion title="使用 Replit 时遇到问题，如何获得帮助？">
        登录 Replit，然后使用页面右上角的 **?** 获取帮助。如需更多支持，请参阅[支持政策文档](/zh/legal-and-security-info/support-policy)。
      </Accordion>

      <Accordion title="在哪里可以获得账单方面的帮助？">
        在联系支持团队之前，请先查看下方 **Settings** 中是否有解决方案。如果仍无法解决问题，请登录并使用页面右上角的 **?** 获取帮助。
      </Accordion>

      <Accordion title="我无法访问 Replit 账户，该怎么办？">
        请发送电子邮件至 `support@replit.com`，并提供你的账户用户名和登录 ID。
      </Accordion>

      <Accordion title="何时会收到 Replit 的回复？">
        Replit 支持服务通常在周一至周五美国东部标准时间 (UTC-5) 上午 9 点至晚上 8 点提供。
      </Accordion>

      <Accordion title="如何恢复 Replit App 中的文件夹？">
        点击 Replit App 右上角的个人资料图标，选择 **CLUI**，然后在出现的搜索框中输入 *restore* 进行搜索。在搜索结果中，你会看到 **restore-folder** 选项，可用于从回收站恢复特定文件夹。

        > 注意：已删除的 Replit Apps 会在删除之日起 **30 天**后被永久删除，无法恢复。
      </Accordion>

      <Accordion title="如何恢复已删除的 Replit App？">
        点击 Replit App 右上角的个人资料图标，选择 **CLUI**，然后在出现的搜索框中输入 *restore* 进行搜索。在搜索结果中，你会看到 **restore-repl** 选项，可用于从回收站恢复特定 Replit App。

        > 注意：已删除的 Replit Apps 会在删除之日起 **30 天**后被永久删除，无法恢复。
      </Accordion>

      <Accordion title="为什么我的 Replit App 无法加载？">
        如果你的 Replit App 无法加载，请尝试以下调试步骤：

        1. 测试你的[互联网连接](https://www.speedtest.net/)。
        2. 尝试使用其他浏览器。
        3. 检查浏览器是否已启用 JavaScript。
        4. 使用 `Cmd+K` (Mac) 或 `Ctrl+K` (Windows) 打开命令面板，搜索并选择 **Restart compute**。

        如果以上步骤均无效，请查看 Replit 的[服务状态](https://status.replit.com)。如果状态显示为 **All systems are go!**，但你的 Replit App 仍然无法加载，请联系 [Replit 支持](https://replit.com/support)。
      </Accordion>

      <Accordion title="如何将大型文件上传到 Replit App？">
        如果文件太大，无法通过标准 GUI 上传，你可以使用 `scp` (安全复制) 通过 [SSH](/zh/features/workspace-tools/ssh) 在本地和远程系统之间安全传输文件。要将文件从本地计算机复制到远程计算机，请使用以下语法：`scp filename username@ip_address:/home/username`

        你也可以使用 scp 复制整个目录。
      </Accordion>

      <Accordion title="如何查看用量额度余额？">
        你可以在 [https://replit.com/~/cli/account/usage-credits-balance](https://replit.com/~/cli/account/usage-credits-balance) 查看当前余额。
      </Accordion>

    <AccordionGroup>
      <Accordion title="我登录不上，该怎么办？">
        1. 请确认你使用的电子邮件地址和密码正确无误。
        2. 若要重置密码，请前往[忘记密码页面](https://replit.com/forgot)。请务必检查垃圾邮件文件夹，查找来自 `notifications@replit.com` 的重置邮件。
        3. 尝试换一个浏览器登录。

        如果以上方法都无效，请[联系支持团队](https://replit.com/support)。
      </Accordion>

      <Accordion title="如果我是用 Google/GitHub/Facebook/Apple 注册的，该如何更改电子邮件地址？">
        更改账户电子邮件地址需要输入密码。如果你是通过 Google 或 GitHub 等第三方身份提供方注册的，需要先创建密码。

        创建密码的步骤：

        1. 打开侧边栏并退出登录。
        2. 返回登录页面，选择[忘记密码](https://replit.com/forgot)，然后输入你的电子邮件地址。
        3. 你会收到一封包含创建新密码链接的邮件。如果没有收到，请检查垃圾邮件文件夹，邮件最长可能需要三十分钟才会送达。
        4. 登录后，打开[设置](https://replit.com/settings)即可更改电子邮件地址。
      </Accordion>

      <Accordion title="如何更改我的用户名？">
        Replit 用户只能更改用户名**一次**。前往 [CLUI](https://replit.com/~/cli/account/change-username?run=1) 并选择 **change-username**。如果该选项不可用，说明你已经更改过了。
      </Accordion>

      <Accordion title="什么是 Explorer 模式？如何启用？">
        Explorer 是指选择抢先体验并测试开发中新功能的 Replit 用户。若要启用 Explorer 模式，请打开[设置](https://replit.com/settings)并打开 Explorer 开关 (通常在 **Account** 或 **User** 下) 。
      </Accordion>
    </AccordionGroup>
