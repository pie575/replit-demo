本参考指南介绍 `replit-object-storage-python` 包中的 `Client` 类，并提供其方法的代码示例。

<div id="client">
  ## 客户端
</div>

`Client` 类用于管理与 Replit App Storage 的交互，并提供操作存储桶中对象的方法。

要从 `replit.object_storage` 包导入该类，请在 Python 代码中添加以下行。

```python theme={null}
from replit.object_storage import Client
```

使用以下代码创建一个可与 Replit App Storage 交互的 `Client` 实例。

```python theme={null}
client = Client()
```

<Tip>
  如果您的应用使用多个存储桶，请为每个存储桶分别创建一个 `Client` 实例。
</Tip>

<div id="__init__">
  ### **init**
</div>

`init` 方法用于初始化 Client 类的实例。

```python theme={null}
def __init__(bucket_id: Optional[str] = None)
```

**参数**:

* `bucket_id` (Optional[str]): 客户端要管理的存储桶 ID。若省略，客户端将使用与 Replit App 或部署关联的默认存储桶。

<div id="copy">
  ### copy
</div>

`copy` 方法可在同一存储桶内复制对象。如果目标位置已存在对象，则会覆盖该对象。

```python theme={null}
def copy(object_name: str, dest_object_name: str) -> None
```

**参数**：

* `object_name` (str) - 源对象的完整路径。
* `dest_object_name` (str) - 目标对象的完整路径。

**引发的异常**：

* `ObjectNotFoundError` - 表示指定路径下不存在源对象。

<div id="delete">
  ### delete
</div>

`delete` 方法会从 App Storage 中永久移除文件。

```python theme={null}
def delete(object_name: str, ignore_not_found: bool = False) -> None
```

**参数**:

* `object_name` (str) - 要删除的对象名称。
* `ignore_not_found` (bool) - 如果为 `True`，则忽略对象不存在时引发的错误。

**引发的异常**:

* `ObjectNotFoundError` - 表示对象不存在。

<div id="download_as_bytes">
  ### download_as_bytes
</div>

`download_as_bytes` 方法以 `bytes` 格式获取文件内容。

```python theme={null}
def download_as_bytes(object_name: str) -> bytes
```

**参数**:

* `object_name` (str) - 要下载的对象名称。

**返回值**:

* `bytes` - 对象内容的原始字节表示。

**引发的异常**:

* `ObjectNotFoundError` - 表示对象不存在。

<div id="download_as_text">
  ### download_as_text
</div>

`download_as_text` 方法会将文件内容以 `str` 格式下载。

```python theme={null}
def download_as_text(object_name: str) -> str
```

**参数**:

* `object_name` (str) - 要获取的源对象名称。

**返回值**:

* str: 以 UTF-8 编码的字符串形式返回对象内容。

**引发的异常**:

* `ObjectNotFoundError` - 表示对象不存在。

<div id="download_to_filename">
  ### download_to_filename
</div>

将对象内容下载到本地磁盘上的文件中。

```python theme={null}
def download_to_filename(object_name: str, dest_filename: str) -> None
```

**参数**:

* `object_name` (str) - 要从 App Storage 获取的源对象名称。
* `dest_filename` (str) - 本地磁盘上的目标文件名。

**引发的异常**:

* `ObjectNotFoundError` - 表示对象不存在。

<div id="exists">
  ### exists
</div>

`exists` 方法用于检查对象是否存在。

```python theme={null}
def exists(object_name: str) -> bool
```

**参数**:

* `object_name` (str) - 要检查是否存在的对象名称。

**返回值**:

* `bool`: 对象存在时为 `True`，否则为 False。

<div id="list">
  ### list
</div>

`list` 方法用于获取存储桶中的对象列表。

```python theme={null}
def list(end_offset: Optional[str] = None,
         match_glob: Optional[str] = None,
         max_results: Optional[int] = None,
         prefix: Optional[str] = None,
         start_offset: Optional[str] = None) -> List[Object]
```

**参数**:

* `end_offset`(Optional[str]) - 筛选名称按字典序位于 `end_offset` 之前的对象。如果指定了 `start_offset`，
  列出的对象名称将介于 `start_offset` (含) 和 `end_offset` (不含) 之间。
* `match_glob` (Optional[str]) - 使用 glob 模式筛选结果。例如，&quot;foo*bar&quot; 可匹配 &quot;footbar&quot;、&quot;foo baz bar&quot; 和 &quot;foobar&quot;。
* `max_results` (Optional[int]) - 响应中返回的最大结果数。
* `prefix` (Optional[str]) - 筛选名称以指定前缀开头的对象。
* `start_offset` (Optional[str]) - 筛选名称按字典序等于或位于 `start_offset` 之后的对象。
  如果设置了 `end_offset`，列出的对象名称将介于 `start_offset` (含) 和 `end_offset` (不含) 之间。

**返回值**:

* `List`(Object)：与指定查询参数匹配的对象列表。

<div id="upload_from_filename">
  ### upload_from_filename
</div>

要将本地磁盘上的源文件上传到 App Storage，请使用 `upload_from_filename()`。

```python theme={null}
def upload_from_filename(dest_object_name: str, src_filename: str) -> None
```

**参数**：

* `dest_object_name`(str) - 上传后文件的名称。
* `src_filename`(str) - 要上传的源文件。

<div id="upload_from_bytes">
  ### upload_from_bytes
</div>

`upload_from_bytes` 方法用于从 `bytes` 数据上传对象。

```python theme={null}
def upload_from_bytes(dest_object_name: str, src_data: bytes) -> None
```

**参数**:

* `dest_object_name`(str) - 要上传的对象名称。
* `src_data`(str) - 要上传的 `bytes` 数据。

<div id="upload_from_text">
  ### upload_from_text
</div>

`upload_from_text` 方法用于从字符串上传对象。

```python theme={null}
def upload_from_text(dest_object_name: str, src_data: Union[bytes, str]) -> None
```

**参数**：

* `dest_object_name`(str) - 要上传的对象名称。
* `src_data`(str) - 要上传的文本数据。

<div id="section">
  ### 异常类型
</div>

* 使用 `Client` 与 Replit App Storage 交互时，任何方法都可能返回以下错误之一。

  * `BucketNotFoundError`：表示配置的存储桶名称与 App Storage 中的任何存储桶都不匹配。

  * `DefaultBucketError`：表示未配置默认存储桶。

  * `ForbiddenError`：表示没有访问该存储桶的足够权限。

  * `TooManyRequestsError`：表示操作因请求过多而受到速率限制。

  * `UnauthorizedError`：表示未获授权访问该操作。
