# Otimizações de Código

> Saiba como controlar se o Agent revisa e simplifica seu próprio código após a construção.

export const YouTubeEmbed = ({videoId, title = "YouTube video", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

As **Otimizações de Código** (anteriormente Nível de Autonomia) são uma configuração ativada/desativada em **Configurações avançadas** dentro do menu suspenso de configurações do Agent. Quando **ativadas**, o Agent revisa seu próprio código e simplifica trabalhos futuros — melhorando a precisão e economizando custos ao evitar erros. Quando **desativadas**, você tem revisão mínima ou nenhuma revisão de código por IA e controle manual máximo. Disponível em [planos pagos](https://replit.com/pricing).

Recomendamos manter as Otimizações de Código **ativadas** para a maioria dos projetos, a fim de obter melhor qualidade de código e menos ciclos de retrabalho onerosos.

## Uso

Acesse as Otimizações de Código pelo menu suspenso de configurações do Agent enquanto trabalha em qualquer projeto. A configuração se aplica à sua conversa atual, afeta como o Agent aborda tarefas subsequentes e está disponível quando você está usando o modo Economy ou Power.

<Accordion title="Como acessar as Otimizações de Código">
  1. Abra seu projeto no Editor de Projetos
  2. Abra o menu suspenso de configurações do Agent na entrada de chat
  3. Expanda as **Configurações avançadas** e localize as **Otimizações de Código**
  4. Ative ou desative conforme sua preferência
</Accordion>

### Quando usar

* **Ativado**: Recomendado para a maioria dos trabalhos. O Agent revisa seu próprio código, detecta erros e pode reduzir o retrabalho. Ligeiramente mais lento por tarefa, mas com melhor qualidade.
* **Desativado**: Use quando quiser a experiência mais rápida e mais controlada manualmente — por exemplo, edições rápidas ou quando prefere revisar cada alteração você mesmo.
