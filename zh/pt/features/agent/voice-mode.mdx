---
title: "Voice Mode"
description: "用语音向 Agent 说出你的 prompt，无需打字。Voice Mode 会把你说的话转写到聊天输入框中，方便你检查后发送。"
---

使用 Voice Mode，直接用语音描述你想构建的内容。点按 Agent 聊天输入框中的麦克风，说出你的 prompt，Replit 会把你的语音转写为可编辑的文本。检查文本、按需修改，然后像发送其他消息一样发送即可。

当打字缓慢或不方便时，Voice Mode 非常有用——尤其是在手机上，口述一段完整的 prompt 通常比用拇指打字更快。

<Note>
  Voice Mode 只是把你的语音转成聊天输入框中的文本，并不会朗读 Agent 的回复——你发送的仍然是文字消息，Agent 也照常在 Chat 中回复。
</Note>

  ## 工作原理
</div>

Voice Mode 会录制你的语音并转写为文字，将结果填入聊天输入框，供你在发送前检查：

1. 打开 Agent，点击聊天输入框中的麦克风。
2. 如果浏览器或设备弹出提示，请允许访问麦克风。
3. 说出你的 prompt。出现波形即表示 Agent 正在录音。
4. 说完后停止录音。停顿一段时间或切换标签页时，录音也会自动停止。
5. 稍等片刻，等待语音转写完成。
6. 检查转写文本，必要时进行修改，然后发送消息。

由于转写内容会以普通文本的形式出现在聊天输入框中，你可以自由地混用语音和键入——先口述 prompt 的一部分，再键入其余内容，或在发送前改掉某个词。

<Tip>
  自然地说就好。Voice Mode 侧重于捕捉你想表达的意思，而不是逐字转写，因此“嗯”“呃”之类的语气词不会出现在结果中。
</Tip>

<div id="onde-voc-pode-usar">
  ## 可以在哪里使用
</div>

Voice Mode 可在 Agent 的聊天输入框中使用：

* 在**项目编辑器**中与 Agent 一起开发 App 时。
* 在主页的 Agent prompt 中**开始创建新 App** 时。

你可以在桌面端网页、移动端网页以及 Replit 移动 App 中使用 Voice Mode。

<div id="bom-saber">
  ## 须知事项
</div>

使用 Voice Mode 时,请留意以下细节:

| 细节    | 预期情况                                                        |
| ----- | ----------------------------------------------------------- |
| 录音时长  | 每次最多可录制 6 分钟,接近上限前会收到提示。                                    |
| 自动停止  | 静音约 30 秒后录音会自动停止;切换标签页或将 App 切换到后台时也会停止。                    |
| 发送前检查 | 转写后的文本会出现在聊天输入框中,你可以在发送前查看和编辑——不会自动发送。                      |
| 麦克风访问 | Voice Mode 需要获得麦克风使用权限。如果无法开始录音,请检查浏览器和设备是否允许 Replit 访问麦克风。 |

<div id="disponibilidade">
  ## 可用性
</div>

所有 Replit 套餐均支持 Voice Mode。在支持音频录制的浏览器和设备上，Agent 聊天输入框中会显示麦克风图标；首次录音时，系统会请求您授予麦克风权限。
