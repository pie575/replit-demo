---

Когда Agent работает, последующее сообщение либо меняет то, над чем он работает в текущем — активном — **ходе**, либо ожидает завершения этого хода.

* **Steer** отправляет сообщение в активный ход. Agent продолжает работу с новым контекстом.
* **Queue** сохраняет сообщение для следующего хода. Agent обработает его после завершения активного хода.

<div id="conversation">
  ## Управление Conversation
</div>

Steer — режим отправки последующих сообщений по умолчанию и в Conversation, и в Project. В обоих случаях его можно изменить на Queue.

<div id="replit">
  ## Выберите способ отправки последующих сообщений в Replit
</div>

Для Conversation и Project можно задать отдельные режимы отправки:

1. Откройте **Settings** &gt; **Personalization**.
2. Разверните раздел **Agent**.
3. Для **Conversation send behavior** и **Project send behavior** выберите **Steer** или **Queue**.

<Frame caption="Настройки режима отправки для Conversation и Project в разделе Agent.">
  <img src="/assets/mirror/agent-follow-ups-settings-98a4c5ca399e.png" alt="Настройки Agent с режимами отправки для Conversation и Project и вариантами Steer и Queue" width="3048" height="1372" data-path="images/replitai/agent-follow-ups-settings.png" />
</Frame>

<Info>
  В режиме Design последующие сообщения всегда отправляются с помощью Steer. Настройки режима отправки для Conversation и Project не применяются в режиме Design.
</Info>

Чтобы отправить одно сообщение в режиме, противоположном выбранному, нажмите `Cmd+Enter` (Mac) или `Ctrl+Enter` (Windows и Linux).

<div id="section">
  ## Работа с сообщениями в Queue
</div>

Когда вы добавляете в очередь последующие сообщения, Message Queue отображается в виде панели над полем ввода чата. Agent последовательно обрабатывает сообщения в Queue после завершения активного хода. После обработки всех сообщений в Queue панель закрывается.

В Queue доступны все параметры сообщений, включая [Visual Editor](/ru/ja/design/visual-editor) и прикрепление файлов.

<Info>
  Agent автоматически обрабатывает сообщения в Queue только при активном подключённом сеансе Project Editor на компьютере или мобильном устройстве.
</Info>

<div id="section-2">
  ### Управление очередью
</div>

Когда открыта панель очереди, вы можете:

* **Steer сейчас**: отправить сообщение из очереди в текущий активный ход.
* **Редактировать сообщение**: изменить сообщение в очереди до того, как Agent его обработает.
* **Удалить сообщение**: удалить ненужное сообщение.
* **Изменить порядок сообщений**: перетаскивать сообщения, чтобы изменить порядок их обработки.
* **Добавить сообщение**: отправить в очередь дополнительные уточнения.

<div id="section-3">
  ## Остановка активного хода
</div>

Нажмите **Остановить** в строке состояния, чтобы прервать текущую работу Replit. Затем вы сможете отправить новое сообщение, не дожидаясь, пока Agent завершит ход или обработает сообщения из очереди.
