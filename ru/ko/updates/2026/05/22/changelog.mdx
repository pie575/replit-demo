<div id="visual-editor">
  ### Элементы управления макетом в Visual Editor
</div>

В Visual Editor теперь есть отдельные элементы управления **макетом**: настраивать flexbox-макеты можно визуально, не прося Agent переписать стили. Выберите контейнер, разверните раздел макета и задайте направление flex, выравнивание и расположение. Укажите отступ между элементами в пикселях или включите переключатель **Space between**, чтобы развести дочерние элементы к противоположным краям.

Панель редактора тоже переработана: теперь она разделена на понятные разделы **Текст**, **Изображение**, **Макет**, **Цвета** и **Границы**, поэтому нужные элементы управления найти проще.

<div id="agent-2">
  ### Настройки Agent в общих проектах остаются вашими
</div>

Настройки Agent — уровень модели, режим планирования, автоматическое слияние и автоматическое утверждение планов — теперь применяются только к вам, а не ко всем участникам проекта. Если коллега переключится на Power Mode в своей работе, ваши настройки от этого больше не изменятся. При отправке следующего сообщения Agent будет использовать выбранные вами настройки — даже в проектах с большим числом соавторов.

Подробнее о [режимах Agent](/ru/ko/features/agent/agent-modes#settings-in-shared-projects).

<div id="agent-power-mode">
  ### Agent предлагает Power Mode, когда работа застопорилась
</div>

Если Agent замечает, что в режиме Economy Mode он раз за разом упирается в одну и ту же проблему, то теперь в следующем сообщении предложит переключиться на Power. Такое предложение появляется при повторяющихся запросах или при коде, который продолжает падать, и показывается не более одного раза на проект. Agent не будет предлагать переключение в сессиях планирования, а также если вы уже упоминали ограничения по бюджету или используете бесплатный тариф.

<div id="section-3">
  ### Упорядоченное выпадающее меню настроек задачи
</div>

Выпадающим меню, которое открывается из заголовка задачи, стало удобнее пользоваться. Название активной задачи или плана теперь находится сверху и переименовывается прямо на месте, настройки автоматизации (автоприменение, автоодобрение) вынесены в отдельный раздел между названием и действиями, а у всплывающего окна фиксированная ширина, поэтому оно не «прыгает» при изменении имени задачи. Отключённые строки автоматизации скрыты, так что в меню отображается только то, что применимо к текущей задаче.

<div id="quiver-ai-browserbase">
  ### Два новых коннектора: Quiver AI и Browserbase
</div>

В каталоге коннекторов появились ещё два сервиса. Чтобы подключить их, откройте панель **Интеграции** и выберите **Добавить новую интеграцию**.

* **Quiver AI**: создавайте SVG-иллюстрации и векторизуйте растровые изображения через управляемый API. Пригодится, когда Agent нужны аккуратные SVG-ресурсы.
* **Browserbase**: запускайте управляемый headless-браузер для fetch, поиска и автоматизации полноценных сессий. Пригодится, когда Agent нужно загрузить настоящую веб-страницу, выполнить JavaScript или взаимодействовать с сайтами, которые блокируют обычные HTTP-запросы.
