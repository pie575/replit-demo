  if (!videoId) {

  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>

    </Frame>;
};

<div id="section-4">
  ### Предпросмотр чекпоинтов
</div>

В среде разработки Replit появился предпросмотр чекпоинтов. Вы можете просматривать App на разных этапах разработки без пересборки или восстановления предыдущих версий.

Эта функция упрощает отслеживание прогресса, сравнение итераций и управление версиями, обеспечивая полное представление о развитии проекта. Ее можно использовать вместе с [рабочим процессом вайб-кодинга](https://learn.replit.com).

<div id="agent">
  ### Попросите Agent добавить базу данных
</div>

Интеграция Agent с панелью базы данных упрощает настройку баз данных. Этот рабочий процесс на базе ИИ помогает реализовать постоянное хранение данных и настроить базу данных без сложного кода конфигурации.

Разработчики могут сосредоточиться на создании основных функций, а Agent возьмёт на себя работу с базой данных. Узнайте больше о [Replit Agent](/ru/core-concepts/agent) и [вариантах баз данных](/ru/ja/learn/projects-and-artifacts/storage-and-databases).

<div id="replit-auth">
  ### Сопоставление Replit Auth по умолчанию
</div>

Автоматическое сопоставление Replit Auth упрощает аутентификацию пользователей в приложении.

Эта функция активируется, когда приложению требуется аутентификация. Она устраняет необходимость в собственной форме регистрации, системе восстановления пароля и настройке входа через социальные сети, упрощая внедрение безопасного управления пользователями.

<div id="section-5">
  ### Полноэкранная аутентификация по электронной почте
</div>

Оптимизированный процесс аутентификации для защищённых действий повышает безопасность аккаунта.

Этот встроенный подход при необходимости предлагает подтвердить адрес электронной почты после входа в систему. Он обеспечивает защиту аккаунта, сохраняя единообразный пользовательский опыт и баланс между безопасностью и удобством.

Это часть нашей постоянной работы по обеспечению [информационной безопасности](/ru/ja/teams/information-security/overview).

<div id="scim">
  ### SCIM для корпоративных клиентов
</div>

Новая интеграция SCIM позволяет корпоративным клиентам напрямую управлять доступом к Replit через своего поставщика удостоверений.

Подключите Okta, Active Directory, Rippling или другую платформу управления идентификацией, чтобы автоматизировать предоставление и отзыв лицензий Replit. Это избавляет от необходимости вручную управлять пользователями и оптимизирует корпоративные рабочие процессы.

Ознакомьтесь с подробной [документацией по SCIM](/ru/ja/teams/identity-and-access-management/scim), чтобы начать работу.

<div id="replit-teams">
  ### Места для зрителей в Replit Teams
</div>

Представляем места для зрителей в Replit Teams. Делитесь App с заинтересованными сторонами, которым нужно лишь просматривать приложения и взаимодействовать с ними, а не редактировать их, — без полной лицензии Teams.

Идеально для руководителей, клиентов и коллег, которые пользуются инструментами, но не создают их. Узнайте, как настраивать места для зрителей и управлять ими [здесь](/ru/ja/teams/identity-and-access-management/viewer-seats).
