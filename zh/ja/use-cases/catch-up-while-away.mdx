</div>

Agent 会生成一份简短的简报，汇总待定的决策、需要回复的线程以及需要确认的会议。它不应罗列所有消息，而应只保留真正需要处理的内容。在实际采取行动之前，请先确认简报覆盖的时间范围和频道。从简报中挑出两条线程，在 Slack 或 Gmail 中打开，核实是否确实需要处理。如果简报中附带了回复草稿，请先给自己发送一封确认效果。

<div id="section-7">
  ## 疑难解答
</div>

* **简报罗列了所有消息：** 请指定重要的 Slack 频道和日历，并要求 Agent 只保留需要你决策或处理的事项，同时告诉它忽略纯通知类频道。
* **缺少休假期间的内容：** 请提供带时区的准确日期，并确认 Gmail、Slack 和日历连接的账户与你休假期间使用的账户一致。
* **草稿不符合你的措辞风格：** 粘贴几条你实际发送过的回复，并要求 Agent 在撰写可能发送的内容之前先贴合这种措辞风格。
