## Replit 앱이란?

Replit 앱은 코드, 데이터, 에셋을 포함하는 클라우드 호스팅 프로젝트입니다.
안전하고 격리된 환경에서 앱을 만들고, 실행하고, 게시할 수 있습니다.

Replit 앱은 프로젝트 편집기의 다음 도구와 통합되어
원활한 개발 경험을 제공합니다:

* **AI 기반 도구**: Agent를 사용하여 코드를 만들고, 디버그하고, 설명하세요.
* **협업**: 실시간으로 같은 앱에서 다른 사람들과 함께 작업하세요.
* **게시**: 클릭 한 번으로 앱을 클라우드에 게시하세요.

## 주요 기능

Replit 앱은 다음과 같은 기능을 제공합니다:

* **설정 불필요:** 설치나 구성 없이 Replit.com에서 바로 앱을 만들거나 코드를 작성하세요.
* **자동 저장:** 프로젝트가 지속적으로 변경 사항을 클라우드에 저장하여 어떤 웹 브라우저에서든 코딩을 재개할 수 있습니다.
* **버전 관리:** 별도의 구성 없이 Replit의 버전 관리 시스템을 통해 변경 사항을 추적하고, 파일 기록을 탐색하고, 파일을 동기화하세요.
* **공개/비공개 공개 여부 제어:** 개인 정보 설정으로 앱을 보고, 실행하거나, 리믹스를 만들 수 있는 사람을 제어하세요.
* **게시:** 복잡한 구성 변경 없이 코드를 클라우드에 게시하세요.
* **맞춤 앱 URL:** 앱의 고유 URL을 얻거나 전문적인 존재감을 위해 커스텀 도메인을 지정하세요.

<Info>
  프로젝트 파일 시스템에 업로드된 파일은 개발 중에만 사용 가능하며
  게시된 앱이나 다른 빌더가 접근할 수 없습니다. 빌더 업로드를 처리하고 파일을 제공하려면 [Object
  Storage](/ko/features/data-and-storage/object-storage)를 사용하고, 앱과 사용자의 데이터를 저장하고
  가져오려면 [Replit
  Database](/ko/features/data-and-storage/sql-database)를 사용하세요.
</Info>

Replit 앱 생성을 간소화하는 프로젝트 편집기 도구에 대해 자세히 알아보려면 [프로젝트 편집기 개요](/ko/learn/projects-and-artifacts/project-editor/)를 참조하세요.

## 작동 방식

Replit 앱을 만들면 Replit이 클라우드에 프로젝트를 위한 개인 공간을 설정합니다.
앱에 기능과 수정 사항을 추가하면 Replit이 변경 사항을 자동으로 저장하여
어떤 웹 브라우저에서든 편집을 재개할 수 있습니다.

Replit은 필요한 모든 구성 요소가 포함된 사전 설정 환경을 제공합니다.
따라서 서버 구성, 데이터베이스 설정, 환경 관리에 대한 걱정 없이
바로 앱 만들기를 시작할 수 있습니다.

Replit은 각 Replit 앱에 작업 중에 앱을 미리 볼 수 있는
고유한 웹 주소를 자동으로 할당합니다. 공유할 준비가 되면
몇 번의 클릭으로 게시하여 24시간 7일 내내 이용 가능하게 만들 수 있습니다.

## 스토리지 개요

Replit은 애플리케이션의 데이터 요구 사항을 충족하기 위해 네 가지 기본 스토리지 유형을 제공합니다. 각 스토리지 유형은 다양한 사용 사례를 지원하며 플랜에 따라 특정 한도가 있습니다.

<Info>
  스토리지 한도에는 설치된 패키지와 종속성을 포함하여 앱이 저장하는 모든 데이터가 포함됩니다.
</Info>
