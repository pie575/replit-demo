⏰ *예상 소요 시간: 15분*

Figma 디자인은 사용자 경험이 어떤 모습이어야 할지를 보여줍니다. Replit Design은 Figma frame을 design frame으로 바꿔 주며, 이를 탐색하고 다듬어 인터랙티브한 앱으로 Build할 수 있습니다.

예제로는 Figma Community의 [Personal Fitness Trainer Template](https://www.figma.com/community/file/1569006333493544411)을 사용합니다.

  <img src="/assets/mirror/figma-import-result-052394025b8d.webp" alt="Replit Design에서 design frame으로 가져온 Personal Fitness Trainer landing page와 Chat 패널에 완료로 표시된 run" width="3440" height="2160" data-path="images/fitstart/turn-mockup-into-app/figma-import-result.webp" />
</Frame>

<div id="before-you-start">
  ## 시작하기 전에
</div>

다음이 필요합니다:

* [Replit 계정](https://replit.com)
* [Figma](https://www.figma.com) 계정 및 import하려는 파일 또는 위의 예제 파일

<div id="import-the-figma-frame">
  ## Figma frame 가져오기
</div>

frame을 Replit Design으로 가져오면 Agent가 실제로 동작하는 design으로 만들어 줍니다.

<Steps>
  <Step title="Figma frame 링크 복사하기">
    직접 만든 Figma 파일을 사용해도 되고, 이 가이드의 예제인 Figma Community의 [Personal Fitness Trainer Template](https://www.figma.com/community/file/1569006333493544411)을 따라 해도 됩니다.

    Figma에서 가져올 frame을 마우스 오른쪽 버튼으로 클릭하고 **Copy/Paste as**를 선택한 다음 **Copy link to selection**을 선택합니다.

    <Frame caption="Figma에서 열린 Personal Fitness Trainer Template과 가져올 Cover frame">
      <img src="/assets/mirror/figma-example-file-65988c40d28d.webp" alt="Figma에서 열린 Personal Fitness Trainer Template으로, 레이어 패널과 캔버스에 Cover frame이 표시된 모습" width="3440" height="2160" data-path="images/fitstart/turn-mockup-into-app/figma-example-file.webp" />
    </Frame>
  </Step>

  <Step title="Replit Design 열기">
    [replit.com/design](https://replit.com/design)으로 이동해 prompt box 아래에 있는 **Import Figma**를 선택합니다.

    <Frame caption="Replit Design 홈의 Import Figma: Figma frame을 가져오면 Agent가 동작하는 design으로 만들어 줍니다.">
      <img src="/assets/mirror/design-import-figma-0a98172e147e.webp" alt="prompt box 아래에서 Import Figma 옵션이 선택된 Replit Design 홈과 Figma frame을 가져오면 Agent가 동작하는 design으로 만들어 준다는 툴팁" width="2293" height="1322" data-path="images/fitstart/turn-mockup-into-app/design-import-figma.webp" />
    </Frame>
  </Step>

  <Step title="URL 붙여넣고 building 시작하기">
    **Import Figma design** 대화 상자에 frame URL을 붙여넣고 **Attach to prompt**를 선택합니다. frame이 prompt에 첨부되며, prompt를 제출하면 building이 시작됩니다.

    <Frame caption="frame URL을 붙여넣어 prompt에 첨부할 준비가 된 Import Figma design 대화 상자">
      <img src="/assets/mirror/design-figma-url-8425e5d8d46d.webp" alt="Replit Design의 Import Figma design 대화 상자에 Figma frame URL이 입력된 필드와 Attach to prompt 버튼" width="2293" height="1440" data-path="images/fitstart/turn-mockup-into-app/design-figma-url.webp" />
    </Frame>
  </Step>
</Steps>

Agent가 frame을 가져와 project 안에 design frame으로 다시 만들어 줍니다.

<Frame caption="Replit Design에 frame으로 가져온 Personal Fitness Trainer landing page">
  <img src="/assets/mirror/figma-import-result-052394025b8d.webp" alt="Replit Design에서 design frame으로 가져온 Personal Fitness Trainer landing page와 chat 패널에서 완료로 표시된 run" width="3440" height="2160" data-path="images/fitstart/turn-mockup-into-app/figma-import-result.webp" />
</Frame>

<div id="make-it-yours">
  ## 나만의 스타일로 바꾸기
</div>

가져온 frame을 선택하고 원하는 대로 다듬어 보세요:

* **[suggestion](/ko/design/explore-suggestions) 따라가기**: import한 frame에는 다크 에디토리얼 변형, pricing 섹션, 모바일 뷰포트 같은 다음 단계 제안이 함께 제공됩니다. 각 제안은 새로운 frame으로 생성되므로 원본은 비교용으로 그대로 남아 있습니다.
* **[Chat으로 다듬기](/ko/design/chat-about-your-design)**: frame 아래의 입력창에 *&quot;hero 사진을 바꿔줘&quot;*, *&quot;call to action을 더 눈에 띄게 해줘&quot;*처럼 원하는 바를 직접 brief로 전달하세요.
