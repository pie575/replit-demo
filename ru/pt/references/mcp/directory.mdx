---
title: "Каталог MCP"
description: "Ознакомьтесь с рекомендуемыми серверами MCP, которые подключают Replit Agent к вашим любимым инструментам и сервисам."
---

В этом каталоге собраны серверы, предоставляющие специализированные инструменты, источники данных или рабочие процессы через Model Context Protocol (MCP). На странице каждого сервера есть краткое описание и бейдж Replit, чтобы вы могли выбрать серверы для подключения к своим проектам.

Это не исчерпывающий список — вы можете [добавить любой удалённый сервер MCP](/ru/pt/features/mcp/overview#add-an-mcp-server) и использовать его с Replit Agent.

<Info>
  Нажмите бейдж **Добавить в Replit**, чтобы установить сервер. Вам будет предложено авторизовать подключение в Редакторе проекта.
</Info>
