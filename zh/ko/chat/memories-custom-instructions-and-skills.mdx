Memories、Custom Instructions 和 Skills 都能帮助 Replit 更好地利用上下文完成工作。请根据相关信息是持续生效的规则、可复用的流程，还是从过往工作中获得的有用上下文，选择合适的选项。

|                         | 维护者             | Replit 使用时机 | 适用场景             |
| ----------------------- | --------------- | ----------- | ---------------- |
| **Custom Instructions** | 用户或团队           | 始终在整个会话期间   | 希望持续一致应用的稳定偏好和规则 |
| **Skills**              | 用户或团队           | 与特定任务相关时    | 可复用的流程、工作流和支持材料  |
| **Memories**            | Replit (由用户监督)  | 相关上下文有用时    | 避免重复过往工作中有用的偏好   |

<div id="section">
  ## 选择合适的工具
</div>

* 对于需要在整个 Workspace 中始终遵循的规则，例如已批准的库或数据处理要求，请使用 **Custom Instructions**。这些内容由你自行编写，Replit 不会对其进行修改。
* 当你需要为特定类型的工作采用可复用的方法时，例如发布准备或设计审核，请使用 **Skill**。稳定的程序性知识应归入 Skills。
* 如果你希望 Replit 保留先前工作中的有用上下文，以免每次都重复相关偏好，请使用 **Memories**。Replit 可以在工作过程中创建 Memories；它们是可供参考的信息，而非可执行的指令。

你的明确请求和 Custom Instructions 的优先级高于 Memories。请在 **设置 → Customization → Memory** 中管理 Memories。个人信息或敏感信息不会被保留，且默认设为私密。是否与协作者共享由你选择，默认关闭。
