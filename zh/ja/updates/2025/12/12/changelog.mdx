<div id="agentmcp">
  ### Agent 支持自定义 MCP 服务器
</div>

Agent 现可连接远程 Model Context Protocol (MCP) 服务器，只需简单设置即可访问新功能和工具。借此，Agent 能够调用外部工具，并从远程系统获取上下文。

使用自定义 MCP 服务器，您可以：

* 连接可从外部工具获取上下文并执行操作的远程服务器
* 通过 MCP 开放标准访问数百种工具和数据源
* 自动加载各服务器提供的工具

合作伙伴可通过发布 MCP 服务器将服务集成到 Agent，无需额外进行集成工作。

<div id="enterpriseplaid">
  ### Enterprise 版 Plaid 连接器
</div>

Enterprise 客户现在可以启用 Plaid 连接器，连接银行账户并构建使用金融科技基础功能的应用。该连接器目前仍在积极开发中，将根据客户反馈持续新增功能和改进。

使用 Plaid 连接器，您可以：

* 将银行账户连接到应用
* 使用金融科技基础功能构建金融功能
* 通过管理控制台集中管理连接器
