<div id="respostas-mais-rpidas-do-agent">
  ### Agent 响应更快
</div>

Agent 在稳定性和性能上的改进，带来了更流畅、更可靠的编码体验。

大多数请求的响应时间显著缩短，让 Agent 用起来更加灵敏、自然。

<div id="lanamento-do-editor-visual">
  ### 可视化编辑器发布
</div>

<Frame>
  <video autoPlay muted loop playsInline src="https://storage.googleapis.com/replit-cdn/sanity/visual-edit-1.mp4" />

全新升级的可视化编辑器现已上线。你可以直观地设计精美布局，编辑器会自动生成对应的代码，让 Web 开发更易上手、更高效。点击[此处](/zh/pt/replitai/visual-editor)了解更多。

<div id="tempo-estendido-de-prvia-do-aplicativo">
  ### 应用预览时间延长
</div>

关闭 workspace 后，应用预览现在会保持运行 10 分钟 (此前仅为 20 秒) 。这让你在多任务处理或分享作品时体验更加流畅，在移动设备上尤其明显——你可以一边测试项目，一边切换到其他应用。

<div id="equipes-e-enterprise">
  ## 团队与 Enterprise
</div>

<div id="transferncias-de-aplicativos-entre-membros-da-equipe">
  ### 团队成员之间的应用转让
</div>

组织成员现在可以将自己的应用转让给组织内的其他成员。该功能解决了协作中的难题，让团队能够随着项目推进和职责调整重新分配应用的归属权。
