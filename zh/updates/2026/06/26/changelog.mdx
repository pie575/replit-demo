<div id="a-new-integrations-experience">
  ### 全新的 集成 体验
</div>

现在，您可以在一处浏览 Replit 可连接的所有服务。重新设计的 集成 页面将 connector、MCP server 和 Git 身份提供方汇集为可点击的卡片，并提供分类筛选功能和徽章，用于标示 Replit 可为您连接的 integration。该目录现已收录超过 450 个 integration，每个 integration 都有专属页面，展示示例使用场景。您可以在 [replit.com/integrations](https://replit.com/integrations) 预览完整目录。

<div id="use-replit-from-slack">
  ### 在 Slack 中使用 Replit
</div>

Replit 现已成为 Slack 的 Slackbot MCP Client 首发合作伙伴。让 Slackbot 使用 Replit 构建应用，它便可直接在 Slack 中创建、更新和展示你的 Replit Apps。Replit Agent 完成工作的同时，你无需离开对话。

  ## Teams 和 Enterprise
</div>

<div id="multiple-workspaces-for-scim-customers">
  ### SCIM 客户可使用多个 workspace
</div>

通过 SCIM 预配成员的 Enterprise 客户现在可以创建多个 workspace。您可以将已同步的群组分配到不同的 workspace，实现更清晰的访问边界、预算控制和团队隔离，同时仍由身份提供方作为唯一事实来源。此功能现已向新的 Enterprise 客户开放注册。

详细了解 [SCIM workspace 访问权限](/zh/teams/identity-and-access-management/scim#managing-workspace-access)。
