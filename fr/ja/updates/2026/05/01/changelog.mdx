<div id="replit-appapp">
  ### Surveiller les applications publiées avec le Monitoring des Replit Apps
</div>

Activez le **Monitoring des Apps** pour une Replit application publiée afin de bénéficier d’une vérification de disponibilité en temps réel, de barres de disponibilité colorées dans la vue **Publishing** et l’onglet **Analytics**, ainsi que de notifications par e-mail lorsque l’App est indisponible. Le Monitoring des Apps est disponible avec tous les forfaits payants et fonctionne avec tous les types de déploiement, à l’exception des déploiements planifiés. Si votre App rencontre un problème, sélectionnez **Enquêter sur les temps d’arrêt récents avec Agent** pour lancer une tâche en arrière-plan qui récupère la période concernée, examine les logs et le code, puis propose une correction.

  ## Agent

<div id="agent-2">
  ### Créer une présentation complète avec Agent
</div>

Décrivez une présentation (pitch deck, aperçu produit, présentation commerciale ou point d’équipe, par exemple) et Agent créera un deck soigné incluant mise en page, texte et visuels. Vous pouvez améliorer les diapositives dans le chat, modifier le texte et la mise en forme dans l’éditeur visuel, présenter depuis votre navigateur, publier le deck via une URL publique ou l’exporter au format PPTX, Google Slides ou PDF.
