<div id="agent">
  ### Visite guidée d’Agent dans l’application mobile et déploiements dans le dock
</div>

L’application mobile propose désormais une visite guidée d’Agent pour aider les nouveaux créateurs à démarrer rapidement. Les déploiements s’affichent également par défaut dans le dock, ce qui facilite la gestion des applications publiées directement depuis un appareil mobile.

<div id="section-3">
  ### Synchronisation des secrets de déploiement avec les secrets de l’espace de travail
</div>

Les déploiements se synchronisent désormais automatiquement avec les secrets de l’espace de travail ! Les variables d’environnement restent ainsi toujours synchronisées, ce qui réduit les redéploiements sources d’erreurs. Vous pouvez toujours remplacer des valeurs individuelles en les « désynchronisant » explicitement si nécessaire.

</div>

<div id="section-6">
  ### Paramètres avancés de confidentialité pour les équipes
</div>

Les équipes Enterprise bénéficient d&#39;un contrôle accru sur les données de leur organisation grâce aux nouveaux paramètres avancés de confidentialité. Elles peuvent restreindre la création d&#39;applications publiques par les membres et l&#39;exportation de code au format ZIP afin de mieux protéger la propriété intellectuelle de l&#39;organisation.
