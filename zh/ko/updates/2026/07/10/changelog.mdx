  ## 平台
</div>

<div id="replit">
  ### 直接在 Replit 内购买域名
</div>

现在，你无需离开 Replit 即可搜索并购买自定义域名。找到可用的域名并完成付款后，Replit 会自动将其绑定到已发布的应用，无需另行注册域名注册商账户。

<div id="section-3">
  ## 集成
</div>

<div id="excalidraw-agent">
  ### 将 Excalidraw 连接到 Agent
</div>

现在你可以连接 Excalidraw，让 Agent 创建和编辑图表与白板。只需在 Connectors 页面登录一次，之后在所有应用中都可以让 Agent 使用 Excalidraw 完成工作，无需复制粘贴任何凭据。

</Frame>

进一步了解[连接器](/zh/ko/features/integrations/overview#available-connectors)。

<div id="section-4">
  ## 工作区
</div>

<div id="agent">
  ### 编辑者可以回答 Agent 的提问
</div>

在共享应用中协作时，现在除应用所有者之外的其他编辑者也可以回答 Agent 提出的日常问题。而连接集成、添加密钥等敏感操作仍然只能由所有者执行。

详细了解[应用访问权限管理](/zh/ko/teams/identity-and-access-management/repl-access-management)。
