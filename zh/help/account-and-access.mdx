以下解答涵盖账户访问与安全相关内容。有关删除账户的详情，请参阅[删除您的数据](/zh/legal-and-security-info/deleting-your-data)；有关封禁的说明，请参阅[违规记分制度常见问题](/zh/legal-and-security-info/strike-system-faq)。

<AccordionGroup>
  <Accordion title="如何重置密码？">
    1. 前往 [replit.com/forgot](https://replit.com/forgot)。
    2. 输入与你账户绑定的邮箱地址。
    3. 打开来自 `notifications@replit.com` 的重置邮件——如果没有收到，请检查垃圾邮件文件夹。
    4. 点击邮件中的链接，设置新密码。

    如果你是通过 Google、GitHub、Facebook 或 Apple 注册的，也可以在同一页面创建独立密码。如果迟迟收不到邮件，请确认输入的邮箱与注册时使用的完全一致。
  </Accordion>

  <Accordion title="我无法登录，如何恢复账户访问权限？">
    按以下顺序尝试：

    1. 前往 [replit.com/forgot](https://replit.com/forgot) 重置密码，并检查垃圾邮件文件夹中是否收到了邮件。
    2. 如果你是通过 Google、GitHub 或 Apple 注册的，请点击**使用 [身份提供方] 继续**按钮，而不要填写邮箱和密码表单。
    3. 确认你使用的是注册时所用的邮箱——你可能用的是另一个邮箱。

    如果以上方法都无效，请[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="我看到了他人的项目，或者我怀疑有人未经授权访问了我的帐户">
    请立即采取以下措施：

    1. 前往 [replit.com/forgot](https://replit.com/forgot) 重置密码。
    2. 在账户安全设置中退出其他活跃会话。
    3. [联系 Replit 支持团队](https://replit.com/support)，并说明你发现的具体情况。

    如果你看到的项目并不属于自己，可能是登录了错误的账户——请查看右上角的账户名称。
  </Accordion>

  <Accordion title="如何更改我的电子邮箱地址或用户名？">
    若要更改用户名，请在 [CLUI](/zh/features/workspace-tools/clui-graphical-cli) 中运行 `account > change-username` 命令并提交新的用户名。用户名仅可更改一次。

    若要更改邮箱，请前往 **设置 → Profile**，然后编辑你的邮箱。如果你无法完成身份验证，请[联系 Replit 支持团队](https://replit.com/support)并提供当前邮箱和新邮箱地址。
  </Accordion>

  <Accordion title="如何永久删除我的 Replit 账户？">
    请先下载你想保留的所有内容——删除后无法恢复。在网页端，先取消所有生效中的订阅，然后前往 **Settings → Profile** 申请删除账户。在移动端，打开 Replit 应用中的 **Account → More → Delete account**。参见[删除你的数据](/zh/legal-and-security-info/deleting-your-data)。
  </Accordion>

  <Accordion title="我好像有两个使用同一电子邮件地址的 Replit 账户——该怎么办？">
    当你用某种方式 (例如邮箱) 注册，之后又用另一种方式 (例如 Google) 登录时，就会产生第二个账户。

    1. 分别用这两种方式登录，确认是否存在两个账户。
    2. 决定保留哪一个。
    3. 将要关闭的账户中的项目转移出来——使用 **Download as zip** 下载，或将其 fork。
    4. 在 **Settings → Profile** 中删除不需要的账户。

    如果你不确定订阅或项目在哪个账户下，请[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="登录后跳转到了与预期不同的帐户">
    你可能有多个账户关联到同一个登录身份提供方。请尝试使用其他方式登录，例如邮箱和密码，或换用另一个身份提供方，以便进入你想要的账户。如果你无法确定哪种登录方式对应哪个账户，请提供你的用户名并[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="我无法再通过 SSH 连接到 workspace.*.repl.co">
    `workspace.*.repl.co` SSH 主机名已停用。请在 project 中打开 [SSH](/zh/features/workspace-tools/ssh) 面板，复制当前的连接命令——该命令使用 `*.replit.dev` 地址。同时更新所有仍引用旧 `repl.co` 地址的脚本或 SSH 配置。
  </Accordion>

  <Accordion title="我的账户为何被暂停？如何申诉？">
    Replit 会封停违反服务条款或社区准则的账户，账单纠纷或拒付也可能触发自动冻结。请先查看你的邮箱 (包括垃圾邮件文件夹) ，其中应有一封说明原因的邮件。

    如果与账单有关，请在 **设置 → 账单** 中结清未付账单。如果你认为封停有误，请[联系 Replit 支持团队](https://replit.com/support)，并提供你的用户名、注册邮箱以及简要说明。另请参阅[记过制度常见问题](/zh/legal-and-security-info/strike-system-faq)和[信任与安全](/zh/legal-and-security-info/trust-and-safety)。
  </Accordion>

  <Accordion title="我无法注册，或者我的 workspace 无法在公司网络下加载">
    即使你的账户一切正常，公司或学校网络也可能屏蔽 Replit。常见现象包括：注册按钮一直转圈、workspace 空白、反复断开连接，或出现 Cloudflare 的 &quot;Attention Required!&quot; 403 页面。这些问题通常是企业安全工具——SSL/TLS 检测设备、重写标头的代理，或信誉较低的共享出口 IP——干扰了 Replit 所依赖的连接。

    首先，确认问题确实出在网络上：

    1. 使用同一浏览器，换一个网络重试，例如个人手机热点。
    2. 尝试无痕或隐私窗口，以及一个没有受管扩展或策略的浏览器。

    如果 Replit 在公司网络之外可以正常使用、在公司网络内却不行，请让 IT 团队将 Replit 加入允许列表。按域名加入允许列表比按 IP 地址更可靠，因为 Replit 的 IP 地址会变化。请他们放行以下域名：

    * `replit.com` 和 `*.replit.com`——主站与静态资源
    * `*.replit.dev`——开发 URL
    * `*.replit.app`——已发布的应用
    * `*.repl.co`——旧版开发 URL
    * `replit-com-static.b-cdn.net`——字体
    * `replitcdn.b-cdn.net`——媒体

    Replit 会在这些域名之间使用持久的 WebSocket 连接、频繁的 API 调用以及身份验证 token 交换，因此也请 IT 团队检查以下各项：

    * **SSL/TLS 检测**——为上述域名添加证书检测豁免。检测代理在处理 Replit 的证书时可能静默失败，导致页面一直卡住且没有任何可见的错误提示。
    * **标头重写**——修改、删除或注入 HTTP 标头的代理规则会破坏跨域 API 与身份验证调用。
    * **WebSocket 流量**——允许指向上述域名的 `wss://` 连接。
    * **浏览器策略**——组策略或 MDM 规则若阻止非允许列表域名保存 Cookie 或使用第三方 Cookie，会导致无法登录。
    * **DNS 解析器**——确认 `replit.com` 和某个 `*.replit.dev` 主机名能够解析，并与 `8.8.8.8` 或 `1.1.1.1` 等公共解析器的结果作对比。分离视图或带过滤功能的解析器有时不会返回开发 URL 的记录。

    如果 IT 团队完成这些调整后，Replit 在公司网络中仍然无法使用，请[联系 Replit 支持团队](https://replit.com/support)，并提供你的用户名以及看到的确切错误信息或 Cloudflare Ray ID。
  </Accordion>

  <Accordion title="连接器（Stripe、GitHub、Resend）无法正常工作，该如何重新连接？">
    Connectors 使用的 OAuth token 可能会过期或被撤销。若要重新连接，请打开 **Tools → Connectors**，断开出现问题的 connector，然后重新连接并再次授权。token 会自动更新到 project 的 [Secrets](/zh/core-concepts/project-editor/app-setup/secrets) 中。

    如果重新连接后仍然失败，请确认你在该第三方服务中的账户处于启用状态并具备相应权限。请参阅[管理 connectors](/zh/replitai/managing-connectors) 和[集成概览](/zh/features/integrations/overview)。
  </Accordion>

  <Accordion title="我可以将我的 Replit 账户转让给他人吗？">
    账户无法直接转移——账户与创建它时使用的凭据绑定。若要移交特定项目，请让新所有者创建一个账户。将项目分享给对方，并请其将项目 fork 到自己的账户中。如需更改当前账户的邮箱，请前往 **设置 → 个人资料**，然后修改邮箱。订阅无法转移——新所有者需要自行订阅。如需移交企业账户，请[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>
</AccordionGroup>
