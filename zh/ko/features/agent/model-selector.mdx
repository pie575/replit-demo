通过模型选择器，您可以让 Replit 自动选择模型，也可以直接选择可用模型。

<div id="section">
  ## 智能模型路由
</div>

智能模型路由会在质量和成本之间取得平衡，为每项任务选择合适的模型。如果产品中显示 **Auto**，则表示 Replit 正在使用智能模型路由。

智能模型路由会考虑所请求任务及其复杂程度。对于范围较小的请求，可能会使用成本更低的模型；复杂任务则可能需要能力更强的模型。任务发生变化时，Replit 也可能会选择其他模型。

<Note>
  Free Mode 始终使用智能模型路由。Free Mode 构建者无法使用模型选择器，也无法直接选择模型。
</Note>

<div id="section-2">
  ## 手动选择模型
</div>

Core 和 Pro 套餐的构建者可以选择 Power Mode 或 Max Mode 下可用的模型。

1. 在提示词输入框中选择 **Agent Mode**。菜单中会显示可用模式 (**Free**、**Power**、**Max**) 。
2. 选择 **Power** 或 **Max**，然后找到 **主模型** 部分。
3. 打开主模型菜单，然后从列表中选择模型。

<Frame caption="模型选择器弹出窗口，包含 Lite、Economy、Power 模式和主模型列表。截图来自 Replit Design；Agent 设置下拉菜单中也会显示相同的控件。">
  <img src="/assets/mirror/model-selector-6826a87089a2.png" alt="显示 Lite、Economy、Power 模式、主模型列表和 Effort 滑块的 Agent 设置弹出窗口" width="1432" height="786" data-path="images/design/replit-design/model-selector.png" />
</Frame>

所选设置会应用于下一条消息，且可随时更改。

<div id="effort">
  ## Effort
</div>

**Effort 不是独立模式，而是针对各模型的控制项。** 您可以设置所选模型在每次回复中投入的推理量，范围从 **Low** 到 **Max**。每个模型都会显示推荐设置，只有在任务需要时才需提高该设置。

<Frame caption="模型列表下方的 Effort 滑块，设置为 Medium。">
  <img src="/assets/mirror/model-selector-effort-bcffb01239a8.png" alt="选择 Claude Fable 5 作为主模型的列表，以及设置为 Medium 的 Effort 滑块，说明为适合日常任务的均衡推理" width="984" height="832" data-path="images/replitai/model-selector-effort.png" />
</Frame>

请参考以下级别说明：

| Effort         | 适用场景                                |
| -------------- | ----------------------------------- |
| **Low**        | 以最少推理实现最快响应。适合速度至关重要的日常明确改动。        |
| **Medium**     | 为日常任务提供均衡的推理。若推荐设置没有特别指示，这是合适的默认选项。 |
| **High**       | 为多步骤功能或不熟悉的领域等较复杂任务提供深度推理。          |
| **Extra High** | 为大规模重构或棘手 bug 等最困难的问题提供更深入的推理。      |
| **Max**        | 提供最高程度的推理深度。仅在追求最佳结果时使用，成本最高且速度最慢。  |

Effort 越高，Agent 的推理就越深入、审慎，并会使用最强大的前沿模型来提升处理最复杂任务的效果。Agent 会选择性地启用这项额外能力——并非每次运行都会如此，而是仅在请求确实困难时才会路由到更强大的模型。

<Tip>
  由于 Agent 只会在最困难的任务中使用最强大的模型，提高 Effort 可能会使最棘手任务的费用最多增加约 2 倍——而对于较简单的任务，费用通常几乎不会增加，甚至完全不增加。处理复杂问题时请提高 Effort，日常改动则保持较低设置。
</Tip>

<div id="section-4">
  ## 模型比较
</div>

**Compare models** 可让你在多个模型中同时运行下一条提示词，直接并排比较结果，无需猜测哪个模型更合适。这是一项 Beta 功能。

要启用此功能，请展开 Agent 模式弹出窗口底部的**高级设置**，然后开启 **Compare models**。

<Note>模型比较仅支持在 Chat 中使用。</Note>

<Frame caption="高级设置下方的 Compare models 开关。">
  <img src="/assets/mirror/compare-models-toggle-05429dc46d64.png" alt="已展开的高级设置，Compare models Beta 开关处于关闭状态，并说明下一条提示词最多可生成 4 个变体" width="1110" height="344" data-path="images/replitai/compare-models-toggle.png" />
</Frame>

开启此开关后，最多可添加 **4 个模型**进行比较。

<Frame caption="已选择四个模型进行比较，发送按钮显示 Compare 4。">
  <img src="/assets/mirror/compare-models-9f5bcecec727.png" alt="已开启 Compare models 的 Agent 模式弹出窗口，显示四个可单独移除的模型槽位（Kimi K3、Claude Fable 5、Claude Opus 5、GPT-5.6 Sol），以及显示 Compare 4 的聊天发送按钮" width="1192" height="1930" data-path="images/replitai/compare-models.png" />
</Frame>

之后，下一条提示词会在每个选定模型中分别运行一次，并各自生成可供比较的变体。

<Note>
  比较中包含的每个模型都会作为独立 Agent 运行并消耗积分，因此运行 Compare 4 的成本与单独运行四次大致相当。
</Note>
