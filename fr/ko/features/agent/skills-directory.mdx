Le répertoire de compétences est un catalogue de compétences prêtes à installer et à utiliser, créées par Replit et ses partenaires. Installez-en une, essayez-la, puis adaptez-la à la façon dont votre équipe travaille.

Pour en savoir plus sur les compétences et sur la façon dont Agent les charge, consultez les [Compétences Agent](/fr/ko/features/agent/skills). Pour savoir comment rendre des compétences disponibles dans tout votre espace de travail, consultez [Agent Customization](/fr/ko/features/agent/agent-customization).

<div id="section">
  ## Installer des compétences
</div>

Vous pouvez ajouter des compétences depuis le répertoire de plusieurs façons :

* **Dans le chat** — Cliquez sur le bouton **+** à côté du champ de saisie, sélectionnez **Utiliser une compétence**, puis choisissez-en une. Cette compétence s’applique uniquement à ce message et rien n’est installé dans votre projet.
* **Dans votre projet** — Ouvrez le **panneau Skills** dans Project Editor, sélectionnez l’onglet **Discover**, recherchez une compétence, puis cliquez sur **Install**. Les compétences installées sont enregistrées dans le répertoire `/.agents/skills` de votre projet et restent disponibles dans plusieurs conversations.
* **Depuis la ligne de commande** — Installez une compétence avec la [CLI skills](https://github.com/vercel-labs/skills) :

  ```bash theme={null}
  npx skills <skill> -a replit
  ```

<Warning>
  Les compétences proposées dans le sélecteur de compétences de Replit ont fait l’objet d’un examen de sécurité. Ce n’est pas le cas des compétences installées depuis des sources externes. Les compétences sont des instructions que suit Agent : examinez donc toujours les compétences externes avant de les installer. Consultez [Compétences Agent](/fr/ko/learn/agent-skills) pour savoir ce qu’il faut vérifier.
</Warning>

<div id="replit">
  ## Compétences Replit
</div>

Replit propose des compétences prédéfinies, disponibles dans le sélecteur **Utiliser une compétence** du chat et dans le sélecteur de point de départ des nouveaux projets. Ces compétences fonctionnent dans tous les projets sans installation. Leurs descriptions s’affichent dès l’ouverture du sélecteur.

| Catégorie              | Compétences                                                                                                   |
| ---------------------- | ------------------------------------------------------------------------------------------------------------- |
| Ventes et marketing    | Ad Creative, AI SDR, SEO Auditor, Programmatic SEO, GEO, Content Machine, Storyboard                          |
| Carrière               | AI Recruiter, Resume Maker, Interview Prep                                                                    |
| Recherche et analyse   | Competitive Analysis, Deep Research, GitHub Solution Finder, Supplier Research                                |
| Entreprise et finance  | Stock Analyzer, Excel Generator, Invoice Generator, Tax Reviewer                                              |
| Documents et outils    | Website Cloner, File Converter, Flashcard Generator, Legal Contract, Infographic Builder, Recreate Screenshot |
| Création               | Photo Editor, Podcast Generator, Podcast Marketing, Branding Generator, Video Editing                         |
| Productivité           | AI Secretary, Product Manager, Design Thinker, Skill Finder, Skill Creator                                    |
| Personnel              | Travel Assistant                                                                                              |
| Sécurité et conformité | Secrets, Sensitive Data, Input Validation, AI Security, Dependency Vetting, License Check                     |
| Qualité et fiabilité   | Accessibility, Responsive UI, Observability, Resilience, Ship Review                                          |

<Note>
  Dans un espace de travail, le sélecteur détecte également les compétences supplémentaires installées dans le répertoire `.local/secondary_skills/` du projet.
</Note>

<div id="section-2">
  ## Compétences de partenaires
</div>

Les partenaires de Replit publient des compétences qui apprennent à Agent à créer avec leurs produits. En en installant une, Agent découvre les modèles et conventions propres à ce service.

| Partenaire       | Ce qu&#39;elle apprend à Agent                               |
| ---------------- | ------------------------------------------------------------ |
| Stripe           | Modèles d&#39;intégration des paiements et de la facturation |
| PayPal           | Modèles d&#39;intégration des paiements                      |
| RevenueCat       | Modèles d&#39;abonnement et de paiements intégrés            |
| Mixpanel         | Mise en œuvre d&#39;analyses et de suivi                     |
| BigQuery         | Modèles de requêtes d&#39;entrepôt de données                |
| Resend           | Intégration d&#39;e-mails transactionnels                    |
| Google Workspace | Intégrations Gmail, Drive, Docs et Calendar                  |
| Atlassian        | Workflows de tickets et de pages Jira et Confluence          |
| Google Maps      | Intégrations de cartes, lieux, itinéraires et géocodage      |

<div id="section-3">
  ## Compétences de la communauté
</div>

En plus des compétences Replit et de partenaires, la communauté propose des compétences installables. Découvrez-les sur [skills.sh](https://skills.sh) et consultez la [spécification des compétences Agent](https://agentskills.io/specification) pour créer vos propres compétences.
