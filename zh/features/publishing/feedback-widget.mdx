反馈组件会在已发布应用的角落添加一个反馈按钮。访客无需离开应用即可反馈问题或提出改进建议，你可以将他们提交的内容直接发送给 Agent 进行修复。

<div id="turn-on-the-feedback-widget">
  ## 开启反馈组件
</div>

1. 在 **Tools** 面板中选择 **Replit Cloud** 下的 **Publishing**，打开发布工具；或在 Project Editor 右上角选择 **Publish**。
2. 在 **Engagement tools** 中开启 **Enable feedback widget**。
3. 选择 **Publish**。该组件即会显示在已发布的应用上。

<div id="position-and-appearance">
  ## 位置与外观
</div>

启用该组件后，会出现两项设置：

* **组件位置**：选择组件显示在应用的哪个角落：左上、右上、左下或右下。默认为右下。
* **外观**：为组件按钮上传自定义图标并设置背景颜色，使其与应用的整体风格保持一致。

<div id="review-and-act-on-feedback">
  ## 查看并处理反馈
</div>

访客提交的内容会汇入你的收件箱。在这里你可以：

* 阅读每条提交内容，了解访客遇到了什么问题。
* 将提交内容发送给 Agent 进行修复。Agent 会把这条反馈作为任务接手，并为你的应用提出修改方案。

<div id="turn-it-off">
  ## 关闭功能
</div>

在 Publishing 工具中关闭 **Enable feedback widget**，然后重新发布。该组件便会从已发布的应用中消失。
