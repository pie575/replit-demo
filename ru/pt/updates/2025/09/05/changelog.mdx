<div id="agent-geral">
  ### Agent Geral
</div>

<Frame>
  <img src="/assets/mirror/general-agent-240ff289e711.png" alt="Иллюстрация Agent Geral" width="1040" height="572" data-path="images/replitai/general-agent.png" />
</Frame>

Replit Agent теперь работает с любой кодовой базой на любом языке или фреймворке, который запускается в NixOS! Раньше Agent был ограничен определёнными шаблонами, а теперь он может помогать с фреймворками для разработчиков, импортом из GitHub и любой пользовательской конфигурацией проекта. Это мощное расширение возможностей открывает полноценную помощь ИИ в написании кода для корпоративных сценариев и опытных пользователей.

Подробнее об Agent Geral читайте [здесь](/ru/pt/core-concepts/agent/general-agent).

<div id="modo-de-plano">
  ### Режим планирования
</div>

<Frame>
  <img src="/assets/mirror/plan-mode-overview-8077807c63b9.png" alt="Интерфейс чата Agent в режиме планирования" width="916" height="362" data-path="images/replitai/plan-mode-overview.png" />
</Frame>

Режим планирования — это новый формат общения с Replit Agent, рассчитанный на вопросы, обсуждение идей и планирование работы. В этом режиме вы можете попросить Agent составить список задач на будущее, а затем запустить длительные задачи в режиме сборки.

Подробнее о режиме планирования читайте [здесь](/ru/pt/core-concepts/agent/plan-mode).

<div id="integrao-com-o-gcp-marketplace">
  ### Интеграция с GCP Marketplace
</div>

Корпоративные клиенты теперь могут приобретать Replit напрямую в Google Cloud Platform Marketplace и оплачивать покупку уже имеющимися кредитами GCP. Это упрощает закупочные процессы и позволяет организациям с выделенным бюджетом на GCP быстрее внедрять Replit в свои процессы разработки.
