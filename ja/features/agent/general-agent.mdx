## General Agent とは？

General Agent は Replit Agent を使用する最も柔軟な方法です。アーティファクトタイプを事前に選択したり、特定のものを構築することにコミットしたりする必要はありません。チャットを始めるだけです — CSV を作成したり、PDF を生成したり、トピックを調査したり、準備ができたらフルアプリを構築したりできます。

主要なコンセプト：

* **事前選択不要**: アーティファクトタイプを選ばずに作業を開始できます
* **あらゆるアウトプット**: ファイル（CSV、PDF、ドキュメント）の生成、リサーチ、アプリの構築
* **コネクター**: BigQuery、Linear、Slack、Notion、Amplitude、Segment、Hex などの外部サービスへの読み書き
* **段階的な拡張**: 軽量なチャットから始めて、自然にフルアプリの構築へとエスカレートできます

## General Agent へのアクセス方法

General Agent にはいくつかの方法でアクセスできます：

1. **Replit ホームページでプロンプトを書く前に「General」を選択**する
2. **既存のプロジェクトを開いて** Agent と直接チャットを始める
3. **任意の[デベロッパーフレームワーク](https://replit.com/templates)を選択**する — すべてのデベロッパーフレームワークには General Agent が自動的に含まれています
4. **GitHub から[インポート](/ja/build/import-from-providers)する** — GitHub からインポートされたプロジェクトには自動的に General Agent が付属します

## General Agent の使い方

### チャットを始めるだけ

プロジェクトを開いてチャットを始めましょう。特定のものを構築することにコミットする必要はありません — Agent は現在のプロジェクトのコンテキスト内で作業し、何でも対応できます。

**プロンプトの例：**

* 「このドキュメントの要点をまとめてください」
* 「収益上位 100 社の CSV を作成してください」
* 「Linear の上位 5 つのチケットは何ですか？」
* 「TypeScript を使った Vue.js プロジェクトをセットアップしてください」

Agent はセッション中に作成されたファイルで作業し、単一ファイルのアウトプットを生成し、推論の一部としてコードを実行できます — すべて何かを構築することを決める前に。

### 外部サービスの接続

ツールを接続して、Agent がデータを直接読み書きできるようにしましょう：

1. プロジェクト設定の**コネクター**に移動します
2. サービスを接続します（BigQuery、Linear、Slack、Notion、Amplitude、Segment、Hex など）
3. Agent にデータの読み書きを依頼します

**コネクターを使ったプロンプトの例：**

* 「Linear のオープンチケットは何ですか？」
* 「#engineering の今日の Slack メッセージを要約してください」
* 「BigQuery から先月の売上データを取得してください」
* 「カレンダーの今後のイベントを表示してください」
* 「オンボーディングバグの新しいチケットを Linear に作成してください」
* 「Slack の #engineering にサマリーを送ってください」

### チャットからフルアプリへ

構築する準備ができたら、そう伝えるだけです。Agent は軽量なチャットからアプリの構築にシームレスに移行します — 最初からやり直したりコンテキストを切り替えたりする必要はありません。

* 「これをウェブアプリにしてください」
* 「このデータを基にアプリを構築してください」
* 「これらのメトリクスのダッシュボードを作成してください」
* 「Rust の CLI ツールをセットアップしてください」

カジュアルに始めることができます — トピックを調査したり、レポートを生成したり、データを探索したりして、適切なタイミングでフルアプリの構築にエスカレートできます。

## 構築できるもの

* **ナレッジワーク**: アプリを構築せずにリサーチ、要約、分析を行います
* **単一ファイルのアウトプット**: CSV、PDF、ドキュメント、データエクスポート、フォーマットされたレポート
* **データアプリケーション**: 接続されたサービスにクエリを実行し、ダッシュボードで結果を可視化します
* **任意のフレームワークや言語**: Angular、Vue、Svelte、Rust、Go、C#、Python tkinter、Godot ゲーム、CLI ツールなど
* **フルスタックアプリ**: 準備ができたら、チャットのコンテキストから完全なアプリケーションを構築します

## 期待できること

General Agent はより多くの力と柔軟性を提供しますが、それには多少のばらつきが伴います：

* **ワンショット設定**: Agent がすべてを一度に設定することもあります
* **反復的なコラボレーション**: 複雑な設定には複数回の改良が必要な場合があります
* **技術的な制限**: 一部の技術は Nix 環境で完全にサポートされていない場合があります

<Note>
  事前設定された環境を持つ標準の Agent とは異なり、General Agent はあなたのリクエストに基づいて独自の環境とコマンドを設定します。デプロイの準備ができたら、公開の設定を依頼する必要がある場合があります。
</Note>

## よくある質問

<Accordion title="Agent は他のプロジェクトを見ることができますか？">
  いいえ。各チャットは単一のプロジェクト内に限定されています。プロジェクト A とプロジェクト B が互いに通信することはできません。
</Accordion>

<Accordion title="なぜ外部ツールにまだアクセスできないのですか？">
  まずコネクターを通じてサービスを接続する必要があります。接続後、Agent はサービスのデータを読み書きできますが、デフォルトではアクセス権がありません。
</Accordion>

<Accordion title="利用可能なコネクターは何ですか？">
  現在サポートされているもの：BigQuery、Linear、Slack、Notion、Amplitude、Segment、Hex など。追加のコネクターが定期的に追加されています。
</Accordion>

<Accordion title="General Agent を使うためにコネクターは必要ですか？">
  いいえ。コネクターはオプションです。外部接続なしでナレッジワーク、ファイル生成、アプリの構築に General Agent を使用できます。
</Accordion>
