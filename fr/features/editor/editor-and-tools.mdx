Le Project Editor offre une gestion de la disposition ainsi que des outils intégrés qui alimentent votre expérience de création d&#39;applications.
Chacune de ces fonctionnalités du Project Editor prend en charge un aspect précis du processus de développement, afin que vous puissiez
vous concentrer sur la création plutôt que sur la configuration.

<div id="customizable-project-editor-layout">
  ## Disposition personnalisable du Project Editor
</div>

Les outils de gestion de la disposition du Project Editor vous permettent de personnaliser les composants de l&#39;environnement de développement.
Il se compose des types d&#39;éléments d&#39;interface suivants :

| Élément      | Description                                                                                       | Fonctionnalités                                                                                                                                                                                    | Cas d&#39;usage                                                                                                                              |
| ------------ | ------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| **Fenêtres** | Onglets de navigateur contenant un ou plusieurs volets                                            | <ul><li>Peuvent être réparties sur plusieurs écrans</li></ul>                                                                                                                                      | <ul><li>Répartir le Project Editor sur plusieurs écrans</li><li> Travailler sur plusieurs projets simultanément</li></ul>                    |
| **Volets**   | Sections d&#39;une fenêtre contenant un ou plusieurs onglets                                      | <ul><li>Prennent en charge la division horizontale et verticale</li><li>Peuvent être redimensionnés et réorganisés</li><li>Peuvent être convertis en volet flottant dans la fenêtre</li></ul>      | <ul><li>Afficher le code et le Preview côte à côte</li><li>Créer des dispositions personnalisées selon les tâches de développement</li></ul> |
| **Onglets**  | Contiennent un seul outil du Project Editor, comme l&#39;éditeur de fichiers, le Preview ou Agent | <ul><li>Peuvent être déplacés d&#39;un volet à l&#39;autre et réordonnés au sein d&#39;un volet</li><li>Permettent de passer d&#39;un fichier ou d&#39;un outil à l&#39;autre en un clic</li></ul> | <ul><li>Ouvrir différents outils ou fichiers au moment voulu</li></ul>                                                                       |

<div id="file-tree">
  ## Arborescence des fichiers
</div>

L&#39;arborescence des fichiers répertorie tous les fichiers et dossiers de votre Replit App.

<Accordion title="Comment accéder à l'arborescence des fichiers">
  Sélectionnez l&#39;icône de dossier <img class="icon-svg" src="/assets/mirror/files-icon-f66bf1b04572.svg" alt="icône de dossier avec des flèches" width="16" height="16" data-path="images/icons/files-icon.svg" /> à gauche pour afficher ou masquer
  l&#39;arborescence des fichiers.
</Accordion>

Vous pouvez effectuer les actions suivantes dans l&#39;arborescence des fichiers :

* Sélectionner un dossier pour afficher son contenu
* Sélectionner un fichier ou le faire glisser dans un volet pour l&#39;ouvrir dans un éditeur de fichiers
* Effectuer des opérations sur les fichiers : dupliquer, renommer, déplacer, télécharger ou supprimer

<div id="run-button">
  ## Bouton Run
</div>

Le bouton **Run** exécute le workflow sélectionné de la Replit App.

<Accordion title="Comment accéder au bouton Run">
  Le bouton **Run** se situe en haut de l&#39;écran du Project Editor. Sélectionnez-le pour lancer le workflow.

  Lorsque votre Replit App est en cours d&#39;exécution, le libellé du bouton devient **Stop**. Sélectionnez-le pour arrêter l&#39;app.
</Accordion>

Pour savoir comment sélectionner, afficher et gérer les workflows, consultez [Workflows](/fr/features/workspace-tools/workflows/).

<div id="options-menu">
  ## Menu Options
</div>

Le menu Options vous permet d&#39;effectuer les types d&#39;actions de disposition suivants :

* **Gestion des fenêtres** : ouvrir le Project Editor de la Replit App dans une nouvelle fenêtre
* **Gestion des volets** : ajouter des volets, déplacer un volet, agrandir un volet et basculer entre les positions flottante et fixe
* **Gestion des onglets** : ouvrir ou sélectionner d&#39;autres onglets, déplacer un onglet vers un autre volet et fermer un onglet

<Accordion title="Comment accéder au menu Options">
  Sélectionnez les <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="icône de points verticaux" height="16" width="16" data-path="images/icons/vertical-dots.svg" /> trois points verticaux
  situés dans le coin supérieur droit de l&#39;onglet actif pour ouvrir le menu Options.
</Accordion>

<div id="resources-panel">
  ## Panneau des ressources
</div>

Le panneau des ressources affiche les ressources de calcul de votre environnement de développement et leur utilisation, notamment la RAM, le processeur et le stockage.
Ces informations vous aident à estimer et à optimiser les besoins de publication de votre Replit App.

<Accordion title="Comment accéder au panneau des ressources">
  1. Sélectionnez l&#39;icône de ressources <img class="icon-svg" src="/assets/mirror/resources-237893692826.svg" alt="icône d'ordinateurs empilés" width="16" height="16" data-path="images/icons/resources.svg" /> située à côté du nom de votre app pour afficher ou masquer le panneau.
  2. Survolez les lignes **Compute** ou **Storage** pour obtenir plus de détails.
</Accordion>
