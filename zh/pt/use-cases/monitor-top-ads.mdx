从 TikTok Ads、Snapchat Ads、Meta Ads 和 Google Ads 获取上周的广告数据。
集中查看广告表现，并根据广告支出、点击率、
获客成本和广告投资回报率找出最佳广告。将表现优异和不佳的广告分类，
以确定哪些广告素材应跨平台扩大投放或暂停。

<div id="soluo-de-problemas">
  ## 故障排除
</div>

* **Google Ads 或 Meta Ads 无法拉取数据：**这两者并非原生连接器。Agent 会要求您提供 API 密钥。请提前准备好，并确认该密钥有权读取您跟踪的广告账户。
* **汇总数据与广告管理平台不一致：**时间范围和时区通常不一致。请让 Agent 使用与各平台相同的时间范围 (通常为上周一至周日) ，并在调整预算前抽查广告支出。
* **表格中缺少某个平台：**请先在 Replit 中连接 TikTok Ads 和 Snapchat Ads。如果原生连接已过期，请重新连接并再次运行该例程。
