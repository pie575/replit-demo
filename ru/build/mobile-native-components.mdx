<div id="why-this-matters">
  ## Почему это важно
</div>

В каждом iPhone уже есть встроенные оповещения, меню «Поделиться», переключатели и меню, и пользователи используют
их во всех своих приложениях. Когда ваше приложение использует те же нативные компоненты, пользователи
уже знают, как они работают, ещё до первого нажатия — именно поэтому оно воспринимается как
настоящее приложение для iPhone.

Ниже приведены примеры промптов для нативных компонентов, которые можно добавить в приложение: оповещений, меню
действий, переключателей и других.

<div id="sf-symbols">
  ## SF Symbols
</div>

<AiPrompt>
  {sfSymbolsPrompt}
</AiPrompt>

SF Symbols — встроенный набор иконок Apple. Символы автоматически подстраиваются под размер,
начертание окружающего текста и тёмный режим, тогда как для пользовательского набора иконок это нужно настраивать вручную.

<Frame caption="SF Symbols для иконок звуковых эффектов и вибрации в Settings.">
  <img src="/assets/mirror/native-sf-46d879d1c2c1.png" alt="Иконки SF Symbols рядом с настройками звуковых эффектов и вибрации" data-path="images/pixelgames/mobile/native-sf.png" width="1516" height="310" data-path="images/pixelgames/mobile/native-sf.png" />

<Note>
  SF Symbols доступны только в iOS. Попросите Agent выбрать подходящий набор иконок для Android: иконки не будут
  попиксельно идентичными на разных платформах — это нормально.
</Note>

<div id="troubleshooting">
  ## Устранение неполадок
</div>

* **Вместо оповещения или меню действий отображается собственное модальное окно:** убедитесь, что Agent использовал нативный API,
  а не похожий на него элемент, отрисованный с помощью JS. Они могут выглядеть одинаково, но работают по-разному.
* **Иконки на Android выглядят неправильно:** для SF Symbols это ожидаемо — они доступны только в iOS. Спросите
  Agent, какой набор иконок он использовал в качестве замены.
* **В меню «Поделиться» нет ожидаемого приложения:** это определяется ОС и
  приложениями, установленными на тестовом устройстве, а не тем, что PixelGames может добавить напрямую.
