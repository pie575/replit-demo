      <Accordion title="在哪里可以获得代码方面的帮助？">
        如需代码方面的帮助，最好的方式是使用 [Replit AI](/zh/pt/build/welcome)。在项目编辑器中，打开新标签页并搜索 **AI**。Replit AI 可以帮助您设置新项目、解答代码相关问题，并协助您梳理思路。如需更多帮助，您还可以访问我们的[社区中心](https://replit.com/community)获取更多资源。
      </Accordion>

      <Accordion title="我在使用 Replit 时遇到困难。如何获得帮助？">
        登录 Replit 后，点击页面右上角的 **?** 获取帮助。如需更多支持，请参阅[支持政策文档](/zh/pt/legal-and-security-info/support-policy)。
      </Accordion>

      <Accordion title="在哪里可以获得账单方面的帮助？">
        联系支持团队前，请先在下方的**设置**中查看是否能找到解决方案。如果问题仍未解决，请登录后点击页面右上角的 **?** 获取帮助。
      </Accordion>

      <Accordion title="我无法访问 Replit 账户，该怎么办？">
        请发送电子邮件至 `support@replit.com`，并提供您的账户用户名和登录 ID。
      </Accordion>

      <Accordion title="何时会收到 Replit 的回复？">
        Replit 支持通常于周一至周五美国东部标准时间 (UTC-5) 9:00 至 20:00 提供服务。
      </Accordion>

      <Accordion title="如何恢复 Replit App 中的文件夹？">
        前往 Replit App 右上角的个人资料图标，选择 **CLUI**，然后在出现的搜索框中输入 *restore* 进行搜索。在搜索结果中，您会看到 **restore-folder** 选项，可用于从回收站恢复指定文件夹。

        > 注意：已删除的 Replit App 会在最初删除日期后的 **30 天**永久删除，且无法恢复。
      </Accordion>

      <Accordion title="如何恢复已删除的 Replit App？">
        前往 Replit App 右上角的个人资料图标，选择 **CLUI**，然后在出现的搜索框中输入 *restore* 进行搜索。在搜索结果中，您会看到 **restore-repl** 选项，可用于从回收站恢复指定的 Replit App。

        > 注意：已删除的 Replit App 会在最初删除日期后的 **30 天**永久删除，且无法恢复。
      </Accordion>

      <Accordion title="为什么我的 Replit App 无法加载？">
        如果您的 Replit App 无法加载，请尝试以下调试步骤：

        1. 测试您的[互联网连接](https://www.speedtest.net/)。
        2. 尝试使用其他浏览器。
        3. 确认您的浏览器已启用 JavaScript。
        4. 在 Shell 中使用 `kill 1` 命令，关闭并重启支撑 Replit App 的 Linux 虚拟机。

        如果以上步骤均无帮助，请查看 Replit 的[服务状态](https://status.replit.com)。如果状态显示为 **All systems are go!**，但您仍无法加载 Replit App，请联系 [Replit 支持](https://replit.com/support)。
      </Accordion>

      <Accordion title="如何将大文件上传到我的 Replit App？">
        如果文件过大，无法通过图形界面进行常规上传，您可以使用 `scp` (安全复制) 通过 [SSH](/zh/pt/features/workspace-tools/ssh) 在本地和远程系统之间安全传输文件。要将文件从本地计算机复制到远程计算机，请使用以下语法：`scp filename username@ip_address:/home/username`

        您也可以使用 scp 复制整个目录。
      </Accordion>

      <Accordion title="如何查看我的使用额度余额？">
        您可以在 [https://replit.com/~/cli/account/usage-credits-balance](https://replit.com/~/cli/account/usage-credits-balance) 查看当前余额。
      </Accordion>

    <AccordionGroup>
      <Accordion title="无法登录，该怎么办？">
        1. 确认您使用的电子邮件地址和密码是否正确。
        2. 如需重置密码，请访问[忘记密码页面](https://replit.com/forgot)。请检查垃圾邮件文件夹，查看由 `notifications@replit.com` 发出的密码重置邮件。
        3. 尝试使用其他浏览器登录。

        如果以上方法均无效，请[联系支持团队](https://replit.com/support)。
      </Accordion>

      <Accordion title="如果我是通过 Google/GitHub/Facebook/Apple 注册的，如何更改电子邮件地址？">
        更改账户电子邮件地址需要密码。如果您通过 Google 或 GitHub 等第三方身份验证提供方注册，需先创建密码。

        创建密码：

        1. 打开侧边栏并退出登录。
        2. 返回登录页面，选择[忘记密码](https://replit.com/forgot)，然后输入您的电子邮件地址。
        3. 您会收到一封包含创建新密码链接的电子邮件。如果没有找到该邮件，请检查垃圾邮件文件夹，并最多等待 30 分钟。
        4. 登录后，打开[设置](https://replit.com/settings)更改您的电子邮件地址。
      </Accordion>

      <Accordion title="如何更改用户名？">
        Replit 用户只能更改用户名**一次**。访问 [CLUI](https://replit.com/~/cli/account/change-username?run=1)，然后选择 **change-username**。如果看不到该选项，说明您已经更改过用户名。
      </Accordion>

      <Accordion title="什么是 Explorer 模式，如何启用？">
        Explorers 是选择抢先查看和测试仍在开发中的新功能的 Replit 用户。要启用 Explorer 模式，请打开[设置](https://replit.com/settings)，然后开启 Explorer 开关 (例如，在**账户**或**用户**中) 。
      </Accordion>
    </AccordionGroup>
