---
title: "工作区地理位置"
description: "选择在哪里托管工作区及其新建项目的开发资源。"
---

工作区地理位置决定了工作区的开发资源托管在哪里。你在创建工作区时进行选择，此后该工作区内的新项目和资源都会使用所选位置。

<Note>
  工作区地理位置与[发布地区](/zh/ja/features/security/geography#publishing-geography)可以不同。发布地区决定了已发布的项目在哪里运行。
</Note>

<div id="section">
  ## 工作区地理位置的作用范围
</div>

工作区将项目、成员、设置、共享资源、集成和账单整合在一起。在每个项目中，你可以使用项目编辑器和 Replit 聊天。开发资源包括应用的开发版本及其开发数据库。

只有 Pro 套餐客户才能选择特定的工作区区域。

Free 和 Core 套餐客户的工作区区域会自动设置，通常会选择离你最近的区域。工作区中新建的项目和资源都将使用该位置。工作区创建后，区域无法更改。

<div id="section-2">
  ## 选择工作区区域
</div>

Pro 套餐客户可以在创建工作区时选择区域。

<Steps>
  <Step>打开 **Create a new workspace** 表单。</Step>

  <Step>
    输入工作区名称，并根据需要输入成员的电子邮件地址。
  </Step>

  <Step>
    展开 **Workspace region**，选择 **North America**、**Europe (EU)**
    或 **Asia**。
  </Step>

  <Step>选择 **Create workspace**。</Step>
</Steps>

<div id="section-3">
  ## 可用区域
</div>

| 区域                           | 可在工作区中选择 |
| :--------------------------- | :------- |
| **North America (北美)&#x20;**&#x20;| 是        |
| **Europe (欧盟)&#x20;**&#x20;       | 是        |
| **Asia (亚洲)&#x20;**&#x20;         | 是        |
| **South America (南美)&#x20;**&#x20;| 否        |
| **Australia (澳大利亚)&#x20;**&#x20;  | 否        |
