Replit에서는 Conversation에서 작업하거나 Project를 만들며 작업하게 됩니다. Conversation은 질문, 탐색, 후속 메시지, Routine을 위한 공간이고, Project는 애플리케이션을 개발하고 슬라이드와 디자인을 제작하는 공간입니다.

[Conversation을 Project로 전환하는 방법을 알아보세요.](/ko/chat/continue-or-create-a-project)

<div id="how-they-differ">
  ## 차이점
</div>

서로 연결되어 있지만, Conversations와 Projects는 서로 다른 목적을 위한 기능입니다. 두 기능의 차이점은 다음과 같습니다.

| 영역           | Conversations           | Projects                                                                                               |
| ------------ | ----------------------- | ------------------------------------------------------------------------------------------------------ |
| 적합한 용도       | 질문, 탐색, Routines        | 앱, slides, dashboard, 여러 artifact 등 심층적인 build 및 design 작업                                             |
| 구조           | 단일 thread               | 여러 artifact를 포함하는 Project workspace                                                                    |
| 백그라운드 작업     | 사용 불가                   | 병렬 실행 가능                                                                                               |
| Routines     | 사용 가능                   | 사용 불가                                                                                                  |
| Integrations | 사용 가능                   | 사용 가능                                                                                                  |
| 생성 가능 항목     | 문서, 이미지, sheet 등의 asset | 문서, 이미지, sheet 등의 asset과 slides, 앱, website 등의 [Artifacts](/ko/features/projects-and-artifacts/artifacts) |
| Publishing   | 게시할 수 없음                | 게시하여 공개할 수 있음                                                                                          |
