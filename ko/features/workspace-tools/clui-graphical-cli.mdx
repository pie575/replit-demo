CLUI(Command Line User Interface)는 메뉴를 일일이 찾아다니지 않고도 다양한 작업을 빠르게 수행할 수 있는 Replit의 인터랙티브 명령 바입니다. 명령줄의 효율성과 그래픽 인터페이스의 편리함을 함께 제공합니다.

<div id="features">
  ## 기능
</div>

CLUI는 Replit의 세 가지 context에서 강력한 명령어 기반 상호작용을 제공합니다:

* **설정 관리**: 설정을 관리하고, 경고를 확인하며, 삭제된 Replit Apps를 복원합니다
* **빠른 탐색**: Replit Apps 간을 이동하고 Shortcuts로 자주 사용하는 기능에 빠르게 접근합니다
* **workspace 작업**: 개발 환경 내에서 파일을 찾고, 코드를 검색하고, 도구를 사용합니다

<div id="usage">
  ## 사용량
</div>

<div id="account-clui">
  ### Account CLUI
</div>

Account CLUI에서는 Settings, Teams, 삭제된 Replit Apps를 관리할 수 있습니다.

**접근 방법**: [CLUI 페이지](https://replit.com/~/cli)로 이동한 뒤 입력창에 명령어를 입력해 검색하고 Enter 키를 눌러 실행합니다.

<Accordion title="Account 명령어">
  `account`를 입력해 설정을 관리합니다:

  * **view-warns**: 받은 경고 확인
  * **change-username**: 사용자 이름 변경(한 번만 가능)
</Accordion>

<Accordion title="Trash 명령어">
  `trash`를 입력해 삭제된 Replit Apps를 관리합니다:

  * **restore &lt;title&gt;**: 제목으로 삭제된 Replit App 복원(같은 이름이 여러 개인 경우 가장 최근에 삭제된 항목을 복원)
  * **view**: 가장 최근에 삭제된 Replit Apps 확인
</Accordion>

<Accordion title="Team 명령어">
  `team`을 입력해 팀을 관리합니다:

  * **view**: 사용자 이름으로 소속된 팀의 Members 확인
  * **fork-repl-to-project**: 기존 Replit App을 fork하여 Team Project 생성
</Accordion>

<Accordion title="Clear 명령어">
  `clear`를 입력하면 지금까지 실행한 명령어가 화면에서 모두 지워집니다
</Accordion>

<div id="shortcuts-clui">
  ### Shortcuts CLUI
</div>

Shortcuts CLUI를 사용하면 어느 페이지에서든 자주 쓰는 Replit 기능에 빠르게 접근할 수 있습니다.

<Frame>
  <img src="/assets/mirror/shortcuts-clui-768d49b44785.png" alt="Shortcuts CLUI" width="689" height="291" data-path="images/getting-started/shortcuts-clui.png" />
</Frame>

**접근 방법**: **CMD/CTRL + K**를 누르거나, 대부분의 Replit 페이지 상단 내비게이션 바에 있는 검색 아이콘을 클릭하세요.

<Accordion title="사용 가능한 명령어">
  * **Search**: Replit에서 Replit Apps, Templates, Code, People 등을 검색합니다
  * **New**: 새 Replit App을 생성합니다
  * **My Replit Apps**: 내 Replit Apps를 둘러보고 원하는 앱으로 이동합니다
  * **My Code**: 내 모든 Replit Apps의 코드를 검색합니다
</Accordion>

<div id="workspace-clui">
  ### Workspace CLUI
</div>

Workspace CLUI를 사용하면 Replit App에서 작업하는 동안 각종 작업을 수행하고, 도구에 접근하고, 파일을 찾고, 코드를 검색할 수 있습니다.

<Frame>
  <img src="/assets/mirror/ws-clui-81764b3d111b.png" alt="Workspace CLUI" width="429" height="202" data-path="images/getting-started/ws-clui.png" />
</Frame>

**사용 방법**: Workspace에서 **CMD/CTRL + K**를 누르거나 왼쪽 위 모서리의 검색 아이콘을 클릭하세요.

<Accordion title="주요 작업">
  * **파일 찾기**: project 내 파일을 빠르게 찾습니다
  * **코드 검색**: 여러 파일에서 특정 코드 조각을 찾습니다
  * **도구 접근**: Workspace에서 사용할 수 있는 모든 도구나 패널을 엽니다
  * **명령어 실행**: workspace 전용 명령어을 실행합니다
</Accordion>
