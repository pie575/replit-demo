Публикация (Publishing) позволяет поделиться вашим приложением Replit со всем миром — это простой и понятный процесс.

<Note>
  Действие, которое делает приложение доступным в сети, называется «Публикация» (Publishing). На этой странице описаны доступные типы развёртываний.
</Note>

<div id="section">
  ## Что такое публикация?
</div>

Публикация сохраняет **снимок** приложения Replit в облаке, чтобы с ним могли взаимодействовать любые пользователи. Снимок фиксирует текущее состояние файлов приложения Replit.

При публикации приложения Replit создается **опубликованное приложение**. Это экземпляр приложения, работающий в облачной инфраструктуре Replit. Благодаря этому приложение будет надежно доступно в интернете независимо от версии в Project Editor.

<Info>
  Инфраструктура Replit работает на базе Google Cloud Platform (GCP). Все
  опубликованные приложения размещаются в США. Корпоративные клиенты могут
  обратиться в отдел продаж, чтобы разместить опубликованные приложения в ЕС.

  Для индивидуальных, организационных и корпоративных клиентов предоставляется выделенный однопользовательский проект GCP для
  опубликованных приложений. Это означает, что вычислительные ресурсы, секреты и хранилище опубликованных приложений полностью изолированы и никогда не используются совместно с приложениями других клиентов.
</Info>

Доступны инструменты для отслеживания статуса опубликованных приложений и просмотра веб-аналитики.

Replit предлагает следующие типы развёртывания:

<div id="section-2">
  ## Начало работы
</div>

Чтобы опубликовать приложение Replit, выполните следующие шаги:

1. В Project Editor выберите вверху <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Значок публикации" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Опубликовать**.
2. На вкладке **Опубликовать** выберите вариант публикации.
3. Если появится запрос **Добавить способ оплаты**, следуйте подсказкам и добавьте способ оплаты.

Replit автоматически подбирает оптимальный вариант публикации для вашего приложения с учётом типа проекта и его требований.

Если же вы хотите выбрать другой тип развёртывания, примите во внимание следующую информацию.

<div id="section-4">
  ## Основные возможности
</div>

Публикация предлагает следующие удобные возможности:

* **Несколько вариантов публикации**: выберите или измените подходящий тип развёртывания за пару кликов.
* **Пользовательский домен**: размещайте приложение на собственном веб-домене.
* **Аналитика**: отслеживайте данные о посетителях и другие метрики опубликованного приложения.
* **Инструменты мониторинга**: просматривайте статус и настройки опубликованного приложения.
* **Контроль доступа**: одним кликом задавайте, кому доступно приложение. Только для участников с планами **Pro** и **Enterprise**.
* **Настройка бейджа**: пользователи Core могут управлять бейджем «Made with Replit» в настройках публикации. Если приложение было опубликовано с бейджем на плане Starter, после перехода на другой план удаление бейджа может занять несколько минут.
* **Сбор отзывов**: включите отзывы в опубликованном приложении, чтобы собирать мнения пользователей.

<div id="section-5">
  ## Как это работает
</div>

Когда вы публикуете приложение Replit, Replit создаёт снимок файлов приложения и его зависимостей.
Этот снимок отправляется в облачную инфраструктуру Replit и запускается там как отдельный экземпляр приложения. Чтобы опубликованное приложение получило последние изменения, опубликуйте его ещё раз — будет создан новый снимок.

<Warning>
  Не сохраняйте данные в файловой системе опубликованного приложения и не полагайтесь на неё.
  Для хранения данных используйте предназначенные для этого решения — Storage и Database в Replit ([Хранилище и базы данных](/ru/ja/learn/projects-and-artifacts/storage-and-databases)).
</Warning>

<div id="section-6">
  ## Сценарии использования
</div>

Ниже приведены примеры приложений разных типов, которые уже опубликованы.

<div id="section-7">
  ### Автомасштабируемое развёртывание: приложение для измерения скорости печати
</div>

Когда пользователи проходят тест на скорость печати, облако наращивает ресурсы, а в периоды простоя — сокращает их.

<div id="section-8">
  ### Статическое развёртывание: симуляция Солнечной системы
</div>

Изучайте планеты с помощью веб-приложения для визуализации Солнечной системы.
Визуализация отрисовывается в браузере и не передаёт пользовательский ввод на сервер.

<div id="vmdiscord">
  ### Развёртывание на зарезервированной ВМ: Discord-бот
</div>

Запустите Discord-бота, который помогает модерировать участников и знакомить новичков с сервером.
Бот всегда онлайн, общается с пользователями и отвечает на команды — при предсказуемых затратах и производительности.

<div id="section-9">
  ### Запланированное развёртывание: триггеры домашней автоматизации
</div>

Планируйте API-вызовы, которые включают и выключают устройства умного дома в заданное время и в нужные дни недели.
