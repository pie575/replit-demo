Custom Instructions — это постоянные указания, которые вы или ваша команда один раз задаёте для Workspace. Replit использует их во всех Projects и сессиях этого Workspace, поэтому вам не нужно повторять одни и те же соглашения в каждом диалоге.

Используйте Custom Instructions для небольшого набора неизменно актуальных указаний, например по утверждённым библиотекам, требованиям безопасности или правилам обработки данных. Формулируйте их кратко и конкретно, чтобы оставить место для текущей задачи.

<div id="escolha-o-tipo-certo-de-orientao">
  ## Выберите подходящий тип инструкций
</div>

* Используйте **Custom Instructions** для инструкций, которые действуют во всём Workspace и применяются всегда.
* Используйте [Skills](/ru/pt/chat/agent-skills) для повторно используемых подходов и вспомогательных материалов, актуальных только для конкретных задач.
* Используйте [Memories](/ru/pt/chat/memories) для полезного контекста, который Replit сохраняет из предыдущей работы.

<div id="configure-as-custom-instructions">
  ## Настройка Custom Instructions
</div>

Управляйте Custom Instructions в **Workspace Settings → Customization**. В подробном руководстве описаны настройка, доступность, разрешения и рекомендации по поддержанию актуальности инструкций.
