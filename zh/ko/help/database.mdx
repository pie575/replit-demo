<AccordionGroup>
  <Accordion title="数据库端点已被禁用——如何解决“endpoint has been disabled”错误？">
    此错误表示数据库计算端点已暂停。要恢复运行：

    1. 打开 **数据库** 面板，然后从下拉菜单中选择 **开发**。
    2. 出现 **取消暂停数据库** 按钮后，点击该按钮。
    3. 将下拉菜单切换为 **生产**，出现 **取消暂停数据库** 后再次点击该按钮。

    如果未出现该按钮，可能是冲突的 `DATABASE_URL` Secrets 将其隐藏了。打开 **Secrets** 面板，将 `DATABASE_URL` 条目与 **数据库** 面板中的连接字符串进行比较，然后更新或删除冲突的 Secrets，使两者保持一致。

    常见原因包括未支付的账单 (请及时付款以避免再次发生) ，或发布期间的临时暂停 (可通过上述恢复步骤解决) 。请参阅[生产数据库](/zh/ko/features/data-and-storage/development-and-production)。
  </Accordion>

  <Accordion title="状态页面显示生产数据库故障——我需要提交工单吗？">
    不需要。如果 [status.replit.com](https://status.replit.com) 已列出该故障，团队正在处理中，提交工单也不会加快修复进度。请打开当前事件并订阅更新，以接收进度通知。

    如果状态页面未列出数据库问题，请[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="如何恢复已删除的数据库表？">
    Replit 支持将生产数据库恢复到特定时间点。可恢复的时间范围因套餐而异：[Core](/zh/ko/billing/plans/replit-core) 为 7 天，[Pro](/zh/ko/billing/plans/replit-pro) 为 28 天。

    如需恢复，请打开 **Database** 窗口，前往相应数据库，打开恢复设置，选择所需的时间戳并确认。如果已超出可恢复的时间范围，请[联系 Replit 支持团队](https://replit.com/support)。请参阅[生产数据库](/zh/ko/features/data-and-storage/development-and-production)。
  </Accordion>

  <Accordion title="数据库处于冻结状态，且未显示 Unpause 按钮">
    冲突的数据库 URL 通常会导致 **Unpause** 按钮被隐藏。打开 **Secrets** 窗口，找到 `DATABASE_URL` 条目，并将其与 **Database** 窗口中的连接字符串进行比较。如果两者不一致，说明该密钥覆盖了正确的 URL——删除该密钥并刷新页面，然后再次检查 **Database** 窗口。

    如果删除冲突的密钥后按钮仍未显示，请通过[联系 Replit 支持团队](https://replit.com/support)并提供项目 URL。
  </Accordion>

  <Accordion title="앱中出现“connection pool exhausted”错误——这是什么意思？">
    你的应用同时打开的数据库连接数超过了连接池允许的上限。常见原因包括：

    * 每次请求后未关闭连接
    * 流量激增
    * 慢查询长时间占用连接

    大多数框架会使用单个共享连接池，而不是为每个请求创建新连接。

    如需尽快修复，请打开新的 Agent 聊天，说明该错误，并让 Agent 检查你的应用如何管理数据库连接。
  </Accordion>

  <Accordion title="如何将开发数据库迁移到生产环境？">
    Replit 将开发数据库与生产数据库分开，确保测试更改不会影响线上数据。若要在生产环境中运行迁移，请将迁移命令添加到部署的构建或预部署阶段，以便在每次部署时执行。例如，Drizzle 可使用 `drizzle-kit migrate`。你也可以在生产环境的 Shell 中手动运行迁移。

    请参阅[发布时创建生产数据库](/zh/ko/features/data-and-storage/development-and-production)。
  </Accordion>

  <Accordion title="支付正常，但数据库中显示“endpoint disabled”">
    有时即使与支付无关，也会发生这种情况。请尝试手动恢复：打开 **Database** 窗口，选择 **Development**，待 **Unpause database** 按钮出现后将其选中，然后对 **Production** 重复此操作。

    如果该按钮未出现或问题仍然存在，请提供项目 URL 并[联系 Replit 支持团队](https://replit.com/support)—可能需要手动恢复。请参阅[生产数据库](/zh/ko/features/data-and-storage/development-and-production)。
  </Accordion>
</AccordionGroup>
