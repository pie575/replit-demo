### Rétention d'historique Neon DB

La rétention d'historique configurable pour les bases de données Neon est désormais disponible pour vous aider à gérer vos coûts plus efficacement. Cela répond directement aux retours concernant la gestion des coûts des bases de données.

### Fonctionnalités de contexte de lien améliorées

### Sélection de modèle pour l'Assistant

Pour les builders avancés, l'option de revenir à Claude 3.5 Sonnet v2 dans les paramètres de l'Assistant est désormais disponible. Les améliorations de performances pour Claude 3.7 Sonnet sont en cours.

### Améliorations des performances de la vue Web

Profitez d'une navigation iframe plus fluide et d'une meilleure compatibilité avec les sites sécurisés dans la vue Web. Le système proxy a été amélioré pour gérer les en-têtes de sécurité de manière plus intelligente, éliminant ainsi les blocages de navigation frustrants que vous avez peut-être rencontrés auparavant.
