<div id="importar-do-vercel">
  ## 从 Vercel 导入
</div>

⏰ *预计用时：三分钟*

关联项目对应的 GitHub 仓库，即可将 Vercel 项目导入 Replit。

如需了解完整的导入选项，包括 GitHub、Figma、Bolt 和 Lovable 等其他平台，请参阅[导入功能文档](/zh/pt/references/workspace/import)。

<div id="antes-de-comear">
  ## 开始之前
</div>

* 已连接 GitHub 的 Vercel 项目
* 对关联 GitHub 仓库的访问权限
* Replit 账户

<div id="etapas-de-importao">
  ## 导入步骤
</div>

1. 打开 [replit.com/import](https://replit.com/import)。
2. 选择 **Vercel**。
3. 连接你的 GitHub 账户。
4. 选择你的 Vercel 项目仓库。
5. 添加所需的 Secrets 和环境变量。
6. 选择 **Import**。

<div id="o-que-importado">
  ## 导入内容
</div>

* 项目文件和目录结构
* 依赖项和框架配置
* Replit 的运行和构建模式

<div id="o-que-no-importado">
  ## 不会导入的内容
</div>

* 现有环境变量的值
* 自定义域名
* Vercel 特有的 edge 或 middleware 行为
* 分析或监控服务的外部配置
