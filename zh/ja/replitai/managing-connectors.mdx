您可以管理连接器，让团队以一致、安全的方式使用集成功能。可用功能因套餐而异。

* **Core 和 Pro**：连接器管理适用于**协作工作区**。账户管理员为该工作区设置和管理连接，构建者可在该工作区内的应用中使用这些连接。
* **Enterprise**：面向整个组织的连接器管理，提供自定义 OAuth 客户端、API 密钥访问控制、自带密钥等高级控制功能。

<div id="section">
  ## 主要功能
</div>

* **集中管理**：管理员只需配置一次服务，构建者即可在该工作区的所有应用中使用。
* **可见性与审计**：随时了解哪些应用和成员正在使用哪些服务。
* **按应用授权与撤销**：无需改动代码即可撤销或轮换访问权限。

**仅限 Enterprise：**

* **基于角色的访问控制**：为 API 密钥提供带作用域的最小权限访问控制。
* **使用自有 OAuth**：以自定义作用域使用组织自有的 OAuth 客户端。
* **自带 OpenAI 密钥**：使用您自己的 OpenAI API 密钥，替代 Replit 的默认密钥。

<div id="section-2">
  ## 工作原理
</div>

<Steps>
  <Step title="管理员设置服务">
    管理员使用凭据一次性完成服务设置。
  </Step>

  <Step title="管理员批准访问">
    管理员批准可使用连接器的群组 (Enterprise) ，或将其开放给协作工作区使用 (Core/Pro) 。
  </Step>

  <Step title="构建者使用连接器">
    成员可让工作区或组织内的应用通过 Agent 使用该服务进行构建。
  </Step>

  <Step title="管理员监控使用情况">
    管理员可以监控哪些成员和应用正在使用哪些服务。
  </Step>
</Steps>

<div id="section-3">
  ## 安全与治理
</div>

* 凭据和令牌由平台统一管理，不会存储在各个应用中。
* 无需修改代码，即可集中撤销和轮换。
* Enterprise：提供作用域访问权限，遵循最小权限原则，并支持可选的自定义 OAuth 配置。

<div id="section-4">
  ## 设置和管理
</div>

<div id="section-5">
  ### 启用新连接器
</div>

<Steps>
  <Step title="前往 Integrations">
    在协作工作区 (Core/Pro) 或组织主页 (Enterprise) 中打开 **Integrations** 页面。
  </Step>

  <Step title="启用新连接器">
    选择右上角的 **Enable new connector**。
  </Step>

  <Step title="选择服务">
    选择要启用的服务 (例如：Notion、GitHub、Google、Outlook、Dropbox、Salesforce) 。
  </Step>

  <Step title="配置连接器">
    使用默认设置启用连接器。仅 **Enterprise** 支持创建自定义 OAuth 连接器 (例如：Drive 作用域 `.../auth/drive.file`、`.../auth/drive.install`) 。
  </Step>

  <Step title="提交">
    选择 **Submit**。
  </Step>
</Steps>

<div id="enterprise">
  ### 配置访问权限 (Enterprise)
</div>

1. 启用连接器后，选择 **Manage**。
2. 根据需要授予特定群组访问权限。

<div id="section-6">
  ### 修改连接器
</div>

* 启用连接器后，选择 **Manage**。
* 删除连接器后，该工作区 (Core/Pro) 或组织 (Enterprise) 中的所有构建者都将无法再使用该连接器。
* 在 Enterprise 中，可以编辑自定义 OAuth 连接器的作用域。

<div id="section-7">
  ## 套餐对比
</div>

| 功能              | Core (协作工作区)  | Pro (协作工作区)  | Enterprise |
| --------------- | ------------- | ------------ | ---------- |
| 启用和管理连接器        | ✓             | ✓            | ✓          |
| 作用域            | 工作区           | 工作区          | 组织         |
| 创建自定义 OAuth 客户端 | —             | —            | ✓          |
| 设置 API 密钥的访问控制  | —             | —            | ✓          |
| 使用自带的 OpenAI 密钥 | —             | —            | ✓          |

<div id="openaienterprise">
  ### 自带 OpenAI 密钥 (Enterprise)
</div>

Enterprise 客户可以通过连接器自带 OpenAI API 密钥，替代 Replit 的默认基础设施。这样即可沿用现有的 OpenAI 合约，并通过自己的账户管理 AI 使用情况。
