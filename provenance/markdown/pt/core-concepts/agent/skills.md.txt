## O que são skills

As Skills ensinam ao Agent como você trabalha. Enquanto vocês constroem juntos, você cria contexto útil sobre seu projeto, mas esse contexto normalmente desaparece quando o chat termina. As Skills preservam o que você aprendeu para que o Agent possa aplicá-lo de forma consistente. Tarefas que eram anteriormente inconsistentes tornam-se mais confiáveis, produzindo melhores resultados a cada vez.

Por exemplo, uma skill de sistema de design garante que o Agent use exatamente suas cores e regras de espaçamento. Uma skill de correção de bugs captura soluções para que o Agent as lembre da próxima vez.

## Duas formas de usar skills

Existem duas formas de usar skills com o Agent, dependendo se você quer que uma skill se aplique a uma única mensagem ou a todo o seu projeto.

### Usar uma skill no chat

A maneira mais rápida de usar uma skill é anexá-la diretamente a uma mensagem. Clique no botão **+** ao lado da entrada de chat, selecione **Usar uma skill** e navegue pelas categorias disponíveis. Quando você seleciona uma skill, ela aparece como um chip anexado à sua mensagem. O Agent usa essa skill apenas para a tarefa atual — ela não é instalada no seu projeto.

Isso é ideal quando você quer que o Agent realize uma tarefa pontual com conhecimento especializado. Por exemplo, você pode selecionar a skill **Analisador de Ações** e pedir ao Agent para pesquisar um investimento, ou escolher a skill **Criador de Currículo** para criar um currículo polido.

As skills estão organizadas nas seguintes categorias:

| Categoria                    | Exemplos de skills                                                                    |
| ---------------------------- | ------------------------------------------------------------------------------------- |
| **Vendas e marketing**       | Criativo de Anúncio, SDR com IA, Auditor de SEO, Máquina de Conteúdo                  |
| **Carreira**                 | Recrutador com IA, Criador de Currículo, Preparação para Entrevista                   |
| **Pesquisa e análise**       | Análise Competitiva, Pesquisa Profunda, Pesquisa de Fornecedores                      |
| **Negócios e finanças**      | Analisador de Ações, Gerador de Faturas, Analisador de Imóveis                        |
| **Documentos e ferramentas** | Gerador de Excel, Clonador de Sites, Conversor de Arquivos, Gerador de Flashcards     |
| **Criativo**                 | Editor de Fotos, Gerador de Podcast, Gerador de Branding                              |
| **Produtividade**            | Secretária com IA, Gerente de Produto, Design Thinker                                 |
| **Pessoal**                  | Assistente de Viagem, Criador de Receitas, Planejador de Refeições, Comprador Pessoal |

<Tip>
  Você também pode digitar "use a skill analisador de ações" (ou qualquer nome de skill) diretamente na sua mensagem sem abrir o seletor de skills — o Agent entende a solicitação.
</Tip>

### Instalar uma skill no seu projeto

Quando você quer que o Agent siga uma skill de forma consistente em todas as conversas de um projeto, instale-a no diretório `/.agents/skills` do seu projeto. As skills instaladas persistem entre sessões de chat e estão sempre disponíveis para o Agent quando trabalha no seu projeto.

Isso é melhor para conhecimento específico do projeto, como seu sistema de design, convenções de codificação ou soluções para problemas recorrentes.

## Adicionando skills ao seu projeto

Existem várias maneiras de adicionar uma skill ao seu projeto de forma permanente.

### Criar com o Agent

A maneira mais natural de criar skills é através de conversação. Depois de resolver um problema juntos, peça ao Agent para capturar o que aprendeu. A skill se escreve a partir do contexto compartilhado.

```
Crie uma skill para o meu sistema de design usando estas paletas de cores e regras de espaçamento
```

Você também pode pedir ao Agent para pesquisar e criar skills para novos domínios:

```
Pesquise melhores práticas para geração de vídeo com Remotion e crie uma skill
```

### Descobrir e instalar no painel de Skills

Abra o **painel de Skills** no Editor de Projetos e selecione a aba **Descobrir** para pesquisar skills contribuídas pela comunidade. Você pode navegar por nome, pesquisar por palavra-chave e instalar qualquer skill diretamente no seu projeto com um único clique.

### Instalar pelo diretório de skills

O [diretório de Skills do Agent](https://skills.sh) oferece skills contribuídas pela comunidade que você pode instalar diretamente. O Replit suporta instalação via [npx skills CLI](https://github.com/vercel-labs/skills):

```bash theme={null}
npx skills <skill> -a replit
```

Isso instala a skill no diretório `/.agents/skills` do seu projeto.

<Warning>
  As skills contêm conteúdo e código arbitrários. Sempre revise a fonte antes de
  instalar uma skill de fontes externas.
</Warning>

## Como as skills funcionam

As skills são armazenadas no diretório `/.agents/skills` do seu projeto. Cada skill segue a [especificação de Skills do Agent](https://agentskills.io/specification), que define a estrutura e o formato dos arquivos de skill.

O Agent vê o nome e a descrição de cada skill instalada, mas só carrega o conteúdo completo de uma skill quando ela é relevante para a tarefa atual. Isso mantém as coisas leves — você pode ter muitas skills instaladas sem deixar o Agent mais lento.

As skills instaladas persistem no seu projeto, por isso permanecem disponíveis entre sessões do Agent e podem ser enviadas ao controle de versão para compartilhamento com a equipe.

As skills podem ter diferentes escopos:

* **Nível de projeto**: Específicas de um projeto, versionadas com seus arquivos em `/.agents/skills`
* **Nível de usuário**: Seu kit de ferramentas pessoal que o acompanha em todos os projetos
* **Enterprise**: Padrões de toda a empresa incorporados em [templates personalizados](/pt/teams/custom-templates) que são fixados na entrada do Agent para sua organização

<Note>
  As skills funcionam melhor quando capturam padrões específicos e repetíveis em vez de
  orientações gerais. Concentre-se em fluxos de trabalho concretos, convenções estabelecidas e
  soluções comprovadas do seu projeto.
</Note>

## Trabalhando com outras ferramentas de codificação com IA

<Accordion title="Importar skills de outras ferramentas de codificação com IA">
  Se você trabalha com várias ferramentas de codificação com IA, o [rulesync](https://github.com/dyoshikawa/rulesync) tem suporte ao Replit e ajuda a manter configurações consistentes.

  Você pode importar skills de outros assistentes de codificação com IA:

  ```bash theme={null}
  npx rulesync init
  npx rulesync import --targets claudecode --features skills
  npx rulesync generate --targets replit --features skills
  ```

  Isso permite manter um único conjunto de skills que funciona em diferentes ambientes de desenvolvimento.
</Accordion>
