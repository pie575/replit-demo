<div id="sugestes-de-tarefas-de-acompanhamento">
  ## 后续任务建议
</div>

应用一项任务后，Agent 会分析您的项目上下文，并推荐您接下来可能需要创建的**后续任务**。**建议的后续任务**对话框会以内联方式显示首要建议，让您无需离开主对话即可继续操作。

<Frame>
  <img src="/assets/mirror/follow-up-tasks-dialog-c1660cec2d1d.png" alt="建议的后续任务对话框，显示一项后续任务、一个“启动”按钮，以及用于在任务看板中查看更多任务的链接" width="495" height="290" data-path="images/agent/follow-up-tasks-dialog.png" />
</Frame>

后续建议可能包括：

* **要创建的新功能**：与您刚刚发布的内容自然契合的功能
* **性能改进**：Agent 在处理任务时发现的优化机会
* **用户体验改进**：让功能更加完善的细节打磨和优化

在建议中选择**启动**即可将其提交到后台处理，或选择**查看计划**先查看建议的工作内容。要查看所有建议，请选择**在任务看板中查看更多**。建议的后续任务会显示在**草稿**列的**建议**部分。

<Frame>
  <img src="/assets/mirror/follow-up-tasks-kanban-21087e0210b6.png" alt="任务看板在“草稿”列的“建议”部分显示多项后续任务建议" width="980" height="627" data-path="images/agent/follow-up-tasks-kanban.png" />
</Frame>

关闭**建议的后续任务**对话框会取消这些建议。如果主对话中已有建议的计划等待处理，Agent 不会显示该对话框，以免这两个提示词同时占用您的注意力。

<div id="gerenciando-muitas-sugestes-de-uma-vez">
  ## 批量管理建议
</div>

如果项目中有许多后续任务建议，请打开任务看板，然后在**草稿**列中选择**编辑**。在编辑模式下，每个建议任务都会显示一个复选框。选择所需的任务，然后使用**启动**或**取消**对所有选中的任务执行相应操作。选择**完成**即可退出编辑模式。
