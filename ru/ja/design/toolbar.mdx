Панель инструментов Canvas — это плавающая панель, закреплённая по центру в нижней части доски. Она содержит инструменты для перемещения, рисования, редактирования и добавления контента. Панель инструментов отображается в режиме Canvas.

<div id="section">
  ## Инструменты
</div>

Выберите инструмент, чтобы включить его. Активный инструмент подсвечивается залитым фоном. Крайняя левая группа — навигация (Interact, Pan). Остальные — инструменты для работы с содержимым и разметкой. Инструменты выбираются взаимоисключающе: при выборе одного остальные отключаются.

<div id="interact">
  ### Interact
</div>

**Interact** — инструмент по умолчанию. С его помощью можно выбирать и перетаскивать фреймы, а также щёлкать внутри работающего артефакта и взаимодействовать с ним как с настоящим приложением. При щелчке по фрейму, когда активен Interact, фрейм будет выбран и появится [панель действий фрейма](/ru/ja/design/frames#per-frame-action-bar).

<Frame>
  <img src="/assets/mirror/canvas-interact-4472dae3de09.png" alt="Canvas с артефактом Website, выбранным с помощью инструмента Interact. Вокруг фрейма отображается рамка с маркерами выбора, а над ним — панель действий фрейма. На плавающей панели инструментов внизу выделен инструмент Interact" width="3450" height="2000" data-path="images/replitai/canvas-interact.png" />
</Frame>

**Сочетание клавиш:** `V`. **Доступность:** всегда.

<div id="pan">
  ### Pan
</div>

**Pan** переключает курсор в режим захвата, позволяя перетаскивать саму доску. Когда Pan активен, перетаскивание перемещает область просмотра вместо выделения фреймов. Перемещать область просмотра также можно, удерживая пробел и перетаскивая мышью или перетаскивая средней кнопкой мыши, даже если активен другой инструмент.

<Frame>
  <img src="/assets/mirror/canvas-pan-9f07d3bf72a3.png" alt="Canvas с активным инструментом Pan. На доске показаны артефакт Website (Velocity — Supercar Rental) и макет Design (Velocity — Home (Mockup)); на плавающей панели инструментов внизу выделен инструмент Pan (курсор в виде ладони)" width="1725" height="1041" data-path="images/replitai/canvas-pan.png" />
</Frame>

**Сочетание клавиш:** `H`. **Доступность:** всегда доступен.

<div id="chat">
  ### Chat
</div>

**Chat** добавляет прямо на доску небольшое поле для ввода сообщений, позволяя отправлять промпты Agent, не покидая Canvas. Выбранные элементы и фреймы прикрепляются к сообщению в виде снимков — так же, как при отправке из боковой панели чата Agent.

<Frame>
  <img src="/assets/mirror/canvas-chat-d28e2d8f216a.png" alt="Canvas в режиме Chat. Остальная часть доски затемнена, а встроенное поле ввода чата наложено поверх артефакта Website. Метка «div» в поле ввода обозначает выбранный элемент, а промпт содержит текст «suggest three alternatives to this image». На плавающей панели инструментов внизу выделен инструмент Chat" width="3450" height="2000" data-path="images/replitai/canvas-chat.png" />
</Frame>

**Доступность:** инструмент Chat (только на настольных устройствах).

<div id="draw">
  ### Draw
</div>

**Draw** активирует инструменты разметки, включая рисование от руки, стрелки, стикеры и фигуры, чтобы вы могли делать наброски поверх фреймов и добавлять аннотации на доску. Используйте его, чтобы обводить проблемные области, указывать на элементы, которые хотите изменить, или оставлять заметки рядом с фреймами.

Когда Draw включён, над плавающей панелью инструментов отображается панель **Shape properties** с настройками цвета, линий и заливки для текущего инструмента разметки. Она автоматически скрывается при переключении на Interact или Pan.

<Frame>
  <img src="/assets/mirror/canvas-draw-d2d9b6556cde.png" alt="Canvas с активным инструментом Draw. Рядом с фреймом нарисованы прямоугольник «Widget» и фиолетовый стикер «Add a widget». Над плавающей панелью инструментов отображается панель Shape properties с инструментами карандаша, текста, прямоугольника, стрелки и стикера, а также образцами цветов и элементом управления размером текста Aa; Draw выделен" width="1725" height="1041" data-path="images/replitai/canvas-draw.png" />
</Frame>

**Доступность:** всегда включён.

<div id="edit">
  ### Edit
</div>

**Edit** — это визуальный селектор элементов. Когда Edit активен, нажмите внутри работающего артефакта, чтобы выбрать элемент — кнопку, заголовок, изображение и т. д. При выборе элемента открывается **визуальный редактор** — правая панель с элементами управления, такими как Layout, Color и Border, а также встроенным промптом, с помощью которого можно попросить Agent изменить только выбранную часть. Подробнее см. в разделах [Элементы](/ru/ja/design/elements) и [Визуальный редактор](/ru/ja/design/visual-editor).

<Frame>
  <img src="/assets/mirror/canvas-edit-67fe5ee02fbe.png" alt="На сайте аренды суперкаров активирован инструмент Edit и выбран элемент div. На панели визуального редактора отображаются элементы управления Text, Layout, Color и Border, а также кнопки Discard и Save edits" width="2000" height="1269" data-path="images/replitai/canvas-edit.png" />
</Frame>

**Доступность:** Всегда доступен на компьютере. Недоступен, пока нет ни одного фрейма; во всплывающей подсказке отображается *«Создайте артефакт или сгенерируйте дизайн для редактирования.»* На мобильных устройствах скрыт.

<div id="generate">
  ### Generate
</div>

**Generate** открывает всплывающее окно **Generate media** для изображений, видео и векторной графики. Выберите тип, напишите промпт — и Agent разместит результат на доске в виде нового фрейма.

<Frame>
  <img src="/assets/mirror/canvas-add-menu-5d97d9c813e1.png" alt="Открытое меню + Add в Canvas с четырьмя вариантами, расположенными вертикально: Design («Mock up interfaces and visual concepts»), Image («Generate and edit images»), Video («Generate motion clips and animations»), Vector Graphic («Generate vector illustrations and SVGs»). Раздел Generate на плавающей панели инструментов внизу теперь отображается как «+ Generate»" width="1102" height="702" data-path="images/replitai/canvas-add-menu.png" />
</Frame>

В верхней части всплывающего окна расположены четыре вкладки.

* **Design**
  — **Image**
* **Video**
* **Vector Graphic**

Часть элементов управления одинакова для всех типов, остальные зависят от конкретного типа.

**Общие элементы управления (для всех типов):**

* **Model**: модель генерации. Набор доступных моделей зависит от типа (см. таблицу ниже).
* **Prompt**: простыми словами опишите, что должен сгенерировать Agent.
* **Generate**: отправляет запрос и резервирует фрейм-заполнитель в позиции курсора. Как только ассет готов, заполнитель заменяется живым фреймом. Если сгенерировать не удалось, заполнитель удаляется, а в панели Chat появляется ошибка.

**Модели и элементы управления по типам:**

| Тип         | В чём хороша                                                                        | Текущие модели                                                  | Специфичные для типа элементы управления                                                              |
| ----------- | ----------------------------------------------------------------------------------- | --------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| **Image**   | Растровый вывод (PNG / JPG). Картинки для мудборда, ключевые изображения, референсы | Nano Banana, Nano Banana 2, Nano Banana Pro, ChatGPT Images 2.0 | Соотношение сторон (`1:1`, `16:9`, `9:16`, `4:3`, `3:4`) и размер (`1K`, `2K`, `4K`)                  |
| **Video**   | Короткие клипы с движением и анимации                                               | Veo 3.1, Seedance 2.0                                           | Соотношение сторон, разрешение (например, `720p`), длительность (например, `4s`), переключатель звука |
| **Graphic** | Векторный вывод SVG. Иконки, логотипы, схемы, стилизованные иллюстрации             | Claude 4.6 Opus, Gemini 3.1 Pro Preview                         | Переключатель анимации                                                                                |

<Note>
  Набор моделей часто меняется. Таблица отражает то, что доступно на данный момент, но актуальный список смотрите в выпадающем списке в приложении.
</Note>

Подробнее о каждом типе фрейма и о том, что можно сделать после создания, см. в разделе [Фреймы](/ru/ja/design/frames).

<div id="section-2">
  #### Прикрепление визуальных референсов
</div>

Перед генерацией в качестве визуальных референсов можно прикрепить то, что уже есть на доске. Agent использует эти референсы, чтобы результат соответствовал внешнему виду проекта. Откройте меню **+** в форме **Generate media** и выберите нужный вариант.

* **Upload file**: загрузите изображение с компьютера и используйте его как референс.
* **Select canvas elements**: выберите уже имеющиеся элементы на доске. Фрейм захватывается как снимок экрана, а текст и фигуры-стикеры прикрепляются в виде текстовой сводки.

Каждый референс отображается в форме в виде чипа. Добавьте столько, сколько нужно, напишите промпт и выберите **Generate**. Чтобы удалить референс, выберите его чип.

<Frame caption="Форма Generate media с открытым меню +. Отображаются Upload file и Select canvas elements.">
  <img src="/assets/mirror/canvas-generate-media-references-ac0cb4340acb.png" alt="В форме Generate media в Canvas открыто меню + с вариантами Upload file и Select canvas elements. В выпадающем списке моделей выбран Nano Banana Pro" width="1134" height="662" data-path="images/replitai/canvas-generate-media-references.png" />
</Frame>

<Note>
  ChatGPT Images 2.0 сейчас не поддерживает загрузку. Чтобы прикрепить визуальные референсы, переключитесь на другую модель, например Nano Banana Pro.
</Note>

Если включено **Add menu**, кнопка Generate заменяется меню **+**, которое объединяет все типы из всплывающего окна вместе с **Design** (самостоятельные визуальные макеты, не затрагивающие фактический код).

**Доступность:** Image generation. Для **Vector Graphic** требуется Vector graphic generation. Для **Video** требуется Video generation. Для меню **+** требуется Add menu (которое, в свою очередь, требует Image generation).
