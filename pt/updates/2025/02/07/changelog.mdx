## Plataforma

### Agent agora é gratuito para experimentar

O Agent e o Assistant agora são gratuitos para experimentar! Seja você um desenvolvedor experiente no Replit ou esteja começando agora, pode experimentar essas ferramentas poderosas sem nenhuma restrição.

Seus primeiros 10 checkpoints são gratuitos (isso inclui desenvolvedores pagos existentes também). Acesse [https://replit.com](https://replit.com) para experimentá-los.

### Replit Mobile

O Replit Mobile foi completamente reconstruído do zero! O novo aplicativo mobile oferece uma experiência de programação mais rápida e intuitiva onde quer que você esteja.

Acesse [https://replit.com/mobile](https://replit.com/mobile) para experimentar.

### Novas páginas de capa do Replit App

Suas páginas de capa receberam uma grande atualização. Elas agora são mais voltadas para desenvolvedores e mostram o prompt inicial de qualquer aplicativo criado com o Agent.
