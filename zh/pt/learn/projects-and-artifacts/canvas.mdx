export const YouTubeEmbed = ({videoId, title = "YouTube 视频", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

<div id="o-que-est-no-canvas">
  ## Canvas 中有什么
</div>

Canvas 是一块无限画布，你可以在其中以可视化方式查看和处理所有内容。

<Frame>
  <img src="/assets/mirror/canvas-mockups-057e738a78da.png" alt="Canvas 显示多个并排的设计模型——深色主题、移动端预览和详情页面" width="3452" height="1620" data-path="images/replitai/canvas-mockups.png" />
</Frame>

* **你的应用**：正在运行的应用会以实时交互式预览的形式直接显示在 Canvas 上。你可以像在浏览器中一样点击和使用它们。
* **设计模型**：Agent 为你创建的视觉原型。它们的外观和使用方式都与真实页面相似——你可以与之交互、调整大小，并让 Agent 进行调整——但它们与在线应用相互独立，因此你可以自由尝试。
* **形状和绘图**：矩形、圆形、星形、箭头、爱心等。你可以用它们快速勾勒想法、标注设计，或展示屏幕之间的连接方式。
* **文本和便签**：在 Canvas 的任意位置添加标签或便签，以整理你的想法。
* **图片**：将截图或参考图片拖放到 Canvas 上。Agent 可以复刻所见内容，或从中获取灵感。
* **视频**：将视频文件放到 Canvas 上，与其他内容一同展示。

* 请 Agent 将粗略草图转化为精致设计

<div id="transformando-um-design-em-um-app-real">
  ## 将 Design 转化为真正的 App
</div>

当您对某个 Design 感到满意并希望将其变为实际 App 时，有两种方式：

<div id="torne-o-um-app-completo">
  ### 将其打造成功能完整的 App
</div>

如果你的设计需要实际功能，例如保存数据、用户账户或连接其他服务，可以让 Agent 将其打造成一个功能完整的 App。你可以这样说：“将其变成真正的 App”或“为此添加 backend。”Agent 会构建让它成为可正常运行并发布的 App 所需的一切。

<Note>
  将设计变成功能完整的 App 需要付费计划。
</Note>

<div id="converta-para-um-tipo-especfico">
  ### 转换为特定类型
</div>

您还可以将设计画框转换为特定类型的工件：

<Steps>
  <Step title="选择一个画框">
    点击要转换的画框。
  </Step>

  <Step title="请 Agent 转换">
    告诉 Agent 您想要什么，例如“将此内容转换为 Web 应用”或“将此内容转换为幻灯片”。
  </Step>

  <Step title="选择类型">
    可选择 Web 应用、移动应用、幻灯片、数据可视化等类型。
  </Step>
</Steps>

<div id="perguntas-frequentes">
  ## 常见问题
</div>

<Accordion title="设计画框与我正在运行的应用相同吗？">
  不相同。设计画框是视觉原型——它们的外观和交互方式都像真实应用，但背后并没有实际运行的 backend 或数据库。而 Canvas 中的应用预览则是实际正在运行的应用。
</Accordion>

<Accordion title="我可以重新设计页面而不影响线上应用吗？">
  可以。让 Agent 将某个页面带到 Canvas 中——例如：“把我的仪表板放到 Canvas 上。”Agent 会创建一个副本，供你自由尝试。在你选择应用更改之前，线上应用不会受到影响。
</Accordion>

<Accordion title="如何将设计变成真实应用？">
  让 Agent 将其变成完整应用 (“让它变成真实应用”) ，或转换为特定类型 (“将它转换为 Web 应用”) 。Agent 会构建所需的一切，使其成为可正常运行并发布的应用。
</Accordion>

<Accordion title="我可以转换为 Web 应用以外的类型吗？">
  可以。你可以将 Canvas 画框转换为 Web 应用、移动应用、幻灯片、数据可视化等。
</Accordion>

<Accordion title="我可以从 Figma 或其他工具导入设计吗？">
  可以。你可以通过以下几种方式将 Figma 设计导入 Replit：

  * **从 Figma 导入**：访问 [replit.com/import](https://replit.com/import)，连接你的 Figma 账户并粘贴画框 URL，即可将设计转换为可正常运行的 React 应用。详情请参阅[从 Figma 导入快速入门指南](/zh/pt/design/import-figma-designs-into-replit-design)。
  * **Agent Chat 中的 Figma MCP**：将 Figma 链接直接粘贴到 Agent Chat 中，让它生成代码、提取设计数据，或根据设计构建组件。请参阅 [Figma MCP 集成](/zh/pt/features/mcp/figma)指南。
  * **截图参考**：将截图拖放到 Canvas 上，并让 Agent 根据截图重新创建设计。
</Accordion>

<Accordion title="我还可以在 Canvas 上放置什么？">
  除了设计模型和应用预览外，你还可以添加形状、箭头、文本标签、便签、图片和视频——可用于勾勒想法、标注设计或整理思路。
</Accordion>

<div id="disponibilidade">
  ## 可用性
</div>

所有方案均可使用 Canvas，包括创建画框、内联编辑、生成变体以及转换为工件。将设计转化为完整 App 需要付费计划。
