<div id="what-is-a-replit-app">
  ## Что такое Replit App?
</div>

Replit App — это облачные проекты, содержащие код, данные и ассеты.
Вы можете создавать, запускать и публиковать их в безопасной изолированной среде.

Replit App интегрируются со следующими инструментами в Project Editor, обеспечивая
удобный процесс разработки:

* **Инструменты на базе ИИ**: используйте Agent для создания, отладки и объяснения кода.
* **Совместная работа**: работайте над одним приложением вместе с другими в реальном времени.
* **Публикация**: публикуйте приложение в облаке одним щелчком.

<div id="key-features">
  ## Ключевые возможности
</div>

Replit App предлагают следующие возможности:

* **Без настройки:** Создавайте приложения или пишите код прямо на Replit.com без установки и настройки.
* **Автосохранение:** Проект непрерывно сохраняет изменения в облаке, поэтому вы можете продолжить работу в любом веб-браузере
* **Контроль версий:** Отслеживайте изменения, просматривайте историю файлов и синхронизируйте их через системы контроля версий Replit — без дополнительной настройки
* **Настройки публичного/приватного доступа:** Настраивайте с помощью параметров конфиденциальности, кто может просматривать, запускать или создавать ремикс вашего приложения
* **Публикация:** Публикуйте код в облаке без сложной настройки
* **Пользовательские URL приложений:** Получите уникальный URL для приложения или назначьте собственный домен для более профессионального представления

<Info>
  Файлы, загруженные в файловую систему проекта, доступны только во время разработки и
  недоступны в опубликованном приложении или другим разработчикам. Используйте [Object
  Storage](/ru/features/data-and-storage/object-storage) для обработки
  загрузок разработчиков и предоставления файлов, а [Replit
  Database](/ru/features/data-and-storage/sql-database) — для хранения и
  получения данных приложения и пользователей.
</Info>

Подробнее об инструментах Project Editor, упрощающих создание Replit App, см. в статье [Обзор Project Editor](/ru/learn/projects-and-artifacts/project-editor/).

<div id="how-it-works">
  ## Как это работает
</div>

Когда вы создаёте Replit App, Replit выделяет в облаке приватное пространство для вашего проекта.
По мере добавления функций и внесения изменений в приложение Replit автоматически сохраняет их,
чтобы вы могли продолжить редактирование в любом браузере.

Replit предоставляет предварительно настроенные среды со всеми необходимыми компонентами.
Это позволяет сразу приступить к созданию приложения, не заботясь о
настройке сервера, базы данных или управлении средой.

Replit автоматически присваивает каждому Replit App уникальный веб-адрес, по которому вы
можете просматривать приложение во время работы над ним. Когда вы будете готовы поделиться своим
творением, его можно опубликовать всего в несколько кликов, чтобы оно было доступно круглосуточно.

<div id="storage-overview">
  ## Обзор хранилищ
</div>

Replit предлагает четыре основных типа хранилищ для различных потребностей вашего приложения в данных. Каждый тип хранилища предназначен для разных сценариев использования и имеет ограничения, зависящие от вашего тарифа.

<Info>
  В лимиты хранилища входят все данные, сохранённые вашим приложением, включая установленные
  пакеты и зависимости.
</Info>

| Тип хранилища                                                   | Описание                              | Сценарии использования                                   | Сохранность                                              | Лимиты тарифа                                                                                                                                        |
| --------------------------------------------------------------- | ------------------------------------- | -------------------------------------------------------- | -------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Файловое хранилище**                                          | Файлы в вашем проекте                 | Код приложения, статические ассеты, файлы конфигурации   | Сохраняется при публикации, сбрасывается при перезапуске | Starter: {StarterWorkspaceStorage}<br />Core: {CoreWorkspaceStorage}<br />Pro: {TeamsWorkspaceStorage}<br />Enterprise: {EnterpriseWorkspaceStorage} |
| **[База данных](/ru/features/data-and-storage/sql-database/)**     | Хранение структурированных данных     | Профили пользователей, игровые рекорды, каталоги товаров | Полностью сохраняется между сессиями                     | 20 ГБ на базу данных для разработки<br />За продакшен-базы данных взимается плата за вычислительное время и хранение                                 |
| **[App Storage](/ru/features/data-and-storage/object-storage/)**   | Неструктурированные данные и медиа    | Изображения, видео, PDF-файлы, документы                 | Полностью сохраняется между сессиями                     | Оплата по мере использования<br />Плата за хранение и пропускную способность                                                                         |
| **[Secrets](/ru/core-concepts/project-editor/app-setup/secrets/)** | Зашифрованные конфиденциальные данные | API-ключи, учётные данные, строки подключения            | Полностью сохраняется и шифруется                        | Без особых ограничений<br />Включено во все тарифы                                                                                                   |
