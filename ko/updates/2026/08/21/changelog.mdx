<div id="work-in-free-mode">
  ### Free Mode에서 작업하기
</div>

Power Mode나 Max Mode credits를 사용하지 않고도 Free Mode에서 대화하고, 아이디어를 탐색하고, 만들고, 빌드해 보세요. Free Mode는 Auto로 모델을 선택하며, limit은 plan에 따라 다릅니다. **Settings** &gt; **Usage**에서 남은 allowance와 초기화 시점을 확인할 수 있습니다.

<Frame caption="Agent modes 패널에서 Free를 선택하세요.">
  <img src="/assets/mirror/free-mode-agent-modes-selector-sanitized-b4b896fb13ab.png" width="1784" height="882" data-path="images/chat/free-mode-agent-modes-selector-sanitized.png" />
</Frame>

[Free Mode를 최대한 활용하는 방법](/ko/chat/free-mode)을 알아보세요.

<div id="start-with-conversations">
  ### Conversations로 시작하기
</div>

비공개 Conversation을 시작해 질문하고, 정보를 탐색하고, context를 첨부하고, Routine을 실행하거나 원하는 결과를 설명해 보세요. 작업 규모가 커지면 Replit에 Conversation을 Project로 전환해 달라고 요청하면 됩니다. context와 파일은 그대로 이어집니다.

[Conversations](/ko/chat/conversations)에 대해 자세히 알아보세요.

<div id="automate-recurring-work-with-routines">
  ### Routines로 반복 작업 자동화하기
</div>

Conversation 안에서 반복할 작업을 Replit에 예약하세요. 각 결과는 동일한 Conversation으로 전달되므로, 결과를 확인하고 바로 작업을 이어갈 수 있습니다. Routine은 Power Mode 또는 Max Mode에서 실행되며 run마다 예산이 필요합니다.

<Frame caption="활성 Routine, schedule, run 기록을 한곳에서 확인하세요.">
  <img src="/assets/mirror/routines-management-page-c8d8f51156d4.png" alt="Slack의 일일 캘린더 요약과 해당 schedule이 활성 상태로 표시된 Routines 페이지" width="2738" height="782" data-path="images/chat/routines-management-page.png" />
</Frame>

자세한 내용은 [Routines](/ko/chat/routines)를 참고하세요.

<div id="steer-agent-while-working">
  ### 작업 중 Agent 방향 조정하기
</div>

Agent가 작업하는 동안 follow-up을 보내 active turn에 새로운 context를 추가하세요. Conversations와 Projects의 기본값은 Steer이며, **Settings** &gt; **Personalization**에서 각 설정을 Queue로 변경할 수 있습니다. Mac에서는 `Cmd+Enter`, Windows와 Linux에서는 `Ctrl+Enter`를 누르면 해당 메시지에 한해 반대 동작이 적용됩니다.

<Frame caption="Conversations와 Projects에 각각 Steer 또는 Queue를 선택하세요.">
  <img src="/assets/mirror/agent-follow-ups-settings-98a4c5ca399e.png" alt="Steer 및 Queue 옵션과 함께 Conversation 및 Project send behavior를 보여주는 Agent settings" width="3048" height="1372" data-path="images/replitai/agent-follow-ups-settings.png" />
</Frame>

[메시지 steer 및 queue 처리](/ko/features/agent/steer-and-queue-messages)에 대해 자세히 알아보세요.

  ### GitHub에서 skill 가져오기
</div>

[Agent skills 공유 및 가져오기](/ko/features/agent/skills#share-project-skills)에 대해 자세히 알아보세요.

  ### Workspace 전반의 Agent 모델 제어
</div>

<div id="run-black-box-pen-tests">
  ### Black-box pen test 실행하기
</div>

Level 3 security scan을 실행하면 세 가지 검사가 함께 수행됩니다. 무료 dependency 및 package 검사, 소스 코드에 대한 Agent 정적 분석, 실행 중인 Preview를 대상으로 한 외부 black-box test가 진행됩니다. Replit은 소스 코드 검토와 외부 테스트를 병렬로 실행합니다.
