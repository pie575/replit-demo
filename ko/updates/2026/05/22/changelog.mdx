<div id="layout-controls-in-the-visual-editor">
  ### Visual Editor의 Layout 컨트롤
</div>

이제 Visual Editor에 전용 **Layout** 컨트롤이 생겨, Agent에게 스타일을 다시 작성해 달라고 요청할 필요 없이 flexbox 레이아웃을 시각적으로 조정할 수 있습니다. 원하는 컨테이너를 선택하고 Layout 섹션을 펼친 뒤 flex direction, 정렬, 배치 방식을 선택하세요. 항목 사이 간격을 픽셀 단위로 지정하거나, **Space between** 토글을 켜서 자식 요소를 양 끝으로 밀어낼 수 있습니다.

에디터 pane도 **Text**, **Image**, **Layout**, **Color**, **Border** 섹션으로 더 명확하게 재구성되어 필요한 컨트롤을 한결 쉽게 찾을 수 있습니다.

<div id="agent-settings-stay-yours-in-shared-projects">
  ### 공유 project에서도 Agent settings는 개인별로 유지됩니다
</div>

model 등급, plan mode, auto-merge, auto-approve-plan 등의 Agent 환경설정이 이제 project의 모든 사람과 공유되지 않고 사용자 개인에게만 적용됩니다. 팀원이 자신의 task에서 Power Mode로 전환해도 더 이상 여러분의 설정까지 바뀌지 않습니다. 협업자가 많은 project에서도 여러분이 선택한 설정 그대로 Agent가 다음 메시지를 처리합니다.

[Agent Modes](/ko/features/agent/agent-modes#settings-in-shared-projects)에 대해 자세히 알아보세요.

<div id="agent-suggests-power-mode-when-youre-stuck">
  ### 막혔을 때 Agent가 Power Mode를 제안합니다
</div>

Economy Mode에서 같은 문제를 반복해서 겪고 있다는 것을 Agent가 감지하면, 이제 다음 메시지부터 Power로 전환하도록 제안합니다. 이 제안은 반복되는 요청이나 계속 실패하는 코드를 기준으로 판단하며, project당 최대 한 번만 표시됩니다. 계획 수립 session이거나, 이미 예산 관련 우려를 언급했거나, 무료 plan을 사용 중인 경우에는 Agent가 제안을 건너뜁니다.

<div id="cleaner-task-settings-dropdown">
  ### 더 깔끔해진 task 설정 드롭다운
</div>

task 헤더에서 열리는 드롭다운이 더 쓰기 편해졌습니다. 이제 활성 task 또는 계획 제목이 맨 위에 표시되어 인라인으로 이름을 바꿀 수 있고, 자동화 설정(자동 적용, 자동 승인)은 제목과 작업 항목 사이의 별도 섹션에 모였습니다. 또한 popover 너비가 고정되어 task 이름이 바뀌어도 메뉴가 들썩이지 않습니다. 사용할 수 없는 자동화 항목은 숨겨져, 현재 task에 해당하는 항목만 메뉴에 표시됩니다.

<div id="two-new-connectors-quiver-ai-and-browserbase">
  ### 새로운 connector 2종: Quiver AI와 Browserbase
</div>

두 가지 서비스가 connector 카탈로그에 새로 추가되었습니다. **Integrations** 패널을 열고 **Add new integration**을 선택해 원하는 서비스를 연결하세요.

* **Quiver AI**: 관리형 API로 SVG 일러스트레이션을 생성하고 래스터 이미지를 벡터로 변환합니다. Agent가 필요한 순간에 깔끔한 SVG asset을 바로 확보해야 할 때 유용합니다.
* **Browserbase**: 페치, 검색, 전체 session 자동화를 지원하는 관리형 헤드리스 브라우저를 실행합니다. Agent가 실제 웹 페이지를 불러오거나, JavaScript를 실행하거나, 일반 HTTP 요청을 차단하는 사이트와 상호작용해야 할 때 유용합니다.
