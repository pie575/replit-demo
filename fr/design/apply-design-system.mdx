---
title: "Appliquer un design system à une app existante"
description: "Reconstruisez un artifact existant selon votre design system — depuis le canvas ou le composeur — et comprenez ce que signifie l'avertissement sur le temps et les crédits."
icon: "paint-roller"
---

Un design system ne sert pas uniquement aux nouveaux projets : vous pouvez l&#39;appliquer à un artifact existant, et Agent en reconstruit l&#39;apparence selon le système.

<Steps>
  <Step title="Choisir la cible">
    Ouvrez le project contenant l&#39;artifact dont vous souhaitez modifier le style.
  </Step>

  <Step title="Appliquer le système">
    Depuis le canvas : sélectionnez la frame cible, ouvrez son menu **⋯** et choisissez **Apply design system**. Vous pouvez aussi en faire la demande dans le composeur (il s&#39;agit alors d&#39;une reconstruction par Agent) : *« applique mon design system à cette app. »*

    <Frame>
      <img src="/assets/mirror/ds-apply-menu-6d3bdcd14977.png" alt="Le menu à trois points de la frame avec l'option Apply design system mise en évidence" width="400" height="180" data-path="images/design/replit-design/ds-apply-menu.png" />
    </Frame>
  </Step>

  <Step title="Confirmer la reconstruction">
    Appliquer un système à un travail existant constitue une véritable reconstruction : un **avertissement sur le temps et les crédits** s&#39;affiche avant le lancement. C&#39;est normal : Agent régénère la couche de style de l&#39;artifact, il ne se contente pas de remplacer une feuille de style.
  </Step>

  <Step title="Vérifier le résultat">
    Comparez les écrans clés avec le système. Les modifications ultérieures continuent de s&#39;appuyer sur le système — si vous constatez un retour à l&#39;ancien style, signalez-le dans le Chat.
  </Step>
</Steps>
