지능형 모델 라우팅은 Replit이 작업에 맞는 모델을 선택하도록 합니다. 직접 선택하려면 프롬프트 박스에서 **Agent Mode**를 선택하고 **Power** 또는 **Max**를 선택한 다음 **Primary model** 섹션에서 모델을 선택하세요.

Free Mode는 항상 지능형 모델 라우팅을 사용합니다. Core 및 Pro 빌더는 Power Mode 또는 Max Mode에서 사용 가능한 모델을 선택할 수 있습니다. 가용성은 달라질 수 있으므로 Replit의 모델 목록이 사용자 계정의 기준이 됩니다.

## 모델의 Effort 설정하기

Effort는 선택한 모델이 응답에 얼마나 많은 추론을 사용하는지를 제어합니다. 이는 별도의 모드가 아니라 모델별 컨트롤입니다. 지원되는 레벨은 **Low**부터 **Max**까지이며, 각 모델은 권장 설정을 표시합니다.

작업에 더 깊은 추론이 필요할 때만 더 높은 Effort를 사용하세요. 복잡한 작업에서 더 높은 설정은 시간이 더 오래 걸리고 비용이 더 들 수 있습니다.
