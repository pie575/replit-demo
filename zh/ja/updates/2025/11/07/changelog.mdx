<div id="agent">
  ### 动画 Agent 图标
</div>

Agent 图标现在会在工作时显示动画，让你更直观地了解 Agent 正在积极处理任务。这项改进提升了响应感知速度，尤其是在初始规划阶段：中央聊天布局会显示更贴近请求的反馈，让你更容易了解 Agent 的工作状态。

<div id="agent-2">
  ### 规划流程中的 Agent 工具下拉菜单
</div>

Agent 工具下拉菜单现已支持在初始规划和任务列表确认流程中使用。这样，你从构建之初就能设定偏好的 Agent 配置，例如自主级别等选项。

  ### Agent 支持 @ 文件名
</div>

<div id="section-3">
  ### Remix 的 connector 支持
</div>

此前，Remix 一个使用了 connector 的 Replit 应用时，Remix 生成的 Repl 不会自动获得 connector 的使用授权，导致 integration 失效。我们已更新 Remix 流程，使其能够妥善处理 connector：

* Remix 时会提示用户设置所需的 connector
* Remix 过程中会明确显示需要配置哪些 integration
* Remix 后不会再出现 integration 失效的情况

了解更多关于 [Agent integration](/zh/replitai/integrations) 和[管理 connector](/zh/ja/replitai/managing-connectors) 的信息。

<div id="enterprise-2">
  ### 面向 Enterprise 管理员的分析仪表板
</div>

Enterprise 管理员现在可以使用全面的分析仪表板。这是包括 Meta 和 Atlassian 在内的众多 Enterprise 用户强烈期待的一项重要功能。该仪表板提供以下能力：

* **用户活动监控**：追踪整个组织的参与度与协作情况
* **资源使用情况追踪**：按用户和 Replit App 监控支出
* **部署监控**：掌握部署活动
* **成本管理**：让资源消耗与成本一目了然
