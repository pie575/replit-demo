<div id="general-agent">
  ### General Agent
</div>

<Frame>
  <img src="/assets/mirror/general-agent-240ff289e711.png" alt="General Agent 主视觉插图" width="1040" height="572" data-path="images/replitai/general-agent.png" />
</Frame>

Replit Agent 现已支持任意代码库，只要其语言或框架能在 NixOS 上运行即可！过去 Agent 仅限于特定 template，如今它还能协助处理 developer frameworks、GitHub 导入以及各类自定义 project 配置。此次重大扩展，让完整的 AI 编程辅助能力覆盖企业与高阶用户的工作流。

点击[这里](/zh/core-concepts/agent/general-agent)了解更多关于 General Agent 的信息。

<div id="plan-mode">
  ### Plan 模式
</div>

<Frame>
  <img src="/assets/mirror/plan-mode-overview-8077807c63b9.png" alt="处于 Plan 模式的 Agent 聊天界面" width="916" height="362" data-path="images/replitai/plan-mode-overview.png" />
</Frame>

Plan 模式带来了与 Replit Agent 对话的全新方式，侧重于提问、头脑风暴和规划工作。借助 Plan 模式，你可以让 Agent 为后续工作生成一份待办清单，再在 Build 模式中执行这些耗时较长的任务。

点击[此处](/zh/core-concepts/agent/plan-mode)了解有关 Plan 模式的更多信息。

  ## Enterprise
</div>

<div id="gcp-marketplace-integration">
  ### GCP Marketplace 集成
</div>

Enterprise 客户现在可以直接通过 Google Cloud Platform Marketplace 购买 Replit，并使用现有的 GCP 额度付款。这简化了采购流程，让拥有 GCP 预算的组织能够更轻松地将 Replit 引入自身的开发工作流。
