Добавляйте звук в свои приложения с помощью генерации аудио в Agent. Попросите Agent создать фоновую музыку, звуковые эффекты или закадровый голос — и он добавит аудио прямо в ваш проект.

Генерация аудио помогает создавать более насыщенные впечатления без студии звукозаписи, актёров озвучивания и сторонних инструментов. Создаёте ли вы игру, интерактивный обучающий курс или приложение, которому нужен голос, — Agent подготовит аудио, подходящее вашему проекту.

<div id="section">
  ## Что можно создать
</div>

Agent может создавать три вида аудио:

* **Музыка**: фоновые треки и тематические мелодии в том настроении и стиле, которые вы опишете.
* **Звуковые эффекты**: короткие клипы — щелчки, уведомления, свисты, игровые звуки.
* **Озвучка**: естественная озвучка и закадровый голос на основе предоставленного вами текста.

<div id="section-2">
  ## Использование
</div>

Генерация аудио встроена в Agent, поэтому включать её отдельно не нужно. Откройте Replit App с Agent и опишите, какое аудио вам нужно. Agent сам решит, когда сгенерировать аудио по вашему запросу, создаст клип и добавит его в проект.

<div id="agent">
  ### Когда Agent создаёт аудио
</div>

Agent создаёт аудио, когда вы запрашиваете звук в проекте:

| Сценарий использования   | Пример промпта                                                          |
| ------------------------ | ----------------------------------------------------------------------- |
| Фоновая музыка           | «Добавь спокойную фоновую музыку в моё приложение для медитации»        |
| Звуковые эффекты в игре  | «Создай звук получения монеты и звук прыжка для моей игры»              |
| Голосовая озвучка        | «Сгенерируй дружелюбный голос, который вслух читает шаги онбординга»    |
| Оповещения и уведомления | «Сделай короткий сигнал, который звучит при получении нового сообщения» |

<div id="section-4">
  ## Как аудио встраивается в приложение
</div>

Agent добавляет сгенерированное аудио в проект так же, как и любые другие ресурсы:

* **Автоматическое создание файлов**: сгенерированные аудиофайлы сохраняются непосредственно в проекте.
* **Обновление кода**: Agent подключает аудио к приложению, чтобы оно воспроизводилось в нужный момент.
* **Итерации**: попросите Agent изменить настроение, длительность, голос или стиль — и он сгенерирует аудио заново.

<div id="section-5">
  ## Оплата
</div>

Генерация аудио — это сервис Agent. Agent тарифицирует её по расценкам провайдера, а стоимость списывается с кредитов Replit. Информация о списаниях отображается на [странице Usage](/ru/ko/billing/managing-spend).

<Note>
  Генерация аудио в Replit работает на технологии [ElevenLabs](https://elevenlabs.io/), которая создаёт высококачественную музыку, звуковые эффекты и речь.
</Note>
