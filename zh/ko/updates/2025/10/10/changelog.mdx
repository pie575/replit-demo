<div id="agent">
  ### Agent 使用成本可见性
</div>

在任务运行期间实时查看 Agent 使用成本。打开聊天标题栏抽屉即可监控当前活动任务的支出——对于耗时较长的高自主性运行尤为实用。

<div id="escape">
  ### 可视化选择/编辑模式中的 Escape 键
</div>

按 Escape 键即可退出可视化选择模式或返回构建模式。这个小小的快捷键，让你的工作流程更加顺畅。

<div id="agent-2">
  ### 更快停止 Agent
</div>

在工作区中停止或启动 Agent 时响应更迅速，等待时间更短。

<div id="github">
  ### GitHub 导入改进
</div>

导入 GitHub 项目时，你将看到实时进度，而不再是笼统的提示信息，导入速度也更快了。

<div id="section-3">
  ### 依赖项漏洞扫描
</div>

安全扫描器现已支持检测 Go、JavaScript、Python 和 Rust 项目的依赖项漏洞，更多语言即将支持。

<div id="section-4">
  ### 网页视图日志体验
</div>

在同一处即可查看 Agent 所用的网页视图日志和控制台输出，让调试更轻松。

<div id="section-6">
  ### 面向团队的支持席位访问
</div>

通过不计入账单的访客账号添加 Replit 支持团队。需要帮助时，你可以仅授予特定应用的访问权限，工作区的隐私始终由你掌控。
