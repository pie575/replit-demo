<div id="agent">
  ### 使用 Agent 构建全栈移动应用
</div>

<Frame>
  <img src="/assets/mirror/cleanshot-2025-12-05-at-12-27-22-2x_273f89390642-dc03158b7d7f.png" width="1082" height="504" data-path="images/changelog/2025-12-05/cleanshot-2025-12-05-at-12-27-22-2x_273f89390642.png" />
</Frame>

Agent 现在可以构建带有完整后端服务器的[移动 Apps](/zh/ja/features/artifact-types/building-mobile-apps)。[AI 集成](/zh/replitai/integrations)、[Database](/zh/ja/features/data-and-storage/sql-database)、[对象存储](/zh/ja/features/data-and-storage/object-storage)、连接器等强大功能均可使用，充分满足生产级移动开发的各项需求。

<div id="database">
  ### Database 正式发布
</div>

全新的 [Database](/zh/ja/features/data-and-storage/sql-database) 现已成为所有新建 Replit Apps 的默认配置。此次升级增强了可靠性和基础设施控制能力，让项目性能更出色、数据管理更轻松。

<div id="fast-mode">
  ### Fast Mode 更加自主
</div>

<Frame>
  <img src="/assets/mirror/image_4f661377d428-8454460e1cca.png" width="720" height="212" data-path="images/changelog/2025-12-05/image_4f661377d428.png" />
</Frame>

[Lite 模式](/zh/core-concepts/agent/agent-modes) (原 Fast Mode) 现在可以独立完成更多任务，遇到较大改动时则会建议改用 Agent。快速迭代，无缝交接，助你更快完成构建。

<div id="section-3">
  ### 更快连接第三方服务
</div>

连接器支持已改进，让你更快地连接第三方服务。只需提供配置，无需复杂的设置流程，即可添加大多数基于 API 密钥的服务。同时还增强了多密钥配置和健康检查功能，让[集成](/zh/replitai/integrations)更加可靠。
