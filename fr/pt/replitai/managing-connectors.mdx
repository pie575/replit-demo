Vous pouvez gérer les connecteurs afin que votre équipe utilise les intégrations de manière cohérente et sécurisée. Les options disponibles dépendent de votre forfait :

* **Core et Pro** : La gestion des connecteurs est disponible dans les **workspaces collaboratifs**. L’administrateur du compte configure et gère les connexions pour ce workspace ; les développeurs peuvent les utiliser dans les applications de ce workspace.
* **Enterprise** : Gestion des connecteurs à l’échelle de l’organisation avec des contrôles avancés : clients OAuth personnalisés, contrôles d’accès aux clés API et utilisation de vos propres clés.

<div id="principais-recursos">
  ## Principales fonctionnalités
</div>

* **Gestion centralisée** : l’administrateur configure un service une seule fois ; les développeurs l’utilisent dans les applications de ce workspace.
* **Visibilité et audit** : voyez quelles applications et quels membres utilisent quels services.
* **Consentement et révocation par application** : révoquez ou renouvelez les accès sans modifier le code.

**Enterprise uniquement :**

* **Contrôles d’accès basés sur les rôles** : autorisations selon le principe du moindre privilège et contrôles d’accès appliqués aux clés API.
* **Utilisez votre propre OAuth** : utilisez des clients OAuth détenus par l’organisation avec des portées personnalisées.
* **Utilisez votre propre clé OpenAI** : utilisez votre propre clé API OpenAI au lieu de l’infrastructure standard de Replit.

<div id="como-funciona">
  ## Comment ça fonctionne
</div>

<Steps>
  <Step title="L’administrateur configure un service">
    L’administrateur configure un service une seule fois à l’aide des identifiants.
  </Step>

  <Step title="L’administrateur approuve l’accès">
    L’administrateur autorise les groupes pouvant utiliser le connecteur (Enterprise) ou le met à la disposition du workspace collaboratif (Core/Pro).
  </Step>

  <Step title="Les développeurs utilisent le connecteur">
    Les membres créent des applications avec ce service en le demandant à Agent dans le workspace ou l’organisation.
  </Step>

  <Step title="L’administrateur surveille l’utilisation">
    Les administrateurs peuvent surveiller quels membres et quelles applications utilisent quels services.
  </Step>
</Steps>

<div id="segurana-e-governana">
  ## Sécurité et gouvernance
</div>

* Les identifiants et jetons sont gérés par la plateforme et ne sont pas stockés dans des applications individuelles.
* Révocation et rotation centralisées, sans modification du code.
* Enterprise : accès à portée limitée, avec des autorisations fondées sur le principe du moindre privilège et une configuration OAuth personnalisée facultative.

<div id="configurao-e-gerenciamento">
  ## Configuration et gestion
</div>

<div id="ativar-novos-conectores">
  ### Activer de nouveaux connecteurs
</div>

<Steps>
  <Step title="Accédez à Intégrations">
    Dans votre workspace collaboratif (Core/Pro) ou depuis la page d’accueil de l’organisation (Enterprise), ouvrez la page **Intégrations**.
  </Step>

  <Step title="Activer un nouveau connecteur">
    Sélectionnez **Activer un nouveau connecteur** dans l’angle supérieur droit.
  </Step>

  <Step title="Sélectionnez le service">
    Sélectionnez le service que vous souhaitez activer (par exemple : Notion, GitHub, Google, Outlook, Dropbox, Salesforce).
  </Step>

  <Step title="Configurez le connecteur">
    Activez le connecteur à l’aide de la configuration par défaut. Avec **Enterprise** uniquement, vous pouvez créer un connecteur OAuth personnalisé (par exemple : portées Drive `.../auth/drive.file`, `.../auth/drive.install`).
  </Step>

  <Step title="Envoyer">
    Sélectionnez **Envoyer**.
  </Step>
</Steps>

<div id="configurar-acesso-enterprise">
  ### Configurer l’accès (Enterprise)
</div>

1. Après avoir activé un connecteur, sélectionnez **Gérer**.
2. Accordez l’accès à des groupes spécifiques selon vos besoins.

<div id="modificar-conectores">
  ### Modifier les connecteurs
</div>

* Après avoir activé un connecteur, sélectionnez **Gérer**.
* La suppression d’un connecteur le supprime pour tous les développeurs de ce workspace (Core/Pro) ou de cette organisation (Enterprise).
* Dans Enterprise, vous pouvez modifier les portées des connecteurs OAuth personnalisés.

<div id="use-sua-prpria-chave-openai-enterprise">
  ### Utilisez votre propre clé OpenAI (Enterprise)
</div>

Les clients Enterprise peuvent utiliser les connecteurs pour utiliser leur propre clé d’API OpenAI plutôt que l’infrastructure d’IA standard de Replit. Ils peuvent ainsi tirer parti de leurs accords existants avec OpenAI et gérer l’utilisation de l’IA depuis leur propre compte.
