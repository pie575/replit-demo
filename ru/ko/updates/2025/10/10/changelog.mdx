<div id="agent">
  ### Прозрачность расходов на использование Agent
</div>

Отслеживайте расходы на Agent в реальном времени, пока выполняется задача. Откройте выдвижную панель в заголовке чата, чтобы следить за тратами по активной задаче, — это особенно полезно для длительных запусков с высокой автономностью.

<div id="escape">
  ### Клавиша Escape в режиме визуального выбора/редактирования
</div>

Нажмите Escape, чтобы выйти из режима визуального выбора или вернуться в режим сборки. Небольшая горячая клавиша, которая помогает не прерывать рабочий процесс.

<div id="agent-2">
  ### Более быстрая остановка Agent
</div>

Остановка и запуск Agent в рабочем пространстве теперь происходят быстрее — ждать приходится меньше.

<div id="github">
  ### Улучшения импорта из GitHub
</div>

Во время импорта из GitHub вместо общего сообщения теперь отображается ход выполнения в реальном времени, а сам импорт стал быстрее.

<div id="section-3">
  ### Сканирование уязвимостей в зависимостях
</div>

Сканер безопасности теперь находит уязвимости в зависимостях для Go, JavaScript, Python и Rust — поддержка других языков появится в ближайшее время.

<div id="section-4">
  ### Логи веб-представления
</div>

Упростите отладку: логи веб-представления и вывод консоли теперь в одном месте — те же самые логи, которые использует Agent.

<div id="section-6">
  ### Доступ к местам поддержки для команд
</div>

Добавляйте сотрудников поддержки Replit как гостевые учётные записи, которые не учитываются при оплате. Вы предоставляете им ограниченный доступ к конкретным приложениям только тогда, когда нужна помощь, а конфиденциальность рабочего пространства остаётся под вашим контролем.
