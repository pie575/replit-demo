选择托管 workspace 和已部署应用基础设施的区域，以满足数据驻留要求并降低延迟。Replit 提供独立的地理位置设置，您可以分别管理开发环境和已部署应用的托管区域。

<div id="compare-a-geografia-do-workspace-e-a-de-publicao">
  ## 比较 Workspace 地理位置与部署地理位置
</div>

| 方面         | Workspace 地理位置   | 部署地理位置         |
| :--------- | :--------------- | :------------- |
| **控制内容**   | Workspace 中的开发资源 | 已部署应用的计算和存储资源  |
| **设置时间**   | 创建 Workspace 时   | 部署项目时          |
| **位置影响**   | 确定新项目和资源所在的区域    | 将已部署产物集中在同一地区域 |
| **之后能否更改** | 否                | 否              |

Workspace 地理位置和部署地理位置无需相同。

如需了解如何在创建 Workspace 时选择开发区域，请参阅 [Workspace 地理位置](/zh/pt/features/collaboration/workspace-geography)。

<div id="geografia-de-publicao">
  ## 部署地理位置
</div>

部署项目时，请设置部署地理位置。默认情况下，Replit 会推荐离您最近的部署地理位置。这有助于降低应用访客的延迟，并满足数据驻留要求。

选择部署地理位置后，项目的所有已部署产物 (如计算资源、数据库和对象存储) 都会自动部署在同一区域。特定部署地理位置的代理也有助于降低应用访客的延迟。

<div id="selecione-uma-geografia-de-publicao">
  ### 选择部署地理位置
</div>

如需选择不同于推荐地理位置的位置：

<Steps>
  <Step>
    在您的 Replit 项目中打开 **Publishing** 工具。
  </Step>

  <Step>
    展开 **Advanced** 设置。
  </Step>

  <Step>
    在 **Geography** 下拉菜单中选择您偏好的地理位置。
  </Step>

  <Step>
    选择 **Publish**，将项目部署到所选地理位置。
  </Step>
</Steps>

<div id="imponha-uma-geografia-em-projetos-publicados">
  ### 为已部署项目强制指定部署地理位置
</div>

Enterprise 管理员可以为组织中的所有项目强制指定部署地理位置。设置该策略后，组织内的构建者将部署到指定区域。该策略仅适用于尚未部署的项目——已部署到其他区域的项目不受影响。

<Note>
  强制指定部署地理位置是 Enterprise 功能。要详细了解 Enterprise 套餐，请参阅[定价](https://replit.com/pricing/)。
</Note>

<Steps>
  <Step>
    前往您的 **Account settings**。
  </Step>

  <Step>
    选择 **Advanced**。
  </Step>

  <Step>
    选择所有首次部署的项目应使用的区域。
  </Step>
</Steps>

<div id="limitaes-da-geografia-de-publicao">
  ### 部署地理位置的限制
</div>

选择部署地理位置前，请注意以下限制：

* **部署后无法更改地理位置。** 将项目部署到某个地理位置后，该选择即为永久性设置。无法将已部署的项目迁移到其他地理位置。
* **开发位置和部署位置可能不同。** 对象存储等资源可在部署前创建，其所在位置可能与部署地理位置不同。

<div id="geografias-disponveis">
  ## 可用区域
</div>

workspace 区域和部署地理位置提供不同的区域选项：

| 区域                | workspace 中可选 | 部署时可选 |
| :---------------- | :------------ | :---- |
| **North America** | 是             | 是     |
| **Europe (EU)**   | 是             | 是     |
| **Asia**          | 是             | 是     |
| **South America** | 否             | 是     |
| **Australia**     | 否             | 是     |

<Note>
  仅 Pro 客户可选择 workspace 区域。
  Core、Pro 和 Enterprise 客户可选择部署地理位置。
  Free 客户默认部署在北美。
</Note>
