今週、Assistant がリリースされました—複数のファイルを編集し、変更を直接適用できる新しい AI ツールです。

<Note>
  **更新（2025年12月）：** Assistant は廃止されました。素早いピンポイント編集には、[Agent の Lite モード](/core-concepts/agent/agent-modes)をご利用ください。計画・討論には、[Agent の Plan モード](/core-concepts/agent/plan-mode)をご利用ください。
</Note>

Assistant はチャットと素早い編集に最適化されています。Agent で MVP を作成し、その後 Assistant で素早い編集を行うというワークフローが一般的です。

Assistant のいくつかのハイライトをご紹介します:

* **軽量:** Assistant はチャットと素早い編集に最適化されており、複数のファイルを編集して変更を直接適用する機能が追加されました。
* **メンションとスクリーンショット:** プロンプトでファイルや URL をメンションしてください。Assistant が URL をスクレイピングするか、スクリーンショットを撮ってくれます。
* **ロールバック:** Assistant は自動的にチェックポイントを作成し、編集を差分としてプレビューし、ワンクリックでロールバックできます。
* **柔軟性:** Assistant は技術スタックに関係なく、あらゆる Replit App で動作します。既存のプロジェクトを持ち込むか、Agent で新鮮に始めてください。
* **より美しいアプリ:** レスポンシブ React アプリのサポートが改善され、見事なアプリを作成できます。
* **課金の更新:** Agent の使用制限がすべて撤廃され、サブスクリプションに含まれるクレジットが増加しました。

## プラットフォームの更新

### Assistant の機能

Replit Assistant はチャットと素早い編集のために構築された軽量な AI ツールです。複数のファイルを自分で編集して直接適用できます。

Assistant はコンテキストを与えると真価を発揮します—特定の機能、ファイル（`@file` でメンション）、URL（そのまま貼り付ける）などが含まれます。

Assistant はより速く反復するのに役立ち、Agent より約 5 倍少ないクレジットを使用します。

### 簡単なロールバック

Assistant は自動的にチェックポイントを作成し、編集を差分として簡単にプレビューし、何かおかしいと思ったらワンクリックでロールバックできます。

**React アプリ**のサポートが改善され、アプリが最高の状態で表示・動作することが保証されます。

### 高速スクレイピング / スクリーンショット

**Assistant** または **Agent** を使用して、任意のサイトのコンテンツをスクリーンショットまたはスクレイピングしてプロンプトに直接取り込めます。

URL を貼り付けるだけで、Replit がページのスクリーンショットを撮るかコンテンツをスクレイピングするかを提案します。

いつも通り、画像をプロンプトに添付したり、`@file` でファイルをメンションすることもできます。

### 好評の使用状況の更新

* **使用量クォータなし:** Agent の使用制限に別れを告げましょう。
* **サブスクライバーへのより多くのクレジット:** Core のサブスクライバーはクレジットが増加しました。
