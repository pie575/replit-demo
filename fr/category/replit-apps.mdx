<div id="what-is-a-replit-app">
  ## Qu’est-ce qu’une Replit App ?
</div>

Les Replit Apps sont des projets hébergés dans le cloud qui contiennent du code, des données et des ressources.
Vous pouvez les créer, les exécuter et les publier depuis un environnement sécurisé et isolé.

Les Replit Apps s’intègrent aux outils suivants du Project Editor pour offrir
une expérience de développement fluide :

* **Outils basés sur l’IA** : utilisez Agent pour créer, déboguer et expliquer votre code.
* **Collaboration** : travaillez avec d’autres personnes en temps réel sur la même app.
* **Publishing** : publiez votre app dans le cloud en un seul clic.

<div id="key-features">
  ## Fonctionnalités clés
</div>

Les Replit Apps offrent les fonctionnalités suivantes :

* **Sans configuration :** Créez des apps ou écrivez du code directement sur Replit.com, sans installation ni configuration.
* **Enregistrement automatique :** Votre projet enregistre continuellement vos modifications dans le cloud et vous permet de reprendre le codage depuis n&#39;importe quel navigateur web.
* **Contrôle de version :** Suivez les modifications, consultez l&#39;historique des fichiers et synchronisez vos fichiers sans configuration grâce aux systèmes de contrôle de version de Replit.
* **Contrôles de visibilité publique/privée :** Déterminez qui peut consulter, exécuter ou créer un Remix de votre app grâce aux paramètres de confidentialité.
* **Publishing :** Publiez votre code dans le cloud sans modifier de paramètres de configuration complexes.
* **URL d&#39;app personnalisées :** Obtenez une URL unique pour votre app ou attribuez-lui un domaine personnalisé pour une présence plus professionnelle.

<Info>
  Les fichiers téléversés dans le système de fichiers de votre projet sont disponibles uniquement pendant le développement et
  ne sont pas accessibles à votre app publiée ni aux autres créateurs. Utilisez [Object
  Storage](/fr/features/data-and-storage/object-storage) pour gérer les
  téléversements des créateurs et servir des fichiers, et [Replit
  Database](/fr/features/data-and-storage/sql-database) pour stocker et
  récupérer les données de votre app et de ses utilisateurs.
</Info>

Pour en savoir plus sur les outils de Project Editor qui simplifient la création de Replit Apps, consultez la [présentation de Project Editor](/fr/learn/projects-and-artifacts/project-editor/).

<div id="how-it-works">
  ## Fonctionnement
</div>

Lorsque vous créez une Replit App, Replit met en place un espace privé dans le cloud pour votre projet.
À mesure que vous ajoutez des fonctionnalités et modifiez votre app, Replit enregistre automatiquement vos modifications
afin que vous puissiez reprendre l’édition depuis n’importe quel navigateur web.

Replit fournit des environnements préconfigurés avec tous les composants nécessaires.
Vous pouvez ainsi commencer à créer votre app immédiatement, sans vous soucier de la
configuration du serveur, de la base de données ou de la gestion de l’environnement.

Replit attribue automatiquement à chaque Replit App une adresse web unique où vous
pouvez prévisualiser votre app pendant que vous y travaillez. Lorsque vous êtes prêt à partager votre
création, vous pouvez la publier en quelques clics pour la rendre accessible 24 h/24, 7 j/7.

<div id="storage-overview">
  ## Présentation du stockage
</div>

Replit propose quatre principaux types de stockage pour répondre aux besoins de votre application en matière de données. Chaque type de stockage répond à des cas d’usage différents et présente des limites spécifiques selon votre forfait.

<Info>
  Les limites de stockage incluent toutes les données stockées par votre application, y compris les packages et dépendances installés.
</Info>

| Type de stockage                                                | Description                      | Cas d’usage                                                         | Persistance                                                  | Limites du forfait                                                                                                                                       |
| --------------------------------------------------------------- | -------------------------------- | ------------------------------------------------------------------- | ------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Stockage de fichiers**                                        | Fichiers de votre projet         | Code d’application, ressources statiques, fichiers de configuration | Conservé lors de la publication, réinitialisé au redémarrage | Starter : {StarterWorkspaceStorage}<br />Core : {CoreWorkspaceStorage}<br />Pro : {TeamsWorkspaceStorage}<br />Enterprise : {EnterpriseWorkspaceStorage} |
| **[Base de données](/fr/features/data-and-storage/sql-database/)** | Stockage de données structurées  | Profils utilisateur, scores de jeu, catalogues de produits          | Entièrement persistante entre les sessions                   | 20 Go par base de données de développement<br />Les bases de données de production sont facturées selon le temps de calcul et le stockage                |
| **[App Storage](/fr/features/data-and-storage/object-storage/)**   | Données et médias non structurés | Images, vidéos, PDF, documents                                      | Entièrement persistante entre les sessions                   | Paiement à l’utilisation<br />Facturé selon le stockage et la bande passante                                                                             |
| **[Secrets](/fr/core-concepts/project-editor/app-setup/secrets/)** | Données sensibles chiffrées      | Clés API, identifiants, chaînes de connexion                        | Entièrement persistante et chiffrée                          | Aucune limite spécifique<br />Inclus avec tous les forfaits                                                                                              |
