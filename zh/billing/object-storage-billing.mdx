<div id="billing-categories">
  ## 计费类别
</div>

Replit 将 App Storage 费用分为以下类别：

* **存储**：每月使用的数据存储容量。所有存储对象的最低计费时长为七天。
* **数据传输**：整个月内上传和下载的数据总量。
* **基本操作**：与更新存储桶和对象相关的操作。详情请参阅 <a href="https://cloud.google.com/storage/pricing" target="_blank">Google Cloud Storage 定价</a>中的 A 类操作。
* **高级操作**：所有其他云对象存储操作，包括检索对象和存储桶的配置及元数据。详情请参阅 <a href="https://cloud.google.com/storage/pricing" target="_blank">Google Cloud Storage 定价</a>中的 B 类操作。

  ## 价格

| 类别               | 价格                                           |
| ---------------- | -------------------------------------------- |

| App Storage 数据传输 | 每 GiB {ObjectStorageDataTransfer}            |
