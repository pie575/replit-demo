<div id="venda-produtos-fsicos-com-o-shopify">
  ### Продавайте физические товары через Shopify
</div>

Теперь вы можете создать интернет-магазин и продавать физические товары. Попросите Agent создать магазин, и он создаст для вас магазин Shopify, добавит товары и настроит корзину и оформление заказа. Agent предоставит ссылку, по которой вы сможете получить магазин, а затем вы выберете тариф Shopify и подключите платежи, чтобы запустить магазин.

Подробнее о [подключении Shopify](/ru/pt/features/integrations/shopify).

<div id="crie-aplicativos-de-dados-no-microsoft-fabric">
  ### Создавайте приложения для работы с данными в Microsoft Fabric
</div>

Теперь в Replit можно создавать приложения для работы с данными на базе ИИ и публиковать их напрямую в Microsoft Fabric. Начните с шаблона Microsoft Fabric, подключите семантическую модель Power BI и попросите Agent создать дашборды и внутренние инструменты на основе управляемых корпоративных данных, сохраняя аутентификацию и политики доступа в Fabric.

<div id="domnios-personalizados-configuram-seu-prprio-dns">
  ### Пользовательские домены автоматически настраивают DNS
</div>

Подключить собственное доменное имя теперь гораздо проще. При привязке домена Replit настраивает необходимые DNS-записи через Entri, поэтому вам не нужно вручную копировать записи у регистратора домена. Выберите домен, подтвердите выбор — остальное сделает Replit.

Подробнее о [пользовательских доменах](/ru/pt/features/publishing/custom-domains).

<div id="melhore-seu-ranking-de-busca-com-o-seo-agent">
  ### Улучшите позиции в поисковой выдаче с SEO Agent
</div>

SEO Agent анализирует опубликованное приложение и выявляет проблемы, которые мешают поисковым системам и инструментам ИИ находить его. Для каждой найденной проблемы доступно исправление в один клик, которое можно просмотреть и применить. Чтобы запустить анализ, откройте панель **Growth** в проекте.

<div id="use-o-stripe-em-workspaces-colaborativos">
  ### Используйте Stripe в совместных рабочих пространствах
</div>

Stripe теперь поддерживается в совместных рабочих пространствах, поэтому вся команда может вместе создавать, тестировать и монетизировать одно приложение. Все участники рабочего пространства могут работать с подключённой учётной записью Stripe вместо того, чтобы настраивать платежи по отдельности.

Подробнее о [платежах с Stripe](/ru/pt/features/monetization/stripe-payments).
