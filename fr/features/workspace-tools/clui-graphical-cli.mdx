CLUI (Command Line User Interface) est la barre de commandes interactive de Replit qui vous permet d’effectuer rapidement diverses actions sans avoir à parcourir les menus. Elle allie l’efficacité d’une ligne de commande à une interface graphique.

<div id="features">
  ## Fonctionnalités
</div>

CLUI permet d&#39;exécuter de puissantes commandes dans trois contextes différents de Replit :

* **Gestion des paramètres** : gérez vos paramètres, consultez les avertissements et restaurez les Replit Apps supprimées
* **Navigation rapide** : passez d&#39;une Replit App à l&#39;autre et accédez aux fonctionnalités courantes grâce à des raccourcis
* **Opérations dans le workspace** : trouvez des fichiers, recherchez dans le code et accédez aux outils de votre environnement de développement

<div id="usage">
  ## Utilisation
</div>

<div id="account-clui">
  ### Account CLUI
</div>

L’Account CLUI vous permet de gérer vos paramètres, vos Teams et vos Replit Apps supprimées.

**Comment y accéder** : accédez à la [page CLUI](https://replit.com/~/cli), saisissez une commande dans le champ de saisie, puis appuyez sur Entrée pour l’exécuter.

<Accordion title="Commandes Account">
  Saisissez `account` pour gérer vos paramètres :

  * **view-warns** : affiche les avertissements qui vous ont été adressés
  * **change-username** : modifie votre nom d’utilisateur (cette opération n’est possible qu’une seule fois)
</Accordion>

<Accordion title="Commandes de la corbeille">
  Saisissez `trash` pour gérer les Replit Apps supprimées :

  * **restore &lt;title&gt;** : restaure une Replit App supprimée à partir de son titre (restaure la plus récemment supprimée si plusieurs portent le même nom)
  * **view** : affiche vos Replit Apps supprimées les plus récentes
</Accordion>

<Accordion title="Commandes Team">
  Saisissez `team` pour gérer vos Teams :

  * **view** : affiche les membres d’une Team dont vous faites partie à l’aide de son nom d’utilisateur
  * **fork-repl-to-project** : duplique une Replit App existante pour créer un Project d’équipe
</Accordion>

<Accordion title="Commande clear">
  Saisissez `clear` pour effacer de l’écran toutes les commandes que vous avez exécutées
</Accordion>

<div id="shortcuts-clui">
  ### Raccourcis CLUI
</div>

Les raccourcis CLUI permettent d’accéder rapidement aux fonctionnalités courantes de Replit depuis n’importe quelle page.

<Frame>
  <img src="/assets/mirror/shortcuts-clui-768d49b44785.png" alt="Raccourcis CLUI" width="689" height="291" data-path="images/getting-started/shortcuts-clui.png" />
</Frame>

**Comment y accéder :** Appuyez sur **CMD/CTRL + K** ou cliquez sur l’icône de recherche dans la barre de navigation supérieure de la plupart des pages Replit.

<Accordion title="Commandes disponibles">
  * **Rechercher :** Recherchez des Replit Apps, des Templates, du code, des personnes et bien plus encore sur Replit
  * **Nouveau :** Créez une Replit App
  * **Mes Replit Apps :** Parcourez vos Replit Apps et accédez-y
  * **Mon code :** Recherchez dans le code de toutes vos Replit Apps
</Accordion>

<div id="workspace-clui">
  ### CLUI du Workspace
</div>

Le CLUI du Workspace vous permet d’effectuer des actions, d’accéder à des outils, de trouver des fichiers et de rechercher dans votre code lorsque vous travaillez dans une Replit App.

<Frame>
  <img src="/assets/mirror/ws-clui-81764b3d111b.png" alt="CLUI du Workspace" width="429" height="202" data-path="images/getting-started/ws-clui.png" />
</Frame>

**Accès** : appuyez sur **CMD/CTRL + K** ou cliquez sur l’icône de recherche dans l’angle supérieur gauche du Workspace.

<Accordion title="Actions courantes">
  * **Trouver des fichiers** : localisez rapidement des fichiers dans votre projet
  * **Rechercher dans le code** : trouvez des extraits de code spécifiques dans vos fichiers
  * **Accéder aux outils** : ouvrez n’importe quel outil ou panneau disponible dans le Workspace
  * **Exécuter des commandes** : exécutez des commandes propres au workspace
</Accordion>
