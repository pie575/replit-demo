Replit App настраивается с помощью двух файлов: `.replit` и `replit.nix`. Они влияют на работу Replit App — от выполнения кода до доступных инструментов разработки и языков программирования.

По умолчанию эти файлы конфигурации скрыты. Чтобы отобразить их в Replit App, выберите «Показать скрытые файлы» в меню дерева файлов.

<div id="arquivo-replitnix">
  ## Файл `replit.nix`
</div>

Replit использует `Nix` для управления пакетами и средами. Файл `replit.nix` позволяет:

**Указывать системные зависимости:** Точно определять, какие программные пакеты необходимы вашему Replit App. Ими управляет Nix — менеджер пакетов.

**Создавать воспроизводимые среды:** Обеспечивать согласованность и воспроизводимость среды разработки, что особенно полезно для совместных проектов и тестирования на разных системах.

Вы можете визуально управлять пакетами Nix с помощью инструмента `Dependencies`. Подробнее см. в руководстве [Системные зависимости](/ru/pt/core-concepts/project-editor/app-setup/dependency-management#system-dependencies).

Чтобы настроить пакеты в файле `replit.nix`, перечислите [пакеты Nix](https://search.nixos.org/packages) в массиве `deps`, добавив к ним префикс `pkgs.`. Все изменения будут синхронизированы после перезагрузки Shell.

```nix theme={null}
{ pkgs }: {
  deps = [
    pkgs.nodejs-19_x
    pkgs.nodePackages.typescript-language-server
    pkgs.yarn
    pkgs.replitPackages.jest
  ];
}
```

<div id="arquivo-replit">
  ## Файл `.replit`
</div>

Файл `.replit` определяет поведение вашего Replit App. В нём используется [формат конфигурации](https://toml.io/en/) `toml`. Вот некоторые основные параметры, которые можно настроить:

**Команда запуска:** Укажите команду, которая выполняется при нажатии кнопки Run. В каждом template есть команда запуска по умолчанию, позволяющая сразу запустить код. Для более кастомизированных и сложных приложений используйте [Workflows](/ru/pt/core-concepts/project-editor/app-setup/workflows).

**Протокол языкового сервера (LSP):** Предоставляет такие возможности, как автодополнение, навигация по коду, подсветка синтаксиса, линтинг и отображение ошибок в реальном времени.

**Переменные окружения:** Задавайте и управляйте переменными окружения, необходимыми для корректной работы приложений.

**Зависимости и пакеты:** Управляйте установкой и настройкой пакетов непосредственно через файл `.replit`, чтобы все необходимые инструменты были доступны в вашем Replit App при запуске. Визуально управлять зависимостями можно с помощью инструмента `Dependencies`. Подробнее — в руководстве по [системным модулям](/ru/pt/core-concepts/project-editor/app-setup/dependency-management#advanced-configuration).

Для приложений Python файл `.replit` по умолчанию выглядит так:

```toml theme={null}
entrypoint = "main.py"
modules = ["python-3.10:v18-20230807-322e88b"]

[nix]
channel = "stable-23_05"

[unitTest]
language = "python3"

[gitHubImport]
requiredFiles = [".replit", "replit.nix"]

[deployment]
run = ["python3", "main.py"]
deploymentTarget = "cloudrun"
```

Теперь, когда вы знакомы со стандартными настройками файла `.replit`, воспользуйтесь следующими разделами, чтобы узнать, как настроить базовые и расширенные параметры для вашего Replit App.

<div id="configurando-definies-bsicas">
  ## Настройка основных параметров
</div>

<div id="entrypoint">
  ### Точка входа
</div>

Это основной файл вашего проекта. Если не задать свойство `run`, `entrypoint` — это файл, выполняемый средой выполнения.

```toml theme={null}
entrypoint = "<file-name>.py"
```

<div id="comando-run">
  ### Команда `Run`
</div>

Свойство `run` в файле `.replit` определяет команду запуска или последовательность команд, выполняемых при нажатии кнопки `Run` в среде Replit. Команду `Run` можно указать как строку с командой для выполнения или как массив строк, содержащий команду и отдельные аргументы.

Распространённые способы настройки команды `Run`:

* **Одна команда:**
  Этот пример показывает, как передать одну команду для запуска непосредственно в Replit App. Если добавить это в файл `.replit`, при нажатии кнопки `Run` в панели `Console` отобразится приветствие:
  **Пример:** `run = "echo 'Hello, Replit!'"`

* **Явные аргументы:**
  Иногда полезно указать всё явно, чтобы не приходилось обрабатывать кавычки или правила подстановки Shell. Вы можете переписать приведённый выше пример, разделив аргументы.
  Обратите внимание: теперь не нужно одновременно использовать `'` и `"`, поскольку приветствие явно передаётся как первый и единственный аргумент для `echo`:
  **Пример:** `run = ["echo", "Hello, Replit!"]`

* **Несколько команд:**
  Этот пример показывает, как одновременно запускать несколько процессов, например фронтенд и бэкенд. Это может быть полезно при разработке бэкенда на Python и фронтенда на TypeScript, когда каждый сервер использует отдельный порт:
  **Пример:** `run = "python -m app & npm run start & wait"`

<div id="gerenciamento-de-processos">
  #### Управление процессами
</div>

Хотя несколько команд можно запускать одновременно с помощью `&`, для более удобного разделения логов разных сервисов можно [добавить системные зависимости](/ru/pt/core-concepts/project-editor/app-setup/dependency-management#system-dependencies), например [`process-compose`](https://github.com/F1bonacc1/process-compose), чтобы эффективнее управлять несколькими процессами.

<div id="fase-de-build">
  #### Этап `Build`
</div>

Для некоторых языков или сред выполнения перед запуском кода с помощью `run` требуется отдельный этап компиляции. Это касается как компилируемых языков, таких как TypeScript, Golang или Java, так и возможности задать команду для сброса среды, данных или конфигурации перед следующим вызовом `run`.

* **Компиляция:**
  В репозитории TypeScript перед запуском кода может потребоваться выполнить `tsc`.
  **Пример:**

```toml theme={null}
build = "tsc app.ts"
run = "node app.js"
```

<div id="incluindo-variveis-de-ambiente">
  #### Добавление переменных окружения
</div>

Чтобы передать переменные окружения сервису перед запуском, разверните свойство `run` в [таблицу](https://toml.io/en/v1.0.0#table).

Это более сложное изменение, которое, вероятно, потребует переместить свойство `run = "..."` в файле `.replit`.

Следующий diff показывает, как указать команду в `args` раздела `[run]`, а также переменную `NAME` в `[run.env]`:

```diff theme={null}
-run = ["bash", "-c", "echo \"Hello, $NAME!\""]

 modules = ["nodejs-20"]

 hidden = [".pythonlibs"]

+# Новый [run] нужно переместить ниже всех
+# свойств верхнего уровня, которые не начинаются с `[`!
+[run]
+args = ["bash", "-c", "echo \"Hello, $NAME!\""]
+
+[run.env]
+NAME="Replit"

 [nix]
 channel = "stable-23_11"
```

<div id="interatividade">
  #### Интерактивность
</div>

Интерактивные программы также можно запускать с помощью кнопки `Run`, что позволяет отличать среду разработки от терминала, в котором выполняется программа.
Рассмотрим следующий скрипт счётчика:

**Пример**

```toml theme={null}
[run]
args = ["bash", "-c", """
count=0
while read -p "$PROMPT" -r next && [ -n "$next" ]; do
    count=$((count+next))
done
echo "The numbers you entered sum to $count!"
"""]

[run.env]
PROMPT = "Next number ([Enter] to end): "
```

<div id="opes-de-configurao-avanada">
  ## Расширенные параметры конфигурации
</div>

Ознакомьтесь с подробными параметрами конфигурации вашего Replit App. Вы можете настроить среду разработки, управлять командами запуска, подключать языковые сервисы и работать с зависимостями.

| **Конфигурация** | **Ключ**                            | **Значение/пример**                         | **Описание**                                                                                   |
| ---------------- | ----------------------------------- | ------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| onBoot           | <a name="onBoot" />`onBoot`         | `onBoot = "npm install"`                    | Команда, выполняемая при запуске Replit App.                                                   |
| compile          | <a name="compile" />`compile`       | (Стандартный пример отсутствует)            | Команда, выполняемая перед командой `run`; используется в компилируемых языках, таких как C++. |
| language         | <a name="language" />`language`     | `language = "javascript"`                   | Указывает язык при импорте из GitHub или создании Replit App.                                  |
| entrypoint       | <a name="entrypoint" />`entrypoint` | `entrypoint = "index.js"`                   | Основной файл, запускаемый и отображаемый при открытии редактора.                              |
| hidden           | <a name="hidden" />`hidden`         | `hidden = [".config", "package-lock.json"]` | Файлы или папки, по умолчанию скрытые в боковом дереве файлов.                                 |
| audio            | <a name="audio" />`audio`           | `audio = true`                              | Включает системный звук при значении `true`.                                                   |

<div id="notas-sobre-o-udio-em-todo-o-sistema">
  ### Примечания о системном аудио
</div>

Если установить `audio = true` в файле `.replit`, может потребоваться выполнить `kill 1` в Shell, чтобы новая настройка вступила в силу.

При запуске графического приложения в правом нижнем углу панели `Output` появится значок наушников с флажком.
Из-за ограничений браузера его нужно будет включать после каждого обновления страницы.

```toml theme={null}
# Убедитесь, что эта строка находится в начале файла `.replit`, вне разделов, заключённых в квадратные скобки `[`
audio = true
```

<div id="configurao-do-gerenciador-de-pacotes">
  ## Настройка менеджера пакетов
</div>

| **Конфигурация** | **Ключ**                                          | **Значение/пример**                           | **Описание**                                                                         |
| ---------------- | ------------------------------------------------- | --------------------------------------------- | ------------------------------------------------------------------------------------ |
| packager         | <a name="language" />`language`                   | `packager.language = "python3"`               | Язык, используемый для операций с пакетами.                                          |
| функции packager | <a name="guessImports" />`guessImports`           | `packager.features.guessImports = true`       | Автоматически определяет пакеты, которые нужно установить перед запуском Replit App. |
| функции packager | <a name="packageSearch" />`packageSearch`         | `packager.features.packageSearch = true`      | Включает поддержку менеджера пакетов, если установлено значение `true`.              |
| функции packager | <a name="enabledForHosting" />`enabledForHosting` | `packager.features.enabledForHosting = false` | Определяет, требуется ли установить пакеты для хостинга Replit App.                  |
| packager         | <a name="afterInstall" />`afterInstall`           | `afterInstall = "echo 'package installed'"`   | Команда, выполняемая после установки нового пакета через менеджер пакетов.           |
| packager         | <a name="ignoredPaths" />`ignoredPaths`           | `ignoredPaths = [".git"]`                     | Пути, игнорируемые при определении пакетов.                                          |
| packager         | <a name="ignoredPackages" />`ignoredPackages`     | `ignoredPackages = ["twitter", "discord"]`    | Модули, для которых никогда не следует определять пакет во время установки.          |

<div id="exemplo-de-configurao-replit-para-o-gerenciador-de-pacotes">
  ### Пример настройки `.replit` для менеджера пакетов
</div>

```toml theme={null}
# Укажите язык для Replit App
packager.language = "python3"

# Включите функции автоматического управления пакетами
[packager.features]
guessImports = true
packageSearch = true
enabledForHosting = false

# Команда, выполняемая после установки каждого пакета
packager.afterInstall = "echo 'Package installed successfully'"

# Укажите пути и пакеты, которые менеджер пакетов должен игнорировать
packager.ignoredPaths = [".git", "node_modules"]
packager.ignoredPackages = ["twitter", "discord"]

# Дополнительные настройки развертывания
[deployment]
run = ["python3", "app.py"]
```

<div id="configurao-de-implantao">
  ## Конфигурация развёртывания
</div>

| **Конфигурация** | **Ключ**                              | **Значение/пример**                  | **Описание**                                                                    |
| ---------------- | ------------------------------------- | ------------------------------------ | ------------------------------------------------------------------------------- |
| deployment       | <a name="run" />`run`                 | `deployment.run = "npm start"`       | Команда, выполняемая при запуске контейнера Deployment.                         |
| deployment       | <a name="build" />`build`             | `deployment.build = "npm run build"` | Команда, выполняемая перед запуском Deployment.                                 |
| deployment       | <a name="ignorePorts" />`ignorePorts` | `deployment.ignorePorts = true`      | Если `true`, для успешного развёртывания не требуется проверка открытого порта. |

<div id="exemplo-de-configurao-replit-para-implantao">
  ### Пример конфигурации `.replit` для развёртывания
</div>

```toml theme={null}

# Указывает главную точку входа проекта
entrypoint = "app.js"

# Параметры конфигурации для развертывания приложения
[deployment]
run = "npm start"
build = "npm run build"
ignorePorts = true
```

<Note>
  **Настройка интерпретатора** больше не поддерживается и недоступна в Replit. Вместо неё рекомендуется использовать команды `Run`, чтобы настроить запуск скриптов и приложений в среде вашего Replit App.
</Note>

<div id="acessando-metadados-do-ambiente-do-replit-app">
  ## Доступ к метаданным среды App в Replit
</div>

<div id="nodejs">
  ### Node.js
</div>

Чтобы получить доступ ко всем переменным окружения:

`console.log(process.env);`

Чтобы получить доступ к отдельной переменной (REPL&#95;SLUG):

`console.log(process.env.REPL_SLUG);`

<div id="python">
  ### Python
</div>

Чтобы получить доступ ко всем переменным окружения:

```python theme={null}
import os
print(os.environ)
```

Чтобы получить доступ к отдельной переменной (REPL&#95;SLUG):

```python theme={null}
import os
variable = os.environ.get('REPL_SLUG')
print(variable)
```

<div id="rust">
  ### Rust
</div>

Чтобы получить доступ ко всем переменным окружения:

```rust theme={null}
use std::env;
fn main() {
    for (key, value) in env::vars() {
        println!("{}: {}", key, value);
    }
}
```

Чтобы обратиться к отдельной переменной (REPL&#95;SLUG):

```rust theme={null}
use std::env;
fn main() {
    let variable = env::var("REPL_SLUG").unwrap();
    println!("{}", variable);
}
```

<div id="variveis-de-ambiente">
  ## Переменные окружения
</div>

Ниже перечислены переменные окружения, доступные в вашем Replit App:

| ключ                                              | описание                                                                                                                                                                              |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <a name="REPL_OWNER" />`REPL_OWNER`               | Имя пользователя — владельца Replit App. Если ваш Replit App является текстовым и не имеет веб-сервера, `REPL_OWNER` будет содержать имя текущего пользователя, открывшего Replit App |
| <a name="REPL_ID" />`REPL_ID`                     | Уникальная UUID-строка вашего Replit App                                                                                                                                              |
| <a name="HOME" />`HOME`                           | Домашний каталог вашего Replit App                                                                                                                                                    |
| <a name="system" />`system`                       | Операционная система, используемая в вашем Replit App                                                                                                                                 |
