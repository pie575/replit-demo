[Replit Mobile App](https://replit.com/mobile) позволяет всегда держать проекты под рукой. Продолжайте с того места, где остановились, или создавайте новые проекты с нуля, где бы вы ни находились. Общайтесь с Agent, редактируйте проекты и развёртывайте их в интернете через интерфейс, оптимизированный для сенсорного управления.

<div id="section">
  ## Начало работы
</div>

Установите App и создайте проект, следуя этим шагам.

<div id="section-2">
  ### Установка App
</div>

1. Перейдите на [страницу загрузки мобильного приложения](https://replit.com/mobile) и установите App, соответствующее операционной системе вашего мобильного устройства.
2. Откройте App и создайте новую учётную запись или войдите в существующую.
   При создании новой учётной записи необходимо подтвердить адрес электронной почты.

<div id="section-3">
  ### Начните разработку
</div>

На главном экране есть два способа начать:

* **Продолжить с того места, где вы остановились**: откройте проект в разделе **Recent Projects**, чтобы продолжить работу.
* **Создать с нуля**: опишите в поле промпта, что вы хотите создать, и отправьте запрос. Agent сразу начнёт работу над проектом.

Чтобы начать с существующего шаблона или кода, нажмите ⋮ в правом верхнем углу и выберите **Remix a Template** или **Import from GitHub**.

<Note>
  Чтобы создавать, просматривать, разрабатывать или отправлять нативные App для iOS, используйте Project Editor на [replit.com](https://replit.com). Работа с нативными мобильными App также доступна в Replit App для Android, если эта функция поддерживается.
</Note>

<div id="section-5">
  ## Мобильные функции
</div>

<div id="section-6">
  ### Голосовой ввод
</div>

С помощью голосовой функции в поле промпта Agent вы можете без помощи рук описать, что хотите создать или изменить.

<div id="section-7">
  ### Live Activities
</div>

Отслеживайте ход работы Agent, где бы вы ни находились. Когда Agent запускается, появляется уведомление. Нажмите **Allow** на экране блокировки. После этого вы сможете следить за ходом работы, не открывая Replit.

<Accordion title="Поддерживаемые устройства">
  * iPhone с iOS 18 или более поздней версии
  * iPad с iOS 18 или более поздней версии
  * Mac с macOS Tahoe или более поздней версии
  * Сопряжённые Apple Watch
</Accordion>

<div id="section-8">
  ### Уведомления
</div>

Получайте важные обновления, где бы вы ни были. Откройте **Settings**, затем **Notifications** (например, в разделе **User**). Убедитесь, что уведомления включены, и при появлении запроса нажмите «Разрешить».

Replit отправляет уведомления в следующих случаях:

* Agent нужна ваша помощь
* Agent завершил работу
* Появились важные обновления по оплате

<div id="section-9">
  ### Режим клавиатуры для планшета
</div>

Подключите клавиатуру к планшету, чтобы комфортно работать на большом экране. При первом открытии Project Editor с подключённой клавиатурой вам будет предложено включить этот режим.

Включить или выключить его можно в любое время: **Account** &gt; **Keyboard Settings**.

<div id="section-10">
  ## Обновление и биллинг
</div>

Чтобы перейти на Core в App, откройте **Account**, нажмите **Upgrade**, выберите план и нажмите **Continue with Core**. Pro нельзя приобрести в мобильном App. Для покупки перейдите на [replit.com](https://replit.com).

Чтобы использовать Agent сверх кредитов, включённых в подписку, добавьте способ оплаты для [биллинга по мере использования](/ru/ja/billing/about-usage-based-billing)：

* **В веб-версии**：перейдите на replit.com и откройте **Settings** → **Account** → **Billing**.
* **В App (только для iOS в США)**：откройте **Settings** → **Billing** (или **Account** → **Billing**).
