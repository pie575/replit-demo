Un cadre de design n’est pas une simple image : c’est le cahier des charges d’un véritable logiciel. Une fois votre frame finalisée, confiez-la à Agent : sélectionnez le frame, choisissez **Build…** dans la barre d’actions, puis indiquez comment procéder :

* Créez une nouvelle application à partir du design dans le même projet
* Appliquez l’apparence du design à une application existante
* Dans les deux cas, vous pouvez effectuer une restauration en toute sécurité — Agent crée un point de contrôle avant de commencer

<div id="2">
  ## Deux façons de passer d’un frame à une application
</div>

<div id="section">
  ### Construire ce design
</div>

Lorsque vous sélectionnez **Build this design**, un nouvel artefact est créé à partir de cette frame. Agent crée la mise en page, le style et les ressources pour en faire une application fonctionnelle en ligne, qui apparaît dans la liste des artefacts du projet.

<div id="section-2">
  ### Appliquer à une application existante
</div>

Ce menu répertorie également tous les artefacts du projet. Lorsque vous en sélectionnez un, le design est appliqué à cette application : Agent réécrit le code de l’artefact pour qu’il corresponde au frame, tandis que le frame Design reste sur le Canvas à titre de référence. Vous pouvez ainsi modifier le style d’une application déjà créée sans repartir de zéro.

<div id="section-3">
  ## Processus
</div>

<Steps>
  <Step title="Choisir le design à créer">
    Déterminez la frame que vous souhaitez publier. Commencez par disposer et comparer les options sur le Canvas : le Build marque la fin de cette phase d’exploration, mais Agent crée un point de contrôle afin que vous puissiez effectuer une restauration à tout moment.
  </Step>

  <Step title="Transmettre à Agent">
    Sélectionnez une frame, puis choisissez **Build…** dans la barre d’actions et indiquez comment procéder : créer un nouvel artefact ou l’appliquer à un artefact existant. Agent crée le design, la mise en page, les styles et les ressources, puis vous informe de sa progression dans le chat.
  </Step>

  <Step title="Vérifier le Build">
    Agent récapitule les modifications et crée un point de contrôle. Ouvrez le résultat pour vérifier que le design fonctionne correctement, puis poursuivez les ajustements dans le chat pour les éléments qui ne se sont pas appliqués comme prévu.
  </Step>
</Steps>

<Note>
  Un forfait Core ou Pro est nécessaire pour créer une nouvelle application à partir d’une frame Design. L’application de designs et toutes les autres fonctionnalités de Replit Design sont disponibles avec tous les forfaits. Pour en savoir plus sur les forfaits, consultez la section [Facturation](/fr/ja/billing/ai-billing).
</Note>

<div id="section-4">
  ## Après le build : passez au concret
</div>

Lorsque vous créez un frame, vous obtenez une application fonctionnelle qui reflète fidèlement votre design. Le mockup ne faisait que simuler son fonctionnement, mais Agent peut désormais ajouter de vraies fonctionnalités. Demandez-lui ce dont vous avez besoin dans le chat :

* **Activer la connexion** : ajoutez des comptes utilisateur avec [Replit Auth](/fr/ja/features/auth-and-identity/authentication). Les utilisateurs peuvent se connecter avec leur compte Replit sans configuration, ou vous pouvez utiliser votre propre fournisseur.
* **Enregistrer des données réelles** : stockez et récupérez les commandes, messages et paramètres avec la [Database](/fr/ja/features/data-and-storage/sql-database) intégrée.
* **Accepter des paiements** : ajoutez des paiements et des abonnements avec l’intégration [Monetization](/fr/ja/features/monetization/overview).
* **Vous connecter à d’autres services** : selon votre prompt, Agent active automatiquement des [intégrations](/fr/ja/features/integrations/overview), de l’e-mail à Slack en passant par les services Google.

<div id="section-5">
  ## Publiez et faites évoluer votre application
</div>

Une fois votre application fonctionnelle, faites-la connaître et continuez à l’améliorer :

* **Publiez-la** : mettez-la en ligne depuis l’[outil Publishing](/fr/ja/features/publishing/overview), puis consultez [Après la publication](/fr/ja/features/publishing/after-you-publish) pour savoir comment mettre à jour votre application en production.
* **Utilisez une véritable adresse** : achetez ou connectez un [domaine personnalisé](/fr/ja/features/publishing/custom-domains).
* **Gagnez en visibilité** : exécutez [SEO Agent](/fr/ja/features/publishing/seo-agent) pour réaliser un audit technique et appliquer des correctifs en un clic.
* **Écoutez vos visiteurs** : ajoutez le [widget de retour](/fr/ja/features/publishing/feedback-widget) afin que les utilisateurs puissent signaler des problèmes ou suggérer des améliorations, puis les envoyer directement à Agent.
* **Gardez-la en bon état** : suivez l’état, les performances et la disponibilité avec le [Monitoring des applications publiées](/fr/ja/features/publishing/monitoring-a-deployment).
