本周，Assistant 正式推出——这款全新的 AI 工具可让你编辑多个文件，并直接应用更改。

<Note>
  **更新 (2025 年 12 月) ：** Assistant 已弃用。如需快速进行针对性编辑，请使用 [Agent 中的 Lite 模式](/zh/core-concepts/agent/agent-modes)。如需讨论和规划，请使用 [Agent 中的 Plan 模式](/zh/core-concepts/agent/plan-mode)。
</Note>

Assistant 专为聊天和快速编辑而优化。常见的工作流程是先用 Agent 创建 MVP，再用 Assistant 快速修改。

以下是 Assistant 的一些亮点：

* **轻量：** Assistant 专为聊天和快速编辑而优化，现在还支持编辑多个文件并直接应用更改。
* **提及和截图：** 在提示词中提及文件或 URL。Assistant 可以为你抓取 URL 内容或截取截图。
* **回滚：** Assistant 会自动创建 checkpoint，让你轻松以差异对比形式预览修改，并一键回滚。
* **灵活性：** Assistant 适用于任何 Replit App，无论使用何种技术栈。你可以导入现有 project，也可以借助 Agent 从头开始。
* **更精美的 App：** 改进了对响应式 React 应用的支持，助你创建出色的 App。
* **计费更新：** 已取消 Agent 的所有使用限制，并增加了订阅包含的积分。

<div id="assistant-features">
  ### Assistant 功能
</div>

Replit Assistant 是一款轻量级 AI 工具，专为聊天和快速编辑而打造。它可以编辑多个文件，并自行直接应用更改。

为 Assistant 提供上下文时，它的表现尤为出色——例如具体功能、文件 (使用 `@file` 提及) 或 URL (直接粘贴即可) 。

Assistant 可帮助你更快迭代，消耗的积分约为 Agent 的五分之一。

<div id="rapid-scraping-screenshots">
  ### 快速抓取 / 截图
</div>

使用 **Assistant** 或 **Agent**，可直接将任意网站的截图或页面内容抓取到提示词中。

只需粘贴 URL，Replit 就会提供截图或抓取页面内容的选项。

一如既往，你也可以随时在提示词中附加图片，或使用 `@file` 引用文件。
