---
title: "免费 Agent 模式"
description: "了解免费模式如何为 Starter、Core 和 Pro 订阅用户提供免费的 Agent 使用额度。"
---

<Note>
  部分额度细节在上线前可能会有所调整。
</Note>

借助免费模式，Starter、Core 和 Pro 订阅用户无需额外付费即可使用 Agent。Starter 在现有限额之外包含免费模式，Core 和 Pro 则包含免费模式额度。开启一个 Conversation，即可探索、规划、构建或寻求帮助。如果你的请求需要使用付费模式或付费操作，Replit 会在产生费用的操作开始前明确告知你。

<div id="section">
  ## 优势亮点
</div>

* 跳过繁琐的设置流程，直接用 Conversation 开始。
* 在决定是否需要更多功能之前，先自由探索并推进你的想法。
* 即使请求需要付费操作，主动权也始终在你手中。
* 在免费模式下完成的工作会带有清晰的 **Free** 标签。

<div id="section-2">
  ## 工作原理
</div>

1. 新的 Starter、Core、Pro 会话均以免费模式启动。
2. 属于免费模式范围内的任务会直接继续执行,不会出现付费操作提示。
3. 如果付费模式能更好地处理某个请求,Agent 会说明原因并提供选项。
4. 你可以仅为该请求启用付费模式,也可以让 Agent 继续使用免费模式。
5. 一次性使用付费模式后,会自动切回免费模式。

<div id="agent">
  ## 三种 Agent 模式
</div>

<CardGroup cols={3}>
  <Card title="Free">
    面向 Starter、Core 和 Pro 订阅用户的免费 Agent 任务。
  </Card>

  <Card title="Power">
    适合需要更多功能的任务，价格实惠的付费中档模式。
  </Card>

  <Card title="Max">
    面向最具挑战性任务的付费最高档模式，提供最先进的前沿模型。
  </Card>
</CardGroup>

Starter、Core 和 Pro 订阅用户均可使用免费模式。Starter 在现有限额基础上包含免费模式。Core 和 Pro 均包含免费模式额度，其中 Pro 的每周限额更高。需要更多功能时，还可以选择付费 Agent 模式。

<Note>
  **达到限额时：** Starter 在现有限额基础上包含免费模式。对于 Core 和 Pro，免费模式额度每 5 小时重置一次，并设有每周限额。请在 **Settings → Usage** 中查看当前状态。接近限额时，Replit 会提前通知你。达到限额后，请切换到付费模式或等待重置后再继续。
</Note>

<div id="section-3">
  ## 常见问题
</div>

<AccordionGroup>
  <Accordion title="免费模式真的免费吗？Replit 现在免费了吗？">
    免费模式包含在 Starter、Core 和 Pro 订阅中。Starter 在现有限额之外还包含免费模式。Core 和 Pro 则包含一定的免费模式额度。这本身并不是一个免费方案。
  </Accordion>

  <Accordion title="这和付费 Agent 模式是一回事吗？">
    不是。免费模式是在额度范围内免费使用的 Agent。Power 和 Max 是付费模式，适用于需要更强能力的任务。
  </Accordion>

  <Accordion title="Economy 和 Power 怎么样了？模式有变化吗？">
    付费模式已更名。Economy 现在叫 Power，是以合理价格提供强大模型的中间档模式；原先的 Power 现在是最高档模式 Max。你原有的模式设置会以新名称保留，不受影响。
  </Accordion>

  <Accordion title="哪个模式最强？">
    是 Max。Power 是付费中档模式，以合理价格提供更强能力；Max 是付费最高档模式，适用于最具挑战性的任务。
  </Accordion>

  <Accordion title="如果请求需要付费操作会怎样？">
    Agent 会说明该请求需要付费模式或付费功能，并在继续之前请你确认。你可以仅为这次请求授权，也可以继续使用免费模式。
  </Accordion>

  <Accordion title="如果 Agent 建议升级，会自动扣费吗？">
    不会。在付费请求开始之前，升级到付费模式都需要你确认。
  </Accordion>

  <Accordion title="我可以拒绝付费选项吗？">
    可以。你可以继续在免费模式下工作。
  </Accordion>

  <Accordion title="授权升级到付费后会怎样？">
    该授权仅对当次请求生效。之后 Agent 模式会恢复为免费模式。
  </Accordion>

  <Accordion title="我为什么会达到额度上限？什么时候重置？">
    Starter 在现有限额之外还包含免费模式。对于 Core 和 Pro，免费模式额度每 5 小时重置一次，并设有每周上限。可在 **Settings → Usage** 中查看当前状态。达到上限后，可切换到付费模式继续使用，或等待额度重置。
  </Accordion>

  <Accordion title="Enterprise 也可以使用免费模式吗？">
    上线初期暂不支持。Enterprise 工作区随后将获得专属的 Agent 使用体验。详情请联系你的管理员。
  </Accordion>
</AccordionGroup>

<div id="section-4">
  ## 进一步了解免费模式
</div>

<AccordionGroup>
  <Accordion title="免费模式和 Lite 是一回事吗？">
    对于 Starter 用户来说，此前称为 Lite 的体验现在就是免费模式。如果你之前使用 Lite 是为了用更便宜的模型，可以在关闭 auto 后，在 Power 中手动选择该模型。
  </Accordion>

  <Accordion title="可以用免费模式创建完整的应用吗？">
    可以。你可以在免费模式下创建完整的应用，并不断迭代改进。
  </Accordion>

  <Accordion title="Free、Power、Max 有什么区别？">
    免费模式面向 Starter、Core、Pro 订阅用户，免费提供日常的 Agent 任务。Starter 在现有限额基础上包含免费模式；Core 和 Pro 包含免费模式额度。Power 是付费中档模式，价格合理且功能更强。Max 是付费最高档模式，适用于最具挑战性的任务。
  </Accordion>

  <Accordion title="什么时候应该切换出免费模式？">
    日常任务建议继续使用免费模式。当你希望在复杂任务中获得更强的效果，或需要免费模式未提供的功能时，再进行切换。
  </Accordion>

  <Accordion title="可以用免费模式生成视频吗？">
    不可以。视频生成属于付费模式的功能，不包含在免费模式中。
  </Accordion>

  <Accordion title="全新的 Conversations 体验是什么？">
    聊天与生成功能融为一体。你可以在同一个 Conversation 中调研想法、规划工作或启动项目。
  </Accordion>

  <Accordion title="独立的聊天会成为已发布应用的一部分吗？">
    不会。在你创建项目或做出更改之前，Conversation 会单独保留。
  </Accordion>

  <Accordion title="可以用免费模式处理现有项目吗？">
    可以。它支持对现有项目进行日常维护和修改。
  </Accordion>
</AccordionGroup>
