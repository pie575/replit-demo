## Importer depuis un ZIP

⏰ *Durée estimée : trois minutes*

Importez un projet local en téléversant un fichier `.zip`.

Pour des options d'importation complètes incluant d'autres plateformes comme GitHub, Figma, Bolt, Lovable et Vercel, consultez la [documentation de la fonctionnalité d'importation](/fr/references/workspace/import).

## Avant de commencer

* Un fichier `.zip` contenant votre projet
* Un dossier racine de projet clair dans l'archive
* Un compte Replit

## Étapes d'importation

1. Ouvrez [replit.com/import](https://replit.com/import).
2. Sélectionnez **ZIP**.
3. Téléversez votre fichier `.zip`.
4. Ajoutez les secrets et variables d'environnement demandés.
5. Sélectionnez **Importer**.

## Ce qui est importé

* Fichiers du projet et structure des répertoires
* Fichiers de dépendances
* Valeurs par défaut d'exécution et de build pour Replit

## Ce qui n'est pas importé

* Valeurs des variables d'environnement existantes
* Domaines personnalisés
* Services spécifiques à la plateforme nécessitant une configuration manuelle
* Données de base de données existantes
* Configuration de connecteurs tiers existants
