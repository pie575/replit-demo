<div id="o-que-so-artefatos">
  ## Que sont les artefacts ?
</div>

Les artefacts sont les éléments que vous pouvez publier sur Replit, comme des applications web, des applications mobiles, des présentations de diapositives, des animations, des applications de données, des jeux 3D et des designs. Chacun constitue un résultat complet et indépendant qui reçoit sa propre URL partageable lorsque vous le publiez.

Tout le reste de votre projet — fichiers, images, CSV, code — sert vos artefacts, mais ne peut pas être publié séparément.

<div id="primeiros-passos">
  ## Premiers pas
</div>

Vous pouvez créer de deux façons depuis la page d’accueil de Replit :

* **Décrivez** : saisissez ce que vous souhaitez — « crée-moi une application de recettes » ou « crée une présentation pour ma startup ». Agent détermine le type adapté et le crée.
* **Choisissez un type** : choisissez l’artefact souhaité — Application web, Application mobile, Visualisation de données, Animation, Jeu 3D ou un autre type pris en charge — avant de décrire votre idée.

Vous pouvez également ajouter du contenu à un projet existant à tout moment en le demandant à Agent dans Chat ou en cliquant sur le bouton **+** dans le panneau d’aperçu.

<div id="alternando-entre-artefatos">
  ## Passer d’un artefact à l’autre
</div>

Lorsque vous avez plusieurs artefacts dans un projet, passez de l’un à l’autre depuis le **panneau d’aperçu** ou la **barre latérale Bibliothèque**. Vous pouvez également demander à Agent : « Montre-moi l’application mobile » ou « Passe aux diapositives ».

<div id="barra-lateral-da-biblioteca">
  ### Barre latérale de la bibliothèque
</div>

La barre latérale de la bibliothèque vous permet d&#39;accéder en un seul endroit à tout le contenu de votre projet. Elle affiche vos artefacts, les images générées ou téléchargées par Agent, ainsi que les autres ressources du projet. Ouvrez la barre latérale de la bibliothèque dans le panneau de gauche pour retrouver et réutiliser n&#39;importe quelle ressource de votre projet.

<div id="vrios-artefatos-em-um-projeto">
  ## Plusieurs artefacts dans un projet
</div>

Un même projet peut contenir jusqu’à **7 artefacts**, avec un maximum de **1 application mobile** par projet. Par exemple, vous pouvez créer une application web pour vos clients, une application mobile pour votre équipe et une présentation de diapositives destinée aux investisseurs, le tout dans le même projet.

<ArtifactGrid />

<div id="adicionando-artefatos-a-um-projeto">
  ### Ajouter des artefacts à un projet
</div>

Il existe trois façons d’ajouter un artefact à un projet existant :

* **Chat** : Demandez à Agent : « ajoute une application mobile à ce projet » ou « crée une présentation de diapositives pour présenter le projet à des investisseurs »
* **Bouton d’ajout** : Cliquez sur le bouton **+** dans le panneau d’aperçu et choisissez ce que vous souhaitez créer
* **Barre latérale de la bibliothèque** : Parcourez vos artefacts, images et autres ressources existantes, puis ajoutez de nouveaux artefacts depuis cet emplacement

<div id="dados-e-backend-compartilhados">
  ### Données et backend partagés
</div>

Lorsque les artefacts se trouvent dans le même projet, ils partagent automatiquement les mêmes données et la même logique backend. Si un client passe une commande via votre application web, votre application mobile et votre tableau de bord de données y auront également accès. Vous n’avez pas besoin de configurer de connexion ni de dupliquer du code : tout fonctionne automatiquement.

<Note>
  La publication déploie l’ensemble de votre projet en une seule fois. Tous les artefacts sont mis en ligne ensemble, afin de rester toujours synchronisés.
</Note>

<div id="exemplos-de-combinaes">
  ### Exemples de combinaisons
</div>

* **Application web + application mobile** : Un restaurant avec une application web destinée aux clients et une application mobile pour l&#39;équipe — toutes deux connectées à la même base de données et à la même API
* **Application + tableau de bord d&#39;administration** : Un produit principal accompagné d&#39;un panneau d&#39;administration interne pour gérer le contenu, les utilisateurs ou les paramètres
* **Application + diaporama** : Votre produit et un pitch deck dans un même projet, afin que les diapositives reflètent toujours la version la plus récente
* **Tableau de bord de données + vidéo** : Une visualisation de données en direct combinée à une vidéo animée qui passe en revue les points forts

<div id="publicao">
  ## Publication
</div>

Les applications, les diapositives et les vidéos peuvent être publiés et partagés. Chaque élément reçoit sa propre URL à partager lorsque vous le déployez.

Les fichiers et ressources qui ne sont pas des artefacts (comme les CSV, les images ou les fichiers markdown) ne peuvent pas être publiés seuls. Pour les partager, ajoutez-les à une application ou créez un nouvel artefact.

<div id="perguntas-frequentes">
  ## Questions fréquentes
</div>

<Accordion title="Puis-je avoir plusieurs artefacts dans un projet ?">
  Oui. Un même projet peut contenir jusqu&#39;à **7 artefacts au total**, avec une limite de **1 application mobile par projet**. Tous les artefacts d&#39;un projet partagent automatiquement le même backend et les mêmes données.

  Si vous atteignez la limite d&#39;applications mobiles et souhaitez en créer une deuxième, créez-la dans un nouveau projet. Si vous atteignez la limite totale de 7 artefacts, supprimez un artefact existant avant d&#39;en ajouter un autre ou répartissez votre travail entre plusieurs projets.
</Accordion>

<Accordion title="Dois-je choisir un type avant de commencer ?">
  Non. Décrivez simplement ce que vous souhaitez, et Agent choisira le type adapté. Vous pouvez également sélectionner un type manuellement dans le menu déroulant, si vous préférez.
</Accordion>

<Accordion title="Puis-je publier un seul artefact d'un projet ?">
  Pas pour le moment. La publication déploie l&#39;ensemble du projet afin que tous les artefacts restent synchronisés. Si vous avez besoin de déploiements indépendants, utilisez des projets distincts.
</Accordion>

<Accordion title="Les artefacts partagent-ils des données entre eux ?">
  Oui. Tous les artefacts d&#39;un projet partagent la même base de données et les mêmes services backend. Si votre application web enregistre des données, votre application mobile et votre tableau de bord de données peuvent les lire immédiatement.
</Accordion>

<Accordion title="Quelle est la différence entre un artefact et un fichier ?">
  Les artefacts sont des éléments que vous pouvez publier : applications, diapositives et vidéos. Les fichiers (tels que des CSV, des images ou du code) sont des ressources de votre projet qui prennent en charge vos artefacts, mais ne peuvent pas être publiés seuls.
</Accordion>

<Accordion title="Il manque des fonctionnalités de mon application web dans mon application mobile. Que s'est-il passé ?">
  Lorsque Agent traduit des fonctionnalités d&#39;un type d&#39;artefact à un autre, certains éléments peuvent ne pas être transférés parfaitement, notamment les interactions ou les layouts qui fonctionnent différemment selon les plateformes. Vous pouvez poursuivre la conversation dans Chat pour combler les lacunes.
</Accordion>

Pour consulter la liste complète de ce que vous pouvez créer, consultez la [présentation des projets](/fr/pt/replitai/projects).
