<div id="custom-prompts">
  ### Prompts personnalisés
</div>

<Note>
  **Mise à jour (décembre 2025) :** Assistant est obsolète. Pour des modifications rapides et ciblées, utilisez le [mode Lite d’Agent](/fr/core-concepts/agent/agent-modes).
</Note>

Les prompts personnalisés vous permettent de contrôler précisément la façon dont Assistant interagit avec votre projet. Que vous souhaitiez définir des normes de codage spécifiques ou personnaliser les paramètres par défaut d’Assistant, les prompts personnalisés vous offrent cette flexibilité.

Vous pouvez notamment ajouter :

* Un style de codage ou un framework spécifique
* Des techniques spécifiques de résolution de problèmes
* Des préférences de gestion des packages

Par exemple, vous pouvez ajouter :

```
use pnpm for package management
use motion/react instead of framer-motion
always use claude-3-5-sonnet-20241022 as your model
```

<div id="replit-app-theming">
  ### Personnalisation des thèmes des Replit App
</div>

Vos projets viennent de bénéficier d’un sérieux coup de neuf. Sans écrire une seule ligne de code 💅

Vous pouvez désormais demander à Agent de créer une Replit App React et la personnaliser facilement avec des outils de personnalisation sans code :

* Modifier la couleur principale
* Basculer entre les modes clair et sombre
* Personnaliser l’esthétique de votre app pour qu’elle vous ressemble vraiment

<Frame>
  <img src="/assets/mirror/theme-3f4e1186c87b.webp" alt="Animation présentant la fonctionnalité de personnalisation des thèmes des Replit App" width="720" height="541" data-path="images/changelog/2024-12-20/theme.webp" />

Copiez-collez ce prompt dans Agent pour l’essayer !

```

```

<div id="workflows">
  ### Workflows
</div>

Un Workflow est un bouton « Exécuter » facilement configurable, capable de lancer une ou plusieurs commandes de votre choix.

Il s&#39;agit d&#39;une séquence d&#39;étapes réutilisable et personnalisable, exécutable dans votre Replit App. Il peut être aussi simple que l&#39;exécution de **`python main.py`** ou aussi complexe qu&#39;une procédure en plusieurs étapes.

Exemples de cas d&#39;utilisation :

* Exécuter plusieurs services en parallèle (par ex., frontend + backend)
* Exécuter des fichiers ou des commandes de manière séquentielle (par ex., exécuter le linter → exécuter les tests, compiler → exécuter le code)

Pour commencer à [créer des workflows](https:/.replit.com/replit-workspace/workflows#creating-workflows), accédez au volet Workflows depuis le menu des outils de la barre latérale, ou recherchez-le avec **`Command + K`**.

Découvrez-les [ici](https:/.replit.com/replit-workspace/workflows).
