<div id="o-que-uma-visualizao-de-dados">
  ## 什么是数据可视化？
</div>

数据可视化是通过与 Agent 对话创建的交互式仪表板或报告工具。只需描述您想要呈现的内容以及数据所在位置，Agent 就会自动选择合适的 KPI、图表类型和布局，只用一条提示词即可生成完整的仪表板。

核心概念：

* **一次生成**：描述您的目标和数据源，Agent 即可创建包含合适图表和指标的完整仪表板
* **已连接的数据源**：访问数据库、[数据仓库连接器](/zh/pt/connectors/warehouses/overview)、外部 API 或上传的文件
* **内置功能**：每个仪表板均支持刷新、自动刷新、导出为 PDF、将图表导出为 CSV，以及浅色/深色模式
* **分析摘要**：Agent 会根据您的请求和生成的数据提供洞察
* **多个产物**：数据可视化可以与您在[同一项目](/zh/pt/replitai/artifacts#multiple-artifacts-in-one-project)中的其他产物共享同一后端和数据库

<div id="como-usar-a-visualizao-de-dados">
  ## 如何使用数据可视化
</div>

<div id="criando-a-partir-de-um-prompt">
  ### 通过提示词创建
</div>

在首页选择 **App** 选项卡，然后描述您想创建的仪表板。Agent 会识别与数据相关的提示词，并选择数据可视化技术栈。

**提示词示例：**

* “创建一个按地区跟踪营收的销售分析仪表板”
* “创建一个可视化我们月度指标的报告工具”
* “根据我们的 BigQuery 销售数据创建一个仪表板，展示表现最佳的产品”
* “连接到 Snowflake，创建一个客户流失分析仪表板”

<div id="criando-a-partir-do-menu-suspenso">
  ### 通过下拉菜单创建
</div>

1. 前往首页的 **App** 标签页。
2. 打开应用类型下拉菜单。
3. 选择 **数据可视化**。
4. 描述您想创建的仪表板或数据工具。

<div id="conectando-a-data-warehouses">
  ### 连接数据仓库
</div>

通过[数据连接器](/zh/pt/connectors/warehouses/overview)将数据可视化功能连接到 BigQuery、Databricks 或 Snowflake，基于现有数据集创建仪表板。

查询数据仓库中的数据时，Agent 会使用并行多智能体搜索来探索您的架构和数据集。这能加快探索过程，并帮助 Agent 为仪表板选择合适的表和字段。

首先，在项目的[集成](/zh/replitai/integrations)中配置数据仓库连接器，然后告诉 Agent 您想要可视化什么内容。

<div id="adicionando-filtros-e-recursos">
  ### 添加筛选器和功能
</div>

Agent 创建仪表板后，您可以让它添加筛选器、下钻功能或其他交互功能。例如，您可以让 Agent 添加日期范围筛选器、地区选择器或搜索栏。

<div id="exportando-e-compartilhando">
  ### 导出与分享
</div>

* **导出为 PDF**：将整个仪表板导出为 PDF，便于分享或离线查看。
* **将图表导出为 CSV**：将单个图表的数据下载为 CSV 文件，以便在电子表格或其他工具中进一步分析。
* **分析文档**：让 Agent 根据仪表板中的数据生成一份详细的分析文档。

<div id="o-que-voc-pode-criar">
  ## 您可以创建的内容
</div>

* **分析仪表板**：跟踪收入、注册量或参与度等关键指标随时间的变化
* **报告工具**：创建内部报告，让利益相关者无需直接访问数据库即可筛选和探索数据
* **数据探索界面**：借助可视化反馈浏览和查询数据集
* **监控面板**：显示来自 API、数据库或外部服务的实时或近实时数据

<div id="perguntas-frequentes">
  ## 常见问题
</div>

<Accordion title="我可以连接哪些数据源？">
  你可以从项目的 Replit 数据库、数据仓库连接器 (BigQuery、Databricks、Snowflake) 、外部 API 或上传的 CSV 文件中提取数据。warehouse 连接可通过[集成](/zh/replitai/integrations)进行配置。
</Accordion>

<Accordion title="我可以自定义外观吗？">
  可以。你只需通过对话就能自定义颜色、布局和排版——让 Agent 贴合你的品牌风格或调整设计即可。仪表板还同时支持浅色和深色模式。
</Accordion>

<Accordion title="Agent 会帮我分析数据吗？">
  创建仪表板后，Agent 会根据你的需求和得到的数据生成一份分析摘要。你也可以要求生成更详细的分析文档。
</Accordion>

<Accordion title="我可以把数据可视化与其他类型的产物结合起来吗？">
  可以。你可以在[同一项目](/zh/pt/replitai/artifacts#multiple-artifacts-in-one-project)中将数据可视化与 [Web 应用](/zh/pt/replitai/web-apps)、[幻灯片演示](/zh/pt/replitai/slide-decks)或其他类型的产物组合使用。它们共享同一个 backend 和数据库。
</Accordion>
