---
title: "Historique des fichiers"
description: "Découvrez comment restaurer des versions antérieures de votre code à l’aide des points de sauvegarde automatiques de l’historique des fichiers."
---

Ouvrez un fichier texte dans l’éditeur de projet, puis cliquez sur le bouton **History** situé dans l’angle inférieur droit.

<Frame>
  <img src="/assets/mirror/history-button-afac6496660a.png" alt="Ouvrir l’historique" width="377" height="292" data-path="images/programming-ide/history-button.png" />
</Frame>

<div id="section">
  ## Afficher les versions précédentes d’un fichier
</div>

Après avoir ouvert l’historique des fichiers, vous pouvez afficher les versions précédentes d’un fichier à l’aide de la barre de défilement, des boutons fléchés ou des touches fléchées **gauche et droite**.

<Frame>
  <img src="/assets/mirror/history-versioning-1a055ecab411.gif" alt="Démonstration de la barre de défilement" width="764" height="720" data-path="images/animations/history-versioning.gif" />
</Frame>

<div id="section-2">
  ## Comparer une version précédente au fichier actuel
</div>

Activez le bouton « Compare Latest », situé en bas à gauche du volet Historique des fichiers, pour afficher une comparaison en ligne entre le fichier à ce stade et sa dernière version.

<Frame>
  <img src="/assets/mirror/compare-history-46fb16debd3a.gif" alt="Comparer avec la dernière version" width="772" height="720" data-path="images/animations/compare-history.gif" />
</Frame>

<div id="section-3">
  ## Restaurer une version précédente d’un fichier
</div>

Pour restaurer un fichier vers une version précédente, cliquez simplement sur le bouton `Restore`. L’historique est conservé. Lorsque vous restaurez une version précédente, elle est ajoutée comme nouvelle version à l’historique du fichier.

<Frame>
  <img src="/assets/mirror/restore-history-5f616d7f961a.webp" alt="Image de restauration de l’historique" width="720" height="495" data-path="images/animations/restore-history.webp" />
</Frame>

<div id="section-4">
  ## Afficher la relecture de l’historique d’un fichier
</div>

La relecture de l’historique des fichiers vous permet de visualiser l’évolution d’un fichier au fil du temps, comme un film. Elle est utile pour créer une vidéo d’une session de programmation.
