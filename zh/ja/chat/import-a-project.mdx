如果你已在开发应用或项目，可以将其导入 Replit，并在项目中继续开发。导入不同于将文件作为 Conversation 的参考资料或上下文附加其中。

<div id="section">
  ## 选择合适的来源
</div>

来源决定了可导入的内容，以及现有工作将如何导入 Replit。目前的导入指南涵盖以下方式。

| 现有工作       | 对应来源                                                                                     |
| ---------- | ---------------------------------------------------------------------------------------- |
| 代码仓库和构建器项目 | **GitHub**、**Bitbucket**、**Vercel**、**Bolt**、**Lovable**、**Base44**，以及**先前导出的 Agent 项目** |
| 设计         | **Figma** 和 **Claude**                                                                   |
| 本地文件和数据    | **ZIP** 和**电子表格** (`.xlsx`、`.csv` 或公开的 Google Sheets URL)                                |

从某些构建器导入时，需要使用从原始服务导出的 GitHub 仓库。导入前，请查看各来源对应的指南。设置、Secrets、数据库值或特定提供商的服务可能需要在之后进行额外配置。

在提示词输入框中选择**加号**菜单，然后选择**导入现有项目**，即可打开导入流程。

<div id="section-2">
  ## 导入还是上传？
</div>

* 如果您想在现有代码、设计或结构化项目的基础上继续构建，请**导入项目**。
* 如果文档、电子表格、图片或屏幕截图能为当前 Conversation 中的问题或任务提供上下文，请**上传文件**。

有关上传文件，请参阅[上传并使用文件](/zh/ja/chat/upload-and-use-files)。
