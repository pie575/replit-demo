L’importation vous permet d’intégrer du code et des designs existants dans vos Replit Apps, puis de poursuivre le développement avec Agent.

<div id="section">
  ## Sources prises en charge
</div>

| Source                       | Éléments requis                                      | Idéal pour                                                       |
| ---------------------------- | ---------------------------------------------------- | ---------------------------------------------------------------- |
| GitHub                       | URL du dépôt ou sélecteur de dépôt                   | Importer des dépôts publics et privés                            |
| Bitbucket                    | URL du dépôt ou sélecteur de dépôt                   | Importer des dépôts hébergés sur Bitbucket                       |
| Vercel                       | Dépôt GitHub associé au projet Vercel                | Migrer des applications Vercel                                   |
| Figma                        | URL du cadre                                         | Convertir des designs en applications React                      |
| Claude                       | Design envoyé depuis Claude                          | Convertir des designs Claude en applications interactives        |
| Bolt                         | Dépôt GitHub exporté depuis Bolt                     | Migrer des projets Bolt                                          |
| Lovable                      | Dépôt GitHub exporté depuis Lovable                  | Migrer des projets Lovable                                       |
| Base44                       | Dépôt GitHub exporté depuis Base44                   | Migrer des projets Base44                                        |
| ZIP                          | Importation d’un fichier `.zip`                      | Importer des archives de projets locaux                          |
| Feuille de calcul            | Fichier `.xlsx`, `.csv` ou URL Google Sheets         | Créer des applications à partir de données de feuilles de calcul |
| Exportation Agent précédente | Dépôt GitHub exporté depuis une précédente App Agent | Réimporter une précédente App Agent                              |
| Vide                         | Aucun                                                | Utilisateurs avancés souhaitant créer un projet vide sans Agent  |

<Note>Replit vérifie la compatibilité avant de lancer l’importation.</Note>

Pour les designs Figma, consultez [Importer des designs Figma dans Replit Design](/fr/ja/design/import-figma-designs-into-replit-design).

Pour les designs envoyés depuis Claude, consultez [Importer des designs Claude dans Replit Design](/fr/ja/design/import-claude-designs-into-replit-design).

  <Tab title="GitHub">
    ⏰ *Durée estimée : 2 minutes*

    Importez un dépôt GitHub dans Replit pour l’exécuter, le tester et le publier plus rapidement.

    **Ce dont vous avez besoin avant de commencer**

    * URL du dépôt GitHub
    * Accès au dépôt (public ou privé)
    * Compte Replit

    **Option 1 : importation rapide**

    L’importation rapide fonctionne avec les dépôts publics.

    1. Copiez le chemin du dépôt après `github.com/`.
    2. Ouvrez `https://replit.com/github.com/<owner>/<repo>`.
    3. Appuyez sur Entrée pour lancer l’importation.

    *Exemple*

    * URL GitHub : `https://github.com/exampleUser/my-app`
    * URL d’importation Replit : `https://replit.com/github.com/exampleUser/my-app`

    **Option 2 : importation guidée**

    L’importation guidée prend en charge les dépôts publics et privés.

    1. Ouvrez [replit.com/import](https://replit.com/import).
    2. Sélectionnez **GitHub**.
    3. Connectez votre compte GitHub.
    4. Sélectionnez le dépôt.
    5. Sélectionnez **Importer**.

    **Éléments importés**

    * Fichiers et dossiers du dépôt
    * Fichiers de dépendances
    * Configurations courantes d’exécution et de Build

    **Éléments non importés**

    * Valeurs existantes de Secrets et de variables d’environnement
    * Services spécifiques à une plateforme qui ne fonctionnent pas par défaut dans Replit

    **Résoudre les problèmes de connexion GitHub**

    Si le message `Failed to get repository, please re-authenticate with GitHub` s’affiche, ou si `No repositories found` apparaît dans la liste déroulante des dépôts, le flux d’importation GitHub utilise une connexion distincte de celle de la page **Compte → Services connectés**. Reconnecter uniquement le service connecté ne résoudra pas le problème dans le flux d’importation.

    <Steps>
      <Step title="Reconnecter GitHub depuis le fournisseur Git">
        Ouvrez la section **Fournisseurs Git** des paramètres de votre compte Replit, déconnectez GitHub, puis reconnectez-le depuis le même écran. Vos dépôts personnels devraient ensuite apparaître dans la liste déroulante d’importation.
      </Step>

      <Step title="Autoriser l’application Replit pour l’organisation GitHub">
        Si le dépôt appartient à une organisation GitHub, ouvrez [https://github.com/settings/applications](https://github.com/settings/applications), recherchez l’application OAuth Replit et autorisez l’accès à l’organisation dans les paramètres d’accès des applications tierces. Si vous n’êtes pas propriétaire de l’organisation, un administrateur de l’organisation devra effectuer cette étape.
      </Step>

      <Step title="Réessayer l’importation">
        Ouvrez [replit.com/import](https://replit.com/import) et réessayez l’importation, à la fois depuis la liste déroulante des dépôts et en collant l’URL du dépôt.
      </Step>
    </Steps>

<div id="section-3">
  ## Autres sources
</div>

<div id="bitbucket">
  ### Bitbucket
</div>

* Collez l’URL d’un dépôt Bitbucket ou connectez votre compte Bitbucket pour rechercher des dépôts.
* La prise en charge d’Agent lors de l’importation peut être plus limitée que pour les projets hébergés sur GitHub.

<div id="section-4">
  ### Feuilles de calcul
</div>

* Importez un fichier Excel (`.xlsx`) ou CSV, ou collez l’URL d’une feuille Google Sheets publique.
* Agent lit la structure de la feuille de calcul et crée une application full-stack avec une base de données alimentée par vos données.
* L’application inclut une UI permettant d’afficher, de rechercher et de gérer les enregistrements.

<div id="agent">
  ### Exportation Agent précédente
</div>

* Réimportez une App Agent précédemment exportée à partir d’un dépôt GitHub.
* Replit conserve la structure spécifique à Agent (code, schéma de base de données et fonctionnalités backend).
* Les données de la base de données et les secrets ne sont pas importés.

<div id="section-5">
  ### Vide
</div>

* Commencez avec un projet entièrement vide, sans Agent, sans choix de framework ni structure initiale.
* Idéal pour les utilisateurs avancés qui souhaitent garder le contrôle total sur la configuration de leur projet.

<div id="section-6">
  ## Limites
</div>

* Les données existantes des bases de données ne sont pas migrées.
* Les téléversements de fichiers ZIP sont limités à 200 Mo.
* Les dépendances complexes ou personnalisées peuvent nécessiter une configuration manuelle.
* Le traitement des projets volumineux peut prendre du temps.

<div id="section-7">
  ## Bonnes pratiques
</div>

* Supprimez les informations sensibles avant l’importation.
* Veillez à conserver une structure claire dans le projet source.
* Vérifiez les dépendances et les commandes d’exécution après l’importation.
* Testez les parcours principaux avant la publication.

<div id="section-8">
  ## Dépannage
</div>

Si l&#39;importation échoue, commencez par vérifier les points suivants :

* **Erreurs de compatibilité** : vérifiez les fichiers de projet requis et les frameworks pris en charge.
* **Erreurs d&#39;accès** : vérifiez les autorisations du dépôt ou de la source.
* **Erreurs de traitement** : simplifiez la structure du projet ou réduisez sa taille, puis réessayez.

Si le problème persiste, rendez-vous sur le [hub communautaire Replit](https://replit.com/community) ou [contactez le support](https://replit.com/support).

<div id="section-9">
  ## Facturation
</div>

Les importations nécessitant une migration avec Agent peuvent consommer des crédits. Le nombre de crédits utilisés varie selon la complexité du projet.
