<div id="azure-marketplace-integration">
  ### Azure Marketplace 集成
</div>

Replit 现已上架 Azure Marketplace！许多组织都已为 Azure 划拨了专项预算，借助这项集成，他们可以直接用这些资金支付 Replit 的订阅和用量费用。

继 9 月推出 GCP Marketplace 集成之后，此次上架让企业团队能够更轻松地沿用现有的云采购流程和预算来引入 Replit。

[在 Azure Marketplace 上查看](https://marketplace.microsoft.com/en-us/product/saas/replit.replit?tab=Overview)

<div id="gitlab-and-bitbucket-support">
  ### GitLab 和 Bitbucket 支持
</div>

除 GitHub 之外，Replit 现已支持 GitLab 和 Bitbucket 仓库，让你在存放代码时拥有更多选择。你可以直接将 GitLab 和 Bitbucket 上的项目导入 Replit，同时所有受支持平台的 git 功能也得到了改进。

增强后的 git 集成包括：

* **多平台支持**：导入并使用来自 GitHub、GitLab 和 Bitbucket 的仓库
* **更强的 git 操作**：整个 workspace 中的 git 命令更快、更可靠
* **更好的仓库管理**：从任意受支持的 git 服务克隆、推送和拉取的工作流更加顺畅

进一步了解[导入项目](/zh/references/workspace/import)和[在 Replit 中使用 git](/zh/references/version-control/git-interface)。
