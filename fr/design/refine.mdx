L&#39;exploration ratisse large ; l&#39;affinage creuse en profondeur. Dès qu&#39;un frame se rapproche du résultat souhaité, deux outils permettent de le peaufiner avec précision, selon votre façon de travailler :

* Échangez avec Agent avec vos propres mots, à propos d&#39;un frame entier ou d&#39;un seul élément
* Modifiez directement les éléments dans le Visual Editor : les retouches simples s&#39;appliquent instantanément, sans consommer de crédits

<div id="chat">
  ## Chat
</div>

Donnez vos consignes à Agent comme vous le feriez à un designer en pleine revue. Sélectionnez un frame et décrivez les modifications dans le chat principal (*« des couleurs plus chaudes »*, *« la section héros semble vide »*), ou sélectionnez l&#39;outil **Chat** dans la barre d&#39;outils et cliquez sur un élément pour cibler votre message sur cet élément uniquement.

</Frame>

Consultez [Chat](/fr/design/chat-about-your-design) pour découvrir les deux points d&#39;entrée.

<div id="visual-editor">
  ## Visual Editor
</div>

Lorsque vous savez exactement ce que vous voulez, passez le prompt. Sélectionnez l’outil **Edit** dans la barre d’outils, puis cliquez sur un élément : le Visual Editor s’ouvre et affiche les propriétés modifiables de cet élément, telles que le contenu, la mise en page, la couleur et la bordure. Les modifications simples, comme les changements de texte, le choix des couleurs et les ajustements d’espacement, s’appliquent instantanément au code source sans consommer de crédits.

<Frame caption="L’outil Edit est actif avec un élément sélectionné, et le Visual Editor affiche ses propriétés modifiables.">
  <img src="/assets/mirror/visual-editor-edit-tool-71d03803471f.png" alt="Un configurateur de supercar avec l’outil Edit actif et un élément sélectionné, affichant à droite le panneau Visual Editor avec les sections Layout, Color et Border, ainsi que les boutons Discard et Save edits" width="2000" height="1250" data-path="images/replitai/visual-editor-edit-tool.png" />

Consultez la page [Visual Editor](/fr/design/visual-editor) pour consulter la référence complète des contrôles.

<div id="which-one-to-reach-for">
  ## Lequel choisir
</div>

| Vous voulez…                                                                                          | Utilisez      |
| ----------------------------------------------------------------------------------------------------- | ------------- |
| Décrire un résultat et laisser Agent en gérer les détails                                             | Chat          |
| Changer le texte, la couleur, l&#39;espacement ou l&#39;image d&#39;un élément par une valeur précise | Visual Editor |
| Retravailler la structure ou le comportement d&#39;une section                                        | Chat          |
| Apporter une retouche rapide, sans consommer de crédits                                               | Visual Editor |

Les deux se complètent naturellement : passez par Chat pour donner une direction, puis affinez les détails d&#39;un clic avec le Visual Editor.
