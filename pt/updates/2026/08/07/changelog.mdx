## Agent

### Verificação de segurança enquanto você constrói

Agora o Agent verifica os arquivos que altera em busca de problemas comuns de segurança como parte de sua revisão de código. Essa verificação automática do Semgrep procura padrões arriscados e segredos codificados diretamente no código, para que o Agent possa resolver as descobertas mais prováveis antes de concluir a tarefa.

Saiba mais sobre a [Verificação de segurança enquanto você constrói](/pt/features/security/project-security-center#security-scan-while-you-build).

## Plataforma

### Regenere as credenciais do banco de dados de produção

Agora você pode regenerar as credenciais de um banco de dados de produção elegível a partir da ferramenta **Database**. O Replit atualiza as credenciais e, quando seu app tem uma implantação suportada ativa, inicia uma nova implantação para que ele possa continuar usando as novas credenciais. Atualize todas as ferramentas externas que usam a string de conexão antiga.

## Teams e Enterprise

### Construa com SSO

Agora, criadores Pro podem configurar SSO empresarial para um Replit App que usa o [Clerk Auth](/pt/features/auth-and-identity/clerk-auth). Peça ao Agent a alteração de autenticação de que você precisa, e o Agent te direciona ao Clerk Dashboard. Lá, conecte o Okta ou o Microsoft Entra ID por meio de OIDC ou SAML. As conexões de SSO empresarial são gratuitas até 1º de outubro de 2026. Depois dessa data, aplica-se o preço repassado da Clerk. A disponibilidade para Enterprise chega em breve.

### Mova projetos entre workspaces

Agora você pode mover um projeto entre workspaces de equipe na mesma conta de faturamento a partir da lista **Projects**. A transferência é executada em segundo plano e não pode ser desfeita. Os Linked Account Secrets não são movidos junto com o projeto, então vincule-os novamente no workspace de destino.
