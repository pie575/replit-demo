<div id="replit-pwa-on-microsoft-app-store">
  ### Microsoft App Store의 Replit PWA
</div>

이제 Replit을 Microsoft App Store에서 프로그레시브 웹 앱(PWA)으로 사용할 수 있습니다. 덕분에 Windows builder는 Replit을 네이티브 앱처럼 더 쉽게 찾아 설치할 수 있습니다.

<div id="empty-project-creation">
  ### 빈 프로젝트 생성
</div>

이제 import 페이지에서 빈 프로젝트를 만들 수 있습니다. 빈 프로젝트는 시작할 때 Agent가 실행되지 않아 생성 시 credits가 소모되지 않으며, 프레임워크와 도구 구성을 원하는 대로 직접 설정할 수 있습니다. 이 옵션은 이러한 수준의 제어를 원하는 builder를 위해 import 페이지에서 제공됩니다.

<div id="enterprise-audit-log-portal">
  ### Enterprise Audit Log Portal
</div>

이제 모든 Enterprise 고객이 Enterprise Audit Log Portal(v1)을 사용할 수 있습니다. Admin은 조직 구성원이 수행한 이벤트를 확인하고, S3, Datadog, Splunk, Google Cloud Storage, Microsoft Sentinel 등 원하는 SIEM 플랫폼과의 이벤트 stream integration을 설정할 수 있습니다.
