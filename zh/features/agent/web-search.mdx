<div id="features">
  ## 功能
</div>

借助 Agent 的网页搜索，你可以基于最新信息构建应用，无需手动查资料、收集数据。无论是制作展示金融数据的仪表板，还是搭建一个呈现近期初创公司发布动态的网站，网页搜索都能让你的应用如实反映现状。

Agent 可以执行以下网页搜索操作：

* **搜索**：从互联网获取最新信息、最新文档和实时数据
* **内容抓取**：从特定网站和 URL 中获取详细信息
* **来源引用**：查看 Agent 具体从何处获取信息，方便你核实并引用来源

<div id="usage">
  ## 使用方法
</div>

网页搜索 已内置于 Agent 中，无需手动开启。只需描述你想构建的内容，Agent 就会自动判断何时需要联网搜索最新信息。你也可以在 prompt 中加入“搜索”“调研”或“使用 网页搜索”等关键词，明确提示 Agent 执行搜索。

<div id="how-web-search-enhances-your-apps">
  ### 网页搜索如何提升你的应用
</div>

网页搜索让你的应用不再依赖占位数据，而是使用真实、准确的信息：

| 优势       | 说明                       |
| -------- | ------------------------ |
| 技术保持最新   | 你的应用可使用训练数据中没有的最新信息和软件包  |
| 选择最佳工具   | Agent 会调研各种方案，选出最合适的软件包  |
| 遵循当前最佳实践 | 获取最新的开发模式和安全实践           |
| 突破限制     | 克服知识截止时间的限制，使用训练之后发布的软件包 |
| 数据准确     | 你的应用展示当前信息，而不是过时的示例      |
| 专业的成果    | 引用真实公司信息的应用更具可信度         |
| 节省时间     | 无需手动调研软件包和收集数据           |

<div id="source-citations">
  ### 来源引用
</div>

Agent 使用 网页搜索 时，会提供**来源引用**，明确标明信息的出处。你可以借助这些引用：

* **验证信息**：核实来源的可靠性和准确性
* **深入了解**：访问原始来源，获取更多背景信息
* **标注来源**：在你的应用中注明出处
* **追踪研究过程**：了解哪些信息为 Agent 的工作提供了依据

<div id="content-fetching">
  ### 内容抓取
</div>

Agent 可以从指定网站抓取详细内容，为你的 project 收集全面的信息。这让 Agent 能够：

* 通读整个网页，提取相关细节
* 处理文档和参考资料
* 从权威来源获取特定数据
* 将结构化信息集成到你的应用中
