Replit 相信，计算属于每一个人。因此，Replit 致力于让包括残障人士在内的所有人都能无障碍地使用我们的服务。本声明介绍我们的无障碍目标、为实现这些目标所取得的进展，以及如何就 Replit 的无障碍情况提供反馈。

<div id="section">
  # 符合性目标
</div>

我们的目标是完全符合 W3C WAI《网页内容无障碍指南》 (WCAG) 2.1。WCAG 2.1 为设计师和开发者规定了提升残障人士无障碍体验的要求。Replit 已部分符合 WCAG 2.1 AA 级标准。部分符合意味着网站的部分内容尚未完全符合无障碍标准。

<div id="section-2">
  # 当前状态
</div>

Replit 持续开展内部项目，以改善网站的无障碍体验。该项目参考了内部评估、对构建者的访谈和报告，以及 Cornell University IT 部门于 2021 年进行的独立评估结果。

网站上的大部分内容目前均以符合现行 W3C HTML 和 CSS 标准的 HTML 格式提供。对于图片和表单元素等非文本内容，我们提供了可由屏幕阅读器识别和朗读的文本替代方案。

尽管 Replit 持续致力于确保无障碍访问，您仍可能遇到一些限制。尤其是，无法仅使用键盘完全操作工作区是一个已知问题，Replit 正在努力解决。

<div id="section-3">
  # 提供反馈
</div>

如果您在访问 Replit 网站时遇到问题，请发送电子邮件至 [contact@replit.com](mailto:contact@replit.com) 向我们反馈。请告知您尝试访问的内容的 URL (网址) 、遇到的问题以及您的联系信息。
