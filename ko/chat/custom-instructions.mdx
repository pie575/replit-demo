Custom Instructions는 사용자나 팀이 Workspace에 한 번만 작성해 두면 항상 적용되는 지침입니다. Replit이 해당 Workspace의 Projects와 세션 전반에서 이 지침을 참고하므로, Conversation마다 팀의 규칙을 반복해서 설명할 필요가 없습니다.

Custom Instructions는 승인된 라이브러리, 보안 요건, 데이터 처리 정책처럼 항상 지켜야 하는 소수의 지침에만 사용하세요. 실제 작업을 위한 여지를 남길 수 있도록 짧고 구체적으로 작성하세요.

<div id="choose-the-right-kind-of-guidance">
  ## 알맞은 가이드 방식 선택하기
</div>

* 항상 적용해야 하는 workspace 전체 지침에는 **Custom Instructions**를 사용하세요.
* 특정 task에만 해당하는 재사용 가능한 방식과 참고 자료에는 [Skills](/ko/chat/agent-skills)를 사용하세요.
* Replit이 이전 작업에서 기억해 둔 유용한 context에는 [Memories](/ko/chat/memories)를 사용하세요.

<div id="set-up-custom-instructions">
  ## Custom Instructions 설정
</div>

Custom Instructions는 **Workspace Settings → Customization**에서 관리합니다. 자세한 기능 가이드에서 설정 방법, 사용 가능 여부, 권한, 그리고 지침을 효과적으로 유지하는 방법을 확인할 수 있습니다.
