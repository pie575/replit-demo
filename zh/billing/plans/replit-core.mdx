[Replit Core](https://replit.com/replit-core) 会员可使用高级工具，助你快速将创意变为 App。有关当前 Core 定价 (月付或年付) ，请参阅[定价页面](https://replit.com/pricing)。

<div id="key-features">
  ## 主要功能
</div>

Core 会员包含以下功能：

<div id="ai-powered-tools">
  ### AI 驱动的工具
</div>

* **Agent**：与 Agent 对话，构建、调试并迭代你的应用
* **付费 Agent 模式**：需要更强能力时，使用 Power 或 Max
* **Free Mode**：在额度范围内与 Agent 对话并构建应用，无需额外费用
* **智能模型路由**：在 Power 或 Max 中，由 Replit 为每个付费任务自动选择模型
* **Design Canvas**：探索视觉创意、生成多种方案，并将设计转化为 artifact
* **Visual Editor**：以可视化方式直接编辑应用的内容和布局
* **全部 artifact 类型**：web app、移动应用、数据可视化、幻灯片演示文稿、动画视频等
* **Plan 模式**：与 Agent 一起头脑风暴、规划工作，无需编辑代码
* **Connectors**：集成 Google、Stripe 等第三方服务

<div id="collaboration">
  ### 协作
</div>

* 最多邀请 5 位成员加入你的 Workspace，无需单独订阅团队套餐
* 后台任务：一次可运行 1 个任务
* 用于规划和跟踪工作的共享看板

<div id="lightning-fast-and-secure-development">
  ### 极速而安全的开发体验
</div>

* 在高性能的云端开发环境中工作
* 按量付费，避免服务中断
* 使用 Secrets 工具将敏感数据与代码分离，安全存储

各方案的费用与限制，请参见<a href="https://replit.com/pricing" target="_blank">定价页面</a>。

<div id="monthly-credits">
  ### 每月积分
</div>

* 每月获得的积分会自动用于支付 Agent、发布、网络传输、数据库存储和 Replit AI 集成等服务。需要更多构建者席位或更高的积分档位？请参阅 [Replit Pro](/zh/billing/plans/replit-pro)。

<div id="one-click-publishing">
  ### 一键发布
</div>

所有方案均可使用发布。免费的 Starter 方案仅支持发布 1 个 App，而 Replit Core 取消了这一上限，并提供更多选项：

* 发布数量不限的 App
* 从多种发布选项中选择，优化支出
* 使用内置的日志与分析功能
* 移除已发布 App 上的“Made with Replit”徽标

<div id="ai-powered-support-and-community-events">
  ### AI 智能支持与社区活动
</div>

* 获得 AI 智能支持，快速解决账单、账户、产品和技术问题
* 访问会员专属论坛和活动
* 抢先体验新功能

<div id="getting-started">
  ## 开始使用
</div>

只需几步即可升级到 Replit Core：

1. 前往 <a href="https://replit.com/pricing" target="_blank">Pricing</a> (定价) 页面
2. 选择 **Join Replit Core** (加入 Replit Core)
3. 选择 **Monthly** (按月) 或 **Yearly** (按年) 方案，并填写付款信息
