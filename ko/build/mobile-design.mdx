앱의 겉모습은 앱이 하는 일만큼이나 중요한 부분입니다. PixelGames는 휴대폰 속의 게임보이입니다. 크림색 외피, 올리브 그린 화면, 두툼한 버튼이 바로 핵심이죠.
평범한 앱 레이아웃으로는 그 느낌을 살릴 수 없습니다.

<div id="troubleshooting">
  ## 문제 해결
</div>

* **변경 범위가 원하는 것보다 넓어진 경우:** Agent에게 되돌려 달라고 요청한 뒤, 화면 하나 또는
  요소 하나씩 더 작은 단위로 변경 사항을 설명하세요.
* **미리보기에서는 정상인데 휴대폰에서는 이상한 경우:** 기기 이름과 어떤 현상이 나타났는지 알려주세요. 대개
  안전 영역과 화면 크기 처리 문제가 원인입니다.
* **변경 사항이 계속 되돌아가는 경우:** 같은 값이 여러 곳에 설정되어 있을 수 있습니다. 해당 화면의
  스타일이 실제로 어디에 정의되어 있는지 Agent에게 물어보세요.
