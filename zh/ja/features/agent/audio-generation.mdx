使用 Agent 的音频生成功能，为应用添加声音。让 Agent 创建背景音乐、音效和旁白，生成的音频会直接添加到项目中。

借助音频生成，您无需录音棚、配音演员或外部工具，即可打造更丰富的体验。无论是游戏、引导式教程，还是需要语音的应用，Agent 都能创建适合项目的音频。

<div id="section">
  ## 可创建的内容
</div>

Agent 可生成三种音频：

* **音乐**：符合指定氛围和风格的背景音乐和主题音乐。
* **音效**：点击声、提示音、呼啸声和游戏音效等短音频片段。
* **语音**：根据输入的文本生成自然流畅的旁白和配音。

<div id="section-2">
  ## 使用方法
</div>

音频生成功能已内置于 Agent，无需启用任何设置。打开任意已启用 Agent 的 Replit App，描述你需要的音频即可。Agent 会根据你的请求判断是否需要生成音频，创建音频片段并将其添加到项目中。

<div id="agent">
  ### Agent 何时生成音频
</div>

当你要求在项目中添加声音时，Agent 会生成音频：

| 使用场景  | 提示词示例                |
| ----- | -------------------- |
| 背景音乐  | “请为冥想应用添加舒缓的背景音乐”    |
| 游戏音效  | “请为游戏创建金币收集音效和跳跃音效”  |
| 语音旁白  | “请生成亲切的声音，朗读引导流程的步骤” |
| 提醒和通知 | “请创建收到新消息时播放的简短提示音”  |

<div id="section-4">
  ## 音频如何集成到应用中
</div>

Agent 会像处理其他资源一样，将生成的音频添加到项目中：

* **自动创建文件**：生成的音频文件会直接保存到项目中。
* **更新代码**：Agent 会将音频集成到应用中，确保其在合适的时机播放。
* **迭代优化**：让 Agent 调整氛围、时长、声音或风格时，它会重新生成音频。

<div id="section-5">
  ## 费用
</div>

音频生成是 Agent 提供的一项服务。费用按提供商的费率计费，并从你的 Replit 积分中扣除。你可以在[使用情况页面](/zh/ja/billing/managing-spend)查看费用。

<Note>
  Replit 的音频生成功能由 [ElevenLabs](https://elevenlabs.io/) 提供支持，可生成高质量的音乐、音效和语音。
</Note>
