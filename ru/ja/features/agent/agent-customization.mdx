Настройка Agent с первого запроса предоставляет Agent контекст, необходимый для работы в вашем стиле и стиле вашей команды. Вместо того чтобы заново объяснять правила в каждом проекте, задайте их один раз в рабочем пространстве — и Agent будет применять их повсюду.

Доступны две функции:

* **Пользовательские инструкции**: постоянно действующие рекомендации, которые применяются ко всем проектам в рабочем пространстве.
* **Навыки**: повторно используемые инструкции, которые Agent загружает только при возникновении соответствующей задачи.

Управляйте обоими в **Workspace Settings → Customization**.

<div id="section">
  ## Различия между пользовательскими инструкциями и навыками
</div>

Пользовательские инструкции загружаются для каждого сообщения. Навыки загружаются только тогда, когда Agent считает их релевантными задаче. Используйте пользовательские инструкции для рекомендаций, которые актуальны всегда, а навыки — для конкретных рабочих процессов, правил и справочных материалов.

Подробнее о том, почему их стоит разделять, как учитывать бюджет контекста, что и где размещать и как эффективно создавать навыки, см. в разделе [Навыки Agent](/ru/ja/learn/agent-skills). О структуре навыков и о том, как Agent их загружает, см. в разделе [Навыки Agent](/ru/ja/features/agent/skills).

<div id="section-2">
  ## Пользовательские инструкции
</div>

Пользовательские инструкции — это постоянно действующие рекомендации, которые добавляются в контекст Agent для всех проектов и сессий ещё до того, как кто-либо введёт запрос. Укажите их один раз в Workspace Settings, и Agent будет применять их во всём рабочем пространстве. Они подходят для неизменно действующих правил: требований безопасности и соответствия нормативам, утверждённых библиотек и фреймворков, политик обработки данных и т. д.

Делайте их краткими. Чем конкретнее и точнее сформулированы инструкции, тем вероятнее, что Agent будет им следовать, и тем больше у него останется места для выполнения работы.

<Warning>
  Пользовательские инструкции могут влиять на работу Agent. Agent старается им следовать, но соблюдение строгих требований не гарантируется. Краткие и конкретные рекомендации соблюдаются надёжнее.
</Warning>

<Note>
  Пользовательские инструкции рабочего пространства отличаются от файла проекта `custom_instruction/instructions.md`. Они задаются один раз в Workspace Settings и применяются ко всем проектам. Файл для конкретного проекта находится внутри одного проекта — подробнее об этом подходе см. в разделе [Создание пользовательской системы дизайна](/ru/ja/teams/custom-design-system).
</Note>

<div id="section-3">
  ## Навыки
</div>

Навык — это набор переиспользуемых инструкций, которые Agent загружает только тогда, когда возникает подходящая задача. Навыки рабочего пространства отображаются в начале меню **+** во всех проектах рабочего пространства, поэтому вся команда пользуется одним и тем же набором.

Создать навык можно тремя способами:

* **Загрузка** — загрузите существующую папку навыка.
* **Создание** — напишите новый навык прямо в форме.
* **Попросить Agent** — попросите Agent подготовить черновик навыка, а затем доработайте его.

<Note>
  Вы можете поручить загрузку навыка Рабочего пространства самому Agent. Попросите Agent скачать навык — он упакует его в загружаемый архив `.zip`, и появится кнопка **Download file** (см. рисунок ниже). Скачайте zip и загрузите его в **Workspace Settings → Customization → Skills** через **Create skill → Choose file or folder**, чтобы навык стал общим для всего рабочего пространства.
</Note>

<Frame>
  <img src="/assets/mirror/agent-customization-download-skill-3727b188c5a8.png" alt="Agent упаковал навык рабочего пространства в загружаемый архив ux-designer-skill.zip, отображается кнопка Download file" width="1716" height="864" data-path="images/replitai/agent-customization-download-skill.png" />
</Frame>

Полную структуру навыка (`SKILL.md`, вспомогательные файлы, открытые стандарты) см. в разделе [Agent Skills](/ru/ja/features/agent/skills). Навыки, уже созданные Replit и партнёрами, можно посмотреть в разделе [Skills directory](/ru/ja/features/agent/skills-directory).

<Note>
  Используйте навыки умеренно. Для каждой задачи Agent читает названия и описания всех навыков. Если навыков слишком много или они дублируют друг друга, фокус размывается и Agent труднее выбрать подходящий. Ограничивайте область каждого навыка и удаляйте те, что больше не нужны.
</Note>

<div id="section-4">
  ## Доступные планы и права доступа
</div>

| Функция                     | Доступные планы   | Кто может управлять                                                         |
| --------------------------- | ----------------- | --------------------------------------------------------------------------- |
| Пользовательские инструкции | Pro и Enterprise  | Enterprise: администраторы. Pro: все участники рабочего пространства        |
| Навыки                      | все платные планы | Enterprise: администраторы. Core и Pro: все участники рабочего пространства |

В рабочих пространствах Enterprise создавать, редактировать и удалять пользовательские инструкции и навыки могут только администраторы. В рабочих пространствах Pro это могут делать все участники. В рабочих пространствах Core все участники могут управлять навыками — пользовательские инструкции в Core недоступны. При этом все участники рабочего пространства могут использовать созданные навыки.

<div id="section-5">
  ## Создание пользовательских инструкций
</div>

<Steps>
  <Step title="Откройте Workspace Settings">
    Перейдите в **Workspace Settings → Customization**.

    <Frame>
      <img src="/assets/mirror/agent-customization-tab-930af2e8ed74.png" alt="Вкладка Customization в Workspace Settings с подкладками Skills и Custom instructions" width="1065" height="394" data-path="images/replitai/agent-customization-tab.png" />
    </Frame>
  </Step>

  <Step title="Напишите инструкции">
    В разделе **Custom instructions** укажите рекомендации, которые Agent должен применять ко всем проектам.
  </Step>

  <Step title="Сохраните изменения">
    Сохраните изменения. Инструкции будут применяться к новым проектам в рабочем пространстве.
  </Step>
</Steps>

<div id="section-6">
  ## Создание навыка
</div>

<Steps>
  <Step title="Откройте настройки Workspace">
    Перейдите в **Workspace Settings → Customization**.
  </Step>

  <Step title="Создайте навык">
    В разделе **Skills** нажмите **Create skill**, затем загрузите папку навыка, напишите инструкции или попросите Agent подготовить черновик.

    <Frame>
      <img src="/assets/mirror/agent-customization-create-skill-fcb794e6de4e.png" alt="Вкладка Customization в Workspace Settings, вкладки Skills и Custom instructions, открыта форма создания навыка" width="2168" height="1350" data-path="images/replitai/agent-customization-create-skill.png" />
    </Frame>
  </Step>

  <Step title="Напишите понятное описание">
    Добавьте описание, в котором чётко указано, когда следует использовать навык, а когда — нет. Agent читает его, чтобы решить, применять ли навык.
  </Step>

  <Step title="Сохраните">
    Сохраните навык. Он станет доступен в меню **+** во всех проектах Workspace.
  </Step>
</Steps>

<div id="section-7">
  ## Использование навыков рабочего пространства в проектах
</div>

Важно, чтобы описание навыка было понятным. Agent читает описания всех навыков рабочего пространства и автоматически подключает нужный навык, если ваш запрос в целом соответствует его назначению, поэтому вам может не понадобиться выбирать навык вручную. Чтобы гарантированно применить навык, можно выбрать его явно.

Чтобы выбрать навык вручную:

<Steps>
  <Step title="Откройте средство выбора навыков">
    В проекте нажмите кнопку **+** рядом с полем ввода сообщения в чате. Навыки рабочего пространства отображаются вверху списка.

    <Frame>
      <img src="/assets/mirror/agent-customization-skill-picker-4643f3a453c7.png" alt="Средство выбора навыков, открытое кнопкой +; группа Workspace skills отображается над Replit skills" width="1668" height="1170" data-path="images/replitai/agent-customization-skill-picker.png" />
    </Frame>
  </Step>

  <Step title="Выберите навык">
    Выберите навык, который хотите использовать. Также можно вызвать его напрямую, введя название навыка после `/`.
  </Step>

  <Step title="Продолжите работу с запросом">
    Продолжайте как обычно. Если задача соответствует описанию навыка, Agent использует этот навык.
  </Step>
</Steps>

<div id="section-8">
  ## Управление инструкциями и навыками
</div>

Все настройки доступны в **Workspace Settings → Customization**. Здесь можно редактировать пользовательские инструкции, а также редактировать, отключать и удалять навыки. Изменения применяются к будущим чатам, но не к текущим.
