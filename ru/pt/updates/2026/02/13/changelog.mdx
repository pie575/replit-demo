<div id="suporte-ao-claude-opus-45">
  ### Поддержка Claude Opus 4.5
</div>

Claude Opus 4.5 теперь поддерживается в ИИ-интеграциях — вы получаете доступ к новейшим возможностям ИИ от Anthropic, оптимизированным для программирования и агентов.

<div id="boto-open-in-replit-beta">
  ### Кнопка Open in Replit (бета)
</div>

Теперь тикеты Linear можно закрывать прямо в Replit с помощью новой кнопки «Open In Replit». Эту бета-функцию нужно включить в настройках; она автоматически подставляет в промпт детали задачи. Команда работает вместе с Linear над улучшением интеграции.

<div id="acesso-do-agent-ao-banco-de-dados-sql-de-produo">
  ### Доступ Agent к продакшен-базе данных SQL
</div>

Теперь Agent может просматривать вашу продакшен-базу данных SQL и выполнять к ней запросы в режиме «только чтение» — это позволяет работать с реальными продакшен-данными без риска случайных изменений.

<div id="melhorias-na-confiabilidade-de-conexo">
  ### Улучшения надёжности подключений
</div>

Ряд доработок, улучшающих работу с интеграциями:

* Токены подключений реже истекают благодаря улучшенному фоновому переподключению
* Наглядное отображение подключений в состоянии ошибки или неактивном состоянии
* Возможность переподключить интеграцию прямо из состояния ошибки

<div id="oramentos-por-usuriogrupo">
  ### Бюджеты по пользователям и группам
</div>

Возможности управления бюджетом теперь доступны всем клиентам Enterprise:

* Администраторы команд Enterprise могут задавать стандартные бюджеты использования для всех участников
* Администраторы могут задавать бюджеты для отдельных групп (например, «Администраторы»/«Участники» и пользовательские группы)
* Скоро: администраторы смогут задавать персональные бюджеты, переопределяющие общие, для отдельных пользователей
