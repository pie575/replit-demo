---

Replit 提供了多种安装和管理 Replit 应用软件包的方式：你可以使用 [Shell](/zh/ja/features/workspace-tools/shell) 安装软件包，也可以交给 [Agent](/zh/ja/features/agent/overview/) 处理，还可以让 Replit 应用在运行时自动检测并安装缺失的依赖项。

<div id="shell">
  ## 使用 Shell 安装软件包
</div>

在项目编辑器中打开 **Shell** 工具，根据所用语言的软件包管理器运行相应命令：

<CodeGroup>
  ```bash Node.js (npm) theme={null}
  npm install <package-name>
  ```

  ```bash Node.js (pnpm) theme={null}
  pnpm add <package-name>
  ```

  ```bash Python (poetry) theme={null}
  poetry add <package-name>
  ```

  ```bash Python (pip) theme={null}
  pip install <package-name>
  ```

  ```bash Ruby theme={null}
  bundle add <gem-name>
  ```
</CodeGroup>

你也可以使用 Replit 的[通用软件包管理器 (UPM)](https://github.com/replit/upm/)，为所有受支持的语言安装软件包：

```bash theme={null}
upm add <package-name>
```

要安装特定版本：

```bash theme={null}
upm add 'flask==2.3.3'
```

有关所有受支持的语言和软件包管理器，请参阅 [UPM：支持的语言](https://github.com/replit/upm/#supported-languages)。

<div id="agent">
  ## 使用 Agent 安装软件包
</div>

你可以在聊天中直接让 [Agent](/zh/ja/features/agent/overview/) 安装软件包。例如：

* “安装 axios 软件包”
* “在项目中添加 Flask 和 SQLAlchemy”
* “配置 TailwindCSS”

Agent 会使用适合当前项目的软件包管理器安装软件包，并更新相关的配置文件。

<div id="section">
  ## 自动导入检测
</div>

每次选择 **Run** 时，Replit 都会自动分析代码，检查是否缺少依赖项。如果代码中导入了尚未安装的软件包，Replit 会检测到并自动安装最新版本。

例如，在 `main.py` 中添加 `import flask` 后，下次选择 **Run** 时，**Console** 中会显示一条消息，提示已安装 **Flask**。

<Note>
  自动导入检测可通过 [.replit](/zh/ja/features/project-setup/configuration#replit-file) 文件中的 `packager.features.guessImports` 设置进行配置。
</Note>

<div id="section-2">
  ### 覆盖自动检测
</div>

如果检测到的软件包有误，或者你需要指定版本，请在 Shell 中运行正确的安装命令。例如：

```bash theme={null}
upm add 'flask==2.3.3'
```

<div id="python">
  ## Python 软件包管理器
</div>

创建 Python Replit 应用时，默认的软件包管理器是 **poetry**。这意味着 `pip install` 并不会管理依赖项。请改为在 Shell 中使用 `poetry add <package>` 或 `upm add <package>`。

<div id="poetrypip">
  ### 从 poetry 切换到 pip
</div>

如果你更习惯使用 `pip`，请按以下步骤操作：

<Steps>
  <Step>
    打开 Shell 并运行：

    删除锁文件，让打包基础设施切换到 pip：

    ```bash theme={null}
    rm poetry.lock
    ```
  </Step>

  <Step title="迁移依赖项">
    将 `pyproject.toml` 中 `[tool.poetry.dependencies]` 部分的依赖项移到 `requirements.txt`。例如，`flask = "^3.0.2"` 会变成 `flask>=3.0.2,<4`。
  </Step>

  <Step title="清理 pyproject.toml">
    从 `pyproject.toml` 中删除 `[tool.poetry...]` 部分。
  </Step>
</Steps>

完成这些更改后，打包基础设施在后续所有操作中都会使用 `pip`，自动导入检测也仍会按预期工作。

<div id="nixdependencies">
  ## 使用 Nix 管理系统依赖项
</div>

Replit 通过集成 [Nix](https://nixos.org/) 支持所有编程语言。如果你需要标准语言软件包之外的系统级依赖项，可以将其添加到 [replit.nix](/zh/ja/features/project-setup/configuration#replit-nix-file) 文件中。

<div id="nix">
  ### Nix 软件包
</div>

直接编辑 `replit.nix` 即可添加系统级依赖项。你可以在 [search.nixos.org](https://search.nixos.org/packages) 上搜索可用的软件包。

<div id="section-3">
  ### 模块
</div>

模块整合了对编程语言、格式化工具和 packager 的支持，为 Replit 应用提供运行基础。当你从模板或 GitHub 仓库创建 Replit 应用时，Replit 会自动安装所需的模块。

你可以通过 [.replit](/zh/ja/features/project-setup/configuration#replit-file) 文件自定义模块及其他 Nix 配置。

<div id="section-4">
  ## packager 设置
</div>

你可以在 [.replit](/zh/ja/features/project-setup/configuration#replit-file) 文件中精细调整软件包管理行为：

| 设置                                    | 说明               | 默认值     |
| ------------------------------------- | ---------------- | ------- |
| `packager.language`                   | 用于软件包操作的语言       | 自动检测    |
| `packager.features.guessImports`      | 运行时自动检测并安装缺失的软件包 | `true`  |
| `packager.features.packageSearch`     | 启用软件包搜索支持        | `true`  |
| `packager.features.enabledForHosting` | 托管时要求安装软件包       | `false` |
| `packager.afterInstall`               | 软件包安装完成后执行的命令    | —       |
| `packager.ignoredPaths`               | 导入检测时忽略的路径       | `[]`    |
| `packager.ignoredPackages`            | 排除在自动检测之外的软件包    | `[]`    |
