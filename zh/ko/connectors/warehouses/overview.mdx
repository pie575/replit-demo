借助数据仓库连接器，Replit Agent 可以安全地查询组织的数据仓库。构建者无需具备 SQL 专业知识，即可使用自然语言创建控制面板、报表工具和数据应用。管理员可通过基于角色的访问控制进行集中管理。

<div id="section">
  ## 支持的数据仓库
</div>

数据仓库连接器适用于 **Enterprise** 套餐。

| 数据仓库             | 设置指南                                                                             |
| ---------------- | -------------------------------------------------------------------------------- |
| BigQuery         | 现已可用 — 设置指南即将推出                                                                  |
| Databricks       | [连接 Databricks](/zh/ko/connectors/warehouses/databricks)                            |
| Microsoft Fabric | [使用 Microsoft Fabric 构建数据应用](/zh/ko/connectors/warehouses/microsoft-fabric) (私有预览)  |
| Snowflake        | [连接 Snowflake](/zh/ko/connectors/warehouses/snowflake)                              |

每个数据仓库的 OAuth 集成、身份模型和凭据格式各不相同，因此设置流程也不同。请选择您使用的数据仓库，并按照相应的专用指南操作。

<div id="section-2">
  ## 分析与数据平台
</div>

除 Enterprise 外，Core 和 Pro 套餐也可使用分析连接器。连接分析工具，让 Agent 能够读取和处理产品数据：

* **Segment** — CDP 中的客户数据、事件流和目标受众细分
* **Amplitude** — 产品分析、用户行为数据和参与度指标
* **Hex** — 协作式数据笔记本和查询结果

请像管理其他 Replit 连接器一样管理这些连接器。请参阅[管理连接器](/zh/ko/replitai/managing-connectors)。

<div id="section-3">
  ## 数据仓库连接器的工作原理
</div>

这是一个涉及三种角色的一次性设置流程：

1. **数据仓库管理员** — 在数据仓库中创建 OAuth 集成或服务身份
2. **Replit 组织管理员** — 将凭据添加到 Replit 并配置访问权限
3. **构建者** — 登录并开始使用 Agent 构建

配置完成后，构建者可要求 Agent 使用数据仓库，Agent 会编写并执行 SQL。

<div id="section-4">
  ### 使用数据仓库数据构建应用
</div>

连接后，您可以让 Agent 构建使用这些数据的应用。Agent 可以：

* 构建获取并展示实时数据的内部工具
* 基于数据仓库数据创建包含图表和可视化内容的控制面板
* 生成用于驱动应用后端的 SQL 查询
* 解释架构和表结构，帮助您了解可以构建哪些内容

<Note>
  Agent 可以回答有关数据的临时问题，但数据仓库连接器的主要用途是让您能够构建利用组织数据的功能性应用。数据仓库查询会直接在实例上执行，因此请确保 OAuth 范围和数据库用户权限允许所需的读写操作。
</Note>
