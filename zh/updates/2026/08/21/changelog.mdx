<div id="work-in-free-mode">
  ### 在 Free Mode 下工作
</div>

使用 Free Mode 聊天、探索创意、创作和构建，无需消耗 Power Mode 或 Max Mode 积分。Free Mode 通过 Auto 自动选择模型，具体限制取决于你的套餐。前往 **设置** &gt; **用量**，即可查看剩余额度和重置时间。

</Frame>

了解如何[充分用好 Free Mode](/zh/chat/free-mode)。

<div id="start-with-conversations">
  ### 从 Conversation 开始
</div>

先创建一个私密的 Conversation，用来提问、查找信息、附加上下文、运行 Routine，或者描述你想要的结果。当工作逐渐深入时，可以让 Replit 把该 Conversation 转换为 Project，你的上下文和文件都会一并延续。

</Frame>

进一步了解 [Conversations](/zh/chat/conversations)。

<div id="automate-recurring-work-with-routines">
  ### 使用 Routine 自动执行重复性工作
</div>

让 Replit 按计划在 Conversation 中重复执行工作。每次的结果都会返回到同一个 Conversation，你可以在其中查看并继续工作。Routine 在 Power Mode 或 Max Mode 下运行，每次运行都需要消耗相应预算。

<Frame caption="在同一页面查看进行中的 Routine、运行计划和历史记录。">
  <img src="/assets/mirror/routines-management-page-c8d8f51156d4.png" alt="Routine 页面列出了一个进行中的每日日历摘要（发送到 Slack）及其运行计划" width="2738" height="782" data-path="images/chat/routines-management-page.png" />
</Frame>

进一步了解 [Routine](/zh/chat/routines)。

<div id="steer-agent-while-working">
  ### 在 Agent 工作时使用 Steer
</div>

在 Agent 工作期间发送 follow-up 消息，为当前的 active turn 补充新的上下文。Steer 是 Conversations 和 Projects 的默认行为，你可以在 **设置** &gt; **Personalization** 中将任一偏好改为 Queue。在 Mac 上按 `Cmd+Enter`，在 Windows 和 Linux 上按 `Ctrl+Enter`，即可让单条消息使用相反的行为。

<Frame caption="为 Conversations 和 Projects 分别选择 Steer 或 Queue。">
  <img src="/assets/mirror/agent-follow-ups-settings-98a4c5ca399e.png" alt="Agent 设置中显示 Conversation 和 Project 的 send behavior，包含 Steer 和 Queue 选项" width="3048" height="1372" data-path="images/replitai/agent-follow-ups-settings.png" />
</Frame>

进一步了解[消息的 steer 与 queue](/zh/features/agent/steer-and-queue-messages)。

<div id="import-skills-from-github">
  ### 从 GitHub 导入 Skills
</div>

从公开的 GitHub 仓库、文件夹或文件 URL 导入 Skills，并在添加前预览 Skill 文件。已保存的 Project Skills 还支持设置成员访问级别：**Required**、**Available** 或 **No access**。

<Frame caption="打开 Workspace Skills，查找并使用共享或导入的 Skills。">
  <img src="/assets/mirror/workspace-skill-picker-d7c3f5525de2.jpg" alt="Agent Workspace Skills 选择器，列出 ask-matt、claude-handoff 和 code-review" width="2000" height="1085" data-path="images/replitai/workspace-skill-picker.jpg" />
</Frame>

详细了解[如何共享和导入 Agent Skills](/zh/features/agent/skills#share-project-skills)。

  ## Teams 与 Enterprise
</div>

<div id="control-agent-models-across-workspaces">
  ### 跨 Workspace 控制 Agent 模型
</div>

Enterprise 账户管理员可以为每个模型身份提供方设置账户级策略，再选择各个 Workspace 中可用的模型。可使用 **Enable all**、**Enable selected** 或 **Disabled**，以符合组织的策略要求。

</Frame>

详细了解 [Enterprise 模型控制](/zh/features/collaboration/enterprise-model-controls)。

<div id="run-black-box-pen-tests">
  ### 运行黑盒渗透测试
</div>

运行 Level 3 security scan，可一次性完成三项检查：免费的 dependency and package checks、Agent 对源代码的静态分析，以及针对实时 Preview 的外部 black-box test。Replit 会并行执行源代码审查和外部测试。

</Frame>
