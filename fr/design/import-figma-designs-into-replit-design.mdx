⏰ *Durée estimée : 15 minutes*

Une maquette Figma montre à quoi l&#39;expérience doit ressembler. Replit Design convertit un frame Figma en frame de design que vous pouvez explorer, affiner, puis transformer en application interactive.

Nous prendrons comme exemple le [Personal Fitness Trainer Template](https://www.figma.com/community/file/1569006333493544411) de la communauté Figma.

<div id="before-you-start">
  ## Avant de commencer
</div>

Vous avez besoin :

* d&#39;un [compte Replit](https://replit.com) ;
* d&#39;un compte [Figma](https://www.figma.com), contenant le fichier que vous souhaitez importer ou le fichier d&#39;exemple ci-dessus.

<div id="import-the-figma-frame">
  ## Importer le frame Figma
</div>

Importez le frame dans Replit Design et laissez Agent le transformer en design fonctionnel.

<Steps>
  <Step title="Récupérer le lien de votre frame Figma">
    Utilisez votre propre fichier Figma ou suivez l&#39;exemple de ce guide : le [Personal Fitness Trainer Template](https://www.figma.com/community/file/1569006333493544411) sur Figma Community.

    Dans Figma, faites un clic droit sur le frame à importer, choisissez **Copy/Paste as**, puis **Copy link to selection**.

    <Frame caption="Le Personal Fitness Trainer Template ouvert dans Figma, avec les frames Cover que vous allez importer.">
      <img src="/assets/mirror/figma-example-file-65988c40d28d.webp" alt="Le Personal Fitness Trainer Template ouvert dans Figma, montrant les frames Cover dans le panneau des calques et sur le canvas" width="3440" height="2160" data-path="images/fitstart/turn-mockup-into-app/figma-example-file.webp" />
    </Frame>
  </Step>

  <Step title="Ouvrir Replit Design">
    Rendez-vous sur [replit.com/design](https://replit.com/design) et sélectionnez **Import Figma** sous le champ de prompt.

    <Frame caption="Import Figma sur l'accueil de Replit Design : importez un frame Figma et Agent le transforme en design fonctionnel.">
      <img src="/assets/mirror/design-import-figma-0a98172e147e.webp" alt="L'accueil de Replit Design avec l'option Import Figma sélectionnée sous le champ de prompt, et une infobulle indiquant d'importer un frame Figma pour qu'Agent le transforme en design fonctionnel" width="2293" height="1322" data-path="images/fitstart/turn-mockup-into-app/design-import-figma.webp" />
    </Frame>
  </Step>

  <Step title="Coller l'URL et lancer la construction">
    Collez l&#39;URL de votre frame dans la boîte de dialogue **Import Figma design** et sélectionnez **Attach to prompt**. Le frame est joint à votre prompt ; envoyez-le pour lancer la construction.

    <Frame caption="La boîte de dialogue Import Figma design avec l'URL du frame collée, prête à être jointe au prompt.">
      <img src="/assets/mirror/design-figma-url-8425e5d8d46d.webp" alt="La boîte de dialogue Import Figma design dans Replit Design avec une URL de frame Figma collée dans le champ et le bouton Attach to prompt" width="2293" height="1440" data-path="images/fitstart/turn-mockup-into-app/design-figma-url.webp" />
    </Frame>
  </Step>
</Steps>

Agent importe le frame et le reconstruit sous forme de frame de design dans votre project.

<Frame caption="La page d'accueil Personal Fitness Trainer importée en tant que frame dans Replit Design.">
  <img src="/assets/mirror/figma-import-result-052394025b8d.webp" alt="La page d'accueil Personal Fitness Trainer importée en tant que frame de design dans Replit Design, avec l'exécution marquée comme terminée dans le panneau de chat" width="3440" height="2160" data-path="images/fitstart/turn-mockup-into-app/figma-import-result.webp" />
</Frame>

<div id="make-it-yours">
  ## Personnalisez-la
</div>

Sélectionnez la frame importée et commencez à la remodeler :

* **Suivez une [suggestion](/fr/design/explore-suggestions)** : l&#39;import arrive avec des propositions d&#39;étapes suivantes, comme une variante éditoriale sombre, une section tarifaire ou un affichage mobile. Chacune génère une nouvelle frame, si bien que l&#39;originale reste disponible pour comparaison.
* **[Discutez-en dans Chat](/fr/design/chat-about-your-design)** : utilisez le champ de saisie sous la frame et exprimez votre demande avec vos propres mots : *« remplace la photo du hero »*, *« rends l&#39;appel à l&#39;action plus percutant »*.
