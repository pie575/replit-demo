---
title: "Tests d’intrusion en boîte noire"
description: "Exécutez une analyse de sécurité Level 3 qui examine le code source et teste l’application en cours d’exécution via les interactions du navigateur et du réseau."
---

Les tests d’intrusion en boîte noire évaluent l’application en cours d’exécution de l’extérieur, via les interactions du navigateur et du réseau. Ils n’utilisent pas le code source de l’application.

Dans le centre de sécurité du projet, **Level 3 (AI pentest)** exécute les trois types de contrôles de sécurité suivants :

1. Vérifications gratuites des dépendances et des paquets
2. Analyse statique du code source par Agent
3. Tests en boîte noire du Preview en direct depuis l’extérieur, sans utiliser le code source

Lorsque vous lancez Level 3, Replit exécute en parallèle la revue du code source par Agent et les tests d’intrusion externes en boîte noire.

<div id="level-3">
  ## Exécuter une analyse Level 3
</div>

<Steps>
  <Step title="Ouvrir le projet">
    Ouvrez le projet que vous souhaitez analyser.
  </Step>

  <Step title="Ouvrir le Security Center">
    Dans le volet **Tools** du projet, sélectionnez **Security Center**.
  </Step>

  <Step title="Lancer l'analyse">
    En haut du Security Center, sélectionnez **Run scan**.
  </Step>

  <Step title="Sélectionner Level 3">
    Sélectionnez **Level 3 (AI pentest)**.

    <Frame caption="Level 3 (AI pentest) ajoute l'analyse statique de l'Agent et des tests externes en direct sur le Preview, en plus des vérifications gratuites des dépendances et des paquets.">
      <img src="/assets/mirror/level-3-ai-pentest-c223c0099d3f.png" alt="Security and Privacy Center ouvert depuis le volet Tools, avec le menu de sélection du niveau d'analyse déployé et Level 3 AI pentest sélectionné" width="2204" height="1200" data-path="images/project-security-center/level-3-ai-pentest.png" />
    </Frame>
  </Step>

  <Step title="Attendre la fin des deux tâches">
    Attendez que la revue du code source ainsi que les tests en boîte noire du navigateur et du réseau soient terminés.
  </Step>

  <Step title="Examiner les résultats">
    Examinez les résultats des deux tâches dans le volet **Security**. Évaluez chaque résultat avant d&#39;envoyer à l&#39;Agent les problèmes que vous avez approuvés.
  </Step>

  <Step title="Corriger et relancer">
    Envoyez les résultats approuvés à l&#39;Agent. Une fois les correctifs appliqués, lancez une nouvelle analyse Level 3 pour les vérifier.
  </Step>
</Steps>

<div id="2">
  ## Comprendre les deux tâches
</div>

| Tâche                | Éléments utilisés                                                                     | Objectif                                                                                                |
| -------------------- | ------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| Revue du code source | Le code source de l&#39;application                                                   | Identifie les vulnérabilités de sécurité, de confidentialité et d&#39;architecture dans la base de code |
| Test en boîte noire  | Les interactions navigateur et réseau avec l&#39;application en cours d&#39;exécution | Vérifie les comportements observables de l&#39;extérieur, sans recourir au code source                  |

Passez en revue les résultats des deux tâches. L&#39;une ne remplace pas l&#39;autre : la revue du code source permet d&#39;identifier les détails d&#39;implémentation vulnérables, tandis que le test en boîte noire évalue l&#39;application en cours d&#39;exécution depuis l&#39;extérieur.
