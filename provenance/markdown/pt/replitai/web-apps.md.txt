# Aplicativos Web

> Saiba como construir aplicativos web full-stack com o Agent — responsivos por padrão, implantáveis instantaneamente e compartilháveis.

Aplicativos web são o tipo de saída padrão no Replit. Quando você descreve uma ideia ao Agent, ele constrói um aplicativo web full-stack a menos que você especifique um tipo de artefato diferente.

## Primeiros passos

Há duas maneiras de criar um aplicativo web:

* **Digite um prompt**: Descreva o que você quer construir na página inicial do Replit. O Agent cria automaticamente um aplicativo web.
* **Selecione no menu suspenso**: Abra o menu suspenso de tipo de aplicativo na página inicial e escolha **Aplicativo web**, depois descreva sua ideia.

## Recursos principais

* **Full-stack por padrão**: Cada aplicativo web inclui um frontend e um backend. O Agent configura rotas de API, um banco de dados e lógica do lado do servidor conforme seu aplicativo precisar.
* **Design responsivo**: Os aplicativos se adaptam automaticamente a diferentes tamanhos de tela.
* **Implantação instantânea**: Publique seu aplicativo com um clique. O Replit cuida da hospedagem, SSL e infraestrutura.
* **Infraestrutura compartilhada**: Se o seu projeto tiver vários artefatos — como um aplicativo mobile ou dashboard de dados — todos eles compartilham o mesmo backend, banco de dados e serviços.

## Casos de uso

* **Produtos SaaS**: Construa ferramentas voltadas para clientes, dashboards e plataformas.
* **Ferramentas internas**: Crie painéis admin, CRMs ou aplicativos de fluxo de trabalho para sua equipe.
* **Landing pages**: Lance sites de marketing com formulários, animações e conteúdo dinâmico.
* **Marketplaces e diretórios**: Construa sites de listagens, quadros de empregos ou plataformas comunitárias.
