export const YouTubeEmbed = ({videoId, title = "YouTube video", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

### Meilleure gestion des images pour les URL Unsplash cassées

Dites adieu aux images d'archives cassées dans vos projets !

Si vous ne le saviez pas, Agent ajoute déjà des images d'archives à vos projets depuis Unsplash. Mais parfois les URL se cassent. La raison ? Les LLM sont très doués pour halluciner des URL d'images d'archives.

Nous avons ajouté une fonctionnalité qui remplace automatiquement les images d'archives cassées par des alternatives fonctionnelles, garantissant que vos applications s'affichent toujours de manière professionnelle.

## Équipes et Entreprise

### Paramètres de confidentialité améliorés pour les déploiements enterprise

Les clients Enterprise disposent désormais d'un plus grand contrôle sur la confidentialité des déploiements avec plusieurs options de configuration.

Cette fonctionnalité améliorée permet aux organisations de gérer précisément l'accès à leurs applications déployées, offrant la sécurité et la flexibilité que les environnements d'entreprise exigent. Les utilisateurs d'équipe bénéficient désormais également de déploiements privés par défaut, nécessitant une activation explicite pour le partage public.
