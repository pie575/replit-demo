<div id="assistant">
  ### Assistant 性能提升
</div>

Assistant 近期的性能改进获得了客户和用户的积极反馈。性能提升为所有 Assistant 用户带来了更流畅的使用体验。这些改进虽与 Agent 的上下文收集无关，但可能会为后续优化提供参考。

<div id="agent">
  ### Agent 稳定性提升
</div>

我们进行了多项修复以提升 Agent 的稳定性，包括减少破坏性变更、解决在异常 nix 环境中的崩溃问题，以及修复 bash 工具的执行问题。
