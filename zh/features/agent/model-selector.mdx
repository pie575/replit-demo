借助模型选择器，你可以让 Replit 采用智能模型路由，也可以自行选择一个可用的模型。

<div id="intelligent-model-routing">
  ## 智能模型路由
</div>

智能模型路由会为每项任务选择合适的模型，在质量与成本之间取得平衡。当你在产品中看到 **Auto** 时，就说明 Replit 正在进行智能模型路由。

智能模型路由会综合考量你请求的工作内容及其复杂度。范围明确的请求可以使用成本更低的模型，复杂的工作则可能需要能力更强的模型。随着任务变化，Replit 可以切换到不同的模型。

<Note>
  Free Mode 始终使用智能模型路由。在 Free Mode 下，构建者无法使用模型选择器，也无法手动选择模型。
</Note>

<div id="choose-a-model-manually">
  ## 手动选择模型
</div>

Core 和 Pro 用户可以在 Power 模式或 Max 模式下选择可用的模型。

1. 在提示框中选择 **Agent Mode**，菜单中会显示可用模式：**Free**、**Power** 和 **Max**。
2. 选择 **Power** 或 **Max**，然后找到 **主模型** 部分。
3. 打开主模型菜单，从列表中选择所需模型。

所选模型将在你发送的下一条消息中生效，你可以随时更改。

<div id="effort">
  ## Effort
</div>

**Effort 是针对单个模型的控制项，而非独立模式。** 它决定所选模型在每次响应中投入多少推理，取值从 **Low** 到 **Max**。每个模型都会显示推荐设置，只有在任务确实需要时才应调高。

<Frame caption="模型列表下方的 Effort 滑块，已设置为 Medium。">
  <img src="/assets/mirror/model-selector-effort-bcffb01239a8.png" alt="Primary 模型列表中已选中 Claude Fable 5，Effort 滑块设置为 Medium，描述为适用于日常任务的均衡推理" width="984" height="832" data-path="images/replitai/model-selector-effort.png" />
</Frame>

请参考各级别的说明：

| Effort         | 适用场景                           |
| -------------- | ------------------------------ |
| **Low**        | 推理最少，响应最快。适用于常规、定义明确且最看重速度的改动。 |
| **Medium**     | 面向日常任务的均衡推理。若推荐设置未另作说明，选它比较稳妥。 |
| **High**       | 面向较复杂工作的深度推理，例如多步骤功能和不太熟悉的领域。  |
| **Extra High** | 面向最棘手问题的扩展推理，例如大规模重构和难缠的缺陷。    |
| **Max**        | 最大推理深度。成本最高、速度最慢，适用于只求最佳结果的场景。 |

Effort 越高，Agent 的推理越深入、越审慎，并会调用能力最强的前沿模型，从而在最复杂的任务上取得更好的结果。不过，Agent 会有选择地动用这份额外算力：只有当请求确实困难时才路由到能力更强的模型，而不是每次运行都如此。

<Tip>
  由于 Agent 只在最困难的任务上才会启用能力最强的模型，
  调高 Effort 在最棘手的任务上最多会带来约 2 倍的成本增加，
  而在较简单的任务上往往几乎不增加成本。处理复杂问题时请调高，
  常规改动则保持较低设置。
</Tip>

<div id="compare-models">
  ## 对比模型
</div>

**对比模型**会让你的下一个 prompt 同时在多个模型上运行，这样你就能并排比较结果，而不用猜哪个模型更合适。该功能目前处于 Beta 阶段。

要开启该功能，请展开 Agent 模式弹出面板底部的 **Advanced settings**，然后打开 **Compare models**。

<Note>对比模型仅支持在 Chat 中使用。</Note>

<Frame caption="Advanced settings 下的 Compare models 开关。">
  <img src="/assets/mirror/compare-models-toggle-05429dc46d64.png" alt="展开的 Advanced settings，其中 Compare models Beta 开关处于关闭状态，说明为使用你的下一个 prompt 创建最多 4 个变体" width="1110" height="344" data-path="images/replitai/compare-models-toggle.png" />
</Frame>

打开开关后，最多可添加 **4 个模型**参与对比。

<Frame caption="已选择四个模型进行对比，发送按钮显示为 Compare 4。">
  <img src="/assets/mirror/compare-models-9f5bcecec727.png" alt="Agent 模式弹出面板中已开启 Compare models，并有四个可移除的模型槽位：Kimi K3、Claude Fable 5、Claude Opus 5 和 GPT-5.6 Sol。聊天发送按钮显示为 Compare 4" width="1192" height="1930" data-path="images/replitai/compare-models.png" />
</Frame>

随后，你的下一个 prompt 会在每个所选模型上各运行一次，每个模型都会生成各自的变体供你对比。

<Note>
  对比中的每个模型都会运行一个独立的 agent 并消耗积分，因此一次
  Compare 4 的开销大致相当于四次单独运行。
</Note>
