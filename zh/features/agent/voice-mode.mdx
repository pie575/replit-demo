使用语音模式，直接开口描述你想构建的内容。点击 Agent 聊天框中的麦克风图标，说出你的 prompt，Replit 就会把语音转写为可编辑的文本。检查文本、按需修改，然后像发送其他消息一样发送即可。

在打字慢或不便打字时，语音模式尤其好用——特别是在手机上，口述一段完整的 prompt 通常比用拇指敲字快得多。

<Note>
  语音模式只会把你的语音转成聊天框中的文字，并不会朗读 Agent 的回复——你发送的仍是一条文字消息，Agent
  也照常在聊天中回复。
</Note>

<div id="how-it-works">
  ## 工作原理
</div>

语音模式 会录下你的语音并转写成文字，然后将结果插入聊天框，供你发送前确认：

1. 打开 Agent，点击聊天框中的麦克风。
2. 如果浏览器或设备弹出提示，请允许访问麦克风。
3. 说出你的 prompt。出现波形即表示 Agent 正在录音。
4. 说完后停止录音。停顿一段时间或切换到其他标签页时，录音也会自动停止。
5. 稍等片刻，等待语音转写完成。
6. 检查转写文本，按需编辑，然后发送消息。

由于转写结果以普通文本形式出现在聊天框中，你可以随意混用语音和键盘输入——先口述一部分 prompt，再打字补全其余内容，或在发送前改掉某个词。

<Tip>
  正常说话即可。语音模式 侧重于捕捉你的意图，而非逐字转写，因此“嗯”“呃”
  之类的语气词不会出现在结果中。
</Tip>

<div id="where-you-can-use-it">
  ## 可以在哪些地方使用
</div>

语音模式可在 Agent 聊天框中使用：

* 在 **Project Editor** 中与 Agent 一起开发应用时。
* 在主屏幕的 Agent prompt 输入框中**创建新应用**时。

语音模式支持桌面网页端、移动网页端以及 Replit 移动应用。

<div id="good-to-know">
  ## 须知事项
</div>

使用语音模式时请留意以下细节：

| 细节    | 预期情况                                               |
| ----- | -------------------------------------------------- |
| 录制时长  | 单次最长可录制 6 分钟。临近上限时会收到提示。                           |
| 自动停止  | 静音约 30 秒后会自动停止录制；切换标签页或将应用切换到后台时也会停止。              |
| 发送前检查 | 转写后的文本会显示在聊天框中，你可以先阅读、编辑后再发送——不会自动发送。              |
| 麦克风权限 | 语音模式需要麦克风使用权限。如果无法开始录制，请检查浏览器和设备是否允许 Replit 使用麦克风。 |

<div id="availability">
  ## 可用性
</div>

所有 Replit 方案均支持语音模式。在支持录音的浏览器和设备上，Agent 聊天框中会显示麦克风图标；首次录音时，系统会请求麦克风权限。
