<div id="section-3">
  ### Пользовательские промпты
</div>

<Note>
  **Обновление (декабрь 2025 г.):** поддержка Assistant прекращена. Для быстрых точечных правок используйте [режим Lite в Agent](/ru/core-concepts/agent/agent-modes).
</Note>

Пользовательские промпты дают полный контроль над тем, как работает Assistant. Задать определённые стандарты кодирования, изменить параметры Assistant по умолчанию — всё это решается с помощью пользовательских промптов.

Добавить можно, например, следующее:

* Определённый стиль кодирования или фреймворк
* Конкретные приёмы решения задач
* Предпочтения по управлению пакетами

Например, можно добавить следующее:

```
use pnpm for package management
use motion/react instead of framer-motion
always use claude-3-5-sonnet-20241022 as your model
```

<div id="workflows">
  ### Рабочие процессы
</div>

Рабочий процесс — это легко настраиваемая кнопка «Run» для выполнения нужных команд.

Это последовательность повторно используемых и настраиваемых шагов, которые можно запускать в Replit App. Она может быть простой, например **`python main.py`**, или представлять собой сложный процесс из нескольких шагов.

Примеры использования:

* Параллельный запуск нескольких сервисов (например, фронтенда и бэкенда)
* Последовательный запуск файлов или команд (например, запуск линтера → запуск тестов, компиляция → запуск кода)

Чтобы начать [создавать рабочий процесс](https:/.replit.com/replit-workspace/workflows#creating-workflows), используйте меню на боковой панели инструментов или найдите панель рабочих процессов с помощью **`Command + K`**.

Подробнее [здесь](https:/.replit.com/replit-workspace/workflows).
