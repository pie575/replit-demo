Workspace Security Center는 모든 plan에서 사용할 수 있습니다. 이 기능으로 workspace 전반의 프로젝트 [dependencies](/ko/features/security/concepts#dependency)를 스캔하고 [심각도](/ko/features/security/concepts#severity)별로 [CVE](/ko/features/security/concepts#cve) 발견 항목를 검토하세요. Replit Agent로 issues를 해결하고, 영향을 받은 프로젝트를 [republish](/ko/features/security/concepts#republish)하고, 규정 준수를 위해 소프트웨어 자재 명세서([SBOM](/ko/features/security/concepts#sbom)) report를 내보낼 수 있습니다.

<Note>
  프로젝트 하나만 스캔하려면 해당 프로젝트 내부의 **Security** pane에서 [Project Security Center](/ko/features/security/project-security-center)를 여세요.
</Note>

<Note>
  dependency 보안이 처음이신가요? CVE, SBOM, 노출 수준, Fix with Agent, Republish, Auto-Protect의 정의는 [보안 개념](/ko/features/security/concepts)에서 확인하세요.
</Note>

  ## 기능

<div id="cve-detection">
  ### CVE 탐지
</div>

workspace 내 모든 프로젝트의 취약점을 한눈에 확인할 수 있습니다.

* [노출 수준](/ko/features/security/concepts#exposure)(게시 상태 및 공개 범위) 기준으로 우선순위가 매겨진 취약 프로젝트 식별
* 영향을 받는 패키지 이름, 버전, 심각도(치명적, 높음, 보통, 낮음) 확인
* 프로젝트별 remediation 가이드 확인

<div id="affected-projects-view">
  ### 영향받는 프로젝트 보기
</div>

어떤 프로젝트에 취약점이 있는지 파악하고 무엇부터 수정할지 우선순위를 정하세요:

* 취약한 프로젝트를 노출 수준별로 묶어 개요 확인: 전체 프로젝트, 게시된 프로젝트, 공개로 게시된 프로젝트
* 영향받는 Replit 프로젝트의 상세 내역 확인
* CVE ID 또는 프로젝트 이름으로 검색하고 심각도, 소유자, 게시 상태(Published / Not published), 공개 범위(Public / Private)로 필터링
* 프로젝트 행을 펼쳐 페이지를 벗어나지 않고 모든 CVE 발견 항목(심각도, 패키지, 버전, CVE ID) 확인

<div id="fix-with-agent-and-republish">
  ### Fix with Agent 및 재게시
</div>

Security Center를 벗어나지 않고 취약점을 해결하고 다시 배포할 수 있습니다:

* 영향을 받는 프로젝트에서 **[Fix with Agent](/ko/features/security/concepts#fix-with-agent)**를 선택하면 해당 프로젝트에 백그라운드 task로 패치 초안이 생성됩니다. 재게시하기 전에 생성된 변경 사항을 검토하고 적용하세요.
* **Task in progress**, **Apply changes**, **Republish**와 최종 상태인 **Republished** 또는 **Failed**로 remediation 진행 상황을 추적할 수 있습니다.
* 수정 사항이 merge되면 확인 대화 상자와 함께 제공되는 원클릭 **Republish**로 기존 configuration을 그대로 사용해 build를 다시 배포합니다.
* 게시 취소, 프로젝트 소유자에게 해당 프로젝트의 취약점 알리기 등 일괄 작업도 수행할 수 있습니다.

<div id="sbom-export">
  ### SBOM 내보내기
</div>

규정 준수 및 감사를 위해 소프트웨어 자재 명세서(SBOM)를 내보냅니다:

* 표준 형식([SPDX](/ko/features/security/concepts#spdx-and-cyclonedx), [CycloneDX](/ko/features/security/concepts#spdx-and-cyclonedx))으로 SBOM 다운로드
* 개별 프로젝트 또는 workspace 전체에 대한 보고서 생성
* 스캔 실행 단위로 묶인 SBOM을 타임스탬프, 프로젝트 수, 실행을 시작한 사용자 정보와 함께 확인
* 스캔 실행에 포함된 모든 SBOM을 하나의 zip 파일로 일괄 다운로드
* 소프트웨어 공급망 투명성에 관한 규정 준수 요구사항 충족

<Note>
  SBOM 일괄 다운로드는 Enterprise plan에서 사용할 수 있습니다. 다른 plan을 사용하는 workspace에서는 SBOM 섹션에 Enterprise 업그레이드 안내가 표시됩니다.
</Note>

<div id="accessing-the-workspace-security-center">
  ## Workspace Security Center 접속하기
</div>

Workspace Security Center를 열려면 다음 단계를 따르세요.

1. [replit.com](https://replit.com)에 접속해 계정에 로그인합니다.
2. 홈 페이지 왼쪽 탐색 메뉴에서 **Security**를 선택합니다.

<div id="scanning-your-workspace">
  ## workspace 스캔하기
</div>

<Frame>
  <img src="/assets/mirror/security-overview-b37f090f236c.png" alt="총 스캔 수, 총 취약점 수, 심각도별로 분류된 CVE를 보여주는 Workspace Security Center 랜딩 화면" width="3438" height="1984" data-path="images/workspace-security-center/security-overview.png" />
</Frame>

1. Workspace Security Center를 엽니다.
2. **Run security scan**을 선택해 workspace 전체를 스캔합니다.
3. 영향을 받은 프로젝트, 심각도, deployment exposure별로 정리된 결과를 검토합니다.
4. 영향을 받은 프로젝트에서 **Fix with Agent**를 선택한 뒤, 수정이 적용되면 **Republish**를 선택합니다.

스캔은 workspace 내 Replit 프로젝트의 dependencies를 분석해 공개 취약점 데이터베이스에 등록된 알려진 취약점을 표시합니다.

<div id="auto-protect">
  ## Auto-Protect
</div>

Admin은 계정에 **[Auto-Protect](/ko/features/security/concepts#auto-protect)**를 활성화할 수 있습니다. 이 기능은 새로 공개된 CVE를 모든 프로젝트의 dependencies와 지속적으로 대조합니다. 일치하는 항목이 발견되면 Replit Agent가 테스트를 마친 패치를 준비하고, builders는 해당 패치를 바로 적용할 수 있는 링크가 담긴 이메일을 받습니다.

**Settings** &gt; **Account** &gt; **Advanced**의 Admin 전용 심각도 임계값을 포함한 전체 workflow와 설정 단계는 [Auto-Protect](/ko/features/security/project-security-center#auto-protect)를 참고하세요.

<Note>
  Workspace Security Center 구성이나 SBOM 내보내기의 규정 준수 workflows 통합에 도움이 필요하면 전담 account manager에게 문의하세요.
</Note>
