Agent の音声生成機能を使ってアプリにサウンドを追加しましょう。バックグラウンドミュージック、効果音、ナレーションの作成を Agent に依頼すると、音声がプロジェクトに直接追加されます。

音声生成により、レコーディングスタジオ、声優、外部ツールを使わずに豊かな体験を構築できます。ゲーム、ガイド付きチュートリアル、声が必要なアプリなど、Agent がプロジェクトに合った音声を作成します。

## 作成できるもの

Agent は3種類の音声を生成できます：

* **音楽**: 指定したムードとスタイルのバックグラウンドトラックとテーマ音楽。
* **効果音**: クリック音、アラート、ウォッシュ音、ゲームサウンドなどの短いクリップ。
* **音声**: 入力したテキストから自然な響きのナレーションとボイスオーバー。

## 使い方

音声生成は Agent に組み込まれているため、設定をオンにする必要はありません。Agent が有効になっている任意の Replit App を開いて、必要な音声を説明してください。Agent がリクエストに基づいて音声を生成するタイミングを判断し、クリップを作成してプロジェクトに追加します。

### Agent が音声を生成するタイミング

Agent はプロジェクトにサウンドを求めたときに音声を生成します：

| ユースケース         | プロンプト例                                |
| -------------- | ------------------------------------- |
| バックグラウンドミュージック | 「瞑想アプリに落ち着いたバックグラウンドミュージックを追加してください」  |
| ゲームの効果音        | 「ゲーム用のコイン取得音とジャンプ音を作成してください」          |
| ボイスナレーション      | 「オンボーディングのステップを読み上げる親しみやすい声を生成してください」 |
| アラートと通知        | 「新しいメッセージが届いたときに鳴る短いチャイムを作成してください」    |

### プロンプトの例

始めるためにこれらのプロンプトを試してみてください：

<AiPrompt>
  アーケードゲームのメインメニューにアップビートな 8 ビットのバックグラウンドミュージックを追加してください。繰り返しても単調にならないよう短めにしてください。
</AiPrompt>

<AiPrompt>
  アプリが読み込まれるときにこのウェルカムメッセージを読み上げる、落ち着いた温かみのある声を生成してください：「Welcome back. Let's pick up where you left off.」
</AiPrompt>

<AiPrompt>
  To-Do アプリ用に3つの短い効果音を作成してください：タスクをチェックオフするときの柔らかいクリック音、穏やかなエラー音、リスト全体をクリアしたときの祝福音。
</AiPrompt>

## 音声がアプリに組み込まれる仕組み

Agent が生成した音声を他のアセットと同じ方法でプロジェクトに追加します：

* **自動ファイル作成**: 生成された音声ファイルはプロジェクトに直接保存されます。
* **コードの更新**: Agent が適切なタイミングで音声が再生されるようアプリに組み込みます。
* **反復**: ムード、長さ、声、スタイルの調整を Agent に依頼すると、音声を再生成します。

## 料金

音声生成は Agent のサービスです。Agent がプロバイダーのレートで課金し、Replit クレジットから差し引かれます。料金は[使用状況ページ](/ja/billing/managing-spend)に表示されます。

<Note>
  Replit の音声生成は、高品質な音楽、効果音、音声を生成する [ElevenLabs](https://elevenlabs.io/) によって動作しています。
</Note>
