Agent 支持四类集成，助你快速把想法变成应用：

* **Replit 托管**：自动生效的内置集成。创建应用后，Agent 立即就能使用。
* **Connectors**：Replit 提供的第一方集成。只需登录一次，Agent 就能直接在 Chat 中读写这些服务——拉取数据、创建记录、发送消息——并在你的各个应用中基于它们进行构建。
* **外部集成**：可用于构建的受信任第三方服务。让 Agent 帮你完成配置，你需要提供 API 密钥。
* **Agent 服务**：Agent 在后台调用的付费第三方 API——无需 API 密钥。用量将从你的 Replit 积分中扣除。

<Note>
  **计划可用性**：大多数 connector 需要 Core、Pro 或 Enterprise 订阅，部分 connector 在 Free 计划上也可使用。workspace 中的 connector 目录会显示你当前计划可使用哪些 connector。Free 计划的构建者始终可以使用 Replit 托管的集成，例如数据库、身份验证等。
</Note>

<div id="getting-started">
  ## 开始使用
</div>

要使用某个集成，只需提及你需要的服务或功能即可。例如：

<AiPrompt>
  创建一个 web app，使用 Stripe 收款，并使用 SendGrid 发送确认邮件
</AiPrompt>

Agent 会自动识别这些关键词，并生成相应的代码和配置。

<div id="let-agent-suggest-a-connector">
  ### 让 Agent 推荐 connector
</div>

有时，多个服务都能完成同一项任务，例如存储文件或发送电子邮件。当你需要某项功能但未指定身份提供方时，Agent 会显示一份符合需求的 connector 简短列表。选择你想要的 connector。

选择身份提供方，然后登录一次以连接你的账户。Agent 会在构建过程中使用你的选择。你也可以直接点名特定服务，以跳过该列表。

<div id="connectors">
  ## Connectors
</div>

Connectors 让 Agent 直接读写你的服务，它们是由 Replit 提供支持的第一方集成。只需在 Project Editor 的 Connectors 页面登录一次，即可在各个 App 中复用这些连接。

  连接与你的 Replit 账号绑定，在你的所有 App 中始终有效。只需连接一次服务，即可在你创建的任意 App 中使用。
</Note>

<div id="configuring-oauth-app-with-replit">
  ### 在 Replit 中配置 OAuth 应用
</div>

<Note>
  **仅限 Enterprise**：配置自定义 OAuth 应用需要 Enterprise 订阅。
</Note>

在 Enterprise 计划下，你可以为 connector 使用自有的 OAuth 应用，而不使用 Replit 的默认应用。这样一来，OAuth 客户端归你的组织所有，授权同意页面上可展示你自己的品牌标识，你也能精确控制构建者可请求的权限范围。

要使用自有 OAuth 应用配置 connector，你需要从身份提供方获取三样东西：**Client ID**、**Client Secret** 以及你想要授权的**权限范围 (scopes)&#x20;**。你还需要在身份提供方处注册 Replit 的回调 URL，身份验证才能顺利完成。

<Frame>
  <img src="/assets/mirror/connector-oauth-configuration-100911ce0c48.png" alt="Connector OAuth 配置对话框，包含 Client ID、Client Secret 和 Connector Scopes 字段，以及设置为 https://replit.com/connectors/oauth/callback 的 Redirect URL" width="1112" height="1218" data-path="images/replitai/connector-oauth-configuration.png" />
</Frame>

<Steps>
  <Step title="在身份提供方处创建 OAuth 应用">
    登录身份提供方的开发者控制台或管理设置，创建一个新的 OAuth 2.0 应用。不同身份提供方对该步骤的叫法各不相同——请查找类似 **Create OAuth app**、**Register application** 或 **Create client credentials** 的选项。
  </Step>

  <Step title="设置回调 URL">
    当身份提供方要求填写 **Authorized redirect URI** (有时称为 **Callback URL** 或 **Redirect URL**) 时，请输入：

    ```
    https://replit.com/connectors/oauth/callback
    ```

    构建者授权应用后，身份提供方会通过该 URL 将他们送回 Replit。该地址必须完全一致——末尾斜杠、协议和子域都不能有差异。如果你添加了多个重定向 URI，其中必须包含这一个。
  </Step>

  <Step title="复制 Client ID 和 Client Secret">
    创建应用后，身份提供方会显示 **Client ID** 和 **Client Secret**。

    * **Client ID**：你的 OAuth 应用的公开标识符，可以安全地出现在 URL 和客户端代码中。
    * **Client Secret**：用于证明请求来自你的应用的机密值。请像对待密码一样对待它——切勿提交到代码仓库或公开分享。Replit 会代你安全存储。

    部分身份提供方只在创建时显示一次 client secret。请立即复制并妥善保存，直到将其粘贴到 Replit 中。
  </Step>

  <Step title="选择权限范围">
    **权限范围 (Scopes) **是一组权限，用于定义你的 OAuth 应用可以代表构建者读取或写入哪些内容。每个身份提供方都会在其 API 文档中公布各自的权限范围列表。

    在 Replit 中配置 connector 时，你输入的权限范围必须与你在身份提供方处注册的权限范围**完全一致** (逐字符一致，包括任何 URL 前缀) 。不匹配错误的常见原因包括：

    * 缺少完整的 URL 前缀 (例如 `https://www.googleapis.com/auth/drive.file` 与 `drive.file`) 。
    * 多余的空格或末尾的逗号。
    * 在 Replit 中请求了身份提供方应用上未启用的权限范围。

    建议先从构建者所需的最小权限范围开始，日后如有需要再添加——大多数身份提供方都允许你在不重新创建应用的情况下更新权限范围。
  </Step>

  <Step title="在 Replit 中配置 connector">
    在你所属组织的 **Connectors** 页面，选择 **Add new integration**，选中相应服务，然后粘贴来自身份提供方的 **Client ID**、**Client Secret** 和 **Scopes**。选择 **Configure** 保存。
  </Step>
</Steps>

<Note>
  如果配置完成后身份验证失败，请再次确认身份提供方处的回调 URL 与 `https://replit.com/connectors/oauth/callback` 完全一致，并确认你在 Replit 中输入的每个权限范围在身份提供方的应用上也已获得授权。
</Note>

<div id="debugging-connectors">
  ## 调试 connector
</div>

连接服务时遇到问题？以下指南将带你了解常见错误及其解决方法。

<AccordionGroup>
  <Accordion title="Google Workspace：&#x22;This app is blocked&#x22;">
    如果在连接 Google Drive、Docs、Sheets、Calendar 或 Gmail 时看到 **&quot;This app is blocked&quot;**，很可能是你所在组织的 Google Workspace 限制了第三方 OAuth 应用。请参阅完整的故障排查指南来解决此问题。

    [解决 Google connector 的 &quot;This app is blocked&quot; 问题](/zh/features/troubleshooting/debugging-google-connectors)
  </Accordion>

  <Accordion title="Salesforce：&#x22;Connection Expired&#x22;">
    如果 Salesforce connector 无法正常工作并报出 **&quot;Connection Expired&quot;** 错误，很可能是你所在 Salesforce 组织的刷新令牌策略设置为在指定期限后让令牌过期。请参阅完整的故障排查指南来更新 Connected App 设置。

    [修复 Salesforce 连接过期错误](/zh/features/troubleshooting/debugging-salesforce-connectors)
  </Accordion>
</AccordionGroup>
