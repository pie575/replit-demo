<div id="preview-empty-state-improvements">
  ### Preview 空状态优化
</div>

Agent 应用中的 Preview 现在能更智能地处理空状态和自动运行，让你使用 Agent 构建应用时流程更顺畅。

<div id="ai-latency-improvements">
  ### AI 延迟优化
</div>

通过基础设施优化，Replit AI 的响应时间和延迟均显著降低。在 Replit 中使用包括 Agent 和 Assistant 在内的各项 AI 功能时，你会感受到更快的交互体验。

<div id="unified-github-tab-refresh">
  ### 统一 GitHub 标签页焕新
</div>

GitHub 集成标签页现采用更简洁、更统一的界面，让你能在 Workspace 中更直观地连接和管理 GitHub 仓库。

<div id="ios-app-payment-support">
  ### iOS App 支付支持
</div>

iOS 用户现在可以直接通过 Replit 移动 App 购买 Replit Core 并设置支付方式，让你能更轻松地随时随地使用高级功能。

<div id="stripe-checkout-release">
  ### Stripe 结账流程上线
</div>

全新的 Stripe 结账流程集成为所有开发者带来更流畅、更安全的支付体验。借助这一符合行业标准的支付解决方案，购买流程更加简化，升级至 Replit Core 也更轻松。

<div id="scim-provisioning-streamlined">
  ### 简化 SCIM 预配流程
</div>
