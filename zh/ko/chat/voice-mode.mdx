使用语音模式，说出你想构建的内容。在 Agent 聊天框中点击麦克风，说出你的提示词，Replit 会将语音转写为可编辑的文本。查看文本，按需修改后，像发送其他消息一样发送即可。

当打字较慢或不方便时，语音模式尤其有用——特别是在移动设备上，口述完整提示词通常比用拇指打字更快。

<Note>
  语音模式会将你的语音转换为聊天框中的文本。它不会朗读
  Agent 的回复——你仍需发送文字消息，Agent 会像往常一样
  在聊天中回复。
</Note>

<div id="how-it-works">
  ## 工作原理
</div>

语音模式会录制你的语音、将其转写为文本，并将结果插入聊天框，供你在发送前查看：

1. 打开 Agent，点击聊天框中的麦克风图标。
2. 如果浏览器或设备提示你授权，请允许访问麦克风。
3. 说出你的提示词。出现波形表示 Agent 正在录音。
4. 说完后停止录音。暂停一段时间后，或切换到其他标签页时，录音也会自动停止。
5. 稍等片刻，等待语音转写完成。
6. 查看转写后的文本，必要时进行编辑，然后发送消息。

转写内容会以普通文本显示在聊天框中，因此你可以自由结合语音和键盘输入：先口述部分提示词，再输入其余内容，或者在发送前修改某个词。

<Tip>
  自然说话即可。语音模式更注重捕捉你的意思，而非逐字转写，因此“嗯”“呃”等语气词不会出现在结果中。
</Tip>

<div id="where-you-can-use-it">
  ## 可在何处使用
</div>

你可以在以下位置的 Agent 聊天框中使用语音模式：

* 在 **Project Editor** 中使用 Agent 开发 App 时。
* 在主屏幕上通过 Agent 提示词 **创建新 App** 时。

你可以在桌面网页端、移动网页端和 Replit 移动 App 上使用语音模式。

<div id="good-to-know">
  ## 使用须知
</div>

使用语音模式时，请注意以下事项：

| 事项      | 说明                                                    |
| ------- | ----------------------------------------------------- |
| 录音时长    | 每次最多可录制 6 分钟。接近时长上限时，你会看到提示。                          |
| 自动停止    | 静音约 30 秒后，或切换标签页或将 App 切至后台时，录音会自动停止。                 |
| 发送前检查   | 转写的文本会显示在聊天框中，你可以在发送前阅读和编辑；系统不会自动发送任何内容。              |
| 麦克风访问权限 | 语音模式需要获得使用麦克风的权限。如果无法开始录音，请检查浏览器和设备是否允许 Replit 访问麦克风。 |

<div id="availability">
  ## 可用性
</div>

所有 Replit 套餐均可使用语音模式。在支持录音的浏览器和设备上，Agent 聊天框中会显示麦克风图标；首次录音时，系统会请求麦克风权限。
