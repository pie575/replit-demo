<div id="neon-db-history-retention">
  ### Neon DB 历史记录保留期限
</div>

Neon 数据库现已支持自定义历史保留期，帮助你更有效地控制成本。这直接回应了用户对数据库成本管理的反馈。

<div id="enhanced-link-context-features">
  ### 链接上下文功能增强
</div>

现在，你可以在 Assistant 和 Agent 中查看链接内容的实时预览 (截图和文本) 。该功能同样适用于 Replit 移动 App。

<div id="assistant-model-selection">
  ### Assistant 模型选择
</div>

<div id="web-view-performance-improvements">
  ### Web View 性能改进
</div>

Web View 中的 iframe 导航更加流畅，与安全网站的兼容性也有所提升。代理系统现已增强，能够更智能地处理安全标头，避免您此前可能遇到的导航受阻问题。
