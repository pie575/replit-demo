description: "Découvrez les serveurs MCP mis en avant qui connectent Replit Agent à vos outils et services préférés."

Utilisez ce répertoire pour découvrir des serveurs qui fournissent des outils spécialisés, des sources de données ou des flux de travail via le Model Context Protocol (MCP). Chaque fiche comprend un bref résumé et un badge Replit pour vous aider à choisir les serveurs à connecter à vos projets.

Cette liste n&#39;est pas exhaustive : vous pouvez [ajouter n&#39;importe quel serveur MCP distant](/fr/pt/features/mcp/overview#add-an-mcp-server) et l&#39;utiliser avec Replit Agent.

<Info>
  Cliquez sur le badge **Add to Replit** pour installer un serveur. Vous serez invité à autoriser la connexion dans l&#39;éditeur de projet.
</Info>
