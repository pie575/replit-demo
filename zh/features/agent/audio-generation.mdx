借助 Agent 的音频生成能力，为你的应用加入声音。只需让 Agent 创建背景音乐、音效或语音旁白，它就会把音频直接添加到你的 project 中。

有了音频生成，无需录音棚、配音演员或外部工具，你也能打造更丰富的体验。无论是制作游戏、引导式教程，还是需要语音的应用，Agent 都能生成契合你 project 的音频。

<div id="what-you-can-create">
  ## 你可以创作什么
</div>

Agent 可以生成三类音频：

* **音乐**：按你描述的情绪和风格生成背景音乐与主题曲。
* **音效**：点击声、提示音、呼啸声、游戏音效等短音频片段。
* **语音**：根据你提供的文本生成自然流畅的旁白与配音。

<div id="usage">
  ## 使用方法
</div>

音频生成功能已内置于 Agent，无需手动开启。用 Agent 打开任意 Replit App，描述你需要的音频即可。Agent 会根据你的请求判断何时生成音频，创建音频片段并将其添加到你的 project 中。

<div id="when-agent-generates-audio">
  ### Agent 何时生成音频
</div>

当你在项目中要求添加声音时，Agent 会生成音频：

| 使用场景  | prompt 示例                |
| ----- | ------------------------ |
| 背景音乐  | “为我的冥想应用添加舒缓的背景音乐”       |
| 游戏音效  | “为我的游戏创建一个金币收集音效和一个跳跃音效” |
| 语音旁白  | “生成一段亲切的语音，朗读我的引导步骤”     |
| 提醒与通知 | “制作一段短提示音，在收到新消息时播放”     |

<div id="how-audio-fits-into-your-app">
  ## 音频如何融入你的应用
</div>

Agent 会像处理其他资源一样，把生成的音频添加到你的 project 中：

* **自动创建文件**：生成的音频文件会直接保存到你的 project 中。
* **代码更新**：Agent 会把音频接入你的应用，让它在恰当的时刻播放。
* **迭代优化**：让 Agent 调整氛围、时长、音色或风格，它就会重新生成音频。

<div id="billing">
  ## 计费
</div>

音频生成属于 Agent 服务。Agent 按提供方的费率计费，费用从你的 Replit 积分中扣除，并显示在[用量页面](/zh/billing/managing-spend)上。

<Note>
  Replit 的音频生成由 [ElevenLabs](https://elevenlabs.io/) 提供支持，可生成高质量的音乐、音效和语音。
</Note>
