<div id="plan">
  ## 什么是 Plan 模式？
</div>

使用 Plan 模式，你可以：

* **头脑风暴**，探索项目的各种实现思路
* 通过**结构化的任务列表**规划开发工作
* 在项目架构和功能规划方面**与 AI 协作**
* **获取策略性指导**并随时提问，而不会改动项目的代码或数据
* 准备好动手实现时**无缝切换到 Build 模式**

默认模式目前称为 **Build** 模式。

与 Build 模式不同，Plan 模式专注于规划和构思，帮助你在写代码之前把项目想清楚。

<div id="section">
  ## 快速入门
</div>

<div id="plan-2">
  ### 访问 Plan 模式
</div>

只要 Replit App 启用了 Agent，即可使用 Plan 模式。访问步骤如下：

1. 在项目编辑器中**打开 Replit App**
2. 找到聊天输入框左下角的**模式选择器**
3. 在下拉菜单中**选择 Plan 模式**

<div id="section-2">
  ## 主要功能
</div>

<div id="section-3">
  ### 任务规划
</div>

Plan 模式擅长将复杂项目拆解为易于管理的任务。只需向 Agent 提供一些需求，它就会生成一份有序的任务列表，列出完成该请求所需的各项开发任务。

<div id="section-4">
  ### 协作头脑风暴
</div>

与 AI 一起探索多种不同的思路：

* 针对复杂问题的**多条解决路径**
* 各种方案的**优缺点分析**
* **风险评估**与缓解措施

<div id="section-5">
  ## 工作流：从规划到构建
</div>

<div id="1-plan">
  ### 1. 计划阶段 (Plan 模式) 
</div>

在 Plan 模式下开始开发流程：

* **定义项目范围与目标**
* **将需求拆解为具体功能**
* **规划架构与技术栈**
* **制定包含里程碑的开发路线图**

<div id="2">
  ### 2. 批准任务
</div>

Agent 生成任务列表后：

* **查看**提案的任务
* 选择**开始构建**以批准该计划

或者继续通过聊天进一步完善计划。

<div id="3-build">
  ### 3. 切换到 Build 模式
</div>

准备好开始实现时：

* **点击&quot;开始构建&quot;**以批准计划
* **Agent 会自动切换到 Build 模式**
* **Agent 开始实现已批准的任务**
* **在整个开发阶段跟踪进度**

使用 Plan 模式与其他 Agent 交互一样，按工作量计费。Plan 模式下 Agent 的所有工作 (回答问题、提供指导、生成任务列表) 都会计费。请求越复杂，或对话上下文越长，费用就越高。

**所有 Agent 交互均会计费** —— 无论 Agent 是给出文字指导还是修改代码，都会产生费用 (不过较小的请求成本更低) 。

  ## 最佳实践
</div>

<div id="section-10">
  ### 高效提示
</div>

要充分发挥 Plan 模式的作用：

* 对项目需求描述得**具体明确**
* 通过**追问**厘清 AI 的建议
* 讨论复杂概念时**要求提供示例**
* **探讨**不同方案的**取舍**
* 在着手实现之前**反复打磨想法**
* **保存关键决策**，以便在后续对话中引用
