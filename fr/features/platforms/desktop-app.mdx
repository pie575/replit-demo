L&#39;<a href="https://replit.com/desktop" target="_blank">application de bureau Replit</a> offre toute l&#39;expérience Replit sur votre ordinateur. Créez avec Agent dans une application dédiée, avec des fonctionnalités natives que vous ne retrouvez pas dans un onglet de navigateur.

<div id="what-is-the-replit-desktop-app">
  ## Qu&#39;est-ce que l&#39;application de bureau Replit
</div>

L&#39;application de bureau Replit est une application native repensée pour Windows et Mac. Elle offre la même expérience que sur le web : vous pouvez créer des apps, discuter avec Agent et publier, le tout depuis une seule fenêtre. Elle y ajoute quelques possibilités propres à une application de bureau :

* **Multitâche** : travaillez sur plusieurs Replit Apps à la fois.
* **Indicateurs d&#39;état** : voyez d&#39;un coup d&#39;œil quand Agent a besoin de vous ou a terminé son travail.
* **Aperçus d&#39;onglets** : jetez un œil à vos apps ouvertes sans passer de l&#39;une à l&#39;autre.
