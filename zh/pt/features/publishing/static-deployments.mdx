title: "静态发布"
description: "了解如何使用 Static Deployments 发布静态网站和前端应用。"
---

Static Deployments 会将你的 Replit App 中的静态文件 (如 HTML、CSS 和 JavaScript) 托管在
云服务器上。服务器会自动采用缓存和扩缩策略，快速且经济地分发你的内容。

Static Deployments 非常适合以下使用场景：

* 营销落地页
* 作品集网站
* 产品与 API 文档站点

<Note>
  Static Deployments 不支持使用 Agent 创建的 Replit App。
  Agent 会自动创建需要后端服务器的 full-stack 应用。对于
  由 Agent 生成的应用，请使用以下 deployment 类型之一： - [Autoscale
  Deployment](/zh/pt/features/publishing/autoscale-deployments) - [Reserved VM
  Deployment](/zh/pt/features/publishing/reserved-vm-deployments)
</Note>

<div id="recursos">
  ## 功能
</div>

Static Deployments 包含以下功能：

* **经济实惠的托管**：仅按站点传输的数据量付费。
* **HTTP 路由选项**：配置响应标头、URL 重写和重定向。
* **自定义域名**：配置自定义域名，或使用 `<应用名称>.replit.app` URL 访问你的应用。
* **自定义错误页面**：创建并提供自定义 404 错误页面。
* **监控**：查看日志并监控已发布应用的状态。

<div id="uso">
  ## 使用方法
</div>

你可以在 Project Editor 的 Publishing 工具中使用 Static Deployments。

<Accordion title="如何打开 Static Deployments">
  在左侧的 **Tool dock** 中：

  1. 选择 <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="所有工具图标" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**，查看 Project Editor 的工具列表。
  2. 选择 <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Publishing 图标" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publishing**。
  3. 选择 **Static** 选项，然后选择 **Set up your published app**。

  在**搜索栏**中：

  1. 选择顶部的 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 放大镜图标，打开搜索工具
  2. 输入“Publishing”查找该工具，并在结果中选择它。
  3. 选择 **Static** 选项，然后选择 **Set up your published app**。
</Accordion>

<div id="domnio-principal">
  ### 主域名
</div>

为已发布的应用指定主机名中的子域名部分。发布后，你可以通过 `https://<subdomain>.replit.app` 访问已发布的应用。

要了解如何使用自定义域名，请参阅[自定义域名](/zh/features/publishing/custom-domains)。

<div id="deployment-privado">
  ### 私有 deployment
</div>

<Info>
  私有发布应用功能仅在 Pro 和 Enterprise 计划中提供。
</Info>

私有发布应用只允许你的 workspace 成员，或你邀请的特定用户和群组访问应用。
发布时，你可以选择 **Public**、**Password protected**、**Workspace only** 或 **Invite only** 访问方式。

如需了解如何设置私有 deployment，请参阅[应用访问](/zh/features/publishing/private-deployments/)。

<div id="diretrio-pblico">
  ### 公共目录
</div>

指定 Replit App 中存放静态文件的基础目录路径，这些文件将被公开提供访问。
部署后，云端主机会提供该目录下的所有页面和资源。

默认值 `/` 表示 Replit App 的根目录。

<div id="build-command">
  ### Build command
</div>

指定一条构建命令 (build command) ，在你创建 Deployment 时于 Replit App 的 Shell 中执行。

例如，如果你使用 <a href="https://gohugo.io/" target="_blank">Hugo</a> 生成静态网站，
可以使用 `hugo --minify` 命令生成文件并优化资源体积。

<div id="deployment-secrets">
  ### Deployment secrets
</div>

选择 **Add deployment secret**，添加构建命令安全运行所需的环境变量或 Secrets。

例如，如果你的站点生成器需要 API 密钥来生成静态站点，可以按 `API_KEY=<你的 secret 名称>` 的格式传入。
