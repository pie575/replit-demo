Décrivez à voix haute ce que vous souhaitez créer grâce à Voice Mode. Appuyez sur le microphone dans la zone de chat d&#39;Agent, énoncez votre prompt : Replit transcrit vos paroles en texte modifiable. Relisez ce texte, apportez-y les modifications souhaitées, puis envoyez-le comme n&#39;importe quel autre message.

Voice Mode est particulièrement utile lorsque la saisie est lente ou peu pratique — notamment sur mobile, où dicter un prompt complet va souvent plus vite que de le taper au pouce.

<Note>
  Voice Mode transforme vos paroles en texte dans la zone de chat. Il ne lit pas
  à voix haute les réponses d&#39;Agent : vous envoyez toujours un message écrit, et Agent répond
  dans le chat comme d&#39;habitude.
</Note>

<div id="how-it-works">
  ## Fonctionnement
</div>

<Frame>
  <img src="/assets/mirror/voice-mode-mic-button-fe7da6953736.png" alt="La zone de chat d'Agent avec le bouton microphone mis en évidence et une infobulle « Start voice input », à côté de la case Plan et de la flèche d'envoi" width="1853" height="423" data-path="images/replitai/voice-mode/voice-mode-mic-button.png" />
</Frame>

Voice Mode enregistre votre voix, la transcrit et insère le résultat dans la zone de chat pour que vous puissiez le relire avant de l&#39;envoyer :

1. Ouvrez Agent et sélectionnez le microphone dans la zone de chat.
2. Autorisez l&#39;accès au microphone si votre navigateur ou votre appareil vous le demande.
3. Énoncez votre prompt. Une forme d&#39;onde indique qu&#39;Agent est en train d&#39;enregistrer.
4. Arrêtez l&#39;enregistrement lorsque vous avez terminé. L&#39;enregistrement s&#39;arrête aussi automatiquement après une pause ou lorsque vous changez d&#39;onglet.
5. Patientez un instant, le temps que votre voix soit transcrite.
6. Relisez le texte transcrit, modifiez-le si nécessaire, puis envoyez votre message.

Comme la transcription apparaît sous forme de texte ordinaire dans la zone de chat, vous pouvez combiner librement voix et saisie : dictez une partie d&#39;un prompt, puis tapez le reste, ou corrigez un mot avant l&#39;envoi.

<Tip>
  Parlez naturellement. Voice Mode cherche à capter ce que vous voulez dire plutôt
  qu&#39;à transcrire chaque mot à la lettre : les mots parasites comme « euh » et « hum »
  sont donc écartés du résultat.
</Tip>

<div id="where-you-can-use-it">
  ## Où l&#39;utiliser
</div>

Voice Mode est disponible dans la zone de Chat d&#39;Agent :

* Dans le **Project Editor**, lorsque vous travaillez avec Agent sur une app.
* Lorsque vous **créez une nouvelle app** depuis le champ de prompt d&#39;Agent sur l&#39;écran d&#39;accueil.

Vous pouvez utiliser Voice Mode sur le web (ordinateur et mobile) ainsi que dans l&#39;application mobile Replit.

<div id="good-to-know">
  ## Bon à savoir
</div>

Gardez ces détails à l&#39;esprit lorsque vous utilisez Voice Mode :

| Détail                         | À quoi s&#39;attendre                                                                                                                                                                                            |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Durée d&#39;enregistrement     | Enregistrez jusqu&#39;à 6 minutes d&#39;affilée. Un avertissement s&#39;affiche peu avant d&#39;atteindre la limite.                                                                                             |
| Arrêt automatique              | L&#39;enregistrement s&#39;arrête tout seul après environ 30 secondes de silence, ou lorsque vous changez d&#39;onglet ou passez l&#39;application en arrière-plan.                                              |
| Vérification avant l&#39;envoi | Le texte transcrit s&#39;affiche dans la zone de chat : vous pouvez le relire et le modifier avant de l&#39;envoyer — rien n&#39;est envoyé automatiquement.                                                     |
| Accès au microphone            | Voice Mode a besoin de votre autorisation pour utiliser le microphone. Si l&#39;enregistrement ne démarre pas, vérifiez que votre navigateur et votre appareil autorisent l&#39;accès au microphone pour Replit. |

<div id="availability">
  ## Disponibilité
</div>

Voice Mode est disponible sur tous les forfaits Replit. Le microphone apparaît dans la zone de Chat d&#39;Agent sur les navigateurs et appareils compatibles avec l&#39;enregistrement audio, et l&#39;autorisation d&#39;accès au microphone vous sera demandée lors de votre premier enregistrement.
