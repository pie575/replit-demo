Canvas — это бесконечное пространство с панорамированием и масштабированием, в котором Replit Design отображает фреймы. Здесь находится всё, что вы создаёте: создавайте фреймы, перетаскивайте их, приближайте детали и повторяйте, пока не добьётесь нужного результата.

<div id="canvas">
  ## Открытие Canvas
</div>

Canvas — это первый экран, который вы увидите в Replit Design. В проекте выберите **Design** в заголовке, чтобы открыть Canvas на всю панель, или выберите **Build**, чтобы вернуться к работающему приложению.

<Frame>
  <img src="/assets/mirror/canvas-design-button-ffa50447cefb.png" alt="Увеличенный заголовок проекта с переключателями Design и Build. Выбран Design, а ниже на Canvas расположены фреймы" width="987" height="619" data-path="images/replitai/canvas-design-button.png" />
</Frame>

Если перейти на [replit.com/design](https://replit.com/design), появится предложение создать новый дизайн, который откроется в Canvas. О том, когда использовать каждый из этих экранов, см. в разделе [Design vs. Build](/ru/ko/design/design-vs-build).

<div id="canvas-2">
  ## Что находится на Canvas
</div>

* **Frames**: все плитки на доске. Фрейм может быть макетом дизайна, веб-приложением, мобильным приложением, слайдом, изображением, видео или векторной графикой. Создавайте их с помощью промптов в чате, через [меню Generate](/ru/ko/design/toolbar#generate) на панели инструментов или [панель библиотеки](/ru/ko/design/library-panel). Все действия с фреймом — Build, Focus, предложения — выполняются через сам фрейм: см. [Frames](/ru/ko/design/frames).
* **Рисунки и заметки**: разметка, которую вы добавляете [инструментом Draw](/ru/ko/design/toolbar#draw), — наброски, стрелки, фигуры, стикеры и прочее. Agent считывает разметку, поэтому вы можете обвести проблемное место и попросить внести изменения.
* **Панель чата**: Agent-чат, закреплённый рядом с Canvas. Если выбрать фрейм перед отправкой сообщения, он прикрепится в виде снимка, и у Agent появится визуальный контекст.

О том, что представляет собой каждый компонент и как они связаны между собой, читайте в [обзоре компонентов](/ru/ko/design/core-components).

<div id="section">
  ## Навигация по доске
</div>

Если не указано иное, панорамирование, масштабирование и выделение работают в любом инструменте.

**Панорамирование:**

* Трекпад: перетаскивание двумя пальцами.
* Мышь: нажмите среднюю кнопку и перетаскивайте либо удерживайте пробел и перетаскивайте левой кнопкой мыши.
* [Инструмент Pan](/ru/ko/design/toolbar#pan): нажмите и перетаскивайте левой кнопкой мыши.

**Масштабирование:**

* Трекпад: сведите или разведите пальцы.
* Мышь: `Ctrl` (на macOS — `Cmd`) + колесо прокрутки.
* Клавиатура: для увеличения — `Cmd`/`Ctrl` + `+`, для уменьшения — `Cmd`/`Ctrl` + `-`, для сброса масштаба — `Cmd`/`Ctrl` + `0`.

Масштабирование привязано к курсору: точка под курсором остаётся на месте, а остальная часть доски масштабируется вокруг неё.

**Выделение:**

* Один фрейм: щёлкните по нему инструментом [Interact](/ru/ko/design/toolbar#interact).
* Несколько фреймов: удерживайте `Shift` и щёлкайте по каждому фрейму или перетащите на доске прямоугольную область выделения.
* Снять выделение: щёлкните по пустой области или нажмите `Escape`.

При выделении одного или нескольких фреймов отображается [панель действий для каждого фрейма](/ru/ko/design/frames#per-frame-action-bar), а эти фреймы прикрепляются в виде снимков к следующему сообщению Agent.

<div id="section-2">
  ### Сочетания клавиш
</div>

| Сочетание                      | Действие                            |
| ------------------------------ | ----------------------------------- |
| `V`                            | Активировать инструмент Interact    |
| `H`                            | Активировать инструмент Pan         |
| `Space` + перетаскивание       | Панорамирование в любом инструменте |
| `Cmd` / `Ctrl` + прокрутка     | Масштабирование                     |
| `Cmd` / `Ctrl` + `+`           | Увеличить                           |
| `Cmd` / `Ctrl` + `-`           | Уменьшить                           |
| `Cmd` / `Ctrl` + `0`           | Сбросить масштаб                    |
| `Shift` + щелчок               | Добавить фрейм к текущему выделению |
| `Cmd` / `Ctrl` + `Shift` + `C` | Скопировать выбранный фрейм как PNG |
| `Escape`                       | Снять выделение                     |

<div id="section-3">
  ## Меню правой кнопки мыши
</div>

Клик правой кнопкой мыши в любом месте доски открывает контекстное меню. Его состав зависит от контекста: набор действий определяется тем, что находится под курсором. Для фрейма доступны действия с фреймом, для пустого Canvas — действия уровня доски, а для фрейма приложения добавляется **Refresh artifact**.

Меню выделенного фрейма содержит следующие пункты.

| Действие                       | Сочетание клавиш              | Что делает                                                         |
| ------------------------------ | ----------------------------- | ------------------------------------------------------------------ |
| Edit                           |                               | Переключает на инструмент Edit для выбора элементов внутри фрейма.  |
| Chat                           |                               | Открывает Chat с Agent по этому фрейму.                             |
| Focus                          |                               | Переходит из фрейма в [режим фокуса](/ru/ko/design/frames#focus-mode). |
| Cursor chat                    | `/`                           | Запускает быстрый чат в позиции курсора.                           |
| Reorder                        |                               | Перемещает фрейм вперёд или назад в порядке наложения.             |
| Copy, Paste, Duplicate, Delete | `⌘C`, `⌘V`, `⌘D`, `Backspace` | Стандартные функции буфера обмена и управления фреймом.              |
| Export as…                     |                               | Экспортирует фрейм в файл.                                         |
| Select all                     | `⌘A`                          | Выделяет все фреймы на доске.                                       |

<div id="png">
  ### Экспорт фрейма в PNG
</div>

Сохраняйте любой артефакт или фрейм дизайна в виде PNG-изображения. Это удобно, чтобы поделиться предпросмотром в документе или чате, зафиксировать состояние перед следующими итерациями или отправить коллегам скриншот.

<Steps>
  <Step title="Выберите фрейм">
    Выберите артефакт или фрейм дизайна для экспорта и дождитесь завершения загрузки.
  </Step>

  <Step title="Выберите Export">
    На панели действий фрейма выберите **Export**. Можно также щёлкнуть фрейм правой кнопкой мыши и выбрать **Export as…** &gt; **PNG**. Изображение скачается на компьютер, а его имя будет основано на названии фрейма.
  </Step>
</Steps>

Чтобы скопировать выбранный фрейм в формате PNG, а не скачивать его, нажмите `Cmd+Shift+C` (`Ctrl+Shift+C` в Windows и Linux).

<Note>Экспортированный PNG соответствует тому, что сейчас отображается во фрейме Canvas. Если приложение или дизайн всё ещё загружается, перед экспортом дождитесь полной отрисовки.</Note>

<div id="canvas-3">
  ## Canvas и запущенное приложение
</div>

Canvas и предпросмотр запущенного приложения размещаются в одной панели, а связывают их несколько режимов.

* **Режим фокуса**: действие **Focus** для выбранного фрейма разворачивает его на весь экран. Чтобы вернуться в Canvas, выберите **Exit focus** в верхней части доски.
* **Режим только для чтения**: если Canvas заблокирован в контексте фоновой задачи, действия, связанные с итерациями, скрываются и остаётся только Focus.

<Note>
  Чтобы собрать новое приложение из фрейма в Design, нужен тариф Core или Pro. Все остальные возможности Canvas доступны на любом тарифе. Подробнее о тарифах см. в разделе [Billing](/ru/ko/billing/ai-billing).
</Note>
