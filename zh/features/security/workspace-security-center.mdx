Workspace 安全中心适用于所有套餐。您可以使用它扫描 workspace 中各项目的[依赖项](/zh/features/security/concepts#dependency)，并按[严重性](/zh/features/security/concepts#severity)查看 [CVE](/zh/features/security/concepts#cve) 发现项。您还可以使用 Replit Agent 修复问题、[重新发布](/zh/features/security/concepts#republish)受影响的项目，以及导出软件物料清单 ([SBOM](/zh/features/security/concepts#sbom)) 报告以满足合规要求。

<Note>
  如需扫描单个项目，请在该项目的 **安全** 窗格中打开 [Project Security Center](/zh/features/security/project-security-center)。
</Note>

<Note>
  不熟悉依赖项安全？请参阅[安全概念](/zh/features/security/concepts)，了解 CVE、SBOM、暴露面、使用 Agent 修复、重新发布和 Auto-Protect 的定义。
</Note>

<div id="features">
  ## 功能
</div>

<div id="cve-detection">
  ### CVE 检测
</div>

查看 workspace 中所有项目的漏洞：

* 识别存在漏洞的项目，并按[暴露面](/zh/features/security/concepts#exposure) (发布状态和可见性) 优先排序
* 查看受影响的软件包名称、版本和严重性 (严重、高、中、低)
* 获取每个项目的修复建议

</Frame>

<div id="affected-projects-view">
  ### 受影响项目视图
</div>

识别包含漏洞的项目，并确定修复优先级：

* 按暴露面查看存在漏洞的项目概览：项目总数、已发布项目和公开发布项目
* 查看受影响的 Replit 项目详细信息
* 按 CVE ID 或项目名称搜索，并按严重性、所有者、发布状态 (Published / Not published) 和可见性 (Public / Private) 筛选
* 展开任意项目行，即可查看所有 CVE 发现项 (严重性、软件包、版本、CVE ID) ，无需离开当前页面

  <img src="/assets/mirror/cve-affected-projects-89f807e09c87.png" alt="Workspace 安全中心中展开的 CVE 行，显示受该漏洞影响的 workspace 项目" width="3438" height="1984" data-path="images/workspace-security-center/cve-affected-projects.png" />
</Frame>

<div id="fix-with-agent-and-republish">
  ### 使用 Agent 修复并重新发布
</div>

无需离开安全中心，即可修复漏洞并重新部署：

* 在任何受影响的项目中选择 **[使用 Agent 修复](/zh/features/security/concepts#fix-with-agent)**，以项目中的后台 task 形式起草补丁。重新发布前，请审核并应用生成的更改。
* 通过 **任务进行中**、**应用更改**、**重新发布** 以及终态 **已重新发布** 或 **失败** 跟踪修复状态。
* 修复合并后，点击 **重新发布**，在确认对话框中确认后，即可使用现有配置重新部署构建。
* 可执行批量操作，例如取消发布项目，或通知项目所有者其项目中存在漏洞。

<div id="sbom-export">
  ### SBOM 导出
</div>

导出软件物料清单，以满足合规和审计需求：

* 以标准格式下载 SBOM ([SPDX](/zh/features/security/concepts#spdx-and-cyclonedx)、[CycloneDX](/zh/features/security/concepts#spdx-and-cyclonedx))
* 为单个项目或整个 workspace 生成报告
* 按扫描运行记录查看 SBOM，其中包含时间戳、项目数量和触发运行的用户
* 将一次扫描运行中的所有 SBOM 打包下载为一个 zip 文件
* 满足软件供应链透明度方面的合规要求

<Note>
  Enterprise 套餐提供批量下载 SBOM 的功能。其他套餐的 workspace 会在 SBOM 部分看到 Enterprise 升级提示。
</Note>

<div id="accessing-the-workspace-security-center">
  ## 访问 Workspace 安全中心
</div>

要打开 Workspace 安全中心：

1. 前往 [replit.com](https://replit.com) 并登录您的账户。
2. 在主页左侧导航栏中选择 **安全**。

<div id="scanning-your-workspace">
  ## 扫描你的 workspace
</div>

<Frame>
  <img src="/assets/mirror/security-overview-b37f090f236c.png" alt="Workspace 安全中心主页，显示扫描总数、漏洞总数以及按严重性分组的 CVE" width="3438" height="1984" data-path="images/workspace-security-center/security-overview.png" />
</Frame>

1. 打开 Workspace 安全中心。
2. 选择 **运行安全扫描**，开始扫描整个 workspace。
3. 查看按受影响项目、严重性和 deployment 暴露面分类的结果。
4. 在任意受影响的项目中，选择 **使用 Agent 修复**，修复完成后选择 **重新发布**。

扫描会分析 workspace 中 Replit 项目的依赖项，并根据公开漏洞记录标记已知漏洞。

<div id="auto-protect">
  ## Auto-Protect
</div>

管理员可以为其账户启用 **[Auto-Protect](/zh/features/security/concepts#auto-protect)**，该功能会持续监控新披露的 CVE 是否与各项目的依赖项匹配。发现匹配项后，Replit Agent 会准备经过测试的补丁，构建者将收到一封包含补丁应用直达链接的电子邮件。

有关完整工作流程和设置步骤，请参阅 [Auto-Protect](/zh/features/security/project-security-center#auto-protect)，其中包括仅限管理员在 **设置** &gt; **账户** &gt; **高级** 中配置的严重性阈值。

<Note>
  如需帮助配置 Workspace 安全中心或将 SBOM 导出集成到合规工作流，请联系专属客户经理。
</Note>
