Preview отображает результат работы вашего веб-приложения и предоставляет браузерные инструменты разработчика и
функции отладки.

Когда вы запускаете веб-приложение кнопкой **Выполнить**, Replit присваивает ему временный
URL, доступный в интернете. Инструмент Preview отображает страницу ровно так же, как вы увидели бы её
в браузере. Кроме того, он включает инструменты разработчика с возможностями, схожими
с теми, что есть в самых популярных браузерах.

<Note>
  Preview — это новое название веб-просмотра.
</Note>

<div id="recursos">
  ## Возможности
</div>

Preview включает следующие функции, позволяющие тестировать и отлаживать веб-приложения без лишних переключений:

* **Живой веб-просмотр**: смотрите свой App и взаимодействуйте с ним, не покидая вкладку браузера
* **Инструменты разработчика**: используйте встроенные инструменты для быстрой диагностики проблем
* **Адаптивное тестирование**: проверяйте, как выглядит ваш App при разных размерах экранов мобильных устройств

<div id="uso">
  ## Использование
</div>

Инструмент Preview открывается автоматически при запуске веб-приложения.
Это поведение можно изменить в **пользовательских настройках**, в пункте **Автоматический Preview**.

Ниже описано, как открыть Preview.

<Accordion title="Как открыть Preview">
  В **доке инструментов** слева:

  1. Выберите <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Иконка «Все инструменты»" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **Все инструменты**, чтобы увидеть список инструментов редактора проектов.
  2. Выберите <img class="icon-svg" src="/assets/mirror/preview-icon-6d37238e8cc2.svg" alt="Иконка Preview" width="16" height="16" data-path="images/icons/preview-icon.svg" /> **Preview**.

  В **строке поиска**:

  1. Нажмите на <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="иконка лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> лупу вверху, чтобы открыть инструмент поиска
  2. Введите «Preview», чтобы найти инструмент, и выберите его в результатах.
</Accordion>

<div id="barra-de-localizao">
  ## Адресная строка
</div>

Адресная строка в верхней части вкладки **Preview** содержит следующие инструменты:

* **Кнопка «Назад»**: переход на предыдущую страницу в истории просмотра
* **Кнопка «Вперёд»**: переход на следующую страницу в истории просмотра
* **Домен приложения**: просмотр сведений о временном URL вашего Replit App — нажмите `{...}.replit.dev`
* **Поле адреса**: просмотр текущего пути URL или ввод нового пути

<div id="ferramentas-do-navegador">
  ## Инструменты браузера
</div>

Инструменты браузера справа от адресной строки включают следующие функции:

* **Размер экрана**: выбор одного из готовых размеров экрана для проверки адаптивного дизайна
* **Devtools**: показать или скрыть панель [инструментов разработчика](#Developer_tools)
* **Новая вкладка**: открытие URL вашего веб-приложения в новой вкладке браузера

<Note>
  **Создаёте мобильное приложение?** Панель Preview также поддерживает предпросмотр в **iOS Simulator** или **Android Emulator**. Подробнее см. [Нативные мобильные приложения](/ru/pt/replitai/building-mobile-apps#preview-on-a-simulator-or-emulator).
</Note>

<div id="ferramentas-de-desenvolvedor">
  ## Инструменты разработчика
</div>

Инструменты разработчика, созданные на основе проекта с открытым исходным кодом <a href="https://github.com/liriliri/eruda" target="_blank">Eruda</a>, помогают выполнять следующие задачи:

* Просматривать консоль JavaScript в контексте вашего app и взаимодействовать с ней
* Исследовать элементы DOM
* Отслеживать сетевые запросы
* Настраивать параметры отображения и поведения

Чтобы открыть инструменты разработчика, нажмите кнопку <img class="icon-svg" src="/assets/mirror/wrench-7cee9d1168da.svg" alt="иконка гаечного ключа" width="16" height="16" data-path="images/icons/wrench.svg" /> **Devtools**
в верхней части вкладки **Preview**.

В следующих разделах описаны действия, доступные на каждой вкладке инструментов разработчика.

<div id="console">
  ### Console
</div>

На вкладке **Console** отображаются JavaScript-логи, которые создаёт ваше приложение.
На этой вкладке доступны следующие действия:

* **Очистить вывод**: удалить весь вывод консоли, выбрав значок <img class="icon-svg" src="/assets/mirror/clear-bd1bf1847597.svg" height="16" width="16" alt="значок очистки" data-path="images/icons/clear.svg" /> перечёркнутого круга.
* **Фильтровать вывод**: просматривать вывод консоли с фильтрацией по типу (Все, Информация, Предупреждение или Ошибка).
* **Фильтровать по тексту**: показать только совпадающий вывод — выберите значок <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="значок фильтра" data-path="images/icons/filter.svg" /> и введите текст.
* **Копировать вывод**: скопировать выбранные сообщения консоли кнопкой <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="значок копирования" data-path="images/icons/copy.svg" /> копирования.
* **Выполнить код JavaScript**: выполнить код JavaScript в контексте вашего приложения, выбрав значок <img class="icon-svg" src="/assets/mirror/arrow-right-2859a6e6bdeb.svg" height="16" width="16" alt="значок стрелки вправо" data-path="images/icons/arrow-right.svg" /> правой угловой скобки. Введите выражение и нажмите **Выполнить**.

<div id="elements">
  ### Elements
</div>

Вкладка **Elements** позволяет исследовать и изменять структуру DOM веб-страницы.

* **Просмотр сведений об элементе**: просмотр сведений об элементе DOM и его расположения в HTML-коде
* **Копировать вывод**: копирование выбранных сообщений консоли с помощью кнопки <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="значок копирования" data-path="images/icons/copy.svg" /> копирования.

Используйте <img class="icon-svg" src="/assets/mirror/select-1165d9548c39.svg" height="16" width="16" alt="значок выбора" data-path="images/icons/select.svg" /> стрелку выбора, чтобы включить режим выбора.
Перейдя в режим выбора, щёлкните нужный элемент на веб-странице.
HTML и CSS этого элемента отобразятся на вкладке Elements.

<div id="network">
  ### Network
</div>

Вкладка **Network** отслеживает запросы, отправленные веб-страницей.
На этой вкладке доступны следующие действия:

* **Отслеживание запросов**: просмотр всех сетевых запросов, отправленных вашим App. Выберите запрос, чтобы увидеть подробности.
* **Фильтрация**: нажмите на значок воронки <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="значок фильтра" data-path="images/icons/filter.svg" />, чтобы отобразить результаты, соответствующие введённому тексту. Оставьте поле фильтра пустым, чтобы сбросить его.
* **Копирование**: копирование информации о хранилище с помощью кнопки копирования <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="значок копирования" data-path="images/icons/copy.svg" />.

<div id="resources">
  ### Resources
</div>

На вкладке **Resources** отображаются ассеты, загруженные страницей, а также хранилище браузера: файлы cookie и локальное хранилище.
Вы можете просматривать и обновлять списки следующих типов ассетов:

* Файлы JavaScript
* Таблицы стилей
* Iframe
* Изображения

На этой вкладке доступны следующие действия:

* **Просмотр хранилища**: изучить локальное хранилище, хранилище сессии и файлы cookie.
* **Фильтрация**: нажмите значок <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="значок фильтра" data-path="images/icons/filter.svg" /> в виде воронки, чтобы показать результаты, соответствующие введённому тексту. Чтобы сбросить фильтр, оставьте поле пустым.
* **Очистка**: удалить все данные этого типа хранилища, нажав кнопку <img class="icon-svg" src="/assets/mirror/clear-bd1bf1847597.svg" height="16" width="16" alt="значок очистки" data-path="images/icons/clear.svg" /> очистки.
* **Удалить выбранное**: удалить элементы хранилища, нажав значок <img class="icon-svg" src="/assets/mirror/delete-a21eb49cac3c.svg" height="16" width="16" alt="значок удаления" data-path="images/icons/delete.svg" /> «X».
* **Копирование**: скопировать информацию о хранилище, нажав кнопку <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="значок копирования" data-path="images/icons/copy.svg" /> копирования.

<div id="settings">
  ### Settings
</div>

Вкладка **Settings** позволяет настроить внешний вид и поведение инструментов разработчика.
На этой вкладке доступны настройки для следующего:

* **Настройки инструментов**: параметры, применимые к каждой вкладке инструментов
* **Управление JavaScript**: настройка поведения JavaScript — например, его отключение, чтобы проверить, как поведёт себя ваш App
* **Параметры отображения**: изменение темы, размера панели, прозрачности и другого поведения инструментов разработчика
