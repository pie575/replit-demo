---
title: "启用反馈小组件"
description: "了解如何收集已部署应用访客的反馈。"
---

您可以为已部署应用启用反馈收集功能，直接从访客那里获取洞察，并将其发送给 Agent。启用反馈后，访客即可提交反馈，包括截图和文件，您可以在收件箱中统一管理这些反馈。

<div id="ativar-o-feedback">
  ## 启用反馈
</div>

<Warning>
  仅 Web 应用支持启用反馈，其他类型的应用 (如自动化或移动应用) 无法启用此功能。
</Warning>

发布新应用时，请在部署对话框中打开 **Enable Feedback** 开关。如果应用已经部署，可以通过重新部署来启用反馈：

1. 打开 Publishing 工具
2. 选择 **Advanced Settings**
3. 打开 **Enable Feedback** 开关
4. 重新部署应用

<div id="enviar-feedback">
  ## 提交反馈
</div>

在已发布的 App 中启用反馈功能后，访客可以直接在 App 内提交反馈。用户可以：

* 登录后提交反馈
* 用文字描述使用体验或提出建议
* 选择页面元素，以指出具体问题或功能
* 上传文件以提供更多背景信息

<div id="gerenciar-feedback-na-sua-caixa-de-entrada">
  ## 在收件箱中管理反馈
</div>

访客提交的所有反馈都会显示在你的收件箱中，可在 Project Editor 内查看。在收件箱中，你可以：

* **Add to Chat**：将反馈添加到你与 Agent 的对话中，以便在发送前补充上下文
* **Send to Agent**：直接将反馈发送给 Agent，立即开始处理
* **Resolve**：反馈处理完成后将其标记为已解决
* **Delete**：删除不再需要的反馈

你还可以使用筛选器来整理和查找特定的反馈条目。

<div id="republicar-com-configuraes-de-feedback-atualizadas">
  ## 使用更新后的反馈设置重新部署
</div>

应用部署后，你可以随时更新设置并重新部署，以启用或禁用反馈小组件：

1. 打开 Publishing 工具中的 **Overview** 标签页
2. 选择 **Advanced Settings**
3. 启用或禁用 **Enable Feedback**
4. 重新部署应用以应用更改

反馈设置的任何更改都会在应用重新部署后生效。
