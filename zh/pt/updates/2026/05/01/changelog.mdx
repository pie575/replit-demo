<div id="monitoramento-de-apps-do-replit-mantm-seus-apps-publicados-sob-vigilncia">
  ### Replit 应用监控，为你已部署的应用保驾护航
</div>

现在，你可以为任何已部署的 Replit App 启用**应用监控**，获得实时的 uptime 检测、在**部署**视图和**分析**标签页中显示的彩色 uptime 状态条，以及应用宕机时的邮件提醒。应用监控适用于所有付费方案，并支持除定时 Deployment 之外的所有 Deployment 类型。如果你的应用出现问题，选择**使用 Agent 排查近期宕机**即可启动一项后台任务，分析受影响的时间窗口、检查日志和代码，并提出修复方案。

  ### 使用 Agent 创建完整的幻灯片演示文稿
</div>

只需描述你想要的演示文稿——比如融资路演文稿、产品概览、销售文稿或团队进展汇报——Agent 就会生成一份精心制作的演示文稿，版式、文案和视觉元素一应俱全。你可以通过 Chat 优化幻灯片，使用可视化编辑器调整文字和样式，直接在浏览器中演示，将演示文稿发布为在线链接，或导出为 PPTX、Google Slides 或 PDF。
