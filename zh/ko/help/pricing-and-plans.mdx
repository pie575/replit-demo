本回答介绍套餐与定价。完整的套餐详情请参阅 [Starter](/zh/ko/billing/plans/starter-plan)、[Core](/zh/ko/billing/plans/replit-core)、[Pro](/zh/ko/billing/plans/replit-pro)，最新价格请查看[定价页面](https://replit.com/pricing)。

<AccordionGroup>
  <Accordion title="Agent 的使用如何计费？为什么在 Plan 模式下也会产生费用？">
    Free Mode 是 Core 和 Pro 订阅包含的权益，可在额度范围内免费使用 Agent 进行开发。额度每 5 小时重置一次，并设有每周上限。要查看使用情况，请前往 **设置 → 使用量**。Free Mode 本身并非单独的免费套餐，Starter 套餐的原有限额保持不变。

    付费模式和已确认的付费任务采用[基于工作量的计费](/zh/ko/billing/ai-billing)，费用取决于请求的复杂程度。即使不修改代码，Plan 模式也可能在付费路径上执行需计费的推理任务。在付费任务开始前，Replit 会请求你确认。

    日常任务建议从 [Free Mode](/zh/ko/features/agent/agent-modes) 开始。若需要以合理的价格获得更强性能，可选择 [Power 模式](/zh/ko/features/agent/agent-modes)。你还可以用 [Plan 模式](/zh/ko/features/agent/plan-mode)来界定任务范围，或在[管理支出](/zh/ko/billing/managing-spend)中设置使用量上限和预算。要查看账单记录，请打开 **设置 → 账户使用量**，然后选择**查看历史账单**。
  </Accordion>

  <Accordion title="各套餐（Starter、Core 和 Pro）包含哪些内容？">
    每种套餐面向不同的构建阶段：

    * **Starter** 为免费套餐，提供每日 Agent 使用额度、有限的每月云端积分、基础 Agent 访问权限以及 1 个已发布的应用。请参阅 [Starter 套餐](/zh/ko/billing/plans/starter-plan)。
    * **Core** 包含每月 {CoreCredits} 积分、含 Plan 与 Build 模式的完整 Agent、最多 5 名协作者、无限量已发布应用，以及 7 天数据库恢复期。请参阅 [Core 套餐](/zh/ko/billing/plans/replit-core)。
    * **Pro** ({ProPlanPrice}/月) 新增 Turbo 模式、最多 15 名共享积分池的构建者、阶梯式积分以及 28 天数据库恢复期。未使用的积分可结转 {ProCreditRolloverPeriod}。请参阅 [Pro 套餐](/zh/ko/billing/plans/replit-pro)。

    如需并排比较各套餐并查看当前价格，请参阅[价格页面](https://replit.com/pricing)。
  </Accordion>

  <Accordion title="你们提供学生或教育优惠吗？">
    Replit 面向学生和教育工作者提供教育计划。如需了解最新的资格条件、优惠折扣和申请方式，请访问 [replit.com/education](https://replit.com/education)。

    <Note>具体的折扣金额和资格条件由教育计划统一管理，可能随时调整。请以教育页面上的信息为准。</Note>
  </Accordion>

  <Accordion title="年度计费如何运作？可以节省多少费用？">
    按年计费需一次性预付全年费用，但折算后的月费更低。[Core](/zh/ko/billing/plans/replit-core) 为 {CoreAnnualPrice}/年。如需切换，请在订阅或更改套餐时选择年付选项。其他套餐及当前的优惠金额，请参阅[价格页面](https://replit.com/pricing)。
  </Accordion>

  <Accordion title="未使用的月度积分会结转到下个月吗？">
    这取决于您的套餐。Core 积分会在每个账单周期开始时重置，不会结转到下一周期。Pro 则包含[积分结转](/zh/ko/billing/plans/replit-pro)，未使用的积分可结转 {ProCreditRolloverPeriod} 后再过期。

    如果您的余额高于每月配额，多出的部分可能是推荐或促销积分，它们有各自的过期日期。
  </Accordion>

  <Accordion title="如何购买额外积分（积分包）？">
    积分包可在每月配额之外额外增加积分，包越大，折扣越多：

    <CreditPackTable />

    打开**设置 → 账户用量**，选择购买积分包。积分可用于 Agent 使用、部署、存储及其他按用量计费的服务。详情请参阅[管理支出](/zh/ko/billing/managing-spend#purchase-credit-packs)。

    如果你是通过 App Store 订阅的，请先在账户中添加网页支付方式。
  </Accordion>

  <Accordion title="Core 或 Pro 提供免费试用吗？">
    Replit 不提供付费套餐的限时免费试用，但你可以通过以下方式先体验 Replit：

    * [Starter 套餐](/zh/ko/billing/plans/starter-plan)完全免费，且没有时间限制。
    * [教育计划](https://replit.com/education)为符合条件的学生提供折扣使用权限。

    如需了解当前订阅的退款条件，请[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="在计费周期中途升级时，费用如何按比例计算？">
    如果在计费周期中途变更套餐，Replit 会将当前套餐未使用部分折算成额度，抵扣新套餐的费用。确切的按比例计算结果会在你确认变更前显示在结算确认页面，方便你在扣费前核对。
  </Accordion>
</AccordionGroup>
