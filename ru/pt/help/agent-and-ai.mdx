Здесь собраны ответы на вопросы по работе с Agent. Подробную информацию смотрите в [обзоре Agent](/ru/pt/features/agent/overview), разделе [режимов Agent](/ru/pt/features/agent/agent-modes) и разделе [биллинга ИИ](/ru/pt/billing/ai-billing).

<AccordionGroup>
  <Accordion title="Agent зависает или постоянно отключается — как это исправить?">
    1. Откройте палитру команд с помощью `Cmd+K` (Mac) или `Ctrl+K` (Windows).
    2. Найдите **Restart compute** и выберите этот пункт, чтобы перезапустить среду разработки.
    3. Откройте новый чат Agent и снова опишите задачу, чтобы продолжить.

    Если Agent кажется зависшим, не отправляйте новые сообщения — они создают конфликтующие инструкции. Если Agent продолжает зависать на той же задаче, разбейте её на более короткие и конкретные промпты.
  </Accordion>

  <Accordion title="Agent зациклился или повторяет одни и те же действия — как его остановить?">
    1. Выберите **Остановить** на панели Agent, чтобы немедленно прервать его работу.
    2. Откройте палитру команд с помощью `Cmd+K` (Mac) или `Ctrl+K` (Windows), найдите **Перезапустить вычислительные ресурсы** и выберите этот пункт.
    3. Откройте новый чат Agent и сформулируйте задачу более конкретно.

    Чтобы избежать зацикливания:

    * Разбивайте большие задачи на небольшие промпты — одна цель в каждом сообщении.
    * Используйте [Режим планирования](/ru/pt/features/agent/plan-mode), чтобы определить объём работы до того, как Agent приступит к её выполнению.
    * Установите лимит расходов в разделе [Управление расходами](/ru/pt/billing/managing-spend), чтобы зацикливание не привело к большому счёту.
  </Accordion>

  <Accordion title="Как сократить расходы на Agent — какие настройки действительно помогают?">
    Наибольшее значение имеют следующие решения:

    * **[Free Mode](/ru/pt/features/agent/agent-modes)**—повседневная работа с Agent без дополнительной платы для подписчиков Core и Pro в пределах квоты.
    * **[Режим Power](/ru/pt/features/agent/agent-modes)**—больше возможностей по доступной цене, когда они нужны для работы.
    * **[Режим планирования](/ru/pt/features/agent/plan-mode)**—определите объём работ и утвердите его до того, как Agent начнёт работу, чтобы не платить за нежелательные изменения.
    * **Лимит использования и бюджет**—установите максимальный лимит в разделе [Управление расходами](/ru/pt/billing/managing-spend).

    Также полезно начинать новый чат с Agent при переходе к другой задаче. Проверяйте панель использования, чтобы узнать, какие задачи обходятся дороже.
  </Accordion>

  <Accordion title="Какие режимы есть у Agent и чем они отличаются?">
    У Agent есть три основных режима. Полное руководство см. в разделе [Free Mode](/ru/pt/help/free-agent-mode).

    * **Free Mode** — бесплатный повседневный режим работы с Agent для подписчиков Core и Pro в рамках квоты, которая обновляется каждые пять часов и имеет недельный лимит. Для тарифа Starter сохраняются текущие лимиты. Проверьте **Настройки → Использование**, чтобы узнать своё использование.
    * **Power** — платный режим среднего уровня с мощными моделями по доступной цене.
    * **Max** — платный режим высшего уровня с лучшими передовыми моделями для самых требовательных задач.
    * **Turbo** — дополнительный переключатель в расширенных настройках, доступный только с Max.

    Платные режимы были переименованы. **Economy теперь называется Power**, а режим, ранее называвшийся **Power, теперь называется Max**. Существующие настройки режимов сохраняются под новыми названиями. Если запросу требуется больше возможностей, чем предоставляет Free Mode, Agent может предложить платный вариант **Разрешить один раз**. Replit запрашивает подтверждение перед началом платного действия, после чего Agent возвращается в Free Mode.

    Отдельно [режим планирования](/ru/pt/features/agent/plan-mode) позволяет Agent определить объём работы до внесения изменений, тогда как режим Build применяет изменения напрямую. См. [Режим планирования и режим Build](/ru/pt/learn/plan-vs-build-mode).
  </Accordion>

  <Accordion title="Agent внёс нежелательные изменения — как их отменить?">
    Replit сохраняет [checkpoints](/ru/pt/features/version-control/checkpoints-and-rollbacks), пока работает Agent. В чате Agent найдите сообщение перед изменением, которое хотите отменить, и выберите рядом с ним вариант отката, чтобы восстановить проект до этого состояния.

    Все варианты отката, включая восстановление отдельных файлов, описаны в разделе [Checkpoints и откаты](/ru/pt/features/version-control/checkpoints-and-rollbacks).
  </Accordion>

  <Accordion title="Agent сообщает, что у него нет доступа к интернету или внешним API — это нормально?">
    На этапе создания и редактирования Agent работает в изолированной среде с ограниченным исходящим доступом. Развернутое приложение по-прежнему может обращаться к внешним API во время работы — песочница применяется к среде редактирования Agent, а не к работающему приложению.

    Если вызов API в работающем приложении завершается ошибкой, убедитесь, что ключи сохранены в разделе [Secrets](/ru/pt/core-concepts/project-editor/app-setup/secrets), затем проверьте страницу статуса провайдера. В корпоративной или школьной сети исходящие подключения вашего приложения могут быть заблокированы — уточните у администратора сети.
  </Accordion>

  <Accordion title="Могу ли я использовать собственные API-ключи с Agent?">
    Да. Добавьте ключи в [Secrets](/ru/pt/core-concepts/project-editor/app-setup/secrets), и приложение будет использовать их для API-вызовов. Откройте **Secrets**, выберите **+ Новый секрет** и укажите имя (например, `OPENAI_API_KEY`) и значение.

    Вы можете [использовать собственные ключи поставщика ИИ](/ru/pt/features/integrations/replit-ai-integrations) для моделей, которые вызывает ваше приложение. Модель, обеспечивающая работу самого Agent, запускается в инфраструктуре Replit и не может быть заменена.
  </Accordion>

  <Accordion title="Agent продолжает добавлять ненужные мне функции — как добиться более точного поведения?">
    Помогите Agent не отвлекаться с помощью более конкретных запросов:

    * Начинайте со слова *Только* — например: &quot;Только добавь кнопку удаления на карточку пользователя. Больше ничего не меняй.&quot;
    * Прежде чем вносить изменения, воспользуйтесь [режимом планирования](/ru/pt/features/agent/plan-mode), чтобы проверить, что именно Agent планирует сделать.
    * Если Agent внёс нежелательное изменение, сразу попросите отменить его в том же чате.

    Подробнее см. в разделе [Эффективное составление запросов](/ru/pt/learn/effective-prompting).
  </Accordion>
</AccordionGroup>
