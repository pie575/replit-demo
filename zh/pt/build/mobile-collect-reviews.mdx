iOS 上的 StoreKit 和 Android 上的 Google Play In-App Review API 会限制
评分提示实际显示的频率，无论代码请求多少次都是如此。

<Note>
  切勿以奖励诱导或强制用户评分，例如要求用户给出 5
  星评分后才能解锁游戏。Apple 和 Google 禁止激励性评分，PixelGames 可能因此遭到拒绝或
  下架。
</Note>

<div id="soluo-de-problemas">
  ## 故障排除
</div>

* **评分提示始终不出现：**这有时属于正常情况。两个平台都会限制系统显示评分提示的频率，
  无论代码调用 API 多少次。
* **测试时每次都会出现评分提示：**在 TestFlight 或 Internal Testing 构建中这是正常现象，
  年度限制仅适用于实际的生产环境安装。
* **玩家抱怨被频繁询问：**请确认调用的是原生 API，而不是每次打开时都显示的
  自定义弹窗；后者会绕过内置的频率限制。
