export const profileImagesPrompt = "将玩家拍摄的头像照片存储在 App Storage 中，并关联到其账户。";

PixelGames 需要一个地方来存放玩家拍摄的照片。本指南假设玩家已经能够
[登录](/zh/build/mobile-login)，因为存储功能需要识别上传者的身份。

<AiPrompt>
  {profileImagesPrompt}
</AiPrompt>

Agent 会配置 [App Storage](/zh/features/data-and-storage/object-storage)，并将每次上传与
已登录的玩家关联起来。这样，PixelGames 就能显示真实的个人资料：在玩家姓名旁展示其上传的照片。

</Frame>

<div id="test-it">
  ## 测试
</div>

1. 使用现有账户登录 PixelGames。
2. 拍摄或选择一张个人资料照片并上传。
3. 关闭后重新打开 App，确认照片仍然存在。
4. 在第二部手机上使用同一账户登录，确认能看到相同的照片。

<div id="troubleshooting">
  ## 故障排除
</div>

* **已登录但未显示照片：**应用可能连接到了与预期不同的存储或身份验证实例。请 Agent 检查连接。
* **上传失败：**确认应用在上传前已请求相机和存储权限。
