La Console vous permet de surveiller et d’examiner en temps réel les journaux générés par votre application Replit en cours d’exécution.
Utilisez les informations des exécutions en cours et précédentes pour comprendre le comportement de votre application,
résoudre les erreurs et optimiser les performances.

<Tip>
  Lorsque vous déboguez avec Agent, incluez les journaux de la Console dans votre prompt afin de lui fournir du contexte.
</Tip>

<div id="section">
  ## Fonctionnalités
</div>

Console fournit les outils suivants pour vous aider à comprendre le fonctionnement de votre application :

* **Journalisation en temps réel** : consultez les sorties de votre application en temps réel
* **Assistance par IA** : obtenez des suggestions pour corriger les erreurs signalées dans les journaux
* **Historique des exécutions** : consultez les journaux des exécutions précédentes afin de suivre les modifications

<div id="section-2">
  ## Utilisation
</div>

Vous pouvez accéder directement à l’outil Console dans le Project Editor.

<Accordion title="Accéder à Console">
  Dans le **dock d’outils** de gauche :

  1. Sélectionnez <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="icône Tous les outils" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **Tous les outils** pour afficher la liste des outils du Project Editor.
  2. Sélectionnez <img class="icon-svg" src="/assets/mirror/console-8a41ac90789c.svg" alt="icône Console" width="16" height="16" data-path="images/icons/console.svg" /> **Console**.

  Dans la **barre de recherche** :

  1. Sélectionnez l’<img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="icône de loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> icône de loupe en haut pour ouvrir l’outil de recherche.
  2. Saisissez « Console », puis sélectionnez l’outil dans les résultats.
</Accordion>

Chaque fois que vous utilisez le bouton **Exécuter** dans une application Replit, Console affiche une nouvelle entrée contenant les informations suivantes :

* La commande ayant exécuté le code
* L’horodatage
* Les journaux de sortie standard et d’erreur

La capture d’écran suivante montre la commande `npm run dev` utilisée pour démarrer l’application, ainsi que les messages du journal d’exécution :

<div id="ai">
  ### Débogage par IA
</div>

Lorsque vous repérez une erreur ou une information à éclaircir dans les journaux, sélectionnez le bouton
**Ask AI** en haut de l’entrée. L’onglet **Agent** s’ouvre alors automatiquement et
le contenu du journal est envoyé pour analyse.

<div id="section-3">
  ### Commandes des entrées de journal
</div>

Console fournit les outils suivants pour gérer les journaux :

* **Show Only Latest** : activez cette option pour n’afficher que l’exécution la plus récente.
* **Réduire les entrées** : sélectionnez la flèche vers le bas <img class="icon-svg" src="/assets/mirror/down-arrow-9c1cf9fd152e.svg" alt="icône de flèche vers le bas" height="16" width="16" data-path="images/icons/down-arrow.svg" /> située à gauche du nom de la commande pour masquer les journaux.
* **Effacer les exécutions précédentes** : sélectionnez cette option pour supprimer les journaux des exécutions précédentes. Cette action est irréversible.

<div id="section-4">
  ### Disponibilité réseau
</div>

Vous pouvez contrôler la disponibilité en ligne de la version de développement de votre application.

Pour arrêter le traitement des requêtes vers l’URL de développement, sélectionnez l’icône de globe barré <img class="icon-svg" src="/assets/mirror/network-off-5bdca8a4fe4e.svg" alt="icône de réseau désactivé" height="16" width="16" data-path="images/icons/network-off.svg" /> à droite de la ligne d’informations réseau.

Pour la réactiver, sélectionnez l’icône de globe <img class="icon-svg" src="/assets/mirror/network-on-15be2e5fb4f5.svg" alt="icône de réseau activé" height="16" width="16" data-path="images/icons/network-on.svg" />.

Pour consulter l’URL de développement, sélectionnez le texte `{...}.replit.dev` dans la barre d’adresse.

<Frame>
  <img src="/assets/mirror/preview-dev-url-b36770b33769.png" alt="emplacement de l’URL de développement dans Preview" width="1222" height="824" data-path="images/workspace/preview-dev-url.png" />
</Frame>

<Note>
  Même après avoir arrêté le traitement des requêtes vers l’URL de développement, l’application reste accessible dans l’onglet Preview.
</Note>

<div id="section-5">
  ### Arrêter les commandes du workflow
</div>

Vous pouvez arrêter les commandes du workflow en cours d’exécution dans l’outil Console de Project Editor.

Pour les arrêter, cliquez sur le bouton carré situé à droite de la ligne contenant la commande d’exécution de l’application Replit.

Pour redémarrer l’application, utilisez le bouton **Exécuter** du workflow en haut de Project Editor.
