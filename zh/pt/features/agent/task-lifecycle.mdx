<div id="rascunho">
  ## 草稿
</div>

**草稿**是 Agent 已规划好但尚未开始构建的任务。草稿可以放心查看，因为其中只包含拟议的工作内容：任务标题、描述和计划。

你可以通过草稿判断 Agent 是否理解了你的目标，然后启动该任务、让 Agent 修改计划，或将草稿归档留待日后处理。

<div id="ativo">
  ## 进行中
</div>

**进行中**的任务正在后台运行。Agent 会在项目的隔离副本中处理该任务，因此任务运行期间，你的主版本不会受到影响。

任务在后台运行时，你可以继续使用主线程。如果某个任务需要你提供反馈，打开对应的线程，在其中继续对话即可。

  ## 排队中
</div>

**排队中**的任务已获批准，但仍在等待启动。当某个任务依赖于另一个任务，或者你已达到所在方案的进行中后台任务上限时，该任务就会进入队列。

一旦前置任务完成且有进行中任务名额空出，队列中的任务会自动启动。

<div id="pronto">
  ## 就绪
</div>

**就绪**状态的任务已经完成，但其更改尚未应用到你的主版本。在应用更改之前，请查看该任务的工作日志、测试结果和 Preview。

如果结果没问题，就将其应用到主版本。如果不符合你的预期，可以将其丢弃并启动一个新任务。

<div id="aplicando">
  ## 应用中
</div>

处于**应用中**的任务正在将其更改合并到主版本。Agent 会在应用多个任务的更改时自动处理冲突。

请等待应用完成后再评估最终结果。如果之后发现有问题，可以在主线程中让 Agent 修复。

<div id="concludo">
  ## 已完成
</div>

**已完成**的任务表示工作已结束，无需再采取任何操作。“已完成”可能表示该任务已应用到主版本、在开始前被归档，或在进入构建阶段后被取消。

可将**已完成**列作为已完成、已归档和已取消工作的历史记录。

<div id="arquivando-e-cancelando-tarefas">
  ## 归档和取消任务
</div>

你可以在任务生命周期的任意阶段将其停止，但看到的选项取决于任务在看板中所处的位置。**归档**和**取消**都会把任务移到**已完成**列，但两者的行为并不相同：

| 操作     | 何时可用                                      | 会发生什么                                     | 可撤销？                                 |
| ------ | ----------------------------------------- | ----------------------------------------- | ------------------------------------ |
| **归档** | 任务仍处于规划会话阶段时：尚未开始构建的**草稿**                | 该规划会话被搁置，不会执行，你的计划会保留下来。                  | 可以。在**已完成**列中打开已归档的卡片，即可将其恢复到**草稿**。 |
| **取消** | 任务已从规划进入构建阶段后：任何**进行中**、**排队中**或**就绪**的任务 | Agent 会停止该任务，并丢弃所有进行中的工作，不会有任何更改应用到你的主版本。 | 不可以。已取消的任务无法恢复。如果想继续这项工作，请新建一个任务。    |

对于想稍后再回来处理的规划会话，请使用**归档**；对于排队中、正在运行或已完成构建的任务，则用**取消**作为永久停止按钮。

已归档的规划会话和已取消的任务都可以在任务看板最右侧的**已完成**列中找到，与已完成的任务放在一起。
