<div id="agent-v2">
  ### Agent v2
</div>

<img src="/assets/mirror/agent-web-01b1f9026de7.webp" alt="Agent v2" width="800" height="450" data-path="images/changelog/2025-02-28/agent-web.webp" />

Новая версия Agent теперь доступна всем пользователям. Она быстрее, точнее и функциональнее предыдущей версии.

Теперь Agent работает на базе Claude 3.7 Sonnet — самой продвинутой на сегодняшний день модели Anthropic.

Попробовать её можно, присоединившись к Explorer Program. Инструкции доступны [здесь](https://youtu.be/pE_XT2TaXCA).

<div id="deployment-improvements">
  ### Улучшения развёртывания
</div>

Теперь пользователям, выбирающим статическое развёртывание для динамических приложений, предлагаются рекомендации ИИ, что улучшает работу Agent с запросами на развёртывание.

<div id="claude-37-sonnet-release">
  ### Выпуск Claude 3.7 Sonnet
</div>

Расширенный режим Assistant теперь использует Claude 3.7 Sonnet для всех пользователей с платной подпиской. Это повышает точность и возможности при обработке сложных запросов.

<div id="database-performance-improvement">
  ### Улучшение производительности базы данных
</div>

Операции с базой данных теперь выполняются быстрее, чем когда-либо: время выполнения самой ресурсоёмкой операции сократилось с 200 мс до менее чем 1 мс.

<div id="better-documentation">
  ### Улучшенная документация
</div>

<img src="/assets/mirror/cleanshot-2025-02-27-at-1042282xpng-220848-e5317a7cfb93.png" alt="Обновлённый дизайн документации" width="3680" height="2382" data-path="images/changelog/2025-02-28/cleanshot-2025-02-27-at-1042282xpng-220848.png" />

Документация была переработана, чтобы её было проще понимать и использовать, и теперь она полностью адаптирована для LLM.

В документации появилась кнопка «Copy Page», позволяющая скопировать всю страницу в формате Markdown. Вы также можете индексировать документацию с помощью `llms.txt` и `llms-full.txt` для использования в собственных LLM.

* [https://docs.replit.com/llms.txt](https://docs.replit.com/llms.txt)
* [https://docs.replit.com/llms-full.txt](https://docs.replit.com/llms-full.txt)
