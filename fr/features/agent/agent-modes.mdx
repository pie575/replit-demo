title: "Modes Agent"
description: "Découvrez comment choisir entre Free Mode, Power Mode et Max Mode pour vos constructions Agent."
---

Les modes Agent vous permettent de contrôler l'équilibre entre coût et capacité lors de l'utilisation d'Agent. Utilisez le menu déroulant des paramètres Agent pour choisir **Free Mode**, **Power Mode** ou **Max Mode**. Free Mode utilise toujours Auto. Les développeurs sur les plans Core et Pro peuvent utiliser le [sélecteur de modèle](/fr/features/agent/model-selector) en Power Mode ou en Max Mode. Les modes et paramètres affichés dépendent de votre plan et de votre espace de travail.

<Note>
  Economy Mode n'est plus disponible. Power Mode le remplace au même prix.
</Note>

<Tip>
  **Raccourci clavier :** Appuyez sur **⌘+Shift+I** (Ctrl+Shift+I sur Windows) pour parcourir les modes Agent sans quitter la zone de saisie du chat.
</Tip>

## Free Mode

**Optimisé pour démarrer.** Free Mode vous aide à explorer des idées, à apprendre comment fonctionne Replit et à démarrer un projet.

**À garder à l'esprit :** Free Mode utilise toujours Auto, le routage de modèle intelligent de Replit. Pour sélectionner un modèle manuellement, utilisez Power Mode ou Max Mode.

<Note>
  Les plans Core et Pro incluent une allocation Free Mode qui se renouvelle toutes les cinq heures. Lorsque vous avez épuisé toute votre allocation, Replit indique quand elle se renouvellera.
</Note>

Les Routines ne s'exécutent pas en Free Mode. Elles s'exécutent en Power Mode ou en Max Mode et nécessitent un budget par exécution. En savoir plus sur les [Routines](/fr/chat/routines).

## Power Mode

**Optimisé pour le coût.** Power Mode utilise moins de crédits par tâche et est le meilleur choix par défaut lorsque vous souhaitez de bons résultats sans payer pour les modèles les plus performants.

**Idéal pour :** Les constructions quotidiennes, l'apprentissage et le travail économique sur un projet existant.

## Max Mode

**Optimisé pour la capacité.** Max Mode utilise des modèles plus performants pour les tâches complexes, les bases de code plus importantes et les problèmes difficiles.

**Idéal pour :** Les projets de qualité production, les fonctionnalités complexes et lorsque vous souhaitez les meilleurs résultats d'Agent.

## Quel mode devrais-je utiliser ?

Utilisez le guide suivant :

| Objectif                                                                      | Mode recommandé                                                                |
| ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| Explorer des idées, apprendre comment fonctionne Replit et démarrer un projet | Free Mode                                                                      |
| Maximiser le nombre de prompts par crédit                                     | Power Mode                                                                     |
| Équilibrer coût et qualité pour la plupart des projets                        | Power Mode                                                                     |
| Sélectionner un modèle manuellement                                           | Power Mode ou Max Mode                                                         |
| Meilleurs résultats sur des projets complexes et de qualité production        | Max Mode                                                                       |
| Meilleur résultat possible sur les tâches les plus complexes                  | Max Mode avec un [Effort](/fr/features/agent/model-selector#effort) plus élevé |

Utilisez le menu déroulant des paramètres Agent dans la zone de saisie du chat pour choisir un mode. Les développeurs sur les plans Core et Pro peuvent définir un [modèle principal et un Effort](/fr/features/agent/model-selector) en Power Mode ou en Max Mode. Aucun mode n'est toujours le meilleur. Choisissez celui qui convient à la tâche en cours.

## Paramètres dans les projets partagés

Vos paramètres Agent vous sont liés, pas au projet. Lorsque vous invitez un coéquipier dans un projet, chacun de vous conserve ses propres choix pour :

* Mode (Free Mode, Power Mode ou Max Mode)
* [Modèle principal et Effort](/fr/features/agent/model-selector), lorsque disponible
* [Mode Plan](/fr/features/agent/plan-mode)
* Fusion automatique pour les tâches en arrière-plan
* Approbation automatique pour les plans

Lorsqu'un coéquipier passe à Max Mode pour sa prochaine tâche, cela ne change pas vos paramètres vers Max Mode. Le mode et les paramètres que vous voyez dans le menu déroulant des paramètres Agent sont ceux qu'Agent utilise lorsque vous envoyez le prochain message, quel que soit le nombre de collaborateurs dans le projet.

## Vérifier votre allocation Free Mode

Ouvrez **Paramètres** → **Utilisation** pour voir combien il vous reste de votre allocation Free Mode et quand elle sera renouvelée. Pour des conseils pratiques afin de tirer le meilleur parti de cette allocation, consultez [Tirer le meilleur parti de Free Mode](/fr/chat/free-mode).
