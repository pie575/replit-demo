<div id="section">
  ## 开始使用
</div>

按照以下步骤安装应用并创建项目。

<div id="section-2">
  ### 安装应用
</div>

1. 前往[移动应用下载页面](https://replit.com/mobile)，下载并安装适用于您的移动设备操作系统的应用。
2. 打开应用，创建新账户或登录现有账户。
   创建新账户时，您需要验证电子邮件地址才能完成注册流程。

<div id="section-3">
  ### 开始构建
</div>

你可以通过主屏幕的两种方式开始：

* **继续之前的工作**：在 **Recent Projects** 中打开项目，然后继续操作。
* **从头开始构建**：在提示框中描述你的需求并发送，Agent 会立即开始构建项目。

如需从预制模板或现有代码开始，请点按右上角的 ⋮，然后选择 **Remix a Template** 或 **Import from GitHub**。

<Note>
  正在构建原生 iOS 应用？请使用 [replit.com](https://replit.com) 上的 Project Editor 创建、预览、构建或提交应用。支持时，你也可以在 Replit Android 应用中开发原生移动应用。
</Note>

<div id="section-5">
  ## 移动端功能
</div>

<div id="section-6">
  ### 语音输入
</div>

使用 Agent 提示框中的语音选项，你无需动手即可说明想要创建或修改的内容。

<div id="live-activities">
  ### 实时活动
</div>

即使在外出时，也能查看 Agent 的进度。Agent 启动后会显示通知。在锁定屏幕上轻点 **允许**，无需打开 Replit 即可查看进度。

<Accordion title="支持的设备">
  * 运行 iOS 18 或更高版本的 iPhone
  * 运行 iOS 18 或更高版本的 iPad
  * 运行 macOS Tahoe 或更高版本的 Mac
  * 已配对的 Apple Watch
</Accordion>

<div id="notifications">
  ### 通知
</div>

无论身在何处，都能接收重要更新。前往 **设置**，打开 **通知** (例如在 **用户** 下) 。确认已开启通知，并在出现提示时轻点“允许”。

以下情况下，Replit 会通知你：

* Agent 需要你协助时
* Agent 完成任务时
* 有重要的付款更新时

<div id="tablet-keyboard-mode">
  ### 平板键盘模式
</div>

将键盘连接到平板后，即可使用针对大屏幕优化的工作环境。连接键盘后首次打开 Project Editor 时，系统会提示您是否启用此功能。

您可随时前往 **账户** &gt; **键盘设置** 将其开启或关闭。

<div id="section-7">
  ## 升级和付款
</div>

如需在应用中升级到 Core，请前往 **账户**，轻点 **升级**，选择套餐后轻点 **继续使用 Core**。Pro 无法在移动应用中购买，需前往 [replit.com](https://replit.com) 购买。

如需使用超出订阅所含额度的 Agent，请添加用于[按用量计费](/zh/ko/billing/about-usage-based-billing)的付款方式：

* **在网页版中**：前往 replit.com，然后打开 **设置** → **账户** → **账单**。
* **在应用中 (仅限美国 iOS)&#x20;**：打开 **设置** → **账单** (或 **账户** → **账单**) 。
