export const YouTubeEmbed = ({videoId, title = "Видео на YouTube", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

Agent 3 существенно улучшает автономность, надёжность и скорость работы:

* **App Testing**: Agent самостоятельно тестирует приложение в реальном браузере, выявляет проблемы и исправляет их в цикле анализа. См. [App Testing](/ru/core-concepts/agent/app-testing).
* **Увеличенное время работы**: Agent может автономно работать до 200 минут с Live Monitoring — это идеально для более крупных проектов. Подробнее см. в [Agent](/ru/core-concepts/agent#max-autonomy).
* **Создание агентов**: Создавайте агентов и автоматизации, работающие по расписанию или интегрирующиеся со Slack и Telegram. См. [Agents &amp; Automations](/ru/core-concepts/agent/agents-and-automations).

<div id="app-connectors-and-integrations">
  ## Коннекторы и интеграции App
</div>

Быстрее выпускайте приложения благодаря встроенным интеграциям и коннекторам:

* **Управляемые Replit**: Встроенные интеграции, которые автоматически работают в ваших приложениях.
* **Коннекторы**: Фирменные интеграции, в которые достаточно войти один раз, чтобы использовать их в разных приложениях.
* **Внешние интеграции**: Надёжные сторонние сервисы, которые Agent настраивает с помощью ваших API-ключей.
