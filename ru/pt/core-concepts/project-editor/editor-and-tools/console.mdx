---
title: "Консоль"
description: "Узнайте, как использовать Консоль для просмотра вывода, ошибок и журналов активности приложения."
---

Консоль позволяет отслеживать и просматривать логи, выводимые запущенным Replit App в реальном времени.
Используйте сведения о текущих и предыдущих запусках, чтобы понять работу приложения,
устранять ошибки и оптимизировать производительность.

<Tip>
  При отладке с помощью Agent добавьте логи консоли в prompt, чтобы предоставить ему контекст.
</Tip>

<div id="recursos">
  ## Ресурсы
</div>

Консоль предоставляет следующие инструменты, которые помогут вам понять, как работает ваше приложение:

* **Журналирование в реальном времени**: Просматривайте вывод приложения по мере его появления
* **Помощь ИИ**: Получайте рекомендации по исправлению ошибок, указанных в логах
* **История запусков**: Просматривайте логи предыдущих запусков, чтобы отслеживать изменения

<div id="uso">
  ## Использование
</div>

Открыть инструмент Консоль можно прямо в редакторе проектов.

<Accordion title="Как открыть Консоль">
  В **панели инструментов** слева:

  1. Выберите <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Значок «Все инструменты»" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **Все инструменты**, чтобы открыть список инструментов редактора проектов.
  2. Выберите <img class="icon-svg" src="/assets/mirror/console-8a41ac90789c.svg" alt="Значок Консоль" width="16" height="16" data-path="images/icons/console.svg" /> **Консоль**.

  В **строке поиска**:

  1. Выберите <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="значок лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> значок лупы в верхней части экрана, чтобы открыть поиск.
  2. Введите «Консоль», найдите инструмент и выберите его в результатах поиска.
</Accordion>

При каждом нажатии кнопки **Запустить** в Replit App в Консоль появляется новая запись со следующей информацией:

* Команда, запустившая ваш код
* Дата и время
* Логи стандартного вывода и ошибок

На следующем снимке экрана показаны команда `npm run dev`, используемая для запуска приложения, и сообщения лога выполнения:

<Frame>
  <img src="/assets/mirror/console-log-entry-b57e5b89087d.png" alt="Запись лога Консоль с указанием выполненной команды" width="1948" height="870" data-path="images/workspace/console-log-entry.png" />

<Note>
  Логи на стороне клиента, например генерируемые кодом HTML, CSS и JS, отображаются только в инструментах разработчика в [Preview](/ru/pt/core-concepts/project-editor/editor-and-tools/preview).
</Note>

<div id="depurao-com-ia">
  ### Отладка с помощью ИИ
</div>

Если в логах вы обнаружите ошибки или другую информацию, которую хотите понять, нажмите
кнопку **Спросить ИИ** в верхней части записи. Откроется вкладка **Agent**, а
содержимое лога автоматически отправится на анализ.

<div id="comandos-de-entrada-de-log">
  ### Команды записей журнала
</div>

Консоль предоставляет следующие инструменты для управления логами:

* **Показывать только последний**: Включите этот переключатель, чтобы отображался только последний запуск.
* **Свернуть запись**: Нажмите <img class="icon-svg" src="/assets/mirror/down-arrow-9c1cf9fd152e.svg" alt="значок стрелки вниз" height="16" width="16" data-path="images/icons/down-arrow.svg" /> стрелку вниз слева от имени команды, чтобы скрыть логи.
* **Очистить предыдущие запуски**: Нажмите, чтобы удалить логи предыдущих запусков. Это действие необратимо.

<div id="disponibilidade-de-rede">
  ### Доступность сети
</div>

Вы можете управлять доступностью в интернете версии приложения для разработки.

Чтобы прекратить обработку запросов к URL-адресу разработки, нажмите значок <img class="icon-svg" src="/assets/mirror/network-off-5bdca8a4fe4e.svg" alt="значок отключенной сети" height="16" width="16" data-path="images/icons/network-off.svg" /> перечёркнутого глобуса справа в строке сведений о сети.

Чтобы снова включить её, нажмите значок <img class="icon-svg" src="/assets/mirror/network-on-15be2e5fb4f5.svg" alt="значок включенной сети" height="16" width="16" data-path="images/icons/network-on.svg" /> глобуса.

Чтобы просмотреть URL-адрес разработки, нажмите текст `{...}.replit.dev` в адресной строке.

<Frame>
  <img src="/assets/mirror/preview-dev-url-b36770b33769.png" alt="Расположение URL-адреса разработки в Preview" width="1222" height="824" data-path="images/workspace/preview-dev-url.png" />
</Frame>

<Note>
  Приложение остаётся доступным в Preview, даже если оно настроено на прекращение обработки запросов к URL-адресу разработки.
</Note>

<div id="parar-um-comando-de-workflow">
  ### Остановка команды рабочего процесса
</div>

Выполняемую команду рабочего процесса можно остановить в инструменте «Консоль» редактора проектов.

Чтобы завершить команду запуска вашего Replit App, нажмите квадратную кнопку справа от строки с этой командой.

Чтобы перезапустить App, используйте кнопку **Запустить** рабочего процесса в верхней части редактора проектов.
