Le contrôle de version sur Replit vous permet de suivre et de gérer votre base de code, et d&#39;y collaborer en toute confiance. Grâce à l&#39;intégration Git native et à la connexion avec GitHub, vous pouvez :

* Suivre les modifications du code et conserver un historique de votre travail de développement
* Collaborer avec les membres de votre équipe sans conflits de code ni perte de travail
* Importer, modifier et pousser du code entre Replit et GitHub
* Utiliser des branches pour expérimenter de nouvelles fonctionnalités en toute sécurité

<div id="what-is-version-control">
  ## Qu&#39;est-ce que le contrôle de version ?
</div>

Le contrôle de version est un système qui enregistre les modifications apportées aux fichiers au fil du temps, ce qui vous permet de revenir à une version précise ultérieurement. Sur Replit, le contrôle de version repose sur Git — l&#39;outil de référence du secteur pour suivre les modifications de code — avec une interface visuelle intuitive qui vous dispense de toute connaissance de la ligne de commande.

<div id="how-version-control-works-on-replit">
  ### Fonctionnement du contrôle de version sur Replit
</div>

Les quatre options de contrôle de version interagissent toutes avec le même dépôt Git sous-jacent :

1. **Les checkpoints de l&#39;Agent** créent automatiquement des commits aux étapes clés lorsque vous développez avec [Replit Agent](/fr/features/agent/overview). [En savoir plus sur les checkpoints et les retours en arrière](/fr/features/version-control/checkpoints-and-rollbacks).
2. **Le panneau Git** offre un accès visuel à l&#39;ensemble du dépôt Git
3. **Git CLI** donne accès à toutes les fonctionnalités Git en ligne de commande
4. **L&#39;historique des fichiers** suit les modifications détaillées au sein de chaque fichier

Choisissez l&#39;interface qui correspond le mieux à vos besoins, en sachant que tout s&#39;appuie sur la robustesse du système de contrôle de version Git.

| Fonctionnalité             | Checkpoints de l&#39;Agent                  | Commits Git                            | Historique des fichiers               |
| -------------------------- | ------------------------------------------- | -------------------------------------- | ------------------------------------- |
| **Création**               | Automatique à des points logiques           | Manuelle ou planifiée                  | Automatique                           |
| **Granularité**            | Modifications au niveau des fonctionnalités | Modifications de toute taille          | Modifications caractère par caractère |
| **Description**            | Résumés générés par l&#39;IA                | Messages rédigés par l&#39;utilisateur | Horodatages automatiques              |
| **Retour en arrière**      | Retour en arrière en un clic                | Nécessite des connaissances en Git     | Retour en arrière en un clic          |
| **Capacités Git**          | Capacités Git complètes                     | Capacités Git complètes                | Aucune capacité Git                   |
| **Synchronisation GitHub** | Synchronisation GitHub complète             | Synchronisation GitHub complète        | Aucune synchronisation GitHub         |

<div id="getting-started">
  ## Premiers pas
</div>

Accédez au contrôle de version dans votre Replit App en ajoutant l&#39;outil Git au Project Editor :

1. Rendez-vous dans la section Tools de votre Replit App
2. Sélectionnez le signe **+** pour ajouter de nouveaux outils
3. Sélectionnez **Git** dans la liste des outils disponibles

Pour importer des projets existants depuis GitHub, consultez [Importer depuis GitHub](/fr/build/import-from-providers).

<div id="automatic-version-control">
  ### Contrôle de version automatique
</div>

<Accordion title="Checkpoints de l'Agent">
  Instantanés automatiques créés pendant le développement assisté par IA avec [Replit Agent](/fr/features/agent/overview).

  **Idéal pour** : le développement avec Replit Agent

  **Fonctionnalités clés** :

  * Création automatique aux étapes clés
  * Retour en arrière en un clic
  * Instantanés au niveau des fonctionnalités
  * Suivi de la progression
  * Aucune configuration requise
  * Chronologie visuelle de l&#39;avancement du développement

  Les checkpoints de l&#39;Agent sont stockés dans Git et accessibles via le panneau Git ou la CLI Git. Vous pouvez également visualiser l&#39;ensemble de vos checkpoints grâce à la fonctionnalité Historique, qui offre :

  * Une visualisation chronologique des checkpoints
  * Des descriptions détaillées des checkpoints
  * Un accès direct aux états des checkpoints
  * Un retour en arrière en un clic vers n&#39;importe quel checkpoint
</Accordion>

<Accordion title="Historique des fichiers">
  Suivi des versions fichier par fichier, avec sauvegarde automatique des modifications effectuées directement dans l&#39;éditeur, en dehors de l&#39;Agent.

  **Idéal pour** : récupérer rapidement des modifications récentes d&#39;un fichier

  **Fonctionnalités clés** :

  * Focus sur un seul fichier
  * Modifications au niveau du caractère
  * Comparaison visuelle
  * Historique sur 30 jours
  * Fonctionnalité de relecture

  Bien que l&#39;Historique des fichiers dispose de sa propre interface, les modifications sous-jacentes font partie de l&#39;historique Git. En savoir plus sur l&#39;[Historique des fichiers](/fr/features/version-control/file-history).
</Accordion>

<Accordion title="Panneau Git">

  **Idéal pour** : la plupart des projets nécessitant une intégration à GitHub et un flux de travail visuel

  **Fonctionnalités principales** :

  * Suivi de l’ensemble du dépôt
  * Gestion des branches
  * Affichage visuel des différences
  * Synchronisation GitHub en un clic

  Pour des instructions détaillées sur l’utilisation du panneau Git, consultez [Utiliser le panneau Git](/fr/features/workspace-tools/git-interface).

<Accordion title="Git CLI">
  Accès complet à Git en ligne de commande via le [Shell](/fr/features/workspace-tools/shell) pour les opérations avancées.

  **Idéal pour** : les utilisateurs avancés ayant besoin de toutes les fonctionnalités de Git

  **Fonctionnalités principales** :

  * Ensemble complet des commandes Git
  * Stratégies de branchement avancées
  * Flux de travail personnalisés
  * Automatisation par scripts
  * Contrôle complet du dépôt

  Pour les commandes Git courantes et leur utilisation, consultez [Utiliser le panneau Git](/fr/features/workspace-tools/git-interface#using-git-commands-in-shell).

<div id="key-features">
  ## Fonctionnalités clés
</div>

* **Interface Git visuelle** : gérez les dépôts, les commits et les branches sans taper de commandes Git
* **Intégration à GitHub** : connectez des dépôts GitHub pour la sauvegarde et la collaboration
* **Importation depuis GitHub** : transformez n’importe quel [dépôt GitHub en Replit App](/fr/build/import-from-providers) en quelques clics
* **Gestion des branches** : créez, changez de branche et fusionnez des branches directement dans le Project Editor
* **Résolution des conflits** : identifiez et résolvez les conflits de fusion grâce à une assistance visuelle

<div id="use-cases">
  ## Cas d&#39;usage
</div>

**Suivre vos projets personnels**

Suivez les modifications apportées à votre code au fil du développement, ce qui vous permet de revenir à une version antérieure si besoin. Le [panneau Git](/fr/features/workspace-tools/git-interface) affiche vos modifications de manière visuelle, ce qui facilite la validation de mises à jour pertinentes.

**Collaborer en équipe**

Travaillez à plusieurs sur la même base de code sans écraser les modifications des autres. Créez des branches pour les nouvelles fonctionnalités, puis fusionnez-les une fois prêtes. Pour en savoir plus, consultez [Inviter des coéquipiers](/fr/build/invite-teammates).

<div id="agent-checkpoints">
  ## Checkpoints de l&#39;Agent
</div>

Lorsque vous créez des applications avec [Replit Agent](/fr/features/agent/overview), vous bénéficiez d&#39;une couche supplémentaire de contrôle de version grâce aux checkpoints. Ceux-ci capturent automatiquement l&#39;état complet de votre projet — contenu du projet, contexte de la conversation avec l&#39;IA et bases de données connectées — aux moments clés du développement assisté par IA.

<div id="how-checkpoints-work">
  ### Fonctionnement des checkpoints
</div>

Les checkpoints d’Agent sont des instantanés complets de l’état de l’ensemble de votre Replit App :

* **Création automatique** : Agent crée des checkpoints à des étapes clés du développement
* **Capture complète de l’état** : Chaque checkpoint préserve le contenu du projet, la mémoire de l’IA et l’état de la base de données
* **Plans d’implémentation** : Avant d’apporter des modifications, Agent vous présente un plan à examiner
* **Suivi des tâches complexes** : Plusieurs checkpoints peuvent être créés pour les tâches de plus grande envergure

<div id="benefits-for-ai-assisted-development">
  ### Avantages pour le développement assisté par IA
</div>

Les checkpoints d&#39;Agent offrent des avantages uniques lorsque vous créez avec l&#39;IA :

* **Filet de sécurité** : expérimentez en toute confiance, en sachant que vous pouvez facilement restaurer des états antérieurs sur l&#39;ensemble de votre environnement de développement
* **Suivi de la progression** : visualisez précisément comment Agent a construit votre application, étape par étape
* **Jalons logiques** : les checkpoints correspondent à des fonctionnalités abouties plutôt qu&#39;à des points de sauvegarde arbitraires
* **Retour arrière instantané** : revenez à n&#39;importe quel état antérieur en un seul clic, avec restauration de la base de données et du contexte IA

<Info>
  Pour en savoir plus sur ce que capturent les checkpoints et sur les possibilités complètes de retour arrière, consultez [Checkpoints et retours arrière](/fr/features/version-control/checkpoints-and-rollbacks).
</Info>

<Tip>
  Même si les checkpoints d&#39;Agent sont très utiles pour développer avec l&#39;IA, privilégiez les commits Git pour le suivi de versions à long terme et la collaboration, en particulier lorsque vous travaillez avec des dépôts externes.
</Tip>
