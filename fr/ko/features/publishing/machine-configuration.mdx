---
title: "Configuration de la machine"
description: "Configurez les performances et le coût du serveur qui exécute votre application publiée : processeur, mémoire et nombre maximal de machines."
---

La configuration de la machine détermine les performances du serveur qui exécute votre application publiée. Replit choisit des valeurs par défaut adaptées ; la plupart des utilisateurs n&#39;ont donc pas besoin de les modifier. Envisagez une configuration plus puissante si votre application ralentit sous charge ou traite de grandes quantités de données en mémoire.

Pour modifier cette configuration, ouvrez l&#39;outil Publishing, sélectionnez **Adjust settings**, puis **Edit** à côté de **Machine configuration**.

<div id="section">
  ## Paramètres
</div>

* **CPU** : quantité de travail que chaque serveur peut traiter simultanément. Plus il y a de vCPU, plus l&#39;application peut prendre en charge d&#39;utilisateurs simultanément.
* **Mémoire (RAM)** : quantité de données que l&#39;application peut conserver en mémoire. Davantage de RAM est utile pour les fichiers volumineux, les médias et les tâches gourmandes en données.
* **Nombre maximal de machines** : s&#39;applique uniquement à Autoscale. Il s&#39;agit du nombre maximal de serveurs que Replit peut ajouter lorsque l&#39;application est sollicitée. L&#39;application ne s&#39;adaptera pas au-delà de ce nombre, ce qui limite le coût maximal.

<div id="section-2">
  ## Coûts
</div>

Lors de la configuration, le panneau affiche deux valeurs :

* **Par machine :** le coût horaire d&#39;exécution d&#39;un serveur avec la configuration sélectionnée.
* **Au pic de trafic :** le coût horaire lorsque votre application est suffisamment sollicitée pour utiliser le nombre maximal de machines.

Les coûts sont exprimés en unités de calcul, une unité de cloud computing basée sur le processeur et la mémoire que vous sélectionnez. Pour consulter les tarifs actuels et en savoir plus sur la facturation à l&#39;utilisation, consultez [Facturation à l&#39;utilisation](/fr/ko/billing/about-usage-based-billing#2-compute-units).

<div id="section-3">
  ## Différences de facturation selon le type de déploiement
</div>

À configuration identique, la facturation varie selon le [type de déploiement](/fr/ko/features/publishing/deployment-types).

* **Autoscale** : des frais sont facturés pendant le traitement des requêtes. Lorsque l’application est inactive, elle est réduite à zéro, sans frais d’exécution.
* **Reserved VM** : le serveur étant toujours actif, vous payez un montant mensuel fixe pour la configuration sélectionnée.
* **Static** : aucune machine n’exécute le site, la configuration de la machine ne s’applique donc pas.
* **Scheduled** : vous payez des frais de machine pour chaque exécution planifiée.

<div id="section-4">
  ## Appliquer les modifications
</div>

Après avoir modifié la configuration, republiez l’application. Les nouveaux paramètres de la machine prendront effet avec le nouveau déploiement.
