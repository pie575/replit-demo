<div id="security-agent-revisa-toda-a-sua-base-de-cdigo">
  ### Security Agent examine l’ensemble de votre base de code
</div>

Le **Security Agent** est un nouvel outil de révision basé sur l’intelligence artificielle qui audite non seulement vos dépendances, mais aussi l’intégralité de votre projet. Il crée un modèle de menaces, cartographie vos routes et flux de données, effectue une analyse statique avec Semgrep et HoundDog.ai, puis utilise un LLM pour déterminer quels constats sont réellement exploitables dans le contexte de votre app. Une fois la révision terminée, le Security Agent organise les constats retenus en tâches parallèles que Replit Agent peut corriger en une seule passe.

<Frame>
  <img src="/assets/mirror/security-agent-findings-b425392bb98a.png" alt="Panneau Security Agent dans le Centre de sécurité du projet montrant un scan terminé avec cinq constats classés par gravité, chacun avec un statut tel que 'Prêt pour révision' ou 'Prêt à republier', ainsi qu’une section d’analyse automatique des dépendances répertoriant les packages vulnérables" width="1438" height="808" data-path="images/changelog/2026-04-24/security-agent-findings.png" />
</Frame>

Security Agent est disponible pour tous les créateurs disposant d’une offre payante. Ouvrez le panneau **Sécurité** dans votre projet et sélectionnez **Exécuter un scan avec Agent** pour l’essayer.

En savoir plus sur [Security Agent](/fr/pt/core-concepts/security/project-security-center#agent-security-scans).

<div id="cve-auto-protect-corrige-vulnerabilidades-crticas-automaticamente">
  ### CVE Auto-Protect corrige automatiquement les vulnérabilités critiques
</div>

Lorsqu’un nouveau CVE critique est divulgué pour un package dont dépend votre app, **CVE Auto-Protect** détecte les projets concernés, demande à Agent de préparer un correctif dans une tâche en arrière-plan, exécute vos tests pour s’assurer que rien ne se casse et vous avertit avec un lien pour le réviser. Vous gardez le contrôle — rien n’est publié tant que vous n’avez pas approuvé le correctif.

Vos apps peuvent ainsi être corrigées quelques minutes après qu’une nouvelle vulnérabilité a été rendue publique, au lieu d’attendre que vous la remarquiez.

En savoir plus sur [CVE Auto-Protect](/fr/pt/core-concepts/security/project-security-center#auto-protect).

<div id="prvia-em-um-ios-simulator-ou-android-emulator">
  ### Aperçu sur un iOS Simulator ou un Android Emulator
</div>

<Frame>
  <video autoPlay muted loop playsInline src="/assets/mirror/ios-emulator-9013ff1b602f.mp4" />
</Frame>

Lorsque votre projet inclut une application mobile, le panneau d’aperçu peut désormais diffuser un véritable **iOS Simulator** ou **Android Emulator** directement dans votre workspace. Pas besoin de Xcode, d’Android Studio ni d’appareil physique. Créez une application mobile avec Agent, sélectionnez votre appareil dans le menu déroulant du panneau d’aperçu et interagissez avec lui comme si vous l’aviez en main. Les modifications se rechargent instantanément dans le simulateur à mesure qu’Agent les effectue.

Disponible pour les créateurs disposant d’un forfait payant Core, Pro ou Enterprise, dans Chrome, Safari et les navigateurs basés sur Chromium. Firefox n’est pas compatible avec les simulateurs mobiles.

En savoir plus sur [l’aperçu sur un simulateur ou un émulateur](/fr/pt/replitai/building-mobile-apps#preview-on-a-simulator-or-emulator).

<div id="adicione-um-app-mobile-a-projetos-mais-antigos">
  ### Ajoutez une application mobile à d’anciens projets
</div>

<Frame>
  <img src="/assets/mirror/multi-artifact-update-approval-f6fa8b70a100.png" alt="Panneau Chat d’Agent affichant la carte d’approbation « Mettre à jour le projet pour créer une application mobile », avec une offre de crédit de 5 $ et les boutons Pas maintenant / Mettre à jour le projet." width="991" height="589" data-path="images/replitai/multi-artifact-update-approval.png" />
</Frame>

Les projets créés avant le lancement d’Agent 4 peuvent désormais être mis à jour pour prendre en charge plusieurs artifacts. Vous pouvez ainsi ajouter une application mobile, un pitch deck ou un autre artifact à un projet qui n’en prenait auparavant en charge qu’un seul. Agent préserve votre URL, vos données, vos Secrets et votre déploiement lors de la réorganisation du projet. Plus de 200 projets ont été migrés au cours des 48 premières heures suivant le lancement généralisé.

Découvrez [comment mettre à jour d’anciens projets pour prendre en charge plusieurs artifacts](/fr/pt/replitai/updating-projects-for-multiple-artifacts).

<div id="conector-plaid-disponvel">
  ### Connecteur Plaid disponible
</div>

Vous pouvez désormais vous connecter à plus de 12 000 institutions financières grâce au connecteur **Plaid**. Les administrateurs d&#39;équipe configurent les identifiants une seule fois dans **Intégrations**, et les utilisateurs de votre app authentifient leurs propres comptes bancaires via Plaid Link. Les jetons d&#39;accès sont propres à chaque utilisateur, afin que les données restent privées.

Créez un coach financier personnel qui utilise des données de transaction réelles, un outil de suivi de portefeuille en temps réel connecté à votre courtier, et bien plus encore. Consultez la [page partenaire Replit x Plaid](https://replit.com/partners/plaid) pour découvrir des démonstrations et les étapes de configuration.

En savoir plus sur [la gestion des connecteurs](/fr/pt/replitai/managing-connectors).
