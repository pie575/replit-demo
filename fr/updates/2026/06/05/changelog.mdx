<div id="sell-physical-products-with-shopify">
  ### Vendez des produits physiques avec Shopify
</div>

Vous pouvez désormais créer une boutique en ligne pour vendre des produits physiques. Demandez à Agent de créer une boutique : il crée pour vous une boutique Shopify, ajoute vos produits et configure le panier et le checkout. Agent vous fournit un lien pour revendiquer la boutique, puis vous souscrivez à un forfait Shopify et connectez les paiements pour la mettre en ligne.

En savoir plus sur la [connexion à Shopify](/fr/features/integrations/shopify).

<div id="build-data-apps-on-microsoft-fabric">
  ### Créez des applications de données sur Microsoft Fabric
</div>

Vous pouvez désormais créer des applications de données basées sur l’IA dans Replit et les publier directement sur Microsoft Fabric. Utilisez le template Microsoft Fabric, connectez un modèle sémantique Power BI et demandez à Agent de créer des tableaux de bord et des outils internes à partir de vos données Enterprise gouvernées, tout en conservant l’authentification et les stratégies d’accès dans Fabric.

<div id="custom-domains-set-up-their-own-dns">
  ### Les domaines personnalisés configurent automatiquement leur DNS
</div>

Associer votre propre nom de domaine est désormais bien plus simple. Lorsque vous associez un domaine, Replit configure les enregistrements DNS requis via Entri. Vous n&#39;avez donc plus besoin de les copier manuellement chez votre fournisseur de domaine. Choisissez votre domaine, confirmez, et Replit s&#39;occupe du reste.

En savoir plus sur les [domaines personnalisés](/fr/features/publishing/custom-domains).

<div id="improve-your-search-ranking-with-seo-agent">
  ### Améliorez votre classement dans les résultats de recherche avec SEO Agent
</div>

SEO Agent examine votre application publiée et identifie les problèmes qui empêchent les moteurs de recherche et les outils d&#39;IA de la trouver. Chaque problème détecté inclut une correction en un clic que vous pouvez examiner et appliquer. Ouvrez le volet **Growth** de votre projet pour lancer une analyse.

<div id="use-stripe-in-collaborative-workspaces">
  ### Utiliser Stripe dans les workspaces collaboratifs
</div>

Stripe fonctionne désormais dans les workspaces collaboratifs, afin que toute votre équipe puisse développer, tester et monétiser la même app. Tous les membres du workspace peuvent utiliser le compte Stripe connecté au lieu de créer seuls les paiements.

En savoir plus sur les [Paiements Stripe](/fr/features/monetization/stripe-payments).
