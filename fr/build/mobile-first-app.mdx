export const PromptActions = ({prompt = "", campaign = "docs-prompt-actions"}) => {
  const LZ_SRC = "https://cdnjs.cloudflare.com/ajax/libs/lz-string/1.5.0/lz-string.min.js";
  const ensureLZString = () => {
    if (typeof document === "undefined") return;
    if (window.LZString) return;
    if (document.querySelector(`script[src="${LZ_SRC}"]`)) return;
    const s = document.createElement("script");
    s.src = LZ_SRC;
    s.async = true;
    document.head.appendChild(s);
  };
  const handleCopy = async e => {
    const btn = e.currentTarget;
    if (!prompt) return;
    try {
      await navigator.clipboard.writeText(prompt);
    } catch {
      const ta = document.createElement("textarea");
      ta.value = prompt;
      document.body.appendChild(ta);
      ta.select();
      try {
        document.execCommand("copy");
      } catch {}
      document.body.removeChild(ta);
    }
    const original = btn.dataset.label || btn.innerText;
    btn.dataset.label = original;
    btn.innerText = "Copié !";
    setTimeout(() => {
      if (btn.isConnected) btn.innerText = original;
    }, 1500);
  };
  const handleBuild = () => {
    if (!prompt || typeof window === "undefined") return;
    const utm = `utm_source=replit-docs&utm_medium=docs&utm_campaign=${encodeURIComponent(campaign)}&utm_content=prompt-actions`;
    let url;
    if (window.LZString) {
      const encoded = window.LZString.compressToEncodedURIComponent(prompt);
      url = `https://replit.com/?prompt=${encoded}&referrer=replit-docs&${utm}`;
    } else {
      url = `https://replit.com/?prompt=${encodeURIComponent(prompt)}&referrer=replit-docs&${utm}`;
    }
    window.open(url, "_blank", "noopener,noreferrer");
  };
  ensureLZString();
  const baseButtonStyle = {
    display: "inline-flex",
    alignItems: "center",
    gap: "6px",
    padding: "8px 16px",
    borderRadius: "8px",
    fontSize: "14px",
    fontWeight: 500,
    cursor: "pointer",
    lineHeight: 1.2,
    fontFamily: "inherit",
    textDecoration: "none"
  };
  return <div style={{
    display: "flex",
    gap: "12px",
    margin: "16px 0",
    flexWrap: "wrap",
    alignItems: "center"
  }}>
      <button type="button" onClick={handleCopy} style={{
    ...baseButtonStyle,
    background: "transparent",
    color: "inherit",
    border: "1px solid rgba(127,127,127,0.4)"
  }}>
        Copier le prompt
      </button>
      <button type="button" onClick={handleBuild} style={{
    ...baseButtonStyle,
    background: "#F26207",
    color: "#FFFFFF",
    border: "1px solid #F26207"
  }}>
        Build sur Replit ↗
      </button>
    </div>;
};

<div id="before-you-start">
  ## Avant de commencer
</div>

Il vous suffit d’un [compte Replit](https://replit.com/), dont la création est gratuite.

L’objectif est de réaliser un cycle complet :

* Créez-la avec [Agent](/fr/features/agent/overview)
* Testez-la comme application mobile
* Publiez-la et partagez-la

Agent est l’outil de création par IA de Replit. Vous décrivez ce que vous voulez, et il crée l’application, explique
ce qu’il a fait et corrige ce qui ne fonctionne pas.

<div id="1-tell-agent-to-build-the-app">
  ## 1. Demandez à Agent de créer l’application
</div>

Ouvrez Replit et créez une nouvelle application. Décrivez ce que vous souhaitez créer, puis sélectionnez **Application mobile**
comme type d’application.

<div id="2-confirm-it-works-in-preview">
  ## 2. Vérifiez que tout fonctionne dans l’aperçu
</div>

Replit simule PixelGames sur iOS ou Android directement dans le volet d’aperçu. C’est le moyen le
plus rapide de vérifier une modification.

<Steps>
  <Step title="Le simulateur démarre automatiquement">

  </Step>

  <Step title="Changez de plateforme avec le menu déroulant">
    Utilisez le menu déroulant **Simulate on...** dans la barre d’outils du volet d’aperçu (à côté des icônes de clé à molette et
    d’actualisation) pour basculer entre **iOS**, **Android** et **Web**.
  </Step>
</Steps>

<div id="check-that-it-actually-works">
  ### Vérifiez que tout fonctionne correctement
</div>

Utilisez PixelGames comme le ferait un joueur :

* Vérifiez que l’écran **MENU** affiche **Blocks** comme sélectionnable et les trois autres jeux comme « BIENTÔT ».
* Ouvrez Blocks et jouez quelques parties avec la croix directionnelle et les boutons A/B.
* Vérifiez que le score, le niveau et les lignes du HUD se mettent à jour au fil de la partie.

Si quelque chose semble incorrect, décrivez ce que vous avez vu à Agent. Vous n’avez pas besoin de trouver le bug
vous-même.

<div id="troubleshooting">
  ## Résolution des problèmes
</div>

<AccordionGroup>
  <Accordion title="Le volet d’aperçu reste vide">
    La première compilation prend une ou deux minutes, alors patientez un instant avant de penser qu’elle est bloquée.
    S’il reste vide après cela, vérifiez si la console affiche une erreur et partagez-la avec Agent.
  </Accordion>

  <Accordion title="Les modifications n’apparaissent pas dans l’aperçu">
    Appuyez sur **R** dans la console pour recharger PixelGames, puis utilisez l’icône d’actualisation dans la barre d’outils du volet
    d’aperçu s’il ne semble toujours pas à jour.
  </Accordion>

  <Accordion title="Écran d’erreur rouge dans l’aperçu">
    Cela indique généralement une erreur JavaScript ou un package manquant. Lisez le message : il
    indique souvent le fichier et la ligne exacts. Partagez-le ensuite avec Agent et demandez-lui de corriger le problème.
  </Accordion>

  <Accordion title="L’App fonctionne sur le Web mais pas sur iOS ou Android (ou inversement)">
    Certains packages se comportent différemment selon les plateformes : un package qui fonctionne sur le Web peut ne pas
    prendre en charge le natif ou nécessiter une configuration différente. Demandez à Agent « Ce package prend-il en charge le natif ? »
    avant de vous y fier.
  </Accordion>

  <Accordion title="La compilation prend beaucoup de temps">
    La première compilation est toujours plus lente, car rien n’est encore mis en cache ; les suivantes devraient être
    plus rapides. Si elle reste lente, demandez à Agent de vérifier s’il y a des packages inutiles dans le project.
  </Accordion>

  <Accordion title="Erreurs « module introuvable »">
    Cela signifie qu’un package n’est pas installé ou qu’il l’est, mais que le cache n’est pas à jour. Demandez à Agent de
    l’installer ou de vider le cache, et vérifiez que le nom du package ne comporte pas de faute de frappe.
  </Accordion>
</AccordionGroup>
