<div id="o-que-o-visual-editor">
  ## Qu&#39;est-ce que le Visual Editor ?
</div>

Le Visual Editor vous permet de modifier concrètement votre interface en cliquant directement sur les éléments. Il fonctionne aussi bien dans le [Design Canvas](/fr/pt/replitai/canvas) que dans l&#39;aperçu, ce qui vous permet de modifier maquettes et applications en cours d&#39;exécution de la même manière.

Les modifications simples — changements de texte, ajustements de couleur ou d&#39;espacement — mettent à jour directement le code source sans consommer de crédits d&#39;IA. Pour les modifications qui impliquent une complexité cachée, le Visual Editor passe automatiquement le relais à Agent.

Concepts clés :

* **Modifications déterministes** : les modifications simples (texte, couleurs, espacement) s&#39;appliquent directement au code source, sans passer par une boucle Agent
* **Aucun coût en crédits** : les modifications directes ne consomment pas de crédits d&#39;IA — seules les modifications complexes sont acheminées vers Agent
* **Double contexte** : fonctionne de façon identique dans les frames du Design Canvas et dans l&#39;aperçu
* **Synchronisation avec le code source** : chaque modification met instantanément à jour le code source sous-jacent

<Note>
  Le Visual Editor est actuellement disponible uniquement dans les **navigateurs web**. Il n&#39;est compatible ni avec l&#39;application Mobile ni avec l&#39;application Desktop.
</Note>

<div id="como-usar-o-visual-editor">
  ## Comment utiliser le Visual Editor
</div>

<div id="editando-na-prvia">
  ### Modifier dans l&#39;aperçu
</div>

Cliquez sur n&#39;importe quel élément de votre application en cours d&#39;exécution pour commencer à le modifier. Changez le texte, les couleurs, l&#39;espacement ou les images — et voyez les modifications s&#39;appliquer en direct.

<Steps>
  <Step title="Sélectionnez un élément">
    Cliquez sur n&#39;importe quel élément dans l&#39;aperçu pour commencer à le modifier.
  </Step>

  <Step title="Effectuez votre modification">
    Modifiez le texte en ligne, ajustez les couleurs avec le sélecteur de couleurs, changez l&#39;espacement à l&#39;aide des contrôles de style ou remplacez les images. Utilisez le panneau de l&#39;éditeur dans le Chat pour accéder à d&#39;autres propriétés comme padding, margin, et bien plus.
  </Step>

  <Step title="Enregistrez">
    Appuyez sur enregistrer pour mettre à jour le code source. Les modifications simples s&#39;appliquent directement, sans consommer de crédits d&#39;IA. Si la modification s&#39;avère plus complexe, le Visual Editor transmet des métadonnées ciblées à Agent pour obtenir de l&#39;aide.
  </Step>
</Steps>

<div id="o-que-voc-pode-fazer">
  ## Ce que vous pouvez faire
</div>

* **Corrections rapides de texte** : mettez à jour les textes, libellés et titres sans ouvrir les fichiers de code source
* **Exploration des couleurs** : testez différentes palettes de couleurs en cliquant et en ajustant — sans avoir à chercher la bonne règle CSS
* **Ajustements de mise en page** : réglez visuellement le padding, les margins et l&#39;espacement au lieu de deviner des valeurs en pixels
* **Remplacement d&#39;images** : remplacez les images d&#39;espace réservé par vos propres ressources en un clic et un téléversement
* **Itération de design** : ajustez rapidement les frames du Canvas pour comparer plusieurs directions visuelles, sans allers-retours avec Agent

<div id="perguntas-frequentes">
  ## Questions fréquentes
</div>

<Accordion title="Les modifications du Visual Editor coûtent-elles des crédits d'IA ?">
  Les modifications simples et déterministes — changements de texte, choix de couleurs, ajustements d&#39;espacement — ne consomment pas de crédits d&#39;IA : elles mettent directement à jour le code source. Si le Visual Editor détecte une complexité cachée, il redirige la modification vers Agent, ce qui consomme des crédits.
</Accordion>

<Accordion title="Puis-je modifier des éléments qui apparaissent à plusieurs endroits ?">
  Oui. Lorsque vous sélectionnez un élément affiché dans une loop ou réutilisé dans plusieurs composants, toutes ses instances sont mises en évidence et mises à jour simultanément.
</Accordion>

<Accordion title="Pourquoi ne puis-je pas modifier le texte de certains éléments ?">
  Le texte des éléments composés, formés de plusieurs sous-éléments, ne peut pas être modifié directement dans le Visual Editor. Demandez à Agent, dans le Chat, d&#39;effectuer ces modifications.
</Accordion>

<Accordion title="Comment trouver le code source d'un élément ?">
  Cliquez sur l&#39;étiquette située en haut à gauche d&#39;un élément sélectionné pour accéder à son emplacement dans le code source.
</Accordion>
