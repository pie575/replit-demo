Инструмент Secrets хранит и шифрует конфиденциальную информацию Replit App — **секреты**, такие как API-ключи, токены аутентификации и строки подключения к базе данных.

При добавлении секрета инструмент автоматически шифрует данные и предоставляет их Replit App в виде переменных окружения.
Это позволяет не хранить секреты непосредственно в коде и снижает риск их раскрытия.

Если хранить секреты непосредственно в кодовой базе, они могут быть случайно раскрыты в следующих ситуациях:

* При публикации Replit App или передаче кода другим людям через копирование и вставку
* При коммите кода в публичный репозиторий
* При трансляции кода или демонстрации экрана

Используйте инструмент Secrets, чтобы делиться кодом, не беспокоясь о раскрытии учетных данных.

<div id="section">
  ## Возможности
</div>

Секреты поддерживают следующие возможности:

* **Сквозное шифрование**: автоматическая защита данных с помощью шифрования AES-256 при хранении и TLS при передаче
* **Секреты на уровне приложения**: хранение секретов и управление ими для конкретного Replit App
* **Секреты на уровне аккаунта**: хранение секретов и управление ими для использования во всех Replit App
* **Доступ к переменным окружения**: доступ к секретам в коде через переменные окружения
* **Совместный доступ**: предоставление доступа к секретам соавторам и участникам команды

<div id="section-2">
  ## Использование
</div>

<Note>
  Секреты можно использовать во всех типах деплоя, кроме статического.
</Note>

Секреты доступны в инструменте Secrets в Project Editor.

<Accordion title="Как получить доступ к секретам">
  В **доке инструментов** слева:

  1. <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Иконка «Все инструменты»" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> Выберите **Все инструменты**, чтобы открыть список инструментов Project Editor.
  2. <img class="icon-svg" src="/assets/mirror/lock-af402c9618dd.svg" alt="Иконка Secrets" width="16" height="16" data-path="images/icons/lock.svg" /> Выберите **Secrets**.

  В **строке поиска**:

  1. Выберите значок <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="иконка лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> в верхней части, чтобы открыть поиск
  2. Введите &quot;Secrets&quot;, найдите инструмент и выберите его в результатах.
</Accordion>

<div id="section-3">
  ### Управление секретами App
</div>

На вкладке **App Secrets** панели **Secrets** можно управлять секретами на уровне приложения.
На этой вкладке отображается список всех секретов, связанных с Replit App.

<Accordion title="Добавление секрета App">
  Чтобы добавить секрет:

  1. Выберите **New Secret**.
  2. Введите **Key** — имя секрета — и **Value** — значение секрета.
  3. Выберите **Add Secret**, чтобы сохранить запись.
</Accordion>

<Accordion title="Редактирование секрета App">
  Чтобы отредактировать секрет:

  1. Выберите меню с вертикальными точками <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="иконка с тремя вертикальными точками" height="16" width="16" data-path="images/icons/vertical-dots.svg" /> рядом с секретом.
  2. В контекстном меню выберите **Edit**.
  3. Измените текст в поле **Key** или **Value** и выберите **Update Secret**, чтобы сохранить изменения, либо **Cancel**, чтобы отменить их.

  Также можно изменить весь список секретов App, выбрав **Edit as JSON** или **Edit as .env** в нижней части вкладки.
</Accordion>

<Accordion title="Просмотр секрета App">
  Чтобы просмотреть секрет, выберите иконку глаза <img class="icon-svg" src="/assets/mirror/eye-8a6472b8a950.svg" alt="иконка глаза" width="16" height="16" data-path="images/icons/eye.svg" /> рядом с ним.

  Чтобы скрыть секрет, выберите иконку перечёркнутого глаза <img class="icon-svg" src="/assets/mirror/eye-slash-6b4ded538179.svg" alt="иконка глаза с перечёркиванием" width="16" height="16" data-path="images/icons/eye-slash.svg" />.
</Accordion>

<Accordion title="Удаление секрета App">
  Чтобы удалить секрет, выберите меню с вертикальными точками <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="иконка с тремя вертикальными точками" height="16" width="16" data-path="images/icons/vertical-dots.svg" /> рядом с секретом, а затем выберите **Delete**.
</Accordion>

<div id="section-4">
  ### Управление секретами аккаунта
</div>

На вкладке **Account Secrets** панели **Secrets** можно управлять секретами на уровне аккаунта.
На этой вкладке отображаются только секреты, связанные с вашим аккаунтом Replit.

<Accordion title="Добавление секрета аккаунта">
  Чтобы добавить секрет на уровне аккаунта:

  1. Перейдите на вкладку **Account Secrets**.
  2. Выберите иконку <img class="icon-svg" src="/assets/mirror/settings-icon-c2664c3691bf.svg" alt="иконка шестерёнки" width="16" height="16" data-path="images/icons/settings-icon.svg" />, чтобы открыть **Settings** и управлять секретами на уровне аккаунта.
  3. Выберите **New Secret**, чтобы добавить секрет.
  4. Введите **Key** — имя секрета — и **Value** — его значение.
  5. Выберите **Save**, чтобы сохранить секрет.
</Accordion>

<Accordion title="Редактирование секрета аккаунта">
  Чтобы отредактировать секрет:

  1. Выберите иконку карандаша <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="иконка карандаша" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> рядом с секретом.
  2. Измените текст в поле **Key** или **Value** и выберите **Save**, чтобы сохранить изменения, либо **Cancel**, чтобы отменить их.
</Accordion>

<Accordion title="Просмотр секрета аккаунта">
  Чтобы просмотреть секрет, выберите иконку глаза <img class="icon-svg" src="/assets/mirror/eye-8a6472b8a950.svg" alt="иконка глаза" width="16" height="16" data-path="images/icons/eye.svg" /> рядом с ним.

  Чтобы скрыть секрет, выберите иконку глаза с перечёркиванием <img class="icon-svg" src="/assets/mirror/eye-slash-6b4ded538179.svg" alt="иконка глаза с перечёркиванием" width="16" height="16" data-path="images/icons/eye-slash.svg" />.
</Accordion>

<Accordion title="Подключение секрета аккаунта">
  Чтобы использовать секрет на уровне аккаунта в Replit App, его необходимо подключить к приложению.
  Чтобы подключить секрет на уровне аккаунта:

  1. Перейдите на вкладку **App Secrets**.
  2. Установите флажок слева от секрета.
  3. Выберите **Link to this App**.

  Чтобы отключить секрет от приложения:

  1. Перейдите на вкладку **App Secrets**.
  2. Выберите меню с вертикальными точками <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" width="16" height="16" alt="иконка с тремя вертикальными точками" data-path="images/icons/vertical-dots.svg" /> рядом с секретом.
  3. Выберите **Unlink**.
</Accordion>

<Accordion title="Удаление секрета аккаунта">
  1. Выберите иконку карандаша <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="иконка карандаша" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> рядом с секретом.
  2. Выберите **Delete**.
</Accordion>

<div id="section-6">
  ### Управление видимостью секретов
</div>

Видимость секретов зависит от прав доступа к Replit App и от того, являетесь ли вы автором приложения.

Вы можете поделиться Replit App одним из следующих способов:

* **Multiplayer**: пригласить пользователей Replit для совместной работы в реальном времени
* **Cover page**: показать предварительный просмотр Replit App и возможность создать ремикс
* **Remix**: сделать личное или организационное Replit App общедоступным, чтобы другие могли создать собственную версию

В следующей таблице показана видимость имён и значений секретов в различных сценариях:

| Способ доступа     | Для кого                                                                           | Имя видно | Значение видно |
| ------------------ | ---------------------------------------------------------------------------------- | --------- | -------------- |
| Multiplayer        | Соавтор в Multiplayer                                                              | ✓         | ✓              |
| Multiplayer        | Участник Organization с ролью Owner                                                | ✓         | ✓              |
| Multiplayer        | Участник Organization без роли Owner                                               | ✓         |                |
| Cover Page         | Все посетители                                                                     |           |                |
| Remix              | Владелец или соавтор, создающий ремикс своего Replit App                           | ✓         | ✓              |
| Remix              | Пользователь, не являющийся владельцем или соавтором и создающий ремикс Replit App | ✓         |                |
| Remix              | Все пользователи, создающие ремикс с cover page                                    | ✓         |                |
| Organization Remix | Участник Organization с ролью Owner                                                | ✓         | ✓              |
| Organization Remix | Участник Organization без роли Owner                                               | ✓         |                |

<Warning>
  Участники Organization без роли Owner не могут просматривать значения секретов в Replit App, но могут получить к ним доступ, выведя переменные окружения.
</Warning>

<div id="section-7">
  ## Секреты базы данных
</div>

При добавлении базы данных Replit Project Editor автоматически создаёт следующий секрет:

| Секрет         | Описание                             |
| -------------- | ------------------------------------ |
| `DATABASE_URL` | Строка подключения к базе данных SQL |

<Info>
  Устаревшие базы данных Neon для разработки также могут включать `PGHOST`, `PGUSER`, `PGPASSWORD`, `PGDATABASE`, `PGPORT`. В современных базах данных Replit для разработки вместо них используется `DATABASE_URL`.
</Info>

Чтобы просмотреть все переменные окружения Replit App, выполните `printenv` в инструменте Shell Project Editor или выведите их в коде.

<div id="section-8">
  ## Предопределённые переменные окружения
</div>

Replit автоматически задаёт следующие переменные окружения, доступные приложению:

| Переменная окружения | Описание                                                                                          |
| -------------------- | ------------------------------------------------------------------------------------------------- |
| `REPLIT_DOMAINS`     | Список всех доменов, связанных с Replit App, разделённых запятыми                                 |
| `REPLIT_USER`        | Имя пользователя текущего редактора (в сеансах Multiplayer может отличаться)                      |
| `REPLIT_DEPLOYMENT`  | Устанавливается в значение `1`, если код выполняется в опубликованном приложении, иначе не задана |
| `REPLIT_DEV_DOMAIN`  | URL для разработки в домене `replit.dev`, отличающийся от URL деплоя                              |

Они не отображаются в инструменте секретов, но доступны в коде через объект `os.environ` или в Shell с помощью команды `printenv`.
