Коннекторы для хранилищ данных позволяют Replit Agent безопасно обращаться с запросами к хранилищам данных вашей организации. Разработчики формулируют задачи на естественном языке и получают дашборды, инструменты отчётности и приложения для работы с данными — знание SQL не требуется. Администраторы сохраняют централизованный контроль благодаря ролевой модели доступа.

<div id="supported-warehouses">
  ## Поддерживаемые хранилища
</div>

Коннекторы к хранилищам данных доступны в планах **Enterprise**.

| Хранилище        | Руководство по настройке                                                                                                                  |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| BigQuery         | Уже доступно — руководство по настройке готовится                                                                                         |
| Databricks       | [Подключение Databricks](/ru/connectors/warehouses/databricks)                                                                               |
| Microsoft Fabric | [Создание приложений для работы с данными на Microsoft Fabric](/ru/connectors/warehouses/microsoft-fabric) (закрытая предварительная версия) |
| Snowflake        | [Подключение Snowflake](/ru/connectors/warehouses/snowflake)                                                                                 |

У каждого хранилища свой порядок настройки, поскольку интеграция OAuth, модель идентификации и формат учётных данных различаются. Выберите используемое вами хранилище и следуйте соответствующему руководству.

<div id="analytics-and-data-platforms">
  ## Аналитика и платформы данных
</div>

Аналитические коннекторы доступны в планах Core и Pro, а также в Enterprise. Подключите свои аналитические инструменты, чтобы Agent мог читать данные о вашем продукте и работать с ними:

* **Segment** — данные о клиентах, потоки событий и сегменты аудитории из вашей CDP
* **Amplitude** — продуктовая аналитика, данные о поведении пользователей и метрики вовлечённости
* **Hex** — совместные блокноты с данными и результаты запросов

Управляйте ими так же, как и другими коннекторами Replit. См. [Управление коннекторами](/ru/replitai/managing-connectors).

<div id="how-warehouse-connectors-work">
  ## Как работают коннектор&#39;ы к хранилищам данных
</div>

Настройка выполняется один раз и затрагивает три роли:

1. **Администратор хранилища** — создаёт OAuth-интеграцию или служебную учётную запись в хранилище
2. **Администратор организации в Replit** — добавляет учётные данные в Replit и настраивает доступ
3. **Разработчик** — входит в систему и начинает создавать приложения с помощью Agent

После настройки разработчикам достаточно попросить Agent обратиться к хранилищу — Agent сам напишет и выполнит SQL-запросы к нему.

<div id="building-with-warehouse-data">
  ### Разработка на данных хранилища
</div>

После подключения вы можете попросить Agent создать приложения, использующие ваши данные. Agent умеет:

* Создавать внутренние инструменты, которые получают и отображают актуальные данные
* Создавать дашборды с графиками и визуализациями на основе данных вашего хранилища
* Генерировать SQL-запросы для серверной части вашего приложения
* Объяснять схему и структуру таблиц, чтобы вы лучше понимали, что именно создавать

<Note>
  Хотя Agent может отвечать на отдельные вопросы о ваших данных, основное назначение коннекторов к хранилищам — дать Agent возможность создавать полноценные приложения на данных вашей организации. Запросы к хранилищу выполняются напрямую в вашем экземпляре, поэтому убедитесь, что области доступа OAuth и права пользователя базы данных разрешают необходимые операции чтения и записи.
</Note>
