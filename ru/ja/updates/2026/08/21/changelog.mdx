<div id="free-mode">
  ### Работа в Free Mode
</div>

С Free Mode можно общаться в чате, прорабатывать идеи, создавать и разрабатывать проекты, не расходуя кредиты Power Mode или Max Mode. Free Mode использует Auto для выбора модели, а лимиты зависят от вашего плана. Оставшийся лимит и время его сброса можно посмотреть в **Settings** &gt; **Usage**.

<Frame caption="Выберите «Free» на панели режимов Agent.">
  <img src="/assets/mirror/free-mode-agent-modes-selector-sanitized-b4b896fb13ab.png" width="1784" height="882" data-path="images/chat/free-mode-agent-modes-selector-sanitized.png" />
</Frame>

Узнайте, как максимально эффективно использовать [Free Mode](/ru/ja/chat/free-mode).

<div id="conversations">
  ### Начните с Conversation
</div>

Начните с приватного Conversation: задавайте вопросы, ищите информацию, добавляйте контекст, запускайте Routine и описывайте желаемый результат. Когда работа станет более серьёзной, попросите Replit преобразовать Conversation в Project. Контекст и файлы сохранятся.

<div id="routines">
  ### Автоматизируйте повторяющиеся задачи с помощью Routines
</div>

Настройте в Replit расписание для повторяющихся задач в Conversation. Результат каждого запуска возвращается в ту же Conversation, где его можно проверить и продолжить работу. Routines запускаются в Power Mode или Max Mode, и для каждого запуска требуется бюджет.

<div id="agent-2">
  ### Управление Agent во время работы
</div>

Отправив дополнительное сообщение, пока Agent работает, вы можете добавить новый контекст к текущему запросу. Steer — режим по умолчанию для Conversations и Projects; в **Settings** &gt; **Personalization** можно выбрать Queue для каждого из них. Чтобы использовать противоположный режим только для одного сообщения, нажмите Cmd+Enter на Mac или Ctrl+Enter в Windows и Linux.

<Frame caption="Для Conversations и Projects можно отдельно выбрать Steer или Queue.">
  <img src="/assets/mirror/agent-follow-ups-settings-98a4c5ca399e.png" alt="Настройки Agent с режимами отправки для Conversation и Project и параметрами Steer и Queue" width="3048" height="1372" data-path="images/replitai/agent-follow-ups-settings.png" />
</Frame>

Подробнее о [режимах Steer и Queue для сообщений](/ru/ja/features/agent/steer-and-queue-messages).

<div id="section-4">
  ### Запуск тестирования на проникновение методом «чёрного ящика»
</div>

Запустите сканирование безопасности Level 3, объединяющее три проверки: бесплатную проверку зависимостей и пакетов, статический анализ исходного кода с помощью Agent и внешнее тестирование запущенного Preview методом «чёрного ящика». Replit выполняет проверку исходного кода и внешнее тестирование параллельно.
