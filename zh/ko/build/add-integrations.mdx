完成此任务后，所有 Velocity 预订都会显示在客户的 Google Calendar 中，并已填入取车和还车时间。

集成功能可让 Velocity 与其他工具互通。您可以将每笔预订发送到客户的日历，在高价值租赁被预订时向负责人发送电子邮件，或将天气信息加载到行程规划页面。目前只选择一个集成 — Google Calendar 可为所有客户提供清晰且可验证的结果 (&quot;我的日历里有这笔租赁&quot;) ，您也可以在测试期间通过自己的日历进行确认。

<div id="agent">
  ## 请求 Agent 添加日历集成
</div>

Replit 提供内置的 **Google Workspace 连接器**，支持 Google Calendar。Agent 只需点击一次即可登录 Google，无需创建 API 项目、复制 OAuth 凭据或粘贴 Secrets。

<AiPrompt>
  当 Velocity 客户确认预订时，将租赁信息添加到 Google Calendar。<br />
  请使用 Replit 的 Google Workspace 连接器连接 Google Calendar，不要请求 OAuth 凭据。<br />
  事件标题应为“Velocity rental: [车辆品牌和型号]”。<br />
  事件应从取车时间持续至还车时间，并在说明中包含取车地址和预订参考编号。<br />
  如果客户更改日期或取消预订，日历事件应自动更新。<br />
  即使添加日历失败，也请在 Velocity 中添加明确的提示，确保预订仍会得到确认。
</AiPrompt>

Agent 会预配 Google Workspace 连接器，在工作区中打开一个 Connect 对话框。你使用拥有该日历的 Google 账号登录后，Agent 会将 Velocity 连接起来，以便在每次确认预订时添加事件。

<Note>
  连接器是 Core、Pro 或 Enterprise 的功能。免费套餐请让 Agent 改用 Google OAuth 项目——你需要创建 Google Cloud 项目、启用 Calendar API，并将生成的凭据粘贴到应用的 Secrets 面板中。
</Note>

<div id="section">
  ## 端到端测试
</div>

1. 在新标签页中打开你的 Google Calendar。
2. 在 Preview 中登录 Velocity。
3. 预订下周六至周日的车辆，并确认预订。
4. 切换到 Google Calendar 标签页。周六至周日应出现一个新的“Velocity rental: [车辆]”事件，其说明中包含取车地址。
5. 在 Velocity 中将预订改为周日至周一。日历事件应自动更新到相应日期。
6. 取消预订。日历事件应消失。
7. 进行第二次测试：打开工作区中的 **集成**，断开 Google Workspace 的连接，然后尝试预订。Velocity 仍应确认预订，并显示清晰的消息，例如“无法添加到日历 — 预订已确认。”测试通过后，重新连接连接器。

如果预订已确认但事件未出现，请将确切的错误信息提供给 Agent。

<AiPrompt>
  集成因以下错误而失败：[粘贴 Velocity 或 Replit 日志中的错误]。<br />
  告诉我最可能的原因，并进行最小范围的修复。<br />
  请确认即使无法访问 Google Calendar，Velocity 中的车辆预订仍能正常进行。
</AiPrompt>

<div id="url">
  ## 部署并通过公开 URL 测试
</div>

当日历集成在 Preview 中正常运行后：

1. 在 Agent 聊天中重新部署 Velocity。
2. 打开公开 URL，以真实客户的身份预订车辆。
3. 确认用于预订的账户日历中是否出现相应事件。
4. 在公开 URL 上更新和取消预订，确认日历事件是否同步更新。

现在，客户离开 Velocity 时，租赁安排已添加到他们的日历中。预订不再只是一封确认邮件，而会成为一个不易忘记的日程。

<div id="section-3">
  ## 还需要帮助吗？
</div>

* **Google Calendar 中未显示事件：**打开工作区的 **集成**，确认 Google Workspace 连接器显示为 Connected，且已授予 Calendar 权限范围。
* **连接器显示为 Connected，但事件仍未送达：**请 Agent 将发送给日历的数据载荷记录到日志中，并修正字段映射。
* **日期或地址字段出现在事件的错误位置：**请 Agent 将发送的事件结构记录到日志中，并修正字段映射。
* **想使用其他集成：**将“Google Calendar”替换为其他连接器——用于团队 Slack 通知的 Slack、将客户记录为 CRM 联系人的 HubSpot，或在共享数据库中跟踪预约的 Airtable。Agent 会通过集成面板以相同方式处理它们。
