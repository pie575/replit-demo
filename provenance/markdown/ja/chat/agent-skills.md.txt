# Skillsを使う

> 再利用可能な指示と補足資料を使って、Replitが繰り返し行う作業への取り組み方をカスタマイズします。

Skillとは、再利用可能な指示と補足ファイルをまとめたフォルダです。繰り返し行うタスクや慣習、ワークフローへのReplitの取り組み方をカスタマイズするために使用します。

プロンプトボックスで**プラス**メニューを選択し、**スキルを使う**を選びます。タスクに合ったSkillを選び、必要な結果をReplitに伝えます。

## 適切な連携方法を選ぶ

* 再利用可能な指示、例、補足資料には**Skill**を使います。
* サポートされているサービスとその認可された情報やアクションには[インテグレーション](/ja/chat/integrate-your-tools)を使います。
* 対応するMCPサーバーやクライアントを通じて公開されるツールには[MCP](/ja/chat/connect-through-mcp)を使います。
