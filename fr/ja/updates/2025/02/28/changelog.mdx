  ## Mises à jour de la plateforme
</div>

<div id="agent-v2">
  ### Agent v2
</div>

<img src="/assets/mirror/agent-web-01b1f9026de7.webp" alt="Agent v2" width="800" height="450" data-path="images/changelog/2025-02-28/agent-web.webp" />

La nouvelle expérience Agent est désormais disponible pour tous les créateurs. Ce nouvel Agent est plus rapide, plus précis et plus performant que les versions précédentes.

Il est désormais propulsé par Claude 3.7 Sonnet, le modèle d’IA le plus avancé d’Anthropic à ce jour.

Vous pouvez l’essayer en rejoignant le programme Explorer. Consultez les instructions [ici](https://youtu.be/pE_XT2TaXCA).

<div id="section-3">
  ### Améliorations des déploiements
</div>

Les créateurs qui choisissent un déploiement statique pour une application dynamique reçoivent désormais des suggestions de l’IA, et le comportement d’Agent lors du traitement des demandes de déploiement a été amélioré.

<img src="/assets/mirror/deployments-debugger-will-now---non-static-app-220824-748b5209b50c.png" alt="Améliorations du débogueur de déploiement" width="1604" height="1244" data-path="images/changelog/2025-02-28/deployments-debugger-will-now---non-static-app-220824.png" />

<div id="claude-37-sonnet">
  ### Lancement de Claude 3.7 Sonnet
</div>

Le mode Assistant avancé a été mis à niveau vers Claude 3.7 Sonnet pour tous les créateurs disposant d&#39;une offre payante. Il offre ainsi une meilleure précision et des capacités accrues pour les requêtes complexes.

<img src="/assets/mirror/50526c4ea4d114b4cd8268425398dd4ed3c2d736_bc521d9780846c35d990a72459794dd81370515f_twitter-fb2c893cd78a.jpeg" alt="Interface de Claude 3.7" width="1200" height="674" data-path="images/changelog/2025-02-28/50526c4ea4d114b4cd8268425398dd4ed3c2d736_bc521d9780846c35d990a72459794dd81370515f_twitter.jpeg" />

<div id="section-4">
  ### Amélioration des performances de la base de données
</div>

Les opérations sur la base de données sont désormais plus rapides que jamais. Les opérations les plus coûteuses sont passées de 200 ms à moins de 1 ms.

<div id="section-5">
  ### Amélioration de la documentation
</div>

<img src="/assets/mirror/cleanshot-2025-02-27-at-1042282xpng-220848-e5317a7cfb93.png" alt="Refonte de la documentation" width="3680" height="2382" data-path="images/changelog/2025-02-28/cleanshot-2025-02-27-at-1042282xpng-220848.png" />

La documentation a été repensée pour être plus claire et plus facile à utiliser, et est désormais entièrement adaptée aux LLM.

Un bouton « Copier la page » a été ajouté pour vous permettre de copier l’intégralité d’une page au format Markdown. Vous pouvez également indexer la documentation à l’aide de `llms.txt` et `llms-full.txt` pour l’utiliser avec votre propre LLM.
