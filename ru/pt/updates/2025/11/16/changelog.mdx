<div id="integrao-com-o-azure-marketplace">
  ### Интеграция с Azure Marketplace
</div>

Replit теперь доступен в Azure Marketplace! У многих организаций уже есть выделенные бюджеты на Azure, и эта интеграция позволяет направлять эти средства напрямую на подписки и оплату использования Replit.

Вслед за сентябрьской интеграцией с GCP Marketplace это нововведение ещё больше упрощает переход на Replit для команд уровня Enterprise: они могут использовать привычные процессы закупок и уже выделенные бюджеты на облачные сервисы.

[Посмотреть в Azure Marketplace](https://marketplace.microsoft.com/en-us/product/saas/replit.replit?tab=Overview)

<div id="suporte-ao-gitlab-e-bitbucket">
  ### Поддержка GitLab и Bitbucket
</div>

Replit теперь поддерживает репозитории GitLab и Bitbucket помимо GitHub — у вас больше свободы в выборе места хранения кода. Проекты из GitLab и Bitbucket можно импортировать прямо в Replit, а работа с git улучшена на всех поддерживаемых платформах.

Улучшенная интеграция с git включает:

* **Поддержку нескольких платформ**: импортируйте репозитории GitHub, GitLab и Bitbucket и работайте с ними
* **Улучшенные операции git**: более быстрые и надёжные команды git во всём workspace
* **Более удобное управление репозиториями**: упрощённые сценарии клонирования, отправки и получения изменений у любого поддерживаемого git-провайдера

Подробнее об [импорте проектов](/ru/pt/core-concepts/project-editor/app-setup/import) и [использовании git в Replit](/ru/pt/core-concepts/project-editor/version-control/git-interface).
