<div id="client">
  ## Client
</div>

`Client` 클래스는 Replit App Storage와의 상호작용을 관리합니다. 이 클래스는 버킷에 있는 파일을 다루는 작업 메서드를 제공합니다.

라이브러리에서 이 클래스를 import하려면 JavaScript 코드에 다음 줄을 추가하세요:

```javascript theme={null}
import { Client } from "@replit/object-storage";
```

다음 코드를 사용해 Replit Object Storage와 상호작용하는 `Client` 인스턴스를 생성하세요:

```javascript theme={null}
const client = new Client();
```

<div id="constructors">
  ## Constructors
</div>

**constructor**

* **new Client**(`options?`): `Client`

Replit App Storage와 상호작용할 새 Client 인스턴스를 생성합니다.

**매개변수**

| 이름         | 타입              | 설명                       |
| :--------- | :-------------- | :----------------------- |
| `options?` | `ClientOptions` | 클라이언트 설정에 사용하는 구성 옵션입니다. |

**반환값**

`Client`

  ## 메서드

<div id="copy">
  ### copy
</div>

* **copy**(`objectName`, `destObjectName`): `Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

동일한 버킷 내에서 객체를 복사합니다.
이 메서드는 대상 경로에 기존 객체가 있으면 덮어씁니다.

**매개변수**

| 이름               | 타입       | 설명                    |
| :--------------- | :------- | :-------------------- |
| `objectName`     | `string` | 복사할 객체의 전체 경로입니다.     |
| `destObjectName` | `string` | 객체를 복사할 대상의 전체 경로입니다. |

**반환값**

`Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

***

* **delete**(`objectName`, `options?`): `Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

**매개변수**

| 이름           | 타입              | 설명                           |
| :----------- | :-------------- | :--------------------------- |

**반환값**

| 이름           | 타입                | 설명                  |

**반환값**

다운로드 중 발생하는 오류는 해당 stream에서 emit됩니다.

**매개변수**

| 이름           | 타입                | 설명                                 |
| :----------- | :---------------- | :--------------------------------- |
| `objectName` | `string`          | 다운로드할 객체의 전체 경로입니다.            |
| `options?`   | `DownloadOptions` | 다운로드 작업에 대한 구성입니다. |

**반환값**

`Readable`

<div id="uploadfrombytes">
  ### uploadFromBytes

* **uploadFromBytes**(`objectName`, `contents`, `options?`): `Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

| 이름           | 타입              | 설명                    |

**반환값**

<div id="uploadfromfilename">

</div>

로컬 파일 시스템의 파일을 버킷에 업로드합니다.
이 메서드는 이름이 같은 기존 객체를 덮어씁니다.

**매개변수**

| 이름            | 타입              | 설명                         |
| :------------ | :-------------- | :------------------------- |
| `objectName`  | `string`        | 객체의 전체 대상 경로입니다.           |
| `srcFilename` | `string`        | 업로드할 로컬 파일 시스템상의 파일 경로입니다. |
| `options?`    | `UploadOptions` | 업로드 작업에 대한 구성입니다.       |

**반환값**

`Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

<div id="uploadfromstream">
  ### uploadFromStream
</div>

* **uploadFromStream**(`objectName`, `stream`, `options?`): `Promise`&lt;`void`&gt;

제공된 stream에서 내용을 읽어 객체를 업로드합니다.
업로드 중 발생하는 오류는 해당 stream이 emit합니다. 이 메서드는 이름이 같은 기존 객체를 덮어씁니다.

**매개변수**

| 이름           | 타입              | 설명                            |
| :----------- | :-------------- | :---------------------------- |
| `objectName` | `string`        | 객체의 전체 대상 경로입니다.              |
| `stream`     | `Readable`      | 객체의 내용을 읽어올 읽기 가능한 stream입니다. |
| `options?`   | `UploadOptions` | 업로드 작업에 대한 구성입니다.          |

**반환값**

`Promise`&lt;`void`&gt;
