<div id="agent">
  ### Создание full-stack мобильных приложений с Agent
</div>

<Frame>
  <img src="/assets/mirror/cleanshot-2025-12-05-at-12-27-22-2x_273f89390642-dc03158b7d7f.png" width="1082" height="504" data-path="images/changelog/2025-12-05/cleanshot-2025-12-05-at-12-27-22-2x_273f89390642.png" />

Теперь Agent может создавать [мобильные приложения](/ru/ko/features/artifact-types/building-mobile-apps) с полноценным серверным бэкендом. Это открывает доступ к [интеграциям с ИИ](/ru/replitai/integrations), [базам данных](/ru/ko/features/data-and-storage/sql-database), [объектному хранилищу](/ru/ko/features/data-and-storage/object-storage), коннекторам и всему остальному, что нужно для мобильной разработки продакшен-уровня.

<div id="section-3">
  ### База данных общедоступна
</div>

Новая [база данных](/ru/ko/features/data-and-storage/sql-database) теперь используется по умолчанию во всех новых приложениях Replit. Это обновление повышает надёжность и даёт больше контроля над инфраструктурой, помогая ускорить работу проектов и упростить управление данными.

<div id="fast-mode">
  ### Fast Mode стал более автономным
</div>

<Frame>
  <img src="/assets/mirror/image_4f661377d428-8454460e1cca.png" width="720" height="212" data-path="images/changelog/2025-12-05/image_4f661377d428.png" />
</Frame>

[Режим Lite](/ru/core-concepts/agent/agent-modes) (ранее Fast Mode) теперь самостоятельно справляется с бо́льшим числом задач, а для крупных изменений рекомендует переключиться на Agent. Создавайте быстрее благодаря коротким итерациям и плавной передаче задач.

<div id="section-4">
  ### Ускоренное подключение сторонних сервисов
</div>

Подключайте сторонние сервисы быстрее благодаря улучшенной поддержке коннекторов. Достаточно указать конфигурацию — и большинство сервисов с доступом по API-ключу можно добавить без сложной настройки. Для более надёжных [интеграций](/ru/replitai/integrations) добавлены конфигурации с несколькими ключами и расширенные проверки состояния.
