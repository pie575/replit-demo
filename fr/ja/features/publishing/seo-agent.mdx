Le SEO Agent réalise un audit SEO technique sur l&#39;ensemble du projet et met en évidence les problèmes qui limitent la capacité des moteurs de recherche et des robots d&#39;exploration d&#39;IA à trouver et comprendre votre application. Chaque constat se transforme en un correctif applicable en un clic, que vous pouvez examiner et appliquer avec l&#39;Agent.

Il se trouve dans le panneau **Growth** du Project Editor et fonctionne avec les applications déjà publiées. Pour la plupart des créateurs, le flux de travail consiste à publier l&#39;application, ouvrir le SEO Agent, lancer une analyse, examiner les constats, puis appliquer les correctifs.

<div id="seo-agent">
  ## Fonctionnalités de SEO Agent
</div>

SEO Agent se concentre sur le **SEO technique**, c&#39;est-à-dire les aspects structurels et lisibles par les machines de votre application, qui déterminent la facilité avec laquelle les moteurs de recherche et les robots d&#39;exploration d&#39;IA peuvent la découvrir, l&#39;indexer et la comprendre.

Il examine votre projet et propose des correctifs pour des problèmes tels que :

* **Explorabilité et indexation** : `robots.txt`, `sitemap.xml`, ainsi que les liens explorables et la structure des pages.
* **Métadonnées de page** : chaque page dispose d&#39;une balise `<title>` et d&#39;une méta-description uniques et descriptives.
* **Données structurées** : balisage JSON-LD qui aide les moteurs de recherche à afficher des résultats enrichis.
* **Open Graph et balises sociales** : métadonnées qui contrôlent l&#39;aperçu de vos liens lors du partage.
* **Balisage sémantique** : hiérarchie correcte des titres, éléments de repère et texte `alt` descriptif pour les images.

<Note>
  SEO Agent vérifie que l&#39;application que vous avez créée est techniquement saine du point de vue du référencement, mais
  il ne rédige pas de contenu et ne développe pas votre autorité thématique.
</Note>

<div id="section">
  ## Avant de commencer
</div>

Pour utiliser SEO Agent, vous devez disposer des éléments suivants :

* **Une application publiée.** SEO Agent audite les déploiements web accessibles en ligne : si vous n&#39;avez pas encore publié votre application, commencez par le faire. Pour connaître les types de déploiement compatibles avec le SEO, consultez [Score SEO](/fr/ja/features/publishing/seo-rating).
* **Un forfait payant.** SEO Agent est réservé aux créateurs disposant d&#39;un forfait payant. Avec un forfait gratuit, le panneau Growth affiche les options de mise à niveau.

Il existe deux façons d&#39;accéder à SEO Agent : ouvrir directement le panneau **Growth** dans le Project Editor, ou sélectionner **Optimize SEO with Agent** à côté du score SEO dans l&#39;outil **Publishing** : le panneau Growth s&#39;ouvre alors, prêt pour l&#39;analyse.

<Tip>
  Pour contrôler l&#39;aperçu de votre application lorsqu&#39;elle est partagée sur les réseaux sociaux,
  connectez un [domaine personnalisé](/fr/ja/build/add-custom-domain) et republiez-la. Les aperçus sur les réseaux sociaux et
  les aperçus de liens utilisent l&#39;URL de production publiée de votre application : un domaine personnalisé publié
  garantit donc des aperçus exacts.
</Tip>

<div id="seo-agentseo">
  ## SEO Agent et score SEO
</div>

Le **score SEO** affiché à côté de SEO Agent est calculé à partir d&#39;un [audit Lighthouse](/fr/ja/features/publishing/seo-rating) automatique exécuté à chaque publication : il évalue votre app comme Healthy, Needs Work ou Weak. Ce score reflète l&#39;&#95;état actuel de votre app&#95;.
SEO Agent vous aide à &#95;l&#39;améliorer&#95; en détectant les problèmes et en appliquant les correctifs. Une fois les corrections effectuées, republiez votre app pour mettre à jour le score.

Vous pouvez aussi contourner entièrement l&#39;interface d&#39;analyse et faire directement la demande à Agent.
