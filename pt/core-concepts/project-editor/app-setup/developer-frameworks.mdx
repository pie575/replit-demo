## O que é um framework para desenvolvedores?

Frameworks para desenvolvedores são Replit Apps que a plataforma e a comunidade publicaram para que outros possam usar como ponto de partida. Os frameworks oficiais, criados pelo Replit, têm uma caixa de seleção ao lado do nome do framework:

</Frame>

O framework [HTML, CSS, JS](https://replit.com/@replit/HTML-CSS-JS?v=1#index.html) é muito popular e pode ser usado como ponto de partida para criar um projeto JavaScript puro. Você pode fazer um fork do framework para utilizá-lo.

## Templates personalizados para empresas

Organizações Enterprise podem criar [templates personalizados](/pt/teams/custom-templates) que aparecem como opções selecionáveis na caixa de entrada do Agent para todos os membros da organização. Os templates personalizados vão além dos frameworks para desenvolvedores ao incluir instruções de Agent específicas da empresa, habilidades e contexto de projeto pré-configurado. Consulte o [guia de templates personalizados](/pt/teams/custom-templates) para mais detalhes.
