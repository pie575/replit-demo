export const McpLinkGenerator = () => {
  const getLink = () => {
    if (typeof document === 'undefined') return 'https://replit.com/integrations?mcp=';
    const displayName = document.getElementById('mcp-display-name')?.value || 'Mon serveur MCP';
    const baseUrl = document.getElementById('mcp-base-url')?.value || 'https://example.com/mcp';
    const payload = {
      displayName,
      baseUrl
    };
    const jsonString = JSON.stringify(payload);
    const encoded = btoa(unescape(encodeURIComponent(jsonString)));
    return `https://replit.com/integrations?mcp=${encoded}`;
  };
  const updateOutputs = () => {
    if (typeof document === 'undefined') return;
    const link = getLink();
    const badgeUrl = 'https://replit.com/badge?caption=Add%20to%20Replit';

    const linkEl = document.getElementById('mcp-link-output');
    const badgeMarkdownEl = document.getElementById('mcp-badge-markdown');
    if (linkEl) linkEl.textContent = link;
    if (badgeMarkdownEl) badgeMarkdownEl.textContent = badgeMarkdown;
  };
  const handleBadgeClick = e => {
    e.preventDefault();
    window.open(getLink(), '_blank');
  };

        <input type="text" id="mcp-display-name" placeholder="Mon serveur MCP" onInput={updateOutputs} className="w-full px-3 py-2 border border-gray-300 dark:border-gray-700 rounded-md bg-white dark:bg-gray-900 text-gray-900 dark:text-gray-100" />

      </div>
      <div>
        <label className="block text-sm font-medium mb-1">Lien d’installation</label>
        <pre className="w-full p-3 bg-gray-100 dark:bg-gray-800 rounded-md text-sm break-all select-all cursor-text">
          <code id="mcp-link-output">https://replit.com/integrations?mcp=eyJkaXNwbGF5TmFtZSI6Ik15IE1DUCBTZXJ2ZXIiLCJiYXNlVXJsIjoiaHR0cHM6Ly9leGFtcGxlLmNvbS9tY3AifQ==</code>

Replit Agent peut se connecter à des centaines d&#39;outils externes et de sources de données via le [Model Context Protocol (MCP)](https://modelcontextprotocol.io), une norme ouverte d&#39;intégration d&#39;outils d&#39;IA. Connectez-vous à des serveurs préenregistrés ou ajoutez des serveurs MCP personnalisés de confiance.

<div id="mcp">
  ## Connecter un serveur MCP préenregistré
</div>

Replit propose une liste sélectionnée de serveurs MCP pour les services les plus courants, comme Stripe, Linear, Notion ou Sentry. La connexion se fait en un seul clic, à partir de votre identification.

<Frame>
  <img src="/assets/mirror/mcp-servers-pane-8e1f431ca33c.png" alt="Panneau de configuration des serveurs MCP pour Replit Agent, listant des serveurs préenregistrés tels que Stripe, Linear, Notion, Sentry, Atlassian, Miro, PostHog, Amplitude, Mixpanel, Granola et Razorpay, avec un bouton de connexion pour chacun" width="3452" height="1988" data-path="images/replitai/mcp-servers-pane.png" />
</Frame>

<Steps>
  <Step title="Ouvrir le panneau Intégrations">
    Rendez-vous sur [replit.com/integrations](https://replit.com/integrations) et faites défiler jusqu&#39;à **MCP Servers for Replit Agent**.
  </Step>

  <Step title="Sélectionner un serveur">
    Repérez le service que vous souhaitez connecter — Stripe, Linear, Notion, Sentry, Atlassian, Miro, PostHog, Amplitude, Mixpanel, Granola, Razorpay, etc.
  </Step>

  <Step title="Se connecter">
    Cliquez sur **Sign in** à côté du serveur. Vous êtes alors guidé dans le flux OAuth du service concerné. Une fois la connexion établie, l&#39;état du serveur est mis à jour et Agent peut utiliser ses outils.
  </Step>
</Steps>

Consultez la [référence des serveurs MCP](/fr/ko/features/mcp/overview) pour le catalogue complet.

<div id="mcp-2">
  ## Ajouter un serveur MCP personnalisé
</div>

Si le serveur souhaité ne figure pas dans le catalogue préenregistré, ajoutez-le à partir de son URL.

<Frame>
  <img src="/assets/mirror/mcp-connect-dialog-5b8f9b0d828e.png" alt="Boîte de dialogue de connexion au serveur MCP avec le champ Nom d'affichage, le champ URL du serveur MCP et une section de paramètres avancés dépliable" width="3452" height="1988" data-path="images/replitai/mcp-connect-dialog.png" />
</Frame>

<Steps>
  <Step title="Ouvrir la boîte de dialogue d'ajout de serveur">
    Dans le panneau de paramètres du serveur MCP, cliquez sur **+ Add MCP server**.
  </Step>

  <Step title="Définir le nom d'affichage">
    Saisissez un nom facilement reconnaissable — Agent l&#39;utilisera pour désigner le serveur dans les journaux de conversation.
  </Step>

  <Step title="Saisir l'URL du serveur">
    Collez le point de terminaison HTTPS du serveur MCP. Si le serveur exige une authentification, ouvrez **Advanced settings** et ajoutez des en-têtes personnalisés (par exemple `X-API-Key`).
  </Step>

  <Step title="Tester et enregistrer">
    Cliquez sur **Test &amp; save**. Replit tente d&#39;établir la connexion et vous guide dans le flux OAuth requis par le serveur. Une fois l&#39;enregistrement terminé, la connexion apparaît dans la liste des serveurs MCP, accompagnée de son statut.
  </Step>
</Steps>

<Warning>
  Ne vous connectez qu&#39;à des serveurs MCP de confiance. Un serveur connecté peut fournir des outils et des données à Agent — vérifiez la source avant d&#39;ajouter un point de terminaison que vous ne connaissez pas.
</Warning>

<div id="agent-mcp">
  ## Utiliser les outils MCP dans Agent
</div>

Une fois le serveur connecté, Agent récupère automatiquement la liste des outils et en rend les fonctionnalités disponibles dans tous vos projets. Pour utiliser un serveur, il suffit de le mentionner dans le chat :

> Use the Notion MCP server to find the most recent meeting notes.

<Frame>
  <img src="/assets/mirror/tool-call-7a53f51a11ae.png" alt="Agent appelant un outil d'un serveur MCP personnalisé depuis le chat" width="571" height="817" data-path="images/replitai/custom-mcp/tool-call.png" />
</Frame>

Agent sélectionne l&#39;outil du serveur le mieux adapté à votre demande. Si un outil nécessite une confirmation, une invite s&#39;affiche avant son exécution.

<div id="section">
  ## Partager un lien d&#39;installation
</div>

Grâce aux liens d&#39;installation, n&#39;importe qui peut ajouter un serveur MCP à Replit en un seul clic — pratique dans une documentation, un fichier README ou partout où vous souhaitez promouvoir votre intégration.

Utilisez le formulaire ci-dessous pour générer le lien d&#39;installation de votre serveur ainsi qu&#39;un badge cliquable :
