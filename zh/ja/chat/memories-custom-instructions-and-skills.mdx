记忆、自定义指令和技能都能帮助 Replit 在更充分的上下文中开展工作。请根据信息是长期有效的规则、可重复使用的流程，还是从过往工作中获得的有用上下文，选择合适的方式。

|           | 由谁管理            | Replit 何时使用 | 最适合的用途              |
| --------- | --------------- | ----------- | ------------------- |
| **自定义指令** | 你或你的团队          | 始终使用，跨会话生效  | 希望持续应用的稳定偏好或规则      |
| **技能**    | 你或你的团队          | 与特定任务相关时    | 可重复使用的流程、工作流和参考资料   |
| **记忆**    | Replit 在你的监督下创建 | 相关上下文有帮助时   | 无需反复说明从过往工作中获得的有用偏好 |

<div id="section">
  ## 选择合适的工具
</div>

* 对于整个工作区中始终必须遵守的规则，例如获准使用的库或数据处理要求，请使用**自定义指令**。这些内容由你编写，Replit 不会修改。
* 对于特定类型任务的可复用方法，例如发布准备或设计评审，请使用**技能**。稳定的程序性知识适合放在技能中。
* 当 Replit 能够保留过往工作中的有用上下文时，请使用**记忆**，这样就无需反复说明相关偏好。Replit 可以在工作过程中写入记忆，但这些只是上下文参考信息，并非可执行指令。

你的明确请求和自定义指令优先于记忆。你可以在**设置 → 自定义 → 记忆**中管理记忆。记忆不会保存个人或敏感信息，且默认不公开。是否与协作者共享由你决定，默认处于关闭状态。
