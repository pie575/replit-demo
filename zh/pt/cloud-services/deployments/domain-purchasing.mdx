使用自定义域名，将您的应用打造为专业的正式网站。

借助域名购买功能，您可以搜索、购买域名并将其连接到已部署的 Replit 应用，所有操作均可在平台内完成。只需几分钟，即可让已部署应用拥有专业的线上形象。

这意味着您可以购买一个域名，例如 `meu-app.com`，并让它自动指向您的应用。

<div id="recursos">
  ## 功能
</div>

域名购买简化了为应用配置专业网址的流程。无需管理多个服务，你可以直接在 Replit 中完成网站的所有配置。

<Frame>
  <img src="/assets/mirror/replit-domains-8453291b634b.png" alt="域名管理界面，显示已购买的域名及其连接状态" width="3176" height="1556" data-path="images/deployments/custom-domains/replit-domains.png" />
</Frame>

主要功能包括：

* **域名搜索与可用性查询**：查询 `.com`、`.ai` 等热门后缀的域名是否可用
* **一键购买**：使用账户默认付款方式，直接通过 Replit 购买域名
* **自动配置**：域名会立即指向你的 Replit 应用，无需手动配置 DNS
* **WHOIS 隐私保护**：你的个人信息将在公开域名记录中保持私密，每次购买域名时均默认包含此服务
* **自定义 DNS 记录**：添加自定义 A、TXT 和 MX 记录，以配置电子邮件提供商及其他服务
* **即时发布**：购买后，用户可立即通过你的自定义域名访问应用
* **自动续订**：域名会自动续订，确保你的应用持续部署，不会中断

<div id="uso">
  ## 使用
</div>

<div id="comprando-domnios">
  ### 购买域名
</div>

1. 发布您的 App，然后打开 <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="发布图标" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publishing** 标签页
2. 选择 **Domains** 标签页
3. 选择 **Buy a domain** 开始搜索
4. 在搜索栏中输入所需的域名
5. 查看不同后缀的可用选项
6. 选择心仪的域名并完成购买

购买域名后，系统会自动将其配置为指向您的 Replit App。您的 App 可立即通过自定义域名访问，无需额外配置。

域名购买费用将通过您的 Replit 账户收取，从账户余额中扣除，并计入您的用量。

<div id="gerenciando-domnios-comprados">
  ### 管理已购买的域名
</div>

您的域名可与已部署的 App 无缝集成：

* **自动续订**：域名会自动续订，确保已部署的 App 持续正常运行
* **集成计费**：域名费用会与其他服务一并显示在您的 Replit 账单中
* **支持转移**：您可根据需要在 Replit 账户之间转移域名，或将其转移至外部注册商

<div id="registros-dns-personalizados">
  ### 自定义 DNS 记录
</div>

对于通过 Replit 购买的域名，您可以添加自定义 DNS 记录来配置电子邮件提供商等其他服务。支持以下 DNS 记录类型：

* **A 记录**：将您的域名或子域名指向特定的 IP 地址
* **TXT 记录**：为电子邮件身份验证 (SPF、DKIM、DMARC) 等服务添加基于文本的验证记录
* **MX 记录**：MX (邮件交换) 记录会告知电子邮件服务器应将发往您域名的邮件投递到哪里。配置 MX 记录后，您可以使用自定义域名创建 `hello@seudominio.com` 等电子邮件地址。

要管理您购买的域名的 DNS 记录：

1. 前往 <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Publish 图标" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> Publishing 中的 **Domains** 标签页
2. 找到要配置的域名
3. 选择 <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="铅笔图标" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> **Edit** 图标
4. 选择 **Add DNS Record**
5. 按照服务提供商的要求，输入记录类型、名称、值和 TTL

<div id="tipos-de-deployment-suportados">
  ### 支持的部署类型
</div>

域名购买支持以下部署类型：

* **[自动扩缩容部署](/zh/pt/cloud-services/deployments/autoscale-deployments/)**
* **[预留 VM 部署](/zh/pt/cloud-services/deployments/reserved-vm-deployments/)**
* **[静态部署](/zh/pt/cloud-services/deployments/static-deployments/)**

目前，你可以为个人账户中已部署的 App 购买域名。Replit Teams 的域名购买功能即将推出。

<div id="perguntas-frequentes">
  ## 常见问题
</div>

<AccordionGroup>
  <Accordion title="费用是多少？">
    域名购买包含两项费用：

    * **注册费**：注册并持有域名一年的初始费用 (`.ai` 域名为两年)
    * **续费价格**：初始注册期结束后自动收取

    Replit 不会对域名购买收取额外费用。域名注册费不予退款。
  </Accordion>

  <Accordion title="如何续费我的域名？">
    Replit 会自动续费您的域名，以确保您的 App 保持可访问状态。如果您
    不想续费，请在 beta 期间联系 Replit 支持。
  </Accordion>

  <Accordion title="如果我想离开 Replit 怎么办？">
    您可以联系
    Replit 支持，将域名转移到其他注册商。根据 ICANN 规定，域名购买后需等待 60 天，
    才能转移至外部注册商。
  </Accordion>

  <Accordion title="我可以在 Replit 账户之间转移域名吗？">
    可以，请联系 Replit 支持，将域名转移到其他 Replit 账户。此
    过程无需等待 60 天。
  </Accordion>

  <Accordion title="我可以为我的组织购买域名吗？">
    Replit Pro 和 Enterprise 套餐的域名购买功能将在
    初始 beta 期结束后推出。
  </Accordion>

  <Accordion title="我可以为我的域名添加自定义 DNS 记录吗？">
    可以！您可以为通过 Replit 购买的域名添加自定义 DNS 记录。目前支持的记录类型包括：

    * **A 记录**：将域名或子域名指向特定 IP 地址
    * **TXT 记录**：添加基于文本的验证记录，用于电子邮件身份验证及其他服务
    * **MX 记录**：配置电子邮件服务器以处理您的域名电子邮件

    前往 Publishing 中的 Domains 标签页配置这些记录。有关如何为电子邮件配置 MX 记录的详细说明，请参阅上方的[自定义 DNS 记录](#custom-dns-records)部分。
  </Accordion>

  <Accordion title="支持哪些域名扩展名？">
    我们支持所有常见的顶级域名 (TLD)。但无法支持具有
    特殊地域限制或其他限制的 TLD。
  </Accordion>

  <Accordion title="什么是 WHOIS 隐私保护？">
    注册域名时，您的联系信息 (姓名、地址、电话号码和电子邮件) 通常会公开在名为 WHOIS 的数据库中，任何人都可以查询。WHOIS 隐私保护会用注册商的通用信息替换您的个人信息，在满足法律要求的同时保护您的隐私。

    所有通过 Replit 购买的域名均默认包含 WHOIS 隐私保护，无需额外付费。这意味着，垃圾邮件发送者、营销人员以及其他可能查询域名所有者信息的人都无法看到您的个人信息。
  </Accordion>

  <Accordion title="如果我已有域名怎么办？">
    要将现有域名连接到您的 Replit App，请参阅我们的[自定义域名](/zh/pt/cloud-services/deployments/custom-domains/)文档。
  </Accordion>
</AccordionGroup>
