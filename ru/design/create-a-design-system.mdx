Создать дизайн-систему можно двумя способами — выбор зависит от того, где сейчас живёт ваш бренд.

<div id="from-scratch-prompt-it-from-the-home-page">
  ## С нуля: создайте её промптом с главной страницы
</div>

Начните отсюда, если система уже сложилась у вас в голове (или в бренд-гайдлайнах), но ещё не воплощена ни в одном дизайне.

<Steps>
  <Step title="Опишите систему в поле создания">
    На главной странице Replit опишите нужную дизайн-систему в поле ввода промпта — например: *«Создай дизайн-систему для Velocity, премиального бренда по аренде суперкаров».*

    <Frame>
      <img src="/assets/mirror/ds-home-create-7f04110e1f71.png" alt="Поле ввода промпта на главной странице с промптом для создания дизайн-системы" width="800" height="240" data-path="images/design/replit-design/ds-home-create.png" />
    </Frame>
  </Step>

  <Step title="Ответьте на вопросы">
    Agent задаст несколько вопросов о вашей системе — характер бренда, цвета, предпочтения по типографике. Также можно указать источник: ссылку на Figma, сайт, код, референсные изображения, бренд-ассеты или готовый файл DESIGN.md.
  </Step>
</Steps>

<div id="from-a-mockup-extract-the-design-system">
  ## Из макета: извлеките дизайн-систему
</div>

Начните отсюда, если у вас уже есть понравившийся дизайн — сгенерированный frame или перетащенный template — и вы хотите, чтобы всё остальное ему соответствовало.

<Steps>
  <Step title="Выберите макет">
    На Canvas щёлкните по макету, внешний вид которого хотите взять за основу.
  </Step>

  <Step title="Извлеките через меню с тремя точками">
    Откройте меню **⋯** (меню с тремя точками) у frame и выберите **Extract design system**. Agent соберёт из макета токены, цвета и типографику в живое руководство по стилю — и применит его ко всему дизайну.

    <Frame>
      <img src="/assets/mirror/ds-extract-menu-3efbe8bb497e.png" alt="Крупный план панели действий выбранного frame с открытым меню дополнительных параметров, где показаны пункты Apply design system и Extract design system" width="958" height="320" data-path="images/design/replit-design/ds-extract-menu.png" />
    </Frame>
  </Step>
</Steps>

<div id="review-and-save">
  ## Проверка и сохранение
</div>

В любом случае просмотрите результат: живое руководство по стилю с вашими цветами (по ролям — primary, accent, muted…), шкалой типографики и токенами (они хранятся в `tokens.json` и задают значения CSS-переменных). Затем нажмите **Save design system**, чтобы сохранить дизайн-систему в вашем workspace.
