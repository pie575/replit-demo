Les suggestions sont idéales pour explorer, tandis que le chat vous permet d’affiner précisément votre direction. Deux méthodes de chat sont disponibles selon l’étendue du design dont vous souhaitez discuter. Utilisez le chat principal pour une frame entière, ou l’outil Chat pour un élément spécifique à l’intérieur de celui-ci.&quot;

<div id="section">
  ## Discuter d&#39;une frame dans le Chat principal
</div>

Sélectionnez la frame dont vous souhaitez parler : elle est jointe au Chat principal sous forme de pastille. Décrivez ensuite les modifications souhaitées, comme si vous briefiez un designer lors d&#39;une revue intermédiaire. Par exemple : *« warmer colors »*, *« the hero feels empty »*, *« try the nav on the left. »*

<div id="chat">
  ## Discuter d&#39;un élément avec l&#39;outil Chat
</div>

Dans la barre d&#39;outils, sélectionnez **Chat**, puis cliquez sur un élément à l&#39;intérieur d&#39;une frame : un bouton, un titre ou une image, par exemple. Le reste du tableau s&#39;assombrit, l&#39;élément apparaît sous forme de puce dans le compositeur et votre message ne s&#39;applique qu&#39;à cet élément.

<div id="section-2">
  ## Pendant la génération
</div>

Pendant que Design travaille, l&#39;état de la génération s&#39;affiche dans le chat. Lorsque le résultat apparaît dans un nouveau cadre, poursuivez la conversation, passez aux [suggestions](/fr/ko/design/explore-suggestions) ou lancez le [Build](/fr/ko/design/build-your-design).
