<div id="what-is-a-project">
  ## Qu&#39;est-ce qu&#39;un projet ?
</div>

Un projet est le conteneur de tout ce que vous créez sur Replit. Il rassemble votre code, vos données et tous les artifacts que vous produisez : web apps, applications mobiles, présentations, tableaux de bord de données et vidéos. Lorsque vous indiquez à Agent ce que vous voulez, il met en place un projet et y construit les artifacts.

Voyez un projet comme un espace de travail sur votre bureau : tout se trouve au même endroit et peut partager les mêmes informations, mais chaque élément a sa propre fonction.

Par exemple, si vous demandez à Agent de créer une application de suivi d&#39;activité physique, il crée un projet contenant un artifact d&#39;application mobile, accompagné du backend, de la base de données et du stockage nécessaires à son fonctionnement.

<ArtifactGrid />

Concepts clés :

* **Projet** : le conteneur qui regroupe tout — votre code, vos données et tous vos artifacts
* **Artifact** : un résultat publiable au sein d&#39;un projet (une web app, une présentation, une vidéo, etc.)
* **Ressources** : chaque artifact dispose automatiquement d&#39;un backend, d&#39;une base de données et d&#39;un stockage de fichiers — aucune configuration requise

<Note>
  Le publishing met en ligne l&#39;intégralité de votre projet en une seule fois. Tous les artifacts sont
  publiés ensemble, ils restent donc toujours synchronisés.
</Note>

<div id="what-you-can-build">
  ## Ce que vous pouvez créer
</div>

| Type                                                                    | De quoi il s&#39;agit                                                           | Exemple                                                                                    |
| ----------------------------------------------------------------------- | ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| **[Web app](/fr/features/artifact-types/web-apps)**                        | Un site ou une application que l&#39;on consulte dans son navigateur            | Une boutique en ligne, un outil de réservation, un site portfolio                          |
| **[Application mobile](/fr/features/artifact-types/building-mobile-apps)** | Une application native que l&#39;on installe sur son téléphone                  | Un suivi d&#39;activité physique, une application de commande en restaurant                |
| **[Visualisation de données](/fr/features/artifact-types/data-apps)**      | Un tableau de bord interactif avec graphiques, filtres et données en temps réel | Un rapport de ventes, un suivi d&#39;indicateurs, une vue analytique                       |
| **[Présentation](/fr/features/artifact-types/slide-decks)**                | Une présentation que vous pouvez projeter ou exporter                           | Un pitch deck, un point d&#39;équipe, une présentation produit                             |
| **[Animation](/fr/features/artifact-types/animated-videos)**               | Une vidéo de motion graphics exportable en MP4                                  | Une vidéo de lancement produit, une vidéo explicative, du contenu pour les réseaux sociaux |
| **Jeu 3D**                                                              | Un jeu 3D, une simulation ou une expérience interactive                         | Un jeu de réflexion, une simulation physique, une expérience interactive                   |
| **[Design](/fr/design/canvas)**                                            | Des directions visuelles et des prototypes explorés sur le canvas de design     | Des planches d&#39;ambiance, des maquettes, de l&#39;exploration de design                 |

Un même projet peut contenir plusieurs artifacts. Vous pouvez par exemple créer une web app pour vos clients, une application mobile pour votre équipe et une présentation pour vos investisseurs — le tout dans le même projet. Lorsque des artifacts se trouvent dans le même projet, ils partagent automatiquement les mêmes données et la même logique backend. Pour en savoir plus, consultez [Artifacts](/fr/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project).

<div id="managing-your-projects">
  ## Gérer vos projets
</div>

Votre page Projets répertorie tous les projets que vous avez créés ou auxquels vous avez été invité. C&#39;est le moyen le plus rapide de reprendre vos travaux récents et de retrouver le bon projet dans un workspace bien rempli.

<div id="see-at-a-glance-whats-inside-each-project">
  ### Voyez d&#39;un coup d&#39;œil ce que contient chaque projet
</div>

Chaque carte de projet affiche de petites icônes correspondant aux artifacts qu&#39;elle contient : web app, application mobile, présentation, visualisation de données ou animation. Survolez une icône pour prévisualiser la capture d&#39;écran de cet artifact directement sur la carte : vous distinguez ainsi vos projets sans avoir à les ouvrir.

<div id="filter-by-artifact">
  ### Filtrer par artifact
</div>

Utilisez le menu déroulant **Build type** en haut de la page Projects pour filtrer votre liste par artifact. Sélectionnez-en un pour n&#39;afficher que les projets contenant ce type d&#39;artifact :

* **Web** — les projets contenant une web app
* **Mobile** — les projets contenant une application mobile
* **Data** — les projets contenant une visualisation de données
* **Slides** — les projets contenant une présentation
* **Design** — les projets en mode Design
* **3D Game**, **Agent &amp; Automation**, et bien d&#39;autres

Sélectionnez **Any build type** pour réinitialiser le filtre.

  <img src="/assets/mirror/projects-page-build-type-filter-9e23df1b365a.png" alt="Menu déroulant Build type sur la page Projects filtrant par artifact, avec les options Design, Web, Data, Mobile, 3D Game et Slides" width="472" height="622" data-path="images/replitai/projects-page-build-type-filter.png" />
</Frame>

<div id="sort-by-last-opened">
  ### Trier par dernière ouverture
</div>

Par défaut, la page Projects est triée par **dernière ouverture par vous** : les projets que vous avez consultés le plus récemment apparaissent en haut de la liste. C&#39;est particulièrement utile dans les workspaces d&#39;équipe, où les modifications récentes des autres membres reléguaient sinon votre travail en cours tout en bas.

Vous pouvez modifier le tri en sélectionnant un autre en-tête de colonne (par exemple, **Last updated** ou **Name**).

<div id="pin-the-projects-you-use-most">
  ### Épinglez les projets que vous utilisez le plus
</div>

Épinglez un projet pour le garder en haut de votre liste. Les épinglages sont **visibles par vous seul** : épingler un projet dans un workspace d&#39;équipe ne change rien à ce que voient les autres membres.

Pour épingler un projet, ouvrez le menu contextuel (trois points) sur la carte du projet et sélectionnez **Pin**. Sélectionnez **Unpin** dans ce même menu pour retirer l&#39;épinglage.
