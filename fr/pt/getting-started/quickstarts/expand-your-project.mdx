⏰ *Temps estimé : 5 minutes* · Suite de [Créez votre première application](/fr/pt/getting-started/quickstarts/ask-ai)

Vous avez créé une application web. Faites-en maintenant quelque chose de plus ambitieux : ajoutez une application mobile, une présentation de diapositives ou tout autre élément, le tout dans le même projet. Tous partagent les mêmes données et le même backend, vous n’avez donc pas besoin de repartir de zéro.

<div id="antes-de-comear">
  ## Avant de commencer
</div>

Vous aurez besoin d&#39;un projet existant sur Replit, qu&#39;il provienne d&#39;un guide de démarrage rapide précédent ou de n&#39;importe quel projet que vous avez créé.

<div id="seu-projeto-pode-fazer-mais-de-uma-coisa">
  ## Votre projet peut faire bien plus qu&#39;une seule chose
</div>

Lorsque vous avez créé votre première application, il s&#39;agissait d&#39;une application web. Mais un même projet sur Replit ne se limite pas à une seule sortie. Vous pouvez y ajouter une **application mobile** qui fonctionne sur téléphone, une **présentation de diapositives** pour exposer votre idée, une **vidéo animée** et bien plus encore — le tout cohabitant au sein d&#39;un même projet.

Ce sont ce qu&#39;on appelle des **artefacts**. Chaque artefact constitue une sortie publiable à part entière, mais tous partagent le même code et les mêmes données en coulisses. Créez une fois, publiez partout.

<div id="adicione-um-aplicativo-mobile">
  ## Ajouter une application mobile
</div>

<Steps>
  <Step title="Demandez à Agent de créer une version mobile">
    Dites à Agent ce que vous souhaitez :

    ```
    Ajoute une version mobile de cette application
    ```

    Vous pouvez aussi cliquer sur le bouton **+** du panneau d&#39;aperçu pour ajouter un nouvel artefact.

    <Frame>
      <video autoPlay muted loop playsInline src="/assets/mirror/design_mobile_app_canvas-a67a35b27fd4.mp4" />
    </Frame>

    Agent crée une application mobile qui partage le même backend que votre application web : toutes les données et la logique déjà créées sont reprises automatiquement.
  </Step>

  <Step title="Prévisualisez dans un simulateur de téléphone">
    Une fois qu&#39;Agent a terminé, le panneau d&#39;aperçu affiche votre application mobile dans un simulateur de téléphone. Touchez l&#39;écran et testez-la comme sur un vrai téléphone.
  </Step>

  <Step title="Passez d'une application à l'autre">
    Utilisez le menu déroulant du **panneau d&#39;aperçu** pour passer de votre application web à l&#39;application mobile.

    <Frame>
      <video autoPlay muted loop playsInline src="/assets/mirror/switch_artifacts-bc0ae3999898.mp4" />
    </Frame>

    Vous pouvez aussi demander à Agent :

    ```
    Montre-moi l'application web
    ```
  </Step>
</Steps>

<div id="adicione-ainda-mais-ao-seu-projeto">
  ## Ajoutez encore plus à votre projet
</div>

Votre projet ne se limite pas aux applications web et mobiles. Vous pouvez également demander à Agent de créer d’autres types d’artefacts :

* **Présentations de diapositives** — « Créez une présentation de diapositives pour cette application »
* **Vidéos animées** — « Créez une courte vidéo explicative pour cette application »
* **Visualisations de données** — « Créez un panneau présentant des statistiques d’utilisation »
* **Documents** — « Rédigez un résumé de cette application »

Chacun devient un nouvel artefact dans votre projet, partageable via sa propre URL.

<div id="publique-seu-projeto">
  ## Publiez votre projet
</div>

Lorsque vous cliquez sur **Publier**, tous les artefacts de votre projet sont mis en ligne simultanément. Votre application web, votre application mobile et votre présentation de diapositives disposent chacune de leur propre URL et restent connectées au même backend.

Pour en savoir plus, consultez [Publier votre application](/fr/pt/getting-started/quickstarts/publish).
