title: "控制台"
description: "了解如何使用控制台查看应用的输出、错误和活动日志。"
---

控制台可让您实时监控和查看正在运行的 Replit App 输出的日志。
您可以利用当前和之前的运行信息了解应用的行为、
排查错误并优化性能。

<Tip>
  使用 Agent 调试时，请在 prompt 中附上控制台日志，以提供上下文。
</Tip>

</Frame>

<div id="recursos">
  ## 功能
</div>

控制台提供以下工具，帮助您了解应用的运行情况：

* **实时日志**：实时查看应用输出
* **AI 协助**：获取修复日志中报告的错误的建议
* **运行历史记录**：查看之前运行的日志，以跟踪变更

<div id="uso">
  ## 使用
</div>

您可以直接在项目编辑器中使用控制台工具。

<Accordion title="如何打开控制台">
  在左侧的**工具停靠栏**中：

  1. 选择 <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="所有工具图标" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **所有工具**，查看项目编辑器中的工具列表。
  2. 选择 <img class="icon-svg" src="/assets/mirror/console-8a41ac90789c.svg" alt="控制台图标" width="16" height="16" data-path="images/icons/console.svg" /> **控制台**。

  在**搜索栏**中：

  1. 选择顶部的 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 放大镜图标，打开搜索工具。
  2. 输入“控制台”查找该工具，然后在搜索结果中选择它。
</Accordion>

每次在 Replit App 中点击**运行**按钮时，控制台都会显示一条新日志条目，其中包含以下信息：

* 用于运行代码的命令
* 日期和时间信息
* 标准输出和错误日志

以下截图展示了用于启动应用的命令 `npm run dev` 及运行日志消息：

</Note>

<div id="depurao-com-ia">
  ### 使用 AI 调试
</div>

当您在日志中发现错误或其他想要了解的信息时，请点击该日志条目顶部的 **询问 AI** 按钮。这会自动打开 **Agent** 标签页，并将日志内容发送给 Agent 进行分析。

<div id="comandos-de-entrada-de-log">
  ### 日志条目操作
</div>

控制台提供以下工具来管理日志：

* **仅显示最新一次**：启用此选项后，仅显示最近一次运行。
* **折叠条目**：选择命令名称左侧的 <img class="icon-svg" src="/assets/mirror/down-arrow-9c1cf9fd152e.svg" alt="向下箭头图标" height="16" width="16" data-path="images/icons/down-arrow.svg" /> 向下箭头，可隐藏日志。
* **清除之前的运行记录**：选择此项可删除之前运行的日志。此操作不可撤销。

<div id="disponibilidade-de-rede">
  ### 网络可用性
</div>

您可以控制 App 开发版本的在线访问状态。

若要停止响应发往开发 URL 的请求，请选择网络信息栏右侧的 <img class="icon-svg" src="/assets/mirror/network-off-5bdca8a4fe4e.svg" alt="网络已停用图标" height="16" width="16" data-path="images/icons/network-off.svg" /> 带斜杠的地球图标。

若要重新启用，请选择 <img class="icon-svg" src="/assets/mirror/network-on-15be2e5fb4f5.svg" alt="网络已启用图标" height="16" width="16" data-path="images/icons/network-on.svg" /> 地球图标。

若要查看开发 URL，请在地址栏中选择 `{...}.replit.dev` 文本。

<Frame>
  <img src="/assets/mirror/preview-dev-url-b36770b33769.png" alt="Preview 中开发 URL 的位置" width="1222" height="824" data-path="images/workspace/preview-dev-url.png" />
</Frame>

<Note>
  即使将 App 设置为停止响应发往开发 URL 的请求，您仍可在 Preview 工具中访问它。
</Note>

<div id="parar-um-comando-de-workflow">
  ### 停止工作流命令
</div>

您可以在项目编辑器的控制台中停止正在运行的工作流命令。

点击包含 Replit App 运行命令的行右侧的方形按钮，即可终止该命令。

要重新启动 App，请使用项目编辑器顶部工作流中的 **运行** 按钮。
