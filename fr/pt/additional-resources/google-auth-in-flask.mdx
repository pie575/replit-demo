Permettre à vos utilisateurs de se connecter à votre site avec leur compte Google présente les avantages suivants :

1. Vous n’avez pas besoin d’implémenter votre propre système d’authentification.
2. Vous pouvez facilement obtenir le nom et les coordonnées des utilisateurs.
3. Vous pouvez utiliser les mêmes identifiants pour accéder aux ressources Google des utilisateurs, telles que Sheets et Drive.

Ce guide vous explique comment procéder avec Python et Flask sur Replit.

Nous allons d’abord voir comment configurer l’authentification OAuth de base, puis comment utiliser les identifiants obtenus pour accéder aux ressources Google des utilisateurs.

<div id="introduo-ao-oauth">
  ## Introduction à OAuth
</div>

L’authentification Google repose sur la norme OAuth. Voici comment fonctionne OAuth :

1. Sur votre site, vous dirigez l’utilisateur vers une page de connexion.
2. Lorsqu’il accède à cette page, vous n’implémentez pas de formulaire de connexion sur votre site : vous le redirigez vers le service de connexion Google afin de l’authentifier.
3. Une fois l’utilisateur authentifié par le service de connexion Google, celui-ci le redirige vers une URL prédéfinie de votre site, telle que `https://YOUR_DOMAIN/oauth2callback`, en transmettant des informations pertinentes sur l’utilisateur et sa session de connexion.
4. Vous utilisez les informations de connexion de l’utilisateur pour obtenir un jeton d’accès, comparable à un laissez-passer vous permettant d’accéder à ses ressources, telles que ses informations de profil, ses feuilles de calcul, ses documents et bien plus encore.

<div id="oauth-mostre-me-o-cdigo">
  ## OAuth : Montrez-moi le code
</div>

Si vous êtes comme moi, la première chose que vous voulez, c’est du code qui fonctionne. Le code ci-dessous est tout ce dont vous avez besoin. Vous devrez toutefois configurer certains éléments dans Google Cloud Console pour que tout fonctionne. Nous aborderons cela dans la section suivante. Créez une nouvelle App sur Replit à l’aide du [template Flask](https://replit.com/@replit/Flask?v=1) et placez le code suivant dans `main.py`. Les commentaires dans le code expliquent le rôle de chaque partie :

```python theme={null}
from flask import Flask, redirect, session, url_for, request
import google_auth_oauthlib.flow
import json
import os
import requests

app = Flask('app')
# `FLASK_SECRET_KEY` est utilisée par les sessions. Créez une chaîne aléatoire
# et stockez-la comme secret.
app.secret_key = os.environ.get('FLASK_SECRET_KEY') or os.urandom(24)

# `GOOGLE_APIS_OAUTH_SECRET` contient le contenu d’un fichier JSON à télécharger
# depuis le panneau Credentials de Google Cloud. Consultez la section suivante.
oauth_config = json.loads(os.environ['GOOGLE_OAUTH_SECRETS'])

# Configure le flux OAuth
oauth_flow = google_auth_oauthlib.flow.Flow.from_client_config(
    oauth_config,
    # les scopes définissent les API auxquelles vous souhaitez accéder pour le compte de l’utilisateur une fois authentifié
    scopes=[
        "https://www.googleapis.com/auth/userinfo.email",
        "openid",
        "https://www.googleapis.com/auth/userinfo.profile",
    ]
)

# Il s’agit du point d’entrée de la page de connexion. Il redirige vers le service de connexion Google à l’adresse
# `authorization_url`. `redirect_uri` est l’URI que le service de connexion Google utilisera pour
# rediriger vers cette application.
@app.route('/signin')
def signin():
    # Nous remplaçons http par https dans l’URL, car http est utilisé au sein de l’App Replit,
    # mais celle-ci est accessible de l’extérieur via https, et redirect_uri doit correspondre à cette URL
    oauth_flow.redirect_uri = url_for('oauth2callback', _external=True).replace('http://', 'https://')
    authorization_url, state = oauth_flow.authorization_url()
    session['state'] = state
    return redirect(authorization_url)

# Il s’agit du point de terminaison vers lequel le service de connexion Google redirige. Il doit être ajouté aux « Authorized redirect URIs »
# dans le panneau des identifiants API de Google Cloud. Ce point de terminaison appelle un point de terminaison Google pour demander
# un jeton d’accès et le stocker dans la session de l’utilisateur. Le jeton d’accès peut ensuite être utilisé pour accéder aux
# API pour le compte de l’utilisateur.
@app.route('/oauth2callback')
def oauth2callback():
    if not session['state'] == request.args['state']:
        return 'Invalid state parameter', 400
    oauth_flow.fetch_token(authorization_response=request.url.replace('http:', 'https:'))
    session['access_token'] = oauth_flow.credentials.token
    return redirect("/")

# Il s’agit de la page d’accueil de l’application. Elle invite l’utilisateur à se connecter s’il ne l’est pas déjà.
# Elle affiche les informations de l’utilisateur s’il est déjà connecté.
@app.route('/')
def welcome():
    if "access_token" in session:
        user_info = get_user_info(session["access_token"])
        if user_info:
            return f"""
                Hello {user_info["given_name"]}!<br>
                Your email address is {user_info["email"]}<br>
                <a href="/logout">Log out</a>
            """
    return """
        <h1>Hello!</h1>
        <a href="/signin">Sign In via Google</a><br>
    """

# Appelez l’API userinfo pour obtenir les informations de l’utilisateur à l’aide d’un jeton d’accès valide.
# Voici le premier exemple d’utilisation du jeton d’accès pour accéder à une API pour le compte de l’utilisateur.
def get_user_info(access_token):
    response = requests.get("https://www.googleapis.com/oauth2/v3/userinfo", headers={
       "Authorization": f"Bearer {access_token}"
   })
    if response.status_code == 200:
        user_info = response.json()
        return user_info
    else:
        print(f"Failed to fetch user info: {response.status_code} {response.text}")
        return None

@app.route('/logout')
def logout():
    session.clear()
    return redirect('/')

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000)

```
