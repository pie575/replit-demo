<div id="o-que-ssh">
  ## 什么是 SSH？
</div>

SSH (即 Secure Shell) 是一种安全协议，可让你远程访问 Replit App 的命令行界面。借助 SSH，你可以轻松传输文件，并使用自己偏好的本地集成开发环境 (IDE) 在 Replit 中编辑代码，从而提升开发工作流中的协作效率和生产力。

SSH 功能适用于 Core、Pro 及所有其他付费方案。

以下是流程概览：

* 在本地计算机上生成 SSH 密钥对
* 将该 SSH 密钥添加到任意 Replit App 的 **SSH** 面板
* 使用 SSH 客户端或支持通过 SSH 连接的编辑器进行连接 (例如 [VSCode](https://code.visualstudio.com/) 或 [Cursor](https://www.cursor.com/)) 

<Note>
  SSH 密钥与你的账户关联，而非与某个特定 Replit App 关联。这意味着你只需添加一次公钥，之后即可连接到你有权访问的任何 Replit App。
</Note>

<div id="por-que-usar-ssh">
  ## 为什么使用 SSH？
</div>

* **Replit App 与编辑器自动同步**：你在 Replit App 中做出的任何更改都会立即同步到编辑器，在编辑器中做出的任何修改也会同步到 Replit App。持续同步可确保你的代码在各个平台上始终保持最新。

* **文件管理同步**：无论是添加、删除还是更新文件，这些更改都会在编辑器与 Replit App 之间实时同步。无论从何处发起更改，你的项目结构都能保持一致。

* **文件夹管理和文件移动**：在文件夹之间移动文件也会在编辑器与 Replit App 之间同步。这样可确保在一个环境中进行的文件组织调整准确反映到另一个环境，保持项目的完整性和结构。

<div id="encontrar-ou-criar-um-par-de-chaves">
  ## 查找或创建密钥对
</div>

要为你的账户配置 SSH，你需要 SSH 公钥。

<div id="verificar-se-voc-j-tem-um-par-de-chaves">
  ### 检查是否已有密钥对
</div>

你可以在本地计算机的终端中运行以下命令，检查是否已有公钥：

<Tabs>
  <Tab title="Mac/Linux">
    ```sh theme={null}
    ls -l ~/.ssh
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    dir %HOMEPATH%\.ssh
    ```
  </Tab>
</Tabs>

如果出现错误，也没关系；请继续[生成新的密钥对](#generating-a-new-keypair)。
如果看到名为 `replit.pub` 的文件，请继续[获取公钥内容](#get-the-contents-of-your-public-key)。

<div id="gerando-um-novo-par-de-chaves">
  ### 生成新的密钥对
</div>

在本机打开终端 (或命令提示符) 窗口，然后粘贴以下命令：

<Tabs>
  <Tab title="Mac/Linux">
    ```bash theme={null}
    ssh-keygen -t ed25519 -f ~/.ssh/replit -q -N ""
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    ssh-keygen -t ed25519 -f %HOMEPATH%\.ssh\replit -q -N ""
    ```
  </Tab>
</Tabs>

此命令会检查指定的 SSH 公钥文件是否已存在。如果不存在，则会使用合理的参数创建新的 SSH 密钥。

<div id="obter-o-contedo-da-sua-chave-pblica">
  ### 获取公钥内容
</div>

确认已有密钥对或创建密钥对后，请查看公钥文件的内容 (两个同名文件中带 `.pub` 后缀的那个) ，稍后会用到。

<Tabs>
  <Tab title="Mac/Linux">
    ```sh theme={null}
    cat ~/.ssh/replit.pub
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    notepad %HOMEPATH%\.ssh\replit.pub
    ```
  </Tab>
</Tabs>

保存 `replit.pub` 的内容，以便在本文后续步骤中使用，然后继续[将 SSH 密钥添加到您的账户](#add-the-ssh-key-to-your-account)。

<div id="adicionar-a-chave-ssh-sua-conta">
  ## 将 SSH 密钥添加到您的账户
</div>

<div id="adicionar-a-chave-pblica-diretamente-em-um-replit-app-usando-o-painel-ssh">
  ### 通过 SSH 面板直接在 Replit App 中添加公钥
</div>

1. 在任意 Replit App 窗口中，点击 **+** 按钮，然后搜索 **SSH**。

<Frame>
  <img src="/assets/mirror/ssh-tool-2db02c6a83d0.png" alt="Replit 界面中的 SSH 工具按钮" width="846" height="328" data-path="images/ssh-vscode/ssh-tool.png" />
</Frame>

2. 前往 **Keys** 标签页，然后选择 **New SSH key**。
3. 在弹出窗口中，为密钥输入 **Label** (例如 my-ssh-key) ，然后将复制的公钥粘贴到 **Key** 字段中。
   点击 **Add SSH Key** 按钮。密钥即会添加并获得使用授权。

<Frame>
  <img src="/assets/mirror/add-ssh-key-with-values-5d6f440e56ba.png" alt="添加 SSH 密钥对话框，其中标签和密钥字段已填写" width="500" height="511" data-path="images/ssh-vscode/add-ssh-key-with-values.png" />
</Frame>

<div id="adicionar-a-chave-pblica-diretamente-nas-configuraes">
  ### 直接在设置中添加公钥
</div>

你也可以打开**设置**，在**账户**中选择**Advanced** (或**SSH keys**) ，以添加 SSH 密钥。选择**Add SSH key**，然后粘贴上一节[查找或创建密钥对](#find-or-create-a-keypair)中的 `replit.pub` 内容。

<Note>
  如果你的计算机上有多个公钥，请务必确保 SSH 配置使用的是相互匹配的私钥和公钥。
</Note>

<div id="conectando-ao-seu-replit-app">
  ## 连接到您的 Replit App
</div>

<div id="configurar-seu-ssh-config">
  ### 配置 SSH config
</div>

1. 在终端中，确认 `~/.ssh` 目录和 `~/.ssh/config` 文件是否存在：

<Tabs>
  <Tab title="Mac/Linux">
    ```sh theme={null}
    mkdir -p ~/.ssh && chmod 700 ~/.ssh && touch ~/.ssh/config && chmod 600 ~/.ssh/config
    open -a 'TextEdit' ~/.ssh/config || nano ~/.ssh/config
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    if not exist %HOMEPATH%\.ssh mkdir %HOMEPATH%\.ssh && type \NUL > %HOMEPATH%\.ssh\config
    notepad %HOMEPATH%\.ssh\config
    ```
  </Tab>
</Tabs>

2. 添加以下配置块，使所有 `*.replit.dev` 域名都使用 `replit` 密钥对：

<Tabs>
  <Tab title="Mac/Linux/Windows">
    ```
    Host *.replit.dev
        Port 22
        IdentityFile ~/.ssh/replit
        StrictHostKeyChecking accept-new
    ```
  </Tab>
</Tabs>

<div id="conectar-pelo-vscode-ou-cursor">
  ### 通过 VSCode 或 Cursor 连接
</div>

1. 在 Replit App 中，打开 **SSH** 面板。

2. 在 SSH 面板中，前往 **Connect** 选项卡，然后选择 **Launch VS Code**。

<Tabs>
  <Tab title="通过 VSCode 连接">
    <img src="/assets/mirror/ssh-connect-439a3c150846.png" alt="显示 Launch VS Code 选项的 SSH 连接选项卡" width="788" height="482" data-path="images/ssh-vscode/ssh-connect.png" />
  </Tab>
</Tabs>

3. 如果系统提示你配置 `~/.ssh/config`，请输入以下内容：

   ```
   Host *.replit.dev
       Port 22
       IdentityFile ~/.ssh/replit
       StrictHostKeyChecking accept-new
   ```

   <Note>
     仅在首次尝试连接 VS Code 或其他编辑器时，系统会提示你添加 SSH 配置。如需再次打开配置文件，请选择 **Configure SSH Hosts...**。
   </Note>

4. 如果出现外部应用提示，请选择 **Yes**，确认要在首选编辑器或 VS Code 中打开项目。

5. 系统可能会定期提示你安装或更新 SSH 扩展。Replit 会尽力兼容这些 IDE 的最新版本，你也可能会收到重要的安全更新。

<div id="conectar-manualmente">
  ### 手动连接
</div>

在 **SSH** 面板的 &quot;Connect&quot; 选项卡底部，您会看到 &quot;Connect manually&quot;。

复制此命令并粘贴到本地终端 (Mac 或 Linux) 或本地命令提示符 (Windows) 中，即可直接连接。

<div id="conectar-via-uma-ferramenta-no-listada-aqui">
  ### 使用此处未列出的工具连接
</div>

适用于不同平台和操作系统的 SSH 客户端有很多，许多客户端还提供不同的功能或集成。

你始终可以将 &quot;Connect Manually&quot; 中显示的命令拆解为各个组成部分，以确定如何配置每个客户端：

```sh theme={null}
ssh -i ~/.ssh/replit -p 22  c96b6ade-d5e4-4f7a-bc5b-52334509b2a3@c96b6ade-d5e4-4f7a-bc5b-52334509b2a3-00-16nh2hskw3ql8.riker.replit.dev
       ^-----v-----^    ^^  ^-----------------v----------------^ ^------------------------------v-------------------------------------^
        Private Key   Port                   User               @                           Hostname
```

**主机名**: `<seu_hostname>.<cluster>.replit.dev`
**端口**: `<número_da_porta>`
**用户名**: `用户名`
**私钥**: 计算机上私钥文件的路径，通常与 `replit.pub` 位于同一位置。
