Пентест методом чёрного ящика изучает работающее приложение снаружи — через взаимодействие в браузере и по сети. Исходный код приложения при этом не используется.

В Project Security Center уровень **Level 3 (AI pentest)** объединяет три типа проверок безопасности:

1. Бесплатные dependency and package checks
2. Статический анализ исходного кода с помощью Agent
3. Внешний пентест методом чёрного ящика работающего Preview, который проводится снаружи, без доступа к вашему исходному коду

После запуска Level 3 Replit параллельно выполняет проверку исходного кода с помощью Agent и внешний пентест методом чёрного ящика.

<div id="run-a-level-3-scan">
  ## Запуск сканирования Level 3
</div>

<Steps>
  <Step title="Откройте project">
    Откройте project, который нужно просканировать.
  </Step>

  <Step title="Откройте Security Center">
    На панели **Tools** в project выберите **Security Center**.
  </Step>

  <Step title="Запустите сканирование">
    В верхней части Security Center нажмите **Run scan**.
  </Step>

  <Step title="Выберите Level 3">
    Выберите **Level 3 (AI pentest)**.

    <Frame caption="Level 3 (AI pentest) добавляет к бесплатным dependency and package checks статический анализ от Agent и внешний тест работающего Preview.">
      <img src="/assets/mirror/level-3-ai-pentest-c223c0099d3f.png" alt="Security and Privacy Center, открытый с панели Tools, с развёрнутым меню выбора уровня сканирования и выбранным Level 3 AI pentest" width="2204" height="1200" data-path="images/project-security-center/level-3-ai-pentest.png" />
    </Frame>
  </Step>

  <Step title="Дождитесь завершения обеих задач">
    Дождитесь окончания проверки исходного кода и теста «чёрного ящика» для браузера и сети.
  </Step>

  <Step title="Изучите результаты">
    Просмотрите находки по обеим задачам на панели **Security**. Оцените каждую находку, прежде чем отправлять принятые проблемы в Agent.
  </Step>

  <Step title="Исправьте и запустите повторно">
    Отправьте принятые находки в Agent. После применения исправлений запустите ещё одно сканирование Level 3, чтобы их проверить.
  </Step>
</Steps>

<div id="understand-the-two-tasks">
  ## Разберитесь в двух задачах
</div>

| Задача                        | Используемые данные                                          | Назначение                                                                 |
| ----------------------------- | ------------------------------------------------------------ | -------------------------------------------------------------------------- |
| Проверка исходного кода       | Исходный код вашего приложения                               | Выявляет уязвимости безопасности, приватности и архитектуры в кодовой базе |
| Пентест методом черного ящика | Взаимодействия с работающим приложением через браузер и сеть | Изучает внешне наблюдаемое поведение без доступа к исходному коду          |

Изучите результаты обеих задач. Одна не заменяет другую: проверка исходного кода выявляет уязвимости в деталях реализации, а тест методом чёрного ящика оценивает работающее приложение снаружи.
