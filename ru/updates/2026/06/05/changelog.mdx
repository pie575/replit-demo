<div id="sell-physical-products-with-shopify">
  ### Продавайте физические товары через Shopify
</div>

Теперь вы можете создать интернет-магазин для продажи физических товаров. Попросите Agent создать магазин — он создаст для вас магазин Shopify, добавит ваши товары и настроит корзину и оформление заказа. Agent предоставит ссылку, по которой вы сможете привязать магазин к своему аккаунту, затем вам нужно будет оформить тариф Shopify и подключить платежи, чтобы начать продажи.

Подробнее о [подключении Shopify](/ru/features/integrations/shopify).

<div id="build-data-apps-on-microsoft-fabric">
  ### Создавайте приложения для работы с данными на Microsoft Fabric
</div>

Теперь в Replit можно создавать приложения для работы с данными на базе ИИ и публиковать их напрямую в Microsoft Fabric. Начните с шаблона Microsoft Fabric, подключите семантическую модель Power BI и попросите Agent создать дашборды и внутренние инструменты на основе ваших корпоративных данных с централизованным управлением. Аутентификация и политики доступа при этом остаются в Fabric.

<div id="custom-domains-set-up-their-own-dns">
  ### Пользовательские домены сами настраивают DNS
</div>

Подключить собственное доменное имя стало намного проще. Когда вы привязываете домен, Replit через Entri настраивает необходимые DNS-записи, поэтому вам больше не нужно вручную копировать их в панели управления регистратора домена. Выберите домен, подтвердите выбор — остальное сделает Replit.

Подробнее о [пользовательских доменах](/ru/features/publishing/custom-domains).

<div id="improve-your-search-ranking-with-seo-agent">
  ### Улучшите позиции в поисковой выдаче с помощью SEO Agent
</div>

SEO Agent проверяет ваше опубликованное приложение и выявляет проблемы, из-за которых поисковые системы и ИИ-инструменты не могут его найти. Для каждой проблемы доступно исправление в один клик: его можно просмотреть и применить. Чтобы запустить сканирование, откройте панель **Growth** в своём проекте.

<div id="use-stripe-in-collaborative-workspaces">
  ### Используйте Stripe в совместных рабочих пространствах
</div>

Stripe теперь поддерживается в совместных рабочих пространствах, поэтому вся команда может вместе создавать, тестировать и монетизировать одно App. Все участники рабочего пространства могут работать с подключённым аккаунтом Stripe, а не настраивать платежи поодиночке.

Подробнее о [Платежах Stripe](/ru/features/monetization/stripe-payments).
