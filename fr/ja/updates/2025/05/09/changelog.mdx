export const YouTubeEmbed = ({videoId, title = "vidéo YouTube", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

L’intégration de Notion à Agent est désormais disponible pour tous les utilisateurs, assurant une intégration fluide entre les projets Replit et les espaces de travail Notion.

Grâce à la configuration guidée par Agent, vous pouvez rapidement créer des applications qui tirent parti des puissantes fonctionnalités de bases de données et de documentation de Notion. Cette intégration vous permet de vous connecter à l’API Notion pour créer des applications connectées.

Autrement dit, vous pouvez créer des applications Replit capables d’envoyer et de récupérer des données depuis vos espaces de travail Notion !

<div id="unsplash-url">
  ### Amélioration de la gestion des images issues d’URL Unsplash cassées
</div>

Dites adieu aux images de banque d’images défectueuses dans vos projets !

Vous le savez peut-être, Agent ajoute déjà des images de banque d’images provenant d’Unsplash à vos projets. Mais il arrive que les URL soient cassées. Pourquoi ? Parce que les LLM sont particulièrement doués pour halluciner des URL d’images de banque d’images.

Nous avons ajouté une fonctionnalité qui remplace automatiquement les images de banque d’images défectueuses par des alternatives fonctionnelles, afin que vos applis conservent toujours une apparence professionnelle.

<div id="section-4">
  ### Renforcement des paramètres de confidentialité des déploiements Enterprise
</div>

Les clients Enterprise disposent désormais d’un contrôle plus précis de la confidentialité des déploiements grâce à plusieurs options de configuration.

Cette fonctionnalité améliorée permet aux organisations de gérer précisément l’accès aux applications déployées, avec le niveau de sécurité et de flexibilité requis par les environnements Enterprise. Les utilisateurs de Teams bénéficient désormais également de déploiements privés par défaut, et doivent explicitement choisir de les partager publiquement.
