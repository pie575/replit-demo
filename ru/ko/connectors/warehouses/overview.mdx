Коннектор хранилища данных позволяет Replit Agent безопасно выполнять запросы к хранилищу данных вашей организации. Разработчики могут создавать дашборды, инструменты отчётности и приложения для работы с данными с помощью естественного языка — без знания SQL. Администраторы сохраняют централизованный контроль благодаря ролевому доступу.

<div id="section">
  ## Поддерживаемые хранилища данных
</div>

Коннектор хранилища данных доступен на тарифе **Enterprise**.

| Хранилище данных | Руководство по настройке                                                                                                                  |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| BigQuery         | Уже доступно — руководство по настройке готовится                                                                                         |
| Databricks       | [Подключение Databricks](/ru/ko/connectors/warehouses/databricks)                                                                            |
| Microsoft Fabric | [Создание приложений для работы с данными с помощью Microsoft Fabric](/ru/ko/connectors/warehouses/microsoft-fabric) (закрытая предварительная версия) |
| Snowflake        | [Подключение Snowflake](/ru/ko/connectors/warehouses/snowflake)                                                                              |

У каждого хранилища данных свой процесс настройки, поскольку они различаются интеграцией OAuth, моделью идентификации и форматом учётных данных. Выберите нужное хранилище данных и следуйте соответствующему руководству.

<div id="section-2">
  ## Платформы аналитики и данных
</div>

Коннекторы для аналитики доступны в тарифах Core и Pro, а также Enterprise. Подключите аналитические инструменты, чтобы Agent мог читать и обрабатывать данные о продукте:

* **Segment** — данные клиентов из CDP, потоки событий и целевые сегменты
* **Amplitude** — продуктовая аналитика, данные о поведении пользователей и показатели вовлечённости
* **Hex** — совместные блокноты для работы с данными и результаты запросов

Управляйте ими так же, как и другими коннекторами Replit. См. [Управление коннекторами](/ru/ko/replitai/managing-connectors).

<div id="section-3">
  ## Как работает коннектор хранилища данных
</div>

Настройка выполняется однократно и требует участия трёх ролей:

1. **Администратор хранилища данных** — создаёт OAuth-интеграцию или сервисный идентификатор в хранилище данных
2. **Администратор организации Replit** — добавляет учётные данные в Replit и настраивает доступ
3. **Разработчик** — входит в систему и начинает работу с Agent

После завершения настройки разработчик просит Agent использовать хранилище данных, а Agent пишет и выполняет SQL-запросы.

<div id="section-4">
  ### Создание приложений на основе данных хранилища
</div>

После подключения вы можете попросить Agent создать приложение, использующее ваши данные. Agent может:

* Создавать внутренние инструменты, которые получают и отображают актуальные данные
* Создавать дашборды с диаграммами и визуализациями на основе данных хранилища
* Генерировать SQL-запросы для серверной части приложения
* Описывать структуру схем и таблиц, чтобы помочь понять, что следует создать

<Note>
  Agent может отвечать на разовые вопросы о данных, но основная цель коннектора хранилища данных — позволить вам создавать функциональные приложения, использующие данные вашей организации. Запросы к хранилищу выполняются непосредственно в экземпляре, поэтому убедитесь, что области OAuth и разрешения пользователя базы данных допускают необходимые операции чтения и записи.
</Note>
