Les contrôles des modèles Enterprise permettent aux administrateurs de compte de gérer les modèles Agent que les créateurs peuvent sélectionner. Définissez une politique pour l&#39;ensemble du compte, puis accordez un accès aux modèles différent à chaque Workspace.

<Note>
  Les contrôles des modèles sont réservés aux administrateurs de compte des comptes Enterprise. Contactez notre équipe commerciale à l&#39;adresse [sales@replit.com](mailto:sales@replit.com) pour les activer dans votre organisation.
</Note>

<div id="use-intelligent-model-routing">
  ## Utiliser le routage intelligent des modèles
</div>

Le routage intelligent des modèles est l&#39;expérience Agent par défaut dans les Workspaces Enterprise. Lorsque le **mode Auto** est activé, Replit choisit le mode et le modèle les mieux adaptés à chaque tâche, en conciliant qualité et coût.

Le routage effectue sa sélection parmi les modèles autorisés par les politiques du compte et du Workspace. Les providers et les modèles qui n&#39;en font pas partie ne peuvent pas être sélectionnés. Les créateurs peuvent laisser le **mode Auto** activé ou le désactiver pour choisir manuellement un modèle autorisé.

<div id="open-agent-model-settings">
  ## Ouvrir les paramètres de modèle d&#39;Agent
</div>

1. Ouvrez **Settings**.
2. Sous **Account**, sélectionnez **Advanced**.
3. Développez **Agent modes and model providers**.

<div id="set-a-provider-policy">
  ## Définir une politique de provider
</div>

<Steps>
  <Step>
    Sélectionnez le provider de modèles que vous souhaitez gérer.
  </Step>

  <Step>
    Sous **Account policy**, sélectionnez l&#39;une des options suivantes :

    | Option              | Résultat                                                             |
    | ------------------- | -------------------------------------------------------------------- |
    | **Enable all**      | Tous les modèles du provider sont disponibles dans chaque Workspace. |
    | **Enable selected** | Vous choisissez les modèles disponibles pour chaque Workspace.       |
    | **Disabled**        | Aucun Workspace ne peut utiliser les modèles du provider.            |

    <Note>
      Au moins un modèle d&#39;OpenAI, d&#39;Anthropic et de Google doit rester activé. Vous pouvez désactiver les autres providers.
    </Note>
  </Step>

  <Step>
    Sélectionnez **Update**.
  </Step>
</Steps>

Les providers de modèles open source sont désactivés par défaut. Pour en rendre un disponible, sélectionnez **Enable all** ou **Enable selected**, puis **Update**.

<div id="set-a-workspace-policy">
  ## Définir une politique de Workspace
</div>

Utilisez **Enable selected** lorsque différents Workspaces nécessitent des accès différents aux modèles.

<Frame caption="La politique du provider Anthropic définie sur Enable selected, avec l'accès aux modèles configuré par Workspace.">
  <img src="/assets/mirror/anthropic-account-policy-workspace-models-38c0f71a609d.jpg" alt="Politique de compte Anthropic définie sur Enable selected avec des interrupteurs de modèles pour un Workspace" width="2000" height="930" data-path="images/workspace/anthropic-account-policy-workspace-models.jpg" />
</Frame>

1. Ouvrez les paramètres du provider.
2. Définissez l&#39;**Account policy** sur **Enable selected**.
3. Dans la liste **Workspace**, ouvrez le menu déroulant **Setting** d&#39;un Workspace.
4. Activez ou désactivez chaque modèle pour ce Workspace.
5. Sélectionnez **Update**.

Avant de sélectionner **Update**, vous pouvez sélectionner **Copy to all** pour appliquer
la sélection de modèles du Workspace actuel à tous les Workspaces du compte.

<div id="limitations">
  ## Limites
</div>

* Les politiques de modèles s&#39;appliquent aux Workspaces. Vous ne pouvez pas définir de politique distincte pour un groupe d&#39;utilisateurs au sein d&#39;un même Workspace.
* Le routage intelligent des modèles ne prévaut pas sur les politiques du compte ou du Workspace. Il ne peut pas sélectionner un provider ou un modèle désactivé.
* Le commutateur **Fast mode models**, dans **Agent modes and model providers**, contrôle l&#39;accès aux variantes de modèles rapides pour tous les Workspaces du compte. Les politiques de providers et le routage intelligent des modèles n&#39;ont aucune incidence sur ce paramètre.
