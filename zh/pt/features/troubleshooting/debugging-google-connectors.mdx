---

<div id="viso-geral">
  ## 概述
</div>

如果您尝试通过[连接器](/zh/pt/features/integrations/overview#connectors)连接 Google Workspace 服务 (Drive、Docs、Sheets、Calendar 或 Gmail) 时看到 **“此应用被屏蔽”** 错误消息，通常是因为您的 Google Workspace 组织中的 Google OAuth 设置配置有误。

本指南将帮助您解决此问题，以便将 Google 服务连接到您的 Replit 应用。

<Frame>
  <img src="/assets/mirror/app-is-blocked-837b32f44f72.png" alt="Google 错误对话框，显示“此应用被屏蔽”消息，阻止 OAuth 访问" width="1279" height="502" data-path="images/replitai/debugging-google-connectors/app-is-blocked.png" />
</Frame>

<Warning>
  这些步骤仅适用于 **Google Workspace** 账号 (由组织管理的账号) 。如果您使用的是关联 `@gmail.com` 地址的个人 Google 账号，且 Replit 连接器被屏蔽，您无法自行更改 OAuth 政策——请联系您的 Google Workspace 管理员，或使用其他账号。
</Warning>

<div id="etapas-de-soluo-de-problemas">
  ## 故障排查步骤
</div>

<div id="etapa-1-tente-o-modo-de-navegao-annima">
  ### 步骤 1：尝试使用无痕浏览模式
</div>

浏览器扩展程序或缓存数据可能会干扰 OAuth 流程，使用无痕浏览模式可以避开这些问题。

<Steps>
  <Step title="打开无痕浏览">
    在浏览器中新建一个**无痕**窗口 (Chrome) 或**隐私**窗口 (Firefox/Safari) 。
  </Step>

  <Step title="登录 Replit">
    在 [replit.com](https://replit.com) 登录你的 Replit 账户。
  </Step>

  <Step title="重新尝试连接">
    在项目编辑器中打开你的应用，在侧边栏中进入 **Connectors**，然后重新尝试连接 Google 服务。
  </Step>
</Steps>

如果错误仍然存在，请继续执行步骤 2。

<div id="etapa-2-verificar-as-configuraes-oauth-no-google-workspace">
  ### 步骤 2：检查 Google Workspace 中的 OAuth 设置
</div>

<Note>
  此步骤需要您拥有所在组织的 **Google 管理控制台**访问权限。如果您没有管理员权限，请联系您的 IT 团队。
</Note>

<Steps>
  <Step title="打开 Google 管理控制台">
    登录您所在组织的 [Google 管理控制台](https://admin.google.com)。
  </Step>

  <Step title="确认用户存在">
    进入 **Users** 部分，确认正在尝试连接 Replit 的账号已列在其中。

    <Frame>
      <img src="/assets/mirror/google-workspace-users-c21d8fd43f71.png" alt="Google 管理控制台的用户部分，显示用户账号" width="1104" height="596" data-path="images/replitai/debugging-google-connectors/google-workspace-users.png" />
    </Frame>
  </Step>

  <Step title="进入 API Controls">
    前往 **Security &gt; Access and data control &gt; API controls**。

    <Frame>
      <img src="/assets/mirror/google-workspace-api-controls-b811709315cf.png" alt="Google 管理控制台显示 Security > API Controls 导航路径" data-og-width="1140" width="1140" data-og-height="631" height="631" data-path="images/replitai/debugging-google-connectors/google-workspace-api-controls.png" data-optimize="true" data-opv="3" srcset="/assets/mirror/google-workspace-api-controls-a27d4577aee8.png 280w, /assets/mirror/google-workspace-api-controls-d681943c082d.png 560w, /assets/mirror/google-workspace-api-controls-8f1b1659e60a.png 840w, /assets/mirror/google-workspace-api-controls-795bc698b885.png 1100w, /assets/mirror/google-workspace-api-controls-c122b9eb493f.png 1650w, /assets/mirror/google-workspace-api-controls-2415c93b4f41.png 2500w" />
    </Frame>
  </Step>

  <Step title="打开第三方应用访问权限">
    选择 **Manage third-party app access**。

    <Frame>
      <img src="/assets/mirror/third-party-app-access-eb5c94107497.png" alt="Google 管理控制台的 API 控制页面，突出显示 Manage third-party app access 按钮" width="1686" height="468" data-path="images/replitai/debugging-google-connectors/third-party-app-access.png" />
    </Frame>
  </Step>

  <Step title="验证 OAuth 访问权限">
    确认 Google Workspace 中已为用户启用 OAuth 访问权限。如果该权限受限，请授予必要的访问权限，以便 Replit 完成 OAuth 流程。
  </Step>
</Steps>

如果连接仍然失败，请继续执行步骤 3。

<div id="etapa-3-adicionar-o-replit-como-cliente-oauth-confivel">
  ### 步骤 3：将 Replit 添加为受信任的 OAuth 客户端
</div>

如果您的组织默认限制第三方应用的访问权限，则需要明确将 Replit 设为受信任应用。

<Steps>
  <Step title="打开 Google 管理控制台">
    登录您所在组织的 [Google 管理控制台](https://admin.google.com)。
  </Step>

  <Step title="前往 API Controls">
    前往 **Security &gt; Access and data control &gt; API controls**。
  </Step>

  <Step title="打开第三方应用访问权限">
    在 **App access control** 中，选择 **Manage third-party app access**。
  </Step>

  <Step title="添加新应用">
    选择 **Add app** 按钮，并在下拉菜单中选择 **OAuth App Name or Client ID**。
  </Step>

  <Step title="搜索 Replit">
    输入 Replit 的 Client ID：

    ```
    1012035106355-2dhot2e6o0malvog2ofss7akj2nsp8nq.apps.googleusercontent.com
    ```

    选择 **Search**。当 Replit 应用出现在搜索结果中时，选中它。
  </Step>

  <Step title="设置访问级别">
    将访问级别设置为 **Trusted**。
  </Step>

  <Step title="保存">
    选择 **Save**。
  </Step>
</Steps>

<Tip>
  Google Workspace 政策的更改可能需要几分钟才能生效。保存后请等待 5-10 分钟，然后在 Replit 中重新尝试连接您的 Google 服务。
</Tip>

<div id="ainda-bloqueado">
  ## 仍然被阻止？
</div>

如果你已完成全部三个步骤，错误依然存在：

* **再次核对组织部门 (OU)&#x20;**：Google Workspace 政策可能只对特定 OU 生效。请确认 OAuth 和受信任应用的设置已应用于该用户所在的 OU。
* **查看 Google Workspace 提醒**：在管理控制台中，进入 **Reporting &gt; Audit and investigation &gt; OAuth log events**，查找与 Replit 相关的被拒绝请求。
* **联系 Replit 支持**：如果问题不在 Google Workspace 一侧，请联系 [Replit 支持](https://replit.com/support) 获取帮助。
