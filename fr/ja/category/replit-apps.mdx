<div id="replit-app">
  ## Qu&#39;est-ce qu&#39;une Replit App ?
</div>

Les applications Replit sont des projets hébergés dans le cloud qui incluent du code, des données et des ressources.
Vous pouvez les créer, les exécuter et les publier depuis un environnement sécurisé et isolé.

Les applications Replit s&#39;intègrent aux outils suivants du Project Editor pour offrir une expérience de développement fluide :

* **Outils basés sur l&#39;IA** : utilisez Agent pour créer, déboguer et expliquer du code.
* **Collaboration** : collaborez en temps réel avec d&#39;autres utilisateurs sur la même App.
* **Publication** : publiez votre App dans le cloud en un clic.

<div id="section-2">
  ## Fonctionnalités principales
</div>

Les applications Replit offrent les fonctionnalités suivantes :

* **Aucune configuration requise** : créez des applications ou écrivez du code directement sur Replit.com, sans installation ni configuration.
* **Enregistrement automatique** : les projets enregistrent continuellement vos modifications dans le cloud, ce qui vous permet de reprendre le codage depuis n’importe quel navigateur web.
* **Gestion des versions** : suivez les modifications, consultez l’historique des fichiers et synchronisez-les grâce au système de gestion des versions de Replit, sans aucune configuration.
* **Paramètres de visibilité publique/privée** : contrôlez qui peut voir, exécuter et remixer votre application grâce aux paramètres de confidentialité.
* **Publication** : publiez votre code dans le cloud sans modifier de paramètres complexes.
* **URL d’application personnalisée** : obtenez une URL unique pour votre application ou associez-lui un domaine personnalisé pour une présence professionnelle.

<Info>
  Les fichiers téléversés dans le système de fichiers du projet sont disponibles uniquement pendant le développement,
  et les applications publiées ainsi que les autres créateurs ne peuvent pas y accéder. Utilisez le [stockage d’objets](/fr/ja/features/data-and-storage/object-storage) pour gérer les téléversements des créateurs et fournir des fichiers, et la [base de données Replit](/fr/ja/features/data-and-storage/sql-database) pour stocker et récupérer les données de votre application et de vos utilisateurs.
</Info>

Pour en savoir plus sur les outils de Project Editor qui facilitent la création de Replit App, consultez la [présentation de Project Editor](/fr/ja/learn/projects-and-artifacts/project-editor/).

<div id="section-3">
  ## Fonctionnement
</div>

Lorsque vous créez une Replit App, Replit configure dans le cloud un espace privé dédié à votre projet.
À mesure que vous ajoutez des fonctionnalités ou apportez des modifications à votre app, Replit enregistre automatiquement vos changements afin que vous puissiez reprendre vos modifications depuis n&#39;importe quel navigateur web.

Replit fournit un environnement préconfiguré comprenant tous les composants nécessaires.
Vous pouvez ainsi commencer immédiatement à créer votre app sans vous soucier de la configuration du serveur, de la mise en place de la base de données ou de la gestion de l&#39;environnement.

Replit attribue automatiquement une adresse web unique à chaque Replit App, ce qui vous permet de prévisualiser votre app pendant que vous travaillez. Lorsque vous êtes prêt à partager votre création, vous pouvez la publier en quelques clics et la rendre accessible 24 h/24, 7 j/7.

<div id="section-4">
  ## Présentation du stockage
</div>

Replit propose quatre principaux types de stockage pour répondre aux besoins en données de votre application. Chaque type de stockage répond à des cas d&#39;utilisation différents et présente des limites spécifiques selon votre forfait.

<Info>
  Les limites de stockage incluent toutes les données enregistrées par votre application, y compris les paquets et les dépendances installés.
</Info>

| Type de stockage                                                                | Description                       | Cas d&#39;utilisation                                                   | Persistance                                                  | Limites du forfait                                                                                                                                       |
| ------------------------------------------------------------------------------- | --------------------------------- | ----------------------------------------------------------------------- | ------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Stockage de fichiers**                                                        | Fichiers du projet                | Code d&#39;application, ressources statiques, fichiers de configuration | Persistant après la publication, réinitialisé au redémarrage | Starter : {StarterWorkspaceStorage}<br />Core : {CoreWorkspaceStorage}<br />Pro : {TeamsWorkspaceStorage}<br />Enterprise : {EnterpriseWorkspaceStorage} |
| **[Base de données](/fr/ja/features/data-and-storage/sql-database/)**              | Données structurées               | Profils utilisateur, scores de jeux, catalogues de produits             | Entièrement persistante entre les sessions                   | 20 Go par base de données de développement<br />Les bases de données de production sont facturées selon le temps de calcul et le stockage                |
| **[Stockage d&#39;application](/fr/ja/features/data-and-storage/object-storage/)** | Données non structurées et médias | Images, vidéos, PDF, documents                                          | Entièrement persistant entre les sessions                    | Tarification à l&#39;usage<br />Facturé selon le stockage et la bande passante                                                                           |
| **[Secrets](/fr/ja/core-concepts/project-editor/app-setup/secrets/)**              | Données sensibles chiffrées       | Clés API, informations d&#39;identification, chaînes de connexion       | Entièrement persistant et chiffré                            | Aucune limite spécifique<br />Inclus dans tous les forfaits                                                                                              |
