Avec l’[application mobile Replit](https://replit.com/mobile), vos projets vous suivent partout. Reprenez votre travail où que vous soyez ou créez un projet de A à Z. Discutez avec Agent, modifiez vos projets et déployez-les sur le Web, le tout dans une interface optimisée pour le tactile.

<div id="section">
  ## Démarrage
</div>

Suivez les étapes ci-dessous pour installer l&#39;application et créer un projet.

<div id="section-2">
  ### Installer l’application
</div>

1. Accédez à la [page de téléchargement de l’application mobile](https://replit.com/mobile) et installez l’application correspondant au système d’exploitation de votre appareil mobile.
2. Ouvrez l’application, puis créez un compte ou connectez-vous à un compte existant.
   Si vous créez un compte, vous devrez vérifier votre adresse e-mail pour terminer le processus.

<div id="section-3">
  ### Commencer à créer
</div>

Vous pouvez commencer de deux façons depuis l’écran d’accueil :

* **Reprendre votre travail** : ouvrez un projet dans **Recent Projects** pour poursuivre.
* **Créer à partir de zéro** : décrivez ce que vous souhaitez dans la zone de saisie, puis envoyez votre demande. Agent commencera immédiatement à créer votre projet.

Pour commencer à partir d’un template prédéfini ou de code existant, appuyez sur ⋮ en haut à droite, puis sélectionnez **Remix a Template** ou **Import from GitHub**.

<Note>
  Vous créez une application iOS native ? Utilisez le Project Editor sur [replit.com](https://replit.com) pour créer, prévisualiser, développer ou soumettre votre application. Le développement d’applications mobiles natives est également disponible dans l’application Replit Android lorsqu’il est pris en charge.
</Note>

<div id="section-5">
  ## Fonctionnalités mobiles
</div>

<div id="section-6">
  ### Saisie vocale
</div>

L’option vocale du champ de prompt d’Agent vous permet de décrire ce que vous souhaitez créer ou modifier, sans les mains.

<div id="live-activities">
  ### Live Activities
</div>

Suivez la progression d&#39;Agent où que vous soyez. Une notification s&#39;affiche dès qu&#39;Agent démarre. Sur l&#39;écran verrouillé, appuyez sur **Allow** pour suivre la progression sans ouvrir Replit.

<Accordion title="Appareils pris en charge">
  * iPhone sous iOS 18 ou version ultérieure
  * iPad sous iOS 18 ou version ultérieure
  * Mac sous macOS Tahoe ou version ultérieure
  * Apple Watch appairée
</Accordion>

<div id="notifications">
  ### Notifications
</div>

Recevez les mises à jour importantes où que vous soyez. Accédez aux **paramètres** et ouvrez **Notifications** (par exemple, sous **User**). Vérifiez que les notifications sont activées et appuyez sur Autoriser lorsque vous y êtes invité.

Replit vous prévient dans les cas suivants :

* L&#39;Agent a besoin de votre aide
* L&#39;Agent a terminé une tâche
* Une mise à jour importante concerne votre facturation

<div id="tablet-keyboard-mode">
  ### Tablet Keyboard Mode
</div>

En connectant un clavier à votre tablette, vous bénéficiez d&#39;un environnement de travail optimisé pour les grands écrans. La première fois que vous ouvrez le Project Editor avec un clavier connecté, un message vous propose de l&#39;activer.

Vous pouvez l&#39;activer ou le désactiver à tout moment depuis **Compte** &gt; **Keyboard Settings**.

<div id="section-7">
  ## Mise à niveau et facturation
</div>

Pour passer à Core depuis l&#39;application, allez dans **compte**, appuyez sur **Upgrade**, choisissez un plan, puis appuyez sur **Continue with Core**. Pro n&#39;est pas disponible à l&#39;achat dans l&#39;application mobile : vous devez le souscrire sur [replit.com](https://replit.com).

Pour utiliser Agent au-delà des crédits inclus dans votre abonnement, ajoutez un moyen de paiement pour la [facturation à l&#39;usage](/fr/ko/billing/about-usage-based-billing) :

* **Sur le web** : rendez-vous sur replit.com et ouvrez **paramètres** → **compte** → **Billing**.
* **Dans l&#39;application (iOS aux États-Unis uniquement)** : ouvrez **paramètres** → **Billing** (ou **compte** → **Billing**).
