Вход пользователей на ваш сайт с помощью учётной записи Google даёт следующие преимущества:

1. Вам не нужно реализовывать собственную систему аутентификации.
2. Вы можете легко получать имена и контактные данные пользователей.
3. Вы можете использовать те же учётные данные для доступа к ресурсам пользователей в Google, например к Google Таблицам и Google Диску.

В этом руководстве вы узнаете, как настроить это с помощью Python и Flask на Replit.

Сначала мы разберём настройку базовой аутентификации OAuth, а затем покажем, как использовать полученные учётные данные для доступа к ресурсам пользователей в Google.

<div id="introduction-to-oauth">
  ## Введение в OAuth
</div>

Аутентификация через Google основана на стандарте OAuth. OAuth работает следующим образом:

1. В каком-либо месте вашего сайта вы направляете пользователя на страницу входа.
2. Перейдя на страницу входа, пользователь не видит форму входа на вашем сайте: вместо этого вы перенаправляете его в службу входа Google для аутентификации.
3. После успешной аутентификации пользователя служба входа Google перенаправляет его обратно на ваш сайт по заранее заданному URL, например `https://YOUR_DOMAIN/oauth2callback`, и передаёт некоторую информацию о пользователе и сеансе входа.
4. Используя данные для входа пользователя, вы получаете токен доступа — своего рода пропуск для доступа к ресурсам пользователя, таким как информация профиля, таблицы, документы и многое другое.

<div id="oauth-show-me-the-code">
  ## OAuth: Покажите код
</div>

Если вы похожи на меня, первое, что вам нужно, — рабочий код. Ниже приведён именно такой код. Однако, чтобы всё заработало, вам потребуется настроить несколько параметров в Google Cloud Console. Об этом рассказывается в следующем разделе. Создайте новый Replit App с помощью [шаблона Flask](https://replit.com/@replit/Flask?v=1) и добавьте в `main.py` следующий код. Комментарии в коде поясняют назначение отдельных частей:

```python theme={null}
from flask import Flask, redirect, session, url_for, request
import google_auth_oauthlib.flow
import json
import os
import requests

app = Flask('app')
# `FLASK_SECRET_KEY` используется для сеансов. Создайте случайную строку
# и сохраните её в Secrets.
app.secret_key = os.environ.get('FLASK_SECRET_KEY') or os.urandom(24)

# `GOOGLE_APIS_OAUTH_SECRET` содержит содержимое JSON-файла, который нужно скачать
# из панели учётных данных Google Cloud. См. следующий раздел.
oauth_config = json.loads(os.environ['GOOGLE_OAUTH_SECRETS'])

# Здесь настраивается OAuth-поток
oauth_flow = google_auth_oauthlib.flow.Flow.from_client_config(
    oauth_config,
    # области доступа определяют, к каким API можно обращаться от имени пользователя после аутентификации
    scopes=[
        "https://www.googleapis.com/auth/userinfo.email",
        "openid",
        "https://www.googleapis.com/auth/userinfo.profile",
    ]
)

# Это точка входа для страницы входа. Она перенаправляет в службу входа Google по адресу
# `authorization_url`. `redirect_uri` — URI, который служба входа Google использует для
# перенаправления обратно в это приложение.
@app.route('/signin')
def signin():
    # Заменяем в URL http на https, поскольку внутри Replit App используется http,
    # а извне доступ осуществляется по https, поэтому redirect_uri должен ему соответствовать
    oauth_flow.redirect_uri = url_for('oauth2callback', _external=True).replace('http://', 'https://')
    authorization_url, state = oauth_flow.authorization_url()
    session['state'] = state
    return redirect(authorization_url)

# Это конечная точка, на которую перенаправляет служба входа Google. Её необходимо добавить в список "Authorized redirect URIs"
# на панели учётных данных API в Google Cloud. Она вызывает конечную точку Google, чтобы запросить
# токен доступа и сохранить его в сеансе пользователя. После этого токен доступа можно использовать для обращения к
# API от имени пользователя.
@app.route('/oauth2callback')
def oauth2callback():
    if not session['state'] == request.args['state']:
        return 'Invalid state parameter', 400
    oauth_flow.fetch_token(authorization_response=request.url.replace('http:', 'https:'))
    session['access_token'] = oauth_flow.credentials.token
    return redirect("/")

# Это главная страница приложения. Если пользователь ещё не вошёл, она предлагает ему войти.
# Если пользователь уже вошёл, она показывает информацию о нём.
@app.route('/')
def welcome():
    if "access_token" in session:
        user_info = get_user_info(session["access_token"])
        if user_info:
            return f"""
                Hello {user_info["given_name"]}!<br>
                Your email address is {user_info["email"]}<br>
                <a href="/logout">Log out</a>
            """
    return """
        <h1>Hello!</h1>
        <a href="/signin">Sign In via Google</a><br>
    """

# Вызов API userinfo для получения информации о пользователе с помощью действительного токена доступа.
# Это первый пример использования токена доступа для обращения к API от имени пользователя.
def get_user_info(access_token):
    response = requests.get("https://www.googleapis.com/oauth2/v3/userinfo", headers={
       "Authorization": f"Bearer {access_token}"
   })
    if response.status_code == 200:
        user_info = response.json()
        return user_info
    else:
        print(f"Failed to fetch user info: {response.status_code} {response.text}")
        return None

@app.route('/logout')
def logout():
    session.clear()
    return redirect('/')

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000)

```

Сначала в разделе OAuth исходного кода оставьте всё без изменений, добавив лишь `"https://www.googleapis.com/auth/spreadsheets.readonly"` в список областей доступа:

```python theme={null}
# Настраиваем конфигурацию OAuth-потока
oauth_flow = google_auth_oauthlib.flow.Flow.from_client_config(
    oauth_config,
    # области доступа определяют, к каким API вы хотите обращаться от имени пользователя после аутентификации
    scopes=[
        "https://www.googleapis.com/auth/userinfo.email",
        "openid",
        "https://www.googleapis.com/auth/userinfo.profile",
        "https://www.googleapis.com/auth/spreadsheets.readonly"
    ]
)
```

Чтобы получить доступ к Google API с помощью библиотеки `googleapiclient.discovery`, сначала создайте объект `Credentials`, используя токен доступа, а затем с помощью функции `build` создайте вызываемый объект API. Для Sheets API это выглядит так:

```python theme={null}
credentials = google.oauth2.credentials.Credentials(token=session['access_token'])
service = build("sheets", "v4", credentials=credentials)
sheets_api = service.spreadsheets()
```

Чтобы работать с Sheets API, я создал несколько вспомогательных функций:

```python theme={null}
# получить все листы из таблицы Google
def get_sheets(sheets_api, spreadsheet_id) -> list[str]:
    result = sheets_api.get(spreadsheetId=spreadsheet_id).execute()
    return [sheet["properties"]["title"] for sheet in result["sheets"]]

# получить данные указанного листа из таблицы Google
def get_sheet_data(sheets_api, spreadsheet_id, sheet_title) -> list[list[str]]:
    result = (
        sheets_api.values()
        .get(spreadsheetId=spreadsheet_id, range=sheet_title)
        .execute()
    )
    return result["values"]
```

С помощью приведённых выше рекомендаций можно создать POST-обработчик, который импортирует таблицу Google:

```python theme={null}
@app.route("/import_spreadsheet", methods = ['POST'])
def import_spreadsheet():
    if 'access_token' not in session:
        return redirect('/signin')
    spreadsheet_id = request.form["spreadsheet_id"]
    credentials = google.oauth2.credentials.Credentials(token=session['access_token'])
    service = build("sheets", "v4", credentials=credentials)
    sheets_api = service.spreadsheets()
    try:
        sheets = get_sheets(sheets_api, spreadsheet_id)
        data_by_sheets = {}
        for sheet in sheets:
            data = get_sheet_data(sheets_api, spreadsheet_id, sheet)
            data_by_sheets[sheet] = data
    except googleapiclient.errors.HttpError as e:
        return f"upload failure"
    dirpath = os.path.join("static", "uploads", spreadsheet_id)
    filepath = os.path.join(dirpath, "data.json")
    os.makedirs(dirpath, exist_ok=True)
    with open(filepath, "w") as file:
        json.dump(data_by_sheets, file)
    return "upload success!"
```

# получить все листы в Google Таблицах
def get_sheets(sheets_api, spreadsheet_id) -> list[str]:
    result = sheets_api.get(spreadsheetId=spreadsheet_id).execute()
    return [sheet["properties"]["title"] for sheet in result["sheets"]]

# получить данные указанного листа в Google Таблицах
def get_sheet_data(sheets_api, spreadsheet_id, sheet_title) -> list[list[str]]:
    result = (
        sheets_api.values()
        .get(spreadsheetId=spreadsheet_id, range=sheet_title)
        .execute()
    )
    return result["values"]

@app.route("/import_spreadsheet", methods = ['POST'])
def import_spreadsheet():
    if 'access_token' not in session:
        return redirect('/signin')
    spreadsheet_id = request.form["spreadsheet_id"]
    credentials = google.oauth2.credentials.Credentials(token=session['access_token'])
    service = build("sheets", "v4", credentials=credentials)
    sheets_api = service.spreadsheets()
    try:
        sheets = get_sheets(sheets_api, spreadsheet_id)
        data_by_sheets = {}
        for sheet in sheets:
            data = get_sheet_data(sheets_api, spreadsheet_id, sheet)
            data_by_sheets[sheet] = data
    except googleapiclient.errors.HttpError as e:
        return f"upload failure"
    dirpath = os.path.join("static", "uploads", spreadsheet_id)
    filepath = os.path.join(dirpath, "data.json")
    os.makedirs(dirpath, exist_ok=True)
    with open(filepath, "w") as file:
        json.dump(data_by_sheets, file)
    return "upload success! Really!"
