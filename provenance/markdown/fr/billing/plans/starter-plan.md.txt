# Plan Starter

> Découvrez les fonctionnalités du plan Starter, ses limitations et ce que vous pouvez créer gratuitement.

## Ce que vous obtenez

Le plan Starter vous donne tout ce dont vous avez besoin pour commencer à créer sur Replit. Créez des applications et publiez votre premier projet — le tout sans frais.

### Crédits quotidiens pour l'Agent

Les utilisateurs du plan Starter reçoivent des crédits quotidiens pour l'utilisation de l'Agent, jusqu'à un plafond mensuel. Ces crédits se réinitialisent chaque jour, vous donnant une nouvelle allocation pour travailler avec l'Agent chaque jour.

### Crédits mensuels pour les services cloud

Vous recevez également des crédits mensuels utilisables pour :

* [Bases de données (Production)](/fr/features/data-and-storage/development-and-production)
* [Stockage d'objets](/fr/features/data-and-storage/object-storage)
* [Publication (Autoscale, statique)](/fr/learn/projects-and-artifacts/replit-deployments)

Ces crédits se réinitialisent chaque mois.

### Construction Lite

Accès à la [Construction Lite](/fr/features/agent/agent-modes), une expérience de construction rapide et ciblée pour des modifications rapides et des changements précis avec l'Agent.

### Une application publiée gratuite

Obtenez {FreeDeployments} application publiée gratuite, que vous utilisiez la Construction Lite ou le Canevas de design. Ce lien publié sera automatiquement désactivé après 30 jours.

Votre application publiée inclura un badge « Fait avec Replit » contenant votre lien de parrainage unique. Si un autre utilisateur s'inscrit via ce lien depuis votre badge, vous recevrez des crédits de parrainage une fois que vous aurez mis à niveau vers un plan payant.

## Limitations

Les fonctionnalités suivantes nécessitent une mise à niveau vers Core :

### Construction complète

La [Construction complète](/fr/features/agent/overview/) permet à l'Agent de travailler de manière indépendante avec plus de puissance et d'autonomie. Les constructeurs du plan Starter ne peuvent utiliser que la [Construction Lite](/fr/features/agent/agent-modes). La Construction complète nécessite Core ou Pro.

### Conversion d'un design en artefact

La conversion d'un design du Canevas de design en artefact complet nécessite Core. Les constructeurs du plan Starter peuvent créer des designs et les déployer, mais la conversion en artefact avec des fonctionnalités backend nécessite une mise à niveau. Si vous souhaitez créer une application avec des fonctionnalités backend, essayez de commencer par la [Construction Lite](/fr/features/agent/agent-modes).

### Connecteurs tiers

Les connecteurs externes nécessitent Core. Cela inclut les intégrations avec des services comme Google, Stripe et d'autres API tierces (voir plus d'informations [ici](https://docs.replit.com/features/integrations/overview#connectors)).

### Intégrations IA Replit

[Les intégrations IA Replit](/fr/features/integrations/replit-ai-integrations) nécessitent Core.

### Suppression du badge « Fait avec Replit »

La suppression du badge « Fait avec Replit » de vos applications publiées nécessite Core. Les utilisateurs du plan Starter auront le badge affiché sur leurs déploiements.

### Applications publiées supplémentaires

Les utilisateurs du plan Starter obtiennent {FreeDeployments} application publiée gratuite. Les applications publiées supplémentaires au-delà de ce quota nécessitent Core ou Pro.

### Mode Plan

L'utilisation du Mode Plan nécessite Core. Le Mode Plan vous permet de réfléchir à des idées, de planifier le travail et de collaborer avec l'Agent Replit sans modifier le code ou les données de votre application.

### Tous les types d'artefacts

La création de types d'artefacts autres que les applications web et mobiles nécessite Core. Choisissez parmi une variété de types, notamment des visualisations de données, des diaporamas, des vidéos animées et plus encore. Voir [Projets](/fr/features/projects-and-artifacts/projects).

## Mise à niveau vers Core

Prêt pour plus ? Passez à Core pour débloquer :

* **Plus de stockage et de crédits mensuels** qui vous permettent également de payer à l'utilisation
* **Applications publiées illimitées** au-delà de votre première gratuite
* **Construction complète** pour un développement autonome
* **Connecteurs tiers** pour vous connecter à des services externes
* **Intégrations IA Replit** pour utiliser des modèles IA sans gérer vos propres clés API
* **Mode Plan** pour planifier les tâches avant de se lancer dans une construction
* **Suppression du badge Replit** pour un aspect professionnel
* Et plus encore
