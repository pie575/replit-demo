<div id="general-agent">
  ## Что такое General Agent?
</div>

General Agent — наиболее гибкий способ работы с Replit Agent. Не нужно заранее выбирать тип артефакта или ограничиваться созданием чего-то конкретного. Просто начните чат — создавайте CSV, генерируйте PDF, изучайте темы, а когда будете готовы, создавайте полноценное приложение.

Основные возможности:

* **Без предварительного выбора**: начните работу, не выбирая тип артефакта
* **Любые результаты**: создание файлов (CSV, PDF, документов), исследования и разработка приложений
* **Коннекторы**: чтение и запись данных во внешних сервисах, таких как BigQuery, Linear, Slack, Notion, Amplitude, Segment и Hex
* **Постепенное расширение**: начните с простого чата и постепенно переходите к созданию полноценного приложения

<div id="general-agent-2">
  ## Как получить доступ к General Agent
</div>

Доступ к General Agent можно получить несколькими способами:

1. **Перед вводом промпта выберите «General» на главной странице Replit**
2. **Откройте существующий проект** и начните чат с Agent
3. **Выберите любой [шаблон для разработчиков](https://replit.com/templates)** — General Agent автоматически включён во все шаблоны для разработчиков
4. **Импортируйте проект из [GitHub](/ru/ja/build/import-from-providers)** — General Agent автоматически добавляется к проектам, импортированным из GitHub

<div id="general-agent-3">
  ## Как использовать General Agent
</div>

<div id="section">
  ### Просто начните чат
</div>

Откройте проект и начните чат. Не нужно заранее решать, что именно вы будете создавать — Agent работает в контексте текущего проекта и справится с любой задачей.

**Примеры промптов:**

* «Кратко изложите основные тезисы этого документа»
* «Создайте CSV со 100 компаниями с наибольшей выручкой»
* «Какие 5 самых приоритетных тикетов в Linear?»
* «Настройте проект на Vue.js с использованием TypeScript»

Agent может работать с файлами, созданными в ходе сессии, формировать результат в виде одного файла и запускать код в процессе рассуждений — и всё это ещё до того, как вы решите что-либо создавать.

<div id="section-2">
  ### Подключение внешних сервисов
</div>

Подключите инструменты, чтобы Agent мог напрямую читать и записывать данные:

1. Перейдите в раздел **Коннекторы** в настройках проекта
2. Подключите сервис (BigQuery, Linear, Slack, Notion, Amplitude, Segment, Hex и другие)
3. Попросите Agent прочитать или записать данные

**Примеры промптов с коннекторами:**

* «Какие открытые тикеты есть в Linear?»
* «Сделай сводку сегодняшних сообщений в канале #engineering в Slack»
* «Получи из BigQuery данные о продажах за прошлый месяц»
* «Покажи предстоящие события в календаре»
* «Создай в Linear новый тикет по ошибке в онбординге»
* «Отправь сводку в канал #engineering в Slack»

<div id="section-3">
  ### От чата к полноценному приложению
</div>

Когда будете готовы приступить к работе, просто скажите об этом. Agent плавно переходит от лёгкой беседы к созданию приложения — не нужно начинать всё заново или переключать контекст.

* «Сделай из этого веб-приложение»
* «Создай приложение на основе этих данных»
* «Создай дашборд с этими метриками»
* «Настрой CLI-инструмент на Rust»

Начать можно неформально — изучить тему, сформировать отчёт или исследовать данные, а затем в нужный момент перейти к созданию полноценного приложения.

<div id="section-4">
  ## Что можно создать
</div>

* **Интеллектуальная работа**: проводите исследования, готовьте сводки и анализ без создания приложения
* **Результат в одном файле**: CSV, PDF, документы, экспорт данных, форматированные отчёты
* **Приложения для работы с данными**: выполняйте запросы к подключённым сервисам и визуализируйте результаты на дашборде
* **Любые фреймворки и языки**: Angular, Vue, Svelte, Rust, Go, C#, Python tkinter, игры на Godot, инструменты командной строки и многое другое
* **Полностековые приложения**: когда будете готовы, создайте полноценное приложение на основе контекста чата

<div id="section-5">
  ## Чего ожидать
</div>

General Agent предлагает больше возможностей и гибкости, но результаты могут быть не всегда одинаковыми:

* **Настройка за один шаг**: Agent может настроить всё сразу
* **Итеративная совместная работа**: для сложных настроек может потребоваться несколько итераций
* **Технические ограничения**: некоторые технологии могут поддерживаться в среде Nix не полностью

<Note>
  В отличие от стандартного Agent с предварительно настроенной средой, General Agent настраивает собственную среду и команды на основе вашего запроса. Когда приложение будет готово к развёртыванию, вам может потребоваться попросить его настроить публикацию.
</Note>

<div id="section-6">
  ## Часто задаваемые вопросы
</div>

<Accordion title="Может ли Agent видеть другие проекты?">
  Нет. Каждый чат ограничен одним проектом. Проект A и проект B не могут обмениваться данными друг с другом.
</Accordion>

<Accordion title="Почему до сих пор нет доступа к внешним инструментам?">
  Сначала нужно подключить сервис через коннектор. После подключения Agent сможет читать и записывать данные сервиса, но по умолчанию доступа у него нет.
</Accordion>

<Accordion title="Какие коннекторы доступны?">
  Сейчас поддерживаются: BigQuery, Linear, Slack, Notion, Amplitude, Segment, Hex и другие. Новые коннекторы добавляются регулярно.
</Accordion>

<Accordion title="Нужны ли коннекторы для работы с General Agent?">
  Нет, коннекторы необязательны. General Agent можно использовать для интеллектуальной работы, создания файлов и разработки приложений без внешних подключений.
</Accordion>
