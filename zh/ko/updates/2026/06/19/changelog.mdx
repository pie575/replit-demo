<div id="claude-replit">
  ### 在 Claude 中使用 Replit
</div>

Replit 现已支持作为连接器在 Claude 中使用。只需连接一次，你就可以在与 Claude 的对话中直接创建、更新 Replit 应用并向其提问。你还可以在 Claude Design 中直接将设计发送到 Replit，它会以可运行的应用形式打开，Agent 会随即制定计划，将其打造成完整的产品。

<div id="mcp-apollo-black-forest-labs">
  ### 新增 MCP 服务器：Apollo 和 Black Forest Labs
</div>

一键式 MCP 目录新增了两个服务器。连接 **Apollo**，即可在与 Agent 的对话中调研客户和联系人信息，并搭建外呼名单。连接 **Black Forest Labs**，无需离开项目即可生成和编辑 FLUX 图像。

前往 [MCP 列表](/zh/ko/features/mcp/overview)了解更多。

<div id="voice-mode">
  ### Voice Mode
</div>

现在，你可以直接用语音描述想要构建的内容。点击 Agent 聊天框中的麦克风图标，说出你的提示词，Replit 会将语音转换为可编辑的文本。检查文本，按需修改，然后像发送普通消息一样发送即可。所有 Replit 套餐均可使用 Voice Mode。

<div id="enterprise">
  ## 团队与 Enterprise
</div>

<div id="enterprise-2">
  ### 邀请外部访客加入 Enterprise 工作区
</div>

Enterprise 管理员现在无需通过身份提供商，即可将外部协作者以 Guest 身份邀请到工作区。只要把某个应用共享给外部邮箱，对方即可作为 Guest 加入，并且仅能访问该应用。Guest 会集中显示在专用表格中，方便你查看他们可访问哪些应用，并随时撤销访问权限。
