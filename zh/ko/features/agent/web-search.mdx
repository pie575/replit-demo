Web Search 可帮助你查找最新的软件包、工具和信息，从而确保应用遵循最新的最佳实践，结果也更准确。

<div id="section">
  ## 功能
</div>

借助 Agent 的 Web Search，构建能够利用最新信息的应用程序，无需再手动调研和收集数据。无论是制作展示金融数据的仪表板，还是搭建呈现近期初创公司上线动态的网站，Web Search 都能确保你的应用反映真实情况。

Agent 可以执行的 Web Search 操作：

* **搜索**：在互联网上查找最新信息、最新文档和实时数据
* **获取内容**：从特定网站和 URL 中提取详细信息
* **来源引用**：准确了解 Agent 从何处获取信息，便于验证和引用

<div id="section-2">
  ## 使用方法
</div>

Web Search 已内置于 Agent 中，无需单独开启。只需描述你想构建的内容，Agent 会自动判断何时需要检索最新信息。在提示词中加入“搜索一下”“帮我调研”“使用 Web Search”等关键词，即可引导 Agent 明确执行搜索。

<div id="section-3">
  ### 来源引用
</div>

当 Agent 使用 Web Search 时，会提供**来源引用**，明确标明信息的具体出处。你可以这样使用这些引用：

* **验证信息**：确认来源的可靠性与准确性
* **深入了解**：访问原始来源，获取更多背景信息
* **标注来源**：在应用中加入恰当的来源说明
* **追溯调研过程**：了解哪些信息影响了 Agent 的工作

<div id="section-4">
  ### 获取内容
</div>

Agent 可以从指定网站获取详细内容，为项目收集全面的信息。借助这一能力，Agent 可以：

* 通读整个网页并提取相关细节
* 处理文档和参考资料
* 从可信来源收集特定数据
* 将结构化信息整合到应用中
