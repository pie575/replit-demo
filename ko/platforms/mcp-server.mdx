Replit MCP는 [Model Context Protocol](https://modelcontextprotocol.io/)을 활용해 이미 사용 중인 AI 도구에서 Replit Apps를 생성, 검색, 확인, 업데이트, 게시할 수 있도록 지원합니다.

<div id="use-replit-in-chatgpt-claude-or-slack">

</div>

<div id="connect-an-mcp-client-directly">
  ## MCP 클라이언트 직접 연결하기
</div>

MCP 클라이언트에 Replit 네이티브 integration이 없는 경우 직접 연결 방식을 사용하세요.

| 속성                 | 값                                   |
| ------------------ | ----------------------------------- |
| **URL**            | `https://replit-mcp.com/server/mcp` |
| **전송 방식**          | Streamable HTTP                     |
| **Authentication** | 보호된 리소스 검색을 사용하는 OAuth              |

Streamable HTTP와 OAuth 인가를 지원하는 MCP 클라이언트에 서버 URL을 추가하세요. 클라이언트가 Replit의 보호된 리소스 메타데이터를 읽은 뒤, Replit에 로그인하라는 메시지를 표시합니다.

커스텀 OAuth 서버를 만들 필요는 없습니다. 클라이언트에 필요한 OAuth 메타데이터는 Replit MCP Server가 제공합니다.

새 앱을 만들거나, 공유받은 앱을 포함해 편집 권한이 있는 앱으로 작업할 수 있습니다.

<div id="set-up-replit-mcp">
  ### Replit MCP 설정하기
</div>

Codex와 Claude Code는 예시일 뿐입니다. 호환되는 MCP 클라이언트라면 어디에나 Replit MCP를 추가할 수 있습니다.

      <Step title="Replit 추가">

<div id="tools">
  ## Tools
</div>

| 도구                        | 필수 입력                         | 선택 입력                                                                     | 용도                                                                                                                                                                                                                               |
| ------------------------- | ----------------------------- | ------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `create_app_from_prompt`  | `appDescription`, `app_stack` | `userSpecifiedAppName`, `userQuotes`, `attachmentSummary`, `sourceReplId` | 새 앱을 시작합니다. `app_stack`에는 `react_website`, `mobile_app`, `design`, `slides`, `animation`, `data_visualization`, `3d_game`, `document`, `spreadsheet` 중 하나를 지정합니다. `sourceReplId`를 설정하면 빈 project가 아니라 기존 앱의 비공개 사본으로 새 앱을 시작합니다. |
| `search_apps`             | 없음                            | `query`, `url`, `updatedAfter`, `updatedBefore`, `limit`                  | 제목 키워드, URL 또는 최종 업데이트 시간으로 앱을 찾습니다. `limit`은 1에서 50까지 지정할 수 있습니다.                                                                                                                                                               |
| `resolve_app_by_name`     | `name`                        | 없음                                                                        | 제목이 정확히 일치하는 앱 하나를 찾습니다.                                                                                                                                                                                                         |
| `list_apps`               | 없음                            | `query`, `limit`                                                          | 편집 권한이 있는 앱을 최근 활동순으로 나열합니다. 기본 limit은 25, 최대는 50입니다.                                                                                                                                                                            |
| `ask_question`            | `replId`, `question`          | 없음                                                                        | 앱을 변경하지 않고 Agent에게 질문합니다.                                                                                                                                                                                                        |
| `update_app_using_prompt` | `replId`, `changeDescription` | `userQuotes`, `attachmentSummary`                                         | 기존 앱에 대한 Agent 업데이트를 시작합니다.                                                                                                                                                                                                      |
| `publish_app`             | `replId`                      | 없음                                                                        | 앱을 게시하거나 최신 changes를 다시 게시합니다.                                                                                                                                                                                          |
| `get_publish_status`      | `replId`                      | 없음                                                                        | 앱의 게시 여부, 현재 게시 status, public URL을 확인합니다.                                                                                                                                                                             |

<div id="troubleshooting">
  ## 문제 해결
</div>

| 문제                                  | 해결 방법                                                                        |
| ----------------------------------- | ---------------------------------------------------------------------------- |
| Replit이 인증을 요청하는 경우                 | MCP 클라이언트에서 OAuth sign-in flow를 다시 완료하세요.                                   |
| App을 찾을 수 없는 경우                     | 해당 app을 편집할 권한이 있는지 확인하세요. 그런 다음 URL로 검색하거나 `list_apps`로 일치하는 app 중에서 선택하세요. |
| 생성, 업데이트 또는 게시 요청이 아직 실행 중인 경우 | 잠시 기다린 후 다시 시도하세요. 게시의 경우 `get_publish_status`로 현재 결과를 확인하세요.        |
