title: "Importer"
description: "Découvrez comment importer des projets et des designs depuis d’autres outils vers Replit."
---

La fonctionnalité Import vous permet d’importer du code ou des designs existants dans vos Replit Apps et de poursuivre votre création avec Agent.

<div id="fontes-suportadas">
  ## Sources prises en charge
</div>

| Source                       | Ce que vous fournissez                          | Idéal pour                                                  |
| ---------------------------- | ----------------------------------------------- | ----------------------------------------------------------- |
| GitHub                       | URL du dépôt ou sélecteur de dépôt              | Importer des dépôts publics et privés                       |
| Bitbucket                    | URL du dépôt ou sélecteur de dépôt              | Importer des dépôts hébergés sur Bitbucket                  |
| Vercel                       | Dépôt GitHub associé à votre projet Vercel      | Migrer des apps Vercel                                      |
| Figma                        | URL du frame                                    | Transformer des designs en apps React                       |
| Bolt                         | Dépôt GitHub exporté depuis Bolt                | Migrer des projets Bolt                                     |
| Lovable                      | Dépôt GitHub exporté depuis Lovable             | Migrer des projets Lovable                                  |
| Base44                       | Dépôt GitHub exporté depuis Base44              | Migrer des projets Base44                                   |
| ZIP                          | Téléversement d’un fichier `.zip`               | Importer des fichiers de projet locaux                      |
| Feuille de calcul            | Fichier `.xlsx`, `.csv` ou URL Google Sheets    | Créer une app à partir de données de feuille de calcul      |
| Exportation précédente Agent | Dépôt GitHub exporté d’une application Agent précédente | Réimporter une application Agent précédente                         |
| Vide                         | Rien                                            | Utilisateurs avancés souhaitant un projet vierge sans Agent |

<Note>Replit vérifie la compatibilité avant de démarrer l’importation.</Note>

<div id="fluxo-padro-de-importao">
  ## Flux d’importation standard
</div>

1. Ouvrez [replit.com/import](https://replit.com/import).
2. Sélectionnez une source d’importation.
3. Connectez les comptes nécessaires.
4. Indiquez l’URL d’un dépôt, l’URL d’un frame ou un fichier `.zip`.
5. Ajoutez les Secrets ou variables d’environnement requis.
6. Sélectionnez **Import**, puis examinez l’App générée.

<div id="notas-sobre-as-fontes">
  ## Notes sur les sources
</div>

<div id="github">
  ### GitHub
</div>

* Utilisez l’importation rapide pour les dépôts publics avec `https://replit.com/github.com/<owner>/<repo>`.
* Utilisez l’importation guidée pour les dépôts publics et privés.
* Si votre dépôt est une application Agent exportée, Replit préserve la structure propre à Agent lors de l’importation.

<div id="bitbucket">
  ### Bitbucket
</div>

* Collez l’URL d’un dépôt Bitbucket ou connectez votre compte Bitbucket pour rechercher vos dépôts.
* La prise en charge d’Agent lors de l’importation peut être limitée par rapport aux projets hébergés sur GitHub.

<div id="figma">
  ### Figma
</div>

* Importez l’URL d’un seul frame Figma.
* Replit génère du code React, puis Agent vous aide à l’affiner.
* Pour de meilleurs résultats, utilisez des frames, la mise en page automatique et des noms de calques explicites.

<div id="vercel">
  ### Vercel
</div>

* Sélectionnez le dépôt GitHub associé à votre projet Vercel.
* Replit importe le code du projet et les configurations associées.
* Ajoutez les valeurs des variables d&#39;environnement lors de l&#39;importation.

<div id="bolt">
  ### Bolt
</div>

* Exportez votre projet Bolt vers GitHub avant de l’importer.
* Replit importe le code, les styles d’UI, les assets, la logique backend (si présente) et le schéma de la base de données (si présent).
* Les données Supabase et les valeurs des Secrets ne sont pas importées.
* Après l’importation, demandez à Agent d’ajouter des Secrets et de recréer les données de la base de données.

<div id="lovable">
  ### Lovable
</div>

* Exportez votre projet Lovable vers GitHub avant de l’importer.
* Replit importe le code, les styles d’UI, les assets, la logique de backend (le cas échéant) et le schéma de la base de données (le cas échéant).
* Les données Supabase et les valeurs des Secrets ne sont pas importées.
* Après l’importation, demandez à Agent d’ajouter des Secrets et de recréer les données de la base de données.

<div id="base44">
  ### Base44
</div>

* Exportez votre projet Base44 vers GitHub avant de l’importer.
* Replit importe le code, le design, les styles, les assets et la logique d’API.
* Le backend de Base44 (entités, agents, SDK), l’authentification et les données ne sont pas importés.
* Après l’importation, demandez à Agent de migrer les fonctionnalités spécifiques à Base44 dont vous avez encore besoin.

<div id="zip">
  ### ZIP
</div>

* Importez un fichier `.zip` dont la racine du projet est clairement définie.
* Replit importe les fichiers, les dépendances et les configurations d’exécution courantes.
* Les valeurs des secrets existants, les domaines et les données de base de données ne sont pas importés.

<div id="planilha">
  ### Feuille de calcul
</div>

* Importez un fichier Excel (`.xlsx`) ou CSV, ou collez l’URL publique d’une feuille Google Sheets.
* Agent lit la structure de votre feuille de calcul et crée une app full-stack avec une base de données alimentée par vos données.
* Inclut une UI pour consulter, rechercher et gérer vos enregistrements.

<div id="exportao-anterior-do-agent">
  ### Exportation précédente d’Agent
</div>

* Réimportez une application Agent et précédemment exportée depuis un dépôt GitHub.
* Replit préserve la structure propre à Agent (code, schéma de base de données, fonctionnalité backend).
* Les données de la base de données et les secrets ne sont pas importés.

<div id="vazio">
  ### Vide
</div>

* Commencez avec un projet entièrement vide — sans Agent, sans choix de framework ni code initial généré.
* Idéal pour les utilisateurs avancés qui souhaitent garder un contrôle total sur la configuration du projet.

<div id="limitaes">
  ## Limites
</div>

* Les données de la base de données existante ne sont pas migrées.
* Certaines dépendances complexes ou propriétaires peuvent nécessiter une configuration manuelle.
* Les projets volumineux peuvent nécessiter plus de temps de traitement.

<div id="melhores-prticas">
  ## Bonnes pratiques
</div>

* Supprimez les identifiants sensibles avant l’importation.
* Gardez une structure organisée dans le projet source.
* Vérifiez les dépendances et exécutez les commandes après l’importation.
* Testez les principaux flux avant la publication.

<div id="soluo-de-problemas">
  ## Dépannage
</div>

Si l’importation échoue, vérifiez d’abord les éléments suivants :

* **Erreurs de compatibilité** : vérifiez les fichiers de projet requis et les frameworks pris en charge.
* **Erreurs d’accès** : confirmez les autorisations du dépôt ou de la source.
* **Erreurs de traitement** : réessayez après avoir simplifié la structure du projet ou réduit sa taille.

Si les problèmes persistent, consultez le [Replit Community Hub](https://replit.com/community) ou [contactez l’assistance](https://replit.com/support).

<div id="faturamento">
  ## Facturation
</div>

Les importations nécessitant un travail de migration par l’Agent peuvent consommer des crédits. L’utilisation des crédits dépend de la complexité du projet.
