Les solutions de stockage flexibles de Replit vous permettent d’ajouter rapidement le stockage de données adapté à votre application. Vous pouvez utiliser les bases de données ou le stockage d’objets de Replit pour les applications ayant les besoins suivants, et Agent peut configurer et intégrer automatiquement ces deux solutions :

* Des jeux qui doivent stocker des informations sur les joueurs, comme leur progression ou leurs meilleurs scores
* Des plateformes de contenu qui gèrent des fichiers multimédias

<div id="replit">
  ## Options de stockage et de bases de données de Replit
</div>

Replit propose les options de stockage de données suivantes :

* **Base de données** : permet de stocker des données structurées, telles que des profils d&#39;utilisateurs, des scores de jeux et des catalogues de produits.
  Vous pouvez stocker et récupérer des données en fonction des relations entre les attributs et les points de données.

* **Stockage des applications** : permet de stocker des données non structurées, telles que des images, des vidéos et des documents.
  Vous pouvez stocker et récupérer des fichiers volumineux et des données binaires.

<div id="section">
  ### Comparaison entre le stockage des applications et les bases de données
</div>

|                           | Base de données                                                           | Stockage des applications                                                   |
| ------------------------- | :------------------------------------------------------------------------ | :-------------------------------------------------------------------------- |
| **Type de données idéal** | Données structurées et relationnelles                                     | Fichiers volumineux (images, vidéos, documents)                             |
| **Modèle de données**     | Tables, lignes, colonnes                                                  | Buckets, fichiers                                                           |
| **Langage de requête**    | SQL                                                                       | API REST                                                                    |
| **Client**                | Clients compatibles avec PostgreSQL et ORM                                | SDK Replit et bibliothèques clientes GCS                                    |
| **Modèle de facturation** | Facturation en fonction du temps de calcul et de l&#39;espace de stockage | Facturation en fonction de la bande passante et de l&#39;espace de stockage |

<div id="project-editor">
  ### Outils du Project Editor
</div>

Découvrez les outils Replit suivants pour configurer et gérer le stockage des données de votre application :

<CardGroup>
  <Card title="Base de données" href="/fr/ko/features/data-and-storage/sql-database" icon="database">
    Idéale pour les données structurées et la modélisation des relations entre elles.
    Repose sur une base de données PostgreSQL entièrement gérée qui évolue avec votre application.
  </Card>

  <Card title="stockage des applications" href="/fr/ko/features/data-and-storage/object-storage" icon="bucket">
    Idéal pour les données non structurées et les fichiers volumineux tels que les images, les vidéos et les documents.
    Repose sur Google Cloud Storage (GCS) pour offrir une haute disponibilité et une grande évolutivité. Agent peut configurer automatiquement le stockage des applications avec une authentification avancée et un contrôle d’accès.
  </Card>
</CardGroup>

<div id="section-2">
  ## Cas d’utilisation
</div>

Les exemples suivants montrent comment les outils de base de données et de stockage d’objets peuvent accompagner les applications Replit.

<div id="e">
  ### Application e-commerce
</div>

Stockez les informations sur les produits, les profils clients et l’historique des commandes dans une base de données.
Utilisez des requêtes SQL pour filtrer les produits par catégorie, rechercher des articles et gérer les commandes clients.

<div id="section-3">
  ### Application de partage de fichiers
</div>

Utilisez le stockage des applications pour partager des fichiers volumineux tels que des images, des vidéos et des documents.
Utilisez le SDK de stockage des applications Replit pour téléverser, télécharger et déplacer des fichiers.
