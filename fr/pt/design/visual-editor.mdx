<div id="o-que-o-visual-editor">
  ## Qu&#39;est-ce que le Visual Editor ?
</div>

Le Visual Editor vous permet de modifier concrètement votre interface en cliquant directement sur les éléments. Il fonctionne aussi bien dans le [canvas](/fr/pt/design/canvas) de Replit Design que dans le Preview : vous éditez ainsi vos maquettes et vos applications en cours d&#39;exécution de la même manière.

Les modifications simples — changements de texte, ajustements de couleur, réglages d&#39;espacement — mettent directement à jour le code source, sans consommer de crédits d’IA. Pour les changements qui impliquent une complexité cachée, le Visual Editor confie automatiquement la tâche à l&#39;Agent.

Concepts clés :

* **Modifications déterministes** : les changements simples (texte, couleurs, espacement) sont appliqués directement au code source, sans passer par un cycle de l&#39;Agent
* **Aucun coût en crédits** : les modifications directes ne consomment pas de crédits d’IA — seuls les changements complexes passent par l&#39;Agent
* **Double contexte** : le fonctionnement est identique dans les frames du canvas et dans le Preview
* **Synchronisation avec le code source** : chaque modification met à jour instantanément le code source sous-jacent

<Note>
  Le Visual Editor est actuellement disponible uniquement sur les **navigateurs web**. Il n&#39;est pas compatible avec l&#39;application mobile ni avec l&#39;application de bureau.
</Note>

<div id="como-usar-o-visual-editor">
  ## Comment utiliser Visual Editor
</div>

<div id="editando-no-canvas">
  ### Édition sur le canvas
</div>

Sélectionnez l&#39;outil **Edit** dans la barre d&#39;outils, puis cliquez sur un élément quelconque à l&#39;intérieur d&#39;un frame. L&#39;élément est mis en surbrillance avec une étiquette qui l&#39;identifie, et le panneau du Visual Editor s&#39;ouvre à droite en affichant les propriétés modifiables de cet élément : contenu, mise en page, couleur et bordure. Ajustez-les, puis sélectionnez **Save edits** pour les appliquer ou **Discard** pour les abandonner.

Les propriétés affichées dépendent de l&#39;élément sélectionné : les éléments de texte proposent des contrôles de police, les images la source et le téléversement, et les conteneurs des contrôles de mise en page.

<div id="editando-no-preview">
  ### Modification dans le Preview
</div>

Vous bénéficiez de la même expérience de modification dans votre application en cours d’exécution.

<Steps>
  <Step title="Sélectionnez un élément">
    Cliquez sur n’importe quel élément dans le Preview pour commencer à le modifier.
  </Step>

  <Step title="Effectuez vos modifications">
    Modifiez le texte directement, ajustez les couleurs à l’aide du sélecteur, modifiez l’espacement avec les contrôles de style ou remplacez des images.
  </Step>

  <Step title="Enregistrez">
    Cliquez sur Enregistrer pour mettre à jour le code source. Les modifications simples sont appliquées directement, sans consommer de crédits d’IA. Si la modification est complexe, le Visual Editor envoie des métadonnées ciblées à l’Agent pour obtenir de l’aide.
  </Step>
</Steps>

<div id="edio-de-texto">
  ### Édition de texte
</div>

Cliquez sur un élément de texte et tapez directement pour le modifier. Si le texte correspond à une chaîne dans votre code source, la modification est appliquée immédiatement.

<div id="ajustes-de-cor">
  ### Ajustements de couleur
</div>

Utilisez le sélecteur de couleurs pour ajuster la couleur du texte et de l&#39;arrière-plan. Saisissez le nom d&#39;une couleur, par exemple « violet », dans le champ, ou utilisez la pipette pour choisir une couleur n&#39;importe où sur votre écran.

<div id="mudanas-de-estilo">
  ### Modifications de style
</div>

Ajustez les espacements internes, les marges et la mise en page des éléments à l’aide de commandes intuitives.

<div id="controles-de-layout">
  ### Contrôles de mise en page
</div>

Le Visual Editor regroupe les contrôles en sections claires pour vous aider à trouver plus vite ce dont vous avez besoin : **Text**, **Layout**, **Color** et **Border**. (La section **Image** apparaît également lorsque vous sélectionnez un élément d&#39;image.)

La section **Layout** vous permet d&#39;ajuster le positionnement des éléments enfants à l&#39;intérieur d&#39;un conteneur, sans passer par l&#39;Agent. Sélectionnez un conteneur flex, développez Layout, et vous disposez des contrôles suivants :

* **Alignment** : un sélecteur de points 3×3 qui définit où les éléments se placent le long des deux axes à l&#39;intérieur du conteneur.
* **Direction** : deux boutons fléchés qui disposent les éléments enfants en ligne ou en colonne.
* **Gap** : une valeur en pixels pour l&#39;espace entre les éléments. L&#39;icône située à côté du champ change selon la direction actuelle, afin que vous sachiez toujours si vous ajustez l&#39;espacement horizontal ou vertical. Juste à côté, une icône fléchée active ou désactive l&#39;option **Distribute space between items**, qui répartit les éléments enfants vers les bords opposés du conteneur.
* **Outer space** : des champs pour l&#39;espace à l&#39;extérieur de l&#39;élément (un champ par côté, avec une bascule de lien pour verrouiller les quatre côtés en une seule fois).
* **Inner space** : des champs pour l&#39;espace à l&#39;intérieur de l&#39;élément sur chaque axe, avec une bascule de lien pour les deux axes à la fois.

La section Layout n&#39;apparaît que si au moins un contrôle de mise en page s&#39;applique à l&#39;élément sélectionné. Les nœuds de texte simples, dépourvus de propriétés d&#39;espacement ou de mise en page, masquent entièrement la section, afin que l&#39;éditeur reste compact.

<div id="atualizaes-de-imagem">
  ### Mises à jour des images
</div>

Sélectionnez des images pour remplacer leurs URL ou importer vos propres fichiers, avec des aperçus instantanés.

<div id="o-que-voc-pode-fazer">
  ## Ce que vous pouvez faire
</div>

* **Corrections rapides de texte** : mettez à jour les textes, libellés et titres sans ouvrir le moindre fichier de code source
* **Exploration des couleurs** : testez différentes palettes en cliquant et en ajustant, sans avoir à chercher la bonne règle CSS
* **Ajustements de mise en page** : affinez visuellement les marges internes, les marges externes et l&#39;espacement au lieu de deviner des valeurs en pixels
* **Remplacement d&#39;images** : remplacez les images génériques par vos propres ressources en un clic et un import
* **Itération de design** : ajustez rapidement les frames du Canvas pour comparer des directions visuelles, sans allers-retours avec l&#39;Agent

<div id="perguntas-frequentes">
  ## Questions fréquentes
</div>

<Accordion title="Les modifications dans le Visual Editor consomment-elles des crédits d’IA ?">
  Les modifications simples et déterministes — changements de texte, choix de couleurs, ajustements d’espacement — ne consomment pas de crédits d’IA. Elles mettent directement à jour le code source. Si le Visual Editor détecte une complexité cachée, il transmet la modification à Agent, qui utilise alors des crédits.
</Accordion>

<Accordion title="Puis-je modifier des éléments qui apparaissent à plusieurs endroits ?">
  Oui. Sélectionner un élément rendu dans une boucle ou réutilisé dans plusieurs composants met en évidence et met à jour toutes les instances à la fois.
</Accordion>

<Accordion title="Pourquoi ne puis-je pas modifier le texte de certains éléments ?">
  Il n’est pas possible de modifier directement dans le Visual Editor le texte des éléments composites formés de plusieurs sous-éléments. Demandez à Agent dans le Chat d’effectuer ces modifications.
</Accordion>

<Accordion title="Comment trouver le code source d’un élément ?">
  Cliquez sur le libellé dans le coin supérieur gauche d’un élément sélectionné pour accéder à son emplacement dans le code source.
</Accordion>
