Le test des applications permet à Agent de tester l&#39;app que vous avez créée dans un véritable navigateur. Agent parcourt votre application comme le ferait un utilisateur réel : il clique et vérifie les fonctionnalités. Cette capacité d&#39;auto-test permet de s&#39;assurer que votre app fonctionne correctement et aide Agent à détecter et corriger les problèmes automatiquement.

Lorsque App Testing est activé, Agent décide périodiquement de procéder lui-même à un auto-test de l&#39;application, dès qu&#39;il estime que suffisamment de modifications ont été apportées. Agent ne teste pas à chaque message utilisateur : il détermine intelligemment les moments où un test apporte le plus de valeur.

<Note>
  App Testing est actuellement disponible pour les applications web full-stack JavaScript et Streamlit Python.
</Note>

<div id="section">
  ### Principaux avantages
</div>

* **Autonomie étendue** : permet à Agent de travailler plus longtemps sans intervention humaine
* **Meilleure qualité** : détecte et corrige les problèmes en amont pour créer des applications comportant moins d&#39;erreurs
* **Rentabilité** : réduit le besoin de sessions de débogage supplémentaires en détectant les problèmes dès la phase de développement
* **Revue interactive** : propose la lecture vidéo et la navigation par segment pour une analyse approfondie des résultats

<div id="section-2">
  ### Processus de test
</div>

Lorsque Agent décide de procéder à un auto-test, voici ce qui se passe :

1. **Aperçu du navigateur** : un aperçu du navigateur s&#39;affiche dans le panneau Agent
2. **Test visuel** : observez le curseur d&#39;Agent cliquer dans votre application pour en tester les fonctionnalités
3. **Simulation d&#39;un utilisateur réel** : Agent parcourt l&#39;application comme le ferait un véritable utilisateur et saisit des données fictives si nécessaire
4. **Analyse automatique** : Agent analyse les résultats des tests et identifie les éventuels problèmes
5. **Correction autonome** : Agent présente un résumé des tests et corrige automatiquement les problèmes rencontrés

<div id="section-3">
  ## Fonctionnalités principales
</div>

Agent parcourt votre application comme un véritable utilisateur et la teste intelligemment, notamment :

* **Validation de l&#39;interface utilisateur** : boutons, formulaires, navigation, éléments visuels
* **Vérification des fonctionnalités** : fonctions essentielles et parcours utilisateur
* **Tests d&#39;intégration** : appels d&#39;API, interactions avec la base de données, services tiers
* **Performance et accessibilité** : temps de chargement, réactivité, normes d&#39;accessibilité

<div id="section-4">
  ## Utilisation
</div>

App Testing se trouve dans les **paramètres avancés**, au sein du menu déroulant des paramètres d&#39;Agent de la zone de saisie du chat. Activez-le lorsque vous utilisez le mode Economy ou Power. Le mode Lite laisse App Testing désactivé.

<Note>
  App Testing fait partie des fonctionnalités autonomes d&#39;Agent et intègre une revue de code. Découvrez les autres [fonctionnalités
  d&#39;Agent](/fr/ko/features/agent/overview).
</Note>

<div id="section-5">
  ## Prendre le relais
</div>

Il arrive qu&#39;Agent se heurte à un obstacle et ait besoin de votre aide pour poursuivre les tests. Le cas le plus fréquent est la connexion à un compte utilisateur (Gmail, par exemple). Agent affiche alors une fenêtre contextuelle avec le bouton « Begin take over ».

<Frame>
  <img src="/assets/mirror/app-testing-takeover-6e0b0b56f4d0.png" alt="Interface de relais d'App Testing affichant les instructions de gestion des erreurs et des CAPTCHA ainsi que les boutons Ignorer et Begin take over" width="924" height="358" data-path="images/replitai/app-testing-takeover.png" />
</Frame>

En cliquant sur « Begin take over », vous accédez à l&#39;aperçu de test pour réaliser les étapes nécessaires, puis laisser Agent reprendre la main. Si Agent ne peut pas avancer sans votre aide, vous pouvez aussi cliquer sur « Ignorer » pour ignorer le relais et quitter App Testing. Sans réponse de votre part dans les 10 minutes, Agent poursuit comme si vous aviez cliqué sur « Ignorer ».

<div id="section-6">
  ### Comportement attendu
</div>

* **Option Ignorer** : au besoin, utilisez le bouton Ignorer pour passer le test et poursuivre le développement
* **Lecture vidéo interactive** : après le test, cliquez sur la vidéo pour revoir l&#39;intégralité de la session de test
* **Navigation par segment** : utilisez le curseur situé en bas pour accéder à un segment précis du test

<div id="section-7">
  ## Dépannage
</div>

**Les tests échouent de manière inattendue**

* Essayez d&#39;ignorer le test, puis de saisir à nouveau le prompt
* Recherchez du contenu dynamique susceptible d&#39;affecter le minutage des tests
* Vérifiez l&#39;exactitude de vos scénarios de test

**Couverture de test incomplète**

* Décrivez plus en détail les fonctionnalités de votre App
* Mentionnez explicitement les parcours utilisateur essentiels à tester

**App Testing ne fonctionne pas du tout ?**

* App Testing ne fonctionne actuellement qu&#39;avec les applications web[*](#how-app-testing-works)

<div id="section-8">
  ## Tarification et utilisation
</div>

App Testing est inclus dans le modèle de tarification à l&#39;effort d&#39;Agent et implique les considérations de coût importantes suivantes :

* **Basé sur l&#39;utilisation** : les tests sont facturés en fonction de l&#39;effort fourni (les tests les plus simples coûtent moins cher)
* **Coût et bénéfices** : les tests ont un coût, mais détecter les erreurs tôt évite des prompts supplémentaires et du travail additionnel de la part d&#39;Agent, ce qui réduit le coût global
* **Développement efficace** : l&#39;approche automatisée réduit le besoin de débogage manuel et de reprises

<Tip>
  **Des tests rentables** : bien qu&#39;App Testing génère des coûts d&#39;utilisation supplémentaires, il permet souvent de réaliser des économies globales en évitant des sessions Agent supplémentaires destinées à corriger des problèmes qui auraient pu être détectés lors des tests.
</Tip>

3. **Itérez** : appuyez-vous sur les retours des tests pour améliorer votre application
4. **Passez à l&#39;échelle** : appliquez App Testing à des projets plus vastes et plus complexes
