## Atualizações da plataforma

### Integração com Slack

O Agent agora integra com a API do Slack. Isso significa que você pode usar o Agent para criar aplicativos que:

* Postam mensagens
* Leem histórico

de/para todos os seus canais favoritos no Slack.

<Frame>
  <img src="/assets/mirror/slack-integration-1072c585c41e.png" alt="Integração com Slack" width="1640" height="739" data-path="images/changelog/2025-01-10/slack-integration.png" />
</Frame>

Envie o que você criar para o [Agent Showcase](https://forms.gle/qxpfr82wNpKsCdok9).

### Melhorias no Agent e no Assistant

* O Agent agora carrega mais rápido na página inicial para que você possa começar a criar mais rápido.
* Um popup flutuante agora fornece acesso rápido ao Assistant ao selecionar texto no Console e no Shell. Basta selecionar o texto e clicar no ícone do Assistant para fazer uma pergunta.

<Frame>
  <img src="/assets/mirror/ask-assistant-cd529bf4a0b1.png" alt="Perguntar ao Assistant" width="2532" height="1474" data-path="images/changelog/2025-01-10/ask-assistant.png" />
</Frame>

### Autocompletar bash no Shell

O Shell agora tem autocompletar! Pressione tab duas vezes para autocompletar um comando.

<Frame>
  <img src="/assets/mirror/tab-tab-6e4a56285881.webp" alt="Tab tab" width="720" height="405" data-path="images/changelog/2025-01-10/tab-tab.webp" />
</Frame>

### Correção do ecossistema Elixir

Problemas com as ferramentas mix do Elixir foram resolvidos; a linguagem agora funciona como esperado.

### Melhoria na UX de domínio personalizado

Agora você pode colar um URL no campo de domínio personalizado e o Replit extrai automaticamente o domínio para você.

## Teams e Enterprise

### Controles aprimorados de destaque de projeto

Agora é mais fácil destacar e retirar o destaque dos projetos públicos da sua organização!

<Frame>
  <img src="/assets/mirror/feature-on-profile-95b81a71e0d7.png" alt="Projeto em destaque no perfil" width="1836" height="644" data-path="images/changelog/2025-01-10/feature-on-profile.png" />
</Frame>

Agora você pode controlar o estado em destaque de um projeto diretamente do espaço de trabalho por meio do modal de informações do projeto e da tabela de índice de projetos.

<Frame>
  <img src="/assets/mirror/profile-preview-b8f2ecfed154.png" alt="Prévia do perfil" width="2126" height="1152" data-path="images/changelog/2025-01-10/profile-preview.png" />
</Frame>

Além disso, quando você destaca um projeto, você obtém uma prévia de como ele aparecerá no seu perfil público.
