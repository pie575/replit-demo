<div id="databricks-apps-integration">
  ### Интеграция с Databricks Apps
</div>

Разработчики Enterprise теперь могут создавать в Replit приложения, работающие с данными, и развертывать их напрямую в Databricks. Agent подключается к вашей среде Databricks и может изучать схему данных, при этом данные не покидают Databricks. Когда приложение будет готово, опубликуйте его напрямую в Databricks Apps. Запущенное приложение полностью размещается в Databricks и наследует аутентификацию Databricks, механизмы управления Unity Catalog и ваши существующие сетевые ограничения.

<Frame>
  <img src="/assets/mirror/databricks-app-template-333354ec6944.png" alt="В Workspace Replit выбран шаблон Databricks App из раскрывающегося списка Templates" width="1368" height="395" data-path="images/changelog/2026-04-10/databricks-app-template.png" />
</Frame>

Эта интеграция доступна организациям Enterprise с workspace Databricks. Подробнее — на [странице партнерства Replit x Databricks](https://replit.com/partners/databricks).

<div id="recreate-any-ui-from-a-screenshot">
  ### Воссоздайте любой UI по скриншоту
</div>

Вставьте скриншот в Agent и попросите его «создать это» или «воссоздать этот UI». Agent с высокой точностью воспроизводит дизайн за один проход — как для веб-приложений, так и для слайд-презентаций. Это удобно для повторения существующих дизайнов, воссоздания референсных UI или быстрого прототипирования по макету.

<div id="razorpay-payments-for-india">
  ### Платежи через Razorpay в Индии
</div>

Разработчики в Индии теперь могут оплачивать подписку через UPI и банковские карты с помощью Razorpay. Также поддерживаются электронные мандаты для регулярных подписок в соответствии с требованиями Резервного банка Индии. Если вы уже являетесь подписчиком в Индии, вскоре вы сможете перейти со Stripe на Razorpay на странице биллинга.

<div id="revenuecat-app-store-connect-sync">
  ### Синхронизация RevenueCat с App Store Connect
</div>

Интеграция RevenueCat теперь поддерживает автоматическую синхронизацию с Apple. Настройки встроенных покупок в RevenueCat автоматически синхронизируются с App Store Connect.

Подробнее о [подписках RevenueCat](/ru/core-concepts/monetization/revenuecat-subscriptions).

<div id="choose-where-your-app-runs-with-publishing-geography">
  ### Выберите регион, в котором будет работать ваше приложение
</div>

Разработчики с тарифами Core, Pro и Enterprise теперь могут выбирать регион публикации приложения. При публикации в определённом регионе вычислительные ресурсы, Database и Object Storage вашего приложения размещаются в нём совместно. Региональный прокси помогает снизить задержку для посетителей приложения.

Помимо Северной Америки теперь доступна Европа, а вскоре появятся Австралия, Южная Америка и Азия. Администраторы Enterprise также могут ограничить организацию одним регионом для соответствия нормативным требованиям.

<div id="past-invoices-in-usage-page">
  ### Предыдущие счета на странице использования
</div>

Теперь вы можете просматривать предыдущие счета прямо на странице **Использование** в настройках аккаунта. Выберите любой предыдущий расчётный период в раскрывающемся списке, чтобы увидеть подробную разбивку потребления по App.
