<div id="web-search-for-agent">
  ### Agent를 위한 Web Search
</div>

<Frame>
  <img src="/assets/mirror/web-search-6c28195531d4.jpg" alt="앱 개발을 위한 Web Search 결과와 source citations를 보여주는 Agent 인터페이스" width="1920" height="1080" data-path="images/replitai/web-search.jpg" />
</Frame>

이제 Agent가 [Web Search](/ko/core-concepts/agent/web-search)로 웹을 검색해 최신 정보를 가져옵니다. 최신 문서, 실시간 시장 데이터, 인터넷 곳곳의 정확한 정보를 활용해 앱을 만들어 보세요. 학습 데이터 시점의 한계는 이제 없습니다. 여러분의 앱은 언제나 가장 최신 정보를 사용합니다.

<div id="custom-agent-instructions">
  ### 사용자 지정 Agent 지침
</div>

<Frame>
  <img src="/assets/mirror/replitmd-65360844a148.jpg" alt="프로젝트 사용자 지정 옵션을 보여주는 replit.md 파일" width="1920" height="1080" data-path="images/replitai/replitmd.jpg" />
</Frame>

[replit.md](/ko/core-concepts/agent/replit-dot-md)로 Agent 사용 경험을 나에게 맞게 설정하세요. 이 전용 파일에서 코딩 스타일, project 선호 사항, context를 정의할 수 있습니다. Agent가 검증된 모범 사례에 따라 이 파일을 자동으로 생성하며, 원하는 workflow에 맞게 자유롭게 수정할 수 있습니다.

<div id="effort-based-billing">
  ### Effort-based billing
</div>

<Frame>
  <img src="/assets/mirror/effort-based-billing-d971548c7c39.png" alt="Agent 작업량에 따른 동적 가격 책정을 보여주는 Effort-based billing 인터페이스" width="2048" height="1424" data-path="images/changelog/2025-07-04/effort-based-billing.png" />
</Frame>

새로워진 [effort-based billing](/ko/billing/ai-billing)으로 더 똑똑해진 checkpoint 요금 체계를 경험해 보세요. 실제 Agent 작업량에 따라 가격이 결정되며, run마다 여러 개가 아닌 하나의 checkpoint만 생성됩니다.

  ### Teams App Store 경험
</div>

팀의 앱을 그 어느 때보다 편리하게 찾아보고 관리하세요. Deployments 페이지의 새로운 조직 &quot;App Store&quot; 경험에서는 즐겨 찾는 앱에 별표를 지정하고, 모든 deployments를 검색하고, 최근에 연 앱을 확인하고, 트래픽 양을 기준으로 인기 있는 deployments를 살펴볼 수 있습니다.
