我们在[欢迎使用 Replit](/zh/ja/build/welcome)中介绍过 Velocity——一款高端超级跑车租赁应用。目前，任何访问已发布 URL 的人都能查看所有预订。没人会匿名预订兰博基尼。让我们添加登录功能，让每位客户都能拥有专属的预订和已保存的车辆。

<div id="agent">
  ## 让 Agent 添加登录功能
</div>

Velocity 将使用 Clerk。借助 Replit 的 Clerk 集成，你可以获得应用专属的品牌化登录页面、仅存在于 Velocity 中的客户账户 (而非 Replit 账户) ，并完全掌控外观和使用体验——非常适合高端租赁品牌。Agent 会自动预配所有内容，因此无需注册 Clerk 控制台或粘贴密钥。

<AiPrompt>
  为 Velocity 添加登录功能，让每位客户都拥有自己的预订和已保存的车辆。<br />
  使用 Clerk Auth。<br />
  保持车辆浏览页面公开，让访客无需账户也能浏览车队。<br />
  要求用户在预订车辆或将车辆保存到收藏夹前登录。<br />
  登录后，在页眉显示客户姓名，并提供“我的预订”部分，仅显示该客户自己的预订。<br />
  添加退出登录按钮。<br />
  使用两位不同的客户为我提供测试清单。
</AiPrompt>

Agent 会为 Velocity 预配 Clerk 租户，添加登录组件，为预订流程设置登录保护，将每项预订关联到当前登录的客户，并添加退出登录功能。你可以在 Agent 聊天中查看构建进度。

<div id="2">
  ## 使用两个客户账户进行测试
</div>

一个账户不够——需要两个账户来证明预订数据彼此隔离。

1. 在 Preview 中打开 Velocity，无需登录即可浏览车辆。车队列表应仍会显示。
2. 点击车辆上的“Reserve”。应跳转到 Clerk 登录页面。
3. 使用你的电子邮箱注册并完成预订 (例如，预订 911 一个周末) 。
4. 登出。“My bookings”部分应消失，预订流程应再次要求你登录。
5. 在无痕窗口中打开 Preview，并使用另一个电子邮箱注册。预订另一辆车。
6. 返回第一个窗口并登录，确认只能看到自己的预订 (看不到第二位客户的预订) 。

如果两位客户都能看到相同的预订，说明预订尚未关联到当前登录的用户。请将具体症状告诉 Agent：

<AiPrompt>
  Velocity 中两位客户都能看到彼此的预订。<br />
  将每个预订和每辆已保存的车辆关联到当前登录的客户，以便每个人只能看到自己的内容。<br />
  向我展示如何使用两个测试账户进行验证。
</AiPrompt>

<div id="url">
  ## 发布到发布 URL 并登录
</div>

通过 Agent 聊天或 Publishing 磁贴重新发布 Velocity，然后在新标签页中打开发布 URL 并登录。Clerk 会分别预配 Development 和 生产环境 环境。Agent 会自动为已发布的应用配置 生产环境 认证信息，因此你可以立即通过发布 URL 登录。

Velocity 现在有了真实客户。每位客户都可以登录自己的预约车库，其他人无法查看。

<div id="section-2">
  ## 如果还需要更多帮助
</div>

* **整个应用都不可见：** 告诉 Agent 保持车辆浏览功能公开，仅保护预订和账户页面。
* **客户可以看到彼此的预订：** 告诉 Agent 将每笔预订和已保存的车辆与当前登录的客户关联。
* **可以在 Preview 中登录，但发布后无法使用：** 在新标签页中打开发布 URL，并将显示的确切错误告知 Agent。确认 Agent 正在配置生产环境的 Clerk 环境。
* **原型开发需要无需配置的快速登录：** Replit Auth 使用客户的 Replit 账户，无需您管理 Clerk 租户 — 请参阅 [Replit Auth](/zh/ja/features/auth-and-identity/authentication)。
