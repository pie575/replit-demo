title: "静态部署"
description: "了解如何使用静态部署发布静态网站和前端应用。"
---

静态部署会在云服务器上托管 Replit App 的 HTML、CSS、JavaScript 等静态文件。
服务器会自动采用缓存和扩缩策略，快速且经济地
分发内容。

静态部署非常适合以下场景：

* 营销着陆页
* 作品集网站
* 产品与 API 文档站点

<Note>
  静态部署与由 Agent 创建的 Replit App 不兼容。
  Agent 会自动生成需要后端服务器的全栈应用。对于 Agent
  创建的应用，请使用以下部署类型之一： - [Autoscale
  部署](/zh/ko/features/publishing/autoscale-deployments) - [Reserved VM
  部署](/zh/ko/features/publishing/reserved-vm-deployments)
</Note>

<div id="section">
  ## 功能
</div>

静态部署包含以下功能：

* **经济高效的托管**：只需按网站传输的数据量付费。
* **HTTP 路由选项**：配置响应标头、URL 重写和重定向。
* **自定义域名**：可以配置自定义域名，也可以通过 `<app-name>.replit.app` URL 访问应用。
* **自定义错误页面**：创建并提供自定义 404 错误页面。
* **监控**：查看日志并监控已发布应用的运行状态。

<div id="section-2">
  ## 使用方法
</div>

你可以在 Publishing Project Editor 工具中访问静态部署。

<Accordion title="访问静态部署的方法">
  在左侧的 **Tool dock** 中：

  1. 选择 <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="所有工具图标" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **所有工具**，查看 Project Editor 工具列表。
  2. 选择 <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Publishing 图标" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publishing**。
  3. 选择 **Static** 选项，然后选择 **Set up your published app**。

  在**搜索框**中：

  1. 选择顶部的 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 放大镜，打开搜索工具。
  2. 输入“Publishing”找到该工具，然后在搜索结果中选择它。
  3. 选择 **Static** 选项，然后选择 **Set up your published app**。
</Accordion>

<div id="section-3">
  ### 默认域名
</div>

为已发布的应用指定主机名中的子域名部分。发布后，你可以通过 `https://<subdomain>.replit.app` 访问已发布的应用。

如需了解如何使用自定义域名，请参阅[自定义域名](/zh/features/publishing/custom-domains)。

<div id="section-4">
  ### 비공개 배포
</div>

<Info>
  私有发布应用功能适用于 Pro 和 Enterprise 套餐。
</Info>

私有发布应用仅向你的 workspace 成员，或你邀请的特定用户和群组开放访问权限。
发布时，你可以选择 **Public**、**Password protected**、**Workspace only** 或 **Invite only** 访问方式。

如需了解如何设置私有部署，请参阅[应用访问](/zh/features/publishing/private-deployments/)。

<div id="section-5">
  ### 公开目录
</div>

指定 Replit App 中存放对外公开的静态文件的默认目录路径。
部署后，云主机会提供该目录下的所有页面和资源。

默认值 `/` 表示 Replit App 的根目录。

<div id="section-6">
  ### 构建命令
</div>

创建部署时，请指定要在 Replit App 的 Shell 中运行的构建命令。

例如，如果使用 <a href="https://gohugo.io/" target="_blank">Hugo</a> 生成静态网站，
可以使用 `hugo --minify` 命令生成文件并优化资源文件的大小。

<div id="section-7">
  ### 部署密钥
</div>

如果构建命令需要环境变量或密钥才能安全运行，请选择 **Add deployment secret** 进行添加。

例如，如果站点生成器需要 API 密钥才能生成静态站点，
可以按 `API_KEY=<密钥名称>` 的格式传入。
