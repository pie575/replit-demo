以下解答涵盖订阅管理。有关计划的完整详情，请参阅 [Core](/zh/pt/billing/plans/replit-core) 和 [Pro](/zh/pt/billing/plans/replit-pro)。

<AccordionGroup>
  <Accordion title="如何从 Core 升级到 Pro？两者有什么区别？">
    与 [Core](/zh/pt/billing/plans/replit-core) 相比，[Pro](/zh/pt/billing/plans/replit-pro) ({ProPlanPrice}/月) 还提供：

    * Turbo 模式
    * 最多 15 名开发者可使用共享积分
    * 分层积分。未使用的积分可结转 {ProCreditRolloverPeriod}
    * 28 天的数据库恢复窗口 (Core 为 7 天)
    * 优先支持

    如需升级，请打开 **设置 → 账单**，选择 Pro 计划并确认付款信息。要查看当前功能和价格对比，请参阅[价格页面](https://replit.com/pricing)。
  </Accordion>

  <Accordion title="如何取消订阅？">
    打开**设置 → 账单**，选择取消订阅选项，然后完成确认步骤。你可以继续使用当前计划的功能，直至当前计费周期结束；之后，你的账户将转为免费的 [Starter 计划](/zh/pt/billing/plans/starter-plan)。

    在转换前，请注意：已发布的应用可能会下线，自定义域名连接会被移除，存储空间也会缩减。请先下载所有想要保留的内容。如果你的订阅显示为 `past_due`，可能是付款失败所致——请先解决此问题，再取消订阅。
  </Accordion>

  <Accordion title="我的续费付款失败了——如何更新我的付款方式？">
    打开**设置 → 计费**，选择**更新付款方式**，然后添加或更新您的银行卡。保存后，Replit 会自动重试待处理的付款。

    如果问题仍然存在，请提供您的付款意向 ID (以 `pi_` 开头) ，[联系 Replit 支持](https://replit.com/support)。计费失败通知有时会进入垃圾邮件文件夹。
  </Accordion>

  <Accordion title="如何将订阅转移至其他电子邮件地址或账户？">
    订阅与您的 Replit 账户绑定，无法直接转移。如需在保留订阅的同时更改账户邮箱，请前往**设置 → 个人资料**，然后修改您的邮箱。

    如需将订阅转移到其他账户，请[联系 Replit 支持团队](https://replit.com/support)——此类情况将逐一处理。
  </Accordion>

  <Accordion title="我一个月内被扣了两次费——这是怎么回事？">
    一个月内出现两笔扣费通常由以下情况之一导致：

    * 订阅费用加上一笔达到开票限额的单独使用费
    * 此前失败的付款重试后成功
    * 有多个有效订阅

    要查看每笔扣费的具体内容，请打开 **设置 → 账户使用情况**，然后选择 **查看以前的发票**。如果仍有疑问，请[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="我更改了套餐，但新功能尚未启用，该怎么办？">
    计划变更通常会立即生效。如果新功能未显示：

    1. 使用 `Cmd+Shift+R` (Mac) 或 `Ctrl+Shift+R` (Windows) 强制刷新。
    2. 退出后重新登录。
    3. 打开 **设置 → 账单**，确认变更已完成——应显示您的新计划名称。

    如果账单页面显示的计划正确，但功能仍不可用，请[联系 Replit 支持团队](https://replit.com/support)，并提供您的用户名及您尝试使用的功能。
  </Accordion>

  <Accordion title="我可以暂停订阅，而不取消吗？">
    部分订阅者可以选择暂停订阅一个月，而不是取消订阅。如果您符合条件，在取消订阅时会看到此选项。暂停期间：

    * 您的下一笔付款将被跳过，且不会获得每月积分
    * 已发布的项目将继续保持活跃，协作者仍可访问
    * 符合条件的积分会累积，积分包仍可使用
    * Agent 和托管服务仍会按使用量计费

    **设置 → 账单**会显示**已暂停**徽章和暂停结束日期，您的订阅将在该日期自动恢复。您可以在计划暂停生效前取消暂停，但已生效的暂停无法提前结束。您只能暂停订阅一次。
  </Accordion>
</AccordionGroup>
