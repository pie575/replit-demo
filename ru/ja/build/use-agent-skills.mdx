Навыки обучают Agent новым подходам: предпочтительным шаблонам, особенностям библиотек, правилам дизайн-системы или решениям уже решённых проблем. Их можно прикреплять к сообщениям, устанавливать в проекты или выбирать в качестве основы для новых проектов.

<div id="section">
  ## Использование навыков в чате
</div>

Самый простой способ опробовать навык — прикрепить его к сообщению: установка не требуется.

<Frame>
  <img src="/assets/mirror/agent-skills-picker-ee4058454475.png" alt="Панель выбора навыков, открытая кнопкой + рядом с полем ввода чата. Отображается список навыков, включая Ad Creative, AI Recruiter, AI SDR и AI Secretary" width="723" height="529" data-path="images/replitai/agent-skills-picker.png" />
</Frame>

<Steps>
  <Step title="Откройте панель выбора навыков">
    Нажмите кнопку **+** рядом с полем ввода чата и выберите **Использовать навыки**.
  </Step>

  <Step title="Найдите и выберите навыки">
    Просматривайте навыки по категориям, таким как «Бизнес и финансы», «Креатив» и «Исследования и анализ». Выберите один или несколько навыков и прикрепите их к сообщению.
  </Step>

  <Step title="Отправьте сообщение">
    Введите и отправьте запрос. Agent использует выбранные навыки только для этого сообщения. В сообщении появятся метки навыков, по которым можно увидеть, какие навыки активны.
  </Step>
</Steps>

Например, прикрепите **Stock Analyzer** и попросите Agent подготовить отчёт по анализу акций или прикрепите **Deep Research**, чтобы Agent изучил тему и представил структурированные результаты.

<Tip>
  Навыки, прикреплённые к чату, ничего не устанавливают в проект. Их можно сразу использовать во всех проектах.
</Tip>

<div id="section-2">
  ## Создание проекта на основе навыка
</div>

При создании нового проекта можно выбрать в качестве отправной точки предварительно проверенный навык. Agent использует инструкции навыка для создания основы проекта.

<Steps>
  <Step title="Откройте меню выбора отправной точки">
    На экране создания нового проекта нажмите **+** и выберите **Использовать навык**.
  </Step>

  <Step title="Выберите навык">
    Ознакомьтесь с подобранными навыками, такими как **AI SDR**, **SEO Auditor**, **Ad Creative** и **Programmatic SEO**. Выберите тот, который соответствует типу приложения, которое вы хотите создать.
  </Step>

  <Step title="Опишите приложение">
    Расскажите Agent, что вы хотите создать. Agent с самого начала применит шаблоны и соглашения выбранного навыка при создании проекта.
  </Step>
</Steps>

<div id="section-3">
  ## Установка навыков в проект
</div>

Установите навык, чтобы Agent последовательно применял его во всех диалогах проекта. Установленные навыки сохраняются в каталоге `/.agents/skills` проекта и доступны во всех сеансах чата.

<div id="section-4">
  ### Установка через панель навыков
</div>

Откройте **панель навыков** в редакторе проекта, перейдите на вкладку **Discover** и найдите навыки от сообщества. Найдя нужный навык, нажмите **Установить** — он будет автоматически добавлен в проект.

<Frame>
  <img src="/assets/mirror/agent-skills-discover-732b2b0c488a.png" alt="Вкладка навыков Discover с доступными для поиска навыками сообщества и кнопками установки" width="2542" height="1850" data-path="images/replitai/agent-skills-discover.png" />
</Frame>

Например, при создании сайта-портфолио со сложными анимациями можно установить следующие навыки:

* **GSAP React** — обучает Agent анимациям, запускаемым при прокрутке, появлению текста и отрисовке SVG-путей
* **Tailwind design system** — предоставляет Agent паттерны Tailwind CSS для типографики, отступов и переходов между представлениями
* **Find skills** — обучает Agent находить и устанавливать новые навыки вместо вас

<Tip>
  Вы также можете установить навыки с помощью [npx skills CLI](https://github.com/vercel-labs/skills):

  ```bash theme={null}
  npx skills <skill> -a replit
  ```
</Tip>

<div id="section-5">
  ### Создание навыка из беседы
</div>

Самый естественный способ создать навык — в ходе беседы с Agent. После совместного решения проблемы или изучения новой библиотеки попросите Agent сохранить полученные знания:

<AiPrompt>
  Изучите лучшие практики интеграции GSAP с React и создайте навык для этого проекта.
</AiPrompt>

Agent использует весь контекст беседы, чтобы создать подробный файл навыка. Это особенно полезно после сеанса отладки, в ходе которого вы выработали общее понимание проблемы.

<div id="section-6">
  ### Написание собственных навыков
</div>

Для продвинутых сценариев создавайте навыки напрямую, следуя [спецификации Agent Skills](https://agentskills.io/specification). На боковой панели файлов включите параметр **Show hidden files**, откройте `/.agents/skills/` и создайте новый файл Markdown. Так вы получите полный контроль над тем, что известно Agent и как он действует.
