Import vous permet d’importer du code ou des designs existants dans vos Replit Apps et de poursuivre le développement avec Agent.

<div id="fontes-suportadas">
  ## Sources prises en charge
</div>

| Source                         | Ce que vous fournissez                                     | Idéal pour                                                          |
| ------------------------------ | ---------------------------------------------------------- | ------------------------------------------------------------------- |
| GitHub                         | URL du dépôt ou sélecteur de dépôt                         | Importer des dépôts publics et privés                               |
| Bitbucket                      | URL du dépôt ou sélecteur de dépôt                         | Importer des dépôts hébergés sur Bitbucket                          |
| Vercel                         | Dépôt GitHub associé à votre projet Vercel                 | Migrer des applications Vercel                                      |
| Figma                          | URL du frame                                               | Transformer des designs en applications React                       |
| Claude                         | Design envoyé depuis Claude                                | Transformer un design Claude en application interactive             |
| Bolt                           | Dépôt GitHub exporté depuis Bolt                           | Migrer des projets Bolt                                             |
| Lovable                        | Dépôt GitHub exporté depuis Lovable                        | Migrer des projets Lovable                                          |
| Base44                         | Dépôt GitHub exporté depuis Base44                         | Migrer des projets Base44                                           |
| ZIP                            | Téléversement d’un fichier `.zip`                          | Importer des fichiers de projet locaux                              |
| Feuille de calcul              | Fichier `.xlsx`, `.csv` ou URL d’une feuille Google Sheets | Construire une application à partir de données de feuille de calcul |
| Exportation précédente d’Agent | Dépôt GitHub exporté d’une application Agent précédente    | Réimporter une application Agent précédente                         |
| Vide                           | Rien                                                       | Utilisateurs avancés souhaitant un projet vierge sans Agent         |

  <Tab title="Lovable">
    ⏰ *Durée estimée : quatre minutes*

    Importez un projet Lovable dans Replit en l’exportant vers GitHub, puis en important ce dépôt.

    **Avant de commencer**

    * Un projet Lovable que vous pouvez exporter
    * Un compte GitHub connecté à Lovable
    * Un compte Replit

    **Étapes**

    1. Exportez votre projet Lovable vers GitHub.
    2. Ouvrez [replit.com/import](https://replit.com/import).
    3. Sélectionnez **Lovable**.
    4. Connectez votre compte GitHub.
    5. Sélectionnez le dépôt Lovable exporté.
    6. Sélectionnez **Importer**.

    * **Schéma de base de données** : structure des tables, le cas échéant

  <Tab title="GitHub">
    ⏰ *Temps estimé : deux minutes*

    Importez un dépôt GitHub dans Replit pour exécuter, tester et publier plus rapidement.

    **Avant de commencer**

    * Une URL de dépôt GitHub
    * L’accès au dépôt (public ou privé)
    * Un compte Replit

    **Option 1 : importation rapide**

    L’importation rapide fonctionne pour les dépôts publics.

    1. Copiez le chemin du dépôt après `github.com/`.
    2. Ouvrez `https://replit.com/github.com/<owner>/<repo>`.
    3. Appuyez sur Entrée pour démarrer l’importation.

    *Exemple*

    * URL GitHub : `https://github.com/exampleUser/my-app`
    * URL d’importation Replit : `https://replit.com/github.com/exampleUser/my-app`

    **Option 2 : importation guidée**

    L’importation guidée prend en charge les dépôts publics et privés.

    1. Ouvrez [replit.com/import](https://replit.com/import).
    2. Sélectionnez **GitHub**.
    3. Connectez votre compte GitHub.
    4. Choisissez un dépôt.
    5. Sélectionnez **Importer**.

    **Ce qui est importé**

    * Les fichiers et dossiers du dépôt
    * Les fichiers de dépendances
    * La configuration courante d’exécution et de build

    **Ce qui n’est pas importé**

    * Les valeurs de Secrets et les variables d’environnement existantes
    * Les services spécifiques à une plateforme qui ne s’exécutent pas sur Replit par défaut

    **Résolution des problèmes de connexion à GitHub**

    Si vous voyez `Failed to get repository, please re-authenticate with GitHub` ou si le menu déroulant des dépôts affiche `No repositories found`, le flux d’importation GitHub utilise une connexion distincte de celle figurant sur la page **Compte → Services connectés**. Vous reconnecter uniquement dans Services connectés ne corrigera pas le flux d’importation.

    <Steps>
      <Step title="Reconnecter GitHub dans les fournisseurs Git">
        Ouvrez la section **Fournisseurs Git** dans les paramètres de votre compte Replit, déconnectez GitHub, puis reconnectez-le depuis le même écran. Ensuite, vos dépôts personnels devraient apparaître dans le menu déroulant d’importation.
      </Step>

      <Step title="Approuver l’app Replit pour votre organisation GitHub">
        Si le dépôt appartient à une organisation GitHub, ouvrez [https://github.com/settings/applications](https://github.com/settings/applications), trouvez l’app OAuth Replit et accordez-lui l’accès à l’organisation dans les paramètres d’accès des applications tierces. Les administrateurs de l’organisation devront peut-être effectuer cette étape si vous n’en êtes pas propriétaire.
      </Step>

      <Step title="Réessayer l’importation">
        Ouvrez [replit.com/import](https://replit.com/import) et réessayez l’importation, depuis le menu déroulant des dépôts ou en collant l’URL du dépôt.
      </Step>
    </Steps>

  <Tab title="ZIP">
    ⏰ *Temps estimé : trois minutes*

    Importez un projet local en téléversant un fichier `.zip`.

    **Avant de commencer**

    * Un fichier `.zip` contenant votre projet, de 200 Mo ou moins
    * Un dossier racine de projet clairement identifié dans le fichier
    * Un compte Replit

    Si votre fichier zip dépasse 200 Mo, le formulaire d’importation le rejettera. Excluez les dossiers de dépendances et de build, comme `node_modules`, `.venv` ou `build`, afin de réduire sa taille. Replit réinstalle les dépendances pendant l’importation.

    **Étapes**

    1. Ouvrez [replit.com/import](https://replit.com/import).
    2. Sélectionnez **ZIP**.
    3. Téléversez votre fichier `.zip`.
    4. Ajoutez les Secrets et variables d’environnement demandés.
    5. Sélectionnez **Importer**.

    **Ce qui est importé**

    * Fichiers du projet et structure des répertoires
    * Fichiers de dépendances
    * Configurations d’exécution et de build pour Replit

    **Ce qui n’est pas importé**

    * Valeurs des variables d’environnement existantes
    * Domaines personnalisés
    * Services propres à la plateforme nécessitant une configuration manuelle
    * Données de base de données existantes
    * Configuration existante de connecteurs tiers

<div id="outras-fontes">
  ## Autres sources
</div>

<div id="bitbucket">
  ### Bitbucket
</div>

* Collez l’URL d’un dépôt Bitbucket ou connectez votre compte Bitbucket pour rechercher vos dépôts.
* La prise en charge par Agent lors de l’importation peut être limitée par rapport aux projets hébergés sur GitHub.

<div id="planilha">
  ### Feuille de calcul
</div>

* Téléversez un fichier Excel (`.xlsx`) ou CSV, ou collez l’URL publique d’un Google Sheets.
* Agent lit la structure de votre feuille de calcul et crée une application full-stack avec une base de données contenant vos données.
* Une interface est incluse pour consulter, rechercher et gérer vos enregistrements.

<div id="exportao-anterior-do-agent">
  ### Exportation précédente d’Agent
</div>

* Réimportez une app Agent précédemment exportée depuis un dépôt GitHub.
* Replit préserve la structure propre à Agent (code, schéma de base de données, fonctionnalités backend).
* Les données de la base de données et les secrets ne sont pas importés.

<div id="vazio">
  ### Vide
</div>

* Commencez avec un projet entièrement vide — sans Agent, sans framework sélectionné ni structure prédéfinie.
* Idéal pour les utilisateurs avancés qui souhaitent garder un contrôle total sur la configuration du projet.

<div id="limitaes">
  ## Limites
</div>

* Les données de bases de données existantes ne sont pas migrées.
* Les téléversements de fichiers ZIP sont limités à 200 Mo.
* Certaines dépendances complexes ou propriétaires peuvent nécessiter une configuration manuelle.
* Les projets volumineux peuvent prendre plus de temps à traiter.

<div id="boas-prticas">
  ## Bonnes pratiques
</div>

* Supprimez les identifiants sensibles avant l’importation.
* Veillez à ce que la structure du projet source reste claire.
* Vérifiez les dépendances et les commandes d’exécution après l’importation.
* Testez les principaux flux avant de publier.

<div id="soluo-de-problemas">
  ## Résolution des problèmes
</div>

Si l’importation échoue, vérifiez d’abord les points suivants :

* **Erreurs de compatibilité** : vérifiez les fichiers de projet requis et les frameworks pris en charge.
* **Erreurs d’accès** : vérifiez les autorisations du dépôt ou de la source.
* **Erreurs de traitement** : réessayez après avoir simplifié la structure du projet ou réduit sa taille.

Si les problèmes persistent, consultez le [Replit Community Hub](https://replit.com/community) ou [contactez l’assistance](https://replit.com/support).

<div id="faturamento">
  ## Facturation
</div>

Les importations nécessitant une migration effectuée par Agent peuvent consommer des crédits. L’utilisation de ces crédits dépend de la complexité du projet.
