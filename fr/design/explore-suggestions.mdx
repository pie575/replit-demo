Les suggestions sont au cœur de l’interface de Replit Design. Au lieu de vous retrouver devant une prompt box vide sans savoir quoi demander, sélectionnez un frame de Design et Replit Design vous propose quoi essayer ensuite. Chaque suggestion peut générer une nouvelle création en un seul clic.

<div id="how-suggestions-work">
  ## Comment fonctionnent les suggestions
</div>

Lorsque vous sélectionnez un frame de design généré, des suggestions s&#39;affichent à côté. Elles se basent sur ce que vous voyez, vous n&#39;avez donc pas besoin de maîtriser le vocabulaire du design pour les explorer. Cliquez sur l&#39;une d&#39;elles et Replit Design génère le résultat dans un nouveau frame ; l&#39;original reste inchangé.

<div id="what-suggestions-propose">
  ## Ce que proposent les suggestions
</div>

Les suggestions répondent à différentes questions d’exploration :

* **Un nouveau style** : le même design dans une autre direction, par exemple une variante éditoriale sombre ou une disposition différente.
* **Une extension** : une section ou une page que votre design laisse entrevoir, mais qu’il ne comporte pas encore, comme une section tarifaire ou une page de contact.
* **Un nouveau contexte** : votre design dans un autre contexte, par exemple dans une fenêtre d’affichage mobile.

<div id="explore-with-suggestions">
  ## Explorer avec des suggestions
</div>

Le cycle est volontairement court :

<Steps>
  <Step title="Sélectionner un frame généré">
    Cliquez sur n’importe quel frame de conception généré sur le Canvas.

    <Frame>
      <img src="/assets/mirror/ambient-select-frame-7147427722bd.png" alt="Un frame Design intitulé APEX X1 Exact Replica affichant une page d’accueil de supercar grise sur le Canvas" width="2000" height="1252" data-path="images/design/replit-design/ambient-select-frame.png" />
    </Frame>
  </Step>

  <Step title="Choisir une suggestion">
    Des suggestions apparaissent à côté du frame sélectionné, en fonction de ce que vous voyez. Examinez-les et cliquez sur l’une d’elles : vous n’avez rien à ajouter.
  </Step>

  <Step title="Agent le crée en un clic">
    Dès que vous cliquez, Agent commence à créer la suggestion sous la forme d’un nouveau frame à côté de l’original. Vos frames précédents restent sur le Canvas, vous ne perdez donc rien en explorant.

    <Frame>
      <img src="/assets/mirror/ambient-suggestion-building-9da4835557d2.png" alt="Un nouveau frame Design intitulé « Add Saturation on Scroll » s’affichant sous forme de disposition squelette avec un indicateur « Création en cours… », à côté du frame APEX X1 d’origine" width="2000" height="1252" data-path="images/design/replit-design/ambient-suggestion-building.png" />
    </Frame>
  </Step>

  <Step title="Observer les modifications">
    Le frame terminé apparaît à côté de l’original afin que vous puissiez les comparer côte à côte. Le panneau Chat résume les modifications.

    <Frame>
      <img src="/assets/mirror/ambient-suggestion-result-a50d1efa94c4.png" alt="Deux frames Design terminés côte à côte sur le Canvas, l’original APEX X1 Exact Replica et la variante Add Saturation on Scroll terminée, avec un résumé « Exécution terminée » dans le panneau Chat" width="2000" height="1189" data-path="images/design/replit-design/ambient-suggestion-result.png" />
    </Frame>
  </Step>

  <Step title="Appliquer le design retenu à votre application">
    Continuez à sélectionner et à créer des variantes jusqu’à ce qu’une piste vous convienne ; de nouvelles suggestions apparaissent pour chaque frame sélectionné. Le design retenu ne doit pas rester une maquette : sélectionnez-le, choisissez **Build…** dans sa barre d’actions, puis sélectionnez votre application existante sous **Appliquer à une création existante**. Agent réécrit le code de l’application pour qu’il corresponde au design, tout en laissant le frame sur le Canvas comme référence.

    <Frame caption="Le menu Build : appliquez le frame retenu à une application existante.">
      <img src="/assets/mirror/explore-variants-apply-b04b893252cd.png" alt="Le menu Build ouvert sur une variante sélectionnée avec deux options : « Créer ce design », qui crée un nouvel artefact, et « Appliquer à une création existante », qui répertorie l’artefact Website du projet" width="2000" height="1226" data-path="images/design/replit-design/explore-variants-apply.png" />
    </Frame>

    Consultez [Créer votre design](/fr/design/build-your-design) pour découvrir le flux complet, notamment comment créer une application à partir du frame. Pour peaufiner les détails avant de l’appliquer, [affinez-le avec Chat](/fr/design/chat-about-your-design).
  </Step>
</Steps>

<div id="tips">
  ## Conseils
</div>

* **Explorez des pistes, pas des étapes.** Les suggestions se ramifient : en suivre une ne vous engage à rien. Générez-en plusieurs et comparez-les sur le Canvas.
* **Ajoutez vos propres mots.** Les suggestions et le [Chat sur votre design](/fr/design/chat-about-your-design) fonctionnent de concert : cliquez sur les suggestions pour explorer différentes pistes, utilisez le Chat pour orienter précisément. Le Chat ne sert pas uniquement à peaufiner ; un message comme *« essayez la navigation à gauche »* ouvre aussi une nouvelle piste.
* **Changez de modèle pour une sensibilité différente.** Chaque modèle explore différemment ; consultez [Explorer avec différents modèles](/fr/design/explore-with-different-models).
