<div id="o-que-uma-visualizao-de-dados">
  ## Что такое визуализация данных?
</div>

Визуализация данных — это интерактивный дашборд или инструмент отчётности, который вы создаёте в диалоге с Agent. Опишите, что хотите визуализировать и где хранятся ваши данные, — Agent автоматически подберёт подходящие KPI, типы графиков и макеты и создаст полноценный дашборд по одному промпту.

Ключевые понятия:

* **Создание за один шаг**: опишите цель и источник данных — и Agent построит полноценный дашборд с подходящими графиками и метриками
* **Подключённые источники данных**: получайте данные из баз данных, [коннектор к хранилищу данных](/ru/pt/connectors/warehouses/overview), внешних API или загруженных файлов
* **Встроенные возможности**: каждый дашборд включает обновление, автообновление, экспорт в PDF, экспорт графиков в CSV и светлую/тёмную тему
* **Аналитическая сводка**: Agent формирует выводы на основе вашего запроса и полученных данных
* **Несколько artifact**: визуализации данных могут использовать общий бэкенд и базу данных с другими вашими artifact в [одном project](/ru/pt/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project)

<div id="como-usar-o-data-visualization">
  ## Как использовать Data Visualization
</div>

<div id="criando-a-partir-de-um-prompt">
  ### Создание по промпту
</div>

Выберите вкладку **App** на главной странице и опишите нужный вам дашборд. Agent распознаёт промпты, связанные с данными, и выбирает стек Data Visualization.

**Примеры промптов:**

* «Построй дашборд аналитики продаж, который отслеживает выручку по регионам»
* «Создай инструмент отчётности, который визуализирует наши ежемесячные метрики»
* «Построй дашборд по нашим данным о продажах из BigQuery с самыми успешными продуктами»
* «Подключись к Snowflake и создай дашборд аналитики оттока клиентов»

<div id="criando-a-partir-do-menu-suspenso">
  ### Создание через выпадающее меню
</div>

1. Перейдите на вкладку **App** на главной странице.
2. Откройте выпадающее меню с типом приложения.
3. Выберите **Data Visualization**.
4. Опишите дашборд или инструмент для работы с данными, который хотите создать.

<div id="conectando-se-a-data-warehouses">
  ### Подключение к хранилищам данных
</div>

Подключите визуализацию данных к BigQuery, Databricks или Snowflake через [коннекторы к хранилищу данных](/ru/pt/connectors/warehouses/overview), чтобы строить дашборды на основе уже имеющихся наборов данных.

При запросе данных из хранилища Agent использует параллельный мультиагентный поиск, чтобы изучить вашу схему и наборы данных. Это ускоряет исследование и помогает Agent подобрать подходящие таблицы и поля для дашборда.

Для начала настройте коннектор к хранилищу данных в разделе [Integrations](/ru/pt/features/integrations/overview) вашего проекта, а затем сообщите Agent, что именно вы хотите визуализировать.

<div id="adicionando-filtros-e-recursos">
  ### Добавление фильтров и функций
</div>

После того как Agent создаст дашборд, вы можете попросить его добавить фильтры, детализацию или другие интерактивные элементы. Например, попросите Agent добавить фильтр по диапазону дат, выбор региона или строку поиска.

<div id="exportando-e-compartilhando">
  ### Экспорт и обмен
</div>

* **Экспорт в PDF**: экспортируйте весь дашборд в PDF, чтобы поделиться им или просмотреть офлайн.
* **Экспорт графиков в CSV**: скачивайте данные отдельных графиков в виде CSV-файлов для дальнейшего анализа в таблицах или других инструментах.
* **Аналитический документ**: попросите Agent подготовить подробный аналитический документ на основе данных вашего дашборда.

<div id="o-que-voc-pode-construir">
  ## Что можно создать
</div>

* **Аналитические дашборды**: отслеживайте ключевые метрики — выручку, регистрации или вовлечённость — в динамике
* **Инструменты отчётности**: создавайте внутренние отчёты, которые заинтересованные стороны смогут фильтровать и изучать без прямого доступа к базе данных
* **Интерфейсы для исследования данных**: просматривайте наборы данных и выполняйте запросы к ним с наглядной обратной связью
* **Панели мониторинга**: выводите данные из API, баз данных или внешних сервисов в реальном или почти реальном времени

<div id="perguntas-frequentes">
  ## Часто задаваемые вопросы
</div>

<Accordion title="Какие источники данных можно подключить?">
  Вы можете извлекать данные из Replit Database вашего проекта, из коннекторов к хранилищам данных (BigQuery, Databricks, Snowflake), из внешних API или из загруженных файлов, например CSV. Подключения к хранилищам настраиваются через [Integrations](/ru/pt/features/integrations/overview).
</Accordion>

<Accordion title="Можно ли настроить внешний вид?">
  Да. Цвета, макеты и типографику можно настроить прямо в диалоге — попросите Agent привести оформление в соответствие с вашим брендом или доработать дизайн. Дашборды также поддерживают светлую и тёмную темы.
</Accordion>

<Accordion title="Анализирует ли Agent данные за меня?">
  После создания дашборда Agent формирует аналитическую сводку на основе вашего запроса и полученных данных. Вы также можете попросить подготовить более подробный аналитический документ.
</Accordion>

<Accordion title="Можно ли объединить визуализацию данных с другими типами artifact?">
  Да. Вы можете объединить визуализацию данных с [веб-приложением](/ru/pt/features/artifact-types/web-apps), [презентацией](/ru/pt/features/artifact-types/slide-decks) или другими типами artifact в [одном проекте](/ru/pt/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project). Они используют общий бэкенд и общую базу данных.
</Accordion>
