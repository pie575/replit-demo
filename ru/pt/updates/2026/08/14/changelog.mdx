<div id="migre-para-o-clerk-auth">
  ### Переход на Clerk Auth
</div>

Теперь вы можете перенести подходящее приложение с Replit Auth на Clerk Auth. Agent сначала переносит данные учётных записей и только затем обновляет код входа, поэтому пользователи, которые уже работают с приложением, не потеряют доступ к своим данным.

<div id="compartilhe-e-gerencie-skills-do-workspace">
  ### Делитесь навыками workspace и управляйте ими
</div>

Теперь любой участник workspace может создавать навыки и оставлять их приватными либо делиться ими с workspace. Общие навыки изначально отключены для остальных участников — каждый сам выбирает, какие из них включить. Администраторы могут управлять всеми навыками workspace и делать отдельные навыки обязательными для workspace. Обновлённая Библиотека навыков упрощает поиск навыков и управление ими.

Подробнее об [Agent Skills](/ru/pt/features/agent/skills).

<div id="teams-e-enterprise">
  ## Teams и Enterprise
</div>

<div id="admin-api-disponvel-em-beta">
  ### Admin API доступен в бета-версии
</div>

Администраторы аккаунтов Enterprise теперь могут создавать ключи API на новой вкладке **Developer** в разделе «Настройки» и использовать Admin API, чтобы:

* просматривать workspace, участников, группы пользователей, проекты и развёртывания;
* просматривать использование по участникам, проектам и workspace за произвольные периоды;
* просматривать и изменять бюджеты workspace, групп пользователей и отдельных участников.

Подробнее — в [документации Admin API](/ru/pt/teams/admin-api) и в [справочнике API](https://api.replit.com/docs).
