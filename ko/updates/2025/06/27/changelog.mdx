<div id="security-scanner-updates">
  ### Security scanner 업데이트
</div>

이번 대규모 Security Scanner 업데이트로 더 빠르고 똑똑해진 보안 검사를 경험해 보세요. 이제 검사 결과를 cache에 저장해 두고 코드가 변경될 때만 다시 실행하므로, 두 번째 검사부터는 훨씬 빠르게 끝납니다. 또한 새로운 무시 기능으로 보고 싶지 않은 보안 issues를 숨겨 두었다가 필요할 때 다시 찾아볼 수 있습니다.

<div id="agent-system-prompt-optimization">
  ### Agent system prompt 최적화
</div>

최신 시스템 개선 사항으로 더 빠르고 효율적인 Agent 상호작용을 경험해 보세요. 이제 Agent는 기대하시는 높은 품질의 결과는 그대로 유지하면서, 각 동작마다 2~3초 더 빠르게 task를 완료합니다.

<div id="new-app-creation-experience">
  ### 새로운 앱 생성 경험
</div>

새롭게 디자인된 생성 경험으로 더 나은 앱을 만들어 보세요! 이제 빌드하기 전에 앱을 시각적으로 확인하고 계획할 수 있어 개발 계획을 파악하고 디자인 방향을 다듬어 나가기가 한결 수월해집니다. 빠른 빌드 과정에 들어가기 전에 Agent가 무엇을 만들지 정확히 확인해 보세요.

  ### viewer seats를 위한 새로운 랜딩 페이지
</div>
