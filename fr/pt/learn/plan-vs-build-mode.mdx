Replit Agent propose deux modes d&#39;interaction : le **mode Planification** et le **mode Construction**. Utilisez-les ensemble pour réfléchir d&#39;abord à vos idées, puis les concrétiser en toute confiance.

<div id="o-que-o-modo-de-planejamento">
  ## Qu’est-ce que le mode Planification ?
</div>

Le [mode Planification](/fr/pt/features/agent/plan-mode) vous permet de réfléchir, de poser des questions et de planifier votre travail avec Agent, sans modifier votre code. Considérez-le comme une session de planification collaborative qui vous permet d’explorer librement vos idées.

Le mode Planification est idéal pour :

* **Réfléchir à des idées** : Explorez différentes approches avant de vous engager dans l’une d’elles
* **Décomposer des projets complexes** : Obtenez une liste de tâches structurée avant de commencer à développer
* **Apprendre et comprendre** : Posez des questions sur des technologies, des modèles ou votre code
* **Planifier l’architecture** : Concevez la structure de votre app avant d’écrire du code

<Info>
  En mode Planification, Agent lit votre projet et vous guide, mais n’apporte aucune modification à vos fichiers. Lorsque vous êtes prêt à implémenter, passez en mode Construction ou approuvez un plan pour commencer à développer automatiquement.
</Info>

<div id="o-que-o-modo-de-construo">
  ## Qu&#39;est-ce que le mode Construction ?
</div>

Le mode Construction est le mode par défaut dans lequel Agent écrit du code, modifie des fichiers et implémente des fonctionnalités directement dans votre projet. C&#39;est là que les idées prennent vie.

Utilisez le mode Construction lorsque vous êtes prêt à :

* **Créer de nouvelles fonctionnalités** : laissez Agent écrire le code de votre prochaine fonctionnalité
* **Configurer votre app** : installer des dépendances, paramétrer des bases de données et connecter des services
* **Corriger des problèmes** : laissez Agent déboguer et résoudre les problèmes de votre code
* **Refactoriser le code** : améliorer la structure et l&#39;organisation du code existant

<div id="usando-ambos-os-modos-juntos">
  ## Utiliser les deux modes ensemble
</div>

**Le mode Planification et le mode Construction donnent les meilleurs résultats lorsqu&#39;ils s&#39;enchaînent.** Commencez par planifier pour clarifier votre réflexion, puis lancez la construction avec une direction claire.

<Steps>
  <Step title="Commencez en mode Planification">
    Passez en mode Planification et décrivez ce que vous souhaitez construire. L&#39;Agent vous aide à définir les besoins, à suggérer des approches et à repérer les difficultés potentielles — le tout sans toucher à votre code.
  </Step>

  <Step title="Générer une liste de tâches">
    Demandez à l&#39;Agent de créer un plan de développement. Il découpera votre projet en tâches précises et concrètes, avec des priorités et des dépendances claires.

    <Frame>
      <img src="/assets/mirror/plan-mode-task-list-6adcdd56f689.png" alt="Liste de tâches générée avec priorités et dépendances" width="924" height="1180" data-path="images/replitai/plan-mode-task-list.png" />
    </Frame>
  </Step>

  <Step title="Réviser et affiner">
    Passez en revue le plan proposé. Posez des questions complémentaires, demandez des modifications ou explorez d&#39;autres approches. Itérez jusqu&#39;à ce que le plan corresponde à votre vision.
  </Step>

  <Step title="Commencer à construire">
    Lorsque le plan vous convient, sélectionnez **Commencer à construire**. L&#39;Agent bascule automatiquement en mode Construction et commence à mettre en œuvre les tâches approuvées.

    <Frame>
      <img src="/assets/mirror/plan-mode-selector-a4f6b14596fa.png" alt="Sélecteur de mode affichant les options mode Planification et mode Construction" width="918" height="224" data-path="images/replitai/plan-mode-selector.png" />
    </Frame>
  </Step>

  <Step title="Suivre la progression">
    Suivez la progression de l&#39;Agent au fil de son avancement dans la liste de tâches. Chaque tâche terminée crée un checkpoint, ce qui vous permet d&#39;examiner les modifications et d&#39;effectuer un rollback si nécessaire.
  </Step>
</Steps>

<div id="quando-usar-cada-modo">
  ## Quand utiliser chaque mode
</div>

<CardGroup cols={2}>
  <Card title="Utilisez le mode Planification lorsque" icon="lightbulb">
    * Vous démarrez un nouveau projet et avez besoin d&#39;orientation
    * Vous souhaitez explorer différentes approches
    * La tâche est complexe et doit être découpée
    * Vous voulez comprendre avant d&#39;implémenter
    * Vous n&#39;êtes pas certain de la meilleure solution
  </Card>

  <Card title="Utilisez le mode Construction lorsque" icon="hammer">
    * Vous savez exactement ce que vous voulez
    * Vous avez un plan clair, prêt à être exécuté
    * Vous effectuez des corrections rapides ou de petites modifications
    * Vous suivez une liste de tâches approuvée
    * La rapidité d&#39;implémentation est la priorité
  </Card>
</CardGroup>

<Tip>
  **Vous hésitez entre les deux ?** Si votre demande implique plusieurs fonctionnalités ou des modifications importantes, commencez par le mode Planification. Pour les tâches simples et bien définies, passez directement au mode Construction.
</Tip>

<div id="diferenas-principais">
  ## Différences principales
</div>

| Fonctionnalité            | Mode Planification                                  | Mode Construction                       |
| ------------------------- | --------------------------------------------------- | --------------------------------------- |
| **Objectif**              | Réfléchir, planifier et apprendre                   | Implémenter et construire               |
| **Modifications de code** | Aucune — lecture seule                              | Écrit et modifie des fichiers           |
| **Résultat**              | Idées, listes de tâches, conseils                   | Code et fonctionnalités opérationnelles |
| **Idéal pour**            | Projets complexes, exploration                      | Tâches précises, implémentation         |
| **Transition**            | Cliquez sur « Commencer à construire » pour changer | Déjà en mode implémentation             |

<div id="boas-prticas">
  ## Bonnes pratiques
</div>

<div id="aproveitando-ao-mximo-o-modo-de-planejamento">
  ### Tirer le meilleur parti du mode Planification
</div>

* **Soyez précis sur vos besoins** : plus vous donnez de détails, meilleur sera le plan
* **Posez des questions de suivi** : faites clarifier les suggestions que vous ne comprenez pas
* **Demandez des exemples** : demandez à Agent de vous montrer des extraits de code ou des modèles
* **Pesez les compromis** : explorez les avantages et les inconvénients de chaque approche
* **Itérez sur les idées** : affinez le plan jusqu&#39;à ce qu&#39;il vous convienne

<div id="transies-perfeitas">
  ### Des transitions fluides
</div>

* **Vérifiez avant de lancer la création** : passez toujours en revue la liste de tâches avant de l&#39;approuver
* **Commencez petit** : démarrez avec un sous-ensemble de tâches si le plan complet vous semble trop ambitieux
* **Utilisez les checkpoints** : Agent crée des checkpoints au fur et à mesure de la création, ce qui vous permet de revenir en arrière à tout moment
