---
title: "Reserved VM 部署"
description: "介绍如何使用 Reserved VM 部署，将应用发布到全天候运行的云服务器上。"
---

Reserved VM 部署运行在虚拟机 (VM) 上，为应用提供专用的计算资源。这种部署类型可带来稳定不中断的性能，成本也更可预测。

它非常适合以下场景：

* 内存占用较高的后台任务
* 需要保持长连接的聊天应用机器人
* 全天候运行的 API 服务器

<div id="section">
  ## 功能
</div>

Reserved VM 部署包含以下功能：

* **专用资源**：预留的计算资源可确保应用性能稳定一致。
* **自定义域名**：配置自定义域名，或使用 `<app-name>.replit.app` URL 访问应用。
* **计算资源选项**：选择符合应用性能需求的 VM 配置。
* **可配置的端口映射**：指定应用向互联网开放的端口。
* **监控**：查看日志并监控已发布应用的状态。

<div id="section-2">
  ## 使用方法
</div>

你可以从 Publishing 项目编辑器工具中访问 Reserved VM 部署。

<Accordion title="如何访问 Reserved VM 部署">
  通过左侧的**工具栏**：

  1. 选择 <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="All tools 图标" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**，查看项目编辑器工具列表。
  2. 选择 <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Publishing 图标" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publishing**。
  3. 选择 **Reserved VM** 选项，然后选择 **Set up your published app**。

  通过**搜索栏**：

  1. 选择顶部的<img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" />放大镜图标，打开搜索工具
  2. 输入“Publishing”搜索该工具，然后在结果中选择它。
  3. 选择 **Reserved VM** 选项，然后选择 **Set up your published app**。
</Accordion>

<div id="section-3">
  ### 机器配置
</div>

为托管部署的机器选择 CPU 和 RAM 配置。所选机器规格旁会显示该选项对应的费用。

<div id="section-4">
  ### 主域名
</div>

指定已发布应用主机名中的子域名部分。发布后，你可以通过 `https://<subdomain>.replit.app` 访问已发布的应用。

要了解如何使用自定义域名，请参阅[自定义域名](/zh/features/publishing/custom-domains)。

<div id="section-5">
  ### 私有部署
</div>

<Info>
  私有发布应用功能面向 Pro 和 Enterprise 计划提供。
</Info>

私有发布的应用仅允许你的 workspace 成员，或你邀请的特定用户和群组访问。
发布时，你可以选择 **Public**、**Password protected**、**Workspace only** 或 **Invite only** 访问方式。

要了解如何设置私有 部署，请参阅[应用访问权限](/zh/features/publishing/private-deployments/)。

<div id="section-6">
  ### 构建命令
</div>

在 **Build command** 字段中输入一条 shell 命令，用于在运行 Run 命令之前编译或配置应用。
例如，若要使用 Vite 为生产环境优化 JavaScript 应用，可以添加 `vite build` 命令。

<div id="section-7">
  ### 运行命令
</div>

在 **Run command** 字段中输入用于启动任务的 shell 命令。该命令应与你在工作流中使用的命令类似。例如，要启动名为“myApp”的 Flask 应用，可以添加 `flask --app myApp run` 命令。

<div id="section-8">
  ### 已发布应用的密钥
</div>

选择 **Add published app secret**，添加安全运行应用所需的环境变量和密钥。

如果 Replit App 中已有环境变量或密钥，Publishing 工具会自动将它们添加到列表 K 中。

<div id="section-9">
  ### 应用类型选项
</div>

请从以下选项中选择一项：

* **Web server**：如果要发布 Web 应用，或用户需要通过互联网访问的应用，请选择此选项。
* **Background worker**：如果应用不监听端口，也不启动服务器，请选择此选项。

选择 **Web Server** 后，可通过以下步骤自定义要对外开放的端口：

1. 展开 **Port configuration** 部分。
2. 选择 **Networking pane to configure** 打开 **Networking** 选项卡，管理端口映射。

有关端口配置的详细信息，请参阅[端口](/zh/ja/features/project-setup/ports/)。
