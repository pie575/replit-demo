## Agent

### Analyse de sécurité pendant que vous construisez

Agent vérifie désormais les fichiers qu'il modifie à la recherche de problèmes de sécurité courants dans le cadre de sa révision de code. Cette analyse Semgrep automatique recherche les modèles à risque et les secrets codés en dur, afin qu'Agent puisse traiter les découvertes probables avant de terminer la tâche.

En savoir plus sur l'[analyse de sécurité pendant que vous construisez](/fr/features/security/project-security-center#analyse-de-sécurité-pendant-que-vous-construisez).

## Plateforme

### Régénérez les identifiants de base de données de production

Vous pouvez désormais régénérer les identifiants d'une base de données de production éligible depuis l'outil **Database**. Replit met à jour les identifiants et, lorsque votre application dispose d'un déploiement actif pris en charge, lance un redéploiement afin qu'elle puisse continuer à utiliser les nouveaux identifiants. Mettez à jour tous les outils externes qui utilisent l'ancienne chaîne de connexion.

## Équipes et Enterprise

### Créez avec SSO

Les builders Pro peuvent désormais configurer le SSO d'entreprise pour une Replit App qui utilise [Clerk Auth](/fr/features/auth-and-identity/clerk-auth). Demandez à Agent la modification d'authentification dont vous avez besoin, et Agent vous dirige vers le tableau de bord Clerk. Là, connectez Okta ou Microsoft Entra ID via OIDC ou SAML. Les connexions SSO d'entreprise sont gratuites jusqu'au 1er octobre 2026. Après cette date, la tarification Clerk s'applique directement. La disponibilité Enterprise arrive bientôt.

### Déplacez des projets entre espaces de travail

Vous pouvez désormais déplacer un projet entre des espaces de travail d'équipe appartenant au même compte de facturation depuis la liste **Projects**. Le transfert s'exécute en arrière-plan et ne peut pas être annulé. Les Secrets du compte liés ne sont pas déplacés avec le projet ; reliez-les à nouveau dans l'espace de travail de destination.
