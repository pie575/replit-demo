<div id="o-que-o-visual-editor">
  ## Что такое Visual Editor?
</div>

Visual Editor позволяет вносить точечные изменения в интерфейс, кликая прямо по элементам. Он работает и на [canvas](/ru/pt/design/canvas) в Replit Design, и в Preview, поэтому макеты и запущенные приложения редактируются одинаково.

Простые правки — изменение текста, подбор цвета, настройка отступов — сразу обновляют исходный код и не расходуют кредиты ИИ. Если же изменение связано со скрытой сложностью, Visual Editor автоматически передаёт задачу Agent.

Ключевые понятия:

* **Детерминированные правки**: простые изменения (текст, цвета, отступы) применяются напрямую к исходному коду, без цикла работы Agent
* **Без расхода кредитов**: прямые правки не тратят кредиты ИИ — через Agent проходят только сложные изменения
* **Двойной контекст**: работает одинаково во frame на canvas и в Preview
* **Синхронизация с исходным кодом**: каждая правка мгновенно обновляет исходный код

<Note>
  Visual Editor сейчас доступен только в **веб-браузерах**. Он не поддерживается в Mobile App и Desktop App.
</Note>

<div id="como-usar-o-visual-editor">
  ## Как пользоваться Visual Editor
</div>

<div id="editando-no-canvas">
  ### Редактирование на Canvas
</div>

Выберите инструмент **Edit** на панели инструментов и щёлкните любой элемент внутри фрейма. Выбранный элемент будет выделен и помечен чипом, а справа откроется панель Visual Editor с доступными для редактирования свойствами, такими как содержимое, макет, цвет и граница. Настройте их, затем выберите **Save edits**, чтобы применить изменения, или **Discard**, чтобы отменить их.

Отображаемые свойства зависят от выбранного элемента: для текстовых элементов доступны настройки шрифта, для изображений — источник и загрузка, а для контейнеров — настройки макета.

<div id="editando-no-preview">
  ### Редактирование в Preview
</div>

Вы можете редактировать элементы прямо в запущенном приложении.

<Steps>
  <Step title="Выберите элемент">
    Нажмите любой элемент в Preview, чтобы начать редактирование.
  </Step>

  <Step title="Внесите изменения">
    Редактируйте текст прямо на странице, настраивайте цвета с помощью палитры, изменяйте отступы с помощью элементов управления стилем или заменяйте изображения.
  </Step>

  <Step title="Сохраните">
    Нажмите «Сохранить», чтобы обновить исходный код. Простые изменения применяются напрямую без расхода кредитов ИИ. Если правка требует более сложной обработки, Visual Editor передаёт Agent соответствующие метаданные для помощи.
  </Step>
</Steps>

<div id="edio-de-texto">
  ### Редактирование текста
</div>

Нажмите на любой текстовый элемент и начните печатать, чтобы изменить его прямо на месте. Если этот текст представляет собой строку в исходном коде, изменение применяется сразу.

<div id="ajustes-de-cor">
  ### Настройка цвета
</div>

Используйте палитру, чтобы настроить цвет текста и фона. Введите название цвета, например «фиолетовый», в соответствующее поле или воспользуйтесь пипеткой, чтобы выбрать цвет в любой точке экрана.

<div id="mudanas-de-estilo">
  ### Изменение стилей
</div>

Настраивайте внутренние и внешние отступы, а также расположение элементов с помощью удобных элементов управления.

<div id="controles-de-layout">
  ### Элементы управления макетом
</div>

Visual Editor группирует все элементы управления по понятным разделам, чтобы вы быстрее находили нужное: **Text**, **Layout**, **Color** и **Border**. (Раздел **Image** появляется, когда вы выбираете элемент изображения.)

В разделе **Layout** вы настраиваете расположение дочерних элементов внутри контейнера, не обращаясь к Agent. Выберите flex-контейнер, разверните Layout — и вам будут доступны:

* **Alignment**: сетка точек 3×3, задающая положение элементов по обеим осям внутри контейнера.
* **Direction**: две кнопки со стрелками, выстраивающие дочерние элементы в строку или в столбец.
* **Gap**: значение в пикселях для промежутка между элементами. Значок рядом с полем gap меняется в соответствии с текущим направлением, чтобы вы всегда знали, горизонтальные или вертикальные отступы настраиваете. Рядом с ним значок со стрелкой включает параметр **Distribute space between items**, который разносит дочерние элементы к противоположным краям контейнера.
* **Outer space**: поля для пространства снаружи элемента (по одному полю на сторону, с переключателем связи, чтобы задать все четыре стороны сразу).
* **Inner space**: поля для пространства внутри элемента по каждой оси, с переключателем связи для обеих осей сразу.

Раздел Layout появляется, только если к выбранному элементу применим хотя бы один элемент управления макетом. Для простых текстовых узлов без свойств отступов и макета раздел скрывается полностью, благодаря чему редактор остаётся компактным.

<div id="atualizaes-de-imagem">
  ### Обновление изображений
</div>

Выделяйте изображения, чтобы заменить URL-адрес или загрузить собственный файл, — результат виден сразу.

<div id="o-que-voc-pode-fazer">
  ## Что вы можете делать
</div>

* **Быстро редактировать текст**: обновляйте текст, подписи и заголовки, не открывая файлы исходного кода
* **Экспериментировать с цветами**: пробуйте разные цветовые схемы, просто нажимая и настраивая их, — без поиска нужного CSS
* **Настраивать макет**: визуально корректируйте внутренние и внешние отступы и интервалы вместо того, чтобы подбирать значения в пикселях
* **Заменять изображения**: заменяйте изображения-заполнители реальными, нажимая на них и загружая файлы
* **Итерировать дизайн**: быстро корректируйте фреймы на Canvas, чтобы сравнивать визуальные варианты без постоянного взаимодействия с Agent

<div id="perguntas-frequentes">
  ## Часто задаваемые вопросы
</div>

<Accordion title="Расходуются ли кредиты ИИ на изменения в Visual Editor?">
  Простые детерминированные правки — изменение текста, выбор цвета, настройка отступов — кредиты ИИ не расходуют. Они обновляют исходный код напрямую. Если Visual Editor обнаружит скрытую сложность, он передаст изменение Agent, а тот уже расходует кредиты.
</Accordion>

<Accordion title="Можно ли редактировать элементы, которые встречаются в нескольких местах?">
  Да. При выборе элемента, отрисованного в цикле или переиспользованного в нескольких компонентах, все его экземпляры подсвечиваются и обновляются одновременно.
</Accordion>

<Accordion title="Почему у некоторых элементов не получается изменить текст?">
  У составных элементов, которые состоят из нескольких вложенных элементов, текст нельзя редактировать напрямую в Visual Editor. Попросите внести такие изменения Agent в Chat.
</Accordion>

<Accordion title="Как найти исходный код элемента?">
  Нажмите на метку в левом верхнем углу выбранного элемента, чтобы перейти к соответствующему месту в исходном коде.
</Accordion>
