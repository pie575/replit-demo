<AccordionGroup>
  <Accordion title="Как подключить Resend или другой почтовый сервис к приложению Replit?">
    Откройте проект, перейдите в **Tools → Connectors**, найдите нужный сервис (например, Resend) и подключите его. После аутентификации API-ключ сохранится как секрет проекта. Если вы настраиваете собственный почтовый домен, добавьте у своего DNS-провайдера DNS-записи, которые укажет сервис.

    Список доступных коннекторов см. в [обзоре интеграций](/ru/ja/features/integrations/overview), а также в разделе [Добавление интеграций](/ru/ja/build/add-integrations).
  </Accordion>

  <Accordion title="Я случайно удалил проект. Можно ли его восстановить?">
    Удалённые проекты можно восстановить в течение определённого времени. Откройте Shell в любом проекте и выполните следующую команду:

    ```bash theme={null}
    trash view
    trash restore your-project-name
    ```

    По истечении срока хранения удалённые проекты удаляются безвозвратно. Если срок уже истёк, [обратитесь в службу поддержки Replit](https://replit.com/support).
  </Accordion>

  <Accordion title="Как скачать или экспортировать проект Replit?">
    Нажмите на меню с тремя точками в верхней части дерева файлов и выберите **Download as zip**. Для крупных проектов загрузка может занять некоторое время. Если она не удаётся, откройте Shell, выполните `zip -r project.zip .` и скачайте `project.zip` из дерева файлов.
  </Accordion>

  <Accordion title="Как поделиться проектом или добавить участников?">
    Доступны три варианта:

    * **Только чтение** — сделайте проект публичным, чтобы его мог просматривать любой, у кого есть ссылка.
    * **Доступ на редактирование по приглашению** — выберите **Invite**, введите имя пользователя или адрес электронной почты и задайте уровень прав.
    * **Ссылка для присоединения** — создайте ссылку через **Invite**, чтобы любой, у кого она есть, мог присоединиться и редактировать проект.

    Core поддерживает до 5 соавторов, Pro — до 15. Платный тарифный план для редактирования проекта соавторам не нужен. См. раздел [Workspace](/ru/ja/features/collaboration/workspaces).
  </Accordion>

  <Accordion title="Как подключить репозиторий GitHub к Replit?">
    Подключите аккаунт GitHub в разделе подключённых сервисов аккаунта, затем откройте [инструменты Git](/ru/ja/features/workspace-tools/git-interface) проекта и подключите репозиторий. Для двусторонней синхронизации включите автоматическую синхронизацию на панели Git. Чтобы импортировать существующий репозиторий, см. [Импорт от провайдеров](/ru/ja/build/import-from-providers).

    Если синхронизация Git прекратилась, повторно подключите GitHub через подключённые сервисы. Использование персонального токена доступа с детализированными разрешениями обеспечивает более стабильное подключение.
  </Accordion>

  <Accordion title="Repl работает медленно или редактор тормозит — что можно сделать?">
    Если редактор работает с задержками, попробуйте следующее:

    * Выполните принудительное обновление: `Cmd+Shift+R` на Mac или `Ctrl+Shift+R` на Windows.
    * Закройте неиспользуемые вкладки файлов.
    * Откройте палитру команд сочетанием `Cmd+K` на Mac или `Ctrl+K` на Windows, затем найдите и выберите **Restart compute**.
    * Попробуйте другой браузер, чтобы исключить проблемы с расширениями.

    Если медленно выполняется код, а не редактор, проверьте наличие ресурсоёмких циклов и ограничения памяти. Использование CPU и памяти можно посмотреть на панели ресурсов в нижней части редактора.
  </Accordion>

  <Accordion title="Как использовать переменные окружения и секреты в проекте?">
    Откройте инструмент **Secrets** (значок ключа) и выберите **+ New secret**, чтобы ввести ключ и значение. В коде обращайтесь к нему через `process.env.API_KEY` (Node.js) или `os.environ["API_KEY"]` (Python).

    Секреты в панели [Secrets](/ru/ja/core-concepts/project-editor/app-setup/secrets) среды разработки доступны только в редакторе. Для опубликованных приложений добавьте те же ключи в секреты развёртывания — так задумано, они управляются раздельно.
  </Accordion>

  <Accordion title="Как использовать Account Secrets（Vault）?">
    [Account Secrets](/ru/ja/core-concepts/project-editor/app-setup/secrets) доступны во всех проектах и удобны для ключей, которые используются повторно. Добавьте их в настройках аккаунта, и они станут доступны во всех ваших проектах. Если один и тот же ключ есть и в Account Secrets, и на панели Secrets проекта, приоритет имеет значение на уровне проекта.
  </Accordion>

  <Accordion title="Как устранить конфликты слияния Git или восстановиться после повреждения состояния Git?">
    Откройте Shell и выполните `git status`, чтобы проверить наличие конфликтов.

    <Warning>Следующие две команды безвозвратно удаляют незафиксированные изменения. Сначала сохраните копию всего, что вам нужно, — например, скопируйте изменённые файлы за пределы проекта.</Warning>

    Чтобы отменить локальные изменения и вернуться к последнему «чистому» состоянию, выполните `git checkout -- .`. Чтобы сбросить состояние до последнего коммита, выполните `git reset --hard HEAD`.

    Если папка `.git` повреждена и команды Git завершаются с ошибкой, откройте новый чат с Agent и вставьте текст ошибки — часто Agent может восстановить репозиторий. См. [Аварийное восстановление](/ru/ja/features/version-control/disaster-recovery).
  </Accordion>

  <Accordion title="Как откатить проект к предыдущей контрольной точке?">
    Replit сохраняет [чекпоинты](/ru/ja/features/version-control/checkpoints-and-rollbacks) по мере работы Agent. Найдите в панели Agent сообщение, предшествующее изменениям, которые вы хотите отменить, выберите рядом с ним вариант отката и подтвердите действие.

    <Note>
      Replit больше не поддерживает откат опубликованных приложений к предыдущим версиям. Чтобы отменить изменения в опубликованном приложении, откатите проект к более раннему чекпоинту (как описано выше) и опубликуйте его снова, чтобы повторно развернуть это состояние. Чтобы восстановить отдельный файл, откройте его, выберите имя файла и с помощью **Show history** восстановите предыдущую версию. См. [историю файлов](/ru/ja/features/version-control/file-history).
    </Note>
  </Accordion>

  <Accordion title="Как перенести проект в другой аккаунт Replit?">
    Проект нельзя перенести напрямую, но его можно скопировать. Самый простой способ — предоставить доступ к проекту аккаунту, в который вы хотите его перенести, и создать в нём форк. Также можно скачать проект в виде ZIP-архива и загрузить его в новый Repl в другом аккаунте.

    После копирования настройте в новом проекте секреты, базу данных и параметры развертывания — они не входят в копию. Подробные инструкции, включая перенос данных базы данных, см. в разделе [Ручное копирование проектов в другую рабочую область](/ru/ja/teams/identity-and-access-management/manually-copy-projects).
  </Accordion>
</AccordionGroup>
