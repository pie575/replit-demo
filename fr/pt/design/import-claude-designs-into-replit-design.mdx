Une maquette créée dans Claude montre à quoi une expérience devrait ressembler. Avec l&#39;option **Send to Replit** de Claude, vous pouvez transmettre cette maquette à Replit, où elle devient un projet que l&#39;Agent transforme en une app fonctionnelle et interactive.

<Note>
  Il s&#39;agit d&#39;une nouvelle intégration. **Send to Replit** n&#39;apparaît dans le menu **Send to…** de Claude que lorsque Claude propose Replit comme destination pour votre maquette. La disponibilité est gérée par Claude : l&#39;option peut donc ne pas encore s&#39;afficher pour tous les comptes. Lorsque vous acceptez le transfert, Claude demande les portées **Access apps**, **Create and manage apps** et **Stay signed in to this application** sur l&#39;écran de consentement de Replit.
</Note>

<div id="como-funciona">
  ## Fonctionnement
</div>

Le transfert commence dans Claude et se termine dans Replit :

1. Vous créez un design autonome sur le canvas de design de Claude.
2. Vous envoyez le design vers Replit via le menu **Share → Send to…** de Claude.
3. Vous autorisez Claude à accéder à votre compte Replit, puis vous choisissez un workspace.
4. Replit crée un projet contenant votre design sous forme de fichier `index.html` statique.
5. L&#39;Agent prend en charge une tâche **Turn this Claude design into a real app** et rend le design interactif.

C&#39;est Claude qui *envoie* un design vers Replit par le biais d&#39;une connexion d&#39;app autorisée. Vous n&#39;avez rien à configurer dans Replit au préalable : tout part de Claude.

<div id="antes-de-comear">
  ## Avant de commencer
</div>

Vous avez besoin de :

* Un [compte Replit](https://replit.com).
* Un compte Claude avec un design sur le canvas de design de Claude.
* Un workspace de destination sur Replit pour le nouveau projet.

<div id="envie-um-design-do-claude-para-a-replit">
  ## Envoyer un design de Claude vers Replit
</div>

Commencez dans Claude avec le design à partir duquel vous souhaitez construire.

<Steps>
  <Step title="Ouvrez votre design dans Claude">
    Dans Claude, ouvrez le design que vous souhaitez transformer en app.
  </Step>

  <Step title="Ouvrez le menu Send to">
    Sélectionnez **Share**, puis ouvrez le menu **Send to…**. Replit apparaît parmi les destinations.

    <Frame>
      <img src="/assets/mirror/claude-send-to-menu-d4353906aea3.png" alt="Le menu Send to… de Claude affichant Replit comme destination à côté de Claude Code" width="2000" height="1143" data-path="images/claude-to-app/claude-send-to-menu.png" />
    </Frame>
  </Step>

  <Step title="Choisissez Replit">
    Sélectionnez **Replit** pour lancer le transfert vers votre compte Replit.
  </Step>

  <Step title="Autorisez l'accès de Replit">
    Sur l&#39;écran de consentement Replit intitulé **Claude would like to access your Replit account**, vérifiez les accès demandés par Claude — **Access apps**, **Create and manage apps** et **Stay signed in to this application** — puis autorisez la connexion.

    <Frame>
      <img src="/assets/mirror/replit-oidc-consent-76dfc4d92a2f.png" alt="L'écran de consentement Replit intitulé Claude would like to access your Replit account, affichant les portées Access apps, Create and manage apps et Stay signed in ainsi qu'un sélecteur de workspace" width="2000" height="1143" data-path="images/claude-to-app/replit-oidc-consent.png" />
    </Frame>
  </Step>

  <Step title="Choisissez un workspace">
    Choisissez le workspace Replit dans lequel créer le nouveau projet, puis confirmez.
  </Step>
</Steps>

Après confirmation, Replit crée un projet à partir de votre design et l&#39;ouvre dans le workspace.

<div id="o-que-importado">
  ## Ce qui est importé
</div>

Replit importe le design sous la forme d&#39;un fichier `index.html` unique et autonome. L&#39;importation préserve la mise en page visuelle, le style et les ressources que Claude a intégrés au design.

L&#39;importation vous fournit un point de départ fonctionnel. Comme le design arrive sous forme de HTML statique, il vous reste à ajouter le comportement, les données et l&#39;interactivité après l&#39;importation.

<div id="o-que-no-importado">
  ## Ce qui n&#39;est pas importé
</div>

Le transfert reprend le design, pas une application complète. Les éléments suivants ne sont pas inclus dans l&#39;importation :

* La logique backend et les fonctionnalités côté serveur.
* Une base de données ou des données stockées.
* L&#39;interactivité, comme les formulaires fonctionnels, l&#39;état et la navigation.

Agent ajoute ces fonctionnalités lorsqu&#39;il transforme le design en app fonctionnelle.

<div id="deixe-o-agent-tornar-o-design-interativo">
  ## Laissez Agent rendre le design interactif
</div>

Après l&#39;importation, Agent lance une tâche **Turn this Claude design into a real app** dans le workspace. Agent part de votre design statique et construit le comportement interactif suggéré par celui-ci.

<Frame caption="Le design Velocity de Claude sous forme de frame dans Replit Design, une fois l'exécution d'Agent terminée.">
  <img src="/assets/mirror/claude-design-in-replit-design-ff81b055b1f5.webp" alt="Le design de location de supercars Velocity envoyé depuis Claude, ouvert comme frame de design Claude dans Replit Design avec la tâche d'Agent marquée comme terminée dans le panneau de chat" width="1600" height="1004" data-path="images/claude-to-app/claude-design-in-replit-design.webp" />

Ouvrez le Preview une fois la tâche terminée pour tester le résultat. Comparez l&#39;app en cours d&#39;exécution avec votre design Claude d&#39;origine et vérifiez que :

* La mise en page et le style correspondent suffisamment au design.
* Les boutons, les formulaires et la navigation fonctionnent comme prévu.
* L&#39;app continue de fonctionner après un rafraîchissement de la page.

S&#39;il manque quelque chose ou si un élément est incorrect, décrivez la modification à Agent et laissez-le affiner l&#39;app.

<div id="configure-and-run-your-app">
  ## Configurez et exécutez votre app
</div>

Lors de l&#39;importation, {setupDescription_0}. Si votre app nécessite des ajustements, utilisez ces outils du Project Editor :

* **[Agent](/fr/features/agent/overview)** : affinez les fonctionnalités, corrigez les problèmes et modifiez le code
* **[Secrets](/fr/core-concepts/project-editor/app-setup/secrets)** : ajoutez des clés API et des variables d&#39;environnement
* **[Workflows](/fr/features/workspace-tools/workflows)** : définissez la commande **Run** de votre app

  ## Facturation
