根据网站和 Google Drive 中的品牌素材，为 X、LinkedIn、Instagram、Facebook、
TikTok 及其他指定平台生成头像和封面横幅。
Agent 会采用各平台当前的尺寸和安全区域，确保实际个人资料中的
人脸、徽标或文本不会被裁切。保持统一的视觉风格，
并导出为 PNG。若不同平台需要不同的裁切方式，则创建专用
画板，避免拉伸图像。

<div id="section-5">
  ## 预期效果
</div>

Agent 会读取网站和云端硬盘中的素材，并为每项素材创建像素尺寸正确的画板。典型配置：

* **X：** 头像 400×400，页眉 1500×500
* **LinkedIn：** 头像 400×400，横幅 1584×396
* **Instagram：** 头像 320×320 (如需帖子封面和快拍封面，还需添加 1080×1080 和 1080×1920)
* **Facebook：** 头像 320×320，封面 820×312 (或双倍尺寸 1640×624)
* **TikTok：** 头像 200×200，封面 1080×1920

上传前，请检查圆形头像和横向横幅的裁切效果。
分别导出一个图标和一个横幅，放入圆形头像和横向页眉中，
检查小尺寸下的留白。

<div id="section-7">
  ## 故障排除
</div>

* **徽标或人脸被裁切：** 请分别在圆形头像和横向横幅中检查素材。注意留出安全区域；如果需要不同的裁切方式，请让 Agent 创建专用画板。避免拉伸。
* **尺寸与平台不匹配：** 指定所需的平台，并让 Agent 使用各平台当前的官方尺寸。平台规格可能会变更，因此请在上传前再次确认。
