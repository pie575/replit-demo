<div id="como-o-replitmd-funciona">
  ## Как работает `replit.md`
</div>

Сначала Agent создаёт файл `replit.md` в корневом каталоге вашего проекта, опираясь на проверенные практики. Этот файл содержит:

* Основные сведения о проекте
* Рекомендуемые стандарты написания кода
* Типичные предпочтения для проектов вашего типа

<YouTubeEmbed videoId="kYv525W-vaU" title="Настройте, как Replit Agent отвечает на запросы" />

При обработке ваших запросов Agent автоматически читает файл `replit.md` и использует его содержимое, чтобы:

* Понимать архитектуру и соглашения вашего проекта
* Соблюдать выбранные вами стандарты и стили написания кода
* Использовать указанные менеджеры пакетов и зависимости

Agent также может обновлять файл `replit.md` по мере того, как узнаёт больше о вашем проекте и вносит изменения в приложение.

<Note>
  Вы можете отредактировать файл `replit.md`, чтобы настроить поведение Agent.
</Note>

<div id="configurando-o-replitmd">
  ## Настройка `replit.md`
</div>

<div id="gerao-automtica">
  ### Автоматическая генерация
</div>

Когда вы создаёте новый проект с помощью Agent, он автоматически генерирует файл `replit.md` на основе проверенной практики. Этот файл располагается в корневом каталоге проекта и содержит:

* Основную информацию о проекте
* Рекомендуемые стандарты написания кода
* Типичные настройки для проектов вашего типа

<div id="criao-manual">
  ### Создание вручную
</div>

Вы можете создать собственный файл `replit.md`, добавив новый файл с именем `replit.md` в корневой каталог проекта. Agent автоматически обнаружит его и будет использовать в дальнейших conversation.

<Note>
  Чтобы файл `replit.md` работал корректно, он должен находиться в корневом каталоге проекта.
</Note>

<div id="regenerando-o-replitmd">
  ### Повторная генерация `replit.md`
</div>

Если файл `replit.md` повреждён или вы хотите начать с чистого листа:

1. Удалите существующий файл `replit.md` из корневого каталога проекта
2. Начните новую беседу с Agent
3. Agent автоматически создаст новый файл `replit.md` на основе вашего текущего проекта


Подробнее о форматировании промптов см. в [руководстве Anthropic по разработке промптов](https://docs.anthropic.com/en/docs/build-with-claude/prompt-engineering/use-xml-tags).

```markdown theme={null}
## Предпочтения по исследованию
- Всегда проверяй наличие последних версий зависимостей, прежде чем предлагать обновления
- Изучай актуальные рекомендации по реализации мер безопасности
```

```markdown theme={null}

- Предлагая новые библиотеки, убеждайтесь в их совместимости с нашим текущим стеком
- Адаптируйте внешние примеры под наши стандарты написания кода и структуру проекта  
- Проверяйте, что предлагаемые решения работают в нашей среде публикации
```

  ## Ограничения
</div>

<div id="limites-de-tamanho-e-contedo-do-arquivo">
  ### Ограничения по размеру и содержимому файла
</div>

Хотя для `replit.md` нет строгого ограничения на количество символов, очень большие файлы могут обрабатываться не полностью. Для наилучших результатов сохраняйте `replit.md` лаконичным и по существу.

<div id="requisito-de-diretrio-raiz">
  ### Требование к корневому каталогу
</div>

Файл `replit.md` должен находиться в корневом каталоге проекта. Agent не обнаруживает такие файлы в подкаталогах автоматически.

<div id="escopo-do-contexto">
  ### Область действия контекста
</div>

Файл `replit.md` предоставляет контекст для Conversation с Agent, но не применяется автоматически к другим ИИ-инструментам.

<div id="prximos-passos">
  ## Дальнейшие шаги
</div>

Готовы настроить Agent под свой проект?

1. **Начните с простого**: создайте базовый `replit.md` с основными предпочтениями
2. **Улучшайте постепенно**: дополняйте `replit.md` по ходу работы с Agent
3. **Делитесь наработками**: применяйте удачные конфигурации `replit.md` в похожих проектах
4. **Отслеживайте эффективность**: следите за тем, насколько точно Agent следует вашим указаниям, и корректируйте их при необходимости

Узнайте больше о [работе с Agent](/ru/pt/features/agent/overview) или изучите другие [инструменты ИИ](/ru/pt/build/welcome).

**Enterprise**: заранее настройте `replit.md` в [пользовательских шаблонах](/ru/pt/teams/custom-templates), чтобы все разработчики вашей организации получали единый стартовый контекст. Рекомендации по дизайну смотрите в разделе [настройка дизайн-системы](/ru/pt/teams/custom-design-system).
