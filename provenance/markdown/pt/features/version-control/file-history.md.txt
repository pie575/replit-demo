# Histórico de Arquivo

> Aprenda como recuperar versões anteriores do seu código usando os pontos de salvamento automáticos do Histórico de Arquivo.

Comece abrindo um arquivo de texto no Project Editor e pressionando o botão **History** no canto inferior direito.

## Visualizar versões anteriores de um arquivo

Após abrir o Histórico de Arquivo, você pode visualizar versões anteriores de um arquivo usando a barra de rolagem, os botões de seta ou as teclas de seta **esquerda** e **direita**.

<Frame>
  <img src="https://mintcdn.com/replit/-6g2hQCrMskerX65/images/animations/history-versioning.gif?s=0ea4ddbe452557870f88eff87b3960dd" alt="demonstração da barra de rolagem" width="764" height="720" data-path="images/animations/history-versioning.gif" />
</Frame>

## Comparar versões anteriores com o arquivo atual

Pressione o botão Compare Latest no canto inferior esquerdo do painel de Histórico de Arquivo para ver comparações em linha do seu arquivo naquele ponto no tempo e a versão mais recente.

<Frame>
  <img src="https://mintcdn.com/replit/-6g2hQCrMskerX65/images/animations/compare-history.gif?s=96b290dc3ded58a6eb2e0bbd70c72285" alt="imagem de comparação com a versão mais recente" width="772" height="720" data-path="images/animations/compare-history.gif" />
</Frame>

## Restaurar uma versão anterior de um arquivo

Se você quiser restaurar um arquivo para uma versão anterior, basta pressionar o botão `Restore`, que fará a restauração. Não se preocupe, você não apagará nenhum histórico. Ao restaurar para uma versão anterior, ela é adicionada como uma nova versão ao histórico do arquivo.

## Visualizar a reprodução do Histórico de Arquivo

Você pode usar o recurso de reprodução do Histórico de Arquivo para assistir seu arquivo mudar ao longo do tempo como um filme. Isso pode ser útil para criar vídeos das suas sessões de programação.
