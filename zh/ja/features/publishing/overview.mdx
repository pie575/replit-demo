---

Publishing 工具用于让应用正式上线，并管理它在 Web 上的运行情况。控制应用网址、可访问人员、生产数据库、监控、安全以及托管方式的各项设置，都集中在同一个面板中。

要打开它，请在 **Tools** 面板的 **Replit Cloud** 下选择 **Publishing**，或在 Project Editor 右上角选择 **Publish**。

<div id="section">
  ## 发布你的应用
</div>

在主面板中，你可以逐项确认应用上线所需的全部内容。确认完各个部分后，选择 **Publish**。

<Frame>
  <img src="/assets/mirror/publish-your-app-851815208b8a.png" alt="Publish your app 面板，Publish 按钮上方依次显示 Domain 字段、要发布的应用、访问设置、数据库设置、监控、安全和互动工具" width="578" height="980" data-path="images/deployments/publish-pane/publish-your-app.png" />
</Frame>

* **Domain**：应用的网址。Replit 会推荐一个 `.replit.app` 名称并检查是否可用。你可以修改该名称，也可以在发布后接入[自定义域名](/zh/ja/features/publishing/custom-domains)。
* **What you&#39;re publishing**：即将上线的应用及其 URL 预览。
* **Who can access your app**：可选择 **Public**、**Password protected**、**Workspace only** 或 **Invite only**。非公开选项会将应用的使用范围限制在 workspace 内，或仅限你邀请的个人或群组。详情请参阅[应用访问](/zh/ja/features/publishing/private-deployments)。
* **Database settings**：管理发布时如何创建应用的生产数据库并写入数据。详情请参阅[生产数据库](/zh/ja/features/data-and-storage/development-and-production)。
* **Monitoring tools**：启用应用监控后，应用一旦宕机你就能第一时间知晓。Replit 会持续检查应用是否在线，出现问题时通过邮件通知你。详情请参阅[监控应用](/zh/ja/features/publishing/monitoring-a-deployment)。
* **Security tools**：在发布前运行详细的安全扫描。Security Agent 结合 AI 与主流静态分析工具，检查 project 中的漏洞。详情请参阅 [Project Security Center](/zh/ja/features/security/project-security-center)。
* **Engagement tools**：启用反馈组件后，已发布应用的角落会出现一个反馈按钮。你可以在收件箱中查看用户提交的内容，并将其发送给 Agent 进行修复。

<div id="section-2">
  ## 调整设置
</div>

选择 **Adjust settings** 即可手动配置应用的托管方式。大多数构建者无需改动这些设置，Replit 会为你选择合适的默认值。

<Frame>
  <img src="/assets/mirror/adjust-settings-d6e124b2249f.png" alt="Adjust settings 部分，显示部署类型、机器配置、部署密钥、部署地理位置以及阻止发布严重漏洞的开关" width="574" height="794" data-path="images/deployments/publish-pane/adjust-settings.png" />
</Frame>

* **Deployment type**：用于发布应用的技术。**Autoscale** 可从零扩展到任意需求规模，因此适合大多数应用。请参阅[部署类型](/zh/ja/features/publishing/deployment-types)进行比较。
* **Machine configuration**：运行应用的服务器性能。选择 **Edit** 可修改 CPU、内存和最大机器数量。面板会显示每台机器的成本以及流量峰值时的成本。详情请参阅[机器配置](/zh/ja/features/publishing/machine-configuration)。
* **Deployment secrets**：应用访问 API 和服务时所用的密钥 (一处安全、非公开的存储区域，用于保存 API 密钥等敏感信息) 。Secrets 会自动从开发环境同步到已发布的应用。详情请参阅 [Secrets](/zh/ja/core-concepts/project-editor/app-setup/secrets)。
* **Deployment geography**：应用的托管位置。选择离用户更近的区域可降低延迟。应用一经发布，其自身及相关资源便会固定在该区域。若之后需要更改区域，请重新混合 (remix) 你的应用。详情请参阅[项目地理位置](/zh/ja/features/publishing/project-geography)。
* **Block publishing of critical vulnerabilities**：Replit 在发布前始终会执行安全扫描。此设置用于控制发现严重漏洞时是否阻止发布。详情请参阅 [Project Security Center](/zh/ja/features/security/project-security-center)。
