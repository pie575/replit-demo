<div id="intelligent-model-routing">
  ### 지능형 모델 라우팅
</div>

지능형 모델 라우팅은 품질과 비용의 균형을 맞추면서 작업에 가장 적합한 모델과 Effort 수준을 자동으로 선택합니다. **Power** 또는 **Max**에서 **Auto**를 선택하면 작업의 복잡도 변화에 따라 Replit이 각 부분을 알맞게 라우팅합니다. 더 세밀하게 제어하고 싶다면 특정 모델과 Effort 수준을 직접 선택할 수도 있습니다.

<div id="intelligent-model-routing-for-enterprise">
  ### Enterprise용 지능형 모델 라우팅
</div>

이제 지능형 모델 라우팅이 Enterprise Workspace의 기본 Agent 모드입니다. **Auto 모드**를 켜면 Replit이 각 task에 가장 적합한 모드와 허용된 모델을 선택합니다. account admin은 Workspace별로 모델 사용 가능 여부를 제어할 수 있으며, **Auto 모드**를 끄고 활성화된 모델을 직접 선택할 수도 있습니다. Enterprise의 Agent 모드 메뉴는 이제 **Power**와 **Max**를 제공하며, **Lite**는 더 이상 포함되지 않습니다.

<Frame caption="Auto 모드를 켜면 Replit이 각 task에 가장 적합한 모드와 모델을 선택합니다.">
  <img src="/assets/mirror/enterprise-auto-mode-9365b7d49c0d.png" alt="Auto 모드가 켜져 있고 모델이 Auto로 고정된 Agent settings" width="558" height="356" data-path="images/changelog/2026-08-28/enterprise-auto-mode.png" />
</Frame>

자세한 내용은 [Enterprise 모델 제어](/ko/features/collaboration/enterprise-model-controls)를 참고하세요.
