Utilisez la fonctionnalité Recherche web d’Agent <img class="icon-svg" src="/assets/mirror/web-search-1fe8f63b5b88.svg" alt="icône de recherche web" width="16" height="16" data-path="images/icons/web-search.svg" /> pour créer des applications à partir de données réelles et à jour.

Cette fonctionnalité permet de dépasser la limite de connaissances d’Agent en accédant aux informations les plus récentes sur le Web. Lorsque vous demandez à Agent de créer quelque chose nécessitant des informations à jour, il recherche sur le Web du contenu détaillé pour rendre votre application plus précise et utile.

<Frame>
  <img src="/assets/mirror/web-search-header-31c6f8a0ab88.jpg" alt="Agent effectuant une recherche web afin de recueillir des informations à jour pour le développement d’applications" width="1920" height="1080" data-path="images/replitai/web-search-header.jpg" />
</Frame>

La recherche web vous aide à trouver les packages, outils et informations les plus récents. Elle garantit ainsi que votre application est plus précise et utilise les bonnes pratiques actuelles.

<div id="section">
  ## Fonctionnalités
</div>

Créez des applications à partir d’informations actualisées grâce à la recherche Web d’Agent. Vous n’avez ainsi plus besoin d’effectuer manuellement des recherches ni de collecter des données. Que vous créiez un tableau de bord de données financières ou un site web présentant de récentes levées de fonds de start-ups, la recherche Web garantit que votre application reflète la réalité.

Actions de recherche Web qu’Agent peut effectuer :

* **Recherche** : trouve des informations actualisées, la documentation la plus récente et des données Internet en temps réel
* **Récupération de contenu** : récupère des informations détaillées depuis des sites web ou des URL spécifiques
* **Citations des sources** : vous permet de vérifier et de consulter les sources en identifiant précisément où Agent a trouvé les informations

<div id="section-2">
  ## Utilisation
</div>

La recherche web est intégrée à Agent : vous n’avez pas besoin de l’activer. Décrivez ce que vous souhaitez créer, et Agent déterminera automatiquement à quel moment rechercher des informations récentes sur le web. Vous pouvez également demander explicitement à Agent d’effectuer une recherche en incluant dans votre prompt des mots-clés tels que « rechercher », « faire des recherches » ou « utiliser la recherche web ».

<div id="section-3">
  ### Comment la recherche web améliore les applications
</div>

La recherche web permet aux applications de remplacer les données fictives par des informations réelles et précises :

| Avantage                   | Description                                                                                           |
| -------------------------- | ----------------------------------------------------------------------------------------------------- |
| Technologies récentes      | Votre application utilise des informations et des packages récents absents des données d’entraînement |
| Choix des meilleurs outils | Agent étudie les options et sélectionne les packages les plus adaptés                                 |
| Bonnes pratiques actuelles | Vous accédez aux dernières approches de développement et pratiques de sécurité                        |
| Dépassement des limites    | Vous surmontez la limite des connaissances pour utiliser des packages publiés après l’entraînement    |
| Données précises           | Votre application affiche des informations actuelles au lieu d’exemples obsolètes                     |
| Résultats professionnels   | Les applications qui font référence à de véritables entreprises sont plus crédibles                   |
| Gain de temps              | Vous n’avez plus besoin de rechercher manuellement des packages ni de collecter des données           |

<div id="section-4">
  ### Citations des sources
</div>

Lorsque Agent utilise la recherche Web, il fournit des **citations des sources** indiquant précisément l’origine des informations. Utilisez ces citations pour :

* **Vérifier les informations** : confirmez la fiabilité et l’exactitude des sources
* **En savoir plus** : consultez les sources originales pour obtenir davantage de contexte
* **Citer les sources** : incluez les mentions d’attribution appropriées dans votre application
* **Suivre les recherches** : identifiez les informations ayant influencé le travail d’Agent

<div id="section-5">
  ### Récupération de contenu
</div>

Agent peut récupérer du contenu détaillé sur des sites web spécifiques afin de recueillir des informations complètes pour votre projet. Cela permet à Agent de :

* lire des pages web entières et d’en extraire les informations pertinentes
* traiter de la documentation et des ressources de référence
* recueillir des données spécifiques auprès de sources fiables
* intégrer des informations structurées à votre application

<div id="section-6">
  ### Exemples de recherche web
</div>

**Découverte de bibliothèques de traitement d’images**

<AiPrompt>
  Créez une application React capable d’appliquer des filtres aux photos. Recherchez les meilleures bibliothèques de traitement d’images pour React et implémentez des effets de flou, de netteté et vintage
</AiPrompt>

Agent recherche les bibliothèques de traitement d’images actuelles, compare leurs fonctionnalités et leurs performances, puis crée l’application avec les outils les plus adaptés.

<Tip>
  La recherche web est particulièrement efficace avec des demandes précises et détaillées. Indiquez des exigences spécifiques pour découvrir des technologies.
</Tip>

**Fonctionnalités récentes des frameworks**

<AiPrompt>
  Effectuez des recherches pour comprendre les dernières bonnes pratiques de sécurité en matière d’authentification et d’autorisation. Implémentez ces bonnes pratiques dans l’application.
</AiPrompt>

Agent étudie les dernières bonnes pratiques de sécurité en matière d’authentification et d’autorisation, puis les implémente dans l’application.

**Intégration d’API modernes**

<AiPrompt>
  Créez une application météo utilisant l’API météo disponible la plus fiable et la plus riche en fonctionnalités
</AiPrompt>

Agent étudie les API météo actuelles, compare leurs fonctionnalités, leur fiabilité et leurs tarifs, puis sélectionne l’option la plus adaptée à vos besoins.

**Site web de présentation de startups**

<AiPrompt>
  Créez un site web présentant les startups de la dernière promotion de Y Combinator
</AiPrompt>

Agent recherche les informations sur la promotion YC actuelle et crée un site avec des données réelles sur les startups, des logos et des descriptions.

**Site de portfolio personnel**

<AiPrompt>
  Créez le site web personnel de Michele Catasta, ancien chercheur à Stanford et président de Replit.
</AiPrompt>

Agent recherche des informations professionnelles et crée un portfolio authentique avec un parcours académique et une expérience professionnelle pertinents.

**Application de planification de voyage**

<AiPrompt>
  Créez un planificateur de voyage au Japon incluant les prix actuels et des recommandations
</AiPrompt>

Agent trouve les coûts de voyage récents, les attractions touristiques et les informations de planification afin de créer une application de voyage réaliste.

**Tableau de bord de comparaison financière**

<AiPrompt>
  Créez un tableau de bord comparant les derniers résultats trimestriels des principaux fournisseurs cloud
</AiPrompt>

Agent recherche les rapports financiers récents et crée un tableau de bord avec des visualisations de données actuelles et précises.

<Warning>
  Pour les applications critiques, vérifiez toujours les informations obtenues à partir des résultats de recherche web. Agent recherche des sources fiables, mais vérifiez les informations importantes avant de les utiliser en production.
</Warning>
