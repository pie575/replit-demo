<div id="agent">
  ### 动效 Agent 图标
</div>

Agent 图标现在会在运行时展示动画效果，让你更直观地感知 Agent 正在工作。这一改进提升了体感速度，尤其是在更贴近请求的居中聊天布局中，你可以更轻松地看到 Agent 在初始规划阶段的活动。

<div id="agent-2">
  ### 计划流程中的 Agent 工具下拉菜单
</div>

现在，你可以在初始计划和任务列表的审批流程中使用 Agent 工具下拉菜单。从构建一开始，你就能配置偏好的 Agent 设置，包括自主级别和其他偏好设置。

<div id="agent-3">
  ### Agent 支持 @ 文件名
</div>

除了 `/` 命令，Agent 现在还支持通过 `@` 提及文件名，与主流开发工具保持一致的交互设计。这是熟悉 Cursor 风格工作流的企业版用户和高级用户呼声很高的功能。

<div id="section-3">
  ### 重混时的连接器支持
</div>

此前，重混使用了连接器的 Replit 应用时，重混得到的 repl 不会自动获得连接器的使用权限，导致集成失效。我们已更新重混流程，使其能够正确处理连接器：

* 重混时会提示你设置所需的连接器
* 重混过程中会明确标示需要配置的集成
* 重混后集成不再失效

了解更多关于 [Agent 集成](/zh/replitai/integrations)和[管理连接器](/zh/ko/replitai/managing-connectors)的信息。

<div id="section-5">
  ### 面向企业版管理员的分析仪表板
</div>

企业版管理员现在可以使用综合分析仪表板——这是 Meta、Atlassian 等企业版客户呼声很高的一项重要功能。该仪表板可帮助你：

* **监控用户活动**：跟踪整个组织的参与度与协作情况
* **跟踪资源使用**：按用户和 Replit App 监控支出
* **掌握部署状况**：了解部署活动动态
* **管理成本**：清晰掌握资源消耗与费用
