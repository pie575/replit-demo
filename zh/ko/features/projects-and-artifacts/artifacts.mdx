<div id="section">
  ## 什么是工件？
</div>

工件是可在 Replit 上发布的成果，包括 Web 应用、移动应用、幻灯片、动画、数据应用、3D 游戏和设计等。每个工件都是完整且独立的成果，发布后都会拥有可供分享的专属 URL。

项目中的其他内容——文件、图片、CSV 和代码——都用于支持工件，但本身无法发布。

<ArtifactGrid />

<div id="section-2">
  ## 可创建的内容
</div>

| 类型                                                           | 说明                                 |
| ------------------------------------------------------------ | ---------------------------------- |
| **[Web 应用](/zh/ko/features/artifact-types/web-apps)**           | 美观且功能强大的网站，可处理用户、数据库等内容。           |
| **[移动应用](/zh/ko/features/artifact-types/building-mobile-apps)** | 适用于 iPhone 和 Android 手机的原生应用。      |
| **[幻灯片](/zh/ko/features/artifact-types/slide-decks)**           | 可用于演示或导出的演示文稿。                     |
| **[动画](/zh/ko/features/artifact-types/animated-videos)**        | 动态图形和动画视频，可导出为 MP4。                |
| **[数据可视化](/zh/ko/features/artifact-types/data-apps)**           | 可用于探索数据和创建图表的交互式控制面板和可视化内容。        |
| **3D 游戏**                                                    | 3D 游戏、模拟和交互式体验。                    |
| **[设计](/zh/ko/design/canvas)**                              | 在 设计 Canvas 中探索视觉方向，并将创意制作成原型。 |

请参阅各类型的专属页面，了解不同套餐的可用情况。

<div id="section-3">
  ## 开始使用
</div>

在 Replit 首页上，你可以通过两种方式创建：

* **描述你的想法**：输入你想要的内容——“帮我创建一个食谱应用”或“帮我为初创公司制作一份融资演示文稿。”Agent 会判断适合的类型并为你创建。
* **选择类型**：在描述想法之前，选择你想创建的工件——Web 应用、移动应用、数据可视化、动画、3D 游戏或其他受支持的类型。

你随时可以在聊天中向 Agent 提出请求，或点击预览面板中的 **+** 按钮，为现有项目添加更多内容。

<div id="section-4">
  ## 在工件之间切换
</div>

如果项目中有多个工件，您可以在**预览面板**或**素材库侧边栏**中切换。您也可以让 Agent 执行操作，例如“显示移动应用”或“切换到幻灯片”。

<div id="section-5">
  ### 素材库侧边栏
</div>

素材库侧边栏集中展示项目中的所有内容。这里会显示工件、Agent 生成或下载的图片，以及其他项目资源。打开左侧面板中的素材库侧边栏，即可在整个项目中查找和复用资源。

<div id="section-6">
  ## 一个项目中的多个工件
</div>

一个项目最多可包含 **7 个工件**，其中移动应用最多只能有 **1 个**。例如，你可以在同一个项目中为客户创建 Web 应用、为团队创建移动应用，并为投资者制作幻灯片。

<ArtifactGrid />

<div id="section-7">
  ### 向项目添加工件
</div>

你可以通过以下三种方式向现有项目添加工件：

* **聊天**：向 Agent 提出请求，例如“在这个项目中添加一个移动应用”或“创建一份用于投资者路演的幻灯片”
* **添加按钮**：点击预览面板中的 **+** 按钮，然后选择要创建的内容
* **素材库侧边栏**：浏览现有工件、图片和其他资源，并在此添加新工件

<div id="section-8">
  ### 共享数据和后端
</div>

同一项目中的工件会自动共享数据和后端逻辑。客户通过 Web 应用下单后，你可以在移动应用和数据控制面板中查看该订单。无需单独设置连接，也无需重复编写代码，一切都会自动运行。

<Note>
  发布后，整个项目会同时上线。所有工件会一同发布，因此始终保持同步。
</Note>

<div id="section-9">
  ### 搭配示例
</div>

* **Web 应用 + 移动应用**：一家餐厅同时拥有面向客户的 Web 应用和面向员工的移动应用——两者都连接到同一 API 和数据库
* **应用 + 管理控制面板**：主打产品配有内部管理面板，用于管理内容、用户和设置
* **应用 + 幻灯片**：产品和融资演示文稿位于同一项目中，幻灯片始终与最新版本保持同步
* **数据控制面板 + 视频**：实时数据可视化搭配用于讲解亮点的动画视频

<div id="section-10">
  ## 发布
</div>

应用、幻灯片和视频均可发布和分享。发布后，它们各自都会有一个可分享的 URL。

非工件的文件和资源 (如 CSV、图片和 Markdown 文件) 本身无法发布。要分享这些内容，请将其添加到应用中，或创建新的工件。

<div id="section-11">
  ## 常见问题
</div>

<Accordion title="一个项目可以包含多个工件吗？">
  可以。一个项目最多可包含 **7 个工件**，且**每个项目仅限 1 个移动应用**。项目中的所有工件会自动共享同一后端和数据。

  如果已达到移动应用数量上限，但想创建第二个移动应用，请在新项目中创建。如果已达到 7 个工件的总数上限，请先移除现有工件，或将工作拆分到多个项目中，再添加其他工件。
</Accordion>

<Accordion title="开始前需要选择类型吗？">
  不需要。只需描述您想要的内容，Agent 会选择合适的类型。如果愿意，也可以从下拉菜单中直接选择类型。
</Accordion>

<Accordion title="可以只发布项目中的一个工件吗？">
  目前不可以。发布后，整个项目会一同上线，以确保所有工件保持同步。如需独立发布，请使用单独的项目。
</Accordion>

<Accordion title="工件之间会共享数据吗？">
  会。项目中的所有工件共享同一个数据库和后端服务。当 Web 应用写入数据时，移动应用和数据控制面板可立即读取。
</Accordion>

<Accordion title="工件和文件有什么区别？">
  工件是可以发布的内容——应用、幻灯片、视频。文件 (CSV、图像、代码等) 是项目中用于支持工件的资源，但本身无法发布。
</Accordion>

<Accordion title="我的移动应用缺少 Web 应用的一些功能，这是怎么回事？">
  当 Agent 在不同工件类型之间转换功能时，某些元素可能无法完全迁移，尤其是不同平台上行为不同的交互或布局。您可以通过聊天中的后续请求补充缺失部分。
</Accordion>

如需查看可创建内容的完整列表，请参阅[项目概述](/zh/ko/features/projects-and-artifacts/projects)。
