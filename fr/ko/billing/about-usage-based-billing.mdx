La publication comporte trois types de facturation à l&#39;usage :

1. Transfert de données sortant
2. Unités de calcul Autoscale
3. Requêtes

Vous pouvez consulter votre utilisation dans **Paramètres**, sous **Compte** → **Utilisation du compte**. La facturation a lieu chaque mois ou dès que le coût cumulé dépasse vos crédits mensuels. Les utilisateurs Replit Core et Pro bénéficient d&#39;un quota mensuel pour ces ressources.

Si vous avez besoin de crédits supplémentaires au-delà du quota de votre abonnement mensuel, vous pouvez acheter des packs de crédits depuis la page de facturation. Pour en savoir plus sur les packs de crédits, consultez [Gestion des dépenses](/fr/ko/billing/managing-spend).

<div id="section">
  # Publication
</div>

<div id="1">
  ## 1. Transfert de données sortantes lié à la publication
</div>

Ce type d&#39;usage est facturé à l&#39;octet, et les utilisateurs Replit Core et Pro bénéficient d&#39;un quota mensuel. Seules les données sortantes (egress) sont comptabilisées dans ce quota et peuvent générer des dépassements. À l&#39;inverse, les données entrantes (ingress) sont toujours gratuites.

| Abonnement  | Quota                                                        |
| ----------- | ------------------------------------------------------------ |
| Replit Core | 100 Gio                                                      |
| Replit Pro  | Voir les [tarifs Replit Pro](https://www.replit.com/pricing) |

Le quota s&#39;applique aux déploiements [statiques](/fr/ko/features/publishing/deployment-types#static), [Autoscale](/fr/ko/features/publishing/deployment-types#autoscale), [Reserved VM](/fr/ko/features/publishing/deployment-types#reserved-vm) et [planifiés](/fr/ko/features/publishing/deployment-types#scheduled).

Pour connaître les tarifs actuels du transfert de données sortantes, consultez la [page des tarifs](https://www.replit.com/pricing).

***

<div id="2">
  ## 2. Unités de calcul
</div>

Les déploiements Autoscale sont facturés sur la base d&#39;unités de calcul, qui tiennent compte à la fois de l&#39;utilisation du CPU et de la RAM dans le temps.

Les dépassements sont facturés en unités de calcul, avec une granularité allant jusqu&#39;à l&#39;unité près. Pour connaître le tarif actuel des unités de calcul, consultez la [page des tarifs](https://www.replit.com/pricing).

Voici comment les secondes de RAM et de CPU des déploiements Autoscale sont converties en unités de calcul :

| Ressource        | Unités de calcul |
| ---------------- | ---------------- |
| 1 seconde de RAM | 2 unités         |
| 1 seconde de CPU | 18 unités        |

Les déploiements statiques ne consomment pas d&#39;unités de calcul. Seul le transfert de données sortantes dépassant la [quantité indiquée](#) est facturé.

[En savoir plus sur les déploiements Autoscale](/fr/ko/features/publishing/deployment-types#autoscale).

***

<div id="3">
  ## 3. Requêtes
</div>

Les déploiements Autoscale tiennent également compte du nombre de requêtes traitées.

Pour connaître les tarifs actuels des requêtes, consultez la [page des tarifs](https://www.replit.com/pricing).

<div id="section-2">
  # Base de données
</div>

Replit facture uniquement l’utilisation des [bases de données de production](/fr/ko/features/data-and-storage/development-and-production). Les bases de données de développement sont toujours gratuites et incluses dans toutes les applications Replit. Pour en savoir plus sur les bases de données de développement, consultez [Base de données de développement](/fr/ko/features/data-and-storage/sql-database).

Replit PostgreSQL est un service entièrement géré et sans serveur, qui offre une haute disponibilité simplifiée et une exploitation sans maintenance. La facturation des bases de données de production repose sur l’utilisation réelle, ce qui peut permettre de réaliser des économies substantielles.

Les bases de données PostgreSQL de production sont facturées selon deux indicateurs d’utilisation :

* **[Temps de calcul](#compute-time)** : quantité de ressources de calcul consommées par heure.
* **[Stockage des données](#data-storage)** : volume total des données stockées, y compris les données historiques.

Vous pouvez consulter votre utilisation actuelle des ressources, y compris celle de votre base de données de production, dans **Paramètres** → **Compte** → **Utilisation du compte**.

<div id="section-3">
  ## Temps de calcul
</div>

Le temps de calcul est déterminé par le nombre d&#39;heures pendant lesquelles votre base de données reste active au cours d&#39;une période de facturation donnée. Une base de données est considérée comme active lorsqu&#39;elle reçoit des requêtes et pendant les 5 minutes qui suivent la dernière requête. Si elle reste inactive pendant 5 minutes, elle est suspendue.

<div id="section-4">
  ## Stockage des données
</div>

Le stockage des données correspond au volume total de données conservées dans l&#39;ensemble des bases de données de votre compte, mesuré en gibioctets (Gio). Il est calculé selon le volume maximal utilisé au cours du mois. Chaque base de données PostgreSQL consomme 33 Mo de stockage, même lorsqu&#39;elle ne contient aucune donnée : il s&#39;agit de l&#39;espace de stockage de base du serveur Postgres.

<Note>La limite de stockage totale de chaque base de données de production est de 10 gibioctets (Gio). Les bases de données de développement incluent 20 Gio de stockage gratuit par application Replit.</Note>

<div id="section-5">
  # Remarques supplémentaires
</div>

Nous vous enverrons une notification en cas de problème avec votre mode de paiement. Des échecs de paiement répétés peuvent entraîner la suspension de votre application publiée. Dans ce cas, [contactez l’assistance](https://replit.com/help) et mettez à jour vos informations de paiement afin de rétablir l’accès au service.
