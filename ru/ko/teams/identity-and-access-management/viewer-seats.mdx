<div id="viewer-seats">
  ## Места для зрителей
</div>

Пользователи с ролью Viewer имеют доступ только для чтения к приложениям и деплоям команды. Вы можете легко делиться работой с заинтересованными сторонами и соавторами, которым не нужны права на редактирование или полная лицензия команды.

Места для зрителей подходят для:

* Пользователей внутренних инструментов, которые не создают приложения
* Заинтересованных сторон, которым нужно отслеживать ход проекта
* Участников команды, изучающих возможности Replit

В тариф команды включено 50 мест для зрителей, что позволяет эффективно масштабировать совместную работу.

Чтобы добавить более 50 пользователей Viewer, обратитесь в отдел продаж по адресу [sales@replit.com](mailto:sales@replit.com) по вопросам тарифа Enterprise.

<div id="viewer">
  ## Приглашение Viewer
</div>

1. Перейдите на вкладку **Members** вашей организации.
2. Выберите **+ Add**.
3. Выберите роль Viewer.
4. Введите через запятую адреса электронной почты пользователей, которых хотите добавить в качестве Viewer.
5. Выберите **Send invites**.

<Frame>
  <img src="/assets/mirror/viewer-0-4460b3177bbe.png" alt="Отправка приглашений Viewer" width="2962" height="1860" data-path="images/teams/viewers/viewer-0.png" />

Приглашённые пользователи без учётной записи Replit получат электронное письмо с инструкциями по созданию учётной записи и присоединению к команде. Пользователи, уже имеющие учётную запись Replit, будут добавлены автоматически.

<div id="viewer-2">
  ## Доступ Viewer
</div>

<Note>
  **Обновлённое поведение доступа по умолчанию (действует с 9 июня 2025 г.)**: приложения, созданные в организации, теперь **по умолчанию приватные**. Viewer необходимо явно предоставить доступ к новым приложениям через панель Access.
</Note>

Viewer необходимо явно предоставить доступ к новым приложениям через панель Access. Пользователи с ролью viewer по-прежнему могут иметь доступ к существующим приложениям, созданным до этого изменения, в зависимости от предыдущих настроек.
