[Project Security Center](/zh/features/security/project-security-center) 和 [Workspace Security Center](/zh/features/security/workspace-security-center) 中所用安全术语的定义。

<div id="cve">
  ## CVE
</div>

通用漏洞披露 (Common Vulnerabilities and Exposures) 。CVE 是为公开披露的软件漏洞分配的唯一标识符，例如 `CVE-2024-12345`。

<div id="severity">
  ## 严重性
</div>

漏洞的风险等级：严重、高、中或低。结合严重性和暴露情况，判断应优先修复哪些 项目。

<div id="dependency">
  ## 依赖项
</div>

你的项目所依赖的第三方软件包。依赖项中的漏洞会影响所有使用它的项目，直到该依赖项被更新或替换为止。

<div id="sbom">
  ## SBOM
</div>

软件物料清单 (Software Bill of Materials) 。SBOM 是一份机器可读的清单，记录项目中使用的软件包、版本和许可证。

<div id="spdx-and-cyclonedx">
  ## SPDX 与 CycloneDX
</div>

安全与合规工具通用的标准 SBOM 格式。请选择你的审计、合规或软件成分分析工具所需的格式。

<div id="exposure">
  ## 暴露面
</div>

由发布状态和可见性决定的风险面。公开发布的 项目 暴露面高于私有或未发布的 项目。

<div id="fix-with-agent">
  ## Fix with Agent
</div>

该操作会让 Replit Agent 以后台任务的方式，为受影响的 项目 生成一份补丁。在应用生成的更改前，请先进行审查。

<div id="republish">
  ## 重新发布
</div>

使用现有的 deployment 配置重新部署 项目。应用修复后，使用 **重新发布** 发布修复后的版本。

<div id="package-firewall">
  ## 软件包防火墙
</div>

一种网络层防护，可在安装时拦截恶意软件包和已被入侵的软件包，防止它们下载到你的应用中。默认开启，由 Socket 提供支持。参见[软件包防火墙](/zh/features/security/package-firewall)。

<div id="auto-protect">
  ## Auto-Protect
</div>

Replit 自动为你的应用启用的一整套防护措施的统称。默认为每位构建者开启的防护包括：用于安装时拦截的 [软件包防火墙](/zh/features/security/package-firewall)、Web 应用防火墙 (WAF) 以及自动 SSL/TLS 加密。管理员还可选择开启自动 CVE 修复：一旦有新披露的依赖项漏洞，Replit Agent 会准备好补丁并通知 项目 所有者。参见 [Auto-Protect](/zh/features/security/project-security-center#auto-protect)。
