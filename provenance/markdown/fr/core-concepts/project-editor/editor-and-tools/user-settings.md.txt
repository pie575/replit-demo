# Paramètres utilisateur

> Apprenez à personnaliser l'Éditeur de projet avec des paramètres utilisateur qui s'appliquent à toutes vos applications.

L'outil Paramètres utilisateur de l'Éditeur de projet offre des options pour personnaliser l'apparence, le comportement et
les raccourcis clavier de votre compte.

## Fonctionnalités

Vous pouvez personnaliser votre expérience de création d'applications Replit avec ces catégories de paramètres :

* **Personnalisation du thème** : Sélectionner entre les thèmes clair et sombre pour l'Éditeur de projet
* **Intelligence du code** : Configurer les fonctionnalités propulsées par l'IA qui améliorent votre expérience de création d'applications
* **Préférences de l'éditeur** : Ajuster le comportement et l'apparence de l'éditeur de fichiers
* **Contrôles de notifications** : Gérer les préférences d'alertes
* **Options d'accessibilité** : Faire fonctionner Replit mieux pour les utilisateurs ayant des besoins spécifiques
* **Raccourcis clavier** : Définir des combinaisons de touches pour exécuter des actions courantes et naviguer dans l'interface graphique

### Apparence

Personnalisez les paramètres suivants liés à l'apparence de l'Éditeur de projet :

* **Sélection du thème** : Choisir parmi les préréglages de thèmes clairs et sombres, les <a href="https://replit.com/themes" target="_blank">thèmes de la communauté</a> ou votre thème personnalisé
* **Thèmes personnalisés** : Créer des palettes de couleurs personnalisées à l'aide de l'éditeur [Thèmes](/fr/core-concepts/project-editor/editor-and-tools/themes)

### Préférences de l'éditeur de fichiers

Contrôlez l'apparence et le comportement de l'éditeur de fichiers à l'aide des paramètres suivants :

* **Taille de la police** : Ajuster la taille du texte pour la lisibilité
* **Fermeture automatique des crochets** : Insérer automatiquement les crochets fermants lorsque vous tapez un crochet ouvrant
* **Détection de l'indentation** : Détecter automatiquement les paramètres d'indentation à l'ouverture d'un fichier
* **Formater l'indentation du texte collé** : Reformater le code collé pour suivre l'indentation correcte
* **Caractère d'indentation** : Choisir entre les espaces et les tabulations pour l'indentation du code
* **Taille de l'indentation** : Définir le nombre de colonnes pour chaque niveau d'indentation
* **Retour à la ligne** : Configurer le comportement du retour à la ligne
* **Minimap** : Inclure un aperçu du code navigable dans une barre latérale
* **Touche modificatrice de sélection multiple** : Définir le modificateur clavier pour la sélection de plusieurs fichiers
* **Statut Git dans l'arborescence** : Afficher les indicateurs de statut Git dans l'arborescence de fichiers

### Intelligence du code

Configurez les outils propulsés par l'IA à l'aide des paramètres suivants :

* **Jetons sémantiques** : Utiliser une coloration syntaxique améliorée propulsée par les serveurs de langages
* **Complétion de code IA** : Ajouter des suggestions de code en ligne au fur et à mesure que vous tapez
* **Accepter la suggestion sur le caractère de validation** : Accepter automatiquement les suggestions de code en tapant certains caractères

### Préférences Shell et Prévisualisation

Personnalisez le comportement des outils Shell et Prévisualisation :

* **Indicateur sonore du Shell** : Jouer des sons lorsque l'outil Shell rencontre des problèmes
* **Prévisualisation automatique** : Ouvrir l'onglet Prévisualisation automatiquement lorsqu'un serveur devient disponible
* **Transférer automatiquement les ports ouverts** : Configurer la gestion des ports nouvellement détectés

### Notifications

Gérez les paramètres de notifications suivants :

* **Notification audio Agent** : Jouer des sons lorsqu'Agent demande des commentaires
* **Notification push Agent** : Recevoir des notifications push mobiles lorsqu'Agent demande des commentaires

### Accessibilité

Vous pouvez personnaliser le paramètre d'accessibilité suivant :

* **Sortie de terminal accessible** : Activer la compatibilité avec les lecteurs d'écran pour les outils Shell et Console

### Raccourcis clavier

Pour accéder aux préférences de raccourcis clavier, sélectionnez l'onglet **Raccourcis clavier** dans l'outil Paramètres utilisateur.

Vous pouvez rechercher des combinaisons de touches à l'aide des méthodes suivantes :

* **Nom** : Tapez le nom ou la description du raccourci clavier dans le champ de recherche
* **Combinaison de touches** : Sélectionnez l'icône <img class="icon-svg" src="https://mintcdn.com/replit/rJldsgYVucXB_6kW/images/icons/keyboard.svg?fit=max&auto=format&n=rJldsgYVucXB_6kW&q=85&s=81adf8d47b1ee530465dc80bccd074b5" alt="icône clavier" width="16" height="16" data-path="images/icons/keyboard.svg" /> et entrez la combinaison de touches

Utilisez les actions suivantes pour gérer les raccourcis :

* **Ajouter** : Sélectionnez **Ajouter un raccourci**
* **Mettre à jour** : Sélectionnez l'icône <img class="icon-svg" src="https://mintcdn.com/replit/rJldsgYVucXB_6kW/images/icons/pencil-icon.svg?fit=max&auto=format&n=rJldsgYVucXB_6kW&q=85&s=09de925e41efd3d1cfa199737639b5a6" alt="icône crayon" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> crayon
* **Supprimer** : Sélectionnez l'icône <img class="icon-svg" src="https://mintcdn.com/replit/X_IP1EeHGm0cA2VA/images/icons/trash-icon.svg?fit=max&auto=format&n=X_IP1EeHGm0cA2VA&q=85&s=031a29f126332bebd5b6a74de4f16e40" alt="icône corbeille" width="16" height="16" data-path="images/icons/trash-icon.svg" /> corbeille
