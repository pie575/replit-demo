<div id="agent-v2">
  ### Agent v2
</div>

<img src="/assets/mirror/agent-web-01b1f9026de7.webp" alt="Agent v2" width="800" height="450" data-path="images/changelog/2025-02-28/agent-web.webp" />

全新的 Agent 体验现已面向所有构建者推出。新版 Agent 比以往更快、更准确，性能也更出色。

现在，它由 Anthropic 最先进的模型 Claude 3.7 Sonnet 驱动。

加入 Explorer 计划，亲自体验。请在[此处](https://youtu.be/pE_XT2TaXCA)查看指南。

<div id="section-3">
  ### 部署改进
</div>

现在，当构建者尝试为动态应用选择静态部署时，AI 会显示建议，帮助 Agent 更好地处理部署请求。

<img src="/assets/mirror/deployments-debugger-will-now---non-static-app-220824-748b5209b50c.png" alt="部署调试器改进" width="1604" height="1244" data-path="images/changelog/2025-02-28/deployments-debugger-will-now---non-static-app-220824.png" />

<div id="claude-37-sonnet">
  ### Claude 3.7 Sonnet 上线
</div>

高级 Assistant 模式现已为所有付费构建者升级至 Claude 3.7 Sonnet，处理复杂请求时的准确度和性能均有提升。

<img src="/assets/mirror/50526c4ea4d114b4cd8268425398dd4ed3c2d736_bc521d9780846c35d990a72459794dd81370515f_twitter-fb2c893cd78a.jpeg" alt="Claude 3.7 界面" width="1200" height="674" data-path="images/changelog/2025-02-28/50526c4ea4d114b4cd8268425398dd4ed3c2d736_bc521d9780846c35d990a72459794dd81370515f_twitter.jpeg" />

<div id="section-4">
  ### 数据库性能提升
</div>

数据库操作速度比以往更快，耗时最长的操作已从 200ms 降至不足 1ms。

<div id="section-5">
  ### 更好的文档
</div>

<img src="/assets/mirror/cleanshot-2025-02-27-at-1042282xpng-220848-e5317a7cfb93.png" alt="文档重新设计" width="3680" height="2382" data-path="images/changelog/2025-02-28/cleanshot-2025-02-27-at-1042282xpng-220848.png" />
