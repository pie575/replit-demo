<div id="intelligent-model-routing">
  ### Routage intelligent des modèles
</div>

Le routage intelligent des modèles sélectionne automatiquement le modèle et le niveau d&#39;effort les mieux adaptés à votre tâche, en conciliant qualité et coût. En mode **Power** ou **Max**, sélectionnez **Auto** pour laisser Replit orienter chaque partie de votre travail à mesure que sa complexité évolue. Vous pouvez aussi choisir un modèle et un niveau d&#39;effort précis si vous souhaitez garder la main.

En savoir plus sur le [mode Auto](/fr/chat/auto-mode).

<div id="intelligent-model-routing-for-enterprise">
  ### Routage intelligent des modèles pour Enterprise
</div>

Le routage intelligent des modèles est désormais le mode Agent par défaut des Workspace Enterprise. Lorsque le **mode Auto** est activé, Replit choisit le mode le plus adapté et un modèle autorisé pour chaque tâche. Les administrateurs de compte peuvent contrôler la disponibilité des modèles dans chaque Workspace, et vous pouvez désactiver le **mode Auto** pour sélectionner un modèle activé. Le menu des modes Agent Enterprise propose désormais **Power** et **Max** et n’inclut plus **Lite**.

<Frame caption="Activez le mode Auto pour laisser Replit choisir le mode et le modèle les plus adaptés à chaque tâche.">
  <img src="/assets/mirror/enterprise-auto-mode-9365b7d49c0d.png" alt="Paramètres d’Agent avec le mode Auto activé et le modèle verrouillé sur Auto" width="558" height="356" data-path="images/changelog/2026-08-28/enterprise-auto-mode.png" />
</Frame>

En savoir plus sur les [contrôles des modèles Enterprise](/fr/features/collaboration/enterprise-model-controls).

<div id="customize-connectors">
  ### Personnaliser les connecteurs
</div>

Les organisations Enterprise peuvent désormais utiliser des configurations OAuth personnalisées pour leurs connecteurs. Par exemple, configurez Gmail avec vos propres **Client ID**, **Client Secret** et **scopes** plutôt qu&#39;avec les valeurs par défaut de Replit.
