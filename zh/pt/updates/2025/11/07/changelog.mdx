<div id="cone-animado-do-agente">
  ### Agent 动画图标
</div>

Agent 图标现在会在运行时播放动画，更直观地表明 Agent 正在工作。这一改进提升了速度感，也让你更容易留意到 Agent 在初始规划阶段的动态，尤其是在居中的 Chat 布局中，反馈就紧贴在你的请求下方。

<div id="menu-suspenso-de-ferramentas-do-agent-no-fluxo-de-planejamento">
  ### 规划流程中的 Agent 工具下拉菜单
</div>

Agent 工具下拉菜单现已支持在初始规划和任务清单审批流程中使用。你可以在开始创建时就配置好 Agent 偏好设置，包括自主级别等各项选项。

<div id="suporte-a-nomes-de-arquivos-com-no-agent">
  ### Agent 支持用 @ 提及文件名
</div>

Agent 现在除了 `/` 命令外，还支持使用 `@` 提及文件名，在交互设计上与主流开发工具保持一致。该功能是企业用户和熟悉 Cursor 式工作流的高级用户呼声最高的需求之一。

<div id="suporte-a-connectors-para-remixagem">
  ### Remix 对 Connectors 的支持
</div>

此前，对任何使用了 connector 的 Replit 应用执行 Remix 时，集成都会失效，因为 Remix 出的 repl 不会自动获得使用该 connector 的授权。我们已更新 Remix 流程，以妥善处理 connector：

* 用户在 Remix 时会收到提示，需配置所需的 connector
* Remix 过程会明确指出哪些集成需要配置
* 不会再出现 Remix 后集成失效的情况

进一步了解 [Agent 集成](/zh/replitai/integrations)和[管理你的 connector](/zh/pt/replitai/managing-connectors)。

<div id="painel-de-analytics-para-admins-corporativos">
  ### 面向企业管理员的分析面板
</div>

企业管理员现在可以使用功能全面的分析面板——这是包括 Meta 和 Atlassian 在内的众多企业客户呼声很高的功能。该面板提供：

* **用户活动监控**：跟踪整个组织的参与和协作情况
* **资源使用跟踪**：按用户和 Replit App 监控支出
* **部署监督**：跟踪部署活动
* **成本管理**：清晰掌握资源消耗与成本
