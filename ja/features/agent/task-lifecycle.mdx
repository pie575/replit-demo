## 下書き

**下書き**は、Agent が計画したがまだ構築を開始していないタスクです。下書きには提案された作業（タスクのタイトル、説明、計画）のみが含まれるため、安全にレビューできます。

下書きを使って、Agent が目標を正しく理解しているかどうかを確認してください。タスクを開始したり、計画の修正を Agent に依頼したり、後のために下書きをアーカイブしたりできます。

## アクティブ

**アクティブ**タスクはバックグラウンドで実行中です。Agent はプロジェクトの独立したコピーで作業するため、タスクの実行中もメインバージョンは変更されません。

アクティブタスクが実行している間もメインスレッドを使い続けることができます。タスクにフィードバックが必要な場合は、そのスレッドを開いて会話を続けてください。

## キュー済み

**キュー済み**タスクは承認済みですが、開始待ちの状態です。タスクが別のタスクに依存している場合や、プランのアクティブなバックグラウンドタスク制限に達している場合にキューに入ることがあります。

キュー済みタスクは、前提条件が完了してアクティブなタスクスロットが開いたときに自動的に開始されます。

## レディ

**レディ**タスクは完了しましたが、変更がまだメインバージョンに適用されていません。変更を適用する前に、タスクの作業ログ、テスト結果、プレビューをレビューしてください。

作業が正しければメインに適用してください。期待通りでなければ却下して新しいタスクを開始してください。

## 適用中

**適用中**タスクは、変更をメインバージョンに移動する途中です。複数のタスクから変更を適用する際の競合は Agent が自動的に処理します。

最終結果を判断する前に適用が完了するまで待ってください。その後何か問題があれば、メインスレッドで Agent に修正を依頼してください。

## 完了

**完了**タスクは終了しており、アクションは不要です。完了には、メインバージョンに適用済み、開始前にアーカイブ済み、構築に移行してからキャンセル済みの場合が含まれます。

**完了**列を、完了済み、アーカイブ済み、キャンセル済みのタスク作業の履歴として使用してください。

## タスクのアーカイブとキャンセル

タスクはライフサイクルの任意の時点で停止できますが、表示されるオプションはボード上のタスクの位置によって異なります。**アーカイブ**と**キャンセル**はどちらもタスクを**完了**列に移動しますが、動作が異なります：

| アクション     | 利用可能なタイミング                                          | 何が起こるか                                           | 元に戻せるか？                                             |
| --------- | --------------------------------------------------- | ------------------------------------------------ | --------------------------------------------------- |
| **アーカイブ** | タスクがまだ計画セッション中の場合：構築を開始していない**下書き**                 | 実行せずに計画セッションが保留にされます。計画は保持されます。                  | はい。**完了**列のアーカイブ済みカードを開いて**下書き**に復元できます。            |
| **キャンセル** | タスクが計画から構築に移行した後：**アクティブ**、**キュー済み**、または**レディ**のタスク | Agent がタスクを停止し、進行中の作業を破棄します。メインバージョンに変更は適用されません。 | いいえ。キャンセルされたタスクは復元できません。作業を再開したい場合は新しいタスクを開始してください。 |

後で再検討したい計画セッションには**アーカイブ**を使用してください。キュー済み、実行中、または構築完了のタスクの永久停止ボタンとして**キャンセル**を使用してください。

アーカイブ済みの計画セッションとキャンセル済みのタスクは、完了済みのタスクとともにタスクボードの右端にある**完了**列で確認できます。
