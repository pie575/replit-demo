<Note>
  Vous souhaitez imposer le SSO pour votre **organisation Replit** (connexion à replit.com) ? Cela se configure séparément — consultez [Authentification unique (SAML SSO)](/fr/teams/identity-and-access-management/saml). Cette page explique comment ajouter le SSO au flux de connexion d&#39;**une application que vous créez** sur Replit.
</Note>

Permettez à vos utilisateurs de se connecter à votre application avec le fournisseur d&#39;identité de leur entreprise, comme Okta ou Microsoft Entra ID. Si votre application utilise [Clerk Auth](/fr/features/auth-and-identity/clerk-auth), vous configurez le SSO et les autres fonctionnalités d&#39;authentification avancées depuis le tableau de bord Clerk. Exprimez votre besoin à Agent : il vous orientera vers le tableau de bord pour finaliser la configuration.

  <img src="/assets/mirror/sso-cover-28a76bfa16fb.jpeg" alt="Bannière Créez des applications Replit avec le SSO ornée d'une icône de cadenas, montrant un créateur travaillant sur un ordinateur portable." width="1920" height="1080" data-path="images/workspace/auth/sso-cover.jpeg" />
</Frame>

Le tableau de bord Clerk va bien au-delà de l&#39;expérience de connexion par défaut. Toute configuration effectuée dans Clerk s&#39;applique automatiquement à l&#39;authentification de votre application Replit.

<div id="what-you-can-configure">
  ## Ce que vous pouvez configurer
</div>

* **Connexions SSO Enterprise** : configurez l&#39;authentification unique avec Okta ou Microsoft Entra ID, via OIDC ou SAML. Permettez à vos clients de se connecter avec le fournisseur d&#39;identité de leur entreprise. Le SSO sécurise également les outils internes qui traitent des données sensibles : les listes blanches d&#39;adresses e-mail gérées manuellement cèdent la place au fournisseur d&#39;identité déjà en place dans votre entreprise.
* **Authentification multifacteur (MFA)** : ajoutez la MFA au flux de connexion de votre app.
* **Contrôles de session** : ajustez la durée des sessions et la fréquence de vérification.
* **Autres paramètres Clerk** : toute configuration Clerk supplémentaire s&#39;applique automatiquement à votre Replit App. Ne modifiez pas les clés d&#39;API ni les paramètres d&#39;environnement — Replit s&#39;en charge. Consultez [Environnements de développement et de production](/fr/features/auth-and-identity/clerk-auth#development-and-production-environments).

<div id="open-the-clerk-dashboard">
  ## Ouvrir le tableau de bord Clerk
</div>

Demandez à Agent la modification d&#39;authentification dont vous avez besoin. Agent configure ce qu&#39;il peut et vous redirige vers le tableau de bord Clerk de votre app pour les réglages qui nécessitent votre intervention.

<Frame>
  <img src="/assets/mirror/build-with-sso-agent-workflow-46422788bd18.webp" alt="Agent redirige une app propulsée par Clerk vers la configuration du SSO d'entreprise dans le tableau de bord Clerk." width="1602" height="1080" data-path="images/workspace/auth/build-with-sso-agent-workflow.webp" />
</Frame>

Vous pouvez aussi ouvrir le tableau de bord depuis le Workspace :

1. Dans le volet Tools, sélectionnez **Users &amp; Auth**.
2. Sélectionnez l&#39;onglet **Configure**.
3. Sélectionnez **Advanced**.
4. Sous **Clerk dashboard**, sélectionnez **Open Clerk dashboard**.

<Frame>
  <img src="/assets/mirror/open-clerk-dashboard-tools-pane-a314ffea741d.webp" alt="L'outil Users & Auth avec l'onglet Configure ouvert, montrant la section Advanced et le bouton Open Clerk dashboard." width="2158" height="1372" data-path="images/workspace/auth/open-clerk-dashboard-tools-pane.webp" />
</Frame>

<div id="set-up-an-enterprise-sso-connection">
  ## Configurer une connexion SSO Enterprise
</div>

1. Dans le tableau de bord Clerk, sélectionnez **Configure**.
2. Sous **User &amp; authentication**, sélectionnez **SSO connections**.
3. Sélectionnez **Enterprise**.
4. Sélectionnez **Add connection**.

<Frame>
  <img src="/assets/mirror/build-with-sso-enterprise-connections-b0a6a27885b5.webp" alt="Tableau de bord Clerk affichant la page des connexions SSO Enterprise et l'action Add connection." width="1826" height="1080" data-path="images/workspace/auth/build-with-sso-enterprise-connections.webp" />
</Frame>

Pour configurer la connexion dans son intégralité, consultez la [documentation Clerk](https://clerk.com/docs).

<div id="validate-the-connection">
  ### Valider la connexion
</div>

Une fois la configuration terminée, connectez-vous avec un compte de test de votre fournisseur d&#39;identité. Vérifiez que ce compte peut bien accéder aux parties prévues de votre application.

Si la connexion échoue, demandez de l&#39;aide à Agent. Indiquez dans votre demande le fournisseur d&#39;identité, le protocole et le message d&#39;erreur.

<Note>
  Cette page traite du SSO d&#39;entreprise pour le flux de connexion propre à votre application. Pour la connexion via un réseau social (Google, GitHub, Apple ou X) — appelée **SSO providers** dans le Workspace — consultez [Fournisseurs de connexion](/fr/features/auth-and-identity/sign-in-providers). Cette page ne couvre ni la migration vers Replit Auth ni la connexion SAML aux comptes Replit.
</Note>

<div id="pricing-and-availability">
  ## Tarification et disponibilité
</div>

L&#39;accès au tableau de bord Clerk est inclus dans le plan [Replit Pro](/fr/billing/plans/replit-pro). Les plans Enterprise arrivent bientôt.

<Info>
  Les connexions SSO Enterprise sont gratuites jusqu&#39;au 1er octobre 2026. Passé cette date, la tarification du SSO s&#39;aligne sur celle de Clerk et est répercutée sur votre facture Replit.
</Info>
