<div id="agent">
  ### 安全 Agent 审查整个代码库
</div>

**安全 Agent** 是一款全新的 AI 审查工具，可对整个项目进行审计，而不只是检查依赖项。它会构建威胁模型、梳理路由和数据流、使用 Semgrep 和 HoundDog.ai 进行静态分析，并借助 LLM 根据应用上下文判断哪些检测结果确实可被利用。审查完成后，安全 Agent 会将已确认的检测结果整理为可由 Replit Agent 一次性修复的并行任务。

<Frame>
  <img src="/assets/mirror/security-agent-findings-b425392bb98a.png" alt="项目安全中心中的安全 Agent 面板。显示已完成的扫描，其中包含按严重程度整理的 5 项检测结果，以及“等待审查”或“等待重新发布”等状态；还显示自动依赖项扫描部分，其中列出了存在漏洞的软件包" width="1438" height="808" data-path="images/changelog/2026-04-24/security-agent-findings.png" />
</Frame>

所有付费构建者均可使用安全 Agent。打开项目的**安全**面板，然后选择**使用 Agent 运行扫描**即可试用。

了解更多[安全 Agent](/zh/core-concepts/security/project-security-center#agent-security-scans)的相关信息。

<div id="cve-auto-protect">
  ### CVE Auto-Protect 自动修复严重漏洞
</div>

当 App 依赖的软件包披露新的严重 CVE 时，**CVE Auto-Protect** 会在您拥有的所有项目中检测受影响项，让 Agent 通过后台任务准备补丁并运行测试，确认不会造成任何功能损坏，然后通过附带审核链接的通知告知您。您始终拥有控制权——在您批准修复前，不会发布任何内容。

这样一来，无需等到自己发现新披露的漏洞，您就能在几分钟内为 App 打上补丁。

了解有关 [CVE Auto-Protect](/zh/core-concepts/security/project-security-center#auto-protect) 的更多信息。

<div id="iosandroid">
  ### 在 iOS 模拟器或 Android 模拟器中预览
</div>

<Frame>
  <video autoPlay muted loop playsInline src="/assets/mirror/ios-emulator-9013ff1b602f.mp4" />
</Frame>

如果项目包含移动 App，现在可在工作区的预览面板中直接串流使用**iOS 模拟器**或**Android 模拟器**。无需 Xcode、Android Studio 或实体设备。只需使用 Agent 构建移动 App，在预览面板的下拉菜单中选择设备，然后像在实体设备上一样轻点操作即可。Agent 做出更改后，模拟器会自动热重载。

使用 Chrome、Safari 或基于 Chromium 的浏览器的 Core、Pro 和 Enterprise 套餐付费构建者均可使用此功能。Firefox 不支持移动模拟器。

了解更多关于[在模拟器或仿真器中预览](/zh/ja/features/artifact-types/building-mobile-apps#preview-on-a-simulator-or-emulator)的信息。

  ### 为旧项目添加移动 App
</div>

<Frame>
  <img src="/assets/mirror/multi-artifact-update-approval-f6fa8b70a100.png" alt="Agent 聊天面板中显示“更新项目以创建移动 App”的确认卡片，其中包含 5 美元额度优惠以及“暂不”/“更新项目”按钮。" width="991" height="589" data-path="images/replitai/multi-artifact-update-approval.png" />

现在，你可以更新在 Agent 4 发布前创建的项目，使其支持多个 Artifact。这意味着，你可以为原先仅支持一个 Artifact 的项目添加移动 App、融资演示文稿或其他 Artifact。Agent 会在重组项目时保留 URL、数据、密钥和部署。全面推出后的前 48 小时内，已有超过 200 个项目完成迁移。

详细了解[如何更新旧项目以支持多个 Artifact](/zh/ja/features/projects-and-artifacts/updating-projects-for-multiple-artifacts)。

<div id="plaid">
  ### Plaid 连接器现已发布
</div>

借助 **Plaid** 连接器，您现在可以连接超过 12,000 家金融机构。团队管理员只需在 **Integrations** 中配置一次凭据，App 用户即可通过 Plaid Link 认证自己的银行账户。访问令牌按用户划分作用域，因此数据始终保持私密。

您可以构建使用真实交易数据的个人理财教练、连接券商的实时投资组合追踪器等应用。有关演示和设置说明，请参阅 [Replit x Plaid 合作伙伴页面](https://replit.com/partners/plaid)。

详细了解[管理连接器](/zh/ja/replitai/managing-connectors)。
