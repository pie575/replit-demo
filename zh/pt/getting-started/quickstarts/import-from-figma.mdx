<div id="importar-do-figma">
  ## 从 Figma 导入
</div>

⏰ *预计用时：三分钟*

将 Figma 中的 frame 导入 Replit，把设计转换为可运行的 React 应用。

如需了解完整的导入选项，包括 GitHub、Bolt、Lovable 等其他平台，请参阅[导入功能文档](/zh/pt/core-concepts/project-editor/app-setup/import)。

<div id="antes-de-comear">
  ## 开始之前
</div>

* 一个包含待导入 frame 的 Figma 文件
* 连接 Figma 账户的权限
* 一个 Replit 账户

<div id="passos-de-importao">
  ## 导入步骤
</div>

1. 打开 [replit.com/import](https://replit.com/import)。
2. 选择 **Figma**。
3. 连接你的 Figma 账户。
4. 在 Figma 中选中一个 frame，并复制其 URL。
5. 将该 URL 粘贴到 Replit 中。
6. 选择 **导入**。

<div id="o-que-importado">
  ## 导入的内容
</div>

* 主题和组件样式
* 图片和图标
* React 项目的项目结构

<div id="melhorar-a-qualidade-da-converso">
  ## 提升转换质量
</div>

* 尽可能使用自动布局。
* 图层命名应简短且具有描述性。
* 导入前将组转换为 frame。
* 将图像图层标记为可导出。

<div id="limites-de-importao">
  ## 导入限制
</div>

Figma 会根据你的套餐和 Figma 席位类型限制导入频率。这些限制由 Figma 设定，而非 Replit。

* **Free、Starter、View 和 Collab 席位**：每月 1 次导入。
* **Dev 和 Full 席位** (Pro、Organization 或 Enterprise 套餐) ：额度更高，并设有每分钟和每日限制。

如果导入时触发速率限制，请升级到 Figma 的 Dev 或 Full 席位以获得更高额度。完整详情请参阅 <a href="https://developers.figma.com/docs/figma-mcp-server/plans-access-and-permissions" target="_blank" rel="noreferrer">Figma 套餐与权限文档</a>。

<div id="interaja-no-chat-do-agent-beta">
  ## 在 Agent 的 Chat 中交互 (beta)
</div>

导入完成后，你可以将 Figma 链接粘贴到 Agent 的 Chat 中，用于检查图层、提取 token 并请求修改代码。使用 Agent 的 Chat 功能时，建议搭配 Figma 的 <strong>Dev</strong> 或 <strong>Full</strong> 席位。Free 和 Starter 席位每月仅限 6 次 MCP 工具调用。

请参阅指南：[Figma MCP 集成](/zh/replitai/mcp/figma)。
