<div id="section">
  ## Qu&#39;est-ce qu&#39;une compétence ?
</div>

Une compétence est un dossier. Il contient un fichier nommé `SKILL.md` qui décrit les instructions à suivre par Agent, ainsi que les fichiers de support auxquels vous souhaitez qu&#39;il se réfère. Les compétences sont enregistrées dans le répertoire `/.agents/skills` de votre projet et respectent la [spécification des compétences Agent](https://agentskills.io/specification), un standard ouvert qui fonctionne d&#39;un agent à l&#39;autre.

Agent consulte le nom et la description de toutes les compétences installées, mais ne charge l&#39;intégralité du contenu d&#39;une compétence que lorsqu&#39;il la juge pertinente pour la tâche en cours. Les compétences sont donc économes en contexte : vous pouvez en installer un grand nombre sans dégrader la qualité des résultats d&#39;Agent.

<div id="section-2">
  ## Compétences prédéfinies
</div>

Replit intègre des compétences prédéfinies, accessibles depuis le sélecteur **Utiliser une compétence** du chat et depuis le sélecteur de point de départ des nouveaux projets. Ces compétences fonctionnent dans tous les projets, sans installation. Pour consulter le catalogue complet, les compétences partenaires et la procédure d&#39;installation, rendez-vous dans le [répertoire des compétences](/fr/ja/features/agent/skills-directory).

Pour ajouter une compétence prédéfinie, ouvrez le sélecteur **Utiliser une compétence** dans la zone de saisie du chat et choisissez une compétence, ou demandez simplement à Agent de charger la compétence.

<div id="section-3">
  ## Portée des compétences
</div>

Les compétences peuvent être définies à différents niveaux de portée :

| Portée                       | Disponibilité                                            | Emplacement de stockage                                                                                                           |
| ---------------------------- | -------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| **Niveau projet**            | Un projet spécifique uniquement                          | Versionné avec les fichiers dans `/.agents/skills`                                                                                |
| **Niveau espace de travail** | Accessible à tous les membres de l&#39;espace de travail | Géré de façon centralisée dans les paramètres de l&#39;espace de travail                                                          |
| **Entreprise**               | Standards à l&#39;échelle de l&#39;entreprise            | Inclus dans les [templates personnalisés](/fr/ja/teams/custom-templates) et les [systèmes de design](/fr/ja/teams/custom-design-system) |

Pour les compétences au niveau de l&#39;espace de travail, consultez [Personnalisation d&#39;Agent](/fr/ja/features/agent/agent-customization) pour savoir comment configurer les compétences d&#39;espace de travail et les instructions personnalisées destinées à votre équipe.

<div id="agent">
  ## Comment Agent charge les compétences
</div>

Agent charge les métadonnées (nom et description) de toutes les compétences installées à chaque conversation. Le corps d&#39;une compétence n&#39;est chargé que si Agent l&#39;estime pertinent pour la tâche en cours. Le contenu des compétences reste ainsi en dehors de la fenêtre de contexte jusqu&#39;à ce qu&#39;il devienne nécessaire.

Les compétences installées sont conservées dans le projet d&#39;une session Agent à l&#39;autre et peuvent être validées dans le contrôle de version afin d&#39;être partagées avec l&#39;équipe.

<div id="ai">
  ## Intégration avec d&#39;autres outils de codage IA
</div>

<Accordion title="Importer des compétences depuis d'autres outils de codage IA">
  Si vous utilisez plusieurs outils de codage IA, [rulesync](https://github.com/dyoshikawa/rulesync) prend en charge Replit et vous aide à maintenir des configurations cohérentes.

  Vous pouvez importer des compétences depuis d&#39;autres assistants de codage IA :

  ```bash theme={null}
  npx rulesync init
  npx rulesync import --targets claudecode --features skills
  npx rulesync generate --targets replit --features skills
  ```

  Vous disposez ainsi d&#39;un ensemble unique de compétences utilisable dans différents environnements de développement.
</Accordion>
