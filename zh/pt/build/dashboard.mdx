仪表板能帮助人们依据数据做出决策。

你将基于一份公开的 CSV 文件构建一个 **Global Progress Explorer**：数据为国家级别，包含年份、人口、大洲、预期寿命和人均 GDP。

<div id="o-que-voc-vai-conquistar">
  ## 你将收获什么
</div>

完成本指南后，你将拥有：

* 一个基于真实公开 CSV 数据构建的 Global Progress Explorer 仪表板。
* 涵盖国家、人口、预期寿命和人均 GDP 的汇总指标。
* 展示进展如何随时间变化的图表和筛选器。
* 一种验证仪表板数据与源数据是否一致的方法。
* 一个可分享或可发布给相关方的仪表板。

<div id="o-que-voc-vai-aprender">
  ## 你将学到什么
</div>

你将学习如何：

* 从要做的决策出发，而不是从图表类型出发。
* 让 Agent 基于公开的 CSV 文件构建仪表板。
* 对照底层数据核对计算结果。
* 添加筛选条件和洞察摘要。
* 判断仪表板何时需要登录、刷新、导出或接入实时数据。

<div id="para-quem-este-guia">
  ## 本指南适合谁
</div>

如果你手上有客户、销售、产品、运营、调研或受众数据，并且需要一个人人都看得懂的仪表板，那么这份指南正适合你。

它适用于分析师、运营人员、创始人、产品经理、教育工作者，以及需要把原始数据转化为决策的团队。

<div id="defina-a-deciso">
  ## 明确决策目标
</div>

在动手构建之前，先写下这个仪表板需要支持的决策。

以全球发展数据集为例：

* **问题**：哪些地区的预期寿命和人均 GDP 随时间推移有所改善？
* **受众**：教育、研究、战略团队或非营利组织。
* **有用的指标**：国家数量、年份范围、最新的预期寿命中位数、覆盖的总人口以及人均 GDP 中位数。
* **有用的筛选器**：大洲、国家和年份范围。

如果你说不清要支持什么决策，仪表板就只会沦为一堆图表的集合，而不是一个真正有用的工具。

<div id="construa-a-partir-de-um-csv-pblico">
  ## 基于公开 CSV 构建
</div>

选择一个内容积极正面的公开数据集，字段要有实际意义，行数也要足够多，便于探索。

数据集：[Gapminder 全球进展 CSV](https://raw.githubusercontent.com/plotly/datasets/master/gapminderDataFiveYear.csv)

让 Agent 基于该 CSV 构建仪表板：

<AiPrompt>
  基于这个公开 CSV 构建一个 Global Progress Explorer 仪表板：<br />
  [https://raw.githubusercontent.com/plotly/datasets/master/gapminderDataFiveYear.csv](https://raw.githubusercontent.com/plotly/datasets/master/gapminderDataFiveYear.csv)<br />
  该仪表板要帮助教育或研究团队了解 1952 年至 2007 年间各国家、各大洲的预期寿命、人口和人均 GDP 发生了怎样的变化。<br />
  加入汇总卡片，展示国家总数、年份范围、最新预期寿命中位数、覆盖的总人口以及最新人均 GDP 中位数。<br />
  添加一个折线图，按大洲展示预期寿命随时间的变化。<br />
  添加一个气泡图，x 轴为人均 GDP，y 轴为预期寿命，气泡大小代表人口，颜色代表大洲。<br />
  添加一个柱状图，展示数据集中从首年到末年预期寿命增幅最大的国家。<br />
  添加大洲、国家和年份范围的筛选器。<br />
  附上一段简短的洞察摘要，说明最主要的趋势，以及哪些地区或国家改善最明显。<br />
  展示关键指标的计算方式，以便我核对数字。<br />
  让仪表板美观精致、自适应，在桌面端和移动端都易于阅读。
</AiPrompt>

<div id="verifique-seu-trabalho">
  ## 检查你的成果
</div>

打开 Preview，在分享之前检查一下仪表板。

请确认：

* 国家总数与 CSV 中不重复的国家数量一致。
* 年份区间显示为 1952 至 2007。
* 最新的预期寿命中位数取自数据集中的最后一年。
* 人口总数基于筛选后的国家和年份计算。
* 筛选器能同步更新汇总卡片和图表。
* 气泡图正确使用了人均 GDP、预期寿命、人口和大洲数据。
* 洞察摘要与图表呈现的内容一致。
* 仪表板在手机尺寸的屏幕上显示正常。

如果某个数字与预期不符，可以让 Agent 展示计算过程。

<AiPrompt>
  最新的预期寿命中位数与我预期的不一样。<br />
  请告诉我你是如何从 CSV 中计算出这个数值的。<br />
  请确认你只使用了筛选后数据中最后一年的行。<br />
  如有必要请更新计算方式，并告诉我如何核对结果。
</AiPrompt>

<div id="adicione-filtros-e-exportaes">
  ## 添加筛选与导出
</div>

第一个仪表板跑通后，可以让 Agent 添加一些交互功能，帮助受众深入探索数据。

<AiPrompt>
  为全球进展仪表板添加一个探索面板。<br />
  让我可以按大洲、国家和年份区间筛选。<br />
  添加一个按钮，将筛选后的图表数据导出为 CSV。<br />
  让汇总卡片和洞察摘要与筛选器保持同步。
</AiPrompt>

仪表板还支持 PDF 导出、图表 CSV 导出、刷新、自动刷新、浅色/深色模式以及分析摘要。概念概览请参阅[数据可视化](/zh/pt/features/artifact-types/data-apps)。

<div id="use-dados-conectados-quando-necessrio">
  ## 需要时使用已连接的数据
</div>

学习或做原型时，用公开的 CSV 就够了。如果仪表板需要保持数据最新，请改用已连接的数据源。

你可以将仪表板连接到：

* Replit 应用数据库。
* 数据仓库连接器，如 BigQuery、Databricks 或 Snowflake。
* 分析工具，如 Segment、Amplitude 或 Hex。
* 外部 API。

对于数据仓库中的数据，可以让 Agent 说明它使用了哪些字段和查询。

<AiPrompt>
  使用我们的数据仓库连接器创建一个增长仪表板。<br />
  确定所需的客户、产品使用、计费和留存字段。<br />
  构建图表，展示活跃客户数随时间的变化、按细分市场划分的账户增长，以及按套餐划分的扩展收入。<br />
  说明你使用的字段和计算方式，以便我核对该仪表板。
</AiPrompt>

有关配置细节和可用性，请参阅[数据连接器](/zh/pt/connectors/warehouses/overview)。

<div id="compartilhe-o-dashboard">
  ## 分享仪表板
</div>

确认数据可靠后，即可分享仪表板。

如果仪表板使用了客户或业务的私密数据，请在大范围分享前添加访问控制。如果是公开数据或示例数据，可以直接发布并分享 URL。

可以这样请审阅者提供反馈：

> 请查看全球进展仪表板，告诉我你会优先突出哪个地区或国家的情况，以及原因。

<div id="voc-terminou-quando">
  ## 完成标准
</div>

* 仪表板能加载公开的 CSV 文件。
* 汇总卡片和图表能回答进展方面的问题。
* 你已手动核实至少一项关键指标。
* 筛选器能正确更新仪表板。
* 洞察摘要与数据一致。
* 你已明确仪表板应保持公开、要求登录，还是连接正式数据。

<div id="precisa-de-mais-ajuda">
  ## 需要更多帮助？
</div>

* **数字与预期不符：** 让 Agent 展示所用的查询、公式或数据转换过程。
* **CSV 无法访问：** 检查 URL、网络访问权限以及 CSV 的表头。
* **筛选器不更新图表：** 让 Agent 把筛选器同时连接到汇总卡片和图表数据。
* **仪表板运行缓慢：** 让 Agent 汇总数据、添加筛选器，或减少启动时加载的行数。
* **仪表板使用了私密数据：** 在大范围共享前先加上登录功能。
