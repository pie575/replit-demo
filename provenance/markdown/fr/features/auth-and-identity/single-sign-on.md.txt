# Ajouter le SSO à votre application (Clerk)

> Permettez aux utilisateurs de votre application de se connecter avec le fournisseur d'identité de leur entreprise, comme Okta ou Microsoft Entra ID, via le tableau de bord Clerk, ainsi que l'authentification multifacteur et les contrôles de session.

<Note>
  Vous cherchez à exiger le SSO pour votre **organisation Replit** (connexion à replit.com) ? Cela se configure séparément — consultez [Authentification unique (SAML SSO)](/fr/teams/identity-and-access-management/saml). Cette page couvre l'ajout du SSO au flux de connexion d'**une application que vous créez** sur Replit.
</Note>

Permettez aux utilisateurs de se connecter à votre application avec l'identité de leur entreprise, via un fournisseur d'identité tel qu'Okta ou Microsoft Entra ID. Si votre application utilise [Clerk Auth](/fr/features/auth-and-identity/clerk-auth), vous configurez le SSO et d'autres fonctionnalités d'authentification avancées via le tableau de bord Clerk. Demandez à Agent ce dont vous avez besoin, et Agent vous dirige vers le tableau de bord pour terminer la configuration.

Le tableau de bord Clerk va bien au-delà de l'expérience de connexion par défaut. Toute configuration que vous effectuez dans Clerk s'applique automatiquement à l'authentification de votre application Replit.

## Ce que vous pouvez configurer

* **Connexions SSO d'entreprise** : configurez l'authentification unique avec Okta ou Microsoft Entra ID, via OIDC ou SAML. Permettez à vos clients de se connecter avec le fournisseur d'identité de leur entreprise. Le SSO sécurise également les outils internes qui traitent des données sensibles, en remplaçant les listes d'autorisation d'e-mails manuelles par le fournisseur d'identité existant de votre entreprise.
* **Authentification multifacteur (MFA)** : ajoutez la MFA au flux de connexion de votre application.
* **Contrôles de session** : ajustez la durée des sessions et la fréquence de vérification.
* **Autres paramètres Clerk** : les configurations Clerk supplémentaires s'appliquent automatiquement à votre application Replit. Ne modifiez pas les clés API ni les paramètres d'environnement — Replit les gère pour vous. Consultez [Environnements de développement et de production](/fr/features/auth-and-identity/clerk-auth#environnements-de-developpement-et-de-production).

## Ouvrir le tableau de bord Clerk

Demandez à Agent la modification d'authentification dont vous avez besoin. Agent configure ce qu'il peut et vous dirige vers le tableau de bord Clerk de votre application pour la configuration nécessitant votre intervention.

<Frame>
  <img src="https://mintcdn.com/replit/WPloUkI4g79N4z7t/images/workspace/auth/build-with-sso-agent-workflow.webp?fit=max&auto=format&n=WPloUkI4g79N4z7t&q=85&s=88a06963c5dda455667bbf86036f5e27" alt="Agent dirige une application propulsée par Clerk pour configurer le SSO d'entreprise dans le tableau de bord Clerk." width="1602" height="1080" data-path="images/workspace/auth/build-with-sso-agent-workflow.webp" />

Vous pouvez également ouvrir le tableau de bord depuis le Workspace :

1. Dans le panneau Outils, sélectionnez **Users & Auth**.
2. Sélectionnez l'onglet **Configure**.
3. Sélectionnez **Advanced**.
4. Sous **Clerk dashboard**, sélectionnez **Open Clerk dashboard**.

  <img src="https://mintcdn.com/replit/cvs5z9OGXBFuFLAf/images/workspace/auth/open-clerk-dashboard-tools-pane.webp?fit=max&auto=format&n=cvs5z9OGXBFuFLAf&q=85&s=d8b04aa2e860a5284475df81622cc369" alt="L'outil Users & Auth avec l'onglet Configure ouvert, montrant la section Advanced et le bouton Open Clerk dashboard." width="2158" height="1372" data-path="images/workspace/auth/open-clerk-dashboard-tools-pane.webp" />

## Configurer une connexion SSO d'entreprise

1. Dans le tableau de bord Clerk, sélectionnez **Configure**.
2. Sous **User & authentication**, sélectionnez **SSO connections**.
3. Sélectionnez **Enterprise**.
4. Sélectionnez **Add connection**.

<Frame>
  <img src="https://mintcdn.com/replit/cvs5z9OGXBFuFLAf/images/workspace/auth/build-with-sso-enterprise-connections.webp?fit=max&auto=format&n=cvs5z9OGXBFuFLAf&q=85&s=00dbad72bda6133493f450eebc305f21" alt="Le tableau de bord Clerk affichant la page des connexions SSO Enterprise et l'action Add connection." width="1826" height="1080" data-path="images/workspace/auth/build-with-sso-enterprise-connections.webp" />
</Frame>

Pour la configuration complète de la connexion, consultez la [documentation Clerk](https://clerk.com/docs).

### Valider la connexion

Une fois la configuration terminée, connectez-vous avec un compte de test de votre fournisseur d'identité. Assurez-vous que le compte peut accéder aux parties attendues de votre application.

Si la connexion échoue, demandez de l'aide à Agent. Incluez le fournisseur d'identité, le protocole et le message d'erreur dans votre demande.

<Note>
  Cette page couvre le SSO d'entreprise pour le flux de connexion propre à votre application. Pour la connexion sociale avec Google, GitHub, Apple ou X — appelée **SSO providers** dans le Workspace — consultez [Fournisseurs de connexion](/fr/features/auth-and-identity/sign-in-providers). Cette page ne couvre pas la migration de Replit Auth ni la connexion SAML pour les comptes Replit.
</Note>

## Tarification et disponibilité

L'accès au tableau de bord Clerk est disponible avec le plan [Replit Pro](/fr/billing/plans/replit-pro). Les plans Enterprise arrivent bientôt.

<Info>
  Les connexions SSO d'entreprise sont gratuites jusqu'au 1er octobre 2026. Après cette date, la tarification du SSO correspond à celle de Clerk et est répercutée sur votre facture Replit.
</Info>
