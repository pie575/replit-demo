      <Accordion title="Où puis-je obtenir de l'aide pour le code ?">
        Le meilleur moyen d&#39;obtenir de l&#39;aide pour le code est d&#39;utiliser [Replit AI](/fr/pt/build/welcome). Dans l&#39;Éditeur de projets, ouvrez un nouvel onglet et recherchez **AI**. Replit AI peut vous aider à configurer de nouveaux projets, répondre à vos questions sur le code et vous aider à réfléchir. Pour obtenir une aide supplémentaire, consultez également notre [Hub de la communauté](https://replit.com/community), qui propose d&#39;autres ressources.
      </Accordion>

      <Accordion title="J'ai des difficultés à utiliser Replit. Comment puis-je obtenir de l'aide ?">
        Connectez-vous à Replit et utilisez le **?** dans le coin supérieur droit de la page pour obtenir de l&#39;aide. Pour plus d&#39;informations, consultez la [politique d&#39;assistance](/fr/pt/legal-and-security-info/support-policy).
      </Accordion>

      <Accordion title="Où puis-je obtenir de l'aide concernant la facturation ?">
        Avant de contacter l&#39;équipe d&#39;assistance, vérifiez si vous pouvez trouver une solution dans **Configurações** ci-dessous. Si ce n&#39;est pas le cas, connectez-vous et utilisez le **?** dans le coin supérieur droit de la page pour obtenir de l&#39;aide.
      </Accordion>

      <Accordion title="Je ne parviens pas à accéder à mon compte Replit — que dois-je faire ?">
        Envoyez un e-mail à `support@replit.com` en indiquant le nom d&#39;utilisateur de votre compte et votre identifiant de connexion.
      </Accordion>

      <Accordion title="Quand recevrai-je une réponse de Replit ?">
        L&#39;assistance Replit est généralement disponible du lundi au vendredi, de 9 h à 20 h, heure normale de l&#39;Est (UTC-5).
      </Accordion>

      <Accordion title="Comment restaurer mes dossiers dans mon App Replit ?">
        Dans le coin supérieur droit de votre App Replit, accédez à l&#39;icône de votre profil, sélectionnez **CLUI**, puis saisissez *restore* dans le champ de recherche qui s&#39;affiche. Dans les résultats de recherche, vous trouverez l&#39;option **restore-folder**, qui permet de restaurer un dossier spécifique depuis la corbeille.

        > Remarque : les Apps Replit supprimées sont définitivement effacées et irrécupérables **30 jours** après leur date de suppression.
      </Accordion>

      <Accordion title="Comment restaurer une App Replit supprimée ?">
        Dans le coin supérieur droit de votre App Replit, accédez à l&#39;icône de votre profil, sélectionnez **CLUI**, puis saisissez *restore* dans le champ de recherche qui s&#39;affiche. Dans les résultats de recherche, vous trouverez l&#39;option **restore-repl**, qui permet de restaurer une App Replit spécifique depuis la corbeille.

        > Remarque : les Apps Replit supprimées sont définitivement effacées et irrécupérables **30 jours** après leur date de suppression.
      </Accordion>

      <Accordion title="Pourquoi mon App Replit ne parvient-elle pas à se charger ?">
        Si votre App Replit ne parvient pas à se charger, essayez ces étapes de débogage :

        1. Testez votre [connexion Internet](https://www.speedtest.net/).
        2. Essayez un autre navigateur.
        3. Vérifiez que JavaScript est activé dans votre navigateur.
        4. Utilisez la commande `kill 1` dans le Shell pour arrêter et redémarrer la machine virtuelle Linux qui exécute votre App Replit.

        Si aucune des étapes ci-dessus ne résout le problème, consultez le [statut du service](https://status.replit.com) de Replit. Si le statut indique **All systems are go!** et que vous rencontrez toujours des problèmes pour charger votre App Replit, contactez l&#39;[assistance Replit](https://replit.com/support).
      </Accordion>

      <Accordion title="Comment puis-je téléverser un fichier volumineux vers mon App Replit ?">
        Si le fichier est trop volumineux pour un téléversement standard via l&#39;interface graphique, vous pouvez utiliser `scp` (Secure Copy) pour transférer des fichiers en toute sécurité entre des systèmes locaux et distants via [SSH](/fr/pt/features/workspace-tools/ssh). Pour copier des fichiers de votre machine locale vers la machine distante, utilisez cette syntaxe : `scp filename username@ip_address:/home/username`

        Vous pouvez également copier des répertoires entiers à l&#39;aide de scp.
      </Accordion>

      <Accordion title="Comment vérifier mon solde de crédits d'utilisation ?">
        Vous pouvez consulter votre solde actuel à l&#39;adresse [https://replit.com/~/cli/account/usage-credits-balance](https://replit.com/~/cli/account/usage-credits-balance).
      </Accordion>

      <Accordion title="J’ai des problèmes de connexion ; que dois-je faire ?">
        1. Assurez-vous d’utiliser la bonne adresse e-mail et le bon mot de passe.
        2. Pour réinitialiser votre mot de passe, accédez à la [page de mot de passe oublié](https://replit.com/forgot). Vérifiez votre dossier de spam pour trouver l’e-mail de réinitialisation envoyé par `notifications@replit.com`.
        3. Essayez de vous connecter depuis un autre navigateur.

        Si aucune de ces étapes ne résout le problème, veuillez [contacter l’assistance](https://replit.com/support).
      </Accordion>

      <Accordion title="Comment modifier mon e-mail si je me suis inscrit avec Google/GitHub/Facebook/Apple ?">
        Un mot de passe est requis pour modifier l’adresse e-mail de votre compte. Si vous vous êtes inscrit via un fournisseur d’authentification tiers, tel que Google ou GitHub, vous devez d’abord créer un mot de passe.

        Pour créer un mot de passe :

        1. Ouvrez la barre latérale et déconnectez-vous.
        2. Retournez à la page de connexion, sélectionnez [mot de passe oublié](https://replit.com/forgot) et saisissez votre adresse e-mail.
        3. Vous recevrez un e-mail contenant un lien pour créer un nouveau mot de passe. Si vous ne le trouvez pas, vérifiez votre dossier de spam et attendez jusqu’à trente minutes.
        4. Une fois connecté, ouvrez les [paramètres](https://replit.com/settings) pour modifier votre adresse e-mail.
      </Accordion>

      <Accordion title="Comment modifier mon nom d’utilisateur ?">
        Les utilisateurs de Replit ne peuvent modifier leur nom d’utilisateur qu’**une seule fois**. Accédez au [CLUI](https://replit.com/~/cli/account/change-username?run=1) et sélectionnez **change-username**. Si cette option n’est pas disponible, vous avez déjà modifié votre nom d’utilisateur.
      </Accordion>

      <Accordion title="Qu’est-ce que le mode Explorer et comment l’activer ?">
        Les Explorers sont des utilisateurs de Replit qui ont choisi de découvrir et de tester de nouvelles fonctionnalités encore en développement. Pour activer le mode Explorer, ouvrez les [paramètres](https://replit.com/settings) et activez l’interrupteur Explorer (par exemple, dans **compte** ou **utilisateur**).
      </Accordion>
