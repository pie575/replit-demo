  ### Rétention de l&#39;historique de Neon DB
</div>

  ### Fonctionnalités améliorées de contexte des liens

<div id="melhorias-de-desempenho-no-web-view">
  ### Améliorations des performances du Web View
</div>

Profitez d&#39;une navigation en iframe plus fluide et d&#39;une meilleure compatibilité avec les sites sécurisés dans le Web View. Le système de proxy a été amélioré afin de gérer les en-têtes de sécurité de manière plus intelligente, ce qui élimine les blocages de navigation frustrants que vous avez pu rencontrer jusqu&#39;ici.
