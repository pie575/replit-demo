export const YouTubeEmbed = ({videoId, title = "Vidéo YouTube", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

<div id="agent-ui">
  ### Interface d&#39;appel d&#39;outils repensée dans le chat Agent
</div>

Le chat Agent bénéficie désormais d&#39;une interface d&#39;appel d&#39;outils plus épurée et plus concise. Les appels d&#39;outils sont condensés en lignes groupées avec des icônes empilées, ce qui permet de voir en un coup d&#39;œil ce qui se passe. Les modifications et créations de fichiers renvoient directement au panneau de diff, pour une révision facilitée. Cette conception simplifiée vous aide à suivre l&#39;exécution d&#39;Agent plus clairement et avec moins de bruit.

<div id="nodejs">
  ### Correctif de sécurité Node.js
</div>

Une vulnérabilité de sécurité critique a été signalée cette semaine dans Node.js. Tous les environnements de développement Agent ainsi que les applications Node.js hébergées sur Replit ont été mis à jour vers une version sécurisée. Republiez votre application pour qu&#39;elle bénéficie elle aussi de cette version sécurisée.
