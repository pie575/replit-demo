<div id="agent-suggests-connectors-when-several-fit">
  ### Agent предлагает подходящие connectors
</div>

Когда вы просите Agent подключить сервис и подходят несколько provider’ов, Agent теперь показывает короткий список, чтобы вы могли выбрать нужный. Раньше Agent сначала приходилось задавать дополнительный вопрос. Выберите provider, войдите в него один раз — и Agent продолжит работу.

<div id="workspace">
  ## Workspace
</div>

<div id="meet-the-new-tools-pane">
  ### Знакомьтесь с новой панелью Tools
</div>

Теперь всё, что может использовать ваше приложение, собрано в одном месте Workspace. Новая закреплённая панель Tools объединяет Database, Auth, Domains, Secrets и другие инструменты. Благодаря этому весь набор инструментов легко найти с первого взгляда. Сами инструменты не изменились — просто теперь у них есть более понятное место.

</Frame>

<div id="a-faster-task-sidebar">
  ### Ускоренная боковая панель задач
</div>

Боковая панель задач стала компактнее и удобнее для просмотра. У каждой задачи теперь есть всплывающая карточка с быстрыми действиями и подробностями, доступ к Task Board стал понятнее, а задачи не смещаются при разворачивании или сворачивании боковой панели.

</Frame>
