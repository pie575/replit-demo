⏰ *Ориентировочное время: 10 минут*

Иногда дизайн, от которого вы хотите оттолкнуться, уже есть в интернете: это может быть ваш текущий сайт или страница, внешний вид которой хочется повторить. Import from URL воссоздаёт веб-сайт в виде frame, который можно изучить, доработать и превратить в интерактивный App.

В качестве примера вы будете использовать [creative-studio-landing.replit.app](https://creative-studio-landing.replit.app) — landing page, созданную Replit для творческой студии.

<div id="antes-de-comear">
  ## Прежде чем начать
</div>

Вам понадобится:

* [Учётная запись Replit](https://replit.com).
* URL-адрес публичного веб-сайта или пример, приведённый выше.

<div id="importe-o-website">
  ## Импортируйте веб-сайт
</div>

<Steps>
  <Step title="Скопируйте URL сайта">
    Используйте свой сайт или скопируйте пример: `https://creative-studio-landing.replit.app`.

    <Frame caption="Сайт из примера: Kosmo Studio, landing page креативной студии.">
      <img src="/assets/mirror/url-example-site-e0ad60629981.webp" alt="Landing page Kosmo Studio с заголовком We craft bold ideas and visuals that truly work над веером арт-карточек" width="3440" height="2160" data-path="images/design/import-from-url/url-example-site.webp" />
    </Frame>
  </Step>

  <Step title="Откройте Replit Design">
    Перейдите на [replit.com/design](https://replit.com/design) и выберите **Import URL** под полем prompt. Agent воссоздаст внешний вид и стиль сайта как отправную точку.

    <Frame caption="Import URL на главной странице Replit Design: вставьте ссылку на любой веб-сайт.">
      <img src="/assets/mirror/design-import-url-07a8ac52e188.webp" alt="Главная страница Replit Design с выбранной опцией Import URL и подсказкой Paste a link to any website and Agent will recreate its look and feel as a starting point" width="2293" height="1322" data-path="images/design/import-from-url/design-import-url.webp" />
    </Frame>
  </Step>

  <Step title="Вставьте URL и начните сборку">
    При выборе **Import URL** поле prompt заполняется автоматически: *«Recreate the look and feel of this website:»*. Вставьте после него свой URL и выберите **Start**.

    <Frame caption="Предзаполненный prompt для воссоздания с URL из примера, готовый к запуску.">
      <img src="/assets/mirror/design-url-prompt-b6196aac1b17.webp" alt="Поле prompt в Replit Design с текстом Recreate the look and feel of this website и URL из примера, рядом кнопка Start" width="2293" height="1322" data-path="images/design/import-from-url/design-url-prompt.webp" />
    </Frame>
  </Step>
</Steps>

Agent воссоздаёт сайт в виде frame дизайна в вашем проекте.

<Frame caption="Воссозданная landing page Kosmo Studio в виде frame дизайна в Replit Design.">
  <img src="/assets/mirror/url-import-result-7a4114a468f3.webp" alt="Воссозданная landing page Kosmo Studio в виде frame дизайна в Replit Design, выполнение отмечено как завершённое на панели Chat" width="1600" height="1004" data-path="images/design/import-from-url/url-import-result.webp" />
</Frame>

<div id="deixe-do-seu-jeito">
  ## Сделайте его своим
</div>

Выберите импортированный frame и начните его переделывать:

* **Воспользуйтесь [предложением](/ru/pt/design/explore-suggestions)**: вместе с импортом вы получаете предложенные следующие шаги — например, тёмный редакционный вариант, мобильный вьюпорт или страницу контактов. Каждый из них создаётся как новый frame, поэтому оригинал сохраняется для сравнения.
* **[Обсудите его в чате](/ru/pt/design/chat-about-your-design)**: используйте поле под frame и объясните своими словами: *«замени фотографии в портфолио»*, *«сделай типографику в hero-блоке более жирной»*.

<Frame caption="Выбранный импортированный frame с предложенными следующими шагами: тёмный редакционный вариант, мобильный вьюпорт и страница контактов.">
  <img src="/assets/mirror/url-make-it-yours-936e5995839a.webp" alt="Воссозданный frame Creative Studio, выбранный в Replit Design, рядом с панелью предложенных следующих шагов, где предлагаются тёмный редакционный вариант, мобильный вьюпорт, страница контактов и другие подходы" width="1600" height="1004" data-path="images/design/import-from-url/url-make-it-yours.webp" />
