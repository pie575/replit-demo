Les modes Agent vous permettent d&#39;ajuster l&#39;équilibre entre coût et performance lorsque vous utilisez Agent. Utilisez le menu déroulant des paramètres d&#39;Agent pour choisir entre **Free Mode**, **Power Mode** et **Max Mode**. Free Mode utilise toujours Auto. Les builders des plans Core et Pro peuvent utiliser le [Model selector](/fr/ko/features/agent/model-selector) en Power Mode ou en Max Mode. Les modes et paramètres affichés varient selon le plan et l&#39;espace de travail que vous utilisez.

<Note>
  Economy Mode n&#39;est plus disponible. Power Mode le remplace au même tarif.
</Note>

<Tip>
  **Raccourci clavier :** appuyez sur **⌘+Maj+I** (Ctrl+Maj+I sous Windows) pour passer d&#39;un mode Agent à l&#39;autre sans quitter le champ de saisie du chat.
</Tip>

<div id="free-mode">
  ## Free Mode
</div>

**Idéal pour démarrer.** Free Mode vous aide à explorer vos idées, à comprendre le fonctionnement de Replit et à lancer vos projets.

**À noter :** Free Mode utilise toujours Auto, le routage intelligent des modèles de Replit. Pour choisir un modèle manuellement, utilisez Power Mode ou Max Mode.

<Note>
  Les plans Core et Pro incluent un quota Free Mode qui se renouvelle toutes les 5 heures. Une fois ce quota épuisé, Replit vous indique quand il sera renouvelé.
</Note>

Les Routines ne s&#39;exécutent pas en Free Mode. Elles s&#39;exécutent en Power Mode ou Max Mode et nécessitent un budget par exécution. Pour en savoir plus, consultez [Routines](/fr/ko/chat/routines).

<div id="power-mode">
  ## Power Mode
</div>

**Optimisé pour les coûts.** Power Mode consomme moins de crédits par tâche : c&#39;est le choix par défaut idéal lorsque vous voulez de bons résultats sans payer pour le modèle le plus performant.

**Quand l&#39;utiliser :** builds quotidiens, apprentissage et travaux à moindre coût sur l&#39;ensemble de vos projets existants.

<div id="max-mode">
  ## Max Mode
</div>

**Optimisé pour la performance.** Max Mode fait appel à des modèles plus puissants pour les tâches complexes, les bases de code volumineuses et les problèmes les plus difficiles.

**Quand l&#39;utiliser :** pour des projets de niveau production, des fonctionnalités complexes ou lorsque vous attendez les meilleurs résultats possibles d&#39;Agent.

<div id="section">
  ## Quel mode utiliser ?
</div>

Utilisez ce tableau comme guide :

| Objectif                                                                        | Mode recommandé                                                                |
| ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| Explorer des idées, apprendre le fonctionnement de Replit et démarrer un projet | Free Mode                                                                      |
| Maximiser le nombre de prompts par crédit                                       | Power Mode                                                                     |
| Équilibrer coût et qualité sur la plupart des projets                           | Power Mode                                                                     |
| Sélectionner un modèle manuellement                                             | Power Mode ou Max Mode                                                         |
| Obtenir les meilleurs résultats sur des tâches complexes, de niveau production  | Max Mode                                                                       |
| Obtenir les meilleurs résultats sur les tâches les plus complexes               | Max Mode avec un [Effort](/fr/ko/features/agent/model-selector#effort) plus élevé |

Sélectionnez le mode à l&#39;aide du menu déroulant des paramètres de l&#39;Agent, dans la zone de saisie du chat. Les builders des plans Core et Pro peuvent définir le [modèle principal et l&#39;Effort](/fr/ko/features/agent/model-selector) en Power Mode ou en Max Mode. Aucun mode n&#39;est optimal en toutes circonstances : choisissez celui qui convient à la tâche du moment.

<div id="section-2">
  ## Paramètres dans les projets partagés
</div>

Les paramètres d&#39;Agent sont liés à votre compte, et non au projet. Lorsque vous invitez des coéquipiers dans un projet, chacun conserve ses propres choix pour les éléments suivants :

* Le mode (Free Mode, Power Mode ou Max Mode)
* [Le modèle principal et l&#39;Effort](/fr/ko/features/agent/model-selector), lorsqu&#39;ils sont disponibles
* [Le mode Plan](/fr/ko/features/agent/plan-mode)
* La fusion automatique des tâches en arrière-plan
* L&#39;approbation automatique des plans

Si un coéquipier passe en Max Mode pour sa prochaine tâche, vos paramètres ne basculent pas pour autant en Max Mode. Le mode et les paramètres affichés dans le menu déroulant des paramètres d&#39;Agent sont ceux qu&#39;Agent applique à votre prochain message, quel que soit le nombre de collaborateurs présents sur le projet.

<div id="free-mode-2">
  ## Vérifier votre quota Free Mode
</div>

Ouvrez **Settings** → **Usage** pour consulter le quota Free Mode restant et sa date de renouvellement. Pour des conseils pratiques permettant d&#39;en tirer le meilleur parti, consultez [Tirer le meilleur parti du Free Mode](/fr/ko/chat/free-mode).
