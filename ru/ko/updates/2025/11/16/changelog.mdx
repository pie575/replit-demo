<div id="azure-marketplace">
  ### Интеграция с Azure Marketplace
</div>

Replit теперь доступен в Azure Marketplace! У многих организаций уже есть выделенный бюджет на Azure, и благодаря этой интеграции его можно напрямую направить на подписку и использование Replit.

Вслед за сентябрьской интеграцией с GCP Marketplace это нововведение позволяет Enterprise-командам ещё проще внедрять Replit, используя существующие процессы закупок в облаке и уже выделенные бюджеты.

[Открыть в Azure Marketplace](https://marketplace.microsoft.com/en-us/product/saas/replit.replit?tab=Overview)

<div id="gitlab-bitbucket">
  ### Поддержка GitLab и Bitbucket
</div>

Теперь Replit поддерживает репозитории GitLab и Bitbucket в дополнение к GitHub — у вас больше свободы в выборе места хранения кода. Проекты из GitLab и Bitbucket можно импортировать напрямую в Replit, а расширенные возможности git доступны на всех поддерживаемых платформах.

Расширенная интеграция с git включает:

* **Поддержка нескольких платформ**: импорт репозиториев из GitHub, GitLab и Bitbucket и работа с ними
* **Улучшенные операции git**: более быстрые и надёжные команды git во всём workspace
* **Удобное управление репозиториями**: упрощённые сценарии клонирования, отправки и получения изменений у всех поддерживаемых провайдеров git

Подробнее об [импорте проектов](/ru/references/workspace/import) и [работе с git в Replit](/ru/references/version-control/git-interface).
