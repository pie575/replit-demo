<div id="security-agent-reviews-your-whole-codebase">
  ### Security Agent проверяет всю вашу кодовую базу
</div>

**Security Agent** — новый ИИ-инструмент для проверки безопасности, который анализирует не только зависимости, но и весь проект. Он строит модель угроз, отслеживает маршруты и потоки данных, выполняет статический анализ с помощью Semgrep и HoundDog.ai, а также использует LLM, чтобы определить, какие выявленные проблемы действительно могут быть использованы в контексте вашего приложения. По завершении проверки Security Agent преобразует подтверждённые проблемы в параллельные задачи, которые Replit Agent может исправить за один раз.

Security Agent доступен всем платным пользователям. Откройте панель **Security** в проекте и выберите **Run Scan with Agent**, чтобы попробовать его.

Подробнее о [Security Agent](/ru/core-concepts/security/project-security-center#agent-security-scans).

<div id="cve-auto-protect-patches-critical-vulnerabilities-automatically">
  ### CVE Auto-Protect автоматически устраняет критические уязвимости
</div>

Когда становится известно о новой критической CVE для пакета, от которого зависит ваше приложение, **CVE Auto-Protect** выявляет её во всех ваших проектах, поручает Agent подготовить исправление в фоновой задаче, запускает тесты, чтобы убедиться, что ничего не сломалось, и отправляет вам уведомление со ссылкой для проверки. Вы сохраняете контроль: ничего не будет опубликовано, пока вы не одобрите исправление.

Благодаря этому исправления для ваших приложений могут быть готовы уже через несколько минут после публикации сведений об уязвимости — вам не придётся ждать, пока вы сами её заметите.

Подробнее о [CVE Auto-Protect](/ru/core-concepts/security/project-security-center#auto-protect).

<div id="preview-on-an-ios-simulator-or-android-emulator">
  ### Предпросмотр в симуляторе iOS или эмуляторе Android
</div>

<Frame>
  <video autoPlay muted loop playsInline src="/assets/mirror/ios-emulator-9013ff1b602f.mp4" />
</Frame>

Если ваш проект включает мобильное приложение, панель предпросмотра теперь позволяет транслировать настоящий **симулятор iOS** или **эмулятор Android** прямо в Workspace. Не нужны ни Xcode, ни Android Studio, ни физическое устройство. Создайте мобильное приложение с Agent, выберите устройство в раскрывающемся списке панели предпросмотра и пользуйтесь им так, будто держите телефон в руках. Изменения, которые вносит Agent, мгновенно отображаются в симуляторе.

Функция доступна платным пользователям тарифов Core, Pro и Enterprise в Chrome, Safari и браузерах на базе Chromium. Firefox не поддерживает мобильные симуляторы.

Подробнее о [предпросмотре в симуляторе или эмуляторе](/ru/features/artifact-types/building-mobile-apps#preview-on-a-simulator-or-emulator).

<div id="add-a-mobile-app-to-older-projects">
  ### Добавление мобильного приложения в старые проекты
</div>

<Frame>
  <img src="/assets/mirror/multi-artifact-update-approval-f6fa8b70a100.png" alt="Панель чата с Agent с карточкой подтверждения «Обновить проект для создания мобильного приложения», предложением 5 $ в кредит и кнопками «Не сейчас» / «Обновить проект»." width="991" height="589" data-path="images/replitai/multi-artifact-update-approval.png" />
</Frame>

Теперь проекты, созданные до запуска Agent 4, можно обновить для поддержки нескольких артефактов. Это значит, что в проект, который раньше поддерживал только один артефакт, можно добавить мобильное приложение, презентацию для питча или другой артефакт. При реорганизации проекта Agent сохраняет ваш URL, данные, Secrets и deployment. За первые 48 часов после широкого запуска было перенесено более 200 проектов.

Подробнее об [обновлении старых проектов для поддержки нескольких артефактов](/ru/features/projects-and-artifacts/updating-projects-for-multiple-artifacts).

<div id="plaid-connector-is-live">
  ### Коннектор Plaid уже доступен
</div>

Теперь вы можете подключаться к более чем 12 000 финансовых учреждений с помощью коннектора **Plaid**. Администраторы команд настраивают учетные данные один раз в разделе **интеграции**, а пользователи вашего приложения аутентифицируют свои банковские счета через Plaid Link. Токены доступа привязаны к конкретным пользователям, поэтому данные остаются конфиденциальными.

Создайте персонального финансового помощника, работающего с реальными данными о транзакциях, трекер портфеля в реальном времени, подключенный к вашему брокерскому счету, и многое другое. Ознакомьтесь со [страницей партнёрства Replit x Plaid](https://replit.com/partners/plaid), где представлены демонстрации и инструкции по настройке.

Подробнее об [управлении коннекторами](/ru/replitai/managing-connectors).
