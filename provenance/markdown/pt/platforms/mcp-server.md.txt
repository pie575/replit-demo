# Servidor MCP do Replit

> Conecte um cliente MCP ao Replit para criar, encontrar, inspecionar, atualizar e publicar Replit Apps.

O Replit MCP usa o [Model Context Protocol](https://modelcontextprotocol.io/) para permitir que você crie, encontre, inspecione, atualize e publique projetos do Replit a partir das ferramentas de IA que você já usa.

Esta página é a referência para clientes MCP diretos e suas ferramentas.

## Conectar um cliente MCP diretamente

Use a conexão direta quando seu cliente MCP não tiver uma integração nativa com o Replit.

| Propriedade      | Valor                                        |
| ---------------- | -------------------------------------------- |
| **URL**          | `https://replit-mcp.com/server/mcp`          |
| **Transporte**   | HTTP com Streaming                           |
| **Autenticação** | OAuth usando descoberta de recurso protegido |

Adicione a URL do servidor a um cliente MCP que ofereça suporte a HTTP com Streaming e autorização OAuth. O cliente lê os metadados de recurso protegido do Replit. Em seguida, ele solicita que você faça login no Replit.

Não crie um servidor OAuth personalizado. O Servidor MCP do Replit fornece os metadados OAuth de que seu cliente precisa.

Você pode criar apps ou trabalhar com apps que você pode editar, incluindo apps compartilhados com você.

## Integrações nativas

O Replit também está disponível como uma integração nativa no [ChatGPT](/pt/features/platforms/chatgpt), no [Claude](/pt/features/platforms/claude) e no [Slack](/pt/features/platforms/slack). Use as páginas vinculadas para as etapas de conexão específicas de cada plataforma.

## Ferramentas

| Ferramenta                | Entrada obrigatória           | Entrada opcional                                          | Uso                                                                                                                                                                               |
| ------------------------- | ----------------------------- | --------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `create_app_from_prompt`  | `appDescription`, `app_stack` | `userSpecifiedAppName`, `userQuotes`, `attachmentSummary` | Inicia um novo app. `app_stack` é um dos seguintes: `react_website`, `mobile_app`, `design`, `slides`, `animation`, `data_visualization`, `3d_game`, `document` ou `spreadsheet`. |
| `search_apps`             | Nenhuma                       | `query`, `url`, `updatedAfter`, `updatedBefore`, `limit`  | Encontra apps por palavras-chave no título, URL ou data da última atualização. `limit` vai de 1 a 50.                                                                             |
| `resolve_app_by_name`     | `name`                        | Nenhuma                                                   | Encontra um único app pelo título exato.                                                                                                                                          |
| `list_apps`               | Nenhuma                       | `query`, `limit`                                          | Lista os apps que você pode editar, ordenados por atividade recente. O limite padrão é 25 e o máximo é 50.                                                                        |
| `ask_question`            | `replId`, `question`          | Nenhuma                                                   | Faz uma pergunta ao Agent sobre um app sem alterá-lo.                                                                                                                             |
| `update_app_using_prompt` | `replId`, `changeDescription` | `userQuotes`, `attachmentSummary`                         | Inicia uma atualização do Agent em um app existente.                                                                                                                              |
| `publish_app`             | `replId`                      | Nenhuma                                                   | Publica um app ou republica suas alterações mais recentes.                                                                                                                        |
| `get_publish_status`      | `replId`                      | Nenhuma                                                   | Verifica se um app foi publicado, seu status atual de publicação e sua URL pública.                                                                                               |

## Solução de problemas

| Problema                                                                     | O que fazer                                                                                                                    |
| ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| O Replit solicita que você se autentique                                     | Conclua o fluxo de login OAuth novamente a partir do seu cliente MCP.                                                          |
| Um app não é encontrado                                                      | Verifique se você pode editar o app. Depois, pesquise pela URL ou use `list_apps` para escolher entre os apps correspondentes. |
| Uma solicitação de criação, atualização ou publicação ainda está em execução | Espere antes de tentar novamente. Para publicação, use `get_publish_status` para verificar o resultado atual.                  |
