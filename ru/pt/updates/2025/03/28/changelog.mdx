<div id="atualizao-do-limite-de-fatura">
  ### Обновление порога выставления счетов
</div>

Для подписок Core и Pro порог выставления счетов увеличен. Благодаря этому счета выставляются реже, а перебои в обслуживании, связанные с оплатой, возникают реже — работа становится комфортнее для разработчиков. Реализация включает комплексные меры по оценке рисков и мониторингу. Подробности о новом пороге см. в разделе [Пороги выставления счетов](/ru/pt/category/billing#invoice-thresholds).
