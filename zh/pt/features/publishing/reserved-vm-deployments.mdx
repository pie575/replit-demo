---
title: "使用 Reserved VM 发布"
description: "了解如何使用 Reserved VM Deployments 将你的应用发布到始终在线的云服务器上。"
---

Reserved VM deployment 运行在一台虚拟机 (VM) 上，为你的应用提供专用的计算资源。这类 deployment 的成本和性能可预测，且运行不中断。

它非常适合以下场景：

* 内存占用较高的后台任务
* 需要保持连接的聊天机器人
* 始终在线的 API 服务器

<div id="recursos">
  ## 功能
</div>

Reserved VM Deployments 包含以下功能：

* **专用资源**：借助预留的计算资源，获得稳定一致的应用性能。
* **自定义域名**：配置自定义域名，或使用 `<应用名称>.replit.app` URL 访问应用。
* **计算资源选项**：选择满足应用性能需求的虚拟机方案。
* **可配置的端口映射**：指定应用向互联网开放的端口。
* **监控**：查看日志并监控已发布应用的状态。

<div id="uso">
  ## 使用方式
</div>

你可以在 Project Editor 的 Publishing 工具中使用 Reserved VM Deployments。

<Accordion title="如何访问 Reserved VM Deployments">
  在左侧的 **Tool dock** 中：

  1. 选择 <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="所有工具图标" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**，查看 Project Editor 的工具列表。
  2. 选择 <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Publishing 图标" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publishing**。
  3. 选择 **Reserved VM** 选项，然后选择 **Set up your published app**。

  在**搜索栏**中：

  1. 选择顶部的 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 放大镜图标，打开搜索工具
  2. 输入“Publishing”以查找该工具，并在结果中选择它。
  3. 选择 **Reserved VM** 选项，然后选择 **Set up your published app**。
</Accordion>

<div id="configurao-da-mquina">
  ### 机器配置
</div>

为托管 deployment 的机器选择 CPU 和内存配置。所选机器规格旁会显示该选项的费用。

<div id="domnio-principal">
  ### 主域名
</div>

指定已发布应用主机名中的子域名部分。发布后，你可以通过 `https://<subdomain>.replit.app` 访问已发布的应用。

要了解如何使用自定义域名，请参阅[自定义域名](/zh/features/publishing/custom-domains)。

<div id="deployment-privado">
  ### 私有 deployment
</div>

<Info>
  私有发布应用功能适用于 Pro 和 Enterprise 方案。
</Info>

私有发布的应用只允许你的 workspace 成员，或你邀请的特定用户和群组访问。
发布时，你可以选择 **Public**、**Password protected**、**Workspace only** 或 **Invite only** 访问方式。

如需了解如何设置私有 deployment，请参阅[应用访问权限](/zh/features/publishing/private-deployments/)。

<div id="build-command">
  ### Build command
</div>

在 **Build command** 字段中输入用于编译或配置应用的 Shell 命令，该命令会在 Run command 之前执行。
例如，若要使用 Vite 针对生产环境优化 JavaScript 应用，可以添加 `vite build` 命令。

<div id="run-command">
  ### Run command
</div>

在 **Run command** 字段中输入用于启动任务的 Shell 命令。该命令应与你在工作流中使用的命令类似。例如，要启动名为“myApp”的 Flask 应用，可以添加命令 `flask --app myApp run`。

<div id="secrets-do-app-publicado">
  ### 已发布应用的 Secrets
</div>

选择 **Add published app secret**，添加应用安全运行所需的环境变量或 secrets。

如果你的 Replit App 中已有环境变量或 secrets，Publishing 工具会自动将它们添加到列表中。

<div id="opes-de-tipo-de-app">
  ### 应用类型选项
</div>

请从以下选项中选择一项：

* **Web server**：如果你要发布 Web 应用，或用户可通过互联网访问的应用，请选择此项。
* **Background worker**：如果你的应用不监听端口，也不启动服务器，请选择此项。

选择 **Web Server** 后，你可以按以下步骤自定义要对外开放的端口：

1. 展开 **Port configuration** 部分。
2. 选择 **Networking pane to configure**，打开 **Networking** 标签页，在其中管理端口映射。

有关端口配置的更多信息，请参阅 [Ports](/zh/pt/features/project-setup/ports/)。
