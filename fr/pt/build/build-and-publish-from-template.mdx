⏰ *Durée estimée : 10 minutes*

À la fin de ce guide, vous aurez une petite application publiée à une URL que vous pourrez partager.

<Frame>
  <img src="/assets/mirror/07-published-site-8fe719004e5a.jpg" alt="Le modèle sélectionné transformé en site web et ouvert à son URL Replit publique" width="1274" height="717" data-path="images/first-app-template/07-published-site.jpg" />
</Frame>

Vous partirez d&#39;un modèle soigné, le transformerez en site web fonctionnel, puis le publierez. Les modèles disponibles peuvent changer : choisissez celui qui correspond le mieux à ce que vous souhaitez créer.

<div id="before-you-start">
  ## Avant de commencer
</div>

Vous avez besoin d&#39;un [compte Replit](https://replit.com). La création d&#39;une application à partir d&#39;un frame Design nécessite un forfait Core ou Pro. Consultez [Créer votre design](/fr/design/build-your-design) et [Facturation](/fr/billing/ai-billing) pour en savoir plus sur les forfaits.

L&#39;objectif est de réaliser un cycle complet :

* Choisir un modèle dans [Replit Design](https://replit.com/design),
* Le développer avec [Agent](/fr/features/agent/overview),
* Tester l&#39;application,
* Publier et partager.

Agent est le créateur d&#39;applications par IA de Replit. Vous décrivez ce que vous souhaitez, et Agent vous aide à créer, expliquer et corriger l&#39;application.

<div id="choose-build-and-publish-a-template">
  ## Choisir, créer et publier un modèle
</div>

<Steps>
  <Step title="Parcourir les modèles de design">
    Ouvrez [replit.com/design](https://replit.com/design). Parcourez les modèles mis en avant ou filtrez par **Landing Pages**, **Mobile**, **Prototypes** et d&#39;autres formats.

    <Frame>
      <img src="/assets/mirror/01-design-gallery-5303cf1cf6d2.jpg" alt="La galerie Replit Design avec les modèles mis en avant et les filtres de format" width="1280" height="720" data-path="images/first-app-template/01-design-gallery.jpg" />
    </Frame>
  </Step>

  <Step title="Aperçu et utilisation d’un modèle">
    Sélectionnez un modèle pour l&#39;examiner, puis sélectionnez **Use template**. Replit crée un nouveau project et place le modèle sur le Canvas Design. Si vous êtes plutôt parti de la page de couverture d&#39;un modèle, consultez [Démarrer à partir d&#39;un modèle](/fr/design/start-from-a-template) pour connaître le déroulement du remix.

    <Frame>
      <img src="/assets/mirror/02-template-preview-facda2e40956.jpg" alt="Aperçu d'un modèle Replit Design avec le bouton Use template" width="1280" height="720" data-path="images/first-app-template/02-template-preview.jpg" />
    </Frame>

    Le modèle remixé s&#39;ouvre sur le Canvas Design, au sein de son nouveau project.

    <Frame>
      <img src="/assets/mirror/03-remixed-design-35b051544510.jpg" alt="Le modèle sélectionné remixé sur le Canvas Design dans un nouveau project Replit" width="1280" height="720" data-path="images/first-app-template/03-remixed-design.jpg" />
    </Frame>
  </Step>

  <Step title="Transformez le design en site web">
    Un modèle se présente d&#39;abord comme une maquette de design. Avant de pouvoir le publier, passez en mode **Build** et demandez à Agent de transformer le design sélectionné en site web fonctionnel. Par exemple :

    > Transforme ce modèle sélectionné en site web fonctionnel. Conserve son design visuel et rends sa navigation et ses actions de contact opérationnelles.

    Agent crée un artifact de site web dans le même project, en utilisant le design sélectionné comme source.

    <Note>
      Le bouton **Publish** est également visible dans Design. Si le project ne contient que des maquettes de design, Publishing signale qu&#39;il n&#39;y a encore rien à déployer et vous invite à demander à Agent de créer une app. Dès qu&#39;un artifact de site web existe, vous pouvez publier depuis Design comme depuis Build.
    </Note>

    <Frame>
      <img src="/assets/mirror/04-build-request-d5a5a3428361.jpg" alt="Le workspace Build avec un design de portfolio sélectionné et joint, la demande de build dans le Chat d'Agent, et Publishing expliquant qu'un project contenant uniquement des designs n'a encore rien à déployer" width="1280" height="720" data-path="images/first-app-template/04-build-request.jpg" />
    </Frame>
  </Step>

  <Step title="Vérifiez le bon fonctionnement de l’app dans Preview">
    Lorsque Agent a terminé, ouvrez [Preview](/fr/features/editor/preview) et utilisez l’app comme le ferait un visiteur. Preview vous permet de tester l’app pendant sa création, avant de la publier.

    Vérifiez que vous pouvez :

    * Utiliser la navigation principale.
    * Utiliser les boutons et formulaires du modèle.
    * Voir un état de réussite ou de validation clair après une action.
    * Actualiser la page et réutiliser le site.
    * Redimensionner Preview à une largeur correspondant à celle d’un téléphone.

    Si quelque chose ne fonctionne pas, décrivez le problème à Agent. Vous n’avez pas besoin de diagnostiquer le code vous-même.

    <Frame>
      <img src="/assets/mirror/05-preview-d5702e9d9ac8.jpg" alt="Le site web basé sur le modèle exécuté dans Preview du Project Editor" width="1280" height="720" data-path="images/first-app-template/05-preview.jpg" />
    </Frame>

    <Tip>
      Vous souhaitez explorer des variantes visuelles avant de publier ? Consultez [Explorer les suggestions](/fr/design/explore-suggestions) pour générer différentes apparences côte à côte et appliquer celle qui vous plaît.
    </Tip>
  </Step>

  <Step title="Publier votre application">
    Lorsque le Preview fonctionne correctement, sélectionnez **Publish**. Confirmez le sous-domaine généré, choisissez qui peut accéder à l&#39;app et vérifiez les paramètres de sécurité. Sélectionnez ensuite **Publish** dans la boîte de dialogue.

    La publication crée une version publique de votre app, accessible via une URL que vous pouvez partager.

    <Frame>
      <img src="/assets/mirror/06-publish-dialog-2f79654c6dfb.jpg" alt="La boîte de dialogue Publish avec le sous-domaine généré, les paramètres d'accès et le bouton Publish" width="1280" height="720" data-path="images/first-app-template/06-publish-dialog.jpg" />
    </Frame>
  </Step>

  <Step title="Ouvrez votre app publiée">
    Ouvrez l&#39;URL publique dans un nouvel onglet du navigateur et effectuez les mêmes vérifications. L&#39;app doit fonctionner en dehors du Project Editor avant que vous ne la partagiez.

    Si l&#39;app publiée ne se comporte pas comme dans la Preview, consultez les journaux de publication ainsi que les éventuels paramètres de production requis par l&#39;app. Pour les problèmes de publication courants, consultez [Résoudre les problèmes de publication](/fr/build/troubleshooting).

    <Frame>
      <img src="/assets/mirror/07-published-site-8fe719004e5a.jpg" alt="Le site web basé sur un modèle, terminé et ouvert à son URL Replit publique" width="1274" height="717" data-path="images/first-app-template/07-published-site.jpg" />
    </Frame>
  </Step>
</Steps>

<div id="congratulations-you-shipped-your-first-app">
  ## 🎉 Félicitations — vous avez publié votre première app
</div>

Vous êtes passé d&#39;un modèle de design à une URL en ligne, prête à être partagée. En chemin, vous avez :

* Choisi et remixé un modèle dans Replit Design.
* Demandé à Agent de transformer le design sélectionné en site web fonctionnel.
* Testé le résultat dans Preview.
* Publié l&#39;app et l&#39;avez ouverte à son URL publique.

Voilà un workflow Replit complet : choisir un point de départ, créer, tester, améliorer et publier.
