<div id="automatic-dependency-scans">
  ## 자동 dependency 스캔
</div>

자동 dependency 스캔은 project의 packages를 공개된 취약점 기록과 대조합니다. 이 스캔은 무료이며 자동으로 실행됩니다. 새로운 Common Vulnerabilities and Exposures(CVE) 항목이 공개되면 Replit이 이를 project의 dependencies와 대조하여, 수동으로 다시 스캔하지 않아도 일치하는 항목을 **Security** pane에 표시합니다.

Dependency 스캔은 Node.js/npm, Python, Go, Rust, PHP, Ruby를 지원합니다.

자동 dependency 수정은 현재 Node.js/npm을 중심으로 지원됩니다.

<div id="auto-protect">
  ### Auto-Protect
</div>

Auto-Protect는 자동 dependency 검사를 확장한 기능입니다. Replit이 조건에 맞는 취약점을 감지하면 Agent가 패치를 준비하고 테스트한 뒤 바로 연결되는 링크를 이메일로 보내드립니다. 해당 패치는 검토를 기다리는 상태로 **Security** pane에 남아 있습니다. 패치를 적용한 후에는 production 버전에 수정 사항이 반영되도록 앱을 다시 게시하세요.

Auto-Protect는 dependency CVE만 다룹니다. 애플리케이션 코드를 검토하려면 [Agent security scan](/ko/features/security/agent-security-scans)을 사용하세요.

두 가지 Auto-Protect 설정은 모두 기본적으로 꺼져 있습니다.

<Steps>
  <Step title="패치 준비 활성화">
    Workspace admin이 **Settings** &gt; **Account** &gt; **Advanced**로 이동한 다음,
    Replit이 remediation을 준비할 최소 severity(low, medium, high, critical)를
    선택합니다.
  </Step>

  <Step title="보안 이메일 활성화">
    **Settings** &gt; **Personalization** &gt; **Email Notifications**로 이동한 다음,
    알림을 받을 최소 severity를 선택하세요.
  </Step>
</Steps>

새로운 취약점이 발견되면 Replit은 영향을 받는 모든 projects를 요약해 Workspace당 최대 한 통의 이메일만 보냅니다. Agent가 준비한 패치를 적용하기 전에 확인하려면 **Go to Task**를 선택하세요. 패치를 적용하면 새 버전을 게시할 때까지 해당 취약점이 **pending republish** 상태로 표시됩니다.

<Note>
  Agent가 준비한 remediation은 Auto-Protect가 선제적으로 준비한 경우를 포함해
  다른 Agent 작업과 동일하게 요금이 청구됩니다.
</Note>

<div id="review-findings">
  ## findings 검토
</div>

보안 검사 결과는 **Security** pane에 표시되며 severity별로 분류됩니다:

| Severity            | 안내                          |
| ------------------- | --------------------------- |
| Critical            | 게시 전에 반드시 해결해야 하는 즉각적인 위험   |
| High                | 특정 조건에서 악용될 수 있는 심각한 issues |
| Medium              | 악용 가능성은 낮지만 잠재적인 위험         |
| Low / Informational | 사소한 issues 및 모범 사례 권장 사항    |

각 finding을 수락, 수정 또는 무시하기 전에 먼저 검토하세요. 수락한 issues는 remediation을 위해 Agent에 전달하고, 수정 사항을 적용한 후에는 해당 스캔을 다시 실행하세요.

  ## 개발 및 게시 중 보안 검사

<div id="security-scan-while-you-build">
  ### Security scan while you build
</div>

Agent로 앱을 만드는 동안 Replit은 Agent가 변경한 파일에 흔한 보안 취약 패턴이나 하드코딩된 secret이 있는지 자동으로 검사합니다. codebase 전체를 검토하는 것이 아니라 Agent workflow 초기에 이루어지는 가벼운 검사입니다. 검사 결과는 **Security** pane에 별도의 report로 표시되지 않습니다.

<div id="publish-checks">
  ### 게시 검사
</div>

Replit은 게시 전에도 security scan을 실행합니다. **Block publishing of critical vulnerabilities** 설정은 스캔에서 심각한 문제가 발견됐을 때의 동작을 결정합니다.

* **On**: 문제를 해결하거나 무시 처리할 때까지 게시가 차단됩니다.
* **Off**: 게시는 그대로 진행되며, finding은 검토할 수 있도록 남습니다.

Enterprise 조직은 모든 App에 이 설정을 필수로 적용할 수 있습니다.

이러한 검사는 전체 [Agent security scan](/ko/features/security/agent-security-scans)이나 [Level 3 스캔](/ko/features/security/black-box-pen-tests)을 대체하는 것이 아니라 보완하는 역할을 합니다.
