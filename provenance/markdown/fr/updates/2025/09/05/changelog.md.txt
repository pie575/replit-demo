## Plateforme

### Agent général

<Frame>
  <img src="https://mintcdn.com/replit/1KNLLtS073bEHM-0/images/replitai/general-agent.png?fit=max&auto=format&n=1KNLLtS073bEHM-0&q=85&s=2facc4c029b86df1fa70948fb92a23c1" alt="General Agent hero illustration" width="1040" height="572" data-path="images/replitai/general-agent.png" />
</Frame>

Replit Agent fonctionne désormais sur n'importe quelle base de code dans n'importe quel langage ou framework fonctionnant sur NixOS ! Précédemment limité à des modèles spécifiques, l'Agent peut désormais assister avec les Frameworks de développement, les importations GitHub et toute configuration de projet personnalisée. Cette expansion puissante apporte une assistance complète au codage par IA aux flux de travail enterprise et aux utilisateurs avancés.

En savoir plus sur l'Agent général [ici](/fr/core-concepts/agent/general-agent).

### Mode Plan

<Frame>
  <img src="https://mintcdn.com/replit/F1Uusll-kiG71hlC/images/replitai/plan-mode-overview.png?fit=max&auto=format&n=F1Uusll-kiG71hlC&q=85&s=247073a58dc0196b6fb486fd32653fbd" alt="Agent chat interface in Plan mode" width="916" height="362" data-path="images/replitai/plan-mode-overview.png" />
</Frame>

Le mode Plan introduit une nouvelle façon de discuter avec Replit Agent axée sur les questions, le brainstorming et la planification de votre travail. Avec le mode Plan, vous pouvez utiliser l'Agent pour créer une liste de tâches pour les travaux futurs, puis exécuter des tâches longues en mode Build.

En savoir plus sur le mode Plan [ici](/fr/core-concepts/agent/plan-mode).

## Enterprise

### Intégration GCP Marketplace

Les clients Enterprise peuvent désormais acheter Replit directement via Google Cloud Platform Marketplace et utiliser leurs crédits GCP existants pour le paiement. Cela simplifie les processus d'approvisionnement et facilite l'adoption de Replit par les organisations disposant de budgets GCP pour leurs flux de travail de développement.
