description: "Узнайте, как публиковать приложения на постоянно работающих облачных серверах с помощью развёртываний Reserved VM."
---

Развёртывания Reserved VM работают на виртуальной машине (VM), которая выделяет вашему приложению отдельные вычислительные ресурсы. Такой тип развёртывания обеспечивает предсказуемые расходы и производительность без прерываний.

Он идеально подходит для следующих сценариев:

* фоновые задачи, требующие большого объёма памяти;
* боты чат-приложений, которым нужно постоянное подключение;
* постоянно работающие API-серверы.

<div id="section">
  ## Возможности
</div>

Развёртывания Reserved VM включают следующие возможности:

* **Выделенные ресурсы**: зарезервированные вычислительные ресурсы обеспечивают стабильную производительность App.
* **Собственные домены**: настройте собственный домен или используйте URL `<app-name>.replit.app` для доступа к App.
* **Варианты вычислительных ресурсов**: выберите конфигурацию VM, соответствующую требованиям вашего App к производительности.
* **Настраиваемая привязка портов**: укажите, какие порты App открывает в интернет.
* **Мониторинг**: просматривайте логи и отслеживайте состояние опубликованных App.

<div id="section-2">
  ## Использование
</div>

Развертывания Reserved VM доступны в инструменте Publishing редактора проектов.

<Accordion title="Как перейти к развертываниям Reserved VM">
  На **панели инструментов** слева:

  1. <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Значок All tools" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> Выберите **All tools**, чтобы открыть список инструментов редактора проектов.
  2. <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Значок Publishing" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> Выберите **Publishing**.
  3. Выберите **Reserved VM**, затем **Set up your published app**.

  Через **строку поиска**:

  1. Нажмите значок <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="Значок лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" />лупы в верхней части экрана, чтобы открыть поиск.
  2. Введите «Publishing», найдите инструмент и выберите его в результатах поиска.
  3. Выберите **Reserved VM**, затем **Set up your published app**.
</Accordion>

<div id="section-3">
  ### Конфигурация машины
</div>

Выберите параметры CPU и RAM для машины, на которой будет размещён деплой. Рядом с каждым размером машины отображается его стоимость.

<div id="section-4">
  ### Основной домен
</div>

Укажите поддомен в имени хоста опубликованного приложения. После публикации приложение будет доступно по адресу `https://<subdomain>.replit.app`.

О том, как использовать собственный домен, см. [Пользовательские домены](/ru/features/publishing/custom-domains).

<div id="section-5">
  ### Приватные развёртывания
</div>

<Info>
  Функция приватной публикации приложения доступна на планах Pro и Enterprise.
</Info>

Приватно опубликованные приложения открывают доступ к приложению только участникам вашего workspace либо тем пользователям и группам, которых вы пригласите.
При публикации можно выбрать один из вариантов доступа: **Public**, **Password protected**, **Workspace only** или **Invite only**.

О том, как настроить приватный deployment, читайте в разделе [Доступ к приложению](/ru/features/publishing/private-deployments/).

<div id="section-6">
  ### Команда сборки
</div>

В поле **Build command** введите команду оболочки, которая компилирует или подготавливает приложение перед выполнением команды Run.
Например, чтобы оптимизировать JavaScript-приложение для продакшена с помощью Vite, можно добавить команду `vite build`.

<div id="section-7">
  ### Команда запуска
</div>

В поле **Run command** введите команду оболочки, запускающую задачу. Она должна совпадать с командой, которую вы используете в рабочем процессе. Например, чтобы запустить Flask-приложение с именем «myApp», можно указать команду `flask --app myApp run`.

<div id="section-8">
  ### Секреты опубликованного приложения
</div>

Выберите **Add published app secret**, чтобы добавить переменные окружения и секреты, необходимые для безопасной работы приложения.

Если в Replit App заданы переменные окружения или секреты, инструмент Publishing автоматически добавит их в список K.

<div id="section-9">
  ### Варианты типа приложения
</div>

Выберите один из следующих вариантов:

* **Web server**: выберите этот вариант, если публикуете веб-приложение или приложение, к которому пользователи смогут подключаться через интернет.
* **Background worker**: выберите этот вариант, если ваше приложение не прослушивает порт и не запускает сервер.

Если вы выбрали **Web Server**, вы можете указать, какие порты будут открыты:

1. Разверните раздел **Port configuration**.
2. Выберите **Networking pane to configure**, чтобы открыть вкладку **Networking** и управлять сопоставлением портов.

Подробнее о настройке портов см. в разделе [Порты](/ru/ja/features/project-setup/ports/).
