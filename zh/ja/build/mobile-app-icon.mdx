export const appIconPrompt = "为 PixelGames 生成 3 种不同的 1024x1024 App 图标设计概念。";

两个应用商店都要求在接受提交前提供应用图标。无需使用其他设计工具，
Replit 即可直接生成应用图标。

<div id="section">
  ## 各应用商店的要求
</div>

* **App Store：** 1024×1024，不含透明通道，不带圆角 (Apple 会自动添加) 。
* **Google Play：** 512×512。

<div id="section-2">
  ## 生成
</div>

发送提示词前，请切换到 **Design** 模式。这样 Agent 就会生成图像。

<AiPrompt>
  {appIconPrompt}
</AiPrompt>

Agent 会一次生成多个设计方向，您可以在决定前进行比较和选择。
