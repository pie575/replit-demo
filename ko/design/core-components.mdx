Replit Design의 핵심은 frames를 펼쳐 보여주는 무한 canvas입니다. 이 페이지에서 다루는 나머지 요소는 모두 그 frames를 다루는 방법에 관한 것입니다.

* 무한한 board 위에 design frames를 생성하고 배치하세요
* chat, suggestions, toolbar로 각 frame을 다듬어 나가세요
* frame의 특정 부분만 지정해 그 부분만 변경하세요
* board를 벗어나지 않고 templates와 실제 제품 inspiration을 가져오세요

Replit Design workspace는 일곱 가지 구성 요소로 이루어져 있습니다:

* **[Canvas](/ko/design/canvas)**: Project Editor의 디자인 보기로, 모든 frame과 도형, 메모를 담는 무한 패닝·확대 board입니다.
* **[Frames](/ko/design/frames)**: Canvas 위의 모든 타일입니다. Frames는 실제로 동작하는 artifact(website, slides)일 수도 있고, design mockup, 이미지, 비디오, 벡터 그래픽일 수도 있습니다.
* **[Elements](/ko/design/elements)**: 제목, 버튼, 이미지, 양식 필드처럼 frame 안에 들어 있는 개별 요소입니다.
* **[Chat](/ko/design/chat-about-your-design)**: canvas에 도킹된 Agent chat입니다. 만들고 싶은 것을 설명하거나, frame을 선택해 작거나 큰 수정을 요청하세요. 최소화하면 canvas를 넓게 쓸 수 있습니다.
* **[Ambient intelligence](/ko/design/explore-suggestions)**: 선택한 frame 옆에 나타나는 다음 단계 suggestions로, 클릭 한 번이면 새로운 direction을 생성합니다. 작동 방식은 [Explore suggestions](/ko/design/explore-suggestions)를 참고하세요.
* **[Toolbar](/ko/design/toolbar)**: Canvas 하단에 떠 있는 막대로, Interact, Pan, Chat, Draw, Edit, Generate 도구를 제공합니다.
* **[Library panel](/ko/design/library-panel)**: 시작용 templates, Mobbin이 선별한 inspiration, 그리고 직접 만든 이전 작업물을 canvas로 바로 끌어다 놓을 수 있습니다.

<div id="how-they-fit-together">
  ## 각 요소가 어우러지는 방식
</div>

각 구성 요소는 앞선 요소가 끝나는 지점에서 이어집니다. 빈 board에서 시작해 Build할 수 있는 Design까지 이어집니다.

<div id="1-put-frames-on-the-canvas">
  ### 1. Canvas에 frame 배치하기
</div>

Chat prompt를 사용하거나 Toolbar의 **Generate** 메뉴에서 frame을 생성합니다. frame은 design mockup, web app, mobile app, slides, 이미지, 동영상, 벡터 그래픽 중 어떤 것이든 될 수 있습니다.

<div id="2-iterate-on-a-frame">
  ### 2. frame 다듬기
</div>

개별적으로 작업하려면 원하는 frame을 선택하세요. Chat에서 자유롭게 원하는 바를 이야기하거나, [suggestion](/ko/design/explore-suggestions)을 따라 새로운 direction으로 분기하거나, **Focus**로 확대해 세밀하게 작업할 수 있습니다. 원하는 결과가 나오면 **Build**로 live app으로 만드세요.

<Frame caption="Build, Focus, 추가 옵션이 표시된 액션 바와 함께 선택된 frame.">
  <img src="/assets/mirror/canvas-frame-action-bar-86f90fdd1375.png" alt="APEX X1 Design frame이 선택된 Canvas. 상단에 종류 label과 Build, Focus, 추가 옵션 액션이 있는 per-frame action bar가 표시되고, 해당 frame이 chat prompt box에 chip으로 첨부되어 있음" width="2000" height="1290" data-path="images/replitai/canvas-frame-action-bar.png" />
</Frame>

<div id="3-edit-annotate-or-generate-with-the-toolbar">
  ### 3. toolbar로 편집, 주석, 생성하기
</div>

toolbar는 세 가지 역할을 합니다. **Edit**는 frame 안의 개별 요소를 선택해 Visual Editor를 열고, **Draw**는 Agent가 읽을 수 있는 스케치, 화살표, 메모로 board에 주석을 달며, **Generate**는 디자인에 필요한 이미지, 동영상, 벡터 그래픽을 만들어 냅니다.

<Frame caption="Edit tool로 요소를 선택하면 오른쪽에 Visual Editor가 열립니다.">
  <img src="/assets/mirror/canvas-edit-67fe5ee02fbe.png" alt="슈퍼카 렌털 웹사이트에서 div 요소가 선택된 채 활성화된 Edit tool과, Text, Layout, Color, Border 컨트롤 및 Discard, Save edits 버튼이 표시된 Visual Editor 패널" width="2000" height="1269" data-path="images/replitai/canvas-edit.png" />
</Frame>

<div id="4-pull-inspiration-from-the-library-panel">
  ### 4. library panel에서 Inspiration 가져오기
</div>

영감이나 시작점이 필요할 때는 library panel을 열어 보세요. Templates는 바로 편집할 수 있는 frame 형태로 Canvas에 추가되고, Mobbin이 큐레이션한 Inspiration은 다음 생성 결과의 방향을 잡아 주는 정적 참고 이미지로 추가됩니다.

<Frame caption="library panel의 Templates 탭: 종류별로 묶여 있으며 검색 가능한 스타터 frame.">
  <img src="/assets/mirror/library-templates-5407d3683e8a.png" alt="검색창, 카테고리 filter, 포스터 한 개와 landing page 두 개가 포함된 template 카드가 있는 library panel의 Templates 탭" width="665" height="583" data-path="images/design/replit-design/library-templates.png" />
</Frame>
