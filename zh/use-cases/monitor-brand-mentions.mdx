<div id="before-you-start">
  ## 开始前准备
</div>

准备好你关注的品牌名称或账号、用于接收提醒的 Slack 频道，以及用于存档的 Notion
数据库。

Agent 会要求你提供 **X Bearer Token**。请前往
[console.x.com](https://console.x.com) 创建账号，并生成 Bearer Token。

请为你的 X 开发者账户充值。否则，X 上的提及搜索
将无法使用。

<div id="prompt-the-agent">
  ## 向 Agent 发出指令
</div>

<AiPrompt>
  创建一个每天早上 8:00 运行的 Routine。监控 X 上提及 [brand] 的内容。
  识别重要对话，总结情感倾向和上下文，将相关提及发送至 Slack，并归档到 Notion。忽略噪音。
  标记所有需要回复的内容。
</AiPrompt>

<div id="what-to-expect">
  ## 预期情况
</div>

Agent 会监测提及内容，评估哪些内容重要，将简短摘要发布到 Slack，并将讨论串
保存到 Notion。查看第一批结果，并进一步明确“重要”的判定标准。
如果一直没有收到提及内容，请检查是否已设置 Bearer Token，以及 X 开发者账户
是否有额度。首次在早间运行后，打开一条 Slack 提醒，点击进入 X，并确认
Notion 中的对应行包含相同的链接。

<div id="troubleshooting">
  ## 故障排查
</div>

* **始终收不到提及：** 确认已设置 X Bearer Token，并且 X 开发者账户中有可用额度。额度不足时，即使令牌有效，提及搜索也会失败。
* **Slack 毫无动静，Notion 却越记越多：** Agent 可能把所有内容都当成了噪音。收紧「重要」的判定标准，或者要求它即使没有需要回复的内容，也发布每日摘要。
* **归档内容杂乱：** 让 Agent 使用你现有的 Notion 数据库及其列 (日期、链接、情感倾向、是否需要回复) ，并要求它将内容映射到这些字段，而不是每次都新建一个页面。
