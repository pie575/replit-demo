<div id="free-mode">
  ### 在 Free Mode 中工作
</div>

使用 Free Mode，你无需消耗 Power Mode 或 Max Mode 积分即可聊天、探索想法、创作和构建。Free Mode 通过 Auto 自动选择模型，额度上限因套餐而异。若要查看剩余额度及重置时间，请前往 **Settings** &gt; **Usage** 查看。

  <img src="/assets/mirror/free-mode-agent-modes-selector-sanitized-b4b896fb13ab.png" width="1784" height="882" data-path="images/chat/free-mode-agent-modes-selector-sanitized.png" />
</Frame>

了解[如何充分利用 Free Mode](/zh/ko/chat/free-mode)。

<div id="conversation">
  ### 从 Conversation 开始
</div>

先从私密的 Conversation 入手：提问、查找信息、附加上下文、运行 Routine，或描述你想要的结果。当工作量逐渐增大时，可以让 Replit 把这个 Conversation 转为 Project，上下文和文件都会完整延续。

<Frame caption="在 Workspace 主页开始一个 Conversation。">

</Frame>

进一步了解 [Conversations](/zh/ko/chat/conversations)。

<div id="routine">
  ### 使用 Routine 自动化重复性工作
</div>

安排 Replit 在 Conversation 中重复执行任务。每次的结果都会返回到同一个 Conversation，你可以在其中查看并继续工作。Routine 在 Power Mode 或 Max Mode 下运行，每次运行都会消耗预算。

<Frame caption="在同一处查看活跃的 Routine、日程安排和运行记录。">
  <img src="/assets/mirror/routines-management-page-c8d8f51156d4.png" alt="Routines 页面列出了 Slack 中活跃的每日日历摘要及其日程安排" width="2738" height="782" data-path="images/chat/routines-management-page.png" />
</Frame>

进一步了解 [Routines](/zh/ko/chat/routines)。

<div id="agent-2">
  ### 在 Agent 工作时进行引导
</div>

在 Agent 工作期间发送后续消息，即可为当前进行中的轮次补充新的上下文。Steer 是 Conversation 和 Project 的默认行为，你可以在 **Settings** &gt; **Personalization** 中分别将偏好设置改为 Queue。若只想对某一条消息使用相反的行为，请在 Mac 上按 `Cmd+Enter`，在 Windows 和 Linux 上按 `Ctrl+Enter`。

<Frame caption="分别为 Conversation 和 Project 选择 Steer 或 Queue。">
  <img src="/assets/mirror/agent-follow-ups-settings-98a4c5ca399e.png" alt="显示 Conversation 和 Project 发送行为及 Steer、Queue 选项的 Agent 设置" width="3048" height="1372" data-path="images/replitai/agent-follow-ups-settings.png" />
</Frame>

详细了解[引导或排队后续消息](/zh/ko/features/agent/steer-and-queue-messages)。

<div id="github-skill">
  ### 从 GitHub 导入 skill
</div>

你可以从公开的 GitHub 仓库、文件夹或文件 URL 导入 skill，并在添加前预览 skill 文件。已保存的 Project skill 还支持 **Required**、**Available** 和 **No access** 三种成员访问级别。

<Frame caption="打开 Workspace Skills，即可查找并使用共享或导入的 skill。">
  <img src="/assets/mirror/workspace-skill-picker-d7c3f5525de2.jpg" alt="列出 ask-matt、claude-handoff、code-review 的 Agent Workspace Skills 选择器" width="2000" height="1085" data-path="images/replitai/workspace-skill-picker.jpg" />
</Frame>

详细了解[如何共享和导入 Agent skill](/zh/ko/features/agent/skills#share-project-skills)。

<div id="workspace-agent">
  ### 跨 Workspace 管理 Agent 模型
</div>

Enterprise 账户管理员可以为每个模型提供方设置账户策略，然后选择各个 Workspace 中可用的模型。请根据组织的策略，在 **Enable all**、**Enable selected** 和 **Disabled** 之间进行选择。

</Frame>

<div id="section-4">
  ### 运行黑盒渗透测试
</div>

运行 Level 3 安全扫描，将三项检查合而为一：免费的依赖项与软件包检查、针对源代码的 Agent 静态分析，以及针对实时 Preview 的外部黑盒测试。Replit 会同时执行源代码审查和外部测试。
