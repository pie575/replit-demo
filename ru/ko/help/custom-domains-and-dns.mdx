Здесь рассматриваются подключение пользовательских доменов и устранение связанных с ними неполадок. Полную справочную информацию см. в разделах [Добавление пользовательского домена](/ru/ko/build/add-custom-domain) и [Пользовательские домены](/ru/ko/features/publishing/custom-domains).

<AccordionGroup>
  <Accordion title="Как подключить собственный домен к Replit App?">
    Если вы приобрели домен через Replit, DNS-записями можно управлять автоматически: откройте **Publishing → Domains** и следуйте инструкциям в интерфейсе. См. [покупка домена](/ru/ko/build/domain-purchasing).

    Чтобы подключить домен, зарегистрированный у стороннего регистратора:

    1. Откройте проект и перейдите в **Publishing → Domains**.
    2. Выберите **Подключить собственный домен**, введите домен и продолжите.
    3. Replit отобразит A- и TXT-записи — скопируйте обе.
    4. Добавьте обе записи у своего DNS-провайдера.
    5. Вернитесь в Replit и начните проверку.

    Несколько важных примечаний:

    * Для SSL необходимы и A-, и TXT-записи. CNAME-записи для корневого домена не поддерживаются — используйте для него A-запись.
    * Подстановочные сертификаты (`*.example.com`) не поддерживаются. Подключайте каждый поддомен отдельно.
    * В Cloudflare установите для A-записи значение **DNS only** (серое облако), чтобы прокси-режим не препятствовал настройке SSL.
    * Распространение изменений DNS может занять до 48 часов.

    Подробности см. в разделе [пользовательские домены](/ru/ko/features/publishing/custom-domains).
  </Accordion>

  <Accordion title="Домен не подтверждён или SSL-сертификат не выпущен — как устранить проблему?">
    Выполните следующие проверки по порядку — большинство проблем возникает на одном из этих этапов:

    1. **Дождитесь распространения DNS.** Изменения могут вступать в силу до 48 часов. С помощью инструмента проверки DNS убедитесь, что записи отображаются по всему миру.
    2. **Удалите AAAA-записи.** Записи IPv6 (AAAA) с тем же именем хоста, что и A-запись, могут препятствовать выпуску SSL-сертификата.
    3. **Удалите старые или конфликтующие A-записи.** Для корневого домена оставьте только одну A-запись, указывающую на Replit.
    4. **Настройте Cloudflare в режим DNS only.** Оранжевое облако (прокси-режим) мешает выпуску SSL-сертификата.
    5. В **Publishing → Domains → Manage** отключите и снова подключите домен, чтобы принудительно выпустить новый сертификат, затем подождите несколько минут и обновите страницу.
    6. **Проверьте CAA-записи.** Если у вас есть CAA-записи, как минимум одна из них должна разрешать Let&#39;s Encrypt выступать центром сертификации, поскольку Replit выпускает сертификаты через Let&#39;s Encrypt.

    Эти проверки применяются к доменам, зарегистрированным у внешних регистраторов. Если вы приобрели домен через Replit, [обратитесь в службу поддержки Replit](https://replit.com/support). См. раздел [Пользовательские домены](/ru/ko/features/publishing/custom-domains).
  </Accordion>

  <Accordion title="Как настроить аутентификацию Clerk на собственном домене?">
    При использовании [аутентификации Clerk](/ru/ko/features/auth-and-identity/clerk-auth) с пользовательским доменом часто возникают следующие проблемы:

    * **Предупреждение &quot;Требуются записи CNAME для Clerk&quot;.** Это требование интеграции Clerk, которое не препятствует проверке домена или выпуску SSL-сертификата. Откройте **Publishing → Domains**, выберите **Manage**, найдите раздел настроек DNS для аутентификации и в точности добавьте все записи CNAME у своего DNS-провайдера. Если раздел не отображается, отключите домен и подключите его снова.
    * **Домен зависает на этапе проверки после предыдущего использования Clerk.** Если домен был подключён к другому приложению Clerk, удалите его в [панели управления Clerk](https://dashboard.clerk.com), затем отключите домен и подключите его снова в Replit.
    * **Переход на собственный экземпляр Clerk.** Для перехода с экземпляра Clerk, управляемого Replit, на собственный экземпляр требуются ручные действия — [обратитесь в службу поддержки Replit](https://replit.com/support). См. раздел [Можно ли использовать собственное приложение Clerk вместо приложения, управляемого Replit?](/ru/ko/features/auth-and-identity/clerk-auth#can-i-bring-my-own-clerk-app-instead-of-using-the-replit-managed-one).

    Если проблема сохраняется, [обратитесь в службу поддержки Replit](https://replit.com/support), указав доменное имя, название проекта и действия, которые вы уже предприняли.
  </Accordion>
