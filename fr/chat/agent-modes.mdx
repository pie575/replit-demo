Les modes Agent vous permettent de choisir l'équilibre entre allocation incluse, crédits et capacité avant d'envoyer une requête. Ouvrez le menu déroulant des paramètres Agent dans la zone de saisie, puis sélectionnez le mode adapté au travail.

<Note>
  Le mode Economy n'est plus disponible. Le mode Power le remplace au même prix.
</Note>

## Choisissez un mode

* **Mode Free :** Explorez des idées, posez des questions, commencez à créer et gardez le travail quotidien en mouvement. Le mode Free utilise le routage de modèle intelligent pour sélectionner le modèle. {FreeModePlanAvailability}
* **Mode Power :** Un équilibre judicieux entre rapidité et capacité pour la plupart des tâches. Utilisez-le lorsque vous avez besoin de plus que votre allocation Free Mode ou souhaitez une option par défaut plus performante pour un projet existant.
* **Mode Max :** L'option la plus performante pour les tâches complexes et ambitieuses, les bases de code plus importantes et les problèmes les plus difficiles.

Le mode Power et le mode Max utilisent des crédits mensuels. Replit vous informe avant qu'une requête ne passe du mode Free à un mode entraînant des coûts d'utilisation. Vérifiez votre allocation Free Mode restante dans **Settings** → **Usage**. Pour des conseils pratiques, consultez [Tirez le meilleur parti du mode Free](/fr/chat/free-mode).

Les routines s'exécutent en mode Power ou Max et nécessitent un budget par exécution. Elles ne peuvent pas s'exécuter en mode Free. En savoir plus sur les [routines](/fr/chat/routines).
