La personnalisation d&#39;Agent lui donne le contexte nécessaire pour travailler à votre manière et à celle de votre équipe, dès le premier prompt. Plutôt que de réexpliquer vos conventions dans chaque projet, définissez-les une seule fois pour votre workspace : Agent les appliquera partout.

Elle comporte deux volets :

* **Instructions personnalisées** : des directives toujours actives qui s&#39;appliquent à chaque projet de votre workspace.
* **Compétences** : des instructions réutilisables qu&#39;Agent charge uniquement lorsqu&#39;une tâche pertinente se présente.

Vous gérez les deux dans **Paramètres du Workspace → Personnalisation**.

<div id="custom-instructions-vs-skills">
  ## Instructions personnalisées et compétences
</div>

Les instructions personnalisées sont chargées à chaque message ; les compétences, uniquement lorsque Agent juge qu&#39;une tâche s&#39;y prête. Réservez les instructions personnalisées aux quelques directives toujours valables, et les compétences aux workflows, conventions et documents de référence spécifiques.

Pour comprendre la logique de cette répartition — le budget de contexte, ce qui relève de chaque catégorie et comment bien rédiger des compétences — consultez [Compétences Agent](/fr/learn/agent-skills). Pour découvrir la structure des compétences et la façon dont Agent les charge, consultez [Compétences Agent](/fr/features/agent/skills).

<div id="custom-instructions">
  ## Instructions personnalisées
</div>

Les instructions personnalisées sont des consignes toujours actives, injectées dans le contexte d&#39;Agent pour chaque projet et à chaque session, avant même que quiconque saisisse un prompt. Rédigez-les une seule fois dans les paramètres du Workspace : Agent les applique ensuite partout dans votre workspace. Elles conviennent particulièrement aux règles toujours valables, comme les exigences de sécurité et de conformité, les bibliothèques et frameworks approuvés ou les politiques de traitement des données.

Restez bref. Une instruction ciblée et précise a plus de chances d&#39;être suivie à la lettre, et elle laisse plus de place au travail qu&#39;Agent doit réellement accomplir.

<Warning>
  Les instructions personnalisées peuvent avoir un impact sur les performances d&#39;Agent. Agent est guidé pour les respecter, mais le respect strict des exigences n&#39;est pas garanti. Plus les consignes sont courtes et spécifiques, plus elles sont suivies de manière fiable.
</Warning>

<Note>
  Les instructions personnalisées du workspace sont différentes du fichier `custom_instruction/instructions.md` d&#39;un projet. L&#39;instruction personnalisée du workspace se définit une seule fois dans les paramètres du Workspace et s&#39;applique à tous les projets. Le fichier propre à un projet, lui, n&#39;existe qu&#39;au sein de ce projet — consultez [Créer un système de design personnalisé](/fr/teams/custom-design-system) pour ce cas de figure.
</Note>

<div id="skills">
  ## Compétences
</div>

Une compétence est un ensemble réutilisable d&#39;instructions qu&#39;Agent ne charge que lorsqu&#39;une tâche pertinente se présente. Les compétences du workspace apparaissent en haut du menu **+** dans chaque projet de votre workspace : toute votre équipe dispose ainsi du même ensemble.

Vous pouvez créer une compétence de trois façons :

* **Importer** un dossier de compétence existant.
* **Rédiger** une nouvelle compétence directement dans le formulaire.
* **Demander à Agent** de rédiger une compétence pour vous, puis l&#39;affiner.

<Note>
  Vous pouvez importer dans votre Workspace des compétences rédigées par Agent. Demandez à Agent de télécharger la compétence : il la conditionnera sous forme d&#39;archive `.zip` téléchargeable accompagnée d&#39;un bouton **Download file** (illustré ci-dessous). Téléchargez le zip, puis importez-le dans **paramètres du Workspace → Customization → compétence** via **Create skill → Choose file or folder** afin qu&#39;il soit partagé dans tout votre workspace.
</Note>

<Frame>
  <img src="/assets/mirror/agent-customization-download-skill-3727b188c5a8.png" alt="Agent a conditionné une compétence de workspace sous forme d'archive téléchargeable ux-designer-skill.zip, avec un bouton Download file" width="1716" height="864" data-path="images/replitai/agent-customization-download-skill.png" />
</Frame>

Pour la structure complète d&#39;une compétence (`SKILL.md`, fichiers associés, le standard ouvert), consultez [Compétences Agent](/fr/features/agent/skills). Pour parcourir les compétences déjà créées par Replit et ses partenaires, consultez le [répertoire des compétences](/fr/features/agent/skills-directory).

<Note>
  Utilisez les compétences avec parcimonie. Agent lit le nom et la description de chaque compétence à chaque tâche : en avoir trop (ou qui se recoupent) dilue sa concentration et peut l&#39;empêcher de choisir la bonne. Gardez chaque compétence bien délimitée et supprimez celles dont vous n&#39;avez plus besoin.
</Note>

<div id="availability-and-permissions">
  ## Disponibilité et autorisations
</div>

| Fonctionnalité              | Disponible sur            | Qui peut gérer                                                       |
| --------------------------- | ------------------------- | -------------------------------------------------------------------- |
| Instructions personnalisées | Pro et Enterprise         | Enterprise : administrateurs. Pro : tout membre du workspace         |
| Compétences                 | Tous les forfaits payants | Enterprise : administrateurs. Core et Pro : tout membre du workspace |

Dans les workspaces Enterprise, seuls les administrateurs peuvent créer, modifier ou supprimer des instructions personnalisées et des compétences. Dans les workspaces Pro, tout membre du workspace le peut. Dans les workspaces Core, tout membre peut gérer les compétences — les instructions personnalisées n&#39;y sont pas disponibles. Dans tous les cas, chaque membre du workspace peut utiliser les compétences créées.

<div id="create-a-custom-instruction">
  ## Créer une instruction personnalisée
</div>

<Steps>
  <Step title="Ouvrir les paramètres du workspace">
    Accédez à **paramètres du Workspace → personnalisation**.

    <Frame>
      <img src="/assets/mirror/agent-customization-tab-930af2e8ed74.png" alt="L'onglet personnalisation dans les paramètres du Workspace, affichant les sous-onglets compétence et instruction personnalisée" width="1065" height="394" data-path="images/replitai/agent-customization-tab.png" />
    </Frame>
  </Step>

  <Step title="Rédiger votre instruction">
    Dans la section **instruction personnalisée**, rédigez les consignes qu&#39;Agent doit appliquer à tous vos projets.
  </Step>

  <Step title="Enregistrer">
    Enregistrez vos modifications. L&#39;instruction s&#39;applique aux nouveaux projets de votre workspace.
  </Step>
</Steps>

<div id="create-a-skill">
  ## Créer une compétence
</div>

<Steps>
  <Step title="Ouvrir les paramètres du workspace">
    Accédez à **paramètres du Workspace → personnalisation**.
  </Step>

  <Step title="Créer la compétence">
    Dans la section **compétence**, cliquez sur **Create skill**, puis importez un dossier de compétence, rédigez les instructions ou demandez à Agent d&#39;en rédiger une.

    <Frame>
      <img src="/assets/mirror/agent-customization-create-skill-fcb794e6de4e.png" alt="L'onglet personnalisation dans les paramètres du Workspace, avec les sous-onglets compétence et instruction personnalisée et le formulaire de création d'une compétence ouvert" width="2168" height="1350" data-path="images/replitai/agent-customization-create-skill.png" />
    </Frame>
  </Step>

  <Step title="Rédiger une description claire">
    Donnez à la compétence une description précise qui indique dans quels cas l&#39;utiliser — et dans quels cas l&#39;éviter. C&#39;est sur cette base qu&#39;Agent détermine si la compétence s&#39;applique.
  </Step>

  <Step title="Enregistrer">
    Enregistrez la compétence. Elle devient alors disponible dans le menu **+** de chaque projet de votre workspace.
  </Step>
</Steps>

<div id="use-a-workspace-skill-in-a-project">
  ## Utiliser une compétence de workspace dans un projet
</div>

Une description de compétence précise fait toute la différence. Agent lit la description de chaque compétence du workspace et en charge une automatiquement dès que votre prompt correspond globalement à sa finalité : vous n&#39;avez donc pas toujours besoin de choisir une compétence vous-même. Vous pouvez aussi sélectionner explicitement une compétence pour être sûr qu&#39;elle soit bien appliquée.

Pour en sélectionner une manuellement :

<Steps>
  <Step title="Ouvrir le sélecteur de compétences">
    Dans un projet, cliquez sur le bouton **+** à côté du champ de saisie du chat. Les compétences de votre workspace apparaissent en haut, regroupées.

    <Frame>
      <img src="/assets/mirror/agent-customization-skill-picker-4643f3a453c7.png" alt="Le sélecteur de compétences ouvert depuis le bouton +, affichant le groupe des compétences du workspace en haut, au-dessus des compétences Replit" width="1668" height="1170" data-path="images/replitai/agent-customization-skill-picker.png" />
    </Frame>
  </Step>

  <Step title="Sélectionner une compétence">
    Choisissez la compétence à activer. Vous pouvez aussi taper `/` suivi du nom de la compétence pour l&#39;invoquer directement.
  </Step>

  <Step title="Poursuivre vos prompts">
    Continuez normalement. Agent utilise la compétence lorsque la tâche correspond à sa description.
  </Step>
</Steps>

<div id="manage-instructions-and-skills">
  ## Gérer les instructions et les compétences
</div>

Toute la gestion s&#39;effectue dans **Paramètres du Workspace → Personnalisation**. Vous pouvez y modifier une instruction personnalisée, et modifier, désactiver ou supprimer n&#39;importe quelle compétence. Les modifications s&#39;appliquent aux prochaines conversations, mais pas à celles déjà en cours.
