Reserved VM deployment работает на виртуальной машине (VM), которая выделяет вычислительные ресурсы исключительно под
ваше приложение. Такой тип deployment обеспечивает предсказуемые расходы и производительность без перебоев.

Он идеально подходит для следующих сценариев:

* Фоновые задачи, требующие много памяти
* Чат-боты, которые должны постоянно оставаться на связи
* Постоянно доступные API-серверы

<div id="recursos">
  ## Возможности
</div>

Reserved VM Deployments включают следующие возможности:

* **Выделенные ресурсы**: стабильная производительность приложения на зарезервированных вычислительных ресурсах.
* **Собственные домены**: настройте собственный домен или используйте URL `<имя-приложения>.replit.app` для доступа к приложению.
* **Варианты вычислительных ресурсов**: выберите конфигурацию виртуальной машины, соответствующую требованиям вашего приложения к производительности.
* **Настраиваемые сопоставления портов**: укажите, какие порты приложение открывает в интернет.
* **Мониторинг**: просматривайте логи и отслеживайте состояние опубликованного приложения.

<div id="uso">
  ## Использование
</div>

Доступ к Reserved VM Deployments можно получить через инструмент Publishing в Project Editor.

<Accordion title="Как получить доступ к Reserved VM Deployments">
  В панели **Tool dock** слева:

  1. Выберите <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Значок всех инструментов" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**, чтобы открыть список инструментов Project Editor.
  2. Выберите <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Значок Publishing" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publishing**.
  3. Выберите вариант **Reserved VM**, а затем — **Set up your published app**.

  Через **строку поиска**:

  1. Нажмите <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="значок лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> значок лупы вверху, чтобы открыть инструмент поиска
  2. Введите «Publishing», чтобы найти инструмент, и выберите его в результатах.
  3. Выберите вариант **Reserved VM**, а затем — **Set up your published app**.
</Accordion>

<div id="configurao-da-mquina">
  ### Конфигурация машины
</div>

Выберите конфигурацию CPU и RAM для машины, на которой размещается ваш deployment. Стоимость выбранного варианта отображается рядом с выбранным размером машины.

<div id="domnio-principal">
  ### Основной домен
</div>

Укажите поддомен в имени хоста для опубликованного приложения. После публикации оно будет доступно по адресу `https://<subdomain>.replit.app`.

О том, как использовать собственный домен, см. в разделе [Пользовательские домены](/ru/features/publishing/custom-domains).

<div id="deployment-privado">
  ### Приватный deployment
</div>

<Info>
  Функция приватной публикации приложения доступна в тарифах Pro и Enterprise.
</Info>

Приватно опубликованные приложения доступны только участникам вашего workspace либо тем пользователям и группам, которых вы пригласите.
При публикации можно выбрать один из типов доступа: **Public**, **Password protected**, **Workspace only** или **Invite only**.

О том, как настроить приватный deployment, см. [Доступ к приложению](/ru/features/publishing/private-deployments/).

<div id="build-command">
  ### Build command
</div>

В поле **Build command** введите команду Shell, которая собирает или настраивает приложение перед выполнением Run command.
Например, чтобы оптимизировать приложение на JavaScript для продакшен-среды с помощью Vite, можно добавить команду `vite build`.

<div id="run-command">
  ### Run command
</div>

В поле **Run command** введите команду Shell, которая запускает вашу задачу. Эта команда должна быть похожа на ту,
которую вы используете в своём рабочем процессе. Например, чтобы запустить приложение Flask с именем «myApp», можно добавить команду `flask --app myApp run`.

<div id="secrets-do-app-publicado">
  ### Secrets опубликованного приложения
</div>

Нажмите **Add published app secret**, чтобы добавить переменные окружения или secrets, которые нужны вашему приложению для безопасной работы.

Если в вашем Replit App заданы переменные окружения или secrets, инструмент Publishing добавит их в список автоматически.

<div id="opes-de-tipo-de-app">
  ### Варианты типа приложения
</div>

Выберите один из следующих вариантов:

* **Web server**: выберите этот вариант, если публикуете веб-приложение или приложение, к которому пользователи будут подключаться через интернет.
* **Background worker**: выберите этот вариант, если ваше приложение не прослушивает порт и не запускает сервер.

При выборе **Web Server** вы можете указать, какие порты открывать. Для этого выполните следующие действия:

1. Разверните раздел **Port configuration**.
2. Выберите **Networking pane to configure**, чтобы открыть вкладку **Networking**, где можно управлять сопоставлениями портов.

Подробнее о настройке портов см. в разделе [Ports](/ru/pt/features/project-setup/ports/).
