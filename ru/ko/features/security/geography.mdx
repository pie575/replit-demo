Выберите, где размещается инфраструктура рабочего пространства и опубликованных приложений, чтобы обеспечить резидентность данных и снизить задержки. Replit предлагает раздельные настройки регионов, поэтому расположением среды разработки и опубликованных приложений можно управлять независимо друг от друга.

<div id="section">
  ## Сравнение региона рабочего пространства и региона публикации
</div>

| Параметр                    | Регион рабочего пространства                    | Регион публикации                                             |
| :-------------------------- | :---------------------------------------------- | :------------------------------------------------------------ |
| **На что распространяется** | Ресурсы разработки в рабочем пространстве       | Вычислительные ресурсы и хранилище опубликованного приложения |
| **Когда задаётся**          | При создании рабочего пространства              | При публикации проекта                                        |
| **Результат размещения**    | Определяет регион для новых проектов и ресурсов | Размещает все опубликованные артефакты в одном регионе        |
| **Можно ли изменить позже** | Нет                                             | Нет                                                           |

Регион рабочего пространства и регион публикации не обязательно должны совпадать.

Подробнее о выборе региона разработки при создании рабочего пространства см. в разделе [Регион рабочего пространства](/ru/ko/features/collaboration/workspace-geography).

<div id="section-2">
  ## Регион публикации
</div>

При публикации проекта вы задаёте регион публикации. По умолчанию Replit рекомендует ближайший к вам регион. Это снижает задержки для посетителей приложения и помогает соблюдать требования к резидентности данных.

После выбора региона все опубликованные артефакты проекта (вычислительные ресурсы, базы данных, Object Storage и другие) автоматически размещаются в одном и том же регионе. Региональные прокси также помогают снизить задержки для посетителей приложения.

<div id="section-3">
  ### Выбор региона публикации
</div>

Чтобы выбрать регион, отличный от рекомендованного, выполните следующие действия.

<Steps>
  <Step>
    В проекте Replit откройте инструмент **Publishing**.
  </Step>

  <Step>
    Разверните раздел **Advanced**.
  </Step>

  <Step>
    В раскрывающемся списке **Geography** выберите нужный регион.
  </Step>

  <Step>
    Нажмите **Publish**, чтобы опубликовать проект в выбранном регионе.
  </Step>
</Steps>

<div id="section-4">
  ### Принудительное применение региона к публикуемым проектам
</div>

Администраторы Enterprise могут принудительно задать регион публикации для всех проектов организации. После настройки такой политики разработчики организации будут публиковать проекты в указанном регионе. Политика распространяется только на ещё не опубликованные проекты и не затрагивает те, что уже опубликованы в другом регионе.

<Note>
  Принудительное применение региона публикации — это функция Enterprise. Подробнее о тарифах Enterprise см. на странице [Pricing](https://replit.com/pricing/).
</Note>

<Steps>
  <Step>
    Перейдите в **Account settings**.
  </Step>

  <Step>
    Выберите **Advanced**.
  </Step>

  <Step>
    Выберите регион, который должны использовать все проекты при первой публикации.
  </Step>
</Steps>

<div id="section-5">
  ### Ограничения региона публикации
</div>

Прежде чем выбрать регион публикации, учтите следующие ограничения.

* **Регион нельзя изменить после публикации.** Если проект опубликован в определённом регионе, этот выбор остаётся окончательным. Перенести опубликованный проект в другой регион невозможно.
* **Регион разработки и регион публикации могут не совпадать.** Такие ресурсы, как Object Storage, могут быть созданы до публикации и не совпадать с регионом публикации.

<div id="section-6">
  ## Доступные регионы
</div>

Для рабочего пространства и для публикации доступны разные наборы регионов.

| Регион            | Доступен для рабочего пространства | Доступен для публикации |
| :---------------- | :--------------------------------- | :---------------------- |
| **North America** | Да                                 | Да                      |
| **Europe (EU)**   | Да                                 | Да                      |
| **Asia**          | Да                                 | Да                      |
| **South America** | Нет                                | Да                      |
| **Australia**     | Нет                                | Да                      |

<Note>
  Выбор региона рабочего пространства доступен только клиентам Pro.
  Выбор региона публикации доступен клиентам Core, Pro и Enterprise.
  Приложения пользователей плана Free по умолчанию публикуются в North America.
</Note>
