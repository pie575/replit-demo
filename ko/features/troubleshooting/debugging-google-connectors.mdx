<div id="overview">
  ## 개요
</div>

[Connectors](/ko/features/integrations/overview#connectors)를 통해 Google Workspace 서비스(Drive, Docs, Sheets, Calendar 또는 Gmail)를 연결할 때 **&quot;This app is blocked&quot;** 오류 메시지가 표시된다면, 대개 조직의 Google Workspace에서 Google OAuth 설정이 잘못 구성되어 있는 것이 원인입니다.

이 가이드에서는 이 문제를 해결하여 Google 서비스를 Replit 앱에 연결하는 방법을 안내합니다.

<Frame>
  <img src="/assets/mirror/app-is-blocked-837b32f44f72.png" alt="OAuth 접근을 차단하는 'This app is blocked' 메시지가 표시된 Google 오류 대화 상자" width="1279" height="502" data-path="images/replitai/debugging-google-connectors/app-is-blocked.png" />
</Frame>

<Warning>
  이 단계는 **Google Workspace** 계정(조직에서 관리하는 계정)에만 적용됩니다. `@gmail.com` 주소에 연결된 개인 Google 계정을 사용 중이고 Replit connector가 차단된 경우에는 OAuth 정책을 직접 변경할 수 없으므로, Google Workspace 관리자에게 문의하거나 다른 계정을 사용하세요.
</Warning>

<div id="troubleshooting-steps">
  ## 문제 해결 단계
</div>

<div id="step-1-try-incognito-mode">
  ### 1단계: 시크릿 모드 사용해 보기
</div>

브라우저 확장 프로그램이나 캐시에 저장된 데이터가 OAuth flow를 방해할 수 있습니다. 시크릿 모드를 사용하면 이러한 문제를 피할 수 있습니다.

<Steps>
  <Step title="시크릿 창 열기">
    브라우저에서 새 **시크릿**(Chrome) 또는 **Private**(Firefox/Safari) 창을 엽니다.
  </Step>

  <Step title="Replit에 로그인">
    [replit.com](https://replit.com)에서 Replit account에 로그인합니다.
  </Step>

  <Step title="연결 다시 시도">
    Project Editor에서 앱을 열고 사이드바의 **Connectors**로 이동한 뒤 Google 서비스 연결을 다시 시도합니다.
  </Step>
</Steps>

오류가 계속되면 2단계로 진행하세요.

<div id="step-2-verify-oauth-settings-in-google-workspace">
  ### 2단계: Google Workspace에서 OAuth 설정 확인
</div>

<Note>
  이 단계를 진행하려면 조직의 **Google Admin 콘솔**에 접근할 수 있어야 합니다. 관리자 권한이 없다면 IT 팀에 문의하세요.
</Note>

<Steps>
  <Step title="Google Admin 콘솔 열기">
    조직의 [Google Admin 콘솔](https://admin.google.com)에 로그인합니다.
  </Step>

  <Step title="사용자 계정 확인">
    **Users** 섹션으로 이동해 Replit 연결을 시도한 계정이 목록에 있는지 확인합니다.

    <Frame>
      <img src="/assets/mirror/google-workspace-users-c21d8fd43f71.png" alt="사용자 계정이 표시된 Google Admin 콘솔 Users 섹션" width="1104" height="596" data-path="images/replitai/debugging-google-connectors/google-workspace-users.png" />
    </Frame>
  </Step>

  <Step title="API Controls로 이동">
    **Security &gt; Access and data control &gt; API controls**로 이동합니다.

    <Frame>
      <img src="/assets/mirror/google-workspace-api-controls-b811709315cf.png" alt="Security > API Controls 탐색 경로를 보여주는 Google Admin 콘솔" data-og-width="1140" width="1140" data-og-height="631" height="631" data-path="images/replitai/debugging-google-connectors/google-workspace-api-controls.png" data-optimize="true" data-opv="3" srcset="/assets/mirror/google-workspace-api-controls-a27d4577aee8.png 280w, /assets/mirror/google-workspace-api-controls-d681943c082d.png 560w, /assets/mirror/google-workspace-api-controls-8f1b1659e60a.png 840w, /assets/mirror/google-workspace-api-controls-795bc698b885.png 1100w, /assets/mirror/google-workspace-api-controls-c122b9eb493f.png 1650w, /assets/mirror/google-workspace-api-controls-2415c93b4f41.png 2500w" />
    </Frame>
  </Step>

  <Step title="third-party app access 열기">
    **Manage third-party app access**를 선택합니다.

    <Frame>
      <img src="/assets/mirror/third-party-app-access-eb5c94107497.png" alt="Manage third-party app access 버튼이 강조된 Google Admin 콘솔 API controls 페이지" width="1686" height="468" data-path="images/replitai/debugging-google-connectors/third-party-app-access.png" />
    </Frame>
  </Step>

  <Step title="OAuth 접근 권한 확인">
    Google Workspace에서 사용자에게 OAuth 접근이 허용되어 있는지 확인합니다. 제한되어 있다면 Replit이 OAuth flow를 완료할 수 있도록 필요한 접근 권한을 부여하세요.
  </Step>
</Steps>

그래도 연결에 실패한다면 3단계로 이동하세요.

<div id="step-3-add-replit-as-a-trusted-oauth-client">
  ### 3단계: Replit을 신뢰할 수 있는 OAuth 클라이언트로 추가
</div>

조직에서 기본적으로 third-party app access를 제한하고 있다면, Replit을 신뢰할 수 있는 앱으로 명시적으로 지정해야 합니다.

<Steps>
  <Step title="Google Admin 콘솔 열기">
    조직의 [Google Admin 콘솔](https://admin.google.com)에 로그인합니다.
  </Step>

  <Step title="API Controls로 이동">
    **Security &gt; Access and data control &gt; API controls**로 이동합니다.
  </Step>

  <Step title="third-party app access 열기">
    **App access control**에서 **Manage third-party app access**를 선택합니다.
  </Step>

  <Step title="새 앱 추가">
    **Add app** 버튼을 선택한 다음, 드롭다운에서 **OAuth App Name or Client ID**를 선택합니다.
  </Step>

  <Step title="Replit 검색">
    Replit Client ID를 입력합니다:

    ```
    1012035106355-2dhot2e6o0malvog2ofss7akj2nsp8nq.apps.googleusercontent.com
    ```

    **Search**를 선택합니다. 검색 결과에 Replit 앱이 나타나면 선택합니다.
  </Step>

  <Step title="액세스 수준 설정">
    액세스 수준을 **Trusted**로 설정합니다.
  </Step>

  <Step title="저장">
    **Save**를 선택합니다.
  </Step>
</Steps>

<Tip>
  Google Workspace 정책 변경 사항이 반영되기까지 몇 분이 걸릴 수 있습니다. 저장 후 5~10분 정도 기다린 다음, Replit에서 Google 서비스 연결을 다시 시도하세요.
</Tip>

<div id="still-blocked">
  ## 여전히 차단되나요?
</div>

세 단계를 모두 완료했는데도 오류가 계속 발생한다면:

* **조직 단위(OU) 다시 확인**: Google Workspace 정책은 특정 OU에만 적용될 수 있습니다. OAuth 및 신뢰할 수 있는 앱 설정이 연결을 시도하는 사용자가 속한 OU에 적용되는지 확인하세요.
* **Google Workspace 알림 검토**: 관리 콘솔에서 **보고 &gt; 감사 및 조사 &gt; OAuth 로그 이벤트**로 이동해 Replit과 관련된 거부된 요청이 있는지 확인하세요.
* **Replit 지원팀에 문의**: Google Workspace 측 문제가 아니라면 [Replit 지원팀](https://replit.com/support)에 도움을 요청하세요.
