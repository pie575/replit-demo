Agent prend en charge quatre types d’intégrations pour vous permettre de passer rapidement de l’idée à l’app :

* **Gérées par Replit** : intégrations intégrées qui fonctionnent automatiquement. Créez une app et votre Agent peut les utiliser immédiatement.
* **Connecteurs** : intégrations propriétaires prises en charge par Replit. Connectez-vous une seule fois. Agent peut lire et écrire directement dans ces services depuis Chat — récupérer des données, créer des enregistrements, envoyer des messages — et les utiliser dans vos apps.
* **Intégrations externes** : services tiers de confiance avec lesquels vous pouvez créer. Demandez à Agent de les configurer ; vous fournirez les clés API.
* **Services Agent** : API tierces payantes qu’Agent utilise en arrière-plan — aucune clé API n’est requise. L’utilisation est facturée sur vos crédits Replit.

<Note>
  **Disponibilité selon le forfait** : la plupart des connecteurs nécessitent un abonnement Core, Pro ou Enterprise, et certains sont disponibles avec le forfait Free. Le catalogue de connecteurs de votre workspace indique ceux que vous pouvez utiliser avec votre forfait actuel. Les créateurs utilisant le forfait Free peuvent toujours utiliser les intégrations gérées par Replit, telles que les bases de données, l’authentification, etc.
</Note>

  ## Premiers pas
</div>

Pour utiliser une intégration, mentionnez le service ou la fonctionnalité dont vous avez besoin. Par exemple :

</AiPrompt>

<div id="let-agent-suggest-a-connector">
  ### Laisser Agent vous suggérer un connecteur
</div>

Plusieurs services peuvent parfois remplir la même fonction, comme stocker des fichiers ou envoyer des e-mails. Lorsque vous demandez une fonctionnalité sans préciser de provider, Agent affiche une courte liste de connecteurs adaptés. Choisissez celui qui vous convient.

Sélectionnez un provider, puis connectez-vous une seule fois pour associer votre compte. Agent utilise votre choix pendant la création de votre application. Vous pouvez également demander un service précis par son nom pour ne pas afficher la liste.

<div id="configuring-oauth-app-with-replit">
  ### Configurer une application OAuth avec Replit
</div>

<Note>
  **Enterprise uniquement** : la configuration d&#39;une application OAuth personnalisée nécessite un abonnement Enterprise.
</Note>

Avec le forfait Enterprise, vous pouvez utiliser votre propre application OAuth pour un connecteur au lieu de celle fournie par défaut par Replit. Votre organisation est ainsi propriétaire du client OAuth, peut afficher sa propre image de marque sur l&#39;écran de consentement et contrôler précisément les scopes que vos créateurs peuvent demander.

Pour configurer un connecteur avec votre propre application OAuth, vous avez besoin de trois éléments fournis par le fournisseur : un **Client ID**, un **Client Secret** et les **scopes** que vous souhaitez autoriser. Vous devez également enregistrer l&#39;URL de rappel de Replit auprès du fournisseur afin que l&#39;authentification puisse aboutir.

<Frame>
  <img src="/assets/mirror/connector-oauth-configuration-100911ce0c48.png" alt="Boîte de dialogue de configuration OAuth du connecteur avec des champs pour le Client ID, le Client Secret et les scopes du connecteur, ainsi qu'une URL de redirection définie sur https://replit.com/connectors/oauth/callback" width="1112" height="1218" data-path="images/replitai/connector-oauth-configuration.png" />
</Frame>

<Steps>
  <Step title="Créer une application OAuth auprès de votre fournisseur">
    Connectez-vous à la console développeur ou aux paramètres d&#39;administration du fournisseur, puis créez une application OAuth 2.0. Les fournisseurs désignent cette étape de différentes manières : recherchez des options telles que **Créer une application OAuth**, **Enregistrer une application** ou **Créer des identifiants client**.
  </Step>

  <Step title="Définir l'URL de redirection">
    Lorsque le fournisseur vous demande un **URI de redirection autorisé** (parfois appelé **URL de rappel** ou **URL de redirection**), saisissez :

    ```
    https://replit.com/connectors/oauth/callback
    ```

    Cette URL indique au fournisseur où rediriger les créateurs vers Replit après qu&#39;ils ont autorisé l&#39;application. Elle doit correspondre exactement : les barres obliques finales, le protocole et le sous-domaine ont tous leur importance. Si vous ajoutez plusieurs URI de redirection, celui-ci doit être inclus.
  </Step>

  <Step title="Copier le Client ID et le Client Secret">
    Après avoir créé l&#39;application, le fournisseur affiche un **Client ID** et un **Client Secret**.

    * **Client ID** : un identifiant public pour votre application OAuth. Il peut être exposé sans risque dans les URL et le code côté client.
    * **Client Secret** : une valeur confidentielle qui prouve que la requête provient de votre application. Traitez-le comme un mot de passe : ne l&#39;ajoutez jamais à un dépôt et ne le partagez jamais publiquement. Replit le stocke de manière sécurisée pour vous.

    Certains fournisseurs n&#39;affichent le secret client qu&#39;une seule fois, lors de sa création. Copiez-le immédiatement et stockez-le dans un endroit sûr jusqu&#39;à ce que vous le colliez dans Replit.
  </Step>

  <Step title="Choisir vos scopes">
    Les **scopes** sont des autorisations qui définissent ce que votre application OAuth peut lire ou écrire au nom du créateur. Chaque fournisseur publie sa propre liste de scopes dans sa documentation API.

    Lorsque vous configurez le connecteur dans Replit, les scopes que vous saisissez doivent **correspondre exactement** (caractère par caractère, y compris les éventuels préfixes d&#39;URL) à ceux que vous avez enregistrés auprès du fournisseur. Causes fréquentes d&#39;erreurs de non-correspondance :

    * Préfixe d&#39;URL complet manquant (par exemple, `https://www.googleapis.com/auth/drive.file` au lieu de `drive.file`).
    * Espaces supplémentaires ou virgules finales.
    * Demande d&#39;un scope dans Replit qui n&#39;est pas activé dans l&#39;application du fournisseur.

    Commencez par les scopes minimaux dont vos créateurs ont besoin, puis ajoutez-en davantage si nécessaire : la plupart des fournisseurs vous permettent de mettre à jour les scopes sans recréer l&#39;application.
  </Step>

  <Step title="Configurer le connecteur dans Replit">
    Depuis la page **Connectors** de votre organisation, sélectionnez **Ajouter une nouvelle intégration**, choisissez le service, puis collez le **Client ID**, le **Client Secret** et les **scopes** du fournisseur. Sélectionnez **Configurer** pour enregistrer.
  </Step>
</Steps>

<Note>
  Si l&#39;authentification échoue après la configuration, vérifiez que l&#39;URL de redirection du fournisseur correspond exactement à `https://replit.com/connectors/oauth/callback` et que chaque scope saisi dans Replit est également autorisé dans l&#39;application du fournisseur.
</Note>

<div id="reconnecting-integrations">
  ## Reconnexion des intégrations
</div>

Si un service connecté cesse de fonctionner — par exemple, si votre session expire ou si les autorisations changent — Replit affiche une alerte de reconnexion dans le Project Editor. Sélectionnez cette alerte pour reconnecter l’intégration directement, sans quitter l’éditeur.
