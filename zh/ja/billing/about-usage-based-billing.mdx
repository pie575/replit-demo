发布按用量计费分为三类：

1. 出站数据传输
2. 自动扩缩计算单元
3. 请求

你可以在**设置**的**账户** → **账户使用量**中查看用量。系统会按月计费，或在累计费用超过月度额度时计费。Replit Core 和 Pro 用户的这些资源均设有月度上限。

如果需要超过月度订阅上限的额外额度，可以在计费页面购买额度包。有关额度包的更多信息，请参阅[管理支出](/zh/ja/billing/managing-spend)。

<div id="section">
  # 发布
</div>

<div id="1">
  ## 1. 发布出站数据传输
</div>

此类用量按字节计费，Replit Core 和 Pro 用户每月有用量上限。只有出站 (发送) 数据会计入此上限，超出上限后可能会产生额外费用。相比之下，入站 (接收) 数据始终免费。

| 订阅          | 上限                                                  |
| ----------- | --------------------------------------------------- |
| Replit Core | 100 GiB                                             |
| Replit Pro  | 请参阅 [Replit Pro 定价](https://www.replit.com/pricing) |

该上限适用于[静态](/zh/ja/features/publishing/deployment-types#static)、[自动扩缩容](/zh/ja/features/publishing/deployment-types#autoscale)、[预留 VM](/zh/ja/features/publishing/deployment-types#reserved-vm)和[定时](/zh/ja/features/publishing/deployment-types#scheduled)部署。

有关当前出站数据传输的价格，请参阅[定价页面](https://www.replit.com/pricing)。

***

<div id="2">
  ## 2. 计算单元
</div>

自动扩缩容部署按计算单元计费，计算单元综合考虑一段时间内的 CPU 和 RAM 使用情况。

超出额度的用量按计算单元计费。计费粒度精确到单个计算单元。有关计算单元的当前价格，请参阅[定价页面](https://www.replit.com/pricing)。

以下是自动扩缩容部署的 RAM 秒和 CPU 秒如何转换为计算单元：

| 资源      | 计算单元  |
| ------- | ----- |
| 1 RAM 秒 | 2 单元  |
| 1 CPU 秒 | 18 单元 |

静态部署不会消耗计算单元。仅对超出[指定额度](#)的出站数据传输计费。

[详细了解自动扩缩容部署](/zh/ja/features/publishing/deployment-types#autoscale)。

***

<div id="3">
  ## 3. 请求
</div>

自动扩缩容部署也会考虑请求数量。

有关当前请求的价格，请参阅[定价页面](https://www.replit.com/pricing)。

<div id="section-2">
  # 数据库
</div>

Replit 仅对[生产数据库](/zh/ja/features/data-and-storage/development-and-production)的使用量收费——开发数据库始终免费，且所有 Replit 应用均包含开发数据库。有关开发数据库的更多信息，请参阅[开发数据库](/zh/ja/features/data-and-storage/sql-database)。

Replit PostgreSQL 是全托管无服务器数据库，提供省心的高可用性，无需维护。生产数据库按实际使用量计费，可显著节省成本。

生产 PostgreSQL 数据库按以下两项使用量指标计费：

* **[计算时间](#compute-time)**：每小时消耗的计算资源量。
* **[数据存储](#data-storage)**：存储数据的总量 (包括历史数据) 。

您可以在 **设置** → **账户** → **账户使用量** 中查看当前的资源使用情况，其中包括生产数据库使用量。

<div id="section-3">
  ## 计算时间
</div>

计算时间取决于数据库在指定计费周期内处于活跃状态的小时数。数据库收到请求时，以及最后一次请求后的额外 5 分钟内，均视为活跃状态。如果数据库连续 5 分钟处于空闲状态，则会被暂停并进入非活跃状态。

<div id="section-4">
  ## 数据存储
</div>

数据存储是指账户中所有数据库存储的数据总量，以吉字节 (GiB) 为单位计量。存储量按每月达到的最大存储量计算。每个 PostgreSQL 数据库即使不包含任何数据，也会占用 33 MB 的存储空间。这是 Postgres 服务器的默认存储占用。

<Note>每个生产数据库的存储总上限为 10 吉字节 (GiB) 。每个 Replit 应用的开发数据库均包含 20 GiB 的免费存储空间。</Note>
