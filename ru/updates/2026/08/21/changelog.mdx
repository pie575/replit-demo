<div id="work-in-free-mode">
  ### Работа в Free Mode
</div>

Используйте Free Mode, чтобы общаться, прорабатывать идеи, создавать и разрабатывать проекты без расхода кредитов Power Mode или Max Mode. Free Mode использует Auto для выбора модели, а его лимиты зависят от вашего тарифа. Откройте **Settings** &gt; **Usage**, чтобы узнать остаток доступного лимита и время его сброса.

<div id="automate-recurring-work-with-routines">
  ### Автоматизируйте регулярные задачи с помощью Routines
</div>

Настройте Replit на повторное выполнение задач в Conversation. Каждый результат возвращается в ту же Conversation, где вы можете просмотреть его и продолжить работу. Routines выполняются в Power Mode или Max Mode и требуют бюджета для каждого запуска.

<div id="steer-agent-while-working">
  ### Направляйте Agent во время работы
</div>

Отправьте дополнительное сообщение во время работы Agent, чтобы добавить новый контекст в активный ход. Steer — режим по умолчанию в Conversation и Project; изменить режим для каждого из них на Queue можно в **Settings** &gt; **Personalization**. Нажмите `Cmd+Enter` на Mac или `Ctrl+Enter` на Windows и Linux, чтобы использовать противоположный режим для одного сообщения.

</Frame>

Подробнее об [управлении сообщениями и постановке их в очередь](/ru/features/agent/steer-and-queue-messages).

<div id="control-agent-models-across-workspaces">
  ### Управление моделями Agent в Workspace
</div>

Администраторы аккаунтов Enterprise могут задать политику для каждого провайдера моделей, а затем выбрать модели, доступные в отдельных Workspace. Используйте **Включить все**, **Включить выбранные** или **Отключено** в соответствии с политикой вашей организации.

<div id="run-black-box-pen-tests">
  ### Запуск тестов на проникновение методом «чёрного ящика»
</div>

Запустите сканирование безопасности Level 3, которое объединяет три проверки: бесплатные проверки зависимостей и пакетов, статический анализ исходного кода с помощью Agent и внешний тест работающего Preview методом «чёрного ящика». Replit выполняет проверку исходного кода и внешний тест параллельно.
