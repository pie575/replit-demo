Project geography는 Project의 publishing geography입니다. 게시할 때 선택하며, 게시된 Project의 컴퓨팅과 스토리지가 호스팅되는 위치를 결정합니다.

<Note>
  Project geography와 [Workspace
  geography](/ko/features/collaboration/workspace-geography)는 서로 다를 수 있습니다. Workspace
  geography는 Workspace에서 새로 만드는 Project의 개발 리소스가 호스팅되는 위치를 결정합니다.
</Note>

<div id="what-project-geography-controls">
  ## Project geography로 제어되는 항목
</div>

Replit은 기본적으로 사용자와 가장 가까운 geography를 추천합니다. 이렇게 하면 앱 방문자의 지연 시간을 줄이고 data residency 요건을 충족하는 데 도움이 됩니다.

geography를 선택하면 컴퓨팅, database, Object Storage 등 Project의 게시된 artifacts가 모두 자동으로 동일한 리전에 함께 배치됩니다. 또한 geography별 프록시가 앱 방문자의 지연 시간을 줄이는 데 도움이 됩니다.

<div id="select-a-project-geography">
  ## Project geography 선택
</div>

권장 geography 대신 다른 geography를 사용하려면 다음 단계를 따르세요.

<Steps>
  <Step>Replit Project에서 **Publishing** 도구를 엽니다.</Step>
  <Step>**Advanced** 설정을 펼칩니다.</Step>
  <Step>**Geography** 드롭다운에서 원하는 geography를 선택합니다.</Step>

  <Step>
    **Publish**를 선택해 선택한 geography에 Project를 게시합니다.
  </Step>
</Steps>

<div id="enforce-a-geography-on-published-projects">
  ## 게시된 Projects에 geography 적용하기
</div>

Enterprise 관리자는 조직 내 모든 Projects에 publishing geography를 강제로 적용할 수 있습니다. 정책이 설정되면 조직의 builders는 지정된 geography로 게시하게 됩니다. 이 정책은 아직 게시되지 않은 Projects에만 적용되며, 이미 다른 geography로 게시된 Projects는 영향을 받지 않습니다.

<Note>
  publishing geography 적용은 Enterprise 기능입니다. Enterprise plans에 대한
  자세한 내용은 [Pricing](https://replit.com/pricing/)을 참조하세요.
</Note>

<Steps>
  <Step>**Account settings**로 이동합니다.</Step>
  <Step>**Advanced**를 선택합니다.</Step>

  <Step>
    처음 게시되는 모든 Projects가 사용할 geography를 선택합니다.
  </Step>
</Steps>

<div id="availability-and-limits">
  ## 사용 가능 여부 및 제한
</div>

| geography  | Project 게시 선택 |
| :--------- | :-------------------- |
| **북미**     | 예                     |
| **유럽(EU)** | 예                     |
| **아시아**    | 예                     |
| **남미**     | 예                     |
| **호주**     | 예                     |

<Note>
  Project geography 선택은 Core, Pro, Enterprise 고객만 사용할 수 있습니다. 무료 고객의 경우 기본적으로 북미에 게시됩니다.
</Note>

Project geography를 선택하기 전에 다음 제한 사항을 확인하세요.

* **게시 후에는 geography를 변경할 수 없습니다.** Project를 특정 geography에 게시하면 해당 선택은 영구적으로 유지됩니다. 이미 게시된 Project는 다른 geography로 이전할 수 없습니다.
* **Development 위치와 게시된 위치가 다를 수 있습니다.** Object Storage와 같은 리소스는 게시 전에 생성될 수 있어 Project geography와 일치하지 않을 수 있습니다.
