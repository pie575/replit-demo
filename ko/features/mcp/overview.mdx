Replit Agent는 AI integrations를 위한 개방형 표준인 [Model Context Protocol (MCP)](https://modelcontextprotocol.io)을 통해 외부 도구 및 데이터 소스에 연결합니다. 아래 서버는 모두 클릭 한 번으로 설치되며, 설치 후에는 Agent가 해당 도구를 자동으로 불러와 필요한 상황에 사용합니다.

개념이 궁금하다면 [Model Context Protocol](/ko/learn/model-context-protocol)을 참고하세요. 실습 가이드는 [Connect via MCP](/ko/build/connect-via-mcp)를 참고하세요. 목록에 없는 서버를 연결하려면 [Add a custom MCP server](/ko/build/connect-via-mcp#add-a-custom-mcp-server)를 참고하세요.

<Info>
  서버를 설치하려면 **Add to Replit**을 선택하세요. Project Editor에서 연결을 승인하라는 메시지가 표시됩니다.
</Info>

<div id="security-protections">
  ## 보안 보호 기능
</div>

모든 MCP 트래픽은 Replit의 Security scanner를 거칩니다. 스캐너는 도구 정의와 실행 계획을 평가해 의심스럽거나 안전하지 않은 도구를 실행 전에 차단합니다. 도구가 거부되면 Agent가 그 사실을 알려줍니다.

<div id="authentication-options">
  ## 인증 옵션
</div>

* **OAuth 동적 클라이언트 등록** — 서버가 OAuth DCR을 지원하면 Replit이 이를 자동으로 감지해 클라이언트를 등록해 줍니다. 기본 목록에 포함된 서버 대부분이 이 방식을 사용합니다.
* **사용자 지정 헤더** — 헤더 이름/값 쌍을 하나 이상 정의합니다(예: `X-API-Key`). Replit은 모든 MCP 요청에 이 헤더를 포함하므로 서버에서 호출자를 검증할 수 있습니다. 정적 토큰으로 인증하는 사용자 지정 서버를 추가할 때 사용하세요.

<div id="share-your-own-install-link">
  ## 나만의 설치 링크 공유하기
</div>

설치 링크를 사용하면 클릭 한 번으로 MCP 서버를 Replit에 추가할 수 있습니다. [Connect via MCP](/ko/build/connect-via-mcp#share-an-install-link) 페이지의 양식으로 생성하거나 직접 만들 수도 있습니다. JSON 페이로드를 base64로 인코딩한 뒤 `https://replit.com/integrations?mcp=` 뒤에 붙이면 됩니다.

```json theme={null}
{
  "displayName": "My MCP Server",
  "baseUrl": "https://example.com/mcp",
  "headers": [{ "key": "Authorization", "value": "Bearer your-token" }]
}
```

* **displayName** — 설치 시 표시되는 이름
* **baseUrl** — MCP 서버의 HTTPS 엔드포인트
* **headers** — 선택 사항인 인증 헤더
