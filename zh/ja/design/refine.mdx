探索要广，优化要深。当框架接近你想要的效果时，可通过两种适合不同工作方式的工具进行精细打磨。

* 用自己的话与Agent Chat — 无论是整个框架还是单个元素都可以
* 在可视化编辑器中直接调整元素 — 简单编辑会立即生效，且不消耗积分

<div id="section">
  ## Chat
</div>

给 Agent 下达指令时，可以把它当成在向评审中的设计师做简报。选中一个框架，在主 Chat 中描述你想要的改动 (*“配色再暖一些”*、*“主视觉不够抓人”*) ，或者在工具栏中选择 **Chat** 工具并点击某个元素，把这条消息的范围只锁定在该部分。

<Frame caption="选中的框架会以标签的形式附加到主 Chat 中。">
  <img src="/assets/mirror/chatbox-9baff03cb443.png" alt="画布上被选中的设计框架（Configurator First），以及左侧的主 Chat 面板。消息框中显示“Describe what you want to design…”，并附有 Configurator First 标签" width="2000" height="1250" data-path="images/design/replit-design/chatbox.png" />
</Frame>

关于这两种入口，请参阅 [Chat](/zh/ja/design/chat-about-your-design)。

<div id="section-2">
  ## 可视化编辑器
</div>

如果你已经清楚自己想要什么，就无需再写提示词。在工具栏中选择 **Edit** 工具，然后点击任意元素，即可打开可视化编辑器，查看该元素的可编辑属性 (内容、布局、颜色、边框等) 。修改文本、选取颜色、微调间距等简单编辑会即时同步到源代码，且不消耗积分。

<Frame caption="启用 Edit 工具并选中元素后的状态，以及展示其可编辑属性的可视化编辑器。">
  <img src="/assets/mirror/visual-editor-edit-tool-71d03803471f.png" alt="在超跑配置器 frame 中启用 Edit 工具并选中了某个元素。右侧显示可视化编辑器面板，包含 Layout、Color、Border 各个部分，以及 Discard 和 Save edits 按钮" width="2000" height="1250" data-path="images/replitai/visual-editor-edit-tool.png" />
</Frame>

有关控件的完整参考，请查阅 [可视化编辑器](/zh/ja/design/visual-editor)。

<div id="section-3">
  ## 应该使用哪个
</div>

| 想要完成的操作                 | 使用的工具  |
| ----------------------- | ------ |
| 描述想要的结果，让Agent处理细节      | Chat     |
| 将特定元素的文案、颜色、间距或图片更改为已知值 | 可视化编辑器 |
| 重做某个部分的结构或行为            | Chat     |
| 不消耗积分即可快速微调             | 可视化编辑器 |

这两者可以自然地结合使用。先通过Chat确定方向，再在可视化编辑器中边点击边完善细节。
