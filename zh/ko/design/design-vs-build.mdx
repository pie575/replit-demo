每个 Replit 项目的顶部都有两个并列的入口：**Design** 和 **Build**。Design 用于设计软件的外观，Build 则让 Agent 将其构建成功能完整的应用。两个入口打开的是同一个项目，因此你的设计不会被困在设计工具中。

<div id="design">
  ## 什么是 Design？
</div>

[Design](/zh/ko/design/what-is-replit-design) 提供了一个画布，你可以通过提示词生成设计画框、探索不同变体，并在编写代码前完善最喜欢的方案。

Design 非常适合：

* **快速验证想法**：在构建功能前直观呈现应用设计
* **打造精美网站**：着陆页、作品集、餐厅菜单、活动页面
* **细致调整设计**：即时调整颜色、布局和内容

<Info>
  Design 设计稿看起来和用起来都像真实页面，但尚未存储数据或连接外部服务。对整体效果满意后，只需点击一下，即可将设计构建为完整应用。以下步骤将向你展示具体方法。
</Info>

<div id="build">
  ## 什么是 Build？
</div>

Build 可将你的创意变成功能完善的应用，让应用能够存储数据、支持用户登录并连接其他服务。

当你的应用需要以下功能时，请使用 Build：

* **用户账户**：让用户创建账户并登录
* **数据存储**：存储订单、消息和用户偏好等数据
* **连接其他服务**：处理付款、发送电子邮件，以及获取其他应用的数据
* **复杂功能**：运营在线商店、管理预约和提供仪表板

<div id="section">
  ## 结合使用两者
</div>

Design 和 Build 可在同一项目中协同使用，无需二选一。先从外观入手，再将其完善为功能完整的应用。

<Steps>
  <Step title="从 Design 开始">
    从 Design 开始，快速将想法可视化。重点关注应用的外观和使用体验，包括布局、颜色、按钮和用户体验。
  </Step>

  <Step title="完善并迭代">
    根据[建议](/zh/ko/design/explore-suggestions)探索所选画框的新方向，或选择 **Edit** 工具并点击元素，在 [Visual Editor](/zh/ko/design/visual-editor) 中进行调整。你还可以[与 Agent 聊天](/zh/ko/design/chat-about-your-design)，描述想要进行的更改。

    <Frame>
      <img src="/assets/mirror/ambient-iq-0989ea31bce7.png" alt="选中的 Website 画框展示 APEX X1 超级跑车主视觉，旁边的 Suggested next steps 面板提供 Explore different approaches、Try different layouts、Explore different vibes、Surprise me 等建议标签" width="2000" height="1254" data-path="images/design/replit-design/ambient-iq.png" />
    </Frame>
  </Step>

  <Step title="构建设计">
    当你对设计感到满意并准备添加实际功能时，请在画框中选择 **Build…**。你可以创建新的工件，也可以将设计应用到现有工件。Agent 在添加数据存储、用户账户处理和服务连接功能时，会保留现有设计不变。

    <Frame>
      <img src="/assets/mirror/canvas-build-menu-f06b8b8b455f.png" alt="从选中的 Design 画框（APEX X1 Exact Replica）打开的 Build 菜单，在“Build or apply your designs”标题下方显示用于创建新工件的“Build this design”，以及列出项目中 APEX X1 Design System 和 Scroll Hero 网站的“Apply to an existing creation”" width="2000" height="1153" data-path="images/replitai/canvas-build-menu.png" />
    </Frame>

    <Note>
      当你尝试为设计稿添加数据库或高级功能时，Agent 会建议进行转换。
    </Note>
  </Step>

  <Step title="发布并分享">
    应用构建完成后，请将其发布，让任何人都能在线访问。Replit 会处理所有技术基础设施，确保你的应用能稳定地为用户提供服务。
  </Step>
</Steps>

<div id="section-2">
  ## 何时该从哪个开始？
</div>

<CardGroup cols={2}>
  <Card title="从 Design 开始" icon="paintbrush">
    * 当外观是最难的部分时
    * 当你想快速验证想法时
    * 当你想探索并比较多个方向时
    * 当速度最重要时
  </Card>

  <Card title="从 Build 开始" icon="cube">
    * 当功能实现是最难的部分时
    * 当应用从一开始就需要存储数据时
    * 当用户需要登录时
    * 当需要连接其他服务时
  </Card>
</CardGroup>

<Tip>
  **不确定该选哪个？** 从 Design 开始。它更快，而且之后随时都可以将设计构建为完整的应用。你的工作不会白费，构建时可以直接延续。反过来也一样：你可以先在 Build 中让应用运行起来，再在 Design 中调整样式。
</Tip>

<div id="section-3">
  ## 主要区别
</div>

| 功能       | Design (设计稿)  | Build (应用)     |
| -------- | ------------ | -------------- |
| **速度**   | 几分钟          | 构建完整应用约需 10 分钟 |
| **数据存储** | 仅视觉呈现 (不保存)  | 实际存储和加载数据      |
| **用户账户** | 仅展示登录效果      | 实际登录功能         |
| **服务连接** | 不可用          | 支付、电子邮件、外部数据   |
