<div id="what-is-a-project">
  ## project란 무엇인가요?
</div>

project는 Replit에서 만드는 모든 것을 담는 컨테이너입니다. 코드와 데이터는 물론, 여러분이 만드는 모든 아티팩트 — 웹 앱, 모바일 앱, 슬라이드 덱, data dashboards, 동영상 — 를 담습니다. Agent에게 원하는 것을 말하면 Agent가 project를 만들고 그 안에 아티팩트를 생성합니다.

project는 책상 위의 작업 공간이라고 생각하면 됩니다. 모든 것이 한곳에 모여 있고 같은 정보를 공유할 수 있지만, 각 요소가 맡은 역할은 서로 다릅니다.

예를 들어 Agent에게 운동 기록 앱을 만들어 달라고 요청하면, 모바일 앱 아티팩트와 함께 앱 구동에 필요한 backend, database, 스토리지까지 갖춘 project를 생성합니다.

<ArtifactGrid />

핵심 개념:

* **Project**: 코드, 데이터, 모든 아티팩트 등 모든 것을 담는 컨테이너
* **Artifact**: project 안에서 게시할 수 있는 결과물(웹 앱, 슬라이드 덱, 동영상 등)
* **리소스**: 모든 아티팩트는 backend, database, 파일 스토리지를 자동으로 사용할 수 있으며 별도의 설정이 필요 없습니다

<Note>
  Publishing은 project 전체를 한 번에 라이브로 전환합니다. 모든 아티팩트가 함께
  게시되므로 항상 서로 동기화된 상태를 유지합니다.
</Note>

하나의 project에 여러 아티팩트를 담을 수 있습니다. 예를 들어 고객용 웹 앱, 팀용 모바일 앱, 투자자용 슬라이드 덱을 모두 같은 project에서 만들 수 있습니다. 같은 project 안에 있는 아티팩트끼리는 데이터와 backend 로직을 자동으로 공유합니다. 자세한 내용은 [Artifacts](/ko/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project)를 참고하세요.

<div id="managing-your-projects">
  ## project 관리
</div>

Projects page에는 직접 만들었거나 초대받은 모든 project가 표시됩니다. 최근 작업을 바로 이어서 하거나, project가 많은 workspace에서 원하는 project를 찾는 가장 빠른 방법입니다.

<div id="see-at-a-glance-whats-inside-each-project">
  ### 각 project에 무엇이 들어 있는지 한눈에 확인하기
</div>

모든 project 카드에는 해당 project에 포함된 웹 앱, 모바일 앱, 슬라이드 덱, 데이터 시각화, 애니메이션 등 아티팩트를 나타내는 작은 icon이 표시됩니다. icon에 마우스를 올리면 해당 아티팩트의 스크린샷을 카드에서 바로 미리 볼 수 있어, project를 열지 않고도 서로 구분할 수 있습니다.

<div id="filter-by-artifact">
  ### 아티팩트별 필터링
</div>

Projects 페이지 상단의 **Build type** 드롭다운을 사용해 목록을 아티팩트 기준으로 필터링할 수 있습니다. 원하는 항목을 선택하면 해당 종류의 아티팩트가 포함된 project만 표시됩니다.

* **Web** — 웹 앱이 포함된 project
* **Mobile** — 모바일 앱이 포함된 project
* **Data** — 데이터 시각화이 포함된 project
* **Slides** — 슬라이드 덱이 포함된 project
* **Design** — Design 모드의 project
* **3D Game**, **Agent &amp; Automation** 등

필터를 해제하려면 **Any build type**을 선택하세요.

<div id="sort-by-last-opened">
  ### 마지막 열람순 정렬
</div>

Projects page는 기본적으로 **내가 마지막으로 연 순서**로 정렬되며, 가장 최근에 작업한 projects가 맨 위에 표시됩니다. 이 정렬 방식은 team workspaces에서 특히 유용합니다. 그렇지 않으면 다른 members의 최근 편집 때문에 현재 작업 중인 항목이 아래로 밀려나기 때문입니다.

다른 열 머리글(예: **Last updated** 또는 **Name**)을 선택해 정렬 기준을 변경할 수 있습니다.

<div id="pin-the-projects-you-use-most">
  ### 가장 자주 사용하는 project 고정하기
</div>

project를 고정하면 목록 맨 위에 계속 표시됩니다. 고정은 **나에게만 적용**되므로, 팀 workspace에서 project를 고정해도 다른 멤버에게 보이는 화면은 달라지지 않습니다.

project를 고정하려면 project 카드의 오버플로 메뉴(점 세 개)를 열고 **Pin**을 선택하세요. 고정을 해제하려면 같은 메뉴에서 **Unpin**을 선택하세요.
