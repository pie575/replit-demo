Replit propose plusieurs façons d’installer et de gérer les paquets de votre application Replit. Vous pouvez installer des paquets à l’aide du [Shell](/fr/pt/core-concepts/project-editor/editor-and-tools/shell), demander à [Agent](/fr/pt/core-concepts/agent/) de s’en charger ou laisser Replit détecter et installer automatiquement les dépendances manquantes lorsque vous exécutez votre application Replit.

<div id="instalar-pacotes-usando-o-shell">
  ## Installer des paquets avec le Shell
</div>

Ouvrez l’outil **Shell** dans l’Éditeur de projet et exécutez la commande correspondant au gestionnaire de paquets de votre langage :

<CodeGroup>
  ```bash Node.js (npm) theme={null}
  npm install <package-name>
  ```

  ```bash Node.js (pnpm) theme={null}
  pnpm add <package-name>
  ```

  ```bash Python (poetry) theme={null}
  poetry add <package-name>
  ```

  ```bash Python (pip) theme={null}
  pip install <package-name>
  ```

  ```bash Ruby theme={null}
  bundle add <gem-name>
  ```
</CodeGroup>

Vous pouvez également utiliser le [gestionnaire universel de paquets de Replit (UPM)](https://github.com/replit/upm/) pour installer des paquets dans les langages pris en charge :

```bash theme={null}
upm add <package-name>
```

Pour installer une version spécifique :

```bash theme={null}
upm add 'flask==2.3.3'
```

Pour connaître tous les langages et gestionnaires de paquets pris en charge, consultez [UPM : Langages pris en charge](https://github.com/replit/upm/#supported-languages).

<div id="instalar-pacotes-usando-o-agent">
  ## Installer des paquets avec Agent
</div>

Vous pouvez demander à [Agent](/fr/pt/core-concepts/agent/) d’installer des paquets directement dans le chat. Par exemple :

* « Installe le paquet axios »
* « Ajoute Flask et SQLAlchemy à mon projet »
* « Configure TailwindCSS »

Agent installe le paquet à l’aide du gestionnaire de paquets adapté à votre projet et met à jour les fichiers de configuration concernés.

<div id="deteco-automtica-de-importaes">
  ## Détection automatique des importations
</div>

Replit analyse automatiquement votre code à la recherche de dépendances manquantes chaque fois que vous sélectionnez **Run**. Si votre code importe un paquet qui n&#39;est pas encore installé, Replit le détecte et installe automatiquement la dernière version.

Par exemple, si vous ajoutez `import flask` à `main.py`, la prochaine fois que vous sélectionnerez **Run**, la **Console** affichera un message indiquant que **Flask** est en cours d&#39;installation.

<Note>
  Vous pouvez configurer la détection automatique des importations dans le fichier [.replit](/fr/pt/core-concepts/project-editor/app-setup/configuration#replit-file) à l&#39;aide du paramètre `packager.features.guessImports`.
</Note>

<div id="substituir-a-deteco-automtica">
  ### Remplacer la détection automatique
</div>

Si le mauvais paquet a été détecté ou si vous avez besoin d’une version spécifique, exécutez la commande d’installation appropriée dans le Shell. Par exemple :

```bash theme={null}
upm add 'flask==2.3.3'
```

<div id="gerenciadores-de-pacotes-python">
  ## Gestionnaires de paquets Python
</div>

Lorsque vous créez une application Replit en Python, le gestionnaire de paquets utilisé par défaut est **poetry**. Cela signifie que `pip install` ne gère pas vos dépendances. Utilisez plutôt `poetry add <package>` ou `upm add <package>` dans le Shell.

<div id="alternar-do-poetry-para-o-pip">
  ### Passer de poetry à pip
</div>

Si vous préférez utiliser `pip`, procédez comme suit :

<Steps>
  <Step>
    Ouvrez le Shell et exécutez la commande suivante :

    Supprimez le fichier de verrouillage afin que l&#39;infrastructure de gestion des paquets passe à pip :

    ```bash theme={null}
    rm poetry.lock
    ```
  </Step>

  <Step title="Déplacez vos dépendances">
    Transférez vos dépendances de la section `[tool.poetry.dependencies]` de `pyproject.toml` vers `requirements.txt`. Par exemple, `flask = "^3.0.2"` devient `flask>=3.0.2,<4`.
  </Step>

  <Step title="Nettoyez le pyproject.toml">
    Supprimez les sections `[tool.poetry...]` de `pyproject.toml`.
  </Step>
</Steps>

Après ces modifications, l&#39;infrastructure de gestion des paquets utilisera `pip` pour toutes les opérations ultérieures, et la détection automatique des importations continuera de fonctionner comme prévu.

<div id="dependncias-de-sistema-com-nix">
  ## Dépendances système avec Nix
</div>

Replit prend en charge tous les langages de programmation grâce à son intégration avec [Nix](https://nixos.org/). Si vous avez besoin de dépendances système en plus des paquets de langage standard, vous pouvez les ajouter à votre fichier [replit.nix](/fr/pt/core-concepts/project-editor/app-setup/configuration#replit-nix-file).

<div id="pacotes-nix">
  ### Paquets Nix
</div>

Ajoutez des dépendances système en modifiant directement `replit.nix`. Vous pouvez rechercher les paquets disponibles sur [search.nixos.org](https://search.nixos.org/packages).

<div id="mdulos">
  ### Modules
</div>

Les modules regroupent la prise en charge des langages de programmation, des formateurs et des empaqueteurs. Ils constituent la base de votre application Replit. Si vous créez une application Replit à partir d’un template ou d’un dépôt GitHub, Replit installe automatiquement les modules nécessaires.

Vous pouvez personnaliser les modules et d’autres paramètres de Nix à l’aide du fichier [.replit](/fr/pt/core-concepts/project-editor/app-setup/configuration#replit-file).

<div id="configurao-do-empacotador">
  ## Configuration du gestionnaire de paquets
</div>

Vous pouvez ajuster le comportement du gestionnaire de paquets dans votre fichier [.replit](/fr/pt/core-concepts/project-editor/app-setup/configuration#replit-file) :

| Configuration                         | Description                                                                            | Par défaut              |
| ------------------------------------- | -------------------------------------------------------------------------------------- | ----------------------- |
| `packager.language`                   | Langage utilisé pour les opérations sur les paquets                                    | Détecté automatiquement |
| `packager.features.guessImports`      | Détecter et installer automatiquement les paquets manquants lors de l’exécution de Run | `true`                  |
| `packager.features.packageSearch`     | Activer la recherche de paquets                                                        | `true`                  |
| `packager.features.enabledForHosting` | Exiger l’installation des paquets lors de l’hébergement                                | `false`                 |
| `packager.afterInstall`               | Commande à exécuter après l’installation d’un paquet                                   | —                       |
| `packager.ignoredPaths`               | Chemins à ignorer lors de la détection des importations                                | `[]`                    |
| `packager.ignoredPackages`            | Paquets à exclure de la détection automatique                                          | `[]`                    |
