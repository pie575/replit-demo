### Password manager keyboard navigation

<Frame>
  <img src="https://mintcdn.com/replit/ft3FvKqPm2QAQR_0/images/changelog/2026-02-27/image_8bb24520b5d6.png?fit=max&auto=format&n=ft3FvKqPm2QAQR_0&q=85&s=9e598654562edc1a1f1d1cc8ade0ff4f" alt="Password manager navigation dropdown showing keyboard navigation between email field and saved accounts" width="1229" height="1150" data-path="images/changelog/2026-02-27/image_8bb24520b5d6.png" />
</Frame>

You can now log into Replit via your password manager extension using only the keyboard. Previously, pressing the down arrow to navigate to the email field would refocus on it, requiring you to use a mouse.

### Agent performance improvements

Agent performance has been improved with new optimizations and an improved architecture.

### System theme support

<Frame>
  <img src="https://mintcdn.com/replit/ft3FvKqPm2QAQR_0/images/changelog/2026-02-27/image_37ce8526b860.png?fit=max&auto=format&n=ft3FvKqPm2QAQR_0&q=85&s=41bc4e83a5336ada7870a2ae28e77988" alt="System theme settings menu showing Light, Dark, and System theme options" width="1120" height="880" data-path="images/changelog/2026-02-27/image_37ce8526b860.png" />
</Frame>

Replit now follows your system theme preference, or you can manually select light or dark mode from the quick menu, the Settings Pane, or the Workspace command palette.

* Full i18n support so browser translation works in other languages
* Customize position, background color, and icon on widget
