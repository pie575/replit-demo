Создайте интерактивный дашборд с ключевыми метриками, графиками и фильтрами на основе API. Она обновляется
автоматически, поддерживает экспорт и отображает только то, что действительно есть в данных.
Всё, что должно сохраняться, храните в Replit Database.

<div id="best-for">
  ## Кому подойдёт
</div>

* Продакт-менеджерам, которым нужен дашборд, который люди смогут изучить сами, а не скриншот.
* Руководителям операционных и аналитических команд, которым нужен закрытый дашборд, который сам обновляется через API.

<div id="before-you-start">
  ## Прежде чем начать
</div>

Определите, какое решение должен поддерживать дашборд. Подготовьте URL API или используйте
указанные ниже конечные точки DummyJSON.

<Info>
  Для тестирования можно использовать эти бесплатные конечные точки API DummyJSON:

  * Заказы: `https://dummyjson.com/carts?limit=0`
  * Клиенты: `https://dummyjson.com/users?limit=0`
  * Каталог: `https://dummyjson.com/products?limit=0`
  * Категории: `https://dummyjson.com/products/categories`
</Info>

<div id="what-to-expect">
  ## Чего ожидать
</div>

Agent загрузит данные, выберет сводные показатели и графики, а затем добавит фильтры. Сверьте хотя бы
одно число с исходными данными. Если вы использовали DummyJSON, выберите заказ и откройте
`https://dummyjson.com/carts/{id}`, чтобы убедиться, что итоговые значения совпадают. Переключите фильтр и убедитесь,
что обновились все карточки и графики. Выполните экспорт и сверьте одну строку с API.

<div id="troubleshooting">
  ## Устранение неполадок
</div>

* **API недоступен или структура данных выглядит неверно:** проверьте URL и убедитесь, что ответ содержит нужные поля. Для быстрой проверки используйте конечные точки DummyJSON, приведённые выше.
* **Числа отличаются от ожидаемых:** попросите Agent показать запрос или преобразование, а затем сверьте хотя бы одно число с источником.
* **Фильтры не обновляют графики:** попросите Agent связать каждый фильтр и с карточками сводки, и с данными графиков. Если дашборд работает медленно, кэшируйте ответы API или уменьшите количество записей, загружаемых при запуске.
