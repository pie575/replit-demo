<div id="section">
  ## Что входит
</div>

Тариф Starter даёт всё необходимое, чтобы начать создавать проекты в Replit. Создавайте App и публикуйте свой первый проект — совершенно бесплатно.

<div id="agent">
  ### Ежедневные кредиты для работы с Agent
</div>

Пользователи тарифа Starter получают ежедневные кредиты на работу с Agent в рамках месячного лимита. Кредиты обновляются каждый день, предоставляя новый лимит для работы с Agent.

<div id="section-2">
  ### Ежемесячные кредиты на использование облака
</div>

Вы также получаете ежемесячные кредиты, которые можно потратить на:

* [базы данных (продакшен)](/ru/ko/features/data-and-storage/development-and-production)
* [объектное хранилище](/ru/ko/features/data-and-storage/object-storage)
* [публикацию (Autoscale, статические сайты)](/ru/ko/learn/projects-and-artifacts/replit-deployments)

Кредиты обновляются каждый месяц.

<div id="lite">
  ### Lite-сборка
</div>

Быстрый и сфокусированный процесс разработки: с помощью Agent вы получаете доступ к [Lite-сборке](/ru/ko/features/agent/agent-modes) для оперативных правок и точечных изменений с чётко поставленной целью.

<div id="1">
  ### 1 бесплатно опубликованное App
</div>

Независимо от того, что вы используете — Lite-сборку или Design Canvas, — вам доступно {FreeDeployments} бесплатно опубликованных App. Срок действия таких ссылок на публикацию истекает автоматически через 30 дней.

На опубликованных App отображается бейдж «Made with Replit» с вашей уникальной реферальной ссылкой. Если другой пользователь зарегистрируется по ссылке из этого бейджа, вы получите реферальные кредиты после того, как он перейдёт на платный тариф.

<div id="section-3">
  ## Ограничения
</div>

Следующие функции доступны только после перехода на план Core:

<div id="section-4">
  ### Полная сборка
</div>

[Полная сборка](/ru/ko/features/agent/overview/) позволяет Agent работать самостоятельно — с расширенными правами и большей автономией. Разработчикам на тарифе Starter доступна только [Lite-сборка](/ru/ko/features/agent/agent-modes). Для полной сборки требуется Core или Pro.

<div id="section-5">
  ### Преобразование дизайна в артефакт
</div>

Чтобы преобразовать дизайн из Design Canvas в полноценный артефакт, требуется тариф Core. Разработчики на тарифе Starter могут создавать и деплоить дизайны, но для преобразования в артефакт с серверной частью нужно перейти на более высокий тариф. Если вы хотите создать App с серверной частью, попробуйте начать со [сборки Lite](/ru/ko/features/agent/agent-modes).

<div id="3">
  ### Сторонние коннекторы
</div>

Для внешних коннекторов требуется план Core. Сюда входят интеграции с Google, Stripe и другими сторонними API (см. [подробнее](https://docs.replit.com/features/integrations/overview#connectors)).

<div id="replit-ai-integrations">
  ### Интеграции Replit AI
</div>

Для [интеграций Replit AI](/ru/ko/features/integrations/replit-ai-integrations) требуется Core.

<div id="made-with-replit">
  ### Удаление бейджа «Made with Replit»
</div>

Чтобы убрать бейдж «Made with Replit» из опубликованного App, требуется Core. У пользователей тарифа Starter бейдж отображается в деплое.

<div id="section-6">
  ### Дополнительные опубликованные App
</div>

Пользователям тарифа Starter доступно {FreeDeployments} бесплатных опубликованных App. Для публикации App сверх этого лимита требуется Core или Pro.

<div id="plan-mode">
  ### Режим Plan
</div>

Для работы в режиме Plan требуется Core. Режим Plan позволяет обдумывать идеи, планировать задачи и работать вместе с Replit Agent, не изменяя код или данные вашего App.

<div id="section-7">
  ### Все типы артефактов
</div>

Для создания артефактов, отличных от веб- и мобильных App, требуется Core. Выбирайте из множества типов: визуализации данных, слайд-деки, анимационные видео и другие. См. [проекты](/ru/ko/features/projects-and-artifacts/projects).

<div id="core">
  ## Переход на Core
</div>

Хотите больше возможностей? Перейдите на Core и получите:

* **больше хранилища и ежемесячных кредитов**, а также оплату по мере использования
* **неограниченное количество опубликованных App** (после первого бесплатного App)
* автономную разработку в режиме **полной сборки**
* **сторонние коннекторы** для подключения к внешним сервисам
* **Интеграции Replit AI** — использование моделей ИИ без собственного ключа API
* **режим Plan** — планирование работы до начала сборки
* **удаление бейджа «Made with Replit»** для профессионального вида
* и множество других преимуществ
