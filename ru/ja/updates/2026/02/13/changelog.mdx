<div id="claude-opus-45">
  ### Поддержка Claude Opus 4.5
</div>

Claude Opus 4.5 теперь доступен в интеграциях с ИИ и предоставляет доступ к новейшим возможностям ИИ от Anthropic, оптимизированным для программирования и агентных задач.

<div id="replit">
  ### Кнопка «Открыть в Replit» (бета)
</div>

Теперь с помощью новой кнопки «Открыть в Replit» можно работать над тикетами Linear прямо в Replit. Эту бета-функцию нужно включить в настройках — после этого детали задачи автоматически подставляются в промпт. Команда работает вместе с Linear над улучшением интеграции.

<div id="agentsql">
  ### Доступ Agent к продакшен-базам данных SQL
</div>

Теперь Agent может просматривать продакшен-базы данных SQL и выполнять к ним запросы в режиме «только чтение» — это позволяет работать с реальными продакшен-данными без риска случайно их изменить.

<div id="section-3">
  ### Повышение надёжности подключений
</div>

Несколько улучшений, которые делают работу с интеграциями удобнее:

* Улучшенный процесс фонового переподключения снижает вероятность истечения срока действия токенов подключения
* Наглядная индикация того, что подключение находится в нештатном состоянии или в состоянии ошибки
* Возможность переподключить интеграцию прямо из состояния ошибки

<div id="enterprise">
  ## Команды и Enterprise
</div>

<div id="section-4">
  ### Бюджеты для пользователей и групп
</div>

Управление бюджетами теперь доступно всем клиентам Enterprise:

* Администраторы команд Enterprise могут задать бюджет использования по умолчанию для всех участников
* Администраторы могут задавать бюджеты для определённых групп (например, администраторов, участников и пользовательских групп)
* Скоро: администраторы смогут задавать индивидуальные бюджеты для отдельных пользователей
