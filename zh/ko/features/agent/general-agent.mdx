<div id="general-agent">
  ## 什么是 General Agent？
</div>

General Agent 是与 Replit Agent 协作最灵活的方式。你无需提前选择产物类型，也不必事先想好要做什么。直接开始对话即可——制作 CSV、生成 PDF、调研某个主题，等准备好了还可以构建一个完整的应用。

核心概念：

* **无需事先选择**：不用提前选定产物类型，直接上手
* **任意产出**：生成文件 (CSV、PDF、文档) 、开展调研，或构建应用
* **连接器**：读写 BigQuery、Linear、Slack、Notion、Amplitude、Segment、Hex 等外部服务
* **渐进式扩展**：从轻量对话起步，自然而然地延伸为完整的应用构建

<div id="general-agent-2">
  ## 使用 General Agent 的方式
</div>

您可以通过以下几种方式使用 General Agent：

1. **在编写提示词前选择「General」**——在 Replit 主页上
2. **打开现有项目**，直接开始与 Agent 对话
3. **从 GitHub [导入](/zh/ko/build/import-from-providers)**——从 GitHub 导入的项目会自动使用 General Agent

<div id="general-agent-3">
  ## General Agent 使用方法
</div>

<div id="section">
  ### 直接开始对话
</div>

打开项目，直接开始对话即可。你不需要事先确定要做什么 —— Agent 会在当前项目上下文中运行，什么都能处理。

**示例提示词：**

* “帮我总结这份文档的核心内容”
* “帮我生成一份按营收排名前 100 的公司 CSV”
* “我的 Linear 工单里排在前 5 的是哪些？”
* “用 TypeScript 帮我搭建一个 Vue.js 项目”

Agent 可以处理会话中生成的文件、产出单个文件的结果，还能把运行代码作为推理过程的一环 —— 哪怕你还没决定要构建什么。

<div id="section-2">
  ### 连接外部服务
</div>

连接工具，让 Agent 可以直接读写数据：

1. 在项目设置中打开**连接器**
2. 连接服务 (BigQuery、Linear、Slack、Notion、Amplitude、Segment、Hex 等)
3. 让 Agent 通过相应服务读取或写入数据

**使用连接器的提示词示例：**

* “Linear 上有哪些未关闭的工单？”
* “帮我总结今天 #engineering 频道的 Slack 消息”
* “从 BigQuery 拉取上个月的销售数据”
* “显示我日历上即将到来的日程”
* “在 Linear 上为入门引导的 bug 创建一个新工单”
* “把总结发到 Slack 的 #engineering 频道”

<div id="section-3">
  ### 从聊天到完整应用
</div>

准备好开始构建时，直接说一声就行。Agent 会从轻量对话无缝转入应用构建——无需推倒重来，也不用切换上下文。

* “把这个做成一个 Web 应用”
* “基于这些数据创建一个应用”
* “为这些指标做一个仪表板”
* “帮我搭建一个 Rust CLI 工具”

你可以先从轻量任务起步——调研主题、生成报告或探索数据——再在合适的时机扩展为完整的应用程序构建。

<div id="section-4">
  ## 你可以创建什么
</div>

* **知识型工作**：无需构建应用，即可进行调研、总结和分析
* **单文件产物**：CSV、PDF、文档、数据导出、带格式的报告
* **数据应用**：查询已连接的服务，并将结果以仪表板形式可视化呈现
* **任意框架或语言**：Angular、Vue、Svelte、Rust、Go、C#、Python tkinter、Godot 游戏、CLI 工具等
* **全栈应用**：准备就绪后，基于聊天上下文构建完整的应用程序

<div id="section-5">
  ## 你可以预期什么
</div>

General Agent 提供更强大的能力和更高的灵活性，但同时也带来一定的不确定性：

* **一次配置到位**：有时 Agent 会一次性完成所有配置
* **反复协作**：复杂的配置可能需要多轮调整
* **技术限制**：某些技术在 Nix 环境中可能无法获得完整支持

<Note>
  与使用预配置环境的标准 Agent 不同，General Agent 会根据你的请求自行搭建环境并执行命令。准备部署时，你可能需要请它配置 Publishing (发布) 。
</Note>

<div id="section-6">
  ## 常见问题
</div>

<Accordion title="Agent 能看到我的其他项目吗？">
  不能。每个聊天都仅限于单个项目内，无法让项目 A 与项目 B 相互通信。
</Accordion>

<Accordion title="为什么我还是无法访问外部工具？">
  你需要先通过连接器连接相应服务。连接完成后，Agent 才能读写该服务的数据；默认情况下并没有访问权限。
</Accordion>

<Accordion title="有哪些连接器可用？">
  目前支持的连接器包括：BigQuery、Linear、Slack、Notion、Amplitude、Segment、Hex 等。我们会定期新增更多连接器。
</Accordion>

<Accordion title="使用 General Agent 需要连接器吗？">
  不需要。连接器是可选的。即使不连接任何外部服务，你也可以使用 General Agent 完成知识型工作、生成文件和构建应用。
</Accordion>
