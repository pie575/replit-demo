지능형 모델 라우팅을 사용하면 Replit이 품질과 비용의 균형을 맞추면서 각 task에 적합한 모델을 선택합니다. 제품에서 **Auto**가 표시된다면 Replit이 지능형 모델 라우팅을 수행하고 있다는 의미입니다.

<div id="enable-intelligent-model-routing">
  ## 지능형 모델 라우팅 활성화
</div>

1. 프롬프트 상자에서 **Agent Mode**를 선택합니다. 메뉴에 사용 가능한 모드인 **Free**, **Power**, **Max**가 표시됩니다.
2. **Power** 또는 **Max**를 선택한 다음 **Primary 모델** 섹션을 찾습니다. 이 섹션의 이름은 선택한 모드에 따라 **Primary Max 모델**처럼 바뀝니다.
3. primary 모델이 이미 **Auto**로 설정되어 있다면 지능형 모델 라우팅이 활성화된 상태입니다. 특정 모델이 선택되어 있다면 primary 모델 메뉴를 열고 **Automatically choose**를 선택하세요.

Free Mode는 항상 지능형 모델 라우팅을 사용하며, 모델을 직접 선택할 수 없습니다.

<div id="let-the-task-guide-the-model">
  ## 작업에 맞는 모델을 선택하세요
</div>

지능형 모델 라우팅은 작업 성격이 바뀔 때마다 Replit이 모델 선택을 알아서 처리하도록 맡기고 싶을 때 유용합니다. 범위가 좁은 요청에는 비용이 낮은 모델을 쓰고, 복잡한 task에는 더 뛰어난 모델이 필요할 수 있습니다.

Power Mode 또는 Max Mode에서는 Core와 Pro 플랜 builder가 사용 가능한 모델을 직접 선택할 수도 있습니다.
