<Info>
  Snowflake连接器仅适用于 Enterprise 套餐。
</Info>

借助数据仓库连接器，Replit Agent 可以查询组织的数据仓库。使用 Snowflake连接器，构建者可以通过自然语言创建控制台、报表工具和数据应用，无需掌握 SQL 专业知识。

设置是一次性流程，需要 Snowflake 管理员和 Replit 工作区管理员共同完成。配置完成后，组织中的所有成员都可以登录并开始使用 Snowflake 数据进行构建。

本指南将介绍完整的设置流程，涉及以下三种角色：

1. **Snowflake 账户管理员** — 在 Snowflake 中创建 OAuth 集成
2. **Replit 工作区管理员** — 在 Replit 中配置连接器
3. **构建者** — 登录并开始构建

<div id="snowflakeoauth">
  ## 在 Snowflake 中创建 OAuth 集成
</div>

Snowflake 账户管理员需要创建 OAuth 安全集成，以便 Replit 能够通过 Snowflake 进行认证。

<div id="section">
  ### 前提条件
</div>

* Snowflake `ACCOUNTADMIN` 角色
* 在 Snowflake 工作表中运行 SQL 的权限

<div id="section-2">
  ### 运行设置脚本
</div>

<Steps>
  <Step title="登录 Snowflake">
    打开您的 Snowflake 账户，确认当前使用的是 `ACCOUNTADMIN` 角色。您可以通过右上角的角色下拉菜单查看。
  </Step>

  <Step title="打开 SQL 工作表">
    点击左侧边栏中的 **Worksheets**，创建一个新工作表。
  </Step>

  <Step title="运行 OAuth 集成脚本">
    复制并粘贴以下 SQL 脚本，然后运行：

    ```sql Create OAuth integration theme={null}
    -- 删除现有集成（如有需要）
    DROP INTEGRATION IF EXISTS REPLIT_OAUTH;

    -- 为 Replit 创建 OAuth 集成
    CREATE SECURITY INTEGRATION REPLIT_OAUTH
      TYPE = OAUTH
      ENABLED = TRUE
      OAUTH_CLIENT = CUSTOM
      OAUTH_CLIENT_TYPE = 'CONFIDENTIAL'
      OAUTH_REDIRECT_URI = 'https://replit.com/connectors/oauth/callback'
      OAUTH_ISSUE_REFRESH_TOKENS = TRUE
      OAUTH_REFRESH_TOKEN_VALIDITY = 7776000
      OAUTH_ALLOW_NON_TLS_REDIRECT_URI = FALSE
      BLOCKED_ROLES_LIST = ()
      COMMENT = 'OAuth integration for Replit connector';
    ```

    <Warning>
      重定向 URI 必须准确设置为 `https://replit.com/connectors/oauth/callback`。使用其他值会在认证过程中导致 404 错误。
    </Warning>

    <Note>
      设置 `BLOCKED_ROLES_LIST = ()` 可确保不会阻止任何角色使用该集成。若未进行此设置，连接时可能会出现“invalid consent request”或“role blocked”错误。
    </Note>
  </Step>

  <Step title="获取 OAuth 凭据">
    运行以下查询以获取客户端 ID 和客户端密钥：

    ```sql Get OAuth credentials theme={null}
    -- 显示集成详细信息
    DESCRIBE INTEGRATION REPLIT_OAUTH;

    -- 获取客户端 ID 和密钥
    WITH secrets AS (
      SELECT PARSE_JSON(
        SYSTEM$SHOW_OAUTH_CLIENT_SECRETS('REPLIT_OAUTH')
      ) as creds
    )
    SELECT
      creds:OAUTH_CLIENT_ID::STRING as CLIENT_ID,
      creds:OAUTH_CLIENT_SECRET::STRING as CLIENT_SECRET
    FROM secrets;
    ```

    从输出中复制 **Client ID** 和 **Client Secret**。下一步需要使用这些信息。
  </Step>
</Steps>

<div id="replit">
  ## 在 Replit 中配置连接器
</div>

Replit 工作区管理员将 Snowflake 凭据添加到 Replit。配置完成后，组织中的任何成员都可以登录。

<Note>
  此步骤需要企业版套餐和管理员权限。
</Note>

<Steps>
  <Step title="打开 Integrations">
    前往组织设置，然后选择 **Integrations** 选项卡。
  </Step>

  <Step title="添加 Snowflake 连接器">
    点击 **Add New Connector**，然后选择 **Snowflake**。
  </Step>

  <Step title="输入凭据">
    输入上一步中的 **Client ID** 和 **Client Secret**。
  </Step>

  <Step title="设置作用域">
    将连接器的作用域设为 `refresh_token`。

    <Warning>
      请仅使用 `refresh_token` 作用域。其他作用域 (如 `session:role-any` 或 `session:role:PUBLIC`) 可能会导致“invalid scope”错误。
    </Warning>
  </Step>

  <Step title="保存">
    点击 **Save** 以启用连接器。
  </Step>
</Steps>

<div id="snowflake">
  ## 登录 Snowflake
</div>

拥有连接器访问权限的组织成员可以登录。请先在 **Integrations** 页面登录，以便在 Agent 中使用前确认连接。

<Steps>
  <Step title="找到 Snowflake 连接器">
    前往 Replit 的 **Integrations**。在 **Connectors** 下找到 **Snowflake**。
  </Step>

  <Step title="点击 Sign In">
    点击 Snowflake 连接器中的 **Sign In**。
  </Step>

  <Step title="输入 Snowflake 账户 ID">
    OAuth 提示词会要求您输入 Snowflake 账户 ID。

    要查找账户 ID，请查看 Snowflake URL：

    ```
    https://app.snowflake.com/myorg/myaccount
    ```

    用连字符连接 `app.snowflake.com/` 后的两个部分：

    ```
    myorg-myaccount
    ```

    <Note>
      URL 中的两个部分之间使用 `/`，而账户 ID 中使用 `-`。
    </Note>
  </Step>

  <Step title="进行认证">
    Snowflake 会将您重定向到登录页面。输入 Snowflake 凭据以完成 OAuth 流程。
  </Step>
</Steps>

<div id="snowflake-2">
  ## 开始使用 Snowflake 数据构建
</div>

连接后，您可以通过以下两种方式使用 Agent 和 Snowflake 连接器：

* **斜杠命令** — 在提示词中输入`/snowflake`以使用连接器
* **自然语言** — 直接让 Agent 使用您的 Snowflake 数据

提示词示例：

```
请使用 Snowflake 数据创建一个控制台。用柱状图按区域展示总收入，用趋势线按季度展示数据，并显示排名前 10 的客户表格。采用深色主题，设计简洁现代。
```

Agent 可以针对您的 Snowflake 数据创建并执行 SQL 查询，并构建可运行的应用。

<div id="section-3">
  ## 故障排除
</div>

<AccordionGroup>
  <Accordion title="invalid consent request 或 role blocked 错误">
    Snowflake 集成中的角色可能默认处于阻止状态。

    确认集成创建时已设置 `BLOCKED_ROLES_LIST = ()`。如果集成此前创建时未使用此设置，请运行以下命令：

    ```sql Fix blocked roles theme={null}
    CREATE OR REPLACE SECURITY INTEGRATION REPLIT_OAUTH
      TYPE = OAUTH
      ENABLED = TRUE
      OAUTH_CLIENT = CUSTOM
      OAUTH_CLIENT_TYPE = 'CONFIDENTIAL'
      OAUTH_REDIRECT_URI = 'https://replit.com/connectors/oauth/callback'
      OAUTH_ISSUE_REFRESH_TOKENS = TRUE
      OAUTH_REFRESH_TOKEN_VALIDITY = 7776000
      OAUTH_ALLOW_NON_TLS_REDIRECT_URI = FALSE
      BLOCKED_ROLES_LIST = ()
      COMMENT = 'OAuth integration for Replit connector';
    ```

    如果错误仍然存在，请确认默认角色未被阻止：

    ```sql Set default role theme={null}
    ALTER USER "YOUR_USERNAME" SET DEFAULT_ROLE = 'PUBLIC';
    ```
  </Accordion>

  <Accordion title="认证时出现 404 错误">
    确认 Snowflake 集成的重定向 URI 与以下地址完全一致：

    ```
    https://replit.com/connectors/oauth/callback
    ```

    如有不一致，OAuth 流程中会出现 404 错误。
  </Accordion>

  <Accordion title="invalid scope 错误">
    确认 Replit 连接器的作用域仅设置为 `refresh_token`。请删除其他作用域，例如 `session:role-any` 或 `session:role:PUBLIC`。
  </Accordion>

  <Accordion title="Failed to connect 错误">
    确认 Replit 的客户端 ID 和客户端密钥与 Snowflake 生成的值一致。运行以下命令进行验证：

    ```sql Verify credentials theme={null}
    WITH secrets AS (
      SELECT PARSE_JSON(
        SYSTEM$SHOW_OAUTH_CLIENT_SECRETS('REPLIT_OAUTH')
      ) as creds
    )
    SELECT
      creds:OAUTH_CLIENT_ID::STRING as CLIENT_ID,
      creds:OAUTH_CLIENT_SECRET::STRING as CLIENT_SECRET
    FROM secrets;
    ```
  </Accordion>
</AccordionGroup>
