L&#39;onglet **My Data** vous permet de consulter et de modifier le contenu de votre base de données. Ouvrez l&#39;outil **Database**, sélectionnez une base de données, puis sélectionnez **My Data**. Vous pouvez travailler de façon visuelle ou exécuter directement des requêtes SQL.

<Note>
  Pour modifier les données de production, sélectionnez la base de données de production, ouvrez **My Data**, puis activez **Edit**. Soyez prudent : il s&#39;agit des données réelles de votre application en ligne.
</Note>

<div id="browse-and-modify-data-visually">
  ## Parcourir et modifier les données visuellement
</div>

L&#39;outil Database intègre <a href="https://orm.drizzle.team/drizzle-studio/overview" target="_blank">Drizzle Studio</a>, qui vous permet de parcourir et de modifier les données visuellement. Ces outils visuels vous aident à éviter les erreurs de syntaxe et offrent les fonctionnalités suivantes :

* Filtrer et trier les données pour vous concentrer sur des informations précises
* Exporter les données vers un fichier en vue d&#39;une utilisation externe
* Insérer ou modifier les données d&#39;une ligne
* Créer et gérer des schémas, des tables, des vues et des énumérations

<div id="run-sql-commands">
  ## Exécuter des commandes SQL
</div>

L&#39;exécuteur SQL vous permet de lancer des commandes SQL sur votre base de données et d&#39;en consulter les résultats.

<Accordion title="Comment accéder à l'exécuteur SQL">
  Depuis l&#39;outil **Database** :

  1. Sélectionnez l&#39;onglet **My Data**
  2. Sélectionnez <img class="icon-svg" src="/assets/mirror/sql-runner-icon-b25868882922.svg" alt="Icône de l'exécuteur SQL" width="16" height="16" data-path="images/icons/sql-runner-icon.svg" /> **exécuteur SQL**
</Accordion>

Pour exécuter une requête, saisissez l&#39;instruction SQL dans la zone de texte, puis sélectionnez le bouton d&#39;exécution <img class="icon-svg" src="/assets/mirror/sql-play-8ed26b5de7f1.svg" alt="icône d'exécution SQL" width="18" height="18" data-path="images/icons/sql-play.svg" /> situé à côté :

<Frame>
  <img src="/assets/mirror/sql-runner-run-8ad798a61335.jpg" alt="capture d'écran de l'exécuteur SQL et du bouton d'exécution" width="1390" height="608" data-path="images/databases/sql-runner-run.jpg" />
</Frame>

<Tip>
  Vous n&#39;avez pas besoin d&#39;écrire le SQL vous-même : demandez à Agent d&#39;interroger ou de modifier vos données, et il rédige et exécute le SQL à votre place.
</Tip>
