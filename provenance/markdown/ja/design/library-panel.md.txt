# ライブラリパネル

> ライブラリパネルのリファレンス: デザインにスターターテンプレートを追加したり、Mobbinが厳選したインスピレーションを閲覧したり、自分の過去の制作物を再利用したりできます。

ライブラリパネルは、Replit Designに組み込まれた出発点と参考資料のソースです。**Templates**、**Inspiration**、**Library** の3つのタブがあります。ここから何かを選んでも新しいプロジェクトが作成されることはなく、すべては今いるプロジェクトのキャンバスに配置されます。

## Templates

Replitが作成した既成のデザインフレームで、ポスター、ソーシャル投稿、ランディングページ、モバイル、バナー、プロトタイプといった種類ごとに分類・検索できます。クリックまたはドラッグしてデザインに追加すると、自分で生成したものと同じように編集できるライブフレームとしてキャンバスに配置されます。

## Inspiration

Mobbinが厳選した、実際のプロダクトのUIスクリーンショットです。*「Airbnb onboarding」* や *「Coinbase checkout」* のようにアプリ画面を検索し、選択するとキャンバスに静的な参考画像として配置されます。Inspirationはプロジェクトにコードを一切追加しません — 眺めたり、チャットで指し示したり、次の生成の参考にしたりするためのものです。

## Library

自分自身の制作物です。このプロジェクトで既に作成したデザインやアーティファクトを、いつでもキャンバスに呼び戻すことができます。

## TemplatesとInspirationの違い

|            | Templates                | Inspiration                    |
| ---------- | ------------------------ | ------------------------------ |
| これは何か      | Replitが作成したスターターデザインフレーム | Mobbin経由の、実際のプロダクトのUIスクリーンショット |
| キャンバス上での扱い | デザイン内の編集可能なライブフレーム       | 静的な参考画像                        |
| 用途         | 動作するデザインから始める            | 次の生成の見た目の方向性を定める               |

ガイド付きのフローについては [テンプレートとインスピレーションを追加する](/ja/design/add-templates-and-inspiration) を参照してください。
