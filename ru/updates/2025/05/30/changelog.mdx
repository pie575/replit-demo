  ## Обновления платформы
</div>

<div id="preview-empty-state-improvements">
  ### Улучшения отображения пустого состояния в Preview
</div>

Preview в приложениях Agent теперь лучше обрабатывает пустые состояния и автозапуск, обеспечивая более удобный рабочий процесс при разработке с Agent.

<div id="ai-latency-improvements">
  ### Уменьшение задержки AI
</div>

Благодаря улучшениям инфраструктуры удалось значительно сократить время отклика и задержки Replit AI. При использовании функций Replit на базе AI, включая Agent и Assistant, взаимодействие станет заметно быстрее.

<div id="unified-github-tab-refresh">
  ### Обновлённая единая вкладка GitHub
</div>

Вкладка интеграции с GitHub стала чище и удобнее. Благодаря обновлённому дизайну подключать репозитории GitHub и управлять ими в Workspace стало проще и понятнее.

<div id="ios-app-payment-support">
  ### Поддержка платежей в приложении для iOS
</div>

Пользователи iOS теперь могут оформлять подписку Replit Core и настраивать способы оплаты прямо в Replit Mobile App. Это упрощает доступ к премиум-функциям в дороге.

<div id="stripe-checkout-release">
  ### Запуск Stripe Checkout
</div>

Новая интеграция Stripe Checkout делает оплату удобнее и безопаснее для всех разработчиков. Воспользуйтесь упрощённым процессом покупки с этим отраслевым стандартом платёжных решений — переход на Replit Core станет ещё проще.

  ## Teams и Enterprise
</div>

<div id="scim-provisioning-streamlined">
  ### Упрощена подготовка учетных записей через SCIM
</div>

Подключать пользователей Enterprise стало значительно проще благодаря улучшенному процессу подготовки учетных записей через SCIM. Новые пользователи создаются автоматически, без ручных действий, что упрощает работу Teams Enterprise, развивающихся на Replit.
