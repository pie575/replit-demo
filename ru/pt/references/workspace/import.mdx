Импорт позволяет перенести существующий код или дизайны в Replit App и продолжить разработку с Agent.

<div id="fontes-suportadas">
  ## Поддерживаемые источники
</div>

| Источник                 | Что нужно предоставить                                        | Лучше всего подходит для                                     |
| ------------------------ | ------------------------------------------------------------- | ------------------------------------------------------------ |
| GitHub                   | URL или выбор репозитория                                     | Импорта публичных и частных репозиториев                     |
| Bitbucket                | URL или выбор репозитория                                     | Импорта репозиториев, размещённых на Bitbucket               |
| Vercel                   | Репозиторий GitHub, связанный с вашим проектом Vercel         | Миграции приложений Vercel                                   |
| Figma                    | URL фрейма                                                    | Преобразования дизайнов в приложения React                   |
| Bolt                     | Репозиторий GitHub, экспортированный из Bolt                  | Миграции проектов Bolt                                       |
| Lovable                  | Репозиторий GitHub, экспортированный из Lovable               | Миграции проектов Lovable                                    |
| Base44                   | Репозиторий GitHub, экспортированный из Base44                | Миграции проектов Base44                                     |
| ZIP                      | Загрузка файла `.zip`                                         | Импорта локальных файлов проекта                             |
| Электронная таблица      | Файл `.xlsx`, `.csv` или URL Google Таблиц                    | Создания App на основе данных электронной таблицы            |
| Предыдущий экспорт Agent | Репозиторий GitHub, экспортированный из предыдущего Agent App | Повторного импорта предыдущего Agent App                     |
| Пустой                   | Ничего                                                        | Опытных пользователей, которым нужен пустой проект без Agent |

<Note>Replit проверяет совместимость перед началом импорта.</Note>

<div id="fluxo-padro-de-importao">
  ## Стандартный процесс импорта
</div>

1. Откройте [replit.com/import](https://replit.com/import).
2. Выберите источник импорта.
3. Подключите необходимые учётные записи.
4. Укажите URL репозитория, URL frame или файл `.zip`.
5. Добавьте запрошенные Secrets или переменные окружения.
6. Нажмите **Import** и проверьте созданное App.

<div id="notas-sobre-as-fontes">
  ## Примечания об источниках
</div>

<div id="github">
  ### GitHub
</div>

* Используйте быстрый импорт общедоступных репозиториев через `https://replit.com/github.com/<owner>/<repo>`.
* Используйте пошаговый импорт для общедоступных и частных репозиториев.
* Если ваш репозиторий — экспортированное Agent App, Replit сохраняет структуру, специфичную для Agent, при импорте.

<div id="bitbucket">
  ### Bitbucket
</div>

* Вставьте URL репозитория Bitbucket или подключите учётную запись Bitbucket, чтобы найти нужные репозитории.
* Поддержка Agent при импорте может быть ограничена по сравнению с проектами, размещёнными на GitHub.

<div id="figma">
  ### Figma
</div>

* Импортируйте URL одного фрейма из Figma.
* Replit генерирует код React, после чего Agent помогает его доработать.
* Для наилучших результатов используйте фреймы, автолейаут и понятные названия слоёв.

<div id="vercel">
  ### Vercel
</div>

* Выберите репозиторий GitHub, связанный с вашим проектом Vercel.
* Replit импортирует код проекта и настройки конфигурации.
* Добавьте значения переменных окружения во время импорта.

<div id="bolt">
  ### Bolt
</div>

* Перед импортом экспортируйте проект Bolt в GitHub.
* Replit импортирует код, стили UI, ассеты, логику бэкенда (если она есть) и схему базы данных (если она есть).
* Данные Supabase и значения секретов не импортируются.
* После импорта попросите Agent добавить секреты и воссоздать данные базы данных.

<div id="lovable">
  ### Lovable
</div>

* Перед импортом экспортируйте проект Lovable в GitHub.
* Replit импортирует код, стили UI, ассеты, логику бэкенда (при наличии) и схему базы данных (при наличии).
* Данные Supabase и значения секретов не импортируются.
* После импорта попросите Agent добавить секреты и восстановить данные базы данных.

<div id="base44">
  ### Base44
</div>

* Перед импортом экспортируйте проект Base44 на GitHub.
* Replit импортирует код, дизайн и стили, ассеты и API-логику.
* Бэкенд Base44 (сущности, agents, SDK), аутентификация и данные не импортируются.
* После импорта попросите Agent перенести все нужные вам функции, специфичные для Base44.

<div id="zip">
  ### ZIP
</div>

* Загрузите файл `.zip` с чётко обозначенной корневой папкой проекта.
* Replit импортирует файлы, зависимости и распространённые настройки запуска.
* Существующие значения секретов, домены и данные баз данных не импортируются.

<div id="planilha">
  ### Электронная таблица
</div>

* Загрузите файл Excel (`.xlsx`) или CSV либо вставьте общедоступный URL Google Таблиц.
* Agent считывает структуру вашей таблицы и создает полностековое App с базой данных, заполненной вашими данными.
* Включает UI для просмотра, поиска и управления записями.

<div id="exportao-anterior-do-agent">
  ### Предыдущий экспорт Agent
</div>

* Повторно импортируйте ранее экспортированное Agent App из репозитория GitHub.
* Replit сохраняет специфичную для Agent структуру (код, схему базы данных, функциональность бэкенда).
* Значения базы данных и секреты не импортируются.

<div id="vazio">
  ### Пустой
</div>

* Начните с полностью пустого проекта — без Agent, выбора фреймворка и стартовой структуры.
* Подходит опытным пользователям, которым нужен полный контроль над настройкой проекта.

<div id="limitaes">
  ## Ограничения
</div>

* Данные из существующей базы данных не переносятся.
* Некоторые сложные или проприетарные зависимости могут потребовать ручной настройки.
* Обработка крупных проектов может занять больше времени.

<div id="melhores-prticas">
  ## Рекомендации
</div>

* Удалите конфиденциальные учетные данные перед импортом.
* Поддерживайте порядок в структуре исходного проекта.
* Проверьте зависимости и выполните команды после импорта.
* Протестируйте основные сценарии перед публикацией.

<div id="soluo-de-problemas">
  ## Устранение неполадок
</div>

Если импорт завершился ошибкой, сначала проверьте следующее:

* **Ошибки совместимости**: проверьте необходимые файлы проекта и поддерживаемые фреймворки.
* **Ошибки доступа**: убедитесь, что у вас есть необходимые разрешения для репозитория или источника.
* **Ошибки обработки**: повторите попытку, упростив структуру проекта или уменьшив его размер.

Если проблема не исчезнет, посетите [Replit Community Hub](https://replit.com/community) или [обратитесь в службу поддержки](https://replit.com/support).

<div id="faturamento">
  ## Оплата
</div>

Импорт, требующий миграции с помощью Agent, может потребовать кредитов. Их расход зависит от сложности проекта.
