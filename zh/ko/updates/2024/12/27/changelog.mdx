<div id="section-3">
  ### 集成
</div>

集成功能现已在 Agent 界面中*更加醒目*。您可以轻松将常用服务添加到 Agent 应用中。多项新集成已上线，并得到改进。主要包括：

* Perplexity
* Firebase
* OpenAI
* Anthropic
* Google Services

<div id="agent">
  ### Agent 改进
</div>

Agent 现在会在您提出请求后立即暂停，不再等待当前运行完成。这样，当您改变主意时，就能更轻松地停止 Agent。

Agent 界面中还新增了“运行”按钮。

  ### Replit Teams 更新
</div>

Teams 推出了一些令人兴奋的更新：

* 您现在可以在 Teams 中自定义 Replit 应用图标和封面图片
* 纯色封面现已替换为自定义图片
* Replit Teams 现已支持移动端！
