export const profileImagesPrompt = "플레이어가 촬영한 프로필 사진을 계정에 연결해 App Storage에 저장하세요.";

PixelGames에는 플레이어가 찍은 사진을 보관할 공간이 필요합니다. 저장 기능은 누가 업로드하는지 알아야 동작하므로, 이 가이드는 플레이어가 이미 [로그인](/ko/build/mobile-login)할 수 있다고 가정합니다.

<AiPrompt>
  {profileImagesPrompt}
</AiPrompt>

Agent는 [App Storage](/ko/features/data-and-storage/object-storage)를 설정하고 각 업로드를 로그인한 플레이어와 연결합니다. 이렇게 하면 PixelGames에서 이름 옆에 업로드한 사진이 표시되는 실제 프로필을 보여줄 수 있습니다.

</Frame>

<div id="test-it">
  ## 테스트하기
</div>

1. 기존 계정으로 PixelGames에 로그인합니다.
2. 프로필 사진을 촬영하거나 선택한 후 업로드합니다.
3. 앱을 닫았다가 다시 열어 사진이 그대로 남아 있는지 확인합니다.
4. 다른 휴대폰에서 같은 계정으로 로그인해 동일한 사진이 표시되는지 확인합니다.

<div id="troubleshooting">
  ## 문제 해결
</div>

* **로그인했는데 사진이 표시되지 않는 경우:** 앱이 예상과 다른 스토리지 또는 인증(auth) 인스턴스를 가리키고 있을 가능성이 높습니다. Agent에게 연결 상태를 확인해 달라고 요청하세요.
* **업로드가 실패하는 경우:** 업로드 전에 앱이 카메라 및 스토리지 권한을 요청했는지 확인하세요.
