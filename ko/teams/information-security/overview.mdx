Replit은 전 세계 수백만 명의 개발자가 사용하는 AI 기반 클라우드 개발 환경을 제공합니다. 보안은 Replit 플랫폼의 근간으로, 사용자가 여러 기기와 플랫폼에서 안심하고 애플리케이션을 개발하고 협업하며 게시할 수 있도록 지원합니다.

<div id="data-protection">
  ## 데이터 보호
</div>

데이터 보호는 Replit의 최우선 과제입니다. Replit은 고객의 데이터를 보호하고 플랫폼의 무결성을 유지하기 위해 포괄적인 보안 조치를 시행하고 있습니다.

<div id="hosting-and-infrastructure">
  ### 호스팅 및 인프라
</div>

Replit은 데이터를 주로 미국 내 Google Cloud Platform(GCP) 데이터 센터에 호스팅하며, 원하는 사용자는 인도 호스팅 리전을 선택할 수 있습니다. Replit은 GCP의 엔터프라이즈급 백업 및 복구 도구를 활용하여 다음을 보장합니다.

<CardGroup cols={2}>
  <Card title="고가용성" icon="server">
    이중화 시스템과 자동 장애 조치 메커니즘이 서비스 중단과 데이터 손실을 방지합니다
  </Card>

  <Card title="데이터 분리" icon="layer-group">
    강력한 논리적 분리를 통해 서로 다른 사용자와 조직 간의 무단 접근을 차단합니다
  </Card>
</CardGroup>

GCP는 업계를 선도하는 클라우드 제공업체로, **ISO 27001** 및 **SOC 2 Type 2** 규정 준수 인증을 받았습니다. 또한 **Replit은 SOC 2 Type 2 규정 준수 인증(Attestation of Compliance)을 획득**하여 보안 모범 사례와 통제 체계에 대한 지속적인 노력을 입증하고 있습니다.

모든 클라이언트 요청은 비공개 정보에 접근하기 전에 반드시 엄격한 **인증 및 권한 부여** 과정을 거쳐야 합니다.

<div id="encryption-standards">
  ### 암호화 표준
</div>

<Note>
  Replit은 정보의 기밀성, 무결성, 보안을 보장하기 위해 모든 데이터 상태에 걸쳐 포괄적인 암호화를 적용합니다.
</Note>

<AccordionGroup>
  <Accordion title="전송 중 암호화" icon="shield-halved">
    업계 표준인 **TLS 1.2+** 암호화가 클라이언트와 Replit 서버 간의 모든 통신을 보호하여 네트워크를 오가는 데이터를 안전하게 지킵니다. 여기에는 모든 API 호출, 웹 트래픽, 실시간 협업 데이터를 비롯한 기타 통신이 포함됩니다.
  </Accordion>

  <Accordion title="저장 데이터" icon="database">
    GCP에 저장된 데이터는 [**AES-256 서버 측 암호화**](https://cloud.google.com/docs/security/encryption/default-encryption)로 보호됩니다. 이 군사 등급 암호화 표준은 코드, 구성, 사용자 정보, 시스템 메타데이터 등 저장된 모든 데이터를 보호합니다.
  </Accordion>

  <Accordion title="데이터베이스 보안" icon="lock">
    Replit은 [데이터베이스 암호화](https://cloud.google.com/sql/references/additional-resources/faq#encryption-manage-rest)와 [안전한 키 관리](https://cloud.google.com/secret-manager)에 **Google Cloud SQL**을 사용하며, 자동 암호화와 정기적인 키 교체, 세분화된 접근 제어로 민감한 데이터를 안전하게 보호합니다.
  </Accordion>
</AccordionGroup>

  ## 인프라 보안

<CardGroup cols={3}>
  <Card title="로드 밸런싱" icon="server">
    최적의 성능과 안정성을 위한 지능형 트래픽 분산
  </Card>

  <Card title="WAF 보호" icon="shield">
    고급 웹 애플리케이션 방화벽이 악성 트래픽과 정교한 공격을 차단합니다
  </Card>

  <Card title="벤더 보안" icon="user-check">
    정기적인 보안 평가 및 모니터링을 포함한 엄격한 하위 처리자 기준

</CardGroup>

Replit은 모든 하위 처리자가 당사의 엄격한 보안 표준과 규정 준수 요건을 충족하는지 확인하기 위해 철저한 **실사**를 수행합니다.
