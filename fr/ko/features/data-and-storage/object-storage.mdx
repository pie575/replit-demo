App Storage est le stockage d’objets intégré de Replit, qui permet aux applications d’héberger et de stocker facilement des fichiers téléversés tels que des images, des vidéos et des documents.
Les buckets sont des conteneurs qui stockent des objets tels que des fichiers. Ils comprennent des politiques d’accès qui limitent les actions que les utilisateurs ou les applications peuvent effectuer sur le contenu.

<Info>
  Nous avons renommé <strong>Object Storage</strong> en <strong>App Storage</strong>. Les fonctionnalités restent inchangées, et les buckets, autorisations et accès programmatiques existants continuent de fonctionner.
</Info>

Avec App Storage, vous pouvez créer les types d’applications suivants :

* **Plateformes de partage de photos ** : permettez aux créateurs de téléverser, stocker et afficher des images
* **Services de diffusion vidéo ** : gérez les téléversements de vidéos et diffusez du contenu aux spectateurs
* **Systèmes de gestion de documents ** : stockez et organisez les fichiers des créateurs avec un accès sécurisé
* **Sites de portfolio ** : présentez votre travail avec des fichiers multimédias qui se chargent de manière fiable
* **Services de sauvegarde de fichiers ** : offrez aux créateurs un stockage cloud pour leurs fichiers importants

<Note>
  Demandez à **Agent** d’ajouter App Storage en précisant les types de fichiers que votre application doit traiter. Agent configure l’intégration, crée les buckets nécessaires et met à jour votre application afin qu’elle puisse téléverser, stocker et récupérer des fichiers grâce à des fonctionnalités avancées telles que l’authentification et le contrôle d’accès.
</Note>

L’outil App Storage vous permet de partager facilement des données entre les environnements de développement et de production, ou avec d’autres applications Replit.

<div id="section">
  ## Fonctionnalités
</div>

<Info>
  App Storage s&#39;appuie sur Google Cloud Storage (GCS).
  Vous bénéficiez ainsi d&#39;une disponibilité, d&#39;une fiabilité et d&#39;une sécurité de premier plan.
</Info>

App Storage offre les fonctionnalités suivantes à vos applications Replit.

* **Stockage cloud persistant :** stockez des fichiers auxquels votre application publiée et vos utilisateurs peuvent continuer à accéder
* **Gestion de fichiers évolutive :** répondez à des besoins croissants en données sans vous soucier des limites de stockage
* **Partage de données entre applications :** partagez des buckets entre plusieurs applications Replit pour les architectures distribuées
* **Accès programmatique :** utilisez une API intuitive pour téléverser, télécharger et gérer des fichiers
* **Intégration améliorée avec Agent :** laissez Agent configurer App Storage avec des paramètres avancés, vérifier la configuration existante et générer un code back-end/front-end complet, y compris pour l&#39;authentification et le contrôle d&#39;accès

Voici quelques façons d&#39;utiliser App Storage dans vos applications Replit.

* Stocker des photos de profil de créateurs et des médias téléversés
* Fournir des images de produits pour des sites d&#39;e-commerce
* Gérer les téléversements de documents associés aux soumissions de formulaires
* Créer des fonctionnalités de partage de fichiers et de collaboration
* Créer des systèmes de gestion de contenu avec des bibliothèques multimédias

<div id="section-2">
  ## Utilisation
</div>

<Note>
  Les applications Replit doivent s’authentifier auprès de Google Cloud Storage pour accéder aux buckets et aux objets qu’ils contiennent.
  Pour vous authentifier automatiquement, utilisez la bibliothèque cliente officielle Replit App Storage.
</Note>

Vous pouvez accéder directement à l’outil App Storage depuis le Project Editor.

<Accordion title="Accéder à l’outil App Storage">
  Dans le **Tool dock** de gauche :

  1. Sélectionnez <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="icône de tous les outils" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools** pour afficher la liste des outils du Project Editor.
  2. Sélectionnez <img class="icon-svg" src="/assets/mirror/object-storage-monoochrome-icon-aaba8f517280.svg" alt="icône App Storage" width="16" height="16" data-path="images/icons/object-storage-monoochrome-icon.svg" /> **App Storage**.

  Dans la **barre de recherche** :

  1. Sélectionnez l’icône de loupe <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="icône de loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> en haut pour ouvrir l’outil de recherche.
  2. Saisissez « App Storage », puis sélectionnez l’outil dans les résultats.
</Accordion>

Pour connecter un nouveau bucket de stockage à une application Replit, créez un bucket.

<Accordion title="Créer un bucket">
  Dans l’outil **App Storage** :

  1. Cliquez sur **Create new bucket**.
  2. Saisissez le nom du bucket dans le champ **Name**, puis sélectionnez **Create bucket**.

  L’onglet App Storage devrait ressembler à la capture d’écran suivante.

  Pour créer des buckets supplémentaires, ouvrez le menu déroulant des buckets en haut à gauche de l’onglet **App Storage**, puis sélectionnez **Create new bucket**.

<div id="id">
  ### Vérifier l’ID du bucket
</div>

Dans le menu déroulant en haut de l’onglet **App Storage**, sélectionnez la page **paramètres** pour afficher l’**ID du bucket**.
L’ID du bucket l’identifie de manière unique et doit être référencé dans votre code pour effectuer des opérations.

Si vous avez plusieurs buckets, sélectionnez le bon dans le menu déroulant en haut à gauche.

<div id="section-4">
  ### Téléverser ou télécharger des objets
</div>

Pour téléverser des objets vers le bucket sélectionné :

1. Dans l’onglet **App Storage**, accédez à l’écran **Objects**.
2. Sélectionnez <img class="icon-svg" src="/assets/mirror/upload-file-5894be4232ce.svg" alt="icône de téléversement de fichier" width="16" height="16" data-path="images/icons/upload-file.svg" /> **Upload files** ou, pour téléverser tous les fichiers d’un dossier, sélectionnez <img class="icon-svg" src="/assets/mirror/upload-folder-fc87519bedf9.svg" alt="icône de téléversement de dossier" width="16" height="16" data-path="images/icons/upload-folder.svg" /> **Upload folder**.
   Sélectionnez ensuite un ou plusieurs fichiers à téléverser dans la boîte de dialogue.
   Vous pouvez également faire glisser des fichiers ou des dossiers vers la zone listant le contenu du bucket.

Pour télécharger des objets depuis le bucket sélectionné :

1. Dans l’onglet **App Storage**, accédez à l’écran **Objects**.
2. Sélectionnez <img class="icon-svg" src="/assets/mirror/download-icon-c7b527953d65.svg" alt="icône de téléchargement" width="16" height="16" data-path="images/icons/download-icon.svg" /> l’icône de téléchargement située à droite du fichier.

<div id="section-5">
  ### Organiser les objets dans des dossiers
</div>

Pour créer un dossier dans le bucket sélectionné :

1. Dans l’onglet **App Storage**, accédez à l’écran **Objects**.
2. Dans l’écran **Objects**, sélectionnez <img class="icon-svg" src="/assets/mirror/create-folder-c9acf112a042.svg" alt="Icône Créer un dossier" width="16" height="16" data-path="images/icons/create-folder.svg" /> **Create Folder**.
3. Saisissez le nom du dossier.

Pour ajouter des objets à un dossier depuis l’écran **Objects**, faites-les glisser vers le dossier cible.

Pour déplacer un objet vers le dossier parent, faites-le glisser vers l’en-tête au-dessus de la liste des objets, puis déposez-le sur le nom du dossier parent.
L’animation suivante montre le déplacement du fichier « product&#95;demo.mov » du dossier « videos » vers le dossier parent « Objects ».

<div id="section-6">
  ### Supprimer des objets ou des buckets
</div>

<Warning>
  Les opérations de suppression sont irréversibles. Veillez à sauvegarder les données importantes avant de continuer.
</Warning>

Pour supprimer définitivement un objet :

1. Dans l’onglet **App Storage**, accédez à l’écran **Objects**.
2. Sélectionnez l’icône de suppression <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="icône de suppression" width="16" height="16" data-path="images/icons/trash-icon.svg" /> située à côté de l’objet à supprimer.
3. Confirmez la suppression dans la boîte de dialogue qui s’affiche.

Pour supprimer un bucket et tous les objets qu’il contient :

1. Dans l’onglet **App Storage**, accédez à l’écran **paramètres**.
2. Vérifiez que le bucket à supprimer est sélectionné dans le menu déroulant des buckets, en haut à gauche.
3. Sélectionnez <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="icône de suppression" width="16" height="16" data-path="images/icons/trash-icon.svg" /> **Supprimer le bucket**.
4. Confirmez la suppression dans la boîte de dialogue qui s’affiche.

<div id="section-7">
  ### Gestion des accès aux buckets
</div>

Replit associe tous les buckets que vous créez à votre compte afin qu’ils puissent être utilisés par toutes les applications Replit. L’application Replit qui crée un bucket obtient automatiquement l’autorisation d’y accéder.

Vous pouvez contrôler les applications Replit autorisées à accéder à un bucket donné afin de partager vos données de manière efficace et sécurisée.

Pour permettre à une application Replit d’accéder à un bucket créé par une autre application de votre compte :

1. Dans le menu des buckets situé en haut à gauche de l’onglet App Storage, sélectionnez <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="icône de loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" />
   **Ajouter un bucket existant**.
2. Dans la boîte de dialogue **Choisir un bucket**, sélectionnez le bucket à ajouter, puis sélectionnez **Ajouter le bucket à Repl**.

<Frame>
  <img src="/assets/mirror/choose-bucket-dialog-b709aa247a85.png" alt="capture d’écran de la boîte de dialogue de sélection de bucket" width="1115" height="457" data-path="images/databases/choose-bucket-dialog.png" />
</Frame>

Pour révoquer l’autorisation d’accès d’une application Replit à un bucket :

1. Dans l’onglet **App Storage**, accédez à l’écran **Paramètres**.
2. Dans la liste déroulante des buckets située en haut à gauche de l’onglet, sélectionnez le nom du bucket.
3. Sélectionnez **Supprimer le bucket de Repl**, puis confirmez la suppression dans la boîte de dialogue de confirmation.
