# Frameworks para Desenvolvedores

> Os templates iniciais de linguagens e frameworks foram removidos. Aprenda a começar um novo projeto Replit hoje.

## Os templates de developer frameworks foram removidos

Os templates iniciais de linguagens e frameworks (antes chamados de developer frameworks) não estão mais disponíveis no Replit. As páginas `replit.com/templates` e `replit.com/developer-frameworks` agora redirecionam para a [Replit Gallery](https://replit.com/gallery).

Para começar um novo projeto, use uma das opções a seguir:

* **Comece com o Replit Agent** — descreva o que você quer construir a partir da [página inicial](https://replit.com/) e deixe o Agent estruturar o projeto para você.
* **[Importe do GitHub, GitLab ou Bitbucket](/pt/build/import-from-providers)** — traga um código-base existente ou uma stack inicial como um novo Replit App.
* **[Faça remix de um app publicado](https://replit.com/gallery)** — navegue pela Replit Gallery em busca de apps da comunidade que você pode visualizar e usar como ponto de partida para um remix.

## Templates personalizados para Enterprise

Organizações Enterprise podem criar [templates personalizados](/pt/teams/custom-templates) que aparecem como opções selecionáveis na caixa de entrada do Agent para todos os membros da organização. Os templates personalizados vão além dos developer frameworks ao incluir instruções do Agent específicas da empresa, skills e contexto de projeto pré-configurado. Veja o [guia de templates personalizados](/pt/teams/custom-templates) para mais detalhes.
