<div id="plan">
  ## Что такое режим Plan?
</div>

Режим Plan позволяет:

* изучать разные подходы к проекту и **прорабатывать идеи**
* **планировать разработку** с помощью структурированного списка задач
* **сотрудничать с ИИ** при планировании архитектуры и функций проекта
* **получать стратегические рекомендации и задавать вопросы**, не изменяя код или данные проекта
* **плавно переходить** в режим Build, когда будете готовы

Теперь режим по умолчанию называется режимом **Build**.

В отличие от режима Build, режим Plan ориентирован на планирование и проработку идей, чтобы вы могли тщательно продумать проект до написания кода.

<div id="plan-2">
  ### Доступ к режиму Plan
</div>

Режим Plan доступен во всех Replit App с включённым Agent. Чтобы перейти в него:

1. **Откройте Replit App в Project Editor**
2. **Найдите переключатель режимов в левом нижнем углу поля ввода чата**
3. **Выберите режим Plan в раскрывающемся списке**

<div id="section-3">
  ### Планирование задач
</div>

Режим Plan особенно удобен для разделения сложных проектов на выполнимые задачи. Передайте Agent требования, и он создаст список задач с последовательностью работ по разработке, необходимых для выполнения запроса.

<div id="section-4">
  ### Совместная разработка идей
</div>

Исследуйте различные подходы вместе с ИИ:

* **Несколько вариантов решения** сложных задач
* Анализ **преимуществ и недостатков** различных подходов
* **Оценка рисков** и стратегии их снижения

<div id="section-5">
  ## Рабочий процесс: от планирования до создания приложения
</div>

<div id="1-plan">
  ### 1. Этап планирования (режим Plan)
</div>

Начните разработку в режиме Plan:

* **Определите** масштаб и цели проекта
* **Разбейте** требования на конкретные функции
* **Спланируйте** архитектуру и технологический стек
* **Составьте** дорожную карту разработки с ключевыми этапами

<div id="2">
  ### 2. Утверждение задач
</div>

Когда Agent создаст список задач:

* **Просмотрите** предложенные задачи
* Чтобы утвердить план, выберите **Начать сборку**

Или продолжите диалог, чтобы доработать план.

<div id="3-build">
  ### 3. Переход в режим Build
</div>

Когда будете готовы приступить к реализации:

* Нажмите **«Начать сборку»**, чтобы утвердить план
* **Agent автоматически** переключится в режим Build
* **Agent начнёт выполнять утверждённые задачи**
* **Отслеживайте прогресс** на протяжении всего этапа разработки

Использование режима Plan оплачивается по той же модели, основанной на затраченных усилиях, что и другие взаимодействия с Agent. Плата взимается за все действия Agent в режиме Plan, включая ответы на вопросы, предоставление рекомендаций и создание списков задач. Более сложные запросы или диалоги с более длинным контекстом стоят дороже.

**Плата взимается за все взаимодействия с Agent** — независимо от того, отвечает ли Agent текстовыми рекомендациями или изменяет код. Однако небольшие запросы обходятся дешевле.

<div id="section-7">
  ### Планирование функций
</div>

Идеально подходит для добавления новых функций:

* **Разбиение** сложных функций на выполнимые задачи
* **Планирование** изменений в базе данных и API
* **Проектирование** пользовательского интерфейса и сценариев взаимодействия
* **Учёт** нестандартных ситуаций и обработки ошибок

  ## Рекомендации

<div id="section-10">
  ### Составление эффективных промптов
</div>

Чтобы максимально эффективно использовать режим Plan:

* **Чётко** формулируйте требования к проекту
* Задавайте **уточняющие вопросы**, чтобы прояснить предложения ИИ
* При обсуждении сложных концепций **запрашивайте примеры**
* Обсуждайте **компромиссы** между разными подходами
* **Прорабатывайте идеи в несколько итераций**, прежде чем определиться с реализацией
* **Сохраняйте важные решения**, чтобы ссылаться на них в последующих беседах
