**Un élément** désigne tout composant individuel rendu dans un frame, comme un titre, un bouton, une image ou un champ de formulaire. Ciblez les éléments lorsque vous souhaitez modifier une seule partie d’un frame sans régénérer l’ensemble.

<div id="section">
  ## Sélectionner des éléments
</div>

Utilisez l’[outil Edit](/fr/ko/design/toolbar#edit) dans la barre d’outils. Lorsque Edit est actif, cliquez dans une frame en cours d’exécution pour sélectionner l’élément situé sous le curseur. L’élément sélectionné est entouré d’un contour de surbrillance et affiche un petit prompt intégré permettant de demander des modifications à Agent.

<Note>
  Si le Canvas ne contient aucune frame, Edit est désactivé et n’est disponible que sur ordinateur.
</Note>

<div id="section-2">
  ## Travailler avec les éléments sélectionnés
</div>

<div id="agent">
  ### Demander des modifications à Agent
</div>

Demandez à Agent de mettre à jour le texte, la couleur, la mise en page, l’espacement et le comportement d’un élément à l’aide d’un prompt intégré.

  <img src="/assets/mirror/canvas-ask-element-53f7468a07d3.png" alt="Vue agrandie du prompt intégré d’un élément sélectionné dans Canvas : après la puce « img », le texte d’aide « Ask about selected element… » et un bouton d’envoi s’affichent." width="1500" height="500" data-path="images/replitai/canvas-ask-element.png" />
</Frame>

<div id="section-3">
  ### Remplacer une image directement
</div>

Lorsque vous sélectionnez un élément d’image, son chemin source et le bouton **Téléverser une image** s’affichent dans la section **Image** du Visual Editor. Vous pouvez ainsi remplacer le fichier sans rédiger de prompt.

<div id="visual-editor">
  ## Visual Editor
</div>

Lorsque vous sélectionnez un élément, le panneau de droite **Visual Editor** s’ouvre avec un prompt intégré. Ce panneau regroupe toutes les options en sections claires afin de vous aider à trouver plus rapidement ce dont vous avez besoin : **Texte**, **Mise en page**, **Couleur**, **Bordure**. (Lorsque vous sélectionnez un élément d’image, une section **Image** apparaît également.)

<div id="layout">
  ### Mise en page
</div>

La section **Mise en page** vous permet d’ajuster directement la disposition des éléments enfants dans un conteneur, sans passer par Agent. Sélectionnez un conteneur flex et ouvrez Mise en page pour afficher les éléments suivants.

* **Alignement** : un sélecteur à 9 points (3×3) permettant de choisir la position des éléments sur les deux axes du conteneur.
* **Direction** : deux boutons fléchés permettant d’empiler les éléments enfants en ligne ou en colonne.
* **Espacement** : une valeur en pixels indiquant l’espace entre les éléments. L’icône située à côté du champ Espacement change selon la direction actuelle, afin que vous sachiez toujours si vous ajustez l’espacement horizontal ou vertical. L’icône fléchée située à côté active ou désactive **Répartir l’espace entre les éléments**, ce qui repousse les éléments enfants vers les extrémités opposées du conteneur.
* **Espace extérieur** : des champs de saisie pour l’espace autour de l’élément, un pour chaque côté, ainsi qu’un bouton de liaison permettant de verrouiller les quatre côtés simultanément.
* **Espace intérieur** : des champs de saisie pour l’espace à l’intérieur de l’élément sur chaque axe, avec un bouton de liaison permettant de verrouiller les deux axes simultanément.

La section Mise en page n’apparaît que lorsqu’au moins un réglage de mise en page est appliqué à l’élément sélectionné. Les nœuds de texte simples, sans espacement ni propriétés de mise en page, masquent entièrement cette section afin que l’éditeur reste concis.

Consultez le [guide du Visual Editor](/fr/ko/design/visual-editor) pour les sections **Texte**, **Couleur**, **Bordure** et **Image**.
