使用 Replit Agent 制作专业的动画视频。用日常语言描述你想要的视频，Agent 就能生成可导出、可分享的动态图形——无需视频剪辑技能，也无需聘请昂贵的制作公司。

<div id="viso-geral">
  ## 概览
</div>

Replit Animation 让你只需与 Agent 对话，就能创建精美的动态图形。这些动画是用 React 构建的程序化动画——并未使用 Remotion，而是依靠多个网页动画库与自定义 Agent skills 的组合来实现。它不同于 Runway 或 Sora 那样由 AI 生成的视频。你的视频可以包含文字叠加、平滑过渡、AI 生成的图像等内容。

视频会在预览面板中自动循环播放，你可以像构建其他应用一样，通过与 Agent 对话来不断迭代。

**所有创作者均可使用**，包括免费方案。

<div id="criando-um-vdeo-animado">
  ## 创建动画视频
</div>

在 Replit 主页上，你可以通过以下两种方式开始创建动画视频：

<div id="opo-1-digite-um-prompt">
  ### 选项 1：输入 prompt
</div>

在首页选择 **App** 标签页，输入 prompt 描述你想要的视频。Agent 会自动识别与视频相关的 prompt，并选择动画视频技术栈。

prompt 示例：

* “为我的新气泡水品牌制作一个宣传视频”
* “创建一个 30 秒的解说视频，介绍大语言模型的工作原理”
* “为得克萨斯州奥斯汀市制作一个电影质感的宣传视频”

  <img src="/assets/mirror/animation-prompt-box-ba406b8e594a.png" alt="Replit 首页，App 标签页显示已选中 Animation，prompt 内容为 Create a launch video for my new app" width="1200" height="675" data-path="images/replitai/animation-prompt-box.png" />
</Frame>

<div id="opo-2-selecione-no-menu-suspenso">
  ### 方式 2：从下拉菜单中选择
</div>

1. 进入首页的 **App** 标签页。
2. 打开应用类型下拉菜单。
3. 选择 **Animation**。
4. 输入你想创建的视频的描述。

<Frame>
  <img src="/assets/mirror/animation-entry-point-b22d4942db44.png" alt="应用类型下拉菜单，在 Web app、Mobile app、Data Visualization、3D Game 和 Automation 等选项中选中了 Animation" width="1200" height="675" data-path="images/replitai/animation-entry-point.png" />
</Frame>

Agent 开始构建后，会生成动画并在预览面板中展示。你可以观看视频自动循环播放，也可以继续对话进行修改。

<div id="iterando-sobre-o-seu-vdeo">
  ## 迭代优化你的视频
</div>

Agent 生成第一版后，你可以通过对话不断打磨。以下几种方式效果不错：

* **使用 Chat 输入框中的 Enhance Prompt 按钮**，它专门针对视频 prompt 做了调优。
* **要求改进** —— 看过第一版后，说一句“把这个做得更好”或“在场景内加入更复杂的动画，更有创意一些”，通常能得到不错的效果。
* **明确说明**你想修改的地方 —— 例如“让转场更流畅”“把配色改成深蓝配金色”或“在结尾加一段 Logo 亮相”。

多试几个不同的 prompt，通常至少会有一个结果让你满意。

<div id="exportando-o-seu-vdeo">
  ## 导出视频
</div>

对视频效果满意后，你可以将其导出为 MP4 文件。

1. 在预览面板右上角找到 **Export** 按钮。
2. 选择你需要的质量设置：
   * **分辨率**：720p 或 1080p
   * **帧率**：30fps 或 60fps
3. 选择 **Export**。渲染可能需要几分钟，具体取决于视频的复杂程度。
4. 渲染完成后，MP4 文件会自动下载。

<Frame>
  <img src="/assets/mirror/animation-export-dialog-cf4d777fca06.png" alt="视频导出对话框，显示 Name 字段、设置为 1080p 60fps 的 Quality 下拉菜单以及 Render 按钮" style={{maxWidth: "350px"}} width="662" height="495" data-path="images/replitai/animation-export-dialog.png" />

你也可以选择 **Publish**，分享视频链接。

**导出耗时**：视频越长或越复杂，渲染时间可能长达数分钟。导出在服务器端进行，因此处理期间你可以继续工作。

<div id="casos-de-uso">
  ## 使用场景
</div>

动画视频适用于各种创意和商务需求：

* **产品发布视频** — 用精美的宣传片发布新应用、新功能或新产品。
* **品牌与影视级视频** — 为企业、城市、大学或活动打造视觉丰富的视频。
* **讲解视频** — 用 30–60 秒讲清楚某个产品、功能或概念的运作方式。
* **社交媒体内容** — 为 Twitter/X、LinkedIn、Instagram 或 TikTok 制作吸睛的动态图形。
* **落地页视频** — 为你的网站添加动画首屏或背景视频。
* **融资与投资人动态** — 为重要里程碑制作专业的announcement视频。

<div id="especificaes-do-vdeo">
  ## 视频规格
</div>

| 属性       | 详情                                                    |
| -------- | ----------------------------------------------------- |
| **格式**   | MP4                                                   |
| **分辨率**  | 720p 或 1080p                                          |
| **帧率**   | 30fps 或 60fps                                         |
| **宽高比**  | 16:9 (标准)                                             |
| **渲染方式** | 服务器端渲染；动画库 (通常用于网站) 搭配自定义 Agent skills —— 而非 Remotion |
| **播放方式** | 在预览面板中自动循环播放                                          |

<div id="perguntas-comuns">
  ## 常见问题
</div>

* **可以暂停或播放视频吗？** 预览不提供内置的暂停/播放控件，视频始终自动循环播放。如果你希望视频支持暂停/播放 (或场景选择) ，可以让 Agent 帮你添加——不过添加这些控件有时会影响设计效果，因此你也可以选择保留默认的循环播放。
* **有场景选择功能吗？** 预览中没有内置的场景选择器。如有需要，可以让 Agent 添加场景选择或其他控件；上述注意事项同样适用。

<div id="limitaes">
  ## 限制
</div>

动画视频是一项新功能，目前存在一些你需要了解的限制：

* **仅支持程序化动画**：视频是基于 React 的动态图形，并非 AI 生成的视频 (如 Runway 或 Sora) ——不过你可以自行生成视频并在代码中使用。
* **渲染时间**：复杂动画的导出可能需要数分钟，较简单的视频渲染速度更快。
* **可能需要多次迭代**：虽然许多 prompt 一次就能得到不错的结果，但你可能需要迭代 2–3 个版本才能达到完全符合预期的效果。建议在初始 prompt 上使用 Enhance Prompt 按钮，并在第一个 checkpoint 之后给出反馈。
