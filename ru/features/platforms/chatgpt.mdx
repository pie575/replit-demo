Интеграция Replit в ChatGPT позволяет создавать, обновлять и просматривать Replit Apps прямо в диалоге — без какой-либо настройки. Просто опишите приложение в ChatGPT, а всё остальное сделает Agent.

<div id="what-is-replit-in-chatgpt">
  ## Что такое Replit в ChatGPT
</div>

Replit в ChatGPT связывает ваши диалоги в ChatGPT с мощной платформой разработки Replit. Вы описываете, что хотите создать, а Agent создаёт для вас полностью работающее Replit App. После этого вы можете попросить ChatGPT изменить, обновить или проанализировать приложение — и всё это в обычном диалоге.

<div id="getting-started">
  ## Начало работы
</div>

Выполните следующие шаги, чтобы подключить Replit к ChatGPT и создать своё первое приложение.

<div id="connect-replit-to-chatgpt">
  ### Подключение Replit к ChatGPT
</div>

Подключить Replit к ChatGPT можно двумя способами:

<Accordion title="Подключение через настройки">
  1. Нажмите значок профиля в ChatGPT 2. Перейдите в **Settings** → **Apps &amp;
     Connectors** 3. Найдите **Replit** и нажмите **Connect** 4. Завершите
     авторизацию OAuth, используя свою учётную запись Replit
</Accordion>

<Accordion title="Подключение из беседы">
  1. Начните новую беседу в ChatGPT 2. Вызовите Replit одним из описанных ниже
     способов 3. Если подключения ещё нет, ChatGPT проведёт вас через процесс
     авторизации OAuth
</Accordion>

<div id="invoke-replit-in-chatgpt">
  ### Вызов Replit в ChatGPT
</div>

После подключения вызвать Replit можно тремя способами:

| Способ            | Как использовать                               |
| ----------------- | ---------------------------------------------- |
| Прямое упоминание | Введите `Replit, <request>` в начале сообщения |
| Слэш-команда      | Введите `/Replit` в поле ввода                 |
| Меню поля ввода   | Нажмите кнопку **+** → **More** → **Replit**   |

<div id="create-your-first-app">
  ### Создайте своё первое приложение
</div>

После подключения создайте свой первый Replit App:

1. Начните новый диалог в ChatGPT
2. Вызовите Replit и опишите, что хотите создать (например: «Replit, создай приложение со списком задач и тёмной темой»)
3. Agent сгенерирует приложение и автоматически опубликует его
4. По завершении вы получите ссылку для просмотра приложения

<Note>
  В рамках одного диалога можно работать только с одним Replit App. Если вы создадите новое приложение в том же диалоге, изменится уже существующее. Чтобы создать несколько приложений, начните отдельные диалоги.
</Note>

<div id="features">
  ## Возможности
</div>

* **[Replit AI](/ru/welcome)**: Agent создаёт и публикует приложения по вашим запросам на естественном языке
* **[Project Editor](/ru/learn/projects-and-artifacts/project-editor)**: полнофункциональная среда разработки, доступная прямо из ChatGPT
* **[Publishing](/ru/learn/projects-and-artifacts/replit-deployments)**: приложения развёртываются автоматически и сразу готовы к тому, чтобы поделиться ими

<Accordion title="Что вы можете делать">
  **Создавать:** создавайте новые Replit App, просто описав, что вам нужно. Agent сгенерирует приложение и опубликует его автоматически.

  **Обновлять:** изменяйте приложение прямо в текущей беседе. Попросите ChatGPT добавить функции, исправить ошибки или внести правки — Agent их применит.

  **Изучать:** анализируйте приложение, не внося изменений. Получайте информацию о структуре кода, путях к файлам или поведении приложения.
</Accordion>

<Accordion title="Поддерживаемые форматы файлов">
  В prompt можно включать различные типы файлов:

  | Формат                              | Поддерживается                  |
  | ----------------------------------- | ------------------------------- |
  | PDF                                 | Да                              |
  | CSV                                 | Да                              |
  | Распространённые форматы документов | Да                              |
  | Изображения (исходные файлы)        | Нет (используйте публичные URL) |
  | Видео (исходные файлы)              | Нет (используйте публичные URL) |

  <Note>
    Чтобы добавить изображения или видео в приложение, укажите в prompt публичные URL. Медиафайлы также можно добавить непосредственно в Replit после создания приложения.
  </Note>
</Accordion>

<Accordion title="Время сборки">
  Обычно Agent создаёт приложения за:

  | Сложность приложения                                  | Типичное время сборки |
  | ----------------------------------------------------- | --------------------- |
  | Простое (калькуляторы, небольшие лендинги)            | 2–3 минуты            |
  | Сложное (игры, насыщенные анимации, плотные дашборды) | 3–4 минуты            |
</Accordion>

<div id="billing-and-credits">
  ## Биллинг и кредиты
</div>

Работа, выполненная Replit в ChatGPT, тарифицируется как использование Replit Agent в вашем аккаунте Replit.

<Accordion title="Как работает биллинг">
  * Планы **Core** и **Pro** включают ежемесячные кредиты, которые покрывают Agent, публикацию и базы данных в пределах вашего лимита
  * Вы можете покупать **пакеты кредитов**: они действуют шесть месяцев и не продлеваются автоматически — удобно при всплесках нагрузки во время запуска или для экспериментов
  * Чтобы ограничить расходы, используйте **лимиты использования** и **бюджеты** в настройках биллинга Replit

  Подробнее — в [документации по биллингу ИИ](/ru/billing/ai-billing).
</Accordion>

<div id="current-limitations">
  ## Текущие ограничения
</div>

На данный момент приложение Replit в ChatGPT:

* Может работать только с приложением, созданным в этом конкретном диалоге
* Не может открывать или изменять:
  * приложения, созданные в других чатах ChatGPT;
  * приложения, созданные вами непосредственно в Replit

Полное соответствие возможностям Replit (базы данных, управление Secrets, расширенные настройки Project Editor) появится позже.

<div id="troubleshooting">
  ## Устранение неполадок
</div>

<Accordion title="Replit не отображается в Browse apps">
  Если Replit не отображается в разделе **Browse apps**, проверьте следующее:

  * доступны ли приложения в вашем регионе;
  * включил ли администратор вашего workspace приложение Replit (Business/Enterprise/Edu).
</Accordion>

<Accordion title="Сбои сборки">
  Если сборка завершается с ошибкой, откройте приложение в Replit:

  * проверьте расход ресурсов и биллинг;
  * используйте checkpoint и откаты, чтобы вернуться к предыдущему состоянию;
  * обратитесь за помощью к Agent прямо в Project Editor.
</Accordion>
