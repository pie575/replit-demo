Инструмент Пользовательские настройки в Project Editor позволяет настроить внешний вид,
поведение и сочетания клавиш для вашей учётной записи.

</Frame>

<div id="section">
  ## Возможности
</div>

Настроить процесс создания Replit App можно с помощью следующих категорий настроек.

* **Настройка темы**: выбор светлой или тёмной темы Project Editor
* **Интеллектуальная работа с кодом**: настройка функций на базе ИИ, которые упрощают создание приложений
* **Параметры редактора**: изменение поведения и внешнего вида редактора файлов
* **Управление уведомлениями**: настройка параметров уведомлений
* **Параметры доступности**: адаптация Replit для пользователей с особыми потребностями
* **Сочетания клавиш**: настройка комбинаций клавиш для выполнения типовых действий и навигации по интерфейсу

<div id="section-2">
  ## Использование
</div>

<Accordion title="Как открыть Пользовательские настройки">
  На левой **панели инструментов**:

  1. Выберите <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="All tools icon" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**, чтобы открыть список инструментов Project Editor.
  2. Выберите <img class="icon-svg" src="/assets/mirror/settings-icon-c2664c3691bf.svg" alt="Settings icon" width="16" height="16" data-path="images/icons/settings-icon.svg" /> **Пользовательские настройки**.

  Через **строку поиска**:

  1. Нажмите значок лупы <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="magnifying glass icon" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> вверху, чтобы открыть инструмент поиска
  2. Введите «Пользовательские настройки» и выберите нужный инструмент в результатах поиска.
</Accordion>

<div id="appearance">
  ### Внешний вид (Appearance)
</div>

Настройте следующие параметры внешнего вида Project Editor.

* **Выбор темы**: выберите одну из готовых светлых и тёмных тем, <a href="https://replit.com/themes" target="_blank">тему сообщества</a> или собственную пользовательскую тему
* **Пользовательские темы**: создайте персональную цветовую схему в редакторе [Themes](/ru/ko/features/editor/themes)

<div id="section-3">
  ### Настройки редактора файлов
</div>

Управляйте внешним видом и поведением редактора файлов с помощью следующих настроек.

* **Размер шрифта**: изменение размера текста для удобства чтения
* **Автоматическое закрытие скобок**: автоматическая вставка закрывающей скобки при вводе открывающей
* **Определение отступов**: автоматическое определение параметров отступов при открытии файла
* **Форматирование отступов вставленного текста**: переформатирование вставленного кода в соответствии с правильными отступами
* **Символ отступа**: выбор между пробелами и табуляцией для отступов в коде
* **Размер отступа**: количество столбцов на каждый уровень отступа
* **Перенос строк**: настройка поведения переноса строк
* **Мини-карта**: отображение обзорной схемы кода с навигацией на боковой панели
* **Клавиша-модификатор множественного выбора**: настройка клавиши-модификатора для выбора нескольких файлов
* **Git-статус в дереве файлов**: отображение индикаторов состояния Git в дереве файлов

<div id="section-4">
  ### Интеллектуальные функции работы с кодом
</div>

Настройте инструменты на базе ИИ с помощью следующих параметров.

* **Семантические токены**: подсветка синтаксиса, улучшенная языковым сервером
* **Автодополнение кода с ИИ**: встроенные подсказки кода прямо во время ввода
* **Принятие подсказок по символам фиксации**: автоматическое принятие подсказок кода при вводе определённых символов

<div id="shell-preview">
  ### Настройки Shell и Preview
</div>

Настройте поведение инструментов Shell и Preview.

* **Звуковой сигнал Shell**: воспроизводить звук при возникновении проблемы в инструменте Shell
* **Автоматический предпросмотр**: автоматически открывать вкладку Preview, когда сервер станет доступен
* **Автоматическая переадресация открытых портов**: настройка обработки вновь обнаруженных портов

<div id="section-5">
  ### Уведомления
</div>

Управляйте следующими настройками уведомлений.

* **Звуковые уведомления Agent**: воспроизводить звук, когда Agent запрашивает обратную связь
* **Push-уведомления Agent**: получать push-уведомления на мобильное устройство, когда Agent запрашивает обратную связь

<div id="section-6">
  #### Оповещения Production
</div>

**Production Alerts** — это отдельная настройка уведомлений по электронной почте, которая позволяет отслеживать состояние опубликованных приложений. Она работает независимо от писем о продуктах и маркетинговых рассылок, поэтому вы получаете только важную информацию без лишних уведомлений.

При включении **Production Alerts** вы будете получать электронные письма о следующем:

* **Инциденты с доступностью**: вы получите уведомление, если опубликованное приложение перестанет работать или возникнут проблемы с его доступностью.
* **Уязвимости безопасности**: вы получите уведомление об уязвимостях, обнаруженных в программном обеспечении, от которого зависит ваше приложение, чтобы устранить их до возникновения проблем.
* **Обновления моделей**: вы получите уведомление, когда используемая приложением языковая модель изменится или потребует вашего внимания.

<Frame>
  <img src="/assets/mirror/production-alerts-highlight-bb76079f20fd.png" alt="Раздел Production Alerts в настройках уведомлений: красным прямоугольником выделены переключатель уведомлений Production и раскрывающийся список уровня серьёзности предупреждений безопасности" width="2400" height="1364" data-path="images/workspace/production-alerts-highlight.png" />
</Frame>

Чтобы найти эту настройку:

1. Откройте **Settings** в меню учётной записи.
2. Выберите вкладку **Personalization**.
3. Прокрутите до раздела **Email Notifications** и найдите **Production Alerts**.

Если опубликованное приложение использует устаревшую языковую модель, Replit подготовит черновик задачи для обновления до поддерживаемой модели. Вы получите электронное письмо со ссылкой на эту задачу и сможете завершить обновление после проверки.

<div id="section-7">
  ### Доступность
</div>

Вы можете настроить следующие параметры доступности.

* **Доступный вывод терминала**: включает совместимость со средствами чтения с экрана для инструментов Shell и Console

<div id="section-8">
  ### Сочетания клавиш
</div>

Чтобы открыть настройки сочетаний клавиш, выберите вкладку **Keyboard shortcuts** в инструменте Пользовательские настройки.

Найти нужное сочетание можно двумя способами:

* **По названию**: введите название или описание сочетания клавиш в поле поиска
* **По комбинации клавиш**: выберите <img class="icon-svg" src="/assets/mirror/keyboard-7ba19771b671.svg" alt="keyboard icon" width="16" height="16" data-path="images/icons/keyboard.svg" /> и нажмите нужную комбинацию клавиш

Управлять сочетаниями можно так:

* **Добавить**: выберите **Add shortcut**
* **Изменить**: выберите значок карандаша <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="pencil icon" width="16" height="16" data-path="images/icons/pencil-icon.svg" />
* **Удалить**: выберите значок корзины <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="trash icon" width="16" height="16" data-path="images/icons/trash-icon.svg" />
