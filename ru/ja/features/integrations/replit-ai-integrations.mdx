С интеграциями Replit AI создавать приложения на основе ИИ проще простого. Вы можете сразу начать работу с моделями OpenAI, Anthropic, Google и OpenRouter — не нужно настраивать аккаунты разработчика и управлять ключами API. Replit берёт всё на себя.

<div id="replit-ai">
  ## Что такое интеграции Replit AI?
</div>

Интеграции Replit AI дают управляемый доступ к моделям ИИ от ведущих провайдеров. Вы можете создавать чат-приложения, генераторы контента и инструменты на базе ИИ, не покидая Replit. Не нужно заводить аккаунты у сторонних разработчиков, искать учётные данные API или отслеживать отдельные счета.

При использовании интеграций Replit AI управлением учётными данными провайдеров ИИ занимается Replit, а оплата взимается по тарифам публичного API. Расход списывается с кредитов Replit и отображается на [странице использования](/ru/ja/billing/managing-spend) отдельно по каждому Replit App.

<Note>
  Для интеграций Replit AI требуется платный план (Core, Pro или Enterprise). На [плане Starter](/ru/ja/billing/plans/starter-plan) можно создавать ИИ-приложения с собственным ключом API. См. [доступность по планам](#plan-availability).
</Note>

<div id="section">
  ## Возможности
</div>

Интеграции Replit AI упрощают разработку с ИИ благодаря встроенному доступу и прозрачному биллингу:

* **Без настройки**: чтобы начать, не нужны ни аккаунты разработчика, ни ключи API
* **Управляемые учётные данные**: Replit берёт на себя аутентификацию у провайдеров и управление учётными данными
* **Прозрачный биллинг**: вы платите по публичным тарифам API, списание идёт с кредитов Replit
* **Отслеживание потребления**: смотрите расход по каждому Replit App на странице использования
* **Поддержка любого стека**: работает со всеми языками программирования и фреймворками
* **BYOK по желанию**: можно подключить собственные ключи API, если предпочитаете свои учётные данные

<div id="section-2">
  ## Начало работы
</div>

<div id="replit">
  ### Использование учётных данных, управляемых Replit
</div>

На платном плане при упоминании в prompt возможностей ИИ или конкретного провайдера (OpenAI, Anthropic, Google или OpenRouter) Agent по умолчанию использует интеграцию Replit AI:

<AiPrompt>
  Create a web app that uses OpenAI to summarize articles
</AiPrompt>

Понять, какая интеграция используется, можно по первому ответу на prompt — найдите в нём **«OpenAI (управляется Replit)»**, **«Anthropic (управляется Replit)»**, **«Google (управляется Replit)»** или **«OpenRouter (управляется Replit)»**. Это означает, что Agent использует учётные данные Replit вместо того, чтобы запрашивать ваш собственный ключ API.

**При первой сборке нового приложения**: когда вы отправляете первый prompt для создания нового приложения с возможностями ИИ, интеграция Replit AI подбирается автоматически. Agent сразу начинает сборку, используя управляемые учётные данные.

**Для существующего Replit App**: если Agent определяет, что в существующий Replit App нужно добавить возможности ИИ, он прямо сообщает в редакторе проекта, что будет использовать интеграцию Replit AI. Появится запрос на подтверждение:

Использование отслеживается автоматически, а оплата начисляется на ваш аккаунт Replit по расценкам публичного API.

<div id="api">
  ### Использование собственного ключа API
</div>

Если вместо интеграции Replit AI вы хотите использовать собственные учётные данные от OpenAI, Anthropic, Google или другого провайдера, у вас есть несколько вариантов:

**При первой сборке нового приложения**: укажите в prompt, что хотите использовать собственный ключ API:

<AiPrompt>
  Create a web app that uses OpenAI to summarize articles. Use my own OpenAI API key.
</AiPrompt>

В ответе появится название провайдера (без пометки «управляется Replit») — это значит, что Agent запросит ключ API.

**Для существующего Replit App**: когда Agent сообщит об использовании интеграции Replit AI и покажет запрос на подтверждение, нажмите «Отклонить» вместо «Одобрить».

В обоих случаях Agent продолжит сборку до первой контрольной точки и только затем запросит ключ API. Так Agent сначала настроит структуру проекта, а потом сделает паузу, чтобы получить учётные данные и продолжить работу.

При использовании собственного ключа API оплату будет взимать напрямую провайдер, а не кредиты Replit.

<div id="section-4">
  ## Поддерживаемые провайдеры
</div>

Интеграции Replit AI на данный момент поддерживают следующих провайдеров:

* **OpenAI**: мультимодальные модели для генерации текста, рассуждений и работы со звуком. Поддерживаются chat completions, ответы, генерация изображений, расшифровка речи (`gpt-4o-transcribe`, `gpt-4o-mini-transcribe`) и аудиовывод (`gpt-audio`, `gpt-audio-mini`).
* **Anthropic**: мультимодальные модели для рассуждений, написания текстов и программирования. Поддерживается работа с Messages API и веб-поиском.
* **Google (Gemini)**: мультимодальные модели для генерации текста и рассуждений. Поддерживается генерация текста и изображений.
* **OpenRouter**: доступ к моделям таких провайдеров, как Microsoft (серия Phi), Meta (серия Llama), Mistral, Qwen, DeepSeek, Nvidia, Amazon и других.

<Note>
  Интеграции Replit AI поддерживают вывод в виде **текста, изображений и аудио**. Вывод видео не поддерживается. Если вам нужна генерация видео, придётся использовать собственный ключ API провайдера, который предоставляет такую возможность.
</Note>

<div id="openrouter-2">
  ## Конфиденциальность и доступность OpenRouter
</div>

При использовании OpenRouter через интеграцию Replit AI запросы отправляются с определёнными настройками конфиденциальности, которые защищают ваши данные. Эти настройки важно понимать, так как от них зависит, какие модели будут доступны.

<div id="section-6">
  ### Настройки конфиденциальности для пользователей самообслуживания
</div>

Для индивидуальных и командных пользователей Replit применяет к запросам OpenRouter следующие настройки конфиденциальности по умолчанию:

* **Обучение на платных эндпоинтах отключено**: провайдеры платных моделей не используют данные для обучения
* **Обучение на бесплатных эндпоинтах включено**: провайдеры бесплатных моделей могут обучаться на промптах и ответах моделей
* **Публикация с бесплатных эндпоинтов включена**: бесплатные провайдеры могут публиковать промпты и ответы моделей в общедоступных наборах данных
* **Логирование ввода и вывода отключено**: OpenRouter не сохраняет запросы и ответы ради скидки в 1% на оплату
* **Аналитические файлы cookie отключены**: аналитические файлы cookie не используются

Эти настройки ставят конфиденциальность на первое место, обеспечивая при этом доступ к максимально широкому кругу моделей. Однако модели, требующие настроек конфиденциальности, отличных от указанных выше, **могут быть недоступны**.

<div id="enterprise">
  ### Настройки конфиденциальности в Enterprise
</div>

Для организаций Enterprise Replit применяет более строгие меры контроля приватности:

* **Только эндпоинты с нулевым хранением данных (ZDR)**: доступны только модели с политикой нулевого хранения данных
* Также действуют все перечисленные выше настройки конфиденциальности для пользователей с самообслуживанием
* Благодаря этому запросы Enterprise направляются только к эндпоинтам, которые не сохраняют данные

Поскольку в Enterprise используются только ZDR-эндпоинты, **выбор доступных моделей ограничен сильнее**, чем у пользователей с самообслуживанием. Такой компромисс обеспечивает наивысший уровень приватности данных для корпоративных рабочих нагрузок.

<div id="section-7">
  ## Доступность в планах
</div>

Для интеграций Replit AI требуется платный план. Способ доступа зависит от вашего плана.

<div id="starter">
  ### Starter (бесплатный)
</div>

В плане Starter интеграции Replit AI отключены. Создавать AI-приложения можно с собственным ключом API. См. раздел [Использование собственного ключа API](#bringing-your-own-api-key).

<div id="core">
  ### Core
</div>

На плане Core вы можете создавать ИИ-приложения с помощью интеграции Replit AI, используя учётные данные под управлением Replit, — управлять ключами API не требуется.

<div id="proenterprise">
  ### Pro и Enterprise
</div>

В организациях Pro и Enterprise доступ к интеграции Replit AI по умолчанию отключён. Администраторы организации могут управлять доступом на странице настроек организации:

1. Перейдите в настройки организации
2. Найдите раздел интеграции Replit AI
3. Включите или отключите доступ для организации

После включения участники организации смогут использовать интеграцию Replit AI в своих приложениях. Всё потребление отслеживается, а счёт выставляется на аккаунт организации. Если доступ отключён, участникам придётся указывать собственные ключи API для работы с провайдерами моделей ИИ.

<div id="section-8">
  ## Сценарии использования
</div>

Создавайте мощные ИИ-приложения на любом стеке:

* **Генерация контента**: краткое изложение статей, создание описаний, подготовка материалов
* **Аналитика и инсайты**: извлечение ключевой информации, анализ тональности, классификация текста
* **Диалоговые интерфейсы**: создание чат-ботов и ИИ-ассистентов
* **Преобразование текста**: перевод, переписывание и форматирование контента
* **Помощь с кодом**: генерация фрагментов кода, объяснение алгоритмов, ревью кода
