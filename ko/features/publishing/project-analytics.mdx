Project Analytics는 사람들이 게시된 웹 앱을 어떻게 찾고 사용하는지 보여줍니다. **Growth** 창을 열어 방문자 추이, 트래픽 소스, 사용자 지정 이벤트를 확인하세요.

Replit은 지원되는 게시된 앱의 기본 트래픽 지표를 수집합니다. 유료 플랜에서는 Agent가 사용자 지정 이벤트를 추가하고 분석 데이터에 관한 질문에 답변할 수 있습니다.

<div id="before-you-start">
  ## 시작하기 전에
</div>

Project Analytics를 사용하려면 다음 조건이 필요합니다.

* **게시된 website.** 분석은 website [artifact](/ko/features/projects-and-artifacts/artifacts)를 지원하며, mobile app이나 그 외 artifact 유형에서는 이벤트를 수집하지 않습니다.
* **지원되는 Deployment.** Project Analytics는 [Autoscale](/ko/features/publishing/deployment-types#autoscale), [Reserved VM](/ko/features/publishing/deployment-types#reserved-vm), [Static](/ko/features/publishing/deployment-types#static) Deployment를 지원합니다.
* **Advanced analytics를 위한 paid plan.** 사용자 지정 이벤트와 Agent를 통한 분석 쿼리는 paid plan에서 사용할 수 있습니다.
* **다음 release에 분석 활성화.** Replit은 **Enable analytics**를 켜고 앱을 게시하거나 republish한 시점부터 이벤트를 수집합니다.

<div id="open-project-analytics">
  ## Project Analytics 열기
</div>

1. Project Editor에서 project를 엽니다.
2. **Tools**를 선택합니다.
3. **Replit Cloud** 아래에서 **Growth**를 선택합니다.

<Note>
  **Growth** pane은 앱을 게시하기 전까지 잠겨 있습니다. 게시 전에는 **Go to Publishing**을
  통해 이동하라는 안내가 표시됩니다.
</Note>

분석 데이터는 published app에 트래픽이 발생한 뒤부터 표시됩니다. 새 앱은 방문자가 생기기 전까지 charts가 비어 있을 수 있습니다.

<div id="review-default-analytics">
  ## 기본 분석 살펴보기
</div>

기본 분석은 IP 트래픽 데이터를 사용해 다음 지표를 보여줍니다.

* **Visitors**: 선택한 기간의 대략적인 순 방문자 수입니다.
* **Visitors over time (hour)** 또는 **Visitors over time (day)**: 선택한 기간 동안 방문자 활동이 어떻게 변하는지 보여줍니다.
* **Top Pages**: 트래픽이 가장 많은 페이지입니다.
* **Top Referrers**: 앱으로 트래픽을 유입시킨 웹사이트입니다.
* **Top Countries**: 방문자의 대략적인 국가입니다.
* **Top Browsers**: 방문자가 사용한 브라우저입니다.
* **Top Devices**: 방문자가 사용한 기기 유형입니다.

시간 범위 메뉴에서 6시간부터 30일까지의 기간을 선택해 확인할 수 있습니다. 방문자 합계는 각 기간을 같은 길이의 직전 기간과 비교해 보여줍니다.

앱에서 [Replit Auth](/ko/features/auth-and-identity/authentication)를 사용하는 경우, 해당 pane에 선택한 기간의 **Unique Logged in Users**도 함께 표시됩니다.

<Note>
  방문자 수는 대략적인 값입니다. 네트워크와 브라우저 데이터를 기반으로 하기 때문에, 한 사람이
  여러 기기나 여러 달에 걸쳐 둘 이상의 방문자로 집계될 수 있습니다.
</Note>

<div id="add-custom-events-with-agent">
  ## Agent로 사용자 지정 이벤트 추가하기
</div>

사용자 지정 이벤트는 앱에서 중요한 동작을 측정합니다. 가입 완료, plan 선택, 양식 제출, 구매 완료 등이 그 예입니다.

<Steps>
  <Step title="Agent로 지표 추가하기">
    **Growth**를 엽니다. **Advanced analytics**에서 **Add metrics with
    Agent**를 선택합니다. 측정하려는 동작을 Agent에게 알려주면, Agent가 앱의
    해당 지점에 이벤트 추적을 추가합니다.
  </Step>

  <Step title="분석 활성화 후 게시하기">
    **Publishing**을 열고 새 게시 또는 재게시를 시작합니다. **Suggested
    add-ons**에서 **Enable analytics**를 켠 다음 앱을 게시합니다. Replit은
    이 release부터 page views와 사용자 지정 이벤트를 수집하기 시작합니다.
  </Step>
</Steps>

<Tip>
  Chat에서 바로 Agent에게 분석 설정을 요청할 수도 있습니다. 앱이나 측정 목표가
  달라지면 언제든지 Agent에게 이벤트 추가나 업데이트를 요청하세요.
</Tip>

Replit이 게시된 앱에 분석 추적기를 추가하므로, 추적 스크립트나 website ID, 분석 환경 변수를 따로 추가할 필요가 없습니다.

<Warning>
  사용자 지정 이벤트 이름이나 속성에 secret, 개인 정보, 방문자가 자유롭게 입력한
  내용을 포함하지 마세요.
</Warning>

<div id="ask-agent-about-your-analytics">
  ## Agent에게 분석 데이터 물어보기
</div>

앱이 데이터를 수집한 후에는 **Advanced analytics**의 chip을 사용하세요.

* **Summarize my analytics**: Agent가 지난 7일간의 project 분석 데이터를 요약합니다.
* **Suggest project improvements**: Agent가 분석 데이터를 검토해 project에서 개선할 점을 추천합니다.

Agent에게 직접 구체적인 질문을 할 수도 있습니다.

<AiPrompt>
  지난 7일간의 방문자 수와 가입 완료 수를 비교해 줘. 일별 추세를 보여주고 전환율이 가장 높은 페이지를 알려줘.
</AiPrompt>

Agent는 page views, 트래픽 소스, 사용자 지정 이벤트, 이벤트 속성, 퍼널을 분석할 수 있습니다. project의 분석 데이터를 바탕으로 집계된 결과를 반환합니다.
