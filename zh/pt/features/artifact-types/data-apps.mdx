<div id="o-que-uma-visualizao-de-dados">
  ## 什么是数据可视化？
</div>

数据可视化是你通过与 Agent 对话构建的交互式仪表板或报表工具。只需描述你想可视化的内容以及数据的存储位置，Agent 就会自动选出合适的 KPI、图表类型和布局，用一个 prompt 生成一个完整的仪表板。

核心概念：

* **一步生成**：描述你的目标和数据源，Agent 即可构建出包含合适图表和指标的完整仪表板
* **连接数据源**：从数据库、[数据仓库连接器](/zh/pt/connectors/warehouses/overview)、外部 API 或上传的文件中提取数据
* **内置功能**：每个仪表板都自带刷新、自动刷新、导出为 PDF、将图表导出为 CSV 以及明暗模式
* **分析摘要**：Agent 会根据你的需求和得到的数据生成洞察
* **多个 artifact**：数据可视化可以与[同一项目](/zh/pt/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project) 中的其他 artifact 共享同一个后端和数据库

<div id="como-usar-o-data-visualization">
  ## 如何使用 Data Visualization
</div>

<div id="criando-a-partir-de-um-prompt">
  ### 通过 prompt 创建
</div>

在主页上选择 **App** 标签页，描述你想要的仪表板。Agent 会识别与数据相关的 prompt，并自动选用 Data Visualization 技术栈。

**prompt 示例：**

* “构建一个销售分析仪表板，按区域跟踪收入”
* “创建一个报表工具，将我们的月度指标可视化”
* “基于我们 BigQuery 中的销售数据构建一个仪表板，展示表现最好的产品”
* “连接 Snowflake 并创建一个客户流失分析仪表板”

<div id="criando-a-partir-do-menu-suspenso">
  ### 从下拉菜单创建
</div>

1. 前往主页上的 **App** 标签页。
2. 打开应用类型下拉菜单。
3. 选择 **Data Visualization**。
4. 描述你想构建的仪表板或数据工具。

<div id="conectando-se-a-data-warehouses">
  ### 连接到数据仓库
</div>

通过[数据仓库连接器](/zh/pt/connectors/warehouses/overview)将数据可视化连接到 BigQuery、Databricks 或 Snowflake，基于现有数据集构建仪表板。

当你查询数据仓库中的数据时，Agent 会通过并行多智能体搜索来探索你的 schema 和数据集，从而加快探索速度，并帮助 Agent 为仪表板挑选合适的表和字段。

要开始使用，请在项目的 [Integrations](/zh/pt/features/integrations/overview) 中配置一个数据仓库连接器，然后告诉 Agent 你想要可视化的内容。

<div id="adicionando-filtros-e-recursos">
  ### 添加筛选器和功能
</div>

Agent 构建好仪表板后，你可以让它添加筛选器、下钻分析或其他交互功能。例如，让 Agent 添加日期范围筛选器、区域选择器或搜索栏。

<div id="exportando-e-compartilhando">
  ### 导出与共享
</div>

* **导出为 PDF**：将整个仪表板导出为 PDF，便于共享或离线查看。
* **将图表导出为 CSV**：将单个图表的数据下载为 CSV 文件，以便在电子表格或其他工具中做进一步分析。
* **分析文档**：让 Agent 根据仪表板中的数据生成一份详细的分析文档。

<div id="o-que-voc-pode-construir">
  ## 你可以构建什么
</div>

* **分析仪表板**：追踪收入、注册量、参与度等关键指标随时间的变化
* **报表工具**：构建内部报表，让相关方无需直接访问数据库即可筛选和探索数据
* **数据探索界面**：以可视化的方式浏览和查询数据集
* **监控面板**：展示来自 API、数据库或外部服务的实时或准实时数据

<div id="perguntas-frequentes">
  ## 常见问题
</div>

<Accordion title="我可以连接哪些数据源？">
  你可以从项目的 Replit Database、数据仓库连接器 (BigQuery、Databricks、Snowflake) 、外部 API 或上传的 CSV 等文件中提取数据。数据仓库连接可通过 [Integrations](/zh/pt/features/integrations/overview) 配置。
</Accordion>

<Accordion title="我可以自定义外观吗？">
  可以。你可以通过对话来自定义颜色、布局和字体样式——只需让 Agent 匹配你的品牌风格或调整设计即可。仪表板还支持浅色和深色模式。
</Accordion>

<Accordion title="Agent 会帮我分析数据吗？">
  仪表板构建完成后，Agent 会根据你的需求和生成的数据输出一份分析摘要。你也可以要求生成更详细的分析文档。
</Accordion>

<Accordion title="我可以把数据可视化与其他类型的 artifact 结合起来吗？">
  可以。你可以在[同一个项目](/zh/pt/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project) 中，将数据可视化与[网页应用](/zh/pt/features/artifact-types/web-apps)、[幻灯片演示](/zh/pt/features/artifact-types/slide-decks)或其他类型的 artifact 结合使用。它们共享同一个后端和数据库。
</Accordion>
