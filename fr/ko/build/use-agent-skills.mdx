Les compétences enseignent de nouvelles capacités à Agent : vos patterns préférés, les détails d&#39;une bibliothèque, les règles d&#39;un système de design ou la solution à un problème que vous avez déjà résolu. Joignez-les à un message, installez-les dans un projet ou choisissez-les comme point de départ d&#39;un nouveau projet.

<div id="skill">
  ## Utiliser une compétence dans le chat
</div>

Le moyen le plus rapide d&#39;utiliser les compétences consiste à les joindre à un message unique — aucune installation n&#39;est nécessaire.

<Frame>
  <img src="/assets/mirror/agent-skills-picker-ee4058454475.png" alt="Sélecteur de compétences ouvert depuis le bouton + à côté de la zone de saisie du chat, affichant la liste des compétences avec Ad Creative, AI Recruiter, AI SDR et AI Secretary" width="723" height="529" data-path="images/replitai/agent-skills-picker.png" />
</Frame>

<Steps>
  <Step title="Ouvrir le sélecteur de compétences">
    Cliquez sur le bouton **+** à côté de la zone de saisie du chat, puis sélectionnez **Utiliser une compétence**.
  </Step>

  <Step title="Parcourir et sélectionner une compétence">
    Parcourez les compétences par catégorie : Business &amp; finance, Creative, Research &amp; analysis, etc. Sélectionnez une ou plusieurs compétences à joindre à votre message.
  </Step>

  <Step title="Envoyer votre message">
    Saisissez votre demande et envoyez-la. Agent n&#39;utilise les compétences sélectionnées que pour ce message. Des puces de compétences s&#39;affichent sur le message afin que vous voyiez lesquelles sont actives.
  </Step>
</Steps>

Par exemple, joignez **Stock Analyzer** et demandez à Agent de rédiger un rapport de recherche boursière, ou joignez **Deep Research** pour qu&#39;Agent étudie un sujet et en produise un résultat structuré.

<Tip>
  Les compétences jointes dans le chat n&#39;installent rien dans votre projet. Elles sont immédiatement utilisables dans tous les projets.
</Tip>

<div id="skill-2">
  ## Démarrer un projet avec une compétence
</div>

Lorsque vous créez un projet, vous pouvez choisir une compétence éprouvée comme point de départ. Agent utilise les instructions de la compétence pour configurer votre projet.

<Steps>
  <Step title="Ouvrir le sélecteur de point de départ">
    Dans l’écran Nouveau projet, cliquez sur **+**, puis sélectionnez **Utiliser une compétence**.
  </Step>

  <Step title="Choisir une compétence">
    Explorez des compétences sélectionnées telles que **AI SDR**, **SEO Auditor**, **Ad Creative** et **Programmatic SEO**. Choisissez celle qui correspond au type d’application que vous souhaitez créer.
  </Step>

  <Step title="Décrire votre application">
    Expliquez à Agent ce que vous souhaitez créer. Agent crée votre projet de A à Z en appliquant les modèles et les règles de la compétence.
  </Step>
</Steps>

<div id="skill-3">
  ## Installer des compétences dans un projet
</div>

Installez-les pour qu’Agent applique systématiquement les compétences dans toutes les conversations du projet. Les compétences installées sont stockées dans le répertoire `/.agents/skills` du projet et persistent d’une session de chat à l’autre.

<div id="skills">
  ### Installer depuis le panneau Skills
</div>

Ouvrez le **panneau Skills** dans Project Editor et sélectionnez l’onglet **Discover** pour rechercher des compétences créées par la communauté. Lorsque vous trouvez celle qui vous intéresse, cliquez sur **Install** pour l’ajouter automatiquement à votre projet.

<Frame>
  <img src="/assets/mirror/agent-skills-discover-732b2b0c488a.png" alt="Onglet Discover affichant des compétences créées par la communauté, avec recherche et bouton d’installation" width="2542" height="1850" data-path="images/replitai/agent-skills-discover.png" />
</Frame>

Par exemple, pour créer un site portfolio avec des animations avancées, vous pouvez installer les compétences suivantes :

* **GSAP React** — apprend à Agent à créer des animations déclenchées au défilement, des révélations de texte et des tracés de chemins SVG
* **Tailwind design system** — fournit à Agent des modèles Tailwind CSS pour la typographie, l’espacement et les transitions entre les vues
* **Find skills** — apprend à Agent à rechercher et installer de nouvelles compétences à votre place

<Tip>
  Vous pouvez également installer des compétences via le [CLI npx skills](https://github.com/vercel-labs/skills) :

  ```bash theme={null}
  npx skills <skill> -a replit
  ```
</Tip>

<div id="skill-4">
  ### Créer une compétence à partir d&#39;une conversation
</div>

La façon la plus naturelle de créer une compétence consiste à passer par une conversation avec Agent. Après avoir résolu un problème ensemble ou exploré une nouvelle bibliothèque, demandez à Agent de consigner ce qu&#39;il a appris :

<AiPrompt>
  Research best practices for GSAP React integration and create a skill for this project.
</AiPrompt>

Agent s&#39;appuie sur l&#39;ensemble du contexte de la conversation pour rédiger un fichier de compétence détaillé. Cela fonctionne particulièrement bien après une session de débogage au cours de laquelle vous avez développé une compréhension commune du problème.

<div id="skill-5">
  ### Rédiger une compétence personnalisée
</div>

Pour les cas d&#39;usage avancés, rédigez vos propres compétences en suivant la [spécification Compétences Agent](https://agentskills.io/specification). Dans la barre latérale des fichiers, activez **Show Hidden Files**, ouvrez `/.agents/skills/` et créez un fichier Markdown. Vous gardez ainsi un contrôle total sur ce qu&#39;Agent sait et sur la façon dont il se comporte.
