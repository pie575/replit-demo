<div id="section">
  ## 创建自定义主题
</div>

按照以下步骤创建并自定义专属主题：

1. 打开[设置](https://replit.com/settings)，进入 **用户** → **个性化** (或 **主题** 部分)
2. 选择 **创建新主题**
3. 输入标题，选择配色方案 (浅色或深色) ，并添加说明 (可选)
4. 选择 **创建主题**，打开主题编辑器

全局主题设置用于控制界面的整体外观：

* **背景**：设置大多数界面区域的基础色
* **轮廓**：控制边框和分隔线的颜色
* **前景**：决定文本和图标的颜色
* **主色**：定义按钮和交互元素的颜色
* **正向色**：用于 **运行** 按钮等表示成功的指示元素
* **负向色**：用于错误和破坏性操作的警告提示

选择 **应用主题**，即可立即开始使用自定义主题。

<div id="section-2">
  ## 语法高亮
</div>

自定义各类代码元素的显示方式，提升可读性和理解效率。

<Tip>
  合理的语法高亮可帮助你快速浏览并理解代码。请选择彼此协调且与背景有足够对比度的颜色。
</Tip>

<Accordion title="语法高亮元素">
  | 元素        | 说明                                       |
  | --------- | ---------------------------------------- |
  | **变量名**   | 适用于未使用声明关键字的变量                           |
  | **变量定义**  | 为使用 `const` 或 `var` 等关键字定义的变量名着色         |
  | **函数引用**  | 适用于函数调用                                  |
  | **函数定义**  | 为声明中的函数名着色                               |
  | **关键字**   | 高亮显示 `import`、`function`、`return` 等语言关键字 |
  | **属性名**   | 为通过变量访问的属性着色                             |
  | **属性定义**  | 用于定义对象属性                                 |
  | **函数属性**  | 适用于调用对象上的方法                              |
  | **标签名**   | 用于 HTML 和 JSX 标签                         |
  | **类型名**   | 为类型化语言中的类型注释着色                           |
  | **类名**    | 适用于类的声明和引用                               |
  | **属性名**   | 高亮显示 HTML 和 JSX 属性                       |
  | **注释**    | 适用于所有代码注释                                |
  | **字符串**   | 为字符串字面量着色                                |
  | **数值**    | 高亮显示数值                                   |
  | **布尔值**   | 设置布尔值 (`true`/`false`) 的格式               |
  | **正则表达式** | 为正则表达式模式着色                               |
  | **运算符**   | 高亮显示 `+`、`-`、`*`、`/` 等运算符                |
  | **括号**    | 在适当情况下为方括号和尖括号着色                         |
</Accordion>

<div id="section-3">
  ## 主题设计最佳实践
</div>

请遵循以下准则，打造既美观又实用的主题：

<div id="section-4">
  ### 颜色与对比度
</div>

* **平衡对比度**：确保背景与前景元素之间有足够的差异
* **打造统一的配色方案**：选择相互协调而非彼此冲突的颜色
* **保持亮度一致**：让各类语法元素的亮度水平相近
* **兼顾无障碍设计**：避免低对比度的搭配，照顾有视觉障碍的用户

<Warning>
  请避免常见的主题设计问题：

  * 语法元素之间亮度差异过大
  * 造成视觉不协调的配色组合
  * 代码与背景之间对比度不足
</Warning>

<div id="section-5">
  ## 管理主题
</div>

在[设置](https://replit.com/settings)的**用户** → **个性化** (或**主题**部分) 中，你可以查看和管理所有已安装的主题。

<div id="section-6">
  ### 切换主题
</div>

点击主题名称旁边的按钮，即可将其设为当前主题。

<div id="section-7">
  ### 编辑主题
</div>

点击三点菜单并选择**编辑**，即可修改自定义主题。

<Note>
  你只能编辑或删除自己创建的自定义主题，默认主题和其他用户创建的主题无法修改。
</Note>

<div id="section-8">
  ### 删除主题
</div>

在三点菜单中选择**删除**，即可删除自定义主题。

<div id="section-9">
  ## 探索社区主题
</div>

前往[主题探索页面](https://replit.com/themes)，发现由 Replit 社区创建的主题。

<div id="section-10">
  ### 查找主题
</div>

* 按名称搜索，找到“Atom One Dark”等特定主题
* 按作者筛选，浏览特定创作者的主题
* 按配色方案浏览，查找浅色或深色主题
* 按特定颜色搜索，找到符合你喜好的主题

安装主题前，你可以先预览，看看它在项目编辑器中的实际效果。

  ## 从 VS Code 迁移

<div id="section-11">
  ## 发布主题
</div>

若要将自定义主题分享给 Replit 社区，请按以下步骤操作：

1. 打开自定义主题的主题编辑器
2. 点击**发布**按钮
3. 填写标题和说明字段
4. 提交主题

发布后，您的主题会显示在主题探索页面中，其他用户可以预览并安装。
