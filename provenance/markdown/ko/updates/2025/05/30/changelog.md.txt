## 플랫폼 업데이트

### 미리보기 빈 상태 개선

Agent 애플리케이션의 미리보기 경험이 이제 빈 상태와 자동 실행을 더 지능적으로 처리하여 Agent로 빌드할 때 더 원활한 워크플로우를 제공합니다.

### AI 레이턴시 개선

인프라 개선을 통해 Replit AI 응답 시간과 레이턴시가 크게 감소했습니다. Agent와 Assistant를 포함하여 Replit 전반의 AI 기반 기능 사용 시 더 빠른 상호작용을 경험하실 수 있습니다.

### 통합 GitHub 탭 새로고침

GitHub 통합 탭이 더 깔끔하고 일관된 인터페이스를 갖추었습니다. 새로워진 디자인으로 워크스페이스 내에서 GitHub 저장소를 연결하고 관리하는 것이 더 직관적입니다.

### iOS 앱 결제 지원

iOS 사용자는 이제 Replit 모바일 앱을 통해 직접 Replit Core를 구매하고 결제 수단을 설정할 수 있습니다. 이를 통해 외출 중에도 프리미엄 기능에 더 쉽게 액세스할 수 있습니다.

### Stripe Checkout 출시

새로운 Stripe Checkout 통합은 모든 개발자에게 더 원활하고 안전한 결제 경험을 제공합니다. 업계 표준 결제 솔루션으로 Replit Core 업그레이드를 손쉽게 만드는 간소화된 구매를 즐기세요.

## Teams 및 엔터프라이즈

### SCIM 프로비저닝 간소화

개선된 SCIM 계정 프로비저닝 플로우로 엔터프라이즈 사용자 온보딩이 훨씬 쉬워졌습니다. 새 사용자는 수동 단계 없이 자동으로 설정되어 Replit에서 성장하는 엔터프라이즈 Teams에 마찰 없는 경험을 제공합니다.
