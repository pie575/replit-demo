Ashby 已会筛选收到的申请。此流程用于外联：从 Drive 读取职位描述，
在 GitHub 上查找合适的工程师，跳过已存在于 Ashby 中的人员，并起草供您发送的外联消息。
Agent 会将新找到的人才标记为已寻访，并附上简短的匹配理由和候选人沟通草稿。您审核后发送。请勿将此
作为唯一的招聘决策依据。

<div id="soluo-de-problemas">
  ## 故障排除
</div>

* **候选名单杂乱：**完成初步筛选后，调整必备条件和优先条件。要求候选人近期在特定编程语言或仓库类型中有提交记录，并排除看似为现有客户或竞争对手员工的人员。
* **已在 Ashby 中的人员仍然出现：**确认 Ashby 已连接到正确的工作区，并且 Agent 会通过电子邮件地址或 GitHub 用户名进行比对，而不只是显示名称。
* **外联消息已发送：**此流程应仅创建草稿。如果有任何内容被发送，请停止该例程，并告知 Agent 永远不要向候选人发送电子邮件或消息。
