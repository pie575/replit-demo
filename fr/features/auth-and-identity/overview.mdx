L'outil Utilisateurs et authentification gère les personnes qui utilisent votre application et la façon dont elles se connectent. Ouvrez **Utilisateurs et authentification** sous **Replit Cloud** dans le volet **Outils**.

L'outil comporte deux onglets :

* **Utilisateurs** : Toutes les personnes qui se sont connectées à votre application, avec leur nom et l'heure de leur dernière connexion. Recherchez dans la liste pour trouver un utilisateur spécifique.
* **Configurer** : L'expérience de connexion de votre application : le nom et l'icône de l'écran de connexion, les fournisseurs de connexion proposés par votre application, et la clé secrète de session.

<Note>
  Cet outil gère les utilisateurs de **votre application** : les personnes qui s'inscrivent et se connectent à ce que vous avez créé. Pour contrôler qui peut ouvrir votre application publiée, consultez [Qui peut accéder à votre application](/fr/features/publishing/private-deployments).
</Note>

## Choisissez votre système d'authentification

* **[Replit Auth](/fr/features/auth-and-identity/authentication)** : L'option sans configuration. Demandez à Agent d'ajouter Replit Auth, et votre application obtient une page de connexion prête à l'emploi, une gestion des utilisateurs et des sessions sécurisées sans aucune configuration.
* **[Clerk](/fr/features/auth-and-identity/clerk-auth)** : Un service d'authentification complet pour les applications qui ont besoin de plus de contrôle, comme des flux de connexion personnalisés et votre propre marque OAuth. Configurez des [fournisseurs de connexion personnalisés](/fr/features/auth-and-identity/sign-in-providers) pour Google, GitHub, Apple et X.

## Prochaines étapes

* [Replit Auth](/fr/features/auth-and-identity/authentication) : Connexion sans configuration pour votre application.
* [Clerk Auth](/fr/features/auth-and-identity/clerk-auth) : Authentification complète.
* [Fournisseurs de connexion](/fr/features/auth-and-identity/sign-in-providers) : Utilisez vos propres identifiants OAuth.
