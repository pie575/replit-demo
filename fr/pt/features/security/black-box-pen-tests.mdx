---
title: "Tests d'intrusion en boîte noire"
description: "Exécutez une analyse de sécurité de Level 3 qui examine le code source et teste l'application en cours d'exécution via des interactions navigateur et réseau."
---

Un test d&#39;intrusion en boîte noire examine une application en cours d&#39;exécution depuis l&#39;extérieur, par le biais d&#39;interactions navigateur et réseau. Il n&#39;utilise pas le code source de l&#39;application.

Dans le Centre de sécurité du projet, le **Level 3 (AI pentest)** regroupe trois types d&#39;analyses de sécurité :

1. Des analyses gratuites des dépendances et des paquets
2. Une analyse statique de votre code source par l&#39;Agent
3. Un test externe en boîte noire du Preview actif, réalisé depuis l&#39;extérieur sans utiliser votre code source

Une fois le Level 3 lancé, Replit exécute en parallèle la revue du code source par l&#39;Agent et le test externe en boîte noire.

<div id="executar-uma-verificao-de-nvel-3">
  ## Exécuter une analyse Level 3
</div>

<Steps>
  <Step title="Ouvrir le projet">
    Ouvrez le projet que vous souhaitez analyser.
  </Step>

  <Step title="Ouvrir le Security Center">
    Dans le panneau **Tools** du projet, sélectionnez **Security Center**.
  </Step>

  <Step title="Lancer une analyse">
    En haut du Security Center, sélectionnez **Run scan**.
  </Step>

  <Step title="Choisir Level 3">
    Sélectionnez **Level 3 (AI pentest)**.

    <Frame caption="Level 3 (AI pentest) ajoute une analyse statique de l'Agent et un test externe du Preview actif aux analyses gratuites des dépendances et des paquets.">
      <img src="/assets/mirror/level-3-ai-pentest-c223c0099d3f.png" alt="Security and Privacy Center ouvert depuis le panneau Tools, avec le menu Select scan level déployé et l'option Level 3 AI pentest sélectionnée" width="2204" height="1200" data-path="images/project-security-center/level-3-ai-pentest.png" />
    </Frame>
  </Step>

  <Step title="Attendre les deux tâches">
    Attendez la fin de la revue du code source et du test boîte noire du navigateur et du réseau.
  </Step>

  <Step title="Examiner les résultats">
    Examinez les résultats des deux tâches dans le panneau **Security**. Évaluez chaque résultat avant d&#39;envoyer les problèmes retenus à l&#39;Agent.
  </Step>

  <Step title="Corriger et relancer">
    Envoyez les résultats retenus à l&#39;Agent. Une fois les corrections appliquées, lancez une nouvelle analyse Level 3 pour les confirmer.
  </Step>
</Steps>

<div id="entenda-as-duas-tarefas">
  ## Comprendre les deux tâches
</div>

| Tâche                               | Éléments analysés                                                                 | Finalité                                                                                                |
| ----------------------------------- | --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| Revue du code source                | Le code source de votre application                                               | Identifie les vulnérabilités de sécurité, de confidentialité et d&#39;architecture dans la base de code |
| Test d&#39;intrusion en boîte noire | Interactions navigateur et réseau avec l&#39;application en cours d&#39;exécution | Examine le comportement observable de l&#39;extérieur, sans recourir au code source                     |

Passez en revue les deux ensembles de résultats. Une tâche ne remplace pas l&#39;autre : la revue de code permet de repérer des détails d&#39;implémentation vulnérables, tandis que le test en boîte noire évalue l&#39;application en cours d&#39;exécution depuis l&#39;extérieur.
