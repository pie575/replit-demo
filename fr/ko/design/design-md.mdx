<div id="section">
  ## Composition d&#39;un système de design
</div>

Le système de design généré comprend les éléments suivants :

* **Jetons (Tokens)** — les valeurs nommées auxquelles le reste du système fait référence (couleurs, espacements, rayons)
* **Couleurs (Colors)** — une palette dont chaque teinte se voit attribuer un rôle (primary, surface, accent, etc.)
* **Typographie (Typography)** — familles de polices, tailles et graisses
* **Composants d&#39;exemple (Example components)** — deux ou trois composants déjà créés pour illustrer l&#39;utilisation du système
* **Logo et assets de marque** — inclus si vous les avez explicitement fournis

<div id="section-2">
  ## Mode de stockage
</div>

Le système généré existe dans le projet sous la forme d’un **guide de style évolutif**. Les jetons de `tokens.json` sont appliqués aux variables CSS utilisées par les composants (par exemple, `src/index.css`). `DESIGN.md` les documente de façon à être lisible par les personnes et utilisable par Agent.

<div id="designmd">
  ## Utiliser DESIGN.md comme source
</div>

Un fichier `DESIGN.md` existant peut servir de source pour un nouveau système de design. [Lors de la création de votre système](/fr/ko/design/create-a-design-system), indiquez-le au même titre que d&#39;autres sources telles qu&#39;une URL Figma, un site web, du code ou des images de référence.
