Les applications web sont le type de résultat par défaut sur Replit. Lorsque vous décrivez une idée à Agent, il crée une application web full-stack, sauf si vous spécifiez un type d'artefact différent.

## Premiers pas

Il existe deux façons de créer une application web :

* **Saisir une invite** : Décrivez ce que vous souhaitez créer sur la page d'accueil de Replit. Agent crée automatiquement une application web.
* **Sélectionner dans le menu déroulant** : Ouvrez le menu déroulant du type d'application sur la page d'accueil et choisissez **Application web**, puis décrivez votre idée.

## Fonctionnalités clés

* **Full-stack par défaut** : Chaque application web inclut un frontend et un backend. Agent configure des routes API, une base de données et une logique côté serveur selon les besoins de votre application.
* **Conception responsive** : Les applications s'adaptent automatiquement aux différentes tailles d'écran.
* **Déploiement instantané** : Publiez votre application en un clic. Replit gère l'hébergement, le SSL et l'infrastructure.
* **Infrastructure partagée** : Si votre projet comporte plusieurs artefacts — comme une application mobile ou un tableau de bord de données — ils partagent tous le même backend, la même base de données et les mêmes services.

## Cas d'utilisation

* **Produits SaaS** : Créez des outils orientés clients, des tableaux de bord et des plateformes.
* **Outils internes** : Créez des panneaux d'administration, des CRM ou des applications de workflow pour votre équipe.
* **Pages d'atterrissage** : Lancez des sites marketing avec des formulaires, des animations et du contenu dynamique.
* **Marchés et annuaires** : Créez des sites de référencement, des tableaux d'offres d'emploi ou des plateformes communautaires.
