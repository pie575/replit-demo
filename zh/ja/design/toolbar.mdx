Canvas 工具栏是固定在画板底部中央的浮动工具栏，集成了用于移动、绘制、编辑和添加内容的工具。工具栏仅在 Canvas 模式下显示。

<div id="section">
  ## 工具
</div>

选择工具后即可启用。已启用的工具会以填充背景高亮显示。最左侧的一组是导航工具 (Interact、Pan) ，其余为内容和标注工具。工具为互斥选择，选择一个工具后，其他工具将被禁用。

<div id="interact">
  ### Interact
</div>

**Interact** 是默认工具。你可以用它选择画框、拖动画框，或点击正在运行的产物，像操作实际应用一样与其交互。启用 Interact 后，点击画框即可选中该画框，并显示[画框操作栏](/zh/ja/design/frames#per-frame-action-bar)。

<Frame>
  <img src="/assets/mirror/canvas-interact-4472dae3de09.png" alt="Canvas 中选中了 Website 产物，使用的是 Interact 工具。画框显示带有选择手柄的边框，上方显示画框操作栏。底部浮动工具栏中的 Interact 工具处于高亮状态" width="3450" height="2000" data-path="images/replitai/canvas-interact.png" />
</Frame>

**键盘快捷键：** `V`。**适用范围：** 始终可用。

<div id="pan">
  ### 平移
</div>

**Pan** 会将光标切换为抓手，让你可以拖动画板。启用 Pan 后，点击并拖动会移动视口，而非选择画框。即使启用了其他工具，也可以按住空格键拖动，或按住鼠标中键拖动来平移。

<Frame>
  <img src="/assets/mirror/canvas-pan-9f07d3bf72a3.png" alt="启用 Pan 工具的 Canvas。画板上显示 Website 产物（Velocity — Supercar Rental）和 Design 模型（Velocity — Home (Mockup)），底部浮动工具栏中的 Pan（手掌光标）工具处于高亮状态" width="1725" height="1041" data-path="images/replitai/canvas-pan.png" />
</Frame>

**键盘快捷键：** `H`。**适用范围：** 始终可用。

<div id="chat">
  ### Chat
</div>

**Chat** 会直接在画板上显示一个小型聊天输入框，让你无需离开 Canvas 即可向 Agent 发送提示词。所选元素或画框会以快照形式附加到消息中，就像通过侧边的 Agent 聊天面板发送时一样。

<Frame>
  <img src="/assets/mirror/canvas-chat-d28e2d8f216a.png" alt="处于 Chat 模式的 Canvas。画板的其余部分变暗，一个内联聊天输入框叠加显示在 Website 产物上方。输入框中的“div”标签表示当前选中的元素，提示词为“为此图片建议三种替代方案”。底部的浮动工具栏中，Chat 工具处于高亮状态" width="3450" height="2000" data-path="images/replitai/canvas-chat.png" />
</Frame>

**适用范围：** Chat 工具 (仅限桌面版) 。

<div id="draw">
  ### Draw
</div>

**Draw** 可启用自由绘制、箭头、便签和形状等标注工具，让你能够在画框上绘制草图或在画板上添加注释。你可以用它圈出问题区域、指明想要更改的元素，或在画框旁写下便签。

启用 Draw 时，浮动工具栏上方会显示 **Shape properties** 栏，其中包含当前标注工具的颜色、线条和填充控件。切换到 Interact 或 Pan 时，它会自动隐藏。

<Frame>
  <img src="/assets/mirror/canvas-draw-d2d9b6556cde.png" alt="启用了 Draw 工具的 Canvas。画框旁绘制了一个标有“Widget”的矩形，并放置了一张紫色的“Add a widget”便签。浮动工具栏上方显示 Shape properties 栏（包含铅笔、文本、矩形、箭头和便签工具，以及颜色色块和 Aa 文本字号控件），其中 Draw 处于高亮状态" width="1725" height="1041" data-path="images/replitai/canvas-draw.png" />
</Frame>

**适用范围：** 始终可用。

<div id="edit">
  ### Edit
</div>

**Edit** 是用于选择元素的可视化工具。启用 Edit 后，点击正在运行的产物中的任意位置，即可选中元素 (如按钮、标题和图片) 。选中元素后会打开**可视化编辑器**：右侧面板提供 Layout、Color、Border 等控件，以及内联提示词，让你可以要求 Agent 仅修改该部分。有关完整流程，请参阅[元素](/zh/ja/design/elements)和[可视化编辑器](/zh/ja/design/visual-editor)。

<Frame>
  <img src="/assets/mirror/canvas-edit-67fe5ee02fbe.png" alt="超级跑车租赁网站中已启用 Edit 工具并选中了 div 元素。可视化编辑器面板显示 Text、Layout、Color 和 Border 控件，以及 Discard 和 Save edits 按钮" width="2000" height="1269" data-path="images/replitai/canvas-edit.png" />
</Frame>

**适用范围：** 始终可用 (桌面端) 。没有任何画框时不可用，工具提示会显示 *「Create an artifact or generate a design to edit.」*。移动端不显示。

<div id="generate">
  ### Generate
</div>

**Generate** 会打开用于生成图像、视频和矢量图形的 **Generate media** 弹出窗口。选择类型并输入提示词后，Agent 会将结果作为新画框放置在 Canvas 上。

<Frame>
  <img src="/assets/mirror/canvas-add-menu-5d97d9c813e1.png" alt="Canvas 的 + Add 菜单已打开，纵向列出四个选项：Design（“Mock up interfaces and visual concepts”）、Image（“Generate and edit images”）、Video（“Generate motion clips and animations”）、Vector Graphic（“Generate vector illustrations and SVGs”）。底部浮动工具栏中的 Generate 区域当前显示“+ Generate”" width="1102" height="702" data-path="images/replitai/canvas-add-menu.png" />
</Frame>

弹出窗口顶部有四个选项卡。

* **Design**
  — **Image**
* **Video**
* **Vector Graphic**

部分控件适用于所有类型，其余控件则因类型而异。

**通用控件 (所有类型) ：**

* **Model**：要使用的生成模型。可用模型因类型而异 (请参阅下表) 。
* **Prompt**：用通俗易懂的语言描述你希望 Agent 生成的内容。
* **Generate**：提交请求，并在光标位置预留一个占位画框。资源准备就绪后，占位画框会切换为活动画框。如果生成失败，占位画框会被删除，Chat 面板中会显示错误。

**各类型的模型和控件：**

| 类型          | 擅长的内容                             | 当前模型                                                         | 类型专属控件                                                      |
| ----------- | --------------------------------- | ------------------------------------------------------------ | ----------------------------------------------------------- |
| **Image**   | 光栅输出 (PNG / JPG) 。情绪板图像、主视觉图像、参考图 | Nano Banana、Nano Banana 2、Nano Banana Pro、ChatGPT Images 2.0 | 宽高比 (`1:1`、`16:9`、`9:16`、`4:3`、`3:4`) 、尺寸 (`1K`、`2K`、`4K`)  |
| **Video**   | 短动态片段和动画                          | Veo 3.1、Seedance 2.0                                         | 宽高比、分辨率 (例如：`720p`) 、时长 (例如：`4s`) 、音频开关                     |
| **Graphic** | SVG 矢量输出。图标、徽标、图表和风格化插图           | Claude 4.6 Opus、Gemini 3.1 Pro Preview                       | 动画开关                                                        |

<Note>
  模型阵容会频繁变化。该表反映当前可用的模型，但请在应用内的下拉菜单中确认实际可用的模型。
</Note>

有关每种画框类型的详细信息，以及创建后可执行的操作，请参阅[画框](/zh/ja/design/frames)。

<div id="section-2">
  #### 添加视觉参考
</div>

生成前，您可以将画板上已有的内容添加为视觉参考。Agent 会利用这些参考，使生成结果与项目的视觉风格保持一致。在 **Generate media** 表单中打开 **+** 菜单，然后选择相应选项。

* **Upload file**：从计算机上传图片用作参考。
* **Select canvas elements**：选择画板上的现有元素。画框会作为屏幕截图导入，文本和便签图形会以文本摘要的形式附加。

每个参考都会以标签形式显示在表单中。您可以按需添加参考，输入提示词后选择 **Generate**。要删除参考，请选择对应的标签。

<Frame caption="打开 + 菜单的 Generate media 表单，显示 Upload file 和 Select canvas elements。">
  <img src="/assets/mirror/canvas-generate-media-references-ac0cb4340acb.png" alt="Canvas 的 Generate media 表单中已打开 + 菜单，显示 Upload file 和 Select canvas elements 选项。模型下拉菜单设置为 Nano Banana Pro" width="1134" height="662" data-path="images/replitai/canvas-generate-media-references.png" />
</Frame>

<Note>
  ChatGPT Images 2.0 目前不支持上传。要添加视觉参考，请切换到 Nano Banana Pro 等其他模型。
</Note>

启用 **Add menu** 后，**Generate** 按钮会替换为 **+** 菜单。该菜单汇集了弹出窗口中的各类选项，并新增 **Design** (不涉及实际代码的独立视觉模型) 。

**适用范围：**Image generation。**Vector Graphic** 需要 Vector graphic generation。**Video** 需要 Video generation。**+** 菜单需要 Add menu (其本身需要 Image generation) 。

<div id="section-3">
  ## 画板导航
</div>

平移、缩放和选择手势及其键盘快捷键属于画板级操作，而非工具栏中的工具。请参阅 Canvas 页面中的[画板导航](/zh/ja/design/canvas#navigate-the-board)。
