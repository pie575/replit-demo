<div id="improved-filesystem-search">
  ### 개선된 파일 시스템 검색
</div>

이제 Agent가 코드베이스 전체에서 더 똑똑하고 직관적인 파일 검색을 제공합니다. 고급 롱 컨텍스트 AI를 통해 Agent는 프로젝트 구조와 내용을 파악하고, 더 풍부한 컨텍스트를 바탕으로 질문에 더 적합하고 폭넓은 답변을 제공합니다. 덕분에 필요한 내용을 정확히 찾기가 그 어느 때보다 쉬워졌습니다.

<div id="object-storage-agent-integration">
  ### Object Storage Agent 통합
</div>

[Agent](/ko/core-concepts/agent)의 새로운 [Object Storage](/ko/features/data-and-storage/object-storage) 기능으로 파일 업로드 기능을 손쉽게 구현해 보세요! 이제 AI 어시스턴트가 Object Storage를 설정하고 구성을 확인하며, authentication과 access controls 같은 고급 기능까지 갖춘 backend 및 frontend 코드를 완성해 줍니다.

[Object Storage](/ko/features/data-and-storage/object-storage)에 대해 자세히 알아보고, 사용 가능한 모든 [Agent integrations](/ko/replitai/integrations#data-storage--management)를 살펴보세요.

<div id="visual-editor-focus-improvement">
  ### Visual Editor 포커스 개선
</div>

[Visual Editor](/ko/learn/projects-and-artifacts/visual-editor)로 작업하는 동안 흐름이 끊기지 않습니다! 편집할 요소를 선택하면 포커스가 자동으로 채팅 입력창으로 돌아가므로, 곧바로 다음 prompt를 입력할 수 있습니다.

<div id="rollback-suggestions-and-date-toggle">
  ### Rollback 제안 및 날짜 토글
</div>

스마트한 rollback 제안과 유연한 날짜 표시 기능으로 project 기록을 더 쉽게 살펴보세요! 코드를 언제 roll back하면 좋을지 알아서 추천해 주고, 상대 시간과 절대 시간 표시를 전환하며 딱 맞는 checkpoint를 찾을 수 있습니다.

<div id="live-activities-on-ios">
  ### iOS 라이브 액티비티
</div>

자리를 비운 순간에도 [Workspace](/ko/learn/projects-and-artifacts/project-editor)와 계속 연결되세요! iOS 라이브 액티비티를 사용하면 실행 중인 project 상태를 확인하고, lock screen이나 알림 센터에서 한 번의 탭만으로 Workspace로 바로 돌아갈 수 있습니다.
