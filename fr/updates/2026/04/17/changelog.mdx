<div id="new-agent-modes-dropdown">
  ### Nouveau menu déroulant des modes Agent
</div>

Le sélecteur de mode Agent dans le champ de saisie du Chat est désormais un contrôle segmenté plus simple. Choisissez entre Lite, Economy et Power directement dans la barre d’outils, et accédez à Turbo via les paramètres avancés lorsque vous en avez besoin.

Nouveautés :

* **Contrôle segmenté dans la barre d’outils.** Lite, Economy et Power sont côte à côte pour vous permettre de voir facilement le mode utilisé et de le changer.
* **Raccourci clavier.** Appuyez sur **⌘+Shift+I** (Ctrl+Shift+I sous Windows) pour faire défiler les modes sans utiliser votre souris.
* **Turbo mis en évidence en orange.** Turbo est le mode le plus rapide, mais aussi le plus coûteux. Il se distingue donc dans l’interface afin de rendre ce compromis clairement visible.
* **Paramètres avancés réduits par défaut.** Les options de test, de révision du code et de Turbo sont regroupées dans les **paramètres avancés**, afin que la vue principale reste épurée.
* **Le mode Max a été retiré.** Utilisez Power pour les builds les plus exigeants, ou activez Turbo dans les paramètres avancés pour obtenir la réponse la plus rapide.

<div id="agent-suggests-follow-up-tasks">
  ### Agent suggère des tâches de suivi
</div>

<Frame>
  <video autoPlay muted loop playsInline src="/assets/mirror/replit-suggested-tasks-b27620d93fd2.mp4" />
</Frame>

Agent propose désormais des **tâches de suivi** une fois son travail terminé : il s&#39;appuie sur l&#39;ensemble du contexte de votre projet pour suggérer la suite à développer. Trois types de suggestions apparaissent sous chaque tâche terminée :

* **Nouvelles fonctionnalités à créer** — des possibilités qui complètent naturellement ce que vous venez de livrer
* **Améliorations de performance** — des optimisations repérées par Agent pendant qu&#39;il travaillait sur la tâche
* **Améliorations de l&#39;expérience utilisateur** — les finitions qui parachèvent la fonctionnalité

Passez en revue chaque suggestion, sélectionnez **Accept** pour celles qui vous intéressent, et Agent les exécute en arrière-plan pendant que vous continuez à développer. Masquez les suggestions dont vous n&#39;avez pas besoin via **Hide suggested tasks** dans la colonne Done, puis réaffichez-les à tout moment.

Pour en savoir plus, consultez [les suggestions de tâches de suivi](/fr/features/agent/follow-up-tasks).

<div id="projects-page-improvements">
  ### Améliorations de la page Projets
</div>

Trois améliorations du confort d&#39;utilisation ont été déployées sur la page Projets :

* **Aperçus des artifacts sur chaque carte.** Chaque carte de projet affiche désormais une petite icône par artifact qu&#39;elle contient. Survolez une icône pour prévisualiser la capture d&#39;écran de l&#39;artifact correspondant sans ouvrir le projet.
* **Tri par défaut selon vos dernières ouvertures.** La page place désormais en haut les projets sur lesquels *vous* avez travaillé le plus récemment, afin que votre travail en cours reste bien en évidence dans les workspaces d&#39;équipe très actifs.
* **Épinglage personnel.** Épinglez les projets que vous consultez souvent. Vos épingles restent privées et n&#39;ont aucune incidence sur ce que voient les autres membres de votre workspace.

<div id="custom-groups-for-scim-organizations">
  ### Groupes personnalisés pour les organisations SCIM
</div>

Les organisations disposant du provisionnement SCIM peuvent désormais créer des groupes personnalisés dans Replit, en complément de leurs groupes synchronisés depuis leur IdP. Utilisez les groupes personnalisés pour gérer les accès par projet, accorder des autorisations ponctuelles ou reproduire toute structure absente de votre fournisseur d&#39;identité.

Les groupes synchronisés par SCIM restent gérés depuis votre fournisseur d&#39;identité, tandis que les groupes personnalisés sont gérés directement dans Replit par les administrateurs de l&#39;organisation.

En savoir plus sur [SCIM](/fr/teams/identity-and-access-management/scim#creating-custom-groups-alongside-scim).
