<div id="novo-menu-suspenso-de-modos-do-agent">
  ### Новое выпадающее меню режимов Agent
</div>

Переключатель режимов Agent в поле ввода чата стал более простым сегментированным элементом управления. Выбирайте Lite, Economy и Power прямо на панели инструментов, а Turbo при необходимости доступен в расширенных настройках.

Что нового:

* **Сегментированный переключатель на панели инструментов.** Lite, Economy и Power расположены рядом, поэтому сразу видно, какой режим выбран и как переключаться между ними.
* **Сочетание клавиш.** Нажмите **⌘+Shift+I** (Ctrl+Shift+I в Windows), чтобы переключаться между режимами без мыши.
* **Turbo выделен оранжевым.** Turbo — самый быстрый режим, но он стоит дороже, поэтому выделен в интерфейсе, чтобы разница в стоимости была заметна.
* **Расширенные настройки по умолчанию свернуты.** Настройки тестирования, проверки кода и Turbo скрыты в разделе **Расширенные настройки**, чтобы основной интерфейс оставался незагромождённым.
* **Режим Max упразднён.** Используйте Power для самых сложных сборок или включите Turbo в расширенных настройках, если вам нужен самый быстрый ответ.

<div id="agent-sugere-tarefas-de-acompanhamento">
  ### Agent предлагает последующие задачи
</div>

<Frame>
  <video autoPlay muted loop playsInline src="/assets/mirror/replit-suggested-tasks-b27620d93fd2.mp4" />
</Frame>

Теперь по завершении работы Agent предлагает **последующие задачи**, опираясь на полный контекст вашего проекта, чтобы подсказать, что создать дальше. Под каждой выполненной задачей появляются три типа предложений:

* **Новые возможности для реализации** — функции, которые органично дополняют то, что вы только что выпустили
* **Улучшения производительности** — оптимизации, которые Agent заметил во время работы над задачей
* **Улучшения пользовательского опыта** — доработки, которые доводят функцию до完 завершённого вида

Просмотрите предложения, нажмите **Принять** для нужных — и Agent выполнит их в фоновом режиме, пока вы продолжаете работу. Скройте лишние предложения с помощью пункта **Скрыть предложенные задачи** в столбце «Выполнено» и верните их в любой момент.

Подробнее о [предложениях последующих задач](/ru/pt/core-concepts/agent/task-system/follow-up-tasks).

<div id="melhorias-na-pgina-de-projetos">
  ### Улучшения страницы проектов
</div>

На странице проектов появились три улучшения, которые делают работу удобнее:

* **Превью артефактов на каждой карточке.** Теперь на карточке проекта отображаются небольшие значки всех артефактов внутри него. Наведите указатель на любой значок, чтобы посмотреть снимок экрана этого артефакта, не открывая проект.
* **Сортировка по умолчанию — по времени вашего последнего открытия.** Теперь вверху страницы оказываются проекты, над которыми недавно работали именно *вы*, так что текущая работа остаётся на виду даже в загруженных командных workspace.
* **Личное закрепление.** Закрепляйте проекты, к которым часто возвращаетесь. Закрепления видны только вам и не влияют на то, что видят другие участники вашего workspace.

<div id="grupos-personalizados-para-organizaes-scim">
  ### Пользовательские группы для организаций с SCIM
</div>

Организации с включённым провижинингом SCIM теперь могут создавать в Replit собственные группы наряду с группами, синхронизируемыми из поставщика идентификации. Используйте такие группы для доступа на уровне проектов, разовой выдачи разрешений или любой структуры, которой нет в вашем поставщике идентификации.

Группы, синхронизированные через SCIM, по-прежнему управляются вашим поставщиком идентификации, а пользовательскими группами администраторы организации управляют непосредственно в Replit.

Подробнее о [SCIM](/ru/pt/teams/identity-and-access-management/scim#creating-custom-groups-alongside-scim).
