你的应用通过 Replit 代为管理的凭据连接到数据库。在 **Database** 工具中即可找到这些凭据：选择一个数据库，然后打开 **Settings** 标签页。该页面会显示连接字符串、存储用量以及高级连接详情。

<div id="environment-variables">
  ## 环境变量
</div>

连接开发数据库时可使用以下环境变量：

* `DATABASE_URL`：连接数据库并进行身份验证的方式

你的应用会自动使用该变量。由于 `DATABASE_URL` 仅在你的应用范围内有效，其他应用 (即便是你自己的应用) 或外部数据库查看器都无法访问你的开发数据库。即使该变量泄露，他人也无法借此访问或修改你的数据库。

<Info>
  如果你的开发数据库仍运行在[旧版 Neon 基础设施](/zh/features/data-and-storage/development-and-production#legacy-development-database)上，则还可使用 `PGHOST`、`PGUSER`、`PGPASSWORD`、`PGDATABASE` 和 `PGPORT` 等额外变量。托管在 Replit 当前基础设施上的数据库**不会**提供这些变量，请改用 `DATABASE_URL`。
</Info>

<Warning>
  如果你仍在使用旧版 Neon 开发数据库，请勿分享你的 `DATABASE_URL`。它包含数据库凭据，任何人都可借此访问和修改你的数据库。切勿将其粘贴到公开场合或支持工单中。
</Warning>

<div id="connect-an-external-tool">
  ## 连接外部工具
</div>

你可以在生产数据库的 **Settings** 选项卡中获取连接字符串，然后通过任何兼容 PostgreSQL 的 SQL 客户端连接到你的**生产**数据库。

<div id="security">
  ## 安全性
</div>

当你使用 Agent 添加数据库集成时，它会添加一个对象关系映射器 (ORM) 来处理所有数据库通信，并内置以下安全机制：

* **模式校验**：验证数据是否符合预期格式
* **数据清理**：自动清理构建者的输入，防止 SQL 注入攻击

<div id="regenerate-production-database-credentials">
  ## 重新生成生产数据库凭据
</div>

如果生产连接字符串已泄露，请在 Database 工具中重新生成其凭据。此操作会为 Neon 生产数据库创建新密码，现有的生产连接字符串会立即失效。

同时满足以下所有条件时，你才能重新生成凭据：

* 你的应用拥有 Neon 生产数据库。
* 你是该应用的所有者，或所属 workspace 的管理员。
* 你在网页浏览器中使用 Replit。
* 当前没有正在进行的 deployment。
* 如果你的应用有正在运行的 deployment，其最新构建已成功完成，并使用 [Autoscale 或 Reserved VM](/zh/features/publishing/deployment-types)。

<Warning>
  此操作无法撤销。现有连接字符串会立即失效。如果你的应用有正在运行的 deployment，在重新部署期间可能会短暂不可用。
</Warning>

<div id="regenerate-the-credentials">
  ### 重新生成凭据
</div>

1. 在工具面板中，选择 **Database**。

2. 选择 **Production Database**，然后切换到 **Settings** 选项卡。

   <Frame>
     <img src="/assets/mirror/database-regenerate-credentials-settings-827c7718a25f.webp" alt="生产数据库 的 Settings 选项卡，显示连接字符串、存储用量以及包含“重新生成凭据”行的 Advanced 部分。" width="2314" height="1608" data-path="images/databases/database-regenerate-credentials-settings.webp" />
   </Frame>

3. 在 **Advanced** 下，展开 **重新生成凭据** 行。

4. 选择 **重新生成凭据** 按钮。

   <Frame>
     <img src="/assets/mirror/database-regenerate-credentials-button-ab9631f21b85.webp" alt="Advanced 部分中展开的“重新生成凭据”行，显示“重新生成凭据”按钮。" width="2206" height="1876" data-path="images/databases/database-regenerate-credentials-button.webp" />
   </Frame>

5. 在确认对话框中，选择 **重新生成凭据** 进行确认。

   <Frame>
     <img src="/assets/mirror/database-regenerate-credentials-dialog-2477fc96f82b.webp" alt="“重新生成凭据”确认对话框，警告该操作无法撤销，且现有连接字符串会立即失效。" width="1364" height="638" data-path="images/databases/database-regenerate-credentials-dialog.webp" />
   </Frame>

6. 选择 **Refresh** 以加载新的连接字符串。

7. 如果你的应用有正在运行的 deployment，请打开 **Publishing** 并关注重新部署的进展。

8. 将此前复制到外部工具或自定义 integration 中的连接字符串全部替换掉。

<div id="what-changes">
  ### 会发生哪些变化
</div>

重新生成凭据会为生产数据库创建新密码。连接字符串中只有密码部分会变化，主机、数据库名称和角色保持不变。

对于受支持的正在运行的 deployment，Replit 会使用更新后的连接字符串重新部署最近一次成功的构建。
