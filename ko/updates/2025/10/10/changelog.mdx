<div id="agent-usage-cost-visibility">
  ### Agent 사용 비용 표시
</div>

task가 실행되는 동안 Agent 사용 비용을 실시간으로 확인하세요. Chat 헤더의 drawer를 열면 진행 중인 task의 지출을 확인할 수 있어, 실행 시간이 길고 자율성이 높은 작업에 특히 유용합니다.

<div id="escape-key-for-visual-selectedit-mode">
  ### Visual Select/Edit 모드의 Escape 키
</div>

Escape 키를 누르면 Visual Select 모드에서 나가거나 Build 모드로 돌아갈 수 있습니다. 작업 흐름을 끊지 않게 해주는 작은 단축키입니다.

<div id="faster-agent-stopping">
  ### 더 빨라진 Agent 중지
</div>

workspace에서 Agent를 중지하거나 시작하면 Agent가 더 빠르게 반응하므로 대기 시간이 줄어듭니다.

<div id="github-import-improvements">
  ### GitHub 가져오기 개선
</div>

GitHub 가져오기 중에 형식적인 메시지 대신 실시간 진행 상황이 표시되며, 가져오기 속도도 더 빨라졌습니다.

<div id="dependency-vulnerability-scanning">
  ### 의존성 취약점 검사
</div>

이제 security scanner가 Go, JavaScript, Python, Rust의 dependency 취약점을 탐지합니다. 지원 언어는 앞으로 계속 추가될 예정입니다.

<div id="webview-logging-experience">
  ### Webview 로깅 경험
</div>

webview 로그와 콘솔 출력을 한곳에서 확인하세요. Agent가 사용하는 것과 동일한 로그라 디버깅이 한결 간편해집니다.
