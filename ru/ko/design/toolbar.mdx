Панель инструментов Canvas — это плавающая панель, закреплённая внизу по центру доски. Она содержит инструменты для навигации, рисования, редактирования и добавления контента. Панель отображается в режиме Canvas.

<div id="section">
  ## Инструменты
</div>

Выбранный инструмент становится активным и выделяется залитым фоном. Крайняя левая группа — инструменты навигации (Interact, Pan). Остальные предназначены для работы с контентом и разметкой. Инструменты взаимоисключающие: при выборе одного остальные деактивируются.

<div id="interact">
  ### Interact
</div>

**Interact** — основной инструмент. Используйте его, чтобы выбирать и перетаскивать фреймы, а также нажимать на запущенные Artifact и взаимодействовать с ними как с работающими приложениями. Когда Interact активен, щелчок по фрейму выделяет его и отображает [панель действий фрейма](/ru/ko/design/frames#per-frame-action-bar).

<Frame>
  <img src="/assets/mirror/canvas-interact-4472dae3de09.png" alt="Canvas с выбранным с помощью инструмента Interact артефактом Website: вокруг фрейма отображаются маркеры выделения, а над ним — панель действий фрейма. Инструмент Interact выделен на плавающей панели инструментов внизу" width="3450" height="2000" data-path="images/replitai/canvas-interact.png" />
</Frame>

**Сочетание клавиш:** `V`. **Доступ:** всегда.

<div id="pan">
  ### Pan
</div>

**Pan** переключает курсор на инструмент захвата, позволяющий перетаскивать сам холст. Когда Pan активен, перетаскивание перемещает область просмотра вместо выбора фреймов. Панорамировать можно и в других режимах: удерживайте пробел при перетаскивании или перетаскивайте средней кнопкой мыши.

<Frame>
  <img src="/assets/mirror/canvas-pan-9f07d3bf72a3.png" alt="Canvas с активным инструментом Pan: на холсте видны артефакт Website (Velocity — Supercar Rental) и мокап Design (Velocity — Home (Mockup)), а на плавающей панели инструментов внизу выделен инструмент Pan (курсор в виде руки)" width="1725" height="1041" data-path="images/replitai/canvas-pan.png" />
</Frame>

**Сочетание клавиш:** `H`. **Доступ:** всегда включено.

<div id="chat">
  ### Chat
</div>

**Chat** позволяет разместить небольшое поле ввода прямо на доске и отправлять промпты Agent, не покидая Canvas. Выбранные элементы и фреймы прикрепляются к сообщению в виде снимков — так же, как при отправке из боковой панели Agent чата.

<Frame>
  <img src="/assets/mirror/canvas-chat-d28e2d8f216a.png" alt="Canvas в режиме Chat. Остальная часть доски затемнена, а поверх артефакта Website размещено встроенное поле ввода чата. Чип «div» в поле ввода обозначает выбранный элемент, а в промпте написано «suggest three alternatives to this image». На плавающей панели инструментов внизу выделен инструмент Chat" width="3450" height="2000" data-path="images/replitai/canvas-chat.png" />
</Frame>

**Доступ:** инструмент Chat (только для компьютеров).

<div id="draw">
  ### Draw
</div>

**Draw** активирует инструменты разметки — рисование от руки, стрелки, стикеры и фигуры, — чтобы вы могли делать наброски поверх фреймов или оставлять комментарии на холсте. Используйте его, чтобы обвести проблемные места, указать элементы, которые хотите изменить, или оставить заметку рядом с фреймом.

Когда Draw активен, над плавающей панелью инструментов отображается панель **Shape properties** с настройками цвета, обводки и заливки для выбранного инструмента разметки. При переключении обратно на Interact или Pan она автоматически исчезает.

<Frame>
  <img src="/assets/mirror/canvas-draw-d2d9b6556cde.png" alt="Canvas с активным инструментом Draw — рядом с фреймом нарисован прямоугольник «Widget» и размещён фиолетовый стикер «Add a widget». Над плавающей панелью инструментов видна панель Shape properties (инструменты карандаша, текста, прямоугольника, стрелки и стикера, а также образцы цветов и элемент управления размером текста Aa); Draw выделен" width="1725" height="1041" data-path="images/replitai/canvas-draw.png" />
</Frame>

**Доступ:** всегда включено.

<div id="edit">
  ### Edit
</div>

**Edit** — инструмент визуального выбора элементов. Когда Edit активен, щёлкните внутри запущенного Artifact, чтобы выбрать элемент (кнопку, заголовок или изображение). После выбора справа откроется панель управления **Visual Editor** (Layout, Color, Border и т. д.), а также появится встроенный промпт, с помощью которого можно попросить Agent изменить только выбранную часть. Подробнее см. в разделах [Elements](/ru/ko/design/elements) и [Visual Editor](/ru/ko/design/visual-editor).

<Frame>
  <img src="/assets/mirror/canvas-edit-67fe5ee02fbe.png" alt="На сайте аренды суперкаров активирован инструмент Edit и выбран элемент div. На панели Visual Editor отображаются элементы управления Text, Layout, Color, Border и кнопки Discard и Save edits" width="2000" height="1269" data-path="images/replitai/canvas-edit.png" />
</Frame>

**Доступ:** всегда включён на компьютере. Если нет ни одного фрейма, инструмент недоступен, а во всплывающей подсказке отображается *&quot;Создайте Artifact для редактирования или сгенерируйте дизайн.&quot;* На мобильных устройствах он скрыт.

<div id="generate">
  ### Generate
</div>

**Generate** открывает всплывающее окно **Generate media** для создания изображений, видео и векторной графики. Выберите тип и напишите промпт — Agent разместит результат на холсте в виде нового фрейма.

<Frame>
  <img src="/assets/mirror/canvas-add-menu-5d97d9c813e1.png" alt="Открыто меню Canvas + Add с четырьмя вариантами, перечисленными по вертикали: Design('Mock up interfaces and visual concepts'), Image('Generate and edit images'), Video('Generate motion clips and animations'), Vector Graphic('Generate vector illustrations and SVGs'). Слот Generate на нижней плавающей панели инструментов теперь отображается как '+ Generate'" width="1102" height="702" data-path="images/replitai/canvas-add-menu.png" />
</Frame>

В верхней части всплывающего окна расположены четыре вкладки.

* **Design**
  — **Image**
* **Video**
* **Vector Graphic**

Некоторые элементы управления общие для всех типов, а другие различаются в зависимости от типа.

**Общие элементы управления (для всех типов):**

* **Model**: модель, используемая для генерации. Доступные модели зависят от типа (см. таблицу ниже).
* **Prompt**: текстовое описание того, что должен сгенерировать Agent.
* **Generate**: отправляет запрос и резервирует фрейм-заполнитель в позиции курсора. Когда ассет будет готов, заполнитель заменится фактическим фреймом. Если генерация завершится ошибкой, заполнитель будет удалён, а на панели чата отобразится сообщение об ошибке.

**Модели и элементы управления для каждого типа:**

| Тип         | Подходит для                                                                                                  | Текущие модели                                                  | Элементы управления для типа                                                                             |
| ----------- | ------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| **Image**   | Растровый вывод (PNG/JPG); изображения для мудбордов, изображения для главного блока, референсные иллюстрации | Nano Banana, Nano Banana 2, Nano Banana Pro, ChatGPT Images 2.0 | Соотношение сторон (`1:1`, `16:9`, `9:16`, `4:3`, `3:4`) · размер (`1K`, `2K`, `4K`)                     |
| **Video**   | Короткие видеоклипы и анимации                                                                                | Veo 3.1, Seedance 2.0                                           | Соотношение сторон · разрешение (например, `720p`) · длительность (например, `4s`) · переключатель аудио |
| **Graphic** | Векторный вывод SVG; иконки, логотипы, диаграммы, стилизованные иллюстрации                                   | Claude 4.6 Opus, Gemini 3.1 Pro Preview                         | Переключатель Animated                                                                                   |

<Note>
  Список моделей часто меняется. В таблице указаны доступные на данный момент варианты; чтобы узнать, какие модели доступны вам сегодня, проверьте выпадающий список в интерфейсе продукта.
</Note>

Подробнее о типах фреймов и о том, что с ними можно делать после генерации, см. в разделе [Frames](/ru/ko/design/frames).

<div id="section-2">
  #### Прикрепление визуальных референсов
</div>

Перед генерацией можно прикрепить в качестве визуальных референсов элементы, уже находящиеся на доске. Agent использует их, чтобы создать результат в стиле проекта. Откройте меню **+** в форме **Generate media** и выберите нужный вариант.

* **Upload file**: загрузите изображение с компьютера для использования в качестве референса.
* **Select canvas elements**: выберите существующие элементы на доске. Фреймы добавляются в виде скриншотов, а текстовые фигуры и заметки — в виде текстовых сводок.

Каждый референс отображается в форме в виде чипа. Добавьте нужное количество референсов, напишите промпт и выберите **Generate**. Чтобы удалить референс, выберите соответствующий чип.

<Frame caption="Форма Generate media с открытым меню +, в котором показаны варианты Upload file и Select canvas elements.">
  <img src="/assets/mirror/canvas-generate-media-references-ac0cb4340acb.png" alt="Форма Generate media в Canvas с открытым меню +. Показаны варианты Upload file и Select canvas elements, а в раскрывающемся списке модели выбрана Nano Banana Pro" width="1134" height="662" data-path="images/replitai/canvas-generate-media-references.png" />
</Frame>

<Note>
  ChatGPT Images 2.0 пока не поддерживает загрузку файлов. Чтобы прикрепить визуальные референсы, переключитесь на другую модель, например Nano Banana Pro.
</Note>

Когда **Add menu** включено, кнопка Generate заменяется меню **+**, которое объединяет типы всплывающих окон с **Design** (независимыми визуальными макетами, не влияющими на выполняемый код).

**Доступ:** Image generation. Для **Vector Graphic** требуется Vector graphic generation, а для **Video** — Video generation. Для меню **+** требуется Add menu, для которого также требуется Image generation.

<div id="section-3">
  ## Навигация по доске
</div>

Жесты панорамирования, масштабирования и выбора, а также соответствующие им сочетания клавиш относятся к функциям самой доски, а не к инструментам на панели. Подробнее см. в разделе [«Навигация по доске»](/ru/ko/design/canvas#navigate-the-board) на странице Canvas.
