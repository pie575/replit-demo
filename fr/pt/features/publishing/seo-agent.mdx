Le SEO Agent réalise un audit SEO technique sur l&#39;ensemble de votre projet et met en évidence les problèmes qui limitent la capacité des moteurs de recherche et des crawlers d&#39;IA à trouver et à comprendre votre app. Chaque constat se transforme en une correction en un clic, que vous pouvez examiner et appliquer avec l&#39;Agent.

Il se trouve dans le panneau **Growth** du Project Editor et fonctionne avec les apps que vous avez déjà publiées. Pour la plupart des créateurs, le flux de travail est le suivant : publiez votre app, ouvrez le SEO Agent, lancez une analyse, examinez les constats et appliquez les corrections.

<div id="o-que-o-seo-agent-faz">
  ## Ce que fait le SEO Agent
</div>

Le SEO Agent se concentre sur le **SEO technique**, c&#39;est-à-dire les éléments structurels et lisibles par les machines de votre app qui déterminent avec quelle facilité les moteurs de recherche et les crawlers d&#39;IA peuvent la découvrir, l&#39;indexer et la comprendre.

Il examine votre projet et propose des correctifs pour des problèmes tels que :

* **Explorabilité et indexation** : `robots.txt`, `sitemap.xml` et une structure de liens et de pages explorable.
* **Métadonnées de page** : balises `<title>` uniques et descriptives et meta descriptions sur toutes les pages.
* **Données structurées** : balisage JSON-LD qui aide les moteurs de recherche à afficher des résultats enrichis.
* **Open Graph et balises sociales** : les métadonnées qui déterminent l&#39;aperçu de vos liens lorsqu&#39;ils sont partagés.
* **Balisage sémantique** : ordre correct des titres, éléments de landmark et texte `alt` descriptif sur les images.

<Note>
  Le SEO Agent garantit que l&#39;app que vous avez créée est techniquement solide pour la recherche,
  mais il ne rédige pas de contenu et ne bâtit pas d&#39;autorité thématique à votre place.
</Note>

<div id="antes-de-comear">
  ## Avant de commencer
</div>

Le SEO Agent nécessite :

* **Une application publiée.** Le SEO Agent audite un deployment web public et actif : publiez donc votre application au préalable si ce n&#39;est pas déjà fait. Consultez [SEO Rating](/fr/pt/features/publishing/seo-rating) pour connaître les types de deployment compatibles avec le SEO.
* **Une offre payante.** Le SEO Agent est accessible aux créateurs disposant d&#39;une offre payante. Si vous utilisez l&#39;offre gratuite, une option de mise à niveau s&#39;affiche dans le panneau Growth.

Il existe deux façons d&#39;accéder au SEO Agent : ouvrez le panneau **Growth** directement dans le Project Editor, ou sélectionnez **Optimize SEO with Agent** à côté de votre note SEO dans l&#39;outil **Publishing**, ce qui ouvre le panneau Growth prêt pour l&#39;analyse.

<div id="onde-encontrar">
  ## Où le trouver
</div>

Le SEO Agent fonctionne sur une application publiée. Tant que vous n&#39;avez pas publié, le panneau **Growth** reste verrouillé et vous invite à **Go to Publishing**.

<Tip>
  Pour contrôler l&#39;apparence de votre application dans l&#39;aperçu lorsqu&#39;elle est partagée sur les réseaux sociaux, connectez un
  [domaine personnalisé](/fr/pt/build/add-custom-domain) et republiez. Les aperçus sociaux et de liens
  utilisent l&#39;URL publique de production de votre application : un domaine personnalisé publié
  garantit donc des aperçus exacts.
</Tip>

<div id="o-seo-agent-e-sua-classificao-de-seo">
  ## Le SEO Agent et votre note SEO
</div>

La **note SEO** affichée à côté du SEO Agent provient d&#39;un [audit Lighthouse automatique](/fr/pt/features/publishing/seo-rating) exécuté après chaque publication, qui classe votre app comme Healthy, Needs Work ou Weak. Cette note indique *où en est votre app*.
Le SEO Agent vous aide à *l&#39;améliorer* en détectant les problèmes et en appliquant les correctifs. Republier après un correctif met la note à jour.

Vous pouvez aussi vous passer complètement de l&#39;interface de vérification et demander directement à Agent :

<AiPrompt>
  Audit my site for SEO best practices and apply the fixes. Add a sitemap,
  robots.txt, Open Graph tags, structured data where it makes sense, and make
  sure every page has a unique title and meta description.
</AiPrompt>
