<div id="section-3">
  ### В визуальный редактор добавлены элементы управления раскладкой
</div>

В визуальном редакторе появились специальные элементы управления **раскладкой**, которые позволяют визуально настраивать flexbox-раскладку, не обращаясь к Agent с просьбой переписать стили. Выберите контейнер и разверните раздел Layout, чтобы задать направление flex, распределение и выравнивание. Можно установить промежуток в пикселях между элементами или включить переключатель **Space between**, чтобы разместить дочерние элементы по противоположным краям.

Панель редактора также теперь сгруппирована в понятные разделы **Text**, **Image**, **Layout**, **Color** и **Border**, чтобы нужные элементы управления было проще находить.

  ## Agent
</div>

<div id="agent-2">
  ### Настройки Agent остаются личными даже в общих проектах
</div>

Настройки Agent, включая уровень модели, режим плана, автоматическое слияние и автоматическое одобрение плана, теперь привязаны к конкретному пользователю, а не ко всему проекту. Если ваш коллега переключится на Power Mode для своей задачи, это не повлияет на ваши настройки. Даже в проектах с большим числом участников Agent будет использовать выбранные вами настройки при отправке следующего сообщения.

Подробнее см. в разделе [Режимы Agent](/ru/ja/features/agent/agent-modes#settings-in-shared-projects).

<div id="agentpower-mode">
  ### Agent предлагает Power Mode, если вы застряли
</div>

Если Agent в режиме Economy замечает, что неоднократно сталкивается с одной и той же проблемой, в следующем сообщении он предложит перейти на Power. Это предложение появляется при обнаружении повторяющихся запросов или кода, который продолжает выдавать ошибки, и отображается не более одного раза для каждого проекта. Во время сеанса планирования Agent не будет показывать это предложение, если вы упоминаете ограничения бюджета или используете бесплатный план.

<div id="section-4">
  ### Упорядоченное выпадающее меню настроек задачи
</div>

Выпадающее меню, открываемое из заголовка задачи, стало удобнее. Вверху теперь отображается название активной задачи или плана с возможностью переименовать его прямо на месте. Настройки автоматизации (автоприменение и автоодобрение) вынесены в отдельный раздел между названием и действиями, а фиксированная ширина предотвращает смещение всплывающего окна при изменении названия задачи. Отключённые параметры автоматизации скрыты, поэтому отображаются только те, которые применимы к текущей задаче.

<div id="2quiver-aibrowserbase">
  ### Два новых коннектора: Quiver AI и Browserbase
</div>

В каталог коннекторов добавлены два сервиса. Откройте панель **Интеграции** и выберите **Добавить новую интеграцию**, чтобы подключить один из них.

* **Quiver AI**: генерирует SVG-иллюстрации и векторизует растровые изображения через управляемый API. Полезен, когда Agent нужны чистые SVG-ассеты по запросу.
* **Browserbase**: запускает управляемые безголовые браузеры для извлечения данных, поиска и полной автоматизации сессий. Полезен, когда Agent нужно загружать реальные веб-страницы, выполнять JavaScript или взаимодействовать с сайтами, блокирующими обычные HTTP-запросы.
