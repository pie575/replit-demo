<div id="open-settings">
  ## Settings 열기
</div>

1. Replit 왼쪽 하단에서 계정 메뉴를 선택합니다.
2. **Settings**를 선택합니다.

<Note>
  사용할 수 있는 tab은 Workspace 유형, plan, 역할에 따라 달라집니다. Admin 전용
  옵션은 해당 권한이 있는 경우에만 표시됩니다.
</Note>

<div id="workspace-settings">
  ## Workspace 설정
</div>

**Workspace** 섹션에서 현재 선택된 Workspace를 관리할 수 있습니다.

* **Workspace overview**: Workspace 이미지나 이름을 변경하고 ID를 확인합니다.
* **Workspace collaborators**: 사용자를 초대하고 Workspace 접근 권한을 관리합니다.
* **Integrations**: Workspace에 연결된 서비스와 리소스를 관리합니다.
* **Customization**: Agent에 적용되는 workspace 전체 범위의 custom instructions, skills, Memory를 구성합니다. 설정 방법과 권한은 [Agent 커스터마이징](/ko/features/agent/agent-customization)을 참조하세요.
* **Design systems** 및 **Slides templates**: 조직 전체에서 재사용할 수 있는 디자인 가이드와 프레젠테이션 템플릿을 관리합니다. 두 기능 모두 Enterprise 전용입니다. [Design systems](/ko/teams/custom-design-system)와 [Custom templates](/ko/teams/custom-templates)를 참조하세요.
* **Security**: Workspace에 적용되는 보안 제어 항목을 검토합니다. [보안 개요](/ko/features/security/overview)를 참조하세요.
* **Groups**: 멤버를 그룹으로 구성하고 그룹 권한을 적용합니다. [그룹 및 권한](/ko/teams/identity-and-access-management/groups-and-permissions)을 참조하세요.

<div id="account-settings">
  ## 계정 설정
</div>

여러 Workspace에 걸쳐 적용되는 설정은 **Account** 섹션에서 관리하세요.

* **Usage**, **Billing**, **Account seats**: usage 및 billing 정보를 확인하고, 역할에서 허용하는 경우 좌석을 관리합니다.
* **Advanced**: Agent model provider 정책을 비롯한 고급 계정 제어 항목을 확인합니다. Enterprise provider 및 Workspace별 workflow는 [모델 제어](/ko/features/collaboration/enterprise-model-controls)를 참조하세요.
* **Developer**: Admin API key를 관리하고 요청 기록을 확인합니다. 키를 생성하거나 교체하기 전에 [Admin API](/ko/teams/admin-api)를 참조하세요.

<div id="user-settings">
  ## User 설정
</div>

**User** 섹션에서 본인의 **Profile** 및 **Personalization** 환경설정을 관리하세요. 같은 섹션에서 Replit 커뮤니티로 이동하는 링크도 제공됩니다.
