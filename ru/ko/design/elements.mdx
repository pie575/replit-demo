**Элемент** — это любая отдельная часть фрейма: заголовок, кнопка, изображение, поле формы и т. д. Элементы позволяют изменить только часть фрейма, не создавая его заново.

<div id="section">
  ## Выбор элементов
</div>

Используйте [инструмент Edit](/ru/ko/design/toolbar#edit) на панели инструментов. Когда Edit активен, щёлкните внутри запущенного фрейма, чтобы выбрать элемент под курсором. Вокруг выбранного элемента появится контур выделения и небольшой встроенный промпт, с помощью которого можно попросить Agent внести изменения.

<Note>
  Если на Canvas нет фреймов, Edit отключён и доступен только на компьютере.
</Note>

<div id="visual-editor">
  ## Visual Editor
</div>

При выборе элемента открывается правая панель **Visual Editor** со встроенным промптом. Все элементы управления на ней сгруппированы в понятные разделы, чтобы вы быстрее находили нужное: **Text**, **раскладка**, **Color**, **Border**. (При выборе изображения также появляется раздел **Image**.)

<div id="layout">
  ### Раскладка
</div>

В разделе **раскладка** можно настроить расположение дочерних элементов внутри контейнера без участия Agent. Выберите flex-контейнер и разверните раскладку, чтобы увидеть следующие параметры.

* **Alignment**: сетка 3×3 для выбора положения элементов по обеим осям внутри контейнера.
* **Direction**: две кнопки со стрелками для расположения дочерних элементов в строку или столбец.
* **Gap**: значение в пикселях, обозначающее расстояние между элементами. Значок рядом с полем ввода Gap меняется в зависимости от текущего направления, поэтому вы всегда знаете, настраиваете ли горизонтальный или вертикальный интервал. Значок стрелки рядом с ним включает или выключает параметр **Distribute space between items**, который распределяет дочерние элементы по противоположным краям контейнера.
* **Outer space**: поля ввода для настройки внешних отступов с каждой стороны элемента (по одному для каждой из четырёх сторон), а также переключатель связи, позволяющий задавать одинаковые значения для всех четырёх сторон.
* **Inner space**: поля ввода для настройки внутреннего пространства элемента по каждой оси, а также переключатель связи, позволяющий задавать одинаковые значения для обеих осей.

Раздел раскладка отображается только тогда, когда к выбранному элементу применён хотя бы один параметр раскладки. Обычные текстовые узлы без отступов или свойств раскладки полностью скрывают этот раздел, помогая сохранять интерфейс редактора лаконичным.

Подробнее о разделах **Text**, **Color**, **Border** и **Image** см. в [руководстве по Visual Editor](/ru/ko/design/visual-editor).
