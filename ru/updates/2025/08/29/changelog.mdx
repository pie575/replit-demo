<div id="app-themes">
  ### Темы App
</div>

Преобразите свои веб-App с помощью красивых профессиональных тем. Применяйте собственные оформления и делитесь темами с командой, чтобы поддерживать единый фирменный стиль во всех проектах.

Подробнее о том, [как использовать темы App](/ru/replitai/app-themes).

Некоторые элементы Preview созданы под влиянием [tweakcn](https://github.com/jnsahaj/tweakcn). Загляните в открытый репозиторий проекта Sahaj Jain [здесь](https://github.com/jnsahaj/tweakcn).

<div id="shareable-app-creation-links">
  ### Ссылки для создания App
</div>

Поделитесь возможностями создания App с помощью ИИ. Генерируйте ссылки, которые автоматически создают App по вашим prompt, — так проще делиться идеями и помогать другим сделать первый шаг.

```md theme={null}
replit.com/create?prompt="Make me a cool demo for my app idea"
```

<div id="agent-infrastructure-upgrades">
  ### Обновления инфраструктуры Agent
</div>

Agent теперь работает на улучшенной инфраструктуре: он эффективнее справляется с задачами, глубже анализирует контекст и дольше работает в рамках одной сессии. Благодаря этим обновлениям Agent справляется с более крупными проектами и выдаёт более качественные результаты в любых задачах по написанию кода.

<div id="organization-subscription-cancellation">
  ### Отмена подписки организации
</div>

Теперь управлять подписками организаций стало гибче. Вы можете отменить подписку, не удаляя организацию, и сохранить полный доступ до конца оплаченного периода.
