  ## 团队与 Enterprise
</div>

<div id="replitenterprise">
  ### 无需离开 Replit 即可升级到 Enterprise
</div>

现在，无论您使用的是 Free、Core 还是 Pro 计划，都可以直接在产品内升级到 Replit Enterprise，无需事先联系销售团队。如果您有协作工作区，完成结账后将自动迁移到新的 Enterprise 组织。已发布的 App 将保持在线运行，不会出现停机。

<div id="stripe">
  ### 安装应用即可连接 Stripe，无需复制密钥
</div>

现在用 Stripe 发布 App 更简单了。不必再从 Stripe 控制台复制线上 API 密钥，只需从 Stripe Marketplace 安装 Replit 集成支付应用，生产环境密钥即会自动配置。打开 Publish 面板，安装应用，然后在 Stripe 中完成连接。

<Frame>
  <img src="/assets/mirror/stripe-replit-integrated-payments-23b3b2386671.png" alt="Agent 聊天面板中的 Stripe 连接器卡片。卡片标题为“连接到 Stripe”，带有 Stripe S 徽标；副标题为“从 Stripe 沙盒开始，测试支付功能。直接在 Replit 中创建产品并执行测试交易。”；以及“忽略”和“连接到 Stripe”按钮。" width="2678" height="1448" data-path="images/billing/stripe-replit-integrated-payments.png" />
</Frame>

详情请参阅[使用 Stripe 上线发布](/zh/ja/features/monetization/stripe-payments#go-live)。

  ## Agent

<div id="agent-2">
  ### Agent 现可生成音乐、音效和语音
</div>

Agent 现在可以为你的应用创建音频。只需请求背景音乐、音效或旁白，Agent 就会生成音频并直接添加到你的项目中。使用量将从 Replit 积分中扣除。

详细了解[音频生成](/zh/ja/features/agent/audio-generation)。

<div id="canvas">
  ### 在 Canvas 上直接生成媒体
</div>

现在你可以直接在 Canvas 上创建媒体内容。打开 Canvas 工具栏中的 **Generate** 工具，选择 **Image**、**Vector Graphic** 或 **Video**，即可就地生成。所有操作都在画板上完成，无需来回切换工具即可完成设计与迭代。
