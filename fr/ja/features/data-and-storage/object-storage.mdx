Le stockage d&#39;App est le stockage d&#39;objets intégré de Replit : il permet à vos applications d&#39;héberger et de conserver facilement des images, des vidéos, des documents et autres fichiers importés.
Un bucket est un conteneur qui stocke des objets, tels que des fichiers. Il inclut des règles d&#39;accès qui limitent les actions que les utilisateurs ou les applications peuvent effectuer sur son contenu.

<Info>
  Nous avons renommé le <strong>stockage d&#39;objets</strong> en <strong>stockage d&#39;App</strong>. Les fonctionnalités restent inchangées : vos buckets, permissions et accès programmatiques existants continuent de fonctionner.
</Info>

Grâce au stockage d&#39;App, vous pouvez créer des applications telles que :

* **Plateformes de partage de photos** : permettez aux créateurs d&#39;importer, de stocker et d&#39;afficher des images
* **Services de diffusion vidéo** : gérez l&#39;import des vidéos et diffusez le contenu aux spectateurs
* **Systèmes de gestion documentaire** : stockez et organisez les fichiers des créateurs avec un accès sécurisé
* **Sites portfolio** : présentez vos travaux avec des fichiers multimédias qui se chargent de façon fiable
* **Services de sauvegarde de fichiers** : offrez aux créateurs un stockage cloud pour leurs fichiers importants

<Note>
  Demandez à **Agent** d&#39;ajouter le stockage d&#39;App à votre application et précisez les types de fichiers qu&#39;elle doit gérer. Agent configure l&#39;intégration, crée les buckets nécessaires et met à jour votre application pour qu&#39;elle puisse importer, stocker et récupérer des fichiers, avec des fonctionnalités avancées comme l&#39;authentification et le contrôle d&#39;accès.
</Note>

L&#39;outil de stockage d&#39;App vous permet de partager vos données en toute fluidité entre vos environnements de développement et de production, ou avec d&#39;autres Replit Apps.

<div id="section">
  ## Fonctionnalités
</div>

<Info>
  stockage d’App utilise Google Cloud Storage (GCS).
  Vous bénéficiez ainsi d’une disponibilité, d’un temps de fonctionnement et d’une sécurité de premier plan.
</Info>

stockage d’App offre les fonctionnalités suivantes aux Apps Replit :

* **Stockage cloud persistant** : stockez les fichiers auxquels vos applications publiées et vos utilisateurs doivent continuer à accéder
* **Gestion évolutive des fichiers** : répondez à des besoins croissants en données sans vous soucier des limites de stockage
* **Partage de données entre applications** : partagez des buckets entre plusieurs Apps Replit pour les architectures distribuées
* **Accès programmatique** : chargez, téléchargez et gérez des fichiers à l’aide d’une API intuitive
* **Intégration Agent avancée** : laissez Agent configurer stockage d’App avec des paramètres avancés, vérifier votre configuration existante et générer le code backend et frontend complet, y compris l’authentification et le contrôle d’accès

Exemples d’utilisation d’stockage d’App dans une App Replit :

* Stocker les photos de profil des créateurs et les fichiers multimédias importés
* Fournir des images de produits pour un site d’e-commerce
* Traiter les documents importés via des formulaires
* Créer des fonctionnalités de partage de fichiers et de collaboration
* Créer un système de gestion de contenu avec une médiathèque

<Tip>
  **Intégration Agent avancée** : vous pouvez demander à [Replit Agent](/fr/ja/features/agent/overview) d’ajouter automatiquement stockage d’App à votre application ! Agent peut configurer le stockage d’objets, vérifier la configuration et générer le code backend et frontend complet incluant des fonctionnalités avancées telles que l’authentification et le contrôle d’accès. Il suffit de mentionner « stockage d’App » ou « stockage de fichiers » dans votre prompt.

  Consultez plus de détails sur les [intégrations Agent](/fr/ja/features/integrations/overview#data-storage--management) et tous les prompts disponibles pour stockage d’App.
</Tip>

<div id="section-2">
  ## Utilisation
</div>

<Note>
  Une Replit App doit s&#39;authentifier auprès de Google Cloud Storage pour accéder aux buckets et à leurs objets.
  Utilisez la bibliothèque cliente officielle stockage d’App de Replit pour vous authentifier automatiquement.
</Note>

Vous pouvez accéder à l&#39;outil stockage d’App directement depuis l&#39;éditeur de projet.

<Accordion title="Comment accéder à l'outil stockage d’App">
  Depuis le **dock d&#39;outils** à gauche :

  1. Sélectionnez <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Icône de tous les outils" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **Tous les outils** pour afficher la liste des outils de l&#39;éditeur de projet.
  2. Sélectionnez <img class="icon-svg" src="/assets/mirror/object-storage-monoochrome-icon-aaba8f517280.svg" alt="Icône stockage d’App" width="16" height="16" data-path="images/icons/object-storage-monoochrome-icon.svg" /> **stockage d’App**.

  Depuis la **barre de recherche** :

  1. Sélectionnez la <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="Icône loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> loupe en haut pour ouvrir l&#39;outil de recherche.
  2. Saisissez « stockage d’App » pour trouver l&#39;outil, puis sélectionnez-le dans les résultats.
</Accordion>

Pour associer un nouveau bucket de stockage à votre Replit App, créez un bucket.

<Accordion title="Comment créer un bucket">
  Depuis l&#39;outil **stockage d’App** :

  1. Cliquez sur **Créer un nouveau bucket**.
  2. Saisissez le nom du bucket dans le champ **Nom**, puis sélectionnez **Créer le bucket**.

  L&#39;onglet stockage d’App ressemble alors à la capture d&#39;écran suivante :

  <Frame>
    <img src="/assets/mirror/object-storage-empty-bucket-3462e2efb1bc.png" alt="Capture d'écran de l'outil stockage d’App" width="2790" height="1218" data-path="images/databases/object-storage-empty-bucket.png" />
  </Frame>

  Pour créer d&#39;autres buckets, ouvrez le menu déroulant des buckets en haut à gauche de l&#39;onglet **stockage d’App** et sélectionnez **Créer un nouveau bucket**.

<div id="id">
  ### Accéder à l&#39;ID du bucket
</div>

Vous pouvez afficher l&#39;**ID du bucket** en sélectionnant la vue **Paramètres** dans le menu déroulant situé en haut de l&#39;onglet **Stockage de l&#39;App**.
L&#39;ID du bucket identifie le bucket de manière unique et votre code doit y faire référence pour effectuer des opérations.

Si vous disposez de plusieurs buckets, sélectionnez celui qui convient dans le menu déroulant situé dans le coin supérieur gauche.

<div id="section-4">
  ### Téléverser et télécharger des objets
</div>

Pour téléverser des objets dans le bucket sélectionné :

1. Accédez à la vue **Objets** de l&#39;onglet **Stockage de l&#39;App**.
2. Sélectionnez <img class="icon-svg" src="/assets/mirror/upload-file-5894be4232ce.svg" alt="Icône de téléversement de fichier" width="16" height="16" data-path="images/icons/upload-file.svg" /> **Téléverser un fichier**, ou <img class="icon-svg" src="/assets/mirror/upload-folder-fc87519bedf9.svg" alt="Icône de téléversement de dossier" width="16" height="16" data-path="images/icons/upload-folder.svg" /> **Téléverser un dossier** pour téléverser tous les fichiers d&#39;un dossier.
   Choisissez ensuite un ou plusieurs fichiers dans la boîte de dialogue.
   Vous pouvez également faire glisser des fichiers ou des dossiers vers la zone qui affiche le contenu du bucket.

Pour télécharger des objets depuis le bucket sélectionné :

1. Accédez à la vue **Objets** de l&#39;onglet **Stockage de l&#39;App**.
2. Sélectionnez l&#39;icône de téléchargement <img class="icon-svg" src="/assets/mirror/download-icon-c7b527953d65.svg" alt="Icône de téléchargement" width="16" height="16" data-path="images/icons/download-icon.svg" /> située à droite du fichier à télécharger.

<div id="section-5">
  ### Organiser les objets dans des dossiers
</div>

Pour créer un dossier dans le bucket sélectionné :

1. Accédez à la vue **Objets** de l&#39;onglet **Stockage de l&#39;App**.
2. Dans la vue **Objets**, sélectionnez <img class="icon-svg" src="/assets/mirror/create-folder-c9acf112a042.svg" alt="Icône de création de dossier" width="16" height="16" data-path="images/icons/create-folder.svg" /> **Créer un dossier**.
3. Saisissez le nom du dossier.

Pour ajouter un objet à un dossier dans la vue **Objets**, faites glisser l&#39;objet vers le dossier souhaité.

Pour déplacer un objet vers le dossier parent, faites-le glisser sur l&#39;en-tête situé au-dessus de la liste des objets, jusqu&#39;au nom du dossier qui y est affiché.

<div id="section-6">
  ### Supprimer un objet ou un bucket
</div>

<Warning>
  Les suppressions sont irréversibles. Sauvegardez vos données importantes avant de continuer.
</Warning>

Pour supprimer définitivement un objet :

1. Accédez à la vue **Objets** de l&#39;onglet **Stockage de l&#39;App**.
2. Sélectionnez l&#39;icône de corbeille <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="Icône de corbeille" width="16" height="16" data-path="images/icons/trash-icon.svg" /> située à côté de l&#39;objet à supprimer.
3. Confirmez la suppression dans la boîte de dialogue.

Pour supprimer un bucket et tous les objets qu&#39;il contient :

1. Accédez à la vue **Paramètres** de l&#39;onglet **Stockage de l&#39;App**.
2. Sélectionnez le bucket à supprimer dans le menu déroulant des buckets, en haut à gauche.
3. Sélectionnez <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="Icône de corbeille" width="16" height="16" data-path="images/icons/trash-icon.svg" /> **Supprimer le bucket**.
4. Confirmez la suppression dans la boîte de dialogue.

<div id="section-7">
  ### Gestion de l&#39;accès aux buckets
</div>

Replit relie à votre compte tous les buckets créés et les rend accessibles à toutes vos Replit Apps. La Replit App à l&#39;origine du bucket en reçoit automatiquement les droits d&#39;accès.

En contrôlant quelles Replit Apps peuvent accéder à un bucket donné, vous partagez vos données de manière efficace et sécurisée.

Pour autoriser une Replit App à accéder à un bucket appartenant à une autre app de votre compte :

1. Dans le menu des buckets situé en haut à gauche de l&#39;onglet Stockage de l&#39;App, sélectionnez <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="Icône loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" />
   **Ajouter un bucket existant**.
2. Dans la boîte de dialogue **Choisir un bucket**, sélectionnez le bucket à ajouter, puis choisissez **Ajouter le bucket au Repl**.

<Frame>
  <img src="/assets/mirror/choose-bucket-dialog-b709aa247a85.png" alt="Capture d'écran de la boîte de dialogue de sélection de bucket" width="1115" height="457" data-path="images/databases/choose-bucket-dialog.png" />
</Frame>

Pour révoquer l&#39;accès d&#39;une Replit App à un bucket :

1. Accédez à la vue **Paramètres** de l&#39;onglet **Stockage de l&#39;App**.
2. Sélectionnez le nom du bucket dans la liste déroulante des buckets, en haut à gauche de l&#39;onglet.
3. Sélectionnez **Supprimer le bucket AI du Repl**, puis confirmez la suppression dans la boîte de dialogue de confirmation.

Pour accéder au stockage d&#39;App depuis une Replit App, utilisez l&#39;une des bibliothèques suivantes :

* SDK Replit App Storage (disponible en JavaScript et en Python)
* <a href="https://cloud.google.com/storage/docs/reference/libraries" target="_blank">Bibliothèques clientes Google Cloud Storage</a>

Pour savoir comment utiliser ces bibliothèques clientes, consultez les ressources suivantes :

* [SDK JavaScript App Storage](/fr/ja/features/sdks/object-storage-javascript-sdk/) : référence client du SDK JavaScript
* [SDK Python App Storage](/fr/ja/features/sdks/object-storage-python-sdk/) : référence client du SDK Python
* [Application d&#39;exemple du SDK Google Cloud Python](https://replit.com/@matt/GCS-Python-Uploads?v=1) : remixez cette application pour gérer vos objets avec le SDK Google Cloud Python
