아래 답변은 구독 관리에 대한 내용입니다. 전체 plan 세부 정보는 [Core](/ko/billing/plans/replit-core)와 [Pro](/ko/billing/plans/replit-pro)를 참고하세요.

<AccordionGroup>
  <Accordion title="Core에서 Pro로 업그레이드하려면 어떻게 하나요? 그리고 차이점은 무엇인가요?">
    [Core](/ko/billing/plans/replit-core)와 비교하면 [Pro](/ko/billing/plans/replit-pro)({ProPlanPrice}/월)에는 다음이 추가됩니다:

    * 더 많은 Free Mode 사용량
    * 최대 10개의 Agent task 동시 실행
    * pooled credits를 함께 사용하는 최대 15명의 builders
    * 등급별 credits. 사용하지 않은 credits는 {ProCreditRolloverPeriod} 동안 이월
    * 28일 database 복원 기간(Core는 7일)
    * 우선 지원

    업그레이드하려면 **Settings → Billing**을 열고 Pro plan을 선택한 뒤 결제 정보를 확인하세요. 기능 비교와 최신 pricing은 [pricing page](https://replit.com/pricing)를 참고하세요.
  </Accordion>

  <Accordion title="구독을 취소하려면 어떻게 하나요?">
    **Settings → Billing**을 열고 구독 취소 옵션을 선택한 다음 확인 단계를 완료하세요. billing period가 끝날 때까지는 plan 기능을 그대로 사용할 수 있으며, 이후 account는 무료 [Starter plan](/ko/billing/plans/starter-plan)으로 전환됩니다.

    전환되기 전에 published app이 offline 상태가 될 수 있고, custom domain 연결이 해제되며, 저장 공간이 줄어든다는 점을 유의하세요. 보관하려는 항목은 미리 download하세요. 구독 상태가 `past_due`로 표시된다면 결제가 실패했을 수 있으니, 취소하기 전에 먼저 해결하세요.
  </Accordion>

  <Accordion title="갱신 결제가 실패했습니다. 결제 수단을 어떻게 업데이트하나요?">
    **Settings → Billing**을 열고 **Update payment method**를 선택한 뒤 카드를 추가하거나 업데이트하세요. 저장하면 Replit이 미결제 금액에 대한 결제를 자동으로 재시도합니다.

    문제가 계속되면 결제 인텐트 ID(`pi_`로 시작)와 함께 [Replit Support에 문의](https://replit.com/support)하세요. billing 실패 안내 메일이 스팸함으로 분류되는 경우도 있습니다.
  </Accordion>

  <Accordion title="구독을 다른 이메일이나 account로 이전하려면 어떻게 하나요?">
    구독은 Replit account에 연결되어 있어 직접 이전할 수 없습니다. 구독을 유지하면서 account의 이메일만 변경하려면 **Settings → Profile**로 이동해 이메일을 수정하세요.

    구독을 다른 account로 옮기려면 [Replit Support에 문의](https://replit.com/support)하세요. 이런 경우는 건별로 처리됩니다.
  </Accordion>

  <Accordion title="한 달에 두 번 청구되었습니다. 무슨 일인가요?">
    한 달에 두 건이 청구되는 경우는 보통 다음 중 하나입니다:

    * 구독료와 별도로, billing 임계값에 도달한 usage 요금이 청구된 경우
    * 이전에 실패한 결제가 재시도되어 성공한 경우
    * 활성 구독이 두 개 이상인 경우

    각 청구 항목의 내역을 확인하려면 **Settings → Account usage**를 열고 **See previous invoices**를 선택하세요. 그래도 내용이 맞지 않는다면 [Replit Support에 문의](https://replit.com/support)하세요.
  </Accordion>

  <Accordion title="plan을 변경했는데 새 기능을 사용할 수 없습니다. 어떻게 해야 하나요?">
    plan 변경은 보통 즉시 적용됩니다. 새 기능이 표시되지 않는다면:

    1. `Cmd+Shift+R`(Mac) 또는 `Ctrl+Shift+R`(Windows)로 강력 새로고침하세요.
    2. 로그아웃한 후 다시 로그인하세요.
    3. **Settings → Billing**을 열고 변경이 정상적으로 처리되었는지 확인하세요. 새 plan 이름이 표시되어야 합니다.

    billing에는 올바른 plan이 표시되는데도 기능이 나타나지 않는다면, 사용자 이름과 사용하려는 기능을 함께 알려 [Replit Support에 문의](https://replit.com/support)하세요.
  </Accordion>

  <Accordion title="취소하는 대신 구독을 일시 중지할 수 있나요?">
    일부 subscribers는 취소 대신 구독을 한 달간 일시 중지할 수 있습니다. 대상에 해당한다면 취소를 진행할 때 해당 옵션이 표시됩니다. 일시 중지 기간에는:

    * 다음 결제가 건너뛰어지고 월별 credits는 지급되지 않습니다
    * published projects는 계속 운영되고 공동 작업자도 그대로 접근할 수 있습니다
    * 대상이 되는 credits는 이월되고 credit packs도 계속 사용할 수 있습니다
    * Agent 및 호스팅 usage는 사용한 만큼 그대로 청구됩니다

    **Settings → Billing**에는 **Paused** badge와 일시 중지 종료일이 표시되며, 해당 날짜에 구독이 자동으로 재개됩니다. 예약된 일시 중지는 적용되기 전에 취소할 수 있지만, 이미 진행 중인 일시 중지는 조기에 종료할 수 없습니다. 구독 일시 중지는 한 번만 가능합니다.
  </Accordion>
</AccordionGroup>
