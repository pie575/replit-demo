Replit AI Integrations를 사용하면 AI 기반 애플리케이션을 손쉽게 만들 수 있습니다. OpenAI, Anthropic, Google, OpenRouter의 모델을 지금 바로 사용해 보세요. 개발자 계정을 만들 필요도, API 키를 관리할 필요도 없습니다. Replit이 모든 것을 알아서 처리합니다.

<div id="what-is-replit-ai-integrations">
  ## Replit AI Integrations란?
</div>

Replit AI Integrations는 주요 provider의 AI 모델을 관리형으로 사용할 수 있게 해줍니다. Replit을 벗어나지 않고도 채팅 앱, 콘텐츠 생성기, AI 기반 도구를 만들 수 있습니다. 외부 developer account를 만들거나 API 자격 증명을 찾거나 별도의 billing을 관리할 필요가 없습니다.

Replit AI Integrations를 사용하면 Replit이 provider 자격 증명을 관리하고 public API price로 요금을 청구합니다. usage는 Replit 크레딧에서 차감되며, [usage page](/ko/billing/managing-spend)에 기존 Replit App별로 구분되어 표시됩니다.

<Note>
  Replit AI Integrations를 사용하려면 paid plan(Core, Pro 또는 Enterprise)이 필요합니다. [Starter plan](/ko/billing/plans/starter-plan)에서도 직접 보유한 API key로 AI 앱을 만들 수 있습니다. [플랜 이용 가능 여부](#plan-availability)를 참고하세요.
</Note>

<div id="features">
  ## 기능
</div>

Replit AI Integrations는 기본 제공되는 액세스와 투명한 청구 방식으로 AI 개발을 간소화합니다:

* **설정 불필요**: 시작하는 데 개발자 계정이나 API 키가 필요하지 않습니다
* **자격 증명 관리**: Replit이 공급자 인증과 자격 증명 관리를 대신 처리합니다
* **투명한 청구**: 공개된 API 요금 그대로 지불하며, Replit 크레딧에서 차감됩니다
* **사용량 추적**: 사용량 페이지에서 기존 Replit App별 사용량을 확인할 수 있습니다
* **모든 스택 지원**: 모든 프로그래밍 언어와 프레임워크에서 작동합니다
* **BYOK 선택 가능**: 자체 자격 증명을 사용하고 싶다면 직접 보유한 API 키를 연결할 수 있습니다

<div id="getting-started">
  ## 시작하기
</div>

<div id="using-replit-managed-credentials">
  ### Replit 관리형 자격 증명 사용하기
</div>

유료 plan에서는 prompt에 AI functionality나 특정 provider(OpenAI, Anthropic, Google, OpenRouter)를 언급하면 Agent가 기본적으로 Replit AI Integrations를 사용합니다:

<AiPrompt>
  OpenAI를 사용해 기사를 요약하는 web app을 만들어 줘
</AiPrompt>

어떤 integration이 사용되는지는 초기 prompt 응답에 **&quot;OpenAI (Replit managed)&quot;**, **&quot;Anthropic (Replit managed)&quot;**, **&quot;Google (Replit managed)&quot;**, **&quot;OpenRouter (Replit managed)&quot;** 중 어떤 표시가 있는지 보면 알 수 있습니다. 이 표시는 Agent가 사용자의 API key 없이 Replit의 자격 증명을 사용한다는 뜻입니다.

**초기 빌드의 경우**: AI functionality가 포함된 새 앱을 만들기 위해 초기 prompt를 제출하면 Replit AI Integrations가 자동으로 연결됩니다. Agent는 곧바로 Replit의 관리형 자격 증명으로 building을 시작합니다.

**기존 Replit Apps의 경우**: 기존 Replit App에 AI functionality를 추가하려는 의도를 Agent가 감지하면, 사용자의 API key 대신 Replit AI Integrations를 사용해도 될지 Project Editor에서 명시적으로 묻습니다. 다음과 같은 confirmation prompt가 표시됩니다:

<Frame>
  <img src="/assets/mirror/replit-ai-integrations-confirmation-msg-9440681ad7d3.png" alt="API key 없이 Replit의 관리형 서비스를 사용해 OpenAI를 추가한다는 메시지와 Dismiss 및 Approve 버튼이 있는 Confirm OpenAI Integration 대화 상자" width="924" height="294" data-path="images/replitai/replit-ai-integrations-confirmation-msg.png" />
</Frame>

Replit 관리형 자격 증명으로 계속하려면 &quot;Approve&quot;를, 직접 준비한 API key를 사용하려면 &quot;Dismiss&quot;를 클릭하세요.

usage는 자동으로 추적되며 public API price로 Replit account에 청구됩니다.

<div id="bringing-your-own-api-key">
  ### 직접 준비한 API key 사용하기
</div>

Replit AI Integrations 대신 OpenAI, Anthropic, Google 등 다른 provider에서 발급받은 본인의 자격 증명을 사용하고 싶다면 몇 가지 방법이 있습니다.

**처음 앱을 만들 때(initial builds)**: 본인의 API key를 사용하겠다는 내용을 prompt에 포함하세요.

<AiPrompt>
  OpenAI를 사용해 기사를 요약하는 web app을 만들어 주세요. 제 OpenAI API key를 사용하세요.
</AiPrompt>

응답에 &quot;Replit managed&quot; 표시 없이 provider 이름만 나타난다면, Agent가 여러분의 API key를 요청하겠다는 의미입니다.

**기존 Replit Apps의 경우**: Agent가 Replit AI Integrations를 사용하겠다고 알리며 confirmation prompt를 표시하면 &quot;Approve&quot; 대신 &quot;Dismiss&quot;를 클릭하세요.

두 경우 모두 Agent는 첫 번째 checkpoint까지 빌드한 뒤에 API key를 요청합니다. 덕분에 Agent가 project 구조를 먼저 잡아 둔 다음 잠시 멈춰 자격 증명을 받을 수 있습니다.

본인의 API key를 사용하면 Replit 크레딧이 아니라 provider가 직접 요금을 청구합니다.

<div id="viewing-your-usage">
  ## 사용량 확인하기
</div>

모든 Replit AI Integrations 사용량은 다른 Replit 사용량과 함께 [사용량 페이지](/ko/billing/managing-spend)에 표시됩니다. 사용량은 기존 Replit App별로 구분되므로 AI 지출이 어디에서 발생하는지 정확히 파악할 수 있습니다.

<div id="supported-providers">
  ## 지원되는 provider
</div>

Replit AI Integrations가 현재 지원하는 항목은 다음과 같습니다:

* **OpenAI**: 텍스트 생성, 추론, 오디오를 지원하는 멀티모달 model. 채팅 완성, 응답, 이미지 생성, 오디오 transcription(`gpt-4o-transcribe`, `gpt-4o-mini-transcribe`), audio output(`gpt-audio`, `gpt-audio-mini`)을 지원합니다.
* **Anthropic**: 추론, 작문, 코딩에 적합한 멀티모달 model. Messages API와 웹 검색 연동을 지원합니다.
* **Google (Gemini)**: 텍스트 생성과 추론에 적합한 멀티모달 model. 텍스트 및 이미지 생성을 지원합니다.
* **OpenRouter**: Microsoft(Phi 시리즈), Meta(Llama 시리즈), Mistral, Qwen, DeepSeek, Nvidia, Amazon 등 다양한 provider의 model을 사용할 수 있습니다.

<Note>
  Replit AI Integrations는 **텍스트, 이미지, audio output**을 지원하며, video output은 지원하지 않습니다. 영상 생성 기능이 필요하다면 해당 기능을 제공하는 provider에서 발급받은 본인의 API key를 사용해야 합니다.
</Note>

<div id="openrouter-privacy-and-availability">
  ## OpenRouter 개인정보 보호 및 사용 가능 여부
</div>

Replit AI Integrations를 통해 OpenRouter를 사용하면 데이터를 보호하기 위해 요청에 특정 개인정보 보호 설정이 적용되어 전송됩니다. 이러한 설정은 사용할 수 있는 model에 영향을 줄 수 있으므로 잘 이해해 두는 것이 중요합니다.

<div id="privacy-settings-for-self-serve-users">
  ### self-serve 사용자를 위한 개인정보 설정
</div>

개인 및 팀 사용자의 경우, Replit은 다음과 같은 개인정보 기본값으로 OpenRouter 요청을 구성합니다.

* **유료 endpoints 학습 비활성화**: 유료 model provider는 사용자의 데이터를 학습에 사용하지 않습니다
* **무료 endpoints 학습 활성화**: 무료 model provider가 사용자의 prompts와 응답을 학습에 사용할 수 있습니다
* **무료 endpoints 게시 활성화**: 무료 provider가 사용자의 prompts와 응답을 공개 datasets에 게시할 수 있습니다
* **입력/출력 로깅 비활성화**: 1% billing 할인을 위해 OpenRouter가 사용자의 요청과 응답을 기록하지 않습니다
* **분석 쿠키 비활성화**: 분석 쿠키를 사용하지 않습니다

이러한 설정은 최대한 다양한 model을 사용할 수 있게 하면서도 개인정보 보호를 우선합니다. 다만 위 구성과 다른 개인정보 설정이 필요한 **일부 model은 사용하지 못할 수 있습니다**.

<div id="privacy-settings-for-enterprise">
  ### Enterprise의 개인정보 보호 설정
</div>

Enterprise 조직에는 Replit이 더 엄격한 개인정보 보호 정책을 적용합니다.

* **Zero Data Retention(ZDR) endpoints만 사용**: Zero Data Retention 정책을 준수하는 model만 사용할 수 있습니다
* 위에 설명된 self-serve 사용자용 개인정보 보호 설정도 모두 동일하게 적용됩니다
* 이에 따라 Enterprise 요청은 데이터를 전혀 보관하지 않는 endpoints로만 라우팅됩니다

Enterprise는 ZDR endpoints만 허용하므로, self-serve 사용자에 비해 **사용 가능한 model의 선택 폭이 좁아집니다**. 대신 이러한 제약을 통해 엔터프라이즈 워크로드에 최고 수준의 데이터 프라이버시를 보장할 수 있습니다.

<div id="plan-availability">
  ## 플랜별 이용 가능 여부
</div>

Replit AI Integrations를 사용하려면 유료 플랜이 필요하며, 액세스 방식은 사용 중인 플랜에 따라 달라집니다.

<div id="starter-free">
  ### Starter(무료)
</div>

Starter plan에서는 Replit AI Integrations를 사용할 수 없습니다. 다만 본인의 API key를 사용해 AI 앱을 빌드할 수는 있습니다. [본인의 API key 사용하기](#bringing-your-own-api-key)를 참조하세요.

<div id="core">
  ### Core
</div>

Core 플랜에서는 Replit이 관리하는 자격 증명을 사용해 Replit AI Integrations로 AI 앱을 만들 수 있으며, 별도로 관리할 API key가 필요하지 않습니다.

<div id="pro-and-enterprise">
  ### Pro 및 Enterprise
</div>

Pro 및 Enterprise 조직에서는 Replit AI Integrations 접근이 기본적으로 비활성화되어 있습니다. 조직 관리자는 조직 설정 페이지에서 접근 권한을 관리할 수 있습니다.

1. 조직 설정으로 이동합니다
2. Replit AI Integrations 섹션을 찾습니다
3. 조직의 접근 권한을 켜거나 끕니다

활성화하면 조직 구성원이 자신의 앱에서 Replit AI Integrations를 사용할 수 있습니다. 모든 사용량은 추적되어 조직 계정으로 청구됩니다. 비활성화하면 구성원이 AI 모델 provider를 사용하려면 직접 API key를 입력해야 합니다.

<div id="use-cases">
  ## 활용 사례

어떤 스택에서든 강력한 AI 애플리케이션을 만들어 보세요:

<div id="faq">
  ## FAQ
</div>

<AccordionGroup>
  <Accordion title="다른 Agent integrations와는 무엇이 다른가요?">
    다른 Agent integrations는 외부 서비스와 API에 연결하는 기능을 제공합니다. 반면 Replit AI Integrations는 OpenAI, Anthropic, Google, OpenRouter 같은 AI 모델 provider에 대한 관리형 액세스를 제공하며, 자격 증명과 billing을 Replit이 처리하므로 곧바로 building을 시작할 수 있습니다.
  </Accordion>

  <Accordion title="유료 Replit account가 필요한가요?">
    네. Replit AI Integrations는 유료 사용자만 이용할 수 있습니다.
  </Accordion>

  <Accordion title="어떤 모델을 사용할 수 있나요?">
    Replit AI Integrations는 주요 AI provider의 모델을 지원합니다:

    |                |                                             |
    | -------------- | ------------------------------------------- |
    | **OpenAI**     | 텍스트 생성, 추론, 이미지 생성용 GPT 모델                  |
    | **Anthropic**  | 추론, 글쓰기, 코딩용 Claude 모델                      |
    | **Google**     | 멀티모달 이해용 Gemini 모델                          |
    | **OpenRouter** | Meta, Mistral, DeepSeek, Qwen 등 200개 이상의 모델 |

    네. Replit secrets를 통해 직접 보유한 API key를 등록할 수 있습니다. 본인의 키를 사용하면 Replit이 아닌 provider가 직접 청구합니다.
  </Accordion>

  <Accordion title="모든 프로그래밍 언어에서 동작하나요?">
    네. Replit AI Integrations는 Replit이 지원하는 모든 stack과 프로그래밍 언어에서 동작합니다.
  </Accordion>

  <Accordion title="제 account나 Organization에서 이 기능을 사용할 수 없는 이유는 무엇인가요?">
    Starter plan에서는 Replit AI Integrations가 비활성화되어 있습니다 — 사용하려면 Core로 업그레이드하거나 본인의 API key로 building하세요. Pro와 Enterprise에서는 보안과 통제를 위해 기본적으로 액세스가 비활성화되어 있으며, Organization admin이 Organization Settings 페이지에서 활성화할 수 있습니다.
  </Accordion>

  <Accordion title="Replit AI Integrations를 사용 중인지 어떻게 알 수 있나요?">
    Agent의 응답에서 &quot;OpenAI (Replit managed)&quot;, &quot;Anthropic (Replit managed)&quot;, &quot;Google (Replit managed)&quot;, &quot;OpenRouter (Replit managed)&quot;가 있는지 확인하세요. 이 표시는 Replit AI Integrations를 사용 중이라는 뜻입니다. &quot;Replit managed&quot; 없이 provider 이름만 표시된다면 Agent가 본인의 API key를 요청합니다.
  </Accordion>

  <Accordion title="Replit AI Integrations를 사용하면 어떻게 되나요?">
    AI functionality나 특정 provider(OpenAI, Anthropic, Google, OpenRouter)를 언급하면 Agent는 기본적으로 Replit AI Integrations를 사용합니다. 새 앱의 경우 Agent가 Replit의 자격 증명을 사용해 즉시 building을 시작합니다. 기존 Replit Apps의 경우, Agent가 Project Editor에서 Replit AI Integrations 사용을 요청한다고 알려주고 confirmation prompt를 표시합니다. 어느 경우든 앱에서 provider로 API 호출을 할 수 있으며, usage는 추적되어 Replit account로 청구됩니다.
  </Accordion>

  <Accordion title="confirmation prompt는 언제 표시되나요?">
    기존 Replit App에 Replit AI Integrations를 추가할 때 confirmation prompt가 표시됩니다. Agent는 본인의 API key 대신 Replit AI Integrations를 사용하도록 요청한다고 명확히 알려줍니다. 새 앱을 만드는 initial builds에서는 팝업 없이 Replit AI Integrations가 자동으로 연결됩니다.
  </Accordion>

  <Accordion title="본인의 키를 사용하려는 경우 Agent는 언제 API key를 요청하나요?">
    Agent는 첫 번째 checkpoint까지 building한 뒤에 API key를 요청합니다. 즉, Agent가 project 구조를 먼저 잡아둔 다음, 이어서 진행하기 전에 자격 증명을 받기 위해 잠시 멈추는 것입니다.
  </Accordion>

  <Accordion title="어떤 유형의 모델과 출력이 지원되나요?">
    Replit AI Integrations는 텍스트, 이미지, audio output을 지원합니다. 오디오 기능에는 `gpt-4o-transcribe`와 `gpt-4o-mini-transcribe`를 통한 transcription(음성-텍스트 변환), `gpt-audio`와 `gpt-audio-mini`를 통한 오디오 생성이 포함됩니다. video output은 지원되지 않습니다. 애플리케이션에 영상 생성 기능이 필요한 경우, Agent는 해당 기능을 제공하는 provider의 API key를 직접 사용하도록 안내합니다.
  </Accordion>
