<div id="o-que-um-framework-para-desenvolvedores">
  ## 什么是开发者框架？
</div>

开发者框架是由 Replit 平台和社区发布的 Replit Apps，其他用户可以将其作为起点使用。由 Replit 创建的官方框架，其名称旁会显示一个复选框：

<Frame>
  <img src="/assets/mirror/template-official-c5fe09e20415.png" alt="Replit 官方开发者框架" width="1051" height="246" data-path="images/programming-ide/creating-a-template/template-official.png" />
</Frame>

[HTML、CSS、JS](https://replit.com/@replit/HTML-CSS-JS?v=1#index.html) 框架非常受欢迎，可作为创建纯 JavaScript 项目的起点。你可以 fork 该框架来使用它。

<div id="templates-personalizados-para-empresas">
  ## Enterprise 自定义模板
</div>

Enterprise 组织可以创建[自定义模板](/zh/pt/teams/custom-templates)，供组织内所有成员在 Agent 收件箱中选择。自定义模板不仅提供开发者框架，还包含企业专属的 Agent 指令、技能和预先配置的项目上下文。有关详细信息，请参阅[自定义模板指南](/zh/pt/teams/custom-templates)。
