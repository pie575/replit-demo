# 관리자 API

> Replit 엔터프라이즈 관리자 API를 사용하여 계정 사용량, 워크스페이스, 멤버, 프로젝트에 프로그래밍 방식으로 액세스하세요.

<Note>
  관리자 API는 **베타** 버전입니다. 사용 가능한 엔드포인트와 동작이 변경될 수 있습니다.
</Note>

관리자 API는 엔터프라이즈 계정 관리자에게 계정 분석 및 관리 기능에 대한 스코프 기반 프로그래밍 방식 액세스를 제공합니다. 이 API를 사용하여 내부 보고, 운영 워크플로우, 엔터프라이즈 계정을 위한 통합을 구축할 수 있습니다.

## 관리자 API에 액세스할 수 있는 사용자

관리자 API는 엔터프라이즈 계정의 **계정 관리자**만 사용할 수 있습니다. 계정 관리자는 API 키를 생성하고 관리할 수 있습니다. 워크스페이스 관리자와 기타 계정 멤버는 관리자 API에 액세스하거나 해당 키를 생성할 수 없습니다.

엔터프라이즈 관리자 역할에 대해 자세히 알아보려면 [계정 및 워크스페이스 관리자](/ko/teams/identity-and-access-management/account-and-workspace-admins)를 참조하세요.

## API 키 생성

<Steps>
  <Step title="개발자 설정 열기">
    **설정**을 엽니다. **계정** 아래에서 **개발자**를 선택합니다.
  </Step>

  <Step title="API 키 생성">
    **API 키 생성**을 선택하고 읽기 전용 또는 읽기 및 쓰기 액세스 중에서 선택합니다.
  </Step>

  <Step title="키를 안전하게 저장">
    `rpl_`로 시작하는 키를 복사하여 안전한 시크릿 관리자에 저장합니다. 비밀번호처럼 취급하고 절대 공유하지 마세요.
  </Step>

  <Step title="통합 인증">
    API 요청과 함께 키를 Bearer 토큰으로 전송합니다.
  </Step>
</Steps>

## 할 수 있는 작업

관리자 API는 스코프를 사용하여 각 키가 수행할 수 있는 작업을 제어합니다. 읽기 스코프는 보고를 위한 계정 데이터를 제공하며, 특정 쓰기 스코프는 예산 업데이트와 같은 작업을 지원합니다.

* **사용량:** 워크스페이스, 멤버, 프로젝트 또는 기간별로 필터링하거나 그룹화된 계정 사용량 및 총 원장 비용을 읽습니다.
* **워크스페이스:** 멤버 및 프로젝트 수, 관리자, 생성 시간을 포함한 워크스페이스 목록 및 세부 정보를 읽습니다.
* **멤버:** 역할별로 필터링하거나 이름, 사용자 이름, 이메일로 검색할 수 있는 계정 및 워크스페이스 멤버십을 읽습니다.
* **프로젝트:** 공개 여부 또는 배포 상태로 필터링하거나 제목, 슬러그, 설명으로 검색할 수 있는 팀 워크스페이스 전체의 프로젝트를 읽습니다.
* **예산:** 계정 예산을 읽고, `write:budgets` 스코프를 사용하여 업데이트합니다.

API 응답은 커서 페이지네이션을 지원하며 요청 추적을 위한 속도 제한 헤더와 `X-Request-Id`를 포함합니다.

## 보고서와 워크플로우 구축하기

내부 대시보드, Slack 알림, 월간 재무 보고서 등 이미 운영을 추적하고 있는 곳이라면 어디에서든 관리자 API 데이터를 활용하세요. 예를 들어 워크스페이스별로 사용량을 그룹화하여 각 워크스페이스의 지출을 보고할 수 있습니다.

## Replit Agent로 구축하기

Replit Agent에게 관리자 API를 사용하여 맞춤형 대시보드를 구축하도록 요청할 수 있습니다. 워크스페이스별 사용량이나 프로젝트별 비용과 같이 추적하고 싶은 계정 데이터를 설명하면 Agent가 대시보드와 해당 API 통합을 구축할 수 있습니다.

<Steps>
  <Step title="스킬 선택 도구 열기">
    Replit 프로젝트에서 채팅 입력 옆의 **+** 버튼을 클릭하고 **스킬 사용**을 선택합니다.
  </Step>

  <Step title="관리자 API 스킬 선택">
    **Replit 스킬** 아래에서 **관리자 API**를 선택하여 Agent에게 API 컨텍스트와 통합 가이드를 제공합니다.
  </Step>

  <Step title="대시보드 설명">
    Agent에게 무엇을 추적하고 싶은지, 어떻게 보고 싶은지 알려주세요. 예를 들어 Agent에게 워크스페이스별 사용량과 프로젝트별 비용을 보여주는 대시보드를 구축하도록 요청하세요.
  </Step>

  <Step title="API 키를 안전하게 추가">
    Agent가 API 요청을 해야 할 때, Admin API 키를 프로젝트의 시크릿에 추가합니다. 키를 채팅에 붙여넣거나 프로젝트에 커밋하지 마세요.
  </Step>
</Steps>
