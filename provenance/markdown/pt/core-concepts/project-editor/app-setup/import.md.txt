# Importar

> Aprenda como importar projetos e designs de outras ferramentas para o Replit.

O recurso de importação permite trazer código ou designs existentes para os Replit Apps e continuar desenvolvendo com o Agent.

## Fontes suportadas

| Fonte                        | O que você fornece                                    | Ideal para                                                    |
| ---------------------------- | ----------------------------------------------------- | ------------------------------------------------------------- |
| GitHub                       | URL do repositório ou seletor de repositórios         | Importações de repositórios públicos e privados               |
| Bitbucket                    | URL do repositório ou seletor de repositórios         | Importações de repositórios hospedados no Bitbucket           |
| Vercel                       | Repositório GitHub vinculado ao seu projeto Vercel    | Migração de apps do Vercel                                    |
| Figma                        | URL do Frame                                          | Transformar designs em apps React                             |
| Bolt                         | Repositório GitHub exportado do Bolt                  | Migração de projetos do Bolt                                  |
| Lovable                      | Repositório GitHub exportado do Lovable               | Migração de projetos do Lovable                               |
| Base44                       | Repositório GitHub exportado do Base44                | Migração de projetos do Base44                                |
| ZIP                          | Upload de arquivo `.zip`                              | Importação de arquivos locais de projetos                     |
| Planilha                     | Arquivo `.xlsx`, `.csv` ou URL do Google Sheets       | Criação de um app a partir de dados de planilha               |
| Exportação anterior do Agent | Repositório GitHub exportado de um Agent App anterior | Reimportação de um Agent App anterior                         |
| Vazio                        | Nada                                                  | Usuários avançados que desejam um projeto em branco sem Agent |

<Note>O Replit valida a compatibilidade antes de iniciar a importação.</Note>

## Fluxo de importação padrão

1. Abra [replit.com/import](https://replit.com/import).
2. Selecione uma fonte de importação.
3. Conecte as contas necessárias.
4. Forneça uma URL de repositório, URL de frame ou arquivo `.zip`.
5. Adicione segredos ou variáveis de ambiente solicitados.
6. Selecione **Importar** e revise o app gerado.

## Notas sobre as fontes

### GitHub

* Use a importação rápida para repositórios públicos com `https://replit.com/github.com/<owner>/<repo>`.
* Use a importação guiada para repositórios públicos e privados.
* Se o seu repositório for um Agent App exportado, o Replit preserva a estrutura específica do Agent durante a importação.

### Bitbucket

* Cole uma URL de repositório do Bitbucket ou conecte sua conta do Bitbucket para pesquisar seus repositórios.
* O suporte ao Agent durante a importação pode ser limitado em comparação com projetos hospedados no GitHub.

### Figma

* Importe uma única URL de frame do Figma.
* O Replit gera código React e o Agent ajuda a refiná-lo.
* Para melhores resultados, use frames, layout automático e nomes de camadas claros.

### Vercel

* Selecione o repositório GitHub vinculado ao seu projeto Vercel.
* O Replit importa o código do projeto e os padrões de configuração.
* Adicione os valores das variáveis de ambiente durante a importação.

### Bolt

* Exporte seu projeto Bolt para o GitHub antes de importar.
* O Replit importa código, estilos de interface, assets, lógica de backend (se presente) e esquema de banco de dados (se presente).
* Dados do Supabase e valores de segredos não são importados.
* Após a importação, peça ao Agent para adicionar segredos e recriar os dados do banco de dados.

### Lovable

* Exporte seu projeto Lovable para o GitHub antes de importar.
* O Replit importa código, estilos de interface, assets, lógica de backend (se presente) e esquema de banco de dados (se presente).
* Dados do Supabase e valores de segredos não são importados.
* Após a importação, peça ao Agent para adicionar segredos e recriar os dados do banco de dados.

### Base44

* Exporte seu projeto Base44 para o GitHub antes de importar.
* O Replit importa código, design e estilos, assets e lógica de API.
* O backend do Base44 (entidades, agents, SDK), autenticação e dados não são importados.
* Após a importação, peça ao Agent para migrar qualquer funcionalidade específica do Base44 que você ainda precise.

### ZIP

* Faça upload de um arquivo `.zip` com uma estrutura de raiz de projeto clara.
* O Replit importa arquivos, dependências e padrões comuns de execução.
* Valores de segredos existentes, domínios e dados de banco de dados não são importados.

### Planilha

* Faça upload de um arquivo Excel (`.xlsx`) ou CSV, ou cole uma URL pública do Google Sheets.
* O Agent lê a estrutura da sua planilha e cria um app full-stack com um banco de dados preenchido com seus dados.
* Inclui uma interface para visualizar, pesquisar e gerenciar seus registros.

### Exportação anterior do Agent

* Reimporte um Agent App exportado anteriormente a partir de um repositório GitHub.
* O Replit preserva a estrutura específica do Agent (código, esquema de banco de dados, funcionalidade de backend).
* Valores do banco de dados e valores de segredos não são importados.

### Vazio

* Comece com um projeto completamente vazio — sem Agent, sem seleção de framework e sem scaffolding.
* Ideal para usuários avançados que desejam controle total sobre a configuração do projeto.

## Limitações

* Dados existentes do banco de dados não são migrados.
* Algumas dependências complexas ou proprietárias podem precisar de configuração manual.
* Projetos grandes podem levar mais tempo para processar.

## Boas práticas

* Remova credenciais sensíveis antes de importar.
* Mantenha a estrutura do projeto de origem organizada.
* Verifique dependências e comandos de execução após a importação.
* Teste os fluxos principais antes de publicar.

## Solução de problemas

Se a importação falhar, verifique estas áreas primeiro:

* **Erros de compatibilidade**: Verifique os arquivos de projeto necessários e os frameworks suportados.
* **Erros de acesso**: Confirme as permissões do repositório ou da fonte.
* **Erros de processamento**: Tente novamente após simplificar a estrutura do projeto ou reduzir o tamanho.

Se os problemas persistirem, visite o [Replit Community Hub](https://replit.com/community) ou [entre em contato com o Suporte](https://replit.com/support).

## Faturamento

Importações que exigem trabalho de migração pelo Agent podem consumir créditos. O uso de créditos depende da complexidade do projeto.
