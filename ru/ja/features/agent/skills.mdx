<div id="section">
  ## Что такое навыки
</div>

Навыки — это папки. В них содержится файл `SKILL.md` с инструкциями для Agent, а также вспомогательные файлы для справки. Навыки хранятся в каталоге `/.agents/skills` проекта и соответствуют [спецификации навыков Agent](https://agentskills.io/specification) — открытому стандарту, совместимому с разными агентами.

Agent видит названия и описания всех установленных навыков, но загружает их полное содержимое только тогда, когда считает их релевантными текущей задаче. Благодаря этому навыки эффективно используют контекст: можно установить множество навыков без снижения качества результатов Agent.

<div id="section-2">
  ## Предустановленные навыки
</div>

Replit включает предустановленные навыки, доступные в меню **Использовать навык** в чате и в меню выбора отправной точки для нового проекта. Эти навыки работают во всех проектах без установки. Полный каталог, партнёрские навыки и инструкции по установке доступны в [каталоге навыков](/ru/ja/features/agent/skills-directory).

Чтобы добавить предустановленный навык, откройте меню **Использовать навык** в поле ввода чата и выберите навык или попросите Agent загрузить его.

<div id="section-3">
  ## Область действия навыков
</div>

Навыки могут быть доступны на разных уровнях:

| Область действия                    | Доступность                          | Место хранения                                                                                                       |
| ----------------------------------- | ------------------------------------ | -------------------------------------------------------------------------------------------------------------------- |
| **На уровне проекта**               | Только в конкретном проекте          | Версионируются вместе с файлами в `/.agents/skills`                                                                  |
| **На уровне рабочего пространства** | Доступны всем в рабочем пространстве | Централизованно управляются в настройках рабочего пространства                                                       |
| **Enterprise**                      | Стандарт для всей компании           | Включены в [пользовательские шаблоны](/ru/ja/teams/custom-templates) и [дизайн-системы](/ru/ja/teams/custom-design-system) |

О настройке навыков рабочего пространства и пользовательских инструкций для команды см. в разделе [Настройка Agent](/ru/ja/features/agent/agent-customization).

<div id="agent">
  ## Как Agent загружает навыки
</div>

Во всех чатах Agent загружает метаданные (названия и описания) всех установленных навыков. Содержимое навыка загружается, только если Agent считает его релевантным текущей задаче. Благодаря этому содержимое навыков остаётся за пределами контекстного окна, пока не потребуется.

Установленные навыки сохраняются в проекте между сеансами Agent и могут быть добавлены в систему контроля версий для совместного использования в команде.

<div id="ai">
  ## Интеграция с другими ИИ-инструментами для написания кода
</div>

<Accordion title="Импорт навыков из других ИИ-инструментов для написания кода">
  Если вы используете несколько ИИ-инструментов для написания кода, [rulesync](https://github.com/dyoshikawa/rulesync) поддерживает Replit и помогает поддерживать единообразные настройки.

  Вы можете импортировать навыки из других ИИ-помощников для написания кода:

  ```bash theme={null}
  npx rulesync init
  npx rulesync import --targets claudecode --features skills
  npx rulesync generate --targets replit --features skills
  ```

  Это позволяет поддерживать единый набор навыков, работающий в разных средах разработки.
</Accordion>
