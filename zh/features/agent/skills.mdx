<div id="what-is-a-skill">
  ## 什么是 skill？
</div>

skill 本质上就是一个文件夹。文件夹里有一个名为 `SKILL.md` 的文件，其中写明了 Agent 需要遵循的指令，此外还可以放入任何你希望它参考的辅助文件。skills 存放在你 project 的 `/.agents/skills` 目录中，并遵循 [Agent Skills 规范](https://agentskills.io/specification)——一项可跨各类 agent 通用的开放标准。

Agent 可以看到每个已安装 skill 的名称和描述，但只有在与当前任务相关时才会加载完整内容。因此 skills 对上下文的占用非常高效：即使安装很多，也不会影响 Agent 的输出质量。

<div id="pre-defined-skills">
  ## 预定义 skills
</div>

Replit 内置了一批预定义 skills，可在 Chat 的 **Use a skill** 选择器和新建 project 的起始模板选择器中使用。这些 skills 无需安装即可在任意 project 中使用。完整目录、合作伙伴 skills 及安装方法，请参阅 [Skills 目录](/zh/features/agent/skills-directory)。

要添加预定义 skill，请从 Chat 输入框打开 **Use a skill** 选择器并选择一个 skill，或直接让 Agent 加载该 skill。

  <img src="/assets/mirror/use-a-skill-picker-335f5e785923.png" alt="Chat 中显示预定义 skills 的 Use a skill 选择器" width="570" height="422" data-path="images/replitai/use-a-skill-picker.png" />

<div id="skill-scope">
  ## skill 作用范围
</div>

skill 可以在不同层级设置作用范围：

| 作用范围            | 可用范围                 | 存放位置                                                                     |
| --------------- | -------------------- | ------------------------------------------------------------------------ |
| **project 级**   | 仅适用于单个 project       | 随文件一起进行版本管理，位于 `/.agents/skills`                                         |
| **workspace 级** | workspace 中的所有成员均可使用 | 在 Workspace 设置中集中管理                                                      |
| **Enterprise**  | 全公司统一标准              | 包含在[自定义模板](/zh/teams/custom-templates)和[设计系统](/zh/teams/custom-design-system)中 |

如需了解 workspace 级 skill，请参阅 [Agent 自定义](/zh/features/agent/agent-customization)，为你的团队设置 workspace skill 和自定义指令。

<div id="create-a-custom-skill">
  ## 创建自定义 Skill
</div>

如果你希望在 Workspace 库中保存可复用的指令，可以创建自定义 Skill。
在共享的 Workspace 中，你可以在创建 Skill 时设置 Workspace 成员访问权限，
之后也可随时修改。哪些人可以管理 Skill 取决于你的套餐——参见
[Agent 自定义](/zh/features/agent/agent-customization)。

Workspace 成员访问策略如下：

| 策略            | 访问权限                        |
| ------------- | --------------------------- |
| **Required**  | 始终启用，无法关闭                   |
| **Available** | 可选，默认关闭；成员需自行开启该 Skill 才能使用 |
| **No access** | 对成员隐藏                       |

<Steps>
  <Step title="打开 Skills 设置">
    在 Workspace 中打开 **Settings** &gt; **Customization** &gt; **Skills**。
  </Step>

  <Step title="开始创建自定义 Skill">
    选择 **Add**，然后选择 **Write a skill**。
  </Step>

  <Step title="描述该 Skill">
    自定义 Skill 包含以下内容：

    * **Name**：在 Workspace 库中标识该 Skill。
    * **Description**：说明 Agent 应在何时使用该 Skill。
    * **Instructions**：定义 Agent 应遵循的步骤。

    <Frame caption="在团队 Workspace 中填写自定义 Skill 的详细信息。">
      <img src="/assets/mirror/workspace-custom-skill-create-6d6014e5c561.jpg" alt="团队 Workspace 自定义 Skill 表单，包含名称、描述、指令以及 Create skill 按钮" width="2000" height="1363" data-path="images/replitai/workspace-custom-skill-create.jpg" />
    </Frame>
  </Step>

  <Step title="设置 Workspace 成员访问权限">
    新建的 Skill 默认为 **Private**，因此只有你和 Workspace 管理员可以使用。
    选择 **Sharing** 控件，然后为 **Members
    in workspace** 设置上述策略之一。

    <Frame caption="在创建 Skill 之前设置 Workspace 成员访问权限。">
      <img src="/assets/mirror/workspace-custom-skill-create-sharing-00a493b8ba70.jpg" alt="自定义 Skill 表单，已展开 Sharing 控件并显示 Required、Available 和 No access 选项" width="2000" height="1154" data-path="images/replitai/workspace-custom-skill-create-sharing.jpg" />
    </Frame>
  </Step>

  <Step title="创建该 Skill">
    确认各项信息无误后，选择 **Create skill**。
  </Step>
</Steps>

<div id="share-project-skills">
  ## 共享 project Skills
</div>

在共享的 Workspace 中，你可以在 Skill 创建后再更新成员的访问权限。

<Steps>
  <Step title="创建或选择 Skill">
    按上述步骤创建自定义 Skill，或在
    **Settings** &gt; **Customization** &gt; **Skills** 中选择已有的 Skill。

    要将 project Skill 保存到 Workspace，请在 project 中打开 **Agent Skills** &gt; **Project skills**，选择 **Save to workspace**，输入名称，然后选择 **Save**。
  </Step>

  <Step title="打开共享">
    在 Workspace 库中的 Skill 卡片上打开选项菜单，然后选择 **Share...**。

    <Frame caption="打开已有 Skill 的菜单，即可在创建后进行共享。">
      <img src="/assets/mirror/workspace-skill-share-menu-af1b84e16a3c.jpg" alt="Workspace Skills 页面，已打开某个已有 Skill 的选项菜单并显示 Share 操作" width="1600" height="1100" data-path="images/replitai/workspace-skill-share-menu.jpg" />
    </Frame>
  </Step>

  <Step title="设置 Workspace 成员访问权限">
    在 **Share skill** 对话框中，为 **Members in
    workspace** 选择上述策略之一。所选设置会立即生效，无需再单独
    确认。

    <Frame caption="选择 Workspace 成员访问该 Skill 的方式。">
      <img src="/assets/mirror/workspace-skill-sharing-policy-24fbbc668714.jpg" alt="Share skill 对话框，显示面向 Workspace 成员的 Required、Available 和 No access 策略" width="1500" height="1000" data-path="images/replitai/workspace-skill-sharing-policy.jpg" />
    </Frame>
  </Step>
</Steps>

<div id="import-skills-from-github">
  ## 从 GitHub 导入 Skills
</div>

通过公开的 GitHub 仓库、文件夹或文件 URL 添加 Skills。

<Steps>
  <Step title="打开 Workspace Skills">
    在 Agent 中，选择 **+** &gt; **Use a skill** 打开 **Workspace Skills**。

    <Frame caption="打开加号菜单并选择 Use a skill 以访问 Workspace Skills。">
      <img src="/assets/mirror/workspace-skill-picker-d7c3f5525de2.jpg" alt="Agent plus menu with Use a skill selected and the Workspace Skills picker listing ask-matt, claude-handoff, and code-review" width="2000" height="1085" data-path="images/replitai/workspace-skill-picker.jpg" />
    </Frame>
  </Step>

  <Step title="预览 Skills">
    粘贴公开的 GitHub 仓库、文件夹或文件 URL，然后选择 **Preview
    skills**。预览仅检查文件结构，不会加载 Skill 的指令或描述。

    <Frame caption="输入公开的 GitHub URL 并预览其 Skill 文件结构。">
      <img src="/assets/mirror/workspace-skill-github-preview-c8476d8d1556.jpg" alt="Add from GitHub page with a public GitHub repository URL and the Preview skills button" width="2000" height="1154" data-path="images/replitai/workspace-skill-github-preview.jpg" />
    </Frame>
  </Step>

  <Step title="选择并导入 Skills">
    查看检测到的 Skills，勾选需要导入的项，然后选择 **Import**。按钮上会显示已选中的 Skills 数量，例如 **Import 36 skills**。

    <Frame caption="查看检测到的 Skills 并选择需要导入的项。">
      <img src="/assets/mirror/workspace-skill-github-select-68589ea766c3.jpg" alt="GitHub Skill preview showing detected Skills with selection controls and the Import 36 skills button" width="2000" height="1154" data-path="images/replitai/workspace-skill-github-select.jpg" />
    </Frame>
  </Step>
</Steps>

上述示例使用的是公开的
[mattpocock/skills](https://github.com/mattpocock/skills) 仓库。

<Note>
  每次导入最多支持 50 个 Skills、3,500 个文件或 200 MiB，且不支持私有仓库。
</Note>

导入的仓库会显示在 **Skills** 标签页的 **GitHub** 筛选项下。

<div id="how-agent-loads-skills">
  ## Agent 如何加载 skills
</div>

每次对话时，Agent 都会读取所有已安装 skill 的元数据 (名称和描述) 。只有当 Agent 判断某个 skill 与当前任务相关时，才会加载它的完整内容。这样在用不到时，skill 内容就不会占用上下文窗口。

已安装的 skills 会保留在你的 project 中，跨 Agent 会话持续存在，也可以提交到版本控制，供团队共享。

<div id="working-with-other-ai-coding-tools">
  ## 配合其他 AI 编程工具使用
</div>

<Accordion title="从其他 AI 编程工具导入 skill">
  如果你同时使用多个 AI 编程工具，[rulesync](https://github.com/dyoshikawa/rulesync) 已支持 Replit，可帮助你保持配置一致。

  你可以从其他 AI 编程助手导入 skill：

  ```bash theme={null}
  npx rulesync init
  npx rulesync import --targets claudecode --features skills
  npx rulesync generate --targets replit --features skills
  ```

  这样你只需维护一套 skill，即可在不同的开发环境中通用。
</Accordion>
