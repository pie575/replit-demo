Il existe deux façons de créer un design system, selon l&#39;endroit où votre marque est présente aujourd&#39;hui.

<div id="from-scratch-prompt-it-from-the-home-page">
  ## À partir de zéro : utilisez la page d’accueil pour le décrire
</div>

Commencez ici si le système est déjà clair dans votre tête (ou défini dans vos directives de marque), mais n’existe encore dans aucun design.

<Steps>
  <Step title="Décrivez-le dans le champ de création">
    Depuis la page d’accueil de Replit, décrivez le design system que vous souhaitez dans le champ de prompt — par exemple : *&quot;Créez un design system pour Velocity, une marque de location de supercars haut de gamme.&quot;*

    <Frame>
      <img src="/assets/mirror/ds-home-create-7f04110e1f71.png" alt="Le champ de prompt de la page d’accueil avec un prompt de création de design system" width="800" height="240" data-path="images/design/replit-design/ds-home-create.png" />
    </Frame>
  </Step>

  <Step title="Répondez au questionnaire">
    Agent vous pose une courte série de questions sur votre système — personnalité de la marque, couleurs et préférences typographiques. Vous pouvez également lui indiquer une source : une URL Figma, un site web, du code, des images de référence, des ressources de marque ou un fichier DESIGN.md existant.
  </Step>
</Steps>

<div id="from-a-mockup-extract-the-design-system">
  ## À partir d’une maquette : extraire le design system
</div>

Commencez ici si vous avez déjà un design que vous aimez — un frame généré ou un template ajouté — et souhaitez harmoniser tout le reste avec celui-ci.

<Steps>
  <Step title="Sélectionner la maquette">
    Sur le Canvas, cliquez sur la maquette dont vous souhaitez reprendre l’apparence.
  </Step>

  <Step title="Extraire depuis le menu à trois points">
    Ouvrez le menu **⋯** (à trois points) du frame, puis choisissez **Extract design system**. Agent synthétise les jetons, les couleurs et la typographie de la maquette dans un guide de style évolutif, puis les applique à l’ensemble du design.

    <Frame>
      <img src="/assets/mirror/ds-extract-menu-3efbe8bb497e.png" alt="Gros plan de la barre d’actions d’un frame sélectionné, avec le menu d’options supplémentaires ouvert, affichant Apply design system et Extract design system" width="958" height="320" data-path="images/design/replit-design/ds-extract-menu.png" />
    </Frame>
  </Step>
</Steps>

<div id="review-and-save">
  ## Vérifier et enregistrer
</div>

Dans les deux cas, examinez ce qui a été généré : un guide de style évolutif avec vos couleurs (par rôle — principale, d’accentuation, atténuée…), votre échelle typographique et vos jetons (stockés dans `tokens.json`, qui alimentent les variables CSS). Sélectionnez ensuite **Enregistrer le design system** pour le conserver dans votre workspace.
