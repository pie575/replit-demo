<div id="web-search-for-agent">
  ### Web Search для Agent
</div>

<Frame>
  <img src="/assets/mirror/web-search-6c28195531d4.jpg" alt="Интерфейс Agent с результатами Web Search и ссылками на источники для разработки приложений" width="1920" height="1080" data-path="images/replitai/web-search.jpg" />
</Frame>

Теперь Agent может искать в интернете и получать актуальную информацию с помощью [Web Search](/ru/core-concepts/agent/web-search). Создавайте приложения, используя новейшую документацию, актуальные рыночные данные и точные сведения из интернета. Больше никаких ограничений, связанных с датой обновления знаний: теперь ваши приложения используют самую свежую доступную информацию.

<div id="custom-agent-instructions">
  ### Пользовательские инструкции для Agent
</div>

<Frame>
  <img src="/assets/mirror/replitmd-65360844a148.jpg" alt="файл replit.md с настройками проекта" width="1920" height="1080" data-path="images/replitai/replitmd.jpg" />
</Frame>

Настройте Agent под себя с помощью [replit.md](/ru/core-concepts/agent/replit-dot-md). В этом специальном файле можно задать стиль написания кода, параметры проекта и контекст. Agent автоматически создаёт этот файл с использованием проверенных рекомендаций, а вы можете настроить его под свой рабочий процесс.

<div id="teams-app-store-experience">
  ### App Store в Teams
</div>

Находите приложения своей команды и управляйте ими как никогда раньше. Новый интерфейс App Store организации на странице Deployments позволяет добавлять приложения в избранное, искать среди всех развертываний, просматривать недавно открытые приложения и находить популярные развертывания по объему трафика.
