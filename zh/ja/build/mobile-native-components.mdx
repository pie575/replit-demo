<div id="section">
  ## 为什么这很重要
</div>

每部 iPhone 都内置了警告框、分享面板、开关和菜单，玩家在自己的其他各种应用里
早已用惯了这些组件。当你的应用使用同样的原生组件时，
玩家还没点击就已经知道它们会有什么反应。这正是让应用感觉像一款地道 iPhone 应用的原因。

以下是可添加到应用中的原生组件提示词示例：警告框、操作
表、开关等。

  ## 原生警告框
</div>

<AiPrompt>
  {nativeAlertPrompt}
</AiPrompt>

</div>

</Note>

<div id="section-6">
  ## 故障排除
</div>

* **显示自定义模态框而非警告框或操作表：** 请确认 Agent 使用的是原生 API，而非由 JS 渲染、仅在视觉上相似的替代方案。它们看起来可能相似，但行为不同。
* **Android 上的图标显示异常：** SF Symbols 出现这种情况属于预期，因为它仅适用于 iOS。请询问 Agent 使用了哪个备用图标集。
* **分享面板中未包含预期的应用：** 这由操作系统以及测试设备上安装的应用决定，PixelGames 无法直接添加应用。
