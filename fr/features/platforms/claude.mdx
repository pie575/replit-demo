Replit est disponible en tant que connector dans Claude. Une fois la connexion établie, vous pouvez développer sur Replit sans quitter votre conversation avec Claude.

<div id="connect-the-replit-connector">
  ## Connecter le connector Replit
</div>

Dans Claude, ouvrez le répertoire des connectors, recherchez **Replit** et connectez-le. Claude vous guide pour la connexion à votre compte Replit. Une fois la connexion établie, vous pouvez demander à Claude de créer une nouvelle app, d&#39;en modifier une existante ou de répondre à des questions sur une app en cours de développement. Claude transmet votre demande à Replit Agent, qui effectue le travail et vous fournit un lien vers l&#39;app en ligne.

<Tip>
  Formulez à Claude des demandes du type « Crée une app Replit qui suit mes habitudes hebdomadaires » ou « Ajoute une page de connexion à mon app Replit ». Claude transmet la demande à Replit Agent et renvoie un lien qui vous permet de suivre la création en direct.
</Tip>

<div id="send-a-design-from-claude-to-replit">
  ## Envoyer un design de Claude vers Replit
</div>

Lorsque vous créez quelque chose dans le canvas de design de Claude, vous pouvez l&#39;envoyer directement vers Replit. Choisissez **Replit** comme destination : votre design s&#39;ouvre alors dans Replit sous la forme d&#39;une application exécutable. Agent détermine ensuite comment transformer ce design statique en produit fonctionnel, ce qui vous permet de continuer à développer, d&#39;ajouter une base de données et de publier.

Pour la procédure complète de transfert de design, consultez [Importer des designs Claude dans Replit Design](/fr/design/import-claude-designs-into-replit-design).

<div id="how-it-works">
  ## Fonctionnement
</div>

Le connector Replit pilote Replit via le [serveur MCP Replit](/fr/platforms/mcp-server). Claude gère la connexion pour vous.
