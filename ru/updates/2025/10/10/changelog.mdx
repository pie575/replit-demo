<div id="agent-usage-cost-visibility">
  ### Прозрачность расходов на использование Agent
</div>

Отслеживайте расходы на Agent в реальном времени, пока выполняются задачи. Откройте выдвижную панель в заголовке Chat, чтобы следить за тратами по активным задачам — это особенно полезно при长 длительных запусках с высокой автономностью.

<div id="escape-key-for-visual-selectedit-mode">
  ### Клавиша Escape для режима Visual Select/Edit
</div>

Нажмите Escape, чтобы выйти из режима Visual Select или вернуться в режим Build. Небольшое сочетание клавиш, которое помогает не прерывать работу.

<div id="faster-agent-stopping">
  ### Более быстрая остановка Agent
</div>

Agent реагирует быстрее, когда вы останавливаете или запускаете его из Workspace, что сокращает время ожидания.

<div id="github-import-improvements">
  ### Улучшения импорта из GitHub
</div>

Теперь во время импорта из GitHub отображается ход выполнения в реальном времени вместо общих сообщений, а сам импорт стал быстрее.

<div id="dependency-vulnerability-scanning">
  ### Сканирование уязвимостей в зависимостях
</div>

Сканер безопасности теперь выявляет уязвимости в зависимостях Go, JavaScript, Python и Rust. Поддержка других языков появится в ближайшее время.

<div id="webview-logging-experience">
  ### Работа с логами Webview
</div>

Просматривайте логи Webview и вывод консоли в одном месте — те же логи, которые использует Agent, — что упрощает отладку.

  ### Доступ к местам поддержки для команд
</div>
