<div id="what-is-ssh">
  ## SSH란?
</div>

SSH는 Secure Shell의 약자로, Replit App의 명령줄 인터페이스에 원격으로 접속할 수 있게 해주는 보안 프로토콜입니다. SSH를 사용하면 파일을 손쉽게 전송하고, 평소 사용하던 로컬 통합 개발 환경(IDE)에서 Replit의 코드를 편집할 수 있어 개발 workflow의 협업 효율과 생산성이 높아집니다.

SSH 기능은 Core, Pro를 비롯한 모든 유료 plan에서 사용할 수 있습니다.

전체 과정은 다음과 같습니다:

* 로컬 컴퓨터에서 SSH keypair 생성
* 생성한 SSH 키를 Replit App의 **SSH** pane에 추가
* SSH 클라이언트 또는 SSH를 지원하는 편집기([VSCode](https://code.visualstudio.com/), [Cursor](https://www.cursor.com/) 등)로 연결

<Note>
  SSH 키는 특정 Replit App이 아니라 Account에 연결됩니다. 따라서 공개 키를 한 번만 추가해 두면 이후에는 접근 권한이 있는 모든 Replit App에 연결할 수 있습니다.
</Note>

<div id="why-use-ssh">
  ## SSH를 사용하는 이유
</div>

* **Replit App과 편집기 간 자동 업데이트**: Replit App에서 변경한 내용은 편집기에 즉시 반영되고, 편집기에서 수정한 내용도 Replit App에 반영됩니다. 이러한 매끄러운 동기화 덕분에 codebase는 여러 플랫폼에서 항상 최신 상태로 유지됩니다.

* **파일 관리 동기화**: 파일을 추가, 삭제, 업데이트하면 해당 변경 사항이 편집기와 Replit App 사이에서 실시간으로 동기화됩니다. 덕분에 변경을 어디에서 시작하든 project 구조가 일관되게 유지됩니다.

* **폴더 관리 및 파일 이동**: 폴더 간 파일 이동도 편집기와 Replit App 사이에서 동기화됩니다. 따라서 한쪽 환경에서 이루어진 구조 변경이 다른 쪽에도 정확히 반영되어 project의 무결성과 구조가 그대로 유지됩니다.

<div id="find-or-create-a-keypair">
  ## keypair 찾기 또는 생성하기
</div>

계정에 SSH를 구성하려면 SSH 공개 키가 필요합니다.

<div id="figuring-out-if-you-already-have-a-keypair">
  ### 이미 keypair가 있는지 확인하기
</div>

로컬 컴퓨터의 터미널에서 다음 명령어를 실행하면 공개 키가 이미 있는지 확인할 수 있습니다:

<Tabs>
  <Tab title="Mac/Linux">
    ```sh theme={null}
    ls -l ~/.ssh
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    dir %HOMEPATH%\.ssh
    ```
  </Tab>
</Tabs>

오류가 발생해도 괜찮습니다. [새 keypair 생성하기](#generating-a-new-keypair)로 이동하세요.
`replit.pub`이라는 파일이 보인다면 [공개 키 내용 확인하기](#get-the-contents-of-your-public-key)로 이동하세요.

<div id="generating-a-new-keypair">
  ### 새 keypair 생성하기
</div>

사용 중인 컴퓨터에서 터미널(또는 명령 프롬프트) 창을 열고 다음 명령을 붙여넣으세요.

<Tabs>
  <Tab title="Mac/Linux">
    ```bash theme={null}
    ssh-keygen -t ed25519 -f ~/.ssh/replit -q -N ""
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    ssh-keygen -t ed25519 -f %HOMEPATH%\.ssh\replit -q -N ""
    ```
  </Tab>
</Tabs>

이 명령은 특정 SSH 공개 키 파일이 이미 있는지 확인하고, 없으면 적절한 기본 매개변수로 새 SSH 키를 생성합니다.

<div id="get-the-contents-of-your-public-key">
  ### 공개 키의 내용 확인하기
</div>

keypair가 있는 것을 확인했거나 새로 만들었다면, 공개 키(이름이 비슷한 두 파일 중 `.pub`으로 끝나는 파일)의 내용을 출력하세요. 나중에 이 내용이 필요합니다.

<Tabs>
  <Tab title="Mac/Linux">
    ```sh theme={null}
    cat ~/.ssh/replit.pub
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    notepad %HOMEPATH%\.ssh\replit.pub
    ```
  </Tab>
</Tabs>

이 문서의 뒷부분에서 사용할 수 있도록 `replit.pub`의 내용을 저장한 뒤 [Account에 SSH 키 추가하기](#add-the-ssh-key-to-your-account)로 넘어가세요.

<div id="add-the-ssh-key-to-your-account">
  ## 계정에 SSH 키 추가하기
</div>

<div id="add-the-public-key-directly-in-a-replit-app-using-the-ssh-pane">
  ### SSH pane을 사용해 Replit App에서 공개 키 직접 추가하기
</div>

1. Replit App의 아무 창에서나 **+** 버튼을 선택한 다음 **SSH**를 검색합니다.

<Frame>
  <img src="/assets/mirror/ssh-tool-2db02c6a83d0.png" alt="Replit 인터페이스의 SSH 도구 버튼" width="846" height="328" data-path="images/ssh-vscode/ssh-tool.png" />
</Frame>

2. **Keys** 탭으로 이동한 후 **New SSH key**를 선택합니다.
3. 팝업 창에서 키의 **Label**(예: my-ssh-key)을 입력하고, 복사한 공개 키를 **Key** 섹션에 붙여넣습니다.
   **Add SSH Key** 버튼을 선택합니다. 키가 추가되고 사용 승인이 완료됩니다.

<Frame>
  <img src="/assets/mirror/add-ssh-key-with-values-5d6f440e56ba.png" alt="label과 key 필드가 입력된 SSH 키 추가 대화 상자" width="500" height="511" data-path="images/ssh-vscode/add-ssh-key-with-values.png" />
</Frame>

<div id="add-the-public-key-directly-in-settings">
  ### Settings에서 공개 키 직접 추가하기
</div>

**Settings**를 열고 **Account** 아래에서 **Advanced**(또는 **SSH keys** 옵션)를 선택해 SSH 키를 추가할 수도 있습니다. **Add SSH key**를 선택한 다음, 이전 섹션인 [keypair 찾기 또는 생성하기](#find-or-create-a-keypair)에서 만든 `replit.pub`의 내용을 붙여 넣으세요.

<Note>
  컴퓨터에 공개 키가 여러 개 있는 경우, SSH 설정에 맞는 개인 키와 공개 키 조합을 정확히 사용하는 것이 중요합니다.
</Note>

<div id="connecting-to-your-replit-app">
  ## Replit App에 연결하기
</div>

<div id="configure-your-ssh-config">
  ### SSH config 구성
</div>

1. 터미널에서 `~/.ssh` 디렉터리와 `~/.ssh/config` 파일이 있는지 확인하세요:

<Tabs>
  <Tab title="Mac/Linux">
    ```sh theme={null}
    mkdir -p ~/.ssh && chmod 700 ~/.ssh && touch ~/.ssh/config && chmod 600 ~/.ssh/config
    open -a 'TextEdit' ~/.ssh/config || nano ~/.ssh/config
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    if not exist %HOMEPATH%\.ssh mkdir %HOMEPATH%\.ssh && type \NUL > %HOMEPATH%\.ssh\config
    notepad %HOMEPATH%\.ssh\config
    ```
  </Tab>
</Tabs>

2. 모든 *.replit.dev 도메인에 `replit` keypair를 사용하도록 다음 구성 블록을 추가하세요:

<Tabs>
  <Tab title="Mac/Linux/Windows">
    ```
    Host *.replit.dev
        Port 22
        IdentityFile ~/.ssh/replit
        StrictHostKeyChecking accept-new
    ```
  </Tab>
</Tabs>

<div id="connect-from-vscode-or-cursor">
  ### VSCode 또는 Cursor에서 연결하기
</div>

1. Replit App에서 **SSH** pane을 엽니다

2. SSH pane에서 **Connect** tab으로 이동한 후 **Launch VS Code**를 선택합니다.

<Tabs>
  <Tab title="VSCode로 연결하기">
    <img src="/assets/mirror/ssh-connect-439a3c150846.png" alt="Launch VS Code 옵션이 표시된 SSH connect 탭" width="788" height="482" data-path="images/ssh-vscode/ssh-connect.png" />
  </Tab>
</Tabs>

3. `~/.ssh/config` 파일을 작성하라는 메시지가 표시되면 다음 내용을 입력합니다.

   ```
   Host *.replit.dev
       Port 22
       IdentityFile ~/.ssh/replit
       StrictHostKeyChecking accept-new
   ```

   <Note>
     SSH 설정을 추가하라는 메시지는 VS Code나 다른 편집기에 처음 연결할 때만 표시됩니다. 이후 설정 파일을 다시 열려면 &#42;&#42;Configure SSH Hosts...&#42;&#42;를 선택하세요.
   </Note>

4. 외부 애플리케이션 경고가 표시되면 **Yes**를 선택해 원하는 편집기나 VS Code에서 project를 열도록 확인합니다.

5. 주기적으로 SSH extensions를 설치하거나 업데이트하라는 안내가 표시될 수 있습니다. Replit은 이러한 IDE의 최신 버전과 호환되도록 노력하고 있으며, 이 과정에서 중요한 보안 업데이트도 함께 적용될 수 있습니다.

<div id="connect-via-a-tool-not-listed-here">
  ### 여기에 없는 도구로 연결하기
</div>

다양한 플랫폼과 운영 체제를 지원하는 SSH 클라이언트가 많이 있으며, 각각 제공하는 기능이나 integration도 다릅니다.

&quot;Connect Manually&quot;에 표시된 명령어를 구성 요소별로 분해해 보면 각 클라이언트를 어떻게 설정해야 하는지 언제든 파악할 수 있습니다:

```sh theme={null}
ssh -i ~/.ssh/replit -p 22  c96b6ade-d5e4-4f7a-bc5b-52334509b2a3@c96b6ade-d5e4-4f7a-bc5b-52334509b2a3-00-16nh2hskw3ql8.riker.replit.dev
       ^-----v-----^    ^^  ^-----------------v----------------^ ^------------------------------v-------------------------------------^
        Private Key   Port                   User               @                           Hostname
```

**호스트 이름**: `<your_hostname>.<cluster>.replit.dev`
**포트**: `<port_number>`
**User**: `Username`
**Private Key**: 컴퓨터에 저장된 개인 키 파일의 경로입니다. 보통 `replit.pub` 파일과 같은 위치에 있습니다.
