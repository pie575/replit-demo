<div id="visual-editor">
  ## 什么是 Visual Editor？
</div>

借助 Visual Editor，您可以直接点击元素来修改界面。它可在 Replit Design 的 [Canvas](/zh/ko/design/canvas) 和 Preview 中使用，因此您可以用同一种方式编辑模型和正在运行的应用。

修改文本、调整颜色和间距等简单编辑不会消耗 AI 积分，并会直接更新源代码。对于涉及隐藏复杂性的更改，Visual Editor 会自动交由 Agent 处理。

核心概念：

* **确定性编辑**：简单更改 (文本、颜色、间距) 会直接应用到源代码，无需经过 Agent 循环。
* **不消耗积分**：直接编辑不会消耗 AI 积分 — 只有复杂更改会通过 Agent 处理。
* **双重上下文**：在 Canvas 画框和 Preview 中均能以相同方式运行。
* **源代码同步**：所有编辑都会立即更新底层源代码。

<Note>
  Visual Editor 目前仅可在**网页浏览器**中使用，不支持移动应用或桌面应用。
</Note>

<div id="visual-editor-2">
  ## 如何使用 Visual Editor
</div>

<div id="canvas">
  ### 在 Canvas 中编辑
</div>

在工具栏中选择 **Edit** 工具，然后点击画框中的元素。元素会高亮显示，并带有显示其名称的标签；右侧会打开 Visual Editor 面板，显示该元素可编辑的属性，如内容、布局、颜色和边框。调整属性后，选择 **Save edits** 应用更改，或选择 **Discard** 放弃更改。

显示的属性取决于所选元素。文本元素会显示字体控件，图片会显示来源和上传选项，容器会显示布局控件。

<div id="preview">
  ### 在 Preview 中编辑
</div>

同样的编辑体验也适用于正在运行的应用。

<Steps>
  <Step title="选择元素">
    在 Preview 中点击元素即可开始编辑。
  </Step>

  <Step title="编辑">
    直接编辑文本、使用颜色选择器调整颜色、通过样式控件更改间距，或替换图片。
  </Step>

  <Step title="保存">
    点击“保存”以更新源代码。简单的更改会直接应用，不消耗 AI 积分。如果编辑较复杂，Visual Editor 会向 Agent 发送目标元数据以寻求帮助。
  </Step>
</Steps>

<div id="section">
  ### 编辑文本
</div>

点击文本元素后直接输入即可修改。若文本是源代码中的字符串，所做更改会立即生效。

<div id="section-2">
  ### 调整颜色
</div>

使用颜色选择器调整文本和背景的颜色。你可以在输入框中输入“purple”等颜色名称，或使用吸管工具从屏幕任意位置选取颜色。

<div id="section-3">
  ### 更改样式
</div>

通过直观的控件调整各元素的内边距、外边距和布局。

<div id="section-4">
  ### 布局控件
</div>

Visual Editor 会将所有控件归类到清晰的分区中，帮助您更快找到所需内容：**Text**、**Layout**、**Color**、**Border**。 (选择图像元素时，还会显示 **Image** 分区。)

在 **Layout** 分区中，您无需借助 Agent，即可调整容器内子元素的排列方式。选择弹性容器并展开 Layout 后，您将看到以下内容：

* **Alignment**：一个 3×3 点选器，用于选择项目在容器内两个轴上的位置。
* **Direction**：两个箭头按钮，用于将子元素按行或列排列。
* **Gap**：表示项目之间间距的像素值。Gap 输入框旁的图标会根据当前方向变化，因此您始终可以知道自己调整的是水平间距还是垂直间距。旁边的箭头图标可切换 **Distribute space between items**，将子元素推向容器的两端。
* **Outer space**：用于设置元素外部空间的各边输入框 (每边一个，也可通过链接切换同时锁定四条边) 。
* **Inner space**：用于设置元素内部空间的各轴输入框，并提供链接切换以同时锁定两个轴。

Layout 分区仅会在所选元素至少应用一个布局控件时显示。没有间距或布局属性的普通文本节点会完全隐藏此分区，使编辑器保持简洁。

<div id="section-5">
  ### 更新图片
</div>

选择图片以替换 URL，或上传自己的文件进行即时预览。

<div id="section-6">
  ## 可以做什么
</div>

* **快速编辑文本**：无需打开源文件，即可更新文案、标签和标题
* **探索颜色**：通过点击和调整尝试不同配色方案，无需寻找对应的 CSS
* **调整布局**：直观微调内边距、外边距和间距，无需猜测像素值
* **替换图片**：点击并上传，将占位图片替换为实际素材
* **迭代设计**：无需与 Agent 反复沟通，即可快速调整 Canvas 画框并比较不同的视觉方向

<div id="section-7">
  ## 常见问题
</div>

<Accordion title="使用 Visual Editor 进行更改会消耗 AI 积分吗？">
  修改文本、选择颜色、调整间距等简单且明确的编辑不会消耗 AI 积分，而是直接更新源代码。如果 Visual Editor 检测到隐藏的复杂情况，会通过 Agent 处理更改，此时会消耗积分。
</Accordion>

<Accordion title="可以编辑在多个位置出现的元素吗？">
  可以。选择在循环中渲染或在多个组件中重复使用的元素时，所有实例都会高亮显示，并会同时更新。
</Accordion>

<Accordion title="为什么无法编辑某些元素的文本？">
  由多个子元素组成的复合元素无法在 Visual Editor 中直接编辑文本。请在聊天中让 Agent 进行相应更改。
</Accordion>

<Accordion title="如何查找元素的源代码？">
  点击所选元素左上角的标签，即可跳转到源代码中的对应位置。
</Accordion>
