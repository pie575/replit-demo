<div id="otimizar-custos-de-ia">
  ## 优化 AI 成本
</div>

[Agent](/zh/pt/features/agent/overview) 等 AI 功能非常强大，但通过合理使用，您可以在控制成本的同时充分发挥其价值。以下是有效降低 AI 支出的方法。

<div id="use-o-modo-de-planejamento-para-colaborao-econmica">
  ### 使用规划模式，更经济高效地协作
</div>

[规划模式](/zh/pt/features/agent/plan-mode)是节省 AI 成本最有效的方法之一。启用规划模式后，Agent 会制定详细计划，而不会对代码做任何更改。这种方式具有多项成本优势：

* **先沟通，再执行**：在开始任何工作前，与 Agent 讨论并完善方案
* **更低的 token 成本**：规划对话使用的 token 少于生成和编辑代码
* **精准聚焦**：审查并调整计划，确保 Agent 只处理真正重要的事项
* **迭代优化**：在将 token 用于实施前，先明确范围

当你在探索解决方案、完善需求，或希望在实施前了解方案时，请使用[规划模式](/zh/pt/features/agent/plan-mode)。

<div id="controle-custos-com-modos-do-agent">
  ### 使用 Agent 模式控制成本
</div>

[Agent 模式](/zh/pt/features/agent/agent-modes)可让您在成本与能力之间权衡：

* **Free Mode**：Core 和 Pro 订阅者可在额度范围内免费用于日常 Agent 工作。
* **Power**：以实惠的价格提供更强能力。
* **Max**：为最具挑战性的工作提供顶尖模型。
* **Turbo**：可与 Max 搭配切换的选项。

Agent 会在构建过程中自动审查自己的代码，检测错误并减少高成本的返工——无需进行任何配置。若要更好地控制支出，请先通过规划模式确定工作范围：

* **执行前审查**：在 Agent 进行更改前，查看它计划执行的操作。
* **选择性审批**：批准符合您目标的更改，忽略其余更改。

<Tip>
  日常工作可先从 [Free Mode](/zh/pt/features/agent/agent-modes) 开始。需要以实惠的价格获得更强能力时，请选择 [Power 模式](/zh/pt/features/agent/agent-modes)。先规划，再逐步批准更改。
</Tip>

<div id="comprar-pacotes-de-crditos">
  ## 购买积分包
</div>

如果你使用 Core 或 Pro 套餐，需要的积分超出每月订阅额度，可前往**设置** → **账户使用情况** → **积分** → **购买积分包**购买积分包。购买数量越多，折扣越大，适合应对临时使用高峰或为较大型项目提前储备积分。

<div id="como-os-pacotes-de-crditos-funcionam">
  ### 积分包的使用方式
</div>

* **购买入口**：Core 和 Pro 套餐用户可通过 **设置** → **账户使用情况** → **积分** → **购买积分包** 购买
* **有效期**：积分包自购买之日起六个月后失效
* **不自动续订**：积分包不会自动续订
* **不可转移**：积分包到期后，其中未使用的积分不会结转
* **自动使用**：系统会自动优先使用最先到期的积分包，帮助您充分利用所购买的积分
* **自动充值**：开启自动充值后，当您的余额较低时，系统会自动购买一个*新的*积分包，避免您在项目进行到一半时中断
* **随时管理**：您可以在 **设置** → **计费** 中开启、调整或关闭自动充值

<Note>
  在用完所有积分包后，您的使用限额和预算将适用于后续使用。如果您只想将使用量限制在积分包中购买的积分范围内，请将限额设为 $0.01。
</Note>

<div id="ver-recibos-de-pagamento">
  ### 查看付款收据
</div>

如果您的账户使用充值，请前往**设置** → **计费**，找到**付款收据**，查看成功的一次性充值和自动充值付款。每一项均显示付款日期、购买类型、金额和退款状态。选择**查看收据**，即可打开支付服务提供商的收据。

<div id="configurar-limites-e-oramentos">
  ## 配置限额和预算
</div>

您可以为所有按用量计费的服务设置每月用量限额和预算，以监控和控制成本。

<div id="limites-de-uso">
  ### 用量限额
</div>

用量限额可限制超出每月积分后的支出。达到限额后，按用量计费的服务将被暂停，直到下一个计费周期开始或您提高限额。

对于 Core 账户，请打开 **设置** → **账户** → **计费**，配置用量限额。对于组织，您可以在[用量页面](https://replit.com/usage)的 **总使用量** 下选择 **管理**，设置用量限额。

<div id="limite-de-desligamento-de-servio">
  ### 服务停用限额
</div>

达到此限额后，服务将暂停，直到您提高预算或下一个计费周期开始。这有助于避免产生额外费用。

对于 Core 账户，请打开 **设置** → **账户** → **计费**，配置服务停用限额。

<div id="oramentos-de-organizao">
  ### 组织预算
</div>

对于组织，你可以在[设置页面](https://replit.com/t/replit/settings/billing)设置使用预算。预算必须以 {OrganizationBudgetIncrement} 为增量。

<Note>你必须拥有组织管理员或所有者权限，才能启用月度使用限额。如果你没有访问权限，请联系组织所有者。</Note>

<div id="limites-de-gasto-por-usurio">
  ### 每位用户的支出限额
</div>

Enterprise 管理员可为个别成员设置不同于 workspace 默认值的支出限额。您可以借此为高级用户提供更高的限额，或限制单个成员的支出，而无需更改 workspace 的其他设置。

<Steps>
  <Step title="打开 workspace 用量页面">
    在您的 Enterprise workspace 中，打开[用量页面](https://replit.com/usage)。**Agent 用户**表格列出了 workspace 中的所有成员及其当前用量。
  </Step>

  <Step title="编辑成员限额">
    找到要调整的成员，然后选择 **用量限额** 列中的编辑图标。对话框会显示 workspace 默认值、所有适用的群组限额，以及用于设置新的用户限额的字段。

    <Frame>
      <img src="/assets/mirror/edit-usage-limit-87127319c809.png" alt="用于编辑 workspace 成员用量限额的对话框，显示 workspace 默认值、当前用户专属限额、适用的群组限额，以及一个设置为 $5 的用户限额字段" width="1202" height="916" data-path="images/billing/edit-usage-limit.png" />
    </Frame>
  </Step>

  <Step title="保存覆盖设置">
    输入新限额并选择 **保存**。覆盖设置会立即生效，新值将显示在 **用量限额** 列中。若要日后移除覆盖设置，请清空该字段并保存。该成员随后将恢复为对其适用的最具体的群组或 workspace 限额。
  </Step>
</Steps>

<Note>每位用户的支出限额仅适用于 Enterprise 套餐。分配到[自定义群组](/zh/pt/teams/identity-and-access-management/groups-and-permissions)的成员会继承该群组的限额，除非设置了个人覆盖限额。用户级覆盖设置始终优先于群组和 workspace 默认值。</Note>

<div id="controles-administrativos-da-organizao">
  ### 组织管理控件
</div>

组织管理员可以在[组织计费设置](https://replit.com/t/replit/settings/billing)中管理对 AI 模型和集成的访问权限。

**禁用外部 AI 模型集成**

启用此设置后，组织内所有用户将无法使用外部 AI 模型集成 (例如通过 Replit 管理的连接器使用 OpenAI、Anthropic、xAI 和 Perplexity) 。

启用此设置后，组织内所有用户将无法使用由 Replit 管理的 AI 集成。
