本页解答有关账户访问和安全性的常见问题。有关删除账户的详细信息，请参阅[删除数据](/zh/ja/legal-and-security-info/deleting-your-data)；有关账户暂停，请参阅[违规计数系统常见问题](/zh/ja/legal-and-security-info/strike-system-faq)。

<AccordionGroup>
  <Accordion title="如何重置密码？">
    1. 访问 [replit.com/forgot](https://replit.com/forgot)。
    2. 输入注册账户时使用的电子邮件地址。
    3. 打开来自 `notifications@replit.com` 的重置邮件——如果未找到，请检查垃圾邮件文件夹。
    4. 点击链接创建新密码。

    如果您通过 Google、GitHub、Facebook 或 Apple 注册，也可以在同一页面设置独立密码。如果未收到邮件，请确认输入的电子邮件地址与注册时使用的完全一致。
  </Accordion>

  <Accordion title="无法登录——如何恢复账户访问权限？">
    请依次尝试以下操作：

    1. 在 [replit.com/forgot](https://replit.com/forgot) 重置密码，并检查垃圾邮件文件夹中的邮件。
    2. 如果您通过 Google、GitHub 或 Apple 注册，请使用 **Continue with [服务提供商]** 按钮，而不是电子邮件和密码表单。
    3. 请确认您使用的是注册时所用的电子邮件地址——您可能正在使用其他地址。

    如果以上方法均无效，请[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="显示了他人的项目，或您的账户可能遭到未经授权的访问">
    请立即采取以下措施：

    1. 在 [replit.com/forgot](https://replit.com/forgot) 重置密码。
    2. 在账户安全设置中退出其他活跃会话。
    3. 请联系 [Replit 支持](https://replit.com/support)，并提供您发现问题的详细信息。

    如果显示了不属于您的项目，您可能登录了错误的账户——请查看右上角显示的账户名称。
  </Accordion>

  <Accordion title="如何更改电子邮件地址或用户名？">
    要更改用户名，请在 [CLUI](/zh/ja/features/workspace-tools/clui-graphical-cli) 中运行 `account > change-username` 命令，然后提交新用户名。用户名只能更改一次。

    要更改电子邮件地址，请前往 **设置 → 个人资料**，然后编辑电子邮件地址。如果无法完成身份认证，请[联系 Replit 支持](https://replit.com/support)，并提供当前及新的电子邮件地址。
  </Accordion>

  <Accordion title="如何彻底删除 Replit 账户？">
    请下载您希望在删除前保留的所有内容——账户删除后将无法恢复。在 Web 端，请先取消所有有效订阅，然后前往 **设置 → 个人资料** 申请删除账户。在移动端，请打开 Replit 应用中的 **账户 → 更多 → 删除账户**。请参阅[删除您的数据](/zh/ja/legal-and-security-info/deleting-your-data)。
  </Accordion>

  <Accordion title="我的同一邮箱地址似乎关联了两个 Replit 账户——该怎么办？">
    当你先通过一种方式 (如电子邮件) 注册，之后又通过另一种方式 (如 Google) 登录时，就会出现这种情况，并创建第二个账户。

    1. 尝试通过两种方式登录，确认是否存在两个账户。
    2. 决定要保留哪个账户。
    3. 从要关闭的账户中复制项目——使用 **Download as zip** 或 Fork 项目。
    4. 前往 **设置 → 个人资料**，删除不需要的账户。

    如果不确定哪个账户包含订阅或项目，请[联系 Replit 支持](https://replit.com/support)。
  </Accordion>

  <Accordion title="登录后被重定向到非预期的账户">
    同一登录提供商可能关联了多个账户。请尝试使用其他方式 (电子邮件和密码，或其他提供商) 登录，以访问所需的账户。如果您需要确认每种登录方式对应哪个账户，请提供您的用户名并[联系 Replit 支持](https://replit.com/support)。
  </Accordion>

  <Accordion title="无法再通过 SSH 连接到 workspace.*.repl.co">
    `workspace.*.repl.co` SSH 主机名已弃用。请打开项目的 [SSH](/zh/ja/features/workspace-tools/ssh) 窗格，复制当前的连接命令——现已改用 `*.replit.dev` 地址。请更新引用旧版 `repl.co` 地址的所有脚本或 SSH 配置。
  </Accordion>

  <Accordion title="账户为何被暂停？如何提出申诉？">
    Replit 会暂停违反服务条款或社区准则的账户。此外，与账单相关的争议或拒付也可能导致账户被自动暂停。请先查看您的电子邮件 (包括垃圾邮件) ，确认是否收到说明原因的消息。

    如果涉及账单问题，请在 **设置 → 账单** 中结清未付款账单。如果您认为账户被暂停有误，请提供您的用户名、注册邮箱地址和简要说明，并[联系 Replit 支持](https://replit.com/support)。请参阅[违规计数系统常见问题](/zh/ja/legal-and-security-info/strike-system-faq)和[信任与安全](/zh/ja/legal-and-security-info/trust-and-safety)。
  </Accordion>

  <Accordion title="无法通过公司网络注册，或工作区无法加载">
    在企业或学校网络中，即使你的账户没有问题，Replit 也可能被阻止。常见症状包括：注册按钮一直转圈、工作区始终空白、频繁断开连接，或显示 Cloudflare 的“Attention Required!”403 页面。这些问题通常是由 SSL/TLS 检查设备、会重写请求头的代理，或信誉不佳的共享出站 IP 地址等企业安全工具干扰 Replit 所依赖的连接造成的。

    请先确认是否由网络导致：

    1. 使用同一浏览器在其他网络上重试，例如个人手机热点。
    2. 尝试使用无痕模式或隐私窗口，或使用不受扩展程序或政策管理的浏览器。

    如果 Replit 在企业网络外可以正常运行，但在企业网络内无法运行，请让 IT 团队将 Replit 添加到允许列表。由于 Replit 的 IP 地址可能会变更，按域名而非 IP 地址添加到允许列表会更可靠。请让他们允许以下域名：

    * `replit.com` 和 `*.replit.com`—主站点和静态资源
    * `*.replit.dev`—开发 URL
    * `*.replit.app`—已发布的应用
    * `*.repl.co`—旧版开发 URL
    * `replit-com-static.b-cdn.net`—字体
    * `replitcdn.b-cdn.net`—媒体

    Replit 会在这些域名之间建立持久的 WebSocket 连接、频繁发起 API 调用并交换认证令牌，因此还请让 IT 团队检查以下事项：

    * **SSL/TLS 检查**—请为上述域名添加证书检查绕过规则。检查代理可能会在处理 Replit 证书时静默失败，导致页面挂起而不显示明显错误。
    * **请求头重写**—修改、删除或插入 HTTP 请求头的代理规则会破坏跨域 API 调用和认证。
    * **WebSocket 流量**—请允许连接到上述域名的 `wss://` 连接。
    * **浏览器政策**—如果群组政策或 MDM 规则阻止未列入允许列表的域名持久化 Cookie 或使用第三方 Cookie，登录可能无法正常工作。
    * **DNS 解析器**—确认 `replit.com` 和 `*.replit.dev` 的主机名能够解析，并与 `8.8.8.8` 或 `1.1.1.1` 等公共解析器的结果进行比较。采用分割 DNS 或过滤功能的解析器可能不会返回开发 URL 的记录。

    如果 IT 团队应用这些更改后，Replit 仍无法在企业网络中运行，请附上你的用户名、显示的确切错误信息或 Cloudflare Ray ID，并[联系 Replit 支持](https://replit.com/support)。
  </Accordion>

  <Accordion title="连接器（Stripe、GitHub、Resend）无法使用了，如何重新连接？">
    连接器使用的 OAuth 令牌可能会过期或被吊销。要重新连接，请打开 **Tools → Connectors**，断开有问题的连接器，然后重新连接并重新认证。令牌会自动更新到项目的 [Secrets](/zh/ja/core-concepts/project-editor/app-setup/secrets) 中。

    如果重新连接后仍然失败，请确认第三方服务的账户处于有效状态，并拥有适当的权限。请参阅[管理连接器](/zh/ja/replitai/managing-connectors)和[集成概览](/zh/ja/features/integrations/overview)。
  </Accordion>

  <Accordion title="可以将 Replit アカウント转让给他人吗？">
    账户与创建时所用的凭据关联，因此无法直接转让。如需交接特定项目，请让新所有者创建账户，与其共享项目，并请其将项目 fork 到自己的账户。若要更改当前账户的电子邮件地址，请前往 **设置 → 个人资料**，然后编辑电子邮件地址。订阅无法转让——新所有者需要自行订阅。有关企业账户交接事宜，请[联系 Replit 支持](https://replit.com/support)。
  </Accordion>
</AccordionGroup>
