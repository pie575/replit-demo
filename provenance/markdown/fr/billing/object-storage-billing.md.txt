# Facturation du stockage d'applications

> Découvrez comment Replit facture le stockage d'applications.

export const ObjectStorageAdvancedOperationsPer1k = '$0.005';

export const ObjectStorageMonth = '$0.015';

## Catégories de facturation

Replit catégorise la facturation du stockage d'applications dans les domaines suivants :

* **Stockage** : Quantité de capacité de données utilisée par mois. Tous les objets stockés ont une période de facturation minimale de sept jours.
* **Transfert de données** : Quantité totale de données téléchargées et uploadées tout au long du mois.
* **Opérations de base** : Opérations associées à la mise à jour des buckets et des objets. Voir les opérations de classe A dans la <a href="https://cloud.google.com/storage/pricing" target="_blank">tarification de Google Cloud Storage</a> pour plus de détails.
* **Opérations avancées** : Toutes les autres opérations de stockage d'objets cloud, y compris la récupération de la configuration et des métadonnées sur les objets et les buckets. Voir les opérations de classe B dans la <a href="https://cloud.google.com/storage/pricing" target="_blank">tarification de Google Cloud Storage</a> pour plus de détails.
