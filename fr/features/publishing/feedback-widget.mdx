Le widget de retours ajoute un bouton de retours dans un coin de votre application publiée. Les visiteurs s&#39;en servent pour signaler des problèmes ou suggérer des améliorations sans quitter votre application, et vous pouvez transmettre leurs messages directement à Agent pour qu&#39;il les traite.

<div id="turn-on-the-feedback-widget">
  ## Activer le widget de retours
</div>

1. Ouvrez l&#39;outil Publishing en sélectionnant **Publishing** sous **Replit Cloud** dans le volet **Tools**, ou sélectionnez **Publish** en haut à droite du Project Editor.
2. Sous **Engagement tools**, activez l&#39;option **Enable feedback widget**.
3. Sélectionnez **Publish**. Le widget apparaît alors sur votre app publiée.

<div id="position-and-appearance">
  ## Position et apparence
</div>

Lorsque le widget est activé, deux paramètres apparaissent :

* **Position du widget** : choisissez le coin de votre application dans lequel le widget s&#39;affiche : en haut à gauche, en haut à droite, en bas à gauche ou en bas à droite. Par défaut, il s&#39;agit du coin inférieur droit.
* **Apparence** : importez votre propre icône pour le bouton du widget et choisissez sa couleur d&#39;arrière-plan afin qu&#39;elle s&#39;harmonise avec le style de votre application.

<div id="review-and-act-on-feedback">
  ## Consulter les retours et agir en conséquence
</div>

Les messages envoyés par vos visiteurs arrivent dans votre boîte de réception. Vous pouvez alors :

* Lire chaque message pour comprendre les problèmes rencontrés par les visiteurs.
* Transmettre un message à Agent pour correction. Agent traite ce retour comme une tâche et propose des modifications à votre app.

<div id="turn-it-off">
  ## Le désactiver
</div>

Désactivez **Enable feedback widget** dans l&#39;outil Publishing, puis publiez à nouveau. Le widget disparaît alors de votre app publiée.
