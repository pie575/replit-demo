<div id="section">
  ## 查看使用量
</div>

通过[使用量页面](https://replit.com/usage)，你可以查看个人账户或整个工作区中的积分去向。你可以按日期、资源、项目、工作区、群组或成员进行筛选，以了解使用量的来源。

使用量几乎实时更新，因此无需等待每日报告即可查看近期活动。

<div id="ai">
  ## 优化 AI 成本
</div>

[Agent](/zh/ja/features/agent/overview) 等 AI 功能功能强大。通过有策略地使用这些功能，您可以在控制成本的同时最大化其价值。以下是降低 AI 支出的有效方法。

<div id="plan">
  ### 使用 Plan 模式实现高性价比协作
</div>

[Plan 模式](/zh/ja/features/agent/plan-mode)是节省 AI 成本最有效的方法之一。启用 Plan 模式后，Agent 会在不修改代码的情况下制定详细计划。这种方式具有多项成本优势：

* **提交前先沟通**：在开始工作前，与 Agent 讨论并完善方案
* **更低的令牌成本**：规划对话消耗的令牌比生成或编辑代码更少
* **提高准确性**：审查并调整计划，确保 Agent 只处理关键部分
* **迭代改进**：在将令牌用于实现之前，准确界定范围

当你想探索解决方案、完善需求，或在实现前了解方案时，请使用 [Plan 模式](/zh/ja/features/agent/plan-mode)。

<div id="agent">
  ### 使用 Agent 模式管理成本
</div>

您可以通过 [Agent 模式](/zh/ja/features/agent/agent-modes) 选择成本和功能：

* **Free Mode**：Core 和 Pro 订阅者可在额度范围内免费完成日常 Agent 任务。
* **Power**：以实惠的价格提供更强的能力。
* **Max**：适用于最具挑战性任务的顶级前沿模型。
* **Turbo**：Max 中可选的切换选项。

Agent 会在构建过程中自动审查自己的代码，发现错误并减少高成本的返工，无需任何开关设置。若要更精细地控制支出，请先在 Plan 模式中明确工作范围：

* **执行前审查**：在 Agent 做出更改前，查看它计划执行的操作。
* **选择性批准**：批准符合目标的更改，跳过其余更改。

<Tip>
  日常任务请从 [Free Mode](/zh/ja/features/agent/agent-modes) 开始。需要更强能力时，请选择 [Power 模式](/zh/ja/features/agent/agent-modes)。先制定计划，再逐步批准更改。
</Tip>

<div id="section-2">
  ## 购买积分包
</div>

如果您使用 Core 或 Pro 套餐，需要在月度订阅额度之外获取额外积分，可依次前往 **设置** → **账户使用量** → **积分** → **购买积分包** 购买积分包。购买的积分包越多，折扣越高，非常适合应对短期使用量高峰或为大型项目做准备。

<div id="section-4">
  ### 积分包的运作方式
</div>

* **购买方式**: Core 和 Pro 套餐用户可通过**设置** → **账户使用量** → **积分** → **购买积分包**进行购买
* **有效期**: 积分包自购买之日起 6 个月后失效
* **不会自动续订**: 积分包不会自动续订
* **不会结转**: 包内未使用的积分在到期后不会结转
* **自动使用**: 系统会自动优先使用最早到期的积分包，帮助您充分利用所购买的积分
* **自动充值**: 启用自动充值后，当余额不足时，系统会自动购买*新的*积分包，避免您的项目在进行过程中中断
* **可随时管理**: 您可以通过**设置** → **账单**启用、调整或停用自动充值

<Note>
  使用量限制和预算适用于使用积分包后的使用量。如果您希望将使用量限制为仅使用所购积分包中的积分，请将限制设为 $0.01。
</Note>

<div id="section-5">
  ### 查看付款收据
</div>

如果你的账户使用了充值功能，请打开**设置** → **账单**，找到**付款收据**，查看已成功完成的一次性充值和自动充值的付款记录。每一行都会显示付款日期、购买类型、金额和退款状态。选择**查看收据**即可打开支付服务提供商提供的收据。

<div id="section-6">
  ## 设置限额和预算
</div>

您可以为所有按使用量计费的服务设置每月使用量限额和预算，以监控和管理成本。

<div id="section-7">
  ### 使用量限制
</div>

使用量限制可为超出每月额度的支出设定上限。达到限制后，按使用量计费的服务将被暂停，直至下一个账单周期开始或您提高限制。

对于 Core 账户，请依次打开**设置** → **账户** → **账单**，然后设置使用量限制。对于组织，您可以在[使用量页面](https://replit.com/usage)中选择**使用量总计**下方的**管理**，以设置使用量限制。

<div id="section-8">
  ### 服务停用限额
</div>

达到此限额后，服务将暂停，直至你增加预算或下一个计费周期开始，以防止产生额外费用。

如果你使用 Core 账户，请前往**设置** → **账户** → **账单**，设置服务停用限额。

<div id="section-9">
  ### 组织预算
</div>

组织可以通过[设置页面](https://replit.com/t/replit/settings/billing)设置使用量预算。预算必须设置为 {OrganizationBudgetIncrement} 的倍数。

<Note>要启用月度使用量限制，你需要拥有组织管理员或所有者权限。若没有访问权限，请联系组织所有者。</Note>

<div id="section-10">
  ### 每位用户的支出限额
</div>

企业版管理员可以为单个成员设置不同于工作区默认值的支出限额。您可以借此为高级用户提高限额，或在不影响工作区其他成员的情况下严格限制特定成员的支出。

<Steps>
  <Step title="打开工作区使用量页面">
    在企业版工作区中，打开[使用量页面](https://replit.com/usage)。**Agent 用户**表格会列出工作区的所有成员及其当前使用量。
  </Step>

  <Step title="编辑成员限额">
    找到要调整的成员，然后选择**使用量限制**列中的编辑图标。对话框会显示工作区默认值、适用的群组限额，以及新的每位用户限额输入字段。

    <Frame>
      <img src="/assets/mirror/edit-usage-limit-87127319c809.png" alt="工作区成员使用量限制编辑对话框。显示工作区默认值、当前用户专属限额、适用的群组限额，以及设为 $5 的用户限额输入字段" width="1202" height="916" data-path="images/billing/edit-usage-limit.png" />
    </Frame>
  </Step>

  <Step title="保存覆盖设置">
    输入新限额，然后选择**保存**。覆盖设置会立即生效，新值将显示在**使用量限制**列中。若要稍后移除覆盖设置，请清空该字段并保存。成员将使用适用范围最具体的群组或工作区限额。
  </Step>
</Steps>

<Note>每位用户的支出限额仅适用于企业版套餐。分配到[自定义群组](/zh/ja/teams/identity-and-access-management/groups-and-permissions)的成员将继承该群组的限额，除非已设置单独的覆盖设置。每位用户的覆盖设置始终优先于群组限额和工作区默认值。</Note>

<div id="section-11">
  ### 组织管理员控制
</div>

组织管理员可以在[组织账单设置](https://replit.com/t/replit/settings/billing)中管理 AI 模型访问权限和集成。

**禁用外部 AI 模型集成**

启用此设置后，组织内的所有用户都将无法使用外部 AI 模型集成，例如通过 Replit 托管的连接器使用 OpenAI、Anthropic、xAI 和 Perplexity。

启用此设置后，组织内的所有用户都将无法使用由 Replit 管理的 AI 集成。
