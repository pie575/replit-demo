Canvas 工具栏是固定在画板底部中央的浮动工具栏，提供用于导航、绘制、编辑和添加内容的工具。该工具栏会在 Canvas 模式下显示。

<div id="section">
  ## 工具
</div>

选择工具即可激活。已激活的工具会以实心背景突出显示。最左侧的一组为导航工具 (Interact、Pan) 。其余为内容和标记工具。工具之间互斥，选择一个工具会停用其他工具。

<div id="interact">
  ### Interact
</div>

**Interact** 是默认工具。你可以用它选择和拖动 frame，或点击正在运行的 Artifact，像使用实际应用一样与其交互。启用 Interact 后，点击 frame 即可将其选中，并显示[单个 frame 操作栏](/zh/ko/design/frames#per-frame-action-bar)。

<Frame>
  <img src="/assets/mirror/canvas-interact-4472dae3de09.png" alt="使用 Interact 工具在 Canvas 中选中 Website 工件——frame 周围显示选择手柄，上方显示单个 frame 操作栏。底部浮动工具栏中的 Interact 工具处于高亮状态" width="3450" height="2000" data-path="images/replitai/canvas-interact.png" />
</Frame>

**键盘快捷键：** `V`。**访问权限：** 始终启用。

<div id="pan">
  ### Pan
</div>

**Pan** 会将光标切换为抓手工具，让你可以拖动画布本身。启用 Pan 后，点击并拖动会移动视口，而非选择画框。使用其他工具时，你也可以按住空格键拖动，或用鼠标中键拖动来平移。

<Frame>
  <img src="/assets/mirror/canvas-pan-9f07d3bf72a3.png" alt="已启用 Pan 工具的 Canvas — 画布上显示 Website 工件（Velocity — Supercar Rental）和 Design 模型（Velocity — Home (Mockup)），底部浮动工具栏中的 Pan（手形光标）工具处于高亮状态" width="1725" height="1041" data-path="images/replitai/canvas-pan.png" />
</Frame>

**键盘快捷键：** `H`。**适用范围：** 始终可用。

<div id="chat">
  ### Chat
</div>

**Chat** 会直接在画板上显示一个小型聊天输入框，让你无需离开 Canvas 即可向 Agent 发送提示词。所选元素和 frame 会以快照形式附加到消息中，与通过侧边的 Agent 聊天面板发送时相同。

<Frame>
  <img src="/assets/mirror/canvas-chat-d28e2d8f216a.png" alt="处于 Chat 模式的 Canvas。其余画板变暗，Website 工件上叠加了内联聊天输入框。输入框中的“div”标签表示所选元素，提示词为“suggest three alternatives to this image”。底部浮动工具栏中 Chat 工具处于高亮状态。" width="3450" height="2000" data-path="images/replitai/canvas-chat.png" />
</Frame>

**开放条件：**Chat 工具 (仅限桌面端) 。

<div id="draw">
  ### Draw
</div>

**Draw** 可启用自由绘制、箭头、便笺、形状等标注工具，让你可以在帧上绘制草图或在画板上添加注释。你可以用它圈出有问题的区域、指向想要修改的元素，或在帧旁留下笔记。

启用 Draw 后，浮动工具栏上方会显示 **Shape properties** 栏，为当前标注工具提供颜色、描边和填充控件。切换回 Interact 或 Pan 后，该栏会自动消失。

<Frame>
  <img src="/assets/mirror/canvas-draw-d2d9b6556cde.png" alt="启用 Draw 工具的 Canvas — 帧旁绘有一个“Widget”矩形，并放置了一张紫色的“Add a widget”便笺。浮动工具栏上方显示 Shape properties 栏（包含铅笔、文本、矩形、箭头、便笺工具，以及颜色样本和 Aa 文本大小控件），且 Draw 处于高亮状态" width="1725" height="1041" data-path="images/replitai/canvas-draw.png" />
</Frame>

**适用范围：** 始终开启。

<div id="edit">
  ### Edit
</div>

**Edit** 是用于可视化选择元素的工具。启用 Edit 后，点击正在运行的工件中的元素 (按钮、标题、图片) 即可将其选中。选中元素后，右侧会打开 **Visual Editor** 控制面板 (布局、颜色、边框等) ，并提供内联提示词，让你可以要求 Agent 仅修改该部分。完整流程请参阅 [Elements](/zh/ko/design/elements) 和 [Visual Editor](/zh/ko/design/visual-editor)。

<Frame>
  <img src="/assets/mirror/canvas-edit-67fe5ee02fbe.png" alt="在超级跑车租赁网站中，Edit 工具已启用并选中了 div 元素。Visual Editor 面板显示文本、布局、颜色和边框控件，以及 Discard 和 Save edits 按钮" width="2000" height="1269" data-path="images/replitai/canvas-edit.png" />
</Frame>

**可用性：**始终启用 (桌面端) 。如果没有任何 frame，则会被禁用，工具提示会显示 *&quot;创建要编辑的工件或生成设计。&quot;*。移动端不显示。

<div id="generate">
  ### Generate
</div>

**Generate** 会打开用于生成图像、视频和矢量图形的 **Generate media** 弹出窗口。选择类型并输入提示词后，Agent 会将生成结果作为新画框放置在 Canvas 上。

<Frame>
  <img src="/assets/mirror/canvas-add-menu-5d97d9c813e1.png" alt="打开的 Canvas + Add 菜单，其中垂直列出四个选项：Design（“Mock up interfaces and visual concepts”）、Image（“Generate and edit images”）、Video（“Generate motion clips and animations”）、Vector Graphic（“Generate vector illustrations and SVGs”）。底部浮动工具栏中的 Generate 槽位现显示为“+ Generate”" width="1102" height="702" data-path="images/replitai/canvas-add-menu.png" />
</Frame>

弹出窗口顶部有四个标签页。

* **Design**
  — **Image**
* **Video**
* **Vector Graphic**

部分控件适用于所有类型，其他控件则因类型而异。

**通用控件 (所有类型) ：**

* **Model**：要使用的生成模型。可用模型因类型而异 (请参阅下表) 。
* **Prompt**：用于描述希望 Agent 生成内容的自然语言说明。
* **Generate**：提交请求，并在光标位置预留一个占位画框。资源准备就绪后，占位符会转换为实际画框。生成失败时，占位符会被移除，Chat 面板中会显示错误信息。

**各类型的模型和控件：**

| 类型          | 适用场景                               | 当前模型                                                            | 类型专属控件                                                       |
| ----------- | ---------------------------------- | --------------------------------------------------------------- | ------------------------------------------------------------ |
| **Image**   | 栅格输出 (PNG/JPG) ；情绪板图像、主视觉图片、参考艺术作品 | Nano Banana, Nano Banana 2, Nano Banana Pro, ChatGPT Images 2.0 | 宽高比 (`1:1`、`16:9`、`9:16`、`4:3`、`3:4`) · 尺寸 (`1K`、`2K`、`4K`)  |
| **Video**   | 短动态片段和动画                           | Veo 3.1, Seedance 2.0                                           | 宽高比 · 分辨率 (例如 `720p`) · 时长 (例如 `4s`) · 音频开关                  |
| **Graphic** | SVG 矢量输出；图标、徽标、图表和风格化插图            | Claude 4.6 Opus, Gemini 3.1 Pro Preview                         | Animated 开关                                                  |

<Note>
  模型列表经常变化。该表反映当前可用的模型；请查看产品内下拉菜单，了解你的账户今日可用的模型。
</Note>

有关各类画框及其生成后的操作，请参阅 [Frames](/zh/ko/design/frames)。

<div id="section-2">
  #### 添加视觉参考
</div>

生成前，您可以将看板中已有的元素添加为视觉参考。Agent 会利用这些参考生成与项目风格一致的内容。打开 **Generate media** 表单中的 **+** 菜单，然后选择相应选项。

* **Upload file**：从计算机上传图片作为参考。
* **Select canvas elements**：在看板上选择现有元素。frame 会截取为屏幕截图，文本和便笺形状则会以文本摘要形式附加。

每项参考都会以标签形式显示在表单中。按需添加参考、编写提示词，然后选择 **Generate**。要移除参考，请选择对应的标签。

<Frame caption="打开 + 菜单的 Generate media 表单，显示 Upload file 和 Select canvas elements 选项。">
  <img src="/assets/mirror/canvas-generate-media-references-ac0cb4340acb.png" alt="Canvas 中打开 + 菜单的 Generate media 表单。显示 Upload file 和 Select canvas elements 选项，模型下拉菜单设为 Nano Banana Pro。" width="1134" height="662" data-path="images/replitai/canvas-generate-media-references.png" />
</Frame>

<Note>
  ChatGPT Images 2.0 目前不支持上传。要添加视觉参考，请切换到 Nano Banana Pro 等模型。
</Note>

启用 **Add menu** 后，Generate 按钮会替换为 **+** 菜单。该菜单将弹出窗口中的各种类型与 **Design** (不影响正在运行代码的独立视觉模型) 整合在一起。

**权限要求：**Image generation。**Vector Graphic** 需要 Vector graphic generation，**Video** 需要 Video generation。**+** 菜单需要 Add menu (其本身需要 Image generation) 。

<div id="section-3">
  ## 浏览画板
</div>

平移、缩放和选择手势及其键盘快捷键属于画板本身的操作，并非工具栏中的工具。请参阅 Canvas 页面中的[浏览画板](/zh/ko/design/canvas#navigate-the-board)。
