<div id="ssh">
  ## Что такое SSH?
</div>

SSH (Secure Shell) — это защищённый протокол, который позволяет удалённо подключаться к интерфейсу командной строки вашего Replit App. С помощью SSH вы можете без лишних сложностей передавать файлы и редактировать код в Replit в привычной локальной среде разработки (IDE), что повышает продуктивность и удобство совместной работы.

Возможности SSH доступны на тарифах Core, Pro и всех остальных платных тарифах.

Кратко о процессе:

* Создайте пару SSH-ключей на локальной машине
* Добавьте этот SSH-ключ в панель **SSH** нужного Replit App
* Подключитесь с помощью SSH-клиента или редактора, который умеет работать по SSH (например, [VSCode](https://code.visualstudio.com/) или [Cursor](https://www.cursor.com/))

<Note>
  SSH-ключи привязываются к учётной записи, а не к конкретному Replit App. Это значит, что достаточно добавить открытый ключ один раз, чтобы подключаться ко всем Replit App, к которым у вас есть доступ.
</Note>

<div id="ssh-2">
  ## Зачем использовать SSH
</div>

* **Автоматическая синхронизация между Replit App и редактором**: любые изменения, сделанные в Replit App, сразу же отражаются в редакторе, а правки из редактора попадают в Replit App. Такая бесшовная синхронизация гарантирует, что кодовая база всегда остаётся актуальной на всех платформах.

* **Синхронизация работы с файлами**: добавляете ли вы файлы, удаляете или обновляете их — эти изменения синхронизируются между редактором и Replit App в реальном времени. Благодаря этому структура проекта остаётся единой независимо от того, где было внесено изменение.

* **Управление папками и перемещение файлов**: перемещение файлов между папками также синхронизируется между редактором и Replit App. Так структурные изменения, сделанные в одном окружении, точно отражаются в другом, сохраняя целостность и структуру проекта.

<div id="section">
  ## Поиск или создание пары ключей
</div>

Чтобы настроить SSH для учётной записи, вам понадобится открытый SSH-ключ.

<div id="section-2">
  ### Проверка наличия пары ключей
</div>

Чтобы узнать, есть ли у вас уже открытый ключ, выполните в терминале на локальном компьютере следующую команду:

<Tabs>
  <Tab title="Mac/Linux">
    ```sh theme={null}
    ls -l ~/.ssh
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    dir %HOMEPATH%\.ssh
    ```
  </Tab>
</Tabs>

Если появилась ошибка — ничего страшного. Перейдите к разделу [Создание новой пары ключей](#generating-a-new-keypair).
Если вы видите файл с именем `replit.pub`, перейдите к разделу [Получение содержимого открытого ключа](#get-the-contents-of-your-public-key).

<div id="section-3">
  ### Создание новой пары ключей
</div>

Откройте на своём компьютере окно терминала (или командной строки) и вставьте следующую команду:

<Tabs>
  <Tab title="Mac/Linux">
    ```bash theme={null}
    ssh-keygen -t ed25519 -f ~/.ssh/replit -q -N ""
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    ssh-keygen -t ed25519 -f %HOMEPATH%\.ssh\replit -q -N ""
    ```
  </Tab>
</Tabs>

Эта команда проверяет, существует ли уже указанный файл открытого SSH-ключа. Если его нет, создаётся новый SSH-ключ с подходящими параметрами.

<div id="section-4">
  ### Получение содержимого открытого ключа
</div>

Если вы убедились, что пара ключей уже есть, или создали новую, выведите содержимое открытого ключа (это один из двух файлов с похожими именами — тот, что заканчивается на `.pub`): оно понадобится вам далее.

<Tabs>
  <Tab title="Mac/Linux">
    ```sh theme={null}
    cat ~/.ssh/replit.pub
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    notepad %HOMEPATH%\.ssh\replit.pub
    ```
  </Tab>
</Tabs>

Сохраните содержимое `replit.pub`, чтобы использовать его далее в этом документе, и переходите к разделу [Добавление SSH-ключа в учётную запись](#add-the-ssh-key-to-your-account).

<div id="ssh-3">
  ## Добавление SSH-ключа в учётную запись
</div>

<div id="ssh-replit">
  ### Добавление публичного ключа напрямую в Replit App через панель SSH
</div>

1. В любом окне Replit App нажмите кнопку **+** и найдите **SSH**.

<Frame>
  <img src="/assets/mirror/ssh-tool-2db02c6a83d0.png" alt="Кнопка инструмента SSH в интерфейсе Replit" width="846" height="328" data-path="images/ssh-vscode/ssh-tool.png" />
</Frame>

2. Перейдите на вкладку **Keys** и выберите **New SSH key**.
3. Во всплывающем окне введите **Label** для ключа (например, my-ssh-key) и вставьте скопированный публичный ключ в поле **Key**.
   Нажмите кнопку **Add SSH Key**. Ключ добавлен и готов к использованию.

<Frame>
  <img src="/assets/mirror/add-ssh-key-with-values-5d6f440e56ba.png" alt="Диалоговое окно добавления SSH-ключа с заполненными полями метки и ключа" width="500" height="511" data-path="images/ssh-vscode/add-ssh-key-with-values.png" />
</Frame>

<div id="section-5">
  ### Добавление открытого ключа напрямую в настройках
</div>

Добавить SSH-ключ можно и через **Настройки**: в разделе **Учётная запись** выберите **Дополнительно** (или пункт **SSH-ключи**). Нажмите **Add SSH key** и вставьте содержимое файла `replit.pub`, полученного в предыдущем разделе [Поиск или создание пары ключей](#find-or-create-a-keypair).

<Note>
  Если на вашем компьютере несколько открытых ключей, важно указать в конфигурации SSH правильное сочетание закрытого и открытого ключей.
</Note>

<div id="replit">
  ## Подключение к Replit App
</div>

<div id="ssh-4">
  ### Настройка конфигурации SSH
</div>

1. В терминале проверьте, существуют ли каталог `~/.ssh` и файл `~/.ssh/config`:

<Tabs>
  <Tab title="Mac/Linux">
    ```sh theme={null}
    mkdir -p ~/.ssh && chmod 700 ~/.ssh && touch ~/.ssh/config && chmod 600 ~/.ssh/config
    open -a 'TextEdit' ~/.ssh/config || nano ~/.ssh/config
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    if not exist %HOMEPATH%\.ssh mkdir %HOMEPATH%\.ssh && type \NUL > %HOMEPATH%\.ssh\config
    notepad %HOMEPATH%\.ssh\config
    ```
  </Tab>
</Tabs>

2. Добавьте блок конфигурации, чтобы для всех доменов *.replit.dev использовалась пара ключей `replit`:

<Tabs>
  <Tab title="Mac/Linux/Windows">
    ```
    Host *.replit.dev
        Port 22
        IdentityFile ~/.ssh/replit
        StrictHostKeyChecking accept-new
    ```
  </Tab>
</Tabs>

<div id="vscode-cursor">
  ### Подключение из VSCode или Cursor
</div>

1. Откройте панель **SSH** в Replit App

2. В панели SSH перейдите на вкладку **Connect** и выберите **Launch VS Code**.

<Tabs>
  <Tab title="Подключение через VSCode">
    <img src="/assets/mirror/ssh-connect-439a3c150846.png" alt="Вкладка SSH connect с параметром Launch VS Code" width="788" height="482" data-path="images/ssh-vscode/ssh-connect.png" />
  </Tab>
</Tabs>

3. Когда появится запрос на заполнение `~/.ssh/config`, введите следующее:

   ```
   Host *.replit.dev
       Port 22
       IdentityFile ~/.ssh/replit
       StrictHostKeyChecking accept-new
   ```

   <Note>
     Запрос на добавление конфигурации SSH появляется только при первой попытке подключения к VS Code или другому редактору. Чтобы вернуться к файлу конфигурации, выберите &#42;&#42;Configure SSH Hosts...&#42;&#42;.
   </Note>

4. Если появится предупреждение о внешнем приложении, выберите **Yes**, чтобы подтвердить открытие проекта в нужном редакторе или в VS Code.

5. Время от времени вам может предлагаться установить или обновить расширение SSH. Replit стремится сохранять совместимость с последними версиями этих IDE, а вы получаете важные обновления безопасности.

<div id="section-6">
  ### Подключение вручную
</div>

В нижней части вкладки &quot;Connect&quot; панели **SSH** находится пункт &quot;Connect manually&quot;.

Скопируйте эту команду и вставьте её в локальный терминал (Mac или Linux) либо в локальную командную строку (Windows), чтобы подключиться напрямую.

<div id="section-7">
  ### Подключение с помощью инструмента, которого нет в этом списке
</div>

Для разных платформ и операционных систем доступно множество SSH-клиентов, предлагающих различные функции и интеграции.

Вы всегда сможете настроить любой клиент, разобрав команду из раздела &quot;Подключиться вручную&quot; на составляющие:

```sh theme={null}
ssh -i ~/.ssh/replit -p 22  c96b6ade-d5e4-4f7a-bc5b-52334509b2a3@c96b6ade-d5e4-4f7a-bc5b-52334509b2a3-00-16nh2hskw3ql8.riker.replit.dev
       ^-----v-----^    ^^  ^-----------------v----------------^ ^------------------------------v-------------------------------------^
        Private Key   Port                   User               @                           Hostname
```

**Hostname**: `<your_hostname>.<cluster>.replit.dev`
**Port**: `<port_number>`
**User**: `Username`
**Private Key**: путь к файлу приватного ключа на вашем компьютере. Обычно он находится рядом с `replit.pub`.
