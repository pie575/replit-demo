<div id="importar-do-lovable">
  ## Importer depuis Lovable
</div>

⏰ *Temps estimé : quatre minutes*

Importez un projet Lovable dans Replit en l’exportant vers GitHub, puis en important ce dépôt.

Pour connaître toutes les options d’importation, notamment depuis d’autres plateformes comme GitHub, Figma et Bolt, consultez la [documentation de la fonctionnalité d’importation](/fr/pt/core-concepts/project-editor/app-setup/import).

<div id="antes-de-comear">
  ## Avant de commencer
</div>

* Un projet Lovable que vous pouvez exporter
* Un compte GitHub connecté à Lovable
* Un compte Replit

<div id="passos-de-importao">
  ## Étapes d’importation
</div>

1. Exportez votre projet Lovable vers GitHub.
2. Ouvrez [replit.com/import](https://replit.com/import).
3. Sélectionnez **Lovable**.
4. Connectez votre compte GitHub.
5. Sélectionnez le dépôt exporté depuis Lovable.
6. Sélectionnez **Importer**.

<div id="what-gets-imported">
  ## Éléments importés
</div>

Replit importe les éléments suivants depuis votre projet {platform_1} :

* **Code** : Logique applicative et fichiers sources
* **Conception et styles** : Composants d&#39;UI et règles de style
* **Assets** : Images, icônes et fichiers statiques
* **Logique backend** : Fonctionnalités côté serveur, le cas échéant
* **Schéma de base de données** : Structure des tables, le cas échéant

<div id="what-is-not-imported">
  ## Éléments non importés
</div>

* **Données Supabase** : les enregistrements existants de la base de données ne sont pas migrés
* **Secrets** : les variables d’environnement et les clés API doivent être ajoutées séparément

Utilisez Agent pour recréer les fonctionnalités manquantes, ajouter des secrets et restaurer les données de la base de données.

<div id="configure-and-run-your-app">
  ## Configurez et exécutez votre app
</div>

Lors de l’importation, {setupDescription_0}. Si votre app nécessite des modifications, utilisez les outils suivants dans le Project Editor :

* **[Agent](/fr/features/agent/overview)** : Améliorez les fonctionnalités, déboguez les problèmes et modifiez le code
* **[Secrets](/fr/core-concepts/project-editor/app-setup/secrets)** : Ajoutez des clés API et des variables d’environnement
* **[Workflows](/fr/features/workspace-tools/workflows)** : Définissez la commande **Run** de votre app
