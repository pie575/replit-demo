Вход пользователей на ваш сайт с помощью аккаунта Google даёт следующие преимущества:

1. Не нужно реализовывать собственный механизм аутентификации.
2. Можно легко получать имена и контактные данные пользователей.
3. С теми же учётными данными можно получать доступ к ресурсам Google пользователей, таким как Sheets и Drive.

В этом руководстве рассказывается, как реализовать это в Replit с помощью Python и Flask.

Сначала мы рассмотрим настройку базовой OAuth-аутентификации, а затем узнаем, как использовать учётные данные, полученные при аутентификации, для доступа к ресурсам Google пользователя.

<div id="oauth">
  ## Введение в OAuth
</div>

Аутентификация Google основана на стандарте OAuth. Вот как работает OAuth:

1. На вашем сайте вы направляете пользователя на страницу входа.
2. Когда пользователь открывает страницу входа, вместо реализации формы входа на сайте вы перенаправляете его в сервис входа Google.
3. После успешного входа сервис Google перенаправляет пользователя обратно на ваш сайт по заранее заданному URL (например, `https://YOUR_DOMAIN/oauth2callback`), передавая информацию о пользователе и его сеансе.
4. Используя данные для входа пользователя, вы получаете токен доступа. Этот токен похож на пропуск, который позволяет получить доступ к ресурсам пользователя, таким как информация профиля, таблицы и документы.

<div id="oauth-2">
  ## OAuth: код
</div>

Если хотите сначала ознакомиться с кодом, вот что вам понадобится. Однако, чтобы всё заработало, потребуется выполнить несколько настроек в Google Cloud Console. Они описаны в следующем разделе. Создайте новое Replit App с помощью [шаблона Flask](https://replit.com/@replit/Flask?v=1) и вставьте следующий код в `main.py`. Комментарии в коде поясняют назначение каждой части:

```python theme={null}
from flask import Flask, redirect, session, url_for, request
import google_auth_oauthlib.flow
import json
import os
import requests

app = Flask('app')
# `FLASK_SECRET_KEY` используется для сессии. Создайте случайную строку
# и сохраните её как секрет.
app.secret_key = os.environ.get('FLASK_SECRET_KEY') or os.urandom(24)

# `GOOGLE_APIS_OAUTH_SECRET` содержит содержимое JSON-файла,
# который нужно скачать в разделе учетных данных Google Cloud. См. следующий раздел.
oauth_config = json.loads(os.environ['GOOGLE_OAUTH_SECRETS'])

# Настройка потока OAuth
oauth_flow = google_auth_oauthlib.flow.Flow.from_client_config(
    oauth_config,
    # scopes определяет API, к которым будет выполняться доступ от имени пользователя после авторизации
    scopes=[
        "https://www.googleapis.com/auth/userinfo.email",
        "openid",
        "https://www.googleapis.com/auth/userinfo.profile",
    ]
)

# Это точка входа на страницу авторизации. Она перенаправляет на страницу входа Google
# по адресу `authorization_url`. `redirect_uri` — URI, который сервис входа Google будет использовать,
# чтобы перенаправить пользователя обратно в это приложение.
@app.route('/signin')
def signin():
    # Внутри Replit App используется http, но извне доступ осуществляется по https,
    # поэтому URL преобразуется из http в https, чтобы redirect_uri ему соответствовал
    oauth_flow.redirect_uri = url_for('oauth2callback', _external=True).replace('http://', 'https://')
    authorization_url, state = oauth_flow.authorization_url()
    session['state'] = state
    return redirect(authorization_url)

# Это эндпоинт, на который перенаправляет сервис входа Google. Его необходимо добавить в
# «Authorized redirect URIs» в разделе учетных данных API Google Cloud.
# Он вызывает эндпоинт Google, чтобы запросить токен доступа, и сохраняет его в сессии пользователя.
# Затем этот токен доступа можно использовать для обращения к API от имени пользователя.
@app.route('/oauth2callback')
def oauth2callback():
    if not session['state'] == request.args['state']:
        return 'Invalid state parameter', 400
    oauth_flow.fetch_token(authorization_response=request.url.replace('http:', 'https:'))
    session['access_token'] = oauth_flow.credentials.token
    return redirect("/")

# Это главная страница приложения. Если пользователь не вошёл в систему, она предлагает выполнить вход,
# а если уже вошёл — отображает сведения о пользователе.
@app.route('/')
def welcome():
    if "access_token" in session:
        user_info = get_user_info(session["access_token"])
        if user_info:
            return f"""
                Hello {user_info["given_name"]}!<br>
                Your email address is {user_info["email"]}<br>
                <a href="/logout">Log out</a>
            """
    return """
        <h1>Hello!</h1>
        <a href="/signin">Sign In via Google</a><br>
    """

# Получает сведения о пользователе, вызывая API userinfo с действительным токеном доступа.
# Это первый пример обращения к API от имени пользователя с помощью токена доступа.
def get_user_info(access_token):
    response = requests.get("https://www.googleapis.com/oauth2/v3/userinfo", headers={
       "Authorization": f"Bearer {access_token}"
   })
    if response.status_code == 200:
        user_info = response.json()
        return user_info
    else:
        print(f"Failed to fetch user info: {response.status_code} {response.text}")
        return None

@app.route('/logout')
def logout():
    session.clear()
    return redirect('/')

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000)

```

  ## Интеграция с Google Sheets: просмотр кода
</div>

В разделе поток OAuth исходного кода оставьте всё без изменений и добавьте в список разрешений только `"https://www.googleapis.com/auth/spreadsheets.readonly"`:

```python theme={null}
# Настройка OAuth-потока
oauth_flow = google_auth_oauthlib.flow.Flow.from_client_config(
    oauth_config,
    # scopes определяют API, к которым будет предоставлен доступ от имени пользователя после аутентификации
    scopes=[
        "https://www.googleapis.com/auth/userinfo.email",
        "openid",
        "https://www.googleapis.com/auth/userinfo.profile",
        "https://www.googleapis.com/auth/spreadsheets.readonly"
    ]
)
```

Чтобы обратиться к Google API с помощью библиотеки `googleapiclient.discovery`, сначала создайте объект `Credentials` с токеном доступа, а затем с помощью функции `build` — объект API, который можно вызывать. Для Sheets API это выглядит так:

```python theme={null}
credentials = google.oauth2.credentials.Credentials(token=session['access_token'])
service = build("sheets", "v4", credentials=credentials)
sheets_api = service.spreadsheets()
```

Мы создали несколько вспомогательных функций для практической работы с Sheets API:

```python theme={null}
# Получение всех листов из Google Таблицы
def get_sheets(sheets_api, spreadsheet_id) -> list[str]:
    result = sheets_api.get(spreadsheetId=spreadsheet_id).execute()
    return [sheet["properties"]["title"] for sheet in result["sheets"]]

# Получение данных конкретного листа из Google Таблицы
def get_sheet_data(sheets_api, spreadsheet_id, sheet_title) -> list[list[str]]:
    result = (
        sheets_api.values()
        .get(spreadsheetId=spreadsheet_id, range=sheet_title)
        .execute()
    )
    return result["values"]
```

С помощью приведённых выше инструкций можно создать конечную точку POST-обработчика для импорта Google Sheets:

```python theme={null}
@app.route("/import_spreadsheet", methods = ['POST'])
def import_spreadsheet():
    if 'access_token' not in session:
        return redirect('/signin')
    spreadsheet_id = request.form["spreadsheet_id"]
    credentials = google.oauth2.credentials.Credentials(token=session['access_token'])
    service = build("sheets", "v4", credentials=credentials)
    sheets_api = service.spreadsheets()
    try:
        sheets = get_sheets(sheets_api, spreadsheet_id)
        data_by_sheets = {}
        for sheet in sheets:
            data = get_sheet_data(sheets_api, spreadsheet_id, sheet)
            data_by_sheets[sheet] = data
    except googleapiclient.errors.HttpError as e:
        return f"upload failure"
    dirpath = os.path.join("static", "uploads", spreadsheet_id)
    filepath = os.path.join(dirpath, "data.json")
    os.makedirs(dirpath, exist_ok=True)
    with open(filepath, "w") as file:
        json.dump(data_by_sheets, file)
    return "upload success!"
```

    )
    return result["values"]

@app.route("/import_spreadsheet", methods = ['POST'])
def import_spreadsheet():
    if 'access_token' not in session:
        return redirect('/signin')
    spreadsheet_id = request.form["spreadsheet_id"]
    credentials = google.oauth2.credentials.Credentials(token=session['access_token'])
    service = build("sheets", "v4", credentials=credentials)
    sheets_api = service.spreadsheets()
    try:
        sheets = get_sheets(sheets_api, spreadsheet_id)
        data_by_sheets = {}
        for sheet in sheets:
            data = get_sheet_data(sheets_api, spreadsheet_id, sheet)
            data_by_sheets[sheet] = data
    except googleapiclient.errors.HttpError as e:
        return f"upload failure"
    dirpath = os.path.join("static", "uploads", spreadsheet_id)
    filepath = os.path.join(dirpath, "data.json")
    os.makedirs(dirpath, exist_ok=True)
    with open(filepath, "w") as file:
        json.dump(data_by_sheets, file)
    return "upload success! Really!"
