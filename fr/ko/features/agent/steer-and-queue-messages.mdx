Pendant qu’Agent travaille, les messages de suivi peuvent modifier la tâche en cours, c’est-à-dire le
**tour** actif, ou attendre la fin de ce tour :

* **Steer (rediriger)** envoie un message au tour actif. Agent poursuit son travail en tenant compte du nouveau contexte.
* **Queue (file d’attente)** conserve le message pour le tour suivant. Agent le traite une fois le tour actif terminé.

<div id="section">
  ## Guider la Conversation
</div>

Steer est le comportement d’envoi par défaut des messages de suivi dans Conversation et Project.
Vous pouvez définir ces deux paramètres sur Queue.

<div id="replit">
  ## Choisir le mode d’envoi des messages de suivi par Replit
</div>

Vous pouvez définir des comportements d’envoi différents pour les Conversations et les Projects :

1. Ouvrez **Paramètres** &gt; **Personnalisation**.
2. Développez **Agent**.
3. Définissez **Comportement d’envoi de Conversation** et **Comportement d’envoi de Project** sur **Steer** ou **Queue**.

<Frame caption="Paramètres du comportement d’envoi pour Conversation et Project dans la section Agent.">
  <img src="/assets/mirror/agent-follow-ups-settings-98a4c5ca399e.png" alt="Paramètres d’Agent affichant les comportements d’envoi de Conversation et Project, avec les options Steer et Queue" width="3048" height="1372" data-path="images/replitai/agent-follow-ups-settings.png" />
</Frame>

<Info>
  Le mode Design utilise toujours Steer pour les messages de suivi. Les paramètres de comportement
  d’envoi de Conversation et Project ne s’appliquent pas au mode Design.
</Info>

Pour envoyer un message ponctuellement avec un comportement différent de celui défini dans vos paramètres,
appuyez sur `Cmd+Enter` (Mac) ou `Ctrl+Enter` (Windows et Linux).

<div id="section-2">
  ## Gérer les messages mis en file d’attente
</div>

Lorsque vous mettez des messages de suivi en file d’attente, la file de messages s’affiche sous forme de tiroir au-dessus du champ de saisie du chat. Agent traite les messages mis en file d’attente dans l’ordre une fois le tour actif terminé. Lorsque Agent a traité tous les messages de la file d’attente, le tiroir se ferme.

Toutes les options de message, y compris [Visual Editor](/fr/ko/design/visual-editor) et les pièces jointes, sont disponibles dans la Queue.

<Info>
  Agent traite automatiquement les messages mis en file d’attente uniquement lorsqu’une session Project Editor active est connectée, sur ordinateur ou sur mobile.
</Info>

<div id="section-3">
  ### Gérer la file d’attente
</div>

Lorsque le tiroir de la file d’attente est ouvert, vous pouvez effectuer les actions suivantes :

* **Steer maintenant (ajuster maintenant)** : déplacer les messages ajoutés à la file d’attente vers le tour actif.
* **Modifier les messages** : modifiez les messages ajoutés à la file d’attente avant qu’Agent ne les traite.
* **Supprimer les messages** : supprimez les messages dont vous n’avez plus besoin.
* **Réorganiser les messages** : faites glisser les messages pour modifier leur ordre de traitement.
* **Ajouter des messages** : envoyez d’autres messages de suivi dans la file d’attente.

<div id="section-4">
  ## Arrêter le tour actif
</div>

Sélectionnez **Stop** dans la barre d’état pour interrompre l’action en cours effectuée par Replit lors du tour actuel. Vous pouvez alors envoyer un nouveau message sans attendre qu’Agent termine le tour ou traite les messages ajoutés à la file d’attente.
