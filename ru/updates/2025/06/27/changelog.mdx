<div id="security-scanner-updates">
  ### Обновления Security Scanner
</div>

Оцените более быстрое и эффективное сканирование безопасности благодаря масштабному обновлению Security Scanner. Теперь результаты сканирования кэшируются, а повторный запуск выполняется только при изменении кода, поэтому последующие проверки проходят молниеносно. Новая функция игнорирования позволяет скрывать ненужные проблемы безопасности, сохраняя возможность найти их при необходимости.

<div id="agent-system-prompt-optimization">
  ### Оптимизация системного промпта для Agent
</div>

Благодаря последним улучшениям системы взаимодействие с Agent стало быстрее и эффективнее. Теперь Agent выполняет task на 2–3 секунды быстрее при каждом действии, сохраняя привычно высокое качество результатов.
