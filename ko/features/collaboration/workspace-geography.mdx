Workspace geography는 Workspace의 개발 리소스가 호스팅되는 위치를 결정합니다. Workspace를 생성할 때 선택하며, 해당 Workspace에서 만드는 새 Project와 리소스는 선택한 위치를 사용합니다.

<Note>
  Workspace geography와 [publishing
  geography](/ko/features/security/geography#publishing-geography)는 서로 다를 수 있습니다.
  Publishing geography는 게시된 Project가 실행되는 위치를 결정합니다.
</Note>

<div id="what-workspace-geography-controls">
  ## Workspace geography가 결정하는 범위
</div>

Workspace는 Projects, 구성원, 설정, 공유 리소스, integrations, billing을 한곳에 모아 관리합니다. 각 Project 내에서는 Project Editor와 Replit 채팅을 사용합니다. 개발 리소스에는 앱의 개발 버전과 해당 development database가 포함됩니다.

특정 Workspace region을 직접 선택할 수 있는 것은 Pro 고객뿐입니다.

Free 및 Core 고객의 Workspace region은 자동으로 설정되며, 대개 사용자와 가장 가까운 Workspace region이 선택됩니다. Workspace에서 새로 만드는 Projects와 리소스는 해당 위치를 사용합니다. Workspace를 생성한 뒤에는 region을 변경할 수 없습니다.

<div id="select-a-workspace-region">
  ## Workspace region 선택
</div>

Pro 고객이라면 Workspace를 생성할 때 Workspace region을 선택할 수 있습니다.

<Steps>
  <Step>**Create a new workspace** 양식을 엽니다.</Step>
  <Step>Workspace 이름을 입력하고, 필요한 경우 멤버 이메일 주소도 입력합니다.</Step>

  <Step>
    **Workspace region**을 열고 **North America**, **Europe (EU)**,
    **Asia** 중 하나를 선택합니다.
  </Step>

  <Step>**Create workspace**를 선택합니다.</Step>
</Steps>
