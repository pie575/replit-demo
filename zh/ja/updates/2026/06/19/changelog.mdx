<div id="claudereplit">
  ### 在 Claude 中使用 Replit
</div>

Replit 现可作为 Claude 的连接器使用。连接后，你可以直接在与 Claude 的对话中创建、更新 Replit App，或提出问题。你还可以将 Claude 中的设计直接发送到 Replit，并以可运行的 App 形式打开。Agent 会制定计划，将其转化为可用的产品。

</Frame>

详细了解[在 Claude 中使用 Replit](/zh/ja/features/platforms/claude)。

<div id="mcpapollo-black-forest-labs">
  ### 新增 MCP 服务器：Apollo 和 Black Forest Labs
</div>

一键式 MCP 目录新增两款服务器。连接 **Apollo**，即可通过与 Agent 对话调研账户和联系人，并构建外联名单。连接 **Black Forest Labs**，无需离开项目即可生成和编辑 FLUX 图像。

详情请参阅 [MCP 列表](/zh/ja/features/mcp/overview)。

<div id="section-3">
  ### 语音模式
</div>

现在，您可以通过语音描述想要创建的内容。点击 Agent 聊天框中的麦克风，说出提示词，Replit 会将语音转录为可编辑的文本。确认文本并进行必要的编辑后，即可像发送其他消息一样发送。所有 Replit 套餐均可使用语音模式。

<div id="enterprise">
  ## 团队和 Enterprise
</div>

<div id="enterprise-2">
  ### 邀请外部访客加入 Enterprise 工作区
</div>

Enterprise 管理员现在无需通过身份提供商，即可邀请外部协作者以访客身份加入工作区。将单个应用分享给外部电子邮件地址后，对方将以仅能访问该应用的访客身份加入。访客会显示在专用表格中，您可以查看他们可访问的应用，并随时撤销其访问权限。
