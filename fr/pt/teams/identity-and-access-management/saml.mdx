<div id="introduo">
  ## Introduction
</div>

<Note>
  Vous souhaitez ajouter le SSO au flux de connexion d&#39;**une app que vous créez** sur Replit ? Consultez [Ajouter le SSO à votre app (Clerk)](/fr/pt/features/auth-and-identity/single-sign-on). Cette page explique comment activer le SSO pour votre **organisation Replit**, c&#39;est-à-dire la façon dont votre équipe se connecte à replit.com.
</Note>

<Note>
  Seules les organisations disposant d&#39;un plan Enterprise peuvent utiliser le SSO SAML. Vous pouvez [acheter le plan Enterprise directement depuis la page des tarifs](https://replit.com/pricing) ou [nous contacter](https://replit.com/teams#inlineForm) pour un accompagnement pas à pas.
</Note>

Le SSO [SAML](https://en.wikipedia.org/wiki/Security_Assertion_Markup_Language) vous permet d&#39;utiliser votre fournisseur d&#39;identité (IdP) pour authentifier les utilisateurs qui se connectent à replit.com. Les utilisateurs de votre organisation sont redirigés vers votre IdP pour l&#39;authentification, et l&#39;IdP renvoie à Replit une réponse qui vérifie l&#39;identité de l&#39;utilisateur et le connecte.

Les administrateurs Enterprise peuvent configurer le SSO SAML directement dans **Paramètres Enterprise → Authentification**, sans contacter Replit. L&#39;assistant génère les valeurs du fournisseur de services (SP), accepte vos identifiants IdP et provisionne le SSO automatiquement. Ce même flux en libre-service est utilisé lors de l&#39;inscription si vous achetez le plan Enterprise en ligne : vous serez donc guidé dans la configuration du SSO durant l&#39;onboarding.

<div id="configurar-saml-sso">
  ## Configurer le SSO SAML
</div>

<img src="/assets/mirror/saml-enterprise-settings-d2d44c2de846.png" alt="Configuration du SSO SAML dans les paramètres Enterprise" width="1024" height="613" data-path="images/teams/identity-and-access-management/saml-enterprise-settings.png" />

L&#39;assistant de configuration vous guide en cinq étapes. Vous devez disposer d&#39;un accès administrateur à la fois sur votre organisation Replit et sur votre fournisseur d&#39;identité.

<Steps>
  <Step title="Ouvrir les paramètres d'authentification">
    Ouvrez le sélecteur de workspace, choisissez votre workspace Enterprise et ouvrez **Settings**. Sélectionnez **Avancé**, développez la section **Authentification**, puis cliquez sur **Activer le SSO** dans la carte **SAML single sign-on**.

    L&#39;indicateur de statut passe à **En cours** et l&#39;assistant affiche les valeurs nécessaires à votre IdP.
  </Step>

  <Step title="Choisir votre fournisseur d'identité">
    Sélectionnez votre IdP dans **Configurer votre fournisseur d&#39;identité** :

    * **Microsoft Entra ID**
    * **Google Workspace**
    * **Okta**
    * **Autre fournisseur**

    Chaque option adapte les libellés des champs et fournit un lien direct vers la console d&#39;administration de votre IdP, afin que vous puissiez créer l&#39;application SAML dans un nouvel onglet.
  </Step>

  <Step title="Créer l'application SAML dans votre IdP">
    Dans la console d&#39;administration de votre IdP, créez une application SAML à partir des valeurs affichées par Replit :

    | Champ                                      | Valeur                                                                                                                           |
    | ------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------- |
    | URI de l&#39;audience / ID d&#39;entité SP | Copiez la valeur affichée dans l&#39;assistant (propre à votre organisation, au format `https://replit.com/<tenant-id>/saml/sp`) |
    | URL SSO (URL ACS)                          | `https://replit.com/__/auth/handler`                                                                                             |
    | Format de l&#39;ID de nom                  | Adresse e-mail                                                                                                                   |
    | Nom d&#39;utilisateur de l&#39;application | E-mail                                                                                                                           |
  </Step>

  <Step title="Saisir les valeurs de votre IdP">
    Une fois l&#39;application SAML créée dans votre IdP, reportez les valeurs suivantes dans la section **Saisir les valeurs de votre fournisseur** sur Replit :

    * **URL SSO de l&#39;IdP** — l&#39;URL vers laquelle Replit redirige les utilisateurs lors de l&#39;authentification.
    * **ID d&#39;entité de l&#39;IdP** — identifie votre IdP auprès de Replit.
    * **Certificat X.509** — le certificat de signature de l&#39;IdP au format PEM ou base64. Les marqueurs `BEGIN/END` sont facultatifs.
    * **Domaines de messagerie** — liste, séparée par des virgules, des domaines avec lesquels vos utilisateurs se connectent (par exemple, `acme.com, acme.co.uk`). Incluez tous les alias et sous-domaines que votre IdP est susceptible de renvoyer.

    Cliquez sur **Envoyer les identifiants**. Replit valide l&#39;URL de façon synchrone, analyse le certificat (en rejetant les certificats expirés ou pas encore valides) et vérifie les domaines de messagerie déclarés. Chaque domaine doit correspondre à l&#39;e-mail d&#39;au moins un administrateur de facturation de votre organisation, et les domaines publics (comme `gmail.com`) ne peuvent pas être déclarés.
  </Step>

  <Step title="Attendre le provisionnement">
    L&#39;indicateur de statut passe à **Provisionnement…** pendant que Replit crée le tenant SAML sous-jacent. Cette opération prend généralement une minute environ. Une fois terminée, l&#39;indicateur de statut devient **Actif** et votre organisation peut se connecter via le SSO.

    Si le provisionnement échoue, l&#39;indicateur de statut devient **Échec de la configuration** et Replit efface automatiquement tout état partiel. Cliquez sur **Réessayer** pour relancer l&#39;assistant.
  </Step>
</Steps>

<div id="escolha-seus-domnios-de-e-mail">
  ## Choisissez vos domaines de messagerie
</div>

Vous pouvez déclarer plusieurs domaines et sous-domaines de messagerie pour votre organisation. Tout utilisateur qui tente de s’inscrire avec un domaine de messagerie correspondant à l’un de vos domaines déclarés devra utiliser le SSO SAML. Vos domaines déclarés doivent correspondre à ceux indiqués par votre IdP pour vos utilisateurs. Si vous utilisez des alias de domaines de messagerie, incluez-les également afin d’empêcher les utilisateurs de s’inscrire sans utiliser le SSO.

Par exemple, si votre entreprise utilise les domaines de messagerie `acmeco.com`, `foo.acmeco.com` et `acmebiz.com`, déclarez-les tous les trois lors de l’envoi de l’identifiant.

Replit valide chaque domaine déclaré à partir des adresses e-mail de vos administrateurs. Pour ajouter ou supprimer des domaines après l’activation, modifiez le champ **Domaines de messagerie** dans la carte **Authentification**. Pour déclarer un domaine qui ne correspond pas à l’adresse e-mail d’un administrateur existant, contactez [support@replit.com](mailto:support@replit.com).

<div id="usando-saml-sso">
  ## Utiliser le SSO SAML
</div>

<Note>
  L&#39;inscription via SAML n&#39;ajoute pas automatiquement les utilisateurs à votre organisation. Pour une gestion automatisée des utilisateurs et des opérations en masse, consultez [SCIM](/fr/pt/teams/identity-and-access-management/scim).
</Note>

Une fois le SSO SAML **actif**, vos utilisateurs peuvent se connecter sur [replit.com](https://replit.com) à l&#39;aide du bouton **Continuer avec SSO**.

<div id="perguntas-frequentes">
  ## Questions fréquentes
</div>

<div id="o-que-acontece-com-usurios-que-j-tm-contas-no-replitcom-antes-do-saml-sso-ser-configurado">
  ### Qu&#39;advient-il des utilisateurs qui possèdent déjà un compte sur replit.com avant la configuration du SSO SAML ?
</div>

Une fois le SSO SAML activé pour votre organisation, tous les utilisateurs dont le domaine de messagerie est déclaré pour le SSO devront se connecter via SSO. Les utilisateurs existants ne pourront plus utiliser leurs anciennes méthodes d&#39;authentification (e-mail ou connexion via un réseau social) si leur adresse e-mail correspond au domaine SSO. Ils ne sont pas ajoutés automatiquement à votre organisation.

<div id="os-usurios-so-automaticamente-desprovisionados-no-replit-quando-meu-idp-remove-o-acesso">
  ### Les utilisateurs sont-ils automatiquement déprovisionnés dans Replit lorsque mon IdP révoque leur accès ?
</div>

Non, le SSO SAML gère uniquement l&#39;authentification. Pour automatiser le provisionnement et le déprovisionnement des utilisateurs, vous pouvez utiliser l&#39;intégration [SCIM](/fr/pt/teams/identity-and-access-management/scim), disponible pour les clients Enterprise. SCIM permet de synchroniser l&#39;annuaire de votre IdP afin de gérer automatiquement les rôles et le provisionnement des utilisateurs.

<div id="os-assentos-da-organizao-so-automaticamente-consumidos-quando-os-usurios-recebem-acesso-no-nosso-idp">
  ### Les sièges de l’Organisation sont-ils automatiquement consommés lorsque des utilisateurs obtiennent un accès via notre IdP ?
</div>

Non, les sièges ne sont consommés que lorsqu’un utilisateur accepte l’invitation à votre Organisation.

<div id="o-que-acontece-se-a-configurao-do-saml-falhar">
  ### Que se passe-t-il si la configuration SAML échoue ?
</div>

L&#39;assistant signale l&#39;échec par un indicateur **Échec de la configuration**, et Replit annule automatiquement tout provisionnement partiel. Cliquez sur **Réessayer** pour relancer l&#39;assistant, vérifiez les valeurs de votre IdP et soumettez à nouveau les identifiants. Si l&#39;erreur persiste, contactez votre gestionnaire de compte.

<div id="como-desabilito-o-saml-sso">
  ### Comment désactiver le SSO SAML ?
</div>

La désactivation en libre-service n’est pas encore prise en charge. Contactez votre responsable de compte pour désactiver le SSO de votre organisation. Après l’activation, vous pouvez toujours modifier les domaines de messagerie revendiqués dans la section **Authentification**.
