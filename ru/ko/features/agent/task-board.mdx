Задачи распределяются по столбцам в зависимости от статуса. Доска показывает, что запланировал Agent, что выполняется, что готово к проверке и что уже применено.

По мере работы над задачами они перемещаются слева направо:

* **Drafts**: задачи, запланированные Agent, но ещё не начатые
* **Активные**: задачи, над которыми Agent сейчас работает, включая задачи, ожидающие из-за ограничения на количество активных задач
* **Ready**: задачи, завершённые Agent и ожидающие проверки
* **Done**: завершённые, заархивированные или отменённые задачи

<div id="drafts">
  ## Drafts
</div>

**Drafts** — это задачи, которые Agent запланировал, но ещё не начал выполнять. Каждый черновик содержит заголовок, описание и пошаговый план.

Используйте Drafts, чтобы ознакомиться с предложенным Agent подходом до начала работы. Вы можете изучить план, попросить Agent внести изменения или начать работу, когда будете готовы.

Drafts полезны, если вы хотите спланировать более крупную функцию перед подтверждением фоновых задач. Например, Agent может разделить проект онбординга на отдельные черновики для аутентификации, настройки профиля, интерфейса панели управления и завершающих задач деплоя.

<div id="active">
  ## Активные
</div>

После утверждения задача перемещается в столбец **Активные**, и Agent приступает к сборке. Каждая задача выполняется в независимой копии проекта, поэтому основная версия не затрагивается, пока вы не примените изменения.

Некоторые задачи зависят от других. Например, задача по созданию панели управления может требовать предварительного завершения работы над схемой базы данных. Зависимые задачи остаются в статусе **Queued**, пока не будут выполнены необходимые условия. Задачи также попадают в очередь при достижении лимита активных фоновых задач вашего тарифа.

<div id="ready">
  ## Ready
</div>

Когда задача завершает сборку, она переходит в статус **Ready**. Это означает, что задача выполнена, но основная версия ещё не изменилась.

Применить изменения можно двумя способами:

* **В ветке**: откройте ветку задачи и выберите **Применить изменения к основной версии**, чтобы внести изменения в проект, или **Удалить**, чтобы отменить их
* **На доске**: откройте меню с тремя точками на карточке задачи в статусе Ready и выберите **Применить изменения**

<div id="section">
  ## Поиск и фильтрация задач
</div>

Используйте Task board, если в проекте много текущих задач. Ищите задачи по названию или номеру, фильтруйте черновики и используйте режим редактирования, чтобы управлять несколькими задачами одновременно.

Например, ищите задачу по номеру, если кто-то упоминает её в ветке, обзоре или беседе в Slack. Фильтруйте черновики, если хотите сосредоточиться только на запланированных задачах, не просматривая активные или завершённые.

Подробнее о предлагаемых дальнейших задачах см. в разделе [Follow-up tasks](/ru/ko/features/agent/follow-up-tasks).

<div id="section-2">
  ## Переименование задачи
</div>

По мере изменения объёма работ в списке давно выполняемых задач может быть сложно быстро сориентироваться. Чтобы переименовать задачу, откройте меню с тремя точками на карточке (на боковой панели списка задач или в Task board) и выберите **Переименовать**. Введите более понятное название и выберите **Сохранить**.

Переименование задачи меняет только то, как она отображается для вас и участников команды. Работа, уже выполненная Agent, история задачи и ожидающие изменения останутся без изменений.

<div id="section-3">
  ## Настройки каждой задачи
</div>

У каждой задачи рядом с заголовком есть собственное выпадающее меню настроек. Откройте его, чтобы выбрать, как Agent завершает задачу и как результат применяется к проекту:

* **Автоматически применять изменения** (Drafts и Активные): когда задача будет готова, изменения сразу применятся к основной версии без проверки.
* **Автоматически утверждать план** (Drafts): когда Agent предложит план для задачи, он будет автоматически утверждён, и начнётся сборка.
* **Применить изменения** (Ready): применяет результат завершённой задачи к основной версии.
* **Переименовать**: изменяет заголовок на карточке.
* **Проверить изменения** (Ready): сразу открывает diff готовой задачи.
* **Отменить**: останавливает задачу или удаляет черновик.

Автоматическое применение и автоматическое утверждение — это быстрые одноразовые действия, а не переключатели, которые остаются включёнными. Меню сохраняет фиксированную ширину, чтобы названия пунктов не смещались, даже если открыто несколько задач.
