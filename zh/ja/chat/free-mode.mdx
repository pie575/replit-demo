在免费模式下，你无需消耗强力模式或 Max Mode 的积分，即可进行 Chat、创作和构建。

<Note>
  免费模式始终使用智能模型路由，由 Replit 根据请求自动选择模型。在免费模式下无法指定特定模型。
</Note>

Routine 不会在免费模式下运行，而是在强力模式或 Max Mode 下运行，且每次运行都需要预算。详情请参阅 [Routine](/zh/ja/chat/routines)。

<div id="section">
  ## 更充分地利用免费额度
</div>

免费模式非常适合让手头的工作保持推进，你可以在以下场景中使用：

* 在着手更大规模的构建之前，探索并验证想法。
* 启动新项目、快速试做某个功能，或处理小的改动。
* 提出问题、制定计划，并通过后续消息不断完善工作成果。
* 在额度可用期间，无需消耗积分即可继续日常工作。

开始时，请打开提示框下方的模式选择器，确认模式已设置为 **Free**，然后向 Replit 提出重点明确的请求：说清你想要的结果，提供关键上下文，并通过追问来改进结果。

<div id="section-2">
  ## 了解何时该切换到其他模式
</div>

免费模式的上限因套餐而异。打开 **设置** → **使用情况**，即可查看当前上限和重置时间。

<Frame caption="使用情况页面会显示剩余的免费用量及其刷新时间。">
  <img src="/assets/mirror/free-mode-usage-sanitized-1b738ae092bb.jpg" alt="显示免费用量面板的设置使用情况页面" width="1538" height="1022" data-path="images/chat/free-mode-usage-sanitized.jpg" />
</Frame>

在 Core 和 Pro 套餐中，当你需要更强的能力、想指定特定模型，或免费模式额度已用完时，可切换到 **强力模式** 或 **Max Mode**。这些模式会消耗每月积分。使用 Starter 套餐的开发者需先升级，才能使用强力模式或 Max Mode。

<Tip>
  如果你的套餐包含强力模式和 Max Mode，建议先用免费模式完成初始步骤，仅在任务确实需要更强能力时再切换。在你的请求切换到会产生费用的模式之前，Replit 会提前告知。
</Tip>

<div id="section-3">
  ## 选择适合任务的模式
</div>

| 你想要...          | 使用的模式 |
| --------------- | ----- |
| 探索、提问、规划或着手构建   | 自由模式  |
| 兼顾速度与能力，适合大多数任务 | 强力模式  |
| 处理复杂或雄心勃勃的任务    | Max Mode  |

强力模式以相同的成本取代经济模式，性能不逊反优。在 Core 和 Pro 套餐中，你可以选择强力模式或 Max Mode 下可用的模型。
