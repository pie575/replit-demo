description: "Apprenez à Agent les règles de votre équipe grâce à des instructions personnalisées et à des compétences à l’échelle de l’espace de travail, puis gérez-les de manière centralisée dans les paramètres du Workspace."
---

La personnalisation d’Agent fournit à Agent, dès le premier prompt, le contexte nécessaire pour travailler selon votre style et celui de votre équipe. Au lieu de réexpliquer les règles dans chaque projet, définissez-les une seule fois dans votre espace de travail, et Agent les appliquera partout.

Deux fonctionnalités sont disponibles :

* **Instructions personnalisées** : des directives toujours actives qui s’appliquent à tous les projets de l’espace de travail.
* **Compétences** : des instructions réutilisables qu’Agent charge uniquement lorsqu’une tâche pertinente se présente.

Les deux se gèrent dans **Paramètres du Workspace → Personnalisation**.

<div id="section">
  ## Différence entre les instructions personnalisées et les compétences
</div>

Les instructions personnalisées sont chargées pour chaque message. Les compétences ne sont chargées que lorsqu’Agent les considère comme pertinentes pour la tâche. Utilisez des instructions personnalisées pour les directives qui s’appliquent en permanence, et des compétences pour des flux de travail, des règles et des documents de référence spécifiques.

Pour en savoir plus sur cette distinction — le budget de contexte, où placer les différents éléments et comment créer efficacement des compétences — consultez [Compétences Agent](/fr/ja/learn/agent-skills). Pour en savoir plus sur la structure des compétences et la façon dont Agent les charge, consultez [Compétences Agent](/fr/ja/features/agent/skills).

<div id="section-2">
  ## Instructions personnalisées
</div>

Les instructions personnalisées sont des directives permanentes injectées dans le contexte d’Agent pour tous les projets et toutes les sessions, avant qu’un utilisateur ne saisisse un prompt. Définissez-les une seule fois dans les paramètres du Workspace, et Agent les appliquera dans tout l’espace de travail. Elles conviennent parfaitement aux règles qui doivent toujours être respectées, telles que les exigences de sécurité et de conformité, les bibliothèques et frameworks approuvés, ou les politiques de traitement des données.

Restez concis. Les instructions précises et ciblées ont davantage de chances d’être suivies fidèlement et laissent plus de place à Agent pour effectuer son travail.

<Warning>
  Les instructions personnalisées peuvent affecter les performances d’Agent. Agent est incité à les suivre, mais le respect d’exigences strictes n’est pas garanti. Les directives courtes et précises sont suivies de manière plus fiable.
</Warning>

<Note>
  Les instructions personnalisées de l’espace de travail sont distinctes du fichier `custom_instruction/instructions.md` d’un projet. Elles sont configurées une seule fois dans les paramètres du Workspace et s’appliquent à tous les projets. Les fichiers propres à chaque projet ne s’appliquent qu’à un seul projet — consultez [Créer un système de design personnalisé](/fr/ja/teams/custom-design-system) pour en savoir plus sur ce modèle.
</Note>

<div id="section-3">
  ## Compétences
</div>

Les compétences sont des ensembles d’instructions réutilisables qu’Agent charge uniquement lorsqu’une tâche pertinente se présente. Les compétences de l’espace de travail apparaissent en tête du menu **+** de tous les projets de l’espace de travail, afin que toute l’équipe partage le même ensemble.

Vous pouvez créer des compétences de trois façons :

* **Téléverser** — Téléversez un dossier de compétences existant.
* **Créer** — Rédigez directement une nouvelle compétence dans le formulaire.
* **Demander à Agent** — Demandez à Agent de créer une ébauche de compétence, puis améliorez-la.

<Note>
  Vous pouvez demander à Agent de téléverser des compétences dans le Workspace. Demandez à Agent de télécharger la compétence. Agent la regroupera dans une archive `.zip` téléchargeable et un bouton **Download file** s’affichera (voir ci-dessous). Téléchargez l’archive zip, puis téléversez-la depuis **paramètres du Workspace → personnalisation → compétence**, via **Create skill → Choose file or folder**, afin de la partager dans tout l’espace de travail.
</Note>

<Frame>
  <img src="/assets/mirror/agent-customization-download-skill-3727b188c5a8.png" alt="Agent regroupe une compétence d’espace de travail dans une archive ux-designer-skill.zip téléchargeable, avec le bouton Download file affiché" width="1716" height="864" data-path="images/replitai/agent-customization-download-skill.png" />
</Frame>

Pour connaître la structure complète d’une compétence (`SKILL.md`, fichiers auxiliaires et standard ouvert), consultez [Compétences Agent](/fr/ja/features/agent/skills). Pour parcourir les compétences déjà créées par Replit et ses partenaires, consultez le [répertoire des compétences](/fr/ja/features/agent/skills-directory).

<Note>
  Utilisez les compétences avec parcimonie. Agent lit le nom et la description de chaque compétence pour chaque tâche. Un trop grand nombre de compétences ou des compétences redondantes peuvent disperser son attention et l’empêcher de choisir la compétence appropriée. Délimitez clairement le champ de chaque compétence et supprimez celles qui ne sont plus nécessaires.
</Note>

<div id="section-4">
  ## Forfaits et autorisations disponibles
</div>

| Fonctionnalité              | Forfaits disponibles      | Utilisateurs autorisés à gérer                                                          |
| --------------------------- | ------------------------- | --------------------------------------------------------------------------------------- |
| Instructions personnalisées | Pro et Enterprise         | Enterprise : administrateurs. Pro : tous les membres de l&#39;espace de travail         |
| Compétences                 | Tous les forfaits payants | Enterprise : administrateurs. Core et Pro : tous les membres de l&#39;espace de travail |

Dans les espaces de travail Enterprise, seuls les administrateurs peuvent créer, modifier et supprimer des instructions personnalisées et des compétences. Dans les espaces de travail Pro, tous les membres de l&#39;espace de travail peuvent le faire. Dans les espaces de travail Core, tous les membres peuvent gérer les compétences ; les instructions personnalisées ne sont pas disponibles dans Core. Dans tous les cas, tous les membres de l&#39;espace de travail peuvent utiliser les compétences créées.

<div id="section-5">
  ## Créer des instructions personnalisées
</div>

<Steps>
  <Step title="Ouvrir les paramètres du Workspace">
    Accédez à **paramètres du Workspace → personnalisation**.

    <Frame>
      <img src="/assets/mirror/agent-customization-tab-930af2e8ed74.png" alt="Onglet Personnalisation des paramètres du Workspace, affichant les sous-onglets compétence et Instructions personnalisées" width="1065" height="394" data-path="images/replitai/agent-customization-tab.png" />
    </Frame>
  </Step>

  <Step title="Rédiger des instructions">
    Dans la section **instructions personnalisées**, rédigez les consignes que vous souhaitez qu’Agent applique à tous les projets.
  </Step>

  <Step title="Enregistrer">
    Enregistrez vos modifications. Les instructions s’appliquent aux nouveaux projets de l’espace de travail.
  </Step>
</Steps>

<div id="section-6">
  ## Créer une compétence
</div>

<Steps>
  <Step title="Ouvrir les paramètres du Workspace">
    Accédez à **paramètres du Workspace → personnalisation**.
  </Step>

  <Step title="Créer une compétence">
    Dans la section **compétence**, cliquez sur **Create skill**, puis importez un dossier de compétences, rédigez des instructions ou demandez à Agent d’en créer un brouillon.

    <Frame>
      <img src="/assets/mirror/agent-customization-create-skill-fcb794e6de4e.png" alt="Onglet personnalisation des paramètres du Workspace, sous-onglets compétence et instructions personnalisées, formulaire de création de compétence ouvert" width="2168" height="1350" data-path="images/replitai/agent-customization-create-skill.png" />
    </Frame>
  </Step>

  <Step title="Rédiger une description claire">
    Ajoutez à la compétence une description indiquant clairement quand l’utiliser — et quand ne pas l’utiliser. C’est ce que lit Agent pour décider s’il doit appliquer la compétence.
  </Step>

  <Step title="Enregistrer">
    Enregistrez la compétence. Elle sera disponible dans le menu **+** de tous les projets de l’espace de travail.
  </Step>
</Steps>

<div id="section-7">
  ## Utiliser les compétences de l’espace de travail dans un projet
</div>

Il est important que les descriptions des compétences soient claires. Agent lit les descriptions de toutes les compétences de l’espace de travail et les utilise automatiquement si le prompt correspond globalement à leur objectif. Vous n’aurez donc peut-être pas besoin de sélectionner vous-même une compétence. Vous pouvez également sélectionner explicitement une compétence pour vous assurer qu’elle est utilisée.

Pour sélectionner une compétence manuellement :

<Steps>
  <Step title="Ouvrir le sélecteur de compétences">
    Dans votre projet, cliquez sur le bouton **+** à côté du champ de saisie du chat. Les compétences de l’espace de travail sont regroupées et affichées en premier.

    <Frame>
      <img src="/assets/mirror/agent-customization-skill-picker-4643f3a453c7.png" alt="Sélecteur de compétences ouvert depuis le bouton +, avec le groupe Workspace skills affiché au-dessus de Replit skills" width="1668" height="1170" data-path="images/replitai/agent-customization-skill-picker.png" />
    </Frame>
  </Step>

  <Step title="Sélectionner une compétence">
    Sélectionnez la compétence à utiliser. Vous pouvez également l’appeler directement en saisissant son nom après `/`.
  </Step>

  <Step title="Continuer avec le prompt">
    Continuez comme d’habitude. Si la tâche correspond à la description de la compétence, Agent l’utilisera.
  </Step>
</Steps>

<div id="section-8">
  ## Gérer les instructions et les compétences
</div>

Tout se gère dans **paramètres du Workspace → personnalisation**. Vous pouvez y modifier les instructions personnalisées, ainsi que modifier, désactiver ou supprimer des compétences. Les modifications s’appliquent aux futurs chats, mais pas aux chats en cours.
