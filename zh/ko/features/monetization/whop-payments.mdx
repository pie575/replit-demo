借助 Whop 集成，Agent 无需任何外部配置或 API 密钥，只需一次对话就能为你的应用添加支付功能。Agent 会创建 Whop 账户、接入支付并构建支付逻辑。如果你想尽快完成第一笔销售，Whop 是最合适的选择。

<div id="section">
  ## 你可以构建什么
</div>

* 面向数字内容的付费墙和“解锁”流程
* 会员资格与社区访问权限
* 订阅与周期性套餐
* 一次性数字产品销售

<div id="section-2">
  ## 工作原理
</div>

当你要求添加支付功能时，Agent 会在后台完成 Whop 的设置：为你的应用创建 Whop 账户、完成连接，并在项目中构建支付流程。你无需粘贴任何凭证，也无需离开 Replit 就能开始。

Whop 是 Replit 支持的多个支付服务商之一。Agent 会帮你根据要构建的内容挑选合适的服务商：

|             | Whop          | Stripe         | Shopify     | RevenueCat                 |
| ----------- | :------------ | :------------- | :---------- | :------------------------- |
| **最适合**     | 步骤最少，最快完成首笔销售 | 灵活性与可扩展性       | 实物商品        | 原生移动应用                     |
| **销售内容**    | 数字产品、会员资格、订阅    | 一次性付款、订阅、店面    | 含库存与配送的实物商品 | 应用内订阅                      |
| **外部设置**    | 起步时无需         | 起步时无需          | 起步时无需       | 起步时无需                      |
| **切换到正式环境** | 身份验证 (KYC)    | 连接正式 Stripe 账户 | 店铺账单        | App Store 或 Google Play 审核 |

如果你没有指定服务商，Agent 会根据你的描述给出推荐，并说明各方案的利弊。

<div id="section-3">
  ## 快速开始
</div>

* **请求 Agent 添加支付功能**
  * 在主页使用斜杠命令，或直接发送以下请求：
    <AiPrompt>添加 Whop 支付功能，以便在我的应用中销售会员资格</AiPrompt>

<Note>
  Whop 集成需要应用具备后端功能。要开始使用，请在主页选择**应用**。
</Note>

<div id="section-4">
  ## 测试支付
</div>

1. 在新标签页中打开应用的**预览**。
2. 完整走一遍你构建的支付或解锁流程。
3. 在分享应用之前，从头到尾体验一遍买家的购买流程。

<div id="section-5">
  ## 产品和定价管理
</div>

你可以通过以下两种方式管理服务：

* **向 Agent 提出请求**：说明需要作出的更改 (如新增套餐、调整价格或添加产品) ，Agent 会更新你的应用和 Whop 配置。
* **使用 Whop 控制面板**：使用 Replit 账户邮箱登录 [Whop](https://whop.com)，即可直接管理产品、价格和套餐。

<div id="section-6">
  ## 查看余额并提现收益
</div>

销售收益会累积至您的 Whop 账户。若要提现收益，请在 Whop 控制面板中完成 Whop 身份验证 (KYC)。您可以在完成验证前开始销售，但必须先完成身份验证才能提现。

<Note>
  Whop 负责付款、支付处理、身份验证 (KYC) 和打款。Replit 不会收集您的银行或税务信息。
</Note>

<div id="section-7">
  ## 管理集成
</div>

* 前往 **集成 &gt; Whop**，打开 Whop 连接器。
* 您可以在此查看连接状态并管理设置。

<div id="section-8">
  ## 常见问题
</div>

<div id="whop">
  ### 开始之前需要有 Whop 账户吗？
</div>

不需要。Agent 会在设置过程中为你的应用创建 Whop 账户。之后你可以使用 Replit 账户邮箱登录 Whop 控制面板，管理产品并提现收益。

<div id="section-9">
  ### 何时需要进行身份验证？
</div>

您可以立即构建并开始销售。Whop 会在您提现前要求进行身份验证 (KYC)，您可在 Whop 控制面板中完成验证。

<div id="section-10">
  ### 如何更改产品或价格？
</div>

请 Agent 进行更改，或直接在 [Whop 控制面板](https://whop.com) 中编辑产品和套餐。

<div id="section-11">
  ### 应该使用哪种支付服务商？
</div>

Whop 是无需任何外部配置即可销售数字产品和会员资格的最快方式。如果希望在 Web 应用中获得最大灵活性，请选择 [Stripe](/zh/ko/features/monetization/stripe-payments)；销售实物商品可选择 [Shopify](/zh/ko/features/integrations/shopify)；原生移动端订阅则可选择 [RevenueCat](/zh/ko/features/monetization/revenuecat-subscriptions)。详细对比请参阅[变现概览](/zh/ko/features/monetization/overview)。
