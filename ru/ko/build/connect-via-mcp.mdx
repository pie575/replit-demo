Replit Agent может подключаться к сотням внешних инструментов и источников данных через [Model Context Protocol (MCP)](https://modelcontextprotocol.io) — открытый стандарт интеграции ИИ-инструментов. Войдите на один из предустановленных серверов или добавьте пользовательский MCP-сервер, которому доверяете.

<div id="mcp">
  ## Подключение предустановленных MCP-серверов
</div>

Replit предоставляет подобранный список MCP-серверов для популярных сервисов: Stripe, Linear, Notion, Sentry и других. Для подключения достаточно одного клика по кнопке входа.

<Frame>
  <img src="/assets/mirror/mcp-servers-pane-8e1f431ca33c.png" alt="Панель настройки MCP-серверов для Replit Agent со списком предустановленных серверов — Stripe, Linear, Notion, Sentry, Atlassian, Miro, PostHog, Amplitude, Mixpanel, Granola, Razorpay — и кнопкой входа для каждого из них" width="3452" height="1988" data-path="images/replitai/mcp-servers-pane.png" />
</Frame>

<Steps>
  <Step title="Откройте панель Integrations">
    Перейдите на [replit.com/integrations](https://replit.com/integrations) и прокрутите до раздела **MCP Servers for Replit Agent**.
  </Step>

  <Step title="Выберите сервер">
    Найдите нужный сервис — доступны Stripe, Linear, Notion, Sentry, Atlassian, Miro, PostHog, Amplitude, Mixpanel, Granola, Razorpay и другие.
  </Step>

  <Step title="Войдите в систему">
    Нажмите **Sign in** рядом с сервером. Вы пройдёте OAuth-процесс соответствующего сервиса. После подключения статус сервера обновится, и Agent сможет использовать его инструменты.
  </Step>
</Steps>

Полный каталог см. в [справочнике по MCP-серверам](/ru/ko/features/mcp/overview).

<div id="mcp-2">
  ## Добавление пользовательского MCP-сервера
</div>

Если нужного сервера нет в предустановленном каталоге, добавьте его по URL.

<Frame>
  <img src="/assets/mirror/mcp-connect-dialog-5b8f9b0d828e.png" alt="Диалог подключения MCP-сервера с полем отображаемого имени, полем URL MCP-сервера и раскрывающимся разделом расширенных настроек" width="3452" height="1988" data-path="images/replitai/mcp-connect-dialog.png" />
</Frame>

<Steps>
  <Step title="Откройте диалог добавления сервера">
    На панели настроек MCP-серверов нажмите **+ Add MCP server**.
  </Step>

  <Step title="Задайте отображаемое имя">
    Введите понятное имя — Agent будет использовать его при упоминании сервера в журнале чата.
  </Step>

  <Step title="Укажите URL сервера">
    Вставьте HTTPS-адрес MCP-сервера. Если сервер требует аутентификации, откройте **Advanced settings** и добавьте собственные заголовки (например, `X-API-Key`).
  </Step>

  <Step title="Проверьте и сохраните">
    Нажмите **Test &amp; save**. Replit попытается установить соединение и проведёт вас через OAuth-процесс, если сервер его требует. После сохранения подключение появится в списке MCP-серверов вместе с его статусом.
  </Step>
</Steps>

<Warning>
  Подключайтесь только к тем MCP-серверам, которым доверяете. Подключённые серверы могут предоставлять Agent инструменты и данные — проверьте источник, прежде чем добавлять незнакомый адрес.
</Warning>

<div id="agent-mcp">
  ## Использование инструментов MCP в Agent
</div>

После подключения сервера Agent автоматически получает список его инструментов и делает их доступными во всех проектах. Чтобы воспользоваться сервером, достаточно упомянуть его в чате:

> Use the Notion MCP server to find the most recent meeting notes.

<Frame>
  <img src="/assets/mirror/tool-call-7a53f51a11ae.png" alt="Agent вызывает инструмент пользовательского MCP-сервера в чате" width="571" height="817" data-path="images/replitai/custom-mcp/tool-call.png" />
</Frame>

Agent сам выбирает на сервере инструмент, подходящий для вашего запроса. Если инструмент требует подтверждения, перед выполнением вы увидите соответствующий запрос.
