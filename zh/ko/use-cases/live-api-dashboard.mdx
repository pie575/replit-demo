利用 API 的关键指标、图表和筛选器创建实时仪表板。它会自动刷新，
支持导出，并且仅显示实际存在的数据。需要长期保留的数据，请存储在
Replit Database 中。

<div id="section">
  ## 适合以下场景
</div>

* 产品经理需要的是可供他人审阅的仪表板，而不只是截图。
* 运营和数据负责人需要基于 API、始终保持最新状态的私有仪表板。

<div id="section-2">
  ## 开始之前
</div>

提前明确仪表板需要支持哪些决策。准备好 API URL，或使用以下 DummyJSON 端点。

<Info>
  您可以使用以下免费的 DummyJSON API 端点进行测试。

  * 订单：`https://dummyjson.com/carts?limit=0`
  * 客户：`https://dummyjson.com/users?limit=0`
  * 产品目录：`https://dummyjson.com/products?limit=0`
  * 类别：`https://dummyjson.com/products/categories`
</Info>

<div id="agent">
  ## 向 Agent 提出请求
</div>

<AiPrompt>
  请基于此 API [URL] 创建一个实时仪表板，展示可用于回答 [决策] 的
  关键指标、图表和筛选器。支持自动刷新和导出功能。将需要持久化的数据
  存储在 Replit Database 中。仅展示数据中实际存在的内容。
</AiPrompt>

<div id="section-3">
  ## 预期结果
</div>

Agent 会加载数据、选择汇总指标和图表，并添加筛选器。至少将一个
数字与原始数据源进行核对验证。如果使用了 DummyJSON，请选择一个订单并
打开 `https://dummyjson.com/carts/{id}`，确认总额是否一致。切换筛选器，
确认所有卡片和图表都会更新。执行一次导出，并将 API 与其中一行数据进行核对。

<div id="section-4">
  ## 按需调整
</div>

<AiPrompt>
  请添加一个类别筛选器，重新计算页面上的所有数字。
</AiPrompt>

<AiPrompt>请缓存 API 响应，确保仪表板快速加载。</AiPrompt>

<div id="section-5">
  ## 故障排除
</div>

* **API 无法使用或格式看起来不对：**检查 URL，并确认响应中包含预期字段。要快速测试，可使用上方的 DummyJSON 端点。
* **数字显示与预期不符：**让 Agent 显示查询或转换过程，然后至少将一个数字与原始数据源进行核对验证。
* **筛选器未更新图表：**让 Agent 将每个筛选器同时关联到汇总卡片和图表数据。如果仪表板运行缓慢，请缓存 API 响应，或减少启动时加载的记录数量。
