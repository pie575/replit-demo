项目分析可帮助您了解用户如何发现和使用已发布的 Web 应用。打开 **Growth** 窗格，查看访客趋势、流量来源和自定义事件。

Replit 会收集对应已发布应用的默认流量指标。付费套餐中，Agent 可以添加自定义事件并解答有关分析的问题。

<div id="section">
  ## 开始前
</div>

项目分析需要满足以下条件：

* **已发布的网站。** Analytics 支持网站[产物](/zh/ja/features/projects-and-artifacts/artifacts)，不会收集移动应用或其他类型产物的事件。
* **受支持的部署。** 项目分析支持 [Autoscale](/zh/ja/features/publishing/deployment-types#autoscale)、[Reserved VM](/zh/ja/features/publishing/deployment-types#reserved-vm) 和 [Static](/zh/ja/features/publishing/deployment-types#static) 部署。
* **高级分析需要付费套餐。** 自定义事件和 Agent 分析查询仅适用于付费套餐。
* **在下次发布时启用分析。** 开启 **Enable analytics** 后发布或重新发布应用，Replit 将开始收集事件。

<div id="project-analytics">
  ## 打开项目分析
</div>

1. 在 Project Editor 中打开项目。
2. 选择 **Tools**。
3. 在 **Replit Cloud** 下选择 **Growth**。

<Note>
  在应用发布之前，**Growth** 窗格处于锁定状态。发布前，会显示引导你前往 **Go
  to Publishing** 的消息。
</Note>

已发布应用开始获得流量后，便会显示分析数据。新应用的图表可能会一直为空，直到有人访问。

<div id="section-2">
  ## 查看默认分析
</div>

默认分析使用 IP 流量数据展示以下指标：

* **访客**：所选时间段内独立访客的大致数量。
* **一段时间内的访客数 (按小时)&#x20;**&#x20;或 **一段时间内的访客数 (按天)&#x20;**：所选时间段内访客活动的变化情况。
* **热门页面**：流量最高的页面。
* **主要引荐来源**：为应用带来流量的网站。
* **主要国家/地区**：访客所在国家/地区的大致分布。
* **主要浏览器**：用户使用的浏览器。
* **主要设备**：用户使用的设备类型。

使用时间范围菜单可查看 6 小时至 30 天的时间段。访客总数会将每个时间段与此前相同长度的时间段进行比较。

如果应用使用 [Replit Auth](/zh/ja/features/auth-and-identity/authentication)，窗格还会显示所选时间段内的 **独立登录用户数**。

<Note>
  访客数量为估算值。该数据基于网络和浏览器信息，
  同一人跨设备或跨日历月访问时，可能会被计为多个访客。
</Note>

<div id="agent">
  ## 使用 Agent 添加自定义事件
</div>

自定义事件用于衡量应用中的重要操作，例如完成注册、选择套餐、提交表单或完成购买。

<Steps>
  <Step title="使用 Agent 添加指标">
    打开 **Growth**。在 **高级分析** 中选择 **使用 Agent 添加指标**。告诉 Agent 你要衡量哪些操作。Agent 会在应用中的相应位置添加事件跟踪。
  </Step>

  <Step title="启用分析并发布">
    打开 **Publishing**，开始新的发布或重新发布。在 **Suggested
    add-ons** 下启用 **Enable analytics**。然后发布应用。Replit 将从此次发布开始收集页面浏览量和自定义事件。
  </Step>
</Steps>

<Tip>
  你也可以直接在聊天中让 Agent 设置分析。应用或衡量目标发生变化时，随时可以让 Agent 添加或更新事件。
</Tip>

Replit 会将分析跟踪器添加到已发布应用。你无需自行添加跟踪脚本、网站 ID 或分析所需的环境变量。

<Warning>
  请勿在自定义事件名称或属性中包含 Secrets、个人信息或访客自由输入的内容。
</Warning>

<div id="agent-2">
  ## 向 Agent 询问分析数据
</div>

当应用开始收集数据后，使用 **高级分析** 选项：

* **汇总我的分析数据**：Agent 会汇总项目过去 7 天的分析数据。
* **建议项目改进方案**：Agent 会查看分析数据，并提出项目改进建议。

你也可以向 Agent 提出具体问题。

<AiPrompt>
  比较过去七天的访客数和完成注册数。显示每日趋势，并找出转化率
  最高的页面。
</AiPrompt>

Agent 可以分析页面浏览量、流量来源、自定义事件、事件属性和漏斗。它会使用项目的分析数据，并返回汇总结果。
