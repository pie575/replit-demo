### Recherche web pour Agent

<Frame>
  <img src="https://mintcdn.com/replit/0UCOQvZyQpUEM03B/images/replitai/web-search.jpg?fit=max&auto=format&n=0UCOQvZyQpUEM03B&q=85&s=2b2afe9380555306e206c62084d996d4" alt="Interface Agent affichant les résultats de Recherche web et les citations de sources pour le développement d'applications" width="1920" height="1080" data-path="images/replitai/web-search.jpg" />

Agent peut désormais rechercher sur le web et récupérer des informations à jour avec la [Recherche web](/fr/core-concepts/agent/web-search). Créez des applications avec la documentation la plus récente, les données de marché actuelles et des informations précises provenant d'internet. Plus de coupures de connaissances — vos applications utilisent désormais les informations les plus récentes disponibles.

### Instructions personnalisées pour Agent

<Frame>
  <img src="https://mintcdn.com/replit/0UCOQvZyQpUEM03B/images/replitai/replitmd.jpg?fit=max&auto=format&n=0UCOQvZyQpUEM03B&q=85&s=63b53f2f18d59701e9b9a08d36663eaa" alt="Fichier replit.md affichant les options de personnalisation du projet" width="1920" height="1080" data-path="images/replitai/replitmd.jpg" />
</Frame>

Personnalisez votre expérience Agent avec [replit.md](/fr/core-concepts/agent/replit-dot-md). Ce fichier spécial vous permet de définir votre style de codage, vos préférences de projet et le contexte. Agent crée automatiquement ce fichier en utilisant les meilleures pratiques éprouvées, et vous pouvez le personnaliser pour correspondre à votre flux de travail.

### Facturation basée sur l'effort

<Frame>
  <img src="https://mintcdn.com/replit/ulqp7CGfE7lmBv7N/images/changelog/2025-07-04/effort-based-billing.png?fit=max&auto=format&n=ulqp7CGfE7lmBv7N&q=85&s=f1d8862fc7d87b2f8554458a45f20f93" alt="Interface de facturation basée sur l'effort affichant une tarification dynamique basée sur l'effort de l'agent" width="2048" height="1424" data-path="images/changelog/2025-07-04/effort-based-billing.png" />

Bénéficiez d'une tarification de points de contrôle plus intelligente avec notre nouvelle [facturation basée sur l'effort](/fr/billing/ai-billing). La tarification dynamique basée sur l'effort réel de l'agent crée des points de contrôle uniques par exécution au lieu de multiples.

## Teams et Enterprise

### Expérience App Store pour les équipes

Découvrez et gérez les applications de votre équipe comme jamais auparavant. La nouvelle expérience « App Store » d'organisation sur la page des Déploiements vous permet de marquer vos favoris, de rechercher parmi tous les déploiements, de voir les applications récemment ouvertes et de découvrir les déploiements populaires en fonction du volume de trafic.
