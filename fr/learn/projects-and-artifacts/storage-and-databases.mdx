Grâce aux solutions de stockage flexibles de Replit, vous pouvez rapidement ajouter le stockage de données adapté aux besoins de votre app. Vous pouvez utiliser la base de données ou le stockage d&#39;objets de Replit pour les apps ayant les exigences suivantes, et Agent peut configurer et intégrer automatiquement les deux solutions :

* Un jeu qui doit enregistrer des informations sur les joueurs, comme leur progression ou leurs meilleurs scores
* Une plateforme de contenu qui gère des fichiers multimédias

<div id="what-are-replits-storage-and-database-options">
  ## Quelles options de stockage et de base de données Replit propose-t-il ?
</div>

Replit propose les options de stockage de données suivantes :

* **Base de données** : stocke des données structurées, telles que des profils utilisateur, des scores de jeu et des catalogues de produits.
  Vous pouvez stocker ou récupérer des données à l’aide d’attributs et de relations entre les données.

* **App Storage** : stocke des données non structurées, telles que des images, des vidéos et des documents.
  Vous pouvez y stocker et récupérer des fichiers volumineux et des données binaires.

<div id="app-storage-and-database-comparison">
  ### Comparaison entre App Storage et une base de données
</div>

|                             | Base de données                                                            | App Storage                                                               |
| --------------------------- | :------------------------------------------------------------------------- | :------------------------------------------------------------------------ |
| **Format de données idéal** | Données structurées avec relations                                         | Fichiers volumineux (images, vidéos, documents)                           |
| **Modèle de données**       | Tables, lignes, colonnes                                                   | Buckets, fichiers                                                         |
| **Langage de requête**      | SQL                                                                        | API REST                                                                  |
| **Clients**                 | Clients et ORM compatibles avec PostgreSQL                                 | SDK Replit et bibliothèques clientes GCS                                  |
| **Modèle de facturation**   | Paiement à l&#39;usage pour le temps de calcul et l&#39;espace de stockage | Paiement à l&#39;usage pour la bande passante et l&#39;espace de stockage |

<div id="project-editor-tools">
  ### Outils du Project Editor
</div>

Découvrez les outils Replit suivants pour configurer et gérer le stockage des données de votre application :

<CardGroup>
  <Card title="Base de données" href="/fr/features/data-and-storage/sql-database" icon="database">
    Idéale pour les données structurées et pour représenter les relations entre les données.
    S’appuie sur une base de données PostgreSQL entièrement gérée, qui évolue avec votre application.
  </Card>

  <Card title="App Storage" href="/fr/features/data-and-storage/object-storage" icon="bucket">
    Idéale pour les données non structurées et les fichiers volumineux, comme les images, les vidéos et les documents.
    S’appuie sur Google Cloud Storage (GCS) pour une haute disponibilité et une grande évolutivité. Agent peut configurer automatiquement App Storage avec une authentification avancée et des contrôles d’accès.
  </Card>
</CardGroup>
