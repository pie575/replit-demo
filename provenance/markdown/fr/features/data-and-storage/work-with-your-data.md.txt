# Travailler avec vos données

> Parcourez, modifiez, exportez et interrogez votre base de données depuis l'onglet My Data, avec des outils visuels ou en SQL.

L'onglet **My Data** est l'endroit où vous consultez et modifiez le contenu de votre base de données. Ouvrez l'outil **Database**, sélectionnez une base de données, puis sélectionnez **My Data**. Vous pouvez travailler visuellement ou exécuter du SQL directement.

<Note>
  Pour modifier les données de production, sélectionnez la base de données de production, ouvrez **My Data**, puis activez **Edit**. Soyez prudent : il s'agit des données réelles de votre application en production.
</Note>

## Parcourir et modifier les données visuellement

L'outil Database inclut <a href="https://orm.drizzle.team/drizzle-studio/overview" target="_blank">Drizzle Studio</a>, un outil qui vous permet de parcourir et de modifier les données visuellement. Ces outils visuels vous aident à éviter les erreurs de syntaxe et offrent les fonctionnalités suivantes :

* Filtrer et trier les données pour se concentrer sur des informations spécifiques
* Exporter les données vers un fichier pour une utilisation externe
* Insérer ou modifier des données de lignes
* Créer et gérer le schéma, les tables, les vues et les énumérations

## Exécuter des commandes SQL

Le SQL runner vous permet d'exécuter des commandes SQL sur votre base de données et d'afficher les résultats.

<Accordion title="Comment accéder au SQL runner">
  Depuis l'outil **Database** :

  1. Sélectionnez l'onglet **My Data**
  2. Sélectionnez <img class="icon-svg" src="https://mintcdn.com/replit/X_IP1EeHGm0cA2VA/images/icons/sql-runner-icon.svg?fit=max&auto=format&n=X_IP1EeHGm0cA2VA&q=85&s=fd73c517972d1a4004105e6ab49d130b" alt="Icône SQL runner" width="16" height="16" data-path="images/icons/sql-runner-icon.svg" /> **SQL runner**
</Accordion>

Pour exécuter une requête, entrez l'instruction SQL dans la zone de texte et sélectionnez le bouton d'exécution adjacent <img class="icon-svg" src="https://mintcdn.com/replit/X_IP1EeHGm0cA2VA/images/icons/sql-play.svg?fit=max&auto=format&n=X_IP1EeHGm0cA2VA&q=85&s=eb0c68e0ab494444f0cbc60325bd1150" alt="icône d'exécution sql" width="18" height="18" data-path="images/icons/sql-play.svg" /> :

<Frame>
  <img src="https://mintcdn.com/replit/tlGd6oyGOaUUeRxr/images/databases/sql-runner-run.jpg?fit=max&auto=format&n=tlGd6oyGOaUUeRxr&q=85&s=258c6ac51524a21e6a6e2070c7cefd3c" alt="capture d'écran du SQL runner et du bouton d'exécution" width="1390" height="608" data-path="images/databases/sql-runner-run.jpg" />

<Tip>
  Vous n'avez pas besoin d'écrire le SQL vous-même. Demandez à Agent d'interroger ou de modifier vos données, et il écrira et exécutera le SQL pour vous.
</Tip>
