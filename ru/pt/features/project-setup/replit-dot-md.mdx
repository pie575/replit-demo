<div id="como-o-replitmd-funciona">
  ## Как работает `replit.md`
</div>

Сначала Agent создаёт файл `replit.md` в корневом каталоге вашего проекта, опираясь на проверенные лучшие практики. В этот файл входят:

* Базовая информация о проекте
* Рекомендуемые стандарты написания кода
* Типичные предпочтения для вашего типа проекта

<YouTubeEmbed videoId="kYv525W-vaU" title="Настройка ответов Replit Agent" />

Обрабатывая ваши запросы, Agent автоматически читает файл `replit.md` и использует его содержимое, чтобы:

* Понимать архитектуру и соглашения вашего проекта
* Следовать выбранным вами стандартам и стилю написания кода
* Использовать указанные вами менеджеры пакетов и зависимости

Agent также может обновлять файл `replit.md` по мере того, как узнаёт больше о вашем проекте и вносит изменения в приложение.

<Note>
  Вы можете отредактировать файл `replit.md`, чтобы настроить поведение Agent.
</Note>

<div id="configurando-o-replitmd">
  ## Настройка `replit.md`
</div>

<div id="gerao-automtica">
  ### Автоматическая генерация
</div>

Когда вы создаёте новый проект с помощью Agent, он автоматически генерирует файл `replit.md` на основе проверенных лучших практик. Этот файл появляется в корневом каталоге проекта и содержит:

* Основные сведения о проекте
* Рекомендуемые стандарты написания кода
* Типичные предпочтения для вашего типа проекта

<div id="criao-manual">
  ### Создание вручную
</div>

Вы можете создать собственный файл `replit.md`, добавив в корневой каталог проекта новый файл с именем `replit.md`. Agent автоматически обнаружит его и будет использовать в дальнейших диалогах.

<Note>
  Чтобы файл `replit.md` работал корректно, он должен находиться в корневом каталоге проекта.
</Note>

<div id="regenerando-o-replitmd">
  ### Повторное создание `replit.md`
</div>

Если файл `replit.md` повредился или вы хотите начать с чистого листа:

1. Удалите существующий файл `replit.md` из корня проекта
2. Начните новый диалог с Agent
3. Agent автоматически создаст новый файл `replit.md` на основе вашего текущего проекта

  ## Сочетание веб-поиска с `replit.md`
</div>

Agent может искать в интернете актуальную информацию, библиотеки и решения. В сочетании с файлом `replit.md` вы получаете и свежие знания, и рекомендации, учитывающие особенности вашего проекта.

<div id="boas-prticas-para-integrao-de-pesquisa-na-web">
  ### Рекомендации по интеграции веб-поиска
</div>

**Чётко указывайте, что именно должен найти Agent:**

```markdown theme={null}
## Предпочтения по исследованию
- Всегда проверяй наличие последних версий зависимостей, прежде чем предлагать обновления
- Изучай актуальные лучшие практики реализации безопасности
- Ищи свежие приёмы оптимизации производительности для нашего стека технологий
```

**Объясните Agent, как использовать внешние знания:**

```markdown theme={null}
## External Research Guidelines
- When suggesting new libraries, ensure compatibility with our existing stack
- Adapt external examples to match our coding standards and project structure  
- Verify that suggested solutions work with our publishing environment
```

**Пример запроса, использующего оба подхода:**
&quot;Research the latest React 18 performance optimization techniques and implement them following the component patterns defined in `replit.md`&quot;

Такой подход даёт решения, которые одновременно актуальны и адаптированы под конкретные потребности вашего проекта.

<div id="limitaes">
  ## Ограничения
</div>

<div id="limites-de-tamanho-e-contedo-do-arquivo">
  ### Ограничения на размер и содержимое файла
</div>

Хотя жёсткого ограничения на количество символов в `replit.md` нет, слишком большие файлы могут быть обработаны не полностью. Чтобы получить наилучший результат, держите `replit.md` кратким и по существу.

<div id="requisito-de-diretrio-raiz">
  ### Требование к корневому каталогу
</div>

Файл `replit.md` должен находиться в корневом каталоге проекта. Agent не находит файлы в подкаталогах автоматически.

<div id="alcance-do-contexto">
  ### Область действия контекста
</div>

Файл `replit.md` задаёт контекст для диалогов с Agent, но не применяется автоматически к другим ИИ-инструментам.

<div id="prximos-passos">
  ## Дальнейшие шаги
</div>

Готовы настроить Agent под свой проект?

1. **Начните с простого**: создайте базовый `replit.md` с основными предпочтениями
2. **Дорабатывайте постепенно**: обновляйте `replit.md` по мере работы с Agent
3. **Делитесь подходами**: применяйте удачные настройки `replit.md` в похожих проектах
4. **Оценивайте результат**: следите за тем, насколько точно Agent следует вашим указаниям, и корректируйте их при необходимости

Узнайте больше о [работе с Agent](/ru/pt/features/agent/overview) или изучите другие [инструменты ИИ](/ru/pt/build/welcome).

**Enterprise**: заранее настройте `replit.md` в [пользовательских шаблонах](/ru/pt/teams/custom-templates), чтобы у каждого разработчика в вашей организации был единообразный стартовый контекст. Рекомендации по дизайну смотрите в разделе [настройка дизайн-системы](/ru/pt/teams/custom-design-system).
