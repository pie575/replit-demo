<div id="section">
  ## Qu’est-ce que la visualisation de données ?
</div>

La visualisation de données est un tableau de bord interactif ou un outil de reporting créé en discutant avec Agent. Décrivez ce que vous souhaitez visualiser et où se trouvent les données : Agent sélectionne automatiquement les KPI, les types de graphiques et la mise en page appropriés pour générer un tableau de bord complet à partir d’un seul prompt.

Concepts clés :

* **Création en une seule étape** : décrivez votre objectif et vos sources de données, et Agent crée un tableau de bord complet avec les graphiques et indicateurs appropriés
* **Sources de données connectées** : importez des données depuis des bases de données, des [connecteurs d’entrepôt de données](/fr/ko/connectors/warehouses/overview), des API externes et des fichiers téléversés
* **Fonctionnalités intégrées** : tous les tableaux de bord incluent l’actualisation, l’actualisation automatique, l’exportation au format PDF, l’exportation de graphiques au format CSV et le mode clair/sombre
* **Résumé analytique** : Agent génère des analyses à partir de votre demande et des données obtenues
* **Plusieurs artefacts** : les visualisations de données peuvent partager le même backend et la même base de données que d’autres artefacts au sein du [même projet](/fr/ko/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project)

<div id="data-visualization">
  ## Comment utiliser la visualisation de données
</div>

<div id="section-2">
  ### Créer à l’aide d’un prompt
</div>

Depuis la page d’accueil, sélectionnez l’onglet **App** et décrivez le tableau de bord souhaité. Agent détecte les prompts liés aux données et sélectionne la pile Visualisation de données.

**Exemples de prompts :**

* &quot;Crée un tableau de bord d’analyse commerciale qui suit les ventes par région&quot;
* &quot;Crée un outil de reporting qui visualise les indicateurs mensuels&quot;
* &quot;Crée un tableau de bord qui présente les produits les plus performants à partir de nos données de vente BigQuery&quot;
* &quot;Connecte-toi à Snowflake et crée un tableau de bord d’analyse de l’attrition client&quot;

<div id="section-3">
  ### Créer depuis le menu déroulant
</div>

1. Sur la page d&#39;accueil, accédez à l&#39;onglet **App**.
2. Ouvrez le menu déroulant des types d&#39;application.
3. Sélectionnez **Visualisation de données**.
4. Décrivez le tableau de bord ou l&#39;outil de données que vous souhaitez créer.

<div id="section-4">
  ### Connecter un entrepôt de données
</div>

Connectez la visualisation de données à BigQuery, Databricks et Snowflake à l’aide du [connecteur d&#39;entrepôt de données](/fr/ko/connectors/warehouses/overview) pour créer des tableaux de bord à partir de vos jeux de données existants.

Lorsqu&#39;il interroge les données de l&#39;entrepôt, Agent utilise une recherche parallèle multi-agents pour explorer les schémas et les jeux de données. Cela accélère l’exploration et aide Agent à sélectionner les tables et les champs les mieux adaptés à votre tableau de bord.

Pour commencer, configurez le connecteur d&#39;entrepôt de données dans les [Intégrations](/fr/ko/features/integrations/overview) de votre projet, puis indiquez à Agent ce que vous souhaitez visualiser.

<div id="section-5">
  ### Ajouter des filtres et des fonctionnalités
</div>

Une fois le tableau de bord créé par Agent, vous pouvez lui envoyer un prompt pour ajouter des filtres, des options d’exploration détaillée et d’autres fonctionnalités interactives. Par exemple, demandez à Agent d’ajouter un filtre de plage de dates, un sélecteur de région et une barre de recherche.

<div id="section-6">
  ### Exporter et partager
</div>

* **Exporter au format PDF** : exportez l’intégralité du tableau de bord au format PDF pour le partager ou le consulter hors ligne.
* **Exporter les graphiques au format CSV** : téléchargez les données de chaque graphique au format CSV pour les analyser plus en détail dans un tableur ou d’autres outils.
* **Document d’analyse** : demandez à Agent de rédiger un document d’analyse détaillé à partir des données du tableau de bord.

<div id="section-7">
  ## Ce que vous pouvez créer
</div>

* **Tableaux de bord analytiques** : suivez des indicateurs clés tels que le chiffre d’affaires, les inscriptions et l’engagement au fil du temps
* **Outils de reporting** : créez des rapports internes que les parties prenantes peuvent filtrer et explorer sans accéder directement à la base de données
* **Interfaces d’exploration de données** : explorez et consultez des jeux de données avec des retours visuels
* **Panneaux de supervision** : affichez des données en temps réel ou quasi réel provenant d’API, de bases de données et de services externes

<div id="section-8">
  ## Questions fréquentes
</div>

<Accordion title="Quelles sources de données puis-je connecter ?">
  Vous pouvez récupérer des données depuis Replit Database de votre projet, des connecteurs d&#39;entrepôt de données (BigQuery, Databricks, Snowflake), des API externes et des fichiers importés, tels que des CSV. Configurez une connexion à un entrepôt de données via les [Intégrations](/fr/ko/features/integrations/overview).
</Accordion>

<Accordion title="Puis-je personnaliser le design et l'apparence ?">
  Oui. Vous pouvez personnaliser les couleurs, la mise en page et la typographie dans la conversation : demandez à Agent d&#39;adapter le résultat à votre marque ou d&#39;ajuster le design. Les tableaux de bord prennent également en charge les modes clair et sombre.
</Accordion>

<Accordion title="Agent analyse-t-il les données à ma place ?">
  Après avoir créé un tableau de bord, Agent génère un résumé analytique à partir de votre demande et des données obtenues. Vous pouvez également demander un document d&#39;analyse plus détaillé.
</Accordion>

<Accordion title="Puis-je associer des visualisations de données à d'autres types d'artefacts ?">
  Oui. Au sein du [même projet](/fr/ko/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project), vous pouvez associer des visualisations de données à des [applications web](/fr/ko/features/artifact-types/web-apps), des [présentations](/fr/ko/features/artifact-types/slide-decks) et d&#39;autres types d&#39;artefacts. Ils partagent le même backend et la même base de données.
</Accordion>
