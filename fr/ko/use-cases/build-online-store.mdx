Fournissez à Agent les informations produit issues de sources dont vous disposez déjà : Google Sheet (nom, prix,
description, code produit, stock) et photos stockées dans Google Drive. Agent configure la boutique Shopify,
importe les produits, les prix, les descriptions et les images, puis connecte le paiement et le passage en caisse.
Le design de la vitrine et le front-end sont hébergés sur Replit, et non dans un thème Shopify. Le paiement
s&#39;effectue via le passage en caisse Shopify ; aucun connecteur Stripe distinct n&#39;est donc nécessaire.

* Designers produit utilisant Shopify comme backend e-commerce et ayant besoin d&#39;une vitrine Replit personnalisée

<div id="section-3">
  ## Avant de commencer
</div>

Préparez une feuille avec une ligne par produit (nom, prix, description, code produit, stock) et un dossier Drive contenant des photos nommées afin qu’Agent puisse les associer aux lignes. Connectez Sheets, Drive et Shopify. Si vous n’avez pas encore de boutique, Agent peut provisionner Shopify dans le chat. Passez une commande de test avant de partager la boutique.

<div id="agent">
  ## Demander à Agent
</div>

<AiPrompt>
  À partir de cette source de produits[Google Sheet et dossier Drive], configurez une boutique Shopify
  complète : importez tous les produits avec leur nom, prix, description et photos. Concevez et développez
  la vitrine (accueil, collections, produits, panier) dans cette application Replit.
  Utilisez Shopify pour le catalogue, le panier, le passage en caisse et le paiement. N’utilisez pas de
  thème Shopify pour les pages destinées aux clients.
</AiPrompt>

<div id="section-4">
  ## Résultat attendu
</div>

Agent importe le catalogue dans Shopify, puis crée une vitrine Replit qui récupère les produits depuis Shopify
et redirige les clients vers le passage en caisse Shopify. Comparez quelques produits (prix,
texte, images) avec la feuille de calcul et passez une commande test. Utilisez les paiements test de Shopify,
vérifiez que le total du panier correspond à celui de la feuille de calcul et que le passage en caisse s’effectue entièrement dans
Shopify.

<div id="section-5">
  ## L’adapter à mes besoins
</div>

<AiPrompt>
  Associez les photos Drive aux lignes du Sheet selon le nom de fichier du code produit (CODE.jpg). Ignorez les
  lignes sans photo.
</AiPrompt>

<AiPrompt>
  Ajoutez des pages de collection en fonction de la colonne des catégories du Sheet, puis ajoutez
  une barre de recherche à la vitrine Replit.
</AiPrompt>

<div id="section-6">
  ## Résolution des problèmes
</div>

* **Les photos ne correspondent pas aux produits :** Nommez les fichiers Drive avec le code produit (`CODE.jpg`) et demandez à Agent d’ignorer les lignes sans photo.
* **Les prix ou le texte diffèrent de la feuille :** Vérifiez que chaque produit est répertorié sur une seule ligne (nom, prix, description, code produit, stock), puis vérifiez quelques éléments après l’importation.
* **Le passage en caisse ne passe pas par Shopify ou la vitrine utilise un thème :** La page que voient les clients doit être hébergée sur Replit. Le paiement s’effectue via le processus de passage en caisse Shopify. Passez une commande test avant de partager la boutique.
