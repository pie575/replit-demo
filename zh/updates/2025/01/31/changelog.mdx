<div id="platform-updates">
  ## 平台更新
</div>

<div id="repl-app">
  ### Repl -&gt; App
</div>

Repl 现已更名为“App”。简洁至上。

<div id="enhanced-notifications">
  ### 通知优化
</div>

我们改进了支付失败和账单通知。现在，在 App 被暂停前，你将获得 24 小时宽限期，整个流程也更加透明。

这项更新有助于你避免 Replit 使用体验中断。

<div id="object-storage-improvements">
  ### Object Storage 改进
</div>

Object Storage 面板新增了搜索和分页功能，让你浏览文件更加轻松。

<div id="de-cluttered-diffs">
  ### 更清晰的差异对比
</div>

Assistant 的文件改动现在会在临时的差异对比窗格中打开，让你更方便地查看改动内容，而不会让 workspace 堆满无穷无尽的标签页。

应用改动后，这些窗格会自动关闭。

<div id="more-performant-agent-in-asia">
  ### 亚洲地区 Agent 性能提升
</div>

我们针对亚洲地区的 Agent 开发者优化了云服务。你会明显感觉到响应更快、体验更流畅。

<div id="x-login">
  ### X 登录
</div>

现在你可以使用 X 账号注册并登录 Replit。欢迎来到未来。

<div id="rapid-repo-import">
  ### 仓库快速导入
</div>

想把你喜欢的 GitHub 仓库搬到 Replit 上？

现在可以一步到位。

只需在浏览器中输入 `replit.com/YOUR_REPO_URL`，例如：

`https://replit.com/github.com/mattppal/magnetic-feel`
