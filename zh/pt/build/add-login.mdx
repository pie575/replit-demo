你已在[欢迎使用 Replit](/zh/pt/build/welcome)中了解过 Velocity——一款高端超级跑车租赁 App。目前，任何访问公开 URL 的人都能看到所有预订。不会有人匿名租赁 Lamborghini。添加登录功能后，每位客户都能查看自己的预订和已保存的车辆。

<div id="pea-ao-agent-para-adicionar-o-login">
  ## 请 Agent 添加登录功能
</div>

对于 Velocity，请使用 Clerk。Clerk 与 Replit 的集成可为你的应用提供带有自有品牌的登录页面、仅存在于 Velocity 中的客户账户 (而非 Replit 账户) ，以及对外观的完全控制——非常适合高端租赁品牌。Agent 会自动完成所有配置，无需在 Clerk 控制台注册，也无需粘贴密钥。

<AiPrompt>
  为 Velocity 添加登录功能，让每位客户都能查看自己的预订和已保存的车辆。<br />
  使用 Clerk Auth。<br />
  保持车辆浏览页面公开，让访客无需账户也能浏览车队。<br />
  要求用户在预订或将车辆添加到收藏夹前先登录。<br />
  登录后，在页眉显示客户姓名，并添加一个仅显示其本人预订的“我的预订”部分。<br />
  添加退出按钮。<br />
  为我提供一份使用两位不同客户进行测试的检查清单。

Agent 将为 Velocity 配置一个 Clerk 租户，添加登录组件，保护预订流程，将每笔预订关联到已登录的客户，并添加退出功能。请在 Agent 的 Chat 中跟踪构建进度。

<div id="teste-com-dois-clientes">
  ## 使用两个客户账户进行测试
</div>

一个账户不够——你需要两个账户来验证预订记录是否彼此隔离。

1. 在 Preview 中打开 Velocity，无需登录即可浏览车辆。车辆列表应仍然可见。
2. 点击某辆车的“预订”。你应会进入 Clerk 登录页面。
3. 使用自己的电子邮件地址注册，并完成一次预订 (例如预订一辆 911 度过周末) 。
4. 退出登录。“我的预订”部分应消失，预订流程应再次要求你登录。
5. 在无痕窗口中打开 Preview，并使用另一个电子邮件地址注册。预订另一辆车。
6. 返回第一个窗口，登录并确认你仍能看到自己的预订，而不是第二位客户的预订。

如果两个客户都能看到彼此的预订，说明预订尚未关联到已登录的用户。请将具体症状告诉 Agent：

<AiPrompt>
  两位客户都能在 Velocity 中看到彼此的预订。<br />
  将每项预订和每辆已保存的车辆关联到已登录的客户，以便每个人只能看到自己的内容。<br />
  向我展示如何使用两个测试账户进行验证。
</AiPrompt>

<div id="publicar-e-entrar-na-url-pblica">
  ## 部署并登录公开 URL
</div>

通过 Agent Chat 或“部署”磁贴重新部署 Velocity，然后在新标签页中打开公共 URL 并登录。Clerk 提供相互独立的开发和生产环境——Agent 会自动将生产环境凭证连接到已部署应用，因此公共 URL 上的登录无需额外配置即可正常使用。

Velocity 现在已有真实客户。每位客户都会登录到自己的私密预约车库，其他人无法查看。

  ## 需要更多帮助？
</div>

* **整个应用都被隐藏了：**让 Agent 保持汽车浏览页面公开，只保护预订和账户页面。
