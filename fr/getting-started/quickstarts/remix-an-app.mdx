## Améliorez votre Remix

Maintenant que vous avez une application fonctionnelle, utilisez Agent pour la modifier et l'étendre. Les sections suivantes montrent des exemples pratiques d'amélioration de votre Remix.

### Ajoutez une fonctionnalité avec Agent

Utilisez Agent pour ajouter des fonctionnalités complexes à votre Remix :

<Steps>
  <Step title="Rédigez un prompt">
    Accédez à l'onglet **Agent**.

    Saisissez le prompt suivant dans la zone de texte :

    <AiPrompt>
      Add a tutorial mode that teaches you how to play simple songs. When tutorial mode is active, highlight the next key that should be played, wait for you to press the correct key before moving on, and display the song name at the top. Include a button to start the tutorial and pre-load at least two simple songs like "Mary Had a Little Lamb" or "Twinkle Twinkle Little Star."
    </AiPrompt>

    Après avoir soumis le prompt, Agent peut faire une pause et demander des clarifications ou une confirmation. Répondez dans la zone de texte.
  </Step>

  <Step title="Testez la fonctionnalité">
    Accédez à l'onglet **Preview** pour voir les mises à jour du piano par Agent.

    Essayez de démarrer le mode tutoriel et de suivre les touches en surbrillance.

    <Frame>
      <video autoPlay muted loop playsInline src="/assets/mirror/quickstart-remix-piano-play-3be628756ae7.mp4" />
    </Frame>

    Étant donné que le prompt initial n'incluait pas de détails spécifiques sur le design visuel, le résultat peut ne pas correspondre exactement à vos attentes.
  </Step>

  <Step title="Affinez la fonctionnalité">
    Si la fonctionnalité diffère de vos attentes, continuez la conversation en saisissant un prompt de suivi dans la zone de texte **Agent**. Par exemple :

    <AiPrompt>
      Make the highlighted key glow with a pulsing animation and add a progress indicator showing how far along in the song I am.
    </AiPrompt>

    Pour annuler ces modifications, sélectionnez **Rollback to here** dans le Point de contrôle créé immédiatement après le démarrage du plan de modification dans l'onglet **Agent**.

    En savoir plus sur les [Points de contrôle et les Retours arrière](/fr/core-concepts/agent/checkpoints-and-rollbacks).
  </Step>
</Steps>

### Ajoutez une fonctionnalité avec le mode Lite

Suivez ces étapes pour ajouter une amélioration rapide à votre Remix en utilisant le [mode Lite](/fr/core-concepts/agent/agent-modes) :

<Steps>
  <Step title="Rédigez un prompt">
    Passez au [mode Lite](/fr/core-concepts/agent/agent-modes) et saisissez le prompt suivant :

    <AiPrompt>
      Add record and playback buttons to capture and replay piano performances.
    </AiPrompt>

    Après avoir soumis le prompt, Agent décrit les modifications qu'il souhaite apporter et vous permet de réviser les changements de code avant de continuer.
    Sélectionnez **Preview code changes** pour voir une comparaison du code actuel et des mises à jour.
  </Step>

  <Step title="Testez la fonctionnalité">
    Sélectionnez **Apply all** et approuvez les confirmations suivantes pour continuer.

    Accédez à l'onglet **Preview** pour vérifier le résultat. Vous devriez maintenant voir des boutons d'enregistrement et de lecture qui vous permettent de capturer et de rejouer ce que vous jouez.

    Pour annuler ces modifications, utilisez la fonctionnalité Rollback dans l'onglet **Agent**.
  </Step>
</Steps>

## Poursuivez votre parcours

Maintenant que vous avez terminé ce tutoriel, voici quelques prochaines étapes spécifiques au remix :

* **Explorez d'autres remixes** : Parcourez la [communauté](https://replit.com/community/all) pour trouver des applications à remixer et dont apprendre
* **Créez de zéro** : Essayez de [créer votre propre application](/fr/getting-started/quickstarts/ask-ai) avec Agent pour comparer l'expérience
* **Publiez pour le remix** : Partagez votre version améliorée pour que d'autres puissent s'appuyer sur votre travail.
