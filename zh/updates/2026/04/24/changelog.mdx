<div id="security-agent-reviews-your-whole-codebase">
  ### Security Agent 审查你的整个代码库
</div>

**Security Agent** 是全新的 AI 审查工具，它不仅检查依赖项，还会审查整个 project。它会构建威胁模型，梳理路由与数据流，使用 Semgrep 和 HoundDog.ai 进行静态分析，并借助大语言模型判断哪些 findings 在你的应用场景中真正可被利用。审查完成后，Security Agent 会将采纳的 findings 拆分为多个并行任务，交由 Replit Agent 一次性修复。

<Frame>
  <img src="/assets/mirror/security-agent-findings-b425392bb98a.png" alt="Project Security Center 中的 Security Agent 面板，显示一次已完成的扫描，其中五个 findings 按严重程度分类，每项带有“待审查”或“待重新发布”等状态，下方是自动依赖扫描部分，列出存在漏洞的软件包" width="1438" height="808" data-path="images/changelog/2026-04-24/security-agent-findings.png" />
</Frame>

所有付费用户均可使用 Security Agent。打开 project 中的 **Security** 面板，选择 **Run Scan with Agent** 即可体验。

进一步了解 [Security Agent](/zh/core-concepts/security/project-security-center#agent-security-scans)。

<div id="cve-auto-protect-patches-critical-vulnerabilities-automatically">
  ### CVE Auto-Protect 自动修复严重漏洞
</div>

当你的应用所依赖的软件包被披露新的严重 CVE 时，**CVE Auto-Protect** 会在你拥有的所有 project 中检测出受影响的部分，由 Agent 在后台任务中准备补丁，并运行你的测试以确保不会破坏任何功能，然后通知你并附上审查链接。一切仍由你掌控——在你批准修复之前，不会发布任何内容。

这意味着新漏洞公开后几分钟内，你的应用就能完成修补，而不必等到你自己发现问题。

进一步了解 [CVE Auto-Protect](/zh/core-concepts/security/project-security-center#auto-protect)。

<div id="preview-on-an-ios-simulator-or-android-emulator">
  ### 在 iOS 模拟器 或 Android 模拟器 中预览
</div>

<Frame>
  <video autoPlay muted loop playsInline src="/assets/mirror/ios-emulator-9013ff1b602f.mp4" />
</Frame>

当你的 project 包含移动应用时，预览 面板现在可以将真实的 **iOS 模拟器** 或 **Android 模拟器** 直接串流到你的 workspace 中，无需 Xcode，无需 Android Studio，也不需要真机。用 Agent 构建一个移动应用，在 预览 面板的下拉菜单中选择设备，就能像手里拿着手机一样随意点按操作。Agent 所做的修改会在模拟器中热重载。

该功能面向 Core、Pro 和 Enterprise 套餐的付费用户开放，支持 Chrome、Safari 及基于 Chromium 的浏览器；移动模拟器不支持 Firefox。

进一步了解[在模拟器中预览](/zh/features/artifact-types/building-mobile-apps#preview-on-a-simulator-or-emulator)。

  ### 为旧 project 添加移动应用
</div>

<Frame>
  <img src="/assets/mirror/multi-artifact-update-approval-f6fa8b70a100.png" alt="Agent 聊天面板显示“更新 project 以创建移动应用”的确认卡片，包含 5 美元额度赠送以及“暂不”/“更新 project”按钮。" width="991" height="589" data-path="images/replitai/multi-artifact-update-approval.png" />

在 Agent 4 发布之前创建的 project 现在也可以更新为支持多个 artifact——也就是说，原本只能包含单个 artifact 的 project，现在可以再添加移动应用、演示文稿或其他 artifact。Agent 在重新组织 project 的过程中会保留原有的 URL、数据、secrets 和 deployment。在更大范围推出后的头 48 小时内，已有超过 200 个 project 完成迁移。

<div id="plaid-connector-is-live">
  ### Plaid connector 已上线
</div>

现在你可以通过 **Plaid** connector 连接 12,000 多家金融机构。团队管理员只需在 **Integrations** 中配置一次凭据，你的应用用户即可通过 Plaid Link 完成自己银行账户的身份验证。访问令牌按用户单独授权，数据始终保持私密。

你可以打造基于真实交易数据的个人理财教练、连接券商账户的实时投资组合追踪器等各类应用。前往 [Replit x Plaid 合作页面](https://replit.com/partners/plaid) 查看演示和设置步骤。

进一步了解[管理 connector](/zh/replitai/managing-connectors)。
