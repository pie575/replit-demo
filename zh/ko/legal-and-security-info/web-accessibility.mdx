Replit 相信，计算应该惠及每个人。因此，Replit 致力于确保所有人，包括残障人士，都能充分使用其服务。本声明介绍了我们的无障碍目标、为实现这些目标所取得的进展，以及如何就 Replit 的无障碍性提供反馈。

<div id="section">
  # 合规目标
</div>

我们的目标是全面遵循 W3C WAI《Web 内容无障碍指南》(WCAG) 2.1，该指南规定了设计师和开发人员为提升残障人士无障碍体验而需满足的要求。Replit 目前部分符合 WCAG 2.1 AA 级标准。部分符合意味着网站的部分内容尚未完全达到无障碍标准。

<div id="section-2">
  # 当前状态
</div>

Replit 正在持续开展内部项目，以提升网站的无障碍访问体验。该项目参考了内部评估、构建者访谈和报告，以及 Cornell University IT 部门于 2021 年开展的独立评估结果。

网站的大部分内容目前以符合 W3C HTML 和 CSS 标准的 HTML 格式提供。对于图像和表单元素等非文本内容，我们提供文本替代内容，以便屏幕阅读器能够识别并朗读。

尽管我们持续努力确保无障碍访问，但仍可能存在一些限制。尤其是无法通过键盘完全操作工作空间的问题，是 Replit 正在努力解决的已知问题。

<div id="section-3">
  # 提供反馈
</div>

如果您无法访问 Replit 网站，请发送电子邮件至 [contact@replit.com](mailto:contact@replit.com) 提供反馈。请附上您尝试访问的资源 URL (网址) 、遇到的问题以及您的联系信息。
