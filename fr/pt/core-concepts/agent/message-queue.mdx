---
title: "File d’attente des messages"
description: "Découvrez comment mettre en file d’attente des messages de suivi pour Agent afin qu’il les traite dans l’ordre une fois la tâche en cours terminée."
---

La file d’attente des messages offre une nouvelle façon d’interagir avec Replit Agent pendant qu’il travaille.
Au lieu d’interrompre le travail en cours, vous pouvez planifier des tâches de suivi qui seront exécutées
dans l’ordre à la fin de chaque cycle de travail d’Agent.

<div id="como-funciona">
  ## Fonctionnement
</div>

Lorsque l’Agent traite activement une demande, vous pouvez planifier une tâche de suivi en ajoutant
des messages à la file d’attente. Ces tâches ou demandes seront traitées dans l’ordre à la fin de
chaque cycle de travail de l’Agent. La file d’attente est automatiquement vidée lorsque l’Agent a terminé toutes les tâches.

Toutes les options de message sont disponibles dans la file d’attente, comme l’[Éditeur visuel](/fr/pt/replitai/visual-editor)
et les pièces jointes.

<Info>
  Les messages en attente ne seront traités automatiquement que tant que vous disposerez d’une
  session active de l’Éditeur de projets connectée à l’Agent, sur ordinateur ou appareil mobile.
</Info>

<div id="usando-a-fila-de-mensagens">
  ## Utiliser la file d’attente des messages
</div>

<div id="quando-a-fila-aparece">
  ### Quand la file d’attente apparaît
</div>

La file d’attente des messages s’affiche automatiquement sous forme de panneau latéral au-dessus du champ de saisie du Chat lorsque vous envoyez un message
alors qu’Agent travaille. Elle se ferme dès que tous les messages en attente ont été traités.

<div id="gerenciando-mensagens-enfileiradas">
  ### Gérer les messages en file d’attente
</div>

Lorsque le panneau latéral de la file d’attente est ouvert, vous pouvez :

* **Modifier des messages :** Cliquez sur l’icône de modification pour modifier un message en attente avant son traitement.
* **Supprimer des messages :** Retirez les tâches indésirables de la file d’attente.
* **Réorganiser les éléments :** Faites glisser et déposez les messages en attente pour modifier leur ordre d’exécution.
* **Ajouter d’autres messages :** Continuez à ajouter de nouvelles tâches à la file d’attente via le champ de saisie du Chat.

<div id="interrupo-imediata">
  ### Interruption immédiate
</div>

Si vous devez interrompre l’Agent et lui envoyer immédiatement un message, utilisez le bouton **Mettre en pause**
dans la barre d’état. Cela interrompt le cycle de travail en cours de l’Agent et vous permet d’envoyer un message immédiatement,
en ignorant les messages en attente, le cas échéant.

<div id="melhores-prticas">
  ## Bonnes pratiques
</div>

<div id="quando-usar-a-fila-de-mensagens">
  ### Quand utiliser la file d&#39;attente des messages
</div>

* **Flux de travail en plusieurs étapes** : Mettez en file d&#39;attente une série de tâches connexes qui s&#39;appuient les unes sur les autres
* **Opérations par lots** : Regroupez des demandes similaires pour un traitement efficace
* **Demandes de suivi** : Ajoutez des précisions ou des exigences supplémentaires après la tâche initiale
* **Tâches non urgentes** : Mettez en file d&#39;attente des demandes moins prioritaires pendant que l&#39;Agent travaille sur des tâches critiques

<div id="quando-usar-a-interrupo-imediata">
  ### Quand utiliser l’interruption immédiate
</div>

* **Modifications urgentes :** lorsque vous devez interrompre immédiatement le travail en cours
* **Erreurs critiques :** si vous repérez un problème nécessitant une attention immédiate
* **Changement de direction :** lorsque vous souhaitez modifier complètement la tâche sur laquelle travaille l’Agent

<div id="comportamento-da-fila">
  ## Comportement de la file d’attente
</div>

* **Exécution dans l’ordre** : les messages sont traités dans l’ordre où ils ont été ajoutés à la file d’attente
* **Fin du cycle de travail** : chaque message en attente est traité une fois que l’Agent a terminé son cycle de travail en cours
* **Conservation du contexte** : l’Agent conserve le contexte entre les messages en attente dans une même conversation
