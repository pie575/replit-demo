Хранилище App — это встроенное объектное хранилище Replit, которое позволяет приложениям легко размещать и хранить загруженные изображения, видео, документы и другие файлы.
Бакет — это контейнер для хранения объектов, например файлов. Он содержит политики доступа, которые ограничивают действия пользователей или приложений с его содержимым.

<Info>
  <strong>Объектное хранилище</strong> переименовано в <strong>Хранилище App</strong>. Функциональность не изменилась: существующие бакеты, права и программный доступ продолжают работать.
</Info>

С помощью Хранилища App можно создавать, например, такие приложения:

* **Платформы для обмена фотографиями**: разработчики могут загружать, хранить и отображать изображения
* **Сервисы потокового видео**: обработка загруженных видео и доставка контента зрителям
* **Системы управления документами**: хранение и упорядочивание файлов разработчиков с безопасным доступом
* **Сайты-портфолио**: демонстрация работ с надёжно загружающимися медиафайлами
* **Сервисы резервного копирования**: облачное хранилище для важных файлов разработчиков

Инструмент «Хранилище App» позволяет беспрепятственно обмениваться данными между средой разработки и продакшеном, а также с другими Replit App.

<div id="section">
  ## Возможности
</div>

<Info>
  App Storage использует Google Cloud Storage (GCS).
  Это обеспечивает ведущие в отрасли показатели времени безотказной работы, доступности и безопасности.
</Info>

App Storage предоставляет Replit App следующие возможности:

* **Постоянное облачное хранилище**: храните файлы, к которым опубликованные приложения и пользователи сохранят доступ
* **Масштабируемая обработка файлов**: работайте с растущими объёмами данных, не беспокоясь об ограничениях хранилища
* **Обмен данными между приложениями**: предоставляйте нескольким Replit App общий доступ к бакетам для распределённых архитектур
* **Программный доступ**: загружайте, скачивайте и управляйте файлами с помощью интуитивно понятного API
* **Расширенная интеграция с Agent**: поручите Agent настроить App Storage с расширенными параметрами, проверить существующую конфигурацию и сгенерировать полный код бэкенда и фронтенда, включая аутентификацию и контроль доступа

Примеры использования App Storage в Replit App:

* Хранение изображений профилей разработчиков и загружаемых медиафайлов
* Отображение изображений товаров на сайтах электронной коммерции
* Обработка загрузки документов через формы
* Создание функций обмена файлами и совместной работы
* Создание систем управления контентом с медиатеками

<div id="section-2">
  ## Использование
</div>

<Note>
  Replit App должен пройти аутентификацию в Google Cloud Storage, чтобы получить доступ к bucket и его объектам.
  Для автоматической аутентификации используйте официальную клиентскую библиотеку App Storage от Replit.
</Note>

Инструмент App Storage доступен прямо из редактора проекта.

<Accordion title="Как открыть инструмент App Storage">
  Через **док инструментов** слева:

  1. Выберите <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Иконка всех инструментов" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **Все инструменты**, чтобы открыть список инструментов редактора проекта.
  2. Выберите <img class="icon-svg" src="/assets/mirror/object-storage-monoochrome-icon-aaba8f517280.svg" alt="Иконка App Storage" width="16" height="16" data-path="images/icons/object-storage-monoochrome-icon.svg" /> **App Storage**.

  Через **строку поиска**:

  1. Нажмите на <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="Иконка лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> лупу вверху, чтобы открыть инструмент поиска.
  2. Введите «App Storage» и выберите нужный инструмент в результатах.
</Accordion>

Чтобы связать новый bucket с вашим Replit App, создайте bucket.

<Accordion title="Как создать bucket">
  В инструменте **App Storage**:

  1. Нажмите **Создать новый bucket**.
  2. Введите имя bucket в поле **Имя** и выберите **Создать bucket**.

  Вкладка App Storage будет выглядеть так, как на скриншоте ниже:

  <Frame>
    <img src="/assets/mirror/object-storage-empty-bucket-3462e2efb1bc.png" alt="Скриншот инструмента App Storage" width="2790" height="1218" data-path="images/databases/object-storage-empty-bucket.png" />
  </Frame>

  Чтобы создать дополнительные bucket, откройте выпадающее меню bucket в левом верхнем углу вкладки **App Storage** и выберите **Создать новый bucket**.
</Accordion>

<div id="id">
  ### Доступ к идентификатору bucket
</div>

Чтобы посмотреть **идентификатор bucket**, выберите представление **Настройки** в выпадающем списке в верхней части вкладки **Хранилище App**.
Идентификатор bucket однозначно определяет bucket, и код должен ссылаться на него при выполнении операций.

Если у вас несколько bucket, выберите нужный в выпадающем меню в левом верхнем углу.

<div id="section-4">
  ### Загрузка и скачивание объектов
</div>

Чтобы загрузить объекты в выбранный бакет:

1. Перейдите в представление **Объекты** на вкладке **Хранилище App**.
2. Выберите <img class="icon-svg" src="/assets/mirror/upload-file-5894be4232ce.svg" alt="Иконка загрузки файла" width="16" height="16" data-path="images/icons/upload-file.svg" /> **Загрузить файл** или, чтобы загрузить все файлы папки, <img class="icon-svg" src="/assets/mirror/upload-folder-fc87519bedf9.svg" alt="Иконка загрузки папки" width="16" height="16" data-path="images/icons/upload-folder.svg" /> **Загрузить папку**.
   Затем выберите один или несколько файлов в диалоговом окне.
   Либо перетащите файлы или папки в область, где отображается содержимое бакета.

Чтобы скачать объекты из выбранного бакета:

1. Перейдите в представление **Объекты** на вкладке **Хранилище App**.
2. Справа от нужного файла выберите <img class="icon-svg" src="/assets/mirror/download-icon-c7b527953d65.svg" alt="Иконка скачивания" width="16" height="16" data-path="images/icons/download-icon.svg" /> иконку скачивания.

<div id="section-5">
  ### Организация объектов по папкам
</div>

Чтобы создать папку в выбранном бакете:

1. Перейдите к представлению **Объекты** на вкладке **Хранилище App**.
2. В представлении **Объекты** выберите <img class="icon-svg" src="/assets/mirror/create-folder-c9acf112a042.svg" alt="Иконка создания папки" width="16" height="16" data-path="images/icons/create-folder.svg" /> **Создать папку**.
3. Введите имя папки.

Чтобы добавить объект в папку в представлении **Объекты**, перетащите объект в нужную папку.

Чтобы переместить объект в родительскую папку, перетащите его на заголовок над списком объектов — к имени папки, расположенному над списком.

<div id="section-6">
  ### Удаление объекта или бакета
</div>

<Warning>
  Удаление необратимо. Перед продолжением создайте резервную копию важных данных.
</Warning>

Чтобы безвозвратно удалить объект:

1. На вкладке **Хранилище App** перейдите в представление **Объекты**.
2. Рядом с нужным объектом выберите иконку корзины <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="Иконка корзины" width="16" height="16" data-path="images/icons/trash-icon.svg" />.
3. Подтвердите удаление в появившемся диалоговом окне.

Чтобы удалить бакет и все объекты в нём:

1. На вкладке **Хранилище App** перейдите в представление **Настройки**.
2. В выпадающем меню бакетов в левом верхнем углу выберите бакет, который нужно удалить.
3. Выберите <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="Иконка корзины" width="16" height="16" data-path="images/icons/trash-icon.svg" /> **Удалить бакет**.
4. Подтвердите удаление в появившемся диалоговом окне.

<div id="section-7">
  ### Управление доступом к bucket
</div>

Replit подключает все созданные вами bucket к аккаунту и делает их доступными во всех Replit App. Replit App, в котором был создан bucket, автоматически получает права доступа к нему.

Управляя тем, какие Replit App имеют доступ к конкретному bucket, вы можете обмениваться данными эффективно и безопасно.

Чтобы предоставить Replit App доступ к bucket из другого приложения вашего аккаунта:

1. В меню bucket в левом верхнем углу вкладки хранилища App выберите <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="иконка лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" />
   **Добавить существующий bucket**.
2. В диалоговом окне **Выбор bucket** выберите нужный bucket и нажмите **Добавить bucket в Repl**.

<Frame>
  <img src="/assets/mirror/choose-bucket-dialog-b709aa247a85.png" alt="Скриншот диалогового окна выбора bucket" width="1115" height="457" data-path="images/databases/choose-bucket-dialog.png" />
</Frame>

Чтобы отозвать у Replit App доступ к bucket:

1. Перейдите в раздел **Настройки** на вкладке **Хранилище App**.
2. Выберите имя bucket в выпадающем списке bucket в левом верхнем углу вкладки.
3. Выберите **Удалить bucket AI из Repl** и подтвердите удаление в диалоговом окне.

О том, как работать с клиентскими библиотеками, см. следующие материалы:

* [Python App Storage SDK](/ru/ja/features/sdks/object-storage-python-sdk/): клиентский справочник по Python SDK
* [Пример приложения на Google Cloud Python SDK](https://replit.com/@matt/GCS-Python-Uploads?v=1): сделайте ремикс этого приложения, чтобы управлять объектами с помощью Google Cloud Python SDK
