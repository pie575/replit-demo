把你的应用变成一门生意。Replit 可与支付服务商集成，助你收取付款、销售订阅，为网页和移动应用实现变现。

<div id="section">
  ## 工作原理
</div>

只需告诉 Agent 你要对什么收费，其余的都交给它：连接支付服务商、构建支付或付费墙界面、接入支付逻辑。正式上线前，你可以安全地测试所有环节。

Replit 支持面向网页应用和原生移动应用的多种变现集成：

* **[Whop 支付](/zh/ko/features/monetization/whop-payments)** (网页应用) ：以最少的步骤销售数字产品、会员和订阅。Agent 会为你创建 Whop 账户——无需外部设置或 API 密钥——让你快速完成首笔销售。
* **[Stripe 支付](/zh/ko/features/monetization/stripe-payments)** (网页应用) ：接受一次性付款、销售订阅，或构建完整店面。Agent 会连接 Stripe 沙盒，让你在正式上线前测试支付流程。
* **[RevenueCat 订阅](/zh/ko/features/monetization/revenuecat-subscriptions)** (移动应用) ：为原生移动应用添加应用内订阅。Agent 会配置 RevenueCat、构建付费墙页面，并开启测试模式，让开发期间的购买以模拟方式进行。

如果要销售涉及库存和配送的实物商品，请参阅 [Shopify 集成](/zh/ko/features/integrations/shopify)。

<div id="section-2">
  ## 选择合适的集成方案
</div>

|             | Whop               | Stripe               | Shopify            | RevenueCat                     |
| ----------- | :----------------- | :------------------- | :----------------- | :----------------------------- |
| **最适合**     | 步骤最少，最快完成首笔销售      | 网页端的灵活性与可扩展性         | 实物商品               | 原生移动应用                         |
| **支付类型**    | 数字产品、会员、订阅         | 一次性支付、订阅、店面          | 含库存与配送的实物商品        | 应用内订阅                          |
| **外部设置**    | 起步时无需设置            | 起步时无需设置 (Stripe 沙盒)  | 起步时无需设置            | 起步时无需设置 (测试模式)                 |
| **切换至正式环境** | 完成身份验证 (KYC) 后即可提现 | 连接正式的 Stripe 账户      | Shopify 店铺计费       | 提交至 App Store 或 Google Play 审核 |
| **所需账户**    | Whop 账户 (自动创建)     | Stripe 账户            | Shopify 店铺 (自动预置)  | RevenueCat 账户                  |

<div id="section-3">
  ## 开始使用
</div>

最快的入门方式就是直接向 Agent 提需求：

* **快速销售数字产品**：&quot;添加 Whop 支付以销售会员资格&quot; —— 参见 [Whop 支付](/zh/ko/features/monetization/whop-payments)
* **网页应用**：&quot;为我的应用添加 Stripe 支付&quot; —— 参见 [Stripe 支付](/zh/ko/features/monetization/stripe-payments)
* **移动应用**：&quot;为我的应用添加每月 $5.99 的订阅&quot; —— 参见 [RevenueCat 订阅](/zh/ko/features/monetization/revenuecat-subscriptions)

Agent 会连接集成、构建界面，并配置好测试环境，让你可以立即上手试用。
