Créez du contenu visuel pour vos applications grâce aux capacités de génération d&#39;images <img class="icon-svg" src="/assets/mirror/image-13b737955126.svg" alt="Icône de génération d'images" width="24" height="24" data-path="images/icons/image.svg" /> d&#39;Agent.

Transformez vos idées en images, illustrations et graphiques personnalisés qui répondent parfaitement aux besoins de votre projet. Que vous créiez un site web, une application mobile ou tout autre projet créatif, Agent génère des images qui donnent vie à votre vision.

  <img src="/assets/mirror/imagegen-9f03c63734cf.png" alt="Agent générant des images par IA pour le développement d'applications" width="870" height="482" data-path="images/image-generation/imagegen.png" />
</Frame>

La génération d&#39;images permet aux créateurs de produire du contenu visuel unique sans compétences en design ni outils externes. Générez aussi bien des icônes et des illustrations que des arrière-plans et des éléments d&#39;interface, directement dans votre flux de développement.

<div id="features">
  ## Fonctionnalités
</div>

Créez des applications visuellement percutantes grâce à la génération d&#39;images d&#39;Agent. Fini les photos d&#39;archives, les outils de design externes ou le recours à des graphistes pour du contenu visuel de base. Que vous créiez un site portfolio, un jeu ou l&#39;interface d&#39;une application mobile, la génération d&#39;images vous fournit des visuels sur mesure, adaptés à votre projet.

Agent peut réaliser les actions de génération d&#39;images suivantes :

* **Création d&#39;images personnalisées** : générez des images à partir de descriptions et de spécifications détaillées
* **Adaptation du style** : créez des images dans divers styles artistiques, du réalisme au dessin animé
* **Arrière-plans transparents** : générez des images en PNG transparent, ou supprimez l&#39;arrière-plan d&#39;une image existante — idéal pour les logos, icônes, autocollants et détourages de produits
* **Intégration au projet** : ajoutez les images générées directement à la base de code de votre application, en toute fluidité
* **Amélioration itérative** : modifiez et perfectionnez les images en fonction de vos retours

<div id="usage">
  ## Utilisation
</div>

La génération d&#39;images est intégrée à Agent : aucune option à activer. Ouvrez n&#39;importe quelle Replit App dans laquelle Agent est activé et demandez à Agent de créer le contenu visuel dont vous avez besoin. Agent détermine automatiquement quand générer des images en fonction de vos demandes et crée des images personnalisées conformes à vos spécifications.

<div id="when-agent-uses-image-generation">

Agent déclenche la génération d&#39;images lorsque vous demandez du contenu visuel pour vos projets :

| ------------------------------------- | -------------------------------------------------------------------------------- |
| **Icônes et logos d&#39;application** | « Génère un logo moderne pour mon application de suivi d&#39;activité physique » |

| **Illustrations d&#39;interface**     | « Crée une illustration pour l&#39;écran vide de mon application »               |

| **Logos et icônes transparents**      | « Génère un logo avec un arrière-plan transparent pour mon application »         |

<div id="best-practices-for-image-generation">
  ### Bonnes pratiques pour la génération d&#39;images
</div>

Suivez ces conseils pour tirer le meilleur parti de la génération d&#39;images d&#39;Agent :

**Soyez précis et descriptif**

* Donnez des détails sur le style, les couleurs, la composition et l&#39;ambiance
* Précisez les dimensions ou le format lorsque c&#39;est pertinent
* Mentionnez l&#39;usage prévu (icône, arrière-plan, illustration, etc.)
* Demandez un arrière-plan transparent lorsque vous avez besoin d&#39;un logo, d&#39;une icône, d&#39;un autocollant ou d&#39;un détourage à superposer à un autre contenu

**Itérez et affinez**

* Commencez par une description simple, puis affinez-la en fonction des résultats
* Demandez à Agent de modifier des aspects précis des images générées
* Demandez des variantes pour explorer différentes directions créatives

**Tenez compte du style de votre projet**

* Maintenez une cohérence visuelle dans toute votre application
* Indiquez des préférences de style conformes à votre marque ou à votre système de design
* Demandez des images qui s&#39;accordent avec vos éléments visuels existants

<div id="project-integration">
  ### Intégration au projet
</div>

Agent intègre les images générées à votre base de code en toute fluidité :

* **Création automatique de fichiers** : les images générées sont enregistrées directement dans les fichiers de votre projet
* **Mise à jour du code** : Agent met à jour votre code pour référencer les nouveaux fichiers image
* **Organisation des ressources** : les images sont placées dans des répertoires cohérents au sein de la structure de votre projet

Grâce à ce flux de travail simplifié, vous pouvez générer et intégrer du contenu visuel sans quitter votre environnement de développement.

<Note>
  La génération d&#39;images de Replit s&#39;appuie sur [Imagen 4 de
  Google](https://deepmind.google/models/imagen/), un modèle texte-image de
  pointe qui excelle dans la création d&#39;images photoréalistes de haute qualité,
  avec des détails fins et un rendu du texte amélioré.
</Note>
