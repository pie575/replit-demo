Replit Agent 可通过 [Model Context Protocol (MCP) ](https://modelcontextprotocol.io) 连接数百种外部工具和数据源——这是一项用于集成 AI 工具的开放标准。请登录预置服务器，或添加可信的自定义 MCP 服务器。

<div id="mcp">
  ## 连接预置 MCP 服务器
</div>

Replit 提供精选的 MCP 服务器列表，可连接 Stripe、Linear、Notion 和 Sentry 等热门服务。只需点击一次登录，即可完成连接。

<Frame>
  <img src="/assets/mirror/mcp-servers-pane-8e1f431ca33c.png" alt="Replit Agent 的 MCP 服务器设置面板，列出了 Stripe、Linear、Notion、Sentry、Atlassian、Miro、PostHog、Amplitude、Mixpanel、Granola 和 Razorpay 等预置服务器，并提供登录按钮。" width="3452" height="1988" data-path="images/replitai/mcp-servers-pane.png" />
</Frame>

<Steps>
  <Step title="打开集成面板">
    前往 [replit.com/integrations](https://replit.com/integrations)，然后滚动至 **Replit Agent 的 MCP 服务器**。
  </Step>

  <Step title="选择服务器">
    找到要连接的服务，例如 Stripe、Linear、Notion、Sentry、Atlassian、Miro、PostHog、Amplitude、Mixpanel、Granola 或 Razorpay。
  </Step>

  <Step title="登录">
    点击服务器旁的**登录**。系统将引导你完成该服务的 OAuth 流程。连接完成后，服务器的连接状态会更新，Agent 即可使用该工具。
  </Step>
</Steps>

完整目录请参阅 [MCP 服务器参考](/zh/ja/features/mcp/overview)。

<div id="mcp-2">
  ## 添加自定义 MCP 服务器
</div>

如果目录中没有你需要的服务器，可以通过 URL 添加。

<Frame>
  <img src="/assets/mirror/mcp-connect-dialog-5b8f9b0d828e.png" alt="MCP 服务器连接对话框，显示名称字段、MCP 服务器 URL 字段和高级设置折叠部分。" width="3452" height="1988" data-path="images/replitai/mcp-connect-dialog.png" />
</Frame>

<Steps>
  <Step title="打开添加服务器对话框">
    在 MCP 服务器设置面板中，点击**+ 添加 MCP 服务器**。
  </Step>

  <Step title="设置显示名称">
    输入一个易于识别的名称 — Agent 在聊天记录中引用该服务器时会使用此名称。
  </Step>

  <Step title="输入服务器 URL">
    粘贴 MCP 服务器的 HTTPS 端点。如果服务器需要认证，请打开**高级设置**并添加自定义标头 (例如：`X-API-Key`) 。
  </Step>

  <Step title="测试并保存">
    点击**测试并保存**。Replit 会尝试建立连接，并引导你完成服务器所需的 OAuth 流程。保存后，该连接会显示在 MCP 服务器列表中，并附带状态信息。
  </Step>
</Steps>

<Warning>
  请仅连接受信任的 MCP 服务器。已连接的服务器可向 Agent 提供工具和数据 — 添加未知端点前，请先确认其来源。
</Warning>

<div id="agentmcp">
  ## 在 Agent 中使用 MCP 工具
</div>

服务器连接后，Agent 会自动获取工具列表，并可在所有项目中使用这些功能。要使用服务器，只需在聊天中提及它：

> 请使用 Notion MCP 服务器查找最新的会议记录。

<Frame>
  <img src="/assets/mirror/tool-call-7a53f51a11ae.png" alt="Agent 正在聊天中调用自定义 MCP 服务器的工具" width="571" height="817" data-path="images/replitai/custom-mcp/tool-call.png" />
</Frame>

Agent 会根据你的请求从服务器中选择合适的工具。如果工具需要确认，会在执行前显示提示。
