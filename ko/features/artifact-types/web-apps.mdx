웹 앱은 Replit의 기본 출력 유형입니다. Agent에게 아이디어를 설명하면 다른 artifact 유형을 지정하지 않는 한 full-stack 웹 애플리케이션을 만들어 줍니다.

<div id="getting-started">
  ## 시작하기
</div>

웹 앱을 만드는 방법은 두 가지입니다:

* **프롬프트 입력**: Replit 홈페이지에서 만들고 싶은 것을 설명하세요. Agent가 자동으로 웹 앱을 생성합니다.
* **드롭다운에서 선택**: 홈페이지에서 앱 유형 드롭다운을 열어 **웹 앱**을 선택한 다음, 아이디어를 설명하세요.

<div id="key-features">
  ## 주요 기능
</div>

* **기본이 full-stack**: 모든 웹 앱에는 frontend와 backend가 포함됩니다. Agent가 앱에 필요한 API 라우트, database, 서버 측 로직을 알아서 구성합니다.
* **반응형 디자인**: 앱이 다양한 화면 크기에 자동으로 맞춰집니다.
* **즉시 publish**: 클릭 한 번으로 앱을 publish하세요. 호스팅, SSL, 인프라는 Replit이 처리합니다.
* **인프라 공유**: project에 mobile app이나 data dashboard처럼 여러 artifact가 있어도 모두 동일한 backend, database, 서비스를 공유합니다.

<div id="use-cases">
  ## 활용 사례
</div>

* **SaaS 제품**: 고객용 도구, 대시보드, 플랫폼을 구축합니다.
* **내부 도구**: 팀을 위한 관리자 패널, CRM, 워크플로우 앱을 만듭니다.
* **랜딩 페이지**: 폼, 애니메이션, 동적 콘텐츠를 갖춘 마케팅 사이트를 출시합니다.
* **마켓플레이스와 디렉터리**: 리스팅 사이트, 채용 게시판, 커뮤니티 플랫폼을 구축합니다.
