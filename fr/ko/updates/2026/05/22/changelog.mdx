<div id="visual-editor">
  ### Contrôles de mise en page du Visual Editor
</div>

Le Visual Editor dispose désormais de contrôles de **mise en page** dédiés, qui permettent d&#39;ajuster visuellement les mises en page flexbox sans demander à Agent de réécrire les styles. Sélectionnez un conteneur, développez la section Mise en page, puis choisissez la direction du flex, l&#39;alignement et la répartition. Définissez un espacement en pixels entre les éléments, ou activez l&#39;option **Space between** pour repousser les éléments enfants vers les bords opposés.

Le panneau de l&#39;éditeur a également été réorganisé en sections plus claires — **Texte**, **Image**, **Mise en page**, **Couleurs** et **Bordures** — afin de trouver plus facilement les contrôles dont vous avez besoin.

<div id="agent-2">
  ### Dans les projets partagés, les paramètres d&#39;Agent restent les vôtres
</div>

Vos préférences Agent — niveau de modèle, mode plan, fusion automatique et approbation automatique des plans — vous sont désormais propres et ne sont plus partagées avec l&#39;ensemble des personnes du projet. Si un membre de votre équipe passe en Power Mode pour son propre travail, vos paramètres n&#39;en sont plus affectés. Lors de votre prochain message, Agent utilisera les paramètres que vous avez choisis, y compris dans les projets comptant de nombreux collaborateurs.

En savoir plus sur les [modes Agent](/fr/ko/features/agent/agent-modes#settings-in-shared-projects).

<div id="agent-power-mode">
  ### Agent propose le mode Power en cas de blocage
</div>

Lorsque Agent détecte qu&#39;il se heurte au même problème à répétition en mode Economy, il propose désormais de passer à Power dans le message suivant. Cette suggestion se déclenche en cas de demandes répétées ou de code qui échoue continuellement, et apparaît au maximum une fois par projet. Agent n&#39;affiche pas la suggestion pendant les sessions de planification, si vous avez déjà évoqué des contraintes budgétaires ou si vous utilisez un plan gratuit.

<div id="section-3">
  ### Menu déroulant des paramètres de tâche épuré
</div>

Le menu déroulant qui s&#39;ouvre depuis l&#39;en-tête de tâche est désormais plus simple à utiliser. Le titre de la tâche ou du plan actif figure en haut, avec renommage en ligne ; les paramètres d&#39;automatisation (application automatique, approbation automatique) occupent leur propre section entre le titre et les actions ; et le popover a une largeur fixe, ce qui évite tout décalage lorsque le nom de la tâche change. Les lignes d&#39;automatisation désactivées sont masquées : le menu n&#39;affiche donc que ce qui s&#39;applique à la tâche en cours.

<div id="quiver-ai-browserbase">
  ### Deux nouveaux connecteurs : Quiver AI et Browserbase
</div>

Deux services supplémentaires sont désormais disponibles dans le catalogue de connecteurs. Ouvrez le panneau **Intégrations** et sélectionnez **Ajouter une nouvelle intégration** pour établir la connexion.

* **Quiver AI** : générez des illustrations SVG et vectorisez des images matricielles via une API gérée. Pratique lorsque Agent a besoin de ressources SVG nettes.
* **Browserbase** : lancez un navigateur headless géré pour la récupération de contenu, la recherche et l&#39;automatisation de sessions complètes. Pratique lorsque Agent doit charger de véritables pages web, exécuter du JavaScript ou interagir avec des sites qui bloquent les requêtes HTTP classiques.
