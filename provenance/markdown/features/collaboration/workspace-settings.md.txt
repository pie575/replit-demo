# Workspace Settings

> Find Workspace, account, and personal settings for collaborators, integrations, usage, security, and more.

Use this page to find Workspace settings and the adjacent account and user
controls available from the same Settings dialog.

## Open Settings

1. Select your account menu in the lower-left corner of Replit.
2. Select **Settings**.

<Note>
  The available tabs depend on your Workspace type, plan, and role. Admin-only
  options appear only when you have permission to manage them.
</Note>

## Workspace settings

Use the **Workspace** section to manage the currently selected Workspace:

* **Workspace overview**: Update the Workspace image or name and view its ID.
* **Workspace collaborators**: Invite people and manage Workspace access.
* **Integrations**: Manage services and resources connected to the Workspace.
* **Customization**: Configure workspace-wide custom instructions, skills, and Memory for Agent. See [Agent customization](/features/agent/agent-customization) for setup and permissions.
* **Design systems** and **Slides templates**: Manage reusable design guidance and presentation templates for your organization. Both are Enterprise features — see [Design systems](/teams/custom-design-system) and [Custom templates](/teams/custom-templates).
* **Security**: Review the security controls that apply to the Workspace. See [Security overview](/features/security/overview).
* **Groups**: Organize members and apply group permissions. See [Groups and permissions](/teams/identity-and-access-management/groups-and-permissions).

## Account settings

Use the **Account** section for settings that can apply across Workspaces:

* **Usage**, **Billing**, and **Account seats**: Review usage and billing information and manage seats when your role allows it.
* **Advanced**: Find advanced account controls, including Agent model-provider policies. See [Model controls](/features/collaboration/enterprise-model-controls) for the Enterprise provider and per-Workspace workflow.
* **Developer**: Manage Admin API keys and review request history. See [Admin API](/teams/admin-api) before creating or rotating a key.

## User settings

Use the **User** section for your own **Profile** and **Personalization** preferences. The same section also links to the Replit Community.
