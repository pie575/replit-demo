Console позволяет в реальном времени отслеживать и просматривать логи, которые выводит ваш запущенный Replit App.
Данные текущего и прошлых запусков помогут понять поведение приложения,
устранить ошибки и оптимизировать производительность.

<Tip>
  При отладке с помощью Agent добавляйте логи консоли в prompt, чтобы передать context.
</Tip>

<div id="features">
  ## Возможности
</div>

Console предоставляет следующие инструменты, которые помогут разобраться в работе вашего App:

* **Логирование в реальном времени**: просматривайте вывод App по мере его появления
* **Помощь ИИ**: получайте предложения по исправлению ошибок, обнаруженных в логах
* **История запусков**: просматривайте логи предыдущих запусков, чтобы отслеживать изменения

<div id="usage">
  ## Использование
</div>

Инструмент Console доступен прямо в Project Editor.

<Accordion title="Как открыть Console">
  На левой панели **Tool dock**:

  1. Выберите <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="All tools icon" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**, чтобы увидеть список инструментов Project Editor.
  2. Выберите <img class="icon-svg" src="/assets/mirror/console-8a41ac90789c.svg" alt="Console icon" width="16" height="16" data-path="images/icons/console.svg" /> **Console**.

  Через **строку поиска**:

  1. Нажмите <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="magnifying glass icon" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> значок лупы вверху, чтобы открыть поиск
  2. Введите «Console», чтобы найти инструмент, и выберите его в результатах.
</Accordion>

Каждый раз, когда вы нажимаете кнопку **Run** в своём Replit App, Console добавляет новую запись со следующей информацией:

* Команда, которая выполнила ваш код
* Отметка времени
* Стандартный вывод и логи ошибок

На следующем снимке экрана показана команда `npm run dev`, которой запускается приложение, и лог-сообщения этого запуска:

<Frame>
  <img src="/assets/mirror/console-log-entry-b57e5b89087d.png" alt="Console log entry showing the command run" width="1948" height="870" data-path="images/workspace/console-log-entry.png" />
</Frame>

<Note>
  Клиентские логи, например созданные кодом HTML, CSS и JS, отображаются только в инструментах разработчика в инструменте [Preview](/ru/features/editor/preview).
</Note>

<div id="ai-powered-debugging">
  ### Отладка с помощью ИИ
</div>

Если в логах встретились ошибки или другая информация, в которой нужно разобраться, нажмите
кнопку **Ask AI** в верхней части записи. Автоматически откроется вкладка **Agent**, и
содержимое лога будет отправлено на анализ.

<div id="log-entry-commands">
  ### Команды для записей логов
</div>

Console предоставляет следующие инструменты для работы с логами:

* **Show Only Latest**: переведите этот переключатель в положение **on**, чтобы отображался только последний запуск.
* **Collapse entry**: нажмите на <img class="icon-svg" src="/assets/mirror/down-arrow-9c1cf9fd152e.svg" alt="иконка стрелки вниз" height="16" width="16" data-path="images/icons/down-arrow.svg" /> стрелку вниз слева от имени команды, чтобы скрыть логи.
* **Clear past runs**: выберите этот пункт, чтобы удалить логи предыдущих запусков. Это действие необратимо.

<div id="network-availability">
  ### Доступность в сети
</div>

Вы можете управлять доступностью в интернете версии вашего приложения для разработки.

Чтобы прекратить обработку запросов по URL-адресу для разработки, выберите иконку <img class="icon-svg" src="/assets/mirror/network-off-5bdca8a4fe4e.svg" alt="иконка «сеть выключена»" height="16" width="16" data-path="images/icons/network-off.svg" /> перечёркнутого глобуса
в правой части строки с информацией о сети.

Чтобы снова включить её, выберите иконку <img class="icon-svg" src="/assets/mirror/network-on-15be2e5fb4f5.svg" alt="иконка «сеть включена»" height="16" width="16" data-path="images/icons/network-on.svg" /> глобуса.

Чтобы посмотреть свой URL-адрес для разработки, выберите текст `{...}.replit.dev` в адресной строке.

<Frame>
  <img src="/assets/mirror/preview-dev-url-b36770b33769.png" alt="Расположение URL-адреса для разработки в Preview" width="1222" height="824" data-path="images/workspace/preview-dev-url.png" />
</Frame>

<Note>
  Ваше приложение остаётся доступным в инструменте Preview, даже если обработка запросов по URL-адресу для разработки отключена.
</Note>

<div id="stop-a-workflow-command">
  ### Остановка команды рабочего процесса
</div>

Остановить выполняющуюся команду рабочего процесса можно с помощью инструмента Console в Project Editor.

Чтобы завершить команду запуска вашего Replit App, нажмите квадратную кнопку справа от строки с этой командой.

Чтобы перезапустить приложение, нажмите кнопку рабочего процесса **Run** в верхней части Project Editor.
