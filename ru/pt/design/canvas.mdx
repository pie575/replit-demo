Canvas — это бесконечная поверхность, по которой можно перемещаться и масштабировать, где Replit Design отображает ваши фреймы. Здесь находится всё, что вы создаёте: генерируйте фреймы, перетаскивайте их, приближайте детали и дорабатывайте, пока не получите нужный результат.

<div id="abra-o-canvas">
  ## Откройте Canvas
</div>

Canvas — это первое, что вы видите в Replit Design. В проекте выберите **Design** в шапке, и Canvas займёт всю панель; выберите **Build**, чтобы вернуться к работающему app.

<Frame>
  <img src="/assets/mirror/canvas-design-button-ffa50447cefb.png" alt="Крупный план шапки проекта с переключателем между Design и Build, выбран Design, над фреймами на canvas" width="987" height="619" data-path="images/replitai/canvas-design-button.png" />
</Frame>

Если начать с нуля на [replit.com/design](https://replit.com/design), вам будет предложено создать новый design, который откроется в Canvas. О том, когда использовать каждый из режимов, читайте в разделе [Design vs. Build](/ru/pt/design/design-vs-build).

<div id="o-que-vive-no-canvas">
  ## Что находится на Canvas
</div>

* **Frames**: каждый блок на холсте. Фрейм может быть макетом дизайна, веб-приложением, мобильным приложением, слайдами, изображением, видео или векторной графикой. Создавайте их с помощью prompt в Chat, через [меню «Сгенерировать»](/ru/pt/design/toolbar#generate) на панели инструментов или из [панели библиотеки](/ru/pt/design/library-panel). Всё, что вы делаете с фреймом — «Построить», «Фокус», предложения, — происходит через сам фрейм: см. [Frames](/ru/pt/design/frames).
* **Рисунки и заметки**: пометки, которые вы добавляете с помощью [инструмента «Рисовать»](/ru/pt/design/toolbar#draw): наброски, стрелки, фигуры и стикеры. Agent распознаёт ваши пометки, так что вы можете обвести проблемный участок и попросить внести изменение.
* **Панель чата**: Chat с Agent, закреплённый рядом с Canvas. Если выбрать фреймы перед отправкой сообщения, они прикрепятся как снимки, чтобы у Agent был визуальный контекст.

Чтобы узнать, что представляет собой каждый компонент и как они связаны между собой, см. [обзор компонентов](/ru/pt/design/core-components).

<div id="navegue-pelo-quadro">
  ## Навигация по холсту
</div>

Панорамирование, масштабирование и выделение доступны в любом инструменте, если не указано иное.

**Панорамирование:**

* Трекпад: перетаскивание двумя пальцами.
* Мышь: зажмите среднюю кнопку и перетащите либо удерживайте пробел и перетаскивайте левой кнопкой.
* [Инструмент панорамирование](/ru/pt/design/toolbar#pan): зажмите левую кнопку мыши и перетащите.

**Масштабирование:**

* Трекпад: жест щипка.
* Мышь: `Ctrl` (или `Cmd` в macOS) + колесо прокрутки.
* Клавиатура: `Cmd`/`Ctrl` + `+` — приблизить, `Cmd`/`Ctrl` + `-` — отдалить, `Cmd`/`Ctrl` + `0` — сбросить масштаб.

Масштабирование привязано к курсору: точка под курсором остаётся на месте, а остальной холст масштабируется вокруг неё.

**Выделение:**

* Один фрейм: щёлкните по нему [инструментом взаимодействие](/ru/pt/design/toolbar#interact).
* Несколько фреймов: удерживайте `Shift` и щёлкайте по каждому фрейму либо растяните рамку выделения по холсту.
* Снять выделение: щёлкните по пустой области или нажмите `Escape`.

При выделении одного или нескольких фреймов появляется [панель действий фрейма](/ru/pt/design/frames#per-frame-action-bar), а сами фреймы прикрепляются к следующему сообщению Agent в виде снимков.

<div id="atalhos-de-teclado">
  ### Сочетания клавиш
</div>

| Сочетание                      | Действие                                      |
| ------------------------------ | --------------------------------------------- |
| `V`                            | Включить инструмент «Взаимодействие»          |
| `H`                            | Включить инструмент «Панорамирование»         |
| Удерживая `Пробел`, перетащить | Панорамировать при любом активном инструменте |
| `Cmd` / `Ctrl` + прокрутка     | Масштабирование                               |
| `Cmd` / `Ctrl` + `+`           | Приблизить                                    |
| `Cmd` / `Ctrl` + `-`           | Отдалить                                      |
| `Cmd` / `Ctrl` + `0`           | Сбросить масштаб                              |
| `Shift` + щелчок               | Добавить фрейм к текущему выделению           |
| `Cmd` / `Ctrl` + `Shift` + `C` | Скопировать выбранный фрейм как PNG           |
| `Escape`                       | Снять выделение                               |

<div id="menu-do-boto-direito">
  ## Контекстное меню
</div>

Щёлкните правой кнопкой мыши в любом месте Canvas, чтобы открыть контекстное меню. Состав меню зависит от того, что находится под курсором: для фрейма доступны действия с фреймом, для пустого Canvas — действия на уровне Canvas, а для фреймов App дополнительно доступно действие **Обновить артефакт**.

Для выбранного фрейма меню содержит:

| Действие                                   | Сочетание клавиш              | Описание                                                                           |
| ------------------------------------------ | ----------------------------- | ---------------------------------------------------------------------------------- |
| Редактировать                              |                               | Переключиться на инструмент редактирования, чтобы выбирать элементы внутри фрейма. |
| Chat                                       |                               | Обсудить фрейм с Agent.                                                            |
| Фокус                                      |                               | Перейти в [режим фокуса](/ru/pt/design/frames#focus-mode) для фрейма.                 |
| Chat по курсору                            | `/`                           | Начать быстрый чат в позиции курсора.                                              |
| Изменить порядок                           |                               | Переместить фрейм вперёд или назад в порядке наложения.                            |
| Копировать, Вставить, Дублировать, Удалить | `⌘C`, `⌘V`, `⌘D`, `Backspace` | Стандартные действия с буфером обмена и фреймами.                                  |
| Экспортировать как…                        |                               | Экспортировать фрейм в файл.                                                       |
| Выбрать всё                                | `⌘A`                          | Выбрать все фреймы на холсте.                                                      |

<div id="exportar-um-frame-como-png">
  ### Экспорт фрейма в PNG
</div>

Сохраните любой артефакт или фрейм дизайна как PNG-изображение. Это удобно, чтобы поделиться предпросмотром в документе или чате, сохранить снимок перед дальнейшими итерациями или отправить снимок экрана коллеге.

<Steps>
  <Step title="Выберите фрейм">
    Выберите артефакт или фрейм дизайна, который хотите экспортировать, затем дождитесь его полной загрузки.
  </Step>

  <Step title="Выберите «Экспортировать»">
    На панели действий фрейма выберите **Экспортировать**. Также можно щёлкнуть фрейм правой кнопкой мыши и выбрать **Экспортировать как…** &gt; **PNG**. Изображение будет сохранено на вашем компьютере, а имя файла будет основано на имени фрейма.
  </Step>
</Steps>

Чтобы скопировать выбранный фрейм как PNG вместо скачивания, нажмите `Cmd+Shift+C` (или `Ctrl+Shift+C` в Windows и Linux).

<Note>Экспортированный PNG соответствует тому, что сейчас отображается во фрейме на Canvas. Если ваше приложение или дизайн всё ещё загружается, дождитесь полной отрисовки перед экспортом.</Note>

<div id="o-canvas-e-o-app-em-execuo">
  ## Canvas и запущенный app
</div>

Canvas и предпросмотр запущенного app находятся в одной панели, а некоторые режимы связывают их между собой:

* **Режим фокуса**: действие **Фокус** для выбранного фрейма разворачивает его на всю область просмотра. Чтобы вернуться на canvas, выберите **Выйти из фокуса** в верхней части области.
* **Режим только для чтения**: когда canvas заблокирован в контексте фоновой задачи, действия по доработке скрыты и доступен только фокус.

<Note>
  Для создания нового app на основе фрейма из Design нужен тариф Core или Pro; все остальные возможности canvas доступны на любом тарифе. Подробности о тарифах см. в разделе [Billing](/ru/pt/billing/ai-billing).
</Note>
