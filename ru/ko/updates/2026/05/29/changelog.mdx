<div id="replit-enterprise">
  ### Переход на Enterprise, не покидая Replit
</div>

Теперь перейти на Replit Enterprise можно с любого тарифа — бесплатного, Core или Pro — не покидая продукт и не обращаясь предварительно в отдел продаж. Если у вас есть совместное рабочее пространство, после оплаты оно автоматически перенесётся в новую организацию Enterprise. Опубликованные приложения продолжат работать без простоев.

<div id="stripe">
  ### Подключение Stripe через установку приложения — без копирования ключей
</div>

Запускать приложения с Stripe стало проще. Вместо того чтобы копировать рабочие ключи API из панели управления Stripe, теперь достаточно установить приложение Replit Integrated Payments из Stripe Marketplace. Ключи для рабочей среды подключатся автоматически. Откройте панель публикации, установите приложение и завершите подключение на стороне Stripe.

Создавайте продукты и тестируйте транзакции прямо в Replit.» Кнопки «Закрыть» и «Подключить Stripe»." width="2678" height="1448" data-path="images/billing/stripe-replit-integrated-payments.png" />

<div id="tripo3d-3d">
  ### Создание 3D-моделей с помощью коннектора Tripo3D
</div>

Tripo3D теперь доступен в каталоге коннекторов. Попросите Agent создать 3D-модель по текстовому описанию или изображению. Пригодится для игр, макетов продуктов и AR-сценариев. Использование оплачивается кредитами Replit.

<div id="agent-2">
  ### Agent может создавать музыку, звуковые эффекты и озвучку
</div>

Теперь Agent может создавать аудио для ваших приложений. Попросите фоновую музыку, звуковой эффект или голосовую озвучку — Agent сгенерирует аудио и добавит его прямо в проект. Использование оплачивается кредитами Replit.

  ## Рабочее пространство
</div>

<div id="canvas">
  ### Создание медиа прямо на Canvas
</div>

Теперь медиафайлы можно создавать прямо на Canvas. Откройте инструмент **Создать** на панели инструментов Canvas и выберите **Изображение**, **Векторную графику** или **Видео**, чтобы сгенерировать их на месте. Весь процесс остаётся на доске, так что вы можете проектировать и дорабатывать дизайн, не переключаясь между инструментами.
