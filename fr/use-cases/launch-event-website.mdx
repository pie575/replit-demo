Créez un site web complet pour un événement payant avec le programme, les intervenants, le lieu, l’itinéraire et le
checkout des billets. Enregistrez les participants dans Replit Database, acceptez les paiements avec Stripe, envoyez une
confirmation avec Resend et exportez la liste. Effectuez une commande de test avant de partager le
lien.

<div id="best-for">
  ## Idéal pour
</div>

* Les responsables marketing événementiel qui ont besoin d&#39;une page publique et de billets payants pour une conférence, une rencontre ou un lancement.
* Les responsables de communauté qui souhaitent pouvoir modifier le programme dans l&#39;app, sans système de gestion de contenu distinct.

<div id="before-you-start">
  ## Avant de commencer
</div>

Munissez-vous du nom de l&#39;événement, des dates, du lieu, du prix des billets et d&#39;une base de données Notion pour les intervenants (nom, photo,
session). Connectez Notion, Resend et Stripe. Agent crée le checkout dans l&#39;App.

<div id="prompt-the-agent">
  ## Donnez un prompt à l’Agent
</div>

<AiPrompt>
  Créez un site web complet pour un événement payant à partir de cette page Notion [link] : programme,
  intervenants, lieu, accès et checkout des billets. Utilisez les noms, photos,
  titres, biographies et horaires des sessions des intervenants depuis Notion. Facturez [price] par billet avec
  Stripe. Enregistrez les participants dans Replit Database, envoyez une confirmation avec Resend et
  exportez la liste.
</AiPrompt>

<div id="what-to-expect">
  ## À quoi vous attendre
</div>

Agent crée le site public et met en place le checkout, le paiement, la confirmation et la liste
des participants. Effectuez une commande test avant de partager le lien. Utilisez le mode test de Stripe et une carte de test,
puis vérifiez que la confirmation est bien reçue, que le participant figure dans la liste et que l’exportation l’inclut
avant de passer aux paiements réels.

<div id="troubleshooting">
  ## Dépannage
</div>

* **L&#39;e-mail de confirmation n&#39;arrive jamais :** vérifiez que Resend est connecté et que le domaine expéditeur est vérifié. Passez une commande test et consultez le dashboard Resend pour vérifier si l&#39;e-mail a été envoyé.
* **Les intervenants ou les horaires sont incorrects :** indiquez à Agent la base de données Notion (nom, photo, titre, biographie, horaires des sessions) et demandez-lui de maintenir la page synchronisée avec les modifications apportées dans Notion.
* **Le checkout ne débite pas :** vérifiez que Stripe est connecté et que vous êtes d&#39;abord en mode test. Passez une commande test avant de partager le lien.
