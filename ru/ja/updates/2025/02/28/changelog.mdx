<div id="agent-v2">
  ### Agent v2
</div>

<img src="/assets/mirror/agent-web-01b1f9026de7.webp" alt="Agent v2" width="800" height="450" data-path="images/changelog/2025-02-28/agent-web.webp" />

Новый Agent теперь доступен всем разработчикам. Он работает быстрее, точнее и умеет больше, чем предыдущая версия.

В его основе — Claude 3.7 Sonnet, самая продвинутая на сегодняшний день ИИ-модель Anthropic.

Попробовать его можно, присоединившись к программе Explorer. Инструкции смотрите [здесь](https://youtu.be/pE_XT2TaXCA).

<div id="section-3">
  ### Улучшения деплоя
</div>

Теперь ИИ подсказывает разработчикам, которые выбирают статический деплой для динамических приложений, а поведение Agent при обработке запросов на деплой стало лучше.

<img src="/assets/mirror/deployments-debugger-will-now---non-static-app-220824-748b5209b50c.png" alt="Улучшения отладчика деплоя" width="1604" height="1244" data-path="images/changelog/2025-02-28/deployments-debugger-will-now---non-static-app-220824.png" />

<div id="claude-37-sonnet">
  ### Выпуск Claude 3.7 Sonnet
</div>

Для всех пользователей платных тарифов режим Advanced в Ассистенте обновлён до Claude 3.7 Sonnet. Это повышает точность и возможности при обработке сложных запросов.

<div id="section-4">
  ### Повышение производительности базы данных
</div>

Операции с базой данных стали быстрее, чем когда-либо. Самые ресурсоёмкие из них теперь выполняются менее чем за 1 мс вместо 200 мс.

<div id="section-5">
  ### Улучшения документации
</div>

<img src="/assets/mirror/cleanshot-2025-02-27-at-1042282xpng-220848-e5317a7cfb93.png" alt="Обновлённый дизайн документации" width="3680" height="2382" data-path="images/changelog/2025-02-28/cleanshot-2025-02-27-at-1042282xpng-220848.png" />

Документация получила новый дизайн: она стала понятнее и удобнее, а также полностью дружественной к LLM.

В документации появилась кнопка «Скопировать страницу» — она копирует всю страницу в формате Markdown. Кроме того, документацию можно проиндексировать через `llms.txt` и `llms-full.txt` и использовать в собственной LLM.

* [https://docs.replit.com/llms.txt](https://docs.replit.com/llms.txt)
* [https://docs.replit.com/llms-full.txt](https://docs.replit.com/llms-full.txt)
