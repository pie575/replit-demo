export const YouTubeEmbed = ({videoId, title = "YouTube video", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

## Lancement d'Agent 3

Cette semaine, nous avons lancé Agent 3.

<YouTubeEmbed videoId="4FxNXFOdt6w" title="Agent 3 Launch Livestream" />

Agent 3 apporte des améliorations majeures en matière d'autonomie, de fiabilité et de vitesse :

* **Tests d'applications** : L'Agent s'auto-teste dans un vrai navigateur, trouve les problèmes et les corrige dans une boucle de réflexion. Voir [Tests d'applications](/fr/core-concepts/agent/app-testing).
* **Durée d'exécution prolongée** : L'Agent peut travailler de manière autonome jusqu'à 200 minutes avec la surveillance en direct, idéal pour les constructions plus importantes. En savoir plus dans [Agent](/fr/core-concepts/agent#max-autonomy).
* **Génération d'agents** : Créez des agents et des automatisations qui s'exécutent selon des plannings ou s'intègrent avec Slack et Telegram. Voir [Agents & Automatisations](/fr/core-concepts/agent/agents-and-automations).

## Connecteurs et intégrations d'applications

Développez plus rapidement avec des intégrations et des connecteurs intégrés :

* **Géré par Replit** : Intégrations intégrées qui fonctionnent automatiquement dans vos applications.
* **Connectors** : Intégrations de première partie auxquelles vous pouvez vous connecter une fois et réutiliser dans toutes vos applications.
* **Intégrations externes** : Services tiers de confiance configurés par l'Agent, en utilisant vos clés API.

## Agents & Automatisations (bêta)

Créez des agents intelligents, des chatbots et des flux de travail automatisés dans le cadre d'Agent 3 :

* **Agent Slack** : Créez des Slackbots pour la recherche, les Q\&R et l'automatisation
* **Agent Telegram** : Créez des bots pour la planification, le support et plus encore
* **Automatisation planifiée** : Exécutez des flux de travail planifiés à une cadence régulière
