Enterprise 모델 컨트롤을 사용하면 계정 관리자가 빌더가 선택할 수 있는 Agent 모델을 관리할 수 있습니다. 계정에 대한 정책을 설정한 다음, 개별 워크스페이스에 대해 서로 다른 모델 액세스를 설정하세요.

<Note>
  모델 컨트롤은 Enterprise 계정의 계정 관리자만 사용할 수 있습니다. 조직에서 이 기능을 사용하려면 영업팀([sales@replit.com](mailto:sales@replit.com))에 문의하세요.
</Note>

## 지능형 모델 라우팅 사용하기

지능형 모델 라우팅은 Enterprise 워크스페이스의 기본 Agent 환경입니다. **Auto mode**가 켜져 있으면 품질과 비용의 균형을 맞추면서 Replit이 각 작업에 가장 적합한 모드와 모델을 선택합니다.

라우팅은 계정 및 워크스페이스 정책에서 승인된 모델 풀 내에서 선택됩니다. 이 풀에 포함되지 않은 제공업체와 모델은 선택할 수 없습니다. 빌더는 **Auto mode**를 켜둔 상태로 유지하거나, 끄고 승인된 모델을 직접 선택할 수 있습니다.

<Frame caption="워크스페이스에 승인된 모델 간에 작업을 라우팅하려면 Auto mode를 켜세요.">

라우팅 방식에 대해 자세히 알아보려면 [지능형 모델 라우팅 사용하기](/ko/chat/auto-mode)를 참고하세요.

## Agent 모델 설정 열기

1. **Settings**를 엽니다.
2. **Account**에서 **Advanced**를 선택합니다.
3. **Agent modes and model providers**를 펼칩니다.

<Frame caption="Advanced 설정에 있는 모델 제공업체 정책과 별도의 Fast mode models 컨트롤.">

## 제공업체 정책 설정하기

<Steps>
  <Step>
    관리하려는 모델 제공업체를 선택합니다.
  </Step>

  <Step>
    **Account policy**에서 다음 중 하나를 선택합니다:

    | 옵션                  | 결과                                      |
    | ------------------- | --------------------------------------- |
    | **Enable all**      | 해당 제공업체의 모든 모델을 모든 워크스페이스에서 사용할 수 있습니다. |
    | **Enable selected** | 워크스페이스별로 사용 가능한 모델을 직접 선택합니다.           |
    | **Disabled**        | 어떤 워크스페이스도 해당 제공업체의 모델을 사용할 수 없습니다.     |

    <Note>
      OpenAI, Anthropic, Google 중 최소 하나의 모델은 계속 활성화 상태로 유지해야 합니다. 다른 제공업체는 비활성화할 수 있습니다.
    </Note>
  </Step>

  <Step>
    **Update**를 선택합니다.
  </Step>
</Steps>

오픈소스 모델 제공업체는 기본적으로 비활성화되어 있습니다. 사용하도록 설정하려면 **Enable all** 또는 **Enable selected**를 선택한 다음 **Update**를 선택하세요.

## 워크스페이스 정책 설정하기

워크스페이스마다 서로 다른 모델 액세스가 필요한 경우 **Enable selected**를 사용하세요.

<Frame caption="Enable selected로 설정된 Anthropic 제공업체 정책과 워크스페이스별로 구성된 모델 액세스.">
  <img src="/assets/mirror/anthropic-account-policy-workspace-models-38c0f71a609d.jpg" alt="Enable selected로 설정된 Anthropic 계정 정책과 워크스페이스의 모델 토글" width="2000" height="930" data-path="images/workspace/anthropic-account-policy-workspace-models.jpg" />
</Frame>

1. 제공업체 설정을 엽니다.
2. **Account policy**를 **Enable selected**로 설정합니다.
3. **Workspace** 목록에서 해당 워크스페이스의 **Setting** 드롭다운을 선택합니다.
4. 해당 워크스페이스에서 각 모델을 켜거나 끕니다.
5. **Update**를 선택합니다.

**Update**를 선택하기 전에 **Copy to all**을 선택하면 현재 워크스페이스의 모델 선택을 계정의 모든 워크스페이스에 적용할 수 있습니다.

## 제한 사항

* 모델 정책은 워크스페이스 단위로 적용됩니다. 동일한 워크스페이스 내 사용자 그룹별로 서로 다른 정책을 설정할 수는 없습니다.
* 지능형 모델 라우팅은 계정 또는 워크스페이스 정책을 재정의하지 않습니다. 비활성화된 제공업체나 모델은 선택할 수 없습니다.
* **Agent modes and model providers**의 **Fast mode models** 토글은 계정의 모든 워크스페이스에서 고속 모델 변형에 대한 액세스를 제어합니다. 제공업체 정책과 지능형 모델 라우팅은 이 설정을 변경하지 않습니다.
