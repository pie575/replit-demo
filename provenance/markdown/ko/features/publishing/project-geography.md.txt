# 프로젝트 지역

> 게시된 프로젝트의 컴퓨팅과 스토리지가 호스팅되는 위치를 선택하세요.

프로젝트 지역은 프로젝트의 게시 지역입니다. 게시할 때 선택하며, 게시된 프로젝트의 컴퓨팅과 스토리지가 호스팅되는 위치를 제어합니다.

<Note>
  프로젝트 지역과 [워크스페이스
  지역](/features/collaboration/workspace-geography)은 다를 수 있습니다. 워크스페이스
  지역은 워크스페이스 내 새 프로젝트의 개발 리소스가 호스팅되는 위치를 제어합니다.
</Note>

## 프로젝트 지역이 제어하는 것

기본적으로 Replit은 사용자와 가장 가까운 지역을 권장합니다. 이는 앱 방문자의 지연 시간을 줄이고 데이터 레지던시 요구 사항을 충족하는 데 도움이 됩니다.

지역을 선택하면 프로젝트의 모든 게시된 아티팩트(컴퓨팅, 데이터베이스, Object Storage 등)가 자동으로 동일한 지역에 통합 배치됩니다. 지역별 프록시 또한 앱 방문자의 지연 시간을 줄이는 데 도움을 줍니다.

## 프로젝트 지역 선택하기

권장 지역이 아닌 다른 지역을 선택하려면 다음을 따르세요.

<Steps>
  <Step>Replit 프로젝트에서 **Publishing** 도구를 엽니다.</Step>
  <Step>**Advanced** 설정을 펼칩니다.</Step>
  <Step>**Geography** 드롭다운에서 원하는 지역을 선택합니다.</Step>

  <Step>
    **Publish**를 선택해 선택한 지역에 프로젝트를 게시합니다.
  </Step>
</Steps>

## 게시된 프로젝트에 지역 강제 적용하기

Enterprise 관리자는 조직 전체의 모든 프로젝트에 게시 지역을 강제로 적용할 수 있습니다. 정책이 설정되면 조직 내 빌더는 지정된 지역으로 게시하게 됩니다. 이 정책은 아직 게시되지 않은 프로젝트에만 적용됩니다. 이미 다른 지역에 게시된 프로젝트에는 영향을 미치지 않습니다.

<Note>
  게시 지역을 강제 적용하는 기능은 Enterprise 기능입니다. Enterprise 플랜에 대해 자세히
  알아보려면 [Pricing](https://replit.com/pricing/)을 참고하세요.
</Note>

<Steps>
  <Step>**Account settings**로 이동합니다.</Step>
  <Step>**Advanced**를 선택합니다.</Step>

  <Step>
    처음 게시되는 모든 프로젝트가 사용해야 하는 지역을 선택합니다.
  </Step>
</Steps>

## 사용 가능 여부 및 제한 사항

| 지역                | 프로젝트 게시 선택 가능 여부 |
| :---------------- | :--------------- |
| **North America** | 가능               |
| **Europe (EU)**   | 가능               |
| **Asia**          | 가능               |
| **South America** | 가능               |
| **Australia**     | 가능               |

<Note>
  프로젝트 지역 선택은 Core, Pro, Enterprise 고객이 이용할 수 있습니다. Free
  고객은 기본적으로 North America에 게시됩니다.
</Note>

프로젝트 지역을 선택하기 전에 다음 제한 사항을 유의하세요.

* **지역은 게시 후 변경할 수 없습니다.** 프로젝트를 특정 지역에 게시하면 그 선택은 영구적입니다. 게시된 프로젝트를 다른 지역으로 마이그레이션할 수 없습니다.
* **개발 위치와 게시 위치가 다를 수 있습니다.** Object Storage와 같은 리소스는 게시 전에 생성될 수 있으며, 프로젝트 지역과 일치하지 않을 수 있습니다.
