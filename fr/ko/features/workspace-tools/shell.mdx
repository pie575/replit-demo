Avec Shell, vous pouvez effectuer dans votre projet des tâches telles que gérer des fichiers,
installer des packages et exécuter des scripts, comme dans un terminal classique. Par exemple, vous pouvez parcourir les fichiers de votre projet
ou utiliser `psql` si une connexion à une base de données y est configurée.

<Tip>
  Pour une meilleure gestion des flux de travail, nous vous recommandons d&#39;utiliser le bouton **Run**
  plutôt que d&#39;exécuter une application dans Shell. Les flux de travail lancés avec le bouton **Run** envoient
  leur sortie vers l&#39;outil Console, offrant ainsi une manière structurée de consulter les journaux.
</Tip>

<div id="section">
  ## Fonctionnalités
</div>

Shell propose les fonctionnalités suivantes :

* **Exécution de plusieurs shells** : ouvrez plusieurs instances de Shell pour effectuer différentes tâches simultanément
* **Recherche de texte** : recherchez un texte spécifique dans la sortie de Shell

<div id="shell">
  ### Vérifier l’accès au Shell
</div>

Pour vérifier que le Shell est prêt et afficher l’espace de travail actuel, exécutez la commande suivante :

```sh theme={null}
pwd
```

Shell affiche le chemin de l’espace de travail actuel.

<Frame caption="La commande pwd affiche le chemin de l’espace de travail actuel, puis revient à l’invite du Shell.">
  <img src="/assets/mirror/shell-pwd-output-2d31a0e0466b.jpg" alt="Onglet Shell affichant la commande pwd, le chemin de l’espace de travail et l’invite réapparue" width="1280" height="246" data-path="images/workspace/shell-pwd-output.jpg" />
</Frame>

Pour les projets avec une base de données, sélectionnez **Tools** → **Database**, puis
ouvrez la page **Development database**. Cette page permet de gérer les
connexions. Gardez les informations de connexion privées. Ne les copiez pas dans la documentation, les captures d’écran, les journaux, les fichiers sources
ou les messages partagés.

<div id="section-3">
  ### Recherche de texte
</div>

Les étapes suivantes expliquent comment accéder à l’outil de recherche de texte et l’utiliser :

1. Sélectionnez la loupe <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="icône de loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> située en haut à droite de l’onglet Shell pour ouvrir la boîte de dialogue de recherche.
2. Saisissez un terme de recherche et sélectionnez **Next** pour parcourir les correspondances.
3. Utilisez **Previous** pour revenir à la correspondance précédente.
4. Sélectionnez **Exit** ou cliquez en dehors de la boîte de dialogue pour quitter la recherche de texte.

<div id="shell-2">
  ### Plusieurs shells
</div>

Pour créer un autre shell :

1. Dans l’en-tête du panneau Shell, sélectionnez le menu des instances de shell.
2. Sélectionnez **New Shell**.

<Frame>
  <img src="/assets/mirror/shell-new-94a280c1230f.png" alt="Menu des instances de shell affichant l’espace de travail actuel et l’option New Shell" width="1280" height="224" data-path="images/workspace/shell-new.png" />
</Frame>

Utilisez ce même menu pour passer d’un shell à l’autre. Replit affiche chaque shell avec la dernière commande exécutée afin de faciliter son identification.

<Warning>
  Lorsque vous ouvrez plusieurs shells, Replit ferme automatiquement les instances de shell inactives.
  Un shell inactif n’est pas sélectionné et n’exécute aucun processus utilisateur.
</Warning>
