使用自定义域名，将你的 App 打造成专业的在线网站。

通过域名购买功能，你可以直接在 Replit 中搜索、购买域名，并将其连接到已部署 App，无需离开平台。几分钟内即可让已部署 App 拥有专业的线上形象。

这意味着你可以购买 `meu-app.com` 这样的域名，并让它自动指向你的 App。

<div id="funcionalidades">
  ## 功能
</div>

域名购买可简化为您的应用获取专业网址的流程。无需使用多个服务，您即可在 Replit 中完成在线形象的所有配置。

<Frame>
  <img src="/assets/mirror/replit-domains-8453291b634b.png" alt="显示已购买域名及其连接状态的域名管理界面" width="3176" height="1556" data-path="images/deployments/custom-domains/replit-domains.png" />
</Frame>

主要功能包括：

* **域名搜索和可用性**：查看 `.com`、`.ai` 等热门扩展名的域名是否可用
* **一键购买**：使用您账户的默认付款方式，直接通过 Replit 购买域名
* **自动配置**：您的域名会立即指向您的 Replit 应用，无需手动配置 DNS
* **WHOIS 隐私保护**：您的个人信息会在公共域名注册信息中保持私密，每次购买域名均默认包含此服务
* **自定义 DNS 记录**：添加自定义 A、TXT 和 MX 记录，以配置电子邮件提供商及其他服务
* **即时发布**：购买后，您的应用可立即通过自定义域名访问
* **自动续费**：域名会自动续订，确保您的应用持续在线，不会中断

<div id="uso">
  ## 使用
</div>

<div id="comprando-domnios">
  ### 购买域名
</div>

1. 部署您的应用，然后前往 <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="部署图标" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **部署** 选项卡
2. 选择 **域名** 选项卡
3. 选择 **购买域名** 以开始搜索
4. 在搜索栏中输入所需的域名
5. 查看不同后缀的可用选项
6. 选择心仪的域名并完成购买

购买域名后，系统会自动将其配置为指向您的 Replit 应用。您的应用将立即可通过自定义域名访问，无需额外配置。

域名购买费用将通过您的 Replit 账户收取，从账户余额中扣除并计入您的用量。

<div id="gerenciando-domnios-comprados">
  ### 管理已购买的域名
</div>

您的域名可与已部署 App 无缝集成：

* **自动续费**：域名会自动续费，确保您的已部署 App 持续可用
* **集成计费**：域名费用会与其他服务一同显示在 Replit 账单中
* **支持转移**：您可以在不同 Replit 账户之间转移域名，或在需要时转移至外部注册商

<div id="registros-dns-personalizados">
  ### 自定义 DNS 记录
</div>

对于通过 Replit 购买的域名，你可以添加自定义 DNS 记录，以配置电子邮件提供商等其他服务。支持以下 DNS 记录类型：

* **A 记录**：将你的域名或子域名指向指定的 IP 地址
* **TXT 记录**：为电子邮件身份验证等服务添加文本验证记录 (SPF、DKIM、DMARC)
* **MX 记录**：MX (邮件交换) 记录会告知邮件服务器应将发往你的域名的电子邮件投递到哪里。配置 MX 记录后，你可以使用自定义域名创建 `ola@seudominio.com` 等电子邮件地址。

要管理已购买域名的 DNS 记录：

1. 前往部署 <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="部署图标" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> 中的 **域名** 标签页
2. 找到要配置的域名
3. 选择 **编辑** 图标 <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="铅笔图标" width="16" height="16" data-path="images/icons/pencil-icon.svg" />
4. 选择 **添加 DNS 记录**
5. 按服务提供商的要求输入记录类型、名称、值和 TTL

<div id="tipos-de-implantao-suportados">
  ### 支持的部署类型
</div>

域名购买支持以下部署类型：

* **[Autoscale Deployments](/zh/pt/features/publishing/deployment-types#autoscale)**
* **[保留 VM 部署](/zh/pt/features/publishing/deployment-types#reserved-vm)**
* **[静态部署](/zh/pt/features/publishing/deployment-types#static)**

目前，你可以为个人账户中已部署的 App 购买域名。Replit Pro 的域名购买功能即将推出。

<div id="perguntas-frequentes">
  ## 常见问题
</div>

<AccordionGroup>
  <Accordion title="费用是多少？">
    购买域名涉及两项费用：

    * **注册费**：域名首年注册费用 (`.ai` 域名为两年)
    * **续费价格**：初始注册期结束后自动收取

    Replit 不会针对域名购买收取额外费用。域名注册费不予退款。
  </Accordion>

  <Accordion title="如何续费我的域名？">
    Replit 会自动续费您的域名，确保您的应用始终可访问。若要关闭
    自动续费，请在 部署 工具中打开 **域名** 选项卡，选择您的
    域名，然后关闭 **自动续费** 开关。此页面还会显示您域名的
    续费日期和续费价格。
  </Accordion>

  <Accordion title="如果我想离开 Replit 怎么办？">
    您可以联系 Replit
    支持团队，将域名转移至其他注册商。根据 ICANN 规定，域名购买后需等待 60 天，
    才能转移至外部注册商。
  </Accordion>

  <Accordion title="我可以在 Replit 账户之间转移域名吗？">
    可以，请联系 Replit 支持团队，将域名转移到其他 Replit 账户。此
    流程无需等待 60 天。
  </Accordion>

  <Accordion title="我可以为我的组织购买域名吗？">
    Replit Pro 和 Enterprise 套餐的域名购买功能将在
    初始 Beta 期后推出。
  </Accordion>

  <Accordion title="我可以为域名添加自定义 DNS 记录吗？">
    可以！您可以为通过 Replit 购买的域名添加自定义 DNS 记录。目前支持的记录类型包括：

    * **A 记录**：将域名或子域名指向特定 IP 地址
    * **TXT 记录**：添加用于电子邮件身份验证及其他服务的文本验证记录
    * **MX 记录**：配置邮件服务器来处理您域名的电子邮件

    前往 部署 中的域名选项卡配置这些记录。有关如何为电子邮件配置 MX 记录的详细说明，请参阅上方的[自定义 DNS 记录](#custom-dns-records)部分。
  </Accordion>

  <Accordion title="支持哪些域名后缀？">
    我们支持所有常见的顶级域名 (TLD)。不支持具有
    特殊地域限制或其他限制的 TLD。
  </Accordion>

  <Accordion title="什么是 WHOIS 隐私保护？">
    注册域名时，您的联系信息 (姓名、地址、电话和电子邮件) 通常会公布在名为 WHOIS 的公共数据库中，任何人都可以查询。WHOIS 隐私保护会以注册商的通用信息替换您的个人信息，在满足法律要求的同时保护您的隐私。

    所有通过 Replit 购买的域名默认包含 WHOIS 隐私保护，无需额外付费。这意味着垃圾邮件发送者、营销人员以及其他可能查询域名所有者信息的人都无法看到您的个人信息。
  </Accordion>

  <Accordion title="如果我已有域名怎么办？">
    若要将现有域名连接到您的 Replit 应用，请参阅我们的[自定义域名](/zh/pt/features/publishing/custom-domains)文档。
  </Accordion>
</AccordionGroup>
