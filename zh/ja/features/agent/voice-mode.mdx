---
title: "语音模式"
description: "无需打字，即可通过语音向 Agent 发送提示词。语音模式会将你的语音转写为聊天框中的文本，供你确认后再发送。"
---

使用语音模式，通过语音描述你想构建的内容。轻点 Agent 聊天框中的麦克风并开始说话，Replit 会将你的语音转写为文本。确认并编辑文本后，即可像发送普通消息一样将其发送。

语音模式适合在打字较慢或不便打字时使用 — 尤其是在移动设备上，说出完整提示词通常比用拇指打字更快。

<Note>
  语音模式会将语音转换为聊天框中的文本，并不会朗读 Agent 的回复 — 你仍会像平常一样发送文字消息，Agent 则会在聊天中回复。
</Note>

语音模式会录制并转写你的语音，然后将结果插入聊天框，供你在发送前查看：

1. 打开 Agent，选择聊天框中的麦克风图标。
2. 如果浏览器或设备提示，请允许访问麦克风。
3. 说出你的提示词。系统会显示波形，表示 Agent 正在录音。
4. 说完后停止录音。暂停或切换标签页时，录音会自动停止。
5. 稍等片刻，等待语音转写完成。
6. 查看转写后的文本，按需编辑后发送消息。

语音会以文本形式显示在普通聊天框中，因此你可以自由结合语音和键盘输入：先口述部分提示词，再输入其余内容，或在发送前修改字词。

<Tip>
  自然说话即可。语音模式更注重理解含义，而非逐字转写，因此会从结果中省略“呃”“嗯”等填充词。
</Tip>

<div id="section-2">
  ## 可用位置
</div>

你可以在 Agent 聊天框中使用语音模式：

* 在使用 Agent 开发应用时的**项目编辑器**中。
* 通过主页上的 Agent 提示词**开始创建新应用**时。

语音模式可在桌面网页版、移动网页版和 Replit 移动应用中使用。

<div id="section-3">
  ## 使用须知
</div>

使用语音模式时，请注意以下事项：

| 详情    | 内容                                                   |
| ----- | ---------------------------------------------------- |
| 录制时长  | 单次最多可录制 6 分钟。接近时长上限时会显示警告。                           |
| 自动停止  | 静音约 30 秒后，或切换标签页或将应用置于后台时，录制会自动停止。                   |
| 发送前确认 | 转写后的文本会显示在聊天框中，你可以在发送前查看和编辑 — 不会自动发送。                |
| 麦克风访问 | 语音模式需要获得麦克风使用权限。如果无法开始录制，请确认浏览器和设备是否允许 Replit 访问麦克风。 |

<div id="section-4">
  ## 可用套餐
</div>

所有 Replit 套餐均支持语音模式。在支持录音功能的浏览器和设备上，Agent 聊天框中会显示麦克风图标；首次录音时，系统会请求麦克风权限。
