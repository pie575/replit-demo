## Sugestões de tarefas de acompanhamento

Após você aplicar uma tarefa, o Agent revisa o contexto do seu projeto e sugere **tarefas de acompanhamento** que você pode querer criar a seguir. A caixa de diálogo **Próximas tarefas sugeridas** mostra a principal recomendação inline, para que você possa continuar sem sair da thread principal.

As sugestões de acompanhamento podem incluir:

* **Novos recursos para criar**: funcionalidades que combinam naturalmente com o que você acabou de lançar
* **Melhorias de desempenho**: otimizações que o Agent notou ao trabalhar na tarefa
* **Melhorias de experiência do usuário**: polimento e refinamentos que completam a funcionalidade

Selecione **Iniciar** em uma sugestão para enviá-la para o segundo plano, ou selecione **Ver plano** para inspecionar o trabalho proposto primeiro. Para ver todas as sugestões, selecione **Ver mais no quadro de tarefas**. Os acompanhamentos sugeridos aparecem em **Sugeridos** na coluna **Rascunhos**.

<Frame>
  <img src="/assets/mirror/follow-up-tasks-kanban-21087e0210b6.png" alt="Quadro de tarefas mostrando muitas sugestões de tarefas de acompanhamento em Sugeridos na coluna Rascunhos" width="980" height="627" data-path="images/agent/follow-up-tasks-kanban.png" />
</Frame>

Fechar a caixa de diálogo **Próximas tarefas sugeridas** cancela as sugestões. O Agent não mostra a caixa de diálogo na versão principal quando um plano proposto já está aguardando lá, para que os dois prompts não concorram pela sua atenção.

## Gerenciando muitas sugestões de uma vez

Para projetos com muitas sugestões de acompanhamento, abra o quadro de tarefas e selecione **Editar** na coluna **Rascunhos**. No modo de edição, cada tarefa sugerida recebe uma caixa de seleção. Selecione as tarefas que você quer e use **Iniciar** ou **Cancelar** para aplicar essa ação a cada tarefa selecionada. Selecione **Concluído** para sair do modo de edição.
