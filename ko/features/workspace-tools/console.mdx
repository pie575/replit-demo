Console에서는 실행 중인 Replit App이 출력하는 로그를 실시간으로 모니터링하고 확인할 수 있습니다.
현재와 이전 실행 기록을 활용해 앱의 동작을 파악하고,
오류를 해결하며, 성능을 최적화할 수 있습니다.

<Tip>
  Agent로 디버깅할 때는 prompt에 console 로그를 함께 넣어 context를 제공하세요.
</Tip>

<div id="features">
  ## 기능
</div>

Console은 앱의 동작을 파악할 수 있도록 다음과 같은 도구를 제공합니다:

* **실시간 로깅**: 앱의 출력을 발생하는 즉시 확인
* **AI 지원**: 로그에 표시된 오류를 해결할 수 있는 제안 제공
* **실행 기록**: 이전 실행의 로그를 표시해 변경 사항 추적

<div id="usage">
  ## 사용법
</div>

Console 도구는 Project Editor에서 바로 사용할 수 있습니다.

<Accordion title="Console 사용하기">
  왼쪽 **Tool dock**에서:

  1. <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="모든 도구 아이콘" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**를 선택해 Project Editor 도구 목록을 확인합니다.
  2. <img class="icon-svg" src="/assets/mirror/console-8a41ac90789c.svg" alt="Console 아이콘" width="16" height="16" data-path="images/icons/console.svg" /> **Console**을 선택합니다.

  **검색창**에서:

  1. 상단의 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="돋보기 아이콘" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 돋보기를 선택해 검색 도구를 엽니다.
  2. &quot;Console&quot;을 입력해 도구를 찾은 후 결과에서 선택합니다.
</Accordion>

Replit App에서 **Run** 버튼을 누를 때마다 Console에 다음 정보가 담긴 새 항목이 표시됩니다.

* 코드를 실행한 명령어
* 타임스탬프 정보
* 표준 출력 및 오류 로그

다음 스크린샷은 앱을 시작하는 데 사용한 `npm run dev` 명령어와 실행 중 기록된 로그 메시지를 보여줍니다.

<div id="ai-powered-debugging">
  ### AI 기반 디버깅
</div>

로그에서 이해하고 싶은 오류나 기타 정보를 발견하면 해당 항목 상단의 **Ask AI** 버튼을 선택하세요.
그러면 **Agent** 탭이 자동으로 열리고 해당 로그 내용이 분석을 위해 전달됩니다.

<div id="log-entry-commands">
  ### 로그 항목 명령어
</div>

Console에서는 로그를 관리할 수 있는 다음 도구를 제공합니다:

* **Show Only Latest**: 이 컨트롤을 **켜기**로 전환하면 가장 최근 run만 표시됩니다.
* **Collapse entry**: 명령어 이름 왼쪽의 <img class="icon-svg" src="/assets/mirror/down-arrow-9c1cf9fd152e.svg" alt="아래쪽 화살표 icon" height="16" width="16" data-path="images/icons/down-arrow.svg" /> 아래쪽 화살표를 선택하면 로그가 숨겨집니다.
* **Clear past runs**: 이 항목을 선택하면 이전 run의 로그가 삭제됩니다. 이 작업은 되돌릴 수 없습니다.

<div id="network-availability">
  ### 네트워크 가용성
</div>

앱의 개발 버전을 온라인에서 이용할 수 있는지 여부를 제어할 수 있습니다.

development URL로 들어오는 요청 처리를 중지하려면, 네트워크 정보 줄 오른쪽에 있는 <img class="icon-svg" src="/assets/mirror/network-off-5bdca8a4fe4e.svg" alt="network off icon" height="16" width="16" data-path="images/icons/network-off.svg" /> 빗금 친 지구본 아이콘을
선택하세요.

다시 활성화하려면 <img class="icon-svg" src="/assets/mirror/network-on-15be2e5fb4f5.svg" alt="network on icon" height="16" width="16" data-path="images/icons/network-on.svg" /> 지구본 아이콘을 선택하세요.

development URL을 확인하려면 주소 표시줄의 `{...}.replit.dev` 텍스트를 선택하세요.

<Frame>
  <img src="/assets/mirror/preview-dev-url-b36770b33769.png" alt="Preview development URL location" width="1222" height="824" data-path="images/workspace/preview-dev-url.png" />
</Frame>

<Note>
  development URL의 요청 처리를 중지하도록 설정하더라도 앱은 Preview 도구에서 계속 사용할 수 있습니다.
</Note>

<div id="stop-a-workflow-command">
  ### workflow 명령 중지
</div>

실행 중인 workflow 명령은 Project Editor의 Console 도구에서 중지할 수 있습니다.

Replit App의 Run command가 포함된 줄 오른쪽에 있는 사각형 버튼을 선택하면 해당 명령이 종료됩니다.

앱을 다시 시작하려면 Project Editor 상단의 workflow **Run** 버튼을 사용하세요.
