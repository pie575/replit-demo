  ## Что такое фреймворк для разработчиков?
</div>

Фреймворки для разработчиков — это Replit App, опубликованные платформой и сообществом, которые другие пользователи могут использовать в качестве отправной точки. У официальных фреймворков, созданных Replit, рядом с названием установлен флажок:

<Frame>
  <img src="/assets/mirror/template-official-c5fe09e20415.png" alt="Официальные фреймворки Replit для разработчиков" width="1051" height="246" data-path="images/programming-ide/creating-a-template/template-official.png" />
</Frame>

Фреймворк [HTML, CSS, JS](https://replit.com/@replit/HTML-CSS-JS?v=1#index.html) очень популярен; его можно использовать в качестве отправной точки для создания проекта на чистом JavaScript. Вы можете сделать форк этого фреймворка и использовать его.

<div id="templates-personalizados-para-empresas">
  ## Пользовательские шаблоны для Enterprise
</div>

Организации Enterprise могут создавать [пользовательские шаблоны](/ru/pt/teams/custom-templates), доступные для выбора во входящих Agent всем участникам организации. Пользовательские шаблоны выходят за рамки фреймворков для разработчиков: они включают специфичные для компании инструкции для Agent, навыки и предварительно настроенный контекст проекта. Подробнее см. в [руководстве по пользовательским шаблонам](/ru/pt/teams/custom-templates).
