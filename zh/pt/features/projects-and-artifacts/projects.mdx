<div id="o-que-um-projeto">
  ## 什么是项目？
</div>

项目是你在 Replit 上构建的一切的容器。它保存你的代码、数据以及你创建的所有 artifact——Web 应用、移动应用、幻灯片演示、数据仪表板和视频。当你告诉 Agent 你想要什么时，它会创建一个项目，并在其中构建相应的 artifact。

可以把项目想象成你桌上的一块工作台。所有东西都集中在一处，可以共用相同的信息，但每一件都有各自的用途。

例如，如果你让 Agent 构建一个健身追踪应用，它会创建一个项目，其中包含一个移动应用 artifact，以及运行所需的后端、数据库和存储。

<ArtifactGrid />

核心概念：

* **项目**：容纳一切的容器——你的代码、数据和所有 artifact
* **Artifact**：项目内可发布的产出 (Web 应用、幻灯片演示、视频等)
* **资源**：每个 artifact 都会自动获得后端、数据库和文件存储——无需任何配置

<Note>
  部署会一次性发布你的整个项目。所有 artifact 同时上线，因此始终保持同步。
</Note>

<div id="o-que-voc-pode-construir">
  ## 你可以构建什么
</div>

| 类型                                                           | 说明                            | 示例                 |
| ------------------------------------------------------------ | ----------------------------- | ------------------ |
| **[Web 应用](/zh/pt/features/artifact-types/web-apps)**           | 人们在浏览器中访问的网站或 Web 应用          | 在线商店、预订工具、作品集网站    |
| **[移动应用](/zh/pt/features/artifact-types/building-mobile-apps)** | 人们安装在手机上的原生应用                 | 健身追踪器、餐厅点餐应用       |
| **[数据可视化](/zh/pt/features/artifact-types/data-apps)**           | 带有图表、筛选器和实时数据的交互式仪表板          | 销售报告、指标追踪器、分析视图    |
| **[幻灯片演示](/zh/pt/features/artifact-types/slide-decks)**         | 可以放映或导出的演示文稿                  | 路演演示、团队进展汇报、产品概览   |
| **[动画](/zh/pt/features/artifact-types/animated-videos)**        | 可导出为 MP4 的 motion graphics 视频 | 产品发布视频、讲解视频、社交媒体内容 |
| **3D 游戏**                                                    | 3D 游戏、模拟或互动体验                 | 益智游戏、物理模拟、互动体验     |
| **[Design](/zh/pt/design/canvas)**                              | 在设计 Canvas 上探索的视觉方向与原型设计      | 情绪板、模型稿、设计探索       |

一个 项目 可以包含多个 artifact。例如，你可以为客户构建一个 Web 应用、为团队构建一个移动应用，再为投资人制作一份幻灯片演示——全部都在同一个 项目 里。当多个 artifact 位于同一个 项目 中时，它们会自动共享相同的数据和后端逻辑。要了解更多信息，请参阅 [Artifact](/zh/pt/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project)。

<div id="gerenciando-seus-projetos">
  ## 管理你的项目
</div>

“项目”页面会列出你创建或受邀加入的所有项目。在繁忙的 workspace 中，这是回到近期工作、快速找到目标项目的最佳方式。

<div id="veja-rapidamente-o-que-h-em-cada-projeto">
  ### 快速查看每个 项目 中的内容
</div>

每个 项目 卡片都会用小图标展示其中包含的 artifact，涵盖该 项目 中的每个 Web 应用、移动应用、幻灯片演示、数据可视化和动画。将鼠标悬停在任一图标上，即可直接在卡片上预览该 artifact 的截图，无需逐个打开 项目 就能分辨它们。

<div id="filtre-por-artefato">
  ### 按artifact筛选
</div>

使用 Projects 页面顶部的 **Build 类型** 下拉菜单，按artifact筛选列表。选择某一项后，只显示包含该类型artifact的 项目：

* **Web** — 包含 Web 应用的 项目
* **Mobile** — 包含移动应用的 项目
* **Data** — 包含数据可视化的 项目
* **Slides** — 包含幻灯片演示的 项目
* **Design** — 处于 Design 模式的 项目
* **3D 游戏**、**Agent 与自动化** 等

选择 **任意 Build 类型** 即可清除筛选。

</Frame>

<div id="ordene-por-ltima-abertura">
  ### 按最近打开时间排序
</div>

“项目”页面默认按**你最近打开的时间**排序——你近期花时间最多的项目会排在最上方。这在团队 workspace 中尤其实用，否则其他成员的近期编辑会把你手头的工作淹没。

如需更改排序方式，可以点击其他列标题 (例如**最近更新**或**名称**) 。

<div id="fixe-os-projetos-que-voc-mais-usa">
  ### 固定你最常用的项目
</div>

固定项目后，它会始终显示在列表顶部。固定状态**仅你自己可见**——在团队 workspace 中固定项目不会影响其他成员看到的内容。

要固定项目，请在项目卡片上打开选项菜单 (三个点) ，然后选择**固定**。在同一菜单中选择**取消固定**即可解除固定。
