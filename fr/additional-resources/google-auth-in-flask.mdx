Permettre à vos utilisateurs de se connecter à votre site web avec leur compte Google présente les avantages suivants :

1. Vous n&#39;avez pas besoin de mettre en œuvre votre propre système d&#39;authentification.
2. Vous pouvez facilement obtenir le nom et les coordonnées des utilisateurs.
3. Vous pouvez utiliser les mêmes identifiants pour accéder aux ressources Google des utilisateurs, comme Sheets et Drive.

Ce guide vous explique comment procéder avec Python et Flask sur Replit.

Nous verrons d&#39;abord comment configurer l&#39;authentification OAuth de base, puis comment utiliser les identifiants obtenus pour accéder aux ressources Google des utilisateurs.

<div id="introduction-to-oauth">
  ## Introduction à OAuth
</div>

L&#39;authentification Google repose sur la norme OAuth. Voici son fonctionnement :

1. À un endroit de votre site web, vous dirigez un utilisateur vers une page de connexion.
2. Lorsqu&#39;il accède à cette page, vous n&#39;implémentez pas le formulaire de connexion sur votre site web ; vous redirigez plutôt l&#39;utilisateur vers le service de connexion de Google.
3. Une fois l&#39;utilisateur connecté avec succès par le service de connexion de Google, celui-ci le redirige vers votre site web à une URL prédéfinie de votre choix, par exemple `https://YOUR_DOMAIN/oauth2callback`, en transmettant des informations pertinentes sur l&#39;utilisateur et la session de connexion.
4. Vous utilisez les informations de connexion de l&#39;utilisateur pour obtenir un jeton d&#39;accès, qui fonctionne comme un laissez-passer vous permettant d&#39;accéder à ses ressources, telles que les informations de son profil, ses feuilles de calcul, ses documents, et bien plus encore.

<div id="oauth-show-me-the-code">
  ## OAuth : montrez-moi le code
</div>

Si vous êtes comme moi, ce que vous voulez avant tout, c&#39;est du code qui fonctionne. Le code ci-dessous est exactement celui qu&#39;il vous faut. Vous devrez toutefois configurer quelques éléments dans la Google Cloud Console pour que tout fonctionne, ce que nous verrons dans la section suivante. Créez une nouvelle Replit App à partir du [template Flask](https://replit.com/@replit/Flask?v=1) et placez le code suivant dans `main.py`. Les commentaires du code expliquent le rôle de chaque partie :

```python theme={null}
from flask import Flask, redirect, session, url_for, request
import google_auth_oauthlib.flow
import json
import os
import requests

app = Flask('app')
# `FLASK_SECRET_KEY` est utilisée par les sessions. Créez une chaîne aléatoire
# et stockez-la comme secret.
app.secret_key = os.environ.get('FLASK_SECRET_KEY') or os.urandom(24)

# `GOOGLE_APIS_OAUTH_SECRET` contient le contenu d’un fichier JSON à télécharger
# depuis le panneau des identifiants Google Cloud. Consultez la section suivante.
oauth_config = json.loads(os.environ['GOOGLE_OAUTH_SECRETS'])

# Configure le flux OAuth
oauth_flow = google_auth_oauthlib.flow.Flow.from_client_config(
    oauth_config,
    # les scopes définissent les API auxquelles vous souhaitez accéder au nom de l’utilisateur une fois authentifié
    scopes=[
        "https://www.googleapis.com/auth/userinfo.email",
        "openid",
        "https://www.googleapis.com/auth/userinfo.profile",
    ]
)

# Il s’agit du point d’entrée de la page de connexion. Il redirige vers le service de connexion Google à l’adresse
# `authorization_url`. `redirect_uri` est l’URI que le service de connexion Google utilise pour
# rediriger vers cette App.
@app.route('/signin')
def signin():
    # Nous remplaçons http par https dans l’URL, car http est utilisé au sein de la Replit App,
    # tandis que l’accès externe se fait via https ; redirect_uri doit donc correspondre à cette URL
    oauth_flow.redirect_uri = url_for('oauth2callback', _external=True).replace('http://', 'https://')
    authorization_url, state = oauth_flow.authorization_url()
    session['state'] = state
    return redirect(authorization_url)

# Il s’agit du point de terminaison vers lequel le service de connexion Google redirige. Il doit être ajouté aux « Authorized redirect URIs »
# dans le panneau des identifiants API de Google Cloud. Il appelle un point de terminaison Google pour demander
# un jeton d’accès et le stocker dans la session de l’utilisateur. Ce jeton permet ensuite d’accéder aux
# API au nom de l’utilisateur.
@app.route('/oauth2callback')
def oauth2callback():
    if not session['state'] == request.args['state']:
        return 'Invalid state parameter', 400
    oauth_flow.fetch_token(authorization_response=request.url.replace('http:', 'https:'))
    session['access_token'] = oauth_flow.credentials.token
    return redirect("/")

# Il s’agit de la page d’accueil de l’App. Elle invite l’utilisateur à se connecter s’il ne l’est pas déjà.
# Elle affiche ses informations s’il est déjà connecté.
@app.route('/')
def welcome():
    if "access_token" in session:
        user_info = get_user_info(session["access_token"])
        if user_info:
            return f"""
                Hello {user_info["given_name"]}!<br>
                Your email address is {user_info["email"]}<br>
                <a href="/logout">Log out</a>
            """
    return """
        <h1>Hello!</h1>
        <a href="/signin">Sign In via Google</a><br>
    """

# Appelez l’API userinfo pour récupérer les informations de l’utilisateur à l’aide d’un jeton d’accès valide.
# Il s’agit du premier exemple d’utilisation du jeton d’accès pour accéder à une API au nom de l’utilisateur.
def get_user_info(access_token):
    response = requests.get("https://www.googleapis.com/oauth2/v3/userinfo", headers={
       "Authorization": f"Bearer {access_token}"
   })
    if response.status_code == 200:
        user_info = response.json()
        return user_info
    else:
        print(f"Failed to fetch user info: {response.status_code} {response.text}")
        return None

@app.route('/logout')
def logout():
    session.clear()
    return redirect('/')

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000)

```

  ## Intégration Google Sheets : le code
</div>

Commencez par ajouter `"https://www.googleapis.com/auth/spreadsheets.readonly"` à la liste des portées dans la section du flux OAuth du code d’origine :

```python theme={null}
# Définit la configuration du flux OAuth
oauth_flow = google_auth_oauthlib.flow.Flow.from_client_config(
    oauth_config,
    # les scope définissent les API auxquelles vous souhaitez accéder au nom de l'utilisateur une fois celui-ci authentifié

        "https://www.googleapis.com/auth/userinfo.email",
        "openid",
        "https://www.googleapis.com/auth/userinfo.profile",
        "https://www.googleapis.com/auth/spreadsheets.readonly"
    ]
)
```

Pour accéder à une API Google avec la bibliothèque `googleapiclient.discovery`, commencez par créer un objet `Credentials` à l’aide du jeton d’accès, puis utilisez la fonction `build` pour créer un objet API appelable. Pour l’API Sheets, cela se présente ainsi :

```python theme={null}
credentials = google.oauth2.credentials.Credentials(token=session['access_token'])
service = build("sheets", "v4", credentials=credentials)
sheets_api = service.spreadsheets()
```

Pour utiliser concrètement l’API Sheets, j’ai créé quelques fonctions d’assistance :

```python theme={null}
# récupère tous les onglets d'une feuille de calcul Google
def get_sheets(sheets_api, spreadsheet_id) -> list[str]:
    result = sheets_api.get(spreadsheetId=spreadsheet_id).execute()
    return [sheet["properties"]["title"] for sheet in result["sheets"]]

# récupère les données d'un onglet donné dans une feuille de calcul Google
def get_sheet_data(sheets_api, spreadsheet_id, sheet_title) -> list[list[str]]:
    result = (
        sheets_api.values()
        .get(spreadsheetId=spreadsheet_id, range=sheet_title)
        .execute()
    )
    return result["values"]
```

Grâce à ce qui précède, nous pouvons créer un point de terminaison POST qui importe une feuille de calcul Google, comme suit :

```python theme={null}
@app.route("/import_spreadsheet", methods = ['POST'])

        for sheet in sheets:

            data_by_sheets[sheet] = data

        return f"upload failure"
    dirpath = os.path.join("static", "uploads", spreadsheet_id)
    filepath = os.path.join(dirpath, "data.json")
    os.makedirs(dirpath, exist_ok=True)
    with open(filepath, "w") as file:
        json.dump(data_by_sheets, file)
    return "upload success!"
```
