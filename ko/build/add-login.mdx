[Welcome to Replit](/ko/welcome)에서 프리미엄 슈퍼카 렌털 앱 Velocity를 보셨을 겁니다. 지금은 public URL에 접속하기만 하면 누구나 모든 예약 건을 볼 수 있습니다. 람보르기니를 익명으로 예약하는 사람은 없겠죠. 로그인 기능을 추가하면 고객마다 자신의 예약 건과 저장한 차량을 따로 갖게 됩니다.

<div id="tell-agent-to-add-sign-in">
  ## Agent에게 로그인 기능 추가 요청하기
</div>

Velocity에는 Clerk을 사용하세요. Replit의 Clerk integration을 사용하면 앱에 브랜드가 적용된 자체 로그인 화면, Velocity 안에서만 존재하는 고객 계정(Replit account가 아님), 그리고 디자인과 분위기에 대한 완전한 제어권을 갖출 수 있습니다. 프리미엄 렌터카 브랜드에 딱 어울리죠. Agent가 모든 것을 자동으로 프로비저닝하므로 Clerk dashboard에 따로 가입할 필요도, 붙여넣을 키도 없습니다.

<AiPrompt>
  각 고객이 자신의 예약과 저장한 차량을 가질 수 있도록 Velocity에 로그인 기능을
  추가해줘.

  <br />

  Clerk Auth를 사용해줘.

  <br />

  차량을 예약하거나 즐겨찾기에 저장할 때는 로그인을 요구해줘.

  <br />

  로그인 후에는 헤더에 고객 이름을 표시하고, 해당 고객의 예약 건만 보여주는
  &quot;My bookings&quot; 섹션을 만들어줘.

  <br />

  로그아웃 버튼도 추가해줘.

  <br />

  서로 다른 두 고객을 사용한 테스트 체크리스트를 만들어줘.

Agent는 Velocity용 Clerk tenant를 프로비저닝하고, 로그인 컴포넌트를 추가하고, 예약 flow에 gate를 적용하고, 각 예약 건을 로그인한 고객과 연결한 뒤, 로그아웃 기능까지 추가합니다. Agent chat에서 빌드 과정을 지켜보세요.

<div id="test-it-with-two-customers">
  ## 고객 두 명으로 테스트하기
</div>

계정 하나로는 부족합니다. 예약이 서로 분리되어 있는지 확인하려면 계정이 두 개 필요합니다.

1. Preview에서 Velocity를 열고 로그인하지 않은 채로 차량을 둘러보세요. 차량 목록은 그대로 보여야 합니다.
2. 차량에서 Reserve를 클릭하세요. Clerk 로그인 화면으로 이동해야 합니다.
3. 본인 이메일로 가입한 뒤 예약 건을 완료하세요(예: 911 차량의 주말 예약).
4. 로그아웃하세요. &quot;My bookings&quot; 섹션이 사라지고, 예약 flow에서 다시 로그인을 요구해야 합니다.
5. 시크릿 창에서 Preview를 열고 다른 이메일로 가입한 뒤, 다른 차량을 예약하세요.
6. 첫 번째 창으로 돌아가 로그인한 다음, 두 번째 고객의 것이 아닌 본인의 예약 건만 보이는지 확인하세요.

두 고객에게 동일한 예약 건이 보인다면, 예약이 아직 로그인한 사용자와 연결되지 않은 것입니다. Agent에게 증상을 그대로 알려주세요:

<AiPrompt>
  Velocity에서 두 고객이 서로의 예약 건을 볼 수 있습니다.

  <br />

  각 예약과 각 저장한 차량을 로그인한 고객에게 연결해서 각자 자신의
  것만 보이도록 해주세요.

  <br />

  테스트 계정 두 개로 확인하는 방법을 알려주세요.
</AiPrompt>

<div id="publish-and-sign-in-on-the-public-url">
  ## 게시하고 public URL에서 로그인하기
</div>

Agent chat 또는 Publishing 타일에서 Velocity를 다시 Publish한 다음, 새 tab에서 public URL을 열어 로그인하세요. Clerk은 Development 환경과 Production 환경이 分리되어 프로비저닝되며, Agent가 Production 자격 증명을 published app에 자동으로 연결해 주므로 별도 설정 없이도 public URL에서 로그인이 작동합니다.

이제 Velocity에 실제 고객이 생겼습니다. 각 고객은 로그인해 자신만의 예약 차고를 이용하며, 다른 사람에게는 보이지 않습니다.

<div id="need-further-help">
  ## 추가 도움이 필요하신가요?
</div>

* **앱 전체가 숨겨진 경우:** 차량 둘러보기는 공개로 두고 예약 및 계정 페이지만 보호하도록 Agent에게 요청하세요.
* **고객이 다른 고객의 예약 건을 볼 수 있는 경우:** 각 예약과 저장한 차량을 로그인한 고객과 연결하도록 Agent에게 요청하세요.
* **Preview에서는 로그인이 되지만 게시 후에는 안 되는 경우:** 새 탭에서 public URL을 열고, 화면에 표시되는 오류 메시지를 그대로 Agent에게 알려주세요. Agent가 Production Clerk 환경을 프로비저닝했는지도 확인하세요.
* **프로토타입에 별도 설정 없는 빠른 로그인이 필요한 경우:** Replit Auth는 고객의 Replit account를 그대로 사용하므로 관리할 Clerk tenant가 없습니다 — [Replit Auth](/ko/features/auth-and-identity/authentication)를 참고하세요.
