title: "Users & Auth"
description: "Gérez les personnes qui se connectent à votre application et choisissez leur méthode de connexion avec Replit Auth ou Clerk."
---

L&#39;outil Users &amp; Auth vous permet de gérer les personnes qui utilisent votre application ainsi que leur méthode de connexion. Ouvrez **Users &amp; Auth** dans **Replit Cloud**, au sein du volet **Tools**.

Cet outil comporte deux onglets :

* **Users** : affiche toutes les personnes qui se sont connectées à votre application, avec leur nom et l&#39;heure de leur dernière connexion. Vous pouvez effectuer une recherche dans la liste pour retrouver un utilisateur en particulier.
* **Configure** : permet de paramétrer l&#39;expérience de connexion de votre application : le nom et l&#39;icône affichés sur l&#39;écran de connexion, les fournisseurs de connexion proposés par votre application, le secret de session, etc.

<Note>
  Cet outil gère les utilisateurs de votre **application**, c&#39;est-à-dire les personnes qui s&#39;inscrivent et se connectent à ce que vous avez créé. Pour savoir comment contrôler qui peut accéder à votre application publiée, consultez [Qui peut accéder à votre application](/fr/ja/features/publishing/private-deployments).
</Note>

<div id="section">
  ## Choisir un système d’authentification
</div>

* **[Replit Auth](/fr/ja/features/auth-and-identity/authentication)** : une solution sans configuration. Demandez simplement à Agent d’« ajouter Replit Auth » pour ajouter à votre application une page de connexion prête à l’emploi, la gestion des utilisateurs et des sessions sécurisées.
* **[Clerk](/fr/ja/features/auth-and-identity/clerk-auth)** : un service d’authentification complet pour les applications qui nécessitent un contrôle plus avancé, notamment des flux de connexion personnalisés ou une image de marque OAuth personnalisée. Vous pouvez configurer des [fournisseurs de connexion personnalisés](/fr/ja/features/auth-and-identity/sign-in-providers) pour Google, GitHub, Apple et X.

<div id="section-2">
  ## Étapes suivantes
</div>

* [Replit Auth](/fr/ja/features/auth-and-identity/authentication) : une connexion sans configuration pour vos applications.

* [Fournisseurs de connexion](/fr/ja/features/auth-and-identity/sign-in-providers) : utilisez vos propres identifiants OAuth.
