Le panneau de bibliothèque est la source intégrée de Replit Design pour trouver des points de départ et des références. Il comporte trois onglets : **Modèles**, **Inspiration** et **Bibliothèque**. Aucun de ses éléments ne crée de nouveau projet ; tout est ajouté au Canvas du projet ouvert.

<div id="templates">
  ## Modèles
</div>

Des design frames prédéfinis créés par Replit, recherchables et regroupés par type : affiches, publications sur les réseaux sociaux, pages de destination, formats mobiles, bannières et prototypes. Cliquez sur l’un d’eux ou faites-le glisser pour l’ajouter à votre design ; il apparaît sur le Canvas sous forme de frame modifiable, comme tout ce que vous avez généré vous-même.

<div id="inspiration">
  ## Inspiration
</div>

Captures d’écran d’interfaces de produits réels, sélectionnées par Mobbin. Recherchez des écrans d’app, comme *« onboarding Airbnb »* ou *« checkout Coinbase »*, puis cliquez sur l’un d’eux pour le placer sur le Canvas comme image de référence statique. Inspiration n’ajoute aucun code à votre projet : vous pouvez la consulter, y faire référence dans le Chat ou l’utiliser comme référence lors de votre prochaine génération.

<div id="library">
  ## Bibliothèque
</div>

Vos créations : les designs et artefacts déjà créés dans ce projet, prêts à être réintégrés dans le Canvas.

<div id="templates-vs-inspiration">
  ## Modèles et Inspiration
</div>

|               | Modèles                                        | Inspiration                                             |
| ------------- | ---------------------------------------------- | ------------------------------------------------------- |
| Description   | Des design frames de départ créés par Replit   | Des captures d’écran d’interface de produits réels, via Mobbin |
| Sur le Canvas | Un frame actif et modifiable dans votre design | Une image de référence statique                         |
| Utilisation   | Partir d’un design fonctionnel                 | Guider l’apparence de votre prochaine génération        |

Consultez [Ajouter des modèles et de l’inspiration](/fr/design/add-templates-and-inspiration) pour suivre le parcours guidé.
