O Console permite monitorar e revisar em tempo real os logs impressos pelo seu Replit App em execução.
Você pode usar informações de execuções atuais e anteriores para entender o comportamento do seu aplicativo,
solucionar erros e otimizar o desempenho.

<Tip>
  Ao depurar usando o Agent, inclua os logs do console no seu prompt para fornecer contexto.
</Tip>

## Recursos

O Console oferece as seguintes ferramentas para ajudar você a entender o comportamento do seu aplicativo:

* **Registro em tempo real**: veja a saída do seu aplicativo enquanto ela acontece
* **Assistência de IA**: receba sugestões para corrigir erros relatados nos logs
* **Histórico de execuções**: mostra logs de execuções anteriores para acompanhar as alterações

## Uso

Você pode acessar a ferramenta Console diretamente no seu Editor de Projetos.

<Accordion title="Como acessar o Console">
  No **Tool dock** à esquerda:

  1. Selecione <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="ícone de todas as ferramentas" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools** para ver uma lista das ferramentas do Editor de Projetos.
  2. Selecione <img class="icon-svg" src="/assets/mirror/console-8a41ac90789c.svg" alt="ícone do Console" width="16" height="16" data-path="images/icons/console.svg" /> **Console**.

  Na **barra de pesquisa**:

  1. Selecione a <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="ícone de lupa" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> lupa no topo para abrir a ferramenta de pesquisa
  2. Digite "Console" para localizar a ferramenta e selecioná-la nos resultados.
</Accordion>

Cada vez que você usa o botão **Run** no seu Replit App, o Console exibe uma nova entrada que inclui as seguintes informações:

* O comando que executou seu código
* Informações de data e hora
* Logs de saída padrão e de erro

### Depuração com IA

Quando você encontrar erros ou outras informações nos logs que deseja entender, selecione o botão
**Ask AI** no topo da entrada. Isso abre automaticamente a aba **Agent** e
envia o conteúdo do log para análise.

### Comandos de entrada de log

O Console oferece as seguintes ferramentas para gerenciar seus logs:

* **Show Only Latest**: ative esse controle para exibir apenas a execução mais recente.
* **Collapse entry**: selecione a <img class="icon-svg" src="/assets/mirror/down-arrow-9c1cf9fd152e.svg" alt="ícone de seta para baixo" height="16" width="16" data-path="images/icons/down-arrow.svg" /> seta para baixo à esquerda do nome do comando para ocultar os logs.
* **Clear past runs**: selecione isso para excluir os logs de execuções anteriores. Essa ação é irreversível.

### Disponibilidade de rede

Você pode controlar a disponibilidade online da versão de desenvolvimento do seu aplicativo.

Para parar de atender solicitações para a URL de desenvolvimento, selecione o ícone <img class="icon-svg" src="/assets/mirror/network-off-5bdca8a4fe4e.svg" alt="ícone de rede desativada" height="16" width="16" data-path="images/icons/network-off.svg" /> globo com um traço
no lado direito da linha de informações de rede.

Para ativá-la, selecione o ícone <img class="icon-svg" src="/assets/mirror/network-on-15be2e5fb4f5.svg" alt="ícone de rede ativada" height="16" width="16" data-path="images/icons/network-on.svg" /> globo.

Para ver sua URL de desenvolvimento, selecione o texto `{...}.replit.dev` na barra de localização.

### Parar um comando de workflow

Você pode parar um comando de workflow em execução na ferramenta Console do Editor de Projetos.

Selecione o botão quadrado no lado direito da linha que contém o comando de execução do seu Replit App para encerrá-lo.

Para reiniciar seu aplicativo, use o botão **Run** do workflow no topo do Editor de Projetos.
