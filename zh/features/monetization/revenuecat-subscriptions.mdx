<div id="what-is-revenuecat">
  ## 什么是 RevenueCat
</div>

RevenueCat 可让你为[原生移动应用](/zh/features/artifact-types/building-mobile-apps)添加应用内订阅。要开始使用，只需让 Agent 设置订阅并连接你的 RevenueCat 账户，Agent 会处理相关逻辑并提供测试环境。

<div id="prerequisites">
  ## 前置条件
</div>

开始之前，你需要准备：

* 一个使用 **Mobile app** 创建的 Replit project
* 一个 [RevenueCat](https://www.revenuecat.com) 账户 (只需邮箱和密码，无需银行账户或其他额外设置)

<Note>
  要开发原生移动应用，请在 [replit.com](https://replit.com) 上使用 Project Editor。在支持的情况下，也可以在 Replit Android 应用中进行原生移动应用开发。如果你使用的是 Replit iOS 应用，请在 replit.com 上打开该 project。
</Note>

<div id="test-subscriptions">
  ## 测试订阅
</div>

Replit 预览使用 RevenueCat 的**测试模式**。在 Expo Go 中测试购买时，你看到的是测试购买对话框，而不是真实的支付流程，不会产生任何扣款。

<Frame>
  <img src="/assets/mirror/revenuecat-test-purchase-8414145a112e.png" alt="移动设备上的测试购买对话框，显示套餐详情和测试按钮" width="683" height="1253" data-path="images/replitai/revenuecat-test-purchase.png" />
</Frame>

<Tip>
  开发阶段可以放心使用测试购买。你可以测试购买成功和失败两种流程，都不会产生真实扣款。
</Tip>

<Warning>
  一旦 Apple 批准你的应用在 App Store 上架，购买就会使用真实资金。
  在提交应用审核之前，请确认你的 RevenueCat 产品和定价无误。
</Warning>

<div id="syncing-to-app-store-connect">
  ## 同步到 App Store Connect
</div>

若要让应用内购买在 TestFlight 和 Apple App Store 中正常使用，[你需要同意
Apple 的付费应用协议并绑定银行账户](https://developer.apple.com/help/app-store-connect/manage-agreements/sign-and-update-agreements/)。
这些操作需在 App Store Connect 中完成。此外，将应用提交到 App Store 之前，你需要拥有付费的 Apple 开发者账户。

完成后，你就可以直接在 Replit 中把 RevenueCat 的应用内购买配置同步到 App Store Connect。

<Steps>
  <Step title="前往 Publishing 中的 Manage 面板">
    你会看到一个将 RevenueCat 同步到 App Store Connect 的按钮。

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-sync-btn-46a2e4e696df.png" alt="将 RevenueCat 同步到 App Store Connect 的按钮" width="1476" height="604" data-path="images/replitai/revenuecat-asc-sync-btn.png" />
    </Frame>

    <Tip>
      此部分仅在你将应用提交到 TestFlight 之后才会出现。
    </Tip>
  </Step>

  <Step title="提供 App Store Connect API 密钥">
    你需要前往 App Store Connect 获取此密钥。

    在 [App Store Connect](https://appstoreconnect.apple.com/access/integrations/api) 中，前往 **Users and Access**，然后选择 **Integrations** 标签页。在侧边栏中选择 **App Store Connect API**。

    创建密钥时，请务必为其授予“App Manager”权限。

    请立即下载 .p8 文件——该文件只能下载一次。文件名以 `AuthKey_` 开头，以 `.p8` 结尾。

    复制此页面上显示的 **Key ID** 和 **Issuer ID**。

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-create-c54be8304d7c.png" alt="App Store Connect 的 Users and Access 页面，带编号步骤标出 Integrations 标签页、App Store Connect API 侧边栏链接，以及用于创建新 API 密钥的加号按钮" width="2390" height="752" data-path="images/replitai/revenuecat-asc-create.png" />
    </Frame>

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-app-manager-93996acd8561.png" alt="App Store Connect 中的 Generate API Key 对话框，名称设置为 RevenueCat，Access 设置为 App Manager" width="1116" height="560" data-path="images/replitai/revenuecat-asc-app-manager.png" />
    </Frame>

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-copy-07a95e1be9af.png" alt="App Store Connect API 密钥页面，箭头指向 Issuer ID 的 Copy 链接和 Key ID 列" width="2330" height="780" data-path="images/replitai/revenuecat-asc-copy.png" />
    </Frame>
  </Step>

  <Step title="创建应用内购买 API 密钥">
    按上一步的方法再创建一个应用内购买 API 密钥。
    在侧边栏中选择 **In-App Purchase**，然后创建一个具有 **App Manager** 权限的 API 密钥。
    下载 .p8 密钥 (文件名以 `SubscriptionKey_` 开头，以 `.p8` 结尾) ，并复制 **Key ID** 和 **Issuer ID**。

    <Frame>
      <img src="/assets/mirror/revenuecat-iap-api-key-7eb34e815ccb.png" alt="App Store Connect 的 Users and Access 页面，侧边栏中已选中 In-App Purchase，箭头指向用于创建新密钥的加号按钮" width="2272" height="637" data-path="images/replitai/revenuecat-iap-api-key.png" />
    </Frame>
  </Step>

  <Step title="同步产品">
    确认产品列表，然后同步到 App Store Connect。

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-products-sync-078d42af83ba.png" alt="管理应用内购买对话框，显示带有价格、时长和地区字段的月度订阅产品，以及一个同步到 App Store Connect 的按钮" width="948" height="476" data-path="images/replitai/revenuecat-asc-products-sync.png" />
    </Frame>
  </Step>
</Steps>

<div id="frequently-asked-questions">
  ## 常见问题
</div>

<AccordionGroup>
  <Accordion title="使用 RevenueCat 需要银行账户吗？">
    不需要。创建 RevenueCat 账户只需邮箱和密码。当你准备从 App Store 或
    Google Play 收款时，银行账户需另行通过 Apple 或 Google 设置。
  </Accordion>

  <Accordion title="测试购买会产生扣款吗？">
    不会。开发阶段，Replit 的预览使用 RevenueCat 的测试模式，
    购买均为模拟，不会产生真实扣款。只有在你的应用通过 Apple 应用审核后，
    才会产生真实扣款。
  </Accordion>

  <Accordion title="我可以在 web app 中使用 RevenueCat 吗？">
    RevenueCat 专为原生移动应用设计。如果要为 web app 添加订阅功能，
    请改用 [Stripe integration](/zh/features/monetization/stripe-payments)。
  </Accordion>

  <Accordion title="使用 RevenueCat 可以配置哪些内容？">
    你可以设置按月或按年的订阅、配置价格、管理权益并搭建付费墙。
    只需让 Agent 进行修改——它会同时处理 RevenueCat 配置和你的应用代码。
  </Accordion>
</AccordionGroup>
