Функции Replit на базе ИИ используют оплату по мере использования: плата зависит от того, что вы создаёте и насколько активно используете наши инструменты на базе ИИ. Благодаря этому вы платите только за ценность, которую получаете от Agent.

<div id="getting-started">
  ## Начало работы
</div>

**Все подписчики** получают бесплатные одноразовые чекпоинты Agent.

Дополнительные ежемесячные кредиты автоматически используются для работы с ИИ:

* **Подписчики Core**: Ежемесячные кредиты (см. [тарифы](https://replit.com/pricing))
* **Подписчики Pro**: Многоуровневые ежемесячные кредиты с переносом на {ProCreditRolloverPeriod}. Подробнее см. в разделе [Replit Pro](/ru/billing/plans/replit-pro).

Эти кредиты покрывают использование Agent и других облачных сервисов Replit, включая опубликованные приложения, хранилище и базы данных. Для бесплатной работы начните с Free Mode. В режимах [Power или Max](/ru/features/agent/agent-modes) выберите Auto, чтобы Replit автоматически подобрал модель для платной работы.

Free Mode позволяет подписчикам Core и Pro выполнять повседневные задачи в Agent бесплатно в пределах доступного лимита. Для платных режимов и подтверждённых платных задач используется оплата по объёму работы в зависимости от сложности запроса. Перед началом платного действия Replit запрашивает подтверждение.

<div id="how-effort-based-pricing-works">
  ### Как работает оплата по объёму работы
</div>

Когда вы общаетесь с Agent в «Build Mode», он создаёт **чекпоинты**, в которых сохраняется результат работы по вашему запросу:

* **Простые запросы** (например, исправление ошибок или небольшие изменения) обычно стоят дешевле сложных задач
* **Сложные задачи** (например, полноценные функции или интеграции) объединяются в один чекпоинт, который может стоить дороже простого запроса и отражает общий объём затраченных усилий
* **Один чекпоинт на запрос** исключает промежуточные чекпоинты и упрощает расчёты
* **Прозрачное ценообразование** позволяет точно увидеть, за что вы платите по каждой выполненной задаче

<Info>
  Чекпоинт создаётся, когда Agent завершает работу по вашему запросу и реализует
  запрошенную функциональность в вашем коде.
</Info>

В платном тарифе Plan Mode может выполнять платные рассуждения, даже если код не изменяется.

Подробную информацию о том, что сохраняют чекпоинты и как они работают, см. в разделе [Чекпоинты и откаты](/ru/features/version-control/checkpoints-and-rollbacks).

<div id="agent-services-billing">
  ### Оплата сервисов Agent
</div>

Некоторые функции Agent используют платные API сторонних сервисов (например, Claude, ChatGPT и Nano Banana / Gemini). Agent автоматически управляет этими интеграциями — ключи API и настройка не требуются. Плата взимается по публичному тарифу API соответствующего поставщика и списывается с ваших кредитов Replit. Эти расходы отображаются на [панели использования](/ru/billing/managing-spend) вместе с остальными данными об использовании.

Чтобы узнать стоимость примеров приложений, воспользуйтесь нашей простой [интерактивной демонстрацией](https://agent-pricing.replit.app/).

<div id="track-your-usage">
  ### Отслеживайте использование
</div>

Вы можете отслеживать расходы на Agent в реальном времени:

1. **Вкладка Agent**: Просматривайте стоимость отдельных чекпоинтов, наведя указатель на иконку использования
2. **Панель использования**: Просматривайте подробную платёжную информацию за текущий период
3. **Settings**: Настройте оповещения и бюджеты в разделе **Account** → **Billing**, чтобы контролировать расходы

<Tip>
  Данные об использовании могут появиться на панели использования в течение 30 минут.
</Tip>

<div id="managing-your-spend">
  ## Управление расходами
</div>

Контролируйте расходы на ИИ с помощью встроенных инструментов управления бюджетом Replit:

* **Оповещения об использовании**: Получайте уведомления при достижении заданных порогов расходов
* **Лимиты бюджета**: Устанавливайте жёсткие лимиты, чтобы избежать неожиданных списаний
* **Отслеживание в реальном времени**: Контролируйте расходы в процессе разработки
* **Пакеты кредитов**: Покупайте дополнительные кредиты со скидкой при крупных покупках. Подробнее см. в разделе [Управление расходами](/ru/billing/managing-spend).

<div id="next-steps">
  ## Следующие шаги
</div>

Готовы начать разработку с ИИ? Вот как извлечь максимум пользы из ваших кредитов:

* **Сначала попробуйте Agent**: Используйте бесплатные чекпоинты, чтобы изучить возможности Agent
* **Начните с малого**: Начните с простых запросов, чтобы разобраться в оплате по объёму работы
* **Используйте Free Mode**: Начните с [Free Mode](/ru/features/agent/agent-modes) для повседневных задач
* **Настройте оповещения**: Настройте уведомления о расходах, прежде чем израсходуете все кредиты

Узнайте больше об [ИИ-инструментах Replit](/ru/welcome) или ознакомьтесь с нашими [тарифами](https://replit.com/pricing).
