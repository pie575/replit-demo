Lorsque vous publiez une application web sur Replit, un audit d’optimisation pour les moteurs de recherche (SEO) est automatiquement effectué sur son URL publique, et une note SEO s’affiche dans l’outil Publishing. Si cette note peut être améliorée, vous pouvez transmettre les problèmes identifiés à Agent en un clic pour les résoudre en quelques secondes.

Pour la plupart des créateurs, le processus est simple : publiez l’application, vérifiez la note, puis demandez à Agent : &quot;Optimise le SEO&quot;. Cette page explique ce qui se passe en arrière-plan et comment en tirer le meilleur parti.

<div id="seo">
  ## Qu’est-ce que le SEO et pourquoi est-il important ?
</div>

L’optimisation pour les moteurs de recherche (SEO) consiste à concevoir votre site de sorte que des moteurs de recherche comme Google puissent le trouver, le comprendre et le classer. Un bon SEO permet à votre application d’apparaître dans les résultats lorsque des internautes recherchent ce que vous proposez, sans avoir à dépenser en publicité.

Quelques facteurs déterminent l’essentiel de vos performances SEO : des titres et descriptions de page clairs, du HTML sémantique, des temps de chargement rapides, une mise en page adaptée aux mobiles, un texte alternatif descriptif pour les images et une structure de site explorable. Les moteurs de recherche privilégient les sites faciles à lire, tant pour les internautes que pour les machines.

Si vous lancez une page de destination, un site marketing, un blog, un répertoire ou tout autre contenu dont la visibilité dans les moteurs de recherche est importante, le SEO est l’un des investissements les plus rentables à réaliser dès le départ.

<div id="replit-seo">
  ## Comment Replit améliore le SEO par défaut
</div>

Replit prend en charge une grande partie des fondamentaux du SEO afin que vous puissiez vous concentrer sur votre contenu et vos produits.

* **Hébergement rapide et distribué dans le monde entier** : les déploiements Replit hébergent votre application sur une infrastructure optimisée pour la vitesse, et vous pouvez choisir où elle s’exécute grâce à la [région du projet](/fr/ko/features/publishing/project-geography).
* **HTTPS intégré** : chaque application publiée reçoit un certificat TLS géré par Replit, un signal de classement essentiel pour les moteurs de recherche.
* **Domaines personnalisés** : connectez votre propre domaine afin de renforcer la confiance et l’autorité de votre marque. Consultez [Custom Domains](/fr/ko/features/publishing/custom-domains).
* **Déploiements statiques pour les sites de contenu** : pour les pages marketing, les blogs et la documentation, les [déploiements statiques](/fr/ko/features/publishing/deployment-types#static) fournissent du HTML prérendu que les moteurs de recherche peuvent facilement explorer.
* **Agent écrit du code optimisé pour le SEO** : lorsque Agent génère des pages, il crée par défaut du HTML sémantique, un balisage accessible et des balises méta. Ce sont les mêmes éléments que vérifient les outils SEO.
* **Score SEO** : des audits exécutés automatiquement après la publication vous permettent de toujours connaître l’état actuel et de transmettre les problèmes détectés à Agent pour les corriger en un clic.

<div id="section">
  ### Où les consulter
</div>

Dans votre application publiée, ouvrez l’outil **Publishing**. Les scores SEO s’affichent dans l’aperçu du déploiement, avec d’autres détails sur le build. Survolez un score pour voir les mesures spécifiques indiquées par Lighthouse pour chaque page.

<Note>
  Si vous ne voyez pas les scores SEO, votre application est peut-être privée ou n’a pas été publiée récemment. Les scores s’affichent uniquement pour les applications web publiques publiées.
</Note>

<div id="section-2">
  ### Comprendre les notes
</div>

Replit affiche l’une des trois notes suivantes, basées sur les audits Lighthouse.

| Note        | Signification                                                                                                       |
| :---------- | :------------------------------------------------------------------------------------------------------------------ |
| Sain        | Votre application respecte les bonnes pratiques SEO. Continuez à la surveiller après des modifications importantes. |
| À améliorer | Plusieurs problèmes empêchent les moteurs de recherche de bien comprendre votre application.                        |
| Faible      | Des éléments essentiels du SEO sont manquants. Vous pouvez généralement les corriger en quelques minutes.           |

Si votre application comporte plusieurs pages, le badge affiche la note **la plus basse** parmi toutes les URL explorées par Replit, afin que la page la plus problématique apparaisse en premier, sans être diluée par une moyenne.

<div id="section-3">
  ### Quand le score est-il calculé ?
</div>

L&#39;audit s&#39;exécute automatiquement à chaque publication réussie. Le score apparaît généralement une à deux minutes après la mise en ligne du déploiement, et l&#39;outil Publishing actualise le badge dès réception des résultats.

<div id="section-4">
  ### Types de déploiement pris en charge
</div>

Les notes SEO ne sont calculées que pour les déploiements web publics, dont les URL peuvent être explorées par les moteurs de recherche.

* [Déploiements Autoscale](/fr/ko/features/publishing/deployment-types#autoscale)
* [Déploiements Reserved VM](/fr/ko/features/publishing/deployment-types#reserved-vm)
* [Déploiements statiques](/fr/ko/features/publishing/deployment-types#static)

Les Scheduled deployments et les déploiements privés ne génèrent pas de note SEO, car ils ne traitent aucun trafic web public.

<div id="agent-seo">
  ## Optimiser le SEO avec Agent
</div>

Le bouton **Optimize SEO with Agent** s’affiche à côté de la note. Sélectionnez-le pour ouvrir le [SEO Agent](/fr/ko/features/publishing/seo-agent) dans le panneau Growth. Vous pourrez y effectuer un audit technique du SEO, examiner les problèmes détectés et appliquer des corrections en un clic.

<Tip>
  Vous pouvez aussi procéder directement sans utiliser le bouton. Ouvrez Agent et dites **&quot;Optimise le SEO&quot;**. Agent récupérera les derniers résultats et commencera à résoudre les problèmes un par un.
</Tip>

Une fois qu’Agent a terminé les modifications, publiez à nouveau votre application. La note SEO est recalculée en fonction du nouveau build et le badge est automatiquement mis à jour.

Corrections courantes appliquées par Agent :

* Ajout ou réécriture des balises `<title>` manquantes ou génériques afin de donner à chaque page un titre unique et descriptif
* Ajout de méta-descriptions à toutes les pages
* Ajout d’un texte `alt` descriptif aux images
* Définition de l’attribut `lang` sur l’élément `<html>`
* Vérification que les liens comportent un texte identifiable (pas de « cliquez ici » ni d’ancres vides)
* Ajout de `robots.txt` et de `sitemap.xml`
* Ajout d’une balise méta viewport pour l’affichage sur mobile
* Amélioration du contraste des couleurs des textes qui ne respectent pas les exigences d’accessibilité
* Ajout de balises méta Open Graph et Twitter Card afin que les liens vers l’application s’affichent correctement sur les plateformes sociales

<div id="replit-seo-2">
  ## Bonnes pratiques pour créer des sites optimisés pour le SEO avec Replit
</div>

Que vous confiiez ces tâches à Agent ou que vous les réalisiez vous-même, suivez ces recommandations pour tirer le meilleur parti des applications créées avec Replit.

* **Donnez à chaque page un titre et une méta-description uniques.** Visez des titres de moins de 60 caractères et des descriptions d’environ 150~160 caractères.
* **Utilisez du HTML sémantique.** Structurez votre mise en page avec `<main>`, `<header>`, `<nav>` et `<footer>`. N’utilisez `<h1>` qu’une seule fois par page et hiérarchisez les niveaux de titre dans l’ordre.
* **Ajoutez un texte alternatif à chaque image.** Décrivez ce que montre l’image, plutôt que ce qu’elle est.
* **Créez `sitemap.xml` et `robots.txt`.** Demandez à Agent de créer ces deux fichiers afin que les moteurs de recherche sachent quoi explorer.
* **Ajoutez des balises Open Graph et Twitter Cards.** Vous pouvez contrôler l’apparence de votre application lorsqu’elle est partagée sur les réseaux sociaux.
* **Utilisez un domaine personnalisé.** Un domaine à votre marque inspire confiance aux visiteurs comme aux moteurs de recherche. Consultez [Custom Domains](/fr/ko/features/publishing/custom-domains).
* **Choisissez le type de déploiement approprié.** Pour les sites riches en contenu, les [déploiements statiques](/fr/ko/features/publishing/deployment-types#static) fournissent du HTML prérendu que les moteurs de recherche peuvent analyser immédiatement.
* **Ajoutez des données structurées.** Le balisage JSON-LD aide les moteurs de recherche à afficher des résultats enrichis pour les produits, les articles, les FAQ et les événements.
* **Maintenez votre application rapide.** Optimisez les images, évitez les scripts qui bloquent le rendu et utilisez l’hébergement de Replit pour maintenir des temps de réponse faibles.

Voici une méthode simple pour appliquer la plupart de ces recommandations en une seule fois :

<AiPrompt>
  Auditez mon site selon les bonnes pratiques SEO et appliquez les corrections. Ajoutez un sitemap, robots.txt, des balises Open Graph, des données structurées lorsque cela est pertinent, et assurez-vous que chaque page possède un titre et une méta-description uniques.
</AiPrompt>
