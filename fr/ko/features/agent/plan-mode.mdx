<div id="plan">
  ## Qu&#39;est-ce que le mode Plan ?
</div>

Le mode Plan vous permet de :

* **Faire de l&#39;idéation** en explorant différentes approches pour votre projet
* **Planifier vos travaux de développement** sous forme de liste de tâches structurée
* **Collaborer avec l&#39;IA** sur l&#39;architecture du projet et la planification des fonctionnalités
* **Obtenir des conseils stratégiques et poser des questions** sans modifier le code ni les données de votre projet
* **Basculer en toute fluidité** vers le mode Build lorsque vous êtes prêt

Le mode par défaut s&#39;appelle désormais le mode **Build**.

Contrairement au mode Build, le mode Plan met l&#39;accent sur la planification et l&#39;idéation, afin de vous aider à bien penser votre projet avant d&#39;écrire la moindre ligne de code.

<div id="section">
  ## Premiers pas
</div>

<div id="plan-2">
  ### Accéder au mode Plan
</div>

Le mode Plan est disponible dans toutes les applications Replit où Agent est activé. Pour y accéder :

1. **Ouvrez votre application Replit dans le Project Editor**
2. **Repérez le sélecteur de mode en bas à gauche du champ de saisie du chat**
3. **Sélectionnez le mode Plan dans le menu déroulant**

<div id="section-2">
  ## Fonctionnalités principales
</div>

<div id="section-3">
  ### Planification des tâches
</div>

Le mode Plan excelle à découper les projets complexes en tâches gérables. Lorsque vous communiquez vos exigences à Agent, il génère une liste ordonnée des tâches de développement nécessaires pour mener à bien votre demande.

<div id="section-4">
  ### Idéation collaborative
</div>

Explorez différentes approches avec l&#39;IA :

* **Plusieurs pistes de résolution** pour les problèmes complexes
* **Analyse des avantages et des inconvénients** de chaque approche
* **Évaluation des risques** et stratégies d&#39;atténuation

<div id="section-5">
  ## Workflow : du plan au build
</div>

<div id="1-plan">
  ### 1. Phase de planification (mode Plan)
</div>

Lancez votre processus de développement en mode Plan :

* **Définissez** la portée et les objectifs du projet
* **Décomposez** les exigences en fonctionnalités concrètes
* **Planifiez** l&#39;architecture et la pile technique
* **Rédigez** une feuille de route de développement jalonnée

<div id="2">
  ### 2. Approuver les tâches
</div>

Lorsque l&#39;Agent génère la liste des tâches :

* **Passez en revue** les tâches proposées
* Sélectionnez **Démarrer le build** pour approuver le plan

Vous pouvez également poursuivre la conversation pour affiner le plan.

<div id="3-build">
  ### 3. Passer en mode Build
</div>

Lorsque vous êtes prêt à lancer l&#39;implémentation :

* **Cliquez sur « Démarrer le build »** pour approuver le plan
* **Agent bascule automatiquement** en mode Build
* **Agent commence à implémenter** les tâches approuvées
* **Suivez la progression** pendant la phase de développement

L&#39;utilisation du mode Plan est soumise à la même tarification basée sur l&#39;effort que les autres interactions avec Agent. Toutes les actions d&#39;Agent en mode Plan sont facturées, qu&#39;il s&#39;agisse de répondre à des questions, de fournir des conseils ou de générer une liste de tâches. Les demandes plus complexes ou les conversations au contexte plus long entraînent des frais plus élevés.

**Toutes les interactions avec Agent sont facturées** : qu&#39;Agent réponde par des explications textuelles ou qu&#39;il modifie du code, des frais s&#39;appliquent toujours, mais les petites demandes coûtent moins cher.

<div id="section-9">
  ## Bonnes pratiques
</div>

<div id="section-10">
  ### Rédiger des prompts efficaces
</div>

Pour tirer le meilleur parti du mode Plan :

* Soyez **précis** sur les exigences de votre projet
* Posez des **questions complémentaires** pour clarifier les suggestions de l&#39;IA
* **Demandez des exemples** lorsque vous abordez des concepts complexes
* **Discutez des compromis** entre les différentes approches
* **Itérez sur les idées** avant de valider une implémentation
* **Conservez les décisions importantes** en y faisant référence dans les conversations ultérieures
