应用的外观与功能同样重要。PixelGames 是智能手机上的 Game Boy，
奶油色机身、橄榄绿色屏幕和厚实的按钮正是它的精髓。普通的应用布局会

<div id="section">
  ## 故障排除
</div>

* **更改范围超出预期：** 请让 Agent 还原更改，并以一个屏幕或一个元素为单位说明更小范围的更改。
* **预览中显示正常，但在实际设备上看起来不同：** 请告知设备名称以及实际显示的效果。
  大多数情况下，原因在于安全区域或屏幕尺寸的处理方式。
* **更改反复被还原：** 同一个值可能在多个位置设置了。请询问 Agent 该屏幕的
  样式实际定义在何处。
