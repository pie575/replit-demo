Web 应用是 Replit 的默认输出类型。当你向 Agent 描述一个想法时，除非指定了其他 artifact 类型，否则它会构建一个全栈 Web 应用。

<div id="getting-started">
  ## 快速开始
</div>

创建 Web 应用 有两种方式：

* **输入 prompt**：在 Replit 主页描述你想构建的内容，Agent 会自动创建一个 Web 应用。
* **从下拉菜单选择**：在主页打开应用类型下拉菜单，选择 **Web 应用**，然后描述你的想法。

<div id="key-features">
  ## 主要功能
</div>

* **默认 full-stack**：每个 Web 应用 都包含前端和后端。Agent 会按应用需要自动配置 API 路由、数据库和服务端逻辑。
* **响应式设计**：应用自动适配各种屏幕尺寸。
* **即时发布**：一键发布应用，托管、SSL 和基础设施均由 Replit 负责。
* **共享基础设施**：如果你的 project 中有多个 artifact (例如移动应用或数据看板) ，它们会共用同一套后端、数据库和服务。

<div id="use-cases">
  ## 使用场景
</div>

* **SaaS 产品**：构建面向客户的工具、仪表板和平台。
* **内部工具**：为团队搭建管理后台、CRM 或工作流应用。
* **落地页**：上线包含表单、动画和动态内容的营销网站。
* **交易平台与目录站点**：构建信息发布网站、招聘平台或社区平台。
