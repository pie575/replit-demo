Claude나 GPT 같은 AI 모델은 강력하지만, 학습한 내용의 범위를 벗어나지 못합니다. Model Context Protocol(MCP)은 이러한 모델이 외부 도구와 데이터 소스, 실제 기능에 연결할 수 있는 표준화된 방법을 제공합니다.

<div id="why-ai-models-need-mcp">
  ## AI 모델에 MCP가 필요한 이유
</div>

외부 도구와 데이터에 접근할 수 없으면 AI 모델은 다음과 같은 작업을 할 수 없습니다.

* 최신 정보 접근
* 외부 시스템과 상호작용
* 실제 환경에서 작업 수행
* 비공개 데이터 활용

MCP는 AI가 도구와 데이터에 연결되는 보편적인 방식을 제공함으로써 이 문제를 해결합니다. USB-C가 기기 연결 방식을 표준화한 것과 비슷합니다.

  <img src="/assets/mirror/mcp-a04e01a01743.avif" alt="AI 모델이 외부 도구 및 데이터 소스에 연결되는 모습을 보여주는 MCP 다이어그램" width="1920" height="1055" data-path="images/tutorials/mcp.avif" />

MCP를 사용하면 AI 모델은 다음과 같은 작업을 할 수 있습니다.

* 전문 도구 및 API 접근
* 비공개 데이터 소스 읽기
* 실제 환경에서 작업 수행
* 다른 시스템과 매끄럽게 연결

<div id="how-mcp-works">
  ## MCP 작동 방식
</div>

MCP 아키텍처는 세 가지 주요 구성 요소로 이루어집니다.

1. **클라이언트 측** — 외부 도구에 접근해야 하는 Claude 같은 AI 모델이나 애플리케이션입니다.
2. **통신 계층** — 요청과 응답의 형식을 표준화하는 프로토콜 자체입니다.
3. **서버 측** — 도구, 데이터 소스, 특화된 기능에 대한 접근을 제공하는 프로그램입니다.

<AccordionGroup>
  <Accordion title="MCP 클라이언트란?">
    MCP 클라이언트는 Claude, Replit Agent, 또는 대규모 언어 모델에 연결되는 명령줄 인터페이스 같은 것을 말합니다. 외부 도구나 데이터 소스에 연결하는 &quot;기기&quot;에 해당합니다.

    MCP 클라이언트의 예:

    * 브라우저에서 사용하는 Claude
    * Replit Agent
    * AI용 명령줄 인터페이스
    * AI SDK로 만든 맞춤형 애플리케이션
  </Accordion>

  <Accordion title="MCP 서버란?">
    MCP 서버는 AI 모델에 도구와 기능을 제공합니다. AI에 문제 해결용 전문 도구 세트를 쥐여주는 것이라고 생각하면 됩니다.

    MCP 서버로 할 수 있는 일의 예:

    * 특정 데이터 소스에 접근해 질문에 답하기
    * AI를 API에 연결해 온라인에서 작업 수행하기
    * 파일 읽기 또는 쓰기
    * 계산 수행 또는 코드 실행
    * Notion, Linear, Stripe 같은 서비스에서 콘텐츠 가져오기
  </Accordion>
</AccordionGroup>

<div id="what-mcp-unlocks">
  ## MCP로 할 수 있는 일
</div>

MCP는 AI 애플리케이션에서 강력한 성능을 발휘할 수 있도록 여러 기본 요소를 정의합니다:

* **Resources** — AI 모델과 데이터 및 콘텐츠를 공유합니다
* **Tools** — AI 모델이 서비스를 통해 작업을 수행할 수 있게 합니다
* **Prompts** — 일관된 AI 상호작용을 위한 재사용 가능한 template입니다
* **Sampling** — 서비스가 AI 모델에 정보를 요청할 수 있게 합니다
* **Transports** — 클라이언트와 서버를 효율적으로 연결합니다

<div id="skills-vs-mcp-servers">
  ## Skills와 MCP 서버 비교
</div>

Skills와 MCP 서버는 AI 에이전트를 확장하는 두 가지 주요 방법으로, 서로 목적이 다릅니다.

|            | Skills                                              | MCP 서버                                    |
| ---------- | --------------------------------------------------- | ---------------------------------------------- |
| **적합한 용도** | workflows, conventions, 참고 자료                       | 외부 서비스 연결, 작업 실행                               |
| **로딩 방식**  | 가벼움 — 호출 전까지는 이름과 설명만 로드                            | 무거움 — 모든 도구 설명을 미리 로드                          |
| **정의하는 것** | 에이전트가 *어떻게* 작동할지                                    | 에이전트가 *무엇에* 접근할 수 있는지                          |
| **예시**     | &quot;Stock Analyzer&quot; skill — 특정 프레임워크로 투자 리서치 | &quot;Stripe&quot; MCP 서버 — 결제 및 구독 데이터 조회 |

skills를 바라보는 관점은 [Agent skills](/ko/learn/agent-skills)에서 확인하세요.

<div id="real-world-applications">
  ## 실제 활용 사례
</div>

MCP를 활용하면 다양한 AI 애플리케이션을 구현할 수 있습니다:

* 회사 데이터베이스에 접근해 구체적인 질문에 답변하는 **고객 서비스 시스템**
* 여러 출처에서 콘텐츠를 검색하고 요약하는 **리서치 어시스턴트**
* 사용자의 파일 및 애플리케이션과 상호작용하는 **생산성 도구**
* 미디어 라이브러리와 퍼블리싱 플랫폼에 접근하는 **콘텐츠 제작 도구**

<div id="benefits">
  ## 이점
</div>

MCP는 세 가지 핵심 이점을 제공합니다:

* AI가 즉시 연결할 수 있는 바로 사용 가능한 integration
* 연결을 다시 구성하지 않고도 AI provider를 전환할 수 있는 유연성
* 민감한 데이터를 안전하게 보호하는 보안 기능

<Note>
  MCP는 AI 생태계 전반으로 지원이 확대되고 있는 신생 표준입니다. 새로운 도구와 integration이 꾸준히 추가되고 있습니다.
</Note>
