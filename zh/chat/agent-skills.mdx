Skill 是一个包含可复用指令和辅助文件的文件夹。你可以用它来定制 Replit 处理某项重复性任务、规范或工作流的方式。

在提示框中打开**加号**菜单，然后选择 **Use a skill**。挑选与任务相符的 Skill，并告诉 Replit 你想要的结果。

<div id="choose-the-right-connection">
  ## 选择合适的连接方式
</div>

* 使用 **Skill** 提供可复用的说明、示例和辅助材料。
* 如需使用受支持的服务及其已获授权的信息或操作，请使用 [integration](/zh/chat/integrate-your-tools)。
* 如需使用通过兼容的 MCP server 或 client 公开的工具，请使用 [MCP](/zh/chat/connect-through-mcp)。
