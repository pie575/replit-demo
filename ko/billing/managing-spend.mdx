Replit에서는 기본 제공되는 예산 관리 기능을 활용하고, [AI Agent](/ko/features/agent/overview) 사용 방식을 최적화하고, credit packs를 구매하고, 사용량 패턴을 모니터링하는 방법으로 비용을 관리할 수 있습니다. [AI 요금 청구](/ko/billing/ai-billing)에 대해 자세히 알아보세요.

<div id="optimize-ai-costs">
  ## AI 비용 최적화
</div>

[Agent](/ko/features/agent/overview)와 같은 AI 기능은 강력한 도구이지만, 전략적으로 활용하면 비용을 관리하면서 가치를 극대화할 수 있습니다. AI 지출을 줄이는 효과적인 방법을 소개합니다.

<div id="use-plan-mode-for-cost-effective-collaboration">
  ### 비용 효율적인 협업을 위해 Plan Mode 사용하기
</div>

[Plan Mode](/ko/features/agent/plan-mode)는 AI 비용을 절감하는 가장 효과적인 방법 중 하나입니다. Plan Mode를 활성화하면 Agent가 코드를 변경하지 않고 상세한 계획을 작성합니다. 이 방식에는 다음과 같은 비용 이점이 있습니다:

* **작업 시작 전 Chat**: 작업에 착수하기 전에 Agent와 접근 방식을 논의하고 다듬을 수 있습니다
* **낮은 token 비용**: 계획 단계의 대화는 코드 생성이나 편집보다 token을 적게 사용합니다
* **정확한 목표 설정**: 계획을 검토하고 조정해 Agent가 꼭 필요한 작업에만 집중하도록 합니다
* **반복적인 개선**: 구현에 token을 쓰기 전에 scope를 정확하게 정할 수 있습니다

해결책을 탐색하거나, requirements를 다듬거나, 구현에 앞서 접근 방식을 파악하고 싶을 때 [Plan Mode](/ko/features/agent/plan-mode)를 사용하세요.

<div id="control-costs-with-agent-modes">
  ### Agent modes로 비용 관리하기
</div>

[Agent modes](/ko/features/agent/agent-modes)를 사용하면 비용과 성능 중 무엇을 우선할지 선택할 수 있습니다.

* **Free Mode**: plan에 포함된 allowance 범위 내에서 무료로 처리하는 일상적인 Agent 작업입니다.
* **Auto**: Power 또는 Max의 유료 작업에 사용할 model을 자동으로 선택합니다.
* **Power**: 합리적인 가격으로 더 뛰어난 성능을 제공합니다.
* **Max**: 가장 까다로운 작업에 적합한 최고 수준의 프런티어 model입니다.

Agent는 빌드하는 동안 자신이 작성한 코드를 자동으로 검토해 실수를 잡아내고 비용이 많이 드는 재작업을 줄여줍니다. 켜거나 끄는 설정은 따로 없습니다. 지출을 더 세밀하게 관리하려면 Plan Mode로 작업 scope를 먼저 정하세요.

* **실행 전 검토**: Agent가 changes를 적용하기 전에 어떤 작업을 하려는지 미리 확인할 수 있습니다.
* **선택적 승인**: 목표에 맞는 changes만 승인하고 나머지는 건너뛸 수 있습니다.

<Tip>
  일상적인 작업은 [Free Mode](/ko/features/agent/agent-modes)로 시작하세요. 합리적인 가격으로 더 뛰어난 성능이 필요하다면 [Power mode](/ko/features/agent/agent-modes)를 선택하세요. 먼저 계획을 세운 뒤 changes를 단계별로 승인하면 됩니다.
</Tip>

<div id="purchase-credit-packs">
  ## credit packs 구매
</div>

Core 또는 Pro plan을 사용 중이고 월 구독 allowance보다 많은 credits가 필요하다면, **Settings** → **Account usage** → **Credits** → **Purchase credit pack**에서 credit packs를 구매할 수 있습니다. credit packs는 많이 구매할수록 할인 폭이 커지므로, 일시적인 usage 급증에 대응하거나 규모가 큰 projects를 준비할 때 유용합니다.

<div id="how-credit-packs-work">
  ### credit packs 작동 방식
</div>

* **구매 위치**: Core 및 Pro plan 고객은 **Settings** → **Account usage** → **Credits** → **Purchase credit pack**에서 구매할 수 있습니다
* **만료**: credit packs는 구매일로부터 6개월 후 만료됩니다
* **자동 갱신 없음**: credit packs는 자동으로 갱신되지 않습니다
* **이월 없음**: 팩에 남은 credits는 만료 후 이월되지 않습니다
* **자동 사용**: credits는 만료일이 가장 빠른 credit pack부터 자동으로 차감되므로 구매한 credits를 최대한 활용할 수 있습니다
* **자동 재충전**: 자동 재충전을 켜두면 balance가 부족할 때 *새* credit pack이 자동으로 구매되어 project 작업 도중 흐름이 끊기지 않습니다
* **언제든지 관리**: **Settings** → **Billing**에서 자동 재충전을 켜거나 조정하거나 끌 수 있습니다

<Note>
  usage limits와 예산은 보유 중인 credit packs를 모두 사용한 이후의 usage에 적용됩니다. 팩으로 구매한 credits 범위 내에서만 사용하려면 모든 limit을 $0.01로 설정하세요.
</Note>

<div id="view-payment-receipts">
  ### 결제 영수증 보기
</div>

계정에서 충전을 사용하는 경우 **Settings** → **Billing**을 열고 **Payment receipts**에서 완료된 일회성 충전 및 자동 재충전 결제 내역을 확인하세요. 각 행에는 결제 날짜, 구매 유형, 금액, 환불 상태가 표시됩니다. **View receipt**를 선택하면 결제 제공업체에서 발행한 영수증이 열립니다.

<div id="set-up-limits-and-budgets">
  ## 한도 및 예산 설정
</div>

모든 사용량 기반 청구 서비스에 월별 사용량 한도와 예산을 설정해 비용을 모니터링하고 관리할 수 있습니다.

<div id="usage-limits">
  ### Usage limits
</div>

Usage limits는 월별 credits를 초과하는 지출에 상한을 설정합니다. 한도에 도달하면 다음 billing 주기가 시작되거나 한도를 높이기 전까지 사용량 기반 서비스가 차단됩니다.

Core 계정은 **Settings** → **Account** → **Usage**로 이동한 뒤, **Account usage** 섹션에서 **Manage limits**를 선택해 usage limit을 설정하세요. Organization의 경우 [usage page](https://replit.com/usage)를 열고 **Account usage** 아래의 **Manage limits**를 선택하세요.

<div id="service-shutdown-limit">
  ### 서비스 중단 한도
</div>

이 한도에 도달하면 예산을 늘리거나 다음 결제 주기가 시작될 때까지 서비스가 일시 중단됩니다. 이를 통해 추가 요금이 발생하는 것을 방지할 수 있습니다.

이 한도는 [Usage limits](#usage-limits)에서 설명한 것과 동일한 **Manage limits** 대화 상자에서 설정합니다.

<div id="organization-budgets">
  ### Organization 예산
</div>

Organization의 경우 [설정 페이지](https://replit.com/t/replit/settings/billing)에서 usage 예산을 설정할 수 있습니다. 예산은 {OrganizationBudgetIncrement} 단위로 지정해야 합니다.

<Note>월별 usage limit을 활성화하려면 Organization의 Admin 또는 소유자 permissions이 필요합니다. 권한이 없다면 Organization 소유자에게 문의하세요.</Note>

<div id="per-user-spend-limits">
  ### 사용자별 spend limits
</div>

Enterprise 관리자는 개별 멤버에게 workspace 기본값과 다른 spend limit을 지정할 수 있습니다. 이를 활용하면 사용량이 많은 사용자에게 더 높은 상한을 부여하거나, 나머지 workspace 설정은 그대로 둔 채 특정 멤버의 지출만 줄일 수 있습니다.

<Steps>
  <Step title="workspace usage page 열기">
    Enterprise workspace에서 [usage page](https://replit.com/usage)를 엽니다. **Agent users** 표에는 workspace의 모든 멤버와 각 멤버의 현재 usage가 표시됩니다.
  </Step>

  <Step title="멤버의 limit 편집">
    조정할 멤버를 찾아 **Usage limit** 열에서 편집 icon을 선택합니다. 대화 상자에는 workspace 기본값, 적용 중인 group limit, 새 사용자별 limit을 입력하는 필드가 표시됩니다.

    <Frame>
      <img src="/assets/mirror/edit-usage-limit-87127319c809.png" alt="workspace 멤버의 usage limit 편집 대화 상자로, workspace 기본값, 현재 사용자별 limit, 적용 중인 group limit, $5로 설정된 User threshold 입력란이 표시됨" width="1202" height="916" data-path="images/billing/edit-usage-limit.png" />
    </Frame>
  </Step>

  <Step title="재정의 저장">
    새 limit을 입력하고 **Save**를 선택합니다. 재정의는 즉시 적용되며 새 값이 **Usage limit** 열에 표시됩니다. 나중에 재정의를 없애려면 필드를 비우고 저장하세요. 그러면 해당 멤버에게 적용되는 가장 구체적인 group 또는 workspace limit으로 되돌아갑니다.
  </Step>
</Steps>

<Note>사용자별 spend limits는 Enterprise plan에서 사용할 수 있습니다. [custom group](/ko/teams/identity-and-access-management/groups-and-permissions)에 배정된 멤버는 개별 재정의가 설정되어 있지 않으면 해당 group의 limit을 상속합니다. 사용자별 재정의는 항상 group 및 workspace 기본값보다 우선합니다.</Note>

<div id="organization-admin-controls">
  ### Organization 관리자 제어
</div>

Organization 관리자는 [organization billing 설정](https://replit.com/t/replit/settings/billing)에서 AI 모델 접근 권한과 integrations를 관리할 수 있습니다.

**외부 AI 모델 integrations 비활성화**

이 설정을 활성화하면 organization의 모든 사용자가 외부 AI 모델 integrations(Replit이 관리하는 connector를 통해 사용하는 OpenAI, Anthropic, xAI, Perplexity 등)를 사용할 수 없습니다.

이 설정을 활성화하면 organization의 모든 사용자가 Replit이 관리하는 AI integrations를 사용할 수 없습니다.
