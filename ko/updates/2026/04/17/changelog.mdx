### 새로운 Agent 모드 드롭다운

채팅 입력의 Agent 모드 선택기가 이제 더 간단한 세그먼트 컨트롤로 변경되었습니다. 툴바에서 바로 Lite, Economy, Power 중에서 선택하고, 필요할 때는 고급 설정에서 Turbo에 접근하세요.

새로운 기능:

* **툴바의 세그먼트 컨트롤.** Lite, Economy, Power가 나란히 배치되어 현재 모드와 전환 방법이 명확합니다.
* **키보드 단축키.** **⌘+Shift+I**(Windows에서는 Ctrl+Shift+I)를 눌러 마우스 없이 모드를 전환하세요.
* **주황색으로 강조된 Turbo.** Turbo는 가장 빠른 모드이지만 비용이 더 많이 들어, 비용 트레이드오프를 명확히 보여주기 위해 UI에서 눈에 띄게 표시됩니다.
* **기본적으로 접혀 있는 고급 설정.** 테스트, 코드 검토, Turbo 컨트롤이 **고급 설정** 뒤에 배치되어 메인 화면이 깔끔하게 유지됩니다.
* **Max 모드가 종료되었습니다.** 가장 강력한 빌드에는 Power를 사용하거나, 가장 빠른 응답을 원할 때는 고급 설정에서 Turbo를 켜세요.

### Agent가 후속 작업을 제안합니다

<Frame>
  <video autoPlay muted loop playsInline src="/assets/mirror/replit-suggested-tasks-b27620d93fd2.mp4" />
</Frame>

Agent는 이제 작업을 완료한 후 프로젝트의 전체 컨텍스트를 활용하여 다음에 빌드할 항목을 제안하는 **후속 작업**을 제안합니다. 완료된 각 작업 아래에 세 가지 유형의 제안이 표시됩니다:

* **빌드할 새로운 기능** — 방금 출시한 것과 자연스럽게 어울리는 기능
* **성능 개선** — 작업 중에 Agent가 발견한 최적화 사항
* **사용자 경험 향상** — 기능을 완성하는 마무리 작업

각 제안을 검토하고 원하는 것에 **수락**을 선택하면 Agent가 백그라운드에서 실행하는 동안 계속 빌드할 수 있습니다. 완료 열의 **제안된 작업 숨기기**로 필요 없는 제안을 숨기고 언제든지 다시 볼 수 있습니다.

[후속 작업 제안](/ko/features/agent/follow-up-tasks)에 대해 자세히 알아보세요.

## 워크스페이스

### 프로젝트 페이지 개선 사항

프로젝트 페이지에 세 가지 편의 기능이 추가되었습니다:

* **모든 카드에 아티팩트 미리보기.** 이제 각 프로젝트 카드에 내부의 각 아티팩트에 대한 작은 아이콘이 표시됩니다. 아이콘 위에 마우스를 올리면 프로젝트를 열지 않고도 해당 아티팩트의 스크린샷을 미리볼 수 있습니다.
* **마지막으로 연 순으로 기본 정렬.** 페이지가 이제 *사용자*가 가장 최근에 작업한 프로젝트를 상단에 표시하므로 바쁜 팀 워크스페이스에서도 현재 작업이 항상 최전방에 유지됩니다.
* **개인 고정.** 자주 돌아오는 프로젝트를 고정하세요. 고정은 사용자에게만 비공개이며 워크스페이스의 다른 구성원이 보는 내용에 영향을 주지 않습니다.

## 팀 및 Enterprise

### SCIM 조직을 위한 사용자 정의 그룹

SCIM 프로비저닝이 활성화된 조직은 이제 IdP 동기화 그룹과 함께 Replit에서 사용자 정의 그룹을 생성할 수 있습니다. Identity Provider에 미러링되지 않는 프로젝트 기반 액세스, 일회성 권한 부여, 또는 기타 구조에 사용자 정의 그룹을 사용하세요.

SCIM 동기화 그룹은 Identity Provider를 통해 관리되며, 사용자 정의 그룹은 조직 관리자가 Replit에서 직접 관리합니다.

[SCIM](/ko/teams/identity-and-access-management/scim#creating-custom-groups-alongside-scim)에 대해 자세히 알아보세요.
