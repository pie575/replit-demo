export const CoreCredits = '$20';

이 답변은 Replit 빌더들이 가장 자주 묻는 청구 관련 질문을 다룹니다. 사용량 기반 청구 방식에 대한 자세한 내용은 [사용량 기반 청구](/ko/billing/about-usage-based-billing) 및 [지출 관리](/ko/billing/managing-spend)를 참조하세요.

<AccordionGroup>
  <Accordion title="월별 청구 주기가 끝나기 전에 청구된 이유는 무엇인가요?">
    Replit은 주기 말에만 청구하는 것이 아니라, 포함된 월 크레딧을 초과하는 사용량이 설정된 금액(청구 임계값)에 도달하면 청구합니다. Core 플랜에는 월 {CoreCredits}의 크레딧이 포함되어 있으며, 해당 크레딧을 초과한 Agent 사용량은 임계값에 도달하면 별도로 청구됩니다.

    향후 청구액을 줄이려면:

    1. [Plan 모드](/ko/features/agent/plan-mode)를 사용하여 Agent가 빌드하기 전에 작업 범위를 정하고 승인하여 비용이 많이 드는 재작업을 방지하세요.
    2. Core 또는 Pro 구독이 있다면 일상적인 Agent 작업에 비용이 들지 않는 [Free Mode](/ko/features/agent/agent-modes)를 사용하세요. 할당량은 5시간마다 재설정되며 주간 한도가 있습니다. 사용량을 확인하려면 **설정 → 사용량**을 확인하세요.
    3. 더 많은 기능이 필요할 때는 합리적인 가격의 Power를 선택하세요.
    4. [지출 관리](/ko/billing/managing-spend)에서 사용량 한도와 예산을 설정하여 크레딧 초과 청구를 제한하세요.
    5. 새 작업마다 새 Agent 채팅을 시작하여 컨텍스트를 짧게 유지하세요.

    어떤 사용으로 청구되었는지 확인하려면 **설정 → 계정 사용량**을 열고 **이전 청구서 보기**를 선택하세요.
  </Accordion>

  <Accordion title="App Store 또는 Google Play를 통해 구독했는데 결제 수단을 추가할 수 없어요. 어떻게 해결하나요?">
    App Store 또는 Google Play를 통해 구독하면 Apple 또는 Google이 결제를 처리하므로 모바일 앱 내에 결제 옵션이 표시되지 않습니다. 웹에서 결제를 관리하세요:

    1. 브라우저를 열고 **설정 → 청구**로 이동합니다.
    2. **결제 수단 업데이트**를 선택합니다.
    3. 카드 정보를 입력하고 저장합니다.

    웹 결제 수단을 추가하면 **청구** 탭에서 청구를 관리하고 크레딧 팩을 구매할 수 있습니다. 크레딧 팩에 대한 자세한 내용은 [지출 관리](/ko/billing/managing-spend)를 참조하세요.
  </Accordion>

  <Accordion title="구독 후 30일 이내인데 환불 자격이 있나요?">
    환불 자격은 플랜과 환불 요청 항목에 따라 다릅니다. 다음 사항을 참고하세요:

    * Agent 및 AI 사용 요금은 이미 사용된 컴퓨팅에 대한 청구이므로 환불되지 않습니다.
    * [커스텀 도메인 등록 수수료는 환불되지 않습니다](/ko/build/domain-purchasing).

    구독료 환불을 원하시면 등록된 이메일로 [Replit 지원팀에 문의](https://replit.com/support)하고 요청 사유를 포함하세요. **설정 → 청구**에서 먼저 구독을 취소하세요.

    <Note>정확한 구독 환불 기간 및 자격은 특정 계정과 플랜에 대해 지원팀이 확인합니다.</Note>
  </Accordion>

  <Accordion title="예상치 못한 Agent 또는 AI 사용 요금이 청구되었는데 환불받을 수 있나요?">
    Agent 및 AI 사용 요금은 Replit이 이미 작업을 실행하는 데 사용한 컴퓨팅에 대한 청구이므로 환불되지 않습니다. 향후 예상치 못한 청구를 방지하세요:

    1. **설정 → 계정 사용량**을 열고 사용량 한도와 예산을 설정하세요. [지출 관리](/ko/billing/managing-spend)를 참조하세요.
    2. Free Mode는 Core 및 Pro 구독에 포함되어 있습니다. 할당량 내에서 비용 없이 일상적인 Agent 작업을 하려면 [Free Mode](/ko/features/agent/agent-modes)를 사용하고, 더 많은 기능이 필요하면 합리적인 가격의 Power를 선택하세요.
    3. [Plan 모드](/ko/features/agent/plan-mode)를 사용하여 Agent가 빌드하기 전에 작업 범위를 정하고 재작업을 줄이세요.

    오류로 청구되었다고 판단되면 청구 금액, 날짜, 결제 의도 ID를 수집하세요. ID는 `pi_`로 시작하며 청구서 세부 정보 페이지에 표시됩니다. 그런 다음 [Replit 지원팀에 문의](https://replit.com/support)하세요.
  </Accordion>

  <Accordion title="구독을 취소한 후 청구되었는데 맞는 건가요?">
    취소 후 청구는 일반적으로 다음 두 가지 이유 중 하나입니다:

    * 취소 전 사용량이 취소일 이후 청구 임계값에 도달한 경우.
    * 이전 청구 기간에 대한 이전 실패 결제의 재시도.

    확인하려면 **설정 → 계정 사용량**을 열고 **이전 청구서 보기**를 선택하여 청구서 날짜와 해당 사용 기간을 확인하세요. 여전히 이상해 보이면 `pi_` 결제 의도 ID를 포함하여 [Replit 지원팀에 문의](https://replit.com/support)하세요.
  </Accordion>

  <Accordion title="구독 중인데 스토리지 요금이 추가로 청구되는 이유는 무엇인가요?">
    스토리지 요금은 저장된 데이터가 플랜에 포함된 한도를 초과할 때 발생합니다. 스토리지 측정 방식은 [사용량 기반 청구](/ko/billing/about-usage-based-billing)를, 오브젝트 스토리지 비용은 [오브젝트 스토리지 청구](/ko/billing/object-storage-billing)를 참조하세요.

    공간을 어디서 사용하고 있는지 확인하려면 프로젝트의 Shell을 열고 다음을 실행하세요:

    ```bash theme={null}
    du -sh *
    du -ah | sort -rh | head -20
    ```

    그런 다음 빌드 아티팩트(`.cache` 또는 `dist`), 오래된 로그, 사용하지 않는 업로드를 제거하고 데이터베이스에서 오래된 데이터를 지우세요. 공간을 확보하면 향후 스토리지 요금이 더 이상 쌓이지 않습니다.
  </Accordion>

  <Accordion title="커스텀 도메인 등록 환불은 어떻게 받나요?">
    [커스텀 도메인 등록 수수료는 환불되지 않습니다](/ko/build/domain-purchasing). 도메인 등록은 처리 후 취소할 수 없는 타사 비용을 수반하기 때문입니다.

    실수로 도메인을 등록했거나 이전을 원하시면 도메인 이름과 계정에 연결된 이메일과 함께 [Replit 지원팀에 문의](https://replit.com/support)하세요. 팀이 옵션을 안내해 드립니다.
  </Accordion>

  <Accordion title="청구서를 결제했는데 계정이 여전히 정지되어 있어요. 언제 해제되나요?">
    청구 보류는 결제가 확인된 후 해제되는 데 잠시 시간이 걸릴 수 있습니다. 다음 단계를 시도하세요:

    1. Mac은 `Cmd+Shift+R`, Windows는 `Ctrl+Shift+R`로 브라우저를 강제 새로고침하세요.
    2. 로그아웃 후 다시 로그인하여 계정 상태를 새로 고치세요.
    3. **설정 → 계정 사용량**을 열고 **이전 청구서 보기**를 선택하여 청구서가 결제됨으로 표시되는지 확인하세요.

    보류가 해제되어도 배포는 자동으로 다시 시작되지 않습니다. 앱이 여전히 오프라인이면 **게시**를 열고 **게시**를 선택하여 다시 라이브로 push하세요. 계정이 계속 정지 상태라면 [Replit 지원팀에 문의](https://replit.com/support)하세요.
  </Accordion>

  <Accordion title="Replit에서 알 수 없는 청구가 발생했어요. 어떻게 해야 하나요?">
    은행에 이의를 제기하기 전에 먼저 청구 내역을 확인하세요:

    1. **설정 → 계정 사용량**을 열고 **이전 청구서 보기**를 선택하여 날짜, 금액, 설명을 검토하세요.
    2. 계정이나 결제 수단에 다른 사람이 접근할 수 있는지 확인하세요.
    3. 청구일 전후로 Replit 청구 이메일을 스팸 폴더까지 확인하세요.

    청구는 보통 구독료, 청구 임계값에 도달한 사용 요금, 또는 크레딧 팩 구매입니다.

    <Warning>은행에 이의를 제기하기 *전에* Replit 지원팀에 문의하세요. 차지백은 계정을 잠글 수 있습니다.</Warning>

    `pi_` 결제 의도 ID, 청구 금액, 날짜와 함께 [Replit 지원팀에 문의](https://replit.com/support)하세요.
  </Accordion>

  <Accordion title="결제가 거절되었어요. Replit 문제인가요?">
    대부분의 거절은 Replit이 아닌 은행 또는 카드 발급사에서 발생합니다. 보통 낯선 거래에 대한 자동 보안 차단입니다. 다음 순서로 시도해보세요:

    1. **설정 → 청구 → 결제 수단 업데이트**에서 다른 카드를 추가하고 다시 시도하세요.
    2. 은행에 전화하여 Replit에 결제를 승인하고 있다고 알리고 승인을 요청하세요.
    3. 카드에 해외 결제 제한이 있다면 은행에 허용을 요청하세요.

    거절이 계속되면 [Replit 지원팀에 문의](https://replit.com/support)하세요.
  </Accordion>

  <Accordion title="같은 금액이 두 번 청구되었어요. 중복 청구인가요?">
    동일한 금액의 두 청구가 항상 중복은 아닙니다. 일반적인 설명:

    * 같은 금액의 구독료와 크레딧 팩이 별도 항목으로 표시된 경우.
    * 이전에 실패한 결제가 재시도되어 성공한 경우.
    * 실제 중복 청구 (드문 경우).

    **설정 → 계정 사용량**을 열고 **이전 청구서 보기**를 선택하여 두 청구의 결제 의도 ID(`pi_`)를 비교하세요. ID가 다르면 별개의 거래입니다. 두 청구 모두 동일한 청구서의 동일한 항목에 대해 결제됨으로 표시된다면 [Replit 지원팀에 문의](https://replit.com/support)하세요.
  </Accordion>

  <Accordion title="App Store를 통해 결제했는데 크레딧이 아직 나타나지 않아요. 어떻게 해야 하나요?">
    App Store 결제는 Replit과 동기화되는 데 잠시 시간이 걸릴 수 있습니다. 먼저 다음을 시도하세요:

    1. Replit 앱을 강제 종료하고 다시 열어보세요.
    2. Replit 계정에서 로그아웃 후 다시 로그인하세요.
    3. **설정 → 계정 사용량**을 열고 크레딧이 이미 나타났는지 확인하세요.

    두 번 구매하지 마세요. 크레딧이 여전히 나타나지 않으면 App Store **구매 내역**에서 Replit 거래를 찾아 거래 ID를 메모하세요. 그런 다음 [Replit 지원팀에 문의](https://replit.com/support)하면 팀이 크레딧을 적용해 드립니다.
  </Accordion>
</AccordionGroup>

## 도움이 더 필요하신가요?

여기서 청구 질문의 답변을 찾을 수 없다면 [Replit 지원팀에 문의](https://replit.com/support)하세요.
