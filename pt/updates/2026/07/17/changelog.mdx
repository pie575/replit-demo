## Integrações

### Agent sugere conectores quando vários se encaixam

Quando você pede ao Agent para conectar um serviço e mais de um provedor funciona, o Agent agora mostra uma lista curta para você escolher o que quiser. Antes, o Agent precisava fazer uma pergunta de acompanhamento primeiro. Escolha um provedor, faça login uma vez, e o Agent continua construindo.

## Workspace

### Conheça o novo painel Tools

Tudo que o seu app pode usar agora tem um único lugar no seu workspace. O novo painel Tools fixado reúne Database, Auth, Domains, Secrets e mais em um só lugar. Isso torna o conjunto completo de ferramentas fácil de encontrar rapidamente. As ferramentas em si não mudaram. Elas só têm um lugar mais claro.

  <img src="/assets/mirror/tools-pane-ceaddcc1d7a2.png" alt="Painel Tools do workspace listando Publishing, Domains, Monitoring, Growth, Database, Users and Auth, Security Center e App Storage em Replit Cloud" width="390" height="716" data-path="images/changelog/2026-07-17/tools-pane.png" />
</Frame>

Saiba mais sobre o [painel Tools](/pt/features/editor/editor-and-tools).

### Uma barra lateral de tarefas mais rápida

A barra lateral de tarefas agora é um navegador de tarefas mais denso e fácil de escanear. Cada tarefa tem seu próprio cartão de hover para ações rápidas e detalhes, o Task Board tem um ponto de entrada mais claro, e as tarefas permanecem no lugar em vez de se deslocarem quando você expande ou recolhe a barra lateral.
