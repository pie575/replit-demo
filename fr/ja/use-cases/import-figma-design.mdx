Supposons que vous ayez déjà un écran dans Figma. Agent le transforme en une
application Replit fonctionnelle que vous pouvez modifier, prévisualiser et publier. La mise en page, la typographie, les couleurs et les espacements sont reproduits.
Le résultat n’est pas une capture d’écran, mais un véritable produit fonctionnel. Si le fichier contient plusieurs
flux, indiquez à Agent le cadre précis à cibler.

<div id="section">
  ## Idéal pour
</div>

* Les designers produit qui ont besoin d’une application Replit codée à partir d’une frame existante.
* Les fondateurs disposant de fichiers Figma qui souhaitent les mettre en ligne sans repartir de zéro.

<div id="section-3">
  ## Avant de commencer
</div>

Préparez un fichier Figma contenant des frames nommées (accueil, produit, tunnel de paiement, etc.).
Connectez Figma. Partagez le fichier avec Agent ou collez le lien du fichier et
celui des frames concernées. Indiquez s’il s’agit d’un site marketing, d’une application
ou d’une page de destination unique.

<div id="section-4">
  ## Instructions pour l’Agent
</div>

<AiPrompt>
  À partir de ce fichier Figma[lien], crée une application Replit fonctionnelle basée sur
  ces frames :[nom ou lien de la frame]. Reproduis la mise en page, la typographie, les couleurs, les espacements
  et les points de rupture (ordinateur et mobile).
</AiPrompt>

<div id="section-5">
  ## À quoi vous attendre
</div>

Agent lit la frame sélectionnée et crée une page correspondante que vous pouvez publier depuis Replit.
Comparez l’espacement, la typographie et les couleurs avec celles de Figma. Vérifiez vous-même les éléments
interactifs, tels que la navigation, les formulaires et les effets de survol. Des ajustements supplémentaires sont souvent
nécessaires. Prévisualisez la page sur ordinateur et sur smartphone. Cliquez sur les éléments de navigation et les
formulaires, puis comparez les captures d’écran avec Figma avant de publier.

<div id="section-6">
  ## Personnalisez selon vos besoins
</div>

<AiPrompt>
  Commencez par implémenter uniquement la frame mobile. Reproduisez la mise en page automatique et l’espacement de Figma.
  Passez à la version desktop après que j’aurai approuvé la version mobile.
</AiPrompt>

<AiPrompt>
  Réutilisez un même composant pour les boutons, les champs de saisie et les cartes. S’il existe des variables Figma,
  utilisez-les pour les couleurs et la typographie.
</AiPrompt>

<div id="section-7">
  ## Dépannage
</div>

* **Agent ne parvient pas à lire le fichier :** connectez Figma, partagez le fichier, puis collez le lien vers la frame, et pas seulement l’URL du fichier. Si le fichier contient plusieurs flux, nommez les frames (accueil, produit, tunnel de paiement, etc.) et précisez-les.
* **Les effets de survol, la navigation ou les formulaires semblent incomplets :** la mise en page et les couleurs sont souvent finalisées en premier. Demandez des ajustements supplémentaires pour les éléments interactifs, puis vérifiez ponctuellement les espacements par rapport à Figma.
