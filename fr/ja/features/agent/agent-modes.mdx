---
title: "Modes Agent"
description: "Découvrez comment choisir entre Free Mode, Power Mode et Max Mode pour vos builds avec Agent."
---

Les modes Agent vous permettent de trouver le bon équilibre entre coût et performances lorsque vous utilisez Agent. Dans le menu déroulant des paramètres d’Agent, sélectionnez **Free Mode**, **Power Mode** ou **Max Mode**. Free Mode utilise toujours Auto. Les créateurs Core et Pro peuvent utiliser le [sélecteur de modèles](/fr/ja/features/agent/model-selector) avec Power Mode ou Max Mode. Les modes et paramètres disponibles varient selon votre forfait et votre espace de travail.

<Note>
  Economy Mode a été supprimé. Power Mode le remplace au même prix.
</Note>

<Tip>
  **Raccourci clavier :** appuyez sur **⌘+Shift+I** (Ctrl+Shift+I sous Windows) pour changer de mode Agent sans quitter le champ de saisie du chat.
</Tip>

<div id="free-mode">
  ## Free Mode
</div>

**Optimisé pour vous aider à démarrer.** Free Mode vous aide à explorer vos idées, à apprendre à utiliser Replit et à lancer vos projets.

**Remarque :** Free Mode utilise toujours Auto, le système de routage intelligent des modèles de Replit. Pour sélectionner un modèle manuellement, utilisez Power Mode ou Max Mode.

<Note>
  Free Mode est disponible avec les forfaits Starter, Core et Pro. Les limites de Free Mode varient selon le forfait, et Core et Pro incluent une allocation qui se renouvelle toutes les 5 heures. Lorsque vous atteignez la limite de votre forfait, Replit indique quand elle sera renouvelée.
</Note>

Les Routines ne s’exécutent pas en Free Mode. Elles s’exécutent en Power ou Max Mode et nécessitent un budget par exécution. Pour en savoir plus, consultez [Routines](/fr/chat/routines).

<div id="power-mode">
  ## Power Mode
</div>

**Optimisé pour réduire les coûts.** Power Mode consomme moins de crédits par tâche et constitue le meilleur choix par défaut si vous souhaitez obtenir d&#39;excellents résultats sans payer pour les modèles les plus performants.

**Idéal pour :** la création au quotidien, l&#39;apprentissage et les tâches soucieuses des coûts sur des projets existants.

<div id="max-mode">
  ## Max Mode
</div>

**Optimisé pour les tâches exigeantes.** Max Mode utilise des modèles plus performants pour les tâches complexes, les grandes bases de code et les problèmes les plus difficiles.

**Idéal pour :** les projets prêts pour la production, les fonctionnalités complexes et obtenir les meilleurs résultats avec Agent.

<div id="section">
  ## Quel mode choisir ?
</div>

Consultez le guide suivant :

| Objectif                                                                       | Mode recommandé                                                                |
| ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------ |
| Explorer des idées, apprendre à utiliser Replit et démarrer un projet          | Free Mode                                                                      |
| Maximiser le nombre de prompts par crédit                                      | Power Mode                                                                     |
| Trouver le bon équilibre entre coût et qualité pour la plupart des projets     | Power Mode                                                                     |
| Sélectionner manuellement un modèle                                            | Power Mode ou Max Mode                                                         |
| Obtenir les meilleurs résultats pour des tâches complexes de niveau production | Max Mode                                                                       |
| Obtenir les meilleurs résultats possibles pour les tâches les plus complexes   | Max Mode avec un [Effort](/fr/ja/features/agent/model-selector#effort) plus élevé |

Sélectionnez un mode dans le menu déroulant des paramètres d’Agent, dans la zone de saisie du chat. Les créateurs Core et Pro peuvent définir le [modèle principal et l’Effort](/fr/ja/features/agent/model-selector) avec Power Mode ou Max Mode. Il n’existe pas de mode systématiquement meilleur. Choisissez celui qui convient à la tâche à accomplir.

<div id="section-2">
  ## Paramètres des projets partagés
</div>

Les paramètres d’Agent sont associés à votre compte, et non au projet. Lorsque vous invitez des membres de l’équipe à un projet, chacun conserve ses propres choix pour les éléments suivants :

* Mode (Free Mode, Power Mode ou Max Mode)
* [Modèle principal et Effort](/fr/ja/features/agent/model-selector) (si disponibles)
* [Plan Mode](/fr/ja/features/agent/plan-mode)
* Fusion automatique des tâches en arrière-plan
* Approbation automatique des plans

Même si un membre de l’équipe passe à Max Mode pour sa prochaine tâche, vos paramètres ne basculeront pas vers Max Mode. Les modes et paramètres affichés dans le menu déroulant des paramètres d’Agent sont ceux qu’Agent utilisera lorsque vous enverrez votre prochain message, quel que soit le nombre de collaborateurs du projet.

<div id="free-mode-2">
  ## Vérifier votre allocation Free Mode
</div>

Ouvrez **Settings** → **Usage** pour consulter l’allocation Free Mode restante et savoir quand elle sera réinitialisée. Pour obtenir des conseils pratiques afin d’en tirer le meilleur parti, consultez [Tirer le meilleur parti de Free Mode](/fr/chat/free-mode).
