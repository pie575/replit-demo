你可以为已发布的应用启用反馈收集功能，直接听取访客的意见并将其发送给 Agent。启用后，访客可以提交反馈，并附上截图和文件，你可以在收件箱中统一管理这些反馈。

<div id="enabling-feedback">
  ## 启用反馈
</div>

<Warning>
  反馈功能仅支持 web 应用，无法为自动化、移动应用等其他类型的应用启用。
</Warning>

发布新应用时，在发布对话框中开启 **Enable Feedback** 设置。如果应用已经发布，可以通过重新发布来启用反馈：

1. 打开 Publishing 工具
2. 选择 **Advanced Settings**
3. 开启 **Enable Feedback**
4. 重新发布应用

<div id="submitting-feedback">
  ## 提交反馈
</div>

在已发布的应用上启用反馈后，访问者可以直接在应用中提交反馈。用户可以：

* 登录后提交反馈
* 填写文字反馈，描述使用体验或提出建议
* 选择页面元素，直观地指出问题或功能
* 上传文件以提供更多上下文

<div id="managing-feedback-in-your-inbox">
  ## 在收件箱中管理反馈
</div>

访问者提交的所有反馈都会显示在收件箱中，你可以在 Project Editor 内打开收件箱。在收件箱中，你可以：

* **添加到 Chat**：将反馈发送到与 Agent 的对话中，在提交前补充上下文
* **发送给 Agent**：立即将反馈发送给 Agent，马上开始处理
* **解决**：反馈处理完成后将其标记为已解决
* **删除**：移除不再需要的反馈

你还可以使用筛选器来整理和查找特定的反馈条目。

<div id="republishing-with-updated-feedback-settings">
  ## 使用更新后的反馈设置重新发布
</div>

应用发布后，你可以随时更新设置并重新发布，以启用或禁用反馈小组件：

1. 在 Publishing 工具中打开 **Overview** 选项卡
2. 选择 **Advanced Settings**
3. 开启或关闭 **Enable Feedback**
4. 重新发布应用以应用更改

反馈设置的任何更改都会在应用重新发布后生效。
