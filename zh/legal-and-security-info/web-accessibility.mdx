Replit 相信，计算技术应惠及每个人。因此，Replit 致力于让所有人，包括残障人士，都能完全无障碍地使用本服务。本声明介绍无障碍目标、实现这些目标的进展情况，以及如何就 Replit 的无障碍功能提供反馈。

<div id="conformance-goals">
  # 合规目标
</div>

我们的目标是完全符合 W3C WAI 的《Web 内容无障碍指南》(WCAG) 2.1，该指南为设计师和开发者规定了改善残障人士访问体验的各项要求。Replit 目前部分符合 WCAG 2.1 AA 级标准。部分符合是指网站的部分内容尚未完全达到该无障碍标准。

<div id="current-status">
  # 当前状态
</div>

Replit 正在推进一项内部项目，以提升网站的无障碍。该项目基于内部评估、构建者访谈与报告，以及 Cornell University IT Department 于 2021 年进行的独立评估结果。

网站上大部分内容均以符合现行 W3C HTML 和 CSS 标准的 HTML 格式提供。向您呈现的非文本内容 (如图片和表单元素) 均提供可由屏幕阅读器识别和朗读的文本替代内容。

尽管 Replit 持续致力于提升无障碍，您仍可能遇到一些限制。尤其是，无法仅通过键盘完全操作 Workspace 是 Replit 已知且正在解决的问题。

<div id="giving-feedback">
  # 提供反馈
</div>

如果您在访问 Replit 网站时遇到任何问题，请发送电子邮件至 [contact@replit.com](mailto:contact@replit.com) 提供反馈。请附上您尝试访问内容的 URL (网址) 、遇到的问题以及您的联系信息。
