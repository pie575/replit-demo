最后，Velocity 的客户将支付可退还的押金以预留车辆，并在取车时支付尾款。

你已为 Velocity 添加了登录功能和数据库。现在，把它打造成真正的预订业务：通过**预订时收取可退还的押金**为每辆车保留订单，并在**取车时收取尾款**。Replit 通过 Stripe 管理付款——你无需自行编写任何 Stripe 代码。

<div id="decida-os-valores-de-depsito-e-saldo">
  ## 确定押金和尾款金额
</div>

让 Agent 开始构建前，先明确以下规则：

* **预订时支付押金：**收取固定金额，还是总额的百分比？固定收取 $500 更容易说明；收取 20% 则会随车价变化。
* **取车时支付尾款：**剩余租车费用在客户领取钥匙时收取。
* **退款期限：**最晚可在何时取消，才能退回押金？48 小时是常见标准。

在本指南中，Velocity 会在预订时收取固定且可退还的 $500 押金，在取车时收取尾款；如果客户提前超过 48 小时取消，则全额退还押金。请根据实际业务情况进行调整。

<div id="teste-o-fluxo-completo-em-modo-de-teste">
  ## 在测试模式下测试完整流程
</div>

Stripe 提供了一张专用测试卡，让您可以模拟真实付款，而无需支付真实款项：`4242 4242 4242 4242`、任意未来有效期和任意 3 位 CVC。

1. 在 Preview 中打开 Velocity，并预订下周末的车辆。
2. 在结账流程中，您应看到“今日押金：$500”和“取车时支付尾款：$1,900” (或您的逻辑计算出的金额) 。
3. 使用测试卡 `4242` 支付押金。您应会返回确认页面，其中显示押金已支付，以及已保存用于支付尾款的付款方式。
4. 在“我的预订”中打开该预订，并通过管理操作或取车操作收取尾款。确认尾款显示为已支付。
5. 创建第二个预订，并在超过 48 小时前取消。押金应退回测试卡 (您可以在 Stripe 测试模式控制面板中查看) 。
6. 创建第三个预订，并在 48 小时内取消。押金应被扣留，并向客户明确说明原因。
7. 使用 Stripe 的拒付测试卡 (`4000 0000 0000 0002`) 尝试完成结账流程。预订不应被确认，客户应看到清晰的失败提示。

如果押金支付成功但预订未被确认，请告诉 Agent：

<AiPrompt>
  Velocity 的 Stripe 测试押金支付成功，但预订未显示为已确认。<br />
  将押金支付成功事件关联到数据库中的预订状态。<br />
  向我展示如何通过另一个测试预订进行验证。
</AiPrompt>

<div id="mude-para-pagamentos-reais-quando-estiver-pronto">
  ## 准备就绪后切换为真实支付
</div>

测试模式供你测试使用。实时模式面向使用真实货币付款的真实客户。Velocity 准备就绪后：

1. 在 Stripe 中，将测试模式切换为实时模式，并复制**实时**密钥。
2. 在 App 设置中，将测试密钥替换为实时密钥。
3. 通过 Agent 的 Chat 重新发布 Velocity。
4. 打开公开 URL，使用你的真实银行卡预订一辆低价测试车辆，并确认押金和尾款功能端到端正常运行。

在广泛分享公开 URL 前，请先用真实银行卡完成一次测试。Velocity 现在已可接受使用真实货币支付的真实预订。

<div id="precisa-de-mais-ajuda">
  ## 需要更多帮助？
</div>

* **押金支付成功，但预订未确认：**请让 Agent 将 Stripe 的支付成功事件与数据库中的预订状态关联起来。
* **测试模式可以使用，但实时模式不行：**请确保已在 App 设置中将测试密钥替换为实时密钥。
* **想一次性预付全款，而不是支付押金 + 尾款：**请让 Agent 将 Velocity 改为在预订时一次性付清全款。
* **想使用定期订阅定价 (每月使用车队) ：**Replit 也支持 RevenueCat——请让 Agent 使用它来替代 Stripe。
