# Raccourcis clavier

> Apprenez à afficher, ajouter et modifier des raccourcis clavier pour améliorer votre productivité dans Replit.

Les raccourcis clavier vous permettent d'exécuter des commandes, de modifier du texte et de naviguer dans l'Éditeur de projet
à l'aide de combinaisons de touches configurables. Vous pouvez définir et utiliser des raccourcis clavier dans
l'application web Replit.com.

## Afficher les raccourcis clavier

Pour afficher vos paramètres de raccourcis clavier, suivez ces étapes :

1. Ouvrez une application Replit pour accéder à l'Éditeur de projet.
2. Ouvrez l'onglet <img class="icon-svg" src="https://mintcdn.com/replit/rJldsgYVucXB_6kW/images/icons/settings-icon.svg?fit=max&auto=format&n=rJldsgYVucXB_6kW&q=85&s=27601119959a9349e102c44c2adbd398" alt="icône d'engrenage" width="16" height="16" data-path="images/icons/settings-icon.svg" /> **Paramètres utilisateur** depuis <img class="icon-svg" src="https://mintcdn.com/replit/X_IP1EeHGm0cA2VA/images/icons/workspace-all-tools-button.svg?fit=max&auto=format&n=X_IP1EeHGm0cA2VA&q=85&s=579643854fb13c402de516695e52c554" alt="icône de tous les outils" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **Tous les outils** dans le dock.
   Vous pouvez également rechercher « Paramètres utilisateur » à l'aide de la <img class="icon-svg" src="https://mintcdn.com/replit/X_IP1EeHGm0cA2VA/images/icons/workspace-search-icon.svg?fit=max&auto=format&n=X_IP1EeHGm0cA2VA&q=85&s=d3feed840da2d19e1ee4873d137114dc" alt="icône de loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> loupe.
3. Sélectionnez l'onglet **Raccourcis clavier** pour afficher la liste des commandes et leurs raccourcis assignés.

## Personnaliser les raccourcis clavier

Pour ajouter ou modifier un raccourci clavier, suivez ces étapes :

1. Sélectionnez <img class="icon-svg" src="https://mintcdn.com/replit/rJldsgYVucXB_6kW/images/icons/create-app-icon.svg?fit=max&auto=format&n=rJldsgYVucXB_6kW&q=85&s=cc16ebed380bbd324dafaa2c93a91a66" alt="icône plus" width="16" height="16" data-path="images/icons/create-app-icon.svg" />**Ajouter un raccourci**, situé à côté
   de la commande non assignée, ou l'icône <img class="icon-svg" src="https://mintcdn.com/replit/rJldsgYVucXB_6kW/images/icons/pencil-icon.svg?fit=max&auto=format&n=rJldsgYVucXB_6kW&q=85&s=09de925e41efd3d1cfa199737639b5a6" alt="icône de crayon" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> crayon pour les commandes assignées.
2. Lorsque « Enregistrement... » apparaît à côté de la commande, appuyez sur la combinaison de touches que vous souhaitez assigner.
   Pour annuler l'enregistrement, cliquez sur une zone vide à l'intérieur de l'onglet.
3. Pour rétablir le raccourci, sélectionnez l'icône <img class="icon-svg" src="https://mintcdn.com/replit/rJldsgYVucXB_6kW/images/icons/rollback-icon.svg?fit=max&auto=format&n=rJldsgYVucXB_6kW&q=85&s=b15faa243c8a17b5993c653314a74c5f" alt="icône de retour arrière" width="12" height="12" data-path="images/icons/rollback-icon.svg" /> de retour arrière.

## Supprimer des raccourcis clavier

Pour supprimer un raccourci clavier, sélectionnez l'icône <img class="icon-svg" src="https://mintcdn.com/replit/X_IP1EeHGm0cA2VA/images/icons/trash-icon.svg?fit=max&auto=format&n=X_IP1EeHGm0cA2VA&q=85&s=031a29f126332bebd5b6a74de4f16e40" alt="icône de corbeille" width="16" height="16" data-path="images/icons/trash-icon.svg" /> corbeille à côté de la commande.

## Navigation par tabulation

Vous pouvez utiliser la touche **Tab** du navigateur pour naviguer entre les éléments interactifs
d'une page. Cependant, les outils Éditeur de fichiers, Console et Shell capturent la touche **Tab** comme
entrée pour des usages tels que l'indentation.

Pour continuer à parcourir les éléments de la page lorsque vous utilisez ces outils, suivez ces étapes :

1. Appuyez sur **Échap** pour libérer le focus des outils
2. Appuyez sur **Tab** pour passer à l'élément suivant
