Transmettez à Agent les informations produit provenant de sources dont vous disposez déjà, par exemple Google Sheets
(nom du produit, prix, description, code produit, stock) et des photos sur Google Drive. Agent
configure votre boutique Shopify, importe les produits, les prix, les descriptions et les images, puis connecte le paiement et le checkout.
La vitrine et le front-end sont créés sur Replit, et non à partir d’un thème Shopify. Les paiements s’effectuent via le checkout Shopify, donc aucun connecteur Stripe distinct n’est
nécessaire.

<div id="section">
  ## Idéal pour
</div>

* Les fondateurs qui souhaitent créer une boutique à partir d’un catalogue qu’ils gèrent déjà dans Sheets et Drive.
* Les designers produit qui utilisent Shopify comme back-end e-commerce et ont besoin d’une vitrine Replit personnalisée.

<div id="section-3">
  ## Avant de commencer
</div>

Préparez une feuille de calcul contenant une ligne par produit (nom du produit, prix, description, code produit, stock), ainsi qu&#39;un dossier Drive regroupant des photos nommées de manière à ce qu&#39;Agent puisse les associer aux lignes. Connectez Sheets, Drive et Shopify. Si vous n&#39;avez pas encore de boutique, Agent peut provisionner Shopify directement depuis le chat. Passez une commande de test avant de publier votre boutique.

<div id="section-4">
  ## Instructions pour l’Agent
</div>

<AiPrompt>
  À partir de cette source de produits[Google Sheets et dossier Google Drive], crée une boutique
  Shopify complète. Importe tous les produits, y compris leurs noms, prix, descriptions et photos.
  Conçois et développe le front-end de la vitrine (accueil, collections, produits, panier) dans
  cette application Replit. Utilise Shopify pour le catalogue, le panier, le checkout et les
  paiements. N’utilise pas de thème Shopify pour les pages destinées aux clients.
</AiPrompt>

<div id="section-5">
  ## À quoi s&#39;attendre
</div>

Agent importe votre catalogue et crée une vitrine Replit qui charge les produits
depuis Shopify et redirige les clients vers le checkout Shopify. Comparez quelques produits
avec votre feuille de calcul (prix, description, image), puis passez une commande
de test. Utilisez le paiement test de Shopify, vérifiez que le total du panier correspond
à la feuille de calcul et assurez-vous que le checkout s&#39;effectue bien sur Shopify.

<div id="section-6">
  ## Personnalisez selon vos besoins
</div>

  Ignore les lignes sans photo.

<AiPrompt>

<div id="section-7">
  ## Dépannage
</div>

* **Les photos ne correspondent pas aux produits :** nommez les fichiers de votre Drive avec le code produit (`CODE.jpg`) et demandez à Agent d&#39;ignorer les lignes sans photo.
* **Les prix ou les descriptions ne correspondent pas à la feuille :** vérifiez qu&#39;il y a bien une ligne par produit (nom du produit, prix, description, code produit, stock), puis vérifiez quelques produits au hasard après l&#39;importation.
* **Le checkout ne passe pas par Shopify, ou la vitrine utilise un thème :** les pages destinées aux clients doivent être hébergées sur Replit. Les paiements sont traités via le checkout Shopify. Passez une commande de test avant de publier votre boutique.
