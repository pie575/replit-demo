⏰ *预计用时：15 分钟*

Figma 设计呈现的是产品体验应有的样子。Replit Design 能把 Figma frame 转换成 design frame，供你探索、优化，并进一步构建成可交互的应用。

本教程以 Figma 社区中的 [Personal Fitness Trainer Template](https://www.figma.com/community/file/1569006333493544411) 为例。

<div id="before-you-start">
  ## 开始之前
</div>

你需要：

* 一个 [Replit 账户](https://replit.com)。
* 一个 [Figma](https://www.figma.com) 账户，并准备好要导入的文件或上文的示例文件。

<div id="import-the-figma-frame">
  ## 导入 Figma frame
</div>

将 frame 导入 Replit Design，让 Agent 把它变成可运行的设计。

<Steps>
  <Step title="获取 Figma frame 链接">
    可以使用你自己的 Figma 文件，也可以跟随本指南的示例：Figma Community 上的 [Personal Fitness Trainer Template](https://www.figma.com/community/file/1569006333493544411)。

    在 Figma 中右键点击要导入的 frame，选择 **Copy/Paste as**，然后选择 **Copy link to selection**。

    <Frame caption="在 Figma 中打开的 Personal Fitness Trainer Template，其中包含即将导入的 Cover frame。">
      <img src="/assets/mirror/figma-example-file-65988c40d28d.webp" alt="在 Figma 中打开的 Personal Fitness Trainer Template，图层面板和画布上显示 Cover frame" width="3440" height="2160" data-path="images/fitstart/turn-mockup-into-app/figma-example-file.webp" />
    </Frame>
  </Step>

  <Step title="打开 Replit Design">
    前往 [replit.com/design](https://replit.com/design)，在提示框下方选择 **Import Figma**。

    <Frame caption="Replit Design 首页上的 Import Figma：导入 Figma frame，Agent 会把它变成可运行的设计。">
      <img src="/assets/mirror/design-import-figma-0a98172e147e.webp" alt="Replit Design 首页，提示框下方选中了 Import Figma 选项，并显示提示文字：导入 Figma frame，Agent 会把它变成可运行的设计" width="2293" height="1322" data-path="images/fitstart/turn-mockup-into-app/design-import-figma.webp" />
    </Frame>
  </Step>

  <Step title="粘贴 URL 并开始构建">
    将 frame 的 URL 粘贴到 **Import Figma design** 对话框中，然后选择 **Attach to prompt**。该 frame 会附加到 prompt 上，提交后即可开始构建。

    <Frame caption="已粘贴 frame URL 的 Import Figma design 对话框，可以附加到 prompt 了。">
      <img src="/assets/mirror/design-figma-url-8425e5d8d46d.webp" alt="Replit Design 上的 Import Figma design 对话框，输入框中已粘贴 Figma frame URL，并显示 Attach to prompt 按钮" width="2293" height="1440" data-path="images/fitstart/turn-mockup-into-app/design-figma-url.webp" />
    </Frame>
  </Step>
</Steps>

Agent 会导入该 frame，并在你的 project 中将其重建为一个 design frame。

<Frame caption="导入后的 Personal Fitness Trainer 落地页，在 Replit Design 中呈现为一个 frame。">
  <img src="/assets/mirror/figma-import-result-052394025b8d.webp" alt="Personal Fitness Trainer 落地页在 Replit Design 中作为 design frame 导入，聊天面板中显示该次运行已完成" width="3440" height="2160" data-path="images/fitstart/turn-mockup-into-app/figma-import-result.webp" />
</Frame>

<div id="make-it-yours">
  ## 打造专属设计
</div>

选中导入的 frame，开始改造：

* **采纳[建议](/zh/design/explore-suggestions)**：导入完成后会附带一些后续步骤建议，例如深色编辑风格变体、定价板块或移动端视口。每条建议都会生成一个全新的 frame，原始 frame 保持不变，方便对比。
* **[与它对话](/zh/design/chat-about-your-design)**：在 frame 下方的输入框中，用你自己的话描述需求，比如*“换掉主视觉照片”*、*“让行动号召更醒目”*。

<Frame caption="选中导入的 frame，旁边的建议提出了深色编辑风格变体、定价板块和移动端视口。">
  <img src="/assets/mirror/figma-make-it-yours-2cf4922ec90a.webp" alt="在 Replit Design 中选中导入的 Personal Fitness Trainer frame，旁边有三张建议卡片：深色编辑风格变体、添加定价板块和移动端视口" width="3440" height="2160" data-path="images/fitstart/turn-mockup-into-app/figma-make-it-yours.webp" />
