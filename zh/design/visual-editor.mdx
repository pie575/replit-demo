<div id="what-is-visual-editor">
  ## 什么是 Visual Editor？
</div>

Visual Editor 可让您直接点击界面元素，对 UI 进行直观修改。它既可在 Replit Design 的 [Canvas](/zh/design/canvas) 中使用，也可在 Preview 中使用，因此您可以用相同的方式编辑设计稿和正在运行的应用。

简单编辑——如修改文本、调整颜色和微调间距——会直接更新源代码，无需消耗 AI 积分。对于涉及底层复杂性的更改，Visual Editor 会自动交由 Agent 处理。

关键概念：

* **确定性编辑**：简单更改 (文本、颜色、间距) 会直接应用到源代码，无需经过 Agent loop
* **无需消耗积分**：直接编辑不会消耗 AI 积分——只有复杂更改才会交由 Agent 处理
* **双重上下文**：在 Canvas frames 和 Preview 中的工作方式完全相同
* **源代码同步**：每次编辑都会立即更新底层源代码

<Note>
  Visual Editor 目前仅可在**网页浏览器**中使用。不支持移动 App 或桌面 App。
</Note>

<div id="how-to-use-visual-editor">
  ## 如何使用 Visual Editor
</div>

<div id="editing-on-the-canvas">
  ### 在 Canvas 上编辑
</div>

在工具栏中选择 **编辑** 工具，然后点击 frame 中的任意元素。该元素会高亮显示，并显示一个标注其名称的标签；右侧随即打开 Visual Editor 面板，展示该元素可编辑的属性，例如内容、布局、颜色和边框。调整完成后，选择 **保存编辑** 以应用更改，或选择 **丢弃** 放弃更改。

显示的属性取决于您选中的元素：文本元素会显示字体控件，图像会显示来源和上传选项，容器会显示布局控件。

<div id="editing-in-preview">
  ### 在 Preview 中编辑
</div>

同样的编辑体验也适用于正在运行的应用。

<Steps>
  <Step title="选择元素">
    在 Preview 中点击任意元素即可开始编辑。
  </Step>

  <Step title="进行编辑">
    直接编辑文本、使用拾色器调整颜色、通过样式控件调整间距，或替换图片。
  </Step>

  <Step title="保存">
    点击保存以更新源代码。简单的更改会直接应用，不会消耗 AI 积分。如果编辑较为复杂，Visual Editor 会将相关元数据发送给 Agent 以获取协助。
  </Step>
</Steps>

<div id="text-editing">
  ### 文本编辑
</div>

点击任意文本元素，直接输入即可修改。如果该文本是源代码中的字符串，修改会立即生效。

<div id="color-adjustments">
  ### 颜色调整
</div>

使用颜色选择器调整文本和背景颜色。可在输入框中输入颜色名称 (如“紫色”) ，或使用吸管工具从屏幕任意位置拾取颜色。

<div id="style-changes">
  ### 样式调整
</div>

使用直观的控件调整各元素的内边距、外边距和布局。

<div id="layout-controls">
  ### 布局控件
</div>

Visual Editor 将所有控件归入清晰的分区，方便你更快找到所需控件：**Text**、**布局**、**Color** 和 **边框**。 (选择图片元素时，还会显示 **Image** 分区。)

你可以在 **布局** 分区中调整子元素在容器内的排列方式，无需通过 Agent。选择一个弹性容器并展开 布局 后，你将看到：

* **对齐**：一个 3×3 点阵选择器，用于设置项目在容器内沿两个轴的位置。
* **方向**：两个箭头按钮，用于将子元素排列为行或列。
* **间距**：用于设置项目之间间隔的像素值。间距输入框旁的图标会随当前方向变化，因此你始终可以知道调整的是水平还是垂直间距。旁边的箭头图标可切换 **在项目之间分配空间**，将子元素推向容器的相对边缘。
* **外部空间**：用于设置元素外部间距的各边输入框 (每边一个输入框，并提供链接切换开关，可一次锁定四边) 。
* **内部空间**：用于设置元素内部沿各轴间距的输入框，并提供链接切换开关，可同时控制两个轴。

仅当至少有一个布局控件适用于所选元素时，才会显示 布局 分区。没有间距或布局属性的纯文本节点会完全隐藏该分区，使编辑器保持简洁。

<div id="image-updates">
  ### 更新图片
</div>

选择图片以替换 URL，或上传自己的文件并即时预览。

<div id="what-you-can-do">
  ## 你可以做什么
</div>

* **快速修改文本**：无需打开源文件，即可更新文案、标签和标题
* **探索配色**：通过点击和调整尝试不同的配色方案，无需查找对应的 CSS
* **微调布局**：以可视化方式精细调整内边距、外边距和间距，无需猜测像素值
* **替换图片**：通过点击和上传，将占位图片替换为实际资源
* **迭代设计**：快速调整 Canvas 中的 frame，比较不同的视觉方向，无需反复与 Agent 交互

<div id="frequently-asked-questions">
  ## 常见问题
</div>

<Accordion title="Visual Editor 中的更改会消耗 AI 积分吗？">
  简单且确定的编辑，例如修改文本、选择颜色和调整间距，不会消耗 AI 积分，而是直接更新源代码。如果 Visual Editor 检测到隐藏的复杂情况，会将更改交由 Agent 处理，此时会消耗积分。
</Accordion>

<Accordion title="我可以编辑在多个位置显示的元素吗？">
  可以。选择在 loop 中渲染或在多个组件中复用的元素，会同时高亮并更新所有实例。
</Accordion>

<Accordion title="为什么无法编辑某些元素中的文本？">
  由多个子元素组成的复合元素无法直接在 Visual Editor 中编辑文本。请改为在 Chat 中让 Agent 进行这些更改。
</Accordion>

<Accordion title="如何找到某个元素的源代码？">
  点击所选元素左上角的标签，即可跳转到它在源代码中的位置。
</Accordion>
