export const YouTubeEmbed = ({videoId, title = "Vidéo YouTube", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

<div id="agent-chatui">
  ### Refonte de l’UI des appels d’outils dans le Chat Agent
</div>

L’affichage des appels d’outils dans le Chat Agent adopte une interface plus épurée et compacte. Les appels d’outils sont regroupés dans des lignes réductibles avec des icônes empilées, ce qui permet de voir plus facilement ce qui se passe d’un seul coup d’œil. Les modifications et créations de fichiers renvoient directement au panneau de diff pour faciliter leur révision. Cette interface simplifiée réduit le bruit visuel et vous permet de suivre plus clairement l’exécution d’Agent.

<div id="nodejs">
  ### Correctif de sécurité Node.js
</div>

Une vulnérabilité de sécurité critique a été signalée cette semaine dans Node.js. Tous les environnements de développement Agent et les applications Node.js sur Replit ont été mis à jour vers une version sécurisée. Republiez votre application pour la mettre également à jour vers une version sécurisée.
