# Shopifyを接続する

> ShopifyをAgentに接続して、Replit内からShopifyストアのプロビジョニング、カスタムストアフロントのビルド、商品と在庫の管理ができます。

Shopifyコネクタを使用すると、AgentがShopifyストアをプロビジョニングし、それに対してカスタムストアフロントをビルドし、商品と在庫を管理します。APIキーなしで、すべて一つの会話の中で完結します。Agentは物理的な商品を販売すると説明するたびにShopifyを推奨します。ライブに公開する時だけShopifyにアクセスするだけです。最初のプロンプトから実際の注文まで約10分です。

<Note>
  ステップバイステップのウォークスルーは [Shopifyストアフロントをビルドする](/ja/build/ecommerce-store) を参照してください。
</Note>

## 何をビルドできるか

* 物理的な商品向けのカスタムデザインストアフロント
* ブランデッドのグッズやアパレルショップ
* カートとチェックアウト付きのDirect-to-Consumerショップ
* Shopifyストアを基盤としたカタログと在庫管理ツール
* 単一のヒーロー商品を販売する商品ランディングページ

## Agentが管理するもの

ストアフロントとカタログのすべてはチャットで編集できます。

| 領域      | Agentの機能                                                                                                                                                                                           |
| ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| デザイン    | あなたのガイダンスからヘッドレスフロントエンドを生成します（Liquidテーマなし、テンプレートライブラリなし）。コピー、レイアウト、ナビゲーション、モーション、商品ページはチャットで編集でき、[Canvas](/ja/design/canvas) バリアントで方向性を探ることができます。本物のReplitプロジェクトなので、ブログ、ウィッシュリスト、ランディングページで拡張できます。 |
| 商品      | 商品とバリアントの作成、更新、削除。フィールド：タイトル、説明、タイプ、ベンダー、タグ、SKU、価格、重量、オプション（サイズ、色）、画像、可用性。                                                                                                                         |
| 在庫      | バリアントごとの在庫を設定・調整します。                                                                                                                                                                               |
| コレクション  | 商品をコレクションにグループ化します。                                                                                                                                                                                |
| 割引      | 価格ルールと引き換えコードを作成します。                                                                                                                                                                               |
| 公開 & 同期 | 新しい商品は自動的にストアフロントに公開されます。同期は双方向で機能します：Shopify管理画面での変更がReplitプレビューに表示され、Agentの変更がShopify管理画面に表示されます。                                                                                                |

## ReplitとShopifyの役割分担

| Replitが担当               | Shopifyが担当          |
| ----------------------- | ------------------- |
| ストアフロントのデザインとビルド        | ホスト型チェックアウト         |
| チャットによるカタログ管理（商品、在庫、割引） | 商品、在庫、カート、注文の記録システム |
| ストアフロントのホスティングとデプロイ     | 決済、本人確認（KYC）、支払い    |
| Canvasデザインバリアント         | 税金、送料、フルフィルメント      |
| アプリの拡張（ブログ、ランディングページなど） | マルチチャネル販売           |

注文、返金、支払い、フルフィルメントはAgentではなくShopify管理画面で処理されます。

## 接続のスコープ

* すべてのプランのすべてのビルダーが利用可能。Connectorsパネルの設定もクレデンシャルも不要で、会話内で接続されます。
* アプリにスコープされます：各アプリが独自のShopifyストアを持ちます。
* ストアはクレームするまでReplit所有の開発ストアです。後でクレームできるよう、メールアドレスがShopifyと共有されます。
* Shopify管理画面からいつでもReplitアプリをアンインストールできます。

## Shopifyでライブに公開する

公開はReplitではなくShopifyで行います。AgentにGo Liveフローを開始するよう依頼し、Shopify管理画面でこれらのマーチャント所有のステップを完了してください：

* **ストアをクレームする** — チャットのリンクまたはShopifyが送るメールから。リンクは7日後に期限切れになります。クレームすると無料トライアルが始まります。
* **プランを選択する**: ライブ注文を処理するには [有料プラン](https://www.shopify.com/pricing) が必要です。
* **支払いを設定する**: [Shopify Payments](https://help.shopify.com/en/manual/payments/shopify-payments) または別のプロバイダーを有効化して本人確認（KYC）を完了します。クレームアカウントがKYCを完了するとライブキャプチャが動作します。
* **[配送](https://help.shopify.com/en/manual/shipping)と[税金](https://help.shopify.com/en/manual/taxes)を設定する。**
* **[カスタムドメインを接続する](/ja/build/add-custom-domain)**（オプション）して、ストアフロントのパスワードを解除して購入者にオープンにします。

チェックアウトは常にShopifyホスト型チェックアウトにリダイレクトされるため、購入者はShopifyで支払います。

<Note>
  決済、本人確認、税金、送料、不正チェックはShopifyが担当します。Replitはマーチャントの銀行情報、納税者ID、その他の機密情報を収集しません。
</Note>

## トラブルシューティング

<AccordionGroup>
  <Accordion title="Shopifyストアの設定に時間がかかる">
    プロビジョニングはいくつかのShopify APIを呼び出すため、少し時間がかかる場合があります。ストアフロントのビルドを依頼する前にAgentがセットアップを完了するまで待ってください。
  </Accordion>

  <Accordion title="開発中にチェックアウトがパスワードページを表示する">
    開発ストアはライブになるまでパスワード保護されているため、チェックアウトのプレビューがパスワードページに移動する場合があります。これは想定される動作ですが、カートは機能します。パスワードはローンチ時にのみShopifyで解除してください。
  </Accordion>

  <Accordion title="チェックアウトで実際の支払いが完了しない">
    ライブキャプチャにはクレームShopifyアカウントが支払い設定とKYCを完了する必要があります。それまではチェックアウトはShopifyにリダイレクトしますが、支払いをキャプチャできません。KYCを完了するか、すでに支払い設定済みのアカウントを使用してください。
  </Accordion>

  <Accordion title="このアプリではShopifyが接続されていないとAgentが言う">
    各ストアは1つのアプリにスコープされています。別のアプリでShopifyを接続した場合は、現在のアプリ用にShopifyストアを設定するようAgentに依頼してください。
  </Accordion>

  <Accordion title="商品がストアフロントに表示されない">
    商品はアクティブで公開されている場合にのみ表示されます。Agentは作成した商品を自動公開します。表示されない場合は、Agentに公開を依頼してプレビューを更新してください。
  </Accordion>

  <Accordion title="転送後に接続の再接続が必要になる">
    ストアをクレームまたは転送した後、Shopifyが接続の再認可を求める場合があります。AgentにShopifyの再接続を依頼すると、ストアを失わずにアクセスが復元されます。
  </Accordion>
</AccordionGroup>
