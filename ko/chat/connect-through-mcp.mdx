Model Context Protocol(MCP)은 AI 제품을 도구 및 데이터 소스와 연결하는 개방형 표준입니다. Replit의 기본 integration과는 별개이지만, Conversation에서 작업하는 동안 사용할 수 있는 도구를 넓혀 줍니다.

<div id="choose-the-connection-direction">
  ## 연결 방향 선택
</div>

* **Replit을 외부 도구에 연결:** 큐레이션된 MCP 서버 또는 custom MCP 서버를 추가하면 Replit이 해당 서버가 제공하는 도구를 사용할 수 있습니다. 신뢰할 수 있는 서버만 연결하세요.
* **MCP 클라이언트에서 Replit 사용:** 호환되는 클라이언트를 Replit MCP 서버에 연결하면 해당 클라이언트에서 Replit Apps를 생성, 검색, 확인, 업데이트할 수 있습니다.

MCP는 기본 제공 integration이나 [Skills](/ko/chat/agent-skills)와는 다릅니다. Integrations는 지원되는 서비스 연결을 제공하고, Skills는 재사용 가능한 지침과 보조 자료를 제공합니다. MCP는 프로토콜을 통해 사용할 수 있는 도구를 확장합니다.
