Коннекторы хранилищ данных позволяют Replit Agent безопасно выполнять запросы к хранилищам данных вашей организации. С помощью естественного языка можно создавать панели мониторинга, инструменты отчетности и приложения для работы с данными — знание SQL не требуется. Администраторы сохраняют централизованный контроль с помощью ролевого доступа.

<div id="section">
  ## Поддерживаемые хранилища данных
</div>

Коннекторы хранилищ данных доступны в плане **Enterprise**.

| Хранилище данных | Руководство по настройке                                                                                                                     |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| BigQuery         | Доступно — руководство по настройке скоро появится                                                                                           |
| Databricks       | [Подключение к Databricks](/ru/ja/connectors/warehouses/databricks)                                                                             |
| Microsoft Fabric | [Создание приложений для работы с данными в Microsoft Fabric](/ru/ja/connectors/warehouses/microsoft-fabric) (закрытая предварительная версия)  |
| Snowflake        | [Подключение к Snowflake](/ru/ja/connectors/warehouses/snowflake)                                                                               |

Для каждого хранилища данных предусмотрен свой процесс настройки, поскольку интеграция OAuth, модель идентификации и формат учётных данных различаются. Выберите нужное хранилище данных и следуйте соответствующему руководству.

<div id="section-2">
  ## Платформы аналитики и работы с данными
</div>

Коннекторы для аналитики доступны в планах Core и Pro, а также Enterprise. Подключив инструменты аналитики, Agent может считывать и обрабатывать данные о продукте.

* **Segment** — данные клиентов из CDP, потоки событий и сегменты аудитории
* **Amplitude** — аналитика продукта, данные о поведении пользователей и показатели вовлечённости
* **Hex** — совместные блокноты для работы с данными и результаты запросов

Управляйте ими так же, как и другими коннекторами Replit. См. [Управление коннекторами](/ru/ja/replitai/managing-connectors).

<div id="section-3">
  ## Как работают коннекторы хранилищ данных
</div>

Настройка — это однократный процесс с участием трёх ролей:

1. **Администратор хранилища данных** — создаёт в хранилище интеграцию OAuth или сервисный идентификатор
2. **Администратор организации Replit** — добавляет учётные данные в Replit и настраивает доступ
3. **Разработчик** — входит в систему и начинает работу с Agent

После завершения настройки разработчик может попросить Agent использовать хранилище данных, а Agent создаст и выполнит соответствующий SQL-запрос.

<div id="section-4">
  ### Создание приложений на основе данных из хранилища
</div>

После подключения вы можете попросить Agent создать приложение, использующее ваши данные. Agent может:

* Создавать внутренние инструменты для получения и отображения данных в реальном времени
* Создавать панели мониторинга с диаграммами и визуализациями на основе данных хранилища
* Генерировать SQL-запросы для работы серверной части приложения
* Объяснять схему и структуру таблиц, чтобы помочь вам понять, что следует создать

<Note>
  Agent может отвечать на разовые вопросы о ваших данных, но основное назначение коннектора к хранилищу данных — позволить Agent создавать функциональные приложения, использующие данные вашей организации. Запросы к хранилищу выполняются непосредственно на экземпляре, поэтому убедитесь, что области действия OAuth и разрешения пользователя базы данных допускают необходимые операции чтения и записи.
</Note>
