<div id="o-que-voc-pode-construir">
  ## Ce que vous pouvez créer
</div>

Utilisez Agent pour ajouter Stripe à votre app en un clic, sans aucune configuration. Créez une boutique, acceptez des paiements uniques ou proposez des abonnements. Agent met en place l&#39;intégration, les modèles de données et l&#39;environnement de test.

<div id="como-funciona">
  ## Fonctionnement
</div>

Agent démarre avec un sandbox Stripe afin que vous puissiez tester les paiements en toute sécurité, sans transfert d&#39;argent réel. Vous pouvez créer et tester des flux immédiatement. Une fois prêt, basculez vers votre compte Stripe live pour publier votre application et accepter de vrais paiements.

<Info>
  Un sandbox Stripe est un environnement de test isolé dans lequel vous pouvez simuler
  des paiements, des abonnements et des événements. Pour en savoir plus, consultez la
  [documentation Stripe sur les sandboxes](https://docs.stripe.com/sandboxes).
</Info>

<div id="use-o-stripe-com-sua-equipe">
  ## Utiliser Stripe avec votre équipe
</div>

Stripe fonctionne dans les workspaces collaboratifs : toute votre équipe peut ainsi créer, tester et monétiser la même app ensemble. Tous les membres du workspace peuvent utiliser le compte Stripe connecté, plutôt qu&#39;une seule personne chargée de développer les paiements dans son coin.

<div id="como-comear">
  ## Pour commencer
</div>

* **Demandez à Agent d&#39;utiliser Stripe**
  * Utilisez une commande slash sur l&#39;écran d&#39;accueil et sélectionnez Stripe, ou formulez directement votre demande :
    <AiPrompt>Crée une boutique et intègre Stripe pour les paiements</AiPrompt>

<Note>
  L&#39;intégration Stripe nécessite une App dotée de fonctionnalités backend. Sélectionnez **App** sur la page d&#39;accueil pour commencer.
</Note>

<div id="teste-pagamentos-no-sandbox">
  ## Tester les paiements en mode sandbox
</div>

1. Ouvrez le **Preview** de votre app dans un nouvel onglet.
2. Effectuez un achat test dans votre boutique ou sur votre page de paiement.
3. Utilisez la carte de test standard de Stripe :

```text theme={null}
Numéro de carte : 4242 4242 4242 4242
Expiration : n'importe quelle date future
CVC : trois chiffres au choix
Nom, adresse : valeurs fictives au choix
```

<Tip>
  Les achats effectués dans le sandbox ne transitent pas par de vrais réseaux et ne génèrent aucun
  mouvement d&#39;argent. Vous pouvez donc tester en toute sécurité, de bout en bout.
</Tip>

<div id="gerencie-produtos-e-preos">
  ## Gérer les produits et les tarifs
</div>

Vous avez deux options :

1. Dans votre app, sélectionnez **Publish** et choisissez de revendiquer votre sandbox Stripe.
   * Si vous n&#39;avez pas encore de compte Stripe, créez-en un pour revendiquer le sandbox.
2. Dans le Stripe Dashboard, ouvrez **Products** pour ajouter ou modifier des produits et des tarifs.
   Les modifications effectuées dans le sandbox Stripe sont automatiquement répercutées dans votre app Replit
   et synchronisées avec la base de données de celle-ci.

<div id="visualize-os-dados-sincronizados-do-stripe">
  ### Consulter les données synchronisées depuis Stripe
</div>

* Dans le Project Editor, ouvrez **Database**.
* Sélectionnez **MyData**.
* Basculez le sélecteur de schéma sur **Stripe** pour afficher les objets de paiement et les enregistrements
  associés.

<div id="v-para-produo">
  ## Passez en production
</div>

Pour accepter de vrais paiements, connectez votre compte Stripe live en installant l&#39;application
[Replit Integrated Payments](https://marketplace.stripe.com/apps/replit-integrated-payments)
depuis le Stripe Marketplace. Le processus d&#39;installation connecte automatiquement votre compte live
— vous n&#39;avez aucune clé d&#39;API à copier-coller.

<Warning>
  Votre intégration en sandbox n&#39;est pas prête pour la production. Elle ne peut pas accepter de paiements
  réels tant que vous n&#39;avez pas suivi les étapes ci-dessous.
</Warning>

<Steps>
  <Step title="Ouvrez le panneau Publish">
    Dans votre app, sélectionnez **Publish** pour lancer le processus de connexion live.
  </Step>

  <Step title="Installez l'application Replit Integrated Payments">
    Sélectionnez **Install Stripe app**. Une fenêtre Stripe s&#39;ouvre sur la fiche
    [Replit Integrated Payments](https://marketplace.stripe.com/apps/replit-integrated-payments).

    Lorsque Stripe vous demande de choisir un compte, sélectionnez votre compte Stripe
    **live** — et non un compte sandbox ou de test.
  </Step>

  <Step>
    Suivez les instructions de Stripe pour installer l&#39;application. Si votre compte live
    n&#39;est pas encore activé, Stripe vous guide d&#39;abord dans la vérification KYB
    (Know Your Business).

    Laissez la fenêtre Stripe ouverte jusqu&#39;à la fin de l&#39;installation.
    Replit finalise la connexion de production en arrière-plan une fois que
    Stripe a confirmé l&#39;installation.
  </Step>

  <Step title="Publiez votre app">
    Revenez sur Replit. Le panneau **Publish** indique que votre compte Stripe live
    est connecté. Publiez votre app pour commencer à accepter de vrais
    paiements.
  </Step>
</Steps>

<Note>
  L&#39;installation de l&#39;application Replit Integrated Payments remplace l&#39;ancien processus manuel
  qui consistait à copier les clés Publishable et Secret dans Replit. L&#39;application configure
  vos clés de production à votre place et maintient la synchronisation entre le sandbox et le
  compte live.
</Note>

<div id="gerencie-a-integrao">
  ## Gérer l&#39;intégration
</div>

* Rendez-vous dans **Integrations &gt; Stripe** pour ouvrir le connector Stripe.
* De là, vous pouvez tester la connexion, consulter son état et gérer les paramètres.

<div id="perguntas-frequentes">
  ## Questions fréquentes
</div>

<div id="como-atualizo-os-preos-dos-meus-produtos">
  ### Comment mettre à jour les prix de mes produits ?
</div>

* Demandez à Agent : décrivez la modification et Agent met à jour votre app ainsi que les objets Stripe.
* Utilisez le Stripe Dashboard : ouvrez **Products** pour modifier les prix et les détails des produits.
  * Dans le sandbox, les modifications sont automatiquement resynchronisées vers votre app et votre base de données.
  * Pour la production, basculez d&#39;abord sur votre compte live, puis mettez à jour les prix. Republiez votre app si elle doit prendre en compte la nouvelle configuration.

<div id="como-testo-transaes-no-replit">
  ### Comment tester des transactions dans Replit ?
</div>

Ouvrez le **Preview** de votre app dans un nouvel onglet. Exécutez le flux Stripe Checkout avec la
carte de test standard (4242 4242 4242 4242), une date d&#39;expiration future quelconque et n&#39;importe quel CVC. Consultez
[Tester les paiements dans le sandbox](#teste-pagamentos-no-sandbox) ci-dessus pour plus de détails.

<div id="o-que-uma-conta-stripe-ao-vivo">
  ### Qu&#39;est-ce qu&#39;un compte Stripe live ?
</div>

Un compte Stripe live est un compte activé et vérifié, capable de traiter de vrais
paiements avec les informations de votre entreprise. Consultez les instructions de Stripe sur la création et
l&#39;activation d&#39;un compte : [Create and manage your Stripe account](https://docs.stripe.com/get-started/account).

<div id="ainda-preciso-colar-minhas-chaves-de-api-do-stripe">
  ### Dois-je encore coller mes clés d&#39;API Stripe ?
</div>

Non. L&#39;application Replit Integrated Payments installe vos clés de production pour vous
lorsque vous connectez votre compte Stripe live. Vous n&#39;avez pas besoin de copier de clés de production
depuis le Stripe Dashboard.

Si vous aviez déjà connecté Stripe en collant des clés de production, cette connexion
continue de fonctionner. Vous pouvez passer au flux d&#39;installation de l&#39;application Stripe en supprimant
la connexion Stripe, puis en vous reconnectant depuis le panneau **Publish**. Consultez
[Mettre à jour ou supprimer la connexion Stripe](#atualizar-ou-remover-a-conexão-do-stripe)
ci-dessous.

<div id="atualizar-ou-remover-a-conexo-do-stripe">
  ## Mettre à jour ou supprimer la connexion Stripe
</div>

Si vous n&#39;êtes pas prêt à publier avec une connexion Stripe active, deux
options s&#39;offrent à vous :

<div id="opo-a-remover-a-integrao-do-stripe-manualmente">
  ### Option A : supprimer manuellement l&#39;intégration Stripe
</div>

Vous pouvez supprimer entièrement l&#39;intégration Stripe de votre projet.

<Steps>
  <Step title="Ouvrez l'onglet Integrations">
    Accédez à votre app Replit et sélectionnez l&#39;onglet **Integrations** en haut. Sous **Connectors**, repérez **Stripe** et sélectionnez **Manage**.

    <Frame>
      <img src="/assets/mirror/stripe-disconnect-1-integrations-371e1e7e5609.png" alt="Onglet Integrations affichant les Connectors avec l'intégration Stripe et un bouton Manage" width="2000" height="1110" data-path="images/replitai/stripe-disconnect-1-integrations.png" />
    </Frame>
  </Step>

  <Step title="Développez vos clés d'API">
    Sélectionnez le chevron pour développer vos **Sandbox API keys** et vos **Live account API keys**, puis sélectionnez **Edit**.

    <Frame>
      <img src="/assets/mirror/stripe-disconnect-2-edit-keys-4e9e76c4065f.png" alt="Clés d'API du sandbox et du compte en direct Stripe développées avec des boutons Edit" width="2000" height="1274" data-path="images/replitai/stripe-disconnect-2-edit-keys.png" />
    </Frame>
  </Step>

  <Step title="Déconnectez votre compte">
    Sélectionnez **Disconnect account** pour supprimer la connexion Sandbox et **Disconnect live account** pour supprimer la connexion en direct.

    <Frame>
      <img src="/assets/mirror/stripe-disconnect-3-disconnect-f4257f534c5c.png" alt="Clés d'API du sandbox et du compte en direct Stripe avec les boutons Disconnect account et Disconnect live account" width="2000" height="1271" data-path="images/replitai/stripe-disconnect-3-disconnect.png" />
    </Frame>
  </Step>

  <Step title="Demandez à Agent de supprimer le code Stripe">
    Rendez-vous dans le chat d&#39;Agent et demandez-lui de supprimer le code du connector Stripe de votre application. Cela supprimera l&#39;intégralité de votre intégration Stripe.
  </Step>
</Steps>

<div id="opo-b-voltar-a-um-checkpoint-anterior-integrao-com-o-stripe">
  ### Option B : revenir à un checkpoint antérieur à l&#39;intégration Stripe
</div>

Si vous souhaitez annuler complètement l&#39;intégration Stripe et revenir à un état antérieur, vous pouvez restaurer un checkpoint précédent.

<Steps>
  <Step title="Ouvrez l'onglet Integrations">
    Accédez à votre app Replit et sélectionnez l&#39;onglet **Integrations** en haut. Sous **Connectors**, repérez **Stripe** et sélectionnez **Manage**.

    <Frame>
      <img src="/assets/mirror/stripe-disconnect-1-integrations-371e1e7e5609.png" alt="Onglet Integrations affichant les Connectors avec l'intégration Stripe et un bouton Manage" width="2000" height="1110" data-path="images/replitai/stripe-disconnect-1-integrations.png" />
    </Frame>
  </Step>

  <Step title="Développez vos clés d'API">
    Sélectionnez le chevron pour développer vos **Sandbox API keys** et **Live account API keys**, puis sélectionnez **Edit**.

    <Frame>
      <img src="/assets/mirror/stripe-disconnect-2-edit-keys-4e9e76c4065f.png" alt="Clés d'API du sandbox et du compte en direct Stripe développées avec des boutons Edit" width="2000" height="1274" data-path="images/replitai/stripe-disconnect-2-edit-keys.png" />
    </Frame>
  </Step>

  <Step title="Déconnectez votre compte">
    Sélectionnez **Disconnect account** pour supprimer la connexion Sandbox et **Disconnect live account** pour supprimer la connexion en direct.

    <Frame>
      <img src="/assets/mirror/stripe-disconnect-3-disconnect-f4257f534c5c.png" alt="Clés d'API du sandbox et du compte en direct Stripe avec les boutons Disconnect account et Disconnect live account" width="2000" height="1271" data-path="images/replitai/stripe-disconnect-3-disconnect.png" />
    </Frame>
  </Step>

  <Step title="Trouvez un checkpoint antérieur à l'intégration Stripe">
    Rendez-vous dans le chat de l&#39;Agent et recherchez un checkpoint créé avant l&#39;intégration Stripe. Sélectionnez l&#39;**icône d&#39;horloge** en haut à gauche du panneau de chat pour consulter l&#39;historique de chat plus ancien.

    <Frame>
      <img src="/assets/mirror/stripe-rollback-5-clock-icon-c54cd19246ea.png" alt="Icône d'horloge permettant d'afficher l'historique de chat et les checkpoints" width="56" height="50" data-path="images/replitai/stripe-rollback-5-clock-icon.png" />
    </Frame>
  </Step>

  <Step title="Sélectionnez Rollback here">
    Une fois que vous avez trouvé un checkpoint qui vous convient, sélectionnez **Rollback here** pour restaurer votre projet dans cet état.

    <Frame>
      <img src="/assets/mirror/stripe-rollback-6-checkpoint-2f195b0ea9ce.png" alt="Checkpoint avec le bouton Rollback here" width="904" height="202" data-path="images/replitai/stripe-rollback-6-checkpoint.png" />
    </Frame>
  </Step>
</Steps>

<div id="notas-e-limitaes">
  ## Notes et limitations
</div>

* L&#39;activité dans le sandbox n&#39;a aucune incidence sur les soldes ni sur les clients réels.
* Certaines fonctionnalités de Stripe ne peuvent pas être testées dans les sandboxes (par exemple, la tarification IC+
  et certains flux Connect). Consultez
  [les limitations des sandboxes Stripe](https://docs.stripe.com/sandboxes).
