## Agent

### Personalize o Agent com instruções e habilidades do workspace

Agora você pode ensinar ao Agent como sua equipe trabalha uma única vez e fazer com que ele aplique isso em todos os projetos. Defina **instruções personalizadas** que o Agent seguirá em cada projeto e crie **habilidades** reutilizáveis que o Agent carrega sob demanda para tarefas específicas. Você gerencia ambas em **Configurações do Workspace** > **Personalização**.

## Plataforma

### Bloqueie pacotes maliciosos com o Firewall de Pacotes

O Replit agora bloqueia pacotes de software maliciosos e comprometidos antes que eles alcancem seu aplicativo. O Firewall de Pacotes verifica cada instalação nos gerenciadores de pacotes mais comuns e interrompe dependências prejudiciais automaticamente. Ele está ativado por padrão, e o Agent adapta seu plano para usar alternativas mais seguras quando algo é bloqueado.

### Adicione referências visuais ao gerar mídia no Canvas

Ao gerar uma imagem, vídeo ou gráfico vetorial no Canvas, agora você pode anexar elementos já presentes no seu quadro como referências visuais. Escolha um frame, uma nota ou uma imagem e o Agent o utiliza para guiar o resultado, fazendo com que a mídia gerada corresponda ao visual do seu projeto.

<Frame caption="Abra o menu + no formulário Gerar mídia para enviar um arquivo ou selecionar elementos do canvas.">
  <img src="/assets/mirror/canvas-generate-media-references-ac0cb4340acb.png" alt="O formulário Gerar mídia no Canvas com o menu de adição aberto, mostrando as opções Enviar arquivo e Selecionar elementos do canvas e o menu suspenso de modelos configurado para Nano Banana Pro" width="1134" height="662" data-path="images/replitai/canvas-generate-media-references.png" />

## Segurança

### Escolha quais alertas de produção chegam à sua caixa de entrada

Agora você controla os alertas de produção separadamente dos outros e-mails. Uma nova configuração de **Alertas de Produção** decide se o Replit envia e-mails sobre incidentes de disponibilidade, vulnerabilidades de segurança nas suas dependências e atualizações de modelos de linguagem. Se um aplicativo publicado estiver usando um modelo desatualizado, o Replit também prepara uma tarefa de rascunho para que você possa atualizar com uma única revisão.

</Frame>

Saiba mais sobre [configurações de notificação](/pt/features/editor/user-settings#notifications).
