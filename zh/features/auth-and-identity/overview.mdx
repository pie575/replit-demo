“用户与身份验证”工具用于管理使用你应用的用户及其登录方式。在 **Tools** 面板中的 **Replit Cloud** 下打开 **Users &amp; Auth**。

该工具包含两个标签页：

* **Users**：所有登录过你应用的用户，显示姓名和最近一次登录时间。可搜索列表以查找特定用户。
* **Configure**：你应用的登录体验，包括登录界面的名称和图标、应用提供哪些登录身份提供方，以及会话密钥。

<Note>
  该工具管理的是你**应用**的用户，即注册并登录你所构建应用的人。若要控制哪些人能够打开你已发布的应用，请参阅[谁可以访问你的应用](/zh/features/publishing/private-deployments)。
</Note>

<div id="choose-your-auth-system">
  ## 选择你的认证系统
</div>

* **[Replit Auth](/zh/features/auth-and-identity/authentication)**：零配置方案。让 Agent 添加 Replit Auth，你的应用即可获得预置的登录页面、用户管理和安全会话，无需任何配置。
* **[Clerk](/zh/features/auth-and-identity/clerk-auth)**：功能完整的身份验证服务，适合需要更强控制力的应用，例如自定义登录流程和使用自有品牌的 OAuth 界面。可为 Google、GitHub、Apple 和 X 配置[自定义登录身份提供方](/zh/features/auth-and-identity/sign-in-providers)。
