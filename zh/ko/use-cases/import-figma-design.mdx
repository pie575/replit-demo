<div id="section-3">
  ## 开始之前
</div>

准备一个包含已命名设计帧 (首页、产品、结账等) 的 Figma 文件，并连接 Figma。
将该文件共享给 Agent，或粘贴文件链接以及你关注的设计帧链接。
请说明这是营销网站、应用，还是单个着陆页。

<div id="agent">
  ## 向 Agent 提出请求
</div>

<AiPrompt>
  请基于这个 Figma 文件[链接]，用以下设计帧[设计帧名称或链接]构建一个可正常
  运行的 Replit 应用。请让布局、排版、配色、间距和
  断点 (桌面端与移动端) 与原设计保持一致。
</AiPrompt>

<div id="section-4">
  ## 预期结果
</div>

Agent 会读取所选的设计帧，在 Replit 中构建出与之匹配、可直接发布的页面。请抽样对照 Figma 检查间距、排版和配色，交互元素 (导航、表单、悬停效果) 则需要你自行验证。通常还需要再打磨一轮。请分别在桌面端和移动端宽度下预览，点击测试导航和表单，然后在发布前将截图与 Figma 进行比对。

<div id="section-5">
  ## 按需引导
</div>

<AiPrompt>
  请先只实现移动端设计帧，并与 Figma 中的自动布局和间距保持一致。等移动端确认通过后，
  再做桌面端。
</AiPrompt>

<AiPrompt>
  请在按钮、输入框和卡片中复用同一套组件。如果有 Figma 变量，
  请从中获取颜色和排版样式。
</AiPrompt>

<div id="section-6">
  ## 故障排查
</div>

* **Agent 无法读取文件：** 请先连接 Figma 并共享文件，然后除了文件 URL 之外，还要粘贴设计帧链接。如果文件中包含多个流程，请指明设计帧名称 (首页、产品、结账) 。
* **悬停、导航、表单看起来不完整：** 布局和配色通常会先生成。你可以再让 Agent 针对交互元素打磨一轮，并对照 Figma 抽查间距。
