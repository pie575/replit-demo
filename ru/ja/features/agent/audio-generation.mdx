Добавьте звук в свой App с помощью функции генерации аудио в Agent. Попросите Agent создать фоновую музыку, звуковые эффекты или закадровый голос — и аудио будет добавлено прямо в проект.

Генерация аудио позволяет создавать насыщенные впечатления без студии звукозаписи, актёров озвучивания и сторонних инструментов. Игры, интерактивные руководства, приложения, которым нужен голос, — Agent подберёт и создаст аудио, подходящее вашему проекту.

<div id="section">
  ## Что можно создать
</div>

Agent может генерировать три вида аудио:

* **Музыка**: фоновые треки и тематические композиции в заданном настроении и стиле.
* **Звуковые эффекты**: короткие фрагменты — щелчки, оповещения, переходы, игровые звуки и т. п.
* **Речь**: естественно звучащая озвучка и закадровый голос по введённому вами тексту.

<div id="section-2">
  ## Как использовать
</div>

Генерация звука встроена в Agent, поэтому включать её в настройках не нужно. Откройте любой Replit App с подключённым Agent и опишите, какой звук вам нужен. Agent сам поймёт, когда по вашему запросу требуется сгенерировать звук, создаст клип и добавит его в проект.

<div id="agent">
  ### Когда Agent генерирует звук
</div>

Agent генерирует звук, когда вы просите добавить звуковое сопровождение в проект:

| Сценарий использования   | Пример промпта                                                          |
| ------------------------ | ----------------------------------------------------------------------- |
| Фоновая музыка           | «Добавь спокойную фоновую музыку в App для медитации»                   |
| Звуковые эффекты в играх | «Создай звук подбора монеты и звук прыжка для игры»                     |
| Голосовая озвучка        | «Сгенерируй дружелюбный голос, который зачитывает шаги онбординга»      |
| Оповещения и уведомления | «Создай короткий сигнал, который звучит при получении нового сообщения» |

<div id="section-4">
  ## Как аудио встраивается в App
</div>

Agent добавляет сгенерированное аудио в проект так же, как и любые другие ресурсы:

* **Автоматическое создание файлов**: сгенерированные аудиофайлы сохраняются прямо в проекте.
* **Обновление кода**: Agent встраивает аудио в App так, чтобы оно воспроизводилось в нужный момент.
* **Итерации**: попросите Agent изменить настроение, длительность, голос или стиль — и он сгенерирует аудио заново.

<div id="section-5">
  ## Стоимость
</div>

Генерация звука — это сервис Agent. Agent взимает плату по тарифам провайдера, а сумма списывается с ваших кредитов Replit. Стоимость отображается на [странице использования](/ru/ja/billing/managing-spend).

<Note>
  Генерация звука в Replit работает на базе [ElevenLabs](https://elevenlabs.io/), которая создаёт высококачественную музыку, звуковые эффекты и речь.
</Note>
