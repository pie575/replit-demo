<div id="o-que-este-fluxo-de-trabalho">
  ## 什么是此工作流程？
</div>

Design Canvas 用于探索，而您的应用在 预览 中。本页面将介绍如何将视觉构想转化为已发布应用的完整流程。

核心概念：

* **Canvas = 草稿**：frame 是用于探索创意的静态 HTML 原型图
* **制品 = 可发布的输出**：转换 frame 会创建可构建和发布的制品
* **单向流程**：Canvas 与您的应用之间没有实时关联——准备就绪后即可转换
* **任何类型的制品**：可转换为 Web 应用、移动应用、幻灯片、数据可视化等

<div id="como-ir-do-design-ao-aplicativo">
  ## 如何从 Design 到应用
</div>

<div id="comece-no-canvas">
  ### 从 Canvas 开始
</div>

打开 [Design Canvas](/zh/pt/replitai/canvas)，探索你的创意。让 Agent 制作原型图、生成多个版本，并排比较不同的设计方向。

**prompt 示例：**

* “为我的 SaaS 产品设计一个落地页”
* “给我看五种仪表板布局的变体”
* “为我的应用勾勒出完整的注册流程”

<div id="refine-com-o-visual-editor">
  ### 使用 Visual Editor 精细调整
</div>

使用 [Visual Editor](/zh/pt/replitai/visual-editor) 直接在您的 frames 中进行实际调整——修改文本、调整颜色和间距——无需经过 Agent 的循环，也不会消耗 AI 积分。

<div id="escolha-uma-direo">
  ### 选择一个方向
</div>

比较各个frame，选择最符合你设想的方案。无需一开始就做到完美——转换后仍可继续完善。

<div id="converta-para-um-artefato">
  ### 转换为制品
</div>

<Steps>
  <Step title="选择 frame">
    点击要转换为实际应用的 frame。
  </Step>

  <Step title="让 Agent 进行转换">
    告诉 Agent 你的需求，例如“将此转换为 Web 应用”或“将此变成移动应用”。
  </Step>

  <Step title="Agent 构建你的应用">
    Agent 会根据你选择的设计创建实际可用的应用，并添加应用所需的后端、数据库和基础设施。
  </Step>

  <Step title="在预览中完善">
    切换到预览，查看正在运行的应用。继续使用 Visual Editor，或与 Agent 对话来添加功能、修正细节并进一步完善。
  </Step>

  <Step title="发布">
    应用准备就绪后即可发布。Replit 会负责托管和基础设施，确保你的应用能够稳定地服务用户。
  </Step>
</Steps>

<div id="o-que-transferido">
  ### 哪些内容会被沿用
</div>

将 frame 转换为 制品 时，Agent 会以该设计为参考构建一个真正可用的应用。视觉布局、配色、排版和结构都会被沿用，Agent 则在此基础上补充功能——数据存储、用户账户、API 连接等。

<Note>
  转换是单向操作。Canvas 中的 frame 与生成的 制品 彼此独立，修改其中一个不会影响另一个。
</Note>

<div id="o-que-voc-pode-construir">
  ## 您可以构建的内容
</div>

* **静态网站 → 全栈应用**：从落地页设计入手，再将其转化为应用，并添加联系表单、支付功能或博客后端
* **仪表板原型图 → 实时数据可视化**：在 Canvas 中设计布局，将其转化为制品，并连接真实数据源
* **移动应用概念 → 原生应用**：在 Canvas 中探索界面，再将其转化为具备导航和真实数据的移动应用
* **幻灯片演示 + 产品**：在同一项目中设计应用和幻灯片演示——二者都始于 Canvas 中的探索，并最终成为真正的制品

<div id="perguntas-frequentes">
  ## 常见问题
</div>

<Accordion title="必须从 Canvas 开始吗？">
  不需要。你可以完全跳过 Canvas，直接在 App 模式下构建。Canvas 用于探索——想在确定方案前尝试不同的视觉方向时，就可以用它。
</Accordion>

<Accordion title="frame 和 制品 有什么区别？">
  frame 是 Canvas 上的静态 HTML 原型图，没有服务器、数据库或后端。制品 则是可真正构建并发布的应用。转换 frame 就会生成一个 制品。
</Accordion>

<Accordion title="同一个 frame 可以转换成多种类型的 制品 吗？">
  可以。你可以先把一个 frame 转换成 Web 应用，之后再单独转换成移动应用或幻灯片演示。每次转换都会生成一个新的 制品。
</Accordion>

<Accordion title="转换之后还能回到 Canvas 吗？">
  Canvas 始终可用。你可以继续创建新的 frame，但转换后的 制品 与原始 frame 相互独立——编辑其中一个不会影响另一个。
</Accordion>

<Accordion title="转换后设计会和原来完全一样吗？">
  Agent 会以你的设计为参考，因此布局、配色和结构都会尽可能还原。随着 Agent 加入实际功能，某些细节可能会有所变化——转换完成后，你可以在预览中进一步调整。
</Accordion>
