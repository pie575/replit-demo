App Storage 是 Replit 内置的对象存储服务，让你的应用可以轻松托管和保存图片、视频、文档等上传内容。
存储桶 (Bucket) 是用于存放对象 (例如文件) 的容器，其中包含访问策略，可限制用户或应用对桶内内容执行的操作。

<Info>
  我们已将 <strong>Object Storage</strong> 更名为 <strong>App Storage</strong>。功能保持不变，你现有的存储桶、权限和程序化访问方式均可继续正常使用。
</Info>

借助 App Storage，你可以构建这样的应用：

* **照片分享平台**：让创作者上传、存储并展示图片
* **视频流媒体服务**：管理视频上传并向观众分发内容
* **文档管理系统**：存储和整理创作者的文件，并提供安全访问
* **作品集网站**：展示作品，媒体文件加载稳定可靠
* **文件备份服务**：为创作者的重要文件提供云端存储

<Note>
  你可以让 **Agent** 为你的应用添加 App Storage，并说明应用需要管理哪些类型的文件。Agent 会配置好集成、创建所需的存储桶，并更新你的应用以实现文件的上传、存储和读取，同时提供身份验证和访问控制等高级功能。
</Note>

借助 App Storage 工具，你可以在开发环境与生产环境之间，或与其他 Replit App 之间，
无缝共享数据。

<div id="recursos">
  ## 功能
</div>

<Info>
  App Storage 基于 Google Cloud Storage (GCS) 构建。
  这意味着你可以获得业界领先的可用性、
  正常运行时间和安全性保障。
</Info>

App Storage 为你的 Replit App 提供以下功能：

* **持久化云存储**：存储的文件始终可供已发布的应用和用户访问
* **可扩展的文件管理**：满足不断增长的数据需求，无需担心存储上限
* **跨应用数据共享**：在多个 Replit App 之间共享存储桶，构建分布式架构
* **程序化访问**：使用直观的 API 上传、下载和管理文件
* **与 Agent 深度集成**：让 Agent 使用高级设置配置 App Storage、检查现有设置，并生成包含身份验证和访问控制的完整后端与前端代码

以下是在 Replit App 中使用 App Storage 的一些场景：

* 存储创作者头像和上传的媒体文件
* 为电商网站提供产品图片
* 管理表单提交中的文档上传
* 构建文件共享与协作功能
* 搭建带有媒体库的内容管理系统

<Tip>
  **与 Agent 深度集成**：你可以让 [Replit Agent](/zh/pt/features/agent/overview) 自动为你的应用添加 App Storage！Agent 现在可以配置对象存储、检查设置，并生成包含身份验证和访问控制等高级功能的完整后端与前端代码。只需在 prompt 中提到&quot;App Storage&quot;或&quot;文件存储&quot;即可。

<div id="uso">
  ## 使用方法
</div>

<Note>
  你的 Replit App 需要向 Google Cloud Storage 进行身份验证，才能访问存储桶及其对象。
  请使用 Replit 官方的 App Storage 客户端库，以自动完成身份验证。
</Note>

你可以直接在 Project Editor 中打开 App Storage 工具。

<Accordion title="如何访问 App Storage 工具">
  在左侧的 **Tool dock** 中：

  1. 选择 <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="所有工具图标" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**，查看 Project Editor 的工具列表。
  2. 选择 <img class="icon-svg" src="/assets/mirror/object-storage-monoochrome-icon-aaba8f517280.svg" alt="App Storage 图标" width="16" height="16" data-path="images/icons/object-storage-monoochrome-icon.svg" /> **App Storage**。

  在**搜索栏**中：

  1. 选择顶部的 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 放大镜图标，打开搜索工具。
  2. 输入“App Storage”以找到该工具，并在结果中选择它。
</Accordion>

要为你的 Replit App 关联一个新的存储桶，请先创建存储桶。

<Accordion title="如何创建存储桶">
  在 **App Storage** 工具中：

  1. 点击 **Create new bucket**。
  2. 在 **Name** 字段中输入存储桶名称，然后选择 **Create bucket**。

  App Storage 选项卡应如下方截图所示：

  <Frame>
    <img src="/assets/mirror/object-storage-empty-bucket-3462e2efb1bc.png" alt="App Storage 工具截图" width="2790" height="1218" data-path="images/databases/object-storage-empty-bucket.png" />
  </Frame>

  如需创建更多存储桶，请打开 **App Storage** 选项卡左上角的存储桶下拉菜单，然后选择 **Create new bucket**。
</Accordion>

<div id="fazer-upload-ou-download-de-objetos">
  ### 上传或下载对象
</div>

要将对象上传到所选存储桶：

1. 在 **App Storage** 选项卡中打开 **Objects** 视图。
2. 选择 <img class="icon-svg" src="/assets/mirror/upload-file-5894be4232ce.svg" alt="上传文件图标" width="16" height="16" data-path="images/icons/upload-file.svg" /> **Upload files**；如需上传某个文件夹中的所有文件，请选择 <img class="icon-svg" src="/assets/mirror/upload-folder-fc87519bedf9.svg" alt="上传文件夹图标" width="16" height="16" data-path="images/icons/upload-folder.svg" /> **Upload folder**。
   然后在文件对话框中选择一个或多个要上传的文件。
   也可以直接将文件或文件夹拖放到显示存储桶内容的区域。

要从所选存储桶下载对象：

1. 在 **App Storage** 选项卡中打开 **Objects** 视图。
2. 点击文件右侧的 <img class="icon-svg" src="/assets/mirror/download-icon-c7b527953d65.svg" alt="下载图标" width="16" height="16" data-path="images/icons/download-icon.svg" /> 下载图标，即可下载该文件。

<div id="organizar-objetos-em-pastas">
  ### 使用文件夹整理对象
</div>

要在选定的存储桶中创建文件夹：

1. 前往 **App Storage** 标签页中的 **Objects** 视图。
2. 在 **Objects** 视图中选择 <img class="icon-svg" src="/assets/mirror/create-folder-c9acf112a042.svg" alt="创建文件夹图标" width="16" height="16" data-path="images/icons/create-folder.svg" /> **Create Folder**。
3. 输入文件夹名称。

要在 **Objects** 视图中将对象添加到文件夹，请将对象拖动到目标文件夹上。

要将对象移动到上级文件夹，请将其拖动到对象列表上方标题栏中的文件夹名称上。

<div id="excluir-objetos-ou-buckets">
  ### 删除对象或存储桶
</div>

<Warning>
  删除操作不可撤销。请在继续之前备份所有重要数据。
</Warning>

永久删除某个对象：

1. 在 **App Storage** 标签页中打开 **Objects** 视图。
2. 点击要删除的对象旁边的 <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="垃圾桶图标" width="16" height="16" data-path="images/icons/trash-icon.svg" /> 垃圾桶
   图标。
3. 在确认对话框中确认删除。

删除某个存储桶及其中的所有对象：

1. 在 **App Storage** 标签页中打开 **Settings** 视图。
2. 在左上角的存储桶下拉菜单中，确保已选中要删除的存储桶。
3. 点击 <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="垃圾桶图标" width="16" height="16" data-path="images/icons/trash-icon.svg" /> **Delete Bucket**。
4. 在确认对话框中确认删除。

<div id="gerenciamento-de-acesso-a-buckets">
  ### 存储桶访问管理
</div>

Replit 会将你创建的所有存储桶关联到你的账户，并提供给你的所有 Replit App 使用。你在哪个 Replit App 中创建存储桶，该 App 就会自动获得访问权限。

你可以控制哪些 Replit App 能够访问特定存储桶，从而高效、安全地共享数据。

要让你的 Replit App 访问账户中其他应用的存储桶：

1. 在 App Storage 标签页左上角的存储桶菜单中，选择 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" />
   **Add an existing bucket**。
2. 在 **Choose a Bucket** 对话框中，选择要添加的存储桶，然后选择 **Add Bucket to Repl**。

<Frame>
  <img src="/assets/mirror/choose-bucket-dialog-b709aa247a85.png" alt="选择存储桶对话框的屏幕截图" width="1115" height="457" data-path="images/databases/choose-bucket-dialog.png" />
</Frame>

要撤销你的 Replit App 对某个存储桶的访问权限：

1. 前往 **App Storage** 标签页中的 **Settings** 视图。
2. 在该标签页左上角的存储桶下拉菜单中，选择存储桶名称。
3. 选择 **Remove Bucket from Repl**，并在确认对话框中确认移除。
