export const YouTubeEmbed = ({videoId, title = "Vidéo YouTube", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

<div id="agent-3">
  ## Lancement d’Agent 3
</div>

Cette semaine, nous avons lancé Agent 3.

<YouTubeEmbed videoId="4FxNXFOdt6w" title="Diffusion en direct du lancement d’Agent 3" />

Agent 3 apporte d’importantes améliorations en matière d’autonomie, de fiabilité et de rapidité :

* **Tests d’application** : Agent effectue ses propres tests dans un navigateur réel, détecte les problèmes et les corrige grâce à une boucle de réflexion. Consultez [Tests d’application](/fr/core-concepts/agent/app-testing).
* **Durée d’exécution prolongée** : Agent peut travailler en autonomie jusqu’à 200 minutes grâce à Live Monitoring, ce qui est idéal pour les projets de grande envergure. Consultez [Agent](/fr/core-concepts/agent#max-autonomy) pour en savoir plus.
* **Création d’agents** : créez des agents et des automatisations qui s’exécutent selon une planification ou s’intègrent à Slack et Telegram. Consultez [Agents et automatisations](/fr/core-concepts/agent/agents-and-automations).

<div id="section">
  ## Connecteurs et intégrations d’applications
</div>

Livrez plus rapidement grâce aux intégrations et connecteurs intégrés :

* **Gérées par Replit** : des intégrations intégrées qui fonctionnent automatiquement dans votre application.
* **Connecteurs** : des intégrations propriétaires auxquelles vous vous connectez une seule fois et que vous pouvez réutiliser dans toutes vos applications.
* **Intégrations externes** : des services tiers de confiance configurés par Agent à l’aide de clés API.

<div id="agents-automations">
  ## Agents et automatisations (bêta)
</div>

Avec Agent 3, vous pouvez créer des agents intelligents, des chatbots et des flux de travail automatisés :

* **Agent Slack** : créez des bots Slack pour la recherche, les questions-réponses et l’automatisation
* **Agent Telegram** : créez des bots pour la planification, l’assistance et bien plus encore
* **Automatisations planifiées** : exécutez des flux de travail selon une planification
