Replit Agent peut se connecter à des centaines d’outils et de sources de données externes via le [Model Context Protocol (MCP)](https://modelcontextprotocol.io), une norme ouverte pour l’intégration d’outils d’IA. Connectez-vous à un serveur prédéfini ou ajoutez un serveur MCP personnalisé auquel vous faites confiance.

<div id="connect-a-pre-listed-mcp-server">
  ## Connecter un serveur MCP prédéfini
</div>

Replit propose une sélection de serveurs MCP pour des services populaires tels que Stripe, Linear, Notion, Sentry et bien d&#39;autres. La connexion se fait en un seul clic.

<Frame>
  <img src="/assets/mirror/mcp-servers-pane-8e1f431ca33c.png" alt="Volet des paramètres Serveurs MCP pour Replit Agent répertoriant des serveurs prédéfinis, notamment Stripe, Linear, Notion, Sentry, Atlassian, Miro, PostHog, Amplitude, Mixpanel, Granola et Razorpay — chacun avec un bouton Se connecter" width="3452" height="1988" data-path="images/replitai/mcp-servers-pane.png" />
</Frame>

<Steps>
  <Step title="Ouvrir le volet Intégrations">
    Accédez à [replit.com/integrations](https://replit.com/integrations) et faites défiler la page jusqu&#39;à **Serveurs MCP pour Replit Agent**.
  </Step>

  <Step title="Choisir un serveur">
    Trouvez le service que vous souhaitez connecter : Stripe, Linear, Notion, Sentry, Atlassian, Miro, PostHog, Amplitude, Mixpanel, Granola, Razorpay et bien d&#39;autres.
  </Step>

  <Step title="Se connecter">
    Cliquez sur **Se connecter** à côté du serveur. Vous serez guidé dans le flux OAuth de ce service. Une fois la connexion établie, l&#39;état de connexion du serveur est mis à jour et Agent peut utiliser ses outils.
  </Step>
</Steps>

Pour consulter le catalogue complet, voir la [référence des serveurs MCP](/fr/features/mcp/overview).

<div id="add-a-custom-mcp-server">
  ## Ajouter un serveur MCP personnalisé
</div>

Si le serveur que vous souhaitez ajouter ne figure pas dans le catalogue prédéfini, ajoutez-le à l’aide de son URL.

<Frame>
  <img src="/assets/mirror/mcp-connect-dialog-5b8f9b0d828e.png" alt="Boîte de dialogue de connexion à un serveur MCP affichant les champs Nom d’affichage et URL du serveur MCP, ainsi qu’une section Paramètres avancés extensible" width="3452" height="1988" data-path="images/replitai/mcp-connect-dialog.png" />
</Frame>

<Steps>
  <Step title="Ouvrir la boîte de dialogue d’ajout de serveur">
    Dans le volet des paramètres des serveurs MCP, cliquez sur **+ Ajouter un serveur MCP**.
  </Step>

  <Step title="Définir un nom d’affichage">
    Indiquez un nom facilement identifiable : Agent l’utilise pour référencer le serveur dans les journaux de discussion.
  </Step>

  <Step title="Saisir l’URL du serveur">
    Collez le point de terminaison HTTPS du serveur MCP. Ouvrez les **paramètres avancés** pour ajouter des en-têtes personnalisés (par exemple, `X-API-Key`) si le serveur nécessite une authentification.
  </Step>

  <Step title="Tester et enregistrer">
    Cliquez sur **Tester et enregistrer**. Replit tente de se connecter et vous guide dans tout flux OAuth requis par le serveur. Une fois enregistrée, la connexion apparaît sous Serveurs MCP avec son état.
  </Step>
</Steps>

<Warning>
  Ne vous connectez qu’à des serveurs MCP auxquels vous faites confiance. Un serveur connecté peut fournir des outils et des données à Agent : vérifiez la source avant d’ajouter un point de terminaison inconnu.
</Warning>

<div id="use-mcp-tools-in-agent">
  ## Utiliser les outils MCP dans Agent
</div>

Une fois un serveur connecté, Agent récupère automatiquement la liste de ses outils et rend ses fonctionnalités disponibles dans tous vos projets. Pour utiliser un serveur, il vous suffit de le mentionner dans le Chat :

> Utilisez le serveur MCP Notion pour trouver les notes de réunion les plus récentes.

<Frame>
  <img src="/assets/mirror/tool-call-7a53f51a11ae.png" alt="Agent appelant les outils d’un serveur MCP personnalisé dans le chat" width="571" height="817" data-path="images/replitai/custom-mcp/tool-call.png" />
</Frame>

Agent sélectionne les outils du serveur les plus adaptés à votre demande. Si un outil nécessite une confirmation, une invite s’affiche avant son exécution.

<div id="share-an-install-link">
  ## Partager un lien d’installation

Utilisez le formulaire ci-dessous pour générer un lien d’installation et un badge cliquable pour votre serveur :
