<div id="ai">
  ### Поддержка аудио в AI-интеграции
</div>

<Frame>
  <img src="/assets/mirror/screenshot-2026-01-22-at-9-08-38-am_80c7a6b9af74-1f051e99efdc.png" alt="Настройки аудио в AI-интеграции с параметрами транскрибации и вывода" width="2884" height="1768" data-path="images/changelog/2026-01-23/screenshot-2026-01-22-at-9-08-38-am_80c7a6b9af74.png" />
</Frame>

AI-интеграция теперь поддерживает аудиофункции в четырёх новых моделях:

* `gpt-4o-transcribe` и `gpt-4o-transcribe-mini` для преобразования речи в текст
* `gpt-4o-audio` и `gpt-4o-audio-mini` для генерации аудиовывода

Создавайте приложения для обработки или генерации аудиоконтента. Расшифровывайте подкасты, создавайте голосовых помощников или добавляйте в приложения голосовые интерфейсы.

<div id="agent">
  ### Веб-поиск в автоматизациях Agent
</div>

<Frame>
  <img src="/assets/mirror/image_935f53bc7191-e59f7aee0cd0.png" alt="Agent предоставляет сводку исследования через автоматизацию" width="1482" height="2492" data-path="images/changelog/2026-01-23/image_935f53bc7191.png" />
</Frame>

Создавайте автоматизации, использующие веб-поиск без ключа API. Agent интегрирует нативный веб-поиск LLM через AI-интеграцию, позволяя получать исследования по расписанию, сводки новостей и образовательный контент.

<div id="replitmdrulessync">
  ### Поддержка replit.md в RulesSync
</div>

Проект с открытым исходным кодом [RulesSync](https://github.com/dyoshikawa/rulesync) теперь поддерживает файлы `replit.md`. Синхронизируйте файлы настроек ИИ-агентов (`CLAUDE.md`, `AGENT.md`, `replit.md`) между несколькими проектами.
