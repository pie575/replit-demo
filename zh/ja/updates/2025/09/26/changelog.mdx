<div id="section-3">
  ### 部署时的安全扫描
</div>

通过全新的发布前安全扫描保护你的应用。在部署应用前，你可以开启或关闭扫描，以检测恶意文件和安全漏洞。高置信度安全规则会在发布前扫描潜在威胁，帮助保障代码安全。

<div id="agent">
  ### Agent Playground 测试功能改进
</div>

增强后的演练场功能可帮助您更高效地测试 AI Agent 和自动化。现在，测试 Slack 和 Telegram Agent 时，您可以查看工具调用的可视化呈现，以及基于时间的工作流自动化的实时测试结果。您可以在部署前更深入地了解 Agent 的表现。

<div id="enterprise">
  ## 团队和 Enterprise
</div>

<div id="enterprise-2">
  ### 强制执行 Enterprise 安全扫描
</div>

Enterprise 管理员现在可以要求对所有团队部署执行安全扫描。通过要求所有已发布的应用进行安全扫描，您可以确保整个组织采用一致的安全标准，并全面掌控团队的安全态势。
