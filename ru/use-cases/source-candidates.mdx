Ashby уже обрабатывает входящие заявки. Этот рабочий процесс предназначен для поиска кандидатов: прочитайте описание вакансии в Drive, найдите подходящих инженеров на GitHub, пропустите тех, кто уже есть в Ashby, и
подготовьте сообщение для отправки. Agent отмечает новых людей как найденных, добавляя краткое пояснение, почему они подходят,
и черновик сообщения для кандидата. Вы проверяете и отправляете. Не используйте это как единственный критерий при найме.

* Руководителей по найму, которым нужны инженеры с подходящими профилями на GitHub, без необходимости весь день заниматься поиском.

<div id="what-to-expect">
  ## Чего ожидать
</div>

Agent читает описание вакансии, ищет кандидатов в GitHub, пропускает тех, кто уже есть в Ashby, и
возвращает короткий список с черновиками. Вы проверяете их и отправляете. Первый результат может быть неточным.
После просмотра уточните обязательные требования. Откройте три профиля GitHub из списка, проверьте, что они
соответствуют обязательным требованиям, и убедитесь, что этих людей ещё нет в Ashby, прежде чем что-либо
отправлять.

<div id="troubleshooting">
  ## Устранение неполадок
</div>

* **В коротком списке слишком много нерелевантных кандидатов:** после первого прохода уточните обязательные и желательные требования. Запросите недавние коммиты на определённом языке или в репозиториях конкретного типа и исключите людей, которые, судя по всему, являются текущими клиентами или сотрудниками конкурентов.
* **В Ashby по-прежнему появляются уже добавленные люди:** убедитесь, что Ashby подключён к нужному workspace и что Agent сопоставляет кандидатов по адресу электронной почты или имени пользователя GitHub, а не только по отображаемому имени.
* **Кандидатам были отправлены сообщения:** этот рабочий процесс должен только создавать черновики. Если что-то было отправлено, остановите Routine и укажите Agent никогда не отправлять кандидатам электронные письма или сообщения.
