<div id="agent-now-supports-custom-mcp-servers">
  ### Agent 现已支持自定义 MCP 服务器
</div>

Agent 现在可以连接到远程 Model Context Protocol (MCP) 服务器，只需简单配置即可使用新的功能和工具。这使 Agent 能够调用外部工具，并从远程系统获取上下文。

使用自定义 MCP 服务器，您可以：

* 连接到能够获取上下文并在外部工具中执行操作的远程服务器
* 通过 MCP 开放标准访问数百种工具和数据源
* 自动加载每个服务器提供的工具

合作伙伴只需提供 MCP 服务器，即可将其服务与 Agent 集成，无需额外的集成工作。

  ### 适用于 Enterprise 的 Plaid Connector
</div>

Enterprise 客户现可启用 Plaid Connector，连接银行账户并使用金融科技基础组件构建 App。该 connector 正在积极开发中，我们会根据客户反馈持续推出新功能和改进。

借助 Plaid Connector，您可以：

* 将银行账户连接到您的应用
* 使用金融科技基础组件构建金融功能
* 通过管理仪表板集中管理 connectors
