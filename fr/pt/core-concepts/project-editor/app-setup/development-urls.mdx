Les URL de développement vous permettent de prévisualiser et de tester vos applications au fur et à mesure que vous les créez. Ces URL suivent le format `UUID.servername.replit.dev` et offrent un aperçu en direct de votre app pendant le développement.

</Frame>

Pour afficher votre URL de développement, cliquez sur le texte `{...}.replit.dev` dans la barre d&#39;adresse.

<div id="entendendo-as-urls-de-desenvolvimento">
  ## Comprendre les URL de développement
</div>

Les URL de développement ne restent actives que lorsque vous travaillez activement sur une Replit App. L’URL peut changer chaque fois que vous rouvrez l’application. Elles vous permettent de prévisualiser votre travail dans un navigateur pendant que vous développez et testez.

Par défaut, les URL de développement sont accessibles publiquement sur le Web. Toute personne disposant de l’URL peut voir votre application pendant que vous la développez. Vous pouvez ainsi facilement partager votre travail en cours avec des collaborateurs, des testeurs ou des parties prenantes.

<Warning>
  Les URL de développement sont temporaires et destinées uniquement aux tests. Pour partager des applications avec d’autres personnes, nous vous recommandons de [publier votre application](/fr/pt/learn/projects-and-artifacts/replit-deployments).
</Warning>

<div id="banner-educativo">
  ### Bannière d’information
</div>

Lorsque vous ouvrez un aperçu de développement dans un nouvel onglet, une bannière d’information s’affiche en haut de la page. Elle vous aide à comprendre le rôle des URL `.replit.dev` lorsque vous créez et testez vos applications. Elle fournit des informations sur les URL de développement et l’usage qui en est prévu pendant le processus de développement.

<div id="tornando-as-urls-de-desenvolvimento-privadas">
  ## Rendre les URL de développement privées
</div>

Vous pouvez restreindre l’accès à votre URL de développement pour protéger votre travail en cours.

Pour rendre votre URL de développement privée :

1. Ouvrez les **Developer tools** dans le Project Editor.
2. Sélectionnez l’onglet **Networking**.
3. Activez le bouton **Private development URL**.

Une fois activée, votre URL de développement nécessite une authentification. Seuls vous-même et les membres autorisés de l’équipe peuvent consulter votre travail en cours.

<Note>
  Les clients Enterprise peuvent imposer des URL de développement privées pour tous les projets, renforçant ainsi la sécurité en garantissant que le travail de développement reste protégé dans l’environnement de l’organisation.
</Note>

<div id="melhores-prticas">
  ## Bonnes pratiques
</div>

* **Utilisez des URL privées** pour les applications sensibles ou propriétaires pendant le développement.
* **Utilisez des URL publiques** pour partager votre travail avec des parties prenantes externes pendant le développement actif ou pour tester votre App dans un autre navigateur.
