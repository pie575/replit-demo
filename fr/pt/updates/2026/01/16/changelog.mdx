export const YouTubeEmbed = ({videoId, title = "Vidéo YouTube", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

<div id="interface-de-chamadas-de-ferramentas-redesenhada-no-chat-do-agent">
  ### Interface des appels d’outils repensée dans le Chat de l’Agent
</div>

Le Chat de l’Agent propose désormais une interface plus épurée et compacte pour les appels d’outils. Les appels d’outils sont regroupés en lignes avec des icônes empilées, ce qui permet de voir d’un coup d’œil ce qui se passe. Les modifications et créations de fichiers renvoient directement au panneau de diff pour faciliter leur révision. Cette interface simplifiée vous aide à suivre les exécutions de l’Agent avec moins d’encombrement et plus de clarté.

<div id="correo-de-segurana-do-nodejs">
  ### Correctif de sécurité pour Node.js
</div>

Une vulnérabilité critique a été annoncée cette semaine dans Node.js. Tous les environnements de développement Agent et les apps Node.js sur Replit ont été corrigés afin d’utiliser des versions sécurisées. Vos apps seront également mises à jour vers une version sécurisée lorsque vous les publierez à nouveau.
