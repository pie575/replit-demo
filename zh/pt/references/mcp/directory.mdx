使用本目录探索通过 Model Context Protocol (MCP) 提供专业工具、数据源或工作流的服务器。每个条目都包含简要介绍和一个 Replit 徽章，方便你决定将哪些服务器连接到自己的项目。

这并非完整清单——你可以[添加任意远程 MCP 服务器](/zh/pt/features/mcp/overview#add-an-mcp-server)，并搭配 Replit Agent 使用。

<Info>
  点击 **Add to Replit** 徽章即可安装任意服务器。系统会提示你在项目编辑器中授权该连接。
</Info>
