<div id="section-3">
  ### Пользовательские промпты
</div>

<Note>
  **Обновление (декабрь 2025 г.):** Assistant был упразднён. Для быстрых точечных правок используйте [режим Lite в Agent](/ru/core-concepts/agent/agent-modes).
</Note>

Пользовательские промпты дают полный контроль над тем, как Assistant взаимодействует с вами. Задать определённые стандарты кодирования или изменить поведение Assistant по умолчанию — всё это можно сделать с помощью пользовательских промптов.

Например, вы можете указать:

* Определённый стиль кодирования или фреймворк
* Конкретные приёмы решения задач
* Предпочтения по управлению пакетами

Например, вы можете добавить следующее:

```
use pnpm for package management
use motion/react instead of framer-motion
always use claude-3-5-sonnet-20241022 as your model
```

<div id="workflows">
  ### Workflows
</div>

Workflow — это легко настраиваемая кнопка «Запустить», которая выполняет любую нужную вам команду.

Это последовательность переиспользуемых и настраиваемых шагов, которые можно выполнить внутри Replit App. Она может быть как совсем простой — например, запуск **`python main.py`**, — так и сложной, включающей многошаговые процедуры.

Примеры использования:

* параллельный запуск нескольких сервисов (например, фронтенда и бэкенда);
* последовательное выполнение файлов и команд (например, запуск линтера → запуск тестов, компиляция → выполнение кода).

Чтобы приступить к [созданию workflow](https:/.replit.com/replit-workspace/workflows#creating-workflows), откройте панель Workflows через меню боковой панели инструментов или найдите её с помощью **`Command + K`**.

Подробнее — [здесь](https:/.replit.com/replit-workspace/workflows).
