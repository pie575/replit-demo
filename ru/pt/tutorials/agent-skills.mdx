<div id="por-que-as-skills-importam">
  ## Почему навыки важны
</div>

Каждый раз, когда вы работаете над проектом с Agent, вы создаёте полезный контекст: решения проблем, выбор в дизайне или предпочтения по фреймворкам. Но этот контекст исчезает, когда чат заканчивается. Навыки помогают его сохранить.

Навык работы с анимациями GSAP учит Agent правильно использовать конкретную библиотеку. Навык дизайн-системы гарантирует, что он применит ваши точно заданные цвета и правила отступов. Навык исправления ошибок сохраняет решение, чтобы Agent не повторял ту же ошибку. Задачи, которые раньше выполнялись нестабильно, становятся надёжными.

Навыки также являются [открытым стандартом](https://agentskills.io/specification). Они работают с любым агентом, включая Replit Agent, поэтому вы можете использовать их в разных инструментах.

<div id="incio-rpido-use-uma-skill-no-chat">
  ## Быстрый старт: используйте навык в Chat
</div>

Самый быстрый способ попробовать навыки — прикрепить навык к сообщению:

<Steps>
  <Step title="Откройте селектор навыков">
    Нажмите кнопку **+** рядом с полем ввода в Chat и выберите **Использовать навык**.
  </Step>

  <Step title="Найдите и выберите навык">
    Просматривайте навыки по категориям: «Бизнес и финансы», «Творчество», «Исследования и анализ» и другим. Выберите один или несколько навыков и прикрепите их к сообщению.
  </Step>

  <Step title="Отправьте сообщение">
    Введите запрос и отправьте его. Agent использует выбранный навык только для этого сообщения. В сообщении появится значок навыка, чтобы вы видели, какие навыки активны.
  </Step>
</Steps>

Например, выберите **Анализатор акций** и попросите Agent подготовить отчёт об исследовании акций или выберите **Углублённое исследование**, чтобы Agent изучил сложную тему и представил структурированные результаты.

<Tip>
  Чтобы использовать навыки из селектора в Chat, ничего устанавливать не нужно. Они мгновенно доступны во всех проектах.
</Tip>

<div id="instale-skills-no-seu-projeto">
  ## Установите навыки в свой проект
</div>

Если вы хотите, чтобы Agent последовательно применял навык во всех чатах проекта, установите его. Установленные навыки хранятся в каталоге `/.agents/skills` вашего проекта и сохраняются между сеансами чата.

<div id="descubra-e-instale-pelo-painel-de-skills">
  ### Находите и устанавливайте навыки через панель Skills
</div>

Откройте **панель Skills** в Редакторе проектов и выберите вкладку **Обзор**, чтобы найти навыки от сообщества. Найдите нужный навык, нажмите **Установить**, и он автоматически добавится в ваш проект.

<Frame>
  <img src="/assets/mirror/agent-skills-discover-732b2b0c488a.png" alt="Вкладка поиска навыков с навыками от сообщества и кнопками установки" width="2542" height="1850" data-path="images/replitai/agent-skills-discover.png" />
</Frame>

Например, при создании [сайта-портфолио](https://palmer.gg) с продвинутыми анимациями можно установить:

* **GSAP React** — обучает Agent анимациям при прокрутке, появлению текста и отрисовке SVG-путей
* **Tailwind design system** — предоставляет Agent знания о паттернах Tailwind CSS для типографики, отступов и переходов между представлениями
* **Find skills** — обучает Agent находить и устанавливать новые навыки от вашего имени

<Tip>
  Вы также можете устанавливать навыки через [npx skills CLI](https://github.com/vercel-labs/skills):

  ```bash theme={null}
  npx skills <skill> -a replit
  ```
</Tip>

<div id="crie-skills-por-meio-de-conversas">
  ### Создавайте навыки Agent в ходе общения
</div>

Самый естественный способ создать навык Agent — попросить об этом Agent в разговоре. После совместного решения проблемы или изучения новой библиотеки попросите Agent сохранить полученные знания:

<AiPrompt>
  Изучите лучшие практики интеграции GSAP с React и создайте навык Agent для этого проекта.
</AiPrompt>

Agent использует весь контекст разговора, чтобы создать подробный файл навыка Agent. Это особенно эффективно после сеансов отладки, когда вы вместе разобрались в проблеме.

<div id="escreva-skills-personalizadas">
  ### Создавайте пользовательские навыки Agent
</div>

Для более сложных сценариев создавайте навыки Agent напрямую в соответствии со [спецификацией навыков Agent](https://agentskills.io/specification). Включите **Показывать скрытые файлы** на боковой панели файлов, откройте `/.agents/skills/` и создайте новый Markdown-файл. Так вы получите полный контроль над тем, что знает Agent и как он себя ведёт.

<div id="skills-proativas-vs-reativas">
  ## Проактивные и реактивные навыки
</div>

Эта структура помогает понять, когда и как создавать навыки. Понимание обоих подходов позволит вам действовать эффективнее.

<div id="skills-proativas">
  ### Проактивные навыки
</div>

Проактивные навыки добавляют *до* начала разработки. Сначала вы изучаете нужные библиотеки или паттерны, находите или создаёте для них навыки, а затем начинаете писать промпты.

**Реальный пример:** Перед созданием сайта-портфолио с рисованной SVG-анимацией вы изучаете библиотеки для анимации и находите GSAP. Вы устанавливаете навык для GSAP React, а затем просите Agent создать анимации. С самого начала Agent обладает необходимыми специализированными знаниями: он понимает API библиотеки, лучшие практики и распространённые паттерны. Без навыка он может создать что-то слишком общее или некорректное.

Этот подход хорошо работает, когда:

* Вы используете популярную библиотеку с тонкими нюансами, которые Agent может не освоить самостоятельно
* Вам нужны единообразные дизайнерские решения во всём проекте (типографика, интервалы, стиль анимации)
* Вы начинаете проект и уже определились с техническим направлением

<div id="skills-reativas">
  ### Реактивные навыки
</div>

Реактивные навыки вы создаёте *после* решения проблемы. Вы обнаруживаете проблему, отлаживаете её с помощью Agent, исправляете, а затем фиксируете решение, чтобы она не повторилась.

**Реальный пример:** При создании Canvas для мобильного приложения вы замечаете неровные края изображений, которые становятся заметнее при увеличении масштаба. Отладка с Agent показывает, что причина — алиасинг при уменьшении: проблема рендеринга, из-за которой изображения, вопреки ожиданиям, выглядят хуже по мере уменьшения. После внесения исправления вы просите Agent создать навык:

<AiPrompt>
  Создай навык, который фиксирует то, что мы только что узнали об исправлении алиасинга при уменьшении. Укажи первопричину, решение и случаи, когда обычно возникает эта проблема, чтобы предотвратить её в будущем.
</AiPrompt>

Agent использует историю разговора, чтобы написать навык для конкретного проекта. В следующий раз, когда возникнет эта проблема, вы сможете указать Agent на этот навык вместо отладки с нуля.

Этот подход хорошо подходит, когда:

* Вы исправили неочевидную ошибку и хотите предотвратить её повторное появление
* Во время сеанса отладки вы узнали что-то об архитектуре своего приложения
* Вы хотите зафиксировать решение, на поиск которого потребовались значительные усилия

<div id="seja-seletivo-com-as-skills">
  ## Тщательно выбирайте навыки
</div>

Думайте о навыках как об инструкциях, которые вы дали бы другу, чтобы найти вашу квартиру. Чёткий список инструкций работает. Папка, набитая документацией, — нет: ни у кого нет времени читать всё это, а важные детали теряются.

То же самое относится к Agent. Если добавить слишком много навыков, Agent может запутаться. Тщательно выбирайте навыки, которые активируете для конкретного проекта, и удаляйте те, которые больше не нужны.

<Note>
  Навыки лучше всего работают, когда они описывают конкретные повторяющиеся шаблоны, а не содержат общие рекомендации. Сосредоточьтесь на конкретных рабочих процессах, устоявшихся соглашениях и проверенных решениях.
</Note>

<div id="consideraes-de-segurana">
  ## Рекомендации по безопасности
</div>

Навыки на панели Skills в Replit проходят проверку безопасности. Однако навыки можно устанавливать откуда угодно — они размещены в [репозитории с открытым исходным кодом](https://github.com/vercel-labs/skills), в который может внести вклад любой пользователь.

Поскольку навыки содержат инструкции, которым следует Agent, вредоносный навык может указать Agent вывести конфиденциальные данные из вашего проекта. Перед установкой любого навыка из внешнего источника:

1. **Откройте файл** — навыки представляют собой обычные Markdown-файлы. Перед использованием прочитайте содержимое `/.agents/skills/`.
2. **Проверьте источник** — убедитесь, что навык получен из надёжного репозитория или от проверенного автора.
3. **Проверьте инструкции** — убедитесь, что навык не содержит ссылок на подозрительные внешние URL и не запрашивает конфиденциальную информацию.

<Warning>
  Всегда проверяйте навыки из внешних источников перед установкой. Навыки на панели Skills в Replit прошли проверку, но навыки, установленные через CLI или скопированные из интернета, — нет.
</Warning>

<div id="skills-vs-servidores-mcp">
  ## Навыки и серверы MCP
</div>

Это два основных способа расширять возможности агентов в 2026 году, и они предназначены для разных задач.

**Навыки** экономно используют контекст. Пока навык не вызван, загружается лишь его краткое описание. Используйте навыки для:

* Рабочих процессов и соглашений («как выполнить деплой», «чек-лист проверки кода»)
* Справочных материалов (стандарты API, руководства по стилю, дизайн-системы)
* Многоразовых промптов и специализированных знаний (библиотеки анимации, паттерны фреймворков)

**Серверы MCP** потребляют много контекста. Все описания инструментов загружаются заранее, что при добавлении слишком большого числа серверов может ухудшить качество результатов. Используйте серверы MCP для:

* Подключения к внешним сервисам (Notion, Linear, Figma)
* Действий, требующих доступа к API
* Инструментов, которые *выполняют* действия, а не просто предоставляют инструкции

Ключевое различие: навыки определяют, *как* должен работать ваш агент. Серверы MCP определяют, *к чему* ваш агент может получать доступ. Оба варианта подходят как для агентов, пишущих код, таких как Replit Agent, так и для агентов, которых вы создаёте самостоятельно с помощью таких инструментов, как [Claude Agent SDK](/ru/pt/tutorials/claude-agent-sdk).
