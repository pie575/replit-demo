<div id="o-que-o-agent-geral">
  ## Что такое Agent Geral?
</div>

Agent Geral — это самый гибкий способ работы с Replit Agent. Не нужно заранее выбирать тип артефакта или решать, что именно вы будете создавать. Просто начните диалог — создайте CSV, сформируйте PDF, изучите тему или соберите полноценное приложение, когда будете готовы.

Ключевые понятия:

* **Без предварительного выбора**: приступайте к работе, не выбирая тип артефакта заранее
* **Любой результат**: создавайте файлы (CSV, PDF, документы), проводите исследования или собирайте приложения
* **Коннекторы**: читайте и записывайте данные во внешних сервисах, таких как BigQuery, Linear, Slack, Notion, Amplitude, Segment, Hex и других
* **Постепенное раскрытие**: начните с простого чата и естественным образом перейдите к созданию полноценного приложения

<div id="como-acessar-o-agent-geral">
  ## Как открыть Agent Geral
</div>

Открыть Agent Geral можно несколькими способами:

1. **Выберите «Geral» перед вводом промпта** на главной странице Replit
2. **Откройте любой существующий проект** и начните общаться с Agent напрямую
3. **[Импортируйте](/ru/pt/build/import-from-providers) проект из GitHub** — импортированные из GitHub проекты автоматически получают Agent Geral

<div id="como-usar-o-agent-geral">
  ## Как использовать Agent Geral
</div>

<div id="apenas-comece-a-conversar">
  ### Просто начните разговор
</div>

Откройте проект и начните общаться. Не нужно сразу решать, что именно вы создаёте, — Agent работает в контексте вашего текущего проекта и справится с любой задачей.

**Примеры промптов:**

* «Кратко изложи ключевые моменты этого документа»
* «Создай CSV со 100 крупнейшими компаниями по выручке»
* «Какие у меня пять главных тикетов в Linear?»
* «Настрой проект на Vue.js с TypeScript»

Agent может работать с файлами, созданными во время сессии, формировать результаты в виде отдельных файлов и выполнять код в процессе рассуждений — всё это ещё до того, как вы решите что-то создавать.

<div id="conectando-servios-externos">
  ### Подключение внешних сервисов
</div>

Подключите свои инструменты, чтобы Agent мог напрямую читать и записывать данные:

1. Перейдите в раздел **Коннекторы** в настройках проекта
2. Подключите нужные сервисы (BigQuery, Linear, Slack, Notion, Amplitude, Segment, Hex и другие)
3. Попросите Agent прочитать или записать данные через них

**Примеры промптов с коннекторами:**

* «Какие тикеты открыты в Linear?»
* «Сделай краткую сводку сегодняшних сообщений из Slack в #engineering»
* «Получи данные о продажах за прошлый месяц из BigQuery»
* «Покажи ближайшие события из моего календаря»
* «Создай в Linear новый тикет по багу с интеграцией»
* «Отправь сводку в #engineering в Slack»

<div id="do-chat-ao-aplicativo-completo">
  ### От чата к полноценному приложению
</div>

Когда будете готовы приступить к разработке, просто скажите об этом. Agent плавно перейдёт от непринуждённого чата к созданию вашего приложения — не нужно начинать заново или переключаться между контекстами.

* «Преврати это в веб-приложение»
* «Создай приложение на основе этих данных»
* «Сделай дашборд для этих метрик»
* «Настрой CLI-инструмент на Rust»

Начать можно с малого — изучить тему, сгенерировать отчёт, посмотреть данные — а затем, когда придёт время, перейти к созданию полноценного приложения.

<div id="o-que-voc-pode-construir">
  ## Что можно создать
</div>

* **Работа со знаниями**: исследуйте, обобщайте и анализируйте данные, не создавая приложение
* **Файлы на выходе**: CSV, PDF, документы, выгрузки данных и форматированные отчёты
* **Приложения для работы с данными**: отправляйте запросы к подключённым сервисам и визуализируйте результаты на дашбордах
* **Любой фреймворк или язык**: Angular, Vue, Svelte, Rust, Go, C#, Python tkinter, игры на Godot, инструменты CLI и многое другое
* **Полностековые приложения**: когда будете готовы, создайте полноценное приложение на основе контекста вашего чата

<div id="o-que-esperar">
  ## Чего ожидать
</div>

Agent Geral даёт больше возможностей и гибкости, но вместе с этим появляется и некоторая непредсказуемость:

* **Настройка с первой попытки**: иногда Agent настраивает всё сразу
* **Итеративная совместная работа**: сложные конфигурации могут потребовать нескольких циклов доработки
* **Ограничения технологий**: некоторые технологии могут поддерживаться в среде Nix не полностью

<Note>
  В отличие от стандартного Agent с предварительно настроенными средами, Agent Geral сам настраивает среду и выполняет команды по вашему запросу. Когда вы будете готовы к развёртыванию, его, возможно, потребуется отдельно попросить настроить публикацию.
</Note>

<div id="perguntas-frequentes">
  ## Часто задаваемые вопросы
</div>

<Accordion title="Видит ли Agent мои другие проекты?">
  Нет. Каждый чат ограничен одним проектом. Заставить Проект A и Проект B «общаться» друг с другом не получится.
</Accordion>

<Accordion title="Почему он всё ещё не может получить доступ к моему внешнему инструменту?">
  Сначала нужно подключить свои сервисы через Коннекторы. После подключения Agent сможет читать из них данные и записывать в них, но по умолчанию доступа у него нет.
</Accordion>

<Accordion title="Какие коннекторы доступны?">
  Сейчас поддерживаются: BigQuery, Linear, Slack, Notion, Amplitude, Segment, Hex и другие. Новые коннекторы добавляются регулярно.
</Accordion>

<Accordion title="Нужны ли коннекторы для работы с Agent Geral?">
  Нет, коннекторы необязательны. Agent Geral можно использовать для работы со знаниями, генерации файлов и создания приложений вообще без внешних подключений.
</Accordion>
