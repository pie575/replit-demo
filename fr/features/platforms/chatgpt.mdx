L&#39;intégration Replit dans ChatGPT vous permet de créer, mettre à jour et inspecter vos Replit Apps directement depuis vos conversations, sans aucune configuration. Créez de vraies applications en discutant avec ChatGPT et laissez Agent s&#39;occuper du reste.

<div id="what-is-replit-in-chatgpt">
  ## Qu&#39;est-ce que Replit dans ChatGPT
</div>

Replit dans ChatGPT relie vos conversations ChatGPT à la puissante plateforme de développement de Replit. Vous décrivez ce que vous souhaitez créer, et Agent construit pour vous une Replit App pleinement fonctionnelle. Une fois l&#39;app créée, vous pouvez demander à ChatGPT de la modifier, de la mettre à jour ou de l&#39;analyser, le tout par simple conversation.

<div id="getting-started">
  ## Premiers pas
</div>

Suivez ces étapes pour connecter Replit à ChatGPT et créer votre première application.

<div id="connect-replit-to-chatgpt">
  ### Connecter Replit à ChatGPT
</div>

Vous pouvez connecter Replit à ChatGPT de deux façons :

<Accordion title="Se connecter depuis les paramètres">
  1. Cliquez sur votre icône de profil dans ChatGPT 2. Accédez à **Settings** → **Apps &amp;
     Connectors** 3. Repérez **Replit** et cliquez sur **Connect** 4. Effectuez l&#39;autorisation OAuth
     avec votre compte Replit
</Accordion>

<Accordion title="Se connecter depuis une conversation">
  1. Démarrez une nouvelle conversation dans ChatGPT 2. Appelez Replit à l&#39;aide de l&#39;une des
     méthodes ci-dessous 3. ChatGPT vous guidera dans le processus OAuth si vous n&#39;êtes pas
     connecté
</Accordion>

<div id="invoke-replit-in-chatgpt">
  ### Invoquer Replit dans ChatGPT
</div>

Une fois la connexion établie, vous pouvez invoquer Replit de trois façons :

| Méthode                 | Utilisation                                             |
| ----------------------- | ------------------------------------------------------- |
| Mention directe         | Saisissez `Replit, <request>` au début de votre message |
| Commande slash          | Saisissez `/Replit` dans le champ de saisie             |
| Menu du champ de saisie | Cliquez sur le bouton **+** → **More** → **Replit**     |

<div id="create-your-first-app">
  ### Créez votre première app
</div>

Une fois la connexion établie, créez votre première Replit App :

1. Démarrez une nouvelle conversation dans ChatGPT
2. Appelez Replit et décrivez ce que vous souhaitez créer (par exemple : « Replit, crée une application de liste de tâches avec un mode sombre »)
3. Agent génère votre app et la publie automatiquement
4. Une fois l&#39;opération terminée, vous recevez un lien pour consulter votre app

<Note>
  Chaque conversation ne peut être associée qu&#39;à une seule Replit App. Si vous créez une nouvelle app dans la
  même conversation, elle modifiera l&#39;app existante. Pour créer plusieurs apps,
  démarrez des conversations distinctes.
</Note>

<div id="features">
  ## Fonctionnalités
</div>

* **[Replit AI](/fr/welcome)** : Agent génère et publie des applications à partir de vos demandes en langage naturel
* **[Project Editor](/fr/learn/projects-and-artifacts/project-editor)** : environnement de développement complet accessible depuis ChatGPT
* **[Publishing](/fr/learn/projects-and-artifacts/replit-deployments)** : les applications sont déployées automatiquement et prêtes à être partagées

<Accordion title="Ce que vous pouvez faire">
  **Créer :** créez de nouvelles Replit Apps en décrivant ce que vous souhaitez. Agent génère l&#39;application et la publie automatiquement.

  **Mettre à jour :** modifiez l&#39;application dans votre conversation en cours. Demandez à ChatGPT d&#39;ajouter des fonctionnalités, de corriger des bugs ou d&#39;apporter des modifications, et Agent s&#39;en chargera.

  **Inspecter :** analysez votre application sans y apporter de modifications. Obtenez des informations sur la structure du code, les chemins de fichiers ou le comportement.
</Accordion>

<Accordion title="Formats de fichiers pris en charge">
  Vous pouvez inclure différents types de fichiers dans vos prompts :

  | Format                        | Pris en charge                          |
  | ----------------------------- | --------------------------------------- |
  | PDF                           | Oui                                     |
  | CSV                           | Oui                                     |
  | Formats de documents courants | Oui                                     |
  | Images (fichiers bruts)       | Non (utilisez plutôt des URL publiques) |
  | Vidéos (fichiers bruts)       | Non (utilisez plutôt des URL publiques) |

  <Note>
    Pour inclure des images ou des vidéos dans votre application, fournissez des URL publiques dans votre prompt. Vous pouvez également ajouter des fichiers multimédias directement dans Replit une fois l&#39;application créée.
  </Note>
</Accordion>

<Accordion title="Temps de création">
  Agent crée généralement les applications en :

  | Complexité de l&#39;application                             | Temps de création habituel |
  | ----------------------------------------------------------- | -------------------------- |
  | Simple (calculatrices, petites landing pages)               | 2 à 3 minutes              |
  | Complexe (jeux, animations riches, tableaux de bord denses) | 3 à 4 minutes              |
</Accordion>

<div id="billing-and-credits">
  ## Facturation et crédits
</div>

Le travail effectué par Replit dans ChatGPT est facturé comme une utilisation de Replit Agent sur votre compte Replit.

<Accordion title="Fonctionnement de la facturation">
  * Les forfaits **Core** et **Pro** incluent des crédits mensuels qui couvrent Agent, la publication et les bases de données, dans la limite de votre allocation
  * Vous pouvez acheter des **packs de crédits** qui expirent au bout de six mois et ne se renouvellent pas automatiquement — idéals pour les pics de lancement ou les expérimentations
  * Utilisez les **limites d&#39;utilisation** et les **budgets** dans les paramètres de facturation de Replit pour plafonner vos dépenses

  Pour en savoir plus, consultez la [documentation sur la facturation de l&#39;IA](/fr/billing/ai-billing).
</Accordion>

<div id="current-limitations">
  ## Limitations actuelles
</div>

Actuellement, l&#39;application Replit dans ChatGPT :

* Ne peut travailler que sur l&#39;app créée dans cette conversation précise
* Ne peut ni ouvrir ni modifier :
  * Les apps créées dans d&#39;autres fils de discussion ChatGPT
  * Les apps que vous avez créées directement dans Replit

La parité fonctionnelle avec l&#39;expérience Replit complète (bases de données, gestion des Secrets, contrôles plus avancés du Project Editor) arrivera plus tard.

<div id="troubleshooting">
  ## Dépannage
</div>

<Accordion title="Replit n'apparaît pas dans Browse apps">
  Si Replit n&#39;apparaît pas dans **Browse apps**, vérifiez :

  * si les applications sont disponibles dans votre région ;
  * si l&#39;administrateur de votre workspace a activé l&#39;application Replit (Business/Enterprise/Edu).
</Accordion>

<Accordion title="Échecs de build">
  Si les builds échouent, ouvrez l&#39;app dans Replit :

  * vérifiez votre consommation et votre facturation ;
  * utilisez les checkpoints et les restaurations pour revenir en arrière ;
  * demandez de l&#39;aide à Agent directement dans le Project Editor.
</Accordion>
