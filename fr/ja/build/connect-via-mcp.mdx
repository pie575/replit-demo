Replit Agent peut se connecter à des centaines d’outils externes et de sources de données via le [Model Context Protocol (MCP)](https://modelcontextprotocol.io), la norme ouverte pour l’intégration d’outils d’IA. Connectez-vous à un serveur répertorié ou ajoutez un serveur MCP personnalisé de confiance.

<div id="mcp">
  ## Se connecter à un serveur MCP répertorié
</div>

Replit propose une liste sélectionnée de serveurs MCP pour des services populaires comme Stripe, Linear, Notion et Sentry. La connexion s’effectue en un seul clic.

<Frame>
  <img src="/assets/mirror/mcp-servers-pane-8e1f431ca33c.png" alt="Panneau de configuration des serveurs MCP pour Replit Agent. Des serveurs répertoriés, notamment Stripe, Linear, Notion, Sentry, Atlassian, Miro, PostHog, Amplitude, Mixpanel, Granola et Razorpay, sont affichés avec des boutons de connexion." width="3452" height="1988" data-path="images/replitai/mcp-servers-pane.png" />
</Frame>

<Steps>
  <Step title="Ouvrir le panneau Intégrations">
    Accédez à [replit.com/integrations](https://replit.com/integrations), puis faites défiler jusqu’à **Serveurs MCP pour Replit Agent**.
  </Step>

  <Step title="Choisir un serveur">
    Trouvez le service auquel vous souhaitez vous connecter — Stripe, Linear, Notion, Sentry, Atlassian, Miro, PostHog, Amplitude, Mixpanel, Granola, Razorpay, etc.
  </Step>

  <Step title="Se connecter">
    Cliquez sur **Se connecter** à côté du serveur. Suivez le flux OAuth du service. Une fois la connexion établie, le statut du serveur est mis à jour et Agent peut utiliser cet outil.
  </Step>
</Steps>

Consultez la [référence des serveurs MCP](/fr/ja/features/mcp/overview) pour voir le catalogue complet.

<div id="mcp-2">
  ## Ajouter un serveur MCP personnalisé
</div>

Si le serveur souhaité ne figure pas dans le catalogue répertorié, ajoutez-le à l’aide de son URL.

<Frame>
  <img src="/assets/mirror/mcp-connect-dialog-5b8f9b0d828e.png" alt="Boîte de dialogue de connexion à un serveur MCP affichant les champs Nom d’affichage et URL du serveur MCP, ainsi qu’une section Paramètres avancés repliée" width="3452" height="1988" data-path="images/replitai/mcp-connect-dialog.png" />
</Frame>

<Steps>
  <Step title="Ouvrir la boîte de dialogue d’ajout d’un serveur">
    Dans le panneau de configuration des serveurs MCP, cliquez sur **+ Ajouter un serveur MCP**.
  </Step>

  <Step title="Définir le nom d’affichage">
    Saisissez un nom facilement reconnaissable : Agent l’utilisera pour désigner le serveur dans les journaux de discussion.
  </Step>

  <Step title="Saisir l’URL du serveur">
    Collez le point de terminaison HTTPS du serveur MCP. Si le serveur nécessite une authentification, ouvrez les **paramètres avancés** et ajoutez des en-têtes personnalisés (par exemple, `X-API-Key`).
  </Step>

  <Step title="Tester et enregistrer">
    Cliquez sur **Tester et enregistrer**. Replit tente de se connecter et vous guide dans les flux OAuth requis par le serveur. Une fois l’enregistrement terminé, la connexion s’affiche avec son statut dans la liste des serveurs MCP.
  </Step>
</Steps>

<Warning>
  Connectez-vous uniquement à des serveurs MCP fiables. Les serveurs connectés peuvent fournir des outils et des données à Agent : vérifiez la source avant d’ajouter un point de terminaison inconnu.
</Warning>

<div id="agentmcp">
  ## Utiliser les outils MCP avec Agent
</div>

Une fois le serveur connecté, Agent récupère automatiquement la liste des outils, qui deviennent disponibles dans tous les projets. Pour utiliser un serveur, mentionnez-le simplement dans le chat :

> Utilisez le serveur MCP Notion pour trouver les notes de réunion les plus récentes.

<Frame>
  <img src="/assets/mirror/tool-call-7a53f51a11ae.png" alt="Agent appelle les outils d’un serveur MCP personnalisé dans le chat" width="571" height="817" data-path="images/replitai/custom-mcp/tool-call.png" />
</Frame>

Agent sélectionne l’outil approprié sur le serveur en fonction de votre demande. Si l’outil nécessite une confirmation, une invite s’affiche avant son exécution.
