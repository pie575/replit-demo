Les modèles d&#39;IA comme Claude et GPT sont puissants, mais ils restent limités aux données sur lesquelles ils ont été entraînés. Le Model Context Protocol (MCP) offre une méthode standard pour les connecter à des outils externes, à des sources de données et à des fonctionnalités du monde réel.

<div id="ai-mcp">
  ## Pourquoi les modèles d&#39;IA ont besoin du MCP
</div>

Sans accès à des outils et à des données externes, les modèles d&#39;IA ne peuvent pas :

* accéder aux informations les plus récentes
* interagir avec des systèmes externes
* agir dans le monde réel
* traiter des données personnelles

Le MCP résout ce problème en offrant à l&#39;IA un moyen universel de se connecter aux outils et aux données — un peu comme l&#39;USB-C a standardisé la connexion des appareils.

  <img src="/assets/mirror/mcp-a04e01a01743.avif" alt="Diagramme MCP montrant des modèles d'IA se connectant à des outils et à des sources de données externes" width="1920" height="1055" data-path="images/tutorials/mcp.avif" />
</Frame>

Grâce au MCP, les modèles d&#39;IA peuvent :

* accéder à des outils et des API spécialisés
* lire des sources de données personnelles
* agir dans le monde réel
* se connecter en toute fluidité à d&#39;autres systèmes

<div id="mcp">
  ## Fonctionnement de MCP
</div>

L’architecture MCP repose sur trois composants principaux :

1. **Côté client** — un modèle d’IA ou une application, comme Claude, qui doit accéder à des outils externes.
2. **Couche de communication** — le protocole lui-même, qui standardise le format des requêtes et des réponses.
3. **Côté serveur** — un programme qui donne accès à des outils, des sources de données et des fonctionnalités spécialisées.

<AccordionGroup>
  <Accordion title="Qu’est-ce qu’un client MCP ?">
    Un client MCP peut être Claude, Replit Agent ou une interface de ligne de commande connectée à un grand modèle de langage. C’est l’« interface » qui se connecte à des outils externes ou à des sources de données.

    Exemples de clients MCP :

    * Claude dans le navigateur
    * Replit Agent
    * Interfaces de ligne de commande pour l’IA
    * Applications personnalisées créées avec un SDK d’IA
  </Accordion>

  <Accordion title="Qu’est-ce qu’un serveur MCP ?">
    Un serveur MCP fournit des outils et des fonctionnalités aux modèles d’IA. C’est comme donner à l’IA un ensemble d’outils spécialisés pour résoudre des problèmes.

    Voici quelques exemples de ce que permettent les serveurs MCP :

    * Accéder à des sources de données spécifiques pour répondre à des questions
    * Connecter l’IA à des API afin d’effectuer des actions en ligne
    * Lire ou écrire des fichiers
    * Effectuer des calculs ou exécuter du code
    * Récupérer du contenu depuis des services comme Notion, Linear et Stripe
  </Accordion>
</AccordionGroup>

<div id="mcp-2">
  ## Ce que MCP rend possible
</div>

MCP définit plusieurs primitives puissantes pour les applications d&#39;IA :

* **Resources** — partager des données et du contenu avec les modèles d&#39;IA
* **Tools** — permettre aux modèles d&#39;IA d&#39;effectuer des actions via des services
* **Prompts** — des modèles réutilisables pour des interactions cohérentes avec l&#39;IA
* **Sampling** — permettre aux services de demander des informations aux modèles d&#39;IA
* **Transports** — connecter efficacement les clients et les serveurs

<div id="vs-mcp">
  ## Compétences vs serveurs MCP
</div>

Les compétences et les serveurs MCP sont les deux principaux moyens d&#39;étendre les agents IA, et ils répondent à des objectifs différents.

|                            | Compétences                                                                        | Serveurs MCP                                                                 |
| -------------------------- | ---------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| **Cas d&#39;usage adapté** | Flux de travail, conventions, documents de référence                               | Connexion à des services externes, exécution d&#39;actions                   |
| **Mode de chargement**     | Léger — uniquement le nom et la description jusqu&#39;à l&#39;appel                | Lourd — toutes les descriptions d&#39;outils sont chargées à l&#39;avance    |
| **Définition**             | *Comment* l&#39;agent doit travailler                                              | *À quoi* l&#39;agent peut accéder                                            |
| **Exemple**                | Compétence « Stock Analyzer » — analyse d&#39;investissement selon un cadre précis | Serveur MCP « Stripe » — lecture des données de paiement et d&#39;abonnement |

Pour savoir comment aborder les compétences, consultez [Compétences Agent](/fr/ko/learn/agent-skills).

<div id="section">
  ## Cas d&#39;usage concrets
</div>

MCP rend possible une grande variété d&#39;applications d&#39;IA :

* **Systèmes de service client** : des systèmes qui accèdent aux bases de données de l&#39;entreprise pour répondre à des questions précises
* **Assistants de recherche** : des outils qui recherchent et résument du contenu issu de plusieurs sources
* **Outils de productivité** : des outils qui interagissent avec les fichiers et les applications
* **Outils de création de contenu** : des outils qui accèdent aux médiathèques et aux plateformes de publication

<div id="section-2">
  ## Avantages
</div>

MCP offre trois avantages majeurs :

* Des intégrations prêtes à l&#39;emploi auxquelles l&#39;IA peut se connecter instantanément
* La possibilité de changer de fournisseur d&#39;IA sans réécrire les connexions
* Des fonctionnalités de sécurité qui protègent les données sensibles

<Note>
  MCP est une norme récente dont la prise en charge s&#39;étend à l&#39;ensemble de l&#39;écosystème de l&#39;IA. De nouveaux outils et de nouvelles intégrations viennent régulièrement enrichir l&#39;offre.
</Note>
