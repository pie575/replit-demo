<div id="open-in-replit-button-beta">
  ### Кнопка Open in Replit (бета)
</div>

Теперь работать с тикетами Linear можно прямо в Replit — с помощью новой кнопки Open In Replit. Эту бета-функцию нужно включить в настройках; она автоматически подставляет в prompt данные задачи. Команда сотрудничает с Linear, чтобы улучшить интеграцию.

<div id="agent-production-sql-database-access">
  ### Доступ Agent к продакшен-базе данных SQL
</div>

Теперь Agent может просматривать вашу продакшен-базу данных SQL и выполнять к ней запросы в режиме «только чтение» — это позволяет ему работать с реальными продакшен-данными без риска случайных изменений.

<div id="connection-reliability-improvements">
  ### Улучшения надёжности подключений
</div>

Несколько улучшений, которые делают работу с интеграциями удобнее:

* Токены подключений реже истекают благодаря улучшенному процессу фонового переподключения
* Наглядное отображение подключений, которые работают некорректно или находятся в состоянии ошибки
* Возможность переподключить интеграцию прямо из состояния ошибки

  ## Teams и Enterprise
</div>

<div id="usergroup-level-budgets">
  ### Бюджеты для пользователей и групп
</div>

Функции управления бюджетами теперь доступны всем клиентам Enterprise:

* Администраторы команд Enterprise могут устанавливать бюджеты использования по умолчанию для всех участников
* Администраторы могут устанавливать бюджеты для отдельных групп (например, Admins/Members и пользовательских групп)
* Скоро: администраторы смогут устанавливать индивидуальные бюджеты для отдельных пользователей
