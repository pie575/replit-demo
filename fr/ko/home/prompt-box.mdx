---

La zone de prompt est le point d’entrée de [Conversation](/fr/ko/chat/conversations). Utilisez-la pour décrire vos besoins, ajouter le contexte pertinent, choisir comment interagir avec Replit et préciser le résultat souhaité.

<Note>
  Les autorisations de l’espace de travail, les intégrations et la sécurité sont gérées en dehors de la zone de prompt. Celle-ci peut utiliser le contexte auquel vous avez accès.
</Note>

<div id="section">
  ## Demande ou description de tâche
</div>

Rédigez vos questions, instructions ou tâches en langage clair. Vous pouvez poursuivre dans la même Conversation pour préciser votre demande ou affiner les résultats.

Pour utiliser la zone de prompt, consultez [Démarrer une conversation](/fr/ko/home/start-a-conversation).

<div id="section-2">
  ## Ajouter le contexte pertinent
</div>

Fournissez à Replit les informations nécessaires à votre travail. Vous pouvez joindre des fichiers, faire référence à des outils connectés, demander à Replit d’effectuer une recherche sur le Web ou importer des contenus existants, comme un design Figma. L’accès aux services connectés dépend des paramètres et des autorisations de l’espace de travail.

* [Travailler avec des fichiers](/fr/ko/chat/upload-and-use-files)
* [Connecteurs](/fr/ko/features/integrations/overview)
* [Web Search](/fr/ko/features/agent/web-search)
* [Importer des designs Figma](/fr/ko/design/import-figma-designs-into-replit-design)

<div id="section-3">
  ## Choisissez votre mode d’interaction
</div>

Choisissez l’expérience adaptée à votre tâche. Les modes Agent modifient la façon dont Replit aborde votre tâche. Lorsqu’il est disponible, le Model selector vous permet de choisir directement un modèle plutôt qu’Auto. Le mode vocal vous permet d’exprimer votre demande oralement.

* [modes Agent](/fr/ko/chat/agent-modes)
* [Model selector](/fr/ko/chat/model-selector)
* [mode vocal](/fr/ko/chat/voice-mode)

<div id="section-4">
  ## Préciser le résultat souhaité
</div>

Décrivez le résultat que vous souhaitez obtenir : une réponse, une Routine récurrente, une application, une présentation, un design, une ressource, etc. Replit s’appuie sur ce résultat attendu pour orienter les tâches suivantes.

* [Découvrir les cas d’utilisation](/fr/ko/use-cases)
* [Créer votre première application](/fr/build-an-app)
* [Créer un design](/fr/create-a-design)
* [Créer une présentation](/fr/ko/features/artifact-types/slide-decks)
