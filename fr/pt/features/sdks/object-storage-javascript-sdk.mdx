Ce guide de référence présente la classe `Client` de la bibliothèque `object-storage` et fournit des exemples de code pour ses méthodes.

<div id="client">
  ## Client
</div>

La classe `Client` gère les interactions avec Replit App Storage. Elle propose des méthodes permettant d&#39;effectuer des opérations sur les fichiers d&#39;un bucket.

Pour importer la classe depuis la bibliothèque, ajoutez la ligne suivante à votre code JavaScript :

```javascript theme={null}
import { Client } from "@replit/object-storage";
```

Utilisez le code suivant pour créer une instance de `Client` qui interagit avec Replit Object Storage :

```javascript theme={null}
const client = new Client();
```

<div id="constructors">
  ## Constructors
</div>

<div id="copy">
  ### copy
</div>

* **copy**(`objectName`, `destObjectName`) : `Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

Copie un objet au sein d&#39;un même bucket.
Cette méthode écrase tout objet existant sur le chemin de destination.

**Paramètres**

| Nom              | Type     | Description                                       |
| :--------------- | :------- | :------------------------------------------------ |
| `objectName`     | `string` | Le chemin complet de l&#39;objet à copier.        |
| `destObjectName` | `string` | Le chemin complet vers lequel copier l&#39;objet. |

**Valeur de retour**

`Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;
