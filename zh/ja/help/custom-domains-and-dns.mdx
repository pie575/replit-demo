本页解答有关连接和排查自定义域名问题的常见问题。有关详细说明，请参阅[添加自定义域名](/zh/ja/build/add-custom-domain)和[自定义域名](/zh/ja/features/publishing/custom-domains)。

<AccordionGroup>
  <Accordion title="如何为 Replit 应用连接自定义域名？">
    如果您通过 Replit 购买了域名，DNS 记录会自动管理。请打开 **Publishing → Domains**，然后按照产品内的设置步骤操作。请参阅[购买域名](/zh/ja/build/domain-purchasing)。

    要连接在外部注册商处注册的域名：

    1. 打开项目并前往 **Publishing → Domains**。
    2. 选择 **Connect your own domain**，输入域名后继续。
    3. Replit 会显示 A 记录和 TXT 记录，请复制这两条记录。
    4. 在您的 DNS 提供商处添加这两条记录。
    5. 返回 Replit 并开始认证。

    重要注意事项：

    * SSL 需要同时配置 A 记录和 TXT 记录。不支持 Apex (根域) CNAME，请为根域名使用 A 记录。
    * 不支持通配符证书 (`*.example.com`) ，请分别连接每个子域名。
    * 在 Cloudflare 中，请将 A 记录设为 **DNS only** (灰色云朵) ，以免代理模式影响 SSL 设置。
    * DNS 更改最多可能需要 48 小时才能生效。

    如需了解更多，请参阅[自定义域名](/zh/ja/features/publishing/custom-domains)。
  </Accordion>

  <Accordion title="域名未通过认证或未预配 SSL 时，如何排查问题？">
    请按顺序检查以下步骤——大多数问题都由其中之一引起：

    1. **请等待 DNS 传播完成。** 更改最多可能需要 48 小时才能生效。请使用 DNS 查询工具检查记录是否已在全球范围内可见。
    2. **请删除 AAAA 记录。** 与 A 记录使用相同主机名的 IPv6 (AAAA) 记录可能会阻碍 SSL 配置。
    3. **请删除旧的或冲突的 A 记录。** 根域名的 A 记录中应仅保留指向 Replit 的记录。
    4. **请将 Cloudflare 设置为 DNS only。** 橙色云朵 (代理模式) 会妨碍 SSL 证书配置。
    5. **在 Publishing → Domains → Manage 中断开并重新连接域名**，以强制获取新证书，然后等待几分钟并刷新页面。
    6. **请检查 CAA 记录。** 如果存在 CAA 记录，Replit 会通过 Let&#39;s Encrypt 签发证书，因此至少应有一条记录允许 Let&#39;s Encrypt 作为证书颁发机构。

    这些步骤适用于在外部注册的域名。如果您是在 Replit 购买的域名，请[联系 Replit 支持](https://replit.com/support)。请参阅[自定义域名](/zh/ja/features/publishing/custom-domains)。
  </Accordion>

  <Accordion title="如何在自定义域名上设置 Clerk 认证？">
    使用自定义域名时，[Clerk 认证](/zh/ja/features/auth-and-identity/clerk-auth) 可能会遇到以下常见问题：

    * **“Clerk CNAME records required”警告。** 这是 Clerk 集成的要求，不会阻碍域名认证或 SSL。打开 **Publishing → Domains**，选择 **Manage**，找到认证 DNS 设置部分，然后将显示的每条 CNAME 记录准确添加到 DNS 提供商处。如果未显示该部分，请断开域名连接后再重新连接。
    * **之前使用 Clerk 后，域名一直卡在认证状态。** 如果该域名之前连接到其他 Clerk 应用，请先在 [Clerk 控制台](https://dashboard.clerk.com)中将其删除，然后在 Replit 中断开域名连接后再重新连接。
    * **迁移到自己的 Clerk 实例。** 从 Replit 管理的 Clerk 切换到自己的实例需要手动操作——请[联系 Replit 支持](https://replit.com/support)。请参阅[我可以使用自己的 Clerk 应用，而不是使用 Replit 管理的应用吗？](/zh/ja/features/auth-and-identity/clerk-auth#can-i-bring-my-own-clerk-app-instead-of-using-the-replit-managed-one)。

    如果问题仍未解决，请提供域名、项目名称以及已尝试的操作，然后[联系 Replit 支持](https://replit.com/support)。
  </Accordion>
