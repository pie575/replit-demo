仪表板可帮助用户根据数据做出决策。

你将使用一份公开 CSV 构建一个**全球发展探索器**，其中包含国家/地区层面的年份、人口、洲别、预期寿命和人均 GDP 数据。

<div id="what-youll-achieve">
  ## 您将达成的目标
</div>

完成本指南后，您将拥有：

* 一个基于真实公开 CSV 构建的全球发展探索器仪表板。
* 国家、人口、预期寿命和人均 GDP 的汇总指标。
* 展示发展状况如何随时间变化的图表和筛选器。
* 验证仪表板数值是否与源数据一致的方法。
* 可与利益相关者共享或发布的仪表板。

<div id="what-youll-learn">
  ## 你将学到什么
</div>

你将学会如何：

* 从要做的决策出发，而不是从图表类型出发。
* 让 Agent 根据公开 CSV 构建仪表板。
* 根据底层数据核对计算结果。
* 添加筛选器和洞察摘要。
* 判断仪表板何时需要登录、刷新、导出或连接数据。

<div id="who-this-is-for">
  ## 适用对象
</div>

如果您拥有客户、销售、产品、运营、研究或公共数据，并需要一个易于理解的仪表板，请使用本指南。

本指南适用于需要将原始数据转化为决策依据的分析师、运营人员、创始人、产品经理、教育工作者和团队。

<div id="define-the-decision">
  ## 明确决策目标
</div>

开始构建前，先明确仪表板需要支持的决策。

对于全球发展数据集：

* **问题**：哪些地区的预期寿命和人均 GDP 随时间推移有所提升？
* **受众**：教育、研究、战略或非营利团队。
* **有用指标**：国家数量、年份范围、最新的预期寿命中位数、所代表的总人口，以及人均 GDP 中位数。
* **有用筛选器**：大洲、国家和年份范围。

如果无法明确这一决策，仪表板就会沦为一组图表，而非实用工具。

<div id="build-from-a-public-csv">
  ## 基于公开 CSV 构建
</div>

使用包含有意义字段且有足够数据行可供探索的正向公开数据集。

数据集：[Gapminder 全球发展 CSV](https://raw.githubusercontent.com/plotly/datasets/master/gapminderDataFiveYear.csv)

让 Agent 基于该 CSV 构建仪表板：

<AiPrompt>
  基于此公开 CSV 构建一个全球发展探索器仪表板：<br />
  [https://raw.githubusercontent.com/plotly/datasets/master/gapminderDataFiveYear.csv](https://raw.githubusercontent.com/plotly/datasets/master/gapminderDataFiveYear.csv)<br />
  该仪表板应帮助教育或研究团队了解 1952 年至 2007 年间各国和各大洲的预期寿命、人口和人均 GDP 的变化。<br />
  包含展示国家总数、年份范围、最新预期寿命中位数、覆盖的总人口以及最新人均 GDP 中位数的摘要卡片。<br />
  添加按大洲展示预期寿命随时间变化的折线图。<br />
  添加气泡图，其中 x 轴为人均 GDP，y 轴为预期寿命，气泡大小表示人口，颜色表示大洲。<br />
  添加柱状图，展示数据集中从最早年份到最新年份预期寿命增幅最大的国家。<br />
  添加大洲、国家和年份范围筛选器。<br />
  包含简短的洞察摘要，说明最显著的趋势，以及改善幅度最大的地区或国家。<br />
  展示关键指标的计算方法，以便我核验数据。<br />
  使仪表板美观、响应迅速，并且在桌面端和移动端都易于阅读。
</AiPrompt>

<div id="check-your-work">
  ## 检查结果
</div>

打开 Preview，并在分享前核对仪表板。

检查以下内容：

* 国家总数是否与 CSV 中的唯一国家数量一致。
* 年份范围是否为 1952 至 2007。
* 最新的预期寿命中位数是否采用数据集中的最新年份。
* 人口总数是否基于筛选后的国家和年份。
* 筛选器是否会更新摘要卡片和图表。
* 气泡图是否正确使用人均 GDP、预期寿命、人口和大洲数据。
* 洞察摘要是否与图表展示的内容一致。
* 仪表板是否能在手机屏幕尺寸下正常运行。

如果某个数字与预期不符，请让 Agent 展示计算过程。

<AiPrompt>
  最新的预期寿命中位数与我的预期不符。<br />
  请展示你如何根据 CSV 计算得出该数值。<br />
  检查你是否只使用了筛选后数据中最新年份的行。<br />
  如有需要，请更新计算方式，并告诉我如何验证。
</AiPrompt>

<div id="add-filters-and-exports">
  ## 添加筛选和导出功能
</div>

第一个仪表板运行后，请让 Agent 添加帮助用户探索数据的交互功能。

<AiPrompt>
  为全球进展仪表板添加探索面板。<br />
  让我可以按大洲、国家和年份范围进行筛选。<br />
  添加一个按钮，将筛选后的图表数据导出为 CSV。<br />
  让摘要卡片和洞察摘要与筛选条件保持同步。
</AiPrompt>

仪表板还支持导出为 PDF、将图表导出为 CSV、刷新、自动刷新、浅色/深色模式和分析摘要。有关概念概览，请参阅 [数据可视化](/zh/features/artifact-types/data-apps)。

<div id="use-connected-data-when-needed">
  ## 需要时使用已连接的数据
</div>

学习或制作原型时，可使用公开的 CSV。需要让仪表板保持最新时，请使用已连接的数据源。

你可以将仪表板连接到：

* Replit App 数据库。
* BigQuery、Databricks 或 Snowflake 等数据仓库连接器。
* Segment、Amplitude 或 Hex 等分析工具。
* 外部 API。

对于数据仓库数据，请让 Agent 说明所使用的字段和查询。

<AiPrompt>
  使用我们的数据仓库连接器创建增长仪表板。<br />
  确定所需的客户、产品使用情况、账单和留存字段。<br />
  构建展示活跃客户随时间变化、按细分市场划分的账户增长以及按套餐划分的扩展收入的图表。<br />
  说明你使用的字段和计算方法，以便我验证仪表板。
</AiPrompt>

有关设置和可用性详情，请参阅 [Data Connectors](/zh/connectors/warehouses/overview)。

<div id="share-the-dashboard">
  ## 分享仪表板
</div>

确认数据可靠后，再分享仪表板。

如果仪表板使用客户或企业的私密数据，请先设置访问控制，再广泛分享。对于公开数据或示例数据，你可以直接 Publish 并分享 URL。

请审核者回答：

> 查看全球进展仪表板，并告诉我你会优先突出哪个地区或国家的情况，以及原因。

<div id="youre-done-when">
  ## 满足以下条件即表示已完成
</div>

* 仪表板能加载公开的 CSV。
* 摘要卡片和图表能够解答进度相关的问题。
* 你已手动核实至少一项关键指标。
* 筛选器能正确更新仪表板。
* 洞察摘要与数据一致。
* 你已确定仪表板是应保持公开、要求登录，还是连接到实时数据。

<div id="need-further-help">
  ## 还需要进一步帮助？
</div>

* **数字与预期不符：**让 Agent 显示查询、公式或转换方式。
* **CSV 不可用：**检查 URL、网络访问和 CSV 标头。
* **筛选器未更新图表：**让 Agent 将筛选器同时关联到摘要卡片和图表数据。
* **仪表板运行缓慢：**让 Agent 汇总数据、添加筛选器，或减少启动时加载的行数。
* **仪表板使用私有数据：**在广泛分享前添加登录功能。
