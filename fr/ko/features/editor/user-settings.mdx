L’outil Paramètres utilisateur de Project Editor vous permet de personnaliser l’apparence, le comportement et les raccourcis clavier de votre compte.

</Frame>

<div id="section">
  ## Fonctionnalités
</div>

Vous pouvez personnaliser votre expérience de création d’apps Replit grâce aux catégories de paramètres suivantes.

* **Personnalisation du thème** : choisissez entre les thèmes clair et sombre de Project Editor
* **Intelligence du code** : configurez des fonctionnalités basées sur l’IA pour améliorer votre expérience de création d’apps
* **Préférences de l’éditeur** : ajustez le comportement et l’apparence de l’éditeur de fichiers
* **Paramètres de notification** : gérez vos préférences de notification
* **Options d’accessibilité** : améliorez l’utilisation de Replit pour les personnes ayant des besoins spécifiques
* **Raccourcis clavier** : configurez des combinaisons de touches pour effectuer des tâches courantes et naviguer dans l’interface graphique

<div id="appearance">
  ### Apparence
</div>

Personnalisez les paramètres d’apparence suivants du Project Editor.

* **Choix du thème** : choisissez parmi les thèmes prédéfinis clairs et sombres, les <a href="https://replit.com/themes" target="_blank">thèmes de la communauté</a> ou votre propre thème personnalisé.
* **Thème personnalisé** : créez une palette de couleurs personnalisée avec l’éditeur [Themes](/fr/ko/features/editor/themes).

<div id="section-3">
  ### Paramètres de l’éditeur de fichiers
</div>

Contrôlez l’apparence et le comportement de l’éditeur de fichiers à l’aide des paramètres suivants.

* **Taille de police** : ajustez la taille du texte pour améliorer la lisibilité
* **Fermeture automatique des parenthèses** : insérez automatiquement une parenthèse fermante lorsque vous saisissez une parenthèse ouvrante
* **Détection de l’indentation** : détectez automatiquement les paramètres d’indentation à l’ouverture d’un fichier
* **Formatage de l’indentation du texte collé** : reformatez le code collé pour respecter l’indentation appropriée
* **Caractères d’indentation** : choisissez des espaces ou des tabulations pour indenter le code
* **Taille d’indentation** : définissez le nombre de colonnes pour chaque niveau d’indentation
* **Retour à la ligne** : configurez le comportement des retours à la ligne
* **Minicarte** : affichez un aperçu navigable du code dans la barre latérale
* **Touche de modification pour la sélection multiple** : définissez la touche de modification à utiliser pour sélectionner plusieurs fichiers
* **État Git dans l’arborescence des fichiers** : affichez les indicateurs d’état Git dans l’arborescence des fichiers

<div id="section-4">
  ### Intelligence du code
</div>

Configurez les outils basés sur l’IA avec les paramètres suivants.

* **Jetons sémantiques :** utilisez la coloration syntaxique enrichie par le serveur de langage
* **Complétion de code par IA :** affichez des suggestions de code en ligne pendant la saisie
* **Accepter les suggestions avec des caractères de validation :** acceptez automatiquement les suggestions de code lorsque vous saisissez certains caractères

<div id="shell-preview">
  ### Paramètres de Shell et Preview
</div>

Personnalisez le comportement des outils Shell et Preview.

* **Alerte sonore de Shell :** émettre un son lorsqu’un problème survient dans Shell
* **Preview automatique :** ouvrir automatiquement l’onglet Preview lorsque le serveur est disponible
* **Transfert automatique des ports ouverts :** configurer la façon de traiter les ports nouvellement détectés

<div id="section-5">
  ### Notifications
</div>

Gérez les paramètres de notification suivants.

* **Notifications audio de l’Agent** : jouer un son lorsque l’Agent demande un retour
* **Notifications push de l’Agent** : recevoir une notification push sur mobile lorsque l’Agent demande un retour

<div id="section-6">
  #### Alertes de production
</div>

Les **Production Alerts** constituent un paramètre distinct de notifications par e-mail qui vous tient informé de l’état de vos applications publiées. Elles fonctionnent indépendamment des e-mails de produit et de marketing, afin que vous ne receviez que les informations importantes, sans notifications inutiles.

Lorsque vous activez les **Production Alerts**, vous recevez des e-mails concernant :

* **Incidents de disponibilité** : vous êtes averti lorsque votre application publiée est indisponible ou rencontre des difficultés à rester en ligne.
* **Vulnérabilités de sécurité** : vous recevez des alertes concernant les faiblesses découvertes dans les logiciels dont dépend votre application, afin de pouvoir les corriger avant qu’elles ne causent des problèmes.
* **Mises à jour de modèles** : vous êtes averti lorsque le modèle de langage utilisé par votre application change ou nécessite votre attention.

<Frame>
  <img src="/assets/mirror/production-alerts-highlight-bb76079f20fd.png" alt="La section Production Alerts dans les paramètres de notification, avec un rectangle rouge mettant en évidence le bouton bascule des e-mails d’alerte de production et le menu déroulant de gravité des alertes de sécurité" width="2400" height="1364" data-path="images/workspace/production-alerts-highlight.png" />
</Frame>

Pour trouver ce paramètre :

1. Ouvrez **Settings** dans le menu de votre compte.
2. Sélectionnez l’onglet **Personalization**.
3. Faites défiler jusqu’à la section **Email Notifications** et recherchez **Production Alerts**.

Si votre application publiée utilise un modèle de langage obsolète, Replit prépare une tâche préremplie pour la mettre à niveau vers un modèle pris en charge. Vous recevrez un e-mail contenant un lien vers cette tâche et pourrez effectuer la mise à niveau après une seule vérification.

<div id="section-7">
  ### Accessibilité
</div>

Vous pouvez personnaliser les paramètres d’accessibilité suivants.

* **Sortie de terminal accessible** : active la compatibilité avec les lecteurs d’écran pour les outils Shell et Console

<div id="section-8">
  ### Raccourcis clavier
</div>

Pour accéder aux paramètres des raccourcis clavier, sélectionnez l’onglet **Raccourcis clavier** dans l’outil Paramètres utilisateur.

Vous pouvez rechercher des combinaisons de touches de l’une des façons suivantes :

* **Nom** : saisissez le nom ou la description du raccourci clavier dans le champ de recherche
* **Combinaison de touches** : sélectionnez <img class="icon-svg" src="/assets/mirror/keyboard-7ba19771b671.svg" alt="icône de clavier" width="16" height="16" data-path="images/icons/keyboard.svg" /> et saisissez la combinaison de touches

Gérez les raccourcis comme suit :

* **Ajouter** : sélectionnez **Ajouter un raccourci**
* **Mettre à jour** : sélectionnez <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="icône de crayon" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> l’icône en forme de crayon
* **Supprimer** : sélectionnez <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="icône de corbeille" width="16" height="16" data-path="images/icons/trash-icon.svg" /> l’icône de corbeille
