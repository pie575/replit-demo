<div id="enterprise-sso">
  ### 在线购买 Enterprise 并自动完成 SSO 设置
</div>

现在你可以直接在[价格页面](https://replit.com/pricing)购买 Replit Enterprise 套餐，无需与销售代表通话。付款后，产品内的向导会全程引导你完成单点登录设置。只需将身份提供方的值粘贴到 SAML 表单中，Replit 就会自动预配 SSO 连接。无需等待邮件往返，团队几分钟内即可用上 Enterprise。

<div id="enterprise-2">
  ### Enterprise 工作区的按用户支出限额
</div>

Enterprise 管理员现在可以为不同的工作区成员分别设置 Agent 支出限额。打开[使用量页面](https://replit.com/usage)中的 **Agent 用户**表格，在任意一行选择编辑图标，然后选择新的限额。按用户设置的限额优先于群组和工作区默认值。如果你想为高级用户放宽限额，或在不影响工作区其他成员的前提下限制某位成员的支出，此功能会非常实用。

<div id="canvas-png">
  ### 将 Canvas 画框导出为 PNG
</div>

在 Canvas 中右键点击 artifact 或设计 frame，选择**导出** &gt; **PNG**，即可下载当前预览的快照。无需手动截图，即可快速将视觉素材分享到文档、聊天中，或交由团队成员审阅。导出的图像与导出时 Canvas 中显示的 frame 完全一致。

<div id="9">
  ### 开箱即用的 9 个全新连接器
</div>

现在有 9 个连接器已内置默认凭证，一键即可连接到 Agent，无需事先自行配置 OAuth 应用。打开项目的**集成**面板，选择服务，然后授权连接即可。

* **Airtable**：读写 base、表格和记录。
* **GitLab**：访问项目、议题、合并请求和流水线。
* **Basecamp**：读取和管理项目、待办事项、消息和日程。
* **Productboard**：读取和更新功能、版本发布和客户反馈。
* **Teamwork**：读取和管理项目、任务和工时记录。
* **Twitch**：读取直播、频道和观众活动。
* **Square**：收款，并管理订单、客户和库存。
* **Intercom**：读写会话、联系人和支持工作流。
* **Mailchimp**：读取和管理受众、营销活动和邮件营销数据。

进一步了解[连接器](/zh/replitai/integrations#available-connectors)。

<div id="4-mcp">
  ### 目录新增 4 个 MCP 服务器
</div>

[MCP 目录](/zh/replitai/mcp/directory)新增了 4 个托管的 Model Context Protocol 服务器。打开**集成**面板，在 **Replit Agent 的 MCP 服务器**下找到相应服务器，然后选择**添加到 Replit** 即可连接。

* **Twilio**：检索 Twilio 文档以及 1,800 多个用于语音、短信、邮件和身份验证的 API 端点。
* **Mixpanel**：查询 Mixpanel 事件、漏斗、留存和仪表板数据。
* **Lazyweb**：搜索 25.7 万多个真实应用界面，用作 UI 参考和设计调研素材。
* **Doola**：注册美国 LLC，并管理公司设立、记账和税务事宜。

完整列表请查看 [MCP 目录](/zh/replitai/mcp/directory)。
