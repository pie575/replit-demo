O Console permite que você monitore e revise os logs impressos pelo seu Replit App em execução em tempo real.
Você pode usar informações de execuções atuais e anteriores para entender o comportamento do seu aplicativo,
solucionar erros e otimizar o desempenho.

<Tip>
  Ao depurar usando o Agent, inclua logs do console no seu prompt para fornecer contexto.
</Tip>

## Recursos

O Console fornece as seguintes ferramentas para ajudá-lo a entender o comportamento do seu aplicativo:

* **Registro em tempo real**: Ver a saída do seu aplicativo à medida que ela acontece
* **Assistência de IA**: Receber sugestões para corrigir erros relatados nos logs
* **Histórico de execuções**: Mostrar logs de execuções anteriores para rastrear alterações

## Uso

Você pode acessar a ferramenta Console diretamente no seu Project Editor.

<Accordion title="Como acessar o Console">
  No **dock de ferramentas** à esquerda:

  1. Selecione <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Ícone Todas as ferramentas" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools** para ver uma lista de ferramentas do Project Editor.
  2. Selecione <img class="icon-svg" src="/assets/mirror/console-8a41ac90789c.svg" alt="Ícone do Console" width="16" height="16" data-path="images/icons/console.svg" /> **Console**.

  Na **barra de pesquisa**:

  1. Selecione a <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="ícone de lupa" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> lupa no topo para abrir a ferramenta de pesquisa
  2. Digite "Console" para localizar a ferramenta e selecione-a nos resultados.
</Accordion>

Cada vez que você usa o botão **Run** no seu Replit App, o Console exibe uma nova entrada que inclui as seguintes informações:

* O Comando que executou seu código
* Informações de timestamp
* Logs de saída padrão e de erro

A captura de tela a seguir mostra o comando `npm run dev` usado para iniciar o aplicativo e mensagens de log da execução:

### Depuração com IA

Quando você encontrar erros ou outras informações nos logs que deseja entender, selecione o
botão **Ask AI** no topo da entrada. Isso abre automaticamente a aba **Agent** e
envia o conteúdo do log para análise.

### Comandos de entrada de log

O Console fornece as seguintes ferramentas para gerenciar seus logs:

* **Show Only Latest**: Alterne este controle para a posição **on** para exibir apenas a execução mais recente.
* **Recolher entrada**: Selecione a <img class="icon-svg" src="/assets/mirror/down-arrow-9c1cf9fd152e.svg" alt="ícone de seta para baixo" height="16" width="16" data-path="images/icons/down-arrow.svg" /> seta para baixo à esquerda do nome do comando para ocultar os logs.
* **Limpar execuções anteriores**: Selecione isto para excluir os logs de execuções anteriores. Esta ação é irreversível.

### Disponibilidade de rede

Você pode controlar a disponibilidade online da versão de desenvolvimento do seu aplicativo.

Para parar de atender requisições para a URL de desenvolvimento, selecione o ícone de <img class="icon-svg" src="/assets/mirror/network-off-5bdca8a4fe4e.svg" alt="ícone de rede desativada" height="16" width="16" data-path="images/icons/network-off.svg" /> globo com barra
no lado direito da linha de informações de rede.

Para ativá-la, selecione o ícone de <img class="icon-svg" src="/assets/mirror/network-on-15be2e5fb4f5.svg" alt="ícone de rede ativada" height="16" width="16" data-path="images/icons/network-on.svg" /> globo.

Para ver sua URL de desenvolvimento, selecione o texto `{...}.replit.dev` na barra de localização.

  <img src="/assets/mirror/preview-dev-url-b36770b33769.png" alt="Localização da URL de desenvolvimento do Preview" width="1222" height="824" data-path="images/workspace/preview-dev-url.png" />

<Note>
  Seu aplicativo permanece acessível na ferramenta Preview mesmo quando configurado para parar de atender requisições para a URL de desenvolvimento.

### Parar um comando de Workflow

Você pode parar um comando de Workflow em execução a partir da ferramenta Console do Project Editor.

Selecione o botão quadrado no lado direito da linha que contém o comando de execução do seu Replit App para encerrá-lo.

Para reiniciar seu aplicativo, use o botão **Run** do Workflow no topo do Project Editor.
