title: "使用 Canvas 创建设计"
description: "在 Canvas 中探索不同的设计变体，选定一个方向并应用到你的应用中。"
---

⏰ *预计用时：5 分钟* · 承接[创建你的第一个应用](/zh/pt/getting-started/quickstarts/ask-ai)

**Canvas** 是一个可视化空间，你可以在动手创建应用之前先探索多种设计方向：生成设计原型、并排对比，然后应用你最满意的那一个。

<div id="antes-de-comear">
  ## 开始之前
</div>

你需要在 Replit 上有一个现成的应用——可以是按[创建你的第一个应用](/zh/pt/getting-started/quickstarts/ask-ai)快速入门指南做的，也可以是任意项目。

<Tip>你也可以从零开始——新建一个项目，先把你的想法描述给 Agent 即可。</Tip>

<div id="crie-o-design-do-seu-aplicativo">
  ## 设计你的应用
</div>

<Steps>
  <Step title="探索设计变体">
    在项目编辑器中打开 **Canvas** 标签页，然后点击**重新构想**。下拉菜单会提供一些快捷提示词，帮助你探索不同方向。
    选择“尝试不同布局”，Agent 就会在 Canvas 上生成多个设计原型。

    <Frame>
      <video autoPlay muted loop playsInline src="/assets/mirror/try_different_layouts-with_canvas-7e77d972c8f5.mp4" />
    </Frame>

    以下是所有可用选项：

    * 探索不同方案
    * 尝试不同布局
    * 探索不同风格
    * 类似这个，但更好
    * 针对易用性优化
    * 展示与此相反的方案
    * 给我惊喜

    或者，你也可以用自己的话让 Agent 生成变体：

    ```
    在 Canvas 上给我展示一个深色主题、一个极简主题和一个多彩主题
    ```

    <Frame>
      <img src="/assets/mirror/quickstart_design_canvas_variations-636d281499e5.png" alt="Canvas 上并排展示的多个设计变体" width="2538" height="1428" data-path="images/getting-started/quickstart_design_canvas_variations.png" />
    </Frame>
  </Step>

  <Step title="选定一个方向">
    浏览这些变体，选出最符合你构想的那一个。在确定之前，你可以让 Agent 对某个具体变体进行优化：

    ```
    我喜欢第二个，但把页头做得大一些
    ```
  </Step>

  <Step title="应用到你的应用">
    对某个设计满意后，让 Agent 把它应用上去：

    ```
    把这个设计应用到我的应用上
    ```

    Agent 会更新你的应用代码，使其与所选设计保持一致。查看**预览**标签页即可看到效果。
  </Step>

  <Step title="发布更新后的应用（可选）">
    在项目编辑器中点击 **Publish**，让新设计上线。你现有的 URL 保持不变，访问者会立即看到更新后的版本。

    <Frame>
      <video autoPlay muted loop playsInline src="/assets/mirror/quickstart-publish-app-ae59052ca92d.mp4" />
    </Frame>

    在[发布你的应用](/zh/pt/getting-started/quickstarts/publish)中了解更多关于部署的内容。
  </Step>
</Steps>
