借助 Replit 灵活的存储方案，你可以快速为应用添加最合适的数据存储。对于有以下需求的应用，你可以使用 Replit 的数据库或对象存储，Agent 还能自动完成这两种方案的配置与集成：

* 需要保存玩家信息 (如游戏进度或最高分) 的游戏
* 需要管理媒体文件的内容平台

<div id="quais-so-as-opes-de-armazenamento-e-banco-de-dados-do-replit">
  ## Replit 提供哪些存储和数据库选项
</div>

Replit 提供以下数据存储选项：

* **数据库**：存储结构化数据，例如用户资料、游戏得分和产品目录。
  你可以按属性以及数据点之间的关系来存储或检索数据。

* **App Storage**：存储非结构化数据，例如图片、视频和文档。
  你可以存储和检索大文件及二进制数据。

<div id="comparao-entre-app-storage-e-banco-de-dados">
  ### App Storage 与数据库对比
</div>

|             | 数据库                     | App Storage           |
| ----------- | :---------------------- | :-------------------- |
| **适合的数据格式** | 有关联关系的结构化数据             | 大文件 (图片、视频、文档)        |
| **数据模型**    | 表、行、列                   | 存储桶、文件                |
| **查询语言**    | SQL                     | REST API              |
| **客户端**     | 兼容 PostgreSQL 的客户端和 ORM | Replit SDK 和 GCS 客户端库 |
| **计费模式**    | 按计算时间和存储空间计费            | 按带宽和存储空间计费            |
