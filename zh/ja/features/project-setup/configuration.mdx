Replit 应用由两个文件 (`.replit` 和 `replit.nix`) 配置。这些文件会影响 Replit 应用的行为，包括代码运行方式、开发工具和编程语言。

这些配置文件默认处于隐藏状态。请在文件树菜单中选择“Show hidden files”，以在 Replit 应用中显示它们。

<div id="replitnix">
  ## `replit.nix` 文件
</div>

Replit 使用 `Nix` 管理软件包和环境。`replit.nix` 文件可用于：

**指定系统依赖项：** 精确定义 Replit 应用所需的、由 Nix 包管理器管理的软件包。

**创建可复现的环境：** 确保开发环境的一致性和可复现性，非常适合协作项目及在多个系统上进行测试。

您可以通过 `Dependencies` 工具以可视化方式管理 Nix 软件包。有关详细信息，请参阅[系统依赖项](/zh/ja/features/project-setup/dependency-management#system-dependencies)指南。

要在 `replit.nix` 文件中配置软件包，您可以在 `deps` 数组中使用 `pkgs.` 前缀列出 [Nix 软件包](https://search.nixos.org/packages)。重新加载 Shell 后，变更将生效。

```nix theme={null}
{ pkgs }: {
  deps = [
    pkgs.nodejs-19_x
    pkgs.nodePackages.typescript-language-server
    pkgs.yarn
    pkgs.replitPackages.jest
  ];
}
```

<div id="replit">
  ## `.replit` 文件
</div>

`.replit` 文件用于控制 Replit 应用的行为，采用 `toml`[配置格式](https://toml.io/en/)。以下是主要可配置项：

**运行命令：** 指定点击 Run 按钮时执行的命令。每个模板都提供默认运行命令，让你可以立即运行代码。对于更复杂的应用，请使用 [Workflows](/zh/ja/features/workspace-tools/workflows)。

**Language Server Protocol (LSP)：** 提供自动补全、代码导航、代码高亮、实时检查和错误提示等功能。

**环境变量：** 设置和管理应用正常运行所需的环境变量。

**依赖项和软件包：** 通过 `.replit` 文件直接管理软件包的安装和配置，确保 Replit 应用启动时已准备好所有必需工具。你还可以通过 `Dependencies` 工具以可视化方式管理依赖项。有关详情，请参阅[系统模块](/zh/ja/features/project-setup/dependency-management#advanced-configuration)指南。

Python 应用的默认 `.replit` 文件如下所示：

```toml theme={null}
entrypoint = "main.py"
modules = ["python-3.10:v18-20230807-322e88b"]

[nix]
channel = "stable-23_05"

[unitTest]
language = "python3"

[gitHubImport]
requiredFiles = [".replit", "replit.nix"]

[deployment]
run = ["python3", "main.py"]
deploymentTarget = "cloudrun"
```

下表概述了`.replit`文件中的各项配置，并说明其对 Replit 应用环境的影响。

| **配置键**                                         | **值/示例**                               | **说明**                                                                                                  |
| ----------------------------------------------- | -------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| <a name="entrypoint" />`entrypoint`             | `main.py`                              | 指定打开编辑器时默认运行和显示的主文件。你可以根据应用更改文件名。                                                                       |
| <a name="modules" />`modules`                   | `["python-3.10:v18-20230807-322e88b"]` | 定义 Replit 支持的编程语言及其他主要依赖项的特定版本。                                                                         |
| <a name="nix" />`[nix]`                         |                                        | 指定 Nix 软件包管理器的使用设置，该管理器用于管理系统依赖项。有关详细信息，请参阅[依赖项管理](/zh/ja/features/project-setup/dependency-management)文档。 |
| <a name="channel" />`channel`                   | `stable-23_05`                         | 指定要使用的 Nix 通道，影响可用系统依赖项的版本。                                                                             |
| <a name="packages" />`packages`                 | `["cowsay", "htop"]`                   | 指定要安装的 Nix 软件包。你也可以使用`replit.nix`进行更精细的控制。                                                              |
| <a name="unitTest" />`[unitTest]`               |                                        | 配置与 Replit 应用中单元测试相关的设置。                                                                                |
| <a name="language" />`language`                 | `python3`                              | 指定用于单元测试的语言，表示测试将使用 Python 3。                                                                           |
| <a name="gitHubImport" />`[gitHubImport]`       |                                        | 配置从 GitHub 导入项目的方式，尤其是指定必须包含的文件。                                                                        |
| <a name="requiredFiles" />`requiredFiles`       | `[".replit", "replit.nix"]`            | 列出导入时必须存在的文件，以确保项目正常运行。                                                                                 |
| <a name="deployment" />`[deployment]`           |                                        | 包含将应用从 Replit 应用部署到线上环境的配置。                                                                             |
| <a name="run" />`run`                           | `["python3", "main.py"]`               | 部署期间用于启动应用而执行的命令。                                                                                       |
| <a name="deploymentTarget" />`deploymentTarget` | `cloudrun`                             | 指定托管应用的部署目标平台。                                                                                          |

了解`.replit`文件的默认设置后，请在下一节了解如何配置 Replit 应用的基本和高级设置。

<div id="section">
  ## 基本设置配置
</div>

<div id="section-2">
  ### 入口文件
</div>

这是项目的主文件。如果未定义 `run` 属性，运行时将执行 `entrypoint` 指定的文件。

```toml theme={null}
entrypoint = "<file-name>.py"
```

<div id="run">
  ### `Run`命令
</div>

`.replit`文件中的`run`属性是一项关键配置，用于指定在 Replit 环境中点击`Run`按钮时最先执行的命令，或一组命令。`Run`命令可以指定为表示待执行命令的字符串，也可以指定为表示命令及其参数的字符串数组。

配置`Run`命令的常见方式：

* **单个命令：**
  此示例说明如何传递可直接在 Replit 应用中执行的单个命令。使用此配置时，点击`Run`按钮会在`Console`窗格中显示问候语：
  **示例：** `run = "echo 'Hello, Replit!'"`

* **显式参数：**
  在某些情况下，为避免受到引号或 shell 插值规则解析的影响，使用更明确的写法会更有帮助。您可以通过分离参数来改写上述示例。
  由于问候语被明确作为`echo`的第一个且唯一的参数传递，因此无需使用`'`和`"`：
  **示例：** `run = ["echo", "Hello, Replit!"]`

* **多个命令：**
  此示例说明如何同时运行多个进程，例如前端和后端。在开发 Python 后端和 TypeScript 前端时，如果每个服务器绑定到不同的端口，这种方式会很有用：
  **示例：** `run = "python -m app & npm run start & wait"`

<div id="section-3">
  #### 进程管理
</div>

你可以使用 `&` 同时运行多个命令，但若想更清晰地区分不同服务的日志，可能需要更好的使用体验。你可以[添加系统依赖项](/zh/ja/features/project-setup/dependency-management#system-dependencies)，并使用 [`process-compose`](https://github.com/F1bonacc1/process-compose) 等工具更好地编排多个进程。

<div id="build">
  #### `Build`阶段
</div>

对于某些语言和运行时，在运行代码前需要经过单独的编译阶段。这适用于 TypeScript、Golang 和 Java 等编译型语言，也可以通过参数在下一次运行前重置环境、数据和配置。

* **编译：**
  对于 TypeScript 仓库，可能需要在运行代码前执行`tsc`。
  **示例：**

```toml theme={null}
build = "tsc app.ts"
run = "node app.js"
```

<div id="section-4">
  #### 设置环境变量
</div>

如需在运行前为服务提供环境变量，可将 `run` 属性扩展为一个[表](https://toml.io/en/v1.0.0#table)。

这项改动较为复杂，可能需要调整 `.replit` 文件中 `run = "..."` 属性的位置。

以下差异示例展示了如何在 `[run]` 的 `args` 中指定命令，并在 `[run.env]` 中设置变量 `NAME`：

```diff theme={null}
-run = ["bash", "-c", "echo \"Hello, $NAME!\""]

 modules = ["nodejs-20"]

 hidden = [".pythonlibs"]

+# 我们需要将新的 [run] 移到所有不以 `[` 开头的
+# 顶层属性之后！
+[run]
+args = ["bash", "-c", "echo \"Hello, $NAME!\""]
+
+[run.env]
+NAME="Replit"

 [nix]
 channel = "stable-23_11"
```

<div id="section-5">
  #### 交互性
</div>

交互式程序也可以通过`Run`按钮启动，这样可以区分程序运行所在的终端和开发环境。
请看以下计数脚本：

**示例**

```toml theme={null}
[run]
args = ["bash", "-c", """
count=0
while read -p "$PROMPT" -r next && [ -n "$next" ]; do
    count=$((count+next))
done
echo "The numbers you entered sum to $count!"
"""]

[run.env]
PROMPT = "Next number ([Enter] to end): "
```

<div id="section-6">
  ## 高级配置选项
</div>

了解 Replit 应用提供的高级配置选项。你可以自定义开发环境、管理运行命令、集成语言服务以及处理依赖项。

| **配置**     | **键**                               | **值/示例**                                    | **说明**                            |
| ---------- | ----------------------------------- | ------------------------------------------- | --------------------------------- |
| onBoot     | <a name="onBoot" />`onBoot`         | `onBoot = "npm install"`                    | Replit 应用启动时执行的命令。                |
| compile    | <a name="compile" />`compile`       |  (无默认示例)                                    | 在`run`命令之前执行的命令。用于 C++ 等编译型语言。    |
| language   | <a name="language" />`language`     | `language = "javascript"`                   | 指定从 GitHub 导入或创建 Replit 应用时使用的语言。 |
| entrypoint | <a name="entrypoint" />`entrypoint` | `entrypoint = "index.js"`                   | 打开编辑器时默认运行和显示的主文件。                |
| hidden     | <a name="hidden" />`hidden`         | `hidden = [".config", "package-lock.json"]` | 默认在侧边文件树中隐藏的文件或文件夹。               |
| audio      | <a name="audio" />`audio`           | `audio = true`                              | 设置为`true`时启用系统级音频。                |

<div id="section-7">
  ### 系统级音频注意事项
</div>

如果在`.replit`文件中设置`audio = true`，可能需要重启开发环境。在 Mac 上按`Cmd+K`或在 Windows 上按`Ctrl+K`打开命令面板，然后搜索并选择**Restart compute**。

运行图形应用程序时，`Output`窗格右下角会显示一个带复选框的耳机图标。
受浏览器限制，每次刷新后都需要重新启用它。

```toml theme={null}
# 请确保此项位于 `.replit` 文件顶部，且不在任何以 `[` 括起的区段内
audio = true
```

<div id="section-8">
  ## packager 配置
</div>

| **设置**      | **键**                                             | **值/示例**                                      | **说明**                       |
| ----------- | ------------------------------------------------- | --------------------------------------------- | ---------------------------- |
| packager    | <a name="language" />`language`                   | `packager.language = "python3"`               | 用于软件包操作的语言。                  |
| packager 功能 | <a name="guessImports" />`guessImports`           | `packager.features.guessImports = true`       | 在运行 Replit 应用前，自动推测需要安装的软件包。 |
| packager 功能 | <a name="packageSearch" />`packageSearch`         | `packager.features.packageSearch = true`      | 设为 `true` 可启用 packager 支持。   |
| packager 功能 | <a name="enabledForHosting" />`enabledForHosting` | `packager.features.enabledForHosting = false` | 设置托管 Replit 应用时是否需要运行软件包安装。  |
| packager    | <a name="afterInstall" />`afterInstall`           | `afterInstall = "echo 'package installed'"`   | 通过 packager 安装新软件包后运行的命令。    |
| packager    | <a name="ignoredPaths" />`ignoredPaths`           | `ignoredPaths = [".git"]`                     | 推测软件包时要忽略的路径。                |
| packager    | <a name="ignoredPackages" />`ignoredPackages`     | `ignoredPackages = ["twitter", "discord"]`    | 安装时不尝试推测软件包的模块。              |

<div id="replit-2">
  ### packager 的`.replit`配置示例
</div>

```toml theme={null}
# 指定 Replit App 的语言
packager.language = "python3"

# 启用自动软件包管理功能
[packager.features]
guessImports = true
packageSearch = true
enabledForHosting = false

# 每次安装软件包后要运行的命令
packager.afterInstall = "echo 'Package installed successfully'"

# 指定软件包管理器应忽略的路径和软件包
packager.ignoredPaths = [".git", "node_modules"]
packager.ignoredPackages = ["twitter", "discord"]

# 其他部署设置
[deployment]
run = ["python3", "app.py"]
```

<div id="section-9">
  ## 部署设置
</div>

| **设置**     | **键**                                 | **值/示例**                             | **说明**                         |
| ---------- | ------------------------------------- | ------------------------------------ | ------------------------------ |
| deployment | <a name="run" />`run`                 | `deployment.run = "npm start"`       | 部署容器启动时执行的命令。                  |
| deployment | <a name="build" />`build`             | `deployment.build = "npm run build"` | 部署前执行的命令。                      |
| deployment | <a name="ignorePorts" />`ignorePorts` | `deployment.ignorePorts = true`      | 当值为 `true` 时，无需检查开放端口即可确认部署成功。 |

<div id="replit-3">
  ### 部署设置的 `.replit` 配置示例
</div>

```toml theme={null}

# 指定项目的主入口文件
entrypoint = "app.js"

# 应用部署配置
[deployment]
run = "npm start"
build = "npm run build"
ignorePorts = true
```

<Note>
  **解释器设置**已弃用，Replit 不再支持此功能。建议改用 `Run` 命令，配置在 Replit 应用环境中运行脚本和应用程序的方式。
</Note>

<div id="replit-5">
  ## 访问 Replit 应用的环境元数据
</div>

<div id="nodejs">
  ### Node.js
</div>

要访问所有环境变量，请使用：

`console.log(process.env);`

要访问单个变量 (REPL&#95;SLUG) ，请使用：

`console.log(process.env.REPL_SLUG);`

<div id="python">
  ### Python
</div>

要访问所有环境变量：

```python theme={null}
import os
print(os.environ)
```

访问单个变量 (REPL&#95;SLUG) ：

```python theme={null}
import os
variable = os.environ.get('REPL_SLUG')
print(variable)
```

<div id="rust">
  ### Rust
</div>

要访问所有环境变量：

```rust theme={null}
use std::env;
fn main() {
    for (key, value) in env::vars() {
        println!("{}: {}", key, value);
    }
}
```

要访问单个变量 (REPL&#95;SLUG) ：

```rust theme={null}
use std::env;
fn main() {
    let variable = env::var("REPL_SLUG").unwrap();
    println!("{}", variable);
}
```

<div id="section-11">
  ## 环境变量
</div>

以下是可在 Replit 应用中访问的环境变量：

| 键                                                 | 描述                                                                              |
| ------------------------------------------------- | ------------------------------------------------------------------------------- |
| <a name="REPL_OWNER" />`REPL_OWNER`               | Replit 应用所有者的用户名。如果 Replit 应用为纯文本且不包含 Web 服务器，`REPL_OWNER`会反映当前访问该 Replit 应用的用户 |
| <a name="REPL_ID" />`REPL_ID`                     | Replit 应用的唯一 UUID 字符串                                                           |
| <a name="HOME" />`HOME`                           | Replit 应用的主目录路径                                                                 |
| <a name="system" />`system`                       | Replit 应用运行所在的操作系统                                                              |
| <a name="LANG" />`LANG`                           | 设置 Replit 应用的语言和字符编码，并影响文本的处理和显示方式                                              |
| <a name="REPL_IMAGE" />`REPL_IMAGE`               | Replit 应用对应的 Docker 镜像                                                          |
| <a name="REPL_LANGUAGE" />`REPL_LANGUAGE`         | 为 Replit 应用设置的编程语言，用于确定运行时环境和工具                                                 |
| <a name="REPL_PUBKEYS" />`REPL_PUBKEYS`           | 包含多个公开 API 密钥的字符串化 JSON 对象                                                      |
| <a name="REPL_SLUG" />`REPL_SLUG`                 | Replit 应用名称的简化机器可读版本，适合用于 URL 和文件名                                              |
| <a name="PRYBAR_FILE" />`PRYBAR_FILE`             | Replit 应用的主入口文件                                                                 |
| <a name="REPLIT_DEV_DOMAIN" />`REPLIT_DEV_DOMAIN` | 为项目编辑器中的 Replit 应用提供 `replit.dev` URL。此环境变量在部署中不可用                              |
