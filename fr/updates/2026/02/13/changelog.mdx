## Plateforme

### Prise en charge de Claude Opus 4.5

Claude Opus 4.5 est désormais pris en charge dans les intégrations IA, vous donnant accès aux dernières capacités IA d'Anthropic optimisées pour le codage et les agents.

### Bouton « Ouvrir dans Replit » (Bêta)

Vous pouvez désormais traiter les tickets Linear directement sur Replit grâce au nouveau bouton « Ouvrir dans Replit ». Cette fonctionnalité bêta doit être activée dans les préférences et remplit automatiquement l'invite avec les détails du ticket. L'équipe travaille avec Linear pour améliorer l'intégration.

### Accès d'Agent à la base de données SQL de production

Agent peut désormais afficher et interroger votre base de données SQL de production en mode lecture seule, lui permettant de travailler avec de vraies données de production sans risque de modifications accidentelles.

### Améliorations de la fiabilité des connexions

Plusieurs améliorations pour renforcer l'expérience des intégrations :

* Les jetons de connexion expirent moins souvent grâce à un processus de reconnexion en arrière-plan amélioré
* Affichage clair lorsque les connexions sont dans un état d'erreur ou défectueux
* Possibilité de reconnecter les intégrations directement depuis l'état d'erreur

## Teams et Enterprise

### Budgets au niveau utilisateur/groupe

Les capacités de gestion budgétaire sont désormais activées pour tous les clients enterprise :

* Les administrateurs d'équipe enterprise peuvent définir des budgets d'utilisation par défaut pour tous les membres
* Les administrateurs peuvent définir des budgets sur des groupes spécifiques (par exemple, Administrateurs/Membres et groupes personnalisés)
* Prochainement : les administrateurs pourront définir des budgets de remplacement pour des utilisateurs individuels
