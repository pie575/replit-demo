---

通过 Enterprise 模型控制，账户管理员可以管理构建者可选择的 Agent 模型。先为账户设置策略，再为各个工作区配置不同的模型访问权限。

<Note>
  只有 Enterprise 账户的账户管理员可以使用模型控制。要为组织启用此功能，请联系销售团队 ([sales@replit.com](mailto:sales@replit.com)) 。
</Note>

<div id="section">
  ## 使用智能模型路由
</div>

智能模型路由是 Enterprise 工作区中 Agent 的默认环境。启用 **Auto mode** 后，Replit 会在兼顾质量与成本的前提下，为每项任务选择最合适的模式和模型。

路由会从账户和工作区策略批准的模型池中选择。无法选择不在该模型池中的提供商和模型。构建者可以保持启用 **Auto mode**，也可以将其关闭并直接选择获批准的模型。

如需详细了解路由机制，请参阅[使用智能模型路由](/zh/ko/chat/auto-mode)。

<div id="agent">
  ## 打开 Agent 模型设置
</div>

1. 打开 **设置**。
2. 在 **账户** 中选择 **高级**。
3. 展开 **Agent 模式与模型提供商**。

<Frame caption="高级设置中的模型提供商策略和独立的快速模式模型控件。">
  <img src="/assets/mirror/agent-model-provider-settings-overview-8f82610dab77.jpg" alt="包含提供商策略和快速模式模型控件的 Agent 模式与模型提供商设置" width="2000" height="930" data-path="images/workspace/agent-model-provider-settings-overview.jpg" />
</Frame>

<div id="section-2">
  ## 设置提供商策略
</div>

<Steps>
  <Step>
    选择要管理的模型提供商。
  </Step>

  <Step>
    在 **Account policy** 中选择以下选项之一：

    | 选项                  | 结果                   |
    | ------------------- | -------------------- |
    | **Enable all**      | 所有工作区都可以使用该提供商的所有模型。 |
    | **Enable selected** | 手动选择各工作区可用的模型。       |
    | **Disabled**        | 所有工作区都无法使用该提供商的模型。   |

    <Note>
      必须始终至少启用 OpenAI、Anthropic 或 Google 其中一家提供商的一个模型。其他提供商可以禁用。
    </Note>
  </Step>

  <Step>
    选择 **Update**。
  </Step>
</Steps>

开源模型提供商默认处于禁用状态。要启用这些提供商，请选择 **Enable all** 或 **Enable selected**，然后选择 **Update**。

<div id="section-3">
  ## 配置工作区策略
</div>

如果不同工作区需要不同的模型访问权限，请使用 **Enable selected**。

<Frame caption="设为 Enable selected 的 Anthropic 提供商策略，以及针对各工作区配置的模型访问权限。">
  <img src="/assets/mirror/anthropic-account-policy-workspace-models-38c0f71a609d.jpg" alt="设为 Enable selected 的 Anthropic 账户政策和工作区模型开关" width="2000" height="930" data-path="images/workspace/anthropic-account-policy-workspace-models.jpg" />
</Frame>

1. 打开提供商设置。
2. 将 **Account policy** 设为 **Enable selected**。
3. 在 **Workspace** 列表中，选择相应工作区的 **Setting** 下拉菜单。
4. 为该工作区中的各个模型启用或禁用访问权限。
5. 选择 **Update**。

在选择 **Update** 前，您可以选择 **Copy to all**，将当前工作区的模型选择应用到账户中的所有工作区。

<div id="section-4">
  ## 限制
</div>

* 模型策略按工作区生效。无法为同一工作区内的不同用户群组设置不同的策略。
* 智能模型路由不会覆盖账户或工作区策略。无法选择已禁用的提供商或模型。
* **Agent 模式与身份提供方**中的 **快速模式模型** 开关控制账户下所有工作区对高速模型变体的访问权限。提供商策略和智能模型路由不会更改此设置。
