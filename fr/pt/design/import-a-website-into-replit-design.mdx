⏰ *Durée estimée : 10 minutes*

Parfois, le design dont vous souhaitez vous inspirer est déjà disponible en ligne : votre site actuel ou une page dont vous souhaitez recréer l’apparence. Import from URL recrée un site web sous forme de frame de design que vous pouvez explorer, affiner et transformer en app interactive.

Vous utiliserez [creative-studio-landing.replit.app](https://creative-studio-landing.replit.app), une landing page créée par Replit pour un studio de création, comme exemple.

<div id="antes-de-comear">
  ## Avant de commencer
</div>

Vous aurez besoin de :

* Un [compte Replit](https://replit.com).
* L’URL d’un site web public ou de l’exemple ci-dessus.

<div id="importe-o-website">
  ## Importez un site web
</div>

<Steps>
  <Step title="Copiez l’URL du site">
    Utilisez votre propre site web ou copiez cet exemple : `https://creative-studio-landing.replit.app`.

    <Frame caption="Le site web d’exemple : Kosmo Studio, une page de destination pour un studio de création.">
      <img src="/assets/mirror/url-example-site-e0ad60629981.webp" alt="La page de destination de Kosmo Studio, avec le titre « We craft bold ideas and visuals that truly work » au-dessus d’un ensemble de cartes artistiques" width="3440" height="2160" data-path="images/design/import-from-url/url-example-site.webp" />
    </Frame>
  </Step>

  <Step title="Ouvrez Replit Design">
    Accédez à [replit.com/design](https://replit.com/design) et sélectionnez **Import URL** sous la zone de prompt. Agent recrée l’apparence du site web comme point de départ.

    <Frame caption="Import URL sur la page d’accueil de Replit Design : collez un lien vers n’importe quel site web.">
      <img src="/assets/mirror/design-import-url-07a8ac52e188.webp" alt="La page d’accueil de Replit Design avec l’option Import URL sélectionnée et une infobulle indiquant « Paste a link to any website and Agent will recreate its look and feel as a starting point »" width="2293" height="1322" data-path="images/design/import-from-url/design-import-url.webp" />
    </Frame>
  </Step>

  <Step title="Collez l’URL et commencez à créer">
    Lorsque vous sélectionnez **Import URL**, le prompt est prérempli : *&quot;Recreate the look and feel of this website:&quot;*. Collez votre URL à la suite, puis sélectionnez **Start**.

    <Frame caption="Le prompt de recréation prérempli avec l’URL d’exemple, prêt à démarrer.">
      <img src="/assets/mirror/design-url-prompt-b6196aac1b17.webp" alt="La zone de prompt de Replit Design affichant « Recreate the look and feel of this website », suivie de l’URL d’exemple et du bouton Start" width="2293" height="1322" data-path="images/design/import-from-url/design-url-prompt.webp" />
    </Frame>
  </Step>
</Steps>

Agent recrée le site web sous forme de frame de design dans votre projet.

<Frame caption="La page de destination recréée de Kosmo Studio sous forme de frame de design dans Replit Design.">
  <img src="/assets/mirror/url-import-result-7a4114a468f3.webp" alt="La page de destination recréée de Kosmo Studio sous forme de frame de design dans Replit Design, avec l’exécution marquée comme terminée dans le panneau Chat" width="1600" height="1004" data-path="images/design/import-from-url/url-import-result.webp" />
</Frame>

<div id="deixe-do-seu-jeito">
  ## Personnalisez-le
</div>

Sélectionnez le frame importé et commencez à le transformer :

* **Suivez une [suggestion](/fr/pt/design/explore-suggestions)** : l’importation propose des étapes suivantes, comme une variante éditoriale sombre, une version mobile ou une page de contact. Chacune est générée sous la forme d’un nouveau frame afin de conserver l’original pour comparaison.
* **[Discutez-en](/fr/pt/design/chat-about-your-design)** : utilisez le champ sous le frame et décrivez avec vos propres mots : *« remplace les photos du portfolio »*, *« rends la typographie du hero plus marquée »*.

<Frame caption="Le frame importé sélectionné, avec des étapes suivantes suggérées proposant une variante éditoriale sombre, une version mobile et une page de contact.">

</Frame>
