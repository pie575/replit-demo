# Diretório de skills

> Explore skills criadas pelo Replit e por nossos parceiros, e saiba como instalá-las em um projeto ou no seu workspace.

O skills directory é um catálogo de skills prontas que você pode instalar e usar imediatamente — criadas pelo Replit e por nossos parceiros. Instale uma, experimente e depois edite-a para se adequar à forma como a sua equipe realmente trabalha.

Para entender o que é uma skill e como o Agent a carrega, veja [Agent Skills](/pt/features/agent/skills). Para disponibilizar uma skill em todo o seu workspace, veja [Agent Customization](/pt/features/agent/agent-customization).

## Instalar uma skill

Você pode adicionar uma skill do diretório de algumas formas:

* **No chat** — clique no botão **+** ao lado da entrada de chat, selecione **Use a skill** e escolha uma. A skill se aplica apenas àquela mensagem, sem nada instalado no seu projeto.
* **Em um projeto** — abra o **Skills pane** no Project Editor, selecione a aba **Discover**, encontre uma skill e clique em **Install**. As skills instaladas ficam no diretório `/.agents/skills` do seu projeto e persistem entre chats.
* **Pela linha de comando** — instale uma skill com a [skills CLI](https://github.com/vercel-labs/skills):

  ```bash theme={null}
  npx skills <skill> -a replit
  ```

<Warning>
  As skills no seletor de skills do Replit passam por auditoria de segurança. Skills instaladas a partir de fontes externas não passam por essa auditoria. Como uma skill nada mais é do que instruções que o Agent segue, sempre revise uma skill externa antes de instalá-la — veja [Agent skills](/pt/learn/agent-skills) para saber o que verificar.
</Warning>

## Skills do Replit

O Replit já vem com skills pré-definidas disponíveis no seletor **Use a skill** no chat e no seletor de ponto de partida para novos projetos. Elas funcionam em todos os projetos sem instalação. As descrições aparecem embutidas quando você abre o seletor.

| Categoria                  | Skills                                                                                                        |
| -------------------------- | ------------------------------------------------------------------------------------------------------------- |
| Vendas e marketing         | Ad Creative, AI SDR, SEO Auditor, Programmatic SEO, GEO, Content Machine, Storyboard                          |
| Carreira                   | AI Recruiter, Resume Maker, Interview Prep                                                                    |
| Pesquisa e análise         | Competitive Analysis, Deep Research, GitHub Solution Finder, Supplier Research                                |
| Negócios e finanças        | Stock Analyzer, Excel Generator, Invoice Generator, Tax Reviewer                                              |
| Documentos e ferramentas   | Website Cloner, File Converter, Flashcard Generator, Legal Contract, Infographic Builder, Recreate Screenshot |
| Criativo                   | Photo Editor, Podcast Generator, Podcast Marketing, Branding Generator, Video Editing                         |
| Produtividade              | AI Secretary, Product Manager, Design Thinker, Skill Finder, Skill Creator                                    |
| Pessoal                    | Travel Assistant                                                                                              |
| Segurança e conformidade   | Secrets, Sensitive Data, Input Validation, AI Security, Dependency Vetting, License Check                     |
| Qualidade e confiabilidade | Accessibility, Responsive UI, Observability, Resilience, Ship Review                                          |

<Note>
  Dentro de um workspace, o seletor também descobre quaisquer skills adicionais instaladas no diretório `.local/secondary_skills/` do projeto.
</Note>

## Skills de parceiros

Os parceiros do Replit publicam skills que ensinam o Agent a construir com seus produtos. Instale uma para dar ao Agent os padrões e convenções daquele serviço.

| Parceiro         | O que ensina ao Agent                                        |
| ---------------- | ------------------------------------------------------------ |
| Stripe           | Padrões de integração de pagamentos e faturamento            |
| PayPal           | Padrões de integração de pagamentos                          |
| RevenueCat       | Padrões de assinatura e compras dentro do app                |
| Mixpanel         | Implementação de analytics e rastreamento                    |
| BigQuery         | Padrões de consulta em data warehouse                        |
| Resend           | Integração de e-mail transacional                            |
| Google Workspace | Integração com Gmail, Drive, Docs e Calendar                 |
| Atlassian        | Fluxos de trabalho de issues do Jira e páginas do Confluence |
| Google Maps      | Integração de mapas, lugares, rotas e geocodificação         |

## Skills da comunidade

Além das skills do Replit e de parceiros, a comunidade publica skills que você pode instalar. Explore-as em [skills.sh](https://skills.sh) e leia a [especificação Agent Skills](https://agentskills.io/specification) para escrever as suas próprias.
