## 플랫폼 업데이트

### 보안 스캔

Replit에 이제 보안 스캔 기능이 포함됩니다. 일반적인 보안 문제에 대해 코드를 스캔하는 간단한 방법입니다.

[보안 기능](/tutorials/vibe-code-securely)을 확인하고 모범 사례를 위한 [보안 체크리스트](/tutorials/vibe-code-security-checklist)를 따르세요.

### 체크포인트 미리보기

Replit 개발 환경에 체크포인트 미리보기를 소개합니다. 이전 버전을 다시 빌드하거나 복원하지 않고도 개발의 다양한 단계에서 앱을 시각화하세요.

이 기능은 더 쉬운 진행 추적, 반복 비교, 버전 관리를 가능하게 하여 프로젝트의 발전에 대한 포괄적인 보기를 제공합니다. 이 기능은 [바이브 코딩 워크플로우](https://learn.replit.com)와 함께 사용됩니다.

### Replit 타임 트래블

타임 트래블 기능이 Replit에 도착했습니다. 개발 컨텍스트를 유지하면서 프로젝트 기록을 원활하게 탐색하세요.

다양한 버전을 탐색하고, 발전적 변화를 이해하고, 실수에서 복구하고, 현재 개발 환경 내에서 더 자신감 있게 실험하세요. 이것은 더 강력한 버전 제어를 위해 [Git 통합](/ko/learn/projects-and-artifacts/version-control)을 보완합니다.

### Agent에게 데이터베이스 추가 요청

DB 창에서 Agent 통합으로 데이터베이스 구성이 간단해집니다. 이 AI 기반 워크플로우는 복잡한 구성 코드 없이 데이터 지속성 구현을 단순화하면서 데이터베이스 설정을 안내합니다.

개발자는 Agent가 데이터베이스 세부 사항을 처리하는 동안 핵심 기능 빌드에 집중할 수 있습니다. [Replit Agent](/core-concepts/agent)와 [데이터베이스 옵션](/ko/learn/projects-and-artifacts/storage-and-databases)에 대해 더 알아보세요.

### 기본 Replit Auth 매칭

앱의 사용자 인증이 자동 Replit Auth 매칭으로 손쉬워집니다.

이 기능은 애플리케이션에 인증이 필요할 때 활성화됩니다. 커스텀 등록 양식, 비밀번호 복구 시스템, 소셜 로그인 구성의 필요성을 없애줍니다. 이를 통해 더 원활하게 안전한 사용자 관리로 나아갈 수 있습니다.

### 전체 화면 이메일 인증

보호된 작업을 위한 간소화된 인증 프로세스로 계정 보안을 강화합니다.

이 통합 접근 방식은 필요할 때 로그인 후 이메일 인증을 제공합니다. 보안과 편의성의 균형을 맞추면서 일관된 사용자 경험을 유지하며 계정 보호를 보장합니다.

이것은 [정보 보안](/ko/teams/information-security/overview)에 대한 지속적인 약속의 일환입니다.

### Google Analytics 블루프린트

Google Analytics 블루프린트로 애플리케이션 성능을 모니터링하세요.

Agent는 이제 분석 설정을 개발 워크플로우에 직접 통합합니다. 이를 통해 복잡한 구성 없이 트래픽 모니터링, 사용자 행동 추적, 성장 지표를 활성화할 수 있습니다.

모든 개발자에게 전문적인 분석 기능을 제공합니다. [Agent 통합](/replitai/integrations)으로 사용해 보세요.

## Teams 및 엔터프라이즈

### 엔터프라이즈 고객을 위한 SCIM

새로운 SCIM 통합을 통해 엔터프라이즈 고객은 ID 공급자를 통해 Replit 액세스를 직접 관리할 수 있습니다.

Okta, Active Directory, Rippling 또는 다른 ID 플랫폼을 연결하여 Replit 시트 프로비저닝 및 프로비저닝 해제를 자동화하세요. 이를 통해 수동 사용자 관리 오버헤드를 없애고 엔터프라이즈 워크플로우를 간소화합니다.

시작하려면 자세한 [SCIM 문서](/ko/teams/identity-and-access-management/scim)를 읽어보세요.

### Replit Teams를 위한 뷰어 시트

Replit Teams를 위한 뷰어 시트를 소개합니다. 앱을 편집하지 않고 보고 상호작용만 하는 이해 관계자와 전체 팀 라이선스 없이 애플리케이션을 공유하세요.

앱을 사용하지만 빌드하지 않는 임원, 클라이언트, 팀원과 공유하기에 적합합니다. [뷰어 시트](/ko/teams/identity-and-access-management/viewer-seats) 설정 및 관리 방법을 알아보세요.
