  const AGENT_INPUT_TYPEWRITER_PROMPTS = ["Build a project tracker for my team", "Design a landing page for my coffee shop", "Add Stripe payments to my app"];

  const AGENT_INPUT_PAUSE_AFTER = 2000;
  const AGENT_INPUT_START_DELAY = 500;
  const getAgentInputTypewriterLoader = () => {
    if (typeof window === "undefined") {
      return null;
    }
    if (!window.__replitDocsAgentInputTypewriterLoader) {
      window.__replitDocsAgentInputTypewriterLoader = {};
    }
    return window.__replitDocsAgentInputTypewriterLoader;
  };
  const ensureAgentInputTypewriterCore = () => {
    if (typeof window === "undefined" || typeof document === "undefined") {
      return Promise.resolve(null);
    }
    if (window.Typewriter) {
      return Promise.resolve(window.Typewriter);
    }
    const loader = getAgentInputTypewriterLoader();
    if (loader.promise) {
      return loader.promise;
    }
    loader.promise = new Promise((resolve, reject) => {
      const handleLoad = () => {
        if (window.Typewriter) {
          resolve(window.Typewriter);
          return;
        }
        loader.promise = null;
        reject(new Error("Typewriter core loaded without a global Typewriter export."));
      };
      const handleError = () => {
        loader.promise = null;
        reject(new Error("Failed to load typewriter core."));
      };
      const existingScript = document.getElementById(AGENT_INPUT_TYPEWRITER_SCRIPT_ID);
      if (existingScript) {
        existingScript.addEventListener("load", handleLoad, {
          once: true
        });
        existingScript.addEventListener("error", handleError, {
          once: true
        });
        return;
      }
      const script = document.createElement("script");
      script.id = AGENT_INPUT_TYPEWRITER_SCRIPT_ID;
      script.src = AGENT_INPUT_TYPEWRITER_SRC;
      script.async = true;
      script.addEventListener("load", handleLoad, {
        once: true
      });
      script.addEventListener("error", handleError, {
        once: true
      });
      document.head.appendChild(script);
    });
    return loader.promise;
  };
  const getAgentInputTypewriterRegistry = () => {
    if (typeof window === "undefined") {
      return null;

  const findAgentInputContainer = node => node?.closest?.("[data-agent-input-container]") || null;

    startButton: container?.querySelector?.('[data-agent-input-role="start-button"]') || null,
    pillsContainer: container?.querySelector?.('[data-agent-input-role="pills"]') || null
  });
  const getAgentInputPromptValue = container => {
    const {textarea} = getAgentInputElements(container);
    return textarea?.value?.trim() || "";
  };
  const updateAgentInputButtonState = container => {
    const {startButton} = getAgentInputElements(container);
    if (!startButton) {
      return;
    }
    const hasText = getAgentInputPromptValue(container).length > 0;
    startButton.style.opacity = hasText ? "1" : "0.4";
    startButton.style.cursor = hasText ? "pointer" : "not-allowed";
  };
  const stopAgentInputTypewriter = (textarea, {placeholder, clearDemo = false} = {}) => {
    if (typeof window === "undefined" || !textarea) {
      return;
    }
    const registry = getAgentInputTypewriterRegistry();
    const record = registry?.get(textarea);
    if (!record) {
      if (placeholder) {
        textarea.setAttribute("placeholder", placeholder);
      }
      return;
    }
    record.stopped = true;
    if (record.startTimer) {
      window.clearTimeout(record.startTimer);
    }
    if (record.writeFrame) {
      window.cancelAnimationFrame(record.writeFrame);
    }
    if (record.typewriter?.stop) {
      record.typewriter.stop();
    }
    textarea.removeEventListener("focus", record.handleFocus);
    textarea.removeEventListener("pointerdown", record.handlePointerDown);
    textarea.removeEventListener("input", record.handleInput);
    if (clearDemo && textarea.value === record.pendingValue) {
      textarea.value = "";
    }
    textarea.setAttribute("placeholder", placeholder || "");
    updateAgentInputButtonState(record.container);
    registry.delete(textarea);

      return;
    }

      return;

        return;

Agent est le builder IA de Replit, le compagnon qui transforme vos idées en logiciels. Agent peut planifier des modifications, écrire du code, expliquer un comportement, déboguer des problèmes et améliorer votre app.

[Vibe coding 101](/fr/ko/learn/foundations/vibe-coding-101) décrit l&#39;état d&#39;esprit à adopter, tandis que cette page explique comment travailler concrètement avec Agent. [Prompting efficace](/fr/ko/learn/effective-prompting) montre comment rédiger des instructions plus claires.

Voyez Agent comme le quarterback sur le terrain : il lit la situation, choisit les trajectoires et fait avancer le jeu. Vous êtes l&#39;entraîneur : vous élaborez la stratégie, définissez les actions, examinez les résultats et décidez du coup suivant.

Agent peut faire beaucoup de choses, mais il donne le meilleur de lui-même lorsque c&#39;est vous qui menez le processus : soyez précis, établissez un plan, ajoutez du contexte, relisez et testez, et utilisez les points de contrôle quand c&#39;est nécessaire.

Adoptez ces habitudes lorsque vous travaillez avec Agent :

1. Soyez précis.
2. Établissez un plan.
3. Ajoutez du contexte.
4. Vérifiez et testez.
5. Utilisez les points de contrôle.

<div id="section">
  ## Soyez précis
</div>

Agent peut gérer des tâches complexes, mais il a besoin d&#39;instructions claires.

Une bonne demande décrit ce que vous voulez, ce qui compte et ce qui ne doit pas être modifié. Inutile d&#39;expliquer tous les détails d&#39;implémentation, mais donnez suffisamment d&#39;indications pour qu&#39;Agent puisse prendre de bonnes décisions.

Au lieu de ceci :

<AiPrompt>
  Améliore mon application.
</AiPrompt>

Essayez plutôt ceci :

<AiPrompt>
  Améliore la page d&#39;inscription afin que les visiteurs comprennent ce que fait le produit avant de créer un compte.<br />
  Conserve la palette de couleurs actuelle, laisse les champs du formulaire tels quels et rends le bouton principal plus visible.
</AiPrompt>

Le second prompt donne à Agent un objectif, un périmètre d&#39;action et des contraintes.

Lorsque votre demande comporte plusieurs volets, indiquez ce qui est le plus important.

<AiPrompt>
  Ajoute une vue d&#39;administration simple pour gérer les demandes de traiteur.<br />
  Le plus important est de pouvoir consulter les nouvelles demandes, les marquer comme contactées et les filtrer par statut.<br />

Agent peut décomposer ce travail en étapes, mais ce sont vos indications qui définissent ce qu&#39;est un résultat réussi.

Pour d&#39;autres exemples d&#39;instructions précises, consultez [Prompting efficace](/fr/ko/learn/effective-prompting).

<AiPrompt>

  ## Vérification et test
</div>

Agent peut proposer un plan avant de créer votre app, puis résumer les modifications apportées. Lisez les deux.

Dans la carte du plan de travail, sélectionnez **Afficher** pour ouvrir le plan. Le plan développé indique ce qu&#39;Agent compte créer, les critères de réussite, ce qui est hors périmètre et les étapes qu&#39;Agent suivra.

Vérifiez le plan avant qu&#39;Agent ne se lance :

* Est-ce que cela résout le bon problème ?
* Manque-t-il quelque chose ?
* Y a-t-il des éléments hors périmètre ?
* Existe-t-il une version plus réduite à créer en premier ?
* Le plan explique-t-il comment tester le résultat ?

Si le plan est trop large, demandez à Agent de le réduire.

<AiPrompt>
  Ce plan est trop large.<br />
  Réduis-le à la plus petite version que je peux tester aujourd&#39;hui.<br />
  Déplace le reste dans une liste d&#39;améliorations futures.
</AiPrompt>

Une fois qu&#39;Agent a terminé, testez l&#39;app vous-même. Ouvrez le Preview et utilisez-la comme le ferait la personne à qui elle est destinée.

À vérifier :

* Peut-on accomplir la tâche principale ?
* La modification demandée a-t-elle bien eu lieu ?
* L&#39;app fonctionne-t-elle toujours sur mobile ?
* Un comportement important est-il cassé ?
* Agent a-t-il modifié quelque chose sans rapport ?
* Le résultat est-il assez bon pour continuer à développer ?

Au lieu de ceci :

<AiPrompt>
  Corrige le formulaire.

<AiPrompt>

  Vide le formulaire après l&#39;envoi et fais en sorte que le message de confirmation reste visible.
</AiPrompt>

Des retours précis aident Agent à corriger le bon ticket.

<div id="section-5">
  ## Utiliser les points de contrôle
</div>

Les points de contrôle vous aident à revenir en arrière lorsqu&#39;une modification part dans la mauvaise direction.

Si le résultat s&#39;approche de votre objectif, formulez un retour ciblé :

<AiPrompt>
  C&#39;est presque ça, mais le formulaire est devenu trop long.<br />
  Conserve le nouveau style visuel, supprime le champ de notes facultatif et rends la date de retrait plus lisible.
</AiPrompt>

Utilisez un point de contrôle lorsque l&#39;application est moins bonne qu&#39;avant, qu&#39;un comportement important ne fonctionne plus ou que l&#39;Agent a modifié plus d&#39;éléments que prévu.

Ouvrez **History** dans le panneau de l&#39;Agent pour consulter les points de contrôle. Chaque point de contrôle affiche les contrôles **Restaurer à partir d&#39;ici** et **Modifications** à côté des changements correspondants.

<Frame>
  <img src="/assets/mirror/agent-checkpoints-history-c33b3b0dd592.png" alt="Panneau Agent History affichant un point de contrôle intitulé « Passage du mode Plan au mode Build » ainsi que les boutons Restaurer à partir d'ici et Modifications" width="720" height="450" data-path="images/fitstart/work-with-agent/agent-checkpoints-history.png" />
</Frame>

Lorsque vous sélectionnez **Restaurer à partir d&#39;ici**, l&#39;Agent confirme ce qui sera restauré avant d&#39;appliquer la restauration.

<Frame>
  <img src="/assets/mirror/agent-checkpoints-rollback-dialog-28de278b44da.png" alt="Boîte de dialogue de confirmation de restauration d'un point de contrôle listant le point de contrôle cible et les éléments concernés, avec les cases à cocher fichiers, mémoire de l'Agent, tâches et base de données" width="900" height="880" data-path="images/fitstart/work-with-agent/agent-checkpoints-rollback-dialog.png" />
</Frame>

Si vous hésitez entre corriger en avançant ou restaurer, demandez à l&#39;Agent de vous aider à comparer.

<AiPrompt>
  La dernière modification a dégradé l&#39;application.<br />
  Compare la version actuelle avec la précédente version fonctionnelle.<br />
  Dis-moi s&#39;il est plus sûr de corriger en avançant ou de restaurer, et pourquoi.
</AiPrompt>

Il est normal de partir dans la mauvaise direction. Les points de contrôle vous permettent d&#39;explorer sans perdre la possibilité de revenir à une version plus sûre.

Pour plus de conseils sur la restauration, consultez [Points de contrôle et restaurations](/fr/ko/features/version-control/checkpoints-and-rollbacks).

<div id="agent-2">
  ## À quoi ressemble une bonne collaboration avec Agent
</div>

Vous êtes sur la bonne voie lorsque :

* votre demande décrit l’objectif et les contraintes ;
* le plan d’Agent est suffisamment clair pour être examiné ;
* vous ajoutez des captures d’écran, des fichiers ou des notes Canvas lorsque les mots ne suffisent pas ;
* vous testez les parcours importants après les modifications ;
* vous fournissez des retours ciblés lorsqu’un problème survient ;
* vous utilisez des points de contrôle plutôt que d’essayer sans fin d’annuler des modifications incorrectes.
