<div id="agentreplit-docs">
  ### Agent 现可访问 Replit Docs
</div>

Agent 现在可以即时解答有关 Replit 功能和文档的问题。借助对 Replit Docs 的直接访问，Agent 可在你编写代码的地方提供快速、准确且全面的帮助。

  ### 全新数据库窗格
</div>

重新设计的数据库窗格让数据库管理更加清晰。全新界面可让您轻松区分开发数据库和生产数据库，并简化数据库工作流程。

</div>

<div id="section-5">
  ### 可视化编辑器颜色选择器改进
</div>

现在，您可以在 Agent 的可视化编辑器中更流畅地编辑颜色。点击颜色的十六进制值输入框，颜色选择器弹窗会自动打开，方便您快速选择颜色。
