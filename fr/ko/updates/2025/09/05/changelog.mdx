  ## Plateforme

<div id="general-agent">
  ### General Agent
</div>

<Frame>
  <img src="/assets/mirror/general-agent-240ff289e711.png" alt="Illustration principale de General Agent" width="1040" height="572" data-path="images/replitai/general-agent.png" />
</Frame>

Replit Agent fonctionne désormais avec les bases de code de n&#39;importe quel langage ou framework s&#39;exécutant sur NixOS ! Auparavant limité à certains templates, Agent prend maintenant en charge les frameworks de développement, les imports depuis GitHub et toute configuration de projet personnalisée. Cette avancée majeure apporte une assistance au codage par IA complète aux workflows des entreprises et des utilisateurs avancés.

Pour en savoir plus sur General Agent, consultez [cette page](/fr/core-concepts/agent/general-agent).

<div id="section-3">
  ### Mode Plan
</div>

<Frame>
  <img src="/assets/mirror/plan-mode-overview-8077807c63b9.png" alt="Interface de chat Agent en mode Plan" width="916" height="362" data-path="images/replitai/plan-mode-overview.png" />
</Frame>

Le mode Plan inaugure une nouvelle façon d&#39;échanger avec Replit Agent, axée sur les questions, le brainstorming et la planification des tâches. Avec le mode Plan, vous pouvez demander à Agent de dresser une liste de tâches pour les travaux à venir, puis lancer des tâches de longue durée en mode Build.

Pour en savoir plus sur le mode Plan, consultez [cette page](/fr/core-concepts/agent/plan-mode).

<div id="section-4">
  ## Enterprise
</div>

<div id="gcp">
  ### Intégration à GCP Marketplace
</div>

Les clients Enterprise peuvent désormais acheter Replit directement sur la marketplace Google Cloud Platform et régler leur achat avec leurs crédits GCP existants. Le processus d&#39;achat s&#39;en trouve simplifié, et les organisations disposant d&#39;un budget GCP peuvent plus facilement intégrer Replit à leurs workflows de développement.
