控制台可让您实时监控和查看正在运行的 Replit App 输出的日志。
您可以利用当前和之前运行的信息来了解应用的行为、
排查错误并优化性能。

<Tip>
  使用 Agent 调试时，请在 prompt 中附上控制台日志，以提供上下文。
</Tip>

</Frame>

<div id="recursos">
  ## 功能
</div>

控制台 提供以下工具，帮助您了解应用的运行情况：

* **实时日志**：查看应用运行时的输出
* **AI 辅助**：获取修复日志中报错的建议
* **运行历史记录**：查看之前运行的日志，以跟踪变更

<div id="uso">
  ## 使用方法
</div>

你可以直接在项目编辑器中打开 控制台 工具。

<Accordion title="如何打开 控制台">
  在左侧的 **Tool dock** 中：

  1. 选择 <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="所有工具图标" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**，查看项目编辑器的工具列表。
  2. 选择 <img class="icon-svg" src="/assets/mirror/console-8a41ac90789c.svg" alt="控制台 图标" width="16" height="16" data-path="images/icons/console.svg" /> **控制台**。

  在**搜索栏**中：

  1. 选择顶部的 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 放大镜图标，打开搜索工具
  2. 输入“控制台”查找该工具，并在结果中选择它。
</Accordion>

每次在 Replit App 中点击 **Run** 按钮，控制台 都会显示一条新条目，其中包含以下信息：

* 运行代码所使用的命令
* 日期和时间信息
* 标准输出日志和错误日志

下面的截图显示了用于启动应用的 `npm run dev` 命令以及本次运行的日志消息：

</Note>

<div id="depurao-com-ia">
  ### 使用 AI 调试
</div>

当您在日志中发现想要了解的错误或其他信息时，请点击日志条目顶部的
**Ask AI** 按钮。这会自动打开 **Agent** 选项卡，并将日志内容发送供其分析。

<div id="comandos-de-entrada-de-log">
  ### 日志条目命令
</div>

控制台提供以下工具来管理日志：

* **Show Only Latest**：启用此选项后，仅显示最近一次运行的日志。
* **Collapse entry**：选择命令名称左侧的 <img class="icon-svg" src="/assets/mirror/down-arrow-9c1cf9fd152e.svg" alt="向下箭头图标" height="16" width="16" data-path="images/icons/down-arrow.svg" /> 向下箭头，隐藏日志。
* **Clear past runs**：选择此项可删除之前运行的日志。此操作无法撤销。

<div id="disponibilidade-de-rede">
  ### 网络可用性
</div>

你可以控制应用开发版本的在线可用性。

要停止响应发往开发 URL 的请求，请选择网络信息行右侧的 <img class="icon-svg" src="/assets/mirror/network-off-5bdca8a4fe4e.svg" alt="网络关闭图标" height="16" width="16" data-path="images/icons/network-off.svg" /> 带斜杠的地球图标。

要重新启用，请选择 <img class="icon-svg" src="/assets/mirror/network-on-15be2e5fb4f5.svg" alt="网络开启图标" height="16" width="16" data-path="images/icons/network-on.svg" /> 地球图标。

要查看你的开发 URL，请选择地址栏中的 `{...}.replit.dev` 文本。

<Frame>
  <img src="/assets/mirror/preview-dev-url-b36770b33769.png" alt="Preview 中开发 URL 的位置" width="1222" height="824" data-path="images/workspace/preview-dev-url.png" />
</Frame>

<Note>
  即使设置为停止响应发往开发 URL 的请求，你的应用在 Preview 标签页中仍然可以访问。
</Note>

<div id="parar-um-comando-de-workflow">
  ### 停止工作流命令
</div>

您可以在项目编辑器的 控制台 工具中停止正在运行的工作流命令。

点击 Replit App 运行命令所在行右侧的方形按钮，即可终止该命令。

要重新启动应用，请使用项目编辑器顶部工作流中的 **Run** 按钮。
