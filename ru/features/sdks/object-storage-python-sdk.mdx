<div id="client">
  ## Client
</div>

Класс `Client` управляет взаимодействием с Replit App Storage. В этом классе есть методы для выполнения операций над объектами в бакете.

Чтобы импортировать класс из пакета `replit.object_storage`, добавьте в свой код на Python следующую строку:

```python theme={null}
from replit.object_storage import Client
```

Используйте следующий код, чтобы создать экземпляр `Client` для работы с Replit App Storage:

```python theme={null}
client = Client()
```

<Tip>
  Если ваше приложение использует несколько бакетов, создайте отдельный экземпляр `Client` для каждого бакета.
</Tip>

<div id="__init__">
  ### **init**
</div>

Метод `init` создаёт экземпляр класса Client.

```python theme={null}
def __init__(bucket_id: Optional[str] = None)
```

**Аргумент**:

* `bucket_id` (Optional[str]): идентификатор бакета, которым управляет клиент. Если не указан, Client использует бакет по умолчанию, связанный с приложением Replit App или деплоем.

<div id="copy">
  ### copy
</div>

Метод `copy` копирует объект в пределах одного бакета. Если по тому же пути уже существует объект, он будет перезаписан.

```python theme={null}
def copy(object_name: str, dest_object_name: str) -> None
```

**Аргументы**:

* `object_name` (str) — полный путь к исходному объекту.
* `dest_object_name` (str) — полный путь назначения объекта.

**Вызывает исключения**:

* `ObjectNotFoundError` — означает, что по указанному пути исходный объект отсутствует.

<div id="delete">
  ### delete
</div>

Метод `delete` безвозвратно удаляет файл из App Storage.

```python theme={null}
def delete(object_name: str, ignore_not_found: bool = False) -> None
```

**Аргументы**:

* `object_name` (str) — имя удаляемого объекта.
* `ignore_not_found` (bool) — если `True`, ошибка не возникает при отсутствии объекта.

**Вызывает исключения**:

* `ObjectNotFoundError` — объект не существует.

<div id="download_as_bytes">
  ### download_as_bytes
</div>

Метод `download_as_bytes` возвращает содержимое файла в виде `bytes`.

```python theme={null}
def download_as_bytes(object_name: str) -> bytes
```

**Аргумент**:

* `object_name` (str) — имя объекта для скачивания.

**Возвращает**:

* `bytes` — содержимое объекта в виде необработанных байтов.

**Вызывает исключения**:

* `ObjectNotFoundError` — указывает, что объект не существует.

  ### download_as_text
</div>

Метод `download_as_text` скачивает содержимое файла в виде значения типа `str`.

```python theme={null}
def download_as_text(object_name: str) -> str
```

**Аргумент**:

* `object_name` (str) — имя исходного объекта, который требуется получить.

**Возвращает**:

* str: содержимое объекта в виде строки в кодировке UTF-8.

**Вызывает исключения**:

* `ObjectNotFoundError` — означает, что объект не существует.

<div id="download_to_filename">
  ### download_to_filename
</div>

Скачивает содержимое объекта в файл на локальном диске.

```python theme={null}
def download_to_filename(object_name: str, dest_filename: str) -> None
```

**Аргументы**:

* `object_name` (str) — имя исходного объекта в App Storage, который требуется загрузить.
* `dest_filename` (str) — имя целевого файла на локальном диске.

**Вызывает исключения**:

* `ObjectNotFoundError` — объект не существует.

<div id="exists">

Метод `exists` проверяет, существует ли объект.

```python theme={null}
def exists(object_name: str) -> bool
```

**Аргумент**:

<div id="list">
  ### list
</div>

Метод `list` возвращает список объектов в бакете.

```python theme={null}
def list(end_offset: Optional[str] = None,
         match_glob: Optional[str] = None,
         max_results: Optional[int] = None,
         prefix: Optional[str] = None,
         start_offset: Optional[str] = None) -> List[Object]
```

**Аргументы**:

* `end_offset`(Optional[str]) — Фильтрует результаты, оставляя объекты, имена которых лексикографически предшествуют `end_offset`. Если задан `start_offset`, в список попадают объекты с именами между `start_offset` (включительно) и `end_offset` (не включая).
* `match_glob` (Optional[str]) — Фильтрует результаты по glob-шаблону. Например: &quot;foo*bar&quot; соответствует &quot;footbar&quot;, &quot;foo baz bar&quot; и &quot;foobar&quot;.
* `max_results` (Optional[int]) — Максимальное количество результатов, возвращаемых в ответе.
* `prefix` (Optional[str]) — Фильтрует результаты, оставляя объекты, имена которых начинаются с указанного префикса.
* `start_offset` (Optional[str]) — Фильтрует результаты, оставляя объекты, имена которых лексикографически равны `start_offset` или следуют за ним.
  Если задан `end_offset`, в список попадают объекты с именами между `start_offset` (включительно) и `end_offset` (не включая).

**Возвращает**:

* `List`(Object): Список объектов, соответствующих заданным параметрам запроса.

<div id="upload_from_filename">

<div id="exception-types">
  ### Типы исключений
</div>

* При работе с Replit App Storage через `Client` любой метод может вернуть одну из следующих ошибок:

  * `BucketNotFoundError`: указанное имя бакета не соответствует ни одному бакету в App Storage.

  * `DefaultBucketError`: отсутствует конфигурация бакета по умолчанию.

  * `ForbiddenError`: недостаточно прав для доступа к бакету.

  * `TooManyRequestsError`: операция ограничена по частоте из-за слишком большого количества запросов.

  * `UnauthorizedError`: доступ к операции ограничен из-за отсутствия авторизации.
