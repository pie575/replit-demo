export const ProCreditRolloverPeriod = 'two months';

Replit 的 AI 功能采用按使用量计费的方式，根据您创建的内容以及使用 AI 工具的程度收费，确保您只为 Agent 为您带来的价值付费。

<div id="primeiros-passos">
  ## 入门
</div>

**所有订阅用户**均可获得一次免费的 Agent checkpoint。

额外的每月积分会自动用于 AI 使用：

* **Core 订阅用户**：每月积分 (请参阅[定价](https://replit.com/pricing))
* **Pro 订阅用户**：分级每月积分，可在 {ProCreditRolloverPeriod} 内结转。请参阅 [Replit Pro](/zh/pt/billing/plans/replit-pro)。

这些积分可用于 Agent 和其他 Replit 云服务，例如已部署 App、存储和数据库。选择 [Lite、Economy 或 Power](/zh/pt/features/agent/agent-modes)，根据速度、成本或能力优化 Agent。

<div id="cobrana-do-agent">
  ## Agent 计费
</div>

<Frame>
  <img src="/assets/mirror/checkpoint-f0cc3c49b9a5.png" alt="Replit Agent 界面，显示 Chat 和 checkpoint 系统" width="1999" height="1242" data-path="images/billing/checkpoint.png" />
</Frame>

Free Mode 为 Core 和 Pro 订阅者提供配额内的免费日常 Agent 服务。付费模式和已确认的付费任务会根据请求的复杂度，按工作量定价。Replit 会在开始付费操作前请求确认。

<div id="como-funciona-a-precificao-baseada-em-esforo">
  ### 基于工作量的定价机制
</div>

当你在“Build 模式”中与 Agent 对话时，它会创建 **checkpoint**，记录为完成你的请求所做的工作：

* **简单请求** (例如修复错误或进行小幅修改) 的费用通常低于复杂 Build
* **复杂 Build** (例如完整功能或集成) 会汇总到一个checkpoint中，其费用可能高于简单请求，以反映所需的总工作量
* **每个请求一个checkpoint**可避免产生中间checkpoint，减少计费上的干扰
* **透明定价**会清晰显示你为每项已完成任务支付的费用

<Info>
  当 Agent 完成你的请求并在代码中实现所需功能时，就会生成一个checkpoint。
</Info>

在付费方案中，即使不修改代码，规划模式也可能会进行需计费的推理。

如需详细了解checkpoint记录的内容及其工作方式，请参阅[checkpoint和回滚](/zh/pt/features/version-control/checkpoints-and-rollbacks)。

<div id="cobrana-dos-servios-do-agent">
  ### Agent 服务计费
</div>

Agent 的部分功能会在后台调用付费的第三方 API (例如 Claude、ChatGPT 和 Nano Banana / Gemini) 。Agent 会自动管理这些集成，无需 API 密钥或额外配置。您将按模型提供方公开的 API 费率付费，费用将从您的 Replit 积分中扣除。这些费用会与其他使用费用一同显示在[使用情况面板](/zh/pt/billing/managing-spend)中。

如需了解示例应用的费用，请查看我们的[简易交互式演示](https://agent-pricing.replit.app/)。

<div id="acompanhar-seu-uso">
  ### 跟踪您的使用情况
</div>

您可以实时监控 Agent 的支出：

1. **Agent 选项卡**：将鼠标悬停在用量图标上，即可查看各个 checkpoint 的费用
2. **使用情况面板**：查看当前周期的详细计费信息
3. **设置**：在 **账户** → **计费** 中设置提醒和预算，以控制支出

<Tip>
  用量数据最长可能需要 30 分钟才会显示在使用情况面板中。
</Tip>

<div id="gerenciando-seus-gastos">
  ## 管理您的支出
</div>

使用 Replit 内置的预算工具，掌控您的 AI 支出：

* **使用提醒**：达到支出限额时接收通知
* **预算限额**：设置严格上限，避免产生意外计费
* **实时跟踪**：在创建过程中监控成本
* **积分包**：购买额外积分，购买越多，折扣越大。有关详情，请参阅[管理您的支出](/zh/pt/billing/managing-spend)。
