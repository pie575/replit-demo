<div id="agent">
  ### 控制 Agent 的自主程度
</div>

通过全新的自主级别设置，控制 Agent 在项目中独立工作的程度。你可以根据自己的工作流偏好和项目需求，在低 (仅执行任务列表) 、中 (增加代码审查) 、高 (全应用审查) 和最高 (完全自主规划) 之间进行选择。

  ### 恶意文件检测
</div>

安全扫描器功能全面增强，可检测并拦截供应链攻击带来的恶意文件，让你在编码时时刻受到保护，也包括针对近期 npm 包攻击事件的防护。

<div id="section-3">
  ### 阻断供应链攻击
</div>

增强的安全功能可自动拦截来自受感染 npm 包的数据外泄尝试，在不干扰开发工作流的同时，保障敏感信息安全。

<div id="section-4">
  ### 在成员页面复制邮箱
</div>

在组织的成员管理页面，只需一键即可快速复制成员的邮箱地址，让团队沟通与管理更高效。
