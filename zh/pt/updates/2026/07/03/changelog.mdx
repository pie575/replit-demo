  ### 通过 Whop 在你的 App 中销售
</div>

现在，只需告诉 Agent，就能借助 Whop 为你的 App 添加支付功能。Agent 会为你创建并连接 Whop 账户，把结账流程集成到项目中，无需任何外部配置，也不用粘贴 API 密钥。Whop 是开始销售数字产品、订阅和会员计划的最快方式。

<div id="faa-downgrade-do-pro-para-o-core-em-uma-nica-etapa">
  ### 一步即可从 Pro 降级到 Core
</div>

现在，你可以直接从 Replit Pro 切换到 Replit Core，无需先取消订阅。此前，降级的唯一方式是取消订阅，这会让你先回到免费计划，然后再重新订阅。如果你发起取消流程，Replit 现在会提供降级到 Core 的选项，这样你既能保留付费计划，已发布的应用也能继续运行。

详细了解[如何更改你的计划](/zh/pt/billing/plans/changing-your-plan)。
