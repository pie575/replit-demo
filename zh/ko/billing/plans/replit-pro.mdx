export const ProCreditRolloverPeriod = 'two months';

[Replit Pro](https://replit.com/pricing)专为超越 Core、认真构建应用的开发者打造——适合发布生产环境应用、与不断壮大的团队协作，或将 Agent 的能力发挥到极致。有关当前 Pro 定价，请参阅[定价页面](https://replit.com/pricing)。

<div id="section">
  ## 主要功能
</div>

<div id="agent">
  ### 强大的 Agent 体验
</div>

* **Turbo 模式**：高级设置中的**独立开关**——在 **Power** 模式下开启后，即可使用速度提升 **2.5 倍**的最快 Agent。每次请求的费用约为原来的 2 倍，建议有经验的构建者使用。
* **并行运行任务**：最多可同时运行 10 个任务，加快迭代速度。
* **Agent 模式**：根据任务选择 Lite、Economy 或 Power。有关模式选择的更多信息，请参阅 [Agent 模式](/zh/ko/features/agent/agent-modes)。

<div id="section-2">
  ### 分级积分与结转
</div>

* **分级月度积分**：设有多个按购买量享受折扣的档位。提前购买可节省更多，并可随着需求增长增加积分。当前档位请参阅[定价页面](https://replit.com/pricing)。
* **积分结转**：未使用的积分可在 {ProCreditRolloverPeriod} 内结转，让您从订阅中获得更多价值。

<div id="section-3">
  ### 扩展团队规模
</div>

* **最多 15 名构建者**：借助共享积分和预算控制功能，最多可邀请 15 名构建者。无需按用户付费，所有人均使用同一套餐。
* **协作工作区**：使用管理员账户的共享积分创建协作工作区，整理应用，并按工作区跟踪用量。

<div id="section-4">
  ### 优先支持与可靠性
</div>

* **优先支持**：工作日内可优先直接联系支持工程师。这是 Pro 和 Enterprise 在 AI 支持之外提供的额外权益。
* **4 倍数据库恢复期**：您可以将数据库恢复到最近 28 天内的任意时间点，而非标准的 7 天。恢复期越长，占用的存储空间越多，因此延长恢复期会增加使用费用。

<div id="section-5">
  ### 社区及更多功能
</div>

* **专属社区**：与其他认真投入的构建者交流学习，分享正在打造的项目，并获得团队专属访问权限。
* **更多功能即将推出**：今年还将上线更多 Pro 专属功能。

<div id="pro">
  ## Pro 专属功能
</div>

| 功能         | 详细信息                                   |
| ---------- | -------------------------------------- |
| Turbo 模式   | 使用性能最强的模型，Agent 速度提升 2.5 倍             |
| 并行执行任务     | 最多可同时运行 10 个任务                         |
| 最多 15 名构建者 | 相较于 Core 的 5 名                         |
| 积分结转       | 未使用的积分可在 {ProCreditRolloverPeriod} 内结转 |
| 优先支持       | 可优先直接获得支持工程师的帮助                        |
| 4 倍数据保留    | 已删除的数据库最长可恢复 28 天                      |

Pro 包含 Core 的所有功能。完整对比请参阅[定价页面](https://replit.com/pricing)。

<div id="section-6">
  ## 开始使用
</div>

1. 前往[定价页面](https://replit.com/pricing)
2. 选择 **Replit Pro** 和所需的积分档位
3. 完成付款后，即可与团队一起开始构建
