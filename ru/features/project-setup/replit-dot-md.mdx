<div id="how-replitmd-works">
  ## Как работает `replit.md`
</div>

Сначала Agent создаёт файл `replit.md` в корневом каталоге вашего проекта, опираясь на проверенные практики. Этот файл содержит:

* Базовую информацию о проекте
* Рекомендуемые шаблоны написания кода
* Типичные предпочтения для вашего типа проекта

<YouTubeEmbed videoId="kYv525W-vaU" title="Настройте, как Replit Agent отвечает вам" />

При обработке ваших запросов Agent автоматически читает файл `replit.md` и использует его содержимое, чтобы:

* Понимать архитектуру и соглашения вашего проекта
* Следовать выбранным вами шаблонам и стилю написания кода
* Использовать указанные вами менеджеры пакетов и зависимости

Agent также может обновлять файл `replit.md` по мере того, как узнаёт больше о вашем проекте и вносит изменения в приложение.

<Note>Вы можете отредактировать файл `replit.md`, чтобы настроить поведение Agent.</Note>

<div id="setting-up-replitmd">
  ## Настройка `replit.md`
</div>

<div id="automatic-generation">
  ### Автоматическая генерация
</div>

Когда вы создаёте новый проект с помощью Agent, он автоматически генерирует файл `replit.md` на основе проверенных практик. Этот файл появляется в корневом каталоге проекта и содержит:

* Основную информацию о проекте
* Рекомендуемые шаблоны написания кода
* Типовые настройки для проектов вашего типа

<div id="manual-creation">
  ### Создание вручную
</div>

Вы можете создать собственный файл `replit.md`, добавив новый файл с именем `replit.md` в корневой каталог вашего проекта. Agent автоматически обнаружит его и будет использовать в дальнейших беседах.

<Note>
  Чтобы файл `replit.md` работал корректно, он должен находиться в корневом каталоге вашего проекта.
</Note>

<div id="regenerating-replitmd">
  ### Повторное создание `replit.md`
</div>

Если файл `replit.md` повреждён или вы хотите начать с чистого листа:

1. Удалите существующий файл `replit.md` из корневой папки проекта
2. Начните новый диалог с Agent
3. Agent автоматически создаст новый файл `replit.md` на основе вашего текущего проекта

```markdown theme={null}

- Используйте TypeScript для всех новых файлов JavaScript
```

Более подробное руководство по форматированию промптов см. в [руководстве Anthropic по prompt engineering](https://docs.anthropic.com/en/docs/build-with-claude/prompt-engineering/use-xml-tags).

<div id="limitations">
  ## Ограничения
</div>

<div id="file-size-and-content-limits">
  ### Ограничения на размер и содержимое файла
</div>

Строгого ограничения на количество символов в `replit.md` нет, однако очень большие файлы могут обрабатываться не полностью. Для достижения наилучших результатов сохраняйте `replit.md` кратким и по существу.

<div id="root-directory-requirement">
  ### Требование к корневому каталогу
</div>

Файл `replit.md` должен находиться в корневом каталоге проекта. Agent не обнаруживает файлы в подкаталогах автоматически.

<div id="context-scope">
  ### Область контекста
</div>

`replit.md` задаёт контекст для диалогов с Agent, но автоматически не распространяется на другие ИИ-инструменты.

<div id="next-steps">
  ## Дальнейшие шаги
</div>

Готовы настроить Agent под свой проект?

1. **Начните с простого**: создайте базовый `replit.md` с ключевыми предпочтениями
2. **Улучшайте постепенно**: обновляйте `replit.md` по мере работы с Agent
3. **Делитесь наработками**: применяйте удачные конфигурации `replit.md` в похожих проектах
4. **Оценивайте результат**: следите за тем, насколько точно Agent следует вашим указаниям, и корректируйте их

Узнайте больше о [работе с Agent](/ru/features/agent/overview) или познакомьтесь с другими [инструментами ИИ](/ru/welcome).

**Enterprise**: заранее настройте `replit.md` в [пользовательских шаблонах](/ru/teams/custom-templates), чтобы у каждого разработчика в вашей организации был единый стартовый контекст. Рекомендации по дизайну см. в разделе [настройка дизайн-системы](/ru/teams/custom-design-system).
