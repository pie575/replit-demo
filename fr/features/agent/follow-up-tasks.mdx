<div id="follow-up-task-suggestions">
  ## Suggestions de tâches de suivi
</div>

Après avoir appliqué une tâche, Agent examine le contexte de votre projet et vous suggère des **tâches de suivi** à créer ensuite. La boîte de dialogue **Prochaines tâches suggérées** affiche directement la principale recommandation, ce qui vous permet de poursuivre sans quitter le fil principal.

<Frame>
  <img src="/assets/mirror/follow-up-tasks-dialog-c1660cec2d1d.png" alt="Boîte de dialogue Prochaines tâches suggérées affichant une tâche de suivi avec un bouton Démarrer et un lien pour voir plus de tâches dans le tableau des tâches" width="495" height="290" data-path="images/agent/follow-up-tasks-dialog.png" />
</Frame>

Les suggestions de suivi peuvent porter sur :

* **De nouvelles fonctionnalités à créer** : des possibilités qui se marient naturellement avec ce que vous venez de livrer
* **Des améliorations de performance** : des optimisations repérées par Agent pendant qu&#39;il travaillait sur la tâche
* **Des améliorations de l&#39;expérience utilisateur** : des finitions et des ajustements qui parachèvent la fonctionnalité

Sélectionnez **Start** sur une suggestion pour l&#39;envoyer en arrière-plan, ou **View plan** pour examiner d&#39;abord le travail proposé. Pour voir toutes les suggestions, sélectionnez **View more in the task board**. Les suivis suggérés apparaissent sous **Suggested** dans la colonne **Drafts**.

<Frame>
  <img src="/assets/mirror/follow-up-tasks-kanban-21087e0210b6.png" alt="Tableau des tâches affichant de nombreuses suggestions de tâches de suivi sous Suggested dans la colonne Drafts" width="980" height="627" data-path="images/agent/follow-up-tasks-kanban.png" />
</Frame>

Fermer la boîte de dialogue **Prochaines tâches suggérées** annule les suggestions. Agent n&#39;affiche pas cette boîte de dialogue sur la version principale lorsqu&#39;un plan proposé y est déjà en attente, afin que les deux messages ne se disputent pas votre attention.

<div id="managing-many-suggestions-at-once">
  ## Gérer plusieurs suggestions à la fois
</div>

Pour les projets comportant de nombreuses suggestions de suivi, ouvrez le tableau des tâches et sélectionnez **Edit** dans la colonne **Drafts**. En mode édition, une case à cocher apparaît devant chaque tâche suggérée. Sélectionnez les tâches souhaitées, puis utilisez **Start** ou **Cancel** pour appliquer cette action à l&#39;ensemble des tâches sélectionnées. Sélectionnez **Done** pour quitter le mode édition.
