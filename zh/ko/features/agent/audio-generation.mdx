使用 Agent 的音频生成功能，为应用添加声音。让 Agent 创建背景音乐、音效和语音旁白，它会直接将音频添加到项目中。

借助音频生成，无需录音室、配音演员或外部工具，也能打造更丰富的体验。无论是制作游戏、引导式教程，还是需要语音的应用，Agent 都能为您的项目创建合适的音频。

<div id="section">
  ## 可以创建的内容
</div>

Agent 可以生成三类音频：

* **音乐**：符合你所描述氛围和风格的背景音轨及主题音乐。
* **音效**：如点击声、通知声、呼啸而过的声音和游戏音效等短音频片段。
* **语音**：根据你提供的文本生成自然的旁白和配音。

<div id="section-2">
  ## 使用方法
</div>

音频生成功能已内置于 Agent，无需单独启用。打开启用了 Agent 的 Replit 应用，描述您需要的音频即可。Agent 会根据您的请求决定何时生成音频，创建音频片段并将其添加到项目中。

<div id="agent">
  ### Agent 何时生成音频
</div>

当你在项目中请求声音时，Agent 会生成音频：

| 使用场景  | 示例提示词                           |
| ----- | ------------------------------- |
| 背景音乐  | &quot;为我的冥想应用添加舒缓的背景音乐&quot;    |
| 游戏音效  | &quot;为我的游戏制作金币收集音效和跳跃音效&quot;  |
| 语音旁白  | &quot;生成一个亲切的声音，为用户朗读入门步骤&quot; |
| 提醒和通知 | &quot;制作一个收到新消息时播放的简短提示音&quot;  |

<div id="section-4">
  ## 如何将音频集成到应用中
</div>

Agent 会像处理其他资源一样，将生成的音频添加到项目中：

* **自动创建文件**：生成的音频文件会直接保存到项目中。
* **更新代码**：Agent 会将音频接入应用，使其在合适的时机播放。
* **迭代**：让 Agent 调整氛围、时长、声音和风格，即可重新生成音频。

<div id="section-5">
  ## 计费
</div>

音频生成功能属于 Agent 服务。Agent 按提供商费率计费，费用将从 Replit 积分中扣除。计费详情会显示在[使用量页面](/zh/ko/billing/managing-spend)中。

<Note>
  Replit 的音频生成功能由 [ElevenLabs](https://elevenlabs.io/) 驱动，可生成高质量的音乐、音效和语音。
</Note>
