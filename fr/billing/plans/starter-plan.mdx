<div id="what-you-get">
  ## Ce que vous obtenez
</div>

Le forfait Starter vous offre tout le nécessaire pour commencer à créer sur Replit. Créez des apps et publiez votre premier projet — le tout gratuitement.

<div id="daily-credits-for-agent">
  ### Crédits quotidiens pour Agent
</div>

Les utilisateurs du forfait Starter reçoivent chaque jour des crédits pour utiliser Agent, dans la limite d&#39;un plafond mensuel. Ces crédits sont réinitialisés quotidiennement, ce qui vous donne une nouvelle enveloppe pour travailler avec Agent chaque jour.

<div id="monthly-credits-for-cloud-usage">
  ### Crédits mensuels pour l&#39;utilisation du cloud
</div>

Vous recevez également des crédits mensuels utilisables pour :

* [Bases de données (production)](/fr/features/data-and-storage/development-and-production)
* [Object Storage](/fr/features/data-and-storage/object-storage)
* [Publishing (Autoscale, statique)](/fr/learn/projects-and-artifacts/replit-deployments)

Ces crédits sont réinitialisés chaque mois.

<div id="lite-build">
  ### Lite build
</div>

Accès à [Lite build](/fr/features/agent/agent-modes), une expérience de build rapide et ciblée pour effectuer des modifications express et des changements précis avec Agent.

<div id="one-free-published-app">
  ### Une application publiée gratuite
</div>

Bénéficiez de {FreeDeployments} application publiée gratuite, que vous utilisiez Lite Build ou Design Canvas. Ce lien publié expirera automatiquement après 30 jours.

Votre application publiée comportera un badge « Made with Replit » contenant votre lien de parrainage unique. Si un autre utilisateur s’inscrit via ce lien depuis votre badge, vous recevrez des crédits de parrainage après être passé à un forfait payant.

<div id="limitations">
  ## Limitations
</div>

Les fonctionnalités suivantes nécessitent de passer à l’offre Core :

<div id="full-build">
  ### Full build
</div>

[Full build](/fr/features/agent/overview/) permet à Agent de travailler de façon autonome, avec plus de puissance et d&#39;indépendance. Les créateurs disposant du forfait Starter peuvent uniquement utiliser [Lite build](/fr/features/agent/agent-modes). Full build nécessite un forfait Core ou Pro.

<div id="converting-a-design-to-an-artifact">
  ### Convertir un design en artifact
</div>

La conversion d&#39;un design du Design Canvas en artifact complet nécessite Core. Les créateurs disposant du forfait Starter peuvent créer des designs et les publier, mais la conversion en artifact doté de fonctionnalités backend requiert une mise à niveau. Si vous souhaitez créer une app avec des fonctionnalités backend, commencez plutôt par [Lite build](/fr/features/agent/agent-modes).

<div id="third-party-connectors">
  ### Connecteurs tiers
</div>

Les connecteurs externes nécessitent le plan Core. Cela inclut les intégrations avec des services comme Google, Stripe et d&#39;autres API tierces (plus d&#39;informations [ici](https://docs.replit.com/features/integrations/overview#connectors)).

<div id="replit-ai-integrations">
  ### Intégrations Replit AI
</div>

Les [intégrations Replit AI](/fr/features/integrations/replit-ai-integrations) nécessitent le plan Core.

<div id="remove-made-with-replit-badge">
  ### Supprimer le badge « Made with Replit »
</div>

La suppression du badge « Made with Replit » de vos applications publiées nécessite le forfait Core. Le badge reste affiché sur les déploiements des utilisateurs du forfait Starter.

<div id="additional-published-apps">
  ### Applications publiées supplémentaires
</div>

Les utilisateurs du forfait Starter bénéficient de {FreeDeployments} application publiée gratuite. Toute application publiée supplémentaire nécessite un forfait Core ou Pro.

<div id="plan-mode">
  ### Plan Mode
</div>

L&#39;utilisation du Plan Mode nécessite Core. Le Plan Mode vous permet de faire émerger des idées, de planifier votre travail et de collaborer avec Replit Agent sans modifier le code ni les données de votre app.

<div id="all-artifact-types">
  ### Tous les types d&#39;artifacts
</div>

La création de types d&#39;artifacts autres que les applications web et mobiles nécessite Core. Choisissez parmi de nombreux types : visualisations de données, slide decks, vidéos animées, et bien d&#39;autres. Consultez [Projects](/fr/features/projects-and-artifacts/projects).

<div id="upgrading-to-core">
  ## Passer à Core
</div>

Envie d&#39;aller plus loin ? Passez à Core pour débloquer :

* **Plus de stockage et de crédits mensuels**, avec la possibilité de payer à l&#39;usage
* **Un nombre illimité d&#39;applications publiées**, au-delà de la première offerte
* **Le Full build** pour un développement autonome
* **Des connecteurs tiers** pour vous relier à des services externes
* **Intégrations Replit AI** pour utiliser des modèles d&#39;IA sans avoir à gérer vos propres API keys
* **Plan Mode** pour définir les tâches avant de vous lancer dans un build.
* **La suppression du badge Replit** pour un rendu professionnel
* Et bien plus encore
