# General Agent

> Découvrez comment General Agent vous permet de travailler avec n'importe quel framework, de créer n'importe quel type de sortie et de lire et écrire dans des services connectés.

## Qu'est-ce que General Agent ?

General Agent est la façon la plus flexible de travailler avec Replit Agent. Vous n'avez pas besoin de présélectionner un type d'artefact ni de vous engager à construire quelque chose de spécifique. Commencez simplement à discuter — créez un CSV, générez un PDF, recherchez un sujet, ou créez une application complète quand vous êtes prêt.

Concepts clés :

* **Pas de présélection** : Commencez à travailler sans choisir un type d'artefact à l'avance
* **N'importe quelle sortie** : Générez des fichiers (CSV, PDF, documents), effectuez des recherches ou créez des applications
* **Connecteurs** : Lisez et écrivez dans des services externes comme BigQuery, Linear, Slack, Notion, Amplitude, Segment, Hex, et plus encore
* **Divulgation progressive** : Commencez par un chat léger et escaladez naturellement vers une construction d'application complète

## Comment accéder à General Agent

Vous pouvez accéder à General Agent de plusieurs façons :

1. **Sélectionnez « Général » avant d'écrire un prompt** sur la page d'accueil Replit
2. **Ouvrez n'importe quel projet existant** et commencez à discuter avec Agent directement
3. **Choisissez n'importe quel [Framework Développeur](https://replit.com/templates)** — tous les Frameworks Développeur incluent automatiquement General Agent
4. **[Importez](/fr/core-concepts/project-editor/app-setup/import) depuis GitHub** — les projets importés depuis GitHub obtiennent automatiquement General Agent

## Comment utiliser General Agent

### Commencez simplement à discuter

Ouvrez un projet et commencez à parler. Vous n'avez pas besoin de vous engager à construire quoi que ce soit de spécifique — Agent travaille dans le contexte de votre projet actuel et peut gérer tout ce que vous lui soumettez.

**Exemples de prompts :**

* « Résumez les points clés de ce document »
* « Créez un CSV des 100 premières entreprises par chiffre d'affaires »
* « Quels sont mes cinq principaux tickets Linear ? »
* « Configurez un projet Vue.js avec TypeScript »

Agent peut travailler avec des fichiers créés pendant la session, générer des sorties à fichier unique et exécuter du code dans le cadre de son raisonnement — tout cela avant que vous ne décidiez de construire quoi que ce soit.

### Connexion de services externes

Connectez vos outils pour qu'Agent puisse lire et écrire des données directement :

1. Accédez aux **Connecteurs** dans les paramètres de votre projet
2. Connectez vos services (BigQuery, Linear, Slack, Notion, Amplitude, Segment, Hex, et plus encore)
3. Demandez à Agent de lire ou d'écrire des données via ceux-ci

**Exemples de prompts avec connecteurs :**

* « Quels sont les tickets ouverts dans Linear ? »
* « Résumez les messages Slack d'aujourd'hui dans #engineering »
* « Récupérez les données de ventes du mois dernier depuis BigQuery »
* « Montrez-moi les événements à venir dans mon calendrier »
* « Créez un nouveau ticket dans Linear pour le bug d'intégration »
* « Envoyez un résumé à #engineering dans Slack »

### Du chat à l'application complète

Quand vous êtes prêt à construire, il vous suffit de le dire. Agent passe d'un chat léger à la construction de votre application de manière transparente — pas besoin de recommencer ou de changer de contexte.

* « Transforme cela en application web »
* « Crée une application basée sur ces données »
* « Crée un tableau de bord pour ces métriques »
* « Configure un outil CLI Rust »

Vous pouvez commencer de façon informelle — rechercher un sujet, générer un rapport, explorer des données — et escalader vers une construction d'application complète au bon moment.

## Ce que vous pouvez construire

* **Travail de connaissance** : Recherchez, résumez et analysez sans créer d'application
* **Sorties à fichier unique** : CSV, PDF, documents, exports de données et rapports formatés
* **Applications de données** : Interrogez les services connectés et visualisez les résultats dans des tableaux de bord
* **N'importe quel framework ou langage** : Angular, Vue, Svelte, Rust, Go, C#, Python tkinter, jeux Godot, outils CLI, et plus encore
* **Applications full-stack** : Quand vous êtes prêt, construisez une application complète à partir de votre contexte de chat

## À quoi s'attendre

General Agent offre plus de puissance et de flexibilité, ce qui s'accompagne d'une certaine variabilité :

* **Configuration en un coup** : Parfois, Agent configure tout en une seule fois
* **Collaboration itérative** : Les configurations complexes peuvent nécessiter plusieurs cycles de raffinement
* **Limitations technologiques** : Certaines technologies peuvent ne pas être entièrement prises en charge dans l'environnement Nix

<Note>
  Contrairement à l'Agent standard avec des environnements préconfigurés, General Agent configure son propre environnement et ses commandes d'exécution en fonction de votre demande. Vous devrez peut-être lui demander de configurer la publication lorsque vous êtes prêt à déployer.
</Note>

## Foire aux questions

<Accordion title="L'agent peut-il voir mes autres projets ?">
  Non. Chaque chat est contenu dans un seul projet. Vous ne pouvez pas faire communiquer le Projet A et le Projet B entre eux.
</Accordion>

<Accordion title="Pourquoi ne peut-il pas encore accéder à mon outil externe ?">
  Vous devez d'abord connecter vos services via Connecteurs. Une fois connecté, Agent peut lire et écrire via ceux-ci, mais il n'y a pas accès par défaut.
</Accordion>

<Accordion title="Quels connecteurs sont disponibles ?">
  Actuellement pris en charge : BigQuery, Linear, Slack, Notion, Amplitude, Segment, Hex, et plus encore. Des connecteurs supplémentaires sont régulièrement ajoutés.
</Accordion>

<Accordion title="Ai-je besoin de connecteurs pour utiliser General Agent ?">
  Non. Les connecteurs sont optionnels. Vous pouvez utiliser General Agent pour le travail de connaissance, la génération de fichiers et la création d'applications sans aucune connexion externe.
</Accordion>
