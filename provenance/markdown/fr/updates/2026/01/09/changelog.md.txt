### Applications privées pour les comptes gratuits

Les builders sur les comptes gratuits peuvent désormais créer des applications privées. Les limites du niveau gratuit s'appliquent toujours au nombre d'applications que vous pouvez créer.

### Badge « Créé avec Replit »

  <img src="https://replit.com/badge?caption=Made%20with%20Replit" alt="Badge Créé avec Replit" noZoom />

### Nouveaux modèles IA dans les intégrations

La prise en charge des modèles IA récemment lancés est désormais disponible dans les intégrations IA :

| Modèle                       | Description                                                                                                                                                                           |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `gpt-5.2`                    | Le modèle le plus performant d'OpenAI pour le travail de connaissance professionnelle. Premier modèle à dépasser 90 % sur ARC-AGI-1 avec une fenêtre de contexte de 400 000 tokens.   |
| `claude-opus-4.5`            | Le modèle phare d'Anthropic optimisé pour le codage, les agents et l'utilisation informatique. Atteint 80,9 % sur SWE-bench Verified.                                                 |
| `gemini-3-flash-preview`     | Le modèle haute vitesse de Google pour les flux de travail agentiques avec un contexte de 1 million de tokens. Raisonnement proche du niveau Pro avec une latence et un coût réduits. |
| `gemini-3-pro-preview`       | Le modèle multimodal avancé de Google avec un raisonnement de pointe et une connaissance du monde réel.                                                                               |
| `gemini-3-pro-image-preview` | Le modèle Nano Banana Pro de Google pour la génération et la retouche d'images de haute qualité avec un rendu de texte précis.                                                        |
