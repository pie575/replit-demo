本周，我们发布了 Assistant——一款可编辑多个文件并直接应用更改的新 AI 工具。

<Note>
  **更新 (2025 年 12 月) ：** Assistant 已停用。如需快速精准编辑，请使用 [Agent 的 Lite 模式](/zh/core-concepts/agent/agent-modes)。如需规划和讨论，请使用 [Agent 的 Plan 模式](/zh/core-concepts/agent/plan-mode)。
</Note>

Assistant 专为聊天和快速编辑而优化。常见的工作流程是先使用 Agent 创建 MVP，再使用 Assistant 快速编辑。

以下是 Assistant 的一些亮点：

* **轻量：** Assistant 专为聊天和快速编辑而优化，支持编辑多个文件并直接应用更改。
* **提及和截图：** 在提示词中提及文件或 URL。Assistant 会抓取 URL 内容或为您截图。
* **回滚：** Assistant 会自动创建检查点，以差异对比的形式预览编辑内容，并支持一键回滚。
* **灵活性：** Assistant 可在任何 Replit App 中运行，不受技术栈限制。您可以导入现有项目，或使用 Agent 从头开始。
* **更精美的应用：** 改进了对响应式 React 应用的支持，帮助您创建出色的应用。
* **计费更新：** 已取消所有 Agent 使用限制，并增加了订阅包含的积分。

<div id="assistant">
  ### Assistant 功能
</div>

Replit Assistant 是一款专为聊天和快速编辑打造的轻量级 AI 工具。你可以自行编辑多个文件，并直接应用更改。

提供上下文后，Assistant 能发挥更大作用——例如特定功能、文件 (使用 `@file` 提及) 或 URL (直接粘贴) 。

Assistant 可帮助你更快迭代，所用积分约为 Agent 的五分之一。

<div id="section-5">
  ### 快速抓取 / 截图
</div>

使用 **Assistant** 或 **Agent**，你可以截取任何网站的内容或抓取其内容，并将其直接添加到提示词中。

只需粘贴 URL，Replit 就会建议你截取页面截图或抓取页面内容。

和往常一样，你也可以将图片附加到提示词中，或使用 `@file` 提及文件。
