<div id="importar-do-vercel">
  ## Importer depuis Vercel
</div>

⏰ *Temps estimé : trois minutes*

Importez un projet Vercel dans Replit en associant le dépôt GitHub du projet.

Pour découvrir toutes les options d’importation, y compris depuis d’autres plateformes comme GitHub, Figma, Bolt et Lovable, consultez la [documentation de la fonctionnalité d’importation](/fr/pt/references/workspace/import).

<div id="antes-de-comear">
  ## Avant de commencer
</div>

* Un projet Vercel connecté à GitHub
* Un accès au dépôt GitHub associé
* Un compte Replit

<div id="etapas-de-importao">
  ## Étapes d’importation
</div>

1. Ouvrez [replit.com/import](https://replit.com/import).
2. Sélectionnez **Vercel**.
3. Connectez votre compte GitHub.
4. Sélectionnez le dépôt de votre projet Vercel.
5. Ajoutez les Secrets et les variables d’environnement requis.
6. Sélectionnez **Import**.

<div id="o-que-importado">
  ## Éléments importés
</div>

* Fichiers du projet et structure des répertoires
* Configuration des dépendances et du framework
* Commandes d’exécution et de build pour Replit

<div id="o-que-no-importado">
  ## Ce qui n’est pas importé
</div>

* Valeurs existantes des variables d’environnement
* Domaines personnalisés
* Comportement spécifique d’Edge ou du middleware de Vercel
* Configuration externe des analyses ou de la surveillance

<div id="configure-and-run-your-app">
  ## Configurer et exécuter votre application
</div>

Lors de l’importation, {setupDescription_0}. Si votre application doit être modifiée, utilisez les outils suivants dans le Project Editor :

* **[Agent](/fr/features/agent/overview)** : Affinez les fonctionnalités, corrigez les problèmes et modifiez le code
* **[Secrets](/fr/core-concepts/project-editor/app-setup/secrets)** : Ajoutez des clés API et des variables d’environnement
* **[Workflows](/fr/features/workspace-tools/workflows)** : Définissez la commande **Run** de votre application
