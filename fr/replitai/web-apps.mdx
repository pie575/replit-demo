Les applications web sont le type de sortie par défaut sur Replit. Lorsque vous décrivez une idée à Agent, il construit une application web full-stack sauf si vous spécifiez un type d'artefact différent.

## Premiers pas

Il y a deux façons de créer une application web :

* **Tapez une invite** : Décrivez ce que vous voulez construire sur la page d'accueil de Replit. Agent crée automatiquement une application web.
* **Sélectionnez dans le menu déroulant** : Ouvrez le menu déroulant des types d'application sur la page d'accueil et choisissez **Application web**, puis décrivez votre idée.

## Fonctionnalités clés

* **Full-stack par défaut** : Chaque application web inclut un frontend et un backend. Agent configure les routes API, une base de données et la logique côté serveur selon les besoins de votre application.
* **Design responsive** : Les applications s'adaptent automatiquement aux différentes tailles d'écran.
* **Déploiement instantané** : Publiez votre application en un clic. Replit gère l'hébergement, le SSL et l'infrastructure.
* **Infrastructure partagée** : Si votre projet a plusieurs artefacts — comme une application mobile ou un tableau de bord de données — ils partagent tous le même backend, la même base de données et les mêmes services.

## Cas d'usage

* **Produits SaaS** : Construisez des outils, tableaux de bord et plateformes orientés clients.
* **Outils internes** : Créez des panneaux d'administration, CRM ou applications de workflow pour votre équipe.
* **Pages d'atterrissage** : Lancez des sites marketing avec des formulaires, animations et contenu dynamique.
* **Marchés et annuaires** : Construisez des sites d'annonces, tableaux d'offres d'emploi ou plateformes communautaires.
