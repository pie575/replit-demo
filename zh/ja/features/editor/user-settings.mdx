用户设置 (User Settings) 项目编辑器工具提供了自定义账户外观、行为和键盘快捷键的选项。

</Frame>

<div id="section">
  ## 功能
</div>

您可以通过以下设置类别自定义 Replit App 的创建体验：

* **主题自定义**：为项目编辑器选择浅色或深色主题
* **代码智能**：配置 AI 驱动的功能，提升应用创建体验
* **编辑器设置**：调整文件编辑器的行为和外观
* **通知控制**：管理提醒设置
* **无障碍选项**：让有特殊需求的用户更轻松地使用 Replit
* **键盘快捷键**：设置用于执行常见操作和浏览图形界面的组合键

<div id="section-2">
  ## 使用方法
</div>

<Accordion title="如何访问 用户设置">

  1. 选择顶部的<img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" />放大镜图标，打开搜索工具

<div id="section-3">
  ### 外观
</div>

您可以自定义与项目编辑器外观相关的以下设置：

* **主题选择**：可从浅色和深色主题预设、<a href="https://replit.com/themes" target="_blank">社区主题</a>或自定义主题中选择
* **自定义主题**：使用[主题](/zh/ja/features/editor/themes)编辑器创建专属配色方案

<div id="section-4">
  ### 文件编辑器设置
</div>

通过以下设置控制文件编辑器的外观和行为：

* **字体大小**：调整文本大小以提升可读性
* **自动闭合括号**：输入左括号时自动补全对应的右括号
* **缩进检测**：打开文件时自动检测缩进设置
* **粘贴文本缩进格式化**：将粘贴的代码调整为合适的缩进
* **缩进字符**：选择使用空格还是制表符缩进代码
* **缩进大小**：设置每个缩进级别的列数
* **自动换行**：配置行的换行方式
* **缩略图**：在侧边栏显示可导航的代码概览
* **多选修饰键**：设置用于多文件选择的键盘修饰键
* **文件树 Git 状态**：在文件树中显示 Git 状态标识

<div id="section-5">
  ### 代码智能
</div>

通过以下设置配置 AI 驱动的工具：

* **语义标记**：启用由语言服务器增强的语法高亮
* **AI 代码补全**：在您输入时提供内联代码建议
* **提交字符自动接受建议**：输入特定字符时自动接受代码建议

<div id="shellpreview">
  ### Shell 与 Preview 设置
</div>

自定义 Shell 与 Preview 工具的行为：

* **Shell 铃声提示音**：Shell 工具检测到问题时播放提示音
* **自动预览**：服务器可用时自动打开 Preview 标签页
* **自动转发新检测到的端口**：设置如何处理新检测到的端口

<div id="section-6">
  ### 通知
</div>

管理以下通知设置：

* **Agent 声音通知**：Agent 请求反馈时播放提示音
* **Agent 推送通知**：Agent 请求反馈时接收移动端推送通知

<div id="section-7">
  #### 生产环境告警
</div>

**生产环境告警**是一项独立的邮件通知设置，用于告知你已发布应用的运行状态。它与产品和营销邮件互相独立，让你在不受多余干扰的情况下掌握重要信息。

开启**生产环境告警**后，你会在以下情况收到通知邮件：

* **可用性故障**：已发布的应用发生宕机或无法保持在线时，你会收到通知。
* **安全漏洞**：应用所依赖的软件中发现漏洞时，你会收到通知，可在问题出现前及时修复。
* **模型更新**：应用所使用的语言模型发生变更或需要你处理时，你会收到通知。

<Frame>
  <img src="/assets/mirror/production-alerts-highlight-bb76079f20fd.png" alt="通知设置中的生产环境告警部分。生产环境告警邮件的开关和安全告警的严重程度下拉菜单以红色方框突出显示" width="2400" height="1364" data-path="images/workspace/production-alerts-highlight.png" />
</Frame>

查找该设置的方法：

1. 从账户菜单中打开**设置**。
2. 选择**个性化**选项卡。
3. 滚动到**邮件通知**部分，找到**生产环境告警**。

如果已发布的应用使用的是旧版语言模型，Replit 会准备一个升级到受支持模型的草稿任务。你会收到一封包含该任务链接的邮件，只需确认一次即可完成升级。

<div id="section-8">
  ### 无障碍功能
</div>

您可以自定义以下无障碍设置：

* **无障碍终端输出**：为 Shell 和 Console 工具启用屏幕阅读器兼容性

<div id="section-9">
  ### 键盘快捷键
</div>

要访问键盘快捷键设置，请在 用户设置 工具中选择**键盘快捷键**选项卡。

你可以通过以下方式搜索按键组合：

* **名称**：在搜索框中输入键盘快捷键的名称或说明
* **按键组合**：选择 <img class="icon-svg" src="/assets/mirror/keyboard-7ba19771b671.svg" alt="键盘图标" width="16" height="16" data-path="images/icons/keyboard.svg" /> 并输入按键组合

通过以下操作管理快捷键：

* **添加**：选择**添加快捷键**
* **更新**：选择 <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="铅笔图标" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> 铅笔图标
* **删除**：选择 <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="垃圾桶图标" width="16" height="16" data-path="images/icons/trash-icon.svg" /> 垃圾桶图标
