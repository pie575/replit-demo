<div id="soluo-de-problemas">
  ## 故障排除
</div>

* **提及从未送达：**确认已配置 X Bearer Token，且 X 开发者账户中有积分。没有积分时，即使 token 有效，也无法搜索提及。
* **Slack 一片安静，Notion 却不断新增内容：**Agent 可能把所有内容都当成噪声。调整“重要”的判定标准，或让它即使没有需要回复的内容也发布每日摘要。
* **归档内容很混乱：**将 Agent 指向一个包含你已在使用的列 (日期、链接、情感倾向、是否需要回复) 的 Notion 数据库。让它映射到这些字段，而不是每次都创建新页面。
