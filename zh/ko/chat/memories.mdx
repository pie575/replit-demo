借助 Memories，Replit 可以保留有用的上下文，并根据以往的工作进行调整，
你无需每次都重复说明相同的偏好。Replit 会在你工作的过程中记录 Memories，
并让这些内容长期保持有用。

<div id="memories">
  ## 管理 Memories
</div>

<Steps>
  <Step title="打开设置">
    在 Replit 中打开 **设置**。
  </Step>

  <Step title="选择自定义">
    选择 **自定义**。
  </Step>

  <Step title="打开 Memory 标签页">
    在这里，你可以选择是否启用 Memory (之后也可以随时关闭) 、是否与协作者共享，
    以及查看或更新 **Memory file**。Memories 默认为私有，
    协作者共享默认关闭。

<Note>
  Memories 不会保留个人信息或敏感信息。由于 Memory 来自
  工作区活动，Replit 会对其进行安全处理。
</Note>

若想了解何时该使用 Memories、Custom Instructions 或 Skills，请参阅 [Memories、Custom Instructions 和 Skills](/zh/ko/chat/memories-custom-instructions-and-skills)。

<div id="faq">
  ## 常见问题
</div>

<AccordionGroup>
  <Accordion title="Memories 可以保留哪些内容？">
    Memories 保留的是有用的上下文，而不是可执行的指令。User memory 可以保存长期的
    工作区偏好和工作方式。Project memory 可以保存约定、注意事项和修正内容。Custom memory 则是
    由你自行定义的上下文，拥有独立的访问和公开设置。你的明确指示和
    [Custom Instructions](/zh/ko/features/agent/agent-customization)
    的优先级高于 memory。
  </Accordion>

  <Accordion title="Replit 会保留个人信息吗？">
    <Note>
      Memories 不会保留个人信息。User memory 可以保留有用的工作区偏好和
      工作方式，但不会保留敏感特征、第三方个人数据、凭据以及项目机密
      信息。
    </Note>
  </Accordion>

  <Accordion title="可以与他人共享我的 Memories 吗？">
    Memories 默认为私有。是否与协作者共享由你决定，且默认关闭。
    如果你希望 Replit 在其他协作者可编辑的 Project 中使用 Memory，
    请在 **设置 → 自定义 → Memory** 中开启该选项。
  </Accordion>

  <Accordion title="Memories 会应用在哪些范围？">
    User memory 属于单个构建者及其工作区。Project memory 只留在该 Project 中，
    并在相关时被检索。Custom memory 遵循为其设定的访问和公开设置。
    默认情况下，除非你开启协作者共享，否则 Replit 不会在其他协作者可编辑的 Project 中
    使用你的 Memory。
  </Accordion>

  <Accordion title="可以查看、编辑或关闭 Memories 吗？">
    可以。在 **设置 → 自定义 → Memory** 中，你可以选择是否使用 Memory，之后也可以
    随时停用，还可以通过 **Memory file** 查看或更新 Replit 记住的内容。
  </Accordion>
</AccordionGroup>
