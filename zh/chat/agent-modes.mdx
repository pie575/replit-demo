<div id="choose-a-mode">
  ## 选择模式
</div>

* **Free Mode：**探索想法、提出问题、开始构建，让日常工作持续推进。Free Mode 使用智能模型路由来选择模型。{FreeModePlanAvailability}
* **Power Mode：**在速度和能力之间取得智能平衡，适合大多数工作。当 Free Mode 额度不足，或你希望为现有项目选择更强的默认模式时，请使用此模式。
* **Max Mode：**功能最强大的选项，适合处理复杂、雄心勃勃的工作、更大的代码库和更棘手的问题。

Power Mode 和 Max Mode 使用每月积分。在请求从 Free Mode 切换到会产生用量费用的模式前，Replit 会提前通知你。你可以在**设置** → **用量**中查看剩余的 Free Mode 额度。有关实用技巧，请参阅[充分利用 Free Mode](/zh/chat/free-mode)。

Routine 在 Power Mode 或 Max Mode 中运行，且每次运行都需要预算。它们无法在 Free Mode 中运行。详细了解 [Routine](/zh/chat/routines)。
