App Testing permet à l&#39;Agent de tester dans un véritable navigateur les applications qu&#39;il crée. L&#39;Agent navigue dans votre application comme le ferait un vrai utilisateur, en cliquant et en validant les fonctionnalités. Cette capacité d&#39;autotest aide à garantir le bon fonctionnement de votre application et permet à l&#39;Agent de détecter et de corriger les problèmes automatiquement.

Lorsque App Testing est activé, Agent décide périodiquement s&#39;il doit lancer des tests, dès qu&#39;il estime que les modifications sont suffisamment importantes pour le justifier. Agent ne teste pas après 100 % des messages de l&#39;utilisateur : il détermine intelligemment le moment où les tests apporteront le plus de valeur.

<Note>
  Pour l&#39;instant, App Testing est disponible pour les applications web JavaScript Full Stack et les applications web Python Streamlit.
</Note>

<div id="principais-benefcios">
  ### Principaux avantages
</div>

* **Autonomie étendue** : permet à Agent de travailler plus longtemps sans intervention humaine
* **Meilleure qualité** : produit des applications comportant moins d&#39;erreurs grâce à l&#39;identification et à la résolution précoces des problèmes
* **Rentabilité** : évite les sessions de débogage supplémentaires en détectant les problèmes dès la phase de développement
* **Revue interactive** : fournit des rediffusions vidéo et une navigation section par section pour une analyse détaillée des résultats

<div id="o-processo-de-teste">
  ### Le processus de test
</div>

Lorsque l&#39;Agent décide de tester, voici ce qui se passe :

1. **Aperçu du navigateur** : un aperçu du navigateur s&#39;affiche dans le panneau de l&#39;Agent
2. **Test visuel** : observez le curseur de l&#39;Agent pendant qu&#39;il clique dans l&#39;application et en teste les fonctionnalités
3. **Simulation d&#39;un utilisateur réel** : l&#39;Agent navigue dans l&#39;application comme le ferait un véritable utilisateur, en saisissant des données fictives si nécessaire
4. **Analyse automatique** : l&#39;Agent analyse les résultats du test et repère les éventuels problèmes
5. **Autocorrection** : l&#39;Agent présente un résumé des tests et corrige automatiquement les problèmes détectés

<div id="principais-capacidades">
  ## Principales capacités
</div>

Agent teste intelligemment votre application en y naviguant comme le ferait un véritable utilisateur, et couvre ainsi :

* **Validation de l&#39;interface utilisateur** : boutons, formulaires, navigation et éléments visuels
* **Vérification du fonctionnement** : fonctionnalités principales et parcours utilisateur
* **Tests d&#39;intégration** : appels d&#39;API, interactions avec la base de données et services tiers
* **Performances et accessibilité** : temps de chargement, réactivité et normes d&#39;accessibilité

<div id="uso">
  ## Utilisation
</div>

App Testing se trouve dans les **Paramètres avancés**, au sein du menu déroulant des paramètres d&#39;Agent, dans la zone de saisie du chat. Activez-le lorsque vous utilisez le mode Economy ou Power. Le mode Lite laisse App Testing désactivé.

<Note>
  App Testing fait partie des capacités autonomes d&#39;Agent. Pour en savoir plus, consultez la [revue de code](/fr/pt/features/agent/agent-modes#code-review) et les autres [fonctionnalités d&#39;Agent](/fr/pt/features/agent/overview).
</Note>

<div id="assumir-controle">
  ## Prendre le contrôle
</div>

Il arrive qu&#39;Agent rencontre un obstacle pendant les tests et ait besoin de votre aide pour continuer. La plupart du temps, il s&#39;agit de se connecter à un compte utilisateur (Gmail, par exemple). Dans ce cas, Agent affiche un bouton « Prendre le contrôle ».

<Frame>
  <img src="/assets/mirror/app-testing-takeover-6e0b0b56f4d0.png" alt="Interface de prise de contrôle d'App Testing affichant les boutons Ignorer et Prendre le contrôle, avec des instructions pour gérer les erreurs et les CAPTCHA" width="924" height="358" data-path="images/replitai/app-testing-takeover.png" />
</Frame>

Cliquez sur « Prendre le contrôle » pour interagir avec l&#39;aperçu de test, effectuer les étapes nécessaires, puis laisser Agent poursuivre. Vous pouvez également cliquer sur « Ignorer » pour refuser la prise de contrôle, ce qui met fin à App Testing si Agent ne peut pas continuer sans votre aide. Sans réponse de votre part dans les 10 minutes, Agent poursuit comme si vous aviez cliqué sur « Ignorer ».

<div id="o-que-esperar">
  ### À quoi s&#39;attendre
</div>

* **Option pour ignorer** : utilisez le bouton Ignorer pour passer les tests si nécessaire et poursuivre le développement
* **Relecture vidéo interactive** : une fois les tests terminés, cliquez sur la vidéo pour rejouer l&#39;intégralité de la session de test
* **Navigation par section** : utilisez les curseurs situés en bas pour accéder à des sections précises du test

<div id="soluo-de-problemas">
  ## Dépannage
</div>

**Tests qui échouent de manière inattendue**

* Essayez d&#39;ignorer le test, puis de le relancer
* Vérifiez la présence de contenu dynamique susceptible d&#39;influencer le déroulement des tests
* Vérifiez l&#39;exactitude des scénarios de test

**Couverture de test manquante**

* Fournissez des descriptions plus détaillées des fonctionnalités de votre application
* Mentionnez explicitement les parcours utilisateur critiques à tester

**App Testing ne fonctionne pas ?**

* App Testing ne fonctionne pour l&#39;instant qu&#39;avec les applications web[*](#how-app-testing-works)

<div id="preos-e-uso">
  ## Tarification et utilisation
</div>

App Testing est inclus dans le modèle de tarification à l&#39;effort de l&#39;Agent, avec quelques points importants à connaître concernant les coûts :

* **Basé sur l&#39;utilisation** : les tests sont facturés en fonction de l&#39;effort fourni (les tests les plus simples coûtent moins cher)
* **Coût et bénéfice** : les tests ont certes un coût, mais ils peuvent vous faire économiser en détectant les erreurs plus tôt, ce qui évite des prompts supplémentaires et du travail additionnel de l&#39;Agent
* **Développement efficace** : l&#39;approche automatisée réduit le besoin de débogage manuel et de reprises

<Tip>
  **Des tests économiques** : App Testing augmente certes vos coûts d&#39;utilisation, mais il permet généralement de faire des économies au global, en évitant des sessions supplémentaires de l&#39;Agent pour corriger des problèmes qui auraient pu être détectés lors des tests.
</Tip>
