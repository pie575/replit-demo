<div id="what-are-artifacts">
  ## 什么是 artifact？
</div>

artifact 是你可以在 Replit 上发布的成果，例如：web app、移动应用、幻灯片、动画、数据应用、3D 游戏和设计。每个 artifact 都是完整、独立的产出，发布后会获得专属的可分享 URL。

project 中的其他内容——文件、图片、CSV、代码——都是为 artifact 服务的，无法单独发布。

  ## 你可以创建什么
</div>

| 类型                                                        | 简介                              |
| --------------------------------------------------------- | ------------------------------- |
| **[Web app](/zh/features/artifact-types/web-apps)**          | 美观且强大的网站，可处理用户、数据库等。            |
| **[移动应用](/zh/features/artifact-types/building-mobile-apps)** | 面向 iPhone 和 Android 手机的原生应用。    |
| **[幻灯片](/zh/features/artifact-types/slide-decks)**           | 可直接演示或导出的演示文稿。                  |
| **[动画](/zh/features/artifact-types/animated-videos)**        | motion graphics 和动画视频，可导出为 MP4。 |
| **[数据可视化](/zh/features/artifact-types/data-apps)**           | 交互式仪表板与可视化内容，用于探索数据和创建图表。       |
| **3D 游戏**                                                 | 3D 游戏、仿真和互动体验。                  |
| **[Design](/zh/design/canvas)**                              | 在 Canvas 上探索视觉方向并快速构建创意原型。      |

各套餐的支持情况，请查看对应类型的专属页面。

<div id="getting-started">
  ## 开始使用
</div>

在 Replit 首页有两种创建方式：

* **直接描述**：输入你想要的内容——比如&quot;帮我做一个菜谱应用&quot;或&quot;为我的创业公司做一份路演演示文稿&quot;。Agent 会自动判断适合的类型并完成构建。
* **选择类型**：先选择你想要的 artifact——web app、移动应用、数据可视化、动画、3D 游戏或其他受支持的类型——再描述你的想法。

你也可以随时在 Chat 中向 Agent 提出需求，或点击 Preview 面板中的 **+** 按钮，为现有 project 添加更多内容。

<div id="switching-between-artifacts">
  ## 在 artifact 之间切换
</div>

当一个 project 中有多个 artifact 时，你可以在 **Preview 面板**或 **Library 侧边栏**中切换。你也可以直接告诉 Agent——比如“给我看看移动应用”或“切换到幻灯片”。

<div id="library-sidebar">
  ### 素材库侧边栏
</div>

素材库侧边栏是你集中浏览 project 中所有内容的入口，会显示你的 artifact、Agent 生成或下载的图片以及其他 project 资源。从左侧面板打开素材库侧边栏，即可查找任意资源并在整个 project 中复用。

<div id="multiple-artifacts-in-one-project">
  ## 一个 project 中的多个 artifact
</div>

单个 project 最多可容纳 **7 个 artifact**，其中移动应用最多 **1 个**。例如，你可以在同一个 project 中构建面向客户的 web app、面向团队的移动应用，以及面向投资人的幻灯片。

<ArtifactGrid />

<div id="adding-artifacts-to-a-project">
  ### 向 project 添加 artifact
</div>

有三种方式可以向现有 project 添加 artifact：

* **Chat**：向 Agent 提出需求 —— “为这个 project 添加一个移动应用”或“为投资人路演制作一个幻灯片”
* **加号按钮**：点击 Preview 面板中的 **+** 按钮，选择你想构建的内容
* **素材库侧边栏**：浏览你已有的 artifact、图片和其他资源，并从这里添加新的 artifact

<div id="shared-data-and-backend">
  ### 共享数据与后端
</div>

当多个 artifact 位于同一个 project 中时，它们会自动共享同一套数据和后端逻辑。如果客户通过你的 web app 下单，你的移动应用和数据仪表板同样能看到这笔订单。你无需配置任何连接，也不用重复编写代码——一切开箱即用。

<Note>
  发布 会一次性将整个 project 发布上线。所有 artifact 同时上线，因此始终保持同步。
</Note>

<div id="example-combinations">
  ### 组合示例
</div>

* **web app + 移动应用**：一家餐厅同时拥有面向顾客的 web app 和供员工使用的移动应用——两者连接同一个 API 和数据库
* **应用 + 管理后台**：主产品搭配一个用于管理内容、用户或设置的内部管理面板
* **应用 + 幻灯片**：产品与路演演示文稿放在同一个 project 中，幻灯片始终与最新版本保持一致
* **数据仪表板 + 视频**：实时数据可视化搭配一段动画视频，逐一讲解其中的亮点

<div id="publishing">
  ## 发布
</div>

应用、幻灯片和视频都可以发布并分享。每一项发布后都会获得专属的可分享 URL。

不属于 artifact 的文件和资源 (如 CSV、图片或 markdown 文件) 无法单独发布。如需分享，请将其添加到某个应用中，或创建一个新的 artifact。

<div id="frequently-asked-questions">
  ## 常见问题
</div>

<Accordion title="一个 project 可以包含多个 artifact 吗？">
  可以。单个 project 最多可包含 **7 个 artifact**，其中**每个 project 限 1 个移动应用**。project 中的所有 artifact 会自动共享同一套后端和数据。

  如果已达到移动应用数量上限，但你还想再 构建 一个移动应用，请在新的 project 中创建。如果已达到 7 个 artifact 的上限，请先移除一个现有 artifact 再添加新的，或者将工作拆分到多个 project 中。
</Accordion>

<Accordion title="开始之前必须先选好类型吗？">
  不必。只需描述你想要什么，Agent 会为你选择合适的类型。你也可以在下拉菜单中手动选择类型。
</Accordion>

<Accordion title="我可以只发布 project 中的某一个 artifact 吗？">
  目前不行。发布 会将整个 project 一并上线，因此所有 artifact 始终保持同步。如果需要单独发布，请使用不同的 project。
</Accordion>

<Accordion title="各个 artifact 之间会共享数据吗？">
  会。project 中的所有 artifact 共享同一个数据库和后端服务。如果你的 web app 写入了数据，移动应用和数据仪表板可以立即读取。
</Accordion>

<Accordion title="artifact 和文件有什么区别？">
  artifact 是可以发布的成果——应用、幻灯片和视频。文件 (例如 CSV、图片或代码) 是 project 内为 artifact 提供支撑的资源，无法单独发布。
</Accordion>

<Accordion title="我的移动应用缺少 web app 中的部分功能，这是怎么回事？">
  Agent 在不同 artifact 类型之间转换功能时，有些内容可能无法完美迁移——尤其是在不同平台上表现方式不同的交互或布局。你可以在 Chat 中继续追问，把缺失的部分补齐。
</Accordion>

如需查看可 构建 内容的完整列表，请参阅 [Projects 概览](/zh/features/projects-and-artifacts/projects)。
