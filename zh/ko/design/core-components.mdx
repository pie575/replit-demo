Replit Design 的核心是一块用于展示框架的无限 Canvas。本页面其余部分将介绍如何使用这些框架：

* 在无限画板上创建和摆放设计框架
* 通过聊天、建议和工具栏持续完善每个框架
* 选中框架的任意部分，仅修改该部分
* 无需离开画板，即可获取模板和真实产品的设计灵感

Replit Design 工作区由七个部分组成：

* **[Canvas](/zh/ko/design/canvas)**：Project Editor 中的设计视图，是可容纳所有 框架、形状和注释的无限画板，支持平移和缩放。
* **[Frames](/zh/ko/design/frames)**：Canvas 上的所有图块。框架 可以是实时工件 (如网站、幻灯片) 、设计稿、图片、视频或矢量图形。
* **[元素](/zh/ko/design/elements)**：框架 中的独立部分，例如标题、按钮、图片和表单字段。
* **[Chat](/zh/ko/design/chat-about-your-design)**：停靠在 Canvas 上的 Agent 聊天。描述你想创建的内容，或选择一个 框架，请求小幅或大幅修改。要查看整个 Canvas，请将其最小化。
* **[环境智能](/zh/ko/design/explore-suggestions)**：显示在所选 框架 旁的建议后续步骤，每项只需点击一下即可生成新的方向。有关其工作原理，请参阅 [探索建议](/zh/ko/design/explore-suggestions)。
* **[工具栏](/zh/ko/design/toolbar)**：悬浮在 Canvas 底部，包含 Interact、Pan、Chat、Draw、Edit 和 Generate 工具。
* **[素材库面板](/zh/ko/design/library-panel)**：提供可直接放置到 Canvas 上的入门模板、Mobbin 精选的灵感，以及你之前的创作。

<div id="section-2">
  ## 协同工作方式
</div>

每个组件都承接前一个组件的工作，让你从空白画板开始，打造可构建的设计。

<div id="1">
  ### 1. 在画布中放置框架
</div>

通过聊天提示词或工具栏中的 **Generate** 菜单创建框架。框架可以是设计稿、Web 应用、移动应用、幻灯片、图片、视频或矢量图形。

<div id="2">
  ### 2. 反复完善 框架
</div>

选择一个 框架，逐个进行调整。你可以用自己的话在聊天中描述需求，或者根据[建议](/zh/ko/design/explore-suggestions)探索新的方向，也可以使用 **Focus** 近距离细化。准备就绪后，使用 **Build** 将其构建为可上线的应用。

<Frame caption="选中的 框架 及其操作栏：Build、Focus 和其他选项。">
  <img src="/assets/mirror/canvas-frame-action-bar-86f90fdd1375.png" alt="Canvas 中选中了 APEX X1 Design 框架，顶部的 框架 专属操作栏包含类型标签以及 Build、Focus 和其他操作选项，聊天提示词框中以标签形式附加了该 框架" width="2000" height="1290" data-path="images/replitai/canvas-frame-action-bar.png" />
</Frame>

<div id="3">
  ### 3. 使用工具栏进行编辑、添加注释和生成内容
</div>

工具栏提供三类操作：**Edit** 用于选择框架中的单个元素并打开 Visual Editor；**Draw** 可通过草图、箭头和便签在画板上添加注释，供 Agent 读取；**Generate** 可生成设计所需的图像、视频和矢量图形。

<Frame caption="使用 Edit 工具选中元素，右侧打开 Visual Editor。">
  <img src="/assets/mirror/canvas-edit-67fe5ee02fbe.png" alt="在超级跑车租赁网站中选中 div 元素时激活的 Edit 工具，以及包含 Text、Layout、Color、Border 控件和 Discard、Save edits 按钮的 Visual Editor 面板" width="2000" height="1269" data-path="images/replitai/canvas-edit.png" />
</Frame>

<div id="4">
  ### 4. 从素材库面板汲取灵感
</div>

打开素材库面板，获取灵感并找到起点。模板会以可运行、可编辑的 框架 形式添加到 Canvas 中，而由 Mobbin 精选的灵感内容则会以静态参考图片的形式添加，用于引导下一次生成。

<Frame caption="素材库面板的 Templates 标签：按类型分组、可搜索的起始 框架。">
  <img src="/assets/mirror/library-templates-5407d3683e8a.png" alt="素材库面板的 Templates 标签，包含搜索框、类别筛选器，以及展示海报和两个着陆页的模板卡片" width="665" height="583" data-path="images/design/replit-design/library-templates.png" />
</Frame>
