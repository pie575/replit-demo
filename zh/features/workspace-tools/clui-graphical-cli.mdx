CLUI (命令行用户界面) 是 Replit 的交互式命令栏，让您无需浏览菜单即可快速执行各种操作。它兼具命令行的效率和图形界面的直观性。

<div id="features">
  ## 功能
</div>

CLUI 在 Replit 中提供覆盖三种不同场景的强大命令式交互：

* **设置管理**：管理设置、查看警告，以及恢复已删除的 Replit Apps
* **快速导航**：在 Replit Apps 之间切换，并通过快捷方式访问常用功能
* **Workspace 操作**：在开发环境中查找文件、搜索代码和访问工具

<div id="usage">
  ## 使用
</div>

<div id="account-clui">
  ### Account CLUI
</div>

Account CLUI 可帮助你管理设置、团队以及已删除的 Replit Apps。

**访问方式**：前往 [CLUI 页面](https://replit.com/~/cli)，在输入框中输入以搜索命令，然后按 Enter 执行。

<Accordion title="账户命令">
  输入 `account` 来管理设置：

  * **view-warns**：查看收到的警告
  * **change-username**：更改用户名 (仅可更改一次) 
</Accordion>

<Accordion title="回收站命令">
  输入 `trash` 来管理已删除的 Replit Apps：

  * **restore &lt;title&gt;**：按标题恢复已删除的 Replit App (如果有多个同名 App，则恢复最近删除的一个) 
  * **view**：查看最近删除的 Replit Apps
</Accordion>

<Accordion title="团队命令">
  输入 `team` 来管理团队：

  * **view**：通过团队用户名查看你所在团队的成员
  * **fork-repl-to-project**：复刻现有 Replit App，创建团队 Project
</Accordion>

<Accordion title="清除命令">
  输入 `clear` 以清除屏幕上此前执行过的所有命令
</Accordion>

<div id="shortcuts-clui">
  ### 快捷命令 CLUI
</div>

快捷命令 CLUI 可让你从任何页面快速访问常用的 Replit 功能。

<Frame>
  <img src="/assets/mirror/shortcuts-clui-768d49b44785.png" alt="快捷命令 CLUI" width="689" height="291" data-path="images/getting-started/shortcuts-clui.png" />
</Frame>

**访问方式**：按 **CMD/CTRL + K**，或点击大多数 Replit 页面顶部导航栏中的搜索图标。

<Accordion title="可用命令">
  * **搜索**：在 Replit 中搜索 Replit Apps、模板、代码、用户等
  * **新建**：创建新的 Replit App
  * **我的 Replit Apps**：浏览并打开你的 Replit Apps
  * **我的代码**：搜索所有 Replit Apps 中的代码
</Accordion>

<div id="workspace-clui">
  ### Workspace CLUI
</div>

Workspace CLUI 可帮助你在 Replit App 中工作时执行操作、使用工具、查找文件和搜索代码。

<Frame>
  <img src="/assets/mirror/ws-clui-81764b3d111b.png" alt="Workspace CLUI" width="429" height="202" data-path="images/getting-started/ws-clui.png" />
</Frame>

**访问方式**：在 Workspace 中按 **CMD/CTRL + K**，或点击左上角的搜索图标。

<Accordion title="常用操作">
  * **查找文件**：快速定位项目中的文件
  * **搜索代码**：在所有文件中查找特定代码片段
  * **使用工具**：打开 Workspace 中可用的任意工具或面板
  * **运行命令**：执行 workspace 专用命令
</Accordion>
