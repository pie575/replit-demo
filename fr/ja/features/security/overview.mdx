Une fois publié depuis Replit, votre projet peut recevoir du trafic réel. Les outils de sécurité de Replit vous permettent de détecter les vulnérabilités, de corriger les problèmes acceptés avec Agent et de conserver des preuves à des fins d&#39;audit.

<div id="section">
  ## Pourquoi la sécurité est essentielle
</div>

* Les projets publiés sont accessibles depuis Internet, y compris leurs routes et API publiques.
* Les projets modernes dépendent de nombreux paquets, et de nouvelles CVE peuvent apparaître après la publication.
* Le code généré par l&#39;IA nécessite lui aussi une revue de sécurité, en particulier concernant l&#39;authentification, les requêtes de base de données, les secrets et le traitement des données.
* Les programmes de conformité exigent souvent un inventaire des dépendances, un suivi des vulnérabilités et des preuves de correction.

<div id="section-2">
  ## Par où commencer
</div>

* Vous installez des paquets ? Le [Package Firewall](/fr/ja/features/security/package-firewall) bloque les dépendances malveillantes dès l&#39;installation (activé par défaut).
* Si vous travaillez sur un seul projet, utilisez le [Centre de sécurité du projet](/fr/ja/features/security/project-security-center).
* Pour auditer l&#39;ensemble de votre workspace, utilisez le [Centre de sécurité du workspace](/fr/ja/features/security/workspace-security-center).
* Pour choisir l&#39;emplacement d&#39;exécution de vos ressources de développement, consultez [Géographie du workspace](/fr/features/collaboration/workspace-geography). Pour choisir l&#39;emplacement d&#39;exécution de vos projets publiés, consultez [Géographie du projet](/fr/ja/features/publishing/project-geography).
* Si vous cherchez des définitions, consultez [Concepts de sécurité](/fr/ja/features/security/concepts).

Les outils de sécurité de Replit protègent différentes étapes du cycle de vie de votre application et fonctionnent de concert :

* **À l&#39;installation** : le [Package Firewall](/fr/ja/features/security/package-firewall) bloque les paquets malveillants ou compromis avant leur téléchargement.
* **Après l&#39;installation** : l&#39;[analyse automatique des dépendances](/fr/ja/features/security/project-security-center#automatic-dependency-scans) détecte les CVE nouvellement divulguées, et Auto-Protect peut préparer un correctif via Agent.
* **Avant la publication** : le [Security Agent](/fr/ja/features/security/agent-security-scans) audite votre base de code à la recherche de vulnérabilités liées au code, aux dépendances et à la confidentialité.

La plupart des tâches de sécurité suivent la même boucle : analyser, examiner les résultats, corriger avec Agent, republier et, si nécessaire, exporter les éléments probants.

<div id="section-3">
  ## La sécurité au sein du produit
</div>

<div id="section-4">
  ### Dans un projet
</div>

Dans le volet **Tools** d&#39;un projet, sélectionnez **Security Center** pour consulter les résultats au niveau du projet, lancer les analyses de sécurité d&#39;Agent et vérifier les vulnérabilités des dépendances avant publication.

Utilisez les [analyses de sécurité d&#39;Agent](/fr/ja/features/security/agent-security-scans) pour examiner votre code source. Si vous devez inspecter votre application en cours d&#39;exécution depuis l&#39;extérieur, utilisez les [tests d&#39;intrusion en boîte noire Level 3](/fr/ja/features/security/black-box-pen-tests).

<div id="section-5">
  ### Dans le workspace
</div>

Depuis la barre latérale d&#39;accueil, sélectionnez **Security** pour passer en revue les vulnérabilités de l&#39;ensemble de vos projets, hiérarchiser les constats selon leur niveau d&#39;exposition et suivre l&#39;historique des analyses au niveau du workspace.

<div id="section-6">
  ### Publication et paramètres
</div>

* Dans **Publish** &gt; **Advanced**, utilisez **Block publishing of critical vulnerabilities** pour bloquer la mise en production lorsque des constats critiques sont détectés.
* Dans **Settings** &gt; **Account** &gt; **Advanced**, définissez le seuil de gravité Auto-Protect pour les correctifs de dépendances préparés par l&#39;Agent.
