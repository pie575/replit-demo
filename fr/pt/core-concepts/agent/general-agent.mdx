<div id="o-que-o-agent-geral">
  ## Qu’est-ce que l’Agent général ?
</div>

L’Agent général est le mode le plus flexible pour travailler avec Replit Agent. Vous n’avez pas besoin de présélectionner un type d’artefact ni de vous engager à créer quelque chose de précis. Commencez simplement à échanger avec lui : créez un CSV, générez un PDF, faites des recherches sur un sujet ou créez une application complète lorsque vous êtes prêt.

Concepts clés :

* **Sans présélection** : Commencez à travailler sans choisir à l’avance un type d’artefact
* **Tout type de résultat** : Générez des fichiers (CSV, PDF, documents), effectuez des recherches ou créez des applications
* **Connecteurs** : Lisez et écrivez dans des services externes tels que BigQuery, Linear, Slack, Notion, Amplitude, Segment, Hex et bien d’autres
* **Divulgation progressive** : Commencez par un chat simple, puis passez naturellement à la création d’une application complète

<div id="como-acessar-o-agent-geral">
  ## Comment accéder à l’Agent général
</div>

Vous pouvez accéder à l’Agent général de plusieurs façons :

1. **Sélectionnez « Général » avant de saisir un prompt** sur la page d’accueil de Replit
2. **Ouvrez n’importe quel projet existant** et commencez à discuter directement avec l’Agent
3. **Choisissez un [framework de développement](https://replit.com/templates)** — tous les frameworks de développement incluent automatiquement l’Agent général
4. **[Importez](/fr/pt/core-concepts/project-editor/app-setup/import) depuis GitHub** — les projets importés depuis GitHub bénéficient automatiquement de l’Agent général

<div id="como-usar-o-agent-geral">
  ## Comment utiliser l’Agent général
</div>

<div id="apenas-comece-a-conversar">
  ### Commencez simplement à échanger
</div>

Ouvrez un projet et commencez à échanger. Vous n’avez pas besoin de vous engager à créer quelque chose de précis : Agent travaille dans le contexte de votre projet actuel et peut répondre à tous vos besoins.

**Exemples de prompts :**

* « Résumez les points clés de ce document »
* « Créez un CSV des 100 principales entreprises par chiffre d’affaires »
* « Quels sont mes cinq principaux tickets Linear ? »
* « Configurez un projet Vue.js avec TypeScript »

Agent peut travailler avec des fichiers créés pendant la session, générer des fichiers uniques en sortie et exécuter du code dans le cadre de son raisonnement, avant même que vous décidiez de créer quoi que ce soit.

<div id="conectando-servios-externos">
  ### Connexion à des services externes
</div>

Connectez vos outils pour que l’Agent puisse lire et écrire directement des données :

1. Accédez à **Connecteurs** dans les paramètres du projet
2. Connectez vos services (BigQuery, Linear, Slack, Notion, Amplitude, Segment, Hex, etc.)
3. Demandez à l’Agent de lire ou d’écrire des données via ces services

**Exemples de prompts avec des connecteurs :**

* &quot;Quels tickets sont ouverts dans Linear ?&quot;
* &quot;Résume les messages Slack d’aujourd’hui dans #engineering&quot;
* &quot;Récupère dans BigQuery les données de ventes du mois dernier&quot;
* &quot;Montre-moi les prochains événements de mon calendrier&quot;
* &quot;Crée un nouveau ticket dans Linear pour le bug d’intégration&quot;
* &quot;Envoie un résumé dans #engineering sur Slack&quot;

<div id="do-chat-ao-aplicativo-completo">
  ### Du chat à l’application complète
</div>

Lorsque vous êtes prêt à créer votre application, dites-le. Agent passe naturellement d’un chat informel à la création de votre application, sans avoir à recommencer ni à changer de contexte.

* « Transforme ceci en application web »
* « Construis une application à partir de ces données »
* « Crée un dashboard pour ces métriques »
* « Configure un outil CLI en Rust »

Vous pouvez commencer de façon informelle — rechercher un sujet, générer un rapport, explorer des données — puis passer à la création d’une application complète au moment opportun.

<div id="o-que-voc-pode-construir">
  ## Ce que vous pouvez créer
</div>

* **Travail de connaissance** : recherchez, résumez et analysez sans créer d’application
* **Fichiers uniques en sortie** : CSV, PDF, documents, exportations de données et rapports mis en forme
* **Applications de données** : interrogez des services connectés et visualisez les résultats dans des tableaux de bord
* **N’importe quel framework ou langage** : Angular, Vue, Svelte, Rust, Go, C#, Python tkinter, jeux Godot, outils CLI et bien plus encore
* **Applications full-stack** : lorsque vous êtes prêt, créez une application complète à partir du contexte de votre Chat

<div id="o-que-esperar">
  ## À quoi s&#39;attendre
</div>

L&#39;Agent général offre davantage de puissance et de flexibilité, avec une certaine variabilité :

* **Configuration en une seule fois** : l&#39;Agent peut parfois tout configurer d&#39;un seul coup
* **Collaboration itérative** : les configurations complexes peuvent nécessiter plusieurs cycles d&#39;ajustement
* **Limites technologiques** : certaines technologies peuvent ne pas être entièrement prises en charge dans l&#39;environnement Nix

<Note>
  Contrairement à l&#39;Agent standard, qui utilise des environnements préconfigurés, l&#39;Agent général configure son propre environnement et exécute des commandes selon votre demande. Vous devrez peut-être lui demander de configurer la publication lorsqu&#39;il sera prêt à déployer.
</Note>

<div id="perguntas-frequentes">
  ## Questions fréquentes
</div>

<Accordion title="L’Agent peut-il voir mes autres projets ?">
  Non. Chaque chat est associé à un seul projet. Vous ne pouvez pas faire communiquer le projet A et le projet B entre eux.
</Accordion>

<Accordion title="Pourquoi n’a-t-il toujours pas accès à mon outil externe ?">
  Vous devez d’abord connecter vos services via les connecteurs. Une fois connectés, l’Agent peut y lire et y écrire, mais il n’y a pas accès par défaut.
</Accordion>

<Accordion title="Quels connecteurs sont disponibles ?">
  Actuellement pris en charge : BigQuery, Linear, Slack, Notion, Amplitude, Segment, Hex et bien d’autres. De nouveaux connecteurs sont ajoutés régulièrement.
</Accordion>

<Accordion title="Ai-je besoin de connecteurs pour utiliser l’Agent général ?">
  Non. Les connecteurs sont facultatifs. Vous pouvez utiliser l’Agent général pour le travail de connaissance, la génération de fichiers et la création d’applications sans connexion externe.
</Accordion>
