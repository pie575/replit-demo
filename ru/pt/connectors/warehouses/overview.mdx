Коннекторы к хранилищам данных позволяют Replit Agent безопасно выполнять запросы к хранилищам данных вашей организации. Разработчики могут использовать естественный язык для создания дашбордов, инструментов отчётности и приложений для работы с данными — без знания SQL. Администраторы сохраняют централизованный контроль с помощью ролевого доступа.

<div id="warehouses-suportados">
  ## Поддерживаемые хранилища данных
</div>

Коннекторы к хранилищам данных доступны в планах **Enterprise**.

| Хранилище данных | Руководство по настройке                                                                                                                    |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| BigQuery         | Уже доступно — руководство по настройке готовится                                                                                           |
| Databricks       | [Подключение Databricks](/ru/pt/connectors/warehouses/databricks)                                                                              |
| Microsoft Fabric | [Создание приложений для работы с данными в Microsoft Fabric](/ru/pt/connectors/warehouses/microsoft-fabric) (закрытая предварительная версия) |
| Snowflake        | [Подключение Snowflake](/ru/pt/connectors/warehouses/snowflake)                                                                                |

Для каждого хранилища данных предусмотрен свой процесс настройки, поскольку различаются интеграция OAuth, модель идентификации и формат учетных данных. Выберите используемое хранилище данных и следуйте соответствующему руководству.

<div id="plataformas-de-anlise-e-dados">
  ## Платформы аналитики и данных
</div>

Коннекторы для аналитики доступны в тарифах Core, Pro и Enterprise. Подключите инструменты аналитики, чтобы Agent мог читать и обрабатывать данные вашего продукта:

* **Segment** — данные клиентов, потоки событий и сегменты аудитории из вашей CDP
* **Amplitude** — аналитика продукта, данные о поведении пользователей и метрики вовлечённости
* **Hex** — совместные блокноты данных и результаты запросов

Управляйте ими так же, как и другими коннекторами Replit. См. [Управление коннекторами](/ru/pt/replitai/managing-connectors).

<div id="como-funcionam-os-conectores-de-warehouse">
  ## Как работают коннекторы к хранилищам данных
</div>

Настройка выполняется один раз и включает три роли:

1. **Администратор хранилища данных** — Создаёт интеграцию OAuth или служебную учётную запись в хранилище данных
2. **Администратор организации Replit** — Добавляет учётные данные в Replit и настраивает доступ
3. **Разработчик** — Входит в систему и начинает создавать приложения с Agent

После настройки разработчики могут попросить Agent использовать хранилище данных, и Agent будет писать и выполнять в нём SQL-запросы.

<div id="criando-com-dados-de-warehouse">
  ### Создание приложений на основе данных из хранилища
</div>

После подключения вы можете попросить Agent создать приложения, использующие ваши данные. Agent может:

* Создавать внутренние инструменты для получения и отображения данных в реальном времени
* Создавать дашборды с графиками и визуализациями на основе данных из вашего хранилища
* Генерировать SQL-запросы для бэкенда вашего приложения
* Объяснять структуру схем и таблиц, чтобы помочь вам понять, что можно создать

<Note>
  Хотя Agent может отвечать на отдельные вопросы о ваших данных, основное назначение коннекторов к хранилищу данных — позволить Agent создавать функциональные приложения, использующие данные вашей организации. Запросы к хранилищу выполняются непосредственно в вашем экземпляре, поэтому убедитесь, что области действия OAuth и разрешения пользователя базы данных позволяют выполнять необходимые операции чтения и записи.
</Note>
