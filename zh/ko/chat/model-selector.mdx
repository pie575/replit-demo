智能模型路由可让 Replit 为任务选择合适的模型。如需手动选择，请在提示词框中选择 **Agent Mode**，再选择 **Power** 或 **Max**，然后在 **Primary model** 部分选择模型。

Free Mode 始终使用智能模型路由。Core 和 Pro 用户可以选择 Power Mode 或 Max Mode 中可用的模型。模型可用性可能有所变化，请以 Replit 为您的账户提供的模型列表为准。

<div id="effort">
  ## 设置模型的 Effort
</div>

Effort 用于控制所选模型在生成响应时投入多少推理。它不是独立模式，而是针对各模型的控制项。支持的级别从 **低** 到 **Max**，每个模型都会显示推荐设置。

仅在任务需要更深入推理时使用更高的 Effort。对于复杂任务，较高设置可能需要更长时间，且成本更高。
