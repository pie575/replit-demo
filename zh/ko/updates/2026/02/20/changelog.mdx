<div id="pro">
  ## Pro 方案发布
</div>

Replit Pro 现已推出，Core 也带来了更超值的体验。我们对各方案做了梳理，让定位更清晰、更贴合实际用途：

* **Replit Pro**：为专业构建者打造——Turbo 模式 (Agent 速度提升 2.5 倍，独立开关) 、可结转的分层积分、最多 15 名构建者且无需按席位付费、优先支持、4 倍数据保留时长。[了解 Pro](/zh/ko/billing/plans/replit-pro)。
* **Core**：可免费邀请最多 5 名协作者。当前 Core 价格请参阅[价格页面](https://replit.com/pricing)。
* **Teams 方案下线**：Teams 由 Pro 取代。现有 Teams 客户将在剩余订阅期内免费升级至 Pro。迁移将于 {TeamsMigrationDate} 开始。[详情与时间安排](https://blog.replit.com/pro-plan)。
* **Agent 模式**：可选择 **Economy** (成本优先) 或 **Power** (性能优先) 。**Turbo** 为独立开关 (仅限 Pro/Enterprise，速度提升 2.5 倍) 。[Agent 模式指南](/zh/core-concepts/agent/agent-modes)。
* **Fast 模式更名为 Lite 模式**：功能不变，同样是快速、范围明确的修改——产品与文档中的名称已同步更新。[Lite 模式](/zh/core-concepts/agent/agent-modes)。
* **Code Optimizations**：用于控制 Agent 如何审查自身代码的设置 (原 Autonomy Level) 现更名为 Code Optimizations。[代码审查](/zh/ko/features/agent/agent-modes)。
* **协作**：所有付费方案的协作体验都更进一步——无限工作区、更简便的共享、统一设置、按工作区跟踪使用量。Core：5 名协作者；Pro：15 名构建者。

<div id="section-3">
  ### 后台内存压缩
</div>

Agent 不再为了优化内存而中断工作流。此前，&quot;Optimized Agent memory&quot; 消息会阻塞进度 30 秒以上。现在该操作会在后台顺畅完成，因此 Agent 在工作过程中始终保持响应。

<div id="section-4">
  ### 访问生产环境部署日志
</div>

Agent 现在可以访问生产环境的部署日志，基于真实的生产数据定位并修复错误。更多生产环境调试功能的改进也即将推出。

<div id="section-5">
  ### 技能搜索
</div>

借助技能搜索，你无需向 Agent 输入提示词或手动上传文件，即可直接在 Replit 中浏览并安装热门技能。
