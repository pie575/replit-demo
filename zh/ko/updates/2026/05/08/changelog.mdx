<div id="workspace-security-center-20">
  ### Workspace Security Center 2.0
</div>

您可以在一个地方集中查看工作区中所有项目的依赖项漏洞并采取处理措施。Workspace Security Center 现在会优先展示风险最高的项目，并支持按严重程度、发布状态、可见性和所有者搜索和筛选受影响的项目。整个修复流程也无需离开 Security Center 即可完成：启动 Agent 任务，查看建议的修复方案，然后重新发布项目。您还可以单独或批量通知项目所有者，立即取消发布暴露风险较高的项目，并下载用于合规审计的 SBOM。

<div id="section-3">
  ### 所有用户均可私密发布
</div>

私密发布和密码保护发布此前仅限 Pro 和 Enterprise 套餐使用。现在，Core 和 Starter 套餐的构建者也能私密发布，任何人都可以把内部工具、测试版应用或进行中的项目放在 Replit 登录之后。

进一步了解[私有部署](/zh/ko/features/publishing/private-deployments)。

<div id="private-deployment">
  ### 私有部署的外部访问令牌
</div>

现在可以为私有 Replit 应用使用外部访问令牌了。你可以签发令牌，为需要访问私有部署的集成 (如 Slack、GitHub、Twilio 等) 单独完成配置，无需依赖连接器。这些令牌让高级用户对应用拥有更强的控制力，也让私有 Replit 应用更加安全。打开部署的**调整设置**，即可看到新增的**外部访问令牌**标签页。

详细了解[外部访问令牌](/zh/references/publishing/external-access-tokens)。

<div id="slide-decks">
  ### Slide Decks 的演讲者备注与演讲者视图
</div>

Slide Decks 现已支持演讲者备注和专用的演讲者视图。备注会在编辑器与演示窗口之间双向实时同步，因此你可以用一台设备共享屏幕，同时用另一台设备远程控制幻灯片。你可以让 Agent 帮你撰写备注，然后在观众只看到幻灯片的同时，在编辑器中继续打磨备注。演讲者视图同样适用于移动端幻灯片 artifact 卡片。

<div id="agent-svg">
  ### Agent 支持上传 SVG
</div>

现在你可以向 Agent 附加 SVG 文件了。将 SVG 拖入聊天窗口或粘贴 URL，Agent 会像处理其他附件一样读取其标记内容。上传的文件会在到达 Agent 或存储之前先在浏览器中完成净化处理，常见的 SVG 攻击手段会被自动清除。

<div id="agent-2">
  ### Agent 模式的全新动画图标
</div>

Lite、Economy 和 Power 三种 Agent 模式新增了专属动画图标，以直观体现各模式的特点。新图标会显示在 Agent 模式选择器中，以及工作区内所有显示模式的位置。
