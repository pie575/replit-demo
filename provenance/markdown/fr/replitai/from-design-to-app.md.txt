# Du design à l'application

> Apprenez à transformer les maquettes du Canvas de design en applications réelles et fonctionnelles — de l'exploration à l'application publiée.

## Quel est ce flux de travail ?

Le Canvas de design est fait pour l'exploration — votre application vit dans l'aperçu. Cette page vous guide à travers le parcours complet pour transformer une direction visuelle en une application publiée.

Concepts clés :

* **Canvas = brouillon** : Les cadres sont des maquettes HTML statiques pour explorer des idées
* **Artefacts = sorties publiables** : La conversion d'un cadre crée un artefact buildable et publiable
* **Flux à sens unique** : Il n'y a pas de lien en direct entre le Canvas et votre application — vous convertissez quand vous êtes prêt
* **Tout type d'artefact** : Convertissez en applications web, applications mobiles, présentations, visualisations de données, et plus encore

## Comment passer du design à l'application

### Commencer sur le Canvas

Ouvrez le [Canvas de design](/replitai/design-canvas) et explorez votre idée. Demandez à Agent des maquettes, générez des variantes et comparez des directions côte à côte.

**Exemples de prompts :**

* « Conçois une page d'accueil pour mon produit SaaS »
* « Montre-moi cinq variations d'une mise en page de tableau de bord »
* « Esquisse le flux d'inscription complet pour mon application »

### Affiner avec l'éditeur visuel

Utilisez l'[éditeur visuel](/fr/replitai/visual-editor) pour apporter des ajustements pratiques directement sur vos cadres — changer le texte, ajuster les couleurs, modifier l'espacement — sans passer par Agent ou consommer de crédits IA.

### Choisir une direction

Comparez vos cadres et choisissez celui qui correspond le mieux à votre vision. Vous n'avez pas besoin de le perfectionner — vous pouvez continuer à affiner après la conversion.

### Convertir en artefact

<Steps>
  <Step title="Sélectionner votre cadre">
    Cliquez sur le cadre que vous souhaitez transformer en application réelle.
  </Step>

  <Step title="Demander à Agent de convertir">
    Dites à Agent ce que vous voulez — par exemple, « Convertis ceci en application web » ou « Transforme ceci en application mobile. »
  </Step>

  <Step title="Agent construit votre application">
    Agent crée un vrai artefact avec le design que vous avez choisi. Il ajoute le backend, la base de données et l'infrastructure dont votre application a besoin.
  </Step>

  <Step title="Affiner dans l'aperçu">
    Passez à l'aperçu pour voir votre application en cours d'exécution. Continuez à utiliser l'éditeur visuel ou discutez avec Agent pour ajouter des fonctionnalités, corriger des détails et peaufiner.
  </Step>

  <Step title="Publier">
    Lorsque votre application est prête, publiez-la. Replit gère l'hébergement et l'infrastructure afin que votre application fonctionne de manière fiable pour votre audience.
  </Step>
</Steps>

### Ce qui est conservé

Lorsque vous convertissez un cadre en artefact, Agent utilise le design comme référence pour construire une vraie application. La mise en page visuelle, les couleurs, la typographie et la structure sont conservées. Agent ajoute la fonctionnalité — stockage de données, comptes utilisateurs, connexions API — par-dessus.

<Note>
  La conversion est une étape à sens unique. Le cadre Canvas et l'artefact résultant sont séparés — les modifications apportées à l'un n'affectent pas l'autre.
</Note>

## Ce que vous pouvez construire

* **Site statique → application full-stack** : Commencez avec une page d'accueil, puis convertissez et ajoutez un formulaire de contact, des paiements ou un backend de blog
* **Maquette de tableau de bord → visualisation de données en direct** : Concevez la mise en page sur le Canvas, convertissez en artefact et connectez des sources de données réelles
* **Concept d'application mobile → application native** : Explorez l'interface sur le Canvas, puis convertissez en artefact mobile avec une vraie navigation et des données
* **Présentation + produit** : Concevez votre application et une présentation dans le même projet — les deux commencent comme des explorations Canvas, les deux deviennent de vrais artefacts

## Foire aux questions

<Accordion title="Dois-je commencer sur le Canvas ?">
  Non. Vous pouvez ignorer complètement le Canvas et construire directement en mode Application. Le Canvas est fait pour l'exploration — utilisez-le lorsque vous souhaitez essayer des directions visuelles avant de vous engager.
</Accordion>

<Accordion title="Quelle est la différence entre un cadre et un artefact ?">
  Un cadre est une maquette HTML statique sur le Canvas — il n'a pas de serveur, de base de données ou de backend. Un artefact est une vraie application buildable que vous pouvez publier. La conversion d'un cadre crée un artefact.
</Accordion>

<Accordion title="Puis-je convertir le même cadre en plusieurs types d'artefacts ?">
  Oui. Vous pouvez convertir un seul cadre en application web, puis le convertir séparément en application mobile ou en présentation. Chaque conversion crée un nouvel artefact.
</Accordion>

<Accordion title="Puis-je revenir au Canvas après la conversion ?">
  Le Canvas est toujours disponible. Vous pouvez continuer à concevoir de nouveaux cadres, mais l'artefact converti et le cadre d'origine sont indépendants — modifier l'un ne change pas l'autre.
</Accordion>

<Accordion title="Mon design aura-t-il exactement le même aspect après la conversion ?">
  Agent utilise votre design comme référence, donc la mise en page, les couleurs et la structure sont étroitement conservées. Certains détails peuvent changer lorsqu'Agent ajoute de vraies fonctionnalités — vous pouvez affiner dans l'aperçu après la conversion.
</Accordion>
