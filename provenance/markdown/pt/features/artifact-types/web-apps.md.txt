# Aplicativos Web

> Saiba como construir aplicações web full-stack com o Agent — responsivas por padrão, instantaneamente implantáveis e compartilháveis.

Os aplicativos web são o tipo de saída padrão no Replit. Quando você descreve uma ideia ao Agent, ele constrói uma aplicação web full-stack, a menos que você especifique um tipo de artefato diferente.

## Primeiros passos

Há duas maneiras de criar um aplicativo web:

* **Digite um prompt**: descreva o que você quer construir na página inicial do Replit. O Agent cria automaticamente um aplicativo web.
* **Selecione no menu suspenso**: abra o menu suspenso de tipo de aplicativo na página inicial e escolha **Web app**, depois descreva sua ideia.

## Principais recursos

* **Full-stack por padrão**: todo aplicativo web inclui um frontend e um backend. O Agent configura rotas de API, um banco de dados e lógica do lado do servidor conforme seu aplicativo precisa.
* **Design responsivo**: os aplicativos se adaptam automaticamente a diferentes tamanhos de tela.
* **Publicação instantânea**: publique seu aplicativo com um clique. O Replit lida com hospedagem, SSL e infraestrutura.
* **Infraestrutura compartilhada**: se o seu projeto tiver vários artefatos — como um aplicativo mobile ou um dashboard de dados — todos eles compartilham o mesmo backend, banco de dados e serviços.

## Casos de uso

* **Produtos SaaS**: construa ferramentas, dashboards e plataformas voltados para clientes.
* **Ferramentas internas**: crie painéis administrativos, CRMs ou aplicativos de fluxo de trabalho para sua equipe.
* **Landing pages**: lance sites de marketing com formulários, animações e conteúdo dinâmico.
* **Marketplaces e diretórios**: construa sites de listagem, quadros de vagas ou plataformas comunitárias.
