广泛探索，深入精修。当画框接近理想效果时，可使用两种工具按自己的方式进行精细调整：

* 用自己的方式与 Agent 对话，无论是整个画框还是单个元素
* 通过 Visual Editor 直接调整元素。简单编辑无需消耗积分，且会立即生效

<div id="section">
  ## Chat
</div>

像向设计师介绍阶段性评审意见一样，向 Agent 说明需求。选择一个画框，然后在主 Chat 中描述要更改的内容 (*&quot;使用更暖的色彩&quot;*、*&quot;主视觉看起来很空&quot;*) ；或者从工具栏中选择 **Chat** 工具并点击元素，将消息范围限定在该部分。

<Frame caption="所选画框会作为标签附加到主 Chat 中。">
  <img src="/assets/mirror/chatbox-9baff03cb443.png" alt="画布中选定的 Design 画框（Configurator First），左侧为主 Chat 面板，消息框中显示“Describe what you want to design…”并附有 Configurator First 标签" width="2000" height="1250" data-path="images/design/replit-design/chatbox.png" />
</Frame>

有关这两种方式的详细说明，请参阅 [Chat](/zh/ko/design/chat-about-your-design)。

<div id="visual-editor">
  ## Visual Editor
</div>

如果你已明确知道自己想要什么，可以跳过提示词。在工具栏中选择 **Edit** 工具并点击元素，即可打开 Visual Editor，查看该元素可编辑的属性 (如内容、布局、颜色和边框) 。更改文本、选择颜色、调整间距等简单编辑不会消耗积分，并会立即应用到源代码中。

<Frame caption="Visual Editor 显示已启用的 Edit 工具、选中的元素及可编辑属性。">
  <img src="/assets/mirror/visual-editor-edit-tool-71d03803471f.png" alt="超级跑车配置器 frame，其中 Edit 工具已启用且元素已选中，右侧为 Visual Editor 面板，包含 Layout、Color、Border 区域以及 Discard 和 Save edits 按钮" width="2000" height="1250" data-path="images/replitai/visual-editor-edit-tool.png" />
</Frame>

有关完整控件的参考信息，请参阅 [Visual Editor](/zh/ko/design/visual-editor)。

<div id="section-2">
  ## 应该选择哪个？
</div>

| 您想要…                     | 使用的工具         |
| ------------------------ | ------------- |
| 描述预期结果，让 Agent 自行处理细节    | Chat            |
| 使用已知的值修改单个元素的文本、颜色、间距或图片 | Visual Editor |
| 重新设计某个部分的结构或行为           | Chat            |
| 不消耗积分，快速进行调整             | Visual Editor |

两者可以自然地结合使用。先通过Chat确定方向，再使用 Visual Editor 完善细节。
