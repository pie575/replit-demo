借助 Whop 集成，Agent 只需一次对话就能为你的应用添加支付功能，无需外部配置，也不需要 API 密钥。Agent 会为你创建 Whop 账户、接入结账流程并构建支付逻辑。Whop 是最快的开售方式，因此如果你想尽快完成第一笔交易，它会是个不错的选择。

<div id="what-you-can-build">
  ## 你可以构建什么
</div>

* 数字内容的付费墙与“解锁”流程
* 会员资格与社区访问权限
* 订阅与周期性套餐
* 一次性数字产品销售

<div id="how-it-works">
  ## 工作原理
</div>

当你提出收款需求时，Agent 会在后台完成 Whop 的接入：为你的应用创建 Whop 账户、建立连接，并把结账流程集成进你的 project。你无需粘贴任何凭据，也无需离开 Replit 就能开始。

Whop 是 Replit 支持的多家支付服务商之一。Agent 会根据你要构建的内容，帮你挑选最合适的一家：

|          | Whop          | Stripe          | Shopify      | RevenueCat                 |
| -------- | :------------ | :-------------- | :----------- | :------------------------- |
| **最适合**  | 步骤最少，最快完成首笔销售 | 灵活性与规模          | 实体商品         | 原生移动应用                     |
| **可销售**  | 数字产品、会员资格、订阅    | 一次性付款、订阅、店面     | 需要库存与履约的实体商品 | 应用内订阅                      |
| **外部配置** | 起步无需          | 起步无需            | 起步无需         | 起步无需                       |
| **上线要求** | 完成身份验证 (KYC)  | 连接正式的 Stripe 账户 | 认领店铺         | App Store 或 Google Play 审核 |

如果你没有指定服务商，Agent 会根据你的描述推荐一家，并说明各自的利弊。

<div id="get-started">
  ## 开始使用
</div>

* **让 Agent 添加支付功能**
  * 在主屏幕上使用斜杠命令，或直接提出请求：
    <AiPrompt>添加 Whop 支付，让我可以在应用中销售会员资格</AiPrompt>

<Note>
  Whop 集成需要具备后端功能的 App。请在主页选择 **App** 开始创建。
</Note>

<div id="test-your-payments">
  ## 测试支付
</div>

1. 在新标签页中打开应用的 **Preview**。
2. 完整走一遍你搭建的结账或解锁流程。
3. 在分享应用之前，端到端地确认买家的完整体验。

<div id="manage-products-and-pricing">
  ## 管理产品与定价
</div>

你可以通过两种方式管理你的销售内容：

* **让 Agent 处理**：描述你想要的变更——新增套餐、调整价格、增加产品——Agent 会同步更新你的应用和 Whop 配置。
* **使用 Whop 控制台**：用你 Replit 账户的邮箱登录 [Whop](https://whop.com)，直接管理产品、定价和套餐。

<div id="track-your-balance-and-get-paid">
  ## 查看余额并收款
</div>

销售收入会累积在你的 Whop 账户中。若要提现收益，请在 Whop 控制台中完成 Whop 的身份验证 (KYC) 。你可以在完成验证之前就开始销售，但必须先通过身份验证才能提现。

<Note>
  结账、支付处理、身份验证 (KYC) 和打款均由 Whop 负责。Replit 绝不会收集你的银行信息或税务信息。
</Note>

<div id="manage-the-integration">
  ## 管理集成
</div>

* 前往 **Integrations &gt; Whop**，打开 Whop 连接器。
* 在这里可以查看连接状态并管理相关设置。

<div id="frequently-asked-questions">
  ## 常见问题
</div>

<div id="do-i-need-a-whop-account-before-i-start">
  ### 开始之前需要先有 Whop 账户吗？
</div>

不需要。Agent 会在设置过程中为你的应用创建 Whop 账户。之后你可以用 Replit 账户的邮箱登录 Whop 控制台，管理产品并提取收益。

<div id="when-do-i-need-to-verify-my-identity">
  ### 我什么时候需要验证身份？
</div>

你可以立即开始构建并销售。Whop 要求你在提现前完成身份验证 (KYC) ，可在 Whop 控制台中完成该流程。

<div id="how-do-i-change-my-products-or-prices">
  ### 如何更改我的产品或价格？
</div>

让 Agent 帮你修改，或直接在 [Whop 控制台](https://whop.com)中编辑你的产品和套餐。

<div id="which-payment-provider-should-i-use">
  ### 我应该选择哪个支付服务商？
</div>

Whop 无需任何外部配置，是开始销售数字产品和会员资格服务的最快方式。若希望在 web 应用上获得最大的灵活性，可选择 [Stripe](/zh/features/monetization/stripe-payments)；销售实体商品可选择 [Shopify](/zh/features/integrations/shopify)；原生移动端订阅则可选择 [RevenueCat](/zh/features/monetization/revenuecat-subscriptions)。详细对比请参阅[变现概览](/zh/features/monetization/overview)。
