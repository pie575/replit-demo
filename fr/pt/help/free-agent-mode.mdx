---
title: "Mode Agent gratuit"
description: "Découvrez comment le mode gratuit permet aux abonnés Starter, Core et Pro d'utiliser Agent sans frais."
---

<Note>
  Certains détails du quota peuvent encore évoluer d&#39;ici au lancement.
</Note>

Le mode gratuit permet aux abonnés Starter, Core et Pro d&#39;utiliser Agent sans frais supplémentaires. Starter inclut le mode gratuit avec ses limites actuelles. Core et Pro incluent un quota de mode gratuit. Ouvrez une conversation pour explorer, planifier, créer ou demander de l&#39;aide. Si une demande nécessite un mode payant ou une action payante, Replit vous en informe clairement avant le lancement de toute opération facturable.

<div id="por-que-voc-vai-gostar">
  ## Pourquoi vous allez aimer
</div>

* Commencez par une conversation plutôt que par un parcours de configuration.
* Explorez vos idées et avancez avant de décider si vous avez besoin de plus de capacité.
* Gardez le contrôle lorsqu&#39;une demande nécessite une action payante.
* Repérez un libellé **Gratuit** bien visible sur le travail réalisé en Mode Gratuit.

<div id="como-funciona">
  ## Fonctionnement
</div>

1. Les nouvelles sessions Starter, Core et Pro démarrent en Mode gratuit.
2. Les tâches qui relèvent du Mode gratuit se poursuivent sans invitation à passer à une option payante.
3. Si un mode payant convient mieux à une demande, Agent vous l&#39;explique et vous laisse le choix.
4. Vous pouvez autoriser le mode payant uniquement pour cette demande ou demander à Agent de poursuivre en Mode gratuit.
5. Après une escalade payante ponctuelle, vous revenez automatiquement au Mode gratuit.

<div id="os-trs-modos-do-agent">
  ## Les trois modes de l&#39;Agent
</div>

<CardGroup cols={3}>
  <Card title="Gratuit">
    Le travail de l&#39;Agent sans frais pour les abonnés Starter, Core et Pro.
  </Card>

  <Card title="Power">
    Un mode payant de niveau intermédiaire pour les tâches qui exigent plus de capacité, à un prix abordable.
  </Card>

  <Card title="Max">
    Un mode payant haut de gamme pour les tâches les plus exigeantes, avec les meilleurs modèles de pointe.
  </Card>
</CardGroup>

Le mode Gratuit est accessible aux abonnés Starter, Core et Pro. Starter inclut le mode Gratuit avec ses limites actuelles. Core et Pro incluent un quota de mode Gratuit, et Pro bénéficie d&#39;une limite hebdomadaire plus élevée. Vous pouvez également opter pour un mode payant de l&#39;Agent lorsque vous avez besoin de plus de capacité.

<Note>
  **Si vous atteignez une limite :** Starter inclut le mode Gratuit avec ses limites actuelles. Pour Core et Pro, le quota du mode Gratuit se renouvelle toutes les cinq heures et comporte une limite hebdomadaire. Consultez **Settings → Usage** pour voir où vous en êtes. Replit vous prévient à l&#39;approche de la limite. Une fois celle-ci atteinte, passez à un mode payant pour continuer ou attendez le renouvellement.
</Note>

<div id="perguntas-comuns">
  ## Questions fréquentes
</div>

<AccordionGroup>
  <Accordion title="Le Mode Gratuit est-il vraiment gratuit ? Replit est-il désormais gratuit ?">
    Le Mode Gratuit est inclus dans les abonnements Starter, Core et Pro. Starter inclut le Mode Gratuit avec ses limites existantes. Core et Pro incluent un quota de Mode Gratuit. Il ne s&#39;agit pas d&#39;un forfait gratuit à part entière.
  </Accordion>

  <Accordion title="Est-ce la même chose qu'un mode payant de l'Agent ?">
    Non. Le Mode Gratuit correspond à l&#39;utilisation de l&#39;Agent sans frais, dans la limite de votre quota. Power et Max sont des modes payants destinés aux travaux qui exigent davantage de capacité.
  </Accordion>

  <Accordion title="Que sont devenus Economy et Power ? Les modes ont-ils changé ?">
    Les modes payants ont été renommés. Economy s&#39;appelle désormais Power, un mode intermédiaire proposant des modèles puissants à un prix accessible. Le mode auparavant appelé Power devient Max, le mode de niveau supérieur. Vos réglages de mode existants sont conservés sous les nouveaux noms.
  </Accordion>

  <Accordion title="Quel mode est le plus performant ?">
    Max. Power est le mode payant intermédiaire, pour plus de capacité à un prix accessible. Max est le mode payant de niveau supérieur, pour les travaux les plus exigeants.
  </Accordion>

  <Accordion title="Et si ma demande nécessite une action payante ?">
    L&#39;Agent vous indique que la demande nécessite un mode payant ou une capacité payante, et vous consulte avant de poursuivre. Vous pouvez approuver cette demande de façon ponctuelle ou continuer en Mode Gratuit.
  </Accordion>

  <Accordion title="Serai-je facturé automatiquement si l'Agent suggère une montée en gamme ?">
    Non. Une escalade payante requiert votre confirmation avant que la demande payante ne démarre.
  </Accordion>

  <Accordion title="Puis-je refuser l'option payante ?">
    Oui. Vous pouvez continuer à travailler en Mode Gratuit.
  </Accordion>

  <Accordion title="Que se passe-t-il après avoir approuvé une escalade payante ?">
    L&#39;approbation ne vaut que pour cette demande. Votre mode d&#39;Agent revient ensuite au Mode Gratuit.
  </Accordion>

  <Accordion title="Pourquoi ai-je atteint une limite ? Quand est-elle renouvelée ?">
    Starter inclut le Mode Gratuit avec ses limites existantes. Pour Core et Pro, le quota du Mode Gratuit se renouvelle toutes les cinq heures et comporte une limite hebdomadaire. Consultez **Settings → Usage** pour voir où vous en êtes. Une fois la limite atteinte, passez à un mode payant pour continuer ou attendez le renouvellement.
  </Accordion>

  <Accordion title="Le Mode Gratuit est-il disponible sur Enterprise ?">
    Pas au lancement. Les workspaces Enterprise bénéficieront peu après d&#39;une expérience Agent dédiée. Votre administrateur pourra vous en dire plus.
  </Accordion>
</AccordionGroup>

<div id="mais-sobre-o-modo-gratuito">
  ## En savoir plus sur le Mode Gratuit
</div>

<AccordionGroup>
  <Accordion title="Le Mode Gratuit est-il identique à Lite ?">
    Pour les utilisateurs Starter, l&#39;expérience auparavant appelée Lite devient le Mode Gratuit. Si vous utilisiez Lite pour bénéficier d&#39;un modèle moins coûteux, vous pouvez toujours sélectionner ce modèle manuellement dans Power lorsque vous désactivez le mode automatique.
  </Accordion>

  <Accordion title="Le Mode Gratuit peut-il créer une application complète ?">
    Oui. Vous pouvez créer des applications complètes et les faire évoluer en Mode Gratuit.
  </Accordion>

  <Accordion title="Quelle est la différence entre Free, Power et Max ?">
    Le Mode Gratuit correspond au travail quotidien de l&#39;Agent, sans frais pour les abonnés Starter, Core et Pro. Starter inclut le Mode Gratuit avec ses limites existantes. Core et Pro incluent un quota de Mode Gratuit. Power est le mode payant de niveau intermédiaire, offrant plus de capacité à un prix abordable. Max est le mode payant de niveau supérieur, destiné aux travaux les plus exigeants.
  </Accordion>

  <Accordion title="Quand dois-je quitter le Mode Gratuit ?">
    Restez en Mode Gratuit pour le travail quotidien. Changez de mode lorsque vous souhaitez de meilleurs résultats sur une tâche complexe ou que vous avez besoin d&#39;une capacité que le Mode Gratuit n&#39;offre pas.
  </Accordion>

  <Accordion title="Le Mode Gratuit peut-il générer des vidéos ?">
    Non. La génération de vidéo est une capacité des modes payants et ne fait pas partie du Mode Gratuit.
  </Accordion>

  <Accordion title="En quoi consiste la nouvelle expérience Conversas ?">
    Chat et création ne font plus qu&#39;un. Vous pouvez explorer une idée, planifier un travail ou démarrer un projet au sein d&#39;une même conversation.
  </Accordion>

  <Accordion title="Les chats indépendants font-ils partie d'un app publicado ?">
    Non. Une conversation reste distincte tant que vous ne créez ni ne modifiez un projet.
  </Accordion>

  <Accordion title="Le Mode Gratuit peut-il travailler sur un projet existant ?">
    Oui. Il prend en charge la maintenance courante et les modifications sur des projets existants.
  </Accordion>
</AccordionGroup>

**Prêt à essayer ?** Dès le lancement du Mode Gratuit, ouvrez une conversation avec l&#39;Agent et lancez-vous.
