С Voice Mode вы можете просто рассказать вслух, что хотите создать. Нажмите на микрофон в поле чата с Agent, произнесите свой prompt — и Replit распознаёт речь в виде редактируемого текста. Проверьте текст, внесите правки и отправьте его как обычное сообщение.

Voice Mode пригодится, когда печатать медленно или неудобно, — особенно на мобильном устройстве, где продиктовать полноценный prompt зачастую быстрее, чем набирать его большими пальцами.

<Note>
  Voice Mode превращает вашу речь в текст в поле чата. Он не зачитывает
  ответы Agent вслух — вы по-прежнему отправляете сообщение текстом, а Agent отвечает
  в чате как обычно.
</Note>

<div id="how-it-works">
  ## Как это работает
</div>

  <img src="/assets/mirror/voice-mode-mic-button-fe7da6953736.png" alt="Поле чата с Agent с выделенной кнопкой микрофона и подсказкой «Start voice input», рядом с флажком Plan и стрелкой отправки" width="1853" height="423" data-path="images/replitai/voice-mode/voice-mode-mic-button.png" />

Voice Mode записывает вашу речь, распознаёт её и вставляет результат в поле чата, чтобы вы могли проверить текст перед отправкой:

1. Откройте Agent и нажмите на микрофон в поле чата.
2. Разрешите доступ к микрофону, если браузер или устройство запросит его.
3. Произнесите свой prompt. Звуковая волна показывает, что Agent ведёт запись.
4. Остановите запись, когда закончите. Запись также остановится автоматически после паузы или при переходе на другую вкладку.
5. Немного подождите, пока речь распознаётся.
6. Проверьте распознанный текст, при необходимости отредактируйте его и отправьте сообщение.

Поскольку распознанный текст появляется в поле чата как обычный текст, вы можете свободно сочетать голос и набор с клавиатуры: продиктовать часть prompt, а остальное напечатать или исправить слово перед отправкой.

<Tip>
  Говорите естественно. Voice Mode стремится передать смысл сказанного, а не
  дословно записать каждое слово, поэтому слова-паразиты вроде «эм» и «ээ» в
  результат не попадают.
</Tip>

<div id="where-you-can-use-it">
  ## Где можно использовать
</div>

Voice Mode доступен в поле чата с Agent:

* В **Project Editor** при работе с Agent над приложением.
* При **создании нового приложения** через поле ввода prompt для Agent на главном экране.

Voice Mode можно использовать в браузере на компьютере, в мобильном браузере и в мобильном приложении Replit.

<div id="good-to-know">
  ## Полезно знать
</div>

При использовании Voice Mode учитывайте следующее:

| Параметр                 | Что ожидать                                                                                                                                                     |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Длительность записи      | За один раз можно записать до 6 минут. Незадолго до достижения лимита появится предупреждение.                                                                  |
| Автоматическая остановка | Запись останавливается сама примерно после 30 секунд тишины, а также при переключении вкладки или сворачивании приложения.                                      |
| Проверка перед отправкой | Распознанный текст попадает в поле чата, чтобы вы могли прочитать и отредактировать его перед отправкой — автоматически ничего не отправляется.                 |
| Доступ к микрофону       | Voice Mode требуется разрешение на использование микрофона. Если запись не начинается, убедитесь, что браузер и устройство разрешают Replit доступ к микрофону. |

<div id="availability">
  ## Доступность
</div>

Voice Mode доступен на всех тарифах Replit. Значок микрофона отображается в поле чата с Agent в браузерах и на устройствах, поддерживающих запись звука; при первой записи система запросит разрешение на доступ к микрофону.
