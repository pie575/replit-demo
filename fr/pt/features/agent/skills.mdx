<div id="o-que-uma-skill">
  ## Qu&#39;est-ce qu&#39;une compétence ?
</div>

Une compétence est un dossier. Il contient un fichier nommé `SKILL.md` avec les instructions que l&#39;Agent suit, ainsi que tous les fichiers complémentaires que vous souhaitez lui faire consulter. Les compétences se trouvent dans le répertoire `/.agents/skills` de votre projet et respectent la [spécification Agent Skills](https://agentskills.io/specification), un standard ouvert compatible avec différents agents.

L&#39;Agent voit le nom et la description de chaque compétence installée, mais il n&#39;en charge le contenu complet que lorsqu&#39;elle est pertinente pour la tâche en cours. Les compétences sont ainsi économes en contexte : vous pouvez en installer un grand nombre sans nuire à la qualité des réponses de l&#39;Agent.

<div id="skills-pr-definidas">
  ## Compétences prédéfinies
</div>

Replit intègre des compétences prédéfinies, disponibles dans le sélecteur **Use a skill** du Chat ainsi que dans le sélecteur de point de départ des nouveaux projets. Ces compétences fonctionnent dans tous les projets, sans installation. Pour consulter le catalogue complet, les compétences des partenaires et la procédure d&#39;installation, reportez-vous au [Répertoire de compétences](/fr/pt/features/agent/skills-directory).

Pour ajouter une compétence prédéfinie, ouvrez le sélecteur **Use a skill** dans la zone de saisie du Chat et sélectionnez une compétence, ou demandez simplement à Agent de la charger.

<div id="escopo-da-skill">
  ## Portée de la compétence
</div>

Les compétences peuvent avoir différents niveaux de portée :

| Portée               | Disponibilité                                    | Emplacement                                                                                                                    |
| -------------------- | ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| **Niveau projet**    | Spécifique à un projet                           | Versionnée avec vos fichiers dans `/.agents/skills`                                                                            |
| **Niveau workspace** | Accessible à tous les membres de votre workspace | Gérée de façon centralisée dans Workspace Settings                                                                             |
| **Enterprise**       | Standards à l&#39;échelle de l&#39;entreprise    | Incluse dans les [templates personnalisés](/fr/pt/teams/custom-templates) et les [design systems](/fr/pt/teams/custom-design-system) |

Pour les compétences au niveau du workspace, consultez [Agent Customization](/fr/pt/features/agent/agent-customization) afin de configurer les compétences de workspace et les instructions personnalisées de votre équipe.

<div id="como-o-agent-carrega-skills">
  ## Comment Agent charge les compétences
</div>

Agent lit les métadonnées (nom et description) de chaque compétence installée à chaque Chat. Le contenu complet d&#39;une compétence n&#39;est chargé que lorsque Agent estime qu&#39;elle est pertinente pour la tâche en cours. Le contenu des compétences reste ainsi en dehors de la fenêtre de contexte tant qu&#39;il n&#39;est pas nécessaire.

Les compétences installées sont conservées dans votre projet d&#39;une session d&#39;Agent à l&#39;autre et peuvent être envoyées au contrôle de version afin d&#39;être partagées avec l&#39;équipe.

<div id="trabalhando-com-outras-ferramentas-de-codificao-com-ia">
  ## Travailler avec d&#39;autres outils de codage assistés par IA
</div>

<Accordion title="Importer des compétences depuis d'autres outils de codage assistés par IA">
  Si vous utilisez plusieurs outils de codage assistés par IA, [rulesync](https://github.com/dyoshikawa/rulesync) prend en charge Replit et vous aide à conserver des configurations cohérentes.

  Vous pouvez importer des compétences depuis d&#39;autres assistants de codage assistés par IA :

  ```bash theme={null}
  npx rulesync init
  npx rulesync import --targets claudecode --features skills
  npx rulesync generate --targets replit --features skills
  ```

  Vous pouvez ainsi maintenir un ensemble unique de compétences qui fonctionne dans différents environnements de développement.
</Accordion>
