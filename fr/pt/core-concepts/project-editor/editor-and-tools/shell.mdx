---
title: "Shell"
description: "Découvrez comment utiliser le Shell pour exécuter des commandes dans l’Éditeur de projets."
---

Le Shell vous permet d’effectuer des tâches liées au système d’exploitation dans l’Éditeur de projets, comme gérer des fichiers,
installer des paquets et exécuter des scripts. Il fournit une interface textuelle puissante pour
interagir avec votre environnement Replit.

Vous pouvez utiliser le Shell pour effectuer les tâches suivantes dans l’Éditeur de projets :

* Exécuter des scripts et des programmes
* Installer et exécuter des outils et paquets Linux populaires
* Téléverser et télécharger des fichiers depuis Internet
* Gérer les fichiers et répertoires du projet

<Tip>
  Pour mieux gérer les workflows, privilégiez le bouton **Exécuter** plutôt que de démarrer votre application depuis le
  Shell. Le workflow démarré à l’aide du bouton **Exécuter** envoie la sortie vers l’outil Console,
  qui permet de consulter les logs de manière structurée.
</Tip>

<div id="recursos">
  ## Fonctionnalités
</div>

Le Shell offre les fonctionnalités suivantes :

* **Exécuter plusieurs shells** : Ouvrez plusieurs instances du Shell pour travailler simultanément sur différentes tâches.
* **Rechercher du texte** : Recherchez du texte spécifique dans la sortie du Shell.

<div id="uso">
  ## Utilisation
</div>

<Accordion title="Accéder au Shell">
  Dans le **dock d’outils** situé à gauche :

  1. Sélectionnez <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Icône Toutes les outils" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **Tous les outils** pour afficher la liste des outils de l’Éditeur de projets.
  2. Sélectionnez <img class="icon-svg" src="/assets/mirror/shell-289d6eb079b0.svg" alt="Icône Shell" width="16" height="16" data-path="images/icons/shell.svg" /> **Shell**.

  Dans la **barre de recherche** :

  1. Sélectionnez l’<img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="icône de loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> icône en forme de loupe en haut pour ouvrir l’outil de recherche.
  2. Saisissez « Shell » pour trouver l’outil, puis sélectionnez-le dans les résultats.
</Accordion>

<div id="pesquisa-de-texto">
  ### Recherche de texte
</div>

Les étapes suivantes expliquent comment accéder à l’outil de recherche de texte et l’utiliser :

1. Sélectionnez l’<img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="icône de loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> icône de loupe dans le coin supérieur droit de l’onglet Shell pour ouvrir la boîte de dialogue de recherche.
2. Saisissez un terme de recherche et sélectionnez **Suivant** pour parcourir les correspondances.
3. Utilisez **Précédent** pour revenir aux correspondances précédentes.
4. Sélectionnez **Quitter** ou cliquez en dehors de la boîte de dialogue pour terminer la recherche de texte.

<div id="mltiplos-shells">
  ### Plusieurs shells
</div>

Pour créer un nouveau shell, ouvrez le menu situé en haut à gauche de l’onglet **Shell**, puis sélectionnez **Nouveau Shell**, comme illustré ci-dessous :

<Frame>
  <img src="/assets/mirror/shell-new-94a280c1230f.png" alt="Sélection du menu Nouveau Shell" width="1280" height="224" data-path="images/workspace/shell-new.png" />
</Frame>

Utilisez ce même menu pour passer d’un shell à l’autre. L’Éditeur de projets identifie chaque shell par la dernière commande exécutée afin de vous aider à les distinguer.

<Warning>
  Lorsque vous ouvrez plusieurs shells, Replit ferme automatiquement les instances de shell inactives.
  Un shell inactif n’est pas sélectionné et n’exécute aucun processus utilisateur.
</Warning>
