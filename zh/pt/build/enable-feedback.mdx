---
title: "启用反馈小组件"
description: "了解如何在已部署 App 中收集访客反馈。"
---

你可以在已部署 App 中启用反馈功能，直接收集访客洞察并发送给 Agent。启用后，访客可以提交反馈，包括截图和文件；你可以通过 Inbox 进行管理。

<div id="ativando-o-feedback">
  ## 启用反馈
</div>

<Warning>
  只有 web 应用可以启用反馈功能。其他类型的应用 (如自动化或移动应用) 无法启用此功能。
</Warning>

部署新应用时，请在部署对话框中开启 **启用反馈** 选项。如果您的应用已部署，可通过重新部署来启用反馈：

1. 打开部署工具
2. 选择 **高级设置**
3. 开启 **启用反馈**
4. 重新部署您的应用

<div id="enviando-feedback">
  ## 提交反馈
</div>

在已部署应用中启用反馈后，访客可以直接在应用内提交反馈。用户可以：

* 登录后提交反馈
* 通过文字描述使用体验或提出建议
* 选择元素来说明问题或所需功能
* 上传文件以提供更多上下文

<div id="gerenciando-feedback-no-seu-inbox">
  ## 在 Inbox 中管理反馈
</div>

访客提交的所有反馈都会显示在 Inbox 中，您可在项目编辑器中访问 Inbox。在 Inbox 中，您可以：

* **添加到 Chat**：将反馈添加到与 Agent 的 Chat 中，在发送前补充上下文
* **发送给 Agent**：立即将反馈发送给 Agent 并着手处理
* **解决**：处理后将反馈标记为已解决
* **删除**：删除不再需要的反馈

您还可以使用筛选器整理和查找特定反馈条目。

<div id="republicando-com-configuraes-de-feedback-atualizadas">
  ## 更新反馈设置后重新部署
</div>

App 部署后，您可以随时通过重新部署并使用更新后的设置来启用或禁用反馈小组件：

1. 在部署工具中打开 **概览** 选项卡
2. 选择 **高级设置**
3. 启用或禁用 **启用反馈**
4. 重新部署您的 App 以应用更改

对反馈设置所做的任何更改，都会在 App 重新部署后立即生效。
