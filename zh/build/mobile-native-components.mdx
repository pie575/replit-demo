<div id="why-this-matters">
  ## 为什么这很重要
</div>

每部 iPhone 都内置了提示框、分享面板、开关和菜单，玩家在使用其他 App 时早已
习惯了它们。当你的 App 使用同样的原生组件时，玩家甚至无需点击就知道
如何使用，这正是它看起来像一款真正 iPhone App 的原因。

以下是可添加到你的 App 中的原生组件提示词示例：提示框、操作
表、开关等。

  ## 原生提示框

<div id="sf-symbols">
  ## SF Symbols
</div>

<AiPrompt>
  {sfSymbolsPrompt}
</AiPrompt>

SF Symbols 是 Apple 内置的图标集。图标会自动适配周围文本的
大小、粗细和深色模式；自定义图标集则需要手动实现这些适配。

<Frame caption="“设置”中用于音效和振动的 SF Symbols 图标。">
  <img src="/assets/mirror/native-sf-46d879d1c2c1.png" alt="“音效”和“振动”设置旁的 SF Symbols 图标" data-path="images/pixelgames/mobile/native-sf.png" width="1516" height="310" data-path="images/pixelgames/mobile/native-sf.png" />

<Note>
  SF Symbols 仅适用于 iOS。请让 Agent 为 Android 选择一套相匹配的图标集；不同平台上的图标不会
  像素级完全一致，这是正常现象。
</Note>

<div id="troubleshooting">
  ## 故障排除
</div>

* **提示框或操作表显示成自定义模态框：**确认 Agent 使用的是原生 API，
  而非由 JS 渲染的仿制界面；两者看起来可能相似，但行为不同。
* **图标在 Android 上显示异常：**这是 SF Symbols 特有的预期现象，因为它们仅适用于 iOS。询问
  Agent 使用了哪套备用图标。
* **分享面板中没有您预期的 App：**这由操作系统和测试设备上
  已安装的 App 决定，并非 PixelGames 能直接添加的内容。
