title: "Работа с данными"
description: "Просматривайте, редактируйте, экспортируйте данные и выполняйте запросы к базе данных на вкладке My Data — с помощью визуальных инструментов или SQL."
---

На вкладке **My Data** вы просматриваете и изменяете содержимое своей базы данных. Откройте инструмент **Database**, выберите базу данных, а затем — **My Data**. Работать можно как визуально, так и напрямую через SQL.

<Note>
  Чтобы изменить данные в продакшене, выберите продакшен-базу данных, откройте **My Data** и включите режим **Edit**. Будьте осторожны: это реальные данные вашего приложения в продакшене.
</Note>

<div id="navegar-e-modificar-dados-visualmente">
  ## Просмотр и изменение данных в визуальном интерфейсе
</div>

Инструмент Database включает <a href="https://orm.drizzle.team/drizzle-studio/overview" target="_blank">Drizzle Studio</a> — средство для визуального просмотра и изменения данных. Визуальные инструменты помогают избежать синтаксических ошибок и предоставляют следующие возможности:

* Фильтрация и сортировка данных, чтобы сосредоточиться на нужной информации
* Экспорт данных в файл для внешнего использования
* Добавление и изменение данных в строках
* Создание схем, таблиц, представлений и перечислений, а также управление ими

<div id="executar-comandos-sql">
  ## Выполнение SQL-команд
</div>

SQL runner позволяет выполнять SQL-команды в вашей базе данных и просматривать результаты.

<Accordion title="Как открыть SQL runner">
  В инструменте **Database**:

  1. Выберите вкладку **My Data**
  2. Выберите <img class="icon-svg" src="/assets/mirror/sql-runner-icon-b25868882922.svg" alt="Значок SQL runner" width="16" height="16" data-path="images/icons/sql-runner-icon.svg" /> **SQL runner**
</Accordion>

Чтобы выполнить запрос, введите SQL-выражение в текстовое поле и нажмите расположенную рядом кнопку запуска <img class="icon-svg" src="/assets/mirror/sql-play-8ed26b5de7f1.svg" alt="значок запуска sql" width="18" height="18" data-path="images/icons/sql-play.svg" />:

<Frame>
  <img src="/assets/mirror/sql-runner-run-8ad798a61335.jpg" alt="снимок экрана SQL runner и кнопки запуска" width="1390" height="608" data-path="images/databases/sql-runner-run.jpg" />
</Frame>

<Tip>
  Писать SQL вручную необязательно. Попросите Agent получить или изменить ваши данные — он сам напишет и выполнит SQL.
</Tip>
