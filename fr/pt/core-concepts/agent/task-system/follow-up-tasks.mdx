<div id="sugestes-de-tarefas-de-acompanhamento">
  ## Suggestions de tâches de suivi
</div>

Après avoir appliqué une tâche, Agent examine le contexte de votre projet et suggère des **tâches de suivi** que vous pourriez vouloir créer ensuite. La boîte de dialogue **Prochaines tâches suggérées** affiche directement la recommandation principale, afin que vous puissiez continuer sans quitter le fil de discussion principal.

<Frame>
  <img src="/assets/mirror/follow-up-tasks-dialog-c1660cec2d1d.png" alt="Boîte de dialogue des prochaines tâches suggérées affichant une tâche de suivi avec un bouton Démarrer et un lien pour voir d’autres tâches dans le tableau des tâches" width="495" height="290" data-path="images/agent/follow-up-tasks-dialog.png" />
</Frame>

Les suggestions de suivi peuvent inclure :

* **Nouvelles fonctionnalités à créer** : des fonctionnalités qui s’intègrent naturellement à ce que vous venez de créer
* **Améliorations des performances** : des optimisations qu’Agent a relevées en travaillant sur la tâche
* **Améliorations de l’expérience utilisateur** : des ajustements et des raffinements qui complètent la fonctionnalité

Sélectionnez **Démarrer** sur une suggestion pour l’exécuter en arrière-plan, ou sélectionnez **Voir le plan** pour examiner d’abord le travail proposé. Pour voir toutes les suggestions, sélectionnez **Voir plus dans le tableau des tâches**. Les suivis suggérés apparaissent dans **Suggérées**, dans la colonne **Brouillons**.

<Frame>
  <img src="/assets/mirror/follow-up-tasks-kanban-21087e0210b6.png" alt="Tableau des tâches affichant de nombreuses suggestions de tâches de suivi dans Suggérées, dans la colonne Brouillons" width="980" height="627" data-path="images/agent/follow-up-tasks-kanban.png" />
</Frame>

Fermer la boîte de dialogue **Prochaines tâches suggérées** annule les suggestions. Agent n’affiche pas cette boîte de dialogue dans le fil principal lorsqu’un plan proposé y est déjà en attente, afin que les deux prompts ne se disputent pas votre attention.

<div id="gerenciando-muitas-sugestes-de-uma-vez">
  ## Gérer plusieurs suggestions à la fois
</div>

Pour les projets comportant de nombreuses suggestions de suivi, ouvrez le tableau des tâches et sélectionnez **Modifier** dans la colonne **Brouillons**. En mode édition, chaque tâche suggérée est associée à une case à cocher. Sélectionnez les tâches de votre choix, puis utilisez **Démarrer** ou **Annuler** pour appliquer cette action à chacune d’elles. Sélectionnez **Terminé** pour quitter le mode édition.
