Виджет обратной связи добавляет кнопку в углу опубликованного приложения. С её помощью посетители сообщают о проблемах и предлагают улучшения, не покидая приложение, а вы можете отправить их отзывы прямо в Agent для исправления.

<div id="turn-on-the-feedback-widget">
  ## Включите виджет обратной связи
</div>

1. Откройте инструмент Publishing, выбрав **Publishing** в разделе **Replit Cloud** на панели **Tools**, или нажмите **Publish** в правом верхнем углу Project Editor.
2. В разделе **Engagement tools** включите параметр **Enable feedback widget**.
3. Нажмите **Publish**. Виджет появится в опубликованном приложении.

<div id="position-and-appearance">
  ## Расположение и внешний вид
</div>

При включённом виджете появляются две настройки:

* **Расположение виджета**: выберите угол приложения, в котором будет отображаться виджет: слева вверху, справа вверху, слева внизу или справа внизу. По умолчанию — справа внизу.
* **Внешний вид**: загрузите собственный значок для кнопки виджета и выберите цвет её фона, чтобы виджет вписывался в оформление вашего приложения.

<div id="review-and-act-on-feedback">
  ## Просмотр отзывов и работа с ними
</div>

Отзывы посетителей приходят в ваш почтовый ящик. Оттуда вы можете:

* Прочитать каждый отзыв, чтобы понять, с какими проблемами столкнулись посетители.
* Отправить отзыв в Agent для исправления. Agent возьмёт отзыв в работу как задачу и предложит изменения в приложении.

<div id="turn-it-off">
  ## Как отключить
</div>

Отключите параметр **Enable feedback widget** в инструменте Publishing и опубликуйте приложение заново. Виджет исчезнет из опубликованного приложения.
