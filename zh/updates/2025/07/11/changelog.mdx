<div id="replitmd-documentation">
  ### replit.md 文档
</div>

使用特殊配置文件 `replit.md` 自定义 Agent 的行为，帮助 Agent 了解你的项目偏好、编码风格和架构。Agent 会根据经过验证的最佳实践自动创建此文件，并据此构建完全符合你要求的应用。你可以在同一位置为 Agent 提供项目背景、定义编码规范、指定首选技术 stack 模式，并设置沟通偏好。

<div id="agent-multi-tool-calling-upgrade">
  ### Agent 多工具调用升级
</div>

借助增强的多工具调用系统，可节省 15% 的 Agent 成本，并将结果生成速度提升 30%。Agent 现在能更高效地批量执行操作，更智能地处理工具错误，以更少的资源提供同等质量的结果。
