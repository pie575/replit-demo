<div id="security-scanner-updates">
  ### Security scanner 更新
</div>

Security Scanner 迎来重大更新，带来更快、更智能的安全扫描体验。现在扫描结果会被缓存，仅在代码发生变更时重新运行，后续扫描快如闪电。新增的忽略功能可将你不想看到的安全问题隐藏起来，需要时仍能随时找到。

  ### Agent 系统 prompt 优化
</div>

借助最新的系统改进，Agent 交互更快、更高效。现在 Agent 每个操作可提速 2-3 秒完成 task，同时保持你所期待的高质量结果。
