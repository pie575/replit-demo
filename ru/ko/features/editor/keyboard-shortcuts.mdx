---
title: "Сочетания клавиш"
description: "Узнайте, как просматривать, добавлять и изменять сочетания клавиш, чтобы повысить производительность в Replit."
---

Сочетания клавиш позволяют выполнять команды, редактировать текст и
работать в Project Editor с помощью настраиваемых комбинаций клавиш. Настраивать и использовать сочетания клавиш можно в веб-приложении Replit.com.

<div id="section">
  ## Просмотр сочетаний клавиш
</div>

Чтобы просмотреть настройки сочетаний клавиш, выполните следующие шаги.

1. Откройте Replit App и перейдите в Project Editor.
2. В доке в разделе <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="all tools icon" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools** откройте вкладку <img class="icon-svg" src="/assets/mirror/settings-icon-c2664c3691bf.svg" alt="gear icon" width="16" height="16" data-path="images/icons/settings-icon.svg" /> **User Settings**.
   Либо нажмите на <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="magnifying glass icon" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> лупу и найдите «User Settings».
3. Выберите вкладку **Keyboard shortcuts**, чтобы увидеть список команд и назначенных им сочетаний клавиш.

<div id="section-2">
  ## Настройка сочетаний клавиш
</div>

Чтобы добавить или изменить сочетание клавиш, выполните следующие шаги.

1. Рядом с командой, которой не назначено сочетание, выберите <img class="icon-svg" src="/assets/mirror/create-app-icon-ba218e87fb67.svg" alt="plus icon" width="16" height="16" data-path="images/icons/create-app-icon.svg" />**Add shortcut**,
   а для команды с уже назначенным сочетанием — иконку карандаша <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="pencil icon" width="16" height="16" data-path="images/icons/pencil-icon.svg" />.
2. Когда рядом с командой появится надпись «Recording...», нажмите нужное сочетание клавиш.
   Чтобы отменить запись, щёлкните по пустой области внутри вкладки.
3. Чтобы вернуть исходное сочетание, выберите иконку отката <img class="icon-svg" src="/assets/mirror/rollback-icon-3197ed1b323b.svg" alt="rollback icon" width="12" height="12" data-path="images/icons/rollback-icon.svg" />.

<div id="section-3">
  ## Удаление сочетания клавиш
</div>

Чтобы удалить сочетание клавиш, нажмите значок корзины <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="иконка корзины" width="16" height="16" data-path="images/icons/trash-icon.svg" /> рядом с командой.

<div id="section-4">
  ## Навигация с помощью клавиши Tab
</div>

С помощью клавиши **Tab** в браузере можно переходить между интерактивными элементами страницы.
Однако File Editor, Console и Shell перехватывают нажатия **Tab** для
таких действий, как создание отступов.

Чтобы продолжить переходить между элементами страницы при работе с этими инструментами, выполните следующие действия.

1. Нажмите **Esc**, чтобы снять фокус с инструмента.
2. Нажмите **Tab**, чтобы перейти к следующему элементу.
