export const YouTubeEmbed = ({videoId, title = "YouTube video", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

## プラットフォーム

### ReplitのモバイルApps

<YouTubeEmbed videoId="YSeDWL4cDLs" title="ReplitのモバイルApps" />

シンプルなプロンプトからネイティブiOSアプリを構築できます。AgentがフルのReact Nativeアプリを作成し、データベース、Stripe決済、OpenAIインテグレーションなどの機能を随時追加できます。Expo Goでスキャンコードをスキャンしてアプリをプレビューし、Replitのガイド付きフローを通じてApp Storeに申請できます。AppleがApp Storeを通じてアプリをレビューおよび配布します。

最初のモバイルアプリを構築する準備はできていますか？[ネイティブモバイルApps](/ja/features/artifact-types/building-mobile-apps)でスタートするか、[モバイルアプリの構築とリリース](/tutorials/build-and-launch-a-mobile-app)チュートリアルに従ってください。

<Callout>
  **\$15K モバイルBuildathon**：モバイルBuildathonに参加して素晴らしいものを構築し、賞品を競い合いましょう。[詳細はこちら](https://replit.com/buildathon)。
</Callout>

### Agent chatのツールコールUIの再設計

Agent chatのツールコール表示がよりクリーンでコンパクトなインターフェースになりました。ツールコールがスタックされたアイコンを持つグループ化された行に折りたたまれ、一目で何が起きているかを確認しやすくなりました。ファイルの編集と作成がレビューしやすいようにdiffパネルに直接リンクされます。このスリム化されたデザインにより、ノイズを減らしてより明確にAgentの実行を追跡できます。

### Node.jsセキュリティパッチ

今週、Node.jsに重大なセキュリティ脆弱性が発表されました。すべてのAgent開発環境とReplitのNode.jsアプリケーションはセキュアなバージョンを使用するようにパッチが適用されています。アプリを再公開すると、あなたのアプリもセキュアなバージョンに更新されます。
