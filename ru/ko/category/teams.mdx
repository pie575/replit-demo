Выберите тариф, подходящий для вашей организации. **Pro** — тариф для команд: до 15 разработчиков используют общий пул кредитов без платы за каждого пользователя. **Enterprise** дополнительно предоставляет крупным организациям расширенные возможности безопасности, соответствия требованиям и поддержки. Если у вас несколько организаций Teams, каждое рабочее пространство будет перенесено на отдельную подписку Pro на оставшийся срок, после чего их можно будет объединить.

<div id="pro">
  ## Pro
</div>

Pro предоставляет общие ресурсы и инструменты для совместной работы серьёзным разработчикам и командам:

* **До 15 разработчиков**: без платы за место — все работают на одном тарифе с общим пулом кредитов
* **Многоуровневые кредиты**: несколько уровней. Неиспользованные кредиты переносятся на {ProCreditRolloverPeriod}. Текущие уровни указаны на [странице цен](https://replit.com/pricing)
* **Турборежим**: Agent работает в 2,5 раза быстрее при включении отдельного переключателя (по умолчанию: выключен). Доступен в Pro и Enterprise; в Enterprise администратор должен сначала включить эту функцию для всей организации.
* **Приватные деплои**: безопасный хостинг приложений с контролируемым доступом
* **Места для зрителей**: позволяют заинтересованным лицам и пользователям, не являющимся разработчиками, пользоваться опубликованными приватными приложениями
* **Единые настройки**: настройка приложений, отслеживание Usage по рабочему пространству, управление оплатой и пользователями в одном месте

<div id="enterprise">
  ## Enterprise
</div>

Enterprise включает все функции Pro, а также расширенные возможности безопасности, контроля и поддержки для организаций:

<CardGroup cols={2}>
  <Card title="Безопасность Enterprise" icon="shield-check">
    Платформа, соответствующая требованиям SOC 2, SSO/SAML, подготовка учётных записей через SCIM и расширенные средства контроля безопасности.
  </Card>

  <Card title="Централизованное управление" icon="folder-open">
    Управляйте командами, биллингом и ресурсами из централизованной панели управления. Отслеживайте Usage и эффективно контролируйте расходы.
  </Card>
</CardGroup>

* **SSO/SAML с подготовкой учётных записей через SCIM**: защитите доступ команды с помощью единого входа и автоматической подготовки учётных записей пользователей
* **Выделенные среды разработки**: управление доступом на основе ролей с использованием групп IdP для детализированных разрешений
* **Контроль администратора**: требование частных деплоев и обязательное статическое сканирование безопасности перед публикацией
* **Центр безопасности рабочего пространства**: обнаруживайте CVE в зависимостях по уровню серьёзности. Просматривайте затронутые приложения и скачивайте SBOM для соблюдения требований.
* **Настраиваемые разрешения для интеграций**: определяйте границы доступа к собственным интеграциям во всей организации
* **Крупные VM для деплоя**: используйте увеличенные размеры VM для масштабируемого хостинга приложений
* **Выделенная поддержка**: воспользуйтесь услугами выделенного менеджера по работе с клиентами и инженера по продажам для поддержки платформы
* **Коннекторы данных Enterprise**: подключайтесь к Snowflake, BigQuery и Databricks для бесшовной интеграции данных
* **Неограниченные места для зрителей**: предоставляйте заинтересованным лицам и пользователям, не занимающимся разработкой, неограниченный доступ к опубликованным частным приложениям

<div id="section-2">
  ## Примеры использования
</div>

Pro и Enterprise отвечают разнообразным потребностям организаций любого масштаба:

* **Корпоративные приложения**: создание и публикация критически важных приложений с безопасностью и масштабируемостью корпоративного уровня
* **Бизнес-инструменты**: разработка и поддержка бизнес-инструментов с эффективным управлением доступом
* **Быстрое прототипирование**: ускорение инноваций благодаря мгновенно доступной среде разработки
