<div id="temas-de-aplicativos">
  ### Темы приложений
</div>

Придайте своим веб-приложениям профессиональный вид с помощью красивых тем. Применяйте пользовательские стили и делитесь темами с командой, чтобы поддерживать единый визуальный стиль во всех проектах.

<Frame>
  <img src="/assets/mirror/manage-custom-themes-8de2e9223013.png" alt="Менеджер тем с возможностью создавать, редактировать и удалять пользовательские темы" width="1772" height="1062" data-path="images/replitai/app-themes/manage-custom-themes.png" />
</Frame>

Подробнее о [работе с темами приложений](/ru/replitai/app-themes).

Некоторые элементы интерфейса вдохновлены [tweakcn](https://github.com/jnsahaj/tweakcn). Ознакомьтесь с открытым репозиторием Sahaj Jain [здесь](https://github.com/jnsahaj/tweakcn).

<div id="links-de-criao-de-aplicativos-compartilhveis">
  ### Ссылки для создания приложений, которыми можно делиться
</div>

Делитесь возможностями создания приложений с помощью ИИ. Создавайте ссылки, по которым приложения автоматически создаются на основе ваших промптов, чтобы проще обмениваться идеями и помогать другим начать работу.

```md theme={null}
replit.com/create?prompt="Make me a cool demo for my app idea"
```

<div id="atualizaes-de-infraestrutura-do-agent">
  ### Обновления инфраструктуры Agent
</div>

Agent теперь работает на улучшенной инфраструктуре с более эффективным управлением задачами, более развитыми возможностями анализа и увеличенной продолжительностью рабочих сессий. Эти улучшения помогают Agent справляться с более крупными проектами и достигать лучших результатов при выполнении любых задач по написанию кода.

  ### Отмена подписки организации
</div>
