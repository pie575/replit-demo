<div id="os-templates-de-developer-frameworks-foram-removidos">
  ## Шаблоны фреймворков для разработчиков удалены
</div>

Стартовые шаблоны языков и фреймворков (ранее — фреймворки для разработчиков) больше не доступны в Replit. Страницы `replit.com/templates` и `replit.com/developer-frameworks` теперь перенаправляют в [Replit Gallery](https://replit.com/gallery).

Чтобы начать новый проект, воспользуйтесь одним из следующих вариантов:

* **Начните с Replit Agent** — опишите на [главной странице](https://replit.com/), что вы хотите создать, и Agent сам выстроит структуру проекта.
* **[Импортируйте из GitHub, GitLab или Bitbucket](/ru/pt/build/import-from-providers)** — перенесите существующую кодовую базу или стартовый стек как новый Replit App.
* **[Сделайте ремикс опубликованного приложения](https://replit.com/gallery)** — найдите в Replit Gallery приложения сообщества, которые можно открыть и взять за отправную точку для ремикса.

<div id="templates-personalizados-para-enterprise">
  ## Пользовательские шаблоны для Enterprise
</div>

Организации Enterprise могут создавать [пользовательские шаблоны](/ru/pt/teams/custom-templates), которые отображаются во входящих Agent как доступные для выбора варианты для всех участников организации. Пользовательские шаблоны — это больше, чем фреймворки для разработчиков: они включают корпоративные инструкции для Agent, навыки и заранее настроенный контекст проекта. Подробнее см. в [руководстве по пользовательским шаблонам](/ru/pt/teams/custom-templates).
