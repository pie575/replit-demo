### Design Mode: 2분 안에 멋진 웹사이트 만들기

Design Mode가 출시되었습니다. Google의 Gemini 3로 구동되는 Design Mode는 2분 안에 아름다운 인터랙티브 디자인과 정적 웹사이트를 생성합니다—이전보다 더 빠르고 더 멋진 결과를 Replit에서 제공합니다.

빠른 프로토타이핑, 랜딩 페이지, 간단한 웹사이트에 적합한 Design Mode는 백엔드 복잡성 없이 시각적 품질에 집중합니다. 기능이 필요할 때는 클릭 한 번으로 디자인을 풀 앱으로 변환할 수 있습니다.

### 모든 사용자에게 Fast Mode 제공

Fast Mode가 이제 모든 사용자에게 제공되며 **12월 1일까지 무료**입니다. Replit 프로젝트 전반에서 더 빠른 실행 속도로 더 빠르게 빌드하고 반복할 수 있습니다.

### ZIP 아카이브 직접 가져오기

`.zip` 아카이브를 새 앱으로 직접 가져올 수 있습니다. Replit이 자동으로 파일을 다운로드하고 Replit App에 압축을 해제하므로, 기존 프로젝트에서 즉시 빌드하고 협업을 시작할 수 있습니다.

### 향상된 Atlassian 커넥터

Atlassian 커넥터(Jira, Confluence)가 이제 액세스 토큰에서 사이트 URL을 자동으로 감지하여 수동 설정을 없앴습니다. 이 간소화된 연결 흐름으로 번거로움을 줄이고 설정 시간을 절약할 수 있습니다.

### HoundDog 개인정보 스캔 통합

HoundDog이 이제 보안 스캐너에 통합되었습니다. 로그나 외부 서비스를 통해 유출될 수 있는 PII, API 키, 자격 증명 등 민감한 데이터 노출을 자동으로 감지합니다. Semgrep과 결합하여 포괄적인 보안 커버리지를 제공합니다.
