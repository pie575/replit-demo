Replit을 사용할 때는 Conversation에서 작업하거나 Project를 빌드하게 됩니다. Conversations는 질문, 탐색, 후속 작업, Routines를 위한 것입니다. Projects는 애플리케이션을 빌드하고 슬라이드와 디자인을 만들기 위한 것입니다.

[Conversation을 Project로 전환하는 방법을 알아보세요.](/ko/chat/continue-or-create-a-project)

## 차이점

서로 연결되어 있지만 Conversations와 Projects는 서로 다른 목적을 수행합니다. 다음은 그 차이점입니다:

| 영역         | Conversations         | Projects                                                                                               |
| ---------- | --------------------- | ------------------------------------------------------------------------------------------------------ |
| 적합한 용도     | 질문, 탐색, Routines      | 앱, 슬라이드, 대시보드, 여러 아티팩트 등 더 심층적인 빌드 및 디자인 작업                                                            |
| 구조         | 단일 스레드                | 여러 아티팩트가 있는 Project 워크스페이스                                                                             |
| 백그라운드 작업   | 사용 불가                 | 병렬로 실행 가능                                                                                              |
| Routines   | 사용 가능                 | 사용 불가                                                                                                  |
| 통합         | 사용 가능                 | 사용 가능                                                                                                  |
| 생성 가능 항목   | 문서, 이미지, 시트 등의 Assets | 문서, 이미지, 시트 등의 Assets, 그리고 슬라이드, 앱, 웹사이트 등의 [Artifacts](/ko/features/projects-and-artifacts/artifacts) |
| Publishing | 게시할 수 없음              | 게시하여 공개할 수 있음                                                                                          |
