Инструмент Users &amp; Auth управляет пользователями вашего приложения и способами их входа. Откройте **Users &amp; Auth** в разделе **Replit Cloud** на панели **Tools**.

В инструменте две вкладки:

* **Users**: все, кто входил в ваше приложение, с указанием имени и времени последнего входа. Используйте поиск по списку, чтобы найти нужного пользователя.
* **Configure**: настройки входа в ваше приложение — название и значок на экране входа, доступные для входа провайдеры и секрет сессии.

<Note>
  Этот инструмент управляет пользователями **вашего приложения** — теми, кто регистрируется и входит в созданный вами продукт. Чтобы определить, кто вообще может открыть опубликованное приложение, см. [Кто может получить доступ к вашему приложению](/ru/features/publishing/private-deployments).
</Note>

<div id="choose-your-auth-system">
  ## Выберите систему аутентификации
</div>

* **[Replit Auth](/ru/features/auth-and-identity/authentication)**: вариант, не требующий настройки. Попросите Agent добавить Replit Auth — и ваше приложение получит готовую страницу входа, управление пользователями и безопасные сессии без какой-либо конфигурации.
* **[Clerk](/ru/features/auth-and-identity/clerk-auth)**: полнофункциональный сервис аутентификации для приложений, которым нужно больше контроля, — например, собственные сценарии входа и свой брендинг OAuth. Настройте [собственные провайдеры входа](/ru/features/auth-and-identity/sign-in-providers) для Google, GitHub, Apple и X.
