<div id="personal-vs-team-workspaces">
  ## 个人 workspace 与团队 workspace
</div>

**workspace** 是承载你的应用、成员、设置和账单的结构。Replit 提供两种类型：

* 个人 workspace
* 团队 workspace

个人 workspace 与团队 workspace 的区别如下：

|          | 个人 workspace         | 团队 workspace                 |
| -------- | -------------------- | ---------------------------- |
| **角色**   | 管理员、project 级访客      | 管理员、成员、project 级访客           |
| **访问模式** | 你将访客邀请到单个 project    | 成员可访问 workspace 中的所有 project |
| **账单**   | 你的账户                 | 来自管理员账户的共享积分池                |
| **成员管理** | 按 project 管理 (加入链接)  | 在 workspace 设置中集中管理          |

如果你独自开发，或只想与他人共享单个 project，**个人 workspace** 最为合适。你是唯一的管理员，其他人只能以 project 级访客身份访问你邀请他们加入的特定 project。

如果你与固定的一群人协作开发——比如创业团队、课堂或有多位参与者的客户 project——**团队 workspace** 更为合适。成员可访问 workspace 中的所有 project，无需为每个 project 逐一邀请。成员统一在**设置**中集中管理。

<div id="when-to-invite-to-your-workspace-vs-to-a-project">
  ### 何时邀请加入 workspace，何时邀请加入 project
</div>

| 场景                       | 应该怎么做                                   |
| ------------------------ | --------------------------------------- |
| 需要访问所有内容的长期协作者           | 邀请加入 workspace                          |
| 只需参与某一个 project 的外包人员或访客 | [邀请加入 project](/zh/build/invite-teammates) |
| 新入职公司的团队成员               | 邀请加入 workspace                          |
| 帮你调试某个应用的朋友              | [邀请加入 project](/zh/build/invite-teammates) |

<div id="create-a-team-workspace">
  ## 创建团队 workspace
</div>

<Frame>
  <img src="/assets/mirror/create-team-workspace-e89eaefd9168.png" alt="创建新 workspace 的表单，其中填有通用的 workspace 名称，以及一个用于邀请团队成员的空白字段" width="784" height="300" data-path="images/workspace/create-team-workspace.png" />
</Frame>

<Steps>
  <Step title="打开 workspace 切换器">
    在主页左上角点击你的 workspace 名称。
  </Step>

  <Step title="创建新的 workspace">
    选择 **Create workspace**，并为团队 workspace 命名。
  </Step>

  <Step title="邀请成员">
    在邀请框中输入一个或多个电子邮件地址 (以逗号分隔) 。受邀者会收到邀请，接受后即可访问该 workspace 中的所有 project。
  </Step>
</Steps>

<div id="managing-members">
  ## 管理成员
</div>

如果你在初始设置时没有邀请成员，或之后需要添加更多成员，请在团队 workspace 中前往 **设置 &gt; Workspace collaborators**，通过电子邮件或 Replit 用户名邀请成员。

<Frame>
  <img src="/assets/mirror/invite-workspace-members-6e3fda413196.jpg" alt="邀请用户对话框，含用于输入电子邮件地址的空白字段" width="510" height="244" data-path="images/workspace/invite-workspace-members.jpg" />
</Frame>

在 **设置** 页面，你还可以：

* **移除成员**，撤销其对所有 workspace project 的访问权限
* 将 project 从个人 workspace **转移**到团队 workspace —— 参阅[将应用转移到 Teams](/zh/teams/identity-and-access-management/transfer-app-to-teams)

  <Warning>
    在 workspace 之间转移 project 的功能已暂时停用，你目前无法发起新的转移。
  </Warning>

如需高级身份管理、基于角色的访问控制和群组权限，请参阅 [Pro 与 Enterprise](/zh/category/teams)。
