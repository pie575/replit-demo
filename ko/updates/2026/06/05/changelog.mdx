<div id="sell-physical-products-with-shopify">
  ### Shopify로 실물 상품 판매하기
</div>

이제 실물 상품을 판매하는 온라인 스토어를 만들 수 있습니다. Agent에게 상점을 만들어 달라고 요청하면 Shopify 스토어를 생성하고 상품을 추가한 뒤 장바구니와 결제까지 설정해 줍니다. Agent가 스토어 소유권을 넘겨받을 수 있는 링크를 전달하면, Shopify 요금제에 가입하고 결제 수단을 연결해 스토어를 공개하면 됩니다.

<div id="build-data-apps-on-microsoft-fabric">
  ### Microsoft Fabric에서 데이터 앱 빌드하기
</div>

이제 Replit에서 AI 기반 데이터 앱을 만들어 Microsoft Fabric으로 바로 publish할 수 있습니다. Microsoft Fabric template으로 시작해 Power BI 시맨틱 모델을 연결한 다음, Agent에게 요청해 거버넌스가 적용된 엔터프라이즈 데이터를 기반으로 dashboard와 사내 도구를 만들어 보세요. authentication과 접근 정책은 Fabric 안에 그대로 유지됩니다.

<div id="custom-domains-set-up-their-own-dns">
  ### custom domain이 DNS를 알아서 설정합니다
</div>

이제 직접 보유한 도메인을 훨씬 간편하게 연결할 수 있습니다. 도메인을 연결하면 Replit이 Entri를 통해 필요한 DNS 레코드를 대신 설정해 주므로, 더 이상 도메인 provider에 레코드를 일일이 복사해 넣을 필요가 없습니다. 도메인을 고르고 확인하기만 하면 나머지는 Replit이 알아서 처리합니다.

[custom domain](/ko/features/publishing/custom-domains)에 대해 자세히 알아보세요.

<div id="use-stripe-in-collaborative-workspaces">
  ### 협업 workspace에서 Stripe 사용하기
</div>

이제 협업 workspace에서도 Stripe를 사용할 수 있습니다. 팀 전체가 하나의 App을 함께 빌드하고 테스트하며 수익화할 수 있습니다. workspace의 모든 구성원이 연결된 Stripe 계정을 함께 사용할 수 있으므로, 혼자서 payments를 구축할 필요가 없습니다.

자세한 내용은 [Stripe Payments](/ko/features/monetization/stripe-payments)를 참고하세요.
