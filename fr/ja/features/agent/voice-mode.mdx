---
title: "Mode vocal"
description: "Envoyez des prompts à Agent à la voix plutôt qu’en les saisissant. Le mode vocal transcrit vos paroles en texte dans la zone de chat afin que vous puissiez les vérifier avant de les envoyer."
---

Utilisez le mode vocal pour décrire à voix haute ce que vous souhaitez créer. Appuyez sur le microphone dans la zone de chat d’Agent et parlez : Replit transcrit votre voix en texte. Vérifiez et modifiez le texte, puis envoyez-le comme un message normal.

Le mode vocal est utile lorsque la saisie est lente ou peu pratique — surtout sur mobile, où dicter un prompt complet est souvent plus rapide que de taper avec les pouces.

<Note>
  Le mode vocal convertit votre voix en texte dans la zone de chat. Il ne lit pas les réponses d’Agent à voix haute — vous envoyez toujours des messages écrits et Agent répond dans le chat.
</Note>

  ## Fonctionnement
</div>

Le mode vocal enregistre et transcrit votre voix, puis insère le résultat dans la zone de chat afin que vous puissiez le vérifier avant l&#39;envoi :

1. Ouvrez Agent et sélectionnez le micro dans la zone de chat.
2. Autorisez l&#39;accès au micro si votre navigateur ou votre appareil vous le demande.
3. Énoncez votre prompt. Une forme d&#39;onde indique qu&#39;Agent est en train d&#39;enregistrer.
4. Arrêtez l&#39;enregistrement lorsque vous avez fini de parler. Il s&#39;arrête automatiquement après une pause ou si vous changez d&#39;onglet.
5. Patientez quelques instants, le temps que votre voix soit transcrite.
6. Vérifiez le texte transcrit, modifiez-le si nécessaire, puis envoyez votre message.

Comme le texte s&#39;affiche dans la zone de chat habituelle, vous pouvez combiner librement la voix et la saisie au clavier : dictez une partie de votre prompt, tapez le reste, ou corrigez un mot avant l&#39;envoi.

<Tip>
  Parlez naturellement. Le mode vocal privilégie la compréhension du sens plutôt qu&#39;une transcription littérale : les mots de remplissage comme « euh » ou « hum » sont donc écartés du résultat.
</Tip>

<div id="section-2">
  ## Où l’utiliser
</div>

Le mode vocal est disponible dans la zone de chat Agent :

* Dans l’**éditeur de projet**, lorsque vous travaillez sur une application avec Agent.
* Lorsque vous **créez une application** depuis l’invite Agent de l’écran d’accueil.

Le mode vocal est disponible sur le web sur ordinateur, le web mobile et l’application mobile Replit.

<div id="section-3">
  ## Ce qu&#39;il faut savoir
</div>

Gardez ces détails à l&#39;esprit lorsque vous utilisez le mode vocal :

| Détail                     | Description                                                                                                                                                                                                    |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Durée d&#39;enregistrement | Vous pouvez enregistrer jusqu&#39;à 6 minutes d&#39;affilée. Un avertissement s&#39;affiche à l&#39;approche de la limite.                                                                                     |
| Arrêt automatique          | L&#39;enregistrement s&#39;arrête automatiquement après environ 30 secondes de silence, ou si vous changez d&#39;onglet ou placez l&#39;application en arrière-plan.                                           |
| Vérification avant envoi   | Le texte transcrit s&#39;affiche dans la zone de chat : vous pouvez donc le relire et le modifier avant de l&#39;envoyer — il n&#39;est pas envoyé automatiquement.                                      |
| Accès au microphone        | Le mode vocal nécessite l&#39;autorisation d&#39;utiliser votre microphone. Si l&#39;enregistrement ne démarre pas, vérifiez que votre navigateur et votre appareil autorisent Replit à accéder au microphone. |

<div id="section-4">
  ## Formules disponibles
</div>

Le mode vocal est disponible avec toutes les formules Replit. Le micro apparaît dans la zone de chat d&#39;Agent sur les navigateurs et les appareils compatibles avec l&#39;enregistrement audio ; l&#39;autorisation d&#39;accès au micro vous est demandée lors de votre premier enregistrement.
