Memories, Custom Instructions, Skills는 각각 Replit이 더 나은 context를 바탕으로 작업하도록 돕습니다. 해당 정보가 지속적으로 적용할 규칙인지, 반복 가능한 절차인지, 과거 작업에서 얻은 유용한 context인지에 따라 알맞은 것을 선택하세요.

|                         | 관리 주체             | Replit이 사용하는 시점    | 적합한 용도                           |
| ----------------------- | ----------------- | ------------------ | -------------------------------- |
| **Custom Instructions** | 사용자 또는 팀          | 항상, 모든 session에 걸쳐 | 일관되게 적용하려는 고정된 선호 사항과 규칙         |
| **Skills**              | 사용자 또는 팀          | 특정 task와 관련이 있을 때  | 반복 가능한 절차, workflow, 보조 자료       |
| **Memories**            | Replit(사용자 감독 하에) | 관련 context가 유용할 때  | 과거 작업에서 얻은 유용한 선호 사항을 다시 설명하지 않기 |

<div id="choose-the-right-tool">
  ## 적합한 도구 선택하기
</div>

* 승인된 라이브러리나 데이터 처리 요건처럼 Workspace 전반에 항상 적용되어야 하는 규칙에는 **Custom Instructions**를 사용하세요. 직접 작성하는 항목이며, Replit이 임의로 수정하지 않습니다.
* release 준비나 design 검토처럼 특정 유형의 작업에 반복해서 쓸 수 있는 방식에는 **Skill**을 사용하세요. 안정적인 절차적 지식은 Skills에 담는 것이 적합합니다.
* Replit이 이전 작업에서 얻은 유용한 context를 기억하게 하려면 **Memories**를 사용하세요. 관련 선호 사항을 매번 다시 알려줄 필요가 없어집니다. Replit은 작업 중에 Memories를 직접 작성할 수 있으며, 이는 실행되는 지시가 아니라 맥락을 뒷받침하는 근거입니다.

명시적인 요청과 Custom Instructions는 Memories보다 우선합니다. Memories는 **Settings → Customization → Memory**에서 관리하세요. Memories에는 개인 정보나 민감한 정보가 저장되지 않으며, 기본적으로 비공개입니다. 공동 작업자와의 공유는 선택 사항이며 기본값은 꺼짐입니다.
