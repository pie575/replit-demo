<div id="section">
  ## 选择模式
</div>

* **免费模式：** 探索创意、提出问题、开始构建，无需中断日常工作。免费模式会通过智能模型路由选择模型。 {FreeModePlanAvailability}
* **Power Mode：** 在速度和能力之间实现良好平衡，适合大多数任务。当你需要超出免费模式额度的能力，或想在现有项目中使用更强大的默认设置时，请使用此模式。
* **Max Mode：** 最适合处理复杂且雄心勃勃的任务、大型代码库和棘手问题。

Power Mode 和 Max Mode 会消耗每月积分。在请求从免费模式切换到会产生使用费用的模式前，Replit 会通知你。你可以在 **设置** → **使用情况** 中查看剩余的免费模式额度。实用技巧请参阅[充分利用免费模式](/zh/ja/chat/free-mode)。

Routine 会在 Power Mode 或 Max Mode 下运行，每次运行都需要相应的预算。免费模式无法运行 Routine。有关详细信息，请参阅[Routine](/zh/ja/chat/routines)。
