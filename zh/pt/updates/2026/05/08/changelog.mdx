<div id="workspace-security-center-20">
  ### Workspace 安全中心 2.0
</div>

在一处集中查看并处理 workspace 中所有项目的依赖项漏洞。Workspace 安全中心 现在会一眼呈现风险最高的项目，并支持按严重性、发布状态、可见性和所有者搜索、筛选受影响的项目。你还能在不离开安全中心的情况下走完整个修复流程：启动 Agent 任务，查看建议的修复方案，然后重新部署项目。你可以逐个或批量通知项目所有者，即时下线高暴露面的项目，并下载 SBOM 用于合规审计。

<div id="publicao-privada-para-todos">
  ### 私有部署，人人可用
</div>

私有的、受密码保护的应用部署此前仅限 Pro 和 Enterprise 套餐使用。现在，Core 和 Starter 套餐的构建者也可以进行私有部署，这样任何人都能将内部工具、Beta 版应用或开发中的项目置于 Replit 登录保护之后。

进一步了解[私有部署](/zh/pt/cloud-services/deployments/private-deployments)。

<div id="tokens-de-acesso-externo-para-deployments-privados">
  ### 私有部署的外部访问 token
</div>

外部访问 token 现已支持私有 Replit Apps。你可以创建 token 来配置 Slack、GitHub、Twilio 等集成，让它们独立于连接器访问你的私有部署。这让高级用户对自己的应用拥有更强的控制力，也让私有 Replit Apps 更加安全。在部署中打开**调整设置**，即可找到新增的**外部访问 token**标签页。

进一步了解[外部访问 token](/zh/pt/cloud-services/deployments/external-access-tokens)。

<div id="notas-do-apresentador-e-modo-apresentao-em-slide-decks">
  ### 幻灯片演示文稿的演讲者备注与演示模式
</div>

幻灯片演示文稿现已支持演讲者备注和专门的演示模式。备注会在编辑器与演示窗口之间双向实时同步，你可以用一台设备共享屏幕，同时用另一台设备远程控制演示文稿。你还可以让 Agent 帮你撰写备注，再在编辑器中细致润色，而观众只会看到幻灯片本身。在移动端，幻灯片 artifact 卡片上也可以使用演示模式。

<div id="agent-aceita-uploads-de-svg">
  ### Agent 支持上传 SVG
</div>

现在你可以向 Agent 附加 SVG 文件。将 SVG 拖入 Chat 或粘贴一个 URL，Agent 就能像读取其他附件一样读取其中的标记内容。上传的文件会先在你的浏览器中完成净化处理，然后才发送到 Agent 或存储，常见的 SVG 攻击向量会被自动清除。

<div id="novos-cones-animados-para-os-modos-do-agent">
  ### Agent 模式全新动画图标
</div>

Agent 的 Lite、Economy 和 Power 模式现已拥有定制的全新动画图标，生动体现各模式的特点。新图标会显示在 Agent 模式选择器中，以及 workspace 内所有展示模式的位置。
