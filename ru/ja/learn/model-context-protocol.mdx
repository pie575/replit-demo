ИИ-модели вроде Claude или GPT обладают большими возможностями, но ограничены тем, на чём они обучались. Model Context Protocol (MCP) предлагает стандартный способ подключения к внешним инструментам, источникам данных и возможностям реального мира.

<div id="aimcp">
  ## Почему моделям ИИ нужен MCP
</div>

Без доступа к внешним инструментам и данным модели ИИ не могут:

* получать актуальную информацию
* взаимодействовать с внешними системами
* выполнять действия в реальном мире
* работать с закрытыми данными

MCP решает эту проблему, создавая универсальный способ подключения ИИ к инструментам и данным — подобно тому, как USB-C стандартизировал подключение устройств.

  <img src="/assets/mirror/mcp-a04e01a01743.avif" alt="Схема MCP: модель ИИ, подключённая к внешним инструментам и источникам данных" width="1920" height="1055" data-path="images/tutorials/mcp.avif" />
</Frame>

Благодаря MCP модели ИИ могут:

* обращаться к специализированным инструментам и API
* читать данные из закрытых источников
* выполнять действия в реальном мире
* бесшовно подключаться к другим системам

<div id="mcp">
  ## Как работает MCP
</div>

Архитектура MCP состоит из трёх основных компонентов:

1. **Клиентская сторона** — Claude, ИИ-приложения и всё остальное, чему нужен доступ к внешним инструментам.
2. **Уровень обмена данными** — сам протокол, стандартизирующий формат запросов и ответов.
3. **Серверная сторона** — программы, которые предоставляют доступ к инструментам, источникам данных и специализированным возможностям.

<AccordionGroup>
  <Accordion title="Что такое MCP-клиент?">
    MCP-клиент — это, например, Claude, Replit Agent или интерфейс командной строки, подключающийся к большой языковой модели. Это «устройство», которое соединяется с внешними инструментами и источниками данных.

    Примеры MCP-клиентов:

    * Claude в браузере
    * Replit Agent
    * Интерфейсы командной строки для ИИ
    * Собственные приложения, созданные с помощью AI SDK
  </Accordion>

  <Accordion title="Что такое MCP-сервер?">
    MCP-сервер предоставляет ИИ-моделям инструменты и возможности. Это всё равно что дать ИИ набор специализированных инструментов для решения задач.

    Что позволяют делать MCP-серверы:

    * Обращаться к нужным источникам данных, чтобы отвечать на вопросы
    * Подключать ИИ к API, чтобы он мог выполнять действия в интернете
    * Читать и записывать файлы
    * Выполнять вычисления и запускать код
    * Получать контент из таких сервисов, как Notion, Linear и Stripe
  </Accordion>
</AccordionGroup>

<div id="mcp-2">
  ## Возможности MCP
</div>

MCP определяет несколько примитивов, которые расширяют возможности AI-приложений:

* **Ресурсы** — предоставляют AI-моделям доступ к данным и контенту
* **Инструменты** — позволяют AI-моделям выполнять действия через сервисы
* **Промпты** — повторно используемые шаблоны для единообразного взаимодействия с AI
* **Сэмплирование** — позволяет сервисам запрашивать информацию у AI-моделей
* **Транспорт** — обеспечивает эффективное соединение клиентов и серверов

<div id="vs-mcp">
  ## Навыки и MCP-серверы
</div>

Навыки и MCP-серверы — это два основных способа расширить возможности ИИ-агентов, и у каждого своё назначение.

|                     | Навыки                                                               | MCP-серверы                                                |
| ------------------- | -------------------------------------------------------------------- | ---------------------------------------------------------- |
| **Лучше всего для** | Рабочие процессы, соглашения, справочные материалы                   | Подключение к внешним сервисам, выполнение действий        |
| **Загрузка**        | Лёгкая — до вызова загружаются только имя и описание                 | Тяжёлая — все описания инструментов загружаются сразу      |
| **Определяет**      | *Как* Agent должен действовать                                       | *К чему* Agent имеет доступ                                |
| **Пример**          | Навык «Анализатор акций» — исследует инвестиции по заданной методике | MCP-сервер «Stripe» — читает данные о платежах и подписках |

О соответствующем подходе к навыкам см. [Навыки Agent](/ru/ja/learn/agent-skills).

<div id="section">
  ## Практическое применение
</div>

MCP позволяет создавать широкий спектр ИИ-приложений:

* **Системы поддержки клиентов** — обращаются к базам данных компании, чтобы отвечать на конкретные вопросы
* **Исследовательские помощники** — ищут и обобщают информацию из нескольких источников
* **Инструменты повышения продуктивности** — взаимодействуют с файлами и приложениями
* **Инструменты для создания контента** — получают доступ к медиатекам и платформам для публикации

<div id="section-2">
  ## Преимущества
</div>

MCP даёт три ключевых преимущества:

* готовые интеграции, к которым ИИ подключается сразу
* возможность сменить поставщика ИИ, не переписывая подключения
* функции безопасности для защиты конфиденциальных данных

<Note>
  MCP — это развивающийся стандарт, поддержка которого расширяется по всей экосистеме ИИ. Новые инструменты и интеграции добавляются регулярно.
</Note>
