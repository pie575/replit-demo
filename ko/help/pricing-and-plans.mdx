아래 답변에서는 요금제와 가격에 대해 안내합니다. 요금제별 자세한 내용은 [Starter](/ko/billing/plans/starter-plan), [Core](/ko/billing/plans/replit-core), [Pro](/ko/billing/plans/replit-pro)를 참조하고, 최신 요금은 [가격 페이지](https://replit.com/pricing)에서 확인하세요.

<AccordionGroup>
  <Accordion title="Agent 사용량 요금은 어떻게 책정되며, Plan mode에서도 요금이 청구되는 이유는 무엇인가요?">
    Free Mode에서는 각 plan의 allowance 범위 내에서 Agent 작업을 무료로 사용할 수 있습니다. Core와 Pro의 allowance는 5시간마다 초기화되며 주간 limit이 적용됩니다. Starter 등급은 기존 limit을 그대로 유지합니다. **Settings → Usage**에서 usage를 확인하세요.

    Core와 Pro에서는 Power 또는 Max에서 Auto를 선택하면 Replit이 유료 작업에 사용할 model을 대신 선택해 줍니다. 사용 가능한 model을 직접 선택할 수도 있습니다.

    유료 모드와 확인을 거친 유료 작업에는 요청 복잡도에 따른 [effort-based pricing](/ko/billing/ai-billing)이 적용됩니다. Plan Mode는 코드를 변경하지 않더라도 유료 경로에서 과금 대상 추론을 수행할 수 있습니다. Replit은 유료 작업을 시작하기 전에 항상 확인을 요청합니다.

    일상적인 작업은 [Free Mode](/ko/features/agent/agent-modes)로 시작하세요. 합리적인 가격으로 더 높은 성능이 필요하다면 [Power mode](/ko/features/agent/agent-modes)를 선택하세요. [Plan mode](/ko/features/agent/plan-mode)로 작업 범위를 정할 수도 있으며, [지출 관리](/ko/billing/managing-spend)에서 usage limit과 예산을 설정할 수 있습니다. 청구 내역을 항목별로 확인하려면 **Settings → Account usage**를 열고 **See previous invoices**를 선택하세요.
  </Accordion>

  <Accordion title="Starter, Core, Pro 요금제에는 각각 무엇이 포함되나요?">
    각 plan은 빌드 과정의 서로 다른 단계에 맞춰져 있습니다:

    * **Starter**는 무료이며, 일일 Agent allowance와 제한된 월간 클라우드 credits, 기본 Agent 이용, published app 1개를 제공합니다. [Starter plan](/ko/billing/plans/starter-plan)을 참고하세요.
    * **Core**는 월 {CoreCredits} credits, Plan 및 Build 모드를 모두 갖춘 Agent, 병렬 Agent task 1개, 최대 5명의 협업자, 무제한 published apps, 7일 database 복원 기간을 제공합니다. [Core plan](/ko/billing/plans/replit-core)을 참고하세요.
    * **Pro**(월 {ProPlanPrice})는 더 많은 Free Mode usage, 최대 10개의 병렬 Agent tasks, 최대 15명의 builders를 추가로 제공합니다. 또한 등급별 credits와 28일 database 복원 기간이 포함됩니다. 사용하지 않은 credits는 {ProCreditRolloverPeriod} 동안 이월됩니다. [Pro plan](/ko/billing/plans/replit-pro)을 참고하세요.

    plan별 비교와 최신 pricing은 [pricing page](https://replit.com/pricing)에서 확인하세요.
  </Accordion>

  <Accordion title="Replit에서 학생 또는 교육 할인을 제공하나요?">
    Replit은 학생과 교육자를 위한 교육 프로그램을 운영합니다. 현재 지원 자격, 할인 혜택, 신청 방법은 [replit.com/education](https://replit.com/education)에서 확인하세요.

    <Note>구체적인 할인 금액과 지원 자격 기준은 교육 프로그램에서 관리하며 변경될 수 있습니다. 교육 페이지의 내용이 기준이 됩니다.</Note>
  </Accordion>

  <Accordion title="연간 결제는 어떻게 이루어지며, 얼마나 절약할 수 있나요?">
    연간 결제를 선택하면 1년치를 미리 결제하는 대신 실질 월 요금이 더 낮아집니다. [Core](/ko/billing/plans/replit-core)는 연 {CoreAnnualPrice}입니다. 전환하려면 구독하거나 플랜을 변경할 때 연간 옵션을 선택하세요. 다른 플랜과 현재 할인 혜택은 [요금제 페이지](https://replit.com/pricing)에서 확인하세요.
  </Accordion>

  <Accordion title="사용하지 않은 월간 credits는 다음 달로 이월되나요?">
    plan에 따라 다릅니다. Core credits는 billing 주기가 시작될 때마다 초기화되며 이월되지 않습니다. Pro에는 [credit 이월](/ko/billing/plans/replit-pro) 기능이 포함되어 있어, 사용하지 않은 credits가 {ProCreditRolloverPeriod} 동안 이월된 후 만료됩니다.

    balance가 월 할당량보다 많다면 초과분은 추천 credits이나 프로모션 credits일 수 있으며, 이러한 credits에는 별도의 만료일이 적용됩니다.
  </Accordion>

  <Accordion title="추가 크레딧(크레딧 팩)은 어떻게 구매하나요?">
    Credit pack은 매월 제공되는 할당량에 credits를 추가해 주며, 용량이 큰 팩일수록 할인 폭이 커집니다:

    <CreditPackTable />

    **Settings → Account usage**를 열고 credit pack 구매 옵션을 선택하세요. credits는 Agent 사용량, deployments, 스토리지 등 사용량 기반 서비스에 적용됩니다. 자세한 내용은 [지출 관리하기](/ko/billing/managing-spend#purchase-credit-packs)를 참조하세요.

    App Store를 통해 구독한 경우에는 먼저 계정에 웹 결제 수단을 추가해야 합니다.
  </Accordion>

  <Accordion title="Core 또는 Pro의 무료 체험이 있나요?">
    Replit은 유료 plan에 대해 기간 한정 무료 trial을 제공하지 않지만, Replit을 먼저 사용해 볼 수 있는 방법이 있습니다:

    * [Starter plan](/ko/billing/plans/starter-plan)은 기간 제한 없이 무료로 이용할 수 있습니다.
    * [교육 program](https://replit.com/education)에서는 자격 요건을 충족하는 학생에게 할인된 이용 권한을 제공합니다.

    현재 구독의 환불 약관은 [Replit Support에 문의](https://replit.com/support)하세요.
  </Accordion>

  <Accordion title="구독 기간 중간에 업그레이드하면 일할 계산은 어떻게 되나요?">
    결제 주기 중간에 plan을 변경하면, Replit은 현재 plan에서 사용하지 않은 기간에 해당하는 금액을 새 plan 비용에서 차감해 드립니다. 정확한 일할 계산 내역은 변경을 완료하기 전에 billing 확인 화면에 표시되므로, 요금이 청구되기 전에 내용을 확인할 수 있습니다.
  </Accordion>
</AccordionGroup>
