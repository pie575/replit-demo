<div id="replit-app">
  ## Что такое Replit App?
</div>

Replit App — это облачные проекты, содержащие код, данные и ассеты.
Их можно создавать, запускать и публиковать в безопасной изолированной среде.

Replit App интегрированы со следующими инструментами Project Editor для удобной разработки:

* **Инструменты на базе ИИ**: используйте Agent для создания, отладки и пояснения кода.
* **Совместная работа**: работайте над одним App вместе с другими пользователями в реальном времени.
* **Публикация**: публикуйте App в облаке одним щелчком.

<div id="section-2">
  ## Основные возможности
</div>

Replit App предоставляет следующие возможности:

* **Без настройки**: создавайте App и пишите код прямо на Replit.com — без установки и настройки.
* **Автосохранение**: проект непрерывно сохраняет изменения в облаке, поэтому вы можете продолжить работу с кодом в любом веб-браузере.
* **Контроль версий**: отслеживайте изменения, просматривайте историю файлов и синхронизируйте их через систему контроля версий Replit — без дополнительной настройки.
* **Настройки публичного/приватного доступа**: с помощью настроек конфиденциальности управляйте тем, кто может просматривать, запускать и ремиксировать ваше App.
* **Публикация**: публикуйте код в облаке без сложной настройки.
* **Собственный URL для App**: получите уникальный URL для App или назначьте собственный домен для профессионального присутствия в интернете.

<Info>
  Файлы, загруженные в файловую систему проекта, доступны только во время разработки,
  и к ним не могут получить доступ опубликованные App или другие разработчики. Для обработки загрузок от разработчиков и предоставления файлов используйте [объектное хранилище](/ru/ja/features/data-and-storage/object-storage), а для хранения и получения данных App и пользователей — [базу данных Replit](/ru/ja/features/data-and-storage/sql-database).
</Info>

Подробнее об инструментах Project Editor, которые упрощают создание Replit App, см. в [обзоре Project Editor](/ru/ja/learn/projects-and-artifacts/project-editor/).

<div id="section-3">
  ## Как это работает
</div>

Когда вы создаёте Replit App, Replit создаёт в облаке приватное пространство для вашего проекта.
По мере добавления функций и внесения изменений в App Replit автоматически сохраняет их, поэтому вы можете продолжить редактирование в любом веб-браузере.

Replit предоставляет предварительно настроенную среду со всеми необходимыми компонентами.
Это позволяет сразу приступить к созданию App, не заботясь о настройке серверов, базы данных и управлении средой.

Replit автоматически назначает каждому Replit App уникальный веб-адрес, чтобы вы могли просматривать App во время работы. Когда вы будете готовы поделиться результатом, App можно опубликовать всего несколькими щелчками, сделав его доступным круглосуточно.

<div id="section-4">
  ## Обзор хранилищ
</div>

Replit предлагает четыре основных типа хранилищ для данных вашего App. Каждый тип хранилища предназначен для разных сценариев использования и имеет ограничения, зависящие от тарифа.

<Info>
  В лимит хранилища входят все данные, сохраняемые App, включая установленные пакеты и зависимости.
</Info>

| Тип хранилища                                                      | Описание                              | Сценарии использования                                      | Постоянство                                              | Ограничения тарифа                                                                                                                                   |
| ------------------------------------------------------------------ | ------------------------------------- | ----------------------------------------------------------- | -------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Файловое хранилище**                                             | Файлы в проекте                       | Код App, статические ассеты, файлы конфигурации      | Сохраняется при публикации, сбрасывается при перезапуске | Starter: {StarterWorkspaceStorage}<br />Core: {CoreWorkspaceStorage}<br />Pro: {TeamsWorkspaceStorage}<br />Enterprise: {EnterpriseWorkspaceStorage} |
| **[База данных](/ru/ja/features/data-and-storage/sql-database/)**     | Хранение структурированных данных     | Профили пользователей, игровые результаты, каталоги товаров | Полностью сохраняется между сеансами                     | 20 ГБ на базу данных разработки<br />За продакшен-базы данных взимается плата за вычислительное время и хранилище                                    |
| **[Хранилище App](/ru/ja/features/data-and-storage/object-storage/)** | Неструктурированные данные и медиа    | Изображения, видео, PDF, документы                          | Полностью сохраняется между сеансами                     | Оплата по мере использования<br />Плата взимается за хранилище и пропускную способность                                                              |
| **[Secrets](/ru/ja/core-concepts/project-editor/app-setup/secrets/)** | Зашифрованные конфиденциальные данные | Ключи API, учётные данные, строки подключения               | Полностью сохраняется и шифруется                        | Без ограничений<br />Включено во все тарифы                                                                                                          |
