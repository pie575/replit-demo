---
title: "Сочетания клавиш"
description: "Узнайте, как просматривать, добавлять и изменять сочетания клавиш, чтобы повысить продуктивность в Replit."
---

Сочетания клавиш позволяют выполнять команды, изменять текст и перемещаться по Редактору проектов
с помощью настраиваемых комбинаций клавиш. Вы можете настраивать и использовать сочетания клавиш в
веб-приложении Replit.com.

<div id="visualizar-atalhos-de-teclado">
  ## Просмотр сочетаний клавиш
</div>

Чтобы просмотреть настройки сочетаний клавиш, выполните следующие действия:

1. Откройте Replit App, чтобы перейти в Редактор проектов.
2. В доке откройте вкладку <img class="icon-svg" src="/assets/mirror/settings-icon-c2664c3691bf.svg" alt="значок шестерёнки" width="16" height="16" data-path="images/icons/settings-icon.svg" /> **Пользовательские настройки** в разделе <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="значок всех инструментов" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **Все инструменты**.
   Либо найдите «Пользовательские настройки» с помощью <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="значок лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> поиска.
3. Выберите вкладку **Сочетания клавиш**, чтобы просмотреть список команд и назначенных им сочетаний клавиш.

<div id="personalizar-atalhos-de-teclado">
  ## Настройка сочетаний клавиш
</div>

Чтобы добавить или изменить сочетание клавиш, выполните следующие действия:

1. Нажмите <img class="icon-svg" src="/assets/mirror/create-app-icon-ba218e87fb67.svg" alt="значок плюса" width="16" height="16" data-path="images/icons/create-app-icon.svg" />**Добавить сочетание** рядом
   с неназначенной командой или значок <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="значок карандаша" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> карандаша для уже назначенных команд.
2. Когда рядом с командой появится надпись «Запись...», нажмите сочетание клавиш, которое хотите назначить.
   Чтобы отменить запись, щёлкните в пустой области вкладки.
3. Чтобы отменить назначенное сочетание клавиш, нажмите значок <img class="icon-svg" src="/assets/mirror/rollback-icon-3197ed1b323b.svg" alt="значок отката" width="12" height="12" data-path="images/icons/rollback-icon.svg" /> отката.

<div id="remover-atalhos-de-teclado">
  ## Удаление сочетаний клавиш
</div>

Чтобы удалить сочетание клавиш, нажмите значок <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="значок корзины" width="16" height="16" data-path="images/icons/trash-icon.svg" /> рядом с командой.

<div id="navegao-por-tab">
  ## Навигация с помощью клавиши Tab
</div>

С помощью клавиши **Tab** в браузере можно переходить между интерактивными элементами страницы. Однако инструменты «Редактор файлов», Console и Shell перехватывают клавишу **Tab** для таких действий, как создание отступов.

Чтобы продолжить переход между элементами страницы при работе с этими инструментами, выполните следующие действия:

1. Нажмите **Esc**, чтобы снять фокус с инструмента
2. Нажмите **Tab**, чтобы перейти к следующему элементу
