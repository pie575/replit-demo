Workspace Security Center 适用于所有方案。您可以使用它检查整个 workspace 中各项目的[依赖项](/zh/pt/features/security/concepts#dependency)，并按[严重性](/zh/pt/features/security/concepts#severity)查看 [CVE](/zh/pt/features/security/concepts#cve) 发现项。您还可以使用 Replit Agent 修复问题、[重新发布](/zh/pt/features/security/concepts#republish)受影响的项目，以及导出软件物料清单 ([SBOM](/zh/pt/features/security/concepts#sbom)) 报告以满足合规要求。

<Note>
  若要检查单个项目，请在该项目的 **Security** 面板中打开 [Project Security Center](/zh/pt/features/security/project-security-center)。
</Note>

<Note>
  刚开始了解依赖项安全？请参阅[安全概念](/zh/pt/features/security/concepts)，了解 CVE、SBOM、暴露面、Fix with Agent、Republish 和 Auto-Protect 的定义。
</Note>

  ## 资源
</div>

<div id="deteco-de-cve">
  ### CVE 检测
</div>

查看 workspace 中所有项目的漏洞：

* 按[暴露面](/zh/pt/features/security/concepts#exposure) (部署状态和可见性) 识别并优先处理存在漏洞的项目
* 查看每个发现项中受影响的软件包名称、版本和严重性 (严重、高、中、低)
* 获取各项目的修复建议

<div id="viso-de-projetos-afetados">
  ### 受影响项目概览
</div>

识别存在漏洞的项目，并确定优先修复项：

* 按暴露面查看易受攻击项目概览：项目总数、已部署项目和公开部署的项目
* 查看受影响 Replit 项目的完整明细
* 按 CVE ID 或项目名称搜索，并按严重性、所有者、部署状态 (Published / Not published) 和可见性 (Public / Private) 筛选
* 展开任意项目行即可查看所有 CVE 发现项 (严重性、软件包、版本、CVE ID) ，无需离开当前页面

<div id="fix-with-agent-e-republicao">
  ### 使用 Agent 修复并重新发布
</div>

无需离开 Security Center，即可修复漏洞并重新部署：

* 在任意受影响的项目中选择 **[Fix with Agent](/zh/pt/features/security/concepts#fix-with-agent)**，以项目中的后台任务形式制定修复方案。重新发布前，请审核并应用生成的更改。
* 通过 **Task in progress**、**Apply changes**、**Republish** 以及最终状态 **Republished** 或 **Failed** 跟踪修复状态。
* 修复合并后，点击 **Republish** 并在确认对话框中确认，即可使用现有配置重新部署构建版本。
* 执行批量操作，例如取消发布，或通知项目所有者其项目中存在的漏洞。

<div id="exportao-de-sbom">
  ### SBOM 导出
</div>

导出软件物料清单，以满足合规和审计要求：

* 以标准格式下载 SBOM ([SPDX](/zh/pt/features/security/concepts#spdx-and-cyclonedx)、[CycloneDX](/zh/pt/features/security/concepts#spdx-and-cyclonedx))
* 为单个项目或整个 workspace 生成报告
* 按检查运行分组浏览 SBOM，并查看运行时间、项目数量及启动运行的用户
* 将一次检查运行中的所有 SBOM 批量下载为单个 zip 文件
* 满足软件供应链透明度方面的合规要求

<Note>
  Enterprise 方案提供批量下载 SBOM 的功能。其他方案的 Workspace 会在 SBOM 部分看到升级到 Enterprise 的提示。
</Note>

<div id="acessando-o-workspace-security-center">
  ## 访问 Workspace Security Center
</div>

要打开 Workspace Security Center：

1. 访问 [replit.com](https://replit.com)，然后登录您的账户。
2. 在主页左侧导航栏中选择 **Security**。

<div id="verificando-seu-workspace">
  ## 检查 workspace
</div>

<Frame>
  <img src="/assets/mirror/security-overview-b37f090f236c.png" alt="Workspace Security Center 的初始视图，显示检查总数、漏洞总数以及按严重性分组的 CVE" width="3438" height="1984" data-path="images/workspace-security-center/security-overview.png" />
</Frame>

1. 打开 Workspace Security Center。
2. 选择 **Run security scan**，对整个 workspace 启动安全检查。
3. 查看按受影响项目、严重性和部署暴露面分类的结果。
4. 在任一受影响项目中，选择 **Fix with Agent**，待修复应用后再选择 **Republish**。

安全检查会分析 workspace 中 Replit 项目的依赖项，并根据公开漏洞数据库标记已知漏洞。

<div id="auto-protect">
  ## Auto-Protect
</div>

管理员可以选择在其账户中启用 **[Auto-Protect](/zh/pt/features/security/concepts#auto-protect)**，该功能会持续监控所有项目依赖项中是否存在新披露的 CVE。发现匹配项后，Replit Agent 会准备经过测试的修复方案，创建者会收到一封包含可直接应用该修复方案的链接的电子邮件。

有关完整流程和配置步骤，请参阅 [Auto-Protect](/zh/pt/features/security/project-security-center#auto-protect)，其中包括仅限管理员设置的严重性阈值，路径为 **设置** &gt; **账户** &gt; **Advanced**。

<Note>
  如需协助配置 Workspace Security Center，或将 SBOM 导出集成到合规工作流程中，请联系您的专属客户经理。
</Note>
