design system은 Replit에 재사용 가능한 visual direction을 제공합니다. color token, typography, spacing, 예시 컴포넌트, logo, 브랜드 asset을 담아 둘 수 있어 새로 만드는 design도 일관된 스타일을 유지합니다.

저장해 둔 시스템을 기준으로 결과물을 만들고 싶다면, prompt box에서 **더하기** 메뉴를 선택한 다음 **Use a design system**을 선택하세요.

<div id="when-a-design-system-helps">
  ## design system이 유용한 경우
</div>

* **일관성 있게 제작:** 새로운 작업 전반에서 color, typography, spacing, 컴포넌트를 일관되게 유지합니다.
* **팀에 공통 direction 제공:** 저장된 하나의 시스템을 여러 Project의 시각적 기준으로 사용합니다.
* **기존 작업물의 스타일 변경:** artifact가 다른 시각 언어를 따라야 할 때 시스템을 적용합니다.

저장된 시스템의 이름과 원하는 결과를 함께 적어 주세요. brief, Figma frame, 스크린샷, 콘텐츠 requirements처럼 작업이 무엇을 달성해야 하는지 정의하는 자료가 있다면 관련 context로 함께 추가하세요.

예: &quot;저장된 Acme design system을 사용해 모바일 온보딩 화면을 만들어 줘. 기존 type 스케일과 버튼 스타일은 그대로 두고, 두 가지 layout direction을 보여 줘.&quot;

design system은 시각적 작업의 방향을 잡아 주고, [Skill](/ko/chat/agent-skills)은 task를 수행하기 위한 재사용 가능한 지침이나 접근 방식을 제공합니다.
