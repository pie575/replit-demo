<Note>
  想为 **Replit 组织**强制启用 SSO (登录 replit.com) 吗？这需要单独配置——请参阅[单点登录 (SAML SSO)](/zh/ko/teams/identity-and-access-management/saml)。本页面介绍如何为在 Replit 上**构建的应用**添加 SSO 登录流程。
</Note>

让用户能够通过 Okta 或 Microsoft Entra ID 等企业身份提供方登录应用。如果你的应用使用 [Clerk Auth](/zh/ko/features/auth-and-identity/clerk-auth)，请通过 Clerk 控制台配置 SSO 和其他高级身份验证功能。只需告诉 Agent 你的需求，Agent 就会引导你前往相应的控制台完成设置。

<Frame>
  <img src="/assets/mirror/sso-cover-28a76bfa16fb.jpeg" alt="使用 SSO 构建 Replit 应用的横幅，画面中有锁图标和一位使用笔记本电脑工作的构建者。" width="1920" height="1080" data-path="images/workspace/auth/sso-cover.jpeg" />
</Frame>

Clerk 控制台提供的功能远不止基本登录体验。你在 Clerk 中配置的设置会自动应用于 Replit 应用的身份验证。

<div id="section">
  ## 可配置的内容
</div>

* **企业版 SSO 连接**：使用 OIDC 或 SAML 配置 Okta 或 Microsoft Entra ID 单点登录，让客户可以使用公司的身份提供方登录。SSO 用公司现有的身份提供方取代手动维护的邮箱白名单，同时也能保护处理敏感数据的内部工具。
* **多因素认证 (MFA)&#x20;**：为应用的登录流程添加 MFA。
* **会话控制**：调整会话时长和认证频率。
* **其他 Clerk 设置**：其他 Clerk 配置会自动应用于 Replit 应用。请勿更改 API 密钥或环境设置——这些由 Replit 管理。请参阅[开发环境和生产环境](/zh/ko/features/auth-and-identity/clerk-auth#development-and-production-environments)。

<div id="clerk">
  ## 打开 Clerk 控制台
</div>

请 Agent 进行所需的身份验证更改。Agent 会完成其可处理的配置，并引导你前往应用的 Clerk 控制台完成需要你操作的配置。

<Frame>
  <img src="/assets/mirror/build-with-sso-agent-workflow-46422788bd18.webp" alt="Agent 引导使用 Clerk 的应用，在 Clerk 控制台中配置企业版 SSO。" width="1602" height="1080" data-path="images/workspace/auth/build-with-sso-agent-workflow.webp" />
</Frame>

你也可以在 Workspace 中打开控制台。

1. 在 Tools 面板中选择 **Users &amp; Auth**。
2. 选择 **Configure** 标签页。
3. 选择 **Advanced**。
4. 在 **Clerk dashboard** 下选择 **Open Clerk dashboard**。

<Frame>
  <img src="/assets/mirror/open-clerk-dashboard-tools-pane-a314ffea741d.webp" alt="Users & Auth 工具中已打开 Configure 标签页，并显示 Advanced 部分和 Open Clerk dashboard 按钮。" width="2158" height="1372" data-path="images/workspace/auth/open-clerk-dashboard-tools-pane.webp" />
</Frame>

<div id="sso">
  ## 设置企业版 SSO 连接
</div>

1. 在 Clerk 控制台中选择 **Configure**。
2. 在 **User &amp; authentication** 下选择 **SSO connections**。
3. 选择 **Enterprise**。
4. 选择 **Add connection**。

<Frame>
  <img src="/assets/mirror/build-with-sso-enterprise-connections-b0a6a27885b5.webp" alt="Clerk 控制台中显示企业版 SSO 连接页面和 Add connection 操作。" width="1826" height="1080" data-path="images/workspace/auth/build-with-sso-enterprise-connections.webp" />
</Frame>

有关完整的连接配置说明，请参阅 [Clerk 文档](https://clerk.com/docs)。

<div id="section-2">
  ### 验证连接
</div>

完成配置后，请使用身份提供方的测试账户登录，确认该账户能否访问应用中预期的内容。

如果登录失败，请向 Agent 寻求帮助。请求中请注明身份提供方、协议和错误消息。

<Note>
  本页面介绍应用自身登录流程所用的企业版 SSO。有关 Workspace 中显示为 **SSO providers** 的 Google、GitHub、Apple 和 X 社交登录，请参阅[登录身份提供方](/zh/ko/features/auth-and-identity/sign-in-providers)。本页面不涵盖 Replit Auth 迁移，也不涉及用于 Replit 账户的 SAML 登录。
</Note>

<div id="section-3">
  ## 定价与可用性
</div>

[Replit Pro](/zh/ko/billing/plans/replit-pro) 套餐提供 Clerk 控制台访问权限。企业版套餐即将推出。

<Info>
  企业版 SSO 连接在 2026 年 10 月 1 日前免费。此后，SSO 定价将与 Clerk 的定价一致，并显示在 Replit 账单中。
</Info>
