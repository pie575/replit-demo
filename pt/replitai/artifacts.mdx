## O que são artefatos?

Artefatos são as coisas que você pode publicar no Replit, como: aplicativos web, aplicativos mobile, apresentações de slides, animações, aplicativos de dados, jogos 3D e designs. Cada um é uma saída completa e independente que recebe sua própria URL compartilhável quando você publica.

Todo o resto no seu projeto — arquivos, imagens, CSVs, código — suporta seus artefatos, mas não pode ser publicado por conta própria.

## Primeiros passos

Há duas maneiras de criar a partir da página inicial do Replit:

* **Descreva**: Digite o que você quer — "crie para mim um aplicativo de receitas" ou "faça um pitch deck para a minha startup." O Agent descobre qual tipo é adequado e o constrói.
* **Escolha um tipo**: Escolha o artefato que você quer — Aplicativo web, Aplicativo mobile, Visualização de dados, Animação, Jogo 3D ou outro tipo suportado — antes de descrever sua ideia.

Você também pode adicionar mais a um projeto existente a qualquer momento pedindo ao Agent no chat ou clicando no botão **+** no painel de prévia.

## Alternando entre artefatos

Quando você tiver vários artefatos em um projeto, alterne entre eles no **painel de prévia** ou na **barra lateral da Biblioteca**. Você também pode perguntar ao Agent — "mostre-me o aplicativo mobile" ou "mude para os slides."

### Barra lateral da Biblioteca

A barra lateral da Biblioteca oferece um lugar central para navegar por tudo no seu projeto. Ela mostra seus artefatos, imagens que o Agent gerou ou baixou, e outros ativos do projeto. Abra a barra lateral da Biblioteca no painel esquerdo para encontrar e reutilizar qualquer ativo no seu projeto.

## Vários artefatos em um projeto

Um único projeto pode conter até **7 artefatos**, com um máximo de **1 aplicativo mobile** por projeto. Por exemplo, você pode construir um aplicativo web para seus clientes, um aplicativo mobile para sua equipe e uma apresentação de slides para investidores — tudo no mesmo projeto.

<ArtifactGrid />

### Adicionando artefatos a um projeto

Há três maneiras de adicionar um artefato a um projeto existente:

* **Chat**: Peça ao Agent — "adicione um aplicativo mobile a este projeto" ou "crie uma apresentação de slides para o pitch de investidor"
* **Botão de adição**: Clique no botão **+** no painel de prévia e escolha o que você quer construir
* **Barra lateral da Biblioteca**: Navegue pelos seus artefatos, imagens e outros ativos existentes, e adicione novos artefatos a partir daí

### Dados e backend compartilhados

Quando os artefatos vivem no mesmo projeto, eles automaticamente compartilham os mesmos dados e lógica de backend. Se um cliente fizer um pedido pelo seu aplicativo web, seu aplicativo mobile e dashboard de dados também verão esse pedido. Você não precisa configurar nenhuma conexão ou duplicar código — simplesmente funciona.

<Note>
  A publicação implanta todo o seu projeto de uma vez. Todos os artefatos entram no ar juntos, para que estejam sempre sincronizados.
</Note>

### Exemplos de combinações

* **Aplicativo web + aplicativo mobile**: Um restaurante com um aplicativo web voltado para clientes e um aplicativo mobile para a equipe — ambos conectados ao mesmo banco de dados e API
* **Aplicativo + dashboard admin**: Um produto principal ao lado de um painel administrativo interno para gerenciar conteúdo, usuários ou configurações
* **Aplicativo + apresentação de slides**: Seu produto e um pitch deck no mesmo projeto, para que os slides sempre reflitam a versão mais recente
* **Dashboard de dados + vídeo**: Uma visualização de dados ao vivo combinada com um vídeo animado que percorre os destaques

## Publicação

Aplicativos, slides e vídeos podem ser publicados e compartilhados. Cada um recebe sua própria URL compartilhável quando você implanta.

Arquivos e ativos que não são artefatos (como CSVs, imagens ou arquivos markdown) não podem ser publicados por conta própria. Para compartilhá-los, adicione-os a um aplicativo ou crie um novo artefato.

## Perguntas frequentes

<Accordion title="Posso ter mais de um artefato em um projeto?">
  Sim. Um único projeto pode conter até **7 artefatos no total**, com um limite de **1 aplicativo mobile por projeto**. Todos os artefatos em um projeto compartilham o mesmo backend e dados automaticamente.

  Se você atingir o limite de aplicativos mobile e quiser construir um segundo, crie-o em um novo projeto. Se você atingir o total de 7 artefatos, remova um artefato existente antes de adicionar outro ou divida seu trabalho entre projetos.
</Accordion>

<Accordion title="Preciso escolher um tipo antes de começar?">
  Não. Basta descrever o que você quer e o Agent escolhe o tipo certo para você. Você também pode escolher um tipo manualmente no menu suspenso, se preferir.
</Accordion>

<Accordion title="Posso publicar apenas um artefato de um projeto?">
  Não no momento. A publicação implanta o projeto inteiro junto, para que todos os artefatos fiquem sincronizados. Se você precisar de implantação independente, use projetos separados.
</Accordion>

<Accordion title="Os artefatos compartilham dados entre si?">
  Sim. Todos os artefatos em um projeto compartilham o mesmo banco de dados e serviços de backend. Se seu aplicativo web grava dados, seu aplicativo mobile e dashboard de dados podem lê-los imediatamente.
</Accordion>

<Accordion title="Qual é a diferença entre um artefato e um arquivo?">
  Artefatos são coisas que você pode publicar — aplicativos, slides e vídeos. Arquivos (como CSVs, imagens ou código) são ativos dentro do seu projeto que suportam seus artefatos, mas não podem ser publicados por conta própria.
</Accordion>

<Accordion title="Meu aplicativo mobile está sem recursos do meu aplicativo web. O que aconteceu?">
  Quando o Agent traduz recursos entre tipos de artefatos, algumas coisas podem não ser transferidas perfeitamente — especialmente interações ou layouts que funcionam de forma diferente entre plataformas. Você pode fazer um acompanhamento no chat para preencher as lacunas.
</Accordion>
