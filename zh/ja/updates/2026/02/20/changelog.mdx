<div id="pro">
  ## 推出 Pro 套餐
</div>

Replit Pro 现已推出，Core 的价值进一步提升。我们让各项计划更清晰，也更贴合不同需求：

* **Replit Pro**：面向专业构建者——Turbo 模式 (Agent 速度提升 2.5 倍，可单独开启) 、可结转的阶梯式积分、最多 15 名构建者且不按人头收费、优先支持，以及延长至 4 倍的数据保留期。[了解 Pro](/zh/ja/billing/plans/replit-pro)。
* **Core**：无需额外付费即可邀请最多 5 名协作者。请前往[定价页面](https://replit.com/pricing)查看当前 Core 价格。
* **Teams 计划终止**：Teams 将由 Pro 取代。现有 Teams 客户将在剩余合同期内免费升级至 Pro。迁移将于 {TeamsMigrationDate} 开始。[详情和时间表](https://blog.replit.com/pro-plan)。
* **Agent 模式**：您可以选择 **Economy** (成本优化) 或 **Power** (注重性能) 。**Turbo** 为独立开关 (仅限 Pro/Enterprise，速度提升 2.5 倍) 。[Agent 模式指南](/zh/core-concepts/agent/agent-modes)。
* **Fast Mode 更名为 Lite Mode**：同样快速且范围明确的更改——产品和文档中均已更新名称。[Lite 模式](/zh/core-concepts/agent/agent-modes)。
* **代码优化**：用于控制 Agent 如何审查自身代码的设置 (此前称为“自主级别”) 已更名为“代码优化”。[代码审查](/zh/ja/features/agent/agent-modes#code-review)。
* **协作**：所有付费计划的协作功能均有所提升——无限工作区、简化的共享、统一设置，以及按工作区追踪使用情况。Core：5 名协作者，Pro：15 名构建者。

<div id="section-3">
  ### 后台内存压缩
</div>

Agent 不再需要暂停工作流来优化内存。此前，系统会显示“已优化 Agent 内存”的消息，并阻塞进度 30 秒以上。现在，该操作会在后台无缝完成，因此您在工作时，Agent 仍能保持响应。

<div id="section-4">
  ### 访问生产环境部署日志
</div>

Agent 现在可以访问生产环境部署日志，从而根据真实的生产数据发现并修复错误。更多生产环境调试改进即将推出。

<div id="section-5">
  ### 搜索技能
</div>

借助技能搜索功能，你无需向 Agent 输入提示词或手动上传文件，即可直接在 Replit 中浏览并安装热门技能。

  ### Razorpay MCP 集成

<div id="video-stack">
  ### Video Stack
</div>

Video Stack 让你能够借助生成的图片和视频打造富有创意的动态视觉效果，用代码制作动画视频。在 Replit 项目中，仅凭代码即可完成一支完整的动画视频。
