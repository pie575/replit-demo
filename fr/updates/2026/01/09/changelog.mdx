<div id="automation-preview-for-agent-users">
  ### Aperçu de l’automatisation pour les utilisateurs d’Agent
</div>

<Frame>
  <video src="/assets/mirror/changelog-01-09-2026-6ad09baf666c.mp4" controls />
</Frame>

L’aperçu de l’automatisation est désormais disponible pour tous les créateurs utilisant Agent. Visualisez le graphique des étapes d’automatisation en quelques secondes, au lieu d’attendre plusieurs minutes pour suivre la progression visuelle.

<div id="private-apps-for-free-accounts">
  ### Apps privées pour les comptes gratuits
</div>

Les créateurs disposant d’un compte gratuit peuvent désormais créer des apps privées. Les limites de l’offre gratuite concernant le nombre d’apps que vous pouvez créer restent applicables.

<div id="made-with-replit-badge">
  ### Badge Made with Replit
</div>

<Frame>
  <img src="https://replit.com/badge?caption=Made%20with%20Replit" alt="Badge Made with Replit" noZoom />
</Frame>

Un badge « Made with Replit » apparaît désormais sur les applications gratuites publiées. Passez à Replit Core pour le supprimer. Sélectionnez le badge pour en savoir plus sur Replit.

<div id="new-ai-models-in-integrations">
  ### Nouveaux modèles d’IA dans Intégrations
</div>

Les modèles d’IA récemment lancés sont désormais pris en charge dans les intégrations d’IA :

| Modèle                       | Description                                                                                                                                                                        |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `gpt-5.2`                    | Le modèle le plus performant d’OpenAI pour le travail de connaissance professionnel. Premier modèle à dépasser 90 % sur ARC-AGI-1 avec une fenêtre de contexte de 400 K.           |
| `claude-opus-4.5`            | Le modèle phare d’Anthropic, optimisé pour le codage, les agents et l’utilisation d’ordinateurs. Il atteint 80,9 % sur SWE-bench Verified.                                         |
| `gemini-3-flash-preview`     | Le modèle haute vitesse de Google pour les workflows agentiques, avec un contexte de 1 M de jetons. Son raisonnement approche le niveau Pro, avec une latence et un coût moindres. |
| `gemini-3-pro-preview`       | Le modèle multimodal avancé de Google, doté d’un raisonnement de pointe et de connaissances du monde réel.                                                                         |
| `gemini-3-pro-image-preview` | Le modèle Nano Banana Pro de Google pour générer et modifier des images de haute qualité avec un rendu de texte précis.                                                            |
