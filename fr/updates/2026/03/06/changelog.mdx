<div id="ai-chat-message-truncation">
  ### Troncature des messages dans le Chat IA
</div>

Les messages longs du Chat IA sont désormais tronqués et accompagnés d&#39;un bouton « Afficher plus », ce qui préserve la lisibilité de votre historique de conversation.

</div>

<div id="revenuecat-integration-now-generally-available">
  ### L&#39;intégration RevenueCat est désormais disponible pour tous
</div>

L&#39;intégration RevenueCat est désormais disponible pour tous et simplifie la monétisation de vos applications mobiles. Demandez à Agent d&#39;ajouter un abonnement : il se charge pour vous de la configuration sur les app stores.
