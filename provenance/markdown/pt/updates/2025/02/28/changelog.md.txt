## Plataforma

### Agent v2

<img src="https://mintcdn.com/replit/_awOuN-Ml26WVE62/images/changelog/2025-02-28/agent-web.webp?fit=max&auto=format&n=_awOuN-Ml26WVE62&q=85&s=6d71d22c536e00754ba0c3f8a949c6ef" alt="Agent v2" width="800" height="450" data-path="images/changelog/2025-02-28/agent-web.webp" />

Uma nova experiência do Agent está disponível para todos os criadores. Este novo Agent é mais rápido, mais preciso e mais capaz do que a versão anterior.

Agora ele é alimentado pelo Claude 3.7 Sonnet, o modelo mais avançado da Anthropic até o momento.

Você pode experimentá-lo ingressando no Programa Explorer. Veja as instruções [aqui](https://youtu.be/pE_XT2TaXCA).

### Melhorias nas implantações

Sugestões de IA agora aparecem para criadores que selecionam implantação estática para aplicativos dinâmicos, melhorando o comportamento do Agent ao lidar com solicitações de implantação.

<img src="https://mintcdn.com/replit/_awOuN-Ml26WVE62/images/changelog/2025-02-28/deployments-debugger-will-now---non-static-app-220824.png?fit=max&auto=format&n=_awOuN-Ml26WVE62&q=85&s=6fcc9e981f9edd8c79a497b06dd43dd0" alt="Melhorias no depurador de implantações" width="1604" height="1244" data-path="images/changelog/2025-02-28/deployments-debugger-will-now---non-static-app-220824.png" />

### Lançamento do Claude 3.7 Sonnet

O modo Advanced do Assistant foi atualizado com o Claude 3.7 Sonnet para todos os criadores pagos. Isso significa maior precisão e capacidade para solicitações complexas.

<img src="https://mintcdn.com/replit/_awOuN-Ml26WVE62/images/changelog/2025-02-28/50526c4ea4d114b4cd8268425398dd4ed3c2d736_bc521d9780846c35d990a72459794dd81370515f_twitter.jpeg?fit=max&auto=format&n=_awOuN-Ml26WVE62&q=85&s=957fd62be704090db16ba82583a0bed9" alt="Interface do Claude 3.7" width="1200" height="674" data-path="images/changelog/2025-02-28/50526c4ea4d114b4cd8268425398dd4ed3c2d736_bc521d9780846c35d990a72459794dd81370515f_twitter.jpeg" />

### Melhoria no desempenho do banco de dados

As operações de banco de dados agora são mais rápidas do que nunca, com a operação mais custosa reduzida de 200ms para menos de 1ms.
