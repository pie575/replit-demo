⏰ *预计用时：10 分钟*

完成本指南后，你将拥有一个已发布的小型 App，可通过可分享的 URL 访问。

<Frame>
  <img src="/assets/mirror/07-published-site-8fe719004e5a.jpg" alt="将所选模板构建为网站，并通过已发布的 Replit URL 打开" width="1274" height="717" data-path="images/first-app-template/07-published-site.jpg" />
</Frame>

从精美的模板开始，将其转换为可运行的网站并发布。具体可用的模板可能会有所变化，请选择最符合你要创建内容的模板。

<div id="section">
  ## 开始之前
</div>

你需要一个 [Replit 账号](https://replit.com)。要从 Design 设计稿构建新应用，你需要订阅 Core 或 Pro 计划。有关计划详情，请参阅[构建设计](/zh/ja/design/build-your-design)和[计费](/zh/ja/billing/ai-billing)。

目标是完成以下完整流程：

* 在 [Replit Design](https://replit.com/design) 中选择模板，
* 使用 [Agent](/zh/ja/features/agent/overview) 构建应用，
* 测试应用，
* 发布并分享。

Agent 是 Replit 的 AI 构建助手。只需描述你想创建的内容，Agent 就会帮助你创建、说明和修改应用。

<div id="section-2">
  ## 选择模板、构建并发布应用
</div>

<Steps>
  <Step title="浏览设计模板">
    打开 [replit.com/design](https://replit.com/design)。浏览精选模板，或按 **落地页**、**移动端**、**原型** 等类别筛选。

    <Frame>
      <img src="/assets/mirror/01-design-gallery-5303cf1cf6d2.jpg" alt="显示精选模板和类别筛选条件的 Replit Design 作品展厅" width="1280" height="720" data-path="images/first-app-template/01-design-gallery.jpg" />
    </Frame>
  </Step>

  <Step title="预览并使用模板">
    选择并查看模板，然后选择 **Use template**。Replit 会创建一个新项目，并将模板放到 Design Canvas 中。如果你是从模板封面页开始操作，请参阅[从模板开始](/zh/ja/design/start-from-a-template)，了解 Remix 流程。

    <Frame>
      <img src="/assets/mirror/02-template-preview-facda2e40956.jpg" alt="显示 Use template 按钮的 Replit Design 模板预览" width="1280" height="720" data-path="images/first-app-template/02-template-preview.jpg" />
    </Frame>

    Remix 后的模板会在新项目的 Design Canvas 中打开。

    <Frame>
      <img src="/assets/mirror/03-remixed-design-35b051544510.jpg" alt="新 Replit 项目的 Design Canvas 中打开的已选 Remix 模板" width="1280" height="720" data-path="images/first-app-template/03-remixed-design.jpg" />
    </Frame>
  </Step>

  <Step title="将设计转换为网站">
    模板一开始只是设计模型。发布前，请切换到 **Build**，让 Agent 将所选设计转化为功能完整的网站。例如：

    > 请将选中的这个模板构建为功能完整的网站。保留视觉设计，并使导航和联系我们功能正常运行。

    Agent 会在同一项目中创建一个网站产物，并以所选设计为基础。

    <Note>
      **Publish** 按钮在 Design 中也会显示。如果项目仅包含设计模型，Publishing 会提示目前没有可部署的内容，并引导您让 Agent 构建应用。如果存在网站产物，您可以从 Design 或 Build 中发布。
    </Note>

    <Frame>
      <img src="/assets/mirror/04-build-request-d5a5a3428361.jpg" alt="Build 工作区中附带了已选定的作品集设计、Agent 聊天中的构建请求，以及 Publishing 说明仅含设计的项目目前没有可部署内容" width="1280" height="720" data-path="images/first-app-template/04-build-request.jpg" />
    </Frame>
  </Step>

  <Step title="确认应用能在 Preview 中正常运行">
    Agent 完成后，打开 [Preview](/zh/ja/features/editor/preview)，像访客一样使用你的 App。Preview 可让你在发布前测试正在构建的 App。

    请检查以下内容：

    * 能否浏览主导航。
    * 能否使用模板中的按钮和表单。
    * 操作后是否会显示明确的成功状态或验证状态。
    * 刷新页面后，是否仍能正常使用网站。
    * 能否将 Preview 调整为手机屏幕的宽度。

    如果有任何内容无法正常运行，请向 Agent 描述具体症状。无需自行诊断代码。

    <Frame>
      <img src="/assets/mirror/05-preview-d5702e9d9ac8.jpg" alt="在项目编辑器的 Preview 中运行的基于模板的网站" width="1280" height="720" data-path="images/first-app-template/05-preview.jpg" />
    </Frame>

    <Tip>
      想在发布前探索不同的视觉效果吗？请参阅[探索建议](/zh/ja/design/explore-suggestions)，并排生成不同外观，再应用你喜欢的版本。
    </Tip>
  </Step>

  <Step title="发布应用">
    Preview 正常运行后，选择 **Publish**。确认系统生成的子域名，选择哪些人可以访问应用，并检查安全设置。然后在对话框中选择 **Publish**。

    发布后，系统会创建应用的公开版本，并生成可分享的 URL。

    <Frame>
      <img src="/assets/mirror/06-publish-dialog-2f79654c6dfb.jpg" alt="显示生成的子域名、访问设置和 Publish 按钮的 Publish 对话框" width="1280" height="720" data-path="images/first-app-template/06-publish-dialog.jpg" />
    </Frame>
  </Step>

  <Step title="打开已发布的应用">
    在新浏览器标签页中打开公开 URL，并重复进行相同检查。分享前，请确认 App 在项目编辑器外也能正常运行。

    如果已发布的 App 与 Preview 表现不同，请检查发布日志以及 App 所需的生产环境配置。有关常见发布问题，请参阅[发布故障排除](/zh/ja/build/troubleshooting)。

    <Frame>
      <img src="/assets/mirror/07-published-site-8fe719004e5a.jpg" alt="在已发布的 Replit URL 中打开的、基于模板构建的完整 Website" width="1274" height="717" data-path="images/first-app-template/07-published-site.jpg" />
    </Frame>
  </Step>
</Steps>

<div id="section-3">
  ## 🎉 恭喜 — 您已发布第一个应用
</div>

您已从设计模板创建出可线上分享的 URL。在此过程中：

* 您从 Replit Design 中选择了一个模板并将其重混。
* 您让 Agent 将所选设计转化为可运行的网站。
* 您在 Preview 中测试了成果。
* 您发布了应用，并通过公开 URL 打开它。

这就是完整的 Replit 工作流程 — 选择起点、构建、测试、改进并发布。
