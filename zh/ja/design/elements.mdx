**元素 (Element) **是指标题、按钮、图片和表单字段等画框所渲染的各个组成部分。当你想在不重新生成整个画框的情况下仅修改其中一部分时，元素就是要操作的对象。

<div id="section">
  ## 选择元素
</div>

使用工具栏中的 [Edit 工具](/zh/ja/design/toolbar#edit)。启用 Edit 后，点击实时画框中的任意位置，即可选中光标所在位置的元素。选中的元素会显示高亮轮廓，并出现一个小型内联提示词输入框，可让你请求 Agent 进行修改。

<Note>
  只有当 Canvas 上至少有一个画框时，Edit 才可用。此外，它仅适用于桌面端。
</Note>

<div id="section-2">
  ## 对所选元素的操作
</div>

<div id="agent">
  ### 请求 Agent 进行更改
</div>

您可以使用内联提示词，请 Agent 更新元素的文案、颜色、布局、间距和行为。

  <img src="/assets/mirror/canvas-ask-element-53f7468a07d3.png" alt="Canvas 中选定元素的内联提示词放大图。“img”标签后显示“Ask about selected element…”占位文本和发送按钮" width="1500" height="500" data-path="images/replitai/canvas-ask-element.png" />
</Frame>

<div id="section-3">
  ### 直接替换图片
</div>

选中图片元素后，Visual Editor 的 **Image** 区域会显示源路径和 **Upload Image** 按钮，无需编写提示词即可直接替换文件。

</Frame>

<div id="visual-editor">
  ## Visual Editor
</div>

选择元素后，右侧会打开与内联提示词配套的 **Visual Editor**。该面板将所有控件清晰地归类到不同部分，方便你更快找到所需内容：**Text**、**布局**、**Color** 和 **Border**。 (选择图像元素时，还会显示 **Image** 部分。)

</Frame>

<div id="layout">
  ### 布局
</div>

在 **布局** 部分，您无需通过 Agent 即可调整容器内子元素的排列方式。选择弹性容器并展开布局后，您将看到：

* **对齐**：一个 3×3 点阵选择器，用于指定项目在容器两个轴上的位置。
* **方向**：两个箭头按钮，用于将子元素排列为行或列。
* **间距**：项目之间间距的像素值。间距输入框旁的图标会随当前方向变化，让您始终清楚正在调整水平还是垂直间距。旁边的箭头图标可切换**在项目之间分配空间 (Distribute space between items) **，将子元素推向容器两端。
* **外部间距**：用于分别设置元素各边外侧间距的输入框 (每边一个，并提供可同时锁定四边的链接切换开关) 。
* **内部间距**：用于沿各轴设置元素内侧间距的输入框，并提供可同时锁定两个轴的链接切换开关。

布局部分仅在所选元素应用了至少一项布局控制时显示。对于没有间距或布局属性的纯文本节点，此部分会完全隐藏，以保持编辑器简洁。

有关 **Text**、**Color**、**Border** 和 **Image** 部分，请参阅 [Visual Editor 指南](/zh/ja/design/visual-editor)。
