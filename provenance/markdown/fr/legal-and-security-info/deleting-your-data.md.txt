# Supprimer vos données

> Découvrez comment supprimer définitivement votre compte et vos informations personnelles de Replit via un navigateur web ou l'application mobile.

Pour supprimer vos informations personnelles de Replit, veuillez suivre ces instructions. Si vous utilisez un navigateur web sur ordinateur :

1. Connectez-vous à Replit et ouvrez les **Paramètres** (cliquez sur votre icône de profil, puis **Paramètres**, ou rendez-vous sur [https://replit.com/settings](https://replit.com/settings)).
2. Sous **Compte**, ouvrez **Facturation** et faites défiler jusqu'à « Gérer l'abonnement » si nécessaire.
3. Dans la section « Supprimer le compte », cliquez sur « Demander la suppression du compte » puis sur « Oui, supprimer mon compte » pour confirmer.

Vous pouvez également effectuer la même procédure via notre application mobile :

1. Ouvrez les **Paramètres** (par exemple, appuyez sur votre profil ou sur l'entrée Paramètres dans l'application).
2. Accédez à la section compte/facturation et trouvez « Gérer le compte » ou « Supprimer le compte ».
3. Appuyez sur « Supprimer le compte » et confirmez lorsque vous y êtes invité.

La suppression de votre compte retire l'intégralité de votre contenu de Replit (y compris les applications Replit, les modèles et les publications) et entraîne la suppression de vos informations personnelles de nos systèmes. Vous ne pourrez pas récupérer ces données si vous changez d'avis.

Pour plus d'informations sur vos droits concernant vos données personnelles, veuillez consulter notre [Politique de confidentialité](https://replit.com/site/privacy).
