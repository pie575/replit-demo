使用 API 构建包含关键指标、图表和筛选器的实时仪表板。它会自动
更新，支持导出，并且只显示数据中实际存在的内容。将需要
持久化的内容保存到 Replit Database。

<div id="section">
  ## 最佳适用场景
</div>

* 需要可交互查看的实时仪表板，而非截图的产品经理。
* 需要通过 API 始终保持最新状态的私有仪表板的运营或数据负责人。

<div id="section-2">
  ## 开始之前
</div>

列出您希望借助该仪表板做出的决策。准备一个 API URL，或使用以下 DummyJSON 端点。

<Info>
  测试时，您可以尝试以下免费的 DummyJSON API 端点。

  * 订单：`https://dummyjson.com/carts?limit=0`
  * 客户：`https://dummyjson.com/users?limit=0`
  * 目录：`https://dummyjson.com/products?limit=0`
  * 类别：`https://dummyjson.com/products/categories`
</Info>

<div id="section-3">
  ## 给 Agent 的指令
</div>

<AiPrompt>
  用这个 API [URL] 构建一个实时仪表板。展示能回答[判断内容]的关键指标、
  图表和筛选器。支持自动刷新和数据导出。需要持久化的内容请保存到
  Replit Database。只展示数据中真实存在的内容。
</AiPrompt>

<div id="section-4">
  ## 预期效果
</div>

Agent 会加载数据，选择汇总指标和图表，并添加筛选器。请至少挑一个数值与数据源核对。如果使用的是 DummyJSON，可以选择一条订单，打开 `https://dummyjson.com/carts/{id}`，确认总额是否一致。切换筛选器，确认所有卡片和图表都会随之更新。导出一次，并将其中一行与 API 核对。

  ## 按需自定义
</div>

  添加一个类别筛选器，重新计算页面上的所有数值。

<AiPrompt>缓存 API 响应，以加快加载速度。</AiPrompt>

<div id="section-6">
  ## 故障排除
</div>

* **API 不可用或结构异常：** 请检查 URL，并确认响应中是否包含预期字段。要快速测试，请使用上述 DummyJSON 端点。
* **数值与预期不符：** 请让 Agent 显示查询或转换逻辑，并至少将一个数值与源数据进行核对。
* **筛选器未更新图表：** 请让 Agent 将每个筛选器同时关联到摘要卡片和图表数据。如果仪表板运行缓慢，请缓存 API 响应，或减少启动时加载的记录数量。
