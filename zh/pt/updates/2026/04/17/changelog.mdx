<div id="novo-menu-suspenso-de-modos-do-agent">
  ### 全新的 Agent 模式下拉菜单
</div>

Chat 输入框中的 Agent 模式选择器现在改为更简洁的分段控件。你可以直接在工具栏中选择 Lite、Economy 和 Power，需要时通过高级设置使用 Turbo。

新增内容：

* **工具栏分段控件。** Lite、Economy 和 Power 并排显示，当前处于哪个模式、如何切换一目了然。
* **键盘快捷键。** 按 **⌘+Shift+I** (Windows 上为 Ctrl+Shift+I) 即可无需鼠标切换模式。
* **Turbo 以橙色突出显示。** Turbo 速度最快，但费用更高，因此在界面中特别标出，让成本差异一目了然。
* **高级设置默认折叠。** 测试、代码审查和 Turbo 的相关控件收纳在**高级设置**中，让主视图保持整洁。
* **Max 模式已停用。** 需要最强构建能力时请使用 Power；想获得最快响应时，可在高级设置中启用 Turbo。

<div id="agent-sugere-tarefas-de-acompanhamento">
  ### Agent 推荐后续任务
</div>

<Frame>
  <video autoPlay muted loop playsInline src="/assets/mirror/replit-suggested-tasks-b27620d93fd2.mp4" />
</Frame>

Agent 现在会在完成工作后推荐**后续任务**，并结合项目的完整上下文，建议下一步可以构建什么。每项已完成任务下方会显示三类建议：

* **可构建的新功能** — 与您刚发布的内容自然契合的功能
* **性能改进** — Agent 在处理任务时发现的优化机会
* **用户体验改进** — 让功能更完善的细节优化

查看每项建议，选择要接受的建议并点击**接受**，Agent 就会在后台执行这些任务，您可以继续构建。您可以在“已完成”列中点击**隐藏建议任务**来隐藏不需要的建议，并随时重新显示。

详细了解[后续任务建议](/zh/pt/core-concepts/agent/task-system/follow-up-tasks)。

<div id="melhorias-na-pgina-de-projetos">
  ### 项目 页面优化
</div>

项目 页面新增三项实用优化：

* **每张卡片均可预览 artifact。** 现在，每张项目卡片都会显示其中各个 artifact 的小图标。将鼠标悬停在任意图标上，即可查看该 artifact 的截图，无需打开项目。
* **默认按你最近打开的时间排序。** 现在，页面会将*你*最近处理过的项目置顶，让你当前的工作在繁忙的团队 workspace 中始终保持醒目。
* **个人置顶。** 将你经常访问的项目置顶。置顶仅对你自己可见，不会影响其他 workspace 成员看到的内容。

<div id="grupos-personalizados-para-organizaes-scim">
  ### 面向 SCIM 组织的自定义群组
</div>

已启用 SCIM 预配的组织现在可以在 Replit 中创建自定义群组，与通过 IdP 同步的群组并存。自定义群组可用于按项目授予访问权限、临时授权，或任何在身份提供方中没有对应结构的场景。

通过 SCIM 同步的群组仍由身份提供方管理，而自定义群组则由组织管理员直接在 Replit 中管理。

详细了解 [SCIM](/zh/pt/teams/identity-and-access-management/scim#creating-custom-groups-alongside-scim)。
