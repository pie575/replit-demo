Replit Database utilise une base de données SQL entièrement gérée qui vous permet d&#39;ajouter un stockage de données persistant à votre Replit App depuis le Project Editor.

<Note>
  Le moyen le plus rapide de démarrer consiste à demander à **Agent** d&#39;ajouter une base de données à votre app. Agent configurera l&#39;intégration, créera le schéma de la base de données et mettra à jour votre app pour qu&#39;elle puisse stocker et récupérer les données.
</Note>

<div id="features">
  ## Fonctionnalités
</div>

L&#39;outil Replit Database offre les fonctionnalités suivantes :

* **Outils de base de données** : exécutez des requêtes, gérez le schéma de votre base de données et visualisez vos données grâce aux outils SQL intégrés
* **Retour dans le temps** : restaurez votre base de données à n&#39;importe quel checkpoint **Agent**. Consultez [Récupération de données](/fr/features/data-and-storage/data-recovery)
* **Stockage gratuit** : comprend 20 Go de stockage gratuit pour chaque Replit App.
* **Variables d&#39;environnement** : utilisez des variables d&#39;environnement dans votre Replit App pour accéder à la base de données en toute sécurité

<Info>
  Avant le 4 décembre 2025, la base de données de développement était hébergée sur Neon et présente quelques différences importantes.
  Consultez [Développement et production](/fr/features/data-and-storage/development-and-production#legacy-development-database) pour plus de détails.
</Info>

<div id="usage">
  ## Utilisation
</div>

<YouTubeEmbed videoId="zbyRuoPNIc8" title="Comment utiliser les bases de données sur Replit" />

Vous pouvez accéder à l&#39;outil Replit Database directement depuis le Project Editor.
Les sections suivantes vous guident dans la configuration et la gestion de votre base de données.

<Accordion title="Comment accéder à l'outil Database">
  1. Ouvrez le volet **Tools** et sélectionnez **Database** sous **Replit Cloud**.
  2. La vue d&#39;accueil répertorie vos bases de données. Sélectionnez-en une, par exemple **Development Database**, pour l&#39;ouvrir.
</Accordion>

L&#39;outil Database s&#39;organise autour de votre liste de bases de données. La vue d&#39;accueil affiche chaque base de données avec son utilisation du stockage, ainsi que vos **Billing Period** et **Hours of Compute Used** actuels. L&#39;ouverture d&#39;une base de données donne accès à trois onglets :

* **Overview** : les tables de votre base de données.
* **My Data** : parcourez et modifiez les lignes, ou exécutez des requêtes SQL.
* **Settings** : la chaîne de connexion, l&#39;utilisation du stockage et les détails de connexion.

<div id="add-a-database">
  ### Ajouter une base de données
</div>

Toutes les Replit Apps incluent une base de données par défaut. Vous pouvez y accéder en sélectionnant l&#39;outil <img class="icon-svg" src="/assets/mirror/postgres-c4cb2a1e2de3.svg" alt="Icône de base de données PostgresSQL" width="24" height="24" data-path="images/icons/postgres.svg" /> **Database** dans le Project Editor.

Pour intégrer la base de données à votre Replit App, demandez à l&#39;**Agent** d&#39;ajouter une base de données PostgreSQL à votre Replit App,
en précisant les données que celle-ci doit stocker. L&#39;Agent créera le schéma de la base de données
et mettra à jour votre app pour qu&#39;elle communique avec la base de données.

<div id="security-features">
  ### Fonctionnalités de sécurité
</div>

Lorsque vous ajoutez une intégration de base de données avec **Agent**, celui-ci met en place un mappeur objet-relationnel (ORM)
qui gère toutes les communications avec la base de données de façon sécurisée.

Cette couche ORM, associée à l&#39;application des bonnes pratiques de sécurité par Agent, protège votre app contre les
exploits grâce aux fonctionnalités suivantes :

* **Validation de schéma** : vérifie que les données respectent les formats attendus
* **Assainissement des données** : nettoie automatiquement les saisies du créateur afin de prévenir les attaques par injection SQL
