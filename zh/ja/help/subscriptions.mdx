export const ProCreditRolloverPeriod = 'two months';

以下内容涵盖订阅管理。有关套餐详情，请参阅 [Core](/zh/ja/billing/plans/replit-core) 和 [Pro](/zh/ja/billing/plans/replit-pro)。

<AccordionGroup>
  <Accordion title="如何从 Core 升级到 Pro，以及两者有何区别？">
    与 [Core](/zh/ja/billing/plans/replit-core) 相比，[Pro](/zh/ja/billing/plans/replit-pro) ({ProPlanPrice}/月) 还提供以下内容：

    * Turbo 模式
    * 最多 15 名构建者，可共享积分池
    * 分级积分：未使用的积分可在{ProCreditRolloverPeriod}内结转
    * 数据库恢复窗口为 28 天 (Core 为 7 天)
    * 优先支持

    如需升级，请打开**设置 → 账单**，选择 Pro 套餐并确认付款信息。有关功能对比和当前价格，请访问[定价页面](https://replit.com/pricing)。
  </Accordion>

  <Accordion title="如何取消订阅？">
    打开**设置 → 账单**，选择取消订阅选项并完成确认步骤。当前计费周期结束前，你仍可使用套餐功能；之后，你的账户将转为免费的[Starter 套餐](/zh/ja/billing/plans/starter-plan)。

    请注意，转换后已发布的应用可能会下线，自定义域名连接将被移除，存储空间也会缩减。请提前下载想要保留的内容。如果订阅显示为 `past_due`，可能表示付款失败——请先解决此问题再取消订阅。
  </Accordion>

  <Accordion title="续费扣款失败——如何更新付款方式？">
    打开**设置 → 账单**，选择**更新付款方式**，然后添加或更新银行卡。保存后，Replit 会自动重试未支付的款项。

    如果问题仍然存在，请提供支付意图 ID (以 `pi_` 开头) 并[联系 Replit 支持团队](https://replit.com/support)。付款失败通知可能会被归入垃圾邮件文件夹。
  </Accordion>

  <Accordion title="如何将订阅转让给其他电子邮件地址或账户？">
    订阅与 Replit 账户绑定，无法直接转让。若要在保留订阅的同时更改账户邮箱，请前往**设置 → 个人资料**编辑邮箱地址。

    如需将订阅迁移到其他账户，请[联系 Replit 支持](https://replit.com/support)—我们将视具体情况处理。
  </Accordion>

  <Accordion title="一个月内被扣费两次——这是怎么回事？">
    一个月内收到两次账单通常是由以下原因之一造成的：

    * 订阅费用达到计费阈值，以及单独的使用量账单
    * 之前付款失败后，重试付款成功
    * 存在多个有效订阅

    要查看每笔账单的详情，请打开**设置 → 账户使用情况**，然后选择**查看历史发票**。如果仍有疑问，请[联系 Replit 支持](https://replit.com/support)。
  </Accordion>

  <Accordion title="我已更改套餐，但无法使用新功能，该怎么办？">
    套餐变更通常会立即生效。如果未显示新功能：

    1. 在 Mac 上按 `Cmd+Shift+R`，或在 Windows 上按 `Ctrl+Shift+R`，进行强制刷新。
    2. 退出登录后重新登录。
    3. 打开**设置 → 账单**，确认变更已完成——此处应显示新套餐的名称。

    如果账单中显示的套餐正确，但仍无法使用相关功能，请提供你的用户名和要使用的功能，并[联系 Replit 支持](https://replit.com/support)。
  </Accordion>

  <Accordion title="我可以暂停订阅，而不是取消订阅吗？">
    部分订阅用户可选择将订阅暂停 1 个月，而非取消订阅。如果你符合条件，在取消订阅时会看到此选项。暂停期间：

    * 将跳过下一次付款，且不会获得每月积分
    * 已发布的项目将继续运行，协作者也将保留访问权限
    * 符合条件的积分将结转，积分包仍可继续使用
    * Agent 和托管使用量仍将按量计费

    **设置 → 账单**会显示**暂停中**徽章和暂停结束日期，订阅将在该日期自动恢复。你可以在计划暂停生效前取消，但无法提前结束已生效的暂停。订阅只能暂停一次。
  </Accordion>
</AccordionGroup>
