URL-адреса для разработки позволяют просматривать и тестировать приложения прямо в процессе их создания. Такие URL-адреса имеют формат `UUID.servername.replit.dev` и дают живой предпросмотр приложения во время разработки.

Чтобы увидеть свой URL-адрес для разработки, нажмите на текст `{...}.replit.dev` в адресной строке.

<div id="entendendo-as-urls-de-desenvolvimento">
  ## Как работают URL-адреса для разработки
</div>

URL-адреса для разработки активны только пока вы активно работаете в Replit App. URL-адрес может меняться при каждом повторном открытии приложения. Они позволяют просматривать результат работы в браузере в процессе разработки и тестирования.

По умолчанию URL-адреса для разработки общедоступны в интернете. Любой, у кого есть URL-адрес, может видеть ваше приложение в процессе разработки. Это упрощает предоставление доступа к незавершённой работе соавторам, тестировщикам или заинтересованным лицам.

<Warning>
  URL-адреса для разработки временные и предназначены только для тестирования. Чтобы поделиться приложением с другими пользователями, рекомендуется [опубликовать приложение](/ru/pt/learn/projects-and-artifacts/replit-deployments).
</Warning>

<div id="banner-educativo">
  ### Обучающий баннер
</div>

Когда вы открываете предпросмотр разработки в новой вкладке, в верхней части страницы появляется обучающий баннер. Он помогает понять назначение URL-адресов `.replit.dev` при создании и тестировании приложений, поясняя, что это за адреса и как их следует использовать в процессе разработки.

<div id="tornando-as-urls-de-desenvolvimento-privadas">
  ## Как сделать URL-адрес для разработки приватным
</div>

Вы можете ограничить доступ к URL-адресу для разработки, чтобы защитить незавершённую работу.

Чтобы сделать URL-адрес для разработки приватным:

1. Откройте **Developer tools** в Project Editor.
2. Перейдите на вкладку **Networking**.
3. Включите переключатель **Private development URL**.

После этого для доступа к URL-адресу для разработки потребуется аутентификация. Просматривать незавершённую работу сможете только вы и авторизованные участники команды.

<Note>
  Клиенты Enterprise могут сделать приватные URL-адреса для разработки обязательными для всех проектов — это повышает безопасность, гарантируя, что работа над проектом остаётся защищённой в среде организации.
</Note>

<div id="melhores-prticas">
  ## Рекомендации
</div>

* **Используйте приватные URL-адреса** для конфиденциальных или проприетарных приложений на этапе разработки
* **Используйте публичные URL-адреса**, чтобы делиться своей работой с внешними заинтересованными сторонами во время активной разработки или тестировать приложение в другом браузере
