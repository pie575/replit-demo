<div id="section">
  ## 功能
</div>

借助 Agent 的图像生成功能，打造视觉效果出众的应用。你无需再依赖图库图片和外部设计工具，也不必为基础视觉内容聘请设计师。无论是制作作品集网站、构建游戏，还是设计移动应用界面，图像生成都能为你的项目提供量身定制的视觉素材。

Agent 可以完成的图像生成任务：

* **定制图像生成**：根据详细描述和规格生成图像
* **风格应用**：以写实、卡通等多种艺术风格生成图像
* **透明背景**：直接生成透明 PNG 图像，或移除现有图像的背景 — 非常适合徽标、图标、贴纸和产品抠图
* **项目集成**：将生成的图像无缝添加到应用代码库中
* **迭代优化**：根据反馈修改和改进图像

<div id="section-2">
  ## 使用方法
</div>

图像生成已内置于 Agent，无需额外开启。打开启用了 Agent 的 Replit 应用，直接告诉 Agent 你需要什么视觉内容即可。Agent 会根据你的请求自动判断何时生成图像，并按你的要求创建定制图像。

<div id="section-3">
  ### 图像生成最佳实践
</div>

若要让 Agent 生成的图像达到最佳效果，请遵循以下准则：

**描述要具体、详细**

* 包含风格、配色、构图和氛围等细节
* 如有需要，注明尺寸或宽高比
* 说明用途 (图标、背景、插图等)
* 如果需要叠加在其他内容之上的徽标、图标、贴纸或抠图，请指定使用透明背景

**反复迭代、持续优化**

* 先用简单的描述起步，再根据生成结果逐步优化
* 让 Agent 修改所生成图像的特定部分
* 请求生成变体，以探索不同的创作方向

**兼顾项目的整体风格**

* 保持整个应用的视觉一致性
* 说明符合品牌或设计系统的风格偏好
* 请求生成与现有视觉元素相协调的图像

<div id="section-5">
  ### 项目集成
</div>

Agent 会将生成的图像无缝集成到代码库中：

* **自动创建文件**：生成的图像直接保存到项目文件中
* **代码更新**：Agent 会更新代码，引用新的图像文件
* **资源整理**：图像会放置在项目结构中相应的目录下

借助这套简化的工作流，你无需离开开发环境即可生成并落地视觉内容。

<Note>
  Replit 的图像生成由 [Google Imagen 4](https://deepmind.google/models/imagen/) 提供支持，这是一款先进的文生图模型，擅长生成细节精致、文本渲染能力更强的高质量写实图像。
</Note>
