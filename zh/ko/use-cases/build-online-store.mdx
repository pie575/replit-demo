Agent 会先将商品目录导入 Shopify，然后构建一个 Replit 店面，从 Shopify 读取商品，并将客户引导至 Shopify 结账页面。请对照 Sheet 核对几件商品 (价格、文案、图片) ，并下一笔测试订单。使用 Shopify 测试支付，确认购物车总额与 Sheet 一致，并确认整个结账流程都停留在 Shopify 中。

<div id="section-6">
  ## 故障排查
</div>

* **照片与产品对不上：** 请将 Drive 中的文件名设为产品代码 (`CODE.jpg`) ，并让 Agent 跳过没有照片的行。
* **价格或文案与 Sheet 不一致：** 确认每个产品只占一行 (名称、价格、说明、产品代码、库存) ，导入后抽查几条记录。
* **结账未走 Shopify，或店面显示为主题：** 顾客看到的页面应位于 Replit 上，支付则通过 Shopify 结账完成。分享店铺前，请先下一笔测试订单。
