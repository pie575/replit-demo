<div id="o-que-este-fluxo-de-trabalho">
  ## En quoi consiste ce flux de travail ?
</div>

Le Design Canvas sert à l&#39;exploration — votre application, elle, vit dans l&#39;aperçu. Cette page retrace le parcours complet qui mène d&#39;une direction visuelle à une application publiée.

Concepts clés :

* **Canvas = brouillon** : les frames sont des maquettes HTML statiques qui servent à explorer des idées
* **Artefacts = sorties publiables** : convertir un frame crée un artefact compilable et publiable
* **Flux unidirectionnel** : aucun lien en direct n&#39;existe entre le Canvas et votre application — vous effectuez la conversion quand vous êtes prêt
* **Tout type d&#39;artefact** : convertissez en applications web, applications mobiles, présentations de diapositives, visualisations de données, et bien plus encore

<div id="como-ir-do-design-ao-aplicativo">
  ## Comment passer du design à l&#39;application
</div>

<div id="comece-no-canvas">
  ### Commencez dans le Canvas
</div>

Ouvrez le [Design Canvas](/fr/pt/replitai/canvas) et explorez votre idée. Demandez des maquettes à l&#39;Agent, générez des variantes et comparez les directions côte à côte.

**Exemples de prompts :**

* « Conçois une page de destination pour mon produit SaaS »
* « Montre-moi cinq variantes d&#39;une mise en page de dashboard »
* « Esquisse le parcours d&#39;inscription complet de mon application »

<div id="refine-com-o-visual-editor">
  ### Peaufinez avec le Visual Editor
</div>

Utilisez le [Visual Editor](/fr/pt/replitai/visual-editor) pour effectuer des retouches directement dans vos frames — modifiez le texte, ajustez les couleurs, changez l&#39;espacement — sans passer par une boucle de l&#39;Agent ni consommer de crédits d&#39;IA.

<div id="escolha-uma-direo">
  ### Choisissez une direction
</div>

Comparez vos frames et choisissez celui qui correspond le mieux à votre vision. Inutile qu&#39;il soit parfait : vous pourrez continuer à l&#39;affiner après la conversion.

<div id="converta-para-um-artefato">
  ### Convertissez en artefact
</div>

<Steps>
  <Step title="Sélectionnez votre frame">
    Cliquez sur le frame que vous souhaitez transformer en véritable application.
  </Step>

  <Step title="Demandez à Agent de le convertir">
    Indiquez à Agent ce que vous voulez — par exemple, « Convertis ceci en application web » ou « Transforme ceci en application mobile ».
  </Step>

  <Step title="Agent construit votre application">
    Agent crée un véritable artefact à partir du design que vous avez choisi. Il y ajoute le backend, la base de données et l&#39;infrastructure dont votre application a besoin.
  </Step>

  <Step title="Peaufinez dans l'aperçu">
    Passez à l&#39;aperçu pour voir votre application en fonctionnement. Continuez à utiliser le Visual Editor ou échangez avec Agent pour ajouter des fonctionnalités, corriger des détails et peaufiner le résultat.
  </Step>

  <Step title="Publiez">
    Lorsque votre application est prête, publiez-la. Replit se charge de l&#39;hébergement et de l&#39;infrastructure afin que votre application fonctionne de manière fiable pour votre public.
  </Step>
</Steps>

<div id="o-que-transferido">
  ### Ce qui est transféré
</div>

Lorsque vous convertissez un frame en artefact, l&#39;Agent s&#39;appuie sur le design comme référence pour construire une véritable application. La mise en page visuelle, les couleurs, la typographie et la structure sont conservées. L&#39;Agent ajoute ensuite les fonctionnalités par-dessus : stockage des données, comptes utilisateurs, connexions API.

<Note>
  La conversion est une étape à sens unique. Le frame du Canvas et l&#39;artefact obtenu sont distincts : les modifications apportées à l&#39;un n&#39;affectent pas l&#39;autre.
</Note>

<div id="o-que-voc-pode-construir">
  ## Ce que vous pouvez construire
</div>

* **Site statique → application full-stack** : commencez par concevoir une page de destination, puis convertissez-la et ajoutez un formulaire de contact, des paiements ou un backend de blog
* **Maquette de dashboard → visualisation de données en direct** : concevez la mise en page sur le Canvas, convertissez-la en artefact et connectez de véritables sources de données
* **Concept d&#39;application mobile → application native** : explorez l&#39;interface sur le Canvas, puis convertissez-la en artefact mobile doté d&#39;une navigation et de données réelles
* **Présentation de diapositives + produit** : concevez votre application et une présentation de diapositives dans le même projet — toutes deux commencent comme des explorations sur le Canvas et deviennent de véritables artefacts

<div id="perguntas-frequentes">
  ## Foire aux questions
</div>

<Accordion title="Dois-je commencer dans le Canvas ?">
  Non. Vous pouvez ignorer complètement le Canvas et construire directement en mode App. Le Canvas sert à l&#39;exploration — utilisez-le lorsque vous souhaitez tester des directions visuelles avant de faire un choix définitif.
</Accordion>

<Accordion title="Quelle est la différence entre un frame et un artefact ?">
  Un frame est une maquette HTML statique dans le Canvas — sans serveur, ni base de données, ni backend. Un artefact est une véritable application compilable que vous pouvez publier. Convertir un frame crée un artefact.
</Accordion>

<Accordion title="Puis-je convertir le même frame en plusieurs types d'artefacts ?">
  Oui. Vous pouvez convertir un même frame en application web, puis le convertir séparément en application mobile ou en présentation de diapositives. Chaque conversion crée un nouvel artefact.
</Accordion>

<Accordion title="Puis-je revenir au Canvas après la conversion ?">
  Le Canvas est toujours disponible. Vous pouvez continuer à créer de nouveaux frames, mais l&#39;artefact converti et le frame d&#39;origine sont indépendants : modifier l&#39;un ne change pas l&#39;autre.
</Accordion>

<Accordion title="Mon design sera-t-il exactement identique après la conversion ?">
  L&#39;Agent utilise votre design comme référence : la disposition, les couleurs et la structure sont donc reprises fidèlement. Certains détails peuvent évoluer à mesure que l&#39;Agent ajoute de vraies fonctionnalités — vous pourrez affiner le résultat dans l&#39;aperçu après la conversion.
</Accordion>
