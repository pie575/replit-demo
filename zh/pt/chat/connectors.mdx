Agent 支持四类集成，助您快速将想法变为 App：

* **Replit 托管**：开箱即用的内置集成。创建 App 后，Agent 即可立即使用这些集成。
* **连接器**：Replit 支持的第一方集成。只需登录一次，Agent 即可直接通过 Chat 读写这些服务——提取数据、创建记录、发送消息——并在各个 App 中使用它们进行构建。
* **外部集成**：可用于构建 App 的可信第三方服务。请 Agent 进行设置；您需要提供 API 密钥。
* **Agent 服务**：Agent 在后台使用的付费第三方 API，无需 API 密钥。相关费用将从您的 Replit 积分中扣除。

<Note>
  **套餐可用性**：大多数连接器需要 Core、Pro 或 Enterprise 订阅，部分连接器可在 Free 套餐中使用。Workspace 中的连接器目录会显示您当前套餐可使用哪些连接器。Free 套餐用户始终可以使用 Replit 托管的集成，例如数据库、身份验证等。
</Note>

<div id="let-agent-suggest-a-connector">
  ### 让 Agent 推荐连接器
</div>

有时，多个服务都能完成同一项任务，例如存储文件或发送电子邮件。当你需要某项功能但未指定身份提供方时，Agent 会显示一份合适的连接器简短列表。选择你需要的连接器。

选择身份提供方，然后登录一次以连接你的账户。Agent 会在 Build 过程中使用你的选择。你也可以直接按名称指定特定服务，跳过该列表。

<div id="connectors">
  ## Connectors
</div>

Connectors 让 Agent 可以直接读写你的各项服务，它们是由 Replit 官方提供支持的第一方集成。只需在 Project Editor 的 Connectors 页面登录一次，即可在各个 App 中复用这些连接。

<Note>
  连接与你的 Replit 账户绑定，在你的所有 App 中长期有效。一次连接服务，即可在你创建的任何 App 中使用。
</Note>

<div id="configuring-oauth-app-with-replit">
  ### 在 Replit 中配置 OAuth 应用
</div>

<Note>
  **仅限 Enterprise**：配置自定义 OAuth 应用需要 Enterprise 订阅。
</Note>

在 Enterprise 方案下，你可以为连接器使用自有的 OAuth 应用，而不必使用 Replit 的默认应用。这样，你的组织便可拥有该 OAuth 客户端、在授权页上展示自己的品牌，并精确控制构建者能够申请的权限范围。

要使用自有 OAuth 应用配置连接器，你需要从身份提供方处获取三样东西：**Client ID**、**Client Secret** 以及你希望授权的 **scopes**。此外，还需在身份提供方处注册 Replit 的回调 URL，身份验证才能顺利完成。

<Frame>
  <img src="/assets/mirror/connector-oauth-configuration-100911ce0c48.png" alt="Connector OAuth 配置对话框，包含 Client ID、Client Secret 和 Connector Scopes 字段，以及设置为 https://replit.com/connectors/oauth/callback 的 Redirect URL" width="1112" height="1218" data-path="images/replitai/connector-oauth-configuration.png" />
</Frame>

<Steps>
  <Step title="在身份提供方处创建 OAuth 应用">
    登录身份提供方的开发者控制台或管理设置，创建一个新的 OAuth 2.0 应用。各家身份提供方对这一步的叫法不尽相同——请留意 **Create OAuth app**、**Register application** 或 **Create client credentials** 之类的选项。
  </Step>

  <Step title="设置回调 URL">
    当身份提供方要求填写 **Authorized redirect URI** (有时称为 **Callback URL** 或 **Redirect URL**) 时，请输入：

    ```
    https://replit.com/connectors/oauth/callback
    ```

    构建者授权应用后，身份提供方会通过该 URL 将其送回 Replit。该地址必须完全一致——末尾斜杠、协议和子域名都不能有出入。如果你添加了多个重定向 URI，其中必须包含这一条。
  </Step>

  <Step title="复制 Client ID 和 Client Secret">
    创建应用后，身份提供方会显示 **Client ID** 和 **Client Secret**。

    * **Client ID**：你的 OAuth 应用的公开标识符，可以安全地出现在 URL 和客户端代码中。
    * **Client Secret**：用于证明请求来自你的应用的机密值。请将其视同密码——切勿提交到代码仓库或公开分享。Replit 会代你安全存储。

    部分身份提供方只在创建时显示一次 client secret。请立即复制并妥善保存，直到将其粘贴到 Replit 中。
  </Step>

  <Step title="选择 scopes">
    **Scopes** 是一组权限，用于定义你的 OAuth 应用可以代表构建者读取或写入哪些内容。每个身份提供方都会在其 API 文档中公布自己的 scopes 列表。

    在 Replit 中配置连接器时，你填写的 scopes 必须与在身份提供方处注册的 scopes **完全一致** (逐字符一致，包括任何 URL 前缀) 。常见的不匹配原因包括：

    * 缺少完整的 URL 前缀 (例如 `https://www.googleapis.com/auth/drive.file` 与 `drive.file`) 。
    * 多余的空格或结尾逗号。
    * 在 Replit 中申请了身份提供方应用上未启用的 scope。

    先从构建者所需的最小 scopes 开始，之后有需要再补充——大多数身份提供方都允许在不重新创建应用的情况下更新 scopes。
  </Step>

  <Step title="在 Replit 中配置连接器">
    在你所属组织的 **Connectors** 页面上，选择 **Add new integration**，选择相应服务，然后粘贴来自身份提供方的 **Client ID**、**Client Secret** 和 **Scopes**，最后选择 **Configure** 保存。
  </Step>
</Steps>

<Note>
  如果配置后身份验证失败，请再次确认身份提供方中的回调 URL 与 `https://replit.com/connectors/oauth/callback` 完全一致，并且你在 Replit 中填写的每个 scope 都已在身份提供方的应用上获得授权。
</Note>

<div id="debugging-connectors">
  ## 调试连接器
</div>

连接服务时遇到问题？以下指南将带你了解常见错误及其解决方法。

<AccordionGroup>
  <Accordion title="Google Workspace：&#x22;This app is blocked&#x22;">
    如果在连接 Google Drive、Docs、Sheets、Calendar 或 Gmail 时看到 **&quot;This app is blocked&quot;**，很可能是你所在组织的 Google Workspace 限制了第三方 OAuth 应用。请查看完整的故障排查指南以解决此问题。

    [解决 Google 连接器的 &quot;This app is blocked&quot; 问题](/zh/features/troubleshooting/debugging-google-connectors)
  </Accordion>

  <Accordion title="Salesforce：&#x22;Connection Expired&#x22;">
    如果 Salesforce 连接器出现 **&quot;Connection Expired&quot;** 错误而无法正常工作，很可能是你所在 Salesforce 组织的刷新令牌策略设置为在指定期限后让令牌过期。请查看完整的故障排查指南，更新你的 Connected App 设置。

    [修复 Salesforce 连接过期错误](/zh/features/troubleshooting/debugging-salesforce-connectors)
  </Accordion>
</AccordionGroup>
