Ce guide de référence présente la classe `Client` de la bibliothèque `object-storage` et fournit des exemples de code pour chacune de ses méthodes.

<div id="client">
  ## Client
</div>

La classe `Client` gère les interactions avec Replit App Storage. Elle fournit des méthodes permettant de manipuler les fichiers d&#39;un bucket.

Pour importer la classe depuis la bibliothèque, ajoutez la ligne suivante à votre code JavaScript :

```javascript theme={null}
import { Client } from "@replit/object-storage";
```

Utilisez le code suivant pour créer une instance `Client` permettant d&#39;interagir avec Replit Object Storage :

```javascript theme={null}
const client = new Client();
```

<div id="section">
  ## Constructeur
</div>

**constructor**

* **new Client**(`options?`) : `Client`

Crée une nouvelle instance de Client permettant d&#39;interagir avec Replit App Storage.

**Paramètres**

| Nom        | Type            | Description                                                   |
| :--------- | :-------------- | :------------------------------------------------------------ |
| `options?` | `ClientOptions` | Options de configuration utilisées pour paramétrer le client. |

**Valeur de retour**

`Client`

<div id="copy">
  ### copy
</div>

* **copy**(`objectName`, `destObjectName`) : `Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

Copie un objet au sein d&#39;un même bucket.
Cette méthode écrase l&#39;objet déjà présent au chemin de destination, le cas échéant.

**Paramètres**

| Nom              | Type     | Description                                |
| :--------------- | :------- | :----------------------------------------- |
| `objectName`     | `string` | Chemin complet de l&#39;objet à copier.    |
| `destObjectName` | `string` | Chemin complet de destination de la copie. |

**Valeur de retour**

`Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

***

</div>

