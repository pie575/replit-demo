<div id="azure-marketplace-integration">
  ### Azure Marketplace integration
</div>

이제 Replit을 Azure Marketplace에서 만나볼 수 있습니다! 많은 조직이 이미 Azure 전용 예산을 확보하고 있는데, 이번 integration을 통해 해당 예산을 Replit 구독과 usage에 바로 사용할 수 있습니다.

9월에 공개된 GCP Marketplace integration에 이어, 이번 추가로 Enterprise 팀이 기존 클라우드 조달 절차와 예산을 활용해 Replit을 한층 손쉽게 도입할 수 있게 되었습니다.

[Azure Marketplace에서 보기](https://marketplace.microsoft.com/en-us/product/saas/replit.replit?tab=Overview)

<div id="gitlab-and-bitbucket-support">
  ### GitLab 및 Bitbucket 지원
</div>

이제 Replit은 GitHub뿐만 아니라 GitLab과 Bitbucket 저장소도 지원하므로, 코드를 저장할 위치를 더 유연하게 선택할 수 있습니다. GitLab과 Bitbucket의 프로젝트를 Replit으로 바로 import할 수 있고, 지원되는 모든 플랫폼에서 Git 기능도 개선되었습니다.

강화된 Git integration의 주요 내용은 다음과 같습니다.

* **멀티 플랫폼 지원**: GitHub, GitLab, Bitbucket 저장소를 import하고 사용
* **개선된 Git 작업**: workspace 전반에서 더 빠르고 안정적인 Git 명령
* **향상된 저장소 관리**: 지원되는 모든 Git provider에서 clone, push, pull을 간소화한 workflow

자세한 내용은 [프로젝트 import하기](/ko/references/workspace/import)와 [Replit에서 Git 사용하기](/ko/references/version-control/git-interface)를 참고하세요.
