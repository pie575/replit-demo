<div id="sugestes-de-tarefas-de-acompanhamento">
  ## Предложения последующих задач
</div>

После того как вы примените задачу, Agent анализирует контекст вашего проекта и предлагает **последующие задачи**, которые вы, возможно, захотите реализовать дальше. Диалоговое окно **Предлагаемые следующие задачи** показывает главную рекомендацию прямо в потоке, поэтому вы можете продолжить работу, не покидая основную ветку.

<Frame>
  <img src="/assets/mirror/follow-up-tasks-dialog-c1660cec2d1d.png" alt="Диалоговое окно предлагаемых следующих задач с последующей задачей, кнопкой «Запустить» и ссылкой на дополнительные задачи на доске задач" width="495" height="290" data-path="images/agent/follow-up-tasks-dialog.png" />
</Frame>

Предложения последующих задач могут включать:

* **Новые функции для реализации** — возможности, которые естественно дополняют то, что вы только что выпустили
* **Улучшения производительности** — оптимизации, которые Agent заметил во время работы над задачей
* **Улучшения пользовательского опыта** — доработки и штрихи, которые доводят функцию до完 завершённого вида

Выберите **Запустить** в предложении, чтобы отправить его в фоновый режим, или выберите **Посмотреть план**, чтобы сначала изучить предлагаемую работу. Чтобы увидеть все предложения, выберите **Посмотреть больше на доске задач**. Предложенные последующие задачи отображаются в разделе **Предложено** в колонке **Черновики**.

<Frame>
  <img src="/assets/mirror/follow-up-tasks-kanban-21087e0210b6.png" alt="Доска задач с несколькими предложениями последующих задач в разделе «Предложено» в колонке «Черновики»" width="980" height="627" data-path="images/agent/follow-up-tasks-kanban.png" />
</Frame>

Если закрыть диалоговое окно **Предлагаемые следующие задачи**, предложения будут отклонены. Agent не показывает это диалоговое окно в основной версии, если там уже ожидает предложенный план, чтобы два prompt не конкурировали за ваше внимание.

<div id="gerenciando-muitas-sugestes-de-uma-vez">
  ## Управление большим количеством предложений сразу
</div>

Если в проекте много предложений по последующим задачам, откройте доску задач и нажмите **Изменить** в колонке **Черновики**. В режиме редактирования рядом с каждой предложенной задачей появляется флажок. Отметьте нужные задачи и нажмите **Запустить** или **Отменить**, чтобы применить действие ко всем выбранным задачам. Нажмите **Готово**, чтобы выйти из режима редактирования.
