---
title: "操作数据"
description: "在 My Data 标签页中，使用可视化工具或 SQL 浏览、编辑、导出数据库并执行查询。"
---

**My Data** 标签页用于查看和修改数据库中的数据。打开 **Database** 工具，选择数据库，然后选择 **My Data**。你既可以通过可视化方式操作，也可以直接运行 SQL。

<Note>
  要编辑生产数据，请选择生产数据库并打开 **My Data**，然后开启 **Edit**。请注意，这些是线上应用的真实数据。
</Note>

<div id="section">
  ## 以可视化方式浏览和修改数据
</div>

Database 工具内置了 <a href="https://orm.drizzle.team/drizzle-studio/overview" target="_blank">Drizzle Studio</a>，可用于以可视化方式浏览和修改数据。这些可视化工具有助于避免语法错误，并提供以下功能：

* 筛选和排序数据，快速定位所需信息
* 将数据导出为文件，供外部使用
* 插入和修改行数据
* 创建和管理模式、表、视图和 enum

<div id="sql">
  ## 运行 SQL 命令
</div>

使用 SQL runner，你可以在数据库上运行 SQL 命令并查看结果。

<Accordion title="如何打开 SQL runner">
  在 **Database** 工具中，

  1. 选择 **My Data** 标签页
  2. 选择 <img class="icon-svg" src="/assets/mirror/sql-runner-icon-b25868882922.svg" alt="SQL runner 图标" width="16" height="16" data-path="images/icons/sql-runner-icon.svg" /> **SQL runner**
</Accordion>

要运行查询，请在文本框中输入 SQL 语句，然后选择旁边的 <img class="icon-svg" src="/assets/mirror/sql-play-8ed26b5de7f1.svg" alt="sql 运行图标" width="18" height="18" data-path="images/icons/sql-play.svg" /> 运行按钮。

<Frame>
  <img src="/assets/mirror/sql-runner-run-8ad798a61335.jpg" alt="SQL runner 与运行按钮的截图" width="1390" height="608" data-path="images/databases/sql-runner-run.jpg" />
</Frame>

<Tip>
  你无需自己编写 SQL。只要让 Agent 查询或修改数据，它就会替你编写并运行 SQL。
</Tip>
