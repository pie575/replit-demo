### Crie apps mobile full-stack com o Agent

<Frame>
  <img src="/assets/mirror/cleanshot-2025-12-05-at-12-27-22-2x_273f89390642-dc03158b7d7f.png" width="1082" height="504" data-path="images/changelog/2025-12-05/cleanshot-2025-12-05-at-12-27-22-2x_273f89390642.png" />

O Agent agora pode criar [apps mobile](/pt/replitai/building-mobile-apps) com um servidor backend completo. Isso desbloqueia capacidades poderosas incluindo [Integrações de IA](/replitai/integrations), [Banco de Dados](/pt/features/data-and-storage/sql-database), [Object Storage](/pt/features/data-and-storage/object-storage) e conectores — tudo o que você precisa para desenvolvimento mobile pronto para produção.

### Banco de Dados agora disponível para todos

O novo [Banco de Dados](/pt/features/data-and-storage/sql-database) agora é o padrão para todos os novos Replit Apps. Esta atualização oferece maior confiabilidade e controle de infraestrutura, com melhor desempenho e gerenciamento de dados mais fácil para seus projetos.

### O Fast Mode lida com mais tarefas de forma autônoma

  <img src="/assets/mirror/image_4f661377d428-8454460e1cca.png" width="720" height="212" data-path="images/changelog/2025-12-05/image_4f661377d428.png" />

O [Lite mode](/pt/core-concepts/agent/agent-modes) (anteriormente Fast Mode) agora pode lidar com mais tarefas de forma autônoma enquanto recomenda o Agent para mudanças maiores. Construa mais rápido com iterações rápidas e transições perfeitas.

### Conecte serviços de terceiros mais rapidamente

Conecte serviços de terceiros mais rapidamente com suporte aprimorado a conectores. Adicione a maioria dos serviços baseados em chave de API simplesmente fornecendo sua configuração — sem configuração complexa necessária. Aprimorado com configurações de múltiplas chaves e verificações de integridade estendidas para [integrações](/replitai/integrations) mais confiáveis.
