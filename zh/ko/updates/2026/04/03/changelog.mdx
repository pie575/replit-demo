<div id="ai">
  ### 素材库中的图库图片与 AI 生成图片
</div>

图库图片和 AI 生成的图片现在会显示在素材库侧边栏中。此前，这些图片虽然在项目中生成，却不会出现在素材库中，查找起来并不方便。现在，你可以直接在素材库侧边栏中找到并重复使用 Agent 下载或生成的图片。

<div id="plan-mode">
  ### Plan Mode 修复
</div>

现在，在发送第一条消息后切换 Plan Mode 可以正确生效。此前在对话过程中切换 Plan Mode 会被自动忽略。

<div id="section-2">
  ### 幻灯片导出改进
</div>

大型幻灯片文稿 (150 页以上) 的导出更加稳定。导出超时时间现在会根据幻灯片数量自动调整，可支持 200 页以上的文稿。
