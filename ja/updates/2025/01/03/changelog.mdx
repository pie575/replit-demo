## プラットフォームの更新

### xAI インテグレーション

Agent があなたのアプリに xAI を直接追加できるようになりました。

<Frame>
  <img src="/assets/mirror/xai-announce-232aa8bf6428.jpeg" alt="xAI インテグレーションのアナウンス" width="3840" height="2160" data-path="images/changelog/2025-01-03/xai-announce.jpeg" />
</Frame>

Grok をプロジェクトに追加し、数秒で公開できます。プロンプトで「xAI を使って AI 機能を追加して」と伝えるか、インテグレーションから xAI を選ぶだけで—Agent が API でビルドします。

<Frame>
  <img src="/assets/mirror/xai-in-product-a0102e19b327.jpeg" alt="製品内の xAI" width="1120" height="1120" data-path="images/changelog/2025-01-03/xai-in-product.jpeg" />
</Frame>

お気に入りのインテグレーションがさらに Agent に追加されます。

### カスタムドメインのエラーハンドリング

カスタムドメインの検証失敗に関する具体的なエラーメッセージが利用できるようになり、問題をより素早くデバッグできます。

### メニュー検索機能

Replit Apps のサイドバーにあるメニュー項目を検索できるようになりました。

### Neon データベースの改善

Neon データベースのインテグレーションが最適化されました。Agent で追加したデータベースは、より費用対効果が高く、パフォーマンスが向上しています。

### デフォルトで React

新しいフロントエンド Replit Apps のデフォルトテンプレートは React を使用するようになりました。プロジェクトは最初から洗練されて機能的になります。

## チームとエンタープライズ

### Replit Teams のログイン

Teams のログインフローが更新され、始めやすくなりました。チームコンテキスト選択ページを含む新しいログインエクスペリエンスと、Teams のお客様向けの改善されたアカウント切り替えが含まれます。
