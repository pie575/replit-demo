<div id="replit-auth">
  ### Replit Auth
</div>

[Replit Auth](/ru/ko/features/auth-and-identity/authentication) теперь доступен всем пользователям! Это встроенная система аутентификации, которая позволяет добавить вход пользователей в приложение с минимальной настройкой. Вместо того чтобы создавать сложную систему аутентификации с нуля, вы получаете безопасное и готовое к использованию решение, интегрированное с инфраструктурой Replit.

**Ключевые возможности:**

* **Без настройки** — аутентификация добавляется одним-единственным prompt в Agent
* **Встроенная безопасность** — инфраструктура Replit с защитой от распространённых атак
* **Управление пользователями** — упрощённое управление пользователями через окно Auth
* **Интеграция с базой данных** — записи о пользователях создаются в базе данных автоматически
* **Настраиваемая страница входа** — персонализация входа в вашем приложении
* **Сброс пароля** — Replit сам отправляет письма для сброса пароля, поэтому собственный сервис рассылки не нужен

Начать очень просто — достаточно упомянуть Replit Auth в prompt для Agent:

<AiPrompt>
  Помогите мне создать приложение [идея приложения], в котором должен быть Replit Auth.
</AiPrompt>
