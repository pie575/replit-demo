title: "Preview"

---

Preview affiche le résultat de votre application web et met à disposition les outils de développement et les fonctionnalités de débogage d&#39;un navigateur.

Lorsque vous lancez votre application web avec le bouton **Exécuter**, Replit lui attribue une URL temporaire accessible sur Internet. L&#39;outil Preview affiche la page exactement comme elle apparaîtrait dans un navigateur. Il propose également des outils de développement semblables à ceux des navigateurs les plus répandus.

<Note>
  Preview est le nouveau nom de Webview.
</Note>

<div id="section">
  ## Fonctionnalités
</div>

Preview inclut les fonctionnalités suivantes pour tester et déboguer vos applications web en toute fluidité :

* **Vue web en direct** : affichez votre application et interagissez avec elle sans quitter l&#39;onglet du navigateur
* **Outils de développement** : diagnostiquez rapidement les problèmes grâce aux outils intégrés
* **Test responsive** : affichez votre application selon différentes tailles d&#39;écran d&#39;appareils mobiles

<div id="section-2">
  ## Utilisation
</div>

L&#39;outil Preview s&#39;ouvre automatiquement lorsque vous exécutez une application web.
Vous pouvez modifier ce comportement via le paramètre **Automatic Preview** de l&#39;outil **User Settings**.

Voici comment ouvrir Preview.

<Accordion title="Comment accéder à Preview">
  Depuis le **dock d&#39;outils** à gauche :

  1. Sélectionnez <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Icône Tous les outils" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **Tous les outils** pour afficher la liste des outils de l&#39;éditeur de projet.
  2. Sélectionnez <img class="icon-svg" src="/assets/mirror/preview-icon-6d37238e8cc2.svg" alt="Icône Preview" width="16" height="16" data-path="images/icons/preview-icon.svg" /> **Preview**.

  Depuis la **barre de recherche** :

  1. Sélectionnez la loupe <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="Icône loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> en haut pour ouvrir l&#39;outil de recherche
  2. Saisissez « Preview » pour trouver l&#39;outil, puis sélectionnez-le dans les résultats.
</Accordion>

<div id="section-3">
  ## Barre d&#39;adresse
</div>

La barre d&#39;adresse située en haut de l&#39;onglet **Preview** contient les outils suivants :

* **Bouton Précédent** : revient à la page précédente de l&#39;historique de navigation
* **Bouton Suivant** : passe à la page suivante de l&#39;historique de navigation
* **Domaine de l&#39;app** : sélectionnez `{...}.replit.dev` pour afficher des informations sur l&#39;URL temporaire de votre Replit App
* **Champ d&#39;adresse** : affiche le chemin de l&#39;URL actuelle ou permet de saisir un nouveau chemin

<div id="section-4">
  ## Outils du navigateur
</div>

Les outils du navigateur, situés à droite de la barre d&#39;adresse, offrent les fonctionnalités suivantes :

* **Taille d&#39;écran** : choisissez parmi différents préréglages de taille d&#39;écran d&#39;appareils pour tester votre design responsive
* **Outils de développement** : affichez ou masquez le volet [Outils de développement](#Developer_tools)
* **Nouvel onglet** : ouvrez l&#39;URL de votre application web dans un nouvel onglet du navigateur

<Note>
  **Vous créez une application mobile ?** Le panneau Preview prend également en charge la prévisualisation dans le **simulateur iOS** et l&#39;**émulateur Android**. Pour en savoir plus, consultez [Applications mobiles natives](/fr/ja/features/artifact-types/building-mobile-apps#preview-on-a-simulator-or-emulator).
</Note>

<div id="section-5">
  ## Outils de développement
</div>

Les outils de développement, propulsés par le projet open source <a href="https://github.com/liriliri/eruda" target="_blank">Eruda</a>, vous permettent d&#39;effectuer les tâches suivantes :

* Afficher et utiliser la console JavaScript dans le contexte de votre app
* Inspecter les éléments du DOM
* Surveiller les requêtes réseau
* Configurer les paramètres d&#39;affichage et de comportement

Pour accéder aux outils de développement, sélectionnez le bouton <img class="icon-svg" src="/assets/mirror/wrench-7cee9d1168da.svg" alt="Icône de clé à molette" width="16" height="16" data-path="images/icons/wrench.svg" /> **Outils de développement** en haut de l&#39;onglet **Preview**
afin de les afficher ou de les masquer.

Les sections suivantes décrivent les actions que vous pouvez effectuer dans chaque onglet des outils de développement.

<div id="console">
  ### Console
</div>

L&#39;onglet **Console** affiche les journaux JavaScript générés par votre application.
Cet onglet vous permet d&#39;effectuer les opérations suivantes :

* **Effacer la sortie** : sélectionnez l&#39;icône <img class="icon-svg" src="/assets/mirror/clear-bd1bf1847597.svg" height="16" width="16" alt="Icône Effacer" data-path="images/icons/clear.svg" /> en forme de cercle barré pour supprimer toute la sortie de la console.
* **Filtrer la sortie** : affichez la sortie de la console filtrée par type (Tous, Info, Warning, Error).
* **Filtrer par correspondance de texte** : sélectionnez l&#39;icône <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="Icône Filtre" data-path="images/icons/filter.svg" /> de filtre et saisissez du texte pour afficher les sorties correspondantes.
* **Copier la sortie** : sélectionnez le bouton <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="Icône Copier" data-path="images/icons/copy.svg" /> de copie pour copier les messages de console sélectionnés.
* **Exécuter du code JavaScript** : sélectionnez le chevron droit <img class="icon-svg" src="/assets/mirror/arrow-right-2859a6e6bdeb.svg" height="16" width="16" alt="Icône Flèche droite" data-path="images/icons/arrow-right.svg" /> pour exécuter du code JavaScript dans le contexte de votre application. Saisissez une expression, puis sélectionnez **Exécuter**.

<div id="elements">
  ### Elements
</div>

L&#39;onglet **Elements** permet d&#39;inspecter et de modifier la structure DOM d&#39;une page web.

* **Afficher les détails d&#39;un élément** : affiche les détails d&#39;un élément DOM et sa position dans le code HTML
* **Copier la sortie** : cliquez sur le bouton de copie <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="Icône de copie" data-path="images/icons/copy.svg" /> pour copier le message de console sélectionné.

Utilisez la flèche de sélection <img class="icon-svg" src="/assets/mirror/select-1165d9548c39.svg" height="16" width="16" alt="Icône de sélection" data-path="images/icons/select.svg" /> pour activer le mode sélection. Une fois ce mode activé, cliquez sur un élément de la page web.
Le code HTML et CSS de cet élément s&#39;affiche alors dans l&#39;onglet Elements.

<div id="network">
  ### Network
</div>

L&#39;onglet **Network** permet de surveiller les requêtes lancées par la page web.
Il offre les possibilités suivantes :

* **Suivre les requêtes** : affichez toutes les requêtes réseau lancées par votre app. Sélectionnez une requête pour en afficher les détails.
* **Filtrer** : sélectionnez l&#39;icône en forme d&#39;entonnoir <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="Icône de filtre" data-path="images/icons/filter.svg" /> et saisissez du texte pour afficher les résultats correspondants. Videz le champ pour effacer le filtre.
* **Copier** : sélectionnez le bouton de copie <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="Icône de copie" data-path="images/icons/copy.svg" /> pour copier les informations de stockage.

<div id="resources">
  ### Resources
</div>

L&#39;onglet **Resources** affiche les ressources chargées par la page ainsi que le stockage du navigateur, comme les cookies et le stockage local.
Vous pouvez afficher et actualiser la liste des types de ressources suivants :

* Fichiers JavaScript
* Feuilles de style
* Iframe
* Images

Cet onglet permet d&#39;effectuer les opérations suivantes :

* **Afficher le stockage** : consultez le stockage local, le stockage de session et les cookies.
* **Filtrer** : sélectionnez l&#39;icône en forme d&#39;entonnoir <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="Icône de filtre" data-path="images/icons/filter.svg" /> et saisissez du texte pour afficher les résultats correspondants. Videz le champ pour effacer le filtre.
* **Effacer** : sélectionnez le bouton Effacer <img class="icon-svg" src="/assets/mirror/clear-bd1bf1847597.svg" height="16" width="16" alt="Icône Effacer" data-path="images/icons/clear.svg" /> pour supprimer toutes les données de ce type de stockage.
* **Supprimer l&#39;élément sélectionné** : sélectionnez l&#39;icône « X » <img class="icon-svg" src="/assets/mirror/delete-a21eb49cac3c.svg" height="16" width="16" alt="Icône Supprimer" data-path="images/icons/delete.svg" /> pour supprimer un élément de stockage.
* **Copier** : sélectionnez le bouton Copier <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="Icône Copier" data-path="images/icons/copy.svg" /> pour copier les informations de stockage.

<div id="settings">
  ### Settings
</div>

L&#39;onglet **Settings** vous permet de personnaliser l&#39;apparence et le comportement des outils de développement.
Cet onglet propose les options de personnalisation suivantes :

* **Paramètres des outils** : personnalisez les options appliquées à chaque onglet d&#39;outil
* **Contrôles JavaScript** : définissez le comportement de JavaScript, par exemple en le désactivant pour tester le fonctionnement de votre application
* **Paramètres d&#39;affichage** : modifiez le thème des outils de développement, la taille des panneaux, la transparence et d&#39;autres comportements
