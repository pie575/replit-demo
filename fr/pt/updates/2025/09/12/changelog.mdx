export const YouTubeEmbed = ({videoId, title = "Vidéo YouTube", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

<div id="lanamento-do-agent-3">
  ## Lancement d&#39;Agent 3
</div>

Cette semaine, nous avons lancé Agent 3.

<YouTubeEmbed videoId="4FxNXFOdt6w" title="Diffusion en direct du lancement d'Agent 3" />

Agent 3 apporte des avancées majeures en matière d&#39;autonomie, de fiabilité et de rapidité :

* **Test d&#39;application** : Agent se teste lui-même dans un véritable navigateur, détecte les problèmes et les corrige au fil d&#39;un cycle de réflexion. Voir [Test d&#39;application](/fr/pt/core-concepts/agent/app-testing).
* **Temps d&#39;exécution prolongé** : Agent peut travailler de façon autonome jusqu&#39;à 200 minutes avec la Supervision en direct, idéal pour les projets d&#39;envergure. En savoir plus sur [Agent](/fr/pt/core-concepts/agent#max-autonomy).
* **Génération d&#39;agents** : créez des agents et des automatisations qui s&#39;exécutent selon une planification ou s&#39;intègrent à Slack et Telegram. Voir [Agents et automatisations](/fr/pt/core-concepts/agent/agents-and-automations).

<div id="conectores-e-integraes-de-app">
  ## Connecteurs et intégrations d&#39;app
</div>

Publiez plus rapidement grâce aux intégrations et connecteurs intégrés :

* **Géré par Replit** : des intégrations natives qui fonctionnent automatiquement dans vos apps.
* **Connectors** : des intégrations propriétaires auxquelles vous vous connectez une seule fois, puis que vous réutilisez dans toutes vos apps.
* **Intégrations externes** : des services tiers de confiance configurés par Agent à partir de vos clés d&#39;API.

<div id="agentes-e-automaes-beta">
  ## Agents et automatisations (bêta)
</div>

Créez des agents intelligents, des chatbots et des flux de travail automatisés dans le cadre d&#39;Agent 3 :

* **Agent Slack** : créez des Slackbots pour la recherche, les questions-réponses et l&#39;automatisation
* **Agent Telegram** : créez des bots pour la planification, l&#39;assistance et bien plus encore
* **Automatisation temporelle** : exécutez des flux de travail planifiés à intervalles réguliers
