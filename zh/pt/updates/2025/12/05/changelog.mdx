<div id="crie-apps-mobile-full-stack-com-o-agent">
  ### 使用 Agent 创建全栈移动应用
</div>

<Frame>
  <img src="/assets/mirror/cleanshot-2025-12-05-at-12-27-22-2x_273f89390642-dc03158b7d7f.png" width="1082" height="504" data-path="images/changelog/2025-12-05/cleanshot-2025-12-05-at-12-27-22-2x_273f89390642.png" />
</Frame>

Agent 现在可以创建搭载完整后端服务器的[移动应用](/zh/pt/replitai/building-mobile-apps)。这为你解锁了强大的功能，包括 [AI 集成](/zh/replitai/integrations)、[数据库](/zh/pt/features/data-and-storage/sql-database)、[对象存储](/zh/pt/features/data-and-storage/object-storage)和连接器——满足生产级移动应用开发的一切所需。

<div id="banco-de-dados-agora-disponvel-para-todos">
  ### 数据库现已向所有用户开放
</div>

全新的[数据库](/zh/pt/features/data-and-storage/sql-database)现已成为所有新 Replit Apps 的默认配置。此次更新提升了可靠性和基础设施控制能力，并为您的项目带来更优性能和更便捷的数据管理。

<div id="o-fast-mode-lida-com-mais-tarefas-de-forma-autnoma">
  ### Fast Mode 可自主处理更多任务
</div>

<Frame>
  <img src="/assets/mirror/image_4f661377d428-8454460e1cca.png" width="720" height="212" data-path="images/changelog/2025-12-05/image_4f661377d428.png" />
</Frame>

[Lite mode](/zh/pt/core-concepts/agent/agent-modes) (原 Fast Mode) 现在可自主处理更多任务，同时会针对较大改动推荐使用 Agent。通过快速迭代和无缝切换，更快地完成构建。

<div id="conecte-servios-de-terceiros-mais-rapidamente">
  ### 更快连接第三方服务
</div>

借助增强的连接器支持，更快连接第三方服务。只需提供配置，即可添加大多数基于 API 密钥的服务，无需复杂设置。支持多密钥配置和扩展的运行状况检查，让[集成](/zh/replitai/integrations)更加可靠。
