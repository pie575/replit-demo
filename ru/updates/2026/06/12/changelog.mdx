<div id="customize-agent-with-workspace-instructions-and-skills">
  ### Настройте Agent с помощью инструкций Workspace и навыков
</div>

Теперь достаточно один раз объяснить Agent, как работает ваша команда, — и он будет учитывать это во всех проектах. Задайте **пользовательские инструкции**, которым Agent будет следовать в каждом проекте, и создайте многоразовые **навыки**, которые Agent будет загружать по запросу для конкретных задач. Всем этим можно управлять в разделе **Workspace Settings** &gt; **Customization**.

<div id="block-malicious-packages-with-package-firewall">
  ### Блокируйте вредоносные пакеты с помощью брандмауэра пакетов
</div>

Replit теперь блокирует вредоносные и скомпрометированные пакеты ещё до того, как они попадут в ваше приложение. Брандмауэр пакетов проверяет каждую установку в популярных менеджерах пакетов и автоматически блокирует опасные зависимости. Он включён по умолчанию, а Agent корректирует свой план, используя более безопасные альтернативы, если что-то заблокировано.

</Frame>

  ### Ускоренный импорт и экспорт презентаций

<div id="add-visual-references-when-you-generate-media-on-canvas">
  ### Добавляйте визуальные референсы при создании медиа на Canvas
</div>

Теперь при создании изображения, видео или векторной графики на Canvas вы можете прикреплять в качестве визуальных референсов элементы с доски. Выберите фрейм, заметку или изображение — Agent использует их как ориентир, чтобы созданный медиафайл соответствовал стилю вашего проекта.

<Frame caption="Откройте меню + в форме создания медиа, чтобы загрузить файл или выбрать элементы Canvas.">
  <img src="/assets/mirror/canvas-generate-media-references-ac0cb4340acb.png" alt="Форма создания медиа на Canvas с открытым меню «плюс», в котором показаны параметры «Загрузить файл» и «Выбрать элементы Canvas», а в раскрывающемся списке моделей выбрана Nano Banana Pro" width="1134" height="662" data-path="images/replitai/canvas-generate-media-references.png" />
</Frame>

<Note>
  ChatGPT Images 2.0 пока не поддерживает загрузку файлов. Чтобы прикрепить визуальные референсы, переключите модель, например на Nano Banana Pro.
</Note>

<div id="choose-which-production-alerts-reach-your-inbox">
  ### Выберите, какие продакшен-оповещения будут приходить на вашу почту
</div>

Теперь вы можете управлять продакшен-оповещениями отдельно от других писем. Новый параметр **Production Alerts** определяет, будет ли Replit отправлять вам письма об инцидентах с доступностью, уязвимостях безопасности в ваших зависимостях и обновлениях языковых моделей. Если опубликованное приложение использует устаревшую модель, Replit также создаёт задачу в статусе черновика, чтобы вы могли обновить модель после одной проверки.

<Frame caption="Параметр Production Alerts находится в Settings → Personalization → Email.">
  <img src="/assets/mirror/production-alerts-settings-333bb4ee8a61.png" alt="Раздел Production Alerts в настройках уведомлений: переключатель писем с продакшен-оповещениями включён, а раскрывающийся список уровня критичности оповещений безопасности открыт" width="2000" height="899" data-path="images/editor/production-alerts-settings.png" />
</Frame>

Подробнее см. в разделе [настроек уведомлений](/ru/features/editor/user-settings#notifications).
