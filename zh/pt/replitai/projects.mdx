<div id="o-que-um-projeto">
  ## 什么是项目？
</div>

项目是你在 Replit 中构建所有内容的容器。它包含你的代码、数据以及创建的所有产物——Web 应用、移动应用、幻灯片演示文稿、数据仪表板和视频。当你告诉 Agent 你想要什么时，它会设置项目，并在其中构建产物。

你可以把项目想象成桌面上的工作区。所有内容都集中在一个地方，可以共享相同的信息，但每一部分都有不同的用途。

例如，如果你让 Agent 构建一个健身追踪应用，它会创建一个项目，其中包含移动应用产物，以及使其正常运行所需的后端、数据库和存储。

<ArtifactGrid />

核心概念：

* **项目**：包含所有内容的容器——你的代码、数据以及所有产物
* **产物**：项目中可发布的输出 (如 Web 应用、幻灯片演示文稿、视频等)
* **资源**：每个产物都会自动获得后端、数据库和文件存储，无需进行配置

<Note>
  部署会一次性部署整个项目。所有产物会同时上线，始终保持同步。
</Note>

| 类型                                            | 说明                          | 示例                 |
| --------------------------------------------- | --------------------------- | ------------------ |
| **[Web 应用](/zh/pt/replitai/web-apps)**           | 用户可通过浏览器访问的网站或 Web 应用       | 在线商店、预订工具、作品集网站    |

| **[数据可视化](/zh/pt/replitai/data-apps)**           | 包含图表、筛选器和实时数据的交互式仪表板        | 销售报告、指标追踪器、分析视图    |
| **[幻灯片演示文稿](/zh/pt/replitai/slide-decks)**       | 可展示或导出的演示文稿                 | 路演演示文稿、团队更新、产品概览   |
| **[动画](/zh/pt/replitai/animated-videos)**        | 可导出为 MP4 的动态图形视频            | 产品发布视频、说明视频、社交媒体内容 |
| **3D 游戏**                                     | 3D 游戏、模拟或交互式体验              | 解谜游戏、物理模拟、交互式体验    |
| **[Design](/zh/pt/replitai/canvas)**             | 在 Design Canvas 中探索的视觉方案和原型 | 情绪板、模型稿、设计探索       |

一个项目可以包含多个产物。例如，您可以为客户构建 Web 应用、为团队构建移动应用，并为投资者创建幻灯片演示文稿——所有内容都位于同一项目中。当产物位于同一项目中时，它们会自动共享数据和后端逻辑。要了解更多信息，请参阅[产物](/zh/pt/replitai/artifacts#multiple-artifacts-in-one-project)。

<div id="gerenciando-seus-projetos">
  ## 管理项目
</div>

“项目”页面会列出您创建或受邀加入的所有项目。在繁忙的 workspace 中，您可以通过此页面快速返回最近处理的工作，并找到所需项目。

<div id="veja-rapidamente-o-que-h-em-cada-projeto">
  ### 快速了解每个项目包含的内容
</div>

每张项目卡片都会显示其所含产物的小图标——项目中的每个 Web 应用、移动应用、幻灯片演示文稿、数据可视化或动画都有对应图标。将鼠标悬停在任意图标上，即可直接在卡片中预览该产物的截图，无需打开项目即可轻松区分不同项目。

<div id="filtre-por-artefato">
  ### 按产物筛选
</div>

使用项目页面顶部的 **构建类型** 下拉菜单，按产物筛选项目列表。选择一种类型，即可仅查看包含该类型产物的项目：

* **Web** — 包含 Web 应用的项目
* **Mobile** — 包含移动应用的项目
* **Data** — 包含数据可视化内容的项目
* **Slides** — 包含幻灯片演示文稿的项目
* **Design** — 处于 Design 模式的项目
* **3D 游戏**、**Agent 和自动化**等

选择 **任何构建类型** 可清除筛选器。

<div id="ordene-por-ltima-abertura">
  ### 按最后打开时间排序
</div>

默认情况下，“项目”页面会按**你最后打开的时间**排序——你最近花费时间最多的项目会显示在最上方。这在团队 workspace 中尤其有用，否则其他成员最近的编辑可能会淹没你当前的工作。

你可以选择其他列标题来更改排序方式 (例如，**最后更新**或**名称**) 。

<div id="fixe-os-projetos-que-voc-mais-usa">
  ### 固定常用项目
</div>

固定项目后，它会显示在列表顶部。固定项目**仅对你自己可见**——在团队 workspace 中固定项目不会影响其他成员看到的内容。

要固定项目，请打开项目卡片上的选项菜单 (三个点) ，然后选择**固定**。如需取消固定，请在同一菜单中选择**取消固定**。
