<div id="agent-2">
  ### Новое выпадающее меню режимов Agent
</div>

Селектор режимов Agent в поле ввода чата теперь представлен простым сегментированным переключателем. На панели инструментов можно переключаться между Lite, Economy и Power, а Turbo при необходимости доступен в расширенных настройках.

Новое:

* **Сегментированный переключатель на панели инструментов.** Lite, Economy и Power отображаются рядом, поэтому текущий режим и способ переключения между режимами понятны с первого взгляда.
* **Сочетание клавиш.** Нажмите **⌘+Shift+I** (Ctrl+Shift+I в Windows), чтобы переключать режимы без мыши.
* **Turbo выделен оранжевым цветом.** Turbo — самый быстрый режим, но он стоит дороже, поэтому в UI он выделен, чтобы было проще оценить компромисс между скоростью и стоимостью.
* **Расширенные настройки свернуты по умолчанию.** Настройки тестирования, проверки кода и Turbo скрыты в разделе Advanced settings, чтобы основной интерфейс оставался лаконичным.
* **Режим Max упразднён.** Для наиболее ресурсоёмких задач используйте Power, а если вам нужны самые быстрые ответы, включите Turbo в расширенных настройках.

<div id="agent-3">
  ### Agent предлагает дальнейшие задачи
</div>

<Frame>
  <video autoPlay muted loop playsInline src="/assets/mirror/replit-suggested-tasks-b27620d93fd2.mp4" />
</Frame>

После завершения работы Agent использует весь контекст проекта, чтобы предложить **дальнейшие задачи** — то, что стоит создать следующим. Под каждой выполненной задачей отображаются три типа предложений:

* **Новые функции** — функции, которые естественно дополняют только что выпущенное
* **Улучшения производительности** — оптимизации, которые Agent заметил во время работы над задачей
* **Улучшения пользовательского опыта** — доработки, которые делают функции более продуманными

Просмотрите предложения и выберите **Одобрить** для нужных, чтобы Agent мог продолжить сборку, выполняя их в фоновом режиме. Ненужные предложения можно скрыть с помощью **Скрыть предложенные задачи** в столбце Done и вернуть в любой момент.

Подробнее см. в разделе [Предложение дальнейших задач](/ru/ja/features/agent/follow-up-tasks).

<div id="section-3">
  ### Улучшения страницы проектов
</div>

На странице проектов появились три улучшения:

* **Предпросмотр артефактов на всех карточках.** На каждой карточке проекта теперь отображаются небольшие значки всех содержащихся в нём артефактов. Наведите курсор на значок, чтобы просмотреть снимок экрана артефакта, не открывая проект.
* **Сортировка по времени последнего открытия по умолчанию.** Теперь в верхней части страницы отображаются проекты, над которыми *вы* недавно работали, чтобы текущая работа оставалась на виду даже в загруженных командных рабочих пространствах.
* **Личное закрепление.** Вы можете закреплять проекты, к которым часто возвращаетесь. Закреплённые проекты видны только вам и не влияют на то, что видят другие участники рабочего пространства.

<div id="scim">
  ### Пользовательские группы для SCIM-организаций
</div>

Organization с включённым SCIM-провижинингом теперь могут создавать в Replit пользовательские группы наряду с группами, синхронизируемыми с IdP. Используйте пользовательские группы для доступа к проектам, разового предоставления прав или структур, не отражённых в поставщике удостоверений.

Группы, синхронизируемые через SCIM, по-прежнему управляются через поставщика удостоверений, а пользовательскими группами напрямую в Replit управляют администраторы Organization.

Подробнее см. в разделе [SCIM](/ru/ja/teams/identity-and-access-management/scim#creating-custom-groups-alongside-scim).
