有了 [Replit 移动应用](https://replit.com/mobile)，你可以把项目装进口袋。无论身在何处，都能接着上次的进度继续，或从零开始构建新项目。借助为触控优化的界面，你可以与 Agent 对话、编辑项目，并将其部署到 Web 上。

<div id="section">
  ## 开始使用
</div>

请按照以下步骤安装应用并创建项目。

<div id="section-2">
  ### 安装应用
</div>

1. 前往[移动应用下载页面](https://replit.com/mobile)，安装适用于你所用移动设备操作系统的应用。
2. 打开应用，注册新账户或使用现有账户登录。
   如果注册新账户，需要验证邮箱地址才能完成注册流程。

<div id="section-3">
  ### 开始构建
</div>

主屏幕提供以下两种方式：

* **接着上次继续**：在 **Recent Projects** 下打开 项目 继续操作。
* **从零开始构建**：在提示框中描述你想做的东西并发送，Agent 会立即开始构建 项目。

如果想改为从现有模板或代码开始，请点按右上角的 ⋮，然后选择 **Remix a Template** 或 **Import from GitHub**。

<Note>
  如果要创建原生 iOS 应用，请在 [replit.com](https://replit.com) 上使用 Project Editor 进行创建、预览、构建或提交。在受支持的情况下，也可以在 Replit Android 应用中处理原生移动应用相关工作。
</Note>

<div id="section-5">
  ## 移动端功能
</div>

<div id="section-6">
  ### 语音输入
</div>

使用 Agent 提示框中的语音选项，你无需动手打字，直接口述想要构建的内容或需要修改的地方即可。

<div id="section-7">
  ### 实时活动
</div>

随时随地查看 Agent 的进度。Agent 启动后会弹出通知，在锁定屏幕上点按 **Allow**。此后无需打开 Replit 即可查看进度。

<Accordion title="支持的设备">
  * 搭载 iOS 18 或更高版本的 iPhone
  * 搭载 iOS 18 或更高版本的 iPad
  * 搭载 macOS Tahoe 或更高版本的 Mac
  * 已配对的 Apple Watch
</Accordion>

<div id="section-8">
  ### 通知
</div>

无论身在何处，都能及时收到重要更新。打开 **Settings**，再进入 **Notifications** (通常位于 **User** 下) 。确认 Notifications 已开启，并在出现提示时点按“允许”。

在以下情况下，Replit 会通知你：

* Agent 需要你的协助时
* Agent 完成工作时
* 有重要的账单更新时

<div id="section-9">
  ### 平板键盘模式
</div>

将键盘连接到平板电脑，即可获得针对大屏幕优化的创作体验。连接键盘后首次打开 Project Editor 时，系统会询问你是否启用该模式。

你可以随时前往 **Account** &gt; **Keyboard Settings** 开启或关闭该模式。

<div id="section-10">
  ## 升级与账单
</div>

要在应用内升级到 Core，请前往 **Account**，点按 **Upgrade**，选择方案后点按 **Continue with Core**。Pro 不支持在移动应用中购买，需前往 [replit.com](https://replit.com) 购买。

如果 Agent 用量超出订阅包含的额度，请添加[按用量计费](/zh/ja/billing/about-usage-based-billing)的支付方式：

* **在网页端**：前往 replit.com，打开 **Settings** → **Account** → **Billing**。
* **在应用内 (仅限美国 iOS)&#x20;**：打开 **Settings** → **Billing** (或 **Account** → **Billing**) 。
