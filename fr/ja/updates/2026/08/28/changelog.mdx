  ## Agent

<div id="section-2">
  ### Routage intelligent des modèles
</div>

Le routage intelligent des modèles sélectionne automatiquement le modèle et le niveau d&#39;Effort les mieux adaptés à la tâche, tout en trouvant le bon équilibre entre qualité et coût. Lorsque vous choisissez **Auto** avec **Power** ou **Max**, Replit oriente chaque partie du travail selon l&#39;évolution de sa complexité. Si vous souhaitez un contrôle plus fin, vous pouvez aussi sélectionner un modèle et un niveau d&#39;Effort précis.

<div id="growth-skills">
  ### Trouvez vos premiers clients grâce aux Growth Skills
</div>

Exécutez les [Growth Skills](https://replit.com/growth-kit) dans Agent pour trouver les premiers clients de votre application. Les intégrations partenaires disponibles comprennent Apollo, Clay, SideShift, RevenueCat, Stripe et PostHog.

<div id="enterprise">
  ### Routage intelligent des modèles pour Enterprise
</div>

Le routage intelligent des modèles devient le mode Agent par défaut dans les espaces de travail Enterprise. Lorsque le mode **Auto mode** est activé, Replit sélectionne le mode et le modèle autorisé les mieux adaptés à chaque tâche. Les administrateurs de compte peuvent gérer la disponibilité des modèles espace de travail par espace de travail, et désactiver le **Auto mode** pour choisir manuellement un modèle activé. Le menu des modes Agent d&#39;Enterprise propose désormais **Power** et **Max**, et n&#39;inclut plus **Lite**.

<Frame caption="Lorsque le Auto mode est activé, Replit sélectionne le mode et le modèle les mieux adaptés à chaque tâche.">

  ### Personnaliser les connecteurs
</div>

Les organisations Enterprise peuvent désormais utiliser une configuration OAuth personnalisée pour leurs connecteurs. Vous pouvez par exemple configurer Gmail avec vos propres **Client ID**, **Client Secret** et **scopes**, plutôt qu&#39;avec les valeurs par défaut de Replit.

</Frame>
