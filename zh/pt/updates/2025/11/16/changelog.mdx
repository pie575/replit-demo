<div id="integrao-com-o-azure-marketplace">
  ### Azure Marketplace 集成
</div>

Replit 现已上架 Azure Marketplace！许多组织已有专门的 Azure 预算，借助此项集成，即可直接用这些资金支付 Replit 的订阅与用量费用。

继 9 月接入 GCP Marketplace 之后，此次上架让 Enterprise 团队能更轻松地沿用现有的云采购流程与预算引入 Replit。

[在 Azure Marketplace 中查看](https://marketplace.microsoft.com/en-us/product/saas/replit.replit?tab=Overview)

<div id="suporte-ao-gitlab-e-bitbucket">
  ### 支持 GitLab 和 Bitbucket
</div>

除 GitHub 外，Replit 现已支持 GitLab 和 Bitbucket 仓库，让你在代码存放位置上有更多选择。你可以将 GitLab 和 Bitbucket 上的项目直接导入 Replit，同时所有受支持的平台都获得了更强的 Git 功能。

增强后的 Git 集成包括：

* **多平台支持**：导入并使用 GitHub、GitLab 和 Bitbucket 上的仓库
* **更强的 Git 操作**：整个 workspace 中的 Git 命令更快、更可靠
* **更完善的仓库管理**：简化了从任意受支持的 Git 提供方克隆、推送和拉取的流程

进一步了解[导入项目](/zh/pt/core-concepts/project-editor/app-setup/import)和[在 Replit 中使用 Git](/zh/pt/core-concepts/project-editor/version-control/git-interface)。
