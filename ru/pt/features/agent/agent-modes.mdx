Режимы Agent позволяют находить баланс между стоимостью и возможностями при работе с Agent. В выпадающем меню настроек Agent выберите **Free Mode**, **Power Mode** или **Max Mode**. Free Mode всегда использует интеллектуальную маршрутизацию моделей. В режимах Power и Max создатели на планах Core и Pro могут выбрать **Auto**, чтобы Replit подбирал модель под каждую задачу. Также можно выбрать модель вручную через [Model selector](/ru/features/agent/model-selector). Набор доступных режимов и настроек зависит от вашего плана и workspace.

<Note>
  Economy Mode больше не доступен. Его заменил Power Mode по той же цене.
</Note>

<Tip>
  **Сочетание клавиш:** нажмите **⌘+Shift+I** (Ctrl+Shift+I в Windows), чтобы
  переключаться между режимами Agent, не покидая поле ввода чата.
</Tip>

<div id="free-mode">
  ## Free Mode
</div>

**Оптимизирован для первых шагов.** Free Mode помогает пробовать идеи, разбираться в том, как работает Replit, и начать project.

**Учтите:** Free Mode всегда использует интеллектуальную маршрутизацию моделей. Чтобы выбрать модель вручную, используйте Power Mode или Max Mode.

<Note>
  {FreeModePlanAvailability} Когда вы достигнете лимита своего тарифного плана, Replit
  покажет, когда он обновится.
</Note>

Routines не выполняются в Free Mode. Они работают в Power или Max Mode и требуют бюджета на каждый запуск. Подробнее о [Routines](/ru/chat/routines).

<div id="intelligent-model-routing-auto">
  ## Интеллектуальная маршрутизация моделей (Auto)
</div>

**Оптимизировано для автоматического выбора модели.** В режиме Power или Max пользователи планов Core и Pro могут выбрать **Auto**. После этого Replit для каждой задачи подбирает модель в пределах возможностей выбранного режима. См. [Использование интеллектуальной маршрутизации моделей](/ru/chat/auto-mode).

Auto — это платная альтернатива Free Mode. Как и другая работа в режимах Power и Max, он расходует кредиты подписки.

В workspace на плане Enterprise вместо Free Mode используется единый режим **Auto**. В Enterprise режим Auto может выбирать для каждой задачи и режим, и разрешённую модель.

<div id="power-mode">
  ## Power Mode
</div>

**Оптимизирован по стоимости.** Power Mode тратит меньше кредитов на задачу и служит лучшим вариантом по умолчанию, когда нужен хороший результат без переплаты за самые мощные модели.

**Лучше всего подходит для:** повседневной разработки, обучения и экономной работы в рамках существующего проекта.

<div id="max-mode">
  ## Max Mode
</div>

**Ориентирован на возможности.** Max Mode использует более мощные модели для сложных задач, крупных кодовых баз и трудных проблем.

**Лучше всего подходит для:** проектов production-уровня, сложных функций и случаев, когда от Agent нужен наилучший результат.

<div id="which-mode-should-i-use">
  ## Какой режим выбрать?
</div>

Ориентируйтесь на следующую таблицу:

| Цель                                                          | Рекомендуемый режим                                                              |
| ------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| Опробовать идеи, разобраться в работе Replit и начать project | Free Mode                                                                        |
| Доверить Replit выбор модели для платной работы               | Auto в Power Mode или Max Mode                                                   |
| Получить максимум prompt на один кредит                       | Power Mode                                                                       |
| Сбалансировать стоимость и качество для большинства projects  | Power Mode                                                                       |
| Выбрать модель вручную                                        | Power Mode или Max Mode                                                          |
| Лучший результат в сложных задачах продакшен-уровня           | Max Mode                                                                         |
| Максимально возможный результат в самых сложных задачах       | Max Mode с более высоким уровнем [Effort](/ru/features/agent/model-selector#effort) |

Чтобы выбрать режим, откройте выпадающее меню настроек Agent в поле ввода чата. В Power или Max создатели на планах Core и Pro могут использовать Auto либо задать [основную модель и Effort](/ru/features/agent/model-selector). Универсально лучшего режима не существует — выбирайте тот, который подходит для текущей задачи.

<div id="settings-in-shared-projects">
  ## Настройки в общих проектах
</div>

Настройки Agent привязаны к вам, а не к проекту. Когда вы приглашаете коллегу в проект, каждый из вас сохраняет собственный выбор для:

* режима (Free Mode, Power Mode или Max Mode);
* [основной модели и Effort](/ru/features/agent/model-selector), если доступно;
* [Plan Mode](/ru/features/agent/plan-mode);
* автоматического слияния фоновых задач;
* автоматического одобрения планов.

Если коллега переключится на Max Mode для своей следующей задачи, ваши настройки на Max Mode не переключатся. Режим и настройки, которые вы видите в выпадающем меню настроек Agent, — это именно те, которые Agent применит при отправке вашего следующего сообщения, независимо от того, сколько соавторов работает над проектом.

<div id="check-your-free-mode-usage">
  ## Проверьте использование Free Mode
</div>

Откройте **Settings** → **Usage**, чтобы посмотреть текущий лимит Free Mode и время его сброса. Практические рекомендации см. в статье [Как получить максимум от Free Mode](/ru/chat/free-mode).
