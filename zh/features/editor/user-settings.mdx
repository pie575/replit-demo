User Settings 是 Project Editor 中的一款工具，可用于自定义账户的外观、行为和键盘快捷键。

</Frame>

<div id="features">
  ## 功能
</div>

你可以通过以下几类设置来定制 Replit App 的创建体验：

* **主题定制**：为 Project Editor 选择浅色或深色主题
* **代码智能**：配置由 AI 驱动的功能，提升应用创建体验
* **编辑器偏好设置**：调整文件编辑器的行为和外观
* **通知控制**：管理提醒偏好
* **无障碍选项**：让 Replit 更好地满足有特殊需求的用户
* **键盘快捷键**：设置按键组合，快速执行常用操作并在图形界面中导航

<div id="usage">
  ## 使用方法
</div>

<Accordion title="如何打开用户设置">
  从左侧的 **工具栏**：

  1. 选择 <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="All tools icon" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **所有工具**，查看 Project Editor 的工具列表。
  2. 选择 <img class="icon-svg" src="/assets/mirror/settings-icon-c2664c3691bf.svg" alt="Settings icon" width="16" height="16" data-path="images/icons/settings-icon.svg" /> **用户设置**。

  从 **搜索栏**：

  1. 选择顶部的 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="magnifying glass icon" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 放大镜图标，打开搜索工具
  2. 输入&quot;User Settings&quot;找到该工具，然后从结果中选择。
</Accordion>

<div id="appearance">
  ### 外观
</div>

自定义以下与 Project Editor 外观相关的设置：

* **主题选择**：可选择浅色和深色预设主题、<a href="https://replit.com/themes" target="_blank">社区主题</a>或你的自定义主题
* **自定义主题**：使用 [Themes](/zh/features/editor/themes) 编辑器创建个性化配色方案

<div id="file-editor-preferences">
  ### 文件编辑器偏好设置
</div>

使用以下设置控制文件编辑器的外观和行为：

* **Font size**：调整文字大小以提升可读性
* **Auto close brackets**：输入左括号时自动补全右括号
* **Indentation detection**：打开文件时自动检测缩进设置
* **Format pasted text indentation**：重新格式化粘贴的代码，使其缩进正确
* **Indentation character**：选择使用空格还是制表符缩进代码
* **Indentation size**：设置每级缩进的列数
* **Wrapping**：配置自动换行行为
* **Minimap**：在侧边栏中显示可导航的代码缩略图
* **Multiselect modifier key**：设置多文件选择使用的键盘修饰键
* **Filetree Git status**：在文件树中显示 Git 状态标识

<div id="code-intelligence">
  ### 代码智能
</div>

通过以下设置配置 AI 驱动的工具：

* **语义标记**：启用由语言服务器提供支持的增强语法高亮
* **AI 代码补全**：在输入时显示内联代码建议
* **在提交字符处接受建议**：输入特定字符时自动采纳代码建议

<div id="shell-and-preview-preferences">
  ### Shell 和 Preview 偏好设置
</div>

自定义 Shell 和 Preview 工具的行为：

* **Shell 提示音**：Shell 工具出现问题时播放提示音
* **自动预览**：服务器就绪后自动打开 Preview 标签页
* **自动转发已打开的端口**：设置新检测到的端口的处理方式

<div id="notifications">
  ### 通知
</div>

管理以下通知设置：

* **Agent 声音通知**：当 Agent 需要你提供反馈时播放提示音
* **Agent 推送通知**：当 Agent 需要你提供反馈时，向手机发送推送通知

<div id="production-alerts">
  #### 生产环境告警
</div>

**Production Alerts** (生产环境告警) 是一项独立的邮件通知设置，让你随时掌握已发布应用的运行状况。它与产品邮件和营销邮件互不影响，因此你只会收到真正重要的信息，不会被无关内容打扰。

开启 **Production Alerts** 后，你将收到以下邮件：

* **uptime 事件**：已发布应用出现宕机或难以保持在线时，你会收到通知。
* **安全漏洞**：应用所依赖的软件中发现漏洞时，你会收到通知，以便在问题发生前及时修复。
* **模型更新**：应用使用的语言模型发生变更或需要你处理时，你会收到通知。

  <img src="/assets/mirror/production-alerts-highlight-bb76079f20fd.png" alt="通知设置中的 Production Alerts 部分，红色矩形突出显示生产环境告警邮件开关和安全告警严重级别下拉菜单" width="2400" height="1364" data-path="images/workspace/production-alerts-highlight.png" />

查找该设置的方法：

1. 从账户菜单中打开 **Settings**。
2. 选择 **Personalization** 选项卡。
3. 向下滚动到 **Email Notifications** 部分，找到 **Production Alerts**。

当已发布应用使用了过时的语言模型时，Replit 会为你准备一个任务草稿，将其升级到受支持的模型。你会收到一封包含该任务链接的邮件，只需一次审阅即可完成升级。

<div id="accessibility">
  ### 无障碍

你可以自定义以下无障碍设置：

* **无障碍终端输出**：为 Shell 和 Console 工具启用屏幕阅读器兼容支持

<div id="keyboard-shortcuts">
  ### 键盘快捷键
</div>

要访问键盘快捷键偏好设置，请在“用户设置”工具中选择 **Keyboard shortcuts** 选项卡。

你可以通过以下方式搜索按键组合：

* **名称**：在搜索框中输入键盘快捷键的名称或描述
* **按键组合**：选择 <img class="icon-svg" src="/assets/mirror/keyboard-7ba19771b671.svg" alt="keyboard icon" width="16" height="16" data-path="images/icons/keyboard.svg" /> 键盘图标并输入按键组合

可通过以下操作管理快捷键：

* **添加**：选择 **Add shortcut**
* **更新**：选择 <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="pencil icon" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> 铅笔图标
* **删除**：选择 <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="trash icon" width="16" height="16" data-path="images/icons/trash-icon.svg" /> 垃圾桶图标
