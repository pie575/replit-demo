Создайте дашборд в реальном времени с ключевыми показателями API, диаграммами и фильтрами. Он автоматически обновляется,
поддерживает экспорт и отображает только реально существующие данные. Данные, которые нужно сохранять,
храните в Replit Database.

<div id="section">
  ## Подходит в следующих случаях
</div>

* Продакт-менеджерам, которым нужен дашборд для совместного просмотра, а не снимок экрана.
* Руководителям операционных и аналитических команд, которым нужен закрытый дашборд с всегда актуальными данными из API.

<div id="section-2">
  ## Перед началом
</div>

Заранее определите, какие решения должен помогать принимать дашборд. Подготовьте URL API или используйте приведённые ниже эндпоинты DummyJSON.

<Info>
  Для тестирования можно использовать следующие бесплатные API-эндпоинты DummyJSON.

  * Заказы: `https://dummyjson.com/carts?limit=0`
  * Клиенты: `https://dummyjson.com/users?limit=0`
  * Каталог: `https://dummyjson.com/products?limit=0`
  * Категории: `https://dummyjson.com/products/categories`
</Info>

<div id="section-3">
  ## Ожидаемый результат
</div>

Agent загружает данные, выбирает ключевые показатели и диаграммы, а также добавляет фильтры. Сверьте хотя бы
одно число с исходным источником. Если вы использовали DummyJSON, выберите один заказ, откройте
`https://dummyjson.com/carts/{id}` и убедитесь, что итоговая сумма совпадает. Переключите фильтры
и убедитесь, что все карточки и диаграммы обновляются. Выполните экспорт и сверьте одну строку с API,
чтобы убедиться, что данные верны.

<div id="section-5">
  ## Устранение неполадок
</div>

* **API недоступен или работает некорректно:** Проверьте URL и убедитесь, что ответ содержит ожидаемые поля. Для быстрой проверки используйте указанный выше эндпоинт DummyJSON.
* **Числа выглядят не так, как ожидалось:** Попросите Agent показать запрос или процесс преобразования, затем сверьте хотя бы одно число с исходным источником.
* **Фильтр не обновляет диаграмму:** Попросите Agent связать каждый фильтр со сводными карточками и данными диаграммы. Если дашборд работает медленно, кэшируйте ответы API или уменьшите количество записей, загружаемых при запуске.
