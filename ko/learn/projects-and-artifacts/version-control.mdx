Replit의 버전 관리를 활용하면 코드베이스를 안심하고 추적하고 관리하며 협업할 수 있습니다. 기본 제공되는 Git 연동과 GitHub 연결을 통해 다음과 같은 작업을 할 수 있습니다.

* 코드 변경 사항을 추적하고 개발 작업 히스토리를 유지
* 코드 충돌이나 작업 손실 없이 팀원과 협업
* Replit과 GitHub 사이에서 코드를 가져오고, 수정하고, push
* 브랜치를 활용해 새로운 기능을 안전하게 실험

<div id="what-is-version-control">
  ## version control이란?
</div>

version control은 시간에 따른 파일 변경 사항을 기록해 두었다가 나중에 특정 버전을 다시 불러올 수 있게 해주는 시스템입니다. Replit의 version control은 코드 변경 사항 추적의 업계 표준 도구인 Git을 기반으로 하며, 명령줄 지식 없이도 사용할 수 있는 직관적인 시각적 인터페이스를 제공합니다.

<div id="how-version-control-works-on-replit">
  ### Replit에서 version control이 작동하는 방식
</div>

네 가지 version control 옵션은 모두 동일한 Git 저장소를 기반으로 동작합니다:

1. **Agent Checkpoints**는 [Replit Agent](/ko/features/agent/overview)로 building할 때 주요 마일스톤마다 자동으로 commit을 생성합니다. [checkpoints와 rollback에 대해 자세히 알아보기](/ko/features/version-control/checkpoints-and-rollbacks).
2. **Git Pane**은 전체 Git 저장소를 시각적으로 다룰 수 있는 환경을 제공합니다
3. **Git CLI**는 모든 Git 기능을 명령줄에서 사용할 수 있게 해줍니다
4. **File History**는 개별 파일 내의 granular한 changes를 추적합니다

필요에 가장 잘 맞는 인터페이스를 선택하세요. 어떤 방식을 택하든 모든 작업은 Git의 견고한 version control 시스템이 뒷받침합니다.

| 기능              | Agent Checkpoints | Git Commits       | File History   |
| --------------- | ----------------- | ----------------- | -------------- |
| **생성 방식**       | 논리적 지점에서 자동       | 수동 또는 schedule 기반 | 자동             |
| **세분화 수준**      | 기능 단위 changes     | 크기 제한 없는 change   | 문자 단위 changes  |
| **설명**          | AI가 생성한 요약        | User가 작성한 메시지     | 자동 타임스탬프       |
| **Rollback**    | 원클릭 복원            | Git 지식 필요         | 원클릭 복원         |
| **Git 기능**      | 전체 Git 기능         | 전체 Git 기능         | Git 기능 없음      |
| **GitHub sync** | 전체 GitHub sync 기능 | 전체 GitHub sync 기능 | GitHub sync 없음 |

<div id="getting-started">
  ## 시작하기
</div>

Project Editor에 Git 도구를 추가하면 Replit App에서 버전 관리를 사용할 수 있습니다:

1. Replit App의 Tools 섹션으로 이동합니다
2. **+** 기호를 선택해 새 도구를 추가합니다
3. 사용 가능한 도구 목록에서 **Git**을 선택합니다

GitHub에 있는 기존 프로젝트를 가져오려면 [GitHub에서 가져오기](/ko/build/import-from-providers)를 참고하세요.

<div id="automatic-version-control">
  ### 자동 버전 관리
</div>

<Accordion title="Agent Checkpoints">
  [Replit Agent](/ko/features/agent/overview)로 AI 기반 개발을 진행하는 동안 자동으로 생성되는 스냅샷입니다.

  **가장 적합한 경우**: Replit Agent를 사용한 개발

  **주요 기능**:

  * 주요 단계마다 자동 생성
  * 원클릭 롤백
  * 기능 단위 스냅샷
  * 진행 상황 추적
  * 별도 설정 불필요
  * 개발 진행 상황을 보여주는 시각적 타임라인

  Agent 체크포인트는 Git에 저장되며 Git Pane 또는 Git CLI를 통해 접근할 수 있습니다. History 기능을 사용하면 모든 체크포인트를 한눈에 확인할 수 있으며, 다음과 같은 기능을 제공합니다:

  * 시간순 체크포인트 시각화
  * 상세한 체크포인트 설명
  * 체크포인트 상태에 바로 접근
  * 원하는 체크포인트로 원클릭 롤백
</Accordion>

<Accordion title="File History">
  에디터에서 직접 수행한 Agent 외 변경 사항을 자동으로 저장하는 파일별 버전 추적 기능입니다.

  **가장 적합한 경우**: 최근 파일 변경 사항의 빠른 복구

  **주요 기능**:

  * 단일 파일 중심
  * 문자 단위 변경 사항
  * 시각적 비교
  * 30일간의 기록
  * 재생 기능

  File History는 자체 인터페이스를 제공하지만, 그 기반이 되는 변경 사항은 Git 기록의 일부입니다. [File History](/ko/features/version-control/file-history)에 대해 자세히 알아보세요.
</Accordion>

<div id="key-features">
  ## 주요 기능
</div>

* **시각적 Git 인터페이스**: Git 명령어를 입력하지 않고도 저장소, commit, 브랜치를 관리합니다
* **GitHub integration**: 백업과 협업을 위해 GitHub 저장소에 연결합니다
* **GitHub에서 가져오기**: 몇 번의 클릭만으로 [GitHub 저장소를 Replit App으로](/ko/build/import-from-providers) 전환합니다
* **브랜치 관리**: Project Editor에서 바로 브랜치를 생성하고 전환하며 merge합니다
* **충돌 해결**: 시각적인 도움을 받아 merge 충돌을 확인하고 해결합니다

<div id="use-cases">
  ## 활용 사례
</div>

**개인 프로젝트 추적하기**

개발하면서 코드 변경 사항을 추적하고, 필요할 때 이전 버전으로 되돌릴 수 있습니다. [Git pane](/ko/features/workspace-tools/git-interface)에서 변경 사항을 시각적으로 확인할 수 있어 의미 있는 업데이트를 손쉽게 커밋할 수 있습니다.

**팀과 협업하기**

여러 개발자가 동일한 코드베이스에서 서로의 변경 사항을 덮어쓰지 않고 함께 작업할 수 있습니다. 새로운 기능을 위한 브랜치를 만들고, 준비가 되면 다시 병합하세요. [팀원 초대하기](/ko/build/invite-teammates)에서 자세히 알아보세요.

<div id="agent-checkpoints">
  ## Agent checkpoints
</div>

[Replit Agent](/ko/features/agent/overview)로 애플리케이션을 빌드할 때는 checkpoints를 통해 한 단계 더 강화된 version control 계층을 활용할 수 있습니다. Checkpoints는 AI 지원 개발 과정의 주요 시점마다 project 콘텐츠, AI conversation context, 연결된 database를 비롯한 project의 전체 상태를 자동으로 캡처합니다.

<Frame>
  <img src="/assets/mirror/checkpoints-9927e500693a.jpg" alt="Git pane의 Agent checkpoints" width="1920" height="1080" data-path="images/workspace/checkpoints.jpg" />
</Frame>

<div id="how-checkpoints-work">
  ### checkpoint 작동 방식
</div>

Agent checkpoint는 Replit App의 전체 상태를 포괄적으로 담은 스냅샷 역할을 합니다.

* **자동 생성**: Agent는 개발 과정에서 적절한 시점마다 checkpoint를 생성합니다
* **전체 상태 저장**: 각 checkpoint에는 project 콘텐츠, AI 메모리, database 상태가 함께 보존됩니다
* **구현 계획**: 변경을 적용하기 전에 Agent가 검토용 계획을 먼저 제시합니다
* **복잡한 task 추적**: 규모가 큰 task에서는 여러 개의 checkpoint가 생성될 수 있습니다

<div id="benefits-for-ai-assisted-development">
  ### AI 기반 개발의 이점
</div>

Agent checkpoints는 AI로 앱을 만들 때 다음과 같은 고유한 장점을 제공합니다:

* **안전망**: 전체 개발 환경에서 이전 상태를 손쉽게 복원할 수 있으므로 마음 놓고 실험할 수 있습니다
* **진행 상황 추적**: Agent가 애플리케이션을 단계별로 어떻게 만들었는지 정확히 확인할 수 있습니다
* **논리적 마일스톤**: checkpoints는 임의의 저장 지점이 아니라 완성된 기능 단위를 나타냅니다
* **즉각적인 rollback**: 클릭 한 번으로 이전 상태로 되돌아갈 수 있으며, database와 AI context까지 복원됩니다

<Info>
  checkpoints가 저장하는 내용과 rollback 기능 전반에 대한 자세한 내용은 [Checkpoints and Rollbacks](/ko/features/version-control/checkpoints-and-rollbacks)를 참조하세요.
</Info>

<Tip>
  Agent checkpoints는 AI를 활용한 개발에 매우 유용하지만, 장기적인 버전 추적과 협업, 특히 외부 저장소와 함께 작업할 때는 Git commit 사용을 고려하세요.
</Tip>
