把你的应用变成一门生意。Replit 已与各类支付服务商集成，让你能够收取付款、销售订阅，为你的网页和移动应用实现变现。

<div id="how-it-works">
  ## 工作原理
</div>

告诉 Agent 你想对什么收费，剩下的交给它：连接支付服务商、构建结账或付费墙界面、接入支付逻辑。正式上线前，你可以安全地测试所有环节。

Replit 为网页应用和原生移动应用提供多种变现集成：

* **[Whop 支付](/zh/features/monetization/whop-payments)** (网页应用) ：用最少的步骤销售数字产品、会员和订阅。Agent 会为你创建 Whop 账户——无需外部设置，也无需 API 密钥——助你快速完成第一笔销售。
* **[Stripe 支付](/zh/features/monetization/stripe-payments)** (网页应用) ：收取一次性付款、销售订阅，或搭建完整的店面。Agent 会连接 Stripe 沙盒，让你在上线前测试结账流程。
* **[RevenueCat 订阅](/zh/features/monetization/revenuecat-subscriptions)** (移动应用) ：为你的原生移动应用添加应用内订阅。Agent 会配置 RevenueCat、构建付费墙页面，并启用测试模式，让开发期间的购买行为均为模拟。

如果你想销售涉及库存和履约的实物商品，请参阅 [Shopify 集成](/zh/features/integrations/shopify)。

<div id="choose-the-right-integration">
  ## 选择合适的集成
</div>

|          | Whop              | Stripe              | Shopify              | RevenueCat                     |
| -------- | :---------------- | :------------------ | :------------------- | :----------------------------- |
| **最适合**  | 步骤最少，最快达成首单       | 网页端的灵活性与规模化         | 实体商品                 | 原生移动应用                         |
| **支付类型** | 数字产品、会员、订阅        | 一次性付款、订阅、店面         | 含库存与履约的实体商品          | 应用内订阅                          |
| **外部设置** | 起步无需设置            | 起步无需设置 (Stripe 沙盒)  | 起步无需设置               | 起步无需设置 (测试模式)                  |
| **正式上线** | 完成身份验证 (KYC) 后可提现 | 关联正式的 Stripe 账户     | 认领你的 Shopify 商店      | 提交至 App Store 或 Google Play 审核 |
| **所需账户** | Whop 账户 (自动为你创建)  | Stripe 账户           | Shopify 商店 (自动为你开通)  | RevenueCat 账户                  |

<div id="getting-started">
  ## 快速开始
</div>

最快的上手方式是直接向 Agent 提出需求：

* **快速销售数字产品**：“添加 Whop 支付，让我可以销售会员”——参见 [Whop 支付](/zh/features/monetization/whop-payments)
* **网页应用**：“为我的应用添加 Stripe 支付”——参见 [Stripe 支付](/zh/features/monetization/stripe-payments)
* **移动应用**：“为我的应用添加每月 $5.99 的订阅”——参见 [RevenueCat 订阅](/zh/features/monetization/revenuecat-subscriptions)

Agent 会连接相应的集成、构建界面并搭建测试环境，让你可以立即试用。
