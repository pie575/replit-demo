## Plateforme

### Security Agent révise l'ensemble de votre base de code

**Security Agent** est un nouvel outil de révision propulsé par l'IA qui audite l'intégralité de votre projet — pas seulement vos dépendances. Il construit un modèle de menaces, cartographie vos routes et flux de données, exécute une analyse statique avec Semgrep et HoundDog.ai, et utilise un LLM pour déterminer quels résultats sont réellement exploitables dans le contexte de votre application. Une fois la révision terminée, Security Agent organise les résultats acceptés en tâches parallèles que Replit Agent peut corriger en une seule passe.

Security Agent est disponible pour tous les builders payants. Ouvrez le volet **Security** dans votre projet et sélectionnez **Run Scan with Agent** pour l'essayer.

En savoir plus sur [Security Agent](/fr/core-concepts/security/project-security-center#agent-security-scans).

### CVE Auto-Protect corrige automatiquement les vulnérabilités critiques

Lorsqu'un nouveau CVE critique est divulgué pour un package dont dépend votre application, **CVE Auto-Protect** détecte la correspondance dans tous vos projets, demande à l'Agent de préparer un correctif dans une tâche en arrière-plan, exécute vos tests pour s'assurer que rien ne casse, et vous notifie avec un lien pour examiner le correctif. Vous gardez le contrôle — rien n'est publié tant que vous n'avez pas approuvé le correctif.

Cela signifie que vos applications peuvent être corrigées en quelques minutes après qu'une nouvelle vulnérabilité devient publique, au lieu d'attendre que vous vous en aperceviez.

En savoir plus sur [CVE Auto-Protect](/fr/core-concepts/security/project-security-center#auto-protect).

## Espace de travail

### Prévisualisation sur un simulateur iOS ou un émulateur Android

<Frame>
  <video autoPlay muted loop playsInline src="/assets/mirror/ios-emulator-9013ff1b602f.mp4" />
</Frame>

Lorsque votre projet inclut une application mobile, le panneau Prévisualisation peut désormais diffuser un vrai **simulateur iOS** ou un **émulateur Android** directement dans votre espace de travail. Pas besoin de Xcode, d'Android Studio ni d'appareil physique. Créez une application mobile avec Agent, choisissez votre appareil dans le menu déroulant du panneau Prévisualisation, et interagissez comme si vous aviez le téléphone en main. Les modifications se rechargent à chaud dans le simulateur au fur et à mesure qu'Agent les effectue.

Disponible pour les builders payants sur les plans Core, Pro et Enterprise, sur Chrome, Safari et les navigateurs basés sur Chromium. Firefox n'est pas pris en charge pour les simulateurs mobiles.

En savoir plus sur la [prévisualisation sur un simulateur ou un émulateur](/fr/features/artifact-types/building-mobile-apps#prévisualiser-sur-un-simulateur-ou-un-émulateur).

## Agent

### Ajouter une application mobile aux anciens projets

<Frame>
  <img src="/assets/mirror/multi-artifact-update-approval-f6fa8b70a100.png" alt="Panneau de chat Agent affichant la carte d'approbation « Mettre à jour le projet pour créer une application mobile » avec une offre de crédit de 5 $ et les boutons Pas maintenant / Mettre à jour le projet." width="991" height="589" data-path="images/replitai/multi-artifact-update-approval.png" />
</Frame>

Les projets créés avant le lancement d'Agent 4 peuvent désormais être mis à jour pour prendre en charge plusieurs artefacts — ce qui signifie que vous pouvez ajouter une application mobile, une présentation ou un autre artefact à un projet qui ne prenait en charge qu'un seul artefact auparavant. L'Agent préserve votre URL, vos données, vos secrets et votre déploiement pendant qu'il réorganise le projet. Plus de 200 projets ont migré dans les 48 premières heures suivant le déploiement général.

En savoir plus sur [la mise à jour des anciens projets pour la prise en charge de plusieurs artefacts](/fr/features/projects-and-artifacts/updating-projects-for-multiple-artifacts).

## Intégrations

### Le connecteur Plaid est disponible

Vous pouvez désormais vous connecter à plus de 12 000 institutions financières avec le connecteur **Plaid**. Les administrateurs d'équipe configurent les identifiants une seule fois dans **Integrations**, et les utilisateurs de votre application authentifient leurs propres comptes bancaires via Plaid Link. Les jetons d'accès sont limités par utilisateur, donc les données restent privées.

Créez un coach de finances personnelles fonctionnant avec de vraies données de transactions, un suivi de portefeuille en direct connecté à votre courtier, et plus encore. Consultez la [page partenaire Replit x Plaid](https://replit.com/partners/plaid) pour des démos et les étapes de configuration.

En savoir plus sur la [gestion des connecteurs](/fr/replitai/managing-connectors).
