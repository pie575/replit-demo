<div id="controles-de-layout-no-editor-visual">
  ### Управление раскладкой в Visual Editor
</div>

В Visual Editor появились специальные элементы управления **Layout**, которые позволяют визуально настраивать flexbox-раскладку, не прося Agent переписывать стили. Выберите любой контейнер, разверните раздел Layout и задайте flex-направление, выравнивание и распределение. Укажите расстояние в пикселях между элементами или включите переключатель **Space between**, чтобы разместить дочерние элементы по противоположным краям.

Панель редактора также перегруппирована в более понятные разделы **Text**, **Image**, **Layout**, **Color** и **Border**, чтобы нужные элементы управления было проще найти.

<div id="configuraes-do-agent-permanecem-suas-em-projetos-compartilhados">
  ### Настройки Agent остаются личными в общих проектах
</div>

Ваши настройки Agent, такие как уровень модели, режим планирования, автоматическое слияние и автоматическое утверждение плана, теперь привязаны к вашей учетной записи, а не доступны всем участникам проекта. Если коллега переключается в режим Power для своих задач, это больше не меняет ваши настройки. Agent использует выбранную вами конфигурацию, когда вы отправляете следующее сообщение, даже в проектах с большим числом участников.

Подробнее о [режимах Agent](/ru/pt/features/agent/agent-modes#settings-in-shared-projects).

<div id="agent-sugere-modo-power-quando-voc-est-travado">
  ### Agent предлагает режим Power, когда вы зашли в тупик
</div>

Когда Agent замечает, что вы раз за разом сталкиваетесь с одной и той же проблемой в режиме Economy, он предлагает переключиться на Power в следующем сообщении. Предложение появляется при повторяющихся запросах или если код продолжает выдавать ошибки — не более одного раза для каждого проекта. Agent не показывает его в сеансах планирования, если вы уже упоминали ограничения бюджета или используете бесплатный тариф.

<div id="menu-suspenso-de-configuraes-de-tarefas-mais-limpo">
  ### Более удобное выпадающее меню настроек задач
</div>

Выпадающее меню в заголовке задачи стало удобнее. Название активной задачи или плана теперь отображается вверху, где его можно переименовать прямо в меню; настройки автоматизации («Применять автоматически», «Утверждать автоматически») вынесены в отдельный раздел между названием и действиями, а благодаря фиксированной ширине всплывающее окно больше не меняет размер при изменении названий задач. Отключённые параметры автоматизации скрыты, поэтому меню показывает только то, что относится к текущей задаче.

<div id="dois-novos-conectores-quiver-ai-e-browserbase">
  ### Два новых коннектора: Quiver AI и Browserbase
</div>

В каталоге коннекторов теперь доступны два новых сервиса. Откройте панель **Интеграции** и выберите **Добавить новую интеграцию**, чтобы подключить любой из них.

* **Quiver AI**: Создавайте SVG-иллюстрации и векторизуйте растровые изображения с помощью управляемого API. Полезно, когда Agent требуется готовый SVG-ассет по запросу.
* **Browserbase**: Запускайте управляемые браузеры без графического интерфейса для поиска, исследований и полной автоматизации сеансов. Полезно, когда Agent нужно загрузить реальную веб-страницу, выполнить JavaScript или взаимодействовать с сайтом, который блокирует обычные HTTP-запросы.
