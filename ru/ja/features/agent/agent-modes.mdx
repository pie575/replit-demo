---
title: "Режимы Agent"
description: "Узнайте, как выбирать Free Mode, Power Mode и Max Mode при сборке с Agent."
---

Режимы Agent позволяют выбирать оптимальный баланс между стоимостью и возможностями при работе с Agent. В раскрывающемся списке настроек Agent выберите **Free Mode**, **Power Mode** или **Max Mode**. Free Mode всегда использует Auto. Пользователи Core и Pro могут использовать [селектор моделей](/ru/ja/features/agent/model-selector) в режимах Power Mode и Max Mode. Доступные режимы и настройки зависят от вашего тарифа и рабочего пространства.

<Note>
  Economy Mode больше не поддерживается. Его заменил Power Mode по той же цене.
</Note>

<Tip>
  **Сочетание клавиш:** нажмите **⌘+Shift+I** (Ctrl+Shift+I в Windows), чтобы переключать режимы Agent, не выходя из поля ввода чата.
</Tip>

<div id="free-mode">
  ## Free Mode
</div>

**Оптимизирован для первых шагов.** Free Mode помогает исследовать идеи, знакомиться с Replit и начинать проекты.

**Обратите внимание:** Free Mode всегда использует Auto — интеллектуальную маршрутизацию моделей Replit. Чтобы выбрать модель вручную, используйте Power Mode или Max Mode.

<Note>
  Free Mode доступен в тарифах Starter, Core и Pro. Ограничения Free Mode зависят от тарифа: в Core и Pro входит квота, которая обновляется каждые 5 часов. При достижении лимита тарифа Replit покажет, когда произойдёт обновление.
</Note>

Routine не выполняются в Free Mode. Они запускаются в Power или Max Mode и требуют бюджета на каждый запуск. Подробнее см. в разделе [Routines](/ru/chat/routines).

<div id="power-mode">
  ## Power Mode
</div>

**Оптимальный по стоимости.** Power Mode требует меньше кредитов на задачу и является оптимальным выбором по умолчанию, если вам нужны отличные результаты без оплаты за самые мощные модели.

**Лучше всего подходит для:** повседневной разработки, обучения и экономичной работы над существующими проектами.

<div id="max-mode">
  ## Max Mode
</div>

**Оптимизирован для максимальной производительности.** Max Mode использует более мощные модели для сложных задач, крупных кодовых баз и трудных проблем.

**Лучше всего подходит для:** проектов продакшен-уровня, сложных функций и случаев, когда вам нужен наилучший результат от Agent.

<div id="section">
  ## Какой режим выбрать?
</div>

Воспользуйтесь следующим руководством:

| Цель                                                             | Рекомендуемый режим                                                                   |
| ---------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| Исследовать идеи, освоить Replit и начать проект                 | Free Mode                                                                             |
| Получить максимум промптов на один кредит                        | Power Mode                                                                            |
| Сбалансировать стоимость и качество в большинстве проектов       | Power Mode                                                                            |
| Выбирать модель вручную                                          | Power Mode или Max Mode                                                               |
| Получить наилучший результат в сложных задачах продакшен-уровня | Max Mode                                                                              |
| Получить максимально возможный результат в самых сложных задачах | Max Mode с более высоким значением [Effort](/ru/ja/features/agent/model-selector#effort) |

Выберите режим в выпадающем списке настроек Agent в поле ввода чата. Билдеры на тарифах Core и Pro могут настроить [основную модель и Effort](/ru/ja/features/agent/model-selector) в Power Mode или Max Mode. Универсально лучшего режима не существует — выбирайте тот, который подходит для текущей задачи.

<div id="section-2">
  ## Настройки в общих проектах
</div>

Настройки Agent привязаны к вам лично, а не к проекту. Когда вы приглашаете участников команды в проект, у каждого из них сохраняются собственные настройки следующих параметров:

* Режим (Free Mode, Power Mode или Max Mode)
* [Основная модель и Effort](/ru/ja/features/agent/model-selector) (если доступно)
* [Режим Plan](/ru/ja/features/agent/plan-mode)
* Автоматическое слияние фоновых задач
* Автоматическое одобрение планов

Если участник команды переключится на Max Mode для следующей задачи, ваши настройки не переключатся на Max Mode. Режим и настройки, указанные в раскрывающемся списке настроек Agent, будут использоваться Agent при отправке следующего сообщения — независимо от количества участников проекта.

<div id="free-mode-2">
  ## Проверка квоты Free Mode
</div>

Откройте **Settings** → **Usage**, чтобы посмотреть, сколько осталось от квоты Free Mode и когда она обновится. Практические советы о том, как использовать квоту максимально эффективно, см. в разделе [Как получить максимум от Free Mode](/ru/chat/free-mode).
