Для публикации предусмотрено три вида оплаты по факту использования:

1. Исходящая передача данных
2. Compute units для Autoscale
3. Запросы

Посмотреть своё потребление можно в разделе **Settings** → **Account** → **Account usage**. Списание происходит ежемесячно или в момент, когда накопленные затраты превысят ваши ежемесячные кредиты. Пользователям Replit Core и Pro ежемесячно предоставляется определённый объём этих ресурсов.

Если вам нужны дополнительные кредиты сверх объёма, включённого в подписку, вы можете приобрести пакеты кредитов на странице оплаты. Подробнее о пакетах кредитов см. в разделе [Управление расходами](/ru/billing/managing-spend).

  # Публикация
</div>

<div id="1-publishing-outbound-data-transfer">
  ## 1. Исходящая передача данных при публикации
</div>

Этот тип использования оплачивается за байт; пользователям Replit Core и Pro предоставляются ежемесячные лимиты. В этот лимит засчитывается только исходящий трафик, и при его превышении может взиматься дополнительная плата. Входящий трафик, напротив, всегда бесплатен.

| Подписка    | Лимит                                                   |
| ----------- | ------------------------------------------------------- |
| Replit Core | 100 GiB                                                 |
| Replit Pro  | См. [тарифы Replit Pro](https://www.replit.com/pricing) |

Лимиты распространяются на [статическое развёртывание](/ru/features/publishing/deployment-types#static), [Autoscale](/ru/features/publishing/deployment-types#autoscale), [Reserved VM](/ru/features/publishing/deployment-types#reserved-vm) и [Scheduled](/ru/features/publishing/deployment-types#scheduled).

Актуальную стоимость исходящей передачи данных см. на [странице тарифов](https://www.replit.com/pricing).

***

<div id="2-compute-units">
  ## 2. Compute Units
</div>

Развёртывания Autoscale тарифицируются по compute units, которые учитывают использование процессора и оперативной памяти с течением времени.

Превышения также тарифицируются в compute units. Тарификация ведётся с точностью до каждой отдельной единицы. Актуальную стоимость compute units смотрите на [странице тарифов](https://www.replit.com/pricing).

Ниже показано, как секунды использования оперативной памяти и процессора в развёртывании Autoscale пересчитываются в compute units:

| Ресурс        | Compute Units |
| ------------- | ------------- |
| 1 секунда RAM | 2 единицы     |
| 1 секунда CPU | 18 единиц     |

Статические развёртывания не потребляют compute units. Они тарифицируются только за исходящую передачу данных сверх [определённого объёма](#).

[Подробнее о развёртываниях Autoscale](/ru/features/publishing/deployment-types#autoscale).

<div id="3-requests">
  ## 3. Запросы
</div>

В развёртываниях Autoscale также учитывается количество выполненных запросов.

Актуальную стоимость запросов смотрите на [странице тарифов](https://www.replit.com/pricing).

<div id="databases">
  # Базы данных
</div>

Replit взимает плату только за использование [продакшен-баз данных](/ru/features/data-and-storage/development-and-production) — базы данных для разработки всегда бесплатны и входят в состав каждого Replit App. Подробнее см. в разделе [База данных для разработки](/ru/features/data-and-storage/sql-database).

Replit PostgreSQL — полностью управляемая бессерверная база данных, обеспечивающая высокую доступность без необходимости обслуживания. Плата за продакшен-базы данных рассчитывается на основе фактического использования, что позволяет существенно сократить расходы.

Плата за продакшен-базы данных PostgreSQL взимается по двум показателям использования:

* **[Вычислительное время](#compute-time)**: Объём вычислительных ресурсов, потребляемых за час.
* **[Хранение данных](#data-storage)**: Общий объём хранимых данных, включая исторические данные.

Текущее потребление ресурсов, включая использование продакшен-базы данных, можно посмотреть в **Настройки** → **Учётная запись** → **Использование учётной записи**.

<div id="compute-time">
  ## Вычислительное время
</div>

Вычислительное время определяется количеством часов, в течение которых ваша база данных остаётся активной за расчётный период. База данных считается активной, когда она получает запросы, а также ещё 5 минут после последнего запроса. Если база данных простаивает 5 минут, она будет приостановлена и перейдёт в неактивное состояние.

<div id="data-storage">
  ## Хранение данных
</div>

Хранение данных — это общий объём данных, хранящихся во всех базах данных вашего аккаунта, измеряемый в гибибайтах (ГиБ). Объём хранилища рассчитывается как максимальный объём, использованный за месяц. Каждая база данных PostgreSQL занимает 33 МБ хранилища, даже если не содержит данных. Это стандартный объём хранилища, занимаемый сервером Postgres.

<Note>Общий лимит хранилища для каждой продакшен-базы данных составляет 10 гибибайт (ГиБ). Для баз данных разработки предоставляется 20 ГиБ бесплатного хранилища на каждое App в Replit.</Note>

<div id="additional-notes">
  # Дополнительные примечания
</div>

Если с вашим способом оплаты возникнут проблемы, мы вас уведомим. Регулярные сбои при оплате могут привести к приостановке ваших опубликованных приложений. Если это произошло, [обратитесь в поддержку](https://replit.com/help) и обновите платёжные данные, чтобы восстановить доступ к нашим сервисам.
