title: "项目地理位置"
description: "选择已发布项目的计算与存储资源的托管位置。"
---

项目地理位置即项目的发布地区，在发布时选定，用于控制已发布项目的计算与存储资源托管在何处。

<Note>
  项目地理位置与[工作区地理位置](/zh/features/collaboration/workspace-geography)可以不同。工作区地理位置决定该工作区内新建项目的开发资源托管在何处。
</Note>

<div id="section">
  ## 项目地理位置决定了什么
</div>

默认情况下，Replit 会推荐离你最近的区域。这有助于降低应用访问者的延迟，并满足数据驻留要求。

选择区域后，项目中所有已发布的工件 (计算资源、数据库、对象存储等) 都会自动集中部署在同一区域。区域化代理同样有助于降低应用访问者的延迟。

<div id="section-2">
  ## 选择项目地理位置
</div>

若要选择推荐地理位置以外的其他地理位置，请按以下步骤操作。

<Steps>
  <Step>在 Replit 项目中打开 **Publishing** 工具。</Step>
  <Step>展开 **Advanced** 设置。</Step>
  <Step>在 **Geography** 下拉菜单中选择所需的地理位置。</Step>

  <Step>
    选择 **Publish**，将项目发布到所选地理位置。
  </Step>
</Steps>

</Frame>

<div id="section-3">
  ## 为发布的项目强制指定地区
</div>

Enterprise 管理员可以为组织内的所有项目强制指定发布地区。策略生效后，组织内的构建者只能发布到指定地区。该策略仅适用于尚未发布的项目，不会影响已发布到其他地区的项目。

<Note>
  强制指定发布地区为 Enterprise 功能。如需详细了解 Enterprise 方案，
  请参阅 [Pricing](https://replit.com/pricing/)。
</Note>

<Steps>
  <Step>前往 **Account settings**。</Step>
  <Step>选择 **Advanced**。</Step>

  <Step>
    选择所有项目首次发布时必须使用的地区。
  </Step>
</Steps>

<div id="section-4">
  ## 可用性与限制
</div>

| 区域                | 是否可选择发布项目 |
| :---------------- | :-------- |
| **North America** | 支持        |
| **Europe (EU)**   | 支持        |
| **Asia**          | 支持        |
| **South America** | 支持        |
| **Australia**     | 支持        |

<Note>
  项目地理位置选择功能面向 Core、Pro 和 Enterprise 客户开放。Free
  客户的项目默认发布到 North America。
</Note>

在选择项目地理位置之前，请注意以下限制：

* **发布后无法更改区域。** 项目一旦发布到特定区域，该选择即为永久性的，已发布的项目无法迁移到其他区域。
* **开发位置与发布位置可能不同。** 对象存储等资源可能在发布前就已创建，因此可能与项目地理位置不一致。
