<div id="personalize-o-agent-com-instrues-e-habilidades-do-workspace">
  ### 使用 workspace 指令和技能自定义 Agent
</div>

现在，您只需教 Agent 一次团队的工作方式，它就会将其应用到所有项目中。您可以定义 Agent 在每个项目中都会遵循的**自定义指令**，并创建可复用的**技能**，供 Agent 按需加载以完成特定任务。您可以在 **Workspace 设置** &gt; **自定义** 中管理这两项内容。

  <img src="/assets/mirror/agent-customization-create-skill-fcb794e6de4e.png" alt="Agent 自定义选项卡，可在其中添加 workspace 指令和技能" width="2168" height="1350" data-path="images/replitai/agent-customization-create-skill.png" />
</Frame>

详细了解 [Agent 自定义](/zh/pt/features/agent/agent-customization)。

<div id="bloqueie-pacotes-maliciosos-com-o-firewall-de-pacotes">
  ### 使用包防火墙拦截恶意包
</div>

Replit 现在会在恶意或已遭入侵的软件包影响你的应用之前将其拦截。包防火墙会检查常见包管理器中的每次安装，并自动阻止有害依赖项。该功能默认启用；当某个包被拦截时，Agent 会调整其计划，改用更安全的替代方案。

<Frame>
  <img src="/assets/mirror/blocked-package-message-04011660ce75.png" alt="包防火墙拦截恶意包的提示信息" width="1372" height="1144" data-path="images/package-firewall/blocked-package-message.png" />
</Frame>

详细了解[包防火墙](/zh/pt/features/security/package-firewall)。

  ### 更快导入和导出演示文稿
</div>

</Frame>

<div id="adicione-referncias-visuais-ao-gerar-mdia-no-canvas">
  ### 在 Canvas 中生成媒体时添加视觉参考
</div>

现在，在 Canvas 中生成图像、视频或矢量图形时，你可以附加画板中已有的元素作为视觉参考。选择一个 frame、便笺或图像，Agent 会将其用作生成依据，让生成的媒体与项目的视觉风格相匹配。

<Frame caption="打开“生成媒体”表单中的 + 菜单，上传文件或选择画布元素。">
  <img src="/assets/mirror/canvas-generate-media-references-ac0cb4340acb.png" alt="Canvas 中的“生成媒体”表单，添加菜单已打开，显示“上传文件”和“选择画布元素”选项，模型下拉菜单设置为 Nano Banana Pro" width="1134" height="662" data-path="images/replitai/canvas-generate-media-references.png" />
</Frame>

<Note>
  ChatGPT Images 2.0 目前不支持上传。请切换到其他模型，例如 Nano Banana Pro，以附加视觉参考。
</Note>

详细了解[如何在 Canvas 中生成媒体](/zh/pt/design/toolbar#generate)。

<div id="escolha-quais-alertas-de-produo-chegam-sua-caixa-de-entrada">
  ### 选择要发送到收件箱的生产环境警报
</div>

现在，您可以单独管理生产环境警报，不再与其他电子邮件混在一起。新的**生产环境警报**设置可决定 Replit 是否发送有关可用性事件、依赖项安全漏洞和语言模型更新的电子邮件。如果已部署的应用使用的是过时模型，Replit 还会准备一个任务草稿，让您只需审核一次即可完成更新。

<Frame caption="在“设置”→“自定义”→“电子邮件”中找到“生产环境警报”。">
  <img src="/assets/mirror/production-alerts-settings-333bb4ee8a61.png" alt="通知设置中的“生产环境警报”部分，显示“启用生产环境警报电子邮件”开关已开启，以及已展开的安全警报严重性下拉菜单" width="2000" height="899" data-path="images/editor/production-alerts-settings.png" />
</Frame>

详细了解[通知设置](/zh/pt/features/editor/user-settings#notifications)。
