# Replit デスクトップアプリ

> リニューアルされた Replit デスクトップアプリは、ネイティブなマルチタスク、ステータスシグナル、タブプレビューを備え、Replit のフル体験をコンピューターにお届けします。

<a href="https://replit.com/desktop" target="_blank">Replit デスクトップアプリ</a>は、Replit のフル体験をコンピューターにお届けします。ブラウザタブでは得られないネイティブな使い心地で、専用アプリで Agent を使ってビルドできます。

## Replit デスクトップアプリとは

Replit デスクトップアプリは、Windows と Mac 向けにリニューアルされたネイティブアプリです。ウェブと同じ体験が得られるため、アプリの作成、Agent とのチャット、公開をすべて 1 つのウィンドウから行えます。さらに、デスクトップアプリだからこそできる機能がいくつか追加されています。

* **マルチタスク**: 複数の Replit アプリを同時に操作できます。
* **ステータスシグナル**: Agent がサポートを必要とするときや作業が完了したときに一目でわかります。
* **タブプレビュー**: タブを切り替えずに開いているアプリをチェックできます。

## はじめ方

<Steps>
  <Step title="アプリをダウンロード">
    <a href="https://replit.com/desktop" target="_blank">デスクトップアプリのダウンロードページ</a>にアクセスして、お使いのコンピューター用のバージョンをダウンロードしてください。
  </Step>

  <Step title="インストールして起動">
    ダウンロードしたファイルを開き、指示に従ってインストールしてください。完了したらアプリを起動します。
  </Step>

  <Step title="サインイン">
    Replit アカウントでサインインするか、新規の場合はアカウントを作成してください。作成したものはすべて [replit.com](https://replit.com) と同期されます。
  </Step>
</Steps>

<Tip>
  アプリ、履歴、設定はデスクトップアプリとウェブで共通です。どちらか一方で始めたものをもう一方で続けることができます。
</Tip>

## 機能

* **[Agent](/ja/build/welcome)**: 会話を通じてアプリをビルド・編集できます。
* **[プロジェクトエディター](/ja/learn/projects-and-artifacts/project-editor)**: フル開発環境です。
* **[公開](/ja/features/publishing/overview)**: セットアップなしでアプリを共有できます。

## エンタープライズチームの場合

デスクトップアプリを使用すると、組織全体に Replit を簡単に展開できます。他のデスクトップアプリと同様にインストールできるため、IT チームはデバイス管理（MDM）プロバイダーを通じて、社内のコンピューターへ自動的に配布・インストールできます。詳細については、アカウントマネージャーにお問い合わせください。
