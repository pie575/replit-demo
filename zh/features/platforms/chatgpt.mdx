ChatGPT 中的 Replit 集成让你直接在对话中创建、更新和查看 Replit App，无需任何设置。只需与 ChatGPT 对话即可构建真正可用的应用，剩下的交给 Agent。

<div id="what-is-replit-in-chatgpt">
  ## 什么是 ChatGPT 中的 Replit
</div>

ChatGPT 中的 Replit 可将你的 ChatGPT 对话连接到 Replit 强大的开发平台。你只需描述想要构建的内容，Agent 就会为你创建一个功能完整的 Replit App。创建完成后，你可以让 ChatGPT 修改、更新或分析你的应用——全程通过自然对话完成。

<div id="getting-started">
  ## 快速开始
</div>

按照以下步骤将 Replit 连接到 ChatGPT，并创建你的第一个应用。

<div id="connect-replit-to-chatgpt">
  ### 将 Replit 连接到 ChatGPT
</div>

你可以通过两种方式将 Replit 连接到 ChatGPT：

<Accordion title="从设置中连接">
  1. 点击 ChatGPT 中的头像图标 2. 前往 **Settings** → **Apps &amp;
     Connectors** 3. 找到 **Replit** 并点击 **Connect** 4. 使用你的 Replit 账户完成 OAuth
     授权
</Accordion>

<Accordion title="在对话中连接">
  1. 在 ChatGPT 中新建一个对话 2. 使用下列任一方式调用 Replit
     3. 如果你尚未连接，ChatGPT 会引导你完成 OAuth 流程
</Accordion>

<div id="invoke-replit-in-chatgpt">
  ### 在 ChatGPT 中调用 Replit
</div>

连接完成后，你可以通过三种方式调用 Replit：

| 方式    | 使用方法                                |
| ----- | ----------------------------------- |
| 直接提及  | 在消息开头输入 `Replit, <request>`         |
| 斜杠命令  | 在输入框中输入 `/Replit`                   |
| 输入框菜单 | 点击 **+** 按钮 → **More** → **Replit** |

<div id="create-your-first-app">
  ### 创建你的第一个应用
</div>

连接完成后，创建你的第一个 Replit App：

1. 在 ChatGPT 中开启一段新对话
2. 调用 Replit 并描述你想构建的内容 (例如：&quot;Replit，创建一个带深色模式的待办事项应用&quot;)
3. Agent 会生成你的应用并自动发布
4. 完成后，你会收到一个可查看应用的链接

<Note>
  每段对话只能对应一个 Replit App。如果你在同一段对话中创建新应用，实际上会修改现有应用。若要创建多个应用，请分别开启新的对话。
</Note>

<div id="features">
  ## 功能
</div>

* **[Replit AI](/zh/welcome)**：Agent 根据你的自然语言需求生成并发布应用
* **[Project Editor](/zh/learn/projects-and-artifacts/project-editor)**：可从 ChatGPT 访问的全功能开发环境
* **[Publishing](/zh/learn/projects-and-artifacts/replit-deployments)**：应用自动部署，随时可分享

<Accordion title="你可以做什么">
  **创建：** 描述你想要的效果，即可构建新的 Replit App。Agent 会生成应用并自动发布。

  **更新：** 在当前对话中修改应用。让 ChatGPT 添加功能、修复缺陷或进行改动，Agent 会自动执行。

  **检查：** 在不做任何改动的情况下分析你的应用，获取代码结构、文件路径或运行行为等信息。
</Accordion>

<Accordion title="支持的文件格式">
  你可以在 prompt 中包含多种文件类型：

  | 格式         | 是否支持             |
  | ---------- | ---------------- |
  | PDF        | 支持               |
  | CSV        | 支持               |
  | 常见文档格式     | 支持               |
  | 图片 (原始文件)  | 不支持 (请改用公开 URL)  |
  | 视频 (原始文件)  | 不支持 (请改用公开 URL)  |

  <Note>
    若要在应用中包含图片或视频，请在 prompt 中提供公开 URL。你也可以在应用创建完成后，直接在 Replit 中添加媒体文件。
  </Note>
</Accordion>

<Accordion title="构建时间">
  Agent 构建应用通常需要：

  | 应用复杂度                  | 典型构建时间 |
  | ---------------------- | ------ |
  | 简单 (计算器、小型落地页)         | 2–3 分钟 |
  | 复杂 (游戏、丰富动画、信息密集的仪表板)  | 3–4 分钟 |
</Accordion>

<div id="availability-and-plans">
  ## 可用性与套餐
</div>

<Accordion title="ChatGPT 套餐">
  Replit 集成适用于所有 ChatGPT 套餐类型：

  | 套餐             | 是否支持 | 说明                                            |
  | -------------- | ---- | --------------------------------------------- |
  | Free           | 是    |                                               |
  | Plus           | 是    |                                               |
  | Pro            | 是    |                                               |
  | Business       | 是    | 需管理员在 **Workspace settings → Connectors** 中启用 |
  | Enterprise/Edu | 是    | 需管理员在 **Workspace settings → Connectors** 中启用 |

  **区域可用性：** 欧盟以外的所有区域。
</Accordion>

<Accordion title="Replit 套餐">
  所有 Replit 套餐类型均支持 ChatGPT 集成：

  | 套餐            | 是否支持 | 说明                          |
  | ------------- | ---- | --------------------------- |
  | Starter (免费)  | 是    | 仅支持公开应用                     |
  | Core          | 是    | 私有应用、更长的构建时长、Publishing、数据库 |
  | Pro           | 是    | 更高的每月额度，涵盖 Core 全部功能        |
  | Enterprise    | 是    | 可使用全部功能                     |
</Accordion>

<div id="billing-and-credits">
  ## 账单与积分
</div>

在 ChatGPT 中由 Replit 完成的工作，将作为 Replit Agent 用量计入你的 Replit 账户账单。

<Accordion title="账单如何计算">
  * **Core** 和 **Pro** 计划每月包含一定积分，可在额度范围内用于 Agent、发布和数据库
  * 你可以购买**积分包**，有效期六个月且不会自动续订——非常适合发布高峰或临时试验
  * 在 Replit 的账单设置中使用**用量上限**和**预算**来控制支出

  详见 [AI 账单文档](/zh/billing/ai-billing)。
</Accordion>

<div id="current-limitations">
  ## 当前限制
</div>

目前，ChatGPT 中的 Replit App：

* 只能处理在该次对话中创建的应用
* 无法打开或修改：
  * 在其他 ChatGPT 对话中创建的应用
  * 你直接在 Replit 中构建的应用

与完整 Replit 体验保持功能一致 (数据库、Secrets 管理、更高级的 Project Editor 控制项) 将在后续实现。

<div id="troubleshooting">
  ## 故障排查
</div>

<Accordion title="Replit 未出现在“浏览应用”中">
  如果你在 **浏览应用** 中找不到 Replit，请检查：

  * 你所在的地区是否支持这些应用
  * 你的 workspace 管理员是否已启用 Replit 应用 (Business/Enterprise/Edu)
</Accordion>

<Accordion title="构建失败">
  如果构建失败，请在 Replit 中打开该应用：

  * 检查用量和账单
  * 使用 checkpoint 和回滚功能还原到之前的状态
  * 直接在 Project Editor 中向 Agent 求助
</Accordion>
