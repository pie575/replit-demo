# Développez votre projet

> Ajoutez une application mobile, une présentation et bien plus à un projet existant — tout en partageant le même backend.

⏰ *Durée estimée : 5 minutes* · Suite de [Créez votre première application](/fr/getting-started/quickstarts/ask-ai)

Vous avez créé une application web. Transformez-la maintenant en davantage — ajoutez une application mobile, une présentation ou autre chose, le tout dans le même projet. Tout partage les mêmes données et le même backend, vous n'avez donc pas besoin de repartir de zéro.

## Avant de commencer

Vous aurez besoin d'un projet existant sur Replit — issu d'un guide de démarrage rapide précédent ou de n'importe quel projet que vous avez créé.

## Votre projet peut faire plus d'une chose

Lorsque vous avez créé votre première application, vous avez créé une application web. Mais un seul projet sur Replit n'est pas limité à un seul résultat. Vous pouvez ajouter une **Application mobile** qui fonctionne sur téléphone, une **présentation** pour exposer votre idée, une **vidéo animée**, et bien plus — tout coexistant dans le même projet.

On appelle ces éléments des **artefacts**. Chaque artefact est un résultat publiable indépendant, mais ils partagent tous le même code et les mêmes données en coulisses. Créez une fois, publiez partout.

## Ajoutez une application mobile

<Steps>
  <Step title="Demandez à Agent de créer une version mobile">
    Dites à Agent ce que vous souhaitez :

    ```
    Add a mobile version of this app
    ```

    Vous pouvez également cliquer sur le bouton **+** dans le panneau Preview pour ajouter un nouvel artefact.

    <Frame>
      <video autoPlay muted loop playsInline src="https://cdn.replit.com/sanity/design_mobile_app_canvas.mp4" />
    </Frame>

    Agent crée une application mobile qui partage le même backend que votre application web — toutes les données ou la logique que vous avez déjà créées sont automatiquement reprises.
  </Step>

  <Step title="Prévisualisez sur un simulateur de téléphone">
    Lorsqu'Agent a terminé, le panneau Preview affiche votre application mobile dans un simulateur de téléphone. Tapotez et testez-la comme vous le feriez sur un vrai téléphone.
  </Step>

  <Step title="Basculez entre vos applications">
    Utilisez le menu déroulant dans le **panneau Preview** pour basculer entre votre application web et votre application mobile.

    <Frame>
      <video autoPlay muted loop playsInline src="https://cdn.replit.com/sanity/switch_artifacts.mp4" />
    </Frame>

    Vous pouvez également demander à Agent :

    ```
    Show me the web app
    ```
  </Step>
</Steps>

## Ajoutez encore plus à votre projet

Votre projet n'est pas limité aux applications web et mobiles. Vous pouvez demander à Agent de créer d'autres types d'artefacts également :

* **Présentations** — « Create a pitch deck for this app »
* **Vidéos animées** — « Make a short explainer video for this app »
* **Visualisations de données** — « Build a dashboard showing usage stats »
* **Documents** — « Write a one-pager describing this app »

Chacun devient un nouvel artefact dans votre projet, partageable avec sa propre URL.

## Publiez votre projet

Lorsque vous cliquez sur **Publish**, tous les artefacts de votre projet sont mis en ligne ensemble. Votre application web, votre application mobile et votre présentation obtiennent chacune leur propre URL, et elles restent connectées via le même backend.

En savoir plus dans [Publiez votre application](/fr/getting-started/quickstarts/publish).
