Shell vous permet de travailler sur votre projet comme dans un terminal classique, de gérer des fichiers,
d’installer des paquets et d’exécuter des scripts. Par exemple, vous pouvez parcourir les fichiers du projet
ou utiliser `psql` si une connexion à une base de données est configurée pour votre projet.

<Tip>
  Pour mieux gérer votre flux de travail, nous vous recommandons d’utiliser le bouton **Run** plutôt que d’exécuter votre application depuis Shell.
  Les flux de travail lancés avec le bouton **Run** envoient leur sortie vers l’outil Console
  et fournissent un moyen structuré de consulter les journaux.
</Tip>

<div id="section">
  ## Fonctionnalités
</div>

Shell offre les fonctionnalités suivantes :

* **Exécuter plusieurs Shell** : ouvrez plusieurs instances de Shell et effectuez différentes tâches simultanément
* **Rechercher du texte** : recherchez du texte spécifique dans la sortie du Shell

<div id="shell">
  ### Vérifier l’accès au Shell
</div>

Pour vérifier que le Shell est prêt et afficher l’espace de travail actuel, exécutez la commande suivante :

```sh theme={null}
pwd
```

Shell affiche le chemin de l’espace de travail actuel.

<Frame caption="La commande pwd affiche le chemin de l’espace de travail actuel, puis revient à l’invite du Shell.">
  <img src="/assets/mirror/shell-pwd-output-2d31a0e0466b.jpg" alt="Onglet Shell affichant la commande pwd, le chemin de l’espace de travail et le retour à l’invite" width="1280" height="246" data-path="images/workspace/shell-pwd-output.jpg" />
</Frame>

Pour les projets dotés d’une base de données, sélectionnez **Tools** → **Database**, puis
ouvrez la page **Development database**. Cette page propose des options de connexion.
Gardez vos informations de connexion privées et ne les copiez pas dans la documentation, les captures d’écran, les journaux, les fichiers source
ou les messages partagés.

<div id="section-3">
  ### Recherche de texte
</div>

Pour accéder à l’outil de recherche de texte et l’utiliser :

1. Sélectionnez l’icône de loupe<img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="Icône de loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" />en haut à droite de l’onglet Shell pour ouvrir la boîte de dialogue de recherche.
2. Saisissez un terme de recherche, puis sélectionnez **Next** pour parcourir les correspondances une par une.
3. Utilisez **Previous** pour revenir à la correspondance précédente.
4. Sélectionnez **Exit** ou cliquez en dehors de la boîte de dialogue pour quitter la recherche de texte.

<div id="section-4">
  ### Plusieurs Shell
</div>

Pour créer un autre Shell :

1. Dans l’en-tête du panneau Shell, sélectionnez le menu des instances Shell.
2. Sélectionnez **New Shell**.

<Frame>
  <img src="/assets/mirror/shell-new-94a280c1230f.png" alt="Menu des instances Shell affichant l’espace de travail actuel et l’option New Shell" width="1280" height="224" data-path="images/workspace/shell-new.png" />
</Frame>

Utilisez ce même menu pour passer d’un Shell à l’autre. Replit identifie chaque Shell par la dernière commande exécutée afin de faciliter leur distinction.

<Warning>
  Lorsque vous ouvrez plusieurs Shell, Replit ferme automatiquement les instances Shell inactives.
  Un Shell inactif est un Shell qui n’est pas sélectionné et qui n’exécute aucun processus utilisateur.
</Warning>
