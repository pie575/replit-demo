Le Workspace Security Center est disponible sur tous les plans. Utilisez-le pour analyser les [dépendances](/fr/pt/core-concepts/security/concepts#dependency) des projets de l&#39;ensemble du workspace et examiner les résultats des [CVE](/fr/pt/core-concepts/security/concepts#cve) par [gravité](/fr/pt/core-concepts/security/concepts#severity). Vous pouvez corriger les problèmes avec Replit Agent, [republier](/fr/pt/core-concepts/security/concepts#republish) les projets affectés et exporter des rapports Software Bill of Materials ([SBOM](/fr/pt/core-concepts/security/concepts#sbom)) à des fins de conformité.

<Note>
  Pour analyser un seul projet, ouvrez le [Project Security Center](/fr/pt/core-concepts/security/project-security-center)
  dans le panneau **Security** de ce projet.
</Note>

<Note>
  Vous débutez avec la sécurité des dépendances ? Consultez les [Concepts de sécurité](/fr/pt/core-concepts/security/concepts) pour les définitions de CVE, SBOM, exposition, Fix with Agent, Republish et Auto-Protect.
</Note>

<div id="deteco-de-cve">
  ### Détection de CVE
</div>

Visualisez les vulnérabilités dans l&#39;ensemble des projets de votre workspace :

* Identifiez les projets vulnérables, classés par ordre de priorité selon l&#39;[exposition](/fr/pt/core-concepts/security/concepts#exposure) (statut de publication et visibilité)
* Consultez le nom des paquets concernés, leur version et leur niveau de gravité (critical, high, medium et low)
* Accédez aux recommandations de remédiation pour chaque projet

<div id="visualizao-de-projetos-afetados">
  ### Visualisation des projets affectés
</div>

Identifiez les projets qui contiennent des vulnérabilités et déterminez les correctifs à traiter en priorité :

* Consultez une vue d&#39;ensemble des projets vulnérables regroupés par exposition : nombre total de projets, projets publiés et projets publiés publiquement
* Consultez le détail des projets Replit affectés
* Effectuez une recherche par ID de CVE ou par nom de projet et filtrez par gravité, propriétaire, statut de publication (Published / Not published) et visibilité (Public / Private)
* Développez n&#39;importe quelle ligne de projet pour afficher tous les résultats de CVE (gravité, paquet, version, ID de CVE) sans quitter la page

<div id="fix-with-agent-e-republicao">
  ### Fix with Agent et republication
</div>

Corrigez les vulnérabilités et redéployez sans quitter le Security Center :

* Sélectionnez **[Fix with Agent](/fr/pt/core-concepts/security/concepts#fix-with-agent)** sur n&#39;importe quel projet concerné pour créer un correctif sous forme de tâche en arrière-plan dans le projet. Vérifiez et appliquez la modification générée avant de republier.
* Suivez l&#39;avancement de la remédiation au fil des étapes **Task in progress**, **Apply changes**, **Republish**, jusqu&#39;aux états finaux **Republished** ou **Failed**.
* **Republish** en un clic, avec une boîte de dialogue de confirmation qui redéploie le build à partir de la configuration existante une fois le correctif appliqué.
* Effectuez des actions en masse, comme annuler la publication ou avertir les propriétaires des vulnérabilités présentes dans leurs projets.

<div id="exportao-de-sbom">
  ### Exportation de SBOM
</div>

Exportez des nomenclatures logicielles (SBOM) à des fins de conformité et d&#39;audit :

* Téléchargez des SBOM aux formats standard ([SPDX](/fr/pt/core-concepts/security/concepts#spdx-and-cyclonedx), [CycloneDX](/fr/pt/core-concepts/security/concepts#spdx-and-cyclonedx))
* Générez des rapports pour des projets individuels ou pour l&#39;ensemble du workspace
* Parcourez les SBOM regroupés par exécution d&#39;analyse, avec l&#39;horodatage, le nombre de projets et l&#39;utilisateur ayant lancé l&#39;exécution
* Téléchargez tous les SBOM d&#39;une exécution d&#39;analyse dans un seul fichier zip
* Répondez aux exigences de conformité en matière de transparence de la chaîne d&#39;approvisionnement logicielle

<Note>
  Les téléchargements groupés de SBOM sont disponibles avec les plans Enterprise. Les workspaces relevant d&#39;autres plans voient s&#39;afficher une proposition de passage à Enterprise dans la section SBOM.
</Note>

<div id="acessar-o-workspace-security-center">
  ## Accéder au Workspace Security Center
</div>

Pour ouvrir le Workspace Security Center :

1. Rendez-vous sur [replit.com](https://replit.com) et connectez-vous à votre compte.
2. Sélectionnez **Security** dans le menu de navigation à gauche de la page d&#39;accueil.

<div id="escanear-o-workspace">
  ## Analyser le workspace
</div>

<Frame>
  <img src="/assets/mirror/security-overview-b37f090f236c.png" alt="La vue initiale du Workspace Security Center avec le nombre total d'analyses, le nombre total de vulnérabilités et les CVE regroupés par gravité" width="3438" height="1984" data-path="images/workspace-security-center/security-overview.png" />
</Frame>

1. Ouvrez le Workspace Security Center.
2. Sélectionnez **Run security scan** pour lancer une analyse sur l&#39;ensemble du workspace.
3. Passez en revue les résultats, classés par projet concerné, gravité et exposition du deployment.
4. Dans chaque projet concerné, sélectionnez **Fix with Agent**, puis **Republish** une fois le correctif appliqué.

Les analyses examinent les dépendances des projects Replit du workspace et signalent les vulnérabilités connues répertoriées dans les registres publics de vulnérabilités.

<div id="auto-protect">
  ## Auto-Protect
</div>

Les administrateurs peuvent activer **[Auto-Protect](/fr/pt/core-concepts/security/concepts#auto-protect)** pour le compte : cette option compare en continu les CVE nouvellement divulguées aux dépendances de tous les projets. En cas de correspondance, Replit Agent prépare un correctif testé et les développeurs reçoivent un e-mail contenant un lien direct pour l&#39;appliquer.

Consultez [Auto-Protect](/fr/pt/core-concepts/security/project-security-center#auto-protect) pour découvrir le flux de travail complet et les étapes de configuration, y compris le seuil de gravité réservé aux administrateurs dans **Settings** &gt; **Account** &gt; **Advanced**.

<Note>
  Contactez votre gestionnaire de compte dédié pour obtenir de l&#39;aide sur la configuration du Workspace Security Center ou sur l&#39;intégration des exports SBOM à vos flux de travail de conformité.
</Note>
