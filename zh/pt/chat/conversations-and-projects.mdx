使用 Replit 时，您可以在 Conversation 中开展工作，或构建 Project。Conversation 可用于提问、探索、后续跟进和运行 Routine。Project 可用于构建应用、创建演示文稿和设计。

[了解如何将 Conversation 转为 Project。](/zh/pt/chat/continue-or-create-a-project)

<div id="como-eles-diferem">
  ## 它们有何不同
</div>

尽管二者有关联，Conversation 和 Projects 的用途不同。具体区别如下：

| 方面       | Conversation    | Projects                                                                                   |
| -------- | --------------- | ------------------------------------------------------------------------------------------ |
| 最适合用于    | 提问、探索和 Routines | 更深入的构建和设计工作，例如 app、演示文稿、仪表板和多个产物                                                           |
| 结构       | 单个线程            | 包含多个产物的 Project 工作区                                                                        |
| 后台任务     | 不可用             | 可并行运行                                                                                      |
| Routines | 可用              | 不可用                                                                                        |
| 集成       | 可用              | 可用                                                                                         |
| 可创建      | 文档、图片和电子表格等资源   | 文档、图片和电子表格等资源，以及 [Artifacts](/zh/pt/features/projects-and-artifacts/artifacts)，例如演示文稿、app 和网站 |
| 部署       | 无法部署            | 可以部署并公开                                                                                    |
