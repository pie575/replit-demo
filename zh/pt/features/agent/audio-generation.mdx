借助 Agent 的音频生成能力，为你的 App 添加声音。只需让 Agent 创作背景音乐、音效或语音旁白，它就会把音频直接添加到你的项目中。

音频生成让你无需录音棚、配音演员或第三方工具，就能打造更丰富的体验。无论是游戏、分步教程，还是需要语音的 App，Agent 都能生成契合你项目的音频。

<div id="o-que-voc-pode-criar">
  ## 你可以创作什么
</div>

Agent 可以生成三种类型的音频：

* **音乐**：按照你描述的氛围和风格生成背景音乐和主题曲。
* **音效**：点击声、提示音、呼啸声和游戏音效等短音频片段。
* **语音**：根据你提供的文本生成自然流畅的旁白和配音。

<div id="uso">
  ## 使用方式
</div>

音频生成已集成在 Agent 中，无需额外启用。用 Agent 打开任意 Replit App，描述你需要的音频即可。Agent 会根据你的请求判断何时生成音频，并将生成的音频片段添加到项目中。

<div id="quando-o-agent-gera-udio">
  ### Agent 何时生成音频
</div>

当你在项目中提出与声音相关的需求时，Agent 就会生成音频：

| 使用场景  | prompt 示例                 |
| ----- | ------------------------- |
| 背景音乐  | “为我的冥想应用添加舒缓的背景音乐”        |
| 游戏音效  | “为我的游戏制作一个收集金币的音效和一个跳跃音效” |
| 语音旁白  | “生成一段亲切的语音，朗读我的新手引导步骤”    |
| 提醒与通知 | “制作一段简短的提示音，在收到新消息时播放”    |

<div id="como-o-udio-se-integra-ao-seu-app">
  ## 音频如何集成到你的 App 中
</div>

Agent 会像处理其他资源一样，将生成的音频添加到你的项目中：

* **自动创建文件**：生成的音频文件会直接保存到你的项目中。
* **代码更新**：Agent 会将音频集成到你的 App 中，让它在恰当的时机播放。
* **迭代优化**：让 Agent 调整氛围、时长、音色或风格，它会重新生成音频。

<div id="faturamento">
  ## 计费
</div>

音频生成是 Agent 提供的一项服务。Agent 会按服务提供商的费率收费，费用从你的 Replit 积分中扣除。相关费用会显示在你的[用量页面](/zh/pt/billing/managing-spend)。

<Note>
  Replit 的音频生成由 [ElevenLabs](https://elevenlabs.io/) 提供支持，可生成高质量的音乐、音效和语音。
</Note>
