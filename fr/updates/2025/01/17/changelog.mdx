<div id="sendgrid-integration">
  ### Intégration SendGrid
</div>

Vous pouvez désormais créer des intégrations d&#39;e-mail avec Agent, ce qui vous permet d&#39;envoyer des e-mails depuis vos nouveaux projets Agent grâce à l&#39;API SendGrid.

<div id="web-view-mobile-support">
  ### Prise en charge mobile de la vue web
</div>

Nous avons ajouté la possibilité d&#39;adapter la vue web aux tailles d&#39;écran mobiles les plus courantes. Nous avons également ajouté un QR code dans le menu déroulant de l&#39;URL et dans le panneau réseau afin de faciliter les tests sur appareil mobile.

Pour rappel : même pendant que vous développez votre project, celui-ci reste accessible depuis internet. Il vous suffit d&#39;ouvrir l&#39;URL de développement depuis n&#39;importe quel appareil.

<div id="dns-record-format-update">
  ### Mise à jour du format des enregistrements DNS
</div>

Nous avons modifié le format des enregistrements DNS des domaines personnalisés afin de le rendre conforme aux standards du secteur.

Cela devrait faciliter la configuration des domaines personnalisés.

<div id="flask-deployment-upgrade">
  ### Amélioration des déploiements Flask
</div>

gunicorn est désormais le serveur web par défaut pour les déploiements utilisant la stack Flask.

Les performances sont ainsi 40 fois supérieures à celles des déploiements Flask précédents.

<div id="assistant-inline-shell-commands">
  ### Commandes Shell intégrées dans Assistant
</div>

Assistant peut désormais exécuter des commandes Shell directement dans le volet Chat. Gagnez du temps en lançant vos commandes sans quitter le Chat !
