<div id="what-is-the-task-system">
  ## Что такое система задач?
</div>

**Задача** — это единица работы, которую Agent может спланировать и выполнить. Задачи позволяют Agent разбить крупную цель на более мелкие части, чтобы вы могли проверить каждую из них до того, как она изменит ваше приложение.

Agent работает в двух местах: в **основной ветке** и в **фоновых задачах**. Основная ветка — это диалог, в котором вы описываете, чего хотите, уточняете направление и решаете, что применить к основной версии. Фоновые задачи — это отдельные потоки, где Agent работает самостоятельно в изолированных копиях вашего project.

Используйте основную ветку для задания направления и принятия решений, а фоновые задачи — для работы, которую можно выполнять параллельно. Фоновые задачи не изменяют основную версию, пока вы их не проверите и не примените.

Система задач — это способ, которым Agent организует эту работу. Когда вы описываете, что хотите создать, Agent может разбить ваш запрос на отдельные задачи и разместить их на доске с колонками: **Черновик**, **Активный**, **Готовый** и **Завершённый**.

<Frame>
  <img src="/assets/mirror/task-board-progress-f4d3b5e7e93e.png" alt="Доска задач с задачами, распределёнными по колонкам Черновик, Активный, Готовый и Завершённый" width="3456" height="1984" data-path="images/replitai/task-board-progress.png" />
</Frame>

По мере выполнения каждая задача перемещается слева направо, поэтому вы с одного взгляда видите, что запланировано, над чем работает Agent, что готово к проверке и что уже завершено. Фоновые задачи ставятся в очередь автоматически в соответствии с вашим планом, так что работа продолжается, не перегружая основную ветку.

Когда задача готова, вы просматриваете изменения и применяете их к основной версии либо отклоняете, если это не то, чего вы хотели.

<div id="how-background-tasks-work">
  ## Как работают фоновые задачи
</div>

<Steps>
  <Step title="Спланируйте задачи">
    Начните разговор в основной ветке или создайте новую ветку и составьте план в ней. Agent анализирует ваш project, определяет, что принесёт наибольшую пользу, и составляет подробный план для каждой задачи: что будет сделано и по каким критериям задача будет считаться завершённой.

    <Frame>
      <img src="/assets/mirror/task-describe-idea-555338f515fd.png" alt="Описание того, что нужно создать, в основной ветке: Agent предлагает и запускает задачи" width="3430" height="1986" data-path="images/replitai/task-describe-idea.png" />
    </Frame>
  </Step>

  <Step title="Проверьте и примите">
    Agent предлагает набор задач, каждая из которых включает название, описание и подробный план, доступный по кнопке **View plan**. Просмотрите весь список, затем выберите:

    * **Accept tasks**: запустить все задачи и отправить их в фоновый режим
    * **Revise plan**: попросить Agent скорректировать задачи перед запуском

    <Frame>
      <img src="/assets/mirror/task-accept-plans-d70b85ce3421.png" alt="Диалог с созданными планами задач, в котором показаны четыре предложенные задачи и варианты Accept tasks и Revise plan" width="3430" height="1986" data-path="images/replitai/task-accept-plans.png" />
    </Frame>
  </Step>

  <Step title="Задачи начинают выполняться">
    После принятия задачи запускаются в изолированных копиях вашего project. план Starter не поддерживает фоновые задачи. Core выполняет по 1 задаче за раз, Pro поддерживает до 10 задач, а Enterprise — до 64. Основная версия остаётся без изменений, пока вы не решите их применить. Отслеживать прогресс можно двумя способами:

    * **Просмотр веток**: каждая задача выполняется в собственной ветке с индикатором текущего статуса, поэтому вы можете следить за ходом работы или перейти к обсуждению любой задачи

    <Frame>
      <img src="/assets/mirror/task-plan-sidebar-ecab81b06bb0.png" alt="Просмотр веток с несколькими параллельно выполняющимися задачами и индикаторами статуса" width="3430" height="1986" data-path="images/replitai/task-plan-sidebar.png" />
    </Frame>

    * **Просмотр доски**: доска с колонками, на которой все задачи упорядочены по статусу: **Черновик**, **Активный**, **Готовый** и **Завершённый**

    <Frame>
      <img src="/assets/mirror/task-board-active-355ecd390c49.png" alt="Просмотр доски с задачами, распределёнными по колонкам Черновик, Активный, Готовый и Завершённый" width="3430" height="1986" data-path="images/replitai/task-board-active.png" />
    </Frame>
  </Step>

  <Step title="Проверьте и примените">
    Когда задача завершается, Agent показывает результаты: журнал работы, результаты тестов и предварительный просмотр изменений в реальном времени. Вы решаете, что делать дальше:

    * **Применить изменения к основной версии**: объединить результаты работы задачи с вашим project
    * **Отклонить**: отменить изменения, если они не соответствуют вашим ожиданиям

    Agent автоматически разрешает конфликты при применении изменений из нескольких задач.

    <Frame>
      <img src="/assets/mirror/task-review-apply-3ef379c7e976.png" alt="Экран проверки задачи с журналом работы Agent, результатами тестов и кнопкой Apply changes" width="3456" height="1984" data-path="images/replitai/task-review-apply.png" />
    </Frame>
  </Step>
</Steps>

<div id="what-you-can-build">
  ## Что можно создать
</div>

Система задач подходит для любого проекта. Вот несколько сценариев, где она особенно полезна:

* **Выпускайте крупные функции по частям**: разделите аутентификацию, панель управления и слой API на отдельные задачи, чтобы Agent мог аккуратно проработать каждую из них
* **Планируйте сложные проекты**: разбейте крупную функцию на чётко очерченные задачи с зависимостями и уверенно выполните их
* **Сравнивайте разные варианты дизайна**: используйте отдельные задачи, чтобы опробовать несколько подходов к интерфейсу, а затем выберите лучший результат

<div id="frequently-asked-questions">
  ## Часто задаваемые вопросы
</div>

<Accordion title="Нужно ли мне менять подход к разработке?">
  Нет. Основная ветка работает точно так же. Agent автоматически создаёт задачи в фоне, когда это полезно. Вы также можете использовать [режим Plan](/ru/features/agent/plan-mode), чтобы явно видеть задачи и управлять ими.
</Accordion>

<Accordion title="Почему мои задачи выполняются по одной?">
  План Starter не поддерживает фоновые задачи. Core выполняет 1 задачу одновременно, Pro — до 10, а Enterprise — до 64. При достижении лимита вашего плана остальные задачи встают в очередь и запускаются по мере освобождения слотов.
</Accordion>

<Accordion title="Как Agent разрешает конфликты при применении фоновых задач?">
  Agent разрешает конфликты с помощью ИИ. Он понимает, чего именно должна была достичь каждая задача, и применяет изменения осмысленно. Если что-то выглядит не так, попросите Agent исправить это прямо в треде.
</Accordion>

<Accordion title="Могут ли задачи зависеть друг от друга?">
  Да. Agent автоматически определяет зависимости. Например, задача по созданию панели управления зависит от задачи, которая создаёт схему базы данных. Зависимые задачи ждут завершения задач, от которых они зависят.
</Accordion>

<Accordion title="Чем архивирование задачи отличается от её отмены?">
  **Архивирование** применяется к сессиям планирования — черновикам, работа над которыми ещё не началась. Архивированные сессии планирования сохраняются, и их можно восстановить из колонки **Завершённый**.

  **Отмена** применяется к задачам, которые уже перешли от планирования к разработке. Отмена останавливает задачу и отбрасывает её результаты; отменённые задачи восстановить нельзя — вместо этого запустите новую задачу.
</Accordion>
