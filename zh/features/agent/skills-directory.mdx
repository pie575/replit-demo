Skills 目录汇集了由 Replit 及合作伙伴打造的现成 skills，安装后即可使用。先装一个试试，再根据团队的实际工作方式进行调整。

关于 skill 是什么以及 Agent 如何加载它，请参阅 [Agent skills](/zh/features/agent/skills)。若要让某个 skill 在整个 workspace 中可用，请参阅 [Agent 自定义](/zh/features/agent/agent-customization)。

<div id="install-a-skill">
  ## 安装 skill
</div>

你可以通过以下几种方式从目录中添加 skill：

* **在聊天中** —— 点击聊天输入框旁边的 **+** 按钮，选择 **Use a skill**，然后挑选一个。该 skill 仅对当前这条消息生效，不会在你的 project 中安装任何内容。
* **在 project 中** —— 在 Project Editor 中打开 **Skills pane**，切换到 **Discover** 标签页，找到需要的 skill，点击 **Install**。已安装的 skills 存放在 project 的 `/.agents/skills` 目录中，并可跨多次聊天持续保留。
* **通过命令行** —— 使用 [skills CLI](https://github.com/vercel-labs/skills) 安装 skill：

  ```bash theme={null}
  npx skills <skill> -a replit
  ```

<Warning>
  Replit skill 选择器中的 skills 均已通过安全审核，而从外部来源安装的 skills 则没有。由于 skill 本质上就是 Agent 会遵循的指令，安装前请务必先审查外部 skill —— 参见 [Agent skills](/zh/learn/agent-skills)，了解需要检查哪些内容。
</Warning>

<div id="replit-skills">
  ## Replit skills
</div>

Replit 内置了一系列预定义 skills，可从 Chat 中的 **Use a skill** 选择器以及新建 project 的起始点选择器中调用。这些 skills 无需安装即可在所有 project 中使用。打开选择器时，各项说明会随列表一同显示。

| 类别     | Skills                                                                                                   |
| ------ | -------------------------------------------------------------------------------------------------------- |
| 销售与营销  | Ad Creative、AI SDR、SEO Auditor、Programmatic SEO、GEO、Content Machine、Storyboard                           |
| 职业发展   | AI Recruiter、Resume Maker、Interview Prep                                                                 |
| 研究与分析  | Competitive Analysis、Deep Research、GitHub Solution Finder、Supplier Research                              |
| 商业与财务  | Stock Analyzer、Excel Generator、Invoice Generator、Tax Reviewer                                            |
| 文档与工具  | Website Cloner、File Converter、Flashcard Generator、Legal Contract、Infographic Builder、Recreate Screenshot |
| 创意     | Photo Editor、Podcast Generator、Podcast Marketing、Branding Generator、Video Editing                        |
| 效率工具   | AI Secretary、Product Manager、Design Thinker、Skill Finder、Skill Creator                                   |
| 个人     | Travel Assistant                                                                                         |
| 安全与合规  | Secrets、Sensitive Data、Input Validation、AI Security、Dependency Vetting、License Check                     |
| 质量与可靠性 | Accessibility、Responsive UI、Observability、Resilience、Ship Review                                         |

<Note>
  在 workspace 中，该选择器还会自动发现安装在 project 的 `.local/secondary_skills/` 目录下的其他 skills。
</Note>

<div id="partner-skills">
  ## 合作伙伴 skills
</div>

Replit 的合作伙伴会发布 skills，教 Agent 如何使用他们的产品进行构建。安装其中一个，即可让 Agent 掌握该服务的模式与约定。

| 合作伙伴             | 教会 Agent 的内容                   |
| ---------------- | ------------------------------ |
| Stripe           | 支付与账单集成模式                      |
| PayPal           | 支付集成模式                         |
| RevenueCat       | 订阅与应用内购买模式                     |
| Mixpanel         | 分析与追踪的实现方式                     |
| BigQuery         | 数据仓库查询模式                       |
| Resend           | 事务性邮件集成                        |
| Google Workspace | Gmail、Drive、Docs 与 Calendar 集成 |
| Atlassian        | Jira 与 Confluence 的事务和页面工作流    |
| Google Maps      | 地图、地点、路线与地理编码集成                |

<div id="community-skills">
  ## 社区 skills
</div>

除了 Replit 和合作伙伴提供的 skills，社区也会发布可供你安装的 skills。你可以在 [skills.sh](https://skills.sh) 浏览，也可以阅读 [Agent Skills 规范](https://agentskills.io/specification) 来编写自己的 skills。
