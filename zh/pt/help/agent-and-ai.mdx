以下内容解答了使用 Agent 时的常见问题。完整参考请参阅 [Agent 概览](/zh/pt/features/agent/overview)、[Agent 模式](/zh/pt/features/agent/agent-modes)和 [AI 计费](/zh/pt/billing/ai-billing)。

<AccordionGroup>
  <Accordion title="Agent 卡住或频繁断开连接，该如何解决？">
    1. 使用 `Cmd+K` (Mac) 或 `Ctrl+K` (Windows) 打开命令面板。
    2. 搜索 **Restart compute**，然后选择该选项以重启开发环境。
    3. 打开新的 Agent Chat，再次描述你的任务以继续操作。

    如果 Agent 看起来卡住了，请不要继续发送消息——额外消息会导致指令冲突。如果 Agent 在同一任务上反复卡住，请将任务拆分为更小、更聚焦的提示词。
  </Accordion>

  <Accordion title="Agent 陷入循环或反复执行相同步骤时，如何停止？">
    1. 在 Agent 面板中选择 **停止**，立即将其停止。
    2. 使用 `Cmd+K` (Mac) 或 `Ctrl+K` (Windows) 打开命令面板，搜索 **Restart compute** 并选择该选项。
    3. 打开新的 Agent Chat，更具体地重新描述你的任务。

    为避免陷入循环：

    * 将大型任务拆分为更小的提示词——每条消息只包含一个目标。
    * 使用[规划模式](/zh/pt/features/agent/plan-mode)，在 Agent 开始构建前明确工作范围。
    * 在[管理支出](/zh/pt/billing/managing-spend)中设置使用限额，避免循环导致高额账单。
  </Accordion>

  <Accordion title="如何降低 Agent 成本——哪些设置确实有效？">
    以下这些选择最能帮您节省开支：

    * **[Free Mode](/zh/pt/features/agent/agent-modes)**—Core 和 Pro 订阅者可在额度内免费使用 Agent 完成日常任务。
    * **[Power 模式](/zh/pt/features/agent/agent-modes)**—需要时以实惠的价格获得更强性能。
    * **[规划模式](/zh/pt/features/agent/plan-mode)**—在 Agent 开始构建前确定范围并批准方案，避免为不需要的更改付费。
    * **使用限额和预算**—在[管理您的支出](/zh/pt/billing/managing-spend)中设置最高限额。

    切换任务时，新开一个 Agent 聊天也会有所帮助。查看使用情况面板，了解哪些任务的成本最高。
  </Accordion>

  <Accordion title="Agent 有哪些模式？它们之间有何区别？">
    Agent 有三种主要模式。有关完整说明，请参阅 [Free Mode](/zh/pt/help/free-agent-mode)。

    * **Free Mode**—Core 和 Pro 订阅者可免费使用 Agent 处理日常任务，配额每五小时重置一次，并设有每周上限。Starter 套餐维持现有上限。请查看 **设置 → 使用情况** 了解你的用量。
    * **Power**—价格实惠的中档付费模式，配备强大的模型。
    * **Max**—高端付费模式，配备最先进的顶级模型，适合处理要求最高的任务。
    * **Turbo**—高级设置中的可选开关，仅在 Max 模式下可用。

    付费模式已更名。**Economy 现更名为 Power**，此前名为 **Power 的模式现更名为 Max**。现有模式设置会保留，并使用新名称。如果某项请求所需的能力超出 Free Mode 所能提供的范围，Agent 可能会提供付费的 **允许一次** 选项。付费操作开始前，Replit 会请求确认，之后 Agent 会返回 Free Mode。

    此外，[规划模式](/zh/pt/features/agent/plan-mode) 可让 Agent 在进行更改前确定工作范围，而 modo de criação 会直接应用更改。请参阅[规划模式与创建模式](/zh/pt/learn/plan-vs-build-mode)。
  </Accordion>

  <Accordion title="Agent 做了你不想要的更改——如何撤销？">
    Replit 会在 Agent 工作期间保存 [checkpoint](/zh/pt/features/version-control/checkpoints-and-rollbacks)。在 Agent Chat 中，找到所要撤销更改之前的消息，然后选择该消息旁的回退选项，将项目恢复到该节点。

    如需了解完整的回退选项 (包括恢复特定文件) ，请参阅 [Checkpoints 和回退](/zh/pt/features/version-control/checkpoints-and-rollbacks)。
  </Accordion>

  <Accordion title="Agent 表示无法访问互联网或外部 API——这是正常现象吗？">
    在创建和编辑阶段，Agent 会在出站访问受限的沙盒环境中工作。已部署的应用在运行时仍可调用外部 API——沙盒限制适用于 Agent 的编辑环境，而非正在运行的应用。

    如果正在运行的应用中的 API 调用失败，请确认密钥已保存到 [Secrets](/zh/pt/core-concepts/project-editor/app-setup/secrets) 面板中，然后查看模型提供方的状态页面。在企业或学校网络中，应用的出站连接可能会被阻止——请向网络管理员确认。
  </Accordion>

  <Accordion title="我可以在 Agent 中使用自己的 API 密钥吗？">
    可以。将密钥添加到 [Secrets](/zh/pt/core-concepts/project-editor/app-setup/secrets) 面板后，您的应用即可在 API 调用中使用这些密钥。打开 **Secrets** 工具，选择 **+ 新建密钥**，然后输入名称 (例如 `OPENAI_API_KEY`) 和值。

    您可以[使用自己的 AI 模型提供方密钥](/zh/pt/features/integrations/replit-ai-integrations)，供应用调用相应模型。为 Agent 体验本身提供支持的模型在 Replit 的基础设施上运行，无法替换。
  </Accordion>

  <Accordion title="Agent 总是添加我没有要求的功能——如何让它更准确地按我的要求执行？">
    使用更具体的提示词，让 Agent 保持专注：

    * 以 *仅* 开头——例如，&quot;仅在用户卡片上添加一个删除按钮。不要更改其他任何内容。&quot;
    * 先使用[规划模式](/zh/pt/features/agent/plan-mode)，在进行任何更改前查看 Agent 计划执行的操作。
    * 如果 Agent 做出了不需要的更改，请立即在同一 Chat 中要求撤销该更改。

    如需了解更多信息，请参阅[如何编写有效提示词](/zh/pt/learn/effective-prompting)。
  </Accordion>
</AccordionGroup>
