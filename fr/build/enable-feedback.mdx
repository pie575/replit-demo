Vous pouvez activer la collecte de retours sur vos apps publiées afin de recueillir directement les avis des visiteurs et de les envoyer à Agent. Une fois cette fonctionnalité activée, les visiteurs peuvent envoyer des retours, y compris des captures d’écran et des fichiers, que vous pouvez gérer dans votre boîte de réception.

<div id="enabling-feedback">
  ## Activer les retours
</div>

<Warning>
  Vous pouvez activer les retours uniquement pour les web apps. Cette fonctionnalité n&#39;est pas disponible pour d&#39;autres types d&#39;apps, comme les automatisations ou les apps mobiles.
</Warning>

Lors de la publication d&#39;une nouvelle app, activez le paramètre **Activer les retours** dans la boîte de dialogue de publication. Si votre app a déjà été publiée, vous pouvez activer les retours en la republiant :

1. Ouvrez l&#39;outil Publishing
2. Sélectionnez **Paramètres avancés**
3. Activez **Activer les retours**
4. Republiez votre app

<div id="submitting-feedback">
  ## Envoyer des retours
</div>

Lorsque les retours sont activés sur une application publiée, les visiteurs peuvent en envoyer directement depuis l&#39;application. Les utilisateurs peuvent :

* Se connecter pour envoyer un retour
* Envoyer un retour textuel décrivant leur expérience ou leurs suggestions
* Sélectionner des éléments pour illustrer des problèmes ou des fonctionnalités
* Téléverser des fichiers pour fournir un contexte supplémentaire

<div id="managing-feedback-in-your-inbox">
  ## Gérer les retours dans votre boîte de réception
</div>

Tous les retours envoyés par les visiteurs apparaissent dans votre boîte de réception, accessible depuis le Project Editor. Depuis la boîte de réception, vous pouvez :

* **Ajouter au Chat** : envoyer un retour dans votre conversation avec Agent pour ajouter du contexte avant de l&#39;envoyer
* **Envoyer à Agent** : envoyer immédiatement un retour à Agent et commencer à travailler dessus
* **Résoudre** : marquer un retour comme résolu une fois qu&#39;il a été traité
* **Supprimer** : supprimer les retours qui ne sont plus nécessaires

Vous pouvez également utiliser des filtres pour organiser et retrouver des retours spécifiques.

<div id="republishing-with-updated-feedback-settings">
  ## Republier avec des paramètres de retour mis à jour
</div>

Après avoir publié votre app, vous pouvez activer ou désactiver le widget de retour à tout moment en la republiant avec des paramètres mis à jour :

1. Ouvrez l’onglet **Overview** de l’outil Publishing
2. Sélectionnez **Paramètres avancés**
3. Activez ou désactivez **Activer les retours**
4. Republiez votre app pour appliquer les modifications

Toute modification du paramètre de retour prend effet une fois l’app republiée.
