SEO Agent 会对你的 project 进行一次技术性 SEO 审计，找出影响搜索引擎和 AI 爬虫发现并理解你的应用的问题。每一条 finding 都会转化为一项可一键修复的操作，你可以先审阅，再交由 Agent 应用。

该功能位于 Project Editor 的 **Growth** 面板中，适用于已发布的应用。对大多数构建者来说，典型流程是：发布应用、打开 SEO Agent、运行扫描、审阅 findings，然后应用修复。

<div id="what-seo-agent-does">
  ## SEO Agent 的作用
</div>

SEO Agent 专注于**技术 SEO**，即应用中那些结构化、机器可读的部分，它们决定了搜索引擎和 AI 爬虫能否顺利发现、索引并理解你的应用。

它会检查你的 project，并针对以下问题提出修复建议：

* **可抓取性与索引**：`robots.txt`、`sitemap.xml`，以及可抓取的链接和页面结构。
* **页面元数据**：每个页面都有唯一且具描述性的 `<title>` 标签和 meta 描述。
* **结构化数据**：帮助搜索引擎展示富媒体结果的 JSON-LD 标记。
* **Open Graph 与社交标签**：控制链接被分享时预览效果的元数据。
* **语义化标记**：正确的标题层级顺序、地标元素，以及图片上具描述性的 `alt` 文本。

<Note>
  SEO Agent 只负责确保你构建的应用在搜索方面技术过硬，
  不会为你撰写内容或建立主题权威度。
</Note>

<div id="before-you-start">
  ## 开始之前
</div>

使用 SEO Agent 需要满足以下条件：

* **已发布的应用。** SEO Agent 审计的是已上线的公开网页 deployment，因此如果你尚未发布应用，请先完成发布。有关支持 SEO 的 deployment 类型，请参阅 [SEO 评级](/zh/features/publishing/seo-rating)。
* **付费方案。** SEO Agent 仅面向付费方案用户开放。如果你使用的是免费方案，会在 Growth 面板中看到升级选项。

有两种方式可以打开 SEO Agent：直接在 Project Editor 中打开 **Growth** 面板；或在 **Publishing** 工具中点击 SEO 评级旁的 **Optimize SEO with Agent**，随即打开 Growth 面板并可直接开始扫描。

<Tip>
  若要控制应用分享到社交平台时的预览效果，请连接
  [自定义域名](/zh/build/add-custom-domain)并重新发布。社交平台和链接
  预览使用的是应用的公开生产环境 URL，因此发布自定义域名后即可获得准确的预览效果。
</Tip>

<div id="seo-agent-and-your-seo-rating">
  ## SEO Agent 与你的 SEO 评级
</div>

SEO Agent 旁显示的 **SEO 评级**来自每次发布后自动运行的 [Lighthouse 审计](/zh/features/publishing/seo-rating)，它会将你的应用评为 Healthy、Needs Work 或 Weak。评级告诉你*应用目前处于什么水平*，而 SEO Agent 则通过扫描问题并应用修复来帮你*提升水平*。修复后重新发布，评级即会刷新。

你也可以完全跳过扫描界面，直接向 Agent 提出要求：

<AiPrompt>
  审计我的网站是否符合 SEO 最佳实践，并应用修复。添加 sitemap、robots.txt、Open Graph
  标签，在合适的地方添加结构化数据，并确保每个页面都有唯一的标题和 meta description。
</AiPrompt>
