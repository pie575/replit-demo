App Storage est le stockage d&#39;objets intégré de Replit qui permet à votre app d&#39;héberger et d&#39;enregistrer facilement des fichiers téléversés, comme des images, des vidéos et des documents.
Les buckets sont des conteneurs destinés au stockage d&#39;objets tels que des fichiers. Ils intègrent des politiques d&#39;accès qui limitent les actions que les utilisateurs ou les applications peuvent effectuer sur leur contenu.

<Info>
  Nous avons renommé <strong>Object Storage</strong> en <strong>App Storage</strong>. Les fonctionnalités restent inchangées et vos buckets, permissions et accès programmatiques existants continuent de fonctionner.
</Info>

Avec App Storage, vous pouvez créer des apps telles que :

* **Plateformes de partage de photos** : permettez aux créateurs de téléverser, de stocker et d&#39;afficher des images
* **Services de diffusion vidéo** : gérez le téléversement de vidéos et diffusez le contenu aux spectateurs
* **Systèmes de gestion documentaire** : stockez et organisez les fichiers des créateurs avec un accès sécurisé
* **Sites portfolio** : présentez vos travaux avec des fichiers multimédias qui se chargent de façon fiable
* **Services de sauvegarde de fichiers** : offrez aux créateurs un stockage cloud pour leurs fichiers importants

<Note>
  Demandez à **Agent** d&#39;ajouter App Storage à votre app en précisant les types de fichiers qu&#39;elle doit gérer. Agent met en place l&#39;intégration, crée les buckets nécessaires et met à jour votre app pour téléverser, stocker et récupérer des fichiers avec des fonctionnalités avancées comme l&#39;authentification et les contrôles d&#39;accès.
</Note>

L&#39;outil App Storage vous permet de partager facilement des données entre vos
environnements de développement et de production, ou avec d&#39;autres Replit Apps.

<div id="features">
  ## Fonctionnalités
</div>

<Info>
  App Storage repose sur Google Cloud Storage (GCS).
  Vous bénéficiez ainsi d&#39;un uptime, d&#39;une disponibilité et d&#39;une sécurité
  parmi les meilleurs du secteur.
</Info>

App Storage offre les fonctionnalités suivantes pour vos Replit Apps :

* **Stockage cloud persistant** : conservez des fichiers qui restent accessibles à votre application publiée et à ses utilisateurs
* **Gestion évolutive des fichiers** : répondez à des besoins de données croissants sans vous soucier des limites de stockage
* **Partage de données entre applications** : partagez des buckets entre plusieurs Replit Apps pour des architectures distribuées
* **Accès programmatique** : téléversez, téléchargez et gérez vos fichiers à l&#39;aide d&#39;API intuitives
* **Intégration Agent améliorée** : laissez Agent configurer App Storage avec des paramètres avancés, inspecter les configurations existantes et générer l&#39;intégralité du code backend et frontend, avec authentification et contrôles d&#39;accès

Voici quelques façons d&#39;utiliser App Storage dans vos Replit Apps :

* Stocker les photos de profil des créateurs et les médias téléversés
* Diffuser les images de produits sur des sites d&#39;e-commerce
* Gérer les documents téléversés via des formulaires
* Créer des fonctionnalités de partage de fichiers et de collaboration
* Concevoir des systèmes de gestion de contenu avec médiathèques

<Tip>
  **Intégration Agent améliorée** : vous pouvez demander à [Replit Agent](/fr/features/agent/overview) d&#39;ajouter automatiquement App Storage à vos applications ! Agent peut désormais mettre en place le stockage d&#39;objets, inspecter les configurations et générer l&#39;intégralité du code backend et frontend avec des fonctionnalités avancées comme l&#39;authentification et les contrôles d&#39;accès. Il suffit de mentionner « App Storage » ou « stockage de fichiers » dans votre prompt.

<div id="usage">
  ## Utilisation
</div>

<Note>
  Votre Replit App doit s&#39;authentifier auprès de Google Cloud Storage pour accéder à un bucket et à ses objets.
  Utilisez les bibliothèques clientes officielles Replit App Storage pour vous authentifier automatiquement.
</Note>

Vous pouvez accéder à l&#39;outil App Storage directement depuis votre Project Editor.

<Accordion title="Comment accéder à l'outil App Storage">
  Depuis le **Tool dock** à gauche :

  1. Sélectionnez <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Icône Tous les outils" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools** pour afficher la liste des outils du Project Editor.
  2. Sélectionnez <img class="icon-svg" src="/assets/mirror/object-storage-monoochrome-icon-aaba8f517280.svg" alt="Icône App Storage" width="16" height="16" data-path="images/icons/object-storage-monoochrome-icon.svg" /> **App Storage**.

  Depuis la **barre de recherche** :

  1. Sélectionnez la <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="icône loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> loupe en haut pour ouvrir l&#39;outil de recherche.
  2. Saisissez « App Storage » pour trouver l&#39;outil, puis sélectionnez-le dans les résultats.
</Accordion>

Pour associer un nouveau bucket de stockage à votre Replit App, créez un bucket.

<Accordion title="Comment créer un bucket">
  Depuis l&#39;outil **App Storage** :

  1. Cliquez sur **Create new bucket**.
  2. Saisissez un nom pour le bucket dans le champ **Name**, puis sélectionnez **Create bucket**.

  L&#39;onglet App Storage devrait ressembler à la capture d&#39;écran suivante :

  <Frame>
    <img src="/assets/mirror/object-storage-empty-bucket-3462e2efb1bc.png" alt="capture d'écran de l'outil App Storage" width="2790" height="1218" data-path="images/databases/object-storage-empty-bucket.png" />
  </Frame>

  Pour créer d&#39;autres buckets, ouvrez le menu déroulant des buckets en haut à gauche de l&#39;onglet **App Storage** et sélectionnez **Create new bucket**.
</Accordion>

<div id="access-the-bucket-id">

</div>

Pour afficher le **Bucket ID**, sélectionnez la vue **Settings** dans le menu déroulant en haut de l&#39;onglet **App Storage**.
Le Bucket ID identifie le bucket de manière unique ; votre code doit y faire référence pour effectuer une opération.

Si vous disposez de plusieurs buckets, sélectionnez celui qui convient dans le menu déroulant situé en haut à gauche.

<div id="upload-or-download-objects">
  ### Téléverser ou télécharger des objets
</div>

Pour téléverser un objet dans le bucket sélectionné :

1. Accédez à la vue **Objects** dans l&#39;onglet **App Storage**.
2. Sélectionnez <img class="icon-svg" src="/assets/mirror/upload-file-5894be4232ce.svg" alt="icône de téléversement de fichier" width="16" height="16" data-path="images/icons/upload-file.svg" /> **Upload files**, ou <img class="icon-svg" src="/assets/mirror/upload-folder-fc87519bedf9.svg" alt="icône de téléversement de dossier" width="16" height="16" data-path="images/icons/upload-folder.svg" /> **Upload folder** pour téléverser tous les fichiers d&#39;un dossier.
   Choisissez ensuite un ou plusieurs fichiers à téléverser dans la boîte de dialogue.
   Vous pouvez également faire glisser un fichier ou un dossier dans la zone qui affiche le contenu du bucket.

Pour télécharger un objet depuis le bucket sélectionné :

1. Accédez à la vue **Objects** dans l&#39;onglet **App Storage**.
2. Sélectionnez l&#39;icône de téléchargement <img class="icon-svg" src="/assets/mirror/download-icon-c7b527953d65.svg" alt="icône de téléchargement" width="16" height="16" data-path="images/icons/download-icon.svg" /> à droite du fichier pour le télécharger.

<div id="organize-objects-in-folders">
  ### Organiser les objets dans des dossiers
</div>

Pour créer un dossier dans le bucket sélectionné :

1. Accédez à la vue **Objects** dans l&#39;onglet **App Storage**.
2. Sélectionnez <img class="icon-svg" src="/assets/mirror/create-folder-c9acf112a042.svg" alt="icône de création de dossier" width="16" height="16" data-path="images/icons/create-folder.svg" /> **Create Folder** dans la vue **Objects**.
3. Saisissez un nom pour le dossier.

Pour ajouter des objets à un dossier dans la vue **Objects**, faites glisser un objet vers le dossier de destination.

Pour déplacer l&#39;objet vers un dossier parent, faites-le glisser au-dessus de l&#39;en-tête, sur le nom du dossier affiché au-dessus de la liste des objets.
L&#39;animation suivante illustre le déplacement du fichier « product&#95;demo.mov » du dossier « videos » vers le dossier parent « Objects » :

<div id="delete-objects-or-buckets">
  ### Supprimer des objets ou des buckets
</div>

<Warning>
  La suppression est irréversible. Veillez à sauvegarder toutes les données essentielles avant de continuer.
</Warning>

Pour supprimer définitivement un objet :

1. Accédez à la vue **Objects** de l&#39;onglet **App Storage**.
2. Sélectionnez l&#39;icône de corbeille <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="icône de corbeille" width="16" height="16" data-path="images/icons/trash-icon.svg" />
   située à côté de l&#39;objet à supprimer.
3. Confirmez la suppression dans la boîte de dialogue.

Pour supprimer un bucket et tous les objets qu&#39;il contient :

1. Accédez à la vue **Settings** de l&#39;onglet **App Storage**.
2. Vérifiez que le bucket à supprimer est bien sélectionné dans le menu déroulant des buckets, en haut à gauche.
3. Sélectionnez <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="icône de corbeille" width="16" height="16" data-path="images/icons/trash-icon.svg" /> **Delete Bucket**.
4. Confirmez la suppression dans la boîte de dialogue.

<div id="bucket-access-management">
  ### Gestion des accès aux buckets
</div>

Replit associe à votre compte tous les buckets que vous créez et les met à disposition de
toutes vos Replit Apps. La Replit App depuis laquelle vous créez le bucket y
obtient automatiquement accès.

Vous pouvez contrôler quelles Replit Apps ont accès à un bucket donné, ce qui vous permet de
partager vos données efficacement et en toute sécurité.

Pour donner à votre Replit App l&#39;accès à un bucket appartenant à une autre app de votre compte :

1. Sélectionnez <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="icône de loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" />
   **Add an existing bucket** dans le menu des buckets, en haut à gauche de l&#39;onglet App Storage.
2. Dans la boîte de dialogue **Choose a Bucket**, choisissez le bucket à ajouter, puis sélectionnez **Add Bucket to Repl**.

<Frame>
  <img src="/assets/mirror/choose-bucket-dialog-b709aa247a85.png" alt="capture d'écran de la boîte de dialogue de choix du bucket" width="1115" height="457" data-path="images/databases/choose-bucket-dialog.png" />
</Frame>

Pour révoquer l&#39;accès de votre Replit App à un bucket :

1. Accédez à la vue **Settings** dans l&#39;onglet **App Storage**.
2. Dans le menu déroulant des buckets, en haut à gauche de l&#39;onglet, sélectionnez le nom du bucket.
3. Sélectionnez **Remove Bucket from Repl**, puis confirmez la suppression dans la boîte de dialogue de confirmation.

<div id="programmatic-access-to-app-storage">
  ### Accès programmatique à App Storage
</div>

Pour accéder à App Storage depuis votre Replit App, utilisez l&#39;une des bibliothèques suivantes :

* le SDK Replit App Storage, disponible pour JavaScript et Python
* la <a href="https://cloud.google.com/storage/docs/reference/libraries" target="_blank">bibliothèque cliente Google Cloud Storage</a>

Pour savoir comment utiliser ces bibliothèques clientes, consultez les ressources suivantes :

* [SDK App Storage JavaScript](/fr/features/sdks/object-storage-javascript-sdk/) : référence client du SDK JavaScript
* [SDK App Storage Python](/fr/features/sdks/object-storage-python-sdk/) : référence client du SDK Python
* [Exemple d&#39;application avec le SDK Google Cloud Python](https://replit.com/@matt/GCS-Python-Uploads?v=1) : remixez cette application pour gérer vos objets avec le SDK Google Cloud Python
