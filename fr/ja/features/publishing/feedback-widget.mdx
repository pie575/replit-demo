---
title: "Widget de feedback"
description: "Ajoutez un widget de feedback à votre application publiée pour permettre aux visiteurs de signaler des problèmes ou de proposer des idées, puis envoyez directement leurs retours à Agent pour les corriger."
---

Le widget de feedback ajoute un bouton de commentaires dans un coin de votre application publiée. Les visiteurs peuvent signaler des problèmes ou proposer des améliorations sans quitter l’application. Vous pouvez envoyer directement les retours reçus à Agent pour demander des corrections.

<div id="section">
  ## Activer le widget de feedback
</div>

1. Dans le volet **Tools**, sélectionnez **Publishing** sous **Replit Cloud**, ou **Publier** en haut à droite du Project Editor pour ouvrir l’outil Publishing.
2. Sous **Engagement tools**, activez **Enable feedback widget**.
3. Sélectionnez **Publier**. Le widget s’affichera dans votre application publiée.

<div id="section-2">
  ## Position et apparence
</div>

Lorsque vous activez le widget, deux paramètres s&#39;affichent :

* **Position du widget** : choisissez le coin de l&#39;App où afficher le widget : en haut à gauche, en haut à droite, en bas à gauche ou en bas à droite. Par défaut, il s&#39;affiche en bas à droite.
* **Apparence** : importez une icône personnalisée pour le bouton du widget et choisissez une couleur d&#39;arrière-plan pour l&#39;harmoniser avec l&#39;apparence de votre App.

<div id="section-3">
  ## Consulter les commentaires et y répondre
</div>

Les messages envoyés par les visiteurs arrivent dans la boîte de réception. Vous pouvez ensuite :

* Lire chaque message pour comprendre les problèmes rencontrés par les visiteurs.
* Envoyer les messages à Agent pour lui demander de les résoudre. Agent traite les commentaires comme des tâches et propose des modifications à l’application.

<div id="section-4">
  ## Désactiver
</div>

Dans l’outil Publishing, désactivez **Enable feedback widget**, puis publiez à nouveau. Le widget disparaîtra de l’application publiée.
