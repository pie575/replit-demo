<div id="checkpoint-previews">
  ### Aperçus des checkpoints
</div>

Découvrez les aperçus de checkpoints dans l&#39;environnement de développement Replit. Visualisez votre app à différentes étapes de son développement, sans avoir à recréer ni restaurer des versions précédentes.

<div id="replit-time-travel">
  ### Voyage dans le temps sur Replit
</div>

La fonctionnalité de voyage dans le temps est désormais disponible sur Replit. Parcourez facilement l’historique de votre projet tout en conservant votre contexte de développement.

Explorez différentes versions, comprenez les évolutions, revenez sur vos erreurs et expérimentez avec plus de confiance, le tout dans votre environnement de développement actuel. Cette fonctionnalité complète l’[intégration Git](/fr/learn/projects-and-artifacts/version-control) pour un contrôle de version plus puissant.

<div id="ask-agent-to-add-a-database">
  ### Demandez à Agent d’ajouter une base de données
</div>

La configuration d’une base de données est simplifiée grâce à l’intégration d’Agent dans le volet DB. Ce flux de travail basé sur l’IA vous guide tout au long de la configuration de votre base de données et facilite la mise en œuvre de la persistance des données, sans code de configuration complexe.

Les développeurs peuvent se concentrer sur les fonctionnalités essentielles pendant qu’Agent gère les détails de la base de données. Pour en savoir plus, consultez [Replit Agent](/fr/core-concepts/agent) et les [options de base de données](/fr/learn/projects-and-artifacts/storage-and-databases).

<div id="replit-auth-matching-by-default">
  ### mise en correspondance Replit Auth par défaut
</div>

L&#39;authentification des utilisateurs dans vos apps devient simple grâce à l&#39;association automatique avec Replit Auth.

Cette fonctionnalité s&#39;active lorsque votre application nécessite une authentification. Elle élimine le besoin de formulaires d&#39;inscription personnalisés, de systèmes de récupération de mot de passe ou de configurations de connexion via les réseaux sociaux, pour une gestion des utilisateurs plus fluide et sécurisée.

<div id="full-screen-email-verification">
  ### Vérification de l’adresse e-mail en plein écran
</div>

Un processus de vérification simplifié pour les actions protégées renforce la sécurité des comptes.

Cette approche intégrée affiche la vérification de l’adresse e-mail après la connexion, lorsque nécessaire. Elle protège les comptes tout en offrant une expérience utilisateur cohérente, conciliant sécurité et simplicité.

Cette fonctionnalité s’inscrit dans notre engagement continu en faveur de la [sécurité de l’information](/fr/teams/information-security/overview).

<div id="google-analytics-blueprint">
  ### Blueprint Google Analytics
</div>

Surveillez les performances de votre application grâce au blueprint Google Analytics.

Agent intègre désormais la configuration des outils d&#39;analyse directement dans votre flux de développement. Vous pouvez ainsi suivre le trafic, le comportement des utilisateurs et vos indicateurs de croissance sans configuration complexe.

Des fonctionnalités d&#39;analyse professionnelles sont ainsi à la portée de tous les développeurs. Essayez-les avec les [intégrations d&#39;Agent](/fr/replitai/integrations).

<div id="scim-for-enterprise-customers">
  ### SCIM pour les clients Enterprise
</div>

La nouvelle intégration SCIM permet aux clients Enterprise de gérer les accès à Replit directement via leurs fournisseurs d’identité.

Connectez Okta, Active Directory, Rippling ou d’autres plateformes d’identité pour automatiser l’attribution et la suppression des licences Replit. Cela élimine la gestion manuelle des utilisateurs et simplifie les flux de travail en entreprise.

Consultez la [documentation SCIM détaillée](/fr/teams/identity-and-access-management/scim) pour commencer.

<div id="viewer-seats-for-replit-teams">
  ### Sièges observateurs pour Replit Teams
</div>

Voici les sièges observateurs pour Replit Teams. Partagez vos applications avec les parties prenantes qui se contentent de les consulter et de les utiliser — sans les modifier — sans avoir à leur attribuer une licence d&#39;équipe complète.

Idéal pour partager vos outils avec des dirigeants, des clients ou des collègues qui les utilisent sans les développer. Découvrez comment configurer et gérer les [sièges observateurs](/fr/teams/identity-and-access-management/viewer-seats).
