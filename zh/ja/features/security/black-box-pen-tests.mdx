黑盒渗透测试通过浏览器和网络交互，从外部验证正在运行的应用，不使用应用的源代码。

在项目安全中心，**Level 3 (AI pentest)** 会一次性执行以下三类安全检查：

1. 免费的依赖项和软件包检查
2. Agent 对源代码的静态分析
3. 不使用源代码、从外部测试实时 Preview 的黑盒测试

启动 Level 3 后，Replit 会并行执行 Agent 的源代码审查和外部黑盒测试。

<div id="level-3">
  ## 运行 Level 3 扫描
</div>

<Steps>
  <Step title="打开 项目">
    打开你要扫描的单个 项目。
  </Step>

  <Step title="打开 Security Center">
    在 项目 的 **Tools** 面板中选择 **Security Center**。
  </Step>

  <Step title="启动扫描">
    在 Security Center 顶部选择 **Run scan**。
  </Step>

  <Step title="选择 Level 3">
    选择 **Level 3 (AI pentest)**。

    <Frame caption="Level 3 (AI pentest) 在免费的依赖项和软件包检查之外，还增加了 Agent 静态分析和外部实时 Preview 测试。">
      <img src="/assets/mirror/level-3-ai-pentest-c223c0099d3f.png" alt="从 Tools 面板打开的 Security and Privacy Center，扫描级别选择菜单已展开，并选中了 Level 3 AI pentest" width="2204" height="1200" data-path="images/project-security-center/level-3-ai-pentest.png" />
    </Frame>
  </Step>

  <Step title="等待两项任务完成">
    等待源代码审查以及浏览器和网络黑盒测试这两项任务全部完成。
  </Step>

  <Step title="查看结果">
    在 **Security** 面板中查看两项任务的检测结果。在将你认可的问题发送给 Agent 之前，先逐条评估检测结果。
  </Step>

  <Step title="修复并重新运行">
    将你认可的检测结果发送给 Agent。应用修复后，再运行一次 Level 3 扫描以进行确认。
  </Step>
</Steps>

<div id="2">
  ## 了解两类任务
</div>

| 任务    | 依据              | 目的                     |
| ----- | --------------- | ---------------------- |
| 源代码审查 | 应用程序的源代码        | 识别代码库中的安全、隐私和架构漏洞      |
| 黑盒测试  | 与运行中应用的浏览器及网络交互 | 在不使用源代码的前提下,验证外部可观测的行为 |

请对两类检测结果都进行审查,二者不能相互替代:源代码审查可以定位存在缺陷的实现细节,黑盒测试则从外部评估运行中的应用。
