Подписка [Replit Core](https://replit.com/replit-core) открывает доступ к премиальным инструментам, которые помогают быстро превращать идеи в приложения. Актуальные тарифы Core (ежемесячные и годовые) указаны на [странице тарифов](https://replit.com/pricing).

<div id="section">
  ## Основные возможности
</div>

Подписка Core предоставляет следующие возможности:

<div id="ai">
  ### Инструменты на базе ИИ
</div>

* **Agent**: общайтесь с Agent в чате, чтобы создавать, отлаживать и дорабатывать приложения
* **Полная сборка**: используйте Economy или Power, когда нужно, чтобы Agent самостоятельно выполнял более крупные задачи
* **Lite-сборка**: точечные правки для быстрых изменений
* **Design Canvas**: прорабатывайте идеи визуально, создавайте варианты и превращайте дизайн в артефакты
* **Visual Editor**: редактируйте содержимое и макет приложения напрямую, в визуальном режиме
* **Все типы артефактов**: веб-приложения, мобильные приложения, визуализации данных, презентации, анимированные видео и многое другое
* **Plan Mode**: обдумывайте идеи и планируйте работу вместе с Agent, не редактируя код
* **Коннекторы**: интеграция со сторонними сервисами — Google, Stripe и другими

<div id="section-2">
  ### Совместная работа
</div>

* Приглашение до 5 разработчиков в рабочее пространство без отдельной подписки для команды
* Фоновые задачи — по одной активной задаче одновременно
* Общая канбан-доска для планирования и отслеживания задач

<div id="section-3">
  ### Быстрая и безопасная разработка
</div>

* Работайте в высокопроизводительной облачной среде разработки
* Пользуйтесь сервисом без перебоев с оплатой по мере использования
* Безопасно храните конфиденциальные данные отдельно от кода с помощью инструмента Secrets

Стоимость и лимиты отдельных тарифов указаны на <a href="https://replit.com/pricing" target="_blank">странице тарифов</a>.

<div id="section-4">
  ### Ежемесячные кредиты
</div>

* Вы получаете ежемесячные кредиты, которые автоматически расходуются на платные услуги: Agent, публикацию, сетевой трафик и хранилище базы данных. Нужно больше разработчиков или более высокий уровень кредитов? См. [Replit Pro](/ru/ko/billing/plans/replit-pro).

<div id="section-5">
  ### Публикация в один клик
</div>

Публикация доступна на всех тарифах. Бесплатный тариф Starter позволяет опубликовать одно приложение, а Replit Core снимает это ограничение и предлагает дополнительные возможности:

* Неограниченная публикация приложений
* Различные варианты публикации для оптимизации расходов
* Доступ к встроенным журналам и аналитике
* Удаление значка &quot;Made with Replit&quot; из опубликованных приложений

<div id="ai-2">
  ### Поддержка на базе ИИ и мероприятия сообщества
</div>

* Поддержка на базе ИИ для быстрого решения вопросов по оплате, аккаунту, продукту и техническим темам
* Доступ к закрытым форумам и мероприятиям для участников
* Ранний доступ к новым возможностям

<div id="section-6">
  ## Начало работы
</div>

Перейдите на Replit Core всего за несколько простых шагов:

1. Откройте страницу <a href="https://replit.com/pricing" target="_blank">тарифов</a>
2. Выберите **Подписаться на Replit Core**
3. Выберите **месячный** или **годовой** тариф и укажите платёжные данные

<div id="section-7">
  ## Следующие шаги
</div>

Чтобы подробнее узнать о возможностях Replit Core, воспользуйтесь следующими ресурсами:
