Web 应用是 Replit 的默认输出类型。向 Agent 描述你的想法后，除非指定其他产物类型，否则 Agent 会构建全栈 Web 应用。

<div id="section">
  ## 入门
</div>

你可以通过以下两种方式创建 Web 应用：

* **输入提示词**：在 Replit 首页描述你想构建的内容，Agent 会自动创建 Web 应用。
* **从下拉菜单中选择**：打开首页的应用类型下拉菜单，选择 **Web 应用**，然后描述你的想法。

<div id="section-2">
  ## 主要功能
</div>

* **默认全栈**：所有 Web 应用均包含前端和后端。Agent 会根据应用需求配置 API 路由、数据库和服务端逻辑。
* **响应式设计**：应用会自动适配不同屏幕尺寸。
* **即时部署**：一键发布应用。Replit 负责处理托管、SSL 和基础设施。
* **共享基础设施**：当一个项目包含移动应用或数据控制台等多个产物时，它们都会共享相同的后端、数据库和服务。

<div id="section-3">
  ## 使用场景
</div>

* **SaaS 产品**：构建面向客户的工具、控制台和平台。
* **内部工具**：为团队创建管理面板、CRM 和工作流应用。
* **落地页**：搭建包含表单、动画和动态内容的营销网站。
* **市场和目录**：构建信息列表网站、招聘网站和社区平台。
