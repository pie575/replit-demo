⏰ *Temps estimé : 10 minutes*

Il arrive que le design dont vous souhaitez partir soit déjà en ligne : votre site actuel ou une page dont vous voulez recréer l’apparence. Importer depuis une URL recrée un site web sous forme de frame que vous pouvez explorer, affiner et transformer en app interactive.

Vous utiliserez [creative-studio-landing.replit.app](https://creative-studio-landing.replit.app), une page de destination créée avec Replit pour un studio de création, comme exemple.

<div id="before-you-start">
  ## Avant de commencer
</div>

Vous aurez besoin de :

* Un [compte Replit](https://replit.com).
* L’URL d’un site web public ou de l’exemple ci-dessus.

<div id="import-the-website">
  ## Importer le site web
</div>

<Steps>
  <Step title="Copier l'URL du site">
    Utilisez votre propre site ou copiez cet exemple : `https://creative-studio-landing.replit.app`.

    <Frame caption="Le site d'exemple : Kosmo Studio, une page de destination pour un studio de création.">
      <img src="/assets/mirror/url-example-site-e0ad60629981.webp" alt="La page d'accueil de Kosmo Studio avec le slogan Nous créons des idées audacieuses et des visuels qui fonctionnent vraiment, au-dessus d'un éventail de cartes illustrées" width="3440" height="2160" data-path="images/design/import-from-url/url-example-site.webp" />
    </Frame>
  </Step>

  <Step title="Ouvrir Replit Design">
    Accédez à [replit.com/design](https://replit.com/design) et sélectionnez **Import URL** sous le champ de prompt. Agent recrée l&#39;apparence du site pour vous offrir un point de départ.

    <Frame caption="Import URL sur la page d'accueil de Replit Design : collez un lien vers n'importe quel site web.">
      <img src="/assets/mirror/design-import-url-07a8ac52e188.webp" alt="La page d'accueil de Replit Design avec l'option Import URL sélectionnée et une info-bulle indiquant Collez un lien vers n'importe quel site web et Agent en recréera l'apparence pour vous offrir un point de départ" width="2293" height="1322" data-path="images/design/import-from-url/design-import-url.webp" />
    </Frame>
  </Step>

  <Step title="Coller l'URL et commencer à créer">
    Lorsque vous sélectionnez **Import URL**, le prompt est prérempli : *« Recréez l&#39;apparence de ce site web : »*. Collez votre URL à la suite, puis sélectionnez **Start**.

    <Frame caption="Le prompt de recréation prérempli avec l'URL d'exemple, prêt à être lancé.">
      <img src="/assets/mirror/design-url-prompt-b6196aac1b17.webp" alt="Le champ de prompt de Replit Design indiquant Recréez l'apparence de ce site web, suivi de l'URL d'exemple, avec le bouton Start" width="2293" height="1322" data-path="images/design/import-from-url/design-url-prompt.webp" />
    </Frame>
  </Step>
</Steps>

Agent recrée le site sous la forme d&#39;une frame de conception dans votre projet.

<Frame caption="La page de destination recréée de Kosmo Studio sous la forme d'une frame de conception dans Replit Design.">
  <img src="/assets/mirror/url-import-result-7a4114a468f3.webp" alt="La page de destination recréée de Kosmo Studio sous la forme d'une frame de conception dans Replit Design, avec l'exécution indiquée comme terminée dans le panneau Chat" width="1600" height="1004" data-path="images/design/import-from-url/url-import-result.webp" />
</Frame>

<div id="make-it-yours">
  ## Personnalisez-la
</div>

Sélectionnez la frame importée et commencez à la retravailler :

* **Suivez une [suggestion](/fr/design/explore-suggestions)** : l&#39;import s&#39;accompagne de prochaines étapes proposées, comme une variante éditoriale sombre, une fenêtre d&#39;affichage mobile ou une page de contact. Chacune génère une nouvelle frame : l&#39;originale reste donc disponible pour comparaison.
* **[Discutez-en dans Chat](/fr/design/chat-about-your-design)** : utilisez le champ de saisie sous la frame et formulez votre demande avec vos propres mots, *« remplace les photos du portfolio »*, *« épaissis la typographie du hero »*.

<Frame caption="La frame importée sélectionnée, avec des prochaines étapes suggérées proposant une variante éditoriale sombre, une fenêtre d'affichage mobile et une page de contact.">
