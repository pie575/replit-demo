Project Analytics vous montre comment les internautes découvrent et utilisent votre app web publiée. Ouvrez le panneau **Growth** pour analyser l&#39;évolution du nombre de visiteurs, les sources de trafic et les événements personnalisés.

Replit collecte les métriques de trafic standard des apps publiées compatibles. Avec un forfait payant, Agent peut ajouter des événements personnalisés et répondre à vos questions sur vos analyses.

<div id="antes-de-comear">
  ## Avant de commencer
</div>

Project Analytics nécessite :

* **Un site publié.** Analytics prend en charge les [artifacts](/fr/pt/features/projects-and-artifacts/artifacts) de type site. Il ne collecte pas les événements provenant d&#39;apps mobiles ni d&#39;autres types d&#39;artifact.
* **Un deployment compatible.** Project Analytics prend en charge les deployments de type [Autoscale](/fr/pt/features/publishing/deployment-types#autoscale), [Reserved VM](/fr/pt/features/publishing/deployment-types#reserved-vm) et [Static](/fr/pt/features/publishing/deployment-types#static).
* **Un plan payant pour les analyses avancées.** Les événements personnalisés et les requêtes d&#39;analyse via l&#39;Agent sont disponibles avec les plans payants.
* **Analytics activé lors de votre prochaine publication.** Replit commence à collecter les événements une fois que vous avez activé **Enable analytics** puis publié ou republié votre app.

<div id="abra-o-project-analytics">
  ## Ouvrir Project Analytics
</div>

1. Ouvrez votre projet dans le Project Editor.
2. Sélectionnez **Tools**.
3. Sous **Replit Cloud**, sélectionnez **Growth**.

<Note>
  Le panneau **Growth** reste verrouillé tant que vous n&#39;avez pas publié votre app. Avant
  cela, il vous invite à sélectionner **Go to Publishing**.
</Note>

Les données d&#39;analyse apparaissent dès que votre app publiée reçoit du trafic. Les nouvelles apps peuvent afficher des graphiques vides tant que personne ne les a visitées.

<div id="analise-as-mtricas-padro">
  ## Analysez les métriques standard
</div>

Les métriques standard s&#39;appuient sur les données de trafic IP pour afficher les indicateurs suivants :

* **Visitors** : le nombre approximatif de visiteurs uniques sur la période sélectionnée.
* **Visitors over time (hour)** ou **Visitors over time (day)** : l&#39;évolution de l&#39;activité des visiteurs sur la période sélectionnée.
* **Top Pages** : les pages qui reçoivent le plus de trafic.
* **Top Referrers** : les sites qui génèrent du trafic vers votre app.
* **Top Countries** : les pays approximatifs de vos visiteurs.
* **Top Browsers** : les navigateurs utilisés par les visiteurs.
* **Top Devices** : les types d&#39;appareils utilisés par les visiteurs.

Utilisez le menu d&#39;intervalle de temps pour afficher des périodes allant de six heures à 30 jours. Le total des visiteurs compare chaque période à la période précédente de même durée.

Si votre app utilise [Replit Auth](/fr/pt/features/auth-and-identity/authentication), le panneau affiche également **Unique Logged in Users** pour la période sélectionnée.

<Note>
  Le nombre de visiteurs est approximatif. Il repose sur des données réseau et
  de navigateur, et une même personne peut être comptabilisée comme plusieurs
  visiteurs sur différents appareils ou mois calendaires.
</Note>

<div id="adicione-eventos-personalizados-com-o-agent">
  ## Ajouter des événements personnalisés avec Agent
</div>

Les événements personnalisés mesurent les actions qui comptent pour votre app : inscriptions finalisées, forfaits sélectionnés, formulaires envoyés ou achats effectués, par exemple.

<Steps>
  <Step title="Ajouter des métriques avec Agent">
    Ouvrez **Growth**. Dans **Advanced analytics**, sélectionnez **Add metrics with
    Agent**. Indiquez à Agent les actions que vous souhaitez mesurer. Agent ajoute le
    suivi des événements aux endroits pertinents de votre app.
  </Step>

  <Step title="Activer l'analytics et publier">
    Ouvrez **Publishing** et lancez une nouvelle publication ou republiez. Dans
    **Suggested add-ons**, activez **Enable analytics**. Publiez ensuite
    votre app. Replit commence alors à collecter les pages vues et les événements
    personnalisés à partir de cette version.
  </Step>
</Steps>

<Tip>
  Vous pouvez également demander à Agent de configurer l&#39;analytics directement
  depuis le chat. Vous pouvez lui demander d&#39;ajouter ou de mettre à jour des événements à tout
  moment, à mesure que votre app ou vos objectifs de mesure évoluent.
</Tip>

Replit ajoute le traceur d&#39;analytics à votre app publiée. Vous n&#39;avez pas besoin d&#39;ajouter de script de suivi, d&#39;identifiant de site ni de variable d&#39;environnement d&#39;analytics.

<Warning>
  N&#39;incluez ni secrets, ni données personnelles, ni contenu libre saisi par les visiteurs dans
  les noms ou les propriétés des événements personnalisés.
</Warning>

<div id="pergunte-ao-agent-sobre-suas-anlises">
  ## Interrogez l&#39;Agent sur vos analyses
</div>

Une fois que votre app a collecté des données, utilisez les puces de la section **Advanced analytics** :

* **Summarize my analytics** : l&#39;Agent résume les analyses de votre projet sur les sept derniers jours.
* **Suggest project improvements** : l&#39;Agent examine vos métriques et recommande les points à améliorer dans votre projet.

Vous pouvez également poser une question précise à l&#39;Agent.

<AiPrompt>
  Compare les visiteurs et les inscriptions finalisées des sept derniers jours.
  Montre la tendance quotidienne et identifie les pages au taux de
  conversion le plus élevé.
</AiPrompt>

L&#39;Agent peut analyser les pages vues, les sources de trafic, les événements personnalisés, les propriétés d&#39;événements et les entonnoirs. Il s&#39;appuie sur les données d&#39;analyse de votre projet et renvoie des résultats agrégés.
