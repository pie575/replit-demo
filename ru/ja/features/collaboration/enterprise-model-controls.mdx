Управление моделями Enterprise позволяет администраторам аккаунта определять, какие модели Agent могут выбирать разработчики. После настройки политик для всего аккаунта можно задать разные уровни доступа к моделям для отдельных рабочих пространств.

<Note>
  Управление моделями доступно только администраторам аккаунта Enterprise. Чтобы включить эту функцию для организации, обратитесь в отдел продаж по адресу [sales@replit.com](mailto:sales@replit.com).
</Note>

<div id="section">
  ## Использование интеллектуальной маршрутизации моделей
</div>

Интеллектуальная маршрутизация моделей — стандартный режим работы Agent в рабочих пространствах Enterprise. Когда включён **Auto mode**, Replit выбирает оптимальные режим и модель для каждой задачи, обеспечивая баланс между качеством и стоимостью.

Маршрутизация выбирает модели из пула, разрешённого политиками аккаунта и рабочего пространства. Провайдеры и модели за пределами этого пула недоступны для выбора. Разработчики могут оставить **Auto mode** включённым или отключить его и вручную выбрать разрешённую модель.

Подробнее о том, как работает маршрутизация, см. в разделе [Использование интеллектуальной маршрутизации моделей](/ru/ja/chat/auto-mode).

<div id="agent">
  ## Откройте настройки моделей Agent
</div>

1. Откройте **Settings**.
2. В разделе **Account** выберите **Дополнительно**.
3. Разверните **Режимы Agent и провайдеры моделей**.

<Frame caption="Политика выбора провайдера моделей в разделе «Дополнительно» и отдельный элемент управления моделями режима Fast.">

<div id="section-2">
  ## Настройка политики провайдера
</div>

<Steps>
  <Step>
    Выберите провайдера моделей, которым хотите управлять.
  </Step>

  <Step>
    В разделе **Account policy** выберите один из следующих вариантов:

    | Вариант             | Результат                                                              |
    | ------------------- | ---------------------------------------------------------------------- |
    | **Enable all**      | Все модели провайдера будут доступны во всех рабочих пространствах.    |
    | **Enable selected** | Вы сможете выбрать модели, доступные в каждом рабочем пространстве.    |
    | **Disabled**        | Ни одно рабочее пространство не сможет использовать модели провайдера. |

    <Note>
      Необходимо оставить включённой хотя бы одну модель от OpenAI, Anthropic или Google. Других провайдеров можно отключить.
    </Note>
  </Step>

  <Step>
    Выберите **Update**.
  </Step>
</Steps>

Провайдеры моделей с открытым исходным кодом по умолчанию отключены. Чтобы сделать их доступными, выберите **Enable all** или **Enable selected**, а затем — **Update**.

<div id="section-3">
  ## Настройка политик рабочего пространства
</div>

Используйте **Enable selected**, если разным рабочим пространствам требуется разный доступ к моделям.

<Frame caption="Политика провайдера Anthropic, настроенная на Enable selected, и доступ к моделям, заданный для каждого рабочего пространства.">
  <img src="/assets/mirror/anthropic-account-policy-workspace-models-38c0f71a609d.jpg" alt="Политика аккаунта Anthropic, настроенная на Enable selected, и переключатели моделей для рабочего пространства" width="2000" height="930" data-path="images/workspace/anthropic-account-policy-workspace-models.jpg" />
</Frame>

1. Откройте настройки провайдера.
2. Установите для **Account policy** значение **Enable selected**.
3. В списке **Workspace** откройте меню **Setting** нужного рабочего пространства.
4. Включите или отключите каждую модель для этого рабочего пространства.
5. Выберите **Update**.

Перед выбором **Update** можно выбрать **Copy to all**, чтобы применить выбранные модели текущего рабочего пространства ко всем рабочим пространствам аккаунта.

<div id="section-4">
  ## Ограничения
</div>

* Политики моделей применяются на уровне рабочего пространства. Нельзя настроить разные политики для отдельных групп пользователей в одном рабочем пространстве.
* Интеллектуальная маршрутизация моделей не отменяет политики аккаунта или рабочего пространства. Нельзя выбрать отключённых провайдеров или модели.
* Переключатель **модели режима Fast** в разделе **Режимы Agent и провайдеры моделей** управляет доступом к быстрым вариантам моделей во всех рабочих пространствах аккаунта. Политики провайдеров и интеллектуальная маршрутизация моделей не изменяют эту настройку.
