export const YouTubeEmbed = ({videoId, title = "Vidéo YouTube", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

Les **optimisations de code** (anciennement Niveau d’autonomie) sont un paramètre d’activation/désactivation dans les **paramètres avancés**, accessibles depuis le menu déroulant des paramètres d’Agent. Lorsqu’elles sont **activées**, Agent examine son propre code et simplifie les tâches ultérieures, ce qui améliore la précision et réduit les coûts en évitant les erreurs. Lorsqu’elles sont **désactivées**, la révision du code par l’IA est minimale, voire inexistante, et vous bénéficiez d’un contrôle manuel maximal. Disponibles avec les [forfaits payants](https://replit.com/pricing).

Nous recommandons de laisser les optimisations de code **activées** pour la plupart des projets, afin d’améliorer la qualité du code et de limiter les coûteux cycles de reprise.

<div id="uso">
  ## Utilisation
</div>

Accédez aux Optimisations de code depuis le menu déroulant des paramètres d’Agent lorsque vous travaillez sur n’importe quel projet. Ce paramètre s’applique à votre conversation actuelle, influence la façon dont Agent aborde les tâches suivantes et est disponible en modes Economy et Power.

<Accordion title="Accéder aux Optimisations de code">
  1. Ouvrez votre projet dans l’Éditeur de projets
  2. Ouvrez le menu déroulant des paramètres d’Agent dans le champ de saisie du Chat
  3. Développez les **Paramètres avancés** et recherchez les **Optimisations de code**
  4. Activez ou désactivez cette option selon vos préférences
</Accordion>

<div id="quando-usar">
  ### Quand l’utiliser
</div>

* **Activé :** Recommandé pour la plupart des tâches. Agent examine son propre code, détecte les erreurs et peut réduire les retouches. Chaque tâche est légèrement plus lente, mais la qualité est meilleure.
* **Désactivé :** Utilisez cette option si vous souhaitez une expérience plus rapide et un contrôle plus direct — par exemple, pour des modifications rapides ou si vous préférez vérifier vous-même chaque changement.
