## 개발자 프레임워크 템플릿이 제거되었습니다

언어 및 프레임워크 스타터 템플릿(이전에는 개발자 프레임워크라고 불렸습니다)은 더 이상 Replit에서 제공되지 않습니다. `replit.com/templates`와 `replit.com/developer-frameworks` 페이지는 이제 [Replit 갤러리](https://replit.com/gallery)로 리디렉션됩니다.

새 프로젝트를 시작하려면 대신 다음 방법 중 하나를 사용하세요.

* **Replit Agent로 시작하기** — [홈페이지](https://replit.com/)에서 만들고 싶은 것을 설명하면 Agent가 프로젝트의 뼈대를 만들어 줍니다.
* **[GitHub, GitLab, Bitbucket에서 가져오기](/ko/build/import-from-providers)** — 기존 코드베이스나 스타터 스택을 새로운 Replit App으로 가져옵니다.
* **[게시된 앱 리믹스하기](https://replit.com/gallery)** — Replit 갤러리를 둘러보고 시작점으로 활용할 수 있는 커뮤니티 앱을 확인하고 리믹스하세요.

## 엔터프라이즈 맞춤 템플릿

엔터프라이즈 조직은 [맞춤 템플릿](/ko/teams/custom-templates)을 만들어 모든 조직 구성원의 Agent 입력창에 선택 가능한 옵션으로 표시할 수 있습니다. 맞춤 템플릿은 회사 고유의 Agent 지침, 스킬, 사전 구성된 프로젝트 컨텍스트를 포함하는 등 개발자 프레임워크보다 한 단계 더 나아갑니다. 자세한 내용은 [맞춤 템플릿 가이드](/ko/teams/custom-templates)를 참조하세요.
