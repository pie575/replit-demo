description: "Узнайте, как опубликовать приложение на постоянно работающем облачном сервере с деплоем Reserved VM."
---

Деплой Reserved VM запускается на виртуальной машине (VM), которая предоставляет приложению выделенные вычислительные ресурсы. Этот тип деплоя обеспечивает предсказуемые затраты и производительность без простоев.

Он подходит для следующих сценариев:

* Фоновые задачи с высоким потреблением памяти
* Боты для чатов, которым необходимо постоянно оставаться подключёнными
* Постоянно работающие API-серверы

<div id="section">
  ## Возможности
</div>

Деплой Reserved VM включает следующие возможности:

* **Выделенные ресурсы**: стабильная производительность приложения благодаря зарезервированным вычислительным ресурсам.
* **Собственные домены**: можно настроить собственный домен или обращаться к приложению по URL `<app-name>.replit.app`.
* **Варианты вычислительных ресурсов**: выберите конфигурацию VM, которая соответствует требованиям вашего приложения к производительности.
* **Настраиваемое сопоставление портов**: укажите, какие порты приложение открывает в интернет.
* **Мониторинг**: просматривайте логи и отслеживайте состояние опубликованного приложения.

<div id="section-2">
  ## Использование
</div>

Открыть деплой Reserved VM можно через инструмент публикации в редакторе проекта.

<Accordion title="Как открыть деплой Reserved VM">
  На **панели инструментов** слева:

  1. Выберите <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Иконка «Все инструменты»" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **Все инструменты**, чтобы увидеть список инструментов редактора проекта.
  2. Выберите <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Иконка публикации" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Опубликовать**.
  3. Выберите вариант **Reserved VM**, а затем — **Настроить опубликованное приложение**.

  Через **строку поиска**:

  1. Нажмите на <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="Иконка лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> лупу вверху, чтобы открыть инструмент поиска
  2. Введите «Опубликовать», чтобы найти инструмент, и выберите его в результатах поиска.
  3. Выберите вариант **Reserved VM**, а затем — **Настроить опубликованное приложение**.
</Accordion>

<div id="section-3">
  ### Конфигурация машины
</div>

Выберите конфигурацию CPU и RAM для машины, на которой будет размещён деплой. Рядом с выбранным размером машины указана стоимость этого варианта.

<div id="section-4">
  ### Базовый домен
</div>

Укажите поддомен для опубликованного App. После публикации App будет доступно по адресу `https://<subdomain>.replit.app`.

Подробнее об использовании собственного домена см. в разделе [Пользовательские домены](/ru/features/publishing/custom-domains).

<div id="private">
  ### Private деплой
</div>

<Info>
  Функция приватной публикации приложения доступна на тарифах Pro и Enterprise.
</Info>

Приватно опубликованные приложения доступны только участникам вашего workspace либо конкретным пользователям и группам, которых вы пригласите.
При публикации вы можете выбрать один из вариантов доступа: **Public**, **Password protected**, **Workspace only** или **Invite only**.

О том, как настроить приватный деплой, читайте в разделе [App access](/ru/features/publishing/private-deployments/).

<div id="section-5">
  ### Команда сборки
</div>

В поле **Команда сборки** введите команду 셀 для компиляции или настройки приложения перед выполнением команды запуска.
Например, чтобы оптимизировать JavaScript-приложение для продакшена с помощью Vite, можно добавить команду `vite build`.

<div id="section-6">
  ### Команда запуска
</div>

В поле **Команда запуска** введите команду оболочки, запускающую проект. Она должна быть похожа на команду, используемую в рабочем процессе. Например, чтобы запустить Flask-приложение с именем &quot;myApp&quot;, можно добавить команду `flask --app myApp run`.

<div id="section-7">
  ### Секреты опубликованного App
</div>

Чтобы добавить переменные окружения или секреты, необходимые для безопасной работы App, выберите **Добавить секреты опубликованного App**.

Если в Replit App есть переменные окружения или секреты, инструмент публикации автоматически добавит их в список.

<div id="section-8">
  ### Варианты типа приложения
</div>

Выберите один из следующих вариантов.

* **Веб-сервер**: выберите этот вариант, если вы публикуете веб-приложение или другое приложение, доступное пользователям через интернет.
* **Фоновый обработчик**: выберите этот вариант, если ваше приложение не прослушивает порт и не запускает сервер.

Выбрав **Веб-сервер**, вы можете указать порт, который будет доступен извне, выполнив следующие действия.

1. Разверните раздел **Конфигурация портов**.
2. Выберите **Настроить через панель сети**, чтобы открыть вкладку **Сеть** и управлять сопоставлениями портов.

Подробнее о настройке портов см. в разделе [Порты](/ru/ko/features/project-setup/ports/).
