<div id="section">
  ## Qu&#39;est-ce qu&#39;un remix ?
</div>

Un **remix** est une nouvelle Replit App créée à partir d&#39;une application à laquelle vous avez accès. Lorsque vous remixez une application publique ou un modèle, vous en obtenez votre propre copie, que vous pouvez modifier et améliorer progressivement. Les changements effectués dans un remix n&#39;affectent pas l&#39;application d&#39;origine.

Un remix indique clairement son application d&#39;origine : un lien **Remixed from** pointant vers celle-ci s&#39;affiche, et l&#39;invite de création de l&#39;application d&#39;origine apparaît sur la page de couverture.

<div id="section-2">
  ## Ce que contient un remix
</div>

Un remix est une copie entièrement fonctionnelle, clairement dissociée de l&#39;App d&#39;origine.

* **Tous les fichiers et paramètres** sont copiés : l&#39;App fonctionne donc exactement comme l&#39;originale.
* **L&#39;historique des checkpoints de l&#39;App d&#39;origine** est lui aussi repris et identifié comme tel. Vous pouvez revenir à ces checkpoints à tout moment, mais les conversations qui les ont générés restent dans l&#39;App d&#39;origine.
* **Un Agent entièrement nouveau**. Un remix démarre avec un nouvel Agent, sans reprise de l&#39;historique de conversation.
* **Le nom des secrets, mais pas leur valeur**. Si l&#39;App utilise des secrets (des clés API, par exemple), le remix les répertorie afin que vous sachiez quoi saisir, mais les valeurs restent vides. Les valeurs ne sont copiées que lorsque vous remixez vos propres Apps.
* **Une nouvelle base de données**. Un remix ne se connecte jamais à la base de données de l&#39;App d&#39;origine. Si l&#39;App d&#39;origine le propose, l&#39;option **Copy data from original App** vous permet de copier les données elles-mêmes, mais vos modifications n&#39;affecteront jamais l&#39;App d&#39;origine.
* Pour les Apps qui utilisent Replit Auth, **une nouvelle configuration de connexion**.

Ce qui n&#39;est pas copié : les déploiements, les domaines et la configuration des connecteurs, que vous paramétrez séparément dans votre copie. Par ailleurs, un remix démarre en mode privé : rien n&#39;est partagé tant que vous n&#39;avez pas choisi de le publier.

<div id="section-3">
  ## Comment remixer une app
</div>

<Steps>
  <Step title="Ouvrir la page de couverture de l'app">
    Trouvez l&#39;app que vous souhaitez remixer, par exemple depuis la [communauté](https://replit.com/community/all). La page de couverture affiche un aperçu en direct ainsi que les options de partage.
  </Step>

  <Step title="Remixer l'app">
    Sélectionnez **Remix this App** pour commencer à créer votre propre version.
  </Step>

  <Step title="Saisir les détails de l'app">
    Dans la boîte de dialogue **Remix App**, donnez un nom à votre copie et, si vous le souhaitez, une description, puis sélectionnez **Remix App**. Vous pourrez modifier ces informations par la suite.

<div id="section-5">
  ## Développer à partir d&#39;un remix
</div>

Une fois le remix ouvert dans l&#39;espace de travail, utilisez Agent pour le modifier et l&#39;enrichir. Dans l&#39;onglet **Agent**, saisissez une invite décrivant les fonctionnalités que vous souhaitez ajouter.

Pour annuler les modifications d&#39;Agent, sélectionnez **Rollback to here** sur un checkpoint créé après ces modifications. Pour en savoir plus, consultez [Checkpoints et retours en arrière](/fr/ja/features/version-control/checkpoints-and-rollbacks).

<div id="section-6">
  ## Remixer ou partir d&#39;une invite : que choisir ?
</div>

Les deux approches mènent au même résultat : votre propre application, qu&#39;Agent vous aide ensuite à faire évoluer. Seul le point de départ diffère.

|                             | Remix                                                   | Construction à partir d&#39;une invite                        |
| --------------------------- | ------------------------------------------------------- | ------------------------------------------------------------- |
| Point de départ             | Une application fonctionnelle copiée telle quelle       | Une application créée par Agent à partir de votre description |
| Premier résultat            | Immédiat et identique à l&#39;application d&#39;origine | Plus long à obtenir et différent à chaque fois                |
| Première action d&#39;Agent | Attendre vos instructions                               | Planifier et construire à partir de votre invite              |

Si une application proche de ce que vous recherchez existe déjà, remixez-la. Plutôt que de partir de zéro, Agent effectue son premier tour sur une application déjà fonctionnelle. Si vous ne trouvez rien qui ressemble à votre idée, partez d&#39;une invite.

  ## Prochaines étapes
</div>

* **Explorer d&#39;autres remix** : parcourez la [communauté](https://replit.com/community/all) pour découvrir des apps à remixer et à étudier

* **Publier pour le remix** : partagez vos versions améliorées afin que d&#39;autres puissent s&#39;appuyer sur votre travail
