<div id="section">
  ## 数据保护
</div>

数据保护是 Replit 的重中之重。我们采取了全面的安全措施，以保护您的数据并确保平台的完整性。

<div id="section-2">
  ### 托管与基础设施
</div>

Replit 主要将数据托管在位于美国的 Google Cloud Platform (GCP) 数据中心，并为选择加入的用户提供印度托管区域。我们借助 GCP 企业级的备份与恢复工具，确保实现以下目标：

<CardGroup cols={2}>
  <Card title="高可用性" icon="server">
    冗余系统与自动故障转移机制可防止服务中断和数据丢失
  </Card>

  <Card title="数据隔离" icon="layer-group">
    严密的逻辑隔离可防止不同用户和组织之间的未授权访问
  </Card>
</CardGroup>

GCP 是业界领先的云服务提供商，已通过 **ISO 27001** 和 **SOC 2 Type 2** 合规认证。此外，**Replit 已取得 SOC 2 Type 2 合规认证**，体现了我们对安全最佳实践与管控措施的持续投入。

所有客户端请求在访问私有信息之前，都必须经过严格的**身份验证和授权**。

<div id="section-3">
  ### 加密标准
</div>

<Note>
  Replit 对各种状态下的数据均实施全面加密，确保信息的机密性、完整性与安全性。
</Note>

<AccordionGroup>
  <Accordion title="传输中加密" icon="shield-halved">
    采用业界标准的 **TLS 1.2+** 加密保护客户端与服务器之间的所有通信，确保数据在网络传输过程中的安全。这涵盖所有 API 调用、网页流量、实时协作数据及其他通信。
  </Accordion>

  <Accordion title="静态数据" icon="database">
    存储在 GCP 中的数据通过 [**AES-256 服务器端加密**](https://cloud.google.com/docs/security/encryption/default-encryption) 加以保护。这一军用级加密标准可保护所有静态数据，包括代码、配置、用户信息和系统元数据。
  </Accordion>

  <Accordion title="数据库安全" icon="lock">
    使用 **Google Cloud SQL** 实现[数据库加密](https://cloud.google.com/sql/references/additional-resources/faq#encryption-manage-rest)和[安全密钥管理](https://cloud.google.com/secret-manager)，通过自动加密、定期密钥轮换和精细的访问控制保护敏感数据。
  </Accordion>
</AccordionGroup>
