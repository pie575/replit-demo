Selon l’état d’avancement de votre marque, vous pouvez créer un système de design de deux façons.

<div id="section">
  ## Créer depuis zéro : générer à partir d’un prompt depuis la page d’accueil
</div>

Commencez ici si le système n’existe encore que dans votre esprit (ou dans votre guide de marque) et n’a pas encore été concrétisé sous forme de design.

<Steps>
  <Step title="Formuler une demande dans le champ de création">
    Décrivez le système de design souhaité dans le champ de prompt de la page d’accueil de Replit. Par exemple : *&quot;Créez un système de design pour Velocity, une marque de location de supercars haut de gamme.&quot;*

    <Frame>
      <img src="/assets/mirror/ds-home-create-7f04110e1f71.png" alt="Champ de prompt de la page d’accueil contenant un prompt de création de système de design" width="800" height="240" data-path="images/design/replit-design/ds-home-create.png" />
    </Frame>
  </Step>

  <Step title="Répondre aux questions">
    Agent vous présente une courte liste de questions sur le système, notamment sur la personnalité de la marque, les couleurs et les préférences typographiques. Vous pouvez également fournir des sources telles qu’une URL Figma, un site web, du code, des images de référence, des assets de marque ou un fichier DESIGN.md existant.
  </Step>
</Steps>

<div id="section-2">
  ## Partir d&#39;une maquette : extraire un système de design
</div>

Commencez ici si vous avez déjà un design qui vous plaît (comme un frame généré ou un modèle importé) et souhaitez harmoniser tout le reste avec celui-ci.

<Steps>
  <Step title="Sélectionner une maquette">
    Sur le canevas, cliquez sur la maquette dont vous souhaitez reprendre l&#39;apparence.
  </Step>

  <Step title="Extraire depuis le menu à trois points">
    Ouvrez le menu **⋯** (trois points) du frame et sélectionnez **Extract design system**. Agent extrait les jetons, les couleurs et la typographie de la maquette pour créer un guide de style dynamique, puis les applique à l&#39;ensemble de votre design.

    <Frame>
      <img src="/assets/mirror/ds-extract-menu-3efbe8bb497e.png" alt="Gros plan sur la barre d'actions d'un frame sélectionné, avec le menu Plus ouvert affichant Apply design system et Extract design system" width="958" height="320" data-path="images/design/replit-design/ds-extract-menu.png" />
    </Frame>
  </Step>
</Steps>

<div id="section-3">
  ## Vérifier et enregistrer
</div>

Quelle que soit la méthode choisie, examinez le résultat généré : un guide de style dynamique comprenant les couleurs par rôle (primary, accent, muted, etc.), l’échelle typographique et les jetons (enregistrés dans `tokens.json` et appliqués sous forme de variables CSS). Sélectionnez ensuite **Enregistrer le système de design** pour l’enregistrer dans votre espace de travail.
