# Console

> Saiba como usar o Console para ver a saída, os erros e os logs de atividade do seu app.

O Console permite monitorar e revisar os logs impressos pelo seu Replit App em execução em tempo real.
Você pode usar as informações de execuções atuais e anteriores para entender o comportamento do seu app,
solucionar erros e otimizar o desempenho.

<Tip>
  Ao depurar usando o Agent, inclua os logs do console no seu prompt para fornecer contexto.
</Tip>

## Recursos

O Console fornece as seguintes ferramentas para ajudá-lo a entender o comportamento do seu app:

* **Registro em tempo real**: Visualize a saída do seu app conforme ela acontece
* **Assistência de IA**: Receba sugestões para corrigir erros relatados nos logs
* **Histórico de execuções**: Exiba logs de execuções anteriores para acompanhar as alterações

## Uso

Você pode acessar a ferramenta Console diretamente no seu Editor de Projetos.

  1. Cada vez que você usa o botão **Executar** no seu Replit App, o Console exibe uma nova entrada que inclui as seguintes informações:

* O comando que executou seu código
* Informações de data e hora
* Logs de saída padrão e de erros

### Depuração com IA

Quando você encontrar erros ou outras informações nos logs que queira entender, selecione o
botão **Perguntar à IA** na parte superior da entrada. Isso abre automaticamente a aba do **Agent** e
envia o conteúdo do log para análise.

### Comandos de entrada de log

O Console fornece as seguintes ferramentas para gerenciar seus logs:

* **Mostrar somente o mais recente**: Ative este controle para exibir apenas a execução mais recente.
* **Recolher entrada**: Selecione a <img class="icon-svg" src="https://mintcdn.com/replit/rJldsgYVucXB_6kW/images/icons/down-arrow.svg?fit=max&auto=format&n=rJldsgYVucXB_6kW&q=85&s=56bcbb702af7e7700c87fa23be223a9d" alt="ícone de seta para baixo" height="16" width="16" data-path="images/icons/down-arrow.svg" /> seta para baixo à esquerda do nome do comando para ocultar os logs.
* **Limpar execuções anteriores**: Selecione para excluir os logs de execuções anteriores. Esta ação é irreversível.

### Disponibilidade de rede

Você pode controlar a disponibilidade online da versão de desenvolvimento do seu app.

Para parar de atender requisições à URL de desenvolvimento, selecione o ícone <img class="icon-svg" src="https://mintcdn.com/replit/rJldsgYVucXB_6kW/images/icons/network-off.svg?fit=max&auto=format&n=rJldsgYVucXB_6kW&q=85&s=83d1529d18164c45a63fab5e340e1320" alt="ícone de rede desativada" height="16" width="16" data-path="images/icons/network-off.svg" /> globo com barra
no lado direito da linha de informações de rede.

Para ativá-la, selecione o ícone <img class="icon-svg" src="https://mintcdn.com/replit/rJldsgYVucXB_6kW/images/icons/network-on.svg?fit=max&auto=format&n=rJldsgYVucXB_6kW&q=85&s=169c03c9769dde9600939635a8b4a5c3" alt="ícone de rede ativada" height="16" width="16" data-path="images/icons/network-on.svg" /> globo.

Para ver sua URL de desenvolvimento, selecione o texto `{...}.replit.dev` na barra de localização.

### Parar um comando de workflow

Você pode parar um comando de workflow em execução a partir da ferramenta Console do Editor de Projetos.

Selecione o botão quadrado no lado direito da linha que contém o comando de execução do seu Replit App para encerrá-lo.

Para reiniciar o app, use o botão **Executar** do workflow na parte superior do Editor de Projetos.
