<div id="atualizaes-do-scanner-de-segurana">
  ### Обновления сканера безопасности
</div>

Воспользуйтесь более быстрым и интеллектуальным сканированием безопасности благодаря масштабному обновлению Сканера безопасности. Результаты проверок теперь кэшируются, а повторный запуск выполняется только при изменении кода, поэтому последующие проверки проходят очень быстро. Новая функция игнорирования позволяет скрывать нежелательные проблемы безопасности, сохраняя к ним доступ при необходимости.

<div id="otimizao-do-prompt-de-sistema-do-agent">
  ### Оптимизация системного промпта Agent
</div>

Благодаря последним улучшениям системы взаимодействие с Agent стало быстрее и эффективнее. Теперь Agent выполняет задачи на 2–3 секунды быстрее за каждое действие, сохраняя привычно высокое качество результатов.
