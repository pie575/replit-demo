## Agent

### Routage de modèle intelligent

Le routage de modèle intelligent sélectionne automatiquement le modèle et le niveau d'effort les mieux adaptés à votre tâche, en équilibrant qualité et coût. En **Power** ou **Max**, sélectionnez **Auto** pour laisser Replit router chaque partie de votre travail à mesure que sa complexité évolue. Vous pouvez aussi sélectionner un modèle et un niveau d'effort spécifiques lorsque vous souhaitez plus de contrôle.

### Trouvez vos premiers clients avec Growth Skills

Exécutez [Growth Skills](https://replit.com/growth-kit) avec Agent pour trouver les premiers clients de votre application. Les intégrations partenaires disponibles incluent Apollo, Clay, SideShift, RevenueCat, Stripe et PostHog.

### Routage de modèle intelligent pour Enterprise

Le routage de modèle intelligent est désormais le mode Agent par défaut pour les Workspaces Enterprise. Lorsque le **mode Auto** est activé, Replit choisit le meilleur mode et un modèle autorisé pour chaque tâche. Les administrateurs de compte peuvent contrôler la disponibilité des modèles pour chaque Workspace, et vous pouvez désactiver le **mode Auto** pour sélectionner un modèle activé. Le menu des modes Agent Enterprise utilise désormais **Power** et **Max**, et n'inclut plus **Lite**.

## Intégrations

### Personnalisez les connecteurs

Les organisations Enterprise peuvent désormais utiliser des configurations OAuth personnalisées pour les connecteurs. Par exemple, configurez Gmail avec votre propre **Client ID**, **Client Secret** et vos propres **périmètres** au lieu des valeurs par défaut de Replit.
