O Shell permite trabalhar em seus projetos, como um terminal comum, para gerenciar arquivos,
instalar pacotes e executar scripts. Por exemplo, você pode navegar pelos arquivos do projeto ou
usar `psql` quando seu projeto tiver uma conexão de banco de dados configurada.

<Tip>
  Para um melhor gerenciamento de workflow, prefira usar o botão **Run** em
  vez de executar seu aplicativo pelo Shell. O workflow iniciado pelo botão
  **Run** envia a saída para a ferramenta Console, que oferece uma forma
  estruturada de revisar os logs.
</Tip>

## Recursos

O Shell oferece as seguintes capacidades:

* **Executar múltiplos shells**: abra várias instâncias de shell para trabalhar em tarefas diferentes simultaneamente
* **Pesquisar texto**: encontre texto específico na saída do shell

### Confirmar acesso ao Shell

Para confirmar que o Shell está pronto e visualizar o espaço de trabalho atual, execute:

```sh theme={null}
pwd
```

O Shell exibe o caminho do espaço de trabalho atual.

<Frame caption="O comando pwd exibe o caminho do espaço de trabalho atual e retorna ao prompt do Shell.">
  <img src="/assets/mirror/shell-pwd-output-2d31a0e0466b.jpg" alt="Aba do Shell mostrando o comando pwd, a saída do caminho do espaço de trabalho e um prompt retornado" width="1280" height="246" data-path="images/workspace/shell-pwd-output.jpg" />
</Frame>

Para um projeto com um banco de dados, selecione **Tools** → **Database**, depois abra a página
**Development database**. Essa página fornece os controles de conexão. Mantenha os
valores de conexão privados; não os copie para documentação, capturas de tela,
logs, arquivos de código-fonte ou mensagens compartilhadas.

### Pesquisa de texto

Os passos a seguir descrevem como acessar e usar a ferramenta de pesquisa de texto:

1. Selecione a <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="ícone de lupa" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> lupa no canto superior direito da aba Shell para abrir a caixa de diálogo de pesquisa.
2. Digite um termo de pesquisa e selecione **Next** para navegar pelas correspondências.
3. Use **Previous** para voltar às correspondências anteriores.
4. Selecione **Exit** ou clique fora da caixa de diálogo para sair da pesquisa de texto.

### Múltiplos shells

Para criar outro shell:

1. Selecione o menu de instâncias do Shell no cabeçalho do painel Shell.
2. Selecione **New Shell**.

<Frame>
  <img src="/assets/mirror/shell-new-94a280c1230f.png" alt="Menu de instâncias do Shell com o espaço de trabalho atual e a opção New Shell" width="1280" height="224" data-path="images/workspace/shell-new.png" />
</Frame>

Use o mesmo menu para alternar entre shells. O Replit identifica cada shell com o último comando executado para ajudar você a identificá-los.

<Warning>
  Quando você abre mais de um shell, o Replit fecha automaticamente as
  instâncias de shell inativas. Um shell inativo é aquele que não está
  selecionado e não está executando nenhum processo do usuário.
</Warning>
