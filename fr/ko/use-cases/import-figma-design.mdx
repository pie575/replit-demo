Si vous avez déjà des écrans dans Figma, Agent les transforme en une véritable application Replit que vous pouvez modifier, prévisualiser et publier : mise en page, typographie, couleurs et espacements. Le résultat n&#39;est pas
une capture d&#39;écran, mais un produit réellement fonctionnel. Si le fichier contient plusieurs parcours, indiquez à Agent une
frame précise.

<div id="section">
  ## À qui s’adresse cette fonctionnalité
</div>

* Les designers produit qui souhaitent créer une application Replit à partir de frames existantes
* Les fondateurs qui doivent rendre un fichier Figma fonctionnel sans le recréer de zéro

<div id="section-3">
  ## Avant de commencer
</div>

Préparez un fichier Figma contenant des frames nommées (accueil, produit, paiement, etc.). Connectez Figma.
Partagez le fichier avec Agent ou collez le lien vers le fichier et celui vers la frame qui vous intéresse.
Indiquez s’il s’agit d’un site marketing, d’une application ou d’une page de destination unique.

<div id="agent">
  ## Demander à Agent
</div>

<AiPrompt>
  À partir de ce fichier Figma[lien], créez une application Replit pleinement
  fonctionnelle à partir des frames suivants[nom ou lien du frame]. Reproduisez la mise
  en page, la typographie, les couleurs, les espacements et les points de rupture (ordinateur et mobile).
</AiPrompt>

<div id="section-4">
  ## Résultat attendu
</div>

Agent lit la frame sélectionnée et crée une page correspondante, prête à être publiée sur
Replit. Comparez les marges, la typographie et les couleurs à celles de Figma. Vérifiez vous-même les
éléments interactifs (navigation, formulaires, survol). Une itération supplémentaire est généralement nécessaire. Prévisualisez la page aux largeurs
d’écran de bureau et mobile. Testez la navigation et les formulaires, puis comparez les
captures d’écran à Figma avant de publier.

<div id="section-5">
  ## Adapter à vos besoins
</div>

<AiPrompt>
  Commencez par implémenter uniquement les frames mobiles. Respectez la mise en page automatique et les marges de Figma. Une fois la version mobile approuvée, nous passerons à la version bureau.
</AiPrompt>

<AiPrompt>
  Réutilisez un même composant pour les boutons, les champs de saisie et les cartes. S&#39;il existe des variables Figma, utilisez-les pour les couleurs et la typographie.
</AiPrompt>

<div id="section-6">
  ## Résolution des problèmes
</div>

* **Agent ne parvient pas à lire le fichier :** connectez Figma et partagez le fichier, puis collez le lien de la frame, pas seulement l’URL du fichier. Si le fichier comporte plusieurs flux, indiquez le nom de la frame (accueil, produit, paiement).
* **Les survols, la navigation et les formulaires semblent inachevés :** la mise en page et les couleurs sont souvent appliquées en premier. Demandez à Agent d’affiner davantage les éléments interactifs, puis comparez les espacements avec ceux de Figma.
