Les thèmes Replit vous permettent de personnaliser l&#39;apparence de l&#39;éditeur de projet, des couleurs d&#39;arrière-plan et des éléments d&#39;interface jusqu&#39;à la coloration syntaxique de votre code. Adaptez votre environnement de développement pour gagner en lisibilité, réduire la fatigue visuelle et rendre la programmation plus agréable.

<div id="criando-um-tema-personalizado">
  ## Créer un thème personnalisé
</div>

Suivez ces étapes pour créer et personnaliser votre propre thème :

1. Ouvrez les [Configurações](https://replit.com/settings) et allez dans **Utilisateur** → **Personalização** (ou la section **Themes**)
2. Sélectionnez **Créer un nouveau thème**
3. Saisissez un titre, choisissez un schéma de couleurs (clair ou sombre) et ajoutez une description facultative
4. Sélectionnez **Créer le thème** pour ouvrir l&#39;Éditeur de thèmes

Les paramètres globaux du thème contrôlent l&#39;apparence générale de l&#39;interface :

* **Background** : définit la couleur de base de la plupart des surfaces de l&#39;interface
* **Outline** : contrôle la couleur des bordures et des séparateurs
* **Foreground** : détermine les couleurs du texte et des icônes
* **Primary** : définit la couleur des boutons et des éléments interactifs
* **Positive** : s&#39;applique aux indicateurs de réussite, comme le bouton **Run**
* **Negative** : s&#39;affiche pour les erreurs et les avertissements d&#39;actions destructrices

Sélectionnez **Appliquer le thème** pour utiliser immédiatement votre thème personnalisé.

<div id="realce-de-sintaxe">
  ## Coloration syntaxique
</div>

Personnalisez l&#39;apparence des différents éléments de code pour améliorer la lisibilité et la compréhension.

<Tip>
  Une coloration syntaxique bien conçue rend le code plus facile à parcourir et à comprendre d&#39;un coup d&#39;œil. Choisissez des couleurs qui s&#39;harmonisent entre elles et offrent un contraste suffisant avec l&#39;arrière-plan.
</Tip>

<Accordion title="Éléments de coloration syntaxique">
  | Élément                  | Description                                                                            |
  | ------------------------ | -------------------------------------------------------------------------------------- |
  | **Variable Names**       | S&#39;applique aux variables lorsqu&#39;aucun mot-clé de déclaration n&#39;est utilisé |
  | **Variable Definitions** | Colore les noms de variables définies avec des mots-clés comme `const` ou `var`        |
  | **Function References**  | S&#39;applique lors de l&#39;appel de fonctions                                        |
  | **Function Definitions** | Colore les noms de fonctions lors de la déclaration                                    |
  | **Keywords**             | Met en évidence les mots-clés du langage comme `import`, `function` et `return`        |
  | **Property Names**       | Colore l&#39;accès aux propriétés depuis des variables                                 |
  | **Property Definitions** | Utilisé lors de la définition de propriétés d&#39;objets                               |
  | **Function Properties**  | S&#39;applique lors de l&#39;appel de méthodes sur des objets                          |
  | **Tag Names**            | Utilisé pour les balises HTML et JSX                                                   |
  | **Type Names**           | Colore les annotations de type dans les langages typés                                 |
  | **Class Names**          | S&#39;applique aux déclarations et références de classes                               |
  | **Attribute Names**      | Met en évidence les attributs HTML et JSX                                              |
  | **Comments**             | S&#39;applique à tous les commentaires de code                                         |
  | **Strings**              | Colore les littéraux de chaîne                                                         |
  | **Numbers**              | Met en évidence les valeurs numériques                                                 |
  | **Booleans**             | Met en forme les valeurs booléennes (`true`/`false`)                                   |
  | **Regular Expressions**  | Colore les motifs d&#39;expressions régulières                                         |
  | **Operators**            | Met en évidence les opérateurs comme `+`, `-`, `*` et `/`                              |
  | **Brackets**             | Colore les crochets et chevrons le cas échéant                                         |
</Accordion>

<div id="boas-prticas-de-design-de-temas">
  ## Bonnes pratiques de conception de thèmes
</div>

Créez des thèmes visuellement attrayants et fonctionnels en suivant ces recommandations :

<div id="cor-e-contraste">
  ### Couleur et contraste
</div>

* **Équilibrez le contraste** : veillez à une différence suffisante entre les éléments d&#39;arrière-plan et de premier plan
* **Créez des palettes cohérentes** : choisissez des couleurs qui se complètent plutôt que de s&#39;opposer
* **Gardez une luminosité constante** : conservez un niveau de luminosité similaire d&#39;un élément de syntaxe à l&#39;autre
* **Concevez pour l&#39;accessibilité** : pensez aux personnes ayant une déficience visuelle en évitant les combinaisons à faible contraste

<Warning>
  Problèmes courants de conception de thèmes à éviter :

  * Écarts de luminosité excessifs entre les éléments de syntaxe
  * Couleurs mal assorties qui créent une dissonance visuelle
  * Contraste insuffisant entre le code et l&#39;arrière-plan
</Warning>

<div id="gerenciando-seus-temas">
  ## Gérer vos thèmes
</div>

Accédez à tous vos thèmes installés et gérez-les dans les [Configurações](https://replit.com/settings), sous **Utilisateur** → **Personalização** (ou la section **Themes**).

<div id="alternando-entre-temas">
  ### Basculer entre les thèmes
</div>

Sélectionnez le bouton situé à côté du titre d&#39;un thème pour l&#39;appliquer comme thème actuel.

<div id="editando-temas">
  ### Modification des thèmes
</div>

Modifiez vos thèmes personnalisés en sélectionnant le menu à trois points, puis en cliquant sur **Modifier**.

<Note>
  Seuls les thèmes personnalisés que vous avez créés peuvent être modifiés ou supprimés. Les thèmes par défaut et ceux créés par d&#39;autres utilisateurs ne peuvent pas être modifiés.
</Note>

<div id="excluindo-temas">
  ### Supprimer des thèmes
</div>

Supprimez les thèmes personnalisés en ouvrant le menu à trois points et en sélectionnant **Supprimer**.

<div id="explorando-temas-da-comunidade">
  ## Explorer les thèmes de la communauté
</div>

Découvrez les thèmes créés par la communauté Replit sur la [page d&#39;exploration des thèmes](https://replit.com/themes).

<div id="encontrando-temas">
  ### Trouver des thèmes
</div>

* Effectuez une recherche par nom pour trouver un thème précis, comme « Atom One Dark »
* Filtrez par auteur pour explorer les thèmes de créateurs en particulier
* Naviguez par schéma de couleurs pour trouver des thèmes clairs ou sombres
* Recherchez des couleurs précises correspondant à vos préférences

Prévisualisez n&#39;importe quel thème avant de l&#39;installer pour voir son rendu dans l&#39;éditeur de projet.

<div id="portando-do-vs-code">
  ## Portage depuis VS Code
</div>

Importez vos thèmes VS Code préférés dans Replit en faisant correspondre les couleurs équivalentes lors de la création du thème.

<div id="publicando-seu-tema">
  ## Publier votre thème
</div>

Partagez vos thèmes personnalisés avec la communauté Replit en suivant ces étapes :

1. Ouvrez l&#39;éditeur de thèmes de votre thème personnalisé
2. Sélectionnez le bouton **Publier**
3. Renseignez les champs de titre et de description
4. Soumettez votre thème

Une fois publié, votre thème apparaît sur la page d&#39;exploration des thèmes, où les autres utilisateurs peuvent le consulter et l&#39;installer.
