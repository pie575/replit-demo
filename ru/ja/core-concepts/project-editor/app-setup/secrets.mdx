Инструмент Secrets хранит и шифрует **секреты** — конфиденциальные данные приложений Replit, такие как API-ключи, токены аутентификации и строки подключения к базе данных.

Когда вы добавляете секрет, инструмент автоматически шифрует данные и делает их доступными в качестве переменных окружения в приложении Replit.
Такой подход избавляет от необходимости жёстко прописывать секреты в коде и снижает риск их утечки.

Жёсткое прописывание секретов в кодовой базе может привести к их случайной утечке в следующих ситуациях:

* Вы публикуете код в приложении Replit или вставляете его в GitHub
* Вы отправляете код в публичный репозиторий
* Вы показываете код во время прямой трансляции или демонстрации экрана

Используйте инструмент Secrets, чтобы делиться кодом, не беспокоясь об утечке учётных данных.

<div id="section">
  ## Возможности
</div>

Secrets включает следующие возможности:

* **Сквозное шифрование**: автоматическая защита данных с помощью шифрования AES-256 при хранении и TLS при передаче
* **Секреты на уровне приложения**: хранение и управление секретами, привязанными к конкретному приложению Replit
* **Секреты на уровне аккаунта**: хранение и управление секретами, доступными во всех приложениях Replit
* **Доступ через переменные окружения**: доступ к секретам из кода через переменные окружения
* **Совместный доступ**: предоставление доступа к секретам соавторам и участникам команды

<div id="section-3">
  ### Управление секретами приложения
</div>

Управлять секретами на уровне приложения можно на вкладке **Секреты приложения** панели **Secrets**.
На этой вкладке отображается список всех секретов, связанных с приложением Replit.

<Accordion title="Добавление секрета приложения">
  Чтобы добавить секрет:

  1. Выберите **Новый секрет**.
  2. Введите **ключ** (имя секрета) и **значение** (сам секрет).
  3. Выберите **Добавить секрет**, чтобы сохранить его.
</Accordion>

<Accordion title="Редактирование секрета приложения">
  Чтобы отредактировать секрет:

  1. Выберите меню с вертикальным многоточием <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="значок вертикального многоточия" height="16" width="16" data-path="images/icons/vertical-dots.svg" /> рядом с секретом.
  2. В контекстном меню выберите **Редактировать**.
  3. Измените текст в поле **ключ** или **значение**, затем выберите **Обновить секрет**, чтобы сохранить изменения, или **Отмена**, чтобы отменить их.

  Вы также можете изменить весь список секретов приложения, выбрав **Редактировать как JSON** или &#42;&#42;Редактировать как .env&#42;&#42; в нижней части вкладки.
</Accordion>

<Accordion title="Просмотр секрета приложения">
  Чтобы просмотреть секрет, выберите значок глаза <img class="icon-svg" src="/assets/mirror/eye-8a6472b8a950.svg" alt="значок глаза" width="16" height="16" data-path="images/icons/eye.svg" /> рядом с секретом.

  Чтобы скрыть секрет, выберите значок глаза с перечёркиванием <img class="icon-svg" src="/assets/mirror/eye-slash-6b4ded538179.svg" alt="значок глаза с перечёркиванием" width="16" height="16" data-path="images/icons/eye-slash.svg" />.
</Accordion>

<Accordion title="Удаление секрета приложения">
  Чтобы удалить секрет, выберите меню с вертикальным многоточием <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="значок вертикального многоточия" height="16" width="16" data-path="images/icons/vertical-dots.svg" /> рядом с секретом, затем выберите **Удалить**.
</Accordion>

<div id="section-4">
  ### Управление секретами аккаунта
</div>

Управлять секретами на уровне аккаунта можно на вкладке **Секреты аккаунта** панели **Secrets**.
На этой вкладке отображаются только секреты, связанные с вашим аккаунтом Replit.

<Accordion title="Добавление секрета аккаунта">
  Чтобы добавить секрет на уровне аккаунта:

  1. Перейдите на вкладку **Секреты аккаунта**.
  2. Нажмите значок <img class="icon-svg" src="/assets/mirror/settings-icon-c2664c3691bf.svg" alt="значок шестерёнки" width="16" height="16" data-path="images/icons/settings-icon.svg" />, чтобы открыть **Настройки** и управлять секретами на уровне аккаунта.
  3. Нажмите **Новый секрет**.
  4. Введите **Ключ** (имя секрета) и **Значение** (сам секрет).
  5. Нажмите **Сохранить**.
</Accordion>

<Accordion title="Редактирование секрета аккаунта">
  Чтобы отредактировать секрет:

  1. Нажмите значок карандаша <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="значок карандаша" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> рядом с секретом.
  2. Измените текст в поле **Ключ** или **Значение**, затем нажмите **Сохранить**, чтобы сохранить изменения, или **Отмена**, чтобы отменить их.
</Accordion>

<Accordion title="Просмотр секрета аккаунта">
  Чтобы просмотреть секрет, нажмите значок глаза <img class="icon-svg" src="/assets/mirror/eye-8a6472b8a950.svg" alt="значок глаза" width="16" height="16" data-path="images/icons/eye.svg" /> рядом с секретом.

  Чтобы скрыть секрет, нажмите значок перечёркнутого глаза <img class="icon-svg" src="/assets/mirror/eye-slash-6b4ded538179.svg" alt="значок перечёркнутого глаза" width="16" height="16" data-path="images/icons/eye-slash.svg" />.
</Accordion>

<Accordion title="Связывание секрета аккаунта">
  Чтобы использовать секрет на уровне аккаунта в приложении Replit, его нужно связать с приложением.
  Чтобы связать секрет на уровне аккаунта:

  1. Перейдите на вкладку **Секреты приложения**.
  2. Установите флажок слева от секрета.
  3. Нажмите **Связать с этим приложением**.

  Чтобы отвязать секрет:

  1. Перейдите на вкладку **Секреты приложения**.
  2. Нажмите меню с тремя вертикальными точками <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" width="16" height="16" alt="значок трёх вертикальных точек" data-path="images/icons/vertical-dots.svg" /> рядом с секретом.
  3. Нажмите **Отменить связь**.
</Accordion>

<Accordion title="Удаление секрета аккаунта">
  1. Нажмите значок карандаша <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="значок карандаша" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> рядом с секретом.
  2. Нажмите **Удалить**.
</Accordion>

<div id="section-6">
  ### Управление видимостью секретов
</div>

Видимость секретов зависит от способа доступа к приложению Replit и от того, являетесь ли вы его создателем.

Чтобы поделиться приложением Replit, используйте один из следующих вариантов:

* **Мультиплеер**: пригласите пользователей Replit к совместной работе в реальном времени
* **Страница обложки**: покажите предварительный просмотр приложения Replit с возможностью создать ремикс
* **Ремикс**: опубликуйте личное приложение Replit или приложение организации, чтобы другие могли создавать собственные версии

В таблице ниже показано, кто может видеть имена и значения секретов в различных сценариях:

| Способ доступа     | Кто                                                                                 | Может видеть имя | Может видеть значение |
| ------------------ | ----------------------------------------------------------------------------------- | ---------------- | --------------------- |
| Мультиплеер        | Соавторы в мультиплеере                                                             | ✓                | ✓                     |
| Мультиплеер        | Участники организации с ролью владельца                                             | ✓                | ✓                     |
| Мультиплеер        | Участники организации без роли владельца                                            | ✓                |                       |
| Страница обложки   | Все посетители                                                                      |                  |                       |
| Ремикс             | Владелец или соавтор, создающий ремикс собственного приложения Replit               | ✓                | ✓                     |
| Ремикс             | Пользователь без статуса владельца или соавтора, создающий ремикс приложения Replit | ✓                |                       |
| Ремикс             | Любой, кто создаёт ремикс со страницы обложки                                       | ✓                |                       |
| Ремикс организации | Участники организации с ролью владельца                                             | ✓                | ✓                     |
| Ремикс организации | Участники организации без роли владельца                                            | ✓                |                       |

<Warning>
  Участники организации без роли владельца не могут просматривать значения секретов приложения Replit, но могут получить к ним доступ, выведя переменные окружения.
</Warning>

<div id="section-7">
  ## Секреты для базы данных
</div>

При добавлении Database в Replit редактор проекта автоматически создаёт следующие секреты:

| Секрет         | Описание                             |
| -------------- | ------------------------------------ |
| `DATABASE_URL` | Строка подключения к SQL-базе данных |

<Info>
  Устаревшие базы данных разработки Neon также могут содержать `PGHOST`, `PGUSER`, `PGPASSWORD`, `PGDATABASE` и `PGPORT`. В текущих базах данных разработки Replit вместо них используется `DATABASE_URL`.
</Info>

Чтобы просмотреть все переменные окружения приложения Replit, выполните `printenv` в Shell редактора проекта или выведите их из кода.

<div id="section-8">
  ## Предопределённые переменные окружения
</div>

Replit автоматически задаёт следующие переменные окружения, доступные приложению:

| Переменная окружения | Описание                                                                                          |
| -------------------- | ------------------------------------------------------------------------------------------------- |
| `REPLIT_DOMAINS`     | Список всех доменов, связанных с приложением Replit, разделённых запятыми                         |
| `REPLIT_USER`        | Имя пользователя текущего редактора, которое может отличаться в мультиплеерных сеансах     |
| `REPLIT_DEPLOYMENT`  | Установлено в `1`, если код выполняется в опубликованном приложении; в противном случае не задано |
| `REPLIT_DEV_DOMAIN`  | URL для разработки в домене `replit.dev`, отличный от URL развёртывания                           |

Они не отображаются в инструменте Secrets, но доступны из кода через объект `os.environ` или при выполнении `printenv` в Shell.
