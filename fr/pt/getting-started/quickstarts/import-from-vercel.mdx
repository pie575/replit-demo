<div id="importar-do-vercel">
  ## Importer depuis Vercel
</div>

⏰ *Durée estimée : trois minutes*

Importez un projet Vercel dans Replit en associant le dépôt GitHub lié au projet.

Pour découvrir toutes les options d’importation, y compris depuis d’autres plateformes comme GitHub, Figma, Bolt et Lovable, consultez la [documentation de la fonctionnalité d’importation](/fr/pt/core-concepts/project-editor/app-setup/import).

<div id="antes-de-comear">
  ## Avant de commencer
</div>

* Un projet Vercel connecté à GitHub
* Accès au dépôt GitHub associé
* Un compte Replit

<div id="passos-de-importao">
  ## Étapes d’importation
</div>

1. Ouvrez [replit.com/import](https://replit.com/import).
2. Sélectionnez **Vercel**.
3. Connectez votre compte GitHub.
4. Sélectionnez le dépôt de votre projet Vercel.
5. Ajoutez les secrets et les variables d’environnement demandés.
6. Sélectionnez **Importer**.

<div id="o-que-importado">
  ## Éléments importés
</div>

* Fichiers du projet et structure des répertoires
* Configuration des dépendances et du framework
* Configurations d’exécution et de build pour Replit

<div id="o-que-no-importado">
  ## Éléments non importés
</div>

* Valeurs existantes des variables d’environnement
* Domaines personnalisés
* Comportement spécifique de Vercel lié à l’edge ou au middleware
* Configuration externe d’analyse ou de surveillance

<div id="configure-and-run-your-app">
  ## Configurez et exécutez votre application
</div>

Lors de l’importation, {setupDescription_0}. Si votre application nécessite des modifications, utilisez les outils suivants du Project Editor :

* **[Agent](/fr/features/agent/overview)** : Affinez les fonctionnalités, corrigez les problèmes et modifiez le code
* **[Secrets](/fr/core-concepts/project-editor/app-setup/secrets)** : Ajoutez des clés API et des variables d’environnement
* **[Workflows](/fr/features/workspace-tools/workflows)** : Définissez la commande **Run** de votre application
