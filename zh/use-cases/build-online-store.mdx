将您已有来源中的产品提供给 Agent：Google Sheet (名称、价格、
描述、产品代码、库存) 以及 Google Drive 中的照片。Agent 会搭建 Shopify 商店，
导入产品、价格、描述和图片，并接入结账流程和支付。
店面设计和前端托管在 Replit 中，而非 Shopify 主题中。支付通过 Shopify 结账流程处理，因此
您无需单独配置 Stripe connector。

* 需要自定义 Replit 店面，并以 Shopify 作为电商 backend 的产品设计师。

<div id="before-you-start">
  ## 开始之前
</div>

准备一个 Sheet，每个产品占一行 (名称、价格、描述、产品代码、库存) ；再准备一个存放照片的 Drive
文件夹，并为照片命名，以便 Agent 将其与对应行匹配。连接 Sheets、Drive 和 Shopify。
如果你还没有商店，Agent 可以通过 Chat 配置 Shopify。分享商店前，
请先下一个测试订单。

<div id="prompt-the-agent">
  ## 向 Agent 提示
</div>

<AiPrompt>
  根据此产品来源 [Google Sheet 和 Drive 文件夹]，搭建完整的
  Shopify 商店：导入所有产品的名称、价格、描述和图片。在此 Replit App 中设计并构建
  店面前端 (首页、商品集合页、商品详情页、购物车) 。使用 Shopify 管理商品目录、购物车、结账流程和支付。请勿
  使用 Shopify 主题构建面向客户的页面。
</AiPrompt>

<div id="what-to-expect">
  ## 预期结果
</div>

Agent 会将商品目录导入 Shopify，然后构建一个 Replit 店面，从 Shopify 读取商品信息，
并将客户引导至 Shopify 结账流程。根据表格抽查几件商品 (价格、文案、图片) ，并完成一笔测试订单。使用 Shopify 测试支付，确认
购物车总额与表格一致，并检查结账流程始终在 Shopify 中完成。

<div id="troubleshooting">
  ## 故障排除
</div>

* **照片与产品不匹配：**请按产品代码命名 Drive 文件 (`CODE.jpg`) ，并让 Agent 跳过没有照片的行。
* **价格或文案与 Sheet 不一致：**确认每个产品各占一行 (名称、价格、描述、产品代码、库存) ，并在导入后抽查几个商品。
* **结账流程不是 Shopify，或店面采用主题：**面向客户的页面应托管在 Replit 上。支付通过 Shopify 结账流程完成。分享商店前，请先下一个测试订单。
