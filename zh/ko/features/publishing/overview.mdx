title: "发布"
description: "了解如何使用发布工具发布 Replit App——在一处管理域名、访问权限、数据库、监控、安全性和部署设置。"
---

发布工具可用于将应用部署上线，并管理其在 Web 上的运行方式。它在同一面板中集中提供应用的 Web 地址、访问权限、生产数据库、监控、安全性以及托管方式等设置。

要打开此面板，请在 **Tools** 面板的 **Replit Cloud** 下选择 **Publishing**，或在 Project Editor 右上角选择 **Publish**。

<div id="section">
  ## 发布应用
</div>

主面板会引导你完成发布应用所需的所有设置。检查每个部分后，选择 **Publish**。

<Frame>
  <img src="/assets/mirror/publish-your-app-851815208b8a.png" alt="显示“发布应用”面板，其中包括域名字段、待发布的应用、访问设置、数据库设置、监控、安全和 Publish 按钮上方的互动工具" width="578" height="980" data-path="images/deployments/publish-pane/publish-your-app.png" />
</Frame>

* **域名**：应用的网页地址。Replit 会建议一个 `.replit.app` 域名并检查是否可用。发布后，你可以更改此地址或连接[自定义域名](/zh/ko/features/publishing/custom-domains)。
* **你要发布的内容**：显示待发布应用的预览及其使用的 URL。
* **谁可以访问你的应用**：从 **Public**、**Password protected**、**Workspace only**、**Invite only** 中选择。私密选项会将应用访问权限限制为工作区成员，或受邀的用户和群组。详细了解[应用访问](/zh/ko/features/publishing/private-deployments)。
* **数据库设置**：管理发布时如何创建应用的生产数据库并填充数据。详细了解[生产数据库](/zh/ko/features/data-and-storage/development-and-production)。
* **监控工具**：启用应用监控后，应用宕机时你会第一时间收到通知。Replit 会持续检查应用是否在线，并在出现问题时通过电子邮件通知你。详细了解[应用监控](/zh/ko/features/publishing/monitoring-a-deployment)。
* **安全工具**：在发布前运行深度安全扫描。Security Agent 将 AI 与一流的静态分析工具相结合，以检查项目中的漏洞。详细了解 [Project Security Center](/zh/ko/features/security/project-security-center)。
* **互动工具**：启用反馈小部件后，已发布应用的角落会出现一个反馈按钮。你可以在收件箱中查看提交的反馈，并将其交给 Agent 进行修改。

<div id="section-2">
  ## 调整设置
</div>

选择 **Adjust settings** 可自行配置应用的托管方式。大多数构建者无需更改这些设置，Replit 会为你选择合适的默认值。

<Frame>
  <img src="/assets/mirror/adjust-settings-d6e124b2249f.png" alt="显示部署类型、机器配置、部署密钥、部署地理位置以及阻止发布存在严重漏洞的应用开关的 Adjust settings 部分" width="574" height="794" data-path="images/deployments/publish-pane/adjust-settings.png" />
</Frame>

* **部署类型**：用于发布应用的技术。**Autoscale** 可根据需求从零流量扩展至任意流量规模，因此推荐用于大多数应用。比较[部署类型](/zh/ko/features/publishing/deployment-types)。
* **机器配置**：运行应用的服务器性能。选择 **Edit** 可更改 CPU、内存和最大机器数量。面板会显示每台机器的费用以及最大流量下的费用。详细了解[机器配置](/zh/ko/features/publishing/machine-configuration)。
* **部署密钥**：应用用于访问 API 和服务的私密密钥，可安全地隐藏存储 API 密钥等敏感值。密钥会自动从开发环境同步到已发布的应用。详细了解[Secrets](/zh/ko/core-concepts/project-editor/app-setup/secrets)。
* **部署地理位置**：应用的托管位置。选择更靠近用户的区域可降低延迟。发布后，应用及其相关资源将固定在该区域。如需更改区域，必须重新混编应用。详细了解[项目区域](/zh/ko/features/publishing/project-geography)。
* **阻止发布存在严重漏洞的应用**：Replit 始终会在发布前运行安全扫描。此设置控制发现严重漏洞时是否阻止发布。在 [Project Security Center](/zh/ko/features/security/project-security-center) 中了解详情。
