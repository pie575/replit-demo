<div id="available-task-types">
  ## 可用的 task 类型
</div>

目前提供 3 种 task 类型：`Execute Shell Command`、`Install Packages` 和 `Run Workflow`。

<div id="execute-shell-command">
  ### 执行 Shell 命令
</div>

`Execute Shell Command` 可保存 shell 命令，并在与 Shell 窗格相同的环境中执行。此 task 类型适用于多种场景，例如运行单个文件：

```text theme={null}
python main.py
```

再到执行复杂的已存储数据库查询命令：

```text theme={null}
psql -h 0.0.0.0 -U your_username -d your_database -c "SELECT * FROM your_table;"
```

<div id="install-packages">
  ### 安装软件包
</div>

`Install Packages` 使用 Replit 内置的依赖项管理系统，自动检测项目的依赖项并安装所需的软件包。有关 UPM 如何在后台判断要为项目安装哪些软件包的更多信息，请参阅[依赖项管理](/zh/features/project-setup/dependency-management#the-universal-package-manager)。

<div id="run-workflow">
  ### 运行 Workflow
</div>

`Run Workflow` 可让你从当前工作流中运行另一个工作流，从而复用并组合工作流，创建更复杂的工作流。

使用示例：

<Frame>
  <img src="/assets/mirror/example-run-workflow-62f93cd1bf00.webp" alt="图片" width="720" height="678" data-path="images/workflows/example-run-workflow.webp" />

使用此 task 类型可在工作流之间建立依赖关系：编辑一个工作流后，引用它的其他工作流会自动使用最新更改。请注意，深度嵌套的工作流调用存在层级限制。

<div id="workflow-execution-mode">
  ## Workflow 执行模式
</div>

Workflows 提供两种执行模式：顺序执行和并行执行。

<div id="sequential">
  ### 顺序执行
</div>

顺序执行会按定义的顺序运行每个 task，等待当前 task 完成后再进入下一步。如果 工作流 中的某个 task 失败，序列将停止执行。

此模式适用于定义逻辑上相互关联的命令，例如先从主分支获取最新更改，再将当前分支变基到主分支上的 git 命令：

<Frame>
  <img src="/assets/mirror/example-sequential-workflow-62ae8a64038f.png" alt="图像" width="721" height="654" data-path="images/workflows/example-sequential-workflow.png" />
</Frame>

<div id="parallel">
  ### 并行
</div>

并行执行会同时运行各个 task，每个 task 都会独立于 工作流 中的其他 task 启动和运行。某个 task 失败不会中止其他 task 的执行。

例如，对于需要同时启动 frontend 和 backend 服务器的全栈 项目，可以使用此模式：

<div id="creating-workflows">
  ## 创建 工作流
</div>

在 工作流 面板中点击 `+ New Workflow` 按钮即可创建 工作流。首先，为 工作流 命名并确保名称具有描述性，选择合适的执行模式，然后开始添加 task。你可以通过拖放 task 来调整其顺序。

<div id="assign-workflow-to-run-button">
  ## 将 Workflow 分配给 Run 按钮
</div>

你也可以将工作流分配给 Run 按钮，以替代其默认行为 (请参阅[配置 Replit App](/zh/features/project-setup/configuration)) 。如需保留在 `.replit` 中配置的默认 Run 命令，请在下拉菜单中选择默认的“Run Replit App”选项。

点击 Run 按钮时，系统会运行其旁边下拉菜单中选定的工作流。要更改 Run 按钮运行的工作流，请在下拉菜单中点击所需的工作流。
