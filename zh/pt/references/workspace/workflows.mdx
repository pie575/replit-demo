它是一系列可复用、可自定义的步骤，可以在你的 Replit App 中运行。它既可以简单到只执行 `python main.py`，也可以复杂到运行一套多步骤流程。

<div id="tipos-de-tarefas-disponveis">
  ## 可用的任务类型
</div>

目前提供 3 种任务类型：`Execute Shell Command`、`Install Packages` 和 `Run Workflow`。

<div id="execute-shell-command">
  ### Execute Shell Command
</div>

`Execute Shell Command` 会保存一条 shell 命令，并在与 Shell 面板相同的环境中执行该命令。这种任务类型的适用场景非常广泛，既可以运行单个文件：

```text theme={null}
python main.py
```

甚至可以执行存储的复杂数据库查询命令：

```text theme={null}
psql -h 0.0.0.0 -U your_username -d your_database -c "SELECT * FROM your_table;"
```

<div id="install-packages">
  ### 安装包
</div>

`Install Packages` 使用 Replit 内置的依赖项管理系统，自动检测项目依赖项并安装所需的包。有关 UPM 如何判断项目需要安装哪些包的详细信息，请参阅[依赖项管理](/zh/pt/references/workspace/dependency-management#the-universal-package-manager)。

<div id="run-workflow">
  ### Run Workflow
</div>

`Run Workflow` 允许你在当前工作流中运行另一个工作流。这样你就可以复用工作流，并将多个工作流组合起来，构建更复杂的流程。

用例示例：

<Frame>
  <img src="/assets/mirror/example-run-workflow-62f93cd1bf00.webp" alt="image" width="720" height="678" data-path="images/workflows/example-run-workflow.webp" />
</Frame>

使用这种任务类型在工作流之间建立依赖关系后，你只需编辑某个工作流，引用它的其他工作流就会自动使用最新的更改。请注意，工作流的嵌套调用存在层级深度限制。

<div id="modo-de-execuo-do-workflow">
  ## 工作流执行模式
</div>

工作流提供两种不同的执行模式：顺序执行和并行执行。

<div id="sequencial">
  ### 顺序执行
</div>

顺序执行会按设定的顺序运行各项任务，在继续下一步之前等待每项任务完成。如果工作流程中的某项任务失败，序列执行将停止。

这种模式适用于定义在逻辑上相互关联的命令，例如使用 Git 命令获取主分支的最新更改，然后将当前分支变基到主分支：

<Frame>
  <img src="/assets/mirror/example-sequential-workflow-62ae8a64038f.png" alt="图像" width="721" height="654" data-path="images/workflows/example-sequential-workflow.png" />
</Frame>

<div id="paralelo">
  ### 并行
</div>

并行执行会同时运行各个任务，每个任务都会独立于工作流中的其他任务启动和执行。某个任务失败不会中断其他任务的执行。

这种模式的一个典型用例是运行全栈项目，需要同时启动前端和后端服务器：

<div id="criando-workflows">
  ## 创建工作流
</div>

通过工作流面板点击 `+ New Workflow` 按钮即可创建工作流。首先为工作流设置一个描述性名称，选择合适的运行模式，然后开始添加任务。你可以通过拖放任务，按所需顺序重新排列它们。

<div id="atribuir-workflow-ao-boto-run">
  ## 将 Workflow 分配给 Run 按钮
</div>

你还可以将 Workflow 分配给 Run 按钮，以替代其默认行为 (参阅[配置 Replit App](/zh/pt/references/configuration/configuration)) 。若要保留 `.replit` 中配置的默认运行命令，请在下拉菜单中选择默认选项“Run Replit App”。

点击 Run 按钮时，会执行其旁边下拉菜单中选定的 Workflow。要更改 Run 按钮执行的 Workflow，请在下拉菜单中点击所需的 Workflow。
