<div id="section-4">
  ## 预期结果
</div>

Agent 会创建一个包含商家名称、金额、付款周期和每月总计的表格。请将原始
邮件与其中几行数据进行核对。标题中未包含“subscription”的商家可能会在首次运行时遗漏，
请添加相应标签后重新运行。选择三家您熟悉的商家，打开 Gmail 收据，并在确认每月总计
可信之前核对金额和付款周期。

<div id="section-6">
  ## 故障排查
</div>

* **已知订阅未出现在表格中：**告诉 Agent 要使用的 Gmail 标签或搜索词，并将邮件主题中未包含“subscription”的商家也纳入其中。将原始邮件与几行数据进行核对。
* **金额或付款周期似乎不正确：**收据通常会显示税费、余额抵扣或其他货币。告诉 Agent 保留邮件中的各项金额和付款周期，并为推断出的行添加标记。
* **同一商家出现两次：**告诉 Agent 按商家名称合并，保留最新收据，然后重新计算每月总计。
