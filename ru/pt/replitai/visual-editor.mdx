<div id="o-que-o-visual-editor">
  ## Что такое Visual Editor?
</div>

Visual Editor позволяет вносить изменения в интерфейс, нажимая непосредственно на элементы. Он работает как в [Design Canvas](/ru/pt/replitai/canvas), так и в Prévia, поэтому вы можете одинаково редактировать макеты и работающие приложения.

Простые правки — изменения текста, настройка цветов, корректировка отступов — напрямую обновляют исходный код без расхода кредитов ИИ. Если изменения требуют более сложной обработки, Visual Editor автоматически передаёт их Agent.

Основные понятия:

* **Детерминированные правки**: Простые изменения (текст, цвета, отступы) применяются непосредственно к исходному коду без участия Agent
* **Без расхода кредитов**: Прямые правки не расходуют кредиты ИИ — через Agent обрабатываются только сложные изменения
* **Двойной контекст**: Работает одинаково во фреймах Design Canvas и в Prévia
* **Синхронизация с исходным кодом**: Каждая правка мгновенно обновляет соответствующий исходный код

<Note>
  Visual Editor сейчас доступен только в **веб-браузерах**. Он не поддерживается в приложениях Mobile и Desktop.
</Note>

<div id="como-usar-o-visual-editor">
  ## Как использовать Visual Editor
</div>

<div id="editando-na-prvia">
  ### Редактирование в Prévia
</div>

Нажмите на любой элемент работающего приложения, чтобы начать редактирование. Меняйте текст, цвета, отступы или изображения — и сразу видите результат.

<Steps>
  <Step title="Выберите элемент">
    Нажмите на любой элемент в Prévia, чтобы начать редактирование.
  </Step>

  <Step title="Внесите изменения">
    Редактируйте текст прямо на месте, подбирайте цвета с помощью палитры, меняйте отступы через элементы управления стилями или заменяйте изображения. Для дополнительных свойств, таких как внутренний отступ, внешний отступ и других, используйте панель редактора в Chat.
  </Step>

  <Step title="Сохраните">
    Нажмите «Сохранить», чтобы обновить исходный код. Простые изменения применяются напрямую и не расходуют кредиты ИИ. Если правка сложнее, Visual Editor передаёт Agent точечные метаданные, чтобы тот помог с изменением.
  </Step>
</Steps>

<div id="editando-no-canvas">
  ### Редактирование в Canvas
</div>

Тот же режим редактирования работает и во фреймах Design Canvas. Нажмите на любой элемент внутри фрейма, чтобы отредактировать его: измените размер, текст, цвета и отступы в своих макетах, не запуская цикл работы с Agent.

<div id="o-que-voc-pode-fazer">
  ## Что можно делать
</div>

* **Быстрые правки текста**: обновляйте тексты, подписи и заголовки, не открывая исходные файлы кода
* **Подбор цветов**: пробуйте разные цветовые схемы кликом и настройкой — не нужно искать нужное правило CSS
* **Настройка макета**: визуально меняйте внутренние отступы, внешние отступы и отступы вместо того, чтобы угадывать значения в пикселях
* **Замена изображений**: меняйте изображения-заглушки на настоящие — достаточно кликнуть и загрузить файл
* **Итерации дизайна**: быстро правьте фреймы на Canvas, чтобы сравнить визуальные направления без лишних обращений к Agent

<div id="perguntas-frequentes">
  ## Часто задаваемые вопросы
</div>

<Accordion title="Расходуют ли изменения в Visual Editor кредиты ИИ?">
  Простые и предсказуемые правки — изменение текста, выбор цветов, настройка отступов — не расходуют кредиты ИИ. Они напрямую обновляют исходный код. Если Visual Editor обнаружит скрытую сложность, он передаст изменение Agent, что потребует кредитов.
</Accordion>

<Accordion title="Можно ли редактировать элементы, которые отображаются в нескольких местах?">
  Да. При выборе элемента, отрисованного в цикле или повторно используемого в компонентах, одновременно выделяются и обновляются все его экземпляры.
</Accordion>

<Accordion title="Почему я не могу редактировать текст в некоторых элементах?">
  Текст в составных элементах, состоящих из нескольких вложенных элементов, нельзя редактировать напрямую в Visual Editor. Попросите Agent в Chat внести эти изменения.
</Accordion>

<Accordion title="Как найти исходный код элемента?">
  Нажмите метку в левом верхнем углу выбранного элемента, чтобы перейти к соответствующему месту в исходном коде.
</Accordion>
