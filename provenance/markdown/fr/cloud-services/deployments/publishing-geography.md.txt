# Géographie de publication

> Choisissez l'emplacement où votre projet publié s'exécute et stocke les données en sélectionnant une géographie de publication.

Lorsque vous publiez un projet Replit, vous pouvez choisir la région géographique où les ressources de calcul et de stockage de votre projet sont hébergées. Par défaut, Replit recommande la géographie la plus proche de vous. Cela contribue à réduire la latence pour les visiteurs de votre application et à respecter les exigences de résidence des données.

<Note>
  La sélection de la géographie de publication est disponible pour les développeurs sur les plans Core, Pro et Enterprise.
  Les développeurs sur le plan gratuit publient par défaut dans la géographie Amérique du Nord.
</Note>

## Géographies disponibles

Replit prend en charge les géographies de publication suivantes :

| Géographie           | Description                                           |
| :------------------- | :---------------------------------------------------- |
| **Amérique du Nord** | Héberge votre projet en Amérique du Nord (par défaut) |
| **Europe (UE)**      | Héberge votre projet dans l'Union européenne          |
| **Amérique du Sud**  | Héberge votre projet en Amérique du Sud               |
| **Australie**        | Héberge votre projet en Australie                     |
| **Asie**             | Héberge votre projet en Asie                          |

<Note>
  L'Amérique du Nord et l'Europe (UE) sont disponibles pour tous les développeurs éligibles. L'Amérique du Sud,
  l'Asie et l'Australie sont déployées progressivement et peuvent ne pas encore être
  visibles dans la liste déroulante des géographies. Si vous ne voyez pas une géographie dont vous avez besoin,
  contactez le support Replit.
</Note>

Lorsque vous sélectionnez une géographie, tous les artefacts publiés de votre projet (tels que le calcul, la base de données et le stockage d'objets) sont automatiquement colocalisés dans la même région. Un proxy spécifique à la géographie contribue également à réduire la latence pour les visiteurs de votre application.

## Sélectionner une géographie

Par défaut, Replit recommande la géographie la plus proche de vous. Pour choisir une géographie différente :

<Steps>
  <Step>
    Ouvrez l'outil **Publication** dans votre projet Replit.
  </Step>

  <Step>
    Développez les paramètres **Avancés**.
  </Step>

  <Step>
    Sélectionnez votre géographie préférée dans la liste déroulante **Géographie**.
  </Step>

  <Step>
    Sélectionnez **Publier** pour publier votre projet dans la géographie sélectionnée.
  </Step>
</Steps>

## Imposer une géographie aux projets publiés

Les administrateurs Enterprise peuvent imposer une géographie de publication pour tous les projets de leur organisation. Lorsqu'une politique est définie, les développeurs de l'organisation publient dans la géographie configurée. Cette politique s'applique uniquement aux projets qui n'ont pas encore été publiés — les projets déjà publiés dans une géographie différente ne sont pas affectés.

<Note>
  L'imposition d'une géographie de publication est une fonctionnalité Enterprise. Pour en savoir plus sur les plans Enterprise, consultez [Tarification](https://replit.com/pricing/).
</Note>

<Steps>
  <Step>
    Accédez à vos **Paramètres de compte**.
  </Step>

  <Step>
    Sélectionnez **Avancé**.
  </Step>

  <Step>
    Choisissez la géographie que tous les projets publiés pour la première fois doivent utiliser.
  </Step>
</Steps>

## Limitations

Avant de sélectionner une géographie, gardez les limitations suivantes à l'esprit :

* **La géographie ne peut pas être modifiée après la publication.** Une fois votre projet publié dans une géographie, cette sélection est permanente. Vous ne pouvez pas migrer un projet publié vers une géographie différente.
* **Les artefacts de l'environnement de développement peuvent ne pas correspondre à votre géographie de publication.** Des ressources telles que le stockage d'objets peuvent être créées avant la publication. Tous les environnements de développement s'exécutent actuellement en Amérique du Nord. La prise en charge de l'hébergement de votre environnement de développement dans la région de publication la plus proche est prévue prochainement.
