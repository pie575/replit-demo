<div id="o-que-voc-recebe">
  ## Ce dont vous bénéficiez
</div>

Le forfait Starter vous offre tout ce dont vous avez besoin pour commencer à créer sur Replit. Créez des apps et publiez votre premier projet, le tout gratuitement.

<div id="crditos-dirios-para-o-agent">
  ### Crédits quotidiens pour Agent
</div>

Les utilisateurs du forfait Starter reçoivent des crédits quotidiens pour utiliser Agent, dans la limite d’un plafond mensuel. Ces crédits sont réinitialisés chaque jour, vous offrant ainsi une nouvelle enveloppe pour travailler avec Agent.

<div id="crditos-mensais-para-uso-na-nuvem">
  ### Crédits mensuels d&#39;utilisation du cloud
</div>

Vous recevez également des crédits mensuels utilisables pour :

* [Bases de données (production)](/fr/features/data-and-storage/development-and-production)
* [Stockage d&#39;objets](/fr/pt/features/data-and-storage/object-storage)
* [Publication (mise à l&#39;échelle automatique, statique)](/fr/pt/learn/projects-and-artifacts/replit-deployments)

Ces crédits sont réinitialisés chaque mois.

<div id="build-lite">
  ### Build Lite
</div>

Accès à [Build Lite](/fr/pt/features/agent/agent-modes), une expérience de build rapide et ciblée pour des modifications rapides et précises avec Agent.

<div id="um-app-publicado-gratuito">
  ### Une application publiée gratuitement
</div>

Obtenez {FreeDeployments} application publiée gratuitement, que vous utilisiez Build Lite ou le Design Canvas. Ce lien expirera automatiquement après 30 jours.

Votre application publiée inclura un badge « Créé avec Replit » contenant votre lien de parrainage unique. Si un autre utilisateur s’inscrit via ce lien à partir de votre badge, vous recevrez des crédits de parrainage dès qu’il passera à un forfait payant.

<div id="limitaes">
  ## Limitations
</div>

Les fonctionnalités suivantes nécessitent de passer à l’offre Core :

<div id="build-completo">
  ### Build complet
</div>

Le [Build complet](/fr/pt/features/agent/overview/) permet à Agent de travailler de manière autonome, avec davantage de capacités. Les créateurs disposant du forfait Starter ne peuvent utiliser que [Build Lite](/fr/pt/features/agent/agent-modes). Le Build complet nécessite un forfait Core ou Pro.

<div id="converter-um-design-em-artefato">
  ### Convertir un design en artefact
</div>

La conversion d’un design du Design Canvas en artefact complet nécessite le forfait Core. Les créateurs disposant du forfait Starter peuvent créer des designs et les publier, mais leur conversion en artefact avec des fonctionnalités backend nécessite une mise à niveau. Si vous souhaitez créer une app avec des fonctionnalités backend, essayez de commencer avec [Build Lite](/fr/pt/features/agent/agent-modes).

<div id="conectores-de-terceiros">
  ### Connecteurs tiers
</div>

Les connecteurs externes nécessitent l’offre Core. Cela inclut les intégrations avec des services tels que Google, Stripe et d’autres API tierces (pour en savoir plus, consultez [cette page](https://docs.replit.com/features/integrations/overview#connectors)).

<div id="integraes-de-ia-do-replit">
  ### intégrations d&#39;IA de Replit
</div>

Les [intégrations d&#39;IA de Replit](/fr/pt/features/integrations/replit-ai-integrations) nécessitent Core.

<div id="remover-o-badge-criado-com-replit">
  ### Supprimer le badge « Créé avec Replit »
</div>

La suppression du badge « Créé avec Replit » de vos apps publiées nécessite le forfait Core. Le badge sera affiché sur les déploiements des utilisateurs du forfait Starter.

<div id="apps-publicados-adicionais">
  ### Applications publiées supplémentaires
</div>

Les utilisateurs du forfait Starter bénéficient de {FreeDeployments} application publiée gratuitement. Les applications publiées supplémentaires nécessitent Core ou Pro.

<div id="modo-de-planejamento">
  ### Mode Planification
</div>

L’utilisation du mode Planification nécessite l’abonnement Core. Le mode Planification vous permet d’explorer des idées, de planifier des tâches et de collaborer avec Replit Agent sans modifier le code ni les données de votre app.

<div id="todos-os-tipos-de-artefato">
  ### Tous les types d’artefacts
</div>

La création d’artefacts autres que des applications web et mobiles nécessite Core. Choisissez parmi différents types, notamment des visualisations de données, des présentations, des vidéos animées et bien plus encore. Consultez [Projets](/fr/pt/features/projects-and-artifacts/projects).

<div id="upgrade-para-core">
  ## Passez à Core

* Et bien plus encore
