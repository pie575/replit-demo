<div id="o-que-o-modo-plan">
  ## Qu&#39;est-ce que le mode Plan ?
</div>

Le mode Plan vous permet de :

* **Faire du brainstorming d'idées** et explorer différentes approches pour votre projet
* **Planifier le travail de développement** à l&#39;aide de listes de tâches structurées
* **Collaborer avec l&#39;IA** sur l&#39;architecture du projet et la planification des fonctionnalités
* **Obtenir des conseils stratégiques** et poser des questions sans modifier le code ni les données de votre projet
* **Passer en toute fluidité** au mode Build dès que vous êtes prêt à implémenter

Le mode par défaut s&#39;appelle désormais le mode **Build**.

Contrairement au mode Build, le mode Plan est axé sur la planification et l&#39;idéation : il vous aide à réfléchir à vos projets avant d&#39;écrire la moindre ligne de code.

<div id="primeiros-passos">
  ## Premiers pas
</div>

<div id="acessando-o-modo-plan">
  ### Accéder au mode Plan
</div>

Le mode Plan est disponible dans toute Replit App où Agent est activé. Pour y accéder :

1. **Ouvrez votre Replit App** dans l&#39;éditeur de projets
2. **Repérez le sélecteur de mode** en bas à gauche de la zone de saisie du Chat
3. **Choisissez le mode Plan** dans le menu déroulant

<div id="principais-recursos">
  ## Principales fonctionnalités
</div>

<div id="planejamento-de-tarefas">
  ### Planification des tâches
</div>

Le mode Plan excelle à décomposer les projets complexes en tâches gérables. Indiquez quelques exigences à Agent : il génère alors une liste de tâches ordonnée présentant les étapes de développement nécessaires pour répondre à votre demande.

<div id="brainstorming-colaborativo">
  ### Brainstorming collaboratif
</div>

Travaillez main dans la main avec l&#39;IA pour explorer différentes approches :

* **Plusieurs pistes de solution** pour les problèmes complexes
* **Analyse des avantages et des inconvénients** des différentes approches
* **Évaluation des risques** et stratégies d&#39;atténuation

<div id="fluxo-de-trabalho-do-planejamento-construo">
  ## Flux de travail : de la planification à la création
</div>

<div id="1-fase-de-planejamento-modo-plan">
  ### 1. Phase de planification (mode Plan)
</div>

Lancez votre processus de développement en mode Plan :

* **Définissez le périmètre de votre projet** et ses objectifs
* **Décomposez les exigences** en fonctionnalités précises
* **Planifiez votre architecture** et votre stack technologique
* **Créez une feuille de route de développement** jalonnée d&#39;étapes clés

<div id="2-aprovao-de-tarefas">
  ### 2. Approbation des tâches
</div>

Lorsque l&#39;Agent génère une liste de tâches :

* **Passez en revue** les tâches proposées
* Sélectionnez **Commencer à construire** pour approuver le plan

ou poursuivez la conversation pour affiner le plan.

<div id="3-transio-para-o-modo-build">
  ### 3. Transition vers le mode Build
</div>

Lorsque vous êtes prêt à passer à l&#39;implémentation :

* **Cliquez sur « Commencer à construire »** pour approuver le plan
* **L&#39;Agent bascule automatiquement** en mode Build
* **L&#39;Agent lance l&#39;implémentation** des tâches approuvées
* **Suivez la progression** pendant la phase de développement

Le mode Plan est soumis à la même tarification basée sur l&#39;effort que les autres interactions avec l&#39;Agent. Tout le travail réalisé par l&#39;Agent en mode Plan vous est facturé, y compris les réponses à vos questions, les conseils fournis et la génération de listes de tâches. Les coûts augmentent pour les demandes plus complexes ou celles formulées dans des conversations au contexte plus long.

**Toutes les interactions avec l&#39;Agent sont facturables** — que l&#39;Agent réponde par des conseils textuels ou qu&#39;il modifie le code, des frais s&#39;appliquent toujours, même si les demandes plus modestes coûtent moins cher.

<div id="boas-prticas">
  ## Bonnes pratiques
</div>

<div id="prompting-eficaz">
  ### Rédiger des prompts efficaces
</div>

Pour tirer le meilleur parti du mode Plan :

* **Soyez précis** sur les exigences de votre projet
* **Posez des questions complémentaires** pour clarifier les suggestions de l&#39;IA
* **Demandez des exemples** lorsque vous abordez des concepts complexes
* **Discutez des compromis** entre les différentes approches
* **Itérez sur les idées** avant de vous lancer dans l&#39;implémentation
* **Conservez les décisions importantes** en y faisant référence dans les conversations ultérieures
