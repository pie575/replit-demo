</div>

**Draft**는 Agent가 계획은 세웠지만 아직 빌드를 시작하지 않은 task입니다. Draft에는 제안된 작업 내용, 즉 task 제목, 설명, 계획만 담겨 있으므로 안심하고 검토할 수 있습니다.

Draft를 통해 Agent가 목표를 제대로 이해했는지 확인하세요. 그런 다음 task를 시작하거나, Agent에게 계획 수정을 요청하거나, 나중을 위해 draft를 보관할 수 있습니다.

<div id="active">
  ## Active
</div>

**Active** 상태의 task는 백그라운드에서 실행됩니다. Agent가 project의 격리된 사본에서 작업하기 때문에, task가 실행되는 동안에도 메인 버전은 그대로 유지됩니다.

Active task가 실행되는 중에도 main thread는 계속 사용할 수 있습니다. task에 feedback이 필요한 경우 해당 thread를 열어 그곳에서 대화를 이어가세요.

<div id="queued">
  ## Queued
</div>

**Queued** task는 승인되었지만 아직 시작되지 않고 대기 중인 task입니다. 다른 task에 의존하거나 계획의 활성 백그라운드 task limit에 도달한 경우 task가 대기열에 들어갈 수 있습니다.

대기열에 있는 task는 선행 조건이 완료되고 활성 task 슬롯이 생기면 자동으로 시작됩니다.

<div id="ready">
  ## Ready
</div>

**Ready** 상태의 task는 작업은 끝났지만 아직 변경 사항이 메인 버전에 적용되지 않은 상태입니다. 변경 사항을 적용하기 전에 task의 작업 로그, 테스트 결과, Preview를 확인하세요.

결과가 만족스러우면 메인에 적용하고, 원하던 결과가 아니라면 해당 작업을 무시하고 새 task를 시작하세요.

<div id="applying">
  ## Applying
</div>

**Applying** 상태의 task는 변경 사항을 메인 버전에 반영하는 중입니다. Agent는 여러 task의 변경 사항을 적용할 때 발생하는 충돌을 자동으로 처리합니다.

최종 결과를 판단하기 전에 적용이 완료될 때까지 기다리세요. 적용 후 이상한 점이 보이면 main thread에서 Agent에게 수정을 요청하세요.

<div id="done">
  ## Done
</div>

**Done** 상태의 task는 완료되어 더 이상 조치가 필요하지 않습니다. Done은 해당 task가 메인 버전에 적용되었거나, 시작 전에 보관 처리되었거나, building 단계로 넘어간 후 취소되었음을 뜻합니다.

**Done** 열은 완료, 보관, 취소된 task 작업의 기록으로 활용하세요.

<div id="archiving-and-cancelling-tasks">
  ## task 보관 및 취소
</div>

task는 수명 주기의 어느 시점에서든 중단할 수 있지만, 표시되는 옵션은 task가 board의 어느 위치에 있는지에 따라 달라집니다. **Archive**와 **Cancel** 모두 task를 **Done** 열로 옮기지만, 동작 방식은 다릅니다:

| 작업          | 사용 가능한 시점                                                                     | 동작                                                                      | 되돌릴 수 있나요?                                                |
| ----------- | ----------------------------------------------------------------------------- | ----------------------------------------------------------------------- | --------------------------------------------------------- |
| **Archive** | task가 아직 계획 session인 경우: building을 시작하지 않은 **Draft**                          | 계획 session이 실행되지 않은 채 보류됩니다. 해당 계획은 그대로 보존됩니다.                        | 예. **Done** 열의 보관된 카드를 열어 **Drafts**로 되돌릴 수 있습니다.         |
| **Cancel**  | task가 계획 단계에서 building으로 넘어간 후: **Active**, **Queued**, **Ready** 상태의 모든 task | Agent가 task를 중단하고 진행 중이던 작업을 모두 폐기합니다. 메인 버전에는 어떤 변경 사항도 적용되지 않습니다. | 아니요. 취소된 task는 복원할 수 없습니다. 해당 작업을 다시 진행하려면 새 task를 시작하세요. |

나중에 다시 진행할 계획 session에는 **Archive**를 사용하세요. queue에 있거나, 이미 실행 중이거나, building이 끝난 task를 영구적으로 중단하려면 **Cancel**을 사용하세요.

보관된 계획 session과 취소된 task는 모두 task board 맨 오른쪽의 **Done** 열에서 완료된 task와 함께 확인할 수 있습니다.
