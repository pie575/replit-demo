## Plataforma

### O Agent agora suporta servidores MCP personalizados

O Agent agora pode se conectar a servidores remotos de Model Context Protocol (MCP), dando acesso a novas capacidades e ferramentas com configuração mínima. Isso desbloqueia a capacidade do Agent de chamar ferramentas externas e obter contexto de sistemas remotos.

Com servidores MCP personalizados, você pode:

* Conectar a servidores remotos que obtêm contexto e realizam ações em ferramentas externas
* Acessar centenas de ferramentas e fontes de dados por meio do padrão aberto MCP
* Carregar automaticamente as ferramentas que cada servidor disponibiliza

Parceiros podem integrar seus serviços com o Agent expondo um servidor MCP — sem trabalho adicional de integração necessário.

## Equipes e Enterprise

### Conector Plaid para Enterprise

Clientes Enterprise agora podem habilitar o Conector Plaid para conectar contas bancárias e criar apps com primitivos de fintech. Este conector está em desenvolvimento ativo, com novos recursos e melhorias sendo adicionados com base no feedback dos clientes.

Com o Conector Plaid, você pode:

* Conectar contas bancárias aos seus aplicativos
* Acessar primitivos de fintech para criar recursos financeiros
* Gerenciar conectores centralmente por meio do painel de administração
