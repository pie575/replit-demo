<div id="section-3">
  ### Новый интерфейс интеграций
</div>

Теперь все сервисы, к которым подключается Replit, доступны в одном месте. На обновлённой странице интеграций коннекторы, MCP-серверы и Git-провайдеры представлены в виде интерактивных карточек. Также появились фильтры по категориям и значки, указывающие на интеграции, которые Replit может подключать автоматически. В каталоге представлено более 450 интеграций; для каждой доступна отдельная страница с примерами использования. Ознакомиться с полным каталогом можно на [replit.com/integrations](https://replit.com/integrations).

<div id="slackreplit">
  ### Использование Replit в Slack
</div>

Replit стал партнёром по запуску MCP-клиента Slackbot в Slack. Попросите Slackbot создать приложение в Replit — и вы сможете создавать, обновлять и просматривать приложения Replit прямо в Slack. Продолжайте общаться, пока Replit Agent выполняет работу.

<div id="scim">
  ### Несколько рабочих пространств для клиентов, использующих SCIM
</div>

Клиенты Enterprise, которые подключают участников через SCIM, теперь могут создавать несколько рабочих пространств. Распределяя синхронизированные группы по отдельным рабочим пространствам, вы получаете более четкие границы доступа, контроль бюджета и разделение команд, при этом поставщик удостоверений остается источником достоверных данных. Функция доступна по открытой регистрации для новых клиентов Enterprise.

Подробнее см. в разделе [Доступ к рабочему пространству через SCIM](/ru/ja/teams/identity-and-access-management/scim#managing-workspace-access).
