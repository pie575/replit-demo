# Geografia do workspace

> Escolha onde os recursos de desenvolvimento de um Workspace e seus novos projetos são hospedados.

A geografia do workspace controla onde os recursos de desenvolvimento de um Workspace são hospedados. Você a seleciona ao criar o Workspace, e novos projetos e recursos nesse Workspace usam o local selecionado.

<Note>
  A geografia do workspace e a [geografia de
  publicação](/pt/features/security/geography#publishing-geography) podem ser
  diferentes. A geografia de publicação controla onde um projeto publicado é
  executado.
</Note>

## O que a geografia do workspace controla

Um Workspace reúne projetos, pessoas, configurações, recursos compartilhados, integrações e faturamento. Dentro de cada projeto, você usa o Project Editor e o chat do Replit. Os recursos de desenvolvimento incluem a versão de desenvolvimento do seu app e seu banco de dados de desenvolvimento.

Somente clientes Pro podem selecionar uma região específica para o workspace.

Clientes Free e Core têm a região do workspace definida automaticamente. Isso geralmente seleciona a região de workspace mais próxima de você. Novos projetos e recursos no workspace usam esse local. Você não pode mudar a região depois de criar o workspace.

## Selecione uma região para o workspace

Se você é cliente Pro, pode selecionar uma região ao criar um workspace:

<Steps>
  <Step>Abra o formulário **Create a new workspace**.</Step>

  <Step>
    Digite o nome do workspace e, opcionalmente, os endereços de e-mail dos
    membros.
  </Step>

  <Step>
    Abra **Workspace region** e selecione **North America**, **Europe (EU)**
    ou **Asia**.
  </Step>

  <Step>Selecione **Create workspace**.</Step>
</Steps>

## Geografias disponíveis

| Geografia         | Seleção no workspace |
| :---------------- | :------------------- |
| **North America** | Sim                  |
| **Europe (EU)**   | Sim                  |
| **Asia**          | Sim                  |
| **South America** | Não                  |
| **Australia**     | Não                  |
