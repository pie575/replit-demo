title: "Статические развёртывания"
description: "Узнайте, как публиковать статические сайты и фронтенд-приложения с помощью статических развёртываний."
---

Статические развёртывания размещают статические файлы вашего Replit App, такие как HTML, CSS и JavaScript,
на облачном сервере. Сервер автоматически использует кэширование и масштабирование, чтобы
быстро и экономично предоставлять ваш контент.

Статические развёртывания идеально подходят для следующих задач:

* Маркетинговые лендинги
* Сайты-портфолио
* Сайты с документацией по продуктам и API

<Note>
  Статические развёртывания не поддерживают Replit Apps, созданные с помощью Agent.
  Agent автоматически создаёт полностековые приложения, которым требуется бэкенд-сервер. Для
  приложений, созданных с помощью Agent, используйте один из следующих типов развёртывания: - [Autoscale
  Deployment](/ru/pt/cloud-services/deployments/autoscale-deployments) - [Reserved VM
  Deployment](/ru/pt/cloud-services/deployments/reserved-vm-deployments)
</Note>

<div id="recursos">
  ## Возможности
</div>

Статические развёртывания предлагают следующие возможности:

* **Экономичный хостинг**: Платите только за объём данных, передаваемых вашим сайтом.
* **Настройки HTTP-маршрутизации**: Настраивайте заголовки ответов, перезаписи URL и перенаправления.
* **Пользовательские домены**: Настройте пользовательский домен или используйте URL `<имя-приложения>.replit.app` для доступа к App.
* **Пользовательские страницы ошибок**: Создавайте и размещайте пользовательские страницы ошибок 404.
* **Мониторинг**: Просматривайте логи и отслеживайте статус опубликованного App.

<div id="uso">
  ## Использование
</div>

Открыть статические развёртывания можно в инструменте Publishing в Project Editor.

<Accordion title="Как открыть статические развёртывания">
  В **панели инструментов** слева:

  1. Выберите <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Иконка всех инструментов" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**, чтобы просмотреть список инструментов Project Editor.
  2. Выберите <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Иконка Publishing" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publishing**.
  3. Выберите **Static**, затем — **Set up your published app**.

  В **строке поиска**:

  1. Выберите <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="Иконка лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> иконку лупы в верхней части экрана, чтобы открыть поиск.
  2. Введите «Publishing», найдите инструмент и выберите его в результатах поиска.
  3. Выберите **Static**, затем — **Set up your published app**.
</Accordion>

<div id="domnio-principal">
  ### Основной домен
</div>

Укажите поддомен для вашего опубликованного App. После публикации ваш App будет доступен по адресу `https://<subdomain>.replit.app`.

Подробнее об использовании пользовательского домена см. в разделе [Custom Domains](/ru/features/publishing/custom-domains).

<div id="deployment-privado">
  ### Приватный deployment
</div>

<Info>
  Функция приватных опубликованных приложений доступна в тарифах Pro и Enterprise.
</Info>

Приватные опубликованные приложения доступны только участникам вашего workspace, а также конкретным пользователям и группам, которых вы пригласите.
При публикации можно выбрать режим доступа **Public**, **Password protected**, **Workspace only** или **Invite only**.

Подробнее о настройке приватного deployment см. в разделе [Доступ к App](/ru/features/publishing/private-deployments/).

<div id="diretrio-pblico">
  ### Публичный каталог
</div>

Укажите путь к базовому каталогу вашего Replit App, содержащему статические файлы, которые должны быть общедоступны.
После развёртывания облачный хост отдаёт все страницы и ассеты из этого каталога.

Значение по умолчанию, `/`, — корневой каталог вашего Replit App.

<div id="build-command">
  ### Команда сборки
</div>

Укажите команду сборки, которая будет выполняться в Shell вашего Replit App при создании развертывания.

Например, если вы создаёте статический сайт с помощью <a href="https://gohugo.io/" target="_blank">Hugo</a>,
можно использовать команду `hugo --minify` для генерации файлов и оптимизации размера ассетов.

<div id="secrets-do-deployment">
  ### Secrets развёртывания
</div>

Выберите **Добавить секрет развёртывания**, чтобы добавить переменные среды или Secrets, необходимые для безопасного выполнения команды сборки.

Например, если генератору сайта нужен ключ API для создания статического сайта, передайте его как `API_KEY=<имя вашего секрета>`.
