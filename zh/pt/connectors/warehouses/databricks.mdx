  Databricks 连接器仅适用于 **Enterprise** 套餐。
</Info>

  <img src="/assets/mirror/templates-dropdown-zoom-9e06ca94568a.png" alt="Replit 初始提示词输入框，已展开 Templates 下拉菜单，显示 Databricks App 组织模板" width="1680" height="300" data-path="images/connectors/databricks/templates-dropdown-zoom.png" />

Databricks 连接器可让 Replit Agent 查询您的 Databricks workspace。开发者可以使用自然语言创建仪表板、报表工具和数据应用，无需具备 SQL 知识。

Replit 支持两种 Databricks 连接方式。请根据应由哪种身份执行查询来选择其中一种。

<div id="escolher-um-tipo-de-conexo">
  ## 选择连接类型
</div>

|                | **用户到机器 (U2M)**                      | **服务主体 (M2M)**                 |
| -------------- | ------------------------------------ | ------------------------------ |
| Replit 中的连接器名称 | Databricks for Databricks Apps (U2M) | Databricks (Service Principal) |
| 查询所用身份         | 各个开发者                                | 共享服务主体                         |
| Databricks 权限  | 各开发者的 Unity Catalog 权限               | 服务主体的权限                        |
| 审计归属           | 执行查询的开发者                             | 服务主体                           |
| 开发者登录          | 每位开发者使用自己的 Databricks 账户登录           | 无需单独登录 Databricks              |
| 最适合            | 按用户划分权限和进行审计归属                       | 共享访问和非交互式工作流                   |

<div id="configurar-o-conector-u2m">
  ## 配置 U2M 连接器
</div>

配置 U2M 需要以下三种角色：

1. **Databricks 账户管理员**：创建 OAuth 应用连接，并提供 SQL Warehouse 的详细信息。
2. **Replit 组织管理员**：使用 OAuth 凭证配置连接器。
3. **开发者**：使用自己的 Databricks 账户登录并开始创建。

<div id="pr-requisitos-do-u2m">
  ### U2M 前提条件
</div>

开始前，请确认你具备：

* Databricks **账户管理员**权限。应用连接需在账户控制台中配置，而非在 workspace 管理设置中配置。
* Replit 组织管理员权限。
* 每位使用该连接器的开发者都拥有 Databricks 账户。
* 每位开发者都可访问 workspace，包括 SQL Warehouse 的 **Can use** 权限以及所需的 Unity Catalog 权限。

<div id="etapa-1-criar-uma-conexo-de-aplicativo-oauth">
  ### 第 1 步：创建 OAuth 应用连接
</div>

<Note>您必须是 Databricks 账户管理员才能完成此步骤。</Note>

Databricks 账户管理员需要将 Replit 注册为 OAuth 应用。该应用连接会提供用于配置 Replit 的 Client ID 和 Client Secret。

<Steps>
  <Step title="打开 Databricks 账户控制台">
    在 Databricks workspace 中，打开右上角的 workspace 选择器，然后选择 **Manage account**。

    <Frame>
      <img src="/assets/mirror/manage-account-6374ed6bf0f2.png" alt="已打开的 Databricks workspace 选择器，显示“管理账户”选项" width="2000" height="1144" data-path="images/connectors/databricks/u2m/manage-account.png" />
    </Frame>
  </Step>

  <Step title="打开应用连接">
    在账户控制台中，选择 **Settings**，然后打开 **App connections** 标签页。

    <Frame>
      <img src="/assets/mirror/app-connections-96228e7f0f2e.png" alt="Databricks 账户设置页面，已选中“应用连接”标签页，并显示“添加连接”按钮" width="2000" height="1144" data-path="images/connectors/databricks/u2m/app-connections.png" />
    </Frame>
  </Step>

  <Step title="配置 Replit 连接">
    选择 **Add connection**。输入用于标识 Replit 的应用名称，例如 `replit-u2m`。

    在 **Redirect URLs** 中，输入：

    ```text theme={null}
    https://replit.com/connectors/oauth/callback
    ```

    在 **Access scopes** 中，选择 **All APIs**。这使 Agent 能够使用创建和管理 Databricks Apps 所需的 Databricks SQL 和 Databricks API。

    选择 **Generate a client secret**。连接创建后，Databricks 无法再为此连接添加 secret。

    根据组织的安全策略设置令牌有效期。示例中，**Access token TTL** 设为 `1440` 分钟 (24 小时) ，**Refresh token TTL** 设为 `129600` 分钟 (90 天) ，这是 Databricks 显示的最大值。刷新令牌有效期较短时，开发者可能需要更频繁地登录。

    选择 **Add**。

    <Warning>
      **All APIs** 授予的访问权限比仅限 SQL 更广。请通过各开发者的 Databricks 权限控制连接器的实际访问权限。
    </Warning>

    <Frame>
      <img src="/assets/mirror/app-configuration-6799b5769326.png" alt="已配置的 Databricks“添加连接”表单，包含 Replit 应用名称、重定向 URL、All APIs 访问权限、client secret 生成和令牌有效期" width="2000" height="1144" data-path="images/connectors/databricks/u2m/app-configuration.png" />
    </Frame>
  </Step>

  <Step title="存储 OAuth 凭证">
    复制 **Client ID** 和 **Client Secret**，并将其存储在组织的密钥管理器中。

    <Warning>
      Databricks 仅显示一次 client secret。请记录到期日期，并在 secret 到期前轮换应用连接。
    </Warning>

    <Frame>
      <img src="/assets/mirror/oauth-credentials-15b2e6c67309.png" alt="Databricks“连接已创建”对话框，其中的 client ID 和 client secret 已隐藏，并显示一次性密钥警告和到期日期" width="2000" height="1144" data-path="images/connectors/databricks/u2m/oauth-credentials.png" />
    </Frame>
  </Step>
</Steps>

<Note>
  新建或更新的 OAuth 应用连接最多可能需要 30 分钟
  才能生效。
</Note>

<div id="etapa-2-compartilhar-os-detalhes-do-sql-warehouse">
  ### 第 2 步：共享 SQL Warehouse 的详细信息
</div>

每位开发者在授权 U2M 连接器时都需要输入 SQL Warehouse 的详细信息。请将这些信息发布在开发者可访问的位置，例如内部入门页面。

<Steps>
  <Step title="打开 SQL Warehouses">
    在 Databricks workspace 中，选择 **SQL Warehouses**，然后打开开发者应使用的 warehouse。

    <Frame>
      <img src="/assets/mirror/sql-warehouses-cc178d18a33b.png" alt="显示可用 warehouse 的 Databricks SQL Warehouses 页面" width="3438" height="1984" data-path="images/connectors/databricks/sql-warehouses.png" />
    </Frame>
  </Step>

  <Step title="复制连接详情">
    选择 **Connection details**，然后复制 **Server hostname** 和 **HTTP path**。

    <Frame>
      <img src="/assets/mirror/connection-details-938b970b98e6.png" alt="Databricks SQL Warehouse 连接详情页面，显示服务器主机名和 HTTP 路径" width="3438" height="1984" data-path="images/connectors/databricks/connection-details.png" />
    </Frame>
  </Step>
</Steps>

<div id="etapa-3-ativar-o-u2m-no-replit">
  ### 第 3 步：在 Replit 中启用 U2M
</div>

<Note>您必须是 Replit 组织管理员，才能配置连接器。</Note>

<Steps>
  <Step title="打开并启用 U2M 连接器">
    在 Replit 账户主页上，打开 **设置**，然后选择 **集成**。搜索 `Databricks U2M`，找到 **Databricks for Databricks Apps (U2M)**，然后选择 **启用**。

    输入 Databricks 应用连接的 **Client ID** 和 **Client Secret**。

    确认 Replit 中显示的重定向 URL 与 Databricks 中配置的 URL 一致：

    ```text theme={null}
    https://replit.com/connectors/oauth/callback
    ```

    在 **连接器作用域** 中，启用 `all-apis` 和 `offline_access`。`offline_access` 作用域会向 Replit 提供用于长期会话的刷新令牌。

    选择 **配置**。

    <Frame>
      <img src="/assets/mirror/enable-connector-39c1eeebd230.png" alt="Replit 集成设置已筛选为 Databricks U2M，启用面板显示重定向 URL、OAuth 凭证字段和连接器作用域" width="2000" height="1144" data-path="images/connectors/databricks/u2m/enable-connector.png" />
    </Frame>
  </Step>

  <Step title="确认连接器已启用">
    确认 **Databricks for Databricks Apps (U2M)** 显示在 **您的集成** 中。
  </Step>
</Steps>

<div id="etapa-4-fazer-login-como-desenvolvedor">
  ### 第 4 步：以开发者身份登录
</div>

每位开发者在使用连接器前，均需使用自己的 Databricks 账户登录。Replit 可在刷新令牌过期前续订会话。

<Steps>
  <Step title="登录连接器">
    在 **集成** 页面中，找到 **Databricks for Databricks Apps (U2M)**，然后选择 **Sign in**。查看连接详情后，选择 **Continue to Databricks for Databricks Apps**。

    <Frame>
      <img src="/assets/mirror/connect-modal-8ae2c2569658.png" alt="“连接 Databricks for Databricks Apps”模态框，说明重定向、隐私和权限控制" width="2000" height="1144" data-path="images/connectors/databricks/u2m/connect-modal.png" />
    </Frame>
  </Step>

  <Step title="输入 SQL Warehouse 详细信息">
    输入 Databricks 管理员提供的 SQL Warehouse **HTTP path**，然后选择 **Next**。

    <Frame>
      <img src="/assets/mirror/http-path-9e8a8a14b6ab.png" alt="“连接 Databricks for Databricks Apps”对话框，在第 1 步（共 2 步）要求输入 SQL Warehouse 的 HTTP 路径" width="2000" height="1144" data-path="images/connectors/databricks/u2m/http-path.png" />
    </Frame>

    接下来，Replit 会要求输入 SQL Warehouse 的 **Server hostname**。输入后，继续前往 Databricks。出现提示时登录，查看请求的访问权限并批准该请求。

    Agent 通过此连接执行的每个查询都会使用你的 Databricks 权限，并在 Databricks 审计日志中归属于你。

    批准后，Databricks 会将你带回 Replit，连接器即可使用。
  </Step>
</Steps>

<div id="configurar-o-conector-de-service-principal">
  ## 配置服务主体连接器
</div>

配置服务主体涉及三个角色：

1. **Databricks 管理员**：创建服务主体并在 Databricks 中授予权限。
2. **Replit 组织管理员**：在 Replit 中配置连接器和访问权限。
3. **开发者**：开始使用共享的 Databricks 身份进行开发。

<div id="pr-requisitos-do-service-principal">
  ### 服务主体的前提条件
</div>

开始前，请确认您具备：

* Databricks 账户或 workspace 的管理员权限。
* Replit 组织的管理员权限。

<div id="etapa-1-criar-um-service-principal-no-databricks">
  ### 第 1 步：在 Databricks 中创建服务主体
</div>

<Note>
  您必须是 Databricks 帐户管理员或 Workspace 管理员才能完成此步骤。
</Note>

Databricks 管理员会创建一种称为服务主体的机器对机器身份，Replit 使用该身份连接到 Databricks。

<Steps>
  <Step title="打开设置">
    在 Databricks 中，选择右上角的头像，然后选择**设置**。

    <Frame>
      <img src="/assets/mirror/settings-menu-8f2dcd4dbee3.png" alt="已选择“设置”的 Databricks Workspace 菜单" width="3438" height="1984" data-path="images/connectors/databricks/settings-menu.png" />
    </Frame>
  </Step>

  <Step title="选择身份与访问">
    在“设置”侧边栏中，选择**身份与访问**。

    <Frame>
      <img src="/assets/mirror/settings-page-2a8bcd7c22a4.png" alt="Databricks 设置页面，侧边栏中显示“身份与访问”" width="3438" height="1984" data-path="images/connectors/databricks/settings-page.png" />
    </Frame>
  </Step>

  <Step title="管理服务主体">
    在**管理和权限**下，找到**服务主体**并选择**管理**。

    <Frame>
      <img src="/assets/mirror/identity-and-access-0e79404ed30f.png" alt="“身份与访问”设置页面，显示“服务主体”的“管理”按钮" width="3438" height="1984" data-path="images/connectors/databricks/identity-and-access.png" />
    </Frame>
  </Step>

  <Step title="添加新的服务主体">
    选择**添加服务主体**，然后选择**新增**。

    <Frame>
      <img src="/assets/mirror/add-service-principal-ac5b52f21f4c.png" alt="“添加服务主体”对话框，其中显示“新增”按钮" width="3438" height="1984" data-path="images/connectors/databricks/add-service-principal.png" />
    </Frame>
  </Step>

  <Step title="为服务主体命名">
    为服务主体输入一个易于识别的名称，然后选择**添加**。

    <Frame>
      <img src="/assets/mirror/add-service-principal-name-897df9e5f7ac.png" alt="“添加服务主体”对话框，其中已输入服务主体名称" width="3438" height="1984" data-path="images/connectors/databricks/add-service-principal-name.png" />
    </Frame>
  </Step>

  <Step title="确认服务主体详细信息">
    Databricks 创建服务主体后，确认其处于活跃状态。配置 Replit 连接器时若需要服务主体的详细信息，请保持此页面打开。

    <Frame>
      <img src="/assets/mirror/service-principal-details-15a381d388bc.png" alt="Databricks 服务主体详细信息页面" width="3438" height="1984" data-path="images/connectors/databricks/service-principal-details.png" />
    </Frame>
  </Step>

  <Step title="授予访问权限">
    打开**权限**选项卡，选择**授予访问权限**，选择服务主体，将权限设置为**管理**，然后选择**保存**。

    <Frame>
      <img src="/assets/mirror/grant-access-edbaa2541a7d.png" alt="Databricks 服务主体的“授予访问权限”对话框，已选择“管理”权限" width="3438" height="1984" data-path="images/connectors/databricks/grant-access.png" />
    </Frame>
  </Step>
</Steps>

<div id="etapa-2-obter-os-detalhes-de-conexo-do-sql-warehouse">
  ### 第 2 步：获取 SQL Warehouse 的连接详情
</div>

Replit 连接器需要 Databricks SQL Warehouse 的连接详情，才能将查询路由到正确的计算资源。

<Steps>
  <Step title="打开 SQL Warehouses">
    在 Databricks 侧边栏中，选择 **SQL Warehouses**。

    <Frame>
      <img src="/assets/mirror/sql-warehouses-cc178d18a33b.png" alt="Databricks SQL Warehouses 页面，显示可用的 warehouse" width="3438" height="1984" data-path="images/connectors/databricks/sql-warehouses.png" />
    </Frame>
  </Step>

  <Step title="选择或创建 warehouse">
    选择要供 Replit Agent 使用的 SQL Warehouse。如果尚未创建，请选择 **创建 SQL warehouse**，然后新建一个 warehouse。
  </Step>

  <Step title="复制连接详情">
    打开该 warehouse，然后选择 **连接详情**。找到 **服务器主机名** 和 **HTTP 路径** 的值。创建 Replit 中的 Databricks 连接器时，需要使用这些值。

    <Frame>
      <img src="/assets/mirror/connection-details-938b970b98e6.png" alt="Databricks SQL Warehouse 的连接详情页面，包含服务器主机名和 HTTP 路径" width="3438" height="1984" data-path="images/connectors/databricks/connection-details.png" />
    </Frame>
  </Step>
</Steps>

<div id="etapa-3-criar-o-conector-databricks-no-replit">
  ### 第 3 步：在 Replit 中创建 Databricks 连接器
</div>

<Note>
  您必须是 Replit 组织管理员才能配置连接器。
</Note>

Replit 管理员将 Databricks 连接详情添加到 Replit，以便开发者使用该连接器。

<Steps>
  <Step title="前往集成">
    在 Replit 账户主页中，打开**集成**页面。在**连接器**中找到 **Databricks (Service Principal)**，然后选择**登录**。

    <Frame>
      <img src="/assets/mirror/integrations-databricks-signin-75d3367013da.png" alt="已筛选 Databricks 的 Replit 集成页面，显示 Databricks (Service Principal) 连接器及登录按钮" width="3436" height="1978" data-path="images/connectors/databricks/integrations-databricks-signin.png" />
    </Frame>
  </Step>

  <Step title="确认连接">
    Replit 会在重定向至 Databricks 进行身份验证前显示确认对话框。查看详情后，选择**继续前往 Databricks**。

    <Frame>
      <img src="/assets/mirror/connect-databricks-intro-e842722d93ea.png" alt="连接 Databricks 对话框，说明 OAuth 重定向、数据使用和权限" width="3436" height="1978" data-path="images/connectors/databricks/connect-databricks-intro.png" />
    </Frame>
  </Step>

  <Step title="输入 SQL Warehouse HTTP 路径">
    粘贴 Databricks SQL Warehouse 连接详情中的**HTTP 路径** (例如 `/sql/1.0/warehouses/abcdef1234567890`) ，然后选择**下一步**。

    <Frame>
      <img src="/assets/mirror/connector-http-path-5c8ae35516f8.png" alt="连接 Databricks 对话框，第 1 步（共 2 步），要求输入 SQL Warehouse HTTP 路径" width="3436" height="1978" data-path="images/connectors/databricks/connector-http-path.png" />
    </Frame>
  </Step>

  <Step title="输入 SQL Warehouse 服务器主机名">
    粘贴同一连接详情中的**服务器主机名** (例如 `abc-12345678-wxyz.cloud.databricks.com`) ，然后选择**继续前往 Databricks**以完成身份验证。

    <Frame>
      <img src="/assets/mirror/connector-server-hostname-b97fb74713f1.png" alt="连接 Databricks 对话框，第 2 步（共 2 步），要求输入 SQL Warehouse 服务器主机名" width="3436" height="1978" data-path="images/connectors/databricks/connector-server-hostname.png" />
    </Frame>
  </Step>

  <Step title="配置访问权限">
    使用基于角色的访问控制，选择组织中哪些成员或群组可以使用此连接器。
  </Step>

  <Step title="确认连接器已启用">
    返回**集成**页面，确认 **Databricks (Service Principal)** 显示在**连接器**中，且连接状态为**启用**。

    <Frame>
      <img src="/assets/mirror/integrations-page-d3e1d6b88376.png" alt="Replit 集成页面，显示连接状态为启用的 Databricks (Service Principal) 连接器" width="1680" height="1199" data-path="images/connectors/databricks/integrations-page.png" />
    </Frame>
  </Step>
</Steps>

<div id="criar-com-o-agent">
  ## 使用 Agent 创建
</div>

通过任一方式完成连接后，开发者即可使用 Agent 创建使用 Databricks 数据的应用。

<Steps>
  <Step title="选择用于部署的 Databricks App 模板">
    如果要将完成的应用部署到您的 Databricks 环境，请选择 **Databricks App** 模板。若只是使用已配置的连接器访问 Databricks 数据和资源，则无需使用该模板。

    在 Replit 首页，打开模板选择器并选择 **Databricks App**。

    <Frame>
      <img src="/assets/mirror/databricks-template-cdfbbba1a2ab.png" alt="Replit 首页，提示词输入框上方已选中 Databricks App 模板" width="1200" height="400" data-path="images/connectors/databricks/u2m/databricks-template.png" />
    </Frame>
  </Step>

  <Step title="描述您的应用">
    在自动填充的说明后添加提示词。如需灵感，请浏览 [Databricks Dev Hub 模板](https://www.databricks.com/devhub/templates)。
  </Step>

  <Step title="审核并迭代">
    审核 Agent 生成的 SQL、查询的表以及应用结构。使用自然语言提出修改要求。
  </Step>
</Steps>

<div id="soluo-de-problemas">
  ## 故障排除
</div>

<AccordionGroup>
  <Accordion title="查询返回空结果">
    检查执行查询的身份在 Databricks 中拥有的权限。使用 U2M 时，该身份为个人开发者。使用
    服务主体连接器时，该身份为共享服务主体。该身份可能可以访问元数据，但没有读取
    数据的权限。授予所需的目录、架构或表权限，然后重试。
  </Accordion>

  <Accordion title="连接器无法访问 SQL Warehouse">
    检查 **服务器主机名** 和 **HTTP 路径** 的值是否与 Databricks 中 SQL Warehouse 的
    连接详情一致。对于 U2M，请检查受影响开发者输入的值。还要确认 warehouse 正在
    运行，并且执行查询的身份有权使用它。
  </Accordion>

  <Accordion title="身份验证失败">
    对于 U2M，请确认 Databricks 应用连接的 **Redirect URLs** 中包含
    `https://replit.com/connectors/oauth/callback`，且末尾没有斜杠。如果所有开发者都无法
    通过身份验证，请检查共享的 Client ID 和 Client Secret，确认 secret 未过期，
    并确保 Replit 中的作用域与 Databricks 应用连接一致。

    对于服务主体连接器，请检查在 Replit 中输入的服务主体信息是否与 Databricks 中
    创建的服务主体一致。如果凭证已更改，请在 Replit 中更新连接器。
  </Accordion>

  <Accordion title="连接器要求我再次登录">
    使用 U2M 时，如果刷新令牌过期或被撤销，可能会出现这种情况。请重新完成 Databricks
    授权流程。如果开发者需要重新连接的频率高于安全策略规定的频率，请检查应用连接的
    token 有效期。
  </Accordion>
</AccordionGroup>
