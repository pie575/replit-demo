<div id="section-3">
  ### 文件系统搜索优化
</div>

Agent 现在可在整个代码库中提供更智能、更直观的文件搜索。借助先进的长上下文 AI，Agent 能够理解项目结构与内容，从而提供更丰富的上下文和更贴切的开放式回答，让你更轻松地找到所需内容。

<div id="object-storage-agent">
  ### Object Storage Agent 集成
</div>

借助 [Agent](/zh/core-concepts/agent) 全新的 [Object Storage](/zh/ko/features/data-and-storage/object-storage) 功能，轻松构建文件上传功能！AI 助手现在可以设置 Object Storage、检查配置，并生成具备身份验证和访问控制等高级特性的完整后端与前端代码。

进一步了解 [Object Storage](/zh/ko/features/data-and-storage/object-storage)，并浏览所有可用的 [Agent 集成](/zh/replitai/integrations#data-storage--management)。

<div id="section-4">
  ### 可视化编辑器焦点优化
</div>

使用[可视化编辑器](/zh/learn/projects-and-artifacts/visual-editor)时，让思路不被打断！选中要编辑的元素后，焦点会自动回到聊天输入框，你可以立即输入下一条提示词，全程顺畅无中断。

<div id="section-5">
  ### 回滚建议与日期切换
</div>

借助智能回滚建议和灵活的日期显示方式，浏览项目历史记录更轻松！系统会智能推荐何时回滚代码，你还可以在相对时间戳与绝对时间戳之间切换，快速找到最合适的检查点。

<div id="ios">
  ### iOS 实时活动
</div>

即使人不在电脑前，也能随时掌握[工作区](/zh/ko/learn/projects-and-artifacts/project-editor)动态！借助 iOS 实时活动，你可以监控正在运行的项目，并从锁定屏幕或通知中心轻点一下即可返回工作区。

<div id="replit">
  ### 将 Replit 应用转移到组织
</div>

轻松将个人项目转移给团队！使用全新的“转移到组织”操作，即可将个人 [Replit 应用](/zh/ko/category/replit-apps)无缝转移到你所在的组织，在现有项目上轻松展开协作。

<div id="mx">
  ### 域名 MX 记录支持
</div>

轻松接入你的电子邮件服务商！现在，你可以为[通过 Replit 购买的域名](/zh/ko/features/publishing/custom-domains)创建 MX 记录，连接邮件服务商并管理项目的自定义电子邮件服务。
