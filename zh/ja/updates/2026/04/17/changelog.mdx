<div id="agent-2">
  ### 全新的 Agent 模式下拉菜单
</div>

聊天输入框中的 Agent 模式选择器现已改为简洁的分段控件。你可以直接在工具栏中切换 Lite、Economy 和 Power，需要时还能在高级设置中使用 Turbo。

新增功能：

* **工具栏分段控件。** Lite、Economy 和 Power 并排显示，当前处于哪种模式、如何切换一目了然。
* **键盘快捷键。** 按 **⌘+Shift+I** (Windows 上为 Ctrl+Shift+I) 即可无需鼠标切换模式。
* **Turbo 以橙色高亮显示。** Turbo 是速度最快的模式，但费用也更高，因此在界面中格外醒目，让成本权衡一目了然。
* **高级设置默认折叠。** 测试、代码审查和 Turbo 的相关控件都收纳在 Advanced settings 中，主视图更加清爽。
* **Max 模式已下线。** 需要最高能力的构建请使用 Power；如需最快响应，请在高级设置中开启 Turbo。

<div id="agent-3">
  ### Agent 推荐后续任务
</div>

<Frame>
  <video autoPlay muted loop playsInline src="/assets/mirror/replit-suggested-tasks-b27620d93fd2.mp4" />
</Frame>

Agent 完成工作后，会根据项目的完整上下文，推荐接下来可以构建的**后续任务**。每个已完成任务下方都会显示三类建议：

* **可构建的新功能** — 可与刚发布的内容自然结合的功能
* **性能改进** — Agent 在执行任务时发现的优化机会
* **用户体验提升** — 用于进一步打磨功能的细节优化

查看每项建议，对需要的建议选择**批准**后，Agent 即可在后台执行这些任务的同时继续构建。你可以通过 Done 列中的**隐藏建议任务**隐藏不需要的建议，并随时重新显示。

详细了解[后续任务推荐](/zh/ja/features/agent/follow-up-tasks)。

<div id="section-3">
  ### 项目页面改进
</div>

项目页面新增了三项使用体验改进：

* **所有卡片均可预览 artifact。** 每个项目卡片现在都会显示其中各个 artifact 的小图标。将鼠标悬停在图标上，无需打开项目即可预览该 artifact 的截图。
* **默认按最近打开时间排序。** 页面现在会将*你*最近处理过的项目排在最上方，即使在繁忙的团队工作区中，也能让当前的工作一目了然。
* **个人置顶。** 你可以将经常访问的项目置顶。置顶仅对你自己可见，不会影响工作区中其他成员看到的内容。

<div id="scim">
  ### SCIM 组织的自定义群组
</div>

启用 SCIM 预配的组织现在可以在 Replit 中创建自定义群组，与 IdP 同步群组并行使用。对于按项目控制访问权限、一次性授予权限，或身份提供方中未体现的组织结构，请使用自定义群组。

SCIM 同步群组仍由身份提供方管理，而自定义群组则由组织管理员直接在 Replit 中管理。

详细了解 [SCIM](/zh/ja/teams/identity-and-access-management/scim#creating-custom-groups-alongside-scim)。
