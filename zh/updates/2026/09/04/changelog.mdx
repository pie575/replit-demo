<div id="recover-production-data-with-scheduled-backups">
  ### 使用定时备份恢复生产数据
</div>

定时备份每天会为你的生产数据库创建一个完整还原点。要启用该功能，请在生产数据库设置中的 **Keep backups for** 下选择保留期限。可选的保留期限上限取决于你所使用的方案。

<div id="understand-app-usage-with-project-analytics">
  ### 通过 Project Analytics 了解 app 使用情况
</div>

Project Analytics 可帮助你了解用户如何发现和使用已发布的 web app。在 **Growth** 窗格中查看访客趋势、热门页面、流量来源、国家/地区、浏览器和设备等概览数据。要开始收集数据，请开启 **Enable analytics**，然后重新发布 app。使用付费套餐时，你可以让 Agent 添加自定义事件，并分析注册、购买等操作的漏斗。
