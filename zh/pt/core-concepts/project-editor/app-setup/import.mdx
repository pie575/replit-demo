导入功能可让你将现有代码或设计引入 Replit Apps，并继续使用 Agent 进行开发。

<div id="fontes-suportadas">
  ## 支持的来源
</div>

| 来源           | 你需要提供的内容                             | 适用场景                    |
| ------------ | ------------------------------------ | ----------------------- |
| GitHub       | 仓库 URL 或仓库选择器                        | 导入公开和私有仓库               |
| Bitbucket    | 仓库 URL 或仓库选择器                        | 导入托管在 Bitbucket 上的仓库    |
| Vercel       | 与你的 Vercel 项目关联的 GitHub 仓库           | 从 Vercel 迁移应用           |
| Figma        | Frame URL                            | 将设计稿转换为 React 应用        |
| Bolt         | 从 Bolt 导出的 GitHub 仓库                 | 迁移 Bolt 项目              |
| Lovable      | 从 Lovable 导出的 GitHub 仓库              | 迁移 Lovable 项目           |
| Base44       | 从 Base44 导出的 GitHub 仓库               | 迁移 Base44 项目            |
| ZIP          | 上传 `.zip` 文件                         | 导入本地项目文件                |
| 电子表格         | `.xlsx`、`.csv` 文件或 Google Sheets URL | 基于表格数据创建应用              |
| 此前的 Agent 导出 | 从此前的 Agent App 导出的 GitHub 仓库         | 重新导入此前的 Agent App       |
| 空白           | 无                                    | 希望创建不含 Agent 的空白项目的高级用户 |

<Note>Replit 会在开始导入前验证兼容性。</Note>

<div id="fluxo-de-importao-padro">
  ## 标准导入流程
</div>

1. 打开 [replit.com/import](https://replit.com/import)。
2. 选择导入来源。
3. 连接所需账户。
4. 提供仓库 URL、frame URL 或 `.zip` 文件。
5. 添加所需的密钥或环境变量。
6. 选择 **导入**，然后检查生成的应用。

<div id="notas-sobre-as-fontes">
  ## 来源说明
</div>

<div id="github">
  ### GitHub
</div>

* 公开仓库可使用快速导入：`https://replit.com/github.com/<owner>/<repo>`。
* 引导式导入同时支持公开和私有仓库。
* 如果你的仓库是导出的 Agent App，Replit 会在导入时保留 Agent 特有的结构。

<div id="bitbucket">
  ### Bitbucket
</div>

* 粘贴 Bitbucket 仓库 URL，或连接您的 Bitbucket 账户以搜索仓库。
* 与托管在 GitHub 上的项目相比，从 Bitbucket 导入时，Agent 支持可能有所限制。

<div id="figma">
  ### Figma
</div>

* 导入单个 Figma frame 的 URL。
* Replit 生成 React 代码，并由 Agent 协助优化。
* 为获得最佳效果，请使用 frame、自动布局和清晰的图层命名。

<div id="vercel">
  ### Vercel
</div>

* 选择与你的 Vercel 项目关联的 GitHub 仓库。
* Replit 会导入项目代码和默认配置。
* 在导入过程中填写环境变量的值。

<div id="bolt">
  ### Bolt
</div>

* 导入前，请先将你的 Bolt 项目导出到 GitHub。
* Replit 会导入代码、界面样式、素材、后端逻辑 (如有) 以及数据库架构 (如有) 。
* Supabase 数据和密钥的值不会被导入。
* 导入完成后，可让 Agent 添加密钥并重建数据库数据。

<div id="lovable">
  ### Lovable
</div>

* 导入前，请先将你的 Lovable 项目导出到 GitHub。
* Replit 会导入代码、界面样式、素材、后端逻辑 (如有) 以及数据库架构 (如有) 。
* Supabase 数据和密钥值不会被导入。
* 导入完成后，可让 Agent 添加密钥并重建数据库数据。

<div id="base44">
  ### Base44
</div>

* 导入前，请先将你的 Base44 项目导出到 GitHub。
* Replit 会导入代码、设计与样式、素材以及 API 逻辑。
* Base44 的后端 (实体、agents、SDK) 、身份验证和数据不会被导入。
* 导入完成后，可以让 Agent 帮你迁移仍需使用的 Base44 专有功能。

<div id="zip">
  ### ZIP
</div>

* 上传项目根目录结构清晰的 `.zip` 文件。
* Replit 会导入文件、依赖项以及常见的运行配置。
* 现有的密钥值、域名和数据库数据不会被导入。

<div id="planilha">
  ### 电子表格
</div>

* 上传 Excel 文件 (`.xlsx`) 或 CSV 文件，或粘贴 Google Sheets 的公开 URL。
* Agent 会读取表格结构，并创建一个 full-stack 应用，其数据库中已填充你的数据。
* 应用自带界面，可用于查看、搜索和管理记录。

<div id="exportao-anterior-do-agent">
  ### 之前导出的 Agent
</div>

* 从 GitHub 仓库重新导入之前导出的 Agent App。
* Replit 会保留 Agent 特有的结构 (代码、数据库架构和后端功能) 。
* 不会导入数据库中的数据和密钥值。

<div id="vazio">
  ### 空白
</div>

* 从完全空白的项目开始——不使用 Agent、不选择框架，也不生成脚手架。
* 适合希望完全掌控项目配置的高级用户。

<div id="limitaes">
  ## 限制
</div>

* 数据库中的现有数据不会被迁移。
* 某些复杂或专有的依赖项可能需要手动配置。
* 大型项目的处理时间可能更长。

<div id="boas-prticas">
  ## 最佳实践
</div>

* 导入前请移除敏感凭证。
* 保持源项目的结构清晰有序。
* 导入后请检查依赖项和运行命令。
* 发布前请测试主要流程。

<div id="soluo-de-problemas">
  ## 故障排查
</div>

如果导入失败，请先检查以下几个方面：

* **兼容性错误**：检查是否包含必需的项目文件，以及框架是否受支持。
* **访问错误**：确认仓库或来源的访问权限。
* **处理错误**：简化项目结构或缩减项目体积后重试。

如果问题仍未解决，请访问 [Replit Community Hub](https://replit.com/community) 或[联系支持团队](https://replit.com/support)。

<div id="faturamento">
  ## 账单
</div>

如果导入需要 Agent 完成迁移工作，可能会消耗积分。积分用量取决于项目的复杂程度。
