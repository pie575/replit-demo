[Claude Agent SDK](https://docs.anthropic.com/en/docs/agents-and-tools/claude-code/sdk) 是将 Claude Code 封装为库的工具。它让您能够以编程方式创建驱动 Claude Code 的同类 Agent，并以代码形式运行它们。将重复性任务转化为自动化工作流，并发布到 Replit。

<div id="como-o-claude-agent-sdk-funciona">
  ## Claude Agent SDK 的工作原理
</div>

Agent 是一个循环：你发送提示词，Agent 选择要执行的工具、观察结果并重复这一过程，直到任务完成。

你提供提示词，SDK 负责处理循环。

但 SDK 的功能不止于此。它支持你创建**多 Agent 架构**：由一个编排 Agent 将任务委派给专门的子 Agent，每个子 Agent 都拥有自己的工具和上下文窗口。

<Tip>
  多 Agent 架构让每个 Agent 都能专注于自己的任务。子 Agent 只会获得所需的工具和上下文，从而避免上下文膨胀并提升性能。
</Tip>

<div id="primitivas-principais">
  ### 核心原语
</div>

| 原语          | 功能                                           |
| ----------- | -------------------------------------------- |
| **查询循环**    | 基础流程：提示词、选择工具、执行、观察、重复                       |
| **Agent**     | 具备各自工具和指令的专用配置                               |
| **工具**      | Agent 可执行的操作 — 运行命令、调用 API、编辑文件                 |
| **MCP 服务器** | 提供工具集合的外部进程 (占用较多上下文，预先加载)                   |
| **Skills**  | 使用 Markdown 编写的指令文件，用于教 Agent 完成任务 (节省上下文，按需加载)  |
| **权限**      | 精细控制每个 Agent 可访问的资源和可执行的操作                       |

<div id="skills-vs-servidores-mcp">
  ### Skills 与 MCP 服务器
</div>

这是扩展 Agent 的两种主要方式：

**Skills** 是包含 Agent 需遵循指令的 Markdown 文件。在实际调用前，只会加载简短描述，从而让上下文窗口保持精简。适合用于：

* 工作流程和规范 (“如何部署”“代码审查清单”)
* 参考资料 (API 模式、风格指南)
* 可通过名称调用的可复用提示词

**MCP 服务器** 是提供工具的进程。所有工具描述都会预先加载，因此会占用较多上下文。适合用于：

* 连接外部服务 (Notion、Linear、数据库)
* 需要访问 API 的操作 (创建任务、查询数据)
* 能够*执行*操作而非仅提供指令的工具

<Info>
  skills 定义 Agent 应当*如何*工作。MCP 服务器定义 Agent 可以访问*什么*。两者都适用于编程 Agent (如 Replit Agent) ，以及你使用 SDK 创建的 Agent。
</Info>

<div id="quando-usar-o-sdk-vs-a-api">
  ### 何时使用 SDK 或 API
</div>

| 使用场景      | 选择               |
| --------- | ---------------- |
| 自动执行多步骤任务 | Claude Agent SDK |
| 多智能体工作流   | Claude Agent SDK |
| 简单的聊天应用   | Anthropic API    |
| 单回合任务     | Anthropic API    |

<div id="crie-um-agente-organizador-do-todoist">
  ## 创建 Todoist 整理 Agent
</div>

本指南使用一个 Replit 模板，其中已按正确结构配置好 Claude Agent SDK 项目，包括 Agent 目录、工具、MCP 服务器、skills 和权限。

<div id="etapa-1-faa-remix-do-template">
  ### 步骤 1：Remix 模板
</div>

<Steps>
  <Step title="打开模板">
    在 Replit 中打开 [Claude Agent SDK 模板](https://replit.com/@matt/Claude-Agent-SDK)，然后选择 **Remix** 创建自己的副本。
  </Step>

  <Step title="为项目命名">
    为项目取一个描述性名称 (例如“我的 Todoist Agent”) ，然后选择 **使用模板**。
  </Step>

  <Step title="查看项目结构">
    环境加载完成后，打开文件侧边栏。如有需要，请启用 **显示隐藏文件** 以查看完整的项目结构：

    * `.agents/skills/` — 用于指导 Replit Agent 使用 Claude Agent SDK 创建应用的 skills
    * `src/agents/` — Agent 定义
    * `src/mcpServers/` — MCP 服务器配置
    * `src/permissions/` — 权限定义
    * `src/skills/` — 供 Agent 使用的 skills (Markdown 文件)
    * `src/tools/` — 自定义工具定义
  </Step>
</Steps>

<Tip>
  该模板包含一项 skill，可指导 Replit Agent 使用 Claude Agent SDK 创建应用。这意味着，当您向 Agent 提供提示词时，它已经了解该框架。
</Tip>

<div id="etapa-2-conecte-o-todoist-via-integraes-do-replit">
  ### 第 2 步：通过 Replit 集成连接 Todoist
</div>

在为 Agent 创建提示词之前，请先连接 Agent 需要与之交互的服务。

1. 在您的 Replit 账户中访问 **replit.com/integrations**。
2. 找到 **Todoist** 并连接您的账户。
3. 授权 Replit 访问您的 Todoist 数据。

<Info>
  Replit 集成会为您处理 OAuth 和身份验证。您的 Agent 无需直接管理令牌，即可访问 Todoist API。这比单独设置需要自行配置 OAuth 流程的 MCP 服务器更简单。
</Info>

<div id="etapa-3-crie-prompts-para-o-agent-construir-seu-agente">
  ### 第 3 步：编写提示词，让 Agent 构建您的 Agent
</div>

将 Replit Agent 切换到**计划模式**，以获得更好的效果——它会在构建前审查计划，让您有机会确认实现方案。

<AiPrompt>
  使用 Claude Agent SDK 的 skill。创建一个 Agent，用于分析我的 Todoist 收件箱，并通过添加相关标签或补充信息来整理任务。

  您需要创建工具，使该 Agent 能够通过 SDK 与 Todoist 交互。

  最终应构建出一个 Agent：触发后，它会加载所有可用的任务和项目，补充相关信息并妥善整理。

  请确保所有身份验证均使用 Replit 与 Todoist 的集成。请使用 Todoist REST API 创建自定义工具，而不是 Todoist MCP 服务器，因为 MCP 服务器需要 OAuth，而 OAuth 在此场景下无法使用。

  该 Agent 还应获取项目列表，并为我收件箱中的每项任务分配相关项目，将收件箱彻底清空。
</AiPrompt>

<Note>
  此提示词的最后两段是在调试后添加的。明确说明*如何*进行身份验证 (使用 Replit 集成，而不是 MCP OAuth) ，以及*最终状态*应是什么样 (收件箱完全清空) ，可以节省迭代时间。
</Note>

<div id="etapa-4-revise-o-plano-e-construa">
  ### 第 4 步：审查计划并构建
</div>

当 Agent 展示计划时，请确认其中包含：

1. 用于 Todoist API 的**自定义工具** (而非 Todoist MCP 服务器)
2. 一个可获取任务、标签和项目的**整理 Agent**
3. 具有适当作用域、可满足 Agent 所需工具需求的**权限**
4. 一个可触发工作流的**入口点**

确认无误后，批准计划，将 Agent 设置为**高自主性**，然后让它开始构建。

<div id="etapa-5-adicione-sua-chave-de-api-da-anthropic">
  ### 第 5 步：添加 Anthropic API 密钥
</div>

Claude Agent SDK 需要 Anthropic API 密钥才能调用 Claude。

1. 在项目编辑器中打开 **Secrets** 面板。
2. 添加一个名为 `ANTHROPIC_API_KEY` 的 Secret，并将其值设为您的 API 密钥。

<Info>
  如果您已将 Anthropic API 密钥保存在[设置中的 Replit 保管库](https://replit.com/settings)，该密钥会自动在您的所有项目中可用。
</Info>

<div id="etapa-6-teste-e-depure">
  ### 第 6 步：测试和调试
</div>

运行 Agent，检查它是否能正确处理你的 Todoist 收件箱。常见问题包括：

* **“收件箱为空”，但实际并非如此** — 用于检测收件箱任务的 API 响应格式可能需要调整。确认 Agent 是按收件箱项目筛选任务，而不是按其他属性筛选。
* **任务已添加标签，但未移至项目** — 在提示词中明确说明，Agent 应查找可用项目，并将每项任务分配到其中一个项目。
* **身份验证错误** — 确认 Todoist 集成已在 Replit 的集成中连接，并且 Agent 代码使用的是该集成，而非单独的 OAuth 流程。

<Tip>
  调试是使用 AI 构建过程的一部分。当某些功能无法正常运行时，请查看输出，找出 Agent 的执行结果与预期有何不同，并提供更具体的提示词。每次修正都会帮助你了解下次应提前说明哪些内容。
</Tip>

<div id="publique-seu-agente">
  ## 发布您的 Agent
</div>

Agent 正常运行后，将其发布以自动执行。

<Steps>
  <Step title="打开“发布”选项卡">
    在项目编辑器中，选择 **发布** 选项卡。
  </Step>

  <Step title="选择定时部署">
    选择 **定时部署**，按时间自动执行任务。输入所需的计划 (例如：“每天 PST 下午 5 点”) 。
  </Step>

  <Step title="检查配置">
    确认运行命令指向主入口文件，并且 secret `ANTHROPIC_API_KEY` 已包含在部署 Secrets 中。
  </Step>

  <Step title="发布">
    选择 **发布**。您的 Agent 现已启用，并会按计划运行。
  </Step>
</Steps>

对于需要响应事件 (Webhook、传入消息) 的 Agent，请改用[预留 VM 部署](/zh/pt/features/publishing/reserved-vm-deployments)。

<div id="estenda-seu-agente">
  ## 扩展你的 Agent
</div>

当基础功能运行正常后，你可以在 Replit 中构建更高级的 Agent：

* **添加持久记忆** — 使用 [Replit 数据库](/zh/pt/features/data-and-storage/sql-database) 在多次运行之间保存状态
* **存储文件** — 使用[应用存储](/zh/pt/features/data-and-storage/object-storage)存储文件型数据
* **连接更多服务** — 添加更多[集成](/zh/pt/features/integrations/overview) (Slack、Linear、GitHub、Notion) ，实现跨服务工作流
* **使用 skills** — 添加 Markdown skill 文件，为 Agent 提供专业知识和操作说明
