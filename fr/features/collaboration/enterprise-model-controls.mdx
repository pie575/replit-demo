Les contrôles de modèles Enterprise permettent aux administrateurs de compte de gérer les modèles Agent que les développeurs peuvent sélectionner. Définissez une politique pour le compte, puis configurez un accès différent aux modèles pour chaque Workspace.

<Note>
  Les contrôles de modèles sont disponibles exclusivement pour les administrateurs de compte sur les comptes Enterprise. Contactez notre équipe commerciale à [sales@replit.com](mailto:sales@replit.com) pour activer cette fonctionnalité pour votre organisation.
</Note>

## Utiliser le routage de modèle intelligent

Le routage de modèle intelligent est l'expérience Agent par défaut pour les Workspaces Enterprise. Lorsque le **mode Auto** est activé, Replit choisit le mode et le modèle les mieux adaptés à chaque tâche tout en équilibrant qualité et coût.

Le routage sélectionne parmi l'ensemble des modèles autorisés par les politiques du compte et du Workspace. Les fournisseurs et modèles en dehors de cet ensemble ne sont pas éligibles à la sélection. Les développeurs peuvent laisser le **mode Auto** activé ou le désactiver pour sélectionner manuellement un modèle autorisé.

## Ouvrir les paramètres de modèle Agent

1. Ouvrez **Paramètres**.
2. Sous **Compte**, sélectionnez **Avancé**.
3. Développez **Modes Agent et fournisseurs de modèles**.

## Définir une politique de fournisseur

<Steps>
  <Step>
    Sélectionnez le fournisseur de modèles que vous souhaitez gérer.
  </Step>

  <Step>
    Sous **Politique de compte**, sélectionnez une option :

    | Option                    | Résultat                                                                |
    | ------------------------- | ----------------------------------------------------------------------- |
    | **Activer tout**          | Tous les modèles du fournisseur sont disponibles dans chaque Workspace. |
    | **Activer une sélection** | Vous choisissez les modèles disponibles pour chaque Workspace.          |
    | **Désactivé**             | Aucun Workspace ne peut utiliser les modèles de ce fournisseur.         |

    <Note>
      Au moins un modèle d'OpenAI, d'Anthropic et de Google doit rester activé. Vous pouvez désactiver les autres fournisseurs.
    </Note>
  </Step>

  <Step>
    Sélectionnez **Mettre à jour**.
  </Step>
</Steps>

Les fournisseurs de modèles open source sont désactivés par défaut. Pour en activer un, sélectionnez **Activer tout** ou **Activer une sélection**, puis sélectionnez **Mettre à jour**.

## Définir une politique de Workspace

Utilisez **Activer une sélection** lorsque différents Workspaces ont besoin d'un accès différent aux modèles.

<Frame caption="La politique du fournisseur Anthropic réglée sur Activer une sélection, avec l'accès aux modèles configuré par Workspace.">
  <img src="/assets/mirror/anthropic-account-policy-workspace-models-38c0f71a609d.jpg" alt="Politique de compte Anthropic réglée sur Activer une sélection avec des bascules de modèles pour un Workspace" width="2000" height="930" data-path="images/workspace/anthropic-account-policy-workspace-models.jpg" />
</Frame>

1. Ouvrez les paramètres du fournisseur.
2. Réglez la **Politique de compte** sur **Activer une sélection**.
3. Dans la liste **Workspace**, sélectionnez le menu déroulant **Paramètre** pour un Workspace.
4. Activez ou désactivez chaque modèle pour ce Workspace.
5. Sélectionnez **Mettre à jour**.

Avant de sélectionner **Mettre à jour**, vous pouvez sélectionner **Copier vers tous** pour appliquer la
sélection de modèles du Workspace actuel à tous les Workspaces du compte.

## Limitations

* Les politiques de modèles s'appliquent aux Workspaces. Vous ne pouvez pas définir une politique différente pour un groupe d'utilisateurs au sein d'un même Workspace.
* Le routage de modèle intelligent ne remplace pas les politiques de compte ou de Workspace. Il ne peut pas sélectionner un fournisseur ou un modèle désactivé.
* Le bouton **Modèles en mode rapide** dans **Modes Agent et fournisseurs de modèles** contrôle l'accès aux variantes de modèles rapides sur tous les Workspaces du compte. Les politiques de fournisseurs et le routage de modèle intelligent ne modifient pas ce paramètre.
