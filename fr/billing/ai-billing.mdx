Replit AI utilise une facturation basée sur l'utilisation pour vous facturer en fonction de ce que vous créez et de la façon dont vous utilisez nos outils alimentés par l'IA. Cela vous garantit de ne payer que pour la valeur que vous retirez de l'Agent.

## Premiers pas

**Tous les abonnés** reçoivent des points de contrôle Agent gratuits à usage unique.

Des crédits mensuels supplémentaires s'appliquent automatiquement à l'utilisation de l'IA :

* **Abonnés Core** : Crédits mensuels (voir [les tarifs](https://replit.com/pricing))
* **Abonnés Pro** : Crédits mensuels échelonnés avec report sur {ProCreditRolloverPeriod}. Voir [Replit Pro](/fr/billing/plans/replit-pro).

Ces crédits couvrent l'Agent et d'autres services cloud Replit tels que les applications publiées, le stockage et les bases de données. Choisissez [Lite, Economy ou Power](/fr/features/agent/agent-modes) pour optimiser l'Agent selon la vitesse, le coût ou les capacités.

## Facturation de l'Agent

Free Mode permet d'effectuer gratuitement les tâches courantes avec l'Agent pour les abonnés Core et Pro, dans la limite de leur allocation. Les modes payants et le travail payant confirmé utilisent une tarification basée sur l'effort, en fonction de la complexité de la demande. Replit demande une confirmation avant le démarrage d'une action payante.

### Fonctionnement de la tarification basée sur l'effort

Lorsque vous discutez avec l'Agent en « Mode Build », il crée des **points de contrôle** qui capturent le travail accompli sur votre demande :

* **Demandes simples** (comme des corrections de bugs ou de petites modifications) coûtent généralement moins cher que les builds complexes
* **Builds complexes** (comme des fonctionnalités complètes ou des intégrations) sont regroupés en un seul point de contrôle qui peut coûter plus qu'une demande simple, reflétant l'effort total engagé
* **Un point de contrôle par demande** élimine les points de contrôle intermédiaires et réduit le bruit de facturation
* **Tarification transparente** vous montre exactement ce que vous payez pour chaque tâche accomplie

<Info>
  Un point de contrôle se produit lorsque l'Agent complète le travail sur votre demande et implémente la fonctionnalité demandée dans votre code.
</Info>

Dans le parcours payant, Plan Mode peut effectuer un raisonnement facturable même s'il ne modifie pas le code.

Pour des informations détaillées sur ce que capturent les points de contrôle et leur fonctionnement, voir [Points de contrôle et retours en arrière](/fr/features/version-control/checkpoints-and-rollbacks).

### Facturation des services Agent

Certaines fonctionnalités de l'Agent utilisent des API tierces payantes en coulisses (comme Claude, ChatGPT et Nano Banana / Gemini). L'Agent gère ces intégrations automatiquement — aucune clé API ni configuration requise. Vous êtes facturé au tarif public de l'API du fournisseur, déduit de vos crédits Replit. Ces coûts apparaissent avec votre autre utilisation dans le [tableau de bord d'utilisation](/fr/billing/managing-spend).

Pour comprendre le coût des exemples d'applications, consultez notre simple [démo interactive](https://agent-pricing.replit.app/).

### Suivi de votre utilisation

Vous pouvez surveiller vos dépenses Agent en temps réel :

1. **Onglet Agent** : Consultez les coûts des points de contrôle individuels en survolant l'icône d'utilisation
2. **Tableau de bord d'utilisation** : Consultez les informations de facturation détaillées pour la période en cours
3. **Paramètres** : Configurez des alertes et des budgets dans **Compte** → **Facturation** pour contrôler vos dépenses

<Tip>
  Les données d'utilisation peuvent prendre jusqu'à 30 minutes pour apparaître dans votre tableau de bord d'utilisation.
</Tip>

## Gestion de vos dépenses

Prenez le contrôle de vos dépenses IA avec les outils budgétaires intégrés de Replit :

* **Alertes d'utilisation** : Recevez une notification lorsque vous atteignez des seuils de dépenses
* **Limites de budget** : Définissez des plafonds stricts pour éviter les frais inattendus
* **Suivi en temps réel** : Surveillez les coûts pendant que vous construisez
* **Packs de crédits** : Achetez des crédits supplémentaires avec des remises sur les achats plus importants. Voir [Gestion de vos dépenses](/fr/billing/managing-spend) pour les détails.

## Prochaines étapes

Prêt à commencer à construire avec l'IA ? Voici comment tirer le meilleur parti de vos crédits :

* **Essayez l'Agent d'abord** : Utilisez vos points de contrôle gratuits pour explorer les capacités de l'Agent
* **Commencez petit** : Débutez avec des demandes simples pour comprendre la tarification basée sur l'effort
* **Utilisez le mode Lite** : Profitez du [mode Lite](/fr/features/agent/agent-modes) pour des modifications rapides et ciblées
* **Configurez des alertes** : Paramétrez les notifications de dépenses avant de dépasser vos crédits

En savoir plus sur les [outils IA de Replit](/fr/welcome) ou explorez nos [abonnements](https://replit.com/pricing).
