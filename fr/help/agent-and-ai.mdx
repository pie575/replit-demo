Ces réponses portent sur l’utilisation d’Agent. Pour en savoir plus, consultez la [présentation d’Agent](/fr/features/agent/overview), les [modes Agent](/fr/features/agent/agent-modes) et la [facturation de l’IA](/fr/billing/ai-billing).

<AccordionGroup>
  <Accordion title="Agent est bloqué ou se déconnecte sans cesse : comment résoudre ce problème ?">
    1. Ouvrez la palette de commandes avec `Cmd+K` (Mac) ou `Ctrl+K` (Windows).
    2. Recherchez **Restart compute** et sélectionnez cette option pour redémarrer l’environnement de développement.
    3. Ouvrez un nouveau Chat avec Agent et décrivez à nouveau votre tâche pour continuer.

    Si Agent semble bloqué, cessez d’envoyer des messages : les messages supplémentaires créent des instructions contradictoires. Si Agent se bloque toujours sur la même tâche, divisez le travail en prompts plus courts et ciblés.
  </Accordion>

  <Accordion title="Agent tourne en boucle ou répète les mêmes étapes : comment l’arrêter ?">
    1. Sélectionnez **Stop** dans le panneau Agent pour l&#39;arrêter immédiatement.
    2. Ouvrez la palette de commandes avec `Cmd+K` (Mac) ou `Ctrl+K` (Windows), recherchez **Restart compute**, puis sélectionnez cette option.
    3. Ouvrez un nouveau Chat Agent et reformulez votre tâche de manière plus précise.

    Pour éviter les boucles :

    * Découpez les grandes tâches en prompts plus courts : un seul objectif par message.
    * Utilisez le [Plan mode](/fr/features/agent/plan-mode) pour cadrer le travail avant qu&#39;Agent ne commence à construire.
    * Définissez une limite d&#39;utilisation dans [Gérer vos dépenses](/fr/billing/managing-spend) afin qu&#39;une boucle ne puisse pas faire grimper votre facture.
  </Accordion>

  <Accordion title="Comment réduire les coûts liés à Agent : quels paramètres sont vraiment utiles ?">
    Ce sont ces choix qui font la plus grande différence :

    * **[Free Mode](/fr/features/agent/agent-modes)** — le travail quotidien avec Agent, sans frais, dans la limite incluse dans votre plan.
    * **[Power mode](/fr/features/agent/agent-modes)** — plus de capacités à un prix abordable lorsque vos travaux l&#39;exigent.
    * **[Plan mode](/fr/features/agent/plan-mode)** — cadrez et validez le travail avant qu&#39;Agent ne le réalise, afin de ne pas payer pour des modifications non souhaitées.
    * **Limite d&#39;utilisation et budget** — fixez un plafond strict dans [Gérer vos dépenses](/fr/billing/managing-spend).

    Il est également utile de démarrer un nouveau Chat Agent lorsque vous changez de tâche. Consultez votre dashboard d&#39;utilisation pour repérer les tâches les plus coûteuses.
  </Accordion>

  <Accordion title="Quels sont les modes Agent et en quoi diffèrent-ils ?">
    Agent propose trois modes principaux, ainsi qu&#39;un paramètre **Auto** au sein des modes payants. Consultez [Free Mode](/fr/help/free-agent-mode) pour tous les détails.

    * **Free Mode** — le travail quotidien avec Agent, sans frais, dans la limite de l&#39;allocation de votre forfait. Les allocations Core et Pro sont réinitialisées toutes les cinq heures et sont soumises à des limites hebdomadaires. Le niveau Starter conserve ses limites actuelles. Consultez **Settings → Usage** pour voir votre utilisation.
    * **Auto** — sélection automatique du modèle pour le travail payant en Power ou Max sur Core et Pro.
    * **Power** — un mode payant de niveau intermédiaire, doté de modèles puissants à un prix abordable.
    * **Max** — un mode payant haut de gamme, doté des meilleurs modèles de pointe pour les tâches les plus exigeantes.

    Les modes payants ont été renommés. **Economy devient Power**, et le mode auparavant appelé **Power devient Max**. Les paramètres de mode existants sont conservés sous les nouveaux noms. Si une demande dépasse les capacités de Free Mode, Agent peut proposer une option payante **Allow once**. Replit demande une confirmation avant le lancement d&#39;une action payante, puis Agent revient au Free Mode.

    Par ailleurs, le [Plan mode](/fr/features/agent/plan-mode) permet à Agent de cadrer le travail avant d&#39;apporter des modifications, tandis que le Mode Build applique directement les changements. Consultez [Plan vs. Build mode](/fr/learn/plan-vs-build-mode).
  </Accordion>

  <Accordion title="Agent a effectué des modifications que je ne souhaitais pas : comment revenir en arrière ?">
    Replit enregistre des [checkpoints](/fr/features/version-control/checkpoints-and-rollbacks) au fur et à mesure qu’Agent travaille. Dans le chat Agent, repérez le message précédant la modification que vous souhaitez annuler, puis sélectionnez l’option de restauration à côté pour rétablir votre projet à cet état.

    Pour connaître toutes les options de restauration, y compris la récupération de fichiers spécifiques, consultez [Checkpoints et restaurations](/fr/features/version-control/checkpoints-and-rollbacks).
  </Accordion>

  <Accordion title="Agent indique ne pas pouvoir accéder à Internet ni aux API externes : est-ce normal ?">
    Pendant la phase de création et de modification, Agent fonctionne dans un environnement isolé dont l&#39;accès sortant est restreint. Votre app publiée peut malgré tout effectuer des appels d&#39;API externes lors de son exécution : l&#39;isolation s&#39;applique à l&#39;environnement d&#39;édition d&#39;Agent, pas à votre app en cours d&#39;exécution.

    Si un appel d&#39;API échoue dans votre app en cours d&#39;exécution, vérifiez que vos clés sont bien enregistrées dans le volet [Secrets](/fr/core-concepts/project-editor/app-setup/secrets), puis consultez la page d&#39;état du provider. Sur un réseau d&#39;entreprise ou scolaire, les connexions sortantes de votre app peuvent être bloquées : renseignez-vous auprès de votre administrateur réseau.
  </Accordion>

  <Accordion title="Puis-je utiliser mes propres clés API avec Agent ?">
    Oui. Ajoutez vos clés dans le volet [Secrets](/fr/core-concepts/project-editor/app-setup/secrets) : votre app les utilisera pour ses appels API. Ouvrez l&#39;outil **Secrets**, sélectionnez **+ New secret**, puis saisissez un nom (par exemple `OPENAI_API_KEY`) et une valeur.

    Vous pouvez [utiliser vos propres clés de provider d&#39;IA](/fr/features/integrations/replit-ai-integrations) pour les modèles appelés par votre app. En revanche, le modèle qui alimente l&#39;expérience Agent elle-même s&#39;exécute sur l&#39;infrastructure de Replit et ne peut pas être remplacé.
  </Accordion>

  <Accordion title="Agent ajoute des fonctionnalités que je n’ai pas demandées : comment obtenir un comportement plus précis ?">
    Gardez Agent concentré grâce à des prompts plus précis :

    * Commencez par le mot *Uniquement* — par exemple, &quot;Ajoute uniquement un bouton de suppression à la carte utilisateur. Ne change rien d&#39;autre.&quot;
    * Utilisez d&#39;abord le [Plan mode](/fr/features/agent/plan-mode) pour vérifier ce qu&#39;Agent compte faire avant qu&#39;il ne modifie quoi que ce soit.
    * Si Agent effectue une modification non souhaitée, demandez-lui de l&#39;annuler immédiatement dans la même conversation.

    Pour en savoir plus, consultez [Rédiger des prompts efficaces](/fr/learn/effective-prompting).
  </Accordion>
</AccordionGroup>
