Replit предлагает несколько способов установки пакетов для вашего Replit App и управления ими. Вы можете устанавливать пакеты через [Shell](/ru/pt/features/workspace-tools/shell), поручить это [Agent](/ru/pt/features/agent/overview/) или позволить Replit автоматически находить и устанавливать недостающие зависимости при запуске вашего Replit App.

<div id="instale-pacotes-usando-o-shell">
  ## Установка пакетов через Shell
</div>

Откройте инструмент **Shell** в Project Editor и выполните команду для менеджера пакетов вашего языка программирования:

<CodeGroup>
  ```bash Node.js (npm) theme={null}
  npm install <package-name>
  ```

  ```bash Node.js (pnpm) theme={null}
  pnpm add <package-name>
  ```

  ```bash Python (poetry) theme={null}
  poetry add <package-name>
  ```

  ```bash Python (pip) theme={null}
  pip install <package-name>
  ```

  ```bash Ruby theme={null}
  bundle add <gem-name>
  ```
</CodeGroup>

Кроме того, для установки пакетов на всех поддерживаемых языках можно использовать [Universal Package Manager (UPM)](https://github.com/replit/upm/) от Replit:

```bash theme={null}
upm add <package-name>
```

Чтобы установить определённую версию:

```bash theme={null}
upm add 'flask==2.3.3'
```

Полный список поддерживаемых языков и менеджеров пакетов см. в разделе [UPM: Supported Languages](https://github.com/replit/upm/#supported-languages).

<div id="instale-pacotes-usando-o-agent">
  ## Установка пакетов с помощью Agent
</div>

Вы можете попросить [Agent](/ru/pt/features/agent/overview/) установить пакеты прямо в чате. Например:

* «Install the axios package»
* «Add Flask and SQLAlchemy to my project»
* «Set up TailwindCSS»

Agent установит пакет с помощью подходящего для вашего проекта менеджера пакетов и обновит соответствующие файлы конфигурации.

<div id="deteco-automtica-de-importaes">
  ## Автоматическое определение импортов
</div>

Replit автоматически проверяет ваш код на наличие недостающих зависимостей каждый раз, когда вы нажимаете **Run**. Если код импортирует пакет, который ещё не установлен, Replit обнаруживает это и автоматически устанавливает последнюю версию.

Например, если добавить `import flask` в `main.py`, то при следующем нажатии на **Run** в **Console** появится сообщение о том, что устанавливается **Flask**.

<Note>
  Настроить автоматическое определение импортов можно в файле [.replit](/ru/pt/features/project-setup/configuration#replit-file) с помощью параметра `packager.features.guessImports`.
</Note>

<div id="substitua-a-deteco-automtica">
  ### Переопределение автоматического определения
</div>

Если пакет определён неверно или вам нужна конкретная версия, выполните нужную команду установки в Shell. Например:

```bash theme={null}
upm add 'flask==2.3.3'
```

Вы также можете исключить определённые пакеты или пути из автоматического определения в файле [.replit](/ru/pt/features/project-setup/configuration#replit-file):

<div id="gerenciadores-de-pacotes-python">
  ## Менеджеры пакетов Python
</div>

При создании Replit App на Python менеджером пакетов по умолчанию используется **poetry**. Это значит, что команда `pip install` не управляет зависимостями вашего приложения. Вместо неё используйте `poetry add <package>` или `upm add <package>` в Shell.

<div id="mude-do-poetry-para-o-pip">
  ### Переход с poetry на pip
</div>

Если вы предпочитаете `pip`, выполните следующие шаги:

<Steps>
  <Step>
    Откройте Shell и выполните:

    Удалите lock-файл, чтобы система управления пакетами переключилась на pip:

    ```bash theme={null}
    rm poetry.lock
    ```
  </Step>

  <Step title="Перенесите зависимости">
    Перенесите зависимости из раздела `[tool.poetry.dependencies]` файла `pyproject.toml` в `requirements.txt`. Например, `flask = "^3.0.2"` превращается в `flask>=3.0.2,<4`.
  </Step>

  <Step title="Очистите pyproject.toml">
    Удалите разделы `[tool.poetry...]` из `pyproject.toml`.
  </Step>
</Steps>

После этих изменений система управления пакетами будет использовать `pip` для всех дальнейших операций, а автоматическое определение импортов продолжит работать как обычно.

<div id="dependncias-do-sistema-com-nix">
  ## Системные зависимости с Nix
</div>

Replit поддерживает все языки программирования благодаря интеграции с [Nix](https://nixos.org/). Если вам нужны зависимости системного уровня помимо стандартных пакетов языка, добавьте их в файл [replit.nix](/ru/pt/features/project-setup/configuration#replit-nix-file).

<div id="pacotes-nix">
  ### Пакеты Nix
</div>

Добавляйте системные зависимости, редактируя файл `replit.nix` напрямую. Найти доступные пакеты можно на [search.nixos.org](https://search.nixos.org/packages).

<div id="mdulos">
  ### Модули
</div>

Модули объединяют в себе поддержку языков программирования, форматировщиков и packager. Они служат основой вашего Replit App. Если вы создаёте Replit App из шаблона или из репозитория GitHub, Replit устанавливает необходимые модули автоматически.

Настроить модули и другие параметры Nix можно в файле [.replit](/ru/pt/features/project-setup/configuration#replit-file).

<div id="configurao-do-packager">
  ## Настройка packager
</div>

Вы можете изменить поведение системы управления пакетами в файле [.replit](/ru/pt/features/project-setup/configuration#replit-file):

| Параметр                              | Описание                                                                   | По умолчанию               |
| ------------------------------------- | -------------------------------------------------------------------------- | -------------------------- |
| `packager.language`                   | Язык, используемый для операций с пакетами                                 | Определяется автоматически |
| `packager.features.guessImports`      | Автоматически находит и устанавливает недостающие пакеты при запуске (Run) | `true`                     |
| `packager.features.packageSearch`     | Включает поддержку поиска пакетов                                          | `true`                     |
| `packager.features.enabledForHosting` | Требует установки пакетов при хостинге                                     | `false`                    |
| `packager.afterInstall`               | Команда, выполняемая после установки пакета                                | —                          |
| `packager.ignoredPaths`               | Пути, игнорируемые при обнаружении импортов                                | `[]`                       |
| `packager.ignoredPackages`            | Пакеты, исключаемые из автоматического обнаружения                         | `[]`                       |
