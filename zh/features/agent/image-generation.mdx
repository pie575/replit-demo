<div id="features">
  ## 功能
</div>

借助 Agent 的图像生成能力，打造视觉效果出众的应用。你无需再依赖图库照片和外部设计工具，也不必为基础视觉内容聘请设计师。无论是搭建作品集网站、开发游戏，还是设计移动应用界面，图像生成都能为你的 project 提供量身定制的视觉素材。

Agent 可以执行以下图像生成操作：

* **自定义图像生成**：根据详细的描述和要求生成图像
* **风格适配**：支持从写实到卡通等多种艺术风格
* **透明背景**：直接生成透明 PNG 图像，或去除现有图像的背景——非常适合徽标、图标、贴纸和商品抠图
* **项目集成**：将生成的图像无缝添加到应用的代码库中
* **迭代优化**：根据你的反馈修改和改进图像

<div id="usage">
  ## 使用方式
</div>

图像生成已内置于 Agent，无需额外开启。打开任意已启用 Agent 的 Replit App，直接让 Agent 创建你需要的视觉内容即可。Agent 会根据你的请求自动判断何时生成图像，并按照你的要求生成定制图像。

<div id="best-practices-for-image-generation">
  ### 图像生成的最佳实践
</div>

遵循以下准则，让 Agent 生成的图像达到最佳效果：

**描述具体、细致**

* 说明风格、色彩、构图和氛围等细节
* 必要时指定尺寸或宽高比
* 说明用途 (图标、背景、插图等)
* 如果需要将徽标、图标、贴纸或抠图叠加在其他内容之上，请要求使用透明背景

**迭代与优化**

* 先给出基本描述，再根据结果逐步优化
* 让 Agent 调整生成图像的特定细节
* 请求生成多个变体，以探索不同的创意方向

**兼顾 project 的整体风格**

* 保持整个应用的视觉一致性
* 指定符合你的品牌或设计系统的风格偏好
* 要求生成与现有视觉元素相协调的图像

<div id="project-integration">
  ### 项目集成
</div>

Agent 可将生成的图像无缝集成到你的代码库中：

* **自动创建文件**：生成的图像会直接保存到你的项目文件中
* **更新代码**：Agent 会更新代码，引用新的图像文件
* **资源整理**：图像会存放在项目结构中合适的目录下

有了这套顺畅的工作流，你无需离开开发环境即可生成并应用视觉内容。

</Note>
