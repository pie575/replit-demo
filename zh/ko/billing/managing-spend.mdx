<div id="ai">
  ## AI 成本优化
</div>

[Agent](/zh/ko/features/agent/overview) 等 AI 功能功能强大，但通过合理使用，您可以在控制成本的同时充分发挥其价值。以下是一些有效降低 AI 支出的办法。

<div id="plan-mode">
  ### 使用 Plan 模式实现高性价比协作
</div>

[Plan 模式](/zh/ko/features/agent/plan-mode)是节省 AI 成本最有效的方法之一。启用 Plan 模式后，Agent 会在不修改代码的情况下生成详细计划。这种方式具有多项成本优势：

* **执行前沟通**：在开始执行前，与 Agent 讨论并完善方案
* **更低的 Token 成本**：规划对话比生成和编辑代码消耗的 Token 更少
* **精准聚焦**：通过审查和引导计划，确保 Agent 只处理重要事项
* **迭代优化**：在为实现消耗 Token 前，先明确范围

当你想探索解决方案、完善需求，或在实现前了解方案时，请使用 [Plan 模式](/zh/ko/features/agent/plan-mode)。

<div id="agent">
  ### 使用 Agent 模式控制成本
</div>

使用 [Agent 模式](/zh/ko/features/agent/agent-modes)，可在成本和性能之间灵活取舍：

* **Free Mode**：Core 和 Pro 订阅用户可在套餐额度内免费完成日常 Agent 任务。
* **Power**：以合理的价格提供更强的性能。
* **Max**：适合最具挑战性任务的顶尖前沿模型。
* **Turbo**：可在 Max 中使用的可选开关。

Agent 会在构建过程中自动审查自己的代码，发现错误并减少代价高昂的返工——无需手动开关。如需更好地控制支出，请先使用 Plan 模式明确工作范围：

* **执行前审查**：在 Agent 进行更改前审查计划。
* **选择性批准**：只批准符合目标的更改，跳过其余更改。

<Tip>
  日常任务请从 [Free Mode](/zh/ko/features/agent/agent-modes) 开始。需要以合理价格获得更强性能时，请选择 [Power 模式](/zh/ko/features/agent/agent-modes)。先制定计划，再逐步批准更改。
</Tip>

<div id="section-2">
  ## 购买积分包
</div>

如果你使用的是 Core 或 Pro 套餐，且需要超出每月订阅额度的额外积分，可前往 **设置** → **账户使用量** → **Credits** → **Purchase credit pack** 购买积分包。批量购买积分包可享受折扣，非常适合应对临时的用量激增，或为更大型的项目做准备。

<div id="section-4">
  ### 积分包的使用方式
</div>

* **购买方式**：Core 和 Pro 套餐用户可前往 **设置** → **账户使用量** → **Credits** → **购买积分包** 购买
* **有效期**：积分包自购买之日起 6 个月后失效
* **不自动续订**：积分包不会自动续订
* **不结转**：积分包中未使用的积分到期后不会结转
* **自动使用**：系统会自动优先使用最早到期的积分包中的积分，以充分发挥购买价值
* **自动充值**：启用自动充值后，余额不足时会自动购买*新的*积分包，避免项目进行中断
* **随时管理**：在 **设置** → **账单** 中启用、调整或禁用自动充值

<Note>
  使用限额和预算适用于用完已购买积分包后的使用量。若要将使用量限制为仅使用已购买积分包中的积分，请将限额设为 $0.01。
</Note>

<div id="section-5">
  ### 查看付款收据
</div>

如果你在账户中使用充值功能，请前往**设置** → **账单**，找到**付款收据**，查看成功的一次性充值和自动充值的付款记录。每一行都会显示付款日期、购买类型、金额和退款状态。选择**查看收据**即可打开支付服务提供商提供的收据。

<div id="section-6">
  ## 设置用量限额和预算
</div>

您可以为所有按用量计费的服务设置每月用量限额和预算，以监控和控制成本。

<div id="section-7">
  ### 使用限额
</div>

使用限额可限制超出每月积分的支出。达到限额后，按使用量计费的服务将被停用，直至下一个账单周期开始或您提高限额。

对于 Core 账户，请依次打开 **设置** → **账户** → **账单**，然后设置使用限额。对于组织，您可以在[使用量页面](https://replit.com/usage)的 **使用量总计** 下选择 **管理**，以设置使用限额。

<div id="section-8">
  ### 服务中断限额
</div>

达到此限额后，服务将暂停，直至预算增加或下一个账单周期开始。这有助于避免产生额外费用。

对于 Core 账户，请前往**设置** → **账户** → **账单**，设置服务中断限额。

<div id="section-9">
  ### 组织预算
</div>

对于组织，您可以在[设置页面](https://replit.com/t/replit/settings/billing)设置使用预算。预算必须以 {OrganizationBudgetIncrement} 为增量进行设置。

<Note>要启用每月使用限额，您必须拥有组织管理员或所有者权限。如无访问权限，请联系组织所有者。</Note>

<div id="section-10">
  ### 用户级支出限额
</div>

Enterprise 管理员可为个别成员设置不同于工作区默认值的支出限额。您可以为重度用户设置更高的限额，或在不影响工作区其他成员的情况下限制特定成员的支出。

<Steps>
  <Step title="打开工作区使用情况页面">
    在 Enterprise 工作区中，打开[使用情况页面](https://replit.com/usage)。**Agent 用户**表格会列出工作区中的所有成员及其当前使用情况。
  </Step>

  <Step title="编辑成员限额">
    找到要调整的成员，然后选择**使用限额**列中的编辑图标。对话框将显示工作区默认值、适用的群组限额以及新的用户级限额字段。

    <Frame>
      <img src="/assets/mirror/edit-usage-limit-87127319c809.png" alt="工作区成员的使用限额编辑对话框，显示工作区默认值、当前用户级限额、适用的群组限额，以及设置为 $5 的用户限额输入框" width="1202" height="916" data-path="images/billing/edit-usage-limit.png" />
    </Frame>
  </Step>

  <Step title="保存覆盖设置">
    输入新限额并选择**保存**。覆盖设置会立即生效，新值将显示在**使用限额**列中。若要稍后移除覆盖设置，请清空该字段并保存。随后，该成员将重新适用最具体的适用群组限额或工作区限额。
  </Step>
</Steps>

<Note>用户级支出限额仅适用于 Enterprise 套餐。分配到[自定义群组](/zh/ko/teams/identity-and-access-management/groups-and-permissions)的成员会继承该群组的限额，除非设置了单独的覆盖设置。用户级覆盖设置始终优先于群组和工作区默认值。</Note>

<div id="section-11">
  ### 组织管理员控制
</div>

组织管理员可在[组织账单设置](https://replit.com/t/replit/settings/billing)中管理 AI 模型访问权限和集成。

**禁用外部 AI 模型集成**

启用此设置后，组织中的所有用户都将无法使用外部 AI 模型集成 (包括通过 Replit 托管连接器使用的 OpenAI、Anthropic、xAI、Perplexity 等) 。

启用此设置后，组织中的所有用户都将无法使用 Replit 托管的 AI 集成。
