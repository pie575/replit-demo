# 데이터로 작업하기

> 시각적 도구나 SQL을 사용해 My Data 탭에서 데이터베이스를 탐색, 편집, 내보내기, 쿼리하세요.

**My Data** 탭은 데이터베이스에 있는 내용을 확인하고 변경하는 곳입니다. **Database** 도구를 열고 데이터베이스를 선택한 다음 **My Data**를 선택하세요. 시각적으로 작업하거나 SQL을 직접 실행할 수 있습니다.

<Note>
  프로덕션 데이터를 편집하려면 프로덕션 데이터베이스를 선택하고 **My Data**를 연 다음 **Edit**을 토글하세요. 주의하세요: 이는 실제 앱의 실제 데이터입니다.
</Note>

## 데이터를 시각적으로 탐색 및 수정

Database 도구에는 데이터를 시각적으로 탐색하고 수정할 수 있는 도구인 <a href="https://orm.drizzle.team/drizzle-studio/overview" target="_blank">Drizzle Studio</a>가 포함되어 있습니다. 이 시각적 도구는 구문 오류를 방지하는 데 도움이 되며 다음과 같은 기능을 제공합니다.

* 데이터를 필터링 및 정렬해 특정 정보에 집중
* 외부에서 사용할 수 있도록 데이터를 파일로 내보내기
* 행 데이터 삽입 또는 수정
* 스키마, 테이블, 뷰, enum 생성 및 관리

## SQL 명령 실행

SQL 러너를 사용하면 데이터베이스에서 SQL 명령을 실행하고 결과를 확인할 수 있습니다.

<Accordion title="SQL 러너에 접근하는 방법">
  **Database** 도구에서:

  1. **My Data** 탭을 선택하세요
  2. <img class="icon-svg" src="https://mintcdn.com/replit/X_IP1EeHGm0cA2VA/images/icons/sql-runner-icon.svg?fit=max&auto=format&n=X_IP1EeHGm0cA2VA&q=85&s=fd73c517972d1a4004105e6ab49d130b" alt="SQL 러너 아이콘" width="16" height="16" data-path="images/icons/sql-runner-icon.svg" /> **SQL runner**를 선택하세요
</Accordion>

쿼리를 실행하려면 텍스트 영역에 SQL 문을 입력하고 인접한 <img class="icon-svg" src="https://mintcdn.com/replit/X_IP1EeHGm0cA2VA/images/icons/sql-play.svg?fit=max&auto=format&n=X_IP1EeHGm0cA2VA&q=85&s=eb0c68e0ab494444f0cbc60325bd1150" alt="SQL 실행 아이콘" width="18" height="18" data-path="images/icons/sql-play.svg" /> 실행 버튼을 선택하세요.

<Frame>
  <img src="https://mintcdn.com/replit/tlGd6oyGOaUUeRxr/images/databases/sql-runner-run.jpg?fit=max&auto=format&n=tlGd6oyGOaUUeRxr&q=85&s=258c6ac51524a21e6a6e2070c7cefd3c" alt="SQL 러너와 실행 버튼 스크린샷" width="1390" height="608" data-path="images/databases/sql-runner-run.jpg" />

<Tip>
  SQL을 직접 작성하지 않아도 됩니다. Agent에게 데이터를 조회하거나 변경해 달라고 요청하면 Agent가 SQL을 작성하고 실행해 줍니다.
</Tip>
