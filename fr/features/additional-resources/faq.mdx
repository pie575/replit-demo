      <Accordion title="Où puis-je obtenir de l'aide au niveau du code ?">
        Le meilleur endroit pour obtenir de l'aide sur le code est d'utiliser [Replit AI](/fr/build/welcome/). Dans l'éditeur de projet, ouvrez un nouvel onglet et recherchez **AI**. Replit AI peut vous aider à configurer de nouveaux projets, répondre à des questions sur votre code et vous accompagner dans votre réflexion. Pour une assistance complémentaire, vous pouvez également consulter notre [Community Hub](https://replit.com/community) pour trouver des ressources supplémentaires.
      </Accordion>

      <Accordion title="J'ai du mal à utiliser Replit. Comment puis-je obtenir de l'aide ?">
        Connectez-vous à Replit et utilisez le **?** dans le coin supérieur droit de la page pour obtenir de l'aide. Pour une assistance supplémentaire, consultez le [document sur la politique d'assistance](/fr/legal-and-security-info/support-policy).
      </Accordion>

      <Accordion title="Où puis-je obtenir de l'aide pour la facturation ?">
        Avant de contacter l'équipe d'assistance, vérifiez si vous pouvez trouver une solution ci-dessous dans **Paramètres**. Si cela ne vous aide pas, veuillez vous connecter et utiliser le **?** dans le coin supérieur droit de la page pour obtenir de l'aide.
      </Accordion>

      <Accordion title="Je n'arrive pas à accéder à mon compte Replit – que dois-je faire ?">
        Veuillez envoyer un e-mail à `support@replit.com` en indiquant votre nom d'utilisateur et votre identifiant de connexion.
      </Accordion>

      <Accordion title="Quand vais-je recevoir une réponse de Replit ?">
        L'assistance Replit est généralement disponible du lundi au vendredi de 9 h à 20 h, heure normale de l'Est (UTC-5).
      </Accordion>

      <Accordion title="Comment restaurer mes dossiers dans mon application Replit ?">
        Accédez à votre profil situé dans le coin supérieur droit de votre application Replit, sélectionnez **CLUI** et, dans la zone de recherche qui apparaît, tapez *restore*. Dans les résultats de recherche, vous verrez l'option **restore-folder** pour restaurer un dossier spécifique depuis la corbeille.

        > Remarque : Les applications Replit supprimées sont définitivement effacées et irrécupérables **30 jours** après leur date de suppression initiale.
      </Accordion>

      <Accordion title="Comment restaurer une application Replit supprimée ?">
        Accédez à votre profil situé dans le coin supérieur droit de votre application Replit, sélectionnez **CLUI** et, dans la zone de recherche qui apparaît, tapez *restore*. Dans les résultats de recherche, vous verrez l'option **restore-repl** pour restaurer une application Replit spécifique depuis la corbeille.

        > Remarque : Les applications Replit supprimées sont définitivement effacées et irrécupérables **30 jours** après leur date de suppression initiale.
      </Accordion>

      <Accordion title="Pourquoi mon application Replit ne se charge-t-elle pas ?">
        Si votre application Replit ne se charge pas, essayez ces étapes de débogage :

        1. Testez votre [connexion Internet](https://www.speedtest.net/).
        2. Essayez un autre navigateur.
        3. Vérifiez que JavaScript est activé dans votre navigateur.
        4. Ouvrez la palette de commandes avec `Cmd+K` (Mac) ou `Ctrl+K` (Windows), recherchez **Restart compute**, puis sélectionnez-la.

        Si aucune de ces étapes n'a fonctionné, consultez l'[état des services](https://status.replit.com) de Replit. Si le statut indique **All systems are go!** et que vous rencontrez toujours des problèmes pour charger votre application Replit, veuillez contacter l'[assistance Replit](https://replit.com/support).
      </Accordion>

      <Accordion title="Comment télécharger un fichier volumineux dans mon application Replit ?">
        Si le fichier est trop volumineux pour un téléchargement standard via l'interface graphique, vous pouvez utiliser `scp` (Secure Copy) pour transférer des fichiers en toute sécurité entre les systèmes locaux et distants via [SSH](/fr/features/workspace-tools/ssh). Pour copier des fichiers de votre machine locale vers la machine distante, utilisez cette syntaxe : `scp filename username@ip_address:/home/username`

        Vous pouvez également copier des répertoires entiers à l'aide de scp.
      </Accordion>

      <Accordion title="Comment vérifier mon solde de crédits d'utilisation ?">
        Vous pouvez consulter votre solde actuel sur [https://replit.com/\~/cli/account/usage-credits-balance](https://replit.com/~/cli/account/usage-credits-balance).
      </Accordion>

      <Accordion title="J'ai du mal à me connecter ; que dois-je faire ?">
        1. Assurez-vous d'utiliser la bonne adresse e-mail et le bon mot de passe.
        2. Pour réinitialiser votre mot de passe, accédez à la [page mot de passe oublié](https://replit.com/forgot). Pensez à vérifier votre dossier spam pour l'e-mail de réinitialisation provenant de `notifications@replit.com`.
        3. Essayez de vous connecter via un autre navigateur.

        Si aucune de ces étapes ne fonctionne, veuillez [contacter l'assistance](https://replit.com/support).
      </Accordion>

      <Accordion title="Comment modifier mon adresse e-mail si je me suis inscrit avec Google/GitHub/Facebook/Apple ?">
        Nous exigeons un mot de passe pour modifier l'adresse e-mail de votre compte. Si vous vous êtes inscrit avec un fournisseur d'authentification tiers comme Google ou GitHub, vous devez d'abord créer un mot de passe.

        Pour créer un mot de passe :

        1. Ouvrez la barre latérale et déconnectez-vous.
        2. Revenez à la page de connexion, sélectionnez [mot de passe oublié](https://replit.com/forgot) et saisissez votre adresse e-mail.
        3. Vous recevrez un e-mail avec un lien pour créer un nouveau mot de passe. Si vous ne voyez pas l'e-mail, vérifiez votre dossier spam et attendez jusqu'à trente minutes pour que l'e-mail vous soit envoyé.
        4. Après vous être connecté, ouvrez [Paramètres](https://replit.com/settings) pour modifier votre adresse e-mail.
      </Accordion>

      <Accordion title="Comment modifier mon nom d'utilisateur ?">
        Les utilisateurs Replit ne peuvent modifier leur nom d'utilisateur qu'**une seule fois**. Accédez à [CLUI](https://replit.com/~/cli/account/change-username?run=1) et sélectionnez **change-username**. Si l'option n'est pas disponible, vous l'avez déjà modifié.
      </Accordion>

      <Accordion title="Qu'est-ce que le mode Explorateur, et comment puis-je l'activer ?">
        Les Explorateurs sont des utilisateurs Replit qui ont choisi de voir et tester les nouvelles fonctionnalités encore en développement. Pour activer le mode Explorateur, ouvrez [Paramètres](https://replit.com/settings) et activez le commutateur Explorateur (par exemple sous **Compte** ou **Utilisateur**).
      </Accordion>
