export const CoreCredits = '$20';

以下解答涵盖了 Replit 开发者最常问到的账单问题。如需详细了解按用量计费的运作方式，请参阅[按用量计费](/zh/pt/billing/about-usage-based-billing)和[管理你的支出](/zh/pt/billing/managing-spend)。

<AccordionGroup>
  <Accordion title="为什么我的月度账单周期尚未结束就被收费了？">
    当使用量超出每月包含的额度并达到某个设定金额 (即*账单阈值*) 时，Replit 会就超出部分计费，而不是仅在计费周期结束时收费。您的 Core 方案每月包含 {CoreCredits} 额度，超出部分的 Agent 使用量会在达到该阈值时单独计费。

    如何降低后续费用：

    1. 使用[规划模式](/zh/pt/features/agent/plan-mode)在 Agent 开始构建前界定范围并确认工作内容，避免代价高昂的返工。
    2. 如果您订阅了 Core 或 Pro，可使用 [Free Mode](/zh/pt/features/agent/agent-modes) 免费完成日常的 Agent 工作。配额每五小时重置一次，并设有每周上限。前往**设置 → 使用情况**查看您的用量。
    3. 需要更多能力又希望控制花费时，可选择 Power。
    4. 在[管理支出](/zh/pt/billing/managing-spend)中设置用量与预算上限，以控制超出额度后的费用。
    5. 每项新任务都新开一个 Agent 对话，让上下文保持精简。

    要查看费用来源，请打开**设置 → 账户使用情况**并选择**查看历史账单**。
  </Accordion>

  <Accordion title="我通过 App Store 或 Google Play 订阅，但无法添加付款方式，该如何解决？">
    当你通过 App Store 或 Google Play 订阅时，账单由 Apple 或 Google 处理，因此移动应用内不会显示付款选项。请通过网页端管理付款：

    1. 打开浏览器，前往 **设置 → 账单**。
    2. 选择 **更新付款方式**。
    3. 输入银行卡信息并保存。

    添加网页端付款方式后，你就可以在 **账单** 标签页中管理账单并购买积分包。有关积分包的详情，请参阅[管理你的支出](/zh/pt/billing/managing-spend)。
  </Accordion>

  <Accordion title="订阅后 30 天内可以提现吗？">
    退款资格取决于您的套餐及申请退款的项目。请注意：

    * Agent 和 AI 使用费用不可退款，因为每笔费用都对应已使用的计算资源。
    * [自定义域名注册费用不可退款](/zh/pt/build/domain-purchasing)。

    如需申请订阅费用退款，请使用注册邮箱[联系 Replit 支持团队](https://replit.com/support)，并说明申请原因。请先在**设置 → 账单**中取消订阅。

    <Note>具体的订阅退款期限和资格将由支持团队根据您的账户和套餐确认。</Note>
  </Accordion>

  <Accordion title="我被收取了意外的 Agent 或 AI 使用费，可以退款吗？">
    Agent 和 AI 的使用费用不予退款，因为每笔费用都对应 Replit 为执行你的任务已经消耗的算力。你可以通过以下方式避免日后出现意外费用：

    1. 打开 **设置 → 账户用量**，设置用量上限和预算。参见[管理你的支出](/zh/pt/billing/managing-spend)。
    2. Core 和 Pro 订阅均包含 Free Mode。日常的 Agent 工作可使用 [Free Mode](/zh/pt/features/agent/agent-modes)，在配额范围内无需付费；也可以选择 Power，以实惠的价格获得更强的能力。
    3. 使用[规划模式](/zh/pt/features/agent/plan-mode)在 Agent 开始构建前界定工作范围，减少返工。

    如果你认为某笔费用属于误收，请准备好费用金额、日期和支付意图 ID。该 ID 以 `pi_` 开头，可在账单详情页面查看。然后[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="取消订阅后仍被扣费，这正常吗？">
    取消后仍被扣费通常源于以下两种情况之一：

    * 取消前产生的用量，直到取消日期之后才达到账单阈值。
    * 系统对此前某个账单周期中失败的付款进行了重新扣款。

    如需核实，请打开**设置 → 账户用量**，选择**查看历史账单**，并核对账单日期及其涵盖的用量周期。如果仍有疑问，请[联系 Replit 支持团队](https://replit.com/support)，并附上以 `pi_` 开头的付款意图 ID。
  </Accordion>

  <Accordion title="我的订阅费用已按时支付，为什么还被收取额外存储空间费用？">
    当您存储的数据超出套餐所含额度时，就会产生存储费用。请参阅[基于用量的计费](/zh/pt/billing/about-usage-based-billing)了解存储的计量方式，参阅[对象存储计费](/zh/pt/billing/object-storage-billing)了解对象存储的费用。

    要查看是什么占用了空间，请在项目中打开 Shell 并运行：

    ```bash theme={null}
    du -sh *
    du -ah | sort -rh | head -20
    ```

    接下来，删除构建产物 (如 `.cache` 或 `dist`) 、旧日志和未使用的上传文件，并清理数据库中的陈旧数据。释放空间后，后续的存储费用就不会再继续累积。
  </Accordion>

  <Accordion title="如何申请自定义域名注册退款？">
    [自定义域名注册费用不予退款](/zh/pt/build/domain-purchasing)，因为域名注册涉及第三方费用，一经处理便无法撤销。

    如果您误注册了域名，或希望转移域名，请[联系 Replit 支持团队](https://replit.com/support)，并提供您的域名和与账户绑定的电子邮件地址。我们的团队会为您说明可选的处理方式。
  </Accordion>

  <Accordion title="我已支付账单，但账户仍被暂停——何时会解除限制？">
    计费冻结在付款确认后可能需要一小段时间才会解除。请尝试以下步骤：

    1. 使用 `Cmd+Shift+R` (Mac) 或 `Ctrl+Shift+R` (Windows) 强制刷新浏览器。
    2. 退出登录后重新登录，以重新加载账户状态。
    3. 打开**设置 → 账户用量**，选择**查看历史账单**，确认账单显示为已支付。

    冻结解除后，部署不会自动重启。如果你的应用仍处于离线状态，请打开**部署**并选择**发布**以重新部署。如果你的账户仍处于暂停状态，请[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="我不认识一笔 Replit 扣款，该怎么办？">
    在向银行提出扣款争议之前，请先确认这笔扣款：

    1. 打开**设置 → 账户用量**，选择**查看历史账单**，然后核对日期、金额和说明。
    2. 确认是否有其他人能访问你的账户或付款方式。
    3. 查找扣款日期前后 Replit 发送的账单邮件，垃圾邮件文件夹也请一并检查。

    扣款通常是订阅费、达到账单限额后产生的用量费用，或积分包购买。

    <Warning>在向银行提出扣款争议*之前*，请先联系 Replit 支持团队——发起拒付可能会导致你的账户被封禁。</Warning>

    [联系 Replit 支持团队](https://replit.com/support)，并提供以 `pi_` 开头的付款意图 ID、扣款金额和日期。
  </Accordion>

  <Accordion title="我的付款被拒绝了——是 Replit 的问题吗？">
    大多数扣款失败来自您的银行或发卡机构，而非 Replit——通常是银行对陌生交易的自动安全拦截。请按以下顺序尝试：

    1. 在 **设置 → 账单 → 更新支付方式** 中添加另一张银行卡，然后重试。
    2. 致电您的银行，说明您正在授权向 Replit 付款，并请其放行。
    3. 如果您的银行卡限制境外消费，请让银行开通该权限。

    如果仍然扣款失败，请[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="我被扣了两次相同的金额——这是重复收费吗？">
    两笔金额相同的收费不一定是重复扣款。常见原因包括：

    * 订阅费和金额相同的积分包，分别显示为独立的明细项。
    * 一笔失败的付款后来重新尝试并成功。
    * 真正的重复扣款，但这种情况很少见。

    打开**设置 → 账户使用情况**，选择**查看过往账单**，比较两笔收费中的付款意向 ID (`pi_`) ——ID 不同表示它们是独立交易。如果两笔都显示为同一账单中同一项目的已付款项，请[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="我通过 App Store 付款了，但我的额度没有到账——该怎么办？">
    App Store 付款可能需要一点时间才能同步到 Replit。请先尝试以下步骤：

    1. 强制关闭 Replit 应用，然后重新打开。
    2. 退出 Replit 账户后重新登录。
    3. 打开 **设置 → 账户使用情况**，确认积分是否已到账。

    请勿重复购买。如果积分仍未到账，请在 App Store 的**购买历史记录**中找到 Replit 交易，并记下交易 ID。然后[联系 Replit 支持团队](https://replit.com/support)，以便团队为您补发积分。
  </Accordion>
</AccordionGroup>
