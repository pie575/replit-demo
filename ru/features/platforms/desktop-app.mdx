<a href="https://replit.com/desktop" target="_blank">Настольное приложение Replit</a> переносит все возможности Replit на ваш компьютер. Создавайте проекты с Agent в отдельном приложении — с нативными функциями, которых нет во вкладке браузера.

<div id="what-is-the-replit-desktop-app">
  ## Что такое Настольное приложение Replit
</div>

Настольное приложение Replit — это переработанное нативное приложение для Windows и Mac. Оно работает так же, как веб-версия: вы можете создавать приложения, общаться с Agent и публиковать проекты — всё в одном окне. Кроме того, у него есть несколько возможностей, доступных только настольному приложению:

* **Многозадачность**: работайте сразу с несколькими Replit App.
* **Индикаторы состояния**: с одного взгляда понятно, когда Agent ждёт вашего ответа или завершил работу.
* **Предпросмотр вкладок**: заглядывайте в открытые приложения, не переключаясь между ними.

<div id="for-enterprise-teams">
  ## Для команд Enterprise
</div>

Настольное приложение упрощает развёртывание Replit в масштабах организации. Поскольку оно устанавливается так же, как любое другое настольное приложение, ваша ИТ-команда может автоматически распространять и устанавливать его на рабочих компьютерах через поставщика услуг управления устройствами (MDM). Чтобы узнать больше, свяжитесь со своим менеджером по работе с клиентами.
