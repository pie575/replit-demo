---
title: "Сочетания клавиш"
description: "Узнайте, как просматривать, добавлять и изменять сочетания клавиш, которые помогут повысить продуктивность работы в Replit."
---

Сочетания клавиш позволяют выполнять команды, редактировать текст и перемещаться по редактору проекта
с помощью настраиваемых комбинаций клавиш. Задавать и использовать сочетания клавиш
можно в веб-приложении Replit.com.

<div id="visualizando-atalhos-de-teclado">
  ## Просмотр сочетаний клавиш
</div>

Чтобы открыть настройки сочетаний клавиш, выполните следующие шаги:

1. Откройте Replit App, чтобы перейти в редактор проекта.
2. Откройте вкладку <img class="icon-svg" src="/assets/mirror/settings-icon-c2664c3691bf.svg" alt="значок шестерёнки" width="16" height="16" data-path="images/icons/settings-icon.svg" /> **Пользовательские настройки** в разделе <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="значок всех инструментов" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **Все инструменты** на панели.
   Также можно найти «User Settings» через поиск по значку лупы <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="значок лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" />.
3. Перейдите на вкладку **Сочетания клавиш**, чтобы увидеть список команд и назначенных им сочетаний.

<div id="personalizando-atalhos-de-teclado">
  ## Настройка сочетаний клавиш
</div>

Чтобы добавить или изменить сочетание клавиш, выполните следующие действия:

1. Выберите <img class="icon-svg" src="/assets/mirror/create-app-icon-ba218e87fb67.svg" alt="значок плюса" width="16" height="16" data-path="images/icons/create-app-icon.svg" />**Добавить сочетание клавиш** рядом
   с неназначенной командой или значок карандаша <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="значок карандаша" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> для уже назначенных команд.
2. Когда рядом с командой появится надпись «Запись...», нажмите нужное сочетание клавиш.
   Чтобы отменить запись, щёлкните по пустой области внутри вкладки.
3. Чтобы вернуть исходное сочетание, выберите значок отката <img class="icon-svg" src="/assets/mirror/rollback-icon-3197ed1b323b.svg" alt="значок отката" width="12" height="12" data-path="images/icons/rollback-icon.svg" />.

<div id="removendo-atalhos-de-teclado">
  ## Удаление сочетаний клавиш
</div>

Чтобы удалить сочетание клавиш, нажмите значок корзины <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="значок корзины" width="16" height="16" data-path="images/icons/trash-icon.svg" /> рядом с командой.

<div id="navegao-por-tab">
  ## Навигация с помощью Tab
</div>

Для перехода между интерактивными элементами страницы можно использовать навигацию клавишей **Tab** в браузере. Однако инструменты «Редактор файлов», «Консоль» и Shell перехватывают клавишу **Tab** и обрабатывают её как ввод, например для отступов.

Чтобы продолжить перемещение по элементам страницы, находясь в этих инструментах, выполните следующие действия:

1. Нажмите **Esc**, чтобы снять фокус с инструмента
2. Нажмите **Tab**, чтобы перейти к следующему элементу
