---
title: "处理你的数据"
description: "在 My Data 标签页中，使用可视化工具或 SQL 浏览、编辑、导出和查询你的数据库。"
---

**My Data** 标签页用于查看和修改数据库中的内容。打开 **Database** 工具，选择一个数据库，然后选择 **My Data**。你可以使用可视化方式操作，也可以直接执行 SQL。

<Note>
  要编辑生产环境数据，请选择生产数据库，打开 **My Data** 并启用 **Edit**。请务必谨慎：这些是你线上应用的真实数据。
</Note>

<div id="navegar-e-modificar-dados-visualmente">
  ## 可视化浏览和修改数据
</div>

Database 工具内置了 <a href="https://orm.drizzle.team/drizzle-studio/overview" target="_blank">Drizzle Studio</a>，让你能够以可视化方式浏览和修改数据。这类可视化工具可以帮你避免语法错误，并提供以下功能：

* 筛选和排序数据，聚焦特定信息
* 将数据导出为文件，供外部使用
* 插入或修改行数据
* 创建和管理 schema、表、视图和枚举

<div id="executar-comandos-sql">
  ## 执行 SQL 命令
</div>

SQL runner 可让你在数据库中执行 SQL 命令并查看结果。

<Accordion title="如何打开 SQL runner">
  在 **Database** 工具中：

  1. 选择 **My Data** 标签页
  2. 选择 <img class="icon-svg" src="/assets/mirror/sql-runner-icon-b25868882922.svg" alt="SQL runner 图标" width="16" height="16" data-path="images/icons/sql-runner-icon.svg" /> **SQL runner**
</Accordion>

要执行查询，请在文本框中输入 SQL 语句，然后选择旁边的执行按钮 <img class="icon-svg" src="/assets/mirror/sql-play-8ed26b5de7f1.svg" alt="执行 sql 图标" width="18" height="18" data-path="images/icons/sql-play.svg" />：

<Frame>
  <img src="/assets/mirror/sql-runner-run-8ad798a61335.jpg" alt="SQL runner 和执行按钮的截图" width="1390" height="608" data-path="images/databases/sql-runner-run.jpg" />
</Frame>

<Tip>
  你无需自己编写 SQL。只要让 Agent 查询或修改数据，它就会替你编写并执行 SQL。
</Tip>
