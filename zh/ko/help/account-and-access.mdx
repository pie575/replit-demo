本页涵盖账户访问和安全相关内容。有关删除账户的详细信息，请参阅[数据删除](/zh/ko/legal-and-security-info/deleting-your-data)；有关账户停用，请参阅[处罚系统常见问题](/zh/ko/legal-and-security-info/strike-system-faq)。

<AccordionGroup>
  <Accordion title="如何重置密码？">
    1. 前往 [replit.com/forgot](https://replit.com/forgot)。
    2. 输入与你的账户关联的电子邮件地址。
    3. 打开来自 `notifications@replit.com` 的重置邮件；如果没有看到，请检查垃圾邮件文件夹。
    4. 点击链接并设置新密码。

    如果你使用 Google、GitHub、Facebook 或 Apple 注册，也可以在同一页面设置单独的密码。如果未收到邮件，请确认输入的是注册时使用的确切电子邮件地址。
  </Accordion>

  <Accordion title="无法登录——如何恢复账户访问权限？">
    请按顺序尝试：

    1. 在 [replit.com/forgot](https://replit.com/forgot) 重置密码，并检查邮箱的垃圾邮件文件夹。
    2. 如果你是通过 Google、GitHub 或 Apple 注册的，请使用 **[提供商]继续** 按钮，而不是填写电子邮箱和密码。
    3. 确认你使用的是注册时所用的邮箱——你可能用了其他邮箱。

    如果以上方法都无法解决问题，请[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="我似乎可以看到他人的项目，或者有人未经授权访问了我的账户">
    请立即采取以下措施：

    1. 在 [replit.com/forgot](https://replit.com/forgot) 重置密码。
    2. 在账户安全设置中退出其他仍处于登录状态的会话。
    3. 请[联系 Replit 支持团队](https://replit.com/support)，并告知您发现的情况。

    如果您看到不属于自己的项目，可能是登录了其他账户——请检查右上角显示的账户名称。
  </Accordion>

  <Accordion title="如何更改电子邮件地址或用户名？">
    要更改用户名，请在 [CLUI](/zh/ko/features/workspace-tools/clui-graphical-cli) 中运行 `account > change-username` 命令，然后提交新用户名。用户名只能更改一次。

    要更改电子邮件地址，请前往 **设置 → 个人资料** 编辑电子邮件地址。如果无法完成身份验证，请联系 [Replit 支持团队](https://replit.com/support)，并提供当前和新的电子邮件地址。
  </Accordion>

  <Accordion title="如何永久删除我的 Replit 账户？">
    请先下载想保留的内容——删除操作无法撤销。请先在网页版取消现有订阅，然后前往**设置 → 个人资料**申请删除账户。在移动端，请在 Replit 앱 中依次打开**账户 → 更多 → 删除账户**。请参阅[删除数据](/zh/ko/legal-and-security-info/deleting-your-data)。
  </Accordion>

  <Accordion title="我似乎有两个使用同一电子邮件地址的 Replit 账户，该如何解决？">
    当你先通过一种方式 (例如电子邮件) 注册，之后又通过另一种方式 (例如 Google) 登录时，可能会创建第二个账户。

    1. 分别通过这两种方式登录，确认两个账户。
    2. 决定要保留哪个账户。
    3. 复制要关闭账户中的项目——使用**下载为 ZIP**，或将其 Fork。
    4. 在**设置 → 个人资料**中删除不需要的账户。

    如果你不确定哪个账户有订阅或项目，请[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="登录时被重定向到非预期账户">
    您可能有多个账户关联了同一登录提供商。请尝试通过其他方式登录——使用电子邮件和密码，或其他提供商——以访问所需账户。如果您需要确认哪种登录方式对应哪个账户，请提供您的用户名并[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="无法再通过 SSH 连接到 workspace.*.repl.co">
    `workspace.*.repl.co` SSH 主机名已弃用。请在项目中打开 [SSH](/zh/ko/features/workspace-tools/ssh) 窗口，复制当前的连接命令——该命令使用 `*.replit.dev` 地址。请更新引用旧版 `repl.co` 地址的脚本或 SSH 配置。
  </Accordion>

  <Accordion title="账户已被暂停——原因是什么？如何申诉？">
    Replit 会暂停违反服务条款或社区准则的账号；付款争议或拒付也可能触发自动冻结。请先检查说明原因的电子邮件，包括垃圾邮件文件夹。

    如果与付款有关，请在**设置 → 账单**中处理未结清的账单。如果您认为账号被暂停有误，请联系 [Replit 支持团队](https://replit.com/support)，并提供您的用户名、注册邮箱和简要说明。请参阅[处罚系统常见问题](/zh/ko/legal-and-security-info/strike-system-faq)和[信任与安全](/zh/ko/legal-and-security-info/trust-and-safety)。
  </Accordion>

  <Accordion title="无法通过公司网络注册，或工作区无法加载">
    即使你的账户没有问题，企业或学校网络也可能会阻止访问 Replit。常见症状包括注册按钮一直转圈、工作区为空、频繁断开连接，或出现 Cloudflare 的 &quot;Attention Required!&quot; 403 页面。当 SSL/TLS 检查设备、会重写标头的代理或信誉较低的共享出站 IP 等企业安全工具干扰 Replit 所依赖的连接时，就可能出现这些情况。

    首先，确认问题是否由网络引起：

    1. 使用同一浏览器，在其他网络 (例如个人手机热点) 上重试。
    2. 尝试使用无痕模式或隐私窗口，并使用没有受管扩展程序或策略的浏览器。

    如果 Replit 在非公司网络上可以正常运行，但在公司网络上无法运行，请让 IT 团队将 Replit 添加到允许列表。Replit 的 IP 地址会发生变化，因此按域名而非 IP 地址配置允许列表会更稳定。请允许以下域名：

    * `replit.com` 和 `*.replit.com`—主站和静态资源
    * `*.replit.dev`—开发 URL
    * `*.replit.app`—已发布的 App
    * `*.repl.co`—旧版开发 URL
    * `replit-com-static.b-cdn.net`—字体
    * `replitcdn.b-cdn.net`—媒体资源

    Replit 在这些域名上使用持久的 WebSocket 连接、频繁的 API 调用和身份验证令牌交换，因此还请 IT 团队检查以下事项：

    * **SSL/TLS 检查**—为上述域名添加证书检查绕过规则。检查代理可能会在验证 Replit 证书时静默失败，导致页面卡住且不显示明显错误。
    * **标头重写**—会修改、删除或插入 HTTP 标头的代理规则可能会破坏跨域 API 和身份验证调用。
    * **WebSocket 流量**—允许连接到上述域名的 `wss://`。
    * **浏览器策略**—组策略或 MDM 规则如果阻止不在允许列表中的域名保留 Cookie，或阻止第三方 Cookie，可能会妨碍登录。
    * **DNS 解析器**—确认 `replit.com` 和 `*.replit.dev` 主机名能够解析，并与 `8.8.8.8` 或 `1.1.1.1` 等公共解析器进行比较。分割域名 (split-horizon) 或过滤型解析器有时不会为开发 URL 返回记录。

    如果 IT 团队应用这些更改后，Replit 在公司网络上仍然无法使用，请联系 [Replit 支持团队](https://replit.com/support)，并提供你的用户名、显示的确切错误信息或 Cloudflare Ray ID。
  </Accordion>

  <Accordion title="连接器（Stripe、GitHub、Resend）停止工作了——如何重新连接？">
    连接器使用可能过期或被撤销的 OAuth 令牌。要重新连接，请打开 **工具 → 连接器**，断开异常的连接器，然后重新连接并再次进行身份验证。令牌会自动更新到项目的 [Secrets](/zh/ko/core-concepts/project-editor/app-setup/secrets) 中。

    如果重新连接后仍然失败，请确认第三方服务的账户处于有效状态，并且拥有正确的权限。请参阅[管理连接器](/zh/ko/replitai/managing-connectors)和[集成概览](/zh/ko/features/integrations/overview)。
  </Accordion>

  <Accordion title="可以将 Replit 账户转让给其他人吗？">
    账户无法直接转移——账户与创建时使用的凭据绑定。若要转让特定项目，请让新所有者创建账户。共享项目，并请其使用自己的账户创建分叉。若要更改当前账户的电子邮件地址，请前往**设置 → 个人资料**编辑电子邮件地址。订阅无法转移——新所有者需要自行订阅。如需转移企业账户，请[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>
