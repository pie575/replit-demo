export const YouTubeEmbed = ({videoId, title = "Vidéo YouTube", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

<YouTubeEmbed videoId="bAUVQfz_SIY" title="Introducing Replit Agent 4" />

Agent 4 est disponible. Conçu pour la créativité, Agent est un partenaire créatif IA qui transforme vos idées en applications, designs, présentations et bien plus encore, en langage courant. Aucune compétence en programmation n&#39;est requise.

Ce que vous pouvez faire avec Agent 4 :

* **Créer tout ce que vous voulez** : générez des applications web, des applications mobiles, des tableaux de bord de données, des outils basés sur l&#39;IA, et bien plus
* **Concevoir avant de créer** : explorez des maquettes sur le [canvas de design](/fr/learn/projects-and-artifacts/canvas) avant d&#39;écrire la moindre ligne de code
* **Planifier votre projet** : utilisez le [mode Plan](/fr/core-concepts/agent/plan-mode) pour établir votre plan de création avant d&#39;écrire du code
* **Exécuter des tâches en parallèle** : Agent traite plusieurs tâches simultanément pour avancer plus vite
* **Collaborer avec votre équipe** : invitez d&#39;autres personnes dans votre projet et créez ensemble, en simultané
* **Connecter vos outils** : récupérez des données depuis BigQuery, Linear, Slack, Notion et d&#39;autres services directement dans le chat
