<div id="replit-pwa-na-microsoft-app-store">
  ### Microsoft App Store 上的 Replit PWA
</div>

Replit 现已以渐进式 Web 应用 (PWA) 的形式登陆 Microsoft App Store，Windows 上的构建者可以更方便地找到 Replit，并将其作为原生应用安装。

<div id="criao-de-projeto-vazio">
  ### 创建空项目
</div>

现在，您可以在导入页面创建空项目。空项目在初始化时不会启动 Agent，因此创建时不会消耗任何积分，并让您能够完全掌控框架和工具的配置。导入页面为希望拥有这种控制权的构建者提供了此选项。

<div id="portal-de-audit-log-enterprise">
  ### Portal de Audit Log Enterprise
</div>

Portal de Audit Log Enterprise (v1) 现已面向所有 Enterprise 客户开放。管理员可以查看组织成员执行的事件，并配置与所选 SIEM 平台的事件流集成，包括 S3、Datadog、Splunk、Google Cloud Storage 和 Microsoft Sentinel。
