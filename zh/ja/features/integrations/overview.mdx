为帮助你快速将创意变成应用，Agent 支持四类集成：

* **由 Replit 管理**：自动生效的内置集成。创建应用后，Agent 即可直接使用。
* **连接器**：由 Replit 提供支持的第一方集成。只需登录一次，Agent 就能在对话中直接读写这些服务——获取数据、创建记录、发送消息——并在整个应用中加以运用。
* **外部集成**：可用于构建的可信第三方服务。只需让 Agent 完成配置，并提供 API 密钥即可。
* **Agent 服务**：Agent 在后台用于 Build 的付费第三方 API——无需 API 密钥，使用费用将从你的 Replit 积分中扣除。

<Note>
  **套餐可用性**：大多数连接器需要 Core、Pro 或 Enterprise 订阅，部分连接器在免费套餐中也可使用。工作区的连接器目录会显示当前套餐可用的连接器。使用免费套餐的构建者随时可以使用数据库、身份验证等由 Replit 管理的集成。
</Note>

<div id="section">
  ## 开始使用
</div>

要使用集成，只需提及所需的服务或功能即可。例如：

<AiPrompt>
  Create a web app that uses Stripe to accept payments and SendGrid to send confirmation emails
</AiPrompt>

Agent 会自动识别这些关键词，并实现相应的代码和配置。

<div id="agent">
  ### 让 Agent 推荐连接器
</div>

保存文件、发送邮件等场景中，往往有多个服务都能胜任同样的工作。如果你在请求某项功能时没有指定提供商，Agent 会列出一份简短的适用连接器清单，你从中选择想用的即可。

选定提供商后，只需登录一次即可连接账户。Agent 在构建应用时会沿用你的选择。你也可以直接指定具体服务的名称，跳过清单选择这一步。

<div id="replitoauth">
  ### 在 Replit 中配置 OAuth 应用
</div>

<Note>
  **仅限 Enterprise**：配置自定义 OAuth 应用需要 Enterprise 订阅。
</Note>

在 Enterprise 方案下，你可以为连接器使用自己的 OAuth 应用，而不必使用 Replit 的默认应用。这样，OAuth 客户端归你的组织所有，授权同意页面可展示自有品牌形象，你也能精确控制构建者可以请求哪些作用域。

要使用自己的 OAuth 应用配置连接器，你需要从提供商获取三项内容：**客户端 ID**、**客户端密钥**，以及要授权的 **作用域**。此外，还需在提供商处注册 Replit 的回调 URL，才能顺利完成身份验证。

<Frame>
  <img src="/assets/mirror/connector-oauth-configuration-100911ce0c48.png" alt="连接器 OAuth 配置对话框，包含客户端 ID、客户端密钥、连接器作用域字段，以及设置为 https://replit.com/connectors/oauth/callback 的重定向 URL" width="1112" height="1218" data-path="images/replitai/connector-oauth-configuration.png" />
</Frame>

<Steps>
  <Step title="在提供商处创建 OAuth 应用">
    登录提供商的开发者控制台或管理设置，创建一个新的 OAuth 2.0 应用。不同提供商对这一步的叫法不同——请查找**创建 OAuth 应用**、**注册应用**、**创建客户端凭据**等选项。
  </Step>

  <Step title="设置重定向 URL">
    如果提供商要求填写**已授权的重定向 URI** (有时称为**回调 URL** 或**重定向 URL**) ，请输入以下内容：

    ```
    https://replit.com/connectors/oauth/callback
    ```

    该 URL 是提供商在构建者授权应用后将其跳转回 Replit 的地址。它必须完全一致，包括末尾的斜杠、协议和子域名。如果要添加多个重定向 URI，其中必须包含此 URL。
  </Step>

  <Step title="复制客户端 ID 和客户端密钥">
    创建应用后，提供商会显示**客户端 ID** 和**客户端密钥**。

    * **客户端 ID**：OAuth 应用的公开标识符，可以安全地出现在 URL 或客户端代码中。
    * **客户端密钥**：用于证明请求来自你的应用的机密值。请像对待密码一样对待它——不要提交到代码仓库，也不要公开。Replit 会代你安全保管。

    某些提供商只在创建时显示一次客户端密钥。请立即复制，并妥善保存在安全位置，直到粘贴到 Replit 中。
  </Step>

  <Step title="选择作用域">
    **作用域**是一种权限，用于定义 OAuth 应用可代表构建者读取或写入哪些内容。每个提供商都会在其 API 文档中公布各自的作用域列表。

    在 Replit 中配置连接器时输入的作用域，必须与你在提供商处注册的作用域**完全一致** (逐字符一致，包括 URL 前缀) 。导致不匹配错误的常见原因：

    * 缺少完整的 URL 前缀 (例如 `https://www.googleapis.com/auth/drive.file` 与 `drive.file`) 。
    * 多余的空格或末尾的逗号。
    * 在 Replit 中请求了提供商应用中未启用的作用域。

    请从构建者所需的最小作用域集开始，之后再按需添加——大多数提供商都支持在不重新创建应用的情况下更新作用域。
  </Step>

  <Step title="在 Replit 中配置连接器">
    在组织的 **连接器** 页面选择**添加新集成**，选择服务，然后粘贴提供商提供的**客户端 ID**、**客户端密钥**和**作用域**。选择**配置**进行保存。
  </Step>
</Steps>

<Note>
  如果配置后身份验证失败，请确认提供商处的重定向 URL 与 `https://replit.com/connectors/oauth/callback` 完全一致，并检查你在 Replit 中输入的所有作用域是否也已在提供商的应用中获得授权。
</Note>
