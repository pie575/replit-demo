# 개인 & 팀 워크스페이스

> 개인 워크스페이스와 팀 워크스페이스의 차이를 이해하고, 팀 워크스페이스를 만들고, 멤버를 초대하여 함께 빌드하세요.

## 개인 워크스페이스와 팀 워크스페이스

**워크스페이스**는 여러분의 앱, 멤버, 설정, 청구 정보를 담는 구조입니다. Replit에는 두 가지 유형이 있습니다.

* 개인 워크스페이스
* 팀 워크스페이스

아래는 개인 워크스페이스와 팀 워크스페이스의 차이입니다.

|           | 개인 워크스페이스          | 팀 워크스페이스                    |
| --------- | ------------------ | --------------------------- |
| **역할**    | Admin, 프로젝트 단위 게스트 | Admin, Members, 프로젝트 단위 게스트 |
| **접근 모델** | 개별 프로젝트에 게스트를 초대함  | 멤버가 워크스페이스의 모든 프로젝트에 접근함    |
| **청구**    | 여러분의 계정            | Admin 계정의 통합 크레딧            |
| **멤버 관리** | 프로젝트별(초대 링크)       | 워크스페이스 Settings에서 중앙 관리     |

**개인 워크스페이스**는 혼자 작업하거나 다른 사람과 개별 프로젝트를 공유할 때 가장 적합합니다. 여러분이 유일한 Admin이며, 다른 사람은 프로젝트 단위 게스트로 초대한 특정 프로젝트에만 접근할 수 있습니다.

**팀 워크스페이스**는 정기적인 그룹과 함께 빌드할 때 가장 적합합니다 — 스타트업 팀, 수업, 여러 기여자가 있는 클라이언트 프로젝트 등입니다. 멤버는 워크스페이스의 모든 프로젝트에 접근할 수 있으므로, 각 프로젝트마다 일일이 초대할 필요가 없습니다. 멤버는 **Settings**에서 중앙 관리됩니다.

### 워크스페이스에 초대할지 프로젝트에 초대할지

| 상황                       | 해야 할 일                                 |
| ------------------------ | -------------------------------------- |
| 모든 것에 접근이 필요한 지속적인 협업자   | 워크스페이스에 초대                             |
| 하나의 프로젝트만 필요한 계약자 또는 게스트 | [프로젝트에 초대](/ko/build/invite-teammates) |
| 회사에 합류하는 새 팀원            | 워크스페이스에 초대                             |
| 특정 앱의 디버깅을 돕는 친구         | [프로젝트에 초대](/ko/build/invite-teammates) |

## 팀 워크스페이스 만들기

<Frame>
  <img src="https://mintcdn.com/replit/7ERBfdpI-Q6cFy9l/images/workspace/create-team-workspace.png?fit=max&auto=format&n=7ERBfdpI-Q6cFy9l&q=85&s=b84bb952bbe5f9e55bf8e51cac7d758a" alt="일반적인 워크스페이스 이름과 팀원을 초대하기 위한 빈 필드가 있는 새 워크스페이스 만들기 양식" width="784" height="300" data-path="images/workspace/create-team-workspace.png" />
</Frame>

<Steps>
  <Step title="워크스페이스 전환기 열기">
    홈페이지에서 왼쪽 상단의 워크스페이스 이름을 클릭하세요.
  </Step>

  <Step title="새 워크스페이스 만들기">
    **Create workspace**를 선택하고 팀 워크스페이스의 이름을 정하세요.
  </Step>

  <Step title="멤버 초대하기">
    초대 필드에 하나 이상의 이메일 주소를 쉼표로 구분하여 입력하세요. 초대받은 사람은 초대장을 받고, 수락하면 워크스페이스의 모든 프로젝트에 접근할 수 있게 됩니다.
  </Step>
</Steps>

## 멤버 관리하기

설정 중에 멤버를 초대하지 않았거나 나중에 더 추가해야 한다면, 팀 워크스페이스의 **Settings > Workspace collaborators**로 이동하여 이메일 또는 Replit 사용자 이름으로 멤버를 초대하세요.

<Frame>
  <img src="https://mintcdn.com/replit/7ERBfdpI-Q6cFy9l/images/workspace/invite-workspace-members.jpg?fit=max&auto=format&n=7ERBfdpI-Q6cFy9l&q=85&s=b9e06b5b4a23458573fc625844071676" alt="이메일 주소를 입력할 빈 필드가 있는 사용자 초대 대화상자" width="510" height="244" data-path="images/workspace/invite-workspace-members.jpg" />
</Frame>

**Settings** 페이지에서 다음도 할 수 있습니다.

* **멤버 제거**로 워크스페이스의 모든 프로젝트에 대한 접근 권한을 취소
* 개인 워크스페이스에서 팀 워크스페이스로 **앱 이전** — [팀으로 앱 이전하기](/ko/teams/identity-and-access-management/transfer-app-to-teams) 참고

  <Warning>
    워크스페이스 간 프로젝트 이전은 일시적으로 비활성화되어 있습니다. 지금은 새 이전을 시작할 수 없습니다.
  </Warning>

고급 자격 증명 관리, 역할 기반 접근, 그룹 권한에 대해서는 [Pro 및 Enterprise](/ko/category/teams)를 참고하세요.
