<div id="o-que-ssh">
  ## Что такое SSH?
</div>

SSH (Secure Shell) — защищённый протокол, который предоставляет удалённый доступ к интерфейсу командной строки вашего Replit App. С помощью SSH можно легко передавать файлы и использовать предпочитаемую локальную IDE для редактирования кода в Replit, повышая эффективность совместной работы и продуктивность разработки.

Функция SSH доступна на тарифах Core, Pro и всех других платных тарифах.

Вот как это работает:

* Создайте пару SSH-ключей на локальной машине
* Добавьте SSH-ключ на панель **SSH** в любом Replit App
* Подключитесь с помощью SSH-клиента или редактора, работающего через SSH (например, [VSCode](https://code.visualstudio.com/) или [Cursor](https://www.cursor.com/))

<Note>
  SSH-ключи связаны с вашей учётной записью, а не с конкретным Replit App. Поэтому достаточно один раз добавить открытый ключ, после чего вы сможете подключаться к любому Replit App, к которому у вас есть доступ.
</Note>

<div id="por-que-usar-ssh">
  ## Зачем использовать SSH?
</div>

* **Автоматическая синхронизация между Replit App и редактором**: Любые изменения, внесённые в Replit App, мгновенно отображаются в вашем редакторе, а изменения, внесённые в редакторе, синхронизируются с Replit App. Благодаря такой синхронизации ваша кодовая база всегда остаётся актуальной на всех платформах.

* **Синхронизация файловых операций**: При добавлении, удалении или обновлении файлов изменения синхронизируются в реальном времени между вашим редактором и Replit App. Это гарантирует, что структура проекта остаётся согласованной независимо от того, где были внесены изменения.

* **Управление папками и перемещение файлов**: Перемещение файлов между папками также синхронизируется между редактором и Replit App. Благодаря этому изменения в организации файлов, внесённые в одной среде, точно отражаются в другой, сохраняя целостность и структуру проекта.

<div id="encontrar-ou-criar-um-par-de-chaves">
  ## Найдите или создайте пару ключей
</div>

Чтобы настроить SSH для своей учётной записи, вам понадобится открытый SSH-ключ.

<div id="verificar-se-voc-j-tem-um-par-de-chaves">
  ### Проверьте, есть ли у вас пара ключей
</div>

Чтобы проверить наличие открытого ключа, выполните следующую команду в терминале на локальной машине:

<Tabs>
  <Tab title="Mac/Linux">
    ```sh theme={null}
    ls -l ~/.ssh
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    dir %HOMEPATH%\.ssh
    ```
  </Tab>
</Tabs>

Если появится ошибка, ничего страшного — перейдите к разделу [Создание новой пары ключей](#generating-a-new-keypair).
Если вы увидите файл `replit.pub`, перейдите к разделу [Получение содержимого открытого ключа](#get-the-contents-of-your-public-key).

<div id="gerando-um-novo-par-de-chaves">
  ### Создание новой пары ключей
</div>

На своём компьютере откройте окно терминала (или командной строки) и вставьте следующую команду:

<Tabs>
  <Tab title="Mac/Linux">
    ```bash theme={null}
    ssh-keygen -t ed25519 -f ~/.ssh/replit -q -N ""
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    ssh-keygen -t ed25519 -f %HOMEPATH%\.ssh\replit -q -N ""
    ```
  </Tab>
</Tabs>

Эта команда проверяет, существует ли уже указанный файл открытого SSH-ключа. Если нет, она создаёт новый SSH-ключ с подходящими параметрами.

<div id="obter-o-contedo-da-sua-chave-pblica">
  ### Просмотр содержимого открытого ключа
</div>

Убедитесь, что у вас есть пара ключей, или создайте её, затем выведите содержимое открытого ключа (одного из двух файлов с похожими именами и суффиксом `.pub`) — оно понадобится позже.

<Tabs>
  <Tab title="Mac/Linux">
    ```sh theme={null}
    cat ~/.ssh/replit.pub
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    notepad %HOMEPATH%\.ssh\replit.pub
    ```
  </Tab>
</Tabs>

Сохраните содержимое `replit.pub`, чтобы использовать его далее в этой статье, и перейдите к разделу [добавления SSH-ключа в учётную запись](#add-the-ssh-key-to-your-account).

<div id="adicionar-a-chave-ssh-sua-conta">
  ## Добавьте SSH-ключ в свою учётную запись
</div>

<div id="adicionar-a-chave-pblica-diretamente-em-um-replit-app-usando-o-painel-ssh">
  ### Добавьте открытый ключ напрямую в Replit App через панель SSH
</div>

1. В любом окне Replit App нажмите кнопку **+** и найдите **SSH**.

<Frame>
  <img src="/assets/mirror/ssh-tool-2db02c6a83d0.png" alt="Кнопка инструмента SSH в интерфейсе Replit" width="846" height="328" data-path="images/ssh-vscode/ssh-tool.png" />
</Frame>

2. Перейдите на вкладку **Keys** и выберите **New SSH key**.
3. Во всплывающем окне укажите **Label** для ключа (например, my-ssh-key) и вставьте скопированный открытый ключ в поле **Key**.
   Нажмите кнопку **Add SSH Key**. Ключ будет добавлен и авторизован для использования.

<Frame>
  <img src="/assets/mirror/add-ssh-key-with-values-5d6f440e56ba.png" alt="Диалог добавления SSH-ключа с заполненными полями метки и ключа" width="500" height="511" data-path="images/ssh-vscode/add-ssh-key-with-values.png" />
</Frame>

<div id="adicionar-a-chave-pblica-diretamente-nas-configuraes">
  ### Добавление открытого ключа непосредственно в настройках
</div>

Вы также можете добавить SSH-ключ: откройте **Настройки**, в разделе **Учётная запись** выберите **Дополнительно** (или **SSH-ключи**). Затем выберите **Добавить SSH-ключ** и вставьте содержимое файла `replit.pub` из предыдущего раздела [Поиск или создание пары ключей](#find-or-create-a-keypair).

<Note>
  Если на вашем компьютере несколько открытых ключей, убедитесь, что для конфигурации SSH используется правильная пара закрытого и открытого ключей.
</Note>

<div id="conectando-ao-seu-replit-app">
  ## Подключение к вашему Replit App
</div>

<div id="configure-seu-ssh-config">
  ### Настройте конфигурацию SSH
</div>

1. В терминале убедитесь, что существуют каталог `~/.ssh` и файл `~/.ssh/config`:

<Tabs>
  <Tab title="Mac/Linux">
    ```sh theme={null}
    mkdir -p ~/.ssh && chmod 700 ~/.ssh && touch ~/.ssh/config && chmod 600 ~/.ssh/config
    open -a 'TextEdit' ~/.ssh/config || nano ~/.ssh/config
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    if not exist %HOMEPATH%\.ssh mkdir %HOMEPATH%\.ssh && type \NUL > %HOMEPATH%\.ssh\config
    notepad %HOMEPATH%\.ssh\config
    ```
  </Tab>
</Tabs>

2. Добавьте блок конфигурации, чтобы использовать пару ключей `replit` для всех доменов *.replit.dev:

<Tabs>
  <Tab title="Mac/Linux/Windows">
    ```
    Host *.replit.dev
        Port 22
        IdentityFile ~/.ssh/replit
        StrictHostKeyChecking accept-new
    ```
  </Tab>
</Tabs>

<div id="conectar-pelo-vscode-ou-cursor">
  ### Подключение через VS Code или Cursor
</div>

1. В Replit App откройте панель **SSH**.

2. На панели SSH перейдите на вкладку **Connect** и выберите **Launch VS Code**.

<Tabs>
  <Tab title="Подключение через VS Code">
    <img src="/assets/mirror/ssh-connect-439a3c150846.png" alt="Вкладка SSH Connect с параметром Launch VS Code" width="788" height="482" data-path="images/ssh-vscode/ssh-connect.png" />
  </Tab>
</Tabs>

3. Если появится запрос на добавление записи в `~/.ssh/config`, вставьте следующее:

   ```
   Host *.replit.dev
       Port 22
       IdentityFile ~/.ssh/replit
       StrictHostKeyChecking accept-new
   ```

   <Note>
     Добавить конфигурацию SSH предлагается только при первой попытке подключиться к VS Code или другому редактору. Чтобы вернуться к файлу конфигурации, выберите **Configure SSH Hosts...**.
   </Note>

4. Если появится предупреждение о внешнем приложении, выберите **Да**, чтобы подтвердить открытие проекта в предпочитаемом редакторе или VS Code.

5. Периодически может появляться запрос на установку или обновление расширений SSH. Replit стремится поддерживать совместимость с последними версиями этих IDE, а также может выпускать важные обновления безопасности.

<div id="conectar-manualmente">
  ### Подключение вручную
</div>

В нижней части вкладки &quot;Connect&quot; панели **SSH** вы найдёте пункт &quot;Connect manually&quot;.

Скопируйте эту команду и вставьте её в локальный терминал (Mac или Linux) или командную строку на компьютере с Windows, чтобы подключиться напрямую.

Это также удобный способ диагностировать проблемы с подключением к IDE и собрать ценную подробную информацию о подключении при отправке сообщений об ошибках в поддержку Replit.

<div id="conectar-via-ferramenta-no-listada-aqui">
  ### Подключение с помощью инструмента, которого нет в списке
</div>

Для разных платформ и операционных систем доступно множество SSH-клиентов с различными функциями и интеграциями.

Вы всегда можете разбить команду из раздела &quot;Connect Manually&quot; на составляющие, чтобы понять, как настроить нужный клиент:

```sh theme={null}
ssh -i ~/.ssh/replit -p 22  c96b6ade-d5e4-4f7a-bc5b-52334509b2a3@c96b6ade-d5e4-4f7a-bc5b-52334509b2a3-00-16nh2hskw3ql8.riker.replit.dev
       ^-----v-----^    ^^  ^-----------------v----------------^ ^------------------------------v-------------------------------------^
        Private Key   Port                   User               @                           Hostname
```

**Имя хоста**: `<your_hostname>.<cluster>.replit.dev`
**Порт**: `<port_number>`
**Пользователь**: `Username`
**Закрытый ключ**: Путь к файлу закрытого ключа на вашей машине. Обычно он находится рядом с `replit.pub`.
