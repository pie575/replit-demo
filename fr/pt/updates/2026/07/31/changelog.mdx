<div id="o-replit-design-est-no-ar">
  ### Replit Design est disponible
</div>

Replit Design est désormais disponible. Décrivez ce que vous souhaitez créer, explorez des maquettes interactives et affinez votre idée. Lorsqu’une frame est prête, les utilisateurs Core et Pro peuvent la transformer en app fonctionnelle dans le même projet.

<div id="agent">
  ## Agent
</div>

<div id="escolha-o-modelo-principal-do-agent">
  ### Choisissez le modèle principal d’Agent
</div>

Vous pouvez désormais choisir le modèle principal qu’Agent utilise pour une tâche. Sélectionnez Lite, Economy ou Power, puis choisissez parmi les modèles disponibles pour ce mode. Lite est désormais disponible partout où vous pouvez utiliser Agent, y compris dans les applications mobiles. Les modèles disponibles varient selon votre organisation, vos autorisations et votre accès à Turbo.

</Frame>

En savoir plus sur le [sélecteur de modèle](/fr/pt/features/agent/model-selector).

<div id="conecte-mais-servidores-mcp">
  ### Connectez davantage de serveurs MCP
</div>

Les workspaces éligibles peuvent se connecter à Supabase, Statsig et Calendly depuis le catalogue de serveurs MCP préconfigurés. Replit reconnaît également le point de terminaison MCP officiel de Braintrust et lance le flux de connexion OAuth lorsque vous l’ajoutez manuellement.

  ## Teams et Enterprise
</div>

<div id="continue-conectado-por-mais-tempo">
  ### Restez connecté plus longtemps
</div>

Les sessions Replit durent désormais plus longtemps avant de vous demander de vous reconnecter. Les administrateurs Enterprise peuvent configurer des durées d’expiration de session prédéfinies.
