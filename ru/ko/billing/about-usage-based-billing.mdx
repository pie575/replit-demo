Для публикаций предусмотрены три типа тарификации на основе Usage:

1. Исходящая передача данных
2. Вычислительные единицы Autoscale
3. Запросы

Использование можно проверить в разделе **Настройки** → **Учётная запись** → **Usage**. Счёт выставляется ежемесячно или при превышении накопленными расходами месячного объёма кредитов. Пользователи Replit Core и Pro получают ежемесячные лимиты на эти ресурсы.

Если вам нужны дополнительные кредиты сверх ежемесячного лимита подписки, вы можете приобрести пакет кредитов на странице оплаты. Подробнее о пакетах кредитов см. в разделе [Управление расходами](/ru/ko/billing/managing-spend).

<div id="section">
  # Публикация
</div>

<div id="1">
  ## 1. Исходящая передача данных при публикации
</div>

Этот тип Usage тарифицируется по объёму переданных байтов, а пользователи Replit Core и Pro получают ежемесячный лимит. В этот лимит засчитывается только исходящий трафик; при его превышении может взиматься дополнительная плата. Входящий трафик, напротив, всегда бесплатен.

| Подписка    | Лимит                                                   |
| ----------- | ------------------------------------------------------- |
| Replit Core | 100 GiB                                                 |
| Replit Pro  | См. [тарифы Replit Pro](https://www.replit.com/pricing) |

Лимит распространяется на [статические](/ru/ko/features/publishing/deployment-types#static), [Autoscale](/ru/ko/features/publishing/deployment-types#autoscale), [Reserved VM](/ru/ko/features/publishing/deployment-types#reserved-vm) и [запланированные](/ru/ko/features/publishing/deployment-types#scheduled) деплои.

Актуальные тарифы на исходящую передачу данных см. на [странице тарифов](https://www.replit.com/pricing).

***

<div id="2">
  ## 2. Вычислительные единицы
</div>

Autoscale-деплои тарифицируются на основе вычислительных единиц, учитывающих использование CPU и RAM с течением времени.

Превышение лимита тарифицируется в вычислительных единицах. Тарификация рассчитывается с точностью до отдельных вычислительных единиц. Актуальные цены на вычислительные единицы указаны на [странице тарифов](https://www.replit.com/pricing).

Ниже показано, как секунды использования RAM и CPU для Autoscale-деплоев преобразуются в вычислительные единицы:

| Ресурс        | Вычислительные единицы |
| ------------- | ---------------------- |
| 1 секунда RAM | 2 единицы              |
| 1 секунда CPU | 18 единиц              |

Статические деплои не потребляют вычислительные единицы. Плата взимается только за исходящую передачу данных сверх [указанного объёма](#).

[Подробнее об Autoscale-деплоях](/ru/ko/features/publishing/deployment-types#autoscale).

<div id="3">
  ## 3. Запросы
</div>

Autoscale-деплой также учитывает количество обработанных запросов.

Актуальные тарифы на запросы указаны на [странице с ценами](https://www.replit.com/pricing).

<div id="section-2">
  # Базы данных
</div>

Replit взимает плату только за использование [продакшен-баз данных](/ru/ko/features/data-and-storage/development-and-production). Базы данных для разработки всегда бесплатны и доступны во всех Replit App. Подробнее см. в разделе [Базы данных для разработки](/ru/ko/features/data-and-storage/sql-database).

Replit PostgreSQL — полностью управляемая бессерверная база данных, обеспечивающая высокую доступность и не требующая обслуживания. Плата за продакшен-базы данных рассчитывается на основе фактического потребления, что позволяет существенно сократить расходы.

Плата за продакшен-базы данных PostgreSQL взимается по двум показателям использования:

* **[Время вычислений](#compute-time)**: объём вычислительных ресурсов, потреблённых за час.
* **[Хранение данных](#data-storage)**: общий объём хранимых данных, включая исторические.

Текущее потребление ресурсов, включая Usage продакшен-баз данных, можно просмотреть в **Настройки** → **Учётная запись** → **Usage**.

<div id="section-3">
  ## Время вычислений
</div>

Время вычислений определяется тем, как долго база данных остаётся активной в течение расчётного периода. База данных считается активной при получении запроса и ещё 5 минут после последнего запроса. Если база данных не получает запросов в течение 5 минут, она приостанавливается и становится неактивной.

<div id="section-4">
  ## Хранилище данных
</div>

Хранилище данных — это общий объём данных, хранящихся во всех базах данных вашей учётной записи, измеряемый в гибибайтах (GiB). Его объём рассчитывается по максимальному объёму использованного хранилища за месяц. Каждая база данных PostgreSQL занимает 33 МБ хранилища, даже если не содержит данных. Это базовое пространство, необходимое серверу Postgres.

<Note>Общий лимит хранилища для каждой продакшен-базы данных составляет 10 гибибайтов (GiB). Для баз данных для разработки предоставляется 20 GiB бесплатного хранилища на каждое Replit App.</Note>
