<div id="azure-marketplace">
  ### Azure Marketplace 集成
</div>

Replit 现已上架 Azure Marketplace！许多组织已经为 Azure 设立了专项预算，借助此集成，这些预算可直接用于 Replit 的订阅与使用。

继 9 月推出 GCP Marketplace 集成之后，此次新增让企业版团队能够沿用现有的云采购流程和预算，更轻松地引入 Replit。

[在 Azure Marketplace 中查看](https://marketplace.microsoft.com/en-us/product/saas/replit.replit?tab=Overview)

<div id="gitlab-bitbucket">
  ### GitLab 和 Bitbucket 支持
</div>

除 GitHub 之外，Replit 现已支持 GitLab 和 Bitbucket 仓库，让你在代码存放位置上有了更大的灵活性。你可以将项目从 GitLab 和 Bitbucket 直接导入 Replit，并在所有受支持的平台上使用增强的 git 功能。

增强的 git 集成包括：

* **多平台支持**：导入并操作 GitHub、GitLab 和 Bitbucket 上的仓库
* **更强的 git 操作**：在整个 workspace 中提供更快、更稳定的 git 命令
* **更完善的仓库管理**：在所有受支持的 git 提供商上简化克隆、推送和拉取的工作流

进一步了解[导入项目](/zh/references/workspace/import)以及[在 Replit 中使用 git](/zh/references/version-control/git-interface)。
