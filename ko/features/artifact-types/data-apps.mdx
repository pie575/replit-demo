<div id="what-is-a-data-visualization">
  ## 데이터 시각화란?
</div>

데이터 시각화는 Agent와의 대화를 통해 만드는 인터랙티브 dashboard 또는 리포팅 도구입니다. 무엇을 시각화할지, 데이터가 어디에 있는지 설명하기만 하면 Agent가 알맞은 KPI, charts 유형, layouts을 자동으로 선택해 prompt 한 번으로 완성도 높은 dashboard를 생성합니다.

핵심 개념:

* **한 번에 생성**: 목표와 데이터 소스를 설명하면 Agent가 알맞은 charts와 지표를 갖춘 완성된 dashboard를 만들어 줍니다
* **연결된 데이터 소스**: database, [warehouse connectors](/ko/connectors/warehouses/overview), 외부 API, 업로드한 파일에서 데이터를 pull할 수 있습니다
* **기본 제공 기능**: 모든 dashboard에 새로 고침, 자동 새로 고침, PDF로 내보내기, charts를 CSV로 내보내기, 라이트/다크 모드가 기본으로 포함됩니다
* **분석 요약**: Agent가 요청 내용과 결과 데이터를 바탕으로 인사이트를 도출합니다
* **여러 artifacts**: 데이터 시각화는 [같은 project](/ko/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project) 내 다른 artifacts와 backend 및 database를 공유할 수 있습니다

<div id="how-to-use-data-visualization">
  ## Data Visualization 사용 방법
</div>

<div id="creating-from-a-prompt">
  ### 프롬프트로 만들기
</div>

홈페이지에서 **App** 탭을 선택한 뒤 원하는 대시보드를 설명하세요. Agent가 데이터 관련 프롬프트를 인식해 Data Visualization 스택을 선택합니다.

**프롬프트 예시:**

* &quot;지역별 매출을 추적하는 영업 분석 대시보드를 만들어줘&quot;
* &quot;월간 지표를 시각화하는 리포팅 도구를 만들어줘&quot;
* &quot;BigQuery 판매 데이터를 기반으로 실적이 가장 좋은 제품을 보여주는 대시보드를 만들어줘&quot;
* &quot;Snowflake에 연결해서 고객 이탈 분석 대시보드를 만들어줘&quot;

<div id="creating-from-the-dropdown">
  ### 드롭다운에서 만들기
</div>

1. 홈페이지에서 **App** 탭으로 이동합니다.
2. 앱 유형 드롭다운을 엽니다.
3. **Data Visualization**을 선택합니다.
4. 만들려는 대시보드 또는 데이터 도구를 설명합니다.

<div id="connecting-to-data-warehouses">
  ### 데이터 웨어하우스에 연결하기
</div>

[warehouse connectors](/ko/connectors/warehouses/overview)를 사용해 데이터 시각화를 BigQuery, Databricks 또는 Snowflake에 연결하면 기존 dataset을 기반으로 dashboard를 만들 수 있습니다.

웨어하우스 데이터를 쿼리하면 Agent가 병렬 멀티 에이전트 검색으로 schema와 dataset을 탐색합니다. 덕분에 탐색 속도가 빨라지고, Agent가 dashboard에 적합한 테이블과 필드를 더 정확하게 선택할 수 있습니다.

시작하려면 project의 [Integrations](/ko/features/integrations/overview)에서 warehouse connector를 설정한 다음, 시각화하려는 내용을 Agent에게 알려주세요.

<div id="adding-filters-and-features">
  ### 필터 및 기능 추가하기
</div>

Agent가 대시보드를 만든 후에는 프롬프트로 필터, 드릴다운 등 다양한 인터랙티브 기능을 추가하도록 요청할 수 있습니다. 예를 들어 Agent에게 날짜 범위 필터, 지역 선택기, 검색창을 추가해 달라고 요청해 보세요.

<div id="exporting-and-sharing">
  ### 내보내기 및 공유
</div>

* **PDF로 내보내기**: 대시보드 전체를 PDF로 내보내 공유하거나 오프라인에서 검토할 수 있습니다.
* **차트를 CSV로 내보내기**: 개별 차트 데이터를 CSV 파일로 다운로드하여 스프레드시트나 다른 도구에서 추가 분석에 활용할 수 있습니다.
* **분석 문서**: Agent에게 대시보드 데이터를 기반으로 상세한 분석 문서를 작성해 달라고 요청하세요.

<div id="what-you-can-build">
  ## 무엇을 만들 수 있나요
</div>

* **Analytics dashboard**: 기간별 revenue, 가입자 수, 참여도 등 핵심 지표를 추적합니다
* **리포팅 도구**: 이해관계자가 database에 직접 접근하지 않고도 filter하고 살펴볼 수 있는 내부 보고서를 만듭니다
* **데이터 탐색 인터페이스**: 시각적 feedback을 보면서 dataset을 둘러보고 쿼리합니다
* **Monitoring 패널**: API, database, 외부 서비스의 실시간 또는 준실시간 데이터를 표시합니다

<div id="frequently-asked-questions">
  ## 자주 묻는 질문
</div>

<Accordion title="어떤 데이터 소스를 연결할 수 있나요?">
  project의 Replit Database, warehouse connectors(BigQuery, Databricks, Snowflake), 외부 API, CSV 같은 업로드 파일에서 데이터를 가져올 수 있습니다. warehouse 연결은 [Integrations](/ko/features/integrations/overview)에서 설정하세요.
</Accordion>

<Accordion title="디자인과 스타일을 원하는 대로 바꿀 수 있나요?">
  네. 대화를 통해 색상, layout, 타이포그래피를 원하는 대로 조정할 수 있습니다. Agent에게 브랜드에 맞춰 달라거나 디자인을 수정해 달라고 요청하세요. dashboard는 라이트 모드와 다크 모드도 지원합니다.
</Accordion>

<Accordion title="Agent가 데이터를 대신 분석해 주나요?">
  dashboard를 만들고 나면 Agent가 요청 내용과 결과 데이터를 바탕으로 분석 요약을 생성합니다. 더 자세한 분석 문서를 요청할 수도 있습니다.
</Accordion>

<Accordion title="데이터 시각화를 다른 artifact 유형과 함께 사용할 수 있나요?">
  네. [같은 project](/ko/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project) 안에서 데이터 시각화를 [web app](/ko/features/artifact-types/web-apps), [slide deck](/ko/features/artifact-types/slide-decks) 등 다른 artifact 유형과 함께 사용할 수 있습니다. 이들은 동일한 backend와 database를 공유합니다.
</Accordion>
