<div id="documentao-replitmd">
  ### replit.md 文档
</div>

使用 `replit.md` 自定义 Agent 的行为——这是一个特殊的配置文件，可帮助 Agent 了解你的偏好、编码风格和项目架构。Agent 会依据经过验证的最佳实践自动创建该文件，并据此构建完全符合你要求的应用。在这一个文件中，你就能为 Agent 提供项目背景、设定编码规范、指定首选技术栈并定义沟通偏好。
