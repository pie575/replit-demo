<div id="agent-mcp">
  ### Agent 现已支持自定义 MCP 服务器
</div>

Agent 现在可以连接到远程 Model Context Protocol (MCP) 服务器，只需极少的配置即可使用全新的功能和工具。借此，Agent 能够调用外部工具，并从远程系统获取上下文。

通过自定义 MCP 服务器，你可以：

* 连接到远程服务器，从外部工具获取上下文并执行操作
* 通过 MCP 开放标准访问数百种工具和数据源
* 自动加载各服务器提供的工具

合作伙伴只需开放 MCP 服务器，即可将自身服务与 Agent 集成，无需额外的集成开发工作。

<div id="enterprise-plaid">
  ### 面向 Enterprise 的 Plaid 连接器
</div>

Enterprise 客户现在可以启用 Plaid 连接器，连接银行账户，并借助金融科技基础能力构建应用。该连接器仍在积极开发中，我们会根据客户反馈持续推出新功能和改进。

借助 Plaid 连接器，你可以：

* 将银行账户接入你的应用
* 使用金融科技基础能力构建金融功能
* 通过管理员仪表板集中管理连接器
