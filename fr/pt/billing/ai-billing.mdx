Les fonctionnalités d’IA de Replit reposent sur une facturation à l’usage, en fonction de ce que vous créez et de votre utilisation de nos outils d’IA. Vous ne payez ainsi que pour la valeur que vous apporte Agent.

<div id="primeiros-passos">
  ## Premiers pas
</div>

**Tous les abonnés** bénéficient de checkpoints Agent gratuits, valables une seule fois.

Des crédits mensuels supplémentaires sont automatiquement appliqués à l’utilisation de l’IA :

* **Abonnés Core** : crédits mensuels (voir les [tarifs](https://replit.com/pricing))
* **Abonnés Pro** : crédits mensuels progressifs, reportables pendant {ProCreditRolloverPeriod}. Voir [Replit Pro](/fr/pt/billing/plans/replit-pro).

Ces crédits couvrent Agent et d’autres services cloud de Replit, tels que les applications publiées, le stockage et les bases de données. Choisissez [Lite, Economy ou Power](/fr/pt/features/agent/agent-modes) pour optimiser Agent selon la vitesse, le coût ou la capacité.

  ## Facturation de l’Agent
</div>

Free Mode permet aux abonnés Core et Pro d’effectuer gratuitement les tâches quotidiennes avec Agent, dans la limite de leur quota. Les modes payants et les tâches payantes confirmées sont facturés en fonction de l’effort requis, selon la complexité de la demande. Replit demande une confirmation avant de lancer une action payante.

<div id="como-funciona-a-precificao-baseada-em-esforo">
  ### Fonctionnement de la tarification basée sur l&#39;effort
</div>

Lorsque vous échangez avec Agent en « mode Build », il crée des **checkpoints** qui capturent le travail effectué pour répondre à votre demande :

* **Les demandes simples** (comme les corrections de bugs ou les petites modifications) coûtent généralement moins cher que les builds complexes
* **Les builds complexes** (comme des fonctionnalités complètes ou des intégrations) sont regroupés dans un checkpoint qui peut coûter plus cher qu&#39;une demande simple, reflétant l&#39;effort total nécessaire
* **Un checkpoint par demande** élimine les checkpoints intermédiaires et réduit le bruit de facturation
* **Des tarifs transparents** indiquent exactement ce que vous payez pour chaque tâche effectuée

<Info>
  Un checkpoint est créé lorsque Agent termine le travail demandé et implémente la fonctionnalité requise dans votre code.
</Info>

Avec le forfait payant, le mode Planification peut effectuer un raisonnement facturable même lorsqu&#39;il ne modifie pas le code.

Pour en savoir plus sur le contenu des checkpoints et leur fonctionnement, consultez [Checkpoints et retours en arrière](/fr/pt/features/version-control/checkpoints-and-rollbacks).

<div id="cobrana-dos-servios-do-agent">
  ### Facturation des services Agent
</div>

Certaines fonctionnalités d’Agent utilisent en arrière-plan des API tierces payantes (comme Claude, ChatGPT et Nano Banana / Gemini). Agent gère automatiquement ces intégrations, sans clé d’API ni configuration requise. Vous êtes facturé au tarif public de l’API du fournisseur, déduit de vos crédits Replit. Ces coûts apparaissent avec le reste de votre utilisation dans le [panneau d’utilisation](/fr/pt/billing/managing-spend).

Pour connaître le coût d’applications d’exemple, consultez notre [démonstration interactive](https://agent-pricing.replit.app/).

<div id="acompanhar-seu-uso">
  ### Suivre votre utilisation
</div>

Vous pouvez suivre vos dépenses liées à Agent en temps réel :

1. **Onglet Agent** : consultez le coût de chaque checkpoint en survolant l’icône d’utilisation
2. **Panneau d’utilisation** : consultez les informations de facturation détaillées pour la période en cours
3. **Paramètres** : configurez des alertes et des budgets dans **Compte** → **Facturation** pour maîtriser vos dépenses

<Tip>
  Les données d’utilisation peuvent mettre jusqu’à 30 minutes à apparaître dans votre panneau d’utilisation.
</Tip>

<div id="gerenciando-seus-gastos">
  ## Gestion de vos dépenses
</div>

Gardez le contrôle de vos dépenses liées à l&#39;IA grâce aux outils de budgétisation intégrés de Replit :

* **Alertes d&#39;utilisation** : recevez des notifications lorsque vous atteignez des seuils de dépenses
* **Limites budgétaires** : définissez des plafonds stricts pour éviter les frais imprévus
* **Suivi en temps réel** : surveillez les coûts au fur et à mesure que vous créez
* **Packs de crédits** : achetez des crédits supplémentaires à prix réduit pour les achats importants. Consultez [Gestion de vos dépenses](/fr/pt/billing/managing-spend) pour en savoir plus.

<div id="prximos-passos">
  ## Prochaines étapes
</div>

Prêt à créer avec l’IA ? Voici comment tirer le meilleur parti de vos crédits :

* **Commencez par essayer Agent** : utilisez vos checkpoints gratuits pour explorer les capacités d’Agent
* **Commencez modestement** : commencez par des demandes simples pour comprendre la tarification basée sur l’effort
* **Utilisez le mode Lite** : profitez du [mode Lite](/fr/pt/features/agent/agent-modes) pour effectuer des modifications rapides et ciblées
* **Configurez des alertes** : activez des notifications de dépenses avant d’épuiser vos crédits
