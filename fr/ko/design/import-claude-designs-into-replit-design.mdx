Les designs créés dans Claude montrent à quoi l’expérience doit ressembler. Grâce à l’option **Send to Replit** de Claude, vous pouvez envoyer ce design à Replit, où il devient un projet qu’Agent transforme en application interactive fonctionnelle.

<Note>
  Il s’agit d’une nouvelle intégration. **Send to Replit** apparaît dans le menu **Send to…** de Claude uniquement lorsque Claude propose Replit comme destination pour le design. Sa disponibilité étant contrôlée par Claude, l’option peut ne pas encore apparaître pour tous les comptes. Lorsque vous acceptez l’envoi, Claude demande les autorisations **Access apps**, **Create and manage apps** et **Stay signed in to this application** sur l’écran de consentement de Replit.
</Note>

<div id="section">
  ## Fonctionnement
</div>

Le processus de transfert commence dans Claude et se termine dans Replit :

1. Créez un design autonome dans le canevas de conception de Claude.
2. Dans le menu **Share → Send to…** de Claude, envoyez le design vers Replit.
3. Autorisez Claude à accéder à votre compte Replit et sélectionnez un espace de travail.
4. Replit crée un projet contenant le design sous la forme d’un fichier `index.html` statique.
5. Agent lance la tâche **Turn this Claude design into a real app** afin de le rendre interactif.

Claude *envoie* ainsi le design vers Replit via une connexion d’application autorisée. Vous n’avez rien à configurer au préalable dans Replit : le processus commence dans Claude.

<div id="section-2">
  ## Avant de commencer
</div>

Vous avez besoin des éléments suivants :

* D’un [compte Replit](https://replit.com).
* D’un compte Claude contenant une conception dans le canevas de conception de Claude.
* D’un espace de travail Replit dans lequel créer un nouveau projet.

<div id="claude-replit">
  ## Envoyer un design de Claude vers Replit
</div>

Commencez dans Claude avec le design que vous souhaitez créer.

<Steps>
  <Step title="Ouvrir le design dans Claude">
    Ouvrez dans Claude le design que vous souhaitez transformer en application.
  </Step>

  <Step title="Ouvrir le menu Send to">
    Sélectionnez **Share**, puis ouvrez le menu **Send to…**. Replit s’affiche comme destination.

    <Frame>
      <img src="/assets/mirror/claude-send-to-menu-d4353906aea3.png" alt="Menu Send to… de Claude listant Replit comme destination avec Claude Code" width="2000" height="1143" data-path="images/claude-to-app/claude-send-to-menu.png" />
    </Frame>
  </Step>

  <Step title="Sélectionner Replit">
    Sélectionnez **Replit** pour lancer l’envoi vers votre compte Replit.
  </Step>

  <Step title="Autoriser l’accès à Replit">
    Sur l’écran de consentement Replit intitulé **Claude would like to access your Replit account**, vérifiez les autorisations demandées par Claude — **Access apps**, **Create and manage apps**, **Stay signed in to this application** — puis autorisez la connexion.

    <Frame>
      <img src="/assets/mirror/replit-oidc-consent-76dfc4d92a2f.png" alt="Écran de consentement Replit intitulé « Claude would like to access your Replit account », affichant les autorisations Access apps, Create and manage apps et Stay signed in, ainsi qu’un sélecteur d’espace de travail" width="2000" height="1143" data-path="images/claude-to-app/replit-oidc-consent.png" />
    </Frame>
  </Step>

  <Step title="Sélectionner un espace de travail">
    Sélectionnez l’espace de travail Replit dans lequel créer le nouveau projet, puis confirmez.
  </Step>
</Steps>

Après confirmation, Replit crée un projet à partir du design et l’ouvre dans votre espace de travail.

<div id="section-3">
  ## Éléments importés
</div>

Replit importe le design sous la forme d’un fichier `index.html` unique et autonome. L’importation préserve la mise en page, le style et les ressources visuelles inclus par Claude dans le design.

L’importation fournit un point de départ fonctionnel. Comme le design est livré sous forme de HTML statique, vous devrez ajouter vous-même le comportement, les données et les fonctionnalités interactives après l’importation.

<div id="section-4">
  ## Éléments non importés
</div>

Seul le design est transféré, pas une application finalisée. Les éléments suivants ne sont pas inclus dans l’importation :

* La logique backend et les fonctionnalités côté serveur.
* Les bases de données ou les données stockées.
* Les fonctionnalités interactives, telles que les formulaires fonctionnels, les états et la navigation.

Agent ajoute ces fonctionnalités lorsqu’il transforme le design en véritable application.

<div id="agent">
  ## Agent rend le design interactif
</div>

Après l&#39;importation, Agent lance la tâche **Turn this Claude design into a real app** dans l&#39;espace de travail. À partir du design statique, Agent crée les interactions qu&#39;il suggère.

<Frame caption="Le design Velocity transmis depuis Claude s'affiche sous forme de frame dans Replit Design, et l'exécution d'Agent est terminée.">
  <img src="/assets/mirror/claude-design-in-replit-design-ff81b055b1f5.webp" alt="Le design de location de supercars Velocity envoyé depuis Claude est ouvert dans Replit Design sous forme de frame Claude design, et le panneau de chat indique que la tâche d'Agent est terminée" width="1600" height="1004" data-path="images/claude-to-app/claude-design-in-replit-design.webp" />
</Frame>

Une fois la tâche terminée, ouvrez Preview pour tester le résultat. Comparez l&#39;application en cours d&#39;exécution au design Claude d&#39;origine et vérifiez les points suivants :

* La mise en page et le style correspondent suffisamment au design.
* Les boutons, formulaires et la navigation fonctionnent comme prévu.
* L&#39;application continue de fonctionner après l&#39;actualisation.

S&#39;il manque quelque chose ou si certains éléments ne correspondent pas, décrivez les modifications à Agent afin qu&#39;il affine l&#39;application.

  ## Tarification
</div>
