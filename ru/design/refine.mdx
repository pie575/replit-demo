Исследование помогает охватить больше возможностей, а доработка — углубиться в детали. Когда фрейм уже почти соответствует вашим ожиданиям, два инструмента помогут точно настроить его удобным для вас способом:

* Общайтесь с Agent своими словами — о фрейме целиком или отдельном элементе
* Редактируйте элементы напрямую в Visual Editor: простые изменения применяются мгновенно и не расходуют кредиты

<div id="chat">
  ## Chat
</div>

Формулируйте задачи для Agent так же, как для дизайнера во время обсуждения макета. Выберите фрейм и опишите изменения в основном чате (*«более тёплые цвета»*, *«главный блок кажется пустым»*) или выберите инструмент **Chat** на панели инструментов и нажмите на элемент, чтобы сообщение относилось только к нему.

Оба способа описаны в разделе [Chat](/ru/design/chat-about-your-design).

<div id="visual-editor">
  ## Visual Editor
</div>

Если вы точно знаете, чего хотите, не используйте prompt. Выберите инструмент **Edit** на панели инструментов и щёлкните любой элемент — откроется Visual Editor с доступными для редактирования свойствами этого элемента, например содержимым, раскладкой, цветом и границей. Простые изменения, такие как редактирование текста, выбор цвета и настройка интервалов, мгновенно применяются к исходному коду без расхода кредитов.

<div id="which-one-to-reach-for">
  ## Что выбрать
</div>

| Вы хотите…                                                                 | Используйте   |
| -------------------------------------------------------------------------- | ------------- |
| Описать желаемый результат и поручить Agent проработать детали             | Chat          |
| Изменить текст, цвет, отступ или изображение элемента на заданное значение | Visual Editor |
| Переработать структуру или поведение раздела                               | Chat          |
| Быстро внести правку без кредитов                                          | Visual Editor |

Эти инструменты естественно дополняют друг друга: в Chat задайте общее направление, а затем с помощью Visual Editor доведите детали до совершенства.
