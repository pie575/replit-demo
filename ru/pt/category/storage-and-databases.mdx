Гибкие решения Replit для хранения данных позволяют быстро подобрать подходящее хранилище для вашего приложения. Для приложений со следующими требованиями можно использовать базу данных или объектное хранилище Replit, а Agent автоматически настроит и интегрирует оба решения:

* Игра, в которой нужно сохранять данные игрока, например прогресс или рекорды
* Контент-платформа для управления медиафайлами

<div id="quais-so-as-opes-de-armazenamento-e-banco-de-dados-do-replit">
  ## Какие возможности хранения данных и работы с базами данных предлагает Replit
</div>

Replit предлагает следующие варианты хранения данных:

* **База данных**: хранит структурированные данные, например профили пользователей, результаты игр и каталоги товаров.
  Вы можете хранить и извлекать данные по атрибутам и связям между ними.

* **App Storage**: хранит неструктурированные данные, например изображения, видео и документы.
  Вы можете хранить и извлекать большие файлы и двоичные данные.

<div id="comparao-entre-app-storage-e-banco-de-dados">
  ### Сравнение App Storage и базы данных
</div>

|                               | База данных                                     | App Storage                                       |
| ----------------------------- | :---------------------------------------------- | :------------------------------------------------ |
| **Оптимальный формат данных** | Структурированные взаимосвязанные данные        | Большие файлы (изображения, видео, документы)     |
| **Модель данных**             | Таблицы, строки, столбцы                        | Бакеты, файлы                                     |
| **Язык запросов**             | SQL                                             | REST API                                          |
| **Клиенты**                   | PostgreSQL-совместимые клиенты и ORM            | SDK Replit и клиентские библиотеки GCS            |
| **Модель биллинга**           | Оплата за вычислительное время и место хранения | Оплата за пропускную способность и место хранения |

<CardGroup>
  <Card title="База данных" href="/ru/pt/features/data-and-storage/sql-database/" icon="database">
    Идеально подходит для структурированных данных и представления связей между ними.
    Работает на полностью управляемой базе данных PostgreSQL, которая масштабируется вместе с вашим приложением.
  </Card>

  <Card title="App Storage" href="/ru/pt/features/data-and-storage/object-storage/" icon="bucket">

    Использует Google Cloud Storage (GCS) для обеспечения высокой доступности и масштабируемости. Agent может автоматически настроить App Storage с расширенной аутентификацией и средствами управления доступом.
  </Card>
</CardGroup>
