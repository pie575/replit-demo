Memories를 사용하면 Replit이 유용한 context를 기억하고 이전 작업에서 배운 내용을 반영하므로, 매번 같은 선호 사항을 다시 알려줄 필요가 없습니다. Replit은 작업하는 동안 Memories를 기록하고, 시간이 지나도 유용하게 유지합니다.

<div id="manage-your-memories">
  ## Memories 관리
</div>

<Steps>
  <Step title="Settings 열기">
    Replit에서 **Settings**를 엽니다.
  </Step>

  <Step title="Customization 선택">
    **Customization**을 선택합니다.
  </Step>

  <Step title="Memory 탭 열기">
    여기에서 Memory를 사용 설정(opt in)하거나 나중에 끌 수 있으며, 협업자와 공유할지 선택하고
    **Memory file**을 보거나 업데이트할 수 있습니다. Memories는 기본적으로
    비공개이며, 협업자 공유는 기본적으로 꺼져 있습니다.

  </Step>
</Steps>

<Note>
  Memories에는 개인 정보나 민감한 정보가 보관되지 않습니다. Memory는 workspace
  활동에서 생성되는 만큼 Replit이 이를 안전하게 처리합니다.
</Note>

Memories, Custom Instructions, Skills를 각각 언제 사용하면 좋은지는 [Memories, Custom Instructions, and Skills](/ko/chat/memories-custom-instructions-and-skills)에서 확인하세요.

<div id="faq">
  ## FAQ
</div>

<AccordionGroup>
  <Accordion title="Memories는 무엇을 저장하나요?">
    Memories는 실행 가능한 지시가 아니라 유용한 context를 저장합니다. 사용자 메모리에는
    오래 유지되는 workspace 환경설정과 작업 방식을 담을 수 있습니다. Project 메모리에는
    conventions, 주의할 점, 해결 방법을 담을 수 있습니다. 사용자 지정 메모리는 접근 권한과
    공개 범위를 직접 설정하는 context입니다. 사용자가 명시적으로 요청한 내용과
    [Custom Instructions](/ko/features/agent/agent-customization)가 메모리보다
    우선합니다.
  </Accordion>

  <Accordion title="Replit이 개인정보를 저장하나요?">
    <Note>
      Memories는 개인정보를 저장하지 않습니다. 사용자 메모리는 유용한 workspace
      환경설정과 작업 방식은 저장할 수 있지만, 민감한 특성, 제3자의 개인정보,
      자격 증명, project 기밀 정보는 저장하지 않습니다.
    </Note>
  </Accordion>

  <Accordion title="Memories를 다른 사람과 공유할 수 있나요?">
    Memories는 기본적으로 비공개입니다. 협업자와의 공유는 선택 사항이며 기본값은
    꺼짐입니다. 다른 협업자가 편집할 수 있는 Projects에서 Replit이 Memory를
    사용하도록 하려면 **Settings → Customization → Memory**에서 켜세요.
  </Accordion>

  <Accordion title="Memories는 어디에 적용되나요?">
    사용자 메모리는 한 명의 builder와 하나의 workspace에 속합니다. Project 메모리는 하나의
    Project에만 남아 있으며 필요할 때 불러옵니다. 사용자 지정 메모리는 해당 메모리에
    정의된 접근 권한과 공개 범위 설정을 따릅니다. 협업자와의 공유를 켜지 않는 한,
    Replit은 다른 협업자가 편집할 수 있는 Projects에서 Memory를 사용하지
    않습니다.
  </Accordion>

  <Accordion title="Memories를 보거나 편집하거나 끌 수 있나요?">
    가능합니다. **Settings → Customization → Memory**에서 Memory에 opt in 할 수 있고,
    나중에 비활성화할 수도 있으며, **Memory file**에서 Replit이 기억하는 내용을
    확인하고 업데이트할 수 있습니다.
  </Accordion>
</AccordionGroup>
