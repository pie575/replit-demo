Ces réponses portent sur la connexion et le dépannage des domaines personnalisés. Pour une référence complète, consultez [Ajouter un domaine personnalisé](/fr/ko/build/add-custom-domain) et [Domaines personnalisés](/fr/ko/features/publishing/custom-domains).

<AccordionGroup>
  <Accordion title="Comment connecter un domaine personnalisé à une application Replit ?">
    Si vous avez acheté un domaine via Replit, les enregistrements DNS sont gérés automatiquement. Ouvrez **Publishing → Domains** et suivez les instructions de configuration. Consultez [Achat de domaine](/fr/ko/build/domain-purchasing).

    Pour connecter un domaine enregistré auprès d’un registraire externe :

    1. Ouvrez votre projet et accédez à **Publishing → Domains**.
    2. Sélectionnez **Connect your own domain**, saisissez votre domaine, puis continuez.
    3. Replit affiche un enregistrement A et un enregistrement TXT : copiez-les tous les deux.
    4. Ajoutez les deux enregistrements chez votre fournisseur DNS.
    5. Revenez sur Replit et lancez la vérification.

    Quelques remarques importantes :

    * Les enregistrements A et TXT sont tous deux requis pour SSL. Les CNAME à la racine (apex) ne sont pas pris en charge : utilisez un enregistrement A pour le domaine racine.
    * Les certificats génériques (`*.example.com`) ne sont pas pris en charge. Connectez chaque sous-domaine individuellement.
    * Avec Cloudflare, définissez l’enregistrement A sur **DNS only** (nuage gris) afin que le mode proxy ne bloque pas la configuration SSL.
    * La propagation des modifications DNS peut prendre jusqu’à 48 heures.

    Pour la documentation complète, consultez [Domaines personnalisés](/fr/ko/features/publishing/custom-domains).
  </Accordion>

  <Accordion title="Le domaine n’est pas vérifié ou le certificat SSL n’est pas provisionné : comment résoudre ce problème ?">
    Effectuez les vérifications suivantes dans l&#39;ordre — la plupart des problèmes viennent de l&#39;une d&#39;entre elles :

    1. **Attendez la propagation DNS.** Les modifications peuvent prendre jusqu&#39;à 48 heures. Utilisez un outil de recherche DNS pour vérifier que vos enregistrements sont visibles partout dans le monde.
    2. **Supprimez les enregistrements AAAA.** Un enregistrement IPv6 (AAAA) portant le même nom d&#39;hôte que votre enregistrement A peut bloquer le SSL.
    3. **Supprimez les enregistrements A obsolètes ou en conflit.** Ne conservez qu&#39;un seul enregistrement A pointant vers Replit sur votre domaine racine.
    4. **Configurez Cloudflare en mode DNS only.** Le nuage orange (mode proxy) empêche le provisionnement SSL.
    5. **Déconnectez puis reconnectez le domaine** dans **Publishing → Domains → Manage** pour forcer l&#39;émission d&#39;un nouveau certificat, patientez quelques minutes, puis actualisez.
    6. **Vérifiez vos enregistrements CAA.** Si vous avez des enregistrements CAA, au moins l&#39;un d&#39;eux doit autoriser Let&#39;s Encrypt comme autorité de certification, car Replit émet les certificats via Let&#39;s Encrypt.

    Ces vérifications s&#39;appliquent aux domaines enregistrés en externe. Si vous avez acheté votre domaine via Replit, [contactez le support Replit](https://replit.com/support). Consultez [Domaines personnalisés](/fr/ko/features/publishing/custom-domains).
  </Accordion>

  <Accordion title="Comment configurer l’authentification Clerk sur un domaine personnalisé ?">
    Lorsque vous utilisez [l’authentification Clerk](/fr/ko/features/auth-and-identity/clerk-auth) avec un domaine personnalisé, vous pouvez rencontrer quelques problèmes courants :

    * **Avertissement &quot;Clerk CNAME records required&quot;.** Il s’agit d’une exigence de l’intégration Clerk qui ne bloque ni la vérification du domaine ni le SSL. Ouvrez **Publishing → Domains**, sélectionnez **Manage**, puis recherchez la section des paramètres DNS d’authentification et ajoutez chaque enregistrement CNAME exactement comme indiqué chez votre fournisseur DNS. Si la section n’apparaît pas, déconnectez puis reconnectez le domaine.
    * **Le domaine reste bloqué lors de la vérification après avoir déjà utilisé Clerk.** Si le domaine était connecté à une autre application Clerk, supprimez-le du [tableau de bord Clerk](https://dashboard.clerk.com), puis déconnectez et reconnectez le domaine dans Replit.
    * **Migration vers votre propre instance Clerk.** Le passage de Clerk géré par Replit à votre propre instance nécessite des étapes manuelles : [contactez l’assistance Replit](https://replit.com/support). Consultez [Puis-je utiliser ma propre application Clerk ?](/fr/ko/features/auth-and-identity/clerk-auth#can-i-bring-my-own-clerk-app-instead-of-using-the-replit-managed-one).

    Si vous êtes toujours bloqué, [contactez l’assistance Replit](https://replit.com/support) en indiquant le nom de domaine, le nom du projet et ce que vous avez déjà essayé.
  </Accordion>
