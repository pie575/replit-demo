<div id="como-o-replitmd-funciona">
  ## `replit.md` 的工作方式
</div>

Agent 会先根据经过验证的最佳实践，在项目根目录中创建 `replit.md` 文件。该文件包含：

* 项目的基本信息
* 推荐的编码规范
* 适合您项目类型的常用偏好设置

<YouTubeEmbed videoId="kYv525W-vaU" title="自定义 Replit Agent 的响应方式" />

Agent 处理您的请求时，会自动读取 `replit.md` 文件，并利用其中的内容：

* 了解项目的架构和约定
* 遵循您偏好的编码规范和风格
* 使用指定的包管理器和依赖项

随着 Agent 对项目的了解不断加深，并对应用进行更改，它还可以更新 `replit.md` 文件。

<Note>
  您可以编辑 `replit.md` 文件，自定义 Agent 的行为。
</Note>

<div id="configurando-o-replitmd">
  ## 配置 `replit.md`
</div>

<div id="gerao-automtica">
  ### 自动生成
</div>

使用 Agent 创建新项目时，它会根据经过验证的最佳实践自动生成 `replit.md` 文件。该文件位于项目根目录，包含：

* 项目的基本信息
* 推荐的编码规范
* 项目类型的常见偏好设置

<div id="criao-manual">
  ### 手动创建
</div>

你可以在项目根目录中创建一个名为 `replit.md` 的文件，以创建自己的 `replit.md` 文件。Agent 会自动检测该文件，并在后续 Conversation 中使用它。

<Note>
  `replit.md` 必须位于项目根目录中，才能正常工作。
</Note>

<div id="regenerando-o-replitmd">
  ### 重新生成 `replit.md`
</div>

如果 `replit.md` 文件损坏，或者你想重新开始：

1. 从项目根目录删除现有的 `replit.md` 文件
2. 与 Agent 开始新的对话
3. Agent 会根据当前项目自动生成新的 `replit.md` 文件

<div id="seja-especfico-e-claro">
  ### 具体且清晰
</div>

编写清晰、具体的指令，帮助 Agent 准确理解你的需求：

```markdown theme={null}
## 编码风格

- 所有新建的 JavaScript 文件均使用 TypeScript
- 优先使用带 Hooks 的函数组件，而非类组件
- 使用 Tailwind CSS 进行样式设计，避免使用内联样式
- 始终为函数参数和返回值添加 TypeScript 类型
```

如需详细了解提示词格式，请参阅 [Anthropic 的提示词工程指南](https://docs.anthropic.com/en/docs/build-with-claude/prompt-engineering/use-xml-tags)。

## 项目概述
使用 React 和 Express.js 构建的任务管理 Web 应用。

- 前端：React（TypeScript）和 Tailwind CSS
- 后端：Express.js（TypeScript）

## 沟通风格

- 为复杂逻辑添加代码注释

<div id="combinando-pesquisa-na-web-com-replitmd">
  ## 将网页搜索与 `replit.md` 结合使用
</div>

Agent 可以通过网页搜索查找最新信息、库和解决方案。结合使用 `replit.md` 文件，您既能获取最新知识，也能获得针对项目的具体指导。

<div id="prticas-recomendadas-para-integrao-com-pesquisa-na-web">
  ### 集成网页搜索的最佳做法
</div>

**请明确说明希望 Agent 搜索的内容：**

```markdown theme={null}
## 研究偏好
- 在建议更新前，始终检查依赖项是否有最新版本
- 调研当前安全实现的最佳实践
- 查找适用于我们技术栈的最新性能优化方法
```

**指导 Agent 如何运用外部知识：**

```markdown theme={null}
## 外部研究指南
- 建议使用新库时，确保其与现有技术栈兼容
- 调整外部示例，使其符合我们的编码标准和项目结构
- 验证建议的解决方案可在我们的发布环境中正常运行
```

**同时利用两者的请求示例：**
&quot;研究 React 18 最新的性能优化技术，并按照 `replit.md` 中定义的组件模式加以实现&quot;

这种方法既能提供最新的解决方案，又能贴合项目的具体需求。

<div id="limitaes">
  ## 限制
</div>

<div id="limites-de-tamanho-e-contedo-do-arquivo">
  ### 文件大小和内容限制
</div>

虽然 `replit.md` 没有严格的字符数限制，但文件过大可能无法被完全处理。请保持 `replit.md` 内容聚焦且简洁，以获得最佳效果。

<div id="requisito-de-diretrio-raiz">
  ### 根目录要求
</div>

`replit.md` 必须位于项目根目录中。Agent 不会自动检测子目录中的文件。

<div id="escopo-do-contexto">
  ### 上下文适用范围
</div>

`replit.md` 会为与 Agent 的对话提供上下文，但不会自动应用于其他 AI 工具。

<div id="prximos-passos">
  ## 后续步骤
</div>

准备好为你的项目定制 Agent 了吗？

1. **从简单开始**：创建一个包含主要偏好的基本 `replit.md`
2. **迭代改进**：在使用 Agent 的过程中不断更新 `replit.md`
3. **共享最佳实践**：在类似项目中复用有效的 `replit.md` 配置
4. **监测效果**：留意 Agent 对指南的遵循情况，并根据需要进行调整
