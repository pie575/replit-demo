Навык — это папка с повторно используемыми инструкциями и вспомогательными файлами. Используйте его, чтобы настроить подход Replit к повторяющимся задачам, соглашениям или рабочим процессам.

В поле prompt откройте меню **«Ещё (+)»**, затем выберите **«Использовать навык»**. Выберите навык для нужной задачи и сообщите Replit, какой результат вам нужен.

<div id="escolha-a-conexo-certa">
  ## Выберите подходящий способ подключения
</div>

* Используйте **навык** для хранения многоразовых инструкций, примеров и справочных материалов.
* Используйте [интеграцию](/ru/pt/chat/integrate-your-tools) для поддерживаемого сервиса и доступа к разрешённым данным или действиям.
* Используйте [MCP](/ru/pt/chat/connect-through-mcp) для инструментов, доступных через совместимый MCP-сервер или MCP-клиент.
