<div id="replitenterprise">
  ### Переход на Enterprise без выхода из Replit
</div>

Теперь перейти на Replit Enterprise можно с любого тарифа — Free, Core или Pro — не покидая продукт и без предварительного обращения в отдел продаж. Если у вас есть совместное рабочее пространство, после оформления заказа оно автоматически перенесётся в новую организацию Enterprise. Опубликованные Apps продолжат работать без простоя.

<div id="stripe">
  ### Установите приложение и подключите Stripe — копировать ключи не нужно
</div>

Публиковать App со Stripe стало проще. Вместо того чтобы копировать боевые API-ключи из панели управления Stripe, установите приложение Replit для интегрированных платежей из Stripe Marketplace — рабочие ключи настроятся автоматически. Откройте панель Publish, установите приложение и завершите подключение в Stripe.

  ### Создавайте 3D-модели с помощью коннектора Tripo3D

  ## Agent

<div id="agent-2">
  ### Agent теперь может создавать музыку, звуковые эффекты и озвучку
</div>

Agent теперь может создавать аудио для ваших приложений. Попросите создать фоновую музыку, звуковые эффекты или озвучку, и Agent сгенерирует и сразу добавит аудио в ваш проект. Использование списывается с кредитов Replit.

Подробнее о [генерации аудио](/ru/ja/features/agent/audio-generation).

  ## Рабочее пространство

<div id="canvas">
  ### Генерация медиа прямо на Canvas
</div>

Теперь медиафайлы можно создавать прямо на Canvas. Откройте инструмент **Generate** на панели инструментов Canvas и выберите **Image**, **Vector Graphic** или **Video**, чтобы сгенерировать материал на месте. Вся работа идёт на доске, так что вы можете создавать дизайн и дорабатывать его, не переключаясь между инструментами.
