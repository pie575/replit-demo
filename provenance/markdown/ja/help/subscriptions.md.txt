# サブスクリプション

> Replit サブスクリプションの管理—アップグレード、キャンセル、支払い失敗の修正、譲渡、一時停止—に関する回答。

export const ProPlanPrice = '$100';

export const ProCreditRolloverPeriod = 'two months';

これらの回答はサブスクリプションの管理をカバーしています。プランの詳細については、[Core](/ja/billing/plans/replit-core) と [Pro](/ja/billing/plans/replit-pro) をご覧ください。

<AccordionGroup>
  <Accordion title="Core から Pro へのアップグレード方法と、その違いは何ですか？">
    [Core](/ja/billing/plans/replit-core) と比較して、[Pro](/ja/billing/plans/replit-pro)（{ProPlanPrice}/月）には次が追加されます:

    * Turbo モード
    * プールされたクレジットを持つ最大 15 名のビルダー
    * 段階的クレジット。未使用のクレジットは{ProCreditRolloverPeriod}繰り越されます
    * 28 日間のデータベースリストアウィンドウ（Core の 7 日間に対して）
    * 優先サポート

    アップグレードするには、**設定 → 課金**を開き、Pro プランを選択して支払い情報を確認してください。機能の比較と現在の料金については、[料金ページ](https://replit.com/pricing)をご覧ください。
  </Accordion>

  <Accordion title="サブスクリプションをキャンセルするにはどうすればよいですか？">
    **設定 → 課金**を開き、サブスクリプションをキャンセルするオプションを選択して、確認手順を完了してください。課金期間が終わるまでプランの機能は維持され、その後アカウントは無料の[Starter プラン](/ja/billing/plans/starter-plan)に移行します。

    移行前に、公開アプリがオフラインになる可能性があること、カスタムドメインの接続が削除されること、ストレージが削減されることにご注意ください。保持したいものは事前にダウンロードしてください。サブスクリプションが `past_due` と表示されている場合、支払いに失敗している可能性があります—キャンセルする前に解決してください。
  </Accordion>

  <Accordion title="更新支払いに失敗しました—支払い方法はどのように更新しますか？">
    **設定 → 課金**を開き、**支払い方法を更新**を選択して、カードを追加または更新してください。保存後、Replit が未払いの支払いを自動的に再試行します。

    問題が続く場合は、支払いインテント ID（`pi_` で始まる）を記載して[Replit サポートにお問い合わせ](https://replit.com/support)ください。課金失敗の通知がスパムフォルダに入っている場合があります。
  </Accordion>

  <Accordion title="サブスクリプションを別のメールアドレスまたはアカウントに譲渡するにはどうすればよいですか？">
    サブスクリプションは Replit アカウントに紐付けられており、直接譲渡することはできません。サブスクリプションを維持しながらアカウントのメールアドレスを変更するには、**設定 → プロフィール**に移動してメールを編集してください。

    サブスクリプションを別のアカウントに移動するには、[Replit サポートにお問い合わせ](https://replit.com/support)ください—ケースバイケースで対応します。
  </Accordion>

  <Accordion title="1 ヶ月に 2 回請求されました—何が起きたのですか？">
    1 ヶ月に 2 回の請求は通常、次のいずれかによるものです:

    * 課金しきい値に達したサブスクリプション料金と別途の使用量請求
    * 以前の失敗の後に成功した再試行された支払い
    * 複数のアクティブなサブスクリプション

    各請求の内容を確認するには、**設定 → アカウントの使用状況**を開き、**過去の請求書を見る**を選択してください。それでも合わない場合は、[Replit サポートにお問い合わせ](https://replit.com/support)ください。
  </Accordion>

  <Accordion title="プランを変更しましたが、新機能が利用できません—どうすればよいですか？">
    プランの変更は通常すぐに反映されます。新機能が表示されない場合:

    1. Mac では `Cmd+Shift+R`、Windows では `Ctrl+Shift+R` でハードリフレッシュしてください。
    2. サインアウトして再度サインインしてください。
    3. **設定 → 課金**を開き、変更が完了していることを確認してください—新しいプラン名が表示されているはずです。

    課金に正しいプランが表示されているのに機能が使えない場合は、ユーザー名と使用しようとしている機能を記載して[Replit サポートにお問い合わせ](https://replit.com/support)ください。
  </Accordion>

  <Accordion title="キャンセルの代わりにサブスクリプションを一時停止できますか？">
    一部のサブスクリプション利用者は、キャンセルする代わりに 1 ヶ月間サブスクリプションを一時停止できる資格があります。対象となる場合、キャンセル操作を行う際にこのオプションが表示されます。一時停止中は次のようになります:

    * 次回の支払いはスキップされ、月次クレジットは付与されません
    * 公開済みのプロジェクトは引き続き稼働し、コラボレーターもアクセスを維持できます
    * 対象のクレジットは繰り越され、クレジットパックは引き続き使用できます
    * Agent とホスティングの使用量は引き続き従量課金制で請求されます

    **設定 → 課金**には**一時停止中**のバッジと一時停止の終了日が表示され、その日にサブスクリプションが自動的に再開します。予定されている一時停止は発効前にキャンセルできますが、有効化された一時停止を早期に終了することはできません。サブスクリプションを一時停止できるのは 1 回のみです。
  </Accordion>
</AccordionGroup>

## お困りの場合は？

アカウント固有のサブスクリプションに関する質問については、[Replit サポートにお問い合わせ](https://replit.com/support)ください。
