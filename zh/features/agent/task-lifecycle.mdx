每个 Agent 任务都会经历一个生命周期：已规划、运行中、待审阅和已完成。这一生命周期能让工作始终保持隔离，直到你决定哪些内容应并入主版本。

<div id="draft">
  ## 草稿
</div>

**草稿**是指 Agent 已规划但尚未开始构建的任务。草稿可以放心查看，因为其中只包含拟议的工作内容：任务标题、说明和计划。

你可以通过草稿判断 Agent 是否理解了你的目标，然后选择启动该任务、让 Agent 修改计划，或将草稿归档以备后用。

<div id="active">
  ## 活动中
</div>

**活动中**的任务正在后台运行。Agent 会在你 project 的隔离副本中处理该任务，因此任务运行期间，你的主版本保持不变。

任务处于活动状态时，你仍可以继续使用主线程。如果某个任务需要你提供反馈，请打开对应的线程，在其中继续对话。

<div id="queued">
  ## 排队中
</div>

**排队中**的任务已获批准，但尚未开始执行。当任务依赖于另一个任务，或你已达到所用方案的活跃后台任务上限时，任务就会进入排队状态。

前置任务完成且有活跃任务名额空出后，排队中的任务会自动开始。

<div id="ready">
  ## 就绪
</div>

**就绪**状态的任务已完成，但其更改尚未应用到你的主版本。在应用更改前，请先查看该任务的工作日志、测试结果和 Preview。

如果结果符合预期，就将其应用到主版本；如果不是你想要的效果，可以将其忽略并新建一个任务。

<div id="applying">
  ## 应用中
</div>

处于**应用中**状态的任务正在将更改合并到你的主版本。应用多个任务的更改时，Agent 会自动处理冲突。

请等应用完成后再评估最终结果。如果之后发现有异常，可以在主线程中让 Agent 修复。

<div id="done">
  ## Done
</div>

处于 **Done** 状态的任务已经结束，无需再做任何处理。Done 可能表示任务已应用到你的主版本、在开始前就被归档，或在进入构建阶段后被取消。

你可以把 **Done** 列看作已完成、已归档和已取消任务的历史记录。

<div id="archiving-and-cancelling-tasks">
  ## 归档与取消任务
</div>

你可以在任务生命周期的任意阶段停止任务，但具体看到哪个选项，取决于该任务在看板上所处的位置。**Archive** 和 **Cancel** 都会把任务移到 **Done** 列，但二者的行为并不相同：

| 操作          | 何时可用                                                       | 会发生什么                                   | 可撤销吗？                                        |
| ----------- | ---------------------------------------------------------- | --------------------------------------- | -------------------------------------------- |
| **Archive** | 任务仍处于规划阶段时：尚未开始构建的 **草稿**                               | 规划会话被搁置，不会运行，其计划会保留下来。                  | 可以。在 **Done** 列中打开已归档的卡片，即可将其恢复到 **草稿**。 |
| **Cancel**  | 任务已从规划进入构建阶段后：处于 **活动中**、**排队中** 或 **就绪** 状态的任何任务 | Agent 会停止该任务，并丢弃所有进行中的工作，不会对你的主版本做任何更改。 | 不可以。已取消的任务无法恢复。如果想继续这项工作，请新建一个任务。            |

如果规划会话你打算日后再处理，请使用 **Archive**；对于已排队、正在运行或已完成构建的任务，**Cancel** 相当于永久停止按钮。

已归档的规划会话和已取消的任务，都可以在任务看板最右侧的 **Done** 列中找到，与已完成的任务放在一起。
