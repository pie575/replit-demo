description: "通过运行时间、请求和使用情况图表，查看已发布应用是否在运行、响应情况如何，以及占用了哪些资源。"
---

监控工具可以回答关于已发布应用的三个问题：是否在运行、运行得怎么样、消耗了多少资源。在 **Tools** 面板中展开 **Replit Cloud**，打开 **Monitoring**。

发布应用后，监控随即开始。发布之前，该工具会显示 **No deployment yet** 提示。

<Note>
  想查看访客或用户相关的分析数据？请在 **Growth** 面板中打开 [Project
  Analytics](/zh/ja/features/publishing/project-analytics)。
</Note>

<div id="application-monitoring">
  ## Application monitoring
</div>

Application monitoring 展示访客视角下应用的运行情况。可在顶部选择时间范围，放大或缩小查看。

<Frame>
  <img src="/assets/mirror/application-monitoring-475523d92a9b.png" alt="显示运行时间监控、包含唯一 IP 地址的请求图表、HTTP 状态和请求时长的 Application monitoring 视图" width="2000" height="1656" data-path="images/deployments/monitoring/application-monitoring.png" />
</Frame>

* **Uptime Monitoring**：以彩色条形展示应用在线时间的占比，并呈现最近的历史状况。Replit 会定期检查你的应用，一旦出现宕机就通过邮件通知你。
* **Requests**：应用所处理流量的时间序列，以及访问应用的唯一 IP 地址数量。
* **HTTP Statuses**：应用对近期请求的响应情况。成功响应说明运行正常，错误激增则提示需要排查。可将错误激增的时间段粘贴到 Agent 聊天中，请它查看日志。
* **Request Durations**：应用的响应耗时，按区间分组展示。如果大多数请求都集中在较慢的区间，可能说明应用需要优化，或需要[更强的机器配置](/zh/ja/features/publishing/machine-configuration)。

<div id="section">
  ### 启用运行时间监控
</div>

运行时间检查在发布设置中进行控制。

<Steps>
  <Step title="打开发布设置">
    打开 **Publishing** 工具，开始新的发布或重新发布应用。
  </Step>

  <Step title="启用开关">
    在 **Monitoring tools** 下开启 **Enable app monitoring**，然后发布应用。
  </Step>

  <Step title="查看运行时间">
    发布后数分钟内，监控工具中即会显示运行时间。
  </Step>
</Steps>

<Note>
  运行时间监控适用于 Replit Core、Pro 和 Enterprise 方案，支持除 Scheduled Deployments 以外的所有部署类型 (Scheduled Deployments 不提供网页，因此不在支持范围内) 。
</Note>

<div id="infrastructure-monitoring">
  ## 基础设施监控
</div>

基础设施监控可以展示应用在底层消耗了哪些资源。

<Frame>
  <img src="/assets/mirror/infrastructure-monitoring-edad0d8d26fc.png" alt="显示过去一小时 CPU 使用率和内存使用率图表的基础设施监控视图" width="2000" height="1513" data-path="images/deployments/monitoring/infrastructure-monitoring.png" />
</Frame>

* **CPU Utilization**：应用正在占用的处理能力。
* **Memory Utilization**：应用正在占用的内存量。

出现短暂的峰值属于正常现象。如果某张图表持续处于高位，则说明应用在高负载时的响应可能变慢，此时可以考虑改用[更强的机器配置](/zh/ja/features/publishing/machine-configuration)。

<div id="logs">
  ## Logs
</div>

Logs 会实时显示应用的运行情况，包括错误以及应用运行时输出的消息。Replit 会将部署日志保留 30 天。

你可以使用以下筛选条件过滤日志：

* **Errors only**：仅显示错误日志。
* **Search**：输入要在日志中搜索的内容。
* **Date**：选择日期范围。

<Tip>
  即使应用看起来出了问题，你也不必自己去看日志。让 Agent 排查即可，它会替你阅读日志。
</Tip>
