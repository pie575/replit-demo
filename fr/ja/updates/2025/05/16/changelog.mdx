<div id="section-4">
  ### Aperçu des points de contrôle
</div>

Découvrez les aperçus des points de contrôle dans l&#39;environnement de développement Replit. Visualisez votre application à différentes étapes de son développement sans avoir à recréer ou restaurer des versions antérieures.

<div id="replit">
  ### Voyage dans le temps Replit
</div>

La fonctionnalité de voyage dans le temps est désormais disponible sur Replit. Parcourez facilement l’historique de votre projet tout en conservant votre contexte de développement.

Explorez différentes versions, comprenez l’évolution des changements, corrigez vos erreurs et expérimentez avec davantage de confiance, le tout dans votre environnement de développement actuel. Cette fonctionnalité complète l’[intégration Git](/fr/ja/learn/projects-and-artifacts/version-control) pour un contrôle de version encore plus puissant.

<div id="agent">
  ### Demandez à Agent d’ajouter une base de données
</div>

L’intégration d’Agent au volet DB simplifie la configuration des bases de données. Ce flux de travail basé sur l’IA vous guide dans la configuration de votre base de données et facilite la mise en œuvre de la persistance des données, sans code de configuration complexe.

Les développeurs peuvent se concentrer sur les fonctionnalités essentielles, tandis qu’Agent gère les détails de la base de données. Pour en savoir plus, consultez [Replit Agent](/fr/core-concepts/agent) et les [options de base de données](/fr/ja/learn/projects-and-artifacts/storage-and-databases).

<div id="replit-auth">
  ### Correspondance automatique de Replit Auth
</div>

La correspondance automatique de Replit Auth simplifie l’authentification des utilisateurs de votre application.

Cette fonctionnalité s’active lorsque votre application nécessite une authentification. Elle élimine le besoin de formulaires d’inscription personnalisés, de systèmes de récupération de mot de passe et de configurations de connexion via les réseaux sociaux. Elle facilite ainsi la mise en place d’une gestion sécurisée des utilisateurs.

<div id="section-5">
  ### Authentification par e-mail en plein écran
</div>

Un processus d&#39;authentification simplifié pour les actions protégées renforce la sécurité de votre compte.

Cette approche intégrée vous invite à vous authentifier par e-mail après votre connexion, lorsque nécessaire. Elle protège votre compte tout en préservant une expérience utilisateur cohérente, conciliant sécurité et simplicité.

Cela s&#39;inscrit dans le cadre de notre engagement continu en faveur de la [sécurité de l&#39;information](/fr/ja/teams/information-security/overview).

<div id="google-analytics">
  ### Blueprint Google Analytics
</div>

Surveillez les performances de votre application avec le blueprint Google Analytics.

Agent intègre désormais directement la configuration des analyses à votre workflow de développement. Vous pouvez ainsi surveiller le trafic, suivre le comportement des utilisateurs et mesurer vos indicateurs de croissance, sans configuration complexe.

Nous proposons des fonctionnalités d’analyse professionnelles à tous les développeurs. Essayez-les dans les [Intégrations d’Agent](/fr/replitai/integrations).

<div id="scim">
  ### SCIM pour les clients Enterprise
</div>

Grâce à la nouvelle intégration SCIM, les clients Enterprise peuvent gérer directement les accès à Replit via leur fournisseur d’identité.

Connectez Okta, Active Directory, Rippling ou une autre plateforme d’identité pour automatiser le provisionnement et le déprovisionnement des licences Replit. Cela élimine la gestion manuelle des utilisateurs et simplifie les flux de travail Enterprise.

Pour commencer, consultez la [documentation SCIM détaillée](/fr/ja/teams/identity-and-access-management/scim).

<div id="replit-teams">
  ### Sièges d’observateur pour Replit Teams
</div>

Nous lançons les sièges d’observateur pour Replit Teams. Partagez des applications avec des parties prenantes qui souhaitent uniquement les consulter et interagir avec elles, sans les modifier, et sans avoir besoin d’une licence Teams complète.

Idéal pour les partager avec la direction, des clients ou des coéquipiers qui utilisent vos outils sans les créer. Découvrez comment configurer et gérer les [sièges d’observateur](/fr/ja/teams/identity-and-access-management/viewer-seats).
