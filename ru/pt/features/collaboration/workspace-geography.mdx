География workspace определяет, где размещаются ресурсы разработки Workspace. Она выбирается при создании Workspace, и все новые проекты и ресурсы в этом Workspace используют выбранное расположение.

<Note>
  География workspace и [география
  публикации](/ru/pt/features/security/geography#publishing-geography) могут
  различаться. География публикации определяет, где выполняется опубликованный
  проект.
</Note>

<div id="o-que-a-geografia-do-workspace-controla">
  ## Что определяет географическое расположение workspace
</div>

Workspace объединяет проекты, участников, настройки, общие ресурсы, интеграции и биллинг. Внутри каждого проекта вы работаете в Project Editor и чате Replit. К ресурсам разработки относятся dev-версия вашего приложения и база данных для разработки.

Выбрать конкретный регион для workspace могут только клиенты Pro.

Для клиентов на планах Free и Core регион workspace задаётся автоматически — как правило, выбирается ближайший к вам регион. Новые проекты и ресурсы в workspace используют это расположение. Изменить регион после создания workspace нельзя.

<div id="selecione-uma-regio-para-o-workspace">
  ## Выберите регион для workspace
</div>

Если у вас тариф Pro, вы можете выбрать регион при создании workspace:

<Steps>
  <Step>Откройте форму **Create a new workspace**.</Step>

  <Step>
    Введите название workspace и при необходимости адреса электронной почты
    участников.
  </Step>

  <Step>
    Откройте **Workspace region** и выберите **North America**, **Europe (EU)**
    или **Asia**.
  </Step>

  <Step>Нажмите **Create workspace**.</Step>
</Steps>

<div id="geografias-disponveis">
  ## Доступные регионы
</div>

| Регион            | Выбор в workspace |
| :---------------- | :---------------- |
| **North America** | Да                |
| **Europe (EU)**   | Да                |
| **Asia**          | Да                |
| **South America** | Нет               |
| **Australia**     | Нет               |
