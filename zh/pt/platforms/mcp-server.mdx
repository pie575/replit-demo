Replit MCP 基于 [Model Context Protocol](https://modelcontextprotocol.io/)，让你可以直接在自己惯用的 AI 工具中创建、查找、检查、更新和发布 Replit 项目。

本页是直连 MCP 客户端及其工具的参考文档。

<div id="conectar-um-cliente-mcp-diretamente">
  ## 直接连接 MCP 客户端
</div>

如果你的 MCP 客户端没有内置 Replit 集成，可使用直接连接方式。

| 属性       | 值                                   |
| -------- | ----------------------------------- |
| **URL**  | `https://replit-mcp.com/server/mcp` |
| **传输方式** | 流式 HTTP                             |
| **认证方式** | OAuth (基于受保护资源发现)                   |

将该服务器 URL 添加到支持流式 HTTP 和 OAuth 授权的 MCP 客户端中。客户端会读取 Replit 的受保护资源元数据，然后提示你登录 Replit。

无需自行搭建 OAuth 服务器，Replit MCP 服务器已提供客户端所需的 OAuth 元数据。

你可以创建 App，也可以操作你有编辑权限的 App，包括他人共享给你的 App。

<div id="configurar-o-replit-mcp">
  ### 配置 Replit MCP
</div>

Codex 和 Claude Code 只是示例，你可以将 Replit MCP 添加到任何兼容的 MCP 客户端中。

<Tabs>
  <Tab title="Codex">
    <Steps>
      <Step title="打开 MCP 列表">
        在 Codex 中，依次打开 **Settings** → **Plugins** → **MCPs**。
      </Step>

      <Step title="添加 Replit">
        添加一个自定义 MCP。使用具有描述性的名称，例如 `Replit`。选择 **Streamable HTTP**，输入 `https://replit-mcp.com/server/mcp` 并保存。请勿添加持有者令牌或自定义标头。

        </Frame>
      </Step>

      <Step title="认证 Replit">
        在 MCP 列表中启用 **Replit**，然后选择 **Authenticate**。选择要连接的 Replit workspace，然后选择 **Allow**。

<div id="ferramentas">
  ## 工具
</div>

| 工具                        | 必需输入                         | 可选输入                                                    | 用途                                                                                                                                                  |
| ------------------------- | ---------------------------- | ------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| `create_app_from_prompt`  | `appDescription`、`app_stack` | `userSpecifiedAppName`、`userQuotes`、`attachmentSummary` | 创建一个新 App。`app_stack` 可取以下值之一：`react_website`、`mobile_app`、`design`、`slides`、`animation`、`data_visualization`、`3d_game`、`document` 或 `spreadsheet`。 |
| `search_apps`             | 无                            | `query`、`url`、`updatedAfter`、`updatedBefore`、`limit`    | 按标题关键词、URL 或最后更新日期查找 App。`limit` 取值范围为 1 到 50。                                                                                                      |
| `resolve_app_by_name`     | `name`                       | 无                                                       | 按完整标题精确查找单个 App。                                                                                                                                    |
| `list_apps`               | 无                            | `query`、`limit`                                         | 列出你可编辑的 App，按最近活动排序。默认上限为 25，最大为 50。                                                                                                                |
| `ask_question`            | `replId`、`question`          | 无                                                       | 就某个 App 向 Agent 提问，而不对其做任何修改。                                                                                                                       |
| `update_app_using_prompt` | `replId`、`changeDescription` | `userQuotes`、`attachmentSummary`                        | 对现有 App 发起一次 Agent 更新。                                                                                                                              |
| `publish_app`             | `replId`                     | 无                                                       | 部署某个 App，或将其最新更改重新部署。                                                                                                                               |
| `get_publish_status`      | `replId`                     | 无                                                       | 查看某个 App 是否已部署、当前的部署状态以及公开 URL。                                                                                                                     |

<div id="soluo-de-problemas">
  ## 故障排查
</div>

| 问题               | 处理方法                                                   |
| ---------------- | ------------------------------------------------------ |
| Replit 提示你进行身份验证 | 在 MCP 客户端中重新完成一次 OAuth 登录流程。                           |
| 找不到某个 App        | 确认你有权限编辑该 App。然后按 URL 搜索，或使用 `list_apps` 从匹配的 App 中选择。 |
| 创建、更新或部署请求仍在进行中  | 请稍候再重试。若为部署，可使用 `get_publish_status` 查看当前结果。           |
