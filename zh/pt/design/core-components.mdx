Replit Design 的核心是一个展示 frame 的无限 Canvas。本页其余内容将介绍如何操作这些 frame：

* 在无限画布上生成和整理设计 frame
* 通过 Chat、建议和工具栏不断完善每个 frame
* 定位 frame 的任意部分，只修改该部分
* 无需离开画布，即可引入模板和真实产品带来的灵感

Replit Design 工作区由七个组件构成：

* **[Canvas](/zh/pt/design/canvas)**：Project Editor 的设计视图，一个可无限平移和缩放的画布，包含所有 Frame、形状和注释。
* **[Frames](/zh/pt/design/frames)**：Canvas 上的每个区块。Frame 可以是可交互的产物 (网站、幻灯片) 、设计稿、图像、视频或矢量图形。
* **[元素](/zh/pt/design/elements)**：Frame 内的各个元素，例如标题、按钮、图像和表单字段。
* **[Chat](/zh/pt/design/chat-about-your-design)**：固定在 Canvas 上的 Agent Chat。描述你想创建的内容，或选择一个 Frame 并请求小幅或大幅编辑；将其最小化，即可全屏使用 Canvas。
* **[环境智能](/zh/pt/design/explore-suggestions)**：显示在所选 Frame 旁边的后续建议，点击即可生成新的设计方向。请参阅[探索建议](/zh/pt/design/explore-suggestions)了解其工作方式。
* **[工具栏](/zh/pt/design/toolbar)**：Canvas 底部的浮动栏，包含交互、平移、Chat、绘制、编辑和生成工具。
* **[素材库面板](/zh/pt/design/library-panel)**：入门模板、由 Mobbin 精选的灵感，以及你之前创建的内容，均可随时放置到 Canvas 上。

<div id="como-eles-se-encaixam">
  ## 它们如何配合
</div>

每个组件都承接上一个组件的成果，将空白画布逐步转化为可构建的设计。

<div id="1-coloque-frames-no-canvas">
  ### 1. 在 Canvas 上放置 frame
</div>

通过 Chat 提示词或工具栏中的 **生成** 菜单生成 frame。frame 可以是设计稿、Web App、移动 App、slides、图像、视频或矢量图。

<div id="2-itere-em-um-frame">
  ### 2. 迭代优化 frame
</div>

选择任意 frame，单独对其进行处理。用自己的话描述你的想法，沿用某个[建议](/zh/pt/design/explore-suggestions)探索新的方向，或使用 **Focus** 聚焦处理。确定后，使用 **Build** 将其构建为可运行的 App。

<Frame caption="选中的 frame 及其操作栏：Build、Focus 和更多选项。">
  <img src="/assets/mirror/canvas-frame-action-bar-86f90fdd1375.png" alt="Canvas 中选中了一个 Design APEX X1 frame，顶部显示该 frame 的操作栏，包括类型标签、Build、Focus 和更多选项；该 frame 以标签形式附加到 Chat 提示词输入框中" width="2000" height="1290" data-path="images/replitai/canvas-frame-action-bar.png" />
</Frame>

<div id="3-edite-anote-ou-gere-com-a-barra-de-ferramentas">
  ### 3. 使用工具栏编辑、标注或生成
</div>

工具栏提供三项功能：**编辑**可选中 frame 中的单个元素并打开可视化编辑器；**绘制**可通过草图、箭头和便签在画布上添加标注，供 Agent 读取；**生成**可创建设计所需的图像、视频和矢量图形。

<Frame caption="使用编辑工具选中元素后，右侧会打开可视化编辑器。">
  <img src="/assets/mirror/canvas-edit-67fe5ee02fbe.png" alt="超跑租赁网站中已启用编辑工具并选中一个 div 元素，可视化编辑器面板显示文本、布局、颜色和边框控件，以及放弃和保存编辑按钮" width="2000" height="1269" data-path="images/replitai/canvas-edit.png" />
</Frame>

<div id="4-traga-inspirao-do-painel-de-biblioteca">
  ### 4. 从素材库面板汲取灵感
</div>

如需获取灵感和起点，请打开素材库面板。模板会以可编辑的活动 frame 形式添加到 Canvas；通过 Mobbin 选择的灵感会以静态参考图片的形式呈现，为你的下一次生成提供指引。
