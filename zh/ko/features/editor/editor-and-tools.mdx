Project Editor 内置了布局管理与集成工具，让应用构建体验更上一层楼。
这些 Project Editor 功能各自专注于开发流程中的特定环节，
帮助你把精力放在创作上，而不是配置上。

<div id="project-editor">
  ## 可自定义的 Project Editor 布局
</div>

使用 Project Editor 布局管理工具，你可以自定义开发环境的布局。
它由以下几类用户界面元素组成：

| 元素                     | 说明                                             | 功能                                                                  | 使用场景                                                       |
| ---------------------- | ---------------------------------------------- | ------------------------------------------------------------------- | ---------------------------------------------------------- |
| **Windows (窗口)&#x20;**&#x20;| 包含一个或多个面板的浏览器标签页                               | <ul><li>可分布在多个屏幕上整理</li></ul>                                       | <ul><li>在多个屏幕上整理 Project Editor</li><li>同时处理多个项目</li></ul> |
| **Panes (面板)&#x20;**&#x20;  | 窗口中包含一个或多个标签页的区域                               | <ul><li>支持水平和垂直拆分</li><li>可调整大小和重新排列</li><li>可在窗口内转换为浮动面板</li></ul> | <ul><li>并排查看代码和预览</li><li>为不同的开发任务创建自定义布局</li></ul>        |
| **Tabs (标签页)&#x20;**&#x20;  | 包含单个 Project Editor 工具，例如文件编辑器、Preview 或 Agent | <ul><li>可在面板之间移动，也可在面板内重新排序</li><li>只需点击一下即可切换到其他文件或工具</li></ul>    | <ul><li>按需打开其他工具或文件</li></ul>                              |

<div id="section">
  ## 文件树
</div>

文件树会列出 Replit App 中的所有文件和目录。

<Accordion title="如何访问文件树">
  选择左侧的 <img class="icon-svg" src="/assets/mirror/files-icon-f66bf1b04572.svg" alt="folder with arrows icon" width="16" height="16" data-path="images/icons/files-icon.svg" /> 文件夹图标，
  即可显示或隐藏文件树。
</Accordion>

在文件树中，你可以执行以下操作：

* 选择文件夹以查看其中的内容
* 选择文件或将其拖入面板，在文件编辑器中打开
* 执行复制、重命名、移动、下载、删除等文件操作

<div id="run">
  ## Run 按钮
</div>

**Run** 按钮用于在 Replit App 中运行所选的工作流。

<Accordion title="如何使用 Run 按钮">
  **Run** 按钮位于 Project Editor 界面顶部。点击该按钮即可运行工作流。

  当 Replit App 正在运行时，按钮标签会变为 **Stop**。点击该按钮即可停止应用。
</Accordion>

关于如何选择、查看和管理工作流，请参阅 [Workflows](/zh/ko/features/workspace-tools/workflows/)。

<div id="section-3">
  ## 选项菜单
</div>

使用选项菜单可进行以下布局操作：

* **管理窗口**：在新窗口中打开 Replit App 的 Project Editor
* **管理面板**：添加、移动或最大化面板，以及在浮动和固定位置之间切换
* **管理标签页**：打开或选择其他标签页、将标签页移至其他面板，或关闭标签页

<Accordion title="如何访问选项菜单">
  点击活动标签页右上角的 <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="垂直三点图标" height="16" width="16" data-path="images/icons/vertical-dots.svg" /> 垂直三点图标，
  即可打开选项菜单。
</Accordion>

  2. 输入搜索内容，然后从自动补全建议中选择。

<div id="section-5">
  ## 资源面板
</div>

资源面板显示开发环境的计算资源及其使用情况，包括 RAM、CPU 和存储空间。
这些信息可帮助你估算并优化 Replit App 的发布资源需求。

<Accordion title="访问资源面板">
  1. 选择应用名称旁的 <img class="icon-svg" src="/assets/mirror/resources-237893692826.svg" alt="堆叠计算机图标" width="16" height="16" data-path="images/icons/resources.svg" /> 资源图标，切换到该面板。
  2. 将鼠标悬停在 **Compute** 或 **Storage** 项目上，查看详细信息。
</Accordion>
