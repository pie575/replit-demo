<a href="https://replit.com/desktop" target="_blank">Replit 桌面应用</a>将完整的 Replit 体验带到你的电脑。在专属应用中与 Agent 一起构建，享受浏览器标签页无法提供的原生体验细节。

<div id="o-que-o-replit-desktop-app">
  ## 什么是 Replit Desktop App
</div>

Replit Desktop App 是一款专为 Windows 和 Mac 重新设计的原生应用。它与网页端体验完全一致，你可以在同一个窗口中创建应用、与 Agent 对话并发布。此外，它还带来了一些只有桌面应用才能实现的功能：

* **多任务处理**：同时处理多个 Replit App。
* **状态提示**：一眼看出 Agent 何时需要你介入，或何时完成了工作。
* **标签页预览**：无需来回切换，即可快速查看已打开的应用。

<div id="como-comear">
  ## 如何开始
</div>

<Steps>
  <Step title="下载应用">
    访问<a href="https://replit.com/desktop" target="_blank">桌面应用下载页面</a>，下载适用于你电脑的版本。
  </Step>

  <Step title="安装并打开">
    打开下载好的文件，按照提示完成安装。安装完成后启动应用。
  </Step>

  <Step title="登录">
    使用你的 Replit 账户登录；如果你是新用户，可以先注册一个账户。你构建的一切都会与 [replit.com](https://replit.com) 保持同步。
  </Step>
</Steps>

<Tip>
  你的应用、历史记录和设置在桌面应用和网页端完全一致。在一端开始，在另一端接着做。
</Tip>

<div id="para-equipes-enterprise">
  ## 面向 Enterprise 团队
</div>

桌面应用让你能够轻松地在整个组织中部署 Replit。由于它的安装方式与其他桌面应用无异，你的 IT 团队可以通过移动设备管理 (MDM) 服务商将其分发并自动安装到公司的电脑上。如需了解更多信息，请联系你的客户经理。
