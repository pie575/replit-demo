## Plataforma

### Agent v2

<img src="/assets/mirror/agent-web-01b1f9026de7.webp" alt="Agent v2" width="800" height="450" data-path="images/changelog/2025-02-28/agent-web.webp" />

Uma nova experiência do Agent está disponível para todos os criadores. Este novo Agent é mais rápido, mais preciso e mais capaz do que a versão anterior.

Agora ele é alimentado pelo Claude 3.7 Sonnet, o modelo mais avançado da Anthropic até o momento.

Você pode experimentá-lo ingressando no Programa Explorer. Veja as instruções [aqui](https://youtu.be/pE_XT2TaXCA).

### Melhorias nas implantações

Sugestões de IA agora aparecem para criadores que selecionam implantação estática para aplicativos dinâmicos, melhorando o comportamento do Agent ao lidar com solicitações de implantação.

<img src="/assets/mirror/deployments-debugger-will-now---non-static-app-220824-748b5209b50c.png" alt="Melhorias no depurador de implantações" width="1604" height="1244" data-path="images/changelog/2025-02-28/deployments-debugger-will-now---non-static-app-220824.png" />

### Lançamento do Claude 3.7 Sonnet

O modo Advanced do Assistant foi atualizado com o Claude 3.7 Sonnet para todos os criadores pagos. Isso significa maior precisão e capacidade para solicitações complexas.

<img src="/assets/mirror/50526c4ea4d114b4cd8268425398dd4ed3c2d736_bc521d9780846c35d990a72459794dd81370515f_twitter-fb2c893cd78a.jpeg" alt="Interface do Claude 3.7" width="1200" height="674" data-path="images/changelog/2025-02-28/50526c4ea4d114b4cd8268425398dd4ed3c2d736_bc521d9780846c35d990a72459794dd81370515f_twitter.jpeg" />

### Melhoria no desempenho do banco de dados

As operações de banco de dados agora são mais rápidas do que nunca, com a operação mais custosa reduzida de 200ms para menos de 1ms.

### Documentação aprimorada

<img src="/assets/mirror/cleanshot-2025-02-27-at-1042282xpng-220848-e5317a7cfb93.png" alt="Redesign da documentação" width="3680" height="2382" data-path="images/changelog/2025-02-28/cleanshot-2025-02-27-at-1042282xpng-220848.png" />

A documentação foi redesenhada para ser mais fácil de entender e usar, tornando-a completamente compatível com LLMs.

A documentação agora conta com um botão "Copiar Página", que permite copiar a página inteira como markdown. Você também pode indexar a documentação com `llms.txt` e `llms-full.txt` para usar com seus próprios LLMs.

* [https://docs.replit.com/llms.txt](https://docs.replit.com/llms.txt)
* [https://docs.replit.com/llms-full.txt](https://docs.replit.com/llms-full.txt)
