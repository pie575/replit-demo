<div id="section">
  ## 包含内容
</div>

Starter 套餐提供在 Replit 上开始构建所需的一切。创建应用并发布你的第一个项目，全部免费。

<div id="agent">
  ### Agent 每日额度
</div>

Starter 套餐用户可获得用于 Agent 的每日额度，直至达到每月上限。这些额度每天都会重置，让你每天都能获得新的 Agent 使用额度。

<div id="section-2">
  ### 云服务每月额度
</div>

你还会获得可用于以下服务的每月额度：

* [数据库 (生产环境) ](/zh/ja/features/data-and-storage/development-and-production)
* [对象存储](/zh/ja/features/data-and-storage/object-storage)
* [发布 (自动扩缩容、静态) ](/zh/ja/learn/projects-and-artifacts/replit-deployments)

这些额度每月重置。

<div id="lite">
  ### Lite构建
</div>

访问 [Lite构建](/zh/ja/features/agent/agent-modes)：一种高速、专注的构建体验，可借助 Agent 快速编辑并进行针对性修改。

<div id="1">
  ### 1 个免费已发布应用
</div>

无论您使用 Lite 构建还是设计 Canvas，均可获得 {FreeDeployments} 个免费已发布应用。该公开链接将在 30 天后自动失效。

已发布应用会显示“Made with Replit”徽章，其中包含您的专属推荐链接。升级至付费套餐后，若其他用户通过该徽章中的链接注册，您将获得推荐积分。

<div id="section-3">
  ## 限制
</div>

以下功能需升级至 Core 才能使用：

<div id="section-4">
  ### 完整构建
</div>

通过[完整构建](/zh/ja/features/agent/overview/)，Agent 可凭借更强的能力和自主性独立完成工作。Starter 套餐的构建者只能使用[Lite 构建](/zh/ja/features/agent/agent-modes)。完整构建需要 Core 或 Pro。

<div id="section-5">
  ### 将设计转换为产物
</div>

将 Canvas 中的设计转换为完整产物需要 Core。Starter 套餐的构建者可以创建和发布设计，但如需将其转换为具备后端功能的产物，则需要升级。如果你想构建具备后端功能的应用，不妨从 [Lite 构建](/zh/ja/features/agent/agent-modes) 开始。

<div id="section-6">
  ### 第三方连接器
</div>

使用外部连接器需要 Core。支持与 Google、Stripe 及其他第三方 API 集成 (详情请参阅[此处](https://docs.replit.com/features/integrations/overview#connectors)) 。

<div id="replit-ai">
  ### Replit AI 集成
</div>

[Replit AI 集成](/zh/ja/features/integrations/replit-ai-integrations)需要订阅 Core。

<div id="made-with-replit">
  ### 移除“Made with Replit”徽章
</div>

要从已发布应用中移除“Made with Replit”徽章，需订阅 Core。Starter 套餐用户部署的应用会显示该徽章。

<div id="section-7">
  ### 额外的已发布应用
</div>

Starter 套餐用户可免费获得 {FreeDeployments} 个已发布应用。若需更多已发布应用，则需要 Core 或 Pro。

<div id="plan">
  ### Plan 模式
</div>

使用 Plan 模式需要 Core。借助 Plan 模式，你可以在不编辑应用代码或数据的情况下，与 Replit Agent 围绕想法进行头脑风暴、制定工作计划并协作。

<div id="section-8">
  ### 所有产物类型
</div>

要构建 Web 应用和移动应用以外的产物类型，需要订阅 Core。您可以选择多种类型，例如数据可视化、幻灯片演示文稿和动画视频。有关详细信息，请参阅[项目](/zh/ja/features/projects-and-artifacts/projects)。

<div id="core">
  ## 升级到 Core
</div>

需要更多功能？升级到 Core，解锁以下权益：

* 更多存储空间和每月额度，并支持按量付费
* **无限数量的已发布应用**，不再仅限于首个免费应用
* 用于自主开发的**完整构建**
* 用于连接外部服务的**第三方连接器**
* **Replit AI 集成**，无需管理自己的 API 密钥即可使用 AI 模型
* 在开始构建前用于规划任务的 **Plan 模式**
* 移除 **Replit 徽章**，打造更专业的外观
* 以及更多功能
