<div id="controles-de-layout-no-editor-visual">
  ### Contrôles de mise en page dans l&#39;Éditeur visuel
</div>

L&#39;Éditeur visuel dispose désormais de contrôles de **Mise en page** dédiés qui vous permettent d&#39;ajuster la disposition flexbox visuellement, sans demander à Agent de réécrire les styles. Sélectionnez n&#39;importe quel conteneur, développez la section Mise en page, puis choisissez une direction flex, un alignement et une justification. Définissez un espacement en pixels entre les éléments ou activez le bouton **Espace entre** pour repousser les éléments enfants vers les bords opposés.

Le panneau de l&#39;éditeur a également été réorganisé en sections plus claires : **Texte**, **Image**, **Mise en page**, **Couleur** et **Bordure**, afin de trouver plus facilement le contrôle recherché.

<div id="configuraes-do-agent-permanecem-suas-em-projetos-compartilhados">
  ### Les paramètres de l&#39;Agent restent les vôtres dans les projets partagés
</div>

Vos préférences d&#39;Agent, comme le niveau de modèle, le mode planification, la fusion automatique et l&#39;approbation automatique du plan, sont désormais liées à votre compte plutôt que partagées avec toutes les personnes du projet. Si un coéquipier passe en mode Power pour ses propres tâches, vos paramètres ne changent plus pour autant. Le paramètre que vous choisissez est celui qu&#39;utilise l&#39;Agent lorsque vous envoyez votre message suivant, même dans les projets comptant de nombreux collaborateurs.

En savoir plus sur les [modes de l&#39;Agent](/fr/pt/features/agent/agent-modes#settings-in-shared-projects).

<div id="agent-sugere-modo-power-quando-voc-est-travado">
  ### Agent suggère le mode Power lorsque vous êtes bloqué
</div>

Lorsque Agent détecte que vous butez sur le même problème à répétition en mode Economy, il vous propose désormais de passer en mode Power dès votre message suivant. La suggestion se déclenche en cas de demandes répétées ou de code qui échoue en boucle, et n&#39;apparaît qu&#39;une seule fois au maximum par projet. Agent n&#39;affiche pas cette suggestion pendant les sessions de planification, lorsque vous avez déjà évoqué une contrainte de budget ou lorsque vous êtes sur le plan gratuit.

<div id="menu-suspenso-de-configuraes-de-tarefas-mais-limpo">
  ### Menu déroulant des paramètres des tâches plus épuré
</div>

Le menu déroulant qui s’ouvre dans l’en-tête d’une tâche est désormais plus facile à utiliser. Le titre de la tâche active ou de la planification apparaît désormais en haut, avec la possibilité de le renommer directement. Les paramètres d’automatisation (appliquer automatiquement, approuver automatiquement) disposent de leur propre section entre le titre et les actions, et le popover a une largeur fixe pour éviter qu’il ne se déplace lorsque les noms des tâches changent. Les options d’automatisation désactivées sont masquées afin que le menu n’affiche que celles qui s’appliquent à la tâche actuelle.

<div id="dois-novos-conectores-quiver-ai-e-browserbase">
  ### Deux nouveaux connecteurs : Quiver AI et Browserbase
</div>

Deux nouveaux services sont désormais disponibles dans le catalogue de connecteurs. Ouvrez le panneau **Intégrations** et sélectionnez **Ajouter une nouvelle intégration** pour connecter l&#39;un ou l&#39;autre.

* **Quiver AI** : générez des illustrations SVG et vectorisez des images matricielles via une API gérée. Utile lorsque Agent a besoin d&#39;une ressource SVG propre à la demande.
* **Browserbase** : exécutez des navigateurs headless gérés pour la recherche, l&#39;exploration et l&#39;automatisation complète de sessions. Utile lorsque Agent doit charger une véritable page web, exécuter du JavaScript ou interagir avec un site qui bloque les simples requêtes HTTP.
