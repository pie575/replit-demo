Agent Customization을 사용하면 Agent가 첫 prompt부터 여러분과 팀의 작업 방식에 맞춰 일하는 데 필요한 context를 갖추게 됩니다. project마다 conventions를 다시 설명할 필요 없이, workspace에 한 번만 정의해 두면 Agent가 모든 곳에 적용합니다.

Agent Customization은 두 부분으로 구성됩니다.

* **Custom instructions**: workspace의 모든 project에 적용되는 상시 활성 지침입니다.
* **Skills**: 관련 task가 있을 때만 Agent가 불러오는 재사용 가능한 지침입니다.

둘 다 **Workspace Settings → Customization**에서 관리합니다.

<div id="custom-instructions-vs-skills">
  ## Custom instructions와 skills 비교
</div>

Custom instructions는 모든 메시지마다 로드되지만, skills는 Agent가 해당 task에 필요하다고 판단할 때만 로드됩니다. 항상 적용되는 소수의 지침에는 custom instructions를 사용하고, 특정 workflows나 conventions, 참고 자료에는 skills를 사용하세요.

이렇게 나누는 이유, 즉 context 예산과 어떤 내용을 어디에 두어야 하는지, skills를 잘 작성하는 방법은 [Agent skills](/ko/learn/agent-skills)를 참조하세요. skills의 구조와 Agent가 이를 로드하는 방식은 [Agent Skills](/ko/features/agent/skills)를 참조하세요.

<div id="custom-instructions">
  ## Custom instructions
</div>

Custom instructions는 누군가 prompt를 입력하기 전에 모든 project와 모든 session에서 Agent의 context에 미리 주입되는 상시 지침입니다. Workspace Settings에서 한 번만 작성해 두면 Agent가 workspace 전체에서 이를 적용합니다. 보안 및 규정 준수 requirements, 승인된 라이브러리와 프레임워크, 데이터 처리 정책처럼 항상 유효한 지침을 담기에 가장 적합합니다.

내용은 짧게 유지하세요. 초점이 분명하고 구체적인 지침일수록 더 정확하게 지켜지고, Agent가 실제 작업에 쓸 여유도 더 많아집니다.

<Warning>
  Custom instructions는 Agent 성능에 영향을 줄 수 있습니다. Agent가 이를 따르도록 유도되기는 하지만, 엄격한 requirements의 준수까지 보장되지는 않습니다. 짧고 구체적인 지침일수록 더 안정적으로 지켜집니다.
</Warning>

<Note>
  Workspace custom instructions는 project의 `custom_instruction/instructions.md` 파일과는 다릅니다. Workspace custom instruction은 Workspace Settings에서 한 번 설정하면 모든 project에 적용됩니다. project별 파일은 개별 project 내부에 존재합니다 — 이 방식은 [Create a custom design system](/ko/teams/custom-design-system)을 참고하세요.
</Note>

<div id="skills">
  ## Skills
</div>

skill은 관련 task가 있을 때만 Agent가 불러오는 재사용 가능한 지침 모음입니다. workspace skill은 workspace 내 모든 project의 **+** 메뉴 상단에 표시되므로 팀 전체가 동일한 skill 모음을 공유할 수 있습니다.

skill을 만드는 방법은 세 가지입니다:

* 기존 skill 폴더를 **업로드**합니다.
* 양식에서 새 skill을 직접 **작성**합니다.
* **Agent에게 요청**해 skill 초안을 받은 뒤 다듬습니다.

<Note>
  Agent가 작성한 Skills를 Workspace에 업로드할 수 있습니다. Agent에게 skill을 다운로드해 달라고 요청하세요. 그러면 Agent가 해당 skill을 다운로드 가능한 `.zip` 아카이브로 패키징하고 **Download file** 버튼(아래 참고)을 함께 표시합니다. zip 파일을 다운로드한 다음 **Workspace Settings → Customization → Skills**에서 **Create skill → Choose file or folder**로 다시 업로드하면 workspace 전체에 공유됩니다.
</Note>

<Frame>
  <img src="/assets/mirror/agent-customization-download-skill-3727b188c5a8.png" alt="Agent가 workspace skill을 다운로드 가능한 ux-designer-skill.zip 아카이브로 패키징했으며 Download file 버튼이 표시된 화면" width="1716" height="864" data-path="images/replitai/agent-customization-download-skill.png" />
</Frame>

skill의 전체 구조(`SKILL.md`, 지원 파일, 개방형 표준)는 [Agent Skills](/ko/features/agent/skills)를 참고하세요. Replit과 파트너가 이미 만들어 둔 skill을 둘러보려면 [Skills directory](/ko/features/agent/skills-directory)를 확인하세요.

<Note>
  skill은 꼭 필요한 만큼만 사용하세요. Agent는 task마다 모든 skill의 이름과 설명을 읽기 때문에, skill이 너무 많거나 서로 겹치면 집중도가 떨어지고 알맞은 skill을 고르기 어려워질 수 있습니다. 각 skill의 범위를 좁게 유지하고, 더 이상 필요하지 않은 skill은 삭제하세요.
</Note>

<div id="availability-and-permissions">
  ## 제공 범위 및 권한
</div>

| 기능                  | 사용 가능 플랜         | 관리 가능 대상                                      |
| ------------------- | ---------------- | --------------------------------------------- |
| Custom instructions | Pro 및 Enterprise | Enterprise: 관리자. Pro: 모든 workspace 구성원        |
| Skills              | 모든 유료 plan       | Enterprise: 관리자. Core 및 Pro: 모든 workspace 구성원 |

Enterprise workspace에서는 관리자만 custom instructions와 skills를 생성, 편집, 삭제할 수 있습니다. Pro workspace에서는 모든 workspace 구성원이 이 작업을 할 수 있습니다. Core workspace에서는 모든 구성원이 skills를 관리할 수 있으며, custom instructions는 Core에서 제공되지 않습니다. 어느 경우든 workspace의 모든 구성원은 생성된 skills를 사용할 수 있습니다.

<div id="create-a-custom-instruction">
  ## Custom instruction 만들기
</div>

<Steps>
  <Step title="Workspace Settings 열기">
    **Workspace Settings → Customization**으로 이동합니다.

    <Frame>
      <img src="/assets/mirror/agent-customization-tab-930af2e8ed74.png" alt="Skills 및 Custom instructions 하위 탭이 표시된 Workspace Settings의 Customization 탭" width="1065" height="394" data-path="images/replitai/agent-customization-tab.png" />
    </Frame>
  </Step>

  <Step title="Instruction 작성하기">
    **Custom instructions** 섹션에 Agent가 모든 project에 적용했으면 하는 지침을 작성합니다.
  </Step>

  <Step title="저장하기">
    변경 사항을 저장합니다. 작성한 instruction은 workspace에서 새로 만드는 project에 적용됩니다.
  </Step>
</Steps>

<div id="create-a-skill">
  ## skill 만들기
</div>

<Steps>
  <Step title="Workspace Settings 열기">
    **Workspace Settings → Customization**으로 이동합니다.
  </Step>

  <Step title="skill 만들기">
    **Skills** 섹션에서 **Create skill**을 클릭한 다음, skill 폴더를 업로드하거나 지침을 직접 작성하거나 Agent에게 초안 작성을 요청하세요.

    <Frame>
      <img src="/assets/mirror/agent-customization-create-skill-fcb794e6de4e.png" alt="Skills 및 Custom instructions 하위 탭과 skill 만들기 양식이 열려 있는 Workspace Settings의 Customization 탭" width="2168" height="1350" data-path="images/replitai/agent-customization-create-skill.png" />
    </Frame>
  </Step>

  <Step title="명확한 설명 작성하기">
    언제 사용해야 하고 언제 사용하지 말아야 하는지가 분명히 드러나도록 skill 설명을 작성하세요. Agent는 이 설명을 읽고 해당 skill을 적용할지 판단합니다.
  </Step>

  <Step title="저장하기">
    skill을 저장합니다. 저장한 skill은 workspace의 모든 project에서 **+** 메뉴를 통해 사용할 수 있습니다.
  </Step>
</Steps>

<div id="use-a-workspace-skill-in-a-project">
  ## project에서 workspace skill 사용하기
</div>

Skill 설명을 명확하게 작성하는 것이 중요합니다. Agent는 모든 workspace skill의 설명을 읽고, prompt가 해당 skill의 용도와 대략적으로 일치하면 자동으로 불러옵니다. 따라서 매번 직접 skill을 고를 필요는 없습니다. 특정 skill이 확실히 적용되기를 원한다면 직접 선택할 수도 있습니다.

수동으로 선택하려면 다음과 같이 진행하세요.

<Steps>
  <Step title="skill 선택기 열기">
    project에서 채팅 입력창 옆의 **+** 버튼을 클릭하세요. workspace skill이 맨 위에 그룹으로 묶여 표시됩니다.

    <Frame>
      <img src="/assets/mirror/agent-customization-skill-picker-4643f3a453c7.png" alt="+ 버튼에서 열린 skill 선택기로, Replit skills 위에 Workspace skills 그룹이 표시된 모습" width="1668" height="1170" data-path="images/replitai/agent-customization-skill-picker.png" />
    </Frame>
  </Step>

  <Step title="skill 선택하기">
    활성화할 skill을 선택하세요. `/` 뒤에 skill 이름을 입력해 바로 호출할 수도 있습니다.
  </Step>

  <Step title="계속 prompt 작성하기">
    평소처럼 계속 진행하세요. 작업이 skill 설명과 일치하면 Agent가 해당 skill을 사용합니다.
  </Step>
</Steps>

<div id="manage-instructions-and-skills">
  ## instructions 및 skills 관리
</div>

모든 관리는 **Workspace Settings → Customization**에서 이루어집니다. 여기에서 custom instruction을 편집할 수 있고, skill은 편집, 비활성화, 삭제가 모두 가능합니다. 변경 사항은 이미 진행 중인 채팅에는 적용되지 않고 이후의 채팅부터 적용됩니다.
