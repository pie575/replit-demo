<div id="workspace-pessoal-vs-workspace-de-equipe">
  ## Workspace personnel ou workspace d’équipe
</div>

Un **workspace** est la structure qui organise vos apps, vos membres, vos paramètres et votre facturation. Replit propose deux types :

* Workspace personnel
* Workspace d’équipe

Voici les différences entre les workspaces personnels et d’équipe :

|                         | Workspace personnel                                | Workspace d’équipe                                    |
| ----------------------- | -------------------------------------------------- | ----------------------------------------------------- |
| **Rôles**               | Admin, invités au niveau du projet                 | Admin, membres, invités au niveau du projet           |
| **Modèle d’accès**      | Vous invitez des invités à des projets individuels | Les membres ont accès à tous les projets du workspace |
| **Facturation**         | Votre compte                                       | Crédits regroupés du compte de l’admin                |
| **Gestion des membres** | Par projet (liens pour rejoindre)                  | Centralisée dans les paramètres du workspace          |

Le **workspace personnel** est préférable lorsque vous travaillez seul ou partagez des projets individuels avec d’autres personnes. Vous êtes le seul admin, et les autres ne peuvent accéder qu’aux projets spécifiques auxquels vous les avez invités en tant qu’invités au niveau du projet.

Le **workspace d’équipe** est préférable lorsque vous travaillez avec un groupe stable — une équipe de start-up, une classe ou un projet client impliquant plusieurs collaborateurs. Les membres ont accès à tous les projets du workspace, vous n’avez donc pas besoin de les inviter un par un à chaque projet. Les membres sont gérés de manière centralisée dans les **Paramètres**.

<div id="quando-convidar-para-o-workspace-vs-para-um-projeto">
  ### Quand inviter dans le workspace ou dans un projet
</div>

| Scénario                                               | Action à effectuer                                   |
| ------------------------------------------------------ | ---------------------------------------------------- |
| Collaborateur régulier ayant besoin d’accéder à tout   | Inviter dans le workspace                            |
| Prestataire ou invité n’ayant besoin que d’un projet   | [Inviter dans le projet](/fr/pt/build/invite-teammates) |
| Nouveau membre de l’équipe rejoignant votre entreprise | Inviter dans le workspace                            |
| Ami aidant à déboguer une app spécifique               | [Inviter dans le projet](/fr/pt/build/invite-teammates) |

<div id="criar-um-workspace-de-equipe">
  ## Créer un workspace d&#39;équipe
</div>

<Frame>
  <video autoPlay muted loop playsInline>
    <source src="/assets/mirror/create_new_team_workspace-f665bec18450.mp4" type="video/mp4" />
  </video>

<Steps>
  <Step title="Ouvrez le sélecteur de workspace">
    Sur la page d&#39;accueil, cliquez sur le nom de votre workspace dans le coin supérieur gauche.
  </Step>

  <Step title="Créez un nouveau workspace">
    Sélectionnez **Créer un workspace**, puis choisissez un nom pour votre workspace d&#39;équipe.
  </Step>

  <Step title="Invitez des membres">
    Saisissez une ou plusieurs adresses e-mail, séparées par des virgules, dans le champ d&#39;invitation. Les invités reçoivent une invitation et ont accès à tous les projets du workspace dès qu&#39;ils l&#39;acceptent.
  </Step>
</Steps>

<div id="gerenciando-membros">
  ## Gérer les membres
</div>

Si vous n’avez pas invité de membres lors de la configuration ou si vous devez en ajouter ultérieurement, accédez aux **Paramètres** de votre workspace d’équipe et invitez des membres par e-mail ou nom d’utilisateur Replit.

<Frame>
  <video autoPlay muted loop playsInline>
    <source src="/assets/mirror/add_team_to_workspace_compressed-41d8163607d2.mp4" type="video/mp4" />
  </video>
</Frame>

Sur la page **Paramètres**, vous pouvez également :

* **Supprimer des membres** pour révoquer leur accès à tous les projets du workspace
* **Transférer des apps** de workspaces personnels vers le workspace d’équipe — consultez [Transférer une app vers Teams](/fr/pt/teams/identity-and-access-management/transfer-app-to-teams)

Pour une gestion avancée des identités, un contrôle d’accès basé sur les rôles et des autorisations de groupe, consultez [Teams](/fr/pt/category/teams).
