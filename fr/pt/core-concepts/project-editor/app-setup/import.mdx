La fonctionnalité d&#39;importation vous permet d&#39;intégrer du code ou des designs existants à vos Replit Apps et de poursuivre le développement avec Agent.

<div id="fontes-suportadas">
  ## Sources prises en charge
</div>

| Source                       | Ce que vous fournissez                               | Idéal pour                                                      |
| ---------------------------- | ---------------------------------------------------- | --------------------------------------------------------------- |
| GitHub                       | URL du dépôt ou sélecteur de dépôts                  | Importations de dépôts publics et privés                        |
| Bitbucket                    | URL du dépôt ou sélecteur de dépôts                  | Importations de dépôts hébergés sur Bitbucket                   |
| Vercel                       | Dépôt GitHub lié à votre projet Vercel               | Migration d&#39;apps depuis Vercel                              |
| Figma                        | URL du frame                                         | Transformer des designs en apps React                           |
| Bolt                         | Dépôt GitHub exporté depuis Bolt                     | Migration de projets Bolt                                       |
| Lovable                      | Dépôt GitHub exporté depuis Lovable                  | Migration de projets Lovable                                    |
| Base44                       | Dépôt GitHub exporté depuis Base44                   | Migration de projets Base44                                     |
| ZIP                          | Téléversement d&#39;un fichier `.zip`                | Importation de fichiers de projets locaux                       |
| Feuille de calcul            | Fichier `.xlsx`, `.csv` ou URL de Google Sheets      | Création d&#39;une app à partir de données de feuille de calcul |
| Exportation précédente Agent | Dépôt GitHub exporté depuis une précédente App Agent | Réimportation d&#39;une précédente App Agent                    |
| Vide                         | Rien                                                 | Utilisateurs avancés souhaitant un projet vierge sans Agent     |

<Note>Replit valide la compatibilité avant de démarrer l&#39;importation.</Note>

<div id="fluxo-de-importao-padro">
  ## Processus d’importation standard
</div>

1. Ouvrez [replit.com/import](https://replit.com/import).
2. Sélectionnez une source d’importation.
3. Connectez les comptes requis.
4. Fournissez l’URL d’un dépôt, l’URL d’un frame ou un fichier `.zip`.
5. Ajoutez les secrets ou variables d’environnement demandés.
6. Sélectionnez **Importer** et consultez l’application générée.

<div id="notas-sobre-as-fontes">
  ## Notes sur les sources
</div>

<div id="github">
  ### GitHub
</div>

* Utilisez l&#39;importation rapide pour les dépôts publics avec `https://replit.com/github.com/<owner>/<repo>`.
* Utilisez l&#39;importation guidée pour les dépôts publics et privés.
* Si votre dépôt est une App Agent exportée, Replit préserve la structure propre à Agent lors de l&#39;importation.

<div id="bitbucket">
  ### Bitbucket
</div>

* Collez l&#39;URL d&#39;un dépôt Bitbucket ou connectez votre compte Bitbucket pour rechercher vos dépôts.
* La prise en charge par Agent lors de l&#39;importation peut être limitée par rapport aux projets hébergés sur GitHub.

<div id="figma">
  ### Figma
</div>

* Importez une seule URL de frame Figma.
* Replit génère le code React et l&#39;Agent vous aide à l&#39;affiner.
* Pour de meilleurs résultats, utilisez des frames, la disposition automatique et des noms de calques explicites.

<div id="vercel">
  ### Vercel
</div>

* Sélectionnez le dépôt GitHub lié à votre projet Vercel.
* Replit importe le code du projet ainsi que la configuration par défaut.
* Ajoutez les valeurs des variables d&#39;environnement lors de l&#39;importation.

<div id="bolt">
  ### Bolt
</div>

* Exportez votre projet Bolt vers GitHub avant de l&#39;importer.
* Replit importe le code, les styles d&#39;interface, les assets, la logique backend (le cas échéant) et le schéma de base de données (le cas échéant).
* Les données Supabase et les valeurs des secrets ne sont pas importées.
* Après l&#39;importation, demandez à Agent d&#39;ajouter les secrets et de recréer les données de la base de données.

<div id="lovable">
  ### Lovable
</div>

* Exportez votre projet Lovable vers GitHub avant de l&#39;importer.
* Replit importe le code, les styles d&#39;interface, les assets, la logique backend (si elle est présente) et le schéma de base de données (s&#39;il est présent).
* Les données Supabase et les valeurs des secrets ne sont pas importées.
* Après l&#39;importation, demandez à Agent d&#39;ajouter les secrets et de recréer les données de la base de données.

<div id="base44">
  ### Base44
</div>

* Exportez votre projet Base44 vers GitHub avant de l&#39;importer.
* Replit importe le code, le design et les styles, les assets ainsi que la logique d&#39;API.
* Le backend de Base44 (entités, agents, SDK), l&#39;authentification et les données ne sont pas importés.
* Une fois l&#39;importation terminée, demandez à Agent de migrer les fonctionnalités propres à Base44 dont vous avez encore besoin.

<div id="zip">
  ### ZIP
</div>

* Téléversez un fichier `.zip` dont la racine du projet est clairement structurée.
* Replit importe les fichiers, les dépendances et les schémas d&#39;exécution courants.
* Les valeurs des secrets existants, les domaines et les données des bases de données ne sont pas importés.

<div id="planilha">
  ### Feuille de calcul
</div>

* Téléversez un fichier Excel (`.xlsx`) ou CSV, ou collez l&#39;URL publique d&#39;un Google Sheets.
* Agent analyse la structure de votre feuille de calcul et crée une app full-stack dotée d&#39;une base de données pré-remplie avec vos données.
* Comprend une interface pour consulter, rechercher et gérer vos enregistrements.

<div id="exportao-anterior-do-agent">
  ### Exportation antérieure d&#39;Agent
</div>

* Réimportez une App Agent précédemment exportée depuis un dépôt GitHub.
* Replit conserve la structure propre à Agent (code, schéma de base de données, fonctionnalités du backend).
* Les valeurs de la base de données et celles des secrets ne sont pas importées.

<div id="vazio">
  ### Vide
</div>

* Démarrez avec un projet entièrement vide — sans Agent, sans sélection de framework et sans scaffolding.
* Idéal pour les utilisateurs avancés qui souhaitent garder un contrôle total sur la configuration du projet.

<div id="limitaes">
  ## Limitations
</div>

* Les données existantes de la base de données ne sont pas migrées.
* Certaines dépendances complexes ou propriétaires peuvent nécessiter une configuration manuelle.
* Le traitement des projets volumineux peut prendre plus de temps.

<div id="boas-prticas">
  ## Bonnes pratiques
</div>

* Supprimez les identifiants sensibles avant l&#39;importation.
* Conservez une structure de projet source bien organisée.
* Vérifiez les dépendances et les commandes d&#39;exécution après l&#39;importation.
* Testez les principaux parcours avant de publier.

<div id="soluo-de-problemas">
  ## Résolution des problèmes
</div>

Si l&#39;importation échoue, vérifiez d&#39;abord ces points :

* **Erreurs de compatibilité** : vérifiez les fichiers de projet requis et les frameworks pris en charge.
* **Erreurs d&#39;accès** : vérifiez les autorisations du dépôt ou de la source.
* **Erreurs de traitement** : réessayez après avoir simplifié la structure du projet ou réduit sa taille.

Si les problèmes persistent, consultez le [Replit Community Hub](https://replit.com/community) ou [contactez l&#39;assistance](https://replit.com/support).

<div id="faturamento">
  ## Facturation
</div>

Les importations qui nécessitent un travail de migration par Agent peuvent consommer des crédits. La consommation de crédits dépend de la complexité du projet.
