これらの回答はプランと料金をカバーしています。プランの詳細については、[Starter](/ja/billing/plans/starter-plan)、[Core](/ja/billing/plans/replit-core)、[Pro](/ja/billing/plans/replit-pro)をご覧ください。現在の料金については[料金ページ](https://replit.com/pricing)をご確認ください。

<AccordionGroup>
  <Accordion title="Agent の使用量はどのように料金設定されていますか？また、Plan モードで課金されるのはなぜですか？">
    Free Modeは CoreおよびProサブスクリプションに含まれる特典です。許容量の範囲内でAgent作業を無料で提供します。許容量は5時間ごとにリセットされ、週次の上限があります。**設定 → 使用量**で使用状況を確認できます。これは単独の無料プランではなく、Starterティアは既存の上限を維持します。

    有料モードおよび確定した有料作業は、リクエストの複雑さに基づく[エフォートベースの料金](/ja/billing/ai-billing)を使用します。有料パスでは、Planモードはコードを変更しない場合でも課金対象の推論を実行できます。Replitは有料アクションが開始する前に確認を求めます。

    日常の作業には[Free Mode](/ja/features/agent/agent-modes)から始めてください。より高い機能が必要な場合は[Power モード](/ja/features/agent/agent-modes)を選択してください。[Plan モード](/ja/features/agent/plan-mode)で作業をスコープし、[支出の管理](/ja/billing/managing-spend)で使用制限と予算を設定することもできます。請求の内訳を確認するには、**設定 → アカウントの使用状況**を開き、**過去の請求書を見る**を選択してください。
  </Accordion>

  <Accordion title="各プラン（Starter、Core、Pro）には何が含まれていますか？">
    各プランはビルドの異なる段階を対象としています:

    * **Starter** は無料で、1 日の Agent 利用枠と限られた月次クラウドクレジット、基本的な Agent アクセス、公開アプリ 1 つが含まれます。[Starter プラン](/ja/billing/plans/starter-plan)をご覧ください。
    * **Core** には毎月 {CoreCredits} のクレジット、Plan モードと Build モードを含む完全な Agent、最大 5 名のコラボレーター、無制限の公開アプリ、7 日間のデータベースリストアウィンドウが含まれます。[Core プラン](/ja/billing/plans/replit-core)をご覧ください。
    * **Pro**（{ProPlanPrice}/月）は、Turbo モード、プールされたクレジットを持つ最大 15 名のビルダー、段階的クレジット、28 日間のデータベースリストアウィンドウが追加されます。未使用のクレジットは{ProCreditRolloverPeriod}繰り越されます。[Pro プラン](/ja/billing/plans/replit-pro)をご覧ください。

    並べて比較して現在の料金を確認するには、[料金ページ](https://replit.com/pricing)をご覧ください。
  </Accordion>

  <Accordion title="Replit は学生や教育機関向けの割引を提供していますか？">
    Replit は学生と教育者向けの教育プログラムを運営しています。現在の資格、割引内容、申し込み方法については、[replit.com/education](https://replit.com/education)をご覧ください。

    <Note>具体的な割引率と資格基準は教育プログラムが管理しており、変更される可能性があります—教育ページが信頼できる情報源です。</Note>
  </Accordion>

  <Accordion title="年間課金はどのように機能し、どのくらい節約できますか？">
    年間課金では、1 年分を前払いする代わりに実質的な月額料金が低くなります。[Core](/ja/billing/plans/replit-core) は {CoreAnnualPrice}/年です。切り替えるには、サブスクリプション時またはプラン変更時に年間オプションを選択してください。他のプランの現在の節約額については、[料金ページ](https://replit.com/pricing)をご覧ください。
  </Accordion>

  <Accordion title="未使用の月次クレジットは翌月に繰り越されますか？">
    プランによって異なります。Core のクレジットは各課金サイクルの開始時にリセットされ、繰り越しはありません。Pro には[クレジットロールオーバー](/ja/billing/plans/replit-pro)が含まれており、未使用のクレジットは有効期限切れになる前に{ProCreditRolloverPeriod}繰り越されます。

    残高が月次割り当てよりも高い場合、その差額は紹介クレジットまたはプロモーションクレジットである可能性があり、それぞれの有効期限があります。
  </Accordion>

  <Accordion title="追加クレジット（クレジットパック）を購入するにはどうすればよいですか？">
    クレジットパックは月次割り当てにクレジットを追加し、大きいパックほど割引があります:

    <CreditPackTable />

    **設定 → アカウントの使用状況**を開き、クレジットパックを購入するオプションを選択してください。クレジットは Agent の使用、デプロイメント、ストレージ、その他の使用量ベースのサービスに適用されます。詳細については、[支出の管理](/ja/billing/managing-spend#purchase-credit-packs)をご覧ください。

    App Store でサブスクリプションを登録した場合は、まずアカウントにウェブの支払い方法を追加してください。
  </Accordion>

  <Accordion title="Core または Pro の無料トライアルはありますか？">
    Replit は有料プランの期間限定無料トライアルを提供していませんが、まず Replit を試すオプションがあります:

    * [Starter プラン](/ja/billing/plans/starter-plan)は期間制限なしで無料です。
    * [教育プログラム](https://replit.com/education)は資格のある学生に割引アクセスを提供しています。

    現在のサブスクリプション返金条件については、[Replit サポートにお問い合わせ](https://replit.com/support)ください。
  </Accordion>

  <Accordion title="サイクル途中でアップグレードした場合、日割り計算はどのように行われますか？">
    サイクル途中でプランを変更すると、Replit は現在のプランの未使用分を新しいプランのコストに充当します。正確な日割り額は変更を完了する前に課金確認画面に表示されるため、課金前に確認できます。
  </Accordion>
</AccordionGroup>
