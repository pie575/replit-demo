  ## Обновления платформы
</div>

<div id="xai">
  ### Интеграция xAI
</div>

Теперь Agent может напрямую добавлять xAI в ваше приложение.

<Frame>
  <img src="/assets/mirror/xai-announce-232aa8bf6428.jpeg" alt="Анонс интеграции xAI" width="3840" height="2160" data-path="images/changelog/2025-01-03/xai-announce.jpeg" />
</Frame>

Добавьте Grok в проект и опубликуйте его за несколько секунд. Просто напишите в промпте: «Добавь ИИ-функции с помощью xAI» — или выберите xAI в списке интеграций, и Agent создаст всё через API.

<Frame>
  <img src="/assets/mirror/xai-in-product-a0102e19b327.jpeg" alt="xAI в продукте" width="1120" height="1120" data-path="images/changelog/2025-01-03/xai-in-product.jpeg" />
</Frame>

В Agent появится ещё больше ваших любимых интеграций.

<div id="section-3">
  ### Обработка ошибок для пользовательских доменов
</div>

Теперь при сбое проверки пользовательского домена отображаются конкретные сообщения об ошибках, что позволяет быстрее устранять неполадки.

<div id="section-4">
  ### Поиск по меню
</div>

Теперь вы можете искать пункты меню на боковой панели Replit App.

<div id="neon">
  ### Улучшения баз данных Neon
</div>

Интеграция с базами данных Neon оптимизирована. Базы данных, добавленные с помощью Agent, стали более экономичными и производительными.

<div id="react">
  ### React по умолчанию
</div>

В шаблонах по умолчанию для новых фронтенд-приложений Replit App теперь используется React. Ваши проекты с самого начала будут выглядеть современно и сразу работать.

<div id="replit-teams">
  ### Вход в Replit Teams
</div>

Мы обновили процесс входа в Teams, чтобы вам было проще начать работу. Новый интерфейс входа включает страницу выбора команды, а для клиентов Teams улучшено переключение между аккаунтами.
