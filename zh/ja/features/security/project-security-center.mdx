项目安全中心是发现并修复 Replit App 安全与隐私漏洞的统一入口。在项目的 **Tools** 窗格中选择 **Security Center**，即可运行扫描、查看扫描结果，并将你确认的问题作为修复请求发送给 Agent。

<Note>
  如果你刚接触依赖项安全，请参阅[安全概念](/zh/ja/features/security/concepts)，了解 CVE、SBOM、暴露程度、使用 Agent 修复、重新发布以及 Auto-Protect 的定义。
</Note>

<div id="section-2">
  ## 自动依赖项扫描
</div>

自动依赖项扫描会将项目中的软件包与公开的漏洞记录进行比对。这些扫描免费且自动运行。当新的 CVE (Common Vulnerabilities and Exposures，通用漏洞披露) 条目公布时，Replit 会将其与项目的依赖项进行比对，并将匹配结果显示在 **Security** 面板中，无需手动重新扫描。

依赖项扫描支持 Node.js/npm、Python、Go、Rust、PHP 和 Ruby。

自动依赖项修复目前主要面向 Node.js/npm。

<div id="auto-protect">
  ### Auto-Protect
</div>

Auto-Protect 是自动依赖项扫描的扩展功能。当检测到匹配的漏洞时，Agent 会准备并测试补丁，然后向你发送一封附带直达链接的邮件。补丁会停留在 **Security** 面板中等待审核。应用补丁后，请重新发布应用，使修复生效于生产版本。

Auto-Protect 仅覆盖依赖项中的 CVE。如需审核应用程序代码，请使用 [Agent 安全扫描](/zh/ja/features/security/agent-security-scans)。

两项 Auto-Protect 设置默认均为关闭状态：

<Steps>
  <Step title="启用补丁准备">
    workspace 管理员前往 **Settings** &gt; **Account** &gt; **Advanced**，
    选择 Replit 需要准备修复的最低严重程度 (低、中、高或严重) 。
  </Step>

  <Step title="启用安全邮件">
    前往 **Settings** &gt; **Personalization** &gt; **Email Notifications**，
    选择希望接收通知的最低严重程度。
  </Step>
</Steps>

对于每个新发现的漏洞，Replit 在每个 workspace 中最多发送一封邮件，并汇总列出所有受影响的项目。选择 **Go to Task**，即可在应用补丁前查看 Agent 准备好的内容。应用补丁后，在你发布新版本之前，该漏洞会显示为**等待重新发布**。

<Note>
  Agent 准备的修复与其他 Agent 工作一样计费，即使是由 Auto-Protect 主动准备的也不例外。
</Note>

<div id="section-3">
  ## 查看检测结果
</div>

安全检测结果显示在 **Security** 面板中，并按严重程度分组：

| 严重程度   | 处理建议             |
| ------ | ---------------- |
| 严重     | 需在发布前处理的紧急风险     |
| 高      | 在特定条件下可能被利用的重大问题 |
| 中      | 被利用可能性较低的潜在风险    |
| 低 / 信息 | 轻微问题或最佳实践建议      |

在批准、修复或忽略之前，请逐条查看检测结果。将已批准的问题作为修复请求发送给 Agent，应用修复后再重新运行相应的扫描。

<div id="section-4">
  ## 开发过程中与发布时的安全检查
</div>

<div id="section-5">
  ### 构建过程中的安全扫描
</div>

在使用 Agent 构建时，Replit 会自动检查 Agent 修改过的文件，查找常见的不安全模式和硬编码的敏感信息。这是 Agent 工作流中一项早期的轻量级检查，并非对整个代码库的全面审查。检查结果不会作为单独的报告显示在 **Security** 面板中。

<div id="section-6">
  ### 发布检查
</div>

Replit 在发布前同样会执行安全扫描。**Block publishing of critical vulnerabilities** 设置决定了扫描发现严重问题时的处理方式：

* **开启**：在问题得到解决或被忽略之前，发布将被阻止。
* **关闭**：发布照常进行，检测结果仍会保留以供查看。

企业组织可以要求所有应用都必须启用此设置。

这些检查并不能取代完整的 [Agent 安全扫描](/zh/ja/features/security/agent-security-scans)或 [Level 3 扫描](/zh/ja/features/security/black-box-pen-tests)，而是对其的补充。
