<div id="certificao-soc-2-tipo-ii">
  ### Сертификация SOC 2 Type II
</div>

Replit теперь сертифицирован по стандарту SOC 2 Type II: платформа прошла строгий 12-месячный аудит безопасности без единого замечания или оговорки. Эта сертификация подтверждает наши практики безопасности корпоративного уровня, а также надёжность платформы и её соответствие требованиям корпоративных клиентов.

<div id="vrios-provedores-sso-para-enterprise">
  ### Несколько SSO-провайдеров для Enterprise
</div>

Клиенты Enterprise теперь могут настраивать несколько SSO-провайдеров и создавать несколько организаций для каждого из них. Это даёт крупным компаниям гибкость: разные команды могут использовать разных провайдеров аутентификации, при этом сохраняются централизованный контроль и общий доступ там, где он необходим.
