# Trabalhe com seus dados

> Navegue, edite, exporte e consulte seu banco de dados na aba My Data, com ferramentas visuais ou SQL.

A aba **My Data** é onde você visualiza e altera o que está no seu banco de dados. Abra a ferramenta **Database**, selecione um banco de dados e depois selecione **My Data**. Você pode trabalhar visualmente ou executar SQL diretamente.

<Note>
  Para editar dados de produção, selecione o banco de dados de produção, abra **My Data** e ative **Edit**. Tenha cuidado: esses são os dados reais do seu app em produção.
</Note>

## Navegar e modificar dados visualmente

A ferramenta Database inclui o <a href="https://orm.drizzle.team/drizzle-studio/overview" target="_blank">Drizzle Studio</a>, uma ferramenta que permite navegar e modificar dados visualmente. Essas ferramentas visuais ajudam você a evitar erros de sintaxe e oferecem as seguintes funcionalidades:

* Filtrar e ordenar dados para focar em informações específicas
* Exportar dados para um arquivo para uso externo
* Inserir ou modificar dados de linhas
* Criar e gerenciar esquemas, tabelas, views e enums

## Executar comandos SQL

O SQL runner permite executar comandos SQL no seu banco de dados e visualizar os resultados.

<Accordion title="Como acessar o SQL runner">
  Na ferramenta **Database**:

  1. Selecione a aba **My Data**
  2. Selecione <img class="icon-svg" src="https://mintcdn.com/replit/X_IP1EeHGm0cA2VA/images/icons/sql-runner-icon.svg?fit=max&auto=format&n=X_IP1EeHGm0cA2VA&q=85&s=fd73c517972d1a4004105e6ab49d130b" alt="Ícone do SQL runner" width="16" height="16" data-path="images/icons/sql-runner-icon.svg" /> **SQL runner**
</Accordion>

Para executar uma consulta, digite a instrução SQL na área de texto e selecione o botão de execução <img class="icon-svg" src="https://mintcdn.com/replit/X_IP1EeHGm0cA2VA/images/icons/sql-play.svg?fit=max&auto=format&n=X_IP1EeHGm0cA2VA&q=85&s=eb0c68e0ab494444f0cbc60325bd1150" alt="ícone de executar sql" width="18" height="18" data-path="images/icons/sql-play.svg" /> adjacente:
