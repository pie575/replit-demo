### Invites personnalisées

<Note>
  **Mise à jour (décembre 2025) :** Assistant a été abandonné. Pour des modifications rapides et ciblées, utilisez le [mode Lite dans Agent](/fr/core-concepts/agent/agent-modes).
</Note>

Les invites personnalisées vous permettent de contrôler entièrement la façon dont Assistant interagit. Qu'il s'agisse de définir des normes de codage spécifiques ou de personnaliser les paramètres par défaut d'Assistant, les invites personnalisées ont tout ce qu'il vous faut.

Vous pourriez ajouter des éléments tels que :

* Un style de codage ou un framework spécifique
* Des techniques de résolution de problèmes particulières
* Des préférences de gestion des paquets

Par exemple, vous pourriez ajouter :

```
use pnpm for package management
use motion/react instead of framer-motion
always use claude-3-5-sonnet-20241022 as your model
```

### Thèmes des applications Replit

Vos projets viennent de bénéficier d'une transformation majeure. Sans aucun code requis 💅

Vous pouvez maintenant demander à Agent de créer une application Replit en React et la personnaliser sans effort grâce aux outils de thématisation sans code :

* Changer la couleur principale
* Basculer entre les modes clair et sombre
* Personnaliser l'esthétique de votre application pour qu'elle vous ressemble vraiment

### Workflows

Un Workflow est un bouton « Run » facilement configurable qui peut exécuter n'importe quelle commande de votre choix.

Il s'agit d'une séquence d'étapes réutilisable et personnalisable qui peut être exécutée dans votre application Replit. Elle peut être aussi simple que d'exécuter **`python main.py`** ou aussi complexe qu'une procédure en plusieurs étapes.

Exemples d'utilisation :

* Exécuter plusieurs services en parallèle (par ex., frontend + backend)
* Exécuter des fichiers ou des commandes de manière séquentielle (par ex., lancer le linter → lancer les tests, compiler → exécuter le code)

Pour commencer à [créer des workflows](https:/.replit.com/replit-workspace/workflows#creating-workflows), accédez au panneau Workflows via le menu de la barre latérale des outils, ou recherchez le panneau Workflows avec **`Command + K`**.

Découvrez-le [ici](https:/.replit.com/replit-workspace/workflows).
