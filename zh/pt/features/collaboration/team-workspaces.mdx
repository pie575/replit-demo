<div id="workspaces-pessoais-vs-de-equipe">
  ## 个人 workspace 与团队 workspace
</div>

**workspace** 是承载你的应用、成员、设置和账单的组织单元。Replit 提供两种类型：

* 个人 workspace
* 团队 workspace

个人 workspace 与团队 workspace 的区别如下：

|          | 个人 workspace        | 团队 workspace           |
| -------- | ------------------- | ---------------------- |
| **角色**   | 管理员、项目级访客           | 管理员、成员、项目级访客           |
| **访问模式** | 你将访客邀请到单个项目         | 成员可访问 workspace 中的所有项目 |
| **账单**   | 你的账户                | 管理员账户的共享积分             |
| **成员管理** | 按项目管理 (Join Links)  | 在 workspace 设置中集中管理    |

如果你独自工作，或只想与他人共享单个项目，**个人 workspace** 更合适。你是唯一的管理员，其他人只能访问你以项目级访客身份邀请他们加入的特定项目。

如果你要与固定的一群人协作构建——比如创业团队、班级或有多位协作者的客户项目——**团队 workspace** 更合适。成员可以访问 workspace 中的所有项目，无需为每个项目逐一邀请。成员统一在**设置**中管理。

<div id="quando-convidar-para-o-seu-workspace-vs-para-um-projeto">
  ### 何时邀请加入 workspace，何时邀请加入单个项目
</div>

| 场景                | 应该怎么做                                |
| ----------------- | ------------------------------------ |
| 需要访问所有内容的长期协作者    | 邀请加入 workspace                       |
| 只需访问某一个项目的外包人员或访客 | [邀请加入项目](/zh/pt/build/invite-teammates) |
| 新入职公司的团队成员        | 邀请加入 workspace                       |
| 帮你调试某个具体应用的朋友     | [邀请加入项目](/zh/pt/build/invite-teammates) |

<div id="criar-um-workspace-de-equipe">
  ## 创建团队 workspace
</div>

<Frame>
  <img src="/assets/mirror/create-team-workspace-e89eaefd9168.png" alt="新建 workspace 表单，其中包含一个通用的 workspace 名称，以及用于邀请团队成员的空白字段" width="784" height="300" data-path="images/workspace/create-team-workspace.png" />
</Frame>

<Steps>
  <Step title="打开 workspace 选择器">
    在主页左上角，点击你的 workspace 名称。
  </Step>

  <Step title="创建新的 workspace">
    选择 **Create workspace**，并为团队 workspace 取一个名称。
  </Step>

  <Step title="邀请成员">
    在邀请字段中输入一个或多个电子邮件地址 (以逗号分隔) 。受邀者会收到邀请，接受后即可访问该 workspace 中的所有项目。
  </Step>
</Steps>

<div id="gerenciando-membros">
  ## 管理成员
</div>

如果你在初始设置时没有邀请成员，或之后需要添加更多成员，请在团队 workspace 中前往 **设置 &gt; Workspace collaborators**，通过电子邮件或 Replit 用户名邀请成员。

<Frame>
  <img src="/assets/mirror/invite-workspace-members-6e3fda413196.jpg" alt="用户邀请对话框，其中有一个用于输入电子邮件地址的空白字段" width="510" height="244" data-path="images/workspace/invite-workspace-members.jpg" />
</Frame>

在 **设置** 页面中，你还可以：

* **移除成员**，撤销其对该 workspace 中所有项目的访问权限
* 将项目从个人 workspace **转移**到团队 workspace —— 参见[将应用转移到团队](/zh/pt/teams/identity-and-access-management/transfer-app-to-teams)

  <Warning>
    workspace 之间的项目转移已暂时停用，你目前无法发起新的转移。
  </Warning>

如需高级身份管理、基于角色的访问以及群组权限，请参见 [Pro 与 Enterprise](/zh/pt/category/teams)。
