<div id="what-is-general-agent">
  ## Что такое General Agent?
</div>

General Agent — это самый гибкий способ работы с Replit Agent. Не нужно заранее выбирать тип artifact или сразу решать, что именно вы создаёте. Просто начните диалог — создайте CSV, сформируйте PDF, изучите тему или соберите полноценное приложение, когда будете готовы.

Ключевые понятия:

* **Без предварительного выбора**: приступайте к работе, не выбирая тип artifact заранее
* **Любой результат**: создавайте файлы (CSV, PDF, документы), проводите исследования или собирайте приложения
* **Коннекторы**: читайте и записывайте данные во внешних сервисах — BigQuery, Linear, Slack, Notion, Amplitude, Segment, Hex и других
* **Постепенное раскрытие**: начните с простой беседы и естественным образом перейдите к полноценной сборке приложения

<div id="how-to-access-general-agent">
  ## Как получить доступ к General Agent
</div>

Получить доступ к General Agent можно несколькими способами:

1. **Выберите «General» перед вводом prompt** на главной странице Replit
2. **Откройте любой существующий проект** и начните общаться с Agent напрямую
3. **[Импортируйте](/ru/build/import-from-providers) из GitHub** — в проектах, импортированных из GitHub, General Agent подключается автоматически

<div id="how-to-use-general-agent">
  ## Как использовать General Agent
</div>

<div id="just-start-chatting">
  ### Просто начните общение
</div>

Откройте проект и начните разговор. Необязательно сразу решать, что именно вы будете создавать, — Agent работает в контексте вашего текущего проекта и справится с любой задачей, которую вы перед ним поставите.

**Примеры prompt:**

* «Кратко изложи ключевые тезисы этого документа»
* «Создай CSV со 100 крупнейшими компаниями по выручке»
* «Какие у меня пять главных тикетов в Linear?»
* «Настрой проект на Vue.js с TypeScript»

Agent может работать с файлами, созданными во время сессии, формировать результат в виде одного файла и выполнять код в процессе рассуждений — и всё это ещё до того, как вы решите что-либо создавать.

<div id="connecting-external-services">
  ### Подключение внешних сервисов
</div>

Подключите свои инструменты, чтобы Agent мог напрямую читать и записывать данные:

1. Перейдите в раздел **Коннекторы** в настройках проекта
2. Подключите нужные сервисы (BigQuery, Linear, Slack, Notion, Amplitude, Segment, Hex и другие)
3. Попросите Agent прочитать или записать данные через них

**Примеры prompt для работы с коннекторами:**

* «Какие тикеты открыты в Linear?»
* «Сделай сводку сегодняшних сообщений в канале #engineering в Slack»
* «Выгрузи данные о продажах за прошлый месяц из BigQuery»
* «Покажи ближайшие события из моего календаря»
* «Создай в Linear новый тикет по ошибке в онбординге»
* «Отправь сводку в канал #engineering в Slack»

<div id="from-chat-to-full-app">
  ### От чата к полноценному приложению
</div>

Когда будете готовы приступить к сборке, просто скажите об этом. Agent плавно перейдёт от обычного чата к разработке вашего приложения — не нужно начинать заново или переключаться между контекстами.

* «Преврати это в веб-приложение»
* «Создай приложение на основе этих данных»
* «Сделай дашборд для этих метрик»
* «Настрой CLI-инструмент на Rust»

Начать можно в свободной форме — изучить тему, сформировать отчёт, покопаться в данных — а затем, в подходящий момент, перейти к созданию полноценного приложения.

<div id="what-you-can-build">
  ## Что можно создать
</div>

* **Интеллектуальная работа**: исследуйте, обобщайте и анализируйте без создания приложения
* **Результат в одном файле**: CSV, PDF, документы, экспорт данных и оформленные отчёты
* **Приложения для работы с данными**: запрашивайте данные из подключённых сервисов и визуализируйте результаты в дашбордах
* **Любой фреймворк или язык**: Angular, Vue, Svelte, Rust, Go, C#, Python tkinter, игры на Godot, инструменты командной строки и многое другое
* **Полностековые приложения**: когда будете готовы, создайте полноценное приложение на основе контекста вашего чата

<div id="what-to-expect">
  ## Чего ожидать
</div>

General Agent даёт больше возможностей и гибкости, но вместе с этим появляется и некоторая непредсказуемость:

* **Настройка с первого раза**: иногда Agent настраивает всё за один подход
* **Совместная доработка**: сложные конфигурации могут потребовать нескольких итераций уточнений
* **Ограничения технологий**: некоторые технологии могут поддерживаться в среде Nix не полностью

<Note>
  В отличие от стандартного Agent с заранее настроенными средами, General Agent сам создаёт среду и команды запуска на основе вашего запроса. Когда вы будете готовы к развёртыванию, возможно, потребуется попросить его настроить Publishing.
</Note>

<div id="frequently-asked-questions">
  ## Часто задаваемые вопросы
</div>

<Accordion title="Видит ли Agent мои другие проекты?">
  Нет. Каждый чат ограничен одним проектом. Проект A и проект B не могут обмениваться данными друг с другом.
</Accordion>

<Accordion title="Почему он пока не может получить доступ к моему внешнему инструменту?">
  Сначала нужно подключить сервисы через Connectors. После подключения Agent сможет читать из них данные и записывать их, но по умолчанию доступа у него нет.
</Accordion>

<Accordion title="Какие коннекторы доступны?">
  Сейчас поддерживаются: BigQuery, Linear, Slack, Notion, Amplitude, Segment, Hex и другие. Новые коннекторы добавляются регулярно.
</Accordion>

<Accordion title="Нужны ли коннекторы для работы с General Agent?">
  Нет, коннекторы необязательны. General Agent можно использовать для интеллектуальной работы, создания файлов и разработки приложений вообще без внешних подключений.
</Accordion>
