借助数据仓库连接器，Replit Agent 可以安全地查询组织的数据仓库。构建者可使用自然语言创建控制台、报告工具和数据应用，无需具备 SQL 专业知识。管理员可通过基于角色的访问控制进行集中管理。

<div id="section">
  ## 支持的数据仓库
</div>

数据仓库连接器可在 **Enterprise** 套餐中使用。

| 数据仓库             | 设置指南                                                                             |
| ---------------- | -------------------------------------------------------------------------------- |
| BigQuery         | 可用 — 设置指南正在准备中                                                                   |
| Databricks       | [连接到 Databricks](/zh/ja/connectors/warehouses/databricks)                           |
| Microsoft Fabric | [在 Microsoft Fabric 上构建数据应用](/zh/ja/connectors/warehouses/microsoft-fabric) (私密预览)  |
| Snowflake        | [连接到 Snowflake](/zh/ja/connectors/warehouses/snowflake)                             |

每个数据仓库的 OAuth 集成、身份模型和凭据格式各不相同，因此需要采用相应的设置流程。请选择要使用的数据仓库，并按照相应的专用指南操作。

<div id="section-2">
  ## 分析与数据平台
</div>

除 Enterprise 外，Core 和 Pro 套餐也可使用分析连接器。连接分析工具后，Agent 可以读取和处理产品数据。

* **Segment** — CDP 中的客户数据、事件流和受众细分
* **Amplitude** — 产品分析、用户行为数据和互动指标
* **Hex** — 协作式数据笔记本和查询结果

这些连接器的管理方式与其他 Replit 连接器相同。请参阅[管理连接器](/zh/ja/replitai/managing-connectors)。

<div id="section-3">
  ## 数据仓库连接器的工作原理
</div>

设置是一次性流程，涉及三个角色：

1. **数据仓库管理员** — 在数据仓库中创建 OAuth 集成或服务 ID
2. **Replit 组织管理员** — 在 Replit 中添加凭据并配置访问权限
3. **构建者** — 登录并开始使用 Agent 构建

配置完成后，构建者可以让 Agent 使用数据仓库，Agent 会据此创建并执行 SQL。

<div id="section-4">
  ### 使用数据仓库数据进行构建
</div>

连接后，您可以让 Agent 构建利用数据的应用。Agent 可以：

* 构建获取并展示实时数据的内部工具
* 创建基于数据仓库的图表和可视化控制台
* 生成驱动应用后端的 SQL 查询
* 解释架构和表结构，帮助您了解应该构建什么

<Note>
  Agent 可以回答有关数据的临时问题，但数据仓库连接器的主要用途是让 Agent 能够构建利用组织数据的实用应用。数据仓库查询会直接针对实例执行，因此请确保 OAuth 范围和数据库用户权限允许所需的读取和写入操作。
</Note>
