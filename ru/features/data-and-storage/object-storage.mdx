App Storage — это встроенное объектное хранилище Replit, которое позволяет вашему приложению легко размещать и сохранять загружаемые файлы: изображения, видео и документы.
Бакеты — это контейнеры для хранения объектов, например файлов. У них есть политики доступа, которые ограничивают действия пользователей и приложений над содержимым.

<Info>
  Мы переименовали <strong>Object Storage</strong> в <strong>App Storage</strong>. Функциональность не изменилась, а ваши существующие бакеты, разрешения и программный доступ продолжат работать.
</Info>

С App Storage вы можете создавать, например:

* **Платформы для обмена фотографиями**: позволяйте разработчикам загружать, хранить и показывать изображения
* **Сервисы потокового видео**: обрабатывайте загрузку видео и доставляйте контент зрителям
* **Системы управления документами**: храните и упорядочивайте файлы разработчиков с безопасным доступом
* **Сайты-портфолио**: демонстрируйте работы с медиафайлами, которые загружаются без сбоев
* **Сервисы резервного копирования**: предоставляйте разработчикам облачное хранилище для важных файлов

<Note>
  Попросите **Agent** добавить App Storage в ваше приложение, указав, с какими типами файлов оно должно работать. Agent настроит интеграцию, создаст необходимые бакеты и доработает приложение так, чтобы оно загружало, хранило и получало файлы, — с расширенными возможностями вроде аутентификации и контроля доступа.
</Note>

Инструмент App Storage позволяет без лишних усилий обмениваться данными между
средой разработки и продакшеном или с другими Replit App.

<div id="features">
  ## Возможности
</div>

<Info>
  App Storage работает на базе Google Cloud Storage (GCS).
  Это значит, что вы получаете лидирующие в отрасли показатели
  доступности, надёжности и безопасности.
</Info>

App Storage предоставляет следующие возможности для ваших Replit App:

* **Постоянное облачное хранилище**: храните файлы, которые остаются доступными для вашего опубликованного приложения и его пользователей
* **Масштабируемая работа с файлами**: справляйтесь с растущими объёмами данных, не беспокоясь об ограничениях хранилища
* **Обмен данными между приложениями**: используйте общие бакеты сразу в нескольких Replit App для распределённых архитектур
* **Программный доступ**: загружайте, скачивайте файлы и управляйте ими с помощью понятных API
* **Расширенная интеграция с Agent**: позвольте Agent настроить App Storage с расширенными конфигурациями, изучить существующие настройки и сгенерировать полный код бэкенда и фронтенда с аутентификацией и контролем доступа

Вот несколько способов использования App Storage в ваших Replit App:

* Хранение аватаров разработчиков и загруженных медиафайлов
* Отдача изображений товаров для сайтов электронной коммерции
* Обработка загрузки документов при отправке форм
* Создание функций обмена файлами и совместной работы
* Разработка систем управления контентом с медиабиблиотеками

<Tip>
  **Расширенная интеграция с Agent**: вы можете попросить [Replit Agent](/ru/features/agent/overview) автоматически добавить App Storage в ваши приложения! Теперь Agent умеет настраивать объектное хранилище, проверять конфигурации и генерировать полный код бэкенда и фронтенда с расширенными возможностями вроде аутентификации и контроля доступа. Просто упомяните «App Storage» или «хранилище файлов» в своём prompt.

  <AiPrompt>Add App Storage to my app to store files</AiPrompt>
  <AiPrompt>Create a photo gallery app with App Storage for images</AiPrompt>
  <AiPrompt>Set up App Storage with authentication for user file uploads</AiPrompt>

  Узнайте больше об [интеграциях Agent](/ru/features/integrations/overview#data-storage--management) и посмотрите все доступные prompt для App Storage.
</Tip>

<div id="usage">
  ## Использование
</div>

<Note>
  Ваше Replit App должно пройти аутентификацию в Google Cloud Storage, чтобы получить доступ к бакету и его объектам.
  Для автоматической аутентификации используйте официальные клиентские библиотеки Replit App Storage.
</Note>

Инструмент App Storage доступен прямо в Project Editor.

<Accordion title="Как открыть инструмент App Storage">
  Через левую **панель инструментов (Tool dock)**:

  1. Выберите <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Значок «Все инструменты»" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**, чтобы открыть список инструментов Project Editor.
  2. Выберите <img class="icon-svg" src="/assets/mirror/object-storage-monoochrome-icon-aaba8f517280.svg" alt="Значок App Storage" width="16" height="16" data-path="images/icons/object-storage-monoochrome-icon.svg" /> **App Storage**.

  Через **строку поиска**:

  1. Нажмите на <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="значок лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> лупу вверху, чтобы открыть инструмент поиска.
  2. Введите «App Storage», чтобы найти инструмент, и выберите его в результатах.
</Accordion>

Чтобы связать новый бакет хранилища с вашим Replit App, создайте бакет.

<Accordion title="Как создать бакет">
  В инструменте **App Storage**:

  1. Нажмите **Create new bucket**.
  2. Введите имя бакета в поле **Name** и выберите **Create bucket**.

  Вкладка App Storage должна выглядеть примерно так:

  <Frame>
    <img src="/assets/mirror/object-storage-empty-bucket-3462e2efb1bc.png" alt="снимок экрана инструмента App Storage" width="2790" height="1218" data-path="images/databases/object-storage-empty-bucket.png" />
  </Frame>

  Чтобы создать дополнительные бакеты, откройте выпадающее меню бакетов в левом верхнем углу вкладки **App Storage** и выберите **Create new bucket**.
</Accordion>

Рядом с названием выбранного бакета отображается галочка, как показано на снимке экрана ниже:

<div id="access-the-bucket-id">
  ### Просмотр идентификатора бакета
</div>

Чтобы посмотреть **Bucket ID**, выберите режим **Settings** в выпадающем списке в верхней части вкладки **App Storage**.
Bucket ID однозначно идентифицирует бакет — именно на него код должен ссылаться при выполнении операций.

Если у вас несколько бакетов, выберите нужный в выпадающем меню в левом верхнем углу.

<div id="upload-or-download-objects">
  ### Загрузка и скачивание объектов
</div>

Чтобы загрузить объект в выбранный бакет:

1. Перейдите в раздел **Objects** на вкладке **App Storage**.
2. Выберите <img class="icon-svg" src="/assets/mirror/upload-file-5894be4232ce.svg" alt="upload file icon" width="16" height="16" data-path="images/icons/upload-file.svg" /> **Upload files** или <img class="icon-svg" src="/assets/mirror/upload-folder-fc87519bedf9.svg" alt="upload folder icon" width="16" height="16" data-path="images/icons/upload-folder.svg" /> **Upload folder**, чтобы загрузить все файлы из папки.
   Затем в диалоговом окне выберите один или несколько файлов для загрузки.
   Также можно просто перетащить файл или папку в область со списком содержимого бакета.

Чтобы скачать объект из выбранного бакета:

1. Перейдите в раздел **Objects** на вкладке **App Storage**.
2. Нажмите значок скачивания <img class="icon-svg" src="/assets/mirror/download-icon-c7b527953d65.svg" alt="download icon" width="16" height="16" data-path="images/icons/download-icon.svg" /> справа от файла.

<div id="organize-objects-in-folders">
  ### Организация объектов в папках
</div>

Чтобы создать папку в выбранном бакете:

1. Перейдите в раздел **Objects** на вкладке **App Storage**.
2. Нажмите <img class="icon-svg" src="/assets/mirror/create-folder-c9acf112a042.svg" alt="create folder icon" width="16" height="16" data-path="images/icons/create-folder.svg" /> **Create Folder** в разделе **Objects**.
3. Введите имя папки.

Чтобы добавить объекты в папку в разделе **Objects**, перетащите объект в нужную папку.

Чтобы переместить объект в родительскую папку, перетащите его выше заголовка — на имя папки, расположенное над списком объектов.
На анимации ниже показано перемещение файла «product&#95;demo.mov» из папки «videos» в родительскую папку «Objects»:

<div id="delete-objects-or-buckets">
  ### Удаление объектов или бакетов
</div>

<Warning>
  Удаление необратимо. Прежде чем продолжить, обязательно создайте резервную копию важных данных.
</Warning>

Чтобы удалить объект навсегда:

1. Перейдите в раздел **Objects** на вкладке **App Storage**.
2. Нажмите значок корзины <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="trash icon" width="16" height="16" data-path="images/icons/trash-icon.svg" />
   рядом с объектом, который хотите удалить.
3. Подтвердите удаление в диалоговом окне.

Чтобы удалить бакет вместе со всеми объектами в нём:

1. Перейдите в раздел **Settings** на вкладке **App Storage**.
2. Убедитесь, что в выпадающем списке бакетов в левом верхнем углу выбран нужный бакет.
3. Нажмите <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="trash icon" width="16" height="16" data-path="images/icons/trash-icon.svg" /> **Delete Bucket**.
4. Подтвердите удаление в диалоговом окне.

<div id="bucket-access-management">
  ### Управление доступом к бакетам
</div>

Replit привязывает все созданные вами бакеты к вашей учётной записи и делает их доступными
для всех ваших Replit App. Replit App, в котором вы создали бакет, получает доступ автоматически.

Вы можете указывать, какие из ваших Replit App имеют доступ к конкретному бакету, — это позволяет
обмениваться данными эффективно и безопасно.

Чтобы предоставить вашему Replit App доступ к бакету из другого приложения в вашей учётной записи:

1. Выберите <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="значок лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" />
   **Add an existing bucket** в меню бакетов в левом верхнем углу вкладки App Storage.
2. В диалоговом окне **Choose a Bucket** выберите нужный бакет и нажмите **Add Bucket to Repl**.

<Frame>
  <img src="/assets/mirror/choose-bucket-dialog-b709aa247a85.png" alt="снимок экрана диалогового окна выбора бакета" width="1115" height="457" data-path="images/databases/choose-bucket-dialog.png" />
</Frame>

Чтобы отозвать у вашего Replit App доступ к бакету:

1. Перейдите в раздел **Settings** на вкладке **App Storage**.
2. В выпадающем списке бакетов в левом верхнем углу вкладки выберите имя бакета.
3. Нажмите **Remove Bucket from Repl** и подтвердите удаление в диалоговом окне.

<div id="programmatic-access-to-app-storage">

Инструкции по работе с клиентскими библиотеками приведены в следующих материалах:

* [JavaScript App Storage SDK](/ru/features/sdks/object-storage-javascript-sdk/): справочник по клиенту для JavaScript SDK
* [Python App Storage SDK](/ru/features/sdks/object-storage-python-sdk/): справочник по клиенту для Python SDK
* [Пример приложения на Google Cloud Python SDK](https://replit.com/@matt/GCS-Python-Uploads?v=1): сделайте ремикс этого приложения, чтобы управлять объектами с помощью Google Cloud Python SDK
