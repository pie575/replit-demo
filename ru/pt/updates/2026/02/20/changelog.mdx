<div id="lanamento-do-plano-pro">
  ## Запуск тарифа Pro
</div>

Replit Pro уже доступен, а Core теперь предлагает ещё больше преимуществ. Мы сделали тарифы понятнее и чётче разграничили их назначение:

* **Replit Pro**: Для серьёзных разработчиков — турбо-режим (Agent работает в 2,5 раза быстрее, включается отдельным переключателем), увеличивающиеся кредиты с переносом остатка, до 15 разработчиков без платы за пользователя, приоритетная поддержка и в 4 раза более длительное хранение данных. [Подробнее о Pro](/ru/pt/billing/plans/replit-pro).
* **Core**: Приглашайте до 5 соавторов без дополнительной платы. Актуальные цены для Core смотрите на [странице цен](https://replit.com/pricing).
* **Прекращение тарифа Teams**: Teams заменяется на Pro. Существующие клиенты Teams будут переведены на Pro без дополнительной платы на оставшийся срок действия тарифа. Миграция начнётся {TeamsMigrationDate}. [Подробности и график](https://blog.replit.com/pro-plan).
* **Режимы Agent**: Выберите **Economy** (для экономии) или **Power** (для производительности); **Turbo** — отдельный переключатель (только для Pro/Enterprise, в 2,5 раза быстрее). [Руководство по режимам Agent](/ru/pt/core-concepts/agent/agent-modes).
* **Fast Mode теперь называется Lite Mode**: Те же быстрые, чётко ограниченные по объёму изменения — обновлено только название в продукте и документации. [Lite Mode](/ru/pt/core-concepts/agent/agent-modes).
* **Оптимизация кода**: Настройка, определяющая, как Agent проверяет собственный код (ранее «Уровень автономности»), теперь называется «Оптимизация кода». [Проверка кода](/ru/pt/features/agent/agent-modes#code-review).
* **Совместная работа**: Улучшенная совместная работа во всех платных тарифах — неограниченное количество рабочих пространств, упрощённый доступ, единые настройки и отслеживание использования по рабочим пространствам. Core: 5 соавторов; Pro: 15 разработчиков.

<div id="compresso-de-memria-em-segundo-plano">
  ### Сжатие памяти в фоновом режиме
</div>

Agent больше не приостанавливает ваш рабочий процесс для оптимизации памяти. Раньше появлялось сообщение «Память Agent оптимизирована», из-за которого работа блокировалась более чем на 30 секунд. Теперь оптимизация незаметно выполняется в фоновом режиме, поэтому Agent остаётся отзывчивым во время работы.

<div id="acesso-a-logs-de-deployment-de-produo">
  ### Доступ к логам production-развёртывания
</div>

Agent теперь имеет доступ к логам production-развёртывания, что позволяет находить и исправлять ошибки на основе реальных данных из production-среды. Вскоре появятся дополнительные улучшения отладки в production.

<div id="busca-de-skills">
  ### Поиск навыков
</div>

Поиск навыков позволяет находить и устанавливать популярные навыки прямо в Replit, не обращаясь к Agent и не загружая файлы вручную.

<div id="integrao-mcp-com-razorpay">
  ### Интеграция MCP с Razorpay
</div>

Интеграция MCP с Razorpay уже доступна и расширяет возможности приёма платежей для разработчиков из Индии. Подключите Razorpay к своему проекту в Replit, чтобы принимать платежи, управлять заказами и оформлять возвраты напрямую через Agent.

<div id="video-stack">
  ### Video Stack
</div>

Video Stack позволяет создавать анимированные видео с помощью кода, используя сгенерированные изображения и видео для создания креативной анимированной графики. Создавайте анимированные видео целиком в коде прямо в своём проекте Replit.
