<div id="o-que-o-revenuecat">
  ## Что такое RevenueCat
</div>

RevenueCat позволяет добавить подписку в приложении в ваше [нативное мобильное приложение](/ru/pt/features/artifact-types/building-mobile-apps). Для начала попросите Agent настроить подписку и подключите свою учётную запись RevenueCat — Agent возьмёт на себя всю логику и предоставит тестовую среду.

<div id="pr-requisitos">
  ## Предварительные требования
</div>

Прежде чем начать, вам понадобятся:

* Проект Replit, созданный как **мобильное приложение**
* Учётная запись [RevenueCat](https://www.revenuecat.com) (нужны только адрес электронной почты и пароль — банковский счёт и дополнительная настройка не требуются)

<Note>
  Для работы над нативным мобильным приложением используйте Project Editor на [replit.com](https://replit.com). Работа с нативными мобильными приложениями также доступна в приложении Replit для Android — там, где она поддерживается. Если вы используете приложение Replit для iOS, откройте проект на replit.com.
</Note>

<div id="teste-as-assinaturas">
  ## Тестирование подписок
</div>

В Preview на Replit используется **тестовый режим** RevenueCat. При тестировании покупки в Expo Go вместо реального платёжного процесса откроется диалоговое окно тестовой покупки. Никакие средства не списываются.

<Frame>
  <img src="/assets/mirror/revenuecat-test-purchase-8414145a112e.png" alt="Диалоговое окно тестовой покупки на мобильном устройстве с деталями пакета и тестовыми кнопками" width="683" height="1253" data-path="images/replitai/revenuecat-test-purchase.png" />
</Frame>

<Tip>
  Тестовые покупки безопасно использовать во время разработки. Вы можете проверить как успешные, так и неудачные сценарии покупки без каких-либо реальных списаний.
</Tip>

<Warning>
  После того как Apple одобрит ваше приложение для распространения в App Store, покупки будут совершаться за реальные деньги.
  Убедитесь, что ваши продукты и цены в RevenueCat указаны верно, прежде чем отправлять приложение
  на проверку в App Review.
</Warning>

<div id="sincronizao-com-o-app-store-connect">
  ## Синхронизация с App Store Connect
</div>

Чтобы покупки в приложении работали в TestFlight и Apple App Store, [необходимо принять
Paid Apps Agreement от Apple и подключить банковский счёт](https://developer.apple.com/help/app-store-connect/manage-agreements/sign-and-update-agreements/).
Это делается через App Store Connect. Кроме того, для отправки приложения в App Store потребуется платная учётная запись Apple Developer.

После этого вы сможете синхронизировать настройки покупок в приложении из RevenueCat с App Store Connect прямо в Replit.

<Steps>
  <Step title="Перейдите на панель Manage в разделе Publishing">
    Вы увидите кнопку синхронизации RevenueCat с App Store Connect.

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-sync-btn-46a2e4e696df.png" alt="Кнопка Sync RevenueCat to App Store Connect" width="1476" height="604" data-path="images/replitai/revenuecat-asc-sync-btn.png" />
    </Frame>

    <Tip>
      Этот раздел появляется только после отправки приложения в TestFlight.
    </Tip>
  </Step>

  <Step title="Укажите ключ API App Store Connect">
    Чтобы получить этот ключ, перейдите в App Store Connect.

    В [App Store Connect](https://appstoreconnect.apple.com/access/integrations/api) откройте **Users and Access**, затем выберите вкладку **Integrations**. На боковой панели выберите **App Store Connect API**.

    При создании ключа обязательно выдайте ему права «App Manager».

    Сразу скачайте файл .p8 — сделать это можно только один раз. Имя файла начинается с `AuthKey_` и заканчивается на `.p8`.

    Скопируйте **Key ID** и **Issuer ID**, указанные на этой странице.

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-create-c54be8304d7c.png" alt="Страница Users and Access в App Store Connect с пронумерованными шагами, выделяющими вкладку Integrations, ссылку App Store Connect API на боковой панели и кнопку «плюс» для создания нового ключа API" width="2390" height="752" data-path="images/replitai/revenuecat-asc-create.png" />
    </Frame>

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-app-manager-93996acd8561.png" alt="Диалог Generate API Key в App Store Connect с именем RevenueCat и уровнем доступа App Manager" width="1116" height="560" data-path="images/replitai/revenuecat-asc-app-manager.png" />
    </Frame>

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-copy-07a95e1be9af.png" alt="Страница ключей API в App Store Connect со стрелками, указывающими на ссылку Copy рядом с Issuer ID и на столбец Key ID" width="2330" height="780" data-path="images/replitai/revenuecat-asc-copy.png" />
    </Frame>
  </Step>

  <Step title="Создайте ключ API для In-App Purchase">
    Повторите предыдущий шаг для ключа API In-App Purchase.
    На боковой панели выберите **In-App Purchase**. Затем создайте ключ API с правами **App Manager**.
    Скачайте ключ .p8 (имя файла начинается с `SubscriptionKey_` и заканчивается на `.p8`). Скопируйте **Key ID** и **Issuer ID**.

    <Frame>

    </Frame>
  </Step>

  <Step title="Синхронизируйте продукты">
    Подтвердите список продуктов и синхронизируйте его с App Store Connect.

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-products-sync-078d42af83ba.png" alt="Диалог Manage in-app purchases с продуктом Monthly Subscription, полями цены, длительности и территории и кнопкой Sync to App Store Connect" width="948" height="476" data-path="images/replitai/revenuecat-asc-products-sync.png" />
    </Frame>
  </Step>
</Steps>

<div id="perguntas-frequentes">
  ## Часто задаваемые вопросы
</div>

<AccordionGroup>
  <Accordion title="Нужен ли банковский счёт для использования RevenueCat?">
    Нет. Для создания учётной записи достаточно электронной почты и пароля. Банковский счёт
    настраивается отдельно — через Apple или Google, когда вы будете
    готовы принимать платежи из App Store или Google Play.
  </Accordion>

  <Accordion title="Взимается ли плата за тестовые покупки?">
    Нет. Во время разработки Preview в Replit работает в тестовом режиме RevenueCat.
    Покупки имитируются, реальные списания не производятся. Реальные списания
    начинаются только после того, как App Review от Apple одобрит ваше приложение.
  </Accordion>

  <Accordion title="Можно ли использовать RevenueCat с веб-приложением?">
    RevenueCat рассчитан на нативные мобильные приложения. Чтобы добавить подписки в веб-приложение,
    используйте [интеграцию со Stripe](/ru/pt/features/monetization/stripe-payments).
  </Accordion>

  <Accordion title="Что можно настроить с помощью RevenueCat?">
    Вы можете настроить ежемесячные или годовые подписки, задать цены, управлять
    entitlements и создавать paywall. Попросите Agent внести изменения — он позаботится
    и о настройке RevenueCat, и о коде вашего приложения.
  </Accordion>
</AccordionGroup>
