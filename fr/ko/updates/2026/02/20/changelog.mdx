<div id="pro">
  ## Lancement du plan Pro
</div>

Replit Pro est disponible, et Core offre désormais encore plus de valeur. Nous avons rendu nos plans plus clairs et mieux adaptés à chaque usage :

* **Replit Pro** : pour les créateurs exigeants — mode Turbo (Agent 2,5× plus rapide, bascule distincte), crédits par paliers avec report, jusqu&#39;à 15 créateurs sans frais par siège, support prioritaire, conservation des données 4× plus longue. [Découvrir Pro](/fr/ko/billing/plans/replit-pro).
* **Core** : invitez jusqu&#39;à 5 collaborateurs sans frais supplémentaires. Consultez la [page des tarifs](https://replit.com/pricing) pour connaître le tarif actuel de Core.
* **Fin du plan Teams** : Teams est remplacé par Pro. Les clients Teams existants passent à Pro sans frais supplémentaires pour la durée restante de leur abonnement. La migration débute le {TeamsMigrationDate}. [Détails et calendrier](https://blog.replit.com/pro-plan).
* **Modes de l&#39;Agent** : choisissez **Economy** (coûts optimisés) ou **Power** (performances). **Turbo** est une bascule distincte (Pro/Enterprise uniquement, 2,5× plus rapide). [Guide des modes de l&#39;Agent](/fr/core-concepts/agent/agent-modes).
* **Le mode Fast devient le mode Lite** : les mêmes modifications rapides et ciblées — seul le nom change, dans le produit comme dans la documentation. [Mode Lite](/fr/core-concepts/agent/agent-modes).
* **Code Optimizations** : le paramètre qui contrôle la façon dont l&#39;Agent révise son propre code (auparavant Autonomy Level) s&#39;appelle désormais Code Optimizations. [Révision du code](/fr/ko/features/agent/agent-modes).
* **Collaboration** : une meilleure collaboration sur tous les plans payants — espaces de travail illimités, partage simplifié, paramètres unifiés, suivi de l&#39;utilisation par espace de travail. Core : 5 collaborateurs, Pro : 15 créateurs.

<div id="section-3">
  ### Compression de la mémoire en arrière-plan
</div>

Agent n&#39;interrompt plus votre flux de travail pour optimiser la mémoire. Auparavant, le message « Optimized Agent memory » bloquait la progression pendant plus de 30 secondes. Désormais, cette opération s&#39;effectue de façon transparente en arrière-plan, ce qui permet à Agent de rester réactif pendant que vous travaillez.

<div id="section-4">
  ### Accès aux journaux des déploiements en production
</div>

Agent peut désormais accéder aux journaux des déploiements en production, ce qui lui permet d&#39;identifier et de corriger les erreurs à partir de données de production réelles. D&#39;autres améliorations du débogage en production arriveront prochainement.
