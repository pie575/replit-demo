<div id="o-que-o-modo-plan">
  ## 什么是 Plan 模式？
</div>

Plan 模式让你可以：

* **头脑风暴**，探索项目的不同实现思路
* 通过结构化的任务清单**规划开发工作**
* 在项目架构和功能规划方面**与 AI 协作**
* **获取策略性建议**并提出问题，而不会改动项目的代码或数据
* 准备好动手实现时，**顺畅切换**到 Build 模式

默认模式现在称为 **Build** 模式。

与 Build 模式不同，Plan 模式专注于规划和构思，帮助你在编写代码之前把项目想清楚。

<div id="primeiros-passos">
  ## 快速入门
</div>

<div id="acessando-o-modo-plan">
  ### 进入 Plan 模式
</div>

任何启用了 Agent 的 Replit App 都可以使用 Plan 模式。进入方式如下：

1. **在项目编辑器中打开你的 Replit App**
2. **找到模式选择器**，它位于聊天输入框的左下角
3. **在下拉菜单中选择 Plan 模式**

<div id="principais-recursos">
  ## 主要功能
</div>

<div id="planejamento-de-tarefas">
  ### 任务规划
</div>

Plan 模式擅长将复杂项目拆解为易于管理的任务。只需向 Agent 提供一些需求，它就会生成一份有序的任务清单，列出完成你的请求所需的各个开发步骤。

<div id="brainstorming-colaborativo">
  ### 协作式头脑风暴
</div>

与 AI 一起探索不同的思路：

* 针对复杂问题的**多种解决路径**
* 不同方案的**利弊分析**
* **风险评估**与应对策略

<div id="fluxo-de-trabalho-do-planejamento-construo">
  ## 工作流程：从规划到构建
</div>

<div id="1-fase-de-planejamento-modo-plan">
  ### 1. 规划阶段 (Plan 模式) 
</div>

在 Plan 模式下开启开发流程：

* **明确项目范围**和目标
* **拆解需求**，细化为具体功能
* **规划架构**和技术栈
* **制定开发路线图**，设置关键里程碑

<div id="2-aprovao-de-tarefas">
  ### 2. 任务审批
</div>

当 Agent 生成任务清单时：

* **查看**建议的任务
* 选择**开始构建**以批准该计划

或者继续对话，进一步完善计划。

<div id="3-transio-para-o-modo-build">
  ### 3. 切换到 Build 模式
</div>

当你准备好开始实现时：

* **点击&quot;开始构建&quot;**以批准计划
* **Agent 会自动切换**到 Build 模式
* **Agent 开始实现**已批准的任务
* **在开发阶段跟踪进度**

Plan 模式与其他 Agent 交互一样，采用基于工作量的计费方式。Plan 模式下 Agent 的所有工作都会计费，包括回答问题、提供指导以及生成任务清单。请求越复杂,或对话上下文越长,费用就越高。

**Agent 的所有交互都会计费**——无论 Agent 是以文字形式提供指导,还是对代码进行修改,都会产生费用,只不过较小的请求费用更低。

<div id="boas-prticas">
  ## 最佳实践
</div>

<div id="prompting-eficaz">
  ### 有效的 prompt 技巧
</div>

要充分利用 Plan 模式：

* 对项目需求要**具体明确**
* **追问细节**，厘清 AI 给出的建议
* 讨论复杂概念时**要求提供示例**
* **权衡不同方案的利弊**
* 在确定实现方案之前**反复打磨想法**
* 在后续对话中引用重要决策，从而**记录并延续这些决策**
