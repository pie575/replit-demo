<div id="replit-pwa-on-microsoft-app-store">
  ### Replit PWA sur le Microsoft App Store
</div>

Replit est désormais disponible sous forme d’application web progressive (PWA) sur le Microsoft App Store, ce qui permet aux créateurs sous Windows de découvrir et d’installer plus facilement Replit comme une application de type native.

<div id="empty-project-creation">
  ### Création d’un projet vide
</div>

Vous pouvez désormais créer un projet vide depuis la page d’importation. Les projets vides ne déclenchent pas Agent au démarrage — aucun crédit n’est consommé lors de leur création — et vous laissent entièrement maîtriser la configuration du framework et des outils. Cette option est disponible sur la page d’importation pour les créateurs qui souhaitent disposer de ce niveau de contrôle.

<div id="teams-and-enterprise">
  ## Teams et Enterprise
</div>

<div id="enterprise-audit-log-portal">
  ### Portail des journaux d’audit Enterprise
</div>

Enterprise Audit Log Portal (v1) est désormais accessible à tous les clients Enterprise. Les administrateurs peuvent consulter les événements réalisés par les membres de leur organisation et configurer des intégrations de flux d’événements avec la plateforme SIEM de leur choix, notamment S3, Datadog, Splunk, Google Cloud Storage et Microsoft Sentinel.
