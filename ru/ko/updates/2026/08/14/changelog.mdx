<div id="section-3">
  ### Выбор региона рабочего пространства
</div>

<div id="mcp-replit">
  ### Использование Replit через MCP
</div>

Подключайте Replit напрямую к ChatGPT, Claude и Slack или подключайте совместимые MCP-клиенты к Replit, чтобы создавать, искать, проверять, обновлять и деплоить приложения. Вместо того чтобы начинать с пустого приложения, можно создать приватную копию существующего и редактировать её.

<div id="clerk-auth">
  ### Миграция на Clerk Auth
</div>

Теперь подходящие приложения с Replit Auth можно перевести на Clerk Auth. Agent переносит данные учётных записей до обновления кода входа, поэтому существующие пользователи не теряют доступ к своим данным.

<div id="section-6">
  ### Общий доступ к навыкам рабочего пространства и управление ими
</div>

Теперь любой участник рабочего пространства может создать навык и оставить его личным или открыть доступ всему рабочему пространству. У других участников общие навыки по умолчанию отключены — каждый сам решает, какие из них включить. Администраторы управляют всеми навыками рабочего пространства и могут сделать отдельные навыки обязательными. Переработанная библиотека Skills упрощает поиск навыков и управление ими.

Подробнее об [Agent Skills](/ru/ko/features/agent/skills).

<div id="section-7">
  ## Команды и Enterprise
</div>

<div id="admin-api">
  ### Выпуск бета-версии Admin API
</div>

Администраторы аккаунтов Enterprise теперь могут создавать API-ключи на новой вкладке **Developer** в настройках и с помощью Admin API выполнять следующие действия:

* Просматривать рабочие пространства, участников, группы пользователей, проекты и деплои.
* Просматривать данные Usage по участникам, проектам и рабочим пространствам за нужный период.
* Просматривать и изменять бюджеты рабочих пространств, групп пользователей и отдельных участников.

Подробнее — в [документации Admin API](/ru/ko/teams/admin-api) и [справочнике API](https://api.replit.com/docs).
