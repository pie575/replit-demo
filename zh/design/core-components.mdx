Replit Design 的核心是一个用于展示 frame 的无限画布。本页面的其余内容介绍如何围绕这些 frame 开展操作：

* 在无限画布上生成和排列设计 frame
* 使用 Chat、建议和工具栏不断完善每个 frame
* 定位 frame 的任意部分，只更改该部分
* 无需离开画布，即可引入模板和真实产品的设计灵感

Replit Design 工作区由七个组件组成：

* **[Canvas](/zh/design/canvas)**：Project Editor 的设计视图，是一块可无限平移和缩放的画板，用于容纳所有 Frame、形状和注释。
* **[Frames](/zh/design/frames)**：Canvas 上的每个图块。Frame 可以是实时 artifact (如网站、幻灯片) 、设计模型、图像、视频或矢量图形。
* **[元素](/zh/design/elements)**：Frame 内的各个组成部分，例如标题、按钮、图像和表单字段。
* **[Chat](/zh/design/chat-about-your-design)**：停靠在 Canvas 上的 Agent Chat。描述你想创建的内容，或选择一个 Frame 并请求小幅或大幅编辑；将其最小化即可查看完整 Canvas。
* **[Ambient intelligence](/zh/design/explore-suggestions)**：显示在所选 Frame 旁的下一步建议，只需单击即可生成新的方向。有关其工作方式，请参阅[探索建议](/zh/design/explore-suggestions)。
* **[Toolbar](/zh/design/toolbar)**：Canvas 底部的浮动栏，包含 Interact、Pan、Chat、绘制、编辑 和 生成 工具。
* **[资源库面板](/zh/design/library-panel)**：入门模板、由 Mobbin 策划的灵感内容以及你过去创建的内容，随时可拖放到 Canvas 上。

<div id="how-they-fit-together">
  ## 它们如何协同配合
</div>

每个组件都衔接前一个组件的工作成果，带你从空白画板完成可用 Build 实现的设计。

<div id="1-put-frames-on-the-canvas">
  ### 1. 在 Canvas 上添加 frame
</div>

通过 Chat 中的 prompt 或工具栏中的 **生成** 菜单生成 frame。frame 可以是设计模型、web app、移动应用、幻灯片、图像、视频或矢量图形。

<div id="2-iterate-on-a-frame">
  ### 2. 迭代优化 frame
</div>

选择任意 frame，即可单独对其进行处理。用自己的话在 Chat 中描述需求，参考[建议](/zh/design/explore-suggestions)探索新方向，或使用 **Focus** 聚焦处理。满意后，将其 **Build** 为可运行的 App。

<Frame caption="选中的 frame 及其操作栏：Build、Focus 和更多选项。">
  <img src="/assets/mirror/canvas-frame-action-bar-86f90fdd1375.png" alt="Canvas 中选中了一个 APEX X1 Design frame，顶部显示该 frame 的操作栏，包括类型标签以及 Build、Focus 和更多选项；该 frame 以标签形式附加在 Chat 的 prompt 输入框中" width="2000" height="1290" data-path="images/replitai/canvas-frame-action-bar.png" />
</Frame>

<div id="3-edit-annotate-or-generate-with-the-toolbar">
  ### 3. 使用工具栏编辑、批注或生成
</div>

工具栏可完成三项操作：**编辑**可选中 frame 内的单个元素并打开 Visual Editor，**绘制**可用草图、箭头和便签在画板上添加批注，供 Agent 读取；**生成**可创建设计所需的图像、视频和矢量图形。

<Frame caption="使用编辑工具选中元素，右侧打开 Visual Editor。">
  <img src="/assets/mirror/canvas-edit-67fe5ee02fbe.png" alt="在超级跑车租赁网站上启用编辑工具并选中一个 div 元素，Visual Editor 面板显示文本、布局、颜色和边框控件，以及放弃编辑和保存编辑按钮" width="2000" height="1269" data-path="images/replitai/canvas-edit.png" />
</Frame>

<div id="4-pull-inspiration-from-the-library-panel">
  ### 4. 从资源库面板汲取灵感
</div>

如需寻找灵感或起点，请打开资源库面板。模板会以可编辑的实时 frame 形式添加到 Canvas；由 Mobbin 精选的灵感内容则会以静态参考图片的形式添加，为下一次生成提供方向。
