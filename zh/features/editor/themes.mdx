借助 Replit 主题，你可以自定义 Project Editor 的外观，从背景色、界面元素到代码的语法高亮，皆可调整。打造专属的开发环境，让代码更易读、眼睛更轻松，编码体验更愉悦。

<div id="creating-a-custom-theme">
  ## 创建自定义主题
</div>

按照以下步骤创建并自定义你的专属主题：

1. 打开 [Settings](https://replit.com/settings)，进入 **User** → **Personalization** (或 **Themes** 板块)
2. 选择 **Create new theme**
3. 输入标题，选择配色方案 (浅色或深色) ，并可选填描述
4. 选择 **Create Theme**，打开主题编辑器

全局主题设置控制整体界面外观：

* **Background**：设置大多数界面区域的基础颜色
* **Outline**：控制边框和分隔线的颜色
* **Foreground**：决定文本和图标的颜色
* **Primary**：定义按钮和交互元素的颜色
* **Positive**：用于成功状态指示，例如 **Run** 按钮
* **Negative**：用于显示错误和破坏性操作警告

选择 **Apply Theme**，即可立即使用你的自定义主题。

<div id="syntax-highlighting">
  ## 语法高亮
</div>

自定义各类代码元素的显示方式，提升代码的可读性和易理解性。

<Tip>
  恰当的语法高亮能让代码一眼看去更易于浏览和理解。请选择彼此协调的颜色，并确保与背景之间有足够的对比度。
</Tip>

<Accordion title="语法高亮元素">
  | 元素                       | 说明                                     |
  | ------------------------ | -------------------------------------- |
  | **Variable Names**       | 适用于未使用声明关键字的变量                         |
  | **Variable Definitions** | 为使用 `const`、`var` 等关键字定义的变量名着色         |
  | **Function References**  | 适用于函数调用                                |
  | **Function Definitions** | 为声明处的函数名着色                             |
  | **Keywords**             | 高亮 `import`、`function`、`return` 等语言关键字 |
  | **Property Names**       | 为通过变量访问的属性着色                           |
  | **Property Definitions** | 用于定义对象属性时                              |
  | **Function Properties**  | 适用于调用对象上的方法                            |
  | **Tag Names**            | 用于 HTML 和 JSX 标签                       |
  | **Type Names**           | 为类型化语言中的类型注解着色                         |
  | **Class Names**          | 适用于类的声明与引用                             |
  | **Attribute Names**      | 高亮 HTML 和 JSX 属性                       |
  | **Comments**             | 适用于所有代码注释                              |
  | **Strings**              | 为字符串字面量着色                              |
  | **Numbers**              | 高亮数值                                   |
  | **Booleans**             | 设置布尔值 (`true`/`false`) 的格式             |
  | **Regular Expressions**  | 为正则表达式模式着色                             |
  | **Operators**            | 高亮 `+`、`-`、`*`、`/` 等运算符                |
  | **Brackets**             | 在适当情况下为方括号和尖括号着色                       |
</Accordion>

<div id="theme-design-best-practices">
  ## 主题设计最佳实践
</div>

遵循以下准则，打造美观又实用的主题：

<div id="color-and-contrast">
  ### 颜色与对比度
</div>

* **平衡对比度**：确保背景与前景元素之间有足够的差异
* **打造协调的配色**：选择相互衬托而非相互冲突的颜色
* **保持亮度一致**：让各语法元素的亮度水平保持相近
* **兼顾无障碍设计**：避免低对比度的组合，照顾视力障碍用户

<Warning>
  应避免的常见主题设计问题：

  * 语法元素之间亮度差异过大
  * 颜色搭配不当，造成视觉上的不协调
  * 代码与背景之间对比度不足
</Warning>

<div id="managing-your-themes">
  ## 管理你的主题
</div>

在 [Settings](https://replit.com/settings) 中依次进入 **User** → **Personalization** (或 **Themes** 部分) ，即可访问和管理所有已安装的主题。

<div id="switching-themes">
  ### 切换主题
</div>

点击主题名称旁边的按钮，即可将其设为当前主题。

<div id="editing-themes">
  ### 编辑主题
</div>

点击三点菜单并选择 **Edit** (编辑) ，即可修改你的自定义主题。

<Note>
  只有你自己创建的自定义主题才能编辑或删除，默认主题和他人创建的主题无法修改。
</Note>

<div id="deleting-themes">
  ### 删除主题
</div>

点击三点菜单并选择 **Delete**，即可删除自定义主题。

<div id="exploring-community-themes">
  ## 探索社区主题
</div>

在[主题探索页面](https://replit.com/themes)浏览由 Replit 社区创建的主题。

<div id="finding-themes">
  ### 查找主题
</div>

* 按名称搜索，查找特定主题，例如“Atom One Dark”
* 按作者筛选，浏览特定创作者的主题
* 按配色方案浏览，查找浅色或深色主题
* 按特定颜色搜索，找到符合你喜好的主题

安装前可先预览任意主题，查看它在 Project Editor 中的实际效果。

<div id="porting-from-vs-code">
  ## 从 VS Code 迁移
</div>

在创建主题时映射对应的颜色，即可将你喜爱的 VS Code 主题导入 Replit。

<div id="publishing-your-theme">
  ## 发布你的主题
</div>

按照以下步骤，将你的自定义主题分享给 Replit 社区：

1. 打开自定义主题的主题编辑器
2. 点击 **Publish** 按钮
3. 填写标题和描述
4. 提交主题

发布后，你的主题会显示在主题浏览页面 (主题探索页面) 中，其他用户可以在此预览并安装。
