<div id="security-agent-revisa-toda-a-sua-base-de-cdigo">
  ### Security Agent проверяет всю вашу кодовую базу
</div>

**Security Agent** — это новый ИИ-ревизор, который проверяет не только зависимости, но и весь проект целиком. Он строит модель угроз, составляет карту маршрутов и потоков данных, выполняет статический анализ с помощью Semgrep и HoundDog.ai и использует LLM, чтобы определить, какие из найденных проблем действительно可 эксплуатируемы в контексте вашего приложения. По завершении проверки Security Agent распределяет принятые находки по параллельным задачам, которые Replit Agent может исправить за один проход.

  <img src="/assets/mirror/security-agent-findings-b425392bb98a.png" alt="Панель Security Agent в Project Security Center: завершённое сканирование с пятью находками, сгруппированными по уровню серьёзности, у каждой из которых указан статус — например, «Готово к проверке» или «Готово к повторной публикации», а ниже раздел автоматического сканирования зависимостей со списком уязвимых пакетов" width="1438" height="808" data-path="images/changelog/2026-04-24/security-agent-findings.png" />

Security Agent доступен всем пользователям платных тарифов. Откройте панель **Безопасность** в своём проекте и выберите **Запустить сканирование с Agent**, чтобы попробовать.

Подробнее о [Security Agent](/ru/pt/core-concepts/security/project-security-center#agent-security-scans).

<div id="cve-auto-protect-corrige-vulnerabilidades-crticas-automaticamente">
  ### CVE Auto-Protect автоматически устраняет критические уязвимости
</div>

Когда для пакета, от которого зависит ваш App, публикуется новый критический CVE, **CVE Auto-Protect** находит совпадения во всех ваших проектах, поручает Agent подготовить патч в фоновой задаче, прогоняет ваши тесты, чтобы убедиться, что ничего не сломалось, и присылает уведомление со ссылкой на проверку. Контроль остаётся за вами — ничего не публикуется, пока вы не одобрите исправление.

Это значит, что ваши Apps могут быть исправлены уже через несколько минут после того, как уязвимость стала публичной, — не дожидаясь, пока вы её заметите.

Подробнее о [CVE Auto-Protect](/ru/pt/core-concepts/security/project-security-center#auto-protect).

<div id="prvia-em-um-ios-simulator-ou-android-emulator">
  ### Предпросмотр в iOS Simulator или Android Emulator
</div>

<Frame>
  <video autoPlay muted loop playsInline src="/assets/mirror/ios-emulator-9013ff1b602f.mp4" />
</Frame>

Если в вашем проекте есть мобильное приложение, панель предпросмотра теперь может транслировать настоящий **iOS Simulator** или **Android Emulator** прямо в ваш workspace. Без Xcode, без Android Studio и без физического устройства. Создайте мобильное приложение с помощью Agent, выберите устройство в выпадающем меню панели предпросмотра и работайте с ним так, будто держите телефон в руках. Изменения мгновенно подгружаются в симуляторе по мере того, как Agent их вносит.

Доступно платным пользователям на планах Core, Pro и Enterprise в браузерах Chrome, Safari и браузерах на базе Chromium. Firefox мобильные симуляторы не поддерживает.

Подробнее о [предпросмотре в симуляторе или эмуляторе](/ru/pt/replitai/building-mobile-apps#preview-on-a-simulator-or-emulator).

<div id="adicione-um-app-mobile-a-projetos-mais-antigos">
  ### Добавьте мобильное приложение в старые проекты
</div>

<Frame>
  <img src="/assets/mirror/multi-artifact-update-approval-f6fa8b70a100.png" alt="Панель Chat в Agent с карточкой подтверждения «Обновить проект для создания мобильного приложения», предложением кредитов на $5 и кнопками «Не сейчас» / «Обновить проект»." width="991" height="589" data-path="images/replitai/multi-artifact-update-approval.png" />
</Frame>

Проекты, созданные до выхода Agent 4, теперь можно обновить для поддержки нескольких artifact — то есть вы можете добавить мобильное приложение, презентацию или другой artifact в проект, который раньше поддерживал только один. При реорганизации проекта Agent сохраняет его URL, данные, Secrets и deployment. За первые 48 часов после широкого запуска было перенесено более 200 проектов.

Подробнее о том, [как обновить старые проекты для поддержки нескольких artifact](/ru/pt/replitai/updating-projects-for-multiple-artifacts).

<div id="conector-plaid-disponvel">
  ### Доступен коннектор Plaid
</div>

Теперь вы можете подключаться к более чем 12 000 финансовых учреждений с помощью коннектора **Plaid**. Администраторы команды один раз настраивают учётные данные в разделе **Integrations**, после чего пользователи вашего app сами подключают свои банковские счета через Plaid Link. Токены доступа выдаются в рамках каждого пользователя, поэтому данные остаются конфиденциальными.

Создайте личного финансового коуча, работающего с реальными данными о транзакциях, трекер портфеля в реальном времени с подключением к вашему брокеру и многое другое. Загляните на [партнёрскую страницу Replit x Plaid](https://replit.com/partners/plaid) — там есть демонстрации и инструкции по настройке.

Подробнее об [управлении коннекторами](/ru/pt/replitai/managing-connectors).
