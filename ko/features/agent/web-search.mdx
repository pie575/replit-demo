Agent의 Web Search <img class="icon-svg" src="/assets/mirror/web-search-1fe8f63b5b88.svg" alt="Web Search 아이콘" width="16" height="16" data-path="images/icons/web-search.svg" /> 기능으로 최신의 실제 데이터를 활용한 애플리케이션을 만들어 보세요.

이 기능은 웹의 최신 정보를 가져와 지식 컷오프의 한계를 뛰어넘습니다. 최신 정보가 필요한 무언가를 만들어달라고 요청하면, Agent는 웹을 검색하고 상세한 콘텐츠를 가져와 앱을 더 정확하고 유용하게 만듭니다.

Web Search는 최신 패키지, 도구, 정보를 찾는 데 유용합니다. 이를 통해 앱이 최신 모범 사례를 사용하고 더 정확해지도록 보장합니다.

## 기능

Agent의 Web Search로 최신 정보를 활용한 애플리케이션을 만들어 보세요. 이를 통해 수동 리서치와 데이터 수집이 필요 없어집니다. 금융 데이터를 담은 대시보드를 만들든, 최근 스타트업 출시 정보를 보여주는 웹사이트를 만들든, Web Search는 앱이 현실을 반영하도록 보장합니다.

Agent가 수행할 수 있는 Web Search 작업:

* **검색**: 인터넷에서 최신 정보, 최신 문서, 실시간 데이터를 찾기
* **콘텐츠 가져오기**: 특정 웹사이트와 URL에서 상세 정보를 가져오기
* **출처 인용**: Agent가 정보를 어디에서 찾았는지 정확히 확인하여 검증하고 참조하기

## 사용법

Web Search는 Agent에 내장되어 있어 따로 켤 필요가 없습니다. 만들고 싶은 것을 설명하면 Agent가 최신 정보를 검색할 시점을 자동으로 판단합니다. 프롬프트에 "검색해줘", "조사해줘", "Web Search를 사용해줘" 같은 키워드를 포함하면 Agent가 명시적으로 검색하도록 유도할 수 있습니다.

### Web Search가 앱을 개선하는 방식

Web Search는 여러분의 애플리케이션을 플레이스홀더 데이터에서 실제 정확한 정보로 전환시켜 줍니다:

| 이점        | 설명                                      |
| --------- | --------------------------------------- |
| 최신 기술     | 앱이 학습 데이터에 없는 최신 정보와 패키지를 사용합니다         |
| 최적의 도구 선택 | Agent가 옵션을 조사해 최적의 패키지를 선택합니다           |
| 최신 모범 사례  | 최신 개발 패턴과 보안 관행에 접근할 수 있습니다             |
| 한계 극복     | 학습 이후 출시된 패키지를 사용할 수 있도록 지식 컷오프를 뛰어넘습니다 |
| 정확한 데이터   | 앱이 오래된 예시 대신 최신 정보를 표시합니다               |
| 전문적인 결과   | 실제 기업을 참조하는 애플리케이션은 더 신뢰감을 줍니다          |
| 시간 절약     | 패키지를 수동으로 조사하고 데이터를 수집하는 수고를 덜어줍니다      |

### 출처 인용

Agent가 Web Search를 사용할 때, 정보가 정확히 어디서 나왔는지 보여주는 **출처 인용**을 제공합니다. 이 인용을 다음과 같이 활용하세요:

* **정보 검증**: 출처의 신뢰성과 정확성을 확인
* **더 알아보기**: 더 많은 맥락을 위해 원본 출처를 방문
* **출처 참조**: 애플리케이션에 적절한 출처 표시를 포함
* **리서치 추적**: Agent의 작업에 어떤 정보가 반영되었는지 파악

### 콘텐츠 가져오기

Agent는 특정 웹사이트에서 상세 콘텐츠를 가져와 프로젝트를 위한 포괄적인 정보를 수집할 수 있습니다. 이를 통해 Agent는 다음을 할 수 있습니다:

* 전체 웹페이지를 읽어 관련 세부 정보를 추출
* 문서와 참조 자료를 처리
* 신뢰할 수 있는 출처에서 특정 데이터를 수집
* 구조화된 정보를 애플리케이션에 통합
