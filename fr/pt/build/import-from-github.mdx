<div id="importar-do-github">
  ## Importer depuis GitHub
</div>

⏰ *Durée estimée : deux minutes*

Importez un dépôt GitHub dans Replit pour l&#39;exécuter, le tester et le publier plus rapidement.

Pour découvrir toutes les options d&#39;importation, y compris depuis d&#39;autres plateformes comme Figma, Bolt et Lovable, consultez la [documentation de la fonctionnalité d&#39;importation](/fr/pt/references/workspace/import).

<div id="antes-de-comear">
  ## Avant de commencer
</div>

* L’URL d’un dépôt GitHub
* L’accès au dépôt (public ou privé)
* Un compte Replit

<div id="opo-um-importao-rpida">
  ## Option 1 : importation rapide
</div>

L’importation rapide fonctionne pour les dépôts publics.

1. Copiez le chemin du dépôt qui suit `github.com/`.
2. Ouvrez `https://replit.com/github.com/<owner>/<repo>`.
3. Appuyez sur Entrée pour lancer l’importation.

**Exemple**

* URL GitHub : `https://github.com/exampleUser/my-app`
* URL d’importation Replit : `https://replit.com/github.com/exampleUser/my-app`

<div id="opo-dois-importao-guiada">
  ## Deuxième option : importation guidée
</div>

L’importation guidée prend en charge les dépôts publics et privés.

1. Ouvrez [replit.com/import](https://replit.com/import).
2. Sélectionnez **GitHub**.
3. Connectez votre compte GitHub.
4. Choisissez un dépôt.
5. Sélectionnez **Import**.

<div id="o-que-importado">
  ## Éléments importés
</div>

* Fichiers et dossiers du dépôt
* Fichiers de dépendances
* Configuration d’exécution et de build courante

<div id="o-que-no-importado">
  ## Éléments non importés
</div>

* Valeurs Secrets et variables d’environnement existantes
* Services spécifiques à la plateforme qui ne s’exécutent pas sur Replit par défaut
