<div id="novos-modelos-de-ia-nas-integraes">
  ### 集成中的新增 AI 模型
</div>

AI 集成现已支持近期发布的多款 AI 模型：

| 模型                           | 描述                                                               |
| ---------------------------- | ---------------------------------------------------------------- |
| `gpt-5.2`                    | OpenAI 面向知识密集型专业工作的最强模型。首个在 ARC-AGI-1 上得分超过 90% 的模型，上下文窗口达 400K。 |
| `claude-opus-4.5`            | Anthropic 针对编码、智能体和计算机操作优化的主模型，在 SWE-bench Verified 上达到 80.9%。   |
| `gemini-3-flash-preview`     | Google 面向智能体工作流的高速模型，支持 1M token 上下文。推理能力接近 Pro 级别，同时延迟更低、成本更省。  |
| `gemini-3-pro-preview`       | Google 的先进多模态模型，具备顶尖推理能力和真实世界知识。                                 |
| `gemini-3-pro-image-preview` | Google 的 Nano Banana Pro 模型，可生成和编辑高质量图像，并精准渲染文字。                 |
