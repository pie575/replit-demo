ИИ-модели, такие как Claude и GPT, обладают широкими возможностями, но ограничены тем, на чём их обучали. Model Context Protocol (MCP) предоставляет им стандартный способ подключаться к внешним инструментам, источникам данных и возможностям реального мира.

<div id="why-ai-models-need-mcp">
  ## Зачем моделям ИИ нужен MCP
</div>

Без доступа к внешним инструментам и данным модели ИИ не могут:

* получать актуальную информацию;
* взаимодействовать с внешними системами;
* выполнять действия в реальном мире;
* работать с вашими приватными данными.

MCP решает эту проблему, предлагая универсальный способ подключения ИИ к инструментам и данным — примерно так же, как USB-C стандартизировал подключение устройств.

  <img src="/assets/mirror/mcp-a04e01a01743.avif" alt="Схема MCP: модели ИИ подключаются к внешним инструментам и источникам данных" width="1920" height="1055" data-path="images/tutorials/mcp.avif" />
</Frame>

С MCP модели ИИ могут:

* обращаться к специализированным инструментам и API;
* читать данные из закрытых источников;
* выполнять действия в реальном мире;
* без лишних сложностей подключаться к другим системам.

<div id="how-mcp-works">
  ## Как работает MCP
</div>

Архитектура MCP состоит из трёх основных компонентов:

1. **Клиентская сторона** — ИИ-модели вроде Claude или приложения, которым нужен доступ к внешним инструментам.
2. **Уровень взаимодействия** — сам протокол, который задаёт единый формат запросов и ответов.
3. **Серверная сторона** — программы, предоставляющие доступ к инструментам, источникам данных и специализированным возможностям.

<AccordionGroup>
  <Accordion title="Что такое клиент MCP?">
    Клиент MCP — это, например, Claude, Replit Agent или интерфейс командной строки, подключённый к большой языковой модели. Это «устройство», которое подключается к внешним инструментам или источникам данных.

    Примеры клиентов MCP:

    * Claude в браузере
    * Replit Agent
    * Интерфейсы командной строки для ИИ
    * Собственные приложения, созданные с помощью ИИ-SDK
  </Accordion>

  <Accordion title="Что такое MCP-сервер?">
    MCP-сервер предоставляет ИИ-моделям инструменты и возможности. Представьте, что вы даёте ИИ набор специализированных инструментов для решения задач.

    Примеры того, что позволяют MCP-серверы:

    * Обращаться к определённым источникам данных для ответа на вопросы
    * Подключать ИИ к API, чтобы он мог выполнять действия онлайн
    * Читать и записывать файлы
    * Выполнять вычисления или запускать код
    * Получать содержимое из таких сервисов, как Notion, Linear или Stripe
  </Accordion>
</AccordionGroup>

<div id="what-mcp-unlocks">
  ## Возможности MCP
</div>

MCP определяет несколько примитивов, которые делают его мощным инструментом для AI-приложений:

* **Ресурсы** — предоставляют AI-моделям доступ к данным и контенту
* **Инструменты** — позволяют AI-моделям выполнять действия через ваши сервисы
* **Промпты** — повторно используемые шаблоны для единообразного взаимодействия с AI
* **Семплирование** — позволяет вашим сервисам запрашивать информацию у AI-моделей
* **Транспорты** — эффективно соединяют клиентов и серверы

<div id="skills-vs-mcp-servers">
  ## Навыки и MCP-серверы
</div>

Навыки и MCP-серверы — два основных способа расширить возможности ИИ-агентов, и у них разные назначения.

|                              | Навыки                                                                      | MCP-серверы                                                        |
| ---------------------------- | --------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| **Лучше всего подходят для** | Рабочих процессов, соглашений и справочных материалов                       | Подключения к внешним сервисам и выполнения действий               |
| **Загрузка**                 | Легковесная — до вызова загружаются только имя и описание                   | Более ресурсоёмкая — все описания инструментов загружаются заранее |
| **Определяют**               | *Как* должен работать ваш агент                                             | *К чему* ваш агент может получать доступ                           |
| **Пример**                   | Навык «Анализатор акций» — исследование инвестиций по определённой методике | MCP-сервер «Stripe» — чтение данных о платежах и подписках         |

Подробнее о соответствующем подходе к навыкам см. в разделе [Навыки Agent](/ru/learn/agent-skills).

<div id="real-world-applications">
  ## Практическое применение
</div>

MCP открывает возможности для широкого спектра ИИ-приложений:

* **Системы клиентской поддержки**, которые обращаются к базам данных компании, чтобы отвечать на конкретные вопросы
* **Исследовательские ассистенты**, которые находят и обобщают материалы из нескольких источников
* **Инструменты для повышения продуктивности**, которые работают с вашими файлами и приложениями
* **Инструменты для создания контента**, которые обращаются к медиатекам и платформам публикации

<div id="benefits">
  ## Преимущества
</div>

MCP предлагает три ключевых преимущества:

* Готовые интеграции, к которым ваш ИИ может подключиться сразу
* Возможность переключаться между поставщиками ИИ без необходимости перенастраивать подключения
* Средства защиты конфиденциальных данных

<Note>
  MCP — развивающийся стандарт, который получает всё большую поддержку в экосистеме ИИ. Новые инструменты и интеграции регулярно добавляются.
</Note>
