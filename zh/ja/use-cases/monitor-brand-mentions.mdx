  ## 预期结果
</div>

Agent 会监控提及内容，评估其重要性，在 Slack 中发布简短摘要，并将讨论串保存到 Notion。请查看首批结果，并调整“重要”的判定标准。如果完全没有收到提及内容，请确认是否已设置 Bearer Token，以及 X 开发者账户是否有可用额度。首次在早晨运行后，打开 Slack 提醒，跳转到 X 中的链接，再确认 Notion 中对应行是否包含相同链接。

<div id="section-6">
  ## 故障排查
</div>

* **完全收不到提及：** 请确认已配置 X 的 Bearer Token，并检查 X 开发者账号中是否还有额度。额度不足时，即使 Token 有效，提及搜索也会失败。
* **Slack 毫无动静，只有 Notion 在不断堆积：** 可能是 Agent 把所有内容都当成了噪声。请收紧“重要”的判定标准，或要求它即使无需回复也发布每日摘要。
* **归档变得杂乱：** 请为 Agent 指定一个已有相应列 (日期、链接、情感倾向、是否需要回复) 的 Notion 数据库，并要求它把内容映射到这些字段，而不是每次都新建页面。
