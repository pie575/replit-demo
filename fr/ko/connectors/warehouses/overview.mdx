Les connecteurs d&#39;entrepôt de données permettent à Replit Agent d&#39;interroger en toute sécurité l&#39;entrepôt de données de votre organisation. Les builders peuvent créer des tableaux de bord, des outils de reporting et des applications de données en langage naturel, sans aucune expertise SQL. Les administrateurs conservent un contrôle centralisé grâce à un accès basé sur les rôles.

<div id="section">
  ## Entrepôts de données pris en charge
</div>

Les connecteurs d&#39;entrepôt de données sont disponibles avec le plan **Enterprise**.

| Entrepôt         | Guide de configuration                                                                                               |
| ---------------- | -------------------------------------------------------------------------------------------------------------------- |
| BigQuery         | Disponible dès maintenant — guide de configuration à venir                                                           |
| Databricks       | [Connexion à Databricks](/fr/ko/connectors/warehouses/databricks)                                                    |
| Microsoft Fabric | [Créer des applications de données avec Microsoft Fabric](/fr/ko/connectors/warehouses/microsoft-fabric) (aperçu privé) |
| Snowflake        | [Connexion à Snowflake](/fr/ko/connectors/warehouses/snowflake)                                                      |

Chaque entrepôt possède son propre flux de configuration, car les intégrations OAuth, les modèles d&#39;identité et les formats d&#39;identifiants varient d&#39;un service à l&#39;autre. Sélectionnez l&#39;entrepôt que vous utilisez et suivez le guide dédié.

<div id="section-2">
  ## Plateformes d&#39;analyse et de données
</div>

Les connecteurs d&#39;analyse sont disponibles avec les plans Core et Pro, en plus d&#39;Enterprise. Connectez vos outils d&#39;analyse pour permettre à Agent de lire vos données produit et de les exploiter :

* **Segment** — données clients, flux d&#39;événements et segments d&#39;audience de votre CDP
* **Amplitude** — analyses produit, données de comportement des utilisateurs et indicateurs d&#39;engagement
* **Hex** — notebooks de données collaboratifs et résultats de requêtes

Gérez-les de la même manière que les autres connecteurs Replit. Consultez [Gestion des connecteurs](/fr/ko/replitai/managing-connectors).

<div id="section-3">
  ## Fonctionnement du connecteur d&#39;entrepôt de données
</div>

La configuration est un processus ponctuel qui fait intervenir trois rôles :

1. **Administrateur de l&#39;entrepôt de données** — crée une intégration OAuth ou une identité de service dans l&#39;entrepôt de données
2. **Administrateur de l&#39;organisation Replit** — ajoute les identifiants dans Replit et configure les accès
3. **Builder** — se connecte et commence à créer avec Agent

Une fois la configuration terminée, le builder demande à Agent d&#39;utiliser l&#39;entrepôt de données, et Agent rédige puis exécute le SQL.

<div id="section-4">
  ### Créer avec les données de l&#39;entrepôt
</div>

Une fois la connexion établie, vous pouvez demander à Agent de créer des applications qui exploitent vos données. Agent peut ainsi :

* Créer des outils internes qui récupèrent et affichent des données en temps réel
* Créer des tableaux de bord avec des graphiques et des visualisations basés sur les données de l&#39;entrepôt
* Générer les requêtes SQL qui alimentent le backend de vos applications
* Décrire les schémas et la structure des tables pour vous aider à définir ce que vous souhaitez créer

<Note>
  Agent peut répondre à des questions ponctuelles sur vos données, mais l&#39;objectif principal du connecteur d&#39;entrepôt de données est de vous permettre de créer des applications fonctionnelles qui exploitent les données de votre organisation. Les requêtes vers l&#39;entrepôt sont exécutées directement sur votre instance : vérifiez donc que les portées OAuth et les autorisations de l&#39;utilisateur de base de données autorisent bien les opérations de lecture et d&#39;écriture dont vous avez besoin.
</Note>
