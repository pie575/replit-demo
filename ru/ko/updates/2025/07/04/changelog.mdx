<div id="agent">
  ### Веб-поиск для Agent
</div>

<Frame>
  <img src="/assets/mirror/web-search-6c28195531d4.jpg" alt="Интерфейс Agent с результатами веб-поиска и ссылками на источники для разработки приложения" width="1920" height="1080" data-path="images/replitai/web-search.jpg" />
</Frame>

Теперь Agent может находить и получать актуальную информацию из интернета с помощью [веб-поиска](/ru/core-concepts/agent/web-search). Создавайте приложения на основе свежей документации, текущих рыночных данных и точных сведений со всего интернета. Никаких ограничений по дате обучения модели — теперь ваши приложения опираются на самые свежие данные.

<div id="agent-2">
  ### Настраиваемые инструкции для Agent
</div>

<Frame>
  <img src="/assets/mirror/replitmd-65360844a148.jpg" alt="Файл replit.md с параметрами настройки проекта" width="1920" height="1080" data-path="images/replitai/replitmd.jpg" />
</Frame>

Персонализируйте работу с Agent с помощью файла [replit.md](/ru/core-concepts/agent/replit-dot-md). В этом специальном файле можно задать стиль написания кода, настройки проекта по умолчанию и контекст. Agent создаёт его автоматически, опираясь на проверенные практики, а вы можете адаптировать его под свой рабочий процесс.

<div id="section-3">
  ### Оплата по объёму работы
</div>

<Frame>
  <img src="/assets/mirror/effort-based-billing-d971548c7c39.png" alt="Интерфейс оплаты по объёму работы с динамическим ценообразованием на основе фактических усилий Agent" width="2048" height="1424" data-path="images/changelog/2025-07-04/effort-based-billing.png" />
</Frame>

Оцените более разумное ценообразование чекпоинтов с новой [оплатой по объёму работы](/ru/ko/billing/ai-billing). Цена определяется динамически, исходя из фактически проделанной Agent работы, и вместо нескольких чекпоинтов создаётся один чекпоинт на запуск.

  ### App Store для Teams
</div>

Теперь находить приложения вашей команды и управлять ими проще, чем когда-либо. Новый раздел «App Store» на странице деплоев позволяет добавлять избранное в звёздочки, искать по всем деплоям, просматривать недавно открытые приложения и находить популярные деплои по объёму трафика.
