<div id="what-are-artifacts">
  ## Que sont les artifacts ?
</div>

Les artifacts sont les éléments que vous pouvez publier sur Replit : web apps, applications mobiles, présentations, animations, applications de données, jeux 3D et designs. Chacun constitue un résultat complet et autonome, doté de sa propre URL partageable dès la publication.

Tout le reste de votre project — fichiers, images, CSV, code — vient en appui de vos artifacts, mais ne peut pas être publié séparément.

<div id="getting-started">
  ## Premiers pas
</div>

Il existe deux façons de créer depuis la page d&#39;accueil Replit :

* **Décrivez votre idée** : indiquez ce que vous souhaitez obtenir — « crée-moi une application de recettes » ou « fais un pitch deck pour ma startup ». Agent détermine le type le mieux adapté et le construit.
* **Choisissez un type** : sélectionnez l&#39;artifact souhaité — web app, application mobile, visualisation de données, animation, jeu 3D ou tout autre type pris en charge — avant de décrire votre idée.

Vous pouvez également enrichir un project existant à tout moment en le demandant à Agent dans le chat ou en cliquant sur le bouton **+** du panneau Preview.

<div id="switching-between-artifacts">
  ## Basculer entre les artifacts
</div>

Dès que votre project contient plusieurs artifacts, vous pouvez passer de l&#39;un à l&#39;autre depuis le **panneau Preview** ou la **barre latérale Bibliothèque**. Vous pouvez aussi le demander à Agent : « montre-moi l&#39;application mobile » ou « passe aux slides ».

<div id="library-sidebar">
  ### Barre latérale Bibliothèque
</div>

La barre latérale Bibliothèque vous offre un espace centralisé pour parcourir tout le contenu de votre project. Elle affiche vos artifacts, les images générées ou téléchargées par Agent, ainsi que les autres ressources du project. Ouvrez-la depuis le panneau de gauche pour retrouver et réutiliser n&#39;importe quelle ressource de votre project.

<div id="multiple-artifacts-in-one-project">
  ## Plusieurs artifacts dans un même project
</div>

Un même project peut contenir jusqu&#39;à **7 artifacts**, dont **1 application mobile** au maximum. Par exemple, vous pouvez créer une web app pour vos clients, une application mobile pour votre équipe et une présentation pour vos investisseurs — le tout dans le même project.

<ArtifactGrid />

<div id="adding-artifacts-to-a-project">
  ### Ajouter des artifacts à un project
</div>

Il existe trois façons d&#39;ajouter un artifact à un project existant :

* **Chat** : demandez à Agent — « ajoute une application mobile à ce project » ou « crée une présentation pour le pitch investisseurs »
* **Bouton plus** : cliquez sur le bouton **+** dans le panneau Preview et choisissez ce que vous souhaitez créer
* **Barre latérale Bibliothèque** : parcourez vos artifacts, images et autres ressources existants, et ajoutez-y de nouveaux artifacts

<div id="shared-data-and-backend">
  ### Données et backend partagés
</div>

Lorsque plusieurs artifacts se trouvent dans le même project, ils partagent automatiquement les mêmes données et la même logique backend. Si un client passe une commande depuis votre web app, votre application mobile et votre tableau de bord de données voient eux aussi cette commande. Aucune connexion à configurer, aucun code à dupliquer — tout fonctionne d&#39;emblée.

<Note>
  La publication met en ligne l&#39;intégralité de votre project en une seule fois. Tous les artifacts sont publiés ensemble, et restent donc toujours synchronisés.
</Note>

<div id="example-combinations">
  ### Exemples de combinaisons
</div>

* **Web app + application mobile** : un restaurant avec une web app destinée aux clients et une application mobile pour le personnel — toutes deux connectées à la même API et à la même base de données
* **Application + tableau de bord d&#39;administration** : un produit principal accompagné d&#39;un panneau d&#39;administration interne pour gérer le contenu, les utilisateurs ou les paramètres
* **Application + présentation** : votre produit et un pitch deck dans le même project, afin que les diapositives reflètent toujours la version la plus récente
* **Tableau de bord de données + vidéo** : une visualisation de données en temps réel associée à une vidéo animée qui en présente les points forts

<div id="publishing">
  ## publication
</div>

Les apps, les présentations et les vidéos peuvent toutes être publiées et partagées. Chacune reçoit sa propre URL partageable lors de la publication.

Les fichiers et ressources qui ne sont pas des artifacts (comme les fichiers CSV, les images ou les fichiers markdown) ne peuvent pas être publiés seuls. Pour les partager, ajoutez-les à une app ou créez un nouvel artifact.

<div id="frequently-asked-questions">
  ## Questions fréquentes
</div>

<Accordion title="Puis-je avoir plusieurs artifacts dans un project ?">
  Oui. Un même project peut contenir jusqu&#39;à **7 artifacts au total**, avec une limite d&#39;**1 application mobile par project**. Tous les artifacts d&#39;un project partagent automatiquement le même backend et les mêmes données.

  Si vous atteignez la limite d&#39;applications mobiles et que vous souhaitez créer une deuxième application mobile, créez-la dans un nouveau project. Si vous atteignez le total de 7 artifacts, supprimez un artifact existant avant d&#39;en ajouter un autre, ou répartissez votre travail sur plusieurs projects.
</Accordion>

<Accordion title="Dois-je choisir un type avant de commencer ?">
  Non. Décrivez simplement ce que vous voulez et Agent choisit le type adapté à votre place. Vous pouvez aussi sélectionner un type manuellement dans le menu déroulant si vous préférez.
</Accordion>

<Accordion title="Puis-je publier un seul artifact d'un project ?">
  Pas pour le moment. La publication met en ligne l&#39;intégralité du project en une seule fois, afin que tous les artifacts restent synchronisés. Si vous avez besoin de publier chaque élément indépendamment, utilisez des projects distincts.
</Accordion>

<Accordion title="Les artifacts partagent-ils leurs données entre eux ?">
  Oui. Tous les artifacts d&#39;un project partagent la même base de données et les mêmes services backend. Si votre web app écrit des données, votre application mobile et votre tableau de bord de données peuvent les lire immédiatement.
</Accordion>

<Accordion title="Quelle est la différence entre un artifact et un fichier ?">
  Les artifacts sont des éléments que vous pouvez publier : applications, présentations et vidéos. Les fichiers (CSV, images ou code, par exemple) sont des ressources de votre project qui alimentent vos artifacts, mais qui ne peuvent pas être publiés seuls.
</Accordion>

<Accordion title="Il manque des fonctionnalités de ma web app dans mon application mobile. Que s'est-il passé ?">
  Lorsque Agent transpose des fonctionnalités d&#39;un type d&#39;artifact à un autre, certains éléments peuvent ne pas être repris à l&#39;identique, en particulier les interactions ou les mises en page qui fonctionnent différemment d&#39;une plateforme à l&#39;autre. Vous pouvez le relancer dans Chat pour combler les manques.
</Accordion>

Pour une liste complète de ce que vous pouvez créer, consultez la [présentation des Projects](/fr/features/projects-and-artifacts/projects).
