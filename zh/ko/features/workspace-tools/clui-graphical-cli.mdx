CLUI (命令行用户界面) 是 Replit 的交互式命令栏，让您无需浏览菜单即可快速执行各种操作。它兼具命令行的高效性与图形界面的直观性。

<div id="section">
  ## 功能
</div>

CLUI 在 Replit 的三种不同场景中提供强大的命令式交互：

* **设置管理**：管理设置、查看提醒，并恢复已删除的 Replit 应用
* **快速导航**：在 Replit 应用之间切换，并通过快捷方式访问常用功能
* **Workspace 操作**：在开发环境中查找文件、搜索代码和访问工具

<div id="section-2">
  ## 使用方法
</div>

<div id="clui">
  ### 账户 CLUI
</div>

账户 CLUI 可帮助您管理设置、团队和已删除的 Replit 应用。

**访问方式**：前往 [CLUI 页面](https://replit.com/~/cli)，在输入框中输入要搜索的命令，然后按 Enter 执行。

<Accordion title="账户命令">
  输入 `account` 以管理设置：

  * **view-warns**：查看您收到的警告
  * **change-username**：更改用户名 (仅限一次) 
</Accordion>

<Accordion title="Trash 命令">
  输入 `trash` 以管理已删除的 Replit 应用：

  * **restore &lt;title&gt;**：按标题恢复已删除的 Replit 应用 (如有多个同名应用，将恢复最近删除的应用) 
  * **view**：查看最近删除的 Replit 应用
</Accordion>

<Accordion title="团队命令">
  输入 `team` 以管理团队：

  * **view**：按用户名查看您所在团队的成员
  * **fork-repl-to-project**：通过分叉现有 Replit 应用创建团队项目
</Accordion>

<Accordion title="清除命令">
  输入 `clear` 以清除已执行命令的屏幕内容
</Accordion>

<div id="clui-2">
  ### 快捷方式 CLUI
</div>

快捷方式 CLUI 可让您从任何页面快速访问常用的 Replit 功能。

<Frame>
  <img src="/assets/mirror/shortcuts-clui-768d49b44785.png" alt="快捷方式 CLUI" width="689" height="291" data-path="images/getting-started/shortcuts-clui.png" />
</Frame>

**访问方式**：在大多数 Replit 页面中，按下 **CMD/CTRL + K**，或点击顶部导航栏中的搜索图标。

<Accordion title="可用命令">
  * **Search**：搜索 Replit 应用、模板、代码、用户等
  * **New**：创建新的 Replit 应用
  * **My Replit Apps**：浏览并前往 Replit 应用
  * **My Code**：搜索所有 Replit 应用中的代码
</Accordion>

<div id="workspace-clui">
  ### Workspace CLUI
</div>

Workspace CLUI 可帮助你在 Replit 应用中工作时执行任务、访问工具、查找文件和搜索代码。

<Frame>
  <img src="/assets/mirror/ws-clui-81764b3d111b.png" alt="Workspace CLUI" width="429" height="202" data-path="images/getting-started/ws-clui.png" />
</Frame>

**访问方式**：在 Workspace 中按 **CMD/CTRL + K**，或点击左上角的搜索图标。

<Accordion title="常用操作">
  * **查找文件**：快速查找项目中的文件
  * **搜索代码**：在所有文件中查找特定代码片段
  * **访问工具**：打开 Workspace 中可用的工具或面板
  * **执行命令**：运行与 Workspace 相关的命令
</Accordion>
