# Surveillez votre application

> Vérifiez si votre application publiée est en ligne, comment elle répond, et ce qu'elle consomme, avec des graphiques de disponibilité, de requêtes et d'utilisation.

L'outil Surveillance répond à trois questions sur votre application publiée : est-elle en ligne, comment se comporte-t-elle, et que consomme-t-elle ? Ouvrez **Surveillance** sous **Replit Cloud** dans le panneau **Outils**.

La surveillance démarre une fois votre application publiée. Avant cela, l'outil affiche un message **Aucun déploiement pour le moment**.

<Note>
  Vous cherchez les informations sur les visiteurs et les utilisateurs ? Ouvrez [Analyses
  du projet](/fr/features/publishing/project-analytics) dans le panneau **Growth**.
</Note>

## Surveillance de l'application

La surveillance de l'application montre comment votre application se comporte du point de vue de vos visiteurs. Choisissez une période en haut pour zoomer ou dézoomer.

<Frame>
  <img src="https://mintcdn.com/replit/BUcQPNDB2pXU4rMm/images/deployments/monitoring/application-monitoring.png?fit=max&auto=format&n=BUcQPNDB2pXU4rMm&q=85&s=cd182ec7dc73b70af96180f05722847d" alt="Vue de surveillance de l'application affichant la surveillance de la disponibilité, un graphique des requêtes avec les adresses IP uniques, les statuts HTTP et les durées des requêtes" width="2000" height="1656" data-path="images/deployments/monitoring/application-monitoring.png" />
</Frame>

* **Surveillance de la disponibilité** : Affiche le pourcentage de temps pendant lequel votre application était en ligne, avec une barre colorée pour l'historique récent. Replit vérifie votre application selon un calendrier régulier et vous envoie un e-mail si elle tombe en panne.
* **Requêtes** : Le volume de trafic que votre application traite au fil du temps, ainsi que le nombre d'adresses IP uniques qui l'atteignent.
* **Statuts HTTP** : Comment votre application a répondu aux requêtes récentes. Les réponses réussies sont saines ; un pic d'erreurs est un signe qu'il faut enquêter. Collez la période d'un pic d'erreurs dans le chat de l'Agent et demandez-lui de vérifier les journaux.
* **Durées des requêtes** : Le temps que prend votre application pour répondre, regroupé en intervalles. Si la plupart des requêtes se trouvent dans les intervalles les plus lents, votre application peut avoir besoin d'attention ou d'une [machine plus puissante](/fr/features/publishing/machine-configuration).

### Activer la surveillance de la disponibilité

Les vérifications de disponibilité sont contrôlées depuis les paramètres de publication.

<Steps>
  <Step title="Ouvrez les paramètres de publication">
    Ouvrez l'outil **Publication** et démarrez une nouvelle publication ou republiez votre application.
  </Step>

  <Step title="Activez la bascule">
    Sous **Outils de surveillance**, activez **Activer la surveillance de l'application**, puis publiez votre application.
  </Step>

  <Step title="Consultez votre disponibilité">
    Après la publication, votre disponibilité apparaît dans l'outil Surveillance en quelques minutes.
  </Step>
</Steps>

<Note>
  La surveillance de la disponibilité est disponible sur les plans Replit Core, Pro et Enterprise. Elle fonctionne pour tous les types de déploiement sauf les déploiements planifiés, qui ne servent pas de page web.
</Note>

## Surveillance de l'infrastructure

La surveillance de l'infrastructure montre ce que votre application consomme en coulisses.

<Frame>
  <img src="https://mintcdn.com/replit/BUcQPNDB2pXU4rMm/images/deployments/monitoring/infrastructure-monitoring.png?fit=max&auto=format&n=BUcQPNDB2pXU4rMm&q=85&s=60d6fea9e0ecb56c963462137d97ae77" alt="Vue de surveillance de l'infrastructure affichant les graphiques d'utilisation du CPU et de la mémoire sur la dernière heure" width="2000" height="1513" data-path="images/deployments/monitoring/infrastructure-monitoring.png" />
</Frame>

* **Utilisation du CPU** : La puissance de traitement que votre application utilise.
* **Utilisation de la mémoire** : La quantité de mémoire que votre application utilise.

Des pics occasionnels sont normaux. Si l'un des graphiques reste constamment élevé, votre application peut répondre lentement sous charge. Envisagez une [configuration de machine plus puissante](/fr/features/publishing/machine-configuration).

## Journaux

Les journaux montrent ce que fait votre application en temps réel, y compris les erreurs et les messages que votre application affiche pendant son exécution. Replit conserve les journaux de déploiement pendant 30 jours.

Vous pouvez affiner les journaux avec les filtres suivants :

* **Erreurs uniquement** : Affichez uniquement les journaux d'erreurs.
* **Rechercher** : Saisissez une phrase à trouver dans les journaux.
* **Date** : Sélectionnez une plage de dates.

<Tip>
  Si quelque chose semble anormal dans votre application, vous n'avez pas besoin de lire les journaux vous-même. Demandez à l'Agent d'enquêter, il lit les journaux pour vous.
</Tip>
