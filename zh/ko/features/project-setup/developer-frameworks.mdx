<div id="section">
  ## 开发者框架模板已移除
</div>

语言和框架入门模板 (原称“开发者框架”) 不再由 Replit 提供。`replit.com/templates` 和 `replit.com/developer-frameworks` 页面现会重定向至 [Replit 作品展厅](https://replit.com/gallery)。

如需开始新项目，请改用以下方式之一：

* **使用 Replit Agent 开始构建** — 在[主页](https://replit.com/)描述您想创建的内容，Agent 会为您的项目搭建基本框架。
* **[从 GitHub、GitLab 或 Bitbucket 导入](/zh/ko/build/import-from-providers)** — 将现有代码库或入门技术栈导入为新的 Replit App。
* **[混搭已发布的应用](https://replit.com/gallery)** — 浏览 Replit 作品展厅，查找并混搭可作为起点的社区应用。

<div id="section-2">
  ## 企业版自定义模板
</div>

企业版组织可以创建[自定义模板](/zh/ko/teams/custom-templates)，让所有组织成员在 Agent 输入框中将其作为可选项使用。自定义模板比开发者框架更进一步，可包含公司专属的 Agent 指令、技能和预先配置的项目上下文。有关详细信息，请参阅[自定义模板指南](/zh/ko/teams/custom-templates)。
