<div id="o-que-so-skills">
  ## Que sont les compétences
</div>

Les compétences apprennent à Agent votre façon de travailler. Au fil de vos créations communes, vous produisez un contexte utile sur votre projet, mais ce contexte disparaît généralement une fois le chat terminé. Les compétences conservent ce que vous avez appris afin qu&#39;Agent puisse l&#39;appliquer de manière cohérente. Les tâches jusque-là irrégulières gagnent en fiabilité et donnent de meilleurs résultats à chaque fois.

Par exemple, une compétence dédiée au système de design garantit qu&#39;Agent utilise exactement vos couleurs et vos règles d&#39;espacement. Une compétence de correction de bugs consigne les solutions pour qu&#39;Agent s&#39;en souvienne la prochaine fois.

<div id="duas-formas-de-usar-skills">
  ## Deux façons d&#39;utiliser les compétences
</div>

Il existe deux façons d&#39;utiliser les compétences avec Agent, selon que vous souhaitiez qu&#39;une compétence s&#39;applique à un seul message ou à l&#39;ensemble de votre projet.

<div id="usar-uma-skill-no-chat">
  ### Utiliser une compétence dans le chat
</div>

Le moyen le plus rapide d&#39;utiliser une compétence consiste à l&#39;ajouter directement à un message. Cliquez sur le bouton **+** à côté du champ de chat, sélectionnez **Utiliser une compétence** et parcourez les catégories disponibles. Lorsque vous sélectionnez une compétence, elle apparaît sous forme de pastille jointe à votre message. Agent utilise cette compétence uniquement pour la tâche en cours — elle n&#39;est pas installée dans votre projet.

Cette option est idéale lorsque vous souhaitez qu&#39;Agent réalise une tâche ponctuelle nécessitant des connaissances spécialisées. Par exemple, vous pouvez sélectionner la compétence **Analyseur d&#39;actions** et demander à Agent d&#39;analyser un investissement, ou choisir la compétence **Créateur de CV** pour créer un CV soigné.

Les compétences sont organisées dans les catégories suivantes :

| Catégorie                | Exemples de compétences                                                                 |
| ------------------------ | --------------------------------------------------------------------------------------- |
| **Ventes et marketing**  | Créatif publicitaire, SDR avec IA, Audit SEO, Machine à contenu                         |
| **Carrière**             | Recruteur avec IA, Créateur de CV, Préparation aux entretiens                           |
| **Recherche et analyse** | Analyse concurrentielle, Recherche approfondie, Recherche de fournisseurs               |
| **Affaires et finances** | Analyseur d&#39;actions, Générateur de factures, Analyseur immobilier                   |
| **Documents et outils**  | Générateur Excel, Cloneur de sites, Convertisseur de fichiers, Générateur de flashcards |
| **Créatif**              | Éditeur de photos, Générateur de podcasts, Générateur d&#39;identité visuelle           |
| **Productivité**         | Secrétaire avec IA, Chef de produit, Penseur en design                                  |
| **Personnel**            | Assistant de voyage, Créateur de recettes, Planificateur de repas, Acheteur personnel   |

<Tip>
  Vous pouvez également saisir « utilise la compétence Analyseur d&#39;actions » (ou le nom de n&#39;importe quelle compétence) directement dans votre message sans ouvrir le sélecteur de compétences — Agent comprend votre demande.
</Tip>

<div id="instalar-uma-skill-no-seu-projeto">
  ### Installer une compétence dans votre projet
</div>

Lorsque vous souhaitez qu&#39;Agent applique une compétence de manière systématique dans toutes les conversations d&#39;un projet, installez-la dans le répertoire `/.agents/skills` de votre projet. Les compétences installées persistent d&#39;une session de Chat à l&#39;autre et restent toujours disponibles pour Agent lorsqu&#39;il travaille sur votre projet.

C&#39;est la solution idéale pour les connaissances propres au projet, comme votre système de design, vos conventions de codage ou les solutions à des problèmes récurrents.

<div id="adicionando-skills-ao-seu-projeto">
  ## Ajouter des compétences à votre projet
</div>

Il existe plusieurs façons d&#39;ajouter une compétence à votre projet de manière permanente.

<div id="criar-com-o-agent">
  ### Créer avec Agent
</div>

La façon la plus naturelle de créer des compétences est de passer par la conversation. Une fois que vous avez résolu un problème ensemble, demandez à Agent de consigner ce qu&#39;il a appris. La compétence s&#39;écrit alors d&#39;elle-même à partir du contexte partagé.

```
Crée une compétence pour mon système de design à partir de ces palettes de couleurs et de ces règles d'espacement
```

Vous pouvez également demander à Agent de faire des recherches et de créer des compétences pour de nouveaux domaines :

```
Recherche les bonnes pratiques de génération vidéo avec Remotion et crée une compétence
```

<div id="descobrir-e-instalar-no-painel-de-skills">
  ### Découvrir et installer depuis le panneau Compétences
</div>

Ouvrez le **panneau Compétences** dans l&#39;Éditeur de projets et sélectionnez l&#39;onglet **Découvrir** pour explorer les compétences proposées par la communauté. Vous pouvez parcourir les compétences par nom, effectuer une recherche par mot-clé et installer n&#39;importe quelle compétence directement dans votre projet en un seul clic.

<div id="instalar-pelo-diretrio-de-skills">
  ### Installer depuis l&#39;annuaire de compétences
</div>

L&#39;[annuaire des Compétences Agent](https://skills.sh) propose des compétences créées par la communauté que vous pouvez installer directement. Replit prend en charge l&#39;installation via [npx skills CLI](https://github.com/vercel-labs/skills) :

```bash theme={null}
npx skills <skill> -a replit
```

Cela installe la compétence dans le répertoire `/.agents/skills` de votre projet.

<Warning>
  Les compétences peuvent contenir du contenu et du code arbitraires. Vérifiez toujours la source avant
  d’installer une compétence provenant de sources externes.
</Warning>

<div id="como-as-skills-funcionam">
  ## Comment fonctionnent les compétences
</div>

Les compétences sont stockées dans le répertoire `/.agents/skills` de votre projet. Chaque compétence suit la [spécification des Compétences Agent](https://agentskills.io/specification), qui définit la structure et le format des fichiers de compétence.

Agent voit le nom et la description de chaque compétence installée, mais il n&#39;en charge le contenu complet que lorsqu&#39;elle est pertinente pour la tâche en cours. L&#39;ensemble reste ainsi léger : vous pouvez installer de nombreuses compétences sans ralentir Agent.

Les compétences installées sont conservées dans votre projet : elles restent donc disponibles d&#39;une session Agent à l&#39;autre et peuvent être ajoutées au contrôle de version pour être partagées avec l&#39;équipe.

Les compétences peuvent avoir différentes portées :

* **Niveau projet** : spécifiques à un projet, versionnées avec vos fichiers dans `/.agents/skills`
* **Niveau utilisateur** : votre boîte à outils personnelle, qui vous suit dans tous vos projets
* **Enterprise** : des standards valables pour toute l&#39;entreprise, intégrés à des [templates personnalisés](/fr/pt/teams/custom-templates) et épinglés à l&#39;entrée d&#39;Agent pour votre organisation

<Note>
  Les compétences donnent les meilleurs résultats lorsqu&#39;elles capturent des schémas précis et reproductibles plutôt que des
  conseils généraux. Concentrez-vous sur des flux de travail concrets, des conventions établies et
  des solutions éprouvées de votre projet.
</Note>

<div id="trabalhando-com-outras-ferramentas-de-codificao-com-ia">
  ## Travailler avec d&#39;autres outils de codage assistés par IA
</div>

<Accordion title="Importer des compétences depuis d'autres outils de codage assistés par IA">
  Si vous utilisez plusieurs outils de codage assistés par IA, [rulesync](https://github.com/dyoshikawa/rulesync) prend en charge Replit et vous aide à conserver des configurations cohérentes.

  Vous pouvez importer des compétences depuis d&#39;autres assistants de codage IA :

  ```bash theme={null}
  npx rulesync init
  npx rulesync import --targets claudecode --features skills
  npx rulesync generate --targets replit --features skills
  ```

  Vous pouvez ainsi conserver un seul ensemble de compétences, utilisable dans différents environnements de développement.
</Accordion>
