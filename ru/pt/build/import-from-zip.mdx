<div id="importar-de-zip">
  ## Импорт из ZIP
</div>

⏰ *Примерное время: три минуты*

Импортируйте локальный проект, загрузив файл `.zip`.

Подробнее о различных вариантах импорта, включая импорт с других платформ, таких как GitHub, Figma, Bolt, Lovable и Vercel, см. в [документации по импорту](/ru/pt/references/workspace/import).

<div id="antes-de-comear">
  ## Перед началом
</div>

* Файл `.zip` с вашим проектом
* Чётко определённая корневая папка проекта в файле
* Учётная запись Replit

<div id="etapas-de-importao">
  ## Этапы импорта
</div>

1. Откройте [replit.com/import](https://replit.com/import).
2. Выберите **ZIP**.
3. Загрузите файл `.zip`.
4. Добавьте необходимые Secrets и переменные окружения.
5. Выберите **Import**.

<div id="o-que-importado">
  ## Что импортируется
</div>

* Файлы проекта и структура каталогов
* Файлы зависимостей
* Настройки запуска и сборки для Replit

<div id="o-que-no-importado">
  ## Что не импортируется
</div>

* Значения существующих переменных окружения
* Пользовательские домены
* Специфичные для платформы сервисы, требующие ручной настройки
* Существующие данные базы данных
* Существующая конфигурация стороннего коннектора

Во время импорта {setupDescription_0}. Если приложению требуется доработка, воспользуйтесь следующими инструментами Project Editor:
