Auth — abréviation d’**authentification** — introduit la notion d’« utilisateur » dans votre application. Sans Auth, tous les visiteurs sont anonymes et votre application ne peut pas distinguer une personne d’une autre. Avec Auth, chaque visiteur peut se connecter, votre application sait qui il est et peut stocker des données qui lui sont propres : réservations, véhicules enregistrés, préférences et progression.

Une fois Auth configuré, vous pouvez :

* Stocker des données propres à chaque utilisateur — réservations, paramètres, contenu et historique.
* Restreindre l’accès à des fonctionnalités après la connexion (paiements, pages de profil, panneaux d’administration).
* Personnaliser l’expérience selon le nom, le rôle, le forfait ou les comportements passés.
* Suivre l’activité et l’utilisation par personne, plutôt que par session.

<div id="replit-auth">
  ## Fonctionnement de l’authentification dans les applications Replit
</div>

Replit propose deux options d’authentification intégrées. Toutes deux sont provisionnées par Agent — pas besoin de créer un compte sur un tableau de bord ni de copier-coller des clés OAuth.

* **[Replit Auth](/fr/ko/features/auth-and-identity/authentication)** — les utilisateurs se connectent avec leur **compte Replit** existant. La page de connexion utilise la marque Replit. Aucune configuration n’est nécessaire : il suffit de demander à Agent de l’ajouter.
* **[Clerk Auth](/fr/ko/features/auth-and-identity/clerk-auth)** — votre application dispose d’un **tenant Clerk** dédié. Les utilisateurs créent des comptes dans *votre* application, et non sur Replit. Vous pouvez contrôler l’image de marque, les méthodes de connexion et l’apparence de l’écran de connexion.

Les deux options prennent en charge les tâches complexes — pages de connexion, sessions, gestion sécurisée des mots de passe et connexion via les réseaux sociaux — afin que le code de votre application n’ait plus qu’à demander : « Qui est l’utilisateur connecté ? »

<div id="replit-auth-vs-clerk-auth">
  ## Replit Auth vs Clerk Auth
</div>

|                         | Replit Auth                                                                                    | Clerk Auth                                                                    |
| ----------------------- | ---------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| **Comptes utilisateur** | Les utilisateurs se connectent avec leur compte Replit                                         | Les utilisateurs créent un compte dans l&#39;app (aucun compte Replit requis) |
| **Image de marque**     | Page de connexion aux couleurs de Replit                                                       | Entièrement personnalisable — nom, icône et couleurs de votre app             |
| **Identifiants SSO**    | Utilise l&#39;app OAuth partagée de Replit                                                     | Vos propres identifiants OAuth pour chaque fournisseur                        |
| **Environnements**      | Environnement unique                                                                           | Environnements de développement et de production distincts                    |
| **Idéal pour**          | Configuration rapide, prototypes, apps où l&#39;image de marque Replit ne pose pas de problème | Apps de marque, produits professionnels et commerciaux                        |

Pour un prototype ou un outil interne, Replit Auth est la solution la plus rapide. Pour une app dotée de sa propre identité de marque, en particulier destinée aux clients ou à un usage commercial, Clerk Auth conviendra mieux.

<div id="auth">
  ## Ajouter l&#39;authentification à votre application
</div>

Inutile de choisir dès le départ : commencez avec l&#39;une des options et migrez plus tard. Le plus rapide est d&#39;indiquer à Agent celle que vous souhaitez utiliser :

* *« Ajoute une connexion à mon application. Utilise Replit Auth. »*
* *« Ajoute une connexion à mon application. Utilise Clerk Auth. »*
