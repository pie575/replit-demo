---
title: "反馈小组件"
description: "为已发布的应用添加反馈小组件，让访客可以反馈问题和想法，你可以将这些内容直接发送给 Agent 进行修复。"
---

反馈小组件会在已发布应用的角落添加一个反馈按钮。访客无需离开应用即可用它反馈问题或提出改进建议，而你可以将收到的反馈直接发送给 Agent 进行修复。

<div id="ative-o-widget-de-feedback">
  ## 启用反馈小组件
</div>

1. 在 **Tools** 面板的 **Replit Cloud** 下选择 **Publishing**，打开 Publishing 工具；或在 Project Editor 右上角选择 **Publish**。
2. 在 **Engagement tools** 中开启 **Enable feedback widget**。
3. 选择 **Publish**。小组件即会显示在已发布的应用中。

<div id="posio-e-aparncia">
  ## 位置与外观
</div>

启用小组件后，会出现两项设置：

* **Widget position**：选择小组件显示在应用的哪个角落：左上角、右上角、左下角或右下角。默认为右下角。
* **Appearance**：上传自定义图标作为小组件按钮，并选择背景颜色，使其与应用的外观风格保持一致。

<div id="revise-e-aja-sobre-o-feedback">
  ## 查看并处理反馈
</div>

访客提交的内容会进入你的收件箱。在这里你可以：

* 逐条阅读提交内容，了解访客遇到了什么问题。
* 将某条提交发送给 Agent 修复。Agent 会把该反馈作为一项任务，并为你的应用提出修改方案。

<div id="desative-o">
  ## 关闭该功能
</div>

在 Publishing 工具中关闭 **Enable feedback widget**，然后重新发布。该小组件就会从已发布的应用中消失。
