export const YouTubeEmbed = ({videoId, title = "Видео на YouTube", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

  ### Мобильные Apps в Replit
</div>

<YouTubeEmbed videoId="YSeDWL4cDLs" title="Мобильные Apps в Replit" />

Создавайте нативные приложения для iOS по простому промпту. Agent соберёт полноценное приложение на React Native, а вы в любой момент сможете добавить нужные возможности: базу данных, платежи через Stripe, интеграцию с OpenAI и другие. Отсканируйте код в Expo Go, чтобы посмотреть приложение, и отправьте его в App Store с помощью пошагового процесса Replit. Проверку и распространение приложения через App Store выполняет Apple.

Готовы создать своё первое мобильное приложение? Начните с раздела [Нативные мобильные Apps](/ru/ja/features/artifact-types/building-mobile-apps) или пройдите руководство [Создание и запуск мобильного приложения](/ru/tutorials/build-and-launch-a-mobile-app).

<div id="agent-chatui">
  ### Переработанный интерфейс вызовов инструментов в Agent chat
</div>

Отображение вызовов инструментов в Agent chat стало чище и компактнее. Вызовы инструментов сворачиваются в сгруппированные строки со стопкой значков, так что происходящее понятно с одного взгляда. Правки и создание файлов ведут напрямую в панель diff, что упрощает их просмотр. Благодаря облегчённому дизайну стало меньше лишнего, а следить за работой Agent — проще.
