Replit MCP использует [Model Context Protocol](https://modelcontextprotocol.io/), позволяя создавать, искать, проверять, обновлять и публиковать Replit App прямо из используемых вами ИИ-инструментов.

<div id="mcp">
  ## Прямое подключение MCP-клиента
</div>

Используйте прямое подключение, если у вашего MCP-клиента нет встроенной интеграции с Replit.

| Свойство           | Значение                                |
| ------------------ | --------------------------------------- |
| **URL**            | `https://replit-mcp.com/server/mcp`     |
| **Транспорт**      | Streamable HTTP                         |
| **Аутентификация** | OAuth с обнаружением protected-resource |

Добавьте URL сервера в MCP-клиент, поддерживающий Streamable HTTP и авторизацию OAuth. Клиент прочитает метаданные protected-resource Replit, а затем предложит войти в Replit.

Не создавайте собственный OAuth-сервер. MCP-сервер Replit предоставляет необходимые клиенту метаданные OAuth.

Вы можете создавать новые App или работать с App, на редактирование которых у вас есть права, включая предоставленные вам App.

<div id="replit-mcp">
  ### Настройка Replit MCP
</div>

Codex и Claude Code — лишь примеры. Replit MCP можно добавить в любой совместимый MCP-клиент.

<Tabs>
  <Tab title="Codex">
    <Steps>
      <Step title="Откройте список MCP">

      </Step>

      <Step title="Добавьте Replit">
        Добавьте пользовательский MCP. Задайте понятное название, например `Replit`. Выберите **Streamable HTTP**. Введите `https://replit-mcp.com/server/mcp` и сохраните. Не добавляйте bearer-токен и пользовательские заголовки.

<div id="section">
  ## Инструменты
</div>

| Инструмент                | Обязательные параметры        | Необязательные параметры                                                  | Назначение                                                                                                                                                                                                                                                                                            |
| ------------------------- | ----------------------------- | ------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `create_app_from_prompt`  | `appDescription`, `app_stack` | `userSpecifiedAppName`, `userQuotes`, `attachmentSummary`, `sourceReplId` | Создаёт новый App. `app_stack` принимает одно из значений: `react_website`, `mobile_app`, `design`, `slides`, `animation`, `data_visualization`, `3d_game`, `document`, `spreadsheet`. Если задать `sourceReplId`, новый App создаётся не как пустой проект, а как приватная копия существующего App. |
| `search_apps`             | нет                           | `query`, `url`, `updatedAfter`, `updatedBefore`, `limit`                  | Ищет App по ключевым словам в названии, URL или времени последнего обновления. `limit` — от 1 до 50.                                                                                                                                                                                           |
| `resolve_app_by_name`     | `name`                        | нет                                                                       | Находит один App по точному названию.                                                                                                                                                                                                                                                                 |
| `list_apps`               | нет                           | `query`, `limit`                                                          | Выводит список доступных для редактирования App в порядке последней активности. По умолчанию — 25, максимум — 50.                                                                                                                                                                              |
| `ask_question`            | `replId`, `question`          | нет                                                                       | Задаёт Agent вопрос об App, не внося в него изменений.                                                                                                                                                                                                                                                |
| `update_app_using_prompt` | `replId`, `changeDescription` | `userQuotes`, `attachmentSummary`                                         | Запускает обновление существующего App силами Agent.                                                                                                                                                                                                                                                  |
| `publish_app`             | `replId`                      | нет                                                                       | Публикует App или повторно публикует последние изменения.                                                                                                                                                                                                                                             |
| `get_publish_status`      | `replId`                      | нет                                                                       | Показывает, опубликован ли App, текущий статус публикации и публичный URL.                                                                                                                                                                                                                            |

<div id="section-2">
  ## Устранение неполадок
</div>

| Проблема                                                      | Решение                                                                                                                              |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| Replit запрашивает аутентификацию                             | Пройдите вход через OAuth заново в клиенте MCP.                                                                                      |
| App не найден                                                 | Убедитесь, что у вас есть права на редактирование этого App. Затем найдите его по URL или выберите нужный App с помощью `list_apps`. |
| Запрос на создание, обновление или публикацию ещё выполняется | Подождите, прежде чем повторять попытку. Для публикации проверьте текущий статус с помощью `get_publish_status`.                     |
