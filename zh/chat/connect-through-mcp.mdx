模型上下文协议 (MCP) 是一项开放标准，用于连接 AI 产品与工具和数据源。它与 Replit 的原生集成不同，但能扩展你在 Conversation 中工作时可使用的工具。

<div id="choose-the-connection-direction">
  ## 选择连接方式
</div>

* **将 Replit 连接到外部工具：**添加精选或自定义 MCP server，让 Replit 使用其提供的工具。请仅连接您信任的 server。
* **从 MCP 客户端使用 Replit：**将兼容的 client 连接到 Replit MCP Server，以便从该 client 创建、查找、检查或更新 Replit Apps。

MCP 不同于原生集成和 [Skills](/zh/chat/agent-skills)。集成提供受支持的服务连接。Skills 提供可复用的说明和辅助材料。MCP 通过该协议扩展可用工具。
