---
title: "Shell"
description: "了解如何使用 Shell 管理项目文件、安装包和运行脚本。"
---

Shell 可让您像使用普通终端一样在项目中操作，管理文件、
安装包和运行脚本。例如，您可以浏览项目文件，或在项目已配置数据库连接时
使用 `psql`。

<Tip>
  为了更好地管理工作流，建议使用 **Run** 按钮，
  而非通过 Shell 运行应用。通过 **Run** 按钮启动的
  工作流会将输出发送到 Console 工具，便于您以结构化方式查看日志。
</Tip>

<div id="recursos">
  ## 功能
</div>

Shell 提供以下功能：

* **运行多个 Shell**：打开多个 Shell 实例，同时处理不同任务
* **搜索文本**：在 Shell 输出中查找特定文本

<div id="confirmar-acesso-ao-shell">
  ### 确认 Shell 访问权限
</div>

要确认 Shell 已准备就绪并查看当前工作区，请运行：

```sh theme={null}
pwd
```

Shell 会显示当前工作区的路径。

<Frame caption="pwd 命令会显示当前工作区的路径，并返回 Shell 提示符。">
  <img src="/assets/mirror/shell-pwd-output-2d31a0e0466b.jpg" alt="Shell 标签页显示 pwd 命令、工作区路径输出和返回的提示符" width="1280" height="246" data-path="images/workspace/shell-pwd-output.jpg" />
</Frame>

对于包含数据库的项目，请选择 **Tools** → **Database**，然后打开
**Development database** 页面。该页面提供连接设置。请妥善保管
连接信息；不要将其复制到文档、截图、
日志、源代码文件或共享消息中。

<div id="pesquisa-de-texto">
  ### 文本搜索
</div>

按照以下步骤访问和使用文本搜索工具：

1. 选择 Shell 标签页右上角的 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 放大镜图标，打开搜索对话框。
2. 输入搜索词，然后选择 **Next** 在匹配项之间切换。
3. 使用 **Previous** 返回上一个匹配项。
4. 选择 **Exit** 或点击对话框外部，退出文本搜索。

<div id="mltiplos-shells">
  ### 多个 Shell
</div>

要创建新的 Shell：

1. 在 Shell 面板标题栏中选择 Shell 实例菜单。
2. 选择 **New Shell**。

<Frame>
  <img src="/assets/mirror/shell-new-94a280c1230f.png" alt="Shell 实例菜单，显示当前工作区和 New Shell 选项" width="1280" height="224" data-path="images/workspace/shell-new.png" />
</Frame>

使用同一菜单可在不同的 Shell 之间切换。Replit 会以每个 Shell 最后执行的命令来标识它们，方便你区分。

<Warning>
  当你打开多个 Shell 时，Replit 会自动关闭未激活的
  Shell 实例。未激活的 Shell 是指未被
  选中且未运行任何用户进程的 Shell。
</Warning>
