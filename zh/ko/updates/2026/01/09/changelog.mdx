</div>

<div id="ai">
  ### 集成中的全新 AI 模型
</div>

AI 集成现已支持新发布的 AI 模型：

| 模型                           | 说明                                                                  |
| ---------------------------- | ------------------------------------------------------------------- |
| `gpt-5.2`                    | OpenAI 面向专业知识工作的最强模型。拥有 400K 上下文窗口，是首个在 ARC-AGI-1 上突破 90% 的模型。      |
| `claude-opus-4.5`            | Anthropic 的旗舰模型，针对编码、智能体和计算机操作进行了优化，在 SWE-bench Verified 上达到 80.9%。 |
| `gemini-3-flash-preview`     | Google 的高速模型，具备 1M 词元上下文，针对智能体工作流进行了优化，以更低的延迟和成本提供接近 Pro 级别的推理能力。   |
| `gemini-3-pro-preview`       | Google 的高级多模态模型，具备顶尖的推理能力和现实世界知识。                                   |
| `gemini-3-pro-image-preview` | Google 的 Nano Banana Pro 模型，用于高质量图像生成与编辑，并支持精准的文本渲染。                |
