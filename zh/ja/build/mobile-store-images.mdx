export const profileImagesPrompt = "将玩家拍摄的个人资料照片存储到 App Storage 中，并关联到其账户。";

PixelGames 需要一个存放玩家拍摄照片的地方。本指南假定玩家已经能够
[登录](/zh/ja/build/mobile-login)，因为存储功能需要知道上传者是谁。

<AiPrompt>
  {profileImagesPrompt}
</AiPrompt>

Agent 会配置 [App Storage](/zh/features/data-and-storage/object-storage)，并将每次上传与当前登录的
玩家关联。这样，PixelGames 就能展示真正的个人资料，在玩家姓名旁显示他们上传的照片。

</Frame>

<div id="section">
  ## 测试
</div>

1. 使用现有账户登录 PixelGames。
2. 拍摄或选择一张个人资料照片并上传。
3. 关闭应用后重新打开，确认照片仍正常显示。
4. 在另一台设备上使用同一账户登录，确认显示的是同一张照片。

<div id="section-2">
  ## 故障排除
</div>

* **已登录但照片未显示：** 应用可能使用了与预期不同的存储或认证实例。请让 Agent 检查连接。
* **上传失败：** 请确认应用在上传前已请求相机和存储权限。
