여기에서는 Replit builder가 가장 자주 묻는 billing 관련 질문에 답합니다. usage-based billing의 작동 방식을 자세히 알아보려면 [Usage-based billing](/ko/billing/about-usage-based-billing)과 [Managing your spend](/ko/billing/managing-spend)를 참고하세요.

<AccordionGroup>
  <Accordion title="월간 청구 주기가 끝나기 전에 왜 요금이 청구되었나요?">
    Replit은 포함된 월간 credits를 초과하는 usage에 대해 청구 주기가 끝날 때만 청구하는 것이 아니라, 해당 usage가 정해진 금액, 즉 *billing threshold*에 도달하는 시점에 청구합니다. Core plan에는 월 {CoreCredits}의 credits가 포함되며, 이 credits를 초과하는 Agent usage는 threshold에 도달하면 별도로 청구됩니다.

    향후 요금을 줄이려면 다음을 참고하세요.

    1. Agent가 빌드하기 전에 [Plan mode](/ko/features/agent/plan-mode)로 작업 범위를 정하고 승인해 비용이 많이 드는 재작업을 피하세요.
    2. Core 또는 Pro 구독을 사용 중이라면 일상적인 Agent 작업에는 무료인 [Free Mode](/ko/features/agent/agent-modes)를 활용하세요. allowance는 5시간마다 초기화되며 주간 limit이 있습니다. **Settings → Usage**에서 usage를 확인할 수 있습니다.
    3. 합리적인 가격으로 더 높은 성능이 필요할 때는 Power를 선택하세요.
    4. [지출 관리](/ko/billing/managing-spend)에서 usage limit과 예산을 설정해 credits를 초과하는 요금에 상한을 두세요.
    5. 새로운 task를 시작할 때마다 새 Agent chat을 열어 context를 짧게 유지하세요.

    요금이 발생한 원인을 확인하려면 **Settings → Account usage**를 열고 **See previous invoices**를 선택하세요.
  </Accordion>

  <Accordion title="App Store 또는 Google Play를 통해 구독했는데 결제 수단을 추가할 수 없습니다. 어떻게 해결할 수 있나요?">
    App Store 또는 Google Play를 통해 구독하면 Apple 또는 Google이 결제를 처리하므로 모바일 앱에는 결제 옵션이 표시되지 않습니다. 대신 웹에서 결제를 관리하세요.

    1. 브라우저를 열고 **Settings → Billing**으로 이동합니다.
    2. **Update payment method**를 선택합니다.
    3. 카드 정보를 입력한 후 저장합니다.

    웹 결제 수단을 추가하면 **Billing** 탭에서 결제를 관리하고 크레딧 팩을 구매할 수 있습니다. 크레딧 팩에 대한 자세한 내용은 [지출 관리](/ko/billing/managing-spend)를 참조하세요.
  </Accordion>

  <Accordion title="구독한 지 30일 이내인데, 환불받을 수 있나요?">
    환불 가능 여부는 사용 중인 plan과 환불을 요청하는 항목에 따라 달라집니다. 다음 사항에 유의하세요.

    * Agent 및 AI usage 요금은 환불되지 않습니다. 각 요금은 이미 사용된 컴퓨팅 자원에 대한 청구이기 때문입니다.
    * [custom domain 등록 수수료는 환불되지 않습니다](/ko/build/domain-purchasing).

    구독료 환불을 원하시면 등록된 이메일로 [Replit Support에 문의](https://replit.com/support)하면서 요청 사유를 함께 알려주세요. 문의 전에 **Settings → Billing**에서 구독을 먼저 취소해야 합니다.

    <Note>정확한 구독 환불 기간과 자격 요건은 해당 Account와 plan에 맞춰 지원팀이 확인해 드립니다.</Note>
  </Accordion>

  <Accordion title="예상치 못한 Agent 또는 AI 사용량에 대한 요금이 청구되었습니다. 환불받을 수 있나요?">
    Agent 및 AI 사용 요금은 환불되지 않습니다. 각 요금은 Replit이 여러분의 task를 실행하는 데 이미 사용한 컴퓨팅 자원에 대한 대가이기 때문입니다. 예상치 못한 요금이 발생하지 않도록 다음과 같이 대비할 수 있습니다.

    1. **Settings → Account usage**에서 usage limit과 예산을 설정하세요. [지출 관리하기](/ko/billing/managing-spend)를 참고하세요.
    2. Free Mode는 Core 및 Pro 구독에 포함되어 있습니다. allowance 범위 내에서 일상적인 Agent 작업을 무료로 처리하려면 [Free Mode](/ko/features/agent/agent-modes)를 사용하고, 더 높은 성능이 필요하다면 합리적인 가격의 Power를 선택하세요.
    3. [Plan mode](/ko/features/agent/plan-mode)로 Agent가 build하기 전에 작업 범위를 정해 두면 재작업을 줄일 수 있습니다.

    요금이 잘못 청구되었다고 생각되면 청구 금액, 날짜, 결제 인텐트 ID를 준비하세요. 이 ID는 `pi_`로 시작하며 인보이스 상세 페이지에서 확인할 수 있습니다. 그런 다음 [Replit Support에 문의](https://replit.com/support)하세요.
  </Accordion>

  <Accordion title="구독을 취소했는데 요금이 청구되었습니다. 정상인가요?">
    해지 후 청구되는 금액은 보통 다음 두 가지 중 하나가 원인입니다.

    * 해지 전에 발생한 usage가 해지일 이후에야 billing 기준액에 도달한 경우.
    * 이전 billing period에 실패한 결제의 재시도.

    내용을 확인하려면 **Settings → Account usage**를 열고 **See previous invoices**를 선택한 뒤, Invoice 날짜와 해당 Invoice가 포함하는 usage 기간을 확인하세요. 그래도 잘못된 것 같다면 [Replit Support에 문의](https://replit.com/support)하고 `pi_` 결제 인텐트 ID를 함께 알려주세요.
  </Accordion>

  <Accordion title="구독은 정상인데 왜 추가 저장용량 요금이 청구되나요?">
    저장된 데이터가 plan에 포함된 limit을 초과하면 스토리지 요금이 발생합니다. 스토리지 사용량 측정 방식은 [Usage-based billing](/ko/billing/about-usage-based-billing)을, Object Storage 비용은 [Object storage billing](/ko/billing/object-storage-billing)을 참고하세요.

    어떤 항목이 공간을 차지하고 있는지 확인하려면 project에서 Shell을 열고 다음 명령을 실행하세요:

    ```bash theme={null}
    du -sh *
    du -ah | sort -rh | head -20
    ```

    그런 다음 빌드 아티팩트(`.cache` 또는 `dist` 등), 오래된 로그, 사용하지 않는 업로드 파일을 삭제하고 데이터베이스에서 오래된 데이터를 정리하세요. 공간을 확보하면 이후 스토리지 요금이 더 이상 늘어나지 않습니다.
  </Accordion>

  <Accordion title="맞춤 도메인 등록 비용을 환불받으려면 어떻게 해야 하나요?">
    [custom domain 등록 수수료는 환불되지 않습니다](/ko/build/domain-purchasing). 도메인 등록에는 한 번 처리되면 되돌릴 수 없는 제3자 비용이 발생하기 때문입니다.

    실수로 도메인을 등록했거나 도메인을 이전하려면, 도메인 이름과 Account에 연결된 이메일 주소를 함께 기재하여 [Replit Support에 문의](https://replit.com/support)하세요. 담당 팀에서 가능한 선택지를 안내해 드립니다.
  </Accordion>

  <Accordion title="청구서를 결제했는데도 계정이 아직 정지 상태입니다. 언제 해제되나요?">
    결제가 확인된 후에도 billing 보류가 해제되기까지 다소 시간이 걸릴 수 있습니다. 다음 단계를 시도해 보세요.

    1. `Cmd+Shift+R`(Mac) 또는 `Ctrl+Shift+R`(Windows)을 눌러 브라우저를 강력 새로 고침합니다.
    2. 로그아웃한 후 다시 로그인하여 Account 상태를 새로 불러옵니다.
    3. **Settings → Account usage**를 열고 **See previous invoices**를 선택한 다음, Invoice가 결제 완료로 표시되는지 확인합니다.

    보류가 해제되어도 Deployments는 자동으로 다시 시작되지 않습니다. 앱이 여전히 offline 상태라면 **Publishing**을 열고 **Publish**를 선택해 다시 게시하세요. Account가 계속 정지 상태라면 [Replit Support에 문의](https://replit.com/support)하세요.
  </Accordion>

  <Accordion title="Replit에서 청구된 내역을 확인할 수 없습니다. 어떻게 해야 하나요?">
    은행에 결제 이의를 제기하기 전에 먼저 해당 청구 내역을 확인하세요.

    1. **Settings → Account usage**를 열고 **See previous invoices**를 선택한 후 날짜, 금액, 설명을 확인합니다.
    2. 다른 사람이 내 계정이나 결제 수단에 접근할 수 있는지 확인합니다.
    3. 청구일 무렵에 받은 Replit 청구 관련 이메일이 있는지 스팸 폴더까지 확인합니다.

    청구 항목은 대개 구독료, 청구 기준액에 도달한 사용량 요금, 크레딧 팩 구매 중 하나입니다.

    <Warning>은행에 결제 이의를 제기하기 *전에* Replit Support에 문의하세요. 지불 거절(chargeback)이 발생하면 계정이 잠길 수 있습니다.</Warning>

    `pi_` 결제 인텐트 ID, 청구 금액, 청구 날짜를 함께 알려주시고 [Replit Support에 문의](https://replit.com/support)하세요.
  </Accordion>

  <Accordion title="결제가 거부되었습니다. Replit 문제인가요?">
    결제 거절은 대부분 Replit이 아니라 은행이나 카드사에서 발생하며, 평소와 다른 거래에 대한 자동 보안 차단인 경우가 많습니다. 다음 순서대로 시도해 보세요.

    1. **Settings → Billing → Update payment method**에서 다른 카드를 추가한 후 다시 시도합니다.
    2. 은행에 전화해 Replit 결제를 승인하려 한다는 점을 알리고 승인을 요청합니다.
    3. 카드에 해외 결제 제한이 걸려 있다면 은행에 해외 결제 허용을 요청합니다.

    그래도 계속 결제가 거절된다면 [Replit Support에 문의](https://replit.com/support)하세요.
  </Accordion>

  <Accordion title="같은 금액이 두 번 청구되었는데, 중복 청구인가요?">
    동일한 금액의 청구가 두 건 있다고 해서 항상 중복 청구인 것은 아닙니다. 흔한 원인은 다음과 같습니다.

    * 구독료와 같은 금액의 크레딧 팩이 각각 별도 항목으로 표시된 경우
    * 결제가 실패한 뒤 재시도되어 성공한 경우
    * 실제 중복 청구인 경우(드물게 발생)

    **Settings → Account usage**를 열고 **See previous invoices**를 선택한 다음, 두 청구의 결제 인텐트 ID(`pi_`)를 비교해 보세요. ID가 서로 다르면 별개의 거래입니다. 동일한 인보이스에서 같은 항목이 두 건 모두 결제 완료로 표시된다면 [Replit Support에 문의하세요](https://replit.com/support).
  </Accordion>

  <Accordion title="App Store를 통해 결제했는데 크레딧이 아직 반영되지 않았습니다. 어떻게 해야 하나요?">
    App Store 결제는 Replit에 반영되기까지 다소 시간이 걸릴 수 있습니다. 먼저 다음을 시도해 보세요.

    1. Replit 앱을 강제 종료한 후 다시 실행합니다.
    2. Replit account에서 로그아웃한 뒤 다시 로그인합니다.
    3. **Settings → Account usage**를 열어 credits가 이미 반영되었는지 확인합니다.

    다시 구매하지 마세요. 그래도 credits가 표시되지 않으면 App Store의 **Purchase History**에서 Replit 거래를 찾아 거래 ID를 확인하세요. 그런 다음 [Replit Support에 문의](https://replit.com/support)하시면 담당 팀에서 credits를 지급해 드립니다.
  </Accordion>
</AccordionGroup>
