Conversation — это отдельная ветка, в которой можно задавать вопросы, изучать информацию, запускать Routines и описывать нужный результат. Любая задача в Replit начинается с Conversation.

  Conversation приватны: доступ к ним в вашем Workspace есть только у вас. Для совместной работы попросите Replit создать Project.
</Note>

<div id="ask-a-question">
  ### Задайте вопрос
</div>

Replit может находить и анализировать информацию в интернете, подключённых инструментах и загруженных файлах. Задайте конкретный вопрос или укажите контекст, на который Replit должен опираться.

Например, попросите Replit кратко изложить вашу активность в Slack за эту неделю и отметить
сообщения, которые ждут ответа.

<div id="run-a-routine">
  ### Запуск Routine
</div>

Routine планирует повторяющуюся работу внутри Conversation. Replit возвращает каждый результат в ту же Conversation, где вы можете его просмотреть и продолжить работу. Подробнее о [Routines](/ru/chat/routines).

Например, попросите Replit каждое утро просматривать Slack и присылать список ваших приоритетов.

<div id="conversations-vs-projects">
  ## Conversation и Project: в чём разница
</div>

Conversation — это отдельный тред для вопросов, исследований и Routine. [Project](/ru/features/projects-and-artifacts/projects) — более основательный workspace для серьёзной работы по разработке и дизайну, в том числе с несколькими artifact.

Начинайте с Conversation. Когда работа перерастает в полноценную разработку или дизайн, Conversation можно превратить в Project.

В боковой панели Conversation обозначается значком чата, а Project — значком сетки из четырёх квадратов.

<Frame>
  <img src="/assets/mirror/conversation-and-project-icons-025a17613daa.png" alt="Боковая панель Replit: Project со значком сетки из четырёх квадратов и Conversation со значком чата" width="466" height="290" data-path="images/chat/conversation-and-project-icons.png" />
</Frame>

| Область         | Conversation                     | Project                                                                                         |
| --------------- | -------------------------------- | ----------------------------------------------------------------------------------------------- |
| Лучше всего для | Вопросов, исследований и Routine | Основательной работы по разработке и дизайну: приложения, слайды, дашборды и несколько artifact |
| Фоновые задачи  | **Недоступны**                   | **Могут выполняться параллельно**                                                               |
| Routine         | **Доступны**                     | **Недоступны**                                                                                  |
| Интеграции      | Доступны                         | Доступны                                                                                        |
| Структура       | Один тред                        | Workspace проекта с несколькими artifact                                                        |
