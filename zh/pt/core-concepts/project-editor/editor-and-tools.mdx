项目编辑器提供布局管理和集成工具，助你更高效地构建应用。
这些工具可处理开发流程中的特定环节，让你
专注于创建，而无需进行配置。

<div id="layout-personalizvel-do-editor-de-projetos">
  ## 可自定义的项目编辑器布局
</div>

项目编辑器的布局管理工具可让你自定义开发环境中的组件。
它包含以下几类界面元素：

| 元素      | 描述                                    | 功能                                                                  | 使用场景                                               |
| ------- | ------------------------------------- | ------------------------------------------------------------------- | -------------------------------------------------- |
| **窗口**  | 包含一个或多个面板的浏览器标签页                      | <ul><li>可排列到多个屏幕上</li></ul>                                         | <ul><li>将项目编辑器排列到多个屏幕上</li><li>同时处理不同项目</li></ul>  |
| **面板**  | 窗口中包含一个或多个标签页的区域                      | <ul><li>支持水平和垂直拆分</li><li>可调整大小和重新排列</li><li>可转换为窗口内的浮动面板</li></ul> | <ul><li>并排查看代码和预览</li><li>为不同开发任务创建自定义布局</li></ul> |
| **标签页** | 恰好包含一个项目编辑器工具，例如文件编辑器、Preview 或 Agent | <ul><li>可在面板之间移动，并在面板内重新排序</li><li>只需单击即可在不同文件或工具之间切换</li></ul>     | <ul><li>按需打开不同的工具或文件</li></ul>                     |

<div id="rvore-de-arquivos">
  ## 文件树
</div>

文件树会列出 Replit App 中的所有文件和目录。

<Accordion title="如何访问文件树">
  选择左侧的 <img class="icon-svg" src="/assets/mirror/files-icon-f66bf1b04572.svg" alt="带箭头的文件夹图标" width="16" height="16" data-path="images/icons/files-icon.svg" /> 图标，即可显示或隐藏
  文件树。
</Accordion>

你可以在文件树中执行以下操作：

* 选择文件夹以查看其内容
* 选择文件，或将其拖到面板中，以在文件编辑器中打开
* 执行复制、重命名、移动、下载或删除等文件操作

<div id="boto-executar">
  ## 运行按钮
</div>

**运行**按钮可运行所选 Replit App 的工作流程。

<Accordion title="如何找到运行按钮">
  **运行**按钮位于项目编辑器屏幕顶部。选择该按钮即可运行工作流程。

  当 Replit App 正在运行时，按钮标签会变为**停止**。选择该按钮即可停止应用。
</Accordion>

要了解如何选择、查看和管理工作流程，请参阅 [Workflows](/zh/pt/core-concepts/project-editor/app-setup/workflows/)。

<div id="menu-de-opes">
  ## 选项菜单
</div>

通过选项菜单，您可以执行以下布局操作：

* **窗口管理**：在新窗口中打开 Replit App 的项目编辑器
* **面板管理**：添加面板、移动面板、最大化面板，以及在浮动和固定位置之间切换
* **标签页管理**：打开或选择其他标签页、将标签页移至其他面板，以及关闭标签页

<Accordion title="如何打开选项菜单">
  选择活动标签页右上角的 <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="三个竖点图标" height="16" width="16" data-path="images/icons/vertical-dots.svg" /> 三个竖点，即可打开选项菜单。
</Accordion>

<div id="painel-de-recursos">
  ## 资源面板
</div>

资源面板显示开发环境的计算资源及其使用情况，包括 RAM、CPU 和存储空间。
这些信息可帮助你估算并优化 Replit App 的部署需求。

<Accordion title="访问资源面板">
  1. 选择应用名称旁的 <img class="icon-svg" src="/assets/mirror/resources-237893692826.svg" alt="堆叠计算机图标" width="16" height="16" data-path="images/icons/resources.svg" /> 资源图标，切换面板。
  2. 将鼠标悬停在 **计算** 或 **存储** 项目上，查看详细信息。
</Accordion>
