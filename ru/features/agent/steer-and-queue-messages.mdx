Пока Agent работает, дополнительное сообщение может либо изменить то, чем Agent
занят в данный момент, — его активный **ход**, — либо дождаться завершения этого хода:

* **Steer** отправляет сообщение в активный ход. Agent учитывает новый контекст и продолжает работу.
* **Queue** сохраняет сообщение для следующего хода. Agent приступит к нему после завершения активного хода.

<div id="steering-conversations">
  ## Направление хода Conversations
</div>

Steer — это режим отправки дополнительных сообщений в Conversations и
Projects. Любую из этих настроек можно изменить на Queue.

<div id="choose-how-replit-sends-follow-ups">
  ## Выберите, как Replit отправляет дополнительные сообщения
</div>

Вы можете задать разные режимы отправки для Conversation и Project:

1. Откройте **Settings** &gt; **Personalization**.
2. Разверните раздел **Agent**.
3. Задайте для **Conversation send behavior** и **Project send behavior** значение **Steer** или **Queue**.

<Frame caption="Настройки режима отправки для Conversation и Project в разделе Agent.">
  <img src="/assets/mirror/agent-follow-ups-settings-98a4c5ca399e.png" alt="Agent settings showing Conversation and Project send behavior with Steer and Queue options" width="3048" height="1372" data-path="images/replitai/agent-follow-ups-settings.png" />
</Frame>

<Info>
  В режиме Design дополнительные сообщения всегда корректируют текущую работу. Настройки режима отправки
  для Conversation и Project в режиме Design не действуют.
</Info>

Чтобы отправить одно сообщение в режиме, противоположном выбранному, нажмите
`Cmd+Enter` (Mac) или `Ctrl+Enter` (Windows и Linux).

<div id="work-with-queued-messages">
  ## Работа с сообщениями в очереди
</div>

Когда вы добавляете следующее сообщение в очередь, Queue сообщений появляется
в виде панели над полем ввода чата. Agent обрабатывает сообщения из очереди по
порядку после завершения активного хода. Панель закрывается, когда Agent
обработает все сообщения из очереди.

В Queue доступны все возможности работы с сообщениями, включая [Visual Editor](/ru/design/visual-editor)
и вложения файлов.

<Info>
  Agent обрабатывает сообщения из очереди автоматически только при наличии
  активного подключения к сеансу Project Editor на компьютере или мобильном устройстве.
</Info>

<div id="manage-the-queue">
  ### Управление очередью
</div>

Когда панель очереди открыта, вы можете:

* **Steer сразу**: перенести сообщение из очереди в активный ход.
* **Редактировать сообщения**: изменить сообщение в очереди до того, как Agent его обработает.
* **Удалять сообщения**: убирать сообщения, которые больше не нужны.
* **Менять порядок сообщений**: перетаскивать сообщения, чтобы изменить порядок их обработки.
* **Добавлять сообщения**: отправлять в очередь новые дополнительные сообщения.

<div id="stop-the-active-turn">
  ## Остановка активного хода
</div>

Нажмите **Stop** в строке состояния, чтобы прервать текущую работу Replit над
активным ходом. После этого вы сможете отправить новое сообщение, не дожидаясь,
пока Agent завершит ход или обработает сообщения из очереди.
