<div id="cone-animado-do-agente">
  ### Анимированный значок Agent
</div>

Значок Agent теперь анимируется во время работы, нагляднее показывая, что Agent активно выполняет задачи. Это улучшение создаёт ощущение более высокой скорости и позволяет легче отслеживать активность Agent на начальном этапе планирования, особенно в раскладке с чатом по центру, где обратная связь находится ближе к вашему запросу.

<div id="menu-suspenso-de-ferramentas-do-agent-no-fluxo-de-planejamento">
  ### Выпадающее меню инструментов Agent в процессе планирования
</div>

Выпадающее меню инструментов Agent теперь доступно на начальных этапах планирования и утверждения списка задач. Это позволяет настроить параметры Agent, включая уровень автономности и другие предпочтения, уже в начале работы.

<div id="suporte-a-nomes-de-arquivos-com-no-agent">
  ### Поддержка упоминаний файлов через @ в Agent
</div>

Теперь Agent поддерживает упоминания файлов с помощью `@` наряду с командами `/`, обеспечивая единообразие с популярными инструментами разработки. Эта возможность была особенно востребована корпоративными и опытными пользователями, знакомыми с рабочими процессами в стиле Cursor.

<div id="suporte-a-connectors-para-remixagem">
  ### Поддержка Connectors при ремиксировании
</div>

Раньше при ремиксировании любого App в Replit, использующего коннектор, интеграция переставала работать, поскольку ремиксированное приложение не получало автоматического разрешения на использование коннектора. Мы обновили процесс ремиксирования, чтобы коннекторы обрабатывались корректно:

* Теперь при ремиксировании пользователям предлагается настроить необходимые коннекторы
* В процессе ремиксирования чётко указано, какие интеграции нужно настроить
* После ремиксирования интеграции больше не перестают работать

Подробнее об [интеграциях Agent](/ru/replitai/integrations) и [управлении коннекторами](/ru/pt/replitai/managing-connectors).

<div id="painel-de-analytics-para-admins-corporativos">
  ### Панель Analytics для корпоративных администраторов
</div>

Корпоративные администраторы теперь могут пользоваться комплексной панелью Analytics — долгожданной функцией для корпоративных клиентов, включая Meta и Atlassian. Панель позволяет:

* **Мониторинг активности пользователей**: отслеживать вовлечённость и совместную работу во всей организации
* **Отслеживание использования ресурсов**: контролировать расходы по пользователям и App в Replit
* **Контроль публикаций**: отслеживать активность публикаций
* **Управление затратами**: получать полное представление о потреблении ресурсов и расходах
