<div id="section">
  ## 后续 task 建议
</div>

应用 task 后，Agent 会检查项目上下文，并建议接下来可以构建的**后续 task**。**建议的下一个 task**对话框会以内联方式显示首要推荐，让你无需离开主会话即可继续操作。

<Frame>
  <img src="/assets/mirror/follow-up-tasks-dialog-c1660cec2d1d.png" alt="“建议的下一个 task”对话框，显示后续 task，并包含“开始”按钮和在任务看板中查看更多 task 的链接" width="495" height="290" data-path="images/agent/follow-up-tasks-dialog.png" />
</Frame>

后续建议可能包括：

* **可构建的新功能**：与刚部署的内容自然契合的功能
* **性能改进**：Agent 在处理 task 时发现的优化机会
* **用户体验改进**：用于完善功能的细节打磨和改进

如要让建议在后台执行，请选择**开始**；如要先查看建议的工作内容，请选择**查看计划**。如要查看所有建议，请选择**在任务看板中查看更多**。建议的后续 task 会显示在**草稿**列的**已建议**下方。

<Frame>
  <img src="/assets/mirror/follow-up-tasks-kanban-21087e0210b6.png" alt="任务看板，在“草稿”列的“已建议”下方显示多条后续 task 建议" width="980" height="627" data-path="images/agent/follow-up-tasks-kanban.png" />
</Frame>

关闭**建议的下一个 task**对话框会取消这些建议。当主分支中已有建议的计划等待处理时，Agent 不会显示该对话框，以免两个提示词同时争夺你的注意力。

<div id="section-2">
  ## 批量管理建议
</div>

如果项目中有许多后续建议，请打开任务看板，并在**草稿**列中选择**编辑**。在编辑模式下，每个建议的 task 都会显示复选框。选择所需的 task，然后使用**开始**或**取消**对所有选中的 task 执行相应操作。要退出编辑模式，请选择**完成**。
