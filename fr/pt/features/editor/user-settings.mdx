L&#39;outil Paramètres utilisateur de l&#39;éditeur de projet propose des options permettant de personnaliser l&#39;apparence, le comportement et les
raccourcis clavier de votre compte.

  <img src="/assets/mirror/user-settings-tool-faae3afb911b.png" alt="capture d'écran de l'outil Paramètres utilisateur" width="4152" height="1894" data-path="images/workspace/user-settings-tool.png" />
</Frame>

<div id="recursos">
  ## Fonctionnalités
</div>

Vous pouvez personnaliser votre expérience de création de Replit Apps grâce à ces catégories de paramètres :

* **Personnalisation du thème** : choisissez entre un thème clair et un thème sombre pour l&#39;éditeur de projet
* **Intelligence de code** : configurez les fonctionnalités d&#39;IA qui améliorent votre expérience de création d&#39;apps
* **Préférences de l&#39;éditeur** : ajustez le comportement et l&#39;apparence de l&#39;éditeur de fichiers
* **Contrôles des notifications** : gérez vos préférences d&#39;alertes
* **Options d&#39;accessibilité** : adaptez Replit aux utilisateurs ayant des besoins spécifiques
* **Raccourcis clavier** : définissez des combinaisons de touches pour effectuer les actions courantes et naviguer dans l&#39;interface

<div id="uso">
  ## Utilisation
</div>

<Accordion title="Comment accéder aux Paramètres utilisateur">
  Dans le **dock d&#39;outils** à gauche :

  1. Sélectionnez <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="icône Tous les outils" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **Tous les outils** pour afficher la liste des outils de l&#39;Éditeur de projet.
  2. Sélectionnez <img class="icon-svg" src="/assets/mirror/settings-icon-c2664c3691bf.svg" alt="icône Paramètres" width="16" height="16" data-path="images/icons/settings-icon.svg" /> **Paramètres utilisateur**.

  Dans la **barre de recherche** :

  1. Sélectionnez la loupe <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="icône de loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> en haut pour ouvrir l&#39;outil de recherche
  2. Saisissez « User Settings » pour trouver l&#39;outil, puis sélectionnez-le dans les résultats.
</Accordion>

<div id="aparncia">
  ### Apparence
</div>

Personnalisez les paramètres suivants liés à l&#39;apparence de l&#39;éditeur de projet :

* **Sélection du thème** : choisissez parmi les thèmes prédéfinis clair et sombre, les <a href="https://replit.com/themes" target="_blank">thèmes de la communauté</a> ou votre thème personnalisé
* **Thèmes personnalisés** : créez vos propres palettes de couleurs à l&#39;aide de l&#39;éditeur de [Themes](/fr/pt/features/editor/themes)

<div id="preferncias-do-editor-de-arquivos">
  ### Préférences de l&#39;éditeur de fichiers
</div>

Contrôlez l&#39;apparence et le comportement de l&#39;éditeur de fichiers à l&#39;aide des paramètres suivants :

* **Taille de la police** : ajustez la taille du texte pour une meilleure lisibilité
* **Fermeture automatique des crochets** : insérez automatiquement le crochet fermant lorsque vous saisissez un crochet ouvrant
* **Détection de l&#39;indentation** : détectez automatiquement les paramètres d&#39;indentation à l&#39;ouverture d&#39;un fichier
* **Formater l&#39;indentation du texte collé** : reformatez le code collé pour respecter l&#39;indentation correcte
* **Caractère d&#39;indentation** : choisissez entre les espaces et les tabulations pour indenter le code
* **Taille de l&#39;indentation** : définissez le nombre de colonnes pour chaque niveau d&#39;indentation
* **Retour à la ligne (Wrapping)** : configurez le comportement du retour à la ligne
* **Minimap** : affichez un aperçu navigable du code dans une barre latérale
* **Touche de modification pour la sélection multiple** : définissez la touche du clavier utilisée pour sélectionner plusieurs fichiers
* **Statut Git dans l&#39;arborescence des fichiers** : affichez les indicateurs de statut Git dans l&#39;arborescence des fichiers

<div id="inteligncia-de-cdigo">
  ### Intelligence de code
</div>

Configurez les outils d&#39;IA à l&#39;aide des paramètres suivants :

* **Jetons sémantiques** : bénéficiez d&#39;une coloration syntaxique avancée, propulsée par des language servers
* **Complétion de code par IA** : affichez des suggestions de code en ligne au fil de votre saisie
* **Accepter la suggestion avec un caractère de validation** : acceptez automatiquement les suggestions de code lorsque vous saisissez certains caractères

<div id="preferncias-de-shell-e-preview">
  ### Préférences du Shell et du Preview
</div>

Personnalisez le comportement des outils Shell et Preview :

* **Indicateur sonore du Shell (bell)** : émettre un son lorsque l&#39;outil Shell rencontre un problème
* **Preview automatique** : ouvrir automatiquement l&#39;onglet Preview dès qu&#39;un serveur devient disponible
* **Transférer automatiquement les ports ouverts** : configurer la gestion des ports nouvellement détectés

<div id="notificaes">
  ### Notifications
</div>

Gérez les paramètres de notification suivants :

* **Notification sonore de l&#39;Agent** : émettre un son lorsque l&#39;Agent demande un retour
* **Notification push de l&#39;Agent** : recevoir des notifications push sur votre mobile lorsque l&#39;Agent demande un retour

<div id="alertas-de-produo">
  #### Alertes de production
</div>

**Alertes de production** est un paramètre de notification par e-mail distinct qui vous tient informé de l&#39;état de vos apps publiées. Il est indépendant des e-mails produit et marketing : vous restez donc au courant de ce qui compte, sans bruit superflu.

Activez les **Alertes de production** pour recevoir des e-mails concernant :

* **Incidents d&#39;uptime** : soyez averti lorsqu&#39;une app publiée est hors ligne ou peine à le rester.
* **Vulnérabilités de sécurité** : soyez averti des failles détectées dans les logiciels dont dépend votre app, afin de pouvoir les corriger avant qu&#39;elles ne posent problème.
* **Mises à jour de modèle** : soyez averti lorsqu&#39;un modèle de langage utilisé par votre app change ou requiert votre attention.

<Frame>
  <img src="/assets/mirror/production-alerts-highlight-bb76079f20fd.png" alt="Section Production Alerts dans les paramètres de notification, avec un rectangle rouge mettant en évidence le commutateur des e-mails d'alertes de production et le menu déroulant de sévérité des alertes de sécurité" width="2400" height="1364" data-path="images/workspace/production-alerts-highlight.png" />
</Frame>

Pour trouver ce paramètre :

1. Ouvrez **Configurações** depuis le menu de votre compte.
2. Sélectionnez l&#39;onglet **Personalização**.
3. Faites défiler jusqu&#39;à la section **Notifications par e-mail** pour y trouver **Alertes de production**.

Lorsqu&#39;une app publiée utilise un modèle de langage obsolète, Replit prépare une tâche (draft task) pour la faire passer à un modèle pris en charge. Vous recevez un e-mail contenant un lien vers cette tâche, ce qui vous permet de finaliser la mise à jour en une seule révision.

<div id="acessibilidade">
  ### Accessibilité
</div>

Vous pouvez personnaliser le paramètre d&#39;accessibilité suivant :

* **Sortie de terminal accessible** : active la prise en charge des lecteurs d&#39;écran pour les outils Shell et Console

<div id="atalhos-de-teclado">
  ### Raccourcis clavier
</div>

Pour accéder aux préférences de raccourcis clavier, sélectionnez l&#39;onglet **Raccourcis clavier** dans l&#39;outil Paramètres utilisateur.

Vous pouvez rechercher des combinaisons de touches selon les méthodes suivantes :

* **Nom** : saisissez le nom ou la description du raccourci clavier dans le champ de recherche
* **Combinaison de touches** : sélectionnez l&#39;icône <img class="icon-svg" src="/assets/mirror/keyboard-7ba19771b671.svg" alt="icône de clavier" width="16" height="16" data-path="images/icons/keyboard.svg" /> puis saisissez la combinaison de touches

Utilisez les actions suivantes pour gérer les raccourcis :

* **Ajouter** : sélectionnez **Ajouter un raccourci**
* **Mettre à jour** : sélectionnez l&#39;icône <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="icône de crayon" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> en forme de crayon
* **Supprimer** : sélectionnez l&#39;icône <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="icône de corbeille" width="16" height="16" data-path="images/icons/trash-icon.svg" /> en forme de corbeille
