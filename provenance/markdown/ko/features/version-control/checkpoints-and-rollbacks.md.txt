# 체크포인트 및 롤백

> 체크포인트가 작업을 자동으로 저장하는 방법과 롤백을 통해 변경 사항을 취소하는 방법을 알아보세요.

Replit을 사용하면 작업을 잃어버릴까 걱정할 필요가 없습니다.

Replit의 체크포인트 및 롤백 시스템은 전체 개발 환경에 대한 포괄적인 버전 관리와 상태 관리를 제공합니다.

Replit Agent를 사용하면 체크포인트가 프로젝트의 전체 상태를 자동으로 캡처합니다. 여기에는 코드 변경 사항뿐만 아니라 프로젝트 파일, AI 대화 컨텍스트, 연결된 데이터베이스도 포함됩니다.

## 체크포인트란 무엇인가요?

**체크포인트**는 주요 개발 단계마다 Agent가 자동으로 생성하는 Replit 앱 상태의 완전한 스냅샷입니다. 코드 변경 사항만 추적하는 기존 버전 관리와 달리, Replit 체크포인트는 전체 개발 컨텍스트를 캡처합니다.

체크포인트를 비디오 게임의 세이브 포인트라고 생각하세요. 언제든지 작동하는 앱 버전으로 돌아갈 수 있습니다.

### 전체 상태 캡처

각 체크포인트는 다음을 보존합니다:

* **프로젝트 파일**: 모든 파일, 디렉터리, 설치된 패키지, 프로젝트 구성
* **AI 대화 컨텍스트**: 현재 상태로 이어진 전체 대화 기록 및 컨텍스트
* **환경 구성**: 런타임 설정 및 게시 구성
* **Agent 메모리**: 프로젝트 아키텍처, 선호도, 패턴에 대한 AI의 이해
* **데이터베이스 내용**: 체크포인트 생성 시점의 데이터베이스 데이터와 스키마

이러한 포괄적인 접근 방식은 코드뿐만 아니라 전체 개발 컨텍스트를 복원할 수 있다는 것을 알기 때문에 자신 있게 변경 사항을 실험할 수 있게 해줍니다.

## 롤백은 어떻게 작동하나요

**롤백** 기능을 사용하면 클릭 한 번으로 Replit 앱을 이전 체크포인트 상태로 복원할 수 있습니다. 이는 기존 Git revert 작업보다 훨씬 강력합니다.

<Frame>
  <img src="https://mintcdn.com/replit/0UCOQvZyQpUEM03B/images/replitai/checkpoint-rollback.png?fit=max&auto=format&n=0UCOQvZyQpUEM03B&q=85&s=f9594eb28458309b2759e8698b8535ce" alt="롤백 옵션을 보여주는 체크포인트 롤백 인터페이스" width="3154" height="2366" data-path="images/replitai/checkpoint-rollback.png" />
</Frame>

롤백은 안전하고 예측 가능하도록 설계되었습니다:

* **비파괴적 미리보기**: 일부 인터페이스에서는 롤백 전에 체크포인트 상태를 미리 볼 수 있습니다
* **명확한 경계**: 각 체크포인트는 논리적인 개발 단계를 나타냅니다
* **대화 연속성**: AI 컨텍스트가 보존되므로 복원된 상태에서 계속 빌드할 수 있습니다
* **즉각적인 효과**: 롤백은 전체 개발 환경에 즉시 적용됩니다

### 롤백 수행하기

이전 체크포인트로 롤백하면 프로젝트가 다음을 포함하여 이전 상태로 돌아갑니다:

1. **전체 프로젝트 상태**: 모든 프로젝트 파일이 선택한 체크포인트 시점의 정확한 상태로 돌아갑니다
2. **AI 대화 컨텍스트**: Agent 대화가 체크포인트 시점으로 복원되어 컨텍스트 연속성이 유지됩니다
3. **프로젝트 구성**: 종속성, 패키지, 런타임 구성
4. **개발 환경**: 도구 구성 및 Project Editor 설정
5. **데이터베이스 내용(선택 사항)**: 선택한 경우 데이터베이스가 체크포인트 시점의 상태로 복원됩니다

<Info>
  기본적으로 롤백은 데이터베이스를 변경하지 않습니다. 롤백에 개발 데이터베이스를 포함하려면 "추가 롤백 옵션"에서 "데이터베이스"를 선택하세요.

  \*\*[프로덕션 데이터베이스](/ko/features/data-and-storage/development-and-production)\*\*를 복원하는 것은 이 롤백 기능을 통해 자동으로 수행되지 않는다는 점에 유의하세요.
  프로덕션 데이터베이스를 이전 시점으로 복원하는 방법을 알아보려면 [특정 시점 복원 수행 방법에 대한 문서](/ko/features/data-and-storage/development-and-production)를 참조하세요.
</Info>

<Warning>
  롤백 기능을 사용하면 Replit 앱이 이전 상태로 복원됩니다. 이는 해당 시점 이후에 이루어진 코드 편집을 포함한 모든 변경 사항을 제거합니다. 데이터베이스 복원을 선택한 경우 데이터베이스 변경 사항도 되돌려집니다.
</Warning>

### 롤포워드

Replit의 체크포인트는 양방향으로 작동합니다—프로젝트 기록을 앞뒤로 모두 이동할 수 있습니다.
이를 통해 작업을 잃어버릴 걱정 없이 개발 타임라인을 자유롭게 탐색할 수 있습니다.

너무 많이 롤백했거나 이후 체크포인트의 변경 사항을 복구하고 싶다면 **롤포워드**를 사용하여 체크포인트 기록에서 앞으로 이동할 수 있습니다. 이를 통해 작업을 잃지 않고 프로젝트 타임라인을 자유롭게 탐색할 수 있습니다.

롤포워드하려면 기록 아이콘 <img class="icon-svg" src="https://mintcdn.com/replit/rJldsgYVucXB_6kW/images/icons/history.svg?fit=max&auto=format&n=rJldsgYVucXB_6kW&q=85&s=d2f027e7ef50dca743e80ed026c3f0ca" alt="기록 아이콘" width="24" height="24" data-path="images/icons/history.svg" />을 클릭하여 Agent 탭의 기록 보기에 접근한 다음 현재 위치 이후에 발생한 체크포인트를 선택하세요.

<Info>
  롤포워드는 현재 위치보다 앞선 체크포인트가 있는 경우에만 가능합니다. 롤백 이후 새로운 변경을 하면 이후의 체크포인트는 대체 기록 분기의 일부가 됩니다.
</Info>

이러한 양방향 탐색은 프로젝트 타임라인에 대한 완전한 제어권을 제공하여 작업이 항상 복구 가능하도록 보장합니다.

## 체크포인트 생성

체크포인트는 개발 중 전략적인 시점에 Replit의 AI 도구가 자동으로 생성합니다.

### Agent 체크포인트

[Replit Agent](/ko/features/agent/overview)는 다음 시점에 체크포인트를 생성합니다:

* **기능 완료**: 요청된 기능을 성공적으로 구현한 후
* **주요 마일스톤**: 복잡한 작업에서 상당한 진전이 있을 때
* **안정적인 상태**: 구현된 변경 사항의 테스트 및 검증 후
* **오류 복구**: 심각한 문제에 대한 수정을 시도하기 전

### 체크포인트 특징

각 체크포인트에는 다음이 포함됩니다:

* **AI 생성 설명**: 수행된 작업에 대한 명확하고 설명적인 요약
* **타임스탬프 정보**: 쉬운 식별을 위한 정확한 생성 시간
* **변경 범위**: 수정된 파일, 기능 또는 시스템에 대한 표시
* **청구 정보**: Agent의 경우 체크포인트별로 투명한 비용 추적

## 체크포인트 및 롤백 사용하기

### 체크포인트 찾기

체크포인트는 Project Editor 전체의 여러 위치에 표시됩니다:

**Agent 탭**: 설명과 롤백 옵션이 있는 모든 Agent 생성 체크포인트 보기
**Git 창**: 전체 버전 관리 통합이 있는 Git 커밋으로 체크포인트 보기
**기록 보기**: Agent 채팅에서 기록 아이콘 <img class="icon-svg" src="https://mintcdn.com/replit/rJldsgYVucXB_6kW/images/icons/history.svg?fit=max&auto=format&n=rJldsgYVucXB_6kW&q=85&s=d2f027e7ef50dca743e80ed026c3f0ca" alt="기록 아이콘" width="24" height="24" data-path="images/icons/history.svg" />을 클릭하여 모든 체크포인트와 그 진행 상황에 대한 전체 타임라인에 접근

### 롤백 수행하기

롤백 프로세스는 시작하는 위치에 따라 약간 다릅니다:

#### Agent 탭에서

<Steps>
  <Step title="Agent로 이동">
    Project Editor에서 **Agent** 탭을 열어 모든 Agent 생성 체크포인트를 확인하세요.
  </Step>

  <Step title="체크포인트 선택">
    복원하려는 체크포인트를 찾아 **여기로 롤백**을 선택하세요.
  </Step>

  <Step title="롤백 확인">
    롤백 경고를 검토하고 확인하여 앱을 선택한 상태로 복원하세요.
  </Step>

  <Step title="복원 확인">
    프로젝트 파일, 데이터베이스, AI 컨텍스트가 복원된 체크포인트 상태와 일치하는지 확인하세요.
  </Step>
</Steps>

### 모범 사례

**체크포인트를 전략적으로 사용하기**:

* 각 주요 체크포인트 이후 앱을 테스트하여 안정성을 확인하세요
* 자동 체크포인트와 함께 장기 버전 추적을 위한 수동 Git 커밋을 만드세요
* 체크포인트 설명을 검토하여 변경된 내용을 파악하세요

**롤백 시 고려 사항**:

* 롤백 전에 항상 변경 범위를 확인하세요
* 데이터베이스와 외부 통합에 미치는 영향을 고려하세요
* 팀 인지도를 유지하기 위해 협업자에게 롤백을 알리세요

**반복적인 개발**:

* 빈번한 체크포인트를 활용하기 위해 점진적으로 빌드하세요
* 롤백을 사용하여 다양한 구현 방식을 안전하게 탐색하세요
* AI 컨텍스트 보존을 활용하여 롤백 후에도 대화를 이어가세요

## 버전 관리와의 통합

체크포인트는 Replit의 더 넓은 버전 관리 생태계와 원활하게 작동합니다:

### Git 통합

* **Git 커밋 생성**: 각 체크포인트가 해당하는 Git 커밋을 생성합니다
* **브랜치 호환성**: 체크포인트는 브랜치 구조와 병합 워크플로를 존중합니다
* **원격 동기화**: GitHub 통합이 체크포인트 동기화를 유지합니다
* **명령줄 접근**: 체크포인트와 함께 전체 Git 기능을 계속 사용할 수 있습니다

### 협업 기능

* **팀 가시성**: 체크포인트는 모든 프로젝트 협업자에게 표시됩니다
* **병합 충돌 방지**: 체크포인트 타이밍이 충돌 가능성을 줄여줍니다
* **공유 컨텍스트**: AI 대화 컨텍스트가 팀원이 변경 사항을 이해하는 데 도움이 됩니다
* **실시간 업데이트**: 협업자는 체크포인트 생성을 실시간으로 확인합니다

## 고급 기능

### 체크포인트 미리보기

일부 인터페이스는 체크포인트 미리보기 기능을 지원합니다:

* **시각적 비교**: 다양한 체크포인트 상태에서 앱의 모습을 확인
* **비파괴적 탐색**: 실제로 롤백하지 않고 미리보기
* **진행 상황 추적**: 앱이 시간에 따라 어떻게 발전했는지 파악
* **반복 비교**: 다양한 구현 방식 비교

### 세션 간 롤백

고급 빌더 및 팀 관리자를 위한 기능:

* **확장된 기록**: 여러 개발 세션에 걸친 체크포인트에 접근
* **관리자 제어**: 팀 관리자는 사용자 세션 간 롤백을 수행할 수 있습니다
* **감사 추적**: 체크포인트 생성 및 롤백 작업의 전체 기록

## 사용 사례

### 실험적 개발

체크포인트는 두려움 없는 실험을 가능하게 합니다:

* 쉽게 되돌릴 수 있다는 것을 알고 새로운 기능을 시도하세요
* 다양한 아키텍처 방식을 테스트하세요
* 대체 UI 디자인이나 사용자 흐름을 탐색하세요
* 안전망과 함께 복잡한 통합을 구현하세요

### 디버깅 및 복구

문제가 발생하면 체크포인트가 안정적인 복구를 제공합니다:

* 버그가 발생했을 때 작동하는 상태로 롤백하세요
* 체크포인트 상태를 비교하여 문제를 격리하세요
* 데이터 손상 후 데이터베이스 무결성을 복원하세요
* 실수로 인한 삭제나 수정에서 복구하세요

### 학습 및 반복

체크포인트는 교육적인 개발을 지원합니다:

* 다양한 구현 전략을 비교하세요
* 체크포인트 진행을 통해 AI의 의사 결정 과정을 학습하세요
* 기능이 어떻게 발전했는지 탐색하며 이해를 쌓으세요
* 롤백 안전성과 함께 새로운 기법을 연습하세요
