Le mode Plan introduit une nouvelle façon de discuter avec Replit Agent, axée sur les questions, le brainstorming et la planification de votre travail.

## Qu'est-ce que le mode Plan ?

Le mode Plan vous permet de :

* **Réfléchir à des idées** et explorer différentes approches de votre projet
* **Planifier le travail de développement** avec des listes de tâches structurées
* **Collaborer avec l'IA** sur l'architecture du projet et la planification des fonctionnalités
* **Obtenir des conseils stratégiques** et poser des questions sans modifier le code ou les données de votre projet
* **Passer facilement** au mode Construction lorsque vous êtes prêt à implémenter

Le mode par défaut est maintenant appelé mode **Construction**.

Contrairement au mode Construction, le mode Plan se concentre sur la planification et l'idéation, vous aidant à réfléchir aux projets avant d'écrire du code.

## Premiers pas

### Accéder au mode Plan

Le mode Plan est disponible dans toute application Replit où Agent est activé. Pour y accéder :

1. **Ouvrez votre application Replit** dans l'Éditeur de projet
2. **Recherchez le sélecteur de mode** en bas à gauche de la zone de saisie du chat
3. **Choisissez le mode Plan** dans le menu déroulant

## Fonctionnalités principales

### Planification des tâches

Le mode Plan excelle dans la décomposition de projets complexes en tâches gérables. Fournissez à Agent quelques exigences et il générera une liste de tâches ordonnée des étapes de développement nécessaires pour réaliser votre demande.

### Brainstorming collaboratif

Travaillez avec l'IA pour explorer différentes approches :

* **Plusieurs chemins de solution** pour les problèmes complexes
* **Analyse des avantages et inconvénients** des différentes approches
* **Évaluation des risques** et stratégies d'atténuation

## Flux de travail : De la planification à la construction

### 1. Phase de planification (Mode Plan)

Démarrez votre processus de développement en mode Plan :

* **Définissez la portée et les objectifs** de votre projet
* **Décomposez les exigences** en fonctionnalités spécifiques
* **Planifiez votre architecture** et votre pile technologique
* **Créez une feuille de route de développement** avec des jalons

### 2. Approbation des tâches

Lorsqu'Agent génère une liste de tâches :

* **Révisez** les tâches proposées
* Sélectionnez **Commencer la construction** pour approuver le plan

ou continuez à discuter pour affiner le plan.

### 3. Passage au mode Construction

Lorsque vous êtes prêt à commencer l'implémentation :

* **Cliquez sur « Commencer la construction »** pour approuver le plan
* **Agent passe automatiquement** au mode Construction
* **Agent commence l'implémentation** des tâches approuvées
* **Suivez la progression** tout au long de la phase de développement

L'utilisation du mode Plan suit la même tarification basée sur l'effort que les autres interactions Agent. Vous êtes facturé pour tout le travail d'Agent en mode Plan, y compris les réponses aux questions, les conseils et la génération de listes de tâches. Les frais augmentent pour les demandes plus complexes ou les conversations avec un contexte plus long.

**Toutes les interactions Agent sont facturables** — que l'Agent réponde avec des conseils textuels ou effectue des modifications de code, il y a toujours un coût, bien que les petites demandes coûtent moins cher.

## Cas d'utilisation

### Planification de fonctionnalités

Idéal pour l'ajout de nouvelles fonctionnalités :

* **Décomposez les fonctionnalités complexes** en tâches implémentables
* **Planifiez les modifications de base de données** et les modifications d'API
* **Concevez l'interface utilisateur** et les flux d'expérience utilisateur
* **Tenez compte des cas limites** et de la gestion des erreurs

## Meilleures pratiques

### Prompting efficace

Pour tirer le meilleur parti du mode Plan :

* **Soyez précis** quant aux exigences de votre projet
* **Posez des questions de suivi** pour clarifier les suggestions de l'IA
* **Demandez des exemples** lors de la discussion de concepts complexes
* **Discutez des compromis** entre différentes approches
* **Itérez sur les idées** avant de vous engager dans l'implémentation
* **Sauvegardez les décisions importantes** en les référençant dans les conversations de suivi
