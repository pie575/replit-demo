<div id="agent-usage-cost-visibility">
  ### Agent 使用成本可见性
</div>

任务运行期间，可实时查看 Agent 的使用成本。打开 Chat 标题栏中的抽屉，即可监控正在运行的任务支出——对于运行时间较长、自主性较高的任务尤其有用。

<div id="escape-key-for-visual-selectedit-mode">
  ### 用 Escape 键退出可视化选择/编辑模式
</div>

按 Escape 键即可退出可视化选择模式或返回 Build 模式。一个小小的快捷键，让操作更流畅。

<div id="faster-agent-stopping">
  ### 更快停止 Agent
</div>

在 workspace 中停止或启动 Agent 时，Agent 响应更迅速，等待时间更短。

<div id="github-import-improvements">
  ### GitHub 导入改进
</div>

GitHub 导入过程中可查看实时进度，不再只显示笼统的提示信息，导入速度也更快。

<div id="dependency-vulnerability-scanning">
  ### 依赖项漏洞扫描
</div>

安全扫描器现已支持检测 Go、JavaScript、Python 和 Rust 的依赖项漏洞，后续还将支持更多语言。

<div id="webview-logging-experience">
  ### Webview 日志体验
</div>

在同一处查看 Webview 日志和控制台输出 (与 Agent 使用的日志一致) ，让调试更轻松。

<div id="teams-and-enterprise-2">
  ## Teams 和 Enterprise
</div>

<div id="support-seat-access-for-teams">
  ### 面向团队的支持席位访问
</div>

将 Replit 支持团队添加为访客账户，不占用计费席位。需要协助时，可仅授予其对特定 App 的访问权限，workspace 的隐私始终由你掌控。
