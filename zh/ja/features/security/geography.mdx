选择托管工作区和已发布应用基础设施的区域，既满足数据驻留要求，又能降低延迟。Replit 将工作区区域设置与发布区域设置分开提供，因此你可以分别管理开发环境和已发布应用所在的位置。

<div id="section">
  ## 比较工作区地理位置与发布地理位置
</div>

| 项目        | 工作区地理位置   | 发布地理位置         |
| :-------- | :--------------- | :------------- |
| **管理对象**  | 工作区中的开发资源 | 已发布应用的计算资源和存储  |
| **设置时机**  | 创建工作区时   | 发布项目时          |
| **位置结果**  | 确定新项目和资源所在的区域    | 将已发布的构件集中在一个区域 |
| **之后可更改** | 否                | 否              |

工作区地理位置与发布地理位置不必一致。

有关在创建工作区时选择开发区域的更多信息，请参阅 [工作区地理位置](/zh/ja/features/collaboration/workspace-geography)。

<div id="section-2">
  ## 发布区域
</div>

发布区域在你发布项目时设置。默认情况下，Replit 会推荐离你最近的区域，这有助于降低应用访问者的延迟，也更容易满足数据驻留要求。

选定区域后，项目发布的所有资源 (如计算资源、数据库、Object Storage 等) 都会自动部署到同一区域。区域专属代理也有助于降低应用访问者的延迟。

<div id="section-3">
  ### 选择发布的区域
</div>

若要选择推荐之外的区域，请按以下步骤操作：

<Steps>
  <Step>
    在 Replit 项目中打开 **Publishing** 工具。
  </Step>

  <Step>
    展开 **Advanced** 设置。
  </Step>

  <Step>
    在 **Geography** 下拉菜单中选择所需的区域。
  </Step>

  <Step>
    选择 **Publish**，将项目发布到所选的区域。
  </Step>
</Steps>

<div id="section-4">
  ### 为已发布的项目强制指定区域
</div>

Enterprise 管理员可以为组织内的所有项目强制指定发布区域。策略生效后，组织内的构建者只能发布到指定区域。该策略仅适用于尚未发布的项目——已发布到其他区域的项目不受影响。

<Note>
  强制指定发布区域为 Enterprise 功能。如需了解 Enterprise 方案详情，请查看[定价](https://replit.com/pricing/)。
</Note>

<Steps>
  <Step>
    前往 **Account settings**。
  </Step>

  <Step>
    选择 **Advanced**。
  </Step>

  <Step>
    选择所有项目首次发布时必须使用的区域。
  </Step>
</Steps>

<div id="section-5">
  ### 发布区域的限制
</div>

在选择发布区域之前，请注意以下限制：

* **发布后无法更改区域。** 将项目发布到某个区域后，该选择即为永久性的，已发布的项目无法迁移到其他区域。
* **开发环境与发布环境所在位置可能不同。** Object Storage 等资源可能在发布之前就已创建，因此可能与发布所在的区域不一致。

<div id="section-6">
  ## 可用区域
</div>

工作区和发布可选择的区域不同。

| 区域                           | 工作区可选 | 发布时可选 |
| :--------------------------- | :---- | :---- |
| **North America (北美)&#x20;**&#x20;| 是     | 是     |
| **Europe (EU)&#x20;**&#x20;       | 是     | 是     |
| **Asia (亚洲)&#x20;**&#x20;         | 是     | 是     |
| **South America (南美)&#x20;**&#x20;| 否     | 是     |
| **Australia (澳大利亚)&#x20;**&#x20;  | 否     | 是     |

<Note>
  仅 Pro 套餐用户可以选择工作区区域。
  Core、Pro 和 Enterprise 套餐用户可以选择发布区域。
  Free 套餐用户默认发布到北美。
</Note>
