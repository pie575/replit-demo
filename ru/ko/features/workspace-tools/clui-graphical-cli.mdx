CLUI (Command Line User Interface) — интерактивная командная панель Replit, которая позволяет быстро выполнять различные действия, не переходя по меню. Она сочетает эффективность командной строки с графическим интерфейсом.

<div id="section">
  ## Возможности
</div>

CLUI обеспечивает удобное управление командами в трёх контекстах Replit:

* **Управление настройками**: управляйте настройками, просматривайте предупреждения и восстанавливайте удалённые Replit App
* **Быстрая навигация**: переходите между Replit App и получайте доступ к часто используемым функциям с помощью быстрых команд
* **Работа в Workspace**: находите файлы, ищите код и получайте доступ к инструментам в среде разработки

<div id="section-2">
  ## Использование
</div>

<div id="clui">
  ### CLUI аккаунта
</div>

CLUI аккаунта помогает управлять настройками, командами и удалёнными Replit App.

**Как получить доступ**: перейдите на [страницу CLUI](https://replit.com/~/cli), введите в поле ввода текст для поиска команды и нажмите Enter, чтобы выполнить её.

<Accordion title="Команды аккаунта">
  Введите `account`, чтобы управлять настройками:

  * **view-warns**: просмотр полученных предупреждений
  * **change-username**: изменение имени пользователя (доступно только один раз)
</Accordion>

<Accordion title="Команды Trash">
  Введите `trash`, чтобы управлять удалёнными Replit App:

  * **restore &lt;title&gt;**: восстановление удалённого Replit App по названию (если есть несколько приложений с одинаковым названием, будет восстановлено то, которое было удалено последним)
  * **view**: просмотр недавно удалённых Replit App
</Accordion>

<Accordion title="Команды Team">
  Введите `team`, чтобы управлять командами:

  * **view**: просмотр участников команд, в которых вы состоите, по имени пользователя
  * **fork-repl-to-project**: создание командного проекта путём форка существующего Replit App
</Accordion>

<Accordion title="Команды Clear">
  Введите `clear`, чтобы очистить экран от всех ранее выполненных команд
</Accordion>

<div id="clui-2">
  ### CLUI быстрых команд
</div>

CLUI быстрых команд открывает быстрый доступ к основным возможностям Replit с любой страницы.

<Frame>
  <img src="/assets/mirror/shortcuts-clui-768d49b44785.png" alt="CLUI быстрых команд" width="689" height="291" data-path="images/getting-started/shortcuts-clui.png" />
</Frame>

**Как открыть**: на большинстве страниц Replit нажмите **CMD/CTRL + K** или щёлкните значок поиска в верхней панели навигации.

<Accordion title="Доступные команды">
  * **Search**: поиск по Replit App, шаблонам, коду, пользователям и другому
  * **New**: создание нового Replit App
  * **My Replit Apps**: просмотр ваших Replit App и переход к ним
  * **My Code**: поиск по коду во всех ваших Replit App
</Accordion>

<div id="workspace-clui">
  ### Workspace CLUI
</div>

Workspace CLUI помогает выполнять задачи, открывать инструменты, находить файлы и искать код при работе в Replit App.

<Frame>
  <img src="/assets/mirror/ws-clui-81764b3d111b.png" alt="Workspace CLUI" width="429" height="202" data-path="images/getting-started/ws-clui.png" />
</Frame>

**Как открыть**: нажмите **CMD/CTRL + K** в Workspace или щёлкните значок Search в левом верхнем углу.

<Accordion title="Основные задачи">
  * **Поиск файлов**: быстро находите файлы в проекте
  * **Поиск кода**: находите нужные фрагменты кода во всех файлах
  * **Доступ к инструментам**: открывайте доступные в Workspace инструменты или панели
  * **Выполнение команд**: выполняйте команды Workspace
</Accordion>
