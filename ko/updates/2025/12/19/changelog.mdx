### 문서 UI 새단장

<Frame>
  <img src="/assets/mirror/cleanshot-2025-12-19-at-08-42-08-2x_d34ab73df672-cb2d456d47a4.png" alt="이전: 이전 문서 외관" width="3309" height="2126" data-path="images/changelog/2025-12-19/cleanshot-2025-12-19-at-08-42-08-2x_d34ab73df672.png" />
</Frame>

문서 사이트가 Replit의 Workspace 디자인 및 브랜드 색상에 더 잘 맞도록 시각적 업데이트를 받았습니다. 이를 통해 문서와 메인 애플리케이션 사이에 더욱 일관된 경험을 제공합니다.

* 브랜드 색상에 맞게 색상 체계 업데이트
* 디자인이 이제 Workspace 인터페이스와 더 유사하게 변경
* Replit 속성 전반에 걸쳐 향상된 시각적 일관성

### 롤백 세션 스티칭

  <img src="/assets/mirror/image_96365209a733-43b242e09e09.png" width="1600" height="1200" data-path="images/changelog/2025-12-19/image_96365209a733.png" />

롤백이 이제 연속적인 세션을 자동으로 연결하여 여러 작업 세션을 통해 더 쉽게 되돌릴 수 있습니다. 이 편의 기능은 프로젝트 기록을 더 원활하게 탐색하는 데 도움이 됩니다.

### 사용자 지정 MCP 서버 아이콘

<Frame>
  <img src="/assets/mirror/68747470733a2f2f6170702e6772617068697465_77c0ef3cd3e9-e82e55fe7691.png" width="676" height="594" data-path="images/changelog/2025-12-19/68747470733a2f2f6170702e6772617068697465_77c0ef3cd3e9.png" />

사용자 지정 MCP 서버가 이제 Google Favicon API를 사용하여 적절한 아이콘을 표시하며, Workspace에서 더 쉽게 식별할 수 있도록 MCP 태그가 추가되었습니다.

### 상태 점 디자인 업데이트

상태 표시 점이 이제 박스 섀도우 제거로 더 깔끔한 시각적 외관을 가집니다.
