App Storage — это встроенное объектное хранилище Replit, которое позволяет App легко размещать и хранить загруженные файлы, например изображения, видео и документы.
Бакеты — это контейнеры для хранения объектов, например файлов. Они содержат политики доступа, ограничивающие действия пользователей или приложений с контентом.

<Info>
  Мы переименовали <strong>Object Storage</strong> в <strong>App Storage</strong>. Функциональность не изменилась, а существующие бакеты, разрешения и программный доступ продолжат работать.
</Info>

С помощью App Storage можно создавать следующие приложения:

* **Платформы для обмена фотографиями**: дайте разработчикам возможность загружать, хранить и отображать изображения
* **Сервисы потокового видео**: обрабатывайте загрузку видео и предоставляйте контент зрителям
* **Системы управления документами**: безопасно храните и упорядочивайте файлы разработчиков
* **Сайты-портфолио**: демонстрируйте работы с медиафайлами, которые надёжно загружаются
* **Сервисы резервного копирования файлов**: предоставляйте разработчикам облачное хранилище для важных файлов

<Note>
  Попросите **Agent** добавить App Storage, указав сведения о типах файлов, которые должно обрабатывать ваше приложение. Agent настроит интеграцию, создаст необходимые бакеты и обновит App, чтобы оно могло загружать, хранить и извлекать файлы с помощью расширенных возможностей, таких как аутентификация и контроль доступа.
</Note>

Инструмент App Storage позволяет беспрепятственно обмениваться данными между окружениями разработки и продакшена, а также с другими Replit App.

<div id="section">
  ## Возможности
</div>

<Info>
  App Storage работает на базе Google Cloud Storage (GCS).
  Это обеспечивает ведущие в отрасли показатели времени безотказной работы, доступности и безопасности.
</Info>

App Storage предоставляет Replit App следующие возможности:

* **Постоянное облачное хранилище**: храните файлы, к которым опубликованные приложения и пользователи могут обращаться в любое время
* **Масштабируемая работа с файлами**: удовлетворяйте растущие потребности в хранении данных, не беспокоясь об ограничениях хранилища
* **Обмен данными между приложениями**: предоставляйте нескольким Replit App общий доступ к бакетам для распределённой архитектуры
* **Программный доступ**: загружайте, скачивайте файлы и управляйте ими с помощью удобного API
* **Расширенная интеграция с Agent**: поручите Agent настроить App Storage с расширенными параметрами, проверить существующую конфигурацию и сгенерировать полный код бэкенда и фронтенда, включая аутентификацию и контроль доступа

Вот несколько способов использовать App Storage в Replit App:

* Хранение фотографий профиля разработчиков и загружаемых медиафайлов
* Размещение изображений товаров для сайтов электронной коммерции
* Обработка загрузки документов через формы
* Создание функций обмена файлами и совместной работы
* Создание систем управления контентом с медиатеками

<Tip>

Agent теперь может настраивать объектное хранилище, проверять конфигурацию и генерировать полный код бэкенда и фронтенда с расширенными функциями, такими как аутентификация и контроль доступа. Просто упомяните в промпте «App Storage» или «файловое хранилище».

<div id="section-2">
  ## Использование
</div>

<Note>
  Для доступа к бакетам и объектам в них Replit App необходимо пройти аутентификацию в Google Cloud Storage.
  Для автоматической аутентификации используйте официальную клиентскую библиотеку Replit App Storage.
</Note>

Инструмент App Storage доступен непосредственно в Project Editor.

<Accordion title="Как открыть инструмент App Storage">
  В левой **Tool dock**:

  1. Выберите <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="иконка всех инструментов" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**, чтобы просмотреть список инструментов Project Editor.
  2. Выберите <img class="icon-svg" src="/assets/mirror/object-storage-monoochrome-icon-aaba8f517280.svg" alt="иконка App Storage" width="16" height="16" data-path="images/icons/object-storage-monoochrome-icon.svg" /> **App Storage**.

  В **строке поиска**:

  1. Нажмите значок <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="иконка лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> лупы вверху, чтобы открыть поиск.
  2. Введите &quot;App Storage&quot;, найдите инструмент и выберите его в результатах поиска.
</Accordion>

Чтобы подключить новый бакет хранилища к Replit App, создайте бакет.

<Accordion title="Как создать бакет">
  В инструменте **App Storage**:

  1. Нажмите **Create new bucket**.
  2. Введите имя бакета в поле **Name** и выберите **Create bucket**.

  Вкладка App Storage будет выглядеть примерно так, как показано на следующем снимке экрана.

  <Frame>
    <img src="/assets/mirror/object-storage-empty-bucket-3462e2efb1bc.png" alt="снимок экрана инструмента App Storage" width="2790" height="1218" data-path="images/databases/object-storage-empty-bucket.png" />
  </Frame>

  Чтобы создать дополнительные бакеты, откройте раскрывающееся меню бакетов в левом верхнем углу вкладки **App Storage** и выберите **Create new bucket**.
</Accordion>

<div id="id">
  ### Как узнать ID бакета
</div>

В раскрывающемся меню в верхней части вкладки **App Storage** выберите экран **Settings**, чтобы найти **Bucket ID**.
ID бакета уникально идентифицирует бакет, и для выполнения операций на него нужно ссылаться в коде.

Если у вас несколько бакетов, выберите нужный в раскрывающемся меню в левом верхнем углу.

На следующем снимке экрана показан Bucket ID бакета «FileVault Bucket One».

<div id="section-4">
  ### Загрузка и скачивание объектов
</div>

Чтобы загрузить объекты в выбранный бакет:

1. На вкладке **App Storage** откройте страницу **Objects**.
2. Выберите <img class="icon-svg" src="/assets/mirror/upload-file-5894be4232ce.svg" alt="Иконка загрузки файла" width="16" height="16" data-path="images/icons/upload-file.svg" /> **Upload files** или, чтобы загрузить все файлы из папки, <img class="icon-svg" src="/assets/mirror/upload-folder-fc87519bedf9.svg" alt="Иконка загрузки папки" width="16" height="16" data-path="images/icons/upload-folder.svg" /> **Upload folder**.
   Затем в диалоговом окне выберите один или несколько файлов для загрузки.
   Также можно перетащить файл или папку в область со списком содержимого бакета.

Чтобы скачать объекты из выбранного бакета:

1. На вкладке **App Storage** откройте страницу **Objects**.
2. Нажмите <img class="icon-svg" src="/assets/mirror/download-icon-c7b527953d65.svg" alt="Иконка скачивания" width="16" height="16" data-path="images/icons/download-icon.svg" /> иконку скачивания справа от файла.

<div id="section-5">
  ### Упорядочивание объектов по папкам
</div>

Чтобы создать папку в выбранном бакете:

1. На вкладке **App Storage** перейдите на страницу **Objects**.
2. На странице **Objects** выберите <img class="icon-svg" src="/assets/mirror/create-folder-c9acf112a042.svg" alt="Иконка создания папки" width="16" height="16" data-path="images/icons/create-folder.svg" /> **Create Folder**.
3. Введите имя папки.

Чтобы добавить объект в папку на странице **Objects**, перетащите его в нужную папку.

Чтобы переместить объект в родительскую папку, перетащите его к заголовку над списком объектов и отпустите над именем родительской папки.
Следующая анимация показывает перемещение файла &quot;product&#95;demo.mov&quot; из папки &quot;videos&quot; в родительскую папку &quot;Objects&quot;.

<div id="section-6">
  ### Удаление объекта или бакета
</div>

<Warning>
  Удаление нельзя отменить. Перед продолжением обязательно создайте резервную копию важных данных.
</Warning>

Чтобы окончательно удалить объект:

1. На вкладке **App Storage** перейдите к разделу **Objects**.
2. Нажмите иконку удаления <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="иконка удаления" width="16" height="16" data-path="images/icons/trash-icon.svg" /> рядом с нужным объектом.
3. Подтвердите удаление в диалоговом окне.

Чтобы удалить бакет и все объекты в нём:

1. На вкладке **App Storage** перейдите к разделу **Settings**.
2. Убедитесь, что в раскрывающемся списке бакетов в левом верхнем углу выбран нужный бакет.
3. Нажмите <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="иконка удаления" width="16" height="16" data-path="images/icons/trash-icon.svg" /> **Delete Bucket**.
4. Подтвердите удаление в диалоговом окне.

<div id="section-7">
  ### Управление доступом к бакетам
</div>

Replit связывает все созданные вами бакеты с вашей учётной записью, чтобы они были доступны во всех ваших Replit App. Replit App, создавшее бакет, автоматически получает к нему доступ.

Вы можете управлять тем, какие Replit App имеют доступ к конкретному бакету, чтобы эффективно и безопасно делиться данными.

Чтобы предоставить Replit App доступ к бакету, созданному другим App в вашей учётной записи:

1. В меню бакетов в левом верхнем углу вкладки App Storage выберите <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="иконка лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" />
   **Add an existing bucket**.
2. В диалоговом окне **Choose a Bucket** выберите бакет, который хотите добавить, и нажмите **Add Bucket to Repl**.

<Frame>
  <img src="/assets/mirror/choose-bucket-dialog-b709aa247a85.png" alt="снимок экрана диалогового окна выбора бакета" width="1115" height="457" data-path="images/databases/choose-bucket-dialog.png" />
</Frame>

Чтобы отозвать у Replit App доступ к бакету:

1. На вкладке **App Storage** перейдите на экран **Settings**.
2. В раскрывающемся списке бакетов в левом верхнем углу вкладки выберите имя бакета.
3. Выберите **Remove Bucket from Repl** и подтвердите удаление в диалоговом окне.
