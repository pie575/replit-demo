description: "Replit propose une fonctionnalité de Virtual Network Computing (VNC). VNC est un protocole de bureau virtuel éprouvé qui permet aux Replit App de diffuser des bureaux natifs dans un navigateur web. Ce protocole permet aux applications natives (développées en Python, Java, C++, etc.) d’ouvrir des fenêtres de bureau comme elles le feraient sur un ordinateur physique."

Cette technologie de streaming vous permet d’utiliser des applications existantes dans un navigateur, depuis n’importe quel appareil ! Par exemple, vous pouvez exécuter directement sur un smartphone ou une tablette un jeu Python conçu pour les ordinateurs de bureau, sans modifier son code source.

<div id="vnc">
  ## Utiliser VNC
</div>

Quel que soit le langage utilisé, toutes les Replit App peuvent utiliser un bureau virtuel. Aucune modification n’est nécessaire pour exécuter des programmes graphiques natifs dans Replit. Le volet VNC s’affiche lorsqu’une application tente d’ouvrir une fenêtre de bureau native.

<div id="replit-app">
  ## Sécuriser votre Replit App
</div>

Par défaut, les connexions VNC ne sont pas protégées par mot de passe et utilisent la même authentification que WebSocket. Elles ne sont donc accessibles que depuis [https://replit.com](https://replit.com). Si vous devez accéder à votre Replit App via un client [noVNC](https://novnc.com) externe, vous pouvez définir un mot de passe VNC.

Définissez un mot de passe dans les paramètres [Secrets](/fr/ja/core-concepts/project-editor/app-setup/secrets) de votre Replit App. `Secrets` vous permet de stocker des mots de passe de manière sécurisée sans craindre que d’autres utilisateurs puissent y accéder. Définir `VNC_PASSWORD` renforce la sécurité des connexions à distance.

<div id="vnc-2">
  ## Utiliser VNC en plein écran
</div>

Pour suivre cette procédure, vous devez avoir sécurisé votre Replit App en suivant les instructions ci-dessus.

1. Dans l’onglet « Shell », exécutez la commande suivante :
   ```sh theme={null}
   echo $REPL_ID
   ```

<Frame>
  <img src="/assets/mirror/replid-6508492b1e8b.png" alt="Image montrant la commande echo" width="628" height="174" data-path="images/vnc/replid.png" />
</Frame>

2. Construisez l’URL de connexion en remplaçant `REPL_ID` par la valeur affichée ci-dessus : `<\REPL_ID\>.id.repl.co`
3. Dans un autre onglet du navigateur, ouvrez le [client noVNC](https://novnc.com/noVNC/vnc.html).
4. Ouvrez les paramètres de connexion.

<Frame>
  <img src="/assets/mirror/settings-3e0e0c4fd198.png" alt="Ouvrir les paramètres de connexion" width="126" height="302" data-path="images/vnc/settings.png" />
</Frame>

5. Développez la section WebSockets. Saisissez l’URL de connexion (`\<REPL_ID\>.id.repl.co`) dans le champ `host` et laissez le champ `path` vide.

<Frame>
  <img src="/assets/mirror/host-31b5c99194b2.png" alt="Hôte" width="214" height="230" data-path="images/vnc/host.png" />
</Frame>

6. Remplacez `Scaling Mode` par `Remote Resizing` :

<Frame>
  <img src="/assets/mirror/scaling-0ffe9aae34bb.png" alt="Mise à l’échelle" width="147" height="74" data-path="images/vnc/scaling.png" />
</Frame>

7. Lorsque vous êtes invité à saisir vos identifiants, utilisez le nom d’utilisateur `runner` et le mot de passe défini ci-dessus.
