<div id="layout-controls-in-the-visual-editor">
  ### Visual Editor 中的布局控件
</div>

Visual Editor 现在提供专门的 **Layout** 控件，你可以可视化地调整 flexbox 布局，无需再让 Agent 重写样式。选中任意容器，展开 Layout 部分，即可设置 flex 方向、对齐方式和分布方式；还可以设置元素之间的像素间距，或打开 **Space between** 开关，让子元素分别贴靠两端。

编辑器面板也重新整理为更清晰的 **Text**、**Image**、**Layout**、**Color** 和 **Border** 几个部分，让你更容易找到所需的控件。

<div id="agent">
  ## Agent
</div>

<div id="agent-settings-stay-yours-in-shared-projects">
  ### 共享项目中的 Agent 设置仅对你生效
</div>

你的 Agent 偏好设置 (如模型层级、Plan 模式、自动合并和自动批准计划) 现在仅对你生效，不再与项目中的其他所有人共享。队友在自己的 task 中切换到 Power Mode，也不会影响你的设置。无论项目中有多少协作者，Agent 都会在你发送下一条消息时使用你所选择的设置。

详细了解 [Agent 模式](/zh/features/agent/agent-modes#settings-in-shared-projects)。

<div id="agent-suggests-power-mode-when-youre-stuck">
  ### 遇到瓶颈时，Agent 会建议使用 Power Mode
</div>

当 Agent 发现你在 Economy Mode 中反复遇到同一问题时，现在会建议你在下一条消息中切换到 Power。该建议会检测重复请求或反复失败的代码，每个项目最多显示一次。在规划会话中、你已提到预算方面的顾虑时，或你使用免费套餐时，Agent 不会显示此建议。

<div id="cleaner-task-settings-dropdown">
  ### 更简洁的 task 设置下拉菜单
</div>

从 task 标题栏打开的下拉菜单更易用了。进行中的 task 或规划标题现在位于顶部，可就地重命名；自动化设置 (自动应用、自动批准) 单独成一栏，位于标题与操作之间；弹出框采用固定宽度，不会再随 task 名称长短而来回抖动。已停用的自动化选项会被隐藏，菜单只显示适用于当前 task 的内容。

<div id="two-new-connectors-quiver-ai-and-browserbase">
  ### 两个新连接器：Quiver AI 和 Browserbase
</div>

连接器目录现已新增两项服务。打开 **集成** 面板，然后选择 **添加新集成**，即可连接其中任一服务。

* **Quiver AI**：通过托管 API 生成 SVG 插图，并将光栅图像矢量化。当 Agent 需要按需生成清晰的 SVG 资源时非常有用。
* **Browserbase**：运行托管无头浏览器，执行内容获取、搜索和完整会话自动化。当 Agent 需要加载真实网页、运行 JavaScript，或与阻止普通 HTTP 请求的网站交互时非常有用。
