<div id="layout-controls-in-the-visual-editor">
  ### Contrôles de mise en page dans le Visual Editor
</div>

Le Visual Editor propose désormais des contrôles de **Mise en page** dédiés qui vous permettent d’ajuster visuellement la disposition flexbox, sans demander à Agent de réécrire les styles. Sélectionnez un conteneur, développez la section Mise en page, puis choisissez une direction flex, un alignement et une justification. Définissez l’espacement en pixels entre les éléments ou activez l’option **Espace entre** pour placer les éléments enfants sur des bords opposés.

Le volet de l’éditeur a également été réorganisé en sections plus claires : **Texte**, **Image**, **Mise en page**, **Couleur** et **Bordure**, afin de faciliter l’accès au contrôle dont vous avez besoin.

<div id="agent-settings-stay-yours-in-shared-projects">
  ### Vos paramètres Agent restent les vôtres dans les projets partagés
</div>

Vos préférences Agent, telles que le niveau de modèle, le mode de planification, la fusion automatique et l’approbation automatique du plan, vous sont désormais propres au lieu d’être partagées avec toutes les personnes du projet. Lorsqu’un coéquipier passe en mode Power pour ses tâches, vos paramètres ne sont plus modifiés. Le paramètre que vous choisissez est celui qu’Agent utilise lorsque vous envoyez votre prochain message, même dans les projets comptant de nombreux collaborateurs.

Pour en savoir plus, consultez les [modes Agent](/fr/features/agent/agent-modes#settings-in-shared-projects).

<div id="agent-suggests-power-mode-when-youre-stuck">
  ### Agent suggère le mode Power lorsque vous êtes bloqué
</div>

Lorsque Agent détecte que vous rencontrez le même problème à répétition en mode Economy, il vous propose désormais de passer à Power pour votre prochain message. Cette suggestion repère les demandes répétées ou le code qui échoue continuellement, et elle ne s’affiche qu’une fois par projet au maximum. Agent ne fait pas cette suggestion lors des sessions de planification, si vous avez déjà mentionné une contrainte budgétaire ou si vous utilisez le forfait gratuit.

<div id="cleaner-task-settings-dropdown">
  ### Menu des paramètres de tâche plus épuré
</div>

Le menu déroulant qui s’ouvre depuis l’en-tête d’une tâche est plus facile à utiliser. Le titre de la tâche active ou du plan se trouve désormais en haut et peut être renommé directement. Les paramètres d’automatisation (application automatique, approbation automatique) disposent de leur propre section entre le titre et les actions, et la fenêtre contextuelle a une largeur fixe pour éviter qu’elle ne se décale lorsque les noms de tâches changent. Les lignes d’automatisation désactivées sont masquées afin que le menu n’affiche que les options applicables à la tâche actuelle.

<div id="two-new-connectors-quiver-ai-and-browserbase">
  ### Deux nouveaux connecteurs : Quiver AI et Browserbase
</div>

Deux services supplémentaires sont désormais disponibles dans le catalogue de connecteurs. Ouvrez le panneau **intégration** et sélectionnez **Add new integration** pour connecter l’un ou l’autre.

* **Quiver AI** : générez des illustrations SVG et vectorisez des images matricielles via une API gérée. Utile lorsqu’Agent a besoin d’un asset SVG net à la demande.
* **Browserbase** : exécutez des navigateurs sans interface graphique gérés pour récupérer des données, effectuer des recherches et automatiser intégralement des sessions. Utile lorsqu’Agent doit charger une page web réelle, exécuter du JavaScript ou interagir avec un site qui bloque les simples requêtes HTTP.
