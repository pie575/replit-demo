Shell vous permet de travailler sur vos projets comme dans un terminal classique, notamment pour gérer des fichiers,
installer des paquets et exécuter des scripts. Par exemple, vous pouvez parcourir les fichiers du projet ou
utiliser `psql` lorsque votre projet est connecté à une base de données.

<Tip>
  Pour mieux gérer votre flux de travail, privilégiez le bouton **Run** plutôt que d&#39;exécuter
  votre app depuis le Shell. Le flux de travail lancé par le bouton **Run** envoie
  la sortie vers l&#39;outil Console, qui permet de consulter les
  logs de manière structurée.
</Tip>

<div id="features">
  ## Fonctionnalités
</div>

Shell offre les fonctionnalités suivantes :

* **Ouvrir plusieurs shells** : Ouvrez plusieurs instances de Shell pour travailler simultanément sur différentes tâches.
* **Rechercher du texte** : Recherchez du texte précis dans la sortie du Shell.

<div id="confirm-shell-access">
  ### Vérifier l’accès au Shell
</div>

Pour vérifier que le Shell est prêt et afficher le workspace actuel, exécutez :

```sh theme={null}
pwd
```

Shell affiche le chemin du workspace actuel.

<Frame caption="La commande pwd affiche le chemin du workspace actuel et revient à l’invite du Shell.">
  <img src="/assets/mirror/shell-pwd-output-2d31a0e0466b.jpg" alt="Onglet Shell affichant la commande pwd, le chemin du workspace en sortie et le retour de l’invite" width="1280" height="246" data-path="images/workspace/shell-pwd-output.jpg" />
</Frame>

Pour un projet avec une base de données, sélectionnez **Tools** → **Database**, puis ouvrez la page
**Development database**. Cette page propose des options de connexion. Gardez
les informations de connexion privées ; ne les copiez pas dans la documentation, les captures d’écran,
les logs, les fichiers source ou les messages partagés.

<div id="text-search">
  ### Recherche de texte
</div>

Les étapes suivantes expliquent comment accéder à l’outil de recherche de texte et l’utiliser :

1. Sélectionnez l’icône de loupe <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="icône de loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> située en haut à droite de l’onglet Shell pour ouvrir la boîte de dialogue de recherche.
2. Saisissez un terme de recherche et sélectionnez **Next** pour parcourir les résultats.
3. Utilisez **Previous** pour revenir aux résultats précédents.
4. Sélectionnez **Exit** ou cliquez en dehors de la boîte de dialogue pour quitter la recherche de texte.

<div id="multiple-shells">
  ### Plusieurs shells
</div>

Pour créer un autre shell :

1. Dans l’en-tête du panneau Shell, sélectionnez le menu de l’instance Shell.
2. Sélectionnez **New Shell**.

<Frame>
  <img src="/assets/mirror/shell-new-94a280c1230f.png" alt="Menu de l’instance Shell avec le workspace actuel et l’option New Shell" width="1280" height="224" data-path="images/workspace/shell-new.png" />
</Frame>

Utilisez ce même menu pour passer d’un shell à l’autre. Replit identifie chaque shell par la dernière commande exécutée afin de vous aider à les distinguer.

<Warning>
  Lorsque vous ouvrez plusieurs shells, Replit ferme automatiquement les instances
  de shell inactives. Un shell inactif n’est pas sélectionné et n’exécute aucun processus utilisateur.
</Warning>
