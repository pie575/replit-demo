<div id="section">
  ## 概要
</div>

如果您尝试通过 [连接器](/zh/ja/features/integrations/overview#connectors) 连接 Google Workspace 服务 (Drive、Docs、Sheets、Calendar 或 Gmail) 时看到 **“此应用已被阻止”** 错误消息，通常是由于您组织的 Google Workspace 中 Google OAuth 设置不正确所致。

本指南将介绍如何解决此问题，以便您能够将 Google 服务连接到 Replit App。

<Frame>
  <img src="/assets/mirror/app-is-blocked-837b32f44f72.png" alt="显示“此应用已被阻止”消息的 Google 错误对话框，该消息阻止 OAuth 访问" width="1279" height="502" data-path="images/replitai/debugging-google-connectors/app-is-blocked.png" />
</Frame>

<Warning>
  这些步骤仅适用于 **Google Workspace** 账号 (由组织管理的账号) 。如果您使用的是关联 `@gmail.com` 地址的个人 Google 账号，且 Replit 连接器 被阻止，则无法自行更改 OAuth 政策——请联系您的 Google Workspace 管理员，或使用其他账号。
</Warning>

<div id="section-2">
  ## 故障排查步骤
</div>

<div id="1">
  ### 步骤 1：尝试无痕模式
</div>

浏览器扩展程序或缓存数据有时会干扰 OAuth 流程，使用无痕模式可以避开这些问题。

<Steps>
  <Step title="打开无痕模式">
    在浏览器中新建一个**无痕** (Chrome) 或**隐私浏览** (Firefox/Safari) 窗口。
  </Step>

  <Step title="登录 Replit">
    在 [replit.com](https://replit.com) 登录你的 Replit 账户。
  </Step>

  <Step title="重新尝试连接">
    在 Project Editor 中打开应用，在侧边栏中前往 **Connectors**，然后重新尝试连接 Google 服务。
  </Step>
</Steps>

如果错误仍未消失，请继续执行步骤 2。

<div id="2-google-workspaceoauth">
  ### 步骤 2：检查 Google Workspace 的 OAuth 设置
</div>

<Note>
  此步骤需要访问贵组织的 **Google 管理控制台**。如果你没有管理员权限，请联系 IT 团队。
</Note>

<Steps>
  <Step title="打开 Google 管理控制台">
    登录贵组织的 [Google 管理控制台](https://admin.google.com)。
  </Step>

  <Step title="确认用户是否存在">
    进入 **Users** 部分，确认尝试连接 Replit 的账户在列表中。

    <Frame>
      <img src="/assets/mirror/google-workspace-users-c21d8fd43f71.png" alt="显示用户账户的 Google 管理控制台 Users 部分" width="1104" height="596" data-path="images/replitai/debugging-google-connectors/google-workspace-users.png" />
    </Frame>
  </Step>

  <Step title="进入 API 控制">
    前往 **Security &gt; Access and data control &gt; API controls**。

    <Frame>
      <img src="/assets/mirror/google-workspace-api-controls-b811709315cf.png" alt="显示 Security > API Controls 导航路径的 Google 管理控制台" data-og-width="1140" width="1140" data-og-height="631" height="631" data-path="images/replitai/debugging-google-connectors/google-workspace-api-controls.png" data-optimize="true" data-opv="3" srcset="/assets/mirror/google-workspace-api-controls-a27d4577aee8.png 280w, /assets/mirror/google-workspace-api-controls-d681943c082d.png 560w, /assets/mirror/google-workspace-api-controls-8f1b1659e60a.png 840w, /assets/mirror/google-workspace-api-controls-795bc698b885.png 1100w, /assets/mirror/google-workspace-api-controls-c122b9eb493f.png 1650w, /assets/mirror/google-workspace-api-controls-2415c93b4f41.png 2500w" />
    </Frame>
  </Step>

  <Step title="打开第三方应用访问设置">
    选择 **Manage third-party app access**。

    <Frame>
      <img src="/assets/mirror/third-party-app-access-eb5c94107497.png" alt="高亮显示 Manage third-party app access 按钮的 Google 管理控制台 API 控制页面" width="1686" height="468" data-path="images/replitai/debugging-google-connectors/third-party-app-access.png" />
    </Frame>
  </Step>

  <Step title="确认 OAuth 访问权限">
    确认 Google Workspace 用户已启用 OAuth 访问权限。如果访问受限，请授予必要的权限，让 Replit 能够完成 OAuth 流程。
  </Step>
</Steps>

如果连接仍然失败，请继续执行步骤 3。

<div id="3-replitoauth">
  ### 步骤 3：将 Replit 添加为 OAuth 受信任客户端
</div>

如果贵组织默认限制第三方应用的访问权限，则需要显式将 Replit 设为受信任应用。

<Steps>
  <Step title="打开 Google 管理控制台">
    登录贵组织的 [Google 管理控制台](https://admin.google.com)。
  </Step>

  <Step title="进入 API 控制">
    前往 **Security &gt; Access and data control &gt; API controls**。
  </Step>

  <Step title="打开第三方应用访问权限">
    在 **App access control** 下选择 **Manage third-party app access**。
  </Step>

  <Step title="添加新应用">
    选择 **Add app** 按钮，然后从下拉菜单中选择 **OAuth App Name or Client ID**。
  </Step>

  <Step title="搜索 Replit">
    输入 Replit 的 Client ID：

    ```
    1012035106355-2dhot2e6o0malvog2ofss7akj2nsp8nq.apps.googleusercontent.com
    ```

    选择 **Search**。当搜索结果中出现 Replit 应用时，选择该应用。
  </Step>

  <Step title="设置访问级别">
    将访问级别设置为 **Trusted**。
  </Step>

  <Step title="保存">
    选择 **Save**。
  </Step>
</Steps>

<Tip>
  Google Workspace 策略的更改可能需要几分钟才能生效。保存后请等待 5～10 分钟，再在 Replit 中重新尝试连接 Google 服务。
</Tip>

<div id="section-3">
  ## 仍然被阻止时
</div>

如果三个步骤都已完成，但错误依然存在：

* **重新确认组织部门 (OU)&#x20;**：Google Workspace 策略的作用范围可能按 OU 划分。请确认 OAuth 和受信任应用的设置已应用到需要连接的用户所在的 OU。
* **查看 Google Workspace 提醒**：在管理控制台中查看 **Reporting &gt; Audit and investigation &gt; OAuth log events**，确认是否有与 Replit 相关的被拒绝请求。
* **联系 Replit 支持团队**：如果问题不在 Google Workspace 一侧，请联系 [Replit 支持团队](https://replit.com/support)。
