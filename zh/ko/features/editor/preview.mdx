Preview 会显示 Web 应用的输出，并提供浏览器开发者工具和调试功能。

点击 **Run** 按钮运行 Web 应用后，Replit 会分配一个可从互联网访问的临时 URL。Preview 工具会以与浏览器中完全相同的效果渲染页面，并内置了与常见浏览器类似的开发者工具。

<Note>
  Preview 是 Webview 的新名称。
</Note>

<div id="section">
  ## 功能
</div>

Preview 提供以下功能，帮助你轻松测试和调试 Web 应用。

* **实时网页预览**：无需离开浏览器标签页即可查看应用并与之交互
* **开发者工具**：借助内置工具快速定位问题
* **响应式测试**：在各种移动设备屏幕尺寸下查看应用

<div id="section-2">
  ## 使用方法
</div>

运行 Web 应用时，Preview 工具会自动打开。
你可以在 **用户设置** 工具的 **Automatic Preview** 设置中开启或关闭该行为。

以下说明介绍了打开 Preview 的方法。

<Accordion title="访问 Preview 的方法">
  在左侧的**工具栏**中：

  1. 选择 <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="All tools icon" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**，查看 Project Editor 工具列表。
  2. 选择 <img class="icon-svg" src="/assets/mirror/preview-icon-6d37238e8cc2.svg" alt="Preview icon" width="16" height="16" data-path="images/icons/preview-icon.svg" /> **Preview**。

  在**搜索栏**中：

  1. 选择顶部的 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="magnifying glass icon" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 放大镜，打开搜索工具
  2. 输入“Preview”查找该工具，并在搜索结果中选择它。
</Accordion>

<div id="section-3">
  ## 地址栏
</div>

**Preview** 标签页顶部的地址栏包含以下工具：

* **后退按钮**：返回浏览记录中的上一个页面
* **前进按钮**：前进到浏览记录中的下一个页面
* **应用域名**：点击 `{...}.replit.dev` 查看 Replit App 的临时 URL 信息
* **地址输入框**：查看当前 URL 路径或输入新路径

<div id="section-4">
  ## 浏览器工具
</div>

地址栏右侧的浏览器工具包含以下功能：

* **屏幕尺寸**：选择不同设备的屏幕尺寸预设，测试响应式设计
* **Devtools**：显示或隐藏[开发者工具](#Developer_tools)面板
* **新标签页**：在新的浏览器标签页中打开 Web 应用 URL

<Note>
  **正在构建移动应用？** Preview 面板还支持在 **iOS 模拟器**或 **Android 模拟器**中预览。详情请参阅 [Native Mobile Apps](/zh/ko/features/artifact-types/building-mobile-apps#preview-on-a-simulator-or-emulator)。
</Note>

<div id="section-5">
  ## 开发者工具
</div>

开发者工具由 <a href="https://github.com/liriliri/eruda" target="_blank">Eruda</a> 开源项目提供支持，可帮助你完成以下操作：

* 在应用上下文中查看 JavaScript 控制台并与之交互
* 检查 DOM 元素
* 监控网络请求
* 配置显示与行为偏好设置

要使用开发者工具，请选择 **Preview** 标签页顶部的 <img class="icon-svg" src="/assets/mirror/wrench-7cee9d1168da.svg" alt="扳手图标" width="16" height="16" data-path="images/icons/wrench.svg" /> **Devtools**
按钮，即可开启或关闭。

以下各节将介绍你在每个开发者工具标签页中可以执行的操作。

<div id="console">
  ### 控制台
</div>

**控制台**标签页显示应用生成的 JavaScript 日志。
在此标签页中，你可以执行以下操作：

* **清除输出**：选择 <img class="icon-svg" src="/assets/mirror/clear-bd1bf1847597.svg" height="16" width="16" alt="clear icon" data-path="images/icons/clear.svg" /> 带斜线的圆形图标，清除所有控制台输出。
* **筛选输出**：按类型 (All、Info、Warning、Error) 查看筛选后的控制台输出。
* **按文本筛选**：选择 <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="filter icon" data-path="images/icons/filter.svg" /> 筛选器图标并输入文本，查看匹配的输出。
* **复制输出**：选择 <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="copy icon" data-path="images/icons/copy.svg" /> 复制按钮，复制选中的控制台消息。
* **运行 JavaScript 代码**：选择 <img class="icon-svg" src="/assets/mirror/arrow-right-2859a6e6bdeb.svg" height="16" width="16" alt="right arrow icon" data-path="images/icons/arrow-right.svg" /> 右向箭头，在应用上下文中运行 JavaScript 代码。输入表达式，然后选择 **Execute**。

<div id="elements">
  ### Elements
</div>

在 **Elements** 标签页中，您可以检查并修改网页的 DOM 结构。

* **查看元素详情**：查看 DOM 元素及其在 HTML 代码中所处位置的详细信息
* **复制输出**：点击 <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="copy icon" data-path="images/icons/copy.svg" /> 复制按钮，即可复制选中的控制台消息。

使用 <img class="icon-svg" src="/assets/mirror/select-1165d9548c39.svg" height="16" width="16" alt="select icon" data-path="images/icons/select.svg" /> 箭头选择工具可切换到选择模式。
进入选择模式后，在网页中选中某个元素。
该元素的 HTML 和 CSS 便会显示在 Elements 标签页中。

<div id="network">
  ### Network
</div>

**Network** 标签页用于监控网页发起的请求。
在该标签页中，你可以执行以下操作：

* **跟踪请求**：查看应用发起的所有网络请求。选择某个请求即可查看详细信息。
* **筛选**：选择 <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="筛选器图标" data-path="images/icons/filter.svg" /> 筛选器图标，仅显示与文本匹配的结果。清空筛选器即可重置。
* **复制**：选择 <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="复制图标" data-path="images/icons/copy.svg" /> 复制按钮，复制存储信息。

<div id="resources">
  ### Resources
</div>

**Resources** 标签页会显示页面加载的资源，以及 Cookie、本地存储等浏览器存储内容。
你可以查看并刷新以下资源类型的列表：

* JavaScript 文件
* 样式表
* Iframe
* 图片

在此标签页中，你可以执行以下操作：

* **查看存储**：检查本地存储、会话存储和 Cookie。
* **筛选**：选择 <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="filter icon" data-path="images/icons/filter.svg" /> 筛选器图标，查看与文本匹配的结果。清空筛选器即可重置。
* **清除**：选择 <img class="icon-svg" src="/assets/mirror/clear-bd1bf1847597.svg" height="16" width="16" alt="clear icon" data-path="images/icons/clear.svg" /> 清除按钮，删除该存储类型下的所有数据。
* **删除所选项**：选择 <img class="icon-svg" src="/assets/mirror/delete-a21eb49cac3c.svg" height="16" width="16" alt="delete icon" data-path="images/icons/delete.svg" /> “X” 图标，移除存储项。
* **复制**：选择 <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="copy icon" data-path="images/icons/copy.svg" /> 复制按钮，复制存储信息。

<div id="settings">
  ### Settings
</div>

在 **Settings** 标签页中，你可以自定义开发者工具的外观和行为。
该标签页包含以下自定义选项：

* **工具设置**：自定义应用于各个工具标签页的选项
* **JavaScript 控制**：指定 JavaScript 的行为选项，例如将其关闭，以测试应用在没有 JavaScript 时的表现
* **显示偏好设置**：更改开发者工具的主题、面板大小、透明度以及其他行为
