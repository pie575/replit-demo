Replit Design vous permet de façonner l’apparence et l’expérience de votre logiciel. Décrivez ce que vous souhaitez et Replit Design génère des maquettes interactives que vous pouvez explorer et affiner. Lorsqu’une maquette vous convient, elle devient une application fonctionnelle dans le même projet.

<div id="start-fresh-or-import-existing-designs">
  ## Partir de zéro ou importer des designs existants
</div>

Accédez à [Replit Design](https://replit.com/design) ou sélectionnez **Design** sous le champ de création, sur la page d’accueil de votre workspace. Quatre possibilités :

* **[Prompt](/fr/design/design-your-first-screen)** : décrivez ce que vous souhaitez et générez vos premiers frames.
* **[Templates](/fr/design/start-from-a-template)** : partez d’une page de destination, d’une affiche, d’une publication sur les réseaux sociaux, d’un écran mobile ou d’un prototype prédéfini, puis personnalisez-le.
* **[Import](/fr/design/import-figma-designs-into-replit-design)** : importez un design depuis Figma ou [Claude](/fr/design/import-claude-designs-into-replit-design), ou recréez un site [à partir de son URL](/fr/design/import-a-website-into-replit-design) ou d’une capture d’écran.
* **[Système de design](/fr/design/design-systems-explained)** : partez d’un système enregistré afin que votre premier frame respecte déjà votre identité de marque.

<div id="explore-variants">
  ## Explorer des variantes
</div>

Explorez différentes pistes avant de vous décider. Chaque résultat apparaît dans un nouveau frame, vous ne perdez donc jamais une direction.

* **[Suggestions](/fr/design/explore-suggestions)** : sélectionnez un frame et Replit Design vous propose des pistes à essayer, chacune en un clic.
* **[Un autre modèle](/fr/design/explore-with-different-models)** : changez le modèle qui alimente Design et envoyez-lui le même brief pour obtenir une direction vraiment différente.

<div id="refine">
  ## Affiner
</div>

Donnez forme au résultat final comme bon vous semble :

* **[Chat](/fr/design/chat-about-your-design)** : expliquez à Agent avec vos propres mots ce que vous souhaitez, pour l’ensemble du tableau ou une frame à la fois.
* **[Visual Editor](/fr/design/visual-editor)** : cliquez sur n’importe quel élément et ajustez directement le texte, les couleurs, l’espacement et les images. Les modifications simples s’appliquent instantanément au code source, sans consommer de crédits.
* **[Draw](/fr/design/toolbar#draw)** : entourez les problèmes, tracez une flèche vers l’élément concerné, laissez une note autocollante. Agent lit vos annotations.
* **[Generate assets](/fr/design/toolbar#generate)** : créez les images, clips vidéo et graphiques vectoriels dont votre design a besoin, en joignant des références pour qu’ils correspondent au style de votre projet.

<div id="build">
  ## Build
</div>

Lorsqu’un frame est prêt, confiez-le à Agent. Ici, un design n’est jamais une simple image : c’est la spécification d’un véritable logiciel.

* **[Build votre design](/fr/design/build-your-design)** : transformez le frame en une nouvelle app fonctionnelle.
* **[Restyler une app existante](/fr/design/frames#build)** : appliquez l’apparence du frame à une app existante.

<Frame caption="L’action Build dans la barre d’actions d’un frame sélectionné.">
  <img src="/assets/mirror/build-design-c5093018b02b.png" alt="La barre d’actions d’un frame sélectionné, avec les actions Build et Focus" width="1124" height="326" data-path="images/design/replit-design/build-design.png" />

</Note>

<div id="scale">
  ## Monter en puissance
</div>

Accélérez la création de votre prochain design :

* **[Créez un système de design](/fr/design/create-a-design-system)** : extrayez les couleurs, la typographie, les jetons et les composants d’un design qui vous plaît, ou créez-en un de zéro à l’aide d’un prompt.
* **Démarrez de nouveaux travaux à partir de celui-ci** : les nouveaux artifacts respectent votre identité de marque dès le premier frame.
* **[Intégrez vos applications existantes au système](/fr/design/apply-design-system)** : refaites le style des applications que vous avez déjà pour que tout soit cohérent.
* **Changez de système** : choisissez ou modifiez le système pour chaque projet.

À partir de là, le parcours revient à **Démarrer**, et chaque design respecte désormais votre identité de marque dès le départ.

<div id="when-to-start-in-design-vs-build">
  ## Quand commencer dans Design ou Build
</div>

Design et Build sont deux points d’entrée vers le même projet. Build est l’endroit où Agent donne vie à votre logiciel ; Design est l’endroit où vous en façonnez l’apparence. Vos créations ne restent jamais cantonnées à un outil de conception.

* Commencez dans **Design** lorsque l’apparence constitue le principal défi : explorez d’abord différentes pistes, puis développez celle que vous retenez.
* Commencez dans **Build** lorsque le comportement constitue le principal défi : faites-le fonctionner, puis retravaillez son style dans Replit Design.
