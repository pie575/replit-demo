Les designs créés dans Claude montrent à quoi l’expérience doit ressembler. Avec l’option **Send to Replit** de Claude, vous pouvez transmettre ce design à Replit, où il est importé en tant que projet et transformé par Agent en application interactive fonctionnelle.

<Note>
  Il s’agit d’une nouvelle intégration. **Send to Replit** apparaît dans le menu **Send to…** de Claude uniquement lorsque Claude propose Replit comme destination d’envoi d’un design. Sa disponibilité est contrôlée par Claude et il est possible que cette option ne soit pas encore proposée à tous les comptes. Lorsque vous acceptez le transfert, Claude demande les portées **Access apps**, **Create and manage apps** et **Stay signed in to this application** sur l’écran de consentement de Replit.
</Note>

<div id="section">
  ## Comment ça fonctionne
</div>

Le transfert commence dans Claude et se termine dans Replit.

1. Créez un design autonome dans le canevas de conception de Claude.
2. Envoyez le design à Replit depuis le menu **Share → Send to…** de Claude.
3. Autorisez Claude à accéder à votre compte Replit et sélectionnez un espace de travail.
4. Replit crée un projet à partir du design sous la forme d’un fichier `index.html` statique.
5. Agent prend en charge la tâche **Turn this Claude design into a real app** et transforme le design en application interactive.

Il s’agit d’un flux dans lequel Claude *envoie* un design à Replit via une connexion d’application autorisée. Vous n’avez rien à configurer au préalable dans Replit — le flux commence dans Claude.

<div id="section-2">
  ## Avant de commencer
</div>

Vous aurez besoin des éléments suivants :

* Un [compte Replit](https://replit.com).
* Un compte Claude avec un design dans le canevas de conception Claude.
* Un espace de travail Replit dans lequel créer votre nouveau projet.

<div id="claudereplit">
  ## Envoyer un design de Claude vers Replit
</div>

Dans Claude, ouvrez le design que vous souhaitez transformer en application.

<Steps>
  <Step title="Ouvrir le design dans Claude">
    Dans Claude, ouvrez le design que vous souhaitez transformer en application.
  </Step>

  <Step title="Ouvrir le menu Send to">
    Sélectionnez **Share**, puis ouvrez le menu **Send to…**. Replit apparaît comme destination.

    <Frame>
      <img src="/assets/mirror/claude-send-to-menu-d4353906aea3.png" alt="Menu Send to… de Claude affichant Replit comme destination à côté de Claude Code" width="2000" height="1143" data-path="images/claude-to-app/claude-send-to-menu.png" />
    </Frame>
  </Step>

  <Step title="Sélectionner Replit">
    Sélectionnez **Replit** pour lancer le transfert vers votre compte Replit.
  </Step>

  <Step title="Autoriser l’accès à Replit">
    Sur l’écran de consentement Replit intitulé **Claude would like to access your Replit account**, vérifiez les accès demandés par Claude — **Access apps**, **Create and manage apps**, **Stay signed in to this application** — puis autorisez la connexion.

    <Frame>
      <img src="/assets/mirror/replit-oidc-consent-76dfc4d92a2f.png" alt="Écran de consentement Replit intitulé « Claude would like to access your Replit account ». Les portées Access apps, Create and manage apps, Stay signed in et le sélecteur d’espace de travail sont affichés." width="2000" height="1143" data-path="images/claude-to-app/replit-oidc-consent.png" />
    </Frame>
  </Step>

  <Step title="Sélectionner un espace de travail">
    Choisissez et confirmez l’espace de travail Replit dans lequel vous souhaitez créer le nouveau projet.
  </Step>
</Steps>

Après confirmation, Replit crée un projet à partir du design et l’ouvre dans cet espace de travail.

<div id="section-3">
  ## Éléments importés
</div>

Replit importe le design sous la forme d’un unique fichier `index.html` autonome. L’importation préserve la mise en page visuelle, les styles et les ressources inclus par Claude dans le design.

L’importation fournit un point de départ fonctionnel. Le design étant fourni sous forme de HTML statique, vous devrez y ajouter des fonctionnalités, des données et de l’interactivité après l’importation.

<div id="section-4">
  ## Éléments non importés
</div>

Le transfert comprend le design, mais pas une application complète. Les éléments suivants ne sont pas inclus dans l’importation.

* La logique backend et les fonctionnalités côté serveur.
* Les bases de données et les données enregistrées.
* Les fonctionnalités interactives, telles que les formulaires fonctionnels, les états et la navigation.

Agent ajoute ces fonctionnalités lorsqu’il transforme le design en véritable application.

<div id="agent">
  ## Rendre un design interactif avec Agent
</div>

Après l’importation, Agent lance la tâche **Transformer ce design Claude en véritable application** dans l’espace de travail. Agent s’appuie sur le design statique pour créer les comportements interactifs qu’il suggère.

<Frame caption="Le design Velocity reçu de Claude est devenu un frame dans Replit Design une fois l’exécution d’Agent terminée.">
  <img src="/assets/mirror/claude-design-in-replit-design-ff81b055b1f5.webp" alt="Le design de location de voitures de luxe Velocity envoyé depuis Claude est ouvert en tant que frame de design Claude dans Replit Design, avec la fin de la tâche d’Agent affichée dans le panneau de discussion" width="1600" height="1004" data-path="images/claude-to-app/claude-design-in-replit-design.webp" />

Une fois la tâche terminée, ouvrez Preview pour tester le résultat. Comparez l’application en cours d’exécution au design Claude d’origine et vérifiez les points suivants :

* La mise en page et le style sont suffisamment fidèles au design.
* Les boutons, formulaires et éléments de navigation fonctionnent comme prévu.
* L’application fonctionne toujours après actualisation.

Si des éléments manquent ou sont mal alignés, décrivez les modifications à Agent afin qu’il améliore l’application.

<div id="section-5">
  ## Tarification
</div>

L’utilisation d’Agent pour transformer un design en application fonctionnelle peut consommer des crédits. Le nombre de crédits consommés dépend de l’ampleur des modifications apportées par Agent au design importé.
