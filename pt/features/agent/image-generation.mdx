A geração de imagens capacita os construtores a criar conteúdo visual único sem precisar de habilidades de design ou ferramentas externas. Gere tudo, desde ícones e ilustrações até fundos e elementos de UI diretamente no seu fluxo de trabalho de desenvolvimento.

## Recursos

Construa aplicativos visualmente atraentes com a geração de imagens do Agent. Isso elimina a necessidade de fotos de banco de imagens, ferramentas de design externas ou contratação de designers para conteúdo visual básico. Seja criando um site de portfólio, construindo um jogo ou projetando uma interface de aplicativo móvel, a geração de imagens fornece visuais personalizados adaptados ao seu projeto.

O Agent pode realizar as seguintes ações de geração de imagens:

* **Criação de imagens personalizadas**: Gere imagens com base em descrições e especificações detalhadas
* **Adaptação de estilo**: Crie imagens em vários estilos artísticos, do realista ao cartoon
* **Fundos transparentes**: Gere imagens como PNGs transparentes ou remova o fundo de uma imagem existente — ideal para logos, ícones, adesivos e recortes de produtos
* **Integração ao projeto**: Adicione imagens geradas diretamente ao codebase do seu aplicativo de forma fluida
* **Refinamento iterativo**: Modifique e melhore imagens com base no seu feedback

## Uso

A geração de imagens está integrada ao Agent — não há nada para ativar. Abra qualquer Replit App com o Agent habilitado e peça ao Agent para criar o conteúdo visual que você precisa. O Agent determina automaticamente quando gerar imagens com base nas suas solicitações, criando imagens personalizadas que correspondem às suas especificações.

### Quando o Agent usa a geração de imagens

O Agent aciona a geração de imagens quando você solicita conteúdo visual para seus projetos:

| Caso de uso                       | Exemplo de prompt                                                             |
| --------------------------------- | ----------------------------------------------------------------------------- |
| **Ícones e logos de aplicativos** | "Gere um logo moderno para meu aplicativo de rastreamento de fitness"         |
| **Fundos de sites**               | "Crie um fundo de gradiente sutil para meu site de portfólio"                 |
| **Assets de jogos**               | "Gere sprites pixel art para meu jogo de plataforma"                          |
| **Ilustrações de UI**             | "Crie uma ilustração para a tela de estado vazio do meu aplicativo"           |
| **Visuais de marketing**          | "Gere uma imagem hero para minha landing page"                                |
| **Mockups de produtos**           | "Crie imagens de mockup do meu aplicativo rodando em diferentes dispositivos" |
| **Logos e ícones transparentes**  | "Gere um logo para meu aplicativo com fundo transparente"                     |

### Melhores práticas para geração de imagens

Siga estas diretrizes para obter os melhores resultados da geração de imagens do Agent:

**Seja específico e descritivo**

* Inclua detalhes sobre estilo, cores, composição e atmosfera
* Especifique dimensões ou proporções quando relevante
* Mencione o uso pretendido (ícone, fundo, ilustração, etc.)
* Peça um fundo transparente quando precisar que um logo, ícone, adesivo ou recorte fique sobre outros conteúdos

**Itere e refine**

* Comece com uma descrição básica e refine com base nos resultados
* Peça ao Agent para modificar aspectos específicos das imagens geradas
* Solicite variações para explorar diferentes direções criativas

**Considere o estilo do seu projeto**

* Mantenha consistência visual em todo o aplicativo
* Especifique preferências de estilo que correspondam à sua marca ou sistema de design
* Peça imagens que complementem seus elementos visuais existentes

### Integração ao projeto

O Agent integra de forma fluida as imagens geradas ao seu codebase:

* **Criação automática de arquivos**: As imagens geradas são salvas diretamente nos arquivos do projeto
* **Atualizações de código**: O Agent atualiza seu código para referenciar os novos arquivos de imagem
* **Organização de assets**: As imagens são colocadas em diretórios lógicos dentro da estrutura do projeto

Este fluxo de trabalho simplificado significa que você pode gerar e implementar conteúdo visual sem sair do seu ambiente de desenvolvimento.

<Note>
  A geração de imagens do Replit é alimentada pelo [Imagen 4 do Google](https://deepmind.google/models/imagen/), um modelo de texto para imagem de última geração que se destaca na criação de imagens de alta qualidade e fotorrealistas com detalhes finos e capacidades aprimoradas de renderização de texto.
</Note>
