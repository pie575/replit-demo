<div id="section">
  ## Зачем использовать интеграции?
</div>

Интеграции позволяют перенести в Replit информацию из инструментов, которыми вы уже пользуетесь.
После подключения сервиса в рамках одного разговора можно попросить Replit найти нужный
контекст, ответить на вопросы или помочь выполнить задачи.

При запуске кофейни Google Drive можно использовать для хранения заметок о бюджете, исследований
локаций, идей для меню и визуальных референсов. Для документирования развивающегося
плана можно использовать Notion. Давайте сначала разберёмся, как работает подключение
интеграций.

<div id="section-2">
  ## Подключение интеграций
</div>

Replit поддерживает коннекторы для коммуникаций, электронной почты, календарей, файлов, клиентских записей,
управления проектами и других задач. В каталоге коннекторов рабочего пространства
отображаются коннекторы, доступные в вашем плане.

<div id="section-3">
  ### Подключение интеграций
</div>

<Steps>
  <Step title="Откройте Integrations">

Подключённые сервисы действуют в рамках разрешений учётной записи, используемой для входа.
Replit может получать доступ только к информации, доступной этой учётной записи.
