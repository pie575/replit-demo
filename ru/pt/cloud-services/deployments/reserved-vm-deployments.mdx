---

Развёртывание Reserved VM работает на виртуальной машине (VM), которая выделяет вычислительные ресурсы исключительно
для вашего приложения. Такой тип развёртывания обеспечивает предсказуемые расходы и стабильную производительность без перебоев.

Он идеально подходит для следующих сценариев:

* Фоновые задачи, требующие большого объёма памяти
* Чат-боты, которые должны постоянно оставаться на связи
* Постоянно доступные API-серверы

<div id="recursos">
  ## Возможности
</div>

Развёртывания Reserved VM предоставляют следующие возможности:

* **Выделенные ресурсы**: стабильная производительность приложения на зарезервированных вычислительных ресурсах.
* **Пользовательские домены**: настройте пользовательский домен или используйте URL вида `<имя-приложения>.replit.app` для доступа к приложению.
* **Варианты вычислительных ресурсов**: выберите конфигурацию виртуальной машины, которая отвечает требованиям вашего приложения к производительности.
* **Настраиваемые сопоставления портов**: укажите, какие порты приложение открывает в интернет.
* **Мониторинг**: просматривайте логи и отслеживайте состояние опубликованного приложения.

<div id="uso">
  ## Использование
</div>

Доступ к Reserved VM Deployments можно получить через инструмент Publishing в Project Editor.

<Accordion title="Как открыть Reserved VM Deployments">
  В **Tool dock** слева:

  1. Выберите <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="All tools icon" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**, чтобы увидеть список инструментов Project Editor.
  2. Выберите <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Publishing icon" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publishing**.
  3. Выберите вариант **Reserved VM**, а затем — **Set up your published app**.

  Через **строку поиска**:

  1. Нажмите на <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="magnifying glass icon" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> лупу вверху, чтобы открыть инструмент поиска
  2. Введите «Publishing», чтобы найти инструмент, и выберите его в результатах.
  3. Выберите вариант **Reserved VM**, а затем — **Set up your published app**.
</Accordion>

<div id="configurao-da-mquina">
  ### Конфигурация машины
</div>

Выберите конфигурацию CPU и RAM для машины, на которой размещается ваш развёртывание. Стоимость выбранного варианта отображается рядом с размером машины.

<div id="domnio-principal">
  ### Основной домен
</div>

Укажите поддомен в имени хоста для вашего опубликованного приложения. После публикации приложение будет доступно по адресу `https://<subdomain>.replit.app`.

О том, как использовать собственный домен, см. [Custom Domains](/ru/features/publishing/custom-domains).

<div id="deployment-privado">
  ### Приватный развёртывание
</div>

<Info>
  Функция приватной публикации приложения доступна на тарифах Pro и Enterprise.
</Info>

Приватные опубликованные приложения открывают доступ к приложению только участникам вашего workspace либо отдельным пользователям и группам, которых вы пригласите.
При публикации можно выбрать один из вариантов доступа: **Public**, **Password protected**, **Workspace only** или **Invite only**.

О том, как настроить приватный развёртывание, читайте в разделе [Доступ к приложению](/ru/features/publishing/private-deployments/).

<div id="build-command">
  ### Build command
</div>

В поле **Build command** введите команду Shell, которая собирает или настраивает ваш App перед выполнением Run command.
Например, чтобы оптимизировать JavaScript-App для продакшен-среды с помощью Vite, можно добавить команду `vite build`.

<div id="run-command">
  ### Run command
</div>

В поле **Run command** введите команду Shell, которая запускает вашу задачу. Эта команда должна быть похожа на ту, которую вы используете в своём рабочем процессе. Например, чтобы запустить приложение Flask с именем «myApp», можно добавить команду `flask --app myApp run`.

<div id="secrets-do-app-publicado">
  ### Secrets опубликованного приложения
</div>

Нажмите **Add published app secret**, чтобы добавить переменные окружения или secrets, необходимые вашему приложению для безопасной работы.

Если в вашем Replit App заданы переменные окружения или secrets, инструмент Publishing добавит их в список автоматически.

<div id="opes-de-tipo-de-app">
  ### Варианты типа App
</div>

Выберите один из следующих вариантов:

* **Web server**: Выберите этот вариант при публикации веб-приложения или приложения, к которому пользователи могут подключаться через интернет.
* **Background worker**: Выберите этот вариант, если ваше приложение не прослушивает порт и не запускает сервер.

Выбрав **Web Server**, вы можете указать, какие порты сделать доступными извне, выполнив следующие действия:

1. Разверните раздел **Port configuration**.
2. Выберите **Networking pane to configure**, чтобы открыть вкладку **Networking**, где можно управлять сопоставлениями портов.

Дополнительные сведения о конфигурации портов см. в разделе [Порты](/ru/pt/core-concepts/project-editor/app-setup/ports/).
