Контроль версий в Replit позволяет уверенно отслеживать изменения в коде, управлять им и работать над ним совместно. Благодаря встроенной интеграции с Git и подключению к GitHub вы можете:

* Отслеживать изменения в коде и вести историю своей разработки
* Работать вместе с участниками команды без конфликтов в коде и потери результатов
* Импортировать, изменять и передавать код между Replit и GitHub
* Работать с ветками, чтобы безопасно экспериментировать с новыми функциями

<div id="o-que-controle-de-verso">
  ## Что такое контроль версий?
</div>

Контроль версий — это система, которая отслеживает изменения в файлах во времени и позволяет впоследствии восстановить нужную версию. В Replit контроль версий построен на Git — отраслевом стандарте для отслеживания изменений в коде — и дополнен удобным визуальным интерфейсом, благодаря которому знание командной строки не требуется.

<div id="como-o-controle-de-verso-funciona-no-replit">
  ### Как работает контроль версий в Replit
</div>

Все четыре варианта контроля версий работают с одним и тем же базовым репозиторием Git:

1. **Agent Checkpoints** автоматически создают коммиты на ключевых этапах работы с [Replit Agent](/ru/pt/core-concepts/agent). [Подробнее о checkpoint и откатах](/ru/pt/core-concepts/agent/checkpoints-and-rollbacks).
2. **Git Pane** обеспечивает визуальный доступ ко всему репозиторию Git
3. **Git CLI** предоставляет доступ ко всем возможностям Git из командной строки
4. **File History** отслеживает мельчайшие изменения в отдельных файлах

Выберите интерфейс, который лучше всего отвечает вашим задачам, — в основе всех них лежит надёжная система контроля версий Git.

| Возможность                | Agent Checkpoints                    | Git Commits                         | File History                       |
| -------------------------- | ------------------------------------ | ----------------------------------- | ---------------------------------- |
| **Создание**               | Автоматически в логических точках    | Вручную или по расписанию           | Автоматически                      |
| **Детализация**            | Изменения на уровне функциональности | Изменения любого объёма             | Изменения на уровне символов       |
| **Описание**               | Сводки, созданные ИИ                 | Сообщения, написанные пользователем | Автоматические метки времени       |
| **Откат**                  | Восстановление в один клик           | Требуется знание Git                | Восстановление в один клик         |
| **Возможности Git**        | Полные возможности Git               | Полные возможности Git              | Возможности Git отсутствуют        |
| **Синхронизация с GitHub** | Полная синхронизация с GitHub        | Полная синхронизация с GitHub       | Синхронизация с GitHub отсутствует |

<div id="primeiros-passos">
  ## Первые шаги
</div>

Чтобы работать с контролем версий в своём Replit App, добавьте инструмент Git в Project Editor:

1. Перейдите в раздел Tools в своём Replit App
2. Нажмите на значок **+**, чтобы добавить новые инструменты
3. Выберите **Git** в списке доступных инструментов

Об импорте существующих проектов из GitHub см. [Импорт из GitHub](/ru/pt/getting-started/quickstarts/import-from-github).

<div id="controle-de-verso-automtico">
  ### Автоматический контроль версий
</div>

<Accordion title="Agent Checkpoints">
  Автоматические снимки, создаваемые в ходе разработки с помощью ИИ через [Replit Agent](/ru/pt/core-concepts/agent).

  **Лучше всего подходит для**: разработки с Replit Agent

  **Ключевые возможности**:

  * Автоматическое создание на логических этапах
  * Откат в один клик
  * Снимки на уровне отдельных функций
  * Отслеживание прогресса
  * Не требует настройки
  * Наглядная временная шкала хода разработки

  Checkpoint&#39;ы Agent хранятся в Git, и к ним можно обратиться через Git Pane или Git CLI. Кроме того, все checkpoint&#39;ы можно просмотреть с помощью функции History, которая предоставляет:

  * Хронологический список checkpoint&#39;ов
  * Подробные описания checkpoint&#39;ов
  * Прямой доступ к состояниям checkpoint&#39;ов
  * Откат в один клик к любому checkpoint
</Accordion>

<Accordion title="File History">
  Отслеживание версий каждого файла с автосохранением изменений, внесённых непосредственно в редакторе (а не через Agent).

  **Лучше всего подходит для**: быстрого восстановления недавних изменений в файлах

  **Ключевые возможности**:

  * Работа с одним файлом
  * Изменения на уровне символов
  * Наглядное сравнение
  * История за 30 дней
  * Функция воспроизведения

  Хотя у File History собственный интерфейс, сами изменения являются частью истории Git. Подробнее о [File History](/ru/pt/core-concepts/project-editor/version-control/file-history).
</Accordion>

<div id="interfaces-baseadas-em-git">
  ### Интерфейсы на основе Git
</div>

<Accordion title="Git Pane">
  Визуальный интерфейс для операций Git, который делает контроль версий доступным без знания командной строки.

  **Лучше всего подходит для**: большинства проектов, которым нужна интеграция с GitHub и визуальный рабочий процесс

  **Ключевые возможности**:

  * Отслеживание на уровне репозитория
  * Управление ветками
  * Просмотр различий
  * Синхронизация с GitHub в один клик
  * Совместная работа в команде

  Подробные инструкции по работе с Git Pane см. в разделе [Использование Git Pane](/ru/pt/core-concepts/project-editor/version-control/git-interface).
</Accordion>

<Accordion title="Git CLI">
  Полный доступ к Git из командной строки через [Shell](/ru/pt/core-concepts/project-editor/editor-and-tools/shell) для продвинутых операций.

  **Лучше всего подходит для**: опытных пользователей, которым нужны все возможности Git

  **Ключевые возможности**:

  * Полный набор команд Git
  * Продвинутые стратегии ветвления
  * Настраиваемые рабочие процессы
  * Автоматизация с помощью скриптов
  * Полный контроль над репозиторием

  Распространённые команды Git и примеры их использования см. в разделе [Использование Git Pane](/ru/pt/core-concepts/project-editor/version-control/git-interface#using-git-commands-in-shell).
</Accordion>

<div id="principais-recursos">
  ## Основные возможности
</div>

* **Визуальный интерфейс Git**: управляйте репозиториями, коммитами и ветками без ввода команд Git
* **Интеграция с GitHub**: подключайтесь к репозиториям GitHub для резервного копирования и совместной работы
* **Импорт из GitHub**: превратите любой [репозиторий GitHub в Replit App](/ru/pt/getting-started/quickstarts/import-from-github) всего за несколько кликов
* **Управление ветками**: создавайте ветки, переключайтесь между ними и выполняйте слияние прямо в Project Editor
* **Разрешение конфликтов**: находите и устраняйте конфликты слияния с помощью наглядных подсказок

<div id="casos-de-uso">
  ## Сценарии использования
</div>

**Отслеживание личных проектов**

Отслеживайте изменения в коде по мере разработки, чтобы при необходимости вернуться к предыдущим версиям. [Git Pane](/ru/pt/core-concepts/project-editor/version-control/git-interface) наглядно показывает внесённые изменения, благодаря чему проще фиксировать значимые обновления в коммитах.

**Совместная работа в команде**

Работайте над одним и тем же кодом с несколькими разработчиками, не перезаписывая изменения друг друга. Создавайте ветки для новых функций и объединяйте их, когда всё будет готово. Подробнее о том, как [приглашать участников команды](/ru/pt/replitai/invite-teammates).

<div id="checkpoints-do-agent">
  ## Checkpoint&#39;ы Agent
</div>

При создании приложений с помощью [Replit Agent](/ru/pt/core-concepts/agent) вы получаете дополнительный уровень контроля версий — checkpoint&#39;ы. Они автоматически фиксируют полное состояние проекта: его содержимое, контекст беседы с ИИ и подключённые базы данных — в ключевые моменты разработки с участием ИИ.

<div id="como-os-checkpoints-funcionam">
  ### Как работают checkpoint
</div>

Checkpoint в Agent представляют собой полные снимки состояния вашего Replit App:

* **Автоматическое создание**: Agent создаёт checkpoint в логических точках процесса разработки
* **Сохранение полного состояния**: каждый checkpoint фиксирует содержимое проекта, память ИИ и состояние базы данных
* **Планы реализации**: перед внесением изменений Agent показывает план для вашего согласования
* **Отслеживание сложных задач**: для крупных задач может создаваться несколько checkpoint

<div id="benefcios-para-o-desenvolvimento-assistido-por-ia">
  ### Преимущества разработки с помощью ИИ
</div>

Checkpoint&#39;ы Agent дают уникальные преимущества при создании приложений с ИИ:

* **Подстраховка**: экспериментируйте уверенно — вы в любой момент легко вернёте предыдущее состояние всей среды разработки
* **Отслеживание прогресса**: вы видите, как именно Agent создавал ваше приложение, шаг за шагом
* **Логические вехи**: checkpoint&#39;ы соответствуют завершённым функциям, а не произвольным точкам сохранения
* **Мгновенный откат**: вернитесь к любому предыдущему состоянию одним щелчком, включая восстановление базы данных и контекста ИИ

<Info>
  Подробнее о том, что сохраняют checkpoint&#39;ы, и о полных возможностях отката читайте в разделе [Checkpoint&#39;ы и откаты](/ru/pt/core-concepts/agent/checkpoints-and-rollbacks).
</Info>

<Tip>
  Checkpoint&#39;ы Agent — мощный инструмент для разработки с ИИ, но для долгосрочного отслеживания версий и совместной работы стоит использовать коммиты Git, особенно при работе с внешними репозиториями.
</Tip>
