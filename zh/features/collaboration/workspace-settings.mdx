本页帮助你查找 工作区 设置，以及同一「设置」对话框中提供的相关账户和用户
控制项。

<div id="open-settings">
  ## 打开设置
</div>

1. 点击 Replit 左下角的账户菜单。
2. 选择 **Settings**。

<Note>
  可用的选项卡取决于你的 工作区 类型、套餐和角色。仅管理员可用的选项只有在你具备相应管理权限时才会出现。
</Note>

<div id="workspace-settings">
  ## 工作区 设置
</div>

在 **工作区** 部分中管理当前选定的 工作区：

* **工作区 概览**：更新 工作区 的图片或名称，并查看其 ID。
* **工作区 协作者**：邀请成员并管理 工作区 访问权限。
* **集成**：管理已连接到 工作区 的服务和资源。
* **自定义**：为 Agent 配置整个工作区范围内的自定义指令、skills 和记忆。有关设置和权限，请参阅 [Agent 自定义](/zh/features/agent/agent-customization)。
* **设计系统**和**幻灯片模板**：为你的组织管理可复用的设计规范和演示文稿模板。二者均为 Enterprise 功能——请参阅[设计系统](/zh/teams/custom-design-system)和[自定义模板](/zh/teams/custom-templates)。
* **安全**：查看适用于该 工作区 的安全控制措施。请参阅[安全概览](/zh/features/security/overview)。
* **群组**：组织成员并应用群组权限。请参阅[群组与权限](/zh/teams/identity-and-access-management/groups-and-permissions)。

<div id="account-settings">
  ## 账户设置
</div>

在 **Account** 部分中管理可跨 工作区 生效的设置：

* **Usage**、**Billing** 和 **Account seats**：查看使用量和账单信息，并在角色权限允许时管理席位。
* **Advanced**：提供高级账户控制项，包括 Agent 的模型提供方策略。有关 Enterprise 级提供方设置以及各 工作区 的操作流程，请参阅[模型控制](/zh/features/collaboration/enterprise-model-controls)。
* **Developer**：管理 Admin API 密钥并查看请求历史记录。创建或轮换密钥前，请先参阅 [Admin API](/zh/teams/admin-api)。

<div id="user-settings">
  ## 用户设置
</div>

在 **User** (用户) 板块中管理个人的 **Profile** (个人资料) 和 **Personalization** (个性化) 偏好设置。该板块中还有指向 Replit 社区的链接。
