<div id="pro-plan-launch">
  ## Запуск тарифа Pro
</div>

Replit Pro уже доступен, а Core теперь предлагает ещё более выгодные условия. Мы сделали тарифы понятнее и лучше соответствующими разным потребностям:

* **Replit Pro**: Для серьёзных разработчиков — Turbo Mode (Agent работает в 2,5 раза быстрее, включается отдельным переключателем), многоуровневые кредиты с переносом остатка, до 15 разработчиков без платы за место, приоритетная поддержка и в 4 раза более длительное хранение данных. [Подробнее о Pro](/ru/billing/plans/replit-pro).
* **Core**: Приглашайте до 5 участников без дополнительной платы. Актуальные цены Core смотрите на [странице с тарифами](https://replit.com/pricing).
* **Прекращение тарифа Teams**: Teams заменяется на Pro. Существующие клиенты Teams будут переведены на Pro без дополнительной платы до конца текущего периода. Миграция начнётся {TeamsMigrationDate}. [Подробности и таймлайн](https://blog.replit.com/pro-plan).
* **Режимы Agent**: Выберите **Economy** (оптимизирован для снижения затрат) или **Power** (для производительности); **Turbo** — отдельный переключатель (только для Pro/Enterprise, в 2,5 раза быстрее). [Руководство по режимам Agent](/ru/core-concepts/agent/agent-modes).
* **Fast Mode теперь называется Lite Mode**: Те же молниеносные, локальные изменения — название обновлено в продукте и документации. [Режим Lite](/ru/core-concepts/agent/agent-modes).
* **Code Optimizations**: Настройка, определяющая, как Agent проверяет собственный код (ранее Autonomy Level), теперь называется Code Optimizations. [Проверка кода](/ru/features/agent/agent-modes).
* **Совместная работа**: Улучшенная совместная работа на всех платных тарифах — неограниченное число рабочих пространств, упрощённый доступ, единые настройки и отслеживание использования по каждому рабочему пространству. Core: 5 участников; Pro: 15 разработчиков.

<div id="background-memory-compression">
  ### Фоновое сжатие памяти
</div>

Agent больше не приостанавливает ваш рабочий процесс, чтобы оптимизировать свою память. Раньше появлялось сообщение «Память Agent оптимизирована», которое блокировало работу более чем на 30 секунд. Теперь это незаметно происходит в фоновом режиме, поэтому Agent остаётся отзывчивым во время работы.

<div id="production-deployment-logs-access">
  ### Доступ к логам production-развёртываний
</div>

Agent теперь имеет доступ к логам production-развёртываний, что позволяет ему находить и устранять ошибки на основе реальных производственных данных. Вскоре появятся дополнительные улучшения для отладки в production.

<div id="razorpay-mcp-integration">
  ### Интеграция Razorpay MCP
</div>

Интеграция Razorpay MCP теперь доступна, расширяя возможности приема платежей для разработчиков в Индии. Подключите Razorpay к проекту Replit, чтобы принимать платежи, управлять заказами и оформлять возвраты напрямую через Agent.
