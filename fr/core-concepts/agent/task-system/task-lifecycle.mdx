## Brouillon

Un **Brouillon** est une tâche qu'Agent a planifiée mais n'a pas encore commencé à construire. Les Brouillons sont sûrs à réviser car ils ne contiennent que le travail proposé : le titre, la description et le plan de la tâche.

Utilisez les Brouillons pour décider si Agent a bien compris l'objectif. Vous pouvez démarrer la tâche, demander à Agent de réviser le plan, ou archiver le brouillon pour plus tard.

## En cours

Une tâche **En cours** s'exécute en arrière-plan. Agent travaille dessus dans une copie isolée de votre projet, de sorte que votre version principale reste inchangée pendant l'exécution de la tâche.

Vous pouvez continuer à utiliser le fil principal pendant que des tâches En cours s'exécutent. Si une tâche a besoin de retours, ouvrez son fil et poursuivez la conversation là.

## En file d'attente

Une tâche **En file d'attente** est approuvée mais attend de démarrer. Une tâche peut être en file d'attente lorsqu'elle dépend d'une autre tâche, ou lorsque vous avez atteint la limite de tâches actives en arrière-plan de votre plan.

Les tâches en file d'attente démarrent automatiquement lorsque leurs prérequis sont terminés et qu'un emplacement de tâche active se libère.

## Prêt

Une tâche **Prête** est terminée, mais ses modifications n'ont pas encore été appliquées à votre version principale. Révisez le journal de travail de la tâche, les résultats des tests et l'aperçu avant d'appliquer les modifications.

Si le travail semble correct, appliquez-le à la version principale. Si ce n'est pas ce que vous vouliez, ignorez-le et démarrez une nouvelle tâche.

## Application en cours

Une tâche en cours d'**Application** est en train de déplacer ses modifications vers votre version principale. Agent gère automatiquement les conflits lors de l'application des modifications de plusieurs tâches.

Attendez que l'application soit terminée avant de juger le résultat final. Si quelque chose semble incorrect ensuite, demandez à Agent de le corriger dans le fil principal.

## Terminé

Une tâche **Terminée** est achevée et ne nécessite plus d'action. Terminé peut signifier que la tâche a été appliquée à votre version principale, archivée avant de démarrer, ou annulée après être passée en construction.

Utilisez la colonne **Terminé** comme historique du travail terminé, archivé et annulé.

## Archivage et annulation de tâches

Vous pouvez arrêter une tâche à n'importe quel moment de son cycle de vie, mais l'option que vous voyez dépend de l'emplacement de la tâche sur le tableau. **Archiver** et **Annuler** déplacent tous deux une tâche dans la colonne **Terminé**, mais leur comportement est différent :

| Action       | Quand elle est disponible                                                                                                                   | Ce qui se passe                                                                                                          | Réversible ?                                                                                                                 |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| **Archiver** | Lorsque la tâche est encore une session de planification — un **Brouillon** qui n'a pas commencé à construire                               | La session de planification est mise de côté sans être exécutée. Son plan est préservé.                                  | Oui. Ouvrez la carte archivée dans la colonne **Terminé** et restaurez-la dans **Brouillons**.                               |
| **Annuler**  | Après que la tâche ait quitté la planification pour passer à la construction — toute tâche **En cours**, **En file d'attente** ou **Prête** | Agent arrête la tâche et supprime tout travail en cours. Aucune modification n'est appliquée à votre version principale. | Non. Les tâches annulées ne peuvent pas être restaurées. Démarrez une nouvelle tâche si vous souhaitez reprendre le travail. |

Utilisez **Archiver** pour les sessions de planification que vous souhaitez revisiter plus tard. Utilisez **Annuler** comme bouton d'arrêt permanent pour les tâches en file d'attente, déjà en cours d'exécution ou qui ont fini de construire.

Vous pouvez trouver les sessions de planification archivées et les tâches annulées dans la colonne **Terminé** à l'extrême droite du tableau des tâches, à côté des tâches terminées.
