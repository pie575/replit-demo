---
title: "Manipuler vos données"
description: "Depuis l'onglet My Data, parcourez, modifiez, exportez et interrogez votre base de données à l'aide d'outils visuels ou en SQL."
---

L&#39;onglet **My Data** vous permet de consulter et de modifier les données de votre base de données. Ouvrez l&#39;outil **Database**, sélectionnez une base de données, puis choisissez **My Data**. Vous pouvez travailler de façon visuelle ou exécuter directement du SQL.

<Note>
  Pour modifier les données de production, sélectionnez la base de données de production, ouvrez **My Data**, puis activez **Edit**. Soyez prudent : il s&#39;agit des données réelles de votre application en ligne.
</Note>

<div id="section">
  ## Consulter et modifier vos données visuellement
</div>

L&#39;outil Database inclut <a href="https://orm.drizzle.team/drizzle-studio/overview" target="_blank">Drizzle Studio</a>, qui permet de consulter et de modifier vos données visuellement. Ces outils visuels aident à éviter les erreurs de syntaxe et offrent les fonctionnalités suivantes :

* Filtrer et trier les données pour cibler des informations précises
* Exporter les données vers un fichier afin de les utiliser en dehors de la plateforme
* Insérer et modifier les données des lignes
* Créer et gérer des schémas, des tables, des vues et des enums

<div id="sql">
  ## Exécuter des commandes SQL
</div>

Le SQL runner vous permet d&#39;exécuter des commandes SQL sur votre base de données et d&#39;en consulter les résultats.

<Accordion title="Comment accéder au SQL runner">
  Depuis l&#39;outil **Database** :

  1. Sélectionnez l&#39;onglet **My Data**
  2. Sélectionnez <img class="icon-svg" src="/assets/mirror/sql-runner-icon-b25868882922.svg" alt="Icône SQL runner" width="16" height="16" data-path="images/icons/sql-runner-icon.svg" /> **SQL runner**
</Accordion>

Pour exécuter une requête, saisissez votre instruction SQL dans la zone de texte, puis sélectionnez le bouton d&#39;exécution <img class="icon-svg" src="/assets/mirror/sql-play-8ed26b5de7f1.svg" alt="icône exécuter sql" width="18" height="18" data-path="images/icons/sql-play.svg" /> situé juste à côté.

<Frame>
  <img src="/assets/mirror/sql-runner-run-8ad798a61335.jpg" alt="Capture d'écran du SQL runner et du bouton d'exécution" width="1390" height="608" data-path="images/databases/sql-runner-run.jpg" />
</Frame>

<Tip>
  Vous n&#39;avez pas besoin d&#39;écrire le SQL vous-même : demandez à Agent d&#39;interroger ou de modifier vos données, et il se chargera de rédiger et d&#39;exécuter le SQL à votre place.
</Tip>
