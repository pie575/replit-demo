<div id="replit">
  ### Кнопка «Открыть в Replit» (бета)
</div>

Благодаря новой кнопке «Открыть в Replit» теперь можно работать с тикетами Linear прямо в Replit. Эту бета-функцию необходимо включить в настройках окружения; после этого сведения о задаче будут автоматически подставляться в промпт. Команда сотрудничает с Linear над улучшением интеграции.

<div id="agent-sql">
  ### Доступ Agent к продакшн-базе данных SQL
</div>

Теперь Agent может просматривать продакшн-базу данных SQL и выполнять к ней запросы в режиме только для чтения — это позволяет работать с реальными продакшн-данными без риска случайных изменений.

<div id="section-3">
  ### Повышение стабильности подключений
</div>

Несколько улучшений, которые делают работу с интеграциями удобнее:

* Доработанный процесс фонового переподключения снижает вероятность истечения срока действия токенов подключения
* Наглядная индикация, если подключение работает некорректно или находится в состоянии ошибки
* Возможность переподключить интеграцию прямо из состояния ошибки

  ## Команды и Enterprise

<div id="section-5">
  ### Бюджеты на уровне пользователей и групп
</div>

Управление бюджетами теперь доступно всем клиентам Enterprise:

* Администраторы команд Enterprise могут задавать бюджет использования по умолчанию для всех участников
* Администраторы могут задавать бюджеты для отдельных групп (например, для администраторов, участников и пользовательских групп)
* Скоро: администраторы смогут задавать индивидуальные бюджеты, переопределяющие общие настройки, для отдельных пользователей
