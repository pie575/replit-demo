Replit 支持多人同时在同一个 project 中协作。每个人都可以与 Agent 开启新的规划线程，所有人的 task 都会显示在共享看板上——团队可以并行推进，无需轮流操作。

<div id="working-in-parallel">
  ### 并行协作
</div>

每个人都可以创建新线程，因此大家可以各自独立工作，互不打扰。所有人的 task 都会显示在共享的看板上，方便你随时了解谁在做什么，避免重复劳动或相互干扰。

<Note>
  在 Core 方案下，整个 project 同一时间只能运行 1 个后台 task。在 Pro 方案下，最多可并行运行 10 个 task —— 因此多人可以同时让 Agent 构建 project 的不同部分。
</Note>

<div id="what-you-can-build-together">
  ## 你们可以一起构建什么
</div>

* **把一个功能拆给团队分工**：一个人做 frontend，另一个人做 backend，各自在自己与 Agent 的 chat 中进行。看板让所有人步调一致。
* **帮新队友快速上手**：他们可以通过自己的 Agent chat 探索 project、了解各部分的运作方式，并着手贡献代码——完全不会耽误其他人。
* **在 Pro 上更快交付**：借助并行执行，两三个人可以各自派发同时运行的 task。原本一个人要花上一整个工作时段的 project，现在只需很短的时间就能完成。

<div id="frequently-asked-questions">
  ## 常见问题
</div>

<Accordion title="我可以通过 Agent 给队友发消息吗？">
  不可以。Agent 不是聊天工具——它始终在监听，并会尝试执行你输入的任何内容。团队沟通请使用 Slack、Discord 或其他工具。
</Accordion>

<Accordion title="我们会覆盖彼此的工作吗？">
  task 系统会为每个 task 分配独立的副本，从而避免这种情况，同时它也清楚存在哪些其他 task。task 完成后，你需要将其合并回主版本，并在这一步解决可能出现的冲突。
</Accordion>

<Accordion title="我怎样查看队友正在做什么？">
  打开看板即可查看进行中的 task。你还可以看到光标位置以及队友正在查看哪些文件。
</Accordion>

<Accordion title="我可以将某人移出我的 project 吗？">
  可以。Project 所有者可以随时管理团队成员并撤销其访问权限。
</Accordion>
