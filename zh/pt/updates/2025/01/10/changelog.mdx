<div id="integrao-com-slack">
  ### Slack 集成
</div>

Agent 现已集成 Slack API。这意味着你可以使用 Agent 构建这样的应用：

* 发送消息
* 读取历史记录

面向你在 Slack 中所有常用的频道，收发皆可。

<Frame>
  <img src="/assets/mirror/slack-integration-1072c585c41e.png" alt="Slack 集成" width="1640" height="739" data-path="images/changelog/2025-01-10/slack-integration.png" />
</Frame>

将你的作品提交到 [Agent Showcase](https://forms.gle/qxpfr82wNpKsCdok9)。

<div id="melhorias-no-agent-e-no-assistant">
  ### Agent 和 Assistant 改进
</div>

* Agent 在首页的加载速度更快，让你更快开始创建。
* 在 Console 和 Shell 中选中文本时，会弹出一个浮动窗口，方便快速使用 Assistant。只需选中文本并点击 Assistant 图标即可提问。

<Frame>
  <img src="/assets/mirror/ask-assistant-cd529bf4a0b1.png" alt="询问 Assistant" width="2532" height="1474" data-path="images/changelog/2025-01-10/ask-assistant.png" />
</Frame>

<div id="autocompletar-bash-no-shell">
  ### Shell 中的 bash 自动补全
</div>

Shell 现在支持自动补全了！连按两次 Tab 键即可自动补全命令。

<Frame>
  <img src="/assets/mirror/tab-tab-6e4a56285881.webp" alt="Tab tab" width="720" height="405" data-path="images/changelog/2025-01-10/tab-tab.webp" />
</Frame>

<div id="correo-do-ecossistema-elixir">
  ### Elixir 生态系统修复
</div>

Elixir 的 mix 工具相关问题已修复，该语言现已恢复正常使用。

<div id="melhoria-na-ux-de-domnio-personalizado">
  ### 自定义域名体验优化
</div>

现在，你可以直接在自定义域名字段中粘贴 URL，Replit 会自动为你提取域名。

</div>

<div id="controles-aprimorados-de-destaque-de-projeto">
  ### 优化的项目精选控件
</div>

现在，将组织的公开项目设为精选或取消精选变得更加轻松！

<Frame>
  <img src="/assets/mirror/feature-on-profile-95b81a71e0d7.png" alt="个人资料上的精选项目" width="1836" height="644" data-path="images/changelog/2025-01-10/feature-on-profile.png" />
</Frame>

现在，你可以在工作区中通过项目信息弹窗和项目索引表，直接控制项目的精选状态。

<Frame>
  <img src="/assets/mirror/profile-preview-b8f2ecfed154.png" alt="个人资料预览" width="2126" height="1152" data-path="images/changelog/2025-01-10/profile-preview.png" />
</Frame>

此外，将项目设为精选时，你还能预览它在公开个人资料上的显示效果。
