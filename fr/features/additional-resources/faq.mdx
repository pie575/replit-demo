      <Accordion title="Où puis-je obtenir de l'aide sur le code ?">
        Pour obtenir de l&#39;aide sur votre code, le mieux est d&#39;utiliser [Replit AI](/fr/welcome). Dans le Project Editor, ouvrez un nouvel onglet et recherchez **AI**. Replit AI peut vous aider à configurer de nouveaux projets, répondre à vos questions sur votre code et vous accompagner dans votre réflexion. Pour aller plus loin, consultez également notre [Community Hub](https://replit.com/community), qui propose des ressources supplémentaires.
      </Accordion>

      <Accordion title="J'ai des difficultés à utiliser Replit. Comment obtenir de l'aide ?">
        Connectez-vous à Replit et cliquez sur le **?** situé dans le coin supérieur droit de la page pour
        obtenir de l&#39;aide. Pour un accompagnement supplémentaire, consultez le [document sur la politique
        de support](/fr/legal-and-security-info/support-policy).
      </Accordion>

      <Accordion title="Où puis-je obtenir de l'aide concernant la facturation ?">
        Avant de contacter l&#39;équipe d&#39;assistance, regardez si vous trouvez une solution ci-dessous, dans la section **Settings**. Si cela ne suffit pas, connectez-vous et cliquez sur le **?** situé dans le coin supérieur droit de la page pour obtenir de l&#39;aide.
      </Accordion>

      <Accordion title="Je n'arrive pas à accéder à mon compte Replit – que dois-je faire ?">
        Envoyez un e-mail à `support@replit.com` en indiquant le nom d&#39;utilisateur de votre compte et votre identifiant de connexion.
      </Accordion>

      <Accordion title="Quand vais-je recevoir une réponse de Replit ?">
        Le support Replit est généralement disponible du lundi au vendredi, de 9 h à 20 h, heure normale de l&#39;Est (UTC-5).
      </Accordion>

      <Accordion title="Comment restaurer les dossiers de mon Replit App ?">
        Accédez à votre profil, dans le coin supérieur droit de votre Replit App, sélectionnez **CLUI**, puis, dans le champ de recherche qui s&#39;affiche, saisissez *restore*. Dans les résultats, vous verrez l&#39;option **restore-folder**, qui permet de restaurer un dossier précis depuis la corbeille.

        > Remarque : les Replit Apps supprimées sont définitivement effacées et irrécupérables **30 jours** après leur date de suppression initiale.
      </Accordion>

      <Accordion title="Comment restaurer une Replit App supprimée ?">
        Accédez à votre profil, dans le coin supérieur droit de votre Replit App, sélectionnez **CLUI**, puis, dans le champ de recherche qui s&#39;affiche, saisissez *restore*. Dans les résultats, vous verrez l&#39;option **restore-repl**, qui permet de restaurer une Replit App précise depuis la corbeille.

        > Remarque : les Replit Apps supprimées sont définitivement effacées et irrécupérables **30 jours** après leur date de suppression initiale.
      </Accordion>

      <Accordion title="Pourquoi ma Replit App ne se charge-t-elle pas ?">
        Si votre Replit App ne se charge pas, suivez ces étapes de dépannage :

        1. Testez votre [connexion internet](https://www.speedtest.net/).
        2. Essayez un autre navigateur.
        3. Vérifiez que JavaScript est activé dans votre navigateur.
        4. Ouvrez la palette de commandes avec `Cmd+K` (Mac) ou `Ctrl+K` (Windows), recherchez **Restart compute**, puis sélectionnez cette option.

        Si aucune de ces étapes n&#39;a résolu le problème, consultez le [Service Status](https://status.replit.com) de Replit. Si le statut affiché est **All systems are go!** et que votre Replit App ne se charge toujours pas, contactez le [support Replit](https://replit.com/support).
      </Accordion>

      <Accordion title="Comment téléverser un fichier volumineux dans ma Replit App ?">
        Si le fichier est trop volumineux pour un téléversement standard via l&#39;interface graphique, vous pouvez utiliser `scp` (Secure Copy) pour transférer des fichiers en toute sécurité entre un système local et un système distant via [SSH](/fr/features/workspace-tools/ssh). Pour copier des fichiers de votre machine locale vers la machine distante, utilisez cette syntaxe :`scp filename username@ip_address:/home/username`

        Vous pouvez également copier des répertoires entiers avec scp.
      </Accordion>

      <Accordion title="Comment vérifier le solde de mes crédits d'utilisation ?">
        Vous pouvez consulter votre solde actuel sur [https://replit.com/~/cli/account/usage-credits-balance](https://replit.com/~/cli/account/usage-credits-balance).
      </Accordion>

      <Accordion title="Je n'arrive pas à me connecter ; que dois-je faire ?">
        1. Vérifiez que vous utilisez la bonne adresse e-mail et le bon mot de passe.
        2. Pour réinitialiser votre mot de passe, rendez-vous sur la [page de mot de passe oublié](https://replit.com/forgot). Pensez à consulter votre dossier de courrier indésirable pour y trouver l&#39;e-mail de réinitialisation envoyé par `notifications@replit.com`.
        3. Essayez de vous connecter depuis un autre navigateur.

        Si aucune de ces étapes ne fonctionne, veuillez [contacter l&#39;assistance](https://replit.com/support).
      </Accordion>

      <Accordion title="Comment changer mon adresse e-mail si je me suis inscrit avec Google/GitHub/Facebook/Apple ?">
        Un mot de passe est nécessaire pour modifier l&#39;adresse e-mail de votre compte. Si vous vous êtes inscrit via un provider d&#39;authentification tiers tel que Google ou GitHub, vous devez d&#39;abord créer un mot de passe.

        Pour créer un mot de passe :

        1. Ouvrez la barre latérale et déconnectez-vous.
        2. Revenez à la page de connexion, sélectionnez [mot de passe oublié](https://replit.com/forgot) et saisissez votre adresse e-mail.
        3. Vous recevrez un e-mail contenant un lien pour créer un nouveau mot de passe. Si vous ne le voyez pas, consultez votre dossier de courrier indésirable et comptez jusqu&#39;à trente minutes pour sa réception.
        4. Une fois connecté, ouvrez les [Paramètres](https://replit.com/settings) pour modifier votre adresse e-mail.
      </Accordion>

      <Accordion title="Comment changer mon nom d'utilisateur ?">
        Les utilisateurs de Replit peuvent modifier leur nom d&#39;utilisateur **une seule fois**. Rendez-vous sur la [CLUI](https://replit.com/~/cli/account/change-username?run=1) et sélectionnez **change-username**. Si l&#39;option n&#39;est pas disponible, c&#39;est que vous l&#39;avez déjà modifié.
      </Accordion>

      <Accordion title="Qu'est-ce que le mode Explorer et comment l'activer ?">
        Les Explorers sont des utilisateurs de Replit qui ont choisi de découvrir et de tester les nouvelles fonctionnalités encore en développement. Pour activer le mode Explorer, ouvrez les [Paramètres](https://replit.com/settings) et activez l&#39;interrupteur Explorer (par exemple sous **Account** ou **User**).
      </Accordion>
    </AccordionGroup>
