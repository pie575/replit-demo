Задайте команду и расписание её выполнения — и Replit будет автоматически запускать её в среде вашего Replit App. После завершения выполнение прекращается до следующего запуска по расписанию.

Запланированные развёртывания (их также называют запланированными заданиями) идеально подходят для регулярных задач: проверки состояния, отправки уведомлений или запуска резервного копирования. Они не предназначены для непрерывных или長 длительных задач, таких как веб-приложения.

<div id="section">
  ## Возможности
</div>

Запланированные развёртывания включают следующие возможности:

* **Автоматическое планирование**: задайте расписание для задачи, и Replit будет запускать её автоматически.
* **Планирование на естественном языке**: опишите расписание понятным человеку языком, а ИИ преобразует его в cron-выражение (машиночитаемый формат расписания).
* **Оповещения об ошибках**: получайте уведомления, если запланированная задача завершилась с ошибкой.
* **Мониторинг**: просматривайте журналы и отслеживайте статус запланированных развёртываний.

<div id="section-2">
  ## Использование
</div>

Запланированные развёртывания доступны через инструмент Publishing в редакторе проекта.

В разделах ниже описано, как настроить запланированные развёртывания и управлять ими.

<Accordion title="Как перейти к запланированным развёртываниям">
  Через **панель инструментов** слева:

  1. Выберите <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Значок All tools" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**, чтобы открыть список инструментов редактора проекта.
  2. Выберите <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Значок Publishing" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publishing**.
  3. Выберите вариант **Scheduled**, затем — **Set up your published app**.

  Через **строку поиска**:

  1. Нажмите на <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="Значок лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" />лупу вверху, чтобы открыть поиск
  2. Введите «Publishing» и выберите инструмент в результатах поиска.
  3. Выберите вариант **Scheduled**, затем — **Set up your published app**.
</Accordion>

<div id="section-3">
  ### Конфигурация машины
</div>

В этом поле отображаются CPU, RAM и стоимость использования машины для запланированного развертывания.

<div id="section-4">
  ### Поля расписания
</div>

* **Описание расписания**: введите описание расписания на естественном языке, например «каждый понедельник и среду в 10:00» или «24 марта 2024 года в 15:00».
* **Выражение cron**: при необходимости введите машиночитаемую строку, определяющую, когда должна выполняться задача.
* **Выбор часового пояса**: выберите часовой пояс расписания в раскрывающемся меню.

Когда вы вводите значение в поле **Описание расписания** или **Выражение cron**, ИИ автоматически преобразует его в соответствующий формат.
Подробнее о выражениях cron см. на странице <a href="https://en.wikipedia.org/wiki/Cron" target="_blank">cron</a> в Википедии.

<div id="section-5">
  ### Тайм-аут задания
</div>

Укажите максимальное время выполнения, по истечении которого планировщик завершит задание. В выпадающем списке единиц времени выберите «minutes» или «hours».

<Tip>
  Запланированные задания могут выполняться медленнее, чем в редакторе проекта. Протестируйте развёртывание и скорректируйте тайм-аут при необходимости.
</Tip>

<div id="section-6">
  ### Команда сборки
</div>

В поле **Build command** введите команду оболочки, которая компилирует или подготавливает приложение перед выполнением **Run command**.
Например, чтобы установить зависимости приложения Node.js, добавьте команду сборки `npm install`.

Время выполнения команды сборки не учитывается в потреблении ресурсов и не входит в тайм-аут задания.

<div id="section-7">
  ### Команда запуска
</div>

В поле **Run command** введите команду оболочки, которая запускает задачу.
Например, чтобы выполнить скрипт на Python, укажите в качестве команды запуска `python app.py`.

Планировщик Replit выполняет команду запуска в назначенное время.
Время выполнения команды засчитывается в потребление ресурсов. Подробнее об оплате см.
[раздел о запланированных развёртываниях](/ru/ja/billing/deployment-pricing#scheduled-deployments) в документации по тарифам.

<div id="section-8">
  ### Secrets для развёртывания
</div>

Выберите **Add deployment secret**, чтобы добавить переменные окружения и secrets, необходимые для безопасной работы приложения.

Если в Replit App есть переменные окружения или secrets, инструмент Publishing автоматически добавит их в список.

Чтобы изменить значение переменной окружения,

нажмите <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" width="16" height="16" alt="значок трёх вертикальных точек" data-path="images/icons/vertical-dots.svg" /> три вертикальные точки и выберите в меню **Edit**. Менеджер Secrets применяет значения только к развёртыванию и не изменяет переменные окружения, заданные в Replit App.
