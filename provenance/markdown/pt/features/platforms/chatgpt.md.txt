# Replit no ChatGPT

> Crie apps reais conversando com o ChatGPT. Crie, atualize e inspecione Replit Apps em uma única conversa.

A integração do Replit no ChatGPT permite criar, atualizar e inspecionar Replit Apps diretamente nas suas conversas — sem necessidade de configuração. Crie apps reais conversando com o ChatGPT e deixe o Agent cuidar do resto.

## O que é o Replit no ChatGPT

O Replit no ChatGPT conecta suas conversas do ChatGPT à poderosa plataforma de desenvolvimento do Replit. Você pode descrever o que quer criar, e o Agent criará um Replit App totalmente funcional para você. Depois de criado, você pode pedir ao ChatGPT para modificar, atualizar ou analisar seu app — tudo através de conversa natural.

## Como começar

Siga estas etapas para conectar o Replit ao ChatGPT e criar seu primeiro app.

### Conectar o Replit ao ChatGPT

Você pode conectar o Replit ao ChatGPT de duas formas:

<Accordion title="Conectar pelas Configurações">
  1. Clique no ícone do seu perfil no ChatGPT
  2. Acesse **Configurações** → **Apps e Conectores**
  3. Encontre o **Replit** e clique em **Conectar**
  4. Conclua a autorização OAuth com sua conta do Replit
</Accordion>

<Accordion title="Conectar a partir de uma conversa">
  1. Inicie uma nova conversa no ChatGPT
  2. Invoque o Replit usando um dos métodos abaixo
  3. O ChatGPT irá guiá-lo pelo fluxo OAuth se você ainda não estiver conectado
</Accordion>

### Invocar o Replit no ChatGPT

Uma vez conectado, você pode invocar o Replit de três formas:

| Método             | Como usar                                                |
| ------------------ | -------------------------------------------------------- |
| Menção direta      | Digite `Replit, <solicitação>` no início da sua mensagem |
| Comando de barra   | Digite `/Replit` no compositor                           |
| Menu do compositor | Clique no botão **+** → **Mais** → **Replit**            |

### Criar seu primeiro app

Após a conexão, crie seu primeiro Replit App:

1. Inicie uma nova conversa no ChatGPT
2. Invoque o Replit e descreva o que você quer criar (por exemplo, "Replit, create a todo app with dark mode")
3. O Agent gerará seu app e fará o deploy automaticamente
4. Após a conclusão, você receberá um link para visualizar seu app

<Note>
  Cada conversa pode trabalhar com um Replit App. Se você criar um novo app na mesma conversa, ele modificará o app existente. Para criar vários apps, inicie conversas separadas.
</Note>

## Recursos

* **[Replit AI](/pt/build/welcome)**: o Agent gera e faz o deploy de apps com base nas suas solicitações em linguagem natural
* **[Project Editor](/pt/learn/projects-and-artifacts/project-editor)**: ambiente de desenvolvimento completo acessível pelo ChatGPT
* **[Publicação](/pt/learn/projects-and-artifacts/replit-deployments)**: os apps são automaticamente implantados e ficam prontos para compartilhar

<Accordion title="O que você pode fazer">
  **Criar:** crie novos Replit Apps descrevendo o que você quer. O Agent gera a aplicação e faz o deploy automaticamente.

  **Atualizar:** modifique o app na sua conversa atual. Peça ao ChatGPT para adicionar recursos, corrigir bugs ou fazer alterações, e o Agent as aplicará.

  **Inspecionar:** analise seu app sem fazer alterações. Obtenha informações sobre a estrutura do código, caminhos de arquivos ou comportamento.
</Accordion>

<Accordion title="Formatos de arquivo suportados">
  Você pode incluir vários tipos de arquivo nas suas solicitações:

  | Formato                      | Suportado               |
  | ---------------------------- | ----------------------- |
  | PDF                          | Sim                     |
  | CSV                          | Sim                     |
  | Formatos de documento comuns | Sim                     |
  | Imagens (arquivos brutos)    | Não (use URLs públicas) |
  | Vídeos (arquivos brutos)     | Não (use URLs públicas) |

  <Note>
    Para incluir imagens ou vídeos no seu app, forneça URLs públicas na sua solicitação. Você também pode adicionar arquivos de mídia diretamente no Replit depois que o app for criado.
  </Note>
</Accordion>

<Accordion title="Tempos de criação">
  O Agent normalmente cria apps em:

  | Complexidade do app                                  | Tempo típico de criação |
  | ---------------------------------------------------- | ----------------------- |
  | Simples (calculadoras, pequenas landing pages)       | 2–3 minutos             |
  | Complexo (jogos, animações ricas, dashboards densos) | 3–4 minutos             |
</Accordion>

## Disponibilidade e planos

<Accordion title="Planos do ChatGPT">
  A integração com o Replit funciona com todos os tipos de planos do ChatGPT:

  | Plano          | Suportado | Notas                                                                             |
  | -------------- | --------- | --------------------------------------------------------------------------------- |
  | Free           | Sim       |                                                                                   |
  | Plus           | Sim       |                                                                                   |
  | Pro            | Sim       |                                                                                   |
  | Business       | Sim       | Requer ativação pelo administrador em **Configurações do Workspace → Conectores** |
  | Enterprise/Edu | Sim       | Requer ativação pelo administrador em **Configurações do Workspace → Conectores** |

  **Disponibilidade regional:** todas as regiões fora da UE.
</Accordion>

<Accordion title="Planos do Replit">
  Todos os tipos de planos do Replit suportam a integração com o ChatGPT:

  | Plano          | Suportado | Notas                                                       |
  | -------------- | --------- | ----------------------------------------------------------- |
  | Starter (Free) | Sim       | Apenas apps públicos                                        |
  | Core           | Sim       | Apps privados, compilações estendidas, Publicação, Database |
  | Pro            | Sim       | Cota mensal de créditos maior, todos os recursos do Core    |
  | Enterprise     | Sim       | Acesso completo aos recursos                                |
</Accordion>

## Cobrança e créditos

O trabalho realizado pelo Replit no ChatGPT é cobrado como uso do Replit Agent na sua conta do Replit.

<Accordion title="Como funciona a cobrança">
  * Os planos **Core** e **Pro** incluem créditos mensais que cobrem o Agent, a publicação e os bancos de dados até o seu limite
  * Você pode comprar **pacotes de créditos** que expiram após seis meses e não renovam automaticamente — ideais para picos de lançamento ou experimentos
  * Use **limites de uso** e **orçamentos** nas configurações de cobrança do Replit para limitar os gastos

  Saiba mais na [documentação de cobrança de IA](/pt/billing/ai-billing).
</Accordion>

## Limitações atuais

Atualmente, o app Replit no ChatGPT:

* Só pode trabalhar no app criado nessa conversa específica
* Não pode abrir ou modificar:
  * Apps criados em outras threads do ChatGPT
  * Apps que você criou diretamente no Replit

A paridade de recursos com a experiência completa do Replit (bancos de dados, gerenciamento de secrets, controles mais avançados do Project Editor) está sendo desenvolvida.

## Solução de problemas

<Accordion title="Replit não aparece em Navegar apps">
  Se você não ver o Replit em **Navegar apps**, verifique:

  * Se os apps estão disponíveis na sua região
  * Se o administrador do workspace habilitou o app do Replit (Business/Enterprise/Edu)
</Accordion>

<Accordion title="Falhas de criação">
  Se as criações falharem, abra o app no Replit:

  * Verifique o uso e a cobrança
  * Use checkpoints e reversões
  * Peça ajuda ao Agent diretamente no Project Editor
</Accordion>
