<div id="section">
  ## 什么是数据可视化？
</div>

数据可视化是通过与 Agent Conversation创建的交互式控制面板或报表工具。只需说明想要可视化的内容以及数据所在的位置，Agent 就会自动选择合适的 KPI、图表类型和布局，通过一条提示词生成完整的控制面板。

核心概念：

* **一次生成**：描述目标和数据源后，Agent 会构建包含合适图表和指标的完整控制面板
* **已连接的数据源**：从数据库、[数据仓库连接器](/zh/ko/connectors/warehouses/overview)、外部 API 和上传的文件中获取数据
* **内置功能**：所有控制面板均包含刷新、自动刷新、导出为 PDF、将图表导出为 CSV，以及浅色/深色模式
* **分析摘要**：Agent 会根据您的请求和结果数据生成洞察
* **多个工件**：数据可视化可与[同一项目](/zh/ko/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project)中的其他工件共享相同的后端和数据库

<div id="data-visualization">
  ## 如何使用 Data Visualization
</div>

<div id="section-2">
  ### 通过提示词创建
</div>

在首页选择 **App** 标签页，然后描述你想要的控制面板。Agent 会识别与数据相关的提示词，并选择 Data Visualization 技术栈。

**提示词示例：**

* “创建一个按地区追踪销售额的销售分析控制面板”
* “创建一个用于可视化月度指标的报表工具”
* “使用我们的 BigQuery 销售数据创建一个展示畅销产品的控制面板”
* “连接 Snowflake，创建一个客户流失分析控制面板”

<div id="section-3">
  ### 通过下拉菜单创建
</div>

1. 在首页打开 **App** 标签页。
2. 打开应用类型下拉菜单。
3. 选择 **Data Visualization**。
4. 描述你想要构建的控制面板或数据工具。

<div id="section-4">
  ### 连接数据仓库
</div>

通过[数据仓库连接器](/zh/ko/connectors/warehouses/overview)将数据可视化功能连接到 BigQuery、Databricks 和 Snowflake，并基于现有数据集构建控制面板。

查询数据仓库中的数据时，Agent 会使用并行多 Agent 搜索来探索架构和数据集。这不仅能加快探索速度，还能帮助 Agent 为控制面板选择合适的表和字段。

首先，在项目的[集成](/zh/ko/features/integrations/overview)中设置数据仓库连接器，然后告诉 Agent 您想要可视化的内容。

<div id="section-5">
  ### 添加筛选器和功能
</div>

Agent 构建好控制面板后，您可以向它发送提示词，要求添加筛选器、下钻功能和其他交互功能。例如，可以请 Agent 添加日期范围筛选器、地区选择器和搜索栏。

<div id="section-6">
  ### 导出与分享
</div>

* **导出为 PDF**：将整个控制面板导出为 PDF，便于分享或离线查看。
* **将图表导出为 CSV**：下载单个图表数据的 CSV 文件，以便在电子表格或其他工具中进行进一步分析。
* **分析文档**：让 Agent 根据控制面板数据生成详细的分析文档。

<div id="section-7">
  ## 可以构建的内容
</div>

* **分析控制面板**：按时间追踪收入、注册量、参与度等关键指标
* **报表工具**：构建内部报告，让利益相关者无需直接访问数据库即可筛选和探索数据
* **数据探索界面**：以可视化方式探索和查询数据集
* **监控面板**：显示来自 API、数据库和外部服务的实时或近实时数据

<div id="section-8">
  ## 常见问题
</div>

<Accordion title="可以连接哪些数据源？">
  您可以从项目的 Replit Database、数据仓库连接器 (BigQuery、Databricks、Snowflake) 、外部 API 和 CSV 等上传文件中获取数据。通过 [集成](/zh/ko/features/integrations/overview)设置数据仓库连接。
</Accordion>

<Accordion title="可以自定义设计和风格吗？">
  可以。您可以通过 Conversation 自定义颜色、布局和排版——让 Agent 根据您的品牌进行调整，或修改设计。控制面板还支持浅色和深色模式。
</Accordion>

<Accordion title="Agent 会代为分析数据吗？">
  构建控制面板后，Agent 会根据您的请求和结果数据生成分析摘要。您还可以请求更详细的分析文档。
</Accordion>

<Accordion title="可以将数据可视化与其他工件类型结合吗？">
  可以。您可以在[同一项目](/zh/ko/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project)中，将数据可视化与 [Web 应用](/zh/ko/features/artifact-types/web-apps)、[幻灯片](/zh/ko/features/artifact-types/slide-decks)及其他工件类型结合使用。它们共享相同的后端和数据库。
</Accordion>
