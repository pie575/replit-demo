title: "Shell"

---

Shell позволяет выполнять задачи операционной системы прямо в редакторе проектов: управлять файлами,
устанавливать пакеты и запускать скрипты. Это мощный текстовый интерфейс для
взаимодействия с вашей средой Replit.

С помощью Shell в редакторе проектов вы можете:

* запускать скрипты и программы;
* устанавливать и запускать популярные инструменты и пакеты Linux;
* загружать файлы из интернета и выгружать их;
* управлять файлами и каталогами проекта.

<Tip>
  Для более удобного управления рабочими процессами запускайте приложение кнопкой **Run**, а не через
  Shell. Рабочий процесс, запущенный кнопкой **Run**, отправляет вывод в инструмент Console,
  где логи представлены в структурированном виде.
</Tip>

<div id="recursos">
  ## Возможности
</div>

Shell предоставляет следующие функции:

* **Запуск нескольких Shell**: открывайте несколько экземпляров Shell, чтобы одновременно работать над разными задачами
* **Поиск по тексту**: находите нужный текст в выводе Shell

<div id="uso">
  ## Использование
</div>

<Accordion title="Как открыть Shell">
  В **доке инструментов** слева:

  1. Нажмите <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Значок «Все инструменты»" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **Все инструменты**, чтобы увидеть список инструментов редактора проектов.
  2. Выберите <img class="icon-svg" src="/assets/mirror/shell-289d6eb079b0.svg" alt="Значок Shell" width="16" height="16" data-path="images/icons/shell.svg" /> **Shell**.

  Через **строку поиска**:

  1. Нажмите на <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="значок лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> лупу вверху, чтобы открыть инструмент поиска
  2. Введите «Shell», чтобы найти инструмент, и выберите его в результатах.
</Accordion>

<div id="pesquisa-de-texto">
  ### Текстовый поиск
</div>

Ниже описано, как открыть и использовать инструмент текстового поиска:

1. Нажмите на значок <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="значок лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> лупы в правом верхнем углу вкладки Shell, чтобы открыть окно поиска.
2. Введите поисковый запрос и нажимайте **Далее** для перехода между совпадениями.
3. Кнопка **Назад** возвращает к предыдущим совпадениям.
4. Нажмите **Выход** или щёлкните за пределами окна, чтобы завершить текстовый поиск.

<div id="mltiplos-shells">
  ### Несколько Shell
</div>

Чтобы создать новый Shell, откройте меню в левом верхнем углу вкладки **Shell** и выберите **Новый Shell**, как показано ниже:

<Frame>
  <img src="/assets/mirror/shell-new-94a280c1230f.png" alt="Выбор пункта меню «Новый Shell»" width="1280" height="224" data-path="images/workspace/shell-new.png" />
</Frame>

Через это же меню можно переключаться между Shell. Редактор проектов присваивает каждому Shell имя последней выполненной команды, чтобы вам было проще их различать.

<Warning>
  Если открыто больше одного Shell, Replit автоматически закрывает простаивающие экземпляры.
  Простаивающим считается Shell, который не выбран и не выполняет ни одного пользовательского процесса.
</Warning>
