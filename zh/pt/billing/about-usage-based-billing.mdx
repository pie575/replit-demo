部署有三种按用量计费的项目：

1. 出站数据传输
2. 自动扩缩容计算单元
3. 请求

你可以在 **设置** 的 **账户** → **账户用量** 中查看用量。系统会按月计费，或在累计费用超过每月积分时计费。Replit Core 和 Pro 用户可获得这些资源的每月额度。

如果需要超出每月订阅额度的额外积分，你可以在计费页面购买积分包。有关积分包的更多信息，请参阅[管理支出](/zh/pt/billing/managing-spend)。

<div id="publicao">
  # 部署
</div>

<div id="1-transferncia-de-dados-de-sada-de-publicao">
  ## 1. 部署出站数据传输
</div>

此类使用按字节计费，Replit Core 和 Pro 用户每月可获得一定配额。只有出站数据会计入此配额，并可能产生超额费用。相比之下，入站数据始终免费。

| 订阅          | 配额                                                 |
| ----------- | -------------------------------------------------- |
| Replit Core | 100 GiB                                            |
| Replit Pro  | 查看 [Replit Pro 定价](https://www.replit.com/pricing) |

配额适用于[静态](/zh/pt/features/publishing/deployment-types#static)、[自动扩缩容](/zh/pt/features/publishing/deployment-types#autoscale)、[预留 VM](/zh/pt/features/publishing/deployment-types#reserved-vm)和[定时](/zh/pt/features/publishing/deployment-types#scheduled)部署。

请查看[定价页面](https://www.replit.com/pricing)，了解当前的出站数据传输价格。

***

<div id="2-unidades-de-computao">
  ## 2. 计算单元
</div>

自动扩缩容部署按计算单元计费，同时考虑 CPU 和 RAM 的使用时长。

超额用量按计算单元计费，计费粒度精确到单个计算单元。请参阅[定价页面](https://www.replit.com/pricing)，了解当前计算单元的价格。

下表说明自动扩缩容部署的 RAM 秒和 CPU 秒如何换算为计算单元：

| 资源      | 计算单元  |
| ------- | ----- |
| 1 RAM 秒 | 2 单元  |
| 1 CPU 秒 | 18 单元 |

静态部署不消耗计算单元，仅对超出[指定额度](#)的出站数据传输计费。

[详细了解自动扩缩容部署](/zh/pt/features/publishing/deployment-types#autoscale)。

***

<div id="3-requisies">
  ## 3. 请求
</div>

自动扩缩容部署还会考虑请求数量。

请查看[定价页面](https://www.replit.com/pricing)了解当前的请求价格。

<div id="bancos-de-dados">
  # 数据库
</div>

Replit 仅对[生产数据库](/zh/pt/features/data-and-storage/development-and-production)收费——开发数据库始终免费，所有 Replit App 均包含开发数据库。有关开发数据库的详细信息，请参阅[开发数据库](/zh/pt/features/data-and-storage/sql-database)。

Replit PostgreSQL 是全托管无服务器服务，轻松实现高可用性，无需维护。生产数据库按实际用量计费，能够显著节省成本。

生产 PostgreSQL 数据库按以下两项使用指标计费：

* **[计算时间](#compute-time)**：每小时消耗的计算资源量。
* **[数据存储](#data-storage)**：存储的数据总量 (包括历史数据) 。

你可以在**设置** → **账户** → **账户使用情况**中查看当前的资源使用情况，包括生产数据库用量。

<div id="tempo-de-computao">
  ## 计算时间
</div>

计算时间取决于您的数据库在特定计费周期内处于活跃状态的小时数。数据库在收到请求时，以及最后一次请求后的额外 5 分钟内，均视为活跃状态。如果数据库连续 5 分钟处于空闲状态，将被暂停并进入非活跃状态。

<div id="armazenamento-de-dados">
  ## 数据存储
</div>

数据存储是指你账户中所有数据库的数据总量，以吉比字节 (GiB) 为单位。存储用量按每月的最高使用量计算。每个 PostgreSQL 数据库都会占用 33 MB 存储空间，即使其中没有任何数据也是如此。这是 Postgres 服务器的默认存储空间。

<Note>每个生产数据库的总存储空间上限为 10 吉比字节 (GiB)。每个 Replit App 的开发数据库包含 20 GiB 免费存储空间。</Note>
