# Replit dans ChatGPT

> Créez de vraies applications en parlant à ChatGPT. Créez, mettez à jour et inspectez des applications Replit depuis une seule conversation.

L'intégration Replit dans ChatGPT vous permet de créer, mettre à jour et inspecter des applications Replit directement depuis vos conversations — aucune configuration requise. Créez de vraies applications en parlant à ChatGPT et laissez Agent s'occuper du reste.

## Qu'est-ce que Replit dans ChatGPT

Replit dans ChatGPT connecte vos conversations ChatGPT à la puissante plateforme de développement Replit. Vous pouvez décrire ce que vous souhaitez créer, et Agent créera une application Replit entièrement fonctionnelle pour vous. Une fois créée, vous pouvez demander à ChatGPT de modifier, mettre à jour ou analyser votre application — tout cela via une conversation naturelle.

## Démarrer

Suivez ces étapes pour connecter Replit à ChatGPT et créer votre première application.

### Connecter Replit à ChatGPT

Vous pouvez connecter Replit à ChatGPT de deux façons :

<Accordion title="Connecter depuis les Paramètres">
  1. Cliquez sur votre icône de profil dans ChatGPT
  2. Allez dans **Paramètres** → **Apps & Connectors**
  3. Trouvez **Replit** et cliquez sur **Connect**
  4. Complétez l'autorisation OAuth avec votre compte Replit
</Accordion>

<Accordion title="Connecter depuis une conversation">
  1. Démarrez une nouvelle conversation dans ChatGPT
  2. Invoquez Replit en utilisant l'une des méthodes ci-dessous
  3. ChatGPT vous guidera dans le flux OAuth si vous n'êtes pas connecté
</Accordion>

### Invoquer Replit dans ChatGPT

Une fois connecté, vous pouvez invoquer Replit de trois façons :

| Méthode             | Comment utiliser                                    |
| ------------------- | --------------------------------------------------- |
| Mention directe     | Tapez `Replit, <requête>` au début de votre message |
| Commande slash      | Tapez `/Replit` dans le compositeur                 |
| Menu du compositeur | Cliquez sur le bouton **+** → **Plus** → **Replit** |

### Créer votre première application

Après la connexion, créez votre première application Replit :

1. Démarrez une nouvelle conversation dans ChatGPT
2. Invoquez Replit et décrivez ce que vous souhaitez créer (par ex., "Replit, create a todo app with dark mode")
3. Agent générera votre application et la déploiera automatiquement
4. Une fois terminé, vous recevrez un lien pour afficher votre application

<Note>
  Chaque conversation peut fonctionner avec une seule application Replit. Si vous créez une nouvelle application dans la même conversation, elle modifiera l'application existante. Pour créer plusieurs applications, démarrez des conversations séparées.
</Note>

## Fonctionnalités

* **[Replit AI](/fr/build/welcome)** : Agent génère et déploie des applications en fonction de vos requêtes en langage naturel
* **[Project Editor](/fr/core-concepts/project-editor)** : Environnement de développement complet accessible depuis ChatGPT
* **[Publication](/fr/category/replit-deployments)** : Les applications sont automatiquement déployées et prêtes à être partagées

<Accordion title="Ce que vous pouvez faire">
  **Créer :** Construisez de nouvelles applications Replit en décrivant ce que vous souhaitez. Agent génère l'application et la déploie automatiquement.

  **Mettre à jour :** Modifiez l'application dans votre conversation actuelle. Demandez à ChatGPT d'ajouter des fonctionnalités, corriger des bugs ou apporter des modifications, et Agent les appliquera.

  **Inspecter :** Analysez votre application sans apporter de modifications. Obtenez des informations sur la structure du code, les chemins de fichiers ou le comportement.
</Accordion>

<Accordion title="Formats de fichiers pris en charge">
  Vous pouvez inclure différents types de fichiers dans vos requêtes :

  | Format                        | Pris en charge                          |
  | ----------------------------- | --------------------------------------- |
  | PDF                           | Oui                                     |
  | CSV                           | Oui                                     |
  | Formats de documents courants | Oui                                     |
  | Images (fichiers bruts)       | Non (utilisez plutôt des URL publiques) |
  | Vidéos (fichiers bruts)       | Non (utilisez plutôt des URL publiques) |

  <Note>
    Pour inclure des images ou des vidéos dans votre application, fournissez des URL publiques dans votre requête. Vous pouvez également ajouter des fichiers multimédias directement dans Replit après la création de l'application.
  </Note>
</Accordion>

<Accordion title="Temps de construction">
  Agent construit généralement des applications en :

  | Complexité de l'application                                 | Temps de construction typique |
  | ----------------------------------------------------------- | ----------------------------- |
  | Simple (calculatrices, petites pages d'atterrissage)        | 2–3 minutes                   |
  | Complexe (jeux, animations riches, tableaux de bord denses) | 3–4 minutes                   |
</Accordion>

  | -------------- | -------------- | --------------------------------------------------------------------------------------- |

  | Plus           | Oui            |                                                                                         |

  | Enterprise     | Oui            | Accès complet aux fonctionnalités                                            |
</Accordion>

## Facturation et crédits

Le travail effectué par Replit dans ChatGPT est facturé comme utilisation de Replit Agent dans votre compte Replit.

<Accordion title="Comment fonctionne la facturation">
  * Les plans **Core** et **Pro** incluent des crédits mensuels couvrant Agent, la publication et les bases de données jusqu'à votre limite
  * Vous pouvez acheter des **packs de crédits** qui expirent après six mois et ne se renouvellent pas automatiquement — idéal pour les pics de lancement ou les expériences
  * Utilisez les **limites d'utilisation** et les **budgets** dans les paramètres de facturation de Replit pour plafonner les dépenses

  En savoir plus dans la [documentation de facturation IA](/fr/billing/ai-billing).
</Accordion>

## Limitations actuelles

Actuellement, l'application Replit dans ChatGPT :

* Ne peut travailler que sur l'application créée dans cette conversation spécifique
* Ne peut pas ouvrir ou modifier :
  * Des applications créées dans d'autres fils ChatGPT
  * Des applications que vous avez créées directement dans Replit

La parité de fonctionnalités avec l'expérience Replit complète (bases de données, gestion des secrets, contrôles du Project Editor plus avancés) arrivera plus tard.

## Dépannage

<Accordion title="Replit n'apparaît pas dans Parcourir les applications">
  Si vous ne voyez pas Replit dans **Parcourir les applications**, vérifiez :

  * Si les applications sont disponibles dans votre région
  * Si l'administrateur de votre workspace a activé l'application Replit (Business/Enterprise/Edu)
</Accordion>

<Accordion title="Échecs de construction">
  Si les constructions échouent, ouvrez l'application dans Replit :

  * Vérifiez l'utilisation et la facturation
  * Utilisez les checkpoints et les retours en arrière pour revenir à une version précédente
  * Demandez à Agent de l'aide directement dans le Project Editor
</Accordion>
