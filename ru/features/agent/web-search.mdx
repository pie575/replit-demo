Создавайте приложения на актуальных данных из реального мира с помощью веб-поиска <img class="icon-svg" src="/assets/mirror/web-search-1fe8f63b5b88.svg" alt="Значок веб-поиска" width="16" height="16" data-path="images/icons/web-search.svg" /> в Agent.

Эта функция снимает ограничение, связанное с датой обучения модели: Agent обращается за свежей информацией напрямую в интернет. Когда вы просите его создать что-то, для чего нужны актуальные сведения, он ищет в интернете и подгружает подробные материалы, чтобы ваше приложение получилось точнее и полезнее.

Веб-поиск помогает находить самые свежие пакеты, инструменты и сведения. Благодаря этому ваши приложения опираются на актуальные передовые практики и работают точнее.

<div id="features">
  ## Возможности
</div>

Создавайте приложения на основе актуальной информации с помощью веб-поиска в Agent. Это избавляет от необходимости вручную искать и собирать данные. Создаёте ли вы панель с финансовыми показателями или сайт с обзором недавних запусков стартапов — веб-поиск гарантирует, что ваше приложение отражает реальное положение дел.

Agent может выполнять следующие действия веб-поиска:

* **Поиск**: находить в интернете актуальную информацию, свежую документацию и данные в реальном времени
* **Получение контента**: извлекать подробную информацию с конкретных сайтов и по конкретным URL
* **Ссылки на источники**: видеть, где именно Agent нашёл информацию, чтобы вы могли проверить и указать источники

<div id="usage">
  ## Использование
</div>

Веб-поиск встроен в Agent — включать ничего не нужно. Опишите, что хотите создать, и Agent сам определит, когда стоит поискать в интернете актуальную информацию. Чтобы явно подтолкнуть Agent к поиску, добавьте в prompt слова вроде «найди», «изучи» или «используй веб-поиск».

<div id="how-web-search-enhances-your-apps">
  ### Как веб-поиск улучшает ваши приложения
</div>

Благодаря веб-поиску ваши приложения переходят от условных данных к реальной, точной информации:

| Преимущество                | Описание                                                                         |
| --------------------------- | -------------------------------------------------------------------------------- |
| Актуальные технологии       | Приложения используют свежую информацию и пакеты, которых нет в обучающих данных |
| Выбор лучших инструментов   | Agent изучает варианты и выбирает оптимальные пакеты                             |
| Современные лучшие практики | Доступ к новейшим подходам к разработке и практикам безопасности                 |
| Преодоление ограничений     | Обход границы знаний модели для работы с пакетами, вышедшими после обучения      |
| Точные данные               | Приложения отображают актуальную информацию вместо устаревших примеров           |
| Профессиональный результат  | Приложения со ссылками на реальные компании выглядят убедительно                 |
| Экономия времени            | Не нужно вручную искать пакеты и собирать данные                                 |

<div id="source-citations">
  ### Ссылки на источники
</div>

Когда Agent использует веб-поиск, он приводит **ссылки на источники**, которые показывают, откуда именно взята информация. Используйте эти ссылки, чтобы:

* **Проверить информацию**: оценить надёжность и достоверность источников
* **Узнать больше**: перейти к первоисточникам за дополнительным контекстом
* **Сослаться на источники**: корректно указать авторство в своих приложениях
* **Проследить ход поиска**: понять, какая информация легла в основу работы Agent

<div id="content-fetching">
  ### Получение контента
</div>

Agent может извлекать подробное содержимое с определённых сайтов, чтобы собрать исчерпывающую информацию для вашего проекта. Это позволяет Agent:

* Читать веб-страницы целиком и извлекать нужные сведения
* Обрабатывать документацию и справочные материалы
* Собирать конкретные данные из авторитетных источников
* Встраивать структурированную информацию в ваше приложение
