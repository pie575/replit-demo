---
title: "Historique des fichiers"
description: "Apprenez à récupérer les versions précédentes de votre code à l'aide des points de sauvegarde automatiques de l'Historique des fichiers."
---

Commencez par ouvrir un fichier texte dans l'Éditeur de projet et appuyez sur le bouton **Historique** dans le coin inférieur droit.

<Frame>
  <img src="/assets/mirror/history-button-afac6496660a.png" alt="ouverture de l'historique" width="377" height="292" data-path="images/programming-ide/history-button.png" />
</Frame>

## Voir les versions précédentes d'un fichier

Une fois que vous avez ouvert l'Historique des fichiers, vous pouvez voir les versions précédentes d'un fichier en utilisant la barre de défilement, les boutons fléchés, ou les touches fléchées **gauche** et **droite**.

<Frame>
  <img src="/assets/mirror/history-versioning-1a055ecab411.gif" alt="démo de la barre de défilement" width="764" height="720" data-path="images/animations/history-versioning.gif" />
</Frame>

## Comparer les versions précédentes avec le fichier actuel

Appuyez sur le bouton Comparer avec la dernière version dans le coin inférieur gauche du panneau Historique des fichiers pour voir les comparaisons en ligne de votre fichier à ce moment précis et la version la plus récente.

<Frame>
  <img src="/assets/mirror/compare-history-46fb16debd3a.gif" alt="image comparer avec la dernière version" width="772" height="720" data-path="images/animations/compare-history.gif" />
</Frame>

## Restaurer une version précédente d'un fichier

Si vous souhaitez restaurer un fichier à une version précédente, appuyez simplement sur le bouton `Restaurer`, qui effectuera la restauration. Ne vous inquiétez pas, vous n'effacerez aucun historique. Lorsque vous restaurez une version précédente, elle est ajoutée comme une nouvelle version à l'historique du fichier.

<Frame>
  <img src="/assets/mirror/restore-history-5f616d7f961a.webp" alt="image restaurer l'historique" width="720" height="495" data-path="images/animations/restore-history.webp" />

## Voir la lecture de l'Historique des fichiers

Vous pouvez utiliser la fonctionnalité de lecture de l'Historique des fichiers pour regarder votre fichier changer au fil du temps comme un film. Cela peut être utile pour créer des vidéos de vos sessions de programmation.
