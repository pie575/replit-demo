Replit AI 기능은 usage-based billing을 적용하여 무엇을 만들었는지, AI 기반 도구를 얼마나 사용했는지에 따라 요금을 청구합니다. 따라서 Agent에서 얻은 가치만큼만 비용을 지불하게 됩니다.

<div id="getting-started">
  ## 시작하기
</div>

**모든 구독자**는 일회성 무료 Agent 체크포인트를 받습니다.

추가 월별 크레딧은 AI 사용량에 자동으로 적용됩니다:

* **Core 구독자**: 월별 크레딧([요금제](https://replit.com/pricing) 참조)
* **Pro 구독자**: {ProCreditRolloverPeriod} 동안 이월되는 등급별 월별 크레딧. [Replit Pro](/ko/billing/plans/replit-pro)를 참조하세요.

이 크레딧은 Agent뿐 아니라 게시된 앱, 스토리지, 데이터베이스 등 다른 Replit 클라우드 서비스에도 사용됩니다. 비용이 들지 않는 작업은 Free Mode로 시작하세요. [Power 또는 Max](/ko/features/agent/agent-modes) 모드에서는 Auto를 선택하면 유료 작업에 사용할 모델을 Replit이 자동으로 골라줍니다.

  ## Agent 요금 청구
</div>

Free Mode에서는 Core 및 Pro 구독자가 제공된 allowance 범위 내에서 일상적인 Agent 작업을 무료로 수행할 수 있습니다. 유료 모드와 사용자가 확인한 유료 작업에는 요청 복잡도에 따라 노력 기반 요금제가 적용됩니다. 유료 작업이 시작되기 전에 Replit이 먼저 확인을 요청합니다.

<div id="how-effort-based-pricing-works">
  ### 노력 기반 요금제 작동 방식
</div>

&quot;Build Mode&quot;에서 Agent와 대화하면 요청에 대해 완료된 작업을 담은 **체크포인트**가 생성됩니다:

* **단순한 요청**(버그 수정이나 소규모 변경 등)은 일반적으로 복잡한 빌드보다 비용이 적게 듭니다
* **복잡한 빌드**(전체 기능 구현이나 integration 등)는 하나의 체크포인트로 묶이며, 투입된 총 노력이 반영되어 단순한 요청보다 비용이 더 많이 들 수 있습니다
* **요청당 체크포인트 하나**로 중간 체크포인트를 없애 billing noise를 줄입니다
* **투명한 pricing**을 통해 완료된 각 task에 대해 무엇을 지불하는지 정확히 확인할 수 있습니다

<Info>
  체크포인트는 Agent가 요청한 작업을 완료하고 요청된 기능을 코드에 구현했을 때 생성됩니다.
</Info>

유료 경로에서는 Plan Mode가 코드를 변경하지 않더라도 과금 대상이 되는 추론을 수행할 수 있습니다.

체크포인트가 무엇을 담고 어떻게 작동하는지 자세한 내용은 [Checkpoints and Rollbacks](/ko/features/version-control/checkpoints-and-rollbacks)를 참고하세요.

<div id="agent-services-billing">
  ### Agent 서비스 청구
</div>

일부 Agent 기능은 내부적으로 유료 서드파티 API(예: Claude, ChatGPT, Nano Banana / Gemini)를 사용합니다. Agent가 이러한 연동을 자동으로 처리하므로 API 키나 별도 설정이 필요하지 않습니다. 요금은 provider의 공개 API 요율로 청구되며 Replit 크레딧에서 차감됩니다. 이 비용은 [사용량 대시보드](/ko/billing/managing-spend)에서 다른 사용량과 함께 확인할 수 있습니다.

샘플 앱의 비용이 궁금하다면 간단한 [대화형 데모](https://agent-pricing.replit.app/)를 확인해 보세요.

<div id="track-your-usage">
  ### 사용량 추적
</div>

Agent 지출은 실시간으로 모니터링할 수 있습니다:

1. **Agent 탭**: 사용량 아이콘에 마우스를 올리면 개별 체크포인트의 비용을 확인할 수 있습니다
2. **사용량 대시보드**: 현재 청구 기간의 상세한 billing 정보를 확인할 수 있습니다
3. **Settings**: **Account** → **Billing**에서 알림과 예산을 설정해 지출을 관리할 수 있습니다

<Tip>
  사용량 데이터가 사용량 대시보드에 반영되기까지 최대 30분이 걸릴 수 있습니다.
</Tip>

<div id="managing-your-spend">
  ## 지출 관리하기
</div>

Replit에 내장된 예산 관리 도구로 AI 지출을 직접 관리하세요:

* **사용량 알림**: 지출이 설정한 기준에 도달하면 알림을 받습니다
* **예산 한도**: 상한선을 설정해 예상치 못한 요금을 방지합니다
* **실시간 추적**: 앱을 만드는 동안 비용을 모니터링합니다
* **크레딧 팩**: 추가 크레딧을 구매할 수 있으며, 대량 구매 시 할인이 적용됩니다. 자세한 내용은 [지출 관리하기](/ko/billing/managing-spend)를 참조하세요.

<div id="next-steps">
  ## 다음 단계
</div>

AI로 앱을 만들어 볼 준비가 되셨나요? 크레딧을 최대한 활용하는 방법은 다음과 같습니다.

* **먼저 Agent를 사용해 보세요**: 무료 체크포인트로 Agent의 기능을 살펴보세요
* **작게 시작하세요**: 간단한 요청부터 시작해 노력 기반 요금제를 이해해 보세요
* **Free Mode를 사용하세요**: 일상적인 작업은 [Free Mode](/ko/features/agent/agent-modes)로 시작하세요
* **알림을 설정하세요**: 크레딧을 모두 소진하기 전에 지출 알림을 설정하세요

[Replit의 AI 도구](/ko/welcome)에 대해 자세히 알아보거나 [요금제](https://replit.com/pricing)를 살펴보세요.
