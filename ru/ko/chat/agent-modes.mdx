Agent Modes позволяют перед отправкой запроса выбрать оптимальный баланс между включённым лимитом, кредитами и производительностью. Откройте раскрывающийся список настроек Agent в поле ввода промпта и выберите режим для своей задачи.

<Note>
  Economy Mode больше не доступен. Его заменяет Power Mode по той же цене.
</Note>

<div id="section">
  ## Выбор режима
</div>

* **Free Mode:** исследуйте идеи, задавайте вопросы, начинайте создавать приложения и выполняйте повседневные задачи. Free Mode использует интеллектуальную маршрутизацию моделей. {FreeModePlanAvailability}
* **Power Mode:** оптимальное сочетание скорости и производительности для большинства задач. Используйте его, когда вам нужна производительность сверх лимита Free Mode или более мощные настройки по умолчанию для существующего проекта.
* **Max Mode:** лучший вариант для сложных задач, больших кодовых баз и трудных проблем.

Power Mode и Max Mode используют ежемесячные кредиты. Replit предупредит вас, прежде чем запрос будет переведён из Free Mode в платный режим. Остаток лимита Free Mode можно проверить в **Settings** → **Usage**. Практические советы см. в статье [Как максимально эффективно использовать Free Mode](/ru/ko/chat/free-mode).

Routine выполняется в Power Mode или Max Mode и требует бюджета для каждого запуска. В Free Mode Routine запускать нельзя. Подробнее см. в статье [Routine](/ru/ko/chat/routines).
