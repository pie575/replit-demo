<div id="prompts-personalizados">
  ### 自定义提示词
</div>

<Note>
  **更新 (2025 年 12 月) ：** Assistant 已停用。如需快速、有针对性的编辑，请使用 [Agent 的 Lite 模式](/zh/pt/core-concepts/agent/agent-modes)。
</Note>

自定义提示词让你完全掌控 Assistant 的交互方式。无论是设定特定的编码规范，还是调整 Assistant 的默认行为，自定义提示词都能满足你的需求。

你可以添加的内容包括：

* 特定的编码风格或框架
* 特定的问题解决方法
* 包管理偏好

例如，你可以添加：

```
use pnpm for package management
use motion/react instead of framer-motion
always use claude-3-5-sonnet-20241022 as your model
```

<div id="workflows">
  ### 工作流
</div>

工作流是一个易于配置的“运行”按钮，可以执行你想要的任何命令。

它是一组可重用、可自定义的步骤序列，能够在你的 Replit App 中运行。它可以简单到只执行 **`python main.py`**，也可以复杂到运行一套多步骤流程。

用例示例：

* 并行运行多个服务 (例如：前端 + 后端)
* 按顺序执行文件或命令 (例如：运行 linter → 运行测试，编译 → 运行代码)

要开始[创建工作流](https:/.replit.com/replit-workspace/workflows#creating-workflows)，请通过工具侧边栏菜单打开工作流面板，或使用 **`Command + K`** 搜索工作流面板。

点击[这里](https:/.replit.com/replit-workspace/workflows)了解更多。
