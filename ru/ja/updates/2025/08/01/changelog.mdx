<div id="agentreplit-docs">
  ### Agent теперь имеет доступ к Replit Docs
</div>

Теперь Agent может мгновенно отвечать на вопросы о функциях и документации Replit. Благодаря прямому доступу к Replit Docs он предоставляет быструю, точную и исчерпывающую помощь прямо там, где вы пишете код.

<div id="section-3">
  ### Обновлённая панель базы данных
</div>

Управляйте базами данных удобнее с обновлённой панелью базы данных. Новый интерфейс упрощает различение базы данных для разработки и продакшен-базы данных, а также оптимизирует рабочие процессы с базами данных.

<div id="section-5">
  ### Улучшенный выбор цвета в визуальном редакторе
</div>

Редактировать цвета в визуальном редакторе Agent стало удобнее. При нажатии на поле ввода шестнадцатеричного кода цвета автоматически открывается палитра, в которой можно легко выбрать нужный цвет.
