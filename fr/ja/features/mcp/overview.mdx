Replit Agent se connecte à des outils et à des sources de données externes via le [Model Context Protocol (MCP)](https://modelcontextprotocol.io), un standard ouvert dédié aux intégrations d&#39;IA. Chacun des serveurs ci-dessous s&#39;installe en un clic : Agent charge automatiquement leurs outils et les utilise au moment opportun.

Pour les concepts, consultez [Model Context Protocol](/fr/ja/learn/model-context-protocol). Pour un guide pratique, consultez [Se connecter via MCP](/fr/ja/build/connect-via-mcp). Pour connecter un serveur qui ne figure pas dans cette liste, consultez [Ajouter un serveur MCP personnalisé](/fr/ja/build/connect-via-mcp#add-a-custom-mcp-server).

<Info>
  Pour installer un serveur, sélectionnez **Ajouter à Replit**. L&#39;éditeur de projet vous invite alors à authentifier la connexion.
</Info>

<div id="section-2">
  ## Protection de sécurité
</div>

Tout le trafic MCP transite par le scanner de sécurité de Replit. Celui-ci évalue les définitions des outils et les plans d&#39;exécution, et bloque les outils suspects ou non sécurisés avant leur exécution. Si un outil est rejeté, Agent vous en informe.

<div id="section-3">
  ## Options d&#39;authentification
</div>

* **Enregistrement dynamique de client OAuth** — si le serveur prend en charge OAuth DCR, Replit détecte et enregistre automatiquement le client. La plupart des serveurs préenregistrés utilisent ce flux.
* **En-têtes personnalisés** — définissez une ou plusieurs paires nom/valeur d&#39;en-tête (par exemple `X-API-Key`). Replit inclut ces en-têtes dans toutes les requêtes, ce qui permet au serveur d&#39;identifier l&#39;appelant. À utiliser lorsque vous ajoutez un serveur personnalisé qui s&#39;authentifie à l&#39;aide d&#39;un jeton statique.

<div id="section-4">
  ## Partager votre lien d&#39;installation
</div>

Un lien d&#39;installation permet d&#39;ajouter votre serveur MCP à Replit en un clic. Vous pouvez le générer à l&#39;aide du formulaire disponible dans [Se connecter via MCP](/fr/ja/build/connect-via-mcp#share-an-install-link), ou le créer vous-même. Encodez la charge utile JSON en base64, puis ajoutez-la à `https://replit.com/integrations?mcp=`.

```json theme={null}
{
  "displayName": "My MCP Server",
  "baseUrl": "https://example.com/mcp",
  "headers": [{ "key": "Authorization", "value": "Bearer your-token" }]
}
```

* **displayName** — le nom affiché lors de l&#39;installation
* **baseUrl** — le point de terminaison HTTPS du serveur MCP
* **headers** — les en-têtes d&#39;authentification facultatifs
