Les modèles d&#39;IA comme Claude et GPT sont puissants, mais ils restent limités aux données sur lesquelles ils ont été entraînés. Le Model Context Protocol (MCP) leur offre un moyen standardisé de se connecter à des outils externes, à des sources de données et à des fonctionnalités concrètes.

<div id="why-ai-models-need-mcp">
  ## Pourquoi les modèles d’IA ont besoin de MCP
</div>

Sans accès à des outils et à des données externes, les modèles d’IA ne peuvent pas :

* Accéder à des informations à jour
* Interagir avec des systèmes externes
* Agir dans le monde réel
* Travailler avec vos données privées

MCP résout ce problème en offrant aux IA un moyen universel de se connecter à des outils et à des données, à l’instar de l’USB-C qui a standardisé les connexions entre appareils.

  <img src="/assets/mirror/mcp-a04e01a01743.avif" alt="Schéma MCP montrant des modèles d’IA connectés à des outils externes et à des sources de données" width="1920" height="1055" data-path="images/tutorials/mcp.avif" />
</Frame>

Avec MCP, les modèles d’IA peuvent :

* Accéder à des outils spécialisés et à des API
* Lire des données provenant de sources privées
* Agir dans le monde réel
* Se connecter facilement à d’autres systèmes

<div id="how-mcp-works">
  ## Fonctionnement de MCP
</div>

L’architecture MCP repose sur trois composants principaux :

1. **Le client** — des modèles d’IA comme Claude ou des applications qui doivent accéder à des outils externes.
2. **La couche de communication** — le protocole lui-même, qui standardise le format des requêtes et des réponses.
3. **Le serveur** — des programmes qui donnent accès à des outils, à des sources de données et à des fonctionnalités spécialisées.

<AccordionGroup>
  <Accordion title="Qu'est-ce qu'un client MCP ?">
    Un client MCP peut être Claude, Replit Agent ou une interface en ligne de commande connectée à un grand modèle de langage. C’est le « point de connexion » aux outils externes ou aux sources de données.

    Exemples de clients MCP :

    * Claude dans le navigateur
    * Replit Agent
    * Interfaces de ligne de commande pour l’IA
    * Applications personnalisées créées avec des SDK d’IA
  </Accordion>

  <Accordion title="Qu'est-ce qu'un serveur MCP ?">
    Un serveur MCP fournit des outils et des fonctionnalités aux modèles d’IA. Voyez-le comme un ensemble d’outils spécialisés mis à la disposition de l’IA pour résoudre des problèmes.

    Exemples de ce que permettent les serveurs MCP :

    * Accéder à des sources de données spécifiques pour répondre à des questions
    * Connecter l’IA à des API afin qu’elle puisse effectuer des actions en ligne
    * Lire ou écrire des fichiers
    * Effectuer des calculs ou exécuter du code
    * Récupérer du contenu depuis des services comme Notion, Linear ou Stripe
  </Accordion>
</AccordionGroup>

<div id="what-mcp-unlocks">
  ## Ce que MCP rend possible
</div>

MCP définit plusieurs primitives qui en font un protocole puissant pour les applications d&#39;IA :

* **Ressources** — partagez des données et du contenu avec les modèles d&#39;IA
* **Outils** — permettez aux modèles d&#39;IA d&#39;effectuer des actions via vos services
* **Prompts** — des modèles réutilisables pour des interactions cohérentes avec l&#39;IA
* **Échantillonnage** — permettez à vos services de solliciter des informations auprès des modèles d&#39;IA
* **Transports** — connectez efficacement les clients et les serveurs

<div id="skills-vs-mcp-servers">
  ## Compétences ou serveurs MCP
</div>

Les compétences et les serveurs MCP sont les deux principaux moyens d&#39;étendre les agents IA — et ils répondent à des besoins différents.

|                | Compétences                                                                                | Serveurs MCP                                                                 |
| -------------- | ------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------- |
| **Idéal pour** | Flux de travail, conventions, documents de référence                                       | Se connecter à des services externes, effectuer des actions                  |
| **Chargement** | Léger — nom + description uniquement jusqu&#39;à l&#39;invocation                          | Plus lourd — toutes les descriptions d&#39;outils sont chargées d&#39;emblée |
| **Définit**    | *Comment* votre agent doit travailler                                                      | *Ce à quoi* votre agent peut accéder                                         |
| **Exemple**    | Compétence « Analyseur d&#39;actions » — étudier des investissements selon un cadre précis | Serveur MCP « Stripe » — lire les données de paiement et d&#39;abonnement    |

Consultez [Compétences Agent](/fr/learn/agent-skills) pour adopter la bonne approche des compétences.

<div id="real-world-applications">
  ## Applications concrètes
</div>

MCP rend possible un large éventail d&#39;applications d&#39;IA :

* **Systèmes de service client** qui accèdent aux bases de données de l&#39;entreprise pour répondre à des questions précises
* **Assistants de recherche** qui recherchent et résument du contenu issu de sources multiples
* **Outils de productivité** qui interagissent avec vos fichiers et vos applications
* **Outils de création de contenu** qui accèdent aux médiathèques et aux plateformes de publication

<div id="benefits">
  ## Avantages
</div>

MCP offre trois avantages majeurs :

* Des intégrations prêtes à l&#39;emploi auxquelles votre IA peut se connecter immédiatement
* La possibilité de changer de fournisseur d&#39;IA sans réécrire vos connexions
* Des fonctionnalités de sécurité qui protègent vos données sensibles

<Note>
  MCP est une norme émergente, de plus en plus prise en charge dans l&#39;écosystème de l&#39;IA. De nouveaux outils et de nouvelles intégrations sont ajoutés régulièrement.
</Note>
