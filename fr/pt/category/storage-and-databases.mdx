Grâce aux solutions de stockage flexibles de Replit, vous pouvez rapidement ajouter la solution de stockage de données idéale pour votre application. Vous pouvez utiliser la base de données ou le stockage d&#39;objets de Replit pour les applications répondant aux exigences suivantes, et Agent peut configurer et intégrer automatiquement ces deux solutions :

* Un jeu qui doit enregistrer des informations sur le joueur, telles que sa progression ou ses meilleurs scores
* Une plateforme de contenu qui gère des fichiers multimédias

<div id="quais-so-as-opes-de-armazenamento-e-banco-de-dados-do-replit">
  ## Quelles sont les options de stockage et de base de données proposées par Replit
</div>

Replit propose les options de stockage de données suivantes :

* **Base de données** : stocke des données structurées, telles que des profils d&#39;utilisateurs, des scores de jeux et des catalogues de produits.
  Vous pouvez stocker ou récupérer des données en fonction de leurs attributs et des relations entre elles.

* **App Storage** : stocke des données non structurées, telles que des images, des vidéos et des documents.
  Vous pouvez stocker et récupérer des fichiers volumineux et des données binaires.

<div id="comparao-entre-app-storage-e-banco-de-dados">
  ### Comparaison entre App Storage et une base de données
</div>

|                             | Base de données                                        | App Storage                                              |
| --------------------------- | :----------------------------------------------------- | :------------------------------------------------------- |
| **Format de données idéal** | Données structurées avec relations                     | Fichiers volumineux (images, vidéos, documents)          |
| **Modèle de données**       | Tables, lignes, colonnes                               | Buckets, fichiers                                        |
| **Langage de requête**      | SQL                                                    | API REST                                                 |
| **Clients**                 | Clients et ORM compatibles avec PostgreSQL             | SDK Replit et bibliothèques clientes GCS                 |
| **Modèle de facturation**   | Paiement du temps de calcul et de l’espace de stockage | Paiement de la bande passante et de l’espace de stockage |
