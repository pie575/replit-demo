<div id="agent">
  ### Agent 自主级别控制
</div>

借助新的自主级别设置，你可以控制 Agent 在项目中的自主程度。可从 Low (仅执行任务清单) 、Medium (增加代码审核) 、High (整个应用审核) 和 Max (完全自主规划) 中选择，以契合你的工作流偏好和项目需求。

<div id="section-3">
  ### 阻断供应链攻击
</div>

增强的安全防护会自动拦截受感染 npm 软件包的数据外泄行为，在不打断工作流的前提下保护开发过程中的敏感信息。

  ### 从成员页面复制邮箱
</div>

在组织的成员管理页面，只需轻轻一点即可直接复制成员的邮箱地址，让团队沟通与管理更高效。

<div id="section-5">
  ### 移动端连接器支持
</div>

Agent 3 推出了 Connectors，可连接 GitHub、Notion 等第三方服务。

现在移动端也已全面支持，你可以直接在移动端将 Connectors 添加到应用中。

如需了解 Connectors 的更多信息，请查看[此处](/zh/replitai/integrations)。

  ### 「Deploy」更名为「Publish」
</div>

我们简化了术语。「Deploy」在整个平台上现已统一称为「Publish」，让你更清晰、更直观地知道项目何时可以分享给全世界。
