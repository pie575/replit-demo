本周，Assistant 正式发布——这款全新的 AI 工具可以编辑多个文件并直接应用更改。

<Note>
  **更新 (2025 年 12 月) ：** Assistant 已停用。如需快速、有针对性的编辑，请使用 [Agent 的 Lite 模式](/zh/pt/core-concepts/agent/agent-modes)。如需讨论和规划，请使用 [Agent 的 Plan 模式](/zh/pt/core-concepts/agent/plan-mode)。
</Note>

Assistant 专为聊天和快速编辑而优化。常见的用法是先用 Agent 搭建 MVP，再用 Assistant 做快速编辑。

以下是 Assistant 的部分亮点：

* **轻量：** Assistant 专为聊天和快速编辑而优化，现在还能编辑多个文件并直接应用更改。
* **提及与截图：** 在提示词中提及文件或 URL，Assistant 可以为你抓取该 URL 或截取截图。
* **回滚：** Assistant 会自动创建 checkpoint，让你轻松以差异对比的形式查看改动，并一键回滚。
* **灵活：** 无论技术栈如何，Assistant 都能在任何 Replit App 中使用。你可以导入现有项目，也可以用 Agent 从零开始。
* **更精美的应用：** 对响应式 React 应用的支持进一步增强，助你打造令人惊艳的应用。
* **计费更新：** Agent 的所有用量限制均已取消，订阅包含的积分也有所提升。

<div id="recursos-do-assistente">
  ### Assistant 功能
</div>

Replit Assistant 是一款轻量级 AI 工具，专为聊天和快速编辑打造。它可以编辑多个文件，并自行直接应用这些更改。

提供上下文时，Assistant 的表现尤为出色——上下文可以是具体的功能、文件 (用 `@file` 提及) 或 URL (直接粘贴即可) 。

Assistant 能帮你更快地迭代，消耗的积分约为 Agent 的五分之一。

<div id="scraping-rpido-capturas-de-tela">
  ### 快速抓取 / 截图
</div>

直接在 **Assistant** 或 **Agent** 的提示词中，对任意网站进行截图或抓取页面内容。

只需粘贴一个 URL，Replit 就会提示你是否要截图或抓取该页面的内容。

一如既往，你可以在提示词中附加图片，或使用 `@file` 提及文件。
