<div id="shopify">
  ### Продажа физических товаров через Shopify
</div>

Теперь вы можете создать интернет-магазин для продажи физических товаров. Попросите Agent построить магазин — он создаст магазин Shopify, добавит товары и настроит корзину и платёж. Когда Agent пришлёт ссылку для получения прав на магазин, оформите тариф Shopify и подключите платёж, чтобы запустить магазин.

<div id="microsoft-fabric">
  ### Создание приложений для работы с данными в Microsoft Fabric
</div>

Теперь вы можете создавать в Replit приложения для работы с данными на базе ИИ и публиковать их прямо в Microsoft Fabric. Начните с шаблона Microsoft Fabric, подключите семантическую модель Power BI и попросите Agent собрать дашборды и внутренние инструменты на основе управляемых корпоративных данных. Политики аутентификации и доступа при этом остаются внутри Fabric.

  ## Рабочее пространство

<div id="dns">
  ### Автоматическая настройка DNS для пользовательских доменов
</div>

Подключить собственное доменное имя стало намного проще. При подключении домена Replit автоматически создаёт нужные DNS-записи через Entri, так что копировать их вручную у своего DNS-провайдера больше не придётся. Просто выберите домен и подтвердите его — остальное Replit возьмёт на себя.

Подробнее о [пользовательских доменах](/ru/ko/features/publishing/custom-domains).

  ## Agent
</div>

<div id="seo-agent">
  ### Улучшение позиций в поиске с помощью SEO Agent
</div>

SEO Agent проверяет опубликованное приложение и выявляет проблемы, из-за которых поисковые системы и ИИ-инструменты не могут его обнаружить. Для каждой найденной проблемы предлагается исправление в один клик, которое можно просмотреть и применить. Чтобы запустить сканирование, откройте в проекте панель **Рост**.

<div id="stripe">
  ### Использование Stripe в совместных рабочих пространствах
</div>

Теперь Stripe работает в совместных рабочих пространствах, так что вся команда может вместе создавать, тестировать и монетизировать одно и то же приложение. Все участники рабочего пространства могут работать с подключённым аккаунтом Stripe, вместо того чтобы настраивать платежи в одиночку.

Подробнее о [платежах через Stripe](/ru/ko/features/monetization/stripe-payments).
