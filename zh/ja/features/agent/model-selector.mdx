借助模型选择器，你可以让 Replit 自动选择模型，也可以自行从可用模型中挑选。

<div id="section">
  ## 智能模型路由
</div>

智能模型路由会在质量与成本之间取得平衡，为每项任务选择合适的模型。当产品中显示 **Auto** 时，表示 Replit 正在使用智能模型路由。

智能模型路由会综合考虑请求的工作内容及其复杂程度。目标明确的请求可以交给成本更低的模型处理，而复杂的工作则可能需要能力更强的模型。随着任务的变化，Replit 也可能改用其他模型。

<Note>
  Free Mode 始终使用智能模型路由。使用 Free Mode 的构建者无法使用模型选择器，也无法手动选择模型。
</Note>

<div id="section-2">
  ## 手动选择模型
</div>

Core 和 Pro 用户可以选择 Power Mode 或 Max Mode 下可用的模型。

1. 在提示框中选择 **Agent Mode**，菜单中会列出可用的模式 (**Free**、**Power**、**Max**) 。
2. 选择 **Power** 或 **Max**，然后找到 **Primary model** 部分。
3. 打开主模型菜单，从列表中选择所需的模型。

<Frame caption="模型选择器弹出窗口，显示 Lite、Economy、Power 模式和 Primary model 列表。此截图取自 Replit Design，Agent 设置的下拉菜单中也有相同的控件。">
  <img src="/assets/mirror/model-selector-6826a87089a2.png" alt="Agent 设置弹出窗口，显示 Lite、Economy、Power 模式、Primary model 列表和 Effort 滑块" width="1432" height="786" data-path="images/design/replit-design/model-selector.png" />
</Frame>

所选模型会应用于下一条消息，你可以随时更改。

<div id="effort">
  ## Effort
</div>

**Effort 是针对每个模型的设置，而非独立模式。** 它用于设置所选模型在每次响应中投入多少推理，范围从 **Low** 到 **Max**。每个模型都会显示推荐设置，你可以仅在任务需要时调高该设置。

<Frame caption="模型列表下方的 Effort 滑块，当前设置为 Medium。">
  <img src="/assets/mirror/model-selector-effort-bcffb01239a8.png" alt="已选择 Claude Fable 5，Primary model 列表中的 Effort 滑块设为 Medium，说明为适合日常任务的均衡推理" width="984" height="832" data-path="images/replitai/model-selector-effort.png" />
</Frame>

请参考各级别说明：

| Effort         | 用途                                  |
| -------------- | ----------------------------------- |
| **Low**        | 以最少的推理实现最快响应。适用于速度最重要、定义明确的日常更改。    |
| **Medium**     | 适合日常任务的均衡推理。若推荐设置未另行指定，这是可靠的默认选择。   |
| **High**       | 提供更深入的推理，适用于更复杂的工作，例如多步骤功能或不太熟悉的领域。 |
| **Extra High** | 提供更扩展的推理，适用于大规模重构或棘手的错误等最困难的问题。     |
| **Max**        | 最大推理深度。成本最高、速度最慢，适用于只追求尽可能最佳结果的情况。  |

调高 Effort 后，Agent 会进行更深入、更谨慎的推理，并调用能力最强的前沿模型，从而提升处理最复杂任务的效果。Agent 会选择性地使用这项额外能力——只有在请求确实困难时才会路由到更强大的模型，不会每次运行都使用。

<Tip>
  Agent 仅会在最困难的工作中使用能力最强的模型，因此调高 Effort 最多会使最具挑战性任务的成本增加约 2 倍，但对于较简单的任务，成本通常几乎不会增加，甚至完全不增加。处理复杂问题时请调高，进行常规更改时则保持较低。
</Tip>

<div id="section-4">
  ## 模型比较
</div>

使用 **模型比较**，你可以让多个模型同时执行同一提示词，无需猜测哪个模型更合适，直接并排比较结果即可。该功能目前处于 Beta 阶段。

要启用此功能，请展开 Agent 模式弹出窗口底部的 **Advanced settings**，然后开启 **Compare models**。

<Note>模型比较仅支持在 Chat 中使用。</Note>

<Frame caption="Advanced settings 中的 Compare models 开关。">
  <img src="/assets/mirror/compare-models-toggle-05429dc46d64.png" alt="Advanced settings 已展开，Compare models 的 Beta 开关处于关闭状态。说明下一条提示词最多可创建 4 个变体" width="1110" height="344" data-path="images/replitai/compare-models-toggle.png" />
</Frame>

开启开关后，最多可添加 **4 个模型** 进行比较。

<Frame caption="已选择 4 个模型进行比较，发送按钮显示 Compare 4。">
  <img src="/assets/mirror/compare-models-9f5bcecec727.png" alt="Compare models 已开启，Agent 模式弹出窗口显示 4 个模型槽位：Kimi K3、Claude Fable 5、Claude Opus 5 和 GPT-5.6 Sol（均可移除），以及显示 Compare 4 的聊天发送按钮" width="1192" height="1930" data-path="images/replitai/compare-models.png" />
</Frame>

下一条提示词会针对每个所选模型分别执行一次，各自生成独立的变体供你比较。

<Note>
  比较中的每个模型都会运行独立的 Agent 并消耗积分，因此运行 Compare 4 的成本大致相当于运行 4 次单独任务。
</Note>
