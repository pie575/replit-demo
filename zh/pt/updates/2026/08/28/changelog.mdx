<div id="roteamento-inteligente-de-modelos">
  ### 智能模型路由
</div>

智能模型路由会自动为你的任务选择最合适的模型和 Effort 级别，兼顾质量与成本。在 **Power** 或 **Max** 模式下，选择 **Auto**，让 Replit 根据复杂度变化为你的各项工作自动路由。你也可以选择特定的模型和 Effort 级别，以获得更精细的控制。

<Frame caption="在 Agent 设置中选择 Auto，或选择模型和 Effort 级别。">
  <img src="/assets/mirror/auto-mode-model-and-effort-selector-fdcabef57097.jpg" alt="Agent 设置中显示 Auto、可用模型和 Effort 控件" width="1839" height="855" data-path="images/chat/auto-mode-model-and-effort-selector.jpg" />
</Frame>

详细了解[智能模型路由](/zh/pt/chat/auto-mode)。

<div id="encontre-seus-primeiros-clientes-com-as-growth-skills">
  ### 借助 Growth Skills 获取首批客户
</div>

让 Agent 运行 [Growth Skills](https://replit.com/growth-kit)，为您的 App 获取首批客户。可用的合作伙伴集成包括 Apollo、Clay、SideShift、RevenueCat、Stripe 和 PostHog。

<Frame caption="探索 Growth Skills，并为您的 App 运行增长策略。">
  <img src="/assets/mirror/growth-skills-55d5f1fd7001.png" alt="Growth Skills 目录，展示 Apollo Cold Email Launch、Pixel and Web Intent，以及 SideShift Consumer and Viral Potential Assessment 增长策略" width="2320" height="1512" data-path="images/changelog/2026-08-28/growth-skills.png" />
</Frame>

<div id="roteamento-inteligente-de-modelos-para-enterprise">
  ### Enterprise 的智能模型路由
</div>

智能模型路由现已成为 Enterprise Workspace 中 Agent 的默认模式。启用 **Auto mode** 后，Replit 会为每项任务选择最佳模式和可用模型。账户管理员可以控制每个 Workspace 中可用的模型，你也可以关闭 **Auto mode** 并选择已启用的模型。Enterprise Agent 的模式菜单现使用 **Power** 和 **Max**，不再提供 **Lite**。

<Frame caption="启用 Auto mode，让 Replit 为每项任务选择最佳模式和模型。">
  <img src="/assets/mirror/enterprise-auto-mode-9365b7d49c0d.png" alt="Agent 设置：已启用 Auto mode，模型锁定为 Auto" width="558" height="356" data-path="images/changelog/2026-08-28/enterprise-auto-mode.png" />
</Frame>

详细了解 [Enterprise 模型控制](/zh/pt/features/collaboration/enterprise-model-controls)。

<div id="personalize-conectores">
  ### 自定义连接器
</div>

Enterprise 组织现在可以为连接器使用自定义 OAuth 配置。例如，您可以使用自己的 **Client ID**、**Client Secret** 和 **scopes** 配置 Gmail，而不是使用 Replit 的默认配置。

<Frame caption="为 Gmail 连接器选择 Use custom configurations。">
  <img src="/assets/mirror/gmail-custom-configuration-43a0bdec6ddb.png" alt="Gmail 连接器设置，已选择 Use custom configurations，并显示 Google Cloud 凭证配置说明" width="1304" height="1564" data-path="images/changelog/2026-08-28/gmail-custom-configuration.png" />
</Frame>

了解如何[为连接器配置自定义 OAuth 应用](/zh/pt/features/integrations/overview#configuring-oauth-app-with-replit)。
