<div id="personal-vs-team-workspaces">
  ## Workspaces personnels et workspaces d&#39;équipe
</div>

Un **workspace** est la structure qui regroupe vos applications, vos membres, vos paramètres et votre facturation. Replit en propose deux types :

* Workspace personnel
* Workspace d&#39;équipe

Voici les différences entre les workspaces personnels et les workspaces d&#39;équipe :

|                         | Workspace personnel                                    | Workspace d&#39;équipe                               |
| ----------------------- | ------------------------------------------------------ | ---------------------------------------------------- |
| **Rôles**               | Admin, invités au niveau du projet                     | Admin, membres, invités au niveau du projet          |
| **Modèle d&#39;accès**  | Vous invitez des personnes sur des projets individuels | Les membres accèdent à tous les projets du workspace |
| **Facturation**         | Votre compte                                           | Crédits mutualisés du compte de l&#39;admin          |
| **Gestion des membres** | Par projet (liens d&#39;invitation)                    | Centralisée depuis les paramètres du workspace       |

Le **workspace personnel** convient parfaitement si vous travaillez seul ou si vous partagez des projets individuels avec d&#39;autres personnes. Vous en êtes l&#39;unique admin, et les autres ne peuvent accéder qu&#39;aux projets sur lesquels vous les invitez en tant qu&#39;invités au niveau du projet.

Le **workspace d&#39;équipe** est idéal lorsque vous développez avec un groupe stable : une équipe de startup, une classe ou un projet client réunissant plusieurs contributeurs. Les membres accèdent à tous les projets du workspace : inutile de les inviter un par un sur chaque projet. Leur gestion est centralisée dans les **paramètres**.

<div id="when-to-invite-to-your-workspace-vs-to-a-project">
  ### Quand inviter dans votre workspace plutôt que dans un projet
</div>

| Scénario                                                          | Que faire                                            |
| ----------------------------------------------------------------- | ---------------------------------------------------- |
| Collaborateur régulier qui doit accéder à tout                    | Invitez-le dans le workspace                         |
| Prestataire ou invité qui n&#39;a besoin que d&#39;un seul projet | [Invitez-le dans le projet](/fr/build/invite-teammates) |
| Nouveau membre qui rejoint votre entreprise                       | Invitez-le dans le workspace                         |
| Ami qui vous aide à déboguer une application précise              | [Invitez-le dans le projet](/fr/build/invite-teammates) |

<div id="create-a-team-workspace">
  ## Créer un workspace d&#39;équipe
</div>

<Frame>
  <img src="/assets/mirror/create-team-workspace-e89eaefd9168.png" alt="Formulaire de création d'un workspace avec un nom de workspace générique et un champ vide pour inviter des membres de l'équipe" width="784" height="300" data-path="images/workspace/create-team-workspace.png" />
</Frame>

<Steps>
  <Step title="Ouvrir le sélecteur de workspace">
    Sur la page d&#39;accueil, cliquez sur le nom de votre workspace en haut à gauche.
  </Step>

  <Step title="Créer un nouveau workspace">
    Sélectionnez **Create workspace**, puis choisissez un nom pour le workspace de votre équipe.
  </Step>

  <Step title="Inviter des membres">
    Saisissez une ou plusieurs adresses e-mail (séparées par des virgules) dans le champ d&#39;invitation. Les personnes invitées reçoivent une invitation et, dès qu&#39;elles l&#39;acceptent, accèdent à tous les projets du workspace.
  </Step>
</Steps>

<div id="managing-members">
  ## Gestion des membres
</div>

Si vous n&#39;avez pas invité de membres lors de la configuration, ou si vous souhaitez en ajouter d&#39;autres par la suite, accédez à **Settings &gt; Workspace collaborators** dans le workspace de votre équipe et invitez des membres par adresse e-mail ou nom d&#39;utilisateur Replit.

<Frame>
  <img src="/assets/mirror/invite-workspace-members-6e3fda413196.jpg" alt="Boîte de dialogue d'invitation d'un utilisateur avec un champ vide pour saisir les adresses e-mail" width="510" height="244" data-path="images/workspace/invite-workspace-members.jpg" />
</Frame>

Depuis la page **Settings**, vous pouvez également :

* **Supprimer des membres** pour révoquer leur accès à l&#39;ensemble des projets du workspace
* **Transférer des projets** depuis des workspaces personnels vers le workspace de l&#39;équipe — voir [Transférer une app vers Teams](/fr/teams/identity-and-access-management/transfer-app-to-teams)

  <Warning>
    Le transfert de projets entre workspaces est temporairement désactivé. Vous ne pouvez pas lancer de nouveau transfert pour le moment.
  </Warning>

Pour la gestion avancée des identités, l&#39;accès basé sur les rôles et les autorisations de groupe, consultez [Pro et Enterprise](/fr/category/teams).
