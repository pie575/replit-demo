<AccordionGroup>
  <Accordion title="Как подключить Resend или другой сервис электронной почты к моему приложению в Replit?">
    Откройте проект и перейдите в **Инструменты → Коннекторы**, найдите нужный сервис (например, Resend) и подключите его. После авторизации ключ API сохраняется в проекте как secret. Если вы настраиваете собственный почтовый домен, добавьте у своего DNS-провайдера DNS-записи, которые укажет сервис.

    Список доступных коннекторов см. в [обзоре интеграций](/ru/pt/features/integrations/overview), а также в разделе [Добавление интеграций](/ru/pt/build/add-integrations).
  </Accordion>

  <Accordion title="Я случайно удалил проект — можно ли его восстановить?">
    Удалённые проекты можно восстановить в течение ограниченного времени. Откройте Shell в любом проекте и выполните:

    ```bash theme={null}
    trash view
    trash restore nome-do-seu-projeto
    ```

    По истечении срока хранения удалённые проекты стираются безвозвратно. Если этот срок уже прошёл, [обратитесь в службу поддержки Replit](https://replit.com/support).
  </Accordion>

  <Accordion title="Как скачать или экспортировать проект из Replit?">
    В меню с тремя точками в верхней части дерева файлов выберите **Скачать как zip**. Для больших проектов скачивание может занять некоторое время. Если скачивание не удалось, откройте Shell и выполните `zip -r project.zip .`, затем скачайте `project.zip` из дерева файлов.
  </Accordion>

  <Accordion title="Как поделиться проектом или добавить соавтора?">
    У вас есть три варианта:

    * **Только чтение** — сделайте проект публичным, чтобы любой, у кого есть ссылка, мог его просматривать.
    * **Доступ к редактированию по приглашению** — выберите **Пригласить**, введите имя пользователя или адрес электронной почты и задайте уровень доступа.
    * **Ссылка для присоединения** — создайте ссылку для присоединения в разделе **Пригласить**, чтобы любой, у кого есть ссылка, мог присоединиться и редактировать проект.

    План Core поддерживает до 5 соавторов, а Pro — до 15; при этом соавторам не нужен платный план, чтобы редактировать ваш проект. См. [Workspaces](/ru/pt/features/collaboration/workspaces).
  </Accordion>

  <Accordion title="Как подключить репозиторий GitHub к Replit?">
    Привяжите учётную запись GitHub в подключённых сервисах своей учётной записи, затем откройте [инструмент Git](/ru/pt/features/workspace-tools/git-interface) в проекте и подключите репозиторий. Чтобы синхронизация была двусторонней, включите автоматическую синхронизацию на панели Git. Об импорте существующего репозитория см. [Импорт от провайдеров](/ru/pt/build/import-from-providers).

    Если синхронизация Git перестала работать, подключите GitHub заново в разделе подключённых сервисов. Персональный токен доступа с детальной настройкой прав обеспечивает более надёжное соединение.
  </Accordion>

  <Accordion title="Мой Repl работает медленно или редактор зависает — что можно попробовать?">
    Если редактор зависает, попробуйте следующее:

    * Выполните принудительное обновление страницы: `Cmd+Shift+R` (Mac) или `Ctrl+Shift+R` (Windows).
    * Закройте неиспользуемые вкладки файлов.
    * Откройте палитру команд с помощью `Cmd+K` (Mac) или `Ctrl+K` (Windows), найдите пункт **Restart compute** и выберите его.
    * Попробуйте другой браузер, чтобы исключить влияние расширений.

    Если дело не в зависании редактора, а в медленном выполнении кода, проверьте ресурсоёмкие циклы и ограничения памяти. Загрузку процессора и памяти можно посмотреть на панели ресурсов в нижней части редактора.
  </Accordion>

  <Accordion title="Как использовать переменные окружения и Secrets в проекте?">
    Откройте инструмент **Secrets** (значок замка), выберите **+ Новый секрет** и введите ключ и значение. Обращайтесь к нему в коде через `process.env.API_KEY` (Node.js) или `os.environ["API_KEY"]` (Python).

    Secrets в разделе разработки [Secrets](/ru/pt/core-concepts/project-editor/app-setup/secrets) доступны только в редакторе. Для развернутых приложений добавьте те же ключи в Secrets развертывания — они намеренно хранятся отдельно.
  </Accordion>

  <Accordion title="Как использовать Secrets аккаунта (Vault)?">
    [Secrets аккаунта](/ru/pt/core-concepts/project-editor/app-setup/secrets) доступны во всех ваших проектах — это удобно для ключей, которые вы используете повторно. Добавьте их в настройках аккаунта, и они будут доступны в каждом вашем проекте. Если один и тот же ключ указан и в Secrets аккаунта, и на панели Secrets проекта, приоритет имеет значение на уровне проекта.
  </Accordion>

  <Accordion title="Как восстановить Git после конфликта при слиянии или повреждения состояния?">
    Откройте Shell и выполните `git status`, чтобы увидеть конфликты.

    <Warning>Следующие две команды удаляют незакоммиченные изменения без возможности отмены. Сначала сохраните всё, что хотите оставить, — например, скопируйте изменённые файлы за пределы проекта.</Warning>

    Чтобы отменить локальные изменения и вернуться к последнему чистому состоянию, выполните `git checkout -- .`; чтобы сбросить состояние до последнего коммита, выполните `git reset --hard HEAD`.

    Если папка `.git` повреждена и команды Git завершаются с ошибкой, откройте новый чат с Agent и вставьте текст ошибки — обычно Agent может восстановить репозиторий. См. [Аварийное восстановление](/ru/pt/features/version-control/disaster-recovery).
  </Accordion>

  <Accordion title="Как откатить проект к предыдущему checkpoint?">
    Replit сохраняет [чекпоинты](/ru/pt/features/version-control/checkpoints-and-rollbacks), пока Agent работает. На панели Agent найдите сообщение, предшествующее изменению, которое нужно отменить, выберите рядом с ним вариант отката и подтвердите действие.

    <Note>
      Replit больше не поддерживает откат опубликованного приложения к предыдущей версии. Чтобы выполнить откат, верните проект к предыдущему чекпоинту (как описано выше), а затем опубликуйте его заново, чтобы развернуть это состояние. Чтобы восстановить отдельный файл, откройте его, выберите его имя и воспользуйтесь пунктом **Показать историю**, чтобы вернуть предыдущую версию. См. [Историю файлов](/ru/pt/features/version-control/file-history).
    </Note>
  </Accordion>

  <Accordion title="Как перенести проект в другую учётную запись Replit?">
    Проекты нельзя перенести напрямую, но их можно скопировать. Самый простой способ — предоставить целевой учётной записи доступ к проекту и создать в ней форк. Также можно скачать проект в виде ZIP-архива и загрузить его в новый Repl в другой учётной записи.

    После копирования настройте Secrets, базу данных и параметры развёртывания в новом проекте — они не копируются. Пошаговые инструкции, включая перенос данных базы данных, см. в разделе [Ручное копирование проекта в другой workspace](/ru/pt/teams/identity-and-access-management/manually-copy-projects).
  </Accordion>
</AccordionGroup>
