## Intégrations

### Vendre des produits physiques avec Shopify

Vous pouvez désormais créer une boutique en ligne qui vend des produits physiques. Demandez à Agent de créer une boutique, et il crée un magasin Shopify pour vous, ajoute vos produits et configure le panier et le paiement. Agent vous remet un lien pour revendiquer la boutique, puis vous vous inscrivez à un plan Shopify et connectez les paiements pour la mettre en ligne.

En savoir plus sur la [connexion à Shopify](/fr/features/integrations/shopify).

### Créer des applications de données sur Microsoft Fabric

Vous pouvez désormais créer des applications de données alimentées par l'IA dans Replit et les publier directement dans Microsoft Fabric. Partez du modèle Microsoft Fabric, connectez un modèle sémantique Power BI et demandez à Agent de créer des tableaux de bord et des outils internes sur vos données d'entreprise gouvernées, avec l'authentification et les politiques d'accès restant dans Fabric.

## Espace de travail

### Les domaines personnalisés configurent leur propre DNS

La connexion de votre propre nom de domaine est désormais beaucoup plus simple. Lorsque vous associez un domaine, Replit configure les enregistrements DNS requis pour vous via Entri, de sorte que vous n'avez plus à copier les enregistrements manuellement chez votre fournisseur de domaine. Choisissez votre domaine, confirmez, et Replit s'occupe du reste.

En savoir plus sur les [domaines personnalisés](/fr/features/publishing/custom-domains).

## Agent

### Améliorez votre classement dans les moteurs de recherche avec SEO Agent

SEO Agent analyse votre application publiée et identifie les problèmes qui empêchent les moteurs de recherche et les outils IA de la découvrir. Chaque constat est accompagné d'un correctif applicable en un clic que vous pouvez examiner et appliquer. Ouvrez le volet **Croissance** de votre projet pour lancer une analyse.

## Facturation

### Utiliser Stripe dans les espaces de travail collaboratifs

Stripe fonctionne désormais dans les espaces de travail collaboratifs, afin que toute votre équipe puisse créer, tester et monétiser la même application ensemble. Tous les membres de l'espace de travail peuvent travailler avec le compte Stripe connecté au lieu de développer les paiements individuellement.

En savoir plus sur les [paiements Stripe](/fr/features/monetization/stripe-payments).
