借助 Whop 集成，Agent 只需一次对话就能为你的应用添加支付功能，无需外部配置，也不需要 API 密钥。Agent 会为你创建 Whop 账户、配置结账流程并编写支付逻辑。Whop 是最快上手销售的方式，因此如果你想尽快达成第一笔成交，它会是不错的选择。

<div id="o-que-voc-pode-construir">
  ## 你可以构建什么
</div>

* 数字内容的付费墙和“解锁”流程
* 会员与社区访问权限
* 订阅与周期性套餐
* 一次性数字产品销售

<div id="como-funciona">
  ## 工作原理
</div>

当你提出要接入支付时,Agent 会在后台完成 Whop 的配置:为你的应用创建 Whop 账户、完成连接,并在项目中搭建结账流程。你无需粘贴任何凭据,也不用离开 Replit 即可开始。

Whop 是 Replit 支持的多家支付服务商之一。Agent 会根据你要构建的内容,帮你挑选最合适的一家:

|          | Whop         | Stripe          | Shopify       | RevenueCat                 |
| -------- | :----------- | :-------------- | :------------ | :------------------------- |
| **最适合**  | 步骤更少,更快开卖    | 灵活性与规模化         | 实物商品          | 原生移动应用                     |
| **可销售**  | 数字产品、会员、订阅 | 一次性付款、订阅、完整店铺   | 带库存和配送物流的实物商品 | 应用内订阅                      |
| **外部配置** | 起步无需任何配置     | 起步无需任何配置        | 起步无需任何配置      | 起步无需任何配置                   |
| **正式上线** | 验证身份(KYC)    | 连接正式的 Stripe 账户 | 认领店铺          | App Store 或 Google Play 审核 |

如果你没有指定服务商,Agent 会根据你的描述推荐一家,并说明各自的利弊。

<div id="como-comear">
  ## 如何开始
</div>

* **让 Agent 添加支付功能**
  * 在首页使用斜杠命令，或直接提出需求：
    <AiPrompt>添加 Whop 支付功能，让我可以在应用中销售会员订阅</AiPrompt>

<Note>
  Whop 集成需要具备后端功能的 App。请在首页选择 **App** 开始。
</Note>

<div id="teste-seus-pagamentos">
  ## 测试支付流程
</div>

1. 在新标签页中打开应用的 **Preview**。
2. 完整走一遍你搭建的结账流程或解锁流程。
3. 在分享应用之前，确认买家端到端的完整体验。

<div id="gerencie-produtos-e-preos">
  ## 管理产品与定价
</div>

你可以通过两种方式管理你的商品：

* **让 Agent 处理**：描述你想要的改动——新增套餐、调整价格、增加产品——Agent 会同步更新你的应用和 Whop 配置。
* **使用 Whop 控制面板**：用你的 Replit 账号邮箱登录 [Whop](https://whop.com)，直接管理产品、价格和套餐。

<div id="acompanhe-seu-saldo-e-receba-pagamentos">
  ## 跟踪余额并收款
</div>

销售收入会累积到你的 Whop 账户中。若要提取收益，请在 Whop 控制面板中完成 Whop 的身份验证 (KYC) 。你可以在完成验证前就开始销售，但必须先通过身份验证才能提现。

<Note>
  Whop 负责结账流程、支付处理、身份验证 (KYC) 和打款。Replit 绝不会收集你的银行资料或税务信息。
</Note>

<div id="perguntas-frequentes">
  ## 常见问题
</div>

<div id="preciso-de-uma-conta-whop-antes-de-comear">
  ### 开始之前需要先有 Whop 账户吗？
</div>

不需要。Agent 会在设置过程中为你的应用创建 Whop 账户。之后你可以用 Replit 账户的邮箱登录 Whop 控制面板，管理产品并提取收益。

<div id="quando-preciso-verificar-minha-identidade">
  ### 我什么时候需要验证身份？
</div>

你可以立即开始构建并销售。Whop 要求你在提取资金前完成身份验证 (KYC) ，该操作可在 Whop 控制面板中完成。

<div id="como-altero-meus-produtos-ou-preos">
  ### 如何更改我的产品或价格？
</div>

让 Agent 帮你修改，或直接在 [Whop 控制面板](https://whop.com)中编辑你的产品和套餐。

<div id="qual-provedor-de-pagamento-devo-usar">
  ### 我应该使用哪个支付服务商？
</div>

Whop 是开始销售数字产品和会员最快捷的方式，无需任何外部配置。如果希望在 Web 应用中获得最大灵活性，可选择 [Stripe](/zh/pt/features/monetization/stripe-payments)；销售实体商品可选择 [Shopify](/zh/pt/features/integrations/shopify)；原生移动应用内的订阅则可选择 [RevenueCat](/zh/pt/features/monetization/revenuecat-subscriptions)。可查看[变现功能概览](/zh/pt/features/monetization/overview)进行对比。
