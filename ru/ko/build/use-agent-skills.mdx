Навыки обучают Agent новому: предпочтительным шаблонам, особенностям библиотек, правилам дизайн-системы и решениям уже найденных проблем. Прикрепите их к сообщению, установите в проект или выберите как отправную точку для нового проекта.

<div id="skill">
  ## Использование навыков в чате
</div>

Самый быстрый способ использовать навыки — прикрепить их к отдельному сообщению. Установка не требуется.

<Frame>
  <img src="/assets/mirror/agent-skills-picker-ee4058454475.png" alt="Открытое кнопкой + рядом с полем ввода чата средство выбора Skill со списком навыков: Ad Creative, AI Recruiter, AI SDR и AI Secretary" width="723" height="529" data-path="images/replitai/agent-skills-picker.png" />
</Frame>

<Steps>
  <Step title="Откройте средство выбора Skill">
    Нажмите кнопку **+** рядом с полем ввода чата и выберите **Use a skill**.
  </Step>

  <Step title="Найдите и выберите Skill">
    Просматривайте навыки по категориям: Business &amp; finance, Creative, Research &amp; analysis и другим. Выберите один или несколько навыков, которые хотите прикрепить к сообщению.
  </Step>

  <Step title="Отправьте сообщение">
    Введите запрос и отправьте его. Agent будет использовать выбранные навыки только для этого сообщения. В сообщении появятся метки навыков, чтобы вы видели, какие из них активны.
  </Step>
</Steps>

Например, прикрепите **Stock Analyzer** и попросите Agent подготовить отчёт об исследовании акций или прикрепите **Deep Research**, чтобы Agent исследовал тему и представил результаты в структурированном виде.

<Tip>
  Навыки, прикреплённые в чате, ничего не устанавливают в проект. Их можно сразу использовать в любом проекте.
</Tip>

<div id="skill-2">
  ## Начните проект с навыка
</div>

При создании нового проекта вы можете выбрать проверенный навык в качестве отправной точки. Agent использует инструкции навыка для настройки проекта.

<Steps>
  <Step title="Откройте выбор отправной точки">
    На экране создания нового проекта нажмите **+** и выберите **Use a skill**.
  </Step>

  <Step title="Выберите навык">
    Ознакомьтесь с подобранными навыками, такими как **AI SDR**, **SEO Auditor**, **Ad Creative** и **Programmatic SEO**. Выберите навык, соответствующий типу приложения, которое вы хотите создать.
  </Step>

  <Step title="Опишите приложение">
    Расскажите Agent, что вы хотите создать. Agent с нуля соберёт проект, применяя шаблоны и правила навыка.
  </Step>
</Steps>

<div id="skill-3">
  ## Установка навыка в проект
</div>

Если хотите, чтобы Agent последовательно применял навык во всех беседах в рамках проекта, установите его. Установленные навыки хранятся в каталоге проекта `/.agents/skills` и сохраняются между сеансами чата.

<div id="skills">
  ### Установка через панель навыков
</div>

Откройте **панель навыков** в Project Editor и выберите вкладку **Discover**, чтобы найти навыки, созданные сообществом. Найдя нужный, нажмите **Install** — он будет автоматически добавлен в проект.

<Frame>
  <img src="/assets/mirror/agent-skills-discover-732b2b0c488a.png" alt="Вкладка Discover навыков с доступными для поиска навыками, созданными сообществом, и кнопкой установки" width="2542" height="1850" data-path="images/replitai/agent-skills-discover.png" />
</Frame>

Например, при создании сайта-портфолио со сложными анимациями можно установить следующее:

* **GSAP React** — обучает Agent анимациям, запускаемым при прокрутке, появлению текста и рисованию SVG-путей
* **Tailwind design system** — предоставляет Agent знания о паттернах Tailwind CSS для типографики, отступов и переходов между представлениями
* **Find skills** — обучает Agent искать и устанавливать новые навыки от вашего имени

<Tip>
  Навыки также можно установить с помощью [npx skills CLI](https://github.com/vercel-labs/skills):

  ```bash theme={null}
  npx skills <skill> -a replit
  ```
</Tip>

<div id="skill-4">
  ### Создание навыка в диалоге
</div>

Самый естественный способ создать навык — обсудить это с Agent. После совместного решения проблемы или изучения новой библиотеки попросите Agent зафиксировать полученные знания:

<AiPrompt>
  Изучи лучшие практики интеграции GSAP с React и создай навык для этого проекта.
</AiPrompt>

Agent использует весь контекст диалога, чтобы создать подробный файл навыка. Это особенно полезно после сеанса отладки, когда вы уже выработали общее понимание проблемы.

<div id="skill-5">
  ### Создание пользовательского навыка
</div>

Для сложных сценариев создавайте навыки самостоятельно в соответствии со [спецификацией Agent Skills](https://agentskills.io/specification). На боковой панели файлов включите **Show Hidden Files**, откройте `/.agents/skills/` и создайте новый Markdown-файл. Это позволит полностью контролировать, что Agent знает и как действует.
