---
title: "Agent 免费模式"
description: "了解免费模式如何让 Starter、Core 和 Pro 订阅者免费使用 Agent。"
---

<Note>
  部分配额细节可能会在发布前调整。
</Note>

免费模式让 Starter、Core 和 Pro 订阅者可以免费使用 Agent。Starter 提供免费模式，但仍受现有限制约束。Core 和 Pro 包含免费模式配额。你可以开启对话进行探索、规划、创建，或寻求帮助。如果某项请求需要使用付费模式或执行付费操作，Replit 会在开始任何可能产生费用的操作前明确告知你。

<div id="por-que-voc-vai-gostar">
  ## 您会喜欢它的理由
</div>

* 通过对话开始，无需经历配置流程。
* 先探索想法并不断推进，再决定是否需要更多容量。
* 当请求涉及付费操作时，始终保持掌控。
* 在免费模式下完成的工作会清晰标注为**免费**。

<div id="como-funciona">
  ## 工作原理
</div>

1. 新建的 Starter、Core 和 Pro 会话默认从免费模式开始。
2. 适合在免费模式下完成的工作会继续进行，无需提示付费操作。
3. 如果付费模式更适合处理某项请求，Agent 会说明原因并提供选择。
4. 您可以仅针对该请求授权使用付费模式，或要求 Agent 继续使用免费模式。
5. 完成一次性付费升级后，系统会恢复为免费模式。

<div id="os-trs-modos-do-agent">
  ## Agent 的三种模式
</div>

<CardGroup cols={3}>
  <Card title="免费">
    Starter、Core 和 Pro 订阅者可免费使用 Agent。
  </Card>

  <Card title="Power">
    适合需要更强能力且注重成本效益的任务的中级付费模式。
  </Card>

  <Card title="Max">
    适合最具挑战性的任务的高级付费模式，采用顶尖模型。
  </Card>
</CardGroup>

Starter、Core 和 Pro 订阅者均可使用免费模式。Starter 包含现有限额的免费模式。Core 和 Pro 包含免费模式配额，其中 Pro 的每周限额更高。需要更多能力时，你也可以选择 Agent 的付费模式。

<Note>
  **如果达到限额：** Starter 包含现有限额的免费模式。对于 Core 和 Pro，免费模式配额每五小时刷新一次，并设有每周限额。查看 **设置 → 使用情况** 以了解你的使用情况。接近限额时，Replit 会提醒你。达到限额后，请切换到付费模式继续使用，或等待配额刷新。
</Note>

<div id="perguntas-comuns">
  ## 常见问题
</div>

<AccordionGroup>
  <Accordion title="免费模式真的免费吗？Replit 现在免费了吗？">
    Starter、Core 和 Pro 订阅均包含免费模式。Starter 包含沿用现有限制的免费模式。Core 和 Pro 则包含一定的免费模式配额。免费模式本身并不是独立的免费套餐。
  </Accordion>

  <Accordion title="这和 Agent 的付费模式一样吗？">
    不一样。免费模式是在配额范围内免费使用 Agent。Power 和 Max 是适用于需要更强能力任务的付费模式。
  </Accordion>

  <Accordion title="Economy 和 Power 怎么了？模式变了吗？">
    付费模式已更名。Economy 现更名为 Power，这是采用强大模型且价格实惠的中档模式。原先名为 Power 的模式现更名为 Max，即最高档模式。现有模式设置将以新名称保留。
  </Accordion>

  <Accordion title="哪个模式能力最强？">
    Max。Power 是以实惠价格提供更强能力的中档付费模式。Max 是适用于最具挑战性任务的最高档付费模式。
  </Accordion>

  <Accordion title="如果我的请求需要付费操作怎么办？">
    Agent 会说明该请求需要付费模式或付费功能，并在继续前征求您的确认。您可以仅批准该请求一次，或继续使用免费模式。
  </Accordion>

  <Accordion title="如果 Agent 建议升级，我会被自动收费吗？">
    不会。付费升级前，必须先获得您的确认。
  </Accordion>

  <Accordion title="我可以拒绝付费选项吗？">
    可以。您可以继续使用免费模式。
  </Accordion>

  <Accordion title="我批准付费升级后会发生什么？">
    此批准仅适用于该请求。之后，您的 Agent 模式会恢复为免费模式。
  </Accordion>

  <Accordion title="为什么我达到限制了？何时会续期？">
    Starter 包含沿用现有限制的免费模式。对于 Core 和 Pro，免费模式配额每五小时续期一次，并设有每周限额。请查看 **设置 → Usage** 了解您的使用情况。达到限制后，您可以切换到付费模式继续使用，或等待配额续期。
  </Accordion>

  <Accordion title="免费模式在 Enterprise 中可用吗？">
    上线时暂不可用。Enterprise workspaces 很快将提供专属的 Agent 体验。您的管理员会提供详细信息。
  </Accordion>
</AccordionGroup>

<div id="mais-sobre-o-modo-gratuito">
  ## 深入了解免费模式
</div>

<AccordionGroup>
  <Accordion title="免费模式和 Lite 是一样的吗？">
    对于 Starter 用户，之前称为 Lite 的体验现已改为免费模式。如果您之前使用 Lite 以较低成本使用模型，关闭 Auto 模式后，仍可在 Power 中手动选择该模型。
  </Accordion>

  <Accordion title="免费模式可以创建完整的 App 吗？">
    可以。您可以在免费模式中创建完整的 App 并持续迭代。
  </Accordion>

  <Accordion title="Free、Power 和 Max 有什么区别？">
    免费模式为 Starter、Core 和 Pro 订阅用户提供无需额外付费的日常 Agent 工作体验。Starter 包含免费模式，但仍受现有限制约束。Core 和 Pro 包含一定的免费模式配额。Power 是价格实惠、能力更强的中级付费模式。Max 是适合最具挑战性任务的高级付费模式。
  </Accordion>

  <Accordion title="何时应切换出免费模式？">
    日常工作请使用免费模式。处理复杂任务时，如果您希望获得更好的结果，或需要免费模式不提供的功能，请切换模式。
  </Accordion>

  <Accordion title="免费模式可以生成视频吗？">
    不可以。视频生成属于付费模式功能，不包含在免费模式中。
  </Accordion>

  <Accordion title="新的 Conversation 体验是什么？">
    Chat 和创建功能现已整合在一起。您可以在同一对话中探索想法、规划工作或启动项目。
  </Accordion>

  <Accordion title="独立 Chat 会成为已部署应用的一部分吗？">
    不会。在您创建或修改项目之前，对话会保持独立。
  </Accordion>

  <Accordion title="免费模式可以处理现有项目吗？">
    可以。它支持对现有项目进行日常维护和编辑。
  </Accordion>
</AccordionGroup>

**准备好试用了吗？** 免费模式推出后，打开与 Agent 的对话即可开始使用。
