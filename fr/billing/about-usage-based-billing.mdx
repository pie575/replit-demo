Il existe trois types de facturation à l'utilisation pour la publication :

1. Transfert de données sortant
2. Unités de calcul Autoscale
3. Requêtes

Vous pouvez consulter votre utilisation dans **Paramètres** sous **Compte** → **Utilisation du compte**. La facturation a lieu mensuellement ou dès que vos coûts accumulés dépassent vos crédits mensuels. Les utilisateurs Replit Core et Pro reçoivent des allocations mensuelles pour ces ressources.

Si vous avez besoin de crédits supplémentaires au-delà de votre allocation d'abonnement mensuel, vous pouvez acheter des packs de crédits sur votre page de facturation. Consultez [Gérer vos dépenses](/fr/billing/managing-spend) pour plus d'informations sur les packs de crédits.

# Publication

## 1. Transfert de données sortant pour la publication

Ce type d'utilisation est facturé par octet, les utilisateurs Replit Core bénéficiant d'une allocation mensuelle. Seules les données en sortie (egress) sont comptabilisées dans cette allocation, ce qui peut entraîner des dépassements. En revanche, les données entrantes (ingress) sont toujours gratuites.

| Abonnement  | Allocation                                                        |
| ----------- | ----------------------------------------------------------------- |
| Replit Core | 100 Gio                                                           |
| Replit Pro  | Voir [la tarification Replit Pro](https://www.replit.com/pricing) |

Les allocations s'appliquent aux déploiements [Statiques](/fr/features/publishing/deployment-types#static), [Autoscale](/fr/features/publishing/deployment-types#autoscale), [VM réservée](/fr/features/publishing/deployment-types#reserved-vm) et [Planifiés](/fr/features/publishing/deployment-types#scheduled).

Consultez la [page de tarification](https://www.replit.com/pricing) pour le prix actuel du transfert de données sortant.

***

## 2. Unités de calcul

Les déploiements Autoscale sont facturés en fonction des unités de calcul, qui prennent en compte à la fois l'utilisation du CPU et de la RAM dans le temps.

Les dépassements sont facturés en fonction des unités de calcul. La granularité de la facturation descend jusqu'à chaque unité de calcul individuelle. Consultez la [page de tarification](https://www.replit.com/pricing) pour le prix actuel des unités de calcul.

Voici une décomposition de la façon dont les secondes de RAM et de CPU d'un déploiement Autoscale se traduisent en unités de calcul :

| Ressource        | Unités de calcul |
| ---------------- | ---------------- |
| 1 seconde de RAM | 2 unités         |
| 1 seconde de CPU | 18 unités        |

Les déploiements statiques ne consomment pas d'unités de calcul. Leur facturation porte uniquement sur les transferts de données sortants au-delà d'un [montant spécifié](#).

[En savoir plus sur les déploiements Autoscale](/fr/features/publishing/deployment-types#autoscale).

***

## 3. Requêtes

Les déploiements Autoscale tiennent également compte du nombre de requêtes effectuées.

Consultez la [page de tarification](https://www.replit.com/pricing) pour le prix actuel des requêtes.

# Bases de données

Replit ne facture que l'utilisation des [bases de données de production](/fr/features/data-and-storage/development-and-production) — les bases de données de développement sont toujours gratuites et incluses avec chaque application Replit. Pour plus de détails sur les bases de données de développement, consultez [Base de données de développement](/fr/features/data-and-storage/sql-database).

Replit PostgreSQL est entièrement géré et sans serveur, offrant une haute disponibilité sans effort et sans maintenance. La facturation des bases de données de production est basée sur l'utilisation réelle, ce qui peut entraîner des économies significatives.

Les bases de données PostgreSQL de production sont facturées selon deux métriques d'utilisation :

* **[Temps de calcul](#compute-time)** : La quantité de ressources de calcul consommées par heure.
* **[Stockage de données](#data-storage)** : Le volume total de données (y compris les données historiques) stockées.

Vous pouvez consulter votre utilisation actuelle des ressources, y compris l'utilisation des bases de données de production, dans **Paramètres** → **Compte** → **Utilisation du compte**.

## Temps de calcul

Le temps de calcul est déterminé par le nombre d'heures pendant lesquelles votre base de données reste active au cours d'une période de facturation donnée. Les bases de données sont considérées comme actives lorsqu'elles reçoivent des requêtes et pendant une période supplémentaire de 5 minutes après la dernière requête. Si une base de données reste inactive pendant 5 minutes, elle sera suspendue et entrera dans un état inactif.

## Stockage de données

Le stockage de données est le volume total de données stockées dans toutes les bases de données de votre compte, mesuré en gibioctets (Gio). Le stockage est calculé comme la quantité maximale de stockage utilisée par mois. Chaque base de données PostgreSQL consomme 33 Mo de stockage, même si elle ne contient aucune donnée. C'est l'empreinte de stockage par défaut du serveur Postgres.

<Note>La limite de stockage totale pour chaque base de données de production est de 10 gibioctets (Gio). Les bases de données de développement incluent 20 Gio de stockage gratuit par application Replit.</Note>

# Notes supplémentaires

En cas de problème avec votre mode de paiement, nous vous en informerons. Des échecs de paiement continus pourraient entraîner la suspension de vos applications publiées. Si cela se produit, veuillez [contacter le support](https://replit.com/help) et mettre à jour vos informations de paiement pour retrouver l'accès à nos services.
