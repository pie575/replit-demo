<div id="recursos">
  ## 功能
</div>

<div id="casos-de-uso-suportados">
  ### 支持的用例
</div>

**现已推出：**

* **Slack Agent** —— 创建智能 Slackbot，用于回答问题、集成 API 并自动执行任务
* **Telegram Agent** —— 构建 Telegram 机器人，用于客户服务、调度、娱乐等场景
* **定时自动化** —— 配置按指定时间自动运行的调度工作流

**即将推出：**

* **自定义 webhook 触发器**：通过 webhook URL 响应任何外部事件或 API 调用

<div id="funcionalidades-adicionais">
  ### 更多功能
</div>

* **丰富的集成**：可连接 Outlook、Spotify、Notion、Linear、GitHub 等众多服务
* **测试环境**：在部署前测试 Agent 并可视化查看工作流
* **云端部署**：自动配置为 24/7 全天候可用，支持 Autoscale 部署或定时部署

<div id="como-comear">
  ## 如何开始
</div>

<div id="passo-1-selecione-agents-automaes">
  ### 第 1 步：选择 Agents &amp; Automações
</div>

登录后，在 Replit 首页的应用类型选择器中**选择“Agents &amp; Automações”**。

<Frame>
  <img src="/assets/mirror/agents-automations-homepage-2-b2bb064da3b0.png" alt="Replit 首页显示带 Beta 标识的 Agents & Automações 选项以及 prompt 输入区域" width="3024" height="1720" data-path="images/replitai/agents-automations-homepage-2.png" />
</Frame>

<div id="passo-2-escolha-o-tipo-de-trigger">
  ### 第 2 步：选择触发器类型
</div>

接下来，你会看到触发器类型选择器。请从以下受支持的选项中选择：

* **Slack** —— 创建可与你的 workspace 集成的智能 Slackbot
* **Telegram** —— 构建适用于各种场景的 Telegram 机器人
* **定时自动化** —— 配置自动运行的定时工作流

<div id="passo-3-insira-seu-prompt">
  ### 第 3 步：输入你的 prompt
</div>

**输入你的 prompt**，描述你希望 Agent 完成的任务。

<div id="passo-4-deixe-o-agent-construir-sua-automao">
  ### 第 4 步：让 Agent 构建你的自动化
</div>

Agent 会根据你的 prompt 和所选的触发器类型创建自动化，包括所需的各项集成和部署配置。

<Frame>
  <img src="/assets/mirror/agent-automations-testing-environment-0665d9cb600a.png" alt="Agent 测试环境，显示带有工作流可视化和测试界面的 StockReporter 自动化" width="3456" height="1984" data-path="images/replitai/agent-automations-testing-environment.png" />
</Frame>

<Accordion title="访问 Agents & Automações 面板">
  项目创建完成后，你会在项目编辑器中看到一个**专用的 Agents &amp; Automações 面板**：

  * **位置**：在项目编辑器的预览区域下方展开
  * **功能**：
    * 查看 agent 并与之交互
    * 在部署前测试聊天机器人功能
    * 查看自动化工作流
    * 监控日志并排查问题
  * **测试**：直接在面板中与 agent 对话，测试其响应和行为
</Accordion>

<div id="requisito-de-implantao">
  ### 部署要求
</div>

<Warning>
  **需要部署**：您的 Agent 或自动化必须先完成部署，才能配合 Slack、Telegram 等外部触发器或定时自动化运行。测试面板可用于开发和测试，但正式触发器需要先完成部署。
</Warning>

当项目准备就绪时，Agent 会自动提示您进行部署。请选择合适的部署类型：

* **Autoscale 部署** —— 适用于聊天机器人和事件驱动型工作流
* **定时部署** —— 适用于基于时间的自动化

<div id="casos-de-uso-e-exemplos-suportados">
  ## 支持的用例和示例
</div>

<div id="exemplos-de-slack-agent">
  ### Slack Agent 示例
</div>

**集成 Perplexity 的研究助手**

<AiPrompt>
  创建一个 AI 驱动的 Slackbot 助手，能够使用 Perplexity API 回答研究类问题。当有人在 #研究 频道提问时，它应当检索最新信息，并给出附带来源的完整回答。
</AiPrompt>

**集成 GitHub 的 代码库 问答**

<AiPrompt>
  创建一个 AI 驱动的 Slackbot，能够通过 GitHub 集成回答关于我的 代码库 的问题。它应当能够解释函数、查找文件，并通过分析我们的仓库协助调试。
</AiPrompt>

**集成 Outlook 的邮件助手**

<AiPrompt>
  创建一个 AI 驱动的 Slackbot，能够回答关于我的 Outlook 邮件的问题。它应当帮我查找特定邮件、总结往来内容，并针对常见的邮件问题给出快速回复。
</AiPrompt>

<div id="exemplos-de-telegram-agent">
  ### Telegram Agent 示例
</div>

**具备日历调度功能的商务助手**

<AiPrompt>
  创建一个 AI 商务助手，能够把邮件安排到我的 Outlook 日历中。
  用户可以请求会议时间，机器人会找出
  空闲时段并发送日历邀请。
</AiPrompt>

**基于 Spotify 的音乐推荐机器人**

<AiPrompt>
  做一个有趣的 AI 聊天机器人，只要我发消息描述想要的氛围，
  它就能推荐一首 Spotify 歌曲。它应该能读懂心情描述，并推荐
  最合适的曲目。
</AiPrompt>

**虚构角色机器人**

<AiPrompt>
  做一个扮演虚构角色的 AI 机器人——具体来说是夏洛克·福尔摩斯。
  它应该始终以角色口吻回复消息、解开谜题，并展开
  侦探风格的对话。
</AiPrompt>

<div id="exemplos-de-automao-temporizada">
  ### 定时自动化示例
</div>

**每日 Linear 任务摘要**

<AiPrompt>
  每天早晨向我发送一封电子邮件，汇总我新增的 Linear 任务。包括
  任务优先级、截止日期和项目背景，帮助我规划当天的工作。
</AiPrompt>

**电子邮件摘要自动化**

<AiPrompt>
  每 6 小时向我发送一封电子邮件，汇总我收到的所有电子邮件。按
  重要程度分组，并突出显示任何需要立即处理的紧急邮件。
</AiPrompt>

**每周竞争对手分析**

<AiPrompt>
  每周一上午 8 点，使用网页搜索向我发送一份关于我
  竞争对手相关新闻的摘要。重点关注产品更新、融资新闻和
  市场动态。
</AiPrompt>
