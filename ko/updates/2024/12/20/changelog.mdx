<div id="custom-prompts">
  ### 커스텀 prompt
</div>

<Note>
  **업데이트(2025년 12월):** Assistant는 지원이 중단되었습니다. 빠르고 정확한 편집이 필요하다면 [Agent의 Lite 모드](/ko/core-concepts/agent/agent-modes)를 사용하세요.
</Note>

커스텀 prompt를 사용하면 Assistant의 동작 방식을 원하는 대로 완전히 제어할 수 있습니다. 특정 코딩 표준을 설정하는 것부터 Assistant 기본값을 변경하는 것까지 커스텀 prompt 하나로 해결됩니다.

예를 들어 다음과 같은 내용을 추가할 수 있습니다:

* 특정 코딩 스타일이나 프레임워크
* 특정 문제 해결 기법
* package 관리 방식 선호도

예를 들어, 다음과 같이 추가할 수 있습니다:

```
use pnpm for package management
use motion/react instead of framer-motion
always use claude-3-5-sonnet-20241022 as your model
```

<div id="workflows">
  ### Workflows
</div>

Workflow는 원하는 명령을 무엇이든 실행할 수 있도록 간편하게 구성할 수 있는 &quot;Run&quot; 버튼입니다.

Workflow는 Replit App 안에서 실행할 수 있는, 재사용 및 커스터마이즈가 가능한 단계 모음입니다. **`python main.py`** 실행처럼 단순할 수도 있고, 여러 단계로 이루어진 절차를 실행할 만큼 복잡할 수도 있습니다.

사용 사례 예시:

* 여러 서비스를 병렬로 실행(예: frontend + backend)
* 파일이나 명령을 순차적으로 실행(예: 린터 실행 → 테스트 실행, 컴파일 → 코드 실행)

[workflow 만들기](https:/.replit.com/replit-workspace/workflows#creating-workflows)를 시작하려면 도구 사이드바 메뉴에서 Workflows pane으로 이동하거나, **`Command + K`**로 Workflows pane을 검색하세요.

자세한 내용은 [여기](https:/.replit.com/replit-workspace/workflows)에서 확인하세요.
