Les contrôles de modèle Enterprise permettent aux administrateurs de compte de gérer les modèles Agent que les créateurs peuvent sélectionner. Définissez une politique au niveau du compte, puis configurez différents accès aux modèles pour chaque Workspace.

<Note>
  Les contrôles de modèle sont réservés aux administrateurs de compte des comptes Enterprise. Contactez notre équipe commerciale à l’adresse [sales@replit.com](mailto:sales@replit.com) pour les activer dans votre organisation.
</Note>

<div id="usar-o-roteamento-inteligente-de-modelos">
  ## Utiliser le routage intelligent des modèles
</div>

Le routage intelligent des modèles est l’expérience par défaut d’Agent pour les Workspaces Enterprise. Lorsque le **mode Auto** est activé, Replit choisit le mode et le modèle les plus adaptés à chaque tâche, en conciliant qualité et coût.

Le routage sélectionne parmi les modèles autorisés par les politiques du compte et du Workspace. Les fournisseurs et les modèles qui ne font pas partie de cet ensemble ne sont pas éligibles à la sélection. Les créateurs peuvent laisser le **mode Auto** activé ou le désactiver afin de sélectionner manuellement un modèle autorisé.

<div id="abrir-as-configuraes-de-modelo-do-agent">
  ## Ouvrir les paramètres des modèles de l’Agent
</div>

1. Ouvrez **Paramètres**.
2. Dans **Compte**, sélectionnez **Avancé**.
3. Développez **Modes Agent et fournisseurs de modèles**.

<div id="definir-uma-poltica-de-provedor">
  ## Configurer une politique de fournisseur
</div>

<Steps>
  <Step>
    Sélectionnez le fournisseur de modèles que vous souhaitez gérer.
  </Step>

  <Step>
    Dans **Account policy**, sélectionnez une option :

    | Option              | Résultat                                                                   |
    | ------------------- | -------------------------------------------------------------------------- |
    | **Enable all**      | Tous les modèles du fournisseur sont disponibles dans tous les Workspaces. |
    | **Enable selected** | Vous choisissez les modèles disponibles pour chaque Workspace.             |
    | **Disabled**        | Aucun Workspace ne peut utiliser les modèles de ce fournisseur.            |

    <Note>
      Au moins un modèle d’OpenAI, d’Anthropic et de Google doit rester activé. Vous pouvez désactiver les autres fournisseurs.
    </Note>
  </Step>

  <Step>
    Sélectionnez **Update**.
  </Step>
</Steps>

Les fournisseurs de modèles open source sont désactivés par défaut. Pour en activer un, sélectionnez **Enable all** ou **Enable selected**, puis sélectionnez **Update**.

<div id="definir-uma-poltica-de-workspace">
  ## Définir une politique de Workspace
</div>

Utilisez **Enable selected** lorsque différents Workspaces doivent avoir accès à différents modèles.

<Frame caption="La politique du fournisseur Anthropic est définie sur Enable selected, avec l’accès aux modèles configuré par Workspace.">
  <img src="/assets/mirror/anthropic-account-policy-workspace-models-38c0f71a609d.jpg" alt="Politique de compte Anthropic définie sur Enable selected avec des boutons bascule pour les modèles d’un Workspace" width="2000" height="930" data-path="images/workspace/anthropic-account-policy-workspace-models.jpg" />
</Frame>

1. Ouvrez les paramètres du fournisseur.
2. Définissez **Account policy** sur **Enable selected**.
3. Dans la liste **Workspace**, sélectionnez le menu déroulant **Setting** d’un Workspace.
4. Activez ou désactivez chaque modèle pour ce Workspace.
5. Sélectionnez **Update**.

Avant de sélectionner **Update**, vous pouvez sélectionner **Copy to all** pour appliquer la
sélection de modèles du Workspace actuel à tous les Workspaces du compte.

<div id="limitaes">
  ## Limitations
</div>

* Les politiques de modèles s’appliquent aux Workspaces. Il n’est pas possible de définir une politique différente pour un groupe d’utilisateurs au sein d’un même Workspace.
* Le routage intelligent des modèles ne remplace pas les politiques du compte ou du Workspace. Il ne peut pas sélectionner un fournisseur ou un modèle désactivé.
* Le bouton **Modèles du Fast mode** dans **Modes Agent et fournisseurs de modèles** contrôle l’accès aux variantes de modèles rapides dans tous les Workspaces du compte. Les politiques des fournisseurs et le routage intelligent des modèles ne modifient pas ce paramètre.
