<div id="o-que-um-remix">
  ## Qu&#39;est-ce qu&#39;un Remix ?
</div>

Un **Remix** est une nouvelle Replit App que vous créez à partir d&#39;une app à laquelle vous avez déjà accès. Lorsque vous remixez une app publique ou un template, vous en obtenez votre propre copie, que vous pouvez explorer et améliorer de manière itérative. Les modifications apportées à votre Remix n&#39;affectent en rien l&#39;app d&#39;origine.

Votre Remix crédite sa source : il affiche un lien **Remixed from** renvoyant à l&#39;original, et le prompt de création de ce dernier apparaît sur votre page de couverture.

<div id="o-que-seu-remix-inclui">
  ## Ce que contient votre Remix
</div>

Un Remix est une copie complète et fonctionnelle, clairement séparée de l&#39;original :

* **Tous les fichiers et paramètres** sont copiés, afin que l&#39;app fonctionne exactement comme l&#39;original.
* **L&#39;historique des checkpoints de l&#39;original** est inclus, identifié comme l&#39;historique de l&#39;app source. Vous pouvez revenir à n&#39;importe lequel de ces checkpoints ; la conversation qui les a produits, elle, reste rattachée à l&#39;original.
* **Un Agent entièrement nouveau.** Votre Remix démarre avec un Agent neuf, sans historique de chat hérité.
* **Les noms des secrets, pas les valeurs.** Si l&#39;app utilise des secrets (comme des clés d&#39;API), votre Remix les liste avec des valeurs vides, pour que vous sachiez quoi renseigner. Les valeurs ne sont copiées que lorsque vous remixez votre propre app.
* **Une base de données neuve.** Votre Remix ne se connecte jamais à la base de données de l&#39;original. Si l&#39;original le propose, l&#39;option **Copy data from original App** copie les données elles-mêmes ; vos modifications n&#39;affectent pour autant jamais la source.
* **Une nouvelle configuration de connexion** pour les apps qui utilisent Replit Auth.

Ne sont pas copiés : les deployments, les domaines et les paramètres des connecteurs, que vous configurez dans votre propre copie. Les Remixes démarrent également en mode privé : rien n&#39;est donc partagé tant que vous ne décidez pas de publier.

<div id="como-fazer-remix-de-um-app">
  ## Comment remixer une app
</div>

<Steps>
  <Step title="Ouvrez la page de couverture de l'app">
    Trouvez une app que vous souhaitez remixer, par exemple dans la [communauté](https://replit.com/community/all). Sa page de couverture affiche un aperçu en direct et des options de partage.
  </Step>

  <Step title="Remixez l'app">
    Sélectionnez **Remix this App** pour commencer à créer votre propre version.
  </Step>

  <Step title="Renseignez les détails de l'app">
    Dans la boîte de dialogue **Remix App**, donnez un nom à votre copie ainsi qu&#39;une description facultative, puis sélectionnez **Remix App**. Vous pourrez modifier ces détails plus tard.

<div id="continue-construindo-no-seu-remix">
  ## Continuez à développer votre Remix
</div>

Une fois votre Remix ouvert dans le workspace, utilisez Agent pour le modifier et l&#39;enrichir. Saisissez dans l&#39;onglet **Agent** un prompt décrivant la fonctionnalité que vous souhaitez ajouter.

Pour annuler les modifications d&#39;Agent, sélectionnez **Rollback to here** sur le checkpoint créé après la modification. Pour en savoir plus, consultez [Checkpoints et rollbacks](/fr/pt/features/version-control/checkpoints-and-rollbacks).

<div id="remix-ou-construir-a-partir-de-um-prompt">
  ## Remixer ou construire à partir d&#39;un prompt ?
</div>

Les deux chemins mènent au même résultat : une app qui vous appartient et que l&#39;Agent vous aide à faire évoluer. Seul le point de départ change :

|                                | Remix                                           | Construire à partir d&#39;un prompt                        |
| ------------------------------ | ----------------------------------------------- | ---------------------------------------------------------- |
| Point de départ                | Une app fonctionnelle, copiée à l&#39;identique | Une app que l&#39;Agent crée à partir de votre description |
| Premier résultat               | Immédiat et identique à la source               | Plus long à obtenir, et variable                           |
| Première action de l&#39;Agent | Il attend vos instructions                      | Il planifie et construit à partir de votre prompt          |

S&#39;il existe déjà une app proche de ce que vous recherchez, remixez-la : le premier tour de l&#39;Agent porte alors sur une app réelle et fonctionnelle plutôt que sur un projet vierge. Construisez à partir d&#39;un prompt lorsque votre idée ne ressemble à rien de ce que vous pouvez trouver.
