<div id="workspace-security-center-20">
  ### Workspace Security Center 2.0
</div>

Просматривайте уязвимости в зависимостях и принимайте меры во всех проектах вашего Workspace из одного места. Workspace Security Center теперь сразу выделяет проекты с наибольшим риском и позволяет искать и фильтровать затронутые проекты по степени критичности, статусу публикации, видимости и владельцу. Вы также получаете полный цикл устранения уязвимостей, не покидая Security Center: запустите задачу Agent, проверьте предложенное исправление, а затем повторно опубликуйте проект. Вы можете уведомлять владельцев проектов по отдельности или массово, мгновенно снимать с публикации проекты с высокой подверженностью и скачивать SBOM для аудитов соответствия.

<div id="publicao-privada-para-todos">
  ### Приватная публикация для всех
</div>

Ранее приватная публикация приложений с защитой паролем была доступна только на тарифах Pro и Enterprise. Теперь разработчики на тарифах Core и Starter также могут публиковать приложения приватно, чтобы скрыть за входом через Replit внутренний инструмент, бета-версию приложения или незавершённый проект.

Подробнее о [приватных развёртываниях](/ru/pt/cloud-services/deployments/private-deployments).

<div id="tokens-de-acesso-externo-para-deployments-privados">
  ### Токены внешнего доступа для приватных развёртываний
</div>

Токены внешнего доступа теперь доступны для приватных Replit App. Создавайте токены для настройки интеграций — Slack, GitHub, Twilio и других сервисов, — которым нужен доступ к вашим приватным развёртываниям без использования коннекторов. Они дают опытным пользователям больше контроля над приложениями и делают приватные Replit App ещё безопаснее. Откройте **Настроить параметры** в настройках развёртывания и перейдите на новую вкладку **Токены внешнего доступа**.

Подробнее: [Токены внешнего доступа](/ru/pt/cloud-services/deployments/external-access-tokens).

<div id="notas-do-apresentador-e-modo-apresentao-em-slide-decks">
  ### Заметки докладчика и режим презентации в слайд-презентациях
</div>

Слайд-презентации теперь поддерживают заметки докладчика и специальный режим презентации. Заметки синхронизируются в реальном времени между редактором и окном презентации в обоих направлениях, поэтому вы можете удалённо управлять презентацией с одного устройства, демонстрируя экран с другого. Попросите Agent написать заметки за вас, а затем доработайте их в редакторе, пока аудитория видит только слайд. Режим презентации также доступен на мобильных устройствах в карточке артефакта презентации.

<div id="agent-aceita-uploads-de-svg">
  ### Agent поддерживает загрузку SVG
</div>

Теперь вы можете прикреплять SVG-файлы к Agent. Перетащите SVG-файл в Chat или вставьте URL — Agent прочитает его разметку так же, как и у любого другого вложения. Файлы очищаются в браузере до отправки в Agent или хранилище, поэтому распространённые векторы атак на основе SVG автоматически удаляются.
