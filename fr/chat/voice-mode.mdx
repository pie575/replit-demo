Décrivez ce que vous souhaitez créer à voix haute avec le Mode Voix. Appuyez sur le microphone dans la zone de chat d'Agent, parlez votre prompt, et Replit transcrit votre discours en texte modifiable. Vérifiez le texte, apportez les modifications nécessaires, et envoyez-le comme n'importe quel autre message.

Le Mode Voix est utile quand taper est lent ou inconfortable — particulièrement sur mobile, où dicter un prompt complet est souvent plus rapide que le taper avec les pouces.

<Note>
  Le Mode Voix transforme votre discours en texte dans la zone de chat. Il ne lit pas les réponses d'Agent à voix haute — vous envoyez toujours un message écrit, et Agent répond dans le chat comme d'habitude.
</Note>

## Comment ça fonctionne

  <img src="/assets/mirror/voice-mode-mic-button-fe7da6953736.png" alt="La zone de chat d'Agent avec le bouton microphone mis en évidence et une info-bulle « Démarrer la saisie vocale », à côté de la case à cocher Plan et la flèche d'envoi" width="1853" height="423" data-path="images/replitai/voice-mode/voice-mode-mic-button.png" />
</Frame>

Le Mode Voix enregistre votre discours, le transcrit et insère le résultat dans la zone de chat pour que vous puissiez le vérifier avant d'envoyer :

1. Ouvrez Agent et sélectionnez le microphone dans la zone de chat.
2. Autorisez l'accès au microphone si votre navigateur ou appareil vous y invite.
3. Parlez votre prompt. Une forme d'onde indique qu'Agent enregistre.
4. Arrêtez l'enregistrement lorsque vous avez terminé. L'enregistrement s'arrête aussi automatiquement après une pause ou lorsque vous quittez l'onglet.
5. Attendez brièvement pendant la transcription de votre discours.
6. Vérifiez le texte transcrit, modifiez-le si nécessaire, puis envoyez votre message.

Étant donné que la transcription apparaît comme du texte ordinaire dans la zone de chat, vous pouvez mélanger librement la voix et la frappe — dictez une partie d'un prompt, puis tapez le reste, ou corrigez un mot avant d'envoyer.

<Tip>
  Parlez naturellement. Le Mode Voix se concentre sur la capture de ce que vous voulez dire plutôt que sur la transcription littérale de chaque mot, donc les mots de remplissage comme « euh » et « hm » sont omis du résultat.
</Tip>

## Où vous pouvez l'utiliser

Le Mode Voix est disponible dans la zone de chat d'Agent :

* Dans l'**Éditeur de projet** lorsque vous travaillez avec Agent sur une application.
* Lors du **démarrage d'une nouvelle application** depuis le prompt Agent sur l'écran d'accueil.

Vous pouvez utiliser le Mode Voix sur le web desktop, le web mobile et l'application mobile Replit.

## Bon à savoir

Gardez ces détails à l'esprit lors de l'utilisation du Mode Voix :

| Détail                 | Ce à quoi s'attendre                                                                                                                                                                                  |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Durée d'enregistrement | Enregistrez jusqu'à 6 minutes à la fois. Un avertissement s'affiche peu avant la limite.                                                                                                              |
| Arrêt automatique      | L'enregistrement s'arrête automatiquement après environ 30 secondes de silence, ou lorsque vous changez d'onglet ou mettez l'application en arrière-plan.                                             |
| Révision avant envoi   | Le texte transcrit apparaît dans la zone de chat pour que vous puissiez le lire et le modifier avant d'envoyer — rien n'est envoyé automatiquement.                                                   |
| Accès au microphone    | Le Mode Voix a besoin de la permission d'utiliser votre microphone. Si l'enregistrement ne démarre pas, vérifiez que votre navigateur et votre appareil autorisent l'accès au microphone pour Replit. |

## Disponibilité

Le Mode Voix est disponible sur tous les abonnements Replit. Le microphone apparaît dans la zone de chat d'Agent sur les navigateurs et appareils qui prennent en charge l'enregistrement audio, et la permission du microphone vous sera demandée la première fois que vous enregistrez.
