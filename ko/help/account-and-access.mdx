여기서는 계정 액세스와 보안에 관한 질문의 답변을 다룹니다. 계정 삭제에 대한 자세한 내용은 [데이터 삭제하기](/ko/legal-and-security-info/deleting-your-data)를, 정지에 대해서는 [스트라이크 시스템 FAQ](/ko/legal-and-security-info/strike-system-faq)를 참조하세요.

<AccordionGroup>
  <Accordion title="비밀번호를 어떻게 재설정하나요?">
    1. [replit.com/forgot](https://replit.com/forgot)으로 이동합니다.
    2. 계정에 연결된 이메일 주소를 입력합니다.
    3. `notifications@replit.com`에서 보낸 재설정 이메일을 엽니다. 메일이 보이지 않으면 스팸함을 확인하세요.
    4. 링크를 선택한 후 새 비밀번호를 설정합니다.

    Google, GitHub, Facebook 또는 Apple 계정으로 가입한 경우에도 같은 페이지에서 별도의 비밀번호를 설정할 수 있습니다. 이메일이 오지 않는다면 가입할 때 사용한 이메일 주소를 정확히 입력했는지 확인하세요.
  </Accordion>

  <Accordion title="로그인할 수 없습니다. 계정에 다시 액세스하려면 어떻게 해야 하나요?">
    다음 방법을 순서대로 시도해 보세요.

    1. [replit.com/forgot](https://replit.com/forgot)에서 비밀번호를 재설정한 후, 스팸 폴더에 메일이 있는지 확인하세요.
    2. Google, GitHub 또는 Apple 계정으로 가입했다면, 이메일과 비밀번호 입력 양식 대신 **[provider] 계정으로 계속하기** 버튼을 사용하세요.
    3. 가입할 때 사용한 이메일이 맞는지 확인하세요. 다른 이메일로 가입했을 수도 있습니다.

    이 방법으로도 해결되지 않으면 [Replit Support에 문의](https://replit.com/support)하세요.
  </Accordion>

  <Accordion title="다른 사람의 프로젝트가 보이거나, 내 허가 없이 내 계정에 접근한 것 같습니다">
    신속하게 조치하세요:

    1. [replit.com/forgot](https://replit.com/forgot)에서 비밀번호를 재설정하세요.
    2. 계정 보안 설정에서 활성 상태인 다른 세션을 모두 로그아웃하세요.
    3. 발견한 내용을 자세히 정리해 [Replit Support에 문의하세요](https://replit.com/support).

    본인의 것이 아닌 프로젝트가 보인다면 다른 계정으로 로그인했을 수 있으니, 오른쪽 상단의 계정 이름을 확인하세요.
  </Accordion>

  <Accordion title="이메일 주소 또는 사용자 이름은 어떻게 변경하나요?">
    사용자 이름을 변경하려면 [CLUI](/ko/features/workspace-tools/clui-graphical-cli)에서 `account > change-username` 명령을 실행한 후 새 사용자 이름을 입력하세요. 사용자 이름은 한 번만 변경할 수 있습니다.

    이메일을 변경하려면 **Settings → Profile**로 이동한 후 이메일을 수정하세요. identity verification을 완료할 수 없는 경우, 현재 이메일 주소와 새 이메일 주소를 함께 기재하여 [Replit Support에 문의하세요](https://replit.com/support).
  </Accordion>

  <Accordion title="Replit 계정을 영구적으로 삭제하려면 어떻게 하나요?">
    보관하려는 항목은 먼저 다운로드하세요. 삭제한 데이터는 복구할 수 없습니다. 웹에서는 사용 중인 구독을 먼저 취소한 다음 **Settings → Profile**로 이동해 계정 삭제를 요청하세요. 모바일에서는 Replit 앱에서 **Account → More → Delete account**로 이동하세요. 자세한 내용은 [데이터 삭제하기](/ko/legal-and-security-info/deleting-your-data)를 참고하세요.
  </Accordion>

  <Accordion title="같은 이메일 주소로 Replit 계정이 두 개 있는 것 같은데, 어떻게 해야 하나요?">
    이런 문제는 처음에 한 가지 방법(예: 이메일)으로 가입한 뒤 나중에 다른 방법(예: Google)으로 로그인하면서 두 번째 계정이 생길 때 발생합니다.

    1. 두 가지 방법으로 각각 로그인해 계정이 두 개인지 확인하세요.
    2. 어떤 계정을 유지할지 결정하세요.
    3. 삭제할 계정에 있는 projects를 옮기세요. **Download as zip**을 사용하거나 fork하면 됩니다.
    4. 필요 없는 계정은 **Settings → Profile**에서 삭제하세요.

    어느 계정에 구독이나 projects가 있는지 확실하지 않다면 [Replit Support에 문의하세요](https://replit.com/support).
  </Accordion>

  <Accordion title="로그인하면 예상과 다른 Account로 리디렉션됩니다">
    동일한 로그인 provider에 여러 계정이 연결되어 있을 가능성이 높습니다. 이메일과 비밀번호 또는 다른 provider 등 다른 방식으로 로그인해 원하는 계정에 접속해 보세요. 어떤 방식이 어떤 계정에 연결되어 있는지 확인하는 데 도움이 필요하면 사용자 이름과 함께 [Replit Support에 문의](https://replit.com/support)하세요.
  </Accordion>

  <Accordion title="workspace.*.repl.co에 대한 SSH 연결이 더 이상 작동하지 않음">
    `workspace.*.repl.co` SSH 호스트 이름은 더 이상 지원되지 않습니다. project에서 [SSH](/ko/features/workspace-tools/ssh) pane을 열고 현재 연결 명령어를 복사하세요. 이 명령어는 `*.replit.dev` 주소를 사용합니다. 이전 `repl.co` 주소를 참조하는 스크립트나 SSH config가 남아 있다면 모두 업데이트하세요.
  </Accordion>

  <Accordion title="내 Account가 정지된 이유와 이의 제기 방법은 무엇인가요?">
    Replit은 Terms of Service 또는 커뮤니티 가이드라인을 위반한 계정을 정지하며, billing 분쟁이나 지불 거절(chargeback)이 발생하면 자동으로 이용 보류 조치가 적용될 수 있습니다. 먼저 이메일(스팸함 포함)에서 사유를 안내하는 메시지가 있는지 확인하세요.

    billing 관련 문제라면 **Settings → Billing**에서 미납 Invoice를 결제하세요. 정지가 잘못된 조치라고 판단되면 사용자 이름, 등록된 이메일, 간단한 설명을 담아 [Replit Support에 문의](https://replit.com/support)하세요. 자세한 내용은 [strike system FAQ](/ko/legal-and-security-info/strike-system-faq)와 [신뢰 및 안전](/ko/legal-and-security-info/trust-and-safety) 문서를 참고하세요.
  </Accordion>

  <Accordion title="회사 네트워크에서 가입할 수 없거나 workspace가 로드되지 않는 경우">
    계정에 문제가 없어도 회사나 학교 네트워크가 Replit을 차단할 수 있습니다. 흔한 증상으로는 회원가입 버튼이 계속 로딩되거나, workspace가 빈 화면으로 표시되거나, 연결이 반복적으로 끊기거나, Cloudflare의 &quot;Attention Required!&quot; 403 페이지가 나타나는 경우가 있습니다. 이러한 현상은 SSL/TLS 검사 장비, 헤더를 재작성하는 프록시, 평판이 낮은 공유 아웃바운드 IP 같은 기업 보안 도구가 Replit이 사용하는 연결을 방해할 때 발생합니다.

    먼저 네트워크가 원인인지 확인하세요.

    1. 같은 브라우저로 개인 휴대폰 핫스팟 등 다른 네트워크에서 다시 시도해 보세요.
    2. 시크릿 창 또는 개인정보 보호 창에서 시도해 보고, 관리형 확장 프로그램이나 정책이 적용되지 않은 브라우저에서도 시도해 보세요.

    회사 네트워크 밖에서는 Replit이 정상 작동하지만 회사 네트워크에서는 작동하지 않는다면, IT 팀에 Replit을 허용 목록에 추가해 달라고 요청하세요. Replit의 IP 주소는 수시로 바뀌기 때문에 IP 주소보다 도메인 기준으로 허용하는 것이 더 안정적입니다. 다음 도메인을 허용해 달라고 요청하세요.

    * `replit.com` 및 `*.replit.com`—메인 사이트 및 정적 assets
    * `*.replit.dev`—development URL
    * `*.replit.app`—published app
    * `*.repl.co`—기존 development URL
    * `replit-com-static.b-cdn.net`—글꼴
    * `replitcdn.b-cdn.net`—미디어

    Replit은 이러한 도메인 전반에서 지속적인 WebSocket 연결, 빈번한 API 호출, auth token 교환을 사용합니다. 따라서 IT 팀에 다음 사항도 함께 확인해 달라고 요청하세요.

    * **SSL/TLS 검사**—위 도메인에 대해 인증서 검사 우회를 추가하세요. 검사 프록시는 Replit의 인증서 처리에 실패하고도 아무런 오류를 표시하지 않아, 페이지가 멈춘 상태로 남을 수 있습니다.
    * **헤더 재작성**—HTTP 헤더를 수정, 제거, 삽입하는 프록시 규칙은 도메인 간 API 및 authentication 호출을 망가뜨립니다.
    * **WebSocket 트래픽**—위 도메인에 대한 `wss://` 연결을 허용하세요.
    * **브라우저 정책**—허용 목록에 없는 도메인에 대해 쿠키 유지나 서드파티 쿠키를 차단하는 그룹 정책 또는 MDM 규칙은 로그인을 방해할 수 있습니다.
    * **DNS 리졸버**—`replit.com`과 `*.replit.dev` 호스트명이 정상적으로 확인되는지 점검하고, `8.8.8.8` 또는 `1.1.1.1` 같은 공용 리졸버와 비교해 보세요. 스플릿 호라이즌 방식이거나 필터링을 수행하는 리졸버는 development URL에 대해 레코드를 반환하지 않는 경우가 있습니다.

    IT 팀이 이러한 변경 사항을 적용한 후에도 회사 네트워크에서 Replit이 계속 작동하지 않으면, 사용자 이름과 화면에 표시되는 정확한 오류 또는 Cloudflare Ray ID를 함께 알려 [Replit Support에 문의](https://replit.com/support)하세요.
  </Accordion>

  <Accordion title="connector(Stripe, GitHub, Resend)가 작동하지 않습니다. 어떻게 다시 연결하나요?">
    Connectors는 만료되거나 취소될 수 있는 OAuth token을 사용합니다. 다시 연결하려면 **Tools → Connectors**를 열고 문제가 있는 connector의 연결을 해제한 뒤, 다시 연결해 재승인하세요. token은 project [Secrets](/ko/core-concepts/project-editor/app-setup/secrets)에 자동으로 업데이트됩니다.

    다시 연결해도 계속 실패한다면 해당 서드파티 서비스의 계정이 활성 상태인지, 그리고 적절한 permissions이 있는지 확인하세요. [Managing connectors](/ko/replitai/managing-connectors)와 [integrations 개요](/ko/features/integrations/overview)를 참고하세요.
  </Accordion>

  <Accordion title="Replit 계정을 다른 사람에게 양도할 수 있나요?">
    Account는 직접 이전할 수 없습니다. Account는 해당 계정을 만든 자격 증명에 연결되어 있기 때문입니다. 대신 특정 project를 넘기려면 새 소유자에게 Account를 만들도록 요청하세요. 그런 다음 해당 project를 공유하고, 자신의 Account로 fork하도록 안내하세요. 현재 Account의 이메일을 변경하려면 **Settings → Profile**로 이동해 이메일을 수정하세요. 구독은 이전할 수 없으므로 새 소유자가 직접 구독해야 합니다. 비즈니스 계정 handoff가 필요한 경우 [Replit Support에 문의하세요](https://replit.com/support).
  </Accordion>
</AccordionGroup>
