CLUI (Command Line User Interface) — это интерактивная командная строка Replit, с помощью которой можно быстро выполнять различные действия, не переходя по меню. Она сочетает эффективность командной строки с удобством графического интерфейса.

<div id="recursos">
  ## Возможности
</div>

CLUI обеспечивает мощное взаимодействие с помощью команд в трёх различных контекстах в Replit:

* **Управление настройками**: управляйте настройками, просматривайте уведомления и восстанавливайте удалённые Replit App
* **Быстрая навигация**: переключайтесь между своими Replit App и обращайтесь к часто используемым возможностям через сочетания клавиш
* **Операции в workspace**: находите файлы, ищите код и открывайте инструменты прямо в своей среде разработки

<div id="uso">
  ## Использование
</div>

<div id="clui-da-conta">
  ### CLUI учётной записи
</div>

CLUI учётной записи помогает управлять настройками, командами и удалёнными Replit App.

**Как открыть**: перейдите на [страницу CLUI](https://replit.com/~/cli), начните вводить текст во входящих, чтобы найти команду, и нажмите Enter для её выполнения.

<Accordion title="Команды учётной записи">
  Введите `account`, чтобы управлять своими настройками:

  * **view-warns**: просмотр полученных предупреждений
  * **change-username**: изменение имени пользователя (доступно только один раз)
</Accordion>

<Accordion title="Команды корзины">
  Введите `trash`, чтобы управлять удалёнными Replit App:

  * **restore &lt;title&gt;**: восстановление удалённого Replit App по названию (если совпадений несколько, восстанавливается удалённый последним)
  * **view**: просмотр недавно удалённых Replit App
</Accordion>

<Accordion title="Команды для работы с командами">
  Введите `team`, чтобы управлять своими командами:

  * **view**: просмотр участников команды, в которой вы состоите, по её имени пользователя
  * **fork-repl-to-project**: создание форка существующего Replit App для командного Project
</Accordion>

<Accordion title="Команда очистки">
  Введите `clear`, чтобы очистить экран от всех ранее выполненных команд
</Accordion>

<div id="clui-de-atalhos">
  ### CLUI быстрых команд
</div>

CLUI быстрых команд даёт быстрый доступ к основным возможностям Replit с любой страницы.

<Frame>
  <img src="/assets/mirror/shortcuts-clui-768d49b44785.png" alt="CLUI быстрых команд" width="689" height="291" data-path="images/getting-started/shortcuts-clui.png" />
</Frame>

**Как открыть**: нажмите **CMD/CTRL + K** или щёлкните значок поиска в верхней панели навигации — он доступен на большинстве страниц Replit.

<Accordion title="Доступные команды">
  * **Search**: поиск по Replit — Replit App, Templates, код, люди и другое
  * **New**: создание нового Replit App
  * **My Replit Apps**: просмотр и открытие ваших Replit App
  * **My Code**: поиск по коду всех ваших Replit App
</Accordion>

<div id="clui-do-workspace">
  ### CLUI в workspace
</div>

CLUI в Workspace помогает выполнять операции, обращаться к инструментам, находить файлы и искать по коду во время работы над Replit App.

<Frame>
  <img src="/assets/mirror/ws-clui-81764b3d111b.png" alt="CLUI в Workspace" width="429" height="202" data-path="images/getting-started/ws-clui.png" />
</Frame>

**Как открыть**: нажмите **CMD/CTRL + K** или щёлкните значок поиска в левом верхнем углу, находясь в Workspace.

<Accordion title="Распространённые операции">
  * **Find files**: быстро находите файлы в проекте
  * **Search code**: находите нужные фрагменты кода в своих файлах
  * **Access tools**: открывайте любой доступный инструмент или панель в Workspace
  * **Run commands**: выполняйте команды workspace
</Accordion>
