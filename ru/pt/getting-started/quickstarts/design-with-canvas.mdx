⏰ *Примерное время: 5 минут* · Продолжение [Создайте своё первое приложение](/ru/pt/getting-started/quickstarts/ask-ai)

**Canvas** — это визуальное пространство, где можно изучить несколько вариантов дизайна перед созданием приложения. Создавайте мокапы, сравнивайте их рядом и применяйте понравившийся вариант.

<div id="antes-de-comear">
  ## Перед началом работы
</div>

Вам понадобится приложение, уже созданное в Replit: из краткого руководства [Создайте своё первое приложение](/ru/pt/getting-started/quickstarts/ask-ai) или из любого другого проекта.

<Tip>Также можно начать с нуля: просто создайте новый проект и сначала опишите свою идею Agent.</Tip>

<div id="crie-o-design-do-seu-aplicativo">
  ## Создайте дизайн приложения
</div>

<Steps>
  <Step title="Изучите варианты дизайна">
    Откройте вкладку **Canvas** в редакторе проектов и нажмите **Переосмыслить**. В выпадающем меню доступны готовые промпты для изучения разных вариантов.
    Выберите «Попробовать другие раскладки», и Agent создаст в Canvas несколько дизайн-мокапов.

    <Frame>
      <video autoPlay muted loop playsInline src="/assets/mirror/try_different_layouts-with_canvas-7e77d972c8f5.mp4" />
    </Frame>

    Вот все доступные варианты:

    * Изучить другие подходы
    * Попробовать другие раскладки
    * Изучить другие стили
    * Больше похоже на это, но лучше
    * Оптимизировать для удобства использования
    * Показать противоположное этому
    * Удиви меня

    Или просто попросите Agent создать варианты своими словами:

    ```
    Покажи мне в Canvas тёмную, минималистичную и красочную темы
    ```

    <Frame>
      <img src="/assets/mirror/quickstart_design_canvas_variations-636d281499e5.png" alt="Canvas с несколькими вариантами дизайна рядом друг с другом" width="2538" height="1428" data-path="images/getting-started/quickstart_design_canvas_variations.png" />
    </Frame>
  </Step>

  <Step title="Выберите направление">
    Просмотрите варианты и выберите тот, который лучше всего соответствует вашему замыслу. Перед подтверждением можно попросить Agent доработать конкретный вариант:

    ```
    Мне нравится второй, но сделай заголовок больше
    ```
  </Step>

  <Step title="Примените дизайн к приложению">
    Когда вы будете довольны дизайном, попросите Agent применить его:

    ```
    Примени этот дизайн к моему приложению
    ```

    Agent обновит код приложения в соответствии с выбранным дизайном. Проверьте вкладку **Предпросмотр**, чтобы увидеть результат.
  </Step>

  <Step title="Опубликуйте обновлённое приложение (необязательно)">
    Нажмите **Опубликовать** в редакторе проектов, чтобы разместить новый дизайн в интернете. Ваш существующий URL останется прежним. Посетители сразу увидят обновлённую версию.

    <Frame>
      <video autoPlay muted loop playsInline src="/assets/mirror/quickstart-publish-app-ae59052ca92d.mp4" />
    </Frame>

    Подробнее о публикации читайте в разделе [Опубликовать своё приложение](/ru/pt/getting-started/quickstarts/publish).
  </Step>
</Steps>
