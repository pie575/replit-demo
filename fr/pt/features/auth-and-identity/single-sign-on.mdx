<Note>
  Vous souhaitez plutôt exiger le SSO pour votre **organisation Replit** (connexion à replit.com) ? Cela se configure séparément — voir [Single sign-on (SAML SSO)](/fr/pt/teams/identity-and-access-management/saml). Cette page explique comment ajouter le SSO au flux de connexion d&#39;**une app que vous créez** sur Replit.
</Note>

Permettez à vos utilisateurs de se connecter à votre app avec le fournisseur d&#39;identité de leur entreprise, comme Okta ou Microsoft Entra ID. Si votre app utilise [Clerk Auth](/fr/pt/features/auth-and-identity/clerk-auth), vous configurez le SSO et les autres fonctionnalités d&#39;authentification avancées depuis le tableau de bord Clerk. Indiquez à Agent ce dont vous avez besoin : il vous dirigera vers le tableau de bord pour finaliser la configuration.

  <img src="/assets/mirror/sso-cover-28a76bfa16fb.jpeg" alt="Bannière de création d'apps Replit avec SSO, avec une icône de cadenas, montrant un développeur travaillant sur un ordinateur portable." width="1920" height="1080" data-path="images/workspace/auth/sso-cover.jpeg" />
</Frame>

Le tableau de bord Clerk va bien au-delà de l&#39;expérience de connexion standard. Toute configuration que vous y effectuez s&#39;applique automatiquement à l&#39;authentification de votre app Replit.

<div id="o-que-voc-pode-configurar">
  ## Ce que vous pouvez configurer
</div>

* **Connexions SSO d&#39;entreprise** : configurez l&#39;authentification unique avec Okta ou Microsoft Entra ID, en OIDC ou SAML. Vos clients peuvent ainsi se connecter avec le fournisseur d&#39;identité de leur entreprise. Le SSO protège également les outils internes qui manipulent des données sensibles : il remplace les listes d&#39;adresses e-mail autorisées gérées manuellement par le fournisseur d&#39;identité déjà en place dans votre entreprise.
* **Authentification multifacteur (MFA)** : ajoutez la MFA au flux de connexion de votre app.
* **Contrôles de session** : ajustez la durée des sessions et la fréquence de vérification.
* **Autres paramètres Clerk** : les paramètres supplémentaires de Clerk s&#39;appliquent automatiquement à votre app Replit. Ne modifiez pas les clés d&#39;API ni les paramètres d&#39;environnement — Replit s&#39;en charge. Consultez [Environnements de développement et de production](/fr/pt/features/auth-and-identity/clerk-auth#development-and-production-environments).

<div id="abra-o-painel-do-clerk">
  ## Ouvrir le tableau de bord Clerk
</div>

Demandez à Agent la modification d&#39;authentification dont vous avez besoin. Agent configure ce qu&#39;il peut et vous dirige vers le tableau de bord Clerk de votre app pour les réglages qui nécessitent votre intervention.

<Frame>
  <img src="/assets/mirror/build-with-sso-agent-workflow-46422788bd18.webp" alt="Agent dirige une app utilisant Clerk vers le tableau de bord Clerk pour y configurer le SSO d'entreprise." width="1602" height="1080" data-path="images/workspace/auth/build-with-sso-agent-workflow.webp" />
</Frame>

Vous pouvez également ouvrir le tableau de bord depuis le Workspace :

1. Dans le panneau Tools, sélectionnez **Users &amp; Auth**.
2. Sélectionnez l&#39;onglet **Configure**.
3. Sélectionnez **Advanced**.
4. Sous **Clerk dashboard**, sélectionnez **Open Clerk dashboard**.

<Frame>
  <img src="/assets/mirror/open-clerk-dashboard-tools-pane-a314ffea741d.webp" alt="L'outil Users & Auth avec l'onglet Configure ouvert, montrant la section Advanced et le bouton Open Clerk dashboard." width="2158" height="1372" data-path="images/workspace/auth/open-clerk-dashboard-tools-pane.webp" />
</Frame>

<div id="configure-uma-conexo-sso-empresarial">
  ## Configurer une connexion SSO Enterprise
</div>

1. Dans le tableau de bord Clerk, sélectionnez **Configure**.
2. Sous **User &amp; authentication**, sélectionnez **SSO connections**.
3. Sélectionnez **Enterprise**.
4. Sélectionnez **Add connection**.

<Frame>
  <img src="/assets/mirror/build-with-sso-enterprise-connections-b0a6a27885b5.webp" alt="Tableau de bord Clerk affichant la page des connexions SSO Enterprise et l'action Add connection." width="1826" height="1080" data-path="images/workspace/auth/build-with-sso-enterprise-connections.webp" />
</Frame>

Pour la configuration complète de la connexion, consultez la [documentation de Clerk](https://clerk.com/docs).

<div id="valide-a-conexo">
  ### Validez la connexion
</div>

Une fois la configuration terminée, connectez-vous avec un compte de test de votre fournisseur d&#39;identité. Vérifiez que ce compte accède bien aux parties attendues de votre app.

Si la connexion échoue, demandez de l&#39;aide à Agent. Précisez le fournisseur d&#39;identité, le protocole et le message d&#39;erreur dans votre demande.

<Note>
  Cette page traite du SSO d&#39;entreprise pour le flux de connexion propre à votre app. Pour la connexion sociale via Google, GitHub, Apple ou X — appelée **SSO providers** dans le Workspace — consultez [Providers de connexion](/fr/pt/features/auth-and-identity/sign-in-providers). Elle ne couvre ni la migration depuis Replit Auth, ni la connexion SAML pour les comptes Replit.
</Note>

<div id="preos-e-disponibilidade">
  ## Tarifs et disponibilité
</div>

L&#39;accès au tableau de bord Clerk est inclus dans le plan [Replit Pro](/fr/pt/billing/plans/replit-pro). Les plans Enterprise seront bientôt disponibles.

<Info>
  Les connexions SSO d&#39;entreprise sont gratuites jusqu&#39;au 1er octobre 2026. Passé cette date, la tarification du SSO s&#39;aligne sur celle de Clerk et est répercutée sur votre facture Replit.
</Info>
