<div id="mobile-app-agent-tour-and-deployments-in-dock">
  ### Visite guidée d’Agent dans l’application mobile et déploiements dans le dock
</div>

L’application mobile propose désormais une visite guidée d’Agent pour aider les nouveaux créateurs à démarrer rapidement. De plus, les déploiements s’affichent désormais par défaut dans le dock, ce qui facilite la gestion de vos applications publiées directement depuis votre appareil mobile.

<div id="deployment-secrets-sync-with-workspace-secrets">
  ### Les secrets de déploiement se synchronisent avec les secrets du workspace
</div>

Les déploiements se synchronisent désormais automatiquement avec les secrets de votre Workspace ! Les redéploiements sont ainsi moins sujets aux erreurs, car vos variables d&#39;environnement restent synchronisées. Vous pouvez toujours remplacer certaines valeurs si nécessaire en les « désynchronisant » explicitement.

</div>

<div id="advanced-privacy-settings-for-teams">
  ### Paramètres de confidentialité avancés pour les équipes
</div>

Les équipes Enterprise bénéficient désormais d&#39;un contrôle accru sur les données de leur organisation grâce aux nouveaux paramètres de confidentialité avancés. Empêchez les membres de créer des apps publiques ou d&#39;exporter du code sous forme de fichiers ZIP, afin de préserver votre propriété intellectuelle au sein de votre organisation.
