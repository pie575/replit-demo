С помощью выбора модели можно разрешить Replit автоматически выбрать модель или выбрать одну из доступных моделей самостоятельно.

<div id="section">
  ## Интеллектуальная маршрутизация моделей
</div>

Интеллектуальная маршрутизация моделей выбирает наиболее подходящую модель для каждой задачи, обеспечивая баланс между качеством и стоимостью. Если в продукте отображается **Auto**, Replit использует интеллектуальную маршрутизацию моделей.

Интеллектуальная маршрутизация моделей учитывает характер и сложность запрошенной работы. Для чётко сформулированных запросов можно использовать менее затратные модели, тогда как для сложных задач могут потребоваться более мощные модели. Replit также может выбирать разные модели по мере изменения задачи.

<Note>
  Free Mode всегда использует интеллектуальную маршрутизацию моделей. Разработчики в Free Mode не могут использовать выбор модели или выбирать модели вручную.
</Note>

<div id="section-2">
  ## Выбор модели вручную
</div>

Разработчики с подпиской Core или Pro могут выбирать модели, доступные в Power Mode или Max Mode.

1. В поле промпта выберите **Agent Mode**. В меню отображаются доступные режимы: **Free**, **Power** и **Max**.
2. Выберите **Power** или **Max**, затем найдите раздел **основная модель**.
3. Откройте меню основной модели и выберите модель из списка.

  <img src="/assets/mirror/model-selector-6826a87089a2.png" alt="Всплывающее окно настроек Agent с режимами Lite, Economy и Power, списком основная модель и ползунком уровня усилий" width="1432" height="786" data-path="images/design/replit-design/model-selector.png" />

Выбранная модель будет применена к следующему сообщению. Вы можете изменить её в любое время.

<div id="effort">
  ## Уровень усилий
</div>

**Уровень усилий — это настройка для каждой модели, а не отдельный режим.** Он определяет, сколько усилий выбранная модель тратит на рассуждения при подготовке каждого ответа: от **Low** до **Max**. Для каждой модели отображается рекомендуемая настройка; повышайте её, только если этого требует задача.

<Frame caption="Ползунок уровень усилий под списком моделей, установленный на Medium.">
  <img src="/assets/mirror/model-selector-effort-bcffb01239a8.png" alt="Список основных моделей: выбрана Claude Fable 5, а ползунок уровень усилий установлен на Medium — сбалансированный уровень рассуждений для повседневных задач" width="984" height="832" data-path="images/replitai/model-selector-effort.png" />
</Frame>

Используйте описания уровней как ориентир.

| Уровень усилий | Назначение                                                                                                                                  |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| **Low**        | Самые быстрые ответы с минимальными усилиями на рассуждения. Для повседневных, чётко определённых изменений, когда скорость важнее всего.   |
| **Medium**     | Сбалансированный уровень рассуждений для повседневных задач. Надёжный вариант по умолчанию, если рекомендуемая настройка не указывает иное. |
| **High**       | Более глубокие рассуждения для сложных задач, например многошаговых функций или менее знакомых областей.                                    |
| **Extra High** | Расширенные рассуждения для самых сложных задач, таких как масштабный рефакторинг или трудные ошибки.                                       |
| **Max**        | Максимальная глубина рассуждений. Самый дорогой и медленный вариант; используйте его, когда важен только наилучший возможный результат.     |

При повышении уровня усилий Agent рассуждает глубже и тщательнее, а также задействует наиболее мощные передовые модели, что улучшает результаты для самых сложных задач. Agent применяет эту дополнительную мощность выборочно — направляет запросы к более мощным моделям, только если они действительно сложные, а не использует их при каждом запуске.

<Tip>
  Agent использует наиболее мощные модели только для самых сложных задач, поэтому повышение уровня усилий может увеличить стоимость наиболее трудных задач примерно вдвое, но для более простых задач стоимость часто почти не увеличивается или не увеличивается вовсе. Повышайте его при работе со сложными проблемами и держите низким для рутинных изменений.
</Tip>

<div id="section-4">
  ## Сравнение моделей
</div>

С помощью **сравнения моделей** можно одновременно запускать один и тот же промпт в нескольких моделях и сравнивать результаты, не гадая, какая модель лучше подойдёт. Сейчас функция находится в бета-версии.

Чтобы включить её, разверните **Дополнительно** в нижней части всплывающего окна режима Agent и включите **Сравнение моделей**.

<Note>Сравнение моделей поддерживается только в Chat.</Note>

<Frame caption="Переключатель «Сравнение моделей» в разделе «Дополнительно».">
  <img src="/assets/mirror/compare-models-toggle-05429dc46d64.png" alt="Развернут раздел «Дополнительно», а бета-переключатель «Сравнение моделей» выключен. Указано, что следующий промпт создаст до 4 вариантов" width="1110" height="344" data-path="images/replitai/compare-models-toggle.png" />
</Frame>

После включения переключателя можно добавить для сравнения до **4 моделей**.

<Frame caption="Для сравнения выбраны 4 модели, а на кнопке отправки указано «Сравнить 4».">
  <img src="/assets/mirror/compare-models-9f5bcecec727.png" alt="Сравнение моделей включено. Во всплывающем окне режима Agent отображаются 4 слота моделей — Kimi K3, Claude Fable 5, Claude Opus 5 и GPT-5.6 Sol, каждый из которых можно удалить, — а также кнопка отправки чата с надписью «Сравнить 4»" width="1192" height="1930" data-path="images/replitai/compare-models.png" />
</Frame>

Следующий промпт будет выполнен по одному разу для каждой выбранной модели, и каждая из них создаст собственный вариант для сравнения.

<Note>
  Каждая модель в сравнении запускает отдельный Agent и расходует кредиты, поэтому запуск «Сравнить 4» стоит примерно столько же, сколько четыре отдельных запуска.
</Note>
