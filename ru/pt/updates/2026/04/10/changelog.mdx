<div id="integrao-com-databricks-apps">
  ### Интеграция с Databricks Apps
</div>

Пользователи Enterprise теперь могут создавать в Replit приложения, работающие с данными, и развертывать их напрямую в Databricks. Agent подключается к вашей среде Databricks и может анализировать схему данных, при этом данные не покидают Databricks. Когда приложение будет готово, опубликуйте его напрямую в Databricks Apps. Запущенное приложение полностью размещается в Databricks и наследует аутентификацию Databricks, механизмы управления Unity Catalog и существующие сетевые ограничения.

<Frame>
  <img src="/assets/mirror/databricks-app-template-333354ec6944.png" alt="Workspace Replit с шаблоном Databricks App, выбранным в раскрывающемся меню «Шаблоны»" width="1368" height="395" data-path="images/changelog/2026-04-10/databricks-app-template.png" />
</Frame>

Эта интеграция доступна организациям Enterprise с рабочим пространством Databricks. Подробнее — на [странице партнерства Replit x Databricks](https://replit.com/partners/databricks).

<div id="recrie-qualquer-interface-a-partir-de-uma-captura-de-tela">
  ### Воссоздайте любой интерфейс по снимку экрана
</div>

Вставьте снимок экрана в Agent и попросите его «создать это» или «воссоздать этот интерфейс». Agent с высокой точностью воспроизведёт дизайн за один подход — как для веб-приложений, так и для презентаций. Это удобно для копирования существующих дизайнов, воссоздания референсных интерфейсов или быстрого прототипирования по макету.

<div id="conectores-disponveis-em-todos-os-planos-pagos">
  ### Коннекторы доступны на всех платных тарифах
</div>

Пользователи тарифов Core и Pro теперь могут получить доступ ко всем коннекторам прямо из Workspace.

Подробнее об [управлении коннекторами](/ru/pt/replitai/managing-connectors).

<div id="pagamentos-razorpay-para-a-ndia">
  ### Платежи Razorpay в Индии
</div>

Теперь разработчики в Индии могут оплачивать подписку через UPI и банковские карты с помощью Razorpay. Также поддерживаются e-mandate для регулярных подписок в соответствии с требованиями Резервного банка Индии. Если вы уже являетесь подписчиком в Индии, вскоре вы сможете перейти со Stripe на Razorpay на странице биллинга.

<div id="sincronizao-revenuecat-com-app-store-connect">
  ### Синхронизация RevenueCat с App Store Connect
</div>

Интеграция с RevenueCat теперь поддерживает автоматическую синхронизацию с Apple. При настройке покупок в приложении в RevenueCat настройки автоматически синхронизируются с App Store Connect.

Подробнее о [подписках RevenueCat](/ru/core-concepts/monetization/revenuecat-subscriptions).

<div id="escolha-onde-seu-app-executado-com-a-geografia-de-publicao">
  ### Выберите регион, в котором будет работать ваше App
</div>

Пользователи тарифов Core, Pro и Enterprise теперь могут выбирать регион публикации своего App. При публикации в регионе вычислительные артефакты, база данных и Object Storage вашего App размещаются в одном регионе. Региональный прокси помогает сократить задержку для посетителей вашего App.

Помимо Северной Америки теперь доступна Европа, а вскоре появятся Австралия, Южная Америка и Азия. Администраторы Enterprise также могут ограничить организацию одним регионом в целях соблюдения требований.

<div id="faturas-anteriores-na-pgina-de-uso">
  ### Предыдущие счета на странице использования
</div>

Теперь вы можете просматривать предыдущие счета прямо на странице **Использование** в настройках учётной записи. Выберите в раскрывающемся меню любой предыдущий расчётный период, чтобы увидеть подробную разбивку потребления по каждому App.
