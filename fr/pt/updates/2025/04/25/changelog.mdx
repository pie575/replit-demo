<div id="tour-do-agent-no-aplicativo-mobile-e-implantaes-no-dock">
  ### Visite guidée d&#39;Agent dans l&#39;application mobile et déploiements dans le dock
</div>

L&#39;application mobile propose désormais une visite guidée de prise en main d&#39;Agent pour aider les nouveaux créateurs à démarrer rapidement. Par ailleurs, les Déploiements apparaissent maintenant dans le dock par défaut, ce qui facilite la gestion de vos applications publiées directement depuis votre appareil mobile.

<div id="sincronizao-de-segredos-de-implantao-com-segredos-do-workspace">
  ### Synchronisation des secrets de déploiement avec les secrets du workspace
</div>

Les déploiements se synchronisent désormais automatiquement avec les secrets de votre Workspace ! Résultat : moins de redéploiements en échec, car vos variables d&#39;environnement restent toujours à jour. Vous pouvez néanmoins remplacer certaines valeurs au cas par cas en les « désynchronisant » explicitement.
