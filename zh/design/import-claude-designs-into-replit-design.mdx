在 Claude 中创建的设计展示了理想的体验效果。通过 Claude 的 **Send to Replit** 选项，你可以将该设计交给 Replit，它会成为一个项目，并由 Agent 将其转化为可用的交互式 App。

<Note>
  这是一个新的集成。只有当 Claude 将 Replit 提供为设计的发送目标时，Claude 的 **发送至…** 菜单中才会显示 **Send to Replit**。该功能是否可用由 Claude 决定，因此可能尚未对所有账户显示此选项。接受交接后，Claude 会在 Replit 的同意屏幕上请求 **访问应用**、**创建和管理应用** 和 **保持登录此应用** 作用域。
</Note>

<div id="how-it-works">
  ## 工作原理
</div>

交接流程从 Claude 发起，在 Replit 中完成：

1. 你在 Claude 的设计画布中创建一个完整且独立的设计。
2. 通过 Claude 的 **分享 → 发送至…** 菜单将设计发送到 Replit。
3. 授权 Claude 访问你的 Replit 帐户，并选择一个 workspace。
4. Replit 会创建一个项目，并将你的设计保存为静态 `index.html` 文件。
5. Agent 会接手 **Turn this Claude design into a real app** task，将其变为可交互的应用。

这是 Claude 通过已授权的应用连接将设计*发送*到 Replit。你无需先在 Replit 中进行任何配置——流程从 Claude 发起。

<div id="before-you-start">
  ## 开始之前
</div>

你需要：

* 一个 [Replit 账户](https://replit.com)。
* 一个 Claude 账户，以及 Claude 设计画布中的设计。
* 用于创建新项目的目标 Replit workspace。

<div id="send-a-design-from-claude-to-replit">
  ## 将设计从 Claude 发送到 Replit
</div>

在 Claude 中打开你想继续构建的设计。

<Steps>
  <Step title="在 Claude 中打开设计">
    在 Claude 中打开你想转换为 App 的设计。
  </Step>

  <Step title="打开“发送至”菜单">
    选择 **分享**，然后打开 **发送至…** 菜单。Replit 会显示为可选目标。

    <Frame>
      <img src="/assets/mirror/claude-send-to-menu-d4353906aea3.png" alt="Claude 的“发送至…”菜单，其中 Replit 与 Claude Code 一同列为可选目标" width="2000" height="1143" data-path="images/claude-to-app/claude-send-to-menu.png" />
    </Frame>
  </Step>

  <Step title="选择 Replit">
    选择 **Replit**，开始将设计交接给你的 Replit Account。
  </Step>

  <Step title="授权 Replit 访问权限">
    在标题为 **Claude 希望访问你的 Replit Account** 的 Replit 授权页面上，查看 Claude 请求的权限——**访问应用**、**创建和管理应用**和**保持登录此应用**——然后授权连接。

    <Frame>
      <img src="/assets/mirror/replit-oidc-consent-76dfc4d92a2f.png" alt="标题为“Claude 希望访问你的 Replit Account”的 Replit 授权页面，显示“访问应用”“创建和管理应用”和“保持登录此应用”作用域，以及 workspace 选择器" width="2000" height="1143" data-path="images/claude-to-app/replit-oidc-consent.png" />
    </Frame>
  </Step>

  <Step title="选择 workspace">
    选择要创建新项目的 Replit workspace，然后确认。
  </Step>
</Steps>

确认后，Replit 会根据你的设计创建一个项目，并在 workspace 中打开它。

<div id="what-gets-imported">
  ## 导入内容
</div>

Replit 会将设计导入为单个独立的 `index.html` 文件。导入会保留 Claude 在设计中包含的视觉布局、样式和资源。

导入后，你将获得一个可用的起点。由于设计以静态 HTML 形式导入，你仍需添加行为、数据和交互功能。

<div id="what-is-not-imported">
  ## 未导入的内容
</div>

交接仅包含设计，不包含完整的应用。以下内容不会被导入：

* 后端逻辑和服务器端功能。
* 数据库或已存储的数据。
* 可用表单、状态管理和导航等交互功能。

Agent 会在将设计转化为实际 App 时添加这些功能。

<div id="let-agent-make-the-design-interactive">
  ## 让 Agent 为设计实现交互功能
</div>

导入后，Agent 会在 workspace 中启动 **Turn this Claude design into a real app** task。Agent 会以你的静态设计为基础，实现其中所体现的交互行为。

<Frame caption="来自 Claude 的 Velocity 设计以 frame 形式显示在 Replit Design 中，Agent 已运行完成。">
  <img src="/assets/mirror/claude-design-in-replit-design-ff81b055b1f5.webp" alt="从 Claude 发送的 Velocity 超级跑车租赁设计，在 Replit Design 中以 Claude 设计 frame 的形式打开，Chat 面板中的 Agent task 已标记为完成" width="1600" height="1004" data-path="images/claude-to-app/claude-design-in-replit-design.webp" />
</Frame>

task 完成后，打开 Preview 测试结果。将运行中的 App 与原始 Claude 设计进行对比，并确认：

* 布局和样式与设计足够接近。
* 按钮、表单和导航均能按预期工作。
* 刷新后 App 仍能正常运行。

如果有任何缺失或不符合预期的地方，请向 Agent 描述需要的更改，让它继续完善 App。
