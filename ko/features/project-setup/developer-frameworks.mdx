<div id="developer-framework-templates-have-been-removed">
  ## 개발자 프레임워크 템플릿이 제거되었습니다
</div>

언어 및 프레임워크 스타터 템플릿(이전 명칭: developer frameworks)은 더 이상 Replit에서 제공되지 않습니다. `replit.com/templates` 및 `replit.com/developer-frameworks` 페이지는 이제 [Replit Gallery](https://replit.com/gallery)로 리디렉션됩니다.

새 project를 시작하려면 대신 다음 방법 중 하나를 사용하세요.

* **Replit Agent로 시작하기** — [홈 페이지](https://replit.com/)에서 만들고 싶은 것을 설명하면 Agent가 project의 기본 구조를 만들어 줍니다.
* **[GitHub, GitLab 또는 Bitbucket에서 가져오기](/ko/build/import-from-providers)** — 기존 codebase나 스타터 stack을 새 Replit App으로 가져옵니다.
* **[published app 리믹스하기](https://replit.com/gallery)** — Replit Gallery에서 커뮤니티 apps를 둘러보고, 마음에 드는 앱을 시작점으로 삼아 리믹스해 보세요.

<div id="enterprise-custom-templates">
  ## Enterprise custom template
</div>

Enterprise 조직은 [custom template](/ko/teams/custom-templates)을 만들어 조직의 모든 구성원에게 Agent input box에서 선택 가능한 옵션으로 제공할 수 있습니다. custom template은 developer frameworks의 범위를 넘어 회사 고유의 Agent Instructions, skills, 사전 구성된 project context까지 포함합니다. 자세한 내용은 [custom templates 가이드](/ko/teams/custom-templates)를 참고하세요.
