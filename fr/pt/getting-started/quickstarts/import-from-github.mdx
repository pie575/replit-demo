<div id="importar-do-github">
  ## Importer depuis GitHub
</div>

⏰ *Durée estimée : deux minutes*

Importez un dépôt GitHub dans Replit pour exécuter, tester et publier plus rapidement.

Pour découvrir toutes les options d&#39;importation, y compris depuis d&#39;autres plateformes comme Figma, Bolt et Lovable, consultez la [documentation de la fonctionnalité d&#39;importation](/fr/pt/core-concepts/project-editor/app-setup/import).

<div id="antes-de-comear">
  ## Avant de commencer
</div>

* L&#39;URL d&#39;un dépôt GitHub
* L&#39;accès au dépôt (public ou privé)
* Un compte Replit

<div id="opo-um-importao-rpida">
  ## Première option : importation rapide
</div>

L’importation rapide fonctionne avec les dépôts publics.

1. Copiez le chemin du dépôt après `github.com/`.
2. Ouvrez `https://replit.com/github.com/<propriétaire>/<repo>`.
3. Appuyez sur Entrée pour lancer l’importation.

**Exemple**

* URL GitHub : `https://github.com/exampleUser/my-app`
* URL d’importation Replit : `https://replit.com/github.com/exampleUser/my-app`

<div id="opo-dois-importao-guiada">
  ## Deuxième option : importation guidée
</div>

L’importation guidée prend en charge les dépôts publics et privés.

1. Ouvrez [replit.com/import](https://replit.com/import).
2. Sélectionnez **GitHub**.
3. Connectez votre compte GitHub.
4. Choisissez un dépôt.
5. Sélectionnez **Importer**.

<div id="o-que-importado">
  ## Ce qui est importé
</div>

* Les fichiers et dossiers du dépôt
* Les fichiers de dépendances
* La configuration d&#39;exécution et de build courante

<div id="o-que-no-importado">
  ## Ce qui n&#39;est pas importé
</div>

* Les valeurs des secrets et des variables d&#39;environnement existants
* Les services spécifiques à une plateforme qui ne s&#39;exécutent pas sur Replit par défaut

<div id="configure-and-run-your-app">
  ## Configurer et exécuter votre app
</div>

Lors de l&#39;importation, {setupDescription_0}. Si votre app nécessite des ajustements, utilisez ces outils du Project Editor :
