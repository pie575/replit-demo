AI-модели, такие как Claude и GPT, мощны, но ограничены данными, на которых они обучались. Model Context Protocol (MCP) предоставляет стандартный способ подключения к внешним инструментам, источникам данных и функциям реального мира.

<div id="ai-mcp">
  ## Почему ИИ-моделям нужен MCP
</div>

Без доступа к внешним инструментам и данным ИИ-модели не могут:

* Получать актуальную информацию
* Взаимодействовать с внешними системами
* Совершать действия в реальном мире
* Обрабатывать персональные данные

MCP решает эту проблему, предоставляя ИИ универсальный способ подключения к инструментам и данным — подобно тому, как USB-C стандартизировал подключение устройств.

</Frame>

С помощью MCP ИИ-модели могут:

* Получать доступ к специализированным инструментам и API
* Читать данные из личных источников
* Совершать действия в реальном мире
* Беспрепятственно подключаться к другим системам

<div id="mcp">
  ## Как работает MCP
</div>

Архитектура MCP состоит из трёх основных компонентов:

1. **Клиентская сторона** — AI-модель или приложение, например Claude, которому нужен доступ к внешним инструментам.
2. **Уровень связи** — сам протокол, стандартизирующий форматы запросов и ответов.
3. **Серверная сторона** — программа, предоставляющая доступ к инструментам, источникам данных и специализированным возможностям.

<AccordionGroup>
  <Accordion title="Что такое MCP-клиент?">
    MCP-клиентом может быть Claude, Replit Agent или интерфейс командной строки, подключённый к большой языковой модели. Это «устройство», которое подключается к внешним инструментам или источникам данных.

    Примеры MCP-клиентов:

    * Claude в браузере
    * Replit Agent
    * Интерфейс командной строки для AI
    * Пользовательские приложения, созданные с помощью AI SDK
  </Accordion>

  <Accordion title="Что такое MCP-сервер?">
    MCP-сервер предоставляет AI-моделям инструменты и возможности. Это специализированный набор инструментов, помогающий AI решать задачи.

    Примеры возможностей MCP-сервера:

    * Доступ к определённым источникам данных для ответов на вопросы
    * Подключение AI к API для выполнения действий в интернете
    * Чтение и запись файлов
    * Выполнение вычислений или запуск кода
    * Получение контента из таких сервисов, как Notion, Linear и Stripe
  </Accordion>
</AccordionGroup>

<div id="mcp-2">
  ## Возможности MCP
</div>

MCP определяет несколько ключевых компонентов для ИИ-приложений:

* **Ресурсы** — обмен данными и контентом с ИИ-моделями
* **Инструменты** — позволяют ИИ-моделям выполнять действия через сервисы
* **Промпты** — многоразовые шаблоны для согласованного взаимодействия с ИИ
* **Сэмплинг** — позволяет сервисам запрашивать информацию у ИИ-моделей
* **Транспорты** — эффективно связывают клиентов и серверы

<div id="vs-mcp">
  ## Навыки и MCP-серверы
</div>

Навыки и MCP-серверы — два основных способа расширить возможности ИИ-агента, предназначенные для разных задач.

|                     | Навыки                                                                                         | MCP-серверы                                                          |
| ------------------- | ---------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| **Подходят для**    | Рабочих процессов, соглашений и справочных материалов                                          | Подключения внешних сервисов и выполнения действий                   |
| **Способ загрузки** | Легковесный — до вызова загружаются только название и описание                                 | Тяжеловесный — описания всех инструментов загружаются заранее        |
| **Определяют**      | *как* агент должен выполнять работу                                                            | *к чему* агент может получить доступ                                 |
| **Пример**          | Навык &quot;Stock Analyzer&quot; — анализ инвестиций с использованием определённого фреймворка | MCP-сервер &quot;Stripe&quot; — чтение данных о платежах и подписках |

Подробнее о подходе к навыкам см. в разделе [Навыки Agent](/ru/ko/learn/agent-skills).

<div id="section">
  ## Практические примеры применения
</div>

MCP позволяет создавать различные ИИ-приложения:

* **Системы поддержки клиентов**: системы, которые обращаются к базам данных компании и отвечают на конкретные вопросы
* **Исследовательские ассистенты**: инструменты, которые ищут и обобщают информацию из нескольких источников
* **Инструменты для повышения продуктивности**: инструменты, взаимодействующие с файлами и приложениями
* **Инструменты для создания контента**: инструменты, которые обращаются к медиатекам и платформам публикации

<div id="section-2">
  ## Преимущества
</div>

MCP предлагает три ключевых преимущества:

* Готовые интеграции, к которым ИИ может подключаться сразу
* Возможность переключаться между поставщиками ИИ без перенастройки подключений
* Функции безопасности для защиты конфиденциальных данных

<Note>
  MCP — новый стандарт, поддержка которого расширяется во всей экосистеме ИИ. Новые инструменты и интеграции регулярно добавляются.
</Note>
