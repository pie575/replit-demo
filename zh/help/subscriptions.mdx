这些解答介绍如何管理订阅。有关完整套餐详情，请参阅 [Core](/zh/billing/plans/replit-core) 和 [Pro](/zh/billing/plans/replit-pro)。

<AccordionGroup>
  <Accordion title="如何从 Core 升级到 Pro？两者有什么区别？">
    与 [Core](/zh/billing/plans/replit-core) 相比，[Pro](/zh/billing/plans/replit-pro) ({ProPlanPrice}/月) 还提供：

    * 更多 Free Mode 使用额度
    * 最多可同时运行 10 个 Agent task
    * 最多 15 名构建者共享积分
    * 分级积分。未使用的积分可在 {ProCreditRolloverPeriod} 内结转
    * 28 天的数据库恢复窗口 (Core 为 7 天)
    * 优先支持

    如需升级，请打开 **设置 → 账单**，选择 Pro 套餐并确认付款信息。有关功能对比和当前定价，请参阅[定价页面](https://replit.com/pricing)。
  </Accordion>

  <Accordion title="如何取消订阅？">
    打开 **设置 → 账单**，选择取消订阅选项，然后完成确认步骤。你可以继续使用套餐功能直到计费周期结束，之后账户将转为免费的 [Starter 套餐](/zh/billing/plans/starter-plan)。

    转换前请注意，已发布的应用可能会下线，自定义域名连接会被移除，存储空间也会减少。请先下载想要保留的内容。如果订阅显示为 `past_due`，可能是付款失败，请先解决该问题再取消订阅。
  </Accordion>

  <Accordion title="我的续费付款失败了——如何更新付款方式？">
    打开 **设置 → 账单**，选择 **更新付款方式**，然后添加或更新银行卡。保存后，Replit 会自动重试未支付的款项。

    如果问题仍然存在，请提供支付意向 ID (以 `pi_` 开头) 并[联系 Replit 支持](https://replit.com/support)。账单失败通知有时会进入垃圾邮件文件夹。
  </Accordion>

  <Accordion title="如何将订阅转移到其他电子邮件地址或账户？">
    订阅与你的 Replit 账户绑定，无法直接转移。若要在保留订阅的同时更改账户电子邮件地址，请前往 **设置 → 个人资料**，然后编辑电子邮件地址。

    若要将订阅转移到其他账户，请[联系 Replit 支持](https://replit.com/support)，此类请求将视具体情况处理。
  </Accordion>

  <Accordion title="我在一个月内被扣费两次——这是怎么回事？">
    一个月内出现两笔扣费通常有以下原因：

    * 订阅费加上一笔达到计费阈值的单独使用费
    * 之前失败的付款在重试后成功
    * 存在多个有效订阅

    若要查看每笔费用的用途，请打开 **设置 → 账户使用情况**，然后选择 **查看以前的发票**。如果仍有疑问，请[联系 Replit 支持](https://replit.com/support)。
  </Accordion>

  <Accordion title="我更改了套餐，但新功能不可用——该怎么办？">
    套餐更改通常会立即生效。如果未显示新功能：

    1. 使用 `Cmd+Shift+R` (Mac) 或 `Ctrl+Shift+R` (Windows) 强制刷新。
    2. 退出登录后重新登录。
    3. 打开 **设置 → 账单**，确认更改已生效——其中应显示新套餐名称。

    如果账单页面显示的套餐正确，但功能仍未出现，请提供用户名和尝试使用的功能，并[联系 Replit 支持](https://replit.com/support)。
  </Accordion>

  <Accordion title="我可以暂停订阅而不是取消吗？">
    部分订阅者可选择暂停订阅一个月，而不是取消订阅。如果你符合条件，取消订阅时会显示该选项。暂停期间：

    * 将跳过下一笔付款，且不会发放每月积分
    * 已发布的项目会保持上线，协作者仍可访问
    * 符合条件的积分可结转，积分包仍可使用
    * Agent 和托管使用量仍按量计费

    **设置 → 账单** 会显示 **已暂停** 标记和暂停结束日期，订阅将在该日期自动恢复。你可以在计划暂停生效前将其取消，但已生效的暂停无法提前结束。每个订阅只能暂停一次。
  </Accordion>
</AccordionGroup>
