本页帮助你查找 Workspace 设置，以及同一「设置」对话框中提供的相关账户和用户
控件。

<div id="abrir-configuraes">
  ## 打开设置
</div>

1. 在 Replit 左下角点击你的账户菜单。
2. 选择 **设置**。

<Note>
  可用的标签页取决于 Workspace 类型、订阅方案以及你的角色。
  管理员专属选项只有在你拥有相应管理权限时才会显示。
</Note>

<div id="configuraes-de-workspace">
  ## Workspace 设置
</div>

使用 **Workspace** 部分管理当前选中的 Workspace：

* **Workspace 概览**：更新 Workspace 的图片或名称，并查看其 ID。
* **Workspace 协作者**：邀请成员并管理 Workspace 的访问权限。
* **集成**：管理连接到 Workspace 的服务和资源。
* **个性化**：在整个 workspace 范围内配置自定义指令、skills 和 Agent Memory。有关配置和权限，请参阅 [Agent 个性化](/zh/pt/features/agent/agent-customization)。
* **Design systems** 和 **幻灯片模板**：为你的组织管理可复用的设计规范和演示文稿模板。两者均为 Enterprise 功能——请参阅 [Design systems](/zh/pt/teams/custom-design-system) 和 [自定义模板](/zh/pt/teams/custom-templates)。
* **安全**：查看适用于该 Workspace 的安全控制项。请参阅[安全概览](/zh/pt/features/security/overview)。
* **群组**：组织成员并应用群组权限。请参阅[群组与权限](/zh/pt/teams/identity-and-access-management/groups-and-permissions)。

<div id="configuraes-de-conta">
  ## 账户设置
</div>

在**账户**部分中配置适用于所有 Workspace 的设置：

* **用量**、**账单**和**账户席位**：查看用量和账单信息，并在角色权限允许时管理席位。
* **高级**：提供账户的高级控制项，包括 Agent 的模型提供方策略。有关按提供方和按 Workspace 设置的 Enterprise 工作流程，请参阅[模型控制](/zh/pt/features/collaboration/enterprise-model-controls)。
* **开发者**：管理 Admin API 密钥并查看请求历史记录。在创建或轮换密钥之前，请先参阅 [Admin API](/zh/pt/teams/admin-api)。

<div id="configuraes-de-usurio">
  ## 用户设置
</div>

在**用户**部分中管理你的**个人资料**和**个性化**偏好设置。该部分还提供了 Replit 社区的入口链接。
