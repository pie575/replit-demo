Replit은 Replit App의 패키지를 설치하고 관리하는 여러 가지 방법을 제공합니다. [Shell](/ko/features/workspace-tools/shell)에서 직접 패키지를 설치하거나, [Agent](/ko/features/agent/overview/)에게 대신 처리해 달라고 요청하거나, Replit App을 실행할 때 Replit이 누락된 의존성을 자동으로 감지해 설치하도록 할 수 있습니다.

<div id="install-packages-using-the-shell">
  ## Shell로 패키지 설치하기
</div>

Project Editor에서 **Shell** 도구를 열고 사용 중인 언어의 package manager에 맞는 명령을 실행하세요:

<CodeGroup>
  ```bash Node.js (npm) theme={null}
  npm install <package-name>
  ```

  ```bash Node.js (pnpm) theme={null}
  pnpm add <package-name>
  ```

  ```bash Python (poetry) theme={null}
  poetry add <package-name>
  ```

  ```bash Python (pip) theme={null}
  pip install <package-name>
  ```

  ```bash Ruby theme={null}
  bundle add <gem-name>
  ```
</CodeGroup>

Replit의 [Universal Package Manager(UPM)](https://github.com/replit/upm/)를 사용하면 지원되는 여러 언어에 걸쳐 packages를 설치할 수도 있습니다:

```bash theme={null}
upm add <package-name>
```

특정 버전을 설치하려면:

```bash theme={null}
upm add 'flask==2.3.3'
```

지원되는 모든 언어와 패키지 관리자는 [UPM: Supported Languages](https://github.com/replit/upm/#supported-languages)를 참고하세요.

<div id="install-packages-using-agent">
  ## Agent로 packages 설치하기
</div>

Chat에서 [Agent](/ko/features/agent/overview/)에게 packages 설치를 바로 요청할 수 있습니다. 예를 들면 다음과 같습니다.

* &quot;axios package를 설치해줘&quot;
* &quot;내 project에 Flask와 SQLAlchemy를 추가해줘&quot;
* &quot;TailwindCSS를 설정해줘&quot;

Agent는 project에 맞는 package manager로 package를 설치하고 관련 구성 파일을 업데이트합니다.

<div id="automatic-import-detection">
  ## 자동 import 감지
</div>

Replit은 **Run**을 선택할 때마다 코드에 누락된 dependencies가 있는지 자동으로 분석합니다. 아직 설치되지 않은 package를 코드에서 import하면 Replit이 이를 감지해 최신 버전을 자동으로 설치합니다.

예를 들어 `main.py`에 `import flask`를 추가한 뒤 **Run**을 선택하면, **Console**에 **Flask**를 설치 중이라는 메시지가 표시됩니다.

<Note>
  자동 import 감지는 [.replit](/ko/features/project-setup/configuration#replit-file) 파일의 `packager.features.guessImports` 설정으로 구성할 수 있습니다.
</Note>

<div id="override-automatic-detection">
  ### 자동 감지 재정의하기
</div>

잘못된 패키지가 감지되었거나 특정 버전이 필요한 경우, Shell에서 올바른 설치 명령어를 실행하세요. 예를 들면 다음과 같습니다:

```bash theme={null}
upm add 'flask==2.3.3'
```

[.replit](/ko/features/project-setup/configuration#replit-file) 파일에서 특정 패키지나 경로를 자동 감지 대상에서 제외할 수도 있습니다:

<div id="python-package-managers">
  ## Python package manager
</div>

Python Replit App을 생성하면 package manager로 **poetry**가 기본 설정됩니다. 따라서 `pip install`로는 dependencies가 관리되지 않으며, 대신 Shell에서 `poetry add <package>` 또는 `upm add <package>`를 사용하세요.

<div id="switch-from-poetry-to-pip">
  ### poetry에서 pip으로 전환하기
</div>

`pip` 사용을 선호한다면 다음 단계를 따르세요.

<Steps>
  <Step>
    Shell을 열고 다음 명령을 실행하세요.

    패키징 인프라가 pip으로 전환되도록 잠금 파일을 삭제합니다.

    ```bash theme={null}
    rm poetry.lock
    ```
  </Step>

  <Step title="dependencies 옮기기">
    `pyproject.toml`의 `[tool.poetry.dependencies]` 섹션에 있는 dependencies를 `requirements.txt`로 옮기세요. 예를 들어 `flask = "^3.0.2"`는 `flask>=3.0.2,<4`가 됩니다.
  </Step>

  <Step title="pyproject.toml 정리하기">
    `pyproject.toml`에서 `[tool.poetry...]` 섹션을 삭제하세요.
  </Step>
</Steps>

이렇게 변경한 뒤에는 패키징 인프라가 이후의 모든 작업에 `pip`을 사용하며, 자동 import 감지 기능도 계속 정상적으로 동작합니다.

<div id="system-dependencies-with-nix">
  ## Nix를 활용한 시스템 dependencies
</div>

Replit은 [Nix](https://nixos.org/) integration을 통해 모든 프로그래밍 언어를 지원합니다. 표준 언어 packages 외에 시스템 수준의 dependencies가 필요한 경우 [replit.nix](/ko/features/project-setup/configuration#replit-nix-file) 파일에 추가하면 됩니다.

<div id="nix-packages">
  ### Nix packages
</div>

`replit.nix` 파일을 직접 편집하여 시스템 수준 dependencies를 추가하세요. 사용 가능한 packages는 [search.nixos.org](https://search.nixos.org/packages)에서 검색할 수 있습니다.

<div id="modules">
  ### 모듈
</div>

모듈은 프로그래밍 언어, 포매터, packager 지원을 하나로 묶은 것으로, Replit App의 기반이 됩니다. template이나 GitHub 저장소에서 Replit App을 만들면 Replit이 필요한 모듈을 자동으로 설치합니다.

[.replit](/ko/features/project-setup/configuration#replit-file) 파일에서 모듈과 그 밖의 Nix 설정을 사용자 지정할 수 있습니다.

<div id="packager-configuration">
  ## packager 구성
</div>

[.replit](/ko/features/project-setup/configuration#replit-file) 파일에서 패키지 관리 동작을 세밀하게 조정할 수 있습니다:

| 설정                                    | 설명                          | 기본값     |
| ------------------------------------- | --------------------------- | ------- |
| `packager.language`                   | 패키지 작업에 사용할 언어              | 자동 감지   |
| `packager.features.guessImports`      | Run 시 누락된 패키지를 자동으로 감지하고 설치 | `true`  |
| `packager.features.packageSearch`     | 패키지 검색 지원 활성화               | `true`  |
| `packager.features.enabledForHosting` | 호스팅 시 패키지 설치 필수 여부          | `false` |
| `packager.afterInstall`               | 패키지 설치 후 실행할 명령             | —       |
| `packager.ignoredPaths`               | import 감지 시 무시할 경로          | `[]`    |
| `packager.ignoredPackages`            | 자동 감지에서 제외할 패키지             | `[]`    |
