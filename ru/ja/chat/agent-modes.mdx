В режиме Agent перед отправкой запроса можно выбрать оптимальный баланс включённых лимитов, кредитов и возможностей. Откройте раскрывающееся меню настроек Agent в поле промпта и выберите режим, подходящий для вашей задачи.

<Note>
  Экономичный режим больше не доступен. Вместо него по той же цене доступен режим Power.
</Note>

<div id="section">
  ## Выберите режим
</div>

* **Свободный режим:** Исследуйте идеи, задавайте вопросы, начинайте создавать и продолжайте работать без перерывов. Свободный режим использует интеллектуальную маршрутизацию моделей для выбора модели. {FreeModePlanAvailability}
* **Режим Power:** Сбалансированный по скорости и возможностям режим, подходящий для большинства задач. Используйте его, когда вам нужны возможности сверх лимита Свободного режима или более мощные настройки по умолчанию для существующего проекта.
* **Режим Max:** Оптимальный вариант для сложных и амбициозных задач, крупных кодовых баз и трудных проблем.

Режимы Power и Max используют ежемесячные кредиты. Replit уведомит вас до того, как запрос переключится со Свободного режима на платный режим. Оставшийся лимит Свободного режима можно проверить в **Настройки** → **Использование**. Практические советы см. в разделе [Как максимально эффективно использовать Свободный режим](/ru/ja/chat/free-mode).

Рутины выполняются в режиме Power или Max и требуют бюджета для каждого запуска. В Свободном режиме их запускать нельзя. Подробнее см. в разделе [Рутины](/ru/ja/chat/routines).
