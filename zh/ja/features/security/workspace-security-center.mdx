工作区安全中心在所有套餐中均可使用。你可以用它扫描整个工作区中 项目 的[依赖项](/zh/ja/features/security/concepts#dependency)，并按[严重性](/zh/ja/features/security/concepts#severity)查看 [CVE](/zh/ja/features/security/concepts#cve) 检测结果。你还可以使用 Replit Agent 修复问题、[重新发布](/zh/ja/features/security/concepts#republish)受影响的 项目，并导出软件物料清单 ([SBOM](/zh/ja/features/security/concepts#sbom)) 报告以满足合规要求。

<Note>
  若要扫描单个 项目，请在该 项目 内通过 **Security** 面板打开[项目安全中心](/zh/ja/features/security/project-security-center)。
</Note>

<Note>
  如果你刚开始接触依赖项安全，请参阅[安全概念](/zh/ja/features/security/concepts)，了解 CVE、SBOM、暴露面、使用 Agent 修复、重新发布以及 Auto-Protect 的定义。
</Note>

<div id="section">
  ## 功能
</div>

<div id="cve">
  ### CVE 检测
</div>

检查 工作区 中所有项目的漏洞：

* 识别存在漏洞的项目，并按[暴露面](/zh/ja/features/security/concepts#exposure) (发布状态与可见性) 排定优先级
* 查看受影响的软件包名称、版本和严重性 (严重、高、中、低)
* 获取各个项目的修复指导

</Frame>

<div id="section-2">
  ### 受影响的项目视图
</div>

识别存在漏洞的项目，确定修复优先级：

* 查看按暴露程度分组的漏洞项目概览 (项目总数、已发布项目、公开发布的项目)
* 查看受影响的 Replit 项目的详细明细
* 按 CVE ID 或项目名称搜索，并按严重性、所有者、发布状态 (Published / Not published) 、可见性 (Public / Private) 筛选
* 展开项目行，无需离开当前页面即可查看全部 CVE 检测结果 (严重性、软件包、版本、CVE ID)

<div id="agent">
  ### 使用 Agent 修复并重新发布
</div>

无需离开安全中心即可修复漏洞并重新部署：

* 在受影响的项目中选择 **[使用 Agent 修复](/zh/ja/features/security/concepts#fix-with-agent)**，即可在项目内以后台任务的形式起草补丁。请在重新发布前查看并应用生成的更改。
* 通过 **Task in progress**、**Apply changes**、**Republish** 以及终态 **Republished** 或 **Failed** 跟踪修复进度。
* 一键 **Republish** 并配有确认对话框，在修复合并后使用现有配置重新部署构建。
* 执行批量操作，例如取消发布项目，或就漏洞问题通知项目所有者。

<div id="sbom">
  ### SBOM 导出
</div>

导出软件物料清单 (Software Bill of Materials) ，用于合规与审计：

* 以标准格式 ([SPDX](/zh/ja/features/security/concepts#spdx-and-cyclonedx)、[CycloneDX](/zh/ja/features/security/concepts#spdx-and-cyclonedx)) 下载 SBOM
* 为单个项目或整个工作区生成报告
* 按扫描运行分组查看 SBOM，并显示时间戳、项目数量以及触发本次运行的用户
* 将一次扫描运行中的所有 SBOM 打包为单个 ZIP 批量下载
* 满足软件供应链透明度方面的合规要求

<Note>
  批量 SBOM 下载仅适用于企业版套餐。其他套餐的工作区在 SBOM 部分会看到升级至企业版的推荐信息。
</Note>

<div id="section-3">
  ## 访问工作区安全中心
</div>

要打开工作区安全中心：

1. 访问 [replit.com](https://replit.com) 并登录你的账户。
2. 在主页的左侧导航栏中选择 **Security**。

<div id="section-4">
  ## 扫描 工作区
</div>

<Frame>
  <img src="/assets/mirror/security-overview-b37f090f236c.png" alt="工作区 安全中心的首页视图，显示扫描总数、漏洞总数以及按严重性分组的 CVE" width="3438" height="1984" data-path="images/workspace-security-center/security-overview.png" />
</Frame>

1. 打开 工作区 安全中心。
2. 选择 **Run security scan**，开始扫描整个 工作区。
3. 查看按受影响项目、严重性和部署暴露面整理的结果。
4. 在受影响的项目中选择**使用 Agent 修复**，修复应用后选择 **Republish**。

扫描会分析 工作区 中 Replit 项目的依赖项，并标记出公开漏洞记录中的已知漏洞。

<div id="auto-protect">
  ## Auto-Protect
</div>

管理员可以为账户启用 **[Auto-Protect](/zh/ja/features/security/concepts#auto-protect)**，持续监控所有 项目 依赖项中新披露的 CVE。一旦发现匹配项，Replit Agent 会准备好经过测试的补丁，builder 会收到一封邮件，其中包含可直接应用该补丁的链接。

完整的工作流程和设置步骤 (包括 **Settings** &gt; **Account** &gt; **Advanced** 中仅管理员可用的严重性阈值) 请参阅 [Auto-Protect](/zh/ja/features/security/project-security-center#auto-protect)。

<Note>
  如需了解工作区安全中心的设置，或将 SBOM 导出集成到合规工作流程中，请联系您的专属客户经理。
</Note>
