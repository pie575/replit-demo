<div id="section">
  ## Qu’est-ce qu’un artefact ?
</div>

Un artefact est un résultat que vous pouvez publier sur Replit, comme une application web ou mobile, un diaporama, une animation, une application de données, un jeu 3D ou un design. Chaque artefact est un résultat complet et autonome qui, une fois publié, dispose de sa propre URL partageable.

Tous les autres éléments du projet — fichiers, images, CSV et code — contribuent à l’artefact, mais ne peuvent pas être publiés seuls.

<ArtifactGrid />

  ## Ce que vous pouvez créer
</div>

| ---------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| **[Applications web](/fr/ko/features/artifact-types/web-apps)**                 | De beaux sites web performants qui gèrent les utilisateurs, les bases de données, etc.                    |
| **[Applications mobiles](/fr/ko/features/artifact-types/building-mobile-apps)** | Des applications natives pour iPhone et téléphones Android.                                               |
| **[Diaporamas](/fr/ko/features/artifact-types/slide-decks)**                    | Des diaporamas que vous pouvez présenter ou exporter.                                                     |
| **[Animations](/fr/ko/features/artifact-types/animated-videos)**                | Du motion design et des vidéos animées, exportables au format MP4.                                        |
| **[Visualisations de données](/fr/ko/features/artifact-types/data-apps)**       | Des tableaux de bord et des visualisations interactifs pour explorer des données et créer des graphiques. |
| **Jeux 3D**                                                                  | Des jeux 3D, des simulations et des expériences interactives.                                             |

Consultez la page dédiée à chaque type pour connaître sa disponibilité selon votre forfait.

<div id="section-3">
  ## Premiers pas
</div>

Vous pouvez créer de deux façons depuis la page d’accueil de Replit.

* **Décrire** : saisissez ce que vous souhaitez — « Crée-moi une application de recettes » ou « Crée-moi une présentation pour ma startup. » Agent déterminera le type le plus adapté et le créera.
* **Choisir un type** : avant de décrire votre idée, sélectionnez l’artefact souhaité — application web, application mobile, visualisation de données, animation, jeu 3D ou autre type pris en charge.

Vous pouvez ajouter du contenu à un projet existant à tout moment en le demandant à Agent dans le chat ou en cliquant sur le bouton **+** du panneau d’aperçu.

<div id="section-4">
  ## Passer d’un artefact à l’autre
</div>

Si votre projet contient plusieurs artefacts, vous pouvez passer de l’un à l’autre depuis le **panneau d’aperçu** ou la **barre latérale de la bibliothèque**. Vous pouvez également le demander à Agent, par exemple : « Montre-moi l’application mobile » ou « Passe aux diapositives ».

<div id="section-5">
  ### Barre latérale de la bibliothèque
</div>

La barre latérale de la bibliothèque offre un espace central pour parcourir tous les éléments de votre projet. Elle affiche les artefacts, les images générées ou téléchargées par Agent, ainsi que d’autres ressources du projet. Ouvrez-la depuis le panneau de gauche pour trouver et réutiliser des ressources dans l’ensemble de votre projet.

<div id="section-6">
  ## Plusieurs artefacts dans un même projet
</div>

Un projet peut contenir jusqu’à **7 artefacts**, dont **1 seule application mobile**. Vous pouvez par exemple créer une application web pour vos clients, une application mobile pour votre équipe et un diaporama pour vos investisseurs, le tout dans le même projet.

<ArtifactGrid />

<div id="section-7">
  ### Ajouter des artefacts à un projet
</div>

Il existe trois façons d&#39;ajouter des artefacts à un projet existant.

* **Chat** : demandez à Agent : « Ajoute une application mobile à ce projet » ou « Crée un diaporama pour une présentation aux investisseurs »
* **Bouton Ajouter** : cliquez sur le bouton **+** dans le panneau d’aperçu et sélectionnez ce que vous souhaitez créer
* **Barre latérale de la bibliothèque** : parcourez les artefacts existants, les images et d’autres ressources, puis ajoutez de nouveaux artefacts depuis cette barre latérale

<div id="section-8">
  ### Données et logique backend partagées
</div>

Lorsque des artefacts se trouvent dans le même projet, ils partagent automatiquement les mêmes données et la même logique backend. Lorsqu’un client passe une commande via l’application web, cette commande est également visible dans l’application mobile et le tableau de bord de données. Tout fonctionne automatiquement, sans configuration de connexions distinctes ni duplication de code.

<Note>
  Lorsque vous publiez, l’ensemble du projet est mis en ligne en une seule fois. Tous les artefacts sont publiés ensemble et restent donc toujours synchronisés.
</Note>

<div id="section-9">
  ### Exemples de combinaisons
</div>

* **Application web + application mobile** : un restaurant doté d’une application web pour les clients et d’une application mobile pour le personnel — toutes deux sont connectées à la même API et à la même base de données
* **Application + tableau de bord d’administration** : un produit phare avec un panneau d’administration interne pour gérer le contenu, les utilisateurs et les paramètres
* **Application + diaporama** : le produit et le pitch deck se trouvent dans le même projet, et les diapositives reflètent toujours la dernière version
* **Tableau de bord de données + vidéo** : une visualisation de données en temps réel accompagnée d’une vidéo animée présentant les points forts

<div id="section-10">
  ## Publication
</div>

Les applications, diapositives et vidéos peuvent toutes être publiées et partagées. Une fois publiées, elles disposent chacune de leur propre URL partageable.

Les fichiers et ressources qui ne sont pas des artefacts (CSV, images, fichiers Markdown, etc.) ne peuvent pas être publiés directement. Pour les partager, ajoutez-les à une application ou créez un nouvel artefact.

<div id="section-11">
  ## Questions fréquentes
</div>

<Accordion title="Puis-je avoir plusieurs artefacts dans un projet ?">
  Oui. Un projet peut contenir **jusqu’à 7 artefacts** au total, avec une limite de **1 application mobile par projet**. Tous les artefacts d’un projet partagent automatiquement le même back-end et les mêmes données.

  Si vous avez atteint la limite d’applications mobiles et souhaitez en créer une deuxième, créez-la dans un nouveau projet. Si vous avez atteint la limite de 7 artefacts, supprimez un artefact existant avant d’en ajouter un autre ou répartissez votre travail sur plusieurs projets.
</Accordion>

<Accordion title="Dois-je choisir un type avant de commencer ?">
  Non. Décrivez simplement ce que vous voulez créer, et Agent choisira le type approprié. Vous pouvez également sélectionner directement un type dans le menu déroulant.
</Accordion>

<Accordion title="Puis-je publier un seul artefact d’un projet ?">
  Ce n’est pas possible actuellement. Lorsque vous publiez, l’ensemble du projet passe en ligne afin que tous les artefacts restent synchronisés. Si vous avez besoin de publications indépendantes, utilisez des projets distincts.
</Accordion>

<Accordion title="Les artefacts partagent-ils des données ?">
  Oui. Tous les artefacts d’un projet partagent la même base de données et les mêmes services back-end. Lorsqu’une application web enregistre des données, l’application mobile et le tableau de bord de données peuvent les lire immédiatement.
</Accordion>

<Accordion title="Quelle est la différence entre un artefact et un fichier ?">
  Un artefact est un élément que vous pouvez publier — une application, des diapositives ou une vidéo. Les fichiers (CSV, images, code, etc.) sont des ressources qui prennent en charge les artefacts de votre projet, mais ne peuvent pas être publiés seuls.
</Accordion>

<Accordion title="Certaines fonctionnalités de l’application web manquent dans l’application mobile. Que s’est-il passé ?">
  Lorsque Agent convertit des fonctionnalités d’un type d’artefact à un autre, certains éléments peuvent ne pas être transférés parfaitement, en particulier les interactions ou les mises en page qui fonctionnent différemment selon les plateformes. Vous pouvez compléter les éléments manquants en envoyant des demandes de suivi dans le chat.
</Accordion>

Pour consulter la liste complète des éléments que vous pouvez créer, consultez la [présentation des projets](/fr/ko/features/projects-and-artifacts/projects).
