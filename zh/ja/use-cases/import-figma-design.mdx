假设您已在 Figma 中设计好界面。Agent 会将其构建为可编辑、可预览、可发布的在线
Replit 应用，布局、排版、颜色和间距都会得到还原。
最终得到的不是截图，而是真正可运行的产品。如果文件包含多个
流程，请向 Agent 指定要处理的具体画板。

<div id="section">
  ## 最适合的场景
</div>

* 已有设计画板，希望将其转化为可运行代码的 Replit 应用的产品设计师。
* 手中已有 Figma 文件，希望无需从零重做即可让设计上线的创业者。

<div id="section-3">
  ## 开始之前
</div>

请准备一个包含已命名画板 (如首页、商品、结账等) 的 Figma 文件，并连接 Figma。你可以将文件共享给 Agent，也可以直接粘贴文件链接和目标画板的链接。同时请说明你要构建的是营销网站、应用还是单个落地页。

<div id="section-4">
  ## 给 Agent 的提示词
</div>

<AiPrompt>
  根据这个 Figma 文件 [链接] 中的这些画板:[画板名称或链接],
  构建一个可运行的 Replit 应用。请保持布局、字体排版、配色、间距以及
  断点(桌面端和移动端)一致。
</AiPrompt>

<div id="section-5">
  ## 预期效果
</div>

Agent 会读取所选画板，并构建可通过 Replit 发布的对应页面。
请对照 Figma 抽查间距、排版和颜色。导航、
表单、悬停效果等交互部分请自行检查。通常还需要进一步
调整。请在桌面和手机屏幕宽度下预览。点击导航和
表单，并在发布前将截图与 Figma 对比。

<div id="section-6">
  ## 按需自定义
</div>

<AiPrompt>
  先只实现移动端画板，确保与 Figma 的自动布局和间距一致。
  等我确认移动端后，再实现桌面端。
</AiPrompt>

<AiPrompt>
  按钮、输入框和卡片请复用同一个组件。如果 Figma 中定义了变量，
  请从中获取颜色和排版样式。
</AiPrompt>

<div id="section-7">
  ## 故障排除
</div>

* **Agent 无法读取文件：** 请连接 Figma 并共享文件，然后粘贴画板链接，而不只是文件 URL。如果文件包含多个流程，请为画板命名 (如首页、商品、结账) ，并告知 Agent。
* **悬停效果、导航和表单看起来不完整：** 布局和颜色通常会先完成。对于交互部分，请要求进一步调整，并将间距与 Figma 对照进行抽查。
