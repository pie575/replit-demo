<div id="what-is-visual-editor">
  ## Что такое Visual Editor?
</div>

Visual Editor позволяет вносить изменения в UI, напрямую нажимая на элементы. Он работает как на [Canvas](/ru/design/canvas) в Replit Design, так и в Preview, поэтому вы можете одинаково редактировать макеты и работающие приложения.

Простые изменения — текста, цветов, отступов — напрямую обновляют исходный код без расхода AI-кредитов. Если изменение связано со скрытой сложностью, Visual Editor автоматически передаёт задачу Agent.

Ключевые понятия:

* **Детерминированные изменения**: Простые изменения (текста, цветов, отступов) напрямую применяются к исходному коду без обращения к Agent
* **Без расхода кредитов**: Прямые изменения не расходуют AI-кредиты — через Agent выполняются только сложные изменения
* **Двойной контекст**: Работает одинаково с фреймами Canvas и в Preview
* **Синхронизация исходного кода**: Каждое изменение мгновенно обновляет исходный код

<Note>
  Visual Editor пока доступен только в **веб-браузерах**. Он не поддерживается в Mobile App или Desktop App.
</Note>

<div id="how-to-use-visual-editor">
  ## Как пользоваться Visual Editor
</div>

<div id="editing-on-the-canvas">
  ### Редактирование на Canvas
</div>

Выберите инструмент **Edit** на панели инструментов, затем щёлкните любой элемент во фрейме. Элемент будет выделен, а рядом с ним появится метка с его названием. Справа откроется панель Visual Editor со свойствами этого элемента, которые можно редактировать: содержимым, раскладкой, цветом и границей. Настройте их, затем выберите **Save edits**, чтобы применить изменения, или **Discard**, чтобы отменить их.

Набор отображаемых свойств зависит от выбранного элемента: для текстовых элементов доступны настройки шрифта, для изображений — источник и загрузка, а для контейнеров — настройки раскладки.

<div id="editing-in-preview">
  ### Редактирование в Preview
</div>

Те же возможности редактирования доступны и в запущенном приложении.

<Steps>
  <Step title="Выберите элемент">
    Нажмите на любой элемент в Preview, чтобы начать редактирование.
  </Step>

  <Step title="Внесите изменения">
    Редактируйте текст прямо на странице, настраивайте цвета с помощью палитры, изменяйте отступы с помощью элементов управления стилями или заменяйте изображения.
  </Step>

  <Step title="Сохраните">
    Нажмите «Сохранить», чтобы обновить исходный код. Простые изменения применяются напрямую без расхода кредитов AI. Если правка требует более сложных изменений, Visual Editor отправляет Agent целевые метаданные для помощи.
  </Step>
</Steps>

<div id="text-editing">
  ### Редактирование текста
</div>

Щёлкните текстовый элемент и начните вводить текст, чтобы изменить его напрямую. Если текст — это строка в исходном коде, изменения применятся сразу.

<div id="color-adjustments">
  ### Настройка цветов
</div>

С помощью палитры цветов настройте цвета текста и фона. Введите в поле название цвета, например «purple», или воспользуйтесь пипеткой, чтобы выбрать цвет в любом месте экрана.

<div id="style-changes">
  ### Изменение стилей
</div>

Настраивайте внутренние и внешние отступы, а также раскладку элементов с помощью понятных элементов управления.

<div id="layout-controls">
  ### Элементы управления Layout
</div>

Visual Editor группирует элементы управления по понятным разделам, чтобы вам было проще найти нужный: **Text**, **Layout**, **Color** и **Border**. (При выборе изображения также появляется раздел **Image**.)

В разделе **Layout** можно настроить расположение дочерних элементов внутри контейнера, не обращаясь к Agent. Выберите flex-контейнер, разверните Layout — и увидите:

* **Выравнивание**: сетка из 3×3 точек для выбора расположения элементов по обеим осям внутри контейнера.
* **Направление**: две кнопки со стрелками для размещения дочерних элементов в строку или столбец.
* **Промежуток**: значение в пикселях для расстояния между элементами. Иконка рядом с полем промежутка меняется в зависимости от текущего направления, поэтому вы всегда знаете, настраиваете ли горизонтальный или вертикальный отступ. Рядом с ней иконка со стрелкой переключает **Распределить пространство между элементами**, размещая дочерние элементы у противоположных краёв контейнера.
* **Внешний отступ**: отдельные поля для отступов снаружи элемента (по одному для каждой стороны, с переключателем связи, чтобы одновременно связать все четыре стороны).
* **Внутренний отступ**: поля для отступов внутри элемента по каждой оси, с переключателем связи для обеих осей одновременно.

Раздел Layout появляется только тогда, когда к выбранному элементу применим хотя бы один параметр раскладки. Для обычных текстовых узлов без свойств отступов или раскладки этот раздел полностью скрыт, поэтому редактор остаётся компактным.

<div id="image-updates">
  ### Обновление изображений
</div>

Выберите изображение, чтобы заменить URL или загрузить собственный файл с мгновенным предпросмотром.

<div id="what-you-can-do">
  ## Что вы можете делать
</div>

* **Быстрая правка текста**: Изменяйте текст, подписи и заголовки, не открывая исходные файлы
* **Эксперименты с цветом**: Пробуйте разные цветовые схемы, кликая и настраивая их, — не нужно искать нужный CSS
* **Настройка раскладки**: Точно настраивайте внутренние и внешние отступы, а также отступы визуально, вместо того чтобы угадывать значения в пикселях
* **Замена изображений**: Заменяйте изображения-заполнители настоящими ассетами, кликая и загружая их
* **Итерации дизайна**: Быстро настраивайте фреймы Canvas, чтобы сравнивать разные визуальные направления без лишних обращений к Agent

<div id="frequently-asked-questions">
  ## Часто задаваемые вопросы
</div>

<Accordion title="Расходуются ли AI-кредиты на изменения в Visual Editor?">
  Простые предсказуемые правки — изменение текста, выбор цвета, настройка отступов — не расходуют AI-кредиты. Они напрямую обновляют исходный код. Если Visual Editor обнаружит скрытую сложность, он передаст изменение Agent, который использует кредиты.
</Accordion>

<Accordion title="Можно ли редактировать элементы, которые отображаются в нескольких местах?">
  Да. При выборе элемента, отображаемого в цикле или повторно используемого в компонентах, все его экземпляры одновременно выделяются и обновляются.
</Accordion>

<Accordion title="Почему текст некоторых элементов нельзя редактировать?">
  Составные элементы из нескольких дочерних элементов нельзя редактировать напрямую в Visual Editor. Вместо этого попросите Agent в Chat внести нужные изменения.
</Accordion>

<Accordion title="Как найти исходный код элемента?">
  Нажмите метку в левом верхнем углу выбранного элемента, чтобы перейти к его расположению в исходном коде.
</Accordion>
