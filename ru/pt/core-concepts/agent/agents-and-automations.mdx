<div id="casos-de-uso-suportados">
  ### Поддерживаемые сценарии
</div>

**Доступно сейчас:**

* **Slack Agent** — Создавайте интеллектуальных Slack-ботов, способных отвечать на вопросы, интегрироваться с API и автоматизировать задачи
* **Telegram Agent** — Создавайте Telegram-ботов для поддержки клиентов, планирования, развлечений и многого другого
* **Автоматизация по расписанию** — Настраивайте рабочие процессы по расписанию, которые автоматически запускаются в заданное время

**Скоро:**

* **Пользовательские webhook-триггеры**: Реагируйте на любые внешние события или вызовы API с помощью URL webhook

<div id="funcionalidades-adicionais">
  ### Дополнительные функции
</div>

* **Расширенные интеграции**: Подключайтесь к Outlook, Spotify, Notion, Linear, GitHub и многим другим сервисам
* **Тестовая среда**: Тестируйте своих агентов и просматривайте рабочие процессы перед развёртыванием
* **Облачное развёртывание**: Автоматическая настройка для круглосуточной доступности с развёртываниями Autoscale или по расписанию

  ## С чего начать
</div>

<div id="passo-1-selecione-agents-automaes">
  ### Шаг 1: Выберите Agents &amp; Automations
</div>

На главной странице Replit после входа в систему **выберите «Agents &amp; Automations»** в списке типов приложений.

  <img src="/assets/mirror/agents-automations-homepage-2-b2bb064da3b0.png" alt="Главная страница Replit с выбранным пунктом Agents & Automations, меткой Beta и полем ввода промпт" width="3024" height="1720" data-path="images/replitai/agents-automations-homepage-2.png" />

<div id="passo-2-escolha-o-tipo-de-trigger">
  ### Шаг 2: Выберите тип триггера
</div>

Далее вы увидите список типов триггеров. Выберите один из поддерживаемых вариантов:

* **Slack** — создавайте интеллектуальных Slack-ботов, интегрированных с вашим рабочим пространством
* **Telegram** — создавайте Telegram-ботов для различных сценариев
* **Автоматизация по расписанию** — настройте рабочие процессы по расписанию, которые запускаются автоматически

<div id="passo-3-insira-seu-prompt">
  ### Шаг 3: Введите промпт
</div>

**Введите промпт**, описав, что должен сделать Agent.

<div id="passo-4-deixe-o-agent-construir-sua-automao">
  ### Шаг 4: Позвольте Agent создать вашу автоматизацию
</div>

Agent создаст автоматизацию на основе вашего промпта и выбранного типа триггера, включая все необходимые интеграции и настройки развёртывания.

  После создания проекта в Редакторе проектов появится отдельная **панель Agents &amp; Automations**:

  * **Расположение**: Открывается под областью предварительного просмотра в Редакторе проектов
  * **Возможности**:
    * Просматривать Agent и взаимодействовать с ним
    * Тестировать функциональность чат-бота перед развёртыванием
    * Просматривать рабочие процессы автоматизации
    * Просматривать логи и отлаживать проблемы
  * **Тестирование**: Общайтесь с Agent прямо на панели, чтобы проверить его ответы и поведение

<div id="requisito-de-implantao">
  ### Требования к развёртыванию
</div>

<Warning>
  **Требуется развёртывание**: чтобы Agent или автоматизация работали с внешними
  триггерами, такими как Slack, Telegram или автоматизации по расписанию, их необходимо развернуть.
  Панель тестирования подходит для разработки и тестирования, но для работы триггеров в реальном времени
  требуется развёртывание.
</Warning>

Когда проект будет готов, Agent автоматически предложит развернуть его. Выберите подходящий тип развёртывания:

* **Развёртывания Autoscale** — для чат-ботов и рабочих процессов, запускаемых событиями
* **Развёртывания по расписанию** — для автоматизаций по времени

<div id="exemplos-de-slack-agent">
  ### Примеры Slack Agent
</div>

**Помощник для исследований с интеграцией Perplexity**

<AiPrompt>
  Создай Slack-бот с ИИ, который сможет отвечать на исследовательские вопросы с помощью
  API Perplexity. Когда кто-то задаёт вопрос в канале #pesquisa, он
  должен находить актуальную информацию и давать исчерпывающие ответы с
  указанием источников.
</AiPrompt>

**Вопросы и ответы по кодовой базе с интеграцией GitHub**

<AiPrompt>
  Создай Slack-бот с ИИ, который сможет отвечать на вопросы о моём кодовой базе с помощью
  интеграции с GitHub. Он должен уметь объяснять функции, находить файлы и
  помогать с отладкой, анализируя наш репозиторий.
</AiPrompt>

**Помощник по электронной почте с интеграцией Outlook**

<AiPrompt>
  Создай Slack-бот с ИИ, который сможет отвечать на вопросы о моих письмах в Outlook. Он
  должен помогать мне находить конкретные письма, резюмировать переписки и давать
  быстрые ответы на распространённые вопросы по электронной почте.
</AiPrompt>

<div id="exemplos-de-telegram-agent">
  ### Примеры Telegram Agent
</div>

**ИИ-помощник для бизнеса с планированием встреч в календаре**

<AiPrompt>
  Создай ИИ-помощника для бизнеса, который сможет планировать встречи в моём календаре Outlook.
  Пользователи должны иметь возможность запрашивать время для встреч, а бот будет находить
  свободные слоты и отправлять приглашения в календарь.
</AiPrompt>

**Бот для рекомендаций музыки в Spotify**

<AiPrompt>
  Создай весёлого ИИ-чат-бота, который сможет подбирать песню в Spotify по любому отправленному мной сообщению,
  описывающему желаемое настроение. Он должен понимать описания настроения и предлагать
  идеально подходящие треки.
</AiPrompt>

**Бот в образе вымышленного персонажа**

<AiPrompt>
  Создай ИИ-бота в образе вымышленного персонажа — Шерлока Холмса.
  Он должен отвечать на сообщения от лица персонажа, разгадывать загадки и вести
  беседы в детективном стиле.
</AiPrompt>

<div id="exemplos-de-automao-temporizada">
  ### Примеры автоматизации по расписанию
</div>

**Ежедневная сводка задач из Linear**

<AiPrompt>
  Каждое утро отправляйте мне письмо со сводкой новых задач в Linear. Включайте
  приоритеты задач, сроки и контекст проекта, чтобы я мог спланировать свой день.
</AiPrompt>

**Автоматизация дайджеста писем**

<AiPrompt>
  Каждые 6 часов отправляйте мне письмо со сводкой всех моих писем. Группируйте их по
  важности и выделяйте срочные сообщения, требующие немедленного внимания.
</AiPrompt>

**Еженедельный анализ конкурентов**

<AiPrompt>
  Каждый понедельник в 8:00 отправляйте мне сводку новостей о моих
  конкурентах на основе веб-поиска. Сосредоточьтесь на обновлениях продуктов, новостях о финансировании и
  изменениях на рынке.
