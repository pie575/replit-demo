---
title: "История файлов"
description: "Узнайте, как восстановить предыдущие версии кода с помощью автоматически создаваемых точек сохранения File History."
---

Откройте текстовый файл в Project Editor и нажмите кнопку **History** в правом нижнем углу.

<Frame>
  <img src="/assets/mirror/history-button-afac6496660a.png" alt="открытие истории" width="377" height="292" data-path="images/programming-ide/history-button.png" />
</Frame>

<div id="visualizando-verses-anteriores-de-um-arquivo">
  ## Просмотр предыдущих версий файла
</div>

После открытия File History вы можете просматривать предыдущие версии файла с помощью полосы прокрутки, кнопок со стрелками или клавиш **стрелка влево** и **стрелка вправо**.

<Frame>
  <img src="/assets/mirror/history-versioning-1a055ecab411.gif" alt="демонстрация полосы прокрутки" width="764" height="720" data-path="images/animations/history-versioning.gif" />
</Frame>

<div id="comparando-verses-anteriores-com-o-arquivo-atual">
  ## Сравнение предыдущих версий с текущим файлом
</div>

Нажмите кнопку Compare Latest в левом нижнем углу панели File History, чтобы просмотреть построчное сравнение версии файла на тот момент с его последней версией.

<Frame>
  <img src="/assets/mirror/compare-history-46fb16debd3a.gif" alt="сравнение с последней версией" width="772" height="720" data-path="images/animations/compare-history.gif" />
</Frame>

<div id="restaurando-uma-verso-anterior-de-um-arquivo">
  ## Восстановление предыдущей версии файла
</div>

Чтобы восстановить файл до предыдущей версии, просто нажмите кнопку `Restore`. История при этом не будет удалена. Восстановленная версия добавится в историю файла как новая версия.

<Frame>
  <img src="/assets/mirror/restore-history-5f616d7f961a.webp" alt="изображение восстановления истории" width="720" height="495" data-path="images/animations/restore-history.webp" />
</Frame>

<div id="visualizando-a-reproduo-do-file-history">
  ## Просмотр воспроизведения File History
</div>

С помощью функции воспроизведения File History можно увидеть, как файл менялся с течением времени, словно в фильме. Это может быть полезно для создания видео ваших сеансов программирования.

</Frame>
