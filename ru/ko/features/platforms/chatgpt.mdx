Интеграция Replit в ChatGPT позволяет создавать, изменять и проверять Replit App прямо в диалоге. Отдельная настройка не требуется. Просто общайтесь с ChatGPT и создавайте настоящие приложения — всё остальное берёт на себя Agent.

<div id="chatgpt-replit">
  ## Что такое Replit в ChatGPT
</div>

Replit в ChatGPT связывает ваши диалоги в ChatGPT с мощной платформой разработки Replit. Опишите, что вы хотите создать, и Agent соберёт полностью рабочее Replit App. Когда приложение готово, вы можете попросить ChatGPT изменить, обновить или проанализировать его — и всё это в обычном диалоге.

<div id="section">
  ## Начало работы
</div>

Выполните следующие шаги, чтобы подключить Replit к ChatGPT и создать своё первое приложение.

<div id="replit-chatgpt">
  ### Подключение Replit к ChatGPT
</div>

Подключить Replit к ChatGPT можно двумя способами:

<Accordion title="Подключение через Settings">
  1. В ChatGPT нажмите на значок профиля
  2. Перейдите в **Settings** → **Apps &amp; Connectors**
  3. Найдите **Replit** и нажмите **Connect**
  4. Завершите авторизацию через OAuth с помощью учётной записи Replit
</Accordion>

<Accordion title="Подключение из чата">
  1. Начните новый чат в ChatGPT
  2. Вызовите Replit одним из способов, описанных ниже
  3. Если подключение ещё не установлено, ChatGPT проведёт вас через процесс OAuth
</Accordion>

<div id="chatgpt-replit-2">
  ### Вызов Replit из ChatGPT
</div>

После подключения вызвать Replit можно тремя способами:

| Method         | How to use                                    |
| -------------- | --------------------------------------------- |
| Direct mention | Начните сообщение с `Replit, <текст запроса>` |
| Slash command  | Введите `/Replit` в поле ввода                |
| Composer menu  | Нажмите кнопку **+** → **More** → **Replit**  |

<div id="section-2">
  ### Создание первого приложения
</div>

После подключения создайте свой первый Replit App:

1. Начните новый диалог в ChatGPT
2. Обратитесь к Replit и опишите, что хотите создать (например, «Replit, create a todo app with dark mode»)
3. Agent создаст приложение и автоматически выполнит его деплой
4. По завершении вы получите ссылку, по которой можно открыть приложение

<Note>
  В каждом диалоге можно работать только с одним Replit App. Если создать новое приложение в том же диалоге, будет изменено уже существующее. Чтобы создать несколько приложений, начинайте отдельные диалоги.
</Note>

<div id="section-3">
  ## Возможности
</div>

* **[Replit AI](/ru/ko/build/welcome)**: Agent создаёт приложения и выполняет их деплой по запросам на естественном языке
* **[Project Editor](/ru/ko/learn/projects-and-artifacts/project-editor)**: полнофункциональная среда разработки, доступная прямо из ChatGPT
* **[Publishing](/ru/ko/learn/projects-and-artifacts/replit-deployments)**: деплой приложения выполняется автоматически, и им сразу можно поделиться

<Accordion title="Что можно делать">
  **Create:** опишите, что вам нужно, и создайте новое Replit App. Agent сгенерирует приложение и автоматически выполнит его деплой.

  **Update:** изменяйте приложение прямо в текущем диалоге. Попросите ChatGPT добавить функции, исправить ошибки или внести правки — Agent всё сделает.

  **Inspect:** анализируйте приложение, ничего в нём не меняя. Вы получите информацию о структуре кода, путях к файлам и поведении приложения.
</Accordion>

<Accordion title="Поддерживаемые форматы файлов">
  В промпт можно добавлять файлы разных форматов:

  | Format                  | Supported                    |
  | ----------------------- | ---------------------------- |
  | PDF                     | Yes                          |
  | CSV                     | Yes                          |
  | Common document formats | Yes                          |
  | Images (raw files)      | No (use public URLs instead) |
  | Videos (raw files)      | No (use public URLs instead) |

  <Note>
    Чтобы добавить в приложение изображения или видео, укажите в промпте публичные URL. После создания приложения медиафайлы также можно добавить напрямую в Replit.
  </Note>
</Accordion>

<Accordion title="Время сборки">
  Типичное время сборки приложения с помощью Agent:

  | App complexity                                     | Typical build time |
  | -------------------------------------------------- | ------------------ |
  | Simple (calculators, small landing pages)          | 2–3 minutes        |
  | Complex (games, rich animations, dense dashboards) | 3–4 minutes        |
</Accordion>

<div id="section-4">
  ## Доступность и тарифы
</div>

<Accordion title="Тарифы ChatGPT">
  Интеграция с Replit работает на всех типах тарифов ChatGPT:

  | Plan           | Supported | Notes                                                                     |
  | -------------- | --------- | ------------------------------------------------------------------------- |
  | Free           | Yes       |                                                                           |
  | Plus           | Yes       |                                                                           |
  | Pro            | Yes       |                                                                           |
  | Business       | Yes       | Требуется включение администратором в **Workspace settings → Connectors** |
  | Enterprise/Edu | Yes       | Требуется включение администратором в **Workspace settings → Connectors** |

  **Доступность по регионам:** все регионы, кроме ЕС.
</Accordion>

<Accordion title="Тарифы Replit">
  Интеграция с ChatGPT поддерживается на всех типах тарифов Replit:

  | Plan           | Supported | Notes                                                          |
  | -------------- | --------- | -------------------------------------------------------------- |
  | Starter (Free) | Yes       | Только публичные приложения                                    |
  | Core           | Yes       | Приватные приложения, расширенная сборка, Publishing, Database |
  | Pro            | Yes       | Увеличенный ежемесячный лимит кредитов, все возможности Core   |
  | Enterprise     | Yes       | Доступны все возможности                                       |
</Accordion>

<div id="section-5">
  ## Оплата и кредиты
</div>

Действия, которые Replit выполняет в ChatGPT, тарифицируются как Usage Replit Agent в вашем аккаунте Replit.

<Accordion title="Как происходит списание">
  * Тарифы **Core** и **Pro** включают ежемесячные кредиты, которые можно расходовать на Agent, publishing и databases в пределах установленных лимитов
  * Можно приобрести **credit pack**: он действует 6 месяцев и не продлевается автоматически. Подходит для всплесков трафика при запуске или для экспериментов
  * Ограничивайте расходы с помощью **usage limits** и **budgets** в настройках платежа Replit

  Подробнее см. в [документации по платежам ИИ](/ru/ko/billing/ai-billing).
</Accordion>

<div id="section-6">
  ## Текущие ограничения
</div>

На данный момент Replit App в ChatGPT:

* может работать только с приложениями, созданными в этом же диалоге
* не может открывать или изменять:
  * приложения, созданные в других чатах ChatGPT
  * приложения, созданные непосредственно в Replit

Полное соответствие возможностям Replit — базы данных, управление секретами, расширенные элементы управления Project Editor — появится позже.

<div id="section-7">
  ## Устранение неполадок
</div>

<Accordion title="Replit не отображается в Browse apps">
  Если Replit не отображается в разделе **Browse apps**, проверьте следующее:

  * доступно ли приложение в вашем регионе;
  * включил ли администратор рабочего пространства Replit App (Business/Enterprise/Edu).
</Accordion>

<Accordion title="Сбой сборки">
  Если сборка завершилась с ошибкой, откройте приложение в Replit:

  * проверьте раздел Usage и историю платежей;
  * воспользуйтесь чекпоинтами и откатом, чтобы вернуться к предыдущему состоянию;
  * обратитесь за помощью напрямую к Agent в Project Editor.
</Accordion>
