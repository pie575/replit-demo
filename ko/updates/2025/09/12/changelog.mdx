export const YouTubeEmbed = ({videoId, title = "YouTube 동영상", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

Agent 3는 자율성, 안정성, 속도 전반에 걸쳐 대폭 향상되었습니다:

* **App Testing**: Agent가 실제 브라우저에서 직접 테스트해 문제를 찾아내고, 반복 점검 loop를 통해 수정합니다. [App Testing](/ko/core-concepts/agent/app-testing)을 참고하세요.
* **더 긴 실행 시간**: Agent는 Live Monitoring과 함께 최대 200분 동안 자율적으로 작업할 수 있어 대규모 빌드에 적합합니다. 자세한 내용은 [Agent](/ko/core-concepts/agent#max-autonomy)에서 확인하세요.
* **에이전트 생성**: schedule에 따라 실행되거나 Slack 및 Telegram과 연동되는 에이전트와 자동화를 만들어 보세요. [Agents &amp; Automations](/ko/core-concepts/agent/agents-and-automations)를 참고하세요.

<div id="app-connectors-and-integrations">
  ## 앱 connector 및 integration
</div>

내장 integration과 connector로 더 빠르게 출시하세요:

* **Replit managed**: 앱에서 별도 설정 없이 자동으로 작동하는 내장 integration입니다.
* **Connectors**: 한 번만 로그인하면 여러 앱에서 재사용할 수 있는 자사 integration입니다.
* **외부 integration**: 사용자의 API key를 사용해 Agent가 설정하는 신뢰할 수 있는 서드파티 서비스입니다.

<div id="agents-automations-beta">
  ## Agents &amp; Automations (베타)
</div>

Agent 3의 일부로 지능형 에이전트, 챗봇, 자동화 workflow를 만들어 보세요:

* **Slack Agent**: 리서치, Q&amp;A, 자동화를 위한 Slackbot 생성
* **Telegram Agent**: 일정 관리, 고객 지원 등을 위한 봇 구축
* **Timed Automation**: 지정한 주기에 맞춰 workflow 예약 실행
