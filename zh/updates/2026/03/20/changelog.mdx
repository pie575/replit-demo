<div id="replit-pwa-on-microsoft-app-store">
  ### Microsoft 应用商店上线 Replit PWA
</div>

Replit 现已以渐进式 Web 应用 (PWA) 的形式在 Microsoft 应用商店上架，Windows 用户可以更方便地找到并安装 Replit，获得接近原生应用的使用体验。

<div id="empty-project-creation">
  ### 创建空白 project
</div>

现在你可以在导入页面创建空白 project。空白 project 启动时不会触发 Agent (创建时不消耗积分) ，框架和工具链的配置完全由你掌控。该选项已上线导入页面，适合希望拥有这种控制力的构建者。

  ## Teams 和 Enterprise

<div id="enterprise-audit-log-portal">
  ### Enterprise 审计日志门户
</div>

Enterprise 审计日志门户 (v1) 现已面向所有 Enterprise 客户开放。管理员可以查看组织成员执行的事件，并将事件流集成到所选的 SIEM 平台，包括 S3、Datadog、Splunk、Google Cloud Storage 和 Microsoft Sentinel。
