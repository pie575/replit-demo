<div id="developer-framework-templates-have-been-removed">
  ## Les modèles de frameworks pour développeurs ont été supprimés
</div>

Les modèles de démarrage de langages et de frameworks (auparavant appelés frameworks pour développeurs) ne sont plus disponibles sur Replit. Les pages `replit.com/templates` et `replit.com/developer-frameworks` redirigent désormais vers la [Replit Gallery](https://replit.com/gallery).

Pour démarrer un nouveau projet, utilisez plutôt l&#39;une des options suivantes :

* **Commencer avec Replit Agent** — Décrivez ce que vous souhaitez créer depuis la [page d&#39;accueil](https://replit.com/) et laissez Agent mettre en place le projet pour vous.
* **[Importer depuis GitHub, GitLab ou Bitbucket](/fr/build/import-from-providers)** — Intégrez une base de code existante ou une stack de démarrage sous forme de nouvelle Replit App.
* **[Remixer une application publiée](https://replit.com/gallery)** — Parcourez la Replit Gallery pour découvrir des applications de la communauté que vous pouvez consulter et remixer comme point de départ.

<div id="enterprise-custom-templates">
  ## Modèles personnalisés Enterprise
</div>

Les organisations Enterprise peuvent créer des [modèles personnalisés](/fr/teams/custom-templates) qui s&#39;affichent comme options sélectionnables dans le champ de saisie d&#39;Agent pour tous les membres de l&#39;organisation. Les modèles personnalisés vont plus loin que les frameworks pour développeurs : ils intègrent des instructions Agent propres à l&#39;entreprise, des compétences et un contexte de projet préconfiguré. Consultez le [guide des modèles personnalisés](/fr/teams/custom-templates) pour en savoir plus.
