  ### Agent 现已支持自定义 MCP 服务器
</div>

Agent 现可连接到远程 Model Context Protocol (MCP) 服务器，只需极少配置即可使用新的功能和工具。这让 Agent 能够调用外部工具，并从远程系统获取上下文。

使用自定义 MCP 服务器，您可以：

* 连接到能够从外部工具获取上下文并执行操作的远程服务器
* 通过 MCP 开放标准访问数百种工具和数据源
* 自动加载各服务器提供的工具

合作伙伴可通过提供 MCP 服务器将其服务与 Agent 集成，无需额外的集成工作。

<div id="conector-plaid-para-enterprise">
  ### 企业版的 Plaid 连接器
</div>

企业版客户现在可以启用 Plaid 连接器，连接银行账户并使用金融科技基础功能构建应用。该连接器仍在积极开发中，我们会根据客户反馈持续添加新功能并进行改进。

使用 Plaid 连接器，您可以：

* 将银行账户连接到您的应用
* 使用金融科技基础功能构建金融功能
* 通过管理面板集中管理连接器
