---
title: "Режимы Agent"
description: "Узнайте, как выбрать режим сборки Agent: Free Mode, Power Mode или Max Mode."
---

Режимы Agent позволяют находить баланс между стоимостью и производительностью при работе с Agent. В раскрывающемся списке настроек Agent выберите **Free Mode**, **Power Mode** или **Max Mode**. В Free Mode всегда используется Auto. Разработчики с тарифами Core и Pro могут использовать [Model selector](/ru/ko/features/agent/model-selector) в Power Mode или Max Mode. Доступные режимы и настройки зависят от вашего тарифа и рабочего пространства.

<Note>
  Economy Mode больше не доступен. Его заменил Power Mode по той же цене.
</Note>

<Tip>
  **Сочетание клавиш:** нажмите **⌘+Shift+I** (Ctrl+Shift+I в Windows), чтобы переключать режимы Agent, не выходя из поля ввода чата.
</Tip>

<div id="free-mode">
  ## Free Mode
</div>

**Оптимизирован для начала работы.** Free Mode помогает генерировать идеи, разобраться в работе Replit и начать проект.

**Примечание:** Free Mode всегда использует Auto — интеллектуальную маршрутизацию моделей Replit. Чтобы выбирать модели вручную, используйте Power Mode или Max Mode.

<Note>
  Тарифы Core и Pro включают квоту Free Mode, которая обновляется каждые 5 часов. Когда квота будет исчерпана, Replit покажет время следующего обновления.
</Note>

Routines не запускаются в Free Mode. Они доступны в Power или Max Mode и требуют бюджета на каждый запуск. Подробнее см. в разделе [Routines](/ru/ko/chat/routines).

<div id="power-mode">
  ## Power Mode
</div>

**Оптимизирован для экономии.** Power Mode использует меньше кредитов на задачу и является оптимальным вариантом по умолчанию, когда нужны хорошие результаты без затрат на самые мощные модели.

**Подходит для:** повседневной разработки, обучения и экономичной работы над существующими проектами.

<div id="max-mode">
  ## Max Mode
</div>

**Оптимизирован для высокой производительности.** Max Mode использует более мощные модели для сложных задач, крупных кодовых баз и трудных проблем.

**Подходит для:** проектов уровня production, сложных функций и случаев, когда вам нужны наилучшие результаты от Agent.

<div id="section">
  ## Какой режим выбрать?
</div>

Ориентируйтесь на следующие рекомендации:

| Цель                                                                           | Рекомендуемый режим                                                                 |
| ------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------- |
| Поиск идей, знакомство с принципами работы Replit и начало работы над проектом | Free Mode                                                                           |
| Максимум промптов на кредит                                                    | Power Mode                                                                          |
| Баланс стоимости и качества для большинства проектов                           | Power Mode                                                                          |
| Ручной выбор модели                                                            | Power Mode или Max Mode                                                             |
| Наилучшие результаты для сложных задач производственного уровня                | Max Mode                                                                            |
| Наилучшие результаты для самых сложных задач                                   | Max Mode с более высоким уровнем [Effort](/ru/ko/features/agent/model-selector#effort) |

Выберите режим в раскрывающемся списке настроек Agent в поле ввода чата. Разработчики тарифов Core и Pro могут настроить [основную модель и Effort](/ru/ko/features/agent/model-selector) в Power Mode или Max Mode. Не существует одного режима, который всегда будет оптимальным. Выберите режим, подходящий для текущей задачи.

<div id="section-2">
  ## Настройки в общих проектах
</div>

Настройки Agent привязаны к вам, а не к проекту. Когда вы приглашаете участников команды в проект, каждый сохраняет собственные настройки следующих параметров:

* Режим (Free Mode, Power Mode или Max Mode)
* [Основная модель и Effort](/ru/ko/features/agent/model-selector), если доступно
* [Режим Plan](/ru/ko/features/agent/plan-mode)
* Автоматическое слияние фоновых задач
* Автоматическое одобрение планов

Если участник команды переключится на Max Mode для следующей задачи, ваши настройки не изменятся. Режим и настройки, указанные в раскрывающемся списке настроек Agent, будут использоваться Agent при отправке следующего сообщения независимо от количества участников проекта.

<div id="free-mode-2">
  ## Проверка квоты Free Mode
</div>

Откройте **Settings** → **Usage**, чтобы узнать остаток квоты Free Mode и дату её обновления. Практические советы по максимально эффективному использованию квоты см. в разделе [Как максимально эффективно использовать Free Mode](/ru/ko/chat/free-mode).
