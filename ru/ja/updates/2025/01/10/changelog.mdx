<div id="slack">
  ### Интеграция со Slack
</div>

Agent теперь интегрирован с API Slack. Это позволяет создавать с помощью Agent App, которые могут:

* Отправлять сообщения
* Читать историю сообщений

в ваших любимых каналах Slack и из них.

  <img src="/assets/mirror/slack-integration-1072c585c41e.png" alt="Интеграция со Slack" width="1640" height="739" data-path="images/changelog/2025-01-10/slack-integration.png" />
</Frame>

Поделитесь тем, что вы создали, в [Agent Showcase](https://forms.gle/qxpfr82wNpKsCdok9).

<div id="agentassistant">
  ### Улучшения Agent и Assistant
</div>

* Agent теперь быстрее загружается с главной страницы, поэтому вы можете быстрее приступить к созданию приложения.
* При выделении текста в Console и Shell появляется всплывающее окно с быстрым доступом к Assistant. Просто выделите текст и нажмите значок Assistant, чтобы задать вопрос.

  <img src="/assets/mirror/ask-assistant-cd529bf4a0b1.png" alt="Спросить Assistant" width="2532" height="1474" data-path="images/changelog/2025-01-10/ask-assistant.png" />
</Frame>

<div id="section-3">
  ### Улучшенное управление избранными проектами
</div>

Теперь добавлять публичные проекты организации в избранное и удалять их оттуда стало проще!

<Frame>
  <img src="/assets/mirror/feature-on-profile-95b81a71e0d7.png" alt="Избранные проекты в профиле" width="1836" height="644" data-path="images/changelog/2025-01-10/feature-on-profile.png" />
</Frame>

Теперь вы можете управлять статусом избранного для проектов прямо из рабочего пространства — через модальное окно сведений о проекте и таблицу индекса проектов.

<Frame>
  <img src="/assets/mirror/profile-preview-b8f2ecfed154.png" alt="Предпросмотр профиля" width="2126" height="1152" data-path="images/changelog/2025-01-10/profile-preview.png" />
</Frame>

Кроме того, добавив проект в избранное, вы можете предварительно просмотреть, как он будет отображаться в публичном профиле.
