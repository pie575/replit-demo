Console позволяет в реальном времени отслеживать и просматривать журналы работающих Replit App.
Используйте сведения о текущих и предыдущих запусках, чтобы понять работу App,
устранять ошибки и оптимизировать производительность.

<Tip>
  При отладке с Agent добавляйте журналы Console в промпт, чтобы предоставить контекст.
</Tip>

<div id="section">
  ## Возможности
</div>

Console предоставляет следующие инструменты, которые помогают понять работу App:

* **Журналирование в реальном времени**: просматривайте вывод App в реальном времени
* **Поддержка ИИ**: получайте рекомендации по устранению ошибок, указанных в журналах
* **История запусков**: просматривайте журналы предыдущих запусков для отслеживания изменений

<div id="section-2">
  ## Использование
</div>

Вы можете открыть инструмент Console прямо в Project Editor.

<Accordion title="Как открыть Console">
  В **панели инструментов** слева:

  1. <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Иконка всех инструментов" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> Выберите **Все инструменты**, чтобы просмотреть список инструментов Project Editor.
  2. <img class="icon-svg" src="/assets/mirror/console-8a41ac90789c.svg" alt="Иконка Console" width="16" height="16" data-path="images/icons/console.svg" /> Выберите **Console**.

  В **строке поиска**:

  1. Выберите значок <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="Иконка лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> в верхней части экрана, чтобы открыть поиск.
  2. Введите &quot;Console&quot;, найдите инструмент и выберите его в результатах поиска.
</Accordion>

При каждом нажатии кнопки **Run** в Replit App в Console появляется новая запись со следующей информацией:

* Команда, запустившая код
* Временная метка
* Стандартный вывод и журналы ошибок

На следующем снимке экрана показаны команда `npm run dev`, использованная для запуска App, и сообщения журнала выполнения:

  <img src="/assets/mirror/console-log-entry-b57e5b89087d.png" alt="Запись журнала Console с выполненной командой" width="1948" height="870" data-path="images/workspace/console-log-entry.png" />

<Note>
  Логи на стороне клиента, создаваемые HTML-, CSS- и JS-кодом, отображаются только в инструментах разработчика [Preview](/ru/ko/features/editor/preview).

<div id="ai">
  ### Отладка с помощью ИИ
</div>

Если в журналах вы обнаружили ошибку или информацию, которую хотите понять, нажмите кнопку
**Ask AI** в верхней части записи. Вкладка **Agent** откроется автоматически,
а содержимое журнала будет отправлено на анализ.

<div id="section-3">
  ### Команды для записей журнала
</div>

Console предоставляет следующие инструменты для управления журналами:

* **Show Only Latest**: включите этот переключатель, чтобы отображался только последний запуск.
* **Свернуть запись**: нажмите стрелку вниз <img class="icon-svg" src="/assets/mirror/down-arrow-9c1cf9fd152e.svg" alt="иконка стрелки вниз" height="16" width="16" data-path="images/icons/down-arrow.svg" /> слева от имени команды, чтобы скрыть журналы.
* **Очистить предыдущие запуски**: выберите этот пункт, чтобы удалить журналы предыдущих запусков. Это действие нельзя отменить.

<div id="section-4">
  ### Доступность в сети
</div>

Вы можете управлять доступностью разрабатываемого App в сети.

Чтобы прекратить обработку запросов по URL для разработки, нажмите значок
<img class="icon-svg" src="/assets/mirror/network-off-5bdca8a4fe4e.svg" alt="Иконка отключённой сети" height="16" width="16" data-path="images/icons/network-off.svg" /> глобуса с косой чертой справа от строки сведений о сети.

Чтобы снова включить обработку запросов, нажмите значок
<img class="icon-svg" src="/assets/mirror/network-on-15be2e5fb4f5.svg" alt="Иконка включённой сети" height="16" width="16" data-path="images/icons/network-on.svg" /> глобуса.

Чтобы узнать URL для разработки, выберите текст `{...}.replit.dev` в адресной строке.

<Frame>
  <img src="/assets/mirror/preview-dev-url-b36770b33769.png" alt="Расположение URL для разработки в Preview" width="1222" height="824" data-path="images/workspace/preview-dev-url.png" />
</Frame>

<Note>
  Даже если отключить обработку запросов по URL для разработки, App останется доступным на вкладке Preview.
</Note>

<div id="section-5">
  ### Остановка команд рабочего процесса
</div>

В инструменте Console редактора Project Editor можно остановить выполняемые команды рабочего процесса.

Чтобы завершить выполнение, нажмите квадратную кнопку справа от строки с командой запуска Replit App.

Чтобы снова запустить App, используйте кнопку **Run** рабочего процесса в верхней части Project Editor.
