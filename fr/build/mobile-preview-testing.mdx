Expo Go est le moyen le plus rapide de tester PixelGames sur votre téléphone. Commencez par là, puis passez à
TestFlight ou à Internal Testing lorsque vous aurez atteint les limites d’Expo Go.

<div id="what-is-expo">
  ## Qu’est-ce qu’Expo ?
</div>

Expo est la boîte à outils utilisée par Agent pour créer PixelGames. Elle permet à Agent d’écrire l’app une seule fois en
JavaScript et d’exécuter ce même code comme une véritable app iOS ou Android.

Expo Go est une app gratuite disponible sur l’App Store ou Google Play. Installez-la une seule fois, puis prévisualisez
n’importe quel projet Expo, y compris PixelGames, simplement en scannant un code QR.

<Steps>
  <Step title="Ouvrez Expo Go">
    Ouvrez l’app **Expo Go** sur votre téléphone (iOS ou Android).
  </Step>

  <Step title="Scannez le code QR">
    Scannez le code QR que Replit affiche dans le volet Preview.
  </Step>

  <Step title="Attendez le chargement">
    Metro, le bundler d’Expo, regroupe PixelGames et l’envoie sur votre téléphone. Le premier
    chargement peut prendre une ou deux minutes, mais les suivants seront plus rapides.
  </Step>

  <Step title="Testez l’app">
    PixelGames s’ouvre sur votre téléphone. Les modifications d’Agent apparaissent en quelques secondes, sans
    réinstallation.
  </Step>
</Steps>

<div id="what-expo-go-cannot-test">
  ## Ce qu’Expo Go ne permet pas de tester
</div>

Expo Go couvre les écrans, les parcours et l’UI. Certaines fonctionnalités ne fonctionnent que lorsque PixelGames s’exécute comme
une App indépendante sur le téléphone : c’est notamment le cas des **notifications push**, des **achats intégrés** et de **Sign in with Apple**.

Pour les tester, téléversez PixelGames sur Apple ou Google, puis installez l’App depuis leur canal de test
bêta. Votre App reste privée et accessible uniquement à vous et aux testeurs que vous invitez, et vous pouvez continuer à l’améliorer
avant toute publication.

* [Téléverser votre App iOS](/fr/build/mobile-upload-ios)
* [Téléverser votre App Android](/fr/build/mobile-upload-android)

<div id="troubleshooting">
  ## Résolution des problèmes
</div>

* **Le code QR ne se scanne pas ou l’app ne se connecte pas :** vérifiez que votre téléphone et votre ordinateur sont sur le
  même réseau WiFi ; certains réseaux d’entreprise et publics bloquent la connexion entre les appareils. Sur
  l’un de ces réseaux, demandez à Agent de démarrer l’app en mode tunnel.
* **Les modifications n’apparaissent pas sur votre téléphone :** secouez votre téléphone pour ouvrir le menu développeur d’Expo,
  puis appuyez sur **Reload** pour télécharger de nouveau PixelGames.
* **Écran d’erreur rouge :** il s’agit généralement d’une erreur JavaScript ou d’un package manquant. Le message
  indique souvent le fichier et la ligne exacts ; partagez-le avec Agent et demandez-lui de corriger le problème.
* **Fonctionne sur iOS, mais pas sur Android (ou inversement) :** collez l’erreur dans Agent en précisant
  la plateforme concernée.
* **La console Shell semble défectueuse sur un appareil :** demandez à Agent de vérifier la taille de l’écran ou la gestion
  des zones de sécurité pour cet appareil.
