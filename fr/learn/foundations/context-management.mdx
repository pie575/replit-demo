Le contexte désigne les informations qu&#39;un modèle d&#39;IA utilise pour produire sa réponse suivante. La gestion du contexte consiste à fournir au modèle les bonnes informations au bon moment.

C&#39;est essentiel, car l&#39;IA ne se fonde pas uniquement sur votre intention. Elle s&#39;appuie sur le texte, les fichiers, les captures d&#39;écran, les logs, les exemples et l&#39;historique de la conversation présents dans sa fenêtre de contexte.

<div id="what-is-a-context-window">
  ## Qu&#39;est-ce qu&#39;une fenêtre de contexte ?
</div>

Un modèle d&#39;IA ne peut prendre en compte qu&#39;une quantité limitée d&#39;informations à la fois. Cette limite s&#39;appelle la fenêtre de contexte.

La fenêtre de contexte peut inclure :

* Votre prompt
* Les messages précédents de la conversation
* Les fichiers ou le code visibles par le modèle
* Les messages d&#39;erreur et les logs
* Les captures d&#39;écran, images ou références de design
* Les instructions du projet, comme `replit.md`
* Les résultats d&#39;outils issus des étapes précédentes

Le modèle s&#39;appuie sur ce contexte pour déterminer ce qu&#39;il doit générer ensuite.

<div id="why-context-windows-matter">
  ## Pourquoi les fenêtres de contexte sont importantes
</div>

Si les détails importants ne figurent pas dans le contexte, le modèle risque de faire des suppositions. Si le contexte contient trop d&#39;informations sans rapport, le modèle risque de se concentrer sur le mauvais élément.

Par exemple, ce prompt fournit peu de contexte :

```text theme={null}
Améliore la page d'inscription.
```

Ce prompt fournit un contexte utile :

```text theme={null}
Améliore la page d'inscription pour des fondateurs débutants qui hésitent à s'inscrire sur la liste d'attente.
Conserve les champs actuels. Rends la proposition de valeur plus claire au-dessus du formulaire.
Ne modifie pas la section des tarifs.
```

Le second prompt indique au modèle à qui s&#39;adresse la page, ce qu&#39;il faut améliorer, ce qu&#39;il faut préserver et ce qui sort du périmètre.

<div id="context-window-sizes-vary">
  ## La taille des fenêtres de contexte varie
</div>

Les modèles d&#39;IA ne traitent pas tous la même quantité de contexte. Les fenêtres de contexte plus grandes permettent de prendre en compte davantage de texte à la fois, mais plus grand ne signifie pas toujours meilleur. Un contexte pertinent reste plus utile que le fait de déverser le moindre détail dans la conversation.

Exemples de tailles de fenêtres de contexte rendues publiques :

| Famille de modèles | Exemple de fenêtre de contexte  |
| ------------------ | ------------------------------- |
| GPT-4.1            | Jusqu&#39;à 1 million de jetons |
| Claude Sonnet 4.5  | Jusqu&#39;à 200 000 jetons      |
| Gemini 2.5 Pro     | Jusqu&#39;à 1 million de jetons |

Ces chiffres évoluent avec le temps et ne garantissent pas que chaque produit expose la limite maximale du modèle. La leçon pratique, elle, ne change pas : gardez les informations importantes claires et ciblées.

<div id="types-of-context">
  ## Types de contexte
</div>

| Type de contexte              | Exemple                                                                                          |
| ----------------------------- | ------------------------------------------------------------------------------------------------ |
| **Objectif**                  | « Cette page de destination doit collecter des inscriptions à la liste d&#39;attente. »          |
| **Audience**                  | « C&#39;est destiné à des restaurateurs très occupés. »                                          |
| **Contraintes**               | « Conserve la palette de couleurs et les champs de formulaire actuels. »                         |
| **Objectifs exclus**          | « N&#39;ajoute pas encore de paiements. »                                                        |
| **Exemples**                  | Une capture d&#39;écran, une maquette, des données d&#39;exemple ou la page d&#39;un concurrent. |
| **État du projet**            | Le fichier, le composant, le message d&#39;erreur ou le parcours utilisateur actuel.             |
| **Définition du « terminé »** | « Un visiteur peut soumettre le formulaire et voir un message de remerciement. »                 |

<div id="fresh-context-and-persistent-context">
  ## Contexte ponctuel et contexte persistant
</div>

Certains éléments de contexte ont leur place dans la conversation en cours. Utilisez-les lorsque vous demandez une modification précise, que vous déboguez un problème ou que vous donnez un retour sur un résultat récent.

D&#39;autres doivent persister à l&#39;échelle du projet. Réservez le contexte persistant au style de code, aux chartes graphiques, aux conventions de nommage, aux règles produit réutilisables et aux contraintes qu&#39;Agent doit garder en mémoire d&#39;une session de travail à l&#39;autre. Sur Replit, [replit.md](/fr/features/project-setup/replit-dot-md) est l&#39;un des moyens de fournir à Agent un contexte de projet persistant.

<div id="when-context-gets-noisy">
  ## Quand le contexte devient confus
</div>

Les longues conversations ont tendance à dériver. Si un fil de discussion mélange trop de décisions sans rapport entre elles, Agent risque de s&#39;appuyer sur un ancien contexte qui n&#39;a plus lieu d&#39;être.

Ouvrez un nouveau fil de discussion lorsque :

* Vous passez à une fonctionnalité sans rapport
* La conversation contient de nombreuses pistes abandonnées
* Agent continue d&#39;appliquer d&#39;anciennes contraintes
* Vous souhaitez repartir sur un plan clair pour un nouveau domaine

Lorsque vous repartez de zéro, résumez le contexte important plutôt que de supposer qu&#39;Agent sait ce qui compte encore.

```text theme={null}
Contexte : ce projet est une application de liste d'attente destinée aux coachs sportifs locaux.
Le parcours principal est : page de destination → formulaire d'inscription → message de confirmation.
Dans ce fil de discussion, améliore uniquement le message de confirmation et le texte de relance.
```

<div id="common-misconceptions">
  ## Idées reçues courantes
</div>

* **« Plus il y a de contexte, mieux c&#39;est. »** C&#39;est un contexte pertinent qui fait la différence. Trop d&#39;informations sans rapport peuvent égarer le modèle.
* **« Le modèle se souvient parfaitement de tout. »** L&#39;IA exploite le contexte disponible, mais n&#39;hésitez pas à rappeler les contraintes importantes lorsqu&#39;elles sont déterminantes.
* **« Le contexte, ce n&#39;est que du texte. »** Captures d&#39;écran, fichiers, données, designs, logs et exemples peuvent tous servir de contexte.
