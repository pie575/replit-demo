  ## 团队与 Enterprise
</div>

<div id="faa-upgrade-para-enterprise-sem-sair-do-replit">
  ### 无需离开 Replit 即可升级至 Enterprise
</div>

现在，您可以从任何套餐 (Free、Core 或 Pro) 升级至 Replit Enterprise，无需离开产品，也无需事先联系销售团队。如果您有协作工作区，完成结账后，这些工作区将自动迁移到新的 Enterprise 组织。整个过程中，您已发布的 App 将持续在线，不会中断。

<div id="faturamento">
  ## 账单

<div id="conecte-o-stripe-instalando-um-app-sem-copiar-chaves">
  ### 安装应用即可连接 Stripe，无需复制密钥
</div>

将应用与 Stripe 一起发布变得更简单了。现在不必再从 Stripe 控制面板复制生产环境 API 密钥，只需在 Stripe Marketplace 中安装 Replit Integrated Payments 应用即可，生产密钥会自动配置完成。打开发布面板，安装该应用，然后在 Stripe 中完成连接。

<div id="agent">
  ## Agent
</div>

<div id="o-agent-pode-gerar-msica-efeitos-sonoros-e-narrao">
  ### Agent 可以生成音乐、音效和旁白
</div>

Agent 现在可以为你的应用创建音频。只需提出背景音乐、音效或语音旁白的需求，Agent 就会生成音频并直接添加到你的项目中。相关用量将从你的 Replit 积分中扣除。

详细了解[音频生成](/zh/pt/features/agent/audio-generation)。

<div id="gere-mdia-diretamente-no-canvas">
  ### 直接在 Canvas 中生成媒体
</div>

现在你可以直接在 Canvas 中创建媒体。打开 Canvas 工具栏中的**生成**工具，选择**图片**、**矢量图形**或**视频**，即可原地生成。整个流程都在画布内完成，无需切换工具即可创建和迭代。
