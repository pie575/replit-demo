<div id="enhanced-link-context-features">
  ### 향상된 링크 컨텍스트 기능
</div>

<div id="web-view-performance-improvements">
  ### Web View 성능 개선
</div>

Web View에서 iframe 탐색이 더 매끄러워지고 보안 웹사이트와의 호환성도 좋아졌습니다. 프록시 시스템이 보안 headers를 더 지능적으로 처리하도록 개선되어, 이전에 겪으셨을 수 있는 답답한 탐색 차단 문제가 사라졌습니다.
