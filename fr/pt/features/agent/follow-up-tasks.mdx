<div id="sugestes-de-tarefas-de-acompanhamento">
  ## Suggestions de tâches de suivi
</div>

Une fois que vous avez appliqué une tâche, l&#39;Agent examine le contexte de votre projet et suggère des **tâches de suivi** que vous pourriez vouloir créer ensuite. La boîte de dialogue **Prochaines tâches suggérées** affiche la principale recommandation directement dans le fil, pour que vous puissiez continuer sans quitter la conversation principale.

<Frame>
  <img src="/assets/mirror/follow-up-tasks-dialog-c1660cec2d1d.png" alt="Boîte de dialogue des prochaines tâches suggérées affichant une tâche de suivi avec un bouton Démarrer et un lien pour voir plus de tâches dans le tableau des tâches" width="495" height="290" data-path="images/agent/follow-up-tasks-dialog.png" />
</Frame>

Les suggestions de suivi peuvent inclure :

* **De nouvelles fonctionnalités à créer** : des capacités qui complètent naturellement ce que vous venez de lancer
* **Des améliorations de performance** : des optimisations que l&#39;Agent a repérées en travaillant sur la tâche
* **Des améliorations de l&#39;expérience utilisateur** : des finitions et des ajustements qui parachèvent la fonctionnalité

Sélectionnez **Démarrer** sur une suggestion pour l&#39;exécuter en arrière-plan, ou **Voir le plan** pour examiner d&#39;abord le travail proposé. Pour voir toutes les suggestions, sélectionnez **Voir plus dans le tableau des tâches**. Les suivis suggérés apparaissent sous **Suggéré** dans la colonne **Brouillons**.

<Frame>
  <img src="/assets/mirror/follow-up-tasks-kanban-21087e0210b6.png" alt="Tableau des tâches affichant plusieurs suggestions de tâches de suivi sous Suggéré dans la colonne Brouillons" width="980" height="627" data-path="images/agent/follow-up-tasks-kanban.png" />
</Frame>

Fermer la boîte de dialogue **Prochaines tâches suggérées** annule les suggestions. L&#39;Agent n&#39;affiche pas cette boîte de dialogue dans la version principale lorsqu&#39;un plan proposé y est déjà en attente, afin que les deux prompts ne se disputent pas votre attention.

<div id="gerenciando-muitas-sugestes-de-uma-vez">
  ## Gérer plusieurs suggestions à la fois
</div>

Pour les projets comportant de nombreuses suggestions de suivi, ouvrez le tableau des tâches et sélectionnez **Modifier** dans la colonne **Brouillons**. En mode édition, une case à cocher apparaît devant chaque tâche suggérée. Sélectionnez les tâches de votre choix, puis utilisez **Démarrer** ou **Annuler** pour appliquer cette action à chacune d&#39;elles. Sélectionnez **Terminé** pour quitter le mode édition.
