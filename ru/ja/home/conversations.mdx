<div id="ask-a-question">
  ### Задайте вопрос
</div>

Replit может находить и анализировать информацию в интернете, подключённых инструментах и загруженных файлах. Задайте конкретный вопрос или укажите контекст, который Replit должен использовать.

Например, попросите Replit подвести итоги вашей активности в Slack за эту неделю и отметить
сообщения, требующие ответа.

<div id="run-a-routine">
  ### Запуск Routine
</div>

Routine планирует повторяющуюся работу внутри Conversation. Replit возвращает каждый результат в ту же Conversation, где вы можете его просмотреть и продолжить работу. Подробнее о [Routines](/ru/chat/routines).

Например, попросите Replit каждое утро просматривать Slack и присылать вам список приоритетов.

<div id="conversations-vs-projects">
  ## Conversation или Project
</div>

Conversation — это один thread для вопросов, исследования и Routine. [Project](/ru/features/projects-and-artifacts/projects) — это более полноценный workspace для серьёзной работы по сборке и дизайну, включающий несколько артефактов.

Начинайте с Conversation. Когда работа перерастает в полноценную сборку или дизайн, Conversation можно превратить в Project.

В боковой панели Conversation обозначается иконкой чата, а Project — иконкой сетки из четырёх квадратов.

<Frame>
  <img src="/assets/mirror/conversation-and-project-icons-025a17613daa.png" alt="Боковая панель Replit: Project с иконкой сетки из четырёх квадратов и Conversation с иконкой чата" width="466" height="290" data-path="images/chat/conversation-and-project-icons.png" />
</Frame>

| Область         | Conversation                     | Project                                                                                              |
| --------------- | -------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Лучше всего для | Вопросов, исследования и Routine | Более серьёзной работы по сборке и дизайну: приложения, презентации, дашборды и несколько артефактов |
| Фоновые задачи  | **Недоступны**                   | **Могут выполняться параллельно**                                                                    |
| Routine         | **Доступны**                     | **Недоступны**                                                                                       |
| Интеграции      | Доступны                         | Доступны                                                                                             |
| Структура       | Один thread                      | Workspace проекта с несколькими артефактами                                                          |
