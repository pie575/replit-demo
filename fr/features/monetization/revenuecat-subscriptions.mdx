<div id="what-is-revenuecat">
  ## Qu&#39;est-ce que RevenueCat
</div>

RevenueCat vous permet d&#39;ajouter des abonnements intégrés à votre [application mobile native](/fr/features/artifact-types/building-mobile-apps). Pour commencer, demandez à Agent de mettre en place un abonnement, puis connectez votre compte RevenueCat : Agent se charge de la logique et fournit un environnement de test.

<div id="prerequisites">
  ## Prérequis
</div>

Avant de commencer, vous devez disposer de :

* Un project Replit créé avec une **application mobile**
* Un compte [RevenueCat](https://www.revenuecat.com) (seuls une adresse e-mail et un mot de passe sont requis — aucun compte bancaire ni configuration supplémentaire)

<Note>
  Pour travailler sur une application mobile native, utilisez le Project Editor sur [replit.com](https://replit.com). Le développement d&#39;applications mobiles natives est également possible dans l&#39;application Replit pour Android, là où il est pris en charge. Si vous utilisez l&#39;application Replit pour iOS, ouvrez le project sur replit.com.
</Note>

<div id="test-subscriptions">
  ## Tester les abonnements
</div>

Les aperçus Replit utilisent le **mode test** de RevenueCat. Lorsque vous testez un achat dans Expo Go, une boîte de dialogue d&#39;achat de test s&#39;affiche à la place d&#39;un véritable flux de paiement. Aucun montant n&#39;est débité.

<Frame>
  <img src="/assets/mirror/revenuecat-test-purchase-8414145a112e.png" alt="Boîte de dialogue d'achat de test sur un appareil mobile affichant les détails du forfait et les boutons de test" width="683" height="1253" data-path="images/replitai/revenuecat-test-purchase.png" />
</Frame>

<Tip>
  Les achats de test peuvent être utilisés en toute sécurité pendant le développement. Vous pouvez tester aussi bien les flux d&#39;achat
  réussis que les flux en échec, sans aucun débit réel.
</Tip>

<Warning>
  Dès qu&#39;Apple approuve la distribution de votre application sur l&#39;App Store, les achats sont facturés avec de l&#39;argent réel.
  Vérifiez que vos produits et vos tarifs RevenueCat sont corrects avant de soumettre votre application à
  l&#39;App Review.
</Warning>

<div id="manage-subscriptions">
  ## Gérer les abonnements
</div>

<div id="syncing-to-app-store-connect">
  ## Synchronisation avec App Store Connect
</div>

Pour que les achats intégrés fonctionnent dans TestFlight et l&#39;App Store d&#39;Apple, [vous devrez accepter
le contrat Applications payantes d&#39;Apple et connecter votre compte bancaire](https://developer.apple.com/help/app-store-connect/manage-agreements/sign-and-update-agreements/).
Cela se fait via App Store Connect. Un compte Apple Developer payant est nécessaire avant de pouvoir soumettre votre app à l&#39;App Store.

Vous pourrez ensuite synchroniser vos configurations d&#39;achats intégrés de RevenueCat vers App Store Connect directement depuis Replit.

<Steps>
  <Step title="Accédez au volet Gérer dans Publishing">
    Vous verrez un bouton permettant de synchroniser RevenueCat avec App Store Connect.

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-sync-btn-46a2e4e696df.png" alt="Bouton Synchroniser RevenueCat avec App Store Connect" width="1476" height="604" data-path="images/replitai/revenuecat-asc-sync-btn.png" />
    </Frame>

    <Tip>
      Cette section n&#39;apparaît qu&#39;après la soumission de votre app à TestFlight.
    </Tip>
  </Step>

  <Step title="Fournissez une clé API App Store Connect">
    Vous devrez vous rendre sur App Store Connect pour obtenir cette clé.

    Dans [App Store Connect](https://appstoreconnect.apple.com/access/integrations/api), allez dans **Users and Access**, puis sélectionnez l&#39;onglet **Integrations**. Dans la barre latérale, sélectionnez **App Store Connect API**.

    Lors de la création d&#39;une clé, veillez à lui accorder les autorisations « App Manager ».

    Téléchargez le fichier .p8 dès maintenant : il n&#39;est téléchargeable qu&#39;une seule fois. Le nom du fichier commence par `AuthKey_` et se termine par `.p8`.

    Copiez le **Key ID** et l&#39;**Issuer ID** affichés sur cette page.

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-create-c54be8304d7c.png" alt="Page Users and Access d'App Store Connect avec des étapes numérotées mettant en évidence l'onglet Integrations, le lien App Store Connect API dans la barre latérale et le bouton plus pour créer une nouvelle clé API" width="2390" height="752" data-path="images/replitai/revenuecat-asc-create.png" />
    </Frame>

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-app-manager-93996acd8561.png" alt="Boîte de dialogue Generate API Key dans App Store Connect avec le nom défini sur RevenueCat et l'accès défini sur App Manager" width="1116" height="560" data-path="images/replitai/revenuecat-asc-app-manager.png" />
    </Frame>

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-copy-07a95e1be9af.png" alt="Page des clés API d'App Store Connect avec des flèches pointant vers le lien Copy de l'Issuer ID et la colonne Key ID" width="2330" height="780" data-path="images/replitai/revenuecat-asc-copy.png" />
    </Frame>
  </Step>

  <Step title="Créez une clé API In-App Purchase">
    Répétez l&#39;étape précédente pour une clé API In-App Purchase.
    Dans la barre latérale, sélectionnez **In-App Purchase**. Créez ensuite une clé API avec les autorisations **App Manager**.
    Téléchargez la clé .p8 (le nom du fichier commence par `SubscriptionKey_` et se termine par `.p8`). Copiez le **Key ID** et l&#39;**Issuer ID**.

    <Frame>
      <img src="/assets/mirror/revenuecat-iap-api-key-7eb34e815ccb.png" alt="Page Users and Access d'App Store Connect avec In-App Purchase sélectionné dans la barre latérale et une flèche pointant vers le bouton plus pour créer une nouvelle clé" width="2272" height="637" data-path="images/replitai/revenuecat-iap-api-key.png" />
    </Frame>
  </Step>

  <Step title="Synchronisez les produits">
    Confirmez la liste des produits et synchronisez-la avec App Store Connect.

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-products-sync-078d42af83ba.png" alt="Boîte de dialogue de gestion des achats intégrés affichant un produit Abonnement mensuel avec les champs prix, durée et territoire, ainsi qu'un bouton Sync to App Store Connect" width="948" height="476" data-path="images/replitai/revenuecat-asc-products-sync.png" />
    </Frame>
  </Step>
</Steps>

<div id="frequently-asked-questions">
  ## Questions fréquentes
</div>

<AccordionGroup>
  <Accordion title="Ai-je besoin d'un compte bancaire pour utiliser RevenueCat ?">
    Non. Une adresse e-mail et un mot de passe suffisent pour créer un compte
    RevenueCat. La configuration du compte bancaire se fait séparément, via Apple
    ou Google, lorsque vous êtes prêt à recevoir vos versements de l&#39;App Store ou
    de Google Play.
  </Accordion>

  <Accordion title="Les achats de test sont-ils facturés ?">
    Non. Pendant le développement, les aperçus Replit utilisent le mode test de
    RevenueCat. Les achats sont simulés et aucun montant réel n&#39;est débité. Les
    facturations réelles n&#39;interviennent qu&#39;après l&#39;approbation de votre app par
    l&#39;App Review d&#39;Apple.
  </Accordion>

  <Accordion title="Puis-je utiliser RevenueCat avec une web app ?">
    RevenueCat est conçu pour les apps mobiles natives. Pour ajouter des
    abonnements à une web app, utilisez plutôt l&#39;[intégration
    Stripe](/fr/features/monetization/stripe-payments).
  </Accordion>

  <Accordion title="Que puis-je configurer avec RevenueCat ?">
    Vous pouvez mettre en place des abonnements mensuels ou annuels, définir les
    tarifs, gérer les droits d&#39;accès et créer des paywalls. Demandez à Agent
    d&#39;effectuer les modifications : il gère à la fois la configuration RevenueCat
    et le code de votre app.
  </Accordion>
</AccordionGroup>
