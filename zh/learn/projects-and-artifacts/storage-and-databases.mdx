借助 Replit 灵活的存储解决方案，您可以快速为应用添加运行所需的数据存储。
对于有以下需求的应用，您可以使用 Replit 的数据库或对象存储，Agent 还可以自动配置和集成这两种方案：

* 需要保存玩家进度或最高分等信息的游戏
* 需要管理媒体文件的内容平台

<div id="what-are-replits-storage-and-database-options">
  ## Replit 提供哪些存储和数据库选项
</div>

Replit 提供以下数据存储选项：

* **数据库**：用于存储用户个人资料、游戏分数和产品目录等结构化数据。
  您可以根据属性和数据点之间的关系存储或检索数据。

* **App Storage**：用于存储图像、视频和文档等非结构化数据。
  您可以存储和检索大型文件及二进制数据。

<div id="app-storage-and-database-comparison">
  ### App Storage 与数据库对比
</div>

|            | 数据库                     | App Storage           |
| ---------- | :---------------------- | :-------------------- |
| **理想数据格式** | 具有关系的结构化数据              | 大型文件 (图片、视频、文档)       |
| **数据模型**   | 表、行、列                   | 存储桶、文件                |
| **查询语言**   | SQL                     | REST API              |
| **客户端**    | 兼容 PostgreSQL 的客户端和 ORM | Replit SDK 和 GCS 客户端库 |
| **计费模式**   | 按计算时间和存储空间计费            | 按带宽和存储空间计费            |

<div id="project-editor-tools">
  ### Project Editor 工具
</div>

了解以下 Replit 工具，帮助你设置和管理应用的数据存储：

<CardGroup>
  <Card title="数据库" href="/zh/features/data-and-storage/sql-database" icon="database">
    适合存储结构化数据和表示数据之间的关系。
    由可随应用扩展的全托管 PostgresSQL 数据库提供支持。
  </Card>

  <Card title="App Storage" href="/zh/features/data-and-storage/object-storage" icon="bucket">
    适合存储非结构化数据和大型文件，例如图片、视频和文档。
    由 Google Cloud Storage (GCS) 提供支持，具备高可用性和可扩展性。Agent 可自动设置具有高级身份验证和访问控制的 App Storage。
  </Card>
</CardGroup>
