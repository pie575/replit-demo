Регион проекта — это регион публикации проекта. Он выбирается при публикации и определяет, где размещаются вычислительные ресурсы и хранилище опубликованного проекта.

<Note>
  Регион проекта может отличаться от [региона
  Workspace](/ru/features/collaboration/workspace-geography). Регион Workspace
  определяет, где размещаются ресурсы разработки новых проектов в Workspace.
</Note>

<div id="section">
  ## Чем управляет регион проекта
</div>

По умолчанию Replit рекомендует ближайший к вам регион. Это помогает сократить задержку для пользователей App и соблюдать требования к размещению данных.

При выборе региона все опубликованные артефакты проекта (вычислительные ресурсы, базы данных, Object Storage и другие) автоматически размещаются в одном регионе. Региональные прокси также помогают сократить задержку для пользователей App.

<div id="section-2">
  ## Выбор региона проекта
</div>

Чтобы выбрать регион, отличный от рекомендованного, выполните следующие действия.

<Steps>
  <Step>В проекте Replit откройте инструмент **Publishing**.</Step>
  <Step>Разверните настройки **Дополнительно**.</Step>
  <Step>В раскрывающемся списке **Geography** выберите нужный регион.</Step>

  <Step>
    Нажмите **Publish**, чтобы опубликовать проект в выбранном регионе.
  </Step>
</Steps>

<div id="section-3">
  ## Принудительное назначение региона публикации для проектов
</div>

Администраторы Enterprise могут принудительно назначить регион публикации для всех проектов в организации. После настройки политики разработчики организации смогут публиковать проекты только в указанном регионе. Эта политика применяется только к ещё не опубликованным проектам. Она не влияет на проекты, уже опубликованные в другом регионе.

<Note>
  Принудительное назначение региона публикации — функция Enterprise. Подробнее о тарифе
  Enterprise см. на странице [Pricing](https://replit.com/pricing/).
</Note>

<Steps>
  <Step>Перейдите в **Account settings**.</Step>
  <Step>Выберите **Дополнительно**.</Step>

  <Step>
    Выберите регион, который будут использовать все проекты при первой публикации.
  </Step>
</Steps>

<div id="section-4">
  ## Доступность и ограничения
</div>

| Регион            | Возможность публикации проекта |
| :---------------- | :----------------------------- |
| **North America** | Доступно                       |
| **Europe (EU)**   | Доступно                       |
| **Asia**          | Доступно                       |
| **South America** | Доступно                       |
| **Australia**     | Доступно                       |

<Note>
  Выбор региона проекта доступен пользователям тарифов Core, Pro и Enterprise. Пользователи Free
  по умолчанию публикуют проекты в North America.
</Note>

Перед выбором региона проекта учитывайте следующие ограничения.

* **Регион нельзя изменить после публикации.** Если вы публикуете проект в определённом регионе, этот выбор становится постоянным. Перенести опубликованный проект в другой регион нельзя.
* **Регионы разработки и публикации могут различаться.** Такие ресурсы, как Object Storage, могут быть созданы до публикации и находиться в регионе, отличном от региона проекта.
