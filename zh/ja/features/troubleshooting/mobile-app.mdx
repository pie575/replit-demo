---
title: "移动应用故障排查"
description: "解决在 Replit 上使用 Expo 和 React Native 创建移动应用时的常见问题。"
---

在 Replit 上创建移动应用时，你可能会遇到预览、打包或软件包依赖方面的问题。本指南介绍常见问题的解决方法，涵盖从快速修复到详细的调试步骤。

<div id="section">
  ## 快速修复
</div>

先试试以下方法，大多数问题都能解决：

| 问题       | 解决方法                         |
| -------- | ---------------------------- |
| 手机上看不到更改 | 摇动手机打开 Expo 菜单，点按 **Reload** |
| 预览中看不到更改 | 在控制台中按 **R** 重新打包            |
| 应用卡死或无响应 | 在控制台中停止应用并重新启动               |

<div id="section-2">
  ## 常见问题
</div>

<AccordionGroup>
  <Accordion title="设备未反映更改">
    如果修改后手机上没有显示更新：

    1. **摇动手机**，打开 Expo 开发者菜单
    2. 点击 **Reload** 重新下载打包文件

    在网页预览中，在控制台按 **R** 即可重新打包。

    如果更改仍未生效，请尝试清除缓存 (参见下方的[清除 Metro 缓存](#clear-the-metro-cache)) 。
  </Accordion>

  <Accordion title="Expo Go 中出现红色错误界面">
    红色错误屏幕通常表示存在 JavaScript 错误或缺少模块。请仔细阅读错误消息——它往往会指出具体的文件和行号。

    **常见原因：**

    * 未安装软件包，或版本不正确
    * 模块在 Web 上可用但在原生环境中不可用 (或反之)
    * 代码中存在语法错误

    **可以尝试的操作：**

    1. 仔细阅读错误消息——它往往会准确指出问题所在
    2. 将该消息分享给 Agent，请它协助修复
    3. 如果错误提到了某个特定软件包，请尝试重新安装依赖项 (参阅[重新安装软件包](#reinstall-packages))
  </Accordion>

  <Accordion title="在 Web 上正常运行，但在智能手机上崩溃（或反之亦然）">
    某些包或功能在不同平台上的行为可能有所不同。React Native 会编译到 iOS、Android 和 Web 三个目标平台。有些库能在 Web 上运行，却不支持原生平台，或者需要不同的配置。

    **可以尝试的方法：**

    1. 查看包的文档，确认其平台支持情况
    2. 向 Agent 提问：“这个包与 Expo Go 兼容吗？”
    3. 如果移动端不支持，可考虑将该功能移到服务器端

    <Tip>
      查找包时，请留意“Expo compatible”标识，或在 [Expo SDK 文档](https://docs.expo.dev/versions/latest/)中查看受支持的模块。
    </Tip>
  </Accordion>

  <Accordion title="无法扫描二维码或无法连接应用">
    **检查网络：**

    * 手机和电脑必须连接到同一个 WiFi 网络
    * 企业网络或公共网络可能会阻止连接

    **尝试隧道模式：**
    如果你所处的网络有限制，隧道模式会将流量通过 Expo 的服务器转发。你可以让 Agent 以隧道模式启动应用，或在 Shell 中运行 `npx expo start --tunnel`。

    **重启 Expo Go：**
    扫描前先彻底关闭 Expo Go，然后重新打开。
  </Accordion>

  <Accordion title="构建耗时过长">
    首次构建由于没有缓存，速度总是较慢，后续构建应该会明显加快。

    **影响构建时间的因素：**

    * 项目中的软件包数量
    * 清除缓存后的首次运行
    * 下载软件包时的网络速度

    如果构建始终很慢，请检查是否安装了不必要的软件包。
  </Accordion>

  <Accordion title="找不到模块的错误">
    如果出现「Unable to resolve module」或「Module not found」：

    1. 可能是软件包未安装 —— 让 Agent 安装该软件包
    2. 可能是软件包已安装但缓存过期 —— 清除缓存
    3. 可能是软件包不存在或名称拼写有误 —— 核对软件包名称

    如果该模块本应存在，请尝试[重新安装软件包](#reinstall-packages)。
  </Accordion>
</AccordionGroup>

<div id="section-3">
  ## 调试命令
</div>

如果快速修复未能解决问题，可以使用以下命令重置各类缓存和状态。请在 Shell 中运行。

<div id="metro">
  ### 清除 Metro 缓存
</div>

Metro 是用于编译 React Native 代码的打包器。清除缓存可强制进行一次全新构建。

在 Shell 中运行以下命令：

```bash theme={null}
npx expo start --clear
```

这会清除打包器缓存并重启开发服务器，输出中会显示 “Bundler cache is empty. Rebuilding.”。

<Tip>
  如果缓存问题频繁出现，可以在启动命令中添加 `-c`。你可以让 Agent 在开发命令中加上清除缓存的标志。
</Tip>

<div id="section-4">
  ### 重新安装软件包
</div>

如果遇到模块错误或版本不匹配的问题，重新安装软件包通常就能解决。

在 Shell 中运行以下命令：

```bash theme={null}
rm -rf node_modules && npm install
```

这会删除所有已安装的软件包，并根据 `package.json` 重新完整安装一次。

<Note>
  如果你的项目使用的是其他软件包管理器 (例如 `bun` 或 `pnpm`) ，请使用相应的安装命令：`bun install` 或 `pnpm install`。
</Note>

<div id="section-5">
  ### 检查版本不匹配
</div>

Expo Doctor 会扫描项目，检测软件包之间的版本不匹配等常见问题。

在 Shell 中运行以下命令：

```bash theme={null}
npx expo-doctor
```

检查输出中的警告。如果系统建议修复，请谨慎评估——如果新版本包含不兼容的变更，盲目升级软件包可能会引入新的问题。

<Warning>
  只有在确有必要时才更新软件包。&quot;顺手&quot;升级可能会因新版本存在不兼容变更而导致应用出错。
</Warning>

<div id="section-6">
  ## 完全重置
</div>

如果其他方法都无效，可以通过完全重置清除所有缓存并重新安装全部内容。

<Accordion title="终极方案：完全重置命令">
  该命令会删除所有缓存，并从头重新安装软件包。请仅在万不得已时使用。

  ```bash theme={null}
  rm -rf node_modules .expo && npm cache clean --force && npm install && npx expo start --clear
  ```

  **具体操作：**

  1. `rm -rf node_modules` — 删除已安装的软件包
  2. `rm -rf .expo` — 删除 Expo 的本地缓存
  3. `npm cache clean --force` — 清除 npm 的全局缓存
  4. `npm install` — 重新安装所有软件包
  5. `npx expo start --clear` — 清除 Metro 缓存后启动

  执行该命令后，所有内容都会从头重新构建，因此下一次构建会耗时较长。
</Accordion>

<div id="section-7">
  ### 清除设备缓存
</div>

如果重新加载后手机上的应用仍在运行旧代码：

* **iOS**：在 Expo Go 中进入 **Settings**，点击 **Clear Cache**
* **Android**：依次进入 **Settings &gt; Apps &gt; Expo Go &gt; Storage &gt; Clear Cache**

<div id="section-8">
  ## 快速参考
</div>

| 问题           | 首先尝试                     | 然后尝试                |
| ------------ | ------------------------ | ------------------- |
| 更改未生效        | 摇动手机 → Reload            | 清除 Metro 缓存         |
| 打包器报错        | `npx expo start --clear` | 删除 node&#95;modules |
| 找不到模块        | 重新安装依赖                   | 完全重置                |
| 版本不匹配警告      | 运行 `npx expo-doctor`     | 评估建议的修复方案           |
| 新安装的包无法使用    | 重启服务器                    | 清除 Metro 缓存         |
| 修改了 app.json | 重启服务器                    | —                   |

<div id="section-9">
  ## 需要更多帮助
</div>

如果问题仍未解决：

* **询问 Agent**：描述你遇到的错误以及已经尝试过的操作。Agent 通常能够诊断并修复问题。
* **查阅 Expo 文档**：[Expo 疑难解答指南](https://docs.expo.dev/troubleshooting/overview/)涵盖了更多场景。
* **搜索错误信息**：复制完整的错误消息进行搜索 —— 很可能已经有人遇到过同样的问题。
