# Gestion de vos connecteurs

> Configurez et gérez les connecteurs sur les plans Core, Pro et Enterprise. Contrôles administrateur centralisés, accès délimité et suivi des audits.

Vous pouvez gérer les connecteurs afin que votre équipe utilise les intégrations de manière cohérente et sécurisée. Les fonctionnalités disponibles dépendent de votre plan :

* **Core et Pro** : La gestion des connecteurs est disponible dans les **espaces de travail collaboratifs**. L'administrateur du compte configure et gère les connexions pour cet espace de travail ; les créateurs peuvent les utiliser dans les applications de cet espace de travail.
* **Enterprise** : Gestion des connecteurs à l'échelle de l'organisation avec des contrôles avancés — clients OAuth personnalisés, contrôles d'accès aux clés API et apport de vos propres clés.

## Fonctionnalités clés

* **Gestion centralisée** : L'administrateur configure un service une seule fois ; les créateurs l'utilisent dans toutes les applications de cet espace de travail.
* **Visibilité et audit** : Voyez quelles applications et quels membres utilisent quels services.
* **Consentement et révocation par application** : Révoquez ou faites pivoter l'accès sans modifier le code.

**Enterprise uniquement :**

* **Contrôles d'accès basés sur les rôles** : Autorisations délimitées avec le principe du moindre privilège et contrôles d'accès sur les clés API.
* **Apportez votre propre OAuth** : Utilisez des clients OAuth appartenant à votre organisation avec des portées personnalisées.
* **Apportez votre propre clé OpenAI** : Utilisez votre propre clé API OpenAI au lieu de celle par défaut de Replit.

## Fonctionnement

<Steps>
  <Step title="L'administrateur configure un service">
    L'administrateur configure un service une seule fois en utilisant les identifiants.
  </Step>

  <Step title="L'administrateur approuve l'accès">
    L'administrateur approuve les groupes pouvant utiliser le connecteur (Enterprise) ou le rend disponible pour l'espace de travail collaboratif (Core/Pro).
  </Step>

  <Step title="Les créateurs utilisent le connecteur">
    Les membres créent des applications avec ce service en demandant à l'Agent dans les applications au sein de l'espace de travail ou de l'organisation.
  </Step>

  <Step title="L'administrateur surveille l'utilisation">
    Les administrateurs peuvent surveiller quels membres et quelles applications utilisent quels services.
  </Step>
</Steps>

## Sécurité et gouvernance

* Les identifiants et jetons sont gérés par la plateforme, et non stockés dans des applications individuelles.
* Révocation et rotation centralisées sans modification du code.
* Enterprise : accès délimité avec autorisations à moindre privilège et configuration OAuth personnalisée optionnelle.

## Configuration et gestion

### Activer de nouveaux connecteurs

<Steps>
  <Step title="Accéder aux Intégrations">
    Depuis votre espace de travail collaboratif (Core/Pro) ou la page d'accueil de l'organisation (Enterprise), ouvrez la page **Intégrations**.
  </Step>

  <Step title="Activer un nouveau connecteur">
    Sélectionnez **Activer un nouveau connecteur** en haut à droite.
  </Step>

  <Step title="Sélectionner le service">
    Sélectionnez le service que vous souhaitez activer (par ex. Notion, GitHub, Google, Outlook, Dropbox, Salesforce).
  </Step>

  <Step title="Configurer le connecteur">
    Activez le connecteur en utilisant la configuration par défaut. Sur **Enterprise** uniquement, vous pouvez créer un connecteur OAuth personnalisé (par ex. portées Drive `.../auth/drive.file`, `.../auth/drive.install`).
  </Step>

  <Step title="Soumettre">
    Sélectionnez **Soumettre**.
  </Step>
</Steps>

### Configurer l'accès (Enterprise)

1. Après avoir activé un connecteur, sélectionnez **Gérer**.
2. Accordez l'accès à des groupes spécifiques selon les besoins.

### Modifier les connecteurs

* Après avoir activé un connecteur, sélectionnez **Gérer**.
* La suppression d'un connecteur le retire pour tous les créateurs de cet espace de travail (Core/Pro) ou de l'organisation (Enterprise).
* Sur Enterprise, vous pouvez modifier les portées des connecteurs OAuth personnalisés.

### Apporter votre propre clé OpenAI (Enterprise)

Les clients Enterprise peuvent utiliser les Connecteurs pour apporter leur propre clé API OpenAI au lieu de l'infrastructure IA par défaut de Replit. Cela vous permet d'utiliser vos accords OpenAI existants et de gérer l'utilisation de l'IA via votre propre compte.
