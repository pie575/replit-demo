Les compétences enseignent à Agent de nouvelles capacités : patterns privilégiés, spécificités de bibliothèques, règles de système de design ou solutions à des problèmes que vous avez déjà résolus. Joignez-en une à un message, installez-en une dans votre projet ou choisissez-en une comme point de départ d&#39;un nouveau projet.

<div id="usar-uma-skill-no-chat">
  ## Utiliser une compétence dans le chat
</div>

Le moyen le plus rapide d’essayer des compétences consiste à en joindre une à un message, sans avoir à l’installer.

<Frame>
  <img src="/assets/mirror/agent-skills-picker-ee4058454475.png" alt="Sélecteur de compétences ouvert via le bouton + à côté du champ de saisie du chat, affichant la liste des compétences, dont Ad Creative, AI Recruiter, AI SDR et AI Secretary" width="723" height="529" data-path="images/replitai/agent-skills-picker.png" />
</Frame>

<Steps>
  <Step title="Ouvrir le sélecteur de compétences">
    Cliquez sur le bouton **+** à côté du champ de saisie du chat, puis sélectionnez **Utiliser une compétence**.
  </Step>

  <Step title="Parcourir et sélectionner une compétence">
    Parcourez les compétences par catégorie : Affaires et finances, Création, Recherche et analyse, entre autres. Sélectionnez une ou plusieurs compétences à joindre à votre message.
  </Step>

  <Step title="Envoyer votre message">
    Saisissez votre demande et envoyez-la. Agent utilise les compétences sélectionnées uniquement pour ce message. Une pastille de compétence apparaît dans votre message pour vous indiquer quelles compétences sont actives.
  </Step>
</Steps>

Par exemple, joignez **Stock Analyzer** et demandez à Agent de créer un rapport d’analyse boursière, ou joignez **Deep Research** pour qu’Agent étudie un sujet et présente des résultats structurés.

<Tip>
  Les compétences jointes dans le chat n’installent rien dans votre projet. Elles sont immédiatement disponibles dans tous les projets.
</Tip>

<div id="iniciar-um-projeto-com-uma-skill">
  ## Démarrer un projet avec une compétence
</div>

Lors de la création d&#39;un nouveau projet, vous pouvez choisir une compétence prédéfinie comme point de départ. Agent s&#39;appuie sur les instructions de la compétence pour structurer le projet.

<Steps>
  <Step title="Ouvrir le sélecteur de point de départ">
    Sur l&#39;écran de nouveau projet, cliquez sur **+**, puis sélectionnez **Utiliser une compétence**.
  </Step>

  <Step title="Choisir une compétence">
    Parcourez les compétences proposées, telles que **AI SDR**, **SEO Auditor**, **Ad Creative** ou **Programmatic SEO**. Choisissez celle qui correspond au type d&#39;app que vous souhaitez créer.
  </Step>

  <Step title="Décrire votre app">
    Indiquez à Agent ce que vous souhaitez obtenir. Agent construit le projet en appliquant dès le départ les standards et conventions de la compétence.
  </Step>
</Steps>

<div id="instalar-uma-skill-no-seu-projeto">
  ## Installer une compétence dans votre projet
</div>

Pour qu&#39;Agent applique une compétence de manière systématique dans toutes les conversations d&#39;un projet, installez-la. Les compétences installées se trouvent dans le répertoire `/.agents/skills` de votre projet et persistent d&#39;une session de Chat à l&#39;autre.

<div id="instalar-pelo-painel-de-skills">
  ### Installer depuis le panneau compétences
</div>

Ouvrez le **panneau compétences** dans le Project Editor et sélectionnez l&#39;onglet **Découvrir** pour parcourir les compétences proposées par la communauté. Trouvez celle qui vous intéresse, cliquez sur **Installer** : elle est automatiquement ajoutée à votre projet.

<Frame>
  <img src="/assets/mirror/agent-skills-discover-732b2b0c488a.png" alt="Onglet Découvrir des compétences affichant les compétences proposées par la communauté, avec une option de recherche et des boutons d'installation" width="2542" height="1850" data-path="images/replitai/agent-skills-discover.png" />
</Frame>

Par exemple, si vous créez un site portfolio avec des animations avancées, vous pouvez installer :

* **GSAP React** — apprend à Agent les animations déclenchées au défilement, les révélations de texte et le tracé de chemins SVG
* **Tailwind design system** — donne à Agent la maîtrise des motifs Tailwind CSS pour la typographie, les espacements et les transitions d&#39;affichage
* **Find skills** — apprend à Agent à découvrir et installer de nouvelles compétences en votre nom

<Tip>
  Vous pouvez également installer des compétences via la [CLI npx skills](https://github.com/vercel-labs/skills) :

  ```bash theme={null}
  npx skills <skill> -a replit
  ```
</Tip>

<div id="criar-uma-skill-a-partir-de-uma-conversa">
  ### Créer une compétence à partir d&#39;une conversation
</div>

La façon la plus naturelle de créer une compétence consiste à passer par une conversation avec Agent. Après avoir résolu un problème ensemble ou exploré une nouvelle bibliothèque, demandez à Agent de consigner ce qu&#39;il a appris :

<AiPrompt>
  Research best practices for GSAP React integration and create a skill for this project.
</AiPrompt>

Agent s&#39;appuie sur l&#39;intégralité du contexte de la conversation pour rédiger un fichier de compétence détaillé. Cela fonctionne particulièrement bien après des sessions de débogage au cours desquelles vous avez élaboré une compréhension commune d&#39;un problème.

<div id="escrever-uma-skill-personalizada">
  ### Écrire une compétence personnalisée
</div>

Pour les cas d&#39;usage avancés, rédigez vos compétences directement en suivant la [spécification des Compétences Agent](https://agentskills.io/specification). Activez **Afficher les fichiers masqués** dans la barre latérale des fichiers, ouvrez `/.agents/skills/` et créez un fichier Markdown. Vous gardez ainsi un contrôle total sur ce que l&#39;Agent sait et sur la façon dont il se comporte.
