Project Editor 中的用户设置工具可让您自定义账户的外观、行为和键盘快捷键。

</Frame>

<div id="section">
  ## 功能
</div>

您可以通过以下设置类别自定义 Replit App 开发体验。

* **主题自定义**：在 Project Editor 的浅色主题和深色主题之间选择
* **代码智能**：配置可提升应用开发体验的 AI 功能
* **编辑器偏好设置**：调整文件编辑器的行为和外观
* **通知控制**：管理通知偏好设置
* **辅助功能选项**：让 Replit 更好地服务有特殊需求的用户
* **键盘快捷键**：设置用于执行常见操作和浏览图形界面的按键组合

<div id="section-2">
  ## 使用方法
</div>

<Accordion title="如何访问用户设置">

<div id="appearance">
  ### 外观(Appearance)
</div>

自定义以下 Project Editor 外观设置。

* **选择主题**：从浅色和深色主题预设、<a href="https://replit.com/themes" target="_blank">社区主题</a>或自定义主题中选择
* **自定义主题**：使用 [Themes](/zh/ko/features/editor/themes) 编辑器创建个性化配色方案

<div id="section-3">
  ### 文件编辑器设置
</div>

使用以下设置控制文件编辑器的外观和行为。

* **字体大小**：调整文本大小以提高可读性
* **自动闭合括号**：输入左括号时自动插入右括号
* **检测缩进**：打开文件时自动检测缩进设置
* **格式化粘贴文本的缩进**：重新格式化粘贴的代码，使其遵循正确的缩进
* **缩进字符**：选择使用空格或制表符缩进代码
* **缩进大小**：设置每个缩进级别的列数
* **自动换行**：配置自动换行行为
* **迷你地图**：在侧边栏中显示可导航的代码概览
* **多选修饰键**：设置用于选择多个文件的键盘修饰键
* **文件树 Git 状态**：在文件树中显示 Git 状态指示器

<div id="section-4">
  ### 代码智能
</div>

通过以下设置配置 AI 驱动的工具。

* **语义令牌**：使用语言服务器增强的语法高亮
* **AI 代码补全**：在输入过程中提供内联代码建议
* **通过提交字符接受建议**：输入特定字符时自动接受代码建议

<div id="shell-preview">
  ### Shell 和 Preview 设置
</div>

自定义 Shell 和 Preview 工具的行为。

* **Shell 响铃声音提示**：Shell 工具出现问题时播放提示音
* **自动预览**：服务器可用后自动打开 Preview 标签页
* **自动转发开放端口**：配置如何处理新检测到的端口

<div id="section-5">
  ### 通知
</div>

管理以下通知设置。

* **Agent 音频通知**：当 Agent 请求反馈时播放提示音
* **Agent 推送通知**：当 Agent 请求反馈时接收移动端推送通知

<div id="section-6">
  #### 生产警报
</div>

**Production Alerts** 是一项独立的电子邮件通知设置，可让您持续了解已发布应用的状态。它与产品和营销电子邮件相互独立，因此您可以及时掌握重要信息，而不会受到不必要通知的干扰。

开启 **Production Alerts** 后，您将收到以下电子邮件通知：

* **运行时间事件**：当已发布的应用宕机或无法保持在线状态时，您会收到通知。
* **安全漏洞**：当应用依赖的软件中发现漏洞时，您会收到通知，以便在问题发生前解决。
* **模型更新**：当应用使用的语言模型发生变更或需要您关注时，您会收到通知。

<Frame>
  <img src="/assets/mirror/production-alerts-highlight-bb76079f20fd.png" alt="通知设置中的 Production Alerts 部分，红色矩形突出显示生产警报电子邮件开关和安全警报严重程度下拉菜单" width="2400" height="1364" data-path="images/workspace/production-alerts-highlight.png" />
</Frame>

要找到此设置：

1. 在账户菜单中打开 **设置**。
2. 选择 **Personalization** 选项卡。
3. 滚动至 **Email Notifications** 部分，找到 **Production Alerts**。

如果已发布的应用使用过时的语言模型，Replit 会准备一个用于升级到受支持模型的草稿任务。您会收到一封包含该任务链接的电子邮件，只需审核一次即可完成升级。

<div id="section-7">
  ### 辅助功能
</div>

您可以自定义以下辅助功能设置。

* **无障碍终端输出**：启用 Shell 和控制台工具的屏幕阅读器兼容性

<div id="section-8">
  ### 键盘快捷键
</div>

要打开键盘快捷键设置，请在用户设置工具中选择 **Keyboard shortcuts** 选项卡。

您可以通过以下方式搜索按键组合：

* **名称**：在搜索框中输入键盘快捷键的名称或说明
* **按键组合**：选择 <img class="icon-svg" src="/assets/mirror/keyboard-7ba19771b671.svg" alt="键盘图标" width="16" height="16" data-path="images/icons/keyboard.svg" />，然后输入按键组合

您可以通过以下操作管理快捷键：

* **添加**：选择 **Add shortcut**
* **更新**：选择 <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="铅笔图标" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> 铅笔图标
* **移除**：选择 <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="垃圾桶图标" width="16" height="16" data-path="images/icons/trash-icon.svg" /> 垃圾桶图标
