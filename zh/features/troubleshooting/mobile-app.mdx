在 Replit 上构建移动应用时，你可能会遇到预览、打包或软件包依赖方面的问题。本指南帮助你解决常见问题：先从快速修复入手，再逐步深入到更细致的调试步骤。

<div id="quick-fixes">
  ## 快速修复
</div>

请先尝试以下方法——它们可以解决大多数问题：

| 问题         | 尝试方法                            |
| ---------- | ------------------------------- |
| 手机上的更改未显示  | 摇晃手机以打开 Expo 菜单，然后点击 **Reload** |
| 预览中未显示更改   | 在控制台中按 **R** 重新打包               |
| App 卡住或无响应 | 在控制台中停止并重启 App                  |

<div id="common-issues">
  ## 常见问题
</div>

<AccordionGroup>
  <Accordion title="改动没有在我的设备上显示">
    如果你做了改动，但手机上看不到：

    1. **摇动手机**打开 Expo 开发者菜单
    2. 点按 **Reload** 重新下载 bundle

    在网页预览中，在控制台按 **R** 触发重新打包。

    如果改动仍未出现，请尝试清除缓存 (参见下方的[清除 Metro 缓存](#clear-the-metro-cache)) 。
  </Accordion>

  <Accordion title="Expo Go 中出现红色错误屏幕">
    红色错误屏幕通常表示存在 JavaScript 错误或缺少模块。请仔细阅读错误信息——它往往会指出具体的文件和行号。

    **常见原因：**

    * 某个软件包未安装或版本不正确
    * 某个模块在网页端可用但在原生端不可用 (或反之)
    * 代码中存在语法错误

    **可以尝试的做法：**

    1. 仔细阅读错误信息——它通常会明确指出问题所在
    2. 把错误信息发给 Agent，请它帮忙修复
    3. 如果错误提到某个特定的软件包，尝试重新安装依赖 (参见[重新安装软件包](#reinstall-packages))
  </Accordion>

  <Accordion title="应用在网页端正常但在手机上崩溃（或反之）">
    有些软件包或功能在不同平台上的表现并不一致。React Native 会编译到三个目标平台：iOS、Android 和网页。在网页端可用的库可能不支持原生平台，或者需要另外配置。

    **可以尝试的做法：**

    1. 在该软件包的文档中确认它是否支持你所用的平台
    2. 询问 Agent：“这个软件包与 Expo Go 兼容吗？”
    3. 如果移动端不支持该功能，考虑把它移到服务器端实现

    <Tip>
      调研软件包时，留意是否标注“Expo compatible”，或查阅 [Expo SDK 文档](https://docs.expo.dev/versions/latest/)了解受支持的模块。
    </Tip>
  </Accordion>

  <Accordion title="二维码无法扫描或应用无法连接">
    **检查你的网络：**

    * 手机和电脑必须连接同一个 WiFi 网络
    * 某些企业网络或公共网络会阻止该连接

    **尝试隧道模式：**
    如果你处于受限网络中，隧道模式会通过 Expo 的服务器转发流量。可以让 Agent 以隧道模式启动应用，或在 shell 中运行 `npx expo start --tunnel`。

    **重启 Expo Go：**
    彻底关闭 Expo Go 后重新打开，再进行扫描。
  </Accordion>

  <Accordion title="构建耗时很长">
    首次构建总是较慢，因为还没有缓存。后续构建会快很多。

    **影响构建时间的因素：**

    * 项目中的软件包数量
    * 清除缓存后的首次运行
    * 下载软件包时的网络速度

    如果构建一直很慢，请检查是否安装了不必要的软件包。
  </Accordion>

  <Accordion title="找不到模块的错误">
    当你看到 “Unable to resolve module” 或 “Module not found” 时：

    1. 该软件包可能未安装——让 Agent 安装它
    2. 该软件包可能已安装，但缓存已过期——清除缓存
    3. 该软件包可能不存在或名称拼写有误——检查软件包名

    如果该模块本应存在，请尝试[重新安装软件包](#reinstall-packages)。
  </Accordion>
</AccordionGroup>

<div id="debugging-commands">
  ## 调试命令
</div>

如果快速修复无效，可以使用以下命令重置各类缓存和状态。请在 Shell 中运行这些命令。

<div id="clear-the-metro-cache">
  ### 清除 Metro 缓存
</div>

Metro 是编译 React Native 代码的打包器。清除它的缓存可强制重新构建。

在 Shell 中运行：

```bash theme={null}
npx expo start --clear
```

这会清除打包器缓存并重启开发服务器。你会在输出中看到“Bundler cache is empty. Rebuilding.”。

<Tip>
  如果你经常遇到缓存问题，可以在启动命令中添加 `-c`。请 Agent 更新开发命令，加入清除缓存标志。
</Tip>

<div id="reinstall-packages">
  ### 重新安装软件包
</div>

如果你遇到模块错误或版本不匹配的问题，重新安装软件包通常就能解决。

在 Shell 中运行：

```bash theme={null}
rm -rf node_modules && npm install
```

这会删除所有已安装的软件包，然后根据你的 `package.json` 重新安装。

<Note>
  如果你的项目使用其他软件包管理器 (如 `bun` 或 `pnpm`) ，请使用相应的安装命令：`bun install` 或 `pnpm install`。
</Note>

<div id="check-for-version-mismatches">
  ### 检查版本不匹配
</div>

Expo Doctor 会扫描你的项目，查找软件包版本不匹配等常见问题。

在 Shell 中运行：

```bash theme={null}
npx expo-doctor
```

查看输出中的警告信息。如果其中给出了修复建议，请仔细评估——不要盲目升级软件包，这可能会引入新的问题。

<Warning>
  只有在确有必要时才更新软件包。“为升级而升级”可能会导致 App 无法正常运行，因为新版本可能包含不兼容的变更。
</Warning>

<div id="full-reset">
  ## 完全重置
</div>

当其他方法都无效时，完全重置会清除所有缓存并重新安装所有内容。

<Accordion title="终极方案：完全重置命令">
  此命令会删除所有缓存并从头重新安装依赖软件包，请仅在万不得已时使用。

  ```bash theme={null}
  rm -rf node_modules .expo && npm cache clean --force && npm install && npx expo start --clear
  ```

  **该命令的作用：**

  1. `rm -rf node_modules` — 删除已安装的依赖软件包
  2. `rm -rf .expo` — 删除 Expo 的本地缓存
  3. `npm cache clean --force` — 清除 npm 的全局缓存
  4. `npm install` — 重新安装所有依赖软件包
  5. `npx expo start --clear` — 以全新的 Metro 缓存启动

  运行之后，所有内容都需从头重新构建，因此下一次构建耗时会更长。
</Accordion>

<div id="clear-cache-on-your-device">
  ### 清除设备缓存
</div>

如果手机上的 App 重新加载后似乎仍在使用旧代码：

* **iOS**：在 Expo Go 中，前往**设置**，然后轻点**清除缓存**
* **Android**：前往**设置 &gt; App &gt; Expo Go &gt; 存储 &gt; 清除缓存**

<div id="quick-reference">
  ## 快速参考
</div>

| 问题           | 先尝试                      | 再尝试                 |
| ------------ | ------------------------ | ------------------- |
| 更改未生效        | 摇动手机 → 重新加载              | 清除 Metro 缓存         |
| 打包器报错        | `npx expo start --clear` | 删除 node&#95;modules |
| 找不到模块        | 重新安装依赖                   | 完全重置                |
| 版本不匹配警告      | 运行 `npx expo-doctor`     | 评估建议的修复方案           |
| 新装的软件包不起作用     | 重启服务器                    | 清除 Metro 缓存         |
| 修改了 app.json | 重启服务器                    | —                   |

<div id="getting-more-help">
  ## 获取更多帮助
</div>

如果问题仍未解决：

* **询问 Agent**：描述遇到的错误以及你已经尝试过的操作。Agent 通常能够诊断并修复问题。
* **查看 Expo 文档**：[Expo 故障排查指南](https://docs.expo.dev/troubleshooting/overview/)涵盖了更多场景。
* **搜索错误信息**：复制完整的错误信息进行搜索——很可能已经有人遇到过同样的问题。
