Secrets 도구는 API 키, 인증 token, 데이터베이스 연결 문자열처럼 Replit App의 민감한 정보인 **secret**을 암호화하여 저장합니다.

secret을 추가하면 도구가 데이터를 자동으로 암호화하고, 환경 변수 형태로 Replit App에서 사용할 수 있게 해줍니다.
이렇게 하면 코드에 secret을 하드코딩할 필요가 없어 노출 위험을 줄일 수 있습니다.

  <iframe width="100%" height="400" src="https://www.youtube.com/embed/qE_2Z8ReyWI" title="Secrets Project Editor tool" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" allowfullscreen />

codebase에 secret을 하드코딩하면 다음과 같은 상황에서 실수로 노출될 수 있습니다:

* 공개 Replit App이나 복사-붙여넣기로 다른 사람과 코드를 공유할 때
* 공개 저장소의 version control에 코드를 체크인할 때
* 코드를 라이브 스트리밍하거나 화면 공유할 때

Secrets 도구를 사용하면 자격 증명 노출을 걱정하지 않고 안심하고 코드를 공유할 수 있습니다.

<div id="features">
  ## 기능
</div>

Secrets는 다음과 같은 기능을 제공합니다:

* **엔드투엔드 암호화**: 저장 데이터는 AES-256, 전송 데이터는 TLS 암호화로 자동 보호합니다
* **앱 수준 secret**: 특정 Replit App에서만 사용하는 secret을 저장하고 관리합니다
* **계정 수준 secret**: 모든 Replit Apps에서 사용할 수 있는 secret을 저장하고 관리합니다
* **환경 변수 접근**: 코드에서 환경 변수를 통해 secret에 접근합니다
* **협업 접근**: 협업자 및 팀 구성원과 secret을 공유합니다

</div>

<Accordion title="Secrets에 접근하는 방법">
  왼쪽 **Tool dock**에서:

  1. <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="All tools icon" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**를 선택해 Project Editor 도구 목록을 확인합니다.
  2. <img class="icon-svg" src="/assets/mirror/lock-af402c9618dd.svg" alt="Secrets icon" width="16" height="16" data-path="images/icons/lock.svg" /> **Secrets**를 선택합니다.

  **검색 창**에서:

  1. 상단의 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="magnifying glass icon" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 돋보기를 선택해 검색 도구를 엽니다

<div id="manage-app-secrets">
  ### 앱 Secrets 관리
</div>

**Secrets** 창의 **App Secrets** 탭에서 앱 수준 secret을 관리할 수 있습니다.
이 탭에는 Replit App에 연결된 모든 secret 목록이 표시됩니다.

<Accordion title="앱 Secrets 추가">
  secret을 추가하려면 다음 단계를 따르세요.

  1. **New Secret**을 선택합니다.
  2. secret의 이름인 **Key**와 secret 값 자체인 **Value**를 입력합니다.
  3. **Add Secret**을 선택해 항목을 저장합니다.
</Accordion>

<Accordion title="앱 Secrets 편집">
  secret을 편집하려면 다음 단계를 따르세요.

  1. secret 옆의 <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="세로 점 세 개 아이콘" height="16" width="16" data-path="images/icons/vertical-dots.svg" /> 세로 점 메뉴를 선택합니다.
  2. 컨텍스트 메뉴에서 **Edit**을 선택합니다.
  3. **Key** 또는 **Value** 필드의 텍스트를 수정한 뒤, **Update Secret**을 선택해 변경 사항을 저장하거나 **Cancel**을 선택해 변경 사항을 취소합니다.

  탭 하단의 **Edit as JSON** 또는 **Edit as .env**를 선택하면 App Secrets 목록 전체를 한 번에 수정할 수도 있습니다.
</Accordion>

<Accordion title="앱 Secrets 보기">
  secret을 보려면 secret 옆의 <img class="icon-svg" src="/assets/mirror/eye-8a6472b8a950.svg" alt="눈 아이콘" width="16" height="16" data-path="images/icons/eye.svg" /> 눈 아이콘을 선택합니다.

  secret을 다시 숨기려면 <img class="icon-svg" src="/assets/mirror/eye-slash-6b4ded538179.svg" alt="사선이 그어진 눈 아이콘" width="16" height="16" data-path="images/icons/eye-slash.svg" /> 사선이 그어진 눈 아이콘을 선택합니다.
</Accordion>

<Accordion title="앱 Secrets 삭제">
  secret을 삭제하려면 secret 옆의 <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="세로 점 세 개 아이콘" height="16" width="16" data-path="images/icons/vertical-dots.svg" /> 세로 점 메뉴를 선택한 뒤 **Delete**를 선택합니다.
</Accordion>

</div>

**Secrets** 창의 **Account Secrets** 탭에서 계정 수준 secret을 관리할 수 있습니다.
이 탭에는 Replit account에 연결된 secret만 표시됩니다.

<Accordion title="Account Secrets 추가">
  계정 수준 secret을 추가하려면 다음 단계를 따르세요.

  1. **Account Secrets** 탭으로 이동합니다.
  2. <img class="icon-svg" src="/assets/mirror/settings-icon-c2664c3691bf.svg" alt="톱니바퀴 아이콘" width="16" height="16" data-path="images/icons/settings-icon.svg" /> icon을 선택해 **Settings**를 열고 계정 수준 secret을 관리합니다.
  3. **New Secret**을 선택해 secret을 추가합니다.
  4. secret의 이름인 **Key**와 secret 값 자체인 **Value**를 입력합니다.
  5. **Save**를 선택해 항목을 저장합니다.
</Accordion>

<Accordion title="Account Secrets 편집">
  secret을 편집하려면 다음 단계를 따르세요.

  2. **Key** 또는 **Value** 필드의 텍스트를 수정한 후, **Save**를 선택해 changes를 저장하거나 **Cancel**을 선택해 changes를 취소합니다.

<Accordion title="Account Secrets 보기">

  secret을 다시 숨기려면 <img class="icon-svg" src="/assets/mirror/eye-slash-6b4ded538179.svg" alt="사선이 그어진 눈 아이콘" width="16" height="16" data-path="images/icons/eye-slash.svg" /> 사선이 그어진 눈 아이콘을 선택합니다.

<Accordion title="Account Secrets 연결">

<div id="managing-secrets-visibility">
  ### Secrets 표시 여부 관리
</div>

Secrets 표시 여부는 해당 Replit App에 대한 접근 권한과 본인이 만든 App인지 여부에 따라 달라집니다.

다음 옵션 중 하나를 사용해 Replit App을 공유할 수 있습니다:

* **멀티플레이어**: Replit 사용자를 초대해 실시간으로 협업합니다
* **커버 페이지**: Replit App의 미리보기를 보여주고 remix할 수 있는 옵션을 제공합니다
* **Remix**: 개인 또는 조직의 Replit App을 공개해 다른 사람이 자신만의 버전을 만들 수 있도록 합니다

다음 표는 상황별로 secret 이름과 값이 어떻게 표시되는지 보여줍니다:

| 접근 방식    | 대상                                 | 이름 확인 가능 | 값 확인 가능 |
| -------- | ---------------------------------- | -------- | ------- |
| 멀티플레이어   | 멀티플레이어 협업자                      | ✓        | ✓       |
| 멀티플레이어   | 조직 구성원(Owner 역할)                   | ✓        | ✓       |
| 멀티플레이어   | 조직 구성원(Owner 아님)                   | ✓        |         |
| 커버 페이지   | 모든 방문자                             |          |         |
| Remix    | 자신의 Replit App을 remix하는 소유자/협업자 | ✓        | ✓       |
| Remix    | Replit App을 remix하는 비소유자/협업자    | ✓        |         |
| Remix    | 커버 페이지에서 remix하는 모든 사람             | ✓        |         |
| 조직 Remix | Owner 역할을 가진 조직 구성원                | ✓        | ✓       |
| 조직 Remix | Owner 역할이 없는 조직 구성원                | ✓        |         |

<Warning>
  Owner 역할이 없는 조직 구성원은 Replit App에서 secret 값을 볼 수 없지만, environment variables를 출력하면 그 값을 확인할 수 있습니다.
</Warning>

<div id="database-related-secrets">
  ## 데이터베이스 관련 secret
</div>

Replit의 Database를 추가하면 Project Editor가 다음 secret을 자동으로 생성합니다.

| Secret         | 설명                |
| -------------- | ----------------- |
| `DATABASE_URL` | SQL 데이터베이스 연결 문자열 |

<Info>
  레거시 Neon development database에는 `PGHOST`, `PGUSER`, `PGPASSWORD`, `PGDATABASE`, `PGPORT`도 포함될 수 있습니다. 현재 Replit development database는 이를 대신해 `DATABASE_URL`을 사용합니다.
</Info>

Replit App의 모든 환경 변수를 확인하려면 Project Editor의 Shell 도구에서 `printenv`를 실행하거나 코드에서 직접 출력하세요.

<div id="predefined-environment-variables">
  ## 사전 정의된 환경 변수
</div>

Replit은 다음 환경 변수를 자동으로 설정하며, 앱에서 이 값에 접근할 수 있습니다.

| 환경 변수               | 설명                                                        |
| ------------------- | --------------------------------------------------------- |
| `REPLIT_DOMAINS`    | Replit App에 연결된 모든 도메인을 쉼표로 구분한 목록                        |
| `REPLIT_USER`       | 현재 편집자의 사용자 이름으로, Multiplayer 세션에서는 달라질 수 있습니다            |
| `REPLIT_DEPLOYMENT` | 코드가 published app에서 실행 중이면 `1`로 설정되고, 그렇지 않으면 설정되지 않습니다   |
| `REPLIT_DEV_DOMAIN` | `replit.dev` 도메인의 development URL로, Deployment URL과는 다릅니다 |

이 변수들은 Secrets 도구에 표시되지 않지만, 코드에서 `os.environ` 객체를 사용하거나 Shell에서 `printenv`를 실행해 확인할 수 있습니다.
