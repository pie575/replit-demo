<div id="como-o-replitmd-funciona">
  ## Как работает `replit.md`
</div>

Сначала Agent создаёт файл `replit.md` в корневом каталоге вашего проекта, опираясь на проверенную лучшую практику. В этот файл входят:

* Базовая информация о проекте
* Рекомендуемые стандарты написания кода
* Типовые предпочтения для данного типа проекта

<YouTubeEmbed videoId="kYv525W-vaU" title="Настройте, как Replit Agent отвечает вам" />

Обрабатывая ваши запросы, Agent автоматически читает файл `replit.md` и использует его содержимое, чтобы:

* Понимать архитектуру и соглашения вашего проекта
* Придерживаться выбранных вами стандартов и стиля написания кода
* Использовать указанные вами менеджеры пакетов и зависимости

Agent также может обновлять файл `replit.md` по мере того, как узнаёт больше о проекте и вносит изменения в ваше приложение.

<Note>
  Вы можете редактировать файл `replit.md`, чтобы настроить поведение Agent.
</Note>

<div id="configurando-o-replitmd">
  ## Настройка `replit.md`
</div>

<div id="gerao-automtica">
  ### Автоматическая генерация
</div>

Когда вы создаёте новый проект с помощью Agent, он автоматически генерирует файл `replit.md` на основе проверенных лучших практик. Этот файл появляется в корневом каталоге проекта и содержит:

* Основные сведения о проекте
* Рекомендуемые стандарты написания кода
* Типичные предпочтения для данного типа проекта

<div id="criao-manual">
  ### Создание вручную
</div>

Вы можете создать собственный файл `replit.md`, добавив новый файл с именем `replit.md` в корневой каталог проекта. Agent автоматически обнаружит его и будет использовать в дальнейших Conversation.

<Note>
  Файл `replit.md` должен находиться в корневом каталоге проекта — иначе он не будет работать.
</Note>

<div id="regenerando-o-replitmd">
  ### Повторная генерация `replit.md`
</div>

Если файл `replit.md` оказался поврежден или вы хотите начать с чистого листа:

1. Удалите существующий файл `replit.md` из корня проекта
2. Начните новый Conversation с Agent
3. Agent автоматически сгенерирует новый файл `replit.md` на основе вашего текущего проекта

  ## Сочетание веб-поиска с `replit.md`

Agent может искать в интернете актуальную информацию, библиотеки и решения. В сочетании с файлом `replit.md` вы получаете и свежие знания, и рекомендации, учитывающие особенности вашего проекта.

<div id="melhores-prticas-para-integrao-de-pesquisa-na-web">
  ### Лучшие практики интеграции веб-поиска
</div>

**Чётко формулируйте, что именно должен найти Agent:**

```markdown theme={null}
## Предпочтения по поиску
- Всегда проверяйте последние версии зависимостей, прежде чем предлагать обновления
- Изучайте актуальные лучшие практики реализации безопасности
- Ищите свежие приёмы оптимизации производительности для нашего стека
```

**Объясните Agent, как использовать внешние знания:**

```markdown theme={null}
## Правила внешнего поиска
- Предлагая новые библиотеки, проверяйте их совместимость с нашим текущим стеком
- Адаптируйте внешние примеры под наши стандарты написания кода и структуру проекта
- Убедитесь, что предложенные решения работают в нашей среде публикации
```

**Пример запроса, использующего оба подхода:**
&quot;Найди в интернете новейшие методы оптимизации производительности React 18 и примени их в соответствии с шаблонами компонентов, описанными в `replit.md`&quot;

Такой подход даёт решения, которые одновременно актуальны и адаптированы под конкретные потребности вашего проекта.

  ## Ограничения
</div>

<div id="limites-de-tamanho-e-contedo-do-arquivo">
  ### Ограничения на размер и содержимое файла
</div>

Хотя жёсткого ограничения по количеству символов для `replit.md` нет, слишком большие файлы могут быть обработаны не полностью. Чтобы добиться лучших результатов, держите `replit.md` кратким и по существу.

<div id="requisito-de-diretrio-raiz">
  ### Требование к корневому каталогу
</div>

Файл `replit.md` должен находиться в корневом каталоге проекта. Agent не находит такие файлы во вложенных каталогах автоматически.

<div id="escopo-do-contexto">
  ### Область действия контекста
</div>

Файл `replit.md` предоставляет контекст для Conversation с Agent, но автоматически не распространяется на другие инструменты ИИ.

<div id="prximos-passos">
  ## Дальнейшие шаги
</div>

Готовы настроить Agent под свой проект?

1. **Начните с простого**: создайте базовый `replit.md` с основными предпочтениями
2. **Дорабатывайте постепенно**: обновляйте `replit.md` по ходу работы с Agent
3. **Делитесь наработками**: применяйте удачные конфигурации `replit.md` в похожих проектах
4. **Следите за результатом**: обращайте внимание на то, как Agent соблюдает ваши указания, и корректируйте их при необходимости

Узнайте больше о [работе с Agent](/ru/pt/core-concepts/agent) или познакомьтесь с другими [инструментами ИИ](/ru/pt/build/welcome).

**Enterprise**: заранее настройте `replit.md` в [пользовательских шаблонах](/ru/pt/teams/custom-templates), чтобы все разработчики вашей организации получали единый начальный контекст. Рекомендации по дизайну смотрите в статье [как настроить дизайн-систему](/ru/pt/teams/custom-design-system).
