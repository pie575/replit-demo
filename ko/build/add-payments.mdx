이 과정을 마치면 Velocity 고객은 환불 가능한 보증금을 결제해 차량을 예약하고, 픽업할 때 잔액을 결제하게 됩니다.

지금까지 Velocity에 로그인과 데이터베이스를 추가했습니다. 이제 실제로 운영 가능한 예약 비즈니스로 만들어 봅니다. **예약 시 환불 가능한 보증금**으로 차량을 확보한 뒤, **픽업 시 잔액을 청구**하는 방식입니다. payments는 Replit이 Stripe를 통해 처리하므로 Stripe 코드를 직접 작성할 필요가 없습니다.

<div id="decide-the-deposit-and-balance-amounts">
  ## 보증금와 잔액 금액 정하기
</div>

Agent에게 build를 요청하기 전에 계산 방식을 정하세요.

* **예약 시 보증금:** 정액으로 할까요, 총액의 일정 비율로 할까요? 정액 $500은 안내하기 간단하고, 20%는 차량 가격에 따라 함께 커집니다.
* **픽업 시 잔액:** 렌털 비용의 나머지 금액으로, 고객이 열쇠를 받아 갈 때 청구합니다.
* **환불 가능 기간:** 언제까지 취소해야 보증금을 돌려받을 수 있나요? 보통 48시간을 기본값으로 씁니다.

이 가이드에서 Velocity는 예약 시 환불 가능한 정액 보증금 $500을 받고, 픽업 시 잔액을 청구하며, 픽업 48시간 이전에 취소하면 전액 환불합니다. 실제 비즈니스에 맞게 조정하세요.

<div id="test-the-full-flow-in-test-mode">
  ## 테스트 모드에서 전체 flow 테스트하기
</div>

Stripe는 실제 돈을 쓰지 않고도 실제와 같은 payments를 실행해 볼 수 있도록 전용 테스트 카드를 제공합니다: `4242 4242 4242 4242`, 만료일은 미래 날짜 아무거나, CVC는 3자리 숫자 아무거나 입력하면 됩니다.

1. Preview에서 Velocity에 로그인한 뒤 다음 주 토~일로 차량을 예약 건하세요.
2. checkout 화면에 &quot;오늘 보증금: $500&quot;과 &quot;픽업 시 잔액: $1,900&quot;(또는 계산 결과에 해당하는 금액)이 표시되어야 합니다.
3. `4242` 테스트 카드로 보증금을 결제하세요. 보증금 결제 완료와 잔액 결제용으로 저장된 결제 수단이 표시된 확인 페이지로 돌아와야 합니다.
4. &quot;My bookings&quot;에서 예약을 열고 admin 또는 픽업 동작으로 잔액을 청구하세요. 잔액이 결제됨으로 표시되는지 확인하세요.
5. 두 번째 예약 건을 만든 다음 48시간 이상 남은 시점에 취소하세요. 보증금이 테스트 카드로 환불되어야 합니다(Stripe 테스트 모드 dashboard에서 확인할 수 있습니다).
6. 세 번째 예약 건을 만들고 48시간 이내에 취소하세요. 보증금은 환불되지 않아야 하며, 그 이유가 고객에게 명확히 안내되어야 합니다.
7. Stripe의 결제 거절 테스트 카드(`4000 0000 0000 0002`)로 checkout을 시도하세요. 예약 건이 확정되지 않아야 하며, 고객에게 명확한 실패 메시지가 표시되어야 합니다.

보증금은 성공했는데 예약 건이 확정되지 않는다면 Agent에게 이렇게 요청하세요:

<AiPrompt>
  Velocity의 Stripe 테스트 보증금은 성공했는데 예약 건이 확정됨으로 표시되지 않습니다.<br />
  보증금 성공 이벤트를 데이터베이스의 예약 건 status와 연결해 주세요.<br />
  다른 테스트 예약으로 확인하는 방법도 알려주세요.
</AiPrompt>

<div id="switch-to-live-payments-when-youre-ready">
  ## 준비되면 실제 결제(payments)로 전환하기
</div>

테스트 모드는 개발자를 위한 것이고, 라이브 모드는 실제 돈을 지불하는 진짜 고객을 위한 것입니다. Velocity가 준비되면 다음 단계를 따르세요.

1. Stripe에서 테스트 모드를 라이브 모드로 전환하고 **실제(라이브)** secret 키를 복사합니다.
2. App의 settings에서 테스트 키를 실제 키로 교체합니다.
3. Agent chat에서 Velocity를 다시 Publish합니다.
4. public URL을 열어 본인의 실제 카드로 저렴한 차량을 테스트 예약한 뒤, 보증금과 잔액 flow가 처음부터 끝까지 정상 작동하는지 확인합니다.

public URL을 널리 공유하기 전에 이 실제 카드 테스트를 반드시 한 번 진행하세요. 이제 Velocity는 실제 돈이 오가는 예약을 받습니다.

<div id="need-further-help">
  ## 추가 도움이 필요하신가요?
</div>

* **보증금 결제는 성공했는데 예약 건이 확정되지 않는 경우:** Stripe의 결제 성공 이벤트를 데이터베이스의 예약 건 상태와 연결해 달라고 Agent에게 요청하세요.
* **테스트 모드에서는 되는데 라이브 모드에서는 안 되는 경우:** 앱 설정에서 테스트 키를 라이브 키로 교체했는지 확인하세요.
* **보증금 + 잔액 대신 선불 일시 결제를 원하는 경우:** 예약 시점에 전액을 한 번에 결제하도록 Velocity를 변경해 달라고 Agent에게 요청하세요.
* **정기 구독 요금제(월 단위 차량 이용)를 원하는 경우:** Replit은 RevenueCat도 지원합니다. Stripe 대신 RevenueCat을 사용해 달라고 Agent에게 요청하세요.
