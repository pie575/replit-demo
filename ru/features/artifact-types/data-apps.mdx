<div id="what-is-a-data-visualization">
  ## Что такое визуализация данных?
</div>

Визуализация данных — это интерактивный дашборд или инструмент отчётности, который вы создаёте в диалоге с Agent. Опишите, что нужно визуализировать и где хранятся данные, — Agent сам подберёт подходящие KPI, типы диаграмм и макет и сформирует полноценный дашборд по одному prompt.

Ключевые понятия:

* **Генерация за один шаг**: опишите цель и источник данных — и Agent соберёт готовый дашборд с подходящими диаграммами и метриками
* **Подключённые источники данных**: берите данные из баз данных, через [connectors к хранилищам](/ru/connectors/warehouses/overview), из внешних API или загруженных файлов
* **Встроенные возможности**: в каждом дашборде есть обновление, автообновление, экспорт в PDF, экспорт диаграмм в CSV, а также светлая и тёмная темы
* **Сводка анализа**: Agent формирует выводы на основе вашего запроса и полученных данных
* **Несколько artifact**: визуализации данных могут использовать тот же бэкенд и ту же базу данных, что и другие artifact в [одном project](/ru/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project)

<div id="how-to-use-data-visualization">
  ## Как использовать визуализацию данных
</div>

<div id="creating-from-a-prompt">
  ### Создание по prompt
</div>

Выберите вкладку **App** на главной странице и опишите нужную панель мониторинга. Agent распознаёт prompt, связанные с данными, и выбирает стек Data Visualization.

**Примеры prompt:**

* «Создай панель аналитики продаж, которая отслеживает выручку по регионам»
* «Создай инструмент отчётности, который визуализирует наши ежемесячные метрики»
* «Создай панель на основе наших данных о продажах из BigQuery с самыми продаваемыми товарами»
* «Подключись к Snowflake и создай панель анализа оттока клиентов»

<div id="creating-from-the-dropdown">
  ### Создание через выпадающий список
</div>

1. Перейдите на вкладку **App** на главной странице.
2. Откройте выпадающий список типов приложений.
3. Выберите **Data Visualization**.
4. Опишите дашборд или инструмент для работы с данными, который хотите создать.

<div id="connecting-to-data-warehouses">
  ### Подключение к хранилищам данных
</div>

Подключите визуализацию данных к BigQuery, Databricks или Snowflake с помощью [connector&#39;ов хранилищ](/ru/connectors/warehouses/overview), чтобы строить дашборды на основе уже имеющихся наборов данных.

При запросах к данным хранилища Agent применяет параллельный многоагентный поиск, чтобы изучить вашу схему и наборы данных. Это ускоряет исследование и помогает Agent подобрать подходящие таблицы и поля для дашборда.

Для начала настройте connector хранилища в разделе [Integrations](/ru/features/integrations/overview) вашего project&#39;а, а затем опишите Agent, что именно вы хотите визуализировать.

<div id="adding-filters-and-features">
  ### Добавление фильтров и функций
</div>

После того как Agent создаст панель мониторинга, вы можете попросить его добавить фильтры, детализацию данных или другие интерактивные элементы. Например, попросите Agent добавить фильтр по диапазону дат, выбор региона или строку поиска.

<div id="exporting-and-sharing">
  ### Экспорт и совместный доступ
</div>

* **Экспорт в PDF**: экспортируйте всю панель в PDF, чтобы поделиться ею или просмотреть офлайн.
* **Экспорт диаграмм в CSV**: скачайте данные отдельных диаграмм в виде CSV-файлов для дальнейшего анализа в электронных таблицах или других инструментах.
* **Аналитический документ**: попросите Agent подготовить подробный аналитический документ на основе данных вашей панели.

<div id="what-you-can-build">
  ## Что можно создать
</div>

* **Аналитические дашборды**: отслеживайте ключевые метрики — выручку, регистрации или вовлечённость — в разрезе периодов
* **Инструменты отчётности**: создавайте внутренние отчёты, которые коллеги и руководство могут фильтровать и изучать без прямого доступа к базе данных
* **Интерфейсы для исследования данных**: просматривайте наборы данных и выполняйте запросы с наглядным отображением результатов
* **Панели мониторинга**: показывайте данные в реальном времени или с минимальной задержкой из API, баз данных или внешних сервисов

<div id="frequently-asked-questions">
  ## Часто задаваемые вопросы
</div>

<Accordion title="Какие источники данных можно подключить?">
  Вы можете загружать данные из Replit Database вашего проекта, коннекторов хранилищ данных (BigQuery, Databricks, Snowflake), внешних API или загруженных файлов, например CSV. Подключения к хранилищам настраиваются через [Интеграции](/ru/features/integrations/overview).
</Accordion>

<Accordion title="Можно ли настроить внешний вид?">
  Да. Цвета, макеты и типографику можно настроить прямо в диалоге — попросите Agent привести всё в соответствие с вашим брендом или изменить оформление. Дашборды также поддерживают светлую и тёмную темы.
</Accordion>

<Accordion title="Анализирует ли Agent данные за меня?">
  После создания дашборда Agent формирует сводку анализа на основе вашего запроса и полученных данных. Вы также можете запросить более подробный документ с анализом.
</Accordion>

<Accordion title="Можно ли объединить визуализацию данных с другими типами artifact?">
  Да. Визуализацию данных можно объединить с [веб-приложением](/ru/features/artifact-types/web-apps), [презентацией](/ru/features/artifact-types/slide-decks) или другими типами artifact в [одном проекте](/ru/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project). Они используют общий бэкенд и базу данных.
</Accordion>
