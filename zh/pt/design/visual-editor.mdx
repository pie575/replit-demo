<div id="o-que-o-visual-editor">
  ## 什么是 Visual Editor？
</div>

Visual Editor 让你只需直接点击元素，就能对界面做出实际修改。它在 Replit Design 的 [Canvas](/zh/pt/design/canvas) 和 Preview 中均可使用，因此你可以用同样的方式编辑原型稿和正在运行的应用。

简单的编辑——修改文本、调整颜色、调整间距——会直接更新源代码，且不消耗 AI 积分。对于涉及底层复杂性的修改，Visual Editor 会自动将任务转交给 Agent。

核心概念：

* **确定性编辑**：简单修改 (文本、颜色、间距) 直接应用到源代码，无需经过 Agent 处理
* **不消耗积分**：直接编辑不消耗 AI 积分——只有复杂修改才会交由 Agent 处理
* **双重上下文**：在 Canvas 的 frames 和 Preview 中的使用体验完全一致
* **与源代码同步**：每次编辑都会即时更新底层源代码

<Note>
  Visual Editor 目前仅支持 **网页浏览器**，不支持移动 App 或桌面应用。
</Note>

<div id="como-usar-o-visual-editor">
  ## 如何使用 Visual Editor
</div>

<div id="editando-no-canvas">
  ### 在 Canvas 中编辑
</div>

在工具栏中选择 **Edit** 工具，然后点击 frame 内的任意元素。该元素会被高亮显示，并附带一个标识该元素的标签，同时右侧会打开 Visual Editor 面板，显示该元素可编辑的属性，例如内容、布局、颜色和边框。调整完成后，选择 **Save edits** 应用更改，或选择 **Discard** 放弃更改。

<Frame caption="Edit 工具已启用，选中了一个按钮，Visual Editor 显示其可编辑属性。">
  <img src="/assets/mirror/visual-editor-edit-tool-71d03803471f.png" alt="一个超级跑车配置器 frame，Edit 工具已启用并选中了一个元素，右侧显示 Visual Editor 面板，其中包含 Layout（Outer 和 Inner space）、Color（Text、Background、Opacity）和 Border（color、width、radius）等部分，以及 Discard 和 Save edits 按钮" width="2000" height="1250" data-path="images/replitai/visual-editor-edit-tool.png" />
</Frame>

面板中显示的属性取决于你所选的元素：文本元素会显示字体控件，图片会显示来源和上传选项，容器则会显示布局控件。

<div id="editando-no-preview">
  ### 在 Preview 中编辑
</div>

同样的编辑体验也适用于正在运行的应用。

<Steps>
  <Step title="选择元素">
    在 Preview 中点击任意元素即可开始编辑。
  </Step>

  <Step title="进行编辑">
    可直接就地编辑文本、用取色器调整颜色、通过样式控件更改间距，或替换图片。
  </Step>

  <Step title="保存">
    点击保存即可更新源代码。简单的更改会直接应用，不消耗 AI 积分。如果编辑较为复杂，Visual Editor 会将相关元数据发送给 Agent，由其协助完成。
  </Step>
</Steps>

<div id="edio-de-texto">
  ### 文本编辑
</div>

点击任意文本元素，直接输入即可修改内容。如果该文本是源代码中的字符串，修改会立即生效。

<div id="ajustes-de-cor">
  ### 颜色调整
</div>

使用颜色选择器调整文本和背景颜色。在输入框中输入颜色名称 (如“紫色”) ，或使用吸管工具从屏幕上的任意位置取色。

<div id="mudanas-de-estilo">
  ### 样式调整
</div>

使用直观的控件调整元素的内边距、外边距以及元素之间的布局。

<div id="controles-de-layout">
  ### 布局控件
</div>

Visual Editor 将各类控件归入清晰的分区，方便你更快找到所需选项：**Text**、**Layout**、**Color** 和 **Border**。 (选中图片元素时，还会出现 **Image** 分区。)

在 **Layout** 分区中，你无需借助 Agent 即可调整子元素在容器内的排布方式。选中一个 flex 容器并展开 Layout，即可看到：

* **Alignment**：一个 3×3 点阵选择器，用于设置各项在容器内沿两个轴的对齐位置。
* **Direction**：两个箭头按钮，将子元素按行或按列排列。
* **Gap**：以像素为单位的项目间距。间距字段旁的图标会随当前方向变化，让你随时清楚自己调整的是水平间距还是垂直间距。旁边的箭头图标用于切换 **Distribute space between items** 选项，将子元素推向容器的两端。
* **Outer space**：按边设置元素外部间距的字段 (每边一个字段，并带有联动开关，可一次锁定四条边) 。
* **Inner space**：按轴设置元素内部间距的字段，并带有联动开关，可一次设置两个轴。

只有当至少有一项布局控件适用于所选元素时，Layout 分区才会显示。不含间距或布局属性的纯文本节点会完全隐藏该分区，让编辑器保持简洁紧凑。

<div id="atualizaes-de-imagem">
  ### 图片更新
</div>

选中图片即可替换 URL 或上传自己的文件，并即时查看预览。

<div id="o-que-voc-pode-fazer">
  ## 你可以做什么
</div>

* **快速修改文本**：无需打开源代码文件，即可更新文案、标签和标题
* **色彩探索**：点击即可调整，尝试不同的配色方案——无需再去找对应的 CSS
* **布局调整**：以可视化方式微调内边距、外边距和间距，不用再靠猜像素值
* **替换图片**：点击并上传，即可将占位图片替换为真实素材
* **设计迭代**：快速调整 Canvas 上的 frame，对比不同视觉方向，无需与 Agent 反复沟通

<div id="perguntas-frequentes">
  ## 常见问题
</div>

<Accordion title="Visual Editor 的修改会消耗 AI 积分吗？">
  简单的确定性编辑——修改文本、选择颜色、调整间距——不会消耗 AI 积分，它们会直接更新源代码。如果 Visual Editor 检测到底层复杂性，则会将该修改转交给 Agent 处理，此时会消耗积分。
</Accordion>

<Accordion title="可以编辑出现在多个位置的元素吗？">
  可以。选中在 loop 中渲染或在多个组件中复用的元素时，所有实例都会同时高亮并一次性更新。
</Accordion>

<Accordion title="为什么有些元素的文本无法编辑？">
  由多个子元素组成的复合元素无法在 Visual Editor 中直接编辑文本。请在 Chat 中让 Agent 来完成这类修改。
</Accordion>

<Accordion title="如何找到某个元素的源代码？">
  点击选中元素左上角的标签，即可跳转到它在源代码中的位置。
</Accordion>
