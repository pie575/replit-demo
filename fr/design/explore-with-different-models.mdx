Les suggestions explorent différentes pistes avec le même designer ; changer de modèle revient à changer de designer. Chaque modèle possède sa propre sensibilité graphique et ses points forts en frontend : un même brief peut donc aboutir à un résultat totalement différent selon le modèle utilisé.

<div id="switch-the-model">
  ## Changer de modèle
</div>

Ouvrez le sélecteur de mode dans le champ de saisie du Chat (il affiche le mode actuel, par exemple **Power**), puis sélectionnez **Modèle principal** et choisissez un modèle dans la liste.

La gamme actuelle :

* **Claude Fable 5** (recommandé)
* **Claude Opus 5**
* **GPT-5.6 Sol**
* **Kimi K3**

<Note>
  La gamme de modèles évolue au rythme des nouvelles sorties. Consultez le menu dans le produit pour connaître les modèles auxquels votre compte a accès actuellement.
</Note>

Deux autres réglages se trouvent dans cette même fenêtre :

* **Mode** (Lite, Economy, Power) : l&#39;équilibre entre vitesse, coût et capacité. Power utilise un modèle plus performant pour le travail de Design, idéal pour les designs complexes et les modifications visuelles détaillées. Consultez les [modes Agent](/fr/features/agent/agent-modes) pour la référence complète.
* **Effort** : la quantité de raisonnement que le modèle consacre à chaque réponse, de Low (le plus rapide) à Max. Chaque modèle indique son réglage recommandé.

<div id="explore-across-models">
  ## Explorez les différents modèles
</div>

Changer de modèle constitue un autre axe d&#39;exploration, en complément des [suggestions](/fr/design/explore-suggestions) :

* **Même brief, designer différent** : générez une frame, changez de modèle, puis envoyez à nouveau le même prompt. Les deux résultats s&#39;affichent sous forme de frames sur le Canvas, ce qui vous permet de les comparer côte à côte.
* **Adaptez le modèle à la tâche** : utilisez le modèle recommandé pour la plupart des tâches et changez-en lorsqu&#39;une conception requiert une sensibilité différente ou que vous souhaitez un second avis sur une direction dont vous n&#39;êtes pas sûr.
* **Changez à tout moment** : le modèle s&#39;applique à votre prochain message. Vous pouvez donc en changer en cours de Project sans rien perdre sur le Canvas.
