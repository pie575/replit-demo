Les modes d&#39;Agent vous permettent de doser l&#39;équilibre entre coût et performance lorsque vous utilisez Agent. Utilisez le menu déroulant des paramètres d&#39;Agent pour choisir **Free Mode**, **Power Mode** ou **Max Mode**. Free Mode utilise toujours le routage intelligent des modèles. En Power ou en Max, les créateurs Core et Pro peuvent sélectionner **Auto** pour laisser Replit choisir le modèle adapté à chaque tâche. Ils peuvent également utiliser le [sélecteur de modèle](/fr/features/agent/model-selector) pour choisir un modèle manuellement. Les modes et paramètres affichés dépendent de votre plan et de votre workspace.

<Note>
  Le mode Economy n&#39;est plus disponible. Power Mode le remplace au même prix.
</Note>

<Tip>
  **Raccourci clavier :** appuyez sur **⌘+Maj+I** (Ctrl+Maj+I sous Windows) pour passer
  d&#39;un mode d&#39;Agent à l&#39;autre sans quitter le champ de saisie du chat.
</Tip>

<div id="free-mode">
  ## Free Mode
</div>

**Optimisé pour bien démarrer.** Free Mode vous aide à explorer des idées, à comprendre le fonctionnement de Replit et à lancer un projet.

**À noter :** Free Mode utilise toujours le routage intelligent des modèles. Pour sélectionner un modèle manuellement, utilisez Power Mode ou Max Mode.

<Note>
  {FreeModePlanAvailability} Lorsque vous atteignez la limite de votre forfait,
  Replit vous indique la date de réinitialisation.
</Note>

Les Routines ne s&#39;exécutent pas en Free Mode. Elles s&#39;exécutent en Power Mode ou Max Mode et nécessitent un budget par exécution. En savoir plus sur les [Routines](/fr/chat/routines).

<div id="intelligent-model-routing-auto">
  ## Routage intelligent des modèles (Auto)
</div>

**Optimisé pour la sélection automatique des modèles.** En Power Mode ou Max Mode, les créateurs Core et Pro peuvent sélectionner **Auto**. Replit choisit alors, pour chaque tâche, un modèle dans la limite des capacités du mode sélectionné. Consultez [Utiliser le routage intelligent des modèles](/fr/chat/auto-mode).

Auto est une alternative payante au Free Mode. Il consomme les crédits d&#39;abonnement, comme les autres tâches effectuées en Power Mode et Max Mode.

Les workspaces Enterprise utilisent un unique **mode Auto** à la place du Free Mode. Le mode Auto Enterprise peut choisir à la fois le mode et un modèle autorisé pour chaque tâche.

<div id="power-mode">
  ## Power Mode
</div>

**Optimisé pour le coût.** Power Mode consomme moins de crédits par tâche et constitue le meilleur choix par défaut lorsque vous recherchez de bons résultats sans payer pour les modèles les plus performants.

**Idéal pour :** les créations du quotidien, l&#39;apprentissage et le travail soucieux des coûts sur un projet existant.

<div id="max-mode">
  ## Max Mode
</div>

**Optimisé pour la puissance.** Max Mode s&#39;appuie sur des modèles plus performants pour les tâches complexes, les bases de code volumineuses et les problèmes difficiles.

**Idéal pour :** les projets de qualité production, les fonctionnalités complexes et tous les cas où vous attendez les meilleurs résultats possibles d&#39;Agent.

<div id="which-mode-should-i-use">
  ## Quel mode utiliser ?
</div>

Utilisez le tableau suivant comme guide :

| Objectif                                                                         | Mode recommandé                                                             |
| -------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| Explorer des idées, découvrir le fonctionnement de Replit et démarrer un projet  | Free Mode                                                                   |
| Laisser Replit choisir un modèle pour les tâches payantes                        | Auto en Power Mode ou Max Mode                                              |
| Maximiser le nombre de prompts par crédit                                        | Power Mode                                                                  |
| Trouver le bon équilibre entre coût et qualité pour la plupart des projets       | Power Mode                                                                  |
| Sélectionner un modèle manuellement                                              | Power Mode ou Max Mode                                                      |
| Obtenir les meilleurs résultats sur des travaux complexes, de qualité production | Max Mode                                                                    |
| Obtenir le meilleur résultat possible sur les tâches les plus complexes          | Max Mode avec un [Effort](/fr/features/agent/model-selector#effort) plus élevé |

Utilisez le menu déroulant des paramètres de l&#39;Agent dans la zone de saisie du chat pour choisir un mode. En Power ou Max, les créateurs Core et Pro peuvent utiliser Auto ou définir un [modèle principal et un Effort](/fr/features/agent/model-selector). Aucun mode n&#39;est le meilleur en toutes circonstances : choisissez celui qui convient à la tâche du moment.

<div id="settings-in-shared-projects">
  ## Paramètres dans les projets partagés
</div>

Vos paramètres Agent sont liés à votre compte, et non au projet. Lorsque vous invitez un coéquipier dans un projet, chacun conserve ses propres choix pour :

* Le mode (Free Mode, Power Mode ou Max Mode)
* [Le modèle principal et l&#39;effort](/fr/features/agent/model-selector), lorsqu&#39;ils sont disponibles
* [Plan Mode](/fr/features/agent/plan-mode)
* La fusion automatique des tâches en arrière-plan
* L&#39;approbation automatique des plans

Si un coéquipier passe en Max Mode pour sa prochaine tâche, vos paramètres ne basculent pas pour autant en Max Mode. Le mode et les paramètres affichés dans le menu déroulant des paramètres d&#39;Agent sont ceux qu&#39;Agent applique lorsque vous envoyez votre message suivant, quel que soit le nombre de collaborateurs présents dans le projet.

<div id="check-your-free-mode-usage">
  ## Vérifier votre utilisation du Free Mode
</div>

Ouvrez **Settings** → **Usage** pour consulter votre limite actuelle du Free Mode et le moment de sa réinitialisation. Pour des conseils pratiques, consultez [Tirer le meilleur parti du Free Mode](/fr/chat/free-mode).
