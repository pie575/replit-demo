素材库面板汇集了 Replit Design 内置的起点和参考资料。它包含三个标签页：**模板**、**灵感**和**素材库**。这些内容都不会创建新项目，而是会添加到当前项目的画布中。

<div id="templates">
  ## 模板
</div>

由 Replit 创建的预设设计 frame，可搜索并按类型分类：海报、社交媒体帖子、着陆页、移动端、横幅和原型。点击或拖动任一 frame 即可将其添加到设计中；它会以可立即编辑的动态 frame 形式出现，就像直接在画布上创建的一样。

</Frame>

<div id="inspiration">
  ## 灵感
</div>

Mobbin 精选的真实产品界面截图。搜索应用界面，例如 *&quot;Airbnb onboarding&quot;* 或 *&quot;Coinbase checkout&quot;*，点击其中一个即可将其作为静态参考图片放到画布上。灵感不会向项目添加任何代码：它仅供查看、在聊天中引用，或作为下次生成时的参考。

<Frame caption="灵感标签：由 Mobbin 精选、可搜索的应用界面。">
  <img src="/assets/mirror/library-inspiration-45662d389f5e.png" alt="素材库面板中的灵感标签，包含 Airbnb onboarding、Coinbase checkout 等推荐搜索词以及 Mobbin 精选的应用截图" width="669" height="830" data-path="images/design/replit-design/library-inspiration.png" />
</Frame>

<div id="library">
  ## 素材库
</div>

你可以随时将自己在此项目中创建的设计、工件和其他内容重新添加到画布中。

<div id="templates-vs-inspiration">
  ## 模板与灵感
</div>

|      | 模板               | 灵感                    |
| ---- | ---------------- | --------------------- |
| 是什么  | Replit 创建的入门设计框架 | 通过 Mobbin 获取的真实产品界面截图 |
| 在画布上 | 设计中可编辑的动态框架      | 静态参考图片                |
| 适用场景 | 从可运行的设计开始时       | 为下一次生成确定方向            |

有关引导式使用流程，请参阅[在设计中添加模板和灵感](/zh/ko/design/add-templates-and-inspiration)。
