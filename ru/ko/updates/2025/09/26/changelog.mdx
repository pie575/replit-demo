<div id="section-3">
  ### Сканирование безопасности при деплое
</div>

Защитите свои приложения с помощью нового сканирования безопасности перед публикацией. Включайте или отключайте сканирование перед деплоем приложения, чтобы выявлять вредоносные файлы и уязвимости. Ваш код остаётся под защитой благодаря точным правилам безопасности, которые заранее обнаруживают потенциальные угрозы.

<div id="agent">
  ### Улучшенное тестирование в песочнице Agent
</div>

Тестируйте ИИ-агентов и автоматизации эффективнее благодаря расширенным возможностям песочницы. Теперь при тестировании агентов для Slack и Telegram вызовы инструментов отображаются наглядно, а для автоматизаций рабочих процессов по расписанию доступны результаты тестов в реальном времени. Получите более чёткое представление о работе агента ещё до деплоя.

<div id="section-4">
  ## Команды и Enterprise
</div>

<div id="section-5">
  ### Обязательное сканирование безопасности для Enterprise
</div>

Администраторы Enterprise теперь могут сделать сканирование безопасности обязательным для всех деплоев команды. Требуйте сканирование безопасности для каждого публикуемого приложения, чтобы поддерживать единые стандарты во всей организации и полностью контролировать уровень защищённости команды.
