---
title: "Agent 模式"
description: "了解如何在 Lite、Economy 和 Power 之间选择，以及何时使用高级设置和 Turbo。"
---

Agent 模式可让你在使用 Agent 时权衡速度、成本和能力。使用 Agent 设置下拉菜单中的主模式选择器，在 **Lite**、**Economy** 和 **Power** 之间切换。若要更精细地控制测试、代码审查和 Turbo，请展开**高级设置**。

<Frame>
  <img src="/assets/mirror/agent-modes-dropdown-segmented-b7d6d560f982.png" alt="Agent 模式弹出菜单，其中 Lite、Economy 和 Power 以分段控件显示，下方的高级设置处于折叠状态" width="760" height="502" data-path="images/replitai/agent-modes/agent-modes-dropdown-segmented.png" />
</Frame>

<Tip>
  **键盘快捷键：**按 **⌘+Shift+I** (Windows 上按 Ctrl+Shift+I) ，即可在不离开聊天输入框的情况下切换 Agent 模式。
</Tip>

<Note>Max 模式已不再提供。若要使用功能最强的标准构建，请选择 Power；需要最快的执行速度时，请在高级设置中启用 Turbo。</Note>

<div id="modo-lite">
  ## Lite 模式
</div>

**专为快速编辑优化。** Lite 使用快速、轻量级的模型，适合进行视觉调整、修复错误及其他范围明确的小型更改。

<Frame>
  <img src="/assets/mirror/agent-modes-lite-05ad32f8f34e.png" alt="已选择 Lite 的 Agent 模式下拉菜单" width="1192" height="1328" data-path="images/replitai/agent-modes-lite.png" />
</Frame>

**最适合：** 快速修复、界面优化，以及无需离开键盘即可进行的短周期迭代。

**请注意：** 如果您已明确知道要更改什么，Lite 最适合用于现有应用。如果您要从零开始、进行大型架构调整、添加新集成或修改数据库架构，请切换到 Economy 或 Power。

**费用：** Lite 采用与其他构建模式相同的按工作量计费模式，但对于相同的定向编辑，针对性请求的成本通常低于 Economy 或 Power。

<div id="modo-economy">
  ## Economy 模式
</div>

**成本更优。** Economy 每项任务消耗的积分更少；当你希望获得可靠的结果，又不想为性能最强的模型付费时，它是最佳默认选择。

<Frame>
  <img src="/assets/mirror/agent-modes-economy-6ae501cc69d6.png" alt="Agent 模式下拉菜单，已选择 Economy 并展开高级设置" width="1192" height="1328" data-path="images/replitai/agent-modes-economy.png" />
</Frame>

**最适合：** 日常构建、学习，以及在现有项目中进行注重成本的工作。

<div id="modo-power">
  ## Power 模式
</div>

**为高性能而优化。** Power 使用能力更强的模型来处理复杂任务、更大的代码库和更棘手的问题。

<Frame>
  <img src="/assets/mirror/agent-modes-power-f956985e7037.png" alt="Agent 模式下拉菜单，其中已选择 Power 并展开高级设置" width="1192" height="1328" data-path="images/replitai/agent-modes-power.png" />
</Frame>

**最适合：**生产级项目、复杂功能，以及希望获得 Agent 最佳效果的场景。

<div id="configuraes-avanadas">
  ## 高级设置
</div>

在下拉菜单中展开**高级设置**，即可管理 Agent 的其他构建控制选项：

* **App 测试**可让 Agent 在浏览器中自动测试您的应用。
* **代码优化**可让 Agent 在工作过程中审查并改进自己的代码。
* 使用 Power 模式时，**Turbo**会提供当前可用的最快模型。

Lite 会关闭 App 测试和代码优化，而 Turbo 仅在选择 Power 时可用。

<div id="modo-turbo">
  ## Turbo 模式
</div>

**Turbo 是高级设置中的独立开关。** 如果您想使用最快的模型获得**快 2.5 倍的响应**，请在 Power 模式下启用它。请求成本最高可能达到 Power 的 6 倍，因此当速度比效率更重要时，Turbo 是理想选择。

<Frame>
  <img src="/assets/mirror/agent-modes-turbo-5bd95033d396.png" alt="Agent 模式下拉菜单，已选中 Power，并在高级设置中启用 Turbo" width="760" height="502" data-path="images/replitai/agent-modes-turbo.png" />
</Frame>

<Warning>
  Turbo 会在 Agent 模式下拉菜单中以橙色突出显示，直观提醒您它的成本显著高于 Power。快速迭代时请留意这一提示——它能让您始终清楚了解成本取舍。
</Warning>

**可用性：** **仅限 Pro 和 Enterprise。**

**最适合：** 您需要 Agent 尽可能快速响应，并且使用 Pro 或 Enterprise 方案时。

<div id="qual-modo-devo-usar">
  ## 应该使用哪种模式？
</div>

可参考以下指南：

| 目标               | 推荐模式                           |
| ---------------- | ------------------------------ |
| 进行小范围、明确的修改并快速迭代 | Lite                           |
| 每个积分可使用尽可能多的提示词  | Economy                        |
| 为大多数项目平衡成本与质量    | Power                          |
| 在较大型任务中获得更快响应    | Power + Turbo (Pro/Enterprise) |

你可以随时在聊天输入框中 Agent 设置的下拉菜单里切换模式。在主控件中选择 Lite、Economy 或 Power；如需对测试、代码审查或 Turbo 进行更多控制，请展开高级设置。没有哪种模式始终最适合所有情况——请选择最适合当前任务的模式。
