<div id="prompts-personalizados">
  ### Пользовательские промпты
</div>

<Note>
  **Обновление (декабрь 2025):** Assistant выведен из эксплуатации. Для быстрых точечных правок используйте [режим Lite в Agent](/ru/pt/core-concepts/agent/agent-modes).
</Note>

Пользовательские промпты дают вам полный контроль над тем, как работает Assistant. От настройки собственных стандартов кодирования до изменения поведения Assistant по умолчанию — пользовательские промпты покрывают все ваши задачи.

Вы можете указать, например:

* Определённый стиль кодирования или фреймворк
* Конкретные приёмы решения задач
* Предпочтения по управлению пакетами

Например, вы можете добавить:

```
use pnpm for package management
use motion/react instead of framer-motion
always use claude-3-5-sonnet-20241022 as your model
```

<div id="workflows">
  ### Workflows
</div>

Workflow — это легко настраиваемая кнопка «Выполнить», запускающая любые нужные вам команды.

Это многократно используемая и настраиваемая последовательность шагов, которую можно выполнить внутри вашего Replit App. Она может быть совсем простой — например, запуск **`python main.py`** — или сложной, вплоть до многоэтапной процедуры.

Примеры сценариев использования:

* Параллельный запуск нескольких сервисов (например, frontend + backend)
* Последовательное выполнение файлов или команд (например, запуск линтера → запуск тестов, компиляция → запуск кода)

Чтобы начать [создавать workflows](https:/.replit.com/replit-workspace/workflows#creating-workflows), откройте панель Workflows через меню боковой панели инструментов или найдите её с помощью **`Command + K`**.

Подробнее — [здесь](https:/.replit.com/replit-workspace/workflows).
