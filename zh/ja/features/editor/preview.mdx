Preview 用于显示 Web 应用的输出，并提供浏览器开发者工具和调试功能。

使用**运行**按钮启动 Web 应用后，Replit 会分配一个可通过互联网访问的临时 URL。Preview 工具渲染页面的效果与在浏览器中打开完全一致，同时还内置了与主流浏览器类似的开发者工具。

<Note>
  Preview 是 Webview 的新名称。
</Note>

</Frame>

<div id="section">
  ## 功能
</div>

Preview 提供以下功能，让你流畅地测试和调试 Web 应用：

* **实时网页视图**：无需离开浏览器标签页即可查看应用并与之交互
* **开发者工具**：借助内置工具快速定位问题
* **响应式测试**：在不同移动设备的屏幕尺寸下查看应用

<div id="section-2">
  ## 使用方法
</div>

运行 Web 应用时，Preview 工具会自动打开。
你可以在**用户设置**工具的 **Automatic Preview** 设置中开启或关闭此行为。

下面介绍打开 Preview 的几种方法。

<Accordion title="访问 Preview 的方法">
  从左侧的**工具栏**：

  1. 选择 <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="所有工具图标" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **所有工具**，显示项目编辑器的工具列表。
  2. 选择 <img class="icon-svg" src="/assets/mirror/preview-icon-6d37238e8cc2.svg" alt="Preview 图标" width="16" height="16" data-path="images/icons/preview-icon.svg" /> **Preview**。

  从**搜索栏**：

  1. 选择顶部的<img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" />放大镜，打开搜索工具
  2. 输入“Preview”找到该工具，并从结果中选择。
</Accordion>

<div id="section-3">
  ## 地址栏
</div>

**Preview** 标签页顶部的地址栏包含以下工具：

* **后退按钮**：返回浏览历史中的上一个页面
* **前进按钮**：前进到浏览历史中的下一个页面
* **应用域名**：选择 `{...}.replit.dev`，查看 Replit App 临时 URL 的相关信息
* **地址输入框**：显示当前的 URL 路径，也可输入新的路径

<div id="section-4">
  ## 浏览器工具
</div>

地址栏右侧的浏览器工具包含以下功能：

* **屏幕尺寸**：从各种设备的屏幕尺寸预设中选择，以测试响应式设计
* **开发者工具**：显示或隐藏[开发者工具](#Developer_tools)窗格
* **新标签页**：在新的浏览器标签页中打开 Web 应用的 URL

<Note>
  **正在构建移动应用？** Preview 面板还支持在 **iOS 模拟器**和 **Android 模拟器**中预览。详情请参阅[原生移动应用](/zh/ja/features/artifact-types/building-mobile-apps#preview-on-a-simulator-or-emulator)。
</Note>

<div id="section-5">
  ## 开发者工具
</div>

开发者工具由 <a href="https://github.com/liriliri/eruda" target="_blank">Eruda</a> 开源项目提供支持，可用于完成以下任务：

* 在应用的上下文中查看和操作 JavaScript 控制台
* 检查 DOM 元素
* 监控网络请求
* 配置显示和行为设置

要使用开发者工具，请选择 **Preview** 标签页顶部的 <img class="icon-svg" src="/assets/mirror/wrench-7cee9d1168da.svg" alt="扳手图标" width="16" height="16" data-path="images/icons/wrench.svg" /> **开发者工具**
按钮进行切换。

以下各节将介绍在每个开发者工具标签页中可以执行的操作。

<div id="console">
  ### Console
</div>

**控制台**标签页会显示应用生成的 JavaScript 日志。
在该标签页中，你可以执行以下操作：

* **清除输出**：选择 <img class="icon-svg" src="/assets/mirror/clear-bd1bf1847597.svg" height="16" width="16" alt="清除图标" data-path="images/icons/clear.svg" />带斜线的圆形图标，清除全部控制台输出。
* **筛选输出**：按类型 (全部、Info、Warning、Error) 筛选查看控制台输出。
* **按文本匹配筛选**：选择 <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="筛选器图标" data-path="images/icons/filter.svg" />筛选器图标并输入文本，即可显示匹配的输出。
* **复制输出**：选择 <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="复制图标" data-path="images/icons/copy.svg" />复制按钮，复制所选的控制台消息。
* **运行 JavaScript 代码**：选择 <img class="icon-svg" src="/assets/mirror/arrow-right-2859a6e6bdeb.svg" height="16" width="16" alt="右箭头图标" data-path="images/icons/arrow-right.svg" />右尖括号，即可在应用的上下文中运行 JavaScript 代码。输入表达式后选择**运行**。

<div id="elements">
  ### Elements
</div>

在 **Elements** 标签页中，你可以检查并修改网页的 DOM 结构。

* **查看元素详情**：显示 DOM 元素的详细信息及其在 HTML 代码中的位置
* **复制输出**：点击 <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="复制图标" data-path="images/icons/copy.svg" /> 复制按钮，即可复制选中的控制台消息。

使用 <img class="icon-svg" src="/assets/mirror/select-1165d9548c39.svg" height="16" width="16" alt="选择图标" data-path="images/icons/select.svg" /> 箭头选择工具切换选择模式。进入选择模式后，在网页上点选某个元素，
该元素的 HTML 和 CSS 就会显示在 Elements 标签页中。

<div id="network">
  ### Network
</div>

**Network** 标签页用于监控网页发起的请求。
在该标签页中，你可以执行以下操作：

* **跟踪请求**：查看应用发起的所有网络请求。选择某个请求即可查看其详细信息。
* **筛选**：选择<img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="筛选器图标" data-path="images/icons/filter.svg" />漏斗图标并输入文本，即可显示匹配的结果。清空输入内容即可取消筛选。
* **复制**：选择<img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="复制图标" data-path="images/icons/copy.svg" />复制按钮即可复制存储信息。

<div id="resources">
  ### Resources
</div>

**Resources** 标签页会显示页面加载的资源，以及 Cookie、本地存储等浏览器存储。
你可以查看并更新以下资源类型的列表：

* JavaScript 文件
* 样式表
* Iframe
* 图片

在此标签页中，你可以执行以下操作：

* **查看存储**：查看本地存储、会话存储和 Cookie。
* **筛选**：选择 <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="筛选器图标" data-path="images/icons/filter.svg" /> 漏斗图标并输入文本，即可显示匹配的结果。清空筛选内容即可取消筛选。
* **清除**：选择 <img class="icon-svg" src="/assets/mirror/clear-bd1bf1847597.svg" height="16" width="16" alt="清除图标" data-path="images/icons/clear.svg" /> 清除按钮，删除该存储类型的所有数据。
* **删除所选项**：选择 <img class="icon-svg" src="/assets/mirror/delete-a21eb49cac3c.svg" height="16" width="16" alt="删除图标" data-path="images/icons/delete.svg" />“X”图标，删除对应的存储项。
* **复制**：选择 <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="复制图标" data-path="images/icons/copy.svg" /> 复制按钮，复制存储信息。

<div id="settings">
  ### Settings
</div>

在 **设置** 标签页中，您可以自定义开发者工具的外观和行为。
该标签页包含以下自定义选项：

* **工具设置**：自定义各个工具标签页所使用的选项
* **JavaScript 控制**：设置 JavaScript 的行为选项，例如关闭 JavaScript 以测试应用的运行效果
* **显示设置**：更改开发者工具的主题、面板大小、透明度及其他行为
