<div id="replit-app">
  ## 什么是 Replit App？
</div>

Replit Apps 是包含代码、数据和资源的云托管项目。
你可以在安全、隔离的环境中创建、运行和发布它们。

Replit Apps 与 Project Editor 中的以下工具集成，为你提供无缝的开发体验：

* **AI 驱动工具**：使用 Agent 创建、调试和解释代码。
* **协作**：与其他用户在同一应用中实时协作。
* **发布**：一键将应用发布到云端。

<div id="section-2">
  ## 主要功能
</div>

Replit Apps 提供以下功能：

* **零配置**：无需安装或配置，直接在 Replit.com 上创建应用或编写代码。
* **自动保存**：项目会持续将更改保存到云端，你可以通过任意网页浏览器继续编写代码。
* **版本控制**：无需配置，即可通过 Replit 的版本控制系统跟踪更改、查看文件历史并同步文件。
* **公开/私密可见性设置**：通过隐私设置，你可以控制哪些人能够查看、运行和复刻你的应用。
* **发布**：无需进行复杂的配置更改，即可将代码发布到云端。
* **自定义应用 URL**：获取应用的唯一 URL，或分配自定义域名以打造专业形象。

<Info>
  上传到项目文件系统的文件仅在开发期间可用，
  已发布的应用和其他构建者无法访问。若要处理构建者上传的文件并提供文件，请使用[对象存储](/zh/ja/features/data-and-storage/object-storage)；若要存储和检索应用及用户数据，请使用[Replit 数据库](/zh/ja/features/data-and-storage/sql-database)。
</Info>

如需详细了解可帮助你高效创建 Replit App 的 Project Editor 工具，请参阅 [Project Editor 概览](/zh/ja/learn/projects-and-artifacts/project-editor/)。

<div id="section-3">
  ## 工作原理
</div>

创建 Replit App 时，Replit 会在云端为你的项目创建一个专属的私有空间。
随着你不断为应用添加功能和修改内容，Replit 会自动保存更改，因此你可以在任何网页浏览器中继续编辑。

Replit 提供预先配置好的环境，其中包含所需的所有组件。
这样，你无需操心服务器配置、数据库设置或环境管理，即可立即开始创建应用。

Replit 会自动为每个 Replit App 分配唯一的网址，让你能够在开发过程中预览应用。准备好分享作品后，只需点击几下即可发布，让其他人随时访问。

<div id="section-4">
  ## 存储概览
</div>

Replit 提供四种主要存储类型，以满足应用的数据需求。每种存储类型适用于不同的使用场景，并有相应的套餐限制。

<Info>
  存储限制包括应用存储的所有数据，其中包括已安装的软件包和依赖项。
</Info>

| 存储类型                                                               | 说明           | 使用场景              | 持久性           | 套餐限制                                                                                                                                                 |
| ------------------------------------------------------------------ | ------------ | ----------------- | ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **文件存储**                                                           | Project 中的文件 | 应用代码、静态资源、配置文件    | 发布后持久保留，重启时重置 | Starter: {StarterWorkspaceStorage}<br />Core: {CoreWorkspaceStorage}<br />Pro: {TeamsWorkspaceStorage}<br />Enterprise: {EnterpriseWorkspaceStorage} |
| **[数据库](/zh/ja/features/data-and-storage/sql-database/)**             | 存储结构化数据      | 用户资料、游戏分数、产品目录    | 跨会话完全持久保留     | 每个开发数据库 20GB<br />生产数据库按计算时间和存储空间计费                                                                                                                  |
| **[应用存储](/zh/ja/features/data-and-storage/object-storage/)**          | 非结构化数据和媒体    | 图片、视频、PDF、文档      | 跨会话完全持久保留     | 按使用量计费<br />按存储空间和带宽计费                                                                                                                               |
| **[Secrets](/zh/ja/core-concepts/project-editor/app-setup/secrets/)** | 加密的敏感数据      | API 密钥、认证信息、连接字符串 | 完全持久且加密       | 无特定限制<br />所有套餐均包含                                                                                                                                   |
