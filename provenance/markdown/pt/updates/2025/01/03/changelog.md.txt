## Atualizações da plataforma

### Integração com xAI

O Agent agora pode adicionar xAI diretamente aos seus aplicativos.

Mais das suas integrações favoritas estão chegando ao Agent.

### Tratamento de erros de domínio personalizado

Mensagens de erro específicas para falhas de verificação de domínio personalizado agora estão disponíveis, ajudando você a depurar problemas mais rapidamente.

### Recurso de pesquisa no menu

Agora você pode pesquisar os itens do menu na barra lateral dos seus Replit Apps.

### Melhorias no banco de dados Neon

A integração com o banco de dados Neon foi otimizada. Bancos de dados adicionados com o Agent agora são mais econômicos e eficientes.

### React por padrão

O template padrão para novos Replit Apps de frontend agora usa React. Seus projetos são mais polidos e funcionais desde o início.

## Teams e Enterprise

### Login no Replit Teams

O fluxo de login do Teams foi atualizado para facilitar a introdução. Isso inclui uma nova experiência de login com uma página de seleção de contexto de equipe e troca de conta aprimorada para clientes Teams.
