技能可让 Agent 掌握新能力——首选模式、库的具体用法、设计系统规则，或您已解决问题的方案。您可以将技能附加到消息中、安装到项目中，或选择一项技能作为新项目的起点。

<div id="usar-uma-skill-no-chat">
  ## 在 Chat 中使用 Skill
</div>

试用 Skills 的最快方式是将其附加到单条消息，无需安装。

<Frame>
  <img src="/assets/mirror/agent-skills-picker-ee4058454475.png" alt="通过 Chat 输入框旁的 + 按钮打开的 Skills 选择器，显示包含 Ad Creative、AI Recruiter、AI SDR 和 AI Secretary 的 Skills 列表" width="723" height="529" data-path="images/replitai/agent-skills-picker.png" />
</Frame>

<Steps>
  <Step title="打开 Skills 选择器">
    点击 Chat 输入框旁的 **+** 按钮，然后选择 **使用 Skill**。
  </Step>

  <Step title="浏览并选择 Skill">
    按类别浏览 Skills，包括业务与金融、创意、研究与分析等。选择一个或多个 Skill 并附加到消息中。
  </Step>

  <Step title="发送消息">
    输入请求并发送。Agent 仅会针对这条消息使用所选 Skills。消息中会显示 Skill 标签，方便你查看哪些 Skills 处于活动状态。
  </Step>
</Steps>

例如，附加 **Stock Analyzer**，让 Agent 创建股票研究报告；或者附加 **Deep Research**，让 Agent 围绕某个主题开展调研并提供结构化发现。

<Tip>
  在 Chat 中附加 Skills 不会在项目中安装任何内容。它们会立即在所有项目中可用。
</Tip>

<div id="iniciar-um-projeto-com-uma-skill">
  ## 使用 Skill 创建项目
</div>

创建新项目时，你可以选择一个预设 Skill 作为起点。Agent 会根据 Skill 中的说明搭建项目结构。

<Steps>
  <Step title="打开起点选择器">
    在新建项目页面，点击 **+**，然后选择 **使用 Skill**。
  </Step>

  <Step title="选择 Skill">
    浏览精选 Skills，例如 **AI SDR**、**SEO Auditor**、**Ad Creative** 或 **Programmatic SEO**。选择与你要构建的 App 类型相匹配的 Skill。
  </Step>

  <Step title="描述你的 App">
    告诉 Agent 你的需求。Agent 会从一开始就按照 Skill 的模式和约定构建项目。
  </Step>
</Steps>

<div id="instalar-uma-skill-no-seu-projeto">
  ## 在项目中安装 Skill
</div>

如果希望 Agent 在项目的所有对话中始终应用某项 Skill，请安装该 Skill。已安装的 Skills 位于项目的 `/.agents/skills` 目录中，并会在不同 Chat 会话之间保留。

<div id="instalar-pelo-painel-de-skills">
  ### 通过 Skills 面板安装
</div>

在 Project Editor 中打开 **Skills 面板**，选择 **发现** 选项卡以搜索社区贡献的 Skills。找到所需的 Skill 后，点击 **安装**，它会自动添加到你的项目中。

<Frame>
  <img src="/assets/mirror/agent-skills-discover-732b2b0c488a.png" alt="Skills 的“发现”选项卡，显示社区贡献的 Skills，并提供搜索和安装按钮" width="2542" height="1850" data-path="images/replitai/agent-skills-discover.png" />
</Frame>

例如，构建包含高级动画的作品集网站时，你可以安装：

* **GSAP React** — 教 Agent 实现滚动触发动画、文本揭示和 SVG 路径绘制
* **Tailwind design system** — 让 Agent 掌握 Tailwind CSS 的排版、间距和显示过渡模式
* **Find skills** — 教 Agent 如何代你发现并安装新的 Skills

<Tip>
  你也可以通过 [CLI npx skills](https://github.com/vercel-labs/skills) 安装 Skills：

  ```bash theme={null}
  npx skills <skill> -a replit
  ```
</Tip>

<div id="criar-uma-skill-a-partir-de-uma-conversa">
  ### 通过对话创建 Skill
</div>

创建 Skill 最自然的方式是与 Agent 对话。在一起解决问题或研究新库后，请 Agent 记录它学到的内容：

<AiPrompt>
  调研 GSAP React 集成的最佳实践，并为该项目创建一个 skill。
</AiPrompt>

Agent 会利用完整的对话上下文编写详细的 Skill 文件。这种方式尤其适合用于调试会话之后，此时你们已经对问题形成了共同理解。

<div id="escrever-uma-skill-personalizada">
  ### 编写自定义 Skill
</div>

对于高级使用场景，请按照 [Agent Skills 规范](https://agentskills.io/specification)直接编写 Skills。在文件侧边栏中启用**显示隐藏文件**，打开 `/.agents/skills/`，然后新建一个 Markdown 文件。这样，你便能完全掌控 Agent 所了解的内容及其行为方式。
