借助 Agent 的 Web Search <img class="icon-svg" src="/assets/mirror/web-search-1fe8f63b5b88.svg" alt="Web Search 图标" width="16" height="16" data-path="images/icons/web-search.svg" /> 能力，构建基于真实、实时数据的应用。

该功能可获取网络上的最新信息，突破知识截止时间的限制。当你让 Agent 创建需要最新信息的内容时，它会搜索网络并抓取详细内容，让你的应用更准确、更实用。

Web Search 非常适合查找最新的包、工具和资讯，可确保你的应用遵循当前的最佳实践，结果也更加准确。

<div id="funcionalidades">
  ## 功能
</div>

借助 Agent 的 Web Search，构建能获取最新信息的应用，无需再手动查找和收集数据。无论是制作展示金融数据的仪表板，还是搭建呈现初创公司最新发布动态的网站，Web Search 都能让你的应用反映真实现状。

Agent 可以执行以下 Web Search 操作：

* **搜索**：从互联网获取最新信息、最新文档和实时数据
* **内容抓取**：从指定网站和 URL 中提取详细信息
* **来源引用**：清楚了解 Agent 的信息出处，便于你核实和引用

<div id="uso">
  ## 用法
</div>

Web Search 已内置于 Agent 中，无需手动启用。只需描述你想构建的内容，Agent 就会自动判断何时需要联网搜索最新信息。你也可以在 prompt 中加入“搜索”“查一下”或“使用 Web Search”等关键词，明确要求 Agent 进行搜索。

<div id="como-o-web-search-melhora-seus-apps">
  ### Web Search 如何提升你的应用
</div>

Web Search 让你的应用告别占位数据，转而使用真实、准确的信息：

| 优势      | 描述                    |
| ------- | --------------------- |
| 技术保持最新  | 应用可使用训练数据中没有的最新信息和包   |
| 工具选择更优  | Agent 会搜索各种方案，挑选最合适的包 |
| 当前最佳实践  | 获取最新的开发规范和安全实践        |
| 突破局限    | 突破知识截止的限制，使用训练之后发布的包  |
| 数据准确    | 应用展示的是当前信息，而非过时示例     |
| 专业的呈现效果 | 引用真实企业信息的应用看起来更可信     |
| 节省时间    | 无需手动查找包、收集数据          |

<div id="citaes-de-fontes">
  ### 来源引用
</div>

当 Agent 使用 Web Search 时，它会提供**来源引用**，明确标明信息的出处。你可以利用这些引用来：

* **验证信息**：核查来源的可靠性与准确性
* **深入了解**：访问原始来源，获取更多背景信息
* **标注来源**：在你的应用中加入恰当的出处标注
* **追溯搜索过程**：了解哪些信息影响了 Agent 的工作

<div id="busca-de-contedo">
  ### 内容抓取
</div>

Agent 可以从特定网站抓取详细内容，为你的项目收集完整信息。借助该功能，Agent 能够：

* 读取整个网页，提取相关细节
* 处理文档和参考资料
* 从可信来源收集特定数据点
* 将结构化信息集成到你的应用中

**框架的最新特性**

<AiPrompt>
  Do research to understand the latest security best practices for authentication and authorization. Implement those best practices in my app.
</AiPrompt>

Agent 会搜索身份验证与授权方面的最新安全最佳实践，并在你的应用中加以实现。

<AiPrompt>
  Build a weather app that uses the most reliable and feature-rich weather API available
</AiPrompt>

Agent 会调研当前的天气 API，比较其功能、可靠性和价格，从中选出最符合你需求的方案。

<AiPrompt>

Agent 会搜索 YC 最新一期的实时信息，并用真实的创业公司数据、logo 和简介创建网站。

**个人作品集网站**

<AiPrompt>
  Create a personal website for Michele Catasta, a former researcher at Stanford and President of Replit.

<AiPrompt>
  Build a trip planner for Japan with current prices and recommendations
</AiPrompt>

**财务对比仪表板**

<AiPrompt>
