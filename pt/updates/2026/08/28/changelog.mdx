## Agent

### Roteamento inteligente de modelos

O roteamento inteligente de modelos seleciona automaticamente o modelo e o nível de esforço mais adequados para sua tarefa, equilibrando qualidade e custo. No **Power** ou no **Max**, selecione **Auto** para deixar o Replit rotear cada parte do seu trabalho conforme a complexidade muda. Você também pode selecionar um modelo e um nível de esforço específicos quando quiser mais controle.

### Roteamento inteligente de modelos para Enterprise

O roteamento inteligente de modelos agora é o modo padrão do Agent para Workspaces Enterprise. Com o **Auto mode** ativado, o Replit escolhe o melhor modo e um modelo permitido para cada tarefa. Os administradores de conta podem controlar a disponibilidade de modelos para cada Workspace, e você pode desativar o **Auto mode** para selecionar um modelo habilitado. O menu de modos do Agent Enterprise agora usa **Power** e **Max** e não inclui mais o **Lite**.

## Integrações

### Personalize conectores

Organizações Enterprise agora podem usar configurações OAuth personalizadas para conectores. Por exemplo, configure o Gmail com seu próprio **Client ID**, **Client Secret** e **scopes** em vez dos padrões do Replit.
