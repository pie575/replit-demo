<div id="o-que-o-agent-geral">
  ## 什么是 Agent Geral？
</div>

Agent Geral 是使用 Replit Agent 最灵活的方式。你无需预先选择产物类型，也不必一开始就确定要构建什么。直接开始对话即可——创建 CSV、生成 PDF、研究某个主题，或者在准备就绪时构建一个完整的应用。

关键概念：

* **无需预选**：不用事先选择产物类型就能开始工作
* **任意输出**：生成文件 (CSV、PDF、文档) 、开展研究或构建应用
* **连接器**：读写 BigQuery、Linear、Slack、Notion、Amplitude、Segment、Hex 等外部服务
* **渐进式展开**：从轻量 Chat 起步，自然而然地过渡到完整的应用构建

<div id="como-acessar-o-agent-geral">
  ## 如何使用 Agent Geral
</div>

你可以通过多种方式使用 Agent Geral：

1. 在 Replit 首页**编写 prompt 前选择“Geral”**
2. **打开任意现有项目**，直接开始与 Agent 对话
3. **从 GitHub [导入](/zh/pt/build/import-from-providers)**——从 GitHub 导入的项目会自动使用 Agent Geral

<div id="como-usar-o-agent-geral">
  ## 如何使用 Agent Geral
</div>

<div id="apenas-comece-a-conversar">
  ### 直接开始对话
</div>

打开一个项目，直接开口就行。你不必一开始就确定要构建什么——Agent 会结合当前项目的上下文来工作，你需要什么它都能处理。

**prompt 示例：**

* “总结这份文档的要点”
* “创建一个按营收排名前 100 的公司 CSV”
* “我在 Linear 上排在前五的工单是哪些？”
* “配置一个使用 TypeScript 的 Vue.js 项目”

Agent 可以处理会话期间创建的文件、生成单文件输出，并在推理过程中执行代码——这一切都发生在你决定构建任何东西之前。

<div id="conectando-servios-externos">
  ### 连接外部服务
</div>

连接你的工具，让 Agent 可以直接读写数据：

1. 进入项目设置中的**连接器**
2. 连接你的服务 (BigQuery、Linear、Slack、Notion、Amplitude、Segment、Hex 等)
3. 让 Agent 通过它们读取或写入数据

**使用连接器的 prompt 示例：**

* “Linear 上有哪些未处理的工单？”
* “总结今天 Slack #engenharia 频道的消息”
* “从 BigQuery 获取上个月的销售数据”
* “显示我日历中即将到来的日程”
* “在 Linear 中为这个集成 bug 创建一个新工单”
* “把摘要发送到 Slack 的 #engenharia 频道”

<div id="do-chat-ao-aplicativo-completo">
  ### 从 Chat 到完整应用
</div>

准备好开始构建时，直接说出来就行。Agent 会从轻量的 Chat 顺畅过渡到构建你的应用——无需重新开始，也不用切换上下文。

* “把这个做成一个 Web 应用”
* “基于这些数据构建一个应用”
* “为这些指标创建一个仪表板”
* “用 Rust 搭一个 CLI 工具”

你可以从随意的探索开始——研究某个主题、生成一份报告、翻翻一些数据——等时机成熟时，再升级为完整的应用构建。

<div id="o-que-voc-pode-construir">
  ## 你可以构建什么
</div>

* **知识型工作**：无需构建应用，即可开展研究、总结和分析
* **单文件输出**：CSV、PDF、文档、数据导出和格式化报告
* **数据应用**：查询已连接的服务，并在仪表板中可视化结果
* **任意框架或语言**：Angular、Vue、Svelte、Rust、Go、C#、Python tkinter、Godot 游戏、CLI 工具等
* **full-stack 应用**：准备就绪后，可基于 Chat 中的上下文构建一个完整的应用

<div id="o-que-esperar">
  ## 预期效果
</div>

Agent Geral 提供更强的能力和更高的灵活性，同时也会带来一定的不确定性：

* **一次性配置到位**：有时 Agent 会一次性完成全部配置
* **迭代式协作**：复杂的配置可能需要多轮打磨
* **技术限制**：部分技术在 Nix 环境中可能无法获得完整支持

<Note>
  与使用预配置环境的标准 Agent 不同，Agent Geral 会根据你的请求自行搭建环境并执行命令。当你准备部署时，可能需要让它来配置发布。
</Note>

<div id="perguntas-frequentes">
  ## 常见问题
</div>

<Accordion title="Agent 能看到我的其他项目吗？">
  不能。每个 Chat 都局限在单个项目内，无法让项目 A 和项目 B 相互通信。
</Accordion>

<Accordion title="为什么它仍然无法访问我的外部工具？">
  你需要先通过连接器连接相应的服务。连接完成后，Agent 才能读取和写入这些服务；默认情况下它没有访问权限。
</Accordion>

<Accordion title="有哪些可用的连接器？">
  目前支持：BigQuery、Linear、Slack、Notion、Amplitude、Segment、Hex 等。我们会定期新增更多连接器。
</Accordion>

<Accordion title="使用 Agent Geral 需要连接器吗？">
  不需要。连接器是可选的。即使没有任何外部连接，你也可以使用 Agent Geral 进行知识型工作、生成文件和构建应用。
</Accordion>
