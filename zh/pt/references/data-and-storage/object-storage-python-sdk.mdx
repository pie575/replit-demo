本参考指南介绍 `replit-object-storage-python` 包中的 `Client` 类，并提供其类方法的代码示例。

<div id="client">
  ## 客户端
</div>

`Client` 类用于管理与 Replit App Storage 的交互，并提供在存储桶中对对象执行操作的方法。

要从 `replit.object_storage` 包导入该类，请在 Python 代码中添加以下代码行：

```python theme={null}
from replit.object_storage import Client
```

使用以下代码创建与 Replit App Storage 交互的 `Client` 实例：

```python theme={null}
client = Client()
```

<Tip>
  如果你的 App 使用多个存储桶，请为每个存储桶创建一个 `Client` 实例。
</Tip>

<div id="__init__">
  ### **init**
</div>

`init` 方法用于初始化 Client 类的实例。

```python theme={null}
def __init__(bucket_id: Optional[str] = None)
```

**参数**:

* `bucket_id` (Optional[str]): 客户端管理的存储桶 ID。省略时，Client 使用与 Replit App 或 deployment 关联的默认存储桶。

<div id="copy">
  ### copy
</div>

`copy` 方法可在同一存储桶内复制对象。如果目标位置已存在对象，该对象将被覆盖。

```python theme={null}
def copy(object_name: str, dest_object_name: str) -> None
```

**参数**：

* `object_name` (str) - 源对象的完整路径。
* `dest_object_name` (str) - 目标对象的完整路径。

**异常**：

* `ObjectNotFoundError` - 表示指定路径中不存在源对象。

<div id="delete">
  ### delete
</div>

`delete` 方法会永久删除 App Storage 中的文件。

```python theme={null}
def delete(object_name: str, ignore_not_found: bool = False) -> None
```

**参数**：

* `object_name` (str) - 要删除的对象名称。
* `ignore_not_found` (bool) - 为 `True` 时，若对象不存在则不报错。

**异常**：

* `ObjectNotFoundError` - 表示该对象不存在。

<div id="download_as_bytes">
  ### download_as_bytes
</div>

`download_as_bytes` 方法以 `bytes` 形式获取文件内容。

```python theme={null}
def download_as_bytes(object_name: str) -> bytes
```

**参数**:

* `object_name` (str) - 要下载的对象名称。

**返回值**:

* `bytes` - 对象内容的原始字节表示。

**异常**:

* `ObjectNotFoundError` - 表示该对象不存在。

<div id="download_as_text">
  ### download_as_text
</div>

`download_as_text` 方法会将文件内容下载为 `str` 类型。

```python theme={null}
def download_as_text(object_name: str) -> str
```

**参数**:

* `object_name` (str) - 要获取的源对象名称。

**返回值**:

* str：对象内容，以 UTF-8 编码的字符串形式返回。

**异常**:

* `ObjectNotFoundError` - 表示对象不存在。

<div id="download_to_filename">
  ### download_to_filename
</div>

将对象内容下载到本地磁盘上的文件中。

```python theme={null}
def download_to_filename(object_name: str, dest_filename: str) -> None
```

**参数**:

* `object_name` (str) - 要从 App Storage 下载的源对象名称。
* `dest_filename` (str) - 本地磁盘上的目标文件名。

**异常**:

* `ObjectNotFoundError` - 表示对象不存在。

<div id="exists">
  ### exists
</div>

`exists` 方法用于检查对象是否存在。

```python theme={null}
def exists(object_name: str) -> bool
```

**参数**：

* `object_name` (str) - 要检查的对象名称。

**返回值**：

* `bool`：如果对象存在，则为 `True`；否则为 `False`。

<div id="list">
  ### list
</div>

`list` 方法用于列出存储桶中的对象。

```python theme={null}
def list(end_offset: Optional[str] = None,
         match_glob: Optional[str] = None,
         max_results: Optional[int] = None,
         prefix: Optional[str] = None,
         start_offset: Optional[str] = None) -> List[Object]
```

**参数**:

* `end_offset` (Optional[str]) - 筛选名称在字典序上位于 `end_offset` 之前的对象。如果设置了 `start_offset`，列出的对象
  名称介于 `start_offset` (含) 和 `end_offset` (不含) 之间。
* `match_glob` (Optional[str]) - 使用 glob 模式筛选结果。例如：&quot;foo*bar&quot; 可匹配 &quot;footbar&quot;、&quot;foo baz bar&quot; 和 &quot;foobar&quot;。
* `max_results` (Optional[int]) - 响应中返回的最大结果数。
* `prefix` (Optional[str]) - 筛选名称带有指定前缀的对象。
* `start_offset` (Optional[str]) - 筛选名称在字典序上等于或位于 `start_offset` 之后的对象。
  设置 `end_offset` 后，列出的对象名称介于 `start_offset` (含) 和 `end_offset` (不含) 之间。

**返回**:

* `List`(Object)：与所提供查询参数匹配的对象列表。

<div id="upload_from_filename">
  ### upload_from_filename
</div>

使用 `upload_from_filename()` 将本地磁盘上的文件上传为 App Storage 中的对象。

```python theme={null}
def upload_from_filename(dest_object_name: str, src_filename: str) -> None
```

**参数**:

* `dest_object_name` (str) - 上传文件的名称。
* `src_filename` (str) - 要上传的源文件。

<div id="upload_from_bytes">
  ### upload_from_bytes
</div>

`upload_from_bytes` 方法用于从 `bytes` 数据上传对象。

```python theme={null}
def upload_from_bytes(dest_object_name: str, src_data: bytes) -> None
```

**参数**：

* `dest_object_name` (str) - 要上传的对象名称。
* `src_data` (str) - 要上传的 `bytes` 数据。

<div id="upload_from_text">
  ### upload_from_text
</div>

`upload_from_text` 方法可根据字符串上传对象。

```python theme={null}
def upload_from_text(dest_object_name: str, src_data: Union[bytes, str]) -> None
```

**参数**：

* `dest_object_name` (str) - 要上传的对象名称。
* `src_data` (str) - 要上传的文本数据。

<div id="tipos-de-exceo">
  ### 异常类型
</div>

* 使用 `Client` 与 Replit App Storage 交互时，任何方法都可能返回以下错误之一：

  * `BucketNotFoundError`：表示配置的存储桶名称与 App Storage 中的任何存储桶都不匹配。

  * `DefaultBucketError`：表示未配置默认存储桶。

  * `ForbiddenError`：表示没有足够权限访问该存储桶。

  * `TooManyRequestsError`：表示该操作因请求过多而受到限制。

  * `UnauthorizedError`：表示未获授权访问该操作。
