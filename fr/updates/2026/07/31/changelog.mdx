<div id="replit-design-is-live">
  ### Replit Design est disponible
</div>

Replit Design est désormais disponible. Décrivez ce que vous souhaitez créer, explorez des maquettes interactives et affinez votre vision. Lorsqu’une frame est prête, les utilisateurs de Core et Pro peuvent la transformer en application fonctionnelle dans le même projet.

<div id="agent">
  ## Agent
</div>

<div id="choose-agents-primary-model">
  ### Choisissez le modèle principal d&#39;Agent
</div>

Vous pouvez désormais choisir le modèle principal qu&#39;Agent utilise pour une tâche. Sélectionnez Lite, Economy ou Power, puis choisissez l&#39;un des modèles disponibles pour ce mode. Lite est désormais disponible partout où vous pouvez utiliser Agent, y compris dans les applications mobiles. Les modèles disponibles varient selon l&#39;organisation, les autorisations et l&#39;accès à Turbo.

<Frame caption="Capturé dans Replit Design ; le même contrôle apparaît dans le menu déroulant des paramètres d'Agent.">
  <img src="/assets/mirror/agent-model-selector-873f18bc6147.png" width="1432" height="786" data-path="images/changelog/2026-07-31/agent-model-selector.png" />
</Frame>

En savoir plus sur le [sélecteur de modèles](/fr/features/agent/model-selector).

<div id="connect-more-mcp-servers">
  ### Connectez davantage de serveurs MCP
</div>

Les workspaces éligibles peuvent se connecter à Supabase, Statsig et Calendly via le catalogue de serveurs MCP disponibles. Replit reconnaît également le point de terminaison MCP officiel de Braintrust et lance le flux de connexion OAuth lorsque vous l&#39;ajoutez manuellement.

</Frame>

En savoir plus sur les [serveurs MCP](/fr/features/mcp/overview).

<div id="teams-and-enterprise">
  ## Teams et Enterprise
</div>

<div id="stay-signed-in-longer">
  ### Restez connecté plus longtemps
</div>

Les sessions Replit durent désormais plus longtemps avant que vous n’ayez à vous reconnecter. Les administrateurs Enterprise peuvent configurer des préréglages de délai d’expiration des sessions.
