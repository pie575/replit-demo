Grâce au routage intelligent des modèles, Replit sélectionne le modèle le plus adapté à chaque tâche, en conciliant qualité et coût. Lorsque le produit affiche **Auto**, Replit utilise le routage intelligent des modèles.

<div id="section">
  ## Activer le routage intelligent des modèles
</div>

1. Dans le champ de saisie du prompt, sélectionnez **Agent Mode**. Les modes disponibles (**Free**, **Power**, **Max**) s’affichent dans le menu.
2. Sélectionnez **Power** ou **Max**, puis repérez la section **modèle principal**. Ce libellé varie selon le mode sélectionné et peut, par exemple, s’afficher comme **modèle principal Max**.
3. Si le modèle principal est déjà défini sur **Auto**, le routage intelligent des modèles est activé. Si un modèle spécifique est sélectionné, ouvrez le menu du modèle principal et sélectionnez **Automatically choose**.

Le mode Free utilise toujours le routage intelligent des modèles et ne permet pas de sélectionner manuellement un modèle.

<div id="section-2">
  ## Laisser Replit choisir le modèle en fonction de la tâche
</div>

Le routage intelligent des modèles est utile si vous souhaitez que Replit gère le choix du modèle à mesure que les tâches évoluent. Les demandes simples peuvent être traitées par un modèle moins coûteux, tandis que les tâches complexes peuvent nécessiter un modèle plus performant.

En mode Power ou Max, les utilisateurs Core et Pro peuvent également sélectionner manuellement les modèles disponibles.
