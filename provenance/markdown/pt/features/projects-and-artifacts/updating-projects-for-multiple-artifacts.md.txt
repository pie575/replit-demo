# Atualizando projetos antigos para suporte a múltiplos artefatos

> Adicione um segundo artefato a um projeto antigo do Replit com uma atualização estrutural única que preserva sua URL, dados e implantação.

Se o seu projeto foi criado antes de 11 de março de 2026, o Agent pode precisar executar uma atualização estrutural única antes de poder adicionar um segundo artefato a ele. Esta página explica o porquê, o que muda e quais projetos são elegíveis.

## Contexto

Em **11 de março de 2026**, o Replit lançou o [Agent 4](/pt/updates/2026/03/13/changelog). Uma das maiores mudanças nesse lançamento foi o **suporte a vários artefatos**: um único [projeto](/pt/features/projects-and-artifacts/projects) agora pode conter vários [artefatos](/pt/features/projects-and-artifacts/artifacts) (por exemplo, um aplicativo web, um aplicativo mobile e um pitch deck) que compartilham o mesmo banco de dados, backend, segredos e implantação.

Antes de 11 de março de 2026, cada projeto era construído em torno de um único aplicativo com um layout de arquivo diferente. Essa estrutura mais antiga não tem a separação que o backend precisa para hospedar mais de um artefato. Por causa dessas diferenças, os projetos criados antes de 11 de março de 2026 precisam de uma **atualização estrutural única** antes que o Agent possa adicionar um segundo artefato a eles. Projetos criados nessa data ou após já usam o novo layout e não precisam dessa etapa.

## O que a atualização faz

Quando você pede ao Agent para adicionar um segundo artefato a um projeto mais antigo (por exemplo, adicionar um aplicativo mobile a um aplicativo web existente), o Agent primeiro reorganiza seu projeto no novo layout de vários artefatos. Sua URL, colaboradores, segredos, banco de dados e domínios são todos preservados. Apenas a estrutura interna muda.

## Como funciona

  </Step>

  <Step title="Revise e aprove">
    O Agent faz uma pausa antes de fazer qualquer alteração e mostra uma proposta no chat. Para até dois projetos elegíveis, você também verá uma oferta única de **crédito de \$5** para começar com a atualização do projeto. Clique em **Update project** para continuar, ou em **Not now** para pular.

## Elegibilidade

Nem todo projeto pode ser atualizado neste momento. Seu projeto deve ser de um destes tipos:

* **Aplicativo Web** (JavaScript full-stack)
* **Mockups de design para aplicativo**
* **Aplicativo Mobile** (Expo)

Outros tipos de projeto criados antes de 11 de março de 2026, incluindo Python, Flask, Streamlit, stacks de jogos, projetos de vídeo e stacks de agentes, não são suportados. Se você precisar de vários artefatos nesses casos, [crie um novo projeto](/pt/features/projects-and-artifacts/projects).

As portas e fluxos de trabalho do seu projeto também devem corresponder à configuração padrão para o seu tipo. Se você editou manualmente o `.replit`, verá esta mensagem:

> *This project cannot be migrated automatically: workflow config does not match expected.*

Para corrigir isso, reverta suas personalizações de porta ou fluxo de trabalho para os padrões e tente novamente.

## Perguntas frequentes

<AccordionGroup>
  <Accordion title="Por que meu projeto precisa de uma atualização?">
    Projetos criados antes de 11 de março de 2026 (quando o Agent 4 foi lançado) usavam um layout de aplicativo único. O layout de workspace compartilhado mais recente é o que permite que um aplicativo web, aplicativo mobile e dashboard admin vivam juntos e compartilhem o mesmo banco de dados e backend. A atualização é uma etapa única para adotar esse layout.
  </Accordion>

  <Accordion title="E se eu não quiser atualizar?">
    Clique em **Not now**. O Agent continua construindo no layout existente de artefato único. Você pode revisitar a oferta mais tarde se suas necessidades mudarem.
  </Accordion>

  <Accordion title="Posso atualizar mais de uma vez?">
    Não. Assim que seu projeto estiver na nova estrutura, nenhuma atualização adicional será necessária. Artefatos futuros são adicionados diretamente sem outra etapa de atualização.
  </Accordion>

  <Accordion title="Meu projeto não é elegível. Quais são as minhas opções?">
    Crie um projeto separado para o novo artefato, ou inicie um projeto novo que suporte vários artefatos desde o início.
  </Accordion>
</AccordionGroup>
