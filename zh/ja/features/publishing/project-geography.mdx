title: "项目区域"
description: "选择托管已发布项目计算和存储资源的位置。"
---

项目区域是指项目发布后所在的区域。您可在发布时选择该区域，它决定已发布项目的计算和存储资源托管位置。

<Note>
  项目区域可能与[工作区区域](/zh/features/collaboration/workspace-geography)不同。工作区区域决定工作区中新项目的开发资源托管位置。
</Note>

<div id="section">
  ## 项目区域控制的内容
</div>

默认情况下，Replit 会推荐离你最近的区域，以帮助降低应用访客的延迟，并满足数据驻留要求。

选择区域后，项目的所有已发布产物 (包括计算资源、数据库和对象存储) 都会自动部署到同一区域。区域专属代理也有助于降低应用访客的延迟。

<div id="section-2">
  ## 选择项目区域
</div>

如需选择推荐区域以外的区域，请按以下步骤操作。

<Steps>
  <Step>在 Replit 项目中打开 **Publishing** 工具。</Step>
  <Step>展开 **Advanced** 设置。</Step>
  <Step>从 **Geography** 下拉菜单中选择所需区域。</Step>

  <Step>
    选择 **Publish**，将项目发布到所选区域。
  </Step>
</Steps>

<div id="section-3">
  ## 强制指定已发布项目的区域
</div>

Enterprise 管理员可以强制要求组织内的所有项目发布到指定区域。设置此策略后，组织内的构建者只能发布到指定区域。此策略仅适用于尚未发布的项目，不会影响已发布到其他区域的项目。

<Note>
  强制指定发布区域是 Enterprise 功能。有关 Enterprise 计划的详细信息，请参阅[定价](https://replit.com/pricing/)。
</Note>

<Steps>
  <Step>前往**账户设置**。</Step>
  <Step>选择 **Advanced**。</Step>

  <Step>
    选择所有首次发布的项目必须使用的区域。
  </Step>
</Steps>

<div id="section-4">
  ## 可用性和限制
</div>

| 区域                | 发布项目时是否可选 |
| :---------------- | :-------- |
| **北美**            | 可选        |
| **欧洲 (欧盟)&#x20;**&#x20;| 可选        |
| **亚洲**            | 可选        |
| **南美洲**           | 可选        |
| **澳大利亚**          | 可选        |

<Note>
  Core、Pro 和 Enterprise 用户可以选择项目区域。免费套餐用户默认发布到北美。
</Note>

选择项目区域前，请注意以下限制：

* **发布后无法更改区域。** 项目一旦发布到某个区域，该选择将永久生效。无法将已发布的项目迁移到其他区域。
* **开发环境与发布位置可能不同。** 对象存储等资源可能在发布前创建，且可能与项目区域不一致。
