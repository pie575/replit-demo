<div id="section">
  ## 什么是 工作区？
</div>

Replit 的 工作区 将项目、成员、设置、共享资源、集成和账单集中在一处管理。

每个 Replit 账户都自带一个用于存放个人项目的个人 工作区；付费方案还可以创建团队 工作区 来管理共享项目。

</Frame>

| 功能       | 个人 工作区 | 团队 工作区           |
| -------- | ------------ | ---------------------- |
| **最适合**  | 个人工作或共享单个项目  | 团队、初创公司、课堂、客户项目        |
| **访问模式** | 将访客邀请到单个项目   | 成员可访问 工作区 中的所有项目 |
| **账单**   | 你自己的账户       | 来自 Pro 管理员账户的共享额度池     |

<div id="section-2">
  ## 个人 工作区
</div>

个人 工作区 是存放你个人项目的地方，你是其中唯一的管理员。只有被你以项目级访客身份邀请的用户，才能访问对应的项目，且不会获得整个 工作区 的访问权限。

<Frame caption="归属于你个人账户的 工作区 会在选择器中显示为个人 工作区。">
  <img src="/assets/mirror/personal-workspace-selector-a7542687e3ac.jpg" alt="标记为个人 工作区 的 工作区 选择器" width="222" height="62" data-path="images/workspace/personal-workspace-selector.jpg" />
</Frame>

<div id="section-3">
  ## 团队 工作区
</div>

团队 工作区 让群组能够跨多个项目协作。成员可以访问 工作区 内的所有项目，无需逐个项目邀请。管理员统一管理账单和设置。

有关设置步骤、成员管理以及可用套餐的详细信息，请参阅[团队 工作区](/zh/ja/features/collaboration/team-workspaces)。
