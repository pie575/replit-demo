Каталог навыков — это подборка готовых навыков, которые можно установить и сразу использовать; они созданы Replit и нашими партнёрами. Установите навык, попробуйте его в деле, а затем измените так, чтобы он соответствовал реальным процессам вашей команды.

Чтобы понять, что такое навык и как Agent его загружает, см. [Навыки Agent](/ru/pt/features/agent/skills). Чтобы сделать навык доступным во всём вашем workspace, см. [Настройка Agent](/ru/pt/features/agent/agent-customization).

<div id="instalar-uma-skill">
  ## Установка навыка
</div>

Добавить навык из каталога можно несколькими способами:

* **В чате** — нажмите кнопку **+** рядом с полем ввода чата, выберите **Use a skill** и укажите нужный навык. Навык применяется только к этому сообщению, в ваш проект при этом ничего не устанавливается.
* **В проекте** — откройте **Skills pane** в Project Editor, перейдите на вкладку **Discover**, найдите навык и нажмите **Install**. Установленные навыки хранятся в каталоге `/.agents/skills` вашего проекта и сохраняются между чатами.
* **Через командную строку** — установите навык с помощью [skills CLI](https://github.com/vercel-labs/skills):

  ```bash theme={null}
  npx skills <skill> -a replit
  ```

<Warning>
  Навыки в селекторе навыков Replit проходят аудит безопасности. Навыки, установленные из внешних источников, такую проверку не проходят. Поскольку навык — это всего лишь инструкции, которым следует Agent, всегда просматривайте внешний навык перед установкой: о том, на что обратить внимание, читайте в разделе [Agent skills](/ru/pt/learn/agent-skills).
</Warning>

<div id="skills-do-replit">
  ## Навыки в Replit
</div>

В Replit уже встроены готовые навыки — они доступны в списке **Use a skill** в Chat и в выборе отправной точки для новых проектов. Они работают во всех проектах без установки. Описания показываются прямо в списке, когда вы его открываете.

| Категория                   | Навыки                                                                                                        |
| --------------------------- | ------------------------------------------------------------------------------------------------------------- |
| Продажи и маркетинг         | Ad Creative, AI SDR, SEO Auditor, Programmatic SEO, GEO, Content Machine, Storyboard                          |
| Карьера                     | AI Recruiter, Resume Maker, Interview Prep                                                                    |
| Исследования и анализ       | Competitive Analysis, Deep Research, GitHub Solution Finder, Supplier Research                                |
| Бизнес и финансы            | Stock Analyzer, Excel Generator, Invoice Generator, Tax Reviewer                                              |
| Документы и инструменты     | Website Cloner, File Converter, Flashcard Generator, Legal Contract, Infographic Builder, Recreate Screenshot |
| Творчество                  | Photo Editor, Podcast Generator, Podcast Marketing, Branding Generator, Video Editing                         |
| Продуктивность              | AI Secretary, Product Manager, Design Thinker, Skill Finder, Skill Creator                                    |
| Личное                      | Travel Assistant                                                                                              |
| Безопасность и соответствие | Secrets, Sensitive Data, Input Validation, AI Security, Dependency Vetting, License Check                     |
| Качество и надежность       | Accessibility, Responsive UI, Observability, Resilience, Ship Review                                          |

<Note>
  Внутри workspace список также находит любые дополнительные навыки, установленные в каталоге проекта `.local/secondary_skills/`.
</Note>

<div id="skills-de-parceiros">
  ## Партнёрские навыки
</div>

Партнёры Replit публикуют навыки, которые учат Agent создавать приложения на основе их продуктов. Установите нужный навык, чтобы Agent знал шаблоны и соглашения соответствующего сервиса.

| Партнёр          | Чему учит Agent                                   |
| ---------------- | ------------------------------------------------- |
| Stripe           | Шаблоны интеграции платежей и выставления счетов  |
| PayPal           | Шаблоны интеграции платежей                       |
| RevenueCat       | Шаблоны подписок и покупок внутри приложения      |
| Mixpanel         | Внедрение аналитики и отслеживания                |
| BigQuery         | Шаблоны запросов к хранилищу данных               |
| Resend           | Интеграция транзакционной электронной почты       |
| Google Workspace | Интеграция с Gmail, Drive, Docs и Calendar        |
| Atlassian        | Работа с задачами Jira и страницами Confluence    |
| Google Maps      | Интеграция карт, мест, маршрутов и геокодирования |

<div id="skills-da-comunidade">
  ## Навыки от сообщества
</div>

Помимо навыков от Replit и партнёров, сообщество публикует собственные навыки, которые вы можете установить. Ищите их на [skills.sh](https://skills.sh), а чтобы создать свои, ознакомьтесь со [спецификацией Agent Skills](https://agentskills.io/specification).
