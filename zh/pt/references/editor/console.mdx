title: "控制台"

---

控制台可让您实时监控和查看正在运行的 Replit App 输出的日志。
您可以利用当前和之前运行时的信息来了解应用的行为、
排查错误并优化性能。

<Tip>
  使用 Agent 调试时，请在 prompt 中附上控制台日志，为其提供上下文。
</Tip>

</Frame>

<div id="recursos">
  ## 功能
</div>

控制台提供以下工具，帮助您了解应用的运行情况：

* **实时日志**：实时查看应用输出
* **AI 辅助**：获取有关修复日志中错误的建议
* **运行历史记录**：查看之前运行的日志，以便追踪变更

<div id="uso">
  ## 使用
</div>

您可以直接在 Project Editor 中访问控制台工具。

<Accordion title="访问控制台">
  在左侧的**工具停靠栏**中：

  1. 选择 <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="所有工具图标" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**，查看 Project Editor 的工具列表。
  2. 选择 <img class="icon-svg" src="/assets/mirror/console-8a41ac90789c.svg" alt="控制台图标" width="16" height="16" data-path="images/icons/console.svg" /> **Console**。

  在**搜索栏**中：

  1. 选择顶部的 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 放大镜图标，打开搜索工具。
  2. 输入“Console”查找该工具，然后在搜索结果中选择它。
</Accordion>

每次您在 Replit App 中点击 **Run** 按钮时，控制台都会显示一条新日志条目，其中包含以下信息：

* 用于运行代码的命令
* 时间戳信息
* 标准输出和错误日志

以下截图显示了用于启动应用的命令 `npm run dev` 以及运行日志消息：

<div id="depurao-com-ia">
  ### 使用 AI 调试
</div>

当您在日志中发现错误或其他想要了解的信息时，请点击该日志条目顶部的
**Ask AI** 按钮。这会自动打开 **Agent** 标签页，并将日志内容
发送给 Agent 进行分析。

<div id="comandos-de-entrada-de-log">
  ### 日志条目命令
</div>

控制台提供以下工具来管理日志：

* **仅显示最新**：将此开关切换为 **开启**，即可仅显示最新一次运行。
* **折叠日志条目**：点击命令名称左侧的 <img class="icon-svg" src="/assets/mirror/down-arrow-9c1cf9fd152e.svg" alt="向下箭头图标" height="16" width="16" data-path="images/icons/down-arrow.svg" /> 向下箭头，隐藏日志。
* **清除之前的运行记录**：选择此项可删除之前运行的日志。此操作不可撤销。

<div id="disponibilidade-de-rede">
  ### 网络可用性
</div>

您可以控制应用开发版本的在线可用性。

如需停止响应发往开发 URL 的请求，请选择网络信息栏右侧带斜杠的 <img class="icon-svg" src="/assets/mirror/network-off-5bdca8a4fe4e.svg" alt="网络已禁用图标" height="16" width="16" data-path="images/icons/network-off.svg" /> 地球图标。

如需重新启用，请选择 <img class="icon-svg" src="/assets/mirror/network-on-15be2e5fb4f5.svg" alt="网络已启用图标" height="16" width="16" data-path="images/icons/network-on.svg" /> 地球图标。

如需查看开发 URL，请在地址栏中选择 `{...}.replit.dev` 文本。

<Frame>
  <img src="/assets/mirror/preview-dev-url-b36770b33769.png" alt="Preview 开发 URL 的位置" width="1222" height="824" data-path="images/workspace/preview-dev-url.png" />
</Frame>

<Note>
  即使应用已配置为停止响应发往开发 URL 的请求，您仍可在 Preview 工具中访问该应用。
</Note>

<div id="parar-um-comando-de-workflow">
  ### 停止工作流命令
</div>

您可以在 Project Editor 的控制台工具中停止正在运行的工作流命令。

点击包含 Replit App 运行命令的行右侧的方形按钮即可将其停止。

要重启应用，请使用 Project Editor 顶部工作流中的 **Run** 按钮。
