# Model Context Protocol

> Comprenez le Model Context Protocol (MCP) — ce qu'il est, comment il fonctionne et pourquoi il est important pour les applications IA.

Les modèles IA comme Claude et GPT sont puissants, mais ils sont limités à ce sur quoi ils ont été entraînés. Le Model Context Protocol (MCP) leur offre un moyen standard de se connecter à des outils externes, des sources de données et des capacités du monde réel.

## Pourquoi les modèles IA ont besoin de MCP

Sans accès à des outils et données externes, les modèles IA ne peuvent pas :

* Accéder à des informations à jour
* Interagir avec des systèmes externes
* Effectuer des actions dans le monde réel
* Travailler avec vos données privées

MCP résout ce problème en créant un moyen universel pour l'IA de se connecter à des outils et des données — similaire à la façon dont USB-C a standardisé les connexions d'appareils.

Avec MCP, les modèles IA peuvent :

* Accéder à des outils et API spécialisés
* Lire à partir de sources de données privées
* Effectuer des actions dans le monde réel
* Se connecter à d'autres systèmes de manière transparente

## Fonctionnement de MCP

L'architecture MCP comporte trois composants principaux :

1. **Le côté client** — les modèles IA comme Claude ou les applications qui ont besoin d'accéder à des outils externes.
2. **La couche de communication** — le protocole lui-même qui standardise la façon dont les requêtes et les réponses sont formatées.
3. **Le côté serveur** — les programmes qui fournissent l'accès aux outils, aux sources de données et aux capacités spécialisées.

<AccordionGroup>
  <Accordion title="Qu'est-ce qu'un client MCP ?">
    Un client MCP est quelque chose comme Claude, Replit Agent ou une interface de ligne de commande qui se connecte à un grand modèle de langage. C'est le « dispositif » qui se branche sur des outils ou des sources de données externes.

    Exemples de clients MCP :

    * Claude dans le navigateur
    * Replit Agent
    * Interfaces de ligne de commande pour l'IA
    * Applications personnalisées construites avec des SDK IA
  </Accordion>

  <Accordion title="Qu'est-ce qu'un serveur MCP ?">
    Un serveur MCP fournit des outils et des capacités aux modèles IA. Pensez-y comme donner à l'IA un ensemble d'outils spécialisés pour résoudre des problèmes.

    Exemples de ce que les serveurs MCP permettent :

    * Accéder à des sources de données spécifiques pour répondre à des questions
    * Connecter l'IA à des API pour qu'elle puisse effectuer des actions en ligne
    * Lire ou écrire des fichiers
    * Effectuer des calculs ou exécuter du code
    * Récupérer du contenu depuis des services comme Notion, Linear ou Stripe
  </Accordion>
</AccordionGroup>

## Ce que MCP débloque

MCP définit plusieurs primitives qui le rendent puissant pour les applications IA :

* **Ressources** — partager des données et du contenu avec les modèles IA
* **Outils** — permettre aux modèles IA d'effectuer des actions via vos services
* **Invites** — modèles réutilisables pour des interactions IA cohérentes
* **Échantillonnage** — permettre à vos services de demander des informations aux modèles IA
* **Transports** — connecter efficacement les clients et les serveurs

## Compétences vs. serveurs MCP

Les compétences et les serveurs MCP sont les deux principales façons d'étendre les agents IA — et ils servent des objectifs différents.

|                | Compétences                                                                                      | Serveurs MCP                                                          |
| -------------- | ------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------- |
| **Idéal pour** | Flux de travail, conventions, matériaux de référence                                             | Connexion à des services externes, prise d'actions                    |
| **Chargement** | Léger — nom + description uniquement jusqu'à invocation                                          | Plus lourd — toutes les descriptions d'outils se chargent à l'avance  |
| **Définit**    | *Comment* votre agent doit fonctionner                                                           | *Ce à quoi* votre agent peut accéder                                  |
| **Exemple**    | Compétence « Analyseur d'actions » — rechercher des investissements avec un framework spécifique | Serveur MCP « Stripe » — lire les données de paiement et d'abonnement |

Consultez [Compétences Agent](/fr/learn/agent-skills) pour la façon de penser correspondante sur les compétences.

## Applications dans le monde réel

MCP permet un large éventail d'applications IA :

* **Systèmes de service client** qui accèdent aux bases de données d'entreprise pour répondre à des questions spécifiques
* **Assistants de recherche** qui recherchent et résument du contenu provenant de plusieurs sources
* **Outils de productivité** qui interagissent avec vos fichiers et applications
* **Outils de création de contenu** qui accèdent aux bibliothèques de médias et aux plateformes de publication

## Avantages

MCP offre trois avantages clés :

* Des intégrations prêtes à l'emploi auxquelles votre IA peut se connecter immédiatement
* La capacité de changer de fournisseur d'IA sans réécrire vos connexions
* Des fonctionnalités de sécurité qui protègent vos données sensibles

<Note>
  MCP est un standard émergent avec un soutien croissant dans l'écosystème IA. De nouveaux outils et intégrations sont ajoutés régulièrement.
</Note>
