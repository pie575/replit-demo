  ## Команды и Enterprise
</div>

<div id="soc-2-type-ii">
  ### Сертификация SOC 2 Type II
</div>

Replit получил сертификацию SOC 2 Type II, успешно пройдя строгий 12-месячный аудит безопасности без исключений и замечаний. Эта сертификация подтверждает, что практики безопасности соответствуют уровню Enterprise, а платформа отвечает требованиям надёжности и соответствия нормативным требованиям для клиентов Enterprise.

<div id="enterprisesso">
  ### Несколько SSO-провайдеров в Enterprise
</div>

Клиенты Enterprise теперь могут настраивать несколько SSO-провайдеров и несколько организаций для каждого из них. Это позволяет крупным компаниям использовать разные провайдеры аутентификации для разных команд, сохраняя при необходимости централизованное управление и общий доступ.
