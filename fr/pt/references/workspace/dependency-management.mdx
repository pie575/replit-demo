Replit propose plusieurs façons d&#39;installer et de gérer les paquets de votre Replit App. Vous pouvez les installer depuis le [Shell](/fr/pt/references/editor/shell), demander à l&#39;[Agent](/fr/pt/features/agent/overview/) de s&#39;en charger, ou laisser Replit détecter et installer automatiquement les dépendances manquantes lorsque vous exécutez votre Replit App.

<div id="instalar-pacotes-usando-o-shell">
  ## Installer des paquets avec le Shell
</div>

Ouvrez l&#39;outil **Shell** dans le Project Editor et exécutez la commande correspondant au gestionnaire de paquets de votre langage :

<CodeGroup>
  ```bash Node.js (npm) theme={null}
  npm install <package-name>
  ```

  ```bash Node.js (pnpm) theme={null}
  pnpm add <package-name>
  ```

  ```bash Python (poetry) theme={null}
  poetry add <package-name>
  ```

  ```bash Python (pip) theme={null}
  pip install <package-name>
  ```

  ```bash Ruby theme={null}
  bundle add <gem-name>
  ```
</CodeGroup>

Vous pouvez également utiliser l&#39;[Universal Package Manager (UPM)](https://github.com/replit/upm/) de Replit pour installer des paquets dans les langages pris en charge :

```bash theme={null}
upm add <package-name>
```

Pour installer une version spécifique :

```bash theme={null}
upm add 'flask==2.3.3'
```

Pour consulter la liste complète des langages et gestionnaires de paquets pris en charge, consultez [UPM : Langages pris en charge](https://github.com/replit/upm/#supported-languages).

<div id="instalar-pacotes-usando-o-agent">
  ## Installer des paquets avec Agent
</div>

Vous pouvez demander à [Agent](/fr/pt/features/agent/overview/) d&#39;installer des paquets pour vous directement dans le Chat. Par exemple :

* « Installe le paquet axios »
* « Ajoute Flask et SQLAlchemy à mon projet »
* « Configure TailwindCSS »

Agent installe le paquet avec le gestionnaire de paquets adapté à votre projet et met à jour les fichiers de configuration correspondants.

<div id="deteco-automtica-de-imports">
  ## Détection automatique des imports
</div>

Replit analyse automatiquement votre code à la recherche de dépendances manquantes chaque fois que vous sélectionnez **Run**. Si votre code importe un paquet qui n&#39;est pas encore installé, Replit le détecte et en installe automatiquement la version la plus récente.

Par exemple, si vous ajoutez `import flask` à `main.py`, la prochaine fois que vous sélectionnerez **Run**, la **Console** affichera un message indiquant que **Flask** est en cours d&#39;installation.

<Note>
  Vous pouvez configurer la détection automatique des imports dans le fichier [.replit](/fr/pt/references/configuration/configuration#replit-file) à l&#39;aide du paramètre `packager.features.guessImports`.
</Note>

<div id="substituir-a-deteco-automtica">
  ### Remplacer la détection automatique
</div>

Si le paquet détecté n&#39;est pas le bon ou si vous avez besoin d&#39;une version spécifique, exécutez la commande d&#39;installation appropriée dans le Shell. Par exemple :

```bash theme={null}
upm add 'flask==2.3.3'
```

Vous pouvez également exclure certains paquets ou chemins de la détection automatique dans votre fichier [.replit](/fr/pt/references/configuration/configuration#replit-file) :

<div id="gerenciadores-de-pacotes-python">
  ## Gestionnaires de paquets Python
</div>

Lorsque vous créez une Replit App en Python, **poetry** est le gestionnaire de paquets utilisé par défaut. Cela signifie que `pip install` ne gère pas vos dépendances. Utilisez plutôt `poetry add <package>` ou `upm add <package>` dans le Shell.

<div id="mudar-de-poetry-para-pip">
  ### Passer de poetry à pip
</div>

Si vous préférez utiliser `pip`, suivez ces étapes :

<Steps>
  <Step>
    Ouvrez le Shell et exécutez :

    Supprimez le fichier de verrouillage pour que l&#39;infrastructure de gestion des paquets bascule vers pip :

    ```bash theme={null}
    rm poetry.lock
    ```
  </Step>

  <Step title="Déplacez vos dépendances">
    Transférez vos dépendances de la section `[tool.poetry.dependencies]` du fichier `pyproject.toml` vers `requirements.txt`. Par exemple, `flask = "^3.0.2"` devient `flask>=3.0.2,<4`.
  </Step>

  <Step title="Nettoyez le pyproject.toml">
    Supprimez les sections `[tool.poetry...]` du `pyproject.toml`.
  </Step>
</Steps>

Après ces modifications, l&#39;infrastructure de gestion des paquets utilise `pip` pour toutes les opérations suivantes, et la détection automatique des imports continue de fonctionner comme prévu.

<div id="dependncias-de-sistema-com-nix">
  ## Dépendances système avec Nix
</div>

Replit prend en charge tous les langages de programmation grâce à son intégration avec [Nix](https://nixos.org/). Si vous avez besoin de dépendances au niveau du système en plus des paquets de langage standard, vous pouvez les ajouter à votre fichier [replit.nix](/fr/pt/references/configuration/configuration#replit-nix-file).

<div id="pacotes-nix">
  ### Paquets Nix
</div>

Ajoutez des dépendances système en modifiant directement le fichier `replit.nix`. Vous pouvez rechercher les paquets disponibles sur [search.nixos.org](https://search.nixos.org/packages).

<div id="mdulos">
  ### Modules
</div>

Les modules regroupent la prise en charge des langages de programmation, des formateurs et des gestionnaires de paquets. Ils constituent la base de votre Replit App. Si vous créez une Replit App à partir d’un template ou d’un dépôt GitHub, Replit installe automatiquement les modules nécessaires.

Vous pouvez personnaliser les modules et d’autres configurations de Nix à l’aide du fichier [.replit](/fr/pt/references/configuration/configuration#replit-file).

<div id="configurao-do-gerenciador-de-pacotes">
  ## Configuration du gestionnaire de paquets
</div>

Vous pouvez ajuster le comportement de la gestion des paquets dans votre fichier [.replit](/fr/pt/references/configuration/configuration#replit-file) :

| Configuration                         | Description                                                                   | Valeur par défaut       |
| ------------------------------------- | ----------------------------------------------------------------------------- | ----------------------- |
| `packager.language`                   | Langage utilisé pour les opérations sur les paquets                           | Détecté automatiquement |
| `packager.features.guessImports`      | Détecter et installer automatiquement les paquets manquants à l&#39;exécution | `true`                  |
| `packager.features.packageSearch`     | Activer la prise en charge de la recherche de paquets                         | `true`                  |
| `packager.features.enabledForHosting` | Exiger l&#39;installation des paquets lors de l&#39;hébergement               | `false`                 |
| `packager.afterInstall`               | Commande à exécuter après l&#39;installation d&#39;un paquet                  | —                       |
| `packager.ignoredPaths`               | Chemins à ignorer lors de la détection des imports                            | `[]`                    |
| `packager.ignoredPackages`            | Paquets à exclure de la détection automatique                                 | `[]`                    |
