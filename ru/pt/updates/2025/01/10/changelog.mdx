<div id="integrao-com-slack">
  ### Интеграция со Slack
</div>

Теперь Agent умеет работать с API Slack. Это значит, что с его помощью вы можете создавать приложения, которые:

* публикуют сообщения;
* читают историю переписки

во всех ваших любимых каналах Slack.

</Frame>

Присылайте свои проекты в [Agent Showcase](https://forms.gle/qxpfr82wNpKsCdok9).

<div id="melhorias-no-agent-e-no-assistant">
  ### Улучшения в Agent и Assistant
</div>

* Agent теперь загружается на главной странице быстрее, так что вы сможете раньше приступить к работе.
* При выделении текста в Console и Shell появляется плавающее всплывающее окно с быстрым доступом к Assistant. Просто выделите текст и нажмите на значок Assistant, чтобы задать вопрос.

</Frame>

  ### Улучшенное управление закреплением проектов
</div>

Теперь закреплять и откреплять публичные проекты вашей организации стало проще!

<Frame>
  <img src="/assets/mirror/feature-on-profile-95b81a71e0d7.png" alt="Закреплённый проект в профиле" width="1836" height="644" data-path="images/changelog/2025-01-10/feature-on-profile.png" />
</Frame>

Теперь управлять закреплением проекта можно прямо из рабочего пространства — через модальное окно с информацией о проекте и таблицу списка проектов.

<Frame>
  <img src="/assets/mirror/profile-preview-b8f2ecfed154.png" alt="Предпросмотр профиля" width="2126" height="1152" data-path="images/changelog/2025-01-10/profile-preview.png" />
</Frame>

Кроме того, при закреплении проекта вы сразу увидите, как он будет выглядеть в вашем публичном профиле.
