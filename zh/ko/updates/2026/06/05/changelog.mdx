<div id="shopify">
  ### 使用 Shopify 销售实物商品
</div>

现在，你可以创建销售实物商品的在线商店。只需让 Agent 搭建购物商城，它就会创建 Shopify 商店、添加商品，并配置购物车和结账流程。Agent 会提供一个认领商店的链接，你订阅 Shopify 套餐并接入支付后即可正式上线。

<div id="microsoft-fabric">
  ### 在 Microsoft Fabric 上构建数据应用
</div>

现在，你可以在 Replit 中构建 AI 驱动的数据应用，并直接发布到 Microsoft Fabric。从 Microsoft Fabric 模板开始，连接 Power BI 语义模型，然后让 Agent 基于受管理的企业数据构建仪表板和内部工具。身份验证和访问策略始终保留在 Fabric 内。

<div id="dns">
  ### 自定义域名自动配置 DNS
</div>

连接自有域名变得更加简单。连接域名后，Replit 会通过 Entri 自动配置所需的 DNS 记录，无需再手动将记录复制到域名服务商处。你只需选择并验证域名，其余的交给 Replit。

进一步了解[自定义域名](/zh/ko/features/publishing/custom-domains)。

<div id="seo-agent">
  ### 使用 SEO Agent 提升搜索排名
</div>

SEO Agent 会检查已发布的应用，找出导致搜索引擎和 AI 工具无法发现该应用的问题。每条发现结果都附带一键修复方案，你可以先查看再应用。在项目中打开**增长**面板即可运行扫描。

<div id="stripe">
  ### 在协作工作区中使用 Stripe
</div>

Stripe 现已支持协作工作区，整个团队可以共同构建、测试同一个应用并实现变现。工作区中的所有成员都可以使用已连接的 Stripe 账户开展工作，无需各自单独搭建支付功能。

详细了解 [Stripe 支付](/zh/ko/features/monetization/stripe-payments)。
