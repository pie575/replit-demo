export const YouTubeEmbed = ({videoId, title = "YouTube 视频", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

  ## Agent 3 发布
</div>

本周,我们发布了 Agent 3。

<YouTubeEmbed videoId="4FxNXFOdt6w" title="Agent 3 发布直播" />

Agent 3 在自主性、可靠性和速度方面实现了重大突破:

* **应用测试**:Agent 会在真实浏览器中自我测试,发现问题并通过反思循环加以修复。参见[应用测试](/zh/pt/core-concepts/agent/app-testing)。
* **更长的运行时间**:借助实时监控,Agent 可自主工作长达 200 分钟,非常适合规模更大的构建任务。详见 [Agent](/zh/pt/core-concepts/agent#max-autonomy)。
* **生成智能体**:创建可按计划运行或与 Slack、Telegram 集成的智能体与自动化流程。参见[智能体与自动化](/zh/pt/core-concepts/agent/agents-and-automations)。

<div id="conectores-e-integraes-de-app">
  ## 应用连接器与集成
</div>

借助内置的集成和连接器，更快地部署应用：

* **Replit 托管**：内置集成，在你的应用中自动生效。
* **Connectors**：第一方集成，只需登录一次即可在所有应用中重复使用。
* **外部集成**：由 Agent 配置的可信第三方服务，使用你自己的 API 密钥。

<div id="agentes-e-automaes-beta">
  ## 智能体与自动化 (Beta)
</div>

作为 Agent 3 的一部分，你可以创建智能体、聊天机器人和自动化工作流：

* **Slack 智能体**：创建用于搜索、问答和自动化的 Slack 机器人
* **Telegram 智能体**：创建用于日程安排、客户支持等场景的机器人
* **定时自动化**：按设定的频率运行计划工作流
