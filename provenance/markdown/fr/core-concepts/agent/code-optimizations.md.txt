# Optimisations de code

> Découvrez comment contrôler si Agent révise et simplifie son propre code après la construction.

export const YouTubeEmbed = ({videoId, title = "YouTube video", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

**Code Optimizations** (anciennement Autonomy Level) est un paramètre activé/désactivé dans les **Paramètres avancés** du menu déroulant des paramètres Agent. Lorsqu'il est **activé**, Agent révise son propre code et simplifie les travaux futurs — améliorant la précision et réduisant les coûts en évitant les erreurs. Lorsqu'il est **désactivé**, vous bénéficiez d'une révision minimale ou nulle du code par l'IA et d'un contrôle maximal. Disponible sur les [plans payants](https://replit.com/pricing).

Nous recommandons d'activer Code Optimizations pour la plupart des projets afin d'obtenir une meilleure qualité de code et moins de cycles de retravail coûteux.

## Utilisation

Accédez à Code Optimizations via le menu déroulant des paramètres Agent lorsque vous travaillez sur un projet. Le paramètre s'applique à votre conversation en cours, affecte la façon dont Agent aborde les tâches suivantes et est disponible lorsque vous utilisez le mode Economy ou Power.

<Accordion title="Comment accéder à Code Optimizations">
  1. Ouvrez votre projet dans le Project Editor
  2. Ouvrez le menu déroulant des paramètres Agent dans la saisie du chat
  3. Développez les **Paramètres avancés** et localisez **Code Optimizations**
  4. Activez-le ou désactivez-le selon vos préférences
</Accordion>

### Quand l'utiliser

* **Activé** : Recommandé pour la plupart des travaux. Agent révise son propre code, corrige les erreurs et peut réduire le retravail. Légèrement plus long par tâche mais de meilleure qualité.
* **Désactivé** : À utiliser lorsque vous souhaitez l'expérience la plus rapide et la plus pratique — par exemple pour des modifications rapides ou lorsque vous préférez réviser chaque modification vous-même.
