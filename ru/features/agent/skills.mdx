<div id="what-is-a-skill">
  ## Что такое навык?
</div>

Навык — это папка. Внутри неё лежит файл `SKILL.md` с инструкциями, которым следует Agent, а также любые вспомогательные файлы, на которые он может ссылаться. Навыки хранятся в каталоге `/.agents/skills` вашего проекта и соответствуют [спецификации Agent Skills](https://agentskills.io/specification) — открытому стандарту, который работает с любыми агентами.

Agent видит название и описание каждого установленного навыка, но загружает содержимое целиком, только если оно относится к текущей задаче. Благодаря этому навыки экономно расходуют контекст: их можно установить много, не ухудшая качество работы Agent.

<div id="pre-defined-skills">
  ## Предустановленные навыки
</div>

Replit поставляется с предустановленными навыками, которые доступны в меню **Use a skill** в чате и в меню выбора отправной точки для нового проекта. Эти навыки работают в любом проекте без установки. Полный каталог, партнёрские навыки и инструкции по их установке смотрите в разделе [Каталог навыков](/ru/features/agent/skills-directory).

Чтобы добавить предустановленный навык, откройте меню **Use a skill** из поля ввода чата и выберите нужный навык или просто попросите Agent загрузить его.

<div id="skill-scope">
  ## Область действия навыка
</div>

Навыки могут действовать на разных уровнях:

| Область               | Доступность                               | Где хранится                                                                                                 |
| --------------------- | ----------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| **Уровень проекта**   | Только в рамках одного проекта            | Версионируется вместе с вашими файлами в `/.agents/skills`                                                   |
| **Уровень workspace** | Доступно всем участникам вашего workspace | Управляется централизованно в настройках Workspace                                                           |
| **Enterprise**        | Стандарты для всей компании               | Входит в [пользовательские шаблоны](/ru/teams/custom-templates) и [дизайн-системы](/ru/teams/custom-design-system) |

О навыках уровня workspace см. [Настройка Agent](/ru/features/agent/agent-customization) — там описано, как настроить навыки workspace и пользовательские инструкции для вашей команды.

<div id="create-a-custom-skill">
  ## Создание пользовательского навыка
</div>

Создайте пользовательский навык, если вам нужны многоразовые инструкции в библиотеке Workspace.
В общем Workspace вы можете задать доступ для участников Workspace прямо при создании навыка
и изменить его позже. Кто именно может управлять навыками, зависит от вашего тарифа — см.
[Настройка Agent](/ru/features/agent/agent-customization).

Доступны следующие политики доступа для участников Workspace:

| Политика         | Доступ                                                                                          |
| ---------------- | ----------------------------------------------------------------------------------------------- |
| **Обязательный** | Всегда включён, отключить нельзя                                                                |
| **Доступный**    | Необязательный, по умолчанию выключен; чтобы пользоваться навыком, участник должен включить его |
| **Без доступа**  | Скрыт от участников                                                                             |

<Steps>
  <Step title="Откройте настройки навыков">
    Откройте **Settings** &gt; **Customization** &gt; **Skills** в Workspace.
  </Step>

  <Step title="Начните создание пользовательского навыка">
    Выберите **Add**, затем — **Write a skill**.
  </Step>

  <Step title="Опишите навык">
    Пользовательский навык включает:

    * **Name**: обозначает навык в библиотеке Workspace.
    * **Description**: поясняет, когда Agent должен использовать навык.
    * **Instructions**: описывает шаги, которым должен следовать Agent.

    <Frame caption="Введите данные пользовательского навыка в командном Workspace.">
      <img src="/assets/mirror/workspace-custom-skill-create-6d6014e5c561.jpg" alt="Форма пользовательского навыка в командном Workspace с полями названия, описания, инструкций и кнопкой Create skill" width="2000" height="1363" data-path="images/replitai/workspace-custom-skill-create.jpg" />
    </Frame>
  </Step>

  <Step title="Задайте доступ для участников Workspace">
    Новый навык создаётся со статусом **Private**, поэтому использовать его можете только вы и администраторы Workspace.
    Откройте элемент управления **Sharing** и выберите одну из указанных выше политик для **Members
    in workspace**.

    <Frame caption="Задайте доступ для участников Workspace перед созданием навыка.">
      <img src="/assets/mirror/workspace-custom-skill-create-sharing-00a493b8ba70.jpg" alt="Форма пользовательского навыка с открытым элементом управления Sharing и вариантами Required, Available и No access" width="2000" height="1154" data-path="images/replitai/workspace-custom-skill-create-sharing.jpg" />
    </Frame>
  </Step>

  <Step title="Создайте навык">
    Проверьте данные и выберите **Create skill**.
  </Step>
</Steps>

<div id="share-project-skills">
  ## Предоставление доступа к навыкам проекта
</div>

В общем Workspace доступ участников можно изменить и после создания навыка.

<Steps>
  <Step title="Создайте или выберите навык">
    Создайте пользовательский навык по шагам выше или выберите существующий навык в разделе
    **Settings** &gt; **Customization** &gt; **Skills**.

    Чтобы сохранить навык проекта в свой Workspace, откройте **Agent Skills** &gt; **Project skills** в проекте. Выберите **Save to workspace**, введите имя и нажмите **Save**.
  </Step>

  <Step title="Откройте настройки доступа">
    На карточке навыка в библиотеке Workspace откройте меню параметров и выберите **Share...**.

    <Frame caption="Откройте меню существующего навыка, чтобы поделиться им после создания.">
      <img src="/assets/mirror/workspace-skill-share-menu-af1b84e16a3c.jpg" alt="Страница навыков Workspace с открытым меню параметров существующего навыка и видимым действием «Поделиться»" width="1600" height="1100" data-path="images/replitai/workspace-skill-share-menu.jpg" />
    </Frame>
  </Step>

  <Step title="Настройте доступ для участников Workspace">
    В диалоговом окне **Share skill** выберите одну из описанных выше политик для параметра **Members in
    workspace**. Выбор вступает в силу сразу — отдельно подтверждать его не нужно.

    <Frame caption="Выберите, как участники Workspace смогут получать доступ к навыку.">
      <img src="/assets/mirror/workspace-skill-sharing-policy-24fbbc668714.jpg" alt="Диалоговое окно Share skill с политиками «Обязательный», «Доступный» и «Нет доступа» для участников Workspace" width="1500" height="1000" data-path="images/replitai/workspace-skill-sharing-policy.jpg" />
    </Frame>
  </Step>
</Steps>

<div id="import-skills-from-github">
  ## Импорт навыков из GitHub
</div>

Добавляйте навыки по URL публичного репозитория, папки или файла на GitHub.

<Steps>
  <Step title="Откройте раздел Workspace Skills">
    В Agent выберите **+** &gt; **Use a skill**, чтобы открыть **Workspace Skills**.

    <Frame caption="Откройте меню «плюс» и выберите Use a skill, чтобы перейти к Workspace Skills.">
      <img src="/assets/mirror/workspace-skill-picker-d7c3f5525de2.jpg" alt="Меню «плюс» в Agent с выбранным пунктом Use a skill и списком навыков Workspace Skills: ask-matt, claude-handoff и code-review" width="2000" height="1085" data-path="images/replitai/workspace-skill-picker.jpg" />
    </Frame>
  </Step>

  <Step title="Просмотрите навыки">
    Вставьте URL публичного репозитория, папки или файла на GitHub и выберите **Preview
    skills**. Предварительный просмотр проверяет только структуру файлов — инструкции и описания
    навыков при этом не загружаются.

    <Frame caption="Введите публичный URL GitHub и просмотрите структуру файлов навыка.">
      <img src="/assets/mirror/workspace-skill-github-preview-c8476d8d1556.jpg" alt="Страница Add from GitHub с URL публичного репозитория GitHub и кнопкой Preview skills" width="2000" height="1154" data-path="images/replitai/workspace-skill-github-preview.jpg" />
    </Frame>
  </Step>

  <Step title="Выберите и импортируйте навыки">
    Просмотрите обнаруженные навыки, отметьте нужные и выберите **Import**. На кнопке отображается количество выбранных навыков, например **Import 36 skills**.

    <Frame caption="Просмотрите обнаруженные навыки и выберите те, которые нужно импортировать.">
      <img src="/assets/mirror/workspace-skill-github-select-68589ea766c3.jpg" alt="Предварительный просмотр навыков из GitHub с обнаруженными навыками, элементами выбора и кнопкой Import 36 skills" width="2000" height="1154" data-path="images/replitai/workspace-skill-github-select.jpg" />
    </Frame>
  </Step>
</Steps>

В примере выше используется публичный репозиторий
[mattpocock/skills](https://github.com/mattpocock/skills).

<Note>
  За один импорт можно добавить не более 50 навыков, 3 500 файлов или 200 МиБ. Приватные репозитории не поддерживаются.
</Note>

Импортированные репозитории отображаются в фильтре **GitHub** на вкладке **Skills**.

<div id="how-agent-loads-skills">
  ## Как Agent загружает навыки
</div>

В каждом чате Agent считывает метаданные (название и описание) всех установленных навыков. Полное содержимое навыка загружается только тогда, когда Agent сочтёт его подходящим для текущей задачи. Благодаря этому содержимое навыков не занимает контекстное окно, пока оно не потребуется.

Установленные навыки сохраняются в проекте между сессиями Agent, и их можно зафиксировать в системе контроля версий, чтобы поделиться с командой.

<div id="working-with-other-ai-coding-tools">
  ## Работа с другими ИИ-инструментами для написания кода
</div>

<Accordion title="Импорт навыков из других ИИ-инструментов для написания кода">
  Если вы работаете сразу с несколькими ИИ-инструментами для написания кода, вам пригодится [rulesync](https://github.com/dyoshikawa/rulesync): он поддерживает Replit и помогает сохранять единообразие конфигураций.

  Вы можете импортировать навыки из других ИИ-помощников по написанию кода:

  ```bash theme={null}
  npx rulesync init
  npx rulesync import --targets claudecode --features skills
  npx rulesync generate --targets replit --features skills
  ```

  Так вы сможете поддерживать единый набор навыков, работающий в разных средах разработки.
</Accordion>
