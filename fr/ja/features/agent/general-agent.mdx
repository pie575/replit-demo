<div id="general-agent">
  ## Qu&#39;est-ce que l&#39;Agent général ?
</div>

L&#39;Agent général est la manière la plus souple d&#39;utiliser Replit Agent. Nul besoin de choisir à l&#39;avance un type d&#39;artefact ni de vous engager à créer quelque chose de précis. Lancez simplement la conversation — vous pouvez créer un CSV, générer un PDF, faire des recherches sur un sujet ou, le moment venu, développer une application complète.

Concepts clés :

* **Aucune présélection** : commencez à travailler sans choisir de type d&#39;artefact
* **Tous les résultats possibles** : générez des fichiers (CSV, PDF, documents), effectuez des recherches, créez des applications
* **Connecteurs** : lisez et écrivez des données dans des services externes comme BigQuery, Linear, Slack, Notion, Amplitude, Segment ou Hex
* **Montée en puissance progressive** : commencez par une simple conversation, puis passez naturellement au développement d&#39;une application complète

<div id="general-agent-2">
  ## Comment accéder à l&#39;Agent général
</div>

Vous pouvez accéder à l&#39;Agent général de plusieurs façons :

1. **Sélectionnez « General »** avant de rédiger votre prompt sur la page d&#39;accueil de Replit
2. **Ouvrez un projet existant** et discutez directement avec l&#39;Agent
3. **Choisissez n&#39;importe quel [framework de développement](https://replit.com/templates)** — tous les frameworks de développement intègrent automatiquement l&#39;Agent général
4. **[Importez](/fr/ja/build/import-from-providers) depuis GitHub** — les projets importés depuis GitHub sont automatiquement dotés de l&#39;Agent général

<div id="general-agent-3">
  ## Comment utiliser l&#39;Agent général
</div>

<div id="section">
  ### Lancez simplement une conversation
</div>

Ouvrez un projet et lancez une conversation. Nul besoin de vous engager à créer quelque chose de précis — Agent travaille dans le contexte du projet en cours et peut répondre à n&#39;importe quelle demande.

**Exemples de prompts :**

* « Résume les points essentiels de ce document »
* « Crée un CSV des 100 entreprises générant le plus de revenus »
* « Quels sont les 5 principaux tickets dans Linear ? »
* « Configure un projet Vue.js avec TypeScript »

Agent peut travailler sur les fichiers créés pendant la session, produire un fichier unique en sortie et exécuter du code dans le cadre de son raisonnement — le tout avant même que vous ayez décidé de créer quoi que ce soit.

<div id="section-2">
  ### Connecter des services externes
</div>

Connectez vos outils pour qu&#39;Agent puisse lire et écrire directement vos données :

1. Rendez-vous dans **Connecteurs**, dans les paramètres du projet
2. Connectez un service (BigQuery, Linear, Slack, Notion, Amplitude, Segment, Hex, etc.)
3. Demandez à Agent de lire ou d&#39;écrire des données

**Exemples de prompts utilisant les connecteurs :**

* « Quels sont les tickets ouverts dans Linear ? »
* « Résume les messages Slack d&#39;aujourd&#39;hui dans #engineering »
* « Récupère les données de ventes du mois dernier depuis BigQuery »
* « Affiche les prochains événements de mon calendrier »
* « Crée un nouveau ticket dans Linear pour le bug d&#39;onboarding »
* « Envoie le résumé dans #engineering sur Slack »

<div id="section-3">
  ### Du chat à l&#39;application complète
</div>

Lorsque vous êtes prêt à construire, il vous suffit de le dire. Agent passe sans effort d&#39;une simple conversation à la création d&#39;une application — sans repartir de zéro ni changer de contexte.

* « Transformez ceci en application web »
* « Créez une application à partir de ces données »
* « Créez un tableau de bord pour ces métriques »
* « Configurez un outil CLI en Rust »

Vous pouvez commencer de façon informelle — explorer un sujet, générer un rapport, examiner des données — puis passer à la création d&#39;une application complète au moment opportun.

<div id="section-4">
  ## Ce que vous pouvez créer
</div>

* **Travail de connaissance** : effectuez des recherches, des synthèses et des analyses sans créer d&#39;application
* **Fichiers uniques en sortie** : CSV, PDF, documents, exports de données, rapports formatés
* **Applications de données** : interrogez les services connectés et visualisez les résultats dans un tableau de bord
* **N&#39;importe quel framework ou langage** : Angular, Vue, Svelte, Rust, Go, C#, Python tkinter, jeux Godot, outils CLI, et bien plus
* **Applications full stack** : lorsque vous êtes prêt, créez une application complète à partir du contexte de la conversation

<div id="section-5">
  ## À quoi s&#39;attendre
</div>

L&#39;Agent général offre plus de puissance et de flexibilité, mais au prix d&#39;une certaine variabilité :

* **Configuration en une seule fois** : l&#39;Agent peut parfois tout configurer d&#39;un coup
* **Collaboration itérative** : les configurations complexes peuvent nécessiter plusieurs ajustements successifs
* **Limites techniques** : certaines technologies ne sont pas toujours entièrement prises en charge dans l&#39;environnement Nix

<Note>
  Contrairement à l&#39;Agent standard, qui dispose d&#39;un environnement préconfiguré, l&#39;Agent général définit son propre environnement et ses propres commandes en fonction de vos demandes. Une fois prêt pour le déploiement, il se peut que vous deviez lui demander de configurer la publication.
</Note>

<div id="section-6">
  ## Questions fréquentes
</div>

<Accordion title="Agent peut-il voir les autres projets ?">
  Non. Chaque conversation est limitée à un seul projet. Le projet A et le projet B ne peuvent pas communiquer entre eux.
</Accordion>

<Accordion title="Pourquoi n'ai-je toujours pas accès aux outils externes ?">
  Vous devez d&#39;abord connecter le service via un connecteur. Une fois la connexion établie, Agent peut lire et écrire les données du service, mais il n&#39;a aucun accès par défaut.
</Accordion>

<Accordion title="Quels connecteurs sont disponibles ?">
  Actuellement pris en charge : BigQuery, Linear, Slack, Notion, Amplitude, Segment, Hex, etc. De nouveaux connecteurs sont ajoutés régulièrement.
</Accordion>

<Accordion title="Un connecteur est-il nécessaire pour utiliser Agent général ?">
  Non. Les connecteurs sont facultatifs. Vous pouvez utiliser Agent général pour le travail de connaissance, la génération de fichiers et la création d&#39;applications, sans aucune connexion externe.
</Accordion>
