skill은 Agent에게 새로운 능력을 가르칩니다. 선호하는 패턴, 라이브러리 세부 사항, design system 규칙, 이미 해결한 문제의 해법 등을 알려줄 수 있습니다. 메시지에 skill을 첨부하거나, project에 설치하거나, 새 project의 시작점으로 선택해 보세요.

<div id="use-a-skill-in-chat">
  ## 채팅에서 skill 사용하기
</div>

skill을 가장 빠르게 사용해 보는 방법은 메시지 하나에 skill을 첨부하는 것입니다. 설치는 필요 없습니다.

<Frame>
  <img src="/assets/mirror/agent-skills-picker-ee4058454475.png" alt="채팅 입력창 옆 + 버튼에서 열린 skill 선택기로, Ad Creative, AI Recruiter, AI SDR, AI Secretary가 포함된 Skills 목록을 보여줍니다" width="723" height="529" data-path="images/replitai/agent-skills-picker.png" />
</Frame>

<Steps>
  <Step title="skill 선택기 열기">
    채팅 입력창 옆의 **+** 버튼을 클릭한 후 **Use a skill**을 선택합니다.
  </Step>

  <Step title="skill 둘러보고 선택하기">
    Business &amp; finance, Creative, Research &amp; analysis 등 카테고리별로 skills를 둘러보세요. 메시지에 첨부할 skill을 하나 이상 선택합니다.
  </Step>

  <Step title="메시지 보내기">
    요청 내용을 입력한 후 전송하세요. Agent는 선택한 skills를 해당 메시지에만 사용합니다. 메시지에 skill chip이 표시되므로 어떤 skills가 활성화되어 있는지 확인할 수 있습니다.
  </Step>
</Steps>

예를 들어 **Stock Analyzer**를 첨부해 Agent에게 주식 리서치 보고서를 만들어 달라고 요청하거나, **Deep Research**를 첨부해 Agent가 특정 주제를 조사하고 체계적인 findings를 정리하도록 할 수 있습니다.

<Tip>
  채팅에 첨부한 skills는 project에 아무것도 설치하지 않습니다. 모든 project에서 곧바로 사용할 수 있습니다.
</Tip>

<div id="start-a-project-with-a-skill">
  ## skill로 project 시작하기
</div>

새 project를 만들 때 사전 검증된 skill을 시작점으로 선택할 수 있습니다. Agent는 해당 skill의 instructions를 활용해 project의 기본 구조를 잡아 줍니다.

<Steps>
  <Step title="시작점 선택기 열기">
    새 project 화면에서 **+**를 클릭한 다음 **Use a skill**을 선택합니다.
  </Step>

  <Step title="skill 선택하기">
    **AI SDR**, **SEO Auditor**, **Ad Creative**, **Programmatic SEO** 등 엄선된 skills를 둘러보세요. 만들려는 앱의 종류에 맞는 skill을 선택합니다.
  </Step>

  <Step title="앱 설명하기">
    원하는 바를 Agent에게 알려주세요. Agent가 해당 skill의 패턴과 conventions를 처음부터 적용해 project를 만들어 줍니다.
  </Step>
</Steps>

<div id="install-a-skill-in-your-project">
  ## project에 skill 설치하기
</div>

project의 모든 대화에서 Agent가 skill을 일관되게 적용하도록 하려면 해당 skill을 설치하세요. 설치된 skill은 project의 `/.agents/skills` 디렉터리에 저장되며, chat session이 종료되어도 그대로 유지됩니다.

<div id="install-from-the-skills-pane">
  ### Skills pane에서 설치하기
</div>

Project Editor에서 **Skills pane**을 열고 **Discover** tab을 선택하면 커뮤니티가 기여한 skills를 검색할 수 있습니다. 원하는 skill을 찾아 **Install**을 클릭하면 project에 자동으로 추가됩니다.

<Frame>
  <img src="/assets/mirror/agent-skills-discover-732b2b0c488a.png" alt="설치 버튼과 함께 검색 가능한 커뮤니티 기여 skills를 보여주는 Discover skills 탭" width="2542" height="1850" data-path="images/replitai/agent-skills-discover.png" />
</Frame>

예를 들어 고급 애니메이션이 들어간 포트폴리오 사이트를 만든다면 다음과 같은 skills를 설치할 수 있습니다:

* **GSAP React** — 스크롤 기반 애니메이션, 텍스트 등장 효과, SVG 경로 드로잉을 Agent에게 가르칩니다
* **Tailwind design system** — typography, spacing, 뷰 전환에 대한 Tailwind CSS 패턴 지식을 Agent에게 제공합니다
* **Find skills** — 사용자를 대신해 새로운 skills를 찾아 설치하는 방법을 Agent에게 가르칩니다

<Tip>
  [npx skills CLI](https://github.com/vercel-labs/skills)로 skills를 설치할 수도 있습니다:

  ```bash theme={null}
  npx skills <skill> -a replit
  ```
</Tip>

<div id="create-a-skill-from-a-conversation">
  ### 대화에서 skill 만들기
</div>

skill을 만드는 가장 자연스러운 방법은 Agent와 대화하는 것입니다. 함께 문제를 해결했거나 새로운 라이브러리를 조사한 뒤, Agent에게 배운 내용을 정리해 달라고 요청하세요.

<AiPrompt>
  GSAP React 통합의 모범 사례를 조사하고 이 프로젝트를 위한 skill을 만들어 줘.
</AiPrompt>

Agent는 전체 대화 context를 활용해 상세한 skill 파일을 작성합니다. 특히 문제에 대한 이해를 함께 쌓아 온 디버깅 session 이후에 특히 효과적입니다.

<div id="write-a-custom-skill">
  ### custom Skill 작성하기
</div>

고급 사용 사례에서는 [Agent Skills specification](https://agentskills.io/specification)을 그대로 따라 skill을 직접 작성할 수 있습니다. 파일 사이드바에서 **Show Hidden Files**를 켠 다음 `/.agents/skills/`를 열고 새 Markdown 파일을 만드세요. 이렇게 하면 Agent가 무엇을 알고 어떻게 동작할지를 완전히 제어할 수 있습니다.
