Le CLUI (Command Line User Interface) est la barre de commande interactive de Replit qui vous permet d&#39;exécuter rapidement de nombreuses actions sans passer par les menus. Il allie l&#39;efficacité de la ligne de commande à une interface graphique.

<div id="section">
  ## Fonctionnalités
</div>

CLUI offre de puissantes interactions pilotées par commandes dans trois contextes distincts au sein de Replit :

* **Gestion des Settings** : gérez vos paramètres, consultez les avertissements et restaurez les applications Replit supprimées
* **Navigation rapide** : passez d&#39;une application Replit à l&#39;autre et accédez aux fonctionnalités courantes grâce à des raccourcis
* **Opérations du Workspace** : recherchez des fichiers, effectuez des recherches dans le code et accédez aux outils depuis votre environnement de développement

<div id="section-2">
  ## Utilisation
</div>

<div id="clui">
  ### CLUI du compte
</div>

Le CLUI du compte vous permet de gérer vos paramètres, vos équipes et les applications Replit supprimées.

**Comment y accéder** : rendez-vous sur la [page CLUI](https://replit.com/~/cli), saisissez une commande dans le champ de saisie pour la rechercher, puis appuyez sur Entrée pour l&#39;exécuter.

<Accordion title="Commandes de compte">
  Saisissez `account` pour gérer vos paramètres :

  * **view-warns** : affiche les avertissements que vous avez reçus
  * **change-username** : modifie votre nom d&#39;utilisateur (une seule fois)
</Accordion>

<Accordion title="Commandes de corbeille">
  Saisissez `trash` pour gérer les applications Replit supprimées :

  * **restore &lt;title&gt;** : restaure une application Replit supprimée à partir de son titre (si plusieurs portent le même nom, la plus récemment supprimée est restaurée)
  * **view** : affiche les applications Replit récemment supprimées
</Accordion>

<Accordion title="Commandes d'équipe">
  Saisissez `team` pour gérer vos équipes :

  * **view** : affiche, par nom d&#39;utilisateur, les membres des équipes auxquelles vous appartenez
  * **fork-repl-to-project** : crée un projet d&#39;équipe en forkant une application Replit existante
</Accordion>

<Accordion title="Commande d'effacement">
  Saisissez `clear` pour effacer de l&#39;écran toutes les commandes précédemment exécutées
</Accordion>

<div id="clui-2">
  ### CLUI de raccourcis
</div>

Le CLUI de raccourcis offre un accès rapide aux fonctionnalités courantes de Replit depuis n&#39;importe quelle page.

<Frame>
  <img src="/assets/mirror/shortcuts-clui-768d49b44785.png" alt="CLUI de raccourcis" width="689" height="291" data-path="images/getting-started/shortcuts-clui.png" />
</Frame>

**Comment y accéder** : appuyez sur **CMD/CTRL + K** ou cliquez sur l&#39;icône de recherche dans la barre de navigation supérieure de la plupart des pages Replit.

<Accordion title="Commandes disponibles">
  * **Search** : recherchez des applications Replit, des Templates, du Code, des People, etc.
  * **New** : créez une nouvelle application Replit
  * **My Replit Apps** : parcourez vos applications Replit et naviguez entre elles
  * **My Code** : recherchez du code dans l&#39;ensemble de vos applications Replit
</Accordion>

<div id="clui-3">
  ### CLUI du Workspace
</div>

Le CLUI du Workspace vous aide à exécuter des actions, accéder aux outils, trouver des fichiers et rechercher du code pendant que vous travaillez sur votre application Replit.

<Frame>
  <img src="/assets/mirror/ws-clui-81764b3d111b.png" alt="CLUI du Workspace" width="429" height="202" data-path="images/getting-started/ws-clui.png" />
</Frame>

**Comment y accéder** : dans le Workspace, appuyez sur **CMD/CTRL + K** ou cliquez sur l&#39;icône de recherche en haut à gauche.

<Accordion title="Actions courantes">
  * **Trouver un fichier** : localisez rapidement les fichiers de votre projet
  * **Rechercher du code** : trouvez des extraits de code précis dans l&#39;ensemble de vos fichiers
  * **Accéder aux outils** : ouvrez n&#39;importe quel outil ou panneau disponible dans le Workspace
  * **Exécuter des commandes** : lancez des commandes propres au Workspace
</Accordion>
