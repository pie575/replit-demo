# Mode Agent Free

> Découvrez comment le mode Free permet aux abonnés Starter, Core et Pro d'utiliser Agent gratuitement.

<Note>
  Certains détails sur les allocations peuvent encore être affinés avant le lancement.
</Note>

Le mode Free permet aux abonnés Starter, Core et Pro d'utiliser Agent sans coût supplémentaire. Starter inclut le mode Free avec ses limites existantes. Core et Pro incluent une allocation de mode Free. Ouvrez une conversation pour explorer, planifier, créer ou demander de l'aide. Si une demande nécessite un mode payant ou une action payante, Replit vous le signale clairement avant que quoi que ce soit de facturable ne commence.

## Pourquoi vous allez l'apprécier

* Commencez par une conversation plutôt que par un flux de configuration.
* Explorez des idées et avancez avant de décider si vous avez besoin de plus de capacité.
* Gardez le contrôle lorsqu'une demande nécessite une action payante.
* Voyez une étiquette **Free** claire sur le travail effectué en mode Free.

## Comment ça marche

1. Les nouvelles sessions Starter, Core et Pro démarrent en mode Free.
2. Le travail qui correspond au mode Free se poursuit sans invite d'action payante.
3. Si un mode payant traiterait mieux une demande, Agent l'explique et vous laisse le choix.
4. Vous pouvez autoriser le mode payant pour cette demande uniquement, ou demander à Agent de continuer en mode Free.
5. Après une escalade payante ponctuelle, votre mode revient au mode Free.

## Les trois modes Agent

<CardGroup cols={3}>
  <Card title="Free">
    Utilisation d'Agent sans coût pour les abonnés Starter, Core et Pro.
  </Card>

  <Card title="Power">
    Un mode payant de milieu de gamme pour le travail nécessitant plus de capacité à un prix abordable.
  </Card>

  <Card title="Max">
    Un mode payant haut de gamme pour le travail le plus exigeant, avec les meilleurs modèles de pointe.
  </Card>
</CardGroup>

Le mode Free est disponible pour les abonnés Starter, Core et Pro. Starter inclut le mode Free avec ses limites existantes. Core et Pro incluent une allocation de mode Free, et Pro inclut une limite hebdomadaire plus élevée. Vous pouvez également choisir un mode Agent payant lorsque vous avez besoin de plus de capacité.

<Note>
  **Si vous atteignez une limite :** Starter inclut le mode Free avec ses limites existantes. Pour Core et Pro, l'allocation de mode Free se réinitialise toutes les cinq heures et comporte une limite hebdomadaire. Consultez **Paramètres → Utilisation du compte** pour voir où vous en êtes. Replit vous prévient lorsque vous approchez de la limite. Lorsque vous l'atteignez, passez à un mode payant pour continuer ou attendez la réinitialisation.
</Note>

## Questions fréquentes

<AccordionGroup>
  <Accordion title="Le mode Free est-il vraiment gratuit ? Replit est-il gratuit maintenant ?">
    Le mode Free est inclus avec les abonnements Starter, Core et Pro. Starter inclut le mode Free avec ses limites existantes. Core et Pro incluent une allocation de mode Free. Ce n'est pas un plan gratuit à part entière.
  </Accordion>

  <Accordion title="Est-ce la même chose qu'un mode Agent payant ?">
    Non. Le mode Free correspond à une utilisation d'Agent sans coût dans la limite de son allocation. Power et Max sont des modes payants pour le travail nécessitant plus de capacité.
  </Accordion>

  <Accordion title="Qu'est-il arrivé à Economy et Power ? Les modes ont-ils changé ?">
    Les modes payants ont été renommés. Economy s'appelle désormais Power, un mode de milieu de gamme avec des modèles puissants à un prix abordable. Le mode auparavant appelé Power s'appelle désormais Max, le mode haut de gamme. Les paramètres de mode existants sont conservés avec les nouveaux noms.
  </Accordion>

  <Accordion title="Quel mode est le plus performant ?">
    Max. Power est le mode payant de milieu de gamme pour plus de capacité à un prix abordable. Max est le mode payant haut de gamme pour le travail le plus exigeant.
  </Accordion>

  <Accordion title="Que se passe-t-il si ma demande nécessite une action payante ?">
    Agent explique que la demande nécessite un mode payant ou une capacité payante et demande votre accord avant de continuer. Vous pouvez approuver cette demande une seule fois ou continuer en mode Free.
  </Accordion>

  <Accordion title="Serai-je facturé automatiquement si Agent suggère une mise à niveau ?">
    Non. Une escalade payante nécessite votre confirmation avant que la demande payante ne commence.
  </Accordion>

  <Accordion title="Puis-je refuser l'option payante ?">
    Oui. Vous pouvez continuer à travailler en mode Free.
  </Accordion>

  <Accordion title="Que se passe-t-il après avoir approuvé une escalade payante ?">
    L'approbation s'applique uniquement à cette demande. Votre mode Agent revient ensuite au mode Free.
  </Accordion>

  <Accordion title="Pourquoi ai-je atteint une limite ? Quand se réinitialise-t-elle ?">
    Starter inclut le mode Free avec ses limites existantes. Pour Core et Pro, l'allocation de mode Free se réinitialise toutes les cinq heures et comporte une limite hebdomadaire. Consultez **Paramètres → Utilisation du compte** pour voir où vous en êtes. Lorsque vous atteignez la limite, passez à un mode payant pour continuer ou attendez la réinitialisation.
  </Accordion>

  <Accordion title="Le mode Free est-il disponible sur Enterprise ?">
    Pas au lancement. Les espaces de travail Enterprise bénéficieront d'une expérience Agent dédiée peu après. Votre administrateur aura les détails.
  </Accordion>
</AccordionGroup>

## En savoir plus sur le mode Free

<AccordionGroup>
  <Accordion title="Le mode Free est-il identique à Lite ?">
    Pour les utilisateurs Starter, l'expérience auparavant appelée Lite s'appelle désormais mode Free. Si vous utilisiez Lite pour un modèle à moindre coût, vous pouvez toujours sélectionner ce modèle manuellement dans Power lorsque vous désactivez le mode automatique.
  </Accordion>

  <Accordion title="Le mode Free peut-il créer une application complète ?">
    Oui. Vous pouvez créer et itérer sur des applications complètes en mode Free.
  </Accordion>

  <Accordion title="En quoi Free, Power et Max diffèrent-ils ?">
    Le mode Free correspond au travail Agent quotidien sans coût pour les abonnés Starter, Core et Pro. Starter inclut le mode Free avec ses limites existantes. Core et Pro incluent une allocation de mode Free. Power est le mode payant de milieu de gamme offrant plus de capacité à un prix abordable. Max est le mode payant haut de gamme pour le travail le plus exigeant.
  </Accordion>

  <Accordion title="Quand devrais-je quitter le mode Free ?">
    Restez en mode Free pour le travail quotidien. Changez de mode lorsque vous souhaitez de meilleurs résultats sur une tâche complexe ou avez besoin d'une capacité que le mode Free n'offre pas.
  </Accordion>

  <Accordion title="Le mode Free peut-il générer des vidéos ?">
    Non. La génération de vidéos est une capacité des modes payants, elle ne fait pas partie du mode Free.
  </Accordion>

  <Accordion title="Qu'est-ce que la nouvelle expérience Conversations ?">
    Le chat et la création restent liés. Vous pouvez explorer une idée, planifier un travail ou démarrer un projet depuis la même conversation.
  </Accordion>

  <Accordion title="Les chats autonomes font-ils partie d'une application publiée ?">
    Non. Une conversation reste séparée jusqu'à ce que vous créiez ou modifiiez un projet.
  </Accordion>

  <Accordion title="Le mode Free peut-il fonctionner sur un projet existant ?">
    Oui. Il prend en charge la maintenance courante et les modifications sur des projets existants.
  </Accordion>
</AccordionGroup>

**Prêt à l'essayer ?** Lorsque le mode Free sera lancé, ouvrez une conversation avec Agent et commencez.
