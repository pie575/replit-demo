사용자 지정 도메인을 연결해 여러분의 apps를 전문적인 website로 만들어 보세요.

Domain Purchasing을 사용하면 Replit 게시된 앱에 연결할 도메인을 검색하고 구매하고 연결하는 모든 과정을 플랫폼 안에서 처리할 수 있습니다. published app을 단 몇 분 만에 전문적인 웹사이트로 탈바꿈시킬 수 있습니다.

즉, `my-app.com` 같은 주소를 구매해 자동으로 여러분의 app을 가리키도록 할 수 있습니다.

<div id="features">
  ## 기능
</div>

Domain Purchasing은 앱에 전문적인 웹 주소를 부여하는 과정을 간소화합니다. 여러 서비스를 오갈 필요 없이 Replit 안에서 웹 주소 설정을 처음부터 끝까지 완료할 수 있습니다.

<Frame>
  <img src="/assets/mirror/replit-domains-8453291b634b.png" alt="구매한 도메인과 연결 상태를 보여주는 도메인 관리 인터페이스" width="3176" height="1556" data-path="images/deployments/custom-domains/replit-domains.png" />
</Frame>

주요 기능은 다음과 같습니다.

* **도메인 검색 및 사용 가능 여부 확인**: `.com`, `.ai` 등 인기 있는 도메인 extensions에서 사용 가능 여부를 확인합니다
* **원클릭 구매**: 계정의 기본 결제 수단으로 Replit에서 바로 도메인을 구매합니다
* **자동 구성**: DNS를 직접 설정하지 않아도 도메인이 즉시 Replit App으로 연결됩니다
* **WHOIS 개인정보 보호**: 공개 도메인 등록 정보에 개인정보가 노출되지 않으며, 모든 도메인 구매에 기본 포함됩니다
* **사용자 지정 DNS 레코드**: A, TXT, MX 레코드를 직접 추가해 이메일 제공업체 및 기타 서비스를 구성합니다
* **즉시 게시**: 구매 직후 사용자 지정 도메인으로 App에 접속할 수 있습니다
* **자동 갱신**: 도메인이 자동으로 갱신되어 apps가 중단 없이 게시된 상태를 유지합니다

<div id="usage">
  ## 사용량
</div>

<div id="purchasing-domains">
  ### 도메인 구매하기
</div>

1. 앱을 게시한 후 <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Publish icon" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publishing** 탭으로 이동합니다
2. **Domains** 탭을 선택합니다
3. **Buy a domain**을 선택해 검색을 시작합니다
4. 검색창에 원하는 도메인 이름을 입력합니다
5. 여러 확장자(extensions)별로 사용 가능한 옵션을 살펴봅니다
6. 원하는 도메인을 선택하고 구매를 완료합니다

도메인을 구매하면 해당 도메인이 자동으로 Replit 앱을 가리키도록 설정됩니다. 별도의 추가 설정 없이도 즉시 사용자 지정 도메인으로 앱에 접속할 수 있습니다.

도메인 구매 비용은 Replit account로 청구되며, 계정 balance에서 차감된 뒤 usage에 반영됩니다.

<div id="managing-purchased-domains">
  ### 구매한 도메인 관리
</div>

구매한 도메인은 게시된 앱과 매끄럽게 연동됩니다.

* **자동 갱신**: 도메인이 자동으로 갱신되어 앱이 계속 게시된 상태로 유지됩니다
* **통합 청구**: 도메인 비용이 다른 서비스와 함께 Replit 청구서에 표시됩니다
* **이전 지원**: 필요할 때 Replit 계정 간에 또는 외부 등록기관으로 도메인을 이전할 수 있습니다

<div id="custom-dns-records">
  ### 사용자 지정 DNS 레코드
</div>

Replit에서 구매한 도메인의 경우, 이메일 제공업체와 같은 추가 서비스를 구성하기 위해 사용자 지정 DNS 레코드를 추가할 수 있습니다. 지원되는 DNS 레코드 유형은 다음과 같습니다.

* **A 레코드**: 도메인 또는 서브도메인을 특정 IP 주소로 연결합니다
* **TXT 레코드**: 이메일 인증(SPF, DKIM, DMARC)과 같은 서비스를 위한 텍스트 기반 확인 레코드를 추가합니다
* **MX 레코드**: MX(Mail Exchange) 레코드는 이메일 서버에 해당 도메인의 이메일을 어디로 전달할지 알려줍니다. MX 레코드를 설정하면 `hello@yourdomain.com`과 같은 이메일 주소에 사용자 지정 도메인을 사용할 수 있습니다.

구매한 도메인의 DNS 레코드를 관리하려면 다음과 같이 하세요.

1. Publishing <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Publish icon" width="16" height="16" data-path="images/icons/deploy-icon.svg" />에서 **Domains** 탭으로 이동합니다
2. 구성하려는 도메인을 찾습니다
3. **Edit** <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="pencil icon" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> 아이콘을 선택합니다
4. **Add DNS Record**를 선택합니다
5. 서비스 제공업체가 요구하는 대로 레코드 유형, 이름, 값, TTL을 입력합니다

다음 짧은 영상에서는 도메인 DNS 레코드 관리 페이지를 찾는 과정을 안내합니다.

<div id="faq">
  ## FAQ
</div>

<AccordionGroup>
  <Accordion title="비용은 얼마인가요?">
    도메인 구매에는 두 가지 비용이 발생합니다.

    * **등록 비용**: 1년간 도메인을 소유하는 데 드는 초기 비용(`.ai` 도메인은 2년)
    * **갱신 가격**: 최초 등록 기간이 끝난 후 자동으로 청구되는 금액

    Replit은 도메인 구매에 별도의 수수료를 부과하지 않습니다. 도메인 등록 비용은 환불되지 않습니다.
  </Accordion>

  <Accordion title="도메인은 어떻게 갱신하나요?">
    Replit은 앱에 계속 접속할 수 있도록 도메인을 자동으로 갱신합니다. 자동 갱신을
    중단하려면 Publishing 도구에서 **Domains** 탭을 열고 도메인을 선택한 다음
    **Auto renewal** 토글을 끄세요. 같은 화면에서 도메인의 renewal date와
    갱신 가격도 확인할 수 있습니다.
  </Accordion>

  <Accordion title="Replit을 떠나고 싶으면 어떻게 하나요?">
    Replit Support에 문의하면 도메인을 다른 registrar로 이전할 수 있습니다. ICANN
    규정에 따라 구매 후 60일이 지나야 외부 registrar로 도메인을 이전할 수 있습니다.
  </Accordion>

  <Accordion title="Replit accounts 간에 도메인을 이전할 수 있나요?">
    네, Replit Support에 문의하면 Replit accounts 간에 도메인을 이전할 수 있습니다. 이
    경우에는 60일 대기 기간이 적용되지 않습니다.
  </Accordion>

  <Accordion title="Organization용으로 도메인을 구매할 수 있나요?">
    Replit Pro 및 Enterprise plans의 Domain Purchasing은 초기 베타 기간 이후에
    제공될 예정입니다.
  </Accordion>

  <Accordion title="도메인에 사용자 지정 DNS 레코드를 추가할 수 있나요?">
    네! Replit을 통해 구매한 도메인에는 사용자 지정 DNS 레코드를 추가할 수 있습니다. 현재 지원되는 레코드 유형은 다음과 같습니다.

    * **A 레코드**: 도메인 또는 서브도메인을 특정 IP 주소로 연결합니다
    * **TXT 레코드**: 이메일 인증 및 기타 서비스를 위한 텍스트 기반 검증 레코드를 추가합니다
    * **MX 레코드**: 도메인의 이메일을 처리할 메일 서버를 설정합니다

    이러한 레코드를 설정하려면 Publishing의 Domains tab으로 이동하세요. 이메일용 MX 레코드 설정에 대한 자세한 안내는 위의 [사용자 지정 DNS 레코드](#custom-dns-records) 섹션을 참고하세요.
  </Accordion>

  <Accordion title="어떤 도메인 extensions가 지원되나요?">
    일반적인 최상위 도메인(TLD)은 모두 지원합니다. 다만 특별한 지역 제한이나 기타
    제한이 있는 TLD는 지원하지 않습니다.
  </Accordion>

  <Accordion title="WHOIS 개인정보 보호란 무엇인가요?">
    도메인을 등록하면 연락처 정보(이름, 주소, 전화번호, 이메일)가 누구나 검색할 수 있는 WHOIS라는 공개 데이터베이스에 공개되는 것이 일반적입니다. WHOIS 개인정보 보호는 이러한 개인 정보를 registrar의 일반 정보로 대체하여, 법적 요건을 충족하면서도 정보를 비공개로 유지해 줍니다.

    Replit을 통해 구매한 모든 도메인에는 WHOIS 개인정보 보호가 추가 비용 없이 기본으로 포함됩니다. 따라서 스팸 발송자, 마케터를 비롯해 도메인 소유자 정보를 검색하려는 누구에게도 개인 정보가 노출되지 않습니다.
  </Accordion>

  <Accordion title="이미 도메인을 보유하고 있다면 어떻게 하나요?">
    기존 도메인을 Replit App에 연결하려면 [Custom Domains](/ko/features/publishing/custom-domains) 문서를 참고하세요.
  </Accordion>
</AccordionGroup>
