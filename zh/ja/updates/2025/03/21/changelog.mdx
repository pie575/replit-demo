<div id="section-3">
  ### 可视化编辑器
</div>

Agent 现在有了“眼睛”。点击、描述，即可完成。

<Frame>
  <img src="/assets/mirror/demo-assistant-feed47b3a11b.webp" alt="可视化编辑器" width="600" height="404" data-path="images/changelog/2025-03-21/demo-assistant.webp" />
</Frame>

我们推出了一项激动人心的新功能，让你可以在 JavaScript 应用项目中直接点击选择元素！

这让界面的构建和编辑变得前所未有地直观。如需了解更多信息，请前往博客 ([https://blog.replit.com/cartographer) 查看详细的操作指南。](https://blog.replit.com/cartographer）で詳細なウォークスルーをご覧ください。)

<div id="agent">
  ### Agent 时间线消息
</div>

现在，每当 Agent 设置项目 Blueprint 时，都会显示一个可视化指示器，方便你跟踪 Agent 的操作并了解开发过程。

我们还增强了分析功能，以便更好地追踪 Blueprint 的使用情况，为未来更智能的改进提供支持。
