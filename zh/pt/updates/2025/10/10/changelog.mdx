<div id="visibilidade-do-custo-de-uso-do-agent">
  ### Agent 使用成本一目了然
</div>

任务运行时即可实时查看 Agent 的使用成本。打开 Chat 顶部的抽屉面板，即可监控进行中任务的花费——对于耗时较长、自主性更高的任务尤为实用。

<div id="tecla-escape-para-o-modo-visual-selectedit">
  ### 使用 Escape 键退出 Visual Select/Edit 模式
</div>

按下 Escape 键即可退出 Visual Select 模式或返回创建模式。一个简单的快捷键，让你的工作节奏不被打断。

<div id="parada-mais-rpida-do-agent">
  ### Agent 停止更迅速
</div>

在工作区中停止或启动 Agent 时，Agent 响应更快，等待时间更短。

<div id="melhorias-na-importao-do-github">
  ### GitHub 导入功能改进
</div>

从 GitHub 导入时可实时查看进度，不再只显示笼统的提示信息，导入速度也更快。

<div id="verificao-de-vulnerabilidades-de-dependncias">
  ### 依赖项漏洞扫描
</div>

安全扫描器现已支持检测 Go、JavaScript、Python 和 Rust 的依赖项漏洞，更多语言即将支持。

<div id="experincia-de-logging-do-webview">
  ### Webview 日志体验
</div>

在同一处集中查看 webview 日志和控制台输出——与 Agent 所用的日志完全一致——让调试更轻松。

<div id="acesso-de-assentos-de-suporte-para-equipes">
  ### 团队支持席位访问
</div>

将 Replit 支持团队添加为不计入账单的 Guest 账户。需要协助时，你可以仅针对特定 App 授予受限访问权限，工作区的隐私始终由你掌控。
