Free Mode lets Starter, Core, and Pro subscribers use Agent at no extra cost. Starter includes Free Mode with its existing limits. Core and Pro include a Free Mode allowance. Open a conversation to explore, plan, create, or ask for help. If a request needs a paid mode or paid action, Replit makes that clear before anything billable starts.

## Why you'll like it

* Start with a conversation instead of a setup flow.
* Explore ideas and make progress before you decide whether you need more capability.
* Keep control when a request needs a paid action.
* See a clear **Free** label on work completed in Free Mode.

## How it works

1. New Starter, Core, and Pro sessions start in Free Mode.
2. Work that fits Free Mode continues with no paid-action prompt.
3. If a paid mode would handle a request better, Agent explains that and gives you a choice.
4. You can allow the paid mode for that request only, or ask Agent to continue in Free Mode.
5. After a one-time paid escalation, your mode returns to Free Mode.

## The three Agent modes

  <Card title="Max">
    A paid, top-tier mode for the most demanding work, with the best frontier models.
  </Card>

Free Mode is available to Starter, Core, and Pro subscribers. Starter includes Free Mode with its existing limits. Core and Pro include a Free Mode allowance, and Pro includes a larger weekly limit. You can also choose a paid Agent mode when you need more capability.

On Core and Pro, intelligent model routing is a paid alternative to Free Mode. Select **Auto** in Power or Max to let Replit choose a model for each task.

<Note>
  **If you hit a limit:** Starter includes Free Mode with its existing limits. For Core and Pro, the Free Mode allowance resets every five hours and has a weekly limit. Check **Settings → Usage** to see where you are. Replit gives you a heads-up as you approach the limit. When you reach it, switch to a paid mode to keep going or wait for the reset.
</Note>

## Common questions

<AccordionGroup>
  <Accordion title="Is Free Mode really free? Is Replit free now?">
    Free Mode is included with Starter, Core, and Pro subscriptions. Starter includes Free Mode with its existing limits. Core and Pro include a Free Mode allowance. It is not a free plan on its own.
  </Accordion>

  <Accordion title="Is this the same as a paid Agent mode?">
    No. Free Mode is no-cost Agent usage within its allowance. Power and Max are paid modes for work that needs more capability.
  </Accordion>

  <Accordion title="What happened to Economy and Power? Did the modes change?">
    The paid modes were renamed. Economy is now Power, a mid-tier mode with powerful models at an affordable price. The mode previously called Power is now Max, the top-tier mode. Existing mode settings carry over with the new names.
  </Accordion>

  <Accordion title="Which mode is the most capable?">
    Max. Power is the paid mid-tier mode for more capability at an affordable price. Max is the paid top-tier mode for the most demanding work.
  </Accordion>

  <Accordion title="What if my request needs a paid action?">
    Agent explains that the request needs a paid mode or paid capability and asks before it proceeds. You can approve that request once or continue in Free Mode.
  </Accordion>

  <Accordion title="Will I be charged automatically if Agent suggests an upgrade?">
    No. A paid escalation requires your confirmation before the paid request starts.
  </Accordion>

  <Accordion title="Can I decline the paid option?">
    Yes. You can keep working in Free Mode.
  </Accordion>

  <Accordion title="What happens after I approve a paid escalation?">
    The approval applies to that request only. Your Agent mode returns to Free Mode afterward.
  </Accordion>

  <Accordion title="Why did I reach a limit? When does it reset?">
    Starter includes Free Mode with its existing limits. For Core and Pro, the Free Mode allowance resets every five hours and has a weekly limit. Check **Settings → Usage** to see where you are. When you reach the limit, switch to a paid mode to keep going or wait for the reset.
  </Accordion>

  <Accordion title="Is Free Mode available on Enterprise?">
    No. Enterprise workspaces use one Auto mode instead. It selects the mode and an allowed model for each task. See [Enterprise model controls](/features/collaboration/enterprise-model-controls).
  </Accordion>
</AccordionGroup>

## More about Free Mode

<AccordionGroup>
  <Accordion title="Is Free Mode the same as Lite?">
    For Starter users, the experience previously called Lite is now Free Mode. If you used Lite for a lower-cost model, you can still select that model manually inside Power when you turn auto off.
  </Accordion>

  <Accordion title="Can Free Mode build a full app?">
    Yes. You can create and iterate on complete apps in Free Mode.
  </Accordion>

  <Accordion title="How do Free, Power, and Max differ?">
    Free Mode is no-cost everyday Agent work for Starter, Core, and Pro subscribers. Starter includes Free Mode with its existing limits. Core and Pro include a Free Mode allowance. Power is the paid mid-tier mode with more capability at an affordable price. Max is the paid top-tier mode for the most demanding work.
  </Accordion>

  <Accordion title="When should I switch from Free Mode?">
    Stay in Free Mode for everyday work. Switch when you want stronger results on a complex task or need a capability that Free Mode does not offer.
  </Accordion>

  <Accordion title="Can Free Mode generate videos?">
    No. Video generation is a paid-mode capability, not part of Free Mode.
  </Accordion>

  <Accordion title="What's the new Conversations experience?">
    Chat and creation stay together. You can research an idea, plan work, or start a project from the same conversation.
  </Accordion>

  <Accordion title="Do standalone chats become part of a published app?">
    No. A conversation stays separate until you create or change a project.
  </Accordion>

  <Accordion title="Can Free Mode work on an existing project?">
    Yes. It supports routine maintenance and edits on existing projects.
  </Accordion>
</AccordionGroup>

**Ready to try it?** When Free Mode launches, open a conversation with Agent and start.
