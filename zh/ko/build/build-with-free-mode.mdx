<div id="free-mode">
  ## 使用 Free Mode 构建第一个版本
</div>

使用 Free Mode，你无需使用积分，即可将创意变成可运行的第一个版本。{FreeModePlanAvailability}

开始构建前，请在提示词输入框下方的模式选择器中选择 **Free**。

<div id="section">
  ## 按明确的步骤构建
</div>

每次向 Replit 提出一个清晰的下一步，Free Mode 的效果最佳。先从能验证想法的版本开始，再逐步迭代完善。

1. **描述你想创建的内容。** 从预期成果、目标用户以及最需要的功能说起。
2. **构建核心流程。** 不要一次性请求所有可能的功能，而是每次只请求一个页面、一项功能或一次交互。
3. **预览并完善。** 测试 Replit 创建的内容，然后根据眼前的结果提出下一项改进。
4. **保持上下文。** 继续在同一段对话中交流，让 Replit 能根据你的决策和已创建的应用继续工作。

例如，你可以这样开始：“创建一个简单的跑步追踪器，用于记录跑步、查看每周总计并添加目标。”然后，逐步完善界面、添加数据，并在每一步进行测试。

<div id="section-2">
  ## 延长额度的使用时间
</div>

* 将较大的功能拆分为更小、更易测试的请求。
* 尤其是在优化现有界面时，请告诉 Replit 需要修改什么、保留什么。
* 在构建更复杂的功能之前，通过后续提问明确计划。
* 带着具体的下一步回到项目中，例如添加验证、优化移动端布局或集成表单。

<div id="section-3">
  ## 查看用量额度
</div>

打开 **设置** → **用量**，查看剩余的 Free Mode 额度及其重置时间。

<Frame caption="用量页面会显示剩余的 Free 额度。">
  <img src="/assets/mirror/free-mode-usage-sanitized-1b738ae092bb.jpg" alt="设置中的用量页面，显示 Free 额度面板" width="1538" height="1022" data-path="images/chat/free-mode-usage-sanitized.jpg" />
</Frame>

如果需要更高性能、想选择特定模型，或已用完 Free Mode 额度，请切换到 **Power Mode** 或 **Max Mode**。这些模式使用每月积分。
