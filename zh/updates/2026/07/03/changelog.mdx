<div id="the-redesigned-replit-desktop-app">
  ### 全新设计的 Replit Desktop App
</div>

全新设计的 Replit Desktop App 将完整的 Replit 体验带到你的电脑上。除了与网页版相同的构建体验外，还提供原生功能：可同时处理多个 App，随时了解 Agent 何时需要你的协助或已完成任务，并且无需在不同 App 之间切换即可预览已打开的 App。

<div id="sell-in-your-app-with-whop">
  ### 通过 Whop 在 App 中销售
</div>

现在，只需让 Agent 帮忙，即可通过 Whop 为你的 App 添加支付功能。Agent 会为你创建并连接 Whop Account，并在你的 项目 中构建结账流程，无需进行外部设置，也无需粘贴 API 密钥。Whop 是快速开始销售数字产品、会员资格和订阅服务的最佳方式。

详细了解 [Whop Payments](/zh/features/monetization/whop-payments)。

<div id="downgrade-from-pro-to-core-in-one-step">
  ### 一步从 Pro 降级至 Core
</div>

现在，你可以直接从 Replit Pro 降级至 Replit Core，无需先取消订阅。此前，唯一的降级方式是取消订阅，这会先将你降至免费套餐，然后才能重新订阅。如果你开始取消订阅，Replit 现在会提供降级至 Core 的选项，让你继续保留付费套餐，并确保已发布的 App 持续运行。

详细了解[更改套餐](/zh/billing/plans/changing-your-plan)。
