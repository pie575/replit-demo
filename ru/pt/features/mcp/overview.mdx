Replit Agent подключается к внешним инструментам и источникам данных через [Model Context Protocol (MCP)](https://modelcontextprotocol.io) — открытый стандарт для интеграций с ИИ. Каждый сервер из списка ниже устанавливается в один клик, после чего Agent автоматически загружает его инструменты и использует их по мере необходимости.

Разобраться в концепции поможет статья [Model Context Protocol](/ru/pt/learn/model-context-protocol). Практическое руководство — [Подключение через MCP](/ru/pt/build/connect-via-mcp). Чтобы подключить сервер, которого нет в этом списке, см. [Добавление пользовательского MCP-сервера](/ru/pt/build/connect-via-mcp#add-a-custom-mcp-server).

<Info>
  Выберите **Add to Replit**, чтобы установить любой сервер. Вам будет предложено авторизовать подключение в редакторе проекта.
</Info>

<div id="protees-de-segurana">
  ## Меры безопасности
</div>

Весь трафик MCP проходит через сканер безопасности Replit. Сканер анализирует определения инструментов и запланированные запуски, блокируя подозрительные или небезопасные инструменты до их выполнения. Если инструмент будет отклонён, Agent сообщит вам об этом.

<div id="opes-de-autenticao">
  ## Варианты аутентификации
</div>

* **Динамическая регистрация клиента OAuth** — если сервер поддерживает OAuth DCR, Replit автоматически распознает и зарегистрирует клиента за вас. Большинство серверов из готового списка используют именно этот способ.
* **Пользовательские заголовки** — задайте одну или несколько пар «имя — значение» заголовка (например, `X-API-Key`). Replit добавляет эти заголовки в каждый MCP-запрос, чтобы ваш сервер мог проверить, кто к нему обращается. Используйте этот вариант при добавлении пользовательского сервера, который аутентифицируется с помощью статических токенов.

<div id="compartilhe-seu-prprio-link-de-instalao">
  ## Поделитесь собственной ссылкой для установки
</div>

Ссылки для установки добавляют ваш MCP-сервер в Replit одним кликом. Сгенерируйте такую ссылку с помощью формы в разделе [Подключение через MCP](/ru/pt/build/connect-via-mcp#share-an-install-link) или создайте её сами: закодируйте JSON-полезную нагрузку в base64 и добавьте к `https://replit.com/integrations?mcp=`.

```json theme={null}
{
  "displayName": "My MCP Server",
  "baseUrl": "https://example.com/mcp",
  "headers": [{ "key": "Authorization", "value": "Bearer your-token" }]
}
```

* **displayName** — имя, отображаемое при установке
* **baseUrl** — HTTPS-эндпоинт вашего MCP-сервера
* **headers** — необязательные заголовки аутентификации
