<div id="recursos">
  ## Возможности
</div>

Создавайте приложения с актуальной информацией с помощью функции Web Search в Agent. Она избавляет от необходимости вручную искать и собирать данные. Создаёте ли вы дашборд с финансовыми данными или сайт с новейшими стартапами, Web Search помогает вашему App отражать актуальную ситуацию.

Agent может выполнять следующие действия с помощью Web Search:

* **Поиск**: находить актуальную информацию, новейшую документацию и данные в реальном времени в интернете
* **Извлечение контента**: получать подробную информацию с указанных сайтов и URL-адресов
* **Цитирование источников**: показывать, откуда именно Agent получил информацию, чтобы вы могли проверять источники и ссылаться на них

<div id="uso">
  ## Использование
</div>

Web Search интегрирован в Agent — ничего активировать не нужно. Опишите, что вы хотите создать, и Agent автоматически определит, когда нужно искать в интернете актуальную информацию. Включите в prompt ключевые слова, например «найди», «исследуй» или «используй Web Search», чтобы явно указать Agent выполнить поиск.

<div id="citaes-de-fontes">
  ### Цитирование источников
</div>

Когда Agent использует Web Search, он указывает **цитирование источников**, которое точно показывает, откуда взята информация. Используйте это цитирование, чтобы:

* **Проверять информацию**: Оценивайте надежность и точность источников
* **Узнавать больше**: Переходите к первоисточникам, чтобы получить больше контекста
* **Ссылаться на источники**: Указывайте источники в своих приложениях
* **Отслеживать ход исследования**: Понимайте, какая информация легла в основу работы Agent

<div id="busca-de-contedo">
  ### Извлечение контента
</div>

Agent может извлекать подробную информацию с определённых сайтов, чтобы собрать исчерпывающие сведения для вашего проекта. Это позволяет Agent:

* Читать страницы целиком, чтобы извлекать нужные сведения
* Обрабатывать документацию и справочные материалы
* Собирать конкретные данные из надёжных источников
* Интегрировать структурированную информацию в ваше приложение
