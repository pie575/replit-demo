## 플랫폼

### 배포 시 보안 스캔

새로운 게시 전 보안 스캔으로 애플리케이션을 보호하세요. 앱을 배포하기 전에 스캔을 켜거나 끄어 악성 파일과 보안 취약점을 감지하세요. 잠재적 위협을 사전에 스캔하는 높은 신뢰도의 보안 규칙으로 코드를 안전하게 유지하세요.

### Agent 플레이그라운드 테스트 개선

향상된 플레이그라운드 기능으로 AI 에이전트와 자동화를 더 효과적으로 테스트하세요. 이제 Slack 및 Telegram 에이전트 테스트 시 도구 호출의 시각적 렌더링이 포함되며, 시간 기반 워크플로 자동화에 대한 실시간 테스트 결과를 확인할 수 있습니다. 배포 전에 에이전트의 성능을 더 명확하게 파악하세요.

## 팀 및 엔터프라이즈

### 엔터프라이즈를 위한 보안 스캔 적용

엔터프라이즈 관리자는 이제 모든 팀 배포에 보안 스캔을 적용할 수 있습니다. 게시된 모든 애플리케이션에 보안 스캔을 요구하여 조직 전반에 일관된 보안 기준을 유지하고 팀의 보안 상태를 완전히 제어하세요.
