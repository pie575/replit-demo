# Espaços de Trabalho Pessoais e de Equipe

> Entenda a diferença entre workspaces pessoais e de equipe, crie um workspace de equipe e convide membros para construir juntos.

## Workspaces pessoais vs. de equipe

Um **workspace** é a estrutura que reúne seus aplicativos, membros, configurações e faturamento. O Replit tem dois tipos:

* Workspace pessoal
* Workspace de equipe

Abaixo está a diferença entre os workspaces Pessoal e de Equipe:

|                              | Workspace pessoal                                 | Workspace de equipe                                    |
| ---------------------------- | ------------------------------------------------- | ------------------------------------------------------ |
| **Funções**                  | Admin, convidados no nível de projeto             | Admin, Membros, convidados no nível de projeto         |
| **Modelo de acesso**         | Você convida convidados para projetos individuais | Os membros têm acesso a todos os projetos do workspace |
| **Faturamento**              | Sua conta                                         | Créditos agrupados da conta do admin                   |
| **Gerenciamento de membros** | Por projeto (Join Links)                          | Centralizado nas Configurações do workspace            |

O **workspace pessoal** é melhor quando você está trabalhando sozinho ou compartilhando projetos individuais com outras pessoas. Você é o único admin, e outras pessoas só podem acessar projetos específicos para os quais você as convida como convidados no nível de projeto.

O **workspace de equipe** é melhor quando você está construindo com um grupo regular — uma equipe de startup, uma turma ou um projeto de cliente com vários colaboradores. Os membros têm acesso a todos os projetos do workspace, então você não precisa convidá-los um por um para cada projeto. Os membros são gerenciados centralmente em **Configurações**.

### Quando convidar para o seu workspace vs. para um projeto

| Cenário                                                  | O que fazer                                           |
| -------------------------------------------------------- | ----------------------------------------------------- |
| Colaborador contínuo que precisa de acesso a tudo        | Convidar para o workspace                             |
| Contratado ou convidado que precisa apenas de um projeto | [Convidar para o projeto](/pt/build/invite-teammates) |
| Novo membro da equipe entrando na sua empresa            | Convidar para o workspace                             |
| Amigo ajudando você a depurar um aplicativo específico   | [Convidar para o projeto](/pt/build/invite-teammates) |

## Criar um workspace de equipe

<Frame>
  <img src="https://mintcdn.com/replit/7ERBfdpI-Q6cFy9l/images/workspace/create-team-workspace.png?fit=max&auto=format&n=7ERBfdpI-Q6cFy9l&q=85&s=b84bb952bbe5f9e55bf8e51cac7d758a" alt="Formulário de criação de novo workspace com um nome genérico de workspace e um campo em branco para convidar membros da equipe" width="784" height="300" data-path="images/workspace/create-team-workspace.png" />
</Frame>

<Steps>
  <Step title="Abra o seletor de workspace">
    Na página inicial, clique no nome do seu workspace no canto superior esquerdo.
  </Step>

  <Step title="Crie um novo workspace">
    Selecione **Create workspace** e escolha um nome para o seu workspace de equipe.
  </Step>

  <Step title="Convide membros">
    Digite um ou mais endereços de e-mail (separados por vírgula) no campo de convite. Os convidados recebem um convite e ganham acesso a todos os projetos do workspace depois de aceitar.
  </Step>
</Steps>

## Gerenciando membros

Se você não convidou membros durante a configuração, ou precisa adicionar mais depois, vá para **Configurações > Colaboradores do workspace** no seu workspace de equipe e convide membros por e-mail ou nome de usuário do Replit.

<Frame>
  <img src="https://mintcdn.com/replit/7ERBfdpI-Q6cFy9l/images/workspace/invite-workspace-members.jpg?fit=max&auto=format&n=7ERBfdpI-Q6cFy9l&q=85&s=b9e06b5b4a23458573fc625844071676" alt="Diálogo de convite de usuário com um campo em branco para inserir endereços de e-mail" width="510" height="244" data-path="images/workspace/invite-workspace-members.jpg" />
</Frame>

Na página **Configurações**, você também pode:

* **Remover membros** para revogar o acesso deles a todos os projetos do workspace
* **Transferir projetos** de workspaces pessoais para o workspace de equipe — consulte [Transferir aplicativo para equipes](/pt/teams/identity-and-access-management/transfer-app-to-teams)

  <Warning>
    A transferência de projetos entre workspaces está temporariamente desativada. Você não pode iniciar uma nova transferência no momento.
  </Warning>

Para gerenciamento avançado de identidade, acesso baseado em funções e permissões de grupo, consulte [Pro e Enterprise](/pt/category/teams).
