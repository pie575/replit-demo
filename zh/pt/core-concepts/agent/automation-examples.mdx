Replit Agent 能够构建 full-stack 自动化流程：连接你的各类工具、响应事件，并按计划定时运行——这一切只需一个 prompt。结合[连接器](/zh/replitai/integrations)和[部署](/zh/category/replit-deployments)，你可以用真正归自己所有、由自己掌控的应用，取代脆弱的胶水代码和昂贵的无代码平台。

<div id="o-que-voc-pode-automatizar">
  ## 您可以实现哪些自动化
</div>

Replit 自动化不只是简单的触发器。由于 Agent 能够使用完整代码构建真正的应用，您可以：

* **响应事件**，对来自任何支持 webhook 的服务的事件作出响应 (Linear、Jira、GitHub、Confluence、Discord 等)
* **按计划运行**，使用基于 cron 的自动化 (每日摘要、每周报告、定期同步)
* **在单个自动化中串联多个服务** (Jira 事件触发通过 Twilio 发送 SMS，Google Drive 文件创建 Notion 页面)
* **为任何工作流添加 AI 处理** — 使用内置 AI 集成总结、分类、提取或生成内容
* **部署后无需操心** — 自动化将在 Replit 的云基础设施上全天候运行，无需管理服务器

与传统自动化平台的主要区别在于：您可以获得完整的源代码。您可以自定义逻辑、添加错误处理、扩展功能，并像管理其他软件项目一样对自动化进行版本控制。

<div id="como-as-automaes-funcionam">
  ## 自动化的工作原理
</div>

大多数自动化都遵循一个简单的模式：

1. **触发** — 某个事件发生 (webhook、cron 定时任务或 API 轮询)
2. **处理** — 你的应用接收事件、执行逻辑，并可选择调用 AI 进行摘要或分析
3. **执行** — 你的应用调用另一个服务来发送消息、创建记录或更新数据

Agent 会负责整个构建过程：配置 webhook 端点、设置 cron 定时任务、通过[连接器](/zh/replitai/integrations)完成与各服务的身份验证，以及部署你的自动化。

<Tip>
  要开始使用，请在 Replit 首页选择 **Agents &amp; Automations**，然后描述你想要自动化的内容。详细步骤请参阅[入门指南](/zh/pt/core-concepts/agent/agents-and-automations)。
</Tip>

<div id="construindo-suas-prprias-automaes">
  ## 构建你自己的自动化
</div>

这些示例只是起点。由于 Agent 构建的是真实可用的应用，你可以组合任意服务并添加自定义逻辑：

* **多步骤工作流**：串联三个或更多服务 (例如：Jira 创建 issue → AI 生成摘要 → 在 Slack 发送通知 → 记录到 Google Sheets)
* **条件逻辑**：添加筛选条件 (例如：仅在出现高优先级 issue 时通知，仅记录特定项目的任务)
* **AI 增强处理**：为任意自动化添加摘要、分类、情感分析或内容生成能力
* **自定义调度**：让自动化每小时运行、每天在指定时间运行、每周运行，或按任意 cron 计划运行

<AiPrompt>
  当 Jira 的 &quot;Backend&quot; 项目中创建了高优先级 issue 时，用 AI 生成摘要，向 Slack 的 #engenharia 频道发送通知，并记录到 Google Sheets
</AiPrompt>
