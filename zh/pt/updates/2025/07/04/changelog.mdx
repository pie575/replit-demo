<div id="pesquisa-na-web-para-o-agent">
  ### Agent 网页搜索
</div>

<Frame>
  <img src="/assets/mirror/web-search-6c28195531d4.jpg" alt="Agent 界面显示网页搜索结果及应用开发相关来源引用" width="1920" height="1080" data-path="images/replitai/web-search.jpg" />
</Frame>

Agent 现在可通过[网页搜索](/zh/pt/core-concepts/agent/web-search)搜索互联网并获取最新信息。利用最新文档、当前市场数据和来自互联网的准确信息创建应用。不再受限于既有知识——你的应用现在可使用最新可用信息。

<div id="instrues-personalizadas-do-agent">
  ### Agent 自定义指令
</div>

<Frame>
  <img src="/assets/mirror/replitmd-65360844a148.jpg" alt="显示项目自定义选项的 replit.md 文件" width="1920" height="1080" data-path="images/replitai/replitmd.jpg" />
</Frame>

使用 [replit.md](/zh/pt/core-concepts/agent/replit-dot-md) 自定义你的 Agent 使用体验。这个特殊文件可让你定义编码风格、项目偏好和上下文。Agent 会根据经验证的最佳实践自动创建此文件，你也可以对其进行自定义，使其更符合自己的工作流程。

  ### 基于工作量的计费
</div>

<Frame>
  <img src="/assets/mirror/effort-based-billing-d971548c7c39.png" alt="基于工作量的计费界面，显示根据 Agent 工作量动态调整的价格" width="2048" height="1424" data-path="images/changelog/2025-07-04/effort-based-billing.png" />
</Frame>

体验更智能的检查点定价：[基于工作量的计费](/zh/pt/billing/ai-billing)。根据 Agent 实际工作量动态定价，每次运行只会创建一个检查点，而非多个检查点。
