Shell 就像常见的终端一样，可用于管理文件、安装软件包和运行脚本，帮助你处理项目中的各项工作。例如，你可以浏览项目文件，或在项目已配置数据库连接时使用 `psql`。

<Tip>
  为了更好地管理工作流，建议使用 **Run** 按钮来运行应用，而不是通过 Shell 运行。由 **Run** 按钮启动的工作流会将输出发送到 Console 工具，便于你以结构化的方式查看日志。
</Tip>

<div id="features">
  ## 功能
</div>

Shell 提供以下功能：

* **运行多个 Shell**：打开多个 Shell 实例，同时处理不同 task
* **搜索文本**：在 Shell 输出中查找特定文本

<div id="confirm-shell-access">
  ### 确认 Shell 访问权限
</div>

要确认 Shell 已就绪并查看当前工作区，请运行：

```sh theme={null}
pwd
```

Shell 会显示当前工作区的路径。

<Frame caption="pwd 命令会显示当前工作区路径，然后返回 Shell 提示符。">
  <img src="/assets/mirror/shell-pwd-output-2d31a0e0466b.jpg" alt="Shell 标签页显示 pwd 命令、工作区路径输出以及返回的提示符" width="1280" height="246" data-path="images/workspace/shell-pwd-output.jpg" />
</Frame>

对于包含数据库的项目，选择 **工具** → **Database**，然后打开
**开发数据库**页面。该页面提供连接控件。请妥善保管连接信息；不要将其复制到文档、屏幕截图、
日志、源文件或共享消息中。

<div id="text-search">
  ### 文本搜索
</div>

以下步骤介绍如何打开并使用文本搜索工具：

1. 点击 Shell 标签页右上角的 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="magnifying glass icon" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 放大镜图标，打开搜索对话框。
2. 输入搜索词，然后点击 **Next** 逐个查看匹配项。
3. 点击 **Previous** 可返回上一个匹配项。
4. 点击 **Exit** 或对话框以外的区域，即可退出文本搜索。

<div id="multiple-shells">
  ### 多个 Shell
</div>

创建新的 Shell：

1. 在 Shell 面板标题栏中选择 Shell 实例菜单。
2. 选择 **New Shell**。

<Frame>
  <img src="/assets/mirror/shell-new-94a280c1230f.png" alt="显示当前工作区和 New Shell 选项的 Shell 实例菜单" width="1280" height="224" data-path="images/workspace/shell-new.png" />
</Frame>

通过同一菜单可在多个 Shell 之间切换。Replit 会以最后执行的命令为每个 Shell 命名，便于你区分。

<Warning>
  当你打开多个 Shell 时，Replit 会自动关闭闲置的 Shell 实例。闲置的 Shell 是指未被选中且没有运行任何用户进程的实例。
</Warning>
