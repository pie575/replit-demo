Les applications web constituent le type de sortie par défaut de Replit. Décrivez votre idée à Agent : il créera une application web full-stack, sauf si vous indiquez un autre type d’artefact.

<div id="section">
  ## Introduction
</div>

Vous pouvez créer une application Web de deux façons :

* **Saisir un prompt** : décrivez ce que vous souhaitez créer sur la page d’accueil de Replit. Agent créera automatiquement votre application Web.
* **Sélectionner une option dans le menu déroulant** : ouvrez le menu déroulant des types d’applications sur la page d’accueil, sélectionnez **Application Web**, puis décrivez votre idée.

<div id="section-2">
  ## Fonctionnalités principales
</div>

* **Full stack par défaut :** toutes les applications web incluent un frontend et un backend. Agent configure les routes API, les bases de données et la logique côté serveur selon les besoins de votre application.
* **Design réactif :** les applications s&#39;adaptent automatiquement aux différentes tailles d&#39;écran.
* **Déploiement instantané :** publiez votre application en un clic. Replit gère l&#39;hébergement, le SSL et l&#39;infrastructure.
* **Infrastructure partagée :** lorsque votre projet comporte plusieurs artefacts, comme des applications mobiles ou des tableaux de bord de données, ils partagent tous le même backend, les mêmes bases de données et les mêmes services.

<div id="section-3">
  ## Cas d’utilisation
</div>

* **Produits SaaS** : créez des outils, des tableaux de bord et des plateformes destinés à vos clients.
* **Outils internes** : créez des panneaux d’administration, des CRM et des applications de gestion des flux de travail pour votre équipe.
* **Pages de destination** : lancez des sites marketing avec des formulaires, des animations et du contenu dynamique.
* **Places de marché et annuaires** : créez des sites d’annonces, des tableaux d’offres d’emploi et des plateformes communautaires.
