### カスタムプロンプト

<Note>
  **更新（2025年12月）：** Assistant は廃止されました。素早いピンポイント編集には、[Agent の Lite モード](/core-concepts/agent/agent-modes)をご利用ください。
</Note>

カスタムプロンプトを使用すると、Assistant のインタラクション方法を完全にコントロールできます。特定のコーディング標準の設定から Assistant のデフォルトのカスタマイズまで、カスタムプロンプトが対応します。

例えば、次のようなものを追加できます:

* 特定のコーディングスタイルやフレームワーク
* 特定の問題解決テクニック
* パッケージ管理の好み

例えば、次のように追加するかもしれません:

```
use pnpm for package management
use motion/react instead of framer-motion
always use claude-3-5-sonnet-20241022 as your model
```

### Replit App のテーマ設定

プロジェクトが大幅にグレードアップしました。コード不要 💅

今後、Agent に React Replit App の構築を依頼し、ノーコードのテーマ設定ツールで簡単にカスタマイズできます:

* プライマリカラーを変更する
* ライトモードとダークモードを切り替える
* アプリの美観を自分らしくパーソナライズする

### Workflows

Workflow は、好きなコマンドを実行できる、簡単に設定できる「実行」ボタンです。

Replit App 内で実行できる、再利用可能でカスタマイズ可能なステップのシーケンスです。**`python main.py`** の実行のように単純なものから、複数ステップの手順の実行のように複雑なものまで対応できます。

使用例:

* 複数のサービスを並行して実行する（例：フロントエンド + バックエンド）
* ファイルやコマンドを順番に実行する（例：リンターの実行 → テストの実行、コンパイル → コードの実行）

[ワークフローの作成](https:/.replit.com/replit-workspace/workflows#creating-workflows)を始めるには、ツールサイドバーメニューを使って Workflows ペインに移動するか、**`Command + K`** を使って Workflows ペインを検索してください。

[こちら](https:/.replit.com/replit-workspace/workflows)でご確認ください。
