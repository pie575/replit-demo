<div id="azure-marketplace-integration">
  ### Интеграция с Azure Marketplace
</div>

Replit теперь доступен на Azure Marketplace! У многих организаций уже есть выделенные бюджеты на Azure, и эта интеграция позволяет напрямую направлять эти средства на подписку и использование Replit.

В дополнение к интеграции с GCP Marketplace, представленной в сентябре, это упрощает корпоративным командам внедрение Replit в рамках существующих процессов закупки облачных сервисов и выделенных бюджетов.

[Открыть в Azure Marketplace](https://marketplace.microsoft.com/en-us/product/saas/replit.replit?tab=Overview)

<div id="gitlab-and-bitbucket-support">
  ### Поддержка GitLab и Bitbucket
</div>

Теперь Replit поддерживает репозитории GitLab и Bitbucket наряду с GitHub, предоставляя больше гибкости в выборе места хранения кода. Теперь вы можете импортировать проекты из GitLab и Bitbucket напрямую в Replit, а также пользоваться улучшенной поддержкой Git на всех совместимых платформах.

Улучшенная интеграция с Git включает:

* **Поддержка нескольких платформ**: импорт и работа с репозиториями GitHub, GitLab и Bitbucket
* **Улучшенные операции Git**: более быстрые и надёжные команды Git во всём рабочем пространстве
* **Улучшенное управление репозиториями**: оптимизированные процессы клонирования, отправки и получения изменений для любого поддерживаемого провайдера Git

Подробнее см. в разделах [импорт проектов](/ru/references/workspace/import) и [использование Git в Replit](/ru/references/version-control/git-interface).
