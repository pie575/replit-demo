<div id="aprimore-seu-remix">
  ## Améliorez votre Remix
</div>

Maintenant que votre application est fonctionnelle, utilisez Agent pour la modifier et l&#39;enrichir. Les sections suivantes présentent des exemples concrets pour améliorer votre Remix.

<div id="adicione-um-recurso-usando-o-agent">
  ### Ajoutez une fonctionnalité avec Agent
</div>

Utilisez Agent pour ajouter des fonctionnalités complexes à votre Remix :

<Steps>
  <Step title="Créez un prompt">
    Accédez à l’onglet **Agent**.

    Saisissez le prompt suivant dans la zone de texte :

    <AiPrompt>
      Ajoute un mode tutoriel qui permet d’apprendre à jouer des morceaux simples. Lorsque le mode tutoriel est actif, mets en évidence la prochaine touche à jouer, attends que j’appuie sur la bonne touche avant de continuer et affiche le nom du morceau en haut. Inclus un bouton pour démarrer le tutoriel et précharge au moins deux morceaux simples, comme « Mary Had a Little Lamb » ou « Twinkle Twinkle Little Star ».
    </AiPrompt>

    Après avoir envoyé le prompt, Agent peut s’arrêter et demander des précisions ou une confirmation. Répondez dans la zone de texte.
  </Step>

  <Step title="Testez la fonctionnalité">
    Accédez à l’onglet **Aperçu** pour voir les mises à jour apportées par Agent au piano.

    Essayez de démarrer le mode tutoriel et suivez les touches mises en évidence.

    <Frame>
      <video autoPlay muted loop playsInline src="/assets/mirror/quickstart-remix-piano-play-3be628756ae7.mp4" />
    </Frame>

    Comme le prompt initial n’incluait pas de détails précis sur la conception visuelle, le résultat peut ne pas correspondre exactement à vos attentes.
  </Step>

  <Step title="Affinez la fonctionnalité">
    Si la fonctionnalité ne correspond pas à vos attentes, poursuivez la conversation en saisissant un prompt de suivi
    dans la zone de texte d’**Agent**. Par exemple :

    <AiPrompt>
      Fais briller la touche mise en évidence avec une animation pulsante et ajoute un indicateur de progression montrant où j’en suis dans le morceau.
    </AiPrompt>

    Pour annuler ces modifications, sélectionnez **Revenir à cet état** dans le Checkpoint créé immédiatement
    après le lancement du plan de modification dans l’onglet **Agent**.

    En savoir plus sur les [Checkpoints et retours en arrière](/fr/pt/core-concepts/agent/checkpoints-and-rollbacks).
  </Step>
</Steps>

<div id="adicione-um-recurso-usando-o-modo-lite">
  ### Ajoutez une fonctionnalité avec le mode Lite
</div>

Suivez ces étapes pour ajouter rapidement une amélioration à votre Remix avec le [mode Lite](/fr/pt/core-concepts/agent/agent-modes) :

<Steps>
  <Step title="Créez un prompt">
    Passez au [mode Lite](/fr/pt/core-concepts/agent/agent-modes) et saisissez le prompt suivant :

    <AiPrompt>
      Ajoutez des boutons d’enregistrement et de lecture pour enregistrer et rejouer des performances au piano.
    </AiPrompt>

    Après avoir envoyé le prompt, Agent décrit les modifications qu’il prévoit d’apporter et vous permet de les examiner dans le code avant de continuer.
    Sélectionnez **Prévisualiser les modifications du code** pour comparer le code actuel aux mises à jour.
  </Step>

  <Step title="Testez la fonctionnalité">
    Sélectionnez **Tout appliquer** et validez les confirmations suivantes pour continuer.

    Accédez à l’onglet **Aperçu** pour vérifier le résultat. Vous devriez maintenant voir des boutons d’enregistrement et de lecture qui vous permettent d’enregistrer et de rejouer ce que vous jouez.

    Pour annuler ces modifications, utilisez la fonctionnalité Annuler dans l’onglet **Agent**.
  </Step>
</Steps>

<div id="continue-sua-jornada">
  ## Poursuivez votre parcours
</div>

Maintenant que vous avez terminé ce tutoriel, voici quelques pistes pour aller plus loin avec le remix :

* **Explorez d’autres remixes** : Parcourez la [communauté](https://replit.com/community/all) pour trouver des applications à remixer et vous en inspirer
* **Créez à partir de zéro** : Essayez de [créer votre propre application](/fr/pt/getting-started/quickstarts/ask-ai) avec Agent pour comparer l’expérience
* **Publiez pour le remix** : Partagez votre version améliorée afin que d’autres puissent s’appuyer sur votre travail.
