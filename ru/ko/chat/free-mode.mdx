Free Mode позволяет общаться, создавать приложения и выполнять сборки без использования кредитов Power Mode или Max Mode.

<Note>
  Free Mode всегда использует интеллектуальную маршрутизацию моделей: Replit выбирает модель, подходящую для вашего запроса. В Free Mode нельзя выбрать конкретную модель.
</Note>

Routine не выполняются в Free Mode. Они выполняются в Power Mode или Max Mode и требуют бюджета для каждого запуска. Подробнее см. в разделе [Routine](/ru/ko/chat/routines).

<div id="section">
  ## Как эффективнее использовать лимит
</div>

Free Mode помогает поддерживать темп текущей работы. Используйте его в следующих случаях:

* Изучайте и проверяйте идеи, прежде чем приступать к более крупной сборке.
* Начинайте новый проект, впервые пробуйте новую функцию или вносите небольшие изменения.
* Задавайте вопросы, составляйте планы и дорабатывайте работу с помощью последующих сообщений.
* Продолжайте выполнять повседневные задачи без использования кредитов, пока не исчерпаете лимит.

Чтобы начать, откройте переключатель режимов под полем ввода промпта и убедитесь, что выбран режим **Free**. Затем отправьте Replit чётко сформулированный запрос. Укажите желаемый результат, поделитесь важным контекстом и уточняйте его с помощью уточняющих вопросов.

<div id="section-2">
  ## Когда стоит использовать другие режимы
</div>

Лимиты Free Mode зависят от вашего тарифа. Откройте **Settings** → **Usage**, чтобы узнать текущий лимит и дату его обновления.

<Frame caption="На странице Usage отображаются оставшийся лимит Free и дата обновления.">
  <img src="/assets/mirror/free-mode-usage-sanitized-1b738ae092bb.jpg" alt="Страница Usage в Settings с панелью лимита Free" width="1538" height="1022" data-path="images/chat/free-mode-usage-sanitized.jpg" />
</Frame>

На тарифах Core и Pro переключайтесь на **Power Mode** или **Max Mode**, если вам нужна более высокая производительность, вы хотите выбрать конкретную модель или достигли лимита Free Mode. В этих режимах расходуются ежемесячные кредиты. Разработчикам на тарифе Starter необходимо перейти на другой тариф, прежде чем использовать Power Mode или Max Mode.

<Tip>
  Если ваш тариф включает Power Mode и Max Mode, начинайте с Free Mode и
  переключайтесь, только когда для задачи потребуется более высокая производительность.
  Replit предупредит вас, прежде чем запрос будет переключён в режим,
  за использование которого взимается плата.
</Tip>

<div id="section-3">
  ## Выберите режим для своей задачи
</div>

| Если вы хотите...                                                                 | Начните с режима |
| --------------------------------------------------------------------------------- | ---------------- |
| изучать, задавать вопросы, планировать или начинать сборку                        | Free Mode        |
| добиться оптимального баланса скорости и производительности для большинства задач | Power Mode       |
| выполнять сложные или трудоёмкие задачи                                           | Max Mode         |

Power Mode заменяет Economy Mode при той же стоимости и обеспечивает сопоставимую или более высокую производительность. На тарифах Core и Pro можно выбрать модель, доступную в Power Mode или Max Mode.
