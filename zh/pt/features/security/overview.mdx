从 Replit 部署后，你的项目可能会接收真实流量。Replit 的安全工具可帮助你发现漏洞、借助 Agent 修复已确认的问题，并留存可用于审计的证据。

<div id="por-que-a-segurana-importante">
  ## 安全为何重要
</div>

* 已部署的项目可通过公共互联网访问，其中包括公开的路由和 API。
* 现代项目依赖大量包，部署之后仍可能出现新的 CVE。
* AI 生成的代码同样需要安全审查，尤其是在身份验证、数据库查询、密钥和数据处理方面。
* 合规项目通常要求提供依赖清单、漏洞跟踪和修复方面的证据。

<div id="por-onde-comear">
  ## 从哪里开始
</div>

* 正在安装包？[Package Firewall](/zh/pt/features/security/package-firewall) 会在安装时拦截恶意依赖项，且默认启用。
* 只针对单个 项目？请使用 [项目 安全中心](/zh/pt/features/security/project-security-center)。
* 要审计整个 workspace？请使用 [Workspace 安全中心](/zh/pt/features/security/workspace-security-center)。
* 正在选择开发环境资源的运行位置？请阅读 [workspace 地理位置](/zh/features/collaboration/workspace-geography)。若要选择已部署 项目的运行位置，请阅读 [项目 地理位置](/zh/pt/features/publishing/project-geography)。
* 需要了解某个术语的含义？请阅读[安全概念](/zh/pt/features/security/concepts)。

Replit 的安全工具覆盖应用生命周期的不同环节，并协同发挥作用：

* **安装时**：[Package Firewall](/zh/pt/features/security/package-firewall) 会在恶意或已被入侵的包下载之前将其拦截。
* **安装后**：[自动依赖项扫描](/zh/pt/features/security/project-security-center#automatic-dependency-scans)会检测新披露的 CVE，Auto-Protect 可为其准备 Agent 修复方案。
* **部署前**：[Security Agent](/zh/pt/features/security/agent-security-scans) 会审计你的代码库，排查代码、依赖项和隐私方面的漏洞。

大部分扫描工作都遵循同样的流程：扫描、查看发现的问题、用 Agent 修复、重新部署，并在需要时导出证据。

<div id="onde-a-segurana-fica-no-produto">
  ## 安全功能在产品中的位置
</div>

<div id="em-um-projeto">
  ### 在项目中
</div>

在项目的 **Tools** 面板中，选择 **Security Center**，即可查看项目级发现、运行 Agent 安全扫描，并在部署前检查依赖项漏洞。

使用 [Agent 安全扫描](/zh/pt/features/security/agent-security-scans) 审查源代码。如果还需要从外部测试正在运行的应用，请使用[第 3 级黑盒渗透测试](/zh/pt/features/security/black-box-pen-tests)。

<div id="no-seu-workspace">
  ### 在你的 workspace 中
</div>

在首页侧边栏中选择 **Security**，即可跨项目查看漏洞、按暴露面为发现的问题排定优先级，并跟踪 workspace 级别的扫描历史。

</Frame>

<div id="na-publicao-e-nas-configuraes">
  ### 在部署和设置中
</div>

* 在 **Publish** &gt; **Advanced** 中，使用 **Block publishing of critical vulnerabilities** 阻止发布含有严重漏洞的内容。
* 在 **Settings** &gt; **Account** &gt; **Advanced** 中，设置 Agent 准备的依赖项修复所适用的 Auto-Protect 严重性阈值。
