使用开发 URL，你可以在构建应用时预览和测试应用。此 URL 的格式为 `UUID.servername.replit.dev`，可为正在开发的应用提供实时预览。

<Frame>
  <img src="/assets/mirror/preview-dev-url-b36770b33769.png" alt="地址栏中显示的开发 URL" width="1222" height="824" data-path="images/workspace/preview-dev-url.png" />
</Frame>

要查看开发 URL，请点击地址栏中的 `{...}.replit.dev` 文本。

<div id="url">
  ## 了解开发 URL
</div>

开发 URL 仅在你积极开发 Replit 应用时有效。每次重新打开应用时，URL 都可能会变化。借助开发 URL，你可以在构建和测试过程中通过浏览器查看应用。

默认情况下，开发 URL 公开可访问。任何拥有该 URL 的人都可以查看你正在构建的应用。这样你就能轻松与协作者、测试人员和利益相关者分享正在进行的工作。

<Warning>
  开发 URL 是临时的，仅用于测试。若要与他人分享应用，建议改为[发布应用](/zh/ko/learn/projects-and-artifacts/replit-deployments)。
</Warning>

<div id="section">
  ### 引导横幅
</div>

在新标签页中打开开发预览时，页面顶部会显示引导横幅。此横幅可帮助您在构建和测试应用时了解 `.replit.dev` URL 的用途。横幅会提供开发 URL 及其在开发过程中的用途等相关上下文。

<div id="url-2">
  ## 将开发 URL 设为私密
</div>

您可以限制对开发 URL 的访问，保障正在进行的工作安全。

要将开发 URL 设为私密：

1. 在 Project Editor 中打开 **Developer 工具**。
2. 选择 **网络** 标签页。
3. 启用 **私密开发 URL** 开关。

启用后，访问开发 URL 需要进行身份验证。只有您和获得授权的团队成员才能查看正在进行的工作。

<Note>
  Enterprise 客户可以要求所有 Project 使用私密开发 URL，以增强安全性，确保开发工作在组织环境中受到保护。
</Note>

<div id="section-2">
  ## 最佳实践
</div>

* 开发敏感或专有应用时，**使用私有 URL**
* 在积极构建应用时，如需与外部利益相关者分享工作成果或在其他浏览器中测试应用，**使用公开 URL**
