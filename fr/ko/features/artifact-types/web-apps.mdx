Les applications web sont le type de sortie par défaut de Replit. Décrivez votre idée à Agent : il créera une application web full-stack, sauf si vous spécifiez un autre type d’artefact.

<div id="section">
  ## Premiers pas
</div>

Vous pouvez créer une application web de deux façons :

* **Saisir un prompt** : décrivez ce que vous souhaitez créer sur la page d’accueil de Replit. Agent générera automatiquement une application web.
* **Sélectionner dans le menu déroulant** : ouvrez le menu déroulant des types d’application sur la page d’accueil, sélectionnez **Application web**, puis décrivez votre idée.

<div id="section-2">
  ## Fonctionnalités principales
</div>

* **Full-stack par défaut :** chaque application web comprend un frontend et un backend. Agent configure les routes API, les bases de données et la logique côté serveur nécessaires à votre application.
* **Design adaptatif :** votre application s&#39;adapte automatiquement aux différentes tailles d&#39;écran.
* **Publication instantanée :** publiez votre application en un clic. Replit gère l&#39;hébergement, le SSL et l&#39;infrastructure.
* **Infrastructure partagée :** si votre projet contient plusieurs artefacts, comme une application mobile ou un tableau de bord de données, ils partagent tous le même backend, la même base de données et les mêmes services.

<div id="section-3">
  ## Cas d&#39;utilisation
</div>

* **Produits SaaS** : créez des outils, des tableaux de bord et des plateformes destinés à vos clients.
* **Outils internes** : créez des panneaux d&#39;administration, des CRM et des applications de workflow pour votre équipe.
* **Pages de destination** : lancez des sites marketing avec des formulaires, des animations et du contenu dynamique.
* **Places de marché et annuaires** : créez des sites de petites annonces, des sites d&#39;offres d&#39;emploi et des plateformes communautaires.
