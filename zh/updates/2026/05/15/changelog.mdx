<div id="buy-enterprise-online-with-automated-sso-setup">
  ### 在线购买 Enterprise，自动完成 SSO 设置
</div>

现在，您可以直接在[定价页面](https://replit.com/pricing)购买 Replit Enterprise 计划，无需联系销售人员。完成结账后，产品内向导会引导您完成单点登录的全流程设置。将身份提供方的值粘贴到 SAML 表单中，Replit 会自动配置您的 SSO 连接。您的团队可在几分钟内启用 Enterprise，无需等待来回邮件沟通。

<div id="per-user-spend-limits-for-enterprise-workspaces">
  ### Enterprise Workspace 的用户个人消费限额
</div>

Enterprise 管理员现在可以为各个 Workspace 成员设置不同的 Agent 消费限额。在[用量页面](https://replit.com/usage)打开 **Agent 用户**表格，点击任意行的编辑图标，然后选择新的限额。用户个人限额优先于群组和 Workspace 默认限额。当你想为高频用户提供更高的上限，或在不影响 Workspace 其他成员的情况下收紧某个成员的消费限额时，此功能非常实用。

</Frame>

<div id="export-canvas-frames-as-pngs">
  ### 将 Canvas frame 导出为 PNG
</div>

在 Canvas 上右键点击任意 artifact 或设计 frame，选择 **Export** &gt; **PNG**，即可下载当前 Preview 的快照。无需手动截图，就能把画面快速分享到文档、聊天或队友评审中。导出的图片与导出那一刻 frame 在 Canvas 上呈现的内容完全一致。

<div id="nine-new-connectors-ready-to-use-out-of-the-box">
  ### 九个开箱即用的新 connector
</div>

另外九个 connector 现已配备默认凭据，只需单击一下即可将其连接到 Agent。无需先设置自己的 OAuth 应用。打开 project 中的 **Integrations** 面板，选择相应服务，然后授权连接。

* **Airtable**：读取和写入库、表和记录。
* **GitLab**：访问项目、议题、合并请求和流水线。
* **Basecamp**：读取和管理项目、待办事项、消息和日程。
* **Productboard**：读取和更新功能、版本和客户反馈。
* **Teamwork**：读取和管理项目、任务和工时记录。
* **Twitch**：读取直播、频道和观众活动。
* **Square**：接受付款并管理订单、客户和库存。
* **Intercom**：读取和写入对话、联系人和支持工作流。
* **Mailchimp**：读取和管理受众、营销活动和电子邮件营销数据。

详细了解 [connectors](/zh/replitai/integrations#available-connectors)。

<div id="four-new-mcp-servers-in-the-directory">
  ### 目录中新增四个 MCP 服务器
</div>

[MCP 目录](/zh/replitai/mcp/directory)现已提供四个托管的 Model Context Protocol 服务器。打开 **Integrations** 面板，在 **MCP Servers for Replit Agent** 下找到相应服务器，然后选择 **Add to Replit** 即可连接。

* **Twilio**：搜索 Twilio 文档以及 1,800 多个 API 端点，涵盖语音、短信、邮件和身份验证。
* **Mixpanel**：查询 Mixpanel 的事件、漏斗、留存和仪表板数据。
* **Lazyweb**：搜索 25.7 万多个真实应用界面，用作 UI 参考和设计调研素材。
* **Doola**：注册美国 LLC，并管理公司设立、记账和税务。

前往 [MCP 目录](/zh/replitai/mcp/directory)浏览完整列表。
