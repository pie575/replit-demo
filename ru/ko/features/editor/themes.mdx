Темы Replit позволяют настраивать внешний вид Project Editor — от цвета фона и элементов интерфейса до подсветки синтаксиса кода. Персонализируйте среду разработки, чтобы повысить читаемость, снизить нагрузку на глаза и сделать программирование приятнее.

<div id="section">
  ## Создание пользовательской темы
</div>

Чтобы создать и настроить собственную тему, выполните следующие действия.

1. Откройте [Settings](https://replit.com/settings) и перейдите в **User** → **Personalization** (или в раздел **Themes**)
2. Выберите **Create new theme**
3. Введите название, выберите цветовую схему (светлую или тёмную) и при желании добавьте описание
4. Выберите **Create Theme**, чтобы открыть редактор тем

Глобальные настройки темы определяют общий вид интерфейса.

* **Background**: основной цвет большинства поверхностей интерфейса
* **Outline**: цвет границ и разделителей
* **Foreground**: цвет текста и значков
* **Primary**: цвет кнопок и интерактивных элементов
* **Positive**: используется для обозначения успешных действий, например для кнопки **Run**
* **Negative**: используется для ошибок и предупреждений о необратимых действиях

Выберите **Apply Theme**, чтобы сразу начать использовать пользовательскую тему.

<div id="section-2">
  ## Подсветка синтаксиса
</div>

Настройте отображение различных элементов кода, чтобы улучшить читаемость и восприятие.

<Tip>
  Грамотно настроенная подсветка синтаксиса помогает быстро просматривать и понимать код. Выбирайте цвета, которые хорошо сочетаются между собой и обеспечивают достаточный контраст с фоном.
</Tip>

<Accordion title="Элементы подсветки синтаксиса">
  | Элемент                    | Описание                                                                                       |
  | -------------------------- | ---------------------------------------------------------------------------------------------- |
  | **Имена переменных**       | Применяется к переменным, объявленным без ключевого слова                                      |
  | **Определения переменных** | Задаёт цвет имён переменных, определённых с помощью ключевых слов, таких как `const` или `var` |
  | **Ссылки на функции**      | Применяется при вызове функций                                                                 |
  | **Определения функций**    | Задаёт цвет имени функции при её объявлении                                                    |
  | **Ключевые слова**         | Выделяет ключевые слова языка, такие как `import`, `function`, `return`                        |
  | **Имена свойств**          | Задаёт цвет при обращении к свойствам переменной                                               |
  | **Определения свойств**    | Используется при определении свойств объекта                                                   |
  | **Свойства-функции**       | Применяется при вызове метода объекта                                                          |
  | **Имена тегов**            | Используется для HTML- и JSX-тегов                                                             |
  | **Имена типов**            | Задаёт цвет аннотаций типов в типизированных языках                                            |
  | **Имена классов**          | Применяется к объявлениям классов и ссылкам на них                                             |
  | **Имена атрибутов**        | Выделяет HTML- и JSX-атрибуты                                                                  |
  | **Комментарии**            | Применяется ко всем комментариям в коде                                                        |
  | **Строки**                 | Задаёт цвет строковых литералов                                                                |
  | **Числа**                  | Выделяет числовые значения                                                                     |
  | **Логические значения**    | Форматирует логические значения (`true`/`false`)                                               |
  | **Регулярные выражения**   | Задаёт цвет шаблонов регулярных выражений                                                      |
  | **Операторы**              | Выделяет операторы, такие как `+`, `-`, `*`, `/`                                               |
  | **Скобки**                 | При необходимости задаёт цвет квадратных и угловых скобок                                      |
</Accordion>

<div id="section-3">
  ## Рекомендации по дизайну тем
</div>

Следуйте этим рекомендациям, чтобы создавать привлекательные и удобные темы.

<div id="section-4">
  ### Цвет и контраст
</div>

* **Балансируйте контраст**: обеспечьте достаточную разницу между фоном и элементами переднего плана
* **Создайте согласованную палитру**: подбирайте цвета, которые сочетаются друг с другом, а не конфликтуют
* **Сохраняйте единообразную яркость**: поддерживайте схожий уровень яркости для всех элементов синтаксиса
* **Проектируйте с учётом доступности**: избегайте сочетаний с низким контрастом — это важно для пользователей с нарушениями зрения

<Warning>
  Типичные ошибки в дизайне тем, которых стоит избегать:

  * чрезмерная разница в яркости между элементами синтаксиса
  * неудачно подобранные цвета, создающие визуальный диссонанс
  * недостаточный контраст между кодом и фоном
</Warning>

<div id="section-5">
  ## Управление темами
</div>

Доступ ко всем установленным темам и управление ими доступны в [Settings](https://replit.com/settings) → **User** → **Personalization** (или в разделе **Themes**).

<div id="section-6">
  ### Переключение темы
</div>

Нажмите кнопку рядом с названием темы, чтобы применить её как текущую.

<div id="section-7">
  ### Редактирование темы
</div>

Чтобы изменить пользовательскую тему, откройте меню с тремя точками и нажмите **Edit**.

<Note>
  Редактировать и удалять можно только те пользовательские темы, которые вы создали сами. Стандартные темы и темы других пользователей изменить нельзя.
</Note>

<div id="section-8">
  ### Удаление темы
</div>

Чтобы удалить пользовательскую тему, откройте меню с тремя точками и выберите **Delete**.

<div id="section-9">
  ## Обзор тем сообщества
</div>

Откройте для себя темы, созданные сообществом Replit, на [странице тем](https://replit.com/themes).

<div id="section-10">
  ### Поиск тем
</div>

* Ищите конкретные темы по названию, например &quot;Atom One Dark&quot;
* Фильтруйте по автору, чтобы находить темы определённых создателей
* Просматривайте цветовые схемы, чтобы найти светлые или тёмные темы
* Ищите по определённым цветам, чтобы подобрать тему на свой вкус

Перед установкой просмотрите тему, чтобы увидеть, как она будет выглядеть в Project Editor.

<div id="vs-code">
  ## Импорт из VS Code
</div>

Перенесите любимую тему VS Code в Replit — при создании темы те же цвета будут сопоставлены автоматически.

<div id="section-11">
  ## Публикация темы
</div>

Выполните следующие шаги, чтобы поделиться своей пользовательской темой с сообществом Replit.

1. Откройте Themes Editor для своей пользовательской темы
2. Нажмите кнопку **Publish**
3. Заполните поля названия и описания
4. Отправьте тему

После публикации тема появится на странице страница тем, где другие пользователи смогут её просмотреть и установить.
