Canvas 上的每一个图块都是 **设计帧 (frame) **。设计帧就是你选中、拖动并进行操作的对象。本页介绍设计帧的类型、选中时出现的各类设计帧操作栏，以及可在此执行的功能：Build 和 Focus。

<div id="section">
  ## 设计帧的类型
</div>

主要有两种：**工件** (正在运行、与 App 关联的画面) 和 **Designs** (原型稿) 。在设计帧左上角的标题栏即可确认它属于哪一种。

| 类型              | 标题标签                     | 基于          | 能像运行中的 App 一样交互吗？ | 能转换为真实 App 吗？                                 |
| --------------- | ------------------------ | ----------- | ----------------- | --------------------------------------------- |
| 工件        | **Website**、**Slides** 等 | 运行中的工件      | 是                 | 本身已是 App。                                     |
| Mobile artifact | **Mobile app**           | 运行中的工件      | 是 (在模拟器中)         | 本身已是 App。                                     |
| Design          | **Design**               | 静态/交互式原型稿   | 仅交互式设计帧             | 是 —— 通过各设计帧的 **Build…** 菜单。请参考 [Build](#build)。 |
| Image           | **Image**                | 生成的 PNG/JPG | 否                 | 否 —— 用作参考素材。                                  |
| Video           | **Video**                | 生成的视频       | 否                 | 否。                                            |
| Vector graphic  | **Graphic**              | 生成的 SVG     | 否                 | 否 —— 可嵌入到真实 App 中。                            |

<Note>
  Design 设计帧表现为静态图片还是交互式原型，取决于 **Interactive frames** 功能。启用该功能后，Design 设计帧会像真实页面一样响应点击和表单输入；未启用时，它只会渲染为快照，虽可继续迭代，但无法通过点击进行跳转。
</Note>

<div id="section-2">
  ## 在不同设备上预览
</div>

查看设计在各种屏幕尺寸下的显示效果。你可以让 Agent 展示移动端、平板或桌面端版本。例如,输入“显示这个页面的移动端版本”,Agent 就会按相应尺寸渲染设计帧。

* **移动端**:390 × 844
* **平板**:768 × 1024
* **桌面端**:1280 × 720

<div id="section-3">
  ## 各类设计帧的操作栏
</div>

选中设计帧后会显示操作栏。可用操作因设计帧类型而异。

<div id="artifact-design">
  ### 工件 与 Design 设计帧
</div>

对于 工件(Website、Slides 等)以及 Design 设计帧,操作栏会横跨显示在设计帧的顶部。

<Frame caption="Design 设计帧的操作栏:Build…、Focus 以及更多选项。">
  <img src="/assets/mirror/canvas-frame-action-bar-86f90fdd1375.png" alt="选中 APEX X1 Design 设计帧的 Canvas。顶部显示类型标签以及包含 Build、Focus、更多选项操作的设计帧级操作栏,该设计帧以标签形式附加在聊天提示词输入框中" width="2000" height="1290" data-path="images/replitai/canvas-frame-action-bar.png" />
</Frame>

宽度较窄时,操作组会收起为图标;设计帧变宽后则会显示文字标签。从左到右的完整列表如下。

| 操作       | 功能                                                                                                              |
| -------- | --------------------------------------------------------------------------------------------------------------- |
| Export   | 将设计帧下载为 PNG。请参阅[将设计帧导出为 PNG](/zh/ko/design/canvas#export-a-frame-as-png)。                                          |
| Build…   | 打开菜单,列出项目中的所有 工件 —— 选择一个以应用该设计,或选择 **Build this design** 新建 工件。仅适用于 Design 设计帧。请参阅 [Build](#build)。 |
| Focus    | 进入聚焦模式,将设计帧放大至主视图。                                                                                              |
| More (…) | 更多设计帧操作。复制、克隆、调整顺序和导出也可在画板的[右键菜单](/zh/ko/design/canvas#right-click-menu)中使用。                                         |

App 设计帧(Website、Slides、Mobile app)会显示 Focus 和更多选项,Design 设计帧则会在其前面额外显示 Build…。若想从选中的设计帧出发探索新方向,可沿着该设计帧的[建议](/zh/ko/design/explore-suggestions)继续。

选中设计帧后,它还会以快照形式附加到下一条 Agent 聊天消息中 —— 请参阅 [Canvas 上有哪些内容](/zh/ko/design/canvas#what-lives-on-the-canvas)。

<Note>
  操作栏遵循**只读模式**。当 Canvas 在后台任务上下文中被锁定时,与迭代相关的操作会隐藏,仅保留 Focus。
</Note>

<div id="section-4">
  ### 媒体设计帧
</div>

Image、Video、Vector graphic 设计帧会在设计帧的上方显示一个小型浮动操作栏。这三种类型都提供以下共同功能：

* **替换媒体**：保持在 Canvas 中的位置和尺寸不变，上传新文件替换设计帧中的媒体。
* **下载**：将媒体文件保存到你的电脑。
* **alt 文本**：添加 alt 文本，既便于无障碍访问，也能让 Agent 在引用该设计帧时获得更多上下文。

<Frame caption="视频设计帧的操作栏：Replace media、Download、Alt text。">
  <img src="/assets/mirror/canvas-frame-video-actions-905585560e90.png" alt="Canvas 中选中的蓝色超跑视频设计帧上方显示浮动操作栏，包含 Replace media、Download（带 'Download original' 提示）和 Alt text 控件" width="2000" height="1252" data-path="images/replitai/canvas-frame-video-actions.png" />
</Frame>

Image 设计帧还额外提供两个控件：

* **裁切 (Crop)&#x20;**：直接在 Canvas 中裁切图片。
* **生成视频 (Generate video)&#x20;**：基于图片生成一段简短的视频片段。

<Frame caption="图片设计帧的操作栏中新增了 Crop 和 Generate video。">
  <img src="/assets/mirror/canvas-frame-image-actions-aae1378db7e3.png" alt="Canvas 中选中的黄色超跑图片设计帧上方显示浮动操作栏，包含 Replace media、Crop、Download、Alt text 和 Generate video 控件" width="1600" height="1002" data-path="images/replitai/canvas-frame-image-actions.png" />
</Frame>

<div id="section-5">
  ## 探索新方向
</div>

选中设计帧后，旁边会出现[建议](/zh/ko/design/explore-suggestions)：基于你当前所看内容的一键式方向提示，比如换一种布局、换一种风格氛围，或是该设计所暗示的页面。每条建议都会在原设计帧旁生成一个新的设计帧，原稿保持不变，方便你直接对比。

  <img src="/assets/mirror/ambient-iq-0989ea31bce7.png" alt="选中的 Website 设计帧展示 APEX X1 超级跑车主视觉，旁边是 Suggested next steps 面板，显示 Explore different approaches、Try different layouts、Explore different vibes、Surprise me 等建议标签" width="2000" height="1254" data-path="images/design/replit-design/ambient-iq.png" />
</Frame>

<div id="build">
  ## Build
</div>

选中 Design 设计帧后，**Build…** 菜单可将设计转化为真正可运行的应用。通过同一菜单，也可以将设计应用到已有的工件上。

<Frame>
  <img src="/assets/mirror/canvas-build-menu-f06b8b8b455f.png" alt="在选中的 Design 设计帧（APEX X1 Exact Replica）上打开的 Build 菜单。标题为“Build or apply your designs”，其中显示用于创建新工件的“Build this design”，以及列出项目中 APEX X1 Design System 和 Scroll Hero 网站的“Apply to an existing creation”" width="2000" height="1153" data-path="images/replitai/canvas-build-menu.png" />
</Frame>

<div id="build-this-design">
  ### Build this design
</div>

在菜单中选择 **Build this design**，即可基于所选的 Design 设计帧创建新工件。新工件会添加到项目的工件列表中，成为可实际运行的应用。使用 Build 需要 Core 或 Pro 方案。

<div id="artifact">
  ### 应用到现有 工件
</div>

Build… 菜单会列出项目中的所有 工件。选择其中一个后，所选 Design 的更改便会应用到该 工件——Agent 会按照设计重写 工件 的代码，而 Design 设计帧会保留在 Canvas 上供参考。

<div id="section-6">
  ## 专注模式
</div>

使用专注模式，你可以停留在 Design 中，以全尺寸编辑所选的设计帧。

<Steps>
  <Step title="在设计帧上选择 Focus">
    选中一个设计帧，然后在操作栏中选择 **Focus**。

    <Frame caption="所选设计帧操作栏中的 Focus 操作。">
      <img src="/assets/mirror/focus-before-0c9ced9218d9.png" alt="Canvas 中选中的 Design 设计帧，其设计帧操作栏中高亮显示 Focus 操作。" width="2000" height="1254" data-path="images/design/replit-design/focus-before.png" />
    </Frame>
  </Step>

  <Step title="以全尺寸进行编辑">
    设计帧会铺满屏幕，让你不受画板上其他内容干扰，专注于近距离编辑。

    <Frame caption="专注模式">
      <img src="/assets/mirror/focus-mode-24da418577ae.png" alt="Design 设计帧铺满屏幕，画板顶部带有 Exit focus 按钮的专注模式。" width="2000" height="1254" data-path="images/design/replit-design/focus-mode.png" />
    </Frame>
  </Step>

  <Step title="返回 Canvas">
    选择画板顶部的 **Exit focus**，即可返回 Canvas。
  </Step>
</Steps>
