---

<Note>
  Certains détails concernant les allocations peuvent être ajustés avant la sortie.
</Note>

Le mode gratuit permet aux abonnés Starter, Core et Pro d’utiliser Agent sans frais supplémentaires. Starter inclut le mode gratuit avec ses limites existantes. Core et Pro incluent des allocations pour le mode gratuit. Lancez une conversation pour explorer, planifier, créer ou demander de l’aide. Si votre demande nécessite un mode ou une tâche payants, Replit vous en informera clairement avant le début de toute opération entraînant des frais.

<div id="section">
  ## Les avantages
</div>

* Commencez directement par une conversation, sans passer par la configuration.
* Explorez vos idées et progressez avant de décider si vous avez besoin de fonctionnalités supplémentaires.
* Gardez le contrôle, même pour les demandes nécessitant des tâches payantes.
* Les tâches effectuées en mode gratuit sont clairement identifiées par le libellé **Free**.

<div id="section-2">
  ## Fonctionnement
</div>

1. Les nouvelles sessions Starter, Core et Pro démarrent en mode gratuit.
2. Les tâches incluses dans le périmètre du mode gratuit se poursuivent sans notification de tâche payante.
3. Si le mode payant peut mieux traiter une demande, Agent l’explique et propose des options.
4. Vous pouvez autoriser le mode payant uniquement pour cette demande ou demander à Agent de continuer en mode gratuit.
5. Après un passage ponctuel à un mode payant, le mode revient au mode gratuit.

  ## Trois modes Agent
</div>

  <Card title="Power">

  <Card title="Max">
    Le mode payant haut de gamme pour les tâches les plus exigeantes, offrant les modèles de pointe les plus performants.
  </Card>
</CardGroup>

Le mode gratuit est accessible aux abonnés Starter, Core et Pro. Starter inclut le mode gratuit dans les limites existantes. Core et Pro incluent une allocation pour le mode gratuit, et Pro offre une limite hebdomadaire plus élevée. Vous pouvez également sélectionner un mode Agent payant lorsque vous avez besoin de davantage de capacités.

<Note>
  **Lorsque vous atteignez une limite :** Starter inclut le mode gratuit dans les limites existantes. Pour Core et Pro, l’allocation du mode gratuit est réinitialisée toutes les 5 heures et est soumise à une limite hebdomadaire. Consultez votre statut actuel dans **Settings → Usage**. Replit vous avertit à l’avance lorsque vous approchez d’une limite. Lorsque vous atteignez une limite, passez à un mode payant ou attendez la réinitialisation pour continuer.
</Note>

  ## Questions fréquentes
</div>

<AccordionGroup>
  <Accordion title="Le mode gratuit est-il vraiment gratuit ? Replit est-il désormais gratuit ?">
    Le mode gratuit est inclus dans les abonnements Starter, Core et Pro. Starter inclut le mode gratuit avec ses limites habituelles. Core et Pro incluent une allocation de mode gratuit. Il ne s&#39;agit pas d&#39;un forfait gratuit à part entière.
  </Accordion>

  <Accordion title="Est-ce la même chose que les modes Agent payants ?">
    Non. Le mode gratuit vous permet d&#39;utiliser Agent gratuitement dans la limite de votre allocation. Power et Max sont des modes payants pour les tâches nécessitant davantage de capacités.
  </Accordion>

  <Accordion title="Que sont devenus Economy et Power ? Les modes ont-ils changé ?">
    Les modes payants ont été renommés. Economy s&#39;appelle désormais Power : il s&#39;agit d&#39;un mode intermédiaire qui offre des modèles puissants à un prix raisonnable. Le mode auparavant appelé Power s&#39;appelle désormais Max, le mode haut de gamme. Vos paramètres de mode existants sont conservés sous les nouveaux noms.
  </Accordion>

  <Accordion title="Quel mode est le plus performant ?">
    Max. Power est un mode payant intermédiaire qui offre davantage de capacités à un prix raisonnable. Max est le mode payant haut de gamme pour les tâches les plus exigeantes.
  </Accordion>

  <Accordion title="Que se passe-t-il si ma demande nécessite une tâche payante ?">
    Agent vous indique que votre demande nécessite un mode payant ou une fonctionnalité payante et vous demande confirmation avant de continuer. Vous pouvez approuver cette demande une seule fois ou continuer en mode gratuit.
  </Accordion>

  <Accordion title="Si Agent suggère une mise à niveau, serai-je automatiquement facturé ?">
    Non. Le passage à un mode payant nécessite votre confirmation avant le début de la demande payante.
  </Accordion>

  <Accordion title="Puis-je refuser les options payantes ?">
    Oui. Vous pouvez continuer à travailler en mode gratuit.
  </Accordion>

  <Accordion title="Que se passe-t-il après avoir approuvé le passage à un mode payant ?">
    L&#39;approbation s&#39;applique uniquement à cette demande. Ensuite, Agent revient au mode gratuit.
  </Accordion>

  <Accordion title="Pourquoi ai-je atteint une limite ? Quand sera-t-elle réinitialisée ?">
    Starter inclut le mode gratuit avec ses limites habituelles. Pour Core et Pro, l&#39;allocation du mode gratuit est réinitialisée toutes les 5 heures et est soumise à une limite hebdomadaire. Consultez votre statut actuel dans **Settings → Usage**. Lorsque vous atteignez une limite, passez à un mode payant ou attendez la réinitialisation pour continuer.
  </Accordion>

  <Accordion title="Puis-je utiliser le mode gratuit avec Enterprise ?">
    Il n&#39;est pas disponible au lancement. Les espaces de travail Enterprise bénéficieront prochainement d&#39;une expérience Agent dédiée. Contactez votre administrateur pour plus d&#39;informations.
  </Accordion>
</AccordionGroup>

<div id="section-4">
  ## En savoir plus sur le mode gratuit
</div>

<AccordionGroup>
  <Accordion title="Le mode gratuit est-il identique à Lite ?">
    Pour les utilisateurs Starter, l’expérience auparavant appelée Lite s’appelle désormais le mode gratuit. Si vous utilisiez Lite pour accéder à des modèles moins coûteux, vous pouvez sélectionner manuellement ce modèle dans Power en désactivant Auto.
  </Accordion>

  <Accordion title="Puis-je créer une application complète avec le mode gratuit ?">
    Oui. Vous pouvez créer une application complète en mode gratuit et l’améliorer de façon itérative.
  </Accordion>

  <Accordion title="Quelles sont les différences entre Free, Power et Max ?">
    Le mode gratuit permet aux abonnés Starter, Core et Pro d’effectuer gratuitement les tâches quotidiennes avec Agent. Starter inclut le mode gratuit avec les limites existantes. Core et Pro incluent une allocation pour le mode gratuit. Power est un mode intermédiaire payant offrant davantage de capacités à un prix raisonnable. Max est le mode haut de gamme payant pour les tâches les plus exigeantes.
  </Accordion>

  <Accordion title="Quand dois-je passer du mode gratuit à un autre mode ?">
    Gardez le mode gratuit pour les tâches quotidiennes. Passez à un autre mode lorsque vous souhaitez de meilleurs résultats pour des tâches complexes ou avez besoin de capacités non disponibles en mode gratuit.
  </Accordion>

  <Accordion title="Puis-je générer des vidéos avec le mode gratuit ?">
    Non. La génération de vidéos est une fonctionnalité des modes payants qui ne fait pas partie du mode gratuit.
  </Accordion>

  <Accordion title="Qu'est-ce que la nouvelle expérience Conversations ?">
    Les fonctionnalités de chat et de création restent réunies. Dans une même Conversation, vous pouvez explorer des idées, planifier le travail ou démarrer un projet.
  </Accordion>

  <Accordion title="Un chat indépendant devient-il une partie d'une application publiée ?">
    Non. Les Conversations restent séparées jusqu&#39;à ce que vous créiez ou modifiiez un projet.
  </Accordion>

  <Accordion title="Puis-je travailler sur des projets existants avec le mode gratuit ?">
    Oui. Il prend en charge la maintenance et les modifications quotidiennes des projets existants.
  </Accordion>
</AccordionGroup>

**Prêt à essayer ?** Lorsque le mode gratuit sera disponible, commencez une Conversation avec Agent.
