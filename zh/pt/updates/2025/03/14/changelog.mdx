<div id="reteno-de-histrico-do-neon-db">
  ### Neon DB 历史记录保留
</div>

Neon 数据库现已支持自定义历史记录保留时长，帮助你更高效地控制成本。此次更新直接回应了用户对数据库成本管理的反馈。

<div id="recursos-aprimorados-de-contexto-de-links">
  ### 链接上下文功能增强
</div>

  ### Assistant 中的模型选择
</div>

<div id="melhorias-de-desempenho-no-web-view">
  ### Web View 性能改进
</div>

在 Web View 中享受更流畅的 iframe 浏览体验，以及对安全站点更好的兼容性。我们改进了代理系统，使其能更智能地处理安全标头，从而消除你此前可能遇到的恼人的浏览拦截问题。
