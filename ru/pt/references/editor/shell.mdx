title: "Shell"
description: "Узнайте, как использовать Shell для выполнения команд в Project Editor."
---

Shell позволяет выполнять в Project Editor задачи операционной системы, например управлять файлами,
устанавливать пакеты и запускать скрипты. Он предоставляет мощный текстовый интерфейс для
взаимодействия со средой Replit.

В Project Editor с помощью Shell можно выполнять следующие задачи:

* Запускать скрипты и программы
* Устанавливать и запускать популярные инструменты и пакеты Linux
* Загружать и скачивать файлы из интернета
* Управлять файлами и каталогами проекта

<Tip>
  Для более удобного управления Workflow используйте кнопку **Run**, а не запускайте приложение из
  Shell. Workflow, запущенный кнопкой **Run**, направляет вывод в инструмент Console,
  где логи удобно просматривать в структурированном виде.
</Tip>

<div id="recursos">
  ## Возможности
</div>

Shell предоставляет следующие возможности:

* **Несколько оболочек**: Открывайте несколько экземпляров Shell для одновременной работы над разными задачами
* **Поиск текста**: Находите нужный текст в выводе Shell

<div id="uso">
  ## Использование
</div>

<Accordion title="Как открыть Shell">
  В **панели инструментов** слева:

  1. Выберите <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Иконка «Все инструменты»" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**, чтобы просмотреть список инструментов Project Editor.
  2. Выберите <img class="icon-svg" src="/assets/mirror/shell-289d6eb079b0.svg" alt="Иконка Shell" width="16" height="16" data-path="images/icons/shell.svg" /> **Shell**.

  В **строке поиска**:

  1. Нажмите на <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="иконка лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> значок лупы вверху, чтобы открыть поиск.
  2. Введите &quot;Shell&quot;, найдите инструмент и выберите его в результатах.
</Accordion>

<div id="pesquisa-de-texto">
  ### Текстовый поиск
</div>

Чтобы открыть и использовать инструмент текстового поиска, выполните следующие действия:

1. Нажмите <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="значок лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> в правом верхнем углу вкладки Shell, чтобы открыть диалоговое окно поиска.
2. Введите поисковый запрос и выберите **Next**, чтобы перейти к следующему результату.
3. Используйте **Previous**, чтобы вернуться к предыдущему результату.
4. Выберите **Exit** или щелкните за пределами диалогового окна, чтобы закрыть текстовый поиск.

<div id="mltiplos-shells">
  ### Несколько Shell
</div>

Чтобы создать новый Shell, откройте меню в левом верхнем углу вкладки **Shell** и выберите **New Shell**, как показано ниже:

<Frame>
  <img src="/assets/mirror/shell-new-94a280c1230f.png" alt="Выбор пункта меню New Shell" width="1280" height="224" data-path="images/workspace/shell-new.png" />
</Frame>

Используйте то же меню для переключения между Shell. Project Editor помечает каждый Shell последней выполненной командой, чтобы их было легче различать.

<Warning>
  При открытии нескольких Shell Replit автоматически закрывает неактивные экземпляры Shell.
  Неактивный Shell — это Shell, который не выбран и не выполняет пользовательские процессы.
</Warning>
