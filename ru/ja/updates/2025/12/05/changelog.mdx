  ### Создавайте полностековые мобильные приложения с Agent
</div>

  <img src="/assets/mirror/cleanshot-2025-12-05-at-12-27-22-2x_273f89390642-dc03158b7d7f.png" width="1082" height="504" data-path="images/changelog/2025-12-05/cleanshot-2025-12-05-at-12-27-22-2x_273f89390642.png" />

Теперь Agent может создавать [мобильные Apps](/ru/ja/features/artifact-types/building-mobile-apps) с полноценным сервером бэкенда. Доступны все мощные возможности, необходимые для разработки мобильных приложений, готовых к продакшену: [ИИ-интеграции](/ru/replitai/integrations), [базы данных](/ru/ja/features/data-and-storage/sql-database), [объектное хранилище](/ru/ja/features/data-and-storage/object-storage), коннекторы и многое другое.

<div id="database">
  ### Database стала общедоступной
</div>

Новая [Database](/ru/ja/features/data-and-storage/sql-database) теперь используется по умолчанию во всех новых Replit App. Это обновление повышает надежность и обеспечивает больше контроля над инфраструктурой, улучшая производительность проектов и упрощая управление данными.

<div id="fast-mode">
  ### Fast Mode стал более автономным
</div>

  <img src="/assets/mirror/image_4f661377d428-8454460e1cca.png" width="720" height="212" data-path="images/changelog/2025-12-05/image_4f661377d428.png" />

[Режим Lite](/ru/core-concepts/agent/agent-modes) (прежний Fast Mode) теперь самостоятельно справляется с большим числом задач и рекомендует Agent для масштабных изменений. Создавайте приложения быстрее благодаря быстрым итерациям и плавной передаче работы.

<div id="section-3">
  ### Быстрое подключение к сторонним сервисам
</div>

Улучшенная поддержка коннекторов позволяет быстрее подключаться к сторонним сервисам. Достаточно указать конфигурацию, чтобы добавить большинство сервисов с API-ключами без сложной настройки. Также улучшены поддержка нескольких ключей и расширенные проверки работоспособности для более надежных [интеграций](/ru/replitai/integrations).
