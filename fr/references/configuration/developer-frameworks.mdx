## Qu'est-ce qu'un framework de développement ?

Les frameworks de développement sont des applications Replit que la plateforme et la communauté ont publiées pour que d'autres puissent les utiliser comme point de départ. Les frameworks de développement officiels, créés par Replit, ont une case à cocher à côté du nom du framework :

</Frame>

Le framework [HTML, CSS, JS](https://replit.com/@replit/HTML-CSS-JS?v=1#index.html) est très populaire et peut être utilisé comme point de départ pour créer un projet JavaScript vanilla. Vous pouvez forker le framework pour l'utiliser.

## Modèles personnalisés Enterprise

Les organisations Enterprise peuvent créer des [modèles personnalisés](/fr/teams/custom-templates) qui apparaissent comme options sélectionnables dans la zone de saisie de l'Agent pour tous les membres de l'organisation. Les modèles personnalisés vont au-delà des frameworks de développement en incluant des instructions Agent spécifiques à l'entreprise, des compétences et un contexte de projet préconfiguré. Consultez le [guide des modèles personnalisés](/fr/teams/custom-templates) pour plus de détails.
