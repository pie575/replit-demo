<div id="billing-categories">
  ## Категории оплаты
</div>

Replit подразделяет плату за App Storage на следующие категории:

* **Хранение**: Объём хранимых данных за месяц. Для всех хранимых объектов действует минимальный расчётный период — семь дней.
* **Передача данных**: Общий объём данных, загруженных и скачанных в течение месяца.
* **Базовые операции**: Операции, связанные с обновлением bucket и объектов. Подробнее см. Class A Operations в <a href="https://cloud.google.com/storage/pricing" target="_blank">тарифах Google Cloud Storage</a>.
* **Расширенные операции**: Все остальные операции объектного облачного хранилища, включая получение конфигурации и метаданных объектов и bucket. Подробнее см. Class B Operations в <a href="https://cloud.google.com/storage/pricing" target="_blank">тарифах Google Cloud Storage</a>.
