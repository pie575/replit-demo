技能目录汇集了由 Replit 及合作伙伴构建的现成技能，可立即安装使用。安装后试用，并根据团队的实际工作方式进行调整。

有关技能的定义以及 Agent 如何加载技能，请参阅 [Agent 技能](/zh/ja/features/agent/skills)。如需让整个工作区都能使用技能，请参阅 [Agent 自定义](/zh/ja/features/agent/agent-customization)。

<div id="section">
  ## 安装技能
</div>

从技能目录添加技能有以下几种方式：

* **在聊天中** — 点击聊天输入框旁的 **+** 按钮，选择 **Use a skill**，然后挑选所需技能。该技能仅对这条消息生效，不会向项目安装任何内容。
* **在项目中** — 打开 Project Editor 的 Skills 面板，切换到 **Discover** 标签页，找到技能后点击 **Install**。已安装的技能保存在项目的 `/.agents/skills` 目录中，并会在多次聊天之间保留。
* **通过命令行** — 使用 [skills CLI](https://github.com/vercel-labs/skills) 安装技能：

  ```bash theme={null}
  npx skills <skill> -a replit
  ```

<Warning>
  Replit 技能选择器中的技能均已通过安全性审核，而从外部来源安装的技能未经审核。由于技能是 Agent 会遵循的指令，安装外部技能前请务必先行审查 —— 有关需要检查的内容，请参阅 [Agent 技能](/zh/ja/learn/agent-skills)。
</Warning>

<div id="replit">
  ## Replit 技能
</div>

Replit 提供了一系列预定义技能，可在聊天的 **Use a skill** 选择器和新建项目的起点选择器中使用。它们无需安装即可在所有项目中使用。打开选择器即可看到内联说明。

| 类别     | 技能                                                                                                    |
| ------ | -------------------------------------------------------------------------------------------------------- |
| 销售与营销  | Ad Creative、AI SDR、SEO Auditor、Programmatic SEO、GEO、Content Machine、Storyboard                           |
| 职业发展   | AI Recruiter、Resume Maker、Interview Prep                                                                 |
| 调研与分析  | Competitive Analysis、Deep Research、GitHub Solution Finder、Supplier Research                              |
| 商业与财务  | Stock Analyzer、Excel Generator、Invoice Generator、Tax Reviewer                                            |
| 文档与工具  | Website Cloner、File Converter、Flashcard Generator、Legal Contract、Infographic Builder、Recreate Screenshot |
| 创意     | Photo Editor、Podcast Generator、Podcast Marketing、Branding Generator、Video Editing                        |
| 效率     | AI Secretary、Product Manager、Design Thinker、Skill Finder、Skill Creator                                   |
| 个人     | Travel Assistant                                                                                         |
| 安全与合规  | Secrets、Sensitive Data、Input Validation、AI Security、Dependency Vetting、License Check                     |
| 质量与可靠性 | Accessibility、Responsive UI、Observability、Resilience、Ship Review                                         |

<Note>
  在工作区中，选择器还会检测安装在项目 `.local/secondary_skills/` 目录下的其他技能。
</Note>

<div id="section-2">
  ## 合作伙伴技能
</div>

Replit 的合作伙伴发布了可教 Agent 如何使用其产品进行构建的技能。安装后，您可以让 Agent 掌握该服务的模式和规则。

| 合作伙伴             | Agent 可学到的内容                   |
| ---------------- | ------------------------------ |
| Stripe           | 支付和计费集成模式                      |
| PayPal           | 支付集成模式                         |
| RevenueCat       | 订阅和应用内购买模式                     |
| Mixpanel         | 分析和跟踪实现                        |
| BigQuery         | 数据仓库查询模式                       |
| Resend           | 事务性电子邮件集成                      |
| Google Workspace | Gmail、Drive、Docs 和 Calendar 集成 |
| Atlassian        | Jira 和 Confluence 的问题和页面工作流    |
| Google Maps      | 地图、地点、路线和地理编码集成                |

<div id="section-3">
  ## 社区技能
</div>

除 Replit 和合作伙伴提供的技能外，你还可以安装社区发布的技能。你可以在 [skills.sh](https://skills.sh) 上浏览；如需自行编写，请参阅 [Agent Skills specification](https://agentskills.io/specification)。
