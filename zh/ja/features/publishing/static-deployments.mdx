---
title: "静态部署"
description: "了解如何使用静态部署发布静态网站和前端应用。"
---

静态部署会将 Replit App 中的 HTML、CSS、JavaScript 等静态文件托管到云服务器上。服务器会自动运用缓存和扩缩策略，快速且经济地分发内容。

静态部署最适合以下场景：

* 营销落地页
* 作品集网站
* 产品与 API 文档站点

<Note>
  静态部署不兼容使用 Agent 创建的 Replit Apps。
  Agent 会自动创建需要后端服务器的全栈应用。
  对于 Agent 生成的应用，请使用以下部署类型之一：

  * [自动扩缩部署](/zh/ja/features/publishing/autoscale-deployments)
  * [Reserved VM 部署](/zh/ja/features/publishing/reserved-vm-deployments)
</Note>

<div id="section">
  ## 功能
</div>

静态部署包含以下功能：

* **经济高效的托管**：仅按网站传输的数据量计费。
* **HTTP 路由选项**：配置响应头、URL 重写和重定向。
* **自定义域名**：可配置自定义域名，也可使用 `<app-name>.replit.app` URL 访问你的应用。
* **自定义错误页面**：创建并提供自定义 404 错误页面。
* **监控**：查看日志，监控已发布应用的状态。

<div id="section-2">
  ## 使用方法
</div>

静态部署可通过 Publishing 项目编辑器工具访问。

<Accordion title="如何访问静态部署">
  在左侧**工具栏**中：

  1. 选择 <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="All tools 图标" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**，查看项目编辑器工具列表。
  2. 选择 <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Publishing 图标" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publishing**。
  3. 选择 **Static** 选项，然后选择 **Set up your published app**。

  在**搜索栏**中：

  1. 选择顶部的 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 放大镜图标，打开搜索工具
  2. 输入“Publishing”查找该工具，并从结果中选择。
  3. 选择 **Static** 选项，然后选择 **Set up your published app**。
</Accordion>

<div id="section-3">
  ### 主域名
</div>

指定已发布应用主机名中的子域名部分。发布后，你可以通过 `https://<subdomain>.replit.app` 访问已发布的应用。

如需了解如何使用自定义域名，请参阅[自定义域名](/zh/features/publishing/custom-domains)。

<div id="section-4">
  ### 私有部署
</div>

<Info>
  私有发布应用功能适用于 Pro 和 Enterprise 方案。
</Info>

私有发布的应用仅向你的 workspace 成员，或你邀请的特定用户和群组开放访问权限。
发布时，你可以选择 **Public**、**Password protected**、**Workspace only** 或 **Invite only** 四种访问方式。

要了解如何设置私有 deployment，请参阅[应用访问](/zh/features/publishing/private-deployments/)。

<div id="section-5">
  ### 公开目录
</div>

指定 Replit App 中存放静态文件的基础目录路径，该目录下的文件将对外公开提供。
部署后，云端主机会提供该目录中的所有页面和资源。

默认值 `/` 表示 Replit App 的根目录。

<div id="section-6">
  ### 构建命令
</div>

指定创建部署时在 Replit App 的 Shell 中执行的构建命令。

例如，使用 <a href="https://gohugo.io/" target="_blank">Hugo</a> 生成静态站点时，
可以使用 `hugo --minify` 命令生成文件并优化资源文件的大小。

<div id="section-7">
  ### 部署密钥
</div>

选择 **Add deployment secret**，添加安全运行构建命令所需的环境变量和密钥。

例如，如果站点生成器需要 API 密钥才能生成静态站点，可以通过 `API_KEY=<密钥名称>` 的形式传入。
