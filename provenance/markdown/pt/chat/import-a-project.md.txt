Se você já estava trabalhando em um app ou projeto, pode trazê-lo para o Replit e continuar o trabalho em um Project. Importar é diferente de anexar um arquivo como evidência ou contexto para uma Conversa.

## Escolha uma fonte suportada

A fonte determina o que você fornece e como o trabalho existente entra no Replit. O guia de importação atual documenta estes caminhos:

| Trabalho existente                  | Fontes suportadas                                                                                              |
| ----------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| Repositórios e projetos de builders | **GitHub**, **Bitbucket**, **Vercel**, **Bolt**, **Lovable**, **Base44** e **exportação de um Agent anterior** |
| Designs                             | **Figma** e **Claude**                                                                                         |
| Arquivos e dados locais             | **ZIP** e **Planilha** (`.xlsx`, `.csv` ou uma URL pública do Google Sheets)                                   |

Algumas importações de builders usam um repositório GitHub exportado do serviço original. Revise o guia específico da fonte antes de importar. Configurações, secrets, valores de banco de dados ou serviços específicos do provedor podem exigir configuração adicional depois.

Na caixa de prompt, selecione o menu **mais (+)** e depois **Importar um projeto existente** para abrir o fluxo de importação.

## Importar ou anexar?

* **Importe um Project** quando quiser continuar a construir a partir de código existente, um design ou trabalho de projeto estruturado.
* **Envie um arquivo** quando um documento, planilha, imagem ou captura de tela fornecer contexto para uma pergunta ou tarefa na Conversa atual.

Para o segundo caminho, veja [Enviar e usar arquivos](/pt/chat/upload-and-use-files).
