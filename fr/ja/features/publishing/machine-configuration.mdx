---
title: "Configuration de la machine"
description: "Configurez les performances et le coût du serveur qui exécute votre application publiée : processeur, mémoire, nombre maximal de machines."
---

La configuration de la machine détermine les performances du serveur qui exécute votre application publiée. Replit choisit des valeurs par défaut adaptées : la plupart des créateurs n&#39;ont donc rien à modifier. Si votre application paraît lente en cas de forte charge ou si elle manipule de grandes quantités de données en mémoire, envisagez une configuration plus puissante.

Pour la modifier, ouvrez l&#39;outil Publishing, sélectionnez **Adjust settings**, puis **Edit** à côté de **Machine configuration**.

<div id="section">
  ## Paramètres de configuration
</div>

* **CPU** : quantité de travail que chaque serveur peut traiter simultanément. Si de nombreuses personnes utilisent votre application en même temps, augmentez le nombre de vCPU.
* **Mémoire (RAM)** : quantité de données que votre application peut conserver en mémoire. Pour les fichiers volumineux, les médias ou les traitements gourmands en données, augmentez la RAM.
* **Max machines** : Autoscale uniquement. Nombre maximal de serveurs que Replit peut ajouter lorsque votre application est fortement sollicitée. L&#39;application ne dépasse jamais ce nombre lors de la mise à l&#39;échelle, ce qui plafonne le coût maximal.

<div id="section-2">
  ## À propos des coûts
</div>

Pendant la configuration, le volet affiche deux valeurs :

* **Per machine** : le coût horaire par serveur avec la configuration sélectionnée.
* **At max traffic** : le coût horaire lorsque votre application est suffisamment sollicitée pour utiliser toutes les machines, jusqu&#39;au nombre maximal.

Les coûts sont exprimés en unités de calcul, une unité de cloud computing déterminée par le CPU et la mémoire que vous avez sélectionnés. Pour connaître les tarifs actuels et le mode de facturation de l&#39;utilisation, consultez [Facturation basée sur l&#39;utilisation](/fr/ja/billing/about-usage-based-billing#2-compute-units).

<div id="section-3">
  ## Différences de facturation selon le type de déploiement
</div>

À configuration identique, le mode de facturation varie selon le [type de déploiement](/fr/ja/features/publishing/deployment-types) :

* **Autoscale** : vous n&#39;êtes facturé que pendant le traitement des requêtes. Lorsque l&#39;application est inactive, elle est mise à l&#39;échelle à zéro et n&#39;engendre aucun coût d&#39;exécution.
* **Reserved VM** : le serveur fonctionne en permanence ; vous payez donc un coût mensuel fixe pour la configuration choisie.
* **Static** : aucune machine n&#39;exécute le site, les paramètres de configuration de la machine ne s&#39;appliquent donc pas.
* **Scheduled** : vous payez l&#39;utilisation de la machine à chaque exécution planifiée.

<div id="section-4">
  ## Appliquer les modifications
</div>

Une fois les paramètres modifiés, republiez votre application. La nouvelle configuration de la machine prendra effet lors du prochain déploiement.
