SEO Agent 会对整个项目进行技术 SEO 审核，找出妨碍搜索引擎和 AI 爬虫发现并理解你的应用的问题。每项发现都可一键修复，你可以与 Agent 一起查看并应用这些修复。

它位于 Project Editor 的 **Growth** 面板中，适用于已发布的应用。对大多数构建者而言，工作流程是：发布应用、打开 SEO Agent、运行扫描、查看发现项并应用修复。

<div id="seo-agent">
  ## SEO Agent 的功能
</div>

SEO Agent 关注的是**技术性 SEO**，即决定搜索引擎和 AI 爬虫能否轻松发现、索引并理解你的应用的那些结构化、机器可读的部分。

它会检查你的项目，并针对以下方面提出修复建议：

* **可爬取性与索引**：`robots.txt`、`sitemap.xml`，以及可爬取的链接和页面结构。
* **页面元数据**：确保每个页面都有唯一且具描述性的 `<title>` 标签和元描述。
* **结构化数据**：帮助搜索引擎展示富媒体搜索结果的 JSON-LD 标记。
* **Open Graph 与社交标签**：控制链接被分享时预览显示效果的元数据。
* **语义化标记**：合理的标题层级顺序、地标元素，以及图片的描述性 `alt` 文本。

<Note>
  SEO Agent 会确保你构建的应用在搜索层面技术健全，但它
  不会替你撰写内容，也不会帮你建立主题权威性。
</Note>

<div id="section">
  ## 开始之前
</div>

使用 SEO Agent 需要满足以下条件：

* **已发布的应用。** SEO Agent 会审核已上线的 Web 部署；如果您的应用尚未发布，请先将其发布。有关支持 SEO 的部署类型，请参阅 [SEO 评分](/zh/ja/features/publishing/seo-rating)。
* **付费套餐。** 订阅付费套餐的构建者可以使用 SEO Agent。如果您使用免费套餐，Growth 面板会显示升级选项。

您可以通过两种方式访问 SEO Agent：直接在 Project Editor 中打开 **Growth** 面板，或在 **Publishing** 工具中选择 SEO 评分旁的 **使用 Agent 优化 SEO**。选择后，Growth 面板将打开并准备好开始扫描。

  如需控制应用在社交平台分享时的预览效果，
  请连接[自定义域名](/zh/ja/build/add-custom-domain)并重新发布。社交媒体和
  链接预览会使用应用已发布的生产环境 URL，因此，使用已发布的自定义域名
  可确保预览准确。
</Tip>

<div id="seo-agentseo">
  ## SEO Agent 和 SEO 评分
</div>

SEO Agent 旁显示的**SEO 评分**基于每次发布时自动运行的 [Lighthouse 审核](/zh/ja/features/publishing/seo-rating)计算得出，并将应用评为 Healthy、Needs Work 或 Weak。此评分反映&#95;应用的当前状态&#95;。
SEO Agent 会扫描问题并应用修复，帮助你&#95;提升评分&#95;。修复后重新发布，评分将会更新。

你也可以完全跳过扫描界面，直接让 Agent 执行。
