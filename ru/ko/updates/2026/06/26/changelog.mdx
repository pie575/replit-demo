<div id="section-3">
  ### Новый опыт работы с интеграциями
</div>

Теперь все сервисы, с которыми связывается Replit, можно изучить в одном месте. Обновлённая страница интеграций собрала коннекторы, MCP-серверы и провайдеров Git в виде кликабельных карточек, а также предлагает фильтры по категориям и значки, отмечающие интеграции, которые Replit может подключить автоматически. Каталог теперь насчитывает более 450 интеграций, и по клику на любую из них открывается отдельная страница с примерами сценариев использования. Полный каталог можно посмотреть на [replit.com/integrations](https://replit.com/integrations).

<div id="slack-replit">
  ### Использование Replit в Slack
</div>

Replit теперь входит в число стартовых партнёров MCP-клиента Slackbot в Slack. Попросите Slackbot собрать что-нибудь на Replit — и вы сможете создавать, обновлять и просматривать Replit App прямо в Slack. Вы не выпадаете из разговора, а всю работу берёт на себя Replit Agent.

<div id="scim">
  ### Несколько рабочих пространств для клиентов с SCIM
</div>

Enterprise-клиенты, которые провижинят участников через SCIM, теперь могут создавать более одного рабочего пространства. Синхронизированные группы можно распределять по отдельным рабочим пространствам — так границы доступа, управление бюджетом и разделение команд становятся чётче, а поставщик удостоверений по-прежнему остаётся единым достоверным источником данных. Функция доступна по открытой регистрации для новых Enterprise-клиентов.

Подробнее об [управлении доступом к рабочим пространствам через SCIM](/ru/ko/teams/identity-and-access-management/scim#managing-workspace-access).
