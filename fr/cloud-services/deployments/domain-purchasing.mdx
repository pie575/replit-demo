Transformez vos applications en sites web professionnels avec des noms de domaine personnalisés.

L'achat de domaine vous permet de rechercher, acheter et connecter des domaines pour vos applications Replit publiées — tout cela depuis la plateforme. Passez d'une application publiée à une présence web professionnelle en quelques minutes.

Cela signifie que vous pouvez acheter un site, comme `mon-app.com`, et le faire pointer automatiquement vers votre application.

## Fonctionnalités

L'achat de domaine simplifie le processus pour donner à vos applications des adresses web professionnelles. Au lieu de jongler avec plusieurs services, vous pouvez compléter l'ensemble de la configuration de votre présence web dans Replit.

<Frame>
  <img src="/assets/mirror/replit-domains-8453291b634b.png" alt="Interface de gestion des domaines affichant les domaines achetés et leur état de connexion" width="3176" height="1556" data-path="images/deployments/custom-domains/replit-domains.png" />
</Frame>

Les principales fonctionnalités incluent :

* **Recherche et disponibilité de domaines** : Vérifiez la disponibilité des domaines parmi les extensions populaires comme `.com`, `.ai`, et plus encore
* **Achat en un clic** : Achetez des domaines directement via Replit en utilisant le mode de paiement par défaut de votre compte
* **Configuration automatique** : Votre domaine pointe instantanément vers votre application Replit sans configuration DNS manuelle
* **Protection de la vie privée WHOIS** : Vos informations personnelles restent privées dans les registres de domaines publics — inclus par défaut avec chaque achat de domaine
* **Enregistrements DNS personnalisés** : Ajoutez des enregistrements A, TXT et MX personnalisés pour configurer des fournisseurs de messagerie et d'autres services
* **Publication instantanée** : Votre application devient accessible à votre domaine personnalisé immédiatement après l'achat
* **Renouvellements automatiques** : Les domaines se renouvellent automatiquement afin que vos applications restent publiées sans interruption

## Utilisation

### Acheter des domaines

1. Publiez votre application et accédez à l'onglet <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Icône de publication" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publication**
2. Sélectionnez l'onglet **Domaines**
3. Choisissez **Acheter un domaine** pour lancer la recherche
4. Saisissez le nom de domaine souhaité dans la barre de recherche
5. Consultez les options disponibles pour différentes extensions
6. Sélectionnez le domaine de votre choix et finalisez l'achat

Lorsque vous achetez un domaine, il est automatiquement configuré pour pointer vers votre application Replit. Votre application devient instantanément accessible au domaine personnalisé, sans configuration supplémentaire requise.

Vous serez facturé pour l'achat du domaine via votre compte Replit, déduit de votre solde de compte puis appliqué à votre utilisation.

### Gérer les domaines achetés

Vos domaines s'intègrent de manière transparente à vos applications publiées :

* **Renouvellements automatiques** : Les domaines se renouvellent automatiquement pour maintenir vos applications publiées
* **Facturation intégrée** : Les coûts des domaines apparaissent sur votre facturation Replit aux côtés des autres services
* **Support de transfert** : Déplacez des domaines entre comptes Replit ou vers des registraires externes si nécessaire

### Enregistrements DNS personnalisés

Pour les domaines achetés via Replit, vous pouvez ajouter des enregistrements DNS personnalisés pour configurer des services supplémentaires comme les fournisseurs de messagerie. Les types d'enregistrements DNS suivants sont pris en charge :

* **Enregistrements A** : Pointez votre domaine ou sous-domaine vers une adresse IP spécifique
* **Enregistrements TXT** : Ajoutez des enregistrements de vérification textuels pour des services comme l'authentification par e-mail (SPF, DKIM, DMARC)
* **Enregistrements MX** : Les enregistrements MX (Mail Exchange) indiquent aux serveurs de messagerie où livrer les e-mails pour votre domaine. La configuration des enregistrements MX vous permet d'utiliser votre domaine personnalisé pour des adresses e-mail comme `bonjour@votredomaine.com`.

Pour gérer les enregistrements DNS de votre domaine acheté :

1. Accédez à l'onglet **Domaines** dans la publication <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Icône de publication" width="16" height="16" data-path="images/icons/deploy-icon.svg" />
2. Trouvez le domaine que vous souhaitez configurer
3. Sélectionnez l'icône **Modifier** <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="icône crayon" width="16" height="16" data-path="images/icons/pencil-icon.svg" />
4. Choisissez **Ajouter un enregistrement DNS**
5. Saisissez le type d'enregistrement, le nom, la valeur et le TTL selon les exigences de votre fournisseur de services

## FAQ

<AccordionGroup>
  <Accordion title="Combien ça coûte ?">
    L'achat de domaine comprend deux coûts :

    * **Frais d'enregistrement** : Le coût initial pour un an de propriété du domaine (deux ans pour les domaines `.ai`)
    * **Prix de renouvellement** : Facturé automatiquement après la période d'enregistrement initiale

    Replit ne facture pas de frais supplémentaires pour les achats de domaines. Les frais d'enregistrement de domaine ne sont pas remboursables.
  </Accordion>

  <Accordion title="Comment renouveler mon domaine ?">
    Replit renouvelle automatiquement votre domaine pour maintenir votre application
    accessible. Si vous préférez ne pas renouveler, contactez le support Replit pendant
    la période bêta.
  </Accordion>

  <Accordion title="Que faire si je veux quitter Replit ?">
    Vous pouvez transférer votre domaine vers un autre registraire en contactant le
    support Replit. Les règles ICANN exigent une période d'attente de 60 jours après
    l'achat avant que les domaines puissent être transférés vers des registraires
    externes.
  </Accordion>

  <Accordion title="Puis-je transférer des domaines entre comptes Replit ?">
    Oui, contactez le support Replit pour transférer des domaines entre comptes Replit.
    Ce processus ne nécessite pas la période d'attente de 60 jours.
  </Accordion>

  <Accordion title="Puis-je acheter des domaines pour mon organisation ?">
    L'achat de domaines pour les plans Replit Pro et Enterprise sera disponible après
    la période bêta initiale.
  </Accordion>

  <Accordion title="Puis-je ajouter des enregistrements DNS personnalisés à mon domaine ?">
    Oui ! Vous pouvez ajouter des enregistrements DNS personnalisés aux domaines achetés via Replit. Les types d'enregistrements actuellement pris en charge comprennent :

    * **Enregistrements A** : Pointez votre domaine ou sous-domaine vers des adresses IP spécifiques
    * **Enregistrements TXT** : Ajoutez des enregistrements de vérification textuels pour l'authentification par e-mail et d'autres services
    * **Enregistrements MX** : Configurez les serveurs de messagerie pour gérer les e-mails de votre domaine

    Accédez à l'onglet Domaines dans la publication pour configurer ces enregistrements. Pour des instructions détaillées sur la configuration des enregistrements MX pour la messagerie, consultez la section [Enregistrements DNS personnalisés](#enregistrements-dns-personnalises) ci-dessus.
  </Accordion>

  <Accordion title="Quelles extensions de domaine sont prises en charge ?">
    Nous prenons en charge tous les domaines de premier niveau (TLD) courants. Nous ne
    pouvons pas prendre en charge les TLD avec des restrictions géographiques ou autres
    restrictions spéciales.
  </Accordion>

  <Accordion title="Qu'est-ce que la protection de la vie privée WHOIS ?">
    Lorsque vous enregistrez un domaine, vos coordonnées (nom, adresse, numéro de téléphone et e-mail) sont normalement publiées dans une base de données publique appelée WHOIS que tout le monde peut consulter. La protection de la vie privée WHOIS remplace vos informations personnelles par des informations génériques du registraire, gardant vos informations privées tout en respectant les exigences légales.

    Tous les domaines achetés via Replit incluent la protection de la vie privée WHOIS par défaut, sans frais supplémentaires. Cela signifie que vos informations personnelles restent cachées des spammeurs, des spécialistes du marketing et de toute autre personne qui pourrait rechercher les détails du propriétaire d'un domaine.
  </Accordion>

  <Accordion title="Que faire si j'ai déjà un domaine ?">
    Pour connecter un domaine existant à votre application Replit, consultez notre documentation sur les [Domaines personnalisés](/fr/cloud-services/deployments/custom-domains/).
  </Accordion>
</AccordionGroup>
