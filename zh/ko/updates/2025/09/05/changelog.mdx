<div id="general-agent">
  ### General Agent
</div>

<Frame>
  <img src="/assets/mirror/general-agent-240ff289e711.png" alt="General Agent 主视觉插图" width="1040" height="572" data-path="images/replitai/general-agent.png" />
</Frame>

Replit Agent 现已支持在 NixOS 上运行的任意语言或框架的代码库！此前 Agent 仅能用于特定模板，如今可支持各类开发框架、GitHub 导入以及任意自定义项目配置。这一重大扩展为企业版和高级用户的工作流带来了完整的 AI 编码支持。

点击[此处](/zh/core-concepts/agent/general-agent)进一步了解 General Agent。

<div id="section-3">
  ### 计划模式
</div>

<Frame>
  <img src="/assets/mirror/plan-mode-overview-8077807c63b9.png" alt="计划模式下的 Agent 聊天界面" width="916" height="362" data-path="images/replitai/plan-mode-overview.png" />
</Frame>

计划模式带来了与 Replit Agent 对话的全新方式，专注于提问、头脑风暴和规划任务。借助计划模式，你可以让 Agent 为后续工作生成待办清单，然后在构建模式中执行长时间运行的任务。

点击[此处](/zh/core-concepts/agent/plan-mode)详细了解计划模式。

<div id="section-4">
  ## 企业版
</div>

<div id="gcp">
  ### GCP Marketplace 集成
</div>

企业版客户现在可以通过 Google Cloud Platform Marketplace 直接购买 Replit，并使用现有的 GCP 额度付款。这简化了采购流程，也让拥有 GCP 预算的组织能够更轻松地将 Replit 引入开发工作流。
