Créez du contenu visuel pour vos applications grâce aux capacités de génération d&#39;images <img class="icon-svg" src="/assets/mirror/image-13b737955126.svg" alt="Icône de génération d'images" width="24" height="24" data-path="images/icons/image.svg" /> d&#39;Agent.

Transformez vos idées en images personnalisées, illustrations et graphiques parfaitement adaptés aux besoins de votre projet. Que vous créiez un site web, une application mobile ou tout autre projet créatif, Agent génère des images qui donnent vie à votre vision.

La génération d&#39;images permet aux créateurs de produire du contenu visuel unique sans compétences en design ni outils externes. Générez aussi bien des icônes et des illustrations que des arrière-plans et des éléments d&#39;UI, directement dans votre flux de travail de développement.

<div id="recursos">
  ## Fonctionnalités
</div>

Créez des applications visuellement attrayantes grâce à la génération d&#39;images d&#39;Agent. Fini les photos de banques d&#39;images, les outils de design externes ou le recours à des designers pour du contenu visuel de base. Que vous créiez un site portfolio, développiez un jeu ou conceviez l&#39;interface d&#39;une application mobile, la génération d&#39;images vous fournit des visuels personnalisés adaptés à votre projet.

Agent peut réaliser les actions de génération d&#39;images suivantes :

* **Création d&#39;images personnalisées** : générez des images à partir de descriptions et de spécifications détaillées
* **Adaptation du style** : créez des images dans divers styles artistiques, du réalisme au dessin animé
* **Intégration au projet** : ajoutez les images générées directement à la base de code de votre application, en toute fluidité
* **Amélioration itérative** : modifiez et perfectionnez les images selon vos retours

<div id="uso">
  ## Utilisation
</div>

La génération d’images est intégrée à Agent : il n’y a rien à activer. Ouvrez n’importe quelle Replit App avec Agent activé et demandez-lui de créer le contenu visuel dont vous avez besoin. Agent détermine automatiquement à quel moment générer des images en fonction de vos demandes et crée des images personnalisées correspondant à vos spécifications.

<div id="quando-o-agent-usa-a-gerao-de-imagens">
  ### Quand l&#39;Agent utilise la génération d&#39;images
</div>

L&#39;Agent déclenche la génération d&#39;images lorsque vous demandez du contenu visuel pour vos projets :

| Cas d&#39;usage                        | Exemple de prompt                                                   |
| -------------------------------------- | ------------------------------------------------------------------- |
| **Icônes et logos d&#39;applications** | « Génère un logo moderne pour mon application de suivi de fitness » |
| **Arrière-plans de sites**             | « Crée un arrière-plan en dégradé subtil pour mon site portfolio »  |
| **Ressources de jeux**                 | « Génère des sprites en pixel art pour mon jeu de plateforme »      |
| **Illustrations d&#39;UI**             | « Crée une illustration pour l&#39;écran vide de mon application »  |
| **Visuels marketing**                  | « Génère une image hero pour ma page de destination »               |
| **Maquettes de produits**              | « Crée des maquettes de mon application sur différents appareils »  |

<div id="melhores-prticas-para-gerao-de-imagens">
  ### Bonnes pratiques pour la génération d&#39;images
</div>

Suivez ces recommandations pour tirer le meilleur parti de la génération d&#39;images d&#39;Agent :

**Soyez précis et descriptif**

* Incluez des détails sur le style, les couleurs, la composition et l&#39;ambiance
* Précisez les dimensions ou les proportions lorsque c&#39;est pertinent
* Mentionnez l&#39;usage prévu (icône, arrière-plan, illustration, etc.)

**Itérez et affinez**

* Commencez par une description simple, puis affinez-la en fonction des résultats
* Demandez à Agent de modifier des aspects précis des images générées
* Demandez des variantes pour explorer différentes directions créatives

**Tenez compte du style de votre projet**

* Maintenez une cohérence visuelle dans toute l&#39;application
* Précisez les préférences de style correspondant à votre marque ou à votre système de design
* Demandez des images qui complètent vos éléments visuels existants

<div id="integrao-ao-projeto">
  ### Intégration au projet
</div>

Agent intègre de façon fluide les images générées à votre base de code :

* **Création automatique de fichiers** : les images générées sont enregistrées directement dans les fichiers du projet
* **Mises à jour du code** : Agent met à jour votre code pour référencer les nouveaux fichiers image
* **Organisation des ressources** : les images sont placées dans des répertoires logiques au sein de la structure du projet

Ce flux de travail simplifié vous permet de générer et d&#39;intégrer du contenu visuel sans quitter votre environnement de développement.

<Note>
  La génération d&#39;images de Replit repose sur [Imagen 4 de Google](https://deepmind.google/models/imagen/), un modèle texte-image de dernière génération qui excelle dans la création d&#39;images photoréalistes de haute qualité, riches en détails et dotées de capacités de rendu de texte améliorées.
</Note>
