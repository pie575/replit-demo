Secrets 工具可存储并加密 Replit 应用中的敏感信息，即 **Secrets** — API 密钥、身份验证令牌、数据库连接字符串等。

添加 Secrets 后，该工具会自动加密数据，并将其作为环境变量提供给 Replit 应用。
这样可避免在代码中硬编码 Secrets，降低泄露风险。

在代码库中硬编码 Secrets 可能会在以下情况下意外泄露：

* 通过公开的 Replit 应用或复制粘贴方式与他人共享代码时
* 将代码提交到公开仓库时
* 直播代码或共享屏幕时

使用 Secrets 工具，安心共享代码，无需担心凭据泄露。

<div id="section">
  ## 功能
</div>

Secrets 具有以下功能：

* **端到端加密**：静态数据采用 AES-256 加密，传输中的数据采用 TLS 加密，自动保护数据安全
* **应用级 Secrets**：为特定 Replit 应用存储和管理 Secrets
* **账户级 Secrets**：存储和管理可在所有 Replit 应用中使用的 Secrets
* **环境变量访问**：通过环境变量在代码中访问 Secrets
* **协作访问**：与协作者和团队成员共享 Secrets

<div id="section-2">
  ## 使用方法
</div>

<Note>
  除静态部署外，所有部署类型均可使用 Secrets。
</Note>

您可以通过 Project Editor 中的 Secrets 工具访问 Secrets。

<Accordion title="如何访问 Secrets">
  在左侧的 **工具栏** 中：

  1. <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="所有工具图标" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> 选择 **All tools**，查看 Project Editor 工具列表。
  2. <img class="icon-svg" src="/assets/mirror/lock-af402c9618dd.svg" alt="Secrets 图标" width="16" height="16" data-path="images/icons/lock.svg" /> 选择 **Secrets**。

  在 **搜索栏** 中：

  1. 选择顶部的 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 放大镜，打开搜索工具。
  2. 输入“Secrets”查找该工具，然后在结果中选择它。
</Accordion>

<div id="section-3">
  ### 管理 App Secrets
</div>

您可以在 **Secrets** 面板的 **App Secrets** 标签页中管理应用级 Secrets。
此标签页会列出与 Replit App 关联的所有 Secrets。

<Accordion title="添加 App Secrets">
  添加 Secret：

  1. 选择 **New Secret**。
  2. 输入 Secret 的名称 **Key** 和 Secret 的值 **Value**。
  3. 选择 **Add Secret** 保存条目。
</Accordion>

<Accordion title="编辑 App Secrets">
  编辑 Secret：

  1. 选择 Secret 旁边的 <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="三个垂直点图标" height="16" width="16" data-path="images/icons/vertical-dots.svg" /> 三点菜单。
  2. 在快捷菜单中选择 **Edit**。
  3. 修改 **Key** 或 **Value** 字段中的文本，然后选择 **Update Secret** 保存更改，或选择 **Cancel** 取消更改。

  您还可以选择标签页底部的 **Edit as JSON** 或 **Edit as .env**，编辑全部 App Secrets。
</Accordion>

<Accordion title="查看 App Secrets">
  要查看 Secret，请选择 Secret 旁边的 <img class="icon-svg" src="/assets/mirror/eye-8a6472b8a950.svg" alt="眼睛图标" width="16" height="16" data-path="images/icons/eye.svg" /> 眼睛图标。

  要隐藏 Secret，请选择 <img class="icon-svg" src="/assets/mirror/eye-slash-6b4ded538179.svg" alt="带斜杠的眼睛图标" width="16" height="16" data-path="images/icons/eye-slash.svg" /> 带斜杠的眼睛图标。
</Accordion>

<Accordion title="删除 App Secrets">
  删除 Secret：

  1. 选择 Secret 旁边的 <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="三个垂直点图标" height="16" width="16" data-path="images/icons/vertical-dots.svg" /> 三点菜单。
  2. 选择 **Delete**。
</Accordion>

<div id="section-4">
  ### 管理账户 Secrets
</div>

您可以在 **Secrets** 面板的 **Account Secrets** 标签页中管理账户级 Secrets。
此标签页仅显示与您的 Replit 账户关联的 Secrets。

<Accordion title="添加账户 Secrets">
  要添加账户级 Secrets：

  1. 前往 **Account Secrets** 标签页。
  2. 选择 <img class="icon-svg" src="/assets/mirror/settings-icon-c2664c3691bf.svg" alt="齿轮图标" width="16" height="16" data-path="images/icons/settings-icon.svg" /> 图标，打开 **Settings** 以管理账户级 Secrets。
  3. 选择 **New Secret**。
  4. 输入 Secret 的名称 **Key** 和内容 **Value**。
  5. 选择 **Save** 保存该条目。
</Accordion>

<Accordion title="编辑账户 Secrets">
  要编辑 Secret：

  1. 选择 Secret 旁的 <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="铅笔图标" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> 铅笔图标。
  2. 修改 **Key** 或 **Value** 字段中的文本，然后选择 **Save** 保存更改，或选择 **Cancel** 取消更改。
</Accordion>

<Accordion title="查看账户 Secrets">
  要查看 Secret，请选择 Secret 旁的 <img class="icon-svg" src="/assets/mirror/eye-8a6472b8a950.svg" alt="眼睛图标" width="16" height="16" data-path="images/icons/eye.svg" /> 眼睛图标。

  要隐藏 Secret，请选择 <img class="icon-svg" src="/assets/mirror/eye-slash-6b4ded538179.svg" alt="带斜杠的眼睛图标" width="16" height="16" data-path="images/icons/eye-slash.svg" /> 带斜杠的眼睛图标。
</Accordion>

<Accordion title="关联账户 Secrets">
  要在 Replit 应用中使用账户级 Secrets，需先将其关联到应用。
  要关联账户级 Secrets：

  1. 前往 **App Secrets** 标签页。
  2. 选中 Secret 左侧的复选框。
  3. 选择 **Link to this App**。

  要取消关联 Secret：

  1. 前往 **App Secrets** 标签页。
  2. 选择 Secret 旁的 <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" width="16" height="16" alt="三个垂直点图标" data-path="images/icons/vertical-dots.svg" /> 垂直点菜单。
  3. 选择 **Unlink**。
</Accordion>

<Accordion title="删除账户 Secrets">
  1. 选择 Secret 旁的 <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="铅笔图标" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> 铅笔图标。
  2. 选择 **Delete**。
</Accordion>

<div id="section-6">
  ### 管理 Secrets 的可见性
</div>

Secrets 的可见性取决于您对 Replit 应用的访问权限，以及您是否创建了该应用。

您可以通过以下任一方式共享 Replit 应用：

* **Multiplayer**：邀请 Replit 用户实时协作
* **Cover page**：展示 Replit 应用的预览和 Remix 选项
* **Remix**：将个人或组织的 Replit 应用设为公开，让其他人创建自己的版本

下表展示了不同场景下 Secrets 名称和值的可见性：

| 访问方式               | 对象                          | 可查看名称 | 可查看值 |
| ------------------ | --------------------------- | ----- | ---- |
| Multiplayer        | Multiplayer 协作者             | ✓     | ✓    |
| Multiplayer        | 组织成员 (Owner 角色)             | ✓     | ✓    |
| Multiplayer        | 组织成员 (非 Owner)              | ✓     |      |
| Cover Page         | 所有访问者                       |       |      |
| Remix              | Remix 自己 Replit 应用的所有者/协作者  | ✓     | ✓    |
| Remix              | 非所有者/协作者 Remix Replit 应用    | ✓     |      |
| Remix              | 从 cover page 进行 Remix 的所有用户 | ✓     |      |
| Organization Remix | 具有 Owner 角色的组织成员            | ✓     | ✓    |
| Organization Remix | 不具有 Owner 角色的组织成员           | ✓     |      |

<Warning>
  没有 Owner 角色的组织成员无法查看 Replit 应用中的 Secrets 值，但可以通过输出环境变量来获取这些值。
</Warning>

<div id="section-7">
  ## 数据库相关 Secrets
</div>

添加 Replit 数据库后，Project Editor 会自动创建以下 Secrets：

| Secrets             | 说明           |
| -------------- | ------------ |
| `DATABASE_URL` | SQL 数据库连接字符串 |

<Info>
  旧版 Neon 开发数据库可能还包含 `PGHOST`、`PGUSER`、`PGPASSWORD`、`PGDATABASE` 和 `PGPORT`。当前的 Replit 开发数据库则使用 `DATABASE_URL`。
</Info>

要查看 Replit 应用的所有环境变量，请在 Project Editor 的 Shell 工具中运行 `printenv`，或在代码中将其输出。

<div id="section-8">
  ## 预定义环境变量
</div>

Replit 会自动设置以下可供应用访问的环境变量：

| 环境变量                | 说明                                   |
| ------------------- | ------------------------------------ |
| `REPLIT_DOMAINS`    | 与 Replit 应用关联的所有域名，以逗号分隔             |
| `REPLIT_USER`       | 当前编辑者的用户名 (在 Multiplayer 会话中可能有所不同)  |
| `REPLIT_DEPLOYMENT` | 如果代码在已发布的应用中运行，则设为 `1`；否则不设置         |
| `REPLIT_DEV_DOMAIN` | 与部署 URL 不同的 `replit.dev` 域名对应的开发 URL |

这些变量不会显示在 Secrets 工具中，但你可以通过代码中的 `os.environ` 对象访问它们，或在 Shell 中运行 `printenv`。
