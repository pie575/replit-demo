Навыки расширяют возможности Agent: они содержат рекомендуемые шаблоны, особенности библиотек, правила дизайн-системы и решения уже известных вам проблем. Прикрепите навык к сообщению, установите его в проект или выберите в качестве отправной точки для нового проекта.

<div id="use-a-skill-in-chat">
  ## Использование навыка в чате
</div>

Быстрее всего попробовать навыки можно, прикрепив один из них к отдельному сообщению — ничего устанавливать не нужно.

<Frame>
  <img src="/assets/mirror/agent-skills-picker-ee4058454475.png" alt="Выбор навыка, открытый по кнопке + рядом с полем ввода чата, со списком навыков: Ad Creative, AI Recruiter, AI SDR и AI Secretary" width="723" height="529" data-path="images/replitai/agent-skills-picker.png" />
</Frame>

<Steps>
  <Step title="Откройте окно выбора навыков">
    Нажмите кнопку **+** рядом с полем ввода чата и выберите **Use a skill**.
  </Step>

  <Step title="Найдите и выберите навык">
    Просматривайте навыки по категориям — Business &amp; finance, Creative, Research &amp; analysis и другим. Выберите один или несколько навыков, чтобы прикрепить их к сообщению.
  </Step>

  <Step title="Отправьте сообщение">
    Введите свой запрос и отправьте его. Agent применит выбранные навыки только к этому сообщению. Рядом с сообщением появится значок навыка, чтобы вы видели, какие навыки активны.
  </Step>
</Steps>

Например, прикрепите **Stock Analyzer** и попросите Agent подготовить аналитический отчёт по акциям либо прикрепите **Deep Research**, чтобы Agent изучил тему и представил структурированные findings.

<Tip>
  Навыки, прикреплённые в чате, ничего не устанавливают в ваш project. Они сразу доступны в любом project.
</Tip>

<div id="start-a-project-with-a-skill">
  ## Начните проект с навыка
</div>

При создании нового проекта можно выбрать проверенный навык в качестве отправной точки. Agent использует инструкции навыка для создания каркаса проекта.

<Steps>
  <Step title="Откройте меню выбора отправной точки">
    На экране создания нового проекта нажмите **+** и выберите **Use a skill**.
  </Step>

  <Step title="Выберите навык">
    Просмотрите подборку навыков, например **AI SDR**, **SEO Auditor**, **Ad Creative** или **Programmatic SEO**. Выберите тот, который соответствует приложению, которое вы хотите создать.
  </Step>

  <Step title="Опишите своё приложение">
    Расскажите Agent, что вы хотите создать. Agent создаст проект, с самого начала применив шаблоны и соглашения выбранного навыка.
  </Step>
</Steps>

<div id="install-a-skill-in-your-project">
  ## Установите навык в свой проект
</div>

Чтобы Agent использовал навык во всех Conversation проекта, установите его. Установленные навыки хранятся в каталоге `/.agents/skills` вашего проекта и сохраняются между сеансами чата.

<div id="install-from-the-skills-pane">
  ### Установка с панели Skills
</div>

Откройте **панель Skills** в Project Editor и перейдите на вкладку **Discover**, чтобы найти навыки, созданные сообществом. Найдите нужный навык, нажмите **Install** — и он автоматически добавится в ваш проект.

<Frame>
  <img src="/assets/mirror/agent-skills-discover-732b2b0c488a.png" alt="Вкладка Discover с доступными для поиска навыками от сообщества и кнопками установки" width="2542" height="1850" data-path="images/replitai/agent-skills-discover.png" />
</Frame>

Например, при создании сайта-портфолио со сложной анимацией можно установить:

* **GSAP React** — обучает Agent анимации, запускаемой при прокрутке, появлению текста и рисованию SVG-контуров
* **Tailwind design system** — даёт Agent знания о паттернах Tailwind CSS для типографики, отступов и переходов между представлениями
* **Find skills** — обучает Agent находить и устанавливать новые навыки для вас

<Tip>
  Вы также можете устанавливать навыки через [npx skills CLI](https://github.com/vercel-labs/skills):

  ```bash theme={null}
  npx skills <skill> -a replit
  ```
</Tip>

<div id="create-a-skill-from-a-conversation">
  ### Создание навыка на основе разговора
</div>

Самый естественный способ создать навык — обсудить это с Agent. После совместного решения проблемы или изучения новой библиотеки попросите Agent зафиксировать полученные знания:

<AiPrompt>
  Изучи лучшие практики интеграции GSAP с React и создай навык для этого проекта.
</AiPrompt>

Agent использует весь контекст разговора, чтобы создать подробный файл навыка. Это особенно полезно после отладки, когда у вас уже сформировалось общее понимание проблемы.

<div id="write-a-custom-skill">
  ### Создайте пользовательский навык
</div>

Для более сложных сценариев создавайте навыки напрямую в соответствии со [спецификацией Agent Skills](https://agentskills.io/specification). Включите **Показать скрытые файлы** на боковой панели файлов, откройте `/.agents/skills/` и создайте новый файл Markdown. Это даёт полный контроль над тем, что Agent знает и как он себя ведёт.
