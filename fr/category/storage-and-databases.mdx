Grâce aux solutions de stockage flexibles de Replit, vous pouvez rapidement ajouter le stockage de données parfait dont votre application a besoin pour fonctionner. Vous pouvez utiliser la base de données ou le stockage d'objets de Replit pour des applications avec les exigences suivantes, et Agent peut automatiquement configurer et intégrer les deux solutions :

* Un jeu qui doit sauvegarder les informations des joueurs, comme la progression ou les meilleurs scores
* Une plateforme de contenu qui gère des fichiers multimédias

## Quelles sont les options de stockage et de bases de données de Replit

Replit propose les options de stockage de données suivantes :

* **Base de données** : stocke des données structurées telles que des profils d'utilisateurs, des scores de jeu et des catalogues de produits.
  Vous pouvez stocker ou récupérer des données par attributs et relations entre les points de données.

* **Stockage d'application** : stocke des données non structurées telles que des images, vidéos, documents.
  Vous pouvez stocker et récupérer des fichiers volumineux et des données binaires.

### Comparaison du stockage d'application et de la base de données

|                             | Base de données                                       | Stockage d'application                               |
| --------------------------- | :---------------------------------------------------- | :--------------------------------------------------- |
| **Format de données idéal** | Données structurées avec des relations                | Fichiers volumineux (images, vidéos, documents)      |
| **Modèle de données**       | Tables, lignes, colonnes                              | Buckets, fichiers                                    |
| **Langage de requête**      | SQL                                                   | API REST                                             |
| **Clients**                 | Clients et ORM compatibles PostgresSQL                | SDK Replit et bibliothèques client GCS               |
| **Modèle de facturation**   | Payer pour le temps de calcul et l'espace de stockage | Payer pour la bande passante et l'espace de stockage |

## Cas d'usage

Les exemples suivants montrent comment les outils de base de données et de stockage d'objets peuvent soutenir vos applications Replit.

### Application e-commerce

Stockez les informations sur les produits, les profils clients et l'historique des commandes dans la base de données.
Utilisez des requêtes SQL pour filtrer les produits par catégorie, rechercher des articles et gérer les commandes clients.
