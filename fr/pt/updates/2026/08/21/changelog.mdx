<div id="agent">
  ## Agent
</div>

<div id="use-o-modo-free">
  ### Utiliser le mode Free
</div>

Utilisez le mode Free pour discuter, explorer des idées, créer et développer sans utiliser de crédits Power ou Max. Le mode Free utilise Auto pour sélectionner un modèle, et ses limites dépendent de votre forfait. Consultez **Paramètres** &gt; **Utilisation** pour connaître votre quota restant et l’heure de réinitialisation.

</Frame>

Découvrez comment [tirer le meilleur parti du mode Free](/fr/pt/chat/free-mode).

<div id="comece-com-conversas">
  ### Commencez avec Conversations
</div>

Commencez par une Conversation privée pour poser des questions, explorer des informations, ajouter du contexte, exécuter une routine ou décrire le résultat souhaité. Lorsque le travail prend de l’ampleur, demandez à Replit de transformer la Conversation en projet. Votre contexte et vos fichiers sont conservés.

</Frame>

En savoir plus sur [Conversations](/fr/pt/chat/conversations).

<div id="automatize-trabalho-recorrente-com-rotinas">
  ### Automatisez les tâches récurrentes avec les Routines
</div>

Planifiez Replit pour répéter une tâche dans une conversation. Chaque résultat est renvoyé dans la même conversation, où vous pouvez l’examiner et poursuivre votre travail. Les Routines s’exécutent en mode Power ou en mode Max et nécessitent un budget pour chaque exécution.

</Frame>

En savoir plus sur les [Routines](/fr/pt/chat/routines).

<div id="direcione-o-agent-enquanto-ele-trabalha">
  ### Dirigez Agent pendant qu’il travaille
</div>

Envoyez un message de suivi pendant qu’Agent travaille afin d’ajouter du contexte au tour actif. Diriger est le comportement par défaut dans Conversations et Projets, mais vous pouvez définir l’une ou l’autre de ces préférences sur Mettre en file d’attente dans **Paramètres** &gt; **Personnalisation**. Appuyez sur `Cmd+Enter` sur Mac ou `Ctrl+Enter` sur Windows et Linux pour utiliser le comportement inverse pour un message donné.

<Frame caption="Choisissez indépendamment Diriger ou Mettre en file d’attente pour Conversations et Projets.">
  <img src="/assets/mirror/agent-follow-ups-settings-98a4c5ca399e.png" alt="Paramètres d’Agent affichant le comportement d’envoi pour Conversations et Projets, avec les options Diriger et Mettre en file d’attente" width="3048" height="1372" data-path="images/replitai/agent-follow-ups-settings.png" />
</Frame>

En savoir plus sur [la façon de diriger et de mettre les messages en file d’attente](/fr/pt/features/agent/steer-and-queue-messages).

<div id="importe-skills-do-github">
  ### Importez des compétences depuis GitHub
</div>

Importez des compétences depuis un dépôt, un dossier ou l’URL d’un fichier GitHub public, puis prévisualisez les fichiers de la compétence avant de les ajouter. Les compétences de projet enregistrées prennent également en charge les niveaux d’accès des membres **Required**, **Available** ou **No access**.

</Frame>

En savoir plus sur [le partage et l’importation des compétences d’Agent](/fr/pt/features/agent/skills#share-project-skills).

  ## Teams et Enterprise

<div id="controle-os-modelos-do-agent-entre-workspaces">
  ### Contrôlez les modèles d’Agent dans les Workspaces
</div>

Les administrateurs de comptes Enterprise peuvent définir une politique de compte pour chaque fournisseur de modèles, puis choisir les modèles disponibles dans chaque Workspace. Utilisez **Enable all**, **Enable selected** ou **Disabled** pour les adapter à la politique de votre organisation.

<div id="execute-testes-de-penetrao-black-box">
  ### Exécutez des tests d’intrusion en boîte noire
</div>

Exécutez une analyse de sécurité Level 3 qui combine trois vérifications. Elle effectue gratuitement des vérifications des dépendances et des paquets, une analyse statique de votre code source par Agent et un test externe en boîte noire du Preview actif. Replit exécute en parallèle la revue du code source et le test externe.

</Frame>

En savoir plus sur les [tests d’intrusion en boîte noire](/fr/pt/features/security/black-box-pen-tests).
