O Model Context Protocol (MCP) é um padrão aberto para conectar produtos de IA a ferramentas e fontes de dados. Ele é distinto das integrações nativas do Replit, mas pode estender as ferramentas disponíveis enquanto você trabalha em uma Conversa.

## Escolha a direção da conexão

* **Conectar o Replit a uma ferramenta externa:** Adicione um servidor MCP selecionado ou personalizado para que o Replit possa usar as ferramentas que ele fornece. Conecte apenas servidores em que você confia.
* **Usar o Replit a partir de um cliente MCP:** Conecte um cliente compatível ao Replit MCP Server para criar, encontrar, inspecionar ou atualizar Replit Apps a partir desse cliente.

O MCP é distinto das integrações nativas e das [Skills](/pt/chat/agent-skills). As integrações oferecem conexões com serviços suportados. As Skills oferecem instruções reutilizáveis e material de apoio. O MCP estende as ferramentas disponíveis por meio do protocolo.
