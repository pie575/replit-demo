Выберите подходящий тариф для вашей организации. **Pro** — тариф для команд: до 15 разработчиков, общий пул кредитов и без платы за места. **Enterprise** предлагает расширенные возможности безопасности, соответствия требованиям и поддержки для крупных организаций. Если у вас несколько организаций Teams, каждое рабочее пространство будет перенесено на отдельную подписку Pro до конца текущего срока; после переноса вы сможете их объединить.

<div id="pro">
  ## Pro
</div>

Pro предоставляет общие ресурсы и инструменты совместной работы для профессиональных разработчиков и команд:

* **До 15 разработчиков**: без платы за каждое место — все работают в рамках одного тарифа с общим пулом credits
* **Многоуровневые credits**: несколько уровней. Неиспользованные credits переносятся на {ProCreditRolloverPeriod}. Актуальные уровни смотрите на [странице тарифов](https://replit.com/pricing)
* **Параллельные задачи Agent**: одновременный запуск до 10 задач Agent
* **Private Deployments**: безопасный хостинг приложений с контролируемым доступом
* **Места Viewer**: возможность для заинтересованных лиц и не-разработчиков пользоваться опубликованными приватными приложениями
* **Единые настройки**: организуйте приложения, отслеживайте использование по каждому рабочему пространству и управляйте оплатой и пользователями в одном месте

<div id="enterprise">
  ## Enterprise
</div>

Enterprise включает все возможности Pro, а также расширенные возможности безопасности, управления и поддержки для организаций:

<CardGroup cols={2}>
  <Card title="Безопасность Enterprise" icon="shield-check">
    Платформа, соответствующая требованиям SOC 2, с SSO/SAML, подготовкой пользователей через SCIM и расширенными средствами управления безопасностью.
  </Card>

  <Card title="Централизованное управление" icon="folder-open">
    Управляйте командами, оплатой и ресурсами с единого дашборда. Отслеживайте использование и эффективно контролируйте расходы.
  </Card>
</CardGroup>

* **SSO/SAML с подготовкой пользователей через SCIM**: Защитите доступ команды с помощью единого входа и автоматической подготовки пользователей
* **Выделенная среда разработки**: Управление доступом на основе ролей и групп IDP для детальной настройки разрешений
* **Средства администрирования**: Требуйте использования Private Deployments и обязательного статического сканирования безопасности перед публикацией
* **Центр безопасности рабочего пространства**: Выявляйте CVE в зависимостях по степени серьезности. Просматривайте затронутые приложения и скачивайте SBOM для соответствия требованиям.
* **Настраиваемые разрешения для интеграций**: Определяйте границы доступа к собственным интеграциям во всей организации
* **Более мощные ВМ для развёртываний**: Используйте ВМ увеличенного размера для масштабируемого хостинга приложений
* **Выделенная поддержка**: Обращайтесь к персональному менеджеру по работе с клиентами и инженеру по продажам за поддержкой по вопросам платформы
* **Корпоративные коннекторы данных**: Подключайтесь к Snowflake, BigQuery и Databricks для бесшовной интеграции данных
* **Неограниченное количество мест Viewer**: Предоставляйте заинтересованным сторонам и пользователям, не являющимся разработчиками, неограниченный доступ к опубликованным частным приложениям

<div id="use-cases">
  ## Сценарии использования
</div>

Pro и Enterprise отвечают разнообразным потребностям организаций любого масштаба:

* **Корпоративные приложения**: Создавайте и публикуйте критически важные приложения с безопасностью и возможностями масштабирования корпоративного уровня
* **Бизнес-инструменты**: Разрабатывайте и поддерживайте бизнес-инструменты с удобным управлением доступом
* **Быстрое прототипирование**: Ускоряйте внедрение инноваций благодаря мгновенно доступным средам разработки
