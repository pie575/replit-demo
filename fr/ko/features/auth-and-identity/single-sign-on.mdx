<Note>
  Vous souhaitez imposer le SSO pour une **organisation Replit** (connexion à replit.com) ? Cette configuration est distincte — consultez [l’authentification unique (SAML SSO)](/fr/ko/teams/identity-and-access-management/saml). Cette page explique comment ajouter le SSO au flux de connexion des **applications créées** sur Replit.
</Note>

Permettez aux utilisateurs de se connecter à votre application à l’aide d’un fournisseur d’identité d’entreprise tel qu’Okta ou Microsoft Entra ID. Si votre application utilise [Clerk Auth](/fr/ko/features/auth-and-identity/clerk-auth), configurez le SSO et d’autres fonctionnalités d’authentification avancées dans le tableau de bord Clerk. Demandez à Agent ce dont vous avez besoin, et il vous guidera vers le tableau de bord où finaliser la configuration.

  <img src="/assets/mirror/sso-cover-28a76bfa16fb.jpeg" alt="Bannière sur la création d’une application Replit avec le SSO, montrant une icône de cadenas et un créateur travaillant sur un ordinateur portable." width="1920" height="1080" data-path="images/workspace/auth/sso-cover.jpeg" />
</Frame>

Le tableau de bord Clerk offre des fonctionnalités qui vont bien au-delà de l’expérience de connexion par défaut. Les configurations définies dans Clerk s’appliquent automatiquement à l’authentification de votre application Replit.

<div id="section">
  ## Éléments configurables
</div>

* **Connexion SSO Enterprise** : configurez l’authentification unique avec Okta ou Microsoft Entra ID à l’aide d’OIDC ou de SAML. Permettez aux utilisateurs de se connecter via le fournisseur d’identité de leur entreprise. Le SSO remplace les listes d’adresses e-mail autorisées manuellement par le fournisseur d’identité existant de l’entreprise et protège également les outils internes qui traitent des données sensibles.
* **Authentification multifacteur (MFA)** : ajoutez l’authentification MFA au flux de connexion de votre application.
* **Contrôle des sessions** : ajustez la durée des sessions et la fréquence d’authentification.
* **Autres paramètres Clerk** : les configurations Clerk supplémentaires sont automatiquement appliquées à votre application Replit. Ne modifiez pas les clés API ni les paramètres d’environnement — Replit les gère. Consultez les [environnements de développement et de production](/fr/ko/features/auth-and-identity/clerk-auth#development-and-production-environments).

<div id="clerk">
  ## Ouvrir le tableau de bord Clerk
</div>

Demandez à Agent d’effectuer les modifications d’authentification nécessaires. Agent configure les éléments qu’il peut prendre en charge et vous redirige vers le tableau de bord Clerk de votre application pour les configurations nécessitant votre intervention.

<Frame>
  <img src="/assets/mirror/build-with-sso-agent-workflow-46422788bd18.webp" alt="Agent vous guide vers le tableau de bord Clerk pour configurer le SSO Enterprise pour une application basée sur Clerk." width="1602" height="1080" data-path="images/workspace/auth/build-with-sso-agent-workflow.webp" />
</Frame>

Vous pouvez également ouvrir le tableau de bord depuis Workspace.

1. Dans le panneau Tools, sélectionnez **Users &amp; Auth**.
2. Sélectionnez l’onglet **Configure**.
3. Sélectionnez **avancé**.
4. Sous **Clerk dashboard**, sélectionnez **Open Clerk dashboard**.

<Frame>
  <img src="/assets/mirror/open-clerk-dashboard-tools-pane-a314ffea741d.webp" alt="Outil Users & Auth avec l’onglet Configure ouvert, affichant la section avancé et le bouton Open Clerk dashboard." width="2158" height="1372" data-path="images/workspace/auth/open-clerk-dashboard-tools-pane.webp" />
</Frame>

<div id="sso">
  ## Configurer une connexion SSO Enterprise
</div>

1. Dans le tableau de bord Clerk, sélectionnez **Configure**.
2. Sous **User &amp; authentication**, sélectionnez **SSO connections**.
3. Sélectionnez **Enterprise**.
4. Sélectionnez **Add connection**.

<Frame>
  <img src="/assets/mirror/build-with-sso-enterprise-connections-b0a6a27885b5.webp" alt="Tableau de bord Clerk affichant la page Enterprise SSO connections et l’action Add connection." width="1826" height="1080" data-path="images/workspace/auth/build-with-sso-enterprise-connections.webp" />
</Frame>

Pour obtenir des instructions complètes sur la configuration d’une connexion, consultez la [documentation de Clerk](https://clerk.com/docs).

<div id="section-2">
  ### Vérifier la connexion
</div>

Une fois la configuration terminée, connectez-vous avec un compte de test de votre fournisseur d’identité. Vérifiez que ce compte peut accéder aux sections prévues de l’application.

Si la connexion échoue, demandez de l’aide à Agent. Indiquez le fournisseur d’identité, le protocole et le message d’erreur dans votre demande.

<Note>
  Cette page traite du SSO Enterprise pour le flux de connexion propre à l’application. Pour la connexion sociale via Google, GitHub, Apple et X, affichés comme **fournisseurs SSO** dans le Workspace, consultez les [fournisseurs de connexion](/fr/ko/features/auth-and-identity/sign-in-providers). Cette page ne traite ni de la migration de Replit Auth ni de la connexion SAML pour les comptes Replit.
</Note>

<div id="section-3">
  ## Tarification et disponibilité
</div>

L&#39;accès au tableau de bord Clerk est inclus dans le plan [Replit Pro](/fr/ko/billing/plans/replit-pro). Le plan Enterprise sera bientôt disponible.

<Info>
  Les connexions SSO Enterprise sont gratuites jusqu&#39;au 1er octobre 2026. Par la suite, la tarification du SSO sera alignée sur celle de Clerk et figurera sur votre facture Replit.
</Info>
