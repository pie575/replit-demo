      <Accordion title="在哪里可以获得代码方面的帮助？">
        获取代码帮助的最佳方式是使用 [Replit AI](/zh/ko/build/welcome/)。在项目编辑器中打开新标签页，然后搜索 **AI**。Replit AI 可以帮你设置新项目、解答代码相关问题，并协助你梳理思路。如需更多帮助，也可以前往[社区中心](https://replit.com/community)查看更多资源。
      </Accordion>

      <Accordion title="使用 Replit 时遇到问题？如何获取帮助？">
        登录 Replit，然后点击页面右上角的 **?** 获取帮助。如需进一步支持，请参阅[支持政策文档](/zh/ko/legal-and-security-info/support-policy)。
      </Accordion>

      <Accordion title="在哪里可以获得账单相关帮助？">
        联系支持团队前，请先查看下方的**设置**是否能帮您解决问题。如果仍无法解决，请登录后点击页面右上角的**?**获取帮助。
      </Accordion>

      <Accordion title="无法访问 Replit 账户，该怎么办？">
        请发送电子邮件至 `support@replit.com`，并注明您的账户用户名和登录 ID。
      </Accordion>

      <Accordion title="何时能收到 Replit 的回复？">
        Replit 支持团队通常在美国东部标准时间 (UTC-5) 周一至周五上午 9 点至晚上 8 点提供服务。
      </Accordion>

      <Accordion title="如何在 Replit 应用中恢复文件夹？">
        前往 Replit 应用右上角的个人资料标识，选择 **CLUI**，然后在出现的搜索框中输入 &#95;restore&#95; 进行搜索。在搜索结果中，您会看到可从回收站恢复特定文件夹的 **restore-folder** 选项。

        > 注意：已删除的 Replit 应用将在原删除日期后的 **30 天**永久删除，且无法恢复。
      </Accordion>

      <Accordion title="如何恢复已删除的 Replit 应用？">
        前往 Replit 应用右上角的个人资料图标，选择 **CLUI**，然后在出现的搜索框中输入 &#95;restore&#95; 进行搜索。在搜索结果中，您会看到 **restore-repl** 选项，可用于从回收站恢复特定的 Replit 应用。

        > 注意：已删除的 Replit 应用会在原始删除日期后的 **30 天**被永久删除，且无法恢复。
      </Accordion>

      <Accordion title="为什么 Replit 应用无法加载？">
        如果 Replit 应用无法加载，请尝试以下排查步骤：

        1. 测试您的[网络连接](https://www.speedtest.net/)。
        2. 尝试使用其他浏览器。
        3. 确认浏览器中已启用 JavaScript。
        4. 使用 `Cmd+K`(Mac) 或 `Ctrl+K`(Windows) 打开命令面板，搜索并选择 **Restart compute**。

        如果以上步骤仍无法解决问题，请查看 Replit 的[服务状态](https://status.replit.com)。如果状态显示为 **所有系统运行正常！**，但您仍无法加载 Replit 应用，请联系 [Replit 支持团队](https://replit.com/support)。
      </Accordion>

      <Accordion title="如何将大文件上传到 Replit 应用？">
        如果文件太大，无法通过标准 GUI 上传，您可以通过 [SSH](/zh/ko/features/workspace-tools/ssh) 使用 `scp` (安全复制) 在本地和远程系统之间安全传输文件。要将文件从本地机器复制到远程机器，请使用以下语法：`scp filename username@ip_address:/home/username`

        您也可以使用 `scp` 复制整个目录。
      </Accordion>

      <Accordion title="如何查看使用量积分余额？">
        您可以在[https://replit.com/~/cli/account/usage-credits-balance](https://replit.com/~/cli/account/usage-credits-balance)查看当前余额。
      </Accordion>

  <Tab title="账户">
    <AccordionGroup>
      <Accordion title="登录遇到问题？该怎么办？">
        1. 确认你使用的是正确的电子邮件地址和密码。
        2. 如需重设密码，请前往[找回密码页面](https://replit.com/forgot)。检查垃圾邮件文件夹中是否有来自 `notifications@replit.com` 的密码重设邮件。
        3. 尝试使用其他浏览器登录。

        如果尝试以上所有步骤后仍无法登录，请[联系支持团队](https://replit.com/support)。
      </Accordion>

      <Accordion title="如果通过 Google/GitHub/Facebook/Apple 注册，如何更改电子邮件地址？">
        更改账户的电子邮件地址需要密码。如果你通过 Google 或 GitHub 等第三方身份验证提供商注册，则必须先创建密码。

        创建密码的步骤如下：

        1. 打开侧边栏并退出登录。
        2. 返回登录页面，选择[找回密码](https://replit.com/forgot)，然后输入你的电子邮件地址。
        3. 你将收到一封包含创建新密码链接的电子邮件。如果未收到邮件，请检查垃圾邮件文件夹，并最多等待 30 分钟。
        4. 登录后，打开[设置](https://replit.com/settings)以更改电子邮件地址。
      </Accordion>

      <Accordion title="如何更改用户名？">
        Replit 用户只能更改用户名**一次**。前往 [CLUI](https://replit.com/~/cli/account/change-username?run=1)，然后选择 **change-username**。如果此选项不可用，说明你此前已经更改过用户名。
      </Accordion>

      <Accordion title="什么是 Explorer 模式？如何启用？">
        Explorer 是指选择查看和测试仍在开发中新功能的 Replit 用户。要启用 Explorer 模式，请打开[设置](https://replit.com/settings)，并开启 Explorer 开关 (例如，在**账户**或**用户**下方) 。
      </Accordion>
    </AccordionGroup>
