<div id="os-templates-de-developer-frameworks-foram-removidos">
  ## developer frameworks 模板已移除
</div>

语言和框架的入门模板 (此前称为 developer frameworks) 已不再在 Replit 上提供。`replit.com/templates` 和 `replit.com/developer-frameworks` 页面现在会重定向至 [Replit Gallery](https://replit.com/gallery)。

要开始新项目，请使用以下方式之一：

* **从 Replit Agent 开始** — 在[首页](https://replit.com/)描述你想构建的内容，让 Agent 为你搭建项目框架。
* **[从 GitHub、GitLab 或 Bitbucket 导入](/zh/pt/build/import-from-providers)** — 将现有代码库或初始技术栈导入为新的 Replit App。
* **[对已发布的应用进行 remix](https://replit.com/gallery)** — 在 Replit Gallery 中浏览社区应用，预览后以其为起点进行 remix。

<div id="templates-personalizados-para-enterprise">
  ## Enterprise 自定义模板
</div>

Enterprise 组织可以创建[自定义模板](/zh/pt/teams/custom-templates)，供组织内所有成员在 Agent 收件箱中选用。自定义模板不只是 developer frameworks，还包含企业专属的 Agent 指令、skills 以及预先配置好的项目上下文。更多详情请参阅[自定义模板指南](/zh/pt/teams/custom-templates)。
