Cette technologie de streaming vous permet d&#39;utiliser des applications héritées dans le navigateur de n&#39;importe quel appareil ! Par exemple, vous pouvez exécuter directement sur un téléphone ou une tablette un jeu Python conçu pour ordinateur de bureau, sans modifier le code existant.

<div id="vnc">
  ## Utiliser VNC
</div>

Toutes les applications Replit peuvent utiliser un bureau virtuel, quel que soit le langage utilisé. Aucune modification n’est nécessaire pour exécuter des programmes graphiques natifs sur Replit. Le panneau VNC s’affiche automatiquement lorsqu’une application tente d’ouvrir une fenêtre de bureau native.

<div id="replit">
  ## Sécuriser les applications Replit
</div>

Par défaut, les connexions VNC ne sont pas protégées par mot de passe et reposent sur l’authentification WebSocket. Elles ne sont donc accessibles que [depuis https://replit.com](https://replit.com에서만). Si vous devez accéder à une application Replit via un client [noVNC](https://novnc.com) externe, vous pouvez définir un mot de passe VNC.

Définissez un mot de passe dans les paramètres des [Secrets](/fr/ko/core-concepts/project-editor/app-setup/secrets) de votre application Replit. Les `Secrets` permettent de stocker des informations de façon sécurisée, sans risquer que d’autres utilisateurs accèdent au mot de passe. La définition de `VNC_PASSWORD` renforce la sécurité des connexions à distance.

<div id="vnc-2">
  ## Utiliser VNC en plein écran
</div>

Pour suivre les étapes ci-dessous, vous devez sécuriser votre application Replit en suivant les instructions ci-dessus.

1. Dans l’onglet « Shell », exécutez la commande suivante :
   ```sh theme={null}
   echo $REPL_ID
   ```

<Frame>
  <img src="/assets/mirror/replid-6508492b1e8b.png" alt="Image montrant la commande echo" width="628" height="174" data-path="images/vnc/replid.png" />
</Frame>

2. Remplacez `REPL_ID` par la valeur affichée ci-dessus pour former l’URL de connexion : `<\REPL_ID\>.id.repl.co`
3. Dans un autre onglet du navigateur, ouvrez le [client noVNC](https://novnc.com/noVNC/vnc.html).
4. Ouvrez les paramètres de connexion.

<Frame>
  <img src="/assets/mirror/settings-3e0e0c4fd198.png" alt="Ouvrir les paramètres de connexion" width="126" height="302" data-path="images/vnc/settings.png" />
</Frame>

5. Développez la section WebSockets. Saisissez l’URL de connexion (`\<REPL_ID\>.id.repl.co`) dans le champ `host` et laissez le champ `path` vide.

<Frame>
  <img src="/assets/mirror/host-31b5c99194b2.png" alt="host" width="214" height="230" data-path="images/vnc/host.png" />
</Frame>

6. Réglez `Scaling Mode` sur `Remote Resizing` :

<Frame>
  <img src="/assets/mirror/scaling-0ffe9aae34bb.png" alt="scaling" width="147" height="74" data-path="images/vnc/scaling.png" />
</Frame>

7. Si des identifiants vous sont demandés, utilisez le nom d’utilisateur `runner` et le mot de passe défini ci-dessus.
