SEO Agent проводит технический SEO-аудит вашего проекта и выявляет проблемы, которые мешают поисковым системам и AI-краулерам находить и понимать ваше приложение. Каждая находка превращается в исправление в один клик, которое вы можете просмотреть и применить с помощью Agent.

Он находится на панели **Growth** в Project Editor и работает с приложениями, которые вы уже опубликовали. Для большинства пользователей порядок работы такой: опубликовать приложение, открыть SEO Agent, запустить сканирование, просмотреть найденные проблемы и применить исправления.

<div id="what-seo-agent-does">
  ## Что делает SEO Agent
</div>

SEO Agent занимается **технической оптимизацией (SEO)** — теми структурными и машиночитаемыми частями вашего приложения, от которых зависит, насколько легко поисковые системы и ИИ-краулеры смогут его найти, проиндексировать и понять.

Он анализирует ваш project и предлагает исправления для таких проблем, как:

* **Сканируемость и индексация**: `robots.txt`, `sitemap.xml`, а также доступная для сканирования структура страниц и ссылок.
* **Метаданные страниц**: уникальные, содержательные теги `<title>` и метаописания на каждой странице.
* **Структурированные данные**: разметка JSON-LD, которая помогает поисковым системам показывать расширенные результаты.
* **Open Graph и теги для соцсетей**: метаданные, определяющие, как выглядит предпросмотр ваших ссылок при публикации.
* **Семантическая разметка**: правильный порядок заголовков, элементы-ориентиры и содержательный текст `alt` для изображений.

<Note>
  SEO Agent следит за тем, чтобы созданное вами приложение было технически исправным с точки зрения поиска,
  но не пишет за вас контент и не выстраивает тематический авторитет.
</Note>

<div id="before-you-start">
  ## Прежде чем начать
</div>

Для работы SEO Agent необходимо:

* **Опубликованное приложение.** SEO Agent проверяет работающий публичный веб-deployment, поэтому сначала опубликуйте приложение, если ещё не сделали этого. Типы deployment, поддерживающие SEO, перечислены в разделе [SEO-рейтинг](/ru/features/publishing/seo-rating).
* **Платный тарифный план.** SEO Agent доступен создателям на платном плане. Если вы на бесплатном плане, в панели Growth появится предложение перейти на платный.

Открыть SEO Agent можно двумя способами: напрямую перейти в панель **Growth** в Project Editor или нажать **Optimize SEO with Agent** рядом с SEO-рейтингом в инструменте **Publishing** — откроется панель Growth, готовая к сканированию.

<Tip>
  Чтобы управлять тем, как ваше приложение выглядит при публикации ссылок в соцсетях, подключите
  [собственный домен](/ru/build/add-custom-domain) и опубликуйте приложение заново. Превью в соцсетях и
  превью ссылок используют публичный production-URL вашего приложения, поэтому опубликованный
  собственный домен обеспечивает корректные превью.
</Tip>

<div id="seo-agent-and-your-seo-rating">
  ## SEO Agent и ваш SEO-рейтинг
</div>

**SEO-рейтинг**, который отображается рядом с SEO Agent, формируется по результатам автоматического [аудита Lighthouse](/ru/features/publishing/seo-rating). Он запускается после каждой публикации и оценивает приложение как Healthy, Needs Work или Weak. Рейтинг показывает, *в каком состоянии находится ваше приложение*.
SEO Agent помогает *улучшить его*: находит проблемы и применяет исправления. Повторная публикация после исправлений обновляет рейтинг.

Можно и вовсе обойтись без интерфейса сканирования — просто обратитесь к Agent напрямую:

<AiPrompt>
  Проверь мой сайт на соответствие лучшим практикам SEO и примени исправления.
  Добавь карту сайта, robots.txt, теги Open Graph, структурированные данные там,
  где это уместно, и убедись, что у каждой страницы есть уникальный заголовок и
  метаописание.
</AiPrompt>
