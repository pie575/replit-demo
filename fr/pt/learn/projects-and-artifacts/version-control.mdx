Le contrôle de version dans Replit vous permet de suivre, de gérer et de modifier votre code en collaboration avec d&#39;autres en toute confiance. Grâce à l&#39;intégration de Git et à la connectivité avec GitHub, vous pouvez :

* Suivre les modifications apportées au code et conserver l&#39;historique de votre travail de développement
* Collaborer avec les membres de votre équipe sans conflits de code ni perte de travail
* Importer, modifier et envoyer du code entre Replit et GitHub
* Travailler avec des branches pour tester de nouvelles fonctionnalités en toute sécurité

<div id="o-que-controle-de-verso">
  ## Qu’est-ce que le contrôle de version ?
</div>

Le contrôle de version est un système qui enregistre les modifications apportées aux fichiers au fil du temps, ce qui vous permet de restaurer ultérieurement des versions spécifiques. Dans Replit, le contrôle de version s’appuie sur Git — l’outil de référence du secteur pour suivre les modifications de code — et sur une interface visuelle intuitive qui évite d’avoir à utiliser la ligne de commande.

<div id="como-o-controle-de-verso-funciona-no-replit">
  ### Comment fonctionne le contrôle de version dans Replit
</div>

Les quatre options de contrôle de version reposent sur le même dépôt Git sous-jacent :

1. Les **checkpoints d’Agent** créent automatiquement des commits à des étapes clés lorsque vous développez avec [Replit Agent](/fr/pt/features/agent/overview). [En savoir plus sur les checkpoints et les restaurations](/fr/pt/features/version-control/checkpoints-and-rollbacks).
2. Le **panneau Git** offre un accès visuel à l’ensemble du dépôt Git
3. La **CLI Git** donne accès en ligne de commande à toutes les fonctionnalités de Git
4. L’**historique des fichiers** suit les modifications détaillées au sein de chaque fichier

Choisissez l’interface qui répond le mieux à vos besoins, en sachant que toutes reposent sur le puissant système de contrôle de version de Git.

| Fonctionnalité                  | Checkpoints d’Agent                                      | Commits Git                                              | Historique des fichiers              |
| ------------------------------- | -------------------------------------------------------- | -------------------------------------------------------- | ------------------------------------ |
| **Création**                    | Automatique à des étapes clés                            | Manuelle ou planifiée                                    | Automatique                          |
| **Granularité**                 | Modifications au niveau des fonctionnalités              | Modifications de toute taille                            | Modifications au niveau du caractère |
| **Description**                 | Résumés générés par IA                                   | Messages rédigés par l’utilisateur                       | Horodatages automatiques             |
| **Restauration**                | Restauration en un clic                                  | Nécessite des connaissances de Git                       | Restauration en un clic              |
| **Fonctionnalités Git**         | Fonctionnalités Git complètes                            | Fonctionnalités Git complètes                            | Aucune fonctionnalité Git            |
| **Synchronisation avec GitHub** | Fonctionnalités complètes de synchronisation avec GitHub | Fonctionnalités complètes de synchronisation avec GitHub | Aucune synchronisation avec GitHub   |

<div id="primeiros-passos">
  ## Premiers pas
</div>

Accédez au contrôle de version dans votre Replit App en ajoutant l&#39;outil Git à l&#39;Éditeur de projet :

1. Rendez-vous dans la section Outils de votre Replit App
2. Sélectionnez le signe **+** pour ajouter de nouveaux outils
3. Sélectionnez **Git** dans la liste des outils disponibles

Pour importer des projets existants depuis GitHub, consultez [Importer depuis GitHub](/fr/pt/build/import-from-providers).

<div id="controle-de-verso-automtico">
  ### Contrôle de version automatique
</div>

<Accordion title="checkpoints d’Agent">
  Instantanés automatiques créés pendant le développement assisté par IA avec [Replit Agent](/fr/pt/features/agent/overview).

  **Idéal pour** : le développement avec Replit Agent

  **Principales fonctionnalités** :

  * Création automatique à des jalons logiques
  * Restauration en un clic
  * Instantanés au niveau des fonctionnalités
  * Suivi de la progression
  * Aucune configuration requise
  * Chronologie visuelle de la progression du développement

  Les checkpoints d’Agent sont stockés dans Git et accessibles depuis le panneau Git ou la CLI Git. Vous pouvez également afficher tous vos checkpoints à l’aide de la fonctionnalité Historique, qui offre :

  * Vue chronologique des checkpoints
  * Descriptions détaillées des checkpoints
  * Accès direct aux états des checkpoints
  * Restauration en un clic vers n’importe quel checkpoint
</Accordion>

<Accordion title="Historique des fichiers">
  Suivi des versions par fichier avec enregistrement automatique des modifications effectuées directement dans l’éditeur, hors Agent.

  **Idéal pour** : récupérer rapidement des modifications récentes dans des fichiers

  **Principales fonctionnalités** :

  * Focus sur un seul fichier
  * Modifications au niveau des caractères
  * Comparaison visuelle
  * Historique de 30 jours
  * Fonctionnalité de relecture

  Bien que l’Historique des fichiers dispose de sa propre interface, les modifications sous-jacentes font partie de l’historique Git. En savoir plus sur l’[Historique des fichiers](/fr/pt/features/version-control/file-history).
</Accordion>

  ### Interfaces Git

<Accordion title="Panneau Git">
  Une interface visuelle pour les opérations Git qui rend le contrôle de version accessible sans connaissances en ligne de commande.

  **Idéal pour** : la plupart des projets nécessitant une intégration à GitHub et un flux de travail visuel

  **Principales fonctionnalités** :

  * Suivi de l&#39;ensemble du dépôt
  * Gestion des branches
  * Visualisation des diffs
  * Synchronisation avec GitHub en un clic
  * Collaboration en équipe

  Pour obtenir des instructions détaillées sur l&#39;utilisation du panneau Git, consultez [Utiliser le panneau Git](/fr/pt/features/workspace-tools/git-interface).
</Accordion>

<Accordion title="Git CLI">
  Accès complet à Git en ligne de commande via le [Shell](/fr/pt/features/workspace-tools/shell) pour les opérations avancées.

  **Idéal pour** : les utilisateurs avancés qui ont besoin de toutes les fonctionnalités Git

  **Principales fonctionnalités** :

  * Ensemble complet de commandes Git
  * Stratégies avancées de gestion des branches
  * Flux de travail personnalisés
  * Automatisation par scripts
  * Contrôle complet du dépôt

  Pour découvrir les commandes Git courantes et leur utilisation, consultez [Utiliser le panneau Git](/fr/pt/features/workspace-tools/git-interface#using-git-commands-in-shell).
</Accordion>

<div id="recursos-principais">
  ## Fonctionnalités principales
</div>

* **Interface Git visuelle** : gérez les dépôts, les commits et les branches sans saisir de commandes Git
* **Intégration GitHub** : connectez-vous à des dépôts GitHub pour la sauvegarde et la collaboration
* **Importer depuis GitHub** : transformez n’importe quel [dépôt GitHub en Replit App](/fr/pt/build/import-from-providers) en quelques clics
* **Gestion des branches** : créez, changez de branche et fusionnez des branches directement dans l’éditeur de projet
* **Résolution des conflits** : identifiez et résolvez les conflits de fusion avec une assistance visuelle

<div id="casos-de-uso">
  ## Cas d&#39;utilisation
</div>

**Suivi de vos projets personnels**

Suivez les modifications apportées à votre code au fil de son développement et revenez à des versions antérieures si nécessaire. Le [panneau Git](/fr/pt/features/workspace-tools/git-interface) affiche vos modifications de manière visuelle, ce qui facilite la validation des mises à jour importantes.

**Collaboration en équipe**

Travaillez à plusieurs sur le même code sans écraser les modifications des autres. Créez des branches pour les nouvelles fonctionnalités, puis fusionnez-les lorsqu&#39;elles sont prêtes. Découvrez comment [inviter des collègues](/fr/pt/build/invite-teammates).

<div id="checkpoints-do-agent">
  ## Checkpoints d’Agent
</div>

Lorsque vous créez des applications avec [Replit Agent](/fr/pt/features/agent/overview), vous bénéficiez d’une couche supplémentaire de contrôle de version grâce aux checkpoints. Les checkpoints capturent automatiquement l’état complet de votre projet — y compris son contenu, le contexte des conversations avec l’IA et les bases de données connectées — à des moments clés du développement assisté par IA.

  <img src="/assets/mirror/checkpoints-9927e500693a.jpg" alt="Checkpoints d’Agent dans le panneau Git" width="1920" height="1080" data-path="images/workspace/checkpoints.jpg" />
</Frame>

<div id="como-os-checkpoints-funcionam">
  ### Fonctionnement des checkpoints
</div>

Les checkpoints d’Agent sont des instantanés complets de l’état de votre Replit App :

* **Création automatique** : l’Agent crée des checkpoints à des étapes clés du développement
* **Capture de l’état complet** : chaque checkpoint préserve le contenu du projet, la mémoire de l’IA et l’état de la base de données
* **Plans de mise en œuvre** : avant d’apporter des modifications, l’Agent vous présente un plan pour validation
* **Suivi des tâches complexes** : plusieurs checkpoints peuvent être créés pour les tâches plus importantes

<div id="benefcios-para-o-desenvolvimento-assistido-por-ia">
  ### Avantages du développement assisté par IA
</div>

Les checkpoints d’Agent offrent des avantages uniques lorsque vous développez avec l’IA :

* **Filet de sécurité** : expérimentez en toute confiance, sachant que vous pouvez facilement restaurer des états antérieurs dans l’ensemble de votre environnement de développement
* **Suivi de l’avancement** : voyez exactement comment Agent a construit votre application, étape par étape
* **Jalons logiques** : les checkpoints représentent des fonctionnalités complètes plutôt que des points de sauvegarde arbitraires
* **Restauration instantanée** : revenez à n’importe quel état antérieur en un seul clic, y compris en restaurant la base de données et le contexte de l’IA

<Info>
  Pour en savoir plus sur les données capturées par les checkpoints et les possibilités complètes de restauration, consultez [Checkpoints et restaurations](/fr/pt/features/version-control/checkpoints-and-rollbacks).
</Info>

<Tip>
  Bien que les checkpoints d’Agent soient particulièrement utiles pour le développement avec l’IA, envisagez d’utiliser des commits Git pour le suivi des versions à long terme et la collaboration, surtout lorsque vous travaillez avec des dépôts externes.
</Tip>
