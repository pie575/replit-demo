# Visualisation de données

> Construisez des tableaux de bord interactifs, des outils de reporting et des interfaces d'exploration de données via une conversation avec Agent.

## Qu'est-ce qu'une visualisation de données ?

Une visualisation de données est un tableau de bord interactif ou un outil de reporting que vous construisez via une conversation avec Agent. Décrivez ce que vous voulez visualiser et où se trouvent vos données — Agent sélectionne automatiquement les KPI appropriés, les types de graphiques et les mises en page, générant un tableau de bord complet en une seule invite.

Concepts clés :

* **Génération en une seule prise** : Décrivez votre objectif et la source de données, et Agent construit un tableau de bord complet avec des graphiques et métriques appropriés
* **Sources de données connectées** : Extraire depuis des bases de données, des [connecteurs d'entrepôt](/fr/connectors/warehouses/overview), des API externes ou des fichiers téléchargés
* **Fonctionnalités intégrées** : Chaque tableau de bord inclut le rafraîchissement, l'auto-rafraîchissement, l'export en PDF, l'export de graphiques en CSV et les modes clair/sombre
* **Résumé d'analyse** : Agent génère des insights basés sur votre demande et les données résultantes
* **Plusieurs artefacts** : Les visualisations de données peuvent partager le même backend et la même base de données que vos autres artefacts dans le [même projet](/fr/replitai/artifacts#multiple-artifacts-in-one-project)

## Comment utiliser la visualisation de données

### Créer depuis une invite

Sélectionnez l'onglet **Application** sur la page d'accueil et décrivez le tableau de bord que vous souhaitez. Agent détecte les invites liées aux données et sélectionne la stack Visualisation de données.

**Exemples d'invites :**

* « Construis un tableau de bord d'analyse des ventes qui suit le chiffre d'affaires par région »
* « Crée un outil de reporting qui visualise nos métriques mensuelles »
* « Construis un tableau de bord à partir de nos données de ventes BigQuery montrant les produits les plus performants »
* « Connecte-toi à Snowflake et crée un tableau de bord d'analyse du churn client »

### Créer depuis le menu déroulant

1. Allez dans l'onglet **Application** sur la page d'accueil.
2. Ouvrez le menu déroulant des types d'application.
3. Sélectionnez **Visualisation de données**.
4. Décrivez le tableau de bord ou l'outil de données que vous souhaitez construire.

### Se connecter aux entrepôts de données

Connectez votre visualisation de données à BigQuery, Databricks ou Snowflake via les [connecteurs d'entrepôt](/fr/connectors/warehouses/overview) pour construire des tableaux de bord sur vos ensembles de données existants.

Lorsque vous interrogez des données d'entrepôt, Agent utilise une recherche multi-agents parallèle pour explorer votre schéma et vos ensembles de données. Cela accélère l'exploration et aide Agent à sélectionner les bonnes tables et champs pour votre tableau de bord.

Pour commencer, configurez un connecteur d'entrepôt dans les [Intégrations](/replitai/integrations) de votre projet, puis dites à Agent ce que vous voulez visualiser.

### Ajouter des filtres et des fonctionnalités

Après qu'Agent construit votre tableau de bord, vous pouvez l'inviter à ajouter des filtres, des vues détaillées ou d'autres fonctionnalités interactives. Par exemple, demandez à Agent d'ajouter un filtre de plage de dates, un sélecteur de région ou une barre de recherche.

### Exporter et partager

* **Exporter en PDF** : Exportez l'intégralité de votre tableau de bord en PDF pour le partage ou la consultation hors ligne.
* **Exporter les graphiques en CSV** : Téléchargez les données de graphiques individuels sous forme de fichiers CSV pour une analyse plus approfondie dans des tableurs ou d'autres outils.
* **Document d'analyse** : Demandez à Agent de produire un document d'analyse détaillé basé sur les données de votre tableau de bord.

## Ce que vous pouvez construire

* **Tableaux de bord analytiques** : Suivez des métriques clés comme le chiffre d'affaires, les inscriptions ou l'engagement sur des périodes de temps
* **Outils de reporting** : Construisez des rapports internes que les parties prenantes peuvent filtrer et explorer sans accès direct à la base de données
* **Interfaces d'exploration de données** : Parcourez et interrogez des ensembles de données avec un retour visuel
* **Panneaux de surveillance** : Affichez des données en temps réel ou quasi réel depuis des API, bases de données ou services externes

## Questions fréquentes

<Accordion title="Quelles sources de données puis-je connecter ?">
  Vous pouvez extraire des données de la base de données Replit de votre projet, des connecteurs d'entrepôt (BigQuery, Databricks, Snowflake), des API externes ou des fichiers téléchargés comme des CSV. Configurez les connexions d'entrepôt via les [Intégrations](/replitai/integrations).
</Accordion>

<Accordion title="Puis-je personnaliser l'apparence ?">
  Oui. Vous pouvez personnaliser les couleurs, mises en page et typographie via la conversation — demandez à Agent de correspondre à votre marque ou d'ajuster le design. Les tableaux de bord prennent également en charge les modes clair et sombre.
</Accordion>

<Accordion title="Agent analyse-t-il les données pour moi ?">
  Après avoir construit un tableau de bord, Agent génère un résumé d'analyse basé sur votre demande et les données résultantes. Vous pouvez également demander un document d'analyse plus détaillé.
</Accordion>

<Accordion title="Puis-je combiner une visualisation de données avec d'autres types d'artefacts ?">
  Oui. Vous pouvez combiner une visualisation de données avec une [application web](/fr/replitai/web-apps), un [diaporama](/fr/replitai/slide-decks) ou d'autres types d'artefacts dans le [même projet](/fr/replitai/artifacts#multiple-artifacts-in-one-project). Ils partagent le même backend et la même base de données.
</Accordion>
