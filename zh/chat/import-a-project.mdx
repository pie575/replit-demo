如果你已在开发某个应用或项目，可以将其导入 Replit，并在 Project 中继续完成后续工作。导入项目不同于将文件作为证据或上下文附加到 Conversation 中。

<div id="choose-a-supported-source">
  ## 选择支持的来源
</div>

来源决定了您需要提供什么，以及现有工作如何导入 Replit。当前导入指南涵盖以下方式：

| 现有工作       | 支持的来源                                                                                           |
| ---------- | ----------------------------------------------------------------------------------------------- |
| 代码仓库和构建者项目 | **GitHub**、**Bitbucket**、**Vercel**、**Bolt**、**Lovable**、**Base44** 和 **Previous Agent export** |
| 设计         | **Figma** 和 **Claude**                                                                          |
| 本地文件和数据    | **ZIP** 和 **Spreadsheet** (`.xlsx`、`.csv` 或公开的 Google Sheets URL)                               |

部分构建者项目需要使用从原始服务导出的 GitHub 仓库进行导入。导入前，请查阅对应来源的指南。导入后，可能还需要额外配置设置、Secrets、数据库值或特定身份提供方的服务。

在提示框中，选择 **加号** 菜单，然后选择 **导入现有项目**，即可打开导入流程。

<div id="import-or-attach">
  ## 导入还是附加？
</div>

* 如果要基于现有代码、设计或结构化的项目工作继续构建，请**导入 Project**。
* 如果文档、电子表格、图片或截图能为当前 Conversation 中的问题或 task 提供上下文，请**上传文件**。

有关第二种方式，请参阅[上传和使用文件](/zh/chat/upload-and-use-files)。
