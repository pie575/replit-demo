Les applications web constituent le type de résultat par défaut sur Replit. Lorsque vous décrivez une idée à Agent, celui-ci crée une application web full-stack, sauf si vous précisez un autre type d&#39;artefact.

<div id="primeiros-passos">
  ## Premiers pas
</div>

Il existe deux façons de créer une application web :

* **Saisissez un prompt** : décrivez ce que vous souhaitez créer depuis la page d&#39;accueil de Replit. Agent crée automatiquement une application web.
* **Faites votre choix dans le menu déroulant** : ouvrez le menu déroulant du type d&#39;application sur la page d&#39;accueil, sélectionnez **Web app**, puis décrivez votre idée.

<div id="principais-recursos">
  ## Fonctionnalités principales
</div>

* **Full-stack par défaut** : chaque application web comprend un frontend et un backend. Agent configure les routes d&#39;API, une base de données et la logique côté serveur en fonction des besoins de votre application.
* **Design responsive** : les applications s&#39;adaptent automatiquement aux différentes tailles d&#39;écran.
* **Publication instantanée** : publiez votre application en un clic. Replit se charge de l&#39;hébergement, du SSL et de l&#39;infrastructure.
* **Infrastructure partagée** : si votre projet comporte plusieurs artefacts — comme une application mobile ou un tableau de bord de données — ils partagent tous le même backend, la même base de données et les mêmes services.

<div id="casos-de-uso">
  ## Cas d&#39;usage
</div>

* **Produits SaaS** : créez des outils, des tableaux de bord et des plateformes destinés à vos clients.
* **Outils internes** : concevez des panneaux d&#39;administration, des CRM ou des applications de gestion de flux de travail pour votre équipe.
* **Landing pages** : lancez des sites marketing avec formulaires, animations et contenu dynamique.
* **Places de marché et annuaires** : créez des sites d&#39;annonces, des plateformes d&#39;offres d&#39;emploi ou des espaces communautaires.
