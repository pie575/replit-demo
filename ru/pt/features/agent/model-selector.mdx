Селектор модели позволяет Replit использовать интеллектуальную маршрутизацию моделей или дает вам возможность самостоятельно выбрать доступную модель.

<div id="roteamento-inteligente-de-modelos">
  ## Интеллектуальная маршрутизация моделей
</div>

Интеллектуальная маршрутизация моделей подбирает подходящую модель для каждой задачи, соблюдая баланс между качеством и стоимостью. Если в интерфейсе отображается **Auto**, значит Replit использует интеллектуальную маршрутизацию моделей.

Интеллектуальная маршрутизация моделей учитывает характер запрошенной работы и её сложность. Для узкой, точечной задачи может подойти более дешёвая модель, а для сложной работы потребуется более мощная. По мере изменения задачи Replit может выбрать другую модель.

<Note>
  Free Mode всегда использует интеллектуальную маршрутизацию моделей. Пользователям в Free
  Mode недоступен выбор модели вручную и селектор модели.
</Note>

<div id="escolher-um-modelo-manualmente">
  ## Выбор модели вручную
</div>

Пользователи планов Core и Pro могут выбрать одну из доступных моделей в режиме Power Mode или Max Mode.

1. В поле ввода prompt выберите **Agent Mode**. В меню отобразятся доступные режимы: **Free**, **Power** и **Max**.
2. Выберите **Power** или **Max** и найдите раздел **Primary model**.
3. Откройте меню основной модели и выберите модель из списка.

<Frame caption="Всплывающее окно селектора модели с режимами Lite, Economy и Power и списком Primary model. Снимок сделан в Replit Design; тот же элемент управления доступен в выпадающем меню настроек Agent.">
  <img src="/assets/mirror/model-selector-6826a87089a2.png" alt="Всплывающее окно настроек Agent с режимами Lite, Economy и Power, списком Primary model и ползунком Effort" width="1432" height="786" data-path="images/design/replit-design/model-selector.png" />
</Frame>

Выбранная модель применяется к следующему сообщению; изменить её можно в любой момент.

<Note>
  У Free Mode нет списка моделей на выбор. Список в вашем селекторе модели — источник истины для вашей учётной записи. Выбор модели вводится постепенно, и набор доступных моделей может отличаться в зависимости от этапа развёртывания, настроек организации и прав доступа. Некоторым быстрым вариантам требуется доступ к Turbo — платной функции ускорения Replit для планов Pro и Enterprise. </Note>

<div id="effort">
  ## Effort
</div>

**Effort — это настройка на уровне модели, а не отдельный режим.** Она определяет, сколько рассуждений выбранная модель тратит на каждый ответ — от **Low** до **Max**. Для каждой модели показано рекомендованное значение, и повышать его стоит только тогда, когда этого требует задача.

<Frame caption="Ползунок Effort под списком моделей, установленный на Medium.">
  <img src="/assets/mirror/model-selector-effort-bcffb01239a8.png" alt="Список Primary model с выбранной моделью Claude Fable 5 и ползунком Effort в положении Medium, которое описано как сбалансированные рассуждения для повседневных задач" width="984" height="832" data-path="images/replitai/model-selector-effort.png" />
</Frame>

Ориентируйтесь на описания уровней:

| Effort         | Когда использовать                                                                                                                      |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| **Low**        | Максимально быстрые ответы с минимумом рассуждений. Рутинные, чётко сформулированные изменения, когда важнее всего скорость.            |
| **Medium**     | Сбалансированные рассуждения для повседневных задач. Хороший вариант по умолчанию, если рекомендованная настройка не указывает на иное. |
| **High**       | Более глубокие рассуждения для сложных работ: многоэтапные функции и малознакомые области.                                              |
| **Extra High** | Расширенные рассуждения для самых трудных задач: крупные рефакторинги и запутанные ошибки.                                              |
| **Max**        | Максимальная глубина рассуждений. Самый дорогой и самый медленный вариант — когда важен только наилучший возможный результат.           |

На более высоких уровнях Effort Agent рассуждает глубже и вдумчивее и задействует самые мощные передовые модели, что улучшает результаты в наиболее сложных задачах. При этом Agent использует эту дополнительную мощность избирательно: он направляет запрос к более мощным моделям только тогда, когда задача действительно трудная, а не при каждом запуске.

<Tip>
  Поскольку Agent обращается к самой мощной модели только в самых трудных случаях, повышенный Effort увеличивает стоимость сложных задач максимум примерно вдвое (~2x), а на простых почти не сказывается. Повышайте его, когда решаете сложные проблемы, и держите на низком уровне для рутинных изменений.
</Tip>

<div id="comparar-modelos">
  ## Сравнение моделей
</div>

**Compare models** выполняет ваш следующий prompt сразу на нескольких моделях, чтобы вы могли сравнить результаты рядом, а не гадать, какая модель подойдёт лучше. Функция находится в бета-версии.

Чтобы включить её, разверните раздел **Advanced settings** внизу всплывающего окна режимов Agent и активируйте **Compare models**.

<Note>Сравнение моделей поддерживается только в Chat.</Note>

<Frame caption="Параметр Compare models в разделе Advanced settings.">
  <img src="/assets/mirror/compare-models-toggle-05429dc46d64.png" alt="Развёрнутый раздел Advanced settings с отключённым параметром Compare models Beta, описанным как создание до 4 вариантов по вашему следующему prompt" width="1110" height="344" data-path="images/replitai/compare-models-toggle.png" />
</Frame>

Когда параметр включён, добавьте в сравнение до **4 моделей**.

<Frame caption="Четыре модели, выбранные для сравнения, и кнопка отправки с надписью Compare 4.">
  <img src="/assets/mirror/compare-models-9f5bcecec727.png" alt="Всплывающее окно режимов Agent с включённым Compare models и четырьмя слотами моделей — Kimi K3, Claude Fable 5, Claude Opus 5 и GPT-5.6 Sol — каждый из которых можно удалить, и кнопкой отправки чата с надписью Compare 4" width="1192" height="1930" data-path="images/replitai/compare-models.png" />
</Frame>

После этого ваш следующий prompt выполняется по одному разу для каждой выбранной модели, и каждая из них создаёт собственный вариант для сравнения.

<Note>
  Каждая модель в сравнении запускает отдельного агента и расходует кредиты, поэтому запуск Compare 4 стоит примерно столько же, сколько четыре отдельных запуска.
</Note>
