description: "Узнайте, как автомасштабируемые развёртывания автоматически подстраивают мощность под трафик приложения."
---

Автомасштабируемые развёртывания работают на облачных вычислительных ресурсах, которые масштабируются вверх и вниз, чтобы эффективно справляться с сетевым трафиком и нагрузкой вашего Replit App. Когда приложение загружено, автомасштабирование добавляет серверы, чтобы справиться с нагрузкой. Когда приложение простаивает, число серверов сокращается до нуля ради экономии средств.

Автомасштабируемые развёртывания идеально подходят для следующих сценариев:

* Веб-приложения с переменной нагрузкой и трафиком, например сайты электронной коммерции
* API и сервисы

<div id="section">
  ## Возможности
</div>

Автомасштабируемые развёртывания включают следующие возможности:

* **Автоматическое масштабирование ресурсов**: ресурсы автоматически подстраиваются под характер трафика, что помогает оптимизировать затраты.
* **Собственные домены**: настройте собственный домен или используйте URL `<app-name>.replit.app` для доступа к приложению.
* **Настраиваемые ограничения**: задайте максимальное количество экземпляров, до которого может масштабироваться опубликованное приложение.
* **Гибкая мощность машины**: выберите конфигурацию CPU и RAM под потребности вашего приложения.
* **Мониторинг**: просматривайте логи и отслеживайте состояние опубликованного приложения.

<div id="section-2">
  ## Как использовать
</div>

Автомасштабируемые развёртывания доступны через инструмент Publishing в редакторе проекта.

<Accordion title="Как получить доступ к автомасштабируемым развёртываниям">
  На **панели инструментов** слева:

  1. Выберите <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Значок All tools" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**, чтобы открыть список инструментов редактора проекта.
  2. Выберите <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Значок Publishing" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publishing**.
  3. Выберите вариант **Autoscale**, а затем — **Set up your published app**.

  Через **строку поиска**:

  1. Нажмите на <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="Значок лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" />лупу вверху, чтобы открыть инструмент поиска
  2. Введите «Publishing», чтобы найти инструмент, и выберите его в результатах.
  3. Выберите вариант **Autoscale**, а затем — **Set up your published app**.
</Accordion>

<div id="section-3">
  ## Мощность машины
</div>

Нажмите **Edit**, чтобы просмотреть и настроить параметры мощности машины. С помощью ползунков выберите объём CPU и RAM для каждого экземпляра сервера опубликованного приложения.

В строке **Total per machine** отображается стоимость выбранной конфигурации в **вычислительных единицах**.
Вычислительная единица — это единица измерения облачных вычислительных ресурсов, зависящая от настроек памяти и CPU машины.

О том, как рассчитывается стоимость на основе вычислительных единиц, см. раздел [Вычислительные единицы](/ru/ja/billing/about-usage-based-billing#2-compute-units).

<div id="section-4">
  ## Максимальное количество машин
</div>

С помощью ползунка задайте максимальное количество машин. Это верхний предел числа серверных экземпляров, которые автомасштабирование может выделить, когда приложение находится под нагрузкой.

В строке ниже отображается эквивалентное количество вычислительных единиц, рассчитанное по формуле:

`Количество машин × Вычислительные единицы на машину`
