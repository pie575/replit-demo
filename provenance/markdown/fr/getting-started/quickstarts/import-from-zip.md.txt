## Importer depuis un ZIP

⏰ *Durée estimée : trois minutes*

Importez un projet local en téléversant un fichier `.zip`.

Pour des options d'import complètes incluant d'autres plateformes comme GitHub, Figma, Bolt, Lovable et Vercel, consultez la [documentation de la fonctionnalité d'import](/fr/core-concepts/project-editor/app-setup/import).

## Avant de commencer

* Un fichier `.zip` contenant votre projet
* Un dossier racine clairement défini dans l'archive
* Un compte Replit

## Étapes d'import

1. Ouvrez [replit.com/import](https://replit.com/import).
2. Sélectionnez **ZIP**.
3. Téléversez votre fichier `.zip`.
4. Ajoutez les secrets et variables d'environnement requis.
5. Sélectionnez **Import**.

## Ce qui est importé

* Les fichiers et la structure de répertoires du projet
* Les fichiers de dépendances
* Les paramètres d'exécution et de build par défaut pour Replit

## Ce qui n'est pas importé

* Les valeurs des variables d'environnement existantes
* Les domaines personnalisés
* Les services spécifiques à la plateforme nécessitant une configuration manuelle
* Les données de base de données existantes
* La configuration existante des connecteurs tiers
