<div id="what-gets-uploaded">
  ## Ce qui est téléversé
</div>

Un **build** est une copie installable de votre app, semblable au fichier que vous obtiendriez depuis
Google Play, mais qui n’est pas encore publiée. Expo Go exécute votre code dans une app d’aperçu
partagée ; un build est votre app autonome. C’est pourquoi des fonctionnalités telles que les notifications push et
les achats intégrés ne fonctionnent que dans un build.

Les builds Android sont des fichiers `.aab` (Android App Bundle), le format attendu par Google Play.

  ## Créez-la
</div>

<AiPrompt>
  {androidReleasePrompt}

Agent lance un build de production sur les serveurs d’Expo et vous fournit un lien de téléchargement lorsqu’il est
prêt, généralement en 10 à 15 minutes. Vous pouvez également le trouver dans votre dashboard Expo, sous
**Builds**.

<div id="upload-it">
  ## Téléversez-le
</div>

<Steps>
  <Step title="Téléchargez le fichier .aab">
    Ouvrez le lien de build fourni par Agent et téléchargez le fichier `.aab`.

    <Frame caption="Lien de téléchargement d’Agent pour le build .aab généré.">
      <img src="/assets/mirror/download-aab-file-37eb1c14cbd2.png" alt="Message du chat Agent avec un lien de téléchargement vers le build .aab généré" data-path="images/pixelgames/mobile/download-aab-file.png" width="449" height="206" data-path="images/pixelgames/mobile/download-aab-file.png" />
    </Frame>
  </Step>

  <Step title="Créez l’application dans Play Console">
    Si ce n’est pas déjà fait, sélectionnez **Create app** dans Play Console et renseignez le nom,
    la langue par défaut et indiquez s’il s’agit d’une application ou d’un jeu.
  </Step>

  <Step title="Créez une version">
    Choisissez un canal, **Internal testing** pour commencer, puis sélectionnez **Create new release**.
  </Step>

  <Step title="Téléversez le fichier .aab">
    Déposez le fichier dans la version et Play Console le traite. Une fois le traitement terminé, la
    build peut être attribuée à des testeurs ou promue en production.
  </Step>
</Steps>

<div id="troubleshooting">
  ## Résolution des problèmes
</div>

* **Play Console refuse le téléversement :** le code de version doit augmenter à chaque téléversement.
  Demandez à Agent de l’incrémenter et de relancer le build.
* **Le build reste bloqué lors de la compilation :** les builds sont mis en file d’attente et prennent généralement 10 à 15 minutes. Consultez
  votre dashboard Expo dans la section **Builds** avant de conclure à un problème.
* **Invite « App signing » lors du premier téléversement :** laissez Google gérer la clé de signature ; c’est
  l’option par défaut, qui permet à Google de signer à nouveau vos futurs téléversements.
