<div id="importar-do-base44">
  ## Импорт из Base44
</div>

⏰ *Примерное время: четыре минуты*

Чтобы импортировать проект из Base44 в Replit, сначала экспортируйте его в GitHub, а затем импортируйте этот репозиторий.

Полный список вариантов импорта, включая другие платформы, такие как GitHub, Figma и Lovable, см. в [документации по функции импорта](/ru/pt/core-concepts/project-editor/app-setup/import).

<div id="antes-de-comear">
  ## Прежде чем начать
</div>

* Проект Base44, который можно экспортировать
* Учётная запись GitHub, подключённая к Base44
* Учётная запись Replit

<div id="passos-de-importao">
  ## Шаги импорта
</div>

1. Экспортируйте проект из Base44 в GitHub.
2. Откройте [replit.com/import](https://replit.com/import).
3. Выберите **Base44**.
4. Подключите свою учётную запись GitHub.
5. Выберите репозиторий, экспортированный из Base44.
6. Нажмите **Импортировать**.

<div id="what-gets-imported">
  ## Что импортируется
</div>

Replit импортирует из вашего проекта {platform_1} следующее:

* **Код**: Логика приложения и исходные файлы
* **Дизайн и стили**: Компоненты UI и правила оформления
* **Ассеты**: Изображения, иконки и статические файлы
* **Логика бэкенда**: Серверная функциональность, если она есть
* **Схема базы данных**: Структура таблиц, если она есть

<div id="what-is-not-imported">
  ## Что не импортируется
</div>

* **Данные Supabase**: Существующие записи в базе данных не переносятся
* **Secrets**: Переменные окружения и ключи API необходимо добавить отдельно

Используйте Agent, чтобы восстановить недостающую функциональность, добавить Secrets и воссоздать данные базы данных.
