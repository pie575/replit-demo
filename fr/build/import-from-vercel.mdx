## Importer depuis Vercel

⏰ *Durée estimée : trois minutes*

Importez un projet Vercel dans Replit en liant le dépôt GitHub derrière le projet.

Pour des options d'importation complètes incluant d'autres plateformes comme GitHub, Figma, Bolt et Lovable, consultez la [documentation de la fonctionnalité d'importation](/fr/references/workspace/import).

## Avant de commencer

* Un projet Vercel connecté à GitHub
* L'accès au dépôt GitHub sous-jacent
* Un compte Replit

## Étapes d'importation

1. Ouvrez [replit.com/import](https://replit.com/import).
2. Sélectionnez **Vercel**.
3. Connectez votre compte GitHub.
4. Sélectionnez le dépôt de votre projet Vercel.
5. Ajoutez les secrets et variables d'environnement demandés.
6. Sélectionnez **Importer**.

## Ce qui est importé

* Fichiers du projet et structure des répertoires
* Configuration des dépendances et du framework
* Valeurs par défaut d'exécution et de build pour Replit

## Ce qui n'est pas importé

* Valeurs des variables d'environnement existantes
* Domaines personnalisés
* Comportement edge ou middleware spécifique à Vercel
* Configuration d'analytique ou de monitoring externe
