Веб-приложения — это тип результата, который Replit создаёт по умолчанию. Опишите свою идею Agent, и он создаст полностековое веб-приложение, если вы не укажете другой тип артефакта.

<div id="section">
  ## Начало работы
</div>

Создать веб-приложение можно двумя способами:

* **Введите запрос**: на главной странице Replit опишите, что вы хотите создать. Agent автоматически создаст веб-приложение.
* **Выберите из раскрывающегося списка**: на главной странице откройте раскрывающийся список типов приложений, выберите **Веб-приложение**, а затем опишите свою идею.

<div id="section-2">
  ## Основные возможности
</div>

* **Полностековые по умолчанию**: каждое веб-приложение включает фронтенд и бэкенд. Agent настраивает маршруты API, базы данных и серверную логику под задачи вашего приложения.
* **Адаптивный дизайн**: приложения автоматически подстраиваются под разные размеры экранов.
* **Мгновенное развёртывание**: публикуйте приложение в один клик. Replit берёт на себя хостинг, SSL и инфраструктуру.
* **Общая инфраструктура**: если в проекте несколько артефактов, например мобильное приложение и панель данных, все они используют один и тот же бэкенд, базу данных и сервисы.

<div id="section-3">
  ## Сценарии использования
</div>

* **SaaS-продукты**: создавайте инструменты, дашборды и платформы для клиентов.
* **Внутренние инструменты**: создавайте админ-панели, CRM и приложения для рабочих процессов команды.
* **Лендинги**: запускайте маркетинговые сайты с формами, анимациями и динамическим контентом.
* **Маркетплейсы и каталоги**: создавайте сайты объявлений, доски вакансий и платформы для сообществ.
