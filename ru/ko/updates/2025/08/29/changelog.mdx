<div id="section-3">
  ### Темы приложений
</div>

Преобразите свои веб-приложения с помощью красивых профессиональных тем. Применяйте собственный дизайн и делитесь темами с командой, чтобы сохранять единый стиль бренда во всех проектах.

<Frame>
  <img src="/assets/mirror/manage-custom-themes-8de2e9223013.png" alt="Менеджер тем с параметрами создания, редактирования и удаления пользовательских тем" width="1772" height="1062" data-path="images/replitai/app-themes/manage-custom-themes.png" />
</Frame>

Подробнее о том, [как использовать темы приложений](/ru/replitai/app-themes).

Некоторые элементы предпросмотра созданы под влиянием проекта [tweakcn](https://github.com/jnsahaj/tweakcn). Открытый репозиторий Sahaj Jain доступен [здесь](https://github.com/jnsahaj/tweakcn).

<div id="section-4">
  ### Ссылки для создания приложений, которыми можно делиться
</div>

Делитесь возможностями создания приложений на базе ИИ. Создавайте ссылки, которые автоматически генерируют приложение по промпту, — так вы легко поделитесь идеей и поможете другим сделать первый шаг.

```md theme={null}
replit.com/create?prompt="Make me a cool demo for my app idea"
```

<div id="agent">
  ### Улучшение инфраструктуры Agent
</div>

Agent теперь работает на улучшенной инфраструктуре: он быстрее обрабатывает задачи, глубже рассуждает и дольше поддерживает рабочие сессии. Благодаря этому Agent справляется с более крупными проектами и выдаёт лучшие результаты в любых задачах программирования.

<div id="section-7">
  ### Повышение рейтинга безопасности
</div>

Replit теперь имеет рейтинг «Advanced» от Bitsight с оценкой безопасности 780 — это подтверждает нашу приверженность безопасности уровня Enterprise для ваших проектов и данных.

<div id="section-8">
  ### Отмена подписки организации
</div>

Теперь организации могут гибче управлять подпиской. Отменить её можно без удаления организации, при этом полный доступ сохраняется до конца оплаченного периода.
