<div id="section-2">
  ## Обновления платформы
</div>

<div id="section-3">
  ### Улучшение пустых состояний в предпросмотре
</div>

Предпросмотр приложений теперь умнее обрабатывает пустые состояния и автозапуск при сборке в Agent, делая рабочий процесс более плавным.

<div id="ai">
  ### Снижение задержек в работе ИИ
</div>

Благодаря улучшениям инфраструктуры время отклика и задержки Replit AI значительно сократились. При использовании ИИ-функций Replit, включая Agent и Assistant, взаимодействие стало заметно быстрее.

<div id="github">
  ### Обновлённая единая вкладка GitHub
</div>

Вкладка интеграции с GitHub стала чище и единообразнее. Благодаря обновлённому дизайну подключать репозитории GitHub и управлять ими в Workspace стало намного удобнее.

<div id="ios">
  ### Поддержка платежей в приложении для iOS
</div>

Пользователи iOS теперь могут оформить подписку Replit Core и настроить способ оплаты прямо в мобильном приложении Replit. Так доступ к премиум-функциям становится проще, где бы вы ни находились.

<div id="stripe">
  ### Запуск Stripe Checkout
</div>

Новая интеграция со Stripe Checkout делает оплату удобнее и безопаснее для всех разработчиков. Покупки стали проще благодаря отраслевому стандарту платёжных решений, с которым перейти на Replit Core легко как никогда.

<div id="scim">
  ### Упрощённая подготовка учётных записей через SCIM
</div>

Улучшенный процесс подготовки аккаунтов через SCIM заметно упростил онбординг пользователей Enterprise. Новые пользователи настраиваются автоматически, без каких-либо ручных действий, что обеспечивает беспроблемную работу растущим командам Enterprise Teams на Replit.
