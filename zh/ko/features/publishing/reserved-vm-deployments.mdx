---
title: "Reserved VM 部署"
description: "了解如何使用 Reserved VM 部署，将应用发布到始终在线的云服务器上。"
---

Reserved VM 部署运行在虚拟机 (VM) 上，为应用提供专用计算资源。这种部署类型不间断运行，成本和性能均可预测。

它适用于以下场景：

* 内存密集型的后台任务
* 需要保持长连接的聊天应用机器人
* 始终在线的 API 服务器

<div id="section">
  ## 功能
</div>

Reserved VM 部署包含以下功能：

* **专用资源**：借助预留的计算资源，获得稳定一致的应用性能。
* **自定义域名**：可配置自定义域名，也可通过 `<app-name>.replit.app` URL 访问应用。
* **计算资源选项**：根据应用的性能需求选择合适的 VM 配置。
* **可配置的端口映射**：指定应用对外开放的端口。
* **监控**：查看日志，监控已发布应用的运行状态。

<div id="section-2">
  ## 使用方法
</div>

您可以通过项目编辑器中的发布工具访问 Reserved VM 部署。

<Accordion title="访问 Reserved VM 部署">
  在左侧**工具栏**中：

  1. <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="所有工具图标" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> 选择**所有工具**，查看项目编辑器的工具列表。
  2. <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="发布图标" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> 选择**发布**。
  3. 选择 **Reserved VM**，然后选择**设置已发布的应用**。

  使用**搜索栏**：

  1. 选择顶部的 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 放大镜，打开搜索工具。
  2. 输入“发布”来查找该工具，然后从搜索结果中选择它。
  3. 选择 **Reserved VM**，然后选择**设置已发布的应用**。
</Accordion>

<div id="section-3">
  ### 机器配置
</div>

选择用于托管部署的机器 CPU 和内存 (RAM) 配置。在所选机器规格旁，可以查看该选项的费用。

<div id="section-4">
  ### 默认域名
</div>

为已发布的应用指定主机名中的子域名部分。发布后，你可以通过 `https://<subdomain>.replit.app` 访问该应用。

若要了解如何使用自定义域名，请参阅[自定义域名](/zh/features/publishing/custom-domains)。

<div id="private">
  ### 私有部署
</div>

<Info>
  私有发布应用功能适用于 Pro 和 Enterprise 套餐。
</Info>

私有发布的应用仅允许你所在 workspace 的成员，或你邀请的特定用户和群组访问。
发布时，你可以选择 **Public**、**Password protected**、**Workspace only** 或 **Invite only** 访问方式。

要了解如何配置私有部署，请参阅[应用访问](/zh/features/publishing/private-deployments/)。

<div id="section-5">
  ### 构建命令
</div>

在**构建命令**字段中输入 Shell 命令，用于在执行运行命令之前编译或配置应用。
例如，若要使用 Vite 针对生产环境优化 JavaScript 应用，可以添加 `vite build` 命令。

<div id="section-6">
  ### 运行命令
</div>

在**运行命令**字段中输入用于启动任务的 Shell 命令。该命令应与你在工作流中
使用的命令类似。例如，要启动名为“myApp”的 Flask 应用，可以添加 `flask --app myApp run` 命令。

<div id="section-7">
  ### 已发布应用的密钥
</div>

若要添加应用安全运行所需的环境变量或密钥，请选择**添加已发布应用密钥**。

如果 Replit App 中已有环境变量或密钥，发布工具会自动将其添加到列表中。

<div id="section-8">
  ### 应用类型选项
</div>

请从以下选项中选择一项：

* **Web 服务器**：如果要发布 Web 应用或用户可通过互联网访问的应用，请选择此选项。
* **后台工作进程**：如果应用不监听端口，也不启动服务器，请选择此选项。

选择 **Web 服务器**后，可通过以下步骤自定义要对外开放的端口：

1. 展开**端口配置**部分。
2. 选择**通过网络面板配置**，打开**网络**标签页并管理端口映射。

有关端口配置的更多信息，请参阅[端口](/zh/ko/features/project-setup/ports/)。
