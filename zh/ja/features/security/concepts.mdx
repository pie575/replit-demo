[项目安全中心](/zh/ja/features/security/project-security-center)和[工作区安全中心](/zh/ja/features/security/workspace-security-center)中所用安全术语的定义。

<div id="cve">
  ## CVE
</div>

Common Vulnerabilities and Exposures (通用漏洞披露) 。CVE 是为公开披露的软件漏洞分配的唯一标识符，例如 `CVE-2024-12345`。

<div id="section">
  ## 严重程度
</div>

漏洞的风险评估等级：严重、高、中或低。请结合严重程度和暴露程度，确定优先修复哪些项目。

<div id="section-2">
  ## 依赖项
</div>

项目所依赖的第三方软件包。依赖项中的漏洞会影响所有使用该依赖项的项目，直到该依赖项被更新或替换为止。

<div id="sbom">
  ## SBOM
</div>

Software Bill of Materials (软件物料清单) 。SBOM 是对项目中所含软件包、版本及许可证的机器可读清单。

<div id="spdx-cyclonedx">
  ## SPDX 和 CycloneDX
</div>

安全与合规工具通用的标准 SBOM 格式。请根据审计、合规或软件成分分析工具的要求选择相应格式。

<div id="section-3">
  ## 暴露程度
</div>

由发布状态和可见性带来的风险面。公开且已发布的项目，其暴露程度高于私有或未发布的项目。

<div id="agent">
  ## 使用 Agent 修复
</div>

该操作可让 Replit Agent 以后台任务的形式为受影响的项目起草补丁。请先检查生成的更改，再进行应用。

<div id="section-4">
  ## 重新发布
</div>

使用现有的部署配置重新部署项目。修复应用完成后，请使用**重新发布**发布修补后的版本。

<div id="package-firewall">
  ## Package Firewall
</div>

网络层防护，在安装时拦截恶意或已被入侵的软件包，阻止其下载到你的应用中。默认启用，由 Socket 提供支持。请参阅 [Package Firewall](/zh/ja/features/security/package-firewall)。

<div id="auto-protect">
  ## Auto-Protect
</div>

Replit 自动为应用启用的一整套保护功能。面向所有构建者默认启用的保护包括：用于在安装时进行拦截的 [Package Firewall](/zh/ja/features/security/package-firewall)、Web 应用防火墙 (WAF) 以及自动 SSL/TLS 加密。管理员还可以选择开启自动 CVE 修复，由 Replit Agent 针对新披露的依赖项漏洞准备补丁，并通知 project 所有者。请参阅 [Auto-Protect](/zh/ja/features/security/project-security-center#auto-protect)。
