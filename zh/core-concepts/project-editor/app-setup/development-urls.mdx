开发 URL 可让你在构建 App 的过程中预览和测试它。这些 URL 的格式为 `UUID.servername.replit.dev`，可让你在开发过程中实时预览 App。

</Frame>

要查看开发 URL，请点击地址栏中的 `{...}.replit.dev` 文本。

<div id="understanding-development-urls">
  ## 了解开发 URL
</div>

开发 URL 仅在你正在使用 Replit App 时有效。每次重新打开应用时，URL 都可能发生变化。开发 URL 让你可以在构建和测试过程中通过浏览器查看成果。

默认情况下，开发 URL 对互联网公开。任何获得该 URL 的人都可以在你构建应用时查看它。这让你可以轻松地与协作者、测试人员或利益相关者分享正在开发的内容。

<Warning>
  开发 URL 是临时的，仅用于测试。若要与他人分享应用，建议[发布你的应用](/zh/learn/projects-and-artifacts/replit-deployments)。
</Warning>

<div id="educational-banner">
  ### 提示横幅
</div>

当你在新标签页中打开开发预览时，页面顶部会出现一个提示横幅。该横幅可帮助你在构建和测试应用的过程中了解 `.replit.dev` URL 的用途，并说明开发 URL 的背景信息及其在开发过程中的适用场景。

<div id="making-development-urls-private">
  ## 将开发 URL 设为私有
</div>

你可以限制对开发 URL 的访问，从而保护正在进行中的工作。

将开发 URL 设为私有的步骤如下：

1. 在 Project Editor 中打开 **Developer tools**。
2. 选择 **Networking** 标签页。
3. 打开 **Private development URL** 开关。

启用后，访问开发 URL 需要通过身份验证，只有你和获得授权的团队成员才能查看进行中的工作。

<Note>
  Enterprise 客户可以要求所有 project 都使用私有开发 URL，确保开发工作始终受组织环境的保护，从而提升安全性。
</Note>

<div id="best-practices">
  ## 最佳实践
</div>

* 开发敏感或专有应用时，**使用私有 URL**
* 在开发过程中需要向外部相关方展示成果，或想在其他浏览器中测试应用时，**使用公开 URL**
