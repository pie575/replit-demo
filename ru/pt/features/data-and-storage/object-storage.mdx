App Storage — это встроенное объектное хранилище Replit, которое позволяет вашему приложению легко размещать и сохранять загружаемые файлы: изображения, видео и документы.
Бакеты — это контейнеры для хранения объектов, например файлов. Для них задаются политики доступа, которые ограничивают действия пользователей и приложений с их содержимым.

<Info>
  Мы переименовали <strong>Object Storage</strong> в <strong>App Storage</strong>. Функциональность не изменилась, а ваши существующие бакеты, разрешения и программный доступ должны продолжать работать.
</Info>

С App Storage вы можете создавать, например:

* **Платформы для обмена фотографиями**: позвольте авторам загружать, хранить и показывать изображения
* **Сервисы потокового видео**: управляйте загрузкой видео и доставляйте контент зрителям
* **Системы управления документами**: храните и упорядочивайте файлы авторов с безопасным доступом
* **Сайты-портфолио**: демонстрируйте работы с медиафайлами, которые всегда загружаются без сбоев
* **Сервисы резервного копирования**: предоставьте авторам облачное хранилище для важных файлов

</Note>

Инструмент App Storage позволяет без труда обмениваться данными между
средами разработки и продакшена или с другими Replit Apps.

<div id="recursos">
  ## Возможности
</div>

<Info>
  App Storage построен на основе Google Cloud Storage (GCS).
  Это значит, что вы получаете доступность, время бесперебойной работы
  и безопасность на уровне лучших решений отрасли.
</Info>

App Storage предоставляет следующие возможности для ваших Replit Apps:

* **Постоянное облачное хранилище**: храните файлы, которые остаются доступными вашему опубликованному приложению и пользователям
* **Масштабируемое управление файлами**: покрывайте растущие потребности в данных, не беспокоясь об ограничениях хранилища
* **Обмен данными между приложениями**: используйте общие бакеты в нескольких Replit Apps для распределённых архитектур
* **Программный доступ**: загружайте, скачивайте файлы и управляйте ими с помощью интуитивно понятных API
* **Расширенная интеграция с Agent**: поручите Agent настроить App Storage с расширенными параметрами, проверить существующие настройки и сгенерировать полный код бэкенда и фронтенда с аутентификацией и контролем доступа

Вот несколько способов использования App Storage в ваших Replit Apps:

* Хранение фотографий профилей авторов и загруженных медиафайлов
* Отдача изображений товаров для сайтов электронной коммерции
* Управление загрузкой документов при отправке форм
* Создание функций обмена файлами и совместной работы
* Создание систем управления контентом с медиабиблиотеками

<Tip>
  **Расширенная интеграция с Agent**: вы можете попросить [Replit Agent](/ru/pt/features/agent/overview) автоматически добавить App Storage в ваши приложения! Теперь Agent может настраивать объектное хранилище, проверять конфигурации и генерировать полный код бэкенда и фронтенда с расширенными возможностями, такими как аутентификация и контроль доступа. Просто упомяните «App Storage» или «хранилище файлов» в своём prompt.

</Tip>

<div id="uso">
  ## Использование
</div>

<Note>
  Вашему Replit App необходимо пройти аутентификацию в Google Cloud Storage, чтобы получить доступ к бакету и его объектам.
  Для автоматической аутентификации используйте официальные клиентские библиотеки App Storage от Replit.
</Note>

Открыть инструмент App Storage можно прямо в Project Editor.

<Accordion title="Как открыть инструмент App Storage">
  На панели **Tool dock** слева:

  1. Выберите <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Значок всех инструментов" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**, чтобы увидеть список инструментов Project Editor.
  2. Выберите <img class="icon-svg" src="/assets/mirror/object-storage-monoochrome-icon-aaba8f517280.svg" alt="Значок App Storage" width="16" height="16" data-path="images/icons/object-storage-monoochrome-icon.svg" /> **App Storage**.

  В **строке поиска**:

  1. Нажмите на <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="значок лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> лупу вверху, чтобы открыть инструмент поиска.
  2. Введите «App Storage», чтобы найти инструмент, и выберите его в результатах.
</Accordion>

Чтобы связать новый бакет хранилища с вашим Replit App, создайте бакет.

<Accordion title="Как создать бакет">
  В инструменте **App Storage**:

  1. Нажмите **Create new bucket**.
  2. Введите имя бакета в поле **Name** и выберите **Create bucket**.

  Вкладка App Storage должна выглядеть так, как на снимке экрана ниже:

  <Frame>
    <img src="/assets/mirror/object-storage-empty-bucket-3462e2efb1bc.png" alt="снимок экрана инструмента App Storage" width="2790" height="1218" data-path="images/databases/object-storage-empty-bucket.png" />
  </Frame>

  Чтобы создать дополнительные бакеты, откройте раскрывающееся меню бакетов в левом верхнем углу вкладки **App Storage** и выберите **Create new bucket**.
</Accordion>

Рядом с названием выбранного бакета отображается галочка, как показано на снимке экрана ниже:

<div id="acessar-o-id-do-bucket">
  ### Доступ к идентификатору бакета
</div>

Чтобы посмотреть **Bucket ID**, выберите представление **Settings** в раскрывающемся меню в верхней части вкладки **App Storage**.
Bucket ID — это уникальный идентификатор бакета, на который должен ссылаться ваш код при выполнении операций.

Если у вас несколько бакетов, выберите нужный в раскрывающемся меню в левом верхнем углу.

На снимке экрана ниже показан Bucket ID бакета «FileVault Bucket One»:

<div id="fazer-upload-ou-download-de-objetos">
  ### Загрузка и скачивание объектов
</div>

Чтобы загрузить объект в выбранный бакет:

1. Перейдите к представлению **Objects** на вкладке **App Storage**.
2. Выберите <img class="icon-svg" src="/assets/mirror/upload-file-5894be4232ce.svg" alt="значок загрузки файла" width="16" height="16" data-path="images/icons/upload-file.svg" /> **Upload files** или <img class="icon-svg" src="/assets/mirror/upload-folder-fc87519bedf9.svg" alt="значок загрузки папки" width="16" height="16" data-path="images/icons/upload-folder.svg" /> **Upload folder**, чтобы загрузить все файлы из папки.
   Затем в диалоговом окне выберите один или несколько файлов для загрузки.
   Также можно перетащить файл или папку в область со списком содержимого бакета.

Чтобы скачать объект из выбранного бакета:

1. Перейдите к представлению **Objects** на вкладке **App Storage**.
2. Нажмите значок скачивания <img class="icon-svg" src="/assets/mirror/download-icon-c7b527953d65.svg" alt="значок скачивания" width="16" height="16" data-path="images/icons/download-icon.svg" /> справа от файла.

<div id="organizar-objetos-em-pastas">
  ### Организация объектов по папкам
</div>

Чтобы создать папку в выбранном бакете:

1. Перейдите к представлению **Objects** на вкладке **App Storage**.
2. В представлении **Objects** выберите <img class="icon-svg" src="/assets/mirror/create-folder-c9acf112a042.svg" alt="значок создания папки" width="16" height="16" data-path="images/icons/create-folder.svg" /> **Create Folder**.
3. Введите имя папки.

Чтобы добавить объекты в папку в представлении **Objects**, перетащите объект на нужную папку.

Чтобы переместить объект в родительскую папку, перетащите его на имя папки в заголовке над списком объектов.

<div id="excluir-objetos-ou-buckets">
  ### Удаление объектов или бакетов
</div>

<Warning>
  Удаление необратимо. Прежде чем продолжить, обязательно создайте резервную копию всех важных данных.
</Warning>

Чтобы удалить объект без возможности восстановления:

1. Откройте раздел **Objects** на вкладке **App Storage**.
2. Нажмите значок корзины <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="значок корзины" width="16" height="16" data-path="images/icons/trash-icon.svg" />
   рядом с объектом, который нужно удалить.
3. Подтвердите удаление в открывшемся диалоговом окне.

Чтобы удалить бакет вместе со всеми объектами в нём:

1. Откройте раздел **Settings** на вкладке **App Storage**.
2. Убедитесь, что в выпадающем списке бакетов в левом верхнем углу выбран нужный бакет.
3. Нажмите <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="значок корзины" width="16" height="16" data-path="images/icons/trash-icon.svg" /> **Delete Bucket**.
4. Подтвердите удаление в открывшемся диалоговом окне.

<div id="gerenciamento-de-acesso-a-buckets">
  ### Управление доступом к бакетам
</div>

Replit привязывает все создаваемые вами бакеты к вашей учётной записи и делает их доступными
для всех ваших Replit App. Replit App, из которого вы создаёте бакет,
получает доступ автоматически.

Вы можете управлять тем, какие из ваших Replit App имеют доступ к конкретному бакету, — это позволяет
обмениваться данными эффективно и безопасно.

Чтобы предоставить вашему Replit App доступ к бакету другого приложения в вашей учётной записи:

1. Выберите <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="значок лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" />
   **Add an existing bucket** в меню бакетов в левом верхнем углу вкладки App Storage.
2. В диалоговом окне **Choose a Bucket** выберите нужный бакет и нажмите **Add Bucket to Repl**.

<Frame>
  <img src="/assets/mirror/choose-bucket-dialog-b709aa247a85.png" alt="снимок экрана диалогового окна выбора бакета" width="1115" height="457" data-path="images/databases/choose-bucket-dialog.png" />
</Frame>

Чтобы отозвать у вашего Replit App доступ к бакету:

1. Перейдите к разделу **Settings** на вкладке **App Storage**.
2. В раскрывающемся меню бакетов в левом верхнем углу вкладки выберите имя бакета.
3. Нажмите **Remove Bucket from Repl** и подтвердите удаление в диалоговом окне.

<div id="acesso-programtico-ao-app-storage">

Инструкции по работе с клиентскими библиотеками приведены в следующих материалах:

* [Python App Storage SDK](/ru/pt/features/sdks/object-storage-python-sdk/): справочник по клиенту для Python SDK
* [Google Cloud Python SDK example app](https://replit.com/@matt/GCS-Python-Uploads?v=1): сделайте ремикс этого приложения, чтобы управлять объектами с помощью Python SDK от Google Cloud
