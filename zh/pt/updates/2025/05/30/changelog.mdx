<div id="melhorias-no-estado-vazio-da-prvia">
  ### 优化预览空状态
</div>

Agent 应用中的预览现可更智能地处理空状态和自动运行，让你使用 Agent 构建应用时更加顺畅。

<div id="melhorias-na-latncia-da-ia">
  ### AI 延迟优化
</div>

通过基础设施优化，Replit AI 的响应时间和延迟显著降低。使用 Replit 各项 AI 功能 (包括 Agent 和 Assistente) 时，您将体验到更快的交互。

<div id="atualizao-da-aba-unificada-do-github">
  ### GitHub 统一标签页更新
</div>

GitHub 集成标签页现已焕新，界面更加简洁统一。在 Workspace 中连接和管理 GitHub 仓库更加直观。

<div id="suporte-a-pagamentos-no-aplicativo-ios">
  ### 支持 iOS App 内支付
</div>

iOS 用户现在可以直接通过 Replit 移动 App 购买 Replit Core 并设置支付方式，随时随地轻松使用高级功能。

<div id="lanamento-do-stripe-checkout">
  ### Stripe 结账流程 发布
