PixelGames는 혼자서만 하는 프로젝트가 아닙니다. 팀원을 초대하면 각자 자신의 Agent task를 동시에
실행할 수 있고, 모든 작업이 공유 board에 기록되므로 작업이 중복될 일이 없습니다.

<div id="invite-a-teammate">
  ## 팀원 초대하기
</div>

<Steps>
  <Step title="프로젝트 공유하기">
    PixelGames 앱에서 **Invite**를 열고 링크를 공유하거나 이메일로 팀원을 추가하세요.

    <Frame caption="Invite를 열고 링크를 공유하거나 이메일로 팀원을 추가하세요.">
      <img src="/assets/mirror/invite-71cee8be2e0e.png" alt="공유 링크와 이메일 초대가 강조 표시된 PixelGames Invite 대화 상자" data-path="images/pixelgames/mobile/invite.png" width="1305" height="598" data-path="images/pixelgames/mobile/invite.png" />
    </Frame>
  </Step>

  <Step title="팀원이 각자 task를 시작합니다">
    참여하는 즉시 각자 Agent 대화를 열 수 있으며, 다른 사람의 작업이 끝나기를
    기다릴 필요가 없습니다.
  </Step>
</Steps>

<div id="track-work-on-the-board">
  ## board에서 작업 추적하기
</div>

각 Agent task는 네 단계를 거칩니다. **Draft**(계획이 검토 대기 중), **Active**
(Agent가 building 중), **Ready**(완료되어 적용 대기 중), **Done**(PixelGames에 merge 완료)입니다.

예를 들어 한 팀원은 Snake를 build하고 다른 팀원은 payments를 추가하는 식으로, 두 task가
board 위에서 각각 독립적으로 이동하므로 누가 무엇을 작업 중인지 한눈에 알 수 있습니다.

<Frame caption="공유 board에서 모든 팀원의 task를 Drafts, Active, Ready, Done 단계별로 확인할 수 있습니다.">
  <img src="/assets/mirror/invite-kanban-a4133033bcfa.png" alt="Drafts, Active, Ready, Done 열이 있는 PixelGames task board" data-path="images/pixelgames/mobile/invite-kanban.png" width="1303" height="597" data-path="images/pixelgames/mobile/invite-kanban.png" />
</Frame>

Agent는 각 task를 PixelGames의 독립된 복사본에서 build하므로, 두 사람이 동시에 작업해도
서로의 changes가 충돌하지 않습니다. 충돌은 task를 실제로 다시 적용할 때, 그리고 이미 적용된
다른 task와 동일한 코드를 건드리는 경우에만 발생합니다.
