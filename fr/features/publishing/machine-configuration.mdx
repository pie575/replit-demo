La configuration de la machine contrôle la puissance des serveurs qui font fonctionner votre application publiée. Replit choisit une valeur par défaut adaptée, donc la plupart des développeurs n'ont jamais besoin de la modifier. Envisagez une configuration plus puissante lorsque votre application semble lente sous charge ou traite de grandes quantités de données en mémoire.

Pour la modifier, ouvrez l'outil Publication, sélectionnez **Ajuster les paramètres**, puis sélectionnez **Modifier** à côté de **Configuration de la machine**.

## Les paramètres

* **CPU** : La quantité de travail simultané que chaque serveur peut gérer. Plus de vCPU aide lorsque de nombreuses personnes utilisent votre application en même temps.
* **Mémoire (RAM)** : La quantité de données que votre application peut conserver en mémoire. Plus de RAM aide avec les fichiers volumineux, les médias ou les traitements de données intensifs.
* **Machines maximales** : Autoscale uniquement. La limite supérieure de serveurs que Replit peut ajouter lorsque votre application est sollicitée. Votre application ne dépasse jamais ce nombre, ce qui plafonne votre coût maximal.

## Ce que cela coûte

Le panneau affiche deux chiffres pendant que vous configurez :

* **Par machine** : Le coût horaire d'un serveur avec la configuration choisie.
* **Au trafic maximal** : Le coût horaire si votre application est suffisamment sollicitée pour utiliser toutes les machines jusqu'à votre maximum.

Les coûts sont mesurés en unités de calcul, une unité de calcul cloud basée sur le CPU et la mémoire que vous choisissez. Pour consulter les tarifs actuels et savoir comment l'utilisation est facturée, consultez [la facturation à l'utilisation](/fr/billing/about-usage-based-billing).

## Comment la facturation diffère selon le type de déploiement

La même configuration est facturée différemment selon votre [type de déploiement](/fr/features/publishing/deployment-types) :

* **Autoscale** : Vous payez pendant que les requêtes sont traitées. Lorsque votre application est inactive, elle s'adapte à zéro et ne coûte rien à faire fonctionner.
* **VM réservée** : Votre serveur est toujours actif, donc vous payez un coût mensuel fixe pour la configuration choisie.
* **Statique** : Aucune machine ne fait fonctionner votre site, donc la configuration de la machine ne s'applique pas.
* **Planifié** : Vous payez pour la machine pendant chaque exécution planifiée.

## Appliquer vos modifications

Republiez votre application après avoir modifié la configuration. Les nouveaux paramètres de machine prennent effet avec le nouveau déploiement.
