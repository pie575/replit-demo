<div id="suporte-a-udio-em-integraes-de-ia">
  ### Поддержка аудио в ИИ-интеграциях
</div>

<Frame>
  <img src="/assets/mirror/screenshot-2026-01-22-at-9-08-38-am_80c7a6b9af74-1f051e99efdc.png" alt="Настройки аудио для ИИ-интеграций с параметрами транскрибации и аудиовывода" width="2884" height="1768" data-path="images/changelog/2026-01-23/screenshot-2026-01-22-at-9-08-38-am_80c7a6b9af74.png" />

ИИ-интеграции теперь поддерживают работу с аудио благодаря четырём новым моделям:

* `gpt-4o-transcribe` и `gpt-4o-transcribe-mini` для преобразования речи в текст
* `gpt-4o-audio` и `gpt-4o-audio-mini` для генерации аудио

Создавайте приложения, которые обрабатывают или генерируют аудиоконтент: расшифровывайте подкасты, создавайте голосовых помощников или добавляйте в свои приложения речевые интерфейсы.

<div id="busca-na-web-em-automaes-do-agent">
  ### Веб-поиск в автоматизациях Agent
</div>

<Frame>
  <img src="/assets/mirror/image_935f53bc7191-e59f7aee0cd0.png" alt="Agent формирует сводку по результатам поиска с помощью автоматизации" width="1482" height="2492" data-path="images/changelog/2026-01-23/image_935f53bc7191.png" />
</Frame>

Создавайте автоматизации с веб-поиском без ключей API. Agent интегрирует встроенный веб-поиск LLM через ИИ-интеграции, позволяя запускать исследования по расписанию, составлять новостные сводки или предоставлять образовательный контент.

<div id="suporte-ao-rulessync-para-replitmd">
  ### Поддержка RulesSync для replit.md
</div>

Проект с открытым исходным кодом [RulesSync](https://github.com/dyoshikawa/rulesync) теперь поддерживает файлы `replit.md`. Поддерживайте синхронизацию файлов конфигурации ИИ-агента (`CLAUDE.md`, `AGENT.md` и `replit.md`) между несколькими проектами.
