## Lançamento do Plano Pro

O Replit Pro chegou, e o Core agora oferece ainda mais valor. Tornamos os planos mais claros e com finalidades específicas:

* **Replit Pro**: Para builders sérios — Modo Turbo (2,5x mais rápido no Agent, toggle separado), créditos escalonados com rollover, até 15 builders sem taxas por usuário, suporte prioritário e retenção de dados 4×. [Saiba mais sobre o Pro](/pt/billing/plans/replit-pro).
* **Core**: Convide até 5 colaboradores sem custo extra. Veja a [página de preços](https://replit.com/pricing) para os preços atuais do Core.
* **Encerramento do plano Teams**: O Teams está sendo substituído pelo Pro. Clientes existentes do Teams são atualizados para o Pro sem custo adicional pelo restante de seu período. A migração começa em {TeamsMigrationDate}. [Detalhes e cronograma](https://blog.replit.com/pro-plan).
* **Modos do Agent**: Escolha **Economy** (otimizado para custo) ou **Power** (desempenho); **Turbo** é um toggle separado (somente Pro/Enterprise, 2,5x mais rápido). [Guia de modos do Agent](/pt/core-concepts/agent/agent-modes).
* **Fast Mode agora é Lite Mode**: As mesmas mudanças rápidas e com escopo definido — nome atualizado no produto e na documentação. [Modo Lite](/pt/core-concepts/agent/agent-modes).
* **Otimizações de Código**: A configuração que controla como o Agent revisa seu próprio código (anteriormente Nível de Autonomia) agora se chama Otimizações de Código. [Revisão de código](/pt/features/agent/agent-modes#code-review).
* **Colaboração**: Melhor colaboração em todos os planos pagos — workspaces ilimitados, compartilhamento simplificado, configurações unificadas, rastreamento de uso por workspace. Core: 5 colaboradores; Pro: 15 builders.

## Plataforma

### Compressão de memória em segundo plano

O Agent não pausa mais o seu fluxo de trabalho para otimizar sua memória. Anteriormente, você via uma mensagem "Memória do Agent otimizada" que bloqueava o progresso por mais de 30 segundos. Agora isso acontece de forma transparente em segundo plano, para que o Agent permaneça responsivo enquanto você trabalha.

### Acesso a logs de deployment de produção

O Agent agora tem acesso aos logs de Deployment de produção, permitindo encontrar e corrigir erros com base em dados reais de produção. Espere mais aprimoramentos de depuração em produção em breve.

A Busca de Skills permite que você navegue e instale skills populares diretamente no Replit sem precisar acionar o Agent ou fazer upload manual de arquivos.

### Integração MCP com Razorpay

A integração MCP com Razorpay já está disponível, expandindo as capacidades de pagamento para builders na Índia. Conecte o Razorpay ao seu projeto no Replit para aceitar pagamentos, gerenciar pedidos e processar reembolsos diretamente pelo Agent.

### Lista MCP padrão expandida

A lista MCP padrão em [replit.com/integrations](https://replit.com/integrations) foi expandida, permitindo que você conecte novas integrações com um único clique.

### Video Stack

O Video Stack permite criar vídeos animados com código, aproveitando imagens e vídeos gerados para visuais de movimento criativos. Construa vídeos animados inteiramente com código diretamente no seu projeto no Replit.
