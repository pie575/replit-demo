<div id="claude-opus-45">
  ### Prise en charge de Claude Opus 4.5
</div>

Claude Opus 4.5 est désormais pris en charge dans les intégrations d&#39;IA : vous accédez ainsi aux toutes dernières capacités d&#39;IA d&#39;Anthropic, optimisées pour le codage et les agents.

<div id="replit">
  ### Bouton « Ouvrir dans Replit » (bêta)
</div>

Grâce au nouveau bouton « Ouvrir dans Replit », vous pouvez désormais traiter vos tickets Linear directement depuis Replit. Cette fonctionnalité en bêta doit être activée dans les paramètres d&#39;environnement ; elle remplit automatiquement le prompt avec les détails du ticket. L&#39;équipe travaille avec Linear pour enrichir cette intégration.

<div id="agent-sql">
  ### Accès d&#39;Agent aux bases de données SQL de production
</div>

Agent peut désormais consulter et interroger les bases de données SQL de production en mode lecture seule, ce qui vous permet de travailler avec de vraies données de production sans risque de modification accidentelle.

<div id="section-3">
  ### Amélioration de la stabilité des connexions
</div>

Plusieurs améliorations destinées à enrichir l&#39;expérience des intégrations :

* Processus de reconnexion en arrière-plan amélioré, réduisant les risques d&#39;expiration des jetons de connexion
* Indication claire lorsqu&#39;une connexion se trouve dans un état anormal ou en erreur
* Possibilité de reconnecter une intégration directement depuis l&#39;état d&#39;erreur

<div id="section-5">
  ### Budgets au niveau des utilisateurs/groupes
</div>

La gestion des budgets est désormais activée pour tous les clients Enterprise :

* Les administrateurs d&#39;équipe Enterprise peuvent définir un budget d&#39;utilisation par défaut pour l&#39;ensemble des membres
* Les administrateurs peuvent définir des budgets pour des groupes spécifiques (par exemple, administrateurs/membres et groupes personnalisés)
* Bientôt disponible : les administrateurs pourront définir des budgets spécifiques qui prévalent pour certains utilisateurs
