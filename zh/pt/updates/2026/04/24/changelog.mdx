<div id="security-agent-revisa-toda-a-sua-base-de-cdigo">
  ### Security Agent 审查你的整个代码库
</div>

**Security Agent** 是一款全新的 AI 审查工具，它不只审计依赖项，而是覆盖整个 项目。它会构建威胁模型，梳理路由与数据流，使用 Semgrep 和 HoundDog.ai 执行静态分析，并借助大语言模型判断哪些 findings 在你的 App 场景下真正可被利用。审查完成后，Security Agent 会将已采纳的 findings 整理为并行任务，交由 Replit Agent 一次性修复。

<Frame>
  <img src="/assets/mirror/security-agent-findings-b425392bb98a.png" alt="Project Security Center 中的 Security Agent 面板，显示一次已完成的扫描，其中五项 findings 按严重程度排列，每项都带有“待审查”或“待重新发布”等状态，下方是依赖项自动扫描部分，列出了存在漏洞的包" width="1438" height="808" data-path="images/changelog/2026-04-24/security-agent-findings.png" />
</Frame>

Security Agent 面向所有付费 构建者开放。打开 项目 中的**安全**面板，选择**使用 Agent 运行扫描**即可体验。

详细了解 [Security Agent](/zh/pt/core-concepts/security/project-security-center#agent-security-scans)。

<div id="cve-auto-protect-corrige-vulnerabilidades-crticas-automaticamente">
  ### CVE Auto-Protect 自动修复严重漏洞
</div>

当你的应用所依赖的某个包被披露新的严重 CVE 时，**CVE Auto-Protect** 会在你拥有的所有 项目 中检测出受影响的部分，并让 Agent 在后台任务中准备补丁、运行你的测试以确保不会破坏现有功能，然后通过一个审查链接通知你。控制权始终在你手中——在你批准修复之前，不会发布任何内容。

这意味着新漏洞公开后几分钟内，你的应用就能完成修复，而不必等到你自己发现问题。

进一步了解 [CVE Auto-Protect](/zh/pt/core-concepts/security/project-security-center#auto-protect)。

  ### 在 iOS Simulator 或 Android Emulator 中预览
</div>

<Frame>
  <video autoPlay muted loop playsInline src="/assets/mirror/ios-emulator-9013ff1b602f.mp4" />
</Frame>

当你的项目包含移动应用时，预览面板现在可以直接在 workspace 中串流真实的 **iOS Simulator** 或 **Android Emulator**，无需 Xcode、无需 Android Studio，也无需实体设备。用 Agent 创建一个移动应用，在预览面板的下拉菜单中选择设备，即可像手持真机一样操作。Agent 每做一次修改，模拟器都会即时重新加载。

该功能面向 Core、Pro 和 Enterprise 付费方案的构建者开放，支持 Chrome、Safari 及基于 Chromium 的浏览器。Firefox 不支持移动模拟器。

进一步了解[在模拟器或仿真器中预览](/zh/pt/replitai/building-mobile-apps#preview-on-a-simulator-or-emulator)。

在 Agent 4 发布之前创建的项目现在可以升级为支持多个 artifact——也就是说，你可以在此前只支持单个 artifact 的项目中添加移动应用、路演演示文稿或其他 artifact。Agent 在重新组织项目时会保留你的 URL、数据、Secrets 和 deployment。在更大范围发布后的最初 48 小时内，已有超过 200 个项目完成迁移。

<div id="conector-plaid-disponvel">
  ### Plaid 连接器现已推出
</div>

现在，你可以通过 **Plaid** 连接器接入超过 12,000 家金融机构。团队管理员只需在**集成**中配置一次凭据，你的 App 用户即可通过 Plaid Link 验证各自的银行账户。访问令牌按用户划分作用域，数据始终保持私密。

你可以打造基于真实交易数据的个人理财教练、连接券商账户的实时投资组合追踪器等各类应用。访问 [Replit x Plaid 合作伙伴页面](https://replit.com/partners/plaid) 查看演示和配置步骤。

进一步了解[如何管理连接器](/zh/pt/replitai/managing-connectors)。
