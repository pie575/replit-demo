<div id="project-editor">
  ## 什么是 Project Editor？
</div>

Project Editor 是你在 Replit 的大本营：在这里开始构建、管理项目，看着应用逐步成形。只需描述你想构建的内容，[Agent](/zh/ko/features/agent/overview) 就会编写代码、配置项目，并实时呈现实时预览。

<div id="section">
  ## 开始使用
</div>

在提示词框中输入你想构建的内容。用日常语言描述你的想法——比如&quot;一个用图表展示我支出情况的预算追踪器&quot;&quot;我的咖啡店的着陆页&quot;&quot;面向儿童的 AI 漫画书生成器&quot;——剩下的交给 Agent。

<AgentInput />

你也可以在轮播中选择项目类型，告诉 Agent 你想要哪种输出：网页应用、移动应用、幻灯片、设计等。或者跳过选择，直接描述你的想法，Agent 会自动确定合适的设置。

<AgentCarousel />

想立即上手，请参阅[构建你的第一个应用](/zh/ko/build/your-first-app)。

<div id="plan">
  ## Plan 模式
</div>

使用 Plan 模式，你可以进行头脑风暴、提出问题并规划项目。它会生成一份有序的任务列表，你可以让 Agent 检查并完善——对计划满意后点击批准，Agent 就会开始构建。你也可以用 Plan 模式提问或探索想法；在你退出之前，Agent 不会做任何更改。

<AgentInput highlightPlan={true} showTypewriter={false} />

通过输入框底部的按钮切换 Plan 模式。详见 [Plan 模式指南](/zh/ko/features/agent/plan-mode)。

<div id="section-2">
  ## 你可以构建什么
</div>

选择项目类型，告诉 Agent 你想要什么；或者直接描述你的想法，让 Agent 为你选择合适的配置。

* **网页应用** — 仪表板、内部工具、SaaS 产品、着陆页
* **移动应用** — 一条提示词生成 iOS 和 Android 应用
* **幻灯片与演示文稿** — 生成布局丰富的演示文稿
* **动画** — 交互式演示流程和动态图形
* **设计** — 在 [Design Canvas](/zh/ko/design/canvas) 中制作视觉模型与原型
* **数据可视化** — 图表、仪表板、基于数据库的工具
* **文档** — CSV、PDF、PowerPoint 文件、Markdown 文档
* **电子表格** — 数据表格与结构化输出

<div id="project-editor-2">
  ## Project Editor
</div>

Agent 开始构建后，你可以在 Project Editor 中看到项目逐步成形。界面分为两个面板：一侧是与 Agent 的对话，另一侧是应用的实时预览。

<div id="section-3">
  ### 线程
</div>

与 Agent 的所有对话都在线程中进行。主线程是你描述需求、并实时查看 Agent 构建过程的地方。使用[任务系统](/zh/ko/core-concepts/agent/task-system)时，每个后台任务都拥有自己的线程——这样 Agent 就能让各项任务保持隔离，不会把对话混在一起。

  ## 常见问题

<Accordion title="我需要会编程吗？">
