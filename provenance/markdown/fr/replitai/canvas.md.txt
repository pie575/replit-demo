export const YouTubeEmbed = ({videoId, title = "YouTube video", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

## Qu'est-ce que le Canvas ?

Le Canvas est un espace pour explorer et itérer sur des designs avec l'Agent. Ici, vous verrez vos artefacts — comme des applications, des vidéos et des diapositives — affichés dans un cadre. Vous pouvez travailler avec l'Agent pour créer des maquettes, comparer des directions de design et appliquer les modifications à votre application — le tout depuis un tableau visuel unique.

## Ce que contient le Canvas

Le Canvas est un tableau infini où vous pouvez tout voir et travailler visuellement.

<Frame>
  <img src="https://mintcdn.com/replit/oJ1dYuTDBrvuslEj/images/replitai/canvas-mockups.png?fit=max&auto=format&n=oJ1dYuTDBrvuslEj&q=85&s=ef0f0cbde2c8685772a84dc07c10ac24" alt="Canvas affichant plusieurs maquettes de design disposées côte à côte — thème sombre, vues mobiles et pages de détail" width="3452" height="1620" data-path="images/replitai/canvas-mockups.png" />

* **Vos applications** : Vos applications en cours d'exécution apparaissent comme des aperçus interactifs en direct sur le Canvas. Vous pouvez cliquer dessus et les utiliser comme vous le feriez dans un navigateur.
* **Maquettes de design** : Des prototypes visuels créés par l'Agent. Ceux-ci ressemblent à de vraies pages — vous pouvez interagir avec eux, les redimensionner et demander à l'Agent de les modifier — mais ils sont séparés de votre application en direct pour que vous puissiez expérimenter librement.
* **Formes et dessins** : Rectangles, cercles, étoiles, flèches, cœurs et plus encore. Utilisez-les pour esquisser des idées brutes, annoter des designs ou cartographier la façon dont les écrans se connectent.
* **Texte et notes autocollantes** : Ajoutez des étiquettes ou des notes n'importe où sur le Canvas pour organiser vos idées.
* **Images** : Déposez des captures d'écran ou des images de référence sur le Canvas. L'Agent peut les recréer ou s'en inspirer.
* **Vidéos** : Placez des fichiers vidéo sur le Canvas aux côtés de votre autre contenu.

Dites quelque chose comme « Rends cette application réelle » ou « Ajoute un backend à ceci. » L'Agent construit tout ce dont il a besoin pour fonctionner comme une vraie application publiable.

</Steps>

## Foire aux questions

<Accordion title="Les cadres de design sont-ils identiques à mon application en cours d'exécution ?">
  Non. Les cadres de design sont des prototypes visuels — ils ressemblent à la vraie chose, mais n'ont pas de backend ou de base de données fonctionnels derrière eux. Les aperçus de votre application sur le Canvas, en revanche, sont votre vraie application en cours d'exécution.
</Accordion>

<Accordion title="Puis-je repenser une page sans casser mon application en direct ?">
  Oui. Demandez à l'Agent d'amener une page sur le Canvas — par exemple, « Mets mon tableau de bord sur le canvas. » L'Agent en fait une copie avec laquelle vous pouvez expérimenter. Votre application en direct n'est pas affectée tant que vous ne choisissez pas d'appliquer les modifications.
</Accordion>

<Accordion title="Comment transformer un design en vraie application ?">
  Demandez à l'Agent d'en faire une application complète (« Rends ceci réel ») ou convertissez-le en un type spécifique (« Convertis ceci en application web »). L'Agent construit tout ce dont il a besoin pour devenir une application fonctionnelle et publiable.
</Accordion>

<Accordion title="Puis-je convertir en types autres que les applications web ?">
  Oui. Vous pouvez transformer des cadres Canvas en applications web, applications mobiles, diapositives, visualisations de données, et plus encore.
</Accordion>

<Accordion title="Puis-je importer des designs depuis Figma ou d'autres outils ?">
  Oui. Il existe plusieurs façons d'importer des designs Figma dans Replit :

  * **Importer depuis Figma** : Rendez-vous sur [replit.com/import](https://replit.com/import), connectez votre compte Figma et collez une URL de cadre pour convertir un design en application React fonctionnelle. Voir le [guide de démarrage rapide Import depuis Figma](/fr/getting-started/quickstarts/import-from-figma) pour plus de détails.
  * **Figma MCP dans le chat Agent** : Collez un lien Figma directement dans le chat Agent et demandez-lui de générer du code, d'extraire des données de design ou de construire un composant à partir du design. Voir le guide [Intégration Figma MCP](/replitai/mcp/figma).
  * **Référence par capture d'écran** : Déposez une capture d'écran sur le Canvas et demandez à l'Agent de recréer le design à partir de celle-ci.
</Accordion>

<Accordion title="Que puis-je d'autre mettre sur le Canvas ?">
  En plus des maquettes de design et des aperçus d'applications, vous pouvez ajouter des formes, des flèches, des étiquettes de texte, des notes autocollantes, des images et des vidéos — utiles pour esquisser des idées, annoter des designs ou organiser votre réflexion.
</Accordion>

## Disponibilité

Le Canvas est disponible sur tous les plans, y compris la création de cadres, l'édition en ligne, la génération de variantes et la conversion en artefacts. Transformer des designs en applications complètes nécessite un plan payant.
