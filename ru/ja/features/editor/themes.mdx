Темы Replit позволяют настроить внешний вид редактора проекта — от цвета фона и элементов интерфейса до подсветки синтаксиса кода. Персонализируйте среду разработки, чтобы улучшить читаемость, снизить нагрузку на глаза и сделать процесс написания кода приятнее.

<div id="section">
  ## Создание пользовательской темы
</div>

Чтобы создать и настроить собственную тему, выполните следующие действия:

1. Откройте [настройки](https://replit.com/settings) и перейдите в раздел **Пользователь** → **Персонализация** (или раздел **Темы**)
2. Выберите **Создать новую тему**
3. Введите название, выберите цветовую схему (светлую или тёмную) и при желании добавьте описание
4. Выберите **Создать тему**, чтобы открыть редактор тем

Глобальные настройки темы определяют общий вид интерфейса:

* **Фон**: задаёт основной цвет для большинства элементов интерфейса
* **Контур**: управляет цветом границ и разделителей
* **Передний план**: определяет цвет текста и значков
* **Основной**: задаёт цвет кнопок и интерактивных элементов
* **Положительный**: применяется к индикаторам успеха, например к кнопке **Запустить**
* **Отрицательный**: используется для ошибок и предупреждений о необратимых действиях

Выберите **Применить тему**, чтобы сразу начать пользоваться своей темой.

<div id="section-2">
  ## Подсветка синтаксиса
</div>

Настройте отображение различных элементов кода, чтобы повысить читаемость и облегчить понимание.

<Tip>
  Правильно настроенная подсветка синтаксиса позволяет схватывать смысл кода с первого взгляда. Выбирайте цвета, которые хорошо сочетаются друг с другом и достаточно контрастны на фоне редактора.
</Tip>

<Accordion title="Элементы подсветки синтаксиса">
  | Элемент                    | Описание                                                                                       |
  | -------------------------- | ---------------------------------------------------------------------------------------------- |
  | **Имя переменной**         | Применяется к переменным, объявленным без ключевого слова                                      |
  | **Определение переменной** | Задаёт цвет имён переменных, определённых с помощью ключевых слов, таких как `const` или `var` |
  | **Ссылка на функцию**      | Применяется при вызове функции                                                                 |
  | **Определение функции**    | Задаёт цвет имени функции при её объявлении                                                    |
  | **Ключевое слово**         | Подсвечивает ключевые слова языка, такие как `import`, `function`, `return`                    |
  | **Имя свойства**           | Задаёт цвет обращения к свойству переменной                                                    |
  | **Определение свойства**   | Используется при определении свойств объекта                                                   |
  | **Свойство-функция**       | Применяется при вызове методов объекта                                                         |
  | **Имя тега**               | Используется для тегов HTML и JSX                                                              |
  | **Имя типа**               | Задаёт цвет аннотаций типов в типизированных языках                                            |
  | **Имя класса**             | Применяется к объявлениям классов и ссылкам на них                                             |
  | **Имя атрибута**           | Подсвечивает атрибуты HTML и JSX                                                               |
  | **Комментарий**            | Применяется ко всем комментариям в коде                                                        |
  | **Строка**                 | Задаёт цвет строковых литералов                                                                |
  | **Число**                  | Подсвечивает числовые значения                                                                 |
  | **Логическое значение**    | Оформляет логические значения (`true`/`false`)                                                 |
  | **Регулярное выражение**   | Задаёт цвет шаблонов регулярных выражений                                                      |
  | **Оператор**               | Подсвечивает операторы, такие как `+`, `-`, `*`, `/`                                           |
  | **Скобки**                 | Задаёт цвет квадратных и угловых скобок там, где это уместно                                   |
</Accordion>

<div id="section-3">
  ## Рекомендации по оформлению темы
</div>

Следуйте приведённым ниже рекомендациям, чтобы создать визуально привлекательную и функциональную тему:

<div id="section-4">
  ### Цвет и контрастность
</div>

* **Соблюдайте баланс контрастности**: обеспечьте достаточную разницу между фоном и элементами переднего плана
* **Создайте единую палитру**: выбирайте цвета, которые дополняют друг друга, а не конфликтуют между собой
* **Сохраняйте одинаковую яркость**: поддерживайте схожий уровень яркости у всех элементов синтаксиса
* **Учитывайте доступность**: избегайте низкоконтрастных сочетаний, чтобы не создавать сложностей пользователям с нарушениями зрения

<Warning>
  Избегайте распространённых ошибок при разработке тем:

  * чрезмерная разница в яркости между элементами синтаксиса
  * цветовые сочетания, создающие визуальный диссонанс
  * недостаточная контрастность между кодом и фоном
</Warning>

<div id="section-5">
  ## Управление темами
</div>

Просматривать все установленные темы и управлять ими можно в разделе [Настройки](https://replit.com/settings) → **Пользователь** → **Персонализация** (или в разделе **Темы**).

<div id="section-6">
  ### Переключение темы
</div>

Нажмите кнопку рядом с названием темы, чтобы сделать её текущей.

<div id="section-7">
  ### Редактирование темы
</div>

Чтобы изменить пользовательскую тему, откройте меню с тремя точками и нажмите **Изменить**.

<Note>
  Редактировать и удалять можно только пользовательские темы, созданные вами. Темы по умолчанию и темы других пользователей изменять нельзя.
</Note>

<div id="section-8">
  ### Удаление темы
</div>

Чтобы удалить пользовательскую тему, выберите **Удалить** в меню с тремя точками.

<div id="section-9">
  ## Обзор тем сообщества
</div>

Находите темы, созданные сообществом Replit, на [странице обзора тем](https://replit.com/themes).

<div id="section-10">
  ### Поиск тем
</div>

* Ищите по названию, чтобы найти конкретную тему, например «Atom One Dark»
* Фильтруйте по автору, чтобы посмотреть темы определённого创 создателя
* Просматривайте темы по цветовой схеме, чтобы выбрать светлую или тёмную
* Ищите по конкретному цвету, чтобы подобрать тему под свои предпочтения

Перед установкой тему можно предварительно просмотреть и оценить, как она будет выглядеть в редакторе проекта.

<div id="section-11">
  ## Публикация темы
</div>

Чтобы поделиться пользовательской темой с сообществом Replit, выполните следующие шаги:

1. Откройте редактор тем для вашей пользовательской темы
2. Нажмите кнопку **Опубликовать**
3. Заполните поля названия и описания
4. Отправьте тему

После публикации тема появится на странице обзора тем, где другие пользователи смогут просмотреть и установить её.
