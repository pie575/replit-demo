<div id="prvias-de-checkpoint">
  ### checkpoint 预览
</div>

Replit 开发环境现已推出 checkpoint 预览功能。无需重新构建或还原到早期版本，即可查看应用在各个开发阶段的样子。

这让追踪进度、比较迭代和版本管理更加轻松，帮你全面了解项目的演进过程。该功能与 [vibe coding 工作流](https://learn.replit.com)相得益彰。

<div id="viagem-no-tempo-do-replit">
  ### Replit 时光回溯
</div>

时光回溯功能正式登陆 Replit。你可以在保留开发上下文的同时，流畅地浏览 project 的历史记录。

探索不同版本、了解变更的演进过程、从错误中恢复，并更放心地进行尝试——这一切都在你当前的开发环境中完成。该功能与 [Git 集成](/zh/pt/core-concepts/project-editor/version-control)相辅相成，带来更强大的版本控制能力。

<div id="pea-ao-agent-para-adicionar-um-banco-de-dados">
  ### 让 Agent 帮你添加数据库
</div>

有了数据库面板中的 Agent 集成，配置数据库变得非常简单。这套 AI 工作流会一步步引导你完成数据库设置，无需编写复杂的配置代码即可实现数据持久化。

开发者可以专注于构建核心功能，数据库的细节则交给 Agent 处理。进一步了解 [Replit Agent](/zh/pt/core-concepts/agent) 和[数据库选项](/zh/pt/category/storage-and-databases)。

<div id="correspondncia-de-auth-do-replit-por-padro">
  ### 默认匹配 Replit Auth
</div>

有了 Replit Auth 自动匹配，在你的应用中实现用户身份验证变得轻而易举。

当你的应用需要身份验证时，该功能会自动启用，省去了自定义注册表单、密码找回系统和社交登录配置的麻烦，让安全的用户管理更加顺畅。

<div id="verificao-de-e-mail-em-tela-cheia">
  ### 全屏邮箱验证
</div>

针对受保护操作的简化验证流程，进一步提升账户安全性。

这一集成式方案会在登录后按需展示邮箱验证，既保障了账户安全，又保持了一致的用户体验——在安全与便捷之间取得平衡。

这是我们持续投入[信息安全](/zh/pt/teams/information-security/overview)的举措之一。

<div id="blueprint-do-google-analytics">
  ### Google Analytics 蓝图
</div>

使用 Google Analytics 蓝图监控应用的运行表现。

Agent 现在可将分析配置直接集成到你的开发工作流中，无需复杂设置即可实现流量监控、用户行为跟踪和增长指标分析。

这让每位开发者都能用上专业级的分析能力。立即通过 [Agent 集成](/zh/replitai/integrations)体验。

<div id="scim-para-clientes-enterprise">
  ### 面向 Enterprise 客户的 SCIM
</div>

全新的 SCIM 集成让 Enterprise 客户能够直接通过自己的身份提供商管理 Replit 访问权限。

连接 Okta、Active Directory、Rippling 或其他身份平台，即可自动完成 Replit 席位的开通与回收，免去手动管理用户的负担，让企业工作流程更加顺畅。

请阅读[SCIM 详细文档](/zh/pt/teams/identity-and-access-management/scim)，快速上手。

<div id="assentos-de-visualizador-para-replit-teams">
  ### Replit Teams 查看者席位
</div>

隆重推出 Replit Teams 查看者席位。现在，您可以将应用分享给只需查看和使用 (而非编辑) 应用的相关方，无需为他们购买完整的团队席位。

非常适合分享给使用但不参与构建工具的高管、客户或团队成员。了解如何设置和管理[查看者席位](/zh/pt/teams/identity-and-access-management/viewer-seats)。
