你曾在[欢迎来到 Replit](/zh/welcome)中见过 Velocity——一款高端超级跑车租赁应用。目前，任何访问公开 URL 的人都能看到所有预订。没人会匿名预订 Lamborghini。添加登录功能后，每位客户都能查看自己的预订和已保存的车辆。

<div id="tell-agent-to-add-sign-in">
  ## 让 Agent 添加登录功能
</div>

Velocity 请使用 Clerk。Replit 的 Clerk 集成可为你的应用提供专属品牌登录页面、仅存在于 Velocity 中的客户账户 (而非 Replit 账户) ，并让你能够完全掌控外观和体验——非常适合高端租赁品牌。Agent 会自动完成所有配置，因此无需注册 Clerk 控制台，也无需粘贴密钥。

Agent 将为 Velocity 配置一个 Clerk 租户，添加登录组件，限制预订流程仅限登录用户使用，将每项预订关联到已登录客户，并添加退出登录功能。在 Agent chat 中查看构建过程。

<div id="test-it-with-two-customers">
  ## 使用两个客户账户进行测试
</div>

一个账户不够——你需要两个账户，以证明预订信息彼此独立。

1. 在 Preview 中打开 Velocity，在不登录的情况下浏览车辆。车队列表仍应可见。
2. 点击某辆车的“预订”。你应该会进入 Clerk 登录页面。
3. 使用自己的电子邮箱注册，并完成一次预订 (例如预订一辆 911 过周末) 。
4. 退出登录。“我的预订”部分应消失，预订流程应再次要求你登录。
5. 在无痕窗口中打开 Preview，使用另一个电子邮箱注册。预订另一辆车。
6. 切回第一个窗口，登录并确认你仍能看到自己的预订，而不是第二位客户的预订。

如果两位客户都能看到相同的预订，说明这些预订尚未关联到已登录的用户。请将具体问题告诉 Agent：

<div id="publish-and-sign-in-on-the-public-url">
  ## 在公开 URL 上发布并登录
</div>

通过 Agent chat 或 Publishing 磁贴再次发布 Velocity，然后在新标签页中打开公开 URL 并登录。Clerk 配置了独立的开发环境与生产环境 — Agent 会自动将生产环境凭据接入已发布的 App，因此你可以直接在公开 URL 上登录。

Velocity 现在已有真实客户。每位客户登录后都只能看到自己车库中的预订，其他人无法查看。

<div id="need-further-help">
  ## 还需要帮助？
</div>

* **整个 App 都被隐藏了：**让 Agent 保持车辆浏览页面公开，仅保护预订和账户页面。
* **客户能看到彼此的预订：**让 Agent 将每笔预订和已保存的车辆关联到对应的已登录客户。
* **登录在 Preview 中正常，但发布后无法使用：**在新标签页中打开公开 URL，并将看到的具体错误告知 Agent。确保 Agent 已配置 Production Clerk 环境。
* **你想为原型快速实现零配置登录：**Replit Auth 使用客户的 Replit 账户，无需管理 Clerk 租户。请参阅 [Replit Auth](/zh/features/auth-and-identity/authentication)。
