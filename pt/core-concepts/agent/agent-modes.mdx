Os modos do Agent permitem controlar o equilíbrio entre velocidade, custo e capacidade ao usar o Agent. Use o seletor de modo principal no menu suspenso de configurações do Agent para alternar entre **Lite**, **Economy** e **Power**. Expanda as **Configurações avançadas** quando quiser mais controle sobre testes, revisão de código e Turbo.

<Tip>
  **Atalho de teclado:** Pressione **⌘+Shift+I** (Ctrl+Shift+I no Windows) para alternar entre os modos do Agent sem sair da entrada de chat.
</Tip>

<Note>O modo Max não está mais disponível. Use Power para as builds padrão mais capazes e ative o Turbo nas Configurações avançadas quando precisar das execuções mais rápidas.</Note>

## Modo Lite

**Otimizado para edições rápidas.** O Lite usa modelos rápidos e leves para ajustes visuais, correções de bugs e outras alterações pequenas e bem delimitadas.

<Frame>
  <img src="/assets/mirror/agent-modes-lite-05ad32f8f34e.png" alt="Menu suspenso de modos do Agent com Lite selecionado" width="1192" height="1328" data-path="images/replitai/agent-modes-lite.png" />
</Frame>

**Melhor para:** Correções rápidas, polimento de UI e ciclos curtos de iteração enquanto você permanece no teclado.

**Tenha em mente:** O Lite funciona melhor em aplicativos existentes quando você já sabe o que quer mudar. Se você está começando do zero, fazendo grandes mudanças arquiteturais, adicionando uma nova integração ou alterando um esquema de banco de dados, mude para Economy ou Power.

**Custo:** O Lite usa o mesmo modelo de precificação baseado em esforço que os outros modos de build, mas solicitações focadas geralmente custam menos que Economy ou Power para a mesma edição direcionada.

## Modo Economy

**Otimizado para custo.** O Economy usa menos créditos por tarefa e é o melhor padrão quando você quer resultados sólidos sem pagar pelos modelos mais capazes.

<Frame>
  <img src="/assets/mirror/agent-modes-economy-6ae501cc69d6.png" alt="Menu suspenso de modos do Agent com Economy selecionado e Configurações avançadas expandidas" width="1192" height="1328" data-path="images/replitai/agent-modes-economy.png" />
</Frame>

**Melhor para:** Builds do dia a dia, aprendizado e trabalho consciente de custo em um projeto existente.

## Modo Power

**Otimizado para capacidade.** O Power usa modelos mais capazes para tarefas complexas, bases de código maiores e problemas mais difíceis.

<Frame>
  <img src="/assets/mirror/agent-modes-power-f956985e7037.png" alt="Menu suspenso de modos do Agent com Power selecionado e Configurações avançadas expandidas" width="1192" height="1328" data-path="images/replitai/agent-modes-power.png" />
</Frame>

**Melhor para:** Projetos de nível de produção, funcionalidades complexas e quando você quer os melhores resultados do Agent.

## Configurações avançadas

Expanda as **Configurações avançadas** no menu suspenso para gerenciar o restante dos controles de build do Agent:

* **Testes de App** permite que o Agent teste seu aplicativo automaticamente em um navegador.
* **Otimizações de Código** permite que o Agent revise e melhore seu próprio código enquanto trabalha.
* **Turbo** fornece os modelos mais rápidos disponíveis quando você está no modo Power.

O Lite mantém os Testes de App e as Otimizações de Código desativados, e o Turbo só está disponível enquanto o Power está selecionado.

## Modo Turbo

**O Turbo é um toggle separado dentro das Configurações avançadas.** Ative-o no modo Power quando quiser respostas **2,5x mais rápidas** usando os modelos mais rápidos. As solicitações podem custar até 6x mais que o Power, então o Turbo é melhor quando a velocidade importa mais que a eficiência.

<Frame>
  <img src="/assets/mirror/agent-modes-turbo-5bd95033d396.png" alt="Menu suspenso de modos do Agent com Power selecionado e Turbo ativado nas Configurações avançadas" width="760" height="502" data-path="images/replitai/agent-modes-turbo.png" />
</Frame>

<Warning>
  O Turbo é destacado em laranja no menu suspenso de modos do Agent como um lembrete visual de que custa significativamente mais que o Power. Fique de olho no destaque quando estiver iterando rapidamente — ele está lá para manter o trade-off de custo visível.
</Warning>

**Disponibilidade:** **Somente Pro e Enterprise.**

**Melhor para:** Quando você precisa da resposta mais rápida possível do Agent e está em um plano Pro ou Enterprise.

## Qual modo devo usar?

Use o seguinte como guia:

| Objetivo                                                 | Modo recomendado               |
| -------------------------------------------------------- | ------------------------------ |
| Edições pequenas e bem delimitadas com iterações rápidas | Lite                           |
| Maximizar o número de prompts por crédito                | Economy                        |
| Equilibrar custo e qualidade para a maioria dos projetos | Power                          |
| Resposta mais rápida em tarefas maiores                  | Power + Turbo (Pro/Enterprise) |

Você pode mudar de modo a qualquer momento no menu suspenso de configurações do Agent na entrada de chat. Escolha Lite, Economy ou Power no controle principal, depois expanda as Configurações avançadas quando quiser mais controle sobre testes, revisão de código ou Turbo. Nenhum modo é sempre o melhor — escolha o que se adapta à tarefa diante de você.
