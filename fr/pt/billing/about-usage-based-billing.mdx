La facturation à l’usage des déploiements comprend trois éléments :

1. Transfert de données sortantes
2. Unités de calcul avec mise à l’échelle automatique
3. Requêtes

Vous pouvez consulter votre utilisation dans **Paramètres**, sous **Compte** → **Utilisation du compte**. La facturation est mensuelle ou intervient lorsque vos coûts cumulés dépassent vos crédits mensuels. Les utilisateurs de Replit Core et Pro bénéficient de quotas mensuels pour ces ressources.

Si vous avez besoin de crédits supplémentaires au-delà de votre quota mensuel inclus dans votre abonnement, vous pouvez acheter des packs de crédits sur votre page de facturation. Consultez [Gérer vos dépenses](/fr/pt/billing/managing-spend) pour en savoir plus sur les packs de crédits.

<div id="1-transferncia-de-dados-de-sada-de-publicao">
  ## 1. Transfert de données sortantes de déploiement
</div>

Ce type d&#39;utilisation est facturé à l&#39;octet, les utilisateurs Replit Core et Pro bénéficiant de quotas mensuels. Seules les données sortantes (egress) sont comptabilisées dans ce quota et peuvent entraîner des frais de dépassement. À l&#39;inverse, les données entrantes (ingress) sont toujours gratuites.

| Abonnement  | Quota                                                           |
| ----------- | --------------------------------------------------------------- |
| Replit Core | 100 Gio                                                         |
| Replit Pro  | Voir les [tarifs de Replit Pro](https://www.replit.com/pricing) |

Les quotas s&#39;appliquent aux déploiements [statiques](/fr/pt/features/publishing/deployment-types#static), [avec mise à l’échelle automatique](/fr/pt/features/publishing/deployment-types#autoscale), [sur VM réservée](/fr/pt/features/publishing/deployment-types#reserved-vm) et [planifiés](/fr/pt/features/publishing/deployment-types#scheduled).

Consultez la [page des tarifs](https://www.replit.com/pricing) pour connaître le prix actuel du transfert de données sortantes.

<div id="2-unidades-de-computao">
  ## 2. Unités de calcul
</div>

Les déploiements avec mise à l&#39;échelle automatique sont facturés en unités de calcul, qui tiennent compte de l&#39;utilisation du CPU et de la RAM au fil du temps.

Les dépassements sont facturés en unités de calcul. La facturation est calculée à l&#39;unité de calcul près. Consultez la [page des tarifs](https://www.replit.com/pricing) pour connaître le tarif actuel des unités de calcul.

Découvrez ci-dessous comment les secondes de RAM et de CPU d&#39;un déploiement avec mise à l&#39;échelle automatique se traduisent en unités de calcul :

| Ressource        | Unités de calcul |
| ---------------- | ---------------- |
| 1 seconde de RAM | 2 unités         |
| 1 seconde de CPU | 18 unités        |

Les déploiements statiques ne consomment pas d&#39;unités de calcul. Leur facturation concerne exclusivement les transferts de données sortantes au-delà d&#39;un [montant spécifié](#).

[En savoir plus sur les déploiements avec mise à l&#39;échelle automatique](/fr/pt/features/publishing/deployment-types#autoscale).

<div id="bancos-de-dados">
  # Bases de données
</div>

Replit facture uniquement l’utilisation des [bases de données de production](/fr/pt/features/data-and-storage/development-and-production) : les bases de données de développement sont toujours gratuites et incluses dans toutes les Replit Apps. Pour en savoir plus sur les bases de données de développement, consultez [Base de données de développement](/fr/pt/features/data-and-storage/sql-database).

Le PostgreSQL de Replit est entièrement géré et sans serveur, offrant une haute disponibilité sans effort et ne nécessitant aucune maintenance. La facturation des bases de données de production est basée sur l’utilisation réelle, ce qui peut générer des économies considérables.

Les bases de données PostgreSQL de production sont facturées selon deux métriques d’utilisation :

* **[Temps de calcul](#compute-time)** : quantité de ressources de calcul consommées par heure.
* **[Stockage des données](#data-storage)** : volume total des données stockées, y compris les données historiques.

Vous pouvez consulter votre utilisation actuelle des ressources, y compris celle des bases de données de production, dans **Paramètres** → **Compte** → **Utilisation du compte**.

<div id="tempo-de-computao">
  ## Temps de calcul
</div>

Le temps de calcul correspond au nombre d&#39;heures pendant lesquelles votre base de données reste active au cours d&#39;une période de facturation donnée. Une base de données est considérée comme active lorsqu&#39;elle reçoit des requêtes, ainsi que pendant les 5 minutes qui suivent la dernière requête. Si une base de données reste inutilisée pendant 5 minutes, elle est suspendue et passe à l&#39;état inactif.

<div id="armazenamento-de-dados">
  ## Stockage des données
</div>

Le stockage des données correspond au volume total de données stockées dans toutes les bases de données de votre compte, mesuré en gibioctets (GiB). Il est calculé en fonction du volume maximal utilisé au cours du mois. Chaque base de données PostgreSQL utilise 33 Mo de stockage, même si elle ne contient aucune donnée. Il s’agit de l’espace de stockage standard du serveur Postgres.

<Note>La limite de stockage totale de chaque base de données de production est de 10 gibioctets (GiB). Les bases de données de développement incluent 20 GiB de stockage gratuit par Replit App.</Note>
