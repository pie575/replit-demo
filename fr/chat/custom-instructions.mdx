Les Instructions personnalisées sont des directives toujours actives que vous ou votre équipe rédigez une seule fois pour un Espace de travail. Replit les utilise dans tous les Projets et sessions de cet Espace de travail, afin que vous n'ayez pas besoin de répéter les conventions dans chaque Conversation.

Utilisez les Instructions personnalisées pour un petit ensemble de directives toujours valables, comme les bibliothèques approuvées, les exigences de sécurité ou les politiques de gestion des données. Gardez-les courtes et précises afin qu'elles laissent de la place pour le travail en cours.

## Choisissez le bon type de directive

* Utilisez les **Instructions personnalisées** pour des directives à l'échelle de l'Espace de travail qui doivent toujours s'appliquer.
* Utilisez les [Compétences](/fr/chat/agent-skills) pour des approches réutilisables et du matériel de support pertinents uniquement pour certaines tâches.
* Utilisez les [Mémoires](/fr/chat/memories) pour le contexte utile que Replit retient d'un travail passé.

## Configurer les Instructions personnalisées

Gérez les Instructions personnalisées dans **Paramètres de l'Espace de travail → Personnalisation**. Le guide de référence détaillé couvre la configuration, la disponibilité, les permissions et la manière de garder les instructions efficaces.
