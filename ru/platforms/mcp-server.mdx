Replit MCP использует [Model Context Protocol](https://modelcontextprotocol.io/), позволяя создавать, находить, изучать, обновлять и публиковать Replit App прямо из привычных вам ИИ-инструментов.

<div id="use-replit-in-chatgpt-claude-or-slack">
  ## Использование Replit в ChatGPT, Claude или Slack
</div>

Replit подключается напрямую к ChatGPT, Claude и Slack. Выберите платформу, подключите Replit и приступайте к разработке. О требованиях, доступности в тарифах и решении проблем читайте в разделах [Replit в ChatGPT](/ru/features/platforms/chatgpt) и [Replit в Claude](/ru/features/platforms/claude).

<div id="connect-an-mcp-client-directly">
  ## Прямое подключение MCP-клиента
</div>

Используйте прямое подключение, если у вашего MCP-клиента нет встроенной интеграции с Replit.

| Свойство           | Значение                                 |
| ------------------ | ---------------------------------------- |
| **URL**            | `https://replit-mcp.com/server/mcp`      |
| **Транспорт**      | Streamable HTTP                          |
| **Аутентификация** | OAuth с обнаружением защищённого ресурса |

Добавьте URL сервера в MCP-клиент, поддерживающий Streamable HTTP и авторизацию через OAuth. Клиент считает метаданные защищённого ресурса Replit, после чего предложит вам войти в Replit.

Не создавайте собственный OAuth-сервер: MCP-сервер Replit сам предоставляет метаданные OAuth, необходимые вашему клиенту.

Вы можете создавать App или работать с теми App, которые доступны вам для редактирования, включая App, которыми с вами поделились.

<div id="set-up-replit-mcp">
  ### Настройка Replit MCP
</div>

Codex и Claude Code — это лишь примеры. Replit MCP можно добавить в любой совместимый MCP-клиент.

<Tabs>
  <Tab title="Codex">
    <Steps>
      <Step title="Откройте список MCP">
        В Codex откройте **Settings** → **Plugins** → **MCPs**.
      </Step>

      <Step title="Добавьте Replit">
        Добавьте пользовательский MCP. Укажите понятное имя, например `Replit`. Выберите **Streamable HTTP**. Введите `https://replit-mcp.com/server/mcp` и сохраните. Не добавляйте bearer-токен и пользовательские заголовки.

        <Frame>
          <img src="/assets/mirror/codex-add-replit-mcp-51365d598c24.png" alt="Форма пользовательского MCP в Codex с Replit, Streamable HTTP, конечной точкой Replit и пустыми полями bearer-токена и заголовков" width="2000" height="1293" data-path="images/replitai/custom-mcp/codex-add-replit-mcp.png" />
        </Frame>
      </Step>

      <Step title="Пройдите аутентификацию в Replit">
        В списке MCP включите **Replit** и нажмите **Authenticate**. Выберите workspace Replit, который нужно подключить. Затем нажмите **Allow**.

        <Frame>
          <img src="/assets/mirror/codex-authenticate-replit-mcp-38e837424d0f.png" alt="Список MCP в Codex с включённым Replit и кнопкой Authenticate" width="2000" height="1293" data-path="images/replitai/custom-mcp/codex-authenticate-replit-mcp.png" />
        </Frame>

        <Frame>
          <img src="/assets/mirror/codex-authorize-replit-workspace-b41e707504ae.png" alt="Диалог авторизации Replit с условными обозначениями аккаунта и workspace, включая выбор workspace и кнопку Allow" width="1588" height="991" data-path="images/replitai/custom-mcp/codex-authorize-replit-workspace.png" />
        </Frame>
      </Step>

      <Step title="Используйте Replit в Codex">
        Попросите Codex создать, проверить или обновить project в Replit. Например: &quot;Покажи мои недавно обновлённые проекты Replit.&quot;

        <Frame>
          <img src="/assets/mirror/codex-list-replit-projects-bebae6a1dbab.png" alt="Ответ Codex со списком трёх недавно обновлённых проектов Replit" width="2000" height="951" data-path="images/replitai/custom-mcp/codex-list-replit-projects.png" />

<div id="tools">
  ## Инструменты
</div>

| Инструмент                | Обязательные входные данные   | Необязательные входные данные                                             | Назначение                                                                                                                                                                                                                                                                                                          |
| ------------------------- | ----------------------------- | ------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `create_app_from_prompt`  | `appDescription`, `app_stack` | `userSpecifiedAppName`, `userQuotes`, `attachmentSummary`, `sourceReplId` | Создать новое App. `app_stack` принимает одно из значений: `react_website`, `mobile_app`, `design`, `slides`, `animation`, `data_visualization`, `3d_game`, `document` или `spreadsheet`. Укажите `sourceReplId`, чтобы создать новое App как приватную копию существующего App, а не как пустой project. |
| `search_apps`             | Нет                           | `query`, `url`, `updatedAfter`, `updatedBefore`, `limit`                  | Найти App по ключевым словам в названии, по URL или по времени последнего обновления. `limit` — от 1 до 50.                                                                                                                                                                                                  |
| `resolve_app_by_name`     | `name`                        | Нет                                                                       | Найти App по его точному названию.                                                                                                                                                                                                                                                                           |
| `list_apps`               | Нет                           | `query`, `limit`                                                          | Показать список App, доступных вам для редактирования, в порядке недавней активности. Значение по умолчанию — 25, максимальное — 50.                                                                                                                                                                         |
| `ask_question`            | `replId`, `question`          | Нет                                                                       | Задать Agent вопрос о App, не изменяя его.                                                                                                                                                                                                                                                                   |
| `update_app_using_prompt` | `replId`, `changeDescription` | `userQuotes`, `attachmentSummary`                                         | Запустить обновление существующего App через Agent.                                                                                                                                                                                                                                                          |
| `publish_app`             | `replId`                      | Нет                                                                       | Опубликовать App или переопубликовать его последние изменения.                                                                                                                                                                                                                                               |
| `get_publish_status`      | `replId`                      | Нет                                                                       | Проверить, опубликовано ли App, его текущий статус публикации и публичный URL.                                                                                                                                                                                                                               |

<div id="troubleshooting">
  ## Устранение неполадок
</div>

| Проблема                                                      | Что делать                                                                                                                                             |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Replit запрашивает аутентификацию                             | Повторно выполните вход через OAuth в клиенте MCP.                                                                                                     |
| App не найден                                                 | Проверьте, есть ли у вас права на редактирование этого App. Затем выполните поиск по URL или используйте `list_apps`, чтобы выбрать из подходящих App. |
| Запрос на создание, обновление или публикацию ещё выполняется | Подождите, прежде чем повторять попытку. Для публикации используйте `get_publish_status`, чтобы узнать текущий статус.                                 |
