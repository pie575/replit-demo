CLUI (Command Line User Interface) 是 Replit 的交互式命令栏，无需层层浏览菜单即可快速执行各种操作，将命令行的高效与图形界面的直观融为一体。

<div id="section">
  ## 功能
</div>

CLUI 在 Replit 的三种不同场景中提供强大的命令驱动交互：

* **Settings 管理**：管理设置、查看警告并恢复已删除的 Replit 应用
* **快速导航**：在各个 Replit 应用之间跳转，并通过快捷方式访问常用功能
* **Workspace 操作**：在开发环境中查找文件、搜索代码并使用各类工具

<div id="section-2">
  ## 使用方法
</div>

<div id="clui">
  ### 账户 CLUI
</div>

账户 CLUI 可帮助你管理设置、团队以及已删除的 Replit 应用。

**访问方式**：前往 [CLUI 页面](https://replit.com/~/cli)，在输入框中输入命令进行搜索，然后按 Enter 执行。

<Accordion title="账户命令">
  输入 `account` 以管理设置：

  * **view-warns**：查看收到的警告
  * **change-username**：更改用户名 (仅可更改一次) 
</Accordion>

<Accordion title="回收站命令">
  输入 `trash` 以管理已删除的 Replit 应用：

  * **restore &lt;title&gt;**：按标题恢复已删除的 Replit 应用 (若存在多个同名应用，则恢复最近删除的那个) 
  * **view**：查看最近删除的 Replit 应用
</Accordion>

<Accordion title="团队命令">
  输入 `team` 以管理团队：

  * **view**：按用户名查看你所属团队的成员
  * **fork-repl-to-project**：复刻现有的 Replit 应用以创建团队 Project
</Accordion>

<Accordion title="清除命令">
  输入 `clear` 可清空屏幕上已执行的所有历史命令
</Accordion>

<div id="clui-2">
  ### 快捷 CLUI
</div>

快捷 CLUI 让你可以从任意页面快速访问 Replit 的常用功能。

<Frame>
  <img src="/assets/mirror/shortcuts-clui-768d49b44785.png" alt="快捷 CLUI" width="689" height="291" data-path="images/getting-started/shortcuts-clui.png" />
</Frame>

**访问方式**：按 **CMD/CTRL + K**，或点击大多数 Replit 页面顶部导航栏中的搜索图标。

<Accordion title="可用命令">
  * **Search**：搜索 Replit 应用、Templates、Code、People 等
  * **New**：创建新的 Replit 应用
  * **My Replit Apps**：浏览并跳转到你的 Replit 应用
  * **My Code**：搜索所有 Replit 应用中的代码
</Accordion>

<div id="clui-3">
  ### Workspace CLUI
</div>

Workspace CLUI 可帮助你在使用 Replit 应用时执行操作、访问工具、查找文件和搜索代码。

<Frame>
  <img src="/assets/mirror/ws-clui-81764b3d111b.png" alt="Workspace CLUI" width="429" height="202" data-path="images/getting-started/ws-clui.png" />
</Frame>

**访问方式**：在 Workspace 中按 **CMD/CTRL + K**，或点击左上角的搜索图标。

<Accordion title="常见操作">
  * **查找文件**：快速定位项目中的文件
  * **搜索代码**：在所有文件中查找特定代码片段
  * **访问工具**：打开 Workspace 中任意可用的工具或面板
  * **运行命令**：执行 Workspace 专属命令
</Accordion>
