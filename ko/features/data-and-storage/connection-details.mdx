앱은 Replit이 관리하는 자격 증명을 통해 데이터베이스에 연결됩니다. **Database** 도구에서 데이터베이스를 선택하고 **Settings** 탭을 열면 확인할 수 있습니다. 이 탭에서는 연결 문자열, 저장 공간 사용량, 고급 연결 세부 정보를 보여줍니다.

## 환경 변수

개발 데이터베이스에 연결하는 데 다음 환경 변수를 사용할 수 있습니다.

* `DATABASE_URL`: 데이터베이스에 연결하고 인증하는 방법

앱이 이를 자동으로 사용합니다. `DATABASE_URL`은 앱에 한정되어 있으므로, 개발 데이터베이스는 여러분이 소유한 다른 앱이나 외부 데이터베이스 뷰어를 포함한 다른 앱에서 접근할 수 없습니다. 노출되더라도 다른 사람이 이를 이용해 데이터베이스에 접근하거나 수정할 수는 없습니다.

<Info>
  개발 데이터베이스가 아직 [레거시 Neon 인프라](/ko/features/data-and-storage/development-and-production#legacy-development-database)를 사용 중이라면, 추가 변수인 `PGHOST`, `PGUSER`, `PGPASSWORD`, `PGDATABASE`, `PGPORT`도 사용할 수 있습니다. Replit의 현재 인프라에서 호스팅되는 데이터베이스에서는 이러한 변수가 제공되지 **않으며**, 대신 `DATABASE_URL`을 사용해야 합니다.
</Info>

<Warning>
  아직 레거시 Neon 개발 데이터베이스를 사용 중이라면 `DATABASE_URL`을 공유하지 마세요. 여기에는 데이터베이스 자격 증명이 포함되어 있어 누구든 이를 이용해 데이터베이스에 접근하고 수정할 수 있습니다. 공개된 장소나 지원 티켓에 절대 붙여넣지 마세요.
</Warning>

## 외부 도구 연결

프로덕션 데이터베이스의 **Settings** 탭에서 확인한 연결 문자열을 사용하면 PostgreSQL과 호환되는 모든 SQL 클라이언트에서 **프로덕션** 데이터베이스에 연결할 수 있습니다.

## 보안

Agent를 사용해 데이터베이스 통합을 추가하면, 내장 보안 기능을 갖춘 ORM(Object-Relational Mapper)이 추가되어 모든 데이터베이스 통신을 처리합니다.

* **스키마 검증**: 데이터가 예상된 형식을 따르는지 확인합니다
* **데이터 정제(Sanitization)**: SQL 인젝션 공격을 방지하기 위해 빌더 입력을 자동으로 정리합니다

## 프로덕션 데이터베이스 자격 증명 재생성

프로덕션 연결 문자열이 노출된 경우, **Database** 도구에서 자격 증명을 재생성하세요. 이 작업은 Neon 프로덕션 데이터베이스에 새 비밀번호를 생성합니다. 기존 프로덕션 연결 문자열은 즉시 작동을 멈춥니다.

다음 조건이 모두 충족될 때 자격 증명을 재생성할 수 있습니다.

* 앱에 Neon 프로덕션 데이터베이스가 있습니다.
* 앱 소유자이거나 소유 워크스페이스의 관리자입니다.
* 웹 브라우저에서 Replit을 사용합니다.
* 진행 중인 배포가 없습니다.
* 앱에 라이브 배포가 있는 경우, 최신 빌드가 성공적으로 완료되었고 [Autoscale 또는 Reserved VM](/ko/features/publishing/deployment-types)을 사용합니다.

<Warning>
  이 작업은 취소할 수 없습니다. 기존 연결 문자열은 즉시 작동을 멈춥니다. 앱에 라이브 배포가 있는 경우,
  재배포 중 잠시 사용할 수 없게 될 수 있습니다.
</Warning>

### 자격 증명 재생성하기

1. Tools 패널에서 **Database**를 선택하세요.

2. **Production Database**를 선택한 다음 **Settings** 탭을 선택하세요.

   <Frame>
     <img src="/assets/mirror/database-regenerate-credentials-settings-827c7718a25f.webp" alt="연결 문자열, 저장 공간 사용량, Regenerate credentials 행이 있는 Advanced 섹션을 보여주는 프로덕션 데이터베이스 Settings 탭" width="2314" height="1608" data-path="images/databases/database-regenerate-credentials-settings.webp" />
   </Frame>

3. **Advanced**에서 **Regenerate credentials** 행을 확장하세요.

4. **Regenerate credentials** 버튼을 선택하세요.

   <Frame>
     <img src="/assets/mirror/database-regenerate-credentials-button-ab9631f21b85.webp" alt="Advanced 섹션에서 확장된 Regenerate credentials 행과 Regenerate credentials 버튼을 보여주는 화면" width="2206" height="1876" data-path="images/databases/database-regenerate-credentials-button.webp" />
   </Frame>

5. 확인 대화상자에서 **Regenerate credentials**를 선택하여 확인하세요.

   <Frame>
     <img src="/assets/mirror/database-regenerate-credentials-dialog-2477fc96f82b.webp" alt="이 작업을 취소할 수 없으며 기존 연결 문자열이 즉시 작동을 멈춘다는 경고가 표시된 Regenerate credentials 확인 대화상자" width="1364" height="638" data-path="images/databases/database-regenerate-credentials-dialog.webp" />
   </Frame>

6. **Refresh**를 선택하여 새 연결 문자열을 불러오세요.

7. 앱에 라이브 배포가 있는 경우 **Publishing**을 열고 재배포 상태를 확인하세요.

8. 외부 도구나 커스텀 통합에 복사해 둔 연결 문자열이 있다면 모두 교체하세요.

### 변경되는 내용

자격 증명을 재생성하면 프로덕션 데이터베이스에 새 비밀번호가 생성됩니다. 연결 문자열 중 비밀번호 부분만 변경되며, 호스트, 데이터베이스 이름, 역할은 그대로 유지됩니다.

지원되는 라이브 배포의 경우, Replit은 업데이트된 연결 문자열로 최신 성공한 빌드를 재배포합니다.
