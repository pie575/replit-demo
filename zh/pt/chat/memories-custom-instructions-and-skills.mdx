记忆、自定义指令和 Skills 可帮助 Replit 更好地利用上下文。请选择与信息类型相对应的选项：长期规则、可复用的流程，或过往工作中有用的上下文。

|            | 由谁维护          | Replit 何时使用 | 最适合用于               |
| ---------- | ------------- | ----------- | ------------------- |
| **自定义指令**  | 您或您的团队        | 始终在所有会话中使用  | 希望始终一致 लागू的稳定偏好和规则 |
| **Skills** | 您或您的团队        | 与特定任务相关时使用  | 可复用的流程、工作流和支持材料     |
| **记忆**     | Replit，在您的监督下 | 需要相关上下文时使用  | 避免重复说明过往工作中的有用偏好    |

<div id="escolha-a-ferramenta-certa">
  ## 选择合适的工具
</div>

* 对于需要在整个 Workspace 中始终生效的规则，请使用**自定义指令**，例如批准使用的库或数据处理要求。由你编写，Replit 不会修改。
* 对于可重复用于特定类型工作的做法，请使用 **Skill**，例如准备发布或评审设计。稳定的流程性知识应归入 Skills。
* 当 Replit 可以保留先前工作中的有用上下文，让你无需重复说明相关偏好时，请使用**记忆**。Replit 可以在你工作时写入记忆；它们是上下文参考，而非可执行指令。

你的明确请求和自定义指令的优先级高于记忆。你可以在**设置 → 个性化 → 记忆**中管理记忆。它们不会保留个人或敏感信息，且默认仅自己可见。是否与协作者共享由你决定，默认关闭。
