借助 Replit 灵活的存储方案，你可以快速为 App 添加运行所需的数据存储能力。对于有以下需求的 App，你可以使用 Replit 的数据库或对象存储，Agent 还能自动完成这两种方案的配置与集成：

* 需要保存玩家信息 (如进度或最高分) 的游戏
* 管理媒体文件的内容平台

<div id="quais-so-as-opes-de-armazenamento-e-banco-de-dados-do-replit">
  ## Replit 提供哪些存储和数据库选项
</div>

Replit 提供以下数据存储选项：

* **数据库**：用于存储用户资料、游戏分数和产品目录等结构化数据。
  你可以根据属性以及数据点之间的关系来存储或检索数据。

* **App Storage**：用于存储图像、视频和文档等非结构化数据。
  你可以存储和检索大型文件及二进制数据。

<div id="comparao-entre-app-storage-e-banco-de-dados">
  ### App Storage 与数据库的对比
</div>

|            | 数据库                     | App Storage           |
| ---------- | :---------------------- | :-------------------- |
| **适用数据格式** | 有关联关系的结构化数据             | 大文件 (图片、视频、文档)        |
| **数据模型**   | 表、行、列                   | 存储桶、文件                |
| **查询语言**   | SQL                     | REST API              |
| **客户端**    | 兼容 PostgreSQL 的客户端和 ORM | Replit SDK 和 GCS 客户端库 |
| **计费模式**   | 按计算时长和存储空间计费            | 按带宽和存储空间计费            |

<div id="ferramentas-do-editor-de-projeto">
  ### 项目编辑器工具
</div>

了解以下 Replit 工具，帮助你配置和管理应用的数据存储：

<CardGroup>
  <Card title="数据库" href="/zh/pt/features/data-and-storage/sql-database" icon="database">
    适合存储结构化数据及表示数据之间的关系。
    由可随应用扩展的全托管 PostgreSQL 数据库提供支持。
  </Card>

  <Card title="App Storage" href="/zh/pt/features/data-and-storage/object-storage" icon="bucket">
    适合存储非结构化数据和图片、视频、文档等大型文件。
    由 Google Cloud Storage (GCS) 提供支持，具备高可用性和可扩展性。Agent 可自动配置 App Storage，并设置高级身份验证和访问控制。
  </Card>
</CardGroup>
