[Replit Core](https://replit.com/replit-core) 会员资格让你能够使用高级工具，助你快速将创意变为应用。有关当前 Core 月度或年度价格，请参阅[定价页面](https://replit.com/pricing)。

<div id="section">
  ## 主要功能
</div>

Core 会员资格提供以下功能：

<div id="ai">
  ### AI 驱动的工具
</div>

* **Agent**: 与 Agent 对话，构建、调试并迭代优化应用
* **完整构建**: 当你希望 Agent 自主处理大型任务时，使用 Economy 或 Power
* **Lite 构建**: 针对快速修改的高效精准编辑
* **设计 Canvas**: 探索视觉创意、生成不同方案，并将设计转化为产物
* **可视化编辑器**: 直接以可视化方式编辑应用的内容和布局
* **所有产物类型**: Web 应用、移动应用、数据可视化、幻灯片和动画视频等
* **Plan 模式**: 无需编辑代码，即可与 Agent 头脑风暴并规划工作
* **连接器**: 与 Google、Stripe 等第三方服务集成

<div id="section-2">
  ### 协作
</div>

* 最多可邀请 5 位构建者加入工作区，无需单独订阅团队版
* 后台任务：一次只能运行一个任务
* 用于规划和跟踪工作的共享看板

<div id="section-3">
  ### 极速、安全的开发
</div>

* 在高性能云端开发环境中工作
* 采用按量计费，避免服务中断
* 使用 Secrets 工具，将敏感数据与代码安全分离并存储

有关特定套餐的费用和限制，请参阅<a href="https://replit.com/pricing" target="_blank">定价页面</a>。

<div id="section-4">
  ### 每月积分
</div>

* 每月获得可自动用于 Agent、发布、网络传输、数据库存储和 Replit AI 集成等付费服务的积分。如需更多构建者席位或更高的积分上限，请参阅 [Replit Pro](/zh/ja/billing/plans/replit-pro)。

<div id="section-5">
  ### 一键发布
</div>

所有套餐均可使用发布功能。免费 Starter 套餐包含 1 个已发布的应用；Replit Core 则取消了这一限制，支持发布无限数量的应用，并提供更多选项：

* 发布无限数量的应用
* 从多种发布选项中选择，以优化成本
* 使用内置日志和分析功能
* 移除已发布应用中的“Made with Replit”徽章

<div id="ai-2">
  ### AI 支持与社区活动
</div>

* 借助 AI 支持，快速解决账单、账户、产品和技术问题
* 访问会员专属论坛和活动
* 抢先体验新功能

<div id="section-6">
  ## 入门
</div>

只需几步即可升级到 Replit Core：

1. 前往<a href="https://replit.com/pricing" target="_blank">定价</a>页面
2. 选择 **Join Replit Core**
3. 选择**月度**或**年度**套餐，并填写付款信息
