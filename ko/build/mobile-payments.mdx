<div id="what-is-revenuecat">
  ## RevenueCat이란
</div>

PixelGames에서 Snake, Racer, Pinball은 출시 예정으로 표시되어 있습니다. RevenueCat을 사용하면 Apple과 Google의 결제 시스템을 직접 연동하지 않고도 이 게임들을 잠금 해제해 주는 구독 상품을 앱에서 판매할 수 있습니다. Agent에게 구독 추가와 RevenueCat 연결을 요청하면 나머지는 알아서 처리해 줍니다.

<Warning>
  Apple과 Google은 이런 디지털 콘텐츠에 대해 각사의 인앱 결제 시스템을 사용하도록 요구하며, 양쪽 모두 판매 금액의 일부를 수수료로 가져갑니다. 외부 결제 링크로는 이를 우회할 수 없습니다.
</Warning>

<div id="test-subscriptions">
  ## 구독 테스트
</div>

Replit previews는 RevenueCat의 테스트 모드를 사용합니다. Expo Go에서 구매를 테스트하면 테스트 구매 대화 상자가 표시되며 실제 결제는 이루어지지 않습니다. Apple이 앱을 App Store에 승인하고 나면 실제 금액이 청구되므로, 제출하기 전에 가격을 다시 한번 확인하세요.

<Frame caption="PixelGames의 paywall과 Expo Go에 표시된 테스트 구매 대화 상자.">
  <img src="/assets/mirror/paywall-7b66dd10c595.png" alt="RevenueCat의 테스트 구매 대화 상자 옆에 표시된 PixelGames paywall 화면" data-path="images/pixelgames/mobile/paywall.png" width="2274" height="1470" data-path="images/pixelgames/mobile/paywall.png" />
</Frame>

위의 테스트 구매 대화 상자는 플레이어에게 실제로 보이는 화면이 아닙니다. Expo Go는 모든 Expo project를 미리 보는 공용 앱이라 앱의 실제 RevenueCat 신원을 확인할 수 없고, 대신 일반적인 테스트 flow를 보여줍니다. 실제 빌드를 만들거나 앱을 게시하고 나면, paywall은 앱에 하드코딩된 화면이 아니라 원격에서 serve되는 RevenueCat의 자체 화면이 됩니다.

<div id="sync-to-app-store-connect">
  ## App Store Connect에 동기화
</div>

동기화를 사용하면 RevenueCat 또는 Replit Agent에서 직접 인앱 구독이나 제품을 생성하거나 수정할 수 있습니다.

App Store Connect를 연결하려면 먼저 다음 세 가지가 준비되어 있어야 합니다.

* 아직 가입하지 않았다면 Apple Developer Program에 **등록**하세요. 연간 membership 비용이 발생합니다.
* App Store에 앱을 **제출**하세요. 아직 제출하지 않았다면 [앱 업로드](/ko/build/mobile-upload-ios)를 참고하세요. RevenueCat이 제품을 동기화하려면 앱 레코드가 있어야 합니다.
* 은행 계좌를 **연결**하고 Apple의 Paid Apps Agreement에 **서명**하세요. 두 작업 모두 App Store Connect에서 진행하며, 이 절차를 마치지 않으면 Apple이 지급을 처리하지 않습니다.

<Steps>
  <Step title="Replit에서 동기화 시작하기">
    Replit에서 **Publishing → Manage**를 열고 **Sync RevenueCat to App Store
    Connect**를 선택합니다. 이 버튼은 앱을 TestFlight에 제출한 후에 나타납니다.

    <Frame caption="Replit의 Publishing 창에서 동기화 시작하기">
      <img src="/assets/mirror/rev-co-step1-e86c72c18850.png" alt="Manage 탭이 열려 있고 Sync RevenueCat to App Store Connect 버튼이 표시된 Replit Publishing 창" data-path="images/pixelgames/mobile/rev-co-step1.png" width="997" height="420" data-path="images/pixelgames/mobile/rev-co-step1.png" />
    </Frame>
  </Step>

  <Step title="App Store Connect API 페이지를 엽니다">
    App Store Connect에서 **Users and Access → Integrations → App Store Connect API**로 이동한 후
    ([바로 열기](https://appstoreconnect.apple.com/access/integrations/api)) **+**를 선택해 새 키를 추가합니다.

    <Frame caption="App Store Connect API 키 페이지로 이동하기.">
      <img src="/assets/mirror/rev-co-step2-642a879843a1.png" alt="App Store Connect Users and Access 페이지, Integrations 탭, App Store Connect API 섹션" data-path="images/pixelgames/mobile/rev-co-step2.png" width="1466" height="657" data-path="images/pixelgames/mobile/rev-co-step2.png" />
    </Frame>
  </Step>

  <Step title="키 생성">
    이름을 입력하고(예: &quot;RevenueCat&quot;), **Access**를 **App Manager**로 설정한 다음
    **Generate**를 선택합니다.

    <Frame caption="RevenueCat용 App Store Connect API 키 생성.">
      <img src="/assets/mirror/rev-co-step3-dcfbd73aafd8.png" alt="이름 필드와 App Manager 액세스가 선택된 API 키 생성 모달" data-path="images/pixelgames/mobile/rev-co-step3.png" width="1453" height="436" data-path="images/pixelgames/mobile/rev-co-step3.png" />
    </Frame>
  </Step>

  <Step title="주요 정보 복사">
    **Key ID**를 복사하고 키 파일을 다운로드합니다.

    <Frame caption="Key ID 복사 및 App Store Connect API 키 다운로드">
      <img src="/assets/mirror/rev-co-step4-24337a1cd6db.png" alt="새 RevenueCat 키와 Copy, Download 작업이 표시된 App Store Connect API 키 목록" data-path="images/pixelgames/mobile/rev-co-step4.png" width="1522" height="695" data-path="images/pixelgames/mobile/rev-co-step4.png" />
    </Frame>
  </Step>

  <Step title="Replit에 추가">
    Replit의 동기화 모달(1/2단계)로 돌아가 키 파일을 업로드하고 **Key ID**와
    **Issuer ID**를 붙여넣은 다음 **Continue**를 선택하세요.

    <Frame caption="Replit에서 App Store Connect API 키 입력하기.">
      <img src="/assets/mirror/rev-co-step5-73640bd1925f.png" alt="App Store Connect API 키를 업로드하고 세부 정보를 붙여넣는 Replit 모달 1/2단계" data-path="images/pixelgames/mobile/rev-co-step5.png" width="995" height="591" data-path="images/pixelgames/mobile/rev-co-step5.png" />
    </Frame>
  </Step>

  <Step title="In-App Purchase 키에도 이 작업을 반복합니다">
    App Store Connect의 같은 위치에서 이번에는 **In-App Purchase** 탭
    ([바로 열기](https://appstoreconnect.apple.com/access/integrations/api/subs))으로 이동해
    키를 하나 더 생성하고 세부 정보를 복사합니다.

    <Frame caption="In-App Purchase API key 생성 및 복사하기">
      <img src="/assets/mirror/rev-co-step6-aed01868e734.png" alt="Download 및 Copy 작업이 있는 App Store Connect In-App Purchase 키 목록" data-path="images/pixelgames/mobile/rev-co-step6.png" width="1547" height="593" data-path="images/pixelgames/mobile/rev-co-step6.png" />

  </Step>

  <Step title="Replit에 추가">
    다시 Replit의 동기화 모달(2단계 중 2단계)로 돌아가 이 키 파일도 업로드하고 **Key ID**와

    <Frame caption="Replit에서 인앱 구매 API 키 입력하기.">

    </Frame>
  </Step>

  <Step title="확인 및 동기화">
    동기화가 완료되면 Replit의 동일한 **Publishing → Manage** pane에서 언제든지 product 가격을 직접 변경할 수 있습니다.

    <Frame caption="App Store Connect에 동기화하기 전 product 확인 화면입니다.">
      <img src="/assets/mirror/rev-co-step8-a790ee2b52ee.png" alt="프리미엄 월간 구독이 동기화 준비된 상태로 표시된 Replit Products to Sync 화면" data-path="images/pixelgames/mobile/rev-co-step8.png" width="996" height="550" data-path="images/pixelgames/mobile/rev-co-step8.png" />

  </Step>

<div id="troubleshooting">
  ## 문제 해결
</div>

* **구매는 성공했지만 아무것도 잠금 해제되지 않는 경우:** RevenueCat의 entitlement가 올바른
  제품 ID에 매핑되어 있는지 확인하세요.
* **테스트에서는 작동하지만 publishing 후에는 작동하지 않는 경우:** 제품이 App Store
  Connect에 동기화되어 있는지, Apple의 Paid Apps Agreement에 서명했는지 확인하세요.

<div id="frequently-asked-questions">
  ## 자주 묻는 질문
</div>

<AccordionGroup>
  <Accordion title="RevenueCat을 사용하려면 은행 계좌가 필요한가요?">
    아닙니다. 계정을 만들 때는 이메일과 비밀번호만 있으면 됩니다. 은행 계좌는 정산금을
    받을 준비가 되었을 때 Apple 또는 Google을 통해 별도로 연결합니다.
  </Accordion>

  <Accordion title="테스트 구매에도 요금이 청구되나요?">
    아닙니다. Replit previews는 RevenueCat의 테스트 모드를 사용하므로 구매가 시뮬레이션으로 처리됩니다.
    실제 청구는 Apple이 App Store에 앱을 승인한 이후부터 시작됩니다.
  </Accordion>

  <Accordion title="RevenueCat으로 무엇을 구성할 수 있나요?">
    가격, 이용 권한(entitlement), 그리고 paywall 자체를 구성할 수 있습니다. Agent에게 변경을 요청하면
    RevenueCat 구성과 앱 코드를 함께 업데이트합니다.
  </Accordion>
</AccordionGroup>
