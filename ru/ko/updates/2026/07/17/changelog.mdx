<div id="agent">
  ### Agent предлагает коннекторы, когда подходит сразу несколько
</div>

Если вы просите Agent подключить сервис и доступно несколько провайдеров, Agent теперь показывает короткий список, из которого вы выбираете нужный. Раньше Agent сначала задавал уточняющий вопрос. После выбора провайдера и однократного входа Agent продолжает сборку приложения.

<div id="section-3">
  ## Рабочее пространство
</div>

<div id="tools">
  ### Представляем новую панель Tools
</div>

Теперь всё, что доступно вашему приложению, собрано в рабочем пространстве в одном месте. Новая закреплённая панель Tools объединяет Database, Auth, Domains, Secrets и другие инструменты. Так весь набор инструментов виден с одного взгляда. Сами инструменты не изменились — у них просто появилось более понятное место.

Подробнее о [панели Tools](/ru/ko/features/editor/editor-and-tools).

<div id="section-4">
  ### Более быстрая боковая панель задач
</div>

Боковая панель задач превратилась в компактный навигатор, который легко окинуть взглядом. У каждой задачи теперь своя карточка при наведении с быстрыми действиями и подробностями, у Task Board появилась более понятная точка входа, а при разворачивании и сворачивании панели задачи остаются на своих местах.
