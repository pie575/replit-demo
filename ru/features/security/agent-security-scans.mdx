Проверки безопасности Agent анализируют всю кодовую базу на предмет уязвимостей в области безопасности и конфиденциальности. Security Agent сочетает анализ на основе моделей со средствами статического анализа, такими как [Semgrep](https://semgrep.dev/) и [HoundDog.ai](https://hounddog.ai), а затем показывает выявленные проблемы в Project Security Center.

Проверки безопасности Agent доступны всем пользователям Replit с платными планами. Для крупных проектов глубокий аудит может занять до 15 минут.

<div id="what-security-agent-reviews">
  ## Что проверяет Security Agent
</div>

При запуске сканирования Security Agent:

1. Составляет карту маршрутов, API, потоков данных и точек входа.
2. Строит модель угроз для приложения.
3. Выполняет статический анализ всей кодовой базы.
4. Оценивает выявленные проблемы в контексте приложения.
5. Формирует отчёт о выявленных проблемах для вашего анализа.

Проверка позволяет обнаружить небезопасные шаблоны кода — SQL-инъекции, межсайтовый скриптинг и межсайтовую подделку запросов; проблемы конфиденциальности, например попадание конфиденциальных данных в журналы или сторонние API; а также архитектурные уязвимости в маршрутах, API и потоках данных.

<div id="start-an-agent-security-scan">
  ## Запуск проверки безопасности с помощью Agent
</div>

<Steps>
  <Step title="Откройте Security Center">
    На панели **Tools** вашего проекта выберите **Security Center**. Также можно
    выбрать **Review security** в процессе публикации.

    <Frame>
      <img src="/assets/mirror/review-security-button-9331149c28f7.png" alt="Действие Review security в процессе публикации" width="1440" height="900" data-path="images/project-security-center/review-security-button.png" />
    </Frame>
  </Step>

  <Step title="Запустите проверку">
    Выберите **Run scan with Agent**.

    <Frame>
      <img src="/assets/mirror/run-scan-with-agent-f54820ac154a.png" alt="Действие Run scan with Agent в Project Security Center" width="1440" height="900" data-path="images/project-security-center/run-scan-with-agent.png" />
    </Frame>
  </Step>

  <Step title="При необходимости добавьте контекст">
    При желании добавьте контекст, чтобы сфокусировать модель угроз на определённых частях приложения, а затем запустите проверку безопасности.

    <Frame>
      <img src="/assets/mirror/scan-options-c2cd398fa78b.png" alt="Параметры проверки безопасности с полем Add context и действием Start security scan" width="1440" height="900" data-path="images/project-security-center/scan-options.png" />
    </Frame>
  </Step>

  <Step title="Дождитесь результатов проверки">
    Дождитесь, пока Security Agent завершит проверку. Обычно это занимает несколько минут, а для крупных проектов — до 15 минут.
  </Step>
</Steps>

<div id="review-and-fix-findings">
  ## Проверка и устранение проблем
</div>

<Steps>
  <Step title="Изучите отчёт">
    Просмотрите каждую проблему и её уровень серьёзности в **Security Center**.
    Отклоните проблемы, которые вам понятны и приемлемы, либо отредактируйте их
    перед отправкой на устранение.
  </Step>

  <Step title="Устраните принятые проблемы с помощью Agent">
    Отправьте принятые проблемы в Agent. Security Agent распределяет уязвимости
    по отдельным задачам, чтобы Agent мог работать над несколькими исправлениями
    параллельно.
  </Step>

  <Step title="Запустите сканирование повторно">
    После того как Agent внесёт исправления, выполните повторное сканирование,
    чтобы убедиться, что проблемы устранены. В крупных проектах после устранения
    проблем с высоким уровнем серьёзности могут обнаружиться дополнительные проблемы.
  </Step>
</Steps>

<div id="when-to-use-level-3">
  ## Когда использовать Level 3
</div>

Проверка безопасности с помощью Agent проверяет исходный код. Если нужно также протестировать работающее приложение через взаимодействие с браузером и сетью, воспользуйтесь [пентестом методом чёрного ящика Level 3](/ru/features/security/black-box-pen-tests). На уровне Level 3 тестирование методом чёрного ящика и анализ исходного кода выполняются параллельно.

<div id="limitations-and-best-practices">
  ## Ограничения и рекомендации
</div>

* Сканирование выполняется на инфраструктуре Replit. Replit не передаёт ваш код и данные в Semgrep, HoundDog.ai или другим третьим лицам.
* Настройки и результаты сканирования хранятся вместе с вашим Replit App.
* Сканирование не заменяет полноценную проверку безопасности. Используйте его вместе с код-ревью, тестами, анализом зависимостей и проверками работающего приложения.
* Повторяйте сканирование после существенных изменений в коде, после добавления или обновления зависимостей и перед публикацией новой версии.
