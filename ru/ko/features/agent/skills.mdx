<div id="section">
  ## Что такое навыки?
</div>

Навык — это папка с файлом `SKILL.md`, содержащим инструкции для Agent, а также дополнительными вспомогательными файлами для справки. Навыки хранятся в каталоге `/.agents/skills` проекта и соответствуют [спецификации навыков Agent](https://agentskills.io/specification) — открытому стандарту для агентов.

Agent видит названия и описания всех установленных навыков, но загружает их полное содержимое только тогда, когда они нужны для текущей задачи. Благодаря этому навыки экономно используют контекст: вы можете установить множество навыков без снижения качества ответов Agent.

<div id="section-2">
  ## Предустановленные навыки
</div>

Replit предлагает предустановленные навыки, доступные в селекторе **Использовать навыки** в чате и при выборе начальной точки для нового проекта. Эти навыки работают во всех проектах без установки. Полный каталог, партнёрские навыки и инструкции по установке см. в [каталоге навыков](/ru/ko/features/agent/skills-directory).

Чтобы добавить предустановленный навык, откройте селектор **Использовать навыки** в поле ввода чата и выберите навык или попросите Agent загрузить его.

<div id="section-3">
  ## Область действия навыков
</div>

Навыки могут иметь разные области действия:

| Область действия                  | Доступность                                    | Место хранения                                                                                                        |
| --------------------------------- | ---------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| **Уровень проекта**               | Только в одном проекте                         | Версионируются вместе с файлами в `/.agents/skills`                                                                   |
| **Уровень рабочего пространства** | Доступно всем участникам рабочего пространства | Централизованно управляются в Workspace Settings                                                                      |
| **Enterprise**                    | Единый стандарт для всей компании              | Включены в [пользовательские шаблоны](/ru/ko/teams/custom-templates) и [системы дизайна](/ru/ko/teams/custom-design-system) |

Подробнее о навыках уровня рабочего пространства и настройке навыков рабочего пространства и пользовательских инструкций для команды см. в разделе [Agent Customization](/ru/ko/features/agent/agent-customization).

<div id="agent">
  ## Как Agent загружает навыки
</div>

В каждом чате Agent читает метаданные всех установленных навыков — их названия и описания. Полное содержимое навыка загружается только тогда, когда Agent определяет, что оно относится к текущей задаче. Благодаря этому содержимое навыка не занимает место в контекстном окне, пока не потребуется.

Установленные навыки сохраняются в проекте на протяжении всего сеанса Agent, а для совместного использования в команде их можно закоммитить в систему контроля версий.

<div id="ai">
  ## Использование с другими инструментами для ИИ-разработки
</div>

<Accordion title="Импорт навыков из других инструментов для ИИ-разработки">
  Если вы используете несколько инструментов для ИИ-разработки, [rulesync](https://github.com/dyoshikawa/rulesync) поддерживает Replit и помогает сохранять единообразную конфигурацию.

  Вы можете импортировать навыки из других ИИ-помощников для разработки:

  ```bash theme={null}
  npx rulesync init
  npx rulesync import --targets claudecode --features skills
  npx rulesync generate --targets replit --features skills
  ```

  Это позволяет использовать единый набор навыков в разных средах разработки.
</Accordion>
