## O que é um Replit App?

Os Replit Apps são projetos hospedados na nuvem que contêm código, dados e recursos.
Você pode criá-los, executá-los e publicá-los a partir de um ambiente seguro e isolado.

Os Replit Apps se integram às seguintes ferramentas no Project Editor para oferecer
uma experiência de desenvolvimento contínua:

* **Ferramentas com IA**: Use o Agent para criar, depurar e explicar seu código.
* **Colaboração**: Trabalhe com outras pessoas em tempo real no mesmo aplicativo.
* **Publicação**: Publique seu aplicativo na nuvem com um único clique.

## Principais funcionalidades

Os Replit Apps oferecem as seguintes funcionalidades:

* **Sem configuração:** Crie aplicativos ou escreva código diretamente no Replit.com sem instalações ou configurações.
* **Salvamento automático:** Seu projeto salva continuamente as alterações na nuvem e permite que você retome a programação de qualquer navegador web
* **Controle de versão:** Acompanhe alterações, explore o histórico de arquivos e sincronize seus arquivos sem nenhuma configuração, através dos sistemas de controle de versão do Replit
* **Controles de visibilidade pública/privada:** Controle quem pode visualizar, executar ou criar um Remix do seu aplicativo com configurações de privacidade
* **Publicação:** Publique seu código na nuvem sem fazer alterações complexas de configuração
* **URLs personalizadas:** Obtenha uma URL exclusiva para seu aplicativo ou atribua um domínio personalizado para uma presença profissional

<Info>
  Os arquivos enviados para o sistema de arquivos do seu projeto estão disponíveis apenas durante o desenvolvimento e
  não são acessíveis ao seu aplicativo publicado ou a outros desenvolvedores. Use o [Object
  Storage](/pt/features/data-and-storage/object-storage) para gerenciar
  uploads e servir arquivos, e o [Replit
  Database](/pt/features/data-and-storage/sql-database) para armazenar e
  recuperar dados para seu aplicativo e usuários.
</Info>

Para saber mais sobre as ferramentas do Project Editor que simplificam a criação de Replit Apps, consulte [Visão Geral do Project Editor](/pt/learn/projects-and-artifacts/project-editor/).

## Como funciona

Quando você cria um Replit App, o Replit configura um espaço privado para seu projeto na nuvem.
À medida que você adiciona funcionalidades e modificações ao seu aplicativo, o Replit salva suas alterações
automaticamente para que você possa retomar a edição de qualquer navegador web.

O Replit fornece ambientes pré-configurados com todos os componentes necessários.
Isso permite que você comece a criar seu aplicativo imediatamente sem se preocupar com
configuração de servidor, configuração de banco de dados ou gerenciamento de ambiente.

O Replit atribui automaticamente a cada Replit App um endereço web exclusivo onde você
pode visualizar seu aplicativo enquanto trabalha nele. Quando estiver pronto para compartilhar sua
criação, você pode publicá-la com apenas alguns cliques para torná-la disponível 24/7.

## Visão Geral de Armazenamento

O Replit oferece quatro tipos principais de armazenamento para atender às necessidades de dados do seu aplicativo. Cada tipo de armazenamento serve a diferentes casos de uso e tem limites específicos com base no seu plano.

<Info>
  Os limites de armazenamento incluem todos os dados armazenados pelo seu aplicativo, incluindo pacotes e dependências instalados.
</Info>

| Tipo de Armazenamento                                              | Descrição                           | Casos de Uso                                                       | Persistência                                | Limites do Plano                                                                                                                                     |
| ------------------------------------------------------------------ | ----------------------------------- | ------------------------------------------------------------------ | ------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Armazenamento de Arquivos**                                      | Arquivos no seu projeto             | Código do aplicativo, recursos estáticos, arquivos de configuração | Persiste na publicação, reinicia no restart | Starter: {StarterWorkspaceStorage}<br />Core: {CoreWorkspaceStorage}<br />Pro: {TeamsWorkspaceStorage}<br />Enterprise: {EnterpriseWorkspaceStorage} |
| **[Database](/pt/features/data-and-storage/sql-database/)**        | Armazenamento de dados estruturados | Perfis de usuários, pontuações de jogos, catálogos de produtos     | Totalmente persistente entre sessões        | 20 GB por banco de dados de desenvolvimento<br />Bancos de dados de produção são cobrados por tempo de computação e armazenamento                    |
| **[App Storage](/pt/features/data-and-storage/object-storage/)**   | Dados não estruturados e mídia      | Imagens, vídeos, PDFs, documentos                                  | Totalmente persistente entre sessões        | Modelo de pagamento por uso<br />Cobrado por armazenamento e largura de banda                                                                        |
| **[Secrets](/pt/core-concepts/project-editor/app-setup/secrets/)** | Dados sensíveis criptografados      | Chaves de API, credenciais, strings de conexão                     | Totalmente persistente e criptografado      | Sem limites específicos<br />Incluído em todos os planos                                                                                             |
