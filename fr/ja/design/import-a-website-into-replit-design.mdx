⏰ *Durée estimée : 10 minutes*

Le design que vous souhaitez utiliser existe peut-être déjà en ligne, qu&#39;il s&#39;agisse de votre site actuel ou d&#39;une page dont vous souhaitez reproduire l&#39;apparence. Import from URL recrée un site web sous la forme d&#39;un cadre de design que vous pouvez explorer, peaufiner et transformer avec Build en app interactive.

Pour cet exemple, utilisez la page de destination pour un studio créatif créée par Replit, [creative-studio-landing.replit.app](https://creative-studio-landing.replit.app).

<div id="section">
  ## Avant de commencer
</div>

Vous aurez besoin des éléments suivants :

* Un [compte Replit](https://replit.com).
* L’URL d’un site web public ou celle de l’exemple ci-dessus.

<div id="section-2">
  ## Importer un site web
</div>

<Steps>
  <Step title="Copier l’URL du site">
    Utilisez votre propre site ou copiez cet exemple : `https://creative-studio-landing.replit.app`.

    <Frame caption="Site utilisé comme exemple : la page de destination du studio de création Kosmo Studio.">
      <img src="/assets/mirror/url-example-site-e0ad60629981.webp" alt="Page de destination de Kosmo Studio avec le titre « We craft bold ideas and visuals that truly work » et des cartes d’illustrations disposées en éventail" width="3440" height="2160" data-path="images/design/import-from-url/url-example-site.webp" />
    </Frame>
  </Step>

  <Step title="Ouvrir Replit Design">
    Accédez à [replit.com/design](https://replit.com/design), puis sélectionnez **Import URL** sous la zone de saisie. Agent recréera l’apparence du site comme point de départ.

    <Frame caption="Import URL sur la page d’accueil de Replit Design : collez un lien vers n’importe quel site web.">
      <img src="/assets/mirror/design-import-url-07a8ac52e188.webp" alt="Écran d’accueil de Replit Design avec l’option Import URL sélectionnée. Une infobulle affiche « Paste a link to any website and Agent will recreate its look and feel as a starting point »" width="2293" height="1322" data-path="images/design/import-from-url/design-import-url.webp" />
    </Frame>
  </Step>

  <Step title="Coller l’URL et commencer à créer">
    Lorsque vous sélectionnez **Import URL**, le prompt contient déjà *« Recreate the look and feel of this website: »*. Collez ensuite l’URL et sélectionnez **Start**.

    <Frame caption="Prompt de recréation avec l’URL d’exemple déjà saisie, prêt à démarrer.">
      <img src="/assets/mirror/design-url-prompt-b6196aac1b17.webp" alt="Zone de saisie de Replit Design contenant « Recreate the look and feel of this website », suivie de l’URL d’exemple, ainsi que le bouton Start" width="2293" height="1322" data-path="images/design/import-from-url/design-url-prompt.webp" />
    </Frame>
  </Step>
</Steps>

Agent recrée le site sous forme de cadre de design dans votre projet.

<Frame caption="Page de destination de Kosmo Studio recréée sous forme de cadre de design dans Replit Design.">
  <img src="/assets/mirror/url-import-result-7a4114a468f3.webp" alt="Page de destination de Kosmo Studio recréée sous forme de cadre de design dans Replit Design. </Frame>

<div id="section-3">
  ## Personnalisez-le
</div>

Sélectionnez une frame importée et façonnez-la à votre image :

* **[Suivez les suggestions](/fr/ja/design/explore-suggestions)** : les frames importées proposent déjà des suggestions pour la suite, comme une variante au style éditorial sombre, une vue mobile ou une page de contact. Chacune est générée dans une nouvelle frame, afin de conserver la frame d’origine à des fins de comparaison.
* **[Discutez dans Chat](/fr/ja/design/chat-about-your-design)** : utilisez le champ de saisie sous la frame pour décrire ce que vous souhaitez avec vos propres mots. Par exemple, *« Remplace les photos du portfolio »* ou *« Mets le texte de la section héro plus en gras »*.

<Frame caption="Suggestions pour la suite concernant la frame importée sélectionnée : une variante au style éditorial sombre, une vue mobile et une page de contact.">

À côté se trouve le panneau Suggested next steps, qui propose une variante au style éditorial sombre, une vue mobile, une page de contact et différentes approches." width="1600" height="1004" data-path="images/design/import-from-url/url-make-it-yours.webp" />
