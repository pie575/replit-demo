L&#39;[application mobile Replit](https://replit.com/mobile) met vos projets dans votre poche : reprenez là où vous vous étiez arrêté, ou lancez un nouveau projet de zéro, où que vous soyez. Discutez avec Agent, modifiez votre projet et publiez-le sur le web, le tout dans une interface optimisée pour le tactile.

<div id="getting-started">
  ## Premiers pas
</div>

Suivez ces étapes pour installer l&#39;application et créer un projet.

<div id="install-the-app">
  ### Installer l&#39;application
</div>

1. Rendez-vous sur la [page de téléchargement de l&#39;application mobile](https://replit.com/mobile) et installez l&#39;application correspondant au système d&#39;exploitation de votre appareil mobile.
2. Ouvrez l&#39;application, puis créez un compte ou connectez-vous avec un compte existant.
   Si vous créez un compte, vous devez vérifier votre adresse e-mail pour finaliser la procédure.

<div id="start-building">
  ### Commencer à créer
</div>

L&#39;écran d&#39;accueil propose les deux approches :

* **Reprendre là où vous vous êtes arrêté** : ouvrez un projet dans **Projets récents** et poursuivez votre travail.
* **Partir de zéro** : décrivez ce que vous souhaitez dans le champ de prompt et envoyez-le. Agent se met aussitôt à créer votre projet.

Pour partir plutôt d&#39;un modèle prédéfini ou d&#39;un code existant, appuyez sur ⋮ en haut à droite, puis choisissez **Remixer un modèle** ou **Importer depuis GitHub**.

<Note>
  Vous créez une application iOS native ? Utilisez le Project Editor sur [replit.com](https://replit.com) pour la créer, la prévisualiser, la compiler ou la soumettre. Le développement d&#39;applications mobiles natives est disponible dans l&#39;application Replit pour Android, là où cette fonctionnalité est prise en charge.
</Note>

<div id="mobile-features">
  ## Fonctionnalités mobiles
</div>

<div id="voice-input">
  ### Saisie vocale
</div>

Utilisez l&#39;option vocale du champ de prompt d&#39;Agent pour décrire ce que vous souhaitez créer ou modifier, sans utiliser vos mains.

<div id="live-activities">
  ### Activités en direct
</div>

Suivez la progression d&#39;Agent où que vous soyez. Lorsqu&#39;Agent démarre, une notification s&#39;affiche : appuyez sur **Autoriser** depuis votre écran verrouillé, et vous pourrez suivre la progression sans ouvrir Replit.

<Accordion title="Appareils compatibles">
  * iPhone sous iOS 18 ou version ultérieure
  * iPad sous iOS 18 ou version ultérieure
  * Mac sous macOS Tahoe ou version ultérieure
  * Apple Watch jumelée
</Accordion>

<div id="notifications">
  ### Notifications
</div>

Recevez les informations qui comptent, où que vous soyez. Accédez aux **Paramètres** et ouvrez **Notifications** (par exemple sous **Utilisateur**). Assurez-vous que les notifications sont activées et appuyez sur Autoriser si vous y êtes invité.

Replit vous avertit lorsque :

* Agent a besoin de votre aide
* Agent a terminé son travail
* Des informations importantes concernent votre facturation

<div id="tablet-keyboard-mode">
  ### Mode clavier pour tablette
</div>

Connectez un clavier à votre tablette pour profiter d&#39;une expérience de création optimisée pour les grands écrans. La première fois que vous ouvrirez le Project Editor avec un clavier connecté, Replit vous proposera de l&#39;activer.

Rendez-vous à tout moment dans **Compte** &gt; **Paramètres du clavier** pour l&#39;activer ou le désactiver.

<div id="upgrade-and-billing">
  ## Mise à niveau et facturation
</div>

Pour passer à Core depuis l&#39;application, accédez à **Account**, appuyez sur **Upgrade**, choisissez votre offre, puis appuyez sur **Continue with Core**. Pro n&#39;est pas proposé à l&#39;achat dans l&#39;application mobile : il doit être souscrit sur [replit.com](https://replit.com).

Pour utiliser Agent au-delà des crédits inclus dans votre abonnement, ajoutez un moyen de paiement pour la [facturation à l&#39;usage](/fr/billing/about-usage-based-billing) :

* **Sur le web** : rendez-vous sur replit.com et ouvrez **Settings** → **Account** → **Billing**.
* **Dans l&#39;application (iOS, aux États-Unis uniquement)** : ouvrez **Settings** → **Billing** (ou **Account** → **Billing**).
