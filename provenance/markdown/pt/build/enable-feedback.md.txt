# Ativar Widget de Feedback

> Aprenda como coletar feedback dos visitantes no seu app publicado.

A coleta de feedback pode ser ativada nos seus apps publicados para obter insights diretamente dos visitantes e enviar diretamente para o Agent. Quando o feedback está ativado, os visitantes podem enviar feedback, incluindo capturas de tela e arquivos, que você pode gerenciar pelo seu Inbox.

## Ativando o feedback

<Warning>
  Você pode ativar o feedback apenas em web apps. Não será possível ativar isso para outros tipos de apps, como automações ou apps mobile.
</Warning>

Ao publicar um novo app, ative a opção **Ativar Feedback** no diálogo de publicação. Se o seu app já foi publicado, você pode ativar o feedback republicando:

1. Abra a ferramenta de Publicação
2. Selecione **Configurações Avançadas**
3. Ative **Ativar Feedback**
4. Republique seu app

## Enviando feedback

Quando o feedback está ativado em um app publicado, os visitantes podem enviar feedback diretamente do app. Os usuários podem:

* Entrar para deixar feedback
* Deixar feedback em texto descrevendo sua experiência ou sugestões
* Selecionar elementos para ilustrar problemas ou funcionalidades
* Fazer upload de arquivos para fornecer contexto adicional

## Gerenciando feedback no seu Inbox

Todo o feedback enviado pelos visitantes aparece no seu Inbox, acessível de dentro do Editor de Projeto. No Inbox, você pode:

* **Adicionar ao Chat**: envie feedback ao seu chat com o Agent para adicionar contexto antes de enviar
* **Enviar para o Agent**: envie feedback imediatamente para o Agent e comece a trabalhar de imediato
* **Resolver**: marque o feedback como resolvido após ser tratado
* **Excluir**: remova feedback que não é mais necessário

Você também pode usar filtros para organizar e encontrar entradas de feedback específicas.

## Republicando com configurações de feedback atualizadas

Após seu app ser publicado, você pode ativar ou desativar o widget de feedback a qualquer momento republicando com configurações atualizadas:

1. Abra a aba **Visão Geral** na ferramenta de Publicação
2. Selecione **Configurações Avançadas**
3. Ative ou desative **Ativar Feedback**
4. Republique seu app para aplicar as alterações

Quaisquer alterações na configuração de feedback entram em vigor assim que o app é republicado.
