As Custom Instructions são orientações sempre ativas que você ou sua equipe escrevem uma vez para um Workspace. O Replit as utiliza em todos os Projects e sessões desse Workspace, para que você não precise repetir convenções em cada Conversa.

Use as Custom Instructions para um pequeno conjunto de diretrizes que sejam sempre válidas, como bibliotecas aprovadas, requisitos de segurança ou políticas de tratamento de dados. Mantenha-as curtas e específicas para deixar espaço para o trabalho em questão.

## Escolha o tipo certo de orientação

* Use as **Custom Instructions** para orientações válidas para todo o Workspace que devem sempre se aplicar.
* Use as [Skills](/pt/chat/agent-skills) para abordagens reutilizáveis e material de apoio relevantes apenas para tarefas específicas.
* Use as [Memories](/pt/chat/memories) para contexto útil que o Replit mantém de trabalhos anteriores.

## Configure as Custom Instructions

Gerencie as Custom Instructions em **Workspace Settings → Customization**. O guia de recursos detalhado aborda configuração, disponibilidade, permissões e como manter as instruções eficazes.
