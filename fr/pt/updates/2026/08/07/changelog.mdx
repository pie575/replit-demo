  ## Agent
</div>

<div id="verificao-de-segurana-enquanto-voc-constri">
  ### Analyse de sécurité pendant le développement
</div>

Agent analyse désormais les fichiers qu’il modifie afin de détecter les problèmes de sécurité courants lors de sa revue de code. Cette analyse automatique de Semgrep recherche des modèles à risque et des secrets codés en dur afin qu’Agent puisse résoudre les problèmes les plus probables avant de terminer la tâche.

En savoir plus sur l’[analyse de sécurité pendant le développement](/fr/pt/features/security/project-security-center#security-scan-while-you-build).

<div id="regenere-as-credenciais-do-banco-de-dados-de-produo">
  ### Régénérez les identifiants de la base de données de production
</div>

Vous pouvez désormais régénérer les identifiants d&#39;une base de données de production éligible depuis l&#39;outil **Database**. Replit met à jour les identifiants et, si votre app dispose d&#39;un déploiement compatible actif, lance un nouveau déploiement afin qu&#39;elle puisse continuer à utiliser les nouveaux identifiants. Mettez à jour tous les outils externes qui utilisent l&#39;ancienne chaîne de connexion.

<div id="teams-e-enterprise">
  ## Teams et Enterprise
</div>

<div id="construa-com-sso">
  ### Créez avec le SSO
</div>

Les créateurs Pro peuvent désormais configurer le SSO d&#39;entreprise pour une Replit App utilisant [Clerk Auth](/fr/pt/features/auth-and-identity/clerk-auth). Demandez à Agent la modification d&#39;authentification dont vous avez besoin : il vous redirigera vers le Clerk Dashboard. Vous pourrez alors connecter Okta ou Microsoft Entra ID via OIDC ou SAML. Les connexions SSO d&#39;entreprise sont gratuites jusqu&#39;au 1er octobre 2026. Après cette date, la tarification de Clerk sera répercutée. La disponibilité pour Enterprise arrive bientôt.

En savoir plus sur [Créez avec le SSO](/fr/features/auth-and-identity/single-sign-on).

<div id="mova-projetos-entre-workspaces">
  ### Déplacez des projets entre les workspaces
</div>

Vous pouvez désormais déplacer un projet entre des workspaces d’équipe associés au même compte de facturation depuis la liste **Projects**. Le transfert s’effectue en arrière-plan et ne peut pas être annulé. Les Linked Account Secrets ne sont pas transférés avec le projet ; associez-les à nouveau au workspace de destination.

  <img src="/assets/mirror/transfer-project-to-workspace-menu-f3accf37a0d6.png" alt="Menu de la carte de projet avec l’action Transfer to workspace" width="1218" height="1146" data-path="images/teams/transfer-project-to-workspace-menu.png" />
</Frame>

Découvrez comment [transférer des projets entre des workspaces d’équipe](/fr/pt/teams/identity-and-access-management/transfer-app-to-teams#transfer-between-team-workspaces).
