<div id="atualizaes-do-scanner-de-segurana">
  ### 安全扫描器更新
</div>

安全扫描器迎来重大升级，安全检查更快、更智能。扫描结果现在会被缓存，只有代码发生变更时才会重新扫描，因此后续扫描速度极快。全新的忽略功能可以隐藏你不想看到的安全问题，需要时仍可随时查看。

<div id="otimizao-do-prompt-de-sistema-do-agent">
  ### Agent 系统 prompt 优化
</div>

借助我们最新的系统改进，你与 Agent 的交互将更快、更高效。现在 Agent 每次操作可提速 2 到 3 秒，同时保持你所期待的高质量结果。
