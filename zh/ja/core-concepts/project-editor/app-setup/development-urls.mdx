借助开发 URL，你可以在构建应用的过程中预览和测试应用。这类 URL 采用 `UUID.servername.replit.dev` 格式，可为开发中的应用提供实时预览。

<Frame>
  <img src="/assets/mirror/preview-dev-url-b36770b33769.png" alt="地址栏中显示的开发 URL" width="1222" height="824" data-path="images/workspace/preview-dev-url.png" />
</Frame>

要查看开发 URL，请点击地址栏中的 `{...}.replit.dev` 文本。

<div id="url">
  ## 了解开发 URL
</div>

开发 URL 仅在你正在开发 Replit 应用期间有效，每次重新打开应用时 URL 可能会变化。借助开发 URL，你可以在构建和测试过程中直接在浏览器中查看效果。

默认情况下，开发 URL 是公开的，任何拿到该 URL 的人都能查看你正在构建的应用。这样你就能轻松地把进行中的工作分享给协作者、测试人员和相关方。

<Warning>
  开发 URL 是临时的，仅供测试使用。若要与他人分享应用，建议改为[发布应用](/zh/ja/learn/projects-and-artifacts/replit-deployments)。
</Warning>

<div id="section">
  ### 说明横幅
</div>

在新标签页中打开开发预览时，页面顶部会显示一条说明横幅，帮助你在构建和测试应用时了解 `.replit.dev` URL 的用途。该横幅会介绍开发 URL 以及它在开发过程中的预期用法。

<div id="url-2">
  ## 将开发 URL 设为私有
</div>

为保护正在进行中的工作，你可以限制对开发 URL 的访问。

将开发 URL 设为私有：

1. 在项目编辑器中打开**开发者工具**。
2. 选择**网络**选项卡。
3. 启用**私有开发 URL** 开关。

启用后，访问开发 URL 需要通过认证。只有你和获得授权的团队成员才能查看进行中的工作。

<Note>
  企业版客户可以要求所有项目都必须使用私有开发 URL，从而进一步加强安全性，确保开发工作始终在组织环境内受到保护。
</Note>

<div id="section-2">
  ## 最佳实践
</div>

* 开发涉及敏感信息或专有内容的应用时，请使用**私有 URL**
* 若需要在开发过程中与外部相关方共享成果，或想在其他浏览器中测试应用，请使用**公开 URL**
