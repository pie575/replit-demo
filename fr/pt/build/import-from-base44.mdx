<div id="importar-do-base44">
  ## Importer depuis Base44
</div>

⏰ *Durée estimée : quatre minutes*

Importez un projet Base44 dans Replit en l’exportant vers GitHub, puis en important ce dépôt.

Pour découvrir toutes les options d’importation, y compris depuis d’autres plateformes comme GitHub, Figma et Lovable, consultez la [documentation de la fonctionnalité d’importation](/fr/pt/references/workspace/import).

<div id="antes-de-comear">
  ## Avant de commencer
</div>

* Un projet Base44 que vous pouvez exporter
* Un compte GitHub connecté à Base44
* Un compte Replit

<div id="etapas-de-importao">
  ## Étapes d’importation
</div>

1. Exportez votre projet de Base44 vers GitHub.
2. Ouvrez [replit.com/import](https://replit.com/import).
3. Sélectionnez **Base44**.
4. Connectez votre compte GitHub.
5. Sélectionnez le dépôt Base44 exporté.
6. Sélectionnez **Import**.

<div id="what-gets-imported">
  ## Éléments importés
</div>

Replit importe les éléments suivants depuis votre projet {platform_1} :

* **Code** : Logique de l’application et fichiers sources
* **Conception et styles** : Composants d’UI et règles de style
* **Assets** : Images, icônes et fichiers statiques
* **Logique backend** : Fonctionnalités côté serveur, le cas échéant
* **Schéma de base de données** : Structure des tables, le cas échéant

<div id="what-is-not-imported">
  ## Éléments non importés
</div>

* **Données Supabase** : les enregistrements existants de la base de données ne sont pas migrés
* **Secrets** : les variables d’environnement et les clés API doivent être ajoutées séparément

Utilisez Agent pour recréer les fonctionnalités manquantes, ajouter des secrets et recréer les données de la base de données.

<div id="configure-and-run-your-app">
  ## Configurez et exécutez votre app
</div>

Lors de l’importation, {setupDescription_0}. Si votre app nécessite des modifications, utilisez les outils suivants du Project Editor :

* **[Agent](/fr/features/agent/overview)** : Améliorez les fonctionnalités, corrigez les problèmes et modifiez le code
* **[Secrets](/fr/core-concepts/project-editor/app-setup/secrets)** : Ajoutez des clés API et des variables d’environnement
* **[Workflows](/fr/features/workspace-tools/workflows)** : Définissez la commande **Run** de votre app
