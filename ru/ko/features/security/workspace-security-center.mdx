Workspace Security Center доступен на всех тарифах. С его помощью вы можете сканировать [зависимости](/ru/ko/features/security/concepts#dependency) проектов во всём рабочем пространстве и просматривать найденные [CVE](/ru/ko/features/security/concepts#cve) по [уровню серьёзности](/ru/ko/features/security/concepts#severity). Проблемы можно устранять с помощью Replit Agent, выполнять [повторную публикацию](/ru/ko/features/security/concepts#republish) затронутых проектов и экспортировать отчёты Software Bill of Materials ([SBOM](/ru/ko/features/security/concepts#sbom)) для соответствия требованиям.

<Note>
  Чтобы просканировать отдельный проект, откройте [Project Security Center](/ru/ko/features/security/project-security-center) на панели **Security** этого проекта.
</Note>

<Note>
  Впервые сталкиваетесь с безопасностью зависимостей? Определения CVE, SBOM, уровня доступности, Fix with Agent, Republish и Auto-Protect смотрите в разделе [Концепции безопасности](/ru/ko/features/security/concepts).
</Note>

<div id="section">
  ## Функции
</div>

<div id="cve">
  ### Обнаружение CVE
</div>

Проверяйте уязвимости во всех проектах рабочего пространства.

* Выявляйте уязвимые проекты, приоритизированные по [уровню доступности](/ru/ko/features/security/concepts#exposure) (статусу публикации и области видимости)
* Просматривайте затронутые пакеты, их версии и уровень серьёзности каждой уязвимости (critical, high, medium, low)
* Просматривайте рекомендации по устранению уязвимостей для каждого проекта

<div id="section-2">
  ### Просмотр затронутых проектов
</div>

Определите, в каких проектах есть уязвимости, и решите, что исправлять в первую очередь.

* Обзор уязвимых проектов с группировкой по уровню доступности: всего проектов, опубликованных проектов, проектов, опубликованных публично
* Подробные сведения о затронутых проектах Replit
* Поиск по идентификатору CVE или названию проекта и фильтрация по уровню серьёзности, владельцу, статусу публикации (Published / Not published) и области видимости (Public / Private)
* Разворачивание строки проекта, чтобы просмотреть все обнаруженные CVE (серьёзность, пакет, версия, идентификатор CVE), не покидая страницу

<div id="fix-with-agent">
  ### Исправление с Agent и повторная публикация
</div>

Устраняйте уязвимости и выполняйте повторный деплой приложений, не выходя из Security Center.

* В затронутом проекте выберите **[Fix with Agent](/ru/ko/features/security/concepts#fix-with-agent)**, чтобы создать патч в виде фоновой задачи. Перед повторной публикацией просмотрите и примените внесённые изменения.
* Отслеживайте ход исправления по статусам **Task in progress**, **Apply changes**, **Republish**, а также итоговым статусам **Republished** и **Failed**.
* Одним нажатием **Republish** выполните повторный деплой сборки с текущей конфигурацией через диалог подтверждения после объединения исправлений.
* Выполняйте массовые действия, например отменяйте публикацию проектов или отправляйте их владельцам уведомления об уязвимостях.

<div id="sbom">
  ### Экспорт SBOM
</div>

Экспортируйте Software Bill of Materials для соблюдения требований и проведения аудита.

* Скачивайте SBOM в стандартных форматах ([SPDX](/ru/ko/features/security/concepts#spdx-and-cyclonedx), [CycloneDX](/ru/ko/features/security/concepts#spdx-and-cyclonedx))
* Создавайте отчёты для отдельных проектов или всего рабочего пространства
* Просматривайте SBOM, сгруппированные по запускам сканирования, с отметками времени, количеством проектов и именем пользователя, запустившего сканирование
* Скачивайте все SBOM, созданные в рамках запуска сканирования, одним ZIP-архивом
* Выполняйте требования к прозрачности цепочки поставок ПО

<Note>
  Пакетное скачивание SBOM доступно на тарифе Enterprise. В рабочих пространствах на других тарифах в разделе SBOM может отображаться предложение перейти на Enterprise.
</Note>

<div id="workspace-security-center">
  ## Доступ к Workspace Security Center
</div>

Чтобы открыть Workspace Security Center:

1. Перейдите на [replit.com](https://replit.com) и войдите в свою учётную запись.
2. На главной странице в левой панели навигации выберите **Security**.

<div id="section-3">
  ## Сканирование рабочего пространства
</div>

<Frame>
  <img src="/assets/mirror/security-overview-b37f090f236c.png" alt="Стартовый экран Workspace Security Center с общим количеством сканирований, общим числом уязвимостей и CVE, сгруппированными по уровню серьёзности" width="3438" height="1984" data-path="images/workspace-security-center/security-overview.png" />
</Frame>

1. Откройте Workspace Security Center.
2. Выберите **Run security scan**, чтобы запустить сканирование всего рабочего пространства.
3. Изучите результаты, сгруппированные по затронутым проектам, уровню серьёзности и уровню доступности деплоя извне.
4. В затронутом проекте выберите **Fix with Agent**, а после применения исправлений — **Republish**.

Сканирование анализирует зависимости в проектах Replit вашего рабочего пространства и отмечает известные уязвимости по данным публичных баз уязвимостей.

<div id="auto-protect">
  ## Auto-Protect
</div>

Администраторы могут включить **[Auto-Protect](/ru/ko/features/security/concepts#auto-protect)** для аккаунта, чтобы непрерывно отслеживать новые CVE, опубликованные для зависимостей всех проектов. При обнаружении соответствия Replit Agent подготовит протестированное исправление, а разработчик получит электронное письмо с прямой ссылкой для его применения.

Полное описание рабочего процесса и шагов настройки, включая доступный только администраторам порог критичности в **Settings** &gt; **Account** &gt; **Advanced**, см. в разделе [Auto-Protect](/ru/ko/features/security/project-security-center#auto-protect).

<Note>
  Если вам нужна помощь с настройкой Workspace Security Center или интеграцией экспорта SBOM в процессы обеспечения соответствия требованиям, обратитесь к своему менеджеру по работе с клиентами.
</Note>
