Skills 可让 Agent 学习新功能——你偏好的模式、库的细节、设计系统规则，或已解决问题的方案。你可以将其附加到消息中、安装到项目中，或选作新项目的起点。

<div id="skill">
  ## 在聊天中使用 skill
</div>

使用 Skills 最快的方式是将其附加到单条消息中，无需安装。

<Frame>
  <img src="/assets/mirror/agent-skills-picker-ee4058454475.png" alt="通过聊天输入框旁的 + 按钮打开的 Skill 选择器，显示包含 Ad Creative、AI Recruiter、AI SDR 和 AI Secretary 的 Skills 列表" width="723" height="529" data-path="images/replitai/agent-skills-picker.png" />
</Frame>

<Steps>
  <Step title="打开 Skill 选择器">
    点击聊天输入框旁的 **+** 按钮，然后选择 **Use a skill**。
  </Step>

  <Step title="浏览并选择 Skill">
    按 Business &amp; finance、Creative、Research &amp; analysis 等类别浏览 Skills。选择一个或多个 skill 并附加到消息中。
  </Step>

  <Step title="发送消息">
    输入请求并发送。Agent 仅会在该消息中使用所选 skills。消息中会显示 skill 标签，方便你查看哪些 skills 处于启用状态。
  </Step>
</Steps>

例如，附加 **Stock Analyzer** 并让 Agent 撰写股票研究报告，或附加 **Deep Research**，让 Agent 针对某个主题开展研究并生成结构化成果。

<Tip>
  在聊天中附加的 Skills 不会在项目中安装任何内容。你可以立即在所有项目中使用它们。
</Tip>

<div id="skill-2">
  ## 使用 skill 创建项目
</div>

创建新项目时，你可以选择经过验证的 skill 作为起点。Agent 会根据 skill 中的说明配置项目。

<Steps>
  <Step title="打开起点选择器">
    在新项目页面，点击 **+**，然后选择 **Use a skill**。
  </Step>

  <Step title="选择 skill">
    浏览 **AI SDR**、**SEO Auditor**、**Ad Creative** 和 **Programmatic SEO** 等精选 skills。选择符合你要创建的应用类型的 skill。
  </Step>

  <Step title="描述你的应用">
    告诉 Agent 你的需求。Agent 会从头开始构建一个遵循 skill 模式和规则的项目。
  </Step>
</Steps>

<div id="skill-3">
  ## 在项目中安装 skill
</div>

如果希望 Agent 在项目中的所有 Conversation 中始终应用 skill，请安装它。已安装的 skills 会存储在项目的 `/.agents/skills` 目录中，并会在不同聊天会话间保留。

<div id="skills">
  ### 通过 Skills 面板安装
</div>

打开 Project Editor 中的 **Skills 面板**，选择 **Discover** 标签页，浏览社区贡献的 skills。找到需要的 skill 后，点击 **Install**，即可自动将其添加到你的项目中。

<Frame>
  <img src="/assets/mirror/agent-skills-discover-732b2b0c488a.png" alt="Discover skills 标签页，显示可搜索的社区贡献 skills 及安装按钮" width="2542" height="1850" data-path="images/replitai/agent-skills-discover.png" />
</Frame>

例如，构建具有高级动画的作品集网站时，你可以安装以下 skills：

* **GSAP React** — 教 Agent 实现滚动触发动画、文字揭示和 SVG 路径绘制
* **Tailwind design system** — 为 Agent 提供有关排版、间距和视图过渡的 Tailwind CSS 模式知识
* **Find skills** — 教 Agent 如何代你搜索和安装新的 skills

<Tip>
  你也可以通过 [npx skills CLI](https://github.com/vercel-labs/skills) 安装 skills：

  ```bash theme={null}
  npx skills <skill> -a replit
  ```
</Tip>

<div id="skill-4">
  ### 在 Conversation 中创建 skill
</div>

创建 skill 最自然的方式是与 Agent 对话。在共同解决问题或研究新库后，请 Agent 记录学到的内容：

<AiPrompt>
  研究 GSAP 与 React 集成的最佳实践，并为这个项目创建一个 skill。
</AiPrompt>

Agent 会利用完整的对话上下文编写详细的 skill 文件。在调试过程中逐步形成对问题的共同理解后，这种方式尤其有效。

<div id="skill-5">
  ### 创建自定义 skill
</div>

对于高级使用场景，请按照 [Agent Skills 规范](https://agentskills.io/specification)自行编写 skills。在文件侧边栏中启用 **Show Hidden Files**，打开 `/.agents/skills/`，然后新建一个 Markdown 文件。这样，你就能完全控制 Agent 所了解的内容及其行为方式。
