L’outil Paramètres utilisateur de l’Éditeur de projet vous permet de personnaliser l’apparence, le comportement et les raccourcis clavier de votre compte.

<Frame>
  <img src="/assets/mirror/user-settings-tool-faae3afb911b.png" alt="capture d’écran de l’outil Paramètres utilisateur" width="4152" height="1894" data-path="images/workspace/user-settings-tool.png" />
</Frame>

<div id="funcionalidades">
  ## Fonctionnalités
</div>

Vous pouvez personnaliser votre expérience de création d&#39;apps Replit à l&#39;aide des catégories de paramètres suivantes :

* **Personnalisation du thème** : choisissez entre des thèmes clairs et sombres pour l&#39;Éditeur de projet
* **Intelligence du code** : configurez des fonctionnalités d&#39;IA qui améliorent votre expérience de création d&#39;applications
* **Préférences de l&#39;éditeur** : ajustez le comportement et l&#39;affichage de l&#39;éditeur de fichiers
* **Paramètres de notification** : gérez vos préférences d&#39;alerte
* **Options d&#39;accessibilité** : optimisez Replit pour les utilisateurs ayant des besoins spécifiques
* **Raccourcis clavier** : définissez des combinaisons de touches pour exécuter des actions courantes et naviguer dans l&#39;interface

<div id="uso">
  ## Utilisation
</div>

<Accordion title="Accéder aux Paramètres utilisateur">
  Dans la **barre d’outils** de gauche :

  1. Sélectionnez <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Icône de tous les outils" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **Tous les outils** pour afficher la liste des outils de l’Éditeur de projet.
  2. Sélectionnez <img class="icon-svg" src="/assets/mirror/settings-icon-c2664c3691bf.svg" alt="Icône des paramètres" width="16" height="16" data-path="images/icons/settings-icon.svg" /> **Paramètres utilisateur**.

  Dans la **barre de recherche** :

  1. Sélectionnez l’<img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="icône de loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> icône de loupe en haut pour ouvrir l’outil de recherche.
  2. Saisissez « User Settings » pour trouver l’outil, puis sélectionnez-le dans les résultats.
</Accordion>

<div id="aparncia">
  ### Apparence
</div>

Personnalisez les paramètres d’apparence suivants de l’Éditeur de projet :

* **Sélection du thème** : choisissez parmi des thèmes prédéfinis clairs et sombres, des <a href="https://replit.com/themes" target="_blank">thèmes de la communauté</a> ou votre propre thème personnalisé
* **Thèmes personnalisés** : créez des palettes de couleurs personnalisées à l’aide de l’éditeur de [thèmes](/fr/pt/core-concepts/project-editor/editor-and-tools/themes)

<div id="preferncias-do-editor-de-arquivos">
  ### Préférences de l’éditeur de fichiers
</div>

Contrôlez l’apparence et le comportement de l’éditeur de fichiers à l’aide des paramètres suivants :

* **Taille de police** : Ajustez la taille du texte pour améliorer la lisibilité
* **Fermeture automatique des crochets** : Insère automatiquement un crochet fermant lorsque vous saisissez un crochet ouvrant
* **Détection de l’indentation** : Détecte automatiquement les paramètres d’indentation à l’ouverture d’un fichier
* **Formater l’indentation du texte collé** : Reformate le code collé pour respecter l’indentation appropriée
* **Caractère d’indentation** : Choisissez entre les espaces et les tabulations pour indenter le code
* **Taille d’indentation** : Définissez le nombre de colonnes pour chaque niveau d’indentation
* **Retour à la ligne** : Configurez le comportement du retour à la ligne
* **Minicarte** : Ajoutez un aperçu navigable du code dans une barre latérale
* **Touche modificatrice de sélection multiple** : Définissez la touche modificatrice permettant de sélectionner plusieurs fichiers
* **Statut Git dans l’arborescence des fichiers** : Affiche les indicateurs de statut Git dans l’arborescence des fichiers

<div id="inteligncia-de-cdigo">
  ### Intelligence du code
</div>

Configurez les outils d&#39;IA à l&#39;aide des paramètres suivants :

* **Jetons sémantiques** : utilisez une coloration syntaxique enrichie par les serveurs de langage
* **Complétion de code par IA** : ajoute des suggestions de code en ligne à mesure que vous tapez
* **Accepter les suggestions lors de la saisie d&#39;un caractère de validation** : accepte automatiquement les suggestions de code lorsque vous tapez certains caractères

<div id="preferncias-de-shell-e-preview">
  ### Préférences de Shell et Preview
</div>

Personnalisez le comportement des outils Shell et Preview :

* **Alerte sonore du Shell :** Émet un son lorsque l’outil Shell rencontre des problèmes
* **Preview automatique :** Ouvre automatiquement l’onglet Preview lorsqu’un serveur devient disponible
* **Redirection automatique des ports ouverts :** Configure la gestion des ports nouvellement détectés

<div id="notificaes">
  ### Notifications
</div>

Gérez les paramètres de notification suivants :

* **Notification sonore de l’Agent** : émet un son lorsque l’Agent demande un retour
* **Notification push de l’Agent** : recevez des notifications push sur votre téléphone lorsque l’Agent demande un retour

<div id="acessibilidade">
  ### Accessibilité
</div>

Vous pouvez personnaliser le paramètre d’accessibilité suivant :

* **Sortie du terminal accessible** : active la compatibilité avec les lecteurs d’écran pour les outils Shell et Console

<div id="atalhos-de-teclado">
  ### Raccourcis clavier
</div>

Pour accéder aux préférences des raccourcis clavier, sélectionnez l’onglet **Raccourcis clavier** dans l’outil Paramètres utilisateur.

Vous pouvez rechercher des combinaisons de touches à l’aide des méthodes suivantes :

* **Nom** : saisissez le nom ou la description du raccourci clavier dans le champ de recherche
* **Combinaison de touches** : sélectionnez l’icône <img class="icon-svg" src="/assets/mirror/keyboard-7ba19771b671.svg" alt="icône de clavier" width="16" height="16" data-path="images/icons/keyboard.svg" /> et saisissez la combinaison de touches

Utilisez les actions suivantes pour gérer les raccourcis :

* **Ajouter** : sélectionnez **Ajouter un raccourci**
* **Mettre à jour** : sélectionnez l’icône en forme de crayon <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="icône de crayon" width="16" height="16" data-path="images/icons/pencil-icon.svg" />
* **Supprimer** : sélectionnez l’icône en forme de corbeille <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="icône de corbeille" width="16" height="16" data-path="images/icons/trash-icon.svg" />
