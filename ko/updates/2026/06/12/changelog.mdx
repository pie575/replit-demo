<div id="customize-agent-with-workspace-instructions-and-skills">
  ### workspace instructions와 skills로 Agent 맞춤 설정하기
</div>

이제 팀의 업무 방식을 Agent에게 한 번만 알려주면 어디에서나 그대로 적용됩니다. 모든 project에서 Agent가 따르는 **Custom instructions**를 설정하고, 특정 task에 필요할 때 Agent가 불러오는 재사용 가능한 **skills**를 만들어 보세요. 두 가지 모두 **Workspace Settings** &gt; **Customization**에서 관리할 수 있습니다.

</Frame>

자세한 내용은 [Agent Customization](/ko/features/agent/agent-customization)에서 확인하세요.

<div id="block-malicious-packages-with-package-firewall">
  ### Package Firewall로 악성 패키지 차단
</div>

이제 Replit이 악성 및 변조된 소프트웨어 패키지를 앱에 도달하기 전에 차단합니다. Package Firewall은 주요 패키지 관리자 전반의 모든 설치를 검사해 유해한 의존성을 자동으로 막아 줍니다. 기본적으로 켜져 있으며, 패키지가 차단되면 Agent가 더 안전한 대안을 사용하도록 계획을 조정합니다.

</Frame>

[Package Firewall](/ko/features/security/package-firewall)에 대해 자세히 알아보세요.

<div id="faster-slide-import-and-export">
  ### 더 빨라진 slide 가져오기 및 내보내기
</div>

PowerPoint 및 Google Slides 내보내기 속도가 3~10배 빨라졌고, 사진이 많은 대용량 deck에서도 더 이상 지나치게 큰 PDF 파일이 생성되지 않으며, 한 번의 선택만으로 Google Slides 내보내기로 바로 이동할 수 있습니다.

<Frame caption="deck을 PDF, PowerPoint 또는 Google Slides로 내보내세요.">
  <img src="/assets/mirror/slides-export-menu-f70338ff9908.png" alt="Export 메뉴가 열린 Slides 도구 모음으로, deck을 PDF, PowerPoint 또는 Google Slides로 내보내는 옵션이 표시된 모습" width="1812" height="926" data-path="images/artifact-types/slides-export-menu.png" />
</Frame>

자세한 내용은 [slide deck 내보내기](/ko/features/artifact-types/slide-decks#exporting)에서 확인하세요.

<div id="add-visual-references-when-you-generate-media-on-canvas">
  ### Canvas에서 미디어를 생성할 때 시각적 참고 자료 추가
</div>

Canvas에서 이미지, 동영상, 벡터 그래픽을 생성할 때 이제 board에 이미 있는 항목을 시각적 참고 자료로 첨부할 수 있습니다. frame, 노트, 이미지를 선택하면 Agent가 이를 참고해 결과물을 만들기 때문에, 생성된 미디어가 project의 분위기와 잘 어울립니다.

<Frame caption="Generate media 양식에서 + 메뉴를 열어 파일을 업로드하거나 캔버스 요소를 선택하세요.">
  <img src="/assets/mirror/canvas-generate-media-references-ac0cb4340acb.png" alt="플러스 메뉴가 열린 Canvas의 Generate media 양식으로, Upload file 및 Select canvas elements 옵션과 Nano Banana Pro로 설정된 모델 드롭다운이 표시되어 있습니다" width="1134" height="662" data-path="images/replitai/canvas-generate-media-references.png" />
</Frame>

<Note>
  ChatGPT Images 2.0은 현재 업로드를 지원하지 않습니다. 시각적 참고 자료를 첨부하려면 Nano Banana Pro 등 다른 모델로 전환하세요.
</Note>

[Canvas에서 미디어 생성하기](/ko/design/toolbar#generate)에 대해 자세히 알아보세요.

<div id="choose-which-production-alerts-reach-your-inbox">
  ### 받은 편지함으로 받을 production alerts 선택하기
</div>

이제 production alerts를 다른 이메일과 분리해 관리할 수 있습니다. 새로 추가된 **Production Alerts** 설정에서 uptime 장애, 의존성의 보안 취약점, 언어 model 업데이트에 대한 Replit 이메일 수신 여부를 결정할 수 있습니다. published app이 오래된 model을 사용 중이면 Replit이 draft task까지 준비해 주므로, 검토 한 번으로 업그레이드할 수 있습니다.

<Frame caption="Production Alerts는 Settings → Personalization → Email에서 확인할 수 있습니다.">
  <img src="/assets/mirror/production-alerts-settings-333bb4ee8a61.png" alt="알림 설정의 Production Alerts 섹션으로, production alert 이메일 토글이 켜져 있고 보안 alerts severity 드롭다운이 펼쳐진 모습" width="2000" height="899" data-path="images/editor/production-alerts-settings.png" />
</Frame>

[알림 설정](/ko/features/editor/user-settings#notifications)에 대해 자세히 알아보세요.
