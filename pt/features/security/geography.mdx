Escolha onde a infraestrutura do seu workspace e do app publicado é hospedada para oferecer suporte à residência de dados e reduzir a latência. O Replit oferece configurações de geografia separadas, para que você possa gerenciar os locais de desenvolvimento e do app publicado de forma independente.

## Compare a geografia do workspace e a de publicação

| Aspecto                      | Geografia do workspace                         | Geografia de publicação                                   |
| :--------------------------- | :--------------------------------------------- | :-------------------------------------------------------- |
| **Controla**                 | Recursos de desenvolvimento em um workspace    | Computação e armazenamento de um app publicado            |
| **Definida ao**              | Criar o workspace                              | Publicar um projeto                                       |
| **Resultado na localização** | Define a região para novos projetos e recursos | Coloca os artefatos publicados juntos em uma única região |
| **Pode mudar depois**        | Não                                            | Não                                                       |

A geografia do workspace e a de publicação não precisam ser iguais.

Para detalhes sobre como escolher uma região de desenvolvimento ao criar um Workspace, consulte [Geografia do workspace](/pt/features/collaboration/workspace-geography).

## Geografia de publicação

Defina a geografia de publicação quando publicar um projeto. Por padrão, o Replit recomenda a geografia mais próxima de você. Isso ajuda a reduzir a latência para os visitantes do seu app e a cumprir os requisitos de residência de dados.

Ao selecionar uma geografia, todos os artefatos publicados do seu projeto (como computação, banco de dados e Object Storage) são automaticamente colocados na mesma região. Um proxy específico da geografia também ajuda a reduzir a latência para os visitantes do seu app.

### Selecione uma geografia de publicação

Para escolher uma geografia diferente da recomendada:

<Steps>
  <Step>
    Abra a ferramenta **Publishing** no seu projeto Replit.
  </Step>

  <Step>
    Expanda as configurações **Advanced**.
  </Step>

  <Step>
    Selecione a sua geografia preferida no menu suspenso **Geography**.
  </Step>

  <Step>
    Selecione **Publish** para publicar o seu projeto na geografia selecionada.
  </Step>
</Steps>

### Imponha uma geografia em projetos publicados

Administradores Enterprise podem impor uma geografia de publicação para todos os projetos da organização. Quando uma política é definida, os builders da organização publicam na geografia configurada. Essa política se aplica apenas a projetos que ainda não foram publicados — projetos já publicados em uma geografia diferente não são afetados.

<Note>
  Impor uma geografia de publicação é um recurso Enterprise. Para saber mais sobre os planos Enterprise, consulte [Preços](https://replit.com/pricing/).
</Note>

<Steps>
  <Step>
    Acesse as suas **Account settings**.
  </Step>

  <Step>
    Selecione **Advanced**.
  </Step>

  <Step>
    Escolha a geografia que todos os projetos publicados pela primeira vez devem usar.
  </Step>
</Steps>

### Limitações da geografia de publicação

Antes de selecionar uma geografia de publicação, tenha em mente as seguintes limitações:

* **A geografia não pode ser alterada após a publicação.** Depois de publicar o seu projeto em uma geografia, essa seleção é permanente. Não é possível migrar um projeto publicado para uma geografia diferente.
* **Os locais de desenvolvimento e de publicação podem ser diferentes.** Recursos como o Object Storage podem ser criados antes da publicação e podem não corresponder à sua geografia de publicação.

## Geografias disponíveis

A geografia do workspace e a de publicação oferecem opções de região diferentes:

| Geografia         | Seleção no workspace | Seleção na publicação |
| :---------------- | :------------------- | :-------------------- |
| **North America** | Sim                  | Sim                   |
| **Europe (EU)**   | Sim                  | Sim                   |
| **Asia**          | Sim                  | Sim                   |
| **South America** | Não                  | Sim                   |
| **Australia**     | Não                  | Sim                   |

<Note>
  A seleção da geografia do workspace está disponível apenas para clientes Pro.
  A seleção da geografia de publicação está disponível para clientes Core, Pro e Enterprise.
  Clientes Free publicam na América do Norte por padrão.
</Note>
