用 Voice Mode 直接说出你想构建的内容。点按 Agent 聊天框中的麦克风，说出你的 prompt，Replit 就会把语音转写成可编辑的文本。检查文本、按需修改，然后像发送普通消息一样发送即可。

打字慢或不方便时，Voice Mode 就派上用场了——尤其是在移动端，口述一段完整的 prompt 通常比用拇指打字快得多。

<Note>
  Voice Mode 只是把你的语音转成聊天框中的文本，并不会朗读 Agent
  的回复——你发送的仍是文字消息，Agent 也照常在聊天中回复。
</Note>

<div id="how-it-works">
  ## 工作原理
</div>

<Frame>
  <img src="/assets/mirror/voice-mode-mic-button-fe7da6953736.png" alt="Agent 聊天框中高亮显示的麦克风按钮及“开始语音输入”提示，旁边是 Plan 复选框和发送箭头" width="1853" height="423" data-path="images/replitai/voice-mode/voice-mode-mic-button.png" />
</Frame>

Voice Mode 会录下你的语音，将其转写为文字并插入聊天框，供你在发送前确认：

1. 打开 Agent，点击聊天框中的麦克风。
2. 如果浏览器或设备弹出提示，请允许访问麦克风。
3. 说出你的 prompt。出现波形即表示 Agent 正在录音。
4. 说完后停止录音。停顿一段时间或切换到其他标签页时，录音也会自动停止。
5. 稍等片刻，等待语音转写完成。
6. 检查转写出的文本，必要时进行修改，然后发送消息。

由于转写结果会以普通文本的形式出现在聊天框中，你可以自由地把语音和键盘输入结合起来——先口述一部分 prompt，再手动输入其余内容，或者在发送前改掉某个词。

<Tip>
  自然说话即可。Voice Mode 侧重于捕捉你想表达的意思，而非逐字转写，因此“嗯”“呃”之类的语气词不会出现在结果中。
</Tip>

<div id="where-you-can-use-it">
  ## 可以在哪里使用
</div>

Voice Mode 可在 Agent 聊天框中使用：

* 在 **Project Editor** 中与 Agent 协作开发应用时。
* 在主屏幕的 Agent prompt 输入框中**创建新应用**时。

你可以在桌面端网页、移动端网页以及 Replit 移动应用中使用 Voice Mode。

<div id="good-to-know">
  ## 须知事项
</div>

使用 Voice Mode 时请注意以下细节：

| 细节    | 预期情况                                                        |
| ----- | ----------------------------------------------------------- |
| 录音时长  | 单次最多可录制 6 分钟，临近上限时会收到提示。                                    |
| 自动停止  | 静默约 30 秒后录音会自动停止；切换标签页或将应用切至后台时也会停止。                        |
| 发送前检查 | 转写后的文本会出现在聊天框中，你可以先阅读并修改，然后再发送——系统不会自动发送。                   |
| 麦克风权限 | Voice Mode 需要获得麦克风使用权限。如果无法开始录音，请检查浏览器和设备是否允许 Replit 访问麦克风。 |

<div id="availability">
  ## 可用性
</div>

所有 Replit 套餐均可使用 Voice Mode。在支持录音的浏览器和设备上，Agent 聊天框中会显示麦克风图标；首次录音时，系统会请求你授予麦克风权限。
