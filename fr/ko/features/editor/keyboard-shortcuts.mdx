---
title: "Raccourcis clavier"
description: "Découvrez comment consulter, ajouter et modifier les raccourcis clavier qui améliorent votre productivité sur Replit."
---

Les raccourcis clavier vous permettent d&#39;exécuter des commandes, de modifier du texte et de naviguer
dans le Project Editor à l&#39;aide de combinaisons de touches configurables. Vous pouvez
configurer et utiliser les raccourcis clavier dans l&#39;application web Replit.com.

<div id="section">
  ## Consulter les raccourcis clavier
</div>

Pour consulter la configuration des raccourcis clavier, suivez les étapes ci-dessous.

1. Ouvrez votre Replit App pour accéder au Project Editor.
2. Dans le dock, sous <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="all tools icon" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**, ouvrez l&#39;onglet <img class="icon-svg" src="/assets/mirror/settings-icon-c2664c3691bf.svg" alt="gear icon" width="16" height="16" data-path="images/icons/settings-icon.svg" /> **User Settings**.
   Vous pouvez également rechercher « User Settings » à l&#39;aide de la loupe <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="magnifying glass icon" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" />.
3. Sélectionnez l&#39;onglet **Keyboard shortcuts** pour afficher la liste des commandes et les raccourcis qui leur sont attribués.

<div id="section-2">
  ## Personnaliser les raccourcis clavier
</div>

Pour ajouter ou modifier un raccourci clavier, suivez les étapes ci-dessous.

1. Sélectionnez <img class="icon-svg" src="/assets/mirror/create-app-icon-ba218e87fb67.svg" alt="plus icon" width="16" height="16" data-path="images/icons/create-app-icon.svg" />**Add shortcut** à côté d&#39;une commande non attribuée,
   ou, pour une commande déjà attribuée, sélectionnez l&#39;icône crayon <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="pencil icon" width="16" height="16" data-path="images/icons/pencil-icon.svg" />.
2. Lorsque « Recording... » s&#39;affiche à côté de la commande, appuyez sur la combinaison de touches que vous souhaitez attribuer.
   Pour annuler l&#39;enregistrement, cliquez sur une zone vide de l&#39;onglet.
3. Pour rétablir un raccourci, sélectionnez l&#39;icône de restauration <img class="icon-svg" src="/assets/mirror/rollback-icon-3197ed1b323b.svg" alt="rollback icon" width="12" height="12" data-path="images/icons/rollback-icon.svg" />.

<div id="section-3">
  ## Supprimer un raccourci clavier
</div>

Pour supprimer un raccourci clavier, sélectionnez l&#39;icône <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="trash icon" width="16" height="16" data-path="images/icons/trash-icon.svg" /> corbeille située à côté de la commande.

<div id="section-4">
  ## Navigation par tabulation
</div>

Vous pouvez utiliser la navigation à la touche **Tab** de votre navigateur pour vous déplacer entre les éléments interactifs de la page.
Toutefois, les outils File Editor, Console et Shell interceptent les appuis sur la touche **Tab**,
notamment pour l&#39;indentation.

Pour continuer à parcourir les éléments de la page depuis ces outils, procédez comme suit :

1. Appuyez sur **Échap** pour retirer le focus de l&#39;outil
2. Appuyez sur **Tab** pour passer à l&#39;élément suivant
