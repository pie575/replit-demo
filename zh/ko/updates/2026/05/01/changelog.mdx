<div id="replit-app-monitoring">
  ### 使用 Replit App Monitoring 监控已发布的应用
</div>

现在，你可以为已发布的 Replit 应用开启**应用监控**，实时掌握运行状况：在**发布**视图和**分析**标签页中查看彩色的正常运行时间条，并在应用宕机时收到邮件通知。应用监控适用于所有付费方案，并支持除计划任务部署外的所有部署类型。当应用出现问题时，选择**让 Agent 调查最近的宕机**，即可启动一个后台任务，自动获取受影响的时间段、检查日志和代码，并给出修复建议。

<div id="agent-slide-decks">
  ### 使用 Agent 制作完整的幻灯片演示文稿
</div>

无论是路演材料、产品概览、销售演示还是团队进展汇报，只需描述你想要的演示文稿，Agent 就会生成版式、文案和视觉元素俱全的精美演示文稿。你可以通过对话修改幻灯片，用 Visual Editor 编辑文字和样式，在浏览器中直接演讲，将演示文稿发布为实时 URL，或导出为 PPTX、Google Slides 或 PDF。
