你可以通过管理连接器，让团队以一致且安全的方式使用各项集成。可用功能因套餐而异：

* **Core 和 Pro**：连接器管理适用于**协作工作区**。账户管理员为该工作区设置并管理连接，构建者可在该工作区内的应用中使用这些连接。
* **Enterprise**：面向整个组织的连接器管理，提供自定义 OAuth 客户端、API 密钥访问控制、自带密钥等高级控制功能。

<div id="section">
  ## 主要功能
</div>

* **集中管理**：管理员只需配置一次服务，构建者即可在该工作区的所有应用中使用。
* **可见性与审计**：查看哪些应用和成员正在使用哪些服务。
* **按应用授权和撤销**：无需更改代码即可撤销或更换访问权限。

**仅限 Enterprise：**

* **基于角色的访问控制**：为 API 密钥设置范围，实施最小权限原则和访问控制。
* **使用自有 OAuth**：使用具有自定义范围的组织自有 OAuth 客户端。
* **使用自有 OpenAI 密钥**：使用自己的 OpenAI API 密钥，而非 Replit 默认密钥。

<div id="section-2">
  ## 工作原理
</div>

<Steps>
  <Step title="管理员设置服务">
    管理员使用凭据一次性完成服务设置。
  </Step>

  <Step title="管理员授权访问">
    管理员批准哪些群组可以使用该连接器 (Enterprise) ，或在协作工作区中开放使用 (Core/Pro) 。
  </Step>

  <Step title="构建者使用连接器">
    成员在工作区或组织内的应用中向 Agent 发出请求，基于该服务进行构建。
  </Step>

  <Step title="管理员监控使用量">
    管理员可以监控哪些成员和应用正在使用哪些服务。
  </Step>
</Steps>

<div id="section-3">
  ## 安全与治理
</div>

* 凭据和令牌由平台统一管理，不会存储在各个应用中。
* 无需改动代码即可集中撤销和轮换凭据。
* Enterprise：基于最小权限原则实现范围化访问，并可选配自定义 OAuth 配置。

<div id="section-4">
  ## 设置与管理
</div>

<div id="section-5">
  ### 启用新连接器
</div>

<Steps>
  <Step title="前往集成">
    在协作工作区 (Core/Pro) 或组织主页 (Enterprise) 中打开**集成**页面。
  </Step>

  <Step title="启用新连接器">
    在右上角选择**启用新连接器**。
  </Step>

  <Step title="选择服务">
    选择要启用的服务 (例如 Notion、GitHub、Google、Outlook、Dropbox、Salesforce) 。
  </Step>

  <Step title="配置连接器">
    使用默认配置启用连接器。仅 **Enterprise** 支持创建自定义 OAuth 连接器 (例如 Drive 权限范围 `.../auth/drive.file`、`.../auth/drive.install`) 。
  </Step>

  <Step title="提交">
    选择**提交**。
  </Step>
</Steps>

<div id="enterprise">
  ### 配置访问权限 (Enterprise)
</div>

1. 启用连接器后，选择**管理**。
2. 根据需要为特定群组授予访问权限。

<div id="section-6">
  ### 修改连接器
</div>

* 启用连接器后，选择**管理**。
* 删除连接器后，它将从相应工作区 (Core/Pro) 或组织 (Enterprise) 的所有构建者处移除。
* 在 Enterprise 中，可以编辑自定义 OAuth 连接器的权限范围。

<div id="section-7">
  ## 套餐对比
</div>

| 功能              | Core (协作工作区)  | Pro (协作工作区)  | Enterprise |
| --------------- | ------------- | ------------ | ---------- |
| 启用和管理连接器        | ✓             | ✓            | ✓          |
| 适用范围            | 工作区           | 工作区          | 组织         |
| 创建自定义 OAuth 客户端 | —             | —            | ✓          |
| 配置 API 密钥访问控制   | —             | —            | ✓          |
| 使用自有 OpenAI 密钥  | —             | —            | ✓          |

<div id="openai-enterprise">
  ### 使用自有 OpenAI 密钥 (Enterprise)
</div>

Enterprise 客户可通过连接器使用自己的 OpenAI API 密钥，无需使用 Replit 默认的 AI 基础设施。这样既能沿用现有的 OpenAI 合同，也能通过自己的账户管理 AI 使用量。
