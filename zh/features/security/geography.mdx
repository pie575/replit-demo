选择你的 workspace 和已发布应用基础设施的托管位置，以满足数据驻留要求并降低延迟。Replit 提供相互独立的地理位置设置，你可以分别管理开发环境和已发布应用所在的位置。

<div id="compare-workspace-and-publishing-geography">
  ## 对比 workspace 地理位置与发布地理位置
</div>

| 方面         | Workspace 地理位置       | 发布地理位置                 |
| :--------- | :------------------- | :--------------------- |
| **控制对象**   | workspace 中的开发资源     | 已发布应用的计算与存储            |
| **设置时机**   | 创建 workspace 时       | 发布 project 时           |
| **位置效果**   | 为新建的 project 和资源指定区域 | 将已发布的 artifact 集中在同一区域 |
| **能否后续更改** | 否                    | 否                      |

workspace 地理位置与发布地理位置不必一致。

有关创建 Workspace 时如何选择开发区域，请参阅 [Workspace 地理位置](/zh/features/collaboration/workspace-geography)。

<div id="publishing-geography">
  ## 发布地理位置
</div>

在发布 project 时设置发布地理位置。默认情况下，Replit 会推荐离你最近的地理位置。这有助于降低应用访问者的访问延迟，并满足数据驻留要求。

选择地理位置后，该 project 的所有已发布 artifact (如计算资源、数据库和 Object Storage) 都会自动部署在同一区域。此外，该地理位置专属的代理也有助于降低应用访问者的延迟。

<div id="select-a-publishing-geography">
  ### 选择发布地理位置
</div>

如需选择推荐地理位置以外的地理位置：

<Steps>
  <Step>
    在 Replit 项目中打开 **Publishing** 工具。
  </Step>

  <Step>
    展开 **Advanced** 设置。
  </Step>

  <Step>
    在 **Geography** 下拉菜单中选择你需要的地理位置。
  </Step>

  <Step>
    点击 **Publish**，将项目发布到所选地理位置。
  </Step>
</Steps>

<div id="enforce-a-geography-on-published-projects">
  ### 为已发布的 project 强制指定地理位置
</div>

Enterprise 管理员可以为组织内的所有 project 强制指定发布地理位置。策略设置后，组织中的构建者只能发布到所配置的地理位置。此策略仅适用于尚未发布的 project——已发布到其他地理位置的 project 不受影响。

<Note>
  强制指定发布地理位置为 Enterprise 功能。如需详细了解 Enterprise 方案，请参阅[定价](https://replit.com/pricing/)。
</Note>

<Steps>
  <Step>
    进入你的 **Account settings**。
  </Step>

  <Step>
    选择 **Advanced**。
  </Step>

  <Step>
    选择所有首次发布的 project 必须使用的地理位置。
  </Step>
</Steps>

<div id="publishing-geography-limitations">
  ### Publishing 地理位置限制
</div>

在选择 Publishing 地理位置之前，请注意以下限制：

* **发布后无法更改地理位置。** 将 project 发布到某个地理位置后，该选择即为永久性的，无法再将已发布的 project 迁移到其他地理位置。
* **开发地理位置与发布地理位置可能不同。** Object Storage 等资源可能在发布之前就已创建，因此可能与发布地理位置不一致。

<div id="available-geographies">
  ## 可用地理位置
</div>

Workspace 与发布可选的地区范围有所不同：

| 地理位置                | Workspace 可选 | 发布可选 |
| :---------------- | :----------- | :--- |
| **北美**            | 是            | 是    |
| **欧洲 (EU)&#x20;**&#x20;| 是            | 是    |
| **亚洲**            | 是            | 是    |
| **南美**            | 否            | 是    |
| **澳大利亚**          | 否            | 是    |

<Note>
  Workspace 地理位置选择仅面向 Pro 客户开放。
  发布地理位置选择面向 Core、Pro 和 Enterprise 客户开放。
  免费客户默认发布到北美。
</Note>
