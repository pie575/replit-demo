<div id="draft">
  ## Draft
</div>

**Draft (brouillon)** désigne une tâche planifiée par Agent, mais dont le build n&#39;a pas encore commencé. Les brouillons ne contiennent que les détails proposés pour la tâche, ce qui vous permet de les examiner en toute sécurité : titre, description et plan de la tâche.

Utilisez Drafts pour vérifier qu’Agent a bien compris votre objectif. Vous pouvez démarrer une tâche, demander à Agent de modifier le plan ou conserver un brouillon pour plus tard.

<div id="active">
  ## Active
</div>

Les tâches **Active(활성)** s’exécutent en arrière-plan. Agent travaille sur une copie isolée du projet afin que la version principale reste inchangée pendant l’exécution de la tâche.

Vous pouvez continuer à utiliser le fil principal pendant l’exécution d’une tâche Active. Si la tâche nécessite votre avis, ouvrez ce fil et poursuivez la conversation.

<div id="queued">
  ## Queued
</div>

Les tâches **Queued (en attente)** ont été approuvées, mais n’ont pas encore démarré. Une tâche peut être mise en file d’attente si elle dépend d’autres tâches ou si la limite de tâches en arrière-plan actives de votre formule est atteinte.

Les tâches en attente démarrent automatiquement lorsque les prérequis sont remplis et qu’un emplacement pour une tâche active se libère.

<div id="ready">
  ## Ready
</div>

Les tâches **Ready(prêt)** sont terminées, mais leurs modifications n’ont pas encore été appliquées à la version principale. Avant de les appliquer, examinez le journal de la tâche, les résultats des tests et l’aperçu.

Si le résultat vous convient, appliquez les modifications à la version principale. Sinon, supprimez la tâche et démarrez-en une nouvelle.

<div id="applying">
  ## Application
</div>

L’étape **Applying (application en cours)** consiste à transférer les modifications vers la version principale. Lorsque vous appliquez les modifications de plusieurs tâches, Agent gère automatiquement les conflits.

Attendez la fin de l’application avant d’évaluer le résultat final. Si quelque chose semble anormal ensuite, demandez à Agent de le corriger dans le fil de discussion principal.

<div id="done">
  ## Done
</div>

Les tâches **Done(terminées)** sont achevées et ne nécessitent plus aucune action. Done peut indiquer qu’une tâche a été intégrée à la version principale, archivée avant son démarrage ou annulée après le début du build.

Utilisez la colonne **Done** pour conserver l’historique des tâches terminées, archivées ou annulées.

<div id="section-2">
  ## Archiver et annuler des tâches
</div>

Vous pouvez arrêter une tâche à n&#39;importe quel moment de son cycle de vie, mais les options proposées dépendent de l&#39;emplacement de la tâche sur le tableau. **Archive (Archiver)** et **Cancel (Annuler)** déplacent tous deux la tâche vers la colonne **Done**, mais leur fonctionnement diffère :

| Action                 | Disponible quand                                                                                                      | Ce qui se passe                                                                                                          | Est-ce réversible ?                                                                                           |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------- |
| **Archive (Archiver)** | Lorsque la tâche est encore une session de planification : un **Draft** dont le build n&#39;a pas démarré             | La session de planification est suspendue sans être exécutée. Le plan est conservé.                                      | Oui. Dans la colonne **Done**, vous pouvez ouvrir la carte archivée et la restaurer dans **Drafts**.          |
| **Cancel (Annuler)**   | Une fois que la tâche est passée de la planification au build : toutes les tâches **Active**, **Queued** et **Ready** | Agent arrête la tâche et abandonne le travail en cours. Aucune modification n&#39;est appliquée à la version principale. | Non. Une tâche annulée ne peut pas être restaurée. Si vous souhaitez la reprendre, lancez une nouvelle tâche. |

Utilisez **Archive** pour les sessions de planification que vous souhaitez réexaminer plus tard. Utilisez **Cancel** pour arrêter définitivement une tâche en attente, déjà en cours d&#39;exécution ou dont le build est terminé.

Les sessions de planification archivées comme les tâches annulées se retrouvent, avec les tâches terminées, dans la colonne **Done**, tout à droite du Task board.
