Replit AI Integrations упрощает создание приложений с искусственным интеллектом. Начните работу с моделями OpenAI, Anthropic, Google и OpenRouter прямо сейчас — без создания аккаунта разработчика и без управления API-ключами. Replit берёт всё на себя.

<div id="what-is-replit-ai-integrations">
  ## Что такое Replit AI Integrations?
</div>

Replit AI Integrations предоставляет управляемый доступ к моделям ИИ от ведущих провайдеров. Создавайте чат-приложения, генераторы контента и инструменты на базе ИИ, не покидая Replit. Не нужно заводить учетные записи разработчика во внешних сервисах, искать учетные данные API или оплачивать отдельные счета.

Когда вы используете Replit AI Integrations, Replit сам управляет учетными данными провайдера и выставляет счет по публичной цене API. Использование оплачивается кредитами Replit и отображается на [странице использования](/ru/billing/managing-spend) с разбивкой по существующим Replit App.

<Note>
  Для Replit AI Integrations требуется платный тарифный план (Core, Pro или Enterprise). Создавать ИИ-приложения с собственным ключом API можно и на [тарифе Starter](/ru/billing/plans/starter-plan). См. [Доступность в тарифных планах](#plan-availability).
</Note>

<div id="features">
  ## Возможности
</div>

Replit AI Integrations упрощает разработку с ИИ благодаря встроенному доступу и прозрачной тарификации:

* **Нулевая настройка**: чтобы начать, не нужны аккаунты разработчика или ключи API
* **Управляемые учётные данные**: Replit берёт на себя аутентификацию у провайдера и управление учётными данными
* **Прозрачная тарификация**: вы платите по публичным ценам API, а списание идёт с ваших кредитов Replit
* **Отслеживание использования**: смотрите расход по каждому существующему Replit App на странице использования
* **Поддержка любого стека**: работает со всеми языками программирования и фреймворками
* **BYOK по желанию**: используйте собственный ключ API, если предпочитаете работать со своими учётными данными

  ## Начало работы
</div>

<div id="using-replit-managed-credentials">
  ### Использование учётных данных, управляемых Replit
</div>

На платном тарифе, когда вы упоминаете в prompt функциональность ИИ или конкретных провайдеров (OpenAI, Anthropic, Google или OpenRouter), Agent по умолчанию использует Replit AI Integrations:

<AiPrompt>
  Создай веб-приложение, которое использует OpenAI для краткого пересказа статей
</AiPrompt>

Понять, какая интеграция используется, можно по надписи **«OpenAI (Replit managed)»**, **«Anthropic (Replit managed)»**, **«Google (Replit managed)»** или **«OpenRouter (Replit managed)»** в ответе на ваш первый prompt. Это значит, что Agent будет использовать учётные данные Replit и не потребует ваш собственный ключ API.

**Для первоначальной сборки**: когда вы отправляете первый prompt для создания нового приложения с функциональностью ИИ, Replit AI Integrations подбирается автоматически, и Agent сразу начинает сборку с управляемыми учётными данными Replit.

**Для существующих Replit App**: если Agent определит, что вы хотите добавить функциональность ИИ в существующий Replit App, он прямо сообщит вам в Project Editor, что запрашивает использование Replit AI Integrations вместо вашего собственного ключа API. Вы увидите запрос на подтверждение:

<Frame>
  <img src="/assets/mirror/replit-ai-integrations-confirmation-msg-9440681ad7d3.png" alt="Диалог подтверждения интеграции OpenAI с сообщением о добавлении OpenAI через управляемый сервис Replit без необходимости в ключах API, с кнопками Dismiss и Approve" width="924" height="294" data-path="images/replitai/replit-ai-integrations-confirmation-msg.png" />

Нажмите «Approve», чтобы продолжить с учётными данными, управляемыми Replit, или «Dismiss», если предпочитаете использовать собственный ключ API.

Ваше потребление автоматически отслеживается и списывается с вашего аккаунта Replit по публичной цене API.

<div id="bringing-your-own-api-key">
  ### Использование собственного ключа API
</div>

Если вместо Replit AI Integrations вы предпочитаете использовать собственные учётные данные OpenAI, Anthropic, Google или других провайдеров, у вас есть несколько вариантов:

**Для первоначальной сборки**: укажите в prompt, что хотите использовать собственный ключ API:

<AiPrompt>
  Создай веб-приложение, которое использует OpenAI для составления кратких изложений статей. Используй мой собственный ключ API OpenAI.
</AiPrompt>

В ответе вы увидите название провайдера (без пометки «Replit managed») — это значит, что Agent запросит ваш ключ API.

**Для существующих Replit App**: когда Agent сообщит, что хочет использовать Replit AI Integrations, и покажет запрос на подтверждение, нажмите «Dismiss», а не «Approve».

В обоих случаях Agent сначала дойдёт до первого checkpoint и только потом запросит ваш ключ API. Так Agent успевает создать структуру проекта, а затем делает паузу, чтобы получить ваши учётные данные.

При использовании собственного ключа API счёт выставляет напрямую провайдер, а оплата не списывается кредитами Replit.

<div id="supported-providers">
  ## Поддерживаемые провайдеры
</div>

Replit AI Integrations в настоящее время поддерживает:

* **OpenAI**: мультимодальные модели для генерации текста, рассуждений и работы со звуком. Поддерживаются chat completions, responses, генерация изображений, транскрибация аудио (`gpt-4o-transcribe`, `gpt-4o-mini-transcribe`) и аудиовывод (`gpt-audio`, `gpt-audio-mini`).
* **Anthropic**: мультимодальные модели для рассуждений, написания текстов и программирования. Поддерживаются Messages API и взаимодействие с веб-поиском.
* **Google (Gemini)**: мультимодальные модели для генерации текста и рассуждений. Поддерживается генерация текста и изображений.
* **OpenRouter**: доступ к моделям таких провайдеров, как Microsoft (серия Phi), Meta (серия Llama), Mistral, Qwen, DeepSeek, Nvidia, Amazon и другие.

<Note>
  Replit AI Integrations поддерживает **вывод текста, изображений и аудио**. Видеовывод не поддерживается. Если вам нужна генерация видео, потребуется использовать собственный ключ API от провайдера, который её предоставляет.
</Note>

<div id="openrouter-privacy-and-availability">
  ## Конфиденциальность и доступность OpenRouter
</div>

При использовании OpenRouter через Replit AI Integrations ваши запросы отправляются с особыми настройками конфиденциальности, которые защищают ваши данные. Эти настройки важно понимать, так как от них зависит, какие модели будут вам доступны.

<div id="privacy-settings-for-self-serve-users">
  ### Настройки конфиденциальности для пользователей с самостоятельным подключением
</div>

Для индивидуальных и командных пользователей Replit отправляет запросы в OpenRouter со следующими параметрами конфиденциальности по умолчанию:

* **Обучение на платных конечных точках отключено**: поставщики платных моделей не будут использовать ваши данные для обучения
* **Обучение на бесплатных конечных точках включено**: поставщики бесплатных моделей могут обучаться на ваших промптах и ответах модели
* **Публикация на бесплатных конечных точках включена**: поставщики бесплатных моделей могут публиковать ваши промпты и ответы модели в общедоступных наборах данных
* **Логирование ввода и вывода отключено**: OpenRouter не сохраняет ваши запросы и ответы ради скидки 1% на оплату
* **Аналитические файлы cookie отключены**: аналитические файлы cookie не используются

Эти настройки ставят конфиденциальность на первое место, но при этом открывают доступ к максимально широкому набору моделей. Тем не менее **некоторые модели могут быть недоступны**, если им требуются иные настройки конфиденциальности, чем указанные выше.

<div id="privacy-settings-for-enterprise">
  ### Настройки конфиденциальности для Enterprise
</div>

Для организаций Enterprise в Replit действуют более строгие правила конфиденциальности:

* **Только конечные точки с нулевым хранением данных (Zero Data Retention, ZDR)**: доступны только модели с политикой нулевого хранения данных
* Также действуют все настройки конфиденциальности, перечисленные выше для пользователей тарифов самообслуживания
* Благодаря этому запросы Enterprise направляются исключительно к конечным точкам, которые не сохраняют никаких данных

Поскольку в Enterprise используются только конечные точки ZDR, **набор доступных моделей будет более ограниченным**, чем у пользователей тарифов самообслуживания. Такой компромисс обеспечивает максимальный уровень конфиденциальности данных для корпоративных рабочих нагрузок.

<div id="plan-availability">
  ## Доступность в тарифах
</div>

Для работы Replit AI Integrations требуется платный тариф. Условия доступа зависят от вашего тарифа.

<div id="starter-free">
  ### Starter (Free)
</div>

На тарифе Starter функция Replit AI Integrations отключена. Вы по-прежнему можете создавать приложения с ИИ, используя собственный ключ API. См. раздел [Использование собственного ключа API](#bringing-your-own-api-key).

<div id="core">
  ### Core
</div>

На плане Core вы можете создавать ИИ-приложения с помощью Replit AI Integrations, используя учётные данные под управлением Replit, — ключи API вам не понадобятся.

<div id="pro-and-enterprise">
  ### Pro и Enterprise
</div>

Для организаций на планах Pro и Enterprise доступ к Replit AI Integrations по умолчанию отключён. Администраторы организации могут управлять доступом на странице настроек организации:

1. Перейдите в настройки организации
2. Найдите раздел Replit AI Integrations
3. Включите или отключите доступ для организации

Если доступ включён, участники организации могут использовать Replit AI Integrations в своих приложениях. Всё использование учитывается и оплачивается со счёта организации. Если доступ отключён, участникам потребуется указать собственные ключи API для работы с провайдерами моделей ИИ.

<div id="use-cases">
  ## Сценарии использования
</div>

Создавайте мощные ИИ-приложения на любом стеке:

* **Генерация контента**: краткий пересказ статей, создание описаний и текстов
* **Анализ и выводы**: извлечение ключевой информации, анализ тональности, классификация текста
* **Диалоговые интерфейсы**: создание чат-ботов и ИИ-ассистентов
* **Преобразование текста**: перевод, переписывание и форматирование контента
* **Помощь с кодом**: генерация фрагментов кода, объяснение алгоритмов, ревью кода
