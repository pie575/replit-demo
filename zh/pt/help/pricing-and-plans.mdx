这些回答涵盖套餐和定价。有关各套餐的完整详情，请参阅 [Starter](/zh/pt/billing/plans/starter-plan)、[Core](/zh/pt/billing/plans/replit-core) 和 [Pro](/zh/pt/billing/plans/replit-pro)，并查看[定价页面](https://replit.com/pricing)了解当前价格。

<AccordionGroup>
  <Accordion title="Agent 如何收费？为什么在规划模式下也会收费？">
    Free Mode 是 Core 和 Pro 订阅包含的一项权益，可在额度范围内免费使用 Agent。额度每五小时重置一次，并设有每周上限。请查看**设置 → 使用情况**了解您的使用量。它本身并非免费套餐，Starter 层级仍维持现有的限制。

    付费模式和已确认的付费工作会根据请求的复杂程度，采用[基于工作量的定价](/zh/pt/billing/ai-billing)。即使不修改代码，规划模式也可能在付费路径中进行可计费的推理。Replit 会在开始付费操作前要求您确认。

    日常工作可从 [Free Mode](/zh/pt/features/agent/agent-modes) 开始。需要以实惠价格获得更高能力时，请选择 [Power 模式](/zh/pt/features/agent/agent-modes)。您还可以通过[规划模式](/zh/pt/features/agent/plan-mode)界定工作范围，并在[管理您的支出](/zh/pt/billing/managing-spend)中设置使用量和预算上限。若要查看费用明细，请打开**设置 → 账户使用情况**，然后选择**查看以前的账单**。
  </Accordion>

  <Accordion title="Starter、Core 和 Pro 套餐分别包含哪些内容？">
    每种方案对应不同的开发阶段：

    * **Starter** 为免费方案，提供每日 Agent 配额和有限的每月云端积分、基础 Agent 使用权限，以及一个已发布的应用。参见 [Starter 方案](/zh/pt/billing/plans/starter-plan)。
    * **Core** 包含每月 {CoreCredits} 积分、具备规划与创建模式的完整 Agent、最多 5 位协作者、不限数量的已发布应用，以及 7 天的数据库恢复窗口。参见 [Core 方案](/zh/pt/billing/plans/replit-core)。
    * **Pro** ({ProPlanPrice}/月) 在此基础上新增 Turbo 模式、最多 15 位开发者共用共享积分、分级积分，以及 28 天的数据库恢复窗口。未使用的积分可结转 {ProCreditRolloverPeriod}。参见 [Pro 方案](/zh/pt/billing/plans/replit-pro)。

    如需查看各方案的横向对比和最新价格，请访问[定价页面](https://replit.com/pricing)。
  </Accordion>

  <Accordion title="Replit 是否为学生或教育机构提供优惠？">
    Replit 为学生和教育工作者提供教育计划。要了解当前的资格要求、折扣及申请方式，请访问 [replit.com/education](https://replit.com/education)。

    <Note>具体折扣金额和资格要求由教育计划决定，且可能会有所变动；请以教育页面的信息为准。</Note>
  </Accordion>

  <Accordion title="年度计费如何运作？我能节省多少？">
    按年订阅可享更低的实际月费，但需预付全年费用。[Core](/zh/pt/billing/plans/replit-core) 的年费为 {CoreAnnualPrice}。如需更改，请在订阅或变更套餐时选择年度选项。有关其他套餐及当前优惠，请查看[定价页面](https://replit.com/pricing)。
  </Accordion>

  <Accordion title="未使用的月度积分会结转到下个月吗？">
    这取决于您的套餐。Core 积分会在每个计费周期开始时重置，且不会累积。Pro 支持[积分结转](/zh/pt/billing/plans/replit-pro)：未使用的积分会在到期前结转 {ProCreditRolloverPeriod}。

    如果您的余额高于每月额度，超出部分可能是推荐积分或促销积分，它们各自有独立的到期日。
  </Accordion>

  <Accordion title="如何购买额外积分（积分包）？">
    积分包可在每月配额之外额外增加积分，且积分包越大折扣越多：

    <CreditPackTable />

    打开**设置 → 账户用量**，选择购买积分包。积分可用于 Agent 用量、部署、存储以及其他按用量计费的服务。详情请参阅[管理支出](/zh/pt/billing/managing-spend#purchase-credit-packs)。

    如果你是通过 App Store 订阅的，请先为账户添加一种网页端支付方式。
  </Accordion>

  <Accordion title="Core 或 Pro 是否提供免费试用？">
    Replit 不为付费套餐提供限时免费试用，但你可以通过以下方式先体验 Replit：

    * [Starter 套餐](/zh/pt/billing/plans/starter-plan)永久免费。
    * [教育计划](https://replit.com/education)为符合条件的学生提供优惠访问权限。

    如需了解现行订阅退款条款，请[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="如果我在计费周期中途升级，费用如何按比例计算？">
    如果您在计费周期中途更改套餐，Replit 会将当前套餐未使用部分的费用抵扣至新套餐费用。完成更改前，账单确认页面会显示确切的按比例金额，您可在扣费前查看。
  </Accordion>
</AccordionGroup>
