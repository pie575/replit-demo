Les suggestions sont au cœur de l&#39;interface de Replit Design. Plutôt que de vous retrouver devant une zone de prompt vide sans savoir quoi demander, vous sélectionnez un frame de design et Replit Design vous propose la prochaine piste à essayer. Chaque suggestion est à un clic de devenir une nouvelle génération.

<div id="como-as-sugestes-funcionam">
  ## Comment fonctionnent les suggestions
</div>

Lorsque vous sélectionnez un frame de design généré, des suggestions s’affichent à côté. Elles s’appuient sur ce que vous voyez : vous n’avez donc pas besoin de vocabulaire de design pour explorer. Cliquez sur l’une d’elles et Replit Design génère le résultat dans un nouveau frame ; l’original reste en place.

<div id="o-que-as-sugestes-propem">
  ## Ce que proposent les suggestions
</div>

Les suggestions répondent à différentes questions d&#39;exploration :

* **Un nouveau look** : le même design dans une autre direction, comme une variante éditoriale sombre ou une disposition différente.
* **Une extension** : une section ou une page que votre design appelle, mais qu&#39;il ne comporte pas encore, comme une section tarifs ou une page de contact.
* **Un nouveau contexte** : votre design ailleurs, par exemple dans une fenêtre d&#39;affichage mobile.

<div id="explore-com-sugestes">
  ## Explorez avec les suggestions
</div>

Le cycle est volontairement court :

<Steps>
  <Step title="Sélectionnez un frame généré">
    Cliquez sur n&#39;importe quel frame de Design généré sur le canvas.

    <Frame>
      <img src="/assets/mirror/ambient-select-frame-7147427722bd.png" alt="Un frame de Design intitulé APEX X1 Exact Replica affichant une page hero de supercar grise sur le canvas" width="2000" height="1252" data-path="images/design/replit-design/ambient-select-frame.png" />
    </Frame>
  </Step>

  <Step title="Choisissez une suggestion">
    Des suggestions apparaissent à côté du frame sélectionné, en fonction de ce que vous consultez. Parcourez-les et cliquez sur celle de votre choix ; vous n&#39;avez rien à ajouter.
  </Step>

  <Step title="Agent construit dès le clic">
    Dès que vous cliquez, Agent commence à construire la suggestion sous forme d&#39;un nouveau frame, à côté de l&#39;original. Vos frames précédents restent sur le canvas : rien ne se perd lorsque vous explorez.

    <Frame>
      <img src="/assets/mirror/ambient-suggestion-building-9da4835557d2.png" alt="Un nouveau frame de Design intitulé « Add Saturation on Scroll » en cours de rendu sous forme de mise en page squelette avec un indicateur Building…, à côté du frame original APEX X1" width="2000" height="1252" data-path="images/design/replit-design/ambient-suggestion-building.png" />
    </Frame>
  </Step>

  <Step title="Observez les changements">
    Le frame finalisé apparaît à côté de l&#39;original afin que vous puissiez les comparer côte à côte. Le panneau de chat résume ce qui a changé.

    <Frame>
      <img src="/assets/mirror/ambient-suggestion-result-a50d1efa94c4.png" alt="Deux frames de Design finalisés côte à côte sur le canvas, l'original APEX X1 Exact Replica et la variante terminée Add Saturation on Scroll, avec un résumé « Run complete » dans le panneau de chat" width="2000" height="1189" data-path="images/design/replit-design/ambient-suggestion-result.png" />
    </Frame>
  </Step>

  <Step title="Appliquez le design gagnant à votre app">
    Continuez à sélectionner et à ramifier jusqu&#39;à ce qu&#39;une direction vous convienne ; de nouvelles suggestions apparaissent pour chaque frame que vous sélectionnez. Le gagnant n&#39;est pas condamné à rester un simple mockup : sélectionnez-le, choisissez **Build…** dans la barre d&#39;actions, puis sélectionnez votre app existante sous **Apply to an existing creation**. Agent réécrit le code de l&#39;app pour qu&#39;il corresponde au design, et laisse le frame sur le canvas à titre de référence.

    <Frame caption="Le menu Build : appliquez le frame gagnant à une app que vous possédez déjà.">
      <img src="/assets/mirror/explore-variants-apply-b04b893252cd.png" alt="Le menu Build ouvert sur une variante sélectionnée avec deux options : « Build this design », qui crée un nouvel artefact, et « Apply to an existing creation » listant l'artefact Website du projet" width="2000" height="1226" data-path="images/design/replit-design/explore-variants-apply.png" />
    </Frame>

    Consultez [Construisez votre design](/fr/pt/design/build-your-design) pour le flux complet, y compris la construction du frame en tant que nouvelle app. Pour peaufiner les détails avant d&#39;appliquer, [affinez avec le chat](/fr/pt/design/chat-about-your-design).
  </Step>
</Steps>

<div id="dicas">
  ## Astuces
</div>

* **Explorez par directions, pas par étapes.** Les suggestions se ramifient ; en suivre une ne vous engage à rien. Générez-en plusieurs et comparez-les sur le Canvas.
* **Combinez-les avec vos propres mots.** Les suggestions et la [zone de Chat de Design](/fr/pt/design/chat-about-your-design) fonctionnent de pair : cliquez sur les suggestions pour explorer largement, et discutez pour orienter avec précision. Le Chat ne sert pas qu&#39;à peaufiner ; un message comme *« essaie le menu de navigation à gauche »* ouvre lui aussi une nouvelle direction.
* **Changez de modèle pour une autre sensibilité.** Chaque modèle explore à sa manière ; consultez [Explorer avec différents modèles](/fr/pt/design/explore-with-different-models).
