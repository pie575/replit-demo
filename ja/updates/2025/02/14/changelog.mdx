## プラットフォームの更新

### モバイル開発

<Frame>
  <img src="/assets/mirror/expo-ios-f28c40825d7e.gif" width="1200" height="650" data-path="images/changelog/2025-02-14/expo-ios.gif" />

React NativeとExpoのサポートにより、ReplitでiOSとAndroid Appを直接構築・テストできるようになりました。

これには以下が含まれます：

* iOSおよびAndroid開発機能の強化
* 統合されたモバイルプレビューとデバッグツール
* Expo EASによるApp Storeデプロイメントの効率化

はじめるには[チュートリアル](https://www.youtube.com/playlist?list=PLto9KpJAqHMRuHwQ9OUjkVgZ69efpvslM)をご覧ください。

### ソーシャルコーディングチャレンジ

最新のチャレンジでは { SocialContestPrizePool } の賞金プールが用意されています！

Replitはエキサイティングなチャレンジとあらゆるスキルレベルの開発者向けの豪華賞品でTikTokを席巻しています。

参加するには[replit.com/contest](https://replit.com/contest)をご覧ください。

### Agentの更新

AgentとAssistantはパフォーマンスと信頼性の内部最適化により継続的に改善されています。

スタック選択の改善と、最新のOpenAI推論モデルのサポートが含まれます。
