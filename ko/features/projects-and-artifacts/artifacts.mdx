## 아티팩트란 무엇인가요?

아티팩트는 Replit에서 게시할 수 있는 결과물로, 웹 앱, 모바일 앱, 슬라이드 덱, 애니메이션, 데이터 앱, 3D 게임, 디자인 등이 포함됩니다. 각 아티팩트는 완전하고 독립적인 결과물이며, 게시하면 자체 공유 가능한 URL을 갖게 됩니다.

프로젝트 내의 다른 모든 것 — 파일, 이미지, CSV, 코드 — 은 아티팩트를 지원하지만 그 자체로는 게시할 수 없습니다.

## 시작하기

Replit 홈페이지에서 만드는 방법은 두 가지입니다.

* **설명하기**: 원하는 것을 입력하세요 — "레시피 앱을 만들어줘" 또는 "내 스타트업을 위한 피치 덱을 만들어줘." Agent가 어떤 유형이 적합한지 파악하고 만들어 줍니다.
* **유형 선택하기**: 아이디어를 설명하기 전에 원하는 아티팩트 — 웹 앱, 모바일 앱, 데이터 시각화, 애니메이션, 3D 게임, 또는 기타 지원되는 유형 — 를 선택하세요.

언제든지 채팅에서 Agent에게 요청하거나 프리뷰 패널의 **+** 버튼을 클릭해 기존 프로젝트에 더 많은 것을 추가할 수 있습니다.

## 아티팩트 간 전환하기

프로젝트에 여러 개의 아티팩트가 있으면 **프리뷰 패널**이나 **라이브러리 사이드바**에서 서로 전환할 수 있습니다. "모바일 앱 보여줘"나 "슬라이드로 전환해줘"처럼 Agent에게 요청할 수도 있습니다.

### 라이브러리 사이드바

라이브러리 사이드바는 프로젝트 내의 모든 항목을 둘러볼 수 있는 중앙 공간을 제공합니다. 아티팩트, Agent가 생성하거나 다운로드한 이미지, 그리고 기타 프로젝트 자산을 보여줍니다. 왼쪽 패널에서 라이브러리 사이드바를 열어 프로젝트 전체에서 자산을 찾고 재사용하세요.

## 하나의 프로젝트에 여러 아티팩트

하나의 프로젝트는 최대 **7개의 아티팩트**를 가질 수 있으며, 프로젝트당 **모바일 앱은 최대 1개**로 제한됩니다. 예를 들어 고객을 위한 웹 앱, 팀을 위한 모바일 앱, 투자자를 위한 슬라이드 덱을 모두 같은 프로젝트 안에 만들 수 있습니다.

<ArtifactGrid />

### 프로젝트에 아티팩트 추가하기

기존 프로젝트에 아티팩트를 추가하는 방법은 세 가지입니다.

* **채팅**: Agent에게 요청하세요 — "이 프로젝트에 모바일 앱을 추가해줘" 또는 "투자자 피치용 슬라이드 덱을 만들어줘"
* **더하기 버튼**: 프리뷰 패널의 **+** 버튼을 클릭하고 만들고 싶은 것을 선택하세요
* **라이브러리 사이드바**: 기존 아티팩트, 이미지, 기타 자산을 둘러보고 여기서 새로운 아티팩트를 추가하세요

### 공유되는 데이터와 백엔드

아티팩트가 같은 프로젝트 안에 있으면 자동으로 동일한 데이터와 백엔드 로직을 공유합니다. 고객이 웹 앱을 통해 주문하면 모바일 앱과 데이터 대시보드에서도 그 주문을 볼 수 있습니다. 별도의 연결을 설정하거나 코드를 중복할 필요 없이 그냥 동작합니다.

<Note>
  게시하면 프로젝트 전체가 한 번에 라이브로 전환됩니다. 모든 아티팩트가 함께 게시되므로 항상 서로 동기화된 상태를 유지합니다.
</Note>

### 조합 예시

* **웹 앱 + 모바일 앱**: 고객용 웹 앱과 직원용 모바일 앱을 모두 갖춘 레스토랑 — 둘 다 같은 API와 데이터베이스에 연결됩니다
* **앱 + 관리자 대시보드**: 콘텐츠, 사용자, 설정을 관리하는 내부 관리자 패널과 함께 있는 주력 제품
* **앱 + 슬라이드 덱**: 같은 프로젝트에 있는 제품과 피치 덱, 슬라이드가 항상 최신 버전을 반영합니다
* **데이터 대시보드 + 영상**: 하이라이트를 설명하는 애니메이션 영상과 함께 제공되는 실시간 데이터 시각화

## 게시

앱, 슬라이드, 영상은 모두 게시하고 공유할 수 있습니다. 게시하면 각각 자체 공유 가능한 URL을 갖게 됩니다.

아티팩트가 아닌 파일과 자산(CSV, 이미지, 마크다운 파일 등)은 그 자체로는 게시할 수 없습니다. 이를 공유하려면 앱에 추가하거나 새로운 아티팩트를 만드세요.

  네. 프로젝트 내의 모든 아티팩트는 동일한 데이터베이스와 백엔드 서비스를 공유합니다. 웹 앱이 데이터를 기록하면 모바일 앱과 데이터 대시보드에서 즉시 읽을 수 있습니다.
</Accordion>

<Accordion title="아티팩트와 파일의 차이는 무엇인가요?">
  아티팩트는 게시할 수 있는 것 — 앱, 슬라이드, 영상입니다. 파일(CSV, 이미지, 코드 등)은 프로젝트 내에서 아티팩트를 지원하는 자산이지만 그 자체로는 게시할 수 없습니다.
</Accordion>

<Accordion title="모바일 앱에 웹 앱의 일부 기능이 빠져 있어요. 어떻게 된 건가요?">
  Agent가 아티팩트 유형 간에 기능을 변환할 때 일부 요소는 완벽하게 옮겨지지 않을 수 있습니다. 특히 플랫폼마다 다르게 동작하는 상호작용이나 레이아웃이 그렇습니다. 채팅에서 후속 요청을 통해 빠진 부분을 채울 수 있습니다.
</Accordion>
