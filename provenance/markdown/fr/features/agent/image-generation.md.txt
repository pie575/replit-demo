La génération d'images permet aux créateurs de produire du contenu visuel unique sans avoir besoin de compétences en design ou d'outils externes. Générez de tout, des icônes et illustrations aux arrière-plans et éléments d'interface directement dans votre flux de travail de développement.

## Fonctionnalités

Construisez des applications visuellement attrayantes avec la génération d'images d'Agent. Cela élimine le besoin de photos de stock, d'outils de design externes ou de faire appel à des designers pour le contenu visuel de base. Que vous créiez un site web portfolio, construisiez un jeu ou conceviez une interface d'application mobile, la génération d'images fournit des visuels personnalisés adaptés à votre projet.

Agent peut effectuer les actions de génération d'images suivantes :

* **Création d'images personnalisées** : Générez des images basées sur des descriptions et spécifications détaillées
* **Adaptation de style** : Créez des images dans différents styles artistiques, du réaliste au dessin animé
* **Arrière-plans transparents** : Générez des images en PNG transparent, ou supprimez l'arrière-plan d'une image existante — idéal pour les logos, icônes, autocollants et découpes de produits
* **Intégration au projet** : Ajoutez de façon transparente les images générées directement à la base de code de votre application
* **Affinement itératif** : Modifiez et améliorez les images en fonction de vos retours

## Utilisation

La génération d'images est intégrée à Agent — il n'y a rien à activer. Ouvrez n'importe quelle application Replit avec Agent activé et demandez à Agent de créer le contenu visuel dont vous avez besoin. Agent détermine automatiquement quand générer des images en fonction de vos demandes, créant des images personnalisées qui correspondent à vos spécifications.

### Quand Agent utilise la génération d'images

Agent déclenche la génération d'images lorsque vous demandez du contenu visuel pour vos projets :

| Cas d'utilisation                 | Exemple de prompt                                                         |
| --------------------------------- | ------------------------------------------------------------------------- |
| **Icônes et logos d'application** | « Génère un logo moderne pour mon application de suivi de fitness »       |
| **Arrière-plans de site web**     | « Crée un arrière-plan dégradé subtil pour mon site portfolio »           |
| **Ressources de jeu**             | « Génère des sprites pixel art pour mon jeu de plateforme »               |
| **Illustrations d'interface**     | « Crée une illustration pour l'écran vide de mon application »            |
| **Visuels marketing**             | « Génère une image hero pour ma page d'atterrissage »                     |
| **Maquettes de produit**          | « Crée des images maquettes de mon application sur différents appareils » |
| **Logos et icônes transparents**  | « Génère un logo pour mon application avec un arrière-plan transparent »  |

### Meilleures pratiques pour la génération d'images

Suivez ces directives pour obtenir les meilleurs résultats de la génération d'images d'Agent :

**Soyez précis et descriptif**

* Incluez des détails sur le style, les couleurs, la composition et l'ambiance
* Précisez les dimensions ou les rapports d'aspect si pertinent
* Mentionnez l'utilisation prévue (icône, arrière-plan, illustration, etc.)
* Demandez un arrière-plan transparent lorsque vous avez besoin d'un logo, d'une icône, d'un autocollant ou d'une découpe à superposer sur d'autres contenus

**Itérez et affinez**

* Commencez par une description basique et affinez-la en fonction des résultats
* Demandez à Agent de modifier des aspects spécifiques des images générées
* Demandez des variations pour explorer différentes directions créatives

**Tenez compte du style de votre projet**

* Maintenez une cohérence visuelle dans votre application
* Précisez les préférences de style qui correspondent à votre marque ou système de design
* Demandez des images qui complètent vos éléments visuels existants

Essayez ces exemples de prompts pour commencer avec la génération d'images :

<AiPrompt>
  Génère une icône propre et moderne pour mon application de gestion de tâches.
  L'icône doit être circulaire avec un arrière-plan dégradé du bleu au violet,
  avec un symbole de coche simple en blanc.
  Rends-la adaptée à une utilisation comme icône d'application.
</AiPrompt>

<AiPrompt>
  Crée une illustration hero pour mon site web de tutoriels de codage.
  Montre un personnage de dessin animé sympathique assis devant un ordinateur avec du code à l'écran.
  Utilise une palette de couleurs chaude avec des bleus et des oranges.
  Le style doit être accessible et encourageant pour les débutants.
</AiPrompt>

<AiPrompt>
  Génère un ensemble d'ennemis pixel art pour mon jeu de plateforme rétro.
  J'ai besoin d'une chauve-souris volante, d'un champignon marchant et d'un slime sautant.
  Chacun devrait être de 32x32 pixels avec une palette de couleurs limitée à 8 couleurs.
  Rends-les mignons mais légèrement menaçants.
</AiPrompt>

### Intégration au projet

Agent intègre de façon transparente les images générées dans votre base de code :

* **Création automatique de fichiers** : Les images générées sont sauvegardées directement dans les fichiers de votre projet
* **Mises à jour du code** : Agent met à jour votre code pour référencer les nouveaux fichiers d'images
* **Organisation des ressources** : Les images sont placées dans des répertoires logiques au sein de la structure de votre projet

Ce flux de travail simplifié vous permet de générer et d'implémenter du contenu visuel sans quitter votre environnement de développement.

<Note>
  La génération d'images de Replit est alimentée par [Imagen 4 de Google](https://deepmind.google/models/imagen/), un modèle de texte vers image de pointe qui excelle dans la création d'images de haute qualité et photoréalistes avec des détails fins et des capacités de rendu de texte améliorées.
</Note>
