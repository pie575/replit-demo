<div id="security-agent-reviews-your-whole-codebase">
  ### Security Agent가 codebase 전체를 검토합니다
</div>

**Security Agent**는 dependencies뿐 아니라 project 전체를 audit하는 새로운 AI 기반 검토 도구입니다. 위협 모델을 구성하고 라우트와 데이터 흐름을 매핑하며, Semgrep과 HoundDog.ai로 정적 분석을 실행한 뒤, LLM으로 앱의 context에서 실제로 악용될 수 있는 findings가 무엇인지 판단합니다. 검토가 끝나면 Security Agent는 채택된 findings를 병렬 task로 정리해 Replit Agent가 한 번에 수정할 수 있도록 합니다.

<Frame>
  <img src="/assets/mirror/security-agent-findings-b425392bb98a.png" alt="Project Security Center의 Security pane에서 완료된 스캔 결과가 severity별로 정리된 다섯 개의 findings와 각각 'Ready for review' 또는 'Ready for republish' 같은 status를 보여주고, 아래에는 취약한 packages를 나열한 자동 dependency 스캔 섹션이 표시된 화면" width="1438" height="808" data-path="images/changelog/2026-04-24/security-agent-findings.png" />
</Frame>

Security Agent는 모든 유료 builders가 사용할 수 있습니다. project에서 **Security** pane을 열고 **Run Scan with Agent**를 선택해 사용해 보세요.

[Security Agent](/ko/core-concepts/security/project-security-center#agent-security-scans)에 대해 자세히 알아보세요.

<div id="cve-auto-protect-patches-critical-vulnerabilities-automatically">
  ### CVE Auto-Protect가 치명적인 취약점을 자동으로 패치합니다
</div>

앱이 의존하는 package에서 새로운 치명적 CVE가 공개되면 **CVE Auto-Protect**가 사용자가 소유한 모든 project에서 해당 항목을 찾아내고, Agent가 백그라운드 task로 패치를 준비한 뒤 테스트를 실행해 문제가 없는지 확인하고, 검토 링크와 함께 알림을 보냅니다. 결정 권한은 항상 사용자에게 있습니다. 수정 사항을 승인하기 전까지는 아무것도 게시되지 않습니다.

따라서 직접 알아차릴 때까지 기다릴 필요 없이, 새로운 취약점이 공개된 지 몇 분 만에 앱을 패치할 수 있습니다.

[CVE Auto-Protect](/ko/core-concepts/security/project-security-center#auto-protect)에 대해 자세히 알아보세요.

<div id="preview-on-an-ios-simulator-or-android-emulator">
  ### iOS Simulator 또는 Android Emulator에서 미리 보기
</div>

<Frame>
  <video autoPlay muted loop playsInline src="/assets/mirror/ios-emulator-9013ff1b602f.mp4" />
</Frame>

project에 mobile app이 포함되어 있으면 이제 미리 보기 패널에서 실제 **iOS Simulator** 또는 **Android Emulator**를 workspace로 바로 스트리밍할 수 있습니다. Xcode도, Android Studio도, 실제 기기도 필요 없습니다. Agent로 mobile app을 만든 뒤 미리 보기 패널의 드롭다운에서 기기를 선택하고, 손에 휴대폰을 들고 있는 것처럼 화면을 탭해 보세요. Agent가 수정한 내용은 시뮬레이터에 바로 반영됩니다.

Core, Pro, Enterprise plan의 유료 builders가 Chrome, Safari 및 Chromium 기반 브라우저에서 사용할 수 있습니다. Firefox는 모바일 시뮬레이터를 지원하지 않습니다.

[시뮬레이터 또는 에뮬레이터에서 미리 보기](/ko/features/artifact-types/building-mobile-apps#preview-on-a-simulator-or-emulator)에 대해 자세히 알아보세요.

  ### 기존 project에 mobile app 추가하기
</div>

<Frame>
  <img src="/assets/mirror/multi-artifact-update-approval-f6fa8b70a100.png" alt="5달러 크레딧 offer와 나중에 하기 / project 업데이트 버튼이 있는 'Update project to create mobile app' 승인 카드가 표시된 Agent chat 패널." width="991" height="589" data-path="images/replitai/multi-artifact-update-approval.png" />

Agent 4 출시 이전에 만든 project도 이제 여러 artifact를 지원하도록 업데이트할 수 있습니다. 즉, artifact를 하나만 지원하던 project에 mobile app이나 pitch deck 같은 artifact를 추가할 수 있습니다. Agent가 project를 재구성하는 동안에도 URL, 데이터, secret, deployment는 그대로 유지됩니다. 정식 출시 후 첫 48시간 동안 200개가 넘는 project가 마이그레이션되었습니다.

[여러 artifact 지원을 위한 기존 project 업데이트](/ko/features/projects-and-artifacts/updating-projects-for-multiple-artifacts)에 대해 자세히 알아보세요.

<div id="plaid-connector-is-live">
  ### Plaid connector 출시
</div>

이제 **Plaid** connector로 12,000개 이상의 금융 기관에 연결할 수 있습니다. 팀 관리자가 **Integrations**에서 자격 증명을 한 번만 구성해 두면, 앱 사용자는 Plaid Link를 통해 각자의 은행 계좌를 인증합니다. 액세스 token은 사용자별로 scope가 지정되므로 데이터는 비공개로 유지됩니다.

실제 거래 데이터를 활용하는 개인 재무 코치, 증권 계좌와 연동된 실시간 포트폴리오 트래커 등을 만들어 보세요. 데모와 설정 방법은 [Replit x Plaid 파트너 페이지](https://replit.com/partners/plaid)에서 확인하세요.

[connector 관리](/ko/replitai/managing-connectors)에 대해 자세히 알아보세요.
