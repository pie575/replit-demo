---
title: "Mode vocal"
description: "Dictez vos prompts à Agent au lieu de les saisir. Le mode vocal transcrit ce que vous dites dans la zone de Chat pour que vous puissiez le relire et l'envoyer."
---

Décrivez à voix haute ce que vous souhaitez créer grâce au mode vocal. Appuyez sur le microphone dans la zone de Chat d&#39;Agent, énoncez votre prompt : Replit transcrit alors votre voix en texte modifiable. Relisez-le, apportez les modifications nécessaires et envoyez-le comme n&#39;importe quel autre message.

Le mode vocal est utile lorsque la saisie est lente ou peu pratique, en particulier sur mobile, où dicter un prompt complet est souvent plus rapide que de le taper avec les pouces.

<Note>
  Le mode vocal transforme votre voix en texte dans la zone de Chat. Il ne lit pas les réponses d&#39;Agent à voix haute : vous envoyez toujours un message écrit, et Agent répond dans le Chat comme d&#39;habitude.
</Note>

  ## Fonctionnement
</div>

Le mode vocal enregistre votre voix, la transcrit et insère le résultat dans la zone de chat pour que vous puissiez le relire avant de l&#39;envoyer :

1. Ouvrez l&#39;Agent et sélectionnez le microphone dans la zone de chat.
2. Autorisez l&#39;accès au microphone si votre navigateur ou votre appareil le demande.
3. Énoncez votre prompt. Une forme d&#39;onde indique que l&#39;Agent est en train d&#39;enregistrer.
4. Arrêtez l&#39;enregistrement lorsque vous avez terminé. L&#39;enregistrement s&#39;arrête aussi automatiquement après une pause ou lorsque vous changez d&#39;onglet.
5. Patientez quelques instants, le temps que votre voix soit transcrite.
6. Relisez le texte transcrit, modifiez-le si nécessaire et envoyez votre message.

Comme la transcription apparaît sous forme de texte ordinaire dans la zone de chat, vous pouvez mêler librement voix et saisie au clavier : dictez une partie d&#39;un prompt, puis tapez le reste, ou corrigez un mot avant l&#39;envoi.

<Tip>
  Parlez naturellement. Le mode vocal cherche à capter ce que vous voulez dire plutôt qu&#39;à transcrire chaque mot littéralement : les mots parasites comme « euh » et « bah » sont donc écartés du résultat.
</Tip>

<div id="onde-voc-pode-usar">
  ## Où l&#39;utiliser
</div>

Le mode vocal est disponible dans la zone de Chat d&#39;Agent :

* Dans l&#39;**éditeur de projets**, lorsque vous travaillez avec Agent sur une app.
* Lorsque vous **créez une nouvelle app** à partir du prompt d&#39;Agent sur l&#39;écran d&#39;accueil.

Vous pouvez utiliser le mode vocal sur le web depuis un ordinateur, sur le web depuis un mobile et dans l&#39;application mobile Replit.

<div id="bom-saber">
  ## Bon à savoir
</div>

Gardez ces détails à l&#39;esprit lorsque vous utilisez le mode vocal :

| Détail                      | À quoi s&#39;attendre                                                                                                                                                                                          |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Durée d&#39;enregistrement  | Enregistrez jusqu&#39;à 6 minutes à la fois. Un avertissement s&#39;affiche peu avant la limite.                                                                                                               |
| Arrêt automatique           | L&#39;enregistrement s&#39;arrête de lui-même après environ 30 secondes de silence, ou lorsque vous changez d&#39;onglet ou basculez l&#39;application en arrière-plan.                                        |
| Relecture avant l&#39;envoi | Le texte transcrit s&#39;affiche dans la zone de Chat afin que vous puissiez le lire et le modifier avant de l&#39;envoyer — rien n&#39;est envoyé automatiquement.                                            |
| Accès au microphone         | Le mode vocal nécessite l&#39;autorisation d&#39;utiliser votre microphone. Si l&#39;enregistrement ne démarre pas, vérifiez que votre navigateur et votre appareil autorisent Replit à accéder au microphone. |

<div id="disponibilidade">
  ## Disponibilité
</div>

Le mode vocal est disponible avec tous les forfaits Replit. Le micro apparaît dans la zone de Chat d&#39;Agent sur les navigateurs et appareils compatibles avec l&#39;enregistrement audio, et une autorisation d&#39;accès au microphone vous sera demandée lors de votre premier enregistrement.
