O Replit Agent se conecta a ferramentas e fontes de dados externas através do [Model Context Protocol (MCP)](https://modelcontextprotocol.io), um padrão aberto para integrações de IA. Cada servidor abaixo se instala com um único clique — o Agent então carrega automaticamente suas ferramentas e as usa quando apropriado.

Para o conceito, veja [Model Context Protocol](/fr/pt/learn/model-context-protocol). Para o guia prático, veja [Se connecter via MCP](/fr/pt/build/connect-via-mcp). Para conectar um servidor que não está listado aqui, veja [Ajouter un serveur MCP personnalisé](/fr/pt/build/connect-via-mcp#add-a-custom-mcp-server).

<Info>
  Selecione **Add to Replit** para instalar qualquer servidor. Você será solicitado a autorizar a conexão no Editor de Projeto.
</Info>

<div id="protees-de-segurana">
  ## Protections de sécurité
</div>

Tout le trafic MCP passe par le scanner de sécurité de Replit. Celui-ci analyse les définitions d&#39;outils et les exécutions prévues, et bloque les outils suspects ou non sécurisés avant leur exécution. Si un outil est rejeté, l&#39;Agent vous en informe.

<div id="opes-de-autenticao">
  ## Options d&#39;authentification
</div>

* **Enregistrement dynamique de client OAuth** — si le serveur prend en charge OAuth DCR, Replit détecte et enregistre automatiquement le client à votre place. La plupart des serveurs préréférencés utilisent ce flux.
* **En-têtes personnalisés** — définissez une ou plusieurs paires nom/valeur d&#39;en-tête (par exemple, `X-API-Key`). Replit inclut ces en-têtes dans chaque requête MCP afin que votre serveur puisse vérifier l&#39;identité de l&#39;appelant. Utilisez cette option lorsque vous ajoutez un serveur personnalisé qui s&#39;authentifie à l&#39;aide de jetons statiques.

<div id="compartilhe-seu-prprio-link-de-instalao">
  ## Partagez votre propre lien d&#39;installation
</div>

Les liens d&#39;installation ajoutent votre serveur MCP à Replit en un seul clic. Générez-en un à l&#39;aide du formulaire de la page [Se connecter via MCP](/fr/pt/build/connect-via-mcp#share-an-install-link), ou créez le vôtre : encodez une charge utile JSON en base64, puis ajoutez-la à `https://replit.com/integrations?mcp=`.

```json theme={null}
{
  "displayName": "My MCP Server",
  "baseUrl": "https://example.com/mcp",
  "headers": [{ "key": "Authorization", "value": "Bearer your-token" }]
}
```

* **displayName** — le nom affiché lors de l&#39;installation
* **baseUrl** — le point de terminaison HTTPS de votre serveur MCP
* **headers** — les en-têtes d&#39;authentification facultatifs
