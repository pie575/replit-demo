Темы в Replit позволяют настроить внешний вид редактора проекта — от цветов фона и элементов интерфейса до подсветки синтаксиса вашего кода. Настройте среду разработки под себя, чтобы улучшить читаемость, снизить нагрузку на глаза и сделать программирование более комфортным.

<div id="criando-um-tema-personalizado">
  ## Создание собственной темы
</div>

Выполните следующие шаги, чтобы создать и настроить собственную тему:

1. Откройте [Настройки](https://replit.com/settings) и перейдите в раздел **Пользователь** → **Персонализация** (или раздел **Themes**)
2. Выберите **Создать новую тему**
3. Введите название, выберите цветовую схему (светлую или тёмную) и при желании добавьте описание
4. Выберите **Создать тему**, чтобы открыть редактор тем

Глобальные настройки темы отвечают за общий вид интерфейса:

* **Background**: задаёт основной цвет большинства поверхностей интерфейса
* **Outline**: определяет цвет границ и разделителей
* **Foreground**: определяет цвет текста и значков
* **Primary**: задаёт цвет кнопок и интерактивных элементов
* **Positive**: применяется к индикаторам успеха, например к кнопке **Run**
* **Negative**: используется для ошибок и предупреждений о необратимых действиях

Выберите **Применить тему**, чтобы сразу начать пользоваться своей темой.

<div id="realce-de-sintaxe">
  ## Подсветка синтаксиса
</div>

Настройте внешний вид различных элементов кода, чтобы улучшить читаемость и понимание.

<Tip>
  Грамотная подсветка синтаксиса позволяет быстрее просматривать и понимать код. Выбирайте цвета, которые хорошо сочетаются друг с другом и дают достаточный контраст с фоном.
</Tip>

<Accordion title="Элементы подсветки синтаксиса">
  | Элемент                  | Описание                                                                               |
  | ------------------------ | -------------------------------------------------------------------------------------- |
  | **Variable Names**       | Применяется к переменным, объявленным без ключевого слова                              |
  | **Variable Definitions** | Окрашивает имена переменных при объявлении с ключевыми словами вроде `const` или `var` |
  | **Function References**  | Применяется при вызове функций                                                         |
  | **Function Definitions** | Окрашивает имена функций при объявлении                                                |
  | **Keywords**             | Выделяет ключевые слова языка, такие как `import`, `function` и `return`               |
  | **Property Names**       | Окрашивает обращение к свойствам переменных                                            |
  | **Property Definitions** | Используется при определении свойств объектов                                          |
  | **Function Properties**  | Применяется при вызове методов объектов                                                |
  | **Tag Names**            | Используется для тегов HTML и JSX                                                      |
  | **Type Names**           | Окрашивает аннотации типов в типизированных языках                                     |
  | **Class Names**          | Применяется к объявлениям классов и ссылкам на них                                     |
  | **Attribute Names**      | Выделяет атрибуты HTML и JSX                                                           |
  | **Comments**             | Применяется ко всем комментариям в коде                                                |
  | **Strings**              | Окрашивает строковые литералы                                                          |
  | **Numbers**              | Выделяет числовые значения                                                             |
  | **Booleans**             | Форматирует логические значения (`true`/`false`)                                       |
  | **Regular Expressions**  | Окрашивает шаблоны регулярных выражений                                                |
  | **Operators**            | Выделяет операторы, такие как `+`, `-`, `*` и `/`                                      |
  | **Brackets**             | Окрашивает скобки и угловые скобки там, где это уместно                                |
</Accordion>

<div id="boas-prticas-de-design-de-temas">
  ## Рекомендации по оформлению тем
</div>

Создавайте визуально привлекательные и удобные темы, следуя этим рекомендациям:

<div id="cor-e-contraste">
  ### Цвет и контраст
</div>

* **Соблюдайте баланс контраста**: обеспечьте достаточную разницу между фоном и элементами переднего плана
* **Создавайте гармоничные палитры**: выбирайте цвета, которые дополняют друг друга, а не конфликтуют
* **Поддерживайте единообразную яркость**: сохраняйте схожий уровень яркости у элементов синтаксиса
* **Проектируйте с учётом доступности**: помните о пользователях с нарушениями зрения и избегайте низкоконтрастных сочетаний

<Warning>
  Распространённые ошибки при оформлении тем, которых стоит избегать:

  * чрезмерная разница в яркости между элементами синтаксиса;
  * плохо сочетающиеся цвета, создающие визуальный диссонанс;
  * недостаточный контраст между кодом и фоном.
</Warning>

<div id="gerenciando-seus-temas">
  ## Управление темами
</div>

Просматривайте и настраивайте все установленные темы в [Настройках](https://replit.com/settings), в разделе **Пользователь** → **Персонализация** (или **Themes**).

<div id="alternando-entre-temas">
  ### Переключение между темами
</div>

Нажмите кнопку рядом с названием темы, чтобы сделать её текущей.

<div id="editando-temas">
  ### Редактирование тем
</div>

Чтобы изменить свою пользовательскую тему, откройте меню с тремя точками и нажмите **Редактировать**.

<Note>
  Редактировать и удалять можно только те пользовательские темы, которые вы создали сами. Стандартные темы и темы, созданные другими пользователями, изменить нельзя.
</Note>

<div id="excluindo-temas">
  ### Удаление тем
</div>

Чтобы удалить пользовательскую тему, откройте меню с тремя точками и выберите **Удалить**.

<div id="explorando-temas-da-comunidade">
  ## Обзор тем сообщества
</div>

Откройте для себя темы, созданные сообществом Replit, на [странице тем](https://replit.com/themes).

<div id="encontrando-temas">
  ### Поиск тем
</div>

* Ищите по названию, чтобы найти конкретную тему, например «Atom One Dark»
* Фильтруйте по автору, чтобы посмотреть темы определённых создателей
* Просматривайте темы по цветовой схеме, чтобы выбрать светлую или тёмную
* Ищите по конкретным цветам, чтобы подобрать тему под свои предпочтения

Перед установкой можно предварительно просмотреть любую тему и увидеть, как она будет выглядеть в редакторе проекта.

<div id="publicando-seu-tema">
  ## Публикация темы
</div>

Поделитесь своими пользовательскими темами с сообществом Replit, выполнив следующие шаги:

1. Откройте редактор тем для своей пользовательской темы
2. Нажмите кнопку **Опубликовать**
3. Заполните поля названия и описания
4. Отправьте тему

После публикации ваша тема появится на странице тем, где другие пользователи смогут её просмотреть и установить.
