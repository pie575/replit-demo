<div id="section">
  ## Шаблоны фреймворков для разработчиков больше не доступны
</div>

Стартовые шаблоны для языков и фреймворков (ранее называвшиеся фреймворками для разработчиков) больше не доступны в Replit. Страницы `replit.com/templates` и `replit.com/developer-frameworks` теперь перенаправляют в [Галерею Replit](https://replit.com/gallery).

Чтобы начать новый проект, воспользуйтесь одним из следующих способов:

* **Начните с Replit Agent** — опишите на [главной странице](https://replit.com/), что вы хотите создать, и Agent подготовит основу проекта.
* **[Импортируйте из GitHub, GitLab или Bitbucket](/ru/ko/build/import-from-providers)** — импортируйте существующую кодовую базу или стартовый стек в новое Replit App.
* **[Создайте ремикс опубликованного приложения](https://replit.com/gallery)** — просмотрите Галерею Replit, найдите приложения сообщества, которые можно использовать в качестве отправной точки, и создайте их ремикс.

<div id="section-2">
  ## Пользовательские шаблоны Enterprise
</div>

Организации Enterprise могут создавать [пользовательские шаблоны](/ru/ko/teams/custom-templates), которые будут доступны в поле ввода Agent всем участникам организации. Пользовательские шаблоны расширяют возможности фреймворков для разработчиков: они могут содержать уникальные для вашей компании инструкции для Agent, навыки и предварительно настроенный контекст проекта. Подробнее см. в [руководстве по пользовательским шаблонам](/ru/ko/teams/custom-templates).
