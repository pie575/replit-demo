### Azure Marketplace 통합

Replit이 이제 Azure Marketplace에 출시되었습니다! 많은 조직이 이미 Azure에 전용 예산을 보유하고 있으며, 이 통합을 통해 해당 예산을 Replit 구독 및 사용에 직접 활용할 수 있습니다.

9월의 GCP Marketplace 통합에 이어, 이번 추가로 엔터프라이즈 팀이 기존의 클라우드 조달 프로세스와 예산을 사용하여 Replit을 더욱 쉽게 도입할 수 있게 되었습니다.

[Azure Marketplace에서 보기](https://marketplace.microsoft.com/en-us/product/saas/replit.replit?tab=Overview)

### GitLab 및 Bitbucket 지원

Replit이 이제 GitHub에 더해 GitLab 및 Bitbucket 저장소를 지원하여 코드를 저장하는 위치에 대한 유연성이 높아졌습니다. GitLab 및 Bitbucket에서 Replit으로 직접 프로젝트를 가져올 수 있으며, 지원되는 모든 플랫폼에서 향상된 git 기능을 사용할 수 있습니다.

향상된 git 통합에는 다음이 포함됩니다:

* **멀티 플랫폼 지원**: GitHub, GitLab, Bitbucket의 저장소 가져오기 및 작업
* **향상된 git 작업**: 작업공간 전반에서 더 빠르고 안정적인 git 명령
* **더 나은 저장소 관리**: 지원되는 모든 git 제공업체에서 클론, 푸시, 풀을 위한 간소화된 워크플로

[프로젝트 가져오기](/references/workspace/import) 및 [Replit에서 git 사용하기](/references/version-control/git-interface)에 대해 자세히 알아보세요.
