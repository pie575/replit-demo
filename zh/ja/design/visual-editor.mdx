<div id="section">
  ## 什么是可视化编辑器？
</div>

使用可视化编辑器，你可以直接点击元素，手动修改界面。它可在 Replit Design 的 [Canvas](/zh/ja/design/canvas) 和 Preview 中使用，因此你可以用相同的方式编辑设计稿和正在运行的应用。

更改文本、调整颜色、微调间距等简单编辑会直接更新源代码，且不消耗 AI 积分。对于涉及更复杂的底层复杂性的更改，可视化编辑器会自动交由 Agent 处理。

核心概念：

* **确定性编辑**：简单更改 (文本、颜色、间距) 会直接应用到源代码，无需经过 Agent 的处理流程
* **无需消耗积分**：直接编辑不会消耗 AI 积分 — 只有复杂更改才会交由 Agent 处理
* **双重上下文**：在 Canvas 上的画框和 Preview 中均可采用相同方式操作
* **源代码同步**：所有编辑都会即时更新底层源代码

<Note>
  可视化编辑器目前仅在**网页浏览器**中可用，暂不支持移动应用和桌面应用。
</Note>

<div id="section-2">
  ## 使用可视化编辑器
</div>

<div id="section-3">
  ### 在 Canvas 上编辑
</div>

在工具栏中选择 **Edit** 工具，然后点击画框中的任意元素。该元素会高亮显示，并带有显示其名称的标签；右侧会打开可视化编辑器面板，显示可编辑的属性，例如内容、布局、颜色和边框。调整数值后，选择 **Save edits** 应用更改，或选择 **Discard** 放弃更改。

<Frame caption="可视化编辑器中已启用 Edit 工具并选中按钮，同时显示其可编辑属性。">
  <img src="/assets/mirror/visual-editor-edit-tool-71d03803471f.png" alt="在超级跑车配置器画框中，Edit 工具已启用且元素已选中。右侧显示可视化编辑器面板，其中包含 Layout（Outer space 和 Inner space）、Color（Text、Background、Opacity）和 Border（颜色、粗细、圆角）部分，以及 Discard 和 Save edits 按钮" width="2000" height="1250" data-path="images/replitai/visual-editor-edit-tool.png" />

显示的属性会因所选元素而异。文本元素会显示字体控件，图片会显示图片来源和上传选项，容器会显示布局控件。

<div id="preview">
  ### 在 Preview 中编辑
</div>

同样的编辑体验也适用于正在运行的应用。

<Steps>
  <Step title="选择元素">
    点击 Preview 中的任意元素，即可开始编辑。
  </Step>

  <Step title="编辑">
    直接编辑文本、使用颜色选择器调整颜色、通过样式控件更改间距，或替换图片。
  </Step>

  <Step title="保存">
    选择“保存”以更新源代码。简单的更改会直接应用，无需消耗 AI 积分。如果编辑较复杂，可视化编辑器会将目标元数据发送给 Agent 以寻求帮助。
  </Step>
</Steps>

<div id="section-4">
  ### 编辑文本
</div>

点击任意文本元素后，直接输入即可修改。如果文本对应源代码中的字符串，编辑会立即生效。

<div id="section-5">
  ### 调整颜色
</div>

使用颜色选择器调整文本和背景颜色。你可以在输入框中输入颜色名称 (如“purple”) ，也可以使用吸管工具从屏幕上的任意位置选取颜色。

<div id="section-6">
  ### 修改样式
</div>

使用直观的控件调整元素的整体内边距、外边距和布局。

<div id="section-7">
  ### 布局控件
</div>

可视化编辑器将所有控件归类到清晰易懂的分区中，帮助您更快找到所需功能：**Text**、**Layout**、**Color**、**Border**。 (选择图像元素时，还会显示 **Image** 分区。)

**Layout** 分区可让您无需借助 Agent，直接调整容器中子元素的排列方式。选择弹性容器并展开 Layout 后，您会看到以下内容：

* **Alignment**：一个 3×3 点阵选择器，用于指定项目在容器两个轴向上的位置。
* **Direction**：两个箭头按钮，用于将子元素排列为行或列。
* **Gap**：以像素值设置项目之间的间距。Gap 输入框旁的图标会随当前方向变化，因此您始终能知道调整的是水平还是垂直间距。旁边的箭头图标可切换 **Distribute space between items**，将子元素分布到容器两端。
* **Outer space**：用于分别设置元素各边外部间距的输入框 (每边一个输入框，以及可同时锁定四边的关联切换开关) 。
* **Inner space**：用于设置元素在各轴向上内部间距的输入框，并配有可同时锁定两个轴的关联切换开关。

仅当所选元素至少应用了一个布局控件时，才会显示 Layout 分区。对于没有间距或布局属性的纯文本节点，此分区会完全隐藏，让编辑器保持紧凑。

<div id="section-8">
  ### 更新图片
</div>

选择图片并替换其 URL，或上传自己的文件以即时预览。

<div id="section-9">
  ## 可以做什么
</div>

* **快速修改文案**：无需打开源文件，即可更新文案、标签和标题
* **探索配色**：只需点击调整，即可尝试不同的配色方案，无需查找合适的 CSS
* **微调布局**：无需猜测像素值，可直观地精细调整内边距、外边距和间距
* **替换图片**：只需点击上传，即可将占位图片替换为真实资源
* **迭代设计**：无需与 Agent 反复沟通，即可快速调整 Canvas 上的画框，并比较不同的视觉方向

<div id="section-10">
  ## 常见问题
</div>

<Accordion title="可视化编辑器的更改会消耗 AI 积分吗？">
  简单、确定性编辑——例如修改文本、选择颜色或调整间距——不会消耗 AI 积分，因为这些更改会直接更新源代码。如果可视化编辑器检测到底层复杂性，更改会通过 Agent 处理并消耗积分。
</Accordion>

<Accordion title="可以编辑在多个位置显示的元素吗？">
  可以。选择在循环中渲染或在多个组件中重复使用的元素时，所有实例都会被突出显示并同时更新。
</Accordion>

<Accordion title="为什么无法编辑某些元素的文本？">
  由多个子元素组成的复合元素无法在可视化编辑器中直接编辑文本。请改为在聊天中让 Agent 进行更改。
</Accordion>

<Accordion title="如何找到元素的源代码？">
  点击所选元素左上角的标签，即可跳转到源代码中的相应位置。
</Accordion>
