# 정보 보안

> Replit의 보안 관행, 데이터 보호 및 컴플라이언스 표준에 대해 알아보세요

Replit은 전 세계 수백만 명의 개발자가 사용하는 AI 기반 클라우드 개발 환경을 제공합니다. 보안은 플랫폼의 근본이며, 사용자가 여러 기기와 플랫폼에서 자신 있게 구축, 협업, 애플리케이션을 게시할 수 있도록 보장합니다.

## 데이터 보호

데이터 보호는 Replit의 최우선 사항입니다. 저희는 데이터를 보호하고 플랫폼의 무결성을 보장하기 위해 포괄적인 보안 조치를 시행합니다.

### 호스팅 및 인프라

Replit은 주로 미국에 있는 Google Cloud Platform(GCP) 데이터 센터에 데이터를 호스팅하며, 인도를 선택한 사용자를 위한 선택적 호스팅 지역을 제공합니다. 저희는 GCP의 엔터프라이즈급 백업 및 복구 도구를 활용하여 다음을 보장합니다:

<CardGroup cols={2}>
  <Card title="고가용성" icon="server">
    중복 시스템과 자동화된 장애 조치 메커니즘으로 서비스 중단 및 데이터 손실 방지
  </Card>

  <Card title="데이터 격리" icon="layer-group">
    강력한 논리적 분리로 서로 다른 사용자와 조직 간의 무단 접근 방지
  </Card>
</CardGroup>

GCP는 **ISO 27001** 및 **SOC 2 Type 2** 인증을 받은 업계 선도적인 클라우드 제공업체입니다. 또한 **Replit은 SOC 2 Type 2 컴플라이언스 인증을 획득**하여 보안 모범 사례 및 제어에 대한 지속적인 의지를 보여주고 있습니다.

모든 클라이언트 요청은 개인 정보에 접근하기 전에 엄격하게 **인증 및 승인**을 받아야 합니다.

### 암호화 표준

<Note>
  Replit은 모든 데이터 상태에 걸쳐 포괄적인 암호화를 구현하여 정보의 기밀성, 무결성 및 보안을 보장합니다.
</Note>

<AccordionGroup>
  <Accordion title="전송 암호화" icon="shield-halved">
    업계 표준 **TLS 1.2+** 암호화로 클라이언트와 서버 간의 모든 통신을 보호하여 네트워크를 통해 이동하는 데이터를 보호합니다. 여기에는 모든 API 호출, 웹 트래픽, 실시간 협업 데이터 및 기타 통신이 포함됩니다.
  </Accordion>

  <Accordion title="저장 데이터" icon="database">
    GCP에 저장된 데이터는 [**AES-256 서버 측 암호화**](https://cloud.google.com/docs/security/encryption/default-encryption)로 보호됩니다. 이 군사급 암호화 표준은 코드, 구성, 사용자 정보 및 시스템 메타데이터를 포함한 모든 저장 데이터를 보호합니다.
  </Accordion>

  <Accordion title="데이터베이스 보안" icon="lock">
    [데이터베이스 암호화](https://cloud.google.com/sql/references/additional-resources/faq#encryption-manage-rest) 및 [보안 키 관리](https://cloud.google.com/secret-manager)를 위해 **Google Cloud SQL**을 사용하여 자동 암호화, 정기적인 키 교체 및 세분화된 접근 제어로 민감한 데이터를 보호합니다.
  </Accordion>
</AccordionGroup>

## 인프라 보안

모든 데이터 처리 구성 요소는 다음으로 보호되는 안전한 클라우드 환경 내 Replit의 **프라이빗 네트워크**에서 작동합니다:

<CardGroup cols={3}>
  <Card title="로드 밸런싱" icon="server">
    최적의 성능과 안정성을 위한 지능적인 트래픽 분산
  </Card>

  <Card title="WAF 보호" icon="shield">
    악성 트래픽과 정교한 공격을 방지하는 고급 웹 애플리케이션 방화벽
  </Card>

  <Card title="공급업체 보안" icon="user-check">
    정기적인 보안 평가 및 모니터링을 통한 엄격한 하위 처리자 표준
  </Card>
</CardGroup>

저희는 모든 하위 처리자에 대해 철저한 **실사**를 수행하여 엄격한 보안 표준 및 컴플라이언스 요구 사항을 충족하는지 확인합니다.

## 추가 리소스

보안 정책, 인증 및 모범 사례에 대한 자세한 정보는 [**신뢰 센터**](http://trust.replit.com)를 방문하세요.

Replit에서 보안은 단순한 요구 사항이 아니라 탁월한 개발자 경험을 제공하는 핵심 요소입니다. 엄격한 보안 표준을 유지함으로써 개인과 팀이 완전한 신뢰를 갖고 구축할 수 있도록 지원합니다.
