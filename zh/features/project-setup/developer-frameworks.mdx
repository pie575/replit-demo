<div id="developer-framework-templates-have-been-removed">
  ## 开发者框架模板已下线
</div>

语言和框架的入门模板 (此前称为 开发者框架) 在 Replit 上已不再提供。`replit.com/templates` 和 `replit.com/developer-frameworks` 页面现在会重定向至 [Replit Gallery](https://replit.com/gallery)。

如需创建新 project，请改用以下方式之一：

* **从 Replit Agent 开始** — 在[主页](https://replit.com/)描述你想构建的内容，让 Agent 为你搭建 project 的基础结构。
* **[从 GitHub、GitLab 或 Bitbucket 导入](/zh/build/import-from-providers)** — 将已有代码库或入门技术栈导入为新的 Replit App。
* **[Remix 已发布的应用](https://replit.com/gallery)** — 在 Replit Gallery 中浏览社区应用，查看并 Remix 它们作为起点。

<div id="enterprise-custom-templates">
  ## Enterprise 自定义模板
</div>

Enterprise 组织可以创建[自定义模板](/zh/teams/custom-templates)，供所有组织成员在 Agent 输入框中直接选用。自定义模板不止于 开发者框架，还可加入公司专属的 Agent 指令、skills 和预先配置的 project 上下文。详情请参阅[自定义模板指南](/zh/teams/custom-templates)。
