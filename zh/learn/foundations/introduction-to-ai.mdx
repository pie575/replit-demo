AI 工具可让你用自然语言下达指令，并获得有用的输出。在 Replit 上，这些输出可以转化为计划、代码、设计、说明、调试步骤，以及对项目的修改。

在开始构建前，你无需深入了解 AI。掌握几个基本概念，就能帮助你给出更好的指令，并更有信心地评估结果。

<div id="large-language-models">
  ## 大型语言模型
</div>

大多数 AI 构建工具都由大型语言模型驱动，通常简称为 LLM。LLM 是经过训练的模型，能够识别文本中的模式，并生成符合这些模式的文本。

文本可以是文章、代码、HTML、CSS、SQL、JSON、终端命令、测试输出、错误信息或配置内容。因此，同一种模型既能帮助撰写文案、解释错误，也能生成代码或总结计划。

<div id="text-generation">
  ## 文本生成
</div>

LLM 不会从数据库中检索固定答案，而是根据你提供的输入和它能看到的上下文，逐步生成回复。

当你编写 提示词 时，模型会利用你的文字、对话以及可用的项目背景，预测下一条有用的回复。该回复可能是说明、计划，或供其他系统执行操作的文本。

这意味着输入质量至关重要。清晰的目标、示例、约束和上下文，都能提高获得良好结果的可能性。

<div id="tokens">
  ## Token
</div>

AI 模型以称为 token 的小单位处理文本。一个 token 可以是一个词、词的一部分、标点符号、空白字符或一段代码。

Token 很重要，因为它们会影响 AI 模型一次能处理多少信息。长对话、大型文件、日志、截图和指令都会构成模型进行推理所依据的上下文。

构建时，你无需计算 token。但你需要了解：重要信息越清晰、越及时、越聚焦，Agent 的表现就越好。

<div id="ai-can-vary">
  ## AI 输出可能有所不同
</div>

AI 的输出并不总是完全一致。同一个请求可能会产生不同的措辞、设计、实现细节或权衡取舍。

这种差异有助于探索，但也意味着你应该审查重要工作。测试 Agent 构建的内容，遇到不清楚的地方及时要求解释，并在需要安全恢复点时使用 checkpoint。

<div id="what-makes-ai-output-better">
  ## 如何获得更好的 AI 输出
</div>

提供以下信息时，Agent 的表现最佳：

* 明确的目标
* 目标受众或用户需求
* 约束条件和非目标
* 示例、截图、文件、数据或链接
* 当前问题或具体错误
* 对“完成”标准的验收条件

比较以下两个提示词：

* *“为一个网站编写代码。”*
* *“为一个网站编写代码，用于收集我的个人邮件列表的电子邮件地址。将提交内容存储在 Google Sheets 中。”*

第二个提示词明确了目标、数据和存储位置，因此 Agent 无需猜测即可执行。

这些信息称为上下文。要了解上下文为何重要，请参阅[上下文管理](/zh/learn/foundations/context-management)。

<div id="from-ai-to-ai-agents">
  ## 从 AI 到 AI 智能体
</div>

聊天模型可以回复消息。AI 智能体则使用模型和工具执行多步骤工作：它能够围绕目标进行推理、选择工具、查看信息、做出修改、检查结果，并持续推进，直到 task 完成或需要你提供输入。

<div id="models-and-tools">
  ### 模型和工具
</div>

一个 智能体 包含两个重要部分：

| 组成部分     | 功能                                                 |
| -------- | -------------------------------------------------- |
| **语言模型** | 理解指令、生成文本、权衡各种选项，并决定下一步该做什么。                       |
| **工具**   | 让 智能体 能够执行操作，例如读取文件、编辑代码、运行命令、搜索文档、测试 App 或发布更改。 |

模型决定哪些操作可能会有帮助，工具则让 智能体 根据该决定采取行动。

<div id="what-agents-can-do">
  ### 智能体 能做什么
</div>

智能体 适合处理需要多个步骤才能完成的工作，例如：

* 规划功能
* 创建文件和代码
* 了解现有项目结构
* 运行命令或测试
* 调试错误
* 更新设计
* 连接服务
* 总结变更内容

智能体 不只是回答问题；它会执行一项 task。

<div id="replit-agent">
  ### Replit Agent
</div>

Replit Agent 是一款可帮助你在 Replit 上进行开发的 AI 智能体。它可以帮助你创建应用和其他 产物、检查项目、编辑文件、运行命令、测试功能、解释代码、创建 task，并引导你完成 Publishing 流程。

例如，你可以让 Agent：

```text theme={null}
为社区聚会构建一个简单的活动报名应用。
访客应能查看活动详情、提交姓名和电子邮件，并收到确认消息。
请将第一个版本保持简单，以便我今天可以发布。
```

Agent 可以将该请求转化为一个项目，创建初版，并帮助您不断完善。

<div id="you-still-lead-the-work">
  ### 你仍然主导工作
</div>

Agent 可以快速推进，但重要决策仍由你来做：

* 产物 应实现哪些功能
* 面向哪些用户
* 哪些内容应纳入范围
* 哪些内容不应更改
* 结果是否符合预期
* 何时可以发布

这就是为什么上下文管理和审查如此重要。为 Agent 提供清晰的方向并测试结果，才能充分发挥它的能力。

<div id="common-misconceptions">
  ## 常见误区
</div>

* **“AI 应该知道我的意思。”** AI 只能根据你提供的信息工作。如果某件事很重要，请明确说明。
* **“第一个回答就应该是最终结果。”** 借助 AI 构建是一个迭代过程。请审查、测试并不断完善。
* **“AI 像人一样理解意图。”** AI 可以识别模式，但不会自动了解你的偏好、受众、限制条件或你对“完成”的定义。
* **“智能体只是聊天机器人。”** 聊天机器人主要负责回应。智能体可以使用工具并采取行动。
* **“Agent 会自动了解整个产品目标。”** Agent 会根据你的指令和上下文工作。如果某件事很重要，请将其纳入指令。
* **“Agent 不需要审查。”** Agent 可以构建，但是否符合你的意图由你决定。
