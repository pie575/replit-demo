<div id="databricks">
  ### Intégration des applications Databricks
</div>

Les créateurs Enterprise peuvent désormais créer des applications exploitant leurs données sur Replit et les déployer directement sur Databricks. Agent se connecte à l&#39;environnement Databricks et peut consulter les schémas de données sans que celles-ci ne sortent de Databricks. Une fois l&#39;application prête, vous pouvez la publier directement sur Databricks Apps. L&#39;application en cours d&#39;exécution est entièrement hébergée sur Databricks et hérite de l&#39;authentification Databricks, de la gouvernance Unity Catalog et des restrictions réseau existantes.

<Frame>
  <img src="/assets/mirror/databricks-app-template-333354ec6944.png" alt="Workspace Replit avec le modèle d'application Databricks sélectionné dans le menu déroulant des modèles" width="1368" height="395" data-path="images/changelog/2026-04-10/databricks-app-template.png" />
</Frame>

Cette intégration est disponible pour les organisations Enterprise disposant d&#39;un espace de travail Databricks. Pour en savoir plus, consultez la [page du partenariat Replit x Databricks](https://replit.com/partners/databricks).

  ## Agent
</div>

<div id="ui">
  ### Reproduire une UI à partir d&#39;une capture d&#39;écran
</div>

Vous pouvez coller une capture d&#39;écran dans Agent et lui demander « construis ceci » ou « reproduis cette UI ». Qu&#39;il s&#39;agisse d&#39;une application web ou d&#39;une présentation, Agent restitue le design avec une grande fidélité en une seule passe. Pratique pour dupliquer un design existant, reconstruire une UI de référence ou prototyper rapidement à partir d&#39;une maquette.

<div id="connectors">
  ### Connectors est disponible avec tous les forfaits payants
</div>

Les créateurs disposant d’un forfait Core ou Pro peuvent désormais accéder à tous les Connectors directement depuis leur espace de travail.

Pour en savoir plus, consultez [la gestion des Connectors](/fr/ja/replitai/managing-connectors).

<div id="razorpay">
  ### Paiements Razorpay en Inde
</div>

Les créateurs en Inde peuvent désormais accepter les paiements par UPI et par carte avec Razorpay. Cette fonctionnalité inclut la prise en charge des mandats électroniques pour les abonnements récurrents, conformément aux exigences de la Banque de réserve de l’Inde. Les abonnés existants en Inde pourront bientôt passer de Stripe à Razorpay depuis la page de facturation.

<div id="revenuecatapp-store-connect">
  ### Synchronisation de RevenueCat avec App Store Connect
</div>

L&#39;intégration RevenueCat prend désormais en charge la synchronisation automatique avec Apple. Lorsque vous configurez des achats intégrés dans RevenueCat, ces paramètres sont directement synchronisés avec App Store Connect.

Pour en savoir plus, consultez la page [Abonnements RevenueCat](/fr/core-concepts/monetization/revenuecat-subscriptions).

<div id="section-4">
  ### Choisir l&#39;emplacement d&#39;exécution de votre application avec les zones géographiques de publication
</div>

Les créateurs Core, Pro et Enterprise peuvent désormais choisir la région dans laquelle publier leur application. Lorsque vous publiez dans une région, tous les artefacts de calcul, de base de données et d&#39;Object Storage y sont hébergés. Des proxys propres à chaque région réduisent la latence pour les visiteurs de votre application.

L&#39;Europe s&#39;ajoute désormais à l&#39;Amérique du Nord, et l&#39;Australie, l&#39;Amérique du Sud et l&#39;Asie arriveront prochainement. Les administrateurs Enterprise peuvent également restreindre leur organisation à une seule région à des fins de conformité.

<div id="section-5">
  ### Afficher les factures précédentes sur la page d’utilisation
</div>

Vous pouvez désormais consulter directement vos anciennes factures depuis la page **Utilisation** des paramètres de votre compte. Sélectionnez une période de facturation antérieure dans le menu déroulant pour afficher une répartition détaillée de la consommation par application.
