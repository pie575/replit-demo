Shopify connector를 사용하면 Agent가 Shopify store를 프로비저닝하고, 그에 맞는 맞춤형 storefront를 만들고, products와 inventory까지 관리합니다. 이 모든 작업이 하나의 conversation 안에서 API key 없이 이루어집니다. 실물 상품을 판매한다고 설명하면 Agent가 Shopify를 추천하며, Shopify에 직접 접속할 일은 go live할 때뿐입니다. 첫 prompt부터 실제 주문까지 약 10분이면 됩니다.

<Note>
  단계별 안내는 [Shopify storefront 만들기](/ko/build/ecommerce-store)를 참고하세요.
</Note>

<div id="what-you-can-build">
  ## 만들 수 있는 것
</div>

* 실물 상품을 위한 맞춤 디자인 storefront
* 브랜드 굿즈 및 의류 store
* 장바구니와 checkout을 갖춘 소비자 직접 판매(D2C) shop
* Shopify store와 연동되는 카탈로그 및 inventory 도구
* 단일 hero 상품을 판매하는 제품 landing page

<div id="what-agent-manages">
  ## Agent가 관리하는 항목
</div>

storefront와 카탈로그의 모든 요소는 Chat으로 편집할 수 있습니다.

| 영역               | Agent가 하는 일                                                                                                                                                                                                                                |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Design           | 사용자의 지시에 따라 헤드리스 프런트엔드를 생성합니다(Liquid 테마 불필요, template 라이브러리 불필요). 문구, layout, 내비게이션, 모션, 제품 페이지를 Chat으로 편집할 수 있고, [Canvas](/ko/design/canvas) 변형으로 여러 direction을 탐색할 수 있습니다. 실제 Replit project이므로 블로그, 위시리스트, landing page 등을 추가해 확장할 수 있습니다. |
| Products         | products와 변형을 생성, 수정, 삭제합니다. 필드: 제목, 설명, type, vendor, 태그, SKU, 가격, 무게, 옵션(사이즈, color), 이미지, 판매 가능 여부.                                                                                                                                     |
| Inventory        | 변형별 재고를 설정하고 조정합니다.                                                                                                                                                                                                                        |
| Collections      | products를 컬렉션으로 묶습니다.                                                                                                                                                                                                                      |
| Discounts        | 가격 규칙과 사용 가능한 할인 코드를 생성합니다.                                                                                                                                                                                                                |
| Publishing 및 동기화 | 새 products는 storefront에 자동으로 게시됩니다. 동기화는 양방향으로 이루어집니다. Shopify admin에서 편집한 내용은 Replit Preview에 반영되고, Agent가 적용한 changes는 Shopify admin에 나타납니다.                                                                                             |

<div id="replit-and-shopify-who-does-what">
  ## Replit과 Shopify: 각자의 역할
</div>

| Replit 담당                                 | Shopify 담당                                  |
| ----------------------------------------- | ------------------------------------------- |
| storefront 디자인 및 빌드                       | 호스팅형 checkout                               |
| Chat을 통한 카탈로그 관리(products, inventory, 할인) | products, inventory, 장바구니, 주문의 기록 시스템       |
| storefront 호스팅 및 deployment               | payments, identity verification(KYC), 대금 지급 |
| Canvas 디자인 변형                             | 세금, 배송, 주문 이행                               |
| 앱 확장(블로그, landing page 등)                 | 멀티채널 판매                                     |

주문, 환불, 대금 지급, 주문 이행은 Agent가 아닌 Shopify admin에서 처리합니다.

<div id="connection-scope">
  ## 연결 범위
</div>

* 모든 builder가 모든 앱에서 사용할 수 있으며, conversation 안에서 바로 연결되므로 Connectors 패널 설정이나 자격 증명이 필요 없습니다.
* 범위는 앱 하나로 한정됩니다. 즉, 앱마다 별도의 Shopify store가 생성됩니다.
* 해당 store는 사용자가 claim하기 전까지 Replit 소유의 development store입니다. 나중에 claim할 수 있도록 사용자의 이메일이 Shopify에 공유됩니다.
* Shopify admin에서 언제든지 Replit 앱을 제거할 수 있습니다.

<div id="go-live-on-shopify">
  ## Shopify에서 Go live 하기
</div>

Go live는 Replit이 아닌 Shopify에서 진행됩니다. Agent에게 Go Live flow를 시작해 달라고 요청한 다음, Shopify admin에서 판매자가 직접 처리해야 하는 아래 단계를 완료하세요.

* Chat에 표시된 링크 또는 Shopify가 보낸 이메일을 통해 **store를 claim**하세요. 링크는 7일 후 만료됩니다. claim하면 무료 trial이 시작됩니다.
* **plan 선택**: 실제 주문을 처리하려면 [paid plan](https://www.shopify.com/pricing)이 필요합니다.
* **payments 설정**: [Shopify Payments](https://help.shopify.com/en/manual/payments/shopify-payments) 또는 다른 provider를 활성화하고 identity verification(KYC)을 완료하세요. claim한 Account가 KYC를 마쳐야 실제 결제 승인이 이루어집니다.
* **[배송](https://help.shopify.com/en/manual/shipping) 및 [세금](https://help.shopify.com/en/manual/taxes) 설정하기.**
* **[custom domain](/ko/build/add-custom-domain) 연결**(선택 사항) 후 storefront 비밀번호를 해제해 구매자에게 store를 공개하세요.

Checkout은 항상 Shopify가 호스팅하는 checkout으로 리디렉션되므로 구매자는 Shopify에서 결제합니다.

<Note>
  payments, identity verification, 세금, 배송, 사기 검사는 모두 Shopify에서 처리됩니다. Replit은 판매자의 은행 정보, 세금 식별번호를 비롯한 민감한 정보를 일절 수집하지 않습니다.
</Note>

<div id="troubleshooting">
  ## 문제 해결
</div>

<AccordionGroup>
  <Accordion title="Shopify store 설정에 시간이 오래 걸립니다">
    provisioning 과정에서 여러 Shopify API를 호출하기 때문에 다소 시간이 걸릴 수 있습니다. storefront 구축을 요청하기 전에 Agent가 설정을 마칠 때까지 기다려 주세요.
  </Accordion>

  <Accordion title="개발 중 checkout에서 비밀번호 페이지가 표시됩니다">
    development store는 go live 전까지 password-protected 상태이므로 checkout previews에서 비밀번호 페이지가 나타날 수 있습니다. 정상적인 동작이며 장바구니는 그대로 작동합니다. Shopify의 비밀번호는 launch 시점에만 제거하세요.
  </Accordion>

  <Accordion title="checkout에서 실제 결제가 완료되지 않습니다">
    실제 결제를 받으려면 store를 claim한 Shopify Account에서 payments 설정과 KYC를 완료해야 합니다. 그전까지는 checkout이 Shopify로 리디렉션되더라도 결제를 처리할 수 없습니다. KYC를 완료하거나, payments 설정이 이미 완료된 Account를 사용하세요.
  </Accordion>

  <Accordion title="이 App에 Shopify가 연결되지 않았다고 Agent가 말합니다">
    각 store는 하나의 App에만 연결됩니다. 다른 App에서 Shopify를 연결했다면, 현재 App에 Shopify store를 설정해 달라고 Agent에게 요청하세요.
  </Accordion>

  <Accordion title="storefront에 products가 표시되지 않습니다">
    product는 Active 상태이면서 게시되어야만 표시됩니다. Agent는 자신이 생성한 products를 자동으로 게시합니다. 누락된 항목이 있다면 Agent에게 게시를 요청한 뒤 Preview를 새로 고치세요.
  </Accordion>

  <Accordion title="이전 후 연결을 다시 설정해야 합니다">
    store를 claim하거나 이전한 뒤에는 Shopify가 연결 재승인을 요청할 수 있습니다. Agent에게 Shopify 재연결을 요청하면 store를 잃지 않고 접근 권한이 복구됩니다.
  </Accordion>
</AccordionGroup>
