<div id="preview-empty-state-improvements">
  ### Preview 빈 상태 개선
</div>

Agent 애플리케이션의 Preview가 이제 빈 상태와 자동 실행을 더 지능적으로 처리하여, Agent로 빌드할 때 한층 매끄러운 작업 흐름을 제공합니다.

<div id="ai-latency-improvements">
  ### AI latency improvements
</div>

인프라 개선을 통해 Replit AI의 응답 시간과 지연 시간이 크게 줄었습니다. Agent와 Assistant를 비롯해 Replit 전반의 AI 기반 기능을 사용할 때 한층 빨라진 반응 속도를 체감할 수 있습니다.

<div id="unified-github-tab-refresh">
  ### 통합 GitHub tab 개편
</div>

GitHub 연동 tab이 더 깔끔하고 일관된 인터페이스로 새단장했습니다. 개편된 디자인으로 Workspace 안에서 GitHub 저장소를 연결하고 관리하는 과정이 한층 직관적으로 바뀌었습니다.

<div id="ios-app-payment-support">
  ### iOS 앱 결제 지원
</div>

이제 iOS 사용자는 Replit Mobile App에서 바로 Replit Core를 구매하고 결제 수단을 설정할 수 있습니다. 덕분에 이동 중에도 프리미엄 기능을 더 쉽게 이용할 수 있습니다.

<div id="stripe-checkout-release">
  ### Stripe Checkout 출시
</div>

새로운 Stripe Checkout 연동으로 모든 개발자가 더 매끄럽고 안전한 결제 경험을 누릴 수 있습니다. 업계 표준 결제 솔루션을 통해 구매 과정이 간소화되어 Replit Core로 손쉽게 업그레이드할 수 있습니다.

  ## Teams 및 Enterprise
</div>

<div id="scim-provisioning-streamlined">
  ### SCIM 프로비저닝 간소화
</div>

SCIM 계정 provisioning flow가 개선되어 Enterprise 사용자 온보딩이 훨씬 수월해졌습니다. 새 사용자는 별도의 수동 작업 없이 자동으로 설정되므로, Replit에서 성장하는 Enterprise Teams는 번거로움 없는 경험을 누릴 수 있습니다.
