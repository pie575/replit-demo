使用 Replit Agent 制作专业级动画视频。用日常语言描述你想要的视频，Agent 就会生成可导出、可分享的 motion graphics——无需视频剪辑技能，也无需花大价钱请制作公司。

<div id="viso-geral">
  ## 概述
</div>

Replit 动画让你完全通过与 Agent 对话来创作精美的 motion graphics。这些是用 React 制作的程序化动画——并未使用 Remotion，而是由多个网页动画库与 Agent 的自定义技能共同实现。它不同于 Runway 或 Sora 那类 AI 生成的视频。你的视频可以包含文字叠加、平滑过渡、AI 生成的图像等内容。

视频会在预览面板中自动循环播放，你可以像构建其他任何应用一样，通过与 Agent 对话不断迭代。

**面向所有构建者开放**，包括免费方案用户。

<div id="criando-um-vdeo-animado">
  ## 创建动画视频
</div>

在 Replit 首页，你可以通过两种方式开始创建动画视频：

<div id="opo-1-digite-um-prompt">
  ### 方式一：输入 prompt
</div>

在首页选择 **App** 标签页，输入 prompt 描述你想要的视频。Agent 会自动识别与视频相关的 prompt，并选择动画视频技术栈。

prompt 示例：

* “为我的新气泡水品牌制作一支宣传视频”
* “制作一个 30 秒的解说视频，讲解大语言模型的工作原理”
* “为德克萨斯州奥斯汀市制作一支具有电影感的宣传视频”

  <img src="/assets/mirror/animation-prompt-box-ba406b8e594a.png" alt="Replit homepage App tab with Animation selected and a prompt reading Create a launch video for my new app" width="1200" height="675" data-path="images/replitai/animation-prompt-box.png" />
</Frame>

<div id="opo-2-selecione-no-menu-suspenso">
  ### 方式 2：从下拉菜单中选择
</div>

1. 在首页进入 **App** 标签页。
2. 打开应用类型下拉菜单。
3. 选择 **Animation**。
4. 输入你想创建的视频的描述。

<Frame>
  <img src="/assets/mirror/animation-entry-point-b22d4942db44.png" alt="App type dropdown showing Animation selected among options including Web app, Mobile app, Data Visualization, 3D Game, and Automation" width="1200" height="675" data-path="images/replitai/animation-entry-point.png" />
</Frame>

Agent 开始创建后，会生成动画并显示在预览面板中。你可以观看视频自动循环播放，并继续对话来进行修改。

<div id="iterando-no-seu-vdeo">
  ## 迭代优化你的视频
</div>

Agent 生成第一版后，你可以通过对话不断打磨。以下几种方式效果不错：

* **使用 Chat 输入框中的 Enhance Prompt 按钮**，它专门针对视频 prompt 做了优化。
* **提出改进要求**——看过第一版后，说一句“再优化一下”或“在场景内加入更复杂的动画，更有创意一些”，通常能得到不错的效果。
* **明确说明**你想修改的地方——例如“让转场更流畅”“把配色改成深蓝配金色”或“在结尾加一个 logo 亮相”。

多试几个不同的 prompt，你很可能至少会对其中一个结果感到满意。

<div id="exportando-seu-vdeo">
  ## 导出视频
</div>

视频效果满意后，你可以将其导出为 MP4 文件。

1. 在预览面板右上角找到 **Export** 按钮。
2. 选择你需要的质量设置：
   * **分辨率**：720p 或 1080p
   * **帧率**：30fps 或 60fps
3. 选择 **Export**。渲染时间视视频的复杂程度而定，可能需要几分钟。
4. 渲染完成后，MP4 文件会自动下载。

<Frame>
  <img src="/assets/mirror/animation-export-dialog-cf4d777fca06.png" alt="Export video dialog showing Name field, Quality dropdown set to 1080p 60fps, and Render button" style={{maxWidth: "350px"}} width="662" height="495" data-path="images/replitai/animation-export-dialog.png" />
</Frame>

你也可以选择 **Publish**，分享视频链接。

**导出时长**：较长或较复杂的视频可能需要数分钟才能渲染完成，较简单的视频则渲染更快。导出在服务器端进行，因此处理期间你可以继续工作。

<div id="casos-de-uso">
  ## 使用场景
</div>

Vídeos Animados 适用于多种创意和专业需求：

* **产品发布视频** —— 用精致的宣传片发布新应用、新功能或新产品。
* **品牌与电影级视频** —— 为企业、城市、大学或活动制作视觉丰富的视频。
* **讲解视频** —— 用 30 到 60 秒说明某个产品、功能或概念的运作方式。
* **社交媒体内容** —— 为 Twitter/X、LinkedIn、Instagram 或 TikTok 制作吸睛的 motion graphics。
* **落地页视频** —— 为网站添加动画首屏区块或背景视频。
* **融资与投资人更新视频** —— 为重要里程碑制作专业的公告视频。

<div id="especificaes-do-vdeo">
  ## 视频规格
</div>

| 属性       | 详情                                                |
| -------- | ------------------------------------------------- |
| **格式**   | MP4                                               |
| **分辨率**  | 720p 或 1080p                                      |
| **帧率**   | 30fps 或 60fps                                     |
| **宽高比**  | 16:9 (标准)                                         |
| **渲染方式** | 服务器端渲染；网页动画库 (通常用于网站) 结合 Agent 的自定义技能——不使用 Remotion |
| **播放方式** | 在预览面板中自动循环播放                                      |

<div id="perguntas-comuns">
  ## 常见问题
</div>

* **可以暂停或播放视频吗？** 预览没有内置的暂停/播放控件，视频始终自动循环播放。如果你希望视频支持暂停/播放 (或场景选择) ，可以让 Agent 添加这些控件——不过添加后有时会影响设计质量，因此你可能更愿意保留默认的循环播放。
* **支持场景选择吗？** 预览中没有内置的场景选择器。如有需要，可以让 Agent 添加场景选择或其他控件；同样需要权衡上述的取舍。

<div id="limitaes">
  ## 限制
</div>

Vídeos Animados 是一项新功能，目前有一些限制需要注意：

* **仅支持程序化动画**：视频是基于 React 的 motion graphics，并非 AI 生成的视频 (如 Runway 或 Sora) ——不过你可以生成视频并在代码中使用。
* **渲染时间**：复杂动画的导出可能需要几分钟，较简单的视频渲染更快。
* **可能需要多次迭代**：虽然许多 prompt 一次就能得到不错的效果，但你可能需要迭代 2 到 3 个版本，才能获得完全符合预期的结果。为初始 prompt 使用 Enhance Prompt 按钮，并在第一个 checkpoint 后提供反馈，会很有帮助。
