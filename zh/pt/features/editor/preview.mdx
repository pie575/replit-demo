title: "Preview"

---

Preview 会显示 Web 应用的输出，并提供浏览器开发者工具和调试功能。

当你使用 **Run** 按钮启动 Web 应用时，Replit 会为其分配一个可通过互联网访问的临时 URL。Preview 工具渲染页面的效果与你在浏览器中看到的完全一致，并且内置了与主流浏览器类似的开发者工具。

<Note>
  Preview 是 Webview 的新名称。
</Note>

</Frame>

<div id="recursos">
  ## 功能
</div>

Preview 提供以下功能，让你无缝测试和调试 Web 应用：

* **实时网页预览**：无需离开浏览器标签页即可查看应用并与之交互
* **开发者工具**：使用内置工具快速诊断问题
* **响应式测试**：在不同的移动设备屏幕尺寸下预览你的应用

<div id="uso">
  ## 使用
</div>

运行 Web 应用时，Preview 工具会自动打开。
你可以在 **Configurações do Usuário** 工具中通过 **Automatic Preview** 设置来开启或关闭该行为。

以下说明介绍如何打开 Preview。

<Accordion title="如何访问 Preview">
  在左侧的**工具栏**中：

  1. 选择 <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="所有工具图标" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **所有工具**，查看项目编辑器的工具列表。
  2. 选择 <img class="icon-svg" src="/assets/mirror/preview-icon-6d37238e8cc2.svg" alt="Preview 图标" width="16" height="16" data-path="images/icons/preview-icon.svg" /> **Preview**。

  在**搜索栏**中：

  1. 选择顶部的放大镜图标 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" />，打开搜索工具
  2. 输入“Preview”找到该工具，并在结果中选择它。
</Accordion>

<div id="barra-de-localizao">
  ## 地址栏
</div>

**Preview** 标签页顶部的地址栏包含以下工具：

* **后退按钮**：跳转到浏览历史中的上一个页面
* **前进按钮**：跳转到浏览历史中的下一个页面
* **应用域名**：点击 `{...}.replit.dev` 可查看 Replit App 临时 URL 的相关信息
* **地址输入框**：查看当前 URL 路径，或输入新的路径

<div id="ferramentas-do-navegador">
  ## 浏览器工具
</div>

地址栏右侧的浏览器工具包含以下功能：

* **屏幕尺寸**：可选择不同的设备屏幕尺寸预设，用于测试响应式设计
* **Devtools**：显示或隐藏[开发者工具](#Developer_tools)面板
* **新标签页**：在浏览器新标签页中打开 Web 应用的 URL

<Note>
  **正在开发移动应用？** Preview 面板还支持在 **iOS Simulator** 或 **Android Emulator** 中预览。详情请参阅[原生移动应用](/zh/pt/features/artifact-types/building-mobile-apps#preview-on-a-simulator-or-emulator)。
</Note>

<div id="ferramentas-de-desenvolvedor">
  ## 开发者工具
</div>

开发者工具由开源项目 <a href="https://github.com/liriliri/eruda" target="_blank">Eruda</a> 提供支持，可帮助你完成以下任务：

* 在应用的上下文中查看 JavaScript 控制台并与之交互
* 检查 DOM 元素
* 监控网络请求
* 配置显示和行为偏好

要使用开发者工具，请选择 **Preview** 标签页顶部的 <img class="icon-svg" src="/assets/mirror/wrench-7cee9d1168da.svg" alt="扳手图标" width="16" height="16" data-path="images/icons/wrench.svg" /> **Devtools** 按钮进行开关切换。

以下各节介绍你可以在开发者工具的各个标签页中执行的操作。

<div id="console">
  ### 控制台
</div>

**Console** 标签页会显示应用生成的 JavaScript 日志。
在该标签页中，你可以执行以下操作：

* **清除输出**：点击 <img class="icon-svg" src="/assets/mirror/clear-bd1bf1847597.svg" height="16" width="16" alt="带斜线的圆圈图标" data-path="images/icons/clear.svg" /> 带斜线的圆圈图标，清除控制台的所有输出。
* **筛选输出**：按类型 (All、Info、Warning 或 Error) 查看筛选后的控制台输出。
* **筛选匹配文本**：点击 <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="筛选图标" data-path="images/icons/filter.svg" /> 筛选图标并输入文本，即可只显示匹配的输出。
* **复制输出**：点击 <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="复制图标" data-path="images/icons/copy.svg" /> 复制按钮，复制选中的控制台消息。
* **执行 JavaScript 代码**：点击 <img class="icon-svg" src="/assets/mirror/arrow-right-2859a6e6bdeb.svg" height="16" width="16" alt="向右箭头图标" data-path="images/icons/arrow-right.svg" /> 右尖括号，在应用的上下文中运行 JavaScript 代码。输入表达式后点击 **Execute**。

<div id="elements">
  ### Elements
</div>

**Elements** 标签页用于检查和修改网页的 DOM 结构。

* **查看元素详情**：查看 DOM 元素的详细信息及其在 HTML 代码中的位置
* **复制输出**：点击复制按钮 <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="复制图标" data-path="images/icons/copy.svg" />，即可复制选中的控制台消息。

点击箭头选择按钮 <img class="icon-svg" src="/assets/mirror/select-1165d9548c39.svg" height="16" width="16" alt="选择图标" data-path="images/icons/select.svg" /> 可切换选择模式。
进入选择模式后，在网页中点击某个元素。
该元素的 HTML 和 CSS 便会显示在 Elements 标签页中。

<div id="network">
  ### Network
</div>

**Network** 选项卡用于监控网页发起的请求。
在此选项卡中，你可以执行以下操作：

* **跟踪请求**：查看应用发起的所有网络请求，选择某个请求即可查看详细信息。
* **筛选**：选择漏斗形的 <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="筛选图标" data-path="images/icons/filter.svg" /> 筛选图标，即可查看与输入文本匹配的结果。将筛选条件留空即可清除筛选。
* **复制**：选择 <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="复制图标" data-path="images/icons/copy.svg" /> 复制按钮，即可复制存储信息。

<div id="resources">
  ### Resources
</div>

**Resources** 选项卡显示页面加载的资源以及浏览器存储 (例如 Cookie 和本地存储) 。
你可以查看并刷新以下资源类型的列表：

* JavaScript 文件
* 样式表
* Iframe
* 图片

在此选项卡中，你可以执行以下操作：

* **查看存储**：查看本地存储、会话存储和 Cookie。
* **筛选**：选择漏斗形筛选图标 <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="筛选图标" data-path="images/icons/filter.svg" />，显示与输入文本匹配的结果。将筛选条件清空即可取消筛选。
* **清除**：选择清除按钮 <img class="icon-svg" src="/assets/mirror/clear-bd1bf1847597.svg" height="16" width="16" alt="清除图标" data-path="images/icons/clear.svg" />，删除该存储类型的所有数据。
* **删除所选项**：选择“X”图标 <img class="icon-svg" src="/assets/mirror/delete-a21eb49cac3c.svg" height="16" width="16" alt="删除图标" data-path="images/icons/delete.svg" />，移除存储项。
* **复制**：选择复制按钮 <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="复制图标" data-path="images/icons/copy.svg" />，复制存储信息。

<div id="settings">
  ### Settings
</div>

**Settings** 标签页可用于自定义开发者工具的外观和行为。
该标签页提供以下方面的个性化选项：

* **工具设置**：自定义适用于各个工具标签页的选项
* **JavaScript 控制**：指定 JavaScript 的行为选项，例如将其禁用，以测试应用在这种情况下的表现
* **显示偏好**：更改主题、面板大小、透明度以及开发者工具的其他行为
