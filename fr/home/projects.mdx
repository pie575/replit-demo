<div id="what-is-a-project">
  ## Qu’est-ce qu’un projet ?
</div>

Un projet regroupe tout ce que vous créez sur Replit. Il contient votre code, vos données et tous les artefacts que vous créez — applications web, applications mobiles, présentations, tableaux de bord de données et vidéos. Lorsque vous expliquez à Agent ce que vous souhaitez, il configure un projet et y crée les artefacts.

Considérez un projet comme un workspace sur votre bureau. Tout se trouve au même endroit et peut partager les mêmes informations, mais chaque élément a une fonction différente.

Par exemple, si vous demandez à Agent de créer une application de suivi d’activité physique, il crée un projet avec un artefact d’application mobile, ainsi que le backend, la base de données et le stockage nécessaires à son fonctionnement.

<ArtifactGrid />

Concepts clés :

* **Projet** : le conteneur qui regroupe tout — votre code, vos données et tous vos artefacts
* **Artefact** : un résultat publiable au sein d’un projet (une application web, une présentation, une vidéo, etc.)
* **Ressources** : chaque artefact bénéficie automatiquement d’un backend, d’une base de données et d’un espace de stockage de fichiers — aucune configuration requise

<Note>
  La publication met en ligne l’intégralité de votre projet en une seule fois. Tous les artefacts sont mis en ligne
  ensemble, afin qu’ils restent toujours synchronisés.
</Note>

<div id="what-you-can-build">
  ## Ce que vous pouvez créer
</div>

| Type                                                                    | Description                                                                             | Exemple                                                                                       |
| ----------------------------------------------------------------------- | --------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| **[Application web](/fr/features/artifact-types/web-apps)**                | Un site web ou une application web que les utilisateurs consultent dans leur navigateur | Une boutique en ligne, un outil de réservation, un site portfolio                             |
| **[Application mobile](/fr/features/artifact-types/building-mobile-apps)** | Une application native que les utilisateurs installent sur leur téléphone               | Une appli de suivi d’activité physique, une application de commande de restaurant             |
| **[Visualisation de données](/fr/features/artifact-types/data-apps)**      | Un dashboard interactif avec des graphiques, des filtres et des données en temps réel   | Un rapport commercial, un suivi de métriques, une vue analytique                              |
| **[Présentation](/fr/features/artifact-types/slide-decks)**                | Une présentation que vous pouvez présenter ou exporter                                  | Une présentation commerciale, un point d’avancement d’équipe, une présentation de produit     |
| **[Animation](/fr/features/artifact-types/animated-videos)**               | Une vidéo d’animation graphique que vous pouvez exporter au format MP4                  | Une vidéo de lancement de produit, une vidéo explicative, du contenu pour les réseaux sociaux |
| **Jeu 3D**                                                              | Un jeu 3D, une simulation ou une expérience interactive                                 | Un jeu de réflexion, une simulation physique, une expérience interactive                      |
| **[Design](/fr/design/canvas)**                                            | Des pistes visuelles et des prototypes explorés sur le Canvas de design                 | Des planches d’inspiration, des maquettes, des explorations de design                         |

Un même projet peut contenir plusieurs artefacts. Par exemple, vous pouvez créer une application web pour vos clients, une application mobile pour votre équipe et une présentation pour les investisseurs, le tout dans le même projet. Lorsque les artefacts se trouvent dans le même projet, ils partagent automatiquement les mêmes données et la même logique backend. Pour en savoir plus, consultez [Artefacts](/fr/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project).

<div id="managing-your-projects">
  ## Gérer vos projets
</div>

La page projets répertorie tous les projets que vous avez créés ou auxquels vous avez été invité. C&#39;est le moyen le plus rapide de reprendre vos travaux récents et de trouver le bon projet dans un workspace très actif.

<div id="see-at-a-glance-whats-inside-each-project">
  ### Découvrez en un coup d’œil le contenu de chaque projet
</div>

Chaque carte de projet affiche de petites icônes représentant les artefacts qu’elle contient : application web, application mobile, présentation, visualisation de données ou animation. Survolez une icône pour afficher un aperçu de la capture d’écran de l’artefact directement sur la carte, afin de distinguer les projets sans les ouvrir.

<div id="filter-by-artifact">
  ### Filtrer par artefact
</div>

Utilisez le menu déroulant **Type de build**, situé en haut de la page projets, pour filtrer votre liste par artefact. Sélectionnez-en un pour n’afficher que les projets contenant ce type d’artefact :

* **Web** — projets contenant une application web
* **Mobile** — projets contenant une application mobile
* **Data** — projets contenant une visualisation de données
* **Slides** — projets contenant un diaporama
* **Design** — projets en mode Design
* **3D Game**, **Agent &amp; Automation** et bien plus encore

Sélectionnez **Any build type** pour supprimer le filtre.

  <img src="/assets/mirror/projects-page-build-type-filter-9e23df1b365a.png" alt="Menu déroulant Type de build de la page projets filtrant par artefact, avec les options Design, Web, Data, Mobile, 3D Game et Slides" width="472" height="622" data-path="images/replitai/projects-page-build-type-filter.png" />
</Frame>

<div id="sort-by-last-opened">
  ### Trier par dernière ouverture
</div>

Par défaut, la page projets est triée selon **dernière ouverture par vous** : les projets sur lesquels vous avez travaillé le plus récemment apparaissent en haut de la liste. Cela est particulièrement utile dans les Workspaces d&#39;équipe, où les modifications récentes d&#39;autres membres pourraient sinon reléguer votre travail en cours plus bas.

Vous pouvez modifier le tri en sélectionnant un autre en-tête de colonne (par exemple, **Dernière mise à jour** ou **Nom**).

<div id="pin-the-projects-you-use-most">
  ### Épinglez les projets que vous utilisez le plus
</div>

Épinglez un projet pour le garder en haut de votre liste. Les épingles sont **privées** : épingler un projet dans un workspace d&#39;équipe ne change pas ce que voient les autres membres.

Pour épingler un projet, ouvrez le menu Plus (trois points) sur la carte du projet et sélectionnez **Épingler**. Sélectionnez **Désépingler** dans le même menu pour retirer l&#39;épingle.
