Les modes Agent vous permettent de choisir le bon équilibre entre l&#39;allocation incluse, les crédits et les performances avant d&#39;envoyer une demande. Ouvrez le menu déroulant des paramètres Agent dans le champ de saisie du prompt, puis sélectionnez le mode adapté à votre tâche.

<Note>
  Economy Mode n&#39;est plus disponible. Power Mode le remplace au même prix.
</Note>

<div id="section">
  ## Choisir un mode
</div>

* **Free Mode :** explorez des idées, posez des questions, commencez à développer et poursuivez vos tâches quotidiennes. Free Mode sélectionne les modèles grâce à un routage intelligent. {FreeModePlanAvailability}
* **Power Mode :** un équilibre entre vitesse et performances adapté à la plupart des tâches. Utilisez-le lorsque vous avez besoin de performances supérieures à celles incluses dans Free Mode ou souhaitez utiliser des paramètres par défaut plus puissants dans un projet existant.
* **Max Mode :** la meilleure option pour les tâches complexes et exigeantes, les bases de code volumineuses et les problèmes difficiles.

Power Mode et Max Mode utilisent des crédits mensuels. Replit vous informe avant qu&#39;une demande ne passe de Free Mode à un mode payant. Consultez votre allocation Free Mode restante dans **Settings** → **Usage**. Pour des conseils pratiques, consultez [Comment tirer le meilleur parti de Free Mode](/fr/ko/chat/free-mode).

Routine s&#39;exécute en Power Mode ou Max Mode et nécessite un budget pour chaque exécution. Il ne peut pas être exécuté en Free Mode. Pour en savoir plus, consultez [Routine](/fr/ko/chat/routines).
