<div id="section-3">
  ### 全新的集成体验
</div>

现在，你可以在一个地方浏览 Replit 支持连接的所有服务。全新设计的集成页面将连接器、MCP 服务器和 Git 提供商整合为可点击的卡片，并提供分类筛选，还会用徽章标示哪些集成可由 Replit 自动连接。目录现已收录 450 多个集成，点击任一集成即可打开对应的专属页面，查看示例用例。你可以在 [replit.com/integrations](https://replit.com/integrations) 预览完整目录。

<div id="slack-replit">
  ### 在 Slack 中使用 Replit
</div>

Replit 现已成为 Slack 的 Slackbot MCP 客户端首发合作伙伴。只需让 Slackbot 用 Replit 来构建，你就能直接在 Slack 中创建、更新和查看 Replit 应用。对话无需中断，Replit Agent 会替你完成工作。

<div id="section-4">
  ## 团队与企业版
</div>

<div id="scim">
  ### 面向 SCIM 客户的多工作区
</div>

通过 SCIM 预配成员的企业版客户现在可以创建多个工作区。将同步的群组分配到不同的工作区，可以更清晰地划分访问边界、管理预算并实现团队隔离，同时身份提供商仍是唯一可信来源。该功能以公开注册的方式向新的企业版客户开放。

详细了解 [SCIM 工作区访问](/zh/ko/teams/identity-and-access-management/scim#managing-workspace-access)。
