# Controles de modelo Enterprise

> Escolha quais provedores de modelos e modelos do Agent estão disponíveis em cada Workspace Enterprise.

Os controles de modelo Enterprise permitem que os administradores de conta gerenciem quais modelos do Agent os builders podem selecionar. Defina uma política para a conta e, em seguida, configure acessos de modelo diferentes para Workspaces individuais.

<Note>
  Os controles de modelo estão disponíveis exclusivamente para administradores de conta em contas Enterprise. Entre em contato com nossa equipe de vendas em [sales@replit.com](mailto:sales@replit.com) para ativá-los para sua organização.
</Note>

## Usar o roteamento inteligente de modelos

O roteamento inteligente de modelos é a experiência padrão do Agent para Workspaces Enterprise. Com o **Auto mode** ativado, o Replit escolhe o modo e o modelo mais adequados para cada tarefa, equilibrando qualidade e custo.

O roteamento seleciona a partir do conjunto de modelos autorizados pelas políticas da conta e do Workspace. Provedores e modelos fora desse conjunto não são elegíveis para seleção. Os builders podem manter o **Auto mode** ativado ou desativá-lo para selecionar manualmente um modelo autorizado.

## Abrir as configurações de modelo do Agent

1. Abra **Configurações**.
2. Em **Conta**, selecione **Avançado**.
3. Expanda **Modos do Agent e provedores de modelos**.

## Definir uma política de provedor

<Steps>
  <Step>
    Selecione o provedor de modelos que você deseja gerenciar.
  </Step>

  <Step>
    Em **Account policy**, selecione uma opção:

    | Opção               | Resultado                                                              |
    | ------------------- | ---------------------------------------------------------------------- |
    | **Enable all**      | Todos os modelos do provedor ficam disponíveis em todos os Workspaces. |
    | **Enable selected** | Você escolhe os modelos disponíveis para cada Workspace.               |
    | **Disabled**        | Nenhum Workspace pode usar modelos desse provedor.                     |

    <Note>
      Pelo menos um modelo da OpenAI, da Anthropic e do Google deve permanecer ativado. Você pode desativar os demais provedores.
    </Note>
  </Step>

  <Step>
    Selecione **Update**.
  </Step>
</Steps>

Provedores de modelos open source vêm desativados por padrão. Para disponibilizar um, selecione **Enable all** ou **Enable selected** e, em seguida, selecione **Update**.

## Definir uma política de Workspace

Use **Enable selected** quando Workspaces diferentes precisarem de acessos de modelo diferentes.

<Frame caption="A política do provedor Anthropic definida como Enable selected, com o acesso a modelos configurado por Workspace.">
  <img src="https://mintcdn.com/replit/7L4DBoA1BILjA874/images/workspace/anthropic-account-policy-workspace-models.jpg?fit=max&auto=format&n=7L4DBoA1BILjA874&q=85&s=0b912c2bfb3f84db70cf495babf96d00" alt="Política de conta da Anthropic definida como Enable selected com alternâncias de modelo para um Workspace" width="2000" height="930" data-path="images/workspace/anthropic-account-policy-workspace-models.jpg" />
</Frame>

1. Abra as configurações do provedor.
2. Defina a **Account policy** como **Enable selected**.
3. Na lista **Workspace**, selecione o menu suspenso **Setting** de um Workspace.
4. Ative ou desative cada modelo para esse Workspace.
5. Selecione **Update**.

Antes de selecionar **Update**, você pode selecionar **Copy to all** para aplicar a
seleção de modelos do Workspace atual a todos os Workspaces da conta.

## Limitações

* As políticas de modelo se aplicam a Workspaces. Não é possível definir uma política diferente para um grupo de usuários dentro do mesmo Workspace.
* O roteamento inteligente de modelos não substitui as políticas da conta ou do Workspace. Ele não pode selecionar um provedor ou modelo desativado.
* O botão **Modelos do Fast mode** em **Modos do Agent e provedores de modelos** controla o acesso a variantes de modelo rápidas em todos os Workspaces da conta. As políticas de provedor e o roteamento inteligente de modelos não alteram essa configuração.
