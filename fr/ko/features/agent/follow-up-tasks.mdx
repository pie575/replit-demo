<div id="section">
  ## Suggestions de tâches de suivi
</div>

Lorsque vous appliquez une tâche, Agent examine le contexte du projet et propose des **tâches de suivi** à réaliser ensuite. La boîte de dialogue **Prochaine tâche suggérée** affiche la recommandation principale directement dans le fil afin que vous puissiez continuer sans quitter le fil principal.

  <img src="/assets/mirror/follow-up-tasks-dialog-c1660cec2d1d.png" alt="Boîte de dialogue Prochaine tâche suggérée présentant une tâche de suivi, avec un bouton Démarrer et un lien permettant de voir davantage de tâches dans le tableau des tâches" width="495" height="290" data-path="images/agent/follow-up-tasks-dialog.png" />
</Frame>

Les suggestions de suivi peuvent inclure :

* **Nouvelles fonctionnalités à créer** : des fonctionnalités qui complètent naturellement ce que vous venez de déployer
* **Améliorations des performances** : des optimisations qu’Agent a identifiées pendant l’exécution de la tâche
* **Améliorations de l’expérience utilisateur** : des ajustements et améliorations qui finalisent une fonctionnalité

Sélectionnez **Démarrer** pour envoyer une suggestion en arrière-plan, ou **Voir le plan** pour examiner d’abord le travail proposé. Sélectionnez **Voir plus dans le tableau des tâches** pour afficher toutes les suggestions. Les tâches de suivi suggérées apparaissent sous **Suggérées** dans la colonne **Brouillons**.

<Frame>
  <img src="/assets/mirror/follow-up-tasks-kanban-21087e0210b6.png" alt="Tableau des tâches affichant de nombreuses suggestions de tâches de suivi sous Suggérées dans la colonne Brouillons" width="980" height="627" data-path="images/agent/follow-up-tasks-kanban.png" />
</Frame>

La fermeture de la boîte de dialogue **Prochaine tâche suggérée** annule les suggestions. Agent n’affiche pas cette boîte de dialogue lorsqu’un plan suggéré est déjà en attente sur la branche principale, afin que deux invites ne se disputent pas votre attention.

<div id="section-2">
  ## Gérer plusieurs suggestions à la fois
</div>

Pour les projets comportant de nombreuses suggestions de suivi, ouvrez le tableau des tâches et sélectionnez **Modifier** dans la colonne **Brouillon**. En mode édition, une case à cocher s’affiche pour chaque tâche suggérée. Sélectionnez les tâches souhaitées, puis utilisez **Démarrer** ou **Annuler** pour appliquer l’action correspondante à toutes les tâches sélectionnées. Pour quitter le mode édition, sélectionnez **Terminer**.
