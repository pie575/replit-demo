Toutes les tuiles de Canvas sont des **frames**. Les frames sont les éléments que vous sélectionnez, faites glisser et manipulez. Cette page présente les différents types de frames, la barre d’actions qui s’affiche lorsque vous en sélectionnez une, ainsi que les actions Build et Focus disponibles depuis cette barre.

<div id="section">
  ## Types de frames
</div>

Les deux principaux types sont les **Artifacts** (écrans fonctionnels connectés à une application) et les **Designs** (maquettes). Vous pouvez identifier leur type dans l’en-tête en haut à gauche de la frame.

| Type            | Libellé de l’en-tête          | Basé sur                         | Interaction possible comme avec une application fonctionnelle ? | Peut être transformé en véritable application ?                          |
| --------------- | ----------------------------- | -------------------------------- | --------------------------------------------------------------- | ------------------------------------------------------------------------ |
| Artifact        | **Website**, **Slides**, etc. | artifact fonctionnel             | Oui                                                             | C’est déjà une application.                                              |
| Mobile artifact | **Mobile app**                | artifact fonctionnel             | Oui (dans le simulateur)                                        | C’est déjà une application.                                              |
| Design          | **Design**                    | maquette statique ou interactive | Uniquement les frames interactives                              | Oui — via le menu **Build…** de chaque frame. Consultez [Build](#build). |
| Image           | **Image**                     | PNG/JPG généré                   | Non                                                             | Non — à utiliser comme référence.                                        |
| Video           | **Video**                     | vidéo générée                    | Non                                                             | Non.                                                                     |
| Vector graphic  | **Graphic**                   | SVG généré                       | Non                                                             | Non — à intégrer dans une véritable application.                         |

<Note>
  Le comportement d’une frame Design — comme une image statique ou un prototype interactif — dépend de la fonctionnalité **Interactive frames**. Lorsqu’elle est activée, les frames Design réagissent aux clics et aux saisies dans les formulaires comme de véritables pages. Sinon, vous pouvez les modifier de façon itérative, mais elles sont rendues comme des instantanés sur lesquels vous ne pouvez pas cliquer pour naviguer.
</Note>

<div id="section-2">
  ## Aperçu sur différents appareils
</div>

Vérifiez l’apparence de votre design sur différentes tailles d’écran. Demandez à Agent d’afficher la version mobile, tablette ou ordinateur de bureau. Par exemple, dites « Montre-moi la version mobile de cette page » et Agent affichera le frame à cette taille.

* **Mobile** : 390 × 844
* **Tablette** : 768 × 1024
* **Ordinateur de bureau** : 1280 × 720

<div id="section-3">
  ## Barre d’actions de chaque frame
</div>

Lorsque vous sélectionnez un frame, une barre d’actions apparaît. Les actions disponibles varient selon le type de frame.

<div id="artifact-design">
  ### Frames Artifact et Design
</div>

Pour les frames Artifact (Website, Slides, etc.) et Design, la barre d’actions s’affiche en haut de la frame.

<Frame caption="Barre d’actions d’une frame Design : Build…, Focus et options supplémentaires.">
  <img src="/assets/mirror/canvas-frame-action-bar-86f90fdd1375.png" alt="Canvas avec une frame APEX X1 Design sélectionnée. En haut, une barre d’actions propre à la frame affiche une étiquette de type ainsi que les actions Build, Focus et options supplémentaires. Cette frame est également jointe sous forme de puce dans le champ de saisie du prompt de chat." width="2000" height="1290" data-path="images/replitai/canvas-frame-action-bar.png" />
</Frame>

Les actions sont réduites à des icônes lorsque l’espace est limité, puis leurs libellés apparaissent à mesure que la frame s’élargit. La liste complète, de gauche à droite, est la suivante :

| Action   | Fonction                                                                                                                                                                                                                                         |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Export   | Télécharge la frame au format PNG. Consultez [Exporter une frame au format PNG](/fr/ko/design/canvas#export-a-frame-as-png).                                                                                                                        |
| Build…   | Ouvre un menu qui répertorie tous les Artifact du projet — sélectionnez-en un auquel appliquer le design, ou choisissez **Build this design** pour créer un nouvel Artifact. S’applique uniquement aux frames Design. Consultez [Build](#build). |
| Focus    | Active le mode Focus, qui agrandit la frame pour en faire l’écran principal.                                                                                                                                                                     |
| More (…) | Actions supplémentaires pour la frame. Vous pouvez également copier, dupliquer, réorganiser et exporter depuis le [menu contextuel](/fr/ko/design/canvas#right-click-menu) du Canvas.                                                               |

Les frames d’application (Website, Slides, Mobile app) affichent Focus et des options supplémentaires, tandis que les frames Design affichent également Build… avant ces actions. Pour explorer une nouvelle piste à partir de la frame sélectionnée, suivez les [suggestions](/fr/ko/design/explore-suggestions) de cette frame.

Lorsque vous sélectionnez une frame, un instantané de celle-ci est également joint à votre prochain message de chat Agent — consultez [Ce qui se trouve sur le Canvas](/fr/ko/design/canvas#what-lives-on-the-canvas).

<Note>
  La barre d’actions respecte le **mode lecture seule**. Si le Canvas est verrouillé dans le contexte d’une tâche en arrière-plan, les actions liées au travail itératif sont masquées et seul Focus reste disponible.
</Note>

<div id="section-4">
  ### Frames multimédias
</div>

Les frames Image, Video et Vector graphic affichent une petite barre d’actions flottante au-dessus de la frame. Toutes trois proposent les options suivantes.

* **Remplacer le média** : importez un nouveau fichier dans la frame tout en conservant sa position et ses dimensions dans Canvas.
* **Télécharger** : enregistrez le fichier multimédia sur votre ordinateur.
* **Texte alternatif** : ajoutez un texte alternatif pour l’accessibilité et pour fournir davantage de contexte à Agent lorsqu’il fait référence à la frame.

<Frame caption="Barre d’actions d’une frame vidéo : Replace media, Download, Alt text.">
  <img src="/assets/mirror/canvas-frame-video-actions-905585560e90.png" alt="Barre d’actions flottante affichée au-dessus d’une frame vidéo de supercar bleue sélectionnée dans Canvas, avec les contrôles Replace media, Download (avec l’infobulle « Download original ») et Alt text" width="2000" height="1252" data-path="images/replitai/canvas-frame-video-actions.png" />
</Frame>

Les frames Image comportent deux contrôles supplémentaires.

* **Rogner (Crop)** : rognez l’image directement dans Canvas.
* **Générer une vidéo (Generate video)** : générez un court clip vidéo à partir de l’image.

<Frame caption="La barre d’actions d’une frame image inclut Crop et Generate video.">
  <img src="/assets/mirror/canvas-frame-image-actions-aae1378db7e3.png" alt="Barre d’actions flottante affichée au-dessus d’une frame image de supercar jaune sélectionnée dans Canvas, avec les contrôles Replace media, Crop, Download, Alt text et Generate video" width="1600" height="1002" data-path="images/replitai/canvas-frame-image-actions.png" />
</Frame>

<div id="section-5">
  ## Explorer de nouvelles pistes
</div>

Lorsque vous sélectionnez un frame, des [Suggestions](/fr/ko/design/explore-suggestions) apparaissent à côté : des pistes accessibles en un clic, basées sur ce que vous voyez, comme d&#39;autres dispositions, de nouvelles ambiances ou des pages suggérées par le design. Chaque suggestion est générée dans un nouveau frame à côté de l&#39;original, ce qui vous permet de les comparer tout en conservant l&#39;original intact.

<div id="build">
  ## Build
</div>

Le menu **Build…** du frame Design sélectionné transforme le design en application fonctionnelle. Il permet également d’appliquer ce design à un Artifact existant.

<Frame>
  <img src="/assets/mirror/canvas-build-menu-f06b8b8b455f.png" alt="Menu Build ouvert depuis le frame Design sélectionné (APEX X1 Exact Replica). L’en-tête indique « Créer ou appliquer vos designs » et propose « Créer ce design » pour créer un nouvel Artifact, ainsi que « Appliquer à une création existante », qui liste APEX X1 Design System et le site web Scroll Hero du projet" width="2000" height="1153" data-path="images/replitai/canvas-build-menu.png" />
</Frame>

<div id="build-this-design">
  ### Build this design
</div>

Sélectionnez **Build this design** dans le menu pour créer un nouvel Artifact à partir du frame Design sélectionné. Il est ajouté à la liste des artefacts du projet et devient une application pleinement fonctionnelle. Build nécessite un abonnement Core ou Pro.

<div id="artifact">
  ### Appliquer à un Artifact existant
</div>

Le menu Build… répertorie tous les Artifact du projet. Lorsque vous en sélectionnez un, les modifications du Design sélectionné sont appliquées à cet Artifact : Agent réécrit son code pour qu’il corresponde au design, tandis que le frame Design reste sur le Canvas à titre de référence.

<div id="section-6">
  ## Mode Focus
</div>

Le mode Focus vous permet de travailler sur le frame sélectionné en plein écran sans quitter Design.

<Steps>
  <Step title="Sélectionner Focus sur un frame">
    Sélectionnez un frame, puis **Focus** dans la barre d’actions.

    <Frame caption="L’action Focus dans la barre d’actions du frame sélectionné.">
      <img src="/assets/mirror/focus-before-0c9ced9218d9.png" alt="L’action Focus est mise en évidence dans la barre d’actions du frame Design sélectionné sur Canvas." width="2000" height="1254" data-path="images/design/replit-design/focus-before.png" />
    </Frame>
  </Step>

  <Step title="Travailler en plein écran">
    Le frame remplit l’écran, ce qui vous permet de travailler de près sans voir le reste du tableau.

    <Frame caption="Mode Focus">
      <img src="/assets/mirror/focus-mode-24da418577ae.png" alt="Mode Focus avec un frame Design remplissant l’écran et un bouton Exit focus en haut du tableau." width="2000" height="1254" data-path="images/design/replit-design/focus-mode.png" />
    </Frame>
  </Step>

  <Step title="Revenir à Canvas">
    Sélectionnez **Exit focus** en haut du tableau pour revenir à Canvas.
  </Step>
</Steps>
