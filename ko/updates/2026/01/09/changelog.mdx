<div id="private-apps-for-free-accounts">
  ### 무료 계정의 Private 앱
</div>

이제 무료 계정을 사용하는 Builder도 Private 앱을 만들 수 있습니다. 생성 가능한 앱 개수에 대한 무료 등급 limit은 그대로 적용됩니다.

<div id="made-with-replit-badge">

</div>

<div id="new-ai-models-in-integrations">
  ### Integrations의 새로운 AI 모델
</div>

새로 출시된 AI 모델을 이제 AI integrations에서 사용할 수 있습니다:

| 모델                           | 설명                                                                                                     |
| ---------------------------- | ------------------------------------------------------------------------------------------------------ |
| `gpt-5.2`                    | 전문적인 knowledge work에 가장 뛰어난 성능을 발휘하는 OpenAI 모델입니다. ARC-AGI-1에서 90%를 넘긴 최초의 모델로, 400K context 창을 제공합니다. |
| `claude-opus-4.5`            | 코딩, 에이전트, 컴퓨터 사용에 최적화된 Anthropic의 대표 모델입니다. SWE-bench Verified에서 80.9%를 기록했습니다.                        |
| `gemini-3-flash-preview`     | 1M token context를 갖춘 에이전트형 workflows용 Google 고속 모델입니다. 더 낮은 지연 시간과 비용으로 Pro에 가까운 추론 능력을 제공합니다.         |
| `gemini-3-pro-preview`       | 최고 수준의 추론 능력과 실세계 지식을 갖춘 Google의 고급 멀티모달 모델입니다.                                                        |
| `gemini-3-pro-image-preview` | 정확한 텍스트 렌더링과 함께 고품질 이미지 생성 및 편집을 지원하는 Google의 Nano Banana Pro 모델입니다.                                   |
