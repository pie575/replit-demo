На вкладке **My Data** вы просматриваете и изменяете содержимое базы данных. Откройте инструмент **Database**, выберите базу данных, затем перейдите на вкладку **My Data**. Работать можно визуально или напрямую выполнять SQL-запросы.

<Note>
  Чтобы изменить производственные данные, выберите производственную базу данных, откройте **My Data** и включите переключатель **Edit**. Будьте внимательны: это реальные данные вашего работающего приложения.
</Note>

<div id="browse-and-modify-data-visually">
  ## Просмотр и изменение данных в визуальном режиме
</div>

Инструмент Database включает <a href="https://orm.drizzle.team/drizzle-studio/overview" target="_blank">Drizzle Studio</a> — средство для визуального просмотра и изменения данных. Визуальные инструменты помогают избежать синтаксических ошибок и предоставляют следующие возможности:

* Фильтрация и сортировка данных для работы с нужной информацией
* Экспорт данных в файл для использования вне платформы
* Вставка и изменение данных в строках
* Создание схем, таблиц, представлений и перечислений, а также управление ими

<div id="run-sql-commands">
  ## Выполнение SQL-команд
</div>

SQL runner позволяет выполнять SQL-команды в базе данных и просматривать результаты.

<Accordion title="Как открыть SQL runner">
  В инструменте **Database**:

  1. Откройте вкладку **My Data**
  2. Выберите <img class="icon-svg" src="/assets/mirror/sql-runner-icon-b25868882922.svg" alt="SQL runner icon" width="16" height="16" data-path="images/icons/sql-runner-icon.svg" /> **SQL runner**
</Accordion>

Чтобы выполнить запрос, введите SQL-выражение в текстовое поле и нажмите расположенную рядом кнопку запуска <img class="icon-svg" src="/assets/mirror/sql-play-8ed26b5de7f1.svg" alt="sql run icon" width="18" height="18" data-path="images/icons/sql-play.svg" />:

<Frame>
  <img src="/assets/mirror/sql-runner-run-8ad798a61335.jpg" alt="screenshot of the SQL runner and run button" width="1390" height="608" data-path="images/databases/sql-runner-run.jpg" />
</Frame>

<Tip>
  Писать SQL самостоятельно не обязательно. Попросите Agent получить или изменить нужные данные — он сам составит и выполнит SQL-запрос.
</Tip>
