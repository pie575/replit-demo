<div id="workspace-security-center-20">
  ### Workspace Security Center 2.0
</div>

workspace 내 모든 project의 dependency 취약점을 한곳에서 검토하고 조치하세요. 이제 Workspace Security Center가 위험도가 가장 높은 project를 맨 앞에 보여주며, 영향을 받는 project를 severity, publish 상태, 공개 범위, 소유자 기준으로 검색하고 filter할 수 있습니다. 또한 Security Center를 벗어나지 않고 remediation loop 전체를 처리할 수 있습니다. Agent task를 시작하고, 제안된 수정 사항을 검토한 뒤 project를 republish하면 됩니다. project 소유자에게 개별 또는 일괄로 알림을 보내고, exposure가 높은 project는 그 자리에서 게시 해제하고, 규정 준수 audit을 위해 SBOM을 download할 수도 있습니다.

<div id="private-publishing-for-everyone">
  ### 모두를 위한 비공개 게시
</div>

비공개 및 비밀번호 보호 앱 게시는 이전까지 Pro와 Enterprise plan에서만 사용할 수 있었습니다. 이제 Core와 Starter의 builder도 비공개로 게시할 수 있어, 누구나 내부 도구나 베타 앱, 작업 중인 프로젝트를 Replit 로그인 뒤에 안전하게 둘 수 있습니다.

[Private Deployments](/ko/features/publishing/private-deployments)에 대해 자세히 알아보세요.

<div id="external-access-tokens-for-private-deployments">
  ### Private Deployments용 External access tokens
</div>

이제 비공개 Replit Apps에서 External access tokens를 사용할 수 있습니다. 토큰을 발급하면 Slack, GitHub, Twilio 등 connector와는 별개로 비공개 deployment에 접근하는 integration을 설정할 수 있습니다. 파워 유저는 애플리케이션을 더 세밀하게 제어할 수 있고, 비공개 Replit Apps의 보안도 한층 강화됩니다. deployment에서 **Adjust settings**를 열면 새로운 **External access tokens** 탭을 확인할 수 있습니다.

[External access tokens](/ko/references/publishing/external-access-tokens)에 대해 자세히 알아보세요.

<div id="speaker-notes-and-presenter-view-in-slide-decks">
  ### Slide Decks의 발표자 노트와 발표자 보기
</div>

이제 Slide Decks에서 발표자 노트와 전용 발표자 보기를 사용할 수 있습니다. 노트는 편집기와 발표 창 사이에서 양방향으로 실시간 동기화되므로, 한 기기로 화면을 공유하면서 다른 기기에서 deck을 원격으로 제어할 수 있습니다. Agent에게 노트 작성을 맡긴 뒤 편집기에서 다듬어 보세요. 청중에게는 slide만 표시됩니다. 발표자 보기는 모바일 slides artifact 카드에서도 사용할 수 있습니다.

<div id="agent-accepts-svg-uploads">
  ### Agent이 SVG 업로드를 지원합니다
</div>

이제 Agent에 SVG 파일을 첨부할 수 있습니다. Chat에 SVG 파일을 끌어다 놓거나 URL을 붙여 넣으면 Agent가 다른 첨부 파일과 동일한 방식으로 마크업을 읽습니다. 업로드된 파일은 Agent나 스토리지에 도달하기 전에 브라우저에서 검사·정제되므로 흔히 악용되는 SVG 기반 공격 요소가 자동으로 제거됩니다.
