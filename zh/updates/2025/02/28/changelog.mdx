<div id="agent-v2">
  ### Agent v2
</div>

<img src="/assets/mirror/agent-web-01b1f9026de7.webp" alt="Agent v2" width="800" height="450" data-path="images/changelog/2025-02-28/agent-web.webp" />

全新的 Agent 体验现已向所有开发者开放。与上一版本相比，新版 Agent 更快、更准确、能力更强。

它现由 Anthropic 迄今最先进的模型 Claude 3.7 Sonnet 提供支持。

加入 Explorer Program 即可抢先体验，操作说明请见[此处](https://youtu.be/pE_XT2TaXCA)。

<div id="deployment-improvements">
  ### 部署改进
</div>

为动态 App 选择静态部署时，开发者现在会收到 AI 建议，帮助 Agent 更好地处理部署请求。

<div id="claude-37-sonnet-release">
  ### Claude 3.7 Sonnet 发布
</div>

高级 Assistant 模式已为所有付费用户升级至 Claude 3.7 Sonnet，这意味着处理复杂请求时的准确性和能力都得到了提升。

<div id="database-performance-improvement">
  ### 数据库性能提升
</div>

数据库操作的速度比以往更快，其中最耗时的操作已从 200 毫秒缩短至 1 毫秒以内。

<div id="better-documentation">
  ### 更完善的文档
</div>

<img src="/assets/mirror/cleanshot-2025-02-27-at-1042282xpng-220848-e5317a7cfb93.png" alt="Docs redesign" width="3680" height="2382" data-path="images/changelog/2025-02-28/cleanshot-2025-02-27-at-1042282xpng-220848.png" />

文档现已新增“Copy Page”按钮，可将整页内容复制为 Markdown 格式。你还可以借助 `llms.txt` 和 `llms-full.txt` 为文档建立索引，供自己的大语言模型使用。
