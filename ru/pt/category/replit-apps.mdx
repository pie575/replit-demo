<div id="o-que-um-replit-app">
  ## Что такое Replit App?
</div>

Replit App — это облачные проекты, которые содержат код, данные и ресурсы.
Вы можете создавать, запускать и публиковать их в безопасной изолированной среде.

Replit App интегрируется со следующими инструментами в Project Editor, обеспечивая
бесперебойный процесс разработки:

* **Инструменты с ИИ**: используйте Agent, чтобы создавать, отлаживать и пояснять свой код.
* **Совместная работа**: работайте над одним приложением вместе с другими в реальном времени.
* **Публикация**: публикуйте своё приложение в облаке одним щелчком мыши.

<div id="principais-funcionalidades">
  ## Основные возможности
</div>

Replit App предоставляет следующие возможности:

* **Без настройки:** создавайте приложения и пишите код прямо на Replit.com — без установки и настройки.
* **Автосохранение:** ваш проект непрерывно сохраняет изменения в облаке, поэтому вы можете продолжить работу над кодом из любого веб-браузера
* **Контроль версий:** отслеживайте изменения, изучайте историю файлов и синхронизируйте их без какой-либо настройки — с помощью систем контроля версий Replit
* **Настройки публичной и приватной видимости:** определяйте, кто может просматривать, запускать или создавать Remix вашего приложения
* **Публикация:** публикуйте код в облаке без сложных изменений конфигурации
* **Персональные URL:** получите уникальный URL для своего приложения или подключите собственный домен, чтобы выглядеть профессионально

<Info>
  Файлы, загруженные в файловую систему вашего проекта, доступны только во время разработки и
  недоступны опубликованному приложению и другим разработчикам. Используйте [Object
  Storage](/ru/pt/features/data-and-storage/object-storage) для управления
  загрузками и раздачи файлов, а [Replit
  Database](/ru/pt/features/data-and-storage/sql-database) — для хранения и
  получения данных вашего приложения и пользователей.
</Info>

Подробнее об инструментах Project Editor, которые упрощают создание Replit App, см. в разделе [Обзор Project Editor](/ru/pt/learn/projects-and-artifacts/project-editor/).

<div id="como-funciona">
  ## Как это работает
</div>

Когда вы создаёте Replit App, Replit разворачивает в облаке приватное пространство для вашего проекта.
По мере того как вы добавляете функции и вносите изменения в приложение, Replit сохраняет их
автоматически, поэтому вы можете продолжить работу из любого веб-браузера.

Replit предоставляет готовые преднастроенные среды со всеми необходимыми компонентами.
Это позволяет сразу приступить к созданию приложения, не задумываясь о
настройке сервера, конфигурации базы данных или управлении средой.

Replit автоматически присваивает каждому Replit App уникальный веб-адрес, по которому вы
можете просматривать приложение прямо в процессе работы. Когда вы будете готовы поделиться
результатом, его можно опубликовать всего в несколько кликов и сделать доступным круглосуточно.

<div id="viso-geral-de-armazenamento">
  ## Обзор хранилища
</div>

Replit предлагает четыре основных типа хранилища для работы с данными вашего приложения. Каждый тип подходит для своих сценариев и имеет ограничения, зависящие от вашего тарифного плана.

<Info>
  Лимиты хранилища учитывают все данные, сохраняемые вашим приложением, включая установленные пакеты и зависимости.
</Info>

| Тип хранилища                                                      | Описание                              | Сценарии использования                                  | Сохранность                                              | Лимиты по планам                                                                                                                                     |
| ------------------------------------------------------------------ | ------------------------------------- | ------------------------------------------------------- | -------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Файловое хранилище**                                             | Файлы в вашем проекте                 | Код приложения, статические ресурсы, файлы конфигурации | Сохраняется при публикации, сбрасывается при перезапуске | Starter: {StarterWorkspaceStorage}<br />Core: {CoreWorkspaceStorage}<br />Pro: {TeamsWorkspaceStorage}<br />Enterprise: {EnterpriseWorkspaceStorage} |
| **[Database](/ru/pt/features/data-and-storage/sql-database/)**        | Хранение структурированных данных     | Профили пользователей, игровые очки, каталоги товаров   | Полностью сохраняется между сессиями                     | 20 ГБ на базу данных разработки<br />Продакшн-базы тарифицируются по времени вычислений и объёму хранилища                                           |
| **[App Storage](/ru/pt/features/data-and-storage/object-storage/)**   | Неструктурированные данные и медиа    | Изображения, видео, PDF, документы                      | Полностью сохраняется между сессиями                     | Оплата по факту использования<br />Тарифицируется по объёму хранилища и трафику                                                                      |
| **[Secrets](/ru/pt/core-concepts/project-editor/app-setup/secrets/)** | Зашифрованные конфиденциальные данные | Ключи API, учётные данные, строки подключения           | Полностью сохраняется и шифруется                        | Без специальных лимитов<br />Входит во все планы                                                                                                     |
