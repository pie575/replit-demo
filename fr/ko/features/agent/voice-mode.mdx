---
title: "Mode vocal"
description: "Au lieu de taper, dites votre prompt à Agent. Le mode vocal transcrit vos paroles en texte dans la fenêtre de chat afin que vous puissiez les relire et les envoyer."
---

Décrivez à voix haute ce que vous souhaitez créer avec le mode vocal. Appuyez sur le microphone dans la fenêtre de chat Agent et énoncez votre prompt : Replit transcrira vos paroles en texte modifiable. Relisez le texte, apportez les modifications nécessaires, puis envoyez-le comme n’importe quel autre message.

Le mode vocal est particulièrement utile lorsque la saisie est lente ou peu pratique — sur mobile, il est souvent plus rapide de parler que de saisir un prompt entier avec vos pouces.

<Note>
  Le mode vocal transforme vos paroles en texte dans la fenêtre de chat. Il ne lit pas à voix haute les réponses d’Agent — vous envoyez toujours des messages texte, et Agent répond dans la fenêtre de chat comme d’habitude.
</Note>

  ## Fonctionnement

Le mode vocal enregistre ce que vous dites, le transcrit en texte et insère le résultat dans la fenêtre de chat afin que vous puissiez le vérifier avant de l’envoyer :

1. Ouvrez Agent et sélectionnez le microphone dans la fenêtre de chat.
2. Autorisez l’accès au microphone lorsque votre navigateur ou votre appareil le demande.
3. Dites votre prompt. Une forme d’onde s’affiche pour indiquer qu’Agent enregistre.
4. Lorsque vous avez terminé, arrêtez l’enregistrement. Il s’arrête également automatiquement si vous faites une pause ou passez à un autre onglet.
5. Patientez pendant que vos paroles sont transcrites en texte.
6. Vérifiez le texte transcrit, modifiez-le si nécessaire, puis envoyez le message.

Le texte transcrit s’affiche comme du texte standard dans la fenêtre de chat. Vous pouvez donc librement combiner la voix et la saisie au clavier : dites une partie de votre prompt et tapez le reste, ou modifiez des mots avant l’envoi.

<Tip>
  Parlez naturellement. Le mode vocal cherche à comprendre votre intention plutôt qu’à transcrire chaque mot tel quel. Les mots de remplissage comme « euh » ou « hum » sont donc exclus du résultat.
</Tip>

<div id="section-2">
  ## Où l’utiliser
</div>

Le mode vocal est disponible dans la fenêtre de chat de l’Agent :

* dans le **Project Editor**, lorsque vous travaillez avec Agent sur une application
* dans le prompt de l’Agent sur l’écran d’accueil, lorsque vous **créez une nouvelle application**

Vous pouvez utiliser le mode vocal sur le Web pour ordinateur, le Web mobile et l’application mobile Replit.

<div id="section-3">
  ## À savoir
</div>

Gardez les points suivants à l&#39;esprit lorsque vous utilisez le mode vocal :

| Élément                        | Comportement attendu                                                                                                                                                                                                         |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Durée d&#39;enregistrement     | Vous pouvez enregistrer jusqu&#39;à 6 minutes à la fois. Un avertissement s&#39;affiche peu avant d&#39;atteindre la limite.                                                                                                 |
| Arrêt automatique              | L&#39;enregistrement s&#39;arrête automatiquement après environ 30 secondes de silence, si vous changez d&#39;onglet ou si vous mettez l&#39;application en arrière-plan.                                                    |
| Vérification avant l&#39;envoi | Le texte transcrit apparaît dans la fenêtre de chat : vous pouvez donc le relire et le modifier avant de l&#39;envoyer — rien n&#39;est envoyé automatiquement.                                                        |
| Accès au microphone            | Le mode vocal nécessite l&#39;autorisation d&#39;utiliser le microphone. Si l&#39;enregistrement ne démarre pas, vérifiez que vous avez autorisé Replit à accéder au microphone dans votre navigateur et sur votre appareil. |

<div id="section-4">
  ## Disponibilité
</div>

Le mode vocal est disponible avec tous les forfaits Replit. Une icône de microphone s’affiche dans la fenêtre de chat Agent sur les navigateurs et appareils compatibles avec l’enregistrement audio. Vous serez invité à autoriser l’accès au microphone lors de votre premier enregistrement.
