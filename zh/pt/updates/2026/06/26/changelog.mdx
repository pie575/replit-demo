  ### 全新集成体验
</div>

现在，您可以在同一处浏览 Replit 可连接的所有服务。重新设计的集成页面以可点击卡片的形式汇集了连接器、MCP 服务器和 Git 提供商，支持按类别筛选，并会标记 Replit 可为您自动连接的集成。该目录现已收录超过 450 项集成，每项集成都有专属页面，提供使用场景示例。您可以在 [replit.com/integrations](https://replit.com/integrations) 查看完整目录。

<div id="use-o-replit-pelo-slack">
  ### 通过 Slack 使用 Replit
</div>

Replit 现已成为 Slack 的 Slackbot MCP Client 首发合作伙伴。让 Slackbot 使用 Replit 进行开发，它即可直接在 Slack 中创建、更新和展示你的 Replit Apps。你可以继续参与对话，同时由 Replit Agent 完成相关工作。

<div id="mltiplos-workspaces-para-clientes-scim">
  ### SCIM 客户可使用多个 workspace
</div>

通过 SCIM 预配成员的 Enterprise 客户现在可以创建多个 workspace。您可以将同步的群组分配到不同的 workspace，以更清晰地划分访问权限、控制预算并分隔团队，同时仍以身份提供方为唯一事实来源。此功能现已向新的 Enterprise 客户开放注册。

详细了解[通过 SCIM 访问 workspace](/zh/pt/teams/identity-and-access-management/scim#managing-workspace-access)。
