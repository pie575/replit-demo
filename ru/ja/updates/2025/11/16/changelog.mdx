<div id="azure-marketplace">
  ### Интеграция с Azure Marketplace
</div>

Replit теперь доступен в Azure Marketplace. Многие организации выделяют отдельные бюджеты на Azure, и эта интеграция позволяет напрямую использовать эти средства для оплаты подписки и использования Replit.

Это дополнение, последовавшее за интеграцией с GCP Marketplace в сентябре, ещё больше упрощает командам Enterprise внедрение Replit, используя существующие процессы облачных закупок и бюджеты.

[Открыть в Azure Marketplace](https://marketplace.microsoft.com/en-us/product/saas/replit.replit?tab=Overview)

<div id="gitlabbitbucket">
  ### Поддержка GitLab и Bitbucket
</div>

Помимо GitHub, Replit теперь поддерживает репозитории GitLab и Bitbucket. Это дает больше гибкости в выборе места хранения кода и позволяет напрямую импортировать проекты из GitLab и Bitbucket в Replit. Улучшенные возможности Git также доступны на всех поддерживаемых платформах.

Расширенная интеграция с Git включает:

* **Поддержка нескольких платформ**: импортируйте репозитории GitHub, GitLab и Bitbucket и работайте с ними
* **Улучшенные операции Git**: более быстрые и надежные команды Git во всем рабочем пространстве
* **Улучшенное управление репозиториями**: оптимизированные процессы клонирования, отправки и получения изменений для всех поддерживаемых провайдеров Git

Подробнее см. в разделах [Импорт проектов](/ru/references/workspace/import) и [Использование Git в Replit](/ru/references/version-control/git-interface).
