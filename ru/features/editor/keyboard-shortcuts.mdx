Сочетания клавиш позволяют выполнять команды, редактировать текст и перемещаться по Project Editor
с помощью настраиваемых комбинаций клавиш. Настраивать и использовать сочетания клавиш можно в
веб-приложении Replit.com.

<div id="viewing-keyboard-shortcuts">
  ## Просмотр сочетаний клавиш
</div>

Чтобы открыть настройки сочетаний клавиш, выполните следующие шаги:

1. Откройте Replit App, чтобы перейти в Project Editor.
2. Откройте вкладку <img class="icon-svg" src="/assets/mirror/settings-icon-c2664c3691bf.svg" alt="значок шестерёнки" width="16" height="16" data-path="images/icons/settings-icon.svg" /> **User Settings** в разделе <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="значок всех инструментов" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools** на панели.
   Также можно найти «User Settings» через <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="значок лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> лупу.
3. Перейдите на вкладку **Keyboard shortcuts**, чтобы увидеть список команд и назначенных им сочетаний клавиш.

<div id="customizing-keyboard-shortcuts">
  ## Настройка сочетаний клавиш
</div>

Чтобы добавить или изменить сочетание клавиш, выполните следующие шаги:

1. Выберите <img class="icon-svg" src="/assets/mirror/create-app-icon-ba218e87fb67.svg" alt="plus icon" width="16" height="16" data-path="images/icons/create-app-icon.svg" />**Add shortcut** рядом
   с неназначенной командой либо значок карандаша <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="pencil icon" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> для назначенных команд.
2. Когда рядом с командой появится надпись «Recording...», нажмите нужное сочетание клавиш.
   Чтобы отменить запись, щёлкните по пустой области внутри вкладки.
3. Чтобы вернуть прежнее сочетание, выберите значок отката <img class="icon-svg" src="/assets/mirror/rollback-icon-3197ed1b323b.svg" alt="rollback icon" width="12" height="12" data-path="images/icons/rollback-icon.svg" />.

<div id="removing-keyboard-shortcuts">
  ## Удаление сочетаний клавиш
</div>

Чтобы удалить сочетание клавиш, нажмите значок корзины <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="значок корзины" width="16" height="16" data-path="images/icons/trash-icon.svg" /> рядом с командой.

<div id="tab-navigation">
  ## Навигация с помощью Tab
</div>

Для перемещения между интерактивными элементами страницы можно использовать браузерную навигацию клавишей **Tab**. Однако редактор файлов, консоль и Shell перехватывают клавишу **Tab** и обрабатывают её как ввод, например для отступов.

Чтобы продолжить переключение между элементами страницы, находясь в этих инструментах, выполните следующие действия:

1. Нажмите **Esc**, чтобы убрать фокус с инструмента
2. Нажмите **Tab**, чтобы перейти к следующему элементу
