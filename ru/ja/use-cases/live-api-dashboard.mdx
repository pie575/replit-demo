Создайте интерактивную панель мониторинга с ключевыми показателями, графиками и фильтрами на основе API. Она автоматически
обновляется, поддерживает экспорт и отображает только данные, которые действительно в ней содержатся. Всё, что
нужно сохранить, храните в Replit Database.

<div id="section">
  ## Оптимальные сценарии использования
</div>

* Продакт-менеджеры, которым нужны интерактивные панели мониторинга вместо скриншотов.
* Руководители операционных и аналитических направлений, которым нужны закрытые панели мониторинга с всегда актуальными данными из API.

<div id="section-2">
  ## Прежде чем начать
</div>

Запишите, какие решения должна поддерживать эта панель. Подготовьте URL своего API или используйте
приведённые ниже эндпоинты DummyJSON.

<Info>
  Для тестирования можно использовать следующие бесплатные эндпоинты DummyJSON API.

  * Заказы: `https://dummyjson.com/carts?limit=0`
  * Клиенты: `https://dummyjson.com/users?limit=0`
  * Каталог: `https://dummyjson.com/products?limit=0`
  * Категории: `https://dummyjson.com/products/categories`
</Info>

<div id="section-4">
  ## Чего ожидать
</div>

Agent загрузит данные, выберет сводные показатели и графики, а также добавит фильтры. Сверьте хотя бы
одно число с источником. Если вы использовали DummyJSON, выберите заказ, откройте
`https://dummyjson.com/carts/{id}` и убедитесь, что итоговая сумма совпадает. Переключите
фильтры и убедитесь, что все карточки и графики обновляются. Один раз экспортируйте данные
и сверьте одну строку с API.

<div id="section-6">
  ## Устранение неполадок
</div>

* **API недоступен или имеет некорректную структуру:** проверьте URL и убедитесь, что ответ содержит ожидаемые поля. Для быстрой проверки используйте указанный выше эндпоинт DummyJSON.
* **Числа отличаются от ожидаемых:** попросите Agent показать запросы и преобразования данных, а затем сверьте хотя бы одно значение с источником.
* **Фильтры не обновляют графики:** попросите Agent подключить каждый фильтр и к сводным карточкам, и к данным графиков. Если панель работает медленно, кэшируйте ответы API или уменьшите количество записей, загружаемых при запуске.
