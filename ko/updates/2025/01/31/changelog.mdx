<div id="repl-app">
  ### Repl -&gt; App
</div>

이제 Repl은 &quot;App&quot;이 되었습니다. 무엇보다 단순함이 우선이니까요.

<div id="enhanced-notifications">
  ### 향상된 알림
</div>

결제 실패 및 인보이스 알림이 개선되었습니다. 이제 App이 정지되기 전 24시간의 유예 기간이 제공되며, 진행 상황도 더욱 투명하게 확인할 수 있습니다.

이번 업데이트로 Replit 사용에 지장이 생기는 일을 방지할 수 있습니다.

<div id="object-storage-improvements">
  ### Object Storage 개선 사항
</div>

Object Storage 창에 검색 기능과 페이지 나누기(페이지네이션)가 추가되어 파일을 더 쉽게 탐색할 수 있습니다.

<div id="de-cluttered-diffs">
  ### 깔끔해진 diff
</div>

이제 Assistant의 파일 변경 사항이 임시 diff pane으로 열립니다. 덕분에 탭이 끝없이 쌓여 workspace가 복잡해지는 일 없이 변경 사항을 더 쉽게 확인할 수 있습니다.

변경 사항을 적용하면 해당 pane은 자동으로 닫힙니다.

<div id="more-performant-agent-in-asia">
  ### 아시아 지역에서 더 빨라진 Agent
</div>

아시아 지역의 Agent 빌더를 위해 클라우드 서비스를 최적화했습니다. 응답 속도가 한층 빨라지고 훨씬 매끄러운 경험을 느낄 수 있습니다.

<div id="x-login">
  ### X login
</div>

이제 X 계정으로 Replit에 가입하고 로그인할 수 있습니다. 미래에 오신 것을 환영합니다.

<div id="rapid-repo-import">
  ### 빠른 저장소 import
</div>

즐겨 쓰는 GitHub 저장소를 Replit으로 가져오고 싶으신가요?

이제 바로 가져올 수 있습니다.

브라우저 주소창에 `replit.com/YOUR_REPO_URL`을 입력하기만 하면 됩니다. 예를 들면 다음과 같습니다.

`https://replit.com/github.com/mattppal/magnetic-feel`
