Project Editor comprend des outils intégrés et de gestion de la disposition qui améliorent votre expérience de création d’applications.
Ces fonctionnalités de Project Editor prennent en charge des aspects spécifiques du processus de développement,
vous permettant de vous concentrer sur la création plutôt que sur la configuration.

<div id="project-editor">
  ## Disposition personnalisable du Project Editor
</div>

Les outils de gestion de la disposition du Project Editor vous permettent de personnaliser les éléments de votre environnement de développement.
Ils comprennent les types d’éléments d’interface utilisateur suivants.

| Élément                | Description                                                                                           | Fonctionnalités                                                                                                                                                                                  | Cas d’utilisation                                                                                                                                    |
| ---------------------- | ----------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Windows (fenêtres)** | Onglet de navigateur contenant un ou plusieurs panneaux                                               | <ul><li>Peuvent être organisées sur plusieurs écrans</li></ul>                                                                                                                                   | <ul><li>Organiser le Project Editor sur plusieurs écrans</li><li>Travailler simultanément sur plusieurs projets</li></ul>                            |
| **Panes (panneaux)**   | Zone d’une fenêtre contenant un ou plusieurs onglets                                                  | <ul><li>Prise en charge du fractionnement horizontal et vertical</li><li>Redimensionnables et repositionnables</li><li>Peuvent être transformés en panneaux flottants dans une fenêtre</li></ul> | <ul><li>Afficher le code et la Preview côte à côte</li><li>Créer des dispositions personnalisées pour différentes tâches de développement</li></ul> |
| **Tabs (onglets)**     | Contiennent exactement un outil du Project Editor, tel qu’un éditeur de fichiers, la Preview ou Agent | <ul><li>Peuvent être déplacés d’un panneau à l’autre et réorganisés au sein d’un panneau</li><li>Permettent de passer à un autre fichier ou outil en un clic</li></ul>                           | <ul><li>Ouvrir d’autres outils ou fichiers selon les besoins</li></ul>                                                                               |

<div id="section">
  ## Arborescence des fichiers
</div>

L’arborescence des fichiers répertorie tous les fichiers et répertoires de votre application Replit.

<Accordion title="Accéder à l’arborescence des fichiers">
  Sélectionnez l’icône de dossier <img class="icon-svg" src="/assets/mirror/files-icon-f66bf1b04572.svg" alt="icône de dossier avec des flèches" width="16" height="16" data-path="images/icons/files-icon.svg" /> à gauche pour
  afficher ou masquer l’arborescence des fichiers.
</Accordion>

Dans l’arborescence des fichiers, vous pouvez effectuer les opérations suivantes :

* Sélectionner un dossier pour afficher son contenu
* Sélectionner un fichier ou le faire glisser vers un panneau pour l’ouvrir dans l’éditeur de fichiers
* Dupliquer, renommer, déplacer, télécharger ou supprimer des fichiers

<div id="run">
  ## Bouton Run
</div>

Le bouton **Run** exécute le workflow sélectionné dans votre application Replit.

<Accordion title="Accéder au bouton Run">
  Le bouton **Run** se trouve en haut du Project Editor. Sélectionnez-le pour exécuter le workflow sélectionné.

  Lorsqu&#39;une application Replit est en cours d&#39;exécution, le libellé du bouton devient **Stop**. Sélectionnez-le pour arrêter l&#39;application.
</Accordion>

Pour savoir comment sélectionner, consulter et gérer les workflows, consultez [Workflows](/fr/ko/features/workspace-tools/workflows/).

<div id="section-3">
  ## Menu d’options
</div>

Le menu d’options vous permet d’effectuer les opérations de disposition suivantes :

* **Gestion des fenêtres :** ouvrir le Project Editor d’une application Replit dans une nouvelle fenêtre
* **Gestion des panneaux :** ajouter, déplacer ou maximiser des panneaux, ou basculer entre une position flottante et fixe
* **Gestion des onglets :** ouvrir ou sélectionner d’autres onglets, déplacer des onglets vers d’autres panneaux ou fermer des onglets

<Accordion title="Accéder au menu d’options">
  Sélectionnez les <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="icône à trois points verticaux" height="16" width="16" data-path="images/icons/vertical-dots.svg" /> trois points verticaux situés dans l’angle supérieur droit de
  l’onglet actif pour ouvrir le menu d’options.
</Accordion>

<div id="section-5">
  ## Panneau des ressources
</div>

Le panneau des ressources affiche les ressources informatiques de l’environnement de développement et leur utilisation (RAM, processeur et espace de stockage, entre autres).
Ces informations vous aident à estimer et à optimiser les exigences de publication de votre application Replit.

<Accordion title="Accéder au panneau des ressources">
  1. Sélectionnez l’icône des ressources <img class="icon-svg" src="/assets/mirror/resources-237893692826.svg" alt="icône d’ordinateurs empilés" width="16" height="16" data-path="images/icons/resources.svg" /> à côté du nom de l’application pour ouvrir ou fermer le panneau.
  2. Survolez **Compute** ou **Storage** pour afficher plus de détails.
</Accordion>
