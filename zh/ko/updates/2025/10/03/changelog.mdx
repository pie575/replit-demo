<div id="vercel">
  ### Vercel 导入集成
</div>

一键将 Vercel 应用迁移到 Replit！全新的导入流程可将 Next.js 及其他托管在 Vercel 上的应用顺畅迁移到 Replit。对于正在寻找 Vercel 替代方案的开发者来说，正当其时。详见 [从 Vercel 导入快速入门](/zh/build/import-from-vercel)和[导入到 Replit 指南](/zh/references/workspace/import)。

<div id="git">
  ### Git 源代码控制改进
</div>

Git 集成全面增强，带来更完善的远程仓库管理和更灵活的工作区体验。借助优化后的交互体验，你可以连接和创建 Git 远程仓库，在个人与组织工作区之间轻松切换，并确保代码在部署前始终保持最新。详见[使用 Git 面板](/zh/references/version-control/git-interface)。

<div id="section-3">
  ### 连接器平台上线
</div>

24 个预构建的应用集成，助你更快完成构建！通过全新的连接器平台，将 Replit 项目连接到 Stripe、Figma 等热门服务。每个连接器均由 MCP (Model Context Protocol) 驱动，带来流畅的 AI 辅助开发体验。详见 [Agent 集成](/zh/replitai/integrations)和[连接器管理](/zh/ko/replitai/managing-connectors)。

<div id="section-4">
  ### 应用主题字体改进
</div>

新增 19 款 Google Fonts 供你自定义应用，其中包括 Crimson、EB Garamond、Figtree、Source Sans Pro 等热门字体。字体选择器现在会以字体的实际样式进行渲染，让你更直观地预览设计效果。字体按类别 (衬线、无衬线、等宽) 分类整理，并配有说明各类别的实用提示，便于浏览查找。详见[应用主题](/zh/replitai/app-themes)。

<div id="section-6">
  ### 连接器管理员管理
</div>

企业版客户可使用高级连接器管理功能，包括对共享 API 密钥的基于角色的访问控制，以及完全自定义的 OAuth 客户端配置。连接器可在组织级别按需启用，让管理员完全掌控向团队成员开放哪些集成。详见[连接器管理](/zh/ko/replitai/managing-connectors)。
