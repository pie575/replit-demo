# Agent 및 AI

> Agent 관련 일반 질문에 대한 답변—멈춤 또는 루프 Agent 수정, 비용 절감, Agent 모드, 변경 사항 롤백, 자체 API 키 사용.

이 답변은 Agent 사용을 다룹니다. 전체 참고 자료는 [Agent 개요](/ko/features/agent/overview), [Agent 모드](/ko/features/agent/agent-modes), [AI 청구](/ko/billing/ai-billing)를 참조하세요.

<AccordionGroup>
  <Accordion title="Agent가 멈추거나 계속 연결이 끊겨요. 어떻게 수정하나요?">
    1. `Cmd+K`(Mac) 또는 `Ctrl+K`(Windows)로 명령 팔레트를 여세요.
    2. **Restart compute**를 검색하여 선택해 개발 환경을 재시작하세요.
    3. 새 Agent 채팅을 열고 작업을 다시 설명하여 계속하세요.

    Agent가 멈춘 것처럼 보이는 동안에는 메시지를 보내지 마세요. 추가 메시지는 상충하는 지시를 만들어냅니다. Agent가 같은 작업에서 계속 멈추면 작업을 더 작고 집중적인 프롬프트로 나누세요.
  </Accordion>

  <Accordion title="Agent가 같은 단계를 반복하거나 루프하고 있어요. 어떻게 중지하나요?">
    1. Agent 패널에서 **중지**를 선택하여 즉시 중단하세요.
    2. `Cmd+K`(Mac) 또는 `Ctrl+K`(Windows)로 명령 팔레트를 열고 **Restart compute**를 검색하여 선택하세요.
    3. 새 Agent 채팅을 열고 작업을 더 구체적으로 재입력하세요.

    루프를 방지하려면:

    * 큰 작업을 더 작은 프롬프트로 나누세요. 메시지당 하나의 목표.
    * [Plan 모드](/ko/features/agent/plan-mode)를 사용하여 Agent가 빌드하기 전에 작업 범위를 정하세요.
    * [지출 관리](/ko/billing/managing-spend)에서 사용량 한도를 설정하여 루프로 인한 과도한 청구를 방지하세요.
  </Accordion>

  <Accordion title="Agent 비용을 줄이려면 어떻게 하나요? 실제로 도움이 되는 설정은 무엇인가요?">
    다음 선택이 가장 큰 차이를 만듭니다:

    * **[Free 모드](/ko/features/agent/agent-modes)**—Core 및 Pro 구독자를 위한 할당량 내에서 비용이 들지 않는 일상적인 Agent 작업입니다.
    * **[Power 모드](/ko/features/agent/agent-modes)**—작업에 더 많은 성능이 필요할 때 합리적인 가격으로 더 큰 성능을 제공합니다.
    * **[Plan 모드](/ko/features/agent/plan-mode)**—Agent가 빌드하기 전에 작업 범위를 정하고 승인하여 원하지 않는 변경에 대한 비용을 방지하세요.
    * **사용량 한도 및 예산**—[지출 관리](/ko/billing/managing-spend)에서 하드 캡을 설정하세요.

    작업을 전환할 때 새 Agent 채팅을 시작하는 것도 도움이 됩니다. 사용량 대시보드를 확인하여 어떤 작업이 가장 많은 비용이 드는지 파악하세요.
  </Accordion>

  <Accordion title="Agent 모드는 무엇이며 어떻게 다른가요?">
    Agent에는 세 가지 최상위 모드가 있습니다. 전체 안내는 [Free 모드](/ko/help/free-agent-mode)를 참조하세요.

    * **Free 모드**—5시간마다 재설정되고 주간 한도가 있는 할당량 내에서 Core 및 Pro 구독자를 위한 비용이 들지 않는 일상적인 Agent 작업입니다. Starter 등급은 기존 한도를 유지합니다. 사용량을 확인하려면 **설정 → 사용량**을 확인하세요.
    * **Power**—합리적인 가격으로 강력한 모델을 제공하는 유료 중급 모드입니다.
    * **Max**—가장 까다로운 작업을 위한 최고의 프론티어 모델을 제공하는 유료 최상급 모드입니다.
    * **Turbo**—Max에서만 사용할 수 있는 고급 설정의 선택적 토글입니다.

    유료 모드의 이름이 변경되었습니다. **Economy는 이제 Power**가 되었고, 이전에 **Power라고 불렸던 모드는 이제 Max**가 되었습니다. 기존 모드 설정은 새 이름으로 그대로 유지됩니다. 요청에 Free 모드보다 더 많은 성능이 필요한 경우 Agent는 유료 **한 번 허용** 옵션을 제공할 수 있습니다. Replit은 유료 작업이 시작되기 전에 확인을 요청하며, 이후 Agent는 Free 모드로 돌아갑니다.

    별도로 [Plan 모드](/ko/features/agent/plan-mode)는 Agent가 변경을 하기 전에 작업 범위를 정할 수 있게 하고, Build 모드는 변경 사항을 직접 적용합니다. [Plan 모드 vs. Build 모드](/ko/learn/plan-vs-build-mode)를 참조하세요.
  </Accordion>

  <Accordion title="Agent가 원하지 않는 변경을 했어요. 어떻게 롤백하나요?">
    Replit은 Agent가 작업하는 동안 [체크포인트](/ko/features/version-control/checkpoints-and-rollbacks)를 저장합니다. Agent 채팅에서 실행 취소하고 싶은 변경 이전의 메시지를 찾아 옆에 있는 롤백 옵션을 선택하여 해당 시점으로 프로젝트를 복원하세요.

    특정 파일 복구를 포함한 전체 롤백 옵션은 [체크포인트 및 롤백](/ko/features/version-control/checkpoints-and-rollbacks)을 참조하세요.
  </Accordion>

  <Accordion title="Agent가 인터넷이나 외부 API에 접근할 수 없다고 해요. 정상인가요?">
    빌드 및 편집 단계에서 Agent는 제한된 아웃바운드 접근이 있는 샌드박스 환경에서 작동합니다. 게시된 앱은 실행될 때 외부 API 호출을 할 수 있습니다. 샌드박스는 실행 중인 앱이 아닌 Agent의 편집 환경에 적용됩니다.

    실행 중인 앱에서 API 호출이 실패하면 [Secrets](/ko/core-concepts/project-editor/app-setup/secrets) 패널에 키가 저장되어 있는지 확인하고 제공업체의 상태 페이지를 확인하세요. 회사 또는 학교 네트워크에서는 앱의 아웃바운드 연결이 차단될 수 있으므로 네트워크 관리자에게 문의하세요.
  </Accordion>

  <Accordion title="Agent에서 자체 API 키를 사용할 수 있나요?">
    네. [Secrets](/ko/core-concepts/project-editor/app-setup/secrets) 패널에 키를 추가하면 앱이 API 호출에 해당 키를 사용합니다. **Secrets** 도구를 열고 **+ 새 시크릿**을 선택한 다음 이름(예: `OPENAI_API_KEY`)과 값을 입력하세요.

    앱이 호출하는 모델에 [자체 AI 제공업체 키를 사용](/ko/features/integrations/replit-ai-integrations)할 수 있습니다. Agent 경험을 구동하는 모델 자체는 Replit의 인프라에서 실행되며 교체할 수 없습니다.
  </Accordion>

  <Accordion title="Agent가 요청하지 않은 기능을 계속 추가해요. 더 정확하게 작동하게 하려면 어떻게 하나요?">
    더 타이트한 프롬프트로 Agent에 집중하세요:

    * *Only*로 시작하세요. 예: "Only add a delete button to the user card. Don't change anything else."
    * [Plan 모드](/ko/features/agent/plan-mode)를 먼저 사용하여 Agent가 무엇을 할지 검토한 후 변경을 가하게 하세요.
    * Agent가 원하지 않는 변경을 했다면 같은 채팅에서 바로 해당 변경을 취소하도록 요청하세요.

    자세한 내용은 [효과적인 프롬프팅](/ko/learn/effective-prompting)을 참조하세요.
  </Accordion>
</AccordionGroup>
