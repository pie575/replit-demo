Skill 是包含可复用指令和支持文件的文件夹。使用 Skill 自定义 Replit 处理重复性任务、规则和工作流的方式。

在提示词输入框中选择 **plus** 菜单，然后选择 **Use a skill**。选择适合当前任务的 Skill，并告诉 Replit 你想要的结果。

  ## 选择合适的连接方式
</div>

* 对于可复用的说明、示例和参考资料，请使用 **Skill**。
* 对于受支持的服务及其经授权的信息或操作，请使用[集成](/zh/ko/chat/integrate-your-tools)。
* 对于由兼容的 MCP 服务器或客户端提供的工具，请使用[MCP](/zh/ko/chat/connect-through-mcp)。
