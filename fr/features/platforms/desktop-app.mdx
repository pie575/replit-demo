L'<a href="https://replit.com/desktop" target="_blank">application de bureau Replit</a> apporte l'expérience Replit complète sur votre ordinateur. Développez avec Agent dans une application dédiée, avec des fonctionnalités natives que vous n'obtenez pas dans un onglet de navigateur.

## Qu'est-ce que l'application de bureau Replit

L'application de bureau Replit est une application native repensée pour Windows et Mac. Elle offre la même expérience que sur le web, vous permettant de créer des applications, de discuter avec Agent et de publier, le tout depuis une seule fenêtre. En plus de cela, elle ajoute quelques fonctionnalités que seule une application de bureau peut offrir :

* **Multitâche** : Travaillez sur plusieurs applications Replit à la fois.
* **Signaux d'état** : Voyez d'un coup d'œil quand Agent a besoin de vous ou termine son travail.
* **Aperçus d'onglets** : Consultez vos applications ouvertes sans passer de l'une à l'autre.

## Premiers pas

<Steps>
  <Step title="Télécharger l'application">
    Accédez à la <a href="https://replit.com/desktop" target="_blank">page de téléchargement de l'application de bureau</a> et téléchargez la version pour votre ordinateur.
  </Step>

  <Step title="Installer et ouvrir">
    Ouvrez le fichier téléchargé et suivez les instructions pour l'installer. Lancez l'application lorsque l'installation est terminée.
  </Step>

  <Step title="Se connecter">
    Connectez-vous avec votre compte Replit, ou créez-en un si vous êtes nouveau. Tout ce que vous créez reste synchronisé avec [replit.com](https://replit.com).
  </Step>
</Steps>

<Tip>
  Vos applications, votre historique et vos paramètres sont identiques sur l'application de bureau et sur le web. Commencez quelque chose sur l'un et reprenez-le sur l'autre.
</Tip>

## Pour les équipes Enterprise

L'application de bureau facilite le déploiement de Replit dans votre organisation. Comme elle s'installe comme n'importe quelle autre application de bureau, votre équipe informatique peut la distribuer et l'installer automatiquement sur les ordinateurs de l'entreprise via votre fournisseur de gestion des appareils (MDM). Contactez votre responsable de compte pour en savoir plus.
