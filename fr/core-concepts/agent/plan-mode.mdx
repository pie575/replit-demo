Plan mode introduit une nouvelle façon de discuter avec Replit Agent, axée sur les questions, le brainstorming et la planification de votre travail.

## Qu'est-ce que Plan Mode ?

Plan mode vous permet de :

* **Brainstormer des idées** et explorer différentes approches de votre projet
* **Planifier le travail de développement** avec des listes de tâches structurées
* **Collaborer avec l'IA** sur l'architecture du projet et la planification des fonctionnalités
* **Obtenir des conseils stratégiques** et poser des questions sans modifier le code ou les données de votre projet
* **Passer de façon transparente** au mode Build quand vous êtes prêt à implémenter

Le mode par défaut est désormais appelé mode **Build**.

Contrairement au mode Build, Plan mode se concentre sur la planification et l'idéation, vous aidant à réfléchir aux projets avant d'écrire du code.

## Premiers pas

### Accéder à Plan Mode

Plan mode est disponible dans toute application Replit où Agent est activé. Pour y accéder :

1. **Ouvrez votre application Replit** dans le Project Editor
2. **Recherchez le sélecteur de mode** en bas à gauche de la zone de saisie du chat
3. **Choisissez Plan mode** dans le menu déroulant

## Fonctionnalités principales

### Planification des tâches

Plan mode excelle à décomposer des projets complexes en tâches gérables. Fournissez à Agent quelques exigences et il générera une liste de tâches ordonnée des tâches de développement nécessaires pour répondre à votre demande.

### Brainstorming collaboratif

Travaillez avec l'IA pour explorer différentes approches :

* **Plusieurs chemins de solution** pour les problèmes complexes
* **Analyse avantages/inconvénients** des différentes approches
* **Évaluation des risques** et stratégies d'atténuation

## Flux de travail : de la planification à la construction

### 1. Phase de planification (Plan Mode)

Commencez votre processus de développement en Plan mode :

* **Définissez la portée de votre projet** et vos objectifs
* **Décomposez les exigences** en fonctionnalités spécifiques
* **Planifiez votre architecture** et votre stack technologique
* **Créez une feuille de route de développement** avec des jalons

### 2. Approbation des tâches

Lorsqu'Agent génère une liste de tâches :

* **Examinez** les tâches proposées
* Sélectionnez **Commencer à construire** pour approuver le plan

ou continuez à discuter pour affiner le plan.

### 3. Passage au mode Build

Quand vous êtes prêt à commencer l'implémentation :

* **Cliquez sur « Commencer à construire »** pour approuver le plan
* **Agent passe automatiquement** au mode Build
* **Agent commence l'implémentation** des tâches approuvées
* **Suivez la progression** tout au long de la phase de développement

L'utilisation de Plan Mode suit la même tarification basée sur l'effort que les autres interactions Agent. Vous êtes facturé pour tout le travail d'Agent en Plan Mode, y compris les réponses aux questions, les conseils et la génération de listes de tâches. Les frais augmentent pour les demandes plus complexes ou dans des conversations avec un contexte plus long.

**Toutes les interactions Agent sont facturables** — qu'Agent réponde par des conseils textuels ou effectue des modifications de code, il y a toujours un coût, bien que les demandes plus petites coûtent moins cher.

## Cas d'utilisation

### Planification de fonctionnalités

Idéal pour ajouter de nouvelles fonctionnalités :

* **Décomposez les fonctionnalités complexes** en tâches implémentables
* **Planifiez les modifications de base de données** et les modifications d'API
* **Concevez l'interface utilisateur** et les flux d'expérience utilisateur
* **Considérez les cas limites** et la gestion des erreurs

## Bonnes pratiques

### Prompting efficace

Pour tirer le meilleur parti de Plan mode :

* **Soyez précis** concernant les exigences de votre projet
* **Posez des questions de suivi** pour clarifier les suggestions de l'IA
* **Demandez des exemples** lors de la discussion de concepts complexes
* **Discutez des compromis** entre différentes approches
* **Itérez sur les idées** avant de vous engager dans l'implémentation
* **Sauvegardez les décisions importantes** en les référençant dans des conversations de suivi
