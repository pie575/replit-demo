Replit MCP는 [Model Context Protocol](https://modelcontextprotocol.io/)을 사용하여, 이미 사용 중인 AI 도구에서 Replit App을 생성, 검색, 확인, 업데이트, 게시할 수 있게 해줍니다.

## MCP 클라이언트를 직접 연결하기

MCP 클라이언트에 Replit 네이티브 통합이 없는 경우 직접 연결을 사용하세요.

| 속성      | 값                                        |
| ------- | ---------------------------------------- |
| **URL** | `https://replit-mcp.com/server/mcp`      |
| **전송**  | Streamable HTTP                          |
| **인증**  | protected-resource discovery을 사용하는 OAuth |

Streamable HTTP와 OAuth 인가를 지원하는 MCP 클라이언트에 서버 URL을 추가하세요. 클라이언트는 Replit의 protected-resource 메타데이터를 읽습니다. 그런 다음 Replit 로그인을 요청합니다.

커스텀 OAuth 서버를 만들지 마세요. Replit MCP 서버가 클라이언트에 필요한 OAuth 메타데이터를 제공합니다.

앱을 새로 생성하거나, 편집 권한이 있는 앱(공유받은 앱 포함)을 다룰 수 있습니다.

## 도구

| 도구                        | 필수 입력                         | 선택 입력                                                                     | 용도                                                                                                                                                                                                                      |
| ------------------------- | ----------------------------- | ------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `create_app_from_prompt`  | `appDescription`, `app_stack` | `userSpecifiedAppName`, `userQuotes`, `attachmentSummary`, `sourceReplId` | 새 앱을 시작합니다. `app_stack`은 `react_website`, `mobile_app`, `design`, `slides`, `animation`, `data_visualization`, `3d_game`, `document`, `spreadsheet` 중 하나입니다. `sourceReplId`를 설정하면 새 앱을 빈 프로젝트가 아닌 기존 앱의 비공개 사본으로 시작합니다. |
| `search_apps`             | 없음                            | `query`, `url`, `updatedAfter`, `updatedBefore`, `limit`                  | 제목 키워드, URL, 또는 마지막 업데이트 시간으로 앱을 찾습니다. `limit`은 1부터 50까지입니다.                                                                                                                                                            |
| `resolve_app_by_name`     | `name`                        | 없음                                                                        | 정확한 제목으로 앱 하나를 찾습니다.                                                                                                                                                                                                    |
| `list_apps`               | 없음                            | `query`, `limit`                                                          | 편집 가능한 앱을 최근 활동 순으로 나열합니다. 기본 한도는 25이고 최대치는 50입니다.                                                                                                                                                                      |
| `ask_question`            | `replId`, `question`          | 없음                                                                        | 앱을 변경하지 않고 Agent에 앱에 대해 질문합니다.                                                                                                                                                                                          |
| `update_app_using_prompt` | `replId`, `changeDescription` | `userQuotes`, `attachmentSummary`                                         | 기존 앱에 대한 Agent 업데이트를 시작합니다.                                                                                                                                                                                             |
| `publish_app`             | `replId`                      | 없음                                                                        | 앱을 게시하거나 최신 변경 사항을 다시 게시합니다.                                                                                                                                                                                            |
| `get_publish_status`      | `replId`                      | 없음                                                                        | 앱이 게시되었는지 여부, 현재 게시 상태, 공개 URL을 확인합니다.                                                                                                                                                                                  |

## 문제 해결

| 문제                        | 해결 방법                                                                      |
| ------------------------- | -------------------------------------------------------------------------- |
| Replit이 인증을 요청함           | MCP 클라이언트에서 OAuth 로그인 흐름을 다시 완료하세요.                                        |
| 앱을 찾을 수 없음                | 해당 앱을 편집할 수 있는지 확인하세요. 그런 다음 URL로 검색하거나 `list_apps`를 사용해 일치하는 앱 중에서 선택하세요. |
| 생성, 업데이트, 게시 요청이 아직 실행 중임 | 재시도하기 전에 기다리세요. 게시의 경우 `get_publish_status`로 현재 결과를 확인하세요.                 |
