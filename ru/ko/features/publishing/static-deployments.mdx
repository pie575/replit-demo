Статический деплой размещает статические файлы Replit App, такие как HTML, CSS и JavaScript,
на облачных серверах. Серверы автоматически используют стратегии кэширования и масштабирования, чтобы
быстро и экономично доставлять контент.

Статический деплой идеально подходит для следующих сценариев:

* Маркетинговые лендинги
* Сайты-портфолио
* Сайты с документацией по продуктам и API

<Note>
  Статический деплой несовместим с Replit App, созданными с помощью Agent.
  Agent автоматически создает полнофункциональные приложения, которым требуется серверная часть. Для приложений,
  созданных Agent, используйте один из следующих типов деплоя: - [деплой Autoscale
  ](/ru/ko/features/publishing/autoscale-deployments) - [деплой Reserved VM
  ](/ru/ko/features/publishing/reserved-vm-deployments)
</Note>

<div id="section">
  ## Возможности
</div>

Статический деплой включает следующие возможности.

* **Экономичный хостинг**: вы платите только за объём данных, передаваемых вашим сайтом.
* **Настройка HTTP-маршрутизации**: настраивайте заголовки ответов, перезапись URL и перенаправления.
* **Пользовательские домены**: настройте пользовательский домен или используйте URL `<app-name>.replit.app` для доступа к приложению.
* **Пользовательские страницы ошибок**: создавайте и размещайте пользовательские страницы ошибок 404.
* **Мониторинг**: просматривайте журналы и отслеживайте состояние опубликованного приложения.

<div id="section-2">
  ## Использование
</div>

Статический деплой доступен в инструменте Publishing в Project Editor.

<Accordion title="Как получить доступ к статическому деплою">
  В левой **панели инструментов**:

  1. Выберите <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="иконка всех инструментов" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **Все инструменты**, чтобы открыть список инструментов Project Editor.
  2. Выберите <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="иконка Publishing" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publishing**.
  3. Выберите вариант **Static**, затем **Set up your published app**.

  В **строке поиска**:

  1. Вверху выберите <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="иконка лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> значок лупы, чтобы открыть поиск.
  2. Введите &quot;Publishing&quot;, найдите инструмент и выберите его в результатах поиска.
  3. Выберите вариант **Static**, затем **Set up your published app**.
</Accordion>

<div id="section-3">
  ### Основной домен
</div>

Укажите поддомен для опубликованного приложения. После публикации приложение будет доступно по адресу `https://<subdomain>.replit.app`.

Подробнее об использовании пользовательского домена см. в разделе [Пользовательские домены](/ru/features/publishing/custom-domains).

<div id="section-4">
  ### Приватный деплой
</div>

<Info>
  Функция приватной публикации App доступна на тарифах Pro и Enterprise.
</Info>

Приватные опубликованные App доступны только участникам вашего workspace, а также конкретным пользователям и группам, которых вы пригласите.
При публикации можно выбрать один из вариантов доступа: **Public**, **Password protected**, **Workspace only** или **Invite only**.

Подробнее о настройке приватного deployment см. в разделе [Доступ к App](/ru/features/publishing/private-deployments/).

<div id="section-5">
  ### Публичная директория
</div>

Укажите путь к каталогу в Replit App, содержащему статические файлы для общего доступа.
После деплоя облачный хост будет предоставлять все страницы и ресурсы из этого каталога.

Значение по умолчанию `/` — корневой каталог Replit App.

<div id="section-6">
  ### Команда сборки
</div>

При создании деплоя укажите команду сборки, которая будет выполняться в оболочке Replit App.

Например, если вы создаёте статический сайт с помощью <a href="https://gohugo.io/" target="_blank">Hugo</a>, команда `hugo --minify` создаст файлы и оптимизирует размер ресурсов.

<div id="section-7">
  ### Секреты деплоя
</div>

Чтобы добавить переменные окружения или секреты, необходимые для безопасного выполнения команды сборки, выберите **Добавить секрет деплоя**.

Например, если генератору сайта для создания статического сайта требуется API-ключ, его можно передать в формате `API_KEY=<имя секрета>`.
