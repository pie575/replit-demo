<div id="section">
  ## 什么是数据可视化？
</div>

数据可视化是一种可通过与 Agent 对话构建的交互式控制台或报告工具。只需说明您想要可视化的内容及数据位置，Agent 就会自动选择合适的 KPI、图表类型和布局，并根据一条提示词生成全面的控制台。

核心概念：

* **一键生成**：描述您的目标和数据源，Agent 会构建包含合适图表和指标的完整控制台
* **已连接的数据源**：从数据库、[数据仓库连接器](/zh/ja/connectors/warehouses/overview)、外部 API 或上传的文件中获取数据
* **内置功能**：所有控制台都包含刷新、自动刷新、导出为 PDF、将图表导出为 CSV，以及浅色/深色模式
* **分析摘要**：Agent 会根据您的请求和结果数据生成洞察
* **多个产物**：数据可视化可以与[同一项目](/zh/ja/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project)中的其他产物共享相同的后端和数据库

<div id="section-2">
  ## 如何使用数据可视化
</div>

<div id="section-3">
  ### 通过提示词创建
</div>

选择主页上的**应用**标签页，描述你想创建的控制台。Agent 会识别与数据相关的提示词，并选择相应的数据可视化技术栈。

**提示词示例：**

* “构建一个按区域跟踪销售额的销售分析控制台”
* “创建一个用于可视化月度指标的报告工具”
* “构建一个展示 BigQuery 销售数据中热门产品的控制台”
* “连接 Snowflake 并创建客户流失分析控制台”

<div id="section-4">
  ### 通过下拉菜单创建
</div>

1. 前往首页的**应用**标签页。
2. 打开应用类型下拉菜单。
3. 选择**数据可视化**。
4. 描述您要构建的控制台或数据工具。

<div id="section-5">
  ### 连接数据仓库
</div>

通过[数据仓库连接器](/zh/ja/connectors/warehouses/overview)将数据可视化连接到 BigQuery、Databricks 或 Snowflake，并基于现有数据集构建控制台。

查询数据仓库中的数据时，Agent 会使用并行多 Agent 搜索来探索架构和数据集。这可加快探索速度，帮助 Agent 为控制台选择合适的表和字段。

要开始使用，请在项目的[集成](/zh/ja/features/integrations/overview)中配置数据仓库连接器，并告诉 Agent 你想要可视化的内容。

<div id="section-6">
  ### 添加筛选器和功能
</div>

Agent 构建好控制台后，您可以通过提示词让它添加筛选器、下钻功能及其他交互功能。例如，您可以让 Agent 添加日期范围筛选器、区域选择器或搜索栏。

<div id="section-7">
  ### 导出与共享
</div>

* **导出为 PDF**：将整个控制台导出为 PDF，方便共享或离线查看。
* **将图表导出为 CSV**：将单个图表的数据下载为 CSV 文件，以便在电子表格或其他工具中进一步分析。
* **分析文档**：让 Agent 根据控制台数据创建详细的分析文档。

<div id="section-8">
  ## 可构建的内容
</div>

* **分析控制台**：跨不同时间段跟踪销售额、注册量、参与度等关键指标
* **报告工具**：构建内部报告，让利益相关者无需直接访问数据库即可筛选和探索数据
* **数据探索界面**：通过可视化反馈浏览和查询数据集
* **监控面板**：显示来自 API、数据库和外部服务的实时或近实时数据

<div id="section-9">
  ## 常见问题
</div>

<Accordion title="可以连接哪些数据源？">
  您可以从项目的 Replit 数据库、数据仓库连接器 (BigQuery、Databricks、Snowflake) 、外部 API 或 CSV 等已上传文件中获取数据。通过[集成](/zh/ja/features/integrations/overview)配置数据仓库连接。
</Accordion>

<Accordion title="可以自定义外观和设计吗？">
  可以。您可以通过对话自定义颜色、布局和排版 — 只需让 Agent 根据您的品牌进行调整，或修改设计即可。控制台还支持浅色和深色模式。
</Accordion>

<Accordion title="Agent 会分析数据吗？">
  构建控制台后，Agent 会根据您的请求和结果数据生成分析摘要。您还可以请求更详细的分析文档。
</Accordion>

<Accordion title="可以将数据可视化与其他产物类型结合使用吗？">
  可以。您可以在[同一项目](/zh/ja/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project)中，将数据可视化与 [Web 应用](/zh/ja/features/artifact-types/web-apps)、[幻灯片演示文稿](/zh/ja/features/artifact-types/slide-decks)及其他产物类型结合使用。它们共享同一个后端和数据库。
</Accordion>
