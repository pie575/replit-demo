Мы представили Velocity в разделе [Добро пожаловать в Replit](/ru/ja/build/welcome) — это App для аренды премиальных суперкаров. Сейчас любой, кто перейдёт по публичному URL, может просмотреть все бронирования. Никто не бронирует Lamborghini анонимно. Добавим вход в систему, чтобы у каждого клиента были собственные бронирования и сохранённые автомобили.

<div id="agent">
  ## Попросите Agent добавить вход в App
</div>

Для Velocity мы используем Clerk. Интеграция Clerk в Replit даёт фирменный экран входа для вашего App, клиентские аккаунты, которые живут внутри Velocity (а не учётные записи Replit), и полный контроль над внешним видом и удобством использования — как раз то, что нужно премиальному бренду проката. Agent настроит всё автоматически, так что регистрироваться в панели мониторинга Clerk и вставлять ключи не придётся.

<AiPrompt>
  Add sign-in to Velocity so each customer has their own bookings and saved cars.<br />
  Use Clerk Auth.<br />
  Keep the car-browsing pages public so visitors can still explore the fleet without an account.<br />
  Require sign-in before someone can reserve a car or save one to their favorites.<br />
  After sign-in, show the customer&#39;s name in the header and a &quot;My bookings&quot; section with only their reservations.<br />
  Add a sign-out button.<br />
  Give me a test checklist using two different customers.
</AiPrompt>

Agent создаст тенант Clerk для Velocity, добавит компоненты входа, закроет ими процесс бронирования, свяжет каждое бронирование с вошедшим клиентом и добавит выход из аккаунта. Ход сборки можно отслеживать в чате Agent.

<div id="2">
  ## Тестирование с двумя клиентами
</div>

Одного аккаунта недостаточно — чтобы убедиться, что бронирования изолированы друг от друга, нужны два аккаунта.

1. Откройте Velocity в Preview и просмотрите автомобили, не выполняя вход. Автопарк должен отображаться и без входа.
2. Нажмите «Reserve» у автомобиля. Должен открыться экран входа Clerk.
3. Зарегистрируйтесь со своим адресом электронной почты и завершите бронирование (например, забронируйте 911 на выходные).
4. Выйдите из аккаунта. Раздел «My bookings» должен исчезнуть, а процесс бронирования — снова потребовать входа.
5. Откройте Preview в окне инкогнито и зарегистрируйтесь с другим адресом электронной почты. Забронируйте другой автомобиль.
6. Вернитесь в первое окно, войдите в аккаунт и убедитесь, что отображаются только ваши бронирования, а бронирований второго клиента не видно.

Если оба клиента видят одни и те же бронирования, значит, бронирования пока не привязаны к вошедшему пользователю. Опишите Agent точные симптомы:

<AiPrompt>
  Both customers can see each other&#39;s reservations in Velocity.<br />
  Attach each booking and each saved car to the signed-in customer so each person only sees their own.<br />
  Show me how to verify it with two test accounts.
</AiPrompt>

<div id="url">
  ## Опубликуйте приложение и войдите по публичному URL
</div>

Снова опубликуйте Velocity через чат Agent или плитку Publishing, затем откройте публичный URL в новой вкладке и войдите. Clerk отдельно подготавливает среды Development и Production — Agent автоматически настраивает учетные данные Production для опубликованного App, поэтому вход по публичному URL сразу работает.

У Velocity появились настоящие клиенты. Каждый из них может войти в свой личный гараж бронирования, недоступный другим.

<div id="section-2">
  ## Если вам нужна дополнительная помощь
</div>

* **Всё App скрыто:** Попросите Agent оставить просмотр автомобилей общедоступным и защитить только страницы бронирования и аккаунта.
* **Клиенты видят бронирования друг друга:** Попросите Agent связать каждое бронирование и сохранённый автомобиль с вошедшим в систему клиентом.
* **В Preview вход работает, но после публикации — нет:** Откройте публичный URL в новой вкладке и сообщите Agent точный текст ошибки. Убедитесь, что Agent подготовил среду Production Clerk.
* **Для прототипов нужен быстрый вход без настройки:** Replit Auth использует учётные записи Replit ваших клиентов и не требует управляемого вами тенанта Clerk — см. [Replit Auth](/ru/ja/features/auth-and-identity/authentication).
