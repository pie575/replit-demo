Эти ответы относятся к продакшен-базе данных. Полную справочную информацию см. в разделах [Продакшен-базы данных](/ru/features/data-and-storage/development-and-production) и [SQL-база данных](/ru/features/data-and-storage/sql-database).

<AccordionGroup>
  <Accordion title="Эндпоинты моей базы данных отключены — как исправить ошибку &#x22;endpoint has been disabled&#x22;?">
    Эта ошибка означает, что вычислительный эндпоинт базы данных приостановлен. Чтобы возобновить его работу:

    1. Откройте панель **База данных** и выберите в раскрывающемся списке **Разработка**.
    2. Если появится кнопка **Возобновить базу данных**, нажмите её.
    3. Переключитесь в раскрывающемся списке на **Продакшен** и снова нажмите **Возобновить базу данных**, если кнопка появится.

    Если кнопка не появляется, её может скрывать конфликтующий секрет `DATABASE_URL`. Откройте панель **Secrets**, сравните значение `DATABASE_URL` со строкой подключения на панели **База данных** и обновите или удалите конфликтующий секрет, чтобы они совпадали.

    Распространённые причины: неоплаченный счёт (оплатите его, чтобы проблема не повторилась) или временная приостановка во время публикации (её устранят описанные выше действия). См. [Продакшен-базы данных](/ru/features/data-and-storage/development-and-production).
  </Accordion>

  <Accordion title="На странице статуса указано, что продакшен-база данных недоступна — нужно ли создавать обращение?">
    Нет. Если сбой уже указан на [status.replit.com](https://status.replit.com), команда уже работает над ним, и обращение не ускорит исправление. Откройте активный инцидент и подпишитесь на обновления, чтобы получать уведомления о ходе работ.

    Если проблема с вашей базой данных *не* указана на странице статуса, [обратитесь в поддержку Replit](https://replit.com/support).
  </Accordion>

  <Accordion title="Как восстановить удалённую таблицу базы данных?">
    Replit поддерживает восстановление на определённый момент времени для продакшен-баз данных. Период восстановления зависит от вашего тарифа: 7 дней на [Core](/ru/billing/plans/replit-core) и 28 дней на [Pro](/ru/billing/plans/replit-pro).

    Чтобы восстановить данные, откройте панель **База данных**, перейдите к нужной базе данных, откройте её настройки восстановления, выберите нужную временную метку и подтвердите действие. Если период восстановления уже истёк, [обратитесь в поддержку Replit](https://replit.com/support). См. [Продакшен-базы данных](/ru/features/data-and-storage/development-and-production).
  </Accordion>

  <Accordion title="Моя база данных приостановлена, и я не вижу кнопки «Возобновить»">
    Конфликтующий URL базы данных обычно скрывает кнопку **Возобновить**. Откройте панель **Secrets**, найдите значение `DATABASE_URL` и сравните его со строкой подключения на панели **База данных**. Если они различаются, секрет переопределяет правильный URL — удалите его, обновите страницу и снова проверьте панель **База данных**.

    Если кнопка всё ещё не появляется после удаления конфликтующего секрета, [обратитесь в поддержку Replit](https://replit.com/support), указав URL вашего проекта.
  </Accordion>

  <Accordion title="Моё приложение выдаёт ошибки &#x22;connection pool exhausted&#x22; — что это означает?">
    Ваше приложение одновременно открывает больше подключений к базе данных, чем допускает пул. Распространённые причины:

    * Подключения не закрываются после каждого запроса
    * Всплеск трафика
    * Медленные запросы, удерживающие подключения открытыми

    Большинство фреймворков предполагают использование одного общего пула подключений вместо создания нового подключения для каждого запроса.

    Чтобы быстрее устранить проблему, откройте новый чат с Agent, опишите ошибку и попросите Agent проверить, как ваше приложение управляет подключениями к базе данных.
  </Accordion>

  <Accordion title="Как выполнить миграцию из базы данных для разработки в продакшен?">
    Replit разделяет базы данных для разработки и продакшен-базы данных, чтобы тестовые изменения не затрагивали рабочие данные. Чтобы запускать миграции в продакшене, добавьте команду миграции на этап сборки или перед развёртыванием deployment, чтобы она выполнялась при каждом развёртывании. Например, для Drizzle используйте `drizzle-kit migrate`. Вы также можете запустить миграцию вручную из Shell в среде продакшена.

    См. [Создание продакшен-базы данных при публикации](/ru/features/data-and-storage/development-and-production).
  </Accordion>

  <Accordion title="Моя база данных показывает &#x22;endpoint disabled&#x22;, хотя биллинг в порядке">
    Иногда это происходит независимо от биллинга. Попробуйте возобновить работу вручную: откройте панель **База данных**, выберите **Разработка** и нажмите **Возобновить базу данных**, если кнопка появится, затем повторите то же для **Продакшен**.

    Если кнопка не появляется или проблема повторяется, [обратитесь в поддержку Replit](https://replit.com/support), указав URL вашего проекта, — может потребоваться ручное возобновление работы. См. [Продакшен-базы данных](/ru/features/data-and-storage/development-and-production).
  </Accordion>
</AccordionGroup>
