### Agent a maintenant accès à la documentation Replit

Agent peut désormais répondre instantanément à vos questions sur les fonctionnalités et la documentation Replit. Avec un accès direct à l'ensemble de la documentation Replit, Agent fournit une aide rapide, précise et complète directement là où vous codez.

### Nouveau panneau de base de données

Bénéficiez d'une gestion de base de données plus claire avec notre panneau de base de données repensé. La nouvelle interface facilite la distinction entre les bases de données de développement et de production, rationalisant votre flux de travail de base de données.

### Basculement de thème dans le menu déroulant d'avatar

Passez instantanément du thème clair au thème sombre grâce au nouveau bouton de basculement de thème, pratiquement situé dans votre menu déroulant d'avatar.

### Amélioration du sélecteur de couleur de l'éditeur visuel

Profitez d'une expérience d'édition des couleurs plus fluide dans l'éditeur visuel d'Agent. Cliquer sur les saisies hexadécimales des couleurs ouvre désormais automatiquement la fenêtre contextuelle du sélecteur de couleur pour une sélection de couleurs sans effort.
