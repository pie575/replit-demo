<div id="replitmd">
  ### Документация replit.md
</div>

Настраивайте поведение Agent с помощью `replit.md`. Этот специальный файл конфигурации помогает Agent разобраться в настройках по умолчанию, стиле кода и архитектуре вашего проекта. Agent автоматически создаёт этот файл на основе проверенных лучших практик, а затем использует его, чтобы создавать приложения в точном соответствии с вашими требованиями. Задавайте Agent контекст проекта, определяйте стандарты написания кода, указывайте предпочитаемый стек технологий и настраивайте формат общения — всё в одном месте.

<div id="section-3">
  ### Индикатор приватности развёртывания
</div>

Новый визуальный индикатор на панели развёртываний позволяет быстро понять, публичное развёртывание или приватное. Это улучшение помогает избежать путаницы и точно знать, у кого есть доступ к развёрнутому приложению.

<div id="agent">
  ### Улучшение множественных вызовов инструментов в Agent
</div>

Усовершенствованная система множественных вызовов инструментов позволяет сократить расходы на Agent на 15% и получать результаты на 30% быстрее. Теперь Agent эффективнее объединяет задачи в пакеты и грамотнее обрабатывает ошибки инструментов, обеспечивая тот же уровень качества при меньшем расходе ресурсов.
