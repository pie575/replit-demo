---

Le Shell vous permet de travailler dans vos projets comme dans un terminal classique, afin de gérer des fichiers,
d’installer des paquets et d’exécuter des scripts. Par exemple, vous pouvez parcourir les fichiers du projet ou
utiliser `psql` lorsque votre projet est configuré avec une connexion à une base de données.

<Tip>
  Pour mieux gérer vos workflows, privilégiez le bouton **Run** plutôt que
  d’exécuter votre application depuis le Shell. Le workflow lancé avec le bouton
  **Run** envoie la sortie vers l’outil Console, qui permet de consulter les log de manière
  structurée.
</Tip>

<div id="recursos">
  ## Fonctionnalités
</div>

Le Shell offre les fonctionnalités suivantes :

* **Exécuter plusieurs shells** : ouvrez plusieurs instances du Shell pour travailler simultanément sur différentes tâches
* **Rechercher du texte** : recherchez du texte spécifique dans la sortie du Shell

<div id="confirmar-acesso-ao-shell">
  ### Vérifier l’accès au Shell
</div>

Pour vérifier que le Shell est prêt et afficher l’espace de travail actuel, exécutez :

```sh theme={null}
pwd
```

Le Shell affiche le chemin de l’espace de travail actuel.

<Frame caption="La commande pwd affiche le chemin de l’espace de travail actuel et revient à l’invite du Shell.">
  <img src="/assets/mirror/shell-pwd-output-2d31a0e0466b.jpg" alt="Onglet Shell affichant la commande pwd, le chemin de l’espace de travail en sortie et le retour à l’invite de commande" width="1280" height="246" data-path="images/workspace/shell-pwd-output.jpg" />
</Frame>

Pour un projet avec une base de données, sélectionnez **Tools** → **Database**, puis ouvrez la page
**Development database**. Cette page fournit les paramètres de connexion. Gardez les
informations de connexion privées ; ne les copiez pas dans la documentation, les captures d’écran,
les logs, les fichiers de code source ou les messages partagés.

<div id="pesquisa-de-texto">
  ### Recherche de texte
</div>

Les étapes suivantes expliquent comment accéder à l’outil de recherche de texte et l’utiliser :

1. Sélectionnez la <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="icône de loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> loupe dans l’angle supérieur droit de l’onglet Shell pour ouvrir la boîte de dialogue de recherche.
2. Saisissez un terme de recherche et sélectionnez **Next** pour parcourir les occurrences.
3. Utilisez **Previous** pour revenir aux occurrences précédentes.
4. Sélectionnez **Exit** ou cliquez en dehors de la boîte de dialogue pour quitter la recherche de texte.

<div id="mltiplos-shells">
  ### Plusieurs shells
</div>

Pour créer un autre shell :

1. Dans l’en-tête du panneau Shell, sélectionnez le menu des instances Shell.
2. Sélectionnez **New Shell**.

<Frame>
  <img src="/assets/mirror/shell-new-94a280c1230f.png" alt="Menu des instances Shell avec l’espace de travail actuel et l’option New Shell" width="1280" height="224" data-path="images/workspace/shell-new.png" />
</Frame>

Utilisez ce même menu pour passer d’un shell à l’autre. Replit identifie chaque shell par la dernière commande exécutée afin de vous aider à les distinguer.

<Warning>
  Lorsque vous ouvrez plusieurs shells, Replit ferme automatiquement les
  instances de shell inactives. Un shell est inactif s’il n’est pas
  sélectionné et n’exécute aucun processus utilisateur.
</Warning>
