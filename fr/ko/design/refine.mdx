Explorez largement, puis affinez en profondeur. Lorsque votre frame se rapproche du résultat souhaité, deux outils vous permettent de le peaufiner selon votre façon de travailler :

* Échangez avec Agent dans vos propres mots, qu’il s’agisse de l’ensemble de la frame ou d’un seul élément
* Ajustez directement les éléments avec Visual Editor. Les modifications simples ne consomment pas de crédits et s’appliquent immédiatement

<div id="section">
  ## Chat
</div>

Briefez Agent comme vous briefteriez un designer lors d&#39;une revue intermédiaire. Sélectionnez un frame et décrivez les modifications dans le chat principal (*« des couleurs plus chaudes »*, *« le hero paraît vide »*), ou choisissez l&#39;outil **Chat** dans la barre d&#39;outils, puis cliquez sur un élément pour restreindre la portée de votre message à cette partie.

  <img src="/assets/mirror/chatbox-9baff03cb443.png" alt="Frame Design sélectionné sur le canvas (Configurator First), avec le panneau de chat principal à gauche et la puce Configurator First jointe dans la zone de message affichant « Describe what you want to design… »" width="2000" height="1250" data-path="images/design/replit-design/chatbox.png" />
</Frame>

Pour ces deux points d&#39;entrée, consultez [Chat](/fr/ko/design/chat-about-your-design).

<div id="visual-editor">
  ## Visual Editor
</div>

Si vous savez exactement ce que vous voulez, passez directement à l’édition. Sélectionnez l’outil **Edit** dans la barre d’outils, puis cliquez sur un élément pour ouvrir Visual Editor avec ses propriétés modifiables (contenu, disposition, couleurs, bordures, etc.). Les modifications simples, comme modifier du texte, choisir des couleurs ou ajuster l’espacement, ne consomment pas de crédits et sont immédiatement appliquées au code source.

<Frame caption="Visual Editor montrant l’outil Edit activé et les propriétés modifiables lorsqu’un élément est sélectionné.">
  <img src="/assets/mirror/visual-editor-edit-tool-71d03803471f.png" alt="Frame du configurateur de supercar avec l’outil Edit activé et un élément sélectionné, panneau Visual Editor à droite avec les sections Layout, Color et Border, ainsi que les boutons Discard et Save edits" width="2000" height="1250" data-path="images/replitai/visual-editor-edit-tool.png" />
</Frame>

Pour consulter l’ensemble des contrôles, consultez [Visual Editor](/fr/ko/design/visual-editor).

<div id="section-2">
  ## Que choisir
</div>

| Ce que vous souhaitez faire…                                                                                     | Outil à utiliser |
| ---------------------------------------------------------------------------------------------------------------- | ---------------- |
| Décrire un résultat et laisser Agent s&#39;occuper des détails                                                   | Chat             |
| Modifier le texte, la couleur, l&#39;espacement ou l&#39;image d&#39;un seul élément à partir de valeurs connues | Visual Editor    |
| Revoir la structure ou le comportement d&#39;une section                                                         | Chat             |
| Faire des ajustements rapides sans consommer de crédits                                                          | Visual Editor    |

Les deux approches se complètent naturellement. Donnez la direction générale dans le chat, puis peaufinez les détails avec le Visual Editor.

  ## Étapes suivantes
