Replit Design est l&#39;espace où vous définissez l&#39;apparence et l&#39;expérience de vos logiciels. Décrivez ce que vous souhaitez, et Replit Design génère des maquettes interactives que vous pouvez explorer et affiner. Une fois le résultat souhaité obtenu, il devient une application fonctionnelle dans le même projet.

<div id="section">
  ## Commencer de zéro ou importer un design existant
</div>

Commencez dans [Replit Design](https://replit.com/design) ou sélectionnez **Design** sous le champ de création sur la page d’accueil de l’espace de travail. Quatre façons de commencer :

* **[Prompt](/fr/ko/design/design-your-first-screen)** : décrivez ce que vous souhaitez et générez votre premier frame.
* **[Template](/fr/ko/design/start-from-a-template)** : partez d’une landing page, d’une affiche, d’une publication sur les réseaux sociaux, d’un écran mobile ou d’un prototype prédéfini, puis remixez-le.
* **[Importer](/fr/ko/design/import-figma-designs-into-replit-design)** : importez un design depuis Figma ou [Claude](/fr/ko/design/import-claude-designs-into-replit-design), ou recréez un site à partir d’une [URL](/fr/ko/design/import-a-website-into-replit-design) ou d’une capture d’écran.
* **[Système de design](/fr/ko/design/design-systems-explained)** : partez d’un système enregistré pour créer un premier frame aux couleurs de votre marque.

<div id="section-2">
  ## Explorez différentes variantes
</div>

Explorez plusieurs pistes avant de vous décider. Chaque résultat apparaît dans un nouveau frame, ce qui vous permet de garder le cap.

* **[Suggestions](/fr/ko/design/explore-suggestions)** : sélectionnez un frame et Replit Design vous suggère des pistes à essayer. Un seul clic suffit.
* **[Autres modèles](/fr/ko/design/explore-with-different-models)** : changez le modèle qui alimente Design et envoyez-lui le même brief pour explorer des directions totalement différentes.

<div id="section-3">
  ## Affiner
</div>

Affinez votre création pour lui donner un aspect naturel :

* **[Chat](/fr/ko/design/chat-about-your-design)** : décrivez votre demande à Agent avec vos propres mots, pour l’ensemble du Canvas ou pour un frame à la fois.
* **[Visual Editor](/fr/ko/design/visual-editor)** : cliquez sur n’importe quel élément pour ajuster directement le texte, les couleurs, l’espacement et les images. Les modifications simples ne consomment pas de crédits et sont immédiatement appliquées au code source.
* **[Dessin](/fr/ko/design/toolbar#draw)** : entourez les zones problématiques, dessinez des flèches vers les éléments concernés et laissez des notes autocollantes. Agent lit les annotations.
* **[Générer des assets](/fr/ko/design/toolbar#generate)** : créez les images, clips vidéo et graphiques vectoriels nécessaires à votre design en joignant des références correspondant à l’apparence de votre projet.

<div id="section-4">
  ## Créer une application
</div>

Une fois votre frame prête, passez-la à Agent. Ici, votre design n’est pas une simple image : il constitue les spécifications d’un véritable logiciel.

* **[Créer une application à partir de votre design](/fr/ko/design/build-your-design)** : transformez votre frame en une nouvelle application fonctionnelle.
* **[Restyler une application existante](/fr/ko/design/frames#build)** : appliquez l’apparence de votre frame à une application existante.

<Frame caption="Action Build dans la barre d’actions d’une frame sélectionnée.">
  <img src="/assets/mirror/build-design-c5093018b02b.png" alt="Barre d’actions d’une frame sélectionnée avec les actions Build et Focus" width="1124" height="326" data-path="images/design/replit-design/build-design.png" />

</Note>

<div id="section-5">
  ## Aller plus loin
</div>

Créez votre prochain design encore plus rapidement :

* **[Créer un système de design](/fr/ko/design/create-a-design-system)** : extrayez les couleurs, la typographie, les jetons et les composants d’un design qui vous plaît, ou créez-en un de A à Z avec un prompt.
* **Démarrer un nouveau travail à partir de là** : les nouveaux artefacts sont créés aux couleurs de votre marque dès le premier frame.
* **[Intégrer une app existante au système](/fr/ko/design/apply-design-system)** : recréez le style d’une app existante pour que tout soit cohérent.
* **Changer de système** : sélectionnez ou modifiez le système pour chaque projet.

À partir de là, le parcours revient à **Commencer**, et tous les designs sont désormais créés aux couleurs de votre marque.

<div id="design-build">
  ## Quand commencer avec Design ou Build
</div>

Design et Build sont deux points d’entrée vers un même projet. Build est l’endroit où Agent rend le logiciel fonctionnel, tandis que Design permet d’en créer l’apparence. Vos créations ne restent pas confinées à l’outil de conception.

* Si l’apparence est l’aspect le plus complexe, commencez dans **Design** : explorez d’abord différentes pistes, puis implémentez celle que vous retenez dans Build.
* Si le comportement est l’aspect le plus complexe, commencez dans **Build** : rendez-le d’abord fonctionnel, puis retravaillez son style dans Replit Design.
