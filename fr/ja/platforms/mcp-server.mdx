Replit MCP s&#39;appuie sur le [Model Context Protocol](https://modelcontextprotocol.io/) pour vous permettre de créer, rechercher, consulter, mettre à jour et publier des Replit Apps directement depuis les outils d&#39;IA que vous utilisez déjà.

<div id="mcp">
  ## Connecter directement un client MCP
</div>

Si votre client MCP ne dispose pas d&#39;une intégration native à Replit, utilisez une connexion directe.

| Propriété            | Valeur                                  |
| -------------------- | --------------------------------------- |
| **URL**              | `https://replit-mcp.com/server/mcp`     |
| **Transport**        | Streamable HTTP                         |
| **Authentification** | OAuth avec protected-resource discovery |

Ajoutez l&#39;URL du serveur à un client MCP prenant en charge Streamable HTTP et l&#39;autorisation OAuth. Le client lit les métadonnées protected-resource de Replit, puis vous invite à vous connecter à Replit.

Ne créez pas de serveur OAuth personnalisé : le serveur MCP Replit fournit au client les métadonnées OAuth nécessaires.

Vous pouvez créer une nouvelle application ou travailler sur les applications pour lesquelles vous disposez de droits de modification (y compris celles qui sont partagées avec vous).

</div>

Codex et Claude Code ne sont que des exemples : vous pouvez ajouter Replit MCP à n&#39;importe quel client MCP compatible.

<div id="section">
  ## Outils
</div>

| Outil                     | Entrées requises              | Entrées facultatives                                      | Utilisation                                                                                                                                                                                               |
| ------------------------- | ----------------------------- | --------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `create_app_from_prompt`  | `appDescription`, `app_stack` | `userSpecifiedAppName`, `userQuotes`, `attachmentSummary` | Démarre une nouvelle App. `app_stack` prend l&#39;une des valeurs suivantes : `react_website`, `mobile_app`, `design`, `slides`, `animation`, `data_visualization`, `3d_game`, `document`, `spreadsheet`. |
| `search_apps`             | aucune                        | `query`, `url`, `updatedAfter`, `updatedBefore`, `limit`  | Recherche des Apps par mot-clé dans le titre, par URL ou par date de dernière modification. `limit` va de 1 à 50.                                                                                         |
| `resolve_app_by_name`     | `name`                        | aucune                                                    | Recherche une App unique d&#39;après son titre exact.                                                                                                                                                     |
| `list_apps`               | aucune                        | `query`, `limit`                                          | Liste les Apps modifiables, classées par activité récente. La limite par défaut est de 25, le maximum de 50.                                                                                              |
| `ask_question`            | `replId`, `question`          | aucune                                                    | Pose une question à l&#39;Agent au sujet d&#39;une App, sans la modifier.                                                                                                                                 |
| `update_app_using_prompt` | `replId`, `changeDescription` | `userQuotes`, `attachmentSummary`                         | Lance une mise à jour d&#39;une App existante par l&#39;Agent.                                                                                                                                            |
| `publish_app`             | `replId`                      | aucune                                                    | Publie une App ou republie les dernières modifications.                                                                                                                                                   |
| `get_publish_status`      | `replId`                      | aucune                                                    | Vérifie si une App est publiée, son statut de publication actuel et son URL de publication.                                                                                                               |

<div id="section-2">
  ## Dépannage
</div>

| Problème                                                                        | Solution                                                                                                                                                 |
| ------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Replit demande une authentification                                             | Effectuez de nouveau le flux de connexion OAuth depuis votre client MCP.                                                                                 |
| L&#39;app est introuvable                                                       | Vérifiez que vous avez le droit de modifier cette app. Recherchez-la ensuite par URL ou utilisez `list_apps` pour sélectionner l&#39;app correspondante. |
| Une requête de création, de mise à jour ou de publication est toujours en cours | Patientez avant de réessayer. Pour la publication, consultez le résultat actuel avec `get_publish_status`.                                               |
