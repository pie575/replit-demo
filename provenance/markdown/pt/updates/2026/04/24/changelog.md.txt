## Plataforma

### Security Agent revisa toda a sua base de código

O **Security Agent** é um novo revisor com inteligência artificial que audita não apenas suas dependências, mas todo o seu projeto. Ele cria um modelo de ameaças, mapeia suas rotas e fluxos de dados, executa análise estática com Semgrep e HoundDog.ai e usa um LLM para decidir quais descobertas são realmente exploráveis no contexto do seu app. Quando a revisão termina, o Security Agent organiza as descobertas aceitas em tarefas paralelas que o Replit Agent pode corrigir em uma única passagem.

O Security Agent está disponível para todos os builders pagos. Abra o painel **Segurança** no seu projeto e selecione **Executar Scan com Agent** para experimentar.

Saiba mais sobre o [Security Agent](/pt/core-concepts/security/project-security-center#agent-security-scans).

### CVE Auto-Protect corrige vulnerabilidades críticas automaticamente

Quando um novo CVE crítico é divulgado para um pacote do qual seu app depende, o **CVE Auto-Protect** detecta a correspondência em todos os projetos que você possui, faz com que o Agent prepare um patch em uma tarefa em segundo plano, executa seus testes para garantir que nada quebre e notifica você com um link para revisão. Você mantém o controle — nada é publicado até você aprovar a correção.

Isso significa que seus apps podem ser corrigidos em minutos após uma nova vulnerabilidade se tornar pública, em vez de esperar você notar.

Saiba mais sobre o [CVE Auto-Protect](/pt/core-concepts/security/project-security-center#auto-protect).

## Workspace

### Prévia em um iOS Simulator ou Android Emulator

<Frame>
  <video autoPlay muted loop playsInline src="https://cdn.replit.com/sanity/ios-emulator.mp4" />
</Frame>

Quando seu projeto inclui um app mobile, o painel de Prévia agora pode transmitir um **iOS Simulator** ou **Android Emulator** real diretamente para o seu workspace. Sem Xcode, sem Android Studio e sem dispositivo físico necessário. Crie um app mobile com o Agent, escolha seu dispositivo no menu suspenso do painel de Prévia e interaja como se tivesse o telefone na mão. As edições recarregam instantaneamente no simulador conforme o Agent as realiza.

Disponível para builders pagos nos planos Core, Pro e Enterprise, nos navegadores Chrome, Safari e baseados em Chromium. O Firefox não é compatível com simuladores mobile.

Saiba mais sobre [prévia em um simulador ou emulador](/pt/replitai/building-mobile-apps#preview-on-a-simulator-or-emulator).

## Agent

### Adicione um app mobile a projetos mais antigos

<Frame>
  <img src="https://mintcdn.com/replit/PUjTWRdx_TNp0SaN/images/replitai/multi-artifact-update-approval.png?fit=max&auto=format&n=PUjTWRdx_TNp0SaN&q=85&s=952936728a532ab0241de383ddcd0172" alt="Painel de chat do Agent mostrando o cartão de aprovação 'Atualizar projeto para criar app mobile' com uma oferta de crédito de $5 e botões Agora não / Atualizar projeto." width="991" height="589" data-path="images/replitai/multi-artifact-update-approval.png" />

Projetos criados antes do lançamento do Agent 4 agora podem ser atualizados para suportar múltiplos artifacts — o que significa que você pode adicionar um app mobile, um pitch deck ou outro artifact a um projeto que antes suportava apenas um. O Agent preserva sua URL, dados, secrets e deployment ao reorganizar o projeto. Mais de 200 projetos foram migrados nas primeiras 48 horas após o lançamento mais amplo.

Saiba mais sobre [como atualizar projetos mais antigos para suporte a múltiplos artifacts](/pt/replitai/updating-projects-for-multiple-artifacts).

## Integrações

### Conector Plaid disponível

Agora você pode se conectar a mais de 12.000 instituições financeiras com o conector **Plaid**. Os administradores de equipe configuram as credenciais uma vez em **Integrações**, e os usuários do seu app autenticam suas próprias contas bancárias pelo Plaid Link. Os tokens de acesso têm escopo por usuário, portanto os dados permanecem privados.

Crie um coach de finanças pessoais que trabalha com dados reais de transações, um rastreador de portfólio ao vivo conectado à sua corretora e muito mais. Confira a [página parceira Replit x Plaid](https://replit.com/partners/plaid) para demonstrações e etapas de configuração.

Saiba mais sobre [como gerenciar conectores](/pt/replitai/managing-connectors).
