Сканирование безопасности Agent проверяет всю кодовую базу на наличие уязвимостей в области безопасности и конфиденциальности. Security Agent сочетает анализ на основе моделей со статическими инструментами анализа, такими как [Semgrep](https://semgrep.dev/) и [HoundDog.ai](https://hounddog.ai), а затем отображает результаты в Project Security Center.

Сканирование безопасности Agent доступно всем разработчикам Replit с платной подпиской. Для крупных проектов углублённая проверка может занять до 15 минут.

<div id="security-agent">
  ## Что проверяет Security Agent
</div>

При запуске сканирования Security Agent выполняет следующее:

1. Сопоставляет маршруты, API, потоки данных и точки входа.
2. Создаёт модель угроз для приложения.
3. Выполняет статический анализ всей кодовой базы.
4. Оценивает выявленные проблемы в контексте приложения.
5. Формирует отчёт о выявленных проблемах для проверки.

Эта проверка может выявить небезопасные паттерны кода, такие как SQL-инъекции, межсайтовый скриптинг и подделка межсайтовых запросов, проблемы конфиденциальности, например передачу чувствительных данных в журналы или сторонние API, а также архитектурные уязвимости в маршрутах, API и потоках данных.

<div id="agent">
  ## Начало работы со сканированием безопасности с Agent
</div>

<Steps>
  <Step title="Откройте Security Center">
    В панели **Tools** проекта выберите **Security Center**. Также можно выбрать **Review security** в процессе Publish.

    <Frame>
      <img src="/assets/mirror/review-security-button-9331149c28f7.png" alt="Действие Review security в процессе Publish" width="1440" height="900" data-path="images/project-security-center/review-security-button.png" />
    </Frame>
  </Step>

  <Step title="Запустите сканирование">
    Выберите **Run scan with Agent**.

    <Frame>
      <img src="/assets/mirror/run-scan-with-agent-f54820ac154a.png" alt="Действие Run scan with Agent в Project Security Center" width="1440" height="900" data-path="images/project-security-center/run-scan-with-agent.png" />
    </Frame>
  </Step>

  <Step title="При необходимости добавьте контекст">
    При необходимости добавьте контекст, чтобы модель угроз сосредоточилась на определённых областях приложения, затем запустите сканирование безопасности.

    <Frame>
      <img src="/assets/mirror/scan-options-c2cd398fa78b.png" alt="Параметры сканирования безопасности с полем Add context и действием Start security scan" width="1440" height="900" data-path="images/project-security-center/scan-options.png" />
    </Frame>
  </Step>

  <Step title="Дождитесь завершения проверки">
    Дождитесь, пока Security Agent завершит проверку. Обычно это занимает несколько минут, но для крупных проектов может потребоваться до 15 минут.
  </Step>
</Steps>

<div id="section">
  ## Проверка и устранение выявленных проблем
</div>

<Steps>
  <Step title="Проверьте отчёт">
    В **Security Center** просмотрите каждую выявленную проблему и её уровень серьёзности. Понятные
    и приемлемые проблемы можно проигнорировать или устранить перед отправкой запроса на исправление.
  </Step>

  <Step title="Устраните подтверждённые проблемы с помощью Agent">
    Отправьте подтверждённые проблемы в Agent. Security Agent разбивает уязвимости на отдельные
    задачи, поэтому Agent может одновременно выполнять несколько исправлений.
  </Step>

  <Step title="Повторно запустите сканирование">
    После того как Agent применит исправления, повторно запустите сканирование, чтобы
    убедиться, что проблемы устранены. В крупных проектах после устранения проблем высокой
    серьёзности могут обнаружиться дополнительные проблемы.
  </Step>
</Steps>

<div id="level-3">
  ## Когда использовать Level 3
</div>

Сканирование безопасности Agent проверяет исходный код. Если нужно также проверить работающее приложение посредством взаимодействия с браузером и сетью, используйте [тестирование на проникновение методом «чёрного ящика» Level 3](/ru/ko/features/security/black-box-pen-tests). Level 3 одновременно выполняет тестирование методом «чёрного ящика» и проверку исходного кода.

<div id="section-2">
  ## Ограничения и рекомендации
</div>

* Сканирование выполняется в инфраструктуре Replit. Replit не передаёт ваш код или данные Semgrep, HoundDog.ai или другим третьим сторонам.
* Конфигурация и результаты сканирования остаются привязанными к вашему Replit App.
* Сканирование не заменяет комплексную проверку безопасности. Используйте его вместе с проверкой кода, тестированием, проверкой зависимостей и проверкой работающего приложения.
* Повторно запускайте сканирование после существенных изменений в коде, добавления или обновления зависимостей, а также перед публикацией новой версии.
