<div id="replit">
  ### 全新改版的 Replit 桌面应用
</div>

全新改版的 Replit 桌面应用让你在电脑上同样享有完整的 Replit 体验。除了与网页端一致的构建体验，还能获得原生应用独有的优势：同时处理多个应用，一眼看清 Agent 何时需要协助或已完成任务，无需切换即可预览已打开的应用。

<div id="whop">
  ### 使用 Whop 在应用内销售
</div>

现在只需向 Agent 提出需求，即可通过 Whop 为应用添加支付功能。Agent 会替你创建并连接 Whop 账户，然后在项目中搭建结账流程，无需任何外部设置或填写 API 密钥。想要开始销售数字产品、会员和订阅，Whop 是最快捷的方式。

进一步了解 [Whop 支付](/zh/ko/features/monetization/whop-payments)。

<div id="section-4">
  ## 账单
</div>

<div id="pro-core">
  ### 一步从 Pro 降级到 Core
</div>

现在，你无需先取消订阅即可直接从 Replit Pro 切换到 Replit Core。此前若要降级，只能先取消订阅、退回免费方案，然后重新订阅。现在当你发起取消时，Replit 会建议你改为降级到 Core，这样既能保留付费方案，已发布的应用也能继续运行。

详细了解[变更方案](/zh/ko/billing/plans/changing-your-plan)。
