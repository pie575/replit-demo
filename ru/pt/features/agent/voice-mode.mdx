---
title: "Voice Mode"
description: "Проговаривайте промпты для Agent вместо того, чтобы печатать их. Voice Mode переводит сказанное в текст в поле чата, чтобы вы могли проверить его и отправить."
---

Описывайте вслух то, что хотите создать, с помощью Voice Mode. Нажмите на микрофон в поле чата у Agent, произнесите промпт — и Replit преобразует вашу речь в редактируемый текст. Проверьте текст, внесите нужные правки и отправьте его как любое другое сообщение.

Voice Mode удобен, когда печатать медленно или неудобно, — особенно на телефоне, где продиктовать промпт целиком обычно быстрее, чем набирать его большими пальцами.

<Note>
  Voice Mode превращает вашу речь в текст в поле чата. Он не зачитывает ответы Agent вслух — вы по-прежнему отправляете письменное сообщение, а Agent отвечает в Chat как обычно.
</Note>

  ## Как это работает
</div>

Voice Mode записывает вашу речь, преобразует её в текст и вставляет результат в поле чата, чтобы вы могли проверить его перед отправкой:

1. Откройте Agent и нажмите на микрофон в поле чата.
2. Разрешите доступ к микрофону, если браузер или устройство запросит его.
3. Произнесите свой промпт. Осциллограмма покажет, что Agent ведёт запись.
4. Остановите запись, когда закончите. Запись останавливается и автоматически — после паузы или при переключении на другую вкладку.
5. Немного подождите, пока речь распознаётся.
6. Проверьте распознанный текст, при необходимости отредактируйте его и отправьте сообщение.

Поскольку результат распознавания появляется в поле чата как обычный текст, вы можете свободно сочетать голос и набор с клавиатуры: продиктуйте часть промпт, а остальное наберите или исправьте слово перед отправкой.

<Tip>
  Говорите естественно. Voice Mode стремится передать смысл сказанного, а не распознать дословно каждое слово, поэтому слова-паразиты вроде «эм» и «ну» в результат не попадают.
</Tip>

<div id="onde-voc-pode-usar">
  ## Где можно использовать
</div>

Voice Mode доступен в поле чата для Agent:

* В **редакторе проектов** при работе с Agent над приложением.
* При **создании нового приложения** из поля ввода промпт для Agent на главном экране.

Voice Mode можно использовать в веб-версии для компьютера, в мобильной веб-версии и в мобильном приложении Replit.

<div id="bom-saber">
  ## Полезно знать
</div>

Учитывайте эти особенности при использовании Voice Mode:

| Особенность              | Чего ожидать                                                                                                                                                            |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Длительность записи      | Записывать можно до 6 минут за раз. Незадолго до достижения лимита появится предупреждение.                                                                             |
| Автоматическая остановка | Запись останавливается сама примерно после 30 секунд тишины, а также если вы переключитесь на другую вкладку или свернёте приложение в фоновый режим.                   |
| Проверка перед отправкой | Распознанный текст попадает в поле чата, чтобы вы могли прочитать и отредактировать его перед отправкой — автоматически ничего не отправляется.                       |
| Доступ к микрофону       | Voice Mode требуется разрешение на использование микрофона. Если запись не начинается, проверьте, разрешён ли доступ к микрофону для Replit в браузере и на устройстве. |

<div id="disponibilidade">
  ## Доступность
</div>

Voice Mode доступен на всех тарифах Replit. Значок микрофона появляется в поле чата у Agent в браузерах и на устройствах, поддерживающих запись звука, а при первой записи вам будет предложено разрешить доступ к микрофону.
