你的应用通过 Replit 管理的凭据连接到数据库。在 **Database** 工具中选择数据库，打开 **Settings** 标签页即可查看，其中会显示连接字符串、存储用量以及详细的连接信息。

<div id="section">
  ## 环境变量
</div>

连接开发数据库时，可以使用以下环境变量。

* `DATABASE_URL`：用于连接数据库并进行身份验证

应用会自动使用该变量。`DATABASE_URL` 的作用范围仅限于单个应用，因此其他应用 (即使是你自己的应用) 或外部数据库查看工具都无法访问该开发数据库。即使万一泄露，他人也无法凭它访问或修改你的数据库。

<Info>
  如果你的开发数据库仍位于[旧版 Neon 基础设施](/zh/ja/features/data-and-storage/development-and-production#legacy-development-database)上，还可以使用 `PGHOST`、`PGUSER`、`PGPASSWORD`、`PGDATABASE`、`PGPORT` 等额外变量。托管在 Replit 现有基础设施上的数据库**不会**提供这些变量，此时请使用 `DATABASE_URL`。
</Info>

<Warning>
  如果你仍在使用旧版 Neon 开发数据库，请勿共享 `DATABASE_URL`。它包含数据库的身份验证凭据，任何人都可以凭此访问并修改你的数据库。切勿将其粘贴到公开场合或支持工单中。
</Warning>

<div id="section-2">
  ## 连接外部工具
</div>

使用 **production** 数据库 **Settings** 选项卡中的连接字符串，即可通过兼容 PostgreSQL 的 SQL 客户端连接到 **production** 数据库。

<div id="section-3">
  ## 安全性
</div>

使用 Agent 添加数据库集成时，系统会一并加入负责处理所有数据库通信的对象关系映射器 (ORM) ，从而提供以下内置安全保障：

* **模式校验**：验证数据是否符合预期格式
* **数据清理**：自动清理构建器的输入内容，防止 SQL 注入攻击

<div id="section-4">
  ## 重新生成生产数据库凭据
</div>

如果生产环境连接字符串发生泄露，请在 Database 工具中重新生成凭据。此操作会为 Neon 生产数据库创建新密码，现有的生产环境连接字符串将立即失效。

同时满足以下条件时，你才能重新生成凭据：

* 应用拥有 Neon 生产数据库。
* 你是应用的所有者，或所属工作区的管理员。
* 你正在 Web 浏览器中使用 Replit。
* 当前没有正在进行的部署。
* 如果应用存在实时部署，其最新构建已成功完成，并且使用 [Autoscale 或 Reserved VM](/zh/ja/features/publishing/deployment-types)。

<Warning>
  此操作无法撤销。现有连接字符串将立即失效。如果应用存在实时部署，在重新部署期间可能会出现短暂不可用的情况。
</Warning>

<div id="section-5">
  ### 重新生成凭据
</div>

1. 在 Tools 面板中选择 **Database**。

2. 选择 **Production Database**，然后切换到 **Settings** 标签页。

   <Frame>
     <img src="/assets/mirror/database-regenerate-credentials-settings-827c7718a25f.webp" alt="生产数据库的 Settings 标签页，显示包含连接字符串、存储用量以及 Regenerate credentials 行的 Advanced 部分" width="2314" height="1608" data-path="images/databases/database-regenerate-credentials-settings.webp" />
   </Frame>

3. 展开 **Advanced** 下的 **Regenerate credentials** 行。

4. 选择 **Regenerate credentials** 按钮。

   <Frame>
     <img src="/assets/mirror/database-regenerate-credentials-button-ab9631f21b85.webp" alt="Advanced 部分中 Regenerate credentials 行已展开，显示 Regenerate credentials 按钮" width="2206" height="1876" data-path="images/databases/database-regenerate-credentials-button.webp" />
   </Frame>

5. 在确认对话框中选择 **Regenerate credentials** 进行确认。

   <Frame>
     <img src="/assets/mirror/database-regenerate-credentials-dialog-2477fc96f82b.webp" alt="Regenerate credentials 确认对话框，警告此操作无法撤销，且现有连接字符串将立即失效" width="1364" height="638" data-path="images/databases/database-regenerate-credentials-dialog.webp" />
   </Frame>

6. 选择 **Refresh** 加载新的连接字符串。

7. 如果你的应用已有实时部署，请打开 **Publishing** 查看重新部署的状态。

8. 替换所有已复制到外部工具或自定义集成中的连接字符串。

<div id="section-6">
  ### 会发生哪些变更
</div>

重新生成凭据会为生产数据库创建新密码。连接字符串中只有密码部分会发生变化,主机、数据库名称和角色保持不变。

对于相关联的实时部署,Replit 会使用更新后的连接字符串,重新部署最近一次成功的构建。
