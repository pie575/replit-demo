      <Accordion title="Où puis-je obtenir de l’aide concernant le code ?">
        La meilleure façon d&#39;obtenir de l&#39;aide pour votre code est d&#39;utiliser [Replit AI](/fr/ko/build/welcome/). Ouvrez un nouvel onglet dans l&#39;éditeur de projet et recherchez **AI**. Replit AI peut configurer de nouveaux projets, répondre à vos questions sur le code et vous aider à trouver des idées. Si vous avez besoin d&#39;aide supplémentaire, vous trouverez également davantage de ressources dans le [hub communautaire](https://replit.com/community).
      </Accordion>

      <Accordion title="Vous rencontrez des problèmes avec Replit ? Comment obtenir de l’aide ?">
        Connectez-vous à Replit et utilisez l’icône **?** en haut à droite de la page pour obtenir de l’aide. Si vous avez besoin d’aide supplémentaire, consultez le [document sur la politique d’assistance](/fr/ko/legal-and-security-info/support-policy).
      </Accordion>

      <Accordion title="Où puis-je obtenir de l’aide concernant la facturation ?">
        Avant de contacter l’équipe d’assistance, vérifiez si les **Paramètres** ci-dessous proposent une solution. Si le problème persiste, connectez-vous et utilisez **?** en haut à droite de la page pour obtenir de l’aide.
      </Accordion>

      <Accordion title="Je n’arrive pas à accéder à mon compte Replit – que dois-je faire ?">
        Envoyez un e-mail à `support@replit.com` en indiquant le nom d’utilisateur du compte et l’identifiant de connexion.
      </Accordion>

      <Accordion title="Quand puis-je espérer recevoir une réponse de Replit ?">
        L’équipe d’assistance Replit est généralement disponible du lundi au vendredi, de 9 h à 20 h (heure normale de l’Est, UTC-5).
      </Accordion>

      <Accordion title="Comment restaurer un dossier dans l’application Replit ?">
        Accédez à votre profil en haut à droite de l’application Replit, sélectionnez **CLUI**, puis saisissez &#95;restore&#95; dans le champ de recherche qui s’affiche. Dans les résultats, vous trouverez l’option **restore-folder**, qui permet de restaurer un dossier spécifique depuis la corbeille.

        > Remarque : les applications Replit supprimées sont définitivement supprimées **30 jours** après leur suppression et ne peuvent plus être restaurées.
      </Accordion>

      <Accordion title="Comment restaurer une application Replit supprimée ?">
        Accédez au profil en haut à droite de l’application Replit, sélectionnez **CLUI**, puis saisissez &#95;restore&#95; dans le champ de recherche qui s’affiche. Dans les résultats, vous trouverez l’option **restore-repl**, qui permet de restaurer une application Replit spécifique depuis la corbeille.

        > Remarque : les applications Replit supprimées sont définitivement supprimées **30 jours** après leur date de suppression initiale et ne peuvent plus être restaurées.
      </Accordion>

      <Accordion title="Pourquoi l’application Replit ne se charge-t-elle pas ?">
        Si l’application Replit ne se charge pas, essayez les étapes de dépannage suivantes :

        1. Testez votre [connexion Internet](https://www.speedtest.net/).
        2. Essayez un autre navigateur.
        3. Vérifiez que JavaScript est activé dans votre navigateur.
        4. Ouvrez la palette de commandes avec `Cmd+K` (Mac) ou `Ctrl+K` (Windows), puis recherchez et sélectionnez **Restart compute**.

        Si le problème persiste après avoir suivi les étapes ci-dessus, consultez l’[état des services](https://status.replit.com) de Replit. Si l’état affiche **Tous les systèmes sont opérationnels !**, mais que vous rencontrez toujours des problèmes de chargement de l’application Replit, contactez [l’assistance Replit](https://replit.com/support).
      </Accordion>

      <Accordion title="Comment téléverser des fichiers volumineux dans une application Replit ?">
        Si le fichier est trop volumineux pour être téléversé via l’interface graphique standard, vous pouvez utiliser `scp` (Secure Copy) via [SSH](/fr/ko/features/workspace-tools/ssh) pour transférer des fichiers de manière sécurisée entre votre système local et le système distant. Pour copier un fichier de votre machine locale vers une machine distante, utilisez la syntaxe suivante : `scp filename username@ip_address:/home/username`

        Vous pouvez également utiliser `scp` pour copier un répertoire entier.
      </Accordion>

      <Accordion title="Comment vérifier le solde de vos crédits d’utilisation ?">
        Vous pouvez consulter votre solde actuel sur [https://replit.com/~/cli/account/usage-credits-balance](https://replit.com/~/cli/account/usage-credits-balance).
      </Accordion>

      <Accordion title="J'ai des problèmes de connexion. Que dois-je faire ?">
        1. Vérifiez que vous utilisez la bonne adresse e-mail et le bon mot de passe.
        2. Pour réinitialiser votre mot de passe, accédez à la [page de récupération du mot de passe](https://replit.com/forgot). Vérifiez que l&#39;e-mail de réinitialisation envoyé par `notifications@replit.com` ne se trouve pas dans votre dossier de spam.
        3. Essayez de vous connecter depuis un autre navigateur.

        Si le problème persiste après avoir suivi toutes ces étapes, [contactez l&#39;assistance](https://replit.com/support).
      </Accordion>

      <Accordion title="Comment modifier mon adresse e-mail si je me suis inscrit avec Google/GitHub/Facebook/Apple ?">
        Vous avez besoin d&#39;un mot de passe pour modifier l&#39;adresse e-mail associée à votre compte. Si vous vous êtes inscrit via un fournisseur d&#39;authentification tiers tel que Google ou GitHub, vous devez d&#39;abord créer un mot de passe.

        Pour créer un mot de passe :

        1. Ouvrez la barre latérale et déconnectez-vous.
        2. Revenez à la page de connexion, sélectionnez [Mot de passe oublié](https://replit.com/forgot), puis saisissez votre adresse e-mail.
        3. Vous recevrez un e-mail contenant un lien pour créer un nouveau mot de passe. Si vous ne le voyez pas, vérifiez votre dossier de spam et patientez jusqu&#39;à 30 minutes.
        4. Après vous être connecté, ouvrez les [paramètres](https://replit.com/settings) pour modifier votre adresse e-mail.
      </Accordion>

      <Accordion title="Comment modifier mon nom d'utilisateur ?">
        Les utilisateurs de Replit ne peuvent modifier leur nom d&#39;utilisateur **qu&#39;une seule fois**. Accédez à [CLUI](https://replit.com/~/cli/account/change-username?run=1) et sélectionnez **change-username**. Si cette option n&#39;est pas disponible, vous avez déjà modifié votre nom d&#39;utilisateur.
      </Accordion>

      <Accordion title="Qu'est-ce que le mode Explorer et comment l'activer ?">
        Les Explorers sont des utilisateurs de Replit qui choisissent de découvrir et de tester de nouvelles fonctionnalités encore en développement. Pour activer le mode Explorer, ouvrez les [paramètres](https://replit.com/settings) et activez le commutateur Explorer (par exemple, sous **Compte** ou **Utilisateur**).
      </Accordion>
    </AccordionGroup>
