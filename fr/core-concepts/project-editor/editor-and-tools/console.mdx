La Console vous permet de surveiller et de consulter en temps réel les journaux imprimés par votre application Replit en cours d'exécution.
Vous pouvez utiliser les informations des exécutions actuelles et passées pour comprendre le comportement de votre application,
résoudre les erreurs et optimiser les performances.

<Tip>
  Lors du débogage avec Agent, incluez les journaux de la console dans votre invite pour fournir du contexte.
</Tip>

## Fonctionnalités

La Console fournit les outils suivants pour vous aider à comprendre le comportement de votre application :

* **Journalisation en temps réel** : Voir la sortie de votre application au fur et à mesure
* **Assistance IA** : Recevoir des suggestions pour corriger les erreurs signalées dans les journaux
* **Historique des exécutions** : Afficher les journaux des exécutions précédentes pour suivre les modifications

## Utilisation

Vous pouvez accéder à l'outil Console directement dans votre Éditeur de projet.

<Accordion title="Comment accéder à la Console">
  Depuis le **Dock d'outils** à gauche :

  1. Sélectionnez <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Icône Tous les outils" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **Tous les outils** pour voir la liste des outils de l'Éditeur de projet.
  2. Sélectionnez <img class="icon-svg" src="/assets/mirror/console-8a41ac90789c.svg" alt="Icône Console" width="16" height="16" data-path="images/icons/console.svg" /> **Console**.

  Depuis la **Barre de recherche** :

  1. Sélectionnez la <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="icône loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> loupe en haut pour ouvrir l'outil de recherche
  2. Tapez « Console » pour localiser l'outil et le sélectionner dans les résultats.
</Accordion>

Chaque fois que vous utilisez le bouton **Exécuter** dans votre application Replit, la Console affiche une nouvelle entrée qui comprend les informations suivantes :

* La commande qui a exécuté votre code
* Les informations d'horodatage
* Les journaux de sortie standard et d'erreur

La capture d'écran suivante montre la commande `npm run dev` utilisée pour démarrer l'application et les messages de journaux de l'exécution :

### Débogage assisté par IA

Lorsque vous rencontrez des erreurs ou d'autres informations dans les journaux que vous souhaitez comprendre, sélectionnez le
bouton **Demander à l'IA** en haut de l'entrée. Cela ouvre automatiquement l'onglet **Agent** et
soumet le contenu du journal pour analyse.

### Commandes des entrées de journal

La Console fournit les outils suivants pour gérer vos journaux :

* **Afficher uniquement le dernier** : Activez ce contrôle pour afficher uniquement l'exécution la plus récente.
* **Réduire l'entrée** : Sélectionnez la <img class="icon-svg" src="/assets/mirror/down-arrow-9c1cf9fd152e.svg" alt="icône flèche vers le bas" height="16" width="16" data-path="images/icons/down-arrow.svg" /> flèche vers le bas à gauche du nom de la commande pour masquer les journaux.
* **Effacer les exécutions passées** : Sélectionnez ceci pour supprimer les journaux des exécutions précédentes. Cette action est irréversible.

### Disponibilité réseau

Vous pouvez contrôler la disponibilité en ligne de la version de développement de votre application.

Pour arrêter de servir les requêtes à l'URL de développement, sélectionnez l'icône <img class="icon-svg" src="/assets/mirror/network-off-5bdca8a4fe4e.svg" alt="icône réseau désactivé" height="16" width="16" data-path="images/icons/network-off.svg" /> globe avec barre oblique
sur le côté droit de la ligne d'information réseau.

Pour l'activer, sélectionnez l'icône <img class="icon-svg" src="/assets/mirror/network-on-15be2e5fb4f5.svg" alt="icône réseau activé" height="16" width="16" data-path="images/icons/network-on.svg" /> globe.

Pour afficher votre URL de développement, sélectionnez le texte `{...}.replit.dev` dans la barre d'adresse.

<Frame>
  <img src="/assets/mirror/preview-dev-url-b36770b33769.png" alt="Emplacement de l'URL de développement Preview" width="1222" height="824" data-path="images/workspace/preview-dev-url.png" />
</Frame>

<Note>
  Votre application reste accessible dans l'outil Prévisualisation même lorsqu'il est configuré pour arrêter de servir les requêtes à l'URL de développement.
</Note>

### Arrêter une commande de workflow

Vous pouvez arrêter une commande de workflow en cours depuis l'outil Console de l'Éditeur de projet.

Sélectionnez le bouton carré sur le côté droit de la ligne contenant la commande d'exécution de votre application Replit pour la terminer.

Pour redémarrer votre application, utilisez le bouton **Exécuter** du workflow en haut de l'Éditeur de projet.
