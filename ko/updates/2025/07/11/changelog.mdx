<div id="replitmd-documentation">
  ### replit.md 문서
</div>

`replit.md`는 Agent가 프로젝트의 선호 사항, 코딩 스타일, 아키텍처를 이해하도록 돕는 특수 설정 파일입니다. 이 파일로 Agent의 동작을 원하는 대로 조정해 보세요. Agent는 검증된 모범 사례에 따라 이 파일을 자동으로 생성한 뒤, 이를 바탕으로 요구 사항에 정확히 부합하는 애플리케이션을 구축합니다. project context를 제공해 Agent를 안내하고, 코딩 표준을 정의하고, 선호하는 기술 stack을 지정하고, 커뮤니케이션 방식을 설정하는 일까지 모두 한곳에서 처리할 수 있습니다.

  ### Deployment privacy indicators
</div>

<div id="agent-multi-tool-calling-upgrade">
  ### Agent 멀티 툴 호출 업그레이드
</div>

개선된 멀티 툴 호출 시스템으로 Agent 비용을 15% 절감하고 결과는 30% 더 빠르게 받아보세요. 이제 Agent는 작업을 더 효율적으로 묶어서 처리하고 툴 오류에도 더 똑똑하게 대응하여, 더 적은 리소스로 동일한 품질의 결과를 제공합니다.
