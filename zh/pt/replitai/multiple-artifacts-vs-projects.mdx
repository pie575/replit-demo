title: "多个产物与独立项目的对比"

---

[项目](/zh/pt/replitai/projects) 是你在 Replit 中构建的一切内容的容器。一个项目包含你的设计、应用、幻灯片、数据以及你创建的所有输出。
[产物](/zh/pt/replitai/artifacts) 则是项目内可发布的输出：Web 应用、移动应用、幻灯片演示和视频。

当你要构建的内容不止一个时，你有两种选择：

* 将多个产物添加到同一个项目中，
* 或者创建多个独立的项目。

如何选择，取决于这些应用是否共享数据、逻辑和同一套部署生命周期。本指南将介绍何时把产物放在同一个项目中，以及何时创建独立的项目。

<div id="o-que-os-artefatos-compartilham-em-um-projeto">
  ## 项目中的产物共享哪些资源
</div>

当[产物](/zh/pt/replitai/artifacts)位于同一[项目](/zh/pt/replitai/projects)中时，它们会自动共享：

* **数据库**：一个产物写入数据，其他产物可立即读取
* **后端和 API**：共享服务器端逻辑，无需重复编写代码
* **文件存储**：产物之间可访问图片、文档和上传的文件
* **部署**：部署时会同步部署所有内容

这意味着你无需在产物之间配置连接或复制代码。但也意味着，你无法在不部署其他产物的情况下单独部署某个产物。

<div id="guia-rpido">
  ## 快速指南
</div>

以下是在决定将多个产物添加到现有项目，还是创建独立项目时需要考虑的主要情形。

| **在同一项目中使用多个产物**          | **使用独立项目**            |
| ------------------------- | --------------------- |
| 应用共享相同的数据和后端              | 应用不共享底层逻辑或数据          |
| 您希望将所有内容一起部署              | 您需要独立的部署周期            |
| 它们相互补充 (例如面向客户的应用和管理后台)  | 它们是互不相关的产品，或面向不同客户    |
| 您希望一个产物中的更改自动反映到其他应用中     | 项目是短期的，例如营销活动落地页或活动网站 |

<div id="exemplos">
  ## 示例
</div>

<div id="mesmo-projeto-aplicativo-web-aplicativo-mobile-para-um-produto">
  ### 同一项目：一个产品的 Web 应用和移动应用
</div>

一家餐厅为顾客构建了用于浏览菜单的 Web 应用，并为员工构建了用于管理订单的移动应用。两者都连接到同一个存储菜单项、订单和客户信息的数据库。

**为何使用同一项目：** 两个应用共享相同的数据和后端。顾客通过 Web 应用下单后，员工会立即在移动应用中看到订单。

<div id="mesmo-projeto-aplicativo-dashboard-admin-pitch-deck-para-investidores">
  ### **同一个项目**：应用 + 管理后台 + 投资人路演文稿
</div>

一家初创公司在同一个项目中构建核心产品、用于管理内容的内部管理后台，以及用于融资的演示文稿。
一家初创公司在同一个项目中构建核心产品、用于管理内容的内部管理后台，以及用于融资的演示文稿。

**为什么放在一个项目里：** 管理后台管理的数据，正是应用要展示的数据，而演示文稿可以引用共享后端中的实时指标。

<div id="projetos-separados-dois-aplicativos-de-clientes-no-relacionados">
  ### **独立项目**：两个互不相关的客户应用
</div>

一位自由职业者为一个客户搭建电商网站，又为另一个客户搭建预订系统。

**为什么要用独立项目：**这两个应用之间没有共享数据或逻辑。每个客户都需要独立部署，而且你也不希望改动其中一个会影响到另一个。

<div id="projetos-separados-landing-page-de-campanha-ao-lado-de-um-produto-principal">
  ### **独立项目**：与核心产品配套的营销活动落地页
</div>

你有一个全年运行的生产应用，以及一个用于短期营销活动的落地页。

**为什么要使用独立项目：** 活动页面有自己的生命周期——你会创建它、运行几周，然后关闭它。将其单独管理可避免干扰核心产品，并让你能够独立发布或移除它。

<div id="perguntas-frequentes">
  ## 常见问题
</div>

<Accordion title="我可以把某个产物移动到另一个项目吗？">
  目前不支持。如果需要单独拆分某个产物，请新建一个 [项目](/zh/pt/replitai/projects)，并让 Agent 在其中重新构建它。
</Accordion>

<Accordion title="一个项目能包含的产物数量有上限吗？">
  一个项目最多可包含 7 个产物。之所以设置该上限，是因为产物越多占用的内存越大，可能会拖慢预览速度。如果需要更多产物，请另外新建一个 [项目](/zh/pt/replitai/projects)。
</Accordion>

<Accordion title="我可以只部署项目中的某一个产物吗？">
  目前不支持。部署时会将所有内容一起发布。如果需要独立部署，请使用彼此独立的项目。
</Accordion>
