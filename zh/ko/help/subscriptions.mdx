本回答介绍订阅管理。完整的套餐详情请参阅 [Core](/zh/ko/billing/plans/replit-core) 和 [Pro](/zh/ko/billing/plans/replit-pro)。

<AccordionGroup>
  <Accordion title="如何从 Core 升级到 Pro？两者有什么区别？">
    与 [Core](/zh/ko/billing/plans/replit-core) 相比，[Pro](/zh/ko/billing/plans/replit-pro) ({ProPlanPrice}/月) 新增以下内容：

    * Turbo 模式
    * 最多 15 名构建者，共享积分池
    * 阶梯式积分。未使用的积分可结转 {ProCreditRolloverPeriod}
    * 28 天数据库恢复期 (Core 为 7 天)
    * 优先支持

    如需升级，请打开 **设置 → 账单**，选择 Pro 套餐，然后确认付款信息。功能对比与最新价格请参阅[价格页面](https://replit.com/pricing)。
  </Accordion>

  <Accordion title="如何取消订阅？">
    打开 **设置 → 账单**，选择取消订阅选项，然后完成确认步骤。在计费周期结束前，你仍可继续使用套餐功能，之后账户将转为免费的 [Starter 套餐](/zh/ko/billing/plans/starter-plan)。

    请注意，转换后已发布的应用可能会下线，自定义域名的绑定会被移除，存储空间也会缩减。请先下载你想保留的内容。如果订阅状态显示为 `past_due`，可能是付款失败，请在取消前先处理该问题。
  </Accordion>

  <Accordion title="续订扣款失败。如何更新付款方式？">
    打开**设置 → 账单**，选择**更新支付方式**以添加或更新银行卡。保存后，Replit 会自动重试未成功的扣款。

    如果问题仍未解决，请提供支付意图 ID (以 `pi_` 开头) 并[联系 Replit 支持团队](https://replit.com/support)。扣款失败的通知邮件可能被归入垃圾邮件文件夹。
  </Accordion>

  <Accordion title="如何将订阅转移到其他电子邮箱或账户？">
    订阅与 Replit 账户绑定，无法直接转移。如果想在保留订阅的同时更改账户邮箱，请前往**设置 → 个人资料**修改邮箱。

    如需将订阅转移到其他账户，请[联系 Replit 支持团队](https://replit.com/support)。我们会逐案处理。
  </Accordion>

  <Accordion title="我一个月被扣了两次费。怎么回事？">
    如果一个月内被扣费两次，通常是以下原因之一：

    * 订阅费用，以及达到计费阈值后单独产生的用量费用
    * 之前扣款失败后重试并成功的付款
    * 存在一个以上的有效订阅

    要查看每一笔扣费明细，请打开**设置 → 账户使用量**，然后选择**查看历史账单**。如果仍有疑问，请[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="我已更改套餐，但无法使用新功能，该怎么办？">
    套餐变更通常会立即生效。如果没有看到新功能：

    1. Mac 上按 `Cmd+Shift+R`，Windows 上按 `Ctrl+Shift+R` 强制刷新页面。
    2. 退出登录后重新登录。
    3. 打开**设置 → 账单**，确认变更是否已生效，此处应显示新的套餐名称。

    如果账单中显示的套餐正确，但仍无法使用相应功能，请[联系 Replit 支持团队](https://replit.com/support)，并提供您的用户名和想要使用的功能。
  </Accordion>

  <Accordion title="我可以暂停订阅，而不是取消吗？">
    部分订阅者符合条件，可以将订阅暂停一个月，而无需直接取消。如果你符合条件，在进入取消流程时会看到该选项。暂停期间：

    * 跳过下一次扣款，且不发放每月积分
    * 已发布的项目保持在线，协作者仍可访问
    * 可结转的积分照常结转，积分包仍可继续使用
    * Agent 和托管用量仍按实际使用量计费

    **设置 → 账单**中会显示**已暂停**徽章以及暂停结束日期，到期后订阅将自动恢复。已安排的暂停可在生效前取消，但已生效的暂停无法提前结束。订阅仅可暂停一次。
  </Accordion>
</AccordionGroup>
