Инструмент Secrets хранит и шифрует **секреты** — конфиденциальные данные вашего Replit App, например API-ключи, токены аутентификации и строки подключения к базе данных.

Когда вы добавляете секрет, инструмент автоматически шифрует данные и предоставляет их вашему Replit App в виде переменной окружения.
Такой подход позволяет не указывать секреты напрямую в коде и снижает риск их раскрытия.

Указание секретов напрямую в коде может привести к их случайному раскрытию в следующих случаях:

* Вы делитесь кодом с другими через публичный Replit App или копируете и вставляете его
* Вы отправляете код в публичный репозиторий системы контроля версий
* Вы ведёте прямую трансляцию или демонстрируете экран с кодом

Используйте инструмент Secrets, чтобы уверенно делиться кодом, не беспокоясь о раскрытии учётных данных.

<div id="funcionalidades">
  ## Функции
</div>

Инструмент Secrets включает следующие функции:

* **Сквозное шифрование**: Автоматическая защита данных с помощью шифрования AES-256 при хранении и TLS-шифрования при передаче
* **Secrets на уровне App**: Хранение и управление secrets, относящимися к конкретному Replit App
* **Secrets на уровне учётной записи**: Хранение и управление secrets, которые можно использовать во всех ваших Replit App
* **Доступ через переменные окружения**: Доступ к secrets в коде через переменные окружения
* **Совместный доступ**: Предоставление доступа к secrets соавторам и участникам команды

  ## Использование
</div>

<Note>
  Secrets доступны для всех типов развёртывания, кроме статических деплоев.

Открыть инструмент Secrets можно в Project Editor.

<Accordion title="Как открыть Secrets">
  На **панели инструментов** слева:

  1. Выберите <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Иконка всех инструментов" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**, чтобы просмотреть список инструментов Project Editor.
  2. Выберите <img class="icon-svg" src="/assets/mirror/lock-af402c9618dd.svg" alt="Иконка Secrets" width="16" height="16" data-path="images/icons/lock.svg" /> **Secrets**.

  В **строке поиска**:

  1. Нажмите <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="иконка лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> на значок лупы вверху, чтобы открыть поиск.
  2. Введите «Secrets», найдите инструмент и выберите его в результатах.
</Accordion>

<div id="gerenciar-secrets-do-app">
  ### Управление секретами App
</div>

Управлять секретами уровня App можно на вкладке **App Secrets** панели **Secrets**.
На этой вкладке отображается список всех секретов, связанных с вашим Replit App.

<Accordion title="Добавление секретов App">
  Чтобы добавить секрет:

  1. Выберите **New Secret**.
  2. Введите **Key** — имя секрета — и **Value** — сам секрет.
  3. Выберите **Add Secret**, чтобы сохранить запись.
</Accordion>

<Accordion title="Редактирование секретов App">
  Чтобы отредактировать секрет:

  1. Нажмите меню <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="иконка с тремя вертикальными точками" height="16" width="16" data-path="images/icons/vertical-dots.svg" /> с тремя вертикальными точками рядом с секретом.
  2. В контекстном меню выберите **Edit**.
  3. Измените текст в поле **Key** или **Value** и выберите **Update Secret**, чтобы сохранить изменения, или **Cancel**, чтобы отменить их.

  Также можно изменить весь список секретов App, выбрав **Edit as JSON** или **Edit as .env** в нижней части вкладки.
</Accordion>

<Accordion title="Просмотр секретов App">
  Чтобы просмотреть секрет, нажмите иконку <img class="icon-svg" src="/assets/mirror/eye-8a6472b8a950.svg" alt="иконка глаза" width="16" height="16" data-path="images/icons/eye.svg" /> глаза рядом с секретом.

  Чтобы скрыть секрет, нажмите иконку <img class="icon-svg" src="/assets/mirror/eye-slash-6b4ded538179.svg" alt="иконка перечёркнутого глаза" width="16" height="16" data-path="images/icons/eye-slash.svg" /> перечёркнутого глаза.
</Accordion>

<Accordion title="Удаление секретов App">
  Чтобы удалить секрет, нажмите меню <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="иконка с тремя вертикальными точками" height="16" width="16" data-path="images/icons/vertical-dots.svg" /> с тремя вертикальными точками рядом с секретом и выберите **Delete**.
</Accordion>

<div id="gerenciar-secrets-da-conta">
  ### Управление секретами учётной записи
</div>

Вы можете управлять секретами на уровне учётной записи на вкладке **Account Secrets** панели **Secrets**.
На этой вкладке отображается список секретов, связанных с вашей учётной записью Replit.

<Accordion title="Добавление секретов учётной записи">
  Чтобы добавить секрет на уровне учётной записи:

  1. Перейдите на вкладку **Account Secrets**.
  2. Выберите иконку <img class="icon-svg" src="/assets/mirror/settings-icon-c2664c3691bf.svg" alt="иконка шестерёнки" width="16" height="16" data-path="images/icons/settings-icon.svg" />, чтобы открыть **Settings** и управлять секретами на уровне учётной записи.
  3. Выберите **New Secret**, чтобы добавить секрет.
  4. Введите **Key** — имя секрета — и **Value** — значение секрета.
  5. Выберите **Save**, чтобы сохранить запись.
</Accordion>

<Accordion title="Редактирование секретов учётной записи">
  Чтобы изменить секрет:

  1. Выберите иконку <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="иконка карандаша" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> рядом с нужным секретом.
  2. Измените текст в поле **Key** или **Value** и выберите **Save**, чтобы сохранить изменения, или **Cancel**, чтобы отменить их.
</Accordion>

<Accordion title="Просмотр секретов учётной записи">
  Чтобы просмотреть секрет, выберите иконку <img class="icon-svg" src="/assets/mirror/eye-8a6472b8a950.svg" alt="иконка глаза" width="16" height="16" data-path="images/icons/eye.svg" /> рядом с ним.

  Чтобы скрыть секрет, выберите иконку <img class="icon-svg" src="/assets/mirror/eye-slash-6b4ded538179.svg" alt="иконка глаза с перечёркиванием" width="16" height="16" data-path="images/icons/eye-slash.svg" />.
</Accordion>

<Accordion title="Привязка секретов учётной записи">
  Чтобы использовать секрет на уровне учётной записи в Replit App, необходимо привязать его к App.
  Чтобы привязать секрет на уровне учётной записи:

  1. Перейдите на вкладку **App Secrets**.
  2. Установите флажок слева от секрета.
  3. Выберите **Link to this App**.

  Чтобы отвязать секрет:

  1. Перейдите на вкладку **App Secrets**.
  2. Выберите меню <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" width="16" height="16" alt="иконка трёх вертикальных точек" data-path="images/icons/vertical-dots.svg" /> рядом с секретом.
  3. Выберите **Unlink**.
</Accordion>

<Accordion title="Удаление секретов учётной записи">
  1. Выберите иконку <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="иконка карандаша" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> рядом с нужным секретом.
  2. Выберите **Delete**.
</Accordion>

<div id="gerenciar-a-visibilidade-dos-secrets">
  ### Управление видимостью Secrets
</div>

Видимость Secrets зависит от вашего уровня доступа к Replit App и от того, являетесь ли вы его автором.

Вы можете использовать один из следующих способов, чтобы поделиться своим Replit App:

* **Multiplayer**: Пригласите пользователей Replit для совместной работы в реальном времени
* **Титульная страница**: Покажите предпросмотр своего Replit App с возможностью создать ремикс
* **Ремикс**: Сделайте свой личный Replit App или App организации общедоступным, чтобы другие могли создать собственную версию

В следующей таблице показано, кто может видеть имена и значения Secrets в различных сценариях:

| Способ доступа     | Кто                                                  | Может видеть имена | Может видеть значения |
| ------------------ | ---------------------------------------------------- | ------------------ | --------------------- |
| Multiplayer        | Участник Multiplayer                                 | ✓                  | ✓                     |
| Multiplayer        | Участник организации с ролью Владельца               | ✓                  | ✓                     |
| Multiplayer        | Участник организации без роли Владельца              | ✓                  |                       |
| Титульная страница | Любой посетитель                                     |                    |                       |
| Ремикс             | Владелец/соавтор, создающий ремикс своего Replit App | ✓                  | ✓                     |
| Ремикс             | Не владелец/соавтор, создающий ремикс Replit App     | ✓                  |                       |
| Ремикс             | Любой, кто создаёт ремикс через титульную страницу   | ✓                  |                       |
| Ремикс организации | Участник организации с ролью Владельца               | ✓                  | ✓                     |
| Ремикс организации | Участник организации без роли Владельца              | ✓                  |                       |

<Warning>
  Участники организации без роли Владельца не могут просматривать значения Secrets в Replit App, но могут получить к ним доступ, выведя переменные окружения.
</Warning>

<div id="secrets-relacionados-ao-banco-de-dados">
  ## Secrets, связанные с базой данных
</div>

Когда вы добавляете базу данных Replit, Project Editor автоматически создаёт следующий секрет:

| Секрет         | Описание                             |
| -------------- | ------------------------------------ |
| `DATABASE_URL` | Строка подключения к базе данных SQL |

<Info>
  Устаревшие базы данных Neon для разработки также могут включать `PGHOST`, `PGUSER`, `PGPASSWORD`, `PGDATABASE` и `PGPORT`. В актуальных базах данных Replit для разработки вместо них используется `DATABASE_URL`.
</Info>

Чтобы просмотреть все переменные окружения в Replit App, выполните `printenv` в Shell Project Editor или выведите их из кода.

<div id="variveis-de-ambiente-predefinidas">
  ## Предустановленные переменные окружения
</div>

Replit автоматически задаёт следующие переменные окружения, доступные в вашем App:

| Переменная окружения | Описание                                                                                            |
| -------------------- | --------------------------------------------------------------------------------------------------- |
| `REPLIT_DOMAINS`     | Список всех доменов, связанных с вашим Replit App, разделённый запятыми                             |
| `REPLIT_USER`        | Имя пользователя текущего редактора; в сеансах Multiplayer оно может различаться                    |
| `REPLIT_DEPLOYMENT`  | Установлено в значение `1`, если код выполняется в опубликованном App; в противном случае не задано |
| `REPLIT_DEV_DOMAIN`  | URL для разработки в домене `replit.dev`, отличающийся от URL развёртывания                         |

Эти переменные не отображаются в инструменте Secrets, но вы можете обращаться к ним в коде через объект `os.environ` или выполнив `printenv` в Shell.
