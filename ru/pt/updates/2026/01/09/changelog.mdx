<div id="novos-modelos-de-ia-nas-integraes">
  ### Новые ИИ-модели в интеграциях
</div>

В Интеграциях ИИ теперь доступны недавно выпущенные модели:

| Модель                       | Описание                                                                                                                                                           |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `gpt-5.2`                    | Самая мощная модель OpenAI для профессиональной работы, требующей глубоких знаний. Первая модель, преодолевшая порог в 90% на ARC-AGI-1, с контекстным окном 400K. |
| `claude-opus-4.5`            | Основная модель Anthropic, оптимизированная для программирования, агентов и работы за компьютером. Достигает 80,9% на SWE-bench Verified.                          |
| `gemini-3-flash-preview`     | Высокоскоростная модель Google для агентных рабочих процессов с контекстом в 1 млн токенов. Рассуждения, близкие к уровню Pro, при меньших задержке и стоимости.   |
| `gemini-3-pro-preview`       | Продвинутая мультимодальная модель Google с передовыми способностями к рассуждению и знаниями о реальном мире.                                                     |
| `gemini-3-pro-image-preview` | Модель Google Nano Banana Pro для высококачественной генерации и редактирования изображений с точной отрисовкой текста.                                            |
