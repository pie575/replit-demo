앱을 라이브하고 전문적인 웹사이트로 전환하세요.

도메인 구매를 통해 Replit 배포 앱의 도메인을 검색하고, 구매하고, 연결할 수 있습니다 — 모두 플랫폼 내에서 가능합니다. 배포된 앱에서 전문적인 웹 프레젠스로 몇 분 만에 전환할 수 있습니다.

즉, `my-app.com`과 같은 사이트를 구매하고 앱으로 자동 연결할 수 있습니다.

## 기능

도메인 구매는 앱에 전문적인 웹 주소를 부여하는 프로세스를 간소화합니다. 여러 서비스를 다룰 필요 없이 Replit 내에서 전체 웹 프레젠스 설정을 완료할 수 있습니다.

<Frame>
  <img src="/assets/mirror/replit-domains-8453291b634b.png" alt="구매한 도메인과 연결 상태를 보여주는 도메인 관리 인터페이스" width="3176" height="1556" data-path="images/deployments/custom-domains/replit-domains.png" />
</Frame>

주요 기능:

* **도메인 검색 및 가용성 확인**: `.com`, `.ai` 등 인기 있는 확장자에서 도메인 가용성 확인
* **원클릭 구매**: 계정의 기본 결제 수단을 사용해 Replit에서 직접 도메인 구매
* **자동 구성**: 수동 DNS 설정 없이 도메인이 즉시 Replit 앱을 가리킴
* **WHOIS 개인 정보 보호**: 공개 도메인 레코드에서 개인 정보가 비공개로 유지됨 — 모든 도메인 구매에 기본으로 포함
* **커스텀 DNS 레코드**: 이메일 공급업체 및 기타 서비스를 구성하기 위한 커스텀 A, TXT, MX 레코드 추가
* **즉시 게시**: 구매 직후 앱이 커스텀 도메인에서 접근 가능해짐
* **자동 갱신**: 도메인이 자동으로 갱신되어 앱이 중단 없이 게시 상태를 유지

## 사용 방법

### 도메인 구매

1. 앱을 배포하고 <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Publish icon" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publishing** 탭으로 이동합니다
2. **Domains** 탭을 선택합니다
3. **Buy a domain**을 선택해 검색을 시작합니다
4. 검색창에 원하는 도메인 이름을 입력합니다
5. 다양한 확장자로 제공되는 옵션을 검토합니다
6. 원하는 도메인을 선택하고 구매를 완료합니다

도메인을 구매하면 자동으로 Replit 앱을 가리키도록 구성됩니다. 추가 설정 없이 즉시 커스텀 도메인에서 앱에 접근할 수 있습니다.

도메인 구매 비용은 Replit 계정을 통해 청구되며, 계정 잔액에서 차감된 후 사용량에 적용됩니다.

### 구매한 도메인 관리

도메인이 배포된 앱과 원활하게 통합됩니다.

* **자동 갱신**: 앱이 게시 상태를 유지하도록 도메인이 자동으로 갱신됨
* **통합 청구**: 도메인 비용이 다른 서비스와 함께 Replit 청구서에 표시됨
* **이전 지원**: 필요 시 Replit 계정 간 또는 외부 등록 기관으로 도메인 이전 가능

### 커스텀 DNS 레코드

Replit을 통해 구매한 도메인의 경우, 이메일 공급업체와 같은 추가 서비스를 구성하기 위한 커스텀 DNS 레코드를 추가할 수 있습니다. 지원되는 DNS 레코드 유형:

* **A 레코드**: 도메인 또는 서브도메인을 특정 IP 주소로 연결
* **TXT 레코드**: SPF, DKIM, DMARC와 같은 이메일 인증 서비스를 위한 텍스트 기반 인증 레코드 추가
* **MX 레코드**: MX(메일 교환) 레코드는 이메일 서버에 도메인의 이메일을 어디로 전달할지 알려줍니다. MX 레코드를 설정하면 `hello@yourdomain.com`과 같은 이메일 주소에 커스텀 도메인을 사용할 수 있습니다.

구매한 도메인의 DNS 레코드를 관리하려면:

1. Publishing <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Publish icon" width="16" height="16" data-path="images/icons/deploy-icon.svg" />의 **Domains** 탭으로 이동합니다
2. 구성하려는 도메인을 찾습니다
3. **Edit** <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="pencil icon" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> 아이콘을 선택합니다
4. **Add DNS Record**를 선택합니다
5. 서비스 공급업체가 요구하는 레코드 유형, 이름, 값, TTL을 입력합니다

이 짧은 동영상에서 도메인 DNS 레코드 관리 페이지를 찾는 방법을 안내합니다.

### 지원되는 배포 유형

도메인 구매는 다음 배포 유형에서 작동합니다.

* **[Autoscale 배포](/ko/features/publishing/deployment-types#autoscale)**
* **[Reserved VM 배포](/ko/features/publishing/deployment-types#reserved-vm)**
* **[Static 배포](/ko/features/publishing/deployment-types#static)**

현재 개인 계정 배포 앱에 대한 도메인 구매가 가능합니다. Replit Pro를 위한 도메인 구매는 곧 출시될 예정입니다.

## FAQ

<AccordionGroup>
  <Accordion title="비용이 얼마나 드나요?">
    도메인 구매에는 두 가지 비용이 포함됩니다.

    * **등록 수수료**: 1년간 도메인 소유에 대한 초기 비용 (`.ai` 도메인은 2년)
    * **갱신 가격**: 초기 등록 기간 이후 자동으로 청구됨

    Replit은 도메인 구매에 추가 수수료를 부과하지 않습니다. 도메인 등록 수수료는 환불되지 않습니다.
  </Accordion>

  <Accordion title="도메인을 어떻게 갱신하나요?">
    Replit이 자동으로 도메인을 갱신하여 앱을 계속 접근할 수 있게 합니다. 자동 갱신을 중지하려면 Publishing 도구의 **Domains** 탭을 열고, 도메인을 선택한 다음 **Auto renewal** 토글을 끄세요. 같은 화면에서 도메인의 갱신 날짜와 갱신 가격을 확인할 수 있습니다.
  </Accordion>

  <Accordion title="Replit을 떠나고 싶으면 어떻게 하나요?">
    Replit 지원팀에 문의하여 도메인을 다른 등록 기관으로 이전할 수 있습니다. ICANN 규정에 따라 구매 후 60일 대기 기간이 지나야 외부 등록 기관으로 도메인을 이전할 수 있습니다.
  </Accordion>

  <Accordion title="Replit 계정 간에 도메인을 이전할 수 있나요?">
    네, Replit 지원팀에 문의하여 Replit 계정 간에 도메인을 이전할 수 있습니다. 이 프로세스는 60일 대기 기간이 필요하지 않습니다.
  </Accordion>

  <Accordion title="조직을 위한 도메인을 구매할 수 있나요?">
    Replit Pro 및 Enterprise 플랜을 위한 도메인 구매는 초기 베타 기간 이후에 제공될 예정입니다.
  </Accordion>

  <Accordion title="도메인에 커스텀 DNS 레코드를 추가할 수 있나요?">
    네! Replit을 통해 구매한 도메인에 커스텀 DNS 레코드를 추가할 수 있습니다. 현재 지원되는 레코드 유형:

    * **A 레코드**: 도메인 또는 서브도메인을 특정 IP 주소로 연결
    * **TXT 레코드**: 이메일 인증 및 기타 서비스를 위한 텍스트 기반 인증 레코드 추가
    * **MX 레코드**: 도메인의 이메일을 처리하는 메일 서버 구성

    Publishing의 Domains 탭으로 이동해서 이러한 레코드를 구성하세요. 이메일을 위한 MX 레코드 설정에 대한 자세한 지침은 위의 [커스텀 DNS 레코드](#custom-dns-records) 섹션을 참조하세요.
  </Accordion>

  <Accordion title="어떤 도메인 확장자가 지원되나요?">
    모든 일반적인 최상위 도메인(TLD)을 지원합니다. 특별한 지리적 또는 기타 제한이 있는 TLD는 지원할 수 없습니다.
  </Accordion>

  <Accordion title="WHOIS 개인 정보 보호란 무엇인가요?">
    도메인을 등록할 때 연락처 정보(이름, 주소, 전화번호, 이메일)는 일반적으로 누구나 검색할 수 있는 WHOIS라는 공개 데이터베이스에 게시됩니다. WHOIS 개인 정보 보호는 개인 정보를 등록 기관의 일반 정보로 대체하여 법적 요구 사항을 충족하면서도 정보를 비공개로 유지합니다.

    Replit을 통해 구매한 모든 도메인에는 추가 비용 없이 기본으로 WHOIS 개인 정보 보호가 포함됩니다. 즉, 도메인 소유자 정보를 검색하는 스패머, 마케터, 기타 누구에게도 개인 정보가 숨겨집니다.
  </Accordion>

  <Accordion title="이미 도메인이 있으면 어떻게 하나요?">
    기존 도메인을 Replit 앱에 연결하려면 [커스텀 도메인](/ko/features/publishing/custom-domains) 문서를 참조하세요.
  </Accordion>
</AccordionGroup>
