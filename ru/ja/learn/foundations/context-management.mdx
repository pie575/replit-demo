Контекст — это информация, которую модель ИИ использует для формирования следующего ответа. Управление контекстом — это умение дать модели нужную информацию в нужный момент.

Это важно, потому что ИИ не читает ваши мысли. Он опирается на текст, файлы, снимки экрана, логи, примеры и историю переписки, доступные в контекстном окне.

<div id="section">
  ## Что такое контекстное окно?
</div>

ИИ-модели могут учитывать лишь ограниченный объём информации за раз. Это ограничение и называется контекстным окном.

В контекстное окно может входить:

* ваш промпт
* предыдущие сообщения в диалоге
* файлы или код, доступные модели
* сообщения об ошибках и логи
* скриншоты, изображения или дизайн-референсы
* инструкции проекта, например `replit.md`
* результаты работы инструментов на предыдущих шагах

Опираясь на этот контекст, модель решает, что сгенерировать дальше.

<div id="section-2">
  ## Почему контекстное окно так важно
</div>

Если важных деталей в контексте нет, модель начнёт додумывать. Если же контекст переполнен посторонней информацией, модель может сосредоточиться не на том, что нужно.

Например, этот запрос почти не даёт контекста:

```text theme={null}
Улучши страницу регистрации.
```

Этот промпт даёт полезный контекст:

```text theme={null}
Улучши страницу регистрации для начинающих предпринимателей, которые решают, записываться ли в лист ожидания.
Оставь текущие поля как есть. Сделай ценностное предложение над формой более понятным.
Раздел с ценами не меняй.
```

Второй промпт сообщает модели, для кого предназначена страница, что нужно улучшить, что сохранить и что выходит за рамки задачи.

<div id="section-3">
  ## Размеры контекстного окна различаются
</div>

Разные модели ИИ способны обрабатывать разный объём контекста. Чем больше контекстное окно, тем больше текста модель учитывает за раз, но больше не всегда значит лучше. Релевантный контекст по-прежнему важнее, чем сваливание всех подряд деталей в диалог.

Примеры публично заявленных размеров контекстного окна:

| Семейство моделей | Пример контекстного окна |
| ----------------- | ------------------------ |
| GPT-4.1           | до 1 млн токенов         |
| Claude Sonnet 4.5 | до 200 тыс. токенов      |
| Gemini 2.5 Pro    | до 1 млн токенов         |

Эти цифры со временем меняются, и не все продукты раскрывают полные ограничения моделей. Практический вывод остаётся неизменным: излагайте важную информацию ясно и по существу.

<div id="section-4">
  ## Типы контекста
</div>

| Тип контекста            | Пример                                                                         |
| ------------------------ | ------------------------------------------------------------------------------ |
| **Цель**                 | «Эта лендинговая страница должна собирать заявки в лист ожидания».             |
| **Аудитория**            | «Это для занятых владельцев ресторанов».                                       |
| **Ограничения**          | «Сохраните текущую цветовую палитру и поля формы».                             |
| **Чего делать не нужно** | «Пока не добавляйте оплату».                                                   |
| **Примеры**              | Скриншоты, макеты, тестовые данные или страницы конкурентов.                   |
| **Состояние проекта**    | Текущие файлы, компоненты, сообщения об ошибках или пользовательские сценарии. |
| **Критерий готовности**  | «Посетитель может отправить форму и увидеть сообщение с благодарностью».       |

<div id="section-5">
  ## Свежий и постоянный контекст
</div>

Часть контекста относится к текущему диалогу. Он нужен, когда вы просите внести конкретное изменение, отладить отдельную проблему или даёте обратную связь по недавнему результату.

Другой контекст должен сохраняться на уровне всего проекта. Используйте постоянный контекст для стиля кода, брендбука, соглашений об именовании, переиспользуемых продуктовых правил и ограничений, которые Agent должен помнить от сессии к сессии. В Replit файл [replit.md](/ru/ja/features/project-setup/replit-dot-md) — один из способов передать Agent постоянный контекст проекта.

<div id="section-6">
  ## Когда контекст становится зашумлённым
</div>

Длинные диалоги могут уходить в сторону. Если в ветке накопилось много посторонних решений, Agent может опираться на устаревший контекст, который уже не имеет значения.

Начните новую ветку, если:

* вы переключаетесь на не связанную с текущей функциональность;
* в диалоге накопилось много брошенных направлений;
* Agent продолжает применять устаревшие ограничения;
* вам нужен понятный план для новой области.

Начиная с чистого листа, кратко изложите важный контекст, а не рассчитывайте на то, что Agent всё ещё помнит существенные детали.

```text theme={null}
Контекст: этот проект — приложение с листом ожидания для местных фитнес-тренеров.
Основной сценарий: лендинг → форма регистрации → сообщение с подтверждением.
В этой ветке улучшай только сообщение с подтверждением и последующие тексты.
```

<div id="section-7">
  ## Распространённые заблуждения
</div>

* **«Чем больше контекста, тем лучше»** — лучше, когда контекст релевантный. Избыток лишней информации рассеивает внимание модели.
* **«Модель всё идеально помнит»** — ИИ использует доступный контекст, но важные ограничения стоит повторять в ключевые моменты.
* **«Контекст — это только текст»** — скриншоты, файлы, данные, макеты, логи и примеры тоже являются контекстом.
