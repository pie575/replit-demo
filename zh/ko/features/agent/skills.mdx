<div id="section">
  ## 什么是技能？
</div>

技能就是一个文件夹，其中包含一个名为 `SKILL.md` 的文件，用于存放 Agent 需要遵循的指令，以及你希望 Agent 参考的其他辅助文件。技能位于项目的 `/.agents/skills` 目录中，遵循通用于各类 agent 的开放标准 [Agent Skills specification](https://agentskills.io/specification)。

Agent 可以看到所有已安装技能的名称和描述，但只有在与当前任务相关时才会加载完整内容。这让技能对上下文的占用非常高效，因此你可以安装大量技能，而不必担心 Agent 的输出质量下降。

<div id="section-2">
  ## 预定义技能
</div>

Replit 提供了一组预定义技能，可在聊天的**使用技能**选择器以及新建项目的起始点选择器中使用。这些技能无需安装即可在所有项目中使用。如需查看完整目录、合作伙伴技能以及安装方法，请参阅 [Skills directory](/zh/ko/features/agent/skills-directory)。

要添加预定义技能，请在聊天输入框中打开**使用技能**选择器并选择相应技能，或直接让 Agent 加载该技能。

<div id="section-3">
  ## 技能适用范围
</div>

技能可在不同层级使用：

| 范围        | 可用范围        | 存储位置                                                                           |
| --------- | ----------- | ------------------------------------------------------------------------------ |
| **项目级别**  | 仅限单个项目      | 在 `/.agents/skills` 中与文件一同进行版本控制                                               |
| **工作区级别** | 工作区内所有人均可使用 | 在 Workspace 设置中集中管理                                                            |
| **企业版**   | 全公司的统一标准    | 包含在[自定义模板](/zh/ko/teams/custom-templates)和[设计系统](/zh/ko/teams/custom-design-system)中 |

如需了解工作区级别的技能，请参阅 [Agent 自定义](/zh/ko/features/agent/agent-customization)，了解如何为团队设置工作区技能和自定义指令。

<div id="agent">
  ## Agent 如何加载技能
</div>

Agent 会在每次对话中读取所有已安装技能的元数据 (名称和描述) 。只有当 Agent 判断某个技能与当前任务相关时，才会加载该技能的完整内容。这样，在真正需要之前，技能内容不会占用上下文窗口。

已安装的技能会跨 Agent 会话保留在项目中，还可以提交到版本控制系统，便于团队共享。

<div id="ai">
  ## 与其他 AI 编程工具配合使用
</div>

<Accordion title="从其他 AI 编程工具导入技能">
  如果你同时使用多个 AI 编程工具，[rulesync](https://github.com/dyoshikawa/rulesync) 已支持 Replit，可帮助你保持配置一致。

  你可以从其他 AI 编程助手导入技能：

  ```bash theme={null}
  npx rulesync init
  npx rulesync import --targets claudecode --features skills
  npx rulesync generate --targets replit --features skills
  ```

  这样，你只需维护一套技能，即可在多个开发环境中通用。
</Accordion>
