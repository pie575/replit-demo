  ## 团队和 Enterprise
</div>

<div id="replit-enterprise">
  ### 无需离开 Replit 即可升级到 Enterprise
</div>

现在，无论你使用的是免费、Core 还是 Pro 计划，都可以直接升级到 Replit Enterprise，无需跳出产品，也无需事先联系销售团队。如果你有协作工作区，完成付款后会自动迁移到新的 Enterprise 组织。已发布的应用将持续运行，不会出现停机。

<div id="section-2">
  ## 账单
</div>

<div id="stripe">
  ### 安装应用即可连接 Stripe，无需复制密钥
</div>

借助 Stripe 让应用上线变得更简单了。现在无需再从 Stripe 仪表板复制实时 API 密钥，只需在 Stripe Marketplace 中安装 Replit Integrated Payments 应用，生产环境密钥便会自动连接。打开发布面板，安装应用，然后在 Stripe 中完成连接。

  <img src="/assets/mirror/stripe-replit-integrated-payments-23b3b2386671.png" alt="聊天面板中 Agent 的 “Connect to Stripe” 连接器卡片。带有 Stripe S 徽标的卡片标题 “Connect to Stripe”；副标题“使用 Stripe 沙盒测试支付功能。直接在 Replit 中创建产品并测试交易。” 关闭按钮与连接 Stripe 按钮。" width="2678" height="1448" data-path="images/billing/stripe-replit-integrated-payments.png" />
</Frame>

详细了解[使用 Stripe 上线](/zh/ko/features/monetization/stripe-payments#go-live)。

  ### 使用 Tripo3D 连接器生成 3D 模型
</div>

<div id="agent">
  ## Agent
</div>

<div id="agent-2">
  ### Agent 可生成音乐、音效和语音
</div>

Agent 现在可以为你的应用生成音频。只要提出背景音乐、音效或语音旁白的需求，Agent 就会生成音频并直接添加到项目中。相关使用量将以 Replit 积分计费。

了解更多关于[音频生成](/zh/ko/features/agent/audio-generation)的信息。

<div id="section-4">
  ## 工作区
</div>

<div id="canvas">
  ### 在 Canvas 中直接生成媒体
</div>

现在你可以直接在 Canvas 中生成媒体。在 Canvas 工具栏中打开**生成**工具，选择**图像**、**矢量图形**或**视频**，即可原地生成。整个流程都保留在画板上，无需切换工具即可完成设计与迭代。
