<div id="databricks-apps-integration">
  ### Intégration Databricks Apps
</div>

Les créateurs Enterprise peuvent désormais concevoir des applications exploitant leurs données sur Replit et les déployer directement sur Databricks. Agent se connecte à votre environnement Databricks et peut examiner le schéma de vos données sans que celles-ci ne quittent Databricks. Une fois votre application prête, publiez-la directement sur Databricks Apps. L&#39;application en cours d&#39;exécution est intégralement hébergée dans Databricks et hérite de l&#39;authentification Databricks, de la gouvernance Unity Catalog et de vos restrictions réseau existantes.

<Frame>
  <img src="/assets/mirror/databricks-app-template-333354ec6944.png" alt="Workspace Replit affichant le template Databricks App sélectionné dans le menu déroulant Modèles" width="1368" height="395" data-path="images/changelog/2026-04-10/databricks-app-template.png" />
</Frame>

Cette intégration est disponible pour les organisations Enterprise disposant d&#39;un workspace Databricks. Pour en savoir plus, consultez la [page partenaire Replit x Databricks](https://replit.com/partners/databricks).

<div id="recreate-any-ui-from-a-screenshot">
  ### Recréez n&#39;importe quelle UI à partir d&#39;une capture d&#39;écran
</div>

Collez une capture d&#39;écran dans Agent et demandez-lui de « build this » ou « recreate this UI ». Agent reproduit le design avec une grande fidélité en une seule passe, aussi bien pour les web apps que pour les slide decks. Pratique pour répliquer des designs existants, reconstruire des UI de référence ou prototyper rapidement à partir d&#39;un mockup.

<div id="razorpay-payments-for-india">
  ### Paiements Razorpay pour l&#39;Inde
</div>

Les créateurs en Inde peuvent désormais payer par UPI et par carte via Razorpay. La prise en charge de l&#39;e-mandat est incluse pour les abonnements récurrents, comme l&#39;exige la Reserve Bank of India. Si vous êtes déjà abonné en Inde, vous pourrez bientôt passer de Stripe à Razorpay depuis votre page de facturation.

<div id="revenuecat-app-store-connect-sync">
  ### Synchronisation RevenueCat avec App Store Connect
</div>

L&#39;intégration RevenueCat inclut désormais la synchronisation automatique avec Apple. Lorsque vous configurez des achats intégrés dans RevenueCat, cette configuration est directement synchronisée avec App Store Connect.

En savoir plus sur les [abonnements RevenueCat](/fr/core-concepts/monetization/revenuecat-subscriptions).

<div id="choose-where-your-app-runs-with-publishing-geography">
  ### Choisissez où s&#39;exécute votre app grâce à la zone géographique de publication
</div>

Les créateurs Core, Pro et Enterprise peuvent désormais choisir la zone géographique dans laquelle leur app est publiée. Lorsque vous publiez dans une zone géographique, vos artefacts de calcul, de Database et d&#39;Object Storage sont tous regroupés dans cette même région. Un proxy dédié à cette zone permet de réduire la latence pour les visiteurs de votre app.

L&#39;Europe est désormais disponible aux côtés de l&#39;Amérique du Nord, et l&#39;Australie, l&#39;Amérique du Sud et l&#39;Asie arriveront prochainement. Les admins Enterprise peuvent également restreindre leur organisation à une seule zone géographique à des fins de conformité.

  ### Factures passées dans la page d&#39;utilisation

Vous pouvez désormais consulter vos factures passées directement depuis la page **Usage** des paramètres de votre compte. Sélectionnez une période de facturation antérieure dans le menu déroulant pour afficher le détail complet de la consommation par app.
