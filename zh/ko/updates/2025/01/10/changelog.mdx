<div id="slack">
  ### Slack 集成
</div>

Agent 现已与 Slack API 集成。也就是说，你可以使用 Agent 构建具备以下功能的应用：

* 发送消息
* 读取历史消息

覆盖你喜欢的任意 Slack 频道。

<Frame>
  <img src="/assets/mirror/slack-integration-1072c585c41e.png" alt="Slack 集成" width="1640" height="739" data-path="images/changelog/2025-01-10/slack-integration.png" />
</Frame>

欢迎将你构建的作品提交到 [Agent Showcase](https://forms.gle/qxpfr82wNpKsCdok9)。

<div id="agent-assistant">
  ### Agent 和 Assistant 改进
</div>

* Agent 现在可在首页更快加载，让你更快开始构建。
* 现在，在控制台和 Shell 中选择文本时，可通过浮动弹窗快速访问 Assistant。选中文本后，点击 Assistant 图标即可提问。

<Frame>
  <img src="/assets/mirror/ask-assistant-cd529bf4a0b1.png" alt="向 Assistant 提问" width="2532" height="1474" data-path="images/changelog/2025-01-10/ask-assistant.png" />
</Frame>

<div id="bash">
  ### Shell Bash 自动补全
</div>

Shell 现已支持自动补全！连按两次 Tab 键即可自动补全命令。

<Frame>
  <img src="/assets/mirror/tab-tab-6e4a56285881.webp" alt="Tab Tab" width="720" height="405" data-path="images/changelog/2025-01-10/tab-tab.webp" />
</Frame>

<div id="elixir">
  ### Elixir 生态系统修复
</div>

Elixir 的 mix 工具问题已修复，该语言现在可以按预期正常运行。

<div id="ux">
  ### 自定义域名体验优化
</div>

现在，将 URL 粘贴到自定义域名输入框后，Replit 会自动提取其中的域名。

<div id="section-3">
  ### 更强大的项目推荐控制
</div>

现在，将组织的公开项目设为推荐或取消推荐更加简单！

<Frame>
  <img src="/assets/mirror/feature-on-profile-95b81a71e0d7.png" alt="个人资料页上的推荐项目" width="1836" height="644" data-path="images/changelog/2025-01-10/feature-on-profile.png" />
</Frame>

现在，你可以通过项目信息弹窗和项目索引表格，直接在工作区中控制项目的推荐状态。

<Frame>
  <img src="/assets/mirror/profile-preview-b8f2ecfed154.png" alt="个人资料预览" width="2126" height="1152" data-path="images/changelog/2025-01-10/profile-preview.png" />
</Frame>

此外，将项目设为推荐后，你还可以预览它在公开个人资料页上的显示效果。
