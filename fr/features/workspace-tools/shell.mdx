Le Shell vous permet de travailler sur vos projets, comme dans un terminal classique, pour gérer les fichiers,
installer des packages et exécuter des scripts. Par exemple, vous pouvez parcourir les fichiers du projet ou
utiliser `psql` lorsque votre projet dispose d'une connexion à une base de données configurée.

<Tip>
  Pour une meilleure gestion des workflows, préférez le bouton **Exécuter**
  plutôt que de lancer votre application depuis le Shell. Le workflow démarré
  par le bouton **Exécuter** envoie les sorties vers l'outil Console, ce qui
  offre une façon structurée d'examiner les journaux.
</Tip>

## Fonctionnalités

Le Shell offre les capacités suivantes :

* **Exécuter plusieurs shells** : Ouvrez plusieurs instances de shell pour travailler sur différentes tâches simultanément
* **Rechercher du texte** : Trouvez du texte spécifique dans la sortie du shell

### Confirmer l'accès au Shell

Pour confirmer que le Shell est prêt et afficher l'espace de travail actuel, exécutez :

```sh theme={null}
pwd
```

Le Shell affiche le chemin de l'espace de travail actuel.

<Frame caption="La commande pwd affiche le chemin de l'espace de travail actuel et revient à l'invite du Shell.">
  <img src="/assets/mirror/shell-pwd-output-2d31a0e0466b.jpg" alt="Onglet Shell affichant la commande pwd, le chemin de l'espace de travail en sortie et une invite retournée" width="1280" height="246" data-path="images/workspace/shell-pwd-output.jpg" />
</Frame>

Pour un projet disposant d'une base de données, sélectionnez **Outils** → **Base de données**, puis ouvrez la page
**Base de données de développement**. Cette page fournit les informations de connexion. Gardez les
valeurs de connexion privées ; ne les copiez pas dans la documentation, les captures d'écran,
les journaux, le code source ou les messages partagés.

### Recherche de texte

Les étapes suivantes décrivent comment accéder et utiliser l'outil de recherche de texte :

1. Sélectionnez la <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="icône loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> loupe en haut à droite de l'onglet Shell pour ouvrir la boîte de dialogue de recherche.
2. Saisissez un terme de recherche et sélectionnez **Suivant** pour naviguer entre les correspondances.
3. Utilisez **Précédent** pour revenir aux correspondances précédentes.
4. Sélectionnez **Quitter** ou cliquez en dehors de la boîte de dialogue pour fermer la recherche de texte.

### Plusieurs shells

Pour créer un autre shell :

1. Sélectionnez le menu des instances de Shell dans l'en-tête du panneau Shell.
2. Sélectionnez **Nouveau Shell**.

<Frame>
  <img src="/assets/mirror/shell-new-94a280c1230f.png" alt="Menu des instances de Shell avec l'espace de travail actuel et l'option Nouveau Shell" width="1280" height="224" data-path="images/workspace/shell-new.png" />
</Frame>

Utilisez le même menu pour passer d'un shell à l'autre. Replit étiquette chaque shell avec la dernière commande exécutée pour vous aider à les identifier.

<Warning>
  Lorsque vous ouvrez plusieurs shells, Replit ferme automatiquement les
  instances de shell inactives. Un shell inactif est celui qui n'est pas
  sélectionné et n'exécute aucun processus utilisateur.
</Warning>
