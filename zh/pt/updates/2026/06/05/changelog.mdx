<div id="venda-produtos-fsicos-com-o-shopify">
  ### 使用 Shopify 销售实体商品
</div>

现在你可以创建销售实体商品的在线商店。只需让 Agent 创建商店，它就会为你建立 Shopify 商店、添加商品，并配置购物车和结账流程。Agent 会提供一个认领商店的链接，之后你只需订阅 Shopify 套餐并接入支付即可正式上线。

<div id="crie-aplicativos-de-dados-no-microsoft-fabric">
  ### 在 Microsoft Fabric 中构建数据应用
</div>

现在，你可以在 Replit 中借助 AI 构建数据应用，并直接发布到 Microsoft Fabric。从 Microsoft Fabric 模板入手，连接 Power BI 语义模型，然后让 Agent 基于你受管控的企业数据创建仪表板和内部工具，同时将身份验证和访问策略保留在 Fabric 内。

<div id="domnios-personalizados-configuram-seu-prprio-dns">
  ### 自定义域名自动配置 DNS
</div>

绑定自己的域名现在简单多了。绑定时，Replit 会通过 Entri 自动配置所需的 DNS 记录，你无需再到域名服务商处手动复制记录。选好域名并确认，剩下的交给 Replit。

了解更多关于[自定义域名](/zh/pt/features/publishing/custom-domains)的信息。

  ## Agent
</div>

<div id="melhore-seu-ranking-de-busca-com-o-seo-agent">
  ### 使用 SEO Agent 提升搜索排名
</div>

SEO Agent 会分析你已部署的应用，找出导致搜索引擎和 AI 工具无法发现它的问题。每个问题都附带一键修复方案，你可以先查看再应用。在项目中打开 **Growth** 面板即可运行分析。

<div id="use-o-stripe-em-workspaces-colaborativos">
  ### 在协作 workspace 中使用 Stripe
</div>

Stripe 现已支持协作 workspace，整个团队可以一起构建、测试同一个应用并实现变现。workspace 中的所有成员都可以使用已连接的 Stripe 账户，无需各自单独开发支付功能。

了解更多关于 [Stripe 支付](/zh/pt/features/monetization/stripe-payments) 的信息。
