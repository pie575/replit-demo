创建一个包含活动日程、演讲嘉宾、场地、交通指南和票务结账功能的完整付费活动网站。
将参与者信息存储在 Replit Database 中，通过 Stripe 收款，使用 Resend 发送确认邮件，并导出名单。分享链接前，先进行一次测试下单。

* 需要在应用内编辑议程、无需独立内容管理系统的社区负责人

<div id="section-6">
  ## 故障排查
</div>

* **未收到确认邮件：** 确认 Resend 已连接且发件域名已通过验证。提交一笔测试订单，然后在 Resend 控制面板中确认邮件是否已发送。
* **演讲嘉宾或时间不正确：** 告知 Agent Notion 数据库中的信息 (姓名、照片、职位、简介、场次时间) ，并要求在 Notion 发生变更时同步更新页面。
* **无法在结账时付款：** 确认 Stripe 已连接，并先在测试模式下进行操作。分享链接前，先提交一笔测试订单。
