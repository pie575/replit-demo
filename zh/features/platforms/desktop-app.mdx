<a href="https://replit.com/desktop" target="_blank">Replit 桌面应用</a>将完整的 Replit 体验带到你的电脑上。在专属应用中使用 Agent 构建，享受浏览器标签页无法带来的原生体验细节。

<div id="what-is-the-replit-desktop-app">
  ## 什么是 Replit 桌面应用
</div>

Replit 桌面应用是一款面向 Windows 和 Mac 重新设计的原生应用。它与网页端体验完全一致，让你在同一个窗口中创建应用、与 Agent 对话并完成发布。在此基础上，它还带来了一些只有桌面应用才能实现的功能：

* **多任务处理**：同时处理多个 Replit App。
* **状态提示**：一眼即可看出 Agent 何时需要你介入或已完成工作。
* **标签页预览**：无需来回切换，就能快速查看已打开的应用。

    打开下载的文件，按提示完成安装。安装完成后启动应用。

<Tip>
  你的应用、历史记录和设置在桌面应用和网页端完全一致。在一端开始，就能在另一端接着做。
</Tip>

<div id="for-enterprise-teams">
  ## 面向 Enterprise 团队
</div>

桌面应用让你可以轻松地在整个组织中部署 Replit。由于其安装方式与其他桌面应用无异，你的 IT 团队可以通过设备管理 (MDM) 服务商，在公司电脑上自动分发和安装。如需了解更多信息，请联系你的客户经理。
