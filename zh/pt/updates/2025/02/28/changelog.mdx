<div id="agent-v2">
  ### Agent v2
</div>

<img src="/assets/mirror/agent-web-01b1f9026de7.webp" alt="Agent v2" width="800" height="450" data-path="images/changelog/2025-02-28/agent-web.webp" />

全新的 Agent 体验现已向所有创作者开放。新版 Agent 比上一版更快、更精准、更强大。

它现在由 Anthropic 迄今最先进的模型 Claude 3.7 Sonnet 提供支持。

加入 Explorer 计划即可抢先体验，操作说明请见[这里](https://youtu.be/pE_XT2TaXCA)。

  ### 部署改进
</div>

当创作者为动态应用选择静态部署时，现在会显示 AI 建议，从而改进 Agent 处理部署请求时的表现。

  ### Claude 3.7 Sonnet 发布
</div>

Assistant 的 Advanced 模式已面向所有付费创作者升级至 Claude 3.7 Sonnet，处理复杂请求时更准确、更强大。

<div id="melhoria-no-desempenho-do-banco-de-dados">
  ### 数据库性能提升
</div>

数据库操作现在比以往更快，其中耗时最长的操作已从 200 毫秒降至 1 毫秒以内。

<div id="documentao-aprimorada">
  ### 文档优化
</div>

<img src="/assets/mirror/cleanshot-2025-02-27-at-1042282xpng-220848-e5317a7cfb93.png" alt="文档改版" width="3680" height="2382" data-path="images/changelog/2025-02-28/cleanshot-2025-02-27-at-1042282xpng-220848.png" />

我们重新设计了文档，使其更易读、更好用，并全面适配大语言模型。

文档现已新增“复制页面”按钮，可将整页内容复制为 markdown 格式。你还可以通过 `llms.txt` 和 `llms-full.txt` 为文档建立索引，供自己的大语言模型使用。

* [https://docs.replit.com/llms.txt](https://docs.replit.com/llms.txt)
* [https://docs.replit.com/llms-full.txt](https://docs.replit.com/llms-full.txt)
