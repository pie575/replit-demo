Replit Agent подключается к внешним инструментам и источникам данных через [Model Context Protocol (MCP)](https://modelcontextprotocol.io) — открытый стандарт интеграции с ИИ. Любой из указанных ниже серверов можно установить одним щелчком. После установки Agent автоматически загрузит соответствующий инструмент и будет использовать его в подходящих случаях.

Обзор концепции см. в разделе [Model Context Protocol](/ru/ko/learn/model-context-protocol). Практическое руководство см. в разделе [Подключение через MCP](/ru/ko/build/connect-via-mcp). Чтобы подключить сервер, которого нет в этом списке, см. раздел [Добавление пользовательского MCP-сервера](/ru/ko/build/connect-via-mcp#add-a-custom-mcp-server).

<Info>
  Чтобы установить сервер, выберите **Добавить в Replit**. В редакторе проекта появится запрос на подтверждение подключения.
</Info>

<div id="section-2">
  ## Защита
</div>

Весь трафик MCP проходит через сканер безопасности Replit. Сканер оценивает определения инструментов и запланированные действия, блокируя подозрительные или небезопасные инструменты до их запуска. Если инструмент будет отклонён, Agent сообщит об этом.

<div id="section-3">
  ## Параметры аутентификации
</div>

* **Динамическая регистрация OAuth-клиента** — если сервер поддерживает OAuth DCR, Replit автоматически обнаружит это и зарегистрирует клиент. Этот способ используется для большинства предварительно зарегистрированных серверов.
* **Пользовательские заголовки** — укажите одну или несколько пар «имя — значение» заголовка (например, `X-API-Key`). Replit добавляет эти заголовки ко всем MCP-запросам, чтобы сервер мог идентифицировать вызывающую сторону. Используйте этот вариант при добавлении пользовательского сервера со статической аутентификацией по токену.

<div id="section-4">
  ## Поделитесь ссылкой для установки
</div>

Ссылка для установки позволяет добавить MCP-сервер в Replit одним щелчком. Создайте её в формате [Подключение через MCP](/ru/ko/build/connect-via-mcp#share-an-install-link) или вручную: закодируйте JSON-полезную нагрузку в base64 и добавьте её к `https://replit.com/integrations?mcp=`.

```json theme={null}
{
  "displayName": "My MCP Server",
  "baseUrl": "https://example.com/mcp",
  "headers": [{ "key": "Authorization", "value": "Bearer your-token" }]
}
```

* **displayName** — имя, отображаемое при установке
* **baseUrl** — HTTPS-эндпоинт MCP-сервера
* **headers** — необязательные заголовки для аутентификации
