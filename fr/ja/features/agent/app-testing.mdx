Le test d&#39;application permet à Agent de tester dans un véritable navigateur l&#39;application que vous avez créée. Agent navigue dans l&#39;application et clique comme le ferait un utilisateur réel afin d&#39;en vérifier les fonctionnalités. Grâce à cette capacité d&#39;auto-test, vous avez l&#39;assurance que votre application fonctionne correctement, et Agent peut détecter et corriger les problèmes automatiquement.

Lorsque les tests d’application sont activés, Agent effectue régulièrement des autotests lorsqu’il estime que les modifications sont suffisamment importantes. Agent ne teste pas après chaque message utilisateur : il détermine intelligemment le moment où les tests sont les plus utiles.

<Note>
  Les tests d’application sont actuellement disponibles pour les applications web JavaScript full stack et Python Streamlit.
</Note>

<div id="section-2">
  ### Principaux avantages
</div>

* **Autonomie accrue :** Agent peut travailler longtemps sans intervention humaine
* **Qualité améliorée :** créez des applications avec moins d’erreurs en détectant et en résolvant les problèmes rapidement
* **Rentabilité :** évitez des sessions de débogage supplémentaires en détectant les problèmes pendant le développement
* **Révision interactive :** propose des relectures vidéo et une navigation par section pour analyser les résultats en détail

<div id="section-3">
  ### Le processus de test
</div>

Voici comment se déroule l&#39;autotest réalisé par Agent :

1. **Aperçu du navigateur** : un aperçu du navigateur s&#39;affiche dans le volet Agent
2. **Test visuel** : vous voyez le curseur d&#39;Agent cliquer dans l&#39;application pour en tester les fonctionnalités
3. **Simulation d&#39;un utilisateur réel** : Agent navigue dans l&#39;application comme le ferait un véritable utilisateur et saisit des données fictives si nécessaire
4. **Analyse automatique** : Agent analyse les résultats des tests et identifie les problèmes
5. **Autocorrection** : Agent présente un résumé des résultats des tests et corrige automatiquement les problèmes rencontrés

<div id="section-4">
  ## Fonctionnalités principales
</div>

Agent teste intelligemment votre application en la parcourant comme le ferait un utilisateur réel, et couvre les aspects suivants :

* **Vérification de l&#39;interface utilisateur** : boutons, formulaires, navigation, éléments visuels
* **Vérification des fonctionnalités** : fonctions principales et parcours utilisateur
* **Tests d&#39;intégration** : appels d&#39;API, opérations de base de données, services tiers
* **Performances et accessibilité** : temps de chargement, réactivité, normes d&#39;accessibilité

<div id="section-5">
  ## Utilisation
</div>

Le test d&#39;application se trouve dans les **paramètres avancés** du menu déroulant des réglages d&#39;Agent, dans la zone de saisie du chat. Activez-le lorsque vous utilisez le mode Economy ou Power. En mode Lite, le test d&#39;application reste désactivé.

<Note>
  Le test d&#39;application fait partie des capacités autonomes d&#39;Agent, au même titre que la revue de code intégrée. Découvrez les autres [fonctionnalités d&#39;Agent](/fr/ja/features/agent/overview).
</Note>

<div id="section-6">
  ## Prise de contrôle
</div>

Pendant les tests, Agent peut rencontrer des blocages nécessitant votre intervention pour poursuivre. Le cas le plus fréquent est lorsqu’une connexion à un compte utilisateur, tel que Gmail, est requise. Dans ce cas, Agent affiche une fenêtre contextuelle avec le bouton « Démarrer la prise de contrôle ».

<Frame>
  <img src="/assets/mirror/app-testing-takeover-6e0b0b56f4d0.png" alt="Interface de prise de contrôle des tests d’application affichant les boutons « Ignorer » et « Démarrer la prise de contrôle », avec des instructions de gestion des erreurs et des CAPTCHA" width="924" height="358" data-path="images/replitai/app-testing-takeover.png" />
</Frame>

Appuyez sur « Démarrer la prise de contrôle », puis cliquez dans l’aperçu du test pour effectuer les étapes nécessaires afin qu’Agent puisse poursuivre. Vous pouvez également appuyer sur « Ignorer » pour passer la prise de contrôle et mettre fin au test de l’application si Agent ne peut pas poursuivre sans votre aide. Si vous ne répondez pas dans les 10 minutes, Agent poursuit comme si vous aviez appuyé sur « Ignorer ».

<div id="section-7">
  ### À quoi s&#39;attendre
</div>

* **Option Ignorer** : ignorez un test si nécessaire et poursuivez le développement
* **Relecture vidéo interactive** : une fois le test terminé, cliquez sur la vidéo pour revoir l&#39;intégralité de la session
* **Navigation par section** : utilisez le curseur situé en bas pour accéder directement à une section précise du test

<div id="section-8">
  ## Dépannage
</div>

**Si les tests échouent de manière inattendue**

* Ignorez le test, puis ressaisissez l’invite et réessayez
* Vérifiez les contenus dynamiques susceptibles d’affecter le moment d’exécution des tests
* Vérifiez l’exactitude du scénario de test

**Si la couverture des tests est insuffisante**

* Fournissez une description détaillée des fonctionnalités de l’application
* Indiquez explicitement les parcours utilisateur importants à tester

**Si les tests d’application ne fonctionnent pas du tout**

* Les tests d’application ne prennent actuellement en charge que les applications web[*](#アプリテストの仕組み)

<div id="section-9">
  ## Tarification et consommation
</div>

Les tests d’application sont inclus dans le modèle de tarification d’Agent basé sur les efforts fournis et impliquent des considérations importantes en matière de coûts :

* **Basée sur l’utilisation** : les tests sont facturés selon les efforts fournis (les tests les plus simples coûtent moins cher)
* **Équilibre entre coûts et avantages** : les tests ont un coût, mais ils peuvent vous faire économiser de l’argent en détectant les erreurs tôt et en évitant des prompts supplémentaires et du travail superflu d’Agent
* **Développement efficace** : les approches automatisées réduisent le besoin de débogage manuel et de retouches

<Tip>
  **Tests économiques** : les tests d’application augmentent les coûts d’utilisation, mais permettent souvent de réduire les coûts globaux en évitant d’avoir recours à des sessions Agent supplémentaires pour corriger des problèmes que les tests auraient pu détecter.
</Tip>

<div id="section-10">
  ## Prochaines étapes
</div>

Prêt à utiliser les tests d&#39;application dans votre projet ?

1. **Commencez à créer** : créez une application avec Agent et attendez que les tests se lancent automatiquement
2. **Examinez les résultats** : consultez le rapport de test et mettez en œuvre les améliorations suggérées
3. **Itérez** : utilisez les retours des tests pour améliorer votre application
4. **Passez à l&#39;échelle** : appliquez les tests d&#39;application à des projets plus grands et plus complexes
