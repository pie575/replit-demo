여기서는 커스텀 도메인 연결과 문제 해결을 다룹니다. 전체 참고 자료는 [커스텀 도메인 추가](/ko/build/add-custom-domain)와 [Custom Domains](/ko/features/publishing/custom-domains)를 확인하세요.

<AccordionGroup>
  <Accordion title="Replit App에 커스텀 도메인을 어떻게 연결하나요?">
    Replit에서 도메인을 구매했다면 DNS 레코드가 자동으로 관리됩니다. **Publishing → Domains**를 열고 화면에 안내된 설정 절차를 따르세요. [Domain purchasing](/ko/build/domain-purchasing)을 참고하세요.

    외부 registrar의 도메인을 연결하려면:

    1. project를 열고 **Publishing → Domains**로 이동합니다.
    2. **Connect your own domain**을 선택하고 도메인을 입력한 뒤 계속 진행합니다.
    3. Replit이 A 레코드와 TXT 레코드를 표시합니다. 둘 다 복사하세요.
    4. DNS provider에서 두 레코드를 모두 추가합니다.
    5. Replit으로 돌아와 검증을 시작합니다.

    몇 가지 중요한 참고 사항:

    * SSL을 사용하려면 A 레코드와 TXT 레코드가 모두 필요합니다. Apex(루트) CNAME은 지원되지 않으므로 루트 도메인에는 A 레코드를 사용하세요.
    * 와일드카드 인증서(`*.example.com`)는 지원되지 않습니다. 각 서브도메인을 개별적으로 연결하세요.
    * Cloudflare에서는 프록시 모드가 SSL 설정을 막지 않도록 A 레코드를 **DNS only**(회색 구름)로 설정하세요.
    * DNS 변경 사항이 전파되는 데 최대 48시간이 걸릴 수 있습니다.

    전체 참고 자료는 [Custom Domains](/ko/features/publishing/custom-domains)를 확인하세요.
  </Accordion>

  <Accordion title="도메인이 검증되지 않거나 SSL이 provisioning되지 않습니다. 어떻게 해결하나요?">
    다음 항목을 순서대로 확인하세요. 대부분의 문제는 이 중 하나가 원인입니다.

    1. **DNS 전파를 기다리세요.** 변경 사항이 반영되는 데 최대 48시간이 걸릴 수 있습니다. DNS 조회 도구로 레코드가 전 세계에서 조회되는지 확인하세요.
    2. **AAAA 레코드를 제거하세요.** A 레코드와 같은 호스트명에 IPv6(AAAA) 레코드가 있으면 SSL이 차단될 수 있습니다.
    3. **오래되었거나 충돌하는 A 레코드를 제거하세요.** 루트 도메인에는 Replit을 가리키는 A 레코드 하나만 남기세요.
    4. **Cloudflare를 DNS only로 설정하세요.** 주황색 구름(프록시 모드)은 SSL provisioning을 방해합니다.
    5. **도메인 연결을 해제한 뒤 다시 연결하세요.** **Publishing → Domains → Manage**에서 진행하면 인증서가 새로 발급됩니다. 몇 분 기다린 후 새로고침하세요.
    6. **CAA 레코드를 확인하세요.** Replit은 Let&#39;s Encrypt를 통해 인증서를 발급하므로, CAA 레코드가 있다면 최소 하나는 Let&#39;s Encrypt를 발급자로 허용해야 합니다.

    이 확인 사항은 외부에 등록된 도메인에 해당합니다. Replit에서 도메인을 구매했다면 [Replit Support에 문의](https://replit.com/support)하세요. [Custom Domains](/ko/features/publishing/custom-domains)를 참고하세요.
  </Accordion>

  <Accordion title="커스텀 도메인에서 Clerk 인증을 어떻게 설정하나요?">
    커스텀 도메인에서 [Clerk 인증](/ko/features/auth-and-identity/clerk-auth)을 사용할 때 흔히 겪는 문제는 다음과 같습니다.

    * **&quot;Clerk CNAME records required&quot; 경고.** 이는 Clerk integration의 요구 사항일 뿐이며, 도메인 검증이나 SSL에는 영향을 주지 않습니다. **Publishing → Domains**를 열고 **Manage**를 선택한 뒤, authentication DNS 설정 섹션을 찾아 나열된 각 CNAME 레코드를 DNS provider에 그대로 추가하세요. 해당 섹션이 보이지 않으면 도메인 연결을 해제하고 다시 연결하세요.
    * **이전에 Clerk를 사용해 도메인이 Verifying 상태에서 멈춤.** 도메인이 다른 Clerk 애플리케이션에 연결되어 있었다면 [Clerk Dashboard](https://dashboard.clerk.com)에서 해당 도메인을 제거한 후, Replit에서 도메인 연결을 해제하고 다시 연결하세요.
    * **직접 운영하는 Clerk 인스턴스로 이전.** Replit이 관리하는 Clerk에서 직접 운영하는 인스턴스로 전환하려면 수동 작업이 필요하니 [Replit Support에 문의](https://replit.com/support)하세요. [직접 만든 Clerk 앱을 사용할 수 있나요?](/ko/features/auth-and-identity/clerk-auth#can-i-bring-my-own-clerk-app-instead-of-using-the-replit-managed-one)를 참고하세요.

    그래도 해결되지 않는다면 도메인 이름, project 이름, 이미 시도해 본 내용을 함께 적어 [Replit Support에 문의](https://replit.com/support)하세요.
  </Accordion>
</AccordionGroup>
