Коннектор Shopify позволяет Agent создать магазин Shopify, собрать индивидуальную витрину и управлять товарами и запасами без API-ключей — всё в одном диалоге. Просто скажите, что продаёте физические товары, и Agent сам предложит Shopify; зайти в Shopify придётся лишь при запуске магазина. От первого промпта до первого реального заказа — около 10 минут.

<Note>
  Пошаговое руководство см. в разделе [Создание витрины Shopify](/ru/ko/build/ecommerce-store).
</Note>

<div id="section">
  ## Что можно создать
</div>

* Витрину с уникальным дизайном для продажи физических товаров
* Магазин фирменного мерча и одежды
* D2C-магазин с корзиной и платежом
* Инструменты для каталога и учёта товаров на базе магазина Shopify
* Лендинг товара для продажи одного флагманского продукта

  ## Как это работает
</div>

<Steps>
  <Step title="Опишите свой магазин">
    Расскажите Agent, что вы хотите продавать. Для физических товаров он порекомендует Shopify, даже если вы не упомянете его по имени.

    </Frame>
  </Step>

  <Step title="Agent создаёт магазин">
    В учётной записи Shopify Partner от Replit создаётся магазин для разработки (около 10 секунд), устанавливается приложение Replit Sales Channel и подключается магазин. API-ключ не требуется. Один магазин на приложение. До тех пор, пока вы не заявите права на него, магазин защищён паролем.

<div id="agent">
  ## Чем управляет Agent
</div>

Всё в витрине и каталоге можно редактировать через чат.

| Область                    | Что делает Agent                                                                                                                                                                                                                                                                                                                                               |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Дизайн                     | Создаёт headless-фронтенд по вашим указаниям (без тем Liquid и библиотек шаблонов). Текст, макет, навигацию, анимацию и страницы товаров можно редактировать через чат, а разные направления — пробовать с помощью вариантов на [Canvas](/ru/ko/design/canvas). Это полноценный проект Replit, поэтому его можно дополнить блогом, списком желаний или лендингом. |
| Товары                     | Создание, изменение и удаление товаров и их опций. Поля: название, описание, тип, поставщик, теги, SKU, цена, вес, опции (размер, цвет), изображения, доступность.                                                                                                                                                                                             |
| Запасы                     | Установка и корректировка запасов по каждой опции.                                                                                                                                                                                                                                                                                                            |
| Коллекции                  | Группировка товаров в коллекции.                                                                                                                                                                                                                                                                                                                               |
| Скидки                     | Создание ценовых правил и промокодов.                                                                                                                                                                                                                                                                                                                          |
| Публикация и синхронизация | Новые товары публикуются в витрине автоматически. Двусторонняя синхронизация: изменения в панели администратора Shopify отражаются в предпросмотре Replit, а изменения Agent — в панели администратора Shopify.                                                                                                                                                                            |

<div id="replit-shopify">
  ## Replit и Shopify: распределение ролей
</div>

| Replit отвечает за                                      | Shopify отвечает за                       |
| ------------------------------------------------------- | ----------------------------------------- |
| Дизайн и создание витрины магазина                      | Встроенный платёж                         |
| Управление каталогом через чат (товары, запасы, скидки) | Учёт товаров, запасов, корзин и заказов   |
| Хостинг и деплой витрины магазина                       | Платежи, проверку личности (KYC), выплаты |
| Варианты дизайна в Canvas                               | Налоги, доставку и выполнение заказов     |
| Расширения приложения (блог, лендинг и т. д.)           | Многоканальные продажи                    |

Заказы, возвраты, выплаты и выполнение заказов обрабатываются в панели администратора Shopify, а не в Agent.

<div id="section-4">
  ## Область подключения
</div>

* Все разработчики во всех приложениях могут подключаться через чат без API-ключей и настройки панели Connectors.
* Одна область действия на приложение: у каждого приложения есть собственный магазин Shopify.
* До момента заявления прав на магазин магазин остаётся принадлежащим Replit магазином для разработки. Ваш адрес электронной почты передаётся Shopify, чтобы вы могли заявить права на магазин позже.
* Вы можете в любое время удалить Replit App в панели администратора Shopify.

<div id="shopify">
  ## Запуск в Shopify
</div>

Запуск выполняется в Shopify, а не в Replit. Попросите Agent запустить процесс Go Live, затем выполните в панели администратора Shopify следующие действия, доступные только владельцу магазина:

* **Заявите права на магазин**: перейдите по ссылке в чате или в письме от Shopify. Срок действия ссылки истекает через 7 дней. После этого начнётся бесплатный пробный период.
* **Выберите тариф**: для обработки реальных заказов необходим [платный тариф](https://www.shopify.com/pricing).
* **Настройте платежи**: активируйте [Shopify Payments](https://help.shopify.com/en/manual/payments/shopify-payments) или другого поставщика и пройдите проверку личности (KYC). Принимать реальные платежи можно после завершения KYC для заявленной учётной записи.
* **Настройте [доставку](https://help.shopify.com/en/manual/shipping) и [налоги](https://help.shopify.com/en/manual/taxes).**
* **Подключите [пользовательский домен](/ru/ko/build/add-custom-domain)** (необязательно), затем удалите пароль магазина, чтобы открыть его для покупателей.

Платёж всегда перенаправляется на платёжную страницу, размещённую Shopify, поэтому покупатели оплачивают покупки через Shopify.

<Note>
  Платежи, проверка личности, налоги, доставка и проверка на мошенничество обрабатываются Shopify. Replit не собирает банковские данные продавца, налоговые идентификаторы или другую конфиденциальную информацию.
</Note>

<div id="section-5">
  ## Устранение неполадок
</div>

<AccordionGroup>
  <Accordion title="Настройка магазина Shopify занимает много времени">
    В процессе подготовки выполняется несколько вызовов API Shopify, поэтому она может занять некоторое время. Дождитесь, пока Agent завершит настройку, и только затем запрашивайте создание витрины.
  </Accordion>

  <Accordion title="При платеже во время разработки открывается страница с паролем">
    Магазины в режиме разработки защищены паролем до перехода в рабочий режим, поэтому предпросмотр платежа может перенаправлять на страницу с паролем. Это ожидаемое поведение, корзина при этом продолжает работать. Удаляйте пароль в Shopify только при запуске магазина.
  </Accordion>

  <Accordion title="Реальные платежи не проходят при оформлении заказа">
    Для реальных платежей необходимо настроить приём платежей в подтверждённом аккаунте Shopify и пройти проверку KYC. До этого платёж будет перенаправляться в Shopify, но списать платёж не получится. Пройдите проверку KYC или используйте аккаунт, в котором платежи уже настроены.
  </Accordion>

  <Accordion title="Agent сообщает, что Shopify не подключён к этому приложению">
    Каждый магазин привязан к одному приложению. Если вы подключили Shopify в другом приложении, попросите Agent настроить магазин Shopify в текущем приложении.
  </Accordion>

  <Accordion title="Товары не отображаются на витрине">
    Товары отображаются, только если они активны и опубликованы. Товары, созданные Agent, публикуются автоматически. Если какого-то товара нет, попросите Agent опубликовать его и обновите предпросмотр.
  </Accordion>

  <Accordion title="После переноса требуется повторное подключение">
    После заявления прав на магазин или его переноса Shopify может запросить повторную авторизацию подключения. Попросите Agent заново подключить Shopify — доступ будет восстановлен без потери данных магазина.
  </Accordion>
</AccordionGroup>
