export const CoreCredits = '$20';

以下解答涵盖 Replit 用户最常提出的账单问题。如需详细了解按用量计费的运作方式，请参阅[按用量计费](/zh/billing/about-usage-based-billing)和[管理支出](/zh/billing/managing-spend)。

<AccordionGroup>
  <Accordion title="为什么我的月度计费周期尚未结束，就被扣费了？">
    当超出每月赠送额度的用量达到设定金额 (即*计费阈值*) 时，Replit 就会计费，而不是等到周期结束时才结算。你的 Core 方案包含 {CoreCredits} 月度额度，超出该额度的 Agent 用量一旦达到阈值即单独计费。

    要降低后续费用：

    1. 使用[规划模式](/zh/features/agent/plan-mode)在 Agent 开始构建前明确并确认工作范围，避免代价高昂的返工。
    2. 如果你订阅了 Core 或 Pro，可使用 [Free Mode](/zh/features/agent/agent-modes) 免费完成日常的 Agent 工作。其额度每五小时重置一次，并设有每周上限。前往 **Settings → Usage** 查看用量。
    3. 需要更强能力时，可选择 Power，价格依然实惠。
    4. 在[管理支出](/zh/billing/managing-spend)中设置用量上限和预算，控制额度之外的费用。
    5. 每个新 task 都新开一个 Agent 对话，让上下文保持精简。

    要查看某笔费用的产生原因，请打开 **Settings → Account usage** 并选择 **See previous invoices**。
  </Accordion>

  <Accordion title="我通过 App Store 或 Google Play 订阅后，无法添加付款方式，该如何解决？">
    当你通过 App Store 或 Google Play 订阅时，账单由 Apple 或 Google 处理，因此移动应用内不会显示付款选项。请改在网页端管理付款：

    1. 打开浏览器，前往 **设置 → 账单**。
    2. 选择 **更新付款方式**。
    3. 输入银行卡信息并保存。

    添加网页端付款方式后，你可以在 **账单** 标签页中管理账单并购买积分包。有关积分包的详情，请参阅[管理支出](/zh/billing/managing-spend)。
  </Accordion>

  <Accordion title="我订阅未满 30 天，可以退款吗？">
    退款资格取决于您的套餐以及您申请退款的项目。请注意以下几点：

    * Agent 和 AI 使用费用不可退款，因为每笔费用都对应已消耗的计算资源。
    * [自定义域名注册费用不可退款](/zh/build/domain-purchasing)。

    如需申请退还订阅费用，请使用注册邮箱[联系 Replit 支持团队](https://replit.com/support)，并说明申请原因。请先在 **Settings → Billing** 中取消订阅。

    <Note>具体的订阅退款期限和退款资格将由支持团队根据您的账户和套餐确认。</Note>
  </Accordion>

  <Accordion title="我被收取了意外的 Agent 或 AI 使用费用，可以退款吗？">
    Agent 和 AI 使用费用不予退款，因为每笔费用均对应 Replit 为运行你的 task 已使用的计算资源。你可以采取以下措施，避免日后产生意外费用：

    1. 打开 **设置 → 账户使用情况**，设置使用限额和预算。请参阅[管理支出](/zh/billing/managing-spend)。
    2. Core 和 Pro 订阅均包含 Free Mode。你可以在额度范围内使用 [Free Mode](/zh/features/agent/agent-modes) 免费完成日常 Agent 工作，或选择 Power，以实惠的价格获得更强的能力。
    3. 在 Agent 开始 Build 前，使用[计划模式](/zh/features/agent/plan-mode)明确工作范围，减少返工。

    如果你认为某笔费用有误，请准备好费用金额、日期和支付意图 ID。该 ID 以 `pi_` 开头，可在发票详情页面找到。然后[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="我取消订阅后仍被扣费——这是正确的吗？">
    取消后仍有扣费，通常有以下两种原因：

    * 您在取消前产生的使用量，直到取消日期之后才达到计费阈值。
    * 系统重试扣除上一计费周期中此前失败的付款。

    如需查看详情，请打开**设置 → 账户使用量**，选择**查看以前的发票**，然后核对发票日期及其涵盖的使用期间。如果仍然觉得不对，请[联系 Replit 支持](https://replit.com/support)，并提供您的 `pi_` 付款意图 ID。
  </Accordion>

  <Accordion title="我的订阅仍然有效，为什么还要收取额外存储空间的费用？">
    当已存储的数据超出套餐包含的限额时，将产生存储费用。有关存储空间的计量方式，请参阅[按用量计费](/zh/billing/about-usage-based-billing)；有关对象存储费用，请参阅[对象存储计费](/zh/billing/object-storage-billing)。

    要查看哪些内容占用了空间，请在项目中打开 Shell 并运行：

    ```bash theme={null}
    du -sh *
    du -ah | sort -rh | head -20
    ```

    然后删除构建产物 (如 `.cache` 或 `dist`) 、旧日志和未使用的上传文件，并清除数据库中的旧数据。释放空间后，后续将不再产生存储费用。
  </Accordion>

  <Accordion title="如何申请自定义域名注册退款？">
    [自定义域名注册费用不予退款](/zh/build/domain-purchasing)，因为域名注册涉及第三方费用，一经处理便无法撤销。

    如果您误注册了域名或希望转移域名，请在[联系 Replit 支持团队](https://replit.com/support)时提供域名以及与您账户关联的电子邮件地址。团队将向您说明可行的选项。
  </Accordion>

  <Accordion title="我已支付账单，但账户仍处于暂停状态——何时会恢复正常？">
    付款确认后，账单冻结可能需要一点时间才能解除。请尝试以下步骤：

    1. 使用 `Cmd+Shift+R` (Mac) 或 `Ctrl+Shift+R` (Windows) 强制刷新浏览器。
    2. 退出登录后重新登录，以刷新账户状态。
    3. 打开 **设置 → 账户使用情况**，选择 **查看以往发票**，确认发票状态显示为已付款。

    冻结解除后，deployment 不会自动重启。如果你的 App 仍处于离线状态，请打开 **Publishing**，选择 **发布**，使其重新上线。如果你的账户仍处于暂停状态，请[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="我不认识一笔来自 Replit 的扣款，该怎么办？">
    在向银行对某笔扣款提出争议之前，请先确认该笔扣款的来源：

    1. 打开 **设置 → 账户使用情况**，选择 **查看过往发票**，并核对日期、金额和说明。
    2. 确认是否有其他人可以访问你的账户或付款方式。
    3. 查找扣款日期前后收到的 Replit 账单邮件，包括垃圾邮件文件夹中的邮件。

    这笔扣款通常是订阅费、达到计费阈值后产生的使用费，或购买信用额度包的费用。

    <Warning>在向银行对扣款提出争议*之前*，请先联系 Replit 支持团队——拒付可能会导致你的账户被锁定。</Warning>

    [联系 Replit 支持团队](https://replit.com/support)，并提供你的 `pi_` 付款意向 ID、扣款金额和日期。
  </Accordion>

  <Accordion title="我的付款被拒绝了——这是 Replit 的问题吗？">
    大多数付款被拒是由您的银行或发卡机构造成的，并非 Replit——通常是系统自动对不熟悉的交易进行安全拦截。请按以下顺序尝试：

    1. 前往 **设置 → 账单 → 更新付款方式**，添加另一张卡后重试。
    2. 致电您的银行，告知对方您正在授权向 Replit 付款，并请其批准该交易。
    3. 如果您的卡限制国际消费，请让银行允许此类交易。

    如果付款仍被拒绝，请[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="我被扣了两次相同金额，这是重复扣费吗？">
    两笔金额相同的扣款不一定是重复扣款。常见原因包括：

    * 订阅费用和等额的积分包，分别显示为单独的条目。
    * 一笔付款失败后重试并成功。
    * 确实发生了重复扣款，但这种情况很少见。

    打开**设置 → 账户用量**，选择**查看之前的发票**，然后比较两笔扣款的付款意图 ID (`pi_`) ——ID 不同表示这是两笔独立交易。如果两笔扣款都显示为同一张发票上的同一项目已付款，请[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="我已通过 App Store 付款，但积分尚未到账，该怎么办？">
    App Store 付款可能需要一点时间才能同步到 Replit。请先尝试以下操作：

    1. 强制关闭 Replit App，然后重新打开。
    2. 退出 Replit 账户后重新登录。
    3. 打开 **设置 → 账户用量**，查看积分是否已到账。

    请勿重复购买。如果积分仍未到账，请在 App Store 的**购买记录**中找到 Replit 交易并记下交易 ID。然后[联系 Replit 支持团队](https://replit.com/support)，以便他们为你补发积分。
  </Accordion>
</AccordionGroup>
