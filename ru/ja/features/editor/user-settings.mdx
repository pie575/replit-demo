Инструмент редактора проектов User Settings предлагает параметры для настройки внешнего вида, поведения и сочетаний клавиш в вашей учётной записи.

</Frame>

<div id="section">
  ## Возможности
</div>

Настроить процесс создания Replit App можно с помощью следующих категорий настроек:

* **Настройка темы** — выберите светлую или тёмную тему редактора проекта
* **Интеллектуальная работа с кодом** — настройте функции на базе ИИ, которые упрощают создание приложений
* **Настройки редактора** — измените поведение и внешний вид редактора файлов
* **Управление уведомлениями** — настройте оповещения
* **Параметры доступности** — сделайте Replit удобнее для пользователей с особыми потребностями
* **Сочетания клавиш** — задайте комбинации клавиш для частых действий и навигации по интерфейсу

  ## Как использовать
</div>

<div id="section-3">
  ### Внешний вид
</div>

Вы можете настроить следующие параметры, связанные с внешним видом редактора проектов:

* **Выбор темы**: выберите одну из готовых светлых и тёмных тем, <a href="https://replit.com/themes" target="_blank">тем сообщества</a> или пользовательских тем
* **Пользовательские темы**: создайте собственную цветовую схему в редакторе [тем](/ru/ja/features/editor/themes)

<div id="section-4">
  ### Настройки редактора файлов
</div>

Следующие настройки управляют внешним видом и поведением редактора файлов:

* **Размер шрифта**: изменяет размер текста для удобства чтения
* **Автозакрытие скобок**: автоматически вставляет закрывающую скобку при вводе открывающей
* **Определение отступов**: автоматически определяет настройки отступов при открытии файла
* **Форматирование отступов при вставке**: приводит вставленный код к правильным отступам
* **Символ отступа**: выбор между пробелами и табуляцией для отступов в коде
* **Размер отступа**: задаёт количество столбцов для каждого уровня отступа
* **Перенос строк**: настраивает поведение переноса строк
* **Мини-карта**: показывает на боковой панели обзор кода с возможностью навигации
* **Модификатор множественного выбора**: задаёт клавишу-модификатор для выбора нескольких файлов
* **Git-статус в дереве файлов**: показывает индикаторы Git-статуса в дереве файлов

<div id="section-5">
  ### Интеллектуальная работа с кодом
</div>

Настройте инструменты на базе ИИ с помощью следующих параметров:

* **Семантические токены**: подсветка синтаксиса, улучшенная за счёт языкового сервера
* **Автодополнение кода с ИИ**: встроенные подсказки кода прямо во время ввода
* **Автоматическое принятие подсказок по символам фиксации**: подсказки кода принимаются автоматически при вводе определённых символов

<div id="shellpreview">
  ### Настройка Shell и Preview
</div>

Настройте поведение инструментов Shell и Preview:

* **Звуковой сигнал Shell**: воспроизводит звук, когда инструмент Shell обнаруживает проблему
* **Автоматический предпросмотр**: автоматически открывает вкладку Preview, когда сервер становится доступен
* **Автоматически перенаправлять новые обнаруженные порты**: определяет, как обрабатывать вновь обнаруженные порты

<div id="section-6">
  ### Уведомления
</div>

Управляйте следующими настройками уведомлений:

* **Звуковые уведомления Agent**: воспроизведение звука, когда Agent запрашивает обратную связь
* **Push-уведомления Agent**: получение push-уведомлений на мобильном устройстве, когда Agent запрашивает обратную связь

<div id="section-7">
  #### Продакшен-оповещения
</div>

**Продакшен-оповещения** — это отдельная настройка уведомлений по электронной почте, которая информирует вас о состоянии опубликованных приложений. Она не связана с продуктовыми и маркетинговыми рассылками, поэтому вы получаете только важную информацию без лишнего шума.

Если включить **продакшен-оповещения**, вы будете получать письма в следующих случаях:

* **Инциденты доступности**: уведомления о том, что опубликованное приложение недоступно или не может стабильно работать в сети.
* **Уязвимости безопасности**: уведомления об уязвимостях, найденных в программном обеспечении, от которого зависит ваше приложение, — чтобы вы могли устранить их до возникновения проблем.
* **Обновления моделей**: уведомления о том, что языковая модель, используемая приложением, изменилась или требует вашего внимания.

<Frame>
  <img src="/assets/mirror/production-alerts-highlight-bb76079f20fd.png" alt="Раздел продакшен-оповещений в настройках уведомлений. Переключатель писем с продакшен-оповещениями и раскрывающийся список уровня важности оповещений безопасности выделены красными рамками" width="2400" height="1364" data-path="images/workspace/production-alerts-highlight.png" />
</Frame>

Чтобы найти эту настройку:

1. Откройте **Settings** в меню аккаунта.
2. Выберите вкладку **Personalization**.
3. Прокрутите до раздела **Email notifications** и найдите **Продакшен-оповещения**.

Если опубликованное приложение использует устаревшую языковую модель, Replit подготовит черновик задачи для перехода на поддерживаемую модель. Вы получите письмо со ссылкой на эту задачу, так что обновление можно завершить одним подтверждением.

<div id="section-8">
  ### Специальные возможности
</div>

Вы можете настроить следующие параметры специальных возможностей:

* **Доступный вывод терминала**: включает совместимость инструментов Shell и Console с программами чтения с экрана

<div id="section-9">
  ### Сочетания клавиш
</div>

Чтобы открыть настройки сочетаний клавиш, выберите вкладку **Сочетания клавиш** в инструменте User Settings.

Найти нужную комбинацию клавиш можно двумя способами:

* **По названию**: введите название или описание сочетания клавиш в поле поиска
* **По комбинации клавиш**: выберите <img class="icon-svg" src="/assets/mirror/keyboard-7ba19771b671.svg" alt="Значок клавиатуры" width="16" height="16" data-path="images/icons/keyboard.svg" /> и нажмите нужную комбинацию клавиш

Управлять сочетаниями клавиш можно так:

* **Добавление**: выберите **Добавить сочетание клавиш**
* **Изменение**: выберите значок карандаша <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="Значок карандаша" width="16" height="16" data-path="images/icons/pencil-icon.svg" />
* **Удаление**: выберите значок корзины <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="Значок корзины" width="16" height="16" data-path="images/icons/trash-icon.svg" />
