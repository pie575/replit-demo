title: "使用数据"
description: "使用可视化工具或 SQL 在 My Data 选项卡中浏览、编辑、导出和查询数据库。"
---

**My Data** 选项卡用于查看和修改数据库中的数据。打开 **Database** 工具，选择数据库，然后点击 **My Data**。您可以使用可视化工具操作，也可以直接运行 SQL。

<Note>
  如需编辑生产数据，请选择生产数据库并打开 **My Data**，然后开启 **Edit**。请谨慎操作：这里的数据来自实际运行的应用。
</Note>

<div id="section">
  ## 以可视化方式浏览和编辑数据
</div>

Database 工具内置 <a href="https://orm.drizzle.team/drizzle-studio/overview" target="_blank">Drizzle Studio</a>，可让你以可视化方式浏览和编辑数据。该工具有助于避免语法错误，并提供以下功能：

* 筛选和排序数据，聚焦特定信息
* 将数据导出为文件，供外部使用
* 插入或编辑行数据
* 创建和管理架构、表、视图和 enum

<div id="sql">
  ## 执行 SQL 命令
</div>

通过 SQL 运行器，您可以在数据库中执行 SQL 命令并查看结果。

<Accordion title="访问 SQL 运行器">
  在 **Database** 工具中：

  1. 选择 **My Data** 标签页
  2. <img class="icon-svg" src="/assets/mirror/sql-runner-icon-b25868882922.svg" alt="SQL 运行器图标" width="16" height="16" data-path="images/icons/sql-runner-icon.svg" /> 选择 **SQL runner**
</Accordion>

要运行查询，请在文本区域中输入 SQL 语句，然后选择旁边的 <img class="icon-svg" src="/assets/mirror/sql-play-8ed26b5de7f1.svg" alt="执行 SQL 图标" width="18" height="18" data-path="images/icons/sql-play.svg" /> 执行按钮。

<Frame>
  <img src="/assets/mirror/sql-runner-run-8ad798a61335.jpg" alt="SQL 运行器和执行按钮截图" width="1390" height="608" data-path="images/databases/sql-runner-run.jpg" />
</Frame>

<Tip>
  无需亲自编写 SQL。让 Agent 查询或修改数据，Agent 就会编写并执行 SQL。
</Tip>
