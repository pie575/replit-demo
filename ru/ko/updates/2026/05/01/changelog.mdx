<div id="replit-app-monitoring">
  ### Мониторинг опубликованных приложений с помощью Replit App Monitoring
</div>

Теперь для опубликованных Replit App можно включить **мониторинг приложения**: следить за доступностью в реальном времени, видеть цветную полосу доступности в разделе **Публикация** и на вкладке **Аналитика**, а также получать уведомления по электронной почте, когда приложение недоступно. Мониторинг приложений доступен на всех платных тарифах и работает со всеми типами деплоя, кроме запланированных. Если с приложением возникли проблемы, выберите **Исследовать недавний простой с помощью Agent** — запустится фоновая задача, которая определит затронутый период, изучит журналы и код и предложит исправления.

<div id="agent-slide-decks">
  ### Создание полноценных презентаций Slide Decks с помощью Agent
</div>

Опишите нужную презентацию — питч-дек, обзор продукта, презентацию для отдела продаж, отчёт команды — и Agent соберёт готовую презентацию с макетом, текстом и визуальными материалами. Слайды можно править через чат, менять текст и стили в Visual Editor, показывать презентацию прямо в браузере, публиковать её по действующей ссылке или экспортировать в PPTX, Google Slides или PDF.
