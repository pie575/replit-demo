# モバイルアプリで画像を保存する

> プロフィール写真などの画像を、各プレイヤーに紐づけて App Storage に保存します。

PixelGames には、プレイヤーが撮影した写真を保管する場所が必要です。このガイドでは、プレイヤーがすでに
[サインイン](/ja/build/mobile-login)できることを前提としています。ストレージは、誰がアップロードしているか
わかっていることに依存しているためです。

<AiPrompt>
  {profileImagesPrompt}
</AiPrompt>

Agent が [App Storage](/features/data-and-storage/object-storage) を構成し、各アップロードをサインイン中の
プレイヤーに紐づけます。これにより PixelGames は、アップロードした写真を名前の横に表示する本物のプロフィールを
見せられるようになります。

## テストする

1. 既存のアカウントで PixelGames にサインインする。
2. プロフィール写真を撮影または選択してアップロードする。
3. アプリを閉じて再度開き、写真がまだ表示されていることを確認する。
4. 同じアカウントで別の端末からサインインし、同じ写真が表示されることを確認する。

## トラブルシューティング

* **サインインしているのに写真が表示されない:** アプリが想定と異なるストレージまたは認証インスタンスを
  参照している可能性があります。Agent に接続を確認するよう依頼してください。
* **アップロードが失敗する:** アップロード前にアプリがカメラとストレージの権限をリクエストしていることを
  確認してください。
