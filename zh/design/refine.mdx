探索重在广泛尝试，优化则重在深入打磨。当某个 frame 已接近你的预期时，可根据自己的工作方式，使用以下两种工具精准调整：

* 用自己的话与 Agent 交流，针对整个 frame 或单个元素提出需求
* 通过 Visual Editor 直接调整元素；简单编辑会立即生效，且不消耗积分

<div id="chat">
  ## Chat
</div>

像在评审中向设计师说明需求一样，简要地向 Agent 交代你的要求。选择一个 frame，然后在主 Chat 中描述要做的更改 (*“颜色更暖一些”*、*“主视觉感觉太空了”*) ；或者在工具栏中选择 **Chat** 工具并点击某个元素，将消息限定在该元素上。

<Frame caption="选中的 frame 会以标签形式附加到主 Chat 中。">
  <img src="/assets/mirror/chatbox-9baff03cb443.png" alt="Canvas 上选中的 Design frame（Configurator First），左侧是主 Chat 面板；消息框中显示“描述你想设计的内容…”，并附加了 Configurator First 标签" width="2000" height="1250" data-path="images/design/replit-design/chatbox.png" />
</Frame>

有关这两种使用方式，请参阅 [Chat](/zh/design/chat-about-your-design)。

<div id="visual-editor">
  ## Visual Editor
</div>

如果你清楚自己想要什么，可以跳过 prompt。在工具栏中选择 **编辑** 工具，然后点击任意元素；Visual Editor 会随即打开，并显示该元素可编辑的属性，例如内容、布局、颜色和边框。修改文本、选择颜色和调整间距等简单编辑会立即应用到源代码，且不消耗积分。

<Frame caption="启用编辑工具并选中元素后，Visual Editor 会显示其可编辑属性。">
  <img src="/assets/mirror/visual-editor-edit-tool-71d03803471f.png" alt="一个超级跑车配置器界面，已启用编辑工具并选中一个元素；右侧显示 Visual Editor 面板，其中包含 Layout、Color 和 Border 部分，以及放弃编辑和保存编辑按钮" width="2000" height="1250" data-path="images/replitai/visual-editor-edit-tool.png" />
</Frame>

完整的控件参考请参阅 [Visual Editor](/zh/design/visual-editor)。

<div id="which-one-to-reach-for">
  ## 该用哪个
</div>

| 你想要…                    | 使用            |
| ----------------------- | ------------- |
| 描述目标效果，让 Agent 处理具体细节   | Chat          |
| 将单个元素的文案、颜色、间距或图片更改为指定值 | Visual Editor |
| 调整某个部分的结构或行为            | Chat          |
| 快速进行无需消耗积分的微调           | Visual Editor |

两者可以自然配合使用：先通过 Chat 确定方向，再使用 Visual Editor 点击调整，完善细节。
