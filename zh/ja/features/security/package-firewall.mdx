软件包防火墙在网络层拦截恶意或被入侵的软件包，防止它们被安装到你的应用中。作为 [Replit Auto-Protect](/zh/ja/features/security/concepts#auto-protect) 的一部分，它对所有构建者默认启用，并由软件供应链安全公司 [Socket](https://socket.dev) 提供支持。

当你或 Agent 运行 `npm install`、`pip install` 等安装命令时，请求会先经过软件包防火墙。干净的软件包照常安装，你不会有任何察觉；而被 Socket 标记为恶意或已被入侵的软件包，则会在代码进入你的环境之前被拦截。

软件包防火墙**对所有构建者默认启用**，无需配置，也无需迁移。它对新建应用和已有应用一视同仁地提供保护，你无需设置任何内容。

<div id="section">
  ## 为什么安装时防护至关重要
</div>

大多数供应链工具只在发布时扫描依赖项，而此时软件包早已安装完毕。对于普通漏洞而言，这或许够用。但恶意软件不同：它在安装的那一刻就开始造成危害——窃取密钥、开启后门、外泄环境变量。等到发布时扫描发出告警，攻击早已得手。

Package Firewall 关上了这扇窗口。它在下载之前就拦截恶意软件包，在任何一行恶意代码运行之前终止攻击。

<div id="section-2">
  ## 工作原理
</div>

1. 你或 Agent 运行安装命令，例如 `npm install <package>` 或 `pip install <package>`。
2. 请求会经过 Package Firewall，依据 Socket 的威胁情报对软件包进行核查。
3. 如果软件包没有问题，安装会照常进行，你不会察觉到任何差异。
4. 如果软件包存在恶意代码或已被入侵，安装会在代码进入你的环境之前被拦截。

一旦有内容被拦截，你会看到一条清晰的提示，说明拦截了什么以及原因，其中包括触发拦截的漏洞或策略。Agent 也会收到相同的信号，因此它可以提出安全的替代方案 (例如更正拼写有误的软件包名称) ，或者把决定权交回给你。

<div id="section-3">
  ### 支持的包管理器
</div>

Package Firewall 可保护以下安装过程：

* **JavaScript** — npm、yarn、pnpm
* **Python** — pip
* **Go** — Go 模块

<div id="package-firewall">
  ## Package Firewall 能检测到什么
</div>

Package Firewall 既拦截彻头彻尾的恶意软件，也拦截已遭入侵或存在已知漏洞的正规软件包版本 (包括广泛使用的软件包) 。其中许多漏洞是在推荐它们的模型训练截止日期之后才披露的，因此模型可能会信心十足地建议某些依赖项版本——它们在训练数据中还是安全的，但之后已被标记为有风险。这些风险在业界都有专门的名称：

* **仿冒抢注 (Typosquatting)&#x20;**&#x20;—— 与真实软件包名称仅相差一个按键的恶意软件包，例如用 `reqeusts` 冒充 `requests`。一旦请求错了软件包，下载到的就是恶意软件。
* **幻觉抢注 (Slopsquatting)&#x20;**&#x20;—— 模型幻觉出一个并不存在的软件包名称，攻击者抢先注册这个名称，静候下一个 Agent 前来安装。
* **过时的推荐** —— 模型依据训练截止日期之前的情况判定为安全而推荐的真实软件包，但其漏洞此后已被披露。

最后这一类，正是 Package Firewall 对 AI 构建的应用如此重要的原因：Agent 可能会信心十足地使用早已不再安全的依赖项，而 Package Firewall 会在这些代码运行之前就阻止安装。

<div id="package-firewallreplit">
  ## Package Firewall 与 Replit 其他安全工具的关系
</div>

Package Firewall 是三层互补防护中的一层。每一层都在应用生命周期的不同阶段提供保护，因此应结合使用，而非只选其中一项。

| 层级                   | 执行时机    | 功能                                                                                                                           |
| -------------------- | ------- | ---------------------------------------------------------------------------------------------------------------------------- |
| **Package Firewall** | 安装时     | 在下载前拦截恶意或已遭入侵的软件包 (预防) 。                                                                                                     |
| **自动依赖项扫描**          | 安装后持续进行 | 检测已安装依赖项中新披露的 CVE，并可选择提供由 Agent 准备的补丁。请参阅[项目安全中心](/zh/ja/features/security/project-security-center#automatic-dependency-scans)。 |
| **Security Agent**   | 发布前     | 审核整个代码库中的代码、依赖项和隐私漏洞。请参阅[Agent 安全扫描](/zh/ja/features/security/agent-security-scans)。                                            |
