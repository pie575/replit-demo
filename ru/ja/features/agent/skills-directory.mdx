Каталог навыков — это подборка готовых навыков от Replit и партнёров, которые можно сразу установить и использовать. Установите и опробуйте их, а затем адаптируйте под рабочий процесс вашей команды.

Подробнее о навыках и о том, как Agent их загружает, см. в разделе [Навыки Agent](/ru/ja/features/agent/skills). Чтобы сделать навыки доступными во всём рабочем пространстве, см. раздел [Настройка Agent](/ru/ja/features/agent/agent-customization).

<div id="section">
  ## Установка навыков
</div>

Добавить навык из каталога можно несколькими способами:

* **В чате** — нажмите кнопку **+** рядом с полем ввода, выберите **Use a skill** и укажите нужный навык. Навык действует только для этого сообщения, в project при этом ничего не устанавливается.
* **В project** — откройте панель Skills в Project Editor, перейдите на вкладку **Discover**, найдите навык и нажмите **Install**. Установленные навыки хранятся в каталоге project `/.agents/skills` и сохраняются между чатами.
* **Из командной строки** — установите навык с помощью [skills CLI](https://github.com/vercel-labs/skills):

  ```bash theme={null}
  npx skills <skill> -a replit
  ```

<Warning>
  Навыки из средства выбора навыков Replit проверены на безопасность. Навыки, установленные из внешних источников, такую проверку не проходят. Поскольку навык — это инструкции, которым следует Agent, всегда просматривайте внешние навыки перед установкой: о том, на что обратить внимание, см. [Навыки Agent](/ru/ja/learn/agent-skills).
</Warning>

<div id="replit">
  ## Навыки Replit
</div>

Replit предлагает предустановленные навыки, доступные через меню **Use a skill** в чате и меню выбора отправной точки при создании проекта. Они работают во всех проектах без установки. При открытии меню отображаются краткие описания навыков.

| Категория                               | Навыки                                                                                                   |
| --------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| Продажи и маркетинг                     | Ad Creative、AI SDR、SEO Auditor、Programmatic SEO、GEO、Content Machine、Storyboard                           |
| Карьера                                 | AI Recruiter、Resume Maker、Interview Prep                                                                 |
| Исследования и анализ                   | Competitive Analysis、Deep Research、GitHub Solution Finder、Supplier Research                              |
| Бизнес и финансы                        | Stock Analyzer、Excel Generator、Invoice Generator、Tax Reviewer                                            |
| Документы и инструменты                 | Website Cloner、File Converter、Flashcard Generator、Legal Contract、Infographic Builder、Recreate Screenshot |
| Творчество                              | Photo Editor、Podcast Generator、Podcast Marketing、Branding Generator、Video Editing                        |
| Продуктивность                          | AI Secretary、Product Manager、Design Thinker、Skill Finder、Skill Creator                                   |
| Личное                                  | Travel Assistant                                                                                         |
| Безопасность и соответствие требованиям | Secrets、Sensitive Data、Input Validation、AI Security、Dependency Vetting、License Check                     |
| Качество и надёжность                   | Accessibility、Responsive UI、Observability、Resilience、Ship Review                                         |

<Note>
  В рабочем пространстве меню также обнаруживает дополнительные навыки, установленные в каталоге проекта `.local/secondary_skills/`.
</Note>

<div id="section-2">
  ## Навыки партнёров
</div>

Партнёры Replit публикуют навыки, обучающие Agent работе с их продуктами. После установки они предоставляют Agent шаблоны и правила соответствующего сервиса.

| Партнёр          | Чему обучает Agent                                       |
| ---------------- | -------------------------------------------------------- |
| Stripe           | Шаблоны интеграции платежей и биллинга                   |
| PayPal           | Шаблоны интеграции платежей                              |
| RevenueCat       | Шаблоны для подписок и встроенных покупок                |
| Mixpanel         | Реализация аналитики и отслеживания                      |
| BigQuery         | Шаблоны запросов к хранилищу данных                      |
| Resend           | Интеграция транзакционных писем                          |
| Google Workspace | Интеграции с Gmail, Drive, Docs и Calendar               |
| Atlassian        | Рабочие процессы для задач и страниц в Jira и Confluence |
| Google Maps      | Интеграции карт, мест, маршрутов и геокодирования        |

<div id="section-3">
  ## Навыки от сообщества
</div>

Помимо навыков от Replit и партнёров, вы можете устанавливать навыки, опубликованные сообществом. Найти их можно на [skills.sh](https://skills.sh), а если хотите написать собственный навык, обратитесь к [Agent Skills specification](https://agentskills.io/specification).
