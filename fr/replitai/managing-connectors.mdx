Vous pouvez gérer les connecteurs afin que votre équipe utilise les intégrations de façon cohérente et sécurisée. Les fonctionnalités disponibles dépendent de votre forfait :

* **Core et Pro** : la gestion des connecteurs est disponible dans les **workspaces collaboratifs**. L&#39;administrateur du compte configure et gère les connexions de ce workspace ; les créateurs peuvent ensuite les utiliser dans les apps de ce workspace.
* **Enterprise** : gestion des connecteurs à l&#39;échelle de l&#39;organisation avec des contrôles avancés — clients OAuth personnalisés, contrôles d&#39;accès par clé API et possibilité d&#39;utiliser vos propres clés.

<div id="key-capabilities">
  ## Fonctionnalités clés
</div>

* **Gestion centralisée** : l&#39;administrateur configure un service une seule fois ; les créateurs l&#39;utilisent ensuite dans toutes les apps de ce workspace.
* **Visibilité et audit** : identifiez quelles apps et quels membres utilisent quels services.
* **Consentement et révocation par app** : révoquez ou renouvelez les accès sans modifier le code.

**Enterprise uniquement :**

* **Contrôles d&#39;accès basés sur les rôles** : permissions selon le principe du moindre privilège et contrôles d&#39;accès sur les clés API.
* **Utilisation de votre propre OAuth** : utilisez des clients OAuth appartenant à votre organisation, avec des scopes personnalisés.
* **Utilisation de votre propre clé OpenAI** : utilisez votre propre clé API OpenAI plutôt que celle par défaut de Replit.

<div id="how-it-works">
  ## Fonctionnement
</div>

<Steps>
  <Step title="L'administrateur configure un service">
    L&#39;administrateur configure un service une seule fois à l&#39;aide des identifiants.
  </Step>

  <Step title="L'administrateur approuve l'accès">
    L&#39;administrateur détermine quels groupes peuvent utiliser le connecteur (Enterprise) ou le met à disposition du workspace collaboratif (Core/Pro).
  </Step>

  <Step title="Les créateurs utilisent le connecteur">
    Les membres développent avec ce service en sollicitant Agent dans les apps du workspace ou de l&#39;organisation.
  </Step>

  <Step title="L'administrateur surveille l'utilisation">
    Les administrateurs peuvent voir quels membres et quelles apps utilisent quels services.
  </Step>
</Steps>

<div id="security-and-governance">
  ## Sécurité et gouvernance
</div>

* Les identifiants et les jetons sont gérés par la plateforme, et non stockés dans chaque app.
* Révocation et rotation centralisées, sans modification du code.
* Enterprise : accès restreint selon le principe du moindre privilège, avec configuration OAuth personnalisée en option.

<div id="setup-and-management">
  ## Configuration et gestion
</div>

<div id="enable-new-connectors">
  ### Activer de nouveaux connecteurs
</div>

<Steps>
  <Step title="Accéder aux Intégrations">
    Depuis votre workspace collaboratif (Core/Pro) ou la page d&#39;accueil de votre organisation (Enterprise), ouvrez la page **Intégrations**.
  </Step>

  <Step title="Activer un nouveau connecteur">
    Sélectionnez **Activer un nouveau connecteur** en haut à droite.
  </Step>

  <Step title="Sélectionner le service">
    Sélectionnez le service que vous souhaitez activer (par exemple Notion, GitHub, Google, Outlook, Dropbox, Salesforce).
  </Step>

  <Step title="Configurer le connecteur">
    Activez le connecteur avec la configuration par défaut. Sur **Enterprise** uniquement, vous pouvez créer un connecteur OAuth personnalisé (par exemple, les scopes Drive `.../auth/drive.file`, `.../auth/drive.install`).
  </Step>

  <Step title="Envoyer">
    Sélectionnez **Envoyer**.
  </Step>
</Steps>

<div id="configure-access-enterprise">
  ### Configurer l&#39;accès (Enterprise)
</div>

1. Après avoir activé un connecteur, sélectionnez **Gérer**.
2. Accordez l&#39;accès aux groupes souhaités.

<div id="modify-connectors">
  ### Modifier les connecteurs
</div>

* Après avoir activé un connecteur, sélectionnez **Gérer**.
* La suppression d&#39;un connecteur le retire pour tous les créateurs du workspace concerné (Core/Pro) ou de l&#39;organisation concernée (Enterprise).
* Avec Enterprise, vous pouvez modifier les scopes des connecteurs OAuth personnalisés.

<div id="bring-your-own-openai-key-enterprise">
  ### Utiliser votre propre clé OpenAI (Enterprise)
</div>

Les clients Enterprise peuvent utiliser les connecteurs pour recourir à leur propre clé API OpenAI plutôt qu&#39;à l&#39;infrastructure d&#39;IA par défaut de Replit. Vous pouvez ainsi tirer parti de vos accords OpenAI existants et gérer l&#39;utilisation de l&#39;IA depuis votre propre compte.
