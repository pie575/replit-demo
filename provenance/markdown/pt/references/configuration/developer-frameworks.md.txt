# Frameworks de Desenvolvedor

> Saiba como usar frameworks de desenvolvedor — pontos de partida reutilizáveis para novos projetos no Replit.

## O que é um framework de desenvolvedor?

Frameworks de desenvolvedor são Replit Apps que a plataforma e a comunidade publicaram para que outros usem como ponto de partida. Os frameworks de desenvolvedor oficiais, feitos pelo Replit, têm uma marca de verificação ao lado do nome do framework:

O framework [HTML, CSS, JS](https://replit.com/@replit/HTML-CSS-JS?v=1#index.html) é muito popular e pode ser usado como ponto de partida para criar um projeto JavaScript vanilla. Você pode fazer um fork do framework para usá-lo.

## Templates personalizados para Enterprise

Organizações Enterprise podem criar [templates personalizados](/pt/teams/custom-templates) que aparecem como opções selecionáveis na caixa de entrada do Agent para todos os membros da organização. Os templates personalizados vão além dos frameworks de desenvolvedor ao incluir instruções de Agent, habilidades e contexto de projeto pré-configurados específicos da empresa. Consulte o [guia de templates personalizados](/pt/teams/custom-templates) para obter detalhes.
