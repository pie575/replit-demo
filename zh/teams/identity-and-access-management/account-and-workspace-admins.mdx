<Info>
  **本页仅适用于企业版。** 只有企业版才会区分账户管理员和 workspace 管理员这两种角色。

  在 **Core** 和 **Pro** 套餐中，你的账户只有一位**账户管理员** (通常是账户所有者) ，没有单独的 workspace 管理员角色。如果你使用的是 Core 或 Pro，请改为参阅[管理成员](/zh/teams/identity-and-access-management/managing-members)和[角色、群组与访问权限](/zh/teams/identity-and-access-management/groups-and-permissions)——其中介绍的 **Admin** 角色就是你的账户管理员。
</Info>

在企业版中，Replit 将管理职责拆分为两种不同的角色：**账户管理员**和 **workspace 管理员**。这样拆分后，你可以让某人全权管理某个 workspace，同时又不必把 计费 和账户级别的控制权一并交给对方。本页将说明这两种角色各自的职责、彼此的区别以及配置方法。

<div id="how-the-two-roles-relate">
  ## 两种角色的关系
</div>

你的 Replit **账户**是计费实体，拥有订阅、席位以及一个或多个 **workspace** (即你的组织) ——Enterprise 账户可以包含多个 workspace。这两种管理员角色分别对应上述两个作用域：

* **账户管理员**管理整个账户，负责计费，并对账户下的每个 workspace 拥有管理权限。
* **Workspace 管理员**仅管理自己所属的 workspace(可能不止一个)，没有计费权限,也无法管理其他 workspace。

每位账户管理员都会自动成为账户下所有 workspace 的管理员,因此账户管理员的权限实际上涵盖了 workspace 管理员。而 workspace 管理员并非账户管理员,无法管理计费或其他 workspace。

<CardGroup cols={2}>
  <Card title="账户管理员" icon="building-shield">
    账户级别。管理计费、席位、安全设置以及账户下的每个 workspace。
  </Card>

  <Card title="Workspace 管理员" icon="user-shield">
    Workspace 级别。仅管理自己所属 workspace 内的成员和资源。
  </Card>
</CardGroup>

<div id="what-each-role-can-do">
  ## 各角色的权限范围
</div>

两种角色都负责管理 workspace，区别在于管理*哪些* workspace。账户管理员管理账户下的所有 workspace，而 workspace 管理员只管理自己所属的 workspace。

| 权限                            | 账户管理员 | Workspace 管理员 |
| ----------------------------- | :---: | :-----------: |
| 在其管理的 workspace 中管理成员         |   是   |       是       |
| 在其管理的 workspace 中管理 App、群组和资源 |   是   |       是       |
| 查看和编辑计费、支付方式与发票               |   是   |       否       |
| 编辑、取消或恢复订阅                    |   是   |       否       |
| 添加、移除和分配席位                    |   是   |       否       |
| 设置支出和用量限额                     |   是   |       否       |
| 创建新的 workspace                |   是   |       否       |
| 管理其他账户管理员                     |   是   |       否       |
| 管理账户下的所有 workspace            |   是   |       否       |
| 配置 SAML、SCIM、审计日志和安全联系人       |   是   |       否       |

Workspace 管理员的管理权限仅限于自己所属的 workspace，而账户管理员则在整个账户范围内拥有全部管理权限。

<Note>
  计费、席位管理、订阅变更以及账户级安全控制均需要账户管理员权限。Workspace 管理员无法执行这些操作，即使在自己的 workspace 内也不行。
</Note>

<div id="configuring-account-admins">
  ## 配置账户管理员
</div>

账户管理员在设置的 **席位** 选项卡中管理。添加账户管理员后，该用户将获得账户范围的管理权限，并自动成为该账户下所有 workspace 的管理员。

<div id="promote-a-member-to-account-admin">
  ### 将成员提升为账户管理员
</div>

<Steps>
  <Step title="打开 席位 标签页">
    在设置中打开 **席位** 标签页。该标签页会列出账户中的所有人员及其当前角色。
  </Step>

  <Step title="提升该成员">
    找到要提升的成员，打开操作菜单，选择 **提升为账户管理员**。更改会立即生效。
  </Step>
</Steps>

<div id="demote-an-account-admin">
  ### 降级 账户管理员
</div>

将 账户管理员 降级后，其账户级权限和 计费 访问权限都会被移除。默认情况下，降级不会将其移出所在的 workspace——无论是否具备 账户管理员 身份，他们的 workspace 访问权限都会保留。

<Steps>
  <Step title="打开 席位 选项卡">
    在设置中打开 **席位** 选项卡。
  </Step>

  <Step title="降级 账户管理员">
    找到该 账户管理员，打开操作菜单，然后选择 **Demote from 账户管理员**。更改会立即生效。
  </Step>
</Steps>

以下几条规则可避免你的账户失去管理权限：

* 无法将自己降级。
* 无法移除最后一位 账户管理员，账户中必须始终至少保留一位。
* 无法降级个人账户的所有者。

<div id="scim-provisioned-admins">
  ### 通过 SCIM 预配的管理员
</div>

如果你通过 [SCIM](/zh/teams/identity-and-access-management/scim) 预配用户，被身份提供方分配了 **Admin** 角色的用户将成为**账户管理员**。若要创建仅限于某个 workspace 的管理员，请在 Replit 中直接分配 **Workspace admin** 角色，而不要通过身份提供方分配。

<div id="configuring-workspace-admins">
  ## 配置 workspace 管理员
</div>

分配 workspace 管理员角色，可以让某人完全掌控某个特定的 workspace，同时又不授予账户级别或 计费 权限。当某位团队负责人需要管理自己的 workspace，但不应管理订阅或其他团队时，这一角色非常有用。

<Steps>
  <Step title="打开 workspace 成员列表">
    打开你要指派管理员的 workspace，然后进入其 **Members** 页面。
  </Step>

  <Step title="将成员角色设置为 Workspace admin">
    找到该成员，打开其角色选择器，选择 **Workspace admin**。该成员将获得仅限于该 workspace 的管理权限。
  </Step>
</Steps>

<Note>
  workspace 管理员的权限仅限于其所属的 workspace，无法访问 计费、管理席位或管理其他 workspace——这些操作需要账户管理员权限。
</Note>

<div id="choosing-the-right-role">
  ## 选择合适的角色
</div>

* 将 **账户管理员** 分配给负责 计费、管理订阅和席位、配置安全设置，或需要统管所有 workspace 的人员。
* 将 **workspace admin** 分配给只负责单个团队或 workspace 的人员，他们可管理该 workspace 的成员和资源，但不涉及 计费 或其他 workspace。
