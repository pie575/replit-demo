export const YouTubeEmbed = ({videoId, title = "Видео на YouTube", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

  ## Запуск Agent 3
</div>

На этой неделе мы выпустили Agent 3.

<YouTubeEmbed videoId="4FxNXFOdt6w" title="Прямая трансляция запуска Agent 3" />

Agent 3 приносит серьёзные улучшения в автономности, надёжности и скорости:

* **Тестирование App**: Agent самостоятельно тестирует приложение в настоящем браузере, находит проблемы и исправляет их в цикле самоанализа. См. [Тестирование App](/ru/pt/core-concepts/agent/app-testing).
* **Более длительная работа**: Agent может работать автономно до 200 минут с Живым мониторингом — идеально для крупных проектов. Подробнее в разделе [Agent](/ru/pt/core-concepts/agent#max-autonomy).
* **Создание агентов**: Создавайте агентов и автоматизации, которые запускаются по расписанию или интегрируются со Slack и Telegram. См. [Агенты и автоматизации](/ru/pt/core-concepts/agent/agents-and-automations).

<div id="conectores-e-integraes-de-app">
  ## Коннекторы и интеграции приложений
</div>

Публикуйте быстрее благодаря встроенным интеграциям и коннекторам:

* **Управляются Replit**: встроенные интеграции, которые работают в ваших приложениях автоматически.
* **Connectors**: собственные интеграции Replit — достаточно войти один раз и использовать их во всех приложениях.
* **Внешние интеграции**: проверенные сторонние сервисы, которые Agent настраивает с помощью ваших ключей API.
