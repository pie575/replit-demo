<div id="workspace-pessoal-vs-workspace-de-equipe">
  ## 个人工作区与团队工作区
</div>

**工作区**用于组织你的 App、成员、设置和账单。Replit 提供两种工作区：

* 个人工作区
* 团队工作区

以下是个人工作区和团队工作区的区别：

|          | 个人工作区         | 团队工作区          |
| -------- | ------------- | -------------- |
| **角色**   | 管理员、项目级访客     | 管理员、成员、项目级访客   |
| **访问模式** | 你可邀请访客加入单个项目  | 成员可访问工作区中的所有项目 |
| **账单**   | 你的账户          | 管理员账户的共享积分     |
| **成员管理** | 按项目管理 (加入链接)  | 在工作区设置中集中管理    |

如果你独自工作，或只需与他人共享个别项目，**个人工作区**是更好的选择。你是唯一的管理员，其他人只能访问你以项目级访客身份邀请他们加入的特定项目。

如果你经常与固定团队协作，例如创业团队、班级，或有多位协作者参与的客户项目，**团队工作区**是更好的选择。成员可访问工作区中的所有项目，因此无需逐一邀请他们加入每个项目。成员可在**设置**中集中管理。

<div id="quando-convidar-para-o-workspace-vs-para-um-projeto">
  ### 何时邀请加入工作区，何时邀请加入项目
</div>

| 场景                | 操作                                   |
| ----------------- | ------------------------------------ |
| 需要访问所有内容的长期协作者    | 邀请加入工作区                       |
| 仅需访问一个项目的服务提供商或访客 | [邀请加入项目](/zh/pt/build/invite-teammates) |
| 即将加入公司的新团队成员      | 邀请加入工作区                       |
| 协助调试特定 App 的朋友    | [邀请加入项目](/zh/pt/build/invite-teammates) |

<div id="criar-um-workspace-de-equipe">
  ## 创建团队工作区
</div>

<Frame>
  <video autoPlay muted loop playsInline>
    <source src="/assets/mirror/create_new_team_workspace-f665bec18450.mp4" type="video/mp4" />
  </video>
</Frame>

<Steps>
  <Step title="打开工作区选择器">
    在主页左上角，点击你的工作区名称。
  </Step>

  <Step title="创建新工作区">
    选择 **创建工作区**，然后为团队工作区命名。
  </Step>

  <Step title="邀请成员">
    在邀请字段中输入一个或多个电子邮件地址 (以逗号分隔) 。访客会收到邀请，接受后即可访问该工作区中的所有项目。
  </Step>
</Steps>

<div id="gerenciando-membros">
  ## 管理成员
</div>

如果您在设置期间未邀请成员，或需要在之后添加成员，请前往团队工作区的**设置**，通过电子邮件或 Replit 用户名邀请成员。

<Frame>
  <video autoPlay muted loop playsInline>
    <source src="/assets/mirror/add_team_to_workspace_compressed-41d8163607d2.mp4" type="video/mp4" />
  </video>
</Frame>

在**设置**页面中，您还可以：

* **移除成员**，撤销其对工作区中所有项目的访问权限
* 将个人工作区中的**应用**转移到团队工作区 — 请参阅[将应用转移到团队](/zh/pt/teams/identity-and-access-management/transfer-app-to-teams)

如需进行高级身份管理、基于角色的访问控制和组权限管理，请参阅 [Teams](/zh/pt/category/teams)。
