项目编辑器提供布局管理功能和集成工具，让应用构建体验更上一层楼。
这些功能各自专注于开发流程中的特定环节，
助你把精力放在创作上，而不是配置上。

<div id="section">
  ## 可自定义的项目编辑器布局
</div>

使用项目编辑器的布局管理工具，你可以自定义开发环境中的组件。
它由以下类型的用户界面元素组成：

| 元素      | 描述                                   | 功能                                                                  | 使用场景                                                      |
| ------- | ------------------------------------ | ------------------------------------------------------------------- | --------------------------------------------------------- |
| **窗口**  | 包含一个或多个窗格的浏览器标签页                     | <ul><li>可跨多个屏幕进行整理</li></ul>                                        | <ul><li>跨多个屏幕整理项目编辑器</li><li>同时处理多个项目</li></ul>           |
| **窗格**  | 窗口中包含一个或多个标签页的区域                     | <ul><li>支持水平和垂直拆分</li><li>可调整大小和重新排序</li><li>可在窗口内转换为浮动窗格</li></ul> | <ul><li>并排显示代码和 Preview</li><li>为不同的开发任务创建自定义布局</li></ul> |
| **标签页** | 仅包含一种项目编辑器工具，例如文件编辑器、Preview 或 Agent | <ul><li>可在窗格之间移动和重新排序</li><li>只需单击即可切换到不同的文件或工具</li></ul>           | <ul><li>按需打开不同的工具或文件</li></ul>                            |

<div id="section-2">
  ## 文件树
</div>

文件树中会显示 Replit App 的所有文件和目录。

<Accordion title="如何访问文件树">
  选择左侧的<img class="icon-svg" src="/assets/mirror/files-icon-f66bf1b04572.svg" alt="带箭头的文件夹图标" width="16" height="16" data-path="images/icons/files-icon.svg" />文件夹图标，
  即可显示或隐藏文件树。
</Accordion>

在文件树中，你可以执行以下操作：

* 选择文件夹以查看其内容
* 选择文件或将文件拖入窗格，在文件编辑器中打开
* 执行复制、重命名、移动、下载、删除等文件操作

<div id="section-4">
  ## 运行按钮
</div>

**运行**按钮用于运行 Replit App 中所选的工作流。

<Accordion title="如何找到运行按钮">
  **运行**按钮位于项目编辑器界面顶部。点击该按钮即可运行工作流。

  当 Replit App 正在运行时，按钮标签会变为**停止**。点击该按钮可停止应用。
</Accordion>

有关如何选择、查看和管理工作流，请参阅[工作流](/zh/ja/features/workspace-tools/workflows/)。

<div id="section-6">
  ## 选项菜单
</div>

在选项菜单中，你可以进行以下类型的布局操作：

* **窗口管理**：在新窗口中打开 Replit App 的项目编辑器
* **窗格管理**：添加、移动、最大化窗格，以及在浮动与固定之间切换
* **标签页管理**：打开或选择其他标签页、将标签页移动到其他窗格、关闭标签页

<Accordion title="如何打开选项菜单">
  选择当前标签页右上角的<img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="竖排三点图标" height="16" width="16" data-path="images/icons/vertical-dots.svg" />竖排三点图标，
  即可打开选项菜单。
</Accordion>

<div id="section-8">
  ## 资源面板
</div>

资源面板会显示开发环境的计算资源及使用情况 (如 RAM、CPU、存储等) 。
这些信息有助于你估算和优化 Replit App 的发布需求。

<Accordion title="如何打开资源面板">
  1. 选择应用名称旁边的<img class="icon-svg" src="/assets/mirror/resources-237893692826.svg" alt="堆叠的计算机图标" width="16" height="16" data-path="images/icons/resources.svg" />资源图标，即可显示或隐藏该面板。
  2. 将鼠标悬停在**计算**或**存储**项上，即可查看详细信息。
</Accordion>
