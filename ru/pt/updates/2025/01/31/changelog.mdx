<div id="repl-app">
  ### Repl -&gt; App
</div>

Теперь Repl&#39;ы называются «Apps». Ставка на простоту.

<div id="notificaes-aprimoradas">
  ### Улучшенные уведомления
</div>

Мы доработали уведомления об ошибках оплаты и выставлении счетов. Теперь перед приостановкой App вам предоставляется льготный период в 24 часа, а сам процесс стал более прозрачным.

Это обновление помогает избежать перебоев в работе с Replit.

<div id="melhorias-no-object-storage">
  ### Улучшения в Object Storage
</div>

На панели Object Storage появились поиск и постраничная навигация — теперь ориентироваться в файлах стало проще.

<div id="diffs-mais-limpos">
  ### Diffs mais limpos
</div>

Изменения файлов, внесённые Assistant, теперь открываются во временных панелях diff. Так удобнее просматривать правки, не засоряя рабочее пространство бесконечными вкладками.

Панели закрываются автоматически, как только вы применяете изменения.

<div id="agent-mais-rpido-na-sia">
  ### Agent работает быстрее в Азии
</div>

Мы оптимизировали облачные сервисы для тех, кто создаёт приложения с помощью Agent в Азии. Вы заметите более быстрые ответы и заметно более плавную работу.

<div id="login-com-x">
  ### Вход через X
</div>

Теперь зарегистрироваться и войти в Replit можно через X. Добро пожаловать в будущее.

<div id="importao-rpida-de-repositrio">
  ### Быстрый импорт репозитория
</div>

Хотите перенести любимый репозиторий с GitHub в Replit?

Теперь это можно сделать мгновенно.

Просто введите в браузере `replit.com/ВАШ_URL_РЕПОЗИТОРИЯ`, например:

`https://replit.com/github.com/mattppal/magnetic-feel`
