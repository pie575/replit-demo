Replit MCP 使用 [Model Context Protocol](https://modelcontextprotocol.io/)，让您可通过常用的 AI 工具创建、查找、查看、更新和发布 Replit Apps。

<div id="use-replit-in-chatgpt-claude-or-slack">
  ## 在 ChatGPT、Claude 或 Slack 中使用 Replit
</div>

Replit 可原生连接到 ChatGPT、Claude 和 Slack。选择平台，连接 Replit 并开始构建。有关前提条件、套餐可用性和故障排除，请参阅 [在 ChatGPT 中使用 Replit](/zh/features/platforms/chatgpt) 和 [在 Claude 中使用 Replit](/zh/features/platforms/claude)。

<div id="connect-an-mcp-client-directly">
  ## 直接连接 MCP 客户端
</div>

如果你的 MCP 客户端没有 Replit 原生集成，请使用直接连接。

| 属性       | 值                                   |
| -------- | ----------------------------------- |
| **URL**  | `https://replit-mcp.com/server/mcp` |
| **传输方式** | 流式 HTTP                             |
| **身份验证** | 使用受保护资源发现的 OAuth                    |

将服务器 URL 添加到支持流式 HTTP 和 OAuth 授权的 MCP 客户端。客户端会读取 Replit 的受保护资源元数据，然后提示你登录 Replit。

请勿创建自定义 OAuth 服务器。Replit MCP Server 会提供客户端所需的 OAuth 元数据。

你可以创建 App，也可以使用你有编辑权限的 App，包括他人与你共享的 App。

<div id="set-up-replit-mcp">
  ### 设置 Replit MCP
</div>

Codex 和 Claude Code 只是示例。你可以将 Replit MCP 添加到任何兼容的 MCP 客户端。

<Tabs>
  <Tab title="Codex">
    <Steps>
      <Step title="打开 MCP 列表">
        在 Codex 中，打开 **设置** → **插件** → **MCP**。
      </Step>

      <Step title="添加 Replit">
        添加一个自定义 MCP。使用便于识别的名称，例如 `Replit`。选择 **流式 HTTP**。输入 `https://replit-mcp.com/server/mcp` 并保存。不要添加 Bearer token 或自定义标头。

        <Frame>
          <img src="/assets/mirror/codex-add-replit-mcp-51365d598c24.png" alt="Codex 自定义 MCP 表单，其中包含 Replit、流式 HTTP、Replit 端点，以及留空的 Bearer token 和标头字段" width="2000" height="1293" data-path="images/replitai/custom-mcp/codex-add-replit-mcp.png" />
        </Frame>
      </Step>

      <Step title="验证 Replit">
        在 MCP 列表中，启用 **Replit** 并选择 **验证**。选择要连接的 Replit workspace，然后选择 **允许**。

        <Frame>
          <img src="/assets/mirror/codex-authenticate-replit-mcp-38e837424d0f.png" alt="Codex MCP 列表，其中已启用 Replit，并显示“验证”按钮" width="2000" height="1293" data-path="images/replitai/custom-mcp/codex-authenticate-replit-mcp.png" />
        </Frame>

        <Frame>

        </Frame>
      </Step>

<div id="tools">
  ## 工具
</div>

| 工具                        | 必填输入                          | 可选输入                                                                      | 用途                                                                                                                                                                                        |
| ------------------------- | ----------------------------- | ------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `create_app_from_prompt`  | `appDescription`, `app_stack` | `userSpecifiedAppName`, `userQuotes`, `attachmentSummary`, `sourceReplId` | 创建新应用。`app_stack` 可选值为 `react_website`、`mobile_app`、`design`、`slides`、`animation`、`data_visualization`、`3d_game`、`document` 或 `spreadsheet`。设置 `sourceReplId` 后，新应用将以现有应用的私有副本为起点，而非空白项目。 |
| `search_apps`             | 无                             | `query`, `url`, `updatedAfter`, `updatedBefore`, `limit`                  | 按标题关键词、URL 或最后更新时间查找应用。`limit` 的取值范围为 1 到 50。                                                                                                                                             |
| `resolve_app_by_name`     | `name`                        | 无                                                                         | 按应用的精确标题查找单个应用。                                                                                                                                                                           |
| `list_apps`               | 无                             | `query`, `limit`                                                          | 列出你可编辑的应用，并按最近活动时间排序。默认 `limit` 为 25，最大值为 50。                                                                                                                                             |
| `ask_question`            | `replId`, `question`          | 无                                                                         | 在不更改应用的情况下，就应用相关问题询问 Agent。                                                                                                                                                               |
| `update_app_using_prompt` | `replId`, `changeDescription` | `userQuotes`, `attachmentSummary`                                         | 使用 Agent 更新现有应用。                                                                                                                                                                          |
| `publish_app`             | `replId`                      | 无                                                                         | 发布应用，或重新发布其最新更改。                                                                                                                                                                          |
| `get_publish_status`      | `replId`                      | 无                                                                         | 检查应用是否已发布、当前发布状态及其公开 URL。                                                                                                                                                                 |

<div id="troubleshooting">
  ## 故障排除
</div>

| 问题               | 处理方法                                                      |
| ---------------- | --------------------------------------------------------- |
| Replit 要求你进行身份验证 | 在 MCP 客户端中重新完成 OAuth 登录流程。                                |
| 找不到 App          | 确认你拥有编辑该 App 的权限。然后按 URL 搜索，或使用 `list_apps` 从匹配的 App 中选择。 |
| 创建、更新或发布请求仍在进行中  | 请稍候再重试。对于发布，请使用 `get_publish_status` 查看当前状态。              |
