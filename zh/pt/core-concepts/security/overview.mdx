通过 Replit 发布后，你的项目可能会接收真实流量。Replit 的安全工具可帮助你发现漏洞、用 Agent 修复已确认的问题，并保留可用于审计的证据。

<div id="por-que-a-segurana-importa">
  ## 为什么安全很重要
</div>

* 已发布的项目可通过公开互联网访问，其中包括公开的路由和 API。
* 现代项目依赖大量软件包，发布后仍可能出现新的 CVE。
* AI 生成的代码同样需要安全审查，尤其是身份验证、数据库查询、Secrets 和数据处理等方面。
* 合规计划通常要求提供依赖清单、漏洞跟踪与修复的相关证据。

<div id="por-onde-comear">
  ## 从哪里开始
</div>

* 只处理单个 project？使用 [Project Security Center](/zh/pt/core-concepts/security/project-security-center)。
* 要审计整个 workspace？使用 [Workspace Security Center](/zh/pt/core-concepts/security/workspace-security-center)。
* 需要了解某个术语的含义？请阅读[安全概念](/zh/pt/core-concepts/security/concepts)。

大多数安全工作都遵循同样的流程：扫描、查看结果、用 Agent 修复、重新发布，并在需要时导出证据。

<div id="onde-fica-a-segurana-no-produto">
  ## 产品中的安全功能在哪里
</div>

<div id="em-um-projeto">
  ### 在 project 中
</div>

打开 **Security** 面板，即可查看 project 级别的检查结果、使用 Agent 运行安全扫描，并在发布前排查依赖项漏洞。

</Frame>

<div id="no-seu-workspace">
  ### 在你的 workspace 中
</div>

在主页侧边栏选择 **Security**，即可查看所有项目的漏洞、按暴露程度对结果排序，并跟踪 workspace 级别的扫描历史记录。

  <img src="/assets/mirror/security-overview-b37f090f236c.png" alt="Workspace Security Center 的初始视图，显示扫描总数、漏洞总数以及按严重程度分组的 CVE" width="3438" height="1984" data-path="images/workspace-security-center/security-overview.png" />
</Frame>

<div id="na-publicao-e-nas-configuraes">
  ### 在发布和设置中
</div>

* 在 **Publish** &gt; **Advanced** 中，使用 **Block publishing of critical vulnerabilities** 阻止存在严重漏洞的应用发布上线。
* 在 **Settings** &gt; **Account** &gt; **Advanced** 中，为 Agent 准备的依赖项修复设置 Auto-Protect 的严重性阈值。
