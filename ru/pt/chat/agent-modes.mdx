Режимы Agent позволяют выбрать баланс между включённой квотой, кредитами и мощностью ещё до отправки запроса. Откройте выпадающее меню настроек Agent в поле prompt и выберите режим, который подходит для вашей задачи.

<Note>
  Режим Economy больше не доступен. Его заменяет режим Power по той же цене.
</Note>

<div id="escolha-um-modo">
  ## Выберите режим
</div>

* **Режим Free:** изучайте идеи, задавайте вопросы, начинайте создавать и ведите повседневную работу. Режим Free выбирает модель с помощью интеллектуальной маршрутизации моделей. {FreeModePlanAvailability}
* **Режим Power:** оптимальный баланс скорости и возможностей для большинства задач. Используйте его, когда квоты режима Free уже не хватает или когда для существующего проекта нужен более мощный вариант по умолчанию.
* **Режим Max:** самый производительный вариант для сложных и амбициозных задач, крупных кодовых баз и трудных проблем.

Режимы Power и Max расходуют ежемесячные кредиты. Replit предупредит, прежде чем запрос перейдёт из режима Free в режим, который тарифицируется. Проверить остаток квоты режима Free можно в разделе **Настройки** → **Использование**. Практические советы см. в статье [Как использовать режим Free по максимуму](/ru/pt/chat/free-mode).

Routines выполняются в режиме Power или Max и требуют бюджета на каждый запуск. В режиме Free они не работают. Подробнее о [Routines](/ru/pt/chat/routines).
