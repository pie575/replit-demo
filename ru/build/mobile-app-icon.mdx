Для подачи заявки в оба магазина нужна иконка App. Replit может создать её
сразу — отдельный инструмент для дизайна не потребуется.

<div id="what-each-store-needs">
  ## Требования для каждого магазина
</div>

* **App Store:** 1024×1024, без прозрачности и скруглённых углов — Apple добавит их сама.
* **Google Play:** 512×512.

<div id="generate-it">
  ## Создайте её
</div>

Перед отправкой промпта переключитесь в режим **Design** — так вы укажете Agent генерировать изображения.

<AiPrompt>
  {appIconPrompt}
</AiPrompt>

Agent сразу создаёт несколько вариантов, чтобы вы могли сравнить их и выбрать один, прежде чем принять решение.
