Инструмент Publishing — это место, где вы запускаете приложение в продакшн и управляете его работой в интернете. Все настройки, определяющие веб-адрес приложения, круг пользователей с доступом, продакшн-базу данных, мониторинг, безопасность и способ размещения, собраны в одной панели.

Чтобы открыть его, выберите **Publishing** в разделе **Replit Cloud** панели **Tools** либо нажмите **Publish** в правом верхнем углу Project Editor.

<div id="section">
  ## Публикация приложения
</div>

В главной панели по порядку собрано всё, что нужно для запуска приложения в продакшне. Просмотрите каждый раздел и нажмите **Publish**.

<Frame>
  <img src="/assets/mirror/publish-your-app-851815208b8a.png" alt="Панель Publish your app: поле Domain, публикуемое приложение, настройки доступа, настройки базы данных, мониторинг, безопасность и инструменты вовлечения расположены над кнопкой Publish" width="578" height="980" data-path="images/deployments/publish-pane/publish-your-app.png" />
</Frame>

* **Domain** — веб-адрес приложения. Replit предлагает имя в домене `.replit.app` и проверяет, свободно ли оно. Имя можно изменить, а после публикации — подключить [собственный домен](/ru/ja/features/publishing/custom-domains).
* **What you&#39;re publishing** — предварительный просмотр приложения, которое будет запущено, и его URL.
* **Who can access your app** — на выбор доступны варианты **Public**, **Password protected**, **Workspace only** и **Invite only**. Закрытые варианты ограничивают доступ к приложению пределами workspace либо кругом приглашённых пользователей и групп. Подробнее — в разделе [Доступ к приложению](/ru/ja/features/publishing/private-deployments).
* **Database settings** — управление тем, как при публикации создаётся и наполняется данными продакшен-база данных приложения. Подробнее — в разделе [Продакшен-база данных](/ru/ja/features/data-and-storage/development-and-production).
* **Monitoring tools** — включите мониторинг приложения, чтобы первыми узнавать о сбоях. Replit постоянно проверяет доступность приложения и при возникновении проблем уведомляет вас по электронной почте. Подробнее — в разделе [Мониторинг приложения](/ru/ja/features/publishing/monitoring-a-deployment).
* **Security tools** — запуск подробного сканирования безопасности перед публикацией. Security Agent сочетает ИИ с ведущими инструментами статического анализа и проверяет project на уязвимости. Подробнее — в разделе [Project Security Center](/ru/ja/features/security/project-security-center).
* **Engagement tools** — включите виджет обратной связи, чтобы в углу опубликованного приложения появилась кнопка отправки отзывов. Полученные сообщения можно просматривать во входящих и отправлять Agent для исправлений.

<div id="section-2">
  ## Настройка параметров
</div>

Выбрав **Adjust settings**, вы можете вручную настроить способ размещения приложения. Большинству разработчиков менять эти параметры не требуется — Replit подбирает подходящие значения по умолчанию.

<Frame>
  <img src="/assets/mirror/adjust-settings-d6e124b2249f.png" alt="Раздел Adjust settings с типом деплоя, конфигурацией машины, секретами деплоя, географией деплоя и переключателем блокировки публикации при критических уязвимостях" width="574" height="794" data-path="images/deployments/publish-pane/adjust-settings.png" />
</Frame>

* **Deployment type**: технология, с помощью которой публикуется приложение. **Autoscale** рекомендуется для большинства приложений, так как масштабируется от нуля до любого уровня нагрузки. Сравните [типы деплоя](/ru/ja/features/publishing/deployment-types).
* **Machine configuration**: мощность сервера, на котором работает приложение. Выберите **Edit**, чтобы изменить количество CPU, объём памяти и максимальное число машин. В панели отображается стоимость одной машины и стоимость при максимальном трафике. Подробнее см. в разделе [конфигурация машины](/ru/ja/features/publishing/machine-configuration).
* **Deployment secrets**: секретные ключи, с помощью которых приложение обращается к API и сервисам (безопасное закрытое хранилище для конфиденциальных данных, например ключей API). Secrets автоматически синхронизируются из среды разработки в опубликованное приложение. Подробнее см. в разделе [Secrets](/ru/ja/core-concepts/project-editor/app-setup/secrets).
* **Deployment geography**: место размещения приложения. Чем ближе регион к вашим пользователям, тем ниже задержка. После публикации приложение и его ресурсы закрепляются за этим регионом. Чтобы изменить регион позже, сделайте ремикс приложения. Подробнее см. в разделе [география проекта](/ru/ja/features/publishing/project-geography).
* **Block publishing of critical vulnerabilities**: Replit всегда выполняет проверку безопасности перед публикацией. Эта настройка определяет, блокировать ли публикацию при обнаружении критических уязвимостей. Подробнее см. в разделе [Project Security Center](/ru/ja/features/security/project-security-center).
