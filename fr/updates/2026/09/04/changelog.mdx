<div id="recover-production-data-with-scheduled-backups">
  ### Récupérer les données de production grâce aux sauvegardes planifiées
</div>

Les sauvegardes planifiées créent chaque jour un point de restauration complet de votre base de données de production. Pour les activer, sélectionnez une durée de conservation sous **Conserver les sauvegardes pendant** dans les paramètres de votre base de données de production. Les limites de conservation dépendent de votre offre.

<div id="understand-app-usage-with-project-analytics">
  ### Comprendre l&#39;utilisation de votre app avec Project Analytics
</div>

Project Analytics vous montre comment les internautes trouvent et utilisent votre web app publiée. Consultez dans le volet **Growth** les tendances approximatives de fréquentation, les pages les plus consultées, les sources de trafic, les pays, les navigateurs et les appareils. Pour commencer à collecter des données, activez **Enable analytics** et republiez votre app. Avec un forfait payant, demandez à Agent d&#39;ajouter des événements personnalisés et d&#39;analyser des tunnels de conversion pour des actions telles que les inscriptions et les achats.
