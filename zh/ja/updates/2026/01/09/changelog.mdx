<div id="ai">
  ### 集成新增 AI 模型
</div>

AI 集成现已支持以下新发布的 AI 模型：

| 模型                           | 描述                                                                   |
| ---------------------------- | -------------------------------------------------------------------- |
| `gpt-5.2`                    | OpenAI 面向专业知识工作推出的最强大模型。首个在 ARC-AGI-1 上取得超过 90% 成绩的模型，拥有 400K 上下文窗口。 |
| `claude-opus-4.5`            | Anthropic 的旗舰模型，专为编程、智能体和计算机操作优化。在 SWE-bench Verified 上达到 80.9%。     |
| `gemini-3-flash-preview`     | Google 面向智能体工作流的高速模型，拥有 1M Token 上下文。以低延迟和低成本提供接近 Pro 级别的推理能力。       |
| `gemini-3-pro-preview`       | Google 的先进多模态模型，具备前沿推理能力和现实世界知识。                                     |
| `gemini-3-pro-image-preview` | Google 的 Nano Banana Pro 模型，可通过精准的文本渲染实现高质量图像生成和编辑。                  |
