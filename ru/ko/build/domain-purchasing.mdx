Превратите своё приложение в полноценный профессиональный сайт.

Покупка домена позволяет подобрать, приобрести и подключить домен к приложению, в деплое в Replit, — и всё это прямо на платформе. Всего за несколько минут приложение в деплое превращается в профессиональный сайт в интернете.

Другими словами, вы можете купить домен вроде `my-app.com`, и он автоматически подключится к вашему приложению.

<div id="section">
  ## Возможности
</div>

Покупка домена упрощает назначение приложению профессионального веб-адреса. Вы можете настроить всё веб-присутствие в Replit, не пользуясь несколькими сервисами.

<Frame>
  <img src="/assets/mirror/replit-domains-8453291b634b.png" alt="Интерфейс управления доменами с приобретёнными доменами и статусом их подключения" width="3176" height="1556" data-path="images/deployments/custom-domains/replit-domains.png" />
</Frame>

Основные возможности:

* **Поиск доменов и проверка доступности**: проверяйте доступность доменов в популярных зонах, таких как `.com` и `.ai`
* **Покупка в один клик**: покупайте домены напрямую в Replit, используя основной способ оплаты в своей учётной записи
* **Автоматическая настройка**: домен сразу указывает на ваше Replit App без ручной настройки DNS
* **Защита конфиденциальности WHOIS**: личные данные остаются скрытыми в общедоступных записях домена — включена по умолчанию при каждой покупке домена
* **Пользовательские записи DNS**: добавляйте пользовательские записи A, TXT и MX для настройки почтовых сервисов и других служб
* **Мгновенная публикация**: сразу после покупки приложение становится доступно по пользовательскому домену
* **Автоматическое продление**: домен автоматически продлевается, чтобы приложение оставалось доступным без перерывов

<div id="section-2">
  ## Как пользоваться
</div>

<div id="section-3">
  ### Покупка домена
</div>

1. Опубликуйте приложение и перейдите на вкладку <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Иконка Publish" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publishing**
2. Выберите вкладку **Domains**
3. Нажмите **Buy a domain**, чтобы начать поиск
4. Введите нужное доменное имя в поле поиска
5. Ознакомьтесь с доступными вариантами доменов с разными расширениями
6. Выберите нужный домен и завершите покупку

После покупки домен будет автоматически настроен для вашего Replit App. Вы сможете сразу открыть приложение по собственному домену без дополнительной настройки.

Стоимость покупки домена списывается через ваш аккаунт Replit: сначала она вычитается из баланса аккаунта, а затем учитывается в Usage.

<div id="section-4">
  ### Управление приобретёнными доменами
</div>

Домен легко интегрируется с приложением в деплое.

* **Автоматическое продление**: домен автоматически продлевается, чтобы приложение оставалось доступным
* **Единый счёт**: стоимость домена отображается в счёте Replit вместе с другими услугами
* **Поддержка переноса**: при необходимости домен можно перенести между аккаунтами Replit или к внешнему регистратору

<div id="dns">
  ### Пользовательские записи DNS
</div>

Для доменов, приобретённых через Replit, можно добавлять пользовательские записи DNS для настройки дополнительных сервисов, например почтовых провайдеров. Поддерживаемые типы записей DNS:

* **Запись A**: связывает домен или поддомен с определённым IP-адресом
* **Запись TXT**: добавляет текстовые записи для аутентификации электронной почты, например SPF, DKIM и DMARC
* **Запись MX**: записи MX (почтового обмена) указывают почтовым серверам, куда направлять почту для домена. Настроив запись MX, вы сможете использовать пользовательский домен для адресов электронной почты, таких как `hello@yourdomain.com`.

Чтобы управлять записями DNS приобретённого домена:

1. Перейдите на вкладку **Domains** в Publishing <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="иконка Publish" width="16" height="16" data-path="images/icons/deploy-icon.svg" />
2. Найдите домен, который хотите настроить
3. Выберите иконку **Edit** <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="иконка карандаша" width="16" height="16" data-path="images/icons/pencil-icon.svg" />
4. Выберите **Add DNS Record**
5. Введите тип, имя, значение и TTL записи, требуемые вашим поставщиком услуг

В этом коротком видео показано, как найти страницу управления записями DNS домена.

  Распространение изменений DNS по всему миру может занять до 48 часов. В течение этого времени приложение будет работать нормально.

<div id="section-5">
  ### Поддерживаемые типы деплоя
</div>

Покупка доменов доступна для следующих типов деплоя:

* **[Автомасштабируемый деплой](/ru/ko/features/publishing/deployment-types#autoscale)**
* **[Деплой Reserved VM](/ru/ko/features/publishing/deployment-types#reserved-vm)**
* **[Статический деплой](/ru/ko/features/publishing/deployment-types#static)**

В настоящее время покупка доменов доступна для приложений в деплое в личных аккаунтах. Покупка доменов для Replit Pro появится в ближайшее время.

<div id="faq">
  ## Часто задаваемые вопросы
</div>

<AccordionGroup>
  <Accordion title="Сколько это стоит?">
    Покупка домена включает два вида расходов.

    * **Регистрационный сбор**: первоначальная стоимость владения доменом в течение одного года (для доменов `.ai` — двух лет)
    * **Стоимость продления**: автоматически взимается после окончания первоначального периода регистрации

    Replit не взимает дополнительную плату за покупку домена. Регистрационные сборы за домен не возвращаются.
  </Accordion>

  <Accordion title="Как продлить домен?">
    Replit автоматически продлевает домен, чтобы ваше приложение оставалось доступным. Чтобы отключить автоматическое продление, откройте вкладку **Domains** в Publishing, выберите домен и выключите переключатель **Auto renewal**. На этом же экране можно узнать дату и стоимость продления домена.
  </Accordion>

  <Accordion title="Что делать, если я хочу уйти из Replit?">
    Обратитесь в службу поддержки Replit, чтобы перенести домен к другому регистратору. Согласно правилам ICANN, перенести домен к внешнему регистратору можно только через 60 дней после покупки.
  </Accordion>

  <Accordion title="Можно ли перенести домен между аккаунтами Replit?">
    Да, обратитесь в службу поддержки Replit, чтобы перенести домен между аккаунтами Replit. В этом случае 60-дневный период ожидания не требуется.
  </Accordion>

  <Accordion title="Можно ли приобрести домен для организации?">
    Покупка доменов для тарифов Replit Pro и Enterprise станет доступна после завершения начального периода бета-тестирования.
  </Accordion>

  <Accordion title="Можно ли добавить к домену пользовательские записи DNS?">
    Да! Вы можете добавлять пользовательские записи DNS к доменам, приобретённым через Replit. В настоящее время поддерживаются следующие типы записей:

    * **Записи A**: связывают домен или поддомен с определённым IP-адресом
    * **Записи TXT**: добавляют текстовые записи подтверждения для проверки электронной почты и других сервисов
    * **Записи MX**: настраивают почтовые серверы для обработки электронной почты домена

    Перейдите на вкладку Domains в Publishing, чтобы настроить эти записи. Подробные инструкции по настройке записей MX для электронной почты см. в разделе [Пользовательские записи DNS](#custom-dns-records) выше.
  </Accordion>

  <Accordion title="Какие доменные зоны поддерживаются?">
    Поддерживаются все распространённые домены верхнего уровня (TLD). TLD с особыми географическими или другими ограничениями могут не поддерживаться.
  </Accordion>

  <Accordion title="Что такое защита конфиденциальности WHOIS?">
    При регистрации домена контактная информация (имя, адрес, номер телефона и электронная почта) обычно публикуется в общедоступной базе данных WHOIS, доступной для поиска любому пользователю. Защита конфиденциальности WHOIS заменяет ваши персональные данные общими данными регистратора, сохраняя информацию конфиденциальной при соблюдении юридических требований.

    Все домены, приобретённые через Replit, по умолчанию включают защиту конфиденциальности WHOIS без дополнительной платы. Это означает, что ваши персональные данные скрыты от спамеров, маркетологов и любых других лиц, ищущих информацию о владельце домена.
  </Accordion>

  <Accordion title="Что делать, если у меня уже есть домен?">
    Чтобы подключить существующий домен к Replit App, см. документацию [Пользовательские домены](/ru/ko/features/publishing/custom-domains).
  </Accordion>
</AccordionGroup>
