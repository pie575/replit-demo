Agent의 Web Search <img class="icon-svg" src="/assets/mirror/web-search-1fe8f63b5b88.svg" alt="Web Search icon" width="16" height="16" data-path="images/icons/web-search.svg" /> 기능으로 최신 실제 데이터를 활용한 애플리케이션을 만들어 보세요.

이 기능은 웹에서 최신 정보를 가져와 지식 컷오프의 한계를 극복합니다. 최신 정보가 필요한 작업을 Agent에 요청하면 Agent가 웹을 검색해 상세한 내용을 가져오므로 앱이 한층 더 정확하고 유용해집니다.

Web Search는 최신 package, 도구, 정보를 찾는 데 유용합니다. 이를 통해 앱이 최신 모범 사례를 따르고 더 정확해집니다.

<div id="features">
  ## 기능
</div>

Agent의 Web Search를 활용해 최신 정보를 반영한 애플리케이션을 만들어 보세요. 직접 자료를 조사하고 데이터를 수집하는 수고를 덜 수 있습니다. 금융 데이터를 담은 대시보드를 만들든, 최근 스타트업 출시 소식을 소개하는 웹사이트를 만들든, Web Search는 앱이 실제 현실을 반영하도록 해줍니다.

Agent는 다음과 같은 Web Search 작업을 수행할 수 있습니다.

* **Search**: 인터넷에서 최신 정보, 최신 문서, 실시간 데이터를 찾습니다
* **Content fetching**: 특정 웹사이트와 URL에서 상세한 정보를 가져옵니다
* **출처 인용**: Agent가 정보를 찾은 위치를 정확히 확인할 수 있어 출처를 검증하고 인용할 수 있습니다

<div id="usage">
  ## Usage
</div>

Web Search는 Agent에 기본 탑재되어 있어 따로 켤 필요가 없습니다. 만들고 싶은 것을 설명하면 Agent가 최신 정보를 얻기 위해 웹을 검색할 시점을 자동으로 판단합니다. prompt에 &quot;검색&quot;, &quot;조사&quot;, &quot;Web Search 사용&quot;과 같은 키워드를 넣으면 Agent가 검색을 수행하도록 명시적으로 유도할 수 있습니다.

<div id="how-web-search-enhances-your-apps">
  ### Web Search가 앱을 향상하는 방식
</div>

Web Search를 사용하면 애플리케이션이 임시 데이터 대신 실제의 정확한 정보를 활용할 수 있습니다:

| 이점        | 설명                                  |
| --------- | ----------------------------------- |
| 최신 기술     | 학습 데이터에 없는 최신 정보와 packages를 앱에서 사용  |
| 최적의 도구 선택 | Agent가 여러 선택지를 조사해 최적의 packages를 선택 |
| 최신 모범 사례  | 최신 개발 패턴과 보안 관행 활용                  |
| 한계 극복     | 지식 컷오프를 넘어 학습 이후 출시된 packages까지 사용  |
| 정확한 데이터   | 오래된 예시 대신 최신 정보를 앱에 표시              |
| 전문적인 결과물  | 실제 기업 정보를 반영해 신뢰감 있는 애플리케이션 구현      |
| 시간 절약     | packages를 직접 조사하고 데이터를 수집하는 수고를 줄임  |

<div id="source-citations">
  ### 출처 인용
</div>

Agent가 Web Search를 사용하면 해당 정보를 어디에서 가져왔는지 정확히 보여주는 **출처 인용**을 함께 제공합니다. 이 인용은 다음과 같이 활용할 수 있습니다.

* **정보 검증**: 출처의 신뢰성과 정확성을 확인합니다
* **더 알아보기**: 원본 출처를 방문해 더 자세한 맥락을 파악합니다
* **출처 표기**: 애플리케이션에 적절한 출처 표기를 포함합니다
* **조사 과정 추적**: 어떤 정보가 Agent의 작업에 반영되었는지 파악합니다

<div id="content-fetching">
  ### Content fetching
</div>

Agent는 특정 웹사이트에서 상세한 콘텐츠를 가져와 프로젝트에 필요한 종합적인 정보를 수집할 수 있습니다. 이를 통해 Agent는 다음과 같은 작업을 수행합니다.

* 웹 페이지 전체를 읽고 관련 세부 정보 추출
* 문서 및 참고 자료 처리
* 신뢰할 수 있는 출처에서 특정 데이터 수집
* 구조화된 정보를 애플리케이션에 통합
