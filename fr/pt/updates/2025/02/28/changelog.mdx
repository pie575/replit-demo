<div id="agent-v2">
  ### Agent v2
</div>

<img src="/assets/mirror/agent-web-01b1f9026de7.webp" alt="Agent v2" width="800" height="450" data-path="images/changelog/2025-02-28/agent-web.webp" />

Une nouvelle expérience Agent est disponible pour tous les créateurs. Ce nouvel Agent est plus rapide, plus précis et plus performant que la version précédente.

Il s&#39;appuie désormais sur Claude 3.7 Sonnet, le modèle le plus avancé d&#39;Anthropic à ce jour.

Pour l&#39;essayer, rejoignez le programme Explorer. Les instructions sont disponibles [ici](https://youtu.be/pE_XT2TaXCA).

<div id="melhorias-nas-implantaes">
  ### Améliorations des déploiements
</div>

Des suggestions d&#39;IA s&#39;affichent désormais lorsque les créateurs choisissent un déploiement statique pour des applications dynamiques, ce qui améliore le comportement de l&#39;Agent face aux demandes de déploiement.

<div id="melhoria-no-desempenho-do-banco-de-dados">
  ### Amélioration des performances de la base de données
</div>

Les opérations de base de données sont désormais plus rapides que jamais : l&#39;opération la plus coûteuse est passée de 200 ms à moins de 1 ms.
