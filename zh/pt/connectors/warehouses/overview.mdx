数据仓库连接器让 Replit Agent 能够安全查询您组织的数据仓库。开发者可使用自然语言创建仪表板、报表工具和数据应用，无需具备 SQL 知识。管理员可通过基于角色的访问控制进行集中管理。

<div id="warehouses-suportados">
  ## 支持的数据仓库
</div>

数据仓库连接器仅适用于 **Enterprise** 方案。

| 数据仓库             | 配置指南                                                                             |
| ---------------- | -------------------------------------------------------------------------------- |
| BigQuery         | 现已支持，配置指南即将推出                                                                    |
| Databricks       | [连接 Databricks](/zh/pt/connectors/warehouses/databricks)                            |
| Microsoft Fabric | [在 Microsoft Fabric 中构建数据应用](/zh/pt/connectors/warehouses/microsoft-fabric) (私密预览)  |
| Snowflake        | [连接 Snowflake](/zh/pt/connectors/warehouses/snowflake)                              |

每种数据仓库都有各自的配置流程，因为 OAuth 集成、身份模型和凭据格式均不相同。请选择您使用的数据仓库，并按照相应指南操作。

<div id="plataformas-de-anlise-e-dados">
  ## 分析与数据平台
</div>

Core、Pro 和 Enterprise 方案均可使用分析连接器。连接您的分析工具，让 Agent 能够读取和处理产品数据：

* **Segment** — CDP 中的客户数据、事件流和受众细分
* **Amplitude** — 产品分析、用户行为数据和互动指标
* **Hex** — 协作式数据笔记本和查询结果

您可以像管理其他 Replit 连接器一样管理它们。请参阅[管理连接器](/zh/pt/replitai/managing-connectors)。

<div id="como-funcionam-os-conectores-de-warehouse">
  ## 数据仓库连接器的工作原理
</div>

配置为一次性流程，涉及三类角色：

1. **数据仓库管理员** — 在数据仓库中创建 OAuth 集成或服务身份
2. **Replit 组织管理员** — 将凭证添加到 Replit 并配置访问权限
3. **开发者** — 登录并开始使用 Agent 创建应用

配置完成后，开发者可让 Agent 使用数据仓库，Agent 会在其中编写和执行 SQL。

<div id="criando-com-dados-de-warehouse">
  ### 使用 warehouse 数据构建应用
</div>

连接后，您可以让 Agent 创建使用您数据的应用。Agent 可以：

* 创建用于获取和展示实时数据的内部工具
* 基于您的 warehouse 创建包含图表和可视化内容的仪表板
* 生成 SQL 查询，为应用的 backend 提供数据
* 解释架构和表结构，帮助您了解可以构建什么

<Note>
  虽然 Agent 可以回答有关您数据的临时问题，但数据仓库连接器的主要目的是让 Agent 创建能够充分利用组织数据的功能性应用。warehouse 查询会直接在您的实例上运行，因此，请确保您的 OAuth 作用域和数据库用户权限允许执行所需的读取和写入操作。
</Note>
