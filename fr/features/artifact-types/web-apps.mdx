Les applications web sont le type de résultat par défaut sur Replit. Lorsque vous décrivez une idée à Agent, celui-ci crée une application web full-stack, sauf si vous précisez un autre type d&#39;artefact.

<div id="getting-started">
  ## Premiers pas
</div>

Il existe deux façons de créer une application web :

* **Saisir un prompt** : décrivez ce que vous souhaitez créer sur la page d&#39;accueil de Replit. Agent crée automatiquement une application web.
* **Choisir dans le menu déroulant** : ouvrez le menu déroulant des types d&#39;app sur la page d&#39;accueil, sélectionnez **Web app**, puis décrivez votre idée.

<div id="key-features">
  ## Fonctionnalités clés
</div>

* **Full-stack par défaut** : chaque application web comprend un frontend et un backend. Agent met en place les routes d&#39;API, une base de données et la logique côté serveur selon les besoins de votre app.
* **Design responsive** : les apps s&#39;adaptent automatiquement aux différentes tailles d&#39;écran.
* **Publication instantanée** : publiez votre app en un clic. Replit se charge de l&#39;hébergement, du SSL et de l&#39;infrastructure.
* **Infrastructure partagée** : si votre project comporte plusieurs artefacts — comme une app mobile ou un tableau de bord de données —, tous partagent le même backend, la même base de données et les mêmes services.

<div id="use-cases">
  ## Cas d&#39;usage
</div>

* **Produits SaaS** : créez des outils, des tableaux de bord et des plateformes destinés à vos clients.
* **Outils internes** : concevez des panneaux d&#39;administration, des CRM ou des applications de gestion de flux de travail pour votre équipe.
* **Landing pages** : lancez des sites marketing avec formulaires, animations et contenu dynamique.
* **Places de marché et annuaires** : créez des sites d&#39;annonces, des plateformes d&#39;offres d&#39;emploi ou des espaces communautaires.
