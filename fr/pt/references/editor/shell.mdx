Le Shell vous permet d&#39;effectuer des tâches au niveau du système d&#39;exploitation dans le Project Editor, comme gérer des fichiers,
installer des paquets et exécuter des scripts. Il fournit une puissante interface textuelle pour
interagir avec votre environnement Replit.

Vous pouvez utiliser le Shell pour effectuer les tâches suivantes dans le Project Editor :

* Exécuter des scripts et des programmes
* Installer et exécuter des outils et paquets Linux populaires
* Téléverser et télécharger des fichiers depuis Internet
* Gérer les fichiers et répertoires du projet

<Tip>
  Pour mieux gérer les Workflow, privilégiez le bouton **Run** plutôt que d&#39;exécuter votre application depuis le
  Shell. Le Workflow lancé par le bouton **Run** envoie la sortie vers l&#39;outil Console,
  qui permet de consulter les logs de manière structurée.
</Tip>

<div id="recursos">
  ## Fonctionnalités
</div>

Le Shell offre les possibilités suivantes :

* **Exécuter plusieurs shells** : ouvrez plusieurs instances du Shell pour travailler simultanément sur différentes tâches
* **Rechercher du texte** : retrouvez un texte précis dans la sortie du Shell

<div id="uso">
  ## Utilisation
</div>

<Accordion title="Comment accéder au Shell">
  Dans le **dock d&#39;outils** à gauche :

  1. Sélectionnez <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Icône Tous les outils" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools** pour afficher la liste des outils du Project Editor.
  2. Sélectionnez <img class="icon-svg" src="/assets/mirror/shell-289d6eb079b0.svg" alt="Icône du Shell" width="16" height="16" data-path="images/icons/shell.svg" /> **Shell**.

  Dans la **barre de recherche** :

  1. Sélectionnez la <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="icône de loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> loupe en haut de l&#39;écran pour ouvrir l&#39;outil de recherche
  2. Saisissez « Shell » pour trouver l&#39;outil, puis sélectionnez-le dans les résultats.
</Accordion>

<div id="pesquisa-de-texto">
  ### Recherche de texte
</div>

Les étapes suivantes expliquent comment accéder à l’outil de recherche de texte et l’utiliser :

1. Sélectionnez l’<img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="icône de loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> icône de loupe située dans l’angle supérieur droit de l’onglet Shell pour ouvrir la boîte de dialogue de recherche.
2. Saisissez un terme de recherche et sélectionnez **Next** pour parcourir les résultats.
3. Utilisez **Previous** pour revenir aux résultats précédents.
4. Sélectionnez **Exit** ou cliquez en dehors de la boîte de dialogue pour quitter la recherche de texte.

<div id="mltiplos-shells">
  ### Plusieurs shells
</div>

Pour créer un nouveau shell, ouvrez le menu situé dans le coin supérieur gauche de l’onglet **Shell**, puis sélectionnez **New Shell**, comme illustré ci-dessous :

<Frame>
  <img src="/assets/mirror/shell-new-94a280c1230f.png" alt="Sélection du menu New Shell" width="1280" height="224" data-path="images/workspace/shell-new.png" />
</Frame>

Utilisez ce même menu pour passer d’un shell à l’autre. Le Project Editor identifie chaque shell par la dernière commande exécutée pour vous aider à les distinguer.

<Warning>
  Lorsque vous ouvrez plusieurs shells, Replit ferme automatiquement les instances de shell inactives.
  Un shell inactif est un shell qui n’est pas sélectionné et qui n’exécute aucun processus utilisateur.
</Warning>
