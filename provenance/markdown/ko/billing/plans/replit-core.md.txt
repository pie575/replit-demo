# Replit Core

> 강력한 AI 도구, 고성능 개발 리소스, 원클릭 게시를 포함한 Replit Core 멤버십 기능을 알아보세요.

[Replit Core](https://replit.com/replit-core) 멤버십은 아이디어에서 앱까지 빠르게 전환할 수 있는 프리미엄 도구에 접근할 수 있게 해줍니다. 현재 Core 요금(월간 또는 연간)은 [요금 페이지](https://replit.com/pricing)를 참조하세요.

## 주요 기능

Core 멤버십은 다음 기능을 제공합니다:

### AI 기반 도구

* **Agent**: Agent와 채팅하여 앱을 빌드, 디버그, 반복 개선
* **전체 빌드**: Agent가 더 큰 작업을 독립적으로 수행하도록 할 때 Economy 또는 Power 사용
* **Lite 빌드**: 빠른 변경을 위한 목표가 명확한 편집
* **Design Canvas**: 시각적 아이디어 탐색, 변형 생성, 디자인을 아티팩트로 변환
* **Visual Editor**: 앱의 콘텐츠와 레이아웃을 시각적으로 직접 편집
* **모든 아티팩트 유형**: 웹 앱, 모바일 앱, 데이터 시각화, 슬라이드 덱, 애니메이션 비디오 등
* **Plan Mode**: 코드를 편집하지 않고 Agent와 아이디어 구상 및 작업 계획
* **커넥터**: Google, Stripe 등 제3자 서비스와 통합

### 협업

* 별도의 팀 구독 없이 워크스페이스에 최대 5명의 빌더 초대
* 백그라운드 작업 — 한 번에 1개의 활성 작업
* 계획 및 작업 추적을 위한 공유 칸반 보드

### 빠르고 안전한 개발

* 고성능 클라우드 개발 환경에서 작업
* 종량제 결제로 서비스 중단 없이 사용
* 비밀 도구를 사용하여 민감한 데이터를 코드와 분리하여 안전하게 보관

특정 플랜의 비용과 한도는 <a href="https://replit.com/pricing" target="_blank">요금 페이지</a>를 참조하세요.

### 월간 크레딧

* Agent, 게시, 네트워크 전송, 데이터베이스 스토리지와 같은 유료 서비스에 자동으로 적용되는 월간 크레딧을 받습니다. 더 많은 빌더나 더 높은 크레딧 단계가 필요하신가요? [Replit Pro](/ko/billing/plans/replit-pro)를 참조하세요.

### 원클릭 게시

게시는 모든 플랜에서 이용 가능합니다. 무료 Starter 플랜에는 게시된 앱 1개가 포함되어 있지만, Replit Core는 이 제한을 없애 무제한으로 제공하며 더 많은 옵션을 추가합니다:

* 무제한 앱 게시
* 지출을 최적화하기 위한 다양한 게시 옵션 선택
* 내장 로깅 및 분석 접근
* 게시된 앱에서 "Made with Replit" 배지 제거

### AI 기반 지원 및 커뮤니티 이벤트

* 청구, 계정, 제품, 기술 관련 문의를 빠르게 해결하는 AI 기반 지원 이용
* 멤버 전용 포럼 및 이벤트 접근
* 새 기능 조기 접근

## 시작하기

몇 가지 간단한 단계로 Replit Core로 업그레이드하세요:

1. <a href="https://replit.com/pricing" target="_blank">요금제</a> 페이지로 이동합니다
2. **Replit Core 가입**을 선택합니다
3. **월간** 또는 **연간** 플랜을 선택하고 결제 세부 정보를 입력합니다
