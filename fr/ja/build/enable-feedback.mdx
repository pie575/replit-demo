title: "Activer le widget de retour"
description: "Découvrez comment recueillir les commentaires des visiteurs de votre application publiée."
---

L&#39;activation de la collecte de commentaires dans votre application publiée vous permet de recueillir directement les retours des visiteurs et de les envoyer à Agent. Une fois cette fonctionnalité activée, les visiteurs peuvent envoyer des commentaires accompagnés de captures d&#39;écran et de fichiers, que vous pouvez gérer depuis l&#39;Inbox.

<div id="section">
  ## Activer les retours
</div>

<Warning>
  Les retours ne peuvent être activés que pour les applications web. Ils ne sont pas disponibles pour les autres types d&#39;applications, comme les automatisations ou les applications mobiles.
</Warning>

Lorsque vous publiez une nouvelle application, activez le paramètre **Activer les retours** dans la boîte de dialogue de publication. Pour une application déjà publiée, vous pouvez activer les retours en la publiant de nouveau :

1. Ouvrez l&#39;outil Publishing
2. Sélectionnez **Paramètres avancés**
3. Activez **Activer les retours**
4. Publiez de nouveau l&#39;application

<div id="section-2">
  ## Envoyer un retour
</div>

Lorsque les retours sont activés dans une application publiée, les visiteurs peuvent envoyer un retour directement depuis l’application. Les utilisateurs peuvent :

* Se connecter et laisser un retour
* Laisser un retour textuel décrivant leur expérience ou leurs suggestions
* Sélectionner des éléments pour signaler des problèmes ou des fonctionnalités
* Téléverser des fichiers pour fournir un contexte supplémentaire

<div id="inbox">
  ## Gérer les retours dans Inbox
</div>

Tous les retours envoyés par les visiteurs s’affichent dans Inbox, accessible depuis le Project Editor. Depuis Inbox, vous pouvez effectuer les actions suivantes :

* **Add to Chat** : envoyer le retour dans un chat avec Agent et ajouter du contexte avant l’envoi
* **Send to Agent** : envoyer immédiatement le retour à Agent pour qu’il commence à travailler
* **Resolve** : marquer les retours traités comme résolus
* **Delete** : supprimer les retours devenus inutiles

Vous pouvez également utiliser des filtres pour organiser et rechercher des retours spécifiques.

<div id="section-3">
  ## Mettre à jour les paramètres de retour et republier
</div>

Même après avoir publié votre application, vous pouvez activer ou désactiver le widget de retours à tout moment en la republiant avec les paramètres mis à jour :

1. Ouvrez l’onglet **Vue d’ensemble** de l’outil Publishing
2. Sélectionnez **Paramètres avancés**
3. Activez ou désactivez **Activer les retours**
4. Republiez l’application pour appliquer les modifications

Les modifications apportées aux paramètres de retour prennent effet lorsque l’application est republiée.
