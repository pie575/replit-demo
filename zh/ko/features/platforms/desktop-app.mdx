<a href="https://replit.com/desktop" target="_blank">Replit 桌面应用</a>把完整的 Replit 体验带到你的电脑上。在专属应用中使用 Agent 构建，并享受浏览器标签页无法提供的原生功能。

<div id="replit">
  ## 什么是 Replit 桌面应用
</div>

Replit 桌面应用是专为 Windows 和 Mac 全新设计的原生应用。它提供与网页端一致的体验，让你在一个窗口中创建应用、与 Agent 对话并完成发布。除此之外，还带来了一些只有桌面应用才能实现的功能：

* **多任务处理**：同时处理多个 Replit 应用。
* **状态提示**：一眼掌握 Agent 何时需要帮助或已完成任务。
* **标签页预览**：无需切换标签页，即可快速查看已打开的应用。

<div id="section">
  ## 开始使用
</div>

<Steps>
  <Step title="下载应用">
    前往<a href="https://replit.com/desktop" target="_blank">桌面应用下载页面</a>，下载适合你电脑的版本。
  </Step>

  <Step title="安装并启动">
    打开下载的文件，按照提示完成安装。安装完成后启动应用。
  </Step>

  <Step title="登录">
    使用 Replit 账号登录；如果是第一次使用，请先创建账号。你构建的所有内容都会与 [replit.com](https://replit.com) 同步。
  </Step>
</Steps>

<Tip>
  应用、历史记录和设置在桌面应用和网页端保持一致，你可以在一端开始工作，再到另一端继续。
</Tip>

<div id="section-3">
  ## 面向企业团队的功能
</div>

借助桌面应用，您可以轻松在整个组织内部署 Replit。它的安装方式与其他桌面应用完全相同，IT 团队可通过设备管理 (MDM) 解决方案将其自动分发并安装到公司电脑上。如需了解更多信息，请联系您的客户经理。
