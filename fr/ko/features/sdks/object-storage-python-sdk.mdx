Ce guide de référence décrit la classe `Client` du package `replit-object-storage-python` et fournit des exemples de code pour ses méthodes.

<div id="client">
  ## Client
</div>

La classe `Client` gère les interactions avec Replit App Storage. Elle fournit des méthodes permettant d&#39;effectuer des opérations sur les objets d&#39;un bucket.

Pour importer la classe depuis le paquet `replit.object_storage`, ajoutez la ligne suivante à votre code Python.

```python theme={null}
from replit.object_storage import Client
```

Utilisez le code suivant pour créer une instance `Client` permettant d&#39;interagir avec Replit App Storage.

```python theme={null}
client = Client()
```

<Tip>
  Si votre application utilise plusieurs buckets, créez une instance `Client` par bucket.
</Tip>

<div id="__init__">
  ### **init**
</div>

La méthode `init` initialise une instance de la classe Client.

```python theme={null}
def __init__(bucket_id: Optional[str] = None)
```

**Arguments** :

* `bucket_id` (Optional[str]) : ID du bucket géré par le client. En cas d&#39;omission, le client utilise le bucket par défaut associé à la Replit App ou au deployment.

<div id="copy">
  ### copy
</div>

La méthode `copy` copie un objet au sein d&#39;un même bucket. Si un objet existe déjà à l&#39;emplacement cible, il est écrasé.

```python theme={null}
def copy(object_name: str, dest_object_name: str) -> None
```

**Arguments** :

* `object_name` (str) - chemin complet de l&#39;objet source.
* `dest_object_name` (str) - chemin complet de l&#39;objet de destination.

**Exceptions levées** :

* `ObjectNotFoundError` - indique qu&#39;aucun objet source n&#39;existe au chemin spécifié.

<div id="delete">
  ### delete
</div>

La méthode `delete` supprime définitivement un fichier d&#39;App Storage.

```python theme={null}
def delete(object_name: str, ignore_not_found: bool = False) -> None
```

**Arguments** :

* `object_name` (str) - Nom de l&#39;objet à supprimer.
* `ignore_not_found` (bool) - Si `True`, ignore l&#39;erreur levée lorsque l&#39;objet n&#39;existe pas.

**Exceptions levées** :

* `ObjectNotFoundError` - Indique que l&#39;objet n&#39;existe pas.

<div id="download_as_bytes">
  ### download_as_bytes
</div>

La méthode `download_as_bytes` récupère le contenu d&#39;un fichier sous forme de `bytes`.

```python theme={null}
def download_as_bytes(object_name: str) -> bytes
```

**Arguments** :

* `object_name` (str) - le nom de l&#39;objet à télécharger.

**Valeur de retour** :

* `bytes` - la représentation en octets bruts du contenu de l&#39;objet.

**Exceptions levées** :

* `ObjectNotFoundError` - indique que l&#39;objet n&#39;existe pas.

  ### download_as_text

La méthode `download_as_text` télécharge le contenu d&#39;un fichier au format `str`.


**Arguments** :

* `object_name` (str) - le nom de l&#39;objet source à récupérer.

**Exceptions levées** :

* `ObjectNotFoundError` - indique que l&#39;objet n&#39;existe pas.


<div id="exists">
  ### exists
</div>

La méthode `exists` vérifie si un objet existe.

```python theme={null}
def exists(object_name: str) -> bool
```

**Arguments** :

* `object_name` (str) - le nom de l&#39;objet dont on souhaite vérifier l&#39;existence.

**Valeur de retour** :

<div id="list">
  ### list
</div>

La méthode `list` récupère la liste des objets présents dans le bucket.

```python theme={null}
def list(end_offset: Optional[str] = None,
         match_glob: Optional[str] = None,
         max_results: Optional[int] = None,
         prefix: Optional[str] = None,
         start_offset: Optional[str] = None) -> List[Object]
```

**Arguments** :

* `end_offset` (Optional[str]) — filtre les résultats pour ne conserver que les objets dont le nom précède `end_offset` dans l&#39;ordre lexicographique. Si `start_offset` est défini,
  les objets listés sont ceux dont le nom se situe entre `start_offset` (inclus) et `end_offset` (exclu).
* `match_glob` (Optional[str]) — filtre les résultats à l&#39;aide d&#39;un motif glob. Par exemple, &quot;foo*bar&quot; correspond à &quot;footbar&quot;, &quot;foo baz bar&quot; et &quot;foobar&quot;.
* `max_results` (Optional[int]) — nombre maximal de résultats à renvoyer dans la réponse.
* `prefix` (Optional[str]) — filtre les résultats pour ne conserver que les objets dont le nom commence par le préfixe indiqué.
* `start_offset` (Optional[str]) — filtre les résultats pour ne conserver que les objets dont le nom est égal ou postérieur à `start_offset` dans l&#39;ordre lexicographique.
  Si `end_offset` est défini, les objets listés sont ceux dont le nom se situe entre `start_offset` (inclus) et `end_offset` (exclu).

**Valeur de retour** :

* `List` (Object) : liste des objets correspondant aux paramètres de requête indiqués.

<div id="section">
  ### Types d&#39;exceptions
</div>

* Lorsque vous utilisez `Client` pour interagir avec Replit App Storage, toute méthode peut renvoyer l&#39;une des erreurs suivantes.

  * `BucketNotFoundError` : indique que le nom de bucket configuré ne correspond à aucun bucket d&#39;App Storage.

  * `DefaultBucketError` : indique que la configuration du bucket par défaut est manquante.

  * `ForbiddenError` : indique que les autorisations sont insuffisantes pour accéder au bucket.

  * `TooManyRequestsError` : indique que l&#39;opération a fait l&#39;objet d&#39;une limitation de débit en raison d&#39;un nombre excessif de requêtes.

  * `UnauthorizedError` : indique que les droits d&#39;accès ont restreint l&#39;accès à l&#39;opération.
