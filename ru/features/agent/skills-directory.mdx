Каталог навыков — это подборка готовых навыков от Replit и наших партнёров, которые можно установить и сразу использовать. Установите навык, попробуйте его в деле, а затем настройте под то, как на самом деле работает ваша команда.

О том, что такое навык и как Agent его загружает, читайте в разделе [Agent Skills](/ru/features/agent/skills). Чтобы навык был доступен во всём workspace, см. [Agent Customization](/ru/features/agent/agent-customization).

<div id="install-a-skill">
  ## Установка навыка
</div>

Добавить навык из каталога можно несколькими способами:

* **В Chat** — нажмите кнопку **+** рядом с полем ввода чата, выберите **Use a skill** и укажите нужный навык. Навык применится только к этому сообщению, в project при этом ничего не устанавливается.
* **В project** — откройте панель **Skills** в Project Editor, перейдите на вкладку **Discover**, найдите навык и нажмите **Install**. Установленные навыки хранятся в каталоге `/.agents/skills` вашего project и сохраняются между чатами.
* **Из командной строки** — установите навык с помощью [skills CLI](https://github.com/vercel-labs/skills):

  ```bash theme={null}
  npx skills <skill> -a replit
  ```

<Warning>
  Навыки в списке выбора навыков Replit проходят проверку безопасности, а навыки из внешних источников — нет. Поскольку навык — это инструкции, которым следует Agent, всегда просматривайте внешний навык перед установкой: о том, на что обратить внимание, читайте в разделе [Agent skills](/ru/learn/agent-skills).
</Warning>

<div id="replit-skills">
  ## Навыки Replit
</div>

Replit поставляется с готовыми навыками, доступными в меню выбора **Use a skill** в Chat и в меню выбора отправной точки для нового проекта. Они работают в любом проекте без установки. Описания отображаются прямо в списке при открытии меню.

| Категория                               | Навыки                                                                                                        |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| Продажи и маркетинг                     | Ad Creative, AI SDR, SEO Auditor, Programmatic SEO, GEO, Content Machine, Storyboard                          |
| Карьера                                 | AI Recruiter, Resume Maker, Interview Prep                                                                    |
| Исследования и анализ                   | Competitive Analysis, Deep Research, GitHub Solution Finder, Supplier Research                                |
| Бизнес и финансы                        | Stock Analyzer, Excel Generator, Invoice Generator, Tax Reviewer                                              |
| Документы и инструменты                 | Website Cloner, File Converter, Flashcard Generator, Legal Contract, Infographic Builder, Recreate Screenshot |
| Творчество                              | Photo Editor, Podcast Generator, Podcast Marketing, Branding Generator, Video Editing                         |
| Продуктивность                          | AI Secretary, Product Manager, Design Thinker, Skill Finder, Skill Creator                                    |
| Личное                                  | Travel Assistant                                                                                              |
| Безопасность и соответствие требованиям | Secrets, Sensitive Data, Input Validation, AI Security, Dependency Vetting, License Check                     |
| Качество и надёжность                   | Accessibility, Responsive UI, Observability, Resilience, Ship Review                                          |

<Note>
  Внутри workspace меню выбора также находит любые дополнительные навыки, установленные в каталоге проекта `.local/secondary_skills/`.
</Note>

<div id="partner-skills">
  ## Партнёрские навыки
</div>

Партнёры Replit публикуют навыки, которые учат Agent разрабатывать приложения на основе их продуктов. Установите нужный навык, чтобы Agent знал паттерны и соглашения соответствующего сервиса.

| Партнёр          | Чему учит Agent                                    |
| ---------------- | -------------------------------------------------- |
| Stripe           | Паттерны интеграции платежей и биллинга            |
| PayPal           | Паттерны интеграции платежей                       |
| RevenueCat       | Паттерны подписок и покупок внутри приложения      |
| Mixpanel         | Реализация аналитики и отслеживания                |
| BigQuery         | Паттерны запросов к хранилищу данных               |
| Resend           | Интеграция транзакционной электронной почты        |
| Google Workspace | Интеграция Gmail, Drive, Docs и Calendar           |
| Atlassian        | Работа с задачами и страницами в Jira и Confluence |
| Google Maps      | Интеграция карт, мест, маршрутов и геокодирования  |

<div id="community-skills">
  ## Навыки сообщества
</div>

Помимо навыков от Replit и партнёров, сообщество публикует навыки, которые вы можете установить. Найти их можно на [skills.sh](https://skills.sh), а чтобы создать собственный навык, изучите [спецификацию Agent Skills](https://agentskills.io/specification).
