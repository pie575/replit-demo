---
title: "部署类型"
description: "比较 Autoscale、Static、Reserved VM 和 Scheduled 四种部署方式，了解为已发布的应用分别在何时选择哪一种。"
---

部署类型是指 Replit 用来发布你的应用所采用的技术。你可以在 Publishing 工具的 **Adjust settings** 中，通过 **Deployment type** 下拉菜单进行选择。**Autoscale** 是默认且推荐的选项，大多数创作者无需更改。

<div id="comparar-tipos-de-deployment">
  ## 比较部署类型
</div>

| 类型              | 适用场景               | 工作方式                | 计费方式         |
| :-------------- | :----------------- | :------------------ | :----------- |
| **Autoscale**   | 流量波动的 Web 应用和 API  | 繁忙时增加服务器，空闲时缩容至零    | 仅在处理请求期间计费   |
| **Static**      | 落地页、作品集、文档站点       | 通过带缓存的云服务器提供文件，无需后端 | 仅按站点传输的数据量计费 |
| **Reserved VM** | 机器人、后台任务、常驻运行的 API | 一台永不休眠的专用服务器        | 固定月费         |
| **Scheduled**   | 备份、通知等周期性任务        | 按计划执行一条命令，随后停止      | 按每次执行的时长计费   |

<div id="autoscale">
  ## Autoscale
</div>

Autoscale Deployments 运行在会随应用流量自动扩缩容的服务器上。应用繁忙时，Replit 会增加服务器来应对负载；应用空闲时，服务器数量会逐步降至零，让你无需为低谷期付费。

适用场景：

* 流量波动较大的 Web 应用，例如电商网站
* API 和各类服务

相关配置位于 **Adjust settings**：[机器性能和最大服务器数量](/zh/pt/features/publishing/machine-configuration)。

<div id="static">
  ## Static
</div>

Static Deployments 会将应用的文件 (如 HTML、CSS 和 JavaScript) 托管在带缓存的云服务器上，从而快速且经济地分发内容，不涉及后端服务器。

适用于：

* 营销落地页
* 作品集网站
* 产品和 API 文档站点

<Note>
  Static Deployments 不支持使用 Agent 创建的 Replit App。Agent 构建的是需要后端服务器的 full-stack 应用，这类情况请改用 Autoscale 或 Reserved VM。
</Note>

配置项包括对外提供服务的公共目录，以及可选的构建命令。关于响应头、URL 重写和重定向，请参阅 [Static 高级配置](/zh/pt/features/deployment-customization/static-deployments-advanced)。

<div id="reserved-vm">
  ## Reserved VM
</div>

Reserved VM Deployments 在一台永不休眠的专用虚拟机上运行你的应用，性能稳定一致，每月费用固定且可预测。

适用于：

* 内存占用较高的后台任务
* 需要保持长连接的聊天机器人
* 始终在线的 API 服务器

配置项包括[机器性能](/zh/pt/features/publishing/machine-configuration)、构建与运行命令、端口映射，以及应用以 Web 服务器还是后台 worker 的方式运行。

<div id="scheduled">
  ## Scheduled
</div>

Scheduled Deployments 会按照设定的计划在你的应用环境中执行某个命令，执行完毕后即停止运行，直到下次触发。你可以用日常语言描述执行计划，比如“每个工作日上午 9 点”，Replit 会自动将其转换为对应的调度计划。如果某次执行失败，你会收到告警。

适用场景：

* 状态检查与健康报告
* 发送通知
* 启动备份

配置项包括执行计划、任务超时时间以及构建和运行命令。Scheduled Deployments 不提供网页服务，因此没有公开 URL。
