<div id="web-view-mobile-support">
  ### Web view 移动端支持
</div>

我们新增了将 Web view 调整为常见移动设备屏幕尺寸的功能。此外，我们还在 URL 下拉菜单和网络面板中添加了二维码，方便您在移动设备上测试。

提醒一下：即使您仍在构建项目，项目也可通过互联网访问。只需使用任意设备访问开发 URL。

<div id="dns-record-format-update">
  ### DNS 记录格式更新
</div>

我们已调整自定义域名 DNS 记录的格式，使其符合行业标准。

这将让自定义域名的配置更加轻松。

<div id="flask-deployment-upgrade">
  ### Flask 部署升级
</div>

gunicorn 现已成为 Flask stack 模式部署的默认 Web 服务器。

与之前的 Flask 部署相比，性能提升了 40 倍。

<div id="assistant-inline-shell-commands">
