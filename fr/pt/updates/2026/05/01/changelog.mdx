<div id="monitoramento-de-apps-do-replit-mantm-seus-apps-publicados-sob-vigilncia">
  ### Le Monitoring des apps Replit veille sur vos apps publiées
</div>

Vous pouvez désormais activer le **Monitoring des apps** pour toute Replit App publiée afin de bénéficier d’une vérification de l’uptime en temps réel, d’une barre d’uptime colorée dans votre vue **Publication** et dans l’onglet **Analyses**, ainsi que d’un e-mail lorsque votre app est hors ligne. Le Monitoring des apps est disponible avec tous les forfaits payants et fonctionne avec tous les types de déploiement, à l’exception des déploiements programmés. Si votre app rencontre un problème, sélectionnez **Examiner une indisponibilité récente avec Agent** pour lancer une tâche en arrière-plan qui analyse les périodes concernées, examine les logs et le code, puis propose une correction.

<div id="crie-slide-decks-completos-com-o-agent">
  ### Créez des Slide Decks complets avec Agent
</div>

Décrivez la présentation que vous souhaitez — pitch deck, présentation du produit, présentation commerciale ou point d’équipe — et Agent crée une présentation soignée incluant mise en page, texte et visuels. Vous pouvez affiner les diapositives dans le Chat, modifier le texte et le style avec l’Éditeur visuel, présenter depuis votre navigateur, publier la présentation via une URL active ou l’exporter au format PPTX, Google Slides ou PDF.
