以下回答涵盖套餐与定价相关内容。有关各套餐的详细信息，请参阅 [Starter](/zh/ja/billing/plans/starter-plan)、[Core](/zh/ja/billing/plans/replit-core)、[Pro](/zh/ja/billing/plans/replit-pro)。如需了解最新价格，请查看[定价页面](https://replit.com/pricing)。

<AccordionGroup>
  <Accordion title="Agent 使用量如何计费？为什么 Plan 模式也会收费？">
    Free Mode 是 Core 和 Pro 订阅包含的一项权益，可在额度范围内免费使用 Agent。额度每 5 小时重置一次，并设有每周上限。你可以在**设置 → 使用情况**中查看用量。这不是独立的免费套餐；Starter 层级仍沿用现有上限。

    付费模式和已确认的付费工作会根据请求的复杂程度采用[按工作量计费](/zh/ja/billing/ai-billing)。在付费流程中，即使 Plan 模式不修改代码，也可能进行需要付费的推理。Replit 会在开始付费操作前请求确认。

    日常任务请从 [Free Mode](/zh/ja/features/agent/agent-modes) 开始。如需更强的能力，请选择 [Power 模式](/zh/ja/features/agent/agent-modes)。你还可以使用 [Plan 模式](/zh/ja/features/agent/plan-mode) 确定工作范围，并在[管理支出](/zh/ja/billing/managing-spend)中设置用量限制和预算。要查看账单明细，请打开**设置 → 账户使用情况**，然后选择**查看历史账单**。
  </Accordion>

  <Accordion title="各个套餐（Starter、Core、Pro）包含哪些内容？">
    每种方案面向构建过程中的不同阶段：

    * **Starter** 免费，包含每日 Agent 使用额度、有限的月度云端积分、基础 Agent 访问权限，以及 1 个已发布的应用。请参阅 [Starter 方案](/zh/ja/billing/plans/starter-plan)。
    * **Core** 包含每月 {CoreCredits} 积分、含 Plan 模式与 Build 模式的完整 Agent、最多 5 名协作者、无限量已发布应用，以及 7 天的数据库恢复窗口。请参阅 [Core 方案](/zh/ja/billing/plans/replit-core)。
    * **Pro** ({ProPlanPrice}/月) 额外提供 Turbo 模式、最多 15 名共享积分池的构建者、阶梯式积分，以及 28 天的数据库恢复窗口。未使用的积分可结转{ProCreditRolloverPeriod}。请参阅 [Pro 方案](/zh/ja/billing/plans/replit-pro)。

    如需并排比较各方案并查看当前价格，请访问[价格页面](https://replit.com/pricing)。
  </Accordion>

  <Accordion title="Replit 是否为学生和教育机构提供折扣？">
    Replit 为学生和教育工作者提供教育计划。有关当前资格要求、折扣内容和申请方式，请访问 [replit.com/education](https://replit.com/education)。

    <Note>具体折扣比例和资格标准由教育计划负责管理，可能会有所变更—请以教育页面为准。</Note>
  </Accordion>

  <Accordion title="年度计费如何运作？我能节省多少费用？">
    按年计费需要一次性预付一年费用，但折算下来的月费更低。[Core](/zh/ja/billing/plans/replit-core) 为 {CoreAnnualPrice}/年。如需切换，请在订阅或更改套餐时选择年付选项。其他套餐当前的优惠幅度，请查看[价格页面](https://replit.com/pricing)。
  </Accordion>

  <Accordion title="未使用的月度积分会结转到下个月吗？">
    这取决于您的套餐。Core 的积分会在每个计费周期开始时重置，不可结转。Pro 则包含[积分结转](/zh/ja/billing/plans/replit-pro)功能，未使用的积分在过期前可结转 {ProCreditRolloverPeriod}。

    如果余额高于月度配额，多出的部分可能是推荐积分或促销积分，它们各自有不同的有效期。
  </Accordion>

  <Accordion title="如何购买额外积分（积分包）？">
    积分包可在每月配额的基础上额外增加积分，且积分包越大，折扣越多：

    <CreditPackTable />

    打开**设置 → 账户使用情况**，选择购买积分包的选项。积分可用于 Agent 使用、部署、存储以及其他按用量计费的服务。更多详情请参阅[管理支出](/zh/ja/billing/managing-spend#purchase-credit-packs)。

    如果你是通过 App Store 订阅的，请先为账户添加网页支付方式。
  </Accordion>

  <Accordion title="Core 或 Pro 有免费试用吗？">
    Replit 不提供付费套餐的限时免费试用，但你可以通过以下方式先行体验 Replit：

    * [Starter 套餐](/zh/ja/billing/plans/starter-plan)永久免费，没有时间限制。
    * [教育项目](https://replit.com/education)为符合条件的学生提供折扣使用权限。

    如需了解当前订阅的退款条款，请[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="如果我在计费周期中途升级，费用将如何按比例计算？">
    如果您在计费周期中途更改套餐，Replit 会将当前套餐未使用部分的费用抵扣新套餐的费用。完成更改前，账单确认页面会显示准确的按比例计算金额，您可在收费前确认。
  </Accordion>
</AccordionGroup>
