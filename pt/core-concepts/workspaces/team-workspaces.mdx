## Workspaces pessoais vs. de equipe

Um **workspace** é a estrutura que contém seus apps, membros, configurações e cobrança. O Replit tem dois tipos:

* Workspace pessoal
* Workspace de equipe

Veja a seguir a diferença entre workspaces Pessoais e de Equipe:

|                              | Workspace pessoal                                 | Workspace de equipe                                    |
| ---------------------------- | ------------------------------------------------- | ------------------------------------------------------ |
| **Funções**                  | Administrador, convidados no nível do projeto     | Administrador, membros, convidados no nível do projeto |
| **Modelo de acesso**         | Você convida convidados para projetos individuais | Os membros têm acesso a todos os projetos do workspace |
| **Cobrança**                 | Sua conta                                         | Créditos compartilhados da conta do administrador      |
| **Gerenciamento de membros** | Por projeto (links de acesso)                     | Centralizado nas configurações do workspace            |

O **workspace pessoal** é ideal quando você trabalha sozinho ou compartilha projetos individuais com outras pessoas. Você é o único administrador e outras pessoas só podem acessar os projetos específicos para os quais você as convida como convidados no nível do projeto.

O **workspace de equipe** é ideal quando você está construindo com um grupo regular — uma equipe de startup, uma turma ou um projeto de cliente com vários colaboradores. Os membros têm acesso a todos os projetos do workspace, então você não precisa convidá-los um a um para cada projeto. Os membros são gerenciados de forma centralizada em **Configurações**.

### Quando convidar para o workspace ou para um projeto

| Cenário                                              | O que fazer                                              |
| ---------------------------------------------------- | -------------------------------------------------------- |
| Colaborador contínuo que precisa de acesso a tudo    | Convidar para o workspace                                |
| Contratado ou convidado que só precisa de um projeto | [Convidar para o projeto](/pt/replitai/invite-teammates) |
| Novo membro da equipe ingressando na empresa         | Convidar para o workspace                                |
| Amigo ajudando a depurar um app específico           | [Convidar para o projeto](/pt/replitai/invite-teammates) |

## Criar um workspace de equipe

  <video autoPlay muted loop playsInline>

<Steps>
  <Step title="Abrir o seletor de workspace">
    Na página inicial, clique no nome do seu workspace no canto superior esquerdo.
  </Step>

  <Step title="Criar um novo workspace">
    Selecione **Criar workspace** e escolha um nome para o seu workspace de equipe.
  </Step>

  <Step title="Convidar membros">
    Insira um ou mais endereços de e-mail (separados por vírgula) no campo de convite. Os convidados receberão um convite e terão acesso a todos os projetos do workspace assim que aceitarem.
  </Step>
</Steps>

## Gerenciar membros

Se você não convidou membros durante a configuração ou precisa adicionar mais posteriormente, vá para **Configurações** no seu workspace de equipe e convide membros por e-mail ou nome de usuário do Replit.

<Frame>
  <video autoPlay muted loop playsInline>
    <source src="/assets/mirror/add_team_to_workspace_compressed-41d8163607d2.mp4" type="video/mp4" />
  </video>
</Frame>

Na página de **Configurações** você também pode:

* **Remover membros** para revogar o acesso deles a todos os projetos do workspace
* **Transferir apps** de workspaces pessoais para o workspace de equipe — veja [Transferir app para equipes](/pt/teams/identity-and-access-management/transfer-app-to-teams)

Para gerenciamento avançado de identidade, controle de acesso baseado em funções e permissões de grupo, veja [Teams](/pt/category/teams).
