<div id="claude-opus-45">
  ### Prise en charge de Claude Opus 4.5
</div>

Claude Opus 4.5 est désormais disponible dans les intégrations IA, vous donnant accès aux dernières fonctionnalités d’IA d’Anthropic, optimisées pour le codage et les agents.

<div id="replit">
  ### Bouton « Ouvrir dans Replit » (bêta)
</div>

Vous pouvez désormais travailler directement sur des tickets Linear dans Replit grâce au nouveau bouton « Ouvrir dans Replit ». Cette fonctionnalité bêta doit être activée dans les préférences et ajoute automatiquement les détails de l’issue au prompt. L’équipe collabore avec Linear afin d’améliorer l’intégration.

<div id="agentsql">
  ### Accès d’Agent aux bases de données SQL de production
</div>

Agent peut désormais consulter et interroger vos bases de données SQL de production en lecture seule, ce qui vous permet de travailler sur des données de production réelles sans risquer de les modifier accidentellement.

<div id="section-3">
  ### Fiabilité des connexions améliorée
</div>

Plusieurs améliorations de l’expérience des intégrations :

* Un processus de reconnexion en arrière-plan amélioré réduit le risque d’expiration des jetons de connexion
* Une indication claire lorsqu’une connexion se trouve dans un état anormal ou d’erreur
* La possibilité de reconnecter directement une intégration depuis l’état d’erreur

<div id="section-4">
  ### Budgets par utilisateur et par groupe
</div>

La gestion des budgets est désormais disponible pour tous les clients Enterprise :

* Les administrateurs des équipes Enterprise peuvent définir un budget d’utilisation par défaut pour tous les membres
* Les administrateurs peuvent définir des budgets pour des groupes spécifiques (par exemple, administrateurs/membres et groupes personnalisés)
* Bientôt disponible : les administrateurs pourront définir des budgets personnalisés pour chaque utilisateur
