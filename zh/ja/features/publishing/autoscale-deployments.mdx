title: "自动扩缩部署"
description: "了解自动扩缩部署如何根据应用流量自动调整容量。"
---

自动扩缩部署运行在可自动扩容和缩容的云计算资源上，能够高效应对 Replit App 的网络流量与工作负载。当应用繁忙时，自动扩缩会增加服务器来分担负载；当应用处于空闲状态时，服务器数量会缩减至零，从而节省成本。

自动扩缩部署最适合以下场景：

* 工作负载和流量波动较大的 Web 应用，例如电商网站
* API 与各类服务

<div id="section">
  ## 功能
</div>

自动扩缩部署包含以下功能：

* **自动资源扩缩**：根据流量模式自动调整资源，优化成本。
* **自定义域名**：配置自定义域名，或使用 `<app-name>.replit.app` URL 访问你的应用。
* **可配置上限**：设置已发布应用可扩展到的最大实例数。
* **灵活的机器性能**：选择符合应用需求的 CPU 和内存配置。
* **监控**：查看日志并监控已发布应用的状态。

<div id="section-2">
  ## 使用方法
</div>

自动扩缩部署可通过 Publishing 项目编辑器工具访问。

<Accordion title="如何访问自动扩缩部署">
  从左侧的**工具栏**：

  1. 选择 <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="All tools 图标" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**，显示项目编辑器工具列表。
  2. 选择 <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Publishing 图标" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publishing**。
  3. 选择 **Autoscale** 选项，然后选择 **Set up your published app**。

  从**搜索栏**：

  1. 选择顶部的 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 放大镜图标，打开搜索工具
  2. 输入“Publishing”搜索该工具，然后从结果中选择。
  3. 选择 **Autoscale** 选项，然后选择 **Set up your published app**。
</Accordion>

<div id="section-3">
  ## 机器性能
</div>

选择 **Edit** 可查看并设置机器性能选项。使用滑块为每个已发布的应用服务器实例选择 CPU 和 RAM 配置。

在 **Total per machine** 行中可查看该配置的**计算单元**成本。
计算单元是一种云计算资源计量单位，取决于机器的内存和 CPU 配置。

如需了解如何根据计算单元计算成本，请参阅[计算单元](/zh/ja/billing/about-usage-based-billing#2-compute-units)。

<div id="section-4">
  ## 最大机器数
</div>

使用滑块调整最大机器数。该数值是自动扩缩功能在判定应用繁忙时可分配的服务器实例上限。

下方一行显示按以下公式计算得出的等效计算单元：

`机器数 × 每台机器的计算单元`
