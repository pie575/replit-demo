模型上下文协议 (MCP) 是一项开放标准，用于将 AI 产品连接到工具和数据源。虽然它不同于 Replit 的原生集成，但能扩展你在 Conversation 中工作时可使用的工具。

<div id="section">
  ## 选择连接方式
</div>

* **将 Replit 连接到外部工具：** 添加精选或自定义的 MCP 服务器后，Replit 即可使用这些服务器提供的工具。请仅连接可信的服务器。
* **通过 MCP 客户端使用 Replit：** 将兼容的客户端连接到 Replit MCP Server，然后通过该客户端创建、搜索、查看和更新 Replit 应用。

MCP 与原生集成和 [Skills](/zh/ja/chat/agent-skills) 不同。集成可让你连接到受支持的服务。Skills 提供可复用的指令和补充材料。MCP 可通过该协议扩展可用工具。
