<div id="follow-up-task-suggestions">
  ## Follow-up 작업 제안
</div>

task를 적용하고 나면 Agent가 project context를 검토해 다음에 만들면 좋을 **Follow-up 작업**를 제안합니다. **Suggested next tasks** 대화 상자에 가장 추천하는 항목이 인라인으로 표시되므로, main thread를 벗어나지 않고 그대로 작업을 이어갈 수 있습니다.

<Frame>
  <img src="/assets/mirror/follow-up-tasks-dialog-c1660cec2d1d.png" alt="Follow-up 작업와 Start 버튼, task board에서 더 많은 task를 볼 수 있는 링크가 표시된 Suggested next tasks 대화 상자" width="495" height="290" data-path="images/agent/follow-up-tasks-dialog.png" />
</Frame>

follow-up 제안에는 다음이 포함될 수 있습니다.

* **새로 만들 기능**: 방금 출시한 기능과 자연스럽게 어울리는 기능
* **성능 개선**: Agent가 task를 진행하면서 발견한 최적화 항목
* **사용자 경험 향상**: 기능의 완성도를 높이는 마무리 작업

제안 항목에서 **Start**를 선택하면 백그라운드로 전송되고, **View plan**을 선택하면 제안된 작업 내용을 먼저 확인할 수 있습니다. 모든 제안을 보려면 **View more in the task board**를 선택하세요. 제안된 Follow-up 작업은 **Drafts** 열의 **Suggested** 아래에 표시됩니다.

<Frame>
  <img src="/assets/mirror/follow-up-tasks-kanban-21087e0210b6.png" alt="Drafts 열의 Suggested 아래에 여러 Follow-up 작업 제안이 표시된 task board" width="980" height="627" data-path="images/agent/follow-up-tasks-kanban.png" />
</Frame>

**Suggested next tasks** 대화 상자를 닫으면 제안이 취소됩니다. main 버전에 이미 제안된 plan이 대기 중일 때는 Agent가 이 대화 상자를 표시하지 않으므로, 두 안내가 한꺼번에 주의를 분산시키지 않습니다.

<div id="managing-many-suggestions-at-once">
  ## 여러 follow-up 제안 한 번에 관리하기
</div>

follow-up 제안가 많은 project에서는 task board를 열고 **Drafts** 열에서 **Edit**을 선택하세요. 편집 모드에서는 제안된 각 task에 체크박스가 표시됩니다. 원하는 task를 선택한 다음 **Start** 또는 **Cancel**을 눌러 선택한 모든 task에 해당 동작을 적용하세요. 편집 모드를 종료하려면 **Done**을 선택하세요.
