<div id="shopify">
  ### Продавайте физические товары через Shopify
</div>

Теперь вы можете создавать интернет-магазины для продажи физических товаров. Попросите Agent создать магазин — он создаст магазин Shopify, добавит товары и настроит корзину и оформление заказа. Agent предоставит ссылку, по которой можно оформить магазин. После оформления подписки Shopify и подключения платежей магазин будет запущен.

<div id="microsoft-fabricapp">
  ### Создание дата-App на Microsoft Fabric
</div>

Теперь в Replit можно создавать дата-App на базе ИИ и публиковать их напрямую в Microsoft Fabric. Начните с шаблона Microsoft Fabric, подключите семантическую модель Power BI и попросите Agent собрать дашборды и внутренние инструменты на основе управляемых корпоративных данных — при этом аутентификация и политики доступа остаются в Fabric.

<div id="section-3">
  ## Рабочее пространство
</div>

<div id="dns">
  ### Пользовательские домены настраивают DNS сами
</div>

Подключить собственное доменное имя стало значительно проще. При привязке домена Replit сам настраивает нужные DNS-записи через Entri, так что вручную копировать их в панель регистратора больше не придётся. Выберите домен, подтвердите его — остальное Replit возьмёт на себя.

Подробнее о [пользовательских доменах](/ru/ja/features/publishing/custom-domains).

  ## Agent

<div id="seo-agent">
  ### Повышайте позиции в поиске с SEO Agent
</div>

SEO Agent проверяет опубликованное App и выявляет проблемы, которые мешают поисковым системам и ИИ-инструментам находить его. Для каждой обнаруженной проблемы предлагается исправление, которое можно просмотреть и применить одним щелчком. Откройте панель **Growth** проекта и запустите сканирование.

<div id="section-4">
  ## Оплата
</div>

<div id="stripe">
  ### Использование Stripe в совместных рабочих пространствах
</div>

Теперь Stripe работает в совместных рабочих пространствах, поэтому вся команда может создавать, тестировать и монетизировать одно и то же App. Все участники рабочего пространства могут работать с подключённым аккаунтом Stripe, вместо того чтобы настраивать приём платежей в одиночку.

Подробнее об [оплате через Stripe](/ru/ja/features/monetization/stripe-payments).
