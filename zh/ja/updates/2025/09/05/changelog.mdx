<div id="general-agent">
  ### General Agent
</div>

<Frame>
  <img src="/assets/mirror/general-agent-240ff289e711.png" alt="General Agent 主视觉插图" width="1040" height="572" data-path="images/replitai/general-agent.png" />
</Frame>

Replit Agent 现已支持在 NixOS 上运行的任意语言和框架的代码库！过去 Agent 仅能用于特定模板，如今它可以协助处理 Developer Frameworks、GitHub 导入以及各类自定义项目配置。这次大幅扩展为 Enterprise 用户和高级用户的工作流带来了完整的 AI 编程辅助。

点击[此处](/zh/core-concepts/agent/general-agent)了解 General Agent 的更多信息。

<div id="section-3">
  ### 规划模式
</div>

<Frame>
  <img src="/assets/mirror/plan-mode-overview-8077807c63b9.png" alt="规划模式的 Agent 聊天界面" width="916" height="362" data-path="images/replitai/plan-mode-overview.png" />
</Frame>

规划模式提供了一种与 Replit Agent 交互的新方式，适合提问、头脑风暴和规划工作。您可以使用 Agent 为后续工作创建待办事项列表，并在构建模式中执行耗时较长的任务。

有关规划模式的更多信息，请参阅[此处](/zh/core-concepts/agent/plan-mode)。

<div id="enterprise">
  ## Enterprise
</div>

<div id="gcp">
  ### GCP Marketplace 集成
</div>

Enterprise 客户现在可以直接从 Google Cloud Platform Marketplace 购买 Replit，并使用现有的 GCP 额度支付。这简化了采购流程，让拥有 GCP 预算的组织更容易将 Replit 纳入自己的开发工作流。
