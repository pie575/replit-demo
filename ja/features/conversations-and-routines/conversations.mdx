会話は、質問したり、情報を調べたり、ルーティンを実行したり、成果を説明したりするための単一のスレッドです。Replit のすべてのタスクは会話から始まります。

<Note>
  会話はプライベートです。ワークスペース内であなただけがアクセスできます。コラボレーションが必要な場合は、Replit にプロジェクトの作成を依頼してください。
</Note>

## やりたいことから始める

### 質問する

例えば、Replit に今週の Slack のアクティビティを要約し、返信が必要なメッセージにフラグを立てるよう依頼します。

## 会話とプロジェクト

会話は、質問、調査、ルーティンのための単一のスレッドです。[プロジェクト](/ja/features/projects-and-artifacts/projects)は、複数のアーティファクトを含む本格的な構築とデザイン作業のための、より深いワークスペースです。

会話から始めましょう。作業が本格的な構築やデザインに発展した場合、会話をプロジェクトに変えることができます。

サイドバーでは、会話にはチャットバブルアイコン、プロジェクトには4つの四角形が並んだグリッドアイコンが使われます。

<Frame>
  <img src="/assets/mirror/conversation-and-project-icons-025a17613daa.png" alt="4つの四角形のグリッドアイコンを持つプロジェクトと、チャットバブルアイコンを持つ会話を示す Replit サイドバー" width="466" height="290" data-path="images/chat/conversation-and-project-icons.png" />
</Frame>

| 領域          | 会話          | プロジェクト                                       |
| ----------- | ----------- | -------------------------------------------- |
| 最適な用途       | 質問、調査、ルーティン | アプリ、スライド、ダッシュボード、複数のアーティファクトなど、より深い構築とデザイン作業 |
| バックグラウンドタスク | **利用不可**    | **並行して実行可能**                                 |
| ルーティン       | **利用可能**    | **利用不可**                                     |
| インテグレーション   | 利用可能        | 利用可能                                         |
| 構造          | 単一のスレッド     | 複数のアーティファクトを持つプロジェクトワークスペース                  |
