export const ProCreditRolloverPeriod = 'two months';

Replit AI 功能采用按用量计费的方式，根据你构建的内容以及 AI 工具的使用量收费。这样一来，你只需为从 Agent 获得的价值付费。

<div id="section">
  ## 开始使用
</div>

**所有订阅用户**均可获得一次性的免费 Agent 检查点。

额外的月度积分会自动用于 AI 使用：

* **Core 订阅用户**：月度积分 (请参阅[价格](https://replit.com/pricing))
* **Pro 订阅用户**：分级月度积分，可在 {ProCreditRolloverPeriod} 内结转。详见 [Replit Pro](/zh/ja/billing/plans/replit-pro)。

这些积分可用于 Agent，以及已发布的应用、存储、数据库等其他 Replit 云服务。你可以选择 [Lite、Economy 或 Power](/zh/ja/features/agent/agent-modes)，以在速度、成本或功能之间取得最佳平衡。

  ## Agent 计费
</div>

Free Mode 面向 Core 和 Pro 订阅者，在其额度范围内免费提供日常 Agent 工作。有偿模式和已确认的付费工作采用按工作量计费的方式，费用取决于请求的复杂程度。Replit 会在开始付费操作前要求你确认。

<div id="section-2">
  ### 按工作量计费的方式
</div>

在「ビルドモード」下与 Agent 对话时，系统会创建 **检查点**，记录针对该请求已完成的工作：

* **简单请求** (例如修复缺陷或小幅改动) 的成本通常低于复杂构建
* **复杂构建** (例如完整功能或集成) 会汇总为一个 检查点，成本可能高于简单请求，以体现其中投入的总工作量
* **每个请求只生成一个 检查点**，不再产生中间 检查点，减少计费噪音
* **计费透明**，让你清楚了解每项已完成任务的费用构成

<Info>
  当 Agent 完成针对某个请求的工作，并将所需功能实现到代码中时，就会生成 检查点。
</Info>

在付费方案中，Plan 模式即使不修改代码，也可能执行需要计费的推理。

有关 检查点 记录哪些内容及其工作原理的详细信息，请参阅 [检查点 与回滚](/zh/ja/features/version-control/checkpoints-and-rollbacks)。

<div id="agent-3">
  ### Agent 服务计费
</div>

部分 Agent 功能会在后台调用付费的第三方 API (如 Claude、ChatGPT、Nano Banana / Gemini 等) 。Agent 会自动处理这些集成——无需 API 密钥，也无需任何配置。费用按提供商公开的 API 费率计算，并从 Replit 积分中扣除。这些费用会与其他用量一并显示在[用量仪表板](/zh/ja/billing/managing-spend)中。

如需了解示例应用的成本构成，可查看这个简单的[交互式演示](https://agent-pricing.replit.app/)。

<div id="section-3">
  ### 用量追踪
</div>

你可以实时监控 Agent 的支出：

1. **Agent 标签页**：将鼠标悬停在用量图标上，即可查看各个检查点的费用
2. **用量仪表板**：查看当前周期的详细账单信息
3. **设置**：在 **账户** → **账单** 中设置提醒和预算，以管理支出

<Tip>
  用量数据最多可能需要 30 分钟才会显示在用量仪表板中。
</Tip>

<div id="section-4">
  ## 管理支出
</div>

使用 Replit 内置的预算工具，掌控 AI 支出：

* **用量提醒**：达到支出阈值时收到通知
* **预算上限**：设置硬性上限，避免产生意外费用
* **实时跟踪**：在构建过程中随时监控成本
* **积分包**：批量购买额外积分可享折扣。详情请参阅[管理支出](/zh/ja/billing/managing-spend)。

<div id="section-5">
  ## 后续步骤
</div>

准备好开始用 AI 构建了吗？为了充分利用积分：

* **先试用 Agent**：使用免费检查点探索 Agent 的功能
* **从小处着手**：通过简单的请求了解按工作量计费的方式
* **使用 Lite 模式**：借助 [Lite 模式](/zh/ja/features/agent/agent-modes)进行快速、精准的编辑
* **设置提醒**：在积分超额前设置消费提醒
