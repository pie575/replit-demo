팀이 일관되고 안전한 방식으로 통합을 사용할 수 있도록 커넥터를 관리할 수 있습니다. 사용 가능한 기능은 플랜에 따라 다릅니다:

* **Core 및 Pro**: 커넥터 관리는 **협업 워크스페이스**에서 사용 가능합니다. 계정 관리자가 해당 워크스페이스의 연결을 설정하고 관리하며, 빌더는 해당 워크스페이스 내 앱에서 사용할 수 있습니다.
* **Enterprise**: 맞춤형 OAuth 클라이언트, API 키 접근 제어, 자체 키 사용 등 고급 제어 기능을 갖춘 조직 전체 커넥터 관리.

## 주요 기능

* **중앙화된 관리**: 관리자가 서비스를 한 번 설정하면 빌더가 해당 워크스페이스의 앱 전반에서 사용.
* **가시성 및 감사**: 어떤 앱과 구성원이 어떤 서비스를 사용하는지 확인.
* **앱별 동의 및 취소**: 코드 변경 없이 접근 취소 또는 교체.

**Enterprise 전용:**

* **역할 기반 접근 제어**: API 키에 대한 범위 지정, 최소 권한 권한 및 접근 제어.
* **자체 OAuth 사용**: 맞춤형 범위를 가진 조직 소유 OAuth 클라이언트 사용.
* **자체 OpenAI 키 사용**: Replit 기본값 대신 자체 OpenAI API 키 사용.

## 작동 방식

<Steps>
  <Step title="관리자가 서비스를 설정합니다">
    관리자가 자격 증명을 사용하여 서비스를 한 번 설정합니다.
  </Step>

  <Step title="관리자가 접근을 승인합니다">
    관리자가 어떤 그룹이 커넥터를 사용할 수 있는지 승인(Enterprise)하거나 협업 워크스페이스에서 사용 가능하게 합니다(Core/Pro).
  </Step>

  <Step title="빌더가 커넥터를 사용합니다">
    구성원이 워크스페이스 또는 조직 내 앱에서 Agent에게 요청하여 해당 서비스로 구축합니다.
  </Step>

  <Step title="관리자가 사용량을 모니터링합니다">
    관리자는 어떤 구성원과 앱이 어떤 서비스를 사용하는지 모니터링할 수 있습니다.
  </Step>
</Steps>

## 보안 및 거버넌스

* 자격 증명과 토큰은 개별 앱에 저장되지 않고 플랫폼이 관리합니다.
* 코드 변경 없이 중앙화된 취소 및 교체.
* Enterprise: 최소 권한 권한과 선택적 맞춤형 OAuth 구성을 통한 범위 지정 접근.

## 설정 및 관리

### 새 커넥터 활성화

<Steps>
  <Step title="통합으로 이동">
    협업 워크스페이스(Core/Pro) 또는 조직 홈(Enterprise)에서 **통합** 페이지를 엽니다.
  </Step>

  <Step title="새 커넥터 활성화">
    오른쪽 상단에서 **새 커넥터 활성화**를 선택합니다.
  </Step>

  <Step title="서비스 선택">
    활성화할 서비스를 선택합니다(예: Notion, GitHub, Google, Outlook, Dropbox, Salesforce).
  </Step>

  <Step title="커넥터 구성">
    기본 구성을 사용하여 커넥터를 활성화합니다. **Enterprise** 전용으로 맞춤형 OAuth 커넥터를 만들 수 있습니다(예: Drive 범위 `.../auth/drive.file`, `.../auth/drive.install`).
  </Step>

  <Step title="제출">
    **제출**을 선택합니다.
  </Step>
</Steps>

### 접근 구성 (Enterprise)

1. 커넥터 활성화 후 **관리**를 선택합니다.
2. 필요에 따라 특정 그룹에 접근 권한을 부여합니다.

### 커넥터 수정

* 커넥터 활성화 후 **관리**를 선택합니다.
* 커넥터를 삭제하면 해당 워크스페이스(Core/Pro) 또는 조직(Enterprise)의 모든 빌더에게서 제거됩니다.
* Enterprise에서는 맞춤형 OAuth 커넥터의 범위를 편집할 수 있습니다.

### 자체 OpenAI 키 사용 (Enterprise)

Enterprise 고객은 커넥터를 사용하여 Replit 기본 AI 인프라 대신 자체 OpenAI API 키를 가져올 수 있습니다. 이를 통해 기존 OpenAI 계약을 활용하고 자체 계정을 통해 AI 사용량을 관리할 수 있습니다.
