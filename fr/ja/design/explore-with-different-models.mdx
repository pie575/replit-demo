Les suggestions permettent d’explorer différentes pistes avec le même designer, mais changer de modèle revient à changer de designer. Chaque modèle a sa propre sensibilité en matière de design et ses propres atouts en front-end. Ainsi, même avec le même brief, un autre modèle peut produire un résultat entièrement nouveau.

<div id="section">
  ## Changer de modèle
</div>

Ouvrez le sélecteur de mode du composeur de chat (il affiche le mode actuel, par exemple **Power**), sélectionnez **Primary model**, puis choisissez un modèle dans la liste.

Modèles actuellement disponibles :

* **Claude Fable 5** (recommandé)
* **Claude Opus 5**
* **GPT-5.6 Sol**
* **Kimi K3**

<Note>
  La sélection de modèles évolue à mesure que de nouveaux modèles sont publiés. Consultez le menu dans l&#39;interface pour voir ceux qui sont actuellement disponibles pour votre compte.
</Note>

Cette même fenêtre contextuelle propose deux autres réglages :

* **Mode** (Lite, Economy, Power) : équilibre entre vitesse, coût et performances. Power utilise des modèles performants pour le travail de design et est idéal pour les designs complexes et les modifications visuelles détaillées. Consultez les [modes Agent](/fr/ja/features/agent/agent-modes) pour en savoir plus.
* **Effort** : détermine le niveau de raisonnement que le modèle consacre à chaque réponse, de Low (le plus rapide) à Max. Chaque modèle affiche un réglage recommandé.

<div id="section-2">
  ## Explorer différents modèles
</div>

Changer de modèle constitue un autre axe d’exploration, en complément des [suggestions](/fr/ja/design/explore-suggestions) :

* **Même brief, designers différents** : générez une frame, changez de modèle, puis renvoyez le même prompt. Les deux pistes restent sous forme de frames sur le Canvas, ce qui vous permet de les comparer côte à côte.
* **Choisissez le modèle adapté à votre travail** : utilisez le modèle recommandé pour la plupart des tâches, puis changez-en lorsque votre Design requiert une sensibilité différente ou que vous souhaitez un second avis sur une piste qui vous laisse hésiter.
* **Changez à tout moment** : le modèle s’applique au message suivant. Vous pouvez donc le modifier en cours de projet sans perdre ce qui se trouve sur le Canvas.
