Skills는 Agent에 새로운 기능을 가르칩니다 — 선호하는 패턴, 라이브러리 세부 사항, 디자인 시스템 규칙, 또는 이미 해결한 문제의 해법. 메시지에 첨부하거나, 프로젝트에 설치하거나, 새 프로젝트의 시작점으로 선택하세요.

## 채팅에서 skill 사용하기

Skills를 가장 빠르게 사용하는 방법은 단일 메시지에 첨부하는 것입니다 — 설치가 필요 없습니다.

<Frame>
  <img src="/assets/mirror/agent-skills-picker-ee4058454475.png" alt="채팅 입력 옆 + 버튼에서 열린 Skill 선택기, Ad Creative, AI Recruiter, AI SDR, AI Secretary가 있는 Skills 목록 표시" width="723" height="529" data-path="images/replitai/agent-skills-picker.png" />
</Frame>

<Steps>
  <Step title="Skill 선택기 열기">
    채팅 입력 옆 **+** 버튼을 클릭하고 **Use a skill**을 선택하세요.
  </Step>

  <Step title="Skill 탐색 및 선택">
    Business & finance, Creative, Research & analysis 등 카테고리별로 Skills를 탐색하세요. 메시지에 첨부할 하나 이상의 skill을 선택하세요.
  </Step>

  <Step title="메시지 보내기">
    요청을 입력하고 보내세요. Agent는 선택한 skills를 해당 메시지에만 사용합니다. 어떤 skills가 활성화되어 있는지 볼 수 있도록 메시지에 skill 칩이 표시됩니다.
  </Step>
</Steps>

예를 들어, **Stock Analyzer**를 첨부하고 Agent에게 주식 리서치 보고서를 작성해 달라고 요청하거나, **Deep Research**를 첨부하여 Agent가 구조화된 결과물로 주제를 조사하게 하세요.

<Tip>
  채팅에서 첨부한 Skills는 프로젝트에 아무것도 설치하지 않습니다. 모든 프로젝트에서 즉시 사용할 수 있습니다.
</Tip>

## Skill로 프로젝트 시작하기

새 프로젝트를 만들 때, 검증된 skill을 시작점으로 선택할 수 있습니다. Agent는 skill의 지시사항을 사용하여 프로젝트를 구성합니다.

<Steps>
  <Step title="시작점 선택기 열기">
    새 프로젝트 화면에서 \*\*+\*\*를 클릭하고 **Use a skill**을 선택하세요.
  </Step>

  <Step title="Skill 선택">
    **AI SDR**, **SEO Auditor**, **Ad Creative**, **Programmatic SEO** 등 큐레이션된 skills를 탐색하세요. 만들고 싶은 앱 유형에 맞는 것을 선택하세요.
  </Step>

  <Step title="앱 설명하기">
    Agent에게 원하는 것을 알려주세요. Agent는 처음부터 skill의 패턴과 규칙이 적용된 프로젝트를 빌드합니다.
  </Step>
</Steps>

## 프로젝트에 skill 설치하기

프로젝트의 모든 대화에 걸쳐 Agent가 skill을 일관되게 적용하길 원한다면 설치하세요. 설치된 skills는 프로젝트의 `/.agents/skills` 디렉토리에 저장되며 채팅 세션에 걸쳐 유지됩니다.

### Skills 패널에서 설치하기

Project Editor의 **Skills 패널**을 열고 **Discover** 탭을 선택하여 커뮤니티가 기여한 skills를 검색하세요. 원하는 것을 찾으면 **Install**을 클릭하면 자동으로 프로젝트에 추가됩니다.

<Frame>
  <img src="/assets/mirror/agent-skills-discover-732b2b0c488a.png" alt="설치 버튼이 있는 검색 가능한 커뮤니티 기여 skills를 보여주는 Discover skills 탭" width="2542" height="1850" data-path="images/replitai/agent-skills-discover.png" />
</Frame>

예를 들어, 고급 애니메이션이 있는 포트폴리오 사이트를 빌드할 때 다음을 설치할 수 있습니다:

* **GSAP React** — Agent에게 스크롤 트리거 애니메이션, 텍스트 리빌, SVG 경로 그리기를 가르칩니다
* **Tailwind design system** — Agent에게 타이포그래피, 간격, 뷰 전환에 대한 Tailwind CSS 패턴 지식을 제공합니다
* **Find skills** — Agent에게 사용자를 대신하여 새 skills를 검색하고 설치하는 방법을 가르칩니다

<Tip>
  [npx skills CLI](https://github.com/vercel-labs/skills)를 통해 skills를 설치할 수도 있습니다:

  ```bash theme={null}
  npx skills <skill> -a replit
  ```
</Tip>

### 대화에서 skill 만들기

skill을 만드는 가장 자연스러운 방법은 Agent와의 대화를 통해서입니다. 함께 문제를 해결하거나 새 라이브러리를 조사한 후, Agent에게 배운 내용을 기록해 달라고 요청하세요:

<AiPrompt>
  Research best practices for GSAP React integration and create a skill for this project.
</AiPrompt>

Agent는 전체 대화 컨텍스트를 사용하여 상세한 skill 파일을 작성합니다. 이는 문제에 대한 공유된 이해를 쌓아온 디버깅 세션 후에 특히 잘 작동합니다.

### 커스텀 skill 작성하기

고급 사용 사례에는 [Agent Skills 명세](https://agentskills.io/specification)에 따라 skills를 직접 작성하세요. 파일 사이드바에서 **Show Hidden Files**를 토글하고, `/.agents/skills/`를 열어 새 Markdown 파일을 만드세요. 이렇게 하면 Agent가 무엇을 알고 어떻게 동작하는지 완전히 제어할 수 있습니다.
