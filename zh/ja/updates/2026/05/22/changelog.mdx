<div id="section-3">
  ### 视觉编辑器新增布局控件
</div>

视觉编辑器现已新增专用的**布局**控件，无需让 Agent 重写样式，即可直观调整 flexbox 布局。选择容器并展开 Layout 部分，然后设置 flex 方向、对齐和分布方式。您可以设置项目之间的像素间距，或开启 **Space between** 开关，将子元素分布在两端。

编辑器窗格也重新归类为清晰的 **Text**、**Image**、**Layout**、**Color** 和 **Border** 部分，方便您更轻松地找到所需控件。

  ## Agent

<div id="agent-2">
  ### 共享项目中的 Agent 设置仍为个人独立设置
</div>

模型层级、计划模式、自动合并、自动批准计划等 Agent 设置现在与个人绑定，不再在整个项目中共享。即使协作者在自己的任务中切换到 Power Mode，也不会影响你的设置。无论项目中有多少协作者，你所选择的设置都将是 Agent 在你发送下一条消息时使用的设置。

了解更多关于 [Agent 模式](/zh/ja/features/agent/agent-modes#settings-in-shared-projects)的信息。

<div id="agentpower-mode">
  ### 遇到瓶颈时 Agent 会建议切换到 Power Mode
</div>

当 Agent 发现自己在 Economy 模式下反复卡在同一个问题上时，会在下一条消息中建议你切换到 Power。该提示基于对重复请求和持续失败代码的检测，每个项目最多出现一次。在规划会话期间、你表示对预算有顾虑时，或使用免费方案时，Agent 会跳过该建议。

<div id="section-4">
  ### 更简洁的任务设置下拉菜单
</div>

从任务标题栏打开的下拉菜单更好用了。当前任务或计划的标题显示在顶部，可直接就地重命名；自动化设置 (自动应用、自动批准) 移到了标题与操作之间的专属区域；弹出面板改为固定宽度，任务名称变化时不再发生位移。已禁用的自动化选项会隐藏，只显示适用于当前任务的项目。

<div id="2quiver-aibrowserbase">
  ### 两款新连接器：Quiver AI 和 Browserbase
</div>

连接器目录中新增了两项服务。打开 **Integrations** 面板，选择 **Add new integration** 即可连接其中任意一个。

* **Quiver AI**：通过托管 API 生成 SVG 插图，并将位图图像矢量化。当 Agent 需要按需获取干净的 SVG 资源时，这项服务非常有用。
* **Browserbase**：运行托管的无头浏览器，用于抓取、搜索和完整会话自动化。当 Agent 需要加载真实网页、执行 JavaScript，或与屏蔽纯 HTTP 请求的网站交互时，这项服务非常有用。
