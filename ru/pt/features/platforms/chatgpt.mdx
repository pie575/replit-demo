Интеграция Replit с ChatGPT позволяет создавать, обновлять и проверять Replit Apps прямо в переписке — без какой-либо настройки. Создавайте настоящие приложения в диалоге с ChatGPT, а обо всём остальном позаботится Agent.

<div id="o-que-o-replit-no-chatgpt">
  ## Что такое Replit в ChatGPT
</div>

Replit в ChatGPT соединяет ваши диалоги в ChatGPT с мощной платформой разработки Replit. Достаточно описать, что вы хотите создать, — и Agent соберёт для вас полностью работающее Replit App. После этого вы можете попросить ChatGPT изменить, обновить или проанализировать ваше приложение — и всё это в обычном диалоге.

<div id="como-comear">
  ## С чего начать
</div>

Выполните эти шаги, чтобы подключить Replit к ChatGPT и создать своё первое приложение.

<div id="conectar-o-replit-ao-chatgpt">
  ### Подключение Replit к ChatGPT
</div>

Подключить Replit к ChatGPT можно двумя способами:

<Accordion title="Подключение через настройки">
  1. Нажмите на значок своего профиля в ChatGPT
  2. Перейдите в **Настройки** → **Приложения и коннекторы**
  3. Найдите **Replit** и нажмите **Подключить**
  4. Завершите авторизацию OAuth со своей учётной записью Replit
</Accordion>

<Accordion title="Подключение из чата">
  1. Начните новый чат в ChatGPT
  2. Вызовите Replit одним из описанных ниже способов
  3. Если вы ещё не подключены, ChatGPT проведёт вас через процесс OAuth
</Accordion>

<div id="invocar-o-replit-no-chatgpt">
  ### Вызов Replit в ChatGPT
</div>

После подключения вызвать Replit можно тремя способами:

| Способ            | Как использовать                              |
| ----------------- | --------------------------------------------- |
| Прямое упоминание | Введите `Replit, <запрос>` в начале сообщения |
| Слеш-команда      | Введите `/Replit` в поле ввода                |
| Меню поля ввода   | Нажмите кнопку **+** → **Ещё** → **Replit**   |

<div id="criar-seu-primeiro-app">
  ### Создание первого приложения
</div>

После подключения создайте свой первый Replit App:

1. Начните новый чат в ChatGPT
2. Вызовите Replit и опишите, что хотите создать (например, «Replit, create a todo app with dark mode»)
3. Agent создаст приложение и автоматически развернёт его
4. По завершении вы получите ссылку для просмотра приложения

<Note>
  В рамках одного чата можно работать только с одним Replit App. Если вы создадите новое приложение в том же чате, оно заменит собой существующее. Чтобы создать несколько приложений, начните отдельные чаты.
</Note>

<div id="recursos">
  ## Возможности
</div>

* **[Replit AI](/ru/pt/build/welcome)**: Agent создаёт и развёртывает приложения по вашим запросам на естественном языке
* **[Project Editor](/ru/pt/learn/projects-and-artifacts/project-editor)**: полноценная среда разработки, доступная через ChatGPT
* **[Публикация](/ru/pt/learn/projects-and-artifacts/replit-deployments)**: приложения развёртываются автоматически и сразу готовы к тому, чтобы поделиться ими

<Accordion title="Что вы можете делать">
  **Создавать:** создавайте новые Replit App, просто описав, что вам нужно. Agent сгенерирует приложение и развернёт его автоматически.

  **Обновлять:** изменяйте приложение прямо в текущем диалоге. Попросите ChatGPT добавить функции, исправить ошибки или внести правки — Agent применит их.

  **Исследовать:** анализируйте приложение, не внося изменений. Получайте информацию о структуре кода, путях к файлам или поведении приложения.
</Accordion>

<Accordion title="Поддерживаемые форматы файлов">
  В своих запросах вы можете использовать различные типы файлов:

  | Формат                              | Поддерживается                  |
  | ----------------------------------- | ------------------------------- |
  | PDF                                 | Да                              |
  | CSV                                 | Да                              |
  | Распространённые форматы документов | Да                              |
  | Изображения (исходные файлы)        | Нет (используйте публичные URL) |
  | Видео (исходные файлы)              | Нет (используйте публичные URL) |

  <Note>
    Чтобы добавить в приложение изображения или видео, укажите в запросе публичные URL. Медиафайлы также можно добавить напрямую в Replit уже после создания приложения.
  </Note>
</Accordion>

<Accordion title="Время создания">
  Обычно Agent создаёт приложения за:

  | Сложность приложения                                  | Типичное время создания |
  | ----------------------------------------------------- | ----------------------- |
  | Простые (калькуляторы, небольшие лендинги)            | 2–3 минуты              |
  | Сложные (игры, насыщенные анимации, плотные дашборды) | 3–4 минуты              |
</Accordion>

<div id="disponibilidade-e-planos">
  ## Доступность и планы
</div>

<Accordion title="Планы ChatGPT">
  Интеграция с Replit работает со всеми типами планов ChatGPT:

  | План           | Поддержка | Примечания                                                                         |
  | -------------- | --------- | ---------------------------------------------------------------------------------- |
  | Free           | Да        |                                                                                    |
  | Plus           | Да        |                                                                                    |
  | Pro            | Да        |                                                                                    |
  | Business       | Да        | Требуется активация администратором в разделе **Настройки Workspace → Коннекторы** |
  | Enterprise/Edu | Да        | Требуется активация администратором в разделе **Настройки Workspace → Коннекторы** |

  **Региональная доступность:** все регионы за пределами ЕС.
</Accordion>

<Accordion title="Планы Replit">
  Все типы планов Replit поддерживают интеграцию с ChatGPT:

  | План           | Поддержка | Примечания                                                     |
  | -------------- | --------- | -------------------------------------------------------------- |
  | Starter (Free) | Да        | Только публичные приложения                                    |
  | Core           | Да        | Приватные приложения, расширенные сборки, публикация, Database |
  | Pro            | Да        | Увеличенная месячная квота кредитов, все возможности Core      |
  | Enterprise     | Да        | Полный доступ ко всем возможностям                             |
</Accordion>

<div id="cobrana-e-crditos">
  ## Оплата и кредиты
</div>

Работа, которую Replit выполняет в ChatGPT, тарифицируется как использование Replit Agent в вашей учётной записи Replit.

<Accordion title="Как работает оплата">
  * Планы **Core** и **Pro** включают ежемесячные кредиты, которые покрывают работу Agent, публикацию и базы данных в пределах вашего лимита
  * Вы можете приобрести **пакеты кредитов**: они действуют шесть месяцев и не продлеваются автоматически — удобно при всплесках нагрузки на запуске или для экспериментов
  * Используйте **лимиты использования** и **бюджеты** в настройках оплаты Replit, чтобы контролировать расходы

  Подробнее — в [документации по оплате ИИ](/ru/pt/billing/ai-billing).
</Accordion>

<div id="limitaes-atuais">
  ## Текущие ограничения
</div>

Сейчас приложение Replit в ChatGPT:

* Может работать только с приложением, созданным в этом конкретном диалоге
* Не может открывать или изменять:
  * Приложения, созданные в других чатах ChatGPT
  * Приложения, которые вы создали непосредственно в Replit

Полное соответствие возможностям Replit (базы данных, управление Secrets, расширенные настройки Project Editor) пока в разработке.

<div id="soluo-de-problemas">
  ## Устранение неполадок
</div>

<Accordion title="Replit не отображается в разделе «Обзор приложений»">
  Если вы не видите Replit в разделе **Обзор приложений**, проверьте:

  * доступны ли приложения в вашем регионе;
  * включил ли администратор workspace приложение Replit (Business/Enterprise/Edu).
</Accordion>

<Accordion title="Ошибки при создании">
  Если создание завершается ошибкой, откройте приложение в Replit:

  * проверьте расход ресурсов и оплату;
  * используйте checkpoint и откаты;
  * обратитесь за помощью к Agent прямо в Project Editor.
</Accordion>
