<div id="section-6">
  ## 故障排查
</div>

* **无法导入 Google Ads 或 Meta Ads：** 这两个并非原生连接器。Agent 会要求提供 API 密钥。请提前准备好密钥，并确认其可读取所需的广告账户。
* **汇总数据与广告管理工具不一致：** 通常是日期范围和时区不同所致。请让 Agent 使用与各平台相同的周期 (通常为上周一至周日) ，并在调整预算前核对支出。
* **表格中缺少某个平台：** 请先在 Replit 中连接 TikTok Ads 和 Snapchat Ads。如果原生连接已过期，请重新连接并再次运行该流程。
