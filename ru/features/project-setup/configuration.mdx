Replit App настраивается двумя файлами: `.replit` и `replit.nix`. Они определяют поведение вашего Replit App — от выполнения кода до инструментов разработки и языков программирования.

По умолчанию эти файлы конфигурации скрыты. Чтобы показать их в своём Replit App, выберите «Show hidden files» в меню дерева файлов.

<div id="replitnix-file">
  ## Файл `replit.nix`
</div>

Replit использует `Nix` для управления пакетами и окружениями. Файл `replit.nix` применяется для:

**Указания системных зависимостей:** определите, какие именно программные пакеты требуются вашему Replit App — ими управляет пакетный менеджер Nix.

**Создания воспроизводимых окружений:** обеспечьте согласованность и воспроизводимость среды разработки — это особенно удобно для совместных проектов и тестирования на разных системах.

Управлять пакетами Nix можно визуально с помощью инструмента `Dependencies`. Подробнее — в руководстве [Системные зависимости](/ru/features/project-setup/dependency-management#system-dependencies).

Чтобы настроить пакеты через файл `replit.nix`, перечислите [пакеты Nix](https://search.nixos.org/packages) в массиве `deps`, добавив префикс `pkgs.`. Все изменения вступят в силу после перезапуска Shell.

```nix theme={null}
{ pkgs }: {
  deps = [
    pkgs.nodejs-19_x
    pkgs.nodePackages.typescript-language-server
    pkgs.yarn
    pkgs.replitPackages.jest
  ];
}
```

<div id="replit-file">
  ## Файл `.replit`
</div>

Файл `.replit` управляет поведением вашего Replit App. Он использует [формат конфигурации](https://toml.io/en/) `toml`. Вот основные аспекты, которые можно настроить:

**Команда запуска:** укажите команду, которая выполняется при нажатии кнопки Run. В каждом шаблоне есть команда запуска по умолчанию, позволяющая сразу же выполнять код. Для более сложных приложений с индивидуальной настройкой используйте [Workflows](/ru/features/workspace-tools/workflows).

**Language Server Protocol (LSP)**: обеспечивает автодополнение, навигацию по коду, подсветку кода, а также линтинг и отображение ошибок в реальном времени.

**Переменные окружения:** задавайте переменные окружения, необходимые для корректной работы ваших приложений, и управляйте ими.

**Зависимости и пакеты:** управляйте установкой и настройкой пакетов напрямую через файл `.replit`, чтобы у вашего Replit App при запуске были все необходимые инструменты. Управлять зависимостями визуально можно с помощью инструмента `Dependencies`. Подробнее — в руководстве [System Modules](/ru/features/project-setup/dependency-management#advanced-configuration).

Для приложений на Python файл `.replit` по умолчанию выглядит так:

```toml theme={null}
entrypoint = "main.py"
modules = ["python-3.10:v18-20230807-322e88b"]

[nix]
channel = "stable-23_05"

[unitTest]
language = "python3"

[gitHubImport]
requiredFiles = [".replit", "replit.nix"]

[deployment]
run = ["python3", "main.py"]
deploymentTarget = "cloudrun"
```

В следующей таблице представлены все настройки файла `.replit` с пояснением того, за что отвечает каждый параметр и как он влияет на окружение Replit App.

| **Ключ конфигурации**                           | **Значение/Пример**                    | **Описание**                                                                                                                                                                                      |
| ----------------------------------------------- | -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <a name="entrypoint" />`entrypoint`             | `main.py`                              | Указывает основной файл, который выполняется и отображается по умолчанию при открытии редактора. Имя файла можно изменить в зависимости от вашего приложения.                                     |
| <a name="modules" />`modules`                   | `["python-3.10:v18-20230807-322e88b"]` | Определяет конкретные версии языков программирования или других основных зависимостей, поддерживаемых Replit.                                                                                     |
| <a name="nix" />`[nix]`                         |                                        | Задаёт настройки использования Nix — менеджера пакетов для управления системными зависимостями. Подробнее см. документ [Управление зависимостями](/ru/features/project-setup/dependency-management). |
| <a name="channel" />`channel`                   | `stable-23_05`                         | Указывает используемый канал Nix, от которого зависят доступные версии системных зависимостей.                                                                                                    |
| <a name="packages" />`packages`                 | `["cowsay", "htop"]`                   | Указывает пакеты Nix для установки. Для более тонкой настройки можно также использовать `replit.nix`.                                                                                             |
| <a name="unitTest" />`[unitTest]`               |                                        | Задаёт параметры, связанные с модульным тестированием в Replit App.                                                                                                                               |
| <a name="language" />`language`                 | `python3`                              | Указывает язык, используемый для модульного тестирования; в данном случае тесты пишутся на Python 3.                                                                                              |
| <a name="gitHubImport" />`[gitHubImport]`       |                                        | Настройки, влияющие на импорт проектов из GitHub, в частности на то, какие файлы должны быть включены.                                                                                            |
| <a name="requiredFiles" />`requiredFiles`       | `[".replit", "replit.nix"]`            | Перечисляет файлы, которые должны присутствовать при импорте проекта, чтобы он работал корректно.                                                                                                 |
| <a name="deployment" />`[deployment]`           |                                        | Содержит настройки развёртывания приложения из Replit App в рабочее окружение.                                                                                                                    |
| <a name="run" />`run`                           | `["python3", "main.py"]`               | Команда, выполняемая для запуска приложения во время развёртывания.                                                                                                                               |
| <a name="deploymentTarget" />`deploymentTarget` | `cloudrun`                             | Указывает целевую платформу развёртывания для размещения приложения.                                                                                                                              |

Теперь, когда вы получили представление о настройках файла `.replit` по умолчанию, воспользуйтесь следующими разделами, чтобы разобраться, как задать базовые и расширенные параметры вашего Replit App.

<div id="configuring-basic-settings">
  ## Настройка основных параметров
</div>

<div id="entrypoint">
  ### Entrypoint
</div>

Это основной файл вашего проекта. Если свойство `run` не задано, среда выполнения запускает файл, указанный в `entrypoint`.

```toml theme={null}
entrypoint = "<file-name>.py"
```

<div id="run-command">
  ### Команда `Run`
</div>

Свойство `run` в файле `.replit` — ключевая настройка, которая определяет начальную команду или набор команд, выполняемых при нажатии кнопки `Run` в среде Replit. Команду `Run` можно задать либо строкой с самой командой, либо массивом строк, где перечислены команда и её отдельные аргументы.

Распространённые способы настройки команды `Run`:

* **Одна команда:**
  В этом примере показано, как передать одну команду для непосредственного выполнения в Replit App. С такой записью в файле `.replit` нажатие кнопки `Run` выведет приветствие на панели `Console`:
  **Пример:** `run = "echo 'Hello, Replit!'"`

* **Явные аргументы:**
  Иногда удобнее указать всё явно, чтобы не полагаться на разбор кавычек и правила подстановки в оболочке. Пример выше можно переписать, разделив аргументы.
  Обратите внимание: одновременно `'` и `"` больше не нужны, поскольку приветствие передаётся явно как первый и единственный аргумент команды `echo`:
  **Пример:** `run = ["echo", "Hello, Replit!"]`

* **Несколько команд:**
  В этом примере показано, как одновременно запустить несколько процессов, например фронтенд и бэкенд. Это удобно при разработке бэкенда на Python и фронтенда на TypeScript, когда каждый сервер слушает свой порт:
  **Пример:** `run = "python -m app & npm run start & wait"`

<div id="process-management">
  #### Управление процессами
</div>

Хотя несколько команд можно запускать одновременно через `&`, вам может понадобиться более удобный способ различать логи разных сервисов. Вы можете [добавить системные зависимости](/ru/features/project-setup/dependency-management#system-dependencies), например [`process-compose`](https://github.com/F1bonacc1/process-compose), чтобы эффективнее оркестрировать несколько процессов.

<div id="build-phase">
  #### Фаза `Build`
</div>

Для некоторых языков или сред выполнения перед выполнением команды `run` требуется отдельная фаза компиляции. Это относится как к компилируемым языкам вроде TypeScript, Golang или Java, так и к возможности задать параметр, который сбрасывает окружение, данные или конфигурацию перед следующим вызовом `run`.

* **Компиляция:**
  В репозитории на TypeScript вам может понадобиться выполнить `tsc` перед запуском кода.
  **Пример:**

```toml theme={null}
build = "tsc app.ts"
run = "node app.js"
```

<div id="including-environment-variables">
  #### Добавление переменных окружения
</div>

Чтобы передать сервису переменные окружения перед запуском, можно развернуть свойство `run` в [таблицу](https://toml.io/en/v1.0.0#table).

Это более серьёзное изменение: скорее всего, свойство `run = "..."` придётся перенести в другое место файла `.replit`.

В приведённом ниже diff команда передаётся через `args` в `[run]`, а переменная `NAME` задаётся в `[run.env]`:

```diff theme={null}
-run = ["bash", "-c", "echo \"Hello, $NAME!\""]

 modules = ["nodejs-20"]

 hidden = [".pythonlibs"]

+# Новую секцию [run] нужно разместить ниже всех
+# свойств верхнего уровня, которые не начинаются с `[`!
+[run]
+args = ["bash", "-c", "echo \"Hello, $NAME!\""]
+
+[run.env]
+NAME="Replit"

 [nix]
 channel = "stable-23_11"
```

<div id="interactivity">
  #### Интерактивность
</div>

Интерактивные программы также можно запускать кнопкой `Run` — так среда разработки отделяется от терминала, в котором выполняется программа.
Рассмотрим такой скрипт подсчёта:

**Пример**

```toml theme={null}
[run]
args = ["bash", "-c", """
count=0
while read -p "$PROMPT" -r next && [ -n "$next" ]; do
    count=$((count+next))
done
echo "The numbers you entered sum to $count!"
"""]

[run.env]
PROMPT = "Next number ([Enter] to end): "
```

<div id="advanced-configuration-options">
  ## Расширенные параметры конфигурации
</div>

Ознакомьтесь с подробными параметрами конфигурации, доступными для вашего Replit App. Вы можете настроить среду разработки, управлять командами запуска, подключать языковые службы и работать с зависимостями.

| **Конфигурация** | **Ключ**                            | **Значение/Пример**                         | **Описание**                                                                                   |
| ---------------- | ----------------------------------- | ------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| onBoot           | <a name="onBoot" />`onBoot`         | `onBoot = "npm install"`                    | Команда, выполняемая при запуске Replit App.                                                   |
| compile          | <a name="compile" />`compile`       | (Пример по умолчанию отсутствует)           | Команда, выполняемая перед командой `run`; используется в компилируемых языках, таких как C++. |
| language         | <a name="language" />`language`     | `language = "javascript"`                   | Указывает язык при импорте из GitHub или при создании Replit App.                              |
| entrypoint       | <a name="entrypoint" />`entrypoint` | `entrypoint = "index.js"`                   | Основной файл, который запускается и открывается в редакторе.                                  |
| hidden           | <a name="hidden" />`hidden`         | `hidden = [".config", "package-lock.json"]` | Файлы и папки, скрытые по умолчанию в боковом дереве файлов.                                   |
| audio            | <a name="audio" />`audio`           | `audio = true`                              | Включает системный звук при значении `true`.                                                   |

<div id="notes-about-system-wide-audio">
  ### Примечания о системном звуке
</div>

Если вы указали `audio = true` в файле `.replit`, может потребоваться перезапустить среду разработки. Откройте палитру команд сочетанием `Cmd+K` (Mac) или `Ctrl+K` (Windows), найдите пункт **Restart compute** и выберите его.

При запуске графического приложения в правом нижнем углу панели `Output` появится значок наушников с флажком.
Из-за ограничений браузера его придётся включать заново после каждого обновления страницы.

```toml theme={null}
# Убедитесь, что эта строка находится в начале файла `.replit`, за пределами любых секций в квадратных скобках `[`
audio = true
```

<div id="packager-configuration">
  ## Настройка пакетного менеджера
</div>

| **Настройка**     | **Ключ**                                          | **Значение/Пример**                           | **Описание**                                                                    |
| ----------------- | ------------------------------------------------- | --------------------------------------------- | ------------------------------------------------------------------------------- |
| packager          | <a name="language" />`language`                   | `packager.language = "python3"`               | Язык, используемый для операций с пакетами.                                     |
| packager features | <a name="guessImports" />`guessImports`           | `packager.features.guessImports = true`       | Автоматически определять пакеты для установки перед запуском Replit App.        |
| packager features | <a name="packageSearch" />`packageSearch`         | `packager.features.packageSearch = true`      | Включает поддержку пакетного менеджера при значении `true`.                     |
| packager features | <a name="enabledForHosting" />`enabledForHosting` | `packager.features.enabledForHosting = false` | Определяет, требуется ли установка пакетов для размещения Replit App.           |
| packager          | <a name="afterInstall" />`afterInstall`           | `afterInstall = "echo 'package installed'"`   | Команда, выполняемая после установки нового пакета через пакетный менеджер.     |
| packager          | <a name="ignoredPaths" />`ignoredPaths`           | `ignoredPaths = [".git"]`                     | Пути, игнорируемые при попытке определить пакеты.                               |
| packager          | <a name="ignoredPackages" />`ignoredPackages`     | `ignoredPackages = ["twitter", "discord"]`    | Модули, для которых никогда не следует пытаться определить пакет при установке. |

<div id="example-replit-configuration-for-packager-configuration">
  ### Пример настройки пакетного менеджера в `.replit`
</div>

```toml theme={null}
# Укажите язык для Replit App
packager.language = "python3"

# Включите функции автоматического управления пакетами
[packager.features]
guessImports = true
packageSearch = true
enabledForHosting = false

# Команда, выполняемая после установки каждого пакета
packager.afterInstall = "echo 'Package installed successfully'"

# Укажите пути и пакеты, которые пакетный менеджер должен игнорировать
packager.ignoredPaths = [".git", "node_modules"]
packager.ignoredPackages = ["twitter", "discord"]

# Дополнительные настройки развёртывания
[deployment]
run = ["python3", "app.py"]
```

<div id="deployment-configuration">
  ## Конфигурация развёртывания
</div>

| **Конфигурация** | **Ключ**                              | **Значение/пример**                  | **Описание**                                                                 |
| ---------------- | ------------------------------------- | ------------------------------------ | ---------------------------------------------------------------------------- |
| развёртывание       | <a name="run" />`run`                 | `deployment.run = "npm start"`       | Команда, которая выполняется при запуске контейнера развёртывания.              |
| развёртывание       | <a name="build" />`build`             | `deployment.build = "npm run build"` | Команда, которая выполняется перед запуском развёртывания.                      |
| развёртывание       | <a name="ignorePorts" />`ignorePorts` | `deployment.ignorePorts = true`      | Если `true`, для успешного развёртывания не требуется проверка открытого порта. |

<div id="example-replit-configuration-for-deployment-configuration">
  ### Пример конфигурации `.replit` для настройки развёртывания
</div>

```toml theme={null}

# Задаёт главную точку входа проекта
entrypoint = "app.js"

# Параметры конфигурации для развёртывания приложения
[deployment]
run = "npm start"
build = "npm run build"
ignorePorts = true
```

<Note>
  **Настройка интерпретатора** объявлена устаревшей и больше недоступна в Replit. Вместо неё рекомендуется использовать команды `Run`, чтобы задать порядок запуска скриптов и приложений в среде вашего Replit App.
</Note>

<div id="accessing-replit-app-environment-metadata">
  ## Доступ к метаданным окружения Replit App
</div>

<div id="nodejs">
  ### Node.js
</div>

Чтобы получить доступ ко всем переменным окружения:

`console.log(process.env);`

Чтобы обратиться к одной переменной (REPL&#95;SLUG):

`console.log(process.env.REPL_SLUG);`

<div id="python">
  ### Python
</div>

Чтобы получить доступ ко всем переменным окружения:

```python theme={null}
import os
print(os.environ)
```

Чтобы обратиться к отдельной переменной (REPL&#95;SLUG):

```python theme={null}
import os
variable = os.environ.get('REPL_SLUG')
print(variable)
```

<div id="rust">
  ### Rust
</div>

Чтобы получить доступ ко всем переменным окружения:

```rust theme={null}
use std::env;
fn main() {
    for (key, value) in env::vars() {
        println!("{}: {}", key, value);
    }
}
```

Чтобы обратиться к одной переменной (REPL&#95;SLUG):

```rust theme={null}
use std::env;
fn main() {
    let variable = env::var("REPL_SLUG").unwrap();
    println!("{}", variable);
}
```

<div id="environment-variables">
  ## Переменные окружения
</div>

Ниже перечислены переменные окружения, доступные внутри вашего Replit App:

| key                                               | описание                                                                                                                                                                          |
| ------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| <a name="HOME" />`HOME`                           | Домашний путь вашего Replit App                                                                                                                                                   |
| <a name="system" />`system`                       | Операционная система, на которой работает ваш Replit App                                                                                                                          |
