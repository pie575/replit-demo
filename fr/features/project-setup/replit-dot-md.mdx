<div id="how-replitmd-works">
  ## Fonctionnement de `replit.md`
</div>

Agent commence par créer un fichier `replit.md` à la racine de votre projet en s&#39;appuyant sur des bonnes pratiques éprouvées. Ce fichier contient :

* Les informations de base sur le projet
* Les modèles de code recommandés
* Les préférences courantes pour votre type de projet

<YouTubeEmbed videoId="kYv525W-vaU" title="Personnaliser la façon dont Replit Agent répond" />

Lorsque Agent traite vos demandes, il lit automatiquement votre fichier `replit.md` et en utilise le contenu pour :

* Comprendre l&#39;architecture et les conventions de votre projet
* Respecter vos modèles de code et votre style de prédilection
* Utiliser les gestionnaires de paquets et les dépendances que vous avez spécifiés

Agent peut également mettre à jour votre fichier `replit.md` au fur et à mesure qu&#39;il en apprend davantage sur votre projet et qu&#39;il modifie votre application.

<Note>Vous pouvez modifier le fichier `replit.md` pour personnaliser le comportement d&#39;Agent.</Note>

<div id="setting-up-replitmd">
  ## Configuration de `replit.md`
</div>

<div id="automatic-generation">
  ### Génération automatique
</div>

Lorsque vous créez un nouveau projet avec Agent, celui-ci génère automatiquement un fichier `replit.md` fondé sur des bonnes pratiques éprouvées. Ce fichier apparaît à la racine de votre projet et contient :

* Les informations de base du projet
* Les modèles de code recommandés
* Les préférences courantes pour votre type de projet

<div id="manual-creation">
  ### Création manuelle
</div>

Vous pouvez créer votre propre fichier `replit.md` en ajoutant un nouveau fichier nommé `replit.md` à la racine de votre projet. Agent le détectera et l&#39;utilisera automatiquement lors de vos prochaines conversations.

<Note>
  Le fichier `replit.md` doit se trouver à la racine de votre projet pour fonctionner correctement.
</Note>

<div id="regenerating-replitmd">
  ### Régénérer `replit.md`
</div>

Si votre fichier `replit.md` est corrompu ou si vous souhaitez repartir de zéro :

1. Supprimez le fichier `replit.md` existant à la racine de votre projet
2. Démarrez une nouvelle conversation avec Agent
3. Agent génère automatiquement un nouveau fichier `replit.md` à partir de votre projet actuel

  ## Bonnes pratiques
</div>

<div id="be-specific-and-clear">
  ### Soyez précis et clair
</div>

Rédigez des instructions claires et précises qui permettent à Agent de comprendre exactement ce que vous souhaitez :

```markdown theme={null}
## Style de code

- Utiliser TypeScript pour tous les nouveaux fichiers JavaScript
- Privilégier les composants fonctionnels avec hooks plutôt que les composants de classe
- Utiliser Tailwind CSS pour le style, éviter les styles en ligne
- Toujours typer les paramètres et les valeurs de retour des fonctions avec TypeScript
```

Pour un guide plus détaillé sur la mise en forme des prompts, consultez le [guide d&#39;ingénierie des prompts d&#39;Anthropic](https://docs.anthropic.com/en/docs/build-with-claude/prompt-engineering/use-xml-tags).

  ### Projet d&#39;application web

```markdown theme={null}
# Directives du projet MyApp

## Présentation du projet

Une application web de gestion de tâches conçue avec React et Express.js.

## Préférences technologiques

- Frontend : React avec TypeScript, Tailwind CSS
- Backend : Express.js avec TypeScript
- Base de données : Neon PostgreSQL avec l'ORM Drizzle
- Gestionnaire de paquets : npm (ni yarn ni pnpm)

## Normes de codage

- Utiliser des composants fonctionnels avec des hooks
- Mettre en place des error boundaries appropriés
- Respecter les conventions d'API REST pour les points de terminaison
- Utiliser des noms de variables et de fonctions explicites

## Style de communication

- Expliquer votre approche avant d'effectuer des modifications
- Commenter le code pour la logique complexe
- Poser des questions si les exigences sont ambiguës
```

## Contexte du projet

Analyse des données de comportement client afin d'identifier des tendances et des enseignements.

- Python avec Streamlit pour les applications web interactives
- pandas, numpy et matplotlib pour l'analyse de données

- Fournir une documentation claire pour chaque étape de l'analyse

- Expliquer les méthodes statistiques et leurs hypothèses
- Replacer les constats et les recommandations dans leur contexte
- Employer un langage clair et non technique pour les enseignements métier
- Créer des tableaux de bord interactifs pour les présentations aux parties prenantes

<div id="api-development-project">

```markdown theme={null}
# Directives de développement d'API

## Présentation du projet

Développement d'une API RESTful pour le backend d'une application mobile.

## Pile technologique

- Node.js with Express.js
- MongoDB with Mongoose
- JWT pour l'authentification
- Gestionnaire de paquets : npm

## Normes de l'API

- Utiliser des codes de statut HTTP sémantiques
- Mettre en place une validation rigoureuse des entrées
- Appliquer une limitation de débit sur les points de terminaison publics
- Suivre la spécification OpenAPI pour la documentation

## Exigences de sécurité

- Valider toutes les entrées utilisateur
- Utiliser des variables d'environnement pour les données sensibles
- Mettre en place des politiques CORS adaptées
- Journaliser les requêtes à des fins de débogage

## Approche de test

- Écrire des tests unitaires pour tous les points de terminaison
- Prévoir des tests d'intégration pour les flux critiques
- Utiliser Jest comme framework de test
```

<div id="combining-web-search-with-replitmd">
  ## Associer la recherche web au fichier `replit.md`
</div>

Agent peut effectuer des recherches sur le web pour trouver des informations, des bibliothèques et des solutions à jour. En les combinant à votre fichier `replit.md`, vous bénéficiez à la fois de connaissances actualisées et de consignes propres à votre projet.

<div id="best-practices-for-web-search-integration">
  ### Bonnes pratiques pour l&#39;intégration de la recherche web
</div>

**Précisez clairement ce que vous souhaitez qu&#39;Agent recherche :**

```markdown theme={null}
## Préférences de recherche

- Vérifiez toujours les dernières versions des dépendances avant de proposer des mises à jour
- Recherchez les bonnes pratiques actuelles en matière d'implémentation de la sécurité
- Consultez les techniques récentes d'optimisation des performances adaptées à notre stack technique
```

**Indiquez à Agent comment exploiter les connaissances externes :**

```markdown theme={null}
## Consignes de recherche externe

- Lorsque vous suggérez de nouvelles bibliothèques, vérifiez leur compatibilité avec notre stack existante
- Adaptez les exemples externes à nos conventions de code et à la structure de notre projet
- Assurez-vous que les solutions proposées fonctionnent avec notre environnement de publication
```

**Exemple de requête combinant les deux :**
« Recherche les dernières techniques d&#39;optimisation des performances de React 18 et implémente-les en suivant les modèles de composants définis dans `replit.md` »

Cette approche vous fournit des solutions à la fois actuelles et adaptées aux besoins spécifiques de votre projet.

<div id="limitations">
  ## Limites
</div>

<div id="file-size-and-content-limits">
  ### Limites de taille et de contenu des fichiers
</div>

Bien qu&#39;aucune limite stricte de caractères ne s&#39;applique à `replit.md`, les fichiers très volumineux risquent de ne pas être traités intégralement. Pour de meilleurs résultats, veillez à ce que votre fichier `replit.md` reste ciblé et concis.

<div id="root-directory-requirement">
  ### Exigence relative au répertoire racine
</div>

Le fichier `replit.md` doit se trouver dans le répertoire racine de votre projet. Agent ne détecte pas automatiquement les fichiers placés dans des sous-répertoires.

<div id="context-scope">
  ### Portée du contexte
</div>

`replit.md` fournit du contexte pour les conversations avec Agent, mais ne s&#39;applique pas automatiquement aux autres outils d&#39;IA.
