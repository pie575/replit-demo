<div id="section">
  ## Créer avec vos coéquipiers
</div>

Dans Replit, plusieurs personnes peuvent travailler simultanément sur le même projet. Chacun peut démarrer un nouveau fil de discussion de planification avec Agent, et les tâches de tous s’affichent sur un tableau partagé : l’équipe peut ainsi construire ensemble plutôt que de travailler à tour de rôle.

<div id="section-2">
  ## Commencer à créer avec vos coéquipiers
</div>

<div id="section-3">
  ### Inviter des coéquipiers
</div>

1. Ouvrez le projet
2. Cliquez sur **Inviter** ou partagez le lien du projet
3. Vos coéquipiers rejoignent le projet et ouvrent un nouveau fil de discussion avec Agent

<div id="section-4">
  ### Travailler en parallèle
</div>

Chacun peut créer un nouveau fil de discussion et travailler de manière indépendante, sans gêner les autres. Les tâches de tous les membres s’affichent sur un tableau Kanban partagé, ce qui permet de voir facilement qui fait quoi et d’éviter les doublons.

<Note>
  Avec Core, une seule tâche en arrière-plan peut s’exécuter à la fois dans l’ensemble du projet. Avec Pro, vous pouvez exécuter jusqu’à 10 tâches en parallèle : plusieurs personnes peuvent ainsi utiliser Agent pour construire simultanément différentes parties du projet.
</Note>

<div id="section-7">
  ## Ce que vous pouvez créer ensemble
</div>

* **Répartir les fonctionnalités au sein de l’équipe** : une personne développe le frontend, tandis qu’une autre s’occupe du backend. Chacun travaille dans son chat avec Agent, tout en coordonnant le travail de tous sur le tableau Kanban.
* **Intégrer de nouveaux coéquipiers à l’équipe** : ils peuvent explorer le projet dans leur propre chat avec Agent, poser des questions sur son fonctionnement et commencer à contribuer, sans bloquer les autres.
* **Livrer plus rapidement avec Pro** : grâce à l’exécution parallèle, 2 à 3 personnes peuvent chacune lancer des tâches qui s’exécutent simultanément. Vous pouvez terminer en une fraction du temps un projet qui demanderait à une seule personne une session complète.

<div id="section-8">
  ## Questions fréquentes
</div>

<Accordion title="Puis-je envoyer un message à un coéquipier via Agent ?">
  Non. Agent n’est pas un outil de messagerie : il tentera toujours d’agir sur ce que vous saisissez. Pour communiquer au sein de votre équipe, utilisez Slack, Discord ou d’autres outils.
</Accordion>

<Accordion title="Nos modifications risquent-elles de s’écraser mutuellement ?">
  Le système de tâches évite cela en attribuant une copie indépendante à chaque tâche, tout en tenant compte de l’existence des autres tâches. Lorsqu’une tâche est terminée, appliquez-la à la version principale et résolvez les conflits à cette étape.
</Accordion>

<Accordion title="Puis-je voir ce que font mes coéquipiers ?">
  Vous pouvez voir les tâches actives dans le tableau Kanban. Vous pouvez également voir la position de leurs curseurs et les fichiers consultés par vos coéquipiers.
</Accordion>

<Accordion title="Puis-je retirer quelqu’un du projet ?">
  Oui. Le propriétaire du projet peut gérer les membres de l’équipe et révoquer leur accès à tout moment.
</Accordion>
