<div id="what-is-a-remix">
  ## Qu&#39;est-ce qu&#39;un Remix
</div>

Un **Remix** est une nouvelle Replit App que vous créez à partir d&#39;une app à laquelle vous avez accès. Lorsque vous remixez une app publique ou un modèle, vous obtenez votre propre copie, que vous pouvez utiliser et améliorer de façon itérative. Les modifications apportées à votre Remix n&#39;ont aucun effet sur l&#39;app d&#39;origine.

Votre Remix crédite sa source : il affiche un lien **Remixed from** renvoyant à l&#39;app d&#39;origine, et le prompt de création de celle-ci apparaît sur sa page de couverture.

<div id="what-your-remix-includes">
  ## Ce que contient votre Remix
</div>

Un Remix est une copie complète et fonctionnelle, bien distincte de l&#39;original :

* **Tous les fichiers et la configuration** sont copiés, afin que l&#39;app fonctionne exactement comme la source.
* **L&#39;historique des checkpoints de la source** est repris et identifié comme provenant de l&#39;app source. Vous pouvez revenir à n&#39;importe lequel de ces checkpoints ; la conversation qui les a produits, elle, reste associée à l&#39;original.
* **Un Agent tout neuf.** Votre Remix démarre avec un Agent vierge, sans historique de chat hérité.
* **Les noms des secrets, pas leurs valeurs.** Si l&#39;app utilise des secrets (comme des clés API), votre Remix les répertorie avec des valeurs vides, afin que vous sachiez quoi renseigner. Les valeurs ne sont copiées que lorsque vous remixez votre propre app.
* **Une base de données vierge.** Votre Remix ne se connecte jamais à la base de données de l&#39;original. Si l&#39;original le permet, l&#39;option **Copy data from original App** copie les données elles-mêmes ; là encore, vos modifications n&#39;affectent jamais la source.
* **Une configuration de connexion vierge** pour les apps qui utilisent Replit Auth.

Ne sont pas copiés : les deployments, les domaines et les configurations de connectors, que vous devez mettre en place sur votre propre copie. Les Remix démarrent aussi en mode privé : rien n&#39;est partagé tant que vous n&#39;avez pas choisi de publier.

<div id="how-to-remix-an-app">
  ## Comment remixer une app
</div>

<Steps>
  <Step title="Ouvrir la page de couverture de l'app">
    Trouvez une app que vous souhaitez remixer, par exemple dans la [communauté](https://replit.com/community/all). Sa page de couverture affiche un aperçu en direct ainsi que des options de partage.
  </Step>

  <Step title="Remixer l'app">
    Sélectionnez **Remix this App** pour commencer à créer votre propre version.
  </Step>

  <Step title="Renseigner les détails de l'app">
    Dans la boîte de dialogue **Remix App**, donnez un nom à votre copie et, si vous le souhaitez, une description, puis sélectionnez **Remix App**. Vous pourrez modifier ces détails plus tard.

<div id="build-on-your-remix">
  ## Développez votre Remix
</div>

Une fois votre Remix ouvert dans le workspace, utilisez Agent pour le modifier et l&#39;enrichir. Dans l&#39;onglet **Agent**, saisissez un prompt décrivant la fonctionnalité que vous souhaitez ajouter.

Pour annuler les modifications d&#39;Agent, sélectionnez **Revenir ici** dans le checkpoint créé après la modification. Pour en savoir plus, consultez [Checkpoints et retours en arrière](/fr/features/version-control/checkpoints-and-rollbacks).

<div id="remix-or-build-from-a-prompt">
  ## Remixer ou créer à partir d&#39;un prompt ?
</div>

Les deux approches mènent au même résultat : une application bien à vous, qu&#39;Agent vous aide à faire évoluer. Seul le point de départ diffère :

|                             | Remix                                                   | Création à partir d&#39;un prompt                             |
| --------------------------- | ------------------------------------------------------- | ------------------------------------------------------------- |
| Point de départ             | Une application fonctionnelle, copiée à l&#39;identique | Une application créée par Agent à partir de votre description |
| Premier résultat            | Immédiat et identique à la source                       | Plus long à obtenir, avec un résultat variable                |
| Première action d&#39;Agent | Attend vos instructions                                 | Planifie et crée à partir de votre prompt                     |

Si une application proche de ce que vous recherchez existe déjà, remixez-la : Agent intervient alors sur une application réelle et fonctionnelle plutôt que de partir d&#39;une page blanche. Créez à partir d&#39;un prompt lorsque votre idée ne ressemble à rien de ce que vous pouvez trouver.
