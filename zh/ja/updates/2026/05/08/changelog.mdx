<div id="20">
  ### 工作区安全中心 2.0
</div>

现在，您可以在一处查看并处理工作区内所有项目的依赖项漏洞。工作区安全中心会优先显示风险最高的项目，您可以按严重程度、发布状态、可见性和所有者搜索和筛选受影响的项目。无需离开安全中心，即可完成完整的修复流程：启动 Agent 任务、审核建议的修复方案，然后重新发布项目。您还可以单独或批量通知项目所有者、立即将高暴露面的项目设为私密，或下载 SBOM 用于合规审计。

详细了解[工作区安全中心](/zh/core-concepts/security/workspace-security-center)。

<div id="section-3">
  ### 面向所有用户的私有发布
</div>

私有发布和密码保护发布此前仅限 Pro 和 Enterprise 套餐使用。现在，Core 和 Starter 构建者也可以进行私有发布，任何人都能将内部工具、Beta App 或开发中的项目置于 Replit 登录保护之下。

详细了解[私有部署](/zh/ja/features/publishing/private-deployments)。

<div id="section-4">
  ### 私有部署的外部访问令牌
</div>

私有 Replit App 现已支持外部访问令牌。您可以创建令牌并设置与 Slack、GitHub 和 Twilio 等服务的集成，让它们无需通过连接器即可访问私有部署。这让高级用户能够更好地掌控应用，同时进一步提升私有 Replit App 的安全性。打开部署的**调整设置**，然后找到新的**外部访问令牌**标签页。

详细了解[外部访问令牌](/zh/ja/features/deployment-customization/external-access-tokens)。

  ## Agent

<div id="section-5">
  ### 幻灯片演示文稿的演讲者备注和演示者视图
</div>

幻灯片演示文稿现已支持演讲者备注和专用演示者视图。备注会在编辑器与演示窗口之间双向实时同步，因此您可以通过一台设备远程控制演示文稿，同时通过另一台设备共享屏幕。您可以让 Agent 撰写备注，并在编辑器中进行修改，而观众只能看到幻灯片。演示者视图也可通过移动端幻灯片的 Artifact 卡片使用。

<div id="agentsvg">
  ### Agent 现已支持上传 SVG
</div>

现在，你可以将 SVG 文件附加到 Agent。将 SVG 拖放到聊天中或粘贴 URL 后，Agent 会像处理其他附件一样读取其标记内容。上传内容在传送到 Agent 或存储空间之前，会先在浏览器中进行净化处理，因此常见的基于 SVG 的攻击手法会被自动移除。

<div id="agent-2">
  ### Agent 模式的新动画图标
</div>

Lite、Economy 和 Power Agent 模式现已新增自定义动画图标，展现各模式的特色。新图标会显示在 Agent 模式选择器以及工作区中所有显示模式的位置。
