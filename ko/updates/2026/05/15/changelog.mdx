<div id="buy-enterprise-online-with-automated-sso-setup">
  ### SSO 자동 설정까지, Enterprise 온라인 구매
</div>

이제 [가격 페이지](https://replit.com/pricing)에서 Replit Enterprise 플랜을 바로 구매할 수 있습니다. 영업 상담은 필요 없습니다. 결제를 마치면 제품 내 마법사가 Single Sign-On 설정을 처음부터 끝까지 안내합니다. Identity Provider 값을 SAML 양식에 붙여 넣기만 하면 Replit이 SSO 연결을 자동으로 프로비저닝합니다. 이메일을 주고받으며 기다릴 필요 없이 몇 분 만에 팀 전체가 Enterprise를 사용할 수 있습니다.

<div id="per-user-spend-limits-for-enterprise-workspaces">
  ### Enterprise workspace의 사용자별 spend limits
</div>

이제 Enterprise 관리자는 workspace 구성원별로 서로 다른 Agent spend limit을 설정할 수 있습니다. [usage page](https://replit.com/usage)에서 **Agent users** 표를 열고, 원하는 행의 편집 icon을 선택한 뒤 새 limit을 지정하세요. 사용자별 limit은 group 및 workspace 기본값보다 우선 적용됩니다. workspace 전체 설정은 그대로 두면서 특정 구성원에게만 더 높은 한도를 부여하거나 지출을 더 조이고 싶을 때 유용합니다.

  <img src="/assets/mirror/edit-usage-limit-4a2fba67693a.png" alt="workspace 구성원의 사용량 한도 편집 대화상자로, workspace 기본값, 현재 사용자별 한도, 적용 중인 group 한도, 그리고 $5로 설정된 User 임계값 입력란을 보여줍니다" width="1202" height="916" data-path="images/changelog/2026-05-15/edit-usage-limit.png" />

자세한 내용은 [지출 관리](/ko/billing/managing-spend#per-user-spend-limits)에서 확인하세요.

<div id="export-canvas-frames-as-pngs">
  ### Canvas의 frame을 PNG로 내보내기
</div>

Canvas에서 artifact나 design frame을 마우스 오른쪽 버튼으로 클릭한 뒤 **Export** &gt; **PNG**를 선택하면 현재 preview의 snapshot을 download할 수 있습니다. 직접 화면을 캡처하지 않고도 문서나 Chat, 팀원 review에 시각 자료를 빠르게 공유할 때 유용합니다. 내보낸 이미지는 내보내는 시점에 Canvas의 frame에 표시된 내용과 정확히 일치합니다.

<div id="nine-new-connectors-ready-to-use-out-of-the-box">
  ### 별도 설정 없이 바로 사용할 수 있는 새로운 connector 9종
</div>

이제 connector 9종이 기본 자격 증명과 함께 제공되어 클릭 한 번으로 Agent에 연결할 수 있습니다. 직접 OAuth app을 먼저 만들 필요가 없습니다. project에서 **Integrations** 패널을 열고 서비스를 선택한 다음 연결을 승인하세요.

* **Airtable**: 베이스, 테이블, 레코드를 읽고 씁니다.
* **GitLab**: project, issues, merge 요청, pipeline에 접근합니다.
* **Basecamp**: project, 할 일, 메시지, schedule을 읽고 관리합니다.
* **Productboard**: 기능, release, 고객 feedback을 읽고 업데이트합니다.
* **Teamwork**: project, task, 시간 기록을 읽고 관리합니다.
* **Twitch**: stream, 채널, 시청자 활동을 읽습니다.
* **Square**: payments를 받고 주문, 고객, inventory를 관리합니다.
* **Intercom**: 대화, 연락처, 지원 workflows를 읽고 씁니다.
* **Mailchimp**: 오디언스, 캠페인, 이메일 마케팅 데이터를 읽고 관리합니다.

[connector](/ko/replitai/integrations#available-connectors)에 대해 자세히 알아보세요.

<div id="four-new-mcp-servers-in-the-directory">
  ### 디렉터리에 새로 추가된 MCP 서버 4종
</div>

이제 [MCP 디렉터리](/ko/replitai/mcp/directory)에서 호스팅형 Model Context Protocol 서버 4종을 사용할 수 있습니다. **Integrations** 패널을 열고 **MCP Servers for Replit Agent** 아래에서 원하는 서버를 찾은 다음, **Add to Replit**을 선택해 연결하세요.

* **Twilio**: 음성, SMS, 이메일, 신원 확인 관련 Twilio 문서와 1,800개 이상의 API 엔드포인트를 검색합니다.
* **Mixpanel**: Mixpanel의 이벤트, 퍼널, 리텐션, 대시보드를 조회합니다.
* **Lazyweb**: 25만 7천 개 이상의 실제 앱 화면을 검색해 UI 참고 자료와 디자인 리서치에 활용합니다.
* **Doola**: 미국 LLC를 등록하고 법인 설립, 회계, 세무를 관리합니다.

전체 목록은 [MCP 디렉터리](/ko/replitai/mcp/directory)에서 확인하세요.
