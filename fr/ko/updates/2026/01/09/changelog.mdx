<div id="ai">
  ### Nouveaux modèles d&#39;IA dans les intégrations
</div>

Les intégrations d&#39;IA prennent désormais en charge de nouveaux modèles d&#39;IA :

| Modèle                       | Description                                                                                                                                                                                     |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `gpt-5.2`                    | Le modèle le plus puissant d&#39;OpenAI pour les tâches expertes. Premier modèle à dépasser 90 % sur ARC-AGI-1, avec une fenêtre de contexte de 400 K.                                          |
| `claude-opus-4.5`            | Le modèle phare d&#39;Anthropic, optimisé pour le codage, les agents et l&#39;utilisation de l&#39;ordinateur. Score de 80,9 % sur SWE-bench Verified.                                          |
| `gemini-3-flash-preview`     | Le modèle rapide de Google, optimisé pour les flux de travail agentiques avec un contexte de 1 M de jetons. Il offre un raisonnement proche du niveau Pro, avec une latence et un coût réduits. |
| `gemini-3-pro-preview`       | Le modèle multimodal avancé de Google, doté d&#39;un raisonnement de pointe et de connaissances du monde réel.                                                                                  |
| `gemini-3-pro-image-preview` | Le modèle Nano Banana Pro de Google, conçu pour la génération et la retouche d&#39;images de haute qualité avec un rendu du texte précis.                                                       |
