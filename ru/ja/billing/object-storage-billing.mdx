<div id="section">
  ## Категории биллинга
</div>

Replit разделяет биллинг хранилища App на следующие категории:

* **Хранилище**: объём данных, использованный за месяц. Для всех сохранённых объектов действует минимальный расчётный период в 7 дней.
* **Передача данных**: суммарный объём данных, загруженных и выгруженных за месяц.
* **Базовые операции**: операции, связанные с обновлением бакетов и объектов. Подробнее см. операции Class A в разделе <a href="https://cloud.google.com/storage/pricing" target="_blank">Цены Google Cloud Storage</a>.
* **Расширенные операции**: прочие операции облачного объектного хранилища, включая получение настроек и метаданных объектов и бакетов. Подробнее см. операции Class B в разделе <a href="https://cloud.google.com/storage/pricing" target="_blank">Цены Google Cloud Storage</a>.
