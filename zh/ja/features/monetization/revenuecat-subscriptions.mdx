<div id="revenuecat">
  ## 什么是 RevenueCat
</div>

借助 RevenueCat，你可以为[原生移动应用](/zh/ja/features/artifact-types/building-mobile-apps)添加应用内订阅。上手很简单：让 Agent 帮你设置订阅，并连接你的 RevenueCat 账户，Agent 便会处理相关逻辑并提供测试环境。

<div id="section">
  ## 前提条件
</div>

开始之前，你需要准备：

* 以**移动应用**形式创建的 Replit 项目
* [RevenueCat](https://www.revenuecat.com) 账户 (只需邮箱地址和密码——无需银行账户或其他额外设置)

<Note>
  要开发原生移动应用，请使用 [replit.com](https://replit.com) 上的项目编辑器。在受支持的情况下，也可以在 Replit Android 应用中开发原生移动应用。如果你使用的是 Replit iOS 应用，请在 replit.com 上打开项目。
</Note>

<div id="section-2">
  ## 开始使用
</div>

<Steps>
  <Step title="让 Agent 添加订阅">
    描述你想要的订阅方案。Agent 会规划集成方案、安装软件包并配置 RevenueCat。

    <AiPrompt>Add a $5.99/mo subscription to my app</AiPrompt>

    <Frame>
      <img src="/assets/mirror/revenuecat-prompt-a230068ba884.png" alt="Replit 项目编辑器中显示 Agent 正在回应添加订阅的提示" width="1957" height="1133" data-path="images/replitai/revenuecat-prompt.png" />
    </Frame>
  </Step>

  <Step title="连接 RevenueCat 账户">
    Agent 会提示你连接到 RevenueCat。选择 **Connect RevenueCat** 启动授权流程。

    <Frame>
      <img src="/assets/mirror/revenuecat-connect-1463c331a55f.png" alt="Agent 聊天中显示带有 Connect 按钮的 Connect RevenueCat 横幅" width="1957" height="1133" data-path="images/replitai/revenuecat-connect.png" />
    </Frame>

    随后会出现确认连接到 RevenueCat 的弹窗。选择 **Continue to RevenueCat** 继续。

    <Frame>
      <img src="/assets/mirror/revenuecat-connect-modal-34362346bf1d.png" alt="显示隐私与安全信息的 Connect RevenueCat 弹窗" width="1957" height="1133" data-path="images/replitai/revenuecat-connect-modal.png" />
    </Frame>
  </Step>

  <Step title="授权 Replit">
    在 RevenueCat 的授权页面上选择 **Read &amp; Write** 访问权限，然后选择 **Authorize**，允许 Replit 访问你的 RevenueCat 账户。

    <Frame>
      <img src="/assets/mirror/revenuecat-authorize-cbab817ca1ae.png" alt="已选择 Read and Write 访问权限的 RevenueCat OAuth 授权页面" width="683" height="897" data-path="images/replitai/revenuecat-authorize.png" />
    </Frame>
  </Step>

  <Step title="Agent 构建订阅功能">
    授权完成后，Agent 会创建 RevenueCat 项目，配置商品和权益，构建付费墙页面，并在整个应用中接入订阅逻辑。

    <Frame>
      <img src="/assets/mirror/revenuecat-agent-summary-d015a344dcac.png" alt="Agent 关于付费墙页面的总结，展示订阅功能与价格" width="1957" height="1133" data-path="images/replitai/revenuecat-agent-summary.png" />
    </Frame>

    <Frame>
      <img src="/assets/mirror/revenuecat-app-home-ea0d4a05b26e.png" alt="移动应用主屏幕，已订阅内容显示 Premium 徽章" width="1957" height="1133" data-path="images/replitai/revenuecat-app-home.png" />
    </Frame>
  </Step>
</Steps>

<div id="section-3">
  ## 测试订阅
</div>

Replit 预览使用 RevenueCat 的**测试模式**。在 Expo Go 中进行测试购买时，系统会弹出测试购买对话框，而不会走真实的支付流程，也不会产生任何实际扣费。

<Frame>
  <img src="/assets/mirror/revenuecat-test-purchase-8414145a112e.png" alt="移动设备上显示套餐详情和测试按钮的测试购买对话框" width="683" height="1253" data-path="images/replitai/revenuecat-test-purchase.png" />
</Frame>

<Tip>
  测试购买在开发阶段可放心使用。你可以在不产生实际费用的情况下，测试购买成功和失败两种流程。
</Tip>

<Warning>
  当 Apple 批准你的应用在 App Store 上架后，购买将使用真实资金。
  在提交 App Review 之前，请确认 RevenueCat 中的商品和价格设置无误。
</Warning>

  ## 管理订阅
</div>

<div id="app-store-connect">
  ## 与 App Store Connect 同步
</div>

要让应用内购买在 TestFlight 和 Apple App Store 中正常使用，你需要[同意 Apple 的 Paid Apps Agreement 并关联银行账户](https://developer.apple.com/help/app-store-connect/manage-agreements/sign-and-update-agreements/)。
此操作通过 App Store Connect 完成。在将应用提交到 App Store 之前，你需要拥有付费的 Apple Developer Account。

完成后，你可以直接从 Replit 将 RevenueCat 的应用内购买配置同步到 App Store Connect。

<Steps>
  <Step title="进入 Publishing 的 Manage 面板">
    你会看到一个用于将 RevenueCat 同步到 App Store Connect 的按钮。

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-sync-btn-46a2e4e696df.png" alt="将 RevenueCat 同步到 App Store Connect 的按钮" width="1476" height="604" data-path="images/replitai/revenuecat-asc-sync-btn.png" />
    </Frame>

    <Tip>
      该部分仅在你将应用提交到 TestFlight 后才会显示。
    </Tip>
  </Step>

  <Step title="提供 App Store Connect API 密钥">
    你需要前往 App Store Connect 获取该密钥。

    在 [App Store Connect](https://appstoreconnect.apple.com/access/integrations/api) 中，进入 **Users and Access**，选择 **Integrations** 标签页，然后在侧边栏中选择 **App Store Connect API**。

    创建密钥时，请授予 “App Manager” 权限。

    请立即下载 .p8 文件——该文件只能下载一次。文件名以 `AuthKey_` 开头、以 `.p8` 结尾。

    复制页面上显示的 **Key ID** 和 **Issuer ID**。

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-create-c54be8304d7c.png" alt="App Store Connect 的 Users and Access 页面，用编号步骤突出显示 Integrations 标签页、App Store Connect API 侧边栏链接，以及用于创建新 API 密钥的加号按钮" width="2390" height="752" data-path="images/replitai/revenuecat-asc-create.png" />
    </Frame>

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-app-manager-93996acd8561.png" alt="App Store Connect 的 Generate API Key 对话框，名称设置为 RevenueCat，访问权限设置为 App Manager" width="1116" height="560" data-path="images/replitai/revenuecat-asc-app-manager.png" />
    </Frame>

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-copy-07a95e1be9af.png" alt="App Store Connect API 密钥页面，箭头指向 Issuer ID 的 Copy 链接和 Key ID 列" width="2330" height="780" data-path="images/replitai/revenuecat-asc-copy.png" />
    </Frame>
  </Step>

  <Step title="创建应用内购买 API 密钥">
    针对应用内购买 API 密钥重复上述步骤。
    在侧边栏中选择 **In-App Purchase**，然后以 **App Manager** 权限创建 API 密钥。
    下载 .p8 密钥 (文件名以 `SubscriptionKey_` 开头、以 `.p8` 结尾) ，并复制 **Key ID** 和 **Issuer ID**。

    <Frame>
      <img src="/assets/mirror/revenuecat-iap-api-key-7eb34e815ccb.png" alt="App Store Connect 的 Users and Access 页面，侧边栏中已选中 In-App Purchase，箭头指向用于创建新密钥的加号按钮" width="2272" height="637" data-path="images/replitai/revenuecat-iap-api-key.png" />
    </Frame>
  </Step>

  <Step title="同步商品">
    确认商品列表，并同步到 App Store Connect。

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-products-sync-078d42af83ba.png" alt="应用内购买管理对话框，显示包含价格、周期和地区字段的 Monthly Subscription 商品以及 “Sync to App Store Connect” 按钮" width="948" height="476" data-path="images/replitai/revenuecat-asc-products-sync.png" />
    </Frame>
  </Step>
</Steps>

<div id="section-5">
  ## 常见问题
</div>

<AccordionGroup>
  <Accordion title="使用 RevenueCat 需要银行账户吗？">
    不需要。创建 RevenueCat 账户只需邮箱地址和密码。银行账户则是在你准备好从 App Store 或 Google Play 收款时，另行通过 Apple 或 Google 设置。
  </Accordion>

  <Accordion title="测试购买会产生费用吗？">
    不会。开发期间，Replit 预览使用的是 RevenueCat 的测试模式，购买行为均为模拟，不会产生任何费用。只有在 Apple App Review 审核通过你的应用之后，才会产生真实扣款。
  </Accordion>

  <Accordion title="可以在网页应用中使用 RevenueCat 吗？">
    RevenueCat 专为原生移动应用设计。若要为网页应用添加订阅功能，请改用 [Stripe 集成](/zh/ja/features/monetization/stripe-payments)。
  </Accordion>

  <Accordion title="使用 RevenueCat 可以配置哪些内容？">
    你可以设置按月或按年的订阅、制定价格、管理权益 (entitlement) 以及搭建付费墙。需要调整时，直接告诉 Agent —— 它会同时处理 RevenueCat 配置和应用代码。
  </Accordion>
</AccordionGroup>
