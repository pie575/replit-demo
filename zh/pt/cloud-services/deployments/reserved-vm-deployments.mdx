title: "Reserved VM 部署"
description: "了解如何通过 Reserved VM 部署将你的 App 发布到始终运行的云服务器。"
---

Reserved VM 部署运行在虚拟机 (VM) 上，为
你的 App 提供专用计算资源。这类部署可提供稳定可预测的成本和性能，且不会中断。

它们非常适合以下使用场景：

* 内存密集型后台任务
* 需要保持连接的聊天机器人
* 始终运行的 API 服务器

<div id="recursos">
  ## 功能
</div>

Reserved VM 部署提供以下功能：

* **专用资源**：在预留计算资源上获得稳定的应用性能。
* **自定义域名**：配置自定义域名，或使用 `<nome-do-app>.replit.app` URL 访问你的应用。
* **计算资源选项**：选择满足应用性能需求的 VM 选项。
* **可配置端口映射**：指定应用要向互联网公开哪些端口。
* **监控**：查看日志并监控已部署应用的状态。

<div id="uso">
  ## 使用
</div>

您可以在 Project Editor 的 Publishing 工具中访问 Reserved VM 部署。

<Accordion title="如何访问 Reserved VM 部署">
  在左侧的**工具停靠栏**中：

  1. 选择 <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="所有工具图标" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**，查看 Project Editor 的工具列表。
  2. 选择 <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Publishing 图标" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publishing**。
  3. 选择 **Reserved VM**，然后选择 **Set up your published app**。

  在**搜索栏**中：

  1. 选择顶部的 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 放大镜图标，打开搜索工具。
  2. 输入“Publishing”以找到该工具，然后在搜索结果中选择它。
  3. 选择 **Reserved VM**，然后选择 **Set up your published app**。
</Accordion>

<div id="configurao-da-mquina">
  ### 机器配置
</div>

选择托管部署的机器的 CPU 和 RAM 配置。您可以在所选机器规格旁查看该配置的费用。

<div id="domnio-principal">
  ### 主域名
</div>

为已发布的 App 指定主机名的子域名部分。发布后，你可以通过 `https://<subdomain>.replit.app` 访问已发布的 App。

如需了解如何使用自定义域名，请参阅[自定义域名](/zh/features/publishing/custom-domains)。

<div id="deployment-privado">
  ### 私有部署
</div>

<Info>
  私有已发布 App 功能适用于 Pro 和 Enterprise 套餐。
</Info>

私有已发布 App 仅允许你的 workspace 成员，或你邀请的特定用户和群组访问。
发布时，你可以选择 **Public**、**Password protected**、**Workspace only** 或 **Invite only** 访问权限。

如需了解如何设置私有部署，请参阅 [App 访问权限](/zh/features/publishing/private-deployments/)。

<div id="build-command">
  ### Build 命令
</div>

在 **Build command** 字段中输入在执行 Run 命令前用于编译或配置 App 的 Shell 命令。
例如，要使用 Vite 为生产环境优化 JavaScript App，可以添加 `vite build` 命令。

<div id="run-command">
  ### Run 命令
</div>

在 **Run 命令** 字段中输入用于启动任务的 Shell 命令。该命令应与您在工作流程中使用的命令类似。例如，要启动名为“myApp”的 Flask App，您可以添加命令 `flask --app myApp run`。

<div id="secrets-do-app-publicado">
  ### 已部署应用的 Secrets
</div>

选择 **Add published app secret**，添加应用安全运行所需的环境变量或 Secrets。

如果您的 Replit App 包含环境变量或 Secrets，Publishing 会自动将其添加到列表中。

<div id="opes-de-tipo-de-app">
  ### App 类型选项
</div>

请选择以下选项之一：

* **Web server**：发布 Web 应用，或发布用户可通过互联网连接的应用时，请选择此选项。
* **Background worker**：如果您的应用不监听端口或不启动服务器，请选择此选项。

选择 **Web Server** 后，您可以按以下步骤自定义要对外暴露的端口：

1. 展开 **Port configuration** 部分。
2. 选择 **Networking pane to configure**，打开 **Networking** 选项卡，并在其中管理端口映射。

有关端口配置的更多信息，请参阅 [端口](/zh/pt/core-concepts/project-editor/app-setup/ports/)。
