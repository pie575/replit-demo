# Editor e Ferramentas

> Saiba mais sobre as ferramentas disponíveis no Editor de Projetos — o editor, Preview, Console, Shell e muito mais.

O Editor de Projetos inclui gerenciamento de layout e ferramentas integradas que potencializam sua experiência de criação de apps.
Esses recursos do Editor de Projetos são especializados em lidar com aspectos específicos do processo de desenvolvimento, permitindo que você
se concentre em criar em vez de configurar.

## Layout personalizável do Editor de Projetos

As ferramentas de gerenciamento de layout do Editor de Projetos permitem personalizar os componentes do ambiente de desenvolvimento.
Ele consiste nos seguintes tipos de elementos de interface:

| Elemento    | Descrição                                                                                           | Funcionalidades                                                                                                                                                               | Casos de Uso                                                                                                                      |
| ----------- | --------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| **Janelas** | Abas do navegador que contêm um ou mais painéis                                                     | <ul><li>Podem ser organizadas em várias telas</li></ul>                                                                                                                       | <ul><li>Organizar o Editor de Projetos em várias telas</li><li>Trabalhar em diferentes projetos simultaneamente</li></ul>         |
| **Painéis** | Seções de uma janela que contêm uma ou mais abas                                                    | <ul><li>Suportam divisão horizontal e vertical</li><li>Podem ser redimensionados e reorganizados</li><li>Podem ser convertidos em painel flutuante dentro da janela</li></ul> | <ul><li>Ver código e prévia lado a lado</li><li>Criar layouts personalizados para diferentes tarefas de desenvolvimento</li></ul> |
| **Abas**    | Contêm exatamente uma ferramenta do Editor de Projetos, como o editor de arquivos, Preview ou Agent | <ul><li>Podem ser movidas entre painéis e reordenadas dentro deles</li><li>Permitem alternar entre diferentes arquivos ou ferramentas com um único clique</li></ul>           | <ul><li>Abrir diferentes ferramentas ou arquivos quando necessário</li></ul>                                                      |

## Árvore de arquivos

A árvore de arquivos lista todos os arquivos e diretórios do seu Replit App.

<Accordion title="Como acessar a árvore de arquivos">
  Selecione o ícone <img class="icon-svg" src="https://mintcdn.com/replit/rJldsgYVucXB_6kW/images/icons/files-icon.svg?fit=max&auto=format&n=rJldsgYVucXB_6kW&q=85&s=4b9ac8b70c07960d9f9a3f6eacee4ab6" alt="ícone de pasta com setas" width="16" height="16" data-path="images/icons/files-icon.svg" /> na esquerda para alternar
  a visibilidade da árvore de arquivos.
</Accordion>

Você pode realizar as seguintes ações na árvore de arquivos:

* Selecionar uma pasta para exibir seu conteúdo
* Selecionar um arquivo ou arrastá-lo para um painel para abri-lo no editor de arquivos
* Realizar operações de arquivo como duplicar, renomear, mover, baixar ou excluir

## Botão Executar

O botão **Executar** executa o workflow selecionado do Replit App.

<Accordion title="Como acessar o botão Executar">
  O botão **Executar** está localizado na parte superior da tela do Editor de Projetos. Selecione o botão para executar o workflow.

  Quando seu Replit App estiver em execução, o rótulo do botão é substituído por **Parar**. Selecione o botão para parar o app.
</Accordion>

Para saber como selecionar, visualizar e gerenciar workflows, veja [Workflows](/pt/core-concepts/project-editor/app-setup/workflows/).

## Menu de opções

O menu de opções permite realizar os seguintes tipos de ações de layout:

* **Gerenciamento de janelas**: Abrir o Editor de Projetos do Replit App em uma nova janela
* **Gerenciamento de painéis**: Adicionar painéis, mover um painel, maximizar um painel e alternar entre posições flutuante e fixa
* **Gerenciamento de abas**: Abrir ou selecionar outras abas, mover uma aba para outro painel e fechar uma aba

<Accordion title="Como acessar o menu de opções">
  Selecione os <img class="icon-svg" src="https://mintcdn.com/replit/X_IP1EeHGm0cA2VA/images/icons/vertical-dots.svg?fit=max&auto=format&n=X_IP1EeHGm0cA2VA&q=85&s=7b4b6a9992b3b20202297b60b6ef416d" alt="ícone de três pontos verticais" height="16" width="16" data-path="images/icons/vertical-dots.svg" /> três pontos verticais
  localizados no canto superior direito da aba ativa para abrir o menu de opções.
</Accordion>

## Painel de recursos

O painel de recursos exibe os recursos de computação e o uso do seu ambiente de desenvolvimento, incluindo RAM, CPU e armazenamento.
Essas informações podem ajudá-lo a estimar e otimizar os requisitos de publicação do seu Replit App.

<Accordion title="Como acessar o painel de recursos">
  1. Selecione o ícone de <img class="icon-svg" src="https://mintcdn.com/replit/rJldsgYVucXB_6kW/images/icons/resources.svg?fit=max&auto=format&n=rJldsgYVucXB_6kW&q=85&s=8df05261182e3e39f28dcccf809d66c2" alt="ícone de computadores empilhados" width="16" height="16" data-path="images/icons/resources.svg" /> recursos localizado ao lado do nome do seu app para alternar o painel.
  2. Passe o mouse sobre os itens **Computação** ou **Armazenamento** para mais detalhes.
</Accordion>
