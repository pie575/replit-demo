라이브러리 패널은 Replit Design에 기본 내장된 시작점이자 참고 자료 모음입니다. **Templates**, **Inspiration**, **Library** 세 개의 탭으로 구성되어 있습니다. 이 패널에서 새 project가 만들어지지는 않으며, 모든 항목은 현재 작업 중인 project의 canvas에 추가됩니다.

<div id="templates">
  ## Templates
</div>

Replit이 미리 만들어 둔 디자인 frame으로, 검색할 수 있고 종류별로 묶여 있습니다. 포스터, 소셜 게시물, landing page, 모바일, 배너, 프로토타입이 있습니다. 원하는 항목을 클릭하거나 드래그해 디자인에 추가하세요. Canvas에 라이브 frame으로 배치되며, 직접 생성한 frame과 똑같이 바로 편집할 수 있습니다.

<div id="inspiration">
  ## Inspiration
</div>

Mobbin이 선별한 실제 제품의 UI 스크린샷입니다. *&quot;Airbnb onboarding&quot;*이나 *&quot;Coinbase checkout&quot;*처럼 앱 화면을 검색한 뒤 원하는 항목을 클릭하면 정적 참조 이미지로 Canvas에 배치됩니다. Inspiration은 project에 코드를 추가하지 않습니다. 눈으로 보고, Chat에서 가리키거나, 다음 생성 작업에서 참고하는 용도입니다.

<div id="library">
  ## Library
</div>

내가 만든 결과물: 이 project에서 이미 만든 디자인와 artifacts로, 언제든지 Canvas로 다시 가져올 수 있습니다.

<div id="templates-vs-inspiration">
  ## Templates와 Inspiration 비교
</div>

|          | Templates                   | Inspiration                        |
| -------- | --------------------------- | ---------------------------------- |
| 개요       | Replit이 만든 스타터 design frame | Mobbin에서 가져온 실제 제품의 UI 스크린샷 |
| Canvas에서 | 디자인 안에서 바로 편집할 수 있는 frame   | 정적 참조 이미지                         |
| 활용 방법    | 완성된 디자인에서 시작하기              | 다음 생성 결과의 스타일 유도하기(Steer)          |
