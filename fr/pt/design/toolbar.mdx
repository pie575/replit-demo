La barre d’outils Canvas est une barre flottante ancrée en bas au centre du Canvas. Elle regroupe les outils permettant de naviguer, dessiner, modifier et ajouter du contenu. La barre d’outils s’affiche en mode Canvas.

<div id="ferramentas">
  ## Outils
</div>

Sélectionner un outil l’active. L’outil actif est mis en évidence par un fond coloré. Le groupe situé le plus à gauche est dédié à la navigation (Interact, Pan). Les autres sont des outils de contenu et d’annotation. Les outils sont mutuellement exclusifs : en sélectionner un désactive les autres.

<div id="interact">
  ### Interact
</div>

**Interact** est l’outil par défaut. Utilisez-le pour sélectionner des frames, les faire glisser et cliquer sur un Artifact actif afin de l’utiliser comme une véritable app en cours d’exécution. Lorsque l’outil Interact est actif, cliquez sur un frame pour le sélectionner et afficher la [barre d’actions par frame](/fr/pt/design/frames#per-frame-action-bar).

<Frame>
  <img src="/assets/mirror/canvas-interact-4472dae3de09.png" alt="Canvas avec un artifact de site web sélectionné à l’aide de l’outil Interact — le frame est entouré de poignées de sélection et la barre d’actions par frame s’affiche au-dessus. L’outil Interact est mis en évidence dans la barre d’outils flottante en bas." width="3450" height="2000" data-path="images/replitai/canvas-interact.png" />
</Frame>

**Raccourci clavier :** `V`. **Disponibilité :** toujours actif.

<div id="pan">
  ### Pan
</div>

**Pan** transforme le curseur en outil de déplacement pour vous permettre de déplacer le Canvas lui-même. Lorsque Pan est actif, cliquer et faire glisser déplace la zone d’affichage au lieu de sélectionner un frame. Vous pouvez également vous déplacer dans le Canvas depuis n’importe quel autre outil en maintenant la barre d’espace enfoncée et en faisant glisser, ou en faisant glisser avec le bouton central de la souris.

<Frame>
  <img src="/assets/mirror/canvas-pan-9f07d3bf72a3.png" alt="Canvas avec l’outil Pan actif — un artifact de site web (Velocity — Supercar Rental) et une maquette Design (Velocity — Home (Mockup)) sont visibles sur le Canvas, et l’outil Pan (curseur en forme de main) est mis en évidence dans la barre d’outils flottante en bas." width="1725" height="1041" data-path="images/replitai/canvas-pan.png" />
</Frame>

**Raccourci clavier :** `H`. **Disponibilité :** toujours actif.

<div id="chat">
  ### Chat
</div>

**Chat** place un petit champ de discussion directement dans le Canvas afin que vous puissiez envoyer des prompts à Agent sans quitter le Canvas. Les éléments et frames sélectionnés restent joints au message sous forme de captures d’écran, comme lors d’un envoi depuis le panneau de chat latéral d’Agent.

<Frame>
  <img src="/assets/mirror/canvas-chat-d28e2d8f216a.png" alt="Canvas en mode Chat, avec le reste du Canvas assombri et un champ de discussion intégré superposé à un artifact de site Web. Une pastille « div » dans le champ de discussion indique un élément sélectionné, et le prompt indique « suggérer trois alternatives à cette image ». L’outil Chat est mis en évidence dans la barre d’outils flottante en bas." width="3450" height="2000" data-path="images/replitai/canvas-chat.png" />
</Frame>

**Disponibilité :** outil Chat (ordinateur de bureau uniquement).

<div id="draw">
  ### Draw
</div>

**Draw** active les outils d’annotation, comme le dessin à main levée, les flèches, les notes adhésives et les formes, afin que vous puissiez dessiner sur les frames ou annoter le Canvas. Utilisez-le pour entourer les zones problématiques, indiquer les éléments que vous souhaitez modifier ou ajouter une note à côté d’un frame.

Lorsque Draw est actif, une barre **Shape properties** apparaît au-dessus de la barre d’outils flottante, avec des commandes de couleur, de trait et de remplissage pour l’outil d’annotation sélectionné. Elle est automatiquement masquée lorsque vous revenez à Interact ou Pan.

<Frame>
  <img src="/assets/mirror/canvas-draw-d2d9b6556cde.png" alt="Canvas avec l’outil Draw actif — un rectangle « Widget » dessiné et une note adhésive violette « Add a widget » sont placés à côté d’un frame. La barre Shape properties (outils crayon, texte, rectangle, flèche et note adhésive, ainsi que des échantillons de couleur et un contrôle de la taille du texte Aa) est affichée au-dessus de la barre d’outils flottante, avec Draw mis en évidence." width="1725" height="1041" data-path="images/replitai/canvas-draw.png" />
</Frame>

**Disponibilité :** toujours active.

<div id="edit">
  ### Edit
</div>

**Edit** est le sélecteur visuel d’éléments. Lorsque Edit est actif, cliquez dans un artifact actif pour cibler un élément (un bouton, un titre, une image). La sélection d’un élément ouvre le **Visual Editor** — un panneau de contrôles à droite (Mise en page, Couleur, Bordure et bien plus), associé à un prompt intégré permettant de demander à Agent de ne modifier que cette partie. Consultez [Elements](/fr/pt/design/elements) et [Visual Editor](/fr/pt/design/visual-editor) pour découvrir le flux de travail complet.

<Frame>
  <img src="/assets/mirror/canvas-edit-67fe5ee02fbe.png" alt="L’outil Edit actif sur un site de location de supercars, avec un élément div sélectionné et le panneau Visual Editor affichant les contrôles Texte, Mise en page, Couleur et Bordure, ainsi que les boutons Abandonner et Enregistrer les modifications" width="2000" height="1269" data-path="images/replitai/canvas-edit.png" />
</Frame>

**Disponibilité :** toujours active (ordinateur). Désactivée jusqu’à ce qu’au moins une frame existe ; l’infobulle affiche *&quot;Créez un artifact ou générez un design à modifier.&quot;* Masquée sur les appareils mobiles.

<div id="generate">
  ### Generate
</div>

**Generate** ouvre la fenêtre contextuelle **Generate media** pour les images, les vidéos et les graphiques vectoriels. Choisissez un type, rédigez un prompt et Agent ajoute le résultat sous forme de nouveau frame sur le Canvas.

<Frame>
  <img src="/assets/mirror/canvas-add-menu-5d97d9c813e1.png" alt="Le menu + Add du Canvas est ouvert avec quatre options empilées verticalement : Design (« Mock up interfaces and visual concepts »), Image (« Generate and edit images »), Video (« Generate motion clips and animations ») et Vector Graphic (« Generate vector illustrations and SVGs »). La zone Generate de la barre d’outils flottante en bas affiche désormais « + Generate »." width="1102" height="702" data-path="images/replitai/canvas-add-menu.png" />
</Frame>

La fenêtre contextuelle comporte quatre onglets en haut :

* **Design**
  — **Image**
* **Video**
* **Vector Graphic**

Certains contrôles sont communs à tous les types, tandis que d’autres sont spécifiques à chaque type.

**Contrôles communs à tous les types :**

* **Model** : le modèle de génération à utiliser. Les modèles disponibles varient selon le type (voir le tableau ci-dessous).
* **Prompt** : description en langage naturel de ce que vous souhaitez qu’Agent génère.
* **Generate** : envoie la demande et crée un frame temporaire à la position du curseur. Ce frame devient actif dès que le média est prêt ; si la génération échoue, il est supprimé et une erreur apparaît dans le panneau Chat.

**Modèles et contrôles par type :**

| Type        | Idéal pour                                                                                                             | Modèles actuels                                                 | Contrôles spécifiques au type                                                                   |
| ----------- | ---------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| **Image**   | Sortie raster (PNG / JPG) ; images pour planches d’inspiration, visuels de mise en avant et illustrations de référence | Nano Banana, Nano Banana 2, Nano Banana Pro, ChatGPT Images 2.0 | Format (`1:1`, `16:9`, `9:16`, `4:3`, `3:4`) · Taille (`1K`, `2K`, `4K`)                        |
| **Video**   | Courtes vidéos et animations                                                                                           | Veo 3.1, Seedance 2.0                                           | Format · Résolution (p. ex. `720p`) · Durée (p. ex. `4s`) · Activation/désactivation de l’audio |
| **Graphic** | Sortie vectorielle SVG ; icônes, logos, diagrammes et illustrations stylisées                                          | Claude 4.6 Opus, Gemini 3.1 Pro Preview                         | Activation/désactivation de l’animation                                                         |

<Note>
  La liste des modèles évolue fréquemment. Le tableau reflète les modèles actuellement disponibles ; consultez le menu déroulant dans le produit pour voir ceux auxquels votre compte a accès.
</Note>

Pour en savoir plus sur chaque type de frame et sur ce que vous pouvez faire après sa création, consultez [Frames](/fr/pt/design/frames).

<div id="anexe-referncias-visuais">
  #### Ajoutez des références visuelles
</div>

Avant de générer, vous pouvez ajouter des éléments déjà présents sur votre Canvas comme références visuelles. Agent utilise ces références pour orienter le résultat afin qu’il corresponde à l’apparence de votre projet. Ouvrez le menu **+** dans le formulaire **Generate media** et choisissez une option :

* **Upload file** : téléversez une image depuis votre ordinateur pour l’utiliser comme référence.
* **Select canvas elements** : choisissez des éléments existants sur le Canvas. Les frames sont capturées sous forme de captures d’écran ; les formes de texte et les notes sont ajoutées sous forme de résumés textuels.

Chaque référence apparaît sous forme de pastille dans le formulaire. Ajoutez-en autant que nécessaire, rédigez votre prompt et sélectionnez **Generate**. Pour supprimer une référence, sélectionnez la pastille.

<Frame caption="Le formulaire Generate media avec le menu + ouvert, affichant Upload file et Select canvas elements.">
  <img src="/assets/mirror/canvas-generate-media-references-ac0cb4340acb.png" alt="Le formulaire Generate media dans Canvas avec le menu plus ouvert, affichant les options Upload file et Select canvas elements ainsi que le menu déroulant de modèle défini sur Nano Banana Pro" width="1134" height="662" data-path="images/replitai/canvas-generate-media-references.png" />
</Frame>

<Note>
  ChatGPT Images 2.0 ne prend actuellement pas en charge les téléversements. Changez de modèle, par exemple pour Nano Banana Pro, afin d’ajouter des références visuelles.
</Note>

Lorsque le **Add menu** est activé, le bouton Generate est remplacé par un menu **+** qui regroupe les types de fenêtres contextuelles de **Design** (une maquette visuelle indépendante qui n’affecte pas le code actif) :

**Disponibilité :** génération d’images. **Vector Graphic** nécessite la génération de graphiques vectoriels ; **Video** nécessite la génération de vidéos. Le menu **+** nécessite le Add menu (qui nécessite lui-même la génération d’images).

<div id="navegao-no-quadro">
  ## Navigation sur le Canvas
</div>

Le panoramique, le zoom, les gestes de sélection et les raccourcis clavier associés sont des interactions propres au Canvas, et non des outils de la barre d’outils. Consultez la section [Naviguer sur le Canvas](/fr/pt/design/canvas#navigate-the-board) de la page Canvas.
