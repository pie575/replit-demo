Replit의 테마를 사용하면 배경 색상과 UI 요소부터 코드의 구문 강조까지 Project Editor의 겉모습을 원하는 대로 바꿀 수 있습니다. 개발 환경을 나에게 맞게 꾸며 가독성을 높이고 눈의 피로를 줄이며 더 즐겁게 코딩해 보세요.

<div id="creating-a-custom-theme">
  ## 커스텀 테마 만들기
</div>

다음 단계에 따라 나만의 테마를 만들고 커스터마이징하세요.

1. [Settings](https://replit.com/settings)를 열고 **User** → **Personalization**(또는 **Themes** 섹션)으로 이동합니다
2. **Create new 테마**을 선택합니다
3. 제목을 입력하고 색 구성(라이트 또는 다크)을 선택한 뒤, 필요하면 설명을 추가합니다
4. **Create 테마**을 선택해 Themes Editor를 엽니다

전역 테마 설정은 UI 전반의 모양을 제어합니다.

* **Background**: 대부분의 UI 영역에 사용되는 기본 색을 지정합니다
* **Outline**: 테두리와 구분선의 색을 제어합니다
* **Foreground**: 텍스트와 icon 색을 결정합니다
* **Primary**: 버튼과 인터랙티브 요소의 색을 정의합니다
* **Positive**: **Run** 버튼처럼 성공을 나타내는 요소에 적용됩니다
* **Negative**: 오류 및 되돌릴 수 없는 작업에 대한 경고에 표시됩니다

**Apply 테마**을 선택하면 커스텀 테마를 바로 사용할 수 있습니다.

<div id="syntax-highlighting">
  ## 구문 강조
</div>

가독성과 이해도를 높일 수 있도록 코드 요소별 표시 방식을 원하는 대로 설정하세요.

<Tip>
  구문 강조가 잘 설정되어 있으면 코드를 한눈에 훑어보고 파악하기 쉽습니다. 서로 잘 어울리면서 배경과 충분한 대비를 이루는 색상을 선택하세요.
</Tip>

<Accordion title="구문 강조 요소">
  | 요소                       | 설명                                              |
  | ------------------------ | ----------------------------------------------- |
  | **Variable Names**       | 선언 키워드를 사용하지 않은 변수에 적용됩니다                       |
  | **Variable Definitions** | `const`나 `var` 같은 키워드로 정의된 변수 이름에 색상을 지정합니다     |
  | **Function References**  | 함수를 호출할 때 적용됩니다                                 |
  | **Function Definitions** | 선언 시 함수 이름에 색상을 지정합니다                           |
  | **Keywords**             | `import`, `function`, `return` 같은 언어 키워드를 강조합니다 |
  | **Property Names**       | 변수에서 접근하는 속성에 색상을 지정합니다                         |
  | **Property Definitions** | 객체 속성을 정의할 때 사용됩니다                              |
  | **Function Properties**  | 객체의 메서드를 호출할 때 적용됩니다                            |
  | **Tag Names**            | HTML 및 JSX 태그에 사용됩니다                            |
  | **Type Names**           | 타입이 있는 언어에서 타입 주석에 색상을 지정합니다                    |
  | **Class Names**          | 클래스 선언 및 참조에 적용됩니다                              |
  | **Attribute Names**      | HTML 및 JSX 속성을 강조합니다                            |
  | **Comments**             | 모든 코드 주석에 적용됩니다                                 |
  | **Strings**              | 문자열 리터럴에 색상을 지정합니다                              |
  | **Numbers**              | 숫자 값을 강조합니다                                     |
  | **Booleans**             | 불리언 값(`true`/`false`)의 서식을 지정합니다                |
  | **Regular Expressions**  | 정규식 패턴에 색상을 지정합니다                               |
  | **Operators**            | `+`, `-`, `*`, `/` 같은 연산자를 강조합니다                |
  | **Brackets**             | 필요한 경우 대괄호와 꺾쇠괄호에 색상을 지정합니다                     |
</Accordion>

<div id="theme-design-best-practices">
  ## 테마 디자인 모범 사례
</div>

다음 가이드라인에 따라 시각적으로 매력적이면서 실용적인 테마를 만들어 보세요.

<div id="color-and-contrast">
  ### 색상과 대비
</div>

* **대비 균형 맞추기**: 배경과 전경 요소 간에 충분한 차이를 두세요
* **조화로운 팔레트 구성하기**: 서로 충돌하지 않고 어울리는 색상을 선택하세요
* **일관된 밝기 유지하기**: 구문 요소 전반에서 비슷한 밝기를 유지하세요
* **접근성을 고려한 설계**: 대비가 낮은 조합을 피해 시각 장애가 있는 사용자를 배려하세요

<Warning>
  피해야 할 대표적인 테마 디자인 문제:

  * 구문 요소 간 지나치게 큰 밝기 차이
  * 시각적 부조화를 일으키는 어울리지 않는 색상
  * 코드와 배경 간 대비 부족
</Warning>

<div id="managing-your-themes">
  ## 테마 관리하기
</div>

설치한 모든 테마는 [Settings](https://replit.com/settings)의 **User** → **Personalization**(또는 **Themes** 섹션)에서 확인하고 관리할 수 있습니다.

<div id="switching-themes">
  ### 테마 전환하기
</div>

테마 이름 옆에 있는 버튼을 선택하면 해당 테마가 현재 테마로 적용됩니다.

<div id="editing-themes">
  ### 테마 편집
</div>

점 세 개 메뉴를 선택한 다음 **Edit**을 클릭해 커스텀 테마를 수정합니다.

<Note>
  직접 만든 커스텀 테마만 편집하거나 삭제할 수 있습니다. 기본 테마와 다른 사용자가 만든 테마는 수정할 수 없습니다.
</Note>

<div id="deleting-themes">
  ### 테마 삭제
</div>

점 세 개 메뉴에서 **Delete**를 선택해 커스텀 테마를 삭제합니다.

<div id="exploring-community-themes">
  ## 커뮤니티 테마 둘러보기
</div>

[Themes Explore Page](https://replit.com/themes)에서 Replit 커뮤니티가 만든 테마를 만나보세요.

<div id="finding-themes">
  ### 테마 찾기
</div>

* 이름으로 검색해 &quot;Atom One Dark&quot; 같은 특정 테마 찾기
* 작성자로 filter를 걸어 특정 제작자의 테마 살펴보기
* color scheme별로 둘러보며 밝은 테마 또는 어두운 테마 찾기
* 특정 color로 검색해 취향에 맞는 테마 찾기

설치하기 전에 테마를 Preview로 확인해 Project Editor에서 어떻게 보일지 미리 살펴보세요.

<div id="publishing-your-theme">
  ## 테마 게시하기
</div>

다음 단계에 따라 직접 만든 커스텀 테마을 Replit 커뮤니티에 공유해 보세요.

1. 커스텀 테마의 Themes Editor를 엽니다
2. **Publish** 버튼을 선택합니다
3. 제목과 설명 필드를 입력합니다
4. 테마를 제출합니다

게시가 완료되면 테마가 Themes Explore Page에 표시되며, 다른 사용자가 미리 보고 설치할 수 있습니다.
