Les modèles d’IA comme Claude et GPT sont puissants, mais ils restent limités à ce sur quoi ils ont été entraînés. Le Model Context Protocol (MCP) leur offre un moyen standardisé de se connecter à des outils externes, à des sources de données et à des fonctionnalités du monde réel.

<div id="por-que-os-modelos-de-ia-precisam-do-mcp">
  ## Pourquoi les modèles d’IA ont besoin du MCP
</div>

Sans accès à des outils et à des données externes, les modèles d’IA ne peuvent pas :

* Accéder à des informations à jour
* Interagir avec des systèmes externes
* Exécuter des actions dans le monde réel
* Travailler avec vos données privées

Le MCP résout ce problème en fournissant un moyen universel pour l’IA de se connecter à des outils et à des données, à l’instar de l’USB-C qui a standardisé les connexions entre appareils.

  <img src="/assets/mirror/mcp-a04e01a01743.avif" alt="Diagramme MCP montrant des modèles d’IA se connectant à des outils externes et à des sources de données" width="1920" height="1055" data-path="images/tutorials/mcp.avif" />
</Frame>

Avec le MCP, les modèles d’IA peuvent :

* Accéder à des outils et API spécialisés
* Consulter des sources de données privées
* Exécuter des actions dans le monde réel
* Se connecter facilement à d’autres systèmes

<div id="como-o-mcp-funciona">
  ## Comment fonctionne MCP
</div>

L’architecture MCP comporte trois composants principaux :

1. **Le côté client** — des modèles d’IA comme Claude ou des applications qui doivent accéder à des outils externes.
2. **La couche de communication** — le protocole lui-même, qui standardise le format des requêtes et des réponses.
3. **Le côté serveur** — des programmes qui donnent accès à des outils, des sources de données et des fonctionnalités spécialisées.

<AccordionGroup>
  <Accordion title="Qu’est-ce qu’un client MCP ?">
    Un client MCP peut être Claude, Replit Agent ou une interface en ligne de commande connectée à un grand modèle de langage. C’est l’« outil » qui se connecte à des outils ou à des sources de données externes.

    Exemples de clients MCP :

    * Claude dans le navigateur
    * Replit Agent
    * Interfaces en ligne de commande pour l’IA
    * Applications personnalisées créées avec des SDK d’IA
  </Accordion>

  <Accordion title="Qu’est-ce qu’un serveur MCP ?">
    Un serveur MCP fournit des outils et des fonctionnalités aux modèles d’IA. C’est comme donner à l’IA un ensemble d’outils spécialisés pour résoudre des problèmes.

    Exemples de ce que permettent les serveurs MCP :

    * Accéder à des sources de données spécifiques pour répondre à des questions
    * Connecter l’IA à des API afin qu’elle puisse effectuer des actions en ligne
    * Lire ou écrire des fichiers
    * Effectuer des calculs ou exécuter du code
    * Obtenir du contenu depuis des services comme Notion, Linear ou Stripe
  </Accordion>
</AccordionGroup>

<div id="o-que-o-mcp-desbloqueia">
  ## Ce que le MCP permet
</div>

Le MCP définit plusieurs primitives qui le rendent particulièrement utile pour les applications d&#39;IA :

* **Resources** — partager des données et du contenu avec des modèles d&#39;IA
* **Tools** — permettre aux modèles d&#39;IA d&#39;exécuter des actions via vos services
* **Prompts** — templates réutilisables pour des interactions d&#39;IA cohérentes
* **Sampling** — permettre à vos services de demander des informations aux modèles d&#39;IA
* **Transports** — connecter efficacement les clients et les serveurs

<div id="skills-vs-servidores-mcp">
  ## Compétences vs. serveurs MCP
</div>

Les compétences et les serveurs MCP sont les deux principaux moyens d’étendre les agents d’IA, mais ils remplissent des rôles différents.

|                | Compétences                                                                                 | Serveurs MCP                                                               |
| -------------- | ------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| **Idéal pour** | Flux de travail, conventions, documents de référence                                        | Se connecter à des services externes, effectuer des actions                |
| **Chargement** | Léger — seul le nom et la description sont chargés jusqu’à l’invocation                     | Plus lourd — toutes les descriptions d’outils sont chargées à l’avance     |
| **Définit**    | *Comment* votre agent doit fonctionner                                                      | *À quoi* votre agent peut accéder                                          |
| **Exemple**    | Compétence « Stock Analyzer » — recherchez des investissements avec un framework spécifique | Serveur MCP « Stripe » — consultez les données de paiement et d’abonnement |

Consultez [Compétences Agent](/fr/pt/learn/agent-skills) pour en savoir plus sur l’approche associée aux compétences.

<div id="aplicaes-no-mundo-real">
  ## Applications concrètes
</div>

Le MCP permet de créer un large éventail d&#39;applications d&#39;IA :

* **Systèmes de service client** qui accèdent aux bases de données d&#39;entreprise pour répondre à des questions précises
* **Assistants de recherche** qui effectuent des recherches et résument des contenus provenant de multiples sources
* **Outils de productivité** qui interagissent avec vos fichiers et vos applications
* **Outils de création de contenu** qui accèdent à des bibliothèques multimédias et à des plateformes de publication

<div id="benefcios">
  ## Avantages
</div>

MCP offre trois avantages principaux :

* Des intégrations prêtes à l’emploi auxquelles votre IA peut se connecter immédiatement
* La possibilité de passer d’un fournisseur d’IA à un autre sans réécrire vos connexions
* Des fonctionnalités de sécurité qui protègent vos données sensibles

<Note>
  MCP est une norme émergente, de plus en plus prise en charge dans l’ensemble de l’écosystème de l’IA. De nouveaux outils et intégrations sont ajoutés régulièrement.
</Note>
