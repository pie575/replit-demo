**元素**是 frame 中的独立组成部分，例如标题、按钮、图片、表单字段，或 frame 渲染的任何其他组件。当你想修改 frame 的某个部分，而无需重新生成整个 frame 时，选择的就是元素。

<div id="selecionando-um-elemento">
  ## 选择元素
</div>

使用工具栏中的 [Edit 工具](/zh/pt/design/toolbar#edit)。启用 Edit 后，点击活动 frame 内的元素即可将其选中。选中的元素会显示高亮边框，并附带一个小型内联 prompt，你可以通过它要求 Agent 进行修改。

<Note>
  Canvas 中至少有一个 frame 后才能使用 Edit，且该功能仅支持桌面端。
</Note>

<div id="agindo-sobre-um-elemento-selecionado">
  ## 对选中的元素执行操作
</div>

<div id="pea-ao-agent-para-alter-lo">
  ### 让 Agent 修改它
</div>

使用内联 prompt，让 Agent 更新元素的文本、颜色、布局、间距或行为。

  <img src="/assets/mirror/canvas-ask-element-53f7468a07d3.png" alt="Canvas 中所选元素的内联 prompt：一个“img”标签，后面是占位文本“询问所选元素……”和发送按钮。" width="1500" height="500" data-path="images/replitai/canvas-ask-element.png" />
</Frame>

<div id="trocar-uma-imagem-diretamente">
  ### 直接替换图片
</div>

选择图片元素后，Visual Editor 的 **Image** 部分会显示图片源路径和 **Upload Image** 按钮，让你无需编写 prompt 即可替换文件。

<div id="visual-editor">
  ## Visual Editor
</div>

选择元素后，会打开 **Visual Editor**——位于右侧、与内联 prompt 搭配使用的面板。该面板将控件归类为清晰的栏目，方便你更快找到所需内容：**Text**、**Layout**、**Color** 和 **Border**。 (选择图片元素时，还会显示 **Image** 栏目。)

  <img src="/assets/mirror/canvas-element-panel-c8972fab0448.png" alt="Canvas 中选中了一个 div 元素（McLaren 预订侧边栏）。右侧的 Visual Editor 面板显示 Text（字号 16、字重 Regular、对齐方式）、Layout（外边距：底部为 24px；内边距：20/20，带联动开关）和 Color（文本 #e4e4e7、背景 #0f0f12）栏目。" width="2000" height="1252" data-path="images/replitai/canvas-element-panel.png" />
</Frame>

<div id="layout">
  ### Layout
</div>

**Layout** 部分可让你无需借助 Agent，直接调整子元素在容器中的排列方式。选择一个弹性布局容器并展开 Layout，你将看到：

* **对齐**：一个 3×3 点位选择器，用于设置项目在容器内两个轴向上的位置。
* **方向**：两个箭头按钮，用于将子元素按行或按列排列。
* **间距 (Gap)**：用于设置项目之间间距的像素值。Gap 字段旁的图标会随当前方向变化，让你始终了解调整的是水平还是垂直间距。旁边的箭头图标可切换 **在项目之间分配空间**，将子元素推向容器相对的边缘。
* **外边距**：用于设置元素外部间距的各边字段 (每边一个字段，并提供关联切换开关，可一次锁定四条边) 。
* **内边距**：用于设置元素内部各轴向间距的字段，并提供关联切换开关，可一次设置两个轴向。

仅当所选元素至少适用一个布局控件时，Layout 部分才会显示。没有间距或布局属性的纯文本节点会完全隐藏该部分，以保持编辑器简洁。

有关 **Text**、**Color**、**Border** 和 **Image** 部分，请参阅 [Visual Editor 指南](/zh/pt/design/visual-editor)。
