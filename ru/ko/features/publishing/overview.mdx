Инструмент публикации — это место, где вы разворачиваете приложение и управляете тем, как оно работает в вебе. Он объединяет в одной панели веб-адрес приложения, права доступа, продакшн-базу данных, мониторинг, безопасность и настройки, определяющие способ хостинга.

Чтобы открыть эту панель, выберите **Publishing** в разделе **Replit Cloud** панели **Tools** или нажмите **Publish** в правом верхнем углу Project Editor.

<div id="section">
  ## Публикация приложения
</div>

Главная панель проведёт вас по всем шагам, необходимым для публикации приложения. Проверьте каждый раздел, а затем выберите **Publish**.

<Frame>
  <img src="/assets/mirror/publish-your-app-851815208b8a.png" alt="Панель Publish your app с полем Domain, публикуемым приложением, настройками доступа, настройками базы данных, мониторингом, безопасностью и инструментами вовлечения над кнопкой Publish" width="578" height="980" data-path="images/deployments/publish-pane/publish-your-app.png" />
</Frame>

* **Domain**: веб-адрес вашего приложения. Replit предлагает имя в зоне `.replit.app` и проверяет, свободно ли оно. После публикации этот адрес можно изменить или подключить [собственный домен](/ru/ko/features/publishing/custom-domains).
* **What you&#39;re publishing**: показывает предпросмотр публикуемого приложения и URL, который будет использоваться.
* **Who can access your app**: выберите один из вариантов — **Public**, **Password protected**, **Workspace only** или **Invite only**. Закрытые варианты ограничивают использование приложения участниками рабочего пространства либо приглашёнными пользователями и группами. Подробнее — в разделе [Доступ к приложению](/ru/ko/features/publishing/private-deployments).
* **Database settings**: управление тем, как при публикации создаётся и наполняется данными продакшн-база данных приложения. Подробнее о [продакшн-базах данных](/ru/ko/features/data-and-storage/development-and-production).
* **Monitoring tools**: включите мониторинг приложения, чтобы первыми узнавать о его недоступности. Replit постоянно проверяет, находится ли приложение в сети, и уведомляет вас по электронной почте при возникновении проблем. Подробнее о [мониторинге приложения](/ru/ko/features/publishing/monitoring-a-deployment).
* **Security tools**: запуск углублённого сканирования безопасности перед публикацией. Security Agent сочетает ИИ и лучшие в своём классе инструменты статического анализа, чтобы проверить проект на уязвимости. Подробнее — в [Project Security Center](/ru/ko/features/security/project-security-center).
* **Engagement tools**: при включении виджета обратной связи в углу опубликованного приложения появляется кнопка обратной связи. Отправленные отзывы можно просматривать во входящих и передавать Agent для исправлений.

<div id="section-2">
  ## Настройка параметров
</div>

Выберите **Настроить параметры**, чтобы вручную настроить хостинг приложения. Большинству разработчиков не нужно менять эти параметры — Replit подберёт подходящие значения по умолчанию.

<Frame>
  <img src="/assets/mirror/adjust-settings-d6e124b2249f.png" alt="Раздел «Настроить параметры» с типом деплоя, конфигурацией машины, секретами деплоя, регионом деплоя и переключателем блокировки публикации при критических уязвимостях" width="574" height="794" data-path="images/deployments/publish-pane/adjust-settings.png" />
</Frame>

* **Тип деплоя**: технология, используемая для публикации приложения. **Autoscale** рекомендуется для большинства приложений, поскольку автоматически масштабируется от нулевого трафика до любого уровня нагрузки. Сравните [типы деплоя](/ru/ko/features/publishing/deployment-types).
* **Конфигурация машины**: характеристики сервера, на котором работает приложение. Выберите **Редактировать**, чтобы изменить ЦП, объём памяти и максимальное количество машин. На панели отображается стоимость одной машины и стоимость при максимальном трафике. Подробнее см. в разделе [Конфигурация машины](/ru/ko/features/publishing/machine-configuration).
* **Секреты деплоя**: закрытые ключи, которые приложение использует для доступа к API и сервисам (безопасное скрытое хранилище для конфиденциальных значений, например ключей API). Секреты автоматически синхронизируются из среды разработки в опубликованное приложение. Подробнее см. в разделе [Secrets](/ru/ko/core-concepts/project-editor/app-setup/secrets).
* **Регион деплоя**: место размещения приложения. Выбор региона ближе к пользователям уменьшает задержку. После публикации приложение и связанные с ним ресурсы закрепляются за этим регионом. Чтобы изменить регион позже, необходимо ремиксировать приложение. Подробнее см. в разделе [Регион проекта](/ru/ko/features/publishing/project-geography).
* **Блокировать публикацию при критических уязвимостях**: Replit всегда выполняет сканирование безопасности перед публикацией. Этот параметр определяет, блокировать ли публикацию при обнаружении критических уязвимостей. Подробнее см. в [Project Security Center](/ru/ko/features/security/project-security-center).
