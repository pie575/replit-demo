---
title: "Preview"
description: "Découvrez comment utiliser Preview pour afficher votre application web et interagir avec elle pendant sa création."
---

Preview affiche le résultat de votre application web et propose des outils de développement du navigateur ainsi que des
fonctionnalités de débogage.

Lorsque vous démarrez votre application web à l’aide du bouton **Exécuter**, Replit lui attribue une URL temporaire
accessible sur Internet. L’outil Preview affiche la page exactement comme elle apparaîtrait
dans un navigateur. Il inclut également des outils de développement offrant des fonctionnalités similaires
à celles des navigateurs les plus populaires.

<Note>
  Preview est le nouveau nom de Webview.
</Note>

<div id="recursos">
  ## Fonctionnalités
</div>

Preview propose les fonctionnalités suivantes pour vous permettre de tester et de déboguer vos Apps web sans interruption :

* **Aperçu web en direct** : Affichez votre App et interagissez avec elle sans quitter l’onglet de votre navigateur
* **Outils de développement** : Utilisez les outils intégrés pour identifier rapidement les problèmes
* **Test responsive** : Visualisez votre App sur des écrans d’appareils mobiles de différentes tailles

<div id="uso">
  ## Utilisation
</div>

L’outil Preview s’ouvre automatiquement lorsque vous exécutez une app web.
Vous pouvez modifier ce comportement dans l’outil **Paramètres utilisateur**, sous **Aperçu automatique**.

Les instructions suivantes expliquent comment ouvrir Preview.

<Accordion title="Comment accéder à Preview">
  Dans le **dock d’outils** à gauche :

  1. Sélectionnez <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Icône Tous les outils" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **Tous les outils** pour afficher la liste des outils de l’Éditeur de projets.
  2. Sélectionnez <img class="icon-svg" src="/assets/mirror/preview-icon-6d37238e8cc2.svg" alt="Icône Preview" width="16" height="16" data-path="images/icons/preview-icon.svg" /> **Preview**.

  Dans la **barre de recherche** :

  1. Sélectionnez l’<img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="icône de loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> icône de loupe en haut pour ouvrir l’outil de recherche.
  2. Saisissez « Preview » pour trouver l’outil, puis sélectionnez-le dans les résultats.
</Accordion>

<div id="barra-de-localizao">
  ## Barre d’adresse
</div>

La barre d’adresse située en haut de l’onglet **Preview** comprend les outils suivants :

* **Bouton Retour** : revenir à la page précédente dans l’historique de navigation
* **Bouton Suivant** : aller à la page suivante dans l’historique de navigation
* **Domaine de l’app** : afficher des informations sur l’URL temporaire de votre App Replit en sélectionnant `{...}.replit.dev`
* **Champ d’adresse** : afficher le chemin d’URL actuel ou saisir un nouveau chemin

<div id="ferramentas-do-navegador">
  ## Outils du navigateur
</div>

Les outils du navigateur, situés à droite de la barre d’adresse, proposent les fonctionnalités suivantes :

* **Taille d’écran** : choisissez parmi différents préréglages de taille d’écran pour tester des interfaces responsives
* **Devtools** : affichez ou masquez le panneau des [outils de développement](#Developer_tools)
* **Nouvel onglet** : ouvrez l’URL de votre app web dans un nouvel onglet du navigateur

<Note>
  **Vous créez une app mobile ?** Le panneau Preview prend également en charge l’aperçu dans **iOS Simulator** ou **Android Emulator**. Consultez [Apps mobiles natives](/fr/pt/replitai/building-mobile-apps#preview-on-a-simulator-or-emulator) pour plus d’informations.
</Note>

<div id="ferramentas-de-desenvolvedor">
  ## Outils de développement
</div>

Les outils de développement, basés sur le projet open source <a href="https://github.com/liriliri/eruda" target="_blank">Eruda</a>, vous permettent d’effectuer les tâches suivantes :

* Afficher et utiliser la console JavaScript dans le contexte de votre App
* Inspecter les éléments du DOM
* Surveiller les requêtes réseau
* Configurer les préférences d’affichage et de comportement

Pour accéder aux outils de développement, sélectionnez le bouton <img class="icon-svg" src="/assets/mirror/wrench-7cee9d1168da.svg" alt="icône de clé à molette" width="16" height="16" data-path="images/icons/wrench.svg" /> **Devtools**
en haut de l’onglet **Preview** pour les activer.

Les sections suivantes décrivent les actions que vous pouvez effectuer dans chaque onglet des outils de développement.

<div id="console">
  ### Console
</div>

L’onglet **Console** affiche les logs JavaScript générés par votre application.
Dans cet onglet, vous pouvez effectuer les actions suivantes :

* **Effacer la sortie** : Effacez toute la sortie de la console en sélectionnant l’icône <img class="icon-svg" src="/assets/mirror/clear-bd1bf1847597.svg" height="16" width="16" alt="icône d’effacement" data-path="images/icons/clear.svg" /> cercle barré.
* **Filtrer la sortie** : Affichez la sortie de la console filtrée par type (Tout, Information, Avertissement ou Erreur).
* **Filtrer par texte correspondant** : Affichez les sorties correspondant au texte en sélectionnant l’icône <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="icône de filtre" data-path="images/icons/filter.svg" /> et en saisissant le texte.
* **Copier la sortie** : Copiez les messages sélectionnés dans la console en sélectionnant le bouton <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="icône de copier" data-path="images/icons/copy.svg" /> de copie.
* **Exécuter du code JavaScript** : Exécutez du code JavaScript dans le contexte de votre application en sélectionnant l’icône <img class="icon-svg" src="/assets/mirror/arrow-right-2859a6e6bdeb.svg" height="16" width="16" alt="icône de flèche vers la droite" data-path="images/icons/arrow-right.svg" /> chevron droit. Saisissez l’expression et sélectionnez **Exécuter**.

<div id="elements">
  ### Elements
</div>

L’onglet **Elements** vous permet d’inspecter et de modifier la structure DOM de la page web.

* **Afficher les détails de l’élément** : affichez des informations sur l’élément DOM et son emplacement dans le code HTML.
* **Copier la sortie** : copiez les messages sélectionnés dans la console à l’aide du bouton <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="icône de copier" data-path="images/icons/copy.svg" /> de copie.

Utilisez la flèche de sélection <img class="icon-svg" src="/assets/mirror/select-1165d9548c39.svg" height="16" width="16" alt="icône de sélection" data-path="images/icons/select.svg" /> pour activer ou désactiver le mode de sélection.
Après avoir activé le mode de sélection, sélectionnez un élément sur la page web.
Le HTML et le CSS de cet élément doivent apparaître dans l’onglet Elements.

<div id="network">
  ### Network
</div>

L’onglet **Network** surveille les requêtes initiées par la page web.
Dans cet onglet, vous pouvez effectuer les actions suivantes :

* **Suivre les requêtes** : Affichez toutes les requêtes réseau initiées par votre app. Sélectionnez une requête pour en voir les détails.
* **Filtrer** : Sélectionnez l’icône <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="icône de filtre" data-path="images/icons/filter.svg" /> en forme d’entonnoir pour afficher les résultats correspondant à votre texte. Saisissez un filtre vide pour l’effacer.
* **Copier** : Copiez les informations de stockage en sélectionnant le bouton <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="icône de copie" data-path="images/icons/copy.svg" /> Copier.

<div id="resources">
  ### Ressources
</div>

L’onglet **Ressources** affiche les actifs chargés par la page et le stockage du navigateur, comme les cookies et le stockage local.
Vous pouvez afficher et actualiser les listes des types d’actifs suivants :

* Fichiers JavaScript
* Feuilles de style
* Iframes
* Images

Dans cet onglet, vous pouvez effectuer les actions suivantes :

* **Afficher le stockage** : Consulter le stockage local, le stockage de session et les cookies.
* **Filtrer** : Pour afficher les résultats correspondant à votre texte, sélectionnez l’icône <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="icône de filtre" data-path="images/icons/filter.svg" /> en forme d’entonnoir. Saisissez un filtre vide pour le réinitialiser.
* **Effacer** : Supprimer toutes les données de ce type de stockage en sélectionnant le bouton <img class="icon-svg" src="/assets/mirror/clear-bd1bf1847597.svg" height="16" width="16" alt="icône d’effacement" data-path="images/icons/clear.svg" /> effacer.
* **Supprimer la sélection** : Supprimer les éléments de stockage sélectionnés en sélectionnant l’icône <img class="icon-svg" src="/assets/mirror/delete-a21eb49cac3c.svg" height="16" width="16" alt="icône de suppression" data-path="images/icons/delete.svg" /> « X ».
* **Copier** : Copier les informations de stockage en sélectionnant le bouton <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="icône de copier" data-path="images/icons/copy.svg" /> copier.

<div id="settings">
  ### Settings
</div>

L’onglet **Settings** permet de personnaliser l’apparence et le comportement des outils de développement.
Il propose les options de personnalisation suivantes :

* **Paramètres de l’outil** : personnaliser les options applicables à chaque onglet d’outil
* **Contrôles JavaScript** : définir des options de comportement JavaScript, comme le désactiver pour tester le comportement de votre app
* **Préférences d’affichage** : modifier le thème, la taille du panneau, la transparence et d’autres comportements des outils de développement
