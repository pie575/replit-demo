<div id="importar-de-zip">
  ## Importer depuis un fichier ZIP
</div>

⏰ *Durée estimée : trois minutes*

Importez un projet local en envoyant un fichier `.zip`.

Pour connaître toutes les options d’importation, notamment depuis d’autres plateformes comme GitHub, Figma, Bolt, Lovable et Vercel, consultez la [documentation de la fonctionnalité d’importation](/fr/pt/core-concepts/project-editor/app-setup/import).

<div id="antes-de-comear">
  ## Avant de commencer
</div>

* Un fichier `.zip` contenant votre projet
* Un dossier racine de projet clairement identifié dans l’archive
* Un compte Replit

<div id="passos-de-importao">
  ## Étapes d’importation
</div>

1. Ouvrez [replit.com/import](https://replit.com/import).
2. Sélectionnez **ZIP**.
3. Importez votre fichier `.zip`.
4. Ajoutez les secrets et les variables d’environnement demandés.
5. Sélectionnez **Importer**.

<div id="o-que-importado">
  ## Éléments importés
</div>

* Fichiers du projet et structure des répertoires
* Fichiers de dépendances
* Configurations d’exécution et de build pour Replit

<div id="o-que-no-importado">
  ## Ce qui n’est pas importé
</div>

* Valeurs existantes des variables d’environnement
* Domaines personnalisés
* Services propres à la plateforme nécessitant une configuration manuelle
* Données existantes de la base de données
* Configuration des connecteurs tiers existants

<div id="configure-and-run-your-app">
  ## Configurez et exécutez votre app
</div>

Lors de l’importation, {setupDescription_0}. Si votre app doit être modifiée, utilisez les outils du Project Editor suivants :

* **[Agent](/fr/features/agent/overview)** : Améliorez les fonctionnalités, déboguez les problèmes et modifiez le code
* **[Secrets](/fr/core-concepts/project-editor/app-setup/secrets)** : Ajoutez des clés API et des variables d’environnement
* **[Workflows](/fr/features/workspace-tools/workflows)** : Définissez la commande **Run** de votre app
