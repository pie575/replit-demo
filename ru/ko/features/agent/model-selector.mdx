Функция селектора моделей позволяет либо доверить подбор модели Replit, либо самостоятельно указать одну из доступных моделей.

<div id="section">
  ## Интеллектуальная маршрутизация моделей
</div>

Интеллектуальная маршрутизация моделей подбирает подходящую модель для каждой задачи, сохраняя баланс между качеством и стоимостью. Если в продукте отображается **Auto**, значит Replit использует интеллектуальную маршрутизацию моделей.

Интеллектуальная маршрутизация моделей учитывает суть запрошенной задачи и её сложность. Для узконаправленных запросов может использоваться более дешёвая модель, а для сложных задач может потребоваться более мощная. Если характер задачи меняется, Replit может выбрать другую модель.

<Note>
  В Free Mode интеллектуальная маршрутизация моделей применяется всегда. Разработчикам в Free Mode недоступен селектор моделей, и выбрать модель вручную нельзя.
</Note>

<div id="section-2">
  ## Выбор модели вручную
</div>

Разработчики с тарифами Core и Pro могут выбирать модели, доступные в режимах Power Mode и Max Mode.

1. В поле ввода запроса выберите **Agent Mode**. В меню будут показаны доступные режимы (**Free**, **Power**, **Max**).
2. Выберите **Power** или **Max**, затем найдите раздел **Primary model**.
3. Откройте меню основной модели и выберите модель из списка.

<Frame caption="Всплывающее окно выбора модели с режимами Lite, Economy и Power, а также списком Primary model. Снимок сделан в Replit Design; те же элементы управления доступны и в раскрывающемся меню настроек Agent.">
  <img src="/assets/mirror/model-selector-6826a87089a2.png" alt="Всплывающее окно настроек Agent с режимами Lite, Economy и Power, списком Primary model и ползунком Effort" width="1432" height="786" data-path="images/design/replit-design/model-selector.png" />
</Frame>

Выбранная модель будет использоваться для следующего сообщения; её можно изменить в любое время.

  ## Модели по режимам
</div>

В стандартном каталоге доступные для выбора модели распределены между режимами Power и Max следующим образом:

| Модель               | Power Mode | Max Mode |
| -------------------- | :--------: | :------: |
| Claude Sonnet 4.6    |      ✓     |          |
| Claude Sonnet 5      |      ✓     |          |
| GPT-5.6 Luna Fast    |      ✓     |          |
| GPT-5.6 Terra        |      ✓     |          |
| Gemini 3.1 Pro       |      ✓     |          |
| GLM 5.2              |      ✓     |          |
| Claude Fable 5       |            |     ✓    |
| Claude Opus 4.8      |            |     ✓    |
| Claude Opus 4.8 Fast |            |     ✓    |
| Claude Opus 5        |            |     ✓    |
| Claude Opus 5 Fast   |            |     ✓    |
| Kimi K3              |            |     ✓    |
| GPT-5.6 Sol          |            |     ✓    |

<Note>
  В Free Mode нет списка моделей для выбора. Список в селекторе моделей — точный перечень моделей, доступных для вашей учетной записи. Возможность выбора моделей предоставляется поэтапно, поэтому доступные модели могут зависеть от этапа развертывания, настроек организации и разрешений. Для некоторых высокоскоростных версий моделей требуется Turbo — платная функция повышенной скорости в тарифах Pro и Enterprise. Если вы не видите **Primary model**, селектор моделей пока недоступен для вашей учетной записи.
</Note>

<div id="effort">
  ## Effort
</div>

**Effort — не отдельный режим, а настройка для каждой модели.** Она определяет, сколько ресурсов на рассуждения выбранная модель будет выделять для каждого ответа: от **Low** до **Max**. Для каждой модели отображается рекомендуемое значение — повышайте его только при необходимости.

<Frame caption="Ползунок Effort под списком моделей, установленный на Medium.">
  <img src="/assets/mirror/model-selector-effort-bcffb01239a8.png" alt="Список Primary model с выбранной Claude Fable 5 и ползунком Effort, установленным на Medium и описанным как сбалансированное рассуждение для повседневных задач" width="984" height="832" data-path="images/replitai/model-selector-effort.png" />
</Frame>

Ознакомьтесь с описанием уровней:

| Effort         | Когда использовать                                                                                                                             |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| **Low**        | Самые быстрые ответы с минимальными рассуждениями. Подходит для повседневных и понятных изменений, когда скорость важнее всего.                |
| **Medium**     | Сбалансированные рассуждения для повседневных задач. Подходящее значение по умолчанию, если для рекомендованной настройки нет особых указаний. |
| **High**       | Более глубокие рассуждения для сложных задач, например многоэтапных функций или незнакомых областей.                                           |
| **Extra High** | Расширенные рассуждения для самых сложных задач, например масштабного рефакторинга или трудноуловимых ошибок.                                  |
| **Max**        | Максимальная глубина рассуждений. Самый дорогой и медленный вариант, когда важен только наилучший результат.                                   |

Чем выше Effort, тем глубже и тщательнее Agent анализирует задачу, используя самые мощные передовые модели для улучшения результатов в наиболее сложных случаях. Agent применяет эту дополнительную мощность выборочно: направляет запросы к более мощной модели только тогда, когда они действительно сложны, а не при каждом запуске.

<Tip>
  Поскольку Agent использует самые мощные модели только для наиболее сложных задач, повышение Effort может увеличить стоимость таких задач примерно вдвое, тогда как для более простых задач она часто почти не меняется или не меняется вовсе. Повышайте Effort при работе со сложными задачами и сохраняйте низкое значение для повседневных изменений.
</Tip>

<div id="section-4">
  ## Сравнение моделей
</div>

**Compare models** запускает следующий промпт сразу в нескольких моделях, чтобы вы могли сравнить результаты бок о бок, а не гадать, какая модель подойдёт. Это бета-функция.

Чтобы включить её, разверните **Расширенные настройки** внизу всплывающего окна режима Agent и включите **Compare models**.

<Note>Сравнение моделей поддерживается только в Chat.</Note>

<Frame caption="Переключатель Compare models в разделе расширенных настроек.">
  <img src="/assets/mirror/compare-models-toggle-05429dc46d64.png" alt="Развёрнутые расширенные настройки с выключенным переключателем Compare models Beta и пояснением, что следующий промпт создаст до четырёх вариантов" width="1110" height="344" data-path="images/replitai/compare-models-toggle.png" />
</Frame>

Когда переключатель включён, в сравнение можно добавить до **4 моделей**.

<Frame caption="Четыре модели, выбранные для сравнения; на кнопке отправки указано Compare 4.">
  <img src="/assets/mirror/compare-models-9f5bcecec727.png" alt="Всплывающее окно режима Agent с включённым Compare models и четырьмя слотами моделей (Kimi K3, Claude Fable 5, Claude Opus 5, GPT-5.6 Sol), каждый из которых можно удалить; кнопка отправки сообщения с надписью Compare 4" width="1192" height="1930" data-path="images/replitai/compare-models.png" />
</Frame>

После этого следующий промпт выполняется по одному разу в каждой выбранной модели, и каждая создаёт свой вариант, который можно сравнить с остальными.

<Note>
  Каждая модель, включённая в сравнение, работает как отдельный агент и расходует кредиты, поэтому запуск Compare 4 обходится примерно как четыре обычных запуска.
</Note>
