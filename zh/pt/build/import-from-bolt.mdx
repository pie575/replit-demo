<div id="importar-do-bolt">
  ## 从 Bolt 导入
</div>

⏰ *预计耗时：四分钟*

<Warning>Agent 目前支持从 Bolt 导入 Vite + React 应用。</Warning>

要将 Bolt 项目导入 Replit，请先将其导出到 GitHub，然后导入该仓库。

如需了解更全面的导入选项 (包括 GitHub、Figma、Lovable 等其他平台) ，请参阅[导入功能文档](/zh/pt/references/workspace/import)。

<div id="antes-de-comear">
  ## 开始之前
</div>

* 一个可导出的 Bolt 项目
* 一个已连接到 Bolt 的 GitHub 账户
* 一个 Replit 账户

<div id="etapas-de-importao">
  ## 导入步骤
</div>

1. 将你的 Bolt 项目导出到 GitHub。
2. 打开 [replit.com/import](https://replit.com/import)。
3. 选择 **Bolt**。
4. 连接你的 GitHub 账户。
5. 选择已导出的 Bolt 仓库。
6. 选择 **Import**。

<div id="what-gets-imported">
  ## 导入内容
</div>

Replit 会从你的 {platform_1} 项目中导入以下内容：

* **代码**：应用逻辑和源文件
* **设计与样式**：界面组件和样式规则
* **资源**：图片、图标和静态文件
* **后端逻辑**：服务端功能 (如有)
* **数据库架构**：表结构 (如有)

<div id="what-is-not-imported">
  ## 不会导入的内容
</div>

* **Supabase 数据**：不会迁移现有数据库记录
* **Secrets**：需要单独添加环境变量和 API 密钥

使用 Agent 重建缺失的功能，添加 Secrets，并重新创建数据库数据。
