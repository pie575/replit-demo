# Fila de Mensagens

> Saiba como enfileirar mensagens de acompanhamento para o Agent para que ele as processe em ordem após concluir a tarefa atual.

A Fila de Mensagens é uma nova forma de interagir com o Replit Agent enquanto ele está trabalhando.
Em vez de interromper o trabalho em andamento, você pode agendar tarefas de acompanhamento que serão executadas
em ordem após cada conclusão de um ciclo de trabalho do Agent.

## Como funciona

Quando o Agent está ativamente processando uma solicitação, você pode agendar uma tarefa de acompanhamento adicionando
mensagens à Fila. Essas tarefas ou solicitações serão processadas em ordem após cada conclusão de
um ciclo de trabalho do Agent. A fila é automaticamente limpa quando o Agent conclui todas as tarefas.

Todas as opções de mensagem estão disponíveis com a Fila, como o [Editor Visual](/pt/replitai/visual-editor)
e anexos de arquivos.

<Info>
  As mensagens enfileiradas só serão processadas automaticamente enquanto você tiver uma
  sessão ativa do Editor de Projetos conectada ao Agent (seja no desktop ou dispositivo móvel).
</Info>

## Usando a Fila de Mensagens

### Quando a Fila aparece

A Fila de Mensagens aparece automaticamente como um drawer acima da entrada de chat quando você envia uma mensagem
enquanto o Agent está trabalhando. Ela fecha assim que todas as mensagens enfileiradas são processadas.

### Gerenciando mensagens enfileiradas

Quando o drawer da fila está aberto, você pode:

* **Editar mensagens**: Clique no ícone de edição para modificar uma mensagem enfileirada antes de ser processada
* **Excluir mensagens**: Remova tarefas indesejadas da fila
* **Reordenar itens**: Arraste e solte para alterar a ordem de execução das mensagens enfileiradas
* **Adicionar mais mensagens**: Continue adicionando novas tarefas à fila pela entrada de chat

### Interrupção imediata

Se você precisar interromper o Agent e enviar uma mensagem imediatamente, pode usar o botão **Pausar**
na barra de status. Isso interromperá o ciclo de trabalho atual do Agent e permitirá que você envie uma mensagem imediata,
ignorando quaisquer mensagens enfileiradas (se existirem).

## Melhores práticas

### Quando usar a Fila de Mensagens

* **Fluxos de trabalho em múltiplas etapas**: Enfileire uma série de tarefas relacionadas que se constroem umas sobre as outras
* **Operações em lote**: Agrupe solicitações similares para processamento eficiente
* **Solicitações de acompanhamento**: Adicione esclarecimentos ou requisitos adicionais após a tarefa inicial
* **Tarefas não urgentes**: Enfileire solicitações de menor prioridade enquanto o Agent trabalha em tarefas críticas

### Quando usar a interrupção imediata

* **Mudanças urgentes**: Quando você precisa parar o trabalho atual imediatamente
* **Erros críticos**: Se você notar um problema que precisa de atenção imediata
* **Mudança de direção**: Quando você quer mudar completamente o que o Agent está trabalhando

## Comportamento da fila

* **Execução ordenada**: As mensagens são processadas na ordem em que foram adicionadas à fila
* **Conclusão do ciclo de trabalho**: Cada mensagem enfileirada é processada após o Agent concluir seu ciclo de trabalho atual
* **Preservação de contexto**: O Agent mantém o contexto entre as mensagens enfileiradas na mesma conversa
