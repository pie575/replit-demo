在 Claude 中制作的设计展示了体验应有的样子。通过 Claude 的 **Send to Replit** 选项，你可以将该设计发送到 Replit，它会在 Replit 中变成一个项目，并由 Agent 将其打造成可运行的交互式应用。

<Note>
  这是一项新的集成功能。只有当 Claude 提供 Replit 作为设计的发送目标时，**Send to Replit** 才会出现在 Claude 的 **Send to…** 菜单中。是否可用由 Claude 决定，因此可能尚未对所有账户开放。接受发送后，Claude 会在 Replit 授权页面上请求 **Access apps**、**Create and manage apps** 和 **Stay signed in to this application** 权限。
</Note>

<div id="section">
  ## 工作原理
</div>

整个传递流程从 Claude 开始，到 Replit 结束：

1. 在 Claude 的设计画布中创建一个自包含的设计。
2. 在 Claude 的 **Share → Send to…** 菜单中，将该设计发送到 Replit。
3. 授权 Claude 访问你的 Replit 账户，并选择工作区。
4. Replit 会创建一个项目，并将该设计保存为静态 `index.html` 文件。
5. Agent 启动 **Turn this Claude design into a real app** 任务，把它变成可交互的应用。

也就是说，Claude 通过已授权的应用连接将设计*发送*到 Replit。你无需事先在 Replit 中做任何设置——整个流程从 Claude 开始。

<div id="section-2">
  ## 开始之前
</div>

你需要准备以下内容：

* [Replit 账户](https://replit.com)。
* 一个 Claude 账户，且在 Claude 的设计画布中已有设计。
* 一个用于创建新项目的 Replit 工作区。

<div id="claude-replit">
  ## 将设计从 Claude 发送到 Replit
</div>

先在 Claude 中打开你想要构建的设计。

<Steps>
  <Step title="在 Claude 中打开设计">
    在 Claude 中打开你想做成应用的设计。
  </Step>

  <Step title="打开 Send to 菜单">
    选择 **Share**，然后打开 **Send to…** 菜单。Replit 会显示为目标之一。

    <Frame>
      <img src="/assets/mirror/claude-send-to-menu-d4353906aea3.png" alt="Claude 的 Send to… 菜单，其中将 Replit 与 Claude Code 一并列为目标" width="2000" height="1143" data-path="images/claude-to-app/claude-send-to-menu.png" />
    </Frame>
  </Step>

  <Step title="选择 Replit">
    选择 **Replit**，开始向你的 Replit 账户传送。
  </Step>

  <Step title="授权 Replit 访问">
    在标题为 **Claude would like to access your Replit account** 的 Replit 授权页面中，查看 Claude 请求的权限——**Access apps**、**Create and manage apps**、**Stay signed in to this application**——然后批准连接。

    <Frame>
      <img src="/assets/mirror/replit-oidc-consent-76dfc4d92a2f.png" alt="标题为“Claude would like to access your Replit account”的 Replit 授权页面——显示 Access apps、Create and manage apps、Stay signed in 权限以及工作区选择器" width="2000" height="1143" data-path="images/claude-to-app/replit-oidc-consent.png" />
    </Frame>
  </Step>

  <Step title="选择工作区">
    选择用于创建新项目的 Replit 工作区，然后确认。
  </Step>
</Steps>

确认后，Replit 会根据该设计创建项目，并在工作区中打开。

<div id="section-3">
  ## 导入的内容
</div>

Replit 会将设计导入为单个自包含的 `index.html` 文件。导入会保留 Claude 在设计中包含的视觉布局、样式和资源。

导入可提供一个可运行的起点。由于设计以静态 HTML 形式交付，导入后仍需你自行添加行为、数据和交互功能。

<div id="section-4">
  ## 不会导入的内容
</div>

导入的是设计，而不是完整的应用程序。以下内容不在导入范围内：

* 后端逻辑和服务器端功能。
* 数据库或已存储的数据。
* 可正常使用的表单、状态、导航等交互功能。

Agent 会在将设计构建为实际应用时添加这些功能。

<div id="agent">
  ## Agent 让设计变得可交互
</div>

导入后，Agent 会在工作区中启动 **Turn this Claude design into a real app** 任务。Agent 会以静态设计为基础，构建该设计所暗示的交互行为。

<Frame caption="从 Claude 传来的 Velocity 设计以设计帧的形式显示在 Replit Design 中，Agent 已运行完成。">
  <img src="/assets/mirror/claude-design-in-replit-design-ff81b055b1f5.webp" alt="从 Claude 发送的 Velocity 超跑租赁设计在 Replit Design 中以 Claude design 设计帧打开，聊天面板显示 Agent 任务已完成" width="1600" height="1004" data-path="images/claude-to-app/claude-design-in-replit-design.webp" />
</Frame>

任务完成后，打开 Preview 测试效果。将运行中的应用与原始 Claude 设计对比，确认以下几点：

* 布局与样式是否与设计足够一致。
* 按钮、表单和导航是否按预期工作。
* 刷新后应用是否仍能正常运行。

如果发现内容缺失或不一致，可以向 Agent 说明需要的改动，让它进一步完善应用。
