<div id="vercel">
  ### Интеграция импорта из Vercel
</div>

Перенесите приложение с Vercel в Replit одним кликом! Новый процесс импорта позволяет без труда перенести в Replit приложения на Next.js и другие проекты, размещённые на Vercel. Отличная новость для разработчиков, которые ищут альтернативу Vercel. Подробнее — в [кратком руководстве по импорту из Vercel](/ru/build/import-from-vercel) и [руководстве по импорту в Replit](/ru/references/workspace/import).

<div id="git">
  ### Улучшения системы контроля версий Git
</div>

Расширенная интеграция с Git обеспечивает более удобное управление удалёнными репозиториями и гибкость рабочих пространств. Подключайте и создавайте удалённые репозитории Git в улучшенном интерфейсе, легко переключайтесь между личными рабочими пространствами и пространствами организации, а также следите за тем, чтобы перед развёртыванием код всегда был актуальным. Подробнее — в разделе [Использование панели Git](/ru/references/version-control/git-interface).

<div id="section-3">
  ### Запуск платформы Connectors
</div>

Создавайте приложения быстрее с 24 готовыми интеграциями! Новая платформа Connectors позволяет подключать проекты Replit к популярным сервисам — Stripe, Figma и другим. Каждый connector работает на базе MCP (Model Context Protocol), что обеспечивает удобную разработку с помощью ИИ. Подробнее — в разделах [Интеграции Agent](/ru/replitai/integrations) и [Управление connectors](/ru/ko/replitai/managing-connectors).

<div id="section-4">
  ### Улучшения шрифтов в темах приложения
</div>

Настраивайте приложения с помощью 19 новых шрифтов Google Fonts, включая такие популярные варианты, как Crimson, EB Garamond, Figtree и Source Sans Pro. Теперь в списке выбора каждый шрифт отображается своим реальным начертанием, поэтому оценить оформление стало проще. Шрифты сгруппированы по категориям (с засечками, без засечек, моноширинные), а подсказки поясняют особенности каждой из них. Подробнее — в разделе [Темы приложения](/ru/replitai/app-themes).

<div id="section-6">
  ### Администрирование connector-ов
</div>

Корпоративным клиентам доступны расширенные возможности управления connector-ами: ролевая модель доступа к общим ключам API и полностью настраиваемая конфигурация клиентов OAuth. Connector-ы можно выборочно включать на уровне организации, благодаря чему администраторы полностью контролируют, какие интеграции доступны участникам команды. Подробнее см. [Управление connector-ами](/ru/ko/replitai/managing-connectors).
