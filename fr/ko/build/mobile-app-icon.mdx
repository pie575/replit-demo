export const appIconPrompt = "Génère 3 concepts d’icônes d’application différents, au format 1024x1024, pour PixelGames.";

Les deux stores exigent une icône d’application avant d’accepter une soumission. Replit peut
générer directement une icône, sans nécessiter d’outil de conception distinct.

<div id="section">
  ## Exigences de chaque store
</div>

* **App Store :** 1024×1024, sans transparence ni coins arrondis (Apple les ajoute).
* **Google Play :** 512×512.

<div id="section-2">
  ## Créer
</div>

Avant d&#39;envoyer le prompt, passez en mode **Design**. Cela indique à Agent de générer des images.

<AiPrompt>
  {appIconPrompt}
</AiPrompt>

Agent génère plusieurs propositions à la fois afin que vous puissiez les comparer avant d&#39;en choisir une.
