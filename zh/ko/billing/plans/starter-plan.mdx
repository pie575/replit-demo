<div id="section">
  ## 提供内容
</div>

Starter 套餐提供在 Replit 上开始构建所需的一切。创建应用并发布您的第一个项目，全部免费。

<div id="agent">
  ### Agent 每日额度
</div>

Starter 套餐用户可获得 Agent 每日额度，直至达到每月限额。额度每天都会重置，让你每天都能获得新的 Agent 使用额度。

<div id="section-2">
  ### 云服务月度额度
</div>

您还将获得可用于以下服务的月度额度：

* [数据库 (生产环境) ](/zh/ko/features/data-and-storage/development-and-production)
* [对象存储](/zh/ko/features/data-and-storage/object-storage)
* [部署 (Autoscale、静态) ](/zh/ko/learn/projects-and-artifacts/replit-deployments)

这些额度每月重置。

<div id="lite">
  ### Lite 构建
</div>

借助快速、专注的构建体验，使用 Agent 访问适合快速编辑和目标明确的更改的 [Lite 构建](/zh/ko/features/agent/agent-modes)。

<div id="1">
  ### 1 个免费发布应用
</div>

无论您使用 Lite 构建还是 Design Canvas，均可获得 {FreeDeployments} 个免费发布应用。这些发布链接将在 30 天后自动失效。

已发布的应用会显示带有专属推荐链接的“Made with Replit”徽章。其他用户通过该徽章中的链接注册后，您将在其升级为付费套餐后获得推荐积分。

<div id="section-3">
  ## 限制
</div>

以下功能需升级至 Core：

<div id="section-4">
  ### 完整构建
</div>

使用[完整构建](/zh/ko/features/agent/overview/)时，Agent 可凭借更高的权限和自主性独立完成工作。Starter 计划的构建者只能使用[轻量构建](/zh/ko/features/agent/agent-modes)。完整构建需要 Core 或 Pro。

<div id="section-5">
  ### 将设计转换为工件
</div>

将 Design Canvas 中的设计转换为完整工件需要 Core。Starter 计划用户可以创建和部署设计，但如需将其转换为具备后端功能的工件，则需要升级。若要构建具备后端功能的应用，请从 [Lite 构建](/zh/ko/features/agent/agent-modes) 开始。

<div id="3">
  ### 第三方连接器
</div>

使用外部连接器需要 Core，包括与 Google、Stripe 和其他第三方 API 的集成 (参阅[详情](https://docs.replit.com/features/integrations/overview#connectors)) 。

<div id="replit-ai-integrations">
  ### Replit AI 集成
</div>

[Replit AI 集成](/zh/ko/features/integrations/replit-ai-integrations)需要 Core 套餐。

<div id="made-with-replit">
  ### 移除“Made with Replit”徽章
</div>

要从已发布的应用中移除“Made with Replit”徽章，你需要订阅 Core。Starter 计划用户的部署会显示该徽章。

<div id="section-6">
  ### 额外部署应用
</div>

Starter 套餐用户可获得 {FreeDeployments} 个免费部署应用。超过此数量的额外部署应用需要 Core 或 Pro。

<div id="plan-mode">
  ### Plan 模式
</div>

使用 Plan 模式需要 Core。借助 Plan 模式，你可以在不修改应用代码或数据的情况下，与 Replit Agent 一起构思、规划工作并协作。

<div id="section-7">
  ### 所有工件类型
</div>

如需构建网页和移动应用以外的工件类型，需要订阅 Core。您可以选择数据可视化、幻灯片、动画视频等多种类型。请参阅 [Project](/zh/ko/features/projects-and-artifacts/projects)。

<div id="core">
  ## 升级至 Core
</div>

想要更多功能？升级至 Core，即可享受：

* **更多存储空间和每月积分**，并支持按量付费
* **无限发布应用** (首个免费应用之后)
* 使用**完整构建**进行自主开发
* 可连接外部服务的**第三方连接器**
* 无需自备 API 密钥即可使用 AI 模型的 **Replit AI Integrations**
* 在开始构建前规划工作的 **Plan 模式**
* 移除 **Replit 徽章**，打造更专业的外观
* 以及更多权益
