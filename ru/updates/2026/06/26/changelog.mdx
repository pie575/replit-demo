<div id="a-new-integrations-experience">
  ### Обновлённый раздел интеграций
</div>

Теперь все сервисы, с которыми связывается Replit, собраны в одном месте. На переработанной странице интеграций коннекторы, серверы MCP и провайдеры Git представлены в виде кликабельных карточек — с фильтрами по категориям и значком, который отмечает интеграции, подключаемые силами Replit. В каталоге уже более 450 интеграций, и у каждой есть отдельная страница с примерами использования. Посмотреть полный каталог можно на [replit.com/integrations](https://replit.com/integrations).

<div id="use-replit-from-slack">
  ### Используйте Replit из Slack
</div>

Replit стал одним из стартовых партнёров Slackbot MCP Client. Попросите Slackbot что-нибудь собрать с помощью Replit — и он создаст, обновит и покажет ваши Replit App прямо в Slack. Вы остаётесь в переписке, а всю работу выполняет Replit Agent.

<div id="multiple-workspaces-for-scim-customers">
  ### Несколько workspace для клиентов с SCIM
</div>

Клиенты Enterprise, которые подключают участников через SCIM, теперь могут создать не один, а несколько workspace. Распределяйте синхронизированные группы по разным workspace — так вы получите более четкие границы доступа, контроль расходов и разделение команд, а источником истины по-прежнему останется ваш провайдер идентификации. Возможность доступна в рамках открытой регистрации для новых клиентов Enterprise.

Подробнее об [управлении доступом к workspace через SCIM](/ru/teams/identity-and-access-management/scim#managing-workspace-access).
