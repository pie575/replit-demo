<div id="section-2">
  ### 智能模型路由
</div>

智能模型路由会自动为任务选择最合适的模型和 Effort 级别，兼顾质量与成本。选择 **Power** 或 **Max** 下的 **Auto** 后，Replit 会根据任务复杂度的变化，为不同部分分配相应的模型和 Effort 级别。如需更精细的控制，你也可以手动选择特定的模型和 Effort 级别。

  <img src="/assets/mirror/auto-mode-model-and-effort-selector-fdcabef57097.jpg" alt="显示 Auto、可用模型和 Effort 控件的 Agent 设置" width="1839" height="855" data-path="images/chat/auto-mode-model-and-effort-selector.jpg" />
</Frame>

详细了解[智能模型路由](/zh/ja/chat/auto-mode)。

<div id="growth-skills">
  ### 使用 Growth Skills 获取首批客户
</div>

在 Agent 中运行 [Growth Skills](https://replit.com/growth-kit)，为你的应用获取首批客户。可用的合作伙伴集成包括 Apollo、Clay、SideShift、RevenueCat、Stripe 和 PostHog。

<Frame caption="浏览 Growth Skills，并为你的应用启动增长活动。">
  <img src="/assets/mirror/growth-skills-55d5f1fd7001.png" alt="Growth Skills 目录，展示 Apollo Cold Email Launch 和 Pixel and Web Intent 增长活动，以及 SideShift Consumer 和 Viral Potential Assessment 增长活动" width="2320" height="1512" data-path="images/changelog/2026-08-28/growth-skills.png" />
</Frame>

<div id="enterprise">
  ### 面向 Enterprise 的智能模型路由
</div>

智能模型路由现已成为 Enterprise 工作区中 Agent 的默认模式。启用 **Auto mode** 后，Replit 会为每项任务选择最合适的模式和获准使用的模型。账户管理员可以按工作区控制模型的可用性，也可以关闭 **Auto mode**，手动选择已启用的模型。Enterprise 的 Agent 模式菜单现提供 **Power** 和 **Max**，不再包含 **Lite**。

<Frame caption="启用 Auto mode 后，Replit 会为每项任务选择最合适的模式和模型。">
  <img src="/assets/mirror/enterprise-auto-mode-9365b7d49c0d.png" alt="已启用 Auto mode，且模型固定为 Auto 的 Agent 设置" width="558" height="356" data-path="images/changelog/2026-08-28/enterprise-auto-mode.png" />
</Frame>

详细了解 [Enterprise 模型控制](/zh/ja/features/collaboration/enterprise-model-controls)。

<div id="section-4">
  ### 自定义连接器
</div>

Enterprise 组织现在可以为连接器使用自定义 OAuth 配置。例如，您可以使用自己的 **Client ID**、**Client Secret** 和 **scopes** 配置 Gmail，而不是使用 Replit 的默认设置。

<Frame caption="在 Gmail 连接器中选择 Use custom configurations。">
  <img src="/assets/mirror/gmail-custom-configuration-43a0bdec6ddb.png" alt="选择“Use custom configurations”的 Gmail 连接器设置，以及 Google Cloud 凭据配置步骤" width="1304" height="1564" data-path="images/changelog/2026-08-28/gmail-custom-configuration.png" />
</Frame>

请参阅[如何为连接器配置自定义 OAuth 应用](/zh/ja/features/integrations/overview#configuring-oauth-app-with-replit)。
