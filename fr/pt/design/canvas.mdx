Le Canvas est la surface infinie de panoramique et de zoom où Replit Design affiche vos frames. Tout ce que vous concevez s’y trouve : générez des frames, faites-les glisser, zoomez sur un détail et itérez jusqu’à obtenir le résultat souhaité.

<div id="abra-o-canvas">
  ## Ouvrir le Canvas
</div>

Le Canvas est la première chose que vous voyez dans Replit Design. Dans un projet, sélectionnez **Design** dans l’en-tête pour afficher le Canvas dans le panneau, ou **Build** pour revenir à votre app en cours d’exécution.

<Frame>
  <img src="/assets/mirror/canvas-design-button-ffa50447cefb.png" alt="Gros plan d’un en-tête de projet avec le sélecteur Design/Build, Design sélectionné, au-dessus de frames dans le Canvas" width="987" height="619" data-path="images/replitai/canvas-design-button.png" />
</Frame>

Pour partir de zéro, accédez à [replit.com/design](https://replit.com/design), puis créez un design qui s’ouvre dans le Canvas. Consultez [Design vs. Build](/fr/pt/design/design-vs-build) pour savoir quand utiliser chaque interface.

<div id="o-que-vive-no-canvas">
  ## Ce qui se trouve sur le Canvas
</div>

* **Frames** : chaque bloc du Canvas. Un frame peut être une maquette de design, une app web ou mobile, des diapositives, une image, une vidéo ou un graphique vectoriel. Générez-les à partir d’un prompt dans Chat, du [menu Générer](/fr/pt/design/toolbar#generate) de la barre d’outils ou du [panneau de bibliothèque](/fr/pt/design/library-panel). Toutes les actions sur un frame — construire, Focus ou proposer des suggestions — s’effectuent directement depuis celui-ci : consultez [Frames](/fr/pt/design/frames).
* **Dessins et notes** : des annotations que vous ajoutez avec l’[outil Dessiner](/fr/pt/design/toolbar#draw), comme des croquis, des flèches, des formes et des notes adhésives. Agent lit vos annotations : vous pouvez donc entourer une zone problématique et demander une modification.
* **Le panneau Chat** : le Chat d’Agent ancré à côté du Canvas. Sélectionnez des frames avant d’envoyer un message pour les joindre sous forme d’instantanés afin qu’Agent dispose d’un contexte visuel.

Pour savoir ce qu’est chaque composant et comment ils s’articulent, consultez la [vue d’ensemble des composants](/fr/pt/design/core-components).

<div id="navegue-pelo-quadro">
  ## Naviguez sur le Canvas
</div>

Le déplacement, le zoom et la sélection fonctionnent depuis n’importe quel outil, sauf indication contraire.

**Déplacement :**

* Pavé tactile : faites glisser avec deux doigts.
* Souris : cliquez avec le bouton du milieu et faites glisser, ou maintenez la barre d’espace enfoncée et cliquez-glissez avec le bouton gauche.
* [Pan](/fr/pt/design/toolbar#pan) : cliquez et faites glisser avec le bouton gauche de la souris.

**Zoom :**

* Pavé tactile : pincez.
* Souris : `Ctrl` (ou `Cmd` sous macOS) + molette de défilement.
* Clavier : `Cmd`/`Ctrl` + `+` pour zoomer, `Cmd`/`Ctrl` + `-` pour dézoomer, `Cmd`/`Ctrl` + `0` pour réinitialiser le zoom.

Le zoom est ancré au curseur : le point situé sous le curseur reste donc fixe tandis que le reste du Canvas se redimensionne autour de lui.

**Sélection :**

* Frame unique : cliquez dessus avec l’[outil Interagir](/fr/pt/design/toolbar#interact).
* Sélection multiple : maintenez `Shift` enfoncée et cliquez sur chaque frame, ou faites glisser un rectangle de sélection sur le Canvas.
* Désélectionner : cliquez dans une zone vide ou appuyez sur `Escape`.

Sélectionner un ou plusieurs frames affiche la [barre d’actions par frame](/fr/pt/design/frames#per-frame-action-bar) et joint ces frames au prochain message de l’Agent sous forme d’instantanés.

<div id="atalhos-de-teclado">
  ### Raccourcis clavier
</div>

| Raccourci                             | Action                                               |
| ------------------------------------- | ---------------------------------------------------- |
| `V`                                   | Activer l’outil Interagir                            |
| `H`                                   | Activer l’outil Pan                                  |
| Maintenir `Espace` enfoncée + glisser | Effectuer un panoramique depuis n’importe quel outil |
| `Cmd` / `Ctrl` + défilement           | Zoomer                                               |
| `Cmd` / `Ctrl` + `+`                  | Zoom avant                                           |
| `Cmd` / `Ctrl` + `-`                  | Zoom arrière                                         |
| `Cmd` / `Ctrl` + `0`                  | Réinitialiser le zoom                                |
| `Shift` + clic                        | Ajouter un frame à la sélection actuelle             |
| `Cmd` / `Ctrl` + `Shift` + `C`        | Copier le frame sélectionné au format PNG            |
| `Escape`                              | Désélectionner                                       |

<div id="menu-do-boto-direito">
  ## Menu du clic droit
</div>

Cliquez avec le bouton droit n’importe où sur le Canvas pour ouvrir un menu contextuel. Les actions proposées s’adaptent à l’élément sous le curseur : un frame donne accès à des actions qui lui sont propres, tandis qu’un Canvas vide propose des actions au niveau du Canvas. Les frames d’App ajoutent l’action **Mettre à jour l’artefact**.

Sur un frame sélectionné, le menu comprend :

| Action                               | Raccourci                     | Description                                                             |
| ------------------------------------ | ----------------------------- | ----------------------------------------------------------------------- |
| Modifier                             |                               | Passer à l’outil Modifier pour sélectionner des éléments dans le frame. |
| Chat                                 |                               | Discuter avec l’Agent au sujet du frame.                                |
| Focus                                |                               | Passer en [mode Focus](/fr/pt/design/frames#focus-mode) sur le frame.      |
| Chat au curseur                      | `/`                           | Démarrer un Chat rapide à l’emplacement du curseur.                     |
| Réorganiser                          |                               | Déplacer le frame vers l’avant ou l’arrière dans l’ordre d’empilement.  |
| Copier, Coller, Dupliquer, Supprimer | `⌘C`, `⌘V`, `⌘D`, `Backspace` | Gestion standard du presse-papiers et des frames.                       |
| Exporter sous…                       |                               | Exporter le frame sous forme de fichier.                                |
| Sélectionner tout                    | `⌘A`                          | Sélectionner tous les frames du Canvas.                                 |

<div id="exportar-um-frame-como-png">
  ### Exporter un frame au format PNG
</div>

Enregistrez n’importe quel artefact ou frame de design au format PNG. Cette option est utile pour partager un aperçu dans un document ou un chat, capturer un instantané avant de poursuivre les itérations ou envoyer une capture d’écran à un membre de votre équipe.

<Steps>
  <Step title="Sélectionnez le frame">
    Sélectionnez l’artefact ou le frame de design que vous souhaitez exporter, puis attendez la fin de son chargement.
  </Step>

  <Step title="Choisissez Exporter">
    Sélectionnez **Exporter** dans la barre d’actions du frame. Vous pouvez également faire un clic droit sur le frame et sélectionner **Exporter sous…** &gt; **PNG**. L’image est téléchargée sur votre ordinateur avec un nom de fichier basé sur le nom du frame.
  </Step>
</Steps>

Pour copier le frame sélectionné au format PNG au lieu de le télécharger, appuyez sur `Cmd+Shift+C` (ou `Ctrl+Shift+C` sous Windows et Linux).

<Note>Le PNG exporté correspond à ce qui est actuellement affiché dans le frame sur le Canvas. Si votre App ou votre design est encore en cours de chargement, attendez qu’il soit entièrement rendu avant de l’exporter.</Note>

<div id="o-canvas-e-o-app-em-execuo">
  ## Le Canvas et l’app en cours d’exécution
</div>

Le Canvas et l’aperçu de l’app en cours d’exécution partagent le même panneau, et certains modes permettent de passer de l’un à l’autre :

* **Mode Focus** : l’action **Focus** sur un frame sélectionné l’agrandit pour remplir la vue. Sélectionnez **Quitter le mode Focus** en haut du frame pour revenir au Canvas.
* **Mode lecture seule** : lorsque le Canvas est verrouillé dans le cadre d’une tâche en arrière-plan, les actions d’itération sont masquées et seule l’action Focus reste disponible.

<Note>
  Créer une nouvelle app à partir d’un frame Design nécessite Core ou Pro ; toutes les autres fonctionnalités du Canvas sont disponibles avec n’importe quel forfait. Consultez [Billing](/fr/pt/billing/ai-billing) pour en savoir plus sur les forfaits.
</Note>
