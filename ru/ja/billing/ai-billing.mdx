Для функций Replit AI применяется оплата по мере использования, зависящая от того, что вы создаёте и насколько активно используете инструменты на базе ИИ. Так вы платите только за ценность, которую получаете от Agent.

<div id="section">
  ## Начало работы
</div>

**Все подписчики** получают один бесплатный чекпоинт Agent.

Дополнительные ежемесячные кредиты автоматически расходуются на использование ИИ:

* **Подписчики Core**: ежемесячные кредиты (см. [цены](https://replit.com/pricing))
* **Подписчики Pro**: многоуровневые ежемесячные кредиты с переносом на {ProCreditRolloverPeriod}. Подробнее — в разделе [Replit Pro](/ru/ja/billing/plans/replit-pro).

Эти кредиты покрывают расходы на Agent и другие облачные сервисы Replit, включая опубликованные приложения, хранилище и базы данных. Выберите [Lite, Economy или Power](/ru/ja/features/agent/agent-modes), чтобы оптимизировать скорость, стоимость или возможности.

Free Mode позволяет подписчикам Core и Pro бесплатно выполнять повседневные задачи с Agent в пределах включённого лимита. Для платных режимов и подтверждённых платных задач применяется оплата по объёму работы, которая зависит от сложности запроса. Replit запрашивает подтверждение перед началом платных действий.

<div id="section-2">
  ### Как работает оплата по объёму работы
</div>

Когда вы общаетесь с Agent в «режиме сборки», создаётся **чекпоинт**, в котором фиксируется выполненная работа по вашему запросу:

* **Простые запросы** (например, исправление ошибок или небольшие изменения) обычно стоят меньше, чем сложные сборки
* **Сложные сборки** (например, реализация полнофункциональных возможностей или интеграций) могут объединяться в один чекпоинт и стоить дороже простых запросов, что отражает общий объём требуемых усилий
* **Один чекпоинт на запрос** исключает промежуточные чекпоинты и делает выставление счетов понятнее
* **Прозрачная тарификация** позволяет точно понимать, за что вы платите при выполнении каждой задачи

<Info>
  Чекпоинт создаётся, когда Agent завершает работу по вашему запросу и реализует запрошенную функциональность в коде.
</Info>

На платных тарифах режим Plan может выполнять платные рассуждения, даже если код не изменяется.

Подробнее о том, что фиксируют чекпоинты и как они работают, см. в разделе [Чекпоинты и откат](/ru/ja/features/version-control/checkpoints-and-rollbacks).

<div id="agent-3">
  ### Тарификация сервисов Agent
</div>

Некоторые возможности Agent используют в фоновом режиме платные сторонние API (Claude, ChatGPT, Nano Banana / Gemini и другие). Agent обрабатывает эти интеграции автоматически — ключи API и настройка не требуются. Оплата рассчитывается по публичным тарифам API соответствующих провайдеров и списывается с кредитов Replit. Эти расходы отображаются вместе с остальным потреблением на [панели использования](/ru/ja/billing/managing-spend).

Чтобы понять, во сколько обходятся примеры приложений, посмотрите простое [интерактивное демо](https://agent-pricing.replit.app/).

<div id="section-3">
  ### Отслеживание использования
</div>

Расходы на Agent можно отслеживать в реальном времени:

1. **Вкладка Agent**: наведите указатель на значок использования, чтобы увидеть стоимость отдельных чекпоинтов
2. **Панель использования**: просмотрите подробную информацию о расходах за текущий период
3. **Настройки**: настройте оповещения и бюджеты в разделе **Аккаунт** → **Оплата**, чтобы контролировать расходы

<Tip>
  Данные об использовании могут появиться на панели использования с задержкой до 30 минут.
</Tip>

<div id="section-4">
  ## Управление расходами
</div>

Контролируйте расходы на ИИ с помощью встроенных инструментов управления бюджетом Replit:

* **Оповещения об использовании**: получайте уведомления при достижении порога расходов
* **Лимиты бюджета**: устанавливайте жёсткие ограничения, чтобы избежать непредвиденных списаний
* **Отслеживание в реальном времени**: контролируйте расходы в процессе разработки
* **Пакеты кредитов**: приобретайте дополнительные кредиты со скидкой при покупке больших объёмов. Подробнее см. в разделе [Управление расходами](/ru/ja/billing/managing-spend).

<div id="section-5">
  ## Следующие шаги
</div>

Готовы начать создавать с ИИ? Чтобы максимально эффективно использовать кредиты:

* **Сначала попробуйте Agent**: изучите возможности Agent с помощью бесплатных чекпоинтов
* **Начните с малого**: начните с простых запросов, чтобы разобраться в оплате по объёму работы
* **Используйте режим Lite**: используйте [режим Lite](/ru/ja/features/agent/agent-modes) для быстрых и точечных правок
* **Настройте оповещения**: настройте уведомления о расходах до того, как исчерпаете кредиты

Узнайте больше об [ИИ-инструментах Replit](/ru/welcome) или ознакомьтесь с [тарифными планами](https://replit.com/pricing).
