<div id="o-que-uma-visualizao-de-dados">
  ## Qu&#39;est-ce qu&#39;une visualisation de données ?
</div>

Une visualisation de données est un tableau de bord interactif ou un outil de reporting que vous créez en dialoguant avec l&#39;Agent. Décrivez ce que vous souhaitez visualiser et où vos données sont stockées : l&#39;Agent sélectionne automatiquement les KPI, les types de graphiques et les mises en page adaptés, et génère un tableau de bord complet à partir d&#39;un seul prompt.

Concepts clés :

* **Génération en une seule étape** : décrivez votre objectif et votre source de données, et l&#39;Agent crée un tableau de bord complet avec les graphiques et les métriques adaptés
* **Sources de données connectées** : récupérez des données depuis des bases de données, [connecteurs d&#39;entrepôt de données](/fr/pt/connectors/warehouses/overview), des API externes ou des fichiers importés
* **Fonctionnalités intégrées** : chaque tableau de bord inclut l&#39;actualisation, l&#39;actualisation automatique, l&#39;export en PDF, l&#39;export des graphiques en CSV et le mode clair/sombre
* **Résumé d&#39;analyse** : l&#39;Agent génère des insights à partir de votre demande et des données obtenues
* **Plusieurs artifacts** : les visualisations de données peuvent partager le même backend et la même base de données que vos autres artifacts au sein du [même projet](/fr/pt/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project)

<div id="como-usar-o-data-visualization">
  ## Comment utiliser Data Visualization
</div>

<div id="criando-a-partir-de-um-prompt">
  ### Créer à partir d&#39;un prompt
</div>

Sélectionnez l&#39;onglet **App** sur la page d&#39;accueil et décrivez le tableau de bord souhaité. Agent détecte les prompts liés aux données et sélectionne la stack Data Visualization.

**Exemples de prompts :**

* « Crée un tableau de bord d&#39;analyse des ventes qui suit le chiffre d&#39;affaires par région »
* « Crée un outil de reporting qui met en forme nos métriques mensuelles »
* « Crée un tableau de bord à partir de nos données de ventes BigQuery affichant les produits les plus performants »
* « Connecte-toi à Snowflake et crée un tableau de bord d&#39;analyse du churn client »

<div id="criando-a-partir-do-menu-suspenso">
  ### Création à partir du menu déroulant
</div>

1. Rendez-vous dans l&#39;onglet **App** de la page d&#39;accueil.
2. Ouvrez le menu déroulant du type d&#39;application.
3. Sélectionnez **Data Visualization**.
4. Décrivez le tableau de bord ou l&#39;outil de données que vous souhaitez créer.

<div id="conectando-se-a-data-warehouses">
  ### Se connecter à des entrepôts de données
</div>

Connectez votre visualisation de données à BigQuery, Databricks ou Snowflake grâce aux [connecteurs d&#39;entrepôts de données](/fr/pt/connectors/warehouses/overview) afin de créer des tableaux de bord à partir de vos ensembles de données existants.

Lorsque vous interrogez les données d&#39;un entrepôt, Agent s&#39;appuie sur une recherche multiagent parallèle pour explorer votre schéma et vos ensembles de données. L&#39;exploration est ainsi plus rapide et Agent sélectionne plus facilement les tables et les champs adaptés à votre tableau de bord.

Pour commencer, configurez un connecteur d&#39;entrepôt de données dans les [Integrations](/fr/pt/features/integrations/overview) de votre projet, puis indiquez à Agent ce que vous souhaitez visualiser.

<div id="adicionando-filtros-e-recursos">
  ### Ajouter des filtres et des fonctionnalités
</div>

Une fois qu&#39;Agent a créé votre tableau de bord, vous pouvez lui demander d&#39;ajouter des filtres, des explorations détaillées (drill-downs) ou d&#39;autres fonctionnalités interactives. Par exemple, demandez à Agent d&#39;ajouter un filtre par plage de dates, un sélecteur de région ou une barre de recherche.

<div id="exportando-e-compartilhando">
  ### Exportation et partage
</div>

* **Exporter en PDF** : exportez l&#39;intégralité de votre tableau de bord au format PDF pour le partager ou le consulter hors ligne.
* **Exporter les graphiques en CSV** : téléchargez les données de chaque graphique sous forme de fichiers CSV pour les analyser plus en détail dans un tableur ou d&#39;autres outils.
* **Document d&#39;analyse** : demandez à Agent de produire un document d&#39;analyse détaillé à partir des données de votre tableau de bord.

<div id="o-que-voc-pode-construir">
  ## Ce que vous pouvez créer
</div>

* **Tableaux de bord analytiques** : suivez vos indicateurs clés, comme le chiffre d&#39;affaires, les inscriptions ou l&#39;engagement, au fil du temps
* **Outils de reporting** : créez des rapports internes que les parties prenantes peuvent filtrer et explorer sans accéder directement à la base de données
* **Interfaces d&#39;exploration de données** : parcourez et interrogez des ensembles de données avec un retour visuel
* **Tableaux de bord de supervision** : affichez des données en temps réel ou quasi réel issues d&#39;API, de bases de données ou de services externes

<div id="perguntas-frequentes">
  ## Questions fréquentes
</div>

<Accordion title="Quelles sources de données puis-je connecter ?">
  Vous pouvez extraire des données depuis la Replit Database de votre projet, depuis des connecteurs d&#39;entrepôt de données (BigQuery, Databricks, Snowflake), depuis des API externes ou depuis des fichiers importés comme des CSV. Configurez les connexions aux entrepôts de données depuis les [Integrations](/fr/pt/features/integrations/overview).
</Accordion>

<Accordion title="Puis-je personnaliser l'apparence ?">
  Oui. Vous pouvez personnaliser les couleurs, les mises en page et la typographie par la conversation : demandez à Agent de s&#39;aligner sur votre marque ou d&#39;ajuster le design. Les tableaux de bord prennent également en charge les modes clair et sombre.
</Accordion>

<Accordion title="Agent analyse-t-il les données à ma place ?">
  Une fois le tableau de bord créé, Agent génère un résumé d&#39;analyse à partir de votre demande et des données obtenues. Vous pouvez aussi demander un document d&#39;analyse plus détaillé.
</Accordion>

<Accordion title="Puis-je combiner une visualisation de données avec d'autres types d'artifact ?">
  Oui. Vous pouvez combiner une visualisation de données avec une [application web](/fr/pt/features/artifact-types/web-apps), une [présentation de slides](/fr/pt/features/artifact-types/slide-decks) ou d&#39;autres types d&#39;artifact au sein du [même projet](/fr/pt/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project). Ils partagent le même backend et la même base de données.
</Accordion>
