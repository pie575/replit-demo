title: "Agent 安全扫描"
description: "运行源代码安全审查、评估发现的问题、使用 Agent 修复漏洞，并验证修复结果。"
---

Agent 安全扫描会在整个代码库中排查与安全和隐私相关的漏洞。Security Agent 将基于模型的分析与 [Semgrep](https://semgrep.dev/)、[HoundDog.ai](https://hounddog.ai) 等静态分析工具相结合，并在 Project Security Center 中展示扫描结果。

所有付费 Replit 用户均可使用 Agent 安全扫描。对于大型 project，深度审计最长可能需要 15 分钟。

<div id="security-agent">
  ## Security Agent 检查哪些内容
</div>

启动扫描后，Security Agent 会执行以下操作：

1. 梳理路由、API、数据流和入口点。
2. 为应用构建威胁模型。
3. 对整个代码库运行静态分析。
4. 结合应用上下文评估发现的问题。
5. 生成发现的问题报告供你查看。

此项检查可识别 SQL 注入、跨站脚本、跨站请求伪造等不安全的代码模式，敏感数据流入日志或第三方 API 等隐私问题，以及路由、API 和数据流中的架构漏洞。

<div id="agent">
  ## 开始 Agent 安全扫描
</div>

<Steps>
  <Step title="打开 Security Center">
    在项目的 **Tools** 面板中选择 **Security Center**。你也可以在发布流程中选择 **Review security**。

    <Frame>
      <img src="/assets/mirror/review-security-button-9331149c28f7.png" alt="发布流程中的 Review security 操作" width="1440" height="900" data-path="images/project-security-center/review-security-button.png" />
    </Frame>
  </Step>

  <Step title="开始扫描">
    选择 **Run scan with Agent**。

    <Frame>
      <img src="/assets/mirror/run-scan-with-agent-f54820ac154a.png" alt="Project Security Center 中的 Run scan with Agent 操作" width="1440" height="900" data-path="images/project-security-center/run-scan-with-agent.png" />
    </Frame>
  </Step>

  <Step title="按需添加上下文">
    如有需要，可添加上下文，让威胁模型聚焦于应用的特定部分，然后开始安全扫描。

    <Frame>
      <img src="/assets/mirror/scan-options-c2cd398fa78b.png" alt="包含 Add context 字段和 Start security scan 操作的安全扫描选项" width="1440" height="900" data-path="images/project-security-center/scan-options.png" />
    </Frame>
  </Step>

  <Step title="等待检查完成">
    等待 Security Agent 完成检查。通常需要几分钟，大型项目最多可能需要 15 分钟。
  </Step>
</Steps>

<div id="section">
  ## 检查并修复发现的问题
</div>

<Steps>
  <Step title="查看报告">
    在 **Security Center** 中查看每一项发现的问题及其严重程度。对于你已了解且
    可以接受的发现的问题，可以将其忽略；也可以在发送修复请求之前先自行修复这些
    发现的问题。
  </Step>

  <Step title="使用 Agent 修复已确认的发现的问题">
    将已确认的问题发送给 Agent。Security Agent 会将漏洞拆分为独立任务，
    因此 Agent 可以同时推进多项修复工作。
  </Step>

  <Step title="重新运行扫描">
    Agent 应用修复后，重新运行扫描以确认问题是否已解决。在大型项目中，
    高严重程度的发现的问题解决后，可能会暴露出更多问题。
  </Step>
</Steps>

<div id="level-3">
  ## 何时使用 Level 3
</div>

Agent 安全扫描只审查源代码。如果你还需要通过浏览器和网络交互来检测正在运行的应用，请使用 [Level 3 黑盒渗透测试](/zh/ko/features/security/black-box-pen-tests)。Level 3 会同时执行黑盒测试和源代码审查。

<div id="section-2">
  ## 限制与最佳实践
</div>

* 扫描在 Replit 基础设施上运行。Replit 不会将您的代码或数据发送给 Semgrep、HoundDog.ai 或任何其他第三方。
* 扫描配置和结果始终与您的 Replit App 关联。
* 扫描并不等同于完整的安全审查，请与代码审查、测试、依赖项审查以及对运行中应用的检查结合使用。
* 在进行重大代码更改后、添加或更新依赖项后，以及发布新版本前，请重新运行扫描。
