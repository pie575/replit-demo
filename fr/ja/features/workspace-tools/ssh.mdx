<div id="ssh">
  ## Qu&#39;est-ce que le SSH ?
</div>

SSH est l&#39;abréviation de Secure Shell, un protocole sécurisé qui facilite l&#39;accès à distance à l&#39;interface en ligne de commande d&#39;une application Replit. Le SSH vous permet de transférer des fichiers en toute simplicité et d&#39;utiliser votre environnement de développement intégré (IDE) local préféré pour modifier votre code sur Replit, ce qui améliore la collaboration et la productivité de votre flux de développement.

La fonctionnalité SSH est disponible avec Core, Pro et tous les autres forfaits payants.

Voici un aperçu du processus :

* Générez une paire de clés SSH sur votre machine locale
* Ajoutez cette clé SSH dans le volet **SSH** de n&#39;importe quelle application Replit
* Connectez-vous à l&#39;aide d&#39;un client SSH ou d&#39;un éditeur compatible SSH (comme [VSCode](https://code.visualstudio.com/) ou [Cursor](https://www.cursor.com/))

<Note>
  Les clés SSH sont associées à votre compte, et non à une application Replit en particulier. Autrement dit, il vous suffit d&#39;ajouter votre clé publique une seule fois pour vous connecter à n&#39;importe quelle application Replit à laquelle vous avez accès.
</Note>

<div id="ssh-2">
  ## Pourquoi utiliser SSH
</div>

* **Mises à jour automatiques entre l&#39;application Replit et l&#39;éditeur** : les modifications effectuées dans l&#39;application Replit sont immédiatement répercutées dans l&#39;éditeur, et celles réalisées dans l&#39;éditeur le sont dans l&#39;application Replit. Cette synchronisation transparente garantit que votre base de code reste toujours à jour sur chaque plateforme.

* **Synchronisation de la gestion des fichiers** : qu&#39;il s&#39;agisse d&#39;ajouter, de supprimer ou de mettre à jour des fichiers, ces changements sont synchronisés en temps réel entre l&#39;éditeur et l&#39;application Replit. Cette fonctionnalité préserve la cohérence de la structure de votre projet, quel que soit l&#39;endroit où la modification a été initiée.

* **Gestion des dossiers et déplacement des fichiers** : le déplacement de fichiers d&#39;un dossier à un autre est lui aussi synchronisé entre l&#39;éditeur et l&#39;application Replit. Les modifications d&#39;organisation réalisées dans un environnement sont ainsi fidèlement reflétées dans l&#39;autre, ce qui préserve l&#39;intégrité et la structure du projet.

<div id="section">
  ## Trouver ou créer une paire de clés
</div>

Pour configurer SSH sur votre compte, vous devez disposer d&#39;une clé publique SSH.

<div id="section-2">
  ### Vérifier si vous disposez déjà d&#39;une paire de clés
</div>

Exécutez la commande suivante dans le terminal de votre ordinateur local pour vérifier si vous possédez déjà une clé publique :

<Tabs>
  <Tab title="Mac/Linux">
    ```sh theme={null}
    ls -l ~/.ssh
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    dir %HOMEPATH%\.ssh
    ```
  </Tab>
</Tabs>

Si une erreur s&#39;affiche, ce n&#39;est pas grave : passez à la section [Générer une nouvelle paire de clés](#generating-a-new-keypair).
Si un fichier nommé `replit.pub` apparaît, passez à la section [Obtenir le contenu de votre clé publique](#get-the-contents-of-your-public-key).

<div id="section-3">
  ### Générer une nouvelle paire de clés
</div>

Ouvrez une fenêtre de terminal (ou d&#39;invite de commandes) sur votre machine et collez-y la commande suivante :

<Tabs>
  <Tab title="Mac/Linux">
    ```bash theme={null}
    ssh-keygen -t ed25519 -f ~/.ssh/replit -q -N ""
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    ssh-keygen -t ed25519 -f %HOMEPATH%\.ssh\replit -q -N ""
    ```
  </Tab>
</Tabs>

Cette commande vérifie si le fichier de clé publique SSH indiqué existe déjà. Si ce n&#39;est pas le cas, elle crée une nouvelle clé SSH avec les paramètres appropriés.

<div id="section-4">
  ### Récupérer le contenu de la clé publique
</div>

Une fois votre paire de clés vérifiée ou créée, affichez le contenu de la clé publique (l&#39;un des deux fichiers aux noms similaires, celui qui porte le suffixe `.pub`). Vous en aurez besoin par la suite.

<Tabs>
  <Tab title="Mac/Linux">
    ```sh theme={null}
    cat ~/.ssh/replit.pub
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    notepad %HOMEPATH%\.ssh\replit.pub
    ```
  </Tab>
</Tabs>

Conservez le contenu de `replit.pub` pour l&#39;utiliser plus loin dans cet article, puis passez à [Ajouter la clé SSH à votre compte](#add-the-ssh-key-to-your-account).

<div id="ssh-3">
  ## Ajouter une clé SSH à votre compte
</div>

<div id="sshreplit">
  ### Ajouter une clé publique directement dans l&#39;application Replit à l&#39;aide du volet SSH
</div>

1. Dans l&#39;application Replit, depuis n&#39;importe quelle fenêtre, sélectionnez le bouton **+** et recherchez **SSH**.

<Frame>
  <img src="/assets/mirror/ssh-tool-2db02c6a83d0.png" alt="Bouton de l'outil SSH dans l'interface Replit" width="846" height="328" data-path="images/ssh-vscode/ssh-tool.png" />
</Frame>

2. Accédez à l&#39;onglet **Keys** et sélectionnez **New SSH key**.
3. Dans la fenêtre contextuelle, saisissez un **Label** pour la clé (par exemple : my-ssh-key), puis collez la clé publique copiée dans la section **Key**.
   Sélectionnez le bouton **Add SSH Key**. La clé est ajoutée et son utilisation est autorisée.

<Frame>
  <img src="/assets/mirror/add-ssh-key-with-values-5d6f440e56ba.png" alt="Boîte de dialogue d'ajout de clé SSH avec les champs Label et Key remplis" width="500" height="511" data-path="images/ssh-vscode/add-ssh-key-with-values.png" />
</Frame>

<div id="settings">
  ### Ajouter une clé publique directement depuis Settings
</div>

Vous pouvez également ajouter une clé SSH en ouvrant **Settings**, puis en sélectionnant **Advanced** sous **Account** (ou l&#39;option **SSH keys**). Sélectionnez **Add SSH key**, puis collez le contenu du fichier `replit.pub` obtenu à la section précédente [Trouver ou créer une paire de clés](#find-or-create-a-keypair).

<Note>
  Si votre machine possède plusieurs clés publiques, veillez à utiliser la bonne combinaison de clé privée et de clé publique dans votre configuration SSH.
</Note>

<div id="replit">
  ## Connexion à une application Replit
</div>

<div id="ssh-4">
  ### Configuration SSH
</div>

1. Dans le terminal, vérifiez que le répertoire `~/.ssh` et le fichier `~/.ssh/config` existent :

<Tabs>
  <Tab title="Mac/Linux">
    ```sh theme={null}
    mkdir -p ~/.ssh && chmod 700 ~/.ssh && touch ~/.ssh/config && chmod 600 ~/.ssh/config
    open -a 'TextEdit' ~/.ssh/config || nano ~/.ssh/config
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    if not exist %HOMEPATH%\.ssh mkdir %HOMEPATH%\.ssh && type \NUL > %HOMEPATH%\.ssh\config
    notepad %HOMEPATH%\.ssh\config
    ```
  </Tab>
</Tabs>

2. Ajoutez un bloc de configuration qui utilise la paire de clés `replit` pour tous les domaines *.replit.dev :

<Tabs>
  <Tab title="Mac/Linux/Windows">
    ```
    Host *.replit.dev
        Port 22
        IdentityFile ~/.ssh/replit
        StrictHostKeyChecking accept-new
    ```
  </Tab>
</Tabs>

<div id="vscodecursor">
  ### Se connecter depuis VSCode ou Cursor
</div>

1. Ouvrez le volet **SSH** depuis votre application Replit

2. Dans le volet SSH, ouvrez l&#39;onglet **Connect**, puis sélectionnez **Launch VS Code**.

<Tabs>
  <Tab title="Se connecter avec VSCode">
    <img src="/assets/mirror/ssh-connect-439a3c150846.png" alt="Onglet de connexion SSH affichant l'option Launch VS Code" width="788" height="482" data-path="images/ssh-vscode/ssh-connect.png" />
  </Tab>
</Tabs>

3. Si vous êtes invité à renseigner `~/.ssh/config`, saisissez ce qui suit :

   ```
   Host *.replit.dev
       Port 22
       IdentityFile ~/.ssh/replit
       StrictHostKeyChecking accept-new
   ```

   <Note>
     L&#39;ajout de la configuration SSH n&#39;est proposé que lors de la première connexion à VS Code ou à un autre éditeur. Pour revenir au fichier de configuration, sélectionnez &#42;&#42;Configure SSH Hosts...&#42;&#42;.
   </Note>

4. Si un avertissement concernant une application externe s&#39;affiche, sélectionnez **Yes** pour confirmer l&#39;ouverture du projet dans l&#39;éditeur de votre choix ou dans VS Code.

5. Il se peut qu&#39;on vous demande régulièrement d&#39;installer ou de mettre à jour l&#39;extension SSH. Replit s&#39;efforce de rester compatible avec les dernières versions de ces IDE, et des mises à jour de sécurité importantes peuvent également être proposées.

<div id="section-6">
  ### Se connecter avec un outil non répertorié ici
</div>

Il existe de nombreux clients SSH pour diverses plateformes et systèmes d&#39;exploitation, chacun offrant des fonctionnalités et des intégrations différentes.

Vous pouvez décomposer la commande affichée dans « Connect Manually » en ses différents éléments afin de déterminer comment configurer chaque client :

```sh theme={null}
ssh -i ~/.ssh/replit -p 22  c96b6ade-d5e4-4f7a-bc5b-52334509b2a3@c96b6ade-d5e4-4f7a-bc5b-52334509b2a3-00-16nh2hskw3ql8.riker.replit.dev
       ^-----v-----^    ^^  ^-----------------v----------------^ ^------------------------------v-------------------------------------^
        Private Key   Port                   User               @                           Hostname
```

**Hostname** : `<your_hostname>.<cluster>.replit.dev`
**Port** : `<port_number>`
**User** : `Username`
**Private Key** : le chemin d&#39;accès au fichier de clé privée sur votre ordinateur. Il se trouve généralement à côté de `replit.pub`.
