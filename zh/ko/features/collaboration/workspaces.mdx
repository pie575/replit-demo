<div id="section">
  ## 什么是工作区？
</div>

Replit 工作区将您的项目、用户、设置、共享资源、集成和账单信息集中管理。

每个 Replit 账户都有一个用于个人项目的个人工作区。使用付费套餐后，您还可以创建用于共享项目的团队工作区。

<Frame caption="工作区主页将最近项目、工作区导航和 Conversation 输入框汇集在同一页面上。">
  <img src="/assets/mirror/start-new-conversation-home-sanitized-neutral-874efff00786.jpg" alt="Demo Workspace 的完整 Replit 主页，包含工作区导航、常见的最近项目、推荐提示词和 Conversation 消息框" width="1451" height="1084" data-path="images/chat/start-new-conversation-home-sanitized-neutral.jpg" />
</Frame>

| 功能       | 个人工作区       | 团队工作区                |
| -------- | ----------- | -------------------- |
| **适用对象** | 独自工作或共享单个项目 | 团队、初创公司、课堂和客户项目      |
| **访问模式** | 邀请访客访问单个项目  | 成员可访问工作区中的所有项目       |
| **账单**   | 您的账户        | Pro 使用 Admin 账户的共享积分 |

<Frame caption="使用导航顶部的工作区选择器，在不同工作区之间切换。">

</Frame>

<div id="section-2">
  ## 个人工作区
</div>

个人工作区是您存放个人项目的地方。您是唯一的 Admin。其他人受邀成为项目级访客后，可以访问特定项目，但无法获得对整个工作区的广泛访问权限。

<Frame caption="由您的账户拥有的工作区会在选择器中显示为个人工作区。">
  <img src="/assets/mirror/personal-workspace-selector-a7542687e3ac.jpg" alt="显示为 Personal workspace 的工作区选择器" width="222" height="62" data-path="images/workspace/personal-workspace-selector.jpg" />
</Frame>

<div id="section-3">
  ## 团队工作区
</div>

使用团队工作区，群组可跨多个项目协作。成员可访问工作区中的所有项目，无需逐一邀请。Admin可集中管理账单和设置。

有关设置、成员管理和可用性的更多信息，请参阅[团队工作区](/zh/ko/features/collaboration/team-workspaces)。
