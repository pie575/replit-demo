<div id="revenuecat">
  ## Qu&#39;est-ce que RevenueCat ?
</div>

Dans PixelGames, Snake, Racer et Pinball sont affichés comme « Bientôt disponible ». Avec RevenueCat, vous pouvez vendre dans votre application des abonnements qui les déverrouillent, sans avoir à intégrer directement les systèmes d&#39;achat d&#39;Apple et de Google. Il vous suffit de demander à Agent d&#39;ajouter des abonnements et de connecter RevenueCat : il s&#39;occupe du reste.

<Warning>
  Apple et Google imposent tous deux l&#39;utilisation de leur propre système d&#39;achat intégré pour ce type de contenu numérique, et prélèvent chacun une commission sur les revenus des ventes. Impossible de contourner cette règle avec des liens de paiement externes.
</Warning>

<div id="section">
  ## Avant de commencer
</div>

* Un projet Replit configuré en tant qu&#39;application mobile.
* Un compte RevenueCat. Une adresse e-mail et un mot de passe suffisent ; aucun compte bancaire n&#39;est nécessaire à ce stade.

<div id="section-3">
  ## Tester les abonnements
</div>

L&#39;aperçu Replit utilise le mode test de RevenueCat. Lorsque vous testez un achat dans Expo Go, une
boîte de dialogue d&#39;achat test s&#39;affiche, sans frais réels. Une fois qu&#39;Apple aura approuvé votre
application pour l&#39;App Store, les achats réels seront facturés en argent réel : vérifiez donc vos tarifs
avant de soumettre votre application.

<Frame caption="Le paywall de PixelGames et la boîte de dialogue d'achat test affichée dans Expo Go.">
  <img src="/assets/mirror/paywall-7b66dd10c595.png" alt="L'écran du paywall de PixelGames à côté de la boîte de dialogue d'achat test de RevenueCat" data-path="images/pixelgames/mobile/paywall.png" width="2274" height="1470" data-path="images/pixelgames/mobile/paywall.png" />
</Frame>

La boîte de dialogue d&#39;achat test ci-dessus n&#39;est pas ce que verront réellement les joueurs. Expo Go
est une application publique qui sert à prévisualiser tous les projets Expo : elle ne peut donc pas
vérifier l&#39;identité RevenueCat réelle de votre application et affiche à la place un flux de test
générique. Une fois que vous disposerez d&#39;un build réel ou que votre application sera publiée, le
paywall sera l&#39;écran propre à RevenueCat, fourni à distance et non codé en dur dans l&#39;application.

<div id="app-store-connect">
  ## Synchroniser avec App Store Connect
</div>

Une fois la synchronisation effectuée, vous pouvez créer ou modifier des abonnements et des produits intégrés directement depuis RevenueCat ou Replit Agent.

Avant de connecter App Store Connect, trois éléments sont nécessaires.

* **S&#39;inscrire** : si ce n&#39;est pas déjà fait, inscrivez-vous à l&#39;Apple Developer Program. Une cotisation annuelle s&#39;applique.
* **Soumettre** : si ce n&#39;est pas déjà fait, soumettez votre application à l&#39;App Store. Consultez [Téléverser une application](/fr/build/mobile-upload-ios). RevenueCat a besoin d&#39;une fiche d&#39;application pour synchroniser les produits.
* **Connecter** : connectez un compte bancaire et **signez** le Paid Apps Agreement d&#39;Apple. Ces deux opérations s&#39;effectuent dans App Store Connect. Sans elles, Apple ne traitera aucun versement.

<Steps>
  <Step title="Démarrer la synchronisation depuis Replit">
    Dans Replit, ouvrez **Publishing → Manage**, puis sélectionnez **Sync RevenueCat to App Store Connect**. Ce bouton apparaît une fois l&#39;application soumise à TestFlight.

    <Frame caption="Lancer la synchronisation depuis le panneau Publishing de Replit.">
      <img src="/assets/mirror/rev-co-step1-e86c72c18850.png" alt="Panneau Publishing de Replit avec l'onglet Manage ouvert et le bouton Sync RevenueCat to App Store Connect affiché" data-path="images/pixelgames/mobile/rev-co-step1.png" width="997" height="420" data-path="images/pixelgames/mobile/rev-co-step1.png" />
    </Frame>
  </Step>

  <Step title="Ouvrir la page de l’API App Store Connect">
    Dans App Store Connect, rendez-vous dans **Users and Access → Integrations → App Store Connect API**
    ([ouvrir directement](https://appstoreconnect.apple.com/access/integrations/api))
    puis sélectionnez **+** pour ajouter une nouvelle clé.

    <Frame caption="Accéder aux clés de l'API App Store Connect.">
      <img src="/assets/mirror/rev-co-step2-642a879843a1.png" alt="Page Users and Access d'App Store Connect, onglet Integrations, section App Store Connect API" data-path="images/pixelgames/mobile/rev-co-step2.png" width="1466" height="657" data-path="images/pixelgames/mobile/rev-co-step2.png" />
    </Frame>
  </Step>

  <Step title="Créer une clé">
    Donnez-lui un nom (par exemple « RevenueCat »), réglez **Access** sur **App Manager**, puis
    sélectionnez **Generate**.

    <Frame caption="Création d'une clé API App Store Connect pour RevenueCat.">
      <img src="/assets/mirror/rev-co-step3-dcfbd73aafd8.png" alt="Fenêtre modale Generate API Key avec le champ du nom et l'autorisation d'accès App Manager sélectionnée" data-path="images/pixelgames/mobile/rev-co-step3.png" width="1453" height="436" data-path="images/pixelgames/mobile/rev-co-step3.png" />
    </Frame>
  </Step>

  <Step title="Copier les détails de la clé">

    <Frame caption="Copier le Key ID et télécharger la clé API App Store Connect.">
      <img src="/assets/mirror/rev-co-step4-24337a1cd6db.png" alt="Liste des clés API App Store Connect affichant la nouvelle clé RevenueCat ainsi que les actions Copy et Download" data-path="images/pixelgames/mobile/rev-co-step4.png" width="1522" height="695" data-path="images/pixelgames/mobile/rev-co-step4.png" />
    </Frame>
  </Step>

  <Step title="Ajouter à Replit">
    Revenez à la fenêtre de synchronisation de Replit (Step 1 of 2), téléversez le fichier de clé, collez le **Key ID** et l&#39;**Issuer
    ID**, puis sélectionnez **Continue**.

    <Frame caption="Saisie de la clé API App Store Connect dans Replit.">
      <img src="/assets/mirror/rev-co-step5-73640bd1925f.png" alt="Étape Step 1 of 2 de la fenêtre Replit permettant de téléverser la clé API App Store Connect et d'en coller les informations" data-path="images/pixelgames/mobile/rev-co-step5.png" width="995" height="591" data-path="images/pixelgames/mobile/rev-co-step5.png" />

  <Step title="Ajouter à Replit">

</Steps>

<div id="section-5">
  ## Dépannage
</div>

* **L&#39;achat réussit mais rien n&#39;est déverrouillé :** vérifiez que les droits d&#39;accès (entitlements) RevenueCat pointent vers les
  bons identifiants de produit.
* **Cela fonctionne en test mais plus après la publication :** vérifiez que les produits sont bien
  synchronisés avec App Store Connect et que vous avez signé le Paid Apps Agreement d&#39;Apple.

<div id="section-6">
  ## Questions fréquentes
</div>

<AccordionGroup>
  <Accordion title="Ai-je besoin d'un compte bancaire pour utiliser RevenueCat ?">
    Non. Vous n&#39;avez besoin que d&#39;une adresse e-mail et d&#39;un mot de passe pour créer un compte. Vous pourrez associer
    séparément votre compte bancaire via Apple ou Google lorsque vous serez prêt à recevoir des paiements.
  </Accordion>

  <Accordion title="Les achats test sont-ils facturés ?">
    Non. L&#39;aperçu Replit utilise le mode test de RevenueCat et les achats sont simulés.
    La facturation réelle ne commencera qu&#39;après l&#39;approbation de votre application par Apple pour l&#39;App Store.
  </Accordion>

  <Accordion title="Que puis-je configurer avec RevenueCat ?">
    Les prix, les droits d&#39;accès et le paywall lui-même. Demandez n&#39;importe quelle modification à Agent, et la configuration de RevenueCat
    ainsi que le code de l&#39;application seront mis à jour.
  </Accordion>
</AccordionGroup>
