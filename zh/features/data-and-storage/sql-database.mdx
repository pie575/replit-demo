Replit Database 采用完全托管的 SQL 数据库，让你可以在 Project Editor 中为 Replit App 添加持久化数据存储。

<Note>
  最快的上手方式是让 **Agent** 为你的应用添加数据库。Agent 会完成集成配置、创建数据库架构，并更新应用代码以实现数据的存储和读取。
</Note>

<div id="features">
  ## 功能
</div>

Replit Database 工具提供以下功能：

* **数据库工具**：使用内置的 SQL 工具运行查询、管理数据库架构并可视化数据
* **时间回溯**：将数据库恢复到任意 **Agent** checkpoint。参见[数据恢复](/zh/features/data-and-storage/data-recovery)
* **免费存储**：每个 Replit App 均包含 20GB 免费存储空间。
* **环境变量**：在 Replit App 中通过环境变量安全地访问数据库

<Info>
  在 2025 年 12 月 4 日之前，开发数据库托管在 Neon 上，存在几处关键差异。
  详情请参见[开发环境与生产环境](/zh/features/data-and-storage/development-and-production#legacy-development-database)。
</Info>

<div id="usage">
  ## 使用方法
</div>

<YouTubeEmbed videoId="zbyRuoPNIc8" title="如何在 Replit 上使用数据库" />

你可以直接在 Project Editor 中使用 Replit Database 工具。
以下各节将指导你完成数据库的设置与管理。

<Accordion title="如何打开数据库工具">
  1. 打开 **Tools** 面板，在 **Replit Cloud** 下选择 **Database**。
  2. 首页视图会列出你的所有数据库。选择其中一个 (例如 **Development Database**) 即可打开。
</Accordion>

数据库工具围绕你的数据库列表进行组织。首页视图会显示每个数据库及其存储用量，并展示当前的 **Billing Period** 和 **Hours of Compute Used**。打开某个数据库后，你会看到三个标签页：

* **Overview**：数据库中的数据表。
* **My Data**：浏览和编辑数据行，或运行 SQL 查询。
* **Settings**：连接字符串、存储用量和连接详情。

<div id="add-a-database">
  ### 添加数据库
</div>

所有 Replit App 默认都自带一个数据库。你可以在 Project Editor 中选择 <img class="icon-svg" src="/assets/mirror/postgres-c4cb2a1e2de3.svg" alt="PostgresSQL database icon" width="24" height="24" data-path="images/icons/postgres.svg" /> **数据库**工具来访问它。

要将数据库集成到 Replit App 中，你可以让 **Agent** 为你的 Replit App 添加一个 PostgreSQL 数据库，
并说明你的 Replit App 需要存储哪些数据。Agent 会创建数据库架构，
并更新你的应用，使其能够与数据库通信。

<div id="security-features">
  ### 安全特性
</div>

当你使用 **Agent** 添加数据库集成时，它会添加一个对象关系映射器 (ORM) ，
由该映射器处理所有数据库通信，并内置安全防护。

这一 ORM 层结合 Agent 对安全最佳实践的落实，通过以下特性保护你的应用免受攻击：

* **架构校验**：验证数据是否符合预期格式
* **数据清洗**：自动清理构建者输入，防止 SQL 注入攻击
