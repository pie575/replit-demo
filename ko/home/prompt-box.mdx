prompt box는 [Conversation](/ko/chat/conversations)이 시작되는 곳입니다. 필요한 내용을 설명하고, 관련 context를 추가하고, Replit과 상호작용할 방식을 선택하고, 원하는 결과를 지정할 때 사용하세요.

<Note>
  workspace permissions, integrations, 보안은 prompt box 밖에서 관리됩니다.
  prompt box는 사용자가 접근할 수 있는 context를 활용할 수 있습니다.
</Note>

<div id="ask-or-describe-the-task">
  ## 질문하거나 작업을 설명하세요
</div>

질문, 지시 사항 또는 작업을 평이한 언어로 작성하세요. 요청을 명확히 하거나 결과를 다듬으면서 같은 Conversation에서 이어갈 수 있습니다.

[대화 시작하기](/ko/home/start-a-conversation)에서 prompt box를 사용해 보세요.

<div id="add-the-right-context">
  ## 적절한 context 추가하기
</div>

Replit이 작업을 수행하는 데 필요한 정보를 제공하세요. 파일을 첨부하거나, 연결된 도구를 참조하거나, Replit에 웹 검색을 요청하거나, Figma 디자인처럼 기존 작업물을 가져올 수 있습니다. 연결된 서비스에 대한 접근 권한은 Workspace 설정과 권한에 따라 달라집니다.

* [파일 활용하기](/ko/chat/upload-and-use-files)
* [Connectors](/ko/features/integrations/overview)
* [Web Search](/ko/features/agent/web-search)
* [Figma 디자인 가져오기](/ko/design/import-figma-designs-into-replit-design)

<div id="choose-how-to-interact">
  ## 상호작용 방식 선택
</div>

작업에 맞는 방식을 선택하세요. Agent Modes는 Replit이 작업을 처리하는 방식을 바꿉니다. 사용할 수 있는 경우 Model selector에서 Auto 대신 원하는 model을 직접 고를 수 있습니다. Voice Mode를 사용하면 요청을 말로 전달할 수 있습니다.

* [Agent Modes](/ko/chat/agent-modes)
* [Model selector](/ko/chat/model-selector)
* [Voice Mode](/ko/chat/voice-mode)

<div id="name-the-outcome">
  ## 결과물을 정하세요
</div>

답변, 반복 실행되는 Routine, 앱, 프레젠테이션, 디자인, 에셋 등 원하는 결과물을 설명하세요. Replit은 이렇게 정한 목표를 기준으로 이후 작업을 진행합니다.
