<div id="section">
  ## Категории тарификации
</div>

Replit делит тарификацию хранилища приложений на следующие категории:

* **Хранилище**: объём данных, хранящихся в течение месяца. Для всех сохранённых объектов действует минимальный срок тарификации — 7 дней.
* **Передача данных**: общий объём данных, загруженных и скачанных в течение месяца.
* **Базовые операции**: операции, связанные с обновлением бакетов и объектов. Подробнее см. операции класса A в <a href="https://cloud.google.com/storage/pricing" target="_blank">тарифах Google Cloud Storage</a>.
* **Расширенные операции**: все прочие операции с облачным объектным хранилищем, включая получение конфигурации и метаданных объектов и бакетов. Подробнее см. операции класса B в <a href="https://cloud.google.com/storage/pricing" target="_blank">тарифах Google Cloud Storage</a>.

  ## Тарифы
</div>

В таблице ниже указаны тарифы для каждой категории использования.

| Категория                                 | Тариф                                                      |
| ----------------------------------------- | ---------------------------------------------------------- |
| Хранилище приложений                      | {ObjectStorageMonth} (в месяц за GiB)                      |
| Передача данных хранилища приложений      | {ObjectStorageDataTransfer} (за GiB)                       |
| Базовые операции хранилища приложений     | {ObjectStorageBasicOperationsPer1k} (за 1 000 запросов)    |
| Расширенные операции хранилища приложений | {ObjectStorageAdvancedOperationsPer1k} (за 1 000 запросов) |
