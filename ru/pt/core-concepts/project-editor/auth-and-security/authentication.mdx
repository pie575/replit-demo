Replit Auth позволяет создавать персонализированный пользовательский опыт в вашем приложении. С помощью пользовательских аккаунтов вы можете сохранять предпочтения пользователей, создавать персонализированные панели управления, добавлять социальные функции, контролировать доступ к премиум-контенту и отслеживать активность пользователей — всё, что делает приложения привлекательными и ценными.

Replit Auth использует собственную систему входа Replit: когда кто-то входит в ваше приложение, он создаёт или использует существующую **учётную запись Replit**. Страница входа оформлена в стиле Replit, а процесс входа такой же, как на сайте replit.com.

<Note>
  **Replit Auth и Clerk Auth** — Replit предлагает два варианта аутентификации. **Replit Auth** (эта страница) использует собственную систему входа Replit, поэтому пользователи вашего приложения входят с учётными записями Replit и видят страницы входа в стиле Replit. **[Clerk Auth](/ru/pt/core-concepts/project-editor/auth-and-security/clerk-auth)** предоставляет вашему приложению собственный выделенный тенант аутентификации на базе Clerk с полностью настраиваемым оформлением и пользовательскими аккаунтами, независимыми от Replit. Выберите Clerk Auth, если вам нужно собственное оформление процесса входа или аккаунты пользователей, не связанные с Replit.
</Note>

Вместо того чтобы тратить месяцы на создание аутентификации с нуля, Replit Auth предоставляет возможности уровня Enterprise с помощью одного промпта в Agent. Он основан на той же инфраструктуре, которую используют компании из списка Fortune 500, — Firebase, Google Cloud Identity Platform, reCAPTCHA, Stytch и Clearout, — и обеспечивает встроенные профессиональную защиту, предотвращение мошенничества и глобальное масштабирование.

<div id="por-que-usar-o-replit-auth">
  ## Почему стоит использовать Replit Auth
</div>

Аутентификация — сложная задача, которой целые компании посвящают свою работу. Основное назначение вашего приложения, скорее всего, не аутентификация, а уникальная идея или решение, которое вы создаёте.

Replit Auth предлагает:

* **Нулевая настройка** — Добавьте аутентификацию с помощью одного промпта в Agent
* **Интеграция с учётной записью Replit** — Пользователи входят в систему через существующие учётные записи Replit, поэтому отдельный этап создания учётной записи не требуется
* **Встроенная безопасность** — Инфраструктура Replit обеспечивает защиту от распространённых атак
* **Управление пользователями** — Упрощённое администрирование пользователей через панель Auth
* **Интеграция с базой данных** — Автоматическое добавление пользовательских записей в вашу базу данных
* **Настраиваемая страница входа** — Настройте вход в приложение в соответствии с брендом Replit
* **Сброс пароля** — Replit отправляет письма для сброса пароля за вас, поэтому вам не нужно настраивать собственного провайдера доставки электронной почты
* **Реферальная программа** — Пользователи, зарегистрировавшиеся через Replit Auth, добавляются в список ожидающих рефералов Replit
* **App в разработке и опубликованные App** — Replit Auth без проблем работает как в среде разработки (replit.dev), так и в опубликованных приложениях (replit.app и пользовательские домены)

<div id="infraestrutura-de-nvel-enterprise">
  ## Инфраструктура уровня Enterprise
</div>

Replit Auth — это не просто управление пользователями, а полностью управляемое решение для аутентификации, построенное на инфраструктуре уровня Enterprise. Благодаря этому ваше App получает те же возможности аутентификации, которыми пользуются компании из списка Fortune 500:

* **Firebase &amp; Google Cloud Identity Platform** — SLA уровня Enterprise и проверенная временем инфраструктура аутентификации Google
* **Расширенное сканирование безопасности** — Автоматическая защита от ботов и злоумышленников благодаря интеграции reCAPTCHA
* **Предотвращение мошенничества** — Проверка и валидация электронной почты с помощью Clearout для предотвращения создания поддельных аккаунтов
* **Многофакторная аутентификация** — Безопасные варианты входа на базе платформы аутентификации уровня Enterprise от Stytch
* **Глобальное масштабирование** — Рассчитано на миллионы пользователей благодаря автоматическому масштабированию и высокой надёжности

Эта инфраструктура уровня Enterprise позволяет сосредоточиться на создании уникальных функций вашего App, зная, что его аутентификация построена на той же инфраструктуре, которая защищает многомиллиардные компании. Вместо того чтобы тратить месяцы на интеграцию нескольких сервисов, вы получаете все эти возможности с помощью одного prompt в Agent.

<div id="primeiros-passos-com-o-replit-auth">
  ## Начало работы с Replit Auth
</div>

Replit Auth можно настроить только с помощью Agent. Просто добавьте запрос на Replit Auth в свой промпт:

```
Помогите мне создать App, которое [ваша идея для App] и включает Replit Auth.
```

Agent настроит весь необходимый для аутентификации код и конфигурацию. Ручная реализация не поддерживается, поскольку Agent берёт на себя всю сложность.

<div id="personalizando-a-pgina-de-login">
  ## Настройка страницы входа
</div>

<Frame>
  <img src="/assets/mirror/auth-login-1ee0460c3780.jpg" alt="Настройка аутентификации" width="1920" height="1080" data-path="images/workspace/auth/auth-login.jpg" />
</Frame>

Вы можете настроить страницу входа в соответствии с фирменным стилем вашего приложения:

1. Перейдите на панель Auth в Project Editor
2. Нажмите **Configure**
3. Настройте следующие элементы:
   * Название приложения
   * Значок приложения
   * Способы входа (Google, GitHub, X, Apple, Email)

Изменения сразу отобразятся на странице входа вашего приложения.

<div id="consideraes-de-segurana">
  ## Рекомендации по безопасности
</div>

Replit Auth использует инфраструктуру Replit и обеспечивает встроенную защиту от распространённых угроз безопасности. Однако вам всё равно следует придерживаться следующих рекомендаций:

* Всегда проверяйте аутентификацию пользователя на сервере перед выполнением важных операций
* Никогда не храните конфиденциальные данные, например пароли, в коде
* Используйте переменные окружения для ключей API и Secrets
* Настройте надлежащий контроль доступа к пользовательским данным

<div id="indicaes">
  ## Рефералы
</div>

Чтобы поощрять приложения, знакомящие пользователей с Replit, все пользователи, зарегистрировавшиеся через Replit Auth, будут автоматически добавлены в список ваших ожидающих рефералов Replit. Если позднее они перейдут на тариф Replit Core, вы получите реферальное вознаграждение, если оно предусмотрено текущими условиями реферальной программы.

<div id="soluo-de-problemas">
  ## Устранение неполадок
</div>

<div id="problemas-comuns">
  ### Распространённые проблемы
</div>

1. **Пользователь не распознаётся после входа**
   * Если возникли проблемы, попросите [Replit Agent](/ru/pt/core-concepts/agent) помочь отладить реализацию аутентификации.

2. **Пользовательский значок не отображается**
   * Убедитесь, что URL значка доступен и использует поддерживаемый формат (PNG или JPG).

3. **Недавно подключённый пользовательский домен не работает**
   * Выполните повторную публикацию, чтобы обновить список доменов (переменная среды REPLIT&#95;DOMAINS).
