Workspace Security Center доступен на всех тарифах. Используйте его для проверки [зависимостей](/ru/pt/features/security/concepts#dependency) проектов во всём вашем рабочем пространстве и просмотра обнаруженных [CVE](/ru/pt/features/security/concepts#cve) по [уровню серьёзности](/ru/pt/features/security/concepts#severity). Вы можете устранять проблемы с помощью Replit Agent, [повторно публиковать](/ru/pt/features/security/concepts#republish) затронутые проекты и экспортировать отчёты Software Bill of Materials ([SBOM](/ru/pt/features/security/concepts#sbom)) для соблюдения требований.

<Note>
  Чтобы проверить отдельный проект, откройте [Project Security Center](/ru/pt/features/security/project-security-center)
  на панели **Security** этого проекта.
</Note>

<Note>
  Впервые работаете с безопасностью зависимостей? См. [Концепции безопасности](/ru/pt/features/security/concepts) с определениями CVE, SBOM, подверженности, Fix with Agent, Republish и Auto-Protect.
</Note>

  ## Ресурсы
</div>

<div id="deteco-de-cve">
  ### Обнаружение CVE
</div>

Просматривайте уязвимости во всех проектах вашего рабочего пространства:

* Выявляйте уязвимые проекты, отсортированные по [подверженности](/ru/pt/features/security/concepts#exposure) (статусу публикации и видимости)
* Просматривайте названия затронутых пакетов, их версии и уровень серьёзности (критический, высокий, средний и низкий)
* Получайте рекомендации по устранению уязвимостей для каждого проекта

<div id="viso-de-projetos-afetados">
  ### Обзор затронутых проектов
</div>

Определите, какие проекты содержат уязвимости, и расставьте приоритеты для их устранения:

* Просматривайте сводку по уязвимым проектам с группировкой по подверженности: общее число проектов, опубликованные проекты и публично опубликованные проекты
* Просматривайте подробную информацию о затронутых проектах Replit
* Выполняйте поиск по ID CVE или названию проекта и фильтруйте по уровню серьезности, владельцу, статусу публикации (Published / Not published) и видимости (Public / Private)
* Разверните строку любого проекта, чтобы просмотреть все обнаруженные CVE (уровень серьезности, пакет, версия, ID CVE), не покидая страницу

<div id="fix-with-agent-e-republicao">
  ### Исправление с Agent и повторная публикация
</div>

Устраняйте уязвимости и повторно развертывайте приложения, не выходя из Security Center:

* Выберите **[Fix with Agent](/ru/pt/features/security/concepts#fix-with-agent)** в любом затронутом проекте, чтобы создать задачу по исправлению, которая будет выполняться в фоновом режиме. Перед повторной публикацией просмотрите и примените созданные изменения.
* Отслеживайте статус исправления по состояниям **Task in progress**, **Apply changes**, **Republish**, а также финальным состояниям **Republished** или **Failed**.
* Одним нажатием **Republish** и подтверждением в диалоговом окне можно повторно развернуть сборку с текущей конфигурацией после слияния исправления.
* Выполняйте массовые действия, например отменяйте публикацию или уведомляйте владельцев проектов об уязвимостях в их проектах.

<div id="exportao-de-sbom">
  ### Экспорт SBOM
</div>

Экспортируйте перечень компонентов ПО (SBOM) для соблюдения требований и аудита:

* Скачивайте SBOM в стандартных форматах ([SPDX](/ru/pt/features/security/concepts#spdx-and-cyclonedx), [CycloneDX](/ru/pt/features/security/concepts#spdx-and-cyclonedx))
* Создавайте отчёты для отдельных проектов или всего рабочего пространства
* Просматривайте SBOM, сгруппированные по запускам проверок, с указанием времени, количества проектов и пользователя, запустившего проверку
* Массово скачивайте все SBOM из одного запуска проверки в виде zip-архива
* Соблюдайте требования к прозрачности цепочки поставок программного обеспечения

<Note>
  Массовое скачивание SBOM доступно на тарифах Enterprise. В рабочих пространствах на других тарифах в разделе SBOM отображается предложение перейти на Enterprise.
</Note>

<div id="acessando-o-workspace-security-center">
  ## Доступ к Workspace Security Center
</div>

Чтобы открыть Workspace Security Center:

1. Перейдите на [replit.com](https://replit.com) и войдите в учётную запись.
2. На главной странице выберите **Security** в левом меню навигации.

<div id="verificando-seu-workspace">
  ## Проверка рабочего пространства
</div>

<Frame>
  <img src="/assets/mirror/security-overview-b37f090f236c.png" alt="Главный экран Workspace Security Center с общим количеством проверок, уязвимостей и CVE, сгруппированных по степени серьёзности" width="3438" height="1984" data-path="images/workspace-security-center/security-overview.png" />
</Frame>

1. Откройте Workspace Security Center.
2. Выберите **Run security scan**, чтобы проверить всё рабочее пространство.
3. Просмотрите результаты, сгруппированные по затронутым проектам, степени серьёзности и подверженности развёртывания.
4. В любом затронутом проекте выберите **Fix with Agent**, а после применения исправления — **Republish**.

Проверка анализирует зависимости в проектах Replit в рабочем пространстве и выявляет известные уязвимости на основе общедоступных реестров уязвимостей.

<div id="auto-protect">
  ## Auto-Protect
</div>

Администраторы могут включить **[Auto-Protect](/ru/pt/features/security/concepts#auto-protect)** для своей учетной записи. Эта функция непрерывно отслеживает недавно раскрытые CVE среди зависимостей всех проектов. При обнаружении совпадения Replit Agent подготавливает протестированное исправление, а создатели получают электронное письмо с прямой ссылкой для его применения.

Полный процесс и инструкции по настройке, включая доступный только администраторам порог уровня серьезности в **Settings** &gt; **Account** &gt; **Advanced**, см. в разделе [Auto-Protect](/ru/pt/features/security/project-security-center#auto-protect).

<Note>
  Обратитесь к своему персональному менеджеру по работе с клиентами за помощью в настройке Workspace Security Center или интеграции экспорта SBOM в процессы обеспечения соответствия требованиям.
</Note>
