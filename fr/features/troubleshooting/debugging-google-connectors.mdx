---

## Aperçu

Si vous voyez le message d'erreur **« Cette application est bloquée »** lorsque vous tentez de connecter un service Google Workspace (Drive, Docs, Sheets, Calendar ou Gmail) via les [Connecteurs](/fr/features/integrations/overview#connectors), cela est généralement causé par une mauvaise configuration des paramètres OAuth de Google au sein de votre organisation Google Workspace.

Ce guide vous explique comment résoudre le problème afin de pouvoir connecter les services Google à vos applications Replit.

<Frame>
  <img src="/assets/mirror/app-is-blocked-837b32f44f72.png" alt="Boîte de dialogue d'erreur Google affichant le message 'Cette application est bloquée' empêchant l'accès OAuth" width="1279" height="502" data-path="images/replitai/debugging-google-connectors/app-is-blocked.png" />
</Frame>

<Warning>
  Ces étapes s'appliquent uniquement aux comptes **Google Workspace** (comptes gérés par une organisation). Si vous utilisez un compte Google personnel lié à une adresse `@gmail.com` et que le connecteur Replit est bloqué, vous ne pouvez pas modifier la politique OAuth vous-même — contactez votre administrateur Google Workspace ou utilisez un compte différent.
</Warning>

## Étapes de dépannage

### Étape 1 : Essayez le mode navigation privée

Les extensions de navigateur ou les données en cache peuvent interférer avec le flux OAuth. L'utilisation du mode navigation privée contourne ces problèmes.

<Steps>
  <Step title="Ouvrir la navigation privée">
    Ouvrez une nouvelle fenêtre **Navigation privée** (Chrome) ou **Privée** (Firefox/Safari) dans votre navigateur.
  </Step>

  <Step title="Se connecter à Replit">
    Connectez-vous à votre compte Replit sur [replit.com](https://replit.com).
  </Step>

  <Step title="Réessayer la connexion">
    Ouvrez votre application dans l'éditeur de projet, accédez aux **Connecteurs** dans la barre latérale et essayez à nouveau de connecter le service Google.
  </Step>
</Steps>

Si l'erreur persiste, passez à l'étape 2.

### Étape 2 : Vérifiez les paramètres OAuth dans Google Workspace

<Note>
  Vous avez besoin d'accéder à la **console d'administration Google** de votre organisation pour cette étape. Contactez votre équipe informatique si vous n'avez pas accès administrateur.
</Note>

<Steps>
  <Step title="Ouvrir la console d'administration Google">
    Connectez-vous à la [console d'administration Google](https://admin.google.com) de votre organisation.
  </Step>

  <Step title="Confirmer que l'utilisateur existe">
    Accédez à la section **Utilisateurs** et confirmez que le compte tentant la connexion Replit est bien listé.

    <Frame>
      <img src="/assets/mirror/google-workspace-users-c21d8fd43f71.png" alt="Section Utilisateurs de la console d'administration Google affichant les comptes utilisateurs" width="1104" height="596" data-path="images/replitai/debugging-google-connectors/google-workspace-users.png" />
    </Frame>
  </Step>

  <Step title="Accéder aux contrôles API">
    Allez dans **Sécurité > Contrôle des accès et données > Contrôles API**.

    <Frame>
      <img src="/assets/mirror/google-workspace-api-controls-b811709315cf.png" alt="Console d'administration Google affichant le chemin de navigation Sécurité > Contrôles API" data-og-width="1140" width="1140" data-og-height="631" height="631" data-path="images/replitai/debugging-google-connectors/google-workspace-api-controls.png" data-optimize="true" data-opv="3" srcset="/assets/mirror/google-workspace-api-controls-a27d4577aee8.png 280w, /assets/mirror/google-workspace-api-controls-d681943c082d.png 560w, /assets/mirror/google-workspace-api-controls-8f1b1659e60a.png 840w, /assets/mirror/google-workspace-api-controls-795bc698b885.png 1100w, /assets/mirror/google-workspace-api-controls-c122b9eb493f.png 1650w, /assets/mirror/google-workspace-api-controls-2415c93b4f41.png 2500w" />
    </Frame>
  </Step>

  <Step title="Ouvrir l'accès aux applications tierces">
    Sélectionnez **Gérer l'accès aux applications tierces**.

    <Frame>
      <img src="/assets/mirror/third-party-app-access-eb5c94107497.png" alt="Page des contrôles API de la console d'administration Google avec le bouton Gérer l'accès aux applications tierces mis en évidence" width="1686" height="468" data-path="images/replitai/debugging-google-connectors/third-party-app-access.png" />
    </Frame>
  </Step>

  <Step title="Vérifier l'accès OAuth">
    Vérifiez que l'accès OAuth est activé pour les utilisateurs dans Google Workspace. S'il est restreint, accordez l'accès requis pour que Replit puisse compléter le flux OAuth.
  </Step>
</Steps>

Si la connexion échoue toujours, passez à l'étape 3.

### Étape 3 : Ajouter Replit comme client OAuth de confiance

Si votre organisation restreint l'accès aux applications tierces par défaut, vous devez explicitement faire confiance à Replit.

<Steps>
  <Step title="Ouvrir la console d'administration Google">
    Connectez-vous à la [console d'administration Google](https://admin.google.com) de votre organisation.
  </Step>

  <Step title="Accéder aux contrôles API">
    Allez dans **Sécurité > Contrôle des accès et données > Contrôles API**.
  </Step>

  <Step title="Ouvrir l'accès aux applications tierces">
    Sous **Contrôle d'accès aux applications**, sélectionnez **Gérer l'accès aux applications tierces**.
  </Step>

  <Step title="Ajouter une nouvelle application">
    Sélectionnez le bouton **Ajouter une application**, puis choisissez **Nom de l'application OAuth ou ID client** dans la liste déroulante.
  </Step>

  <Step title="Rechercher Replit">
    Saisissez l'ID client Replit :

    ```
    1012035106355-2dhot2e6o0malvog2ofss7akj2nsp8nq.apps.googleusercontent.com
    ```

    Sélectionnez **Rechercher**. Lorsque l'application Replit apparaît dans les résultats, sélectionnez-la.
  </Step>

  <Step title="Définir le niveau d'accès">
    Définissez le niveau d'accès sur **Approuvé**.
  </Step>

  <Step title="Enregistrer">
    Sélectionnez **Enregistrer**.
  </Step>
</Steps>

<Tip>
  Les modifications apportées aux politiques Google Workspace peuvent prendre quelques minutes à se propager. Attendez 5 à 10 minutes après l'enregistrement, puis réessayez de connecter votre service Google dans Replit.
</Tip>

## Toujours bloqué ?

Si vous avez effectué les trois étapes et que l'erreur persiste :

* **Vérifiez l'unité organisationnelle (UO)** : Les politiques Google Workspace peuvent être limitées à des UO spécifiques. Assurez-vous que les paramètres OAuth et d'application approuvée s'appliquent à l'UO contenant l'utilisateur qui tente de se connecter.
* **Examinez les alertes Google Workspace** : Dans la console d'administration, vérifiez **Rapports > Audit et investigation > Événements du journal OAuth** pour les demandes refusées liées à Replit.
* **Contactez le support Replit** : Si le problème ne vient pas de Google Workspace, contactez le [support Replit](https://replit.com/support) pour obtenir de l'aide.
