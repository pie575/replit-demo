<div id="workspaces-pessoais-vs-de-equipe">
  ## 个人 workspace 与团队 workspace
</div>

**workspace** 是用于承载你的应用、成员、设置和账单的组织结构。Replit 提供两种类型：

* 个人 workspace
* 团队 workspace

两者的区别如下：

|          | 个人 workspace  | 团队 workspace           |
| -------- | ------------- | ---------------------- |
| **角色**   | 管理员、项目级访客     | 管理员、成员、项目级访客           |
| **访问模式** | 你逐个把访客邀请到单个项目 | 成员可访问 workspace 中的所有项目 |
| **账单**   | 你的账户          | 共享管理员账户的积分             |
| **成员管理** | 按项目管理 (访问链接)  | 在 workspace 设置中集中管理    |

如果你独自工作，或只想与他人共享单个项目，**个人 workspace** 是理想选择。你是唯一的管理员，其他人只能访问你以项目级访客身份邀请他们加入的特定项目。

如果你要与固定的一群人协作构建——比如创业团队、一个班级，或有多名协作者的客户项目——**团队 workspace** 更为合适。成员可访问 workspace 中的所有项目，因此无需为每个项目逐一邀请他们。成员统一在**设置**中集中管理。

<div id="quando-convidar-para-o-workspace-ou-para-um-projeto">
  ### 何时邀请加入 workspace，何时邀请加入项目
</div>

| 场景               | 应采取的操作                                  |
| ---------------- | --------------------------------------- |
| 需要访问所有内容的长期协作者   | 邀请加入 workspace                          |
| 只需访问单个项目的外包人员或访客 | [邀请加入项目](/zh/pt/replitai/invite-teammates) |
| 新入职公司的团队成员       | 邀请加入 workspace                          |
| 帮忙调试某个特定应用的朋友    | [邀请加入项目](/zh/pt/replitai/invite-teammates) |

<div id="criar-um-workspace-de-equipe">
  ## 创建团队 workspace
</div>

<Frame>
  <video autoPlay muted loop playsInline>
    <source src="/assets/mirror/create_new_team_workspace-f665bec18450.mp4" type="video/mp4" />
  </video>
</Frame>

<Steps>
  <Step title="打开 workspace 选择器">
    在首页左上角，点击你的 workspace 名称。
  </Step>

  <Step title="创建新的 workspace">
    选择 **创建 workspace**，并为团队 workspace 取一个名称。
  </Step>

  <Step title="邀请成员">
    在邀请输入框中填写一个或多个电子邮件地址 (用逗号分隔) 。访客会收到邀请，接受后即可访问该 workspace 中的所有项目。
  </Step>
</Steps>

<div id="gerenciar-membros">
  ## 管理成员
</div>

如果你在初始设置时没有邀请成员，或后续需要添加更多成员，请前往团队 workspace 的**设置**，通过电子邮件或 Replit 用户名邀请成员。

<Frame>
  <video autoPlay muted loop playsInline>
    <source src="/assets/mirror/add_team_to_workspace_compressed-41d8163607d2.mp4" type="video/mp4" />
  </video>
</Frame>

在**设置**页面中，你还可以：

* **移除成员**，撤销其对该 workspace 中所有项目的访问权限
* 将应用从个人 workspace **转移**到团队 workspace —— 参见[将应用转移到团队](/zh/pt/teams/identity-and-access-management/transfer-app-to-teams)

如需高级身份管理、基于角色的访问控制和群组权限，请参见 [Teams](/zh/pt/category/teams)。
