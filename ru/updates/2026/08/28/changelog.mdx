<div id="intelligent-model-routing">
  ### Интеллектуальная маршрутизация моделей
</div>

Интеллектуальная маршрутизация моделей автоматически выбирает модель и уровень усилий, оптимально подходящие для вашей задачи, соблюдая баланс между качеством и стоимостью. В режимах **Power** и **Max** выберите **Auto**, чтобы Replit автоматически подбирал их для каждой части работы по мере изменения её сложности. Если вам нужен больший контроль, можно также выбрать конкретную модель и уровень усилий.

</Frame>

Подробнее см. в разделе [режим Auto](/ru/chat/auto-mode).

<div id="intelligent-model-routing-for-enterprise">
  ### Интеллектуальная маршрутизация моделей для Enterprise
</div>

Интеллектуальная маршрутизация моделей теперь используется в Agent по умолчанию для Enterprise Workspace. При включённом режиме **Auto** Replit сам выбирает оптимальный режим и разрешённую модель для каждой задачи. Администраторы аккаунта могут управлять доступностью моделей для каждого Workspace, а вы можете отключить режим **Auto** и выбрать одну из доступных моделей. В меню режимов Agent для Enterprise теперь есть **Power** и **Max**, а режим **Lite** убран.

<Frame caption="Включите режим Auto, чтобы Replit подбирал оптимальный режим и модель для каждой задачи.">

</Frame>

Подробнее об [управлении моделями в Enterprise](/ru/features/collaboration/enterprise-model-controls).

  ### Настройка connector’ов
</div>
