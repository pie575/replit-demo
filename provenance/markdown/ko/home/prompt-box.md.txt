# 프롬프트 박스

> 프롬프트 박스가 여러분의 요청, 컨텍스트, 상호작용 선택, 원하는 결과를 어떻게 하나로 모으는지 알아보세요.

프롬프트 박스는 [Conversation](/ko/chat/conversations)의 진입점입니다. 필요한 사항을 설명하고, 관련 컨텍스트를 추가하고, Replit과 상호작용할 방식을 선택하고, 원하는 결과를 명시하는 데 사용하세요.

<Note>
  워크스페이스 권한, 통합, 보안은 프롬프트 박스 외부에서 관리됩니다. 프롬프트 박스는 여러분이 사용할 수 있는 컨텍스트를 활용할 수 있습니다.
</Note>

## 작업 요청 또는 설명

질문, 지시 사항, 작업을 평이한 언어로 작성하세요. 요청을 명확히 하거나 결과를 다듬는 동안 같은 Conversation에서 계속 이어갈 수 있습니다.

프롬프트 박스를 사용해 보려면 [대화 시작하기](/ko/home/start-a-conversation)를 참고하세요.

## 올바른 컨텍스트 추가

작업에 필요한 정보를 Replit에 제공하세요. 파일을 첨부하거나, 연결된 도구를 참조하거나, Replit에 웹 검색을 요청하거나, Figma 디자인처럼 기존 작업물을 가져올 수 있습니다. 연결된 서비스에 대한 접근은 워크스페이스 설정과 권한에 따라 달라집니다.

* [파일로 작업하기](/ko/chat/upload-and-use-files)
* [커넥터](/ko/features/integrations/overview)
* [Web Search](/ko/features/agent/web-search)
* [Figma 디자인 가져오기](/ko/design/import-figma-designs-into-replit-design)

## 상호작용 방식 선택

작업에 맞는 경험을 선택하세요. Agent Modes는 Replit이 작업에 접근하는 방식을 바꿉니다. 사용할 수 있는 경우, Model selector를 통해 Auto 대신 모델을 직접 선택할 수 있습니다. Voice Mode를 사용하면 요청을 음성으로 말할 수 있습니다.

* [Agent Modes](/ko/chat/agent-modes)
* [Model selector](/ko/chat/model-selector)
* [Voice Mode](/ko/chat/voice-mode)
