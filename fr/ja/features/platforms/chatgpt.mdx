Grâce à l&#39;intégration Replit dans ChatGPT, vous pouvez créer, mettre à jour et consulter une Replit App directement depuis votre conversation, sans aucune configuration préalable. Créez de vraies applications en discutant avec ChatGPT et laissez Agent s&#39;occuper du reste.

<div id="chatgptreplit">
  ## Qu&#39;est-ce que Replit pour ChatGPT ?
</div>

Replit pour ChatGPT relie vos conversations ChatGPT à la puissante plateforme de développement de Replit. Décrivez ce que vous souhaitez créer et Agent construit pour vous une Replit App entièrement fonctionnelle. Une fois l&#39;app créée, vous pouvez demander à ChatGPT de la modifier, de la mettre à jour ou de l&#39;analyser — le tout par simple conversation.

<div id="section">
  ## Prise en main
</div>

Suivez les étapes ci-dessous pour connecter Replit à ChatGPT et créer votre première application.

<div id="replitchatgpt">
  ### Connecter Replit à ChatGPT
</div>

Il existe deux façons de connecter Replit à ChatGPT :

<Accordion title="Se connecter depuis les paramètres">
  1. Dans ChatGPT, cliquez sur l&#39;icône de votre profil
  2. Accédez à **Settings** → **Apps &amp; Connectors**
  3. Repérez **Replit**, puis cliquez sur **Connect**
  4. Effectuez l&#39;authentification OAuth avec votre compte Replit
</Accordion>

<Accordion title="Se connecter depuis une conversation">
  1. Démarrez une nouvelle conversation dans ChatGPT
  2. Appelez Replit à l&#39;aide de l&#39;une des méthodes suivantes
  3. Si la connexion n&#39;est pas établie, ChatGPT vous guidera tout au long du flux OAuth
</Accordion>

<div id="chatgptreplit-2">
  ### Appeler Replit depuis ChatGPT
</div>

Une fois la connexion établie, vous pouvez appeler Replit de trois façons :

| Méthode             | Utilisation                                         |
| ------------------- | --------------------------------------------------- |
| Mention directe     | Saisissez `Replit, <requête>` en début de message   |
| Commande slash      | Saisissez `/Replit` dans le compositeur             |
| Menu du compositeur | Cliquez sur le bouton **+** → **More** → **Replit** |

<div id="section-2">
  ### Créer votre première application
</div>

Une fois la connexion établie, créez votre première Replit App :

1. Démarrez une nouvelle conversation dans ChatGPT
2. Mentionnez Replit et décrivez ce que vous souhaitez créer (par exemple : « Replit, crée une application Todo avec un mode sombre »)
3. Agent génère l&#39;application et la déploie automatiquement
4. À la fin du processus, vous recevez un lien pour consulter votre application

<Note>
  Chaque conversation ne permet de travailler que sur une seule Replit App. Si vous créez une nouvelle application dans la même conversation, l&#39;application existante sera modifiée. Pour créer plusieurs applications, démarrez des conversations distinctes.
</Note>

<div id="section-3">
  ## Fonctionnalités
</div>

* **[Replit AI](/fr/ja/build/welcome)** : Agent génère et déploie des applications à partir de demandes en langage naturel
* **[Project Editor](/fr/ja/learn/projects-and-artifacts/project-editor)** : un environnement de développement complet accessible depuis ChatGPT
* **[Publishing](/fr/ja/learn/projects-and-artifacts/replit-deployments)** : vos applications sont déployées automatiquement et prêtes à être partagées

<Accordion title="Ce que vous pouvez faire">
  **Créer** : décrivez ce que vous souhaitez créer pour lancer une nouvelle Replit App. Agent génère l&#39;application et la déploie automatiquement.

  **Mettre à jour** : modifiez votre application dans la conversation en cours. Demandez à ChatGPT d&#39;ajouter des fonctionnalités, de corriger des bugs ou d&#39;apporter des modifications, et Agent les applique.

  **Vérifier** : analysez votre application sans la modifier. Obtenez des informations sur la structure du code, les chemins de fichiers et le comportement.
</Accordion>

<Accordion title="Formats de fichiers pris en charge">
  Vous pouvez inclure différents types de fichiers dans vos prompts :

  | Format                        | Prise en charge                        |
  | ----------------------------- | -------------------------------------- |
  | PDF                           | Oui                                    |
  | CSV                           | Oui                                    |
  | Formats de documents courants | Oui                                    |
  | Images (fichiers bruts)       | Non (utilisez plutôt une URL publique) |
  | Vidéos (fichiers bruts)       | Non (utilisez plutôt une URL publique) |

  <Note>
    Pour inclure des images ou des vidéos dans votre application, indiquez une URL publique dans votre prompt. Vous pouvez également ajouter des fichiers multimédias directement dans Replit après la création de l&#39;application.
  </Note>
</Accordion>

<Accordion title="Temps de build">
  Temps généralement nécessaire à Agent pour créer une application :

  | Complexité de l&#39;application                                             | Temps de build courant |
  | --------------------------------------------------------------------------- | ---------------------- |
  | Simple (calculatrice, petite page d&#39;accueil)                            | 2 à 3 min              |
  | Complexe (jeux, animations riches, tableaux de bord riches en informations) | 3 à 4 min              |
</Accordion>

<div id="section-5">
  ## Facturation et crédits
</div>

Le travail effectué par Replit pour ChatGPT est facturé au titre de l&#39;utilisation d&#39;Agent sur votre compte Replit.

<Accordion title="Fonctionnement de la facturation">
  * Les plans **Core** et **Pro** incluent des crédits mensuels couvrant l&#39;utilisation d&#39;Agent, le Publishing et les bases de données, dans la limite prévue
  * Vous pouvez acheter des **packs de crédits**, qui expirent au bout de 6 mois et ne se renouvellent pas automatiquement — idéals pour les lancements et les phases d&#39;expérimentation
  * Vous pouvez plafonner vos dépenses grâce aux **limites d&#39;utilisation** et aux **budgets** dans les paramètres de facturation de Replit

  Pour en savoir plus, consultez la [documentation sur la facturation de l&#39;IA](/fr/ja/billing/ai-billing).
</Accordion>

<div id="section-6">
  ## Limitations actuelles
</div>

Actuellement, l&#39;application Replit pour ChatGPT :

* ne peut travailler que sur les apps créées dans cette conversation précise ;
* ne peut pas ouvrir ni modifier :
  * les apps créées dans d&#39;autres fils de discussion ChatGPT,
  * les apps créées directement dans Replit.

La parité fonctionnelle avec l&#39;expérience Replit complète — bases de données, gestion des Secrets et contrôles plus avancés du Project Editor — sera ajoutée prochainement.

<div id="section-7">
  ## Dépannage
</div>

<Accordion title="Replit n'apparaît pas dans Browse apps">
  Si Replit n&#39;apparaît pas dans **Browse apps** :

  * Vérifiez que l&#39;application est disponible dans votre région
  * Vérifiez que l&#39;administrateur de votre espace de travail a bien activé l&#39;application Replit (Business/Enterprise/Edu)
</Accordion>

<Accordion title="Échecs de build">
  Si un build échoue, ouvrez l&#39;application dans Replit :

  * Vérifiez votre utilisation et votre facturation
  * Revenez à un état antérieur grâce aux points de contrôle et au retour arrière
  * Demandez directement de l&#39;aide à Agent depuis le Project Editor
</Accordion>
