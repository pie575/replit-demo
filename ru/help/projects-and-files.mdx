Здесь собраны ответы на вопросы о работе с проектами и файлами. См. также [Secrets](/ru/core-concepts/project-editor/app-setup/secrets), [контрольные точки и откаты](/ru/features/version-control/checkpoints-and-rollbacks) и [обзор интеграций](/ru/features/integrations/overview).

<AccordionGroup>
  <Accordion title="Как подключить Resend или другой почтовый сервис к моему App в Replit?">
    Откройте проект, перейдите в **Инструменты → Connectors**, найдите нужный сервис (например, Resend) и подключите его. После авторизации API-ключ сохраняется в проекте как секрет. Если вы настраиваете собственный почтовый домен, добавьте у DNS-провайдера DNS-записи, указанные сервисом.

    Список доступных коннекторов см. в [обзоре интеграций](/ru/features/integrations/overview), а инструкции по подключению — в разделе [Добавление интеграций](/ru/build/add-integrations).
  </Accordion>

  <Accordion title="Я случайно удалил проект — можно ли его восстановить?">
    Удалённые проекты можно восстановить в течение ограниченного времени. Откройте Shell в любом проекте и выполните:

    ```bash theme={null}
    trash view
    trash restore your-project-name
    ```

    По истечении срока хранения удалённые проекты безвозвратно удаляются. Если этот срок уже истёк, [обратитесь в службу поддержки Replit](https://replit.com/support).
  </Accordion>

  <Accordion title="Как скачать или экспортировать проект Replit?">
    В меню с тремя точками в верхней части дерева файлов выберите **Скачать как ZIP**. Скачивание больших проектов может занять некоторое время. Если скачивание не удаётся, откройте Shell, выполните `zip -r project.zip .`, а затем скачайте `project.zip` из дерева файлов.
  </Accordion>

  <Accordion title="Как предоставить доступ к проекту или добавить соавтора?">
    У вас есть три варианта:

    * **Только просмотр** — сделайте проект общедоступным, чтобы любой, у кого есть ссылка, мог его просматривать.
    * **Доступ к редактированию по приглашению** — выберите **Пригласить**, введите имя пользователя или адрес электронной почты и задайте уровень доступа.
    * **Ссылка для присоединения** — создайте ссылку для присоединения через **Пригласить**, чтобы любой, у кого есть ссылка, мог присоединиться к проекту и редактировать его.

    Core поддерживает до 5 соавторов, а Pro — до 15; соавторам не нужен платный тариф для редактирования вашего проекта. См. [Workspace](/ru/features/collaboration/workspaces).
  </Accordion>

  <Accordion title="Как подключить репозиторий GitHub к Replit?">
    Подключите учётную запись GitHub в разделе подключённых сервисов аккаунта, затем откройте [инструмент Git](/ru/features/workspace-tools/git-interface) в проекте и подключите репозиторий. Включите автосинхронизацию на панели Git для двусторонней синхронизации. Чтобы импортировать существующий репозиторий, см. [Импорт из сервисов](/ru/build/import-from-providers).

    Если синхронизация Git перестала работать, заново подключите GitHub в разделе подключённых сервисов. Токен персонального доступа с точными разрешениями обеспечивает более надёжное подключение.
  </Accordion>

  <Accordion title="Мой Repl работает медленно или редактор тормозит — что можно сделать?">
    Если редактор работает с задержками, попробуйте следующее:

    * Выполните жёсткое обновление страницы с помощью `Cmd+Shift+R` (Mac) или `Ctrl+Shift+R` (Windows).
    * Закройте неиспользуемые вкладки с файлами.
    * Откройте палитру команд с помощью `Cmd+K` (Mac) или `Ctrl+K` (Windows), найдите **Restart compute** и выберите этот пункт.
    * Попробуйте другой браузер, чтобы исключить влияние расширений.

    Если код выполняется медленно, а не редактор работает с задержками, проверьте, нет ли ресурсоёмких циклов или ограничений памяти. Использование ЦП и памяти отображается на панели ресурсов в нижней части редактора.
  </Accordion>

  <Accordion title="Как использовать переменные окружения и Secrets в моём проекте?">
    Откройте инструмент **Secrets** (иконка замка), выберите **+ New secret** и введите ключ и значение. Обращайтесь к нему в коде через `process.env.API_KEY` (Node.js) или `os.environ["API_KEY"]` (Python).

    Secrets на панели [Secrets](/ru/core-concepts/project-editor/app-setup/secrets) в среде разработки доступны только в редакторе. Для опубликованных приложений добавьте те же ключи в Secrets развертывания — они намеренно хранятся отдельно.
  </Accordion>

  <Accordion title="Как использовать Secrets аккаунта (Vault)?">
    [Secrets аккаунта](/ru/core-concepts/project-editor/app-setup/secrets) доступны во всех ваших проектах — это удобно для повторно используемых ключей. Добавьте их в настройках аккаунта, и они будут доступны в каждом вашем проекте. Если один и тот же ключ есть и в Secrets аккаунта, и на панели Secrets проекта, приоритет имеет значение проекта.
  </Accordion>

  <Accordion title="Как устранить конфликт при слиянии в Git или восстановить повреждённое состояние Git?">
    Откройте Shell и выполните `git status`, чтобы просмотреть конфликты.

    <Warning>Следующие две команды удаляют незафиксированные изменения без возможности отмены. Сначала сохраните всё, что хотите оставить: например, скопируйте отредактированные файлы за пределы проекта.</Warning>

    Чтобы отменить локальные изменения и вернуться к последнему чистому состоянию, выполните `git checkout -- .`; чтобы сбросить изменения до последнего коммита, выполните `git reset --hard HEAD`.

    Если папка `.git` повреждена и команды Git не выполняются, откройте новый чат Agent и вставьте сообщение об ошибке — Agent часто может восстановить репозиторий. См. [Восстановление после сбоев](/ru/features/version-control/disaster-recovery).
  </Accordion>

  <Accordion title="Как откатить проект к более ранней контрольной точке?">
    Replit сохраняет [контрольные точки](/ru/features/version-control/checkpoints-and-rollbacks) по мере работы Agent. На панели Agent найдите сообщение, предшествующее изменению, которое нужно отменить, выберите рядом с ним вариант отката и подтвердите действие.

    <Note>
      Replit больше не поддерживает откат опубликованного приложения к предыдущей версии. Чтобы вернуть опубликованное приложение к предыдущему состоянию, откатите project к более ранней контрольной точке (как описано выше), а затем снова опубликуйте его, чтобы развернуть это состояние. Чтобы восстановить отдельный файл, откройте его, выберите его имя и используйте **Показать историю**, чтобы восстановить предыдущую версию. См. [История файлов](/ru/features/version-control/file-history).
    </Note>
  </Accordion>

  <Accordion title="Как перенести проект в другой аккаунт Replit?">
    Projects нельзя перенести напрямую, но можно скопировать. Проще всего предоставить целевой учётной записи доступ к project и создать в ней fork этого project. Также можно скачать project в виде ZIP-архива и загрузить его в новый Repl в другой учётной записи.

    После копирования настройте в новом project Secrets, базу данных и конфигурацию deployment — они не копируются. Пошаговые инструкции, в том числе по переносу данных базы данных, см. в разделе [Копирование project в другой workspace вручную](/ru/teams/identity-and-access-management/manually-copy-projects).
  </Accordion>
</AccordionGroup>
