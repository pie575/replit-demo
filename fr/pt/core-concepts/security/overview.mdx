Lorsque vous publiez depuis Replit, votre projet peut recevoir du trafic réel. Les outils de sécurité de Replit vous aident à repérer les vulnérabilités, à corriger avec Agent les problèmes que vous avez acceptés et à conserver des preuves pour vos audits.

<div id="por-que-a-segurana-importa">
  ## Pourquoi la sécurité est importante
</div>

* Les projets publiés sont accessibles depuis l&#39;internet ouvert, y compris leurs routes et API publiques.
* Les projets modernes reposent sur de nombreux paquets, et de nouvelles CVE peuvent apparaître après la publication.
* Le code généré par l&#39;IA nécessite toujours une revue de sécurité, en particulier pour l&#39;authentification, les requêtes de base de données, les Secrets et le traitement des données.
* Les programmes de conformité exigent souvent des preuves d&#39;inventaire des dépendances, de suivi des vulnérabilités et de remédiation.

<div id="por-onde-comear">
  ## Par où commencer
</div>

* Vous travaillez sur un seul projet ? Utilisez le [Project Security Center](/fr/pt/core-concepts/security/project-security-center).
* Vous auditez l&#39;ensemble du workspace ? Utilisez le [Workspace Security Center](/fr/pt/core-concepts/security/workspace-security-center).
* Besoin d&#39;une définition ? Consultez les [concepts de sécurité](/fr/pt/core-concepts/security/concepts).

La plupart des tâches de sécurité suivent le même cycle : analyser, examiner les résultats, corriger avec l&#39;Agent, republier et exporter les preuves si nécessaire.

<div id="onde-fica-a-segurana-no-produto">
  ## Où se trouve la sécurité dans le produit
</div>

<div id="em-um-projeto">
  ### Dans un projet
</div>

Ouvrez le panneau **Security** pour consulter les résultats à l&#39;échelle du projet, lancer des analyses de sécurité avec Agent et inspecter les vulnérabilités des dépendances avant de publier.

<Frame>
  <img src="/assets/mirror/review-security-button-9331149c28f7.png" alt="Le bouton Review security dans le flux de publication du projet, qui ouvre le panneau Security" width="1440" height="900" data-path="images/project-security-center/review-security-button.png" />
</Frame>

<div id="no-seu-workspace">
  ### Dans votre workspace
</div>

Sélectionnez **Security** dans la barre latérale de la page d&#39;accueil pour examiner les vulnérabilités de tous les projets, classer les résultats par niveau d&#39;exposition et consulter l&#39;historique des analyses à l&#39;échelle du workspace.

<Frame>
  <img src="/assets/mirror/security-overview-b37f090f236c.png" alt="La vue initiale du Workspace Security Center avec le nombre total d'analyses, le nombre total de vulnérabilités et les CVE regroupés par gravité" width="3438" height="1984" data-path="images/workspace-security-center/security-overview.png" />
</Frame>

<div id="na-publicao-e-nas-configuraes">
  ### Dans la publication et les paramètres
</div>

* Dans **Publish** &gt; **Advanced**, utilisez **Block publishing of critical vulnerabilities** pour empêcher la publication des résultats critiques.
* Dans **Settings** &gt; **Account** &gt; **Advanced**, définissez le seuil de gravité d&#39;Auto-Protect pour les remédiations de dépendances préparées par l&#39;Agent.
