Существует три вида тарификации публикаций по использованию:

1. Исходящий трафик
2. Вычислительные единицы автомасштабирования
3. Запросы

Использование можно проверить в **Настройках**: **Учётная запись** → **Использование аккаунта**. Счета выставляются ежемесячно или когда накопленные расходы превышают ежемесячные кредиты. Для пользователей Replit Core и Pro установлены ежемесячные лимиты на эти ресурсы.

Если вам нужны дополнительные кредиты сверх лимита ежемесячной подписки, вы можете приобрести пакеты кредитов на странице оплаты. Подробнее о пакетах кредитов см. в разделе [Управление расходами](/ru/ja/billing/managing-spend).

<div id="section">
  # Публикация
</div>

<div id="1">
  ## 1. Исходящая передача данных при публикации
</div>

Этот вид использования тарифицируется в байтах, и для пользователей Replit Core и Pro действует ежемесячный лимит. В лимит засчитывается только исходящий (egress) трафик, при этом возможно превышение. Входящие (ingress) данные, напротив, всегда бесплатны.

| Подписка    | Лимит                                                   |
| ----------- | ------------------------------------------------------- |
| Replit Core | 100 ГиБ                                                 |
| Replit Pro  | См. [тарифы Replit Pro](https://www.replit.com/pricing) |

Лимит применяется к [статическим](/ru/ja/features/publishing/deployment-types#static), [автомасштабируемым](/ru/ja/features/publishing/deployment-types#autoscale), [зарезервированным ВМ](/ru/ja/features/publishing/deployment-types#reserved-vm) и [запланированным](/ru/ja/features/publishing/deployment-types#scheduled) деплоям.

Актуальные цены на исходящую передачу данных смотрите на [странице тарифов](https://www.replit.com/pricing).

***

<div id="2">
  ## 2. Вычислительные единицы
</div>

Автомасштабируемые деплои тарифицируются по вычислительным единицам, которые учитывают использование как CPU, так и RAM во времени.

Превышение лимитов также тарифицируется по вычислительным единицам. Счёт детализируется вплоть до отдельных вычислительных единиц. Актуальные цены на вычислительные единицы смотрите на [странице тарифов](https://www.replit.com/pricing).

Ниже показано, как секунды RAM и CPU автомасштабируемых деплоев пересчитываются в вычислительные единицы:

| Ресурс        | Вычислительные единицы |
| ------------- | ---------------------- |
| 1 секунда RAM | 2 единицы              |
| 1 секунда CPU | 18 единиц              |

Статические деплои не расходуют вычислительные единицы. Плата взимается только за исходящую передачу данных сверх [указанного объёма](#).

[Подробнее об автомасштабируемых деплоях](/ru/ja/features/publishing/deployment-types#autoscale).

***

<div id="3">
  ## 3. Запросы
</div>

При автомасштабируемых деплоях также учитывается количество запросов.

Актуальные цены на запросы указаны на [странице цен](https://www.replit.com/pricing).

<div id="section-2">
  # Базы данных
</div>

Replit взимает плату только за использование [продакшен-базы данных](/ru/ja/features/data-and-storage/development-and-production) — базы данных для разработки всегда бесплатны и включены в каждое приложение Replit. Подробнее см. в разделе [Базы данных для разработки](/ru/ja/features/data-and-storage/sql-database).

Replit PostgreSQL — полностью управляемое бессерверное решение, которое обеспечивает высокую доступность без лишних хлопот и не требует обслуживания. Плата за продакшен-базы данных начисляется по фактическому использованию, что позволяет заметно сократить расходы.

Стоимость продакшен-баз данных PostgreSQL рассчитывается по двум показателям использования:

* **[Вычислительное время](#compute-time)**: объём вычислительных ресурсов, потребляемых за час.
* **[Хранение данных](#data-storage)**: общий объём хранимых данных (включая исторические).

Текущее потребление ресурсов, в том числе продакшен-базами данных, можно посмотреть в разделе **Настройки** → **Аккаунт** → **Использование аккаунта**.

<div id="section-3">
  ## Вычислительное время
</div>

Вычислительное время определяется количеством часов, в течение которых база данных оставалась активной в рамках указанного расчётного периода. База данных считается активной с момента получения запроса и ещё 5 минут после последнего запроса. Если база данных простаивает 5 минут, она приостанавливается и переходит в неактивное состояние.

<div id="section-4">
  ## Хранение данных
</div>

Хранение данных — это общий объём данных, сохранённых во всех базах данных вашей учётной записи; измеряется в гибибайтах (ГиБ). Объём хранилища рассчитывается как максимальный объём, использованный за месяц. Каждая база данных PostgreSQL занимает 33 МБ, даже если не содержит данных, — это стандартный объём, который занимает сам сервер Postgres.

<Note>Общий лимит хранилища для каждой продакшен-базы данных составляет 10 гибибайт (ГиБ). Базы данных для разработки включают 20 ГиБ бесплатного хранилища на каждое приложение Replit.</Note>
