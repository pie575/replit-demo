  ### 有多个合适选项时，Agent 会推荐连接器
</div>

当你让 Agent 连接某项服务，而有多个连接器都适用时，Agent 现在会显示一个简短列表供你选择。此前，Agent 需要先进一步询问。选择一个提供方并登录一次后，Agent 就会继续构建。

<div id="workspace">
  ## Workspace
</div>

<div id="conhea-o-novo-painel-tools">
  ### 了解全新的 Tools 面板
</div>

现在，您的应用可用的一切都集中在 workspace 中的一个位置。固定显示的全新 Tools 面板将 Database、Auth、Domains、Secrets 等功能汇集于一处，让您能快速找到所有工具。工具本身没有变化，只是位置更清晰了。

<Frame>
  <img src="/assets/mirror/tools-pane-ceaddcc1d7a2.png" alt="workspace 的 Tools 面板，其中列出了 Replit Cloud 中的 Publishing、Domains、Monitoring、Growth、Database、Users and Auth、安全中心和 App Storage" width="390" height="716" data-path="images/changelog/2026-07-17/tools-pane.png" />
</Frame>

详细了解 [Tools 面板](/zh/pt/features/editor/editor-and-tools)。

<div id="uma-barra-lateral-de-tarefas-mais-rpida">
  ### 更快捷的 task 侧边栏
</div>

task 侧边栏现已升级为更紧凑、更便于快速浏览的 task 导航器。每个 task 都有独立的悬停卡片，可用于快速操作和查看详细信息；任务看板的入口更加清晰，并且展开或收起侧边栏时，task 会保持原位，不再随之移动。

<Frame>
  <img src="/assets/mirror/task-sidebar-7687ab8089b2.png" alt="Workspace task 侧边栏显示 Main、Board 和 New task，以及 task 列表和所选 task 的 Apply changes 卡片" width="1228" height="556" data-path="images/changelog/2026-07-17/task-sidebar.png" />
</Frame>

详细了解 [task 生命周期](/zh/pt/features/agent/task-lifecycle)。
