对话是一个独立的会话线程，可用于提问、查找信息、运行例程或说明成果。在 Replit 中，所有任务都从对话开始。

<Note>
  对话是私密的，在工作区中只有你本人可以访问。如果需要协作，请让 Replit 创建一个项目。
</Note>

<div id="section-6">
  ## Conversation 与 Project
</div>

Conversation 是用于提问、调研和运行 routine 的单个线程。[Project](/zh/ja/features/projects-and-artifacts/projects) 则是更深入的工作区，适合包含多个 artifact 的正式构建与设计工作。

不妨先从 Conversation 开始。当工作发展为正式的构建或设计时，你可以将 Conversation 转换为 Project。

在侧边栏中，Conversation 使用聊天气泡图标，Project 使用由四个方块组成的网格图标。

<Frame>
  <img src="/assets/mirror/conversation-and-project-icons-025a17613daa.png" alt="Replit 侧边栏，显示带有四方块网格图标的 Project 和带有聊天气泡图标的 Conversation" width="466" height="290" data-path="images/chat/conversation-and-project-icons.png" />
</Frame>

| 方面      | Conversation  | Project                             |
| ------- | ------------- | ----------------------------------- |
| 最适合的场景  | 提问、调研、routine | 应用、幻灯片、仪表盘、多个 artifact 等更深入的构建与设计工作 |
| 后台任务    | **不可用**       | **可并行运行**                           |
| routine | **可用**        | **不可用**                             |
| 集成      | 可用            | 可用                                  |
| 结构      | 单个线程          | 包含多个 artifact 的 Project 工作区        |
