<div id="build-your-first-version-with-free-mode">
  ## 使用 Free Mode 构建首个版本
</div>

使用 Free Mode，无需消耗积分即可将想法变为可用的初始版本。{FreeModePlanAvailability}

开始构建前，请在提示框下方的模式选择器中选择 **Free**。

<div id="build-in-focused-steps">
  ## 分步骤专注构建
</div>

每次只向 Replit 提出一个明确的下一步，Free Mode 的效果最佳。先从能够验证想法的 App 版本开始，再在此基础上逐步构建。

1. **描述你想构建的内容。** 从预期成果、目标用户以及它首先需要实现的功能说起。
2. **构建核心流程。** 每次只请求一个界面、功能或交互，而不是一次要求实现所有可能的功能。
3. **预览并完善。** 测试 Replit 创建的内容，然后根据眼前的结果提出下一项改进。
4. **保留上下文。** 在同一个 Conversation 中继续操作，这样 Replit 就能基于你的决策和现有 App 继续构建。

例如，你可以这样开始：“构建一个简单的跑步记录器，让我可以记录跑步、查看每周总量并添加目标。”然后逐步完善界面、添加数据，并在过程中测试每一步。

<div id="make-the-allowance-go-further">
  ## 让额度物尽其用
</div>

* 将较大的功能拆分为小型、可测试的请求。
* 告诉 Replit 哪些内容需要更改、哪些需要保留，尤其是在优化现有界面时。
* 在构建更复杂的功能之前，通过后续提问明确计划。
* 回到项目时，带着明确的下一步操作，例如添加验证、优化移动端布局或连接表单。

<div id="check-your-allowance">
  ## 查看你的额度
</div>

打开 **设置** → **Usage**，查看剩余的 Free Mode 额度以及额度刷新时间。

<Frame caption="Usage 页面会显示剩余的 Free 额度。">
  <img src="/assets/mirror/free-mode-usage-sanitized-1b738ae092bb.jpg" alt="设置中的 Usage 页面，显示 Free 额度面板" width="1538" height="1022" data-path="images/chat/free-mode-usage-sanitized.jpg" />
</Frame>

如果需要更强的能力、想选择特定模型，或已用完 Free Mode 额度，请切换到 **Power Mode** 或 **Max Mode**。这些模式使用每月积分。
