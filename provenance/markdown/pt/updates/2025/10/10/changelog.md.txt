### Visibilidade do custo de uso do Agent

Veja os custos de uso do Agent em tempo real enquanto as tarefas são executadas. Abra o drawer do cabeçalho do chat para monitorar os gastos de tarefas ativas—especialmente útil para execuções mais longas e com maior autonomia.

### Tecla Escape para o modo Visual Select/Edit

Pressione Escape para sair do modo Visual Select ou retornar ao modo de criação. Um atalho simples que mantém você em movimento.

### Parada mais rápida do Agent

O Agent responde mais rapidamente quando você o para ou inicia a partir do espaço de trabalho, reduzindo o tempo de espera.

### Melhorias na importação do GitHub

Obtenha progresso em tempo real durante as importações do GitHub em vez de mensagens genéricas, além de velocidades de importação mais rápidas.

### Verificação de vulnerabilidades de dependências

O scanner de segurança agora detecta vulnerabilidades de dependências para Go, JavaScript, Python e Rust, com mais linguagens chegando em breve.

### Experiência de logging do Webview

Visualize logs do webview e saída do console em um único lugar—os mesmos logs que o Agent usa—tornando a depuração mais simples.

## Equipes e Enterprise

### Acesso de assentos de suporte para equipes

Adicione o Suporte do Replit como uma conta Guest que não é contabilizada na cobrança. Conceda acesso com escopo limitado a Apps específicos quando precisar de ajuda, mantendo a privacidade do espaço de trabalho sob seu controle.
