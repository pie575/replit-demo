<div id="section">
  ## Qu’est-ce qu’un projet ?
</div>

Un projet est le conteneur de tout ce que vous créez dans Replit. Il contient votre code, vos données et tous les artefacts que vous créez — applications web, applications mobiles, présentations, tableaux de bord de données et vidéos. Indiquez à Agent ce que vous souhaitez, et il configurera un projet et y créera des artefacts.

Considérez votre projet comme un espace de travail sur votre bureau. Tout se trouve au même endroit et peut partager les mêmes informations, mais chaque élément a un objectif différent.

Par exemple, si vous demandez à Agent de créer une application de suivi de l’activité physique, il créera un projet comprenant un artefact d’application mobile, ainsi que le backend, la base de données et le stockage nécessaires.

<ArtifactGrid />

Concepts clés :

* **Projet** : conteneur regroupant le code, les données et tous les artefacts
* **Artefact** : résultat publiable au sein d’un projet (application web, présentation, vidéo, etc.)
* **Ressources** : tous les artefacts peuvent accéder automatiquement au backend, à la base de données et au stockage de fichiers, sans configuration supplémentaire

<Note>
  Lorsque vous publiez, l’ensemble du projet est mis en ligne en une seule fois. Tous les artefacts sont publiés ensemble et restent donc toujours synchronisés.
</Note>

  ## Ce que vous pouvez créer
</div>

| Type                                                                         | Description                                                                    | Exemples                                                                              |
| ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------- |
| **[Applications web](/fr/ko/features/artifact-types/web-apps)**                 | Sites et applications web que les utilisateurs consultent dans leur navigateur | Boutiques en ligne, outils de réservation, sites portfolio                            |
| **[Applications mobiles](/fr/ko/features/artifact-types/building-mobile-apps)** | Applications natives que les utilisateurs installent sur leur téléphone        | Applications de suivi d’activité physique, applications de commande de restaurant     |
| **[Visualisations de données](/fr/ko/features/artifact-types/data-apps)**       | Tableaux de bord interactifs avec graphiques, filtres et données en temps réel | Rapports de ventes, suivis de métriques, vues analytiques                             |
| **[Présentations](/fr/ko/features/artifact-types/slide-decks)**                    | Présentations à présenter ou à exporter                                        | Présentations commerciales, mises à jour d’équipe, aperçus de produits                |
| **[Animations](/fr/ko/features/artifact-types/animated-videos)**                | Vidéos en motion design exportables au format MP4                              | Vidéos de lancement de produit, vidéos explicatives, contenu pour les réseaux sociaux |
| **Jeux 3D**                                                                  | Jeux 3D, simulations ou expériences interactives                               | Jeux de puzzle, simulations physiques, expériences interactives                       |
| **[Design](/fr/ko/design/canvas)**                                              | Orientations visuelles et prototypes à explorer dans le Canvas Design          | Planches d’inspiration, maquettes, explorations de design                             |

Un projet peut contenir plusieurs artefacts. Par exemple, vous pouvez créer dans le même projet une application web pour vos clients, une application mobile pour votre équipe et une présentation pour vos investisseurs. Lorsque les artefacts se trouvent dans le même projet, ils partagent automatiquement les mêmes données et la même logique côté serveur. Pour en savoir plus, consultez les [artefacts](/fr/ko/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project).

<div id="section-3">
  ## Gérer les projets
</div>

La page des projets répertorie tous les projets que vous avez créés ou auxquels vous avez été invité. C’est le moyen le plus rapide de retrouver vos travaux récents et de trouver le bon projet dans un espace de travail très actif.

<div id="section-4">
  ### Voir en un coup d’œil le contenu de chaque projet
</div>

Chaque carte de projet affiche de petites icônes pour les différents artefacts qu’il contient, comme des applications web et mobiles, des présentations, des visualisations de données et des animations. Survolez une icône pour afficher un aperçu de la capture d’écran de l’artefact directement depuis la carte et distinguer les projets sans avoir à les ouvrir.

<div id="section-5">
  ### Filtrer par artefact
</div>

Utilisez le menu déroulant **Type de build** en haut de la page des projets pour filtrer la liste par artefact. En sélectionnant un type, vous ne verrez que les projets contenant ce type d’artefact.

* **Web** — Projets contenant une application web
* **Mobile** — Projets contenant une application mobile
* **Données** — Projets contenant des visualisations de données
* **Diapositives** — Projets contenant une présentation
* **Design** — Projets en mode Design
* **Jeux 3D**, **Agent et automatisation**, etc.

Pour supprimer le filtre, sélectionnez **Tous les types de build**.

<div id="section-6">
  ### Trier par dernier projet ouvert
</div>

Par défaut, la page des projets est triée selon **le dernier projet que vous avez ouvert**. Le projet sur lequel vous avez passé le plus de temps récemment s’affiche en haut. Cela est particulièrement utile dans les espaces de travail d’équipe, où les modifications récentes apportées par d’autres membres peuvent reléguer votre travail en cours au second plan.

Vous pouvez modifier le critère de tri en sélectionnant un autre en-tête de colonne, par exemple **Dernière mise à jour** ou **Nom**.

<div id="section-7">
  ### Épingler les projets que vous utilisez le plus
</div>

Les projets épinglés restent en haut de la liste. L’épinglage s’applique **uniquement à vous** : épingler un projet dans un espace de travail d’équipe ne modifie pas ce que voient les autres membres.

Pour épingler un projet, ouvrez le menu Plus (trois points) de la carte du projet, puis sélectionnez **Épingler**. Pour le désépingler, sélectionnez **Désépingler** dans le même menu.
