Replit 的版本控制功能让你能够安心地跟踪、管理代码库，并与他人协作。借助内置的 Git 集成和 GitHub 连接功能，你可以：

* 跟踪代码更改，保留开发工作历史
* 与团队成员协作，避免代码冲突或工作丢失
* 在 Replit 和 GitHub 之间导入、修改和推送代码
* 使用分支安全地试验新功能

<div id="what-is-version-control">
  ## 什么是版本控制？
</div>

版本控制是一种记录文件随时间推移所发生变更的系统，让你可以在之后找回特定版本。在 Replit 上，版本控制由用于跟踪代码变更的行业标准工具 Git 提供支持，并提供易用的可视化界面，无需掌握命令行知识。

<div id="how-version-control-works-on-replit">
  ### Replit 中的版本控制如何工作
</div>

四种版本控制方式都基于同一个底层 Git 仓库：

1. **Agent Checkpoints** 会在使用 [Replit Agent](/zh/features/agent/overview) 进行构建时的重要节点自动创建提交。[详细了解 checkpoint 和 回滚](/zh/features/version-control/checkpoints-and-rollbacks)。
2. **Git 面板** 提供对完整 Git 仓库的可视化访问
3. **Git CLI** 提供对全部 Git 功能的命令行访问
4. **File History** 跟踪单个文件中的细粒度更改

选择最适合你需求的界面；所有内容都由 Git 强大的版本控制系统提供支持。

| 功能            | Agent Checkpoints | Git 提交         | 文件历史          |
| ------------- | ----------------- | -------------- | ------------- |
| **创建方式**      | 在关键节点自动创建         | 手动或按计划创建       | 自动            |
| **粒度**        | 功能级更改             | 任意规模的更改        | 字符级更改         |
| **描述**        | AI 生成的摘要          | 用户编写的消息        | 自动时间戳         |
| **回滚**  | 一键恢复              | 需要了解 Git       | 一键恢复          |
| **Git 功能**    | 完整 Git 功能         | 完整 Git 功能      | 不支持 Git 功能    |
| **GitHub 同步** | 完整 GitHub 同步功能    | 完整 GitHub 同步功能 | 不支持 GitHub 同步 |

<div id="getting-started">
  ## 开始使用
</div>

将 Git 工具添加到 Project Editor 后，即可在 Replit App 中使用版本控制：

1. 前往 Replit App 中的“工具”区域
2. 选择 **+** 以添加新工具
3. 在可用工具列表中选择 **Git**

要从 GitHub 导入现有项目，请参阅[从 GitHub 导入](/zh/build/import-from-providers)。

<div id="automatic-version-control">
  ### 自动版本控制
</div>

<Accordion title="Agent Checkpoint">
  在使用 [Replit Agent](/zh/features/agent/overview) 进行 AI 辅助开发时自动创建的快照。

  **最适合**：使用 Replit Agent 开发

  **主要功能**：

  * 在关键节点自动创建
  * 一键回滚
  * 功能级快照
  * 进度跟踪
  * 无需设置
  * 开发进度可视化时间线

  Agent checkpoint 存储在 Git 中，可通过 Git 面板 或 Git CLI 访问。你还可以通过 History 功能直观查看所有 checkpoint，该功能提供：

  * 按时间顺序展示 checkpoint
  * 详细的 checkpoint 说明
  * 直接访问 checkpoint 状态
  * 一键回滚到任意 checkpoint
</Accordion>

<Accordion title="文件历史">
  对直接在编辑器中进行的非 Agent 更改按文件跟踪版本，并自动保存。

  **最适合**：快速恢复最近的文件更改

  **主要功能**：

  * 聚焦单个文件
  * 字符级更改
  * 可视化对比
  * 30 天历史记录
  * 回放功能

  虽然文件历史提供独立的界面，但底层更改仍属于 Git 历史记录的一部分。详细了解[文件历史](/zh/features/version-control/file-history)。
</Accordion>

  ### 基于 Git 的界面
</div>

<Accordion title="Git 面板">
  用于执行 Git 操作的可视化界面，无需掌握命令行即可使用版本控制。

  **最适合**：需要 GitHub 集成和可视化工作流的大多数项目

  **主要功能**：

  * 全仓库变更跟踪
  * 分支管理
  * 可视化查看差异
  * 一键同步 GitHub
  * 团队协作

  有关如何使用 Git 面板 的详细说明，请参阅[使用 Git 面板](/zh/features/workspace-tools/git-interface)。
</Accordion>

<Accordion title="Git CLI">
  通过 [Shell](/zh/features/workspace-tools/shell) 完整访问 Git 命令行，适用于高级操作。

  **最适合**：需要完整 Git 功能的高级用户

  **主要功能**：

  * 完整的 Git 命令集
  * 高级分支策略
  * 自定义工作流
  * 脚本自动化
  * 完全控制仓库

  有关常用 Git 命令及其用法，请参阅[使用 Git 面板](/zh/features/workspace-tools/git-interface#using-git-commands-in-shell)。
</Accordion>

<div id="key-features">
  ## 主要功能
</div>

* **可视化 Git 界面**：无需输入 Git 命令，即可管理仓库、提交和分支
* **GitHub 集成**：连接 GitHub 仓库，实现备份与协作
* **从 GitHub 导入**：只需点击几下，即可将任何 [GitHub 仓库导入为 Replit App](/zh/build/import-from-providers)
* **分支管理**：直接在 Project Editor 中创建、切换和合并分支
* **冲突解决**：借助可视化工具识别并解决合并冲突

<div id="use-cases">
  ## 使用场景
</div>

**跟踪个人项目**

在开发过程中跟踪代码变更，以便在需要时恢复到先前版本。[Git 面板](/zh/features/workspace-tools/git-interface)会以可视化方式显示变更内容，方便你提交有意义的更新。

**团队协作**

与多位开发者共同处理同一代码库，而不会覆盖彼此的变更。为新功能创建分支，准备就绪后再将其合并回主分支。详细了解如何[邀请团队成员](/zh/build/invite-teammates)。

<div id="agent-checkpoints">
  ## Agent checkpoint
</div>

使用 [Replit Agent](/zh/features/agent/overview) 构建应用时，checkpoint 可提供额外一层版本控制保障。checkpoint 会在 AI 辅助开发过程中的关键时刻自动记录项目的完整状态，包括项目内容、AI 对话上下文以及已连接的数据库。

<div id="how-checkpoints-work">
  ### checkpoint 的工作方式
</div>

Agent checkpoint 是整个 Replit App 状态的完整快照：

* **自动创建**：Agent 会在开发过程中的适当节点创建 checkpoint
* **完整状态捕获**：每个 checkpoint 都会保留 project 内容、AI 记忆和数据库状态
* **实施计划**：在进行更改前，Agent 会先展示计划供你审核
* **复杂 task 跟踪**：较大的 task 可能会创建多个 checkpoint

<div id="benefits-for-ai-assisted-development">
  ### AI 辅助开发的优势
</div>

使用 AI 构建应用时，Agent checkpoint 具有独特优势：

* **安全保障**：放心尝试，因为你可以轻松将整个开发环境恢复到之前的状态
* **进度跟踪**：清楚了解 Agent 如何逐步构建你的应用
* **逻辑里程碑**：checkpoint 代表完整的功能，而不是任意的保存点
* **即时回滚**：只需点击一下，即可恢复到任一先前状态，包括数据库和 AI 上下文

<Info>
  有关 checkpoint 捕获内容和完整回滚功能的详细信息，请参阅 [Checkpoints and Rollbacks](/zh/features/version-control/checkpoints-and-rollbacks)。
</Info>

<Tip>
  虽然 Agent checkpoint 非常适合 AI 辅助开发，但对于长期版本跟踪和协作，建议使用 Git 提交，尤其是在使用外部仓库时。
</Tip>
