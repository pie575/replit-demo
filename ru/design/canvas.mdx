Canvas — это бесконечная поверхность, которую можно панорамировать и масштабировать, где Replit Design отображает ваши фреймы. Здесь находится всё, что вы создаёте: генерируйте фреймы, перетаскивайте их, приближайте отдельные детали и дорабатывайте, пока не получите нужный результат.

<div id="open-the-canvas">
  ## Откройте Canvas
</div>

Canvas — первое, что вы видите в Replit Design. В Project выберите **Design** в заголовке, и Canvas заполнит панель. Чтобы вернуться к работающему приложению, выберите **Build**.

<Frame>
  <img src="/assets/mirror/canvas-design-button-ffa50447cefb.png" alt="Крупный план заголовка Project с переключателем Design и Build: выбран Design; ниже расположены фреймы на Canvas" width="987" height="619" data-path="images/replitai/canvas-design-button.png" />
</Frame>

Если начать с нуля на [replit.com/design](https://replit.com/design), вам будет предложено создать новый дизайн, который откроется на Canvas. О том, когда использовать каждую среду, см. [Design и Build](/ru/design/design-vs-build).

<div id="what-lives-on-the-canvas">
  ## Что находится на Canvas
</div>

* **Фреймы**: каждая плитка на доске. Фрейм может быть макетом, веб-приложением, мобильным приложением, презентацией, изображением, видео или векторной графикой. Создавайте их с помощью prompt в чате, [меню Generate](/ru/design/toolbar#generate) на панели инструментов или [панели библиотеки](/ru/design/library-panel). Всё, что вы делаете с фреймом — Build, Фокус, предложения, — происходит непосредственно в нём: см. [Фреймы](/ru/design/frames).
* **Рисунки и заметки**: разметка, которую вы добавляете с помощью [инструмента Draw](/ru/design/toolbar#draw): наброски, стрелки, фигуры и стикеры. Agent считывает вашу разметку, поэтому вы можете обвести проблемную область и попросить внести изменения.
* **Панель чата**: чат с Agent, закреплённый рядом с Canvas. Если выбрать фреймы перед отправкой сообщения, они будут прикреплены в виде снимков, чтобы Agent получил визуальный контекст.

Описание каждого компонента и их взаимодействия см. в [обзоре компонентов](/ru/design/core-components).

<div id="navigate-the-board">
  ## Навигация по доске
</div>

Панорамирование, масштабирование и выделение доступны в любом инструменте, если не указано иное.

**Панорамирование:**

* Трекпад: перетаскивание двумя пальцами.
* Мышь: перетаскивание средней кнопкой мыши либо удерживайте пробел и перетаскивайте левой кнопкой мыши.
* [Инструмент «Панорамирование»](/ru/design/toolbar#pan): перетаскивание левой кнопкой мыши.

**Масштабирование:**

* Трекпад: сведение или разведение пальцев.
* Мышь: `Ctrl` (или `Cmd` в macOS) + колесо прокрутки.
* Клавиатура: `Cmd`/`Ctrl` + `+` для увеличения, `Cmd`/`Ctrl` + `-` для уменьшения, `Cmd`/`Ctrl` + `0` для сброса масштаба.

Масштабирование происходит относительно курсора, поэтому точка под ним остаётся на месте, пока остальная часть доски масштабируется вокруг неё.

**Выделение:**

* Один фрейм: щёлкните по нему инструментом [«Взаимодействие»](/ru/design/toolbar#interact).
* Несколько фреймов: удерживайте `Shift` и щёлкайте по каждому фрейму либо протяните по доске прямоугольную область выделения.
* Снять выделение: щёлкните по пустой области или нажмите `Escape`.

При выборе одного или нескольких фреймов появляется [панель действий для каждого фрейма](/ru/design/frames#per-frame-action-bar), а сами фреймы прикрепляются к следующему сообщению Agent в виде снимков.

<div id="keyboard-shortcuts">
  ### Сочетания клавиш
</div>

| Сочетание клавиш                   | Действие                             |
| ---------------------------------- | ------------------------------------ |
| `V`                                | Активировать инструмент «Взаимодействие»     |
| `H`                                | Активировать инструмент «Панорамирование»          |
| Удерживать `Space` и перетаскивать | Панорамировать при любом инструменте |
| `Cmd` / `Ctrl` + прокрутка         | Масштабировать                       |
| `Cmd` / `Ctrl` + `+`               | Увеличить масштаб                    |
| `Cmd` / `Ctrl` + `-`               | Уменьшить масштаб                    |
| `Cmd` / `Ctrl` + `0`               | Сбросить масштаб                     |
| `Shift` + щелчок                   | Добавить фрейм к текущему выделению  |
| `Cmd` / `Ctrl` + `Shift` + `C`     | Скопировать выбранный фрейм в PNG    |
| `Escape`                           | Снять выделение                      |

<div id="right-click-menu">
  ## Контекстное меню
</div>

Щёлкните правой кнопкой мыши в любом месте доски, чтобы открыть контекстное меню. Его содержимое зависит от того, что находится под курсором: для фрейма доступны действия с фреймом, для пустого Canvas — действия на уровне доски, а для фрейма приложения также доступно действие **Обновить артефакт**.

Меню выбранного фрейма включает:

| Действие                                   | Сочетание клавиш              | Описание                                                                          |
| ------------------------------------------ | ----------------------------- | --------------------------------------------------------------------------------- |
| Редактировать                              |                               | Переключиться на инструмент редактирования, чтобы выбирать элементы внутри фрейма. |
| Chat                                       |                               | Обсудить фрейм с Agent.                                                           |
| Фокус                                      |                               | Войти в [режим фокуса](/ru/design/frames#focus-mode) для фрейма.                      |
| Чат у курсора                              | `/`                           | Начать быстрый чат в месте, где находится курсор.                                 |
| Изменить порядок                           |                               | Переместить фрейм вперёд или назад в порядке наложения.                           |
| Копировать, Вставить, Дублировать, Удалить | `⌘C`, `⌘V`, `⌘D`, `Backspace` | Стандартные операции с буфером обмена и управление фреймом.                         |
| Экспортировать как…                        |                               | Экспортировать фрейм в файл.                                                      |
| Выбрать всё                                | `⌘A`                          | Выбрать все фреймы на доске.                                                       |

<div id="export-a-frame-as-png">
  ### Экспорт фрейма в PNG
</div>

Сохраните любой артефакт или фрейм дизайна как изображение PNG. Это удобно, чтобы поделиться предварительным просмотром в документе или чате, сохранить снимок перед дальнейшими изменениями или отправить скриншот коллеге.

<Steps>
  <Step title="Выберите фрейм">
    Выберите артефакт или фрейм дизайна, который хотите экспортировать, затем дождитесь его полной загрузки.
  </Step>

  <Step title="Выберите Export">
    Выберите **Export** на панели действий фрейма. Также можно щёлкнуть фрейм правой кнопкой мыши и выбрать **Экспортировать как…** &gt; **PNG**. Изображение скачается на ваш компьютер, а его имя будет основано на названии фрейма.
  </Step>
</Steps>

Чтобы скопировать выбранный фрейм в формате PNG, а не скачивать его, нажмите `Cmd+Shift+C` (или `Ctrl+Shift+C` в Windows и Linux).

<Note>Экспортированный PNG будет соответствовать тому, что фрейм сейчас отображает на Canvas. Если ваше приложение или дизайн ещё загружается, дождитесь полной отрисовки перед экспортом.</Note>

<div id="the-canvas-and-the-live-app">
  ## Canvas и работающее приложение
</div>

Canvas и предпросмотр работающего приложения отображаются в одной панели, а переключаться между ними помогают несколько режимов:

* **Режим фокуса**: действие **Фокус** для выбранного фрейма разворачивает его на весь экран. Чтобы вернуться к Canvas, выберите **Exit focus** в верхней части доски.
* **Режим только для чтения**: когда Canvas заблокирован в контексте фоновой задачи, действия для внесения изменений скрываются, и остаётся только Фокус.

<Note>
  Для создания нового приложения из фрейма дизайна требуется Core или Pro; все остальные возможности Canvas доступны на любом тарифе. Подробнее о тарифах см. в разделе [Биллинг](/ru/billing/ai-billing).
</Note>
