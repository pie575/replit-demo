피드백 위젯은 게시된 앱의 모서리에 피드백 버튼을 추가합니다. 방문자는 앱을 벗어나지 않고도 이 버튼으로 문제를 알리거나 개선 사항을 제안할 수 있으며, 제출된 내용을 바로 Agent에 보내 수정할 수 있습니다.

<div id="turn-on-the-feedback-widget">
  ## feedback 위젯 켜기
</div>

1. **Tools** pane에서 **Replit Cloud** 아래의 **Publishing**을 선택해 Publishing 도구를 열거나, Project Editor 오른쪽 상단의 **Publish**를 선택합니다.
2. **Engagement tools**에서 **Enable feedback 위젯**을 켭니다.
3. **Publish**를 선택합니다. published app에 위젯이 표시됩니다.

<div id="position-and-appearance">
  ## 위치 및 외형
</div>

위젯을 활성화하면 두 가지 설정이 나타납니다:

* **Widget position**: 앱에서 위젯이 표시될 모서리를 선택합니다. 왼쪽 위, 오른쪽 위, 왼쪽 아래, 오른쪽 아래 중에서 고를 수 있으며 기본값은 오른쪽 아래입니다.
* **Appearance**: 위젯 버튼에 사용할 아이콘을 직접 업로드하고 배경 색상을 선택해 앱의 디자인에 어울리도록 맞출 수 있습니다.

<div id="review-and-act-on-feedback">
  ## feedback 검토 및 조치
</div>

방문자가 제출한 내용은 Inbox로 전달됩니다. 여기서 다음과 같은 작업을 할 수 있습니다.

* 각 제출 내용을 읽고 방문자가 겪은 문제를 파악합니다.
* 제출 내용을 Agent로 보내 수정을 요청합니다. Agent는 해당 feedback을 task로 받아 App에 적용할 changes를 제안합니다.

<div id="turn-it-off">
  ## 끄기
</div>

Publishing 도구에서 **Enable feedback widget**을 끄고 다시 게시하세요. 게시된 앱에서 위젯이 사라집니다.
