## Agent

### 지능형 모델 라우팅

지능형 모델 라우팅은 품질과 비용의 균형을 맞추면서 작업에 가장 적합한 모델과 Effort 레벨을 자동으로 선택합니다. **Power** 또는 **Max**에서 **Auto**를 선택하면 작업의 복잡도가 변할 때마다 Replit이 작업의 각 부분을 라우팅합니다. 더 세밀한 제어가 필요하다면 특정 모델과 Effort 레벨을 직접 선택할 수도 있습니다.

### Enterprise용 지능형 모델 라우팅

지능형 모델 라우팅이 이제 Enterprise 워크스페이스의 기본 Agent 모드가 되었습니다. **Auto mode**가 켜져 있으면 Replit이 각 작업에 가장 적합한 모드와 허용된 모델을 선택합니다. 계정 관리자는 워크스페이스별로 모델 사용 가능 여부를 제어할 수 있으며, **Auto mode**를 꺼서 활성화된 모델을 직접 선택할 수도 있습니다. Enterprise Agent 모드 메뉴는 이제 **Power**와 **Max**를 사용하며 더 이상 **Lite**를 포함하지 않습니다.
