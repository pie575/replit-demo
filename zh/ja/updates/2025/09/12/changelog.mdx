export const YouTubeEmbed = ({videoId, title = "YouTube 视频", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

<div id="agent-3">
  ## Agent 3 发布
</div>

本周，我们正式发布了 Agent 3。

<YouTubeEmbed videoId="4FxNXFOdt6w" title="Agent 3 发布直播" />

Agent 3 在自主性、可靠性和速度方面均有重大升级：

* **应用测试**：Agent 会在真实浏览器中自行测试应用、发现问题，并通过反思循环加以修复。请参阅[应用测试](/zh/core-concepts/agent/app-testing)。
* **更长的运行时间**：借助 Live Monitoring，Agent 最长可自主工作 200 分钟，非常适合大型构建。详情请参阅 [Agent](/zh/core-concepts/agent#max-autonomy)。
* **构建 Agent**：构建可按计划运行或与 Slack 和 Telegram 集成的 Agent 及自动化功能。请参阅 [Agents &amp; Automations](/zh/core-concepts/agent/agents-and-automations)。

  ## 应用连接器和集成
</div>

借助内置集成和连接器，更快发布应用：

* **Replit managed**：可在应用中自动运行的内置集成。
* **连接器**：只需登录一次，即可在所有应用中重复使用的第一方集成。
* **外部集成**：由 Agent 使用 API 密钥配置的可信第三方服务。
