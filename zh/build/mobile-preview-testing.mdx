想在自己的手机上查看 PixelGames，Expo Go 是最快的方式。先从这里入手，等遇到 Expo Go 做不到的场景，再转用 TestFlight 或内部测试。

<div id="what-is-expo">
  ## 什么是 Expo？
</div>

Expo 是 Agent 用来构建 PixelGames 的工具包。借助它，Agent 只需用 JavaScript 编写一次应用，
同一套代码就能作为真正的 iOS 应用和 Android 应用运行。

Expo Go 是一款可在 App Store 或 Google Play 免费下载的应用。只需安装一次，扫描二维码
即可预览任意 Expo project，包括 PixelGames。

<Steps>
  <Step title="打开 Expo Go">
    在手机 (iOS 或 Android) 上打开 **Expo Go** 应用。
  </Step>

  <Step title="扫描二维码">
    扫描 Replit 在预览窗格中显示的二维码。
  </Step>

  <Step title="等待加载">
    Expo 的打包工具 Metro 会打包 PixelGames 并发送到你的手机。首次
    加载可能需要一两分钟，之后会快很多。
  </Step>

  <Step title="上手体验">
    PixelGames 会在你的手机上打开。Agent 的改动几秒内就会呈现，无需
    重新安装。
  </Step>
</Steps>

<div id="what-expo-go-cannot-test">
  ## Expo Go 无法测试的内容
</div>

Expo Go 可以测试页面、流程和界面。有少数功能只有当 PixelGames 作为独立 App 在手机上运行时才生效：常见的有**推送通知**、**应用内购买**和**通过 Apple 登录**。

要测试这些功能，请将 PixelGames 上传到 Apple 或 Google，然后从对应的 Beta 测试渠道安装。你的 App 仅对你和你邀请的测试者可见，在正式发布之前你可以持续迭代。

<div id="troubleshooting">
  ## 故障排查
</div>

* **二维码无法扫描，或应用无法连接：** 确认手机和电脑连接的是同一个 WiFi 网络，部分企业网络和公共网络会阻断两者之间的连接。若处于此类网络中，可让 Agent 以隧道模式启动应用。
* **手机上看不到改动：** 摇晃手机打开 Expo 开发者菜单，然后点按 **Reload** 重新下载 PixelGames。
* **红色报错界面：** 通常是 JavaScript 错误或缺少软件包。报错信息一般会指出具体的文件和行号，把它分享给 Agent 并请求修复。
* **在 iOS 上正常，在 Android 上出错 (或反之) ：** 把错误信息连同出问题的平台一并粘贴给 Agent。
* **主机外壳在某台设备上显示异常：** 让 Agent 检查该设备的屏幕尺寸或安全区域处理。
