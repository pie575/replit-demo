Autoscale Deployments 运行在可自动扩容和缩容的云计算资源上，能够高效应对 Replit App 的网络流量和工作负载。应用繁忙时，自动扩缩容会增加服务器来分担负载；应用空闲时，服务器数量会缩减至零，从而节省成本。

Autoscale Deployments 适合以下使用场景：

* 流量和工作负载波动较大的 Web 应用，例如电商网站
* API 和各类服务

<div id="recursos">
  ## 功能
</div>

Autoscale Deployment 包含以下功能：

* **资源自动伸缩**：根据流量情况自动调整资源，优化成本。
* **自定义域名**：配置自定义域名，或使用 `<app-name>.replit.app` 形式的 URL 访问你的应用。
* **可配置的上限**：设置已发布应用最多可扩展到的实例数量。
* **灵活的机器规格**：选择符合应用需求的 CPU 和内存配置。
* **监控**：查看日志并监控已发布应用的状态。

<div id="uso">
  ## 使用方法
</div>

你可以在 Project Editor 的 Publishing 工具中使用 Autoscale Deployment。

<Accordion title="如何访问 Autoscale Deployment">
  在左侧的 **Tool dock** 中：

  1. 选择 <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="所有工具图标" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**，查看 Project Editor 的工具列表。
  2. 选择 <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Publishing 图标" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publishing**。
  3. 选择 **Autoscale** 选项，然后选择 **Set up your published app**。

  在**搜索栏**中：

  1. 选择顶部的 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 放大镜图标，打开搜索工具
  2. 输入“Publishing”查找该工具，并在结果中选择它。
  3. 选择 **Autoscale** 选项，然后选择 **Set up your published app**。
</Accordion>

<div id="capacidade-da-mquina">
  ## 机器性能
</div>

选择 **Edit**，查看并设置机器性能选项。使用滑块为已发布应用的每个服务器实例选择 CPU 和 RAM 配置。

在 **Total per machine** 一行中可查看该配置所需的 **计算单元** 成本。
计算单元是一种衡量云计算资源的单位，取决于机器的内存和 CPU 配置。

有关如何基于 Compute Units 计算成本的更多信息，请参阅 [Compute Units](/zh/pt/billing/about-usage-based-billing#2-compute-units)。

<div id="nmero-mximo-de-mquinas">
  ## 最大机器数量
</div>

使用滑块调整最大机器数量。该数值是自动扩缩容功能在判定应用处于繁忙状态时，可分配的服务器实例数量上限。

下方一行显示等效的计算单元数，计算公式如下：

`机器数量 * 每台机器的计算单元`
