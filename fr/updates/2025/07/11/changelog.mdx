## Plateforme

### Documentation replit.md

Personnalisez le comportement d'Agent avec `replit.md`, un fichier de configuration spécial qui aide Agent à comprendre les préférences, le style de codage et l'architecture de votre projet. Agent crée automatiquement ce fichier en utilisant les meilleures pratiques éprouvées, puis l'utilise pour créer des applications correspondant à vos spécifications exactes. Guidez Agent avec le contexte du projet, définissez les normes de codage, spécifiez votre pile technologique préférée et définissez vos préférences de communication — le tout en un seul endroit.

### Indicateurs de confidentialité des déploiements

Identifiez rapidement si vos déploiements sont publics ou privés grâce aux nouveaux indicateurs visuels dans le panneau de déploiements. Cette amélioration aide à éviter toute confusion et garantit que vous savez exactement qui peut accéder à vos applications déployées.
