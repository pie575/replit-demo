<div id="visual-editor">
  ### Visual Editor 中的布局控件
</div>

Visual Editor 现已提供专门的**布局**控件，无需再让 Agent 重写样式，即可直观地调整 flexbox 布局。选中容器，展开“布局”部分，即可选择 flex 方向、对齐方式和排布方式。你可以设置元素之间的像素间距，也可以打开 **Space between** 开关，将子元素推向两端边缘。

编辑器面板也重新划分为更清晰的**文本**、**图片**、**布局**、**颜色**、**边框**等部分，让你更轻松地找到所需控件。

  ## Agent
</div>

<div id="agent-2">
  ### 共享项目中的 Agent 设置仅对你自己生效
</div>

模型层级、Plan 模式、自动合并和自动批准计划等 Agent 偏好设置，现在仅保留给你自己，不再与项目中的所有人共享。团队成员在自己的工作中切换到 Power Mode，不会再改变你的设置。发送下一条消息时，Agent 会使用你所选择的设置，即使在协作者众多的项目中也是如此。

进一步了解 [Agent 模式](/zh/ko/features/agent/agent-modes#settings-in-shared-projects)。

<div id="agent-power-mode">
  ### Agent 卡住时会建议使用 Power Mode
</div>

当 Agent 检测到自己在 Economy Mode 下反复遇到同一个问题时，现在会在下一条消息中建议切换到 Power。该建议会通过识别重复的请求或持续失败的代码来触发，且每个项目最多出现一次。如果处于规划会话中、你已提出预算方面的顾虑，或你使用的是免费方案，Agent 则会跳过该建议。

<div id="section-3">
  ### 更清爽的任务设置下拉菜单
</div>

从任务标题栏打开的下拉菜单更好用了。当前任务或计划的标题位于顶部，可直接就地重命名；自动化设置 (自动应用、自动批准) 单独成组，位于标题与操作之间；弹出框采用固定宽度，任务名称变化时不会来回抖动。已停用的自动化选项会被隐藏，因此菜单中只显示适用于当前任务的选项。

<div id="quiver-ai-browserbase">
  ### 两款新连接器：Quiver AI 和 Browserbase
</div>

连接器目录中新增了两项服务。打开**集成**面板，选择**添加新集成**即可连接。

* **Quiver AI**：通过托管 API 生成 SVG 插图，并将位图矢量化。当 Agent 需要简洁的 SVG 素材时，这项服务很有用。
* **Browserbase**：运行托管的无头浏览器，可用于抓取、搜索和完整的会话自动化。当 Agent 需要加载真实网页、执行 JavaScript，或与拦截普通 HTTP 请求的网站交互时，这项服务很有用。
