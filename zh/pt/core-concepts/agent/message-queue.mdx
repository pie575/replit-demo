---
title: "消息队列"
description: "了解如何将后续消息加入 Agent 队列，使其在完成当前任务后按顺序处理。"
---

消息队列提供了一种在 Replit Agent 工作期间与其交互的新方式。
无需中断当前工作，您可以安排后续任务，Agent 会在每个工作周期完成后
按顺序执行这些任务。

</Frame>

<div id="como-funciona">
  ## 工作原理
</div>

当 Agent 正在处理请求时，你可以向队列添加消息来安排后续任务。这些任务或请求会在 Agent 每完成一个工作周期后按顺序处理。当 Agent 完成所有任务后，队列会自动清空。

队列支持所有消息选项，例如[可视化编辑器](/zh/pt/replitai/visual-editor)和文件附件。

<Info>
  只有在连接到 Agent 的项目编辑器会话保持活跃时 (无论是在桌面端还是移动设备上) ，队列中的消息才会自动处理。
</Info>

<div id="usando-a-fila-de-mensagens">
  ## 使用消息队列
</div>

<div id="quando-a-fila-aparece">
  ### 消息队列何时显示
</div>

当 Agent 正在工作时，如果您发送消息，消息队列会自动以抽屉面板显示在聊天输入框上方。
所有排队消息处理完毕后，消息队列会自动关闭。

<div id="gerenciando-mensagens-enfileiradas">
  ### 管理队列中的消息
</div>

打开队列抽屉面板后，您可以：

* **编辑消息**：点击编辑图标，在消息处理前修改队列中的消息
* **删除消息**：从队列中移除不需要的任务
* **重新排序项目**：通过拖放调整队列中消息的执行顺序
* **添加更多消息**：继续通过聊天输入框向队列添加新任务

<div id="interrupo-imediata">
  ### 立即中断
</div>

如果您需要中断 Agent 并立即发送消息，可使用状态栏中的**暂停**按钮。
这会中断 Agent 当前的工作周期，让您立即发送消息，
并忽略所有已排队的消息 (如有) 。

<div id="melhores-prticas">
  ## 最佳实践
</div>

<div id="quando-usar-a-fila-de-mensagens">
  ### 何时使用消息队列
</div>

* **多步骤工作流**：将一系列相互关联、层层递进的任务加入队列
* **批量操作**：将类似请求分组，以便高效处理
* **后续请求**：在初始任务之后补充说明或额外要求
* **非紧急任务**：当 Agent 处理关键任务时，将优先级较低的请求加入队列

<div id="quando-usar-a-interrupo-imediata">
  ### 何时使用立即中断
</div>

* **紧急变更**：需要立即停止当前工作时
* **严重错误**：发现需要立即处理的问题时
* **调整方向**：想要彻底改变 Agent 正在处理的任务时

<div id="comportamento-da-fila">
  ## 队列行为
</div>

* **按顺序执行**：消息会按照加入队列的顺序处理
* **完成当前工作周期后处理**：每条排队消息都会在 Agent 完成当前工作周期后处理
* **保留上下文**：Agent 会在同一对话的排队消息之间保留上下文
