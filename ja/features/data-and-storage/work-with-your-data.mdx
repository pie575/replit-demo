**My Data** タブは、データベース内のデータを確認・変更する場所です。**Database** ツールを開き、データベースを選択してから **My Data** を選択します。ビジュアルに操作することも、SQL を直接実行することもできます。

<Note>
  本番データを編集するには、本番データベースを選択して **My Data** を開き、**Edit** を切り替えます。これはライブアプリの実データなので注意してください。
</Note>

## データをビジュアルに参照・変更する

Database ツールには <a href="https://orm.drizzle.team/drizzle-studio/overview" target="_blank">Drizzle Studio</a> が含まれており、データをビジュアルに参照・変更できるツールです。これらのビジュアルツールは構文エラーを避けるのに役立ち、次のような機能を提供します。

* データをフィルタリング・並べ替えして特定の情報に絞り込む
* データをファイルにエクスポートして外部で利用する
* 行データを挿入・変更する
* スキーマ、テーブル、ビュー、enum を作成・管理する

## SQL コマンドを実行する

SQL runner を使うと、データベース上で SQL コマンドを実行し、結果を確認できます。

<Accordion title="SQL runner にアクセスする方法">
  **Database** ツールから、

  1. **My Data** タブを選択します
  2. <img class="icon-svg" src="/assets/mirror/sql-runner-icon-b25868882922.svg" alt="SQL runner アイコン" width="16" height="16" data-path="images/icons/sql-runner-icon.svg" /> **SQL runner** を選択します
</Accordion>

クエリを実行するには、テキストエリアに SQL 文を入力し、隣にある <img class="icon-svg" src="/assets/mirror/sql-play-8ed26b5de7f1.svg" alt="sql 実行アイコン" width="18" height="18" data-path="images/icons/sql-play.svg" /> 実行ボタンを選択します。

<Frame>
  <img src="/assets/mirror/sql-runner-run-8ad798a61335.jpg" alt="SQL runner と実行ボタンのスクリーンショット" width="1390" height="608" data-path="images/databases/sql-runner-run.jpg" />
</Frame>

<Tip>
  自分で SQL を書く必要はありません。Agent にデータの照会や変更を依頼すれば、代わりに SQL を書いて実行してくれます。
</Tip>
