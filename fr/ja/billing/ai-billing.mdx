Les fonctionnalités d’IA de Replit reposent sur une facturation à l’usage, basée sur ce que vous créez et sur votre utilisation des outils d’IA. Vous ne payez ainsi que pour la valeur apportée par Agent.

<div id="section">
  ## Pour commencer
</div>

**Tous les abonnés** bénéficient d’un point de contrôle Agent gratuit, valable une seule fois.

Des crédits mensuels supplémentaires sont automatiquement appliqués à l’utilisation de l’IA :

* **Abonnés Core** : crédits mensuels (consultez les [tarifs](https://replit.com/pricing))
* **Abonnés Pro** : crédits mensuels progressifs, reportables pendant {ProCreditRolloverPeriod}. Consultez [Replit Pro](/fr/ja/billing/plans/replit-pro).

Ces crédits couvrent Agent et d’autres services cloud Replit, tels que les applications publiées, le stockage et les bases de données. Choisissez [Lite, Economy ou Power](/fr/ja/features/agent/agent-modes) pour optimiser la vitesse, le coût ou les fonctionnalités.

  ## Facturation d’Agent
</div>

<Frame>
  <img src="/assets/mirror/checkpoint-f0cc3c49b9a5.png" alt="Interface de Replit Agent affichant la conversation et le système de points de contrôle" width="1999" height="1242" data-path="images/billing/checkpoint.png" />

Free Mode permet aux abonnés Core et Pro d’effectuer gratuitement leurs tâches quotidiennes avec Agent, dans la limite de leur quota. Les modes payants et les tâches payantes confirmées sont facturés selon l’effort requis, en fonction de la complexité de la demande. Replit demande une confirmation avant le lancement d’une action payante.

<div id="section-2">
  ### Fonctionnement de la tarification basée sur l’effort
</div>

Lorsque vous échangez avec Agent en « mode Build », un **point de contrôle** est créé pour enregistrer le travail effectué pour votre demande :

* Les **demandes simples** (comme les corrections de bugs ou les petites modifications) coûtent généralement moins cher que les builds complexes
* Les **builds complexes** (comme des fonctionnalités complètes ou des intégrations) peuvent être regroupés dans un seul point de contrôle, dont le coût peut être supérieur à celui des demandes simples afin de refléter l’effort total requis
* **Un point de contrôle par demande** élimine les points de contrôle intermédiaires et réduit le bruit dans la facturation
* Une **tarification transparente** vous permet de savoir exactement ce que vous payez pour chaque tâche terminée

<Info>
  Les points de contrôle sont créés lorsque Agent termine le travail sur votre demande et implémente les fonctionnalités demandées dans le code.
</Info>

Dans les offres payantes, le mode Plan peut effectuer des raisonnements facturables même s’il ne modifie pas le code.

Pour en savoir plus sur ce que les points de contrôle enregistrent et sur leur fonctionnement, consultez [points de contrôle et restaurations](/fr/ja/features/version-control/checkpoints-and-rollbacks).

<div id="agent-3">
  ### Facturation des services Agent
</div>

Certaines fonctionnalités d’Agent utilisent en arrière-plan des API tierces payantes (Claude, ChatGPT, Nano Banana / Gemini, etc.). Agent gère automatiquement ces intégrations — aucune clé API ni configuration n’est requise. La facturation est effectuée aux tarifs API publics des fournisseurs et déduite de vos crédits Replit. Ces coûts s’affichent avec vos autres dépenses dans le [tableau de bord d’utilisation](/fr/ja/billing/managing-spend).

Pour mieux comprendre le coût d’une application exemple, consultez cette [démo interactive](https://agent-pricing.replit.app/).

<div id="section-3">
  ### Suivi de l’utilisation
</div>

Vous pouvez suivre les dépenses liées à Agent en temps réel :

1. **Onglet Agent** : survolez l’icône d’utilisation pour consulter le coût de chaque point de contrôle
2. **Tableau de bord d’utilisation** : consultez les informations détaillées de facturation pour la période en cours
3. **Paramètres** : configurez des alertes et des budgets dans **Compte** → **Facturation** afin de gérer vos dépenses

<Tip>
  Les données d’utilisation peuvent mettre jusqu’à 30 minutes à apparaître dans le tableau de bord d’utilisation.
</Tip>

<div id="section-4">
  ## Gérer vos dépenses
</div>

Maîtrisez vos dépenses liées à l’IA grâce aux outils de gestion du budget intégrés à Replit :

* **Alertes d’utilisation** : recevez une notification lorsque vos dépenses atteignent un seuil défini
* **Plafonds budgétaires** : définissez des limites strictes pour éviter les frais imprévus
* **Suivi en temps réel** : surveillez vos coûts au fur et à mesure de vos créations
* **Packs de crédits** : achetez des crédits supplémentaires à prix réduit en gros. Consultez la page [Gestion des dépenses](/fr/ja/billing/managing-spend) pour en savoir plus.

<div id="section-5">
  ## Prochaines étapes
</div>

Prêt à commencer à créer avec l’IA ? Pour tirer le meilleur parti de vos crédits :

* **Commencez par essayer Agent** : explorez ses fonctionnalités grâce aux points de contrôle gratuits
* **Commencez petit** : familiarisez-vous avec la tarification basée sur l’effort à l’aide de demandes simples
* **Utilisez le mode Lite** : utilisez le [mode Lite](/fr/ja/features/agent/agent-modes) pour des modifications rapides et ciblées
* **Configurez des alertes** : activez des notifications de dépenses avant d’épuiser vos crédits

Découvrez les [outils d’IA de Replit](/fr/welcome) ou consultez les [plans tarifaires](https://replit.com/pricing).
