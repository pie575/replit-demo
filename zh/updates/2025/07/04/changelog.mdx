<div id="web-search-for-agent">
  ### Agent 网页搜索
</div>

<Frame>
  <img src="/assets/mirror/web-search-6c28195531d4.jpg" alt="Agent 界面显示用于应用开发的网页搜索结果和来源引用" width="1920" height="1080" data-path="images/replitai/web-search.jpg" />
</Frame>

Agent 现在可以通过[网页搜索](/zh/core-concepts/agent/web-search)搜索网络并获取最新信息。利用最新文档、当前市场数据和来自互联网各处的准确信息构建应用。无需再受知识截止日期限制，你的应用现在可以使用最新可用信息。

<div id="custom-agent-instructions">
  ### 自定义 Agent 指令
</div>

<Frame>
  <img src="/assets/mirror/replitmd-65360844a148.jpg" alt="显示项目自定义选项的 replit.md 文件" width="1920" height="1080" data-path="images/replitai/replitmd.jpg" />
</Frame>

使用 [replit.md](/zh/core-concepts/agent/replit-dot-md) 打造个性化的 Agent 体验。这个特殊文件可让你定义编码风格、项目偏好和上下文。Agent 会根据经过验证的最佳实践自动创建此文件，你也可以将其自定义为符合自己工作流程的形式。

<div id="effort-based-billing">
  ### 按工作量计费
</div>

<Frame>
  <img src="/assets/mirror/effort-based-billing-d971548c7c39.png" alt="按 Agent 工作量动态定价的按工作量计费界面" width="2048" height="1424" data-path="images/changelog/2025-07-04/effort-based-billing.png" />
</Frame>

全新的[按工作量计费](/zh/billing/ai-billing)带来更智能的 checkpoint 定价。系统会根据 Agent 的实际工作量动态定价，每次运行只创建一个 checkpoint，而非多个。

<div id="teams-app-store-experience">
  ### Teams App Store 体验
</div>

以前所未有的方式发现和管理团队的 App。Deployments 页面新增了面向组织的“App Store”体验，让你可以收藏常用 App、搜索所有部署、查看最近打开的 App，并根据流量发现热门部署。
