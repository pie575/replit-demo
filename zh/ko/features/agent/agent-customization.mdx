title: "Agent 自定义"
description: "通过在工作区设置中集中管理的工作区级自定义指令和技能，让 Agent 了解团队的规则。"
---

Agent 自定义为 Agent 提供必要的上下文，让它从第一条提示词起就按照你和团队的工作方式来干活。无需在每个项目中重复说明规则，只需在工作区中定义一次，Agent 便会处处遵循。

它包含两个部分：

* **自定义指令**：适用于工作区中所有项目的常驻指导原则。
* **技能**：仅在出现相关任务时才由 Agent 加载的可复用指令。

两者均在 **工作区设置 → 自定义** 中管理。

<div id="section">
  ## 自定义指令与技能
</div>

自定义指令会随每条消息加载，而技能只有在 Agent 判断与当前任务相关时才会加载。始终适用的少数几条准则请写成自定义指令；特定的工作流、规范和参考资料则用技能来承载。

如需了解这样区分的原因——上下文预算、哪些内容该放在哪里、如何写好技能——请参阅 [Agent 技能](/zh/ko/learn/agent-skills)。如需了解技能的组织方式以及 Agent 加载技能的机制，请参阅 [Agent 技能](/zh/ko/features/agent/skills)。

<div id="section-2">
  ## 自定义指令
</div>

自定义指令是始终生效的准则，在任何人输入提示词之前，它就会被注入到所有项目、所有会话的 Agent 上下文中。只需在工作区设置中编写一次，Agent 便会在整个工作区应用它。它最适合用于始终成立的准则，例如安全与合规要求、经批准的库和框架、数据处理策略等。

请尽量简洁。指令越聚焦、越具体，被准确遵循的可能性就越高，同时也为 Agent 的实际操作留出更多空间。

<Warning>
  自定义指令可能会影响 Agent 的性能。Agent 会被引导去遵循这些指令，但无法保证严格满足要求。指令越简短、越具体，遵循得就越稳定。
</Warning>

<Note>
  工作区自定义指令与项目中的 `custom_instruction/instructions.md` 文件不同。工作区自定义指令只需在工作区设置中设置一次，即可适用于所有项目；而项目专属文件位于单个项目内部——关于该模式，请参阅[创建自定义设计系统](/zh/ko/teams/custom-design-system)。
</Note>

<div id="section-3">
  ## 技能
</div>

技能是一组可重复使用的指令，Agent 仅在处理相关任务时才会加载。工作区技能会显示在工作区中所有项目的 **+** 菜单顶部，因此整个团队可以共享同一组技能。

创建技能有三种方式：

* **上传**：上传现有的技能文件夹。
* **编写**：直接在表单中创建新技能。
* **请求 Agent**：让 Agent 起草技能，然后再进行完善。

<Note>
  您可以将 Agent 起草的技能上传到工作区。请让 Agent 下载该技能。Agent 会将技能打包为可下载的 `.zip` 归档文件，并提供 **下载文件** 按钮 (见下文) 。下载 zip 后，在 **工作区设置 → 自定义 → 技能** 中选择 **创建技能 → 选择文件或文件夹**，重新上传即可在整个工作区中共享。
</Note>

<Frame>
  <img src="/assets/mirror/agent-customization-download-skill-3727b188c5a8.png" alt="Agent 将工作区技能打包为可下载的 ux-designer-skill.zip 归档文件，并显示下载文件按钮" width="1716" height="864" data-path="images/replitai/agent-customization-download-skill.png" />
</Frame>

有关完整的技能结构 (`SKILL.md`、支持文件和开放标准) ，请参阅 [Agent 技能](/zh/ko/features/agent/skills)。如需浏览 Replit 及其合作伙伴已创建的技能，请参阅 [技能目录](/zh/ko/features/agent/skills-directory)。

<Note>
  请合理使用技能。Agent 在处理每项任务时都会读取所有技能的名称和描述，因此技能过多 (或重复) 可能会分散 Agent 的注意力，使其难以选择正确的技能。请将每项技能的范围保持明确，并移除不再需要的技能。
</Note>

<div id="section-4">
  ## 可用性与权限
</div>

| 功能    | 可用套餐             | 可管理者                              |
| ----- | ---------------- | --------------------------------- |
| 自定义指令 | Pro 和 Enterprise | Enterprise：管理员。Pro：所有工作区成员        |
| 技能    | 所有付费套餐           | Enterprise：管理员。Core 和 Pro：所有工作区成员 |

在 Enterprise 工作区中，只有管理员可以创建、编辑和删除自定义指令与技能；在 Pro 工作区中，所有工作区成员都可以执行这些操作。在 Core 工作区中，所有成员都可以管理技能——自定义指令在 Core 中不可用。无论哪种情况，工作区的所有成员都可以使用已创建的技能。

<div id="section-5">
  ## 创建自定义指令
</div>

<Steps>
  <Step title="打开工作区设置">
    前往 **工作区设置 → 自定义**。

    <Frame>
      <img src="/assets/mirror/agent-customization-tab-930af2e8ed74.png" alt="工作区设置中的“自定义”标签页，显示技能和自定义指令子标签页" width="1065" height="394" data-path="images/replitai/agent-customization-tab.png" />
    </Frame>
  </Step>

  <Step title="编写指令">
    在 **自定义指令** 部分中，编写希望 Agent 在所有项目中遵循的准则。
  </Step>

  <Step title="保存">
    保存更改。这些指令将对工作区中新建的项目生效。
  </Step>
</Steps>

<div id="section-6">
  ## 创建技能
</div>

<Steps>
  <Step title="打开工作区设置">
    前往 **工作区设置 → 自定义**。
  </Step>

  <Step title="创建技能">
    在 **技能** 部分点击 **创建技能**，然后上传技能文件夹、编写指令，或让 Agent 帮你起草。

    <Frame>
      <img src="/assets/mirror/agent-customization-create-skill-fcb794e6de4e.png" alt="工作区设置中的自定义标签页，显示技能与自定义指令子标签页以及已打开的创建技能表单" width="2168" height="1350" data-path="images/replitai/agent-customization-create-skill.png" />
    </Frame>
  </Step>

  <Step title="撰写清晰的说明">
    为技能撰写准确的说明，明确指出何时该用、何时不该用。Agent 会根据该说明判断技能是否适用。
  </Step>

  <Step title="保存">
    保存技能。此后即可在工作区所有项目的 **+** 菜单中使用它。
  </Step>
</Steps>

<div id="section-7">
  ## 在项目中使用工作区技能
</div>

准确的技能说明非常重要。Agent 会读取所有工作区技能的说明，当提示词与某个技能的用途大致匹配时会自动调用它，因此你不必每次都手动选择技能。如果想确保某个技能一定生效，也可以手动指定。

手动选择的方法：

<Steps>
  <Step title="打开技能选择器">
    在项目中点击聊天输入框旁边的 **+** 按钮。工作区技能会以分组形式显示在最上方。

    <Frame>
      <img src="/assets/mirror/agent-customization-skill-picker-4643f3a453c7.png" alt="从 + 按钮打开的技能选择器，工作区技能分组显示在最顶部、Replit 技能上方" width="1668" height="1170" data-path="images/replitai/agent-customization-skill-picker.png" />
    </Frame>
  </Step>

  <Step title="选择技能">
    选择你想启用的技能。你也可以输入 `/` 加技能名称来直接调用。
  </Step>

  <Step title="继续编写提示词">
    照常继续操作。如果任务与说明匹配，Agent 就会使用该技能。
  </Step>
</Steps>

<div id="section-8">
  ## 指令与技能管理
</div>

所有管理操作均在**工作区设置 → 自定义**中完成。你可以在此编辑自定义指令，并对所有技能进行编辑、停用或删除。更改仅对后续聊天生效，不会影响正在进行中的聊天。
