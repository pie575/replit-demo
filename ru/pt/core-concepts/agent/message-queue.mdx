Очередь сообщений — это новый способ взаимодействия с Replit Agent, пока он работает.
Вместо того чтобы прерывать текущую работу, вы можете запланировать последующие задачи: они будут выполняться
по порядку после завершения каждого рабочего цикла Agent.

<div id="como-funciona">
  ## Как это работает
</div>

Пока Agent активно обрабатывает запрос, вы можете запланировать следующую задачу, добавив
сообщения в очередь. Эти задачи и запросы будут выполняться по порядку — по завершении каждого
рабочего цикла Agent. Когда Agent выполнит все задачи, очередь автоматически очистится.

В очереди доступны все возможности работы с сообщениями, в том числе [Визуальный редактор](/ru/pt/replitai/visual-editor)
и вложения файлов.

<Info>
  Сообщения из очереди обрабатываются автоматически только при наличии активной
  сессии редактора проекта, подключённой к Agent (на компьютере или мобильном устройстве).
</Info>

<div id="usando-a-fila-de-mensagens">
  ## Использование очереди сообщений
</div>

<div id="quando-a-fila-aparece">
  ### Когда появляется очередь
</div>

Очередь сообщений автоматически появляется в виде выдвижной панели над полем ввода чата, когда вы отправляете сообщение,
пока Agent работает. Она закрывается, как только все сообщения в очереди будут обработаны.

<div id="gerenciando-mensagens-enfileiradas">
  ### Управление сообщениями в очереди
</div>

Когда панель очереди открыта, вы можете:

* **Редактировать сообщения**: нажмите значок редактирования, чтобы изменить сообщение в очереди до того, как оно будет обработано
* **Удалять сообщения**: убирайте из очереди ненужные задачи
* **Менять порядок элементов**: перетаскивайте сообщения, чтобы изменить порядок их выполнения
* **Добавлять новые сообщения**: продолжайте добавлять задачи в очередь через поле ввода чата

<div id="interrupo-imediata">
  ### Немедленное прерывание
</div>

Если нужно прервать работу Agent и сразу отправить сообщение, воспользуйтесь кнопкой **Пауза**
в строке состояния. Это остановит текущий рабочий цикл Agent и позволит немедленно отправить сообщение,
минуя очередь сообщений (если она не пуста).

<div id="melhores-prticas">
  ## Рекомендации и лучшие практики
</div>

<div id="quando-usar-a-fila-de-mensagens">
  ### Когда использовать очередь сообщений
</div>

* **Многоэтапные рабочие процессы**: поставьте в очередь серию связанных задач, каждая из которых опирается на предыдущую
* **Пакетные операции**: сгруппируйте однотипные запросы для более эффективной обработки
* **Уточняющие запросы**: добавьте пояснения или дополнительные требования после исходной задачи
* **Несрочные задачи**: ставьте в очередь запросы с низким приоритетом, пока Agent работает над критически важными задачами

<div id="quando-usar-a-interrupo-imediata">
  ### Когда использовать немедленное прерывание
</div>

* **Срочные изменения**: когда нужно немедленно прервать текущую работу
* **Критические ошибки**: если вы заметили проблему, требующую немедленного вмешательства
* **Смена направления**: когда вы хотите полностью изменить задачу, над которой работает Agent

<div id="comportamento-da-fila">
  ## Поведение очереди
</div>

* **Последовательное выполнение**: Сообщения обрабатываются в порядке добавления в очередь
* **Завершение рабочего цикла**: Каждое сообщение в очереди обрабатывается после того, как Agent завершит текущий рабочий цикл
* **Сохранение контекста**: Agent сохраняет контекст между сообщениями в очереди в рамках одного диалога
