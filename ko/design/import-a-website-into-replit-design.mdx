⏰ *예상 소요 시간: 10분*

시작점으로 삼고 싶은 디자인이 이미 웹에 공개되어 있을 때가 있습니다. 현재 운영 중인 사이트일 수도 있고, 외형을 그대로 다시 만들어 보고 싶은 페이지일 수도 있습니다. Import from URL을 사용하면 웹사이트를 design frame으로 재현해, 이를 살펴보고 다듬어 상호작용이 가능한 앱으로 Build할 수 있습니다.

예제로는 Replit으로 만든 크리에이티브 스튜디오 landing page인 [creative-studio-landing.replit.app](https://creative-studio-landing.replit.app)을 사용합니다.

<div id="before-you-start">
  ## 시작하기 전에
</div>

다음이 필요합니다:

* [Replit 계정](https://replit.com)
* 공개 웹사이트의 URL 또는 위의 예시

<div id="import-the-website">
  ## website 가져오기
</div>

<Steps>
  <Step title="사이트의 URL 복사">
    직접 만든 사이트를 사용하거나, 다음 예시를 복사하세요: `https://creative-studio-landing.replit.app`.

    <Frame caption="예시 사이트: 크리에이티브 스튜디오 landing page인 Kosmo Studio.">
      <img src="/assets/mirror/url-example-site-e0ad60629981.webp" alt="아트워크 카드가 부채꼴로 펼쳐진 이미지 위에 We craft bold ideas and visuals that truly work라는 헤드라인이 있는 Kosmo Studio landing page" width="3440" height="2160" data-path="images/design/import-from-url/url-example-site.webp" />
    </Frame>
  </Step>

  <Step title="Replit Design 열기">
    [replit.com/design](https://replit.com/design)으로 이동한 뒤 prompt box 아래의 **Import URL**을 선택하세요. Agent가 해당 사이트의 분위기와 스타일을 시작점으로 재현합니다.

    <Frame caption="Replit Design 홈의 Import URL: 원하는 website 링크를 붙여넣으세요.">
      <img src="/assets/mirror/design-import-url-07a8ac52e188.webp" alt="Import URL 옵션이 선택되어 있고 Paste a link to any website and Agent will recreate its look and feel as a starting point라는 툴팁이 표시된 Replit Design 홈" width="2293" height="1322" data-path="images/design/import-from-url/design-import-url.webp" />
    </Frame>
  </Step>

  <Step title="URL 붙여넣고 빌드 시작">
    **Import URL**을 선택하면 *&quot;Recreate the look and feel of this website:&quot;*라는 prompt가 미리 채워집니다. 그 뒤에 URL을 붙여넣고 **Start**를 선택하세요.

    <Frame caption="예시 URL이 입력되어 시작할 준비가 된, 미리 채워진 재현 prompt.">
      <img src="/assets/mirror/design-url-prompt-b6196aac1b17.webp" alt="Recreate the look and feel of this website 뒤에 예시 URL이 입력된 Replit Design prompt box와 Start 버튼" width="2293" height="1322" data-path="images/design/import-from-url/design-url-prompt.webp" />
    </Frame>
  </Step>
</Steps>

Agent가 해당 사이트를 project 내 design frame으로 재현합니다.

<Frame caption="Replit Design에서 design frame으로 재현된 Kosmo Studio landing page.">
  <img src="/assets/mirror/url-import-result-7a4114a468f3.webp" alt="Replit Design에서 design frame으로 재현된 Kosmo Studio landing page와 채팅 패널에 완료로 표시된 run" width="1600" height="1004" data-path="images/design/import-from-url/url-import-result.webp" />
</Frame>

<div id="make-it-yours">
  ## 나만의 것으로 만들기
</div>

가져온 frame을 선택하고 원하는 대로 바꿔보세요:

* **[suggestion](/ko/design/explore-suggestions) 따라가기**: 가져온 결과에는 다크 에디토리얼 변형, 모바일 뷰포트, 문의 페이지 같은 다음 단계 제안이 함께 제공됩니다. 각 제안은 새 frame으로 생성되므로 원본은 그대로 남아 비교해 볼 수 있습니다.
* **[Chat으로 대화하기](/ko/design/chat-about-your-design)**: frame 아래의 입력창에 *&quot;포트폴리오 사진을 바꿔줘&quot;*, *&quot;hero의 type을 더 두껍게 해줘&quot;*처럼 원하는 내용을 직접 설명해 보세요.
