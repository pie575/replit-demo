<div id="xai-integration">
  ### Интеграция с xAI
</div>

Теперь Agent может напрямую добавлять xAI в ваши приложения.

<Frame>
  <img src="/assets/mirror/xai-announce-232aa8bf6428.jpeg" alt="Анонс интеграции xAI" width="3840" height="2160" data-path="images/changelog/2025-01-03/xai-announce.jpeg" />
</Frame>

Добавляйте Grok в свои проекты и публикуйте их за считаные секунды. Просто упомяните в промпте «добавь ИИ-функции с xAI» или выберите xAI в интеграциях — Agent использует API для создания приложения.

<Frame>
  <img src="/assets/mirror/xai-in-product-a0102e19b327.jpeg" alt="xAI в продукте" width="1120" height="1120" data-path="images/changelog/2025-01-03/xai-in-product.jpeg" />
</Frame>

Скоро в Agent появится ещё больше ваших любимых интеграций.

<div id="custom-domain-error-handling">
  ### Обработка ошибок пользовательских доменов
</div>

Теперь при сбое проверки пользовательского домена выводятся конкретные сообщения об ошибках — так вы быстрее найдете причину проблемы.

<div id="menu-search-feature">
  ### Поиск в меню
</div>

Теперь в своих Replit App вы можете искать пункты меню на боковой панели.

<div id="neon-database-improvements">
  ### Улучшения базы данных Neon
</div>

Интеграция с базой данных Neon оптимизирована. Базы данных, добавленные с помощью Agent, стали дешевле и производительнее.

<div id="react-by-default">
  ### React по умолчанию
</div>

Шаблон по умолчанию для новых фронтенд-приложений Replit App теперь использует React. Ваши проекты сразу становятся более отточенными и функциональными.

<div id="replit-teams-login">
  ### Вход в Replit Teams
</div>

Процесс входа в Teams обновлён, чтобы упростить начало работы. Обновление включает новый интерфейс входа со страницей выбора командного контекста и удобное переключение между аккаунтами для клиентов Teams.
