Интеграция Replit в ChatGPT позволяет создавать, обновлять и просматривать Replit App прямо в переписке — без какой-либо настройки. Создавайте настоящие приложения, просто общаясь с ChatGPT, а обо всём остальном позаботится Agent.

<div id="o-que-o-replit-no-chatgpt">
  ## Что такое Replit в ChatGPT
</div>

Replit в ChatGPT связывает ваши диалоги в ChatGPT с мощной платформой разработки Replit. Вы описываете, что хотите создать, и Agent собирает для вас полностью работающее Replit App. После этого вы можете попросить ChatGPT изменить, обновить или проанализировать ваше приложение — и всё это в обычном диалоге.

<div id="como-comear">
  ## С чего начать
</div>

Выполните эти шаги, чтобы подключить Replit к ChatGPT и создать свой первый app.

<div id="conectar-o-replit-ao-chatgpt">
  ### Подключение Replit к ChatGPT
</div>

Подключить Replit к ChatGPT можно двумя способами:

<Accordion title="Подключение через Настройки">
  1. Нажмите на значок своего профиля в ChatGPT
  2. Перейдите в **Настройки** → **Приложения и коннекторы**
  3. Найдите **Replit** и нажмите **Подключить**
  4. Завершите авторизацию OAuth, используя свою учётную запись Replit
</Accordion>

<Accordion title="Подключение из чата">
  1. Начните новый чат в ChatGPT
  2. Вызовите Replit одним из описанных ниже способов
  3. Если вы ещё не подключены, ChatGPT проведёт вас через процесс авторизации OAuth
</Accordion>

<div id="invocar-o-replit-no-chatgpt">
  ### Вызов Replit в ChatGPT
</div>

После подключения вызвать Replit можно тремя способами:

| Способ            | Как использовать                              |
| ----------------- | --------------------------------------------- |
| Прямое упоминание | Введите `Replit, <запрос>` в начале сообщения |
| Слеш-команда      | Введите `/Replit` в поле ввода                |
| Меню поля ввода   | Нажмите кнопку **+** → **Ещё** → **Replit**   |

<div id="criar-seu-primeiro-app">
  ### Создайте свой первый App
</div>

После подключения создайте свой первый Replit App:

1. Начните новый чат в ChatGPT
2. Вызовите Replit и опишите, что хотите создать (например, «Replit, создай приложение со списком дел в тёмном режиме»)
3. Agent сгенерирует ваш App и автоматически развернёт его
4. По завершении вы получите ссылку для просмотра App

<Note>
  В каждом чате можно работать только с одним Replit App. Если вы создадите новый App в том же чате, он изменит существующий App. Чтобы создать несколько App, начните отдельные чаты.
</Note>

<div id="recursos">
  ## Возможности
</div>

* **[Replit AI](/ru/pt/build/welcome)**: Agent создаёт и развёртывает приложения по вашим запросам на естественном языке
* **[Project Editor](/ru/pt/core-concepts/project-editor)**: Полнофункциональная среда разработки, доступная через ChatGPT
* **[Публикация](/ru/category/replit-deployments)**: Приложения автоматически развёртываются и готовы к публикации

<Accordion title="Что вы можете делать">
  **Создавать:** Создавайте новые Replit App, описывая, что вам нужно. Agent создаёт приложение и автоматически развёртывает его.

  **Обновлять:** Изменяйте приложение в текущем чате. Попросите ChatGPT добавить функции, исправить ошибки или внести изменения — Agent применит их.

  **Проверять:** Анализируйте приложение, не внося изменений. Получайте сведения о структуре кода, путях к файлам или работе приложения.
</Accordion>

<Accordion title="Поддерживаемые форматы файлов">
  В запросы можно включать файлы разных типов:

  | Формат                              | Поддерживается                      |
  | ----------------------------------- | ----------------------------------- |
  | PDF                                 | Да                                  |
  | CSV                                 | Да                                  |
  | Распространённые форматы документов | Да                                  |
  | Изображения (исходные файлы)        | Нет (используйте общедоступные URL) |
  | Видео (исходные файлы)              | Нет (используйте общедоступные URL) |

  <Note>
    Чтобы добавить изображения или видео в приложение, укажите в запросе общедоступные URL. Вы также можете добавить медиафайлы непосредственно в Replit после создания приложения.
  </Note>
</Accordion>

<Accordion title="Время создания">
  Обычно Agent создаёт приложения за:

  | Сложность приложения                                  | Типичное время создания |
  | ----------------------------------------------------- | ----------------------- |
  | Простое (калькуляторы, небольшие лендинги)            | 2–3 минуты              |
  | Сложное (игры, насыщенная анимация, сложные дашборды) | 3–4 минуты              |

<div id="cobrana-e-crditos">
  ## Оплата и кредиты
</div>

Работа, которую Replit выполняет в ChatGPT, тарифицируется как использование Replit Agent в вашем аккаунте Replit.

<Accordion title="Как работает оплата">
  * Тарифы **Core** и **Pro** включают ежемесячные кредиты, которые покрывают Agent, публикацию и базы данных в пределах вашего лимита
  * Вы можете приобрести **пакеты кредитов**: они действуют шесть месяцев и не продлеваются автоматически — удобно для пиковых нагрузок при запуске или для экспериментов
  * Чтобы контролировать расходы, используйте **лимиты использования** и **бюджеты** в настройках оплаты Replit

  Подробнее — в [документации по оплате ИИ](/ru/pt/billing/ai-billing).
</Accordion>

<div id="limitaes-atuais">
  ## Текущие ограничения
</div>

Сейчас приложение Replit в ChatGPT:

* Может работать только с приложением, созданным в этом конкретном диалоге
* Не может открывать или изменять:
  * Приложения, созданные в других чатах ChatGPT
  * Приложения, которые вы создали напрямую в Replit

Полное соответствие возможностям Replit (базы данных, управление Secrets, более продвинутые настройки Project Editor) пока в разработке.

<div id="soluo-de-problemas">
  ## Устранение неполадок
</div>

<Accordion title="Replit не отображается в разделе «Обзор приложений»">
  Если Replit не отображается в разделе **Обзор приложений**, проверьте:

  * доступны ли приложения в вашем регионе;
  * включил ли администратор workspace приложение Replit (Business/Enterprise/Edu).
</Accordion>

<Accordion title="Сбои при создании">
  Если создание завершается сбоем, откройте App в Replit:

  * проверьте использование и оплату;
  * используйте checkpoint и откаты;
  * обратитесь за помощью к Agent прямо в Project Editor.
</Accordion>
