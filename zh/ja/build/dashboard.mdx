控制台可帮助您基于数据做出决策。

使用公开 CSV 构建 **Global Progress Explorer**：其中包含年份、人口、大洲、预期寿命和人均 GDP 等国家级数据。

<div id="section">
  ## 您将完成的内容
</div>

完成本指南后，您将拥有：

* 一个基于真实公开 CSV 构建的 Global Progress Explorer 控制台。
* 国家数量、人口、预期寿命和人均 GDP 等汇总指标。
* 展示进展随时间变化的图表和筛选器。
* 将控制台中的数值与源数据进行核对的方法。
* 可与利益相关者共享或发布的控制台。

<div id="section-2">
  ## 你将学到什么
</div>

你将学习如何：

* 从决策出发，而不是从图表类型出发。
* 让 Agent 基于公开 CSV 构建控制台。
* 根据原始数据验证计算结果。
* 添加筛选器和洞察摘要。
* 判断控制台是否需要登录、更新、导出和连接数据。

<div id="section-3">
  ## 适用对象
</div>

如果你拥有客户、销售、产品、运营、研究或公开数据，并且需要易于理解的控制台，请使用本指南。

本指南适合需要将原始数据转化为决策依据的分析师、运营人员、创始人、PM、教育工作者和团队。

<div id="section-4">
  ## 明确决策目标
</div>

在开始构建之前，先明确控制台需要支持哪些决策。

对于全球发展数据集：

* **问题**：哪些地区的人均 GDP 和平均寿命随时间推移有所改善？
* **受众**：教育、研究、战略或非营利团队。
* **有用的指标**：国家数量、年份范围、最新的平均寿命中位数、所覆盖的总人口、人均 GDP 中位数。
* **有用的筛选条件**：大洲、国家、年份范围。

如果无法明确要支持的决策，控制台就会沦为图表的集合，而非实用工具。

<div id="csv">
  ## 从公开 CSV 构建
</div>

请使用字段有意义且行数充足的高质量公开数据集。

数据集：[Gapminder 全球发展 CSV](https://raw.githubusercontent.com/plotly/datasets/master/gapminderDataFiveYear.csv)

请让 Agent 根据该 CSV 构建控制台：

<AiPrompt>
  根据这个公开 CSV 构建一个全球发展探索控制台：<br />
  [https://raw.githubusercontent.com/plotly/datasets/master/gapminderDataFiveYear.csv](https://raw.githubusercontent.com/plotly/datasets/master/gapminderDataFiveYear.csv)<br />

  包含以下摘要卡片：国家总数、年份范围、最新预期寿命中位数、涵盖的总人口以及最新人均 GDP 中位数。<br />
  添加按大洲展示预期寿命随时间变化的折线图。<br />
  添加气泡图，其中 x 轴为人均 GDP，y 轴为预期寿命，气泡大小表示人口，颜色表示大洲。<br />
  添加柱状图，展示数据集中从最早年份到最新年份预期寿命增长最多的国家。<br />
  添加大洲、国家和年份范围筛选器。<br />

  让控制台美观完善、响应迅速，并且在桌面端和移动端都易于阅读。

<div id="section-5">
  ## 检查你的工作
</div>

打开 Preview，在分享前检查控制台。

请确认以下内容：

* 国家总数与 CSV 中的唯一国家数一致。
* 年份范围为 1952 年至 2007 年。
* 最新的预期寿命中位数基于数据集中的最新年份。
* 总人口基于筛选后的国家和年份。
* 筛选条件会更新摘要卡片和图表。
* 气泡图正确使用人均 GDP、预期寿命、人口和大洲数据。
* 洞察摘要与图表内容一致。
* 控制台可在智能手机尺寸的屏幕上正常运行。

如果数值与预期不符，请让 Agent 显示计算过程。

<AiPrompt>
  最新的预期寿命中位数与我的预期不符。<br />
  请向我展示你是如何根据 CSV 计算出该数值的。<br />
  检查你是否只使用了筛选后数据中最新年份的行。<br />
  如有需要，请更新计算，并告诉我如何验证。
</AiPrompt>

<div id="section-6">
  ## 添加筛选和导出功能
</div>

初始控制台运行后，请 Agent 添加交互功能，帮助用户探索数据。

<AiPrompt>
  为全球进展控制台添加探索面板。<br />
  让我可以按大洲、国家和年份范围进行筛选。<br />
  添加一个按钮，将筛选后的图表数据导出为 CSV。<br />
  让摘要卡片和洞察摘要与筛选条件保持同步。
</AiPrompt>

控制台还支持 PDF 导出、图表 CSV 导出、刷新、自动刷新、浅色/深色模式和分析摘要。有关概念概览，请参阅 [Data Visualization](/zh/ja/features/artifact-types/data-apps)。

<div id="section-7">
  ## 按需使用连接的数据
</div>

学习或制作原型时，请使用公开 CSV。若需让控制台保持最新，请使用已连接的数据源。

你可以将控制台连接到：

* Replit 应用的数据库。
* BigQuery、Databricks 和 Snowflake 等数据仓库连接器。
* Segment、Amplitude 和 Hex 等分析工具。
* 外部 API。

对于数据仓库中的数据，请让 Agent 说明所使用的字段和查询。

<AiPrompt>
  使用我们的数据仓库连接器创建一个增长控制台。<br />
  确定所需的客户、产品使用情况、计费和留存字段。<br />
  为活跃客户数随时间变化、按细分市场划分的账户增长，以及按套餐划分的扩张收入创建图表。<br />
  说明所使用的字段和计算方法，以便我验证控制台。
</AiPrompt>

有关设置和可用性的详细信息，请参阅 [Data Connectors](/zh/ja/connectors/warehouses/overview)。

<div id="section-8">
  ## 分享控制台
</div>

确认数据可靠后，即可分享控制台。

如果控制台使用私密的客户或业务数据，请先添加访问控制，再广泛分享。对于公开数据或示例数据，您可以直接公开并分享 URL。

请审核者：

> 查看全球进展控制台，并告诉我应优先重点呈现哪些地区或国家，以及原因。

<div id="section-9">
  ## 完成检查
</div>

* 控制台正在读取公开 CSV。
* 摘要卡片和图表能够回答与进度相关的问题。
* 已手动核实至少一项关键指标。
* 筛选器能够正确更新控制台。
* 洞察摘要与数据一致。
* 已决定是将控制台保持公开、要求登录，还是连接实时数据。

<div id="section-11">
  ## 还需要更多帮助吗？
</div>

* **数值与预期不符：** 请让 Agent 显示查询、计算公式或转换过程。
* **CSV 不可用：** 请检查 URL、网络访问和 CSV 标头。
* **筛选器未更新图表：** 请让 Agent 将筛选器同时关联到摘要卡片和图表数据。
* **控制台运行缓慢：** 请让 Agent 汇总数据、添加筛选器，并减少启动时加载的行数。
* **控制台使用私有数据：** 在广泛分享前，请添加登录功能。
