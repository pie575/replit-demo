以下内容涵盖账户访问与安全。有关删除账户的详细信息，请参阅[删除您的数据](/zh/pt/legal-and-security-info/deleting-your-data)；有关停用，请参阅[违规系统常见问题](/zh/pt/legal-and-security-info/strike-system-faq)。

<AccordionGroup>
  <Accordion title="如何重置密码？">
    1. 访问 [replit.com/forgot](https://replit.com/forgot)。
    2. 输入与你的账户关联的电子邮件地址。
    3. 打开来自 `notifications@replit.com` 的密码重置邮件——如果找不到，请检查垃圾邮件文件夹。
    4. 点击链接并设置新密码。

    如果你通过 Google、GitHub、Facebook 或 Apple 注册，请在同一页面设置独立密码。如果未收到邮件，请确认输入的是注册时使用的准确电子邮件地址。
  </Accordion>

  <Accordion title="无法登录——如何恢复账户访问权限？">
    请按以下顺序尝试：

    1. 前往 [replit.com/forgot](https://replit.com/forgot) 重置密码，并检查垃圾邮件文件夹。
    2. 如果您是通过 Google、GitHub 或 Apple 注册的，请使用 **使用 [模型提供方]继续** 按钮，而非电子邮件和密码表单。
    3. 确认您使用的是注册时所用的电子邮件地址——您可能用了其他地址。

    如果以上方法都无效，[请联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="我看到了别人的项目，或者怀疑有人未经授权访问了我的账户">
    请立即采取以下措施：

    1. 在 [replit.com/forgot](https://replit.com/forgot) 重置密码。
    2. 在账户安全设置中退出其他活跃会话。
    3. [联系 Replit 支持团队](https://replit.com/support)，并说明您发现的情况。

    如果您看到不属于自己的项目，可能登录到了错误的账户——请检查右上角显示的账户名称。
  </Accordion>

  <Accordion title="如何更改我的电子邮件地址或用户名？">
    要更改用户名，请在 [CLUI](/zh/pt/features/workspace-tools/clui-graphical-cli) 中运行 `account > change-username` 命令，然后提交新用户名。用户名只能更改一次。

    要更改电子邮件地址，请前往**设置 → 个人资料**并编辑电子邮件地址。如果无法完成身份验证，请使用当前和新的电子邮件地址[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="如何永久删除我的 Replit 账户？">
    请先下载所有需要保留的内容——账户删除后无法恢复。在网页端，请先取消所有有效订阅，然后前往**设置 → 个人资料**，申请删除账户。在移动端，请在 Replit 应用中依次打开**账户 → 更多 → 删除账户**。请参阅[删除您的数据](/zh/pt/legal-and-security-info/deleting-your-data)。
  </Accordion>

  <Accordion title="我好像有两个使用同一电子邮箱的 Replit 账户——该怎么办？">
    当你先通过一种方式 (如电子邮件) 注册，之后又通过另一种方式 (如 Google) 登录时，就会创建第二个账户。

    1. 尝试通过两种方式登录，确认是否存在两个账户。
    2. 决定要保留哪个账户。
    3. 复制要关闭账户中的项目——使用 **下载为 zip** 或 fork 这些项目。
    4. 在 **设置 → 个人资料** 中删除不需要的账户。

    如果不确定哪个账户包含你的订阅或项目，[请联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="登录后，我被重定向到了非预期的账户">
    您的多个账户可能关联了同一个登录提供方。请尝试使用其他登录方式——电子邮箱和密码，或其他提供方——访问您想要的账户。如果您需要帮助确认每种登录方式对应哪个账户，请提供您的用户名并[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="我无法再通过 SSH 连接到 workspace.*.repl.co">
    SSH 主机名 `workspace.*.repl.co` 已停用。请在项目中打开 [SSH](/zh/pt/features/workspace-tools/ssh) 面板，复制当前的连接命令——该命令使用 `*.replit.dev` 地址。请更新所有仍引用旧 `repl.co` 地址的 SSH 脚本或配置。
  </Accordion>

  <Accordion title="我的账户为何被暂停？如何申诉？">
    Replit 会暂停违反其服务条款或社区准则的账号，计费争议或拒付也可能触发自动封禁。请先查看您的电子邮箱 (包括垃圾邮件) ，确认是否有说明原因的邮件。

    如果与计费相关，请在 **设置 → 计费** 中处理未结账单。如果您认为账号被暂停是误判，请[联系 Replit 支持团队](https://replit.com/support)，并提供您的用户名、注册邮箱和简要说明。请参阅[违规系统常见问题](/zh/pt/legal-and-security-info/strike-system-faq)和[信任与安全](/zh/pt/legal-and-security-info/trust-and-safety)。
  </Accordion>

  <Accordion title="我无法注册，或无法通过公司网络加载我的 workspace">
    企业或学校网络可能会阻止 Replit，即使你的账户本身没有问题。常见症状包括注册按钮一直转圈、Workspace 一片空白、反复断开连接，或出现 Cloudflare 的 403 &quot;Attention Required!&quot; 页面。当企业安全工具——SSL/TLS 检查设备、会重写标头的代理，或信誉较低的共享出口 IP——干扰 Replit 所依赖的连接时，就可能出现这种情况。

    首先，确认是否由网络导致：

    1. 使用同一浏览器，在其他网络上重试，例如个人手机热点。
    2. 尝试使用无痕或隐私窗口，以及不含扩展程序或不受管理策略控制的浏览器。

    如果 Replit 在企业网络外可以正常运行、但在网络内无法运行，请让你的 IT 团队将 Replit 加入允许列表。按域名允许比按 IP 地址允许更可靠，因为 Replit 的 IP 地址会变动。请让他们允许以下域名：

    * `replit.com` 和 `*.replit.com`——主网站和静态资源
    * `*.replit.dev`——开发 URL
    * `*.replit.app`——已发布的应用
    * `*.repl.co`——旧版开发 URL
    * `replit-com-static.b-cdn.net`——字体
    * `replitcdn.b-cdn.net`——媒体资源

    Replit 在这些域名上使用持久的 WebSocket 连接、频繁的 API 调用和身份验证 token 交换，因此还请让你的 IT 团队检查以下事项：

    * **SSL/TLS 检查**——为上述域名添加证书检查例外。检查代理可能会在验证 Replit 证书时静默失败，导致页面卡住且没有显示错误。
    * **标头重写**——修改、移除或注入 HTTP 标头的代理规则会破坏跨域 API 调用和身份验证。
    * **WebSocket 流量**——允许连接到上述域名的 `wss://`。
    * **浏览器策略**——组策略或 MDM 规则若阻止未获允许域名的 Cookie 持久化或第三方 Cookie，可能会导致登录失败。
    * **DNS 解析器**——确认 `replit.com` 和一个 `*.replit.dev` 主机名能够解析，并与 `8.8.8.8` 或 `1.1.1.1` 等公共解析器进行比较。分割视界或带过滤功能的解析器有时不会为开发 URL 返回任何记录。

    如果你的 IT 团队应用这些更改后，Replit 在企业网络中仍然无法运行，请提供你的用户名以及看到的确切错误信息或 Cloudflare Ray ID，[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="某个连接器（Stripe、GitHub、Resend）无法正常工作，该如何重新连接？">
    连接器使用的 OAuth token 可能会过期或被撤销。要重新连接，请打开 **工具 → 连接器**，断开有问题的连接器，然后重新连接并重新授权。token 会在您项目的 [Secrets](/zh/pt/core-concepts/project-editor/app-setup/secrets) 中自动更新。

    如果重新连接后仍然失败，请确认您在第三方服务中的账户处于有效状态，并拥有相应权限。请参阅[管理连接器](/zh/pt/replitai/managing-connectors)和[集成概览](/zh/pt/features/integrations/overview)。
  </Accordion>

  <Accordion title="我可以将 Replit 账户转让给他人吗？">
    账户无法直接转让——账户与创建它的凭据绑定。要转让特定项目，请让新所有者创建账户。与其共享该项目，并让其将项目 fork 到自己的账户。要更改当前账户的电子邮箱，请前往 **设置 → 个人资料** 并编辑电子邮箱。订阅无法转让——新所有者需要自行订阅。如需转让企业账户，[请联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>
</AccordionGroup>
