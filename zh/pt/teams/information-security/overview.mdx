<div id="proteo-de-dados">
  ## 数据保护
</div>

数据保护是 Replit 的重中之重。我们采取了全面的安全措施，保护您的数据并确保平台的完整性。

<div id="hospedagem-e-infraestrutura">
  ### 托管与基础设施
</div>

Replit 主要将数据托管在美国的 Google Cloud Platform (GCP) 数据中心，同时为有需要的用户提供印度可选托管区域。我们借助 GCP 的企业级备份与恢复工具，确保：

<CardGroup cols={2}>
  <Card title="高可用性" icon="server">
    冗余系统与自动故障转移机制可防范服务中断和数据丢失
  </Card>

  <Card title="数据隔离" icon="layer-group">
    严格的逻辑隔离可阻止不同用户和组织之间的未授权访问
  </Card>
</CardGroup>

GCP 是业界领先的云服务提供商，已通过 **ISO 27001** 和 **SOC 2 Type 2** 合规认证。此外，**Replit 已获得 SOC 2 Type 2 合规鉴证**，体现了我们对安全最佳实践与控制措施的持续投入。

每个客户端请求在访问任何私密信息之前，都必须经过严格的**身份验证和授权**。

<div id="padres-de-criptografia">
  ### 加密标准
</div>

<Note>
  Replit 对各种状态的数据均实施全面加密，以确保您的信息的机密性、完整性和安全性。
</Note>

<AccordionGroup>
  <Accordion title="传输中加密" icon="shield-halved">
    行业标准的 **TLS 1.2+** 加密保护客户端与我们服务器之间的所有通信，确保数据在网络中传输时的安全。这包括所有 API 调用、网页流量、实时协作数据以及其他通信。
  </Accordion>

  <Accordion title="静态数据" icon="database">
    存储在 GCP 中的数据通过 [**服务器端 AES-256 加密**](https://cloud.google.com/docs/security/encryption/default-encryption) 进行保护。这一军用级加密标准可保护所有已存储的数据，包括代码、配置、用户信息和系统元数据。
  </Accordion>

  <Accordion title="数据库安全" icon="lock">
    我们使用 **Google Cloud SQL** 实现[数据库加密](https://cloud.google.com/sql/references/additional-resources/faq#encryption-manage-rest)和[安全密钥管理](https://cloud.google.com/secret-manager)，通过自动加密、定期轮换密钥和精细的访问控制，确保敏感数据始终受到保护。
  </Accordion>
</AccordionGroup>
