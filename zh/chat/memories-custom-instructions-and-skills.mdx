Memories、Custom Instructions 和 Skills 都能让 Replit 掌握更充分的上下文。请根据信息的性质来选择：它是一条长期规则、一套可重复的流程，还是过往工作中沉淀下来的有用上下文。

|                         | 由谁维护           | Replit 何时使用 | 适用场景             |
| ----------------------- | -------------- | ----------- | ---------------- |
| **Custom Instructions** | 你或你的团队         | 始终生效，跨会话适用  | 希望被一致应用的稳定偏好和规则  |
| **Skills**              | 你或你的团队         | 与特定任务相关时    | 可重复的流程、工作流以及配套材料 |
| **Memories**            | Replit 维护，由你监督 | 相关上下文有帮助时   | 避免重复说明过往工作中的有用偏好 |

<div id="choose-the-right-tool">
  ## 选择合适的工具
</div>

* 使用**自定义指令**来设定在整个 Workspace 中始终生效的规则，例如指定获准使用的库或数据处理要求。这些内容由你编写，Replit 不会修改。
* 使用 **skill** 来沉淀某类具体工作的可复用做法，例如准备发布或评审设计。稳定的流程性知识应放在 skill 中。
* 使用**记忆**让 Replit 保留以往工作中的有用上下文，这样你就不必反复说明相关偏好。Replit 可以在你工作时写入记忆；它们是上下文参考，而非可执行的指令。

你的明确请求和自定义指令优先于记忆。可在**设置 → 自定义 → 记忆**中管理记忆。记忆不会保留个人或敏感信息，且默认为私有。是否与协作者共享由你决定，默认关闭。
