技能目录汇集了由 Replit 及合作伙伴创建、可立即安装使用的现成技能。安装并试用一项技能后，再根据团队的实际工作方式进行调整。

如需了解技能及 Agent 如何加载技能，请参阅 [Agent Skills](/zh/ko/features/agent/skills)。如需了解如何让技能在整个工作区内可用，请参阅 [Agent 自定义](/zh/ko/features/agent/agent-customization)。

<div id="section">
  ## 安装技能
</div>

你可以通过以下几种方式从目录中添加技能：

* **在聊天中** — 点击聊天输入框旁的 **+** 按钮，选择 **使用技能**，然后选择一个技能。该技能仅适用于当前消息，不会在项目中安装任何内容。
* **在项目中** — 在 Project Editor 中打开 **Skills 面板**，选择 **Discover** 标签页，找到所需技能后点击 **Install**。已安装的技能会保存在项目的 `/.agents/skills` 目录中，可在多个聊天中持续使用。
* **通过命令行** — 使用 [skills CLI](https://github.com/vercel-labs/skills) 安装技能：

  ```bash theme={null}
  npx skills <skill> -a replit
  ```

<Warning>
  Replit 技能选择器中的技能均已通过安全审核，外部来源安装的技能则不然。技能是 Agent 会遵循的指令，因此安装前请务必审核外部技能。有关需要检查的内容，请参阅 [Agent skills](/zh/ko/learn/agent-skills)。
</Warning>

<div id="replit">
  ## Replit 技能
</div>

Replit 提供预定义技能，可在聊天中的**使用技能**选择器和新项目起点选择器中使用。这些技能无需安装，即可在所有项目中使用。打开选择器后即可查看说明。

| 类别     | 技能                                                                                                            |
| ------ | ------------------------------------------------------------------------------------------------------------- |
| 销售与营销  | Ad Creative, AI SDR, SEO Auditor, Programmatic SEO, GEO, Content Machine, Storyboard                          |
| 职业发展   | AI Recruiter, Resume Maker, Interview Prep                                                                    |
| 研究与分析  | Competitive Analysis, Deep Research, GitHub Solution Finder, Supplier Research                                |
| 商务与财务  | Stock Analyzer, Excel Generator, Invoice Generator, Tax Reviewer                                              |
| 文档与工具  | Website Cloner, File Converter, Flashcard Generator, Legal Contract, Infographic Builder, Recreate Screenshot |
| 创作     | Photo Editor, Podcast Generator, Podcast Marketing, Branding Generator, Video Editing                         |
| 生产力    | AI Secretary, Product Manager, Design Thinker, Skill Finder, Skill Creator                                    |
| 个人     | Travel Assistant                                                                                              |
| 安全与合规  | Secrets, Sensitive Data, Input Validation, AI Security, Dependency Vetting, License Check                     |
| 质量与稳定性 | Accessibility, Responsive UI, Observability, Resilience, Ship Review                                          |

<Note>
  在工作区中，选择器还会查找安装在项目 `.local/secondary_skills/` 目录中的其他技能。
</Note>

<div id="section-2">
  ## 合作伙伴技能
</div>

Replit 的合作伙伴会发布技能，教 Agent 如何使用其产品进行构建。安装技能后，Agent 就能了解该服务的常用模式和惯例。

| 合作伙伴             | Agent 可学习的内容                 |
| ---------------- | ---------------------------- |
| Stripe           | 支付和计费集成模式                    |
| PayPal           | 支付集成模式                       |
| RevenueCat       | 订阅和应用内支付模式                   |
| Mixpanel         | 分析和跟踪实现                      |
| BigQuery         | 数据仓库查询模式                     |
| Resend           | 事务性电子邮件集成                    |
| Google Workspace | Gmail、Drive、Docs、Calendar 集成 |
| Atlassian        | Jira 和 Confluence 议题及页面工作流   |
| Google Maps      | 地图、地点、路线和地理编码集成              |

<div id="section-3">
  ## 社区技能
</div>

除 Replit 和合作伙伴提供的技能外，社区还发布了可安装的技能。你可以在 [skills.sh](https://skills.sh) 浏览这些技能；如需自行编写技能，请参阅 [Agent Skills specification](https://agentskills.io/specification)。
