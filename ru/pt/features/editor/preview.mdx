Preview показывает результат работы вашего веб-приложения и предоставляет браузерные инструменты разработчика и
средства отладки.

Когда вы запускаете веб-приложение кнопкой **Run**, Replit присваивает ему временный URL,
доступный через интернет. Инструмент Preview отображает страницу точно так же, как вы увидели бы её
в браузере. Он также включает инструменты разработчика, по возможностям схожие
с теми, что есть в популярных браузерах.

<Note>
  Preview — это новое название Webview.
</Note>

<div id="recursos">
  ## Возможности
</div>

Preview включает следующие функции, позволяющие тестировать и отлаживать веб-приложения, не выходя из рабочей среды:

* **Живой просмотр веб-приложения**: просматривайте приложение и взаимодействуйте с ним, не покидая вкладку браузера
* **Инструменты разработчика**: используйте встроенные инструменты для быстрой диагностики проблем
* **Проверка адаптивности**: смотрите, как приложение выглядит при разных размерах экранов мобильных устройств

<div id="uso">
  ## Использование
</div>

Инструмент Preview открывается автоматически при запуске веб-приложения.
Это поведение можно изменить в инструменте **Пользовательские настройки**, в параметре **Automatic Preview**.

Ниже описано, как открыть Preview.

<Accordion title="Как открыть Preview">
  На **панели инструментов** слева:

  1. Выберите <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="значок «Все инструменты»" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **Все инструменты**, чтобы открыть список инструментов редактора проекта.
  2. Выберите <img class="icon-svg" src="/assets/mirror/preview-icon-6d37238e8cc2.svg" alt="значок Preview" width="16" height="16" data-path="images/icons/preview-icon.svg" /> **Preview**.

  В **строке поиска**:

  1. Нажмите значок лупы <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="значок лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> вверху, чтобы открыть инструмент поиска
  2. Введите «Preview», чтобы найти инструмент, и выберите его в результатах.
</Accordion>

<div id="barra-de-localizao">
  ## Адресная строка
</div>

Адресная строка в верхней части вкладки **Preview** содержит следующие инструменты:

* **Кнопка «Назад»**: переход на предыдущую страницу в истории навигации
* **Кнопка «Вперёд»**: переход на следующую страницу в истории навигации
* **Домен приложения**: чтобы посмотреть информацию о временном URL вашего Replit App, выберите `{...}.replit.dev`
* **Поле адреса**: просмотр текущего пути URL или ввод нового пути

<div id="ferramentas-do-navegador">
  ## Инструменты браузера
</div>

Инструменты браузера справа от адресной строки включают следующие функции:

* **Размер экрана**: выберите одну из предустановок размера экрана устройства, чтобы протестировать адаптивный дизайн
* **Devtools**: переключение панели [инструментов разработчика](#Developer_tools)
* **Новая вкладка**: откройте URL вашего веб-приложения в новой вкладке браузера

<Note>
  **Разрабатываете мобильное приложение?** Панель Preview также поддерживает просмотр в **iOS Simulator** или **Android Emulator**. Подробности см. в разделе [Нативные мобильные приложения](/ru/pt/features/artifact-types/building-mobile-apps#preview-on-a-simulator-or-emulator).
</Note>

<div id="ferramentas-de-desenvolvedor">
  ## Инструменты разработчика
</div>

Инструменты разработчика, созданные на базе проекта с открытым исходным кодом <a href="https://github.com/liriliri/eruda" target="_blank">Eruda</a>, помогают решать следующие задачи:

* Просматривать консоль JavaScript в контексте вашего приложения и работать с ней
* Проверять элементы DOM
* Отслеживать сетевые запросы
* Настраивать параметры отображения и поведения

Чтобы открыть инструменты разработчика, нажмите кнопку <img class="icon-svg" src="/assets/mirror/wrench-7cee9d1168da.svg" alt="значок гаечного ключа" width="16" height="16" data-path="images/icons/wrench.svg" /> **Devtools**
в верхней части вкладки **Preview** — она включает и отключает их.

В следующих разделах описаны действия, доступные на каждой вкладке инструментов разработчика.

<div id="console">
  ### Консоль
</div>

На вкладке **Console** отображаются журналы JavaScript, которые создаёт ваше приложение.
На этой вкладке доступны следующие действия:

* **Очистить вывод**: удалите весь вывод консоли, нажав значок <img class="icon-svg" src="/assets/mirror/clear-bd1bf1847597.svg" height="16" width="16" alt="значок круга с чертой" data-path="images/icons/clear.svg" /> круга с чертой.
* **Фильтровать вывод**: просматривайте вывод консоли с фильтрацией по типу (All, Info, Warning или Error).
* **Фильтровать по тексту**: отобразите только совпадающий вывод — нажмите значок <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="значок фильтра" data-path="images/icons/filter.svg" /> фильтра и введите текст.
* **Копировать вывод**: скопируйте выбранные сообщения консоли, нажав кнопку <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="значок копирования" data-path="images/icons/copy.svg" /> копирования.
* **Выполнить код JavaScript**: выполните код JavaScript в контексте вашего приложения, нажав <img class="icon-svg" src="/assets/mirror/arrow-right-2859a6e6bdeb.svg" height="16" width="16" alt="значок стрелки вправо" data-path="images/icons/arrow-right.svg" /> правую угловую скобку. Введите выражение и нажмите **Execute**.

<div id="elements">
  ### Elements
</div>

Вкладка **Elements** позволяет просматривать и изменять структуру DOM веб-страницы.

* **Просмотр сведений об элементе**: смотрите информацию об элементе DOM и его расположение в HTML-коде
* **Копировать вывод**: копируйте выбранные сообщения консоли с помощью кнопки копирования <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="значок копирования" data-path="images/icons/copy.svg" />.

Используйте стрелку выбора <img class="icon-svg" src="/assets/mirror/select-1165d9548c39.svg" height="16" width="16" alt="иконка выбора" data-path="images/icons/select.svg" />, чтобы включить режим выбора.
После перехода в режим выбора выберите элемент на веб-странице.
HTML и CSS этого элемента появятся на вкладке Elements.

<div id="network">
  ### Network
</div>

Вкладка **Network** отслеживает запросы, отправленные веб-страницей.
На этой вкладке доступны следующие действия:

* **Отслеживание запросов**: просматривайте все сетевые запросы, отправленные вашим приложением. Выберите запрос, чтобы увидеть подробности.
* **Фильтрация**: нажмите значок воронки <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="значок фильтра" data-path="images/icons/filter.svg" />, чтобы показать только результаты, соответствующие введённому тексту. Оставьте поле фильтра пустым, чтобы сбросить его.
* **Копирование**: копируйте сведения о хранилище, нажав кнопку копирования <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="значок копирования" data-path="images/icons/copy.svg" />.

<div id="resources">
  ### Resources
</div>

Вкладка **Resources** показывает ресурсы, загруженные страницей, и данные браузера — файлы cookie, локальное хранилище и т. д.
Вы можете просматривать и обновлять списки следующих типов ресурсов:

* Файлы JavaScript
* Таблицы стилей
* Iframe-элементы
* Изображения

На этой вкладке доступны следующие действия:

* **Просмотр хранилища**: изучите локальное хранилище, хранилище сессии и файлы cookie.
* **Фильтрация**: нажмите значок воронки <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="значок фильтра" data-path="images/icons/filter.svg" />, чтобы отобразить результаты, соответствующие введённому тексту. Оставьте поле фильтра пустым, чтобы сбросить его.
* **Очистка**: удалите все данные этого типа хранилища, нажав кнопку очистки <img class="icon-svg" src="/assets/mirror/clear-bd1bf1847597.svg" height="16" width="16" alt="значок очистки" data-path="images/icons/clear.svg" />.
* **Удаление выбранного**: удалите элементы хранилища, нажав значок «X» <img class="icon-svg" src="/assets/mirror/delete-a21eb49cac3c.svg" height="16" width="16" alt="значок удаления" data-path="images/icons/delete.svg" />.
* **Копирование**: скопируйте сведения о хранилище, нажав кнопку копирования <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="значок копирования" data-path="images/icons/copy.svg" />.

<div id="settings">
  ### Settings
</div>

Вкладка **Settings** позволяет настроить внешний вид и поведение инструментов разработчика.
На этой вкладке доступны следующие параметры персонализации:

* **Настройки инструментов**: настройте параметры, применимые к каждой вкладке инструментов
* **Управление JavaScript**: задайте параметры работы JavaScript — например, отключите его, чтобы проверить, как поведёт себя ваше приложение
* **Параметры отображения**: измените тему, размер панели, прозрачность и другие особенности поведения инструментов разработчика
