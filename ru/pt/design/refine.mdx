Исследование расширяет возможности, а доработка помогает проработать детали. Когда фрейм уже почти соответствует вашим ожиданиям, две инструмента позволяют точно настроить его в соответствии с вашим стилем работы:

* Общайтесь с Agent своими словами — о фрейме целиком или об отдельном элементе
* Настраивайте элементы напрямую в Visual Editor: простые изменения применяются мгновенно и не расходуют кредитов

<div id="chat">
  ## Chat
</div>

Объясните Agent задачу так, как объяснили бы её дизайнеру во время ревью. Выберите фрейм и опишите изменения в основном чате (*«более тёплые цвета»*, *«hero выглядит пустым»*), либо выберите инструмент **Chat** на панели инструментов и щёлкните элемент, чтобы ограничить сообщение только этим элементом.

<div id="visual-editor">
  ## Visual Editor
</div>

Если вы уже точно знаете, чего хотите, пропустите prompt. Выберите инструмент **Edit** на панели инструментов и щёлкните любой элемент — откроется Visual Editor со свойствами этого элемента, такими как содержимое, раскладка, цвет и граница. Простые изменения, например текста, цвета или отступов, мгновенно применяются к исходному коду без расхода кредитов.

<div id="qual-ferramenta-usar">
  ## Какой инструмент использовать
</div>

| Вы хотите…                                                                    | Используйте   |
| ----------------------------------------------------------------------------- | ------------- |
| Описать желаемый результат и поручить Agent разобраться с деталями            | Chat          |
| Изменить текст, цвет, отступы или изображение элемента на конкретное значение | Visual Editor |
| Переделать структуру или поведение раздела                                    | Chat          |
| Быстро внести изменения без затрат кредитов                                   | Visual Editor |

Эти инструменты естественно дополняют друг друга: в Chat задайте направление, а затем с помощью Visual Editor доработайте детали.
