开发 URL 让你在构建应用的同时进行预览和测试。这些 URL 采用 `UUID.servername.replit.dev` 格式，可在开发过程中提供应用的实时预览。

  <img src="/assets/mirror/preview-dev-url-b36770b33769.png" alt="地址栏中显示的开发 URL" width="1222" height="824" data-path="images/workspace/preview-dev-url.png" />
</Frame>

要查看你的开发 URL，请点击地址栏中的 `{...}.replit.dev` 文本。

<div id="entendendo-as-urls-de-desenvolvimento">
  ## 了解开发 URL
</div>

开发 URL 仅在你正在编辑某个 Replit App 时保持可用。每次重新打开应用时，URL 都可能发生变化。借助开发 URL，你可以一边构建和测试，一边在浏览器中查看效果。

默认情况下，开发 URL 是公开的。任何拿到该 URL 的人都能在你构建应用的过程中查看它。这样一来，你可以方便地与协作者、测试人员或相关方分享进行中的工作。

<Warning>
  开发 URL 是临时的，仅供测试使用。若要与他人分享应用，建议[发布你的应用](/zh/pt/learn/projects-and-artifacts/replit-deployments)。
</Warning>

<div id="banner-educativo">
  ### 说明横幅
</div>

当你在新标签页中打开开发预览时，页面顶部会显示一个说明横幅。它可以帮助你在构建和测试应用的过程中，了解 `.replit.dev` URL 的用途，并提供有关开发 URL 及其在开发过程中预期用法的上下文。

<div id="tornando-as-urls-de-desenvolvimento-privadas">
  ## 将开发 URL 设为私有
</div>

你可以限制对开发 URL 的访问，保护尚未完成的工作。

要将开发 URL 设为私有：

1. 在 Project Editor 中打开 **Developer tools**。
2. 选择 **Networking** 标签页。
3. 打开 **Private development URL** 开关。

启用后，访问开发 URL 需要通过身份验证，只有你和已授权的团队成员才能查看进行中的工作。

<Note>
  Enterprise 客户可以要求所有项目都使用私有开发 URL，确保开发工作在组织环境中始终受到保护，从而提升安全性。
</Note>

<div id="melhores-prticas">
  ## 最佳实践
</div>

* **使用私有 URL**：在开发敏感或专有应用时使用
* **使用公开 URL**：在积极开发过程中与外部相关方分享成果，或在其他浏览器中测试你的 App
