应用测试让 Agent 能够使用真实浏览器测试其构建的应用。Agent 会像真实用户一样浏览应用、点击操作并验证功能。这项自测功能有助于确保应用正常运行，并让 Agent 自动发现和修复问题。

启用应用测试后，Agent 会在认为已发生足够多更改时定期自测。Agent 不会在每条用户消息后都进行测试，而是会智能判断何时测试最有价值。

<Note>
  应用测试目前适用于全栈 JavaScript 和 Streamlit Python Web 应用。
</Note>

<div id="section">
  ### 主要优势
</div>

* **更高的自主性**：让 Agent 无需人工干预即可持续工作更长时间
* **更高质量**：及早发现并解决问题，打造错误更少的应用
* **成本效益**：在开发过程中发现问题，减少额外调试会话的需求
* **交互式审查**：提供视频回放和分段浏览，便于深入分析结果

<div id="section-2">
  ### 测试流程
</div>

当 Agent 决定自测时，将执行以下流程：

1. **浏览器预览**：Agent 面板中会显示浏览器预览
2. **视觉测试**：你可以看到 Agent 的光标在应用中点击并测试各项功能
3. **模拟真实用户**：Agent 会像真实用户一样浏览应用，并在需要时输入模拟数据
4. **自动分析**：Agent 会分析测试结果并找出所有问题
5. **自我修复**：Agent 会报告测试摘要，并自动修复发现的问题

<div id="section-3">
  ## 主要功能
</div>

Agent 会像真实用户一样探索应用，并智能测试以下内容：

* **用户界面验证**：按钮、表单、导航和视觉元素
* **功能检查**：核心功能和用户工作流
* **集成测试**：API 调用、数据库交互和第三方服务
* **性能和无障碍访问**：加载时间、响应速度和无障碍标准

<div id="section-4">
  ## 使用方法
</div>

应用测试位于聊天输入框中 Agent 设置下拉菜单的**高级设置**里。使用 Economy 或 Power 模式时，请开启此功能。Lite 模式下，应用测试会保持关闭状态。

<Note>
  应用测试是 Agent 的一项自主功能，并附带内置代码审查功能。了解更多其他 [Agent
  功能](/zh/ko/features/agent/overview)。
</Note>

<div id="section-5">
  ## 接管
</div>

有时，Agent 在测试过程中会遇到需要你协助才能继续的障碍。最常见的情况是需要登录用户账户 (例如 Gmail) 。此时，Agent 会弹出“开始接管”按钮。

<Frame>
  <img src="/assets/mirror/app-testing-takeover-6e0b0b56f4d0.png" alt="显示错误和 CAPTCHA 处理说明，以及“跳过”和“开始接管”按钮的应用测试接管界面" width="924" height="358" data-path="images/replitai/app-testing-takeover.png" />
</Frame>

点击“开始接管”后，你可以进入测试预览，完成所需步骤，再让 Agent 继续。如果 Agent 无法在没有你协助的情况下继续，也可以点击“跳过”，跳过接管并结束应用测试。如果你在 10 分钟内未响应，Agent 将视同你点击了“跳过”并继续执行。

<div id="section-6">
  ### 预期行为
</div>

* **跳过选项**：如有需要，可使用跳过按钮跳过测试并继续开发
* **交互式视频回放**：测试完成后，点击视频可回放整个测试会话
* **区段导航**：使用底部滑块跳转到测试的特定区段

<div id="section-7">
  ## 故障排查
</div>

**测试意外失败**

* 跳过后重新输入提示词，再次尝试测试
* 检查可能影响测试时序的动态内容
* 核查测试场景是否准确

**测试覆盖不足**

* 更详细地说明应用功能
* 明确指出需要测试的重要用户流程

**应用测试完全无法运行？**

* 应用测试目前仅适用于 Web 应用[*](#how-app-testing-works)

<div id="section-8">
  ## 定价和使用量
</div>

应用测试采用 Agent 基于工作量的定价模式，使用时需注意以下成本因素：

* **按工作量计费**：测试费用取决于所需工作量 (测试越简单，费用越低)
* **成本效益**：测试虽会产生费用，但能及早发现问题，避免额外编写提示词和让 Agent 进行更多工作，从而降低总成本
* **高效开发**：自动化方式可减少手动调试和返工

<Tip>
  **经济高效的测试**：虽然应用测试会增加使用成本，但它通常能避免额外开启 Agent 会话来修复原本可在测试中发现的问题，从而降低总成本。
</Tip>

<div id="section-9">
  ## 下一步

3. **迭代**：根据测试反馈改进应用
4. **扩展**：将应用测试应用于规模更大、更复杂的项目
