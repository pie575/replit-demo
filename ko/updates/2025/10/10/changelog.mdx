### Agent 사용 비용 가시성

작업이 실행되는 동안 Agent 사용 비용을 실시간으로 확인하세요. 채팅 헤더 서랍을 열어 활성 작업의 지출을 모니터링하세요—특히 더 오래 걸리는 고자율성 실행에 유용합니다.

### 시각적 선택/편집 모드의 Escape 키

Escape 키를 눌러 시각적 선택 모드를 종료하거나 빌드 모드로 돌아갈 수 있습니다. 작업 흐름을 끊기지 않게 해주는 작은 단축키입니다.

### 더 빠른 Agent 중지

작업공간에서 Agent를 중지하거나 시작할 때 더 빠르게 응답하여 대기 시간이 줄어들었습니다.

### GitHub 가져오기 개선

GitHub 가져오기 중에 일반적인 메시지 대신 실시간 진행 상황을 확인할 수 있으며, 가져오기 속도도 빨라졌습니다.

### 종속성 취약점 스캔

보안 스캐너가 이제 Go, JavaScript, Python, Rust의 종속성 취약점을 감지하며, 더 많은 언어가 곧 추가될 예정입니다.

### 웹뷰 로깅 경험

Agent가 사용하는 동일한 로그인 웹뷰 로그와 콘솔 출력을 한 곳에서 확인하여 디버깅을 더 간단하게 만드세요.
