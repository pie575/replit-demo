<div id="shopify">
  ### Vendre des produits physiques avec Shopify
</div>

Vous pouvez désormais créer une boutique en ligne pour vendre des produits physiques. Demandez à Agent de créer une boutique : il génère une boutique Shopify, y ajoute vos produits et configure le panier et le paiement. Lorsque Agent vous transmet le lien permettant de revendiquer votre boutique, souscrivez à un plan Shopify et connectez le paiement pour la mettre en ligne.

<div id="microsoft-fabric">
  ### Créer des applications de données sur Microsoft Fabric
</div>

Vous pouvez désormais créer des applications de données basées sur l&#39;IA dans Replit et les publier directement sur Microsoft Fabric. Partez du modèle Microsoft Fabric, connectez vos modèles sémantiques Power BI et demandez à Agent de créer des tableaux de bord et des outils internes s&#39;appuyant sur vos données d&#39;entreprise gérées. L&#39;authentification et les politiques d&#39;accès restent gérées au sein de Fabric.

<div id="dns">
  ### Configuration DNS automatique pour les domaines personnalisés
</div>

Connecter votre propre nom de domaine est désormais bien plus simple. Lorsque vous connectez un domaine, Replit configure automatiquement les enregistrements DNS nécessaires via Entri : vous n&#39;avez donc plus à les copier manuellement chez votre fournisseur de domaine. Sélectionnez votre domaine, confirmez, et Replit s&#39;occupe du reste.

En savoir plus sur les [domaines personnalisés](/fr/ko/features/publishing/custom-domains).

<div id="seo-agent">
  ### Améliorer votre classement dans les résultats de recherche avec SEO Agent
</div>

SEO Agent analyse votre application publiée et repère les problèmes qui empêchent les moteurs de recherche et les outils d&#39;IA de la découvrir. Chaque problème détecté s&#39;accompagne d&#39;un correctif en un clic, que vous pouvez examiner avant de l&#39;appliquer. Ouvrez le panneau **Croissance** dans votre projet pour lancer une analyse.

<div id="stripe">
  ### Utiliser Stripe dans les espaces de travail collaboratifs
</div>

Stripe fonctionne désormais dans les espaces de travail collaboratifs : toute l&#39;équipe peut ainsi créer, tester et monétiser la même application ensemble. Chaque membre de l&#39;espace de travail peut utiliser le compte Stripe connecté, au lieu de configurer les paiements de son côté.

Pour en savoir plus, consultez [Paiements Stripe](/fr/ko/features/monetization/stripe-payments).
