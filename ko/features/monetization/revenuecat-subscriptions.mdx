<div id="what-is-revenuecat">
  ## RevenueCat이란
</div>

RevenueCat을 사용하면 [네이티브 모바일 앱](/ko/features/artifact-types/building-mobile-apps)에 인앱 구독을 추가할 수 있습니다. 시작하려면 Agent에게 구독 설정을 요청한 뒤 RevenueCat 계정을 연결하세요. 이후 Agent가 관련 로직을 처리하고 테스트 환경을 제공합니다.

<div id="prerequisites">
  ## 사전 준비 사항
</div>

시작하기 전에 다음이 필요합니다.

* **모바일 앱**으로 생성한 Replit project
* [RevenueCat](https://www.revenuecat.com) 계정(이메일과 비밀번호만 있으면 되며, 은행 계좌나 별도의 추가 설정은 필요하지 않습니다)

<Note>
  네이티브 모바일 앱 작업은 [replit.com](https://replit.com)의 Project Editor에서 진행하세요. 지원되는 경우 Replit Android 앱에서도 네이티브 모바일 앱 작업을 할 수 있습니다. Replit iOS 앱을 사용 중이라면 replit.com에서 project를 열어 주세요.
</Note>

<div id="test-subscriptions">
  ## 구독 테스트하기
</div>

<Frame>
  <img src="/assets/mirror/revenuecat-test-purchase-8414145a112e.png" alt="package 세부 정보와 테스트 버튼이 표시된 모바일 기기의 테스트 구매 대화 상자" width="683" height="1253" data-path="images/replitai/revenuecat-test-purchase.png" />
</Frame>

<Tip>
  개발 중에는 테스트 구매를 안심하고 사용할 수 있습니다. 실제 청구 없이 구매 성공
  flow와 실패 flow를 모두 테스트해 볼 수 있습니다.
</Tip>

<Warning>
  Apple이 App Store 배포를 승인한 뒤부터는 구매에 실제 금액이 사용됩니다.
  App Review에 제출하기 전에 RevenueCat products와 pricing이 올바른지 확인하세요.
</Warning>

<div id="syncing-to-app-store-connect">
  ## App Store Connect에 동기화하기
</div>

TestFlight와 Apple App Store에서 인앱 구매가 작동하려면 [Apple의 Paid Apps Agreement에 동의하고 은행 계좌를 연결해야 합니다](https://developer.apple.com/help/app-store-connect/manage-agreements/sign-and-update-agreements/).
이 작업은 App Store Connect에서 진행합니다. App Store에 앱을 제출하려면 먼저 유료 Apple Developer Account가 있어야 합니다.

그 이후에는 RevenueCat의 인앱 구매 설정을 Replit에서 바로 App Store Connect로 동기화할 수 있습니다.

<Steps>
  <Step title="Publishing의 Manage 창으로 이동">
    RevenueCat을 App Store Connect에 동기화하는 버튼이 표시됩니다.

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-sync-btn-46a2e4e696df.png" alt="RevenueCat을 App Store Connect에 동기화하는 버튼" width="1476" height="604" data-path="images/replitai/revenuecat-asc-sync-btn.png" />
    </Frame>

    <Tip>
      이 섹션은 앱을 TestFlight에 제출한 후에만 나타납니다.
    </Tip>
  </Step>

  <Step title="App Store Connect API key 입력">
    이 키를 얻으려면 App Store Connect로 이동해야 합니다.

    [App Store Connect](https://appstoreconnect.apple.com/access/integrations/api)에서 **Users and Access**로 이동한 다음 **Integrations** 탭을 선택합니다. 사이드바에서 **App Store Connect API**를 선택합니다.

    키를 생성할 때 반드시 &quot;App Manager&quot; permissions을 부여하세요.

    .p8 파일은 지금 download하세요. 단 한 번만 download할 수 있습니다. 파일 이름은 `AuthKey_`로 시작하고 `.p8`로 끝납니다.

    이 페이지에 표시된 **Key ID**와 **Issuer ID**를 복사하세요.

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-create-c54be8304d7c.png" alt="Integrations 탭, App Store Connect API 사이드바 링크, 새 API key를 생성하는 더하기 버튼을 번호로 강조 표시한 App Store Connect Users and Access 페이지" width="2390" height="752" data-path="images/replitai/revenuecat-asc-create.png" />
    </Frame>

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-app-manager-93996acd8561.png" alt="이름이 RevenueCat으로, Access가 App Manager로 설정된 App Store Connect의 Generate API Key 대화 상자" width="1116" height="560" data-path="images/replitai/revenuecat-asc-app-manager.png" />
    </Frame>

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-copy-07a95e1be9af.png" alt="Issuer ID Copy 링크와 Key ID 열을 화살표로 가리키는 App Store Connect API keys 페이지" width="2330" height="780" data-path="images/replitai/revenuecat-asc-copy.png" />
    </Frame>
  </Step>

  <Step title="In-App Purchase API key 생성">
    In-App Purchase API key에 대해서도 이전 단계를 반복합니다.
    사이드바에서 **In-App Purchase**를 선택합니다. 그런 다음 **App Manager** permissions을 가진 API key를 생성합니다.
    .p8 키를 download하세요(파일 이름은 `SubscriptionKey_`로 시작하고 `.p8`로 끝납니다). **Key ID**와 **Issuer ID**를 복사하세요.

    <Frame>
      <img src="/assets/mirror/revenuecat-iap-api-key-7eb34e815ccb.png" alt="사이드바에서 In-App Purchase가 선택되어 있고 새 키를 생성하는 더하기 버튼을 화살표로 가리키는 App Store Connect Users and Access 페이지" width="2272" height="637" data-path="images/replitai/revenuecat-iap-api-key.png" />
    </Frame>
  </Step>

  <Step title="products 동기화">
    products 목록을 확인한 다음 App Store Connect로 동기화합니다.

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-products-sync-078d42af83ba.png" alt="가격, 기간, 지역 필드가 있는 Monthly Subscription product와 Sync to App Store Connect 버튼이 표시된 인앱 구매 관리 대화 상자" width="948" height="476" data-path="images/replitai/revenuecat-asc-products-sync.png" />
    </Frame>
  </Step>
</Steps>

<div id="frequently-asked-questions">
  ## 자주 묻는 질문
</div>

<AccordionGroup>
  <Accordion title="RevenueCat을 사용하려면 은행 계좌가 필요한가요?">
    아니요. RevenueCat 계정을 만들려면 이메일과 비밀번호만 있으면 됩니다. 은행
    계좌 설정은 App Store 또는 Google Play에서 정산금을 받을 준비가 되었을 때
    Apple 또는 Google을 통해 별도로 진행합니다.
  </Accordion>

  <Accordion title="테스트 구매에도 요금이 청구되나요?">
    아니요. 개발 중에는 Replit 미리보기가 RevenueCat의 테스트 모드를 사용합니다.
    구매는 시뮬레이션으로 처리되며 실제 요금은 청구되지 않습니다. 실제 요금은 Apple App Review에서
    앱이 승인된 이후부터만 부과됩니다.
  </Accordion>

  <Accordion title="웹 앱에서도 RevenueCat을 사용할 수 있나요?">
    RevenueCat은 네이티브 모바일 앱을 위해 설계되었습니다. 웹 앱에 구독을 추가하려면
    대신 [Stripe 연동](/ko/features/monetization/stripe-payments)을
    사용하세요.
  </Accordion>

  <Accordion title="RevenueCat으로 무엇을 설정할 수 있나요?">
    월간 또는 연간 구독을 만들고, 가격을 설정하고, 엔타이틀먼트를 관리하고,
    paywall을 구축할 수 있습니다. Agent에게 변경을 요청하세요. RevenueCat
    설정과 앱 코드를 모두 알아서 처리해 줍니다.
  </Accordion>
</AccordionGroup>
