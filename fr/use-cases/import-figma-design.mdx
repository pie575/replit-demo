Vous avez déjà des écrans dans Figma. Agent les transforme en une application Replit fonctionnelle que vous pouvez modifier,
prévisualiser et publier : disposition, typographie, couleurs et espacement. Le résultat est un produit fonctionnel,
pas une capture d’écran. Indiquez à Agent les frames concernées si le fichier comporte plusieurs parcours.

<div id="best-for">
  ## Idéal pour
</div>

* Les designers produit qui souhaitent créer une app Replit codée à partir de frames existantes.
* Les fondateurs qui disposent d’un fichier Figma et souhaitent le mettre en ligne sans repartir de zéro.

<div id="before-you-start">
  ## Avant de commencer
</div>

Préparez un fichier Figma contenant des frames nommées (accueil, produit, checkout, etc.). Connectez Figma.
Partagez le fichier avec Agent ou collez le lien vers le fichier et ceux des frames qui vous intéressent. Indiquez
s’il s’agit d’un site marketing, d’une app ou d’une page de destination unique.

<div id="prompt-the-agent">
  ## Donnez des instructions à l’Agent
</div>

<AiPrompt>
  À partir de ce fichier Figma [lien], créez une application Replit fonctionnelle à partir de ces frames : [noms ou
  liens des frames]. Respectez la disposition, la typographie, les couleurs, les espacements et les points de rupture
  (ordinateur et mobile).
</AiPrompt>

<div id="what-to-expect">
  ## À quoi s’attendre
</div>

Agent lit les frames sélectionnées et crée les pages correspondantes, que vous pouvez publier depuis Replit. Vérifiez rapidement l’espacement,
la typographie et les couleurs par rapport à Figma. Testez vous-même les éléments interactifs (navigation, formulaires, survol). Ils
nécessitent souvent une seconde passe. Prévisualisez sur ordinateur et avec une largeur d’écran de téléphone. Cliquez sur la navigation et les formulaires,
puis comparez une capture d’écran à Figma avant de publier.

<div id="make-it-work-for-you">
  ## Adaptez-le à vos besoins
</div>

<AiPrompt>
  Commencez par implémenter uniquement les frames mobiles. Respectez la disposition
  automatique et l’espacement de Figma. Passez à la version bureau après avoir obtenu mon approbation pour la version mobile.
</AiPrompt>

<AiPrompt>
  Réutilisez un même composant pour les boutons, les champs de saisie et les cartes. Utilisez les couleurs et la typographie définies dans les
  variables Figma, si elles existent.
</AiPrompt>

<div id="troubleshooting">
  ## Résolution des problèmes
</div>

* **Agent ne parvient pas à lire le fichier :** connectez Figma, partagez le fichier et collez les liens vers les frames, pas seulement l’URL du fichier. Nommez les frames (home, product, checkout) si le fichier comporte plusieurs parcours.
* **Les effets de survol, la navigation ou les formulaires semblent inachevés :** la disposition et les couleurs sont souvent traitées en premier. Demandez une deuxième passe sur les éléments interactifs et vérifiez ponctuellement les espacements par rapport à Figma.
