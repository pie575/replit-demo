# FAQ

> Trouvez des réponses aux questions fréquentes sur Replit, notamment la gestion de compte, le dépannage, l'assistance à la facturation et l'utilisation des fonctionnalités clés.

<Tabs>
  <Tab title="Général">
    <AccordionGroup>
      <Accordion title="Où puis-je obtenir de l'aide sur le code ?">
        Le meilleur endroit pour obtenir de l'aide avec le code est d'utiliser [Replit AI](/fr/build/welcome). Dans le Project Editor, ouvrez un nouvel onglet et recherchez **AI**. Replit AI peut vous aider à configurer de nouveaux projets, répondre à des questions sur votre code et vous aider dans votre réflexion. Pour obtenir de l'aide supplémentaire, vous pouvez également consulter notre [Community Hub](https://replit.com/community) pour des ressources additionnelles.
      </Accordion>

      <Accordion title="J'ai des difficultés à utiliser Replit. Comment obtenir de l'aide ?">
        Connectez-vous à Replit et utilisez le **?** dans le coin supérieur droit de la page pour obtenir de l'aide. Pour une assistance supplémentaire, consultez le [document de politique de support](/fr/legal-and-security-info/support-policy).
      </Accordion>

      <Accordion title="Où puis-je obtenir de l'aide pour la facturation ?">
        Avant de contacter l'équipe de support, vérifiez si vous pouvez trouver une solution ci-dessous sous **Paramètres**. Si cela ne vous aide pas, veuillez vous connecter et utiliser le **?** dans le coin supérieur droit de la page pour obtenir de l'aide.
      </Accordion>

      <Accordion title="Je n'arrive pas à accéder à mon compte Replit — que dois-je faire ?">
        Veuillez envoyer un email à `support@replit.com` en indiquant votre nom d'utilisateur de compte et votre identifiant de connexion.
      </Accordion>

      <Accordion title="Quand recevrai-je une réponse de Replit ?">
        Le support Replit est généralement disponible du lundi au vendredi de 9h à 20h, heure normale de l'Est (UTC-5).
      </Accordion>

      <Accordion title="Comment restaurer mes dossiers dans mon application Replit ?">
        Accédez à votre identité de profil située dans le coin supérieur droit de votre application Replit, sélectionnez **CLUI**, et dans la zone de recherche qui apparaît, recherchez en tapant *restore*. Dans les résultats de recherche, vous verrez une option **restore-folder** pour restaurer un dossier spécifique depuis la corbeille.

        > Remarque : Les applications Replit supprimées sont définitivement effacées et irrécupérables **30 jours** après leur date de suppression initiale.
      </Accordion>

      <Accordion title="Comment restaurer une application Replit supprimée ?">
        Accédez à votre identité de profil située dans le coin supérieur droit de votre application Replit, sélectionnez **CLUI**, et dans la zone de recherche qui apparaît, recherchez en tapant *restore*. Dans les résultats de recherche, vous verrez une option **restore-repl** pour restaurer une application Replit spécifique depuis la corbeille.

        > Remarque : Les applications Replit supprimées sont définitivement effacées et irrécupérables **30 jours** après leur date de suppression initiale.
      </Accordion>

      <Accordion title="Pourquoi mon application Replit ne charge-t-elle pas ?">
        Si votre application Replit ne se charge pas, essayez ces étapes de débogage :

        1. Testez votre [connexion internet](https://www.speedtest.net/).
        2. Essayez un autre navigateur.
        3. Vérifiez que JavaScript est activé dans votre navigateur.
        4. Utilisez la commande `kill 1` dans le shell pour arrêter et redémarrer la machine virtuelle Linux qui alimente votre application Replit.

        Si aucune des étapes ci-dessus n'a aidé, consultez le [statut du service](https://status.replit.com) de Replit. Si vous voyez le statut **All systems are go!** et que vous avez toujours des problèmes pour charger votre application Replit, veuillez contacter le [support Replit](https://replit.com/support).
      </Accordion>

      <Accordion title="Comment télécharger un fichier volumineux dans mon application Replit ?">
        Si le fichier est trop volumineux pour un téléchargement GUI standard, vous pouvez utiliser `scp` (Secure Copy) pour transférer en toute sécurité des fichiers entre systèmes locaux et distants via [SSH](/fr/references/workspace/ssh). Pour copier des fichiers depuis votre machine locale vers la machine distante, utilisez cette syntaxe : `scp filename username@ip_address:/home/username`

        Vous pouvez également copier des répertoires entiers avec scp.
      </Accordion>

      <Accordion title="Comment vérifier mon solde de crédits d'utilisation ?">
        Vous pouvez consulter votre solde actuel sur [https://replit.com/\~/cli/account/usage-credits-balance](https://replit.com/~/cli/account/usage-credits-balance).
      </Accordion>

    <AccordionGroup>
      <Accordion title="J'ai des difficultés à me connecter ; que dois-je faire ?">
        1. Assurez-vous d'utiliser le bon email et mot de passe.
        2. Pour réinitialiser votre mot de passe, accédez à la [page mot de passe oublié](https://replit.com/forgot). Vérifiez votre dossier spam pour l'email de réinitialisation provenant de `notifications@replit.com`.
        3. Essayez de vous connecter via un autre navigateur.

        Si toutes les étapes que vous avez essayées ne réussissent pas, veuillez [contacter le support](https://replit.com/support).
      </Accordion>

      <Accordion title="Comment changer mon email si je me suis inscrit avec Google/GitHub/Facebook/Apple ?">
        Nous exigeons un mot de passe pour changer l'email sur votre compte. Si vous vous êtes inscrit avec un fournisseur d'authentification tiers tel que Google ou GitHub, vous devrez d'abord créer un mot de passe.

        Pour créer un mot de passe :

        1. Ouvrez la barre latérale et déconnectez-vous.
        2. Retournez à la page de connexion, sélectionnez [mot de passe oublié](https://replit.com/forgot) et entrez votre adresse email.
        3. Vous recevrez un email avec un lien pour créer un nouveau mot de passe. Si vous ne voyez pas l'email, vérifiez votre dossier spam et attendez jusqu'à trente minutes pour la réception de l'email.
        4. Après vous être connecté, ouvrez [Paramètres](https://replit.com/settings) pour changer votre adresse email.
      </Accordion>

      <Accordion title="Comment changer mon nom d'utilisateur ?">
        Les utilisateurs Replit peuvent changer leur nom d'utilisateur une seule fois **seulement**. Accédez au [CLUI](https://replit.com/~/cli/account/change-username?run=1) et sélectionnez **change-username**. Si l'option n'est pas disponible, vous l'avez déjà utilisée.
      </Accordion>

      <Accordion title="Qu'est-ce que le mode Explorateur et comment l'activer ?">
        Les Explorateurs sont des utilisateurs Replit qui ont choisi de voir et tester de nouvelles fonctionnalités encore en développement. Pour activer le mode Explorateur, ouvrez [Paramètres](https://replit.com/settings) et activez le bouton Explorateur (par ex. sous **Compte** ou **Utilisateur**).
      </Accordion>
    </AccordionGroup>
