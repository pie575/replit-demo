export const YouTubeEmbed = ({videoId, title = "YouTube 视频", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

  ### Replit 移动 App
</div>

<YouTubeEmbed videoId="YSeDWL4cDLs" title="Replit 移动 App" />

只需一句简单的提示词，即可构建原生 iOS 应用。Agent 会创建完整的 React Native 应用，你可以随时添加数据库、Stripe 支付、OpenAI 集成等功能。用 Expo Go 扫码即可预览应用，并通过 Replit 的引导式流程提交到 App Store。Apple 会对应用进行审核，并通过 App Store 分发。

准备好构建你的第一个移动应用了吗？请从[原生移动 Apps](/zh/ja/features/artifact-types/building-mobile-apps) 入手，或跟随[构建并发布移动应用](/zh/tutorials/build-and-launch-a-mobile-app)教程操作。

<div id="agent-chatui">
  ### Agent chat 工具调用界面重新设计
</div>

Agent chat 的工具调用显示现已采用更简洁、更紧凑的界面。工具调用会折叠成带堆叠图标的分组行，让你一眼看清正在进行的操作。文件的编辑和创建会直接链接到 diff 面板，便于查看。这一精简设计减少了干扰，让你更清晰地跟踪 Agent 的执行过程。
