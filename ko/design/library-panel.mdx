라이브러리 패널은 Replit Design에 내장된 시작점과 참고 자료의 원천입니다. 여기에는 **Templates**, **Inspiration**, **Library** 세 개의 탭이 있습니다. 이 안의 어떤 것도 새 프로젝트를 만들지 않으며, 모든 것은 현재 작업 중인 프로젝트의 캔버스에 추가됩니다.

## Templates

Replit이 만든 미리 제작된 디자인 프레임으로, 검색 가능하며 종류별로 정리되어 있습니다: 포스터, 소셜 게시물, 랜딩 페이지, 모바일, 배너, 프로토타입. 하나를 클릭하거나 드래그하면 디자인에 추가되며, 캔버스에 직접 생성한 것과 마찬가지로 바로 편집 가능한 살아있는 프레임으로 도착합니다.

## Inspiration

Mobbin이 엄선한 실제 제품의 UI 스크린샷입니다. \*"Airbnb onboarding"\*이나 \*"Coinbase checkout"\*처럼 앱 화면을 검색하고, 하나를 클릭하면 캔버스에 정적 참고 이미지로 배치됩니다. Inspiration은 프로젝트에 어떤 코드도 추가하지 않습니다: 그저 보고, 채팅에서 가리키거나, 다음 생성 시 참고할 대상일 뿐입니다.

## Library

이 프로젝트에서 이미 만든 디자인과 아티팩트 등 여러분이 직접 만든 것들로, 언제든 캔버스로 다시 가져올 수 있습니다.

## Templates vs. Inspiration

|         | Templates              | Inspiration               |
| ------- | ---------------------- | ------------------------- |
| 이것의 정체  | Replit이 만든 시작용 디자인 프레임 | Mobbin을 통한 실제 제품의 UI 스크린샷 |
| 캔버스에서는  | 디자인 안의 살아있는 편집 가능한 프레임 | 정적 참고 이미지                 |
| 이럴 때 사용 | 동작하는 디자인에서 시작할 때       | 다음 생성물의 방향을 잡을 때          |

가이드에 따른 사용 흐름은 [디자인에 템플릿과 영감 추가하기](/ko/design/add-templates-and-inspiration)를 참고하세요.
