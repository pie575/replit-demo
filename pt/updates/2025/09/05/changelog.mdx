## Plataforma

### Agent Geral

<Frame>
  <img src="/assets/mirror/general-agent-240ff289e711.png" alt="Ilustração de destaque do Agent Geral" width="1040" height="572" data-path="images/replitai/general-agent.png" />
</Frame>

O Replit Agent agora funciona em qualquer codebase em qualquer linguagem ou framework que execute no NixOS! Anteriormente limitado a templates específicos, o Agent agora pode auxiliar com Frameworks de Desenvolvedor, importações do GitHub e qualquer configuração de projeto personalizada. Essa expansão poderosa traz assistência completa de codificação com IA para fluxos de trabalho corporativos e de usuários avançados.

Leia mais sobre o Agent Geral [aqui](/pt/core-concepts/agent/general-agent).

### Modo de Plano

<Frame>
  <img src="/assets/mirror/plan-mode-overview-8077807c63b9.png" alt="Interface de chat do Agent no modo de Plano" width="916" height="362" data-path="images/replitai/plan-mode-overview.png" />
</Frame>

O modo de Plano introduz uma nova forma de conversar com o Replit Agent que se concentra em fazer perguntas, brainstorming e planejamento do seu trabalho. Com o modo de Plano, você pode usar o Agent para criar uma lista de tarefas para trabalhos futuros e, em seguida, executar tarefas de longa duração no modo de criação.

Leia mais sobre o modo de Plano [aqui](/pt/core-concepts/agent/plan-mode).

## Enterprise

### Integração com o GCP Marketplace

Os clientes corporativos agora podem adquirir o Replit diretamente pelo Google Cloud Platform Marketplace e usar seus créditos GCP existentes para pagamento. Isso simplifica os processos de aquisição e facilita que organizações com orçamentos GCP adotem o Replit em seus fluxos de trabalho de desenvolvimento.
