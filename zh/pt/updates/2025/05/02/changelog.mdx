<div id="replit-auth">
  ### Replit Auth
</div>

[Replit Auth](/zh/pt/core-concepts/project-editor/auth-and-security/authentication) 现已面向所有用户开放！这是一套内置的身份验证系统，只需极少的配置即可为你的应用添加用户登录功能。无需从零搭建复杂的身份验证系统，Replit Auth 依托 Replit 基础设施，提供安全、开箱即用的解决方案。

**主要功能：**

* **零配置** —— 在 Agent 中用一句 prompt 即可添加身份验证
* **内置安全防护** —— 基于 Replit 基础设施，可抵御常见攻击
* **用户管理** —— 通过 Auth 面板轻松管理用户
* **数据库集成** —— 自动在你的数据库中创建用户条目
* **可定制的登录页面** —— 为你的应用打造专属登录体验
* **密码重置** —— 由 Replit 负责发送密码重置邮件，无需自行配置邮件投递服务商

上手非常简单——在你的 Agent prompt 中提出 Replit Auth 的需求即可：

<AiPrompt>
  帮我创建一个应用，功能是 [你的应用想法]，并且需要包含 Replit Auth。
</AiPrompt>
