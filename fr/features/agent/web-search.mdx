Créez des applications s&#39;appuyant sur des données actuelles et concrètes grâce aux fonctionnalités Recherche web <img class="icon-svg" src="/assets/mirror/web-search-1fe8f63b5b88.svg" alt="Icône Recherche web" width="16" height="16" data-path="images/icons/web-search.svg" /> d&#39;Agent.

Cette fonctionnalité s&#39;affranchit des limites de connaissances des modèles en accédant aux informations les plus récentes disponibles sur le web. Lorsque vous demandez à Agent de créer quelque chose qui nécessite des informations à jour, il lance une recherche sur le web et en extrait du contenu détaillé afin de rendre votre application plus précise et plus utile.

La recherche web est particulièrement utile pour trouver les paquets, outils et informations les plus récents. Vos apps s&#39;appuient ainsi sur les bonnes pratiques actuelles et gagnent en précision.

<div id="features">
  ## Fonctionnalités
</div>

Créez des applications s&#39;appuyant sur des informations à jour grâce à la recherche web d&#39;Agent. Fini les recherches et la collecte de données manuelles. Que vous conceviez un tableau de bord de données financières ou un site web présentant les derniers lancements de startups, la recherche web garantit que votre application reflète la réalité.

Agent peut effectuer les actions de recherche web suivantes :

* **Recherche** : trouver des informations à jour, la documentation la plus récente et des données en temps réel sur Internet
* **Récupération de contenu** : extraire des informations détaillées de sites web et d&#39;URL spécifiques
* **Citation des sources** : voir exactement où Agent a trouvé les informations, afin de pouvoir vérifier et citer les sources

<div id="usage">
  ## Utilisation
</div>

La recherche web est intégrée à Agent : il n&#39;y a rien à activer. Décrivez ce que vous souhaitez créer et Agent détermine automatiquement quand chercher des informations à jour sur le web. Ajoutez des mots-clés comme « rechercher », « faire des recherches » ou « utilise la recherche web » dans votre prompt pour l&#39;inciter à lancer explicitement une recherche.

| Avantage                    | Description                                                                                                         |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| Technologies à jour         | Vos applications utilisent les informations et les paquets les plus récents, absents des données d&#39;entraînement |

| Bonnes pratiques actuelles  | Accès aux modèles de développement et aux pratiques de sécurité les plus récents                                    |

| Données exactes             | Vos applications affichent des informations actuelles plutôt que des exemples obsolètes                             |
| Résultats professionnels    | Les applications qui citent de vraies entreprises inspirent confiance                                               |
| Gain de temps               | Évitez de rechercher manuellement des paquets et de collecter des données                                           |

<div id="source-citations">
  ### Citations des sources
</div>

Lorsqu&#39;Agent utilise la recherche web, il fournit des **citations des sources** qui indiquent précisément d&#39;où provient l&#39;information. Utilisez ces citations pour :

* **Vérifier l&#39;information** : contrôlez la fiabilité et l&#39;exactitude des sources
* **En savoir plus** : consultez les sources d&#39;origine pour obtenir plus de contexte
* **Référencer les sources** : indiquez une attribution correcte dans vos applications
* **Suivre les recherches** : comprenez quelles informations ont guidé le travail d&#39;Agent

<div id="content-fetching">
  ### Récupération de contenu
</div>

Agent peut récupérer le contenu détaillé de sites web précis afin de rassembler des informations complètes pour votre projet. Cela lui permet de :

* Lire des pages web entières pour en extraire les détails pertinents
* Traiter de la documentation et des supports de référence
* Recueillir des données précises auprès de sources fiables
* Intégrer des informations structurées à votre application
