<div id="section">
  ## Qu&#39;est-ce qu&#39;un artefact ?
</div>

Un artefact est un élément publiable sur Replit : application web, application mobile, présentation, animation, application de données, jeu 3D, design, etc. Chacun constitue un résultat complet et autonome, doté d&#39;une URL dédiée et partageable dès sa publication.

Tous les autres éléments de votre projet (fichiers, images, CSV, code) viennent en support des artefacts, mais ne peuvent pas être publiés seuls.

<ArtifactGrid />

| Type                                                                         | Description                                                                                           |
| ---------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| **[Applications web](/fr/ja/features/artifact-types/web-apps)**                 | Des sites web élégants et puissants, capables de gérer les utilisateurs, les bases de données, etc.   |
| **[Applications mobiles](/fr/ja/features/artifact-types/building-mobile-apps)** | Des applications natives pour iPhone et smartphones Android.                                          |
| **[Présentations](/fr/ja/features/artifact-types/slide-decks)**                 | Des présentations que vous pouvez projeter ou exporter.                                               |

Pour connaître la disponibilité selon les forfaits, consultez la page dédiée à chaque type.

<div id="section-3">
  ## Prise en main
</div>

Il existe deux façons de créer depuis la page d&#39;accueil de Replit :

* **Décrivez** : saisissez ce que vous souhaitez — « Crée une application de recettes » ou « Crée un pitch deck pour ma startup ». Agent détermine le type le plus adapté et le construit.
* **Choisissez un type** : sélectionnez l&#39;artefact souhaité (application web, application mobile, visualisation de données, animation, jeu 3D ou tout autre type pris en charge) avant de décrire votre idée.

Vous pouvez aussi enrichir un projet existant à tout moment : demandez-le à Agent dans le chat ou cliquez sur le bouton **+** du panneau d&#39;aperçu.

<div id="section-4">
  ## Basculer entre les artefacts
</div>

Si votre projet comporte plusieurs artefacts, passez de l&#39;un à l&#39;autre depuis le **panneau d&#39;aperçu** ou la **barre latérale Bibliothèque**. Vous pouvez aussi le demander à Agent : « Montre-moi l&#39;application mobile » ou « Passe aux diapositives ».

<div id="section-5">
  ### Barre latérale Bibliothèque
</div>

La barre latérale Bibliothèque offre un emplacement central pour parcourir tout le contenu de votre projet. Elle affiche les artefacts, les images générées ou téléchargées par Agent, ainsi que les autres ressources du projet. Ouvrez-la depuis le panneau de gauche pour retrouver et réutiliser les ressources de l&#39;ensemble du projet.

<div id="section-6">
  ## Plusieurs artefacts dans un même projet
</div>

Un projet peut contenir jusqu&#39;à **7 artefacts**, dont **une seule application mobile**. Vous pouvez par exemple créer une application web destinée à vos clients, une application mobile pour votre équipe et une présentation pour vos investisseurs, le tout au sein d&#39;un même projet.

<ArtifactGrid />

<div id="section-7">
  ### Ajouter un artefact à un projet
</div>

Il existe trois façons d&#39;ajouter un artefact à un projet existant :

* **Chat** : demandez à Agent — « Ajoute une application mobile à ce projet » ou « Crée une présentation pour les investisseurs »
* **Bouton plus** : cliquez sur le bouton **+** du panneau d&#39;aperçu, puis choisissez ce que vous souhaitez créer
* **Barre latérale Bibliothèque** : parcourez les artefacts, images et autres ressources existants, et ajoutez-y de nouveaux artefacts

<div id="section-8">
  ### Données et backend partagés
</div>

Les artefacts d&#39;un même projet partagent automatiquement les mêmes données et la même logique backend. Lorsqu&#39;un client passe une commande depuis l&#39;application web, l&#39;application mobile et le tableau de bord de données voient cette commande instantanément. Aucune connexion à configurer, aucun code à dupliquer — tout fonctionne d&#39;emblée.

<Note>
  Lors de la publication, l&#39;ensemble du projet est déployé en une seule fois. Tous les artefacts sont publiés simultanément : ils restent donc toujours synchronisés.
</Note>

<div id="section-9">
  ### Exemples de combinaisons
</div>

* **Application web + application mobile** : un restaurant avec une application web pour ses clients et une application mobile pour son personnel — les deux se connectent à la même API et à la même base de données
* **Application + tableau de bord d&#39;administration** : le produit principal accompagné d&#39;un panneau d&#39;administration interne pour gérer le contenu, les utilisateurs et les paramètres
* **Application + présentation** : le produit et la présentation dans le même projet, pour que les diapositives reflètent toujours la version la plus récente
* **Tableau de bord de données + vidéo** : une visualisation de données en direct associée à une vidéo animée qui en explique les points clés

<div id="section-10">
  ## Publication
</div>

Les applications, les diaporamas et les vidéos peuvent tous être publiés et partagés. Une fois déployés, chacun dispose de sa propre URL partageable.

Les fichiers et ressources qui ne sont pas des artefacts (fichiers CSV, images, fichiers Markdown, etc.) ne peuvent pas être publiés seuls. Pour les partager, ajoutez-les à une application ou créez un nouvel artefact.

<div id="section-11">
  ## Questions fréquentes
</div>

<Accordion title="Puis-je avoir plusieurs artefacts dans un projet ?">
  Oui. Un projet peut contenir jusqu’à **7 artefacts**, avec **une seule application mobile par projet**. Tous les artefacts d’un projet partagent automatiquement le même back-end et les mêmes données.

  Si vous avez atteint la limite d’applications mobiles et souhaitez en créer une deuxième, créez-la dans un nouveau projet. Si vous avez atteint la limite totale de 7 artefacts, supprimez un artefact existant ou scindez le projet avant d’en ajouter un autre.
</Accordion>

<Accordion title="Dois-je choisir un type avant de commencer ?">
  Non. Décrivez simplement ce que vous souhaitez, et Agent sélectionnera le type approprié. Si vous le souhaitez, vous pouvez également sélectionner manuellement un type dans le menu déroulant.
</Accordion>

<Accordion title="Puis-je publier un seul artefact d’un projet ?">
  Ce n’est pas possible actuellement. Lorsque vous publiez, l’ensemble du projet est déployé afin que tous les artefacts restent synchronisés. Si vous avez besoin de déploiements indépendants, utilisez des projets distincts.
</Accordion>

<Accordion title="Les artefacts partagent-ils les données ?">
  Oui. Tous les artefacts d’un projet partagent la même base de données et les mêmes services back-end. Lorsqu’une application Web écrit des données, l’application mobile et le tableau de bord de données peuvent les lire immédiatement.
</Accordion>

<Accordion title="Quelle est la différence entre un artefact et un fichier ?">
  Un artefact est un élément pouvant être publié — une application, des diapositives ou une vidéo. Les fichiers (CSV, images, code, etc.) sont des ressources du projet qui prennent en charge les artefacts, mais ne peuvent pas être publiés seuls.
</Accordion>

<Accordion title="Il manque des fonctionnalités de mon application Web dans l’application mobile. Que s’est-il passé ?">
  Lorsque Agent convertit des fonctionnalités entre différents types d’artefacts, certains éléments peuvent ne pas être entièrement conservés — en particulier les interactions et les mises en page qui diffèrent selon les plateformes. Vous pouvez poursuivre la conversation dans le chat pour ajouter les éléments manquants.
</Accordion>

Pour consulter la liste complète de ce que vous pouvez créer, consultez l’[aperçu des projets](/fr/ja/features/projects-and-artifacts/projects).
