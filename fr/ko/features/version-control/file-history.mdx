---
title: "Historique des fichiers"
description: "Découvrez comment restaurer des versions précédentes de votre code grâce aux points de sauvegarde automatiques de File History."
---

Dans le Project Editor, ouvrez un fichier texte, puis cliquez sur le bouton **History** en bas à droite pour commencer.

<Frame>
  <img src="/assets/mirror/history-button-afac6496660a.png" alt="Ouvrir l'historique" width="377" height="292" data-path="images/programming-ide/history-button.png" />
</Frame>

<div id="section">
  ## Consulter les versions précédentes d&#39;un fichier
</div>

Une fois File History ouvert, vous pouvez consulter les versions précédentes d&#39;un fichier à l&#39;aide de la barre de défilement, des boutons fléchés ou des touches fléchées **gauche** et **droite**.

<Frame>
  <img src="/assets/mirror/history-versioning-1a055ecab411.gif" alt="Démonstration de la barre de défilement" width="764" height="720" data-path="images/animations/history-versioning.gif" />
</Frame>

<div id="section-2">
  ## Comparer une version précédente avec le fichier actuel
</div>

Dans la fenêtre File History, activez le bouton Compare Latest en bas à gauche pour comparer en ligne le fichier tel qu&#39;il était à ce moment-là avec sa version la plus récente.

<Frame>
  <img src="/assets/mirror/compare-history-46fb16debd3a.gif" alt="Image comparant avec la dernière version" width="772" height="720" data-path="images/animations/compare-history.gif" />
</Frame>

<div id="section-3">
  ## Restaurer une version précédente d&#39;un fichier
</div>

Pour restaurer une version précédente d&#39;un fichier, cliquez sur le bouton `Restore`. Pas d&#39;inquiétude : l&#39;historique n&#39;est pas effacé. La version restaurée est ajoutée à l&#39;historique du fichier en tant que nouvelle version.

<Frame>
  <img src="/assets/mirror/restore-history-5f616d7f961a.webp" alt="Image de restauration de l'historique" width="720" height="495" data-path="images/animations/restore-history.webp" />
</Frame>

<div id="file-history">
  ## Visualiser la relecture de File History
</div>

La fonctionnalité de relecture de File History permet de voir l&#39;évolution d&#39;un fichier au fil du temps, comme dans un film. C&#39;est pratique pour créer une vidéo de vos sessions de programmation.
