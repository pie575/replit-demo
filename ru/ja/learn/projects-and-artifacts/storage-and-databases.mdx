Гибкие решения Replit для хранения данных позволяют быстро добавить в App именно то хранилище, которое ему нужно. Базы данных и объектное хранилище Replit подойдут для App со следующими требованиями, причём Agent может настроить и интегрировать оба решения автоматически:

* Игры, которым нужно сохранять данные — например, прогресс игроков или рекорды
* Контент-платформы, работающие с медиафайлами

<div id="replit">
  ## Варианты хранилищ и баз данных в Replit
</div>

Replit предлагает следующие варианты хранения данных:

* **Базы данных**: хранение структурированных данных — профилей пользователей, игровых результатов, каталогов товаров.
  Позволяют сохранять и получать данные по атрибутам и связям между записями.

* **App Storage**: хранение неструктурированных данных — изображений, видео и документов.
  Позволяет сохранять и получать крупные файлы и двоичные данные.

<div id="app-storage">
  ### Сравнение App Storage и базы данных
</div>

|                               | База данных                                                                         | App Storage                                                                             |
| ----------------------------- | :---------------------------------------------------------------------------------- | :-------------------------------------------------------------------------------------- |
| **Оптимальный формат данных** | Структурированные данные со связями                                                 | Крупные файлы (изображения, видео, документы)                                           |
| **Модель данных**             | Таблицы, строки, столбцы                                                            | Бакеты, файлы                                                                           |
| **Язык запросов**             | SQL                                                                                 | REST API                                                                                |
| **Клиенты**                   | PostgreSQL-совместимые клиенты и ORM                                                | Replit SDK и клиентские библиотеки GCS                                                  |
| **Модель оплаты**             | Оплата по мере использования в зависимости от времени вычислений и объёма хранилища | Оплата по мере использования в зависимости от пропускной способности и объёма хранилища |

<div id="section">
  ### Инструменты редактора проекта
</div>

Подробнее познакомьтесь со следующими инструментами Replit для настройки хранения данных вашего App и управления им:

<CardGroup>
  <Card title="База данных" href="/ru/ja/features/data-and-storage/sql-database" icon="database">
    Идеально подходит для структурированных данных и описания связей между ними.
    В основе лежит полностью управляемая база данных PostgreSQL, которая масштабируется вместе с вашим App.
  </Card>

  <Card title="App Storage" href="/ru/ja/features/data-and-storage/object-storage" icon="bucket">
    Идеально подходит для неструктурированных данных и больших файлов: изображений, видео, документов.
    Работает на базе Google Cloud Storage (GCS), обеспечивая высокую доступность и масштабируемость. Agent может автоматически настроить App Storage с продвинутой аутентификацией и контролем доступа.
  </Card>
</CardGroup>
