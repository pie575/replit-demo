Пока Agent работает, последующее сообщение может изменить то, чем Agent занят прямо сейчас, — то есть активный
**ход (turn)**, — либо дождаться завершения этого хода:

* **Steer (корректировка)** отправляет сообщение в активный ход. Agent продолжает работу с учётом нового контекста.
* **Queue (очередь)** сохраняет сообщение для следующего хода. Agent приступит к нему после завершения активного хода.

<div id="section">
  ## Корректировка беседы
</div>

Steer — это стандартное поведение при отправке последующих сообщений в Conversation и Project.
Обе настройки можно переключить на Queue.

<div id="replit">
  ## Выбор способа отправки последующих сообщений в Replit
</div>

Для Conversation и Project можно задать разное поведение отправки:

1. Откройте **Settings** &gt; **Personalization**.
2. Разверните **Agent**.
3. Задайте для **Conversation send behavior** и **Project send behavior** значение **Steer** или **Queue**.

<Frame caption="Настройки поведения отправки для Conversation и Project в разделе Agent.">
  <img src="/assets/mirror/agent-follow-ups-settings-98a4c5ca399e.png" alt="Настройки Agent с поведением отправки для Conversation и Project и вариантами Steer и Queue" width="3048" height="1372" data-path="images/replitai/agent-follow-ups-settings.png" />
</Frame>

<Info>
  В режиме Design последующие сообщения всегда корректируют ход работы. Настройки поведения отправки
  для Conversation и Project на режим Design не влияют.
</Info>

Чтобы отправить одно сообщение с поведением, противоположным вашей настройке, нажмите
`Cmd+Enter` (Mac) или `Ctrl+Enter` (Windows и Linux).

<div id="section-2">
  ## Работа с сообщениями в очереди
</div>

Когда вы добавляете следующее сообщение в очередь, Message Queue появляется
в виде выдвижной панели над полем ввода чата. Agent обрабатывает сообщения из
очереди по порядку после завершения активного хода. Как только Agent обработает
все сообщения в очереди, панель закроется.

В Queue доступны все параметры сообщения, включая
[Visual Editor](/ru/ko/design/visual-editor) и вложение файлов.

<Info>
  Agent автоматически обрабатывает сообщения из очереди только при активном
  подключённом сеансе Project Editor на компьютере или мобильном устройстве.
</Info>

<div id="section-3">
  ### Управление очередью
</div>

Когда выдвижная панель очереди открыта, вы можете выполнить следующие действия:

* **Steer now (Направить сейчас)**: перевести сообщение из очереди в активный ход.
* **Edit messages (Изменить сообщения)**: изменить сообщения в очереди до того, как Agent их обработает.
* **Delete messages (Удалить сообщения)**: удалить сообщения, которые больше не нужны.
* **Reorder messages (Изменить порядок сообщений)**: перетащить сообщения, чтобы изменить порядок их обработки.
* **Add messages (Добавить сообщения)**: отправить в очередь последующие сообщения.

<div id="section-4">
  ## Остановка активного хода
</div>

Нажмите **Stop** в строке состояния, чтобы прервать задачу, которую Replit выполняет в текущем ходе. После этого можно отправить новое сообщение, не дожидаясь, пока Agent завершит ход или обработает сообщения из очереди.
