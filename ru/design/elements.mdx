**Элемент** — это отдельная часть фрейма: заголовок, кнопка, изображение, поле формы или любой другой компонент, отображаемый во фрейме. Элементы позволяют изменить отдельную часть фрейма без повторной генерации всего фрейма.

<div id="selecting-an-element">
  ## Выбор элемента
</div>

Выберите [инструмент Edit](/ru/design/toolbar#edit) на панели инструментов. Когда Edit активен, щёлкните внутри активного фрейма, чтобы выбрать элемент под курсором. Выбранный элемент будет обведён, а рядом с ним появится небольшое встроенное поле промпта, где можно попросить Agent изменить его.

<Note>
  Edit недоступен, пока на Canvas не появится хотя бы один фрейм, и работает только на компьютере.
</Note>

<div id="acting-on-a-selected-element">
  ## Работа с выбранным элементом
</div>

<div id="ask-agent-to-change-it">
  ### Попросите Agent внести изменения
</div>

С помощью встроенного промпта попросите Agent изменить текст, цвет, раскладку, отступы или поведение элемента.

<div id="swap-an-image-directly">
  ### Замените изображение напрямую
</div>

Выберите элемент изображения — в разделе **Image** в Visual Editor отобразятся путь к исходному файлу и кнопка **Upload Image**, позволяющая заменить файл без промпта.

<div id="visual-editor">
  ## Visual Editor
</div>

При выборе элемента открывается **Visual Editor** — правая панель со встроенным промптом. Все элементы управления в ней сгруппированы по понятным разделам, чтобы вы быстрее находили нужные: **Text**, **раскладка**, **Color** и **Border**. (При выборе изображения также появляется раздел **Image**.)

<div id="layout">
  ### Раскладка
</div>

В разделе **раскладки** можно настроить расположение дочерних элементов внутри контейнера без помощи Agent. Выберите flex-контейнер, разверните раскладку — и вам станут доступны следующие настройки:

* **Выравнивание**: селектор из 3×3 точек для выбора расположения элементов по обеим осям внутри контейнера.
* **Направление**: две кнопки со стрелками для размещения дочерних элементов в строку или столбец.
* **Промежуток**: значение в пикселях для расстояния между элементами. Иконка рядом с полем ввода Gap меняется в соответствии с текущим направлением, поэтому вы всегда видите, настраиваете ли горизонтальный или вертикальный отступ. Рядом расположена иконка со стрелкой, которая включает **Распределить пространство между элементами** и размещает дочерние элементы у противоположных краёв контейнера.
* **Внешний отступ**: отдельные поля для пространства снаружи элемента — по одному для каждой стороны — и переключатель связи, позволяющий одновременно связать все четыре стороны.
* **Внутренний отступ**: поля для настройки пространства внутри элемента по каждой оси и переключатель связи для обеих осей одновременно.

Раздел раскладки отображается, только если к выбранному элементу применима хотя бы одна настройка раскладки. Для обычных текстовых узлов без свойств отступов или раскладки этот раздел полностью скрыт, поэтому редактор остаётся компактным.

О разделах **Text**, **Color**, **Border** и **Image** см. в [руководстве по Visual Editor](/ru/design/visual-editor).
