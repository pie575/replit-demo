CLUI (Interface de ligne de commande graphique) est la barre de commandes interactive de Replit qui vous permet d'effectuer diverses actions rapidement sans naviguer dans les menus. Elle combine l'efficacité d'une ligne de commande avec une interface graphique.

## Fonctionnalités

CLUI propose des interactions pilotées par commandes dans trois contextes différents de Replit :

* **Gestion des paramètres** : Gérez vos paramètres, consultez les avertissements et restaurez les Applications Replit supprimées
* **Navigation rapide** : Passez d'une Application Replit à l'autre et accédez aux fonctionnalités courantes via des raccourcis
* **Opérations dans l'espace de travail** : Recherchez des fichiers, effectuez des recherches dans le code et accédez aux outils dans votre environnement de développement

## Utilisation

### CLUI de compte

La CLUI de compte vous aide à gérer vos paramètres, vos équipes et vos Applications Replit supprimées.

**Comment y accéder** : Accédez à la [page CLUI](https://replit.com/~/cli), saisissez du texte dans le champ de saisie pour rechercher une commande, puis appuyez sur Entrée pour l'exécuter.

<Accordion title="Commandes de compte">
  Saisissez `account` pour gérer vos paramètres :

  * **view-warns** : Consultez les avertissements qui vous ont été émis
  * **change-username** : Modifiez votre nom d'utilisateur (peut seulement être fait une fois)
</Accordion>

<Accordion title="Commandes de corbeille">
  Saisissez `trash` pour gérer les Applications Replit supprimées :

  * **restore \<title>** : Restaurez une Application Replit supprimée par son titre (restaure la plus récemment supprimée s'il en existe plusieurs avec le même nom)
  * **view** : Consultez vos Applications Replit supprimées les plus récentes
</Accordion>

<Accordion title="Commandes d'équipe">
  Saisissez `team` pour gérer vos équipes :

  * **view** : Consultez les membres d'une équipe dont vous faites partie par son nom d'utilisateur
  * **fork-repl-to-project** : Dupliquez une Application Replit existante pour créer un Projet d'équipe
</Accordion>

<Accordion title="Commande effacer">
  Saisissez `clear` pour effacer l'écran de toutes les commandes précédemment exécutées
</Accordion>

### CLUI des raccourcis

La CLUI des raccourcis offre un accès rapide aux fonctionnalités courantes de Replit depuis n'importe quelle page.

<Frame>
  <img src="/assets/mirror/shortcuts-clui-768d49b44785.png" alt="CLUI des raccourcis" width="689" height="291" data-path="images/getting-started/shortcuts-clui.png" />
</Frame>

**Comment y accéder** : Appuyez sur **CMD/CTRL + K** ou cliquez sur l'icône de recherche dans la barre de navigation supérieure sur la plupart des pages Replit.

<Accordion title="Commandes disponibles">
  * **Rechercher** : Recherchez dans Replit des Applications Replit, des modèles, du code, des personnes, et plus encore
  * **Nouveau** : Créez une nouvelle Application Replit
  * **Mes Applications Replit** : Parcourez et accédez à vos Applications Replit
  * **Mon code** : Recherchez dans le code de toutes vos Applications Replit
</Accordion>

### CLUI de l'espace de travail

La CLUI de l'espace de travail vous aide à effectuer des opérations, à accéder aux outils, à trouver des fichiers et à rechercher dans votre code lorsque vous travaillez dans une Application Replit.

<Frame>
  <img src="/assets/mirror/ws-clui-81764b3d111b.png" alt="CLUI de l'espace de travail" width="429" height="202" data-path="images/getting-started/ws-clui.png" />
</Frame>

**Comment y accéder** : Appuyez sur **CMD/CTRL + K** ou cliquez sur l'icône de recherche dans le coin supérieur gauche de l'Espace de travail.

<Accordion title="Opérations courantes">
  * **Rechercher des fichiers** : Localisez rapidement des fichiers dans votre projet
  * **Rechercher dans le code** : Trouvez des extraits de code spécifiques dans vos fichiers
  * **Accéder aux outils** : Ouvrez n'importe quel outil ou panneau disponible dans l'Espace de travail
  * **Exécuter des commandes** : Exécutez des commandes spécifiques à l'espace de travail
</Accordion>
