**Элемент** — это отдельная часть фрейма: например, заголовок, кнопка, изображение, поле формы или любой другой компонент, который отображается во фрейме. Выбирайте элементы, когда нужно изменить часть фрейма без повторной генерации всего содержимого.

<div id="selecionando-um-elemento">
  ## Выбор элемента
</div>

Выберите на панели инструментов [инструмент Edit](/ru/pt/design/toolbar#edit). Когда Edit активен, щелкните элемент внутри активного фрейма, чтобы выбрать его. Выбранный элемент выделяется контуром и небольшим встроенным промптом, с помощью которого можно попросить Agent изменить его.

<Note>
  Edit недоступен, пока на Canvas нет хотя бы одного фрейма, и работает только на компьютере.
</Note>

<div id="agindo-sobre-um-elemento-selecionado">
  ## Работа с выбранным элементом
</div>

<div id="pea-ao-agent-para-alter-lo">
  ### Попросите Agent изменить его
</div>

С помощью встроенного промпта попросите Agent изменить текст, цвет, раскладку, интервалы или поведение элемента.

</Frame>

<div id="trocar-uma-imagem-diretamente">
  ### Замените изображение напрямую
</div>

Выберите элемент изображения. В разделе **изображение** Visual Editor отображаются путь к исходному файлу и кнопка **Upload Image**, позволяющая заменить файл без промпта.

<div id="visual-editor">
  ## Visual Editor
</div>

При выборе элемента открывается **Visual Editor** — панель справа, связанная со встроенным промптом. Элементы управления сгруппированы в понятные разделы, чтобы вы быстрее находили нужное: **Text**, **раскладка**, **Color** и **Border**. (Раздел **Изображение** также появляется при выборе изображения.)

<div id="layout">
  ### Раскладка
</div>

В разделе **Раскладка** можно настроить расположение дочерних элементов внутри контейнера, не прибегая к Agent. Выберите flex-контейнер, разверните раздел «Раскладка» — и увидите:

* **Выравнивание**: селектор из 9 точек (3×3), задающий положение элементов по обеим осям внутри контейнера.
* **Направление**: две кнопки со стрелками для размещения дочерних элементов в строку или столбец.
* **Интервал (Gap)**: значение в пикселях для расстояния между элементами. Значок рядом с полем Gap меняется в соответствии с текущим направлением, поэтому вы всегда знаете, настраиваете ли горизонтальный или вертикальный интервал. Рядом значок со стрелкой переключает **Distribute space between items**, размещая дочерние элементы у противоположных краёв контейнера.
* **Внешний отступ**: поля для каждой стороны, задающие пространство снаружи элемента (по одному полю на сторону, с переключателем связи для одновременного изменения всех четырёх сторон).
* **Внутренний отступ**: поля для настройки пространства внутри элемента по каждой оси, с переключателем связи для обеих осей одновременно.

Раздел «Раскладка» отображается, только если к выбранному элементу применим хотя бы один параметр раскладки. Простые текстовые узлы без свойств интервалов или раскладки полностью скрывают этот раздел, чтобы редактор оставался компактным.

Сведения о разделах **Text**, **Color**, **Border** и **Image** см. в [руководстве по Visual Editor](/ru/pt/design/visual-editor).
