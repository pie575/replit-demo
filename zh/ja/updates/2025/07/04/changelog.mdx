<div id="agentweb-search">
  ### Agent 的网页搜索
</div>

<Frame>
  <img src="/assets/mirror/web-search-6c28195531d4.jpg" alt="显示用于应用开发的网页搜索结果及来源引用的 Agent 界面" width="1920" height="1080" data-path="images/replitai/web-search.jpg" />
</Frame>

Agent 现在可以搜索网络，并通过[网页搜索](/zh/core-concepts/agent/web-search)获取最新信息。借助最新文档、当前市场数据和来自整个互联网的准确信息构建应用。不再受知识截止时间限制——你的应用可以使用当前可获取的最新信息。

<div id="agent">
  ### Agent 自定义指令
</div>

<Frame>
  <img src="/assets/mirror/replitmd-65360844a148.jpg" alt="显示项目自定义选项的 replit.md 文件" width="1920" height="1080" data-path="images/replitai/replitmd.jpg" />
</Frame>

使用 [replit.md](/zh/core-concepts/agent/replit-dot-md) 个性化定制 Agent 体验。通过这个特殊文件，你可以定义代码风格、项目设置和上下文。Agent 会根据成熟的最佳实践自动创建此文件，你也可以按自己的工作流程进行自定义。

<div id="section-3">
  ### 按工作量计费
</div>

<Frame>
  <img src="/assets/mirror/effort-based-billing-d971548c7c39.png" alt="显示按 Agent 工作量动态定价的计费界面" width="2048" height="1424" data-path="images/changelog/2025-07-04/effort-based-billing.png" />
</Frame>

使用全新的[按工作量计费](/zh/ja/billing/ai-billing)，体验更智能的检查点定价。系统会根据 Agent 的实际工作量动态定价，因此每次运行只会创建一个检查点，而不是多个检查点。

<div id="teamsapp-store">
  ### Teams 的 App Store 体验
</div>

以全新方式发现和管理团队 App。通过 Deployments 页面新增的组织级“App Store”体验，你可以为收藏的 App 添加星标、搜索所有部署、查看最近打开的 App，并根据流量发现热门部署。
