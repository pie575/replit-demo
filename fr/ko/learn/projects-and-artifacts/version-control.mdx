Le contrôle de version de Replit vous permet de suivre, gérer et partager votre base de code en toute confiance grâce à l&#39;intégration Git intégrée et à la connexion à GitHub :

* Suivre les modifications apportées au code et conserver l&#39;historique de votre travail de développement
* Collaborer avec votre équipe sans conflits de code ni perte de travail
* Importer, modifier et envoyer du code entre Replit et GitHub
* Tester de nouvelles fonctionnalités en toute sécurité à l&#39;aide de branches

<div id="section">
  ## Qu’est-ce que le contrôle de version ?
</div>

Le contrôle de version est un système qui enregistre les modifications apportées aux fichiers au fil du temps, afin de pouvoir restaurer ultérieurement une version donnée. Sur Replit, le contrôle de version repose sur Git, l’outil standard du secteur pour suivre les modifications du code, et propose une interface visuelle intuitive utilisable sans connaître la ligne de commande.

<div id="replit">
  ### Fonctionnement de la gestion des versions dans Replit
</div>

Les quatre options de gestion des versions reposent toutes sur le même dépôt Git sous-jacent :

1. Les **checkpoints Agent** créent automatiquement des commits aux étapes importantes lorsque vous développez avec [Replit Agent](/fr/ko/features/agent/overview). [En savoir plus sur les checkpoints et la restauration](/fr/ko/features/version-control/checkpoints-and-rollbacks).
2. Le **panneau Git** offre un accès visuel à l’ensemble du dépôt Git.
3. L’**interface de ligne de commande Git** donne accès à toutes les fonctionnalités de Git.
4. L’**historique des fichiers** suit les modifications détaillées apportées à chaque fichier.

Choisissez l’interface adaptée à vos besoins, en vous appuyant sur le puissant système de gestion des versions de Git.

| Fonctionnalité             | Checkpoints Agent                                    | Commits Git                                          | Historique des fichiers                |
| -------------------------- | ---------------------------------------------------- | ---------------------------------------------------- | -------------------------------------- |
| **Création**               | Automatique aux étapes clés                          | Manuelle ou planifiée                                | Automatique                            |
| **Granularité**            | Modifications au niveau des fonctionnalités          | Modifications de toute ampleur                       | Modifications au niveau des caractères |
| **Description**            | Résumé généré par l’IA                               | Message rédigé par l’utilisateur                     | Horodatage automatique                 |
| **Restauration**           | Restauration en un clic                              | Connaissances de Git requises                        | Restauration en un clic                |
| **Fonctionnalités Git**    | Toutes les fonctionnalités Git                       | Toutes les fonctionnalités Git                       | Aucune fonctionnalité Git              |
| **Synchronisation GitHub** | Toutes les fonctionnalités de synchronisation GitHub | Toutes les fonctionnalités de synchronisation GitHub | Aucune synchronisation GitHub          |

<div id="section-2">
  ## Premiers pas
</div>

Ajoutez l’outil Git au Project Editor de l’application Replit pour accéder au contrôle de version :

1. Accédez à la section Tools de l’application Replit.
2. Sélectionnez le symbole **+** pour ajouter un nouvel outil.
3. Sélectionnez **Git** dans la liste des outils disponibles.

Pour importer un projet existant depuis GitHub, consultez [Importer depuis GitHub](/fr/ko/build/import-from-providers).

<div id="section-4">
  ### Gestion automatique des versions
</div>

<Accordion title="Points de contrôle Agent">
  Instantanés automatiques créés lors du développement assisté par IA avec [Replit Agent](/fr/ko/features/agent/overview).

  **Idéal pour** : le développement avec Replit Agent

  **Fonctionnalités principales** :

  * Création automatique à des jalons logiques
  * Restauration en un clic
  * Instantanés au niveau des fonctionnalités
  * Suivi de la progression
  * Aucune configuration requise
  * Chronologie visuelle de l’avancement du développement

  Les points de contrôle Agent sont enregistrés dans Git et accessibles via le panneau Git ou l’interface de ligne de commande Git. Vous pouvez également visualiser tous les points de contrôle à l’aide de la fonctionnalité History, qui offre :

  * Visualisation chronologique des points de contrôle
  * Descriptions détaillées des points de contrôle
  * Accès direct à l’état de chaque point de contrôle
  * Restauration en un clic vers n’importe quel point de contrôle
</Accordion>

<Accordion title="Historique des fichiers">
  Suivi des versions fichier par fichier, avec sauvegarde automatique des modifications effectuées directement dans l’éditeur, hors Agent.

  **Idéal pour** : restaurer rapidement les modifications récentes d’un fichier

  **Fonctionnalités principales** :

  * Focus sur un seul fichier
  * Modifications au niveau des caractères
  * Comparaison visuelle
  * Historique de 30 jours
  * Fonction de lecture

  L’historique des fichiers possède sa propre interface, mais les modifications sous-jacentes font partie de l’historique Git. En savoir plus sur l’[historique des fichiers](/fr/ko/features/version-control/file-history).
</Accordion>

<div id="git">
  ### Interfaces Git
</div>

<Accordion title="Panneau Git">
  Une interface visuelle pour les opérations Git, qui rend la gestion des versions accessible sans connaissance de la ligne de commande.

  **Idéal pour** : la plupart des projets nécessitant une intégration GitHub et des flux de travail visuels

  **Fonctionnalités principales** :

  * Suivi de l’ensemble du dépôt
  * Gestion des branches
  * Affichage visuel des différences
  * Synchronisation avec GitHub en un clic
  * Collaboration en équipe

  Pour des instructions détaillées sur l’utilisation du panneau Git, consultez [Utiliser le panneau Git](/fr/ko/features/workspace-tools/git-interface).
</Accordion>

<Accordion title="Git CLI">
  Offre un accès complet à Git en ligne de commande via le [Shell](/fr/ko/features/workspace-tools/shell) pour les opérations avancées.

  **Idéal pour** : les utilisateurs avancés ayant besoin de toutes les fonctionnalités de Git

  **Fonctionnalités principales** :

  * Jeu complet de commandes Git
  * Stratégies de branches avancées
  * Flux de travail personnalisés
  * Automatisation par scripts
  * Contrôle total du dépôt

  Pour connaître les commandes Git courantes et leur utilisation, consultez [Utiliser le panneau Git](/fr/ko/features/workspace-tools/git-interface#using-git-commands-in-shell).
</Accordion>

<div id="section-5">
  ## Fonctionnalités principales
</div>

* **Interface Git visuelle** : gérez les dépôts, les commits et les branches sans saisir de commandes Git
* **Intégration GitHub** : connectez des dépôts GitHub pour les sauvegarder et collaborer
* **Importation depuis GitHub** : transformez des [dépôts GitHub en applications Replit](/fr/ko/build/import-from-providers) en quelques clics
* **Gestion des branches** : créez, changez de branche et fusionnez des branches directement dans le Project Editor
* **Résolution des conflits** : identifiez et résolvez les conflits de fusion grâce à une aide visuelle

<div id="section-6">
  ## Cas d’utilisation
</div>

**Suivi de projets personnels**

Suivez les modifications du code pendant le développement afin de pouvoir revenir à une version précédente si nécessaire. Le [panneau Git](/fr/ko/features/workspace-tools/git-interface) affiche les modifications de manière visuelle pour vous permettre de valider facilement des mises à jour importantes.

**Collaboration en équipe**

Plusieurs développeurs travaillent sur la même base de code sans écraser les modifications des autres. Créez une branche pour une nouvelle fonctionnalité, puis fusionnez-la lorsqu’elle est prête. Découvrez comment [inviter des coéquipiers](/fr/ko/build/invite-teammates).

<div id="agent">
  ## Points de contrôle Agent
</div>

Lorsque vous développez une application avec [Replit Agent](/fr/ko/features/agent/overview), les points de contrôle ajoutent une couche supplémentaire de gestion des versions. Ils capturent automatiquement l&#39;état complet de votre projet aux moments clés du développement assisté par l&#39;IA, y compris le contenu du projet, le contexte des conversations avec l&#39;IA et les bases de données connectées.

  <img src="/assets/mirror/checkpoints-9927e500693a.jpg" alt="Points de contrôle Agent dans le panneau Git" width="1920" height="1080" data-path="images/workspace/checkpoints.jpg" />

<div id="section-7">
  ### Fonctionnement des points de contrôle
</div>

Les points de contrôle d’Agent constituent des instantanés complets de l’état de votre app Replit :

* **Création automatique** : Agent crée des points de contrôle aux étapes clés du développement.
* **Capture complète de l’état** : chaque point de contrôle préserve le contenu du projet, la mémoire de l’IA et l’état de la base de données.
* **Plan d’implémentation** : avant d’apporter des modifications, Agent présente un plan pour validation.
* **Suivi des tâches complexes** : plusieurs points de contrôle peuvent être créés pour les tâches plus importantes.

<div id="ai">
  ### Les avantages du développement assisté par l’IA
</div>

Les checkpoints Agent offrent des avantages uniques lorsque vous développez avec l’IA :

* **Filet de sécurité** : expérimentez en toute confiance, sachant que vous pouvez facilement restaurer un état antérieur de l’ensemble de votre environnement de développement.
* **Suivi de la progression** : voyez précisément comment Agent a développé votre application, étape par étape.
* **Jalons cohérents** : les checkpoints correspondent à des fonctionnalités complètes, et non à de simples points d’enregistrement arbitraires.
* **Restauration instantanée** : revenez à n’importe quel état antérieur en un seul clic, y compris pour restaurer la base de données et le contexte d’IA.

<Info>
  Pour en savoir plus sur le contenu capturé par les checkpoints et sur les fonctionnalités complètes de restauration, consultez [Checkpoints et restaurations](/fr/ko/features/version-control/checkpoints-and-rollbacks).
</Info>

<Tip>
  Les checkpoints Agent sont particulièrement utiles pour le développement avec l’IA, mais pour le suivi des versions à long terme et la collaboration, notamment lorsque vous travaillez avec des dépôts externes, envisagez d’utiliser des commits Git.
</Tip>
