<div id="replitmd">
  ### replit.md 文档
</div>

使用 `replit.md` 自定义 Agent 的行为。这个特殊的配置文件可以帮助 Agent 了解项目的偏好设置、编码风格和架构。Agent 会依据经过验证的最佳实践自动生成该文件，并据此构建完全符合你要求的应用程序。用项目上下文引导 Agent、定义编码规范、指定偏好的技术栈、设置沟通偏好——这一切都在同一处完成。

  ### 部署隐私标识
</div>

<div id="agent">
  ### Agent 多工具调用升级
</div>

升级后的多工具调用系统可为你节省 15% 的 Agent 成本，并将结果输出速度提升 30%。Agent 现在能更高效地批量处理任务，更智能地应对工具报错，用更少的资源交付同样出色的结果。
