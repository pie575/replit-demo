<div id="o-que-um-framework-de-desenvolvedor">
  ## 什么是开发者框架？
</div>

开发者框架是由 Replit 平台和社区发布的 Replit Apps，可供其他人用作起点。由 Replit 创建的官方开发者框架会在名称旁显示验证标记：

<Frame>
  <img src="/assets/mirror/template-official-c5fe09e20415.png" alt="Replit 官方开发者框架" width="1051" height="246" data-path="images/programming-ide/creating-a-template/template-official.png" />
</Frame>

[HTML、CSS、JS](https://replit.com/@replit/HTML-CSS-JS?v=1#index.html) 框架非常受欢迎，可作为创建原生 JavaScript 项目的起点。你可以 fork 此框架以供使用。

<div id="templates-personalizados-para-enterprise">
  ## Enterprise 自定义模板
</div>

Enterprise 组织可以创建[自定义模板](/zh/pt/teams/custom-templates)，供组织内所有成员在 Agent 收件箱中选择。除开发者框架外，自定义模板还包含针对企业预先配置的 Agent 指令、技能和项目上下文。有关详情，请参阅[自定义模板指南](/zh/pt/teams/custom-templates)。
