<div id="section">
  ## 什么是项目？
</div>

项目是你在 Replit 中构建的所有内容的容器。它包含代码、数据以及你创建的所有产物 (Web 应用、移动应用、幻灯片演示文稿、数据可视化、视频) 。告诉 Agent 你想要什么后，它会配置项目并在其中构建产物。

你可以把项目想象成桌面上的工作区。所有内容都集中在一处，可以共享相同的信息，但各个部分各司其职。

例如，当你让 Agent 构建一款健身追踪应用时，它会创建一个项目，其中包含移动应用产物，以及让它正常运行所需的后端、数据库和存储。

<ArtifactGrid />

核心概念：

* **项目**：容纳一切的容器 — 代码、数据和所有产物
* **产物**：项目中可发布的成果 (如 Web 应用、幻灯片演示文稿和视频)
* **资源**：所有产物都能自动访问后端、数据库和文件存储 — 无需设置

<Note>
  发布时，整个项目会一次性部署。所有产物都会
  同时发布，因此始终保持同步。
</Note>

一个项目可以包含多个产物。例如，你可以在同一项目中构建面向客户的 Web 应用、面向团队的移动应用和面向投资者的幻灯片演示文稿。同一项目内的产物会自动共享数据和后端逻辑。有关详细信息，请参阅[产物](/zh/ja/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project)。

<div id="section-3">
  ## 管理项目
</div>

项目页面会列出您创建或受邀加入的所有项目。您可以快速返回最近处理的项目，并在繁忙的工作区中找到合适的项目。

<div id="section-4">
  ### 一目了解每个项目包含的内容
</div>

每张项目卡片都会显示其中包含的每个产物 (Web 应用、移动应用、幻灯片演示文稿、数据可视化和动画) 的图标。将鼠标悬停在图标上，即可直接在卡片中预览该产物的截图，无需打开项目即可轻松区分。

<div id="section-5">
  ### 按产物筛选
</div>

使用项目页面顶部的**构建类型**下拉菜单，按产物筛选列表。选择一种类型后，只会显示包含该类型产物的项目。

* **Web** — 包含 Web 应用的项目
* **移动端** — 包含移动应用的项目
* **数据** — 包含数据可视化内容的项目
* **幻灯片** — 包含幻灯片演示文稿的项目
* **设计** — 设计模式项目
* **3D 游戏**、**智能体与自动化**等

选择**所有构建类型**可清除筛选条件。

<div id="section-6">
  ### 按最近打开时间排序
</div>

项目页面默认按**最近打开时间**排序，最近处理过的项目会显示在最上方。在团队工作区中，这一排序方式尤其有用，不会因其他成员最近的编辑而让你当前的项目被淹没。

你可以选择其他列标题 (例如 **最后更新**或**名称**) 来更改排序方式。

<div id="section-7">
  ### 固定常用项目
</div>

将项目固定到列表顶部。固定仅对**你个人**生效——即使你在团队工作区中固定项目，其他成员看到的内容也不会改变。

要固定项目，请打开项目卡片的更多菜单 (三点图标) ，然后选择**Pin**。要取消固定，请在同一菜单中选择**Unpin**。
