以下解答涵盖套餐与定价。有关套餐的完整详情，请参阅 [Starter](/zh/billing/plans/starter-plan)、[Core](/zh/billing/plans/replit-core) 和 [Pro](/zh/billing/plans/replit-pro)，并访问[定价页面](https://replit.com/pricing)查看最新价格。

<AccordionGroup>
  <Accordion title="Agent 用量如何计费？为什么在 Plan 模式下也会收费？">
    Free Mode 在各套餐额度内提供免费的 Agent 使用。Core 和 Pro 的额度每五小时重置一次，并设有每周上限。Starter 层级维持现有限制。在 **设置 → 用量** 中可查看你的用量。

    在 Core 和 Pro 套餐中，可在 Power 或 Max 下选择 Auto，由 Replit 为付费任务挑选模型；你也可以手动选择可用的模型。

    付费模式以及经确认的付费任务采用[按 effort 计费](/zh/billing/ai-billing)，费用取决于请求的复杂程度。Plan 模式在付费路径下即使不修改代码，也可能产生计费的推理开销。付费操作开始前，Replit 都会先请求确认。

    日常工作建议先使用 [Free Mode](/zh/features/agent/agent-modes)。需要更强能力又希望控制成本时，可选择 [Power 模式](/zh/features/agent/agent-modes)。你还可以用 [Plan 模式](/zh/features/agent/plan-mode)界定工作范围，并参考[管理支出](/zh/billing/managing-spend)设置用量上限和预算。若要查看费用明细，请打开 **设置 → 账户用量**并选择**查看历史账单**。
  </Accordion>

  <Accordion title="Starter、Core 和 Pro 套餐分别包含哪些内容？">
    每个套餐针对构建过程中的不同阶段：

    * **Starter** 免费，提供每日 Agent 额度、有限的每月云积分、基础 Agent 访问权限，以及 1 个已发布应用。参阅 [Starter 套餐](/zh/billing/plans/starter-plan)。
    * **Core** 包含每月 {CoreCredits} 积分、支持 Plan 和 Build 模式的完整 Agent、1 个并行 Agent task、最多 5 位协作者、无限量已发布应用，以及 7 天的数据库恢复窗口。参阅 [Core 套餐](/zh/billing/plans/replit-core)。
    * **Pro** ({ProPlanPrice}/月) 提供更多 Free Mode 用量、最多 10 个并行 Agent task，以及最多 15 位构建者，同时还包含分级积分和 28 天的数据库恢复窗口。未用完的积分可结转 {ProCreditRolloverPeriod}。参阅 [Pro 套餐](/zh/billing/plans/replit-pro)。

    如需逐项对比和最新价格，请参阅[价格页面](https://replit.com/pricing)。
  </Accordion>

  <Accordion title="Replit 是否提供学生或教育优惠？">
    Replit 为学生和教育工作者提供教育计划。要了解当前的资格要求、折扣和申请方式，请访问 [replit.com/education](https://replit.com/education)。

    <Note>具体折扣金额和资格要求由教育计划决定，且可能随时调整——请以教育页面的信息为准。</Note>
  </Accordion>

  <Accordion title="年度计费如何运作？我能节省多少？">
    按年计费可通过预付全年费用，享受更低的实际月费。[Core](/zh/billing/plans/replit-core) 的年费为 {CoreAnnualPrice}。如需切换，请在订阅或更改套餐时选择按年计费选项。有关其他套餐和当前优惠，请参阅[定价页面](https://replit.com/pricing)。
  </Accordion>

  <Accordion title="未使用的月度积分会结转到下个月吗？">
    这取决于你的套餐。Core 积分在每个账单周期开始时重置，不会结转。Pro 则支持[积分结转](/zh/billing/plans/replit-pro)——未使用的积分可保留 {ProCreditRolloverPeriod} 后才过期。

    如果你的余额高于每月分配额度，多出的部分可能是推荐奖励积分或促销积分，它们有各自的过期时间。
  </Accordion>

  <Accordion title="如何购买额外积分（积分包）？">
    积分包可在每月配额之外额外增加积分，且积分包越大折扣越多：

    <CreditPackTable />

    打开**设置 → 账户用量**，选择购买积分包。积分可用于 Agent 用量、部署、存储以及其他按用量计费的服务。详情请参阅[管理支出](/zh/billing/managing-spend#purchase-credit-packs)。

    如果你是通过 App Store 订阅的，请先为账户添加一种网页端支付方式。
  </Accordion>

  <Accordion title="Core 或 Pro 是否提供免费试用？">
    Replit 不为付费套餐提供限时免费试用，但你可以通过以下方式先体验 Replit：

    * [Starter 套餐](/zh/billing/plans/starter-plan)完全免费，且没有时间限制。
    * [教育项目](https://replit.com/education)为符合条件的学生提供优惠使用权限。

    如需了解当前的订阅退款条款，请[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="如果我在计费周期中途升级，费用将如何按比例计算？">
    如果你在计费周期中途更改套餐，Replit 会将当前套餐未使用部分的费用抵扣新套餐的费用。完成更改前，计费确认页面会显示具体的按比例计费金额，供你在扣费前查看确认。
  </Accordion>
</AccordionGroup>
