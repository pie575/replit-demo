Les applications publiées privées ajoutent une authentification à vos applications Replit sans nécessiter de
modifications du code. Lorsqu'elle est activée, Replit restreint l'accès à votre application à l'aide d'un écran de connexion Replit.
Seuls les utilisateurs connectés auxquels vous avez accordé l'accès peuvent utiliser le site.

<Note>
  Les déploiements privés sont disponibles sur tous les plans.
</Note>

L'accès restreint à l'application est utile pour les types de projets suivants :

* Outils internes
* Applications en phase de test bêta
* Applications accédant à des informations sensibles

## Options d'accès

Lorsque vous publiez une application, vous pouvez contrôler qui y a accès. Vous verrez trois options de confidentialité :

* **Public** : Votre application est accessible à toute personne sur Internet qui possède l'URL. Il s'agit de l'option d'accès par défaut.
* **Espace de travail uniquement** : Votre application est limitée aux membres de votre espace de travail. Tous les administrateurs, membres et spectateurs de l'espace de travail obtiennent automatiquement l'accès lors de la publication. C'est particulièrement utile dans les espaces de travail collaboratifs où vous souhaitez partager une application avec votre équipe sans la rendre publique.
* **Vous seulement** : Votre application est entièrement privée. Seul vous pouvez y accéder, ainsi que les administrateurs de l'espace de travail et toute personne que vous invitez explicitement (utilisateurs individuels ou groupes). Il s'agit de l'option la plus restrictive.

Quelques points à garder à l'esprit :

* **Espace de travail uniquement** et **Vous seulement** sont tous deux des déploiements privés — les visiteurs sans accès sont invités à se connecter via Replit avant de pouvoir consulter l'application.
* Dans un espace de travail personnel où vous êtes le seul membre, **Espace de travail uniquement** et **Vous seulement** se comportent de la même manière car il n'y a pas d'autres membres dans l'espace de travail. La distinction devient significative lorsque vous travaillez dans un espace de travail partagé avec des collaborateurs.
* Si vous avez besoin de déploiements protégés par mot de passe (où toute personne disposant d'un mot de passe peut accéder à l'application, qu'elle ait ou non un compte Replit), cette option est également prise en charge sur tous les plans.

## Fonctionnalités

Les applications publiées privées offrent les fonctionnalités suivantes :

* **Gestion des accès** : Accordez ou restreignez l'accès à l'application à des utilisateurs individuels ou à des groupes au sein de votre espace de travail.
* **Configuration sans code** : Authentification transparente pour votre application sans modifications de code requises.

## Utilisation

Lors de la publication de votre application Replit, vous pouvez choisir une option de confidentialité dans la liste déroulante **Public**, **Espace de travail uniquement** ou **Vous seulement**.
Les sections suivantes décrivent comment configurer et gérer l'accès à votre application publiée.

<Info>
  Les tâches planifiées omettent cette option car elles n'écoutent pas le trafic entrant.
</Info>

<Accordion title="Publier une application avec accès restreint">
  1. Sélectionnez le menu utilisateur en haut à gauche de l'écran d'accueil pour afficher vos espaces de travail.
  2. Vérifiez ou sélectionnez l'espace de travail dans lequel publier votre application Replit.
  3. Ouvrez l'application Replit que vous souhaitez publier.
  4. Dans les options de publication, sélectionnez **Public**, **Espace de travail uniquement** ou **Vous seulement** dans la liste déroulante d'accès.
  5. Sélectionnez **Publier** pour confirmer la publication.
</Accordion>

<Accordion title="Afficher vos applications publiées">
  1. Sélectionnez le menu utilisateur en haut à gauche de l'écran d'accueil pour afficher vos espaces de travail.
  2. Vérifiez ou sélectionnez l'espace de travail dans lequel vous avez publié votre application Replit.
  3. Depuis l'écran d'accueil, sélectionnez <img class="svg-icon" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Icône Applications publiées" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Applications publiées** dans le dock gauche.
     Vous devriez voir une liste des applications publiées de l'espace de travail similaire à la capture d'écran ci-dessous :

       <img src="/assets/mirror/private-deployments-list-b95893c56c31.png" alt="Liste des déploiements privés" width="2782" height="526" data-path="images/deployments/private-deployments/private-deployments-list.png" />
</Accordion>

<Accordion title="Modifier l'accès d'une application publiée existante">
  1. Sélectionnez l'application publiée et ouvrez l'outil Publication.
  2. Dans l'onglet Publication, sélectionnez **Modifier les commandes et les secrets**, puis choisissez l'option d'accès souhaitée (**Public**, **Espace de travail uniquement** ou **Vous seulement**).
  3. Sélectionnez **Publier** pour confirmer la publication.
</Accordion>
