<div id="choose-a-workspace-region">
  ### 选择工作区地理位置
</div>

Pro 构建者现在可以在创建工作区时选择北美、欧洲 (EU) 或亚洲。此选择将决定新项目和工作区资源所在的区域。

<div id="use-replit-through-mcp">
  ### 通过 MCP 使用 Replit
</div>

将 Replit 原生连接到 ChatGPT、Claude 或 Slack，或者将任何兼容的 MCP 客户端连接到 Replit，即可创建、查找、检查、更新和发布应用。你还可以创建应用的私有可编辑副本，无需从空白应用开始。

<Frame>
  <img src="/assets/mirror/codex-list-replit-projects-bebae6a1dbab.png" alt="Codex 回复中列出了三个最近更新的 Replit 项目" width="2000" height="951" data-path="images/replitai/custom-mcp/codex-list-replit-projects.png" />
</Frame>

详细了解 [Replit MCP Server](/zh/platforms/mcp-server)。

<div id="migrate-to-clerk-auth">
  ### 迁移到 Clerk Auth
</div>

现在，你可以将符合条件的 Replit Auth 应用迁移至 Clerk Auth。Agent 会先迁移账户数据，再更新登录代码，因此老用户仍可访问自己的数据。

  <img src="/assets/mirror/replit-auth-to-clerk-dialog-c485c7e997bc.png" alt="新版 Replit Auth 对话框，其中包含“让 Agent 执行迁移”按钮" width="1259" height="790" data-path="images/workspace/auth/replit-auth-to-clerk-dialog.png" />
</Frame>

详细了解[如何迁移至 Clerk Auth](/zh/features/auth-and-identity/migrate-auth-to-clerk)。

<div id="share-and-manage-workspace-skills">
  ### 共享和管理工作区技能
</div>

现在，任何工作区成员都可以创建技能，并将其设为私有或与工作区共享。共享技能默认对其他成员处于关闭状态，每个人都可以选择要启用哪些技能。管理员可以管理所有工作区技能，并要求其工作区使用特定技能。经过重新设计的技能库让技能更易于查找和管理。

详细了解 [Agent Skills](/zh/features/agent/skills)。

<div id="teams-and-enterprise">
  ## Teams 和 Enterprise
</div>

<div id="admin-api-available-in-beta">
  ### Admin API 现已进入测试阶段
</div>

Enterprise 账户管理员现在可以在“设置”的新 **Developer** 选项卡中创建 API 密钥，并使用 Admin API：

* 查看工作区、成员、用户群组、项目和部署。
* 查看成员、项目和工作区在自定义日期范围内的使用情况。
* 查看和编辑工作区、用户群组及个人成员的预算。

请参阅 [Admin API 文档](/zh/teams/admin-api) 和 [API 参考](https://api.replit.com/docs)，了解更多信息。
