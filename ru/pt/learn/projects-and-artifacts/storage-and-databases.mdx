Гибкие решения Replit для хранения данных позволяют быстро добавить хранилище, необходимое для работы вашего App. Для App со следующими требованиями можно использовать базу данных или объектное хранилище Replit, а Agent может автоматически настроить и интегрировать оба решения:

* Игра, в которой нужно сохранять данные игроков, например прогресс или рекорды
* Контентная платформа для управления медиафайлами

<div id="quais-so-as-opes-de-armazenamento-e-banco-de-dados-do-replit">
  ## Какие варианты хранения данных и баз данных доступны в Replit
</div>

Replit предлагает следующие варианты хранения данных:

* **База данных**: хранит структурированные данные, например профили пользователей, игровые результаты и каталоги товаров.
  Вы можете сохранять и получать данные по атрибутам и связям между ними.

* **App Storage**: хранит неструктурированные данные, например изображения, видео и документы.
  Вы можете сохранять и получать большие файлы и двоичные данные.

<div id="comparao-entre-app-storage-e-banco-de-dados">
  ### Сравнение App Storage и базы данных
</div>

|                               | База данных                                         | App Storage                                           |
| ----------------------------- | :-------------------------------------------------- | :---------------------------------------------------- |
| **Оптимальный формат данных** | Структурированные данные со связями                 | Большие файлы (изображения, видео, документы)         |
| **Модель данных**             | Таблицы, строки, столбцы                            | Бакеты, файлы                                         |
| **Язык запросов**             | SQL                                                 | REST API                                              |
| **Клиенты**                   | PostgreSQL-совместимые клиенты и ORM                | SDK Replit и клиентские библиотеки GCS                |
| **Модель оплаты**             | Оплата за вычислительное время и место для хранения | Оплата за пропускную способность и место для хранения |

<div id="ferramentas-do-editor-de-projeto">
  ### Инструменты редактора проекта
</div>

Ознакомьтесь со следующими инструментами Replit для настройки и управления хранением данных вашего приложения:

<CardGroup>
  <Card title="База данных" href="/ru/pt/features/data-and-storage/sql-database" icon="database">
    Идеально подходит для структурированных данных и представления связей между ними.
    Работает на полностью управляемой базе данных PostgreSQL, которая масштабируется вместе с вашим приложением.
  </Card>

  <Card title="App Storage" href="/ru/pt/features/data-and-storage/object-storage" icon="bucket">
    Идеально подходит для неструктурированных данных и больших файлов, таких как изображения, видео и документы.
    Работает на базе Google Cloud Storage (GCS), обеспечивая высокую доступность и масштабируемость. Agent может автоматически настроить App Storage с расширенной аутентификацией и контролем доступа.
  </Card>
</CardGroup>
