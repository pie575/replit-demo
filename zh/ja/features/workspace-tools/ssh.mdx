<div id="ssh">
  ## 什么是 SSH？
</div>

SSH 是 Secure Shell 的缩写，是一种安全协议，可让你便捷地远程访问 Replit 应用的命令行界面。借助 SSH，你可以无缝传输文件，并使用自己惯用的本地集成开发环境 (IDE) 在 Replit 上编写代码，从而提升开发流程中的协作效率与生产力。

SSH 功能适用于 Core、Pro 及其他所有付费方案。

整个流程概览如下：

* 在本地机器上生成 SSH 密钥对
* 在任意 Replit 应用的 **SSH** 面板中添加该 SSH 密钥
* 使用 SSH 客户端或支持 SSH 的编辑器 (如 [VSCode](https://code.visualstudio.com/) 或 [Cursor](https://www.cursor.com/)) 进行连接

<Note>
  SSH 密钥关联的是你的账户，而非某个特定的 Replit 应用。也就是说，公钥只需添加一次，即可连接到你有访问权限的任意 Replit 应用。
</Note>

<div id="ssh-2">
  ## 为什么使用 SSH
</div>

* **Replit 应用与编辑器自动同步更新**：在 Replit 应用中所做的更改会立即反映到编辑器中，在编辑器中所做的更改也会同步到 Replit 应用。这种无缝同步可确保代码库在各个平台上始终保持最新状态。

* **文件管理同步**：无论是添加、删除还是更新文件，这些更改都会在编辑器与 Replit 应用之间实时同步。有了该功能，无论更改从哪一端发起，项目结构都能保持一致。

* **文件夹管理与文件移动**：在文件夹之间移动文件同样会在编辑器与 Replit 应用之间同步。这样，在其中一端所做的结构调整能够准确反映到另一端，从而保持项目的完整性与结构。

<div id="section">
  ## 查找或创建密钥对
</div>

要为账户配置 SSH，你需要一个 SSH 公钥。

<div id="section-2">
  ### 检查是否已有密钥对
</div>

在本地计算机的终端中运行以下命令，即可确认是否已有公钥：

<Tabs>
  <Tab title="Mac/Linux">
    ```sh theme={null}
    ls -l ~/.ssh
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    dir %HOMEPATH%\.ssh
    ```
  </Tab>
</Tabs>

如果出现报错，也没有关系，请继续阅读[生成新的密钥对](#generating-a-new-keypair)。
如果看到名为 `replit.pub` 的文件，请前往[获取公钥内容](#get-the-contents-of-your-public-key)。

<div id="section-3">
  ### 生成新的密钥对
</div>

在你的机器上打开终端 (或命令提示符) 窗口，粘贴以下命令：

<Tabs>
  <Tab title="Mac/Linux">
    ```bash theme={null}
    ssh-keygen -t ed25519 -f ~/.ssh/replit -q -N ""
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    ssh-keygen -t ed25519 -f %HOMEPATH%\.ssh\replit -q -N ""
    ```
  </Tab>
</Tabs>

该命令会检查指定的 SSH 公钥文件是否已存在。如果不存在，则会使用相应的参数创建一个新的 SSH 密钥。

<div id="section-4">
  ### 获取公钥内容
</div>

确认或创建密钥对后，查看公钥的内容 (即两个名称相似的文件中带 `.pub` 后缀的那一个) ，稍后会用到。

<Tabs>
  <Tab title="Mac/Linux">
    ```sh theme={null}
    cat ~/.ssh/replit.pub
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    notepad %HOMEPATH%\.ssh\replit.pub
    ```
  </Tab>
</Tabs>

保存 `replit.pub` 的内容以供本文后续步骤使用，然后继续阅读[将 SSH 密钥添加到您的账户](#add-the-ssh-key-to-your-account)。

<div id="ssh-3">
  ## 将 SSH 密钥添加到账户
</div>

<div id="sshreplit">
  ### 使用 SSH 面板直接向 Replit 应用添加公钥
</div>

1. 在任意窗口的 Replit 应用中，选择 **+** 按钮，然后搜索 **SSH**。

<Frame>
  <img src="/assets/mirror/ssh-tool-2db02c6a83d0.png" alt="Replit 界面中的 SSH 工具按钮" width="846" height="328" data-path="images/ssh-vscode/ssh-tool.png" />
</Frame>

2. 切换到 **Keys** 标签页，选择 **New SSH key**。
3. 在弹出窗口中，为密钥输入 **Label** (例如 my-ssh-key) ，并将复制的公钥粘贴到 **Key** 字段中。
   然后选择 **Add SSH Key** 按钮。密钥即添加完成，可以使用了。

<Frame>
  <img src="/assets/mirror/add-ssh-key-with-values-5d6f440e56ba.png" alt="已填写标签和密钥字段的添加 SSH 密钥对话框" width="500" height="511" data-path="images/ssh-vscode/add-ssh-key-with-values.png" />
</Frame>

<div id="settings">
  ### 直接在 Settings 中添加公钥
</div>

你也可以打开 **Settings**，在 **Account** 下选择 **Advanced** (或 **SSH keys** 选项) 来添加 SSH 密钥。选择 **Add SSH key**，然后粘贴上一节[查找或创建密钥对](#find-or-create-a-keypair)中 `replit.pub` 的内容。

<Note>
  如果你的机器上有多个公钥，务必在 SSH 配置中使用正确的私钥与公钥组合。
</Note>

<div id="replit">
  ## 连接到 Replit 应用
</div>

<div id="ssh-4">
  ### SSH 配置
</div>

1. 在终端中，确认 `~/.ssh` 目录和 `~/.ssh/config` 文件已存在：

<Tabs>
  <Tab title="Mac/Linux">
    ```sh theme={null}
    mkdir -p ~/.ssh && chmod 700 ~/.ssh && touch ~/.ssh/config && chmod 600 ~/.ssh/config
    open -a 'TextEdit' ~/.ssh/config || nano ~/.ssh/config
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    if not exist %HOMEPATH%\.ssh mkdir %HOMEPATH%\.ssh && type \NUL > %HOMEPATH%\.ssh\config
    notepad %HOMEPATH%\.ssh\config
    ```
  </Tab>
</Tabs>

2. 添加以下配置块，让所有 *.replit.dev 域名都使用 `replit` 密钥对：

<Tabs>
  <Tab title="Mac/Linux/Windows">
    ```
    Host *.replit.dev
        Port 22
        IdentityFile ~/.ssh/replit
        StrictHostKeyChecking accept-new
    ```
  </Tab>
</Tabs>

<div id="vscodecursor">
  ### 从 VSCode 或 Cursor 连接
</div>

1. 在 Replit 应用中打开 **SSH** 面板

2. 在 SSH 面板中切换到 **Connect** 标签页，然后选择 **Launch VS Code**。

<Tabs>
  <Tab title="在 VSCode 中连接">
    <img src="/assets/mirror/ssh-connect-439a3c150846.png" alt="显示 Launch VS Code 选项的 SSH 连接标签页" width="788" height="482" data-path="images/ssh-vscode/ssh-connect.png" />
  </Tab>
</Tabs>

3. 如果系统提示填写 `~/.ssh/config`，请输入以下内容：

   ```
   Host *.replit.dev
       Port 22
       IdentityFile ~/.ssh/replit
       StrictHostKeyChecking accept-new
   ```

   <Note>
     添加 SSH 配置的提示仅在首次连接 VS Code 或其他编辑器时出现。若要再次打开该配置文件，需要选择 &#42;&#42;Configure SSH Hosts...&#42;&#42;。
   </Note>

4. 如果出现外部应用程序警告，请选择 **Yes**，确认在你常用的编辑器或 VS Code 中打开项目。

5. 系统可能会不时提示你安装或更新 SSH 扩展。Replit 会持续保持与这些 IDE 最新版本的兼容性，这些更新有时也包含重要的安全修复。

<div id="section-5">
  ### 手动连接
</div>

在 **SSH** 面板「Connect」标签页的底部可以找到「Connect manually」。

复制该命令，粘贴到本地终端 (Mac 或 Linux) 或本地命令提示符 (Windows) 中，即可直接连接。

这也是排查 IDE 连接问题的好方法，同时有助于收集有价值的「详细」连接信息，便于向 Replit 支持团队报告缺陷。

<div id="section-6">
  ### 使用此处未列出的工具连接
</div>

面向各种平台和操作系统的 SSH 客户端有很多，它们提供的功能和集成方式各不相同。

你可以将“Connect Manually”中显示的命令拆解为各个组成部分，据此确定各个客户端的配置方法：

```sh theme={null}
ssh -i ~/.ssh/replit -p 22  c96b6ade-d5e4-4f7a-bc5b-52334509b2a3@c96b6ade-d5e4-4f7a-bc5b-52334509b2a3-00-16nh2hskw3ql8.riker.replit.dev
       ^-----v-----^    ^^  ^-----------------v----------------^ ^------------------------------v-------------------------------------^
        Private Key   Port                   User               @                           Hostname
```

**Hostname**: `<your_hostname>.<cluster>.replit.dev`
**Port**: `<port_number>`
**User**: `Username`
**Private Key**：计算机上私钥文件的路径，通常与 `replit.pub` 位于同一目录。
