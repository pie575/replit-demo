⏰ *Tempo estimado: 10 minutos*

Às vezes o design do qual você quer partir já está no ar na web: seu site atual, ou uma página cujo visual você quer recriar. O Import from URL recria um website como um frame de design que você pode explorar, refinar e transformar em um app interativo.

Você vai usar [creative-studio-landing.replit.app](https://creative-studio-landing.replit.app), uma landing page construída pela Replit para um estúdio criativo, como exemplo.

## Antes de começar

Você precisa de:

* Uma [conta Replit](https://replit.com).
* A URL de um website público, ou o exemplo acima.

## Importe o website

<Steps>
  <Step title="Copie a URL do site">
    Use seu próprio site, ou copie o exemplo: `https://creative-studio-landing.replit.app`.

    <Frame caption="O site de exemplo: Kosmo Studio, uma landing page de estúdio criativo.">
      <img src="/assets/mirror/url-example-site-e0ad60629981.webp" alt="A landing page da Kosmo Studio com a manchete We craft bold ideas and visuals that truly work, acima de um leque de cartões de arte" width="3440" height="2160" data-path="images/design/import-from-url/url-example-site.webp" />
    </Frame>
  </Step>

  <Step title="Abra o Replit Design">
    Vá para [replit.com/design](https://replit.com/design) e selecione **Import URL** abaixo da caixa de prompt. O Agent recria o visual e a sensação do site como ponto de partida.

    <Frame caption="Import URL na página inicial do Replit Design: cole um link para qualquer website.">
      <img src="/assets/mirror/design-import-url-07a8ac52e188.webp" alt="A página inicial do Replit Design com a opção Import URL selecionada e uma dica de ferramenta lendo Paste a link to any website and Agent will recreate its look and feel as a starting point" width="2293" height="1322" data-path="images/design/import-from-url/design-import-url.webp" />
    </Frame>
  </Step>

  <Step title="Cole a URL e comece a construir">
    Selecionar **Import URL** preenche antecipadamente o prompt: *"Recreate the look and feel of this website:"*. Cole sua URL depois dele e selecione **Start**.

    <Frame caption="O prompt de recriação pré-preenchido com a URL de exemplo, pronto para começar.">
      <img src="/assets/mirror/design-url-prompt-b6196aac1b17.webp" alt="A caixa de prompt do Replit Design lendo Recreate the look and feel of this website seguida da URL de exemplo, com o botão Start" width="2293" height="1322" data-path="images/design/import-from-url/design-url-prompt.webp" />
    </Frame>
  </Step>
</Steps>

O Agent recria o site como um frame de design no seu projeto.

## Deixe do seu jeito

Selecione o frame importado e comece a remodelá-lo:

* **Siga uma [sugestão](/pt/design/explore-suggestions)**: a importação chega com próximos passos propostos, como uma variante editorial escura, uma viewport mobile ou uma página de contato. Cada uma é gerada como um novo frame, então o original permanece para comparação.
* **[Converse sobre isso](/pt/design/chat-about-your-design)**: use o campo abaixo do frame e explique em suas próprias palavras, *"troque as fotos do portfólio"*, *"deixe a tipografia do hero mais pesada"*.
