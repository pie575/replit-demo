Console позволяет отслеживать и просматривать логи, которые запущенное приложение Replit выводит в реальном времени.
Данные текущего и прошлых запусков помогут разобраться в поведении приложения, устранить ошибки и оптимизировать производительность.

<Tip>
  При отладке с помощью Agent добавляйте логи консоли в запрос, чтобы дать необходимый контекст.
</Tip>

<div id="section">
  ## Возможности
</div>

Console предоставляет следующие инструменты, которые помогают понять, как работает приложение:

* **Логирование в реальном времени** — вывод приложения отображается сразу же, как только он появляется
* **Помощь ИИ** — получайте подсказки по исправлению ошибок, о которых сообщается в логах
* **История запусков** — просматривайте логи предыдущих запусков, чтобы отслеживать изменения

<div id="section-2">
  ## Использование
</div>

Открыть инструмент Console можно прямо из редактора проекта.

<Accordion title="Как открыть Console">
  Через **док инструментов** слева:

  1. Выберите <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Значок всех инструментов" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**, чтобы открыть список инструментов редактора проекта.
  2. Выберите <img class="icon-svg" src="/assets/mirror/console-8a41ac90789c.svg" alt="Значок Console" width="16" height="16" data-path="images/icons/console.svg" /> **Console**.

  Через **строку поиска**:

  1. Нажмите на <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="Значок лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" />лупу вверху, чтобы открыть поиск
  2. Введите «Console», чтобы найти инструмент, и выберите его в результатах.
</Accordion>

Каждый раз, когда вы нажимаете кнопку **Run** в приложении Replit, в Console появляется новая запись со следующей информацией:

* команда, которой был запущен код;
* отметка времени;
* стандартный вывод и логи ошибок.

<div id="ai">
  ### Отладка с помощью ИИ
</div>

Если в логах появилась ошибка или другая информация, в которой вы хотите разобраться, нажмите кнопку **Ask AI** в верхней части записи. Автоматически откроется вкладка **Agent**, а содержимое лога будет отправлено на анализ.

<div id="section-3">
  ### Команды записей лога
</div>

Консоль предоставляет следующие инструменты для управления логами:

* **Показывать только последние**: включите этот переключатель, чтобы отображался только последний запуск.
* **Свернуть записи**: выберите <img class="icon-svg" src="/assets/mirror/down-arrow-9c1cf9fd152e.svg" alt="Значок стрелки вниз" height="16" width="16" data-path="images/icons/down-arrow.svg" />стрелку вниз слева от имени команды, чтобы скрыть логи.
* **Очистить прошлые запуски**: выберите этот пункт, чтобы удалить логи прошлых запусков. Это действие нельзя отменить.

<div id="section-4">
  ### Доступность по сети
</div>

Вы можете управлять доступностью версии приложения для разработки в сети.

Чтобы прекратить обработку запросов к URL разработки, выберите значок перечёркнутого глобуса <img class="icon-svg" src="/assets/mirror/network-off-5bdca8a4fe4e.svg" alt="Значок отключения сети" height="16" width="16" data-path="images/icons/network-off.svg" /> справа от строки с информацией о сети.

Чтобы снова включить обработку, выберите значок глобуса <img class="icon-svg" src="/assets/mirror/network-on-15be2e5fb4f5.svg" alt="Значок включения сети" height="16" width="16" data-path="images/icons/network-on.svg" />.

Чтобы посмотреть URL разработки, выберите текст `{...}.replit.dev` в адресной строке.

<Frame>
  <img src="/assets/mirror/preview-dev-url-b36770b33769.png" alt="Расположение URL разработки в Preview" width="1222" height="824" data-path="images/workspace/preview-dev-url.png" />
</Frame>

<Note>
  Даже если вы отключите обработку запросов к URL разработки, приложение останется доступным в инструменте Preview.
</Note>

<div id="section-5">
  ### Остановка команды рабочего процесса
</div>

Запущенную команду рабочего процесса можно остановить с помощью инструмента Console в редакторе проекта.

Чтобы завершить её, нажмите квадратную кнопку справа от строки с командой запуска приложения Replit.

Чтобы перезапустить приложение, воспользуйтесь кнопкой рабочего процесса **Run** в верхней части редактора проекта.
