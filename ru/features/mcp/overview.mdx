Replit Agent подключается к внешним инструментам и источникам данных через [Model Context Protocol (MCP)](https://modelcontextprotocol.io) — открытый стандарт для ИИ-интеграций. Любой сервер из списка ниже устанавливается в один клик, после чего Agent автоматически загружает его инструменты и применяет их, когда это уместно.

О самой концепции читайте в разделе [Model Context Protocol](/ru/learn/model-context-protocol). Практическое руководство — [Подключение через MCP](/ru/build/connect-via-mcp). Чтобы подключить сервер, которого нет в этом списке, см. [Добавление пользовательского MCP-сервера](/ru/build/connect-via-mcp#add-a-custom-mcp-server).

<Info>
  Нажмите **Добавить в Replit**, чтобы установить нужный сервер. Вам будет предложено авторизовать подключение в Project Editor.
</Info>

<div id="security-protections">
  ## Меры безопасности
</div>

Весь трафик MCP проходит через сканер безопасности Replit. Сканер анализирует определения инструментов и планируемые действия, блокируя подозрительные или небезопасные инструменты до их запуска. Если инструмент отклонён, Agent сообщит вам об этом.

<div id="authentication-options">
  ## Варианты аутентификации
</div>

* **Динамическая регистрация клиента OAuth** — если сервер поддерживает OAuth DCR, Replit автоматически обнаруживает и регистрирует клиент за вас. Большинство серверов из готового списка используют именно этот способ.
* **Пользовательские заголовки** — задайте одну или несколько пар «имя заголовка — значение» (например, `X-API-Key`). Replit добавляет эти заголовки в каждый запрос MCP, чтобы ваш сервер мог проверить отправителя. Используйте этот вариант при добавлении собственного сервера, который аутентифицируется с помощью статических токенов.

<div id="share-your-own-install-link">
  ## Поделитесь своей ссылкой для установки
</div>

Ссылки для установки позволяют добавить ваш MCP-сервер в Replit одним кликом. Создайте такую ссылку с помощью формы на странице [Подключение через MCP](/ru/build/connect-via-mcp#share-an-install-link) или соберите её вручную: закодируйте JSON-данные в base64 и добавьте результат к `https://replit.com/integrations?mcp=`.

```json theme={null}
{
  "displayName": "My MCP Server",
  "baseUrl": "https://example.com/mcp",
  "headers": [{ "key": "Authorization", "value": "Bearer your-token" }]
}
```

* **displayName** — имя, отображаемое при установке
* **baseUrl** — HTTPS-эндпоинт вашего MCP-сервера
* **headers** — необязательные заголовки аутентификации
