ChatGPT의 Replit 통합을 통해 대화에서 바로 Replit Apps를 생성, 수정, 검사할 수 있습니다. 별도의 설정이 필요하지 않습니다. ChatGPT와 대화하며 실제 앱을 만들고, 나머지는 Agent가 처리합니다.

## ChatGPT에서 Replit이란

ChatGPT의 Replit은 ChatGPT 대화를 Replit의 강력한 개발 플랫폼과 연결합니다. 만들고 싶은 것을 설명하면 Agent가 완전히 동작하는 Replit App을 생성해 드립니다. 앱이 만들어지면 ChatGPT에게 앱을 수정, 업데이트, 또는 분석하도록 요청할 수 있습니다. 모두 자연스러운 대화로 진행됩니다.

## 시작하기

다음 단계를 따라 Replit을 ChatGPT에 연결하고 첫 번째 앱을 만들어보세요.

### Replit을 ChatGPT에 연결하기

Replit을 ChatGPT에 연결하는 방법은 두 가지입니다:

<Accordion title="Settings에서 연결하기">
  1. ChatGPT에서 프로필 아이콘을 클릭하세요
  2. **Settings** → **Apps & Connectors**로 이동하세요
  3. **Replit**을 찾아 **Connect**를 클릭하세요
  4. Replit 계정으로 OAuth 인증을 완료하세요
</Accordion>

<Accordion title="대화에서 연결하기">
  1. ChatGPT에서 새 대화를 시작하세요
  2. 아래 방법 중 하나로 Replit을 호출하세요
  3. 연결되어 있지 않으면 ChatGPT가 OAuth 흐름을 안내합니다
</Accordion>

### ChatGPT에서 Replit 호출하기

연결 후 세 가지 방법으로 Replit을 호출할 수 있습니다:

| Method         | How to use                          |
| -------------- | ----------------------------------- |
| Direct mention | 메시지 앞에 `Replit, <요청 내용>` 입력         |
| Slash command  | 작성창에 `/Replit` 입력                   |
| Composer menu  | **+** 버튼 클릭 → **More** → **Replit** |

### 첫 번째 앱 만들기

연결 후 첫 번째 Replit App을 만들어보세요:

1. ChatGPT에서 새 대화를 시작하세요
2. Replit을 호출하고 만들고 싶은 것을 설명하세요 (예: "Replit, create a todo app with dark mode")
3. Agent가 앱을 생성하고 자동으로 배포합니다
4. 완료되면 앱을 볼 수 있는 링크가 제공됩니다

<Note>
  각 대화에서는 하나의 Replit App으로 작업할 수 있습니다. 같은 대화에서 새 앱을 만들면 기존 앱이 수정됩니다. 여러 앱을 만들려면 별도의 대화를 시작하세요.
</Note>

## 기능

* **[Replit AI](/ko/build/welcome)**: Agent가 자연어 요청을 바탕으로 앱을 생성하고 배포합니다
* **[Project Editor](/ko/learn/projects-and-artifacts/project-editor)**: ChatGPT에서 접근 가능한 풀 기능 개발 환경
* **[Publishing](/ko/learn/projects-and-artifacts/replit-deployments)**: 앱이 자동으로 배포되어 바로 공유할 수 있습니다

<Accordion title="할 수 있는 것들">
  **Create:** 원하는 것을 설명하여 새 Replit Apps를 만드세요. Agent가 애플리케이션을 생성하고 자동으로 배포합니다.

  **Update:** 현재 대화의 앱을 수정하세요. ChatGPT에게 기능 추가, 버그 수정, 변경 사항 적용을 요청하면 Agent가 실행합니다.

  **Inspect:** 변경 없이 앱을 분석하세요. 코드 구조, 파일 경로, 동작에 대한 정보를 얻을 수 있습니다.
</Accordion>

<Accordion title="지원되는 파일 형식">
  프롬프트에 다양한 파일 형식을 포함할 수 있습니다:

  | Format                  | Supported                    |
  | ----------------------- | ---------------------------- |
  | PDF                     | Yes                          |
  | CSV                     | Yes                          |
  | Common document formats | Yes                          |
  | Images (raw files)      | No (use public URLs instead) |
  | Videos (raw files)      | No (use public URLs instead) |

  <Note>
    앱에 이미지나 동영상을 포함하려면 프롬프트에 공개 URL을 제공하세요. 앱이 만들어진 후 Replit에서 직접 미디어 파일을 추가할 수도 있습니다.
  </Note>
</Accordion>

<Accordion title="빌드 시간">
  Agent의 일반적인 앱 빌드 시간:

  | App complexity                                     | Typical build time |
  | -------------------------------------------------- | ------------------ |
  | Simple (calculators, small landing pages)          | 2–3 minutes        |
  | Complex (games, rich animations, dense dashboards) | 3–4 minutes        |
</Accordion>

## 이용 가능 범위 및 플랜

<Accordion title="ChatGPT 플랜">
  Replit 통합은 모든 ChatGPT 플랜 유형에서 작동합니다:

  | Plan           | Supported | Notes                                            |
  | -------------- | --------- | ------------------------------------------------ |
  | Free           | Yes       |                                                  |
  | Plus           | Yes       |                                                  |
  | Pro            | Yes       |                                                  |
  | Business       | Yes       | **Workspace settings → Connectors**에서 관리자 활성화 필요 |
  | Enterprise/Edu | Yes       | **Workspace settings → Connectors**에서 관리자 활성화 필요 |

  **지역 이용 가능 여부:** EU 외 모든 지역.
</Accordion>

<Accordion title="Replit 플랜">
  모든 Replit 플랜 유형에서 ChatGPT 통합을 지원합니다:

  | Plan           | Supported | Notes                              |
  | -------------- | --------- | ---------------------------------- |
  | Starter (Free) | Yes       | 공개 앱만 가능                           |
  | Core           | Yes       | 비공개 앱, 확장 빌드, Publishing, Database |
  | Pro            | Yes       | 월간 크레딧 한도 증가, 모든 Core 기능 포함        |
  | Enterprise     | Yes       | 전체 기능 이용 가능                        |
</Accordion>

## 요금 청구 및 크레딧

ChatGPT에서 Replit이 수행한 작업은 Replit 계정의 Replit Agent 사용량으로 청구됩니다.

<Accordion title="요금 청구 방식">
  * **Core** 및 **Pro** 플랜에는 허용 범위 내에서 Agent, publishing, databases를 사용할 수 있는 월간 크레딧이 포함됩니다
  * 6개월 후 만료되며 자동 갱신되지 않는 **credit pack**을 구매할 수 있습니다. 출시 시 트래픽 급증이나 실험에 적합합니다
  * Replit의 결제 설정에서 **usage limits** 및 **budgets**을 사용하여 지출을 제한하세요

  자세한 내용은 [AI 결제 문서](/ko/billing/ai-billing)를 참고하세요.
</Accordion>

## 현재 제한 사항

현재 ChatGPT의 Replit 앱은:

* 해당 대화에서 생성된 앱에만 작업할 수 있습니다
* 다음 항목을 열거나 수정할 수 없습니다:
  * 다른 ChatGPT 스레드에서 생성된 앱
  * Replit에서 직접 만든 앱

데이터베이스, 시크릿 관리, 더 고급 Project Editor 컨트롤 등 전체 Replit 경험과의 기능 동등성은 추후 제공될 예정입니다.

## 문제 해결

<Accordion title="Browse apps에 Replit이 표시되지 않는 경우">
  **Browse apps**에 Replit이 보이지 않으면 다음을 확인하세요:

  * 해당 지역에서 앱을 이용할 수 있는지 여부
  * 워크스페이스 관리자가 Replit 앱을 활성화했는지 여부 (Business/Enterprise/Edu)
</Accordion>

<Accordion title="빌드 실패">
  빌드가 실패하면 Replit에서 앱을 여세요:

  * 사용량 및 결제 내역 확인
  * 체크포인트와 롤백을 사용하여 되돌리기
  * Project Editor에서 Agent에게 직접 도움 요청
</Accordion>
