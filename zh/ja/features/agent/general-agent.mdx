<div id="general-agent">
  ## 什么是 General Agent？
</div>

General Agent 是使用 Replit Agent 最灵活的方式。你无需提前选择工件类型，也不必一开始就确定要构建什么，直接开始聊天即可——可以创建 CSV、生成 PDF、调研某个主题，等准备好了再构建完整的应用。

核心概念：

* **无需提前选择**：不用先选定工件类型就能开始工作
* **各种产出**：生成文件 (CSV、PDF、文档) 、进行调研、构建应用
* **连接器**：对 BigQuery、Linear、Slack、Notion、Amplitude、Segment、Hex 等外部服务进行读写
* **逐步扩展**：从轻量的聊天起步，自然而然地升级为构建完整应用

<div id="general-agent-2">
  ## 如何使用 General Agent
</div>

你可以通过以下几种方式使用 General Agent：

1. 在 Replit 主页输入提示词前，**选择「General」**
2. **打开现有项目**，直接开始与 Agent 对话
3. **选择任意[开发者框架](https://replit.com/templates)** — 所有开发者框架都自动包含 General Agent
4. **从 GitHub [导入](/zh/ja/build/import-from-providers)** — 从 GitHub 导入的项目会自动附带 General Agent

<div id="general-agent-3">
  ## General Agent 的使用方法
</div>

<div id="section">
  ### 直接开始聊天
</div>

打开项目并开始聊天。无需先确定要构建什么——Agent 会结合当前项目的上下文工作，几乎可以处理任何任务。

**提示词示例：**

* “请总结这份文档的要点”
* “请创建一份营收排名前 100 的公司的 CSV”
* “Linear 中排名前 5 的工单是什么？”
* “请使用 TypeScript 设置一个 Vue.js 项目”

Agent 可以处理会话期间创建的文件，生成单个文件的输出，并在推理过程中运行代码——这一切都无需你先决定要构建什么。

<div id="section-2">
  ### 连接外部服务
</div>

连接各类工具，让 Agent 可以直接读写数据：

1. 前往项目设置中的**连接器**
2. 连接服务 (BigQuery、Linear、Slack、Notion、Amplitude、Segment、Hex 等)
3. 让 Agent 读写数据

**使用连接器的提示词示例：**

* “Linear 上有哪些未关闭的工单？”
* “总结一下 #engineering 今天的 Slack 消息”
* “从 BigQuery 获取上个月的销售数据”
* “显示日历中即将到来的活动”
* “在 Linear 中为新用户引导的 bug 创建一个工单”
* “把摘要发送到 Slack 的 #engineering”

<div id="section-3">
  ### 从聊天到完整应用
</div>

准备好构建时，只需告诉 Agent。Agent 会从轻量级聊天无缝过渡到应用构建，无需从头开始或切换上下文。

* “把这个做成 Web 应用”
* “基于这些数据构建应用”
* “为这些指标创建仪表板”
* “搭建一个 Rust CLI 工具”

你可以轻松开始：调研主题、生成报告或探索数据，并在合适的时机转而构建完整应用。

<div id="section-4">
  ## 可以构建什么
</div>

* **知识工作**：无需构建应用，即可完成调研、总结和分析
* **单文件产出**：CSV、PDF、文档、数据导出、格式化报告
* **数据应用**：查询已连接的服务，并在仪表板中可视化结果
* **任意框架与语言**：Angular、Vue、Svelte、Rust、Go、C#、Python tkinter、Godot 游戏、CLI 工具等
* **全栈应用**：准备就绪后，直接基于聊天上下文构建完整的应用程序

<div id="section-5">
  ## 可以期待什么
</div>

General Agent 提供更强的能力和更高的灵活性，但结果也会存在一定的波动：

* **一次成型**：Agent 有时能一次性完成全部配置
* **迭代协作**：复杂的配置可能需要多轮打磨
* **技术限制**：部分技术在 Nix 环境中可能无法获得完整支持

<Note>
  与环境已预先配置好的标准 Agent 不同，General Agent 会根据你的请求自行搭建环境并设置命令。准备部署时，你可能需要请它配置发布相关设置。
</Note>

<div id="section-6">
  ## 常见问题
</div>

<Accordion title="Agent 能查看其他项目吗？">
  不能。每次对话都仅限于单个项目内，项目 A 与项目 B 之间无法互通。
</Accordion>

<Accordion title="为什么还无法访问外部工具？">
  你需要先通过连接器接入相应服务。接入后，Agent 才能读写该服务的数据；默认情况下它没有访问权限。
</Accordion>

<Accordion title="有哪些可用的连接器？">
  目前支持：BigQuery、Linear、Slack、Notion、Amplitude、Segment、Hex 等。我们还会定期新增更多连接器。
</Accordion>

<Accordion title="使用 General Agent 需要连接器吗？">
  不需要，连接器是可选的。即使不接入外部服务，你也可以使用 General Agent 进行知识工作、生成文件和构建应用。
</Accordion>
