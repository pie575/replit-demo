⏰ *Durée estimée : 10 minutes*

Il arrive que le design que vous souhaitez utiliser soit déjà disponible sur le web. Il peut s’agir de votre site actuel ou d’une page dont vous souhaitez recréer l’apparence. Import from URL recrée un site web sous forme de frame de conception que vous pouvez explorer, affiner et transformer en application interactive.

Pour cet exemple, nous utiliserons [creative-studio-landing.replit.app](https://creative-studio-landing.replit.app), une page de destination de studio créatif créée par Replit.

<div id="section">
  ## Avant de commencer
</div>

Vous aurez besoin de ce qui suit :

* Un [compte Replit](https://replit.com).
* L’URL d’un site web public ou de l’exemple ci-dessus.

<div id="section-2">
  ## Importer un site web
</div>

<Steps>
  <Step title="Copier l’URL du site">
    Utilisez un site que vous avez créé ou copiez l’URL d’exemple : `https://creative-studio-landing.replit.app`.

    <Frame caption="Site d’exemple : Kosmo Studio, une page de destination pour un studio de création.">
      <img src="/assets/mirror/url-example-site-e0ad60629981.webp" alt="Page de destination de Kosmo Studio avec le slogan « We craft bold ideas and visuals that truly work » et des cartes d’illustrations disposées en éventail en dessous" width="3440" height="2160" data-path="images/design/import-from-url/url-example-site.webp" />
    </Frame>
  </Step>

  <Step title="Ouvrir Replit Design">
    Accédez à [replit.com/design](https://replit.com/design) et sélectionnez **Import URL** sous la zone de prompt. Agent recrée l’apparence du site pour vous offrir un point de départ.

    <Frame caption="Import URL sur la page d’accueil de Replit Design : collez le lien de n’importe quel site web.">
      <img src="/assets/mirror/design-import-url-07a8ac52e188.webp" alt="Page d’accueil de Replit Design avec l’option Import URL sélectionnée et une infobulle indiquant « Paste a link to any website and Agent will recreate its look and feel as a starting point »" width="2293" height="1322" data-path="images/design/import-from-url/design-import-url.webp" />
    </Frame>
  </Step>

  <Step title="Coller l’URL et lancer la création">
    Lorsque vous sélectionnez **Import URL**, le prompt *&quot;Recreate the look and feel of this website:&quot;* est prérempli. Collez ensuite l’URL, puis sélectionnez **Start**.

    <Frame caption="Prompt de recréation prérempli avec l’URL d’exemple, prêt à être lancé.">
      <img src="/assets/mirror/design-url-prompt-b6196aac1b17.webp" alt="Zone de prompt de Replit Design affichant le texte « Recreate the look and feel of this website » suivi de l’URL d’exemple, avec le bouton Start" width="2293" height="1322" data-path="images/design/import-from-url/design-url-prompt.webp" />
    </Frame>
  </Step>
</Steps>

Agent recrée le site sous forme d’un frame de conception dans votre projet.

<Frame caption="Page de destination de Kosmo Studio recréée sous forme d’un frame de conception dans Replit Design.">
  <img src="/assets/mirror/url-import-result-7a4114a468f3.webp" alt="Page de destination de Kosmo Studio recréée sous forme d’un frame de conception dans Replit Design, le panneau de discussion indiquant que l’exécution est terminée" width="1600" height="1004" data-path="images/design/import-from-url/url-import-result.webp" />
</Frame>

<div id="section-3">
  ## Personnalisez-le
</div>

Sélectionnez le frame importé et transformez-le à votre guise :

* **[Suivre les suggestions](/fr/ko/design/explore-suggestions)** : le résultat de l’importation propose des étapes suivantes, comme une variante éditoriale sombre, un viewport mobile ou une page de contact. Chacune est créée dans un nouveau frame afin de conserver l’original pour comparaison.
* **[Discuter dans le Chat](/fr/ko/design/chat-about-your-design)** : utilisez le champ de saisie sous le frame pour décrire directement ce que vous souhaitez. Par exemple : *« Change la photo du portfolio »* ou *« Rends le texte principal plus épais »*.
