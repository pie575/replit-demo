## 플랫폼 업데이트

### Replit Auth

[Replit Auth](/ko/features/auth-and-identity/authentication)가 모든 사용자에게 출시되었습니다! 최소한의 설정으로 앱에 사용자 로그인을 추가할 수 있는 내장 인증 시스템입니다. 처음부터 복잡한 인증 시스템을 빌드하는 대신, Replit Auth는 Replit 인프라와 통합된 안전하고 바로 사용 가능한 솔루션을 제공합니다.

**주요 기능:**

* **설정 불필요** - Agent에서 단 하나의 프롬프트로 인증 추가
* **내장 보안** - 일반적인 공격에 대한 보호 기능이 있는 Replit 인프라 사용
* **사용자 관리** - Auth 창을 통한 간소화된 사용자 관리
* **데이터베이스 통합** - 데이터베이스에 자동 사용자 항목 생성
* **커스터마이즈 가능한 로그인 페이지** - 앱의 로그인 경험 개인화
* **비밀번호 재설정** - Replit이 비밀번호 재설정 이메일을 처리하여 자체 이메일 전송 공급자 불필요

시작하는 것은 간단합니다 - Agent 프롬프트에 Replit Auth 요청을 포함하기만 하면 됩니다:
