# Console

> Console을 사용하여 앱의 출력, 오류, 활동 로그를 확인하는 방법을 알아보세요.

Console을 사용하면 실행 중인 Replit 앱이 출력하는 로그를 실시간으로 모니터링하고 검토할 수 있습니다.
현재 및 이전 실행의 정보를 사용하여 앱의 동작을 이해하고,
오류를 해결하고, 성능을 최적화할 수 있습니다.

<Tip>
  Agent로 디버깅할 때는 컨텍스트를 제공하기 위해 프롬프트에 콘솔 로그를 포함하세요.
</Tip>

## 기능

Console은 앱의 동작을 이해하는 데 도움이 되는 다음 도구를 제공합니다:

* **실시간 로깅**: 앱의 출력을 실시간으로 확인합니다
* **AI 지원**: 로그에 보고된 오류를 수정하기 위한 제안을 받습니다
* **실행 기록**: 변경 사항을 추적하기 위해 이전 실행의 로그를 표시합니다

## 사용법

Project Editor에서 직접 Console 도구에 접근할 수 있습니다.

<Accordion title="Console 접근 방법">
  왼쪽 **도구 독**에서:

  1. <img class="icon-svg" src="https://mintcdn.com/replit/X_IP1EeHGm0cA2VA/images/icons/workspace-all-tools-button.svg?fit=max&auto=format&n=X_IP1EeHGm0cA2VA&q=85&s=579643854fb13c402de516695e52c554" alt="모든 도구 아이콘" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **모든 도구**를 선택하여 Project Editor 도구 목록을 확인합니다.
  2. <img class="icon-svg" src="https://mintcdn.com/replit/rJldsgYVucXB_6kW/images/icons/console.svg?fit=max&auto=format&n=rJldsgYVucXB_6kW&q=85&s=37f7aafac9aa06f60851eb8fffe9e42d" alt="Console 아이콘" width="16" height="16" data-path="images/icons/console.svg" /> **Console**을 선택합니다.

  **검색 바**에서:

  1. 상단의 <img class="icon-svg" src="https://mintcdn.com/replit/X_IP1EeHGm0cA2VA/images/icons/workspace-search-icon.svg?fit=max&auto=format&n=X_IP1EeHGm0cA2VA&q=85&s=d3feed840da2d19e1ee4873d137114dc" alt="돋보기 아이콘" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 돋보기를 선택하여 검색 도구를 엽니다
  2. "Console"을 입력하여 도구를 찾고 결과에서 선택합니다.
</Accordion>

Replit 앱에서 **Run** 버튼을 사용할 때마다 Console은 다음 정보를 포함한 새 항목을 표시합니다:

* 코드를 실행한 Command
* 타임스탬프 정보
* 표준 출력 및 오류 로그

다음 스크린샷은 앱을 시작하는 데 사용된 `npm run dev` 명령과 실행 로그 메시지를 보여줍니다:

### AI 기반 디버깅

로그에서 이해하고 싶은 오류나 정보를 발견하면 항목 상단의
**Ask AI** 버튼을 선택하세요. 이렇게 하면 **Agent** 탭이 자동으로 열리고
분석을 위해 로그 내용이 제출됩니다.

### 로그 항목 명령

Console은 로그를 관리하기 위한 다음 도구를 제공합니다:

* **Show Only Latest**: 이 컨트롤을 **켬**으로 전환하면 가장 최근 실행만 표시됩니다.
* **항목 접기**: 명령 이름 왼쪽의 <img class="icon-svg" src="https://mintcdn.com/replit/rJldsgYVucXB_6kW/images/icons/down-arrow.svg?fit=max&auto=format&n=rJldsgYVucXB_6kW&q=85&s=56bcbb702af7e7700c87fa23be223a9d" alt="아래쪽 화살표 아이콘" height="16" width="16" data-path="images/icons/down-arrow.svg" /> 아래쪽 화살표를 선택하여 로그를 숨깁니다.
* **이전 실행 지우기**: 이전 실행의 로그를 삭제하려면 선택하세요. 이 작업은 되돌릴 수 없습니다.

### 네트워크 가용성

개발 버전 앱의 온라인 가용성을 제어할 수 있습니다.

개발 URL로의 요청 처리를 중단하려면 네트워크 정보 줄 오른쪽의
<img class="icon-svg" src="https://mintcdn.com/replit/rJldsgYVucXB_6kW/images/icons/network-off.svg?fit=max&auto=format&n=rJldsgYVucXB_6kW&q=85&s=83d1529d18164c45a63fab5e340e1320" alt="네트워크 꺼짐 아이콘" height="16" width="16" data-path="images/icons/network-off.svg" /> 슬래시가 있는 지구본 아이콘을 선택하세요.

다시 활성화하려면 <img class="icon-svg" src="https://mintcdn.com/replit/rJldsgYVucXB_6kW/images/icons/network-on.svg?fit=max&auto=format&n=rJldsgYVucXB_6kW&q=85&s=169c03c9769dde9600939635a8b4a5c3" alt="네트워크 켜짐 아이콘" height="16" width="16" data-path="images/icons/network-on.svg" /> 지구본 아이콘을 선택하세요.

개발 URL을 확인하려면 위치 표시줄의 `{...}.replit.dev` 텍스트를 선택하세요.

<Frame>
  <img src="https://mintcdn.com/replit/9NKf1XREDj9JhKJb/images/workspace/preview-dev-url.png?fit=max&auto=format&n=9NKf1XREDj9JhKJb&q=85&s=d7009e0a58f9d0e36cefa654664231b1" alt="Preview 개발 URL 위치" width="1222" height="824" data-path="images/workspace/preview-dev-url.png" />

<Note>
  개발 URL로의 요청 처리를 중단하도록 설정해도 앱은 Preview 탭에서 계속 접근할 수 있습니다.
</Note>

### 워크플로 명령 중지하기

Console Project Editor 도구에서 실행 중인 워크플로 명령을 중지할 수 있습니다.

Replit 앱 실행 명령이 포함된 줄 오른쪽의 정사각형 버튼을 선택하여 종료하세요.

앱을 다시 시작하려면 Project Editor 상단의 워크플로 **Run** 버튼을 사용하세요.
