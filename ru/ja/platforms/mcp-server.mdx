Replit MCP использует [Model Context Protocol](https://modelcontextprotocol.io/), позволяя создавать, искать, просматривать, обновлять и публиковать Replit App из инструментов ИИ, которыми вы уже пользуетесь.

<div id="mcp">
  ## Прямое подключение MCP-клиента
</div>

Если MCP-клиент не имеет встроенной интеграции с Replit, используйте прямое подключение.

| Свойство           | Значение                                |
| ------------------ | --------------------------------------- |
| **URL**            | `https://replit-mcp.com/server/mcp`     |
| **Транспорт**      | Streamable HTTP                         |
| **Аутентификация** | OAuth с обнаружением protected-resource |

Добавьте URL сервера в MCP-клиент, поддерживающий Streamable HTTP и авторизацию OAuth. Клиент прочитает метаданные protected-resource Replit, а затем предложит войти в Replit.

Не создавайте собственный OAuth-сервер. MCP-сервер Replit предоставляет необходимые клиенту метаданные OAuth.

Вы можете создавать новые App или работать с App, для которых у вас есть права на редактирование, включая App, к которым вам предоставлен доступ.

<div id="replit-mcp">
  ### Настройка Replit MCP
</div>

Codex и Claude Code — лишь примеры. Replit MCP можно добавить в любой совместимый MCP-клиент.

<div id="section">
  ## Инструменты
</div>

| Инструмент                | Обязательные параметры        | Необязательные параметры                                  | Назначение                                                                                                                                                                             |
| ------------------------- | ----------------------------- | --------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `create_app_from_prompt`  | `appDescription`, `app_stack` | `userSpecifiedAppName`, `userQuotes`, `attachmentSummary` | Создаёт новое App. `app_stack` может принимать значения `react_website`, `mobile_app`, `design`, `slides`, `animation`, `data_visualization`, `3d_game`, `document` или `spreadsheet`. |
| `search_apps`             | нет                           | `query`, `url`, `updatedAfter`, `updatedBefore`, `limit`  | Ищет App по ключевым словам в названии, URL или времени последнего обновления. `limit` может быть от 1 до 50.                                                                          |
| `resolve_app_by_name`     | `name`                        | нет                                                       | Ищет одно App по точному названию.                                                                                                                                                     |
| `list_apps`               | нет                           | `query`, `limit`                                          | Выводит список App, доступных для редактирования, в порядке недавней активности. Ограничение по умолчанию — 25, максимальное — 50.                                                     |
| `ask_question`            | `replId`, `question`          | нет                                                       | Задаёт Agent вопрос об App, не изменяя его.                                                                                                                                            |
| `update_app_using_prompt` | `replId`, `changeDescription` | `userQuotes`, `attachmentSummary`                         | Запускает обновление существующего App с помощью Agent.                                                                                                                                |
| `publish_app`             | `replId`                      | нет                                                       | Публикует App или повторно публикует последние изменения.                                                                                                                              |
| `get_publish_status`      | `replId`                      | нет                                                       | Проверяет, опубликовано ли App, его текущий статус публикации и URL публикации.                                                                                                        |

<div id="section-2">
  ## Устранение неполадок
</div>

| Проблема                                                          | Решение                                                                                                                                  |
| ----------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| Replit запрашивает аутентификацию                                 | Повторно выполните вход через OAuth из MCP-клиента.                                                                                      |
| Не удаётся найти App                                              | Убедитесь, что у вас есть права на редактирование этого App. Затем найдите его по URL или выберите подходящий App с помощью `list_apps`. |
| Запрос на создание, обновление или публикацию всё ещё выполняется | Подождите, прежде чем повторять попытку. При публикации проверьте текущий статус с помощью `get_publish_status`.                         |
