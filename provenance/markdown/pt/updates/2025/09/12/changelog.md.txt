export const YouTubeEmbed = ({videoId, title = "YouTube video", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

## Lançamento do Agent 3

Esta semana, lançamos o Agent 3.

<YouTubeEmbed videoId="4FxNXFOdt6w" title="Transmissão ao vivo do lançamento do Agent 3" />

O Agent 3 oferece grandes avanços em autonomia, confiabilidade e velocidade:

* **Teste de App**: O Agent se autotesta em um navegador real, encontra problemas e os corrige em um ciclo de reflexão. Veja [Teste de App](/pt/core-concepts/agent/app-testing).
* **Tempo de execução mais longo**: O Agent pode trabalhar de forma autônoma por até 200 minutos com Monitoramento ao Vivo, ideal para criações maiores. Saiba mais em [Agent](/pt/core-concepts/agent#max-autonomy).
* **Geração de agentes**: Crie agentes e automações que são executados em agendamentos ou se integram ao Slack e Telegram. Veja [Agentes e Automações](/pt/core-concepts/agent/agents-and-automations).

## Conectores e integrações de app

Publique mais rapidamente com integrações e conectores integrados:

* **Gerenciado pelo Replit**: Integrações integradas que funcionam automaticamente nos seus apps.
* **Connectors**: Integrações de primeira parte nas quais você pode fazer login uma vez e reutilizar em todos os apps.
* **Integrações externas**: Serviços de terceiros confiáveis configurados pelo Agent, usando suas chaves de API.
