<div id="section">
  ## Ce que vous pouvez créer
</div>

Utilisez Agent pour ajouter Stripe à votre application en un clic, sans aucune configuration supplémentaire. Créez une boutique en ligne, acceptez des paiements ponctuels ou mettez en place des abonnements : Agent se charge de connecter l&#39;intégration, le modèle de données et l&#39;environnement de test.

<div id="section-2">
  ## Fonctionnement
</div>

Agent commence par un sandbox Stripe, ce qui vous permet de tester les paiements en toute sécurité, sans aucun mouvement d&#39;argent réel. Vous pouvez créer vos flux et les essayer immédiatement. Lorsque vous êtes prêt, basculez vers un compte Stripe en production pour publier votre application et accepter de vrais paiements.

<Info>
  Le sandbox Stripe est un environnement de test isolé qui permet de simuler des paiements, des abonnements et des événements.
  Pour en savoir plus, consultez la [documentation Stripe sur les sandbox](https://docs.stripe.com/sandboxes).
</Info>

<div id="stripe">
  ## Utiliser Stripe avec les Teams
</div>

Stripe fonctionne dans les espaces de travail collaboratifs, ce qui permet à toute votre équipe de développer, tester et monétiser la même application. Toutes les personnes de l’espace de travail peuvent utiliser le compte Stripe connecté, sans qu’une seule personne ait à développer les fonctionnalités de paiement.

<div id="section-3">
  ## Prise en main
</div>

* **Demander à Agent d&#39;utiliser Stripe**
  * Depuis l&#39;écran d&#39;accueil, utilisez une commande slash et sélectionnez Stripe, ou formulez directement votre demande :
    <AiPrompt>Build a storefront and integrate Stripe for payments</AiPrompt>

<Note>
  L&#39;intégration de Stripe nécessite une application dotée de fonctionnalités backend. Pour commencer, sélectionnez **Application** sur la page d&#39;accueil.
</Note>

<div id="section-4">
  ## Tester les paiements dans le sandbox
</div>

1. Ouvrez l&#39;**aperçu** de votre application dans un nouvel onglet.
2. Effectuez un achat test depuis la boutique ou la page de paiement.
3. Utilisez les cartes de test standard de Stripe :

```text theme={null}
Numéro de carte : 4242 4242 4242 4242
Expiration : toute date future
CVC : 3 chiffres au choix
Nom, adresse : valeurs fictives au choix
```

<Tip>
  Les achats en sandbox ne transitent pas par le réseau réel et ne donnent lieu à aucun mouvement d&#39;argent.
  Vous pouvez donc tester en toute sécurité, de bout en bout.
</Tip>

<div id="section-5">
  ## Gérer les produits et les tarifs
</div>

Vous avez deux options :

1. Dans votre application, sélectionnez **Publier**, puis choisissez de revendiquer le sandbox Stripe.
   * Si vous n&#39;avez pas encore de compte Stripe, créez-en un pour revendiquer le sandbox.
2. Dans le tableau de bord Stripe, ouvrez **Produits** pour ajouter ou modifier des produits et des tarifs.
   Les modifications effectuées dans votre sandbox Stripe sont automatiquement répercutées dans votre application Replit et synchronisées avec la base de données de l&#39;application.

<div id="stripe-2">
  ### Consulter les données Stripe synchronisées
</div>

* Dans l&#39;éditeur de projet, ouvrez **Base de données**.
* Sélectionnez **MyData**.
* Basculez le sélecteur de schéma sur **Stripe** pour consulter les objets de paiement et les enregistrements associés.

<div id="section-6">
  ## Passer en production
</div>

Pour accepter de vrais paiements, connectez votre compte Stripe de production en installant l&#39;application
[Replit Integrated Payments](https://marketplace.stripe.com/apps/replit-integrated-payments)
depuis la marketplace Stripe. Le processus d&#39;installation connecte automatiquement votre compte de production — aucune clé API à copier-coller.

<Warning>
  L&#39;intégration en sandbox n&#39;est pas destinée à la production. Vous ne pourrez pas accepter de vrais paiements tant que vous n&#39;aurez pas suivi les étapes ci-dessous.
</Warning>

<Steps>
  <Step title="Ouvrir la fenêtre de publication">
    Dans votre app, sélectionnez **Publier** pour lancer le processus de connexion en production.
  </Step>

  <Step title="Installer l'application Replit Integrated Payments">
    Sélectionnez **Install Stripe app**. Une fenêtre Stripe s&#39;ouvre et affiche la fiche
    [Replit Integrated Payments](https://marketplace.stripe.com/apps/replit-integrated-payments).

    Lorsque Stripe vous invite à choisir un compte, sélectionnez votre compte Stripe **de production** — et non un compte sandbox ou de test.
  </Step>

  <Step>
    Suivez les instructions de Stripe pour installer l&#39;application. Si votre compte de production n&#39;est pas encore activé, Stripe vous guide d&#39;abord dans la procédure de vérification d&#39;entreprise (KYB).

    Laissez la fenêtre Stripe ouverte jusqu&#39;à la fin de l&#39;installation.
    Une fois l&#39;installation confirmée par Stripe, Replit finalise la connexion de production en arrière-plan.
  </Step>

  <Step title="Publier votre app">
    Revenez sur Replit. La fenêtre **Publier** indique que votre compte Stripe de production est connecté. Publiez votre app pour commencer à accepter de vrais paiements.
  </Step>
</Steps>

<Note>
  L&#39;installation de l&#39;application Replit Integrated Payments remplace l&#39;ancienne méthode, qui consistait à copier directement vos clés publique et secrète dans Replit. L&#39;application configure vos clés de production et maintient la synchronisation entre le sandbox et la production.
</Note>

<div id="section-7">
  ## Gérer les intégrations
</div>

* Accédez à **Intégrations &gt; Stripe** pour ouvrir le connecteur Stripe.
* Vous pouvez tester la connexion, vérifier son état et gérer les paramètres.

<div id="section-8">
  ## Questions fréquentes
</div>

<div id="section-9">
  ### Comment mettre à jour le prix d&#39;un produit ?
</div>

* Demandez-le à Agent : décrivez la modification et Agent met à jour votre application ainsi que les objets Stripe.
* Utilisez le tableau de bord Stripe : ouvrez **Produits** pour modifier les prix et les détails des produits.
  * En sandbox, les modifications sont automatiquement resynchronisées avec votre application et votre base de données.
  * En production, basculez d&#39;abord sur votre compte de production, puis mettez à jour les prix. Republiez l&#39;application si elle doit récupérer la nouvelle configuration.

<div id="replit">
  ### Comment tester les transactions sur Replit ?
</div>

Ouvrez l’**aperçu** de votre application dans un nouvel onglet. Effectuez le checkout Stripe avec la carte de test standard (4242 4242 4242 4242), une date d’expiration future au choix et un CVC au choix. Pour plus d’informations, consultez la section [Tester les paiements dans le bac à sable](#샌드박스에서-결제-테스트하기) ci-dessus.

<div id="stripe-3">
  ### Qu&#39;est-ce qu&#39;un compte Stripe en mode production ?
</div>

Un compte Stripe en mode production est un compte activé et vérifié qui permet de traiter de vrais paiements à partir des informations de votre entreprise. Consultez le guide Stripe sur la création et l&#39;activation d&#39;un compte : [Créer et gérer un compte Stripe](https://docs.stripe.com/get-started/account).

<div id="stripe-api">
  ### Dois-je coller moi-même mes clés API Stripe ?
</div>

Non. L&#39;application Replit Integrated Payments configure automatiquement les clés de production lorsqu&#39;elle connecte votre compte Stripe en mode production. Vous n&#39;avez pas besoin de copier vos clés de production depuis le tableau de bord Stripe.

Si vous aviez connecté Stripe auparavant en collant vous-même vos clés de production, cette connexion reste fonctionnelle. Pour passer à l&#39;installation via l&#39;application Stripe, supprimez la connexion Stripe dans la fenêtre **Publier**, puis reconnectez-vous. Consultez [Mettre à jour ou supprimer la connexion Stripe](#stripe-연결-업데이트-또는-제거하기) ci-dessous.

<div id="stripe-4">
  ## Mettre à jour ou supprimer la connexion Stripe
</div>

Si vous n&#39;êtes pas prêt à publier avec une connexion Stripe en production, deux options s&#39;offrent à vous :

<div id="a-stripe">
  ### Option A : supprimer manuellement l’intégration Stripe
</div>

Vous pouvez supprimer entièrement l’intégration Stripe de votre projet.

<Steps>
  <Step title="Ouvrir l’onglet Intégrations">
    Accédez à votre application Replit et sélectionnez l’onglet **Intégrations** en haut de la page. Sous **Connecteurs**, recherchez **Stripe**, puis sélectionnez **Gérer**.

    <Frame>
      <img src="/assets/mirror/stripe-disconnect-1-integrations-371e1e7e5609.png" alt="Onglet Intégrations affichant l’intégration Stripe et le bouton Gérer sous Connecteurs" width="2000" height="1110" data-path="images/replitai/stripe-disconnect-1-integrations.png" />
    </Frame>
  </Step>

  <Step title="Développer les clés API">
    Sélectionnez le chevron pour développer **Sandbox API keys** et **Live account API keys**, puis sélectionnez **Edit**.

    <Frame>
      <img src="/assets/mirror/stripe-disconnect-2-edit-keys-4e9e76c4065f.png" alt="Clés API Stripe de l’environnement sandbox et du compte de production développées avec le bouton Edit" width="2000" height="1274" data-path="images/replitai/stripe-disconnect-2-edit-keys.png" />
    </Frame>
  </Step>

  <Step title="Déconnecter les comptes">
    Sélectionnez **Disconnect account** pour supprimer la connexion sandbox, puis **Disconnect live account** pour supprimer la connexion de production.

    <Frame>
      <img src="/assets/mirror/stripe-disconnect-3-disconnect-f4257f534c5c.png" alt="Clés API Stripe de l’environnement sandbox et du compte de production avec les boutons Disconnect account et Disconnect live account" width="2000" height="1271" data-path="images/replitai/stripe-disconnect-3-disconnect.png" />
    </Frame>
  </Step>

  <Step title="Demander à Agent de supprimer le code Stripe">
    Accédez au chat Agent et demandez à Agent de supprimer le code du connecteur Stripe de votre application. L’intégration Stripe sera alors entièrement supprimée.
  </Step>
</Steps>

<div id="b-stripe">
  ### Option B : revenir à un checkpoint antérieur à l&#39;intégration Stripe
</div>

Pour annuler complètement l&#39;intégration Stripe et revenir à l&#39;état précédent, vous pouvez restaurer un checkpoint antérieur.

<Steps>
  <Step title="Ouvrir l'onglet Intégrations">
    Accédez à votre app Replit et sélectionnez l&#39;onglet **Intégrations** en haut. Sous **Connecteurs**, repérez **Stripe** et sélectionnez **Gérer**.

    <Frame>
      <img src="/assets/mirror/stripe-disconnect-1-integrations-371e1e7e5609.png" alt="Onglet Intégrations affichant l'intégration Stripe et le bouton Gérer dans les connecteurs" width="2000" height="1110" data-path="images/replitai/stripe-disconnect-1-integrations.png" />
    </Frame>
  </Step>

  <Step title="Déplier les clés API">
    Sélectionnez le chevron pour déplier **Sandbox API keys** et **Live account API keys**, puis sélectionnez **Edit**.

    <Frame>
      <img src="/assets/mirror/stripe-disconnect-2-edit-keys-4e9e76c4065f.png" alt="Clés API du compte sandbox et du compte de production Stripe dépliées avec le bouton Modifier" width="2000" height="1274" data-path="images/replitai/stripe-disconnect-2-edit-keys.png" />
    </Frame>
  </Step>

  <Step title="Déconnecter le compte">
    Sélectionnez **Disconnect account** pour supprimer la connexion sandbox, et **Disconnect live account** pour supprimer la connexion de production.

    <Frame>
      <img src="/assets/mirror/stripe-disconnect-3-disconnect-f4257f534c5c.png" alt="Clés API du compte sandbox et du compte de production Stripe avec les boutons Déconnecter le compte et Déconnecter le compte de production" width="2000" height="1271" data-path="images/replitai/stripe-disconnect-3-disconnect.png" />
    </Frame>
  </Step>

  <Step title="Trouver un checkpoint antérieur à l'intégration Stripe">
    Accédez au chat Agent et recherchez un checkpoint créé avant l&#39;intégration Stripe. Sélectionnez l&#39;**icône d&#39;horloge** en haut à gauche de la fenêtre de chat pour consulter l&#39;historique de chat plus ancien.

    <Frame>
      <img src="/assets/mirror/stripe-rollback-5-clock-icon-c54cd19246ea.png" alt="Icône d'horloge permettant de consulter l'historique de chat et les checkpoints" width="56" height="50" data-path="images/replitai/stripe-rollback-5-clock-icon.png" />
    </Frame>
  </Step>

  <Step title="Sélectionner Revenir ici">
    Lorsque vous trouvez un checkpoint qui vous convient, sélectionnez **Revenir ici** pour restaurer le projet dans cet état.

    <Frame>
      <img src="/assets/mirror/stripe-rollback-6-checkpoint-2f195b0ea9ce.png" alt="Checkpoint avec le bouton Revenir ici" width="904" height="202" data-path="images/replitai/stripe-rollback-6-checkpoint.png" />
    </Frame>
  </Step>
</Steps>

<div id="section-10">
  ## Remarques et limites
</div>

* Les activités dans le sandbox n’ont aucune incidence sur les soldes réels ni sur les clients.
* Certaines fonctionnalités de Stripe ne peuvent pas être testées dans le sandbox (par exemple, la tarification IC+ et certains flux Connect). Consultez les [limites du sandbox Stripe](https://docs.stripe.com/sandboxes).
