  const AGENT_INPUT_PAUSE_AFTER = 2000;
  const AGENT_INPUT_START_DELAY = 500;
  const getAgentInputTypewriterLoader = () => {
    if (typeof window === "undefined") {
      return null;
    }
    if (!window.__replitDocsAgentInputTypewriterLoader) {
      window.__replitDocsAgentInputTypewriterLoader = {};
    }
    return window.__replitDocsAgentInputTypewriterLoader;
  };
  const ensureAgentInputTypewriterCore = () => {
    if (typeof window === "undefined" || typeof document === "undefined") {
      return Promise.resolve(null);
    }
    if (window.Typewriter) {
      return Promise.resolve(window.Typewriter);
    }
    const loader = getAgentInputTypewriterLoader();
    if (loader.promise) {
      return loader.promise;
    }
    loader.promise = new Promise((resolve, reject) => {
      const handleLoad = () => {
        if (window.Typewriter) {
          resolve(window.Typewriter);
          return;
        }
        loader.promise = null;
        reject(new Error("Typewriter core loaded without a global Typewriter export."));
      };
      const handleError = () => {
        loader.promise = null;
        reject(new Error("Failed to load typewriter core."));
      };
      const existingScript = document.getElementById(AGENT_INPUT_TYPEWRITER_SCRIPT_ID);
      if (existingScript) {
        existingScript.addEventListener("load", handleLoad, {
          once: true
        });
        existingScript.addEventListener("error", handleError, {
          once: true
        });
        return;
      }
      const script = document.createElement("script");
      script.id = AGENT_INPUT_TYPEWRITER_SCRIPT_ID;
      script.src = AGENT_INPUT_TYPEWRITER_SRC;
      script.async = true;
      script.addEventListener("load", handleLoad, {
        once: true
      });
      script.addEventListener("error", handleError, {
        once: true
      });
      document.head.appendChild(script);
    });
    return loader.promise;
  };

    if (typeof window === "undefined") {
      return null;

    startButton: container?.querySelector?.('[data-agent-input-role="start-button"]') || null,
    pillsContainer: container?.querySelector?.('[data-agent-input-role="pills"]') || null

    const {textarea} = getAgentInputElements(container);
    return textarea?.value?.trim() || "";
  };
  const updateAgentInputButtonState = container => {
    const {startButton} = getAgentInputElements(container);
    if (!startButton) {
      return;
    }
    const hasText = getAgentInputPromptValue(container).length > 0;
    startButton.style.opacity = hasText ? "1" : "0.4";
    startButton.style.cursor = hasText ? "pointer" : "not-allowed";
  };
  const stopAgentInputTypewriter = (textarea, {placeholder, clearDemo = false} = {}) => {
    if (typeof window === "undefined" || !textarea) {
      return;
    }
    const registry = getAgentInputTypewriterRegistry();
    const record = registry?.get(textarea);
    if (!record) {
      if (placeholder) {
        textarea.setAttribute("placeholder", placeholder);
      }
      return;
    }
    record.stopped = true;
    if (record.startTimer) {
      window.clearTimeout(record.startTimer);
    }
    if (record.writeFrame) {
      window.cancelAnimationFrame(record.writeFrame);
    }
    if (record.typewriter?.stop) {
      record.typewriter.stop();
    }
    textarea.removeEventListener("focus", record.handleFocus);
    textarea.removeEventListener("pointerdown", record.handlePointerDown);
    textarea.removeEventListener("input", record.handleInput);
    if (clearDemo && textarea.value === record.pendingValue) {
      textarea.value = "";
    }
    textarea.setAttribute("placeholder", placeholder || "");

    registry.delete(textarea);

      return;

      return;

Agent peut faire beaucoup de choses, mais il donne le meilleur de lui-même lorsque c&#39;est vous qui menez le processus : soyez précis, planifiez le travail, ajoutez du contexte, vérifiez et testez, et utilisez les checkpoints lorsqu&#39;il faut revenir en arrière.

<div id="section">
  ## Soyez précis
</div>

Agent peut gérer des tâches complexes, mais il a besoin d&#39;orientations claires.

Une requête utile explique ce que vous voulez, ce qui est important et ce qui ne doit pas changer. Il n&#39;est pas nécessaire de décrire tous les détails de l&#39;implémentation, mais vous devez donner à Agent suffisamment d&#39;éléments pour prendre de bonnes décisions.

Au lieu de dire ceci :

<AiPrompt>
  Améliore mon app.
</AiPrompt>

Essayez plutôt ceci :

<AiPrompt>
  Améliore la page d&#39;inscription afin que les visiteurs comprennent ce que fait le produit avant de créer un compte.<br />
  Conserve la palette de couleurs actuelle, garde les mêmes champs de formulaire et rends le bouton principal plus visible.
</AiPrompt>

Le deuxième prompt donne à Agent un objectif, des points d&#39;attention et des contraintes.

Si votre requête comporte plusieurs parties, indiquez ce qui compte le plus.

<AiPrompt>
  Ajoute une interface d&#39;administration simple pour gérer les demandes de service traiteur.<br />
  Le plus important est de pouvoir consulter les nouvelles demandes, les marquer comme traitées et les filtrer par statut.<br />
  Garde la première version simple.
</AiPrompt>

Agent peut décomposer cette tâche en étapes, mais vos indications définissent à quoi ressemble la réussite.

Pour d&#39;autres exemples d&#39;instructions précises, consultez les [prompts efficaces](/fr/ja/learn/effective-prompting).

</div>

Agent peut proposer un plan avant de se lancer dans la construction, puis résumer ce qui a changé après les modifications. Lisez les deux.

Sélectionnez **Afficher** sur la carte du plan de tâche pour ouvrir le plan. Le plan développé indique ce qu&#39;Agent va construire, les critères de réussite, ce qui est hors périmètre et les étapes qu&#39;Agent va suivre.

Avant qu&#39;Agent ne se lance, passez le plan en revue :

* Est-ce que cela résout le bon problème ?
* Manque-t-il quelque chose ?
* Y a-t-il des éléments hors périmètre ?
* Existe-t-il une version plus réduite à construire en premier ?
* Est-il expliqué comment tester le résultat ?

Si le plan est trop large, demandez à Agent de le réduire.

<AiPrompt>
  This plan is too broad.<br />
  Reduce it to the smallest version I can test today.<br />
  Move everything else into a future improvements list.
</AiPrompt>

Une fois qu&#39;Agent a terminé, testez l&#39;app vous-même. Ouvrez le Preview et utilisez-la comme le ferait la personne à qui elle est destinée.

À vérifier :

* Quelqu&#39;un peut-il accomplir l&#39;action principale ?
* Les modifications demandées ont-elles bien été effectuées ?
* L&#39;app fonctionne-t-elle aussi sur mobile ?
* Un comportement important est-il cassé ?
* Agent a-t-il modifié des éléments sans rapport ?
* Le résultat est-il suffisant pour continuer à construire ?

<AiPrompt>

<AiPrompt>
  This is close, but the form is now too long.<br />
  Keep the new visual style, remove the optional notes field, and make the pickup date easier to scan.
</AiPrompt>

Utilisez un checkpoint si l&#39;app est moins bonne qu&#39;avant, si un comportement important ne fonctionne plus, ou si Agent a modifié plus de choses que prévu.

Ouvrez History dans le panneau Agent pour consulter les checkpoints. Chaque checkpoint indique ce qui a changé et propose les contrôles **Revenir ici** et **Modifications**.

Lorsque vous sélectionnez **Revenir ici**, Agent vous confirme ce qui sera restauré avant d&#39;appliquer le retour en arrière.

<Frame>
  <img src="/assets/mirror/agent-checkpoints-rollback-dialog-28de278b44da.png" alt="Boîte de dialogue de confirmation de retour à un checkpoint, listant le checkpoint ciblé et les éléments concernés (fichiers, mémoire d'Agent, tâches, cases à cocher de base de données)" width="900" height="880" data-path="images/fitstart/work-with-agent/agent-checkpoints-rollback-dialog.png" />
</Frame>

Si vous hésitez entre corriger en avançant ou revenir en arrière, demandez à Agent de vous aider à comparer.

<AiPrompt>
  The last change made the app worse.<br />
  Compare the current version to the previous working version.<br />
  Tell me whether it is safer to fix forward or roll back, and explain why.
</AiPrompt>

Il est normal de partir dans une mauvaise direction. Les checkpoints vous permettent d&#39;explorer sans perdre la possibilité de revenir à une version plus sûre.

Pour plus de conseils sur la récupération, consultez [Checkpoints et retours en arrière](/fr/ja/features/version-control/checkpoints-and-rollbacks).

<div id="agent">
  ## Qu&#39;est-ce qu&#39;une bonne collaboration avec Agent
</div>

Vous êtes sur la bonne voie si :

* votre demande explique l&#39;objectif et les contraintes ;
* le plan d&#39;Agent est suffisamment clair pour être relu ;
* vous ajoutez des captures d&#39;écran, des fichiers ou des annotations Canvas lorsque les mots ne suffisent pas ;
* vous testez les parcours importants après chaque modification ;
* vous donnez un retour ciblé lorsque quelque chose ne va pas ;
* vous utilisez les checkpoints plutôt que de tenter indéfiniment de démêler une modification ratée.
