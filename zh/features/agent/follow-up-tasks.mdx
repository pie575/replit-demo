<div id="follow-up-task-suggestions">
  ## 后续任务建议
</div>

应用某个任务后，Agent 会分析你的 project 上下文，并建议你接下来可能想构建的**后续任务**。**Suggested next tasks** 对话框会直接内嵌显示最推荐的一项，让你无需离开主对话即可继续推进。

<Frame>
  <img src="/assets/mirror/follow-up-tasks-dialog-c1660cec2d1d.png" alt="建议的后续任务对话框，显示一个后续任务，带有开始按钮以及在任务看板中查看更多任务的链接" width="495" height="290" data-path="images/agent/follow-up-tasks-dialog.png" />
</Frame>

后续建议可能包括：

* **可构建的新功能**：与你刚刚上线的内容天然契合的能力
* **性能改进**：Agent 在处理该任务时发现的优化点
* **用户体验提升**：让功能更加完善的打磨与细化

在某条建议上选择 **Start**，即可将其放到后台执行；或选择 **View plan**，先查看拟议的工作内容。若要查看全部建议，请选择 **View more in the task board**。建议的后续任务会显示在 **Drafts** 列的 **Suggested** 分组下。

<Frame>
  <img src="/assets/mirror/follow-up-tasks-kanban-21087e0210b6.png" alt="任务看板，在 Drafts 列的 Suggested 下方显示多条后续任务建议" width="980" height="627" data-path="images/agent/follow-up-tasks-kanban.png" />
</Frame>

关闭 **Suggested next tasks** 对话框即表示取消这些建议。如果主版本上已有等待处理的拟议方案，Agent 不会再显示该对话框，避免两个提示同时争夺你的注意力。

<div id="managing-many-suggestions-at-once">
  ## 批量管理多条建议
</div>

如果 project 中有很多后续建议，可以打开任务看板，在 **Drafts** 列中选择 **Edit**。进入编辑模式后，每条建议任务前都会出现一个复选框。勾选需要的任务，然后使用 **Start** 或 **Cancel** 对所有选中的任务执行相应操作。选择 **Done** 即可退出编辑模式。
