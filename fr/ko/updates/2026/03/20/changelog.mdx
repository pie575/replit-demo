<div id="microsoft-app-store-replit-pwa">
  ### Replit PWA sur le Microsoft App Store
</div>

Replit est désormais disponible sur le Microsoft App Store sous forme de Progressive Web App (PWA) : les créateurs sous Windows peuvent ainsi découvrir et installer Replit facilement, comme une application quasi native.

<div id="section-3">
  ### Création d&#39;un projet vide
</div>

Vous pouvez désormais créer un projet vide depuis la page d&#39;importation. Un projet vide ne déclenche pas Agent au démarrage : aucun crédit n&#39;est donc consommé à la création, et vous gardez un contrôle total sur la configuration du framework et des outils. Cette option est disponible sur la page d&#39;importation pour les créateurs qui souhaitent ce niveau de contrôle.

<div id="section-4">
  ## Équipes et Enterprise
</div>

<div id="section-5">
  ### Portail des journaux d&#39;audit Enterprise
</div>

Le portail des journaux d&#39;audit Enterprise (v1) est désormais accessible à tous les clients Enterprise. Les administrateurs peuvent consulter les événements réalisés par les membres de l&#39;organisation et configurer l&#39;intégration du flux d&#39;événements avec la plateforme SIEM de leur choix, notamment S3, Datadog, Splunk, Google Cloud Storage et Microsoft Sentinel.
