<div id="correspondncia-mais-inteligente-de-integraes">
  ### 更智能的集成匹配
</div>

Agent 现在能更准确地判断何时在新的 Chat 中添加外部工具和服务。不妨新建一个 Chat，输入以下 prompt 试试：

<AiPrompt>
  Add AI with Anthropic to my app
</AiPrompt>

在 Agent 将你的应用与外部服务连接时，你会得到更精准的结果，从而更快构建出功能更强大的应用。

<div id="respostas-de-ia-mais-rpidas">
  ### AI 响应更快
</div>

AI 系统全面提速，响应速度大幅提升：

* 与 Agent 和 Assistant 的交互近乎即时
* 响应更快，对话更流畅
* 创建和迭代应用比以往更加顺畅

<div id="ux-de-progresso-do-agent-simplificada">
  ### 简化的 Agent 进度体验
</div>

全新的“预览”面板取代了原有的“进度”和“Webview”面板，并被放在醒目位置，从而省去了输出抽屉。这项改进让你在构建应用时保持专注，无需深入代码。浮动横幅还会提供实用提示，在构建过程中为你指引方向。
