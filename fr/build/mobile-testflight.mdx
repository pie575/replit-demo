TestFlight est l’app d’Apple qui permet de tester des apps avant leur publication. Les testeurs installent
TestFlight, puis y accèdent à PixelGames. Elle distribue une build que vous avez déjà
[téléversée](/fr/build/mobile-upload-ios).

<div id="test-it-yourself">
  ## Testez par vous-même
</div>

Vous pouvez commencer dès que le téléversement est terminé. Apple vous envoie une invitation pour votre propre build.
Sélectionnez **View in TestFlight** pour installer PixelGames sur votre téléphone, comme expliqué dans
[téléverser votre app](/fr/build/mobile-upload-ios).

PixelGames fonctionne désormais comme une app autonome. Vous pouvez donc tester les notifications push, les achats intégrés,
Sign in with Apple et tout ce qui nécessite une véritable app installée.

<div id="invite-other-testers">
  ## Inviter d’autres testeurs
</div>

Pour permettre à d’autres personnes d’essayer PixelGames sans être à proximité de votre ordinateur, ajoutez-les en tant que testeurs dans
App Store Connect.

<Steps>
  <Step title="Créer un groupe de testeurs">
    Dans App Store Connect, ouvrez PixelGames et sélectionnez l’onglet **TestFlight**. Dans la barre latérale,
    sélectionnez **+** à côté de **External Testing**.

    <Frame caption="L’onglet TestFlight, avec le + à côté d’External Testing dans la barre latérale.">
      <img src="/assets/mirror/testers-step1-4f2a5a07c998.png" alt="Onglet TestFlight d’App Store Connect avec le bouton plus d’External Testing mis en évidence" data-path="images/pixelgames/mobile/testers-step1.png" width="1555" height="772" data-path="images/pixelgames/mobile/testers-step1.png" />
    </Frame>
  </Step>

  <Step title="Nommer le groupe">
    Donnez-lui un nom que vous reconnaîtrez facilement, comme **Beta Testers**, puis sélectionnez **Create**.

    <Frame caption="Attribution d’un nom au nouveau groupe de testeurs externes.">
      <img src="/assets/mirror/testers-step2-fc83fcac6046.png" alt="Boîte de dialogue Create a New Group avec Beta Testers saisi comme nom du groupe" data-path="images/pixelgames/mobile/testers-step2.png" width="1561" height="717" data-path="images/pixelgames/mobile/testers-step2.png" />
    </Frame>
  </Step>

  <Step title="Ajouter un build, puis inviter des testeurs">
    Sur la page du groupe, sélectionnez **Add Builds** pour choisir le build que recevront les testeurs, puis
    **Invite Testers** pour les ajouter par e-mail. Chacun recevra une invitation.

    <Frame caption="Page du nouveau groupe, avec Add Builds et Invite Testers à effectuer.">
      <img src="/assets/mirror/testers-step3-c0b22a92c728.png" alt="Page du groupe Beta Testers affichant les étapes Add Builds et Invite Testers" data-path="images/pixelgames/mobile/testers-step3.png" width="1592" height="739" data-path="images/pixelgames/mobile/testers-step3.png" />
    </Frame>
  </Step>

  <Step title="Les testeurs installent TestFlight, puis PixelGames">
    Les testeurs installent l’app gratuite **TestFlight** depuis l’App Store, acceptent votre invitation et
    installent PixelGames depuis celle-ci. Les mises à jour sont disponibles de la même façon.
  </Step>
</Steps>

<Note>
  Les groupes externes sont soumis à l’App Review bêta d’Apple avant que les testeurs puissent installer l’app, ce qui prend généralement
  environ une journée pour le premier build. Les testeurs ajoutés sous **Internal Testing** peuvent installer l’app immédiatement.
</Note>

<div id="troubleshooting">
  ## Résolution des problèmes
</div>

* **Le testeur n&#39;a pas reçu l&#39;invitation :** vérifiez l&#39;adresse e-mail dans App Store Connect et
  demandez-lui de vérifier ses spams.
* **La build fonctionne pour vous, mais pas pour les testeurs :** vérifiez qu&#39;ils utilisent la même version de build ; un
  ancien lien d&#39;invitation peut renvoyer vers une build obsolète.
* **Le testeur a perdu l&#39;accès à l&#39;application :** les builds TestFlight expirent après 90 jours ; c&#39;est généralement
  la raison. Soumettez une nouvelle build.
