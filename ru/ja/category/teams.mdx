Выберите подходящий для вашей организации план. **Pro** — командный план для не более чем 15 разработчиков с общим пулом кредитов и без платы за каждого пользователя. **Enterprise** предлагает крупным организациям расширенные возможности безопасности, соответствия требованиям и поддержки. Если у вас несколько организаций Teams, каждое рабочее пространство будет переведено на отдельную подписку Pro на оставшийся период. После переноса их можно объединить.

<div id="pro">
  ## Pro
</div>

Pro предоставляет общие ресурсы и возможности для совместной работы профессиональным разработчикам и командам.

* **До 15 разработчиков**: без оплаты за каждое место — все используют общий пул кредитов в рамках одного плана
* **Многоуровневые кредиты**: несколько уровней. Неиспользованные кредиты переносятся на {ProCreditRolloverPeriod}. Текущие уровни указаны на [странице тарифов](https://replit.com/pricing)
* **режим Turbo**: Agent работает в 2,5 раза быстрее благодаря отдельному переключателю, который по умолчанию выключен. Доступен в Pro и Enterprise; в Enterprise администратор сначала включает его для всей организации.
* **Приватные развертывания**: безопасный хостинг приложений с контролем доступа
* **Места для зрителей**: позволяют заинтересованным лицам и пользователям, не занимающимся разработкой, использовать опубликованные приватные приложения
* **Настройки интеграций**: организуйте приложения в одном месте, отслеживайте использование по рабочим пространствам и управляйте выставлением счетов и пользователями

<div id="enterprise">
  ## Enterprise
</div>

Enterprise включает все функции Pro, а также усиленные средства безопасности, управления и поддержки для организаций.

<CardGroup cols={2}>
  <Card title="Безопасность Enterprise" icon="shield-check">
    Платформа, соответствующая SOC 2, с SSO/SAML, подготовкой пользователей через SCIM и расширенными средствами безопасности.
  </Card>

  <Card title="Централизованное управление" icon="folder-open">
    Управляйте командами, выставлением счетов и ресурсами из единой панели управления. Отслеживайте использование и эффективно контролируйте расходы.
  </Card>
</CardGroup>

* **SSO/SAML с подготовкой пользователей через SCIM**: защитите доступ команды с помощью единого входа и автоматической подготовки пользователей
* **Выделенные среды разработки**: ролевое управление доступом с использованием групп IdP для детальной настройки разрешений
* **Средства управления для администраторов**: обязательное использование приватных развертываний и статического сканирования безопасности перед публикацией
* **Центр безопасности рабочего пространства**: выявляйте CVE во всех зависимостях с указанием уровня критичности. Просматривайте затронутые приложения и скачивайте SBOM для соблюдения требований
* **Настраиваемые разрешения для интеграций**: определяйте границы доступа для собственных интеграций в масштабе всей организации
* **VM повышенной мощности для развертываний**: доступ к VM большего размера для масштабируемого хостинга приложений
* **Выделенная поддержка**: доступ к персональному менеджеру по работе с клиентами и инженеру по продажам для поддержки платформы
* **Коннекторы данных Enterprise**: подключайтесь к Snowflake, BigQuery и Databricks для бесшовной интеграции данных
* **Неограниченное число мест для просмотров**: заинтересованные стороны и пользователи, не занимающиеся разработкой, получают неограниченный доступ к опубликованным приватным приложениям

<div id="section-2">
  ## Сценарии использования
</div>

Pro и Enterprise закрывают самые разные потребности организаций любого масштаба.

* **Корпоративные приложения**: создавайте и публикуйте критически важные приложения с безопасностью и масштабированием корпоративного уровня
* **Бизнес-инструменты**: разрабатывайте и поддерживайте бизнес-инструменты с удобным управлением доступом
* **Быстрое прототипирование**: ускоряйте инновации благодаря готовой к работе среде разработки
