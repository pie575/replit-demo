Ce guide de référence présente la classe `Client` du package `replit-object-storage-python` et fournit des exemples de code pour ses méthodes de classe.

<div id="client">
  ## Client
</div>

La classe `Client` gère les interactions avec Replit App Storage. Elle propose des méthodes permettant d&#39;effectuer des opérations sur les objets d&#39;un bucket.

Pour importer la classe depuis le package `replit.object_storage`, ajoutez la ligne suivante à votre code Python :

```python theme={null}
from replit.object_storage import Client
```

Utilisez le code suivant pour créer une instance `Client` qui interagit avec Replit App Storage :

```python theme={null}
client = Client()
```

<Tip>
  Si votre application utilise plusieurs buckets, créez une instance `Client` par bucket.
</Tip>

<div id="__init__">
  ### **init**
</div>

La méthode `init` initialise une instance de la classe Client.

```python theme={null}
def __init__(bucket_id: Optional[str] = None)
```

**Argument** :

* `bucket_id` (Optional[str]) : l&#39;ID du bucket géré par le client. S&#39;il est omis, le client utilise le bucket par défaut associé à la Replit App ou au déploiement.

<div id="copy">
  ### copy
</div>

La méthode `copy` copie un objet à l&#39;intérieur d&#39;un même bucket. Si un objet existe déjà au même emplacement, elle écrase l&#39;original.

```python theme={null}
def copy(object_name: str, dest_object_name: str) -> None
```

**Arguments** :

* `object_name` (str) - Le chemin complet de l&#39;objet source.
* `dest_object_name` (str) - Le chemin complet de l&#39;objet de destination.

**Exceptions levées** :

* `ObjectNotFoundError` - Indique que l&#39;objet source n&#39;existe pas au chemin spécifié.

<div id="delete">
  ### delete
</div>

La méthode `delete` supprime définitivement un fichier d&#39;App Storage.

```python theme={null}
def delete(object_name: str, ignore_not_found: bool = False) -> None
```

**Arguments** :

* `object_name` (str) - Le nom de l&#39;objet à supprimer.
* `ignore_not_found` (bool) - Lorsque la valeur est `True`, ignore l&#39;erreur si l&#39;objet n&#39;existe pas.

**Exceptions levées** :

* `ObjectNotFoundError` - Indique que l&#39;objet n&#39;existe pas.

<div id="download_as_bytes">
  ### download_as_bytes
</div>

La méthode `download_as_bytes` récupère le contenu d&#39;un fichier sous forme de `bytes`.

```python theme={null}
def download_as_bytes(object_name: str) -> bytes
```

**Argument** :

* `object_name` (str) - Le nom de l&#39;objet à télécharger.

**Retourne** :

* `bytes` - La représentation brute en octets du contenu de l&#39;objet.

**Lève** :

* `ObjectNotFoundError` - Indique que l&#39;objet n&#39;existe pas.

```python theme={null}
def download_as_text(object_name: str) -> str
```

**Argument** :

**Lève** :

* `ObjectNotFoundError` - Indique que l&#39;objet n&#39;existe pas.


<div id="exists">
  ### exists
</div>

La méthode `exists` vérifie si un objet existe.

```python theme={null}
def exists(object_name: str) -> bool
```

**Argument** :

* `object_name` (str) - Le nom de l&#39;objet dont il faut vérifier l&#39;existence.

<div id="list">
  ### list
</div>

La méthode `list` répertorie les objets du Bucket.

```python theme={null}
def list(end_offset: Optional[str] = None,
         match_glob: Optional[str] = None,
         max_results: Optional[int] = None,
         prefix: Optional[str] = None,
         start_offset: Optional[str] = None) -> List[Object]
```

**Arguments** :

* `end_offset`(Optional[str]) - Filtre les résultats pour ne conserver que les objets dont le nom précède lexicographiquement `end_offset`. Si `start_offset` est défini, les objets listés
  portent des noms compris entre `start_offset` (inclus) et `end_offset` (exclu).
* `match_glob` (Optional[str]) - Utilise un motif glob pour filtrer les résultats. Par exemple : &quot;foo*bar&quot; correspond à &quot;footbar&quot;, &quot;foo baz bar&quot; et &quot;foobar&quot;.
* `max_results` (Optional[int]) - Le nombre maximal de résultats à renvoyer dans la réponse.
* `prefix` (Optional[str]) - Filtre les résultats pour ne conserver que les objets dont le nom comporte le préfixe spécifié.
* `start_offset` (Optional[str]) - Filtre les résultats pour ne conserver que les objets dont le nom est lexicographiquement égal ou postérieur à `start_offset`.
  Lorsque `end_offset` est défini, les objets listés portent des noms compris entre `start_offset` (inclus) et `end_offset` (exclu).

**Renvoie** :

* `List`(Object) : une liste d&#39;objets correspondant aux paramètres de requête fournis.

<div id="exception-types">
  ### Types d&#39;exceptions
</div>

* Lors de l&#39;utilisation de Replit App Storage via le `Client`, n&#39;importe quelle méthode peut renvoyer l&#39;une des erreurs suivantes :

  * `BucketNotFoundError` : indique que le nom de bucket configuré ne correspond à aucun bucket dans App Storage.

  * `DefaultBucketError` : indique que la configuration du bucket par défaut est manquante.

  * `ForbiddenError` : indique que les autorisations sont insuffisantes pour accéder au bucket.

  * `TooManyRequestsError` : indique que l&#39;opération est soumise à une limitation de débit en raison d&#39;un nombre excessif de requêtes.

  * `UnauthorizedError` : indique que l&#39;accès à l&#39;opération est restreint par les autorisations.
