<div id="section">
  ## 什么是技能
</div>

技能是一个文件夹，其中包含名为 `SKILL.md` 的文件 (其中定义了 Agent 应遵循的步骤) ，以及供 Agent 参考的支持文件。技能存储在项目的 `/.agents/skills` 目录中，并遵循 [Agent 技能规范](https://agentskills.io/specification)。这是一项可供不同智能体使用的开放标准。

Agent 会查看所有已安装技能的名称和描述，但仅在判断某项技能与当前任务相关时，才会加载其完整内容。这使技能能高效利用上下文：即使安装许多技能，也不会降低 Agent 的输出质量。

<div id="section-2">
  ## 预置技能
</div>

Replit 提供预置技能，可通过聊天中的**使用技能**选择器和新建项目的起点选择器使用。这些技能无需安装，即可在所有项目中使用。有关完整目录、合作伙伴技能和安装方法，请参阅[技能目录](/zh/ja/features/agent/skills-directory)。

要添加预置技能，请在聊天输入框中打开**使用技能**选择器并选择技能，或直接要求 Agent 加载技能。

<div id="section-3">
  ## 技能的作用域
</div>

技能可在不同层级设定作用域：

| 作用域      | 可用范围         | 存储位置                                                                           |
| -------- | ------------ | ------------------------------------------------------------------------------ |
| **项目级**  | 仅适用于特定项目     | 与 `/.agents/skills` 中的文件一起进行版本控制                                               |
| **工作区级** | 工作区内所有成员均可使用 | 在工作区设置中统一管理                                                                    |
| **企业版**  | 全公司的标准       | 包含在[自定义模板](/zh/ja/teams/custom-templates)和[设计系统](/zh/ja/teams/custom-design-system)中 |

有关工作区级技能，请参阅 [Agent 自定义](/zh/ja/features/agent/agent-customization)，了解如何为团队配置工作区技能和自定义指令。

<div id="agent">
  ## Agent 如何加载技能
</div>

Agent 会在每次聊天时加载所有已安装技能的元数据 (名称和描述) 。只有当 Agent 判断技能内容与当前任务相关时，才会加载其正文。这样一来，在需要之前，技能内容不会占用上下文窗口。

已安装的技能会在不同的 Agent 会话之间保留在项目中，也可以提交到版本控制系统，以便与团队共享。

<div id="ai">
  ## 与其他 AI 编程工具集成
</div>

<Accordion title="从其他 AI 编程工具导入技能">
  如果您使用多种 AI 编程工具，[rulesync](https://github.com/dyoshikawa/rulesync) 支持 Replit，可帮助您统一管理配置。

  您可以从其他 AI 编程助手导入技能：

  ```bash theme={null}
  npx rulesync init
  npx rulesync import --targets claudecode --features skills
  npx rulesync generate --targets replit --features skills
  ```

  这样，您就能维护一套可在不同开发环境中使用的技能。
</Accordion>
