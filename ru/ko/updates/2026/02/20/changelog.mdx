<div id="pro">
  ## Запуск тарифа Pro
</div>

Replit Pro уже доступен, а Core теперь даёт ещё больше возможностей за те же деньги. Мы сделали линейку тарифов понятнее и логичнее:

* **Replit Pro**: для тех, кто работает всерьёз, — режим Turbo (Agent в 2,5 раза быстрее, отдельный переключатель), многоуровневые кредиты с переносом остатка, до 15 разработчиков без платы за место, приоритетная поддержка, в 4 раза больший срок хранения данных. [Узнать о Pro](/ru/ko/billing/plans/replit-pro).
* **Core**: приглашайте до 5 соавторов без дополнительной платы. Актуальные цены Core смотрите на [странице тарифов](https://replit.com/pricing).
* **Закрытие тарифа Teams**: на смену Teams приходит Pro. Действующие клиенты Teams будут переведены на Pro на оставшийся срок без дополнительной платы. Миграция начнётся {TeamsMigrationDate}. [Подробности и сроки](https://blog.replit.com/pro-plan).
* **Режимы Agent**: выберите **Economy** (экономия расходов) или **Power** (производительность). **Turbo** — отдельный переключатель (только для Pro/Enterprise, в 2,5 раза быстрее). [Руководство по режимам Agent](/ru/core-concepts/agent/agent-modes).
* **Режим Fast теперь называется Lite**: те же быстрые и точечные изменения — название обновлено в продукте и документации. [Режим Lite](/ru/core-concepts/agent/agent-modes).
* **Code Optimizations**: настройка, определяющая, как Agent проверяет собственный код (ранее Autonomy Level), теперь называется Code Optimizations. [Проверка кода](/ru/ko/features/agent/agent-modes).
* **Совместная работа**: удобнее на всех платных тарифах — неограниченное количество рабочих пространств, упрощённый доступ, единые настройки, отслеживание использования по каждому рабочему пространству. Core: 5 соавторов, Pro: 15 разработчиков.

<div id="section-3">
  ### Фоновое сжатие памяти
</div>

Agent больше не прерывает рабочие процессы ради оптимизации памяти. Раньше сообщение «Optimized Agent memory» останавливало работу более чем на 30 секунд. Теперь эта операция незаметно выполняется в фоновом режиме, поэтому Agent остаётся отзывчивым даже во время работы.

<div id="section-4">
  ### Доступ к логам продакшн-деплоя
</div>

Теперь Agent может обращаться к логам продакшн-деплоя, а значит — находить и исправлять ошибки на основе реальных данных из продакшена. Вскоре появятся и другие улучшения отладки в продакшене.

<div id="section-5">
  ### Поиск навыков
</div>

Поиск навыков позволяет находить и устанавливать популярные навыки прямо в Replit — без промптов для Agent и ручной загрузки файлов.

<div id="razorpay-mcp">
  ### Интеграция Razorpay MCP
</div>
