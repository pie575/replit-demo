<div id="buy-a-domain-right-inside-replit">
  ### 直接在 Replit 中购买域名
</div>

现在，你无需离开 Replit，即可为应用搜索并购买自定义域名。找到可用域名并完成结账后，Replit 会自动将域名连接到你已发布的应用。无需另行设置域名注册商账户。

详细了解[如何在 Replit 上购买域名](/zh/features/publishing/custom-domains#buy-a-new-domain-on-replit)。

<div id="integrations">
  ## 集成
</div>

<div id="connect-excalidraw-to-agent">
  ### 将 Excalidraw 连接到 Agent
</div>

现在你可以连接 Excalidraw，让 Agent 帮你创建和编辑图表与白板。只需在 Connectors 页面登录一次，就能在各个应用中让 Agent 使用 Excalidraw 进行构建，无需复制粘贴任何凭据。

</Frame>

进一步了解 [connector](/zh/features/integrations/overview#available-connectors)。

<div id="workspace">
  ## Workspace
</div>

<div id="editors-can-answer-agents-questions">
  ### 编辑者可以回答 Agent 的提问
</div>

在共享 App 中协作构建时，任何编辑者现在都可以回答 Agent 的常规提问，无需等待 App 所有者。而连接集成、添加密钥等敏感操作，仍然只能由所有者执行。

了解更多关于[管理 App 访问权限](/zh/teams/identity-and-access-management/repl-access-management)的信息。
