本页介绍 工作区 设置，以及可在同一设置对话框中使用的相关账户与用户控制项。

<div id="section">
  ## 打开设置
</div>

1. 选择 Replit 左下角的账户菜单。
2. 选择**设置**。

<Note>
  可用的标签页会因工作区类型、套餐和角色而异。只有在你拥有相应管理权限时，才会显示管理员专属选项。
</Note>

<div id="section-2">
  ## 工作区设置
</div>

在**工作区**部分中管理当前选中的工作区：

* **工作区概览**：更新工作区的图片或名称，并查看其 ID。
* **工作区协作者**：邀请用户并管理工作区的访问权限。
* **集成**：管理已连接到工作区的服务和资源。
* **自定义**：为 Agent 配置适用于整个工作区的自定义指令、技能和 Memory。有关设置与权限，请参阅 [Agent 自定义](/zh/ja/features/agent/agent-customization)。
* **设计系统**和**幻灯片模板**：为组织管理可复用的设计规范和演示文稿模板。两者均为 Enterprise 功能 — 请参阅[设计系统](/zh/ja/teams/custom-design-system)和[自定义模板](/zh/ja/teams/custom-templates)。
* **安全**：查看应用于工作区的安全管控措施。请参阅[安全概览](/zh/ja/features/security/overview)。
* **群组**：整理成员并应用群组权限。请参阅[群组与权限](/zh/ja/teams/identity-and-access-management/groups-and-permissions)。

<div id="section-3">
  ## 账户设置
</div>

**账户**部分用于配置适用于多个工作区的设置：

* **使用情况**、**账单**、**账户席位**：查看使用情况和账单信息；如果您的角色具有相应权限，还可管理席位。
* **高级设置**：查看高级账户控制项，包括 Agent 的模型提供商策略。有关 Enterprise 提供商及各工作区的工作流，请参阅[模型控制](/zh/ja/features/collaboration/enterprise-model-controls)。
* **开发者**：管理 Admin API 密钥并查看请求历史记录。创建或轮换密钥前，请先参阅 [Admin API](/zh/ja/teams/admin-api)。

<div id="section-4">
  ## 用户设置
</div>

**用户**部分用于配置你的**个人资料**和**个人设置**。该部分中还提供了 Replit 社区的链接。
