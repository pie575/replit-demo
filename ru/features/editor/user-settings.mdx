Инструмент «Пользовательские настройки» в Project Editor позволяет настроить внешний вид, поведение и
сочетания клавиш для вашей учётной записи.

  <img src="/assets/mirror/user-settings-tool-faae3afb911b.png" alt="снимок экрана инструмента пользовательских настроек" width="4152" height="1894" data-path="images/workspace/user-settings-tool.png" />
</Frame>

<div id="features">
  ## Возможности
</div>

Настроить процесс создания Replit App можно с помощью следующих категорий параметров:

* **Настройка темы**: выбор светлой или тёмной темы для Project Editor
* **Интеллектуальная работа с кодом**: настройка функций на базе ИИ, которые упрощают создание приложений
* **Параметры редактора**: изменение поведения и внешнего вида редактора файлов
* **Управление уведомлениями**: настройка оповещений
* **Параметры доступности**: адаптация Replit для пользователей с особыми потребностями
* **Сочетания клавиш**: назначение комбинаций клавиш для частых действий и навигации по интерфейсу

<div id="usage">
  ## Использование
</div>

<Accordion title="Как открыть Пользовательские настройки">
  На левой панели **Tool dock**:

  1. Выберите <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Значок всех инструментов" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**, чтобы открыть список инструментов Project Editor.
  2. Выберите <img class="icon-svg" src="/assets/mirror/settings-icon-c2664c3691bf.svg" alt="Значок настроек" width="16" height="16" data-path="images/icons/settings-icon.svg" /> **Пользовательские настройки**.

  Через **строку поиска**:

  1. Нажмите на значок лупы <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="значок лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> вверху, чтобы открыть инструмент поиска
  2. Введите «Пользовательские настройки», чтобы найти инструмент, и выберите его в результатах.
</Accordion>

<div id="appearance">
  ### Внешний вид
</div>

Настройте параметры внешнего вида Project Editor:

* **Выбор темы**: выберите одну из готовых светлых или тёмных тем, <a href="https://replit.com/themes" target="_blank">темы сообщества</a> или собственную тему
* **Пользовательские темы**: создавайте свои цветовые схемы в редакторе [Themes](/ru/features/editor/themes)

<div id="file-editor-preferences">
  ### Настройки редактора файлов
</div>

Управляйте внешним видом и поведением редактора файлов с помощью следующих настроек:

* **Font size**: размер текста для удобства чтения
* **Auto close brackets**: автоматическая вставка закрывающей скобки при вводе открывающей
* **Indentation detection**: автоматическое определение параметров отступов при открытии файла
* **Format pasted text indentation**: переформатирование вставленного кода в соответствии с правилами отступов
* **Indentation character**: выбор между пробелами и табуляцией для отступов в коде
* **Indentation size**: количество столбцов для каждого уровня отступа
* **Wrapping**: настройка переноса строк
* **Minimap**: обзор кода с возможностью навигации на боковой панели
* **Multiselect modifier key**: клавиша-модификатор для выбора нескольких файлов
* **Filetree Git status**: отображение индикаторов статуса Git в дереве файлов

<div id="code-intelligence">
  ### Интеллектуальная работа с кодом
</div>

Настройте инструменты на базе ИИ с помощью следующих параметров:

* **Semantic tokens**: расширенная подсветка синтаксиса на основе языковых серверов
* **AI code completion**: встроенные подсказки по коду по мере ввода
* **Accept suggestion on commit character**: автоматическое принятие подсказок при вводе определённых символов

<div id="shell-and-preview-preferences">
  ### Настройки Shell и Preview
</div>

Настройте поведение инструментов Shell и Preview:

* **Звуковой сигнал Shell**: воспроизводить звук при возникновении проблем в инструменте Shell
* **Автоматический предпросмотр**: автоматически открывать вкладку Preview, когда сервер становится доступен
* **Автоматически перенаправлять открытые порты**: настройка обработки вновь обнаруженных портов

<div id="notifications">
  ### Уведомления
</div>

Управляйте следующими настройками уведомлений:

* **Звуковое уведомление Agent**: воспроизводить звук, когда Agent запрашивает ответ
* **Push-уведомление Agent**: получать push-уведомления на мобильном устройстве, когда Agent запрашивает ответ

<div id="production-alerts">
  #### Оповещения о работе приложений
</div>

**Production Alerts** — это отдельная настройка email-уведомлений, которая держит вас в курсе состояния ваших опубликованных приложений. Она не зависит от продуктовых и маркетинговых рассылок, поэтому вы получаете только действительно важную информацию без лишнего шума.

Включите **Production Alerts**, чтобы получать письма о следующем:

* **Инциденты с доступностью**: уведомления о том, что опубликованное приложение недоступно или не может стабильно оставаться в сети.
* **Уязвимости безопасности**: уведомления об уязвимостях в программном обеспечении, от которого зависит ваше приложение, чтобы вы могли устранить их до того, как они приведут к проблемам.
* **Обновления моделей**: уведомления о том, что языковая модель, используемая вашим приложением, изменилась или требует вашего внимания.

<Frame>
  <img src="/assets/mirror/production-alerts-highlight-bb76079f20fd.png" alt="Раздел Production Alerts в настройках уведомлений: красным прямоугольником выделены переключатель писем с оповещениями о работе приложений и выпадающий список уровня важности оповещений безопасности" width="2400" height="1364" data-path="images/workspace/production-alerts-highlight.png" />
</Frame>

Чтобы найти эту настройку:

1. Откройте **Settings** в меню аккаунта.
2. Выберите вкладку **Personalization**.
3. Прокрутите до раздела **Email Notifications** и найдите **Production Alerts**.

Если опубликованное приложение использует устаревшую языковую модель, Replit подготовит черновик задачи для перехода на поддерживаемую модель. Вы получите письмо со ссылкой на эту задачу и сможете завершить обновление, просто просмотрев её.

<div id="keyboard-shortcuts">
  ### Сочетания клавиш
</div>

Чтобы открыть настройки сочетаний клавиш, перейдите на вкладку **Keyboard shortcuts** в инструменте User Settings.

Искать сочетания клавиш можно следующими способами:

* **По названию**: введите название или описание сочетания клавиш в поле поиска
* **По комбинации клавиш**: нажмите <img class="icon-svg" src="/assets/mirror/keyboard-7ba19771b671.svg" alt="keyboard icon" width="16" height="16" data-path="images/icons/keyboard.svg" /> и введите нужную комбинацию клавиш

Для управления сочетаниями клавиш используйте следующие действия:

* **Добавить**: выберите **Add shortcut**
* **Изменить**: нажмите значок карандаша <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="pencil icon" width="16" height="16" data-path="images/icons/pencil-icon.svg" />
* **Удалить**: нажмите значок корзины <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="trash icon" width="16" height="16" data-path="images/icons/trash-icon.svg" />
