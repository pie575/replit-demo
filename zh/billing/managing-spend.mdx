<div id="optimize-ai-costs">
  ## 优化 AI 成本
</div>

[Agent](/zh/features/agent/overview) 等 AI 功能功能强大，但合理规划使用方式，既能充分发挥其价值，也能控制成本。以下是降低 AI 支出的有效方法。

<div id="use-plan-mode-for-cost-effective-collaboration">
  ### 使用 Plan Mode，实现更具成本效益的协作
</div>

[Plan Mode](/zh/features/agent/plan-mode) 是节省 AI 成本最有效的方法之一。启用 Plan Mode 后，Agent 会制定详细计划，但不会更改任何代码。这种方式具有多项成本优势：

* **先 Chat，再提交**：在开始工作前，先与 Agent 讨论并完善方案
* **更低的 token 成本**：规划对话所用的 token 少于代码生成和编辑
* **精准聚焦**：审查并调整计划，确保 Agent 只处理真正重要的内容
* **迭代优化**：在将 token 用于实施前，先明确合适的范围

在探索解决方案、完善 requirements，或希望在实施前了解整体方案时，请使用 [Plan Mode](/zh/features/agent/plan-mode)。

<div id="control-costs-with-agent-modes">
  ### 使用 Agent 模式控制成本
</div>

[Agent 模式](/zh/features/agent/agent-modes)可让您在成本与能力之间权衡：

* **Free Mode**：在套餐额度内免费完成日常 Agent 工作。
* **Auto**：为 Power 或 Max 中的付费任务自动选择模型。
* **Power**：以实惠的价格提供更强的能力。
* **Max**：为最具挑战性的任务提供最先进的模型。

Agent 会在构建过程中自动审查自己的代码，及时发现错误并减少高成本返工，无需手动开启或关闭。若要更好地掌控支出，请先通过 Plan Mode 明确工作范围：

* **执行前审查**：在 Agent 进行更改前，查看它计划执行的操作。
* **选择性批准**：批准符合您目标的更改，跳过其余更改。

<Tip>
  日常工作请先使用 [Free Mode](/zh/features/agent/agent-modes)。需要以实惠的价格获得更强能力时，请选择 [Power mode](/zh/features/agent/agent-modes)。先规划，再逐步批准更改。
</Tip>

<div id="purchase-credit-packs">

<div id="how-credit-packs-work">
  ### 积分包的使用方式
</div>

* **购买位置**：Core 和 Pro 套餐用户可在 **设置** → **账户用量** → **积分** → **购买积分包** 中购买
* **有效期**：积分包自购买之日起六个月后到期
* **不会续订**：积分包不会自动续订
* **不会结转**：积分包中未使用的积分到期后不会结转
* **自动使用**：系统会优先使用最早到期的积分包中的积分，帮助您充分利用购买的积分
* **自动充值**：开启自动充值后，当余额不足时，系统会自动购买*新的*积分包，避免项目进行过程中被打断
* **随时管理**：您可以在 **设置** → **账单** 中启用、调整或关闭自动充值

<Note>
  使用完您拥有的所有积分包后，用量限制和预算将适用于后续用量。如果您只想使用积分包中购买的积分，请将所有限制设为 $0.01。
</Note>

<div id="view-payment-receipts">
  ### 查看付款收据
</div>

如果你的账户使用充值功能，请打开 **设置** → **账单**，然后找到 **付款收据**，查看成功的一次性充值和自动续充付款。每一行都会显示付款日期、购买类型、金额和退款状态。选择 **查看收据**，即可在支付服务提供商处打开收据。

<div id="set-up-limits-and-budgets">
  ## 设置限额和预算
</div>

您可以为所有按用量计费的服务设置每月用量限额和预算，以监控并控制成本。

<div id="usage-limits">
  ### 用量限额
</div>

用量限额可限制每月额度用尽后的额外支出。达到限额后，按用量计费的服务将无法使用，直到下一个计费周期开始或你提高限额。

对于 Core 账户，依次打开 **设置** → **Account** → **Usage**。在 **账户用量** 部分，选择 **管理限额** 设置用量限额。对于组织，请打开[用量页面](https://replit.com/usage)，然后在 **账户用量** 下选择 **管理限额**。

<div id="service-shutdown-limit">
  ### 服务停用限额
</div>

达到此限额后，服务将暂停，直到您提高预算或下一个计费周期开始，从而避免产生额外费用。

请在[用量限额](#usage-limits)中所述的 **管理限额** 对话框中设置此限额。

<div id="organization-budgets">
  ### 组织预算
</div>

你可以在[设置页面](https://replit.com/t/replit/settings/billing)为组织设置使用预算。预算金额必须是 {OrganizationBudgetIncrement} 的整数倍。

<Note>你必须拥有组织管理员或所有者权限，才能启用每月使用限额。如果无权访问，请联系组织所有者。</Note>

<div id="per-user-spend-limits">
  ### 每位用户的支出限额
</div>

Enterprise 管理员可以为个别成员设置不同于 workspace 默认值的支出限额。您可以借此提高高级用户的上限，或收紧单个成员的支出限额，而无需更改 workspace 中其他成员的限额。

<Steps>
  <Step title="打开 workspace 用量页面">
    在 Enterprise workspace 中，打开[用量页面](https://replit.com/usage)。**Agent 用户**表格会列出 workspace 中的所有成员及其当前用量。
  </Step>

  <Step title="编辑成员限额">
    找到要调整的成员，然后选择 **用量限额**列中的编辑图标。对话框会显示 workspace 默认值、所有适用的群组限额，以及用于设置新的每用户限额的字段。

    <Frame>
      <img src="/assets/mirror/edit-usage-limit-87127319c809.png" alt="workspace 成员的编辑用量限额对话框，显示 workspace 默认值、当前用户专属限额、适用的群组限额，以及设为 $5 的用户阈值输入框" width="1202" height="916" data-path="images/billing/edit-usage-limit.png" />
    </Frame>
  </Step>

  <Step title="保存覆盖设置">
    输入新限额并选择**保存**。覆盖设置会立即生效，新值将显示在**用量限额**列中。若要日后移除覆盖设置，请清空该字段并保存。该成员随后将使用对其适用的最具体群组限额或 workspace 限额。
  </Step>
</Steps>

<Note>每用户支出限额仅适用于 Enterprise 计划。分配到[自定义群组](/zh/teams/identity-and-access-management/groups-and-permissions)的成员会继承该群组的限额，除非设置了个人覆盖值。每用户覆盖值始终优先于群组和 workspace 默认值。</Note>

<div id="organization-admin-controls">
  ### 组织管理员控制
</div>

组织管理员可以通过[组织账单设置](https://replit.com/t/replit/settings/billing)管理 AI 模型访问权限和集成。

**禁用外部 AI 模型集成**

启用此设置后，组织中的所有用户将无法使用外部 AI 模型集成 (例如通过 Replit 托管的 connector 使用 OpenAI、Anthropic、xAI 和 Perplexity) 。

启用此设置后，组织中的所有用户将无法使用 Replit 托管的 AI 集成。
