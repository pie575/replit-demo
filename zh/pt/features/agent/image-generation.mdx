<div id="recursos">
  ## 功能
</div>

使用 Agent 的图像生成功能构建视觉效果出色的应用。这样一来，你无需再依赖图库照片、外部设计工具，也不必为基础视觉内容聘请设计师。无论是创建作品集网站、构建游戏，还是设计移动应用界面，图像生成都能提供贴合项目需求的定制视觉素材。

Agent 可以执行以下图像生成操作：

* **创建定制图像**：根据详细的描述和规格生成图像
* **风格适配**：以多种艺术风格创建图像，从写实到卡通皆可
* **透明背景**：将图像生成为透明 PNG，或移除现有图像的背景——非常适合徽标、图标、贴纸和产品抠图
* **项目集成**：将生成的图像顺畅地直接添加到应用的代码库中
* **迭代优化**：根据你的反馈修改和改进图像

<div id="uso">
  ## 使用方法
</div>

图像生成已内置于 Agent 中，无需额外启用。打开任意已启用 Agent 的 Replit App，直接让 Agent 创建你需要的视觉内容即可。Agent 会根据你的需求自动判断何时生成图像，并按照你的要求生成定制图像。

<div id="melhores-prticas-para-gerao-de-imagens">
  ### 图像生成最佳实践
</div>

遵循以下建议，让 Agent 的图像生成发挥最佳效果：

**描述具体、细致**

* 说明风格、色彩、构图和氛围等细节
* 必要时指定尺寸或宽高比
* 说明用途 (图标、背景、插图等)
* 若需要将 logo、图标、贴纸或抠图叠加在其他内容之上，请要求使用透明背景

**迭代优化**

* 先给出基础描述，再根据结果逐步优化
* 让 Agent 调整生成图像中的特定细节
* 请求生成多个变体，探索不同的创意方向

**考虑项目的整体风格**

* 保持整个应用的视觉一致性
* 指定符合品牌或设计系统的风格偏好
* 要求生成与现有视觉元素相协调的图像

<div id="integrao-ao-projeto">
  ### 集成到项目中
</div>

Agent 会将生成的图像无缝集成到你的代码库中：

* **自动创建文件**：生成的图像会直接保存到项目文件中
* **代码更新**：Agent 会更新代码，以引用新的图像文件
* **资源整理**：图像会存放在项目结构中合理的目录下

这一简化的工作流程意味着，你无需离开开发环境即可生成并应用视觉内容。

<Note>
  Replit 的图像生成由 [Google Imagen 4](https://deepmind.google/models/imagen/) 提供支持，这是一款先进的文生图模型，擅长生成细节精致、文本渲染能力更强的高质量写实图像。
</Note>
