アセット作成はその場で結果を生み出します。スケジュールに沿って繰り返すべき作業には、[Routine タスクを実行する](/ja/chat/routines)に進んでください。

生成された動画クリップとアニメーション動画は異なるワークフローを使用します。アニメーション動画は MP4 としてエクスポートできるプログラムによるモーショングラフィックスです。ビジュアルアセットの例については、[最初の画面をデザインする](/ja/design/design-your-first-screen)をご覧ください。

## 最新の情報を取り入れる

Web Search はアセットを作成しません。画像、音声クリップ、動画、グラフィックが最新情報に基づくべきときに使用し、その方向性をもとに適切なアセットの作成を Replit に依頼しましょう。
