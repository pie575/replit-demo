Выберите, где будет размещаться инфраструктура вашего рабочего пространства и опубликованных приложений, чтобы соблюсти требования к местонахождению данных и снизить задержки. В Replit регион рабочего пространства и регион публикации задаются отдельно, поэтому расположением среды разработки и опубликованных приложений можно управлять независимо друг от друга.

<div id="section">
  ## Сравнение региона рабочего пространства и региона публикации
</div>

| Параметр                 | Регион рабочего пространства                     | Регион публикации                                             |
| :----------------------- | :----------------------------------- | :------------------------------------------------------------ |
| **Что охватывает**       | Ресурсы разработки внутри рабочего пространства  | Вычислительные ресурсы и хранилище опубликованного приложения |
| **Когда задаётся**       | При создании рабочего пространства               | При публикации проекта                                        |
| **Что определяет**       | Регион для новых проектов и ресурсов | Сведение опубликованных артефактов в один регион              |
| **Можно изменить позже** | Нет                                  | Нет                                                           |

Регион рабочего пространства и регион публикации могут не совпадать.

Подробнее о выборе региона разработки при создании рабочего пространства см. в разделе [География рабочего пространства](/ru/ja/features/collaboration/workspace-geography).

<div id="section-2">
  ## Регион публикации
</div>

Регион публикации задаётся при публикации проекта. По умолчанию Replit предлагает ближайший к вам регион. Это снижает задержки для посетителей приложения и упрощает соблюдение требований к месту хранения данных.

После выбора региона все опубликованные артефакты проекта (вычислительные ресурсы, базы данных, Object Storage и другие) автоматически размещаются в этом же регионе. Снизить задержки для посетителей приложения помогают и региональные прокси-серверы.

<div id="section-3">
  ### Выбор региона публикации
</div>

Чтобы выбрать регион, отличный от рекомендованного, выполните следующие шаги.

<Steps>
  <Step>
    Откройте инструмент **Publishing** в проекте Replit.
  </Step>

  <Step>
    Разверните раздел настроек **Advanced**.
  </Step>

  <Step>
    Выберите нужный регион в раскрывающемся списке **Geography**.
  </Step>

  <Step>
    Нажмите **Publish**, чтобы опубликовать проект в выбранном регионе.
  </Step>
</Steps>

<div id="section-4">
  ### Принудительный выбор региона публикации для проектов
</div>

Администраторы Enterprise могут задать обязательный регион публикации для всех проектов организации. После включения этой политики разработчики организации будут публиковать проекты только в указанном регионе. Политика распространяется лишь на проекты, которые ещё не публиковались, — на проекты, уже опубликованные в другом регионе, она не влияет.

<Note>
  Принудительный выбор региона публикации — возможность Enterprise. Подробнее о планах Enterprise см. на странице [тарифов](https://replit.com/pricing/).
</Note>

<Steps>
  <Step>
    Перейдите в раздел **Account settings**.
  </Step>

  <Step>
    Выберите **Advanced**.
  </Step>

  <Step>
    Укажите регион, который должны использовать все проекты при первой публикации.
  </Step>
</Steps>

<div id="section-5">
  ### Ограничения регионов публикации
</div>

Прежде чем выбрать регион публикации, обратите внимание на следующие ограничения:

* **После публикации регион изменить нельзя.** Если проект опубликован в определённом регионе, этот выбор становится окончательным. Перенести опубликованный проект в другой регион невозможно.
* **Расположение среды разработки и среды публикации может различаться.** Такие ресурсы, как Object Storage, могут быть созданы до публикации и не совпадать с регионом, в котором вы публикуете проект.

<div id="section-6">
  ## Доступные регионы
</div>

Для рабочего пространства и для публикации доступны разные наборы регионов.

| Регион                               | Доступен для рабочего пространства | Доступен для публикации |
| :----------------------------------- | :--------------------------------- | :---------------------- |
| **North America (Северная Америка)** | Да                                 | Да                      |
| **Europe (ЕС)**                      | Да                                 | Да                      |
| **Asia (Азия)**                      | Да                                 | Да                      |
| **South America (Южная Америка)**    | Нет                                | Да                      |
| **Australia (Австралия)**            | Нет                                | Да                      |

<Note>
  Выбор региона для рабочего пространства доступен только клиентам с планом Pro.
  Выбор региона для публикации доступен клиентам с планами Core, Pro и Enterprise.
  Приложения клиентов с бесплатным планом по умолчанию публикуются в Северной Америке.
</Note>
