Canvas Toolbar는 board 하단 중앙에 고정되어 떠 있는 막대입니다. 화면 이동, 그리기, 편집, 콘텐츠 추가에 사용하는 도구를 모아 제공하며, Canvas 모드에서 나타납니다.

</Frame>

<div id="tools">
  ## Tools
</div>

도구를 선택하면 해당 도구가 활성화됩니다. 활성 도구는 배경이 채워진 형태로 강조 표시됩니다. 가장 왼쪽 그룹은 탐색 도구(Interact, Pan)이며, 나머지는 콘텐츠 및 마크업 도구입니다. 도구는 상호 배타적이어서 하나를 선택하면 나머지는 해제됩니다.

<div id="interact">
  ### Interact
</div>

**Interact**는 기본 도구입니다. frame을 선택하거나 드래그해 옮길 수 있고, 실행 중인 artifact를 클릭해 실제 앱처럼 사용할 수도 있습니다. Interact가 활성화된 상태에서 frame을 클릭하면 해당 frame이 선택되면서 [per-frame action bar](/ko/design/frames#per-frame-action-bar)가 표시됩니다.

<Frame>
  <img src="/assets/mirror/canvas-interact-4472dae3de09.png" alt="Interact 도구로 Website artifact를 선택한 Canvas — frame에 선택 핸들과 외곽선이 표시되고 그 위에 per-frame action bar가 나타나 있습니다. 하단의 플로팅 Toolbar에서 Interact 도구가 강조되어 있습니다." width="3450" height="2000" data-path="images/replitai/canvas-interact.png" />
</Frame>

**키보드 단축키:** `V`. **Gate:** 항상 사용 가능.

<div id="pan">
  ### Pan
</div>

**Pan**을 선택하면 커서가 손 모양 도구로 바뀌어 board 자체를 드래그할 수 있습니다. Pan이 활성화된 상태에서는 클릭한 채 드래그하면 frame이 선택되지 않고 뷰포트가 이동합니다. 다른 도구를 사용 중일 때도 스페이스바를 누른 채 드래그하거나 마우스 가운데 버튼으로 드래그하면 화면을 이동할 수 있습니다.

<Frame>
  <img src="/assets/mirror/canvas-pan-9f07d3bf72a3.png" alt="Pan 도구가 활성화된 Canvas — board에 Website artifact(Velocity — Supercar Rental)와 Design mockup(Velocity — Home (Mockup))이 표시되어 있고, 하단의 플로팅 Toolbar에서 Pan(손 모양 커서) 도구가 강조되어 있습니다." width="1725" height="1041" data-path="images/replitai/canvas-pan.png" />
</Frame>

**키보드 단축키:** `H`. **Gate:** 항상 사용 가능.

<div id="chat">
  ### Chat
</div>

**Chat**을 사용하면 board 위에 작은 채팅 입력창이 바로 나타나 Canvas를 벗어나지 않고도 Agent에게 prompt를 보낼 수 있습니다. 선택한 요소와 frame은 측면 Agent chat 패널에서 보낼 때와 마찬가지로 snapshot 형태로 메시지에 첨부됩니다.

<Frame>
  <img src="/assets/mirror/canvas-chat-d28e2d8f216a.png" alt="Chat 모드의 Canvas. board의 나머지 부분은 흐리게 처리되고 Website artifact 위에 인라인 채팅 입력창이 겹쳐 표시됩니다. 입력창의 'div' chip은 선택된 요소를 나타내며, prompt에는 'suggest three alternatives to this image'라고 적혀 있습니다. 하단의 플로팅 Toolbar에서 Chat 도구가 강조되어 있습니다." width="3450" height="2000" data-path="images/replitai/canvas-chat.png" />
</Frame>

**Gate:** Chat 도구(데스크톱 전용).

<div id="draw">
  ### Draw
</div>

**Draw**를 선택하면 자유 곡선, 화살표, 스티커 메모, 도형 등의 markup tools가 활성화되어 frames 위에 스케치하거나 board에 주석을 달 수 있습니다. 문제가 되는 영역에 동그라미를 치거나, 변경하고 싶은 요소를 가리키거나, frame 옆에 메모를 남길 때 활용하세요.

Draw가 활성화되면 플로팅 Toolbar 위에 **Shape properties** 바가 나타나 현재 markup 도구의 색상, 선, 채우기를 조절할 수 있습니다. Interact나 Pan으로 돌아가면 자동으로 사라집니다.

<Frame>
  <img src="/assets/mirror/canvas-draw-d2d9b6556cde.png" alt="Draw 도구가 활성화된 Canvas — frame 옆에 'Widget' 사각형이 그려져 있고 보라색 'Add a widget' 스티커 메모가 놓여 있습니다. 플로팅 Toolbar 위에 Shape properties 바(연필, 텍스트, 사각형, 화살표, 스티커 메모 도구와 색상 견본, Aa 글자 크기 조절기)가 보이며 Draw가 강조 표시되어 있습니다." width="1725" height="1041" data-path="images/replitai/canvas-draw.png" />
</Frame>

**Gate:** 항상 사용 가능.

<div id="edit">
  ### Edit
</div>

**Edit**는 요소를 시각적으로 선택하는 도구입니다. Edit가 활성화된 상태에서 실행 중인 artifact 내부를 클릭하면 요소(버튼, 제목, 이미지 등)를 지정할 수 있습니다. 요소를 선택하면 **Visual Editor**가 열립니다. 오른쪽 패널에 각종 컨트롤(Layout, Color, Border 등)이 표시되고, 선택한 부분만 변경하도록 Agent에게 요청할 수 있는 인라인 prompt도 함께 제공됩니다. 전체 흐름은 [Elements](/ko/design/elements)와 [Visual Editor](/ko/design/visual-editor)를 참고하세요.

<Frame>
  <img src="/assets/mirror/canvas-edit-67fe5ee02fbe.png" alt="슈퍼카 렌털 웹사이트에서 div 요소가 선택된 채 활성화된 Edit tool과, Text, Layout, Color, Border 컨트롤 및 편집 취소·저장 버튼이 표시된 Visual Editor 패널" width="2000" height="1269" data-path="images/replitai/canvas-edit.png" />
</Frame>

**Gate:** 항상 사용 가능(데스크톱). frame이 하나 이상 있어야 활성화되며, 그전까지는 툴팁에 *&quot;Create an artifact or generate a design to edit.&quot;*가 표시됩니다. 모바일에서는 숨겨집니다.

<div id="generate">
  ### Generate
</div>

**Generate**를 선택하면 이미지, 비디오, 벡터 그래픽을 만들 수 있는 **Generate media** popover가 열립니다. 종류를 고르고 prompt를 작성하면 Agent가 결과물을 board 위에 새 frame으로 배치합니다.

<Frame>
  <img src="/assets/mirror/canvas-add-menu-5d97d9c813e1.png" alt="Canvas의 + Add 메뉴가 열려 있고 네 가지 옵션이 세로로 나열되어 있습니다: Design('인터페이스와 비주얼 콘셉트를 목업으로 만들기'), Image('이미지 생성 및 편집'), Video('모션 클립과 애니메이션 생성'), Vector Graphic('벡터 일러스트와 SVG 생성'). 하단 플로팅 Toolbar의 Generate 자리에는 이제 '+ Generate'가 표시됩니다." width="1102" height="702" data-path="images/replitai/canvas-add-menu.png" />
</Frame>

popover 상단에는 네 개의 tab이 있습니다:

* **Design**
  — **Image**
* **Video**
* **Vector Graphic**

일부 컨트롤은 모든 종류에 공통으로 적용되고, 나머지는 종류별로 다릅니다.

**공통 컨트롤(모든 종류):**

* **Model**: 사용할 생성 model입니다. 사용 가능한 model은 종류에 따라 다릅니다(아래 표 참조).
* **Prompt**: Agent가 무엇을 생성할지 일상적인 언어로 설명합니다.
* **Generate**: 요청을 제출하고 커서 위치에 자리 표시용 frame을 확보합니다. asset이 준비되면 자리 표시자가 실제 frame으로 전환됩니다. 생성에 실패하면 자리 표시자가 사라지고 Chat 패널에 오류가 표시됩니다.

**종류별 model과 컨트롤:**

| 종류          | 적합한 용도                                      | 현재 model                                                        | 종류별 컨트롤                                                         |
| ----------- | ------------------------------------------- | --------------------------------------------------------------- | --------------------------------------------------------------- |
| **Image**   | 래스터 출력(PNG / JPG), 무드보드 이미지, hero 컷, 참고용 아트 | Nano Banana, Nano Banana 2, Nano Banana Pro, ChatGPT Images 2.0 | 종횡비(`1:1`, `16:9`, `9:16`, `4:3`, `3:4`) · 크기(`1K`, `2K`, `4K`) |
| **Video**   | 짧은 모션 클립과 애니메이션                             | Veo 3.1, Seedance 2.0                                           | 종횡비 · 해상도(예: `720p`) · 길이(예: `4s`) · 오디오 토글                     |
| **Graphic** | SVG 벡터 출력, icon, logo, 다이어그램, 스타일화된 일러스트    | Claude 4.6 Opus, Gemini 3.1 Pro Preview                         | 애니메이션 토글                                                        |

<Note>
  model 구성은 자주 바뀝니다. 위 표는 현재 사용 가능한 항목을 반영한 것이므로, 지금 내 Account에서 사용할 수 있는 항목은 제품 내 드롭다운에서 확인하세요.
</Note>

각 frame 종류가 무엇이고 생성한 뒤에 무엇을 할 수 있는지는 [Frames](/ko/design/frames)를 참조하세요.

<div id="attach-visual-references">
  #### 시각적 참조 첨부
</div>

생성하기 전에 board에 이미 있는 항목을 시각적 참조로 첨부할 수 있습니다. Agent는 이러한 참조를 바탕으로 결과물이 프로젝트의 분위기와 어울리도록 만듭니다. **Generate media** 양식 안의 **+** 메뉴를 열고 다음 옵션 중 하나를 선택하세요.

* **Upload file**: 컴퓨터에 있는 이미지를 upload하여 참조로 사용합니다.
* **Select canvas 요소**: board에 있는 기존 항목을 선택합니다. frame은 스크린샷으로 캡처되고, 텍스트와 노트 도형은 텍스트 요약으로 첨부됩니다.

각 참조는 양식에 chip으로 표시됩니다. 필요한 만큼 추가하고 prompt를 작성한 뒤 **Generate**를 선택하세요. 참조를 제거하려면 해당 chip을 선택합니다.

<Frame caption="+ 메뉴가 열린 Generate media 양식으로, Upload file과 Select canvas 요소가 표시된 모습.">
  <img src="/assets/mirror/canvas-generate-media-references-ac0cb4340acb.png" alt="Canvas의 Generate media 양식에서 플러스 메뉴가 열려 Upload file 및 Select canvas 요소 옵션과 Nano Banana Pro로 설정된 model 드롭다운이 표시된 모습" width="1134" height="662" data-path="images/replitai/canvas-generate-media-references.png" />
</Frame>

<Note>
  ChatGPT Images 2.0은 현재 upload를 지원하지 않습니다. 시각적 참조를 첨부하려면 Nano Banana Pro 등 다른 model로 전환하세요.
</Note>

**Add menu**가 활성화되면 Generate 버튼이 **+** 메뉴로 바뀌며, 이 메뉴는 popover의 항목들을 **Design**(실제 코드를 건드리지 않는 독립형 시각적 mockup)과 함께 하나로 모아 보여줍니다.

**Gate:** 이미지 생성. **Vector Graphic**은 벡터 그래픽 생성이, **Video**는 비디오 생성이 필요합니다. **+** 메뉴는 Add menu가 필요하며, Add menu 자체는 이미지 생성이 필요합니다.

<div id="board-navigation">
  ## board 탐색
</div>

패닝, 확대/축소, 선택 제스처와 이에 해당하는 키보드 단축키는 Toolbar의 도구가 아니라 board 수준의 동작입니다. Canvas 페이지의 [board 탐색하기](/ko/design/canvas#navigate-the-board)를 참고하세요.
