title: "黑盒渗透测试"
description: "执行 Level 3 安全检查，审查源代码并通过浏览器和网络交互测试正在运行的应用。"
---

黑盒渗透测试通过浏览器和网络交互，从外部检测正在运行的应用，不会使用应用的源代码。

在 Project Security Center 中，**Level 3 (AI pentest)** 包含三类安全检查：

1. 免费的依赖项和包检查
2. Agent 对您的源代码进行静态分析
3. 对当前 Preview 进行外部黑盒测试，从外部执行且不使用您的源代码

启动 Level 3 后，Replit 会并行执行 Agent 的源代码审查和外部黑盒测试。

<div id="executar-uma-verificao-de-nvel-3">
  ## 运行 Level 3 检查
</div>

<Steps>
  <Step title="打开项目">
    打开要检查的项目。
  </Step>

  <Step title="打开 Security Center">
    在项目的 **Tools** 面板中，选择 **Security Center**。
  </Step>

  <Step title="启动检查">
    在 Security Center 顶部，选择 **Run scan**。
  </Step>

  <Step title="选择 Level 3">
    选择 **Level 3 (AI pentest)**。

    <Frame caption="Level 3 (AI pentest) 在免费的依赖项和包检查基础上，增加了 Agent 静态分析以及对当前 Preview 的外部测试。">
      <img src="/assets/mirror/level-3-ai-pentest-c223c0099d3f.png" alt="从 Tools 面板打开的 Security and Privacy Center，其中 Select scan level 菜单已展开，并选中了 Level 3 AI pentest 选项" width="2204" height="1200" data-path="images/project-security-center/level-3-ai-pentest.png" />
    </Frame>
  </Step>

  <Step title="等待两项任务完成">
    等待源代码审查以及浏览器和网络黑盒测试完成。
  </Step>

  <Step title="查看结果">
    在 **Security** 面板中查看两项任务的发现结果。将接受的问题发送给 Agent 前，请先评估每项发现。
  </Step>

  <Step title="修复并重新运行">
    将接受的发现发送给 Agent。应用修复后，再运行一次 Level 3 检查以确认修复是否生效。
  </Step>
</Steps>

<div id="entenda-as-duas-tarefas">
  ## 了解两项任务
</div>

| 任务     | 使用的证据               | 目的                      |
| ------ | ------------------- | ----------------------- |
| 源代码审查  | 您的应用源代码             | 识别代码库中安全、隐私和架构方面的漏洞     |
| 黑盒渗透测试 | 与正在运行的应用之间的浏览器和网络交互 | 在不使用源代码的情况下检查可从外部观察到的行为 |

请审查两组发现。一项任务不能替代另一项：代码审查可以识别易受攻击的实现细节，而黑盒测试则从外部评估正在运行的应用。
