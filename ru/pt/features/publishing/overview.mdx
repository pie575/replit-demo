---

Инструмент Publishing — это место, где вы публикуете своё приложение и управляете его работой в вебе. Он собирает всё в одной панели: веб-адрес приложения, список тех, кто может им пользоваться, продакшен-базу данных, мониторинг, безопасность и настройки, определяющие, как приложение размещается.

Чтобы открыть его, выберите **Publishing** в разделе **Replit Cloud** на панели **Tools** или нажмите **Publish** в правом верхнем углу Project Editor.

<div id="publique-seu-app">
  ## Опубликуйте свое приложение
</div>

Основная панель проведет вас по всем шагам, необходимым для запуска приложения. Просмотрите каждый раздел и нажмите **Publish**.

<Frame>
  <img src="/assets/mirror/publish-your-app-851815208b8a.png" alt="Панель Publish your app с полем Domain, публикуемым приложением, настройками доступа, настройками базы данных, мониторингом, безопасностью и инструментами вовлечения над кнопкой Publish" width="578" height="980" data-path="images/deployments/publish-pane/publish-your-app.png" />
</Frame>

* **Domain**: веб-адрес вашего приложения. Replit предлагает имя в зоне `.replit.app` и проверяет, свободно ли оно. Вы можете изменить его или подключить [собственный домен](/ru/pt/features/publishing/custom-domains) после публикации.
* **What you&#39;re publishing**: предварительный просмотр приложения, которое будет запущено, и URL, по которому оно будет доступно.
* **Who can access your app**: выберите **Public**, **Password protected**, **Workspace only** или **Invite only**. Приватные варианты ограничивают доступ к приложению вашим workspace либо теми людьми и группами, которых вы пригласите. Подробнее о [доступе к приложению](/ru/pt/features/publishing/private-deployments).
* **Database settings**: настройте, как при публикации создается и наполняется данными продакшен-база данных вашего приложения. Подробнее о [продакшен-базах данных](/ru/pt/features/data-and-storage/development-and-production).
* **Monitoring tools**: включите мониторинг приложения, чтобы первым узнавать о сбоях. Replit постоянно проверяет доступность приложения и отправляет письмо, если что-то пойдет не так. Подробнее о [мониторинге приложения](/ru/pt/features/publishing/monitoring-a-deployment).
* **Security tools**: выполните углубленную проверку безопасности перед публикацией. Security Agent сочетает ИИ с ведущими инструментами статического анализа и ищет уязвимости в вашем project. Подробнее — в [Project Security Center](/ru/pt/features/security/project-security-center).
* **Engagement tools**: включите виджет обратной связи, чтобы в углу опубликованного приложения появилась кнопка отзыва. Просматривайте присланные отзывы во входящих и передавайте их Agent для исправлений.

<div id="ajustar-configuraes">
  ## Настройка параметров
</div>

Выберите **Adjust settings**, чтобы вручную настроить, как размещается ваше приложение. Большинству создателей никогда не приходится менять эти параметры — Replit подбирает разумные значения по умолчанию.

<Frame>
  <img src="/assets/mirror/adjust-settings-d6e124b2249f.png" alt="Раздел Adjust settings с типом deployment, конфигурацией машины, секретами deployment, географией deployment и переключателем блокировки публикации при критических уязвимостях" width="574" height="794" data-path="images/deployments/publish-pane/adjust-settings.png" />
</Frame>

* **Deployment type**: технология, используемая для публикации приложения. **Autoscale** рекомендуется для большинства приложений, так как масштабируется от нуля до любого уровня нагрузки. Сравните [типы deployment](/ru/pt/features/publishing/deployment-types).
* **Machine configuration**: мощность серверов, на которых работает ваше приложение. Выберите **Edit**, чтобы изменить процессор, память и максимальное количество машин. На панели отображается стоимость одной машины и стоимость при пиковом трафике. Подробнее о [конфигурации машины](/ru/pt/features/publishing/machine-configuration).
* **Deployment secrets**: приватные ключи, с помощью которых приложение обращается к API и сервисам (защищённое скрытое хранилище для конфиденциальных значений, например ключей API). Секреты автоматически синхронизируются из среды разработки в опубликованное приложение. Подробнее о [Secrets](/ru/pt/core-concepts/project-editor/app-setup/secrets).
* **Deployment geography**: где размещается ваше приложение. Чем ближе выбранный регион к вашим пользователям, тем ниже задержка. После публикации приложение и его ресурсы привязываются к этому региону. Чтобы сменить регион позже, сделайте ремикс приложения. Подробнее о [географии project](/ru/pt/features/publishing/project-geography).
* **Block publishing of critical vulnerabilities**: Replit всегда выполняет проверку безопасности перед публикацией. Этот параметр определяет, блокируется ли публикация при обнаружении критических уязвимостей. Подробнее в [Project Security Center](/ru/pt/features/security/project-security-center).
