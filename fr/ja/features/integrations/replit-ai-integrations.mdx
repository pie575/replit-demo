Avec l&#39;intégration Replit AI, créer des applications dopées à l&#39;IA devient un jeu d&#39;enfant. Utilisez immédiatement les modèles d&#39;OpenAI, Anthropic, Google et OpenRouter — sans avoir à configurer de compte développeur ni à gérer de clés API. Replit s&#39;occupe de tout.

<div id="replit-ai">
  ## Qu&#39;est-ce que l&#39;intégration Replit AI ?
</div>

L&#39;intégration Replit AI offre un accès géré aux modèles d&#39;IA des principaux fournisseurs. Vous pouvez créer des applications de chat, des générateurs de contenu et des outils dopés à l&#39;IA sans quitter Replit. Inutile de créer des comptes développeur externes, de chercher des identifiants d&#39;API ou de gérer une facturation distincte.

Avec l&#39;intégration Replit AI, Replit gère les identifiants d&#39;IA des fournisseurs et vous facture au tarif public de l&#39;API. Votre consommation est débitée de vos crédits Replit et s&#39;affiche par Replit App sur la [page d&#39;utilisation](/fr/ja/billing/managing-spend).

<Note>
  L&#39;intégration Replit AI nécessite un forfait payant (Core, Pro ou Enterprise). Le [forfait Starter](/fr/ja/billing/plans/starter-plan) vous permet de créer des applications d&#39;IA avec vos propres clés d&#39;API. Consultez la [disponibilité selon les forfaits](#plan-availability).
</Note>

<div id="section">
  ## Fonctionnalités
</div>

L&#39;intégration Replit AI simplifie le développement avec l&#39;IA grâce à un accès intégré et une facturation transparente :

* **Aucune configuration** : aucun compte développeur ni clé API n&#39;est nécessaire pour démarrer
* **Identifiants gérés** : Replit se charge de l&#39;authentification auprès des fournisseurs et de la gestion des identifiants
* **Facturation transparente** : vous payez les tarifs publics des API, débités de vos crédits Replit
* **Suivi de la consommation** : consultez la consommation par Replit App sur la page d&#39;utilisation
* **Prise en charge multi-stack** : compatible avec tous les langages de programmation et frameworks
* **BYOK en option** : utilisez votre propre clé API si vous préférez vos propres identifiants

<div id="section-2">
  ## Introduction
</div>

<div id="replit">
  ### Utiliser les identifiants gérés par Replit
</div>

Avec une offre payante, lorsque vous mentionnez une fonctionnalité d&#39;IA ou un fournisseur spécifique (OpenAI, Anthropic, Google ou OpenRouter) dans un prompt, Agent utilise par défaut l&#39;intégration Replit AI :

<AiPrompt>
  Create a web app that uses OpenAI to summarize articles
</AiPrompt>

Pour savoir quelle intégration est utilisée, repérez dans la première réponse au prompt les mentions **« OpenAI (géré par Replit) »**, **« Anthropic (géré par Replit) »**, **« Google (géré par Replit) »** ou **« OpenRouter (géré par Replit) »**. Cela indique qu&#39;Agent utilise les identifiants de Replit au lieu de vous demander votre propre clé API.

**Lors de la première création d&#39;une nouvelle application** : lorsque vous envoyez votre premier prompt pour créer une application intégrant des fonctionnalités d&#39;IA, l&#39;intégration Replit AI est associée automatiquement. Agent commence aussitôt à construire avec les identifiants gérés.

**Pour une Replit App existante** : si Agent détecte qu&#39;il doit ajouter des fonctionnalités d&#39;IA à une Replit App existante, il vous indique explicitement dans l&#39;éditeur de projet qu&#39;il utilisera l&#39;intégration Replit AI. Une demande de confirmation s&#39;affiche :

<Frame>
  <img src="/assets/mirror/replit-ai-integrations-confirmation-msg-9440681ad7d3.png" alt="Boîte de dialogue de confirmation de l'intégration OpenAI affichant un message sur l'ajout d'OpenAI via les services gérés de Replit sans clé API, avec les boutons Refuser et Approuver" width="924" height="294" data-path="images/replitai/replit-ai-integrations-confirmation-msg.png" />
</Frame>

Cliquez sur « Approuver » pour continuer avec les identifiants gérés par Replit, ou sur « Refuser » pour utiliser votre propre clé API.

L&#39;utilisation est suivie automatiquement et facturée sur votre compte Replit au tarif public de l&#39;API.

<div id="api">
  ### Utiliser vos propres clés API
</div>

Si vous souhaitez utiliser vos propres identifiants OpenAI, Anthropic, Google ou d&#39;un autre fournisseur plutôt que l&#39;intégration Replit AI, plusieurs options s&#39;offrent à vous :

**Lors de la première création d&#39;une nouvelle app** : précisez dans votre prompt que vous souhaitez utiliser votre propre clé API :

<AiPrompt>
  Create a web app that uses OpenAI to summarize articles. Use my own OpenAI API key.
</AiPrompt>

La réponse affiche le nom du fournisseur (sans la mention « géré par Replit »), ce qui indique que l&#39;Agent vous demandera une clé API.

**Pour une Replit App existante** : lorsque l&#39;Agent vous indique qu&#39;il utilise l&#39;intégration Replit AI et affiche l&#39;invite de confirmation, cliquez sur « Refuser » plutôt que sur « Approuver ».

Dans les deux cas, l&#39;Agent développe l&#39;app jusqu&#39;au premier point de contrôle avant de vous demander la clé API. Il peut ainsi mettre en place la structure du projet, puis marquer une pause pour recueillir les identifiants avant de poursuivre.

Lorsque vous utilisez vos propres clés API, la facturation se fait directement auprès du fournisseur, et non via les crédits Replit.

</div>

La consommation de toutes les intégrations Replit AI apparaît avec le reste de votre consommation Replit sur la [page d&#39;utilisation](/fr/ja/billing/managing-spend). Elle est détaillée par Replit App, ce qui vous permet de voir précisément à quoi servent vos dépenses liées à l&#39;IA.

<div id="section-4">
  ## Fournisseurs pris en charge
</div>

L&#39;intégration Replit AI prend actuellement en charge :

* **OpenAI** : modèles multimodaux pour la génération de texte, le raisonnement et l&#39;audio. Prise en charge des complétions de chat, des réponses, de la génération d&#39;images, de la transcription audio (`gpt-4o-transcribe`, `gpt-4o-mini-transcribe`) et de la sortie audio (`gpt-audio`, `gpt-audio-mini`).
* **Anthropic** : modèles multimodaux pour le raisonnement, la rédaction et le codage. Prise en charge des interactions avec l&#39;API Messages et la recherche web.
* **Google (Gemini)** : modèles multimodaux pour la génération de texte et le raisonnement. Prise en charge de la génération de texte et d&#39;images.
* **OpenRouter** : accès aux modèles de fournisseurs tels que Microsoft (série Phi), Meta (série Llama), Mistral, Qwen, DeepSeek, Nvidia et Amazon.

<Note>
  L&#39;intégration Replit AI prend en charge les sorties **texte, image et audio**. La sortie vidéo n&#39;est pas prise en charge. Si vous avez besoin de fonctionnalités de génération vidéo, vous devez utiliser votre propre clé API auprès d&#39;un fournisseur qui les propose.
</Note>

<div id="openrouter-2">
  ## Confidentialité et disponibilité d&#39;OpenRouter
</div>

Lorsque vous utilisez OpenRouter via l&#39;intégration Replit AI, les requêtes sont envoyées avec des paramètres de confidentialité spécifiques afin de protéger vos données. Il est important de bien comprendre ces paramètres, car ils peuvent avoir une incidence sur les modèles disponibles.

<div id="section-6">
  ### Paramètres de confidentialité pour les utilisateurs en libre-service
</div>

Pour les utilisateurs individuels et les équipes, Replit applique les paramètres de confidentialité par défaut suivants aux requêtes OpenRouter :

* **Entraînement désactivé sur les points de terminaison payants** : les données ne sont pas utilisées à des fins d&#39;entraînement par les fournisseurs de modèles payants
* **Entraînement activé sur les points de terminaison gratuits** : les fournisseurs de modèles gratuits peuvent s&#39;entraîner sur les invites et les complétions
* **Publication activée sur les points de terminaison gratuits** : les fournisseurs gratuits peuvent publier les invites et les complétions dans des jeux de données publics
* **Journalisation des entrées et sorties désactivée** : les requêtes et les réponses ne sont pas journalisées par OpenRouter en échange de la remise de 1 % sur la facturation
* **Cookies d&#39;analyse désactivés** : aucun cookie d&#39;analyse n&#39;est utilisé

Ces paramètres privilégient la confidentialité tout en donnant accès à la plus large gamme de modèles possible. Toutefois, les modèles exigeant des paramètres de confidentialité différents de ceux définis ci-dessus **peuvent ne pas être disponibles**.

<div id="enterprise">
  ### Paramètres de confidentialité Enterprise
</div>

Pour les organisations Enterprise, Replit applique des contrôles de confidentialité plus stricts :

* **Points de terminaison à rétention de données nulle (ZDR) uniquement** : seuls les modèles assortis d&#39;une politique de rétention de données nulle sont disponibles
* Tous les paramètres de confidentialité décrits ci-dessus pour les utilisateurs en libre-service s&#39;appliquent également
* Les requêtes Enterprise sont donc acheminées exclusivement vers des points de terminaison qui ne conservent aucune donnée

Comme Enterprise impose l&#39;usage exclusif de points de terminaison ZDR, **le choix de modèles disponibles est plus restreint** que pour les utilisateurs en libre-service. Ce compromis garantit le plus haut niveau de confidentialité des données pour les charges de travail d&#39;entreprise.

<div id="section-7">
  ## Disponibilité selon les plans
</div>

Les intégrations Replit AI nécessitent un plan payant. Les modalités d&#39;accès varient selon le plan.

<div id="starter">
  ### Starter (gratuit)
</div>

Avec le plan Starter, l&#39;intégration de Replit AI est désactivée. Vous pouvez créer des applications d&#39;IA avec votre propre clé API. Consultez [Utiliser votre propre clé API](#bringing-your-own-api-key).

<div id="core">
  ### Core
</div>

Le plan Core vous permet de créer des applications d&#39;IA avec l&#39;intégration Replit AI grâce à des identifiants gérés par Replit — aucune clé API à gérer.

<div id="proenterprise">
  ### Pro et Enterprise
</div>

Dans les organisations Pro et Enterprise, l&#39;accès à l&#39;intégration Replit AI est désactivé par défaut. Les administrateurs de l&#39;organisation peuvent contrôler cet accès depuis la page des paramètres de l&#39;organisation :

1. Accédez aux paramètres de l&#39;organisation
2. Repérez la section Intégration Replit AI
3. Activez ou désactivez l&#39;accès pour votre organisation

Une fois l&#39;accès activé, les membres de l&#39;organisation peuvent utiliser l&#39;intégration Replit AI dans leurs applications. L&#39;ensemble de la consommation est suivi et facturé au compte de l&#39;organisation. Si l&#39;accès est désactivé, les membres doivent fournir leurs propres clés API pour utiliser les fournisseurs de modèles d&#39;IA.

<div id="section-8">
  ## Cas d&#39;usage
</div>

Créez de puissantes applications d&#39;IA sur n&#39;importe quelle stack technique :

* **Génération de contenu** : résumez des articles, générez des descriptions, créez du contenu
* **Analyse et insights** : extrayez des informations clés, analysez les sentiments, classez du texte
* **Interfaces conversationnelles** : créez des chatbots et des assistants IA
* **Transformation de texte** : traduisez, reformulez et mettez en forme du contenu
* **Assistance au code** : générez des extraits de code, expliquez des algorithmes, relisez du code
