---

Publishing 工具用于将应用发布上线，并管理它在网络上的运行方式。它把所有内容集中在一个面板中：应用的网址、谁可以访问、生产数据库、监控、安全，以及控制托管方式的各项设置。

要打开该工具，请在 **Tools** 面板的 **Replit Cloud** 下选择 **Publishing**，或在 Project Editor 右上角选择 **Publish**。

<div id="publique-seu-app">
  ## 发布你的应用
</div>

主面板会引导你完成应用上线所需的各项准备。逐项检查后，选择 **Publish**。

<Frame>
  <img src="/assets/mirror/publish-your-app-851815208b8a.png" alt="Publish your app 面板，显示 Domain 字段、待发布的应用、访问设置、数据库设置、监控、安全和互动工具，下方为 Publish 按钮" width="578" height="980" data-path="images/deployments/publish-pane/publish-your-app.png" />
</Frame>

* **Domain**：应用的网址。Replit 会推荐一个 `.replit.app` 名称并检查是否可用。你可以修改它，也可以在发布后绑定[自定义域名](/zh/pt/features/publishing/custom-domains)。
* **What you&#39;re publishing**：即将上线的应用预览，以及它将使用的 URL。
* **Who can access your app**：选择 **Public**、**Password protected**、**Workspace only** 或 **Invite only**。私有选项会将应用的访问范围限制在你的 workspace 内，或仅限你邀请的人员和群组。详细了解[应用访问权限](/zh/pt/features/publishing/private-deployments)。
* **Database settings**：管理发布时如何创建应用的生产数据库并填充数据。详细了解[生产数据库](/zh/pt/features/data-and-storage/development-and-production)。
* **Monitoring tools**：启用应用监控，第一时间获知应用宕机。Replit 会持续检查应用是否在线，一旦出现问题就发送电子邮件通知。详细了解[监控你的应用](/zh/pt/features/publishing/monitoring-a-deployment)。
* **Security tools**：在发布前运行深度安全扫描。Security Agent 将 AI 与主流静态分析工具相结合，检查 project 中的漏洞。详见 [Project Security Center](/zh/pt/features/security/project-security-center)。
* **Engagement tools**：启用反馈组件，在已发布应用的角落添加一个反馈按钮。你可以在收件箱中查看提交的反馈，并将其发送给 Agent 进行修复。

<div id="ajustar-configuraes">
  ## 调整设置
</div>

选择 **Adjust settings** 可手动配置应用的托管方式。大多数创作者无需更改这些设置，Replit 会自动选择合理的默认值。

<Frame>
  <img src="/assets/mirror/adjust-settings-d6e124b2249f.png" alt="Adjust settings 部分，显示 deployment 类型、机器配置、deployment secrets、deployment 地域以及阻止发布严重漏洞的开关" width="574" height="794" data-path="images/deployments/publish-pane/adjust-settings.png" />
</Frame>

* **Deployment type**：用于发布应用的技术。推荐大多数应用使用 **Autoscale**，因为它能从零弹性扩展到任意需求水平。可对比各种 [deployment 类型](/zh/pt/features/publishing/deployment-types)。
* **Machine configuration**：运行应用的服务器性能。选择 **Edit** 可更改 CPU、内存和最大机器数量。面板会显示每台机器的费用以及流量峰值时的费用。详细了解[机器配置](/zh/pt/features/publishing/machine-configuration)。
* **Deployment secrets**：应用访问 API 和服务时所用的私有密钥 (用于存放 API 密钥等敏感值的安全隐藏存储区) 。Secrets 会自动从开发环境同步到已发布的应用。详细了解 [Secrets](/zh/pt/core-concepts/project-editor/app-setup/secrets)。
* **Deployment geography**：应用的托管位置。选择更靠近用户的区域可以降低延迟。发布后，应用及其资源会绑定到该区域。若之后需要更换区域，请对应用进行 remix。详细了解 [project 地域](/zh/pt/features/publishing/project-geography)。
* **Block publishing of critical vulnerabilities**：Replit 在发布前始终会执行安全扫描。此设置用于控制发现严重漏洞时是否阻止发布。更多信息请参阅 [Project Security Center](/zh/pt/features/security/project-security-center)。
