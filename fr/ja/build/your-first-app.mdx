export const PromptActions = ({prompt = "", campaign = "docs-prompt-actions"}) => {
  const LZ_SRC = "https://cdnjs.cloudflare.com/ajax/libs/lz-string/1.5.0/lz-string.min.js";
  const ensureLZString = () => {
    if (typeof document === "undefined") return;
    if (window.LZString) return;
    if (document.querySelector(`script[src="${LZ_SRC}"]`)) return;
    const s = document.createElement("script");
    s.src = LZ_SRC;
    s.async = true;
    document.head.appendChild(s);
  };
  const handleCopy = async e => {
    const btn = e.currentTarget;
    if (!prompt) return;
    try {
      await navigator.clipboard.writeText(prompt);
    } catch {
      const ta = document.createElement("textarea");
      ta.value = prompt;
      document.body.appendChild(ta);
      ta.select();
      try {
        document.execCommand("copy");
      } catch {}
      document.body.removeChild(ta);
    }
    const original = btn.dataset.label || btn.innerText;
    btn.dataset.label = original;
    btn.innerText = "Copié !";
    setTimeout(() => {
      if (btn.isConnected) btn.innerText = original;
    }, 1500);
  };
  const handleBuild = () => {
    if (!prompt || typeof window === "undefined") return;
    const utm = `utm_source=replit-docs&utm_medium=docs&utm_campaign=${encodeURIComponent(campaign)}&utm_content=prompt-actions`;
    let url;
    if (window.LZString) {
      const encoded = window.LZString.compressToEncodedURIComponent(prompt);
      url = `https://replit.com/?prompt=${encoded}&referrer=replit-docs&${utm}`;
    } else {
      url = `https://replit.com/?prompt=${encodeURIComponent(prompt)}&referrer=replit-docs&${utm}`;
    }
    window.open(url, "_blank", "noopener,noreferrer");
  };
  ensureLZString();
  const baseButtonStyle = {
    display: "inline-flex",
    alignItems: "center",
    gap: "6px",
    padding: "8px 16px",
    borderRadius: "8px",
    fontSize: "14px",
    fontWeight: 500,
    cursor: "pointer",
    lineHeight: 1.2,
    fontFamily: "inherit",
    textDecoration: "none"
  };
  return <div style={{
    display: "flex",
    gap: "12px",
    margin: "16px 0",
    flexWrap: "wrap",
    alignItems: "center"
  }}>
      <button type="button" onClick={handleCopy} style={{
    ...baseButtonStyle,
    background: "transparent",
    color: "inherit",
    border: "1px solid rgba(127,127,127,0.4)"
  }}>
        Copier le prompt
      </button>
      <button type="button" onClick={handleBuild} style={{
    ...baseButtonStyle,
    background: "#F26207",
    color: "#FFFFFF",
    border: "1px solid #F26207"
  }}>
        Build sur Replit ↗
      </button>
    </div>;
};

export const GATHER_PROMPT = `Créez une application responsive de découverte d'ateliers appelée Gather.

Les visiteurs doivent pouvoir parcourir les ateliers à venir, consulter les détails des événements et confirmer leur participation à l'aide de données d'exemple réalistes.

L'objectif est que la navigation fonctionne, qu'une confirmation claire s'affiche après l'envoi d'une participation et que la mise en page fonctionne correctement sur mobile comme sur ordinateur.

N'ajoutez pas encore de connexion, de base de données, de paiements ni d'intégrations externes.`;

⏰ *Durée : 10 minutes*

À la fin de ce guide, vous aurez utilisé le **mode Free** pour créer et améliorer une petite application à partir d’un prompt.

<div id="section">
  ## Avant de commencer
</div>

Vous avez besoin d’un [compte Replit](https://replit.com). Ce guide utilise le **mode Free**, qui s’appuie sur Auto pour sélectionner le modèle.{FreeModePlanAvailability}

L’objectif est de vous entraîner à suivre un cycle de prompts réutilisable :

1. Décrivez un résultat utile.
2. Ajoutez des critères de réussite observables.
3. Définissez les limites de ce que vous ne souhaitez pas encore créer.
4. Testez le résultat dans Preview.
5. Demandez une amélioration ciblée.

<div id="section-2">
  ## Créer la première version
</div>

<Steps>
  <Step title="Créer un nouveau Website">
    Démarrez une nouvelle conversation et sélectionnez **Website** comme artefact. Vous pouvez le sélectionner dans le menu **New** ou via **Add attachment → Create something new → Website** dans la zone de saisie.

    Ouvrez le sélecteur de mode et choisissez **Free**.

    <Tip>
      Vous pouvez aussi demander directement à Replit de créer un site web en langage naturel. Sélectionner Website au préalable clarifie l&#39;artefact souhaité et ajoute une pastille Website au prompt.
    </Tip>
  </Step>

  <Step title="Décrire le résultat attendu et les critères de réussite">
    Utilisez le prompt suivant :

    <PromptActions prompt={GATHER_PROMPT} campaign="docs-your-first-app" />

    <Frame>
      <img src="/assets/mirror/01-prompt-free-mode-f5c56ce766c8.jpg" alt="Prompt Gather prêt à être envoyé, avec l'artefact Website sélectionné et le mode Free activé" width="1280" height="720" data-path="images/first-app-gather/01-prompt-free-mode.jpg" />
    </Frame>

    Ce prompt commence par un résultat attendu : une application permettant de découvrir des ateliers. Il décrit ensuite ce que les visiteurs doivent pouvoir faire, définit des critères de réussite observables et reporte à plus tard la connexion, les données, les paiements et les intégrations.

    Ces limites permettent de garder la première version ciblée. Vous pourrez ajouter des fonctionnalités prêtes pour la production une fois que l&#39;expérience principale fonctionnera correctement.
  </Step>

  <Step title="Laisser Agent créer l'application en mode Free">
    Envoyez le prompt. Agent planifie l&#39;artefact, crée l&#39;application, la lance et vérifie le résultat. Suivez la progression dans le chat et attendez qu&#39;Agent présente l&#39;artefact Website et que le Preview s&#39;affiche.

    La première version complète peut prendre quelques minutes en mode Free. Si Replit recommande un mode supérieur pour des demandes plus complexes, vous décidez vous-même si vous souhaitez passer à ce mode. Cette version de Gather se termine en mode Free.

    <Frame>
      <img src="/assets/mirror/02-first-version-163a5fb49aac.jpg" alt="Premier Website Gather fonctionnel affiché dans la mise en page Build par défaut, avec le chat Agent et le Preview" width="1393" height="868" data-path="images/first-app-gather/02-first-version.jpg" />
    </Frame>
  </Step>

  <Step title="Tester le résultat dans le Preview">
    Essayez d&#39;utiliser l&#39;application comme le ferait un visiteur. Vérifiez les points suivants :

    * Vous pouvez parcourir la liste des ateliers.
    * Vous pouvez ouvrir la page de détails d&#39;un atelier.
    * Vous pouvez envoyer une RSVP.
    * Une confirmation claire s&#39;affiche après l&#39;envoi.
    * Vous pouvez utiliser la navigation principale.
    * Vous pouvez redimensionner le Preview à une largeur de téléphone.

    Comparez le résultat aux critères de réussite du prompt. Si quelque chose ne fonctionne pas, décrivez le symptôme à Agent plutôt que d&#39;essayer de diagnostiquer le code vous-même.
  </Step>
</Steps>

<div id="section-3">
  ## Améliorer votre app avec des prompts ciblés
</div>

Une fois l’expérience principale opérationnelle, demandez une amélioration claire à la fois. Pour Gather, ajoutez une vue limitée à la session pour les RSVP envoyés :

> Ajoutez une vue My RSVPs pour que les ateliers auxquels vous avez répondu apparaissent pendant la session en cours. Conservez le style visuel existant et n’ajoutez ni connexion ni base de données.
