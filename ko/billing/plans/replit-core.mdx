[Replit Core](https://replit.com/replit-core) 멤버십에 가입하면 아이디어를 앱으로 빠르게 구현할 수 있는 프리미엄
도구를 사용할 수 있습니다. 현재 Core 요금(월간 또는 연간)은 [요금제 페이지](https://replit.com/pricing)에서 확인하세요.

<div id="key-features">
  ## 주요 기능
</div>

Replit Core 멤버십은 다음 기능을 제공합니다:

<div id="ai-powered-tools">
  ### AI 기반 도구
</div>

* **Agent**: Agent와 대화하며 앱을 만들고, 디버깅하고, 개선하세요
* **유료 Agent 모드**: 더 강력한 성능이 필요할 때 Power 또는 Max를 사용하세요
* **Free Mode**: 허용량 내에서 추가 비용 없이 Agent와 대화하며 앱을 만드세요
* **지능형 모델 라우팅**: Power 또는 Max에서 유료 작업마다 Replit이 알아서 모델을 선택합니다
* **Design Canvas**: 시각적 아이디어를 탐색하고 다양한 변형을 생성하며 디자인을 artifact로 전환하세요
* **Visual Editor**: 앱의 콘텐츠와 레이아웃을 시각적으로 직접 편집하세요
* **모든 artifact 유형**: 웹 앱, 모바일 앱, 데이터 시각화, 슬라이드 덱, 애니메이션 영상 등
* **Plan Mode**: 코드를 수정하지 않고 Agent와 함께 아이디어를 구상하고 작업을 계획하세요
* **Connectors**: Google, Stripe 등 서드파티 서비스와 연동하세요

<div id="collaboration">
  ### 협업
</div>

* 별도의 팀 구독 없이 최대 5명의 빌더를 Workspace에 초대
* 백그라운드 작업 — 동시에 1개의 활성 작업 실행
* 업무 계획 및 추적을 위한 공유 Kanban 보드

<div id="lightning-fast-and-secure-development">
  ### 번개처럼 빠르고 안전한 개발
</div>

* 고성능 클라우드 개발 환경에서 작업하세요
* 사용한 만큼만 지불하는 결제로 서비스 중단 없이 이용하세요
* Secrets 도구로 민감한 데이터를 코드와 분리해 안전하게 보관하세요

각 plan별 비용과 limit은 <a href="https://replit.com/pricing" target="_blank">요금제 페이지</a>에서
확인하세요.

<div id="monthly-credits">
  ### 월별 credits
</div>

* Agent, publishing, 네트워크 전송, database 스토리지, Replit AI Integrations 같은 유료 서비스에 자동으로 사용되는 월별 credits를 제공합니다. builders를 더 추가하거나 더 높은 credit 등급이 필요하신가요? [Replit Pro](/ko/billing/plans/replit-pro)를 참고하세요.

<div id="one-click-publishing">
  ### 원클릭 게시
</div>

Publishing은 모든 plan에서 사용할 수 있습니다. 무료 Starter plan에서는 published app 1개가 제공되지만, Replit Core에서는 이 제한이 사라져 무제한으로 이용할 수 있고 다음과 같은 옵션이 추가됩니다:

* 무제한으로 apps 게시
* 여러 게시 옵션 중에서 선택해 비용 최적화
* 내장 로깅 및 분석 이용
* published app에서 &quot;Made with Replit&quot; badge 제거

<div id="ai-powered-support-and-community-events">
  ### AI 기반 지원 및 커뮤니티 이벤트
</div>

* AI 기반 지원으로 결제, 계정, 제품, 기술 관련 문의를 빠르게 해결하세요
* 회원 전용 포럼과 이벤트에 참여하세요
* 새로운 기능을 가장 먼저 사용해 보세요

<div id="core-vs-starter-vs-pro">
  ## Core vs Starter vs Pro
</div>

| 기능                        | Starter   | Core | Pro |

| Intelligent model routing | ❌         | ✅    | ✅   |

| Design Canvas             | ✅         | ✅    | ✅   |

| Replit AI Integrations    | ❌         | ✅    | ✅   |

<div id="getting-started">
  ## 시작하기
</div>

몇 단계만 거치면 Replit Core로 업그레이드할 수 있습니다.

1. <a href="https://replit.com/pricing" target="_blank">Pricing</a> 페이지로 이동합니다.
2. **Join Replit Core**를 선택합니다.
3. **Monthly** 또는 **Yearly** 플랜을 선택하고 결제 정보를 입력합니다.
