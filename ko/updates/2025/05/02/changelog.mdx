<div id="replit-auth">
  ### Replit Auth
</div>

[Replit Auth](/ko/features/auth-and-identity/authentication)를 모든 사용자에게 공개했습니다! 최소한의 설정만으로 앱에 사용자 login 기능을 추가할 수 있는 내장 authentication 시스템입니다. 복잡한 authentication 시스템을 처음부터 만들 필요 없이, Replit Auth가 Replit 인프라와 통합된 안전하고 즉시 사용 가능한 솔루션을 제공합니다.

**주요 기능:**

* **설정 불필요** - Agent에 prompt 한 번만 입력하면 authentication 추가
* **내장 보안** - 일반적인 공격에 대한 보호 기능을 갖춘 Replit 인프라 사용
* **사용자 관리** - Auth pane에서 간편하게 사용자 관리
* **Database 통합** - database에 user entries 자동 생성
* **맞춤형 login 페이지** - 앱에 맞게 login 경험 개인화
* **비밀번호 재설정** - Replit이 비밀번호 재설정 이메일을 처리하므로 별도의 이메일 전송 provider 불필요

시작하는 방법은 간단합니다. Agent prompt에 Replit Auth 요청을 포함하기만 하면 됩니다.
