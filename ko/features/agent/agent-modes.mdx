Agent 모드를 사용하면 Agent를 사용할 때 비용과 성능 간의 균형을 조절할 수 있습니다. Agent 설정 드롭다운을 사용하여 **Free Mode**, **Power Mode**, **Max Mode** 중에서 모드를 선택하세요. Free Mode는 항상 Auto를 사용합니다. Core 및 Pro 플랜의 빌더는 Power Mode 또는 Max Mode에서 [Model selector](/ko/features/agent/model-selector)를 사용할 수 있습니다. 표시되는 모드와 설정은 사용 중인 플랜과 워크스페이스에 따라 달라집니다.

<Note>
  Economy Mode는 더 이상 제공되지 않습니다. Power Mode가 동일한 가격으로 이를 대체합니다.
</Note>

<Tip>
  **키보드 단축키:** **⌘+Shift+I**(Windows에서는 Ctrl+Shift+I)를 눌러 채팅 입력창을 벗어나지 않고 Agent 모드를 순환할 수 있습니다.
</Tip>

## Free Mode

**시작하기에 최적화되었습니다.** Free Mode는 아이디어를 탐색하고, Replit이 작동하는 방식을 배우고, 프로젝트를 시작하는 데 도움이 됩니다.

**참고 사항:** Free Mode는 항상 Replit의 지능형 모델 라우팅인 Auto를 사용합니다. 모델을 수동으로 선택하려면 Power Mode 또는 Max Mode를 사용하세요.

<Note>
  Core 및 Pro 플랜에는 5시간마다 갱신되는 Free Mode 할당량이 포함되어 있습니다. 할당량을 모두 사용하면 Replit이 언제 갱신되는지 표시합니다.
</Note>

Routines는 Free Mode에서 실행되지 않습니다. Power 또는 Max Mode에서 실행되며 실행당 예산이 필요합니다. 자세한 내용은 [Routines](/ko/chat/routines)를 참고하세요.

## Power Mode

**비용에 최적화되었습니다.** Power Mode는 작업당 더 적은 크레딧을 사용하며, 가장 능력 있는 모델에 비용을 들이지 않고도 좋은 결과를 원할 때 최적의 기본값입니다.

**적합한 경우:** 일상적인 빌드, 학습, 기존 프로젝트 전반에서의 비용 절약형 작업.

## Max Mode

**성능에 최적화되었습니다.** Max Mode는 복잡한 작업, 더 큰 코드베이스, 더 어려운 문제를 위해 더 능력 있는 모델을 사용합니다.

**적합한 경우:** 프로덕션 수준의 프로젝트, 복잡한 기능, Agent로부터 최상의 결과를 원할 때.

## 어떤 모드를 사용해야 할까요?

다음을 가이드로 사용하세요:

| 목표                                         | 권장 모드                                                                 |
| ------------------------------------------ | --------------------------------------------------------------------- |
| 아이디어를 탐색하고, Replit이 작동하는 방식을 배우고, 프로젝트를 시작 | Free Mode                                                             |
| 크레딧당 프롬프트 수 최대화                            | Power Mode                                                            |
| 대부분의 프로젝트에서 비용과 품질의 균형                     | Power Mode                                                            |
| 모델을 수동으로 선택                                | Power Mode 또는 Max Mode                                                |
| 복잡하고 프로덕션 수준의 작업에서 최상의 결과                  | Max Mode                                                              |
| 가장 복잡한 작업에서 최상의 결과                         | 더 높은 [Effort](/ko/features/agent/model-selector#effort)를 적용한 Max Mode |

채팅 입력의 Agent 설정 드롭다운을 사용하여 모드를 선택하세요. Core 및 Pro 플랜의 빌더는 Power Mode 또는 Max Mode에서 [프라이머리 모델과 Effort](/ko/features/agent/model-selector)를 설정할 수 있습니다. 항상 최적인 단일 모드는 없습니다. 눈앞의 작업에 맞는 모드를 선택하세요.

## 공유 프로젝트의 설정

Agent 설정은 프로젝트가 아니라 여러분에게 연결됩니다. 프로젝트에 팀원을 초대하면 각자 다음 항목에 대해 자신만의 선택을 유지합니다:

* 모드(Free Mode, Power Mode 또는 Max Mode)
* [프라이머리 모델과 Effort](/ko/features/agent/model-selector), 사용 가능한 경우
* [Plan 모드](/ko/features/agent/plan-mode)
* 백그라운드 작업의 자동 병합
* 계획의 자동 승인

팀원이 다음 작업에서 Max Mode로 전환해도 여러분의 설정이 Max Mode로 바뀌지는 않습니다. Agent 설정 드롭다운에서 보는 모드와 설정은 프로젝트에 협업자가 몇 명 있든 상관없이 다음 메시지를 보낼 때 Agent가 사용하는 설정입니다.

## Free Mode 할당량 확인하기

**Settings** → **Usage**를 열면 남은 Free Mode 할당량과 갱신 시점을 확인할 수 있습니다. 할당량을 최대한 활용하는 실용적인 방법은 [Free Mode 최대한 활용하기](/ko/chat/free-mode)를 참고하세요.

## 관련 문서

* [지출 관리](/ko/billing/managing-spend): 알림, 예산을 설정하고 Plan Mode를 사용하여 비용을 관리하세요.
* [Replit Pro](/ko/billing/plans/replit-pro): 플랜 기능과 계층형 크레딧.

Enterprise에서는 계정 관리자가 [Workspace Settings](/ko/features/collaboration/workspace-settings)를 사용하여 각 워크스페이스에서 사용 가능한 모델 제공업체와 모델을 제어합니다.
