Autoscale деплой работает на облачных вычислительных ресурсах, которые масштабируются для эффективной обработки сетевого трафика и рабочей нагрузки Replit App. Когда App активно, добавляются серверы для управления нагрузкой. Когда App простаивает, количество серверов сокращается вплоть до нуля, чтобы снизить расходы.

Autoscale деплой подходит для следующих сценариев:

* Веб-приложения с переменной рабочей нагрузкой и трафиком, например сайты электронной коммерции
* API и сервисы

<div id="section">
  ## Возможности
</div>

Autoscale-деплои включают следующие возможности:

* **Автоматическое масштабирование ресурсов**: ресурсы автоматически подстраиваются под характер трафика, оптимизируя расходы.
* **Пользовательские домены**: настройте пользовательский домен или используйте URL `<app-name>.replit.app` для доступа к App.
* **Настраиваемые ограничения**: задайте максимальное количество экземпляров, до которого может масштабироваться опубликованное App.
* **Гибкая производительность машины**: выберите необходимую для App конфигурацию CPU и RAM.
* **Мониторинг**: просматривайте логи и отслеживайте состояние опубликованного App.

<div id="section-2">
  ## Использование
</div>

Доступ к Autoscale-деплою можно получить в инструменте публикации редактора проекта.

<Accordion title="Как получить доступ к Autoscale-деплою">
  На левой **панели инструментов**:

  1. Выберите <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Иконка всех инструментов" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **Все инструменты**, чтобы открыть список инструментов редактора проекта.
  2. Выберите <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Иконка публикации" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Публикация**.
  3. Выберите **Autoscale**, затем **Настроить опубликованное App**.

  В **строке поиска**:

  1. Выберите значок <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="Иконка лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> лупы в верхней части, чтобы открыть поиск.
  2. Введите «Публикация», найдите инструмент и выберите его в результатах поиска.
  3. Выберите **Autoscale**, затем **Настроить опубликованное App**.
</Accordion>

<div id="section-3">
  ## Производительность машины
</div>

Нажмите **Редактировать**, чтобы просмотреть и настроить параметры производительности машины. С помощью ползунка выберите конфигурацию CPU и RAM для каждого серверного экземпляра опубликованного App.

В строке **Всего на машину** указан расход **вычислительных единиц** для выбранной конфигурации. Вычислительные единицы — это единица измерения ресурсов облачных вычислений, зависящая от конфигурации памяти и CPU машины.

Подробнее о расчёте расходов в вычислительных единицах см. в разделе [Вычислительные единицы](/ru/ko/billing/about-usage-based-billing#2-compute-units).

<div id="section-4">
  ## Максимальное количество машин
</div>

С помощью ползунка задайте максимальное количество машин. Это значение определяет максимальное число экземпляров серверов, которые функция автомасштабирования может выделить, когда App находится под высокой нагрузкой.

В нижней строке отображается соответствующее количество вычислительных единиц, рассчитанное по следующей формуле:

`количество машин * вычислительные единицы на машину`
