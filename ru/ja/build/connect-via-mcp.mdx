Replit Agent может подключаться к сотням внешних инструментов и источников данных через [Model Context Protocol (MCP)](https://modelcontextprotocol.io) — открытый стандарт интеграции ИИ-инструментов. Войдите в один из серверов из списка или добавьте доверенный пользовательский MCP-сервер.

<div id="mcp">
  ## Подключение к MCP-серверам из готового списка
</div>

Replit предлагает подборку MCP-серверов для популярных сервисов, включая Stripe, Linear, Notion и Sentry. Подключение выполняется одним нажатием кнопки входа.

<Frame>
  <img src="/assets/mirror/mcp-servers-pane-8e1f431ca33c.png" alt="Панель настройки MCP-серверов для Replit Agent со списком готовых серверов, включая Stripe, Linear, Notion, Sentry, Atlassian, Miro, PostHog, Amplitude, Mixpanel, Granola и Razorpay, с кнопками входа" width="3452" height="1988" data-path="images/replitai/mcp-servers-pane.png" />
</Frame>

<Steps>
  <Step title="Откройте панель интеграций">
    Перейдите на [replit.com/integrations](https://replit.com/integrations) и прокрутите страницу до раздела **MCP-серверы для Replit Agent**.
  </Step>

  <Step title="Выберите сервер">
    Найдите сервис, который хотите подключить: Stripe, Linear, Notion, Sentry, Atlassian, Miro, PostHog, Amplitude, Mixpanel, Granola, Razorpay и другие.
  </Step>

  <Step title="Войдите в аккаунт">
    Нажмите **Войти** рядом с сервером. Следуйте инструкциям OAuth для этого сервиса. После завершения подключения статус сервера обновится, и Agent сможет использовать этот инструмент.
  </Step>
</Steps>

Полный каталог доступен в [справочнике MCP-серверов](/ru/ja/features/mcp/overview).

<div id="mcp-2">
  ## Добавление пользовательского MCP-сервера
</div>

Если нужного сервера нет в каталоге, добавьте его по URL.

<Frame>
  <img src="/assets/mirror/mcp-connect-dialog-5b8f9b0d828e.png" alt="Диалог подключения MCP-сервера с полями отображаемого имени и URL MCP-сервера, а также сворачиваемым разделом дополнительных настроек" width="3452" height="1988" data-path="images/replitai/mcp-connect-dialog.png" />
</Frame>

<Steps>
  <Step title="Откройте диалог добавления сервера">
    В панели настроек MCP-сервера нажмите **+ Добавить MCP-сервер**.
  </Step>

  <Step title="Укажите отображаемое имя">
    Введите понятное имя — Agent будет использовать его при упоминании сервера в чате.
  </Step>

  <Step title="Введите URL сервера">
    Вставьте URL HTTPS-эндпоинта MCP-сервера. Если сервер требует аутентификации, откройте **Дополнительные настройки** и добавьте пользовательский заголовок, например `X-API-Key`.
  </Step>

  <Step title="Проверьте и сохраните">
    Нажмите **Проверить и сохранить**. Replit попытается подключиться к серверу и проведёт вас через необходимый OAuth-процесс. После сохранения подключение появится в списке MCP-серверов с указанием статуса.
  </Step>
</Steps>

<Warning>
  Подключайтесь только к доверенным MCP-серверам. Подключённые серверы могут предоставлять Agent доступ к инструментам и данным — проверяйте источник, прежде чем добавлять неизвестные эндпоинты.
</Warning>

<div id="agentmcp">
  ## Использование MCP-инструментов в Agent
</div>

После подключения сервера Agent автоматически получает список инструментов, и они становятся доступны во всех проектах. Чтобы использовать сервер, просто упомяните его в чате:

> Используйте MCP-сервер Notion, чтобы найти последние заметки со встреч.

<Frame>
  <img src="/assets/mirror/tool-call-7a53f51a11ae.png" alt="Agent вызывает инструменты пользовательского MCP-сервера в чате" width="571" height="817" data-path="images/replitai/custom-mcp/tool-call.png" />
</Frame>

Agent выбирает на сервере подходящий инструмент на основе вашего запроса. Если для инструмента требуется подтверждение, перед выполнением появится промпт.
