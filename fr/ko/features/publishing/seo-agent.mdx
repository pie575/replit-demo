SEO Agent effectue un audit technique de référencement de l’ensemble du projet et identifie les problèmes qui empêchent les moteurs de recherche et les robots d’IA d’indexer et de comprendre correctement votre application. Chaque problème détecté est accompagné d’une correction en un clic que vous pouvez examiner et appliquer avec Agent.

Cette fonctionnalité se trouve dans le panneau **Growth** du Project Editor et fonctionne sur les applications que vous avez déjà publiées. Pour la plupart des utilisateurs, le flux de travail est le suivant : publiez votre application, ouvrez SEO Agent, lancez une analyse, examinez les problèmes détectés, puis appliquez les corrections.

<div id="seo-agent">
  ## Ce que fait SEO Agent
</div>

SEO Agent se concentre sur le **SEO technique**, c’est-à-dire les éléments structurés et lisibles par les machines qui déterminent dans quelle mesure les moteurs de recherche et les robots d’IA peuvent facilement découvrir, indexer et comprendre une application.

Il examine votre projet et propose des correctifs pour les problèmes suivants :

* **Explorabilité et indexation** : `robots.txt`, `sitemap.xml`, ainsi que des liens explorables et une structure de pages adaptée.
* **Métadonnées des pages** : des balises `<title>` uniques et descriptives ainsi que des méta-descriptions sur chaque page.
* **Données structurées** : un balisage JSON-LD qui aide les moteurs de recherche à afficher des résultats enrichis.
* **Balises Open Graph et réseaux sociaux** : des métadonnées qui contrôlent l’affichage des aperçus lors du partage de liens.
* **Balisage sémantique** : une hiérarchie de titres correcte, des éléments de repère et un texte alternatif descriptif pour les images.

<Note>
  SEO Agent garantit que votre application est techniquement solide pour la recherche,
  mais il ne rédige pas de contenu et ne développe pas votre autorité thématique.
</Note>

<div id="section">
  ## Avant de commencer
</div>

Pour utiliser SEO Agent, vous devez disposer des éléments suivants :

* **Une application publiée.** SEO Agent audite un déploiement web accessible publiquement. Si vous n&#39;avez pas encore publié votre application, faites-le d&#39;abord. Pour connaître les types de déploiement compatibles avec le référencement, consultez [SEO Rating](/fr/ko/features/publishing/seo-rating).
* **Un plan payant.** SEO Agent est accessible aux créateurs disposant d&#39;un plan payant. Si vous utilisez le plan gratuit, une option de mise à niveau s&#39;affichera dans le panneau Growth.

Vous pouvez accéder à SEO Agent de deux façons : ouvrez directement le panneau **Growth** dans le Project Editor ou sélectionnez **Optimiser le SEO avec Agent** à côté de SEO Rating dans l&#39;outil **Publishing** pour ouvrir le panneau Growth, prêt à lancer l&#39;analyse.

<div id="section-2">
  ## Comment y accéder
</div>

SEO Agent fonctionne sur les applications publiées. Avant la publication, le panneau **Growth** est verrouillé et vous invite à accéder à **Go to Publishing**.

<Tip>
  Pour contrôler l’aperçu de votre application lorsqu’elle est partagée sur les réseaux sociaux, connectez un
  [domaine personnalisé](/fr/ko/build/add-custom-domain), puis publiez à nouveau. Les aperçus sur les réseaux sociaux et des
  liens utilisent l’URL de production publique de votre application. Un domaine personnalisé publié vous
  permet donc d’obtenir un aperçu fidèle.
</Tip>

<div id="seo-agent-seo-rating">
  ## SEO Agent et SEO Rating
</div>

Le **SEO Rating** affiché à côté de SEO Agent provient de l&#39;[audit Lighthouse automatique](/fr/ko/features/publishing/seo-rating) exécuté après chaque publication. Il classe l&#39;application comme Healthy, Needs Work ou Weak. Cette note indique *l&#39;état actuel de votre application*.
SEO Agent vous aide à *l&#39;améliorer* en analysant les problèmes et en appliquant des correctifs. Après les corrections, publiez à nouveau pour actualiser la note.

Vous pouvez également ignorer complètement l&#39;interface de scan et demander directement à Agent.
