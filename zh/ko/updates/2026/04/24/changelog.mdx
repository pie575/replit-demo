<div id="security-agent">
  ### Security Agent 会审查整个代码库
</div>

**Security Agent** 是一款全新的 AI 驱动审查工具，它不仅审计依赖项，还会审计整个项目。它会构建威胁模型，梳理路径与数据流，通过 Semgrep 和 HoundDog.ai 运行静态分析，并借助大语言模型判断在你的应用场景中哪些问题真正可被利用。审查完成后，Security Agent 会将已确认的问题整理成并行任务，交由 Replit Agent 一次性修复。

  <img src="/assets/mirror/security-agent-findings-b425392bb98a.png" alt="Project Security Center 的 Security Agent 面板，显示已完成的扫描，其中 5 个问题按严重程度分类，每个问题标注有“可供审查”或“可供重新发布”等状态，下方是列出存在漏洞的软件包的自动依赖项扫描部分" width="1438" height="808" data-path="images/changelog/2026-04-24/security-agent-findings.png" />

所有付费构建者均可使用 Security Agent。打开项目的**安全**面板，选择**使用 Agent 运行扫描**即可体验。

进一步了解 [Security Agent](/zh/core-concepts/security/project-security-center#agent-security-scans)。

<div id="cve-auto-protect">
  ### CVE Auto-Protect 自动修补严重漏洞
</div>

当应用所依赖的软件包出现新的严重 CVE 时，**CVE Auto-Protect** 会在你拥有的所有项目中检测受影响的匹配项，由 Agent 在后台任务中准备补丁并运行测试，确认不会影响现有功能，然后向你发送通知并附上查看链接。在你批准修复之前不会发布任何内容，控制权始终在你手中。

这样，新漏洞公开后几分钟内应用即可完成修补，无需等你自己发现问题。

进一步了解 [CVE Auto-Protect](/zh/core-concepts/security/project-security-center#auto-protect)。

<div id="ios-simulator-android-emulator">
  ### 在 iOS Simulator 或 Android Emulator 中预览
</div>

<Frame>
  <video autoPlay muted loop playsInline src="/assets/mirror/ios-emulator-9013ff1b602f.mp4" />
</Frame>

如果项目中包含移动应用，现在可以将真实的 **iOS Simulator** 或 **Android Emulator** 直接流式传输到工作区的预览面板中，无需 Xcode、Android Studio 或实体设备。用 Agent 构建移动应用，在预览面板的下拉菜单中选择设备，然后像拿着手机一样直接点按操作。Agent 一旦应用修改，模拟器会立即同步呈现。

该功能面向 Core、Pro、Enterprise 计划的付费构建者开放，支持 Chrome、Safari 及基于 Chromium 的浏览器。Firefox 不支持移动模拟器。

进一步了解[在模拟器或仿真器中预览](/zh/ko/features/artifact-types/building-mobile-apps#preview-on-a-simulator-or-emulator)。

<div id="section-4">
  ### 向现有 项目 添加移动应用
</div>

<Frame>
  <img src="/assets/mirror/multi-artifact-update-approval-f6fa8b70a100.png" alt="Agent 聊天面板，显示“更新 项目 以创建移动应用”审批卡片，卡片上有赠送 5 美元额度提示以及“暂不处理”／“更新 项目”按钮" width="991" height="589" data-path="images/replitai/multi-artifact-update-approval.png" />

在 Agent 4 上线之前创建的 项目，现在也可以更新为支持多个 artifact。也就是说，你可以向此前仅支持单个 artifact 的 项目 中添加移动应用、路演文稿或其他 artifact。在重构 项目 的过程中，Agent 会保留 URL、数据、密钥和部署。全面上线后的头 48 小时内，已有 200 多个 项目 完成迁移。

<div id="plaid">
  ### Plaid 连接器上线
</div>

现在可以通过 **Plaid** 连接器连接超过 12,000 家金融机构。团队管理员只需在**集成**中配置一次凭据,应用用户即可通过 Plaid Link 验证自己的银行账户。访问令牌按用户单独授权,确保数据隐私。

快来构建基于真实交易数据的个人理财顾问、对接证券账户的实时投资组合追踪器等应用吧。演示和设置步骤请查看 [Replit x Plaid 合作伙伴页面](https://replit.com/partners/plaid)。

了解更多关于[管理连接器](/zh/ko/replitai/managing-connectors)的信息。
