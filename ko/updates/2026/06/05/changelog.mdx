## 통합

### Shopify로 실물 제품 판매

이제 실물 제품을 판매하는 온라인 스토어를 만들 수 있습니다. Agent에게 쇼핑몰 구축을 요청하면 Shopify 스토어를 생성하고, 제품을 추가하고, 장바구니 및 결제를 설정합니다. Agent가 스토어를 주장할 링크를 제공하면, Shopify 플랜에 가입하고 결제를 연결하여 라이브로 전환합니다.

### Microsoft Fabric에서 데이터 앱 빌드

이제 Replit에서 AI 기반 데이터 앱을 구축하고 Microsoft Fabric으로 바로 게시할 수 있습니다. Microsoft Fabric 템플릿에서 시작하고, Power BI 시맨틱 모델을 연결하고, Agent에게 관리형 엔터프라이즈 데이터에 대한 대시보드 및 내부 도구 구축을 요청하세요. 인증 및 액세스 정책은 Fabric 내에 유지됩니다.

## 워크스페이스

### 커스텀 도메인이 자체 DNS 설정

자체 도메인 이름 연결이 훨씬 간단해졌습니다. 도메인을 연결하면 Replit이 Entri를 통해 필요한 DNS 레코드를 자동으로 설정하므로, 더 이상 도메인 제공업체에 수동으로 레코드를 복사할 필요가 없습니다. 도메인을 선택하고 확인하면 나머지는 Replit이 처리합니다.

[커스텀 도메인](/ko/features/publishing/custom-domains)에 대해 자세히 알아보세요.

## Agent

### SEO Agent로 검색 순위 향상

SEO Agent는 게시된 앱을 검토하고 검색 엔진과 AI 도구가 앱을 발견하지 못하게 하는 문제를 찾습니다. 각 발견 사항에는 검토하고 적용할 수 있는 원클릭 수정이 포함되어 있습니다. 프로젝트에서 **성장** 패널을 열어 스캔을 실행하세요.

### 협업 워크스페이스에서 Stripe 사용
