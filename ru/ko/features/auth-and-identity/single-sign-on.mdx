<Note>
  Хотите сделать SSO обязательным для **организации Replit** (входа на replit.com)? Это настраивается отдельно — см. [единый вход (SAML SSO)](/ru/ko/teams/identity-and-access-management/saml). На этой странице рассказывается, как добавить SSO в процесс входа для **App, созданных в Replit**.
</Note>

Разрешите пользователям входить в App через корпоративного провайдера идентификации, например Okta или Microsoft Entra ID. Если App использует [Clerk Auth](/ru/ko/features/auth-and-identity/clerk-auth), настройте SSO и другие расширенные функции аутентификации в Clerk Dashboard. Сообщите Agent, что вам нужно, и он направит вас в Clerk Dashboard для завершения настройки.

Clerk Dashboard предлагает возможности, выходящие далеко за рамки базового процесса входа. Настройки, заданные в Clerk, автоматически применяются к аутентификации Replit App.

<div id="section">
  ## Что можно настроить
</div>

* **Подключение Enterprise SSO**: Настройте единый вход через Okta или Microsoft Entra ID с помощью OIDC или SAML. Это позволит клиентам входить через корпоративного провайдера идентификации. SSO также защищает внутренние инструменты, работающие с конфиденциальными данными, заменяя ручной список разрешённых адресов электронной почты корпоративным провайдером идентификации.
* **Многофакторная аутентификация (MFA)**: Добавьте MFA в процесс входа в App.
* **Управление сеансами**: Настройте длительность сеанса и частоту аутентификации.
* **Другие настройки Clerk**: Дополнительные настройки Clerk автоматически применяются к Replit App. Не изменяйте API-ключи или настройки окружения — ими управляет Replit. См. [окружения разработки и продакшена](/ru/ko/features/auth-and-identity/clerk-auth#development-and-production-environments).

<div id="clerk">
  ## Откройте Clerk Dashboard
</div>

Попросите Agent внести необходимые изменения в настройки аутентификации. Agent настроит всё, что может, и перенаправит вас в Clerk Dashboard вашего приложения для выполнения настроек, требующих вашего участия.

<Frame>
  <img src="/assets/mirror/build-with-sso-agent-workflow-46422788bd18.webp" alt="Agent помогает настроить Enterprise SSO для приложения на основе Clerk через Clerk Dashboard." width="1602" height="1080" data-path="images/workspace/auth/build-with-sso-agent-workflow.webp" />
</Frame>

Дашборд также можно открыть из Workspace.

1. На панели Tools выберите **Users &amp; Auth**.
2. Откройте вкладку **Configure**.
3. Выберите **Дополнительно**.
4. В разделе **Clerk dashboard** выберите **Open Clerk dashboard**.

  <img src="/assets/mirror/open-clerk-dashboard-tools-pane-a314ffea741d.webp" alt="Инструмент Users & Auth с открытой вкладкой Configure, разделом Дополнительно и кнопкой Open Clerk dashboard." width="2158" height="1372" data-path="images/workspace/auth/open-clerk-dashboard-tools-pane.webp" />

<div id="sso">
  ## Настройка подключений Enterprise SSO
</div>

1. В Clerk Dashboard выберите **Configure**.
2. В разделе **User &amp; authentication** выберите **SSO connections**.
3. Выберите **Enterprise**.
4. Выберите **Add connection**.

<Frame>
  <img src="/assets/mirror/build-with-sso-enterprise-connections-b0a6a27885b5.webp" alt="Clerk Dashboard со страницей Enterprise SSO connections и кнопкой Add connection." width="1826" height="1080" data-path="images/workspace/auth/build-with-sso-enterprise-connections.webp" />
</Frame>

Подробные инструкции по настройке подключения см. в [документации Clerk](https://clerk.com/docs).

<div id="section-2">
  ### Проверка подключения
</div>

Завершив настройку, войдите с тестовой учётной записью провайдера идентификации. Убедитесь, что эта учётная запись имеет доступ к нужным разделам App.

Если не удаётся войти, обратитесь за помощью к Agent. Укажите в запросе провайдера идентификации, протокол и сообщение об ошибке.

<Note>
  На этой странице описывается Enterprise SSO для встроенного процесса входа в App. Сведения о входе через Google, GitHub, Apple и X, которые в Workspace отображаются как **SSO providers**, см. в разделе [Провайдеры входа](/ru/ko/features/auth-and-identity/sign-in-providers). Эта страница не посвящена миграции Replit Auth или входу по SAML для учётных записей Replit.
</Note>

<div id="section-3">
  ## Цены и доступность
</div>

Доступ к Clerk Dashboard доступен в рамках тарифа [Replit Pro](/ru/ko/billing/plans/replit-pro). Тариф Enterprise появится в ближайшее время.

<Info>
  Подключение Enterprise SSO бесплатно до 1 октября 2026 года. После этого стоимость SSO будет соответствовать ценовой политике Clerk и включаться в счёт Replit.
</Info>
