使用自定义域名，让你的应用成为专业的在线网站。

借助域名购买功能，你可以直接在平台内搜索、购买域名，并将其连接到已发布的 Replit 应用。几分钟内，即可让已发布的应用拥有专业的网站形象。

这意味着你可以购买一个域名，例如 `my-app.com`，并让它自动指向你的应用。

<div id="features">
  ## 功能
</div>

域名购买功能可让你轻松为应用配置专业的网址。无需在多个服务之间来回切换，你可以直接在 Replit 中完成整个网站配置。

<Frame>
  <img src="/assets/mirror/replit-domains-8453291b634b.png" alt="显示已购买域名及其连接状态的域名管理界面" width="3176" height="1556" data-path="images/deployments/custom-domains/replit-domains.png" />
</Frame>

主要功能包括：

* **域名搜索和可用性查询**：查询 `.com`、`.ai` 等热门后缀的域名是否可用
* **一键购买**：使用账户默认付款方式，直接通过 Replit 购买域名
* **自动配置**：域名会立即指向你的 Replit App，无需手动配置 DNS
* **WHOIS 隐私保护**：你的个人信息不会显示在公开的域名记录中——每次购买域名均默认包含此功能
* **自定义 DNS 记录**：添加自定义 A、TXT 和 MX 记录，以配置电子邮件服务商及其他服务
* **即时发布**：购买后，用户可立即通过你的自定义域名访问应用
* **自动续费**：域名会自动续订，确保应用持续在线，不会中断

<div id="usage">
  ## 使用方法
</div>

<div id="purchasing-domains">
  ### 购买域名
</div>

1. 发布你的应用，然后前往 <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="发布图标" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publishing** 选项卡
2. 选择 **Domains** 选项卡
3. 选择 **Buy a domain** 开始搜索
4. 在搜索栏中输入所需的域名
5. 查看不同后缀的可用选项
6. 选择心仪的域名并完成购买

购买域名后，系统会自动将其配置为指向你的 Replit 应用。你的应用会立即可通过自定义域名访问，无需额外设置。

域名购买费用将通过你的 Replit 账户收取，先从账户余额中扣除，然后计入用量。

<div id="managing-purchased-domains">
  ### 管理已购买的域名
</div>

你的域名可与已发布的 App 无缝集成：

* **自动续费**：域名自动续费，确保 App 持续处于已发布状态
* **统一计费**：域名费用与其他服务一同显示在你的 Replit 账单中
* **支持转移**：需要时可在 Replit 账户之间转移域名，或转出至外部注册商

<div id="custom-dns-records">
  ### 自定义 DNS 记录
</div>

对于通过 Replit 购买的域名，你可以添加自定义 DNS 记录，以配置电子邮件服务商等其他服务。支持以下 DNS 记录类型：

* **A 记录**：将你的域名或子域名指向指定的 IP 地址
* **TXT 记录**：为电子邮件身份验证 (SPF、DKIM、DMARC) 等服务添加基于文本的验证记录
* **MX 记录**：MX (邮件交换) 记录用于告知邮件服务器该将发往你域名的邮件投递到何处。设置 MX 记录后，你就可以使用自定义域名的邮箱地址，例如 `hello@yourdomain.com`。

管理已购域名的 DNS 记录：

1. 在 Publishing <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Publish icon" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> 中进入 **Domains** 标签页
2. 找到要配置的域名
3. 选择 **Edit** <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="pencil icon" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> 图标
4. 选择 **Add DNS Record**
5. 按服务提供商的要求填写记录类型、名称、值和 TTL

<div id="faq">
  ## 常见问题
</div>

<AccordionGroup>
  <Accordion title="费用是多少？">
    购买域名包含两项费用：

    * **注册费**：首年域名所有权的初始费用 (`.ai` 域名为两年)
    * **续费价格**：初始注册期满后自动扣费

    Replit 不会对购买域名收取额外费用。域名注册费不可退款。
  </Accordion>

  <Accordion title="如何为域名续费？">
    Replit 会自动为你的域名续费，以确保应用持续可访问。若要停止自动续费，请在
    Publishing 工具中打开 **Domains** 标签页，选择你的域名，然后关闭
    **Auto renewal** 开关。该页面还会显示域名的续费日期和续费价格。
  </Accordion>

  <Accordion title="如果我想离开 Replit 怎么办？">
    你可以联系 Replit 支持团队，将域名转移到其他注册商。根据 ICANN 规定，域名购买后需等待
    60 天才能转移至外部注册商。
  </Accordion>

  <Accordion title="可以在 Replit 账户之间转移域名吗？">
    可以，请联系 Replit 支持团队在 Replit 账户之间转移域名。此流程无需等待 60 天。
  </Accordion>

  <Accordion title="可以为我的组织购买域名吗？">
    面向 Replit Pro 和 Enterprise 方案的域名购买功能将在初始 beta 阶段结束后推出。
  </Accordion>

  <Accordion title="可以为我的域名添加自定义 DNS 记录吗？">
    可以！你可以为通过 Replit 购买的域名添加自定义 DNS 记录。目前支持的记录类型包括：

    * **A 记录**：将域名或子域名指向指定 IP 地址
    * **TXT 记录**：添加基于文本的验证记录，用于电子邮件身份验证等服务
    * **MX 记录**：配置邮件服务器，以处理该域名的电子邮件

    前往 Publishing 中的 Domains 标签页即可配置这些记录。有关为电子邮件设置 MX 记录的详细说明，请参阅上文的[自定义 DNS 记录](#custom-dns-records)部分。
  </Accordion>

  <Accordion title="支持哪些域名后缀？">
    我们支持所有常见的顶级域名 (TLD) ，但无法支持带有特殊地理或其他限制的 TLD。
  </Accordion>

  <Accordion title="什么是 WHOIS 隐私保护？">
    注册域名时，你的联系信息 (姓名、地址、电话号码和电子邮件) 通常会被发布到名为 WHOIS 的公开数据库中，任何人都能搜索到。WHOIS 隐私保护会用注册商提供的通用信息替换你的个人信息，在满足法律要求的同时保护你的隐私。

    通过 Replit 购买的所有域名均默认包含 WHOIS 隐私保护，无需额外付费。这意味着垃圾邮件发送者、营销人员以及其他试图查找域名所有者信息的人都无法看到你的个人信息。
  </Accordion>

  <Accordion title="如果我已经拥有域名怎么办？">
    要将已有域名连接到你的 Replit App，请参阅我们的[自定义域名](/zh/features/publishing/custom-domains)文档。
  </Accordion>
</AccordionGroup>
