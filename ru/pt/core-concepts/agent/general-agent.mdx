<div id="o-que-o-agent-geral">
  ## Что такое Agent Geral?
</div>

Agent Geral — самый гибкий способ работы с Replit Agent. Вам не нужно заранее выбирать тип артефакта или ограничиваться чем-то конкретным. Просто начните общение: создайте CSV, сгенерируйте PDF, изучите тему или, когда будете готовы, создайте полноценное приложение.

Ключевые возможности:

* **Без предварительного выбора**: Начинайте работу, не выбирая заранее тип артефакта
* **Любой результат**: Создавайте файлы (CSV, PDF, документы), проводите исследования или создавайте приложения
* **Коннекторы**: Читайте и записывайте данные во внешние сервисы, такие как BigQuery, Linear, Slack, Notion, Amplitude, Segment, Hex и другие
* **Постепенное раскрытие**: Начните с простого чата и по мере необходимости переходите к созданию полноценного приложения

<div id="como-acessar-o-agent-geral">
  ## Как получить доступ к Agent Geral
</div>

Доступ к Agent Geral можно получить несколькими способами:

1. **Выберите «Geral» перед вводом промпта** на главной странице Replit
2. **Откройте любой существующий проект** и начните общаться с Agent напрямую
3. **Выберите любой [фреймворк для разработчиков](https://replit.com/templates)** — все фреймворки для разработчиков автоматически включают Agent Geral
4. **[Импортируйте](/ru/pt/core-concepts/project-editor/app-setup/import) из GitHub** — проекты, импортированные из GitHub, автоматически получают Agent Geral

<div id="como-usar-o-agent-geral">
  ## Как пользоваться Agent Geral
</div>

<div id="apenas-comece-a-conversar">
  ### Просто начните общаться
</div>

Откройте проект и начните общение. Вам не нужно заранее решать, что именно создавать — Agent работает в контексте текущего проекта и может помочь с любыми вашими задачами.

**Примеры промптов:**

* «Кратко изложи ключевые моменты этого документа»
* «Создай CSV-файл со 100 крупнейшими компаниями по выручке»
* «Какие пять моих главных тикетов в Linear?»
* «Настрой проект Vue.js с TypeScript»

Agent может работать с файлами, созданными в ходе сеанса, генерировать результаты в виде отдельных файлов и выполнять код в процессе анализа — ещё до того, как вы решите что-то создать.

<div id="conectando-servios-externos">
  ### Подключение внешних сервисов
</div>

Подключите инструменты, чтобы Agent мог напрямую читать и записывать данные:

1. Перейдите в раздел **Коннекторы** в настройках проекта
2. Подключите сервисы (BigQuery, Linear, Slack, Notion, Amplitude, Segment, Hex и другие)
3. Попросите Agent читать или записывать данные через них

**Примеры промптов с коннекторами:**

* &quot;Какие тикеты открыты в Linear?&quot;
* &quot;Составь сводку сегодняшних сообщений в Slack из канала #engineering&quot;
* &quot;Получи из BigQuery данные о продажах за прошлый месяц&quot;
* &quot;Покажи предстоящие события в моём календаре&quot;
* &quot;Создай в Linear новый тикет об ошибке интеграции&quot;
* &quot;Отправь сводку в канал #engineering в Slack&quot;

<div id="do-chat-ao-aplicativo-completo">
  ### От чата к полноценному приложению
</div>

Когда будете готовы приступить к разработке, просто скажите об этом. Agent плавно перейдёт от непринуждённого общения в чате к созданию приложения — без необходимости начинать заново или переключаться на другой контекст.

* &quot;Преврати это в веб-приложение&quot;
* &quot;Создай приложение на основе этих данных&quot;
* &quot;Создай дашборд для этих метрик&quot;
* &quot;Настрой CLI-инструмент на Rust&quot;

Можно начать с простого — изучить тему, создать отчёт, проанализировать данные — а когда придёт время, перейти к созданию полноценного приложения.

<div id="o-que-voc-pode-construir">
  ## Что можно создать
</div>

* **Работа со знаниями**: Исследуйте, обобщайте и анализируйте информацию, не создавая приложение
* **Однофайловые результаты**: CSV, PDF, документы, экспортированные данные и форматированные отчёты
* **Приложения для работы с данными**: Обращайтесь к подключённым сервисам и визуализируйте результаты на дашбордах
* **Любой фреймворк или язык**: Angular, Vue, Svelte, Rust, Go, C#, Python tkinter, игры на Godot, инструменты CLI и многое другое
* **Полностековые приложения**: Когда будете готовы, создайте полноценное приложение на основе контекста вашего чата

<div id="o-que-esperar">
  ## Чего ожидать
</div>

Agent Geral предлагает больше возможностей и гибкости, но возможны некоторые нюансы:

* **Настройка с первой попытки**: Иногда Agent настраивает всё сразу
* **Итеративная работа**: Сложные конфигурации могут потребовать нескольких этапов доработки
* **Технологические ограничения**: Некоторые технологии могут поддерживаться в среде Nix не в полной мере

<Note>
  В отличие от стандартного Agent с преднастроенными средами, Agent Geral самостоятельно настраивает среду и выполняет команды на основе вашего запроса. Когда вы будете готовы к развертыванию, возможно, потребуется попросить его настроить публикацию.
</Note>

<div id="perguntas-frequentes">
  ## Часто задаваемые вопросы
</div>

<Accordion title="Может ли Agent видеть мои другие проекты?">
  Нет. Каждый чат ограничен одним проектом. Нельзя сделать так, чтобы проект A и проект B взаимодействовали друг с другом.
</Accordion>

<Accordion title="Почему он всё ещё не может получить доступ к моему внешнему инструменту?">
  Сначала необходимо подключить сервисы через коннекторы. После подключения Agent может читать и записывать в них данные, но по умолчанию доступа к ним у него нет.
</Accordion>

<Accordion title="Какие коннекторы доступны?">
  Сейчас поддерживаются BigQuery, Linear, Slack, Notion, Amplitude, Segment, Hex и другие. Дополнительные коннекторы добавляются регулярно.
</Accordion>

<Accordion title="Нужны ли коннекторы для использования Agent Geral?">
  Нет. Коннекторы необязательны. Agent Geral можно использовать для работы со знаниями, создания файлов и разработки приложений без внешних подключений.
</Accordion>
