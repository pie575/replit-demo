<div id="como-o-replitmd-funciona">
  ## `replit.md` 的工作原理
</div>

Agent 会先根据经过验证的最佳实践，在项目根目录中创建一个 `replit.md` 文件。该文件包含：

* 项目的基本信息
* 推荐的编码规范
* 适合你的项目类型的常见偏好设置

<YouTubeEmbed videoId="kYv525W-vaU" title="Customize how Replit Agent responds" />

当 Agent 处理你的请求时，会自动读取 `replit.md` 文件，并根据其中的内容来：

* 了解项目的架构和约定
* 遵循你偏好的编码规范和风格
* 使用你指定的包管理器和依赖项

随着对项目的了解不断加深，以及对应用进行修改，Agent 也可能会更新你的 `replit.md` 文件。

<Note>
  你可以编辑 `replit.md` 文件来自定义 Agent 的行为。
</Note>

<div id="configurando-o-replitmd">
  ## 配置 `replit.md`
</div>

<div id="gerao-automtica">
  ### 自动生成
</div>

当你使用 Agent 创建新项目时，它会依据经过验证的最佳实践自动生成一个 `replit.md` 文件。该文件位于项目根目录下，内容包括：

* 项目基本信息
* 推荐的编码规范
* 与你的项目类型相匹配的常用偏好设置

<div id="criao-manual">
  ### 手动创建
</div>

你可以在项目根目录中新建一个名为 `replit.md` 的文件，来创建自己的 `replit.md`。Agent 会在后续对话中自动检测并使用该文件。

<Note>
  `replit.md` 必须位于项目根目录下才能正常生效。
</Note>

<div id="regenerando-o-replitmd">
  ### 重新生成 `replit.md`
</div>

如果你的 `replit.md` 文件损坏，或者你想从头开始：

1. 删除项目根目录下现有的 `replit.md` 文件
2. 与 Agent 开启一段新对话
3. Agent 会根据你当前的项目自动生成新的 `replit.md` 文件

<div id="seja-especfico-e-claro">
  ### 具体明确
</div>

编写清晰、具体的指令，帮助 Agent 准确理解你的需求：

```markdown theme={null}
## 编码风格

- 所有新的 JavaScript 文件均使用 TypeScript
- 优先使用带 hooks 的函数式组件，而非类组件
- 使用 Tailwind CSS 编写样式，避免内联样式
- 始终为函数参数和返回值标注 TypeScript 类型
```

如需更详细的 prompt 格式化指南，请参阅 [Anthropic 的 prompt 工程指南](https://docs.anthropic.com/en/docs/build-with-claude/prompt-engineering/use-xml-tags)。

  ### Web 应用项目

```markdown theme={null}
# MyApp 项目指南

## 项目概述
一个使用 React 和 Express.js 构建的任务管理 Web 应用。

## 技术偏好
- 前端：React + TypeScript、Tailwind CSS
- 后端：Express.js + TypeScript
- 数据库：Neon PostgreSQL + Drizzle ORM
- 包管理器：npm（不使用 yarn 或 pnpm）

## 编码规范
- 使用配合 hooks 的函数式组件
- 实现恰当的错误边界
- 接口遵循 REST API 约定
- 使用具有描述性的变量名和函数名

## 沟通风格
- 修改前先说明你的思路
- 为复杂逻辑添加代码注释
- 需求不明确时主动提问
```

<div id="combinando-pesquisa-na-web-com-o-replitmd">
  ## 将网页搜索与 `replit.md` 结合使用
</div>

Agent 可以通过网页搜索查找最新的信息、库和解决方案。将其与你的 `replit.md` 文件结合使用，你既能获得最新的知识，又能得到针对具体项目的指导。

<div id="boas-prticas-para-integrao-de-pesquisa-na-web">
  ### 网页搜索集成的最佳实践
</div>

**明确说明你希望 Agent 搜索什么：**

```markdown theme={null}
## Research Preferences
- Always check for the latest versions of dependencies before suggesting updates
- Research current best practices for security implementations
- Look up recent performance optimization techniques for our tech stack
```

**指导 Agent 如何运用外部知识：**

```markdown theme={null}
## 外部研究准则
- 推荐新库时，确保与我们现有的技术栈兼容
- 调整外部示例，使其符合我们的编码规范和项目结构  
- 验证建议的方案能在我们的发布环境中正常运行
```

**同时利用两者的提示词示例：**
&quot;Research the latest React 18 performance optimization techniques and implement them following the component patterns defined in `replit.md`&quot;

这种方式给出的解决方案既紧跟最新技术，又贴合你项目的具体需求。

<div id="limitaes">
  ## 限制
</div>

<div id="limites-de-tamanho-e-contedo-do-arquivo">
  ### 文件大小和内容限制
</div>

虽然 `replit.md` 没有严格的字符数上限，但文件过大可能无法被完整处理。建议保持 `replit.md` 重点突出、简明扼要，以获得最佳效果。

<div id="requisito-de-diretrio-raiz">
  ### 根目录要求
</div>

`replit.md` 必须位于项目的根目录下。Agent 不会自动检测子目录中的文件。

<div id="alcance-do-contexto">
  ### 上下文范围
</div>

`replit.md` 会为 Agent 对话提供上下文，但不会自动应用于其他 AI 工具。

<div id="prximos-passos">
  ## 后续步骤
</div>

准备好为你的项目定制 Agent 了吗？

1. **从简单开始**：先创建一个基础的 `replit.md`，写入你的主要偏好设置
2. **持续迭代**：在与 Agent 协作的过程中不断完善 `replit.md`
3. **复用模式**：将行之有效的 `replit.md` 配置应用到类似项目中
4. **关注效果**：留意 Agent 对你所设定规范的遵循情况，并按需调整

进一步了解[如何与 Agent 协作](/zh/pt/features/agent/overview)，或探索其他 [AI 工具](/zh/pt/build/welcome)。

**Enterprise**：在[自定义模板](/zh/pt/teams/custom-templates)中预先配置 `replit.md`，让组织中的每位创作者都获得一致的初始上下文。有关设计方面的具体指导，请参阅[配置设计系统](/zh/pt/teams/custom-design-system)。
