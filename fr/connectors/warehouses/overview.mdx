Les connecteurs d&#39;entrepôts de données permettent à Replit Agent d&#39;interroger en toute sécurité les entrepôts de données de votre organisation. Les créateurs utilisent le langage naturel pour concevoir des tableaux de bord, des outils de reporting et des applications de données — sans aucune expertise SQL. Les administrateurs gardent un contrôle centralisé grâce à la gestion des accès basée sur les rôles.

<div id="supported-warehouses">
  ## Entrepôts pris en charge
</div>

Les connecteurs d&#39;entrepôt sont disponibles sur les plans **Enterprise**.

| Entrepôt         | Guide de configuration                                                                                                |
| ---------------- | --------------------------------------------------------------------------------------------------------------------- |
| BigQuery         | Disponible dès maintenant — guide de configuration en cours de rédaction                                              |
| Databricks       | [Connecter Databricks](/fr/connectors/warehouses/databricks)                                                             |
| Microsoft Fabric | [Créer des applications de données sur Microsoft Fabric](/fr/connectors/warehouses/microsoft-fabric) (préversion privée) |
| Snowflake        | [Connecter Snowflake](/fr/connectors/warehouses/snowflake)                                                               |

Chaque entrepôt dispose de son propre processus de configuration, car l&#39;intégration OAuth, le modèle d&#39;identité et le format des identifiants varient. Choisissez l&#39;entrepôt que vous utilisez et suivez le guide qui lui est dédié.

<div id="analytics-and-data-platforms">
  ## Plateformes d&#39;analytique et de données
</div>

Les connecteurs d&#39;analytique sont disponibles avec les plans Core et Pro, ainsi qu&#39;Enterprise. Connectez vos outils d&#39;analytique pour qu&#39;Agent puisse lire et exploiter les données de votre produit :

* **Segment** — Données clients, flux d&#39;événements et segments d&#39;audience issus de votre CDP
* **Amplitude** — Analytique produit, données comportementales des utilisateurs et métriques d&#39;engagement
* **Hex** — Notebooks de données collaboratifs et résultats de requêtes

Gérez-les comme n&#39;importe quel autre connecteur Replit. Consultez [Gérer vos connecteurs](/fr/replitai/managing-connectors).

<div id="how-warehouse-connectors-work">
  ## Fonctionnement des connecteurs d&#39;entrepôt de données
</div>

La configuration s&#39;effectue une seule fois et fait intervenir trois rôles :

1. **Administrateur de l&#39;entrepôt de données** — Crée une intégration OAuth ou une identité de service dans l&#39;entrepôt
2. **Administrateur de l&#39;organisation Replit** — Ajoute les identifiants à Replit et configure les accès
3. **Créateur** — Se connecte et commence à créer avec Agent

Une fois la configuration terminée, les créateurs demandent à Agent d&#39;utiliser l&#39;entrepôt de données : Agent rédige alors des requêtes SQL et les exécute sur celui-ci.

<div id="building-with-warehouse-data">
  ### Créer avec les données de votre entrepôt
</div>

Une fois la connexion établie, vous pouvez demander à Agent de créer des applications qui exploitent vos données. Agent peut :

* Créer des outils internes qui récupèrent et affichent des données en temps réel
* Créer des tableaux de bord avec des graphiques et des visualisations alimentés par votre entrepôt
* Générer des requêtes SQL pour alimenter le backend de votre application
* Expliquer les schémas et la structure des tables pour vous aider à cerner ce que vous pouvez créer

<Note>
  Si Agent peut répondre à des questions ponctuelles sur vos données, l&#39;objectif premier des connecteurs d&#39;entrepôt est de lui permettre de créer des applications fonctionnelles qui tirent parti des données de votre organisation. Les requêtes d&#39;entrepôt sont exécutées directement sur votre instance : veillez donc à ce que vos portées OAuth et les autorisations de votre utilisateur de base de données autorisent les opérations de lecture et d&#39;écriture nécessaires.
</Note>
