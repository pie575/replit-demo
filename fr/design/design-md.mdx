<div id="contents-of-a-design-system">
  ## Contenu d’un design system
</div>

Un design system généré comprend :

* **Jetons** — valeurs nommées (couleurs, espacements, rayons) utilisées dans le reste du système
* **Couleurs** — palette avec des rôles (principale, surface, accent…)
* **Typographie** — familles, tailles, graisses
* **Exemples de composants** — 2 à 3 composants illustrant l’utilisation du système
* **Logos et éléments de marque** — inclus si vous les fournissez de manière claire

<div id="how-its-stored">
  ## Comment il est stocké
</div>

Un système généré est enregistré dans votre projet sous la forme d’un **guide de style évolutif** : les jetons de `tokens.json` alimentent les variables CSS (par exemple dans `src/index.css`) utilisées par vos composants. `DESIGN.md` en est la représentation documentaire : lisible pour vous, exploitable par Agent.

<div id="using-designmd-as-a-source">
  ## Utiliser DESIGN.md comme source
</div>

Un fichier `DESIGN.md` existant peut servir de point de départ pour créer un nouveau design system : indiquez-le lors de sa [création](/fr/design/create-a-design-system), parmi d’autres sources comme une URL Figma, un site web, du code ou des images de référence.
