title: "Устранение неполадок мобильных App"
description: "Решайте распространённые проблемы, возникающие при разработке мобильных App с Expo и React Native в Replit."
---

При разработке мобильных App в Replit вы можете столкнуться с проблемами предпросмотра, сборки бандла и зависимостей пакетов. Это руководство поможет устранить распространённые неполадки — от быстрых решений до более углублённых шагов отладки.

<div id="section">
  ## Быстрые решения
</div>

Сначала попробуйте эти способы — они помогают в большинстве случаев.

| Проблема                                  | Что попробовать                                                   |
| ----------------------------------------- | ----------------------------------------------------------------- |
| Изменения не отображаются на телефоне     | Встряхните телефон, чтобы открыть меню Expo, и нажмите **Reload** |
| Изменения не отображаются в предпросмотре | Нажмите **R** в консоли, чтобы пересобрать бандл                  |
| App зависает или не отвечает              | Остановите App в консоли и запустите заново                       |

<div id="section-2">
  ## Частые проблемы
</div>

<AccordionGroup>
  <Accordion title="Изменения не появляются на устройстве">
    Если вы внесли изменения, но не видите их на телефоне:

    1. **Встряхните телефон**, чтобы открыть меню разработчика Expo.
    2. Нажмите **Reload**, чтобы заново загрузить бандл.

    В веб-предпросмотре нажмите **R** в консоли, чтобы запустить повторную сборку бандла.

    Если изменения по-прежнему не появляются, попробуйте очистить кэш (см. [Очистка кэша Metro](#clear-the-metro-cache) ниже).
  </Accordion>

  <Accordion title="В Expo Go появляется красный экран с ошибкой">
    Красный экран с ошибкой обычно указывает на ошибку JavaScript или отсутствующий модуль. Прочитайте сообщение об ошибке — как правило, в нём указан конкретный файл и строка.

    **Частые причины:**

    * Пакет не установлен или установлена неверная версия
    * Модуль работает в вебе, но не работает в нативной среде (или наоборот)
    * В коде есть синтаксическая ошибка

    **Что можно сделать:**

    1. Внимательно прочитайте сообщение об ошибке. Обычно в нём точно указано, что пошло не так.
    2. Отправьте это сообщение Agent и попросите помочь исправить ошибку.
    3. Если ошибка ссылается на конкретный пакет, попробуйте переустановить зависимости (см. [Переустановка пакетов](#reinstall-packages)).
  </Accordion>

  <Accordion title="App работает в вебе, но падает на телефоне (или наоборот)">
    Некоторые пакеты и функции работают по-разному на разных платформах. React Native компилируется под три целевые платформы: iOS, Android и веб. Библиотека, работающая в вебе, может не поддерживать нативную среду или требовать другой конфигурации.

    **Что можно сделать:**

    1. Проверьте в документации пакета, поддерживает ли он нужную платформу.
    2. Спросите Agent: «Совместим ли этот пакет с Expo Go?»
    3. Если функция не поддерживается на мобильных устройствах, подумайте о переносе её на сервер.

    <Tip>
      Изучая пакет, ищите пометку «Expo compatible» или проверьте список поддерживаемых модулей в [документации Expo SDK](https://docs.expo.dev/versions/latest/).
    </Tip>
  </Accordion>

  <Accordion title="QR-код не сканируется или app не подключается">
    **Проверьте сеть:**

    * Телефон и компьютер должны быть в одной сети WiFi
    * Некоторые корпоративные и общедоступные сети блокируют подключения

    **Попробуйте режим туннеля:**
    Если вы находитесь в сети с ограничениями, режим туннеля направит трафик через серверы Expo. Попросите Agent запустить app в режиме туннеля или выполните `npx expo start --tunnel` в оболочке.

    **Перезапустите Expo Go:**
    Полностью закройте Expo Go и откройте его заново перед сканированием.
  </Accordion>

  <Accordion title="Сборка занимает много времени">
    Первая сборка всегда медленнее, так как кэша ещё нет. Последующие сборки должны идти быстрее.

    **Что влияет на время сборки:**

    * Количество пакетов в проекте
    * Первый запуск после очистки кэша
    * Скорость сети при загрузке пакетов

    Если сборка остаётся медленной, проверьте, не установлены ли ненужные пакеты.
  </Accordion>

  <Accordion title="Ошибка: модуль не найден">
    Если вы видите «Unable to resolve module» или «Module not found»:

    1. Пакет может быть не установлен — попросите Agent установить его.
    2. Пакет установлен, но кэш устарел — очистите кэш.
    3. Пакета не существует или указано неверное имя — проверьте название пакета.

    Если модуль точно должен быть на месте, попробуйте [Переустановку пакетов](#reinstall-packages).
  </Accordion>
</AccordionGroup>

<div id="section-3">
  ## Команды для отладки
</div>

Если быстрые решения не помогли, эти команды позволят сбросить различные кэши и состояния. Выполните их в Shell.

<div id="metro">
  ### Очистка кэша Metro
</div>

Metro — это бандлер, который компилирует код React Native. После очистки кэша сборка выполняется заново.

Выполните в оболочке следующую команду:

```bash theme={null}
npx expo start --clear
```

Это очистит кэш сборщика и перезапустит сервер разработки. В выводе вы увидите сообщение &quot;Bundler cache is empty. Rebuilding.&quot;

<Tip>
  Если проблемы с кэшем возникают часто, добавьте `-c` в команду запуска. Попросите Agent обновить команду dev, включив в неё флаг очистки.
</Tip>

<div id="section-4">
  ### Переустановка пакетов
</div>

Если возникают ошибки модулей или несоответствие версий, обычно помогает переустановка пакетов.

Выполните в оболочке следующую команду:

```bash theme={null}
rm -rf node_modules && npm install
```

Это удалит все установленные пакеты и установит их заново с нуля на основе `package.json`.

<Note>
  Если в проекте используется другой менеджер пакетов (например, `bun` или `pnpm`), выполните соответствующую команду установки: `bun install` или `pnpm install`.
</Note>

<div id="section-5">
  ### Проверка несоответствия версий
</div>

Expo Doctor сканирует проект на наличие распространённых проблем, например несоответствия версий пакетов.

Выполните в оболочке следующую команду.

```bash theme={null}
npx expo-doctor
```

Изучите предупреждения. Если предлагается исправление, тщательно его оцените — не обновляйте пакеты бездумно, поскольку несовместимые изменения в новой версии могут привести к новым проблемам.

<Warning>
  Обновляйте пакеты только при наличии конкретной причины. Обновление &quot;просто так&quot; может сломать ваш App, если в новой версии есть несовместимые изменения.
</Warning>

<div id="section-6">
  ## Полный сброс
</div>

Когда ничего другого не помогает, полный сброс очищает все кэши и переустанавливает всё заново.

<Accordion title="Крайняя мера: команда полного сброса">
  Эта команда удаляет все кэши и переустанавливает пакеты с нуля. Используйте её только как крайнюю меру.

  ```bash theme={null}
  rm -rf node_modules .expo && npm cache clean --force && npm install && npx expo start --clear
  ```

  **Что делает эта команда:**

  1. `rm -rf node_modules` — удаляет установленные пакеты
  2. `rm -rf .expo` — удаляет локальный кэш Expo
  3. `npm cache clean --force` — очищает глобальный кэш npm
  4. `npm install` — переустанавливает все пакеты
  5. `npx expo start --clear` — запускает проект с чистым кэшем Metro

  После выполнения этой команды следующая сборка займёт больше времени, поскольку всё будет собираться заново с нуля.
</Accordion>

<div id="section-7">
  ### Очистка кэша устройства
</div>

Если после перезагрузки App на телефоне всё ещё работает на старом коде:

* **iOS**: в Expo Go перейдите в **Settings** и нажмите **Clear Cache**
* **Android**: перейдите в **Settings &gt; Apps &gt; Expo Go &gt; Storage &gt; Clear Cache**

  ## Краткая справка
</div>

| Проблема                             | Что попробовать сначала     | Что попробовать затем            |
| ------------------------------------ | --------------------------- | -------------------------------- |
| Изменения не отображаются            | Встряхнуть телефон → Reload | Очистить кэш Metro               |

| Новый пакет не работает              | Перезапустить сервер        | Очистить кэш Metro               |
| Изменён app.json                     | Перезапустить сервер        | —                                |

<div id="section-9">
  ## Дополнительная помощь
</div>

Если проблема всё ещё не решена:

* **Спросите Agent**: опишите ошибку и то, что вы уже пробовали. Часто Agent способен сам найти причину и устранить проблему.
* **Загляните в документацию Expo**: [руководство Expo по устранению неполадок](https://docs.expo.dev/troubleshooting/overview/) охватывает дополнительные сценарии.
* **Поищите ошибку в интернете**: скопируйте точный текст сообщения об ошибке и выполните поиск. Скорее всего, кто-то уже сталкивался с этим.
