# Diretório MCP

> Explore servidores MCP em destaque que conectam o Replit Agent às suas ferramentas e serviços favoritos.

Use este diretório para explorar servidores que disponibilizam ferramentas especializadas, fontes de dados ou fluxos de trabalho por meio do Model Context Protocol (MCP). Cada listagem inclui um breve resumo e um badge do Replit para que você possa decidir quais servidores conectar aos seus projetos.

Esta não é uma lista exaustiva — você pode [adicionar qualquer servidor MCP remoto](/pt/features/mcp/overview#add-an-mcp-server) e usá-lo com o Replit Agent.

<Info>
  Clique no badge **Add to Replit** para instalar qualquer servidor. Você será solicitado a autorizar a conexão no Editor de Projeto.
</Info>
