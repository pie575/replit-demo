<div id="build-full-stack-mobile-apps-with-agent">
  ### 使用 Agent 构建全栈移动应用
</div>

<Frame>
  <img src="/assets/mirror/cleanshot-2025-12-05-at-12-27-22-2x_273f89390642-dc03158b7d7f.png" width="1082" height="504" data-path="images/changelog/2025-12-05/cleanshot-2025-12-05-at-12-27-22-2x_273f89390642.png" />
</Frame>

Agent 现可构建配备完整后端服务器的[移动应用](/zh/features/artifact-types/building-mobile-apps)。借助 [AI Integrations](/zh/replitai/integrations)、[Database](/zh/features/data-and-storage/sql-database)、[对象存储](/zh/features/data-and-storage/object-storage) 和 connector 等强大功能，满足生产环境移动端开发所需的一切。

<div id="database-now-generally-available">
  ### Database 现已全面推出
</div>

全新的 [Database](/zh/features/data-and-storage/sql-database) 现已成为所有新 Replit Apps 的默认数据库。此次升级提升了可靠性和基础设施控制能力，并为你的项目带来更佳性能和更便捷的数据管理。

<div id="fast-mode-handles-more-autonomously">
  ### Fast Mode 的自主处理能力更强
</div>

<Frame>
  <img src="/assets/mirror/image_4f661377d428-8454460e1cca.png" width="720" height="212" data-path="images/changelog/2025-12-05/image_4f661377d428.png" />
</Frame>

[Lite 模式](/zh/core-concepts/agent/agent-modes) (原 Fast Mode) 现在可以自主处理更多任务，同时会在涉及较大改动时推荐使用 Agent。通过快速迭代和无缝交接，更快完成构建。

<div id="connect-third-party-services-faster">
  ### 更快速地连接第三方服务
</div>

借助改进的 connector 支持，更快速地连接第三方服务。只需提供配置，即可添加大多数基于 API 密钥的服务，无需复杂设置。多密钥配置和扩展的运行状况检查进一步提升了[integration](/zh/replitai/integrations)的可靠性。
