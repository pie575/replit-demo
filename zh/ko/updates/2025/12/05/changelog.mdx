<div id="agent">
  ### 使用 Agent 构建全栈移动应用
</div>

<Frame>
  <img src="/assets/mirror/cleanshot-2025-12-05-at-12-27-22-2x_273f89390642-dc03158b7d7f.png" width="1082" height="504" data-path="images/changelog/2025-12-05/cleanshot-2025-12-05-at-12-27-22-2x_273f89390642.png" />

Agent 现在可以构建配备完整后端服务器的[移动应用](/zh/ko/features/artifact-types/building-mobile-apps)。你可以使用 [AI 集成](/zh/replitai/integrations)、[数据库](/zh/ko/features/data-and-storage/sql-database)、[对象存储](/zh/ko/features/data-and-storage/object-storage)、连接器等生产级移动开发所需的一切功能。

<div id="section-3">
  ### 数据库正式发布
</div>

全新的[数据库](/zh/ko/features/data-and-storage/sql-database)现已成为所有新建 Replit 应用的默认配置。此次升级带来了更强的稳定性和更完善的基础设施控制能力，助力提升项目性能，让数据管理更加轻松。

<div id="fast-mode">
  ### Fast Mode 自主处理能力增强
</div>

<Frame>
  <img src="/assets/mirror/image_4f661377d428-8454460e1cca.png" width="720" height="212" data-path="images/changelog/2025-12-05/image_4f661377d428.png" />
</Frame>

[Lite 模式](/zh/core-concepts/agent/agent-modes) (原 Fast Mode) 现在能自行处理更多任务，遇到较大改动时则会推荐改用 Agent。快速迭代、顺畅交接，让你构建得更快。

<div id="section-4">
  ### 更快连接第三方服务
</div>

连接器支持全面增强，让你更快接入第三方服务。只需提供配置，无需复杂设置，即可添加大多数基于 API 密钥的服务。新增多密钥配置和更全面的状态检查，让[集成](/zh/replitai/integrations)更稳定可靠。
