<div id="contedo-de-um-design-system">
  ## Contenu d’un design system
</div>

Un design system généré comprend :

* **Tokens** — valeurs nommées (couleurs, espacements, rayons) auxquelles le reste du système fait référence
* **Couleurs** — palette définissant des rôles (primaire, surface, accent…)
* **Typographie** — familles, tailles, graisses
* **Composants d’exemple** — 2 à 3 composants illustrant l’utilisation du système
* **Logos et ressources de marque** — inclus lorsque vous les fournissez clairement

<div id="como-armazenado">
  ## Comment il est stocké
</div>

Un système généré est intégré à votre projet sous la forme d’un **guide de style vivant** : les jetons de `tokens.json` alimentent les variables CSS (par exemple, dans `src/index.css`) utilisées par vos composants. Le fichier `DESIGN.md` en est la représentation documentaire — lisible par vous et exploitable par Agent.

<div id="usando-o-designmd-como-fonte">
  ## Utiliser DESIGN.md comme source
</div>

Un fichier `DESIGN.md` existant peut servir de base à un nouveau design system : indiquez-le lors de la [création d’un](/fr/pt/design/create-a-design-system), parmi d’autres sources telles qu’une URL Figma, un site web, du code ou des images de référence.
