Un design créé dans Claude donne un aperçu de l’expérience visée. Avec l’option **Send to Replit** de Claude, vous pouvez transmettre ce design à Replit, où il devient un projet qu’Agent transforme en app fonctionnelle et interactive.

<Note>
  Il s’agit d’une nouvelle intégration. **Send to Replit** apparaît dans le menu **Send to…** de Claude uniquement lorsque Claude propose Replit comme destination pour votre design. Sa disponibilité est contrôlée par Claude. L’option peut donc ne pas encore s’afficher pour tous les comptes. Lorsque vous acceptez le transfert, Claude demande les autorisations **Access apps**, **Create and manage apps** et **Stay signed in to this application** sur l’écran de consentement de Replit.
</Note>

<div id="how-it-works">
  ## Fonctionnement
</div>

Le transfert commence dans Claude et se termine dans Replit :

1. Vous créez un design autonome dans le canvas de design de Claude.
2. Vous envoyez le design à Replit depuis le menu **Share → Send to…** de Claude.
3. Vous autorisez Claude à accéder à votre compte Replit et choisissez un workspace.
4. Replit crée un projet à partir de votre design sous la forme d’un fichier statique `index.html`.
5. Agent prend en charge la tâche **Transformer ce design Claude en une véritable application** et le rend interactif.

Claude *envoie* un design à Replit via une connexion d’application autorisée. Vous ne configurez rien dans Replit au préalable : le processus commence dans Claude.

<div id="before-you-start">
  ## Avant de commencer
</div>

Il vous faut :

* Un [compte Replit](https://replit.com).
* Un compte Claude comportant un design dans le canvas de design de Claude.
* Un workspace Replit cible pour le nouveau projet.

<div id="send-a-design-from-claude-to-replit">
  ## Envoyer un design depuis Claude vers Replit
</div>

Commencez dans Claude avec le design que vous souhaitez développer.

<Steps>
  <Step title="Ouvrir votre design dans Claude">
    Dans Claude, ouvrez le design que vous souhaitez transformer en application.
  </Step>

  <Step title="Ouvrir le menu Send to">
    Sélectionnez **Share**, puis ouvrez le menu **Send to…**. Replit y apparaît comme destination.

    <Frame>
      <img src="/assets/mirror/claude-send-to-menu-d4353906aea3.png" alt="Menu Send to… de Claude répertoriant Replit comme destination aux côtés de Claude Code" width="2000" height="1143" data-path="images/claude-to-app/claude-send-to-menu.png" />
    </Frame>
  </Step>

  <Step title="Choisir Replit">
    Sélectionnez **Replit** pour lancer le transfert vers votre compte Replit.
  </Step>

  <Step title="Autoriser l’accès à Replit">
    Sur l’écran de consentement Replit intitulé **Claude would like to access your Replit account**, examinez les accès demandés par Claude — **Access apps**, **Create and manage apps** et **Stay signed in to this application** — puis autorisez la connexion.

    <Frame>
      <img src="/assets/mirror/replit-oidc-consent-76dfc4d92a2f.png" alt="Écran de consentement Replit intitulé Claude would like to access your Replit account, affichant les autorisations Access apps, Create and manage apps et Stay signed in to this application, ainsi qu’un sélecteur de workspace" width="2000" height="1143" data-path="images/claude-to-app/replit-oidc-consent.png" />
    </Frame>
  </Step>

  <Step title="Choisir un workspace">
    Sélectionnez le workspace Replit dans lequel créer le nouveau projet, puis confirmez.
  </Step>
</Steps>

Après confirmation, Replit crée un projet à partir de votre design et l’ouvre dans le workspace.

<div id="what-gets-imported">
  ## Ce qui est importé
</div>

Replit importe le design sous la forme d&#39;un fichier `index.html` unique et autonome. L&#39;importation conserve la mise en page, les styles et les ressources que Claude a inclus dans le design.

L&#39;importation vous donne un point de départ fonctionnel. Comme le design se présente sous forme de HTML statique, c&#39;est à vous d&#39;ajouter ensuite le comportement, les données et l&#39;interactivité.

<div id="what-is-not-imported">
  ## Ce qui n&#39;est pas importé
</div>

Le transfert reprend le design, pas une application complète. Les éléments suivants ne sont pas inclus dans l&#39;importation :

* La logique backend et les fonctionnalités côté serveur.
* Une base de données ou des données stockées.
* L&#39;interactivité, comme les formulaires fonctionnels, la gestion d&#39;état et la navigation.

Agent ajoute ces fonctionnalités lorsqu&#39;il transforme le design en véritable app.

<div id="let-agent-make-the-design-interactive">
  ## Laissez Agent rendre le design interactif
</div>

Après l’importation, Agent lance une tâche **Transformer ce design Claude en véritable application** dans le workspace. Agent s’appuie sur votre design statique et met en œuvre le comportement interactif qu’il suggère.

  <img src="/assets/mirror/claude-design-in-replit-design-ff81b055b1f5.webp" alt="Le design de location de supercars Velocity envoyé depuis Claude, ouvert comme frame de design Claude dans Replit Design, avec la tâche d’Agent marquée comme terminée dans le panneau Chat" width="1600" height="1004" data-path="images/claude-to-app/claude-design-in-replit-design.webp" />

Ouvrez Preview une fois la tâche terminée pour tester le résultat. Comparez l’application en cours d’exécution à votre design Claude d’origine et vérifiez que :

* La mise en page et le style correspondent suffisamment au design.
* Les boutons, formulaires et la navigation fonctionnent comme prévu.
* L’application fonctionne toujours après une actualisation.

S’il manque quelque chose ou si un élément ne va pas, décrivez la modification à Agent et laissez-le affiner l’application.

  ## Facturation
