[Replit Core](https://replit.com/replit-core) 会员资格让您可以使用高级工具，快速将创意变为应用。有关当前 Core 价格 (月付或年付) ，请参阅[定价页面](https://replit.com/pricing)。

<div id="section">
  ## 主要功能
</div>

Core 会员资格可享以下功能：

<div id="ai">
  ### AI 驱动工具
</div>

* **Agent**：与 Agent 对话，构建、调试并迭代改进应用
* **完整构建**：使用 Economy 或 Power，让 Agent 自主完成更大型的任务
* **Lite 构建**：针对快速更改进行目标明确的编辑
* **Design Canvas**：探索视觉创意、生成变体，并将设计转化为工件
* **Visual Editor**：以可视化方式直接编辑应用内容和布局
* **所有工件类型**：Web 应用、移动应用、数据可视化、幻灯片演示文稿、动画视频等
* **Plan 模式**：无需编辑代码，即可与 Agent 一起构思创意并规划工作
* **连接器**：集成 Google、Stripe 等第三方服务

<div id="section-2">
  ### 协作
</div>

* 无需单独订阅团队套餐，即可邀请最多 5 位构建者加入工作区
* 后台任务 — 同时只能运行 1 个活跃任务
* 用于规划和跟踪任务的共享看板

<div id="section-3">
  ### 快速、安全地开发
</div>

* 在高性能云端开发环境中工作
* 按量付费，服务不中断
* 使用 Secrets 工具，将敏感数据与代码分离并安全存储

有关特定套餐的费用和限额，请参阅<a href="https://replit.com/pricing" target="_blank">定价页面</a>。

<div id="section-4">
  ### 每月额度
</div>

* 获得可自动用于 Agent、发布、网络传输和数据库存储等付费服务的每月额度。需要更多构建者席位或更高额度档位？请参阅 [Replit Pro](/zh/ko/billing/plans/replit-pro)。

<div id="section-5">
  ### 一键发布
</div>

所有套餐均可使用发布功能。免费的 Starter 套餐包含 1 个已发布应用，而 Replit Core 则取消了这一限制，支持无限发布，并提供更多选项：

* 无限发布应用
* 选择不同的发布选项来优化成本
* 使用内置日志和分析功能
* 移除已发布应用中的“Made with Replit”徽章

<div id="ai-2">
  ### AI 支持与社区活动
</div>

* 通过 AI 支持快速解决账单、账户、产品和技术相关问题
* 访问会员专属论坛和活动
* 抢先体验新功能

<div id="section-6">
  ## 开始使用
</div>

只需几个简单步骤，即可升级到 Replit Core：

1. 前往<a href="https://replit.com/pricing" target="_blank">定价</a>页面
2. 选择**订阅 Replit Core**
3. 选择**月付**或**年付**套餐，然后填写付款信息
