Un frame de Design n&#39;est jamais une simple image : c&#39;est la spécification d&#39;une véritable application. Une fois votre frame prêt, confiez-le à Agent : sélectionnez-le, choisissez **Build…** dans sa barre d&#39;actions, puis choisissez une option :

* Créez une nouvelle app à partir du design dans le même projet
* Appliquez l&#39;apparence du design à une app existante
* Revenez en arrière en toute sécurité dans les deux cas : Agent crée un checkpoint avant de commencer

  ## Deux façons de passer d’une frame à une application
</div>

Le menu **Build…** d’une frame Design sélectionnée propose deux options :

<div id="build-this-design">
  ### Build this design
</div>

En sélectionnant **Build this design**, vous créez un nouvel artefact à partir du frame. Agent transforme la disposition, le style et les assets en une app fonctionnelle, qui apparaît dans la liste des artefacts de votre projet.

<div id="apply-to-an-existing-app">
  ### Appliquer à une app existante
</div>

Le menu répertorie également chaque artefact du projet. En en sélectionnant un, vous lui appliquez le design : Agent réécrit le code de l&#39;artefact pour qu&#39;il corresponde au frame, tandis que le frame Design reste sur le Canvas à titre de référence. Vous pouvez ainsi modifier le style d&#39;une app déjà créée sans repartir de zéro.

<div id="the-flow">
  ## Le déroulement
</div>

<Steps>
  <Step title="Choisissez le design à créer">
    Choisissez le frame que vous souhaitez publier. Comparez d&#39;abord les différentes options côte à côte sur le
    Canvas : le Build met fin à cette phase d&#39;exploration, mais Agent crée
    un checkpoint pour vous permettre de revenir en arrière à tout moment.
  </Step>

  <Step title="Confiez-le à Agent">
    Sélectionnez le frame, choisissez **Build…** dans sa barre d&#39;actions, puis sélectionnez l&#39;option souhaitée :
    un nouvel artefact ou un artefact existant. Agent crée le design, la disposition, le style
    et les assets, et indique sa progression dans le Chat.
  </Step>

  <Step title="Examinez le résultat">
    Agent indique les modifications apportées et crée un checkpoint. Ouvrez le résultat pour voir
    le design en direct, puis continuez la discussion pour ajuster tout ce qui ne s&#39;est pas traduit correctement.
  </Step>
</Steps>

<Note>
  Créer une nouvelle app à partir d&#39;un frame Design nécessite Core ou Pro ; appliquer un design
  et utiliser toutes les autres fonctionnalités de Replit Design est possible avec tous les forfaits. Consultez
  la page [Facturation](/fr/billing/ai-billing) pour en savoir plus sur les forfaits.
</Note>

<div id="after-you-build-make-it-real">
  ## Après le Build : donnez vie à votre projet
</div>

La création du frame vous fournit une application fonctionnelle qui reprend votre design. La maquette ne faisait que simuler son fonctionnement ; désormais, Agent peut ajouter de véritables fonctionnalités. Demandez ce dont vous avez besoin dans le Chat :

* **Permettez aux utilisateurs de se connecter** : ajoutez des comptes utilisateurs avec [Replit Auth](/fr/features/auth-and-identity/authentication) ; les utilisateurs se connectent avec leur compte Replit sans aucune configuration, ou utilisez votre propre fournisseur.
* **Enregistrez de vraies données** : stockez et récupérez des commandes, des messages et des préférences avec la [Database](/fr/features/data-and-storage/sql-database) intégrée.
* **Faites payer votre service** : ajoutez des paiements et des abonnements avec les intégrations de [Monetization](/fr/features/monetization/overview).
* **Connectez d&#39;autres services** : Agent active automatiquement des [intégrations](/fr/features/integrations/overview) selon vos prompts, de l&#39;e-mail à Slack en passant par les services Google.

<div id="ship-it-and-grow-it">
  ## Publiez-la et faites-la évoluer
</div>

Lorsque votre app est prête, présentez-la au public et continuez à l’améliorer :

* **Publier** : publiez-la depuis l’[outil Publishing](/fr/features/publishing/overview), puis consultez [Après la publication](/fr/features/publishing/after-you-publish) pour mettre à jour l’app en ligne.
* **Obtenir une véritable adresse** : achetez ou connectez un [domaine personnalisé](/fr/features/publishing/custom-domains).
* **Gagner en visibilité** : lancez l’[Agent SEO](/fr/features/publishing/seo-agent) pour réaliser un audit technique avec des correctifs en un clic.
* **Recueillir l’avis de vos visiteurs** : ajoutez le [widget de retour](/fr/features/publishing/feedback-widget) pour permettre aux utilisateurs de signaler des problèmes et des idées que vous pouvez envoyer directement à Agent.
* **La maintenir en bon état** : suivez l’état, les performances et la disponibilité avec le [Monitoring des apps publiées](/fr/features/publishing/monitoring-a-deployment).
