Le contrôle des modèles Enterprise permet aux administrateurs de compte de gérer les modèles Agent que les créateurs peuvent sélectionner. Après avoir défini des politiques à l’échelle du compte, vous pouvez configurer un accès différent aux modèles pour chaque espace de travail.

<Note>
  Le contrôle des modèles est réservé aux administrateurs de compte Enterprise. Pour l’activer dans votre organisation, contactez l’équipe commerciale à l’adresse [sales@replit.com](mailto:sales@replit.com).
</Note>

<div id="section">
  ## Utiliser le routage intelligent des modèles
</div>

Le routage intelligent des modèles constitue l&#39;expérience Agent par défaut dans les espaces de travail Enterprise. Lorsque vous activez le mode **Auto mode**, Replit sélectionne le mode et le modèle les mieux adaptés à chaque tâche, en conciliant qualité et coût.

Le routage puise dans un ensemble de modèles autorisés par les politiques du compte et de l&#39;espace de travail. Les fournisseurs et modèles extérieurs à cet ensemble ne peuvent pas être sélectionnés. Les créateurs peuvent laisser le **Auto mode** activé ou le désactiver pour choisir manuellement un modèle autorisé.

<div id="agent">
  ## Ouvrir les paramètres du modèle Agent
</div>

1. Ouvrez **Settings**.
2. Sous **Account**, sélectionnez **Advanced**.
3. Développez **Agent modes and model providers**.

<Frame caption="Stratégie relative aux fournisseurs de modèles dans les paramètres avancés et contrôle distinct des Fast mode models.">

</Frame>

<div id="section-2">
  ## Configurer les politiques des fournisseurs
</div>

<Steps>
  <Step>
    Sélectionnez le fournisseur de modèles que vous souhaitez gérer.
  </Step>

  <Step>
    Sous **Account policy**, sélectionnez l’une des options suivantes :

    | Option              | Résultat                                                                           |
    | ------------------- | ---------------------------------------------------------------------------------- |
    | **Enable all**      | Tous les modèles du fournisseur sont disponibles dans tous les espaces de travail. |
    | **Enable selected** | Vous pouvez sélectionner les modèles disponibles pour chaque espace de travail.    |
    | **Disabled**        | Aucun espace de travail ne peut utiliser les modèles du fournisseur.               |

    <Note>
      Vous devez laisser activé au moins un modèle d’OpenAI, d’Anthropic ou de Google. Les autres fournisseurs peuvent être désactivés.
    </Note>
  </Step>

  <Step>
    Sélectionnez **Update**.
  </Step>
</Steps>

Les fournisseurs de modèles open source sont désactivés par défaut. Pour les rendre disponibles, sélectionnez **Enable all** ou **Enable selected**, puis **Update**.

<div id="section-3">
  ## Configurer les politiques d’espace de travail
</div>

Utilisez **Enable selected** lorsque les besoins d’accès aux modèles diffèrent d’un espace de travail à l’autre.

<Frame caption="Politique du fournisseur Anthropic définie sur Enable selected et accès aux modèles configuré pour chaque espace de travail.">
  <img src="/assets/mirror/anthropic-account-policy-workspace-models-38c0f71a609d.jpg" alt="Politique de compte Anthropic définie sur Enable selected et interrupteurs de modèles pour les espaces de travail" width="2000" height="930" data-path="images/workspace/anthropic-account-policy-workspace-models.jpg" />
</Frame>

1. Ouvrez les paramètres du fournisseur.
2. Définissez **Account policy** sur **Enable selected**.
3. Dans la liste **Workspace**, sélectionnez le menu déroulant **Setting** de l’espace de travail concerné.
4. Activez ou désactivez chaque modèle pour cet espace de travail.
5. Sélectionnez **Update**.

Avant de sélectionner **Update**, vous pouvez sélectionner **Copy to all** pour appliquer la sélection de modèles de l’espace de travail actuel à tous les espaces de travail du compte.

<div id="section-4">
  ## Limites
</div>

* Les politiques de modèles s’appliquent à l’espace de travail. Vous ne pouvez pas définir de politiques différentes pour chaque groupe d’utilisateurs au sein d’un même espace de travail.
* Le routage intelligent des modèles ne remplace pas les politiques du compte ou de l’espace de travail. Vous ne pouvez pas sélectionner de fournisseurs ou de modèles désactivés.
* Le bouton bascule **Fast mode models** dans **Agent modes and model providers** contrôle l’accès aux variantes rapides des modèles dans tous les espaces de travail de votre compte. Les politiques des fournisseurs et le routage intelligent des modèles ne modifient pas ce paramètre.
