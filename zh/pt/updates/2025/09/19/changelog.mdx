<div id="controle-de-nvel-de-autonomia-para-o-agent">
  ### Agent 自主级别控制
</div>

借助全新的&quot;自主级别&quot;设置，你可以掌控 Agent 在项目中独立工作的方式。可选择低 (仅执行任务清单) 、中 (增加代码审查) 、高 (完整应用审查) 或最高 (完全自主规划) ，以契合你的工作流偏好和项目需求。

<div id="deteco-de-arquivos-maliciosos">
  ### 恶意文件检测
</div>

安全扫描器功能升级，现可检测并拦截供应链攻击中的恶意文件，包括防御近期针对 npm 包的攻击，让你在编写代码时始终受到保护。

<div id="bloqueio-de-ataques-cadeia-de-suprimentos">
  ### 阻止供应链攻击
</div>

增强的安全防护会自动拦截被入侵的 npm 包发起的数据外泄行为，在开发过程中保护你的敏感信息，同时不打断你的工作流程。

<div id="cpia-de-e-mail-da-pgina-de-membros">
  ### 成员页面一键复制邮箱
</div>

只需点击一下，即可直接在组织的成员管理页面快速复制成员的电子邮件地址，让团队沟通与管理更高效。

<div id="suporte-a-conectores-no-mobile">
  ### 移动端支持 Connectors
</div>

随着 Agent 3 的推出，Connectors 也正式上线，让你可以连接 GitHub、Notion 等第三方服务。

现在，你可以随时随地为应用添加 Connectors，移动设备同样完整支持。

点击[此处](/zh/replitai/integrations)了解有关 Connectors 的更多信息。

</div>

我们简化了术语：全平台的“Deploy”现统一称为“Publish”，让你在准备将项目分享给全世界时更加清晰直观。
