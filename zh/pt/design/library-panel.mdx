素材库面板是 Replit Design 内置的起点与参考资源。它包含三个选项卡：**模板**、**灵感**和**素材库**。其中的内容不会创建新项目；所有内容都会添加到当前项目的 Canvas 中。

<div id="templates">
  ## 模板
</div>

由 Replit 制作的预建设计设计帧，可搜索并按类型分组，包括海报、社交媒体帖子、落地页、移动端界面、横幅和原型。点击或拖动一个模板即可将其添加到你的设计中；它会作为活动设计帧添加到 Canvas，你可以像编辑自己生成的内容一样随时编辑它。

<div id="inspiration">
  ## 灵感
</div>

由 Mobbin 精选的真实产品界面截图。你可以搜索应用界面，例如 *“Airbnb 新手引导”* 或 *“Coinbase 结账流程”*，然后点击任意一张，将其作为静态参考图片添加到 Canvas。灵感不会向项目添加代码；你可以查看它、在 Chat 中指向它，或将其作为下一次生成的参考。

<div id="library">
  ## 素材库
</div>

你在此项目中创建的设计和产物，可随时重新添加到 Canvas。

<div id="templates-vs-inspiration">
  ## 模板与灵感
</div>

|            | 模板               | 灵感                    |
| ---------- | ---------------- | --------------------- |
| 是什么        | Replit 提供的初始设计帧 | 通过 Mobbin 获取的真实产品界面截图 |
| 在 Canvas 中 | 设计中的可编辑活动设计帧      | 静态参考图片                |
| 用途         | 基于可用的设计开始创作      | 指导下一次生成的外观            |

请参阅[添加模板和灵感](/zh/pt/design/add-templates-and-inspiration)，了解引导式流程。
