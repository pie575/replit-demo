title: "Mode Free d’Agent"
description: "Découvrez l’utilisation d’Agent offerte gratuitement par le mode Free aux abonnés Starter, Core et Pro."
---

<Note>
  Certains détails concernant les allocations peuvent encore être ajustés avant le lancement.
</Note>

Avec le mode Free, les abonnés Starter, Core et Pro peuvent utiliser Agent sans frais supplémentaires. Starter inclut le mode Free avec les limites existantes. Core et Pro incluent des allocations pour le mode Free. Commencez une conversation pour explorer, planifier, créer ou demander de l’aide. Si votre demande nécessite un mode ou une action payante, Replit vous l’indiquera clairement avant que des frais ne vous soient facturés.

<div id="section">
  ## Pourquoi vous allez l’apprécier
</div>

* Commencez par une conversation plutôt que par un processus de configuration.
* Explorez et développez vos idées avant de décider si vous avez besoin de fonctionnalités plus avancées.
* Vous gardez le contrôle, même si votre demande nécessite une action payante.
* Le travail effectué en mode Free est clairement identifié par le libellé **Free**.

<div id="section-2">
  ## Fonctionnement
</div>

1. Les nouvelles sessions Starter, Core et Pro démarrent en mode Free.
2. Les tâches pouvant être effectuées en mode Free se poursuivent sans prompt d’action payante.
3. Lorsqu’un mode payant peut mieux répondre à votre demande, Agent vous l’explique et vous présente les options.
4. Vous pouvez autoriser un mode payant uniquement pour cette demande ou demander à Agent de continuer en mode Free.
5. Après une escalade ponctuelle d’un mode payant, le mode revient à Free.

</div>

Le mode Free est accessible aux abonnés Starter, Core et Pro. Starter inclut le mode Free avec les limites existantes. Core et Pro incluent une allocation pour le mode Free, Pro bénéficiant d’une limite hebdomadaire plus élevée. Si vous avez besoin de davantage de capacités, vous pouvez également choisir un mode Agent payant.

<Note>
  **Lorsque vous atteignez une limite :** Starter inclut le mode Free avec les limites existantes. Avec Core et Pro, l’allocation du mode Free se réinitialise toutes les 5 heures et est soumise à une limite hebdomadaire. Pour connaître votre utilisation actuelle, consultez **Paramètres → Utilisation**. Replit vous avertira à l’avance lorsque vous approcherez d’une limite. Si vous atteignez une limite, passez à un mode payant pour continuer ou attendez la réinitialisation.
</Note>

<div id="section-3">
  ## Questions fréquentes
</div>

<AccordionGroup>
  <Accordion title="Le mode Free est-il vraiment gratuit ? Replit est-il devenu gratuit ?">
    Le mode Free est inclus dans les abonnements Starter, Core et Pro. L’offre Starter inclut le mode Free avec les limites existantes. Core et Pro incluent une allocation pour le mode Free. Il ne s’agit pas d’une offre gratuite à part entière.
  </Accordion>

  <Accordion title="Est-ce la même chose que les modes Agent payants ?">
    Non. Le mode Free vous permet d’utiliser Agent gratuitement dans la limite de votre allocation. Power et Max sont des modes payants destinés aux tâches nécessitant davantage de capacités.
  </Accordion>

  <Accordion title="Qu’est-il arrivé à Economy et Power ? Les modes ont-ils changé ?">
    Les modes payants ont été renommés. Economy s’appelle désormais Power, un mode intermédiaire qui permet d’utiliser des modèles puissants à un prix abordable. Le mode auparavant appelé Power s’appelle désormais Max et constitue le mode haut de gamme. Vos paramètres de mode existants sont automatiquement transférés vers les nouveaux noms.
  </Accordion>

  <Accordion title="Quel mode offre le plus de capacités ?">
    Max. Power est un mode payant intermédiaire qui offre davantage de capacités à un prix abordable. Max est le mode payant haut de gamme destiné aux tâches les plus exigeantes.
  </Accordion>

  <Accordion title="Que se passe-t-il si ma demande nécessite une action payante ?">
    Agent vous indique que votre demande nécessite un mode ou des capacités payants et vous demande confirmation avant de continuer. Vous pouvez approuver cette demande une seule fois ou continuer à utiliser le mode Free.
  </Accordion>

  <Accordion title="Si Agent suggère une mise à niveau, serai-je facturé automatiquement ?">
    Non. Toute escalade vers une option payante nécessite votre confirmation avant le lancement de la demande payante.
  </Accordion>

  <Accordion title="Puis-je refuser l’option payante ?">
    Oui. Vous pouvez continuer à travailler en mode Free.
  </Accordion>

  <Accordion title="Que se passe-t-il après avoir approuvé une escalade payante ?">
    Votre approbation s’applique uniquement à cette demande. Ensuite, votre mode Agent revient au mode Free.
  </Accordion>

  <Accordion title="Pourquoi ai-je atteint ma limite ? Quand sera-t-elle réinitialisée ?">
    L’offre Starter inclut le mode Free avec les limites existantes. Avec Core et Pro, l’allocation du mode Free est réinitialisée toutes les 5 heures et comporte une limite hebdomadaire. Pour consulter votre situation actuelle, accédez à **Paramètres → Utilisation**. Si vous atteignez votre limite, passez à un mode payant pour continuer ou attendez la réinitialisation.
  </Accordion>

  <Accordion title="Le mode Free est-il disponible avec Enterprise ?">
    Il n’est pas disponible au lancement. Les espaces de travail Enterprise bénéficieront peu après d’une expérience Agent dédiée. Contactez votre administrateur pour plus d’informations.
  </Accordion>
</AccordionGroup>

<div id="free">
  ## En savoir plus sur le mode Free
</div>

<AccordionGroup>
  <Accordion title="Le mode Free est-il identique à Lite ?">
    Pour les utilisateurs Starter, l’expérience auparavant appelée Lite s’appelle désormais le mode Free. Si vous utilisiez Lite pour ses modèles plus économiques, vous pouvez toujours les sélectionner manuellement dans Power en désactivant les paramètres automatiques.
  </Accordion>

  <Accordion title="Puis-je créer une application complète avec le mode Free ?">
    Oui. Vous pouvez créer une application complète et la faire évoluer de manière itérative avec le mode Free.
  </Accordion>

  <Accordion title="Quelle est la différence entre Free, Power et Max ?">
    Le mode Free permet aux abonnés Starter, Core et Pro d’utiliser Agent gratuitement au quotidien. Starter inclut le mode Free avec les limites existantes. Core et Pro incluent une allocation pour le mode Free. Power est un mode payant de niveau intermédiaire qui offre davantage de capacités à un prix abordable. Max est un mode payant haut de gamme destiné aux tâches les plus exigeantes.
  </Accordion>

  <Accordion title="Quand devrais-je passer du mode Free à un autre mode ?">
    Vous pouvez rester en mode Free pour les tâches quotidiennes. Passez à un autre mode si vous souhaitez de meilleurs résultats pour des tâches complexes ou si vous avez besoin de capacités indisponibles en mode Free.
  </Accordion>

  <Accordion title="Puis-je générer des vidéos avec le mode Free ?">
    Non. La génération de vidéos est une fonctionnalité des modes payants et n’est pas incluse dans le mode Free.
  </Accordion>

  <Accordion title="Qu’est-ce que la nouvelle expérience Conversations ?">
    Le chat et la création sont réunis au même endroit. Dans une même conversation, vous pouvez explorer des idées, planifier votre travail et démarrer un projet.
  </Accordion>

  <Accordion title="Les chats autonomes feront-ils partie des applications publiées ?">
    Non. Les conversations restent indépendantes jusqu’à ce que vous créiez ou modifiiez un projet.
  </Accordion>

  <Accordion title="Puis-je utiliser le mode Free avec des projets existants ?">
    Oui. Il prend en charge la maintenance et les modifications quotidiennes des projets existants.
  </Accordion>
</AccordionGroup>

**Prêt à essayer ?** Lorsque le mode Free sera disponible, démarrez une conversation avec Agent pour vous lancer.
