<div id="troubleshooting">
  ## 故障排查
</div>

* **改动幅度超出预期：** 让 Agent 撤销该改动，并重新描述一个更小的改动，一次只改一个页面或一个元素。
* **预览里看着正常，手机上却不对：** 说明具体的设备型号和你看到的现象，通常是安全区域和屏幕尺寸的适配问题。
* **改动总是被还原：** 同一个值可能在多处被设置，可以问 Agent 该页面的样式实际定义在哪里。
