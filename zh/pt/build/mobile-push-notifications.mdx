Android 可立即在 Expo Go 中测试此功能。iOS 则需要先[通过 TestFlight 提交并安装 App](/zh/build/mobile-testflight)。Apple 要求 App 必须先在其平台完成注册，才能接收任何通知，即使是测试通知也不例外。

<Steps>
  <Step title="请求权限">
    iOS 和 Android 会在首次发送通知前请求一次权限。拒绝后将不会再收到通知，直到玩家在设置中重新启用。
  </Step>

  <Step title="注册设备">
    Agent 会为已登录的玩家注册推送 token，以便 PixelGames 知道该向哪个设备发送通知。
  </Step>

  <Step title="发送">
    当好友打破该玩家的纪录时，系统会触发通知。
  </Step>
</Steps>

<div id="teste">
  ## 测试
</div>

1. 系统提示时，请授予通知权限。在获得权限之前，PixelGames 无法发送任何通知，而且该提示只会出现一次。
2. 触发真实条件，例如使用第二个账号打破好友的纪录，而不是只让 Agent 发送一条测试通知。这能确认整个流程均正常运行：保存纪录、检查要通知的对象以及发送通知，而不只是确认已授予权限。
3. 确认通知会显示在锁定屏幕上，然后点按通知，确认它会打开 PixelGames。点按通知可验证它确实能将你带回 App，而不只是显示出来。

请在真机上完成此操作；通知不会发送到模拟器。有关配置，请参阅
[使用 Expo Go 测试](/zh/build/mobile-preview-testing)。

<div id="soluo-de-problemas">
  ## 故障排除
</div>

* **iOS 上始终收不到通知：**确认你是通过
  [TestFlight](/zh/build/mobile-testflight) 进行测试；Expo Go 无法在 iOS 上接收推送通知。
* **玩家已授予权限但仍未收到任何通知：**检查 token 是否确实
  已保存到其账户中；登录和通知配置
  分开进行时，常常会遗漏这一步。
