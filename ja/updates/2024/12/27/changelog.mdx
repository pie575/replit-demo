## プラットフォームの更新

### インテグレーション

インテグレーションが Agent UI の\_中心的な位置\_に配置されました。お気に入りのサービスを Agent アプリに簡単に追加できます。新しいインテグレーションが複数リリースされ、改善されました。ぜひご確認ください。いくつかのハイライトをご紹介します:

* Perplexity
* Firebase
* OpenAI
* Anthropic
* Google Services

### Agent の改善

Agent は現在の実行を完了する代わりに、リクエストされるとすぐに一時停止するようになりました。気が変わったときに Agent を停止しやすくなります。

Agent UI に新しくおしゃれな「実行」ボタンが追加されているのにも気付くかもしれません。

## チームとエンタープライズ

### Replit Teams の更新

Teams のいくつかのエキサイティングな更新をご紹介します:

* チームが Replit App のアイコンとカバー画像をカスタマイズできるようになりました
* 単色カバーがカスタム画像に置き換えられました
* Replit Teams がモバイルで利用できるようになりました！

今や実質的にどこからでも株主価値を生み出せます 🤯
