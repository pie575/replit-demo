В этом справочном руководстве описан класс `Client` из пакета `replit-object-storage-python` и приведены примеры кода для его методов.

<div id="client">
  ## Client
</div>

Класс `Client` управляет взаимодействием с Replit App Storage. Он предоставляет методы для работы с объектами в бакете.

Чтобы импортировать этот класс из пакета `replit.object_storage`, добавьте в код Python следующую строку.

```python theme={null}
from replit.object_storage import Client
```

Используйте следующий код, чтобы создать экземпляр `Client` для работы с Replit App Storage.

```python theme={null}
client = Client()
```

<Tip>
  Если приложение использует несколько бакетов, создайте отдельный экземпляр `Client` для каждого из них.
</Tip>

<div id="__init__">
  ### **init**
</div>

Метод `init` инициализирует экземпляр класса Client.

```python theme={null}
def __init__(bucket_id: Optional[str] = None)
```

**Аргументы**:

* `bucket_id` (Optional[str]): идентификатор бакета, которым управляет клиент. Если не указан, клиент использует бакет по умолчанию, связанный с Replit App или развёртыванием.

<div id="copy">
  ### copy
</div>

Метод `copy` копирует объект в пределах одного бакета. Если объект уже существует по тому же пути, он будет перезаписан исходным объектом.

```python theme={null}
def copy(object_name: str, dest_object_name: str) -> None
```

**Аргументы**:

* `object_name` (str) — полный путь к исходному объекту.
* `dest_object_name` (str) — полный путь к целевому объекту.

**Вызываемые исключения**:

* `ObjectNotFoundError` — исходный объект не существует по указанному пути.

<div id="delete">
  ### delete
</div>

Метод `delete` безвозвратно удаляет файлы из App Storage.

```python theme={null}
def delete(object_name: str, ignore_not_found: bool = False) -> None
```

**Аргументы**:

* `object_name` (str) — имя удаляемого объекта.
* `ignore_not_found` (bool) — если `True`, игнорирует ошибку, возникающую, если объект не найден.

**Вызываемые исключения**:

* `ObjectNotFoundError` — объект не найден.

<div id="list">
  ### list
</div>

Метод `list` возвращает список объектов в бакете.

```python theme={null}
def list(end_offset: Optional[str] = None,
         match_glob: Optional[str] = None,
         max_results: Optional[int] = None,
         prefix: Optional[str] = None,
         start_offset: Optional[str] = None) -> List[Object]
```

**Аргументы**:

* `end_offset`(Optional[str]) — Фильтрует результаты, оставляя объекты с именами, лексикографически предшествующими `end_offset`. Если задан `start_offset`,
  в список включаются объекты с именами в диапазоне от `start_offset` (включительно) до `end_offset` (исключительно).
* `match_glob` (Optional[str]) — Фильтрует результаты по glob-шаблону. Например, &quot;foo*bar&quot; соответствует &quot;footbar&quot;, &quot;foo baz bar&quot; и &quot;foobar&quot;.
* `max_results` (Optional[int]) — Максимальное число результатов, возвращаемых в ответе.
* `prefix` (Optional[str]) — Фильтрует результаты, оставляя объекты с именами, начинающимися с указанного префикса.
* `start_offset` (Optional[str]) — Фильтрует результаты, оставляя объекты с именами, лексикографически равными `start_offset` или следующими за ним.
  Если задан `end_offset`, в список включаются объекты с именами в диапазоне от `start_offset` (включительно) до `end_offset` (исключительно).

**Возвращает**:

* `List`(Object): Список объектов, соответствующих указанным параметрам запроса.

<div id="section">
  ### Типы исключений
</div>

* При работе с Replit App Storage через `Client` любой метод может вернуть одну из следующих ошибок.

  * `BucketNotFoundError`: указывает, что указанное имя бакета не соответствует ни одному бакету в App Storage.

  * `DefaultBucketError`: указывает, что не настроен бакет по умолчанию.

  * `ForbiddenError`: указывает на недостаточные права доступа к бакету.

  * `TooManyRequestsError`: указывает, что операция ограничена из-за слишком большого количества запросов.

  * `UnauthorizedError`: указывает, что авторизация ограничивает доступ к операции.
