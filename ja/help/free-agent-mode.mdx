title: "Free Agent モード"
description: "Free モードが Starter、Core、Pro のサブスクライバーに無料で提供する Agent 利用について学びましょう。"
---

<Note>
  一部の割り当ての詳細は、リリースに向けてまだ調整される可能性があります。
</Note>

Free モードを使用すると、Starter、Core、Pro のサブスクライバーは追加費用なしで Agent を利用できます。Starter には既存の制限のまま Free モードが含まれます。Core と Pro には Free モードの割り当てが含まれます。会話を開始して、探索、計画、作成、またはヘルプの依頼を行いましょう。リクエストに有料モードや有料アクションが必要な場合、Replit は課金が発生する前にその旨を明確に伝えます。

## 気に入る理由

* セットアップフローではなく会話から始められます。
* より高い能力が必要かどうかを決める前に、アイデアを探索して進めることができます。
* リクエストに有料アクションが必要な場合でも、コントロールはあなたの手に残ります。
* Free モードで完了した作業には、わかりやすい **Free** ラベルが表示されます。

## 仕組み

1. 新しい Starter、Core、Pro のセッションは Free モードで開始します。
2. Free モードに収まる作業は、有料アクションのプロンプトなしで続行されます。
3. リクエストをより適切に処理できる有料モードがある場合、Agent はその旨を説明し、選択肢を提示します。
4. そのリクエストに限り有料モードを許可するか、Agent に Free モードのまま続行するよう依頼できます。
5. 一度限りの有料エスカレーションの後、モードは Free モードに戻ります。

## 3つの Agent モード

<CardGroup cols={3}>
  <Card title="Free">
    Starter、Core、Pro のサブスクライバー向けの無料の Agent 利用。
  </Card>

  <Card title="Power">
    より高い能力を手頃な価格で必要とする作業向けの、有料のミドルティアモード。
  </Card>

  <Card title="Max">
    最も要求の厳しい作業向けの、最高峰のフロンティアモデルを備えた有料のトップティアモード。
  </Card>
</CardGroup>

Free モードは Starter、Core、Pro のサブスクライバーが利用できます。Starter には既存の制限のまま Free モードが含まれます。Core と Pro には Free モードの割り当てが含まれ、Pro にはより大きな週次制限が含まれます。より高い能力が必要な場合は、有料の Agent モードを選択することもできます。

<Note>
  **制限に達した場合：** Starter には既存の制限のまま Free モードが含まれます。Core と Pro では、Free モードの割り当ては5時間ごとにリセットされ、週次の上限があります。現在の状況を確認するには、**設定 → 使用状況** を確認してください。制限に近づくと、Replit が事前に通知します。制限に達した場合は、有料モードに切り替えて続行するか、リセットを待ってください。
</Note>

## よくある質問

<AccordionGroup>
  <Accordion title="Free モードは本当に無料ですか？Replit は無料になったのですか？">
    Free モードは Starter、Core、Pro のサブスクリプションに含まれています。Starter には既存の制限のまま Free モードが含まれます。Core と Pro には Free モードの割り当てが含まれます。これ自体が無料プランというわけではありません。
  </Accordion>

  <Accordion title="これは有料の Agent モードと同じですか？">
    いいえ。Free モードは、その割り当ての範囲内での無料の Agent 利用です。Power と Max は、より高い能力が必要な作業向けの有料モードです。
  </Accordion>

  <Accordion title="Economy と Power はどうなりましたか？モードは変更されましたか？">
    有料モードの名称が変更されました。Economy は Power という名称になり、手頃な価格で強力なモデルを使えるミドルティアモードです。以前 Power と呼ばれていたモードは、現在は Max という名称になり、トップティアモードです。既存のモード設定は、新しい名称にそのまま引き継がれます。
  </Accordion>

  <Accordion title="最も能力が高いモードはどれですか？">
    Max です。Power は、手頃な価格でより高い能力を提供する有料のミドルティアモードです。Max は、最も要求の厳しい作業向けの有料のトップティアモードです。
  </Accordion>

  <Accordion title="リクエストに有料アクションが必要な場合はどうなりますか？">
    Agent は、そのリクエストに有料モードや有料の能力が必要であることを説明し、進める前に確認を求めます。そのリクエストを一度だけ承認するか、Free モードのまま続けることができます。
  </Accordion>

  <Accordion title="Agent がアップグレードを提案した場合、自動的に課金されますか？">
    いいえ。有料へのエスカレーションには、有料リクエストが開始される前にあなたの確認が必要です。
  </Accordion>

  <Accordion title="有料オプションを断ることはできますか？">
    はい。Free モードのまま作業を続けることができます。
  </Accordion>

  <Accordion title="有料エスカレーションを承認した後はどうなりますか？">
    承認はそのリクエストにのみ適用されます。その後、あなたの Agent モードは Free モードに戻ります。
  </Accordion>

  <Accordion title="なぜ制限に達したのですか？いつリセットされますか？">
    Starter には既存の制限のまま Free モードが含まれます。Core と Pro では、Free モードの割り当ては5時間ごとにリセットされ、週次の上限があります。現在の状況を確認するには、**設定 → 使用状況** を確認してください。制限に達した場合は、有料モードに切り替えて続行するか、リセットを待ってください。
  </Accordion>

  <Accordion title="Free モードは Enterprise で利用できますか？">
    リリース時点では利用できません。Enterprise ワークスペースには、その後まもなく専用の Agent 体験が提供される予定です。詳細については管理者にお問い合わせください。
  </Accordion>
</AccordionGroup>

## Free モードについてさらに詳しく

<AccordionGroup>
  <Accordion title="Free モードは Lite と同じですか？">
    Starter ユーザーにとって、以前 Lite と呼ばれていた体験は現在 Free モードになっています。低コストのモデルのために Lite を使用していた場合でも、自動設定をオフにすれば Power 内で手動でそのモデルを選択できます。
  </Accordion>

  <Accordion title="Free モードで完全なアプリを構築できますか？">
    はい。Free モードで完全なアプリを作成し、反復開発することができます。
  </Accordion>

  <Accordion title="Free、Power、Max はどう違いますか？">
    Free モードは、Starter、Core、Pro のサブスクライバー向けの無料の日常的な Agent 利用です。Starter には既存の制限のまま Free モードが含まれます。Core と Pro には Free モードの割り当てが含まれます。Power は、手頃な価格でより高い能力を提供する有料のミドルティアモードです。Max は、最も要求の厳しい作業向けの有料のトップティアモードです。
  </Accordion>

  <Accordion title="いつ Free モードから切り替えるべきですか？">
    日常的な作業には Free モードのままで構いません。複雑なタスクでより強力な結果が欲しい場合や、Free モードにない能力が必要な場合に切り替えてください。
  </Accordion>

  <Accordion title="Free モードで動画を生成できますか？">
    いいえ。動画生成は有料モードの機能であり、Free モードには含まれません。
  </Accordion>

  <Accordion title="新しい Conversations 体験とは何ですか？">
    チャットと作成が一つにまとまっています。同じ会話の中で、アイデアを調査したり、作業を計画したり、プロジェクトを開始したりできます。
  </Accordion>

  <Accordion title="スタンドアロンのチャットは公開されたアプリの一部になりますか？">
    いいえ。プロジェクトを作成または変更するまで、会話は独立したままです。
  </Accordion>

  <Accordion title="Free モードは既存のプロジェクトで使用できますか？">
    はい。既存のプロジェクトに対する日常的なメンテナンスや編集をサポートしています。
  </Accordion>
</AccordionGroup>

**試してみませんか？** Free モードがリリースされたら、Agent との会話を開始して始めてみましょう。
