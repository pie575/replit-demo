title: "Replit dans Slack"
description: "Mentionnez @Replit dans Slack pour transformer un prompt en prototype fonctionnel, sans quitter le workspace de votre équipe."
---

Ajoutez l&#39;application **Replit** à votre workspace Slack et mentionnez **@Replit** avec un prompt pour passer de l&#39;idée au prototype fonctionnel : le développement assisté par IA directement dans les conversations de votre équipe.

<div id="o-que-voc-pode-fazer">
  ## Ce que vous pouvez faire
</div>

Mentionnez **@Replit** avec votre idée dans n&#39;importe quel canal : Replit Agent crée un prototype fonctionnel que vous pouvez utiliser ou faire évoluer immédiatement.

* Générez des prototypes et des designs à partir d&#39;un prompt en langage naturel.
* Obtenez un résultat fonctionnel en quelques secondes, puis affinez-le directement dans le fil de discussion.
* Collaborez avec votre équipe sur le prototype sans quitter Slack.

<Tip>
  Essayez de mentionner Replit avec une idée, par exemple « @Replit build a form that collects team lunch orders » ou « @Replit make a landing page for our launch ». Replit Agent crée un prototype et le publie dans la conversation.
</Tip>

<div id="adicione-o-replit-ao-slack">
  ## Ajoutez Replit à Slack
</div>

Installez l&#39;application depuis [Replit for Slack](https://replit.com/partners/slack-app) et sélectionnez **Add to Slack**. Choisissez le workspace Slack à connecter, vérifiez les autorisations et sélectionnez **Allow**. Une fois l&#39;installation terminée, mentionnez **@Replit** dans n&#39;importe quel canal pour commencer à créer.

<Note>
  Replit Agent utilise l&#39;IA pour générer ses réponses ; les résultats peuvent donc parfois être inexacts ou incomplets — vérifiez par vous-même les informations importantes.
</Note>

<div id="como-funciona">
  ## Fonctionnement
</div>

Mentionner **@Replit** pilote Replit via le [serveur MCP Replit](/fr/pt/platforms/mcp-server). Slack se charge de la connexion pour vous.
