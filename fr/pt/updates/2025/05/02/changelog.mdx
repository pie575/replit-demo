<div id="replit-auth">
  ### Replit Auth
</div>

[Replit Auth](/fr/pt/core-concepts/project-editor/auth-and-security/authentication) est désormais disponible pour tous les utilisateurs ! Il s&#39;agit d&#39;un système d&#39;authentification intégré qui permet d&#39;ajouter la connexion des utilisateurs à vos applications avec un minimum de configuration. Plutôt que de développer des systèmes d&#39;authentification complexes de A à Z, Replit Auth offre une solution sécurisée et prête à l&#39;emploi, intégrée à l&#39;infrastructure de Replit.

**Principales fonctionnalités :**

* **Aucune configuration** - Ajoutez l&#39;authentification avec un simple prompt dans Agent
* **Sécurité intégrée** - S&#39;appuie sur l&#39;infrastructure de Replit, avec des protections contre les attaques courantes
* **Gestion des utilisateurs** - Administration simplifiée des utilisateurs depuis le tableau de bord Auth
* **Intégration à la base de données** - Création automatique des entrées utilisateur dans votre base de données
* **Page de connexion personnalisable** - Adaptez l&#39;expérience de connexion à votre application
* **Réinitialisation du mot de passe** - Replit gère les e-mails de réinitialisation de mot de passe, ce qui vous évite de recourir à votre propre fournisseur d&#39;envoi d&#39;e-mails

Se lancer est simple : mentionnez Replit Auth dans votre prompt destiné à Agent :

<AiPrompt>
  Aide-moi à créer une application qui [votre idée d&#39;application] et qui doit inclure Replit Auth.
</AiPrompt>

</div>
