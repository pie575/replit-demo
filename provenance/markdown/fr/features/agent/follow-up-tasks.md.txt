# Tâches de suivi

> Examinez, démarrez et gérez en masse les suggestions de tâches de suivi d'Agent après la fin d'une tâche.

## Suggestions de tâches de suivi

Après avoir appliqué une tâche, Agent examine le contexte de votre projet et suggère des **tâches de suivi** que vous pourriez vouloir construire ensuite. La boîte de dialogue **Prochaines tâches suggérées** affiche la meilleure recommandation en ligne, afin que vous puissiez continuer sans quitter le fil principal.

Les suggestions de suivi peuvent inclure :

* **Nouvelles fonctionnalités à construire** : des capacités qui s'associent naturellement à ce que vous venez de livrer
* **Améliorations des performances** : des optimisations qu'Agent a remarquées en travaillant sur la tâche
* **Améliorations de l'expérience utilisateur** : des finitions et des raffinements qui complètent la fonctionnalité

Sélectionnez **Démarrer** sur une suggestion pour l'envoyer en arrière-plan, ou sélectionnez **Voir le plan** pour inspecter d'abord le travail proposé. Pour voir toutes les suggestions, sélectionnez **Voir plus dans le tableau des tâches**. Les suivis suggérés apparaissent sous **Suggérée** dans la colonne **Brouillons**.

La fermeture de la boîte de dialogue **Prochaines tâches suggérées** annule les suggestions. Agent n'affiche pas la boîte de dialogue sur la version principale lorsqu'un plan proposé y attend déjà, de sorte que les deux invites ne se concurrencent pas pour votre attention.

## Gérer de nombreuses suggestions à la fois

Pour les projets comportant de nombreuses suggestions de suivi, ouvrez le tableau des tâches et sélectionnez **Modifier** dans la colonne **Brouillons**. En mode édition, chaque tâche suggérée reçoit une case à cocher. Sélectionnez les tâches souhaitées, puis utilisez **Démarrer** ou **Annuler** pour appliquer cette action à toutes les tâches sélectionnées. Sélectionnez **Terminé** pour quitter le mode édition.
