<div id="replitmd">
  ### Documentation replit.md
</div>

Utilisez `replit.md` pour personnaliser le comportement d&#39;Agent. Ce fichier de configuration spécial aide Agent à comprendre les préférences, le style de code et l&#39;architecture de votre projet. Agent génère automatiquement ce fichier en s&#39;appuyant sur des bonnes pratiques éprouvées, puis l&#39;utilise pour créer des applications conformes à vos spécifications exactes. Guidez Agent avec le contexte de votre projet, définissez vos normes de codage, précisez votre pile technologique préférée et paramétrez vos préférences de communication — le tout au même endroit.

  ### Indicateur de confidentialité des déploiements
</div>
