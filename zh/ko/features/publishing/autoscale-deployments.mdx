---

Autoscale 部署在可自动扩缩容的云计算资源上运行，可高效处理 Replit App 的网络流量和工作负载。应用繁忙时，会添加服务器来应对负载。应用空闲时，服务器数量会缩减至最少 0 台，以节省成本。

Autoscale 部署适用于以下场景：

* 工作负载和流量波动较大的 Web 应用，例如电商网站
* API 和服务

<div id="section">
  ## 功能
</div>

Autoscale 部署提供以下功能：

* **自动扩缩容**：根据流量模式自动调整资源，以优化成本。
* **自定义域名**：配置自定义域名，或使用 `<app-name>.replit.app` URL 访问应用。
* **可配置限制**：设置已发布应用可扩展到的最大实例数。
* **灵活的机器性能**：选择应用所需的 CPU 和 RAM 配置。
* **监控**：查看日志并监控已发布应用的状态。

<div id="section-2">
  ## 使用方法
</div>

您可以在项目编辑器的部署工具中访问 Autoscale 部署。

<Accordion title="如何访问 Autoscale 部署">
  在左侧**工具栏**中：

  1. 选择 <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="所有工具图标" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **所有工具**，查看项目编辑器的工具列表。
  2. 选择 <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="部署图标" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **部署**。
  3. 选择 **Autoscale** 选项，然后选择 **设置已部署的应用**。

  在**搜索栏**中：

  1. 选择顶部的 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 放大镜，打开搜索工具。
  2. 输入“部署”查找该工具，然后从搜索结果中选择它。
  3. 选择 **Autoscale** 选项，然后选择 **设置已部署的应用**。
</Accordion>

<div id="section-3">
  ## 机器性能
</div>

选择**编辑**，查看并配置机器性能选项。使用滑块为已发布应用的每个服务器实例选择 CPU 和 RAM 配置。

在**每台机器总计**一行中查看该配置的**计算单元**费用。
计算单元是根据机器的内存和 CPU 配置衡量云计算资源的单位。

如需了解如何按计算单元计费，请参阅[计算单元](/zh/ko/billing/about-usage-based-billing#2-compute-units)。

<div id="section-4">
  ## 最大机器数
</div>

使用滑块调整最大机器数。当自动扩缩功能判断应用繁忙时，此数值表示可分配的服务器实例数量上限。

底部会显示根据以下公式计算得出的相应计算单元数：

`机器数 * 每台机器的计算单元数`
