<div id="agent-v2">
  ### Agent v2
</div>

<img src="/assets/mirror/agent-web-01b1f9026de7.webp" alt="Agent v2" width="800" height="450" data-path="images/changelog/2025-02-28/agent-web.webp" />

Новый Agent доступен всем создателям. Он работает быстрее, точнее и умеет больше, чем предыдущая версия.

Теперь в его основе — Claude 3.7 Sonnet, самая продвинутая модель Anthropic на сегодняшний день.

Попробовать его можно, присоединившись к программе Explorer. Инструкции смотрите [здесь](https://youtu.be/pE_XT2TaXCA).

<div id="melhorias-nas-implantaes">
  ### Улучшения развёртываний
</div>

Теперь пользователям, которые выбирают статическое развёртывание для динамических приложений, показываются подсказки ИИ — это улучшает поведение Agent при обработке запросов на развёртывание.

<div id="lanamento-do-claude-37-sonnet">
  ### Запуск Claude 3.7 Sonnet
</div>

Режим Advanced в Assistant обновлён до Claude 3.7 Sonnet для всех создателей с платной подпиской. Это означает более высокую точность и лучшую работу со сложными запросами.

<div id="melhoria-no-desempenho-do-banco-de-dados">
  ### Повышение производительности базы данных
</div>

Операции с базой данных теперь выполняются быстрее, чем когда-либо: время самой затратной операции сократилось с 200 мс до менее чем 1 мс.

<div id="documentao-aprimorada">
  ### Улучшенная документация
</div>

<img src="/assets/mirror/cleanshot-2025-02-27-at-1042282xpng-220848-e5317a7cfb93.png" alt="Обновлённый дизайн документации" width="3680" height="2382" data-path="images/changelog/2025-02-28/cleanshot-2025-02-27-at-1042282xpng-220848.png" />

Мы обновили дизайн документации: теперь её проще понимать и использовать, а сама она полностью совместима с LLM.

В документации появилась кнопка «Копировать страницу» — она позволяет скопировать всю страницу в формате markdown. Кроме того, документацию можно проиндексировать с помощью `llms.txt` и `llms-full.txt`, чтобы использовать её со своими LLM.

* [https://docs.replit.com/llms.txt](https://docs.replit.com/llms.txt)
* [https://docs.replit.com/llms-full.txt](https://docs.replit.com/llms-full.txt)
