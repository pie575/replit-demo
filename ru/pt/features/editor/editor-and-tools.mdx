Редактор проекта включает управление макетом рабочей области и встроенные инструменты, которые упрощают создание приложений.
Каждый из этих инструментов отвечает за свой аспект процесса разработки, чтобы вы могли
сосредоточиться на создании, а не на настройке.

<div id="layout-personalizvel-do-editor-de-projeto">
  ## Настраиваемый макет редактора проекта
</div>

Инструменты управления макетом редактора проекта позволяют настроить компоненты среды разработки.
Он состоит из следующих типов элементов интерфейса:

| Элемент     | Описание                                                                                        | Возможности                                                                                                                                                                | Сценарии использования                                                                                                  |
| ----------- | ----------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| **Окна**    | Вкладки браузера, содержащие одну или несколько панелей                                         | <ul><li>Можно размещать на нескольких экранах</li></ul>                                                                                                                    | <ul><li>Размещение редактора проекта на нескольких экранах</li><li>Одновременная работа над разными проектами</li></ul> |
| **Панели**  | Разделы окна, содержащие одну или несколько вкладок                                             | <ul><li>Поддерживают горизонтальное и вертикальное разделение</li><li>Можно изменять их размер и порядок</li><li>Можно превратить в плавающую панель внутри окна</li></ul> | <ul><li>Просмотр кода и Preview бок о бок</li><li>Создание собственных макетов под разные задачи разработки</li></ul>   |
| **Вкладки** | Содержат ровно один инструмент редактора проекта — например, редактор файлов, Preview или Agent | <ul><li>Можно перемещать между панелями и менять их порядок внутри панели</li><li>Можно переключаться между файлами и инструментами одним нажатием</li></ul>               | <ul><li>Открытие нужных инструментов или файлов по мере необходимости</li></ul>                                         |

<div id="rvore-de-arquivos">
  ## Дерево файлов
</div>

В дереве файлов перечислены все файлы и каталоги вашего Replit App.

<Accordion title="Как открыть дерево файлов">
  Нажмите значок папки <img class="icon-svg" src="/assets/mirror/files-icon-f66bf1b04572.svg" alt="значок папки со стрелками" width="16" height="16" data-path="images/icons/files-icon.svg" /> слева, чтобы показать или скрыть
  дерево файлов.
</Accordion>

В дереве файлов доступны следующие действия:

* Выбрать папку, чтобы посмотреть её содержимое
* Выбрать файл или перетащить его на панель, чтобы открыть в редакторе файлов
* Выполнить операции с файлом: дублировать, переименовать, переместить, скачать или удалить

<div id="boto-run">
  ## Кнопка Run
</div>

Кнопка **Run** запускает выбранный рабочий процесс вашего Replit App.

<Accordion title="Как найти кнопку Run">
  Кнопка **Run** находится в верхней части экрана редактора проекта. Нажмите её, чтобы запустить рабочий процесс.

  Когда Replit App запущен, надпись на кнопке меняется на **Stop**. Нажмите её, чтобы остановить приложение.
</Accordion>

О том, как выбирать, просматривать рабочие процессы и управлять ими, см. в разделе [Рабочие процессы](/ru/pt/features/workspace-tools/workflows/).

<div id="menu-de-opes">
  ## Меню параметров
</div>

Меню параметров позволяет выполнять следующие действия с макетом:

* **Управление окнами**: открыть редактор проекта Replit App в новом окне
* **Управление панелями**: добавить панели, переместить панель, развернуть панель, переключаться между плавающим и закреплённым положением
* **Управление вкладками**: открыть или выбрать другие вкладки, переместить вкладку на другую панель, закрыть вкладку

<Accordion title="Как открыть меню параметров">
  Нажмите на значок с тремя вертикальными точками <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="значок трёх вертикальных точек" height="16" width="16" data-path="images/icons/vertical-dots.svg" />
  в правом верхнем углу активной вкладки, чтобы открыть меню параметров.
</Accordion>

На следующем снимке экрана показано всплывающее меню параметров на левой панели:

<div id="barra-de-pesquisa">
  ## Строка поиска
</div>

Строка поиска позволяет находить файлы, текст или инструменты в редакторе проекта.

<Accordion title="Как открыть строку поиска">
  1. Чтобы открыть строку поиска, выберите значок лупы <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="значок лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> в верхней части экрана.
  2. Введите текст, который хотите найти, и выберите один из вариантов автодополнения.
</Accordion>

На следующем снимке экрана показано всплывающее меню поиска:

<div id="painel-de-recursos">
  ## Панель ресурсов
</div>

Панель ресурсов показывает вычислительные ресурсы среды разработки и их использование, включая ОЗУ, ЦП и хранилище.
Эта информация поможет вам оценить и оптимизировать требования к публикации вашего Replit App.

<Accordion title="Как открыть панель ресурсов">
  1. Нажмите значок ресурсов <img class="icon-svg" src="/assets/mirror/resources-237893692826.svg" alt="значок в виде стопки компьютеров" width="16" height="16" data-path="images/icons/resources.svg" /> рядом с названием приложения, чтобы показать или скрыть панель.
  2. Наведите курсор на строки **Compute** или **Storage**, чтобы увидеть подробности.
</Accordion>

На снимке экрана ниже показана панель ресурсов:
