description: "选择每个 Enterprise Workspace 中可用的模型提供方和 Agent 模型。"

Enterprise 模型控制让账户管理员能够管理构建者可选用哪些 Agent 模型。您可以为整个账户设定策略，再为各个 Workspace 单独配置不同的模型访问权限。

<Note>
  模型控制仅面向 Enterprise 账户的账户管理员开放。如需为您的组织启用，请通过 [sales@replit.com](mailto:sales@replit.com) 联系我们的销售团队。
</Note>

<div id="usar-o-roteamento-inteligente-de-modelos">
  ## 使用智能模型路由
</div>

智能模型路由是 Enterprise Workspace 中 Agent 的默认体验。启用 **Auto mode** 后，Replit 会为每项任务选择最合适的模式和模型，在质量与成本之间取得平衡。

路由只会从账户和 Workspace 策略允许的模型范围内进行选择，此范围之外的提供商和模型均不可选。构建者可以保持 **Auto mode** 开启，也可以将其关闭，手动选择某个已授权的模型。

<Frame caption="启用 Auto mode，即可在 Workspace 已授权的模型之间路由任务。">

</Frame>

如需进一步了解路由的工作方式，请参阅[使用智能模型路由](/zh/pt/chat/auto-mode)。

<div id="abrir-as-configuraes-de-modelo-do-agent">
  ## 打开 Agent 模型设置
</div>

1. 打开**设置**。
2. 在**账户**下，选择**高级**。
3. 展开 **Agent 模式与模型提供方**。

<Frame caption="高级设置中的模型提供方策略，以及独立的 Fast mode 模型控制。">
  <img src="/assets/mirror/agent-model-provider-settings-overview-8f82610dab77.jpg" alt="包含提供方策略和 Fast mode 模型控制的 Agent 模式与模型提供方设置" width="2000" height="930" data-path="images/workspace/agent-model-provider-settings-overview.jpg" />
</Frame>

<div id="definir-uma-poltica-de-provedor">
  ## 设置提供商策略
</div>

<Steps>
  <Step>
    选择你要管理的模型提供商。
  </Step>

  <Step>
    在 **Account policy** 中选择一个选项：

    | 选项                  | 结果                            |
    | ------------------- | ----------------------------- |
    | **Enable all**      | 该提供商的所有模型在所有 Workspace 中均可使用。 |
    | **Enable selected** | 你可以为每个 Workspace 指定可用的模型。     |
    | **Disabled**        | 所有 Workspace 都无法使用该提供商的模型。    |

    <Note>
      OpenAI、Anthropic 和 Google 必须各自至少保留一个模型处于启用状态，其他提供商则可以全部禁用。
    </Note>
  </Step>

  <Step>
    选择 **Update**。
  </Step>
</Steps>

开源模型提供商默认处于禁用状态。若要启用某个提供商，请选择 **Enable all** 或 **Enable selected**，然后选择 **Update**。

<div id="definir-uma-poltica-de-workspace">
  ## 设置 Workspace 策略
</div>

当不同 Workspace 需要不同的模型访问权限时，请使用 **Enable selected**。

<Frame caption="Anthropic 提供方策略设置为 Enable selected，并按 Workspace 配置模型访问权限。">
  <img src="/assets/mirror/anthropic-account-policy-workspace-models-38c0f71a609d.jpg" alt="Anthropic 账户策略设置为 Enable selected，并显示某个 Workspace 的模型开关" width="2000" height="930" data-path="images/workspace/anthropic-account-policy-workspace-models.jpg" />
</Frame>

1. 打开提供方设置。
2. 将 **Account policy** 设置为 **Enable selected**。
3. 在 **Workspace** 列表中，打开某个 Workspace 的 **Setting** 下拉菜单。
4. 为该 Workspace 启用或禁用各个模型。
5. 选择 **Update**。

在选择 **Update** 之前，你可以选择 **Copy to all**，将当前 Workspace 的模型选择
应用到该账户下的所有 Workspace。

<div id="limitaes">
  ## 限制
</div>

* 模型策略以 Workspace 为单位生效，无法针对同一 Workspace 内的某个用户组单独设置不同的策略。
* 智能模型路由不会覆盖账户或 Workspace 级别的策略，也无法选用已停用的提供方或模型。
* **Agent 模式与模型提供方**中的 **Fast mode 模型**开关，控制账户下所有 Workspace 能否使用快速模型变体。提供方策略和智能模型路由均不会改变该设置。
