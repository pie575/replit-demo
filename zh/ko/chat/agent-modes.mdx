<div id="section">
  ## 选择模式
</div>

* **Free Mode：** 探索想法、提出问题、开始构建，并持续推进日常任务。Free Mode 使用智能模型路由来选择模型。{FreeModePlanAvailability}
* **Power Mode：** 在速度与性能之间取得平衡，适合大多数任务。当你需要超出 Free Mode 额度的性能，或希望在现有项目中使用更强的默认配置时，可以选用。
* **Max Mode：** 最适合复杂且富有挑战的任务、大型代码库以及棘手的问题。

Power Mode 和 Max Mode 会消耗每月的额度。在请求从 Free Mode 切换到会产生费用的模式之前，Replit 会提前告知你。可在 **Settings** → **Usage** 中查看剩余的 Free Mode 额度。实用技巧请参阅[如何充分利用 Free Mode](/zh/ko/chat/free-mode)。

Routine 在 Power Mode 或 Max Mode 下运行，每次执行都需要预算，无法在 Free Mode 下运行。详情请参阅 [Routine](/zh/ko/chat/routines)。
