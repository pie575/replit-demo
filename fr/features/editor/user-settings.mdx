L&#39;outil Paramètres utilisateur du Project Editor permet de personnaliser l&#39;apparence, le comportement et
les raccourcis clavier de votre compte.

  <img src="/assets/mirror/user-settings-tool-faae3afb911b.png" alt="capture d'écran de l'outil Paramètres utilisateur" width="4152" height="1894" data-path="images/workspace/user-settings-tool.png" />
</Frame>

<div id="features">
  ## Fonctionnalités
</div>

Vous pouvez personnaliser votre expérience de création de Replit App grâce à ces catégories de paramètres :

* **Personnalisation du thème** : choisissez entre un thème clair et un thème sombre pour le Project Editor
* **Intelligence de code** : configurez les fonctionnalités basées sur l&#39;IA qui enrichissent votre expérience de création d&#39;app
* **Préférences de l&#39;éditeur** : ajustez le comportement et l&#39;apparence de l&#39;éditeur de fichiers
* **Contrôles des notifications** : gérez vos préférences d&#39;alertes
* **Options d&#39;accessibilité** : adaptez Replit aux utilisateurs ayant des besoins spécifiques
* **Raccourcis clavier** : définissez des combinaisons de touches pour exécuter les actions courantes et naviguer dans l&#39;interface graphique

<div id="usage">
  ## Utilisation
</div>

<Accordion title="Comment accéder aux Paramètres utilisateur">
  Depuis le **dock d&#39;outils** à gauche :

  1. Sélectionnez <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Icône Tous les outils" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **Tous les outils** pour afficher la liste des outils du Project Editor.
  2. Sélectionnez <img class="icon-svg" src="/assets/mirror/settings-icon-c2664c3691bf.svg" alt="Icône Paramètres" width="16" height="16" data-path="images/icons/settings-icon.svg" /> **Paramètres utilisateur**.

  Depuis la **barre de recherche** :

  1. Sélectionnez la <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="icône loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> loupe en haut de l&#39;écran pour ouvrir l&#39;outil de recherche
  2. Saisissez « Paramètres utilisateur » pour trouver l&#39;outil, puis sélectionnez-le dans les résultats.
</Accordion>

<div id="appearance">
  ### Apparence
</div>

Personnalisez les paramètres suivants liés à l&#39;apparence du Project Editor :

* **Sélection du thème** : choisissez parmi les thèmes prédéfinis clairs et sombres, les <a href="https://replit.com/themes" target="_blank">thèmes de la communauté</a> ou votre thème personnalisé
* **Thèmes personnalisés** : créez vos propres palettes de couleurs à l&#39;aide de l&#39;éditeur [Themes](/fr/features/editor/themes)

<div id="file-editor-preferences">
  ### Préférences de l&#39;éditeur de fichiers
</div>

Contrôlez l&#39;apparence et le comportement de l&#39;éditeur de fichiers à l&#39;aide des paramètres suivants :

* **Font size** : ajuste la taille du texte pour une meilleure lisibilité
* **Auto close brackets** : insère automatiquement la parenthèse fermante lorsque vous saisissez une parenthèse ouvrante
* **Indentation detection** : détecte automatiquement les paramètres d&#39;indentation à l&#39;ouverture d&#39;un fichier
* **Format pasted text indentation** : reformate le code collé pour respecter l&#39;indentation appropriée
* **Indentation character** : choisissez entre les espaces et les tabulations pour indenter le code
* **Indentation size** : définit le nombre de colonnes pour chaque niveau d&#39;indentation
* **Wrapping** : configure le comportement du retour à la ligne
* **Minimap** : affiche un aperçu navigable du code dans une barre latérale
* **Multiselect modifier key** : définit la touche de modification utilisée pour sélectionner plusieurs fichiers
* **Filetree Git status** : affiche les indicateurs d&#39;état Git dans l&#39;arborescence des fichiers

<div id="code-intelligence">
  ### Intelligence de code
</div>

Configurez les outils basés sur l&#39;IA à l&#39;aide des paramètres suivants :

* **Semantic tokens** : utilisez la coloration syntaxique enrichie assurée par les serveurs de langage
* **AI code completion** : affichez des suggestions de code en ligne au fil de la saisie
* **Accept suggestion on commit character** : acceptez automatiquement les suggestions de code en saisissant certains caractères

<div id="shell-and-preview-preferences">
  ### Préférences Shell et Preview
</div>

Personnalisez le comportement des outils Shell et Preview :

* **Indicateur sonore du Shell** : émet un son lorsque l&#39;outil Shell rencontre un problème
* **Preview automatique** : ouvre automatiquement l&#39;onglet Preview dès qu&#39;un serveur est disponible
* **Transférer automatiquement les ports ouverts** : définit la gestion des ports nouvellement détectés

<div id="notifications">
  ### Notifications
</div>

Gérez les paramètres de notification suivants :

* **Notification audio d&#39;Agent** : émet un son lorsqu&#39;Agent demande un retour
* **Notification push d&#39;Agent** : recevez des notifications push sur mobile lorsqu&#39;Agent demande un retour

<div id="production-alerts">
  #### Alertes de production
</div>

**Production Alerts** est un paramètre de notification par e-mail distinct qui vous tient informé de l&#39;état de vos applications publiées. Indépendant des e-mails produit et marketing, il vous permet de rester au courant de l&#39;essentiel sans bruit superflu.

Activez **Production Alerts** pour recevoir des e-mails concernant :

* **Les incidents de disponibilité** : soyez averti lorsqu&#39;une application publiée tombe en panne ou peine à rester en ligne.
* **Les vulnérabilités de sécurité** : soyez averti des failles détectées dans les logiciels dont dépend votre application, afin de les corriger avant qu&#39;elles ne posent problème.
* **Les mises à jour de modèles** : soyez averti lorsqu&#39;un modèle de langage utilisé par votre application change ou nécessite votre attention.

<Frame>
  <img src="/assets/mirror/production-alerts-highlight-bb76079f20fd.png" alt="La section Production Alerts dans les paramètres de notification, avec un rectangle rouge mettant en évidence le bouton d'activation des e-mails d'alerte de production et le menu déroulant de gravité des alertes de sécurité" width="2400" height="1364" data-path="images/workspace/production-alerts-highlight.png" />
</Frame>

Pour trouver ce paramètre :

1. Ouvrez **Settings** depuis le menu de votre compte.
2. Sélectionnez l&#39;onglet **Personalization**.
3. Faites défiler jusqu&#39;à la section **Email Notifications** pour trouver **Production Alerts**.

Lorsqu&#39;une application publiée utilise un modèle de langage obsolète, Replit prépare un brouillon de tâche pour vous faire passer à un modèle pris en charge. Vous recevez un e-mail contenant un lien vers cette tâche : une seule vérification suffit alors pour finaliser la mise à niveau.

<div id="accessibility">
  ### Accessibilité
</div>

Vous pouvez personnaliser le paramètre d&#39;accessibilité suivant :

* **Sortie de terminal accessible** : active la compatibilité avec les lecteurs d&#39;écran pour les outils Shell et Console

<div id="keyboard-shortcuts">
  ### Raccourcis clavier
</div>

Pour accéder aux préférences de raccourcis clavier, sélectionnez l&#39;onglet **Keyboard shortcuts** dans l&#39;outil Paramètres utilisateur.

Vous pouvez rechercher des combinaisons de touches de deux manières :

* **Nom** : saisissez le nom ou la description du raccourci clavier dans le champ de recherche
* **Combinaison de touches** : sélectionnez l&#39;icône <img class="icon-svg" src="/assets/mirror/keyboard-7ba19771b671.svg" alt="icône clavier" width="16" height="16" data-path="images/icons/keyboard.svg" /> puis saisissez la combinaison de touches

Utilisez les actions suivantes pour gérer vos raccourcis :

* **Ajouter** : sélectionnez **Add shortcut**
* **Modifier** : sélectionnez l&#39;icône crayon <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="icône crayon" width="16" height="16" data-path="images/icons/pencil-icon.svg" />
* **Supprimer** : sélectionnez l&#39;icône corbeille <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="icône corbeille" width="16" height="16" data-path="images/icons/trash-icon.svg" />
