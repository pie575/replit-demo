export const YouTubeEmbed = ({videoId, title = "YouTube video", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

### Applications mobiles sur Replit

### Interface des appels d'outils repensée dans le chat Agent

Le chat Agent dispose désormais d'une interface plus épurée et compacte pour les appels d'outils. Les appels d'outils se regroupent en lignes avec des icônes empilées, ce qui facilite la vue d'ensemble. Les modifications et créations de fichiers renvoient directement au panneau de diff pour une révision facile. Ce design simplifié vous aide à suivre les exécutions d'Agent avec moins de bruit et plus de clarté.

### Correctif de sécurité Node.js

Une faille de sécurité critique a été annoncée dans Node.js cette semaine. Tous les environnements de développement Agent et les applications Node.js de Replit ont été mis à jour pour utiliser des versions sécurisées. Vos applications seront également mises à jour vers la version sécurisée lors de leur prochaine republication.
