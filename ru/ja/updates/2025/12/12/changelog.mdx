<div id="agentmcp">
  ### Agent поддерживает пользовательские MCP-серверы
</div>

Теперь Agent может подключаться к удалённым серверам Model Context Protocol (MCP), открывая доступ к новым возможностям и инструментам с минимальной настройкой. Благодаря этому Agent может вызывать внешние инструменты и получать контекст из удалённых систем.

С пользовательскими MCP-серверами вы можете:

* Подключаться к удалённым серверам, которые получают контекст от внешних инструментов и выполняют действия
* Получать доступ к сотням инструментов и источников данных через открытый стандарт MCP
* Автоматически загружать инструменты, предоставляемые каждым сервером

Партнёры могут интегрировать свои сервисы с Agent, публикуя MCP-серверы. Дополнительная работа по интеграции не требуется.

<div id="enterpriseplaid">
  ### Коннектор Plaid для Enterprise
</div>

Теперь клиенты Enterprise могут включить коннектор Plaid, который позволяет подключаться к банковским счетам и создавать приложения на основе финтех-примитивов. Коннектор активно дорабатывается: новые возможности и улучшения добавляются с учётом отзывов клиентов.

Коннектор Plaid позволяет:

* подключать банковские счета к приложениям;
* использовать финтех-примитивы для создания финансовых функций;
* централизованно управлять коннекторами через панель мониторинга администратора.
