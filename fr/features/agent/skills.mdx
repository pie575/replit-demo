<div id="what-is-a-skill">
  ## Qu&#39;est-ce qu&#39;une compétence ?
</div>

Une compétence est un dossier. Il contient un fichier nommé `SKILL.md` avec les instructions que suit Agent, ainsi que tous les fichiers complémentaires auxquels vous souhaitez qu&#39;il se réfère. Les compétences se trouvent dans le répertoire `/.agents/skills` de votre projet et respectent la [spécification Compétences Agent](https://agentskills.io/specification) — un standard ouvert compatible avec l&#39;ensemble des agents.

Agent voit le nom et la description de chaque compétence installée, mais n&#39;en charge le contenu complet que lorsqu&#39;il est pertinent pour la tâche en cours. Les compétences sont donc économes en contexte : vous pouvez en installer un grand nombre sans dégrader la qualité des résultats d&#39;Agent.

<div id="pre-defined-skills">
  ## Compétences prédéfinies
</div>

Replit intègre des compétences prédéfinies, accessibles depuis le sélecteur **Use a skill** dans Chat et depuis le sélecteur de point de départ d&#39;un nouveau projet. Ces compétences fonctionnent dans tous les projets, sans installation. Pour consulter le catalogue complet, les compétences partenaires et la procédure d&#39;installation, consultez le [répertoire des compétences](/fr/features/agent/skills-directory).

Pour ajouter une compétence prédéfinie, ouvrez le sélecteur **Use a skill** depuis le champ de saisie de Chat et choisissez une compétence, ou demandez simplement à Agent de la charger.

<div id="skill-scope">
  ## Portée des compétences
</div>

Les compétences peuvent être définies à différents niveaux :

| Portée               | Disponibilité                                    | Emplacement                                                                                                            |
| -------------------- | ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------- |
| **Niveau projet**    | Spécifique à un seul projet                      | Versionnée avec vos fichiers dans `/.agents/skills`                                                                    |
| **Niveau workspace** | Accessible à tous les membres de votre workspace | Gérée de façon centralisée dans les paramètres du Workspace                                                            |
| **Enterprise**       | Standards à l&#39;échelle de l&#39;entreprise    | Incluse dans les [modèles personnalisés](/fr/teams/custom-templates) et les [design systems](/fr/teams/custom-design-system) |

Pour les compétences au niveau du workspace, consultez [Personnalisation d&#39;Agent](/fr/features/agent/agent-customization) afin de configurer les compétences du workspace et des instructions personnalisées pour votre équipe.

<div id="create-a-custom-skill">
  ## Créer une compétence personnalisée
</div>

Créez une compétence personnalisée lorsque vous souhaitez disposer d&#39;instructions réutilisables dans la bibliothèque de votre Workspace.
Dans un Workspace partagé, vous pouvez définir l&#39;accès des membres du Workspace au moment de la création de la compétence,
puis le modifier ultérieurement. Les personnes autorisées à gérer les compétences dépendent de votre forfait — voir
[Personnalisation d&#39;Agent](/fr/features/agent/agent-customization).

Les politiques d&#39;accès des membres du Workspace sont les suivantes :

| Politique       | Accès                                                                                        |
| --------------- | -------------------------------------------------------------------------------------------- |
| **Obligatoire** | Toujours activée et impossible à désactiver                                                  |
| **Disponible**  | Facultative et désactivée par défaut ; les membres doivent l&#39;activer pour l&#39;utiliser |
| **Aucun accès** | Masquée pour les membres                                                                     |

<Steps>
  <Step title="Ouvrir les paramètres des compétences">
    Ouvrez **Settings** &gt; **Customization** &gt; **Skills** dans le Workspace.
  </Step>

  <Step title="Démarrer une compétence personnalisée">
    Sélectionnez **Add**, puis **Write a skill**.
  </Step>

  <Step title="Décrire la compétence">
    Une compétence personnalisée comprend :

    * **Name** : identifie la compétence dans la bibliothèque du Workspace.
    * **Description** : explique quand Agent doit utiliser la compétence.
    * **Instructions** : définit les étapes qu&#39;Agent doit suivre.

    <Frame caption="Saisissez les détails d'une compétence personnalisée dans un Workspace d'équipe.">
      <img src="/assets/mirror/workspace-custom-skill-create-6d6014e5c561.jpg" alt="Formulaire de compétence personnalisée d'un Workspace d'équipe avec le nom, la description, les instructions et le bouton Create skill" width="2000" height="1363" data-path="images/replitai/workspace-custom-skill-create.jpg" />
    </Frame>
  </Step>

  <Step title="Définir l'accès des membres du Workspace">
    Une nouvelle compétence est créée en mode **Private** : vous seul et les administrateurs du Workspace pouvez donc l&#39;utiliser.
    Sélectionnez le contrôle **Sharing**, puis choisissez l&#39;une des politiques ci-dessus pour **Members
    in workspace**.

    <Frame caption="Définissez l'accès des membres du Workspace avant de créer la compétence.">
      <img src="/assets/mirror/workspace-custom-skill-create-sharing-00a493b8ba70.jpg" alt="Formulaire de compétence personnalisée avec le contrôle Sharing ouvert et les options Required, Available et No access visibles" width="2000" height="1154" data-path="images/replitai/workspace-custom-skill-create-sharing.jpg" />
    </Frame>
  </Step>

  <Step title="Créer la compétence">
    Vérifiez les détails, puis sélectionnez **Create skill**.
  </Step>
</Steps>

<div id="share-project-skills">
  ## Partager les compétences d&#39;un projet
</div>

Dans un Workspace partagé, vous pouvez modifier l&#39;accès des membres une fois la compétence créée.

<Steps>
  <Step title="Créer ou sélectionner une compétence">
    Créez une compétence personnalisée en suivant les étapes ci-dessus, ou sélectionnez une compétence existante dans
    **Settings** &gt; **Customization** &gt; **Skills**.

    Pour enregistrer une compétence de projet dans votre Workspace, ouvrez **Compétences Agent** &gt; **Project skills** dans votre projet. Sélectionnez **Save to workspace**, saisissez un nom, puis sélectionnez **Save**.
  </Step>

  <Step title="Ouvrir le partage">
    Sur la carte de la compétence dans la bibliothèque du Workspace, ouvrez le menu d&#39;options, puis sélectionnez **Share...**.

    <Frame caption="Ouvrez le menu d'une compétence existante pour la partager après sa création.">
      <img src="/assets/mirror/workspace-skill-share-menu-af1b84e16a3c.jpg" alt="Page des compétences du Workspace avec le menu d'options d'une compétence existante ouvert et l'action Share visible" width="1600" height="1100" data-path="images/replitai/workspace-skill-share-menu.jpg" />
    </Frame>
  </Step>

  <Step title="Définir l'accès des membres du Workspace">
    Dans la boîte de dialogue **Share skill**, sélectionnez l&#39;une des politiques ci-dessus pour **Members in
    workspace**. Votre choix prend effet immédiatement ; aucune action de
    confirmation distincte n&#39;est nécessaire.

    <Frame caption="Choisissez comment les membres du Workspace peuvent accéder à la compétence.">
      <img src="/assets/mirror/workspace-skill-sharing-policy-24fbbc668714.jpg" alt="Boîte de dialogue Share skill affichant les politiques Required, Available et No access pour les membres du Workspace" width="1500" height="1000" data-path="images/replitai/workspace-skill-sharing-policy.jpg" />
    </Frame>
  </Step>
</Steps>

<div id="import-skills-from-github">
  ## Importer des compétences depuis GitHub
</div>

Ajoutez des compétences à partir de l&#39;URL d&#39;un dépôt, d&#39;un dossier ou d&#39;un fichier GitHub public.

<Steps>
  <Step title="Ouvrir Workspace Skills">
    Dans Agent, sélectionnez **+** &gt; **Use a skill** pour ouvrir **Workspace Skills**.

    <Frame caption="Ouvrez le menu plus et sélectionnez Use a skill pour accéder à Workspace Skills.">
      <img src="/assets/mirror/workspace-skill-picker-d7c3f5525de2.jpg" alt="Menu plus d'Agent avec Use a skill sélectionné et le sélecteur Workspace Skills listant ask-matt, claude-handoff et code-review" width="2000" height="1085" data-path="images/replitai/workspace-skill-picker.jpg" />
    </Frame>
  </Step>

  <Step title="Prévisualiser les compétences">
    Collez l&#39;URL d&#39;un dépôt, d&#39;un dossier ou d&#39;un fichier GitHub public, puis sélectionnez **Preview
    skills**. La prévisualisation vérifie uniquement la structure des fichiers : elle ne charge ni les instructions
    ni les descriptions des compétences.

    <Frame caption="Saisissez une URL GitHub publique et prévisualisez la structure de ses fichiers de compétences.">
      <img src="/assets/mirror/workspace-skill-github-preview-c8476d8d1556.jpg" alt="Page Add from GitHub avec l'URL d'un dépôt GitHub public et le bouton Preview skills" width="2000" height="1154" data-path="images/replitai/workspace-skill-github-preview.jpg" />
    </Frame>
  </Step>

  <Step title="Sélectionner et importer les compétences">
    Passez en revue les compétences détectées, sélectionnez celles à importer, puis sélectionnez **Import**. Le bouton affiche le nombre de compétences sélectionnées, par exemple **Import 36 skills**.

    <Frame caption="Passez en revue les compétences détectées et sélectionnez celles à importer.">
      <img src="/assets/mirror/workspace-skill-github-select-68589ea766c3.jpg" alt="Prévisualisation des compétences GitHub affichant les compétences détectées avec les commandes de sélection et le bouton Import 36 skills" width="2000" height="1154" data-path="images/replitai/workspace-skill-github-select.jpg" />
    </Frame>
  </Step>
</Steps>

L&#39;exemple ci-dessus utilise le dépôt public
[mattpocock/skills](https://github.com/mattpocock/skills).

<Note>
  Chaque import est limité à 50 compétences, 3 500 fichiers ou 200 Mio. Les dépôts privés ne sont pas pris en charge.
</Note>

Les dépôts importés apparaissent sous le filtre **GitHub** de l&#39;onglet **Skills**.

<div id="how-agent-loads-skills">
  ## Comment Agent charge les compétences
</div>

Agent lit les métadonnées (nom et description) de chaque compétence installée à chaque conversation. Le corps complet d&#39;une compétence n&#39;est chargé que lorsqu&#39;Agent estime qu&#39;elle est pertinente pour la tâche en cours. Le contenu des compétences reste ainsi en dehors de la fenêtre de contexte tant qu&#39;il n&#39;est pas nécessaire.

Les compétences installées persistent dans votre projet d&#39;une session Agent à l&#39;autre et peuvent être validées dans le contrôle de version pour être partagées avec votre équipe.

<div id="working-with-other-ai-coding-tools">
  ## Utiliser d&#39;autres outils de développement IA
</div>

<Accordion title="Importer des compétences depuis d'autres outils de développement IA">
  Si vous travaillez avec plusieurs outils de développement IA, [rulesync](https://github.com/dyoshikawa/rulesync) prend en charge Replit et vous aide à conserver des configurations cohérentes.

  Vous pouvez importer des compétences depuis d&#39;autres assistants de développement IA :

  ```bash theme={null}
  npx rulesync init
  npx rulesync import --targets claudecode --features skills
  npx rulesync generate --targets replit --features skills
  ```

  Vous pouvez ainsi conserver un seul jeu de compétences, utilisable dans différents environnements de développement.
</Accordion>
