通过 ChatGPT 的 Replit 集成，你可以直接在对话中创建、修改和检查 Replit Apps，无需额外设置。只需与 ChatGPT 对话来构建真实应用，其余工作由 Agent 完成。

<div id="chatgpt-replit">
  ## 什么是 ChatGPT 中的 Replit
</div>

ChatGPT 中的 Replit 可将 ChatGPT 对话连接到 Replit 强大的开发平台。只需描述您想创建的内容，Agent 就会为您生成一个功能完整的 Replit App。应用创建完成后，您可以让 ChatGPT 修改、更新或分析它。整个过程均可通过自然语言对话完成。

<div id="section">
  ## 开始使用
</div>

按照以下步骤将 Replit 连接到 ChatGPT，并创建你的第一个应用。

<div id="replit-chatgpt">
  ### 将 Replit 连接到 ChatGPT
</div>

将 Replit 连接到 ChatGPT 有两种方法：

<Accordion title="通过设置连接">
  1. 在 ChatGPT 中点击个人资料图标
  2. 前往 **设置** → **应用和连接器**
  3. 找到 **Replit**，然后点击 **连接**
  4. 使用你的 Replit 账户完成 OAuth 授权
</Accordion>

<Accordion title="通过对话连接">
  1. 在 ChatGPT 中发起新对话
  2. 通过以下任一方式调用 Replit
  3. 如果尚未连接，ChatGPT 会引导你完成 OAuth 流程
</Accordion>

<div id="chatgpt-replit-2">
  ### 在 ChatGPT 中调用 Replit
</div>

连接后，您可以通过以下三种方式调用 Replit：

| 方法   | 使用方法                              |
| ---- | --------------------------------- |
| 直接提及 | 在消息开头输入 `Replit, <请求内容>`          |
| 斜杠命令 | 在输入框中输入 `/Replit`                 |
| 编辑菜单 | 点击 **+** 按钮 → **更多** → **Replit** |

<div id="section-2">
  ### 创建第一个 App
</div>

完成连接后，创建你的第一个 Replit App：

1. 在 ChatGPT 中发起新对话
2. 调用 Replit，并说明你想创建什么 (例如：“Replit, create a todo app with dark mode”)
3. Agent 会创建 App 并自动部署
4. 完成后，你会收到可查看 App 的链接

<Note>
  每个对话只能处理一个 Replit App。在同一对话中创建新的 App 会修改现有 App。若要创建多个 App，请分别发起新的对话。
</Note>

<div id="section-3">
  ## 功能
</div>

* **[Replit AI](/zh/ko/build/welcome)**：Agent 可根据自然语言请求创建并部署应用
* **[Project Editor](/zh/ko/learn/projects-and-artifacts/project-editor)**：可通过 ChatGPT 使用的全功能开发环境
* **[Publishing](/zh/ko/learn/projects-and-artifacts/replit-deployments)**：应用会自动部署，可立即分享

<Accordion title="您可以做什么">
  **创建：**描述您的需求，即可创建新的 Replit Apps。Agent 会创建并自动部署应用。

  **更新：**修改当前对话中的应用。让 ChatGPT 添加功能、修复错误或应用更改，Agent 将执行这些操作。

  **检查：**无需进行任何更改即可分析应用。您可以获取代码结构、文件路径和运行行为等信息。
</Accordion>

<Accordion title="支持的文件格式">
  您可以在提示词中包含多种文件格式：

  | 格式         | 是否支持           |
  | ---------- | -------------- |
  | PDF        | 是              |
  | CSV        | 是              |
  | 常见文档格式     | 是              |
  | 图片 (原始文件)  | 否 (请改用公开 URL)  |
  | 视频 (原始文件)  | 否 (请改用公开 URL)  |

  <Note>
    若要在应用中包含图片或视频，请在提示词中提供公开 URL。应用创建后，您也可以直接在 Replit 中添加媒体文件。
  </Note>
</Accordion>

<Accordion title="构建时间">
  Agent 构建应用的典型耗时：

  | 应用复杂度                  | 典型构建时间 |
  | ---------------------- | ------ |
  | 简单 (计算器、小型落地页)         | 2–3 分钟 |
  | 复杂 (游戏、丰富动画、信息密集的仪表板)  | 3–4 分钟 |
</Accordion>

<div id="section-4">
  ## 可用范围和套餐
</div>

<Accordion title="ChatGPT 套餐">
  Replit 集成适用于所有类型的 ChatGPT 套餐：

  | 套餐             | 支持 | 备注                                       |
  | -------------- | -- | ---------------------------------------- |
  | Free           | 是  |                                          |
  | Plus           | 是  |                                          |
  | Pro            | 是  |                                          |
  | Business       | 是  | 需要管理员在 **Workspace 设置 → 连接器** 中启用 |
  | Enterprise/Edu | 是  | 需要管理员在 **Workspace 设置 → 连接器** 中启用 |

  **可用地区：**除 EU 外的所有地区。
</Accordion>

<Accordion title="Replit 套餐">
  所有 Replit 套餐均支持 ChatGPT 集成：

  | 套餐             | 支持 | 备注                            |
  | -------------- | -- | ----------------------------- |
  | Starter (Free) | 是  | 仅支持公开应用                       |
  | Core           | 是  | 私密应用、扩展构建、Publishing、Database |
  | Pro            | 是  | 更高的每月积分上限，包含所有 Core 功能        |
  | Enterprise     | 是  | 可使用全部功能                       |
</Accordion>

<div id="section-5">
  ## 计费与积分
</div>

在 ChatGPT 中由 Replit 完成的工作会计入你的 Replit 账户的 Replit Agent 使用量。

<Accordion title="计费方式">
  * **Core** 和 **Pro** 套餐包含每月积分，可在额度内使用 Agent、Publishing 和数据库
  * 你可以购买 **credit pack**；它们将在 6 个月后到期，且不会自动续订，适合应对上线时的流量激增或进行试验
  * 使用 Replit 账单设置中的 **使用限额** 和 **预算** 限制支出

  详情请参阅 [AI 计费文档](/zh/ko/billing/ai-billing)。
</Accordion>

<div id="section-6">
  ## 当前限制
</div>

ChatGPT 中的 Replit 应用目前：

* 只能处理在该会话中创建的应用
* 无法打开或修改以下应用：
  * 在其他 ChatGPT 会话中创建的应用
  * 直接在 Replit 中创建的应用

数据库、密钥管理和更高级的 Project Editor 控件等与完整 Replit 体验相当的功能将陆续推出。

<div id="section-7">
  ## 故障排查
</div>

<Accordion title="“浏览应用”中未显示 Replit">
  如果在 **浏览应用** 中看不到 Replit，请检查：

  * 您所在地区是否提供该应用
  * 工作区管理员是否已启用 Replit 应用 (Business/Enterprise/Edu)
</Accordion>

<Accordion title="构建失败">
  如果构建失败，请在 Replit 中打开该应用：

  * 查看使用量和账单记录
  * 使用检查点和回滚功能恢复到之前的版本
  * 在 Project Editor 中直接向 Agent 寻求帮助
</Accordion>
