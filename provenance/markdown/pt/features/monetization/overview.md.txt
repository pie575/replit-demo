# Monetização

> Adicione pagamentos e assinaturas aos seus apps Replit com integrações baseadas no Agent.

Transforme seu app em um negócio. O Replit se integra a provedores de pagamento para que você possa aceitar pagamentos, vender assinaturas e monetizar seus apps web e mobile.

## Como funciona

Diga ao Agent pelo que você quer cobrar, e ele cuida do resto: conectar-se a um provedor de pagamento, construir a interface de checkout ou paywall e configurar a lógica de pagamento. Você pode testar tudo com segurança antes de entrar em produção.

O Replit oferece suporte a várias integrações de monetização em apps web e apps mobile nativos:

* **[Pagamentos com Whop](/pt/features/monetization/whop-payments)** (apps web): venda produtos digitais, memberships e assinaturas com o menor número de etapas. O Agent cria uma conta Whop para você — sem configuração externa e sem chaves de API — para que você chegue à sua primeira venda rapidamente.
* **[Pagamentos com Stripe](/pt/features/monetization/stripe-payments)** (apps web): aceite pagamentos únicos, venda assinaturas ou construa uma loja completa. O Agent conecta um sandbox do Stripe para que você possa testar os fluxos de checkout antes de entrar em produção.
* **[Assinaturas com RevenueCat](/pt/features/monetization/revenuecat-subscriptions)** (apps mobile): adicione assinaturas no app ao seu app mobile nativo. O Agent configura o RevenueCat, constrói uma tela de paywall e configura o modo de teste para que as compras sejam simuladas durante o desenvolvimento.

Se você quiser vender produtos físicos com controle de estoque e logística de entrega, veja a [integração com Shopify](/pt/features/integrations/shopify).

## Escolha a integração certa

|                          | Whop                                         | Stripe                                          | Shopify                                             | RevenueCat                                         |
| ------------------------ | :------------------------------------------- | :---------------------------------------------- | :-------------------------------------------------- | :------------------------------------------------- |
| **Melhor para**          | Menos etapas, venda mais rápida              | Flexibilidade e escala na web                   | Produtos físicos                                    | Apps mobile nativos                                |
| **Tipos de pagamento**   | Produtos digitais, memberships, assinaturas  | Pagamentos únicos, assinaturas, lojas completas | Produtos físicos com estoque e logística de entrega | Assinaturas no app                                 |
| **Configuração externa** | Nenhuma para começar                         | Nenhuma para começar (sandbox do Stripe)        | Nenhuma para começar                                | Nenhuma para começar (modo de teste)               |
| **Entrar em produção**   | Verificar identidade (KYC) para sacar fundos | Conectar uma conta Stripe ao vivo               | Reivindicar sua loja Shopify                        | Enviar para revisão na App Store ou no Google Play |
| **Conta necessária**     | Conta Whop (criada para você)                | Conta Stripe                                    | Loja Shopify (provisionada para você)               | Conta RevenueCat                                   |

## Como começar

A forma mais rápida de começar é pedir ao Agent:

* **Vender produtos digitais rapidamente**: "Adicione pagamentos do Whop para que eu possa vender uma assinatura" — veja [Pagamentos com Whop](/pt/features/monetization/whop-payments)
* **App web**: "Adicione pagamentos do Stripe ao meu app" — veja [Pagamentos com Stripe](/pt/features/monetization/stripe-payments)
* **App mobile**: "Adicione uma assinatura de \$5,99/mês ao meu app" — veja [Assinaturas com RevenueCat](/pt/features/monetization/revenuecat-subscriptions)

O Agent conecta a integração, constrói a interface e configura um ambiente de teste para que você possa experimentá-la imediatamente.
