<div id="agent-geral">
  ### Agent général
</div>

<Frame>
  <img src="/assets/mirror/general-agent-240ff289e711.png" alt="Illustration de présentation de l'Agent général" width="1040" height="572" data-path="images/replitai/general-agent.png" />
</Frame>

Replit Agent fonctionne désormais sur n&#39;importe quelle base de code, dans n&#39;importe quel langage ou framework s&#39;exécutant sur NixOS ! Auparavant limité à certains modèles, Agent peut maintenant vous aider avec les frameworks de développeur, les importations depuis GitHub et toute configuration de projet personnalisée. Cette avancée majeure met une assistance de codage par IA complète au service des flux de travail des entreprises et des utilisateurs avancés.

En savoir plus sur l&#39;Agent général [ici](/fr/pt/core-concepts/agent/general-agent).

<div id="modo-de-plano">
  ### Mode Plan
</div>

<Frame>
  <img src="/assets/mirror/plan-mode-overview-8077807c63b9.png" alt="Interface de chat d'Agent en mode Plan" width="916" height="362" data-path="images/replitai/plan-mode-overview.png" />
</Frame>

Le mode Plan inaugure une nouvelle façon d&#39;échanger avec Replit Agent, centrée sur les questions, le brainstorming et la planification de votre travail. Avec le mode Plan, vous pouvez demander à Agent de créer une liste de tâches pour les travaux à venir, puis lancer des tâches de longue durée en mode création.

Pour en savoir plus sur le mode Plan, cliquez [ici](/fr/pt/core-concepts/agent/plan-mode).

<div id="enterprise">
  ## Enterprise
</div>

<div id="integrao-com-o-gcp-marketplace">
  ### Intégration à GCP Marketplace
</div>

Les clients Enterprise peuvent désormais acheter Replit directement sur Google Cloud Platform Marketplace et régler leurs achats avec leurs crédits GCP existants. Cela simplifie les processus d&#39;achat et permet aux organisations disposant d&#39;un budget GCP d&#39;intégrer plus facilement Replit à leurs flux de travail de développement.
