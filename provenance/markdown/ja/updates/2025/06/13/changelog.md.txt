export const YouTubeEmbed = ({videoId, title = "YouTube video", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

### Workspaceの品質向上

チームは作成体験をよりスムーズで直感的にするための多数の改善を展開しました。より信頼性の高いプレビューペインからより一貫したモバイルの動作まで、これらの改良によりアイデアを実現するためのより洗練された環境が生まれます。

### インフラの改善

チームはより速く安定したプラットフォームを提供するためにインフラの近代化に取り組んでいます。これらの技術的な改善により、将来のより強力な機能とより良い開発者体験への道が開かれます。

## チームとエンタープライズ

### 組織のアプリ共有の改善

チームでよりすっきりと整理されたWorkspaceをお楽しみください！組織内で作成された新しいアプリは、すべてのメンバーと自動的に共有されなくなりました。これによりチームメンバーのWorkspaceに表示されるものの混乱が減り、より細かいコントロールが可能になります。

### チームメンバーページの改善

Teams Membersページの新しいユーザビリティ改善でチームの管理が簡単になりました。メンバー、閲覧者、招待タブで並び替え、フィルタリング、検索が可能になりました。これはエンタープライズのお客様が大規模なチームを効率的に管理するために要望していた機能です。
