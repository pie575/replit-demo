      <Accordion title="Où puis-je obtenir de l’aide sur le code ?">
        Pour obtenir de l’aide sur le code, le mieux est d’utiliser [Replit AI](/fr/ja/build/welcome/). Ouvrez un nouvel onglet dans l’éditeur de projet et recherchez **AI**. Replit AI peut configurer de nouveaux projets, répondre à vos questions sur le code et vous aider à développer vos idées. Si vous avez besoin d’une aide supplémentaire, consultez également les ressources disponibles dans le [hub communautaire](https://replit.com/community).
      </Accordion>

      <Accordion title="J’ai des difficultés à utiliser Replit. Comment puis-je obtenir de l’aide ?">
        Connectez-vous à Replit et cliquez sur **?** en haut à droite de la page pour obtenir de l’aide. Pour en savoir plus sur l’assistance, consultez le [document sur la politique d’assistance](/fr/ja/legal-and-security-info/support-policy).
      </Accordion>

      <Accordion title="Où puis-je obtenir de l’aide concernant la facturation ?">
        Avant de contacter l’équipe d’assistance, vérifiez si vous pouvez trouver une solution dans **Paramètres**. Si le problème persiste, connectez-vous et utilisez **?** en haut à droite de la page pour obtenir de l’aide.
      </Accordion>

      <Accordion title="Que faire si je ne peux pas accéder à mon compte Replit ?">
        Envoyez un e-mail à `support@replit.com` en précisant le nom d’utilisateur et l’identifiant de connexion de votre compte.
      </Accordion>

      <Accordion title="Quand recevrai-je une réponse de Replit ?">
        L’assistance Replit est généralement disponible du lundi au vendredi, de 9 h à 20 h (heure normale de l’Est, UTC-5).
      </Accordion>

      <Accordion title="Comment restaurer un dossier dans une application Replit ?">
        Accédez à l’icône de profil située dans l’angle supérieur droit de votre application Replit, puis sélectionnez **CLUI**. Dans le champ de recherche qui s’affiche, saisissez « *restore* ». Les résultats incluent l’option **restore-folder**, qui permet de restaurer un dossier précis depuis la corbeille.

        > Attention : les applications Replit supprimées sont définitivement effacées **30 jours** après leur suppression initiale et ne peuvent plus être restaurées.
      </Accordion>

      <Accordion title="Comment restaurer une application Replit supprimée ?">
        Accédez à l’icône de profil en haut à droite de l’application Replit, puis sélectionnez **CLUI**. Dans le champ de recherche qui s’affiche, saisissez « *restore* ». Les résultats incluront l’option **restore-repl**, qui permet de restaurer une application Replit spécifique depuis la corbeille.

        > Remarque : les applications Replit supprimées sont définitivement effacées **30 jours** après leur date de suppression initiale et ne peuvent plus être restaurées.
      </Accordion>

      <Accordion title="Que faire si l’application Replit ne se charge pas ?">
        Si votre application Replit ne se charge pas, essayez les étapes de dépannage suivantes :

        1. Testez votre [connexion Internet](https://www.speedtest.net/).
        2. Essayez un autre navigateur.
        3. Vérifiez que JavaScript est activé dans votre navigateur.
        4. Ouvrez la palette de commandes avec `Cmd+K` sur Mac ou `Ctrl+K` sur Windows, puis recherchez et sélectionnez **Restart compute**.

        Si les étapes ci-dessus ne résolvent pas le problème, consultez le [statut des services](https://status.replit.com) de Replit. Si le statut indique **All systems are go!** mais que vous rencontrez toujours des problèmes de chargement de votre application Replit, contactez l’[assistance Replit](https://replit.com/support).
      </Accordion>

      <Accordion title="Comment téléverser des fichiers volumineux dans une application Replit ?">
        Si un fichier est trop volumineux pour être téléversé via l’interface graphique habituelle, vous pouvez utiliser `scp` (Secure Copy) pour le transférer de manière sécurisée entre votre système local et un système distant via [SSH](/fr/ja/features/workspace-tools/ssh). Pour copier un fichier de votre machine locale vers une machine distante, utilisez la syntaxe suivante : `scp filename username@ip_address:/home/username`

        Vous pouvez également utiliser `scp` pour copier un répertoire entier.
      </Accordion>

      <Accordion title="Comment consulter le solde de mes crédits d’utilisation ?">
        Vous pouvez consulter votre solde actuel à l’adresse [https://replit.com/~/cli/account/usage-credits-balance](https://replit.com/~/cli/account/usage-credits-balance).
      </Accordion>

      <Accordion title="J’ai des problèmes pour me connecter. Que dois-je faire ?">
        1. Vérifiez que vous utilisez la bonne adresse e-mail et le bon mot de passe.
        2. Pour réinitialiser votre mot de passe, accédez à la [page Mot de passe oublié](https://replit.com/forgot). Vérifiez que l’e-mail de réinitialisation envoyé par `notifications@replit.com` n’est pas arrivé dans votre dossier de spam.
        3. Essayez de vous connecter depuis un autre navigateur.

        Si aucune des étapes ci-dessus ne résout le problème, [contactez l’assistance](https://replit.com/support).
      </Accordion>

      <Accordion title="Comment modifier mon adresse e-mail si je me suis inscrit avec Google/GitHub/Facebook/Apple ?">
        Un mot de passe est nécessaire pour modifier l’adresse e-mail de votre compte. Si vous vous êtes inscrit auprès d’un fournisseur d’authentification tiers tel que Google ou GitHub, vous devez d’abord créer un mot de passe.

        Pour créer un mot de passe :

        1. Ouvrez la barre latérale et déconnectez-vous.
        2. Retournez à la page de connexion, sélectionnez [Mot de passe oublié](https://replit.com/forgot), puis saisissez votre adresse e-mail.
        3. Vous recevrez un e-mail contenant un lien pour créer un nouveau mot de passe. Si vous ne le trouvez pas, vérifiez votre dossier de spam et attendez jusqu’à 30 minutes.
        4. Une fois connecté, ouvrez les [paramètres](https://replit.com/settings) et modifiez votre adresse e-mail.
      </Accordion>

      <Accordion title="Comment modifier mon nom d’utilisateur ?">
        Les utilisateurs de Replit ne peuvent modifier leur nom d’utilisateur qu’**une seule fois**. Accédez à [CLUI](https://replit.com/~/cli/account/change-username?run=1) et sélectionnez **change-username**. Si cette option n’est pas disponible, vous avez déjà effectué cette modification.
      </Accordion>

      <Accordion title="Qu’est-ce que le mode Explorer et comment l’activer ?">
        Les Explorers sont des utilisateurs de Replit qui ont choisi d’afficher et de tester de nouvelles fonctionnalités encore en cours de développement. Pour activer le mode Explorer, ouvrez les [paramètres](https://replit.com/settings) et activez le commutateur Explorer (par exemple, sous **compte** ou **utilisateur**).
      </Accordion>
    </AccordionGroup>
