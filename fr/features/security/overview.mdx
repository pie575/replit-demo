Lorsque vous publiez depuis Replit, votre projet peut recevoir du trafic réel. Les outils de sécurité de Replit vous aident à repérer les vulnérabilités, à corriger avec Agent les problèmes que vous avez validés et à conserver des preuves en vue des audits.

<div id="why-security-matters">
  ## Pourquoi la sécurité est importante
</div>

* Les projets publiés sont accessibles depuis Internet, y compris leurs routes et API publiques.
* Les projets modernes reposent sur de nombreux paquets, et de nouvelles CVE peuvent apparaître après la publication.
* Le code généré par l&#39;IA nécessite malgré tout une revue de sécurité, en particulier autour de l&#39;authentification, des requêtes de base de données, des Secrets et du traitement des données.
* Les programmes de conformité exigent souvent des preuves d&#39;inventaire des dépendances, de suivi des vulnérabilités et de remédiation.

<div id="where-to-start">
  ## Par où commencer
</div>

* Vous installez des paquets ? Le [pare-feu de paquets](/fr/features/security/package-firewall) bloque les dépendances malveillantes dès l&#39;installation ; il est activé par défaut.
* Vous travaillez sur un seul project ? Utilisez le [centre de sécurité du project](/fr/features/security/project-security-center).
* Vous réalisez un audit sur l&#39;ensemble de votre workspace ? Utilisez le [centre de sécurité du workspace](/fr/features/security/workspace-security-center).
* Vous choisissez le lieu d&#39;exécution de vos ressources de développement ? Consultez [Géographie du workspace](/fr/features/collaboration/workspace-geography). Pour choisir où s&#39;exécute un Project publié, consultez [Géographie du Project](/fr/features/publishing/project-geography).
* Besoin d&#39;une définition ? Consultez [Concepts de sécurité](/fr/features/security/concepts).

Les outils de sécurité de Replit protègent différentes étapes du cycle de vie de votre app et fonctionnent de concert :

* **À l&#39;installation** : le [pare-feu de paquets](/fr/features/security/package-firewall) bloque les paquets malveillants et compromis avant leur téléchargement.
* **Après l&#39;installation** : les [analyses automatiques des dépendances](/fr/features/security/project-security-center#automatic-dependency-scans) détectent les CVE récemment divulguées, et Auto-Protect peut préparer des correctifs Agent correspondants.
* **Avant la publication** : le [Security Agent](/fr/features/security/agent-security-scans) audite votre base de code afin d&#39;y repérer les vulnérabilités de code, de dépendances et de confidentialité.

La plupart des analyses suivent la même boucle : analyser, examiner les constats, corriger avec Agent, republier et exporter les preuves si nécessaire.

<div id="where-security-lives-in-the-product">
  ## Où se situe la sécurité dans le produit
</div>

<div id="in-a-project">
  ### Dans un project
</div>

Dans le volet **Tools** de votre project, sélectionnez **Security Center** pour examiner les constats au niveau du project, lancer des analyses de sécurité Agent et inspecter les vulnérabilités des dépendances avant la publication.

Utilisez une [analyse de sécurité Agent](/fr/features/security/agent-security-scans) pour examiner le code source. Optez pour un [test d&#39;intrusion en boîte noire de Level 3](/fr/features/security/black-box-pen-tests) si vous devez également tester l&#39;application en cours d&#39;exécution depuis l&#39;extérieur.

<div id="in-your-workspace">
  ### Dans votre workspace
</div>

Sélectionnez **Security** dans la barre latérale de l&#39;accueil pour examiner les vulnérabilités de l&#39;ensemble de vos projects, hiérarchiser les constats selon leur niveau d&#39;exposition et suivre l&#39;historique des analyses au niveau du workspace.

</Frame>

<div id="in-publishing-and-settings">
  ### Dans la publication et les paramètres
</div>

* Dans **Publier** &gt; **Avancé**, utilisez **Bloquer la publication des vulnérabilités critiques** pour empêcher la mise en ligne des constats critiques.
* Dans **Paramètres** &gt; **Compte** &gt; **Avancé**, définissez le seuil de gravité d&#39;Auto-Protect pour les correctifs de dépendances préparés par Agent.
