<div id="section-3">
  ### Обновление сканера безопасности
</div>

Благодаря крупному обновлению сканера безопасности проверки стали быстрее и эффективнее. Результаты сканирования кешируются, а повторный запуск выполняется только при изменении кода, поэтому последующие проверки проходят очень быстро. Новая функция игнорирования позволяет скрывать нежелательные предупреждения безопасности, сохраняя возможность вернуться к ним при необходимости.

<div id="agent">
  ### Оптимизация системного промпта Agent
</div>

Благодаря последним улучшениям системы взаимодействие с Agent стало быстрее и эффективнее. Теперь Agent выполняет задачи на 2–3 секунды быстрее при каждом действии, сохраняя прежнее высокое качество результатов.
