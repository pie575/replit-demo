使用 Free Mode，您无需消耗 Power Mode 或 Max Mode 积分即可聊天、创建和构建。

<Note>
  Free Mode 始终采用智能模型路由，由 Replit 选择最适合您请求的模型。
  您无法在 Free Mode 中选择特定模型。
</Note>

Routine 无法在 Free Mode 中运行，只能在 Power Mode 或 Max Mode 中运行，且每次运行都需要预算。有关详细信息，请参阅 [Routine](/zh/ko/chat/routines)。

<div id="section">
  ## 更充分地利用额度
</div>

Free Mode 非常适合让当前工作保持进展。您可以在以下情况下使用它：

* 在着手更大型的构建之前，探索并验证想法。
* 开始新项目、首次尝试某项功能，或进行小幅调整。
* 提出问题、制定计划，并通过后续消息完善工作。
* 在额度尚有剩余时，无需使用积分即可继续处理日常任务。

要开始使用，请打开提示词输入框下方的模式选择器，并确认模式设置为 **Free**。然后向 Replit 提出目标明确的请求。说明您希望达成的结果，分享重要上下文，并通过后续问题完善结果。

<div id="section-2">
  ## 了解何时使用其他模式
</div>

Free Mode 的额度因套餐而异。打开 **设置** → **用量**，查看当前额度和续期时间。

<Frame caption="用量页面会显示剩余的 Free 额度和续期时间。">
  <img src="/assets/mirror/free-mode-usage-sanitized-1b738ae092bb.jpg" alt="设置中的用量页面，显示 Free 额度面板" width="1538" height="1022" data-path="images/chat/free-mode-usage-sanitized.jpg" />
</Frame>

使用 Core 和 Pro 套餐时，如果需要更高性能、想选择特定模型，或已达到 Free Mode 额度，请切换到 **Power Mode** 或 **Max Mode**。这些模式会消耗每月积分。Starter 用户必须先升级，才能使用 Power Mode 或 Max Mode。

<Tip>
  如果你的套餐包含 Power Mode 和 Max Mode，请先使用 Free Mode，
  仅当任务需要更高性能时再切换。在请求切换到会产生使用费用的
  模式前，Replit 会通知你。
</Tip>

<div id="section-3">
  ## 选择适合任务的模式
</div>

| 您要完成的任务...     | 推荐起始模式     |
| -------------- | ---------- |
| 探索、提问、规划或开始构建  | Free Mode  |
| 在大多数任务中兼顾速度与性能 | Power Mode |
| 处理复杂或高难度任务     | Max Mode   |

Power Mode 以相同成本取代 Economy Mode，并提供相当或更出色的性能。Core 和 Pro 套餐可让您选择 Power Mode 或 Max Mode 中可用的模型。
