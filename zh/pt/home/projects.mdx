<div id="what-is-a-project">
  ## 什么是 project？
</div>

project 是你在 Replit 上构建的所有内容的容器，它承载你的代码、数据，以及你创建的全部 artifact —— Web 应用、移动应用、幻灯片、数据看板和视频。当你把需求告诉 Agent 后，它会创建一个 project，并在其中构建相应的 artifact。

可以把 project 想象成你办公桌上的工作台：所有东西都集中在一处，彼此可以共享同样的信息，但每一件各司其职。

例如，你让 Agent 构建一个健身追踪应用，它会创建一个 project，其中包含一个移动应用 artifact，以及运行所需的后端、数据库和存储。

<ArtifactGrid />

关键概念：

* **Project**：承载一切的容器 —— 你的代码、数据和所有 artifact
* **Artifact**：project 内可发布的产出 (Web 应用、幻灯片、视频等)
* **资源**：每个 artifact 都自动获得后端、数据库和文件存储 —— 无需任何配置

<Note>
  发布会一次性将整个 project 上线，所有 artifact 同时生效，因此始终保持同步。
</Note>

<div id="what-you-can-build">
  ## 你可以构建什么
</div>

| 类型                                                        | 简介                            | 示例                 |
| --------------------------------------------------------- | ----------------------------- | ------------------ |
| **[Web 应用](/zh/features/artifact-types/web-apps)**          | 用户在浏览器中访问的网站或 Web 应用         | 在线商店、预订工具、作品集网站    |
| **[移动应用](/zh/features/artifact-types/building-mobile-apps)** | 用户安装在手机上的原生应用                 | 健身追踪器、餐厅点餐应用       |
| **[数据可视化](/zh/features/artifact-types/data-apps)**           | 包含图表、筛选器和实时数据的交互式仪表板          | 销售报表、指标追踪器、分析视图    |
| **[幻灯片](/zh/features/artifact-types/slide-decks)**           | 可用于演示或导出的演示文稿                 | 融资路演稿、团队进展汇报、产品概览  |
| **[动画](/zh/features/artifact-types/animated-videos)**        | 可导出为 MP4 的 motion graphics 视频 | 产品发布视频、讲解短片、社交媒体内容 |
| **3D 游戏**                                                 | 3D 游戏、模拟或交互式体验                | 益智游戏、物理模拟、交互式体验    |
| **[Design](/zh/design/canvas)**                              | 在设计画布上探索的视觉方向与原型              | 情绪板、设计稿、设计探索       |

一个 project 可以包含多个 artifact。例如,你可以在同一个 project 中构建面向客户的 Web 应用、面向团队的移动应用,以及面向投资人的幻灯片。当多个 artifact 位于同一个 project 中时,它们会自动共享相同的数据和后端逻辑。了解更多,请参阅 [Artifacts](/zh/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project)。

<div id="managing-your-projects">
  ## 管理你的 project
</div>

Projects 页面会列出你创建的以及受邀加入的所有 project。当 workspace 内容繁多时，这里是回到近期工作、快速找到目标 project 的最快途径。

<div id="see-at-a-glance-whats-inside-each-project">
  ### 一眼看清每个 project 里有什么
</div>

每张 project 卡片都会用小图标展示其中包含的 artifact，涵盖 project 里的每个 Web 应用、移动应用、幻灯片、数据可视化和动画。将鼠标悬停在任意图标上，即可直接在卡片上预览该 artifact 的截图，不用打开就能区分不同的 project。

<div id="filter-by-artifact">
  ### 按 artifact 筛选
</div>

使用 Projects 页面顶部的 **Build type** 下拉菜单，按 artifact 筛选列表。选择某一项后，将只显示包含该类 artifact 的 project：

* **Web** — 包含 Web 应用 的 project
* **Mobile** — 包含移动应用的 project
* **Data** — 包含数据可视化的 project
* **Slides** — 包含幻灯片的 project
* **Design** — 处于 Design 模式的 project
* **3D Game**、**Agent &amp; Automation** 等

选择 **Any build type** 即可清除筛选。

  <img src="/assets/mirror/projects-page-build-type-filter-9e23df1b365a.png" alt="Build type dropdown on the Projects page filtering by artifact, with Design, Web, Data, Mobile, 3D Game, and Slides options" width="472" height="622" data-path="images/replitai/projects-page-build-type-filter.png" />
</Frame>

<div id="sort-by-last-opened">
  ### 按最近打开排序
</div>

Projects 页面默认按**你最近打开的时间**排序——你最近处理过的 project 会排在最上方。这在团队 workspace 中尤其有用，否则其他成员的最新编辑会把你当前的工作挤到后面。

你可以点击其他列标题 (例如**最近更新**或**名称**) 来切换排序方式。

<div id="pin-the-projects-you-use-most">
  ### 置顶最常用的 project
</div>

置顶 project 后，它会始终显示在列表顶部。置顶**仅对你自己生效**——在团队 workspace 中置顶 project 不会影响其他成员看到的内容。

若要置顶 project，请打开 project 卡片上的更多菜单 (三个点) ，然后选择 **Pin**。在同一菜单中选择 **Unpin** 即可取消置顶。
