Shell позволяет работать с проектом как в обычном терминале: управлять файлами,
устанавливать пакеты и запускать скрипты. Например, вы можете просматривать файлы проекта
или использовать `psql`, если для проекта настроено подключение к базе данных.

<Tip>
  Для более удобного управления рабочими процессами рекомендуем запускать приложение кнопкой **Run**, а не из Shell.
  Рабочие процессы, запущенные кнопкой **Run**, отправляют вывод в инструмент Console,
  что дает структурированный способ просмотра логов.
</Tip>

<div id="section">
  ## Возможности
</div>

Shell предоставляет следующие возможности:

* **Запуск нескольких оболочек**: открывайте несколько экземпляров Shell и работайте над разными задачами одновременно
* **Поиск текста**: находите нужный текст в выводе Shell

<div id="shell">
  ### Проверка доступа к Shell
</div>

Чтобы убедиться, что Shell готов к работе, и посмотреть текущее рабочее пространство, выполните:

```sh theme={null}
pwd
```

Shell отобразит путь к текущему рабочему пространству.

<Frame caption="Команда pwd выводит путь к текущему рабочему пространству и возвращает приглашение Shell.">
  <img src="/assets/mirror/shell-pwd-output-2d31a0e0466b.jpg" alt="Вкладка Shell с командой pwd, выводом пути к рабочему пространству и вернувшимся приглашением" width="1280" height="246" data-path="images/workspace/shell-pwd-output.jpg" />
</Frame>

Для проектов с базой данных выберите **Tools** → **Database**,
чтобы открыть страницу **Development database**. На ней собраны элементы управления подключением.
Не разглашайте данные подключения и не копируйте их в документы, скриншоты, журналы, исходные файлы
и сообщения, которыми вы делитесь с другими.

<div id="section-3">
  ### Текстовый поиск
</div>

Как открыть и использовать инструмент текстового поиска:

1. В правом верхнем углу вкладки Shell выберите значок лупы <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="значок лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" />, чтобы открыть диалоговое окно поиска.
2. Введите поисковый запрос и нажимайте **Next**, чтобы последовательно просматривать совпадения.
3. Используйте **Previous**, чтобы вернуться к предыдущему совпадению.
4. Выберите **Exit** или щёлкните за пределами диалогового окна, чтобы завершить текстовый поиск.

<div id="section-4">
  ### Несколько Shell
</div>

Чтобы создать ещё один Shell:

1. Откройте меню экземпляров Shell в заголовке панели Shell.
2. Выберите **New Shell**.

<Frame>
  <img src="/assets/mirror/shell-new-94a280c1230f.png" alt="Меню экземпляров Shell с текущим рабочим пространством и опцией New Shell" width="1280" height="224" data-path="images/workspace/shell-new.png" />
</Frame>

Переключаться между Shell можно через то же меню. Replit помечает каждый Shell последней выполненной в нём командой, чтобы их было проще различать.

<Warning>
  Если открыто несколько Shell, Replit автоматически закрывает простаивающие экземпляры Shell.
  Простаивающий Shell — это Shell, который не выбран и не выполняет пользовательских процессов.
</Warning>
