# Connecteurs Databricks

> Choisissez et configurez un connecteur Databricks afin que Replit Agent puisse créer des applications basées sur les données de votre espace de travail Databricks.

<Info>
  Les connecteurs Databricks sont disponibles exclusivement sur le plan
  **Enterprise**.
</Info>

<Frame>
  <img src="https://mintcdn.com/replit/xfCoeTDIPMvB7evM/images/connectors/databricks/templates-dropdown-zoom.png?fit=max&auto=format&n=xfCoeTDIPMvB7evM&q=85&s=92d2df97ba167b7fd5b9dfe7509e7dfa" alt="Boîte d'invite d'accueil Replit avec le menu déroulant Modèles ouvert, affichant le modèle d'organisation Databricks App" width="1680" height="300" data-path="images/connectors/databricks/templates-dropdown-zoom.png" />
</Frame>

Les connecteurs Databricks permettent à Replit Agent d'interroger votre espace de travail Databricks. Les créateurs peuvent concevoir des tableaux de bord, des outils de reporting et des applications de données en langage naturel. Aucune expertise SQL n'est requise.

Replit prend en charge deux types de connexion Databricks. Choisissez-en un en fonction de l'identité qui doit exécuter chaque requête.

## Choisir un type de connexion

|                               | **Utilisateur-à-machine (U2M)**                               | **Principal de service (M2M)**             |
| ----------------------------- | ------------------------------------------------------------- | ------------------------------------------ |
| Nom du connecteur dans Replit | Databricks for Databricks Apps (U2M)                          | Databricks (Service Principal)             |
| Identité de la requête        | Le créateur individuel                                        | Un principal de service partagé            |
| Permissions Databricks        | Les permissions Unity Catalog de chaque créateur              | Les permissions du principal de service    |
| Attribution d'audit           | Le créateur qui a exécuté la requête                          | Le principal de service                    |
| Connexion du créateur         | Chaque créateur se connecte avec son propre compte Databricks | Aucune connexion Databricks individuelle   |
| Idéal pour                    | Permissions par utilisateur et attribution d'audit            | Accès partagé et workflows non interactifs |

## Configurer le connecteur U2M

La configuration U2M implique trois rôles :

1. **Administrateur de compte Databricks** : crée une connexion d'application OAuth et fournit les détails de l'entrepôt SQL.
2. **Administrateur d'organisation Replit** : configure le connecteur avec les identifiants OAuth.
3. **Créateur** : se connecte avec son compte Databricks et commence à créer.

### Prérequis U2M

Avant de commencer, confirmez que vous disposez des éléments suivants :

* Un **administrateur de compte** Databricks. Les connexions d'application se configurent dans la console de compte, et non dans les paramètres d'administration de l'espace de travail.
* Un administrateur d'organisation Replit.
* Un compte Databricks pour chaque créateur qui utilisera le connecteur.
* Un accès à l'espace de travail pour chaque créateur, incluant la permission **Can use** sur l'entrepôt SQL et les permissions Unity Catalog requises.

### Étape 1 : Créer une connexion d'application OAuth

<Note>Vous devez être administrateur de compte Databricks pour effectuer cette étape.</Note>

L'administrateur de compte Databricks enregistre Replit en tant qu'application OAuth. La connexion d'application fournit l'ID client et le secret client utilisés pour configurer Replit.

<Steps>
  <Step title="Ouvrir la console de compte Databricks">
    Dans votre espace de travail Databricks, ouvrez le sélecteur d'espace de travail dans le coin supérieur droit et sélectionnez **Manage account**.

    <Frame>
      <img src="https://mintcdn.com/replit/zZsRspCDhA4G7dI6/images/connectors/databricks/u2m/manage-account.png?fit=max&auto=format&n=zZsRspCDhA4G7dI6&q=85&s=c42eac89fbf3452678a9dc33926301da" alt="Sélecteur d'espace de travail Databricks ouvert avec Manage account visible" width="2000" height="1144" data-path="images/connectors/databricks/u2m/manage-account.png" />
    </Frame>
  </Step>

  <Step title="Ouvrir Connexions d'application">
    Dans la console de compte, sélectionnez **Paramètres**, puis ouvrez l'onglet **Connexions d'application**.

    <Frame>
      <img src="https://mintcdn.com/replit/zZsRspCDhA4G7dI6/images/connectors/databricks/u2m/app-connections.png?fit=max&auto=format&n=zZsRspCDhA4G7dI6&q=85&s=6ecb6f5b70ebe137a4bab2369f28c872" alt="Page Paramètres du compte Databricks avec l'onglet Connexions d'application sélectionné et le bouton Ajouter une connexion visible" width="2000" height="1144" data-path="images/connectors/databricks/u2m/app-connections.png" />
    </Frame>
  </Step>

  <Step title="Configurer la connexion Replit">
    Sélectionnez **Ajouter une connexion**. Entrez un nom d'application qui identifie Replit, par exemple `replit-u2m`.

    Sous **URL de redirection**, entrez :

    ```text theme={null}
    https://replit.com/connectors/oauth/callback
    ```

    Sous **Portées d'accès**, sélectionnez **All APIs**. Cela permet à Agent d'utiliser Databricks SQL et les API Databricks nécessaires pour créer et gérer des Databricks Apps.

    Sélectionnez **Générer un secret client**. Databricks ne peut pas ajouter de secret à cette connexion après sa création.

    Définissez les durées de vie des jetons selon la politique de sécurité de votre organisation. L'exemple utilise une **durée de vie du jeton d'accès** de `1440` minutes (24 heures) et une **durée de vie du jeton de rafraîchissement** de `129600` minutes (90 jours), les valeurs maximales proposées par Databricks. Une durée de vie de jeton de rafraîchissement plus courte peut obliger les créateurs à se reconnecter plus souvent.

    Sélectionnez **Ajouter**.

    <Warning>
      **All APIs** accorde un accès plus large que le SQL seul. Contrôlez l'accès effectif du connecteur grâce aux permissions Databricks de chaque créateur.
    </Warning>

    <Frame>
      <img src="https://mintcdn.com/replit/zZsRspCDhA4G7dI6/images/connectors/databricks/u2m/app-configuration.png?fit=max&auto=format&n=zZsRspCDhA4G7dI6&q=85&s=e1a23573f61e949408c56394ae503be5" alt="Formulaire Add connection de Databricks configuré avec un nom d'application Replit, une URL de redirection, l'accès All APIs, la génération d'un secret client et les durées de vie des jetons" width="2000" height="1144" data-path="images/connectors/databricks/u2m/app-configuration.png" />
    </Frame>
  </Step>

  <Step title="Enregistrer les identifiants OAuth">
    Copiez l'**ID client** et le **secret client**, puis stockez-les dans le gestionnaire de secrets de votre organisation.

    <Warning>
      Databricks affiche le secret client une seule fois. Notez sa date d'expiration et faites tourner la connexion d'application avant que le secret n'expire.
    </Warning>

    <Frame>
      <img src="https://mintcdn.com/replit/zZsRspCDhA4G7dI6/images/connectors/databricks/u2m/oauth-credentials.png?fit=max&auto=format&n=zZsRspCDhA4G7dI6&q=85&s=45bfd27ecee3d65ffced138fdd60dafc" alt="Boîte de dialogue Connection created de Databricks avec l'ID client et le secret client masqués, ainsi que l'avertissement de secret à usage unique et la date d'expiration" width="2000" height="1144" data-path="images/connectors/databricks/u2m/oauth-credentials.png" />
    </Frame>
  </Step>
</Steps>

<Note>
  Les connexions d'application OAuth nouvelles ou mises à jour peuvent
  prendre jusqu'à 30 minutes pour devenir disponibles.
</Note>

### Étape 2 : Partager les détails de l'entrepôt SQL

Chaque créateur saisit les détails de l'entrepôt SQL lors de l'autorisation du connecteur U2M. Publiez ces valeurs à un endroit accessible à vos créateurs, par exemple une page d'intégration interne.

<Steps>
  <Step title="Ouvrir les entrepôts SQL">
    Dans l'espace de travail Databricks, sélectionnez **SQL Warehouses** et ouvrez l'entrepôt que les créateurs doivent utiliser.

    <Frame>
      <img src="https://mintcdn.com/replit/xfCoeTDIPMvB7evM/images/connectors/databricks/sql-warehouses.png?fit=max&auto=format&n=xfCoeTDIPMvB7evM&q=85&s=8610ede28b6a723fd5774fb9e97c7485" alt="Page des entrepôts SQL Databricks affichant les entrepôts disponibles" width="3438" height="1984" data-path="images/connectors/databricks/sql-warehouses.png" />
    </Frame>
  </Step>

  <Step title="Copier les détails de connexion">
    Sélectionnez **Détails de connexion**, puis copiez le **Nom d'hôte du serveur** et le **Chemin HTTP**.

    <Frame>
      <img src="https://mintcdn.com/replit/xfCoeTDIPMvB7evM/images/connectors/databricks/connection-details.png?fit=max&auto=format&n=xfCoeTDIPMvB7evM&q=85&s=b2e51207eb945f4e9e939caa093c2b23" alt="Page des détails de connexion de l'entrepôt SQL Databricks avec le nom d'hôte du serveur et le chemin HTTP" width="3438" height="1984" data-path="images/connectors/databricks/connection-details.png" />
    </Frame>
  </Step>
</Steps>

### Étape 3 : Activer U2M dans Replit

<Note>Vous devez être administrateur d'organisation Replit pour configurer les connecteurs.</Note>

<Steps>
  <Step title="Ouvrir et activer le connecteur U2M">
    Depuis la page d'accueil de votre compte Replit, ouvrez **Paramètres**, puis **Intégrations**. Recherchez `Databricks U2M`, trouvez **Databricks for Databricks Apps (U2M)**, et sélectionnez **Activer**.

    Entrez l'**ID client** et le **secret client** de la connexion d'application Databricks.

    Confirmez que l'URL de redirection affichée dans Replit correspond à l'URL configurée dans Databricks :

    ```text theme={null}
    https://replit.com/connectors/oauth/callback
    ```

    Sous **Portées du connecteur**, activez `all-apis` et `offline_access`. La portée `offline_access` fournit à Replit un jeton de rafraîchissement pour les sessions de longue durée.

    Sélectionnez **Configurer**.

    <Frame>
      <img src="https://mintcdn.com/replit/zZsRspCDhA4G7dI6/images/connectors/databricks/u2m/enable-connector.png?fit=max&auto=format&n=zZsRspCDhA4G7dI6&q=85&s=b83ecf60327fd12139ac5d499d7a2878" alt="Paramètres Intégrations Replit filtrés sur Databricks U2M avec le panneau d'activation affichant l'URL de redirection, les champs d'identifiants OAuth et les portées du connecteur" width="2000" height="1144" data-path="images/connectors/databricks/u2m/enable-connector.png" />
    </Frame>
  </Step>

  <Step title="Vérifier que le connecteur est activé">
    Confirmez que **Databricks for Databricks Apps (U2M)** apparaît sous **Vos intégrations**.
  </Step>
</Steps>

### Étape 4 : Se connecter en tant que créateur

Chaque créateur se connecte avec son propre compte Databricks avant d'utiliser le connecteur. Replit peut rafraîchir la session jusqu'à l'expiration du jeton de rafraîchissement.

<Steps>
  <Step title="Se connecter au connecteur">
    Sur la page **Intégrations**, trouvez **Databricks for Databricks Apps (U2M)** et sélectionnez **Se connecter**. Examinez les détails de connexion, puis sélectionnez **Continuer vers Databricks for Databricks Apps**.

    <Frame>
      <img src="https://mintcdn.com/replit/zZsRspCDhA4G7dI6/images/connectors/databricks/u2m/connect-modal.png?fit=max&auto=format&n=zZsRspCDhA4G7dI6&q=85&s=05a11145d2602535df79f0d60c76ad7e" alt="Fenêtre modale Connect Databricks for Databricks Apps expliquant la redirection, la confidentialité et les contrôles de permission" width="2000" height="1144" data-path="images/connectors/databricks/u2m/connect-modal.png" />
    </Frame>
  </Step>

  <Step title="Entrer les détails de l'entrepôt SQL">
    Entrez le **Chemin HTTP** de l'entrepôt SQL fourni par votre administrateur Databricks, puis sélectionnez **Suivant**.

    <Frame>
      <img src="https://mintcdn.com/replit/zZsRspCDhA4G7dI6/images/connectors/databricks/u2m/http-path.png?fit=max&auto=format&n=zZsRspCDhA4G7dI6&q=85&s=8c95432a240fa353d0138402ffef0207" alt="Boîte de dialogue Connect Databricks for Databricks Apps demandant le chemin HTTP de l'entrepôt SQL à l'étape 1 sur 2" width="2000" height="1144" data-path="images/connectors/databricks/u2m/http-path.png" />
    </Frame>

    Replit demande ensuite le **Nom d'hôte du serveur** de l'entrepôt SQL. Entrez-le et continuez vers Databricks. Connectez-vous lorsque vous y êtes invité, examinez l'accès demandé, puis approuvez la demande.

    Chaque requête exécutée par Agent via cette connexion utilise vos permissions Databricks et est attribuée à vous dans les journaux d'audit Databricks.

    Après approbation, Databricks vous redirige vers Replit et le connecteur est prêt à l'emploi.
  </Step>
</Steps>

## Configurer le connecteur à principal de service

La configuration du principal de service implique trois rôles :

1. **Administrateur Databricks** : crée le principal de service et accorde les permissions dans Databricks.
2. **Administrateur d'organisation Replit** : configure le connecteur et l'accès dans Replit.
3. **Créateur** : commence à créer avec l'identité Databricks partagée.

### Prérequis du principal de service

Avant de commencer, confirmez que vous disposez des éléments suivants :

* Accès administrateur de compte ou administrateur d'espace de travail Databricks.
* Accès administrateur d'organisation Replit.

### Étape 1 : Créer un principal de service dans Databricks

<Note>
  Vous devez être administrateur de compte ou administrateur d'espace de travail Databricks pour effectuer cette étape.
</Note>

L'administrateur Databricks crée une identité machine-à-machine, appelée [principal de service](https://docs.databricks.com/aws/en/admin/users-groups/service-principals), que Replit utilise pour se connecter à Databricks.

<Steps>
  <Step title="Ouvrir les Paramètres">
    Dans Databricks, sélectionnez votre avatar dans le coin supérieur droit, puis sélectionnez **Paramètres**.

    <Frame>
      <img src="https://mintcdn.com/replit/xfCoeTDIPMvB7evM/images/connectors/databricks/settings-menu.png?fit=max&auto=format&n=xfCoeTDIPMvB7evM&q=85&s=4179d36f68585cf88af24ab86d960694" alt="Menu de l'espace de travail Databricks avec Paramètres sélectionné" width="3438" height="1984" data-path="images/connectors/databricks/settings-menu.png" />
    </Frame>
  </Step>

  <Step title="Sélectionner Identité et accès">
    Dans la barre latérale des Paramètres, sélectionnez **Identité et accès**.

    <Frame>
      <img src="https://mintcdn.com/replit/xfCoeTDIPMvB7evM/images/connectors/databricks/settings-page.png?fit=max&auto=format&n=xfCoeTDIPMvB7evM&q=85&s=8e22324831c8804b135a3b5e550e7f45" alt="Page Paramètres Databricks avec Identité et accès dans la barre latérale" width="3438" height="1984" data-path="images/connectors/databricks/settings-page.png" />
    </Frame>
  </Step>

  <Step title="Gérer les principaux de service">
    Sous **Gestion et autorisations**, trouvez **Principaux de service** et sélectionnez **Gérer**.

    <Frame>
      <img src="https://mintcdn.com/replit/xfCoeTDIPMvB7evM/images/connectors/databricks/identity-and-access.png?fit=max&auto=format&n=xfCoeTDIPMvB7evM&q=85&s=4c502716a573596cbe0550644036654d" alt="Page des paramètres Identité et accès affichant le bouton Gérer des principaux de service" width="3438" height="1984" data-path="images/connectors/databricks/identity-and-access.png" />
    </Frame>
  </Step>

  <Step title="Ajouter un nouveau principal de service">
    Sélectionnez **Ajouter un principal de service**, puis sélectionnez **Ajouter nouveau**.

    <Frame>
      <img src="https://mintcdn.com/replit/xfCoeTDIPMvB7evM/images/connectors/databricks/add-service-principal.png?fit=max&auto=format&n=xfCoeTDIPMvB7evM&q=85&s=ca1c2ec068049bd48b2c590d9cae4b3f" alt="Boîte de dialogue Ajouter un principal de service avec le bouton Ajouter nouveau" width="3438" height="1984" data-path="images/connectors/databricks/add-service-principal.png" />
    </Frame>
  </Step>

  <Step title="Nommer le principal de service">
    Entrez un nom clair pour le principal de service, puis sélectionnez **Ajouter**.

    <Frame>
      <img src="https://mintcdn.com/replit/xfCoeTDIPMvB7evM/images/connectors/databricks/add-service-principal-name.png?fit=max&auto=format&n=xfCoeTDIPMvB7evM&q=85&s=f2490e64e7bb1516e153f7690da5c9a2" alt="Boîte de dialogue Ajouter un principal de service avec un nom de principal de service saisi" width="3438" height="1984" data-path="images/connectors/databricks/add-service-principal-name.png" />
    </Frame>
  </Step>

  <Step title="Confirmer les détails du principal de service">
    Après que Databricks crée le principal de service, confirmez qu'il est actif. Gardez cette page ouverte si vous avez besoin des détails du principal de service lors de la configuration du connecteur Replit.

    <Frame>
      <img src="https://mintcdn.com/replit/xfCoeTDIPMvB7evM/images/connectors/databricks/service-principal-details.png?fit=max&auto=format&n=xfCoeTDIPMvB7evM&q=85&s=ffdb270b49e7b6a330c3691358b8234b" alt="Page de détails du principal de service Databricks" width="3438" height="1984" data-path="images/connectors/databricks/service-principal-details.png" />
    </Frame>
  </Step>

  <Step title="Accorder l'accès">
    Ouvrez l'onglet **Permissions**, sélectionnez **Accorder l'accès**, choisissez le principal de service, définissez la permission sur **Gérer**, puis sélectionnez **Enregistrer**.

    <Frame>
      <img src="https://mintcdn.com/replit/xfCoeTDIPMvB7evM/images/connectors/databricks/grant-access.png?fit=max&auto=format&n=xfCoeTDIPMvB7evM&q=85&s=ee85ab8f1741b86f830efcd80427a596" alt="Boîte de dialogue Accorder l'accès pour un principal de service Databricks avec la permission Gérer sélectionnée" width="3438" height="1984" data-path="images/connectors/databricks/grant-access.png" />
    </Frame>
  </Step>
</Steps>

### Étape 2 : Obtenir les détails de connexion à votre entrepôt SQL

Le connecteur Replit a besoin des détails de connexion à l'entrepôt SQL Databricks pour acheminer les requêtes vers la bonne ressource de calcul.

<Steps>
  <Step title="Ouvrir les entrepôts SQL">
    Dans la barre latérale Databricks, sélectionnez **Entrepôts SQL**.

    <Frame>
      <img src="https://mintcdn.com/replit/xfCoeTDIPMvB7evM/images/connectors/databricks/sql-warehouses.png?fit=max&auto=format&n=xfCoeTDIPMvB7evM&q=85&s=8610ede28b6a723fd5774fb9e97c7485" alt="Page des entrepôts SQL Databricks affichant les entrepôts disponibles" width="3438" height="1984" data-path="images/connectors/databricks/sql-warehouses.png" />
    </Frame>
  </Step>

  <Step title="Sélectionner ou créer un entrepôt">
    Sélectionnez l'entrepôt SQL que vous souhaitez que Replit Agent utilise. Si vous n'en avez pas encore, sélectionnez **Créer un entrepôt SQL** et créez un nouvel entrepôt.
  </Step>

  <Step title="Copier les détails de connexion">
    Ouvrez l'entrepôt et sélectionnez **Détails de connexion**. Repérez les valeurs **Nom d'hôte du serveur** et **Chemin HTTP**. Vous aurez besoin de ces valeurs lors de la création du connecteur Databricks dans Replit.

    <Frame>
      <img src="https://mintcdn.com/replit/xfCoeTDIPMvB7evM/images/connectors/databricks/connection-details.png?fit=max&auto=format&n=xfCoeTDIPMvB7evM&q=85&s=b2e51207eb945f4e9e939caa093c2b23" alt="Page des détails de connexion de l'entrepôt SQL Databricks avec le nom d'hôte du serveur et le chemin HTTP" width="3438" height="1984" data-path="images/connectors/databricks/connection-details.png" />
    </Frame>
  </Step>
</Steps>

### Étape 3 : Créer le connecteur Databricks dans Replit

<Note>Vous devez être administrateur d'organisation Replit pour configurer les connecteurs.</Note>

L'administrateur Replit ajoute les détails de connexion Databricks à Replit pour que les créateurs puissent utiliser le connecteur.

<Steps>
  <Step title="Accéder aux Intégrations">
    Depuis la page d'accueil de votre compte Replit, ouvrez la page **Intégrations**. Sous **Connecteurs**, trouvez **Databricks (Principal de service)** et sélectionnez **Se connecter**.

    <Frame>
      <img src="https://mintcdn.com/replit/xfCoeTDIPMvB7evM/images/connectors/databricks/integrations-databricks-signin.png?fit=max&auto=format&n=xfCoeTDIPMvB7evM&q=85&s=f3b1558a4d4afc021fd7b2be96004ea7" alt="Page Intégrations Replit filtrée sur Databricks, affichant le connecteur Databricks (Principal de service) avec un bouton Se connecter" width="3436" height="1978" data-path="images/connectors/databricks/integrations-databricks-signin.png" />
    </Frame>
  </Step>

  <Step title="Confirmer la connexion">
    Replit affiche une boîte de dialogue de confirmation avant de rediriger vers Databricks pour l'authentification. Examinez les détails et sélectionnez **Continuer vers Databricks**.

    <Frame>
      <img src="https://mintcdn.com/replit/xfCoeTDIPMvB7evM/images/connectors/databricks/connect-databricks-intro.png?fit=max&auto=format&n=xfCoeTDIPMvB7evM&q=85&s=d1bd23f4bb71d62a555993b106f4596e" alt="Boîte de dialogue Connecter Databricks expliquant la redirection OAuth, l'utilisation des données et les permissions" width="3436" height="1978" data-path="images/connectors/databricks/connect-databricks-intro.png" />
    </Frame>
  </Step>

  <Step title="Entrer le chemin HTTP de l'entrepôt SQL">
    Collez le **chemin HTTP** depuis les détails de connexion de votre entrepôt SQL Databricks (par exemple, `/sql/1.0/warehouses/abcdef1234567890`), puis sélectionnez **Suivant**.

    <Frame>
      <img src="https://mintcdn.com/replit/xfCoeTDIPMvB7evM/images/connectors/databricks/connector-http-path.png?fit=max&auto=format&n=xfCoeTDIPMvB7evM&q=85&s=c68fa0868bed7dbd56c46f3be3bbc4b3" alt="Boîte de dialogue Connecter Databricks étape 1 sur 2 demandant le chemin HTTP de l'entrepôt SQL" width="3436" height="1978" data-path="images/connectors/databricks/connector-http-path.png" />
    </Frame>
  </Step>

  <Step title="Entrer le nom d'hôte du serveur de l'entrepôt SQL">
    Collez le **Nom d'hôte du serveur** depuis les mêmes détails de connexion (par exemple, `abc-12345678-wxyz.cloud.databricks.com`), puis sélectionnez **Continuer vers Databricks** pour terminer l'authentification.

    <Frame>

## Créer avec Agent

Après la connexion avec l'une ou l'autre méthode, les créateurs peuvent créer des applications utilisant les données Databricks avec Agent.

<Steps>
  <Step title="Sélectionner le modèle Databricks App pour le déploiement">
    Sélectionnez le modèle **Databricks App** lorsque vous souhaitez déployer l'application terminée dans votre environnement Databricks. Le modèle n'est pas nécessaire pour utiliser un connecteur configuré afin d'accéder aux données et ressources Databricks.

    Depuis la page d'accueil Replit, ouvrez le sélecteur de modèles et choisissez **Databricks App**.

    <Frame>
      <img src="https://mintcdn.com/replit/zZsRspCDhA4G7dI6/images/connectors/databricks/u2m/databricks-template.png?fit=max&auto=format&n=zZsRspCDhA4G7dI6&q=85&s=4a1b0725cfa264171933ecc344e7794c" alt="Page d'accueil Replit avec le modèle Databricks App sélectionné au-dessus de la boîte d'invite" width="1200" height="400" data-path="images/connectors/databricks/u2m/databricks-template.png" />

  <Step title="Décrire votre application">

## Résolution des problèmes

<AccordionGroup>
  <Accordion title="Les requêtes retournent des résultats vides">
    Vérifiez les permissions Databricks de l'identité qui exécute la requête.
    Avec U2M, il s'agit du créateur individuel. Avec le connecteur à
    principal de service, il s'agit du principal de service partagé.
    L'identité peut avoir accès aux métadonnées mais aucune permission de
    lecture sur les données. Accordez les permissions de catalogue, de
    schéma ou de table requises, puis réessayez.
  </Accordion>

  <Accordion title="Le connecteur ne peut pas atteindre l'entrepôt SQL">
    Vérifiez que les valeurs **Nom d'hôte du serveur** et **Chemin HTTP**
    correspondent aux détails de connexion de l'entrepôt SQL dans
    Databricks. Pour U2M, vérifiez les valeurs saisies par le créateur
    concerné. Confirmez également que l'entrepôt est actif et que
    l'identité de la requête dispose de la permission de l'utiliser.
  </Accordion>

  <Accordion title="L'authentification échoue">
    Pour U2M, confirmez que la connexion d'application Databricks liste
    `https://replit.com/connectors/oauth/callback` sous **URL de redirection**,
    sans barre oblique finale. Si l'authentification échoue pour tous les
    créateurs, vérifiez l'ID client et le secret client partagés, confirmez
    que le secret n'a pas expiré, et assurez-vous que les portées dans
    Replit correspondent à la connexion d'application Databricks.

    Pour le connecteur à principal de service, vérifiez que les détails du
    principal de service saisis dans Replit correspondent au principal de
    service créé dans Databricks. Si les identifiants ont été renouvelés,
    mettez à jour le connecteur dans Replit.
  </Accordion>

  <Accordion title="Le connecteur me demande de me reconnecter">
    Cela peut se produire avec U2M lorsque le jeton de rafraîchissement
    expire ou est révoqué. Recommencez le flux d'autorisation Databricks.
    Si les créateurs doivent se reconnecter plus souvent que ne l'exige
    votre politique de sécurité, vérifiez les durées de vie des jetons de
    la connexion d'application.
  </Accordion>
</AccordionGroup>
