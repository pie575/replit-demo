В этом справочном руководстве описывается класс `Client` из пакета `replit-object-storage-python` и приводятся примеры кода для его методов.

<div id="client">
  ## Client
</div>

Класс `Client` управляет взаимодействием с Replit App Storage. Этот класс содержит методы для выполнения операций над объектами в бакете.

Чтобы импортировать класс из пакета `replit.object_storage`, добавьте в свой код на Python следующую строку:

```python theme={null}
from replit.object_storage import Client
```

Используйте следующий код, чтобы создать экземпляр `Client` для работы с Replit App Storage:

```python theme={null}
client = Client()
```

<Tip>
  Если ваше приложение использует несколько бакетов, создайте отдельный экземпляр `Client` для каждого бакета.
</Tip>

<div id="__init__">
  ### **init**
</div>

Метод `init` инициализирует экземпляр класса Client.

```python theme={null}
def __init__(bucket_id: Optional[str] = None)
```

**Аргумент**:

* `bucket_id` (Optional[str]): идентификатор бакета, которым управляет клиент. Если не указан, Client использует бакет по умолчанию, связанный с Replit App или деплойментом.

<div id="copy">
  ### copy
</div>

Метод `copy` копирует объект в пределах одного бакета. Если по этому пути объект уже существует, он будет перезаписан.

```python theme={null}
def copy(object_name: str, dest_object_name: str) -> None
```

**Аргументы**:

* `object_name` (str) — полный путь к исходному объекту.
* `dest_object_name` (str) — полный путь к объекту назначения.

**Исключения**:

* `ObjectNotFoundError` — исходный объект не найден по указанному пути.

<div id="delete">
  ### delete
</div>

Метод `delete` безвозвратно удаляет файл из App Storage.

```python theme={null}
def delete(object_name: str, ignore_not_found: bool = False) -> None
```

**Аргументы**:

* `object_name` (str) — имя удаляемого объекта.
* `ignore_not_found` (bool) — если `True`, ошибка не возникает, когда объект не существует.

**Исключения**:

* `ObjectNotFoundError` — объект не существует.

<div id="download_as_bytes">
  ### download_as_bytes
</div>

Метод `download_as_bytes` возвращает содержимое файла в виде `bytes`.

```python theme={null}
def download_as_bytes(object_name: str) -> bytes
```

**Аргумент**:

* `object_name` (str) — имя загружаемого объекта.

**Возвращает**:

* `bytes` — сырое байтовое представление содержимого объекта.

**Вызывает исключения**:

* `ObjectNotFoundError` — объект не существует.

<div id="download_as_text">
  ### download_as_text
</div>

Метод `download_as_text` скачивает содержимое файла как значение типа `str`.

```python theme={null}
def download_as_text(object_name: str) -> str
```

**Аргумент**:

* `object_name` (str) — имя исходного объекта, который нужно получить.

**Возвращает**:

* str: содержимое объекта в виде строки в кодировке UTF-8.

**Исключения**:

* `ObjectNotFoundError` — объект не существует.

<div id="download_to_filename">
  ### download_to_filename
</div>

Скачивает содержимое объекта в файл на локальном диске.

```python theme={null}
def download_to_filename(object_name: str, dest_filename: str) -> None
```

**Аргументы**:

* `object_name` (str) — имя исходного объекта в App Storage, который требуется получить.
* `dest_filename` (str) — имя конечного файла на локальном диске.

**Исключения**:

* `ObjectNotFoundError` — означает, что объект не существует.

<div id="exists">
  ### exists
</div>

Метод `exists` проверяет, существует ли объект.

```python theme={null}
def exists(object_name: str) -> bool
```

**Аргумент**:

* `object_name` (str) — имя объекта, существование которого нужно проверить.

**Возвращает**:

* `bool`: `True`, если объект существует, и False в противном случае.

<div id="list">
  ### list
</div>

Метод `list` возвращает список объектов в бакете.

```python theme={null}
def list(end_offset: Optional[str] = None,
         match_glob: Optional[str] = None,
         max_results: Optional[int] = None,
         prefix: Optional[str] = None,
         start_offset: Optional[str] = None) -> List[Object]
```

**Аргументы**:

* `end_offset`(Optional[str]) — фильтрует результаты, оставляя объекты, имена которых лексикографически предшествуют `end_offset`. Если задан `start_offset`, в список попадают объекты
  с именами между `start_offset` (включительно) и `end_offset` (не включая).
* `match_glob` (Optional[str]) — фильтрует результаты по glob-шаблону. Например, &quot;foo*bar&quot; соответствует &quot;footbar&quot;, &quot;foo baz bar&quot; и &quot;foobar&quot;.
* `max_results` (Optional[int]) — максимальное количество результатов, возвращаемых в ответе.
* `prefix` (Optional[str]) — фильтрует результаты, оставляя объекты, имена которых начинаются с указанного префикса.
* `start_offset` (Optional[str]) — фильтрует результаты, оставляя объекты, имена которых лексикографически равны `start_offset` или следуют за ним.
  Если задан `end_offset`, в список попадают объекты с именами между `start_offset` (включительно) и `end_offset` (не включая).

**Возвращает**:

* `List`(Object): список объектов, соответствующих заданным параметрам запроса.

<div id="upload_from_filename">

<div id="tipos-de-exceo">
  ### Типы исключений
</div>

* При работе с Replit App Storage через `Client` любой метод может вернуть одну из следующих ошибок:

  * `BucketNotFoundError`: указывает, что заданное имя бакета не соответствует ни одному бакету в App Storage.

  * `DefaultBucketError`: указывает на отсутствие настроек бакета по умолчанию.

  * `ForbiddenError`: указывает на нехватку прав для доступа к бакету.

  * `TooManyRequestsError`: указывает, что для операции сработало ограничение частоты запросов из-за их избыточного количества.

  * `UnauthorizedError`: указывает, что доступ к операции ограничен из-за авторизации.
