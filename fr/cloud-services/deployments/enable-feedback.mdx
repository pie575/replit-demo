---
title: "Activer le widget de commentaires"
description: "Apprenez à collecter des commentaires des visiteurs sur votre application publiée."
---

La collecte de commentaires peut être activée sur vos applications publiées pour recueillir des informations directement auprès des visiteurs et les envoyer directement à Agent. Lorsque les commentaires sont activés, les visiteurs peuvent soumettre des retours, y compris des captures d'écran et des fichiers, que vous pouvez gérer via votre Boîte de réception.

## Activer les commentaires

<Warning>
  Vous pouvez activer les commentaires uniquement sur les applications web. Vous ne pourrez pas l'activer pour d'autres types d'applications, comme les automatisations ou les applications mobiles.
</Warning>

Lors de la publication d'une nouvelle application, activez le paramètre **Activer les commentaires** dans la boîte de dialogue de publication. Si votre application est déjà publiée, vous pouvez activer les commentaires en republiant :

1. Ouvrez l'outil Publication
2. Sélectionnez **Paramètres avancés**
3. Activez **Activer les commentaires**
4. Republiez votre application

## Soumettre des commentaires

Lorsque les commentaires sont activés sur une application publiée, les visiteurs peuvent soumettre des retours directement depuis l'application. Les utilisateurs peuvent :

* Se connecter pour laisser des commentaires
* Laisser des commentaires textuels décrivant leur expérience ou leurs suggestions
* Sélectionner des éléments pour illustrer des problèmes ou des fonctionnalités
* Télécharger des fichiers pour fournir un contexte supplémentaire

## Gérer les commentaires dans votre Boîte de réception

Tous les commentaires soumis par les visiteurs apparaissent dans votre Boîte de réception, accessible depuis l'Éditeur de projet. Depuis la Boîte de réception, vous pouvez :

* **Ajouter au Chat** : Envoyer des commentaires à votre conversation avec Agent, pour ajouter du contexte avant de soumettre
* **Envoyer à Agent** : Envoyer immédiatement les commentaires à Agent et commencer le travail tout de suite
* **Résoudre** : Marquer les commentaires comme résolus une fois qu'ils ont été traités
* **Supprimer** : Supprimer les commentaires dont vous n'avez plus besoin

Vous pouvez également utiliser des filtres pour organiser et trouver des entrées de commentaires spécifiques.

## Republier avec des paramètres de commentaires mis à jour

Après la publication de votre application, vous pouvez activer ou désactiver le widget de commentaires à tout moment en republiant avec des paramètres mis à jour :

1. Ouvrez l'onglet **Vue d'ensemble** de l'outil Publication
2. Sélectionnez **Paramètres avancés**
3. Activez ou désactivez **Activer les commentaires**
4. Republiez votre application pour appliquer les modifications

Toute modification du paramètre de commentaires prend effet une fois l'application republiée.
