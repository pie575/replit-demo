<div id="o-que-um-projeto">
  ## Qu&#39;est-ce qu&#39;un projet ?
</div>

Un projet est le conteneur de tout ce que vous créez sur Replit. Il regroupe votre code, vos données et tous les artefacts que vous produisez : applications web, applications mobiles, présentations de diapositives, tableaux de bord de données et vidéos. Lorsque vous indiquez à Agent ce que vous souhaitez, il configure un projet et y construit les artefacts.

Voyez un projet comme un plan de travail sur votre bureau : tout se trouve au même endroit et peut partager les mêmes informations, mais chaque élément remplit un rôle différent.

Par exemple, si vous demandez à Agent de créer une application de suivi d&#39;activité physique, il crée un projet contenant un artefact d&#39;application mobile, ainsi que le backend, la base de données et le stockage nécessaires à son fonctionnement.

<ArtifactGrid />

Concepts clés :

* **Projet** : le conteneur qui regroupe tout — votre code, vos données et l&#39;ensemble de vos artefacts
* **Artefact** : un résultat publiable au sein d&#39;un projet (une application web, une présentation de diapositives, une vidéo, etc.)
* **Ressources** : chaque artefact bénéficie automatiquement d&#39;un backend, d&#39;une base de données et d&#39;un stockage de fichiers — aucune configuration nécessaire

<Note>
  La publication déploie l&#39;intégralité de votre projet en une seule fois. Tous les artefacts sont mis en ligne ensemble, ce qui garantit leur synchronisation permanente.
</Note>

<div id="o-que-voc-pode-construir">
  ## Ce que vous pouvez créer
</div>

| Type                                                                        | Description                                                                     | Exemple                                                                                       |
| --------------------------------------------------------------------------- | ------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| **[Application web](/fr/pt/features/artifact-types/web-apps)**                 | Un site ou une application web que l&#39;on consulte dans le navigateur         | Une boutique en ligne, un outil de réservation, un site portfolio                             |
| **[Application mobile](/fr/pt/features/artifact-types/building-mobile-apps)**  | Une application native que l&#39;on installe sur son téléphone                  | Un suivi de forme physique, une application de commande en restaurant                         |
| **[Visualisation de données](/fr/pt/features/artifact-types/data-apps)**       | Un tableau de bord interactif avec graphiques, filtres et données en temps réel | Un rapport de ventes, un suivi d&#39;indicateurs, une vue analytique                          |
| **[Présentation de diapositives](/fr/pt/features/artifact-types/slide-decks)** | Une présentation que vous pouvez projeter ou exporter                           | Un pitch deck, un point d&#39;équipe, une présentation de produit                             |
| **[Animation](/fr/pt/features/artifact-types/animated-videos)**                | Une vidéo en motion design que vous pouvez exporter en MP4                      | Une vidéo de lancement de produit, une vidéo explicative, du contenu pour les réseaux sociaux |
| **Jeu 3D**                                                                  | Un jeu 3D, une simulation ou une expérience interactive                         | Un jeu de réflexion, une simulation physique, une expérience interactive                      |
| **[Design](/fr/pt/design/canvas)**                                             | Des directions visuelles et du prototypage explorés sur le Canvas de design     | Des mood boards, des maquettes, de l&#39;exploration de design                                |

Un même projet peut contenir plusieurs artefacts. Par exemple, vous pouvez créer une application web pour vos clients, une application mobile pour votre équipe et une présentation de diapositives pour vos investisseurs — le tout dans le même projet. Lorsque les artefacts se trouvent dans le même projet, ils partagent automatiquement les mêmes données et la même logique backend. Pour en savoir plus, consultez [Artefacts](/fr/pt/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project).

<div id="gerenciando-seus-projetos">
  ## Gérer vos projets
</div>

Votre page Projets répertorie tous les projets que vous avez créés ou auxquels vous avez été invité. C&#39;est le moyen le plus rapide de reprendre vos travaux récents et de retrouver le bon projet dans un workspace bien rempli.

<div id="veja-rapidamente-o-que-h-em-cada-projeto">
  ### Voyez d&#39;un coup d&#39;œil ce que contient chaque projet
</div>

Chaque carte de projet affiche de petites icônes correspondant aux artefacts qu&#39;elle contient : application web, application mobile, présentation de diapositives, visualisation de données ou animation. Survolez une icône pour prévisualiser la capture d&#39;écran de cet artefact directement sur la carte, et distinguez ainsi vos projets sans avoir à les ouvrir.

<div id="filtre-por-artefato">
  ### Filtrer par artefact
</div>

Utilisez le menu déroulant **Type de build** en haut de la page Projets pour filtrer votre liste par artefact. Sélectionnez-en un pour n&#39;afficher que les projets contenant ce type d&#39;artefact :

* **Web** — les projets contenant une application web
* **Mobile** — les projets contenant une application mobile
* **Data** — les projets contenant une visualisation de données
* **Slides** — les projets contenant une présentation de diapositives
* **Design** — les projets en mode Design
* **Jeu 3D**, **Agent et Automatisation**, et bien d&#39;autres

Sélectionnez **Tout type de build** pour effacer le filtre.

<div id="ordene-por-ltima-abertura">
  ### Trier par dernière ouverture
</div>

Par défaut, la page Projets est triée par **dernière ouverture par vous** : les projets sur lesquels vous avez passé le plus de temps récemment s&#39;affichent en haut. C&#39;est particulièrement utile dans les workspaces d&#39;équipe, où les modifications récentes des autres membres reléguraient sinon votre travail en cours en bas de liste.

Vous pouvez modifier le tri en sélectionnant un autre en-tête de colonne (par exemple, **Dernière mise à jour** ou **Nom**).

<div id="fixe-os-projetos-que-voc-mais-usa">
  ### Épinglez les projets que vous utilisez le plus
</div>

Épinglez un projet pour le garder en haut de votre liste. Les épinglages sont **visibles par vous seul** — épingler un projet dans un workspace d&#39;équipe ne change rien à ce que voient les autres membres.

Pour épingler un projet, ouvrez le menu d&#39;options (trois points) sur la carte du projet et sélectionnez **Épingler**. Sélectionnez **Désépingler** dans ce même menu pour annuler l&#39;épinglage.
