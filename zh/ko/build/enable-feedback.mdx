---
title: "启用反馈小组件"
description: "了解如何收集已部署的应用访客的反馈。"
---

在已部署的应用中启用反馈收集后，您可以直接收集访客的意见，并立即发送给 Agent。启用后，访客可以提交包含截图和文件的反馈，您可以在收件箱中进行管理。

<div id="section">
  ## 启用反馈
</div>

<Warning>
  反馈功能仅可在 Web 应用中启用，无法用于自动化、移动应用等其他类型的应用。
</Warning>

部署新应用时，请在发布对话框中开启 **Enable Feedback**。如果应用已部署，可通过重新部署启用反馈功能。

1. 打开 Publishing 工具
2. 选择 **Advanced Settings**
3. 开启 **Enable Feedback**
4. 重新部署应用

<div id="section-2">
  ## 提交反馈
</div>

在已部署的应用中启用反馈功能后，访问者可以直接在应用内提交反馈。用户可以：

* 登录后提交反馈
* 提交描述使用体验或建议的文字反馈
* 选择元素来说明问题或功能需求
* 上传文件以提供更多背景信息

<div id="section-3">
  ## 在收件箱中管理反馈
</div>

访客提交的所有反馈都会显示在可通过 Project Editor 访问的收件箱中。你可以在收件箱中执行以下操作：

* **添加到聊天**：将反馈发送到与 Agent 的聊天中，以便在提交前补充上下文
* **发送给 Agent**：立即将反馈发送给 Agent 并开始处理
* **解决**：处理完反馈后，将其标记为已解决
* **删除**：移除不再需要的反馈

你还可以使用筛选条件整理和查找特定的反馈条目。

<div id="section-4">
  ## 使用更新后的反馈设置重新部署
</div>

应用部署后，您可以随时使用更新后的设置重新部署，以启用或禁用反馈小组件。

1. 打开 Publishing 工具中的 **Overview** 标签页
2. 选择 **Advanced Settings**
3. 启用或禁用 **Enable Feedback**
4. 重新部署应用以应用更改

重新部署应用后，反馈设置更改将生效。
