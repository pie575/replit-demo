Conversation 是一条独立的对话线程，可用于提问、查找信息、运行 Routine 以及描述你想要的结果。在 Replit 中，每项任务都从一次对话开始。

<Note>
  Conversation 是私密的，只有你本人可以在 工作区 中访问。如需协作，请让
  Replit 创建一个 Project。
</Note>

<div id="conversations-vs-projects">
  ## Conversation 与 Project 的区别
</div>

Conversation 是用于提问、探索和运行 Routine 的单个会话线程。[Project](/zh/features/projects-and-artifacts/projects) 则是更完整的工作区，适合较大规模的构建和设计工作，可包含多个 artifact。

建议先从 Conversation 开始。当工作逐渐发展为较大规模的构建或设计任务时，可以将 Conversation 转为 Project。

在侧边栏中，Conversation 显示为聊天气泡图标，Project 显示为四宫格图标。

<Frame>
  <img src="/assets/mirror/conversation-and-project-icons-025a17613daa.png" alt="Replit 侧边栏中显示使用四宫格图标的 Project 和使用聊天气泡图标的 Conversation" width="466" height="290" data-path="images/chat/conversation-and-project-icons.png" />
</Frame>

| 方面      | Conversation   | Project                              |
| ------- | -------------- | ------------------------------------ |
| 适用场景    | 提问、探索和 Routine | 更深入的构建与设计工作，如应用、幻灯片、仪表板以及多个 artifact |
| 后台任务    | **不支持**        | **可并行运行**                            |
| Routine | **支持**         | **不支持**                              |
| 集成      | 支持             | 支持                                   |
| 结构      | 单个会话线程         | 包含多个 artifact 的项目工作区                |
