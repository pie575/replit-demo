Превратите приложение в полноценный сайт с пользовательским доменом.

С помощью Domain Purchasing можно искать, покупать и подключать домены, не выходя из Replit. Всего за несколько минут превратите опубликованное приложение в профессиональный веб-сайт.

Например, вы можете купить домен вроде `my-app.com` и автоматически направить его на своё приложение.

<div id="section">
  ## Возможности
</div>

Domain Purchasing упрощает добавление профессионального веб-адреса для вашего приложения. Не нужно пользоваться несколькими сервисами: всё необходимое для настройки веб-присутствия доступно в Replit.

<Frame>
  <img src="/assets/mirror/replit-domains-8453291b634b.png" alt="Интерфейс управления доменами с приобретёнными доменами и статусом их подключения" width="3176" height="1556" data-path="images/deployments/custom-domains/replit-domains.png" />
</Frame>

Основные возможности:

* **Поиск и проверка доступности доменов**: проверяйте доступность доменов с популярными расширениями, такими как `.com` и `.ai`
* **Покупка в один клик**: приобретайте домены напрямую в Replit, используя способ оплаты по умолчанию для вашей учётной записи
* **Автоматическая настройка**: домен сразу будет указывать на ваше приложение Replit без ручной настройки DNS
* **Защита конфиденциальности WHOIS**: ваши личные данные по умолчанию скрыты в общедоступной информации о домене. Эта функция включена во все покупки доменов
* **Пользовательские DNS-записи**: добавляйте записи A, TXT и MX для настройки таких сервисов, как почтовые провайдеры
* **Мгновенная публикация**: ваше приложение будет доступно по пользовательскому домену сразу после покупки
* **Автоматическое продление**: домен продлевается автоматически, чтобы ваше приложение оставалось доступным без перерывов

<div id="section-2">
  ## Использование
</div>

<div id="section-3">
  ### Покупка домена
</div>

1. Опубликуйте приложение и перейдите на вкладку <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Иконка Publish" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publishing**
2. Выберите вкладку **Domains**
3. Выберите **Buy a domain**, чтобы начать поиск
4. Введите желаемое доменное имя в строку поиска
5. Просмотрите доступные варианты с разными расширениями
6. Выберите нужный домен и завершите покупку

После покупки домен будет автоматически настроен на приложение Replit. Вы сможете сразу получить доступ к приложению по пользовательскому домену без дополнительной настройки.

Стоимость домена будет списана с баланса вашей учётной записи Replit и учтена в расходах на использование.

<div id="section-4">
  ### Управление приобретёнными доменами
</div>

Домены без проблем работают с опубликованными приложениями:

* **Автоматическое продление**: домены автоматически продлеваются, чтобы ваше приложение оставалось доступным
* **Единый биллинг**: стоимость доменов отображается в счёте Replit вместе с другими сервисами
* **Поддержка переноса**: при необходимости вы можете перенести домены между аккаунтами Replit или к внешнему регистратору

<div id="dns">
  ### Пользовательские записи DNS
</div>

Для доменов, приобретённых через Replit, можно добавлять пользовательские записи DNS для настройки дополнительных сервисов, например почтовых провайдеров. Поддерживаются следующие типы записей DNS:

* **A-запись**: направляет домен или поддомен на определённый IP-адрес
* **TXT-запись**: добавляет текстовые записи для проверки сервисов аутентификации электронной почты, таких как SPF, DKIM и DMARC
* **MX-запись**: MX-записи (Mail Exchange) указывают почтовым серверам, куда доставлять письма, отправленные на ваш домен. Настроив MX-записи, вы сможете использовать адрес электронной почты с пользовательским доменом, например `hello@yourdomain.com`.

Чтобы управлять записями DNS приобретённого домена:

1. Перейдите на вкладку **Domains** в Publishing <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Иконка Publish" width="16" height="16" data-path="images/icons/deploy-icon.svg" />
2. Найдите домен, который хотите настроить
3. Выберите иконку **Edit** <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="иконка карандаша" width="16" height="16" data-path="images/icons/pencil-icon.svg" />
4. Выберите **Add DNS Record**
5. Введите тип записи, имя, значение и TTL в соответствии с инструкциями поставщика услуг

  ### Поддерживаемые типы развёртывания

<div id="section-6">
  ## Часто задаваемые вопросы
</div>

<AccordionGroup>
  <Accordion title="Сколько это стоит?">
    При покупке домена предусмотрены два вида платежей:

    * **Регистрационный сбор**: первоначальная плата за владение доменом в течение одного года (для доменов `.ai` — в течение двух лет)
    * **Стоимость продления**: списывается автоматически после окончания первоначального периода регистрации

    Replit не взимает дополнительную плату за покупку домена. Регистрационный сбор за домен не подлежит возврату.
  </Accordion>

  <Accordion title="Как продлить домен?">
    Replit автоматически продлевает домены, чтобы ваше приложение оставалось доступным. Чтобы отключить автоматическое продление, откройте вкладку **Domains** в разделе Publishing, выберите домен и выключите переключатель **Auto renewal**. На этом же экране можно посмотреть дату и стоимость продления домена.
  </Accordion>

  <Accordion title="Что произойдет, если я решу уйти с Replit?">
    Вы можете перенести домен к другому регистратору, обратившись в Replit Support. Согласно правилам ICANN, в течение 60 дней после покупки домен нельзя перенести к внешнему регистратору.
  </Accordion>

  <Accordion title="Можно ли перенести домен между аккаунтами Replit?">
    Да, вы можете перенести домен между аккаунтами Replit, обратившись в Replit Support. Для этой процедуры не требуется 60-дневный период ожидания.
  </Accordion>

  <Accordion title="Можно ли купить домен для организации?">
    Domain Purchasing для планов Replit Pro и Enterprise станет доступна после завершения начального периода бета-тестирования.
  </Accordion>

  <Accordion title="Можно ли добавить пользовательские DNS-записи для домена?">
    Да! Вы можете добавлять пользовательские DNS-записи для доменов, приобретенных через Replit. Сейчас поддерживаются следующие типы записей:

    * **A-запись**: направляет домен или поддомен на определенный IP-адрес
    * **TXT-запись**: добавляет текстовые записи для проверки подлинности электронной почты и других сервисов
    * **MX-запись**: настраивает почтовые серверы, обрабатывающие почту для домена

    Чтобы настроить эти записи, перейдите на вкладку Domains в Publishing. Подробные инструкции по настройке почты с помощью MX-записей см. в разделе [Пользовательские DNS-записи](#custom-dns-records) выше.
  </Accordion>

  <Accordion title="Какие доменные зоны поддерживаются?">
    Мы поддерживаем все распространенные домены верхнего уровня (TLD). TLD с географическими или другими специальными ограничениями не поддерживаются.
  </Accordion>

  <Accordion title="Что такое защита конфиденциальности WHOIS?">
    При регистрации домена ваша контактная информация (имя, адрес, номер телефона и адрес электронной почты) обычно публикуется в общедоступной базе данных WHOIS, где ее может найти любой пользователь. Защита конфиденциальности WHOIS скрывает вашу информацию, заменяя ее общими данными регистратора и при этом соблюдая юридические требования.

    Защита конфиденциальности WHOIS включена по умолчанию без дополнительной платы для всех доменов, приобретенных через Replit. Это защищает вашу личную информацию от спамеров, маркетологов и других лиц, которые могут пытаться найти сведения о владельце домена.
  </Accordion>

  <Accordion title="Что делать, если у меня уже есть домен?">
    Чтобы подключить существующий домен к приложению Replit, ознакомьтесь с документацией по [пользовательским доменам](/ru/ja/features/publishing/custom-domains).
  </Accordion>
</AccordionGroup>
