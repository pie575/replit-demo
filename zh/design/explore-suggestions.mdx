建议是 Replit Design 界面的核心。你无需面对空白的提示框，苦思冥想该提出什么要求；只需选择一个设计 frame，Replit Design 就会建议下一步可以尝试什么。每条建议只需一键即可生成新的设计方向。

<div id="how-suggestions-work">
  ## 建议的使用方式
</div>

选择生成的设计 frame 后，其旁边会显示相关建议。这些建议基于你当前查看的内容，因此无需掌握设计术语也能轻松探索。点击任一建议，Replit Design 会将结果生成为新的 frame；原始 frame 会保持不变。

<div id="what-suggestions-propose">
  ## 建议内容
</div>

建议可帮助你从不同角度探索设计：

* **全新外观**：以不同方向呈现同一设计，例如深色编辑风格变体或不同的布局。
* **扩展内容**：设计所暗示但尚未包含的版块或页面，例如定价版块或联系页面。
* **全新场景**：将设计应用于其他场景，例如移动端视口。

<div id="explore-with-suggestions">
  ## 通过建议探索
</div>

这一流程特意设计得很简短：

<Steps>
  <Step title="选择生成的 frame">
    点击 Canvas 上任意一个生成的设计 frame。

    <Frame>
      <img src="/assets/mirror/ambient-select-frame-7147427722bd.png" alt="Canvas 上一个名为 APEX X1 Exact Replica 的 Design frame，展示灰色超级跑车的主视觉页面" width="2000" height="1252" data-path="images/design/replit-design/ambient-select-frame.png" />
    </Frame>
  </Step>

  <Step title="选择建议">
    建议会显示在所选 frame 旁，并根据你当前查看的内容生成。查看后点击其中一项即可，无需额外输入任何内容。
  </Step>

  <Step title="点击后 Agent 即开始构建">
    点击后，Agent 会立即将该建议构建为原始 frame 旁的新 frame。之前的 frame 会保留在 Canvas 上，因此你可以放心探索，不会丢失任何内容。

    <Frame>
      <img src="/assets/mirror/ambient-suggestion-building-9da4835557d2.png" alt="一个名为“Add Saturation on Scroll”的新 Design frame 正以骨架布局呈现，并显示“Building…”指示器，位于原始 APEX X1 frame 旁边" width="2000" height="1252" data-path="images/design/replit-design/ambient-suggestion-building.png" />
    </Frame>
  </Step>

  <Step title="查看更改">
    完成后的 frame 会显示在原始 frame 旁边，方便你并排比较。Chat 面板会汇总更改内容。

    <Frame>
      <img src="/assets/mirror/ambient-suggestion-result-a50d1efa94c4.png" alt="Canvas 上并排显示两个已完成的 Design frame：原始 APEX X1 Exact Replica 和完成的 Add Saturation on Scroll 变体，Chat 面板中显示“Run complete”摘要" width="2000" height="1189" data-path="images/design/replit-design/ambient-suggestion-result.png" />
    </Frame>
  </Step>

  <Step title="将最佳设计应用到你的应用">
    不断选择和分支，直到找到合适的方向；无论选择哪个 frame，都会出现新的建议。最佳方案不必一直只是模型：选择它，在操作栏中点击 **Build…**，然后在 **Apply to an existing creation** 下选择现有应用。Agent 会重写应用代码以匹配该设计，同时将 frame 保留在 Canvas 上供你参考。

    <Frame caption="Build 菜单：将最佳 frame 应用到已有的应用。">
      <img src="/assets/mirror/explore-variants-apply-b04b893252cd.png" alt="在选定变体上打开的 Build 菜单，包含两个选项：“Build this design”（创建新的 artifact）和“Apply to an existing creation”（列出项目的 Website artifact）" width="2000" height="1226" data-path="images/design/replit-design/explore-variants-apply.png" />
    </Frame>

    完整流程 (包括将 frame 构建为新应用) 请参阅[构建设计](/zh/design/build-your-design)。如需在应用前完善细节，请[使用 Chat 优化设计](/zh/design/chat-about-your-design)。
  </Step>
</Steps>

<div id="tips">
  ## 提示
</div>

* **按方向探索，而非按步骤推进。** 建议会分叉；选择其中一个并不意味着你就此确定方向。生成几个建议，在 Canvas 上比较。
* **加入你自己的想法。** 建议与[设计聊天框](/zh/design/chat-about-your-design)可配合使用：点击建议可进行广泛探索，通过 Chat 可精准引导。Chat 不仅用于润色；像 *“尝试将导航栏放在左侧”* 这样的消息也能开启新方向。
* **切换模型，获得不同的设计感。** 每个模型的探索方式各不相同；请参阅[使用不同模型探索](/zh/design/explore-with-different-models)。
