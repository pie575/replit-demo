⏰ *Durée estimée : 5 minutes*

Découvrez comment créer des applications Replit directement depuis ChatGPT grâce à l’intégration Replit. Cette intégration intègre l’environnement de développement Replit à votre flux de travail dans ChatGPT, ce qui vous permet de :

* Créer des applications complètes à partir de descriptions en langage naturel
* Initialiser des projets sans quitter ChatGPT
* Passer facilement à Replit pour poursuivre le développement

<div id="aplicativos-no-chatgpt">
  ## Applications dans ChatGPT
</div>

Replit est le moyen le plus rapide de transformer vos idées en application en ligne. Vous pouvez désormais le faire sans quitter ChatGPT.

Les applications dans ChatGPT vous permettent de connecter des outils et services externes directement à la conversation. Au lieu de passer d&#39;un onglet à l&#39;autre ou de copier du contexte, vous pouvez demander à ChatGPT d&#39;agir dans les outils que vous utilisez déjà.

L&#39;application Replit vous permet de créer et de lancer de véritables applications directement depuis ChatGPT, le code étant hébergé dans l&#39;éditeur de projets.

Suivez les étapes ci-dessous pour créer votre première application Replit dans ChatGPT, ou essayez dès maintenant en cliquant sur le bouton ci-dessous.

<Card title="Essayez maintenant" icon="rocket" href="https://chatgpt.com?prompt=build+me+a+cool+app+with+%40replit">
  Créez une application avec Replit directement dans ChatGPT
</Card>

<Steps>
  <Step title="Ouvrez une conversation dans ChatGPT">
    Démarrez une nouvelle conversation ou poursuivez une conversation existante dans ChatGPT.
  </Step>

  <Step title="Décrivez ce que vous souhaitez créer et invoquez @Replit">
    Dans le champ de saisie du chat, décrivez votre idée d&#39;application et mentionnez `@Replit` pour invoquer l&#39;application Replit.

    Exemple de prompt :

    ```text theme={null}
    Créez une belle application pour partager l'addition au restaurant @Replit
    ```

    <Frame>
      <img src="/assets/mirror/quickstart_replit_app_chatgpt_prompt-84b24a8d2769.png" alt="Conversation dans ChatGPT avec un prompt pour créer une application de partage d'addition à l'aide de @Replit" width="3392" height="1748" data-path="images/getting-started/quickstart_replit_app_chatgpt_prompt.png" />
    </Frame>
  </Step>

  <Step title="ChatGPT crée le projet directement dans Replit">
    ChatGPT utilisera l&#39;application Replit pour créer votre projet. Vous verrez l&#39;application se générer en temps réel.

    <Frame>
      <img src="/assets/mirror/quickstart_replit_app_chatgpt_plan-e0f56622fbb1.png" alt="ChatGPT planifiant la structure de l'application" width="3392" height="1748" data-path="images/getting-started/quickstart_replit_app_chatgpt_plan.png" />
    </Frame>

    <Frame>
      <img src="/assets/mirror/quickstart_replit_app_chatgpt_execution-2696b7059d62.png" alt="ChatGPT exécutant et créant l'application dans Replit" width="3392" height="1748" data-path="images/getting-started/quickstart_replit_app_chatgpt_execution.png" />
    </Frame>
  </Step>

  <Step title="Ouvrez et publiez votre application">
    Une fois le projet créé, ouvrez-le dans Replit pour modifier, exécuter et publier votre application.

    <Frame>
      <img src="/assets/mirror/quickstart_replit_app_chatgpt_result-2b368a32c3dd.png" alt="L'application de partage d'addition terminée dans Replit" width="3392" height="1748" data-path="images/getting-started/quickstart_replit_app_chatgpt_result.png" />
    </Frame>
  </Step>
</Steps>

Ce flux de travail est particulièrement adapté au prototypage : vous pouvez passer d&#39;une idée à une application fonctionnelle en quelques minutes, puis itérer à l&#39;aide des outils habituels de Replit.
