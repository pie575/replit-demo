게시된 앱에서 피드백 수집을 활성화하면 방문자의 의견을 직접 받아 Agent로 바로 전달할 수 있습니다. 피드백이 활성화되면 방문자는 스크린샷과 파일을 첨부해 피드백을 제출할 수 있으며, 제출된 내용은 Inbox에서 관리할 수 있습니다.

<div id="enabling-feedback">
  ## 피드백 활성화하기
</div>

<Warning>
  피드백은 web app에서만 활성화할 수 있습니다. 자동화나 mobile app 등 다른 종류의 app에서는 활성화할 수 없습니다.
</Warning>

새 app을 게시할 때 게시 대화 상자에서 **Enable Feedback** 설정을 켜세요. 이미 게시한 app이라면 다시 게시하여 피드백을 활성화할 수 있습니다.

1. Publishing 도구를 엽니다
2. **Advanced Settings**를 선택합니다
3. **Enable Feedback**을 켭니다
4. app을 다시 게시합니다

<Warning>
  게시된 앱에 피드백 위젯이 표시되지 않으면 페이지를 새로고침해 보세요
</Warning>

<div id="submitting-feedback">
  ## 피드백 제출하기
</div>

게시된 앱에서 피드백이 활성화되어 있으면 방문자가 앱에서 직접 피드백을 제출할 수 있습니다. User는 다음 작업을 할 수 있습니다.

* 로그인하여 피드백 남기기
* 사용 경험이나 제안을 설명하는 텍스트 피드백 남기기
* 요소를 선택해 issues나 기능 설명하기
* 파일을 upload하여 추가 context 제공하기

<div id="managing-feedback-in-your-inbox">
  ## Inbox에서 피드백 관리하기
</div>

방문자가 제출한 모든 피드백은 Project Editor 안에서 열 수 있는 Inbox에 표시됩니다. Inbox에서는 다음 작업을 할 수 있습니다.

* **Add to Chat**: 피드백을 Agent와의 Chat으로 보내 제출하기 전에 context를 추가합니다
* **Send to Agent**: 피드백을 Agent에게 바로 보내 즉시 작업을 시작합니다
* **Resolve**: 처리가 끝난 피드백을 해결됨으로 표시합니다
* **Delete**: 더 이상 필요하지 않은 피드백을 삭제합니다

filter를 사용해 특정 피드백 항목을 정리하거나 찾을 수도 있습니다.

<div id="republishing-with-updated-feedback-settings">
  ## 업데이트된 피드백 설정으로 다시 게시하기
</div>

App을 publish한 후에도 설정을 변경한 뒤 republish하면 언제든지 피드백 위젯을 켜거나 끌 수 있습니다.

1. Publishing 도구에서 **Overview** tab을 엽니다
2. **Advanced Settings**를 선택합니다
3. **Enable Feedback**을 켜거나 끕니다
4. App을 republish하여 changes를 적용합니다

피드백 설정의 changes는 App을 republish한 후에 적용됩니다.
