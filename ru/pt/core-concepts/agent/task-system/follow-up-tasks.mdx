<div id="sugestes-de-tarefas-de-acompanhamento">
  ## Предложения последующих задач
</div>

После применения задачи Agent анализирует контекст проекта и предлагает **последующие задачи**, которые вы можете создать далее. В диалоговом окне **Предлагаемые следующие задачи** основная рекомендация отображается прямо в нём, чтобы вы могли продолжить работу, не покидая основного thread.

<Frame>
  <img src="/assets/mirror/follow-up-tasks-dialog-c1660cec2d1d.png" alt="Диалоговое окно предлагаемых следующих задач с последующей задачей, кнопкой «Начать» и ссылкой для просмотра других задач на доске задач" width="495" height="290" data-path="images/agent/follow-up-tasks-dialog.png" />
</Frame>

Предложения последующих задач могут включать:

* **Новые возможности для создания**: функции, которые естественно дополняют то, что вы только что запустили
* **Улучшения производительности**: оптимизации, которые Agent заметил во время работы над задачей
* **Улучшения пользовательского опыта**: доработки и улучшения, завершающие функциональность

Выберите **Начать** в предложении, чтобы запустить его в фоновом режиме, или **Просмотреть план**, чтобы сначала изучить предложенную работу. Чтобы просмотреть все предложения, выберите **Посмотреть больше на доске задач**. Предложенные последующие задачи отображаются в разделе **Предложенные** столбца **Черновики**.

<Frame>
  <img src="/assets/mirror/follow-up-tasks-kanban-21087e0210b6.png" alt="Доска задач с несколькими предложениями последующих задач в разделе «Предложенные» столбца «Черновики»" width="980" height="627" data-path="images/agent/follow-up-tasks-kanban.png" />
</Frame>

Закрытие диалогового окна **Предлагаемые следующие задачи** отменяет предложения. Agent не показывает это диалоговое окно в основном thread, если там уже ожидает предложенный план, чтобы два prompt не конкурировали за ваше внимание.

<div id="gerenciando-muitas-sugestes-de-uma-vez">
  ## Управление несколькими предложениями одновременно
</div>

Если в проекте много предложенных последующих задач, откройте доску задач и нажмите **Редактировать** в столбце **Черновики**. В режиме редактирования у каждой предложенной задачи появляется флажок. Выберите нужные задачи и нажмите **Начать** или **Отменить**, чтобы выполнить это действие для всех выбранных задач. Нажмите **Concluído**, чтобы выйти из режима редактирования.
