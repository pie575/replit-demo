<div id="replitmd-documentation">
  ### Документация replit.md
</div>

Настройте поведение Agent с помощью `replit.md` — специального файла конфигурации, который помогает Agent разобраться в предпочтениях вашего проекта, стиле написания кода и архитектуре. Agent автоматически создаёт этот файл на основе проверенных лучших практик, а затем использует его, чтобы создавать приложения, точно соответствующие вашим требованиям. Передавайте Agent контекст проекта, задавайте стандарты написания кода, указывайте предпочитаемый технологический стек и настраивайте параметры общения — всё в одном месте.

<div id="deployment-privacy-indicators">
  ### Индикаторы приватности развёртывания
</div>

Новые визуальные индикаторы на панели Deployments позволяют сразу увидеть, какие из ваших deployment публичные, а какие — приватные. Это избавляет от путаницы: вы точно знаете, кто имеет доступ к вашим опубликованным приложениям.

<div id="agent-multi-tool-calling-upgrade">
  ### Улучшение множественных вызовов инструментов в Agent
</div>

Экономьте 15% затрат на Agent и получайте результаты на 30% быстрее благодаря усовершенствованной системе множественных вызовов инструментов. Теперь Agent эффективнее объединяет операции в пакеты и умнее обрабатывает ошибки инструментов, обеспечивая то же качество результатов при меньшем расходе ресурсов.
