---
title: "多个产物与独立项目"
description: "了解何时应将多个产物归入一个项目，以及何时应在 Replit 中创建独立项目。"
---

[项目](/zh/ja/features/projects-and-artifacts/projects)是容纳你在 Replit 中构建的一切内容的容器。项目包括设计、应用、幻灯片、数据以及你创建的所有内容。
[产物](/zh/ja/features/projects-and-artifacts/artifacts)是项目中可发布的成果，例如 Web 应用、移动应用、幻灯片和视频。

当你要构建多个内容时，有两种选择：

* 在一个项目中添加多个产物
* 或者，创建独立项目

选择哪种方式取决于你的应用是否共享数据、逻辑和部署生命周期。本指南将说明何时应将多个产物归入一个项目，以及何时应分别创建独立项目。

<div id="section">
  ## 项目内产物共享的资源
</div>

当[产物](/zh/ja/features/projects-and-artifacts/artifacts)位于同一[项目](/zh/ja/features/projects-and-artifacts/projects)中时，会自动共享以下资源：

* **数据库**：一个产物写入数据后，其他产物可立即读取
* **后端和 API**：共享服务器端逻辑，无需重复编写代码
* **文件存储**：产物之间可访问图片、文档和上传内容
* **部署**：发布时，所有内容会保持同步并一同部署

这意味着无需在产物之间配置连接或重复编写代码。不过，无法只发布单个产物而不发布其他产物。

<div id="section-2">
  ## 快速指南
</div>

以下列出了在现有项目中添加产物，还是创建单独项目时的主要适用场景。

| **在一个项目中使用多个产物**        | **使用单独项目**               |
| ----------------------- | ------------------------ |
| 应用共享相同的数据和后端            | 应用不共享底层逻辑或数据             |
| 希望将所有内容一起部署             | 需要独立的部署周期                |
| 彼此互补 (例如面向客户的应用和管理控制台)  | 无关的产品，或面向不同客户的产品         |
| 希望一个产物的更改能自动反映到其他产物     | 项目生命周期较短 (例如活动落地页或活动网站)  |

<div id="section-3">
  ## 示例
</div>

<div id="1">
  ### 同一项目：同一产品的 Web 应用和移动应用
</div>

一家餐厅正在开发一个供顾客浏览菜单的 Web 应用，以及一个供员工管理订单的移动应用。这两个应用都连接到同一个包含菜单项、订单和客户信息的数据库。

**使用同一项目的原因：** 这两个应用共享相同的数据和后端。顾客通过 Web 应用下单后，员工可以立即在移动应用中查看。

<div id="section-4">
  ### **同一个项目**：应用＋管理控制台＋面向投资者的幻灯片演示文稿
</div>

一家初创公司在同一个项目中构建主产品、用于内容管理的内部管理面板，以及用于融资的幻灯片演示文稿。

**使用同一个项目的原因：** 管理控制台管理着应用所显示的数据，幻灯片演示文稿则可以从共享后端获取实时指标。

<div id="2">
  ### **独立的项目**：两个互不相关的客户端应用
</div>

一名自由职业者正在为一位客户搭建电商店铺，并为另一位客户开发预约系统。

**使用独立项目的原因：** 两个应用之间没有共享的数据或逻辑。每位客户都需要独立部署，并且必须确保对一个应用的修改不会影响另一个应用。

<div id="section-5">
  ### **独立项目**：与主产品并行的营销活动落地页
</div>

您有一个全年运行的生产应用，以及用于营销活动的短期落地页。

**使用独立项目的原因：** 活动页面有自己的生命周期。上线后运行几周，再将其下线。将它们分开，可以避免主产品中混入多余内容，并可独立发布或删除。

<div id="section-6">
  ## 常见问题
</div>

<Accordion title="可以将产物移至其他项目吗？">
  目前不支持。如果需要将产物分开，请创建一个新的[项目](/zh/ja/features/projects-and-artifacts/projects)，然后让 Agent 在其中重新构建。
</Accordion>

<Accordion title="一个项目可包含的产物数量是否有限制？">
  一个项目最多可包含 7 个产物。之所以设置这一限制，是因为产物越多，消耗的内存越多，预览速度也可能变慢。如果需要更多产物，请创建另一个[项目](/zh/ja/features/projects-and-artifacts/projects)。
</Accordion>

<Accordion title="可以只发布项目中的一个产物吗？">
  目前不支持。发布时，所有内容都会一并部署。如需独立部署，请使用不同的项目。
</Accordion>
