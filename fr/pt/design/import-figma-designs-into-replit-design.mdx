⏰ *Temps estimé : 15 minutes*

Un design Figma montre à quoi doit ressembler l’expérience. Replit Design transforme un frame Figma en frame de design que vous pouvez explorer, affiner et convertir en app interactive.

Vous utiliserez le [Personal Fitness Trainer Template](https://www.figma.com/community/file/1569006333493544411) de Figma Community comme exemple.

<div id="antes-de-comear">
  ## Avant de commencer
</div>

Vous aurez besoin de :

* Un [compte Replit](https://replit.com).
* Un compte [Figma](https://www.figma.com) contenant le fichier à importer ou le fichier d’exemple ci-dessus.

<div id="importe-o-frame-do-figma">
  ## Importez un frame depuis Figma
</div>

Importez le frame dans Replit Design et laissez Agent le transformer en maquette fonctionnelle.

<Steps>
  <Step title="Obtenez le lien vers votre frame Figma">
    Utilisez votre propre fichier Figma ou suivez l&#39;exemple de ce guide : le [Personal Fitness Trainer Template](https://www.figma.com/community/file/1569006333493544411) sur Figma Community.

    Dans Figma, faites un clic droit sur le frame que vous souhaitez importer, choisissez **Copy/Paste as**, puis **Copy link to selection**.

    <Frame caption="Le Personal Fitness Trainer Template ouvert dans Figma, avec les frames Cover que vous allez importer.">
      <img src="/assets/mirror/figma-example-file-65988c40d28d.webp" alt="Le Personal Fitness Trainer Template ouvert dans Figma, affichant les frames Cover dans le panneau des calques et sur le canevas" width="3440" height="2160" data-path="images/fitstart/turn-mockup-into-app/figma-example-file.webp" />
    </Frame>
  </Step>

  <Step title="Ouvrez Replit Design">
    Accédez à [replit.com/design](https://replit.com/design) et sélectionnez **Import Figma** sous le champ de prompt.

    <Frame caption="Import Figma sur la page d'accueil de Replit Design : importez un frame Figma et Agent le transforme en maquette fonctionnelle.">
      <img src="/assets/mirror/design-import-figma-0a98172e147e.webp" alt="La page d'accueil de Replit Design avec l'option Import Figma sélectionnée sous le champ de prompt et une info-bulle indiquant « Importez un frame Figma et Agent le transformera en maquette fonctionnelle »" width="2293" height="1322" data-path="images/fitstart/turn-mockup-into-app/design-import-figma.webp" />
    </Frame>
  </Step>

  <Step title="Collez l'URL et commencez à créer">
    Collez l&#39;URL de votre frame dans la boîte de dialogue **Import Figma design** et sélectionnez **Attach to prompt**. Le frame est joint à votre prompt ; envoyez-le pour commencer à créer.

    <Frame caption="La boîte de dialogue Import Figma design avec l'URL du frame collée, prête à être jointe au prompt.">
      <img src="/assets/mirror/design-figma-url-8425e5d8d46d.webp" alt="La boîte de dialogue Import Figma design dans Replit Design avec une URL de frame Figma collée dans le champ et le bouton Attach to prompt" width="2293" height="1440" data-path="images/fitstart/turn-mockup-into-app/design-figma-url.webp" />
    </Frame>
  </Step>
</Steps>

Agent importe le frame et le reconstruit sous forme de frame de design dans votre projet.

<Frame caption="La page de destination Personal Fitness Trainer importée comme frame dans Replit Design.">
  <img src="/assets/mirror/figma-import-result-052394025b8d.webp" alt="La page de destination Personal Fitness Trainer importée comme frame de design dans Replit Design, avec l'exécution indiquée comme terminée dans le panneau de Chat" width="3440" height="2160" data-path="images/fitstart/turn-mockup-into-app/figma-import-result.webp" />
</Frame>

<div id="deixe-do-seu-jeito">
  ## Personnalisez-le à votre guise
</div>

Sélectionnez le frame importé et commencez à le transformer :

* **Suivez une [suggestion](/fr/pt/design/explore-suggestions)** : l’importation inclut déjà des suggestions pour la suite, comme une variante éditoriale sombre, une section de tarifs ou un affichage mobile. Chacune génère un nouveau frame, afin que l’original reste disponible à des fins de comparaison.
* **[Discutez-en](/fr/pt/design/chat-about-your-design)** : utilisez le champ sous le frame et décrivez avec vos propres mots ce que vous souhaitez, *« remplace la photo principale »*, *« rends l’appel à l’action plus percutant »*.
