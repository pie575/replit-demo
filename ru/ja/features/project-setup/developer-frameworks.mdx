<div id="section">
  ## Что такое фреймворки для разработчиков?
</div>

Фреймворки для разработчиков — это приложения Replit, опубликованные платформой или сообществом в качестве отправной точки для других пользователей. У официальных фреймворков для разработчиков от Replit рядом с названием отображается значок с галочкой:

<Frame>
  <img src="/assets/mirror/template-official-c5fe09e20415.png" alt="Официальный фреймворк для разработчиков Replit" width="1051" height="246" data-path="images/programming-ide/creating-a-template/template-official.png" />
</Frame>

[Шаблон HTML, CSS, JS](https://replit.com/@replit/HTML-CSS-JS?v=1#index.html) очень популярен и может служить отправной точкой для создания проектов на чистом JavaScript. Вы можете сделать его форк и использовать.

<div id="enterprise">
  ## Пользовательские шаблоны Enterprise
</div>

Организации Enterprise могут создавать [пользовательские шаблоны](/ru/ja/teams/custom-templates), доступные для выбора в поле ввода Agent всем участникам организации. Пользовательские шаблоны расширяют возможности за пределы фреймворков для разработчиков, включая инструкции для Agent, навыки и предварительно настроенный контекст проекта, адаптированные под конкретную компанию. Подробнее см. в [руководстве по пользовательским шаблонам](/ru/ja/teams/custom-templates).
