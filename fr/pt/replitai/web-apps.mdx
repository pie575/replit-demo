Les applications web sont le type de sortie par défaut sur Replit. Lorsque vous décrivez une idée à Agent, il crée une application web full-stack, sauf si vous spécifiez un autre type d’artefact.

<div id="primeiros-passos">
  ## Premiers pas
</div>

Il existe deux façons de créer une application web :

* **Saisissez un prompt** : Décrivez ce que vous souhaitez créer sur la page d’accueil de Replit. Agent crée automatiquement une application web.
* **Sélectionnez une option dans le menu déroulant** : Ouvrez le menu déroulant du type d’application sur la page d’accueil, choisissez **Application web**, puis décrivez votre idée.

<div id="recursos-principais">
  ## Fonctionnalités principales
</div>

* **Full-stack par défaut :** Chaque application web comprend un frontend et un backend. Agent configure les routes d’API, une base de données et la logique côté serveur selon les besoins de votre application.
* **Design réactif :** Les applications s’adaptent automatiquement aux différentes tailles d’écran.
* **Déploiement instantané :** Publiez votre application en un clic. Replit s’occupe de l’hébergement, du SSL et de l’infrastructure.
* **Infrastructure partagée :** Si votre projet comporte plusieurs artefacts — comme une application mobile ou un tableau de bord de données — ils partagent tous le même backend, la même base de données et les mêmes services.

<div id="casos-de-uso">
  ## Cas d’utilisation
</div>

* **Produits SaaS** : créez des outils destinés à vos clients, des dashboards et des plateformes.
* **Outils internes** : créez des panneaux d’administration, des CRM ou des applications de gestion des flux de travail pour votre équipe.
* **Pages de destination** : lancez des sites marketing avec des formulaires, des animations et du contenu dynamique.
* **Places de marché et annuaires** : créez des sites d’annonces, des tableaux d’offres d’emploi ou des plateformes communautaires.
