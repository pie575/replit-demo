Grâce aux solutions de stockage flexibles de Replit, vous pouvez rapidement ajouter le stockage de données parfait dont votre application a besoin pour fonctionner. Vous pouvez utiliser la base de données ou le stockage d'objets de Replit pour des applications ayant les exigences suivantes, et Agent peut automatiquement configurer et intégrer les deux solutions :

* Un jeu qui doit sauvegarder des informations sur les joueurs telles que la progression ou les meilleurs scores
* Une plateforme de contenu qui gère des fichiers multimédias

## Quelles sont les options de stockage et de base de données de Replit

Replit propose les options de stockage de données suivantes :

* **Base de données** : stocke des données structurées telles que des profils utilisateur, des scores de jeux et des catalogues de produits.
  Vous pouvez stocker ou récupérer des données par attributs et relations entre les points de données.

* **Stockage d'application** : stocke des données non structurées telles que des images, des vidéos, des documents.
  Vous pouvez stocker et récupérer des fichiers volumineux et des données binaires.

### Comparaison du stockage d'application et de la base de données

|                             | Base de données                                       | Stockage d'application                               |
| --------------------------- | :---------------------------------------------------- | :--------------------------------------------------- |
| **Format de données idéal** | Données structurées avec relations                    | Fichiers volumineux (images, vidéos, documents)      |
| **Modèle de données**       | Tables, lignes, colonnes                              | Compartiments, fichiers                              |
| **Langage de requête**      | SQL                                                   | API REST                                             |
| **Clients**                 | Clients et ORM compatibles PostgreSQL                 | SDK Replit et bibliothèques clientes GCS             |
| **Modèle de facturation**   | Payer pour le temps de calcul et l'espace de stockage | Payer pour la bande passante et l'espace de stockage |

## Cas d'utilisation

Les exemples suivants montrent comment les outils de base de données et de stockage d'objets peuvent prendre en charge vos applications Replit.

### Application e-commerce

Stockez des informations sur les produits, les profils clients et l'historique des commandes dans la base de données.
Utilisez des requêtes SQL pour filtrer les produits par catégorie, rechercher des articles et gérer les commandes clients.

### Application de partage de fichiers
