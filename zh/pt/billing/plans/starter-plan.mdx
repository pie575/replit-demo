<div id="o-que-voc-recebe">
  ## 你将获得什么
</div>

Starter 方案提供了在 Replit 上开始创作所需的一切。创建 App 并发布你的第一个项目——完全免费。

<div id="crditos-dirios-para-o-agent">
  ### Agent 每日额度
</div>

Starter 方案用户每天都可获得用于 Agent 的额度，但不超过每月上限。这些额度每天重置，让你每天都有新的额度来使用 Agent。

<div id="crditos-mensais-para-uso-na-nuvem">
  ### 每月云使用额度
</div>

你还会获得每月额度，可用于：

* [数据库 (生产环境) ](/zh/features/data-and-storage/development-and-production)
* [对象存储](/zh/pt/features/data-and-storage/object-storage)
* [部署 (自动扩展、静态) ](/zh/pt/learn/projects-and-artifacts/replit-deployments)

这些额度每月重置。

<div id="build-lite">
  ### Build Lite
</div>

可使用 [Build Lite](/zh/pt/features/agent/agent-modes)：一种快速、专注的构建体验，适合借助 Agent 进行快速编辑和定向修改。

<div id="um-app-publicado-gratuito">
  ### 一个免费发布的应用
</div>

无论使用 Build Lite 还是 Design Canvas，你都可获得 {FreeDeployments} 个免费发布的应用。该发布链接将在 30 天后自动失效。

你发布的应用会带有&quot;Made with Replit&quot;徽章，其中包含你的专属推荐链接。如果有用户通过该徽章上的链接注册，在其升级到付费方案后，你即可获得推荐积分。

<div id="limitaes">
  ## 限制
</div>

以下功能需要升级到 Core 方案后才能使用：

<div id="build-completo">
  ### 完整 Build
</div>

[完整 Build](/zh/pt/features/agent/overview/) 让 Agent 能够以更强的能力和更高的自主性独立完成工作。Starter 方案的创作者仅可使用 [Build Lite](/zh/pt/features/agent/agent-modes)。完整 Build 需要 Core 或 Pro 方案。

<div id="converter-um-design-em-artefato">
  ### 将设计转换为工件
</div>

将 Design Canvas 中的设计转换为完整工件需要 Core 方案。Starter 方案的创作者可以创建并发布设计，但若要转换为具备后端功能的工件，则需要升级方案。如果你想创建带后端功能的应用，不妨先从 [Build Lite](/zh/pt/features/agent/agent-modes) 开始。

<div id="conectores-de-terceiros">
  ### 第三方连接器
</div>

外部连接器需要 Core 套餐。这包括与 Google、Stripe 等服务以及其他第三方 API 的集成 (详见[此处](https://docs.replit.com/features/integrations/overview#connectors)) 。

<div id="integraes-de-ia-do-replit">
  ### Replit AI 集成
</div>

[Replit AI 集成](/zh/pt/features/integrations/replit-ai-integrations)需要 Core 订阅。

<div id="remover-o-badge-criado-com-replit">
  ### 移除“Made with Replit”徽章
</div>

要从已发布的应用中移除“Made with Replit”徽章，需要 Core 套餐。Starter 方案用户的部署中会显示该徽章。

<div id="apps-publicados-adicionais">
  ### 额外的已发布 App
</div>

Starter 方案用户可免费获得 {FreeDeployments} 个已发布 App。超出该数量的已发布 App 需要 Core 或 Pro 计划。

<div id="modo-de-planejamento">
  ### 规划模式
</div>

使用规划模式需要 Core 订阅。规划模式让你可以探索思路、规划工作并与 Replit Agent 协作，而不会改动应用的代码或数据。

<div id="todos-os-tipos-de-artefato">
  ### 所有工件类型
</div>

创建网页和移动应用以外的工件类型需要 Core 套餐。你可以从多种类型中选择，包括数据可视化、幻灯片演示、动画视频等。请参阅 [Projects](/zh/pt/features/projects-and-artifacts/projects)。

<div id="upgrade-para-core">
  ## 升级到 Core
</div>

想要更多功能？升级到 Core 即可解锁：

* **更多存储空间和每月额度**，还支持按用量付费
* **无限发布应用**，不再仅限首个免费应用
* **完整的 Build 功能**，实现自主开发
* **第三方连接器**，轻松对接外部服务
* **Replit AI 集成**，无需自行管理 API 密钥即可使用 AI 模型
* **规划模式**，在开始构建前梳理任务
* **移除 Replit 徽标**，呈现专业外观
* 以及更多功能
