<div id="importar-de-zip">
  ## 从 ZIP 导入
</div>

⏰ *预计用时：三分钟*

通过上传 `.zip` 文件导入本地项目。

如需了解更全面的导入选项，包括从 GitHub、Figma、Bolt、Lovable 和 Vercel 等平台导入，请参阅[导入功能文档](/zh/pt/references/workspace/import)。

<div id="antes-de-comear">
  ## 开始前
</div>

* 包含您项目的 `.zip` 文件
* 文件中明确的项目根目录
* Replit 账户

<div id="etapas-de-importao">
  ## 导入步骤
</div>

1. 打开 [replit.com/import](https://replit.com/import)。
2. 选择 **ZIP**。
3. 上传 `.zip` 文件。
4. 添加所需的 Secrets 和环境变量。
5. 选择 **Import**。

<div id="o-que-importado">
  ## 导入的内容
</div>

* 项目文件和目录结构
* 依赖项文件
* 适用于 Replit 的运行和 Build 配置

<div id="o-que-no-importado">
  ## 不会被导入的内容
</div>

* 现有环境变量的值
* 自定义域名
* 需要手动配置的平台专属服务
* 现有数据库数据
* 现有第三方连接器配置
