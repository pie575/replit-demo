  ## 集成

<div id="agent-suggests-connectors-when-several-fit">
  ### 有多个适用的 connector 时，Agent 会提供建议
</div>

当你让 Agent 连接某项服务，而有多个身份提供方都可用时，Agent 现在会显示一个简短列表，供你选择所需的身份提供方。此前，Agent 必须先提出后续问题。选择身份提供方并完成一次登录后，Agent 会继续构建。

</Frame>

<div id="workspace">
  ## Workspace
</div>

<div id="meet-the-new-tools-pane">
  ### 全新工具窗格
</div>

应用可用的所有功能现在都集中在 workspace 中。新的固定工具窗格将 Database、Auth、Domains、Secrets 等功能汇集一处，让您一眼就能找到全部工具。工具本身没有变化，只是有了更清晰的位置。

<Frame>
  <img src="/assets/mirror/tools-pane-ceaddcc1d7a2.png" alt="workspace 的工具窗格，在 Replit Cloud 下列出 Publishing、Domains、Monitoring、Growth、Database、Users and Auth、安全中心和 App Storage" width="390" height="716" data-path="images/changelog/2026-07-17/tools-pane.png" />
</Frame>

详细了解[工具窗格](/zh/features/editor/editor-and-tools)。

<div id="a-faster-task-sidebar">
  ### 更快的任务侧边栏
</div>

任务侧边栏现在是一个信息更紧凑、更易浏览的任务导航器。每个 task 都有独立的悬停卡片，可执行快捷操作并查看详情；任务看板的入口更加清晰；展开或折叠侧边栏时，task 也不会再发生位移。

<Frame>
  <img src="/assets/mirror/task-sidebar-7687ab8089b2.png" alt="workspace 任务侧边栏，显示 Main、Board 和 New task，以及任务列表和所选 task 的 Apply changes 卡片" width="1228" height="556" data-path="images/changelog/2026-07-17/task-sidebar.png" />
</Frame>

进一步了解 [task 生命周期](/zh/features/agent/task-lifecycle)。
