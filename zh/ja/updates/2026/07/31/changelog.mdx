<div id="replit-design">
  ### Replit Design 现已推出
</div>

Replit Design 现已推出。描述你想创建的内容，探索交互式模型，并不断调整方向。准备好 frame 后，Core 和 Pro 用户可以在同一项目中将其转换为可运行的应用。

</Frame>

如需了解更多，请参阅 [Replit Design](/zh/ja/design/what-is-replit-design)。

<div id="agent">
  ## Agent
</div>

<div id="agent-2">
  ### 选择 Agent 的主模型
</div>

现在你可以选择 Agent 在任务中使用的主模型：先选择 Lite、Economy 或 Power，再从该模式下可用的模型中挑选。Lite 现已在所有可使用 Agent 的地方提供，包括移动应用。可用模型因组织、权限和 Turbo 访问权限而异。

<Frame caption="截取自 Replit Design。相同的控件也会显示在 Agent 的设置下拉菜单中。">
  <img src="/assets/mirror/agent-model-selector-873f18bc6147.png" width="1432" height="786" data-path="images/changelog/2026-07-31/agent-model-selector.png" />
</Frame>

详情请参阅[模型选择器](/zh/ja/features/agent/model-selector)。

<div id="mcp">
  ### 连接更多 MCP 服务器
</div>

符合条件的工作区现可通过预先列出的 MCP 服务器目录连接 Supabase、Statsig 和 Calendly。Replit 还可识别官方 Braintrust MCP 端点；手动添加时，会启动 OAuth 登录流程。

<Frame>
  <img src="/assets/mirror/integrations-4cb26ed8a654.png" alt="集成设置页面，列出了 GitHub、GitLab、AWS、Calendly 等连接器" width="3124" height="1636" data-path="images/changelog/2026-07-31/integrations.png" />
</Frame>

详情请参阅 [MCP 服务器](/zh/ja/features/mcp/overview)。

  ## 团队和企业版

<div id="section-6">
  ### 登录状态持续更久
</div>

Replit 会话的持续时间更长，无需频繁重新登录。企业版管理员可以配置会话超时预设。
