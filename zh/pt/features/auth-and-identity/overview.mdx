Users &amp; Auth 工具用于管理使用你应用的用户及其登录方式。在 **Tools** 面板中打开 **Replit Cloud** 下的 **Users &amp; Auth**。

该工具包含两个标签页：

* **Users**：所有登录过你应用的用户，显示姓名和最近一次登录时间。可搜索列表以查找特定用户。
* **Configure**：应用的登录体验，包括登录界面的名称和图标、应用支持哪些登录方式，以及 session secret。

<Note>
  该工具管理的是**你的应用**的用户，也就是在你所构建的应用中注册和登录的人。若要控制谁可以打开你已发布的应用，请参阅[谁可以访问你的应用](/zh/pt/features/publishing/private-deployments)。
</Note>

<div id="escolha-seu-sistema-de-autenticao">
  ## 选择你的身份验证系统
</div>

* **[Replit Auth](/zh/pt/features/auth-and-identity/authentication)**：零配置方案。只需让 Agent 添加 Replit Auth，你的应用便能获得预置的登录页面、用户管理和安全会话，无需任何配置。
* **[Clerk](/zh/pt/features/auth-and-identity/clerk-auth)**：功能完整的身份验证服务，适合需要更多控制权的应用，比如自定义登录流程和自有品牌的 OAuth。你可以为 Google、GitHub、Apple 和 X 配置[自定义登录身份提供方](/zh/pt/features/auth-and-identity/sign-in-providers)。

<div id="prximos-passos">
  ## 后续步骤
</div>

* [Replit Auth](/zh/pt/features/auth-and-identity/authentication)：为你的应用提供免配置的登录功能。
* [Clerk Auth](/zh/pt/features/auth-and-identity/clerk-auth)：完整的身份验证方案。
* [登录身份提供方](/zh/pt/features/auth-and-identity/sign-in-providers)：使用你自己的 OAuth 凭据。
