<div id="replitmd">
  ### Documentation replit.md
</div>

Vous pouvez personnaliser le comportement d’Agent avec `replit.md`. Ce fichier de configuration spécial aide Agent à comprendre la configuration, le style de code et l’architecture de votre projet. Agent crée automatiquement ce fichier en s’appuyant sur des bonnes pratiques éprouvées, puis l’utilise pour créer des applications correspondant précisément à vos spécifications. Vous pouvez guider Agent grâce au contexte du projet, définir des normes de code, indiquer votre pile technologique préférée et définir vos préférences de communication. Tout est centralisé au même endroit.

<div id="section-3">
  ### Indicateur de confidentialité des déploiements
</div>

Un nouvel indicateur visuel dans le panneau de déploiement vous permet d&#39;identifier rapidement si un déploiement est public ou privé. Cette amélioration évite toute confusion et vous permet de savoir précisément qui peut accéder à vos applications déployées.
