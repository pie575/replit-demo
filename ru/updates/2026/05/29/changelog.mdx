<div id="upgrade-to-enterprise-without-leaving-replit">
  ### Перейдите на Enterprise, не выходя из Replit
</div>

Теперь вы можете перейти на Replit Enterprise с любого тарифа — Free, Core или Pro — не выходя из продукта и без предварительного обращения в отдел продаж. Если у вас есть совместные рабочие пространства, после оформления покупки они автоматически перейдут в вашу новую организацию Enterprise. Ваши опубликованные приложения продолжат работать без простоев.

<div id="connect-stripe-by-installing-an-app-no-keys-to-copy">
  ### Подключите Stripe, установив приложение — ключи копировать не нужно
</div>

Запустить приложение с Stripe стало проще. Вместо копирования рабочих ключей API из панели управления Stripe теперь можно установить приложение Replit Integrated Payments из Stripe Marketplace. Рабочие ключи будут настроены автоматически. Откройте панель публикации, установите приложение и завершите подключение в Stripe.

<div id="agent-can-generate-music-sound-effects-and-speech">
  ### Agent может генерировать музыку, звуковые эффекты и речь
</div>

Теперь Agent может создавать аудио для ваших приложений. Попросите фоновую музыку, звуковые эффекты или голосовое сопровождение — Agent сгенерирует аудио и добавит его прямо в ваш project. Использование оплачивается кредитами Replit.

<div id="generate-media-right-on-canvas">
  ### Создавайте медиа прямо на Canvas
</div>

Теперь вы можете создавать медиа прямо на Canvas. Откройте инструмент **Generate** на панели инструментов Canvas и выберите **Image**, **Vector Graphic** или **Video**, чтобы создать нужный медиафайл прямо на холсте. Весь процесс происходит на Canvas, поэтому вы можете разрабатывать дизайн и вносить изменения, не переключаясь между инструментами.
