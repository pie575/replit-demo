  ## Как работает доска задач
</div>

Доска задач — это единое место, где вы можете просматривать, запускать, отслеживать и применять задачи Agent. Используйте её, когда Agent разбивает большой запрос на несколько частей, когда вы хотите выполнять работу в фоновом режиме или когда нужно понять, что уже изменилось в вашем project.

Задачи распределяются по колонкам в зависимости от статуса. На доске видно, что Agent запланировал, что выполняется сейчас, что готово к проверке и что уже применено.

По мере выполнения каждая задача перемещается слева направо:

* **Черновики**: задачи, которые Agent запланировал, но ещё не начал
* **В работе**: задачи, над которыми Agent работает сейчас, включая те, что стоят в очереди из-за лимита активных задач
* **Готово к проверке**: задачи, которые Agent завершил и которые ждут вашей проверки
* **Завершено**: задачи, которые выполнены, помещены в архив или отменены

<div id="drafts">
  ## Черновики
</div>

**Черновики** — это запланированные задачи, к которым Agent ещё не приступил. Каждый черновик содержит заголовок, описание и пошаговый план.

Используйте черновики, чтобы оценить предложенный Agent подход до начала работы. Вы можете изучить план, попросить Agent скорректировать его или запустить задачу, когда будете готовы.

Черновики удобны, когда нужно продумать крупную функцию, прежде чем запускать фоновую работу. Например, Agent может разбить project по онбордингу на отдельные черновики: аутентификация, настройка профиля, интерфейс панели управления и доработка deployment.

<div id="active">

</div>

Как только вы примете задачу, она переместится в столбец **В работе**, и Agent приступит к работе. Каждая задача выполняется в отдельной изолированной копии вашего project, поэтому в основной версии ничего не меняется, пока вы не примените результат.

Некоторые задачи зависят от других. Например, задаче по созданию панели управления может потребоваться, чтобы сначала завершилась задача по схеме базы данных. Зависимые задачи ждут со статусом **В очереди**, пока не будут выполнены необходимые для них задачи. Задачи также попадают в очередь, если вы достигли лимита активных фоновых задач в вашем тарифе.

<div id="ready">
  ## Готовые к проверке
</div>

Когда сборка задачи завершается, она переходит в статус **Готовые к проверке**. Это значит, что работа выполнена, но в вашей основной версии пока ничего не изменилось.

Применить изменения можно двумя способами:

* **Из треда**: откройте тред задачи и выберите **Apply changes to main version**, чтобы перенести результат в ваш project, либо **Dismiss**, чтобы отклонить его
* **С доски**: откройте меню из трёх точек на карточке любой задачи в статусе готово к проверке и выберите **Apply changes**

</div>

В колонке завершённых также хранятся архивные сессии планирования и отменённые задачи. Так у вас остаётся история происходившего, а завершённая работа не смешивается с колонками черновиков и в работе.

Agent автоматически разрешает конфликты, когда вы применяете изменения из нескольких задач. Если что-то выглядит не так, попросите Agent это исправить.

<div id="find-and-filter-tasks">
  ## Поиск и фильтрация задач
</div>

Используйте доску задач, когда в project одновременно выполняется много задач. Вы можете искать по названию или номеру задачи, фильтровать черновики и управлять сразу группами задач в режиме редактирования.

Например, ищите по номеру задачи, когда кто-то ссылается на неё в треде, при проверке или в переписке в Slack. Фильтруйте черновики, когда хотите сосредоточиться на запланированной работе, не просматривая активные или завершённые задачи.

О предлагаемых последующих действиях см. [Последующие задачи](/ru/features/agent/follow-up-tasks).

<div id="rename-a-task">
  ## Переименование задачи
</div>

По мере изменения объёма работ длинные списки задач становится всё труднее просматривать. Чтобы переименовать любую задачу, откройте меню с тремя точками на её карточке (на боковой панели со списком задач или на доске задач) и выберите **Rename**. Введите более понятное название и нажмите **Save**.

Переименование задачи меняет только то, как она отображается для вас и ваших коллег. Работа, уже выполненная Agent, история задачи и все ожидающие изменения остаются нетронутыми.

<div id="settings-on-each-task">
  ## Настройки каждой задачи
</div>

У каждой задачи есть собственное выпадающее меню настроек рядом с заголовком. Откройте его, чтобы задать, как Agent завершит задачу и как результат попадёт в ваш project:

* **Auto-apply changes** (черновики и задачи в работе): как только задача готова, сразу применить её к основной версии, не дожидаясь проверки.
* **Auto-approve plan** (черновики): когда Agent предлагает план для задачи, автоматически принимать его и приступать к сборке.
* **Apply changes** (задачи, готовые к проверке): применить выполненную работу к основной версии.
* **Rename**: изменить заголовок, отображаемый на карточке.
* **Review changes** (задачи, готовые к проверке): сразу перейти к списку изменений готовой задачи.
* **Cancel**: остановить задачу или удалить черновик.

Auto-apply и auto-approve — это разовые быстрые действия, а не переключатели, которые остаются включёнными. Ширина меню всегда одинаковая, поэтому подписи не смещаются при открытии разных задач.
