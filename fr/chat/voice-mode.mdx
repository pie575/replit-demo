Décrivez à voix haute ce que vous souhaitez créer avec le mode vocal. Appuyez sur le microphone dans la zone de chat Agent, énoncez votre prompt et Replit transcrit vos paroles en texte modifiable. Relisez le texte, apportez les modifications nécessaires, puis envoyez-le comme n&#39;importe quel autre message.

Le mode vocal est utile lorsque la saisie est lente ou peu pratique, notamment sur mobile, où dicter un prompt complet est souvent plus rapide que de le taper avec les pouces.

<Note>
  Le mode vocal transforme vos paroles en texte dans la zone de chat. Il ne lit pas
  les réponses d&#39;Agent à voix haute : vous envoyez toujours un message écrit, et Agent répond
  dans le chat comme d&#39;habitude.
</Note>

<div id="how-it-works">
  ## Fonctionnement
</div>

<Frame>
  <img src="/assets/mirror/voice-mode-mic-button-fe7da6953736.png" alt="La zone de Chat Agent avec le bouton du microphone mis en évidence et une infobulle « Démarrer la saisie vocale », à côté de la case à cocher Plan et de la flèche d’envoi" width="1853" height="423" data-path="images/replitai/voice-mode/voice-mode-mic-button.png" />
</Frame>

Le mode vocal enregistre votre voix, la transcrit et insère le résultat dans la zone de chat afin que vous puissiez le vérifier avant de l’envoyer :

1. Ouvrez Agent et sélectionnez le microphone dans la zone de chat.
2. Autorisez l’accès au microphone si votre navigateur ou votre appareil vous y invite.
3. Énoncez votre prompt. Une forme d’onde indique qu’Agent enregistre.
4. Arrêtez l’enregistrement lorsque vous avez terminé. L’enregistrement s’arrête également automatiquement après une pause ou lorsque vous changez d’onglet.
5. Patientez un instant pendant la transcription de votre voix.
6. Vérifiez le texte transcrit, modifiez-le si nécessaire, puis envoyez votre message.

Comme la transcription s’affiche sous forme de texte normal dans la zone de chat, vous pouvez librement alterner entre la voix et la saisie au clavier : dictez une partie d’un prompt, puis tapez le reste, ou corrigez un mot avant de l’envoyer.

<Tip>
  Parlez naturellement. Le mode vocal cherche à saisir ce que vous voulez dire plutôt qu’à
  transcrire chaque mot à la lettre ; les mots de remplissage comme « euh » sont donc absents
  du résultat.
</Tip>

<div id="where-you-can-use-it">
  ## Où vous pouvez l&#39;utiliser
</div>

Le mode vocal est disponible dans la zone de chat Agent :

* Dans le **Project Editor**, lorsque vous travaillez avec Agent sur une app.
* Lorsque vous **créez une nouvelle app** depuis le prompt Agent sur l&#39;écran d&#39;accueil.

Vous pouvez utiliser le mode vocal sur le Web sur ordinateur, le Web mobile et l&#39;application mobile Replit.

<div id="good-to-know">
  ## Bon à savoir
</div>

Gardez les points suivants à l’esprit lorsque vous utilisez le mode vocal :

| Détail                     | À quoi vous attendre                                                                                                                                                                                  |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Durée d’enregistrement     | Enregistrez jusqu’à 6 minutes à la fois. Un avertissement s’affiche peu avant d’atteindre la limite.                                                                                                  |
| Arrêt automatique          | L’enregistrement s’arrête automatiquement après environ 30 secondes de silence, ou lorsque vous changez d’onglet ou mettez l’app en arrière-plan.                                                     |
| Vérification avant l’envoi | Le texte transcrit apparaît dans la zone de chat afin que vous puissiez le lire et le modifier avant de l’envoyer — rien n’est envoyé automatiquement.                                                |
| Accès au microphone        | Le mode vocal nécessite l’autorisation d’utiliser votre microphone. Si l’enregistrement ne démarre pas, vérifiez que votre navigateur et votre appareil autorisent l’accès au microphone pour Replit. |

<div id="availability">
  ## Disponibilité
</div>

Le mode vocal est disponible avec tous les forfaits Replit. Le microphone apparaît dans la zone de chat Agent sur les navigateurs et appareils compatibles avec l&#39;enregistrement audio. Vous serez invité à autoriser l&#39;accès au microphone lors de votre premier enregistrement.
