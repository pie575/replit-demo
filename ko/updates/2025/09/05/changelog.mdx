## 플랫폼

### General Agent

<Frame>
  <img src="/assets/mirror/general-agent-240ff289e711.png" alt="General Agent 히어로 일러스트레이션" width="1040" height="572" data-path="images/replitai/general-agent.png" />
</Frame>

Replit Agent가 이제 NixOS에서 실행되는 모든 언어 또는 프레임워크의 코드베이스에서 작동합니다! 이전에는 특정 템플릿으로 제한되었으나, 이제 Agent는 개발자 프레임워크, GitHub 가져오기, 모든 커스텀 프로젝트 설정을 지원할 수 있습니다. 이 강력한 확장으로 엔터프라이즈 및 파워 유저 워크플로에 완전한 AI 코딩 지원을 제공합니다.

General Agent에 대해 [여기](/core-concepts/agent/general-agent)에서 자세히 알아보세요.

### 플랜 모드

<Frame>
  <img src="/assets/mirror/plan-mode-overview-8077807c63b9.png" alt="플랜 모드의 Agent 채팅 인터페이스" width="916" height="362" data-path="images/replitai/plan-mode-overview.png" />
</Frame>

플랜 모드는 질문하고, 브레인스토밍하고, 작업을 계획하는 데 초점을 맞춘 Replit Agent와의 새로운 채팅 방식을 도입합니다. 플랜 모드를 사용하면 Agent를 통해 향후 작업을 위한 할 일 목록을 만든 다음 빌드 모드에서 장기 실행 작업을 실행할 수 있습니다.

플랜 모드에 대해 [여기](/core-concepts/agent/plan-mode)에서 자세히 알아보세요.

## 엔터프라이즈

### GCP 마켓플레이스 통합

엔터프라이즈 고객은 이제 Google Cloud Platform 마켓플레이스를 통해 Replit을 직접 구매하고 기존 GCP 크레딧을 결제에 사용할 수 있습니다. 이를 통해 조달 프로세스가 간소화되고 GCP 예산을 보유한 조직이 개발 워크플로에 Replit을 도입하기가 더 쉬워집니다.
