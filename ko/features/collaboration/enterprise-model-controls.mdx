Enterprise 모델 제어를 사용하면 account admin이 builder가 선택할 수 있는 Agent 모델을 관리할 수 있습니다. 계정 전체에 적용할 정책을 설정한 다음, Workspace별로 서로 다른 모델 접근 권한을 지정하세요.

<Note>
  모델 제어는 Enterprise 계정의 account admin만 사용할 수 있습니다. 조직에서 이 기능을 활성화하려면 영업팀([sales@replit.com](mailto:sales@replit.com))으로 문의하세요.
</Note>

<div id="use-intelligent-model-routing">
  ## Intelligent model routing 사용하기
</div>

Intelligent model routing은 Enterprise Workspace의 기본 Agent 환경입니다. **Auto 모드**를 켜면 Replit이 품질과 비용의 균형을 고려해 각 task에 가장 적합한 모드와 모델을 선택합니다.

라우팅은 계정 및 Workspace 정책에서 승인된 모델 풀 안에서만 선택합니다. 해당 풀에 포함되지 않은 provider와 모델은 선택 대상이 아닙니다. Builder는 **Auto 모드**를 켜 둘 수도 있고, 꺼서 승인된 모델을 직접 선택할 수도 있습니다.

<Frame caption="Auto 모드를 켜면 Workspace에서 승인된 모델 사이에서 task가 라우팅됩니다.">
  <img src="/assets/mirror/enterprise-auto-mode-9365b7d49c0d.png" alt="Auto 모드가 켜져 있고 모델 선택이 Auto로 설정된 Agent settings" width="558" height="356" data-path="images/changelog/2026-08-28/enterprise-auto-mode.png" />
</Frame>

라우팅의 작동 방식은 [Auto 모드 사용하기](/ko/chat/auto-mode)에서 자세히 알아보세요.

<div id="open-agent-model-settings">
  ## Agent 모델 설정 열기
</div>

1. **Settings**를 엽니다.
2. **Account**에서 **Advanced**를 선택합니다.
3. **Agent modes and model providers**를 펼칩니다.

<div id="set-a-provider-policy">
  ## provider 정책 설정
</div>

<Steps>
  <Step>
    관리할 모델 provider를 선택합니다.
  </Step>

  <Step>
    **Account policy**에서 다음 옵션 중 하나를 선택합니다.

    | 옵션                  | 결과                                                |
    | ------------------- | ------------------------------------------------- |
    | **Enable all**      | 해당 provider의 모든 모델을 모든 Workspace에서 사용할 수 있습니다. |
    | **Enable selected** | 각 Workspace에서 사용할 모델을 직접 선택합니다.                |
    | **Disabled**        | 어떤 Workspace에서도 해당 provider의 모델을 사용할 수 없습니다.   |

    <Note>
      OpenAI, Anthropic, Google의 모델 중 최소 하나는 활성화된 상태로 유지해야 합니다. 그 외 provider는 비활성화할 수 있습니다.
    </Note>
  </Step>

  <Step>
    **Update**를 선택합니다.
  </Step>
</Steps>

오픈 소스 모델 provider는 기본적으로 비활성화되어 있습니다. 사용하려면 **Enable all** 또는 **Enable selected**를 선택한 다음 **Update**를 선택하세요.

<div id="set-a-workspace-policy">
  ## Workspace 정책 설정
</div>

Workspace마다 서로 다른 모델 접근 권한이 필요한 경우 **Enable selected**를 사용하세요.

<Frame caption="Enable selected로 설정된 Anthropic provider 정책과 Workspace별로 구성된 모델 접근 권한.">
  <img src="/assets/mirror/anthropic-account-policy-workspace-models-38c0f71a609d.jpg" alt="Enable selected로 설정되고 Workspace별 모델 토글이 표시된 Anthropic 계정 정책" width="2000" height="930" data-path="images/workspace/anthropic-account-policy-workspace-models.jpg" />
</Frame>

1. provider 설정을 엽니다.
2. **Account policy**를 **Enable selected**로 설정합니다.
3. **Workspace** 목록에서 해당 Workspace의 **Setting** 드롭다운을 선택합니다.
4. 해당 Workspace에서 각 모델을 켜거나 끕니다.
5. **Update**를 선택합니다.

**Update**를 선택하기 전에 **Copy to all**을 선택하면 현재 Workspace의 모델 선택 내용을
계정 내 모든 Workspace에 적용할 수 있습니다.

<div id="limitations">
  ## 제한 사항
</div>

* 모델 정책은 Workspace 단위로 적용됩니다. 동일한 Workspace 내에서 사용자 group마다 다른 정책을 설정할 수는 없습니다.
* Intelligent Model Routing은 Account 또는 Workspace 정책보다 우선하지 않으며, 비활성화된 provider나 모델은 선택할 수 없습니다.
* **Agent modes and model providers**의 **Fast mode models** 토글은 해당 Account의 모든 Workspace에서 fast 모델 변형에 대한 접근 권한을 제어합니다. Provider 정책이나 Intelligent Model Routing은 이 설정에 영향을 주지 않습니다.
