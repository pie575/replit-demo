更多评分有助于提升你的 App 排名，并赢得新用户的信任。两个应用商店都提供
原生评分提示：直接在 App 内弹出窗口，请求用户评分。

iOS 上的 StoreKit 和 Android 上的 Google Play 应用内评价 API 都会限制实际展示频率，无论你的代码请求得多频繁。

<Note>
  切勿以奖励诱导或强制用户评分，例如要求用户给出 5 星评分后才能解锁游戏。Apple 和 Google 都禁止激励性评价，PixelGames 可能因此被拒绝上架或下架。
</Note>

<div id="troubleshooting">
  ## 故障排除
</div>

* **提示始终未出现：** 这有时属于预期情况；无论代码调用 API 多少次，两个平台都会限制系统显示提示的频率。
* **测试时每次都会显示提示：** 在 TestFlight 或 Internal Testing 构建中，这属于正常情况；年度频率限制仅适用于实际的生产环境安装。
* **玩家抱怨被频繁询问：** 请确认调用的是原生 API，而不是每次启动时都会显示的自定义弹窗；后者会绕过内置的频率限制。
