Replit AI 기능은 빌드한 내용과 AI 기반 도구 사용량에 따라 요금을 청구하는 사용량 기반 청구 방식을 사용합니다. 이를 통해 Agent에서 받는 가치에 대해서만 비용을 지불할 수 있습니다.

## 시작하기

**모든 구독자**는 일회성 무료 Agent 체크포인트를 받습니다.

추가 월간 크레딧이 AI 사용량에 자동으로 적용됩니다:

* **Core 구독자**: 월간 크레딧 ([요금제](https://replit.com/pricing) 참조)
* **Pro 구독자**: {ProCreditRolloverPeriod} 롤오버가 있는 단계별 월간 크레딧. [Replit Pro](/ko/billing/plans/replit-pro) 참조.

이 크레딧은 Agent와 게시된 앱, 스토리지, 데이터베이스 등 다른 Replit 클라우드 서비스를 포함합니다. [Lite, Economy 또는 Power](/ko/features/agent/agent-modes)를 선택하여 속도, 비용 또는 성능을 위해 Agent를 최적화하세요.

## Agent 청구

Free Mode는 허용량 내에서 Core 및 Pro 구독자에게 일상적인 Agent 작업을 무료로 지원합니다. 유료 모드와 확정된 유료 작업에는 요청의 복잡성에 따른 노력 기반 요금제가 적용됩니다. Replit은 유료 작업이 시작되기 전에 확인을 요청합니다.

### 노력 기반 요금제 작동 방식

"Build 모드"에서 Agent와 채팅하면 요청에 대한 완료된 작업을 캡처하는 **체크포인트**가 생성됩니다:

* **단순 요청** (버그 수정이나 소소한 변경 등)은 일반적으로 복잡한 빌드보다 비용이 적습니다
* **복잡한 빌드** (전체 기능이나 통합 등)는 하나의 체크포인트로 묶여 단순 요청보다 비용이 많을 수 있으며, 이는 총 투입 노력을 반영합니다
* **요청당 하나의 체크포인트**로 중간 체크포인트가 제거되고 청구 노이즈가 감소합니다
* **투명한 요금제**로 완료된 각 작업에 대해 정확히 무엇을 지불하는지 확인할 수 있습니다

<Info>
  체크포인트는 Agent가 요청에 대한 작업을 완료하고 요청된 기능을 코드에 구현할 때 발생합니다.
</Info>

유료 경로에서는 Plan Mode가 코드를 변경하지 않아도 청구 대상이 되는 추론 작업을 수행할 수 있습니다.

체크포인트가 캡처하는 내용과 작동 방식에 대한 자세한 내용은 [체크포인트 및 롤백](/ko/features/version-control/checkpoints-and-rollbacks)을 참조하세요.

### Agent 서비스 청구

일부 Agent 기능은 내부적으로 유료 제3자 API(Claude, ChatGPT, Nano Banana / Gemini 등)를 사용합니다. Agent가 이러한 통합을 자동으로 처리하므로 API 키나 설정이 필요 없습니다. 제공업체의 공개 API 요금으로 청구되며 Replit 크레딧에서 차감됩니다. 이 비용은 [사용량 대시보드](/ko/billing/managing-spend)에서 다른 사용량과 함께 표시됩니다.

샘플 앱 비용을 이해하려면 간단한 [인터랙티브 데모](https://agent-pricing.replit.app/)를 확인하세요.

### 사용량 추적

실시간으로 Agent 지출을 모니터링할 수 있습니다:

1. **Agent 탭**: 사용량 아이콘 위에 마우스를 올려 개별 체크포인트 비용 확인
2. **사용량 대시보드**: 현재 기간의 자세한 청구 정보 확인
3. **설정**: **계정** → **청구**에서 알림 및 예산 설정으로 지출 제어

<Tip>
  사용량 데이터가 사용량 대시보드에 표시되는 데 최대 30분이 걸릴 수 있습니다.
</Tip>

## 지출 관리

Replit의 내장 예산 도구로 AI 지출을 제어하세요:

* **사용량 알림**: 지출 임계값에 도달하면 알림 받기
* **예산 한도**: 예기치 않은 요금을 방지하는 강력한 상한선 설정
* **실시간 추적**: 빌드하는 동안 비용 모니터링
* **크레딧 팩**: 대량 구매 시 할인으로 추가 크레딧 구매. 자세한 내용은 [지출 관리](/ko/billing/managing-spend)를 참조하세요.

## 다음 단계

AI로 빌드를 시작할 준비가 됐나요? 크레딧으로 최대 가치를 얻는 방법:

* **먼저 Agent 사용해보기**: 무료 체크포인트를 사용하여 Agent의 기능 탐색
* **작게 시작하기**: 노력 기반 요금제를 이해하기 위해 단순 요청으로 시작
* **Lite 모드 사용**: 빠르고 목표가 명확한 편집에는 [Lite 모드](/ko/features/agent/agent-modes) 활용
* **알림 설정**: 크레딧을 초과하기 전에 지출 알림 설정

[Replit의 AI 도구](/ko/welcome)에 대해 자세히 알아보거나 [요금제](https://replit.com/pricing)를 탐색하세요.
