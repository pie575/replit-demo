借助可配置的组合键，你可以使用键盘快捷键运行命令、修改文本，并在 Project Editor
中导航。你可以在 Replit.com 网页应用中设置和使用键盘快捷键。

<div id="viewing-keyboard-shortcuts">
  ## 查看键盘快捷键
</div>

要查看键盘快捷键设置，请按以下步骤操作：

1. 打开一个 Replit App，进入 Project Editor。
2. 在停靠栏的 <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="all tools icon" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools** 中打开 <img class="icon-svg" src="/assets/mirror/settings-icon-c2664c3691bf.svg" alt="gear icon" width="16" height="16" data-path="images/icons/settings-icon.svg" /> **User Settings** 标签页。
   或者，使用 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="magnifying glass icon" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 放大镜搜索“User Settings”。
3. 选择 **Keyboard shortcuts** 标签页，即可查看命令列表及其对应的快捷键。

<div id="customizing-keyboard-shortcuts">
  ## 自定义键盘快捷键
</div>

要添加或修改键盘快捷键，请按以下步骤操作：

1. 选择未分配命令旁的 <img class="icon-svg" src="/assets/mirror/create-app-icon-ba218e87fb67.svg" alt="plus icon" width="16" height="16" data-path="images/icons/create-app-icon.svg" />**添加快捷键**；对于已分配的命令，则选择 <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="pencil icon" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> 铅笔图标。
2. 当命令旁出现“正在录制…”时，按下要分配的组合键。
   如需取消录制，请点击标签页内的空白区域。
3. 如需还原快捷键，请选择 <img class="icon-svg" src="/assets/mirror/rollback-icon-3197ed1b323b.svg" alt="rollback icon" width="12" height="12" data-path="images/icons/rollback-icon.svg" /> 回滚图标。

<div id="removing-keyboard-shortcuts">
  ## 删除键盘快捷键
</div>

要删除某个键盘快捷键，请点击该命令旁的 <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="trash icon" width="16" height="16" data-path="images/icons/trash-icon.svg" /> 垃圾桶图标。

<div id="tab-navigation">
  ## Tab 键导航
</div>

你可以使用浏览器的 **Tab** 键在页面的交互元素之间切换。不过，文件编辑器、控制台和 Shell 工具会将 **Tab** 键作为输入捕获，用于缩进等操作。

若要在使用这些工具时继续在页面元素之间循环切换，请按以下步骤操作：

1. 按 **Esc** 键，让焦点离开当前工具
2. 按 **Tab** 键移动到下一个元素
