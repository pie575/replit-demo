<div id="uma-nova-experincia-de-integraes">
  ### Новый интерфейс «Интеграции»
</div>

Теперь все сервисы, к которым подключается Replit, доступны в одном месте. Обновлённая страница «Интеграции» объединяет коннекторы, серверы MCP и Git-провайдеров в кликабельные карточки с фильтрами по категориям и значком для интеграций, которые Replit может подключить за вас. В каталоге теперь представлено более 450 интеграций, и для каждой есть отдельная страница с примерами использования. Полный каталог доступен на [replit.com/integrations](https://replit.com/integrations).

<div id="use-o-replit-pelo-slack">
  ### Используйте Replit в Slack
</div>

Replit стал партнёром по запуску Slackbot MCP Client от Slack. Попросите Slackbot разработать приложение с помощью Replit — он создаст, обновит и покажет ваши Replit App прямо в Slack. Вы остаетесь в беседе, пока Replit Agent выполняет работу.

<div id="mltiplos-workspaces-para-clientes-scim">
  ### Несколько рабочих пространств для клиентов SCIM
</div>

Клиенты Enterprise, предоставляющие доступ участникам через SCIM, теперь могут создавать несколько рабочих пространств. Назначайте синхронизированные группы разным рабочим пространствам для более чёткого разграничения доступа, контроля бюджета и разделения команд, сохраняя провайдера идентификации в качестве единого источника достоверных данных. Эта возможность доступна новым клиентам Enterprise по открытой регистрации.

Подробнее о [доступе к рабочему пространству через SCIM](/ru/pt/teams/identity-and-access-management/scim#managing-workspace-access).
