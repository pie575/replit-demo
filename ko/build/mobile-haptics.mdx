export const hapticsPrompt = "D-pad와 액션 버튼을 누를 때 햅틱 피드백을 추가하세요. D-pad에는 가벼운 진동을 적용하고, Blocks에서 줄을 지울 때는 약간 더 강한 진동을 적용하세요.";

haptics는 화면을 탭할 때 휴대폰이 전해주는 작은 진동으로, 버튼을 누를 때 느껴지는
짧은 떨림 같은 것입니다.

<AiPrompt>
  {hapticsPrompt}
</AiPrompt>

**iOS:** 약함, 중간, 강함의 임팩트와 성공 및 경고 알림 feedback 등 여러 가지 뚜렷한 feedback styles를
지원합니다.

**Android:** 지원하는 진동 패턴이 더 적습니다. Agent가 가장 비슷한 패턴을 선택하므로 iOS와
똑같지는 않아도 의도한 느낌은 그대로 살아납니다.

<div id="troubleshooting">
  ## 문제 해결
</div>

* **실제 기기에서 feedback이 느껴지지 않는 경우:** 시스템 설정에서 휴대전화의 햅틱/진동 설정이
  꺼져 있지 않은지 확인하세요. PixelGames가 이 설정을 무시하고 동작할 수는 없습니다.
* **Replit의 iOS/Android Preview에서 Simulate를 눌러도 아무 일도 일어나지 않는 경우:** 해당 화면은
  화면만 렌더링할 뿐, 휴대전화의 진동 모터를 작동시킬 수 없습니다. 햅틱를 직접 느껴 보려면
  실제 기기에서 Expo Go로 전환하세요. [휴대전화에서 미리 보기 및 테스트하기](/ko/build/mobile-preview-testing)를 참고하세요.
* **iOS와 Android에서 느낌이 다른 경우:** 정상입니다. 두 플랫폼이 제공하는 feedback styles가 서로
  다르기 때문입니다. 차이가 거슬린다면 Agent에게 각각 따로 조정해 달라고 요청하세요.
