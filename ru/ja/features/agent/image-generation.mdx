Генерация изображений позволяет создавать уникальный визуальный контент без навыков дизайна и сторонних инструментов. Всё — от значков и иллюстраций до фонов и элементов интерфейса — можно генерировать прямо в процессе разработки.

<div id="section">
  ## Возможности
</div>

Создавайте визуально привлекательные приложения с помощью генерации изображений в Agent. Больше не нужно искать стоковые фотографии, осваивать сторонние инструменты дизайна или нанимать дизайнера ради базового визуального контента. Создаёте ли вы сайт-портфолио, разрабатываете игру или проектируете интерфейс мобильного приложения — генерация изображений даст вам уникальные визуальные материалы, подходящие именно вашему проекту.

Действия по генерации изображений, которые может выполнять Agent:

* **Создание собственных изображений**: генерирует изображения по подробным описаниям и требованиям
* **Адаптация стиля**: создаёт изображения в различных художественных стилях — от реалистичного до мультипликационного
* **Прозрачный фон**: генерирует изображения в формате PNG с прозрачностью или удаляет фон с уже существующих изображений — идеально для логотипов, иконок, стикеров и вырезанных изображений товаров
* **Интеграция с проектом**: без лишних действий добавляет сгенерированные изображения прямо в кодовую базу вашего приложения
* **Пошаговая доработка**: изменяет и улучшает изображения с учётом ваших замечаний

<div id="section-2">
  ## Использование
</div>

Генерация изображений встроена в Agent — включать её в настройках не нужно. Откройте любое приложение Replit с активированным Agent и попросите его создать нужный визуальный контент. Agent автоматически определит по вашему запросу, когда нужно создать изображения, и подготовит уникальные изображения в соответствии с вашими требованиями.

<div id="section-3">
  ### Лучшие практики генерации изображений
</div>

Чтобы получать наилучшие результаты при генерации изображений с помощью Agent, следуйте этим рекомендациям:

**Будьте конкретны и подробны**

* Указывайте детали стиля, цветов, композиции и настроения
* При необходимости задавайте размер или соотношение сторон
* Чётко обозначайте назначение (иконка, фон, иллюстрация и т. п.)
* Запрашивайте прозрачный фон, если вам нужны логотипы, иконки, стикеры или вырезанные элементы для наложения поверх другого содержимого

**Дорабатывайте результат итеративно**

* Начните с базового описания и улучшайте его по мере получения результатов
* Просите Agent изменить отдельные части сгенерированного изображения
* Запрашивайте варианты, чтобы попробовать разные творческие направления

**Учитывайте стиль проекта**

* Сохраняйте визуальную целостность во всём приложении
* Указывайте стилевые предпочтения, соответствующие вашему бренду или дизайн-системе
* Просите изображения, которые дополняют уже существующие визуальные элементы

<div id="section-5">
  ### Интеграция с проектом
</div>

Agent легко интегрирует созданные изображения в кодовую базу:

* **Автоматическое создание файлов**: созданные изображения сохраняются непосредственно в файлах проекта
* **Обновление кода**: Agent обновляет код, чтобы он ссылался на новые файлы изображений
* **Организация ресурсов**: изображения размещаются в логичных каталогах в структуре проекта

Этот удобный рабочий процесс позволяет создавать и внедрять визуальный контент, не выходя из среды разработки.

<Note>
  Генерация изображений в Replit работает на базе [Imagen 4 от Google](https://deepmind.google/models/imagen/) — передовой модели преобразования текста в изображение, которая создаёт высококачественные фотореалистичные изображения и точно отображает текст.
</Note>
