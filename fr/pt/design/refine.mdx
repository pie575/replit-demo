Explorer élargit les possibilités ; affiner permet de peaufiner les détails. Lorsqu’un frame est déjà proche de ce que vous souhaitez, deux outils vous permettent de le perfectionner avec précision, selon votre façon de travailler :

* Échangez avec l’Agent dans vos propres mots, à propos d’un frame entier ou d’un seul élément.
* Ajustez directement les éléments dans le Visual Editor, avec des modifications simples appliquées instantanément, sans consommer de crédits.

<div id="chat">
  ## Chat
</div>

Expliquez à Agent ce que vous souhaitez, comme vous le feriez à un designer en pleine révision. Sélectionnez un frame et décrivez les modifications dans le chat principal (*« des couleurs plus chaudes »*, *« le hero semble vide »*), ou sélectionnez l’outil **Chat** dans la barre d’outils et cliquez sur un élément pour limiter votre message à cet élément.

</Frame>

Consultez [Chat](/fr/pt/design/chat-about-your-design) pour découvrir les deux points d’entrée.

<div id="visual-editor">
  ## Visual Editor
</div>

Lorsque vous savez déjà exactement ce que vous voulez, passez directement au Visual Editor. Sélectionnez l’outil **Edit** dans la barre d’outils, puis cliquez sur n’importe quel élément : le Visual Editor s’ouvre avec les propriétés modifiables de cet élément, telles que le contenu, la mise en page, la couleur et la bordure. Les modifications simples, comme les changements de texte, les choix de couleur et les ajustements d’espacement, sont appliquées instantanément au code source, sans consommer de crédits.

<Frame caption="L’outil Edit est actif avec un élément sélectionné, et le Visual Editor affiche ses propriétés modifiables.">

Consultez la page [Visual Editor](/fr/pt/design/visual-editor) pour accéder à la référence complète des commandes.

<div id="qual-ferramenta-usar">
  ## Quel outil utiliser
</div>

| Vous voulez…                                                                                | Utilisez      |
| ------------------------------------------------------------------------------------------- | ------------- |
| Décrire le résultat souhaité et laisser Agent gérer les détails                             | Chat          |
| Modifier le texte, la couleur, l’espacement ou l’image d’un élément selon une valeur connue | Visual Editor |
| Revoir la structure ou le comportement d’une section                                        | Chat          |
| Effectuer un ajustement rapide sans consommer de crédits                                    | Visual Editor |

Les deux outils se complètent naturellement : utilisez Chat pour définir une orientation, puis cliquez dans le Visual Editor pour peaufiner les détails.
