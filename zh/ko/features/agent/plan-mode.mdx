Plan 模式提供了一种全新的方式，让你可以与 Replit Agent 对话，专注于提问、构思和规划工作。

<div id="plan">
  ## 什么是 Plan 模式？
</div>

使用 Plan 模式，您可以：

* 探索项目的不同实现方案，进行**创意构思**
* 通过结构化任务清单**规划开发工作**
* 就项目架构和功能规划与 **AI 协作**
* 在不修改项目代码或数据的情况下，**获取策略建议并提出问题**
* 准备就绪后，**无缝切换**到 Build 模式

默认模式现称为 **Build** 模式。

不同于 Build 模式，Plan 模式专注于规划和创意构思，帮助您在编写代码前充分思考项目。

<div id="section">
  ## 开始使用
</div>

<div id="plan-2">
  ### 访问 Plan 模式
</div>

所有启用了 Agent 的 Replit 应用都可使用 Plan 模式。要进入该模式：

1. **在 Project Editor 中打开 Replit 应用**
2. **找到聊天输入框左下角的模式选择器**
3. **在下拉菜单中选择 Plan 模式**

<div id="section-2">
  ## 主要功能
</div>

<div id="section-3">
  ### 任务规划
</div>

Plan 模式擅长将复杂的项目拆解为易于管理的任务。向 Agent 说明需求后,它会生成一份有序的开发任务清单,涵盖完成该请求所需的各项工作。

<div id="section-4">
  ### 协作式创意构思
</div>

与 AI 一起探索多种思路：

* 解决复杂问题的**多种路径**
* 不同方法的**优缺点分析**
* **风险评估**与缓解策略

<div id="section-5">
  ## 工作流：从规划到构建
</div>

<div id="1-plan">
  ### 1. 规划阶段 (Plan 模式) 
</div>

在 Plan 模式下开始你的开发流程：

* **明确**项目范围与目标
* 将需求**拆解**为具体功能
* **规划**架构与技术栈
* **制定**包含里程碑的开发路线图

<div id="2">
  ### 2. 批准任务
</div>

当 Agent 生成任务清单后：

* **查看**建议的任务
* 选择**开始构建**以批准计划

您也可以继续对话，进一步完善计划。

<div id="3-build">
  ### 3. 切换到 Build 模式
</div>

准备好开始实现时：

* **点击&quot;开始构建&quot;**以批准计划
* **Agent 会自动**切换到 Build 模式
* **Agent 开始实现已批准的任务**
* 在开发阶段**跟踪进度**

使用 Plan 模式与其他 Agent 交互一样，采用基于工作量的计费方式。Plan 模式下的所有 Agent 操作都会计费，包括回答问题、提供指导或生成任务清单。请求越复杂、Conversation 上下文越长，费用就越高。

**所有 Agent 交互都会计费** —— 无论 Agent 是以文字说明回复还是修改代码，都会产生费用，但较小的请求花费更少。

<div id="section-9">
  ## 最佳实践
</div>

<div id="section-10">
  ### 编写有效的提示词
</div>

要充分利用 Plan 模式：

* **明确说明**项目需求
* 提出**后续问题**，以明确 AI 的建议
* 讨论复杂概念时，**请求示例**
* **讨论不同方法之间的权衡**
* 确定实施方案前，**反复打磨想法**
* **保存重要决策**，以便在后续对话中参考
