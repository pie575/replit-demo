Задайте команду и расписание — Replit будет автоматически выполнять её
в среде вашего Replit App. После выполнения команда завершает работу до следующего
запланированного запуска.

Запланированные развёртывания, также известные как запланированные задания, лучше всего подходят для периодических задач,
таких как проверка состояния, отправка уведомлений и запуск резервного копирования. Они не предназначены
для непрерывных или длительных задач, например веб-приложений.

<div id="recursos">
  ## Возможности
</div>

Запланированные развёртывания включают следующие возможности:

* **Автоматическое планирование**: Запланируйте задачу — Replit выполнит её автоматически.
* **Планирование на естественном языке**: Введите понятное описание расписания, и ИИ преобразует его в cron-выражение — машиночитаемый формат расписания.
* **Оповещения об ошибках**: Получайте уведомления, если запланированная задача завершится с ошибкой.
* **Мониторинг**: Просматривайте логи и отслеживайте статус запланированного развёртывания.

<div id="uso">
  ## Использование
</div>

Доступ к запланированным развёртываниям можно получить через инструмент Publishing в Project Editor.

В следующих разделах описывается настройка и управление запланированными развёртываниями.

<Accordion title="Как открыть запланированные развёртывания">
  На **панели инструментов** слева:

  1. Выберите <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Иконка всех инструментов" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**, чтобы открыть список инструментов Project Editor.
  2. Выберите <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Иконка Publishing" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publishing**.
  3. Выберите **Scheduled**, затем — **Set up your published app**.

  В **строке поиска**:

  1. Нажмите на <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="иконка лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> иконку лупы вверху, чтобы открыть поиск.
  2. Введите &quot;Publishing&quot;, найдите инструмент и выберите его в результатах поиска.
  3. Выберите **Scheduled**, затем — **Set up your published app**.
</Accordion>

<div id="configurao-da-mquina">
  ### Конфигурация машины
</div>

В этом поле указаны ЦП, ОЗУ и стоимость использования машины для запланированного развёртывания.

<div id="campos-de-agendamento">
  ### Поля расписания
</div>

* **Schedule description**: Введите описание расписания на естественном языке, например «Каждый понедельник и среду в 10:00» или «24 марта 2024 года в 15:00».
* **Cron expression**: При необходимости введите машиночитаемую строку, определяющую время выполнения задачи.
* **Timezone selection**: Выберите часовой пояс для расписания в раскрывающемся меню.

Когда вы вводите значение в поле **Schedule description** или **Cron expression**, ИИ автоматически преобразует его в другой формат.
Подробнее о cron-выражениях см. на странице Википедии о <a href="https://en.wikipedia.org/wiki/Cron" target="_blank">cron</a>.

<div id="tempo-limite-do-job">
  ### Тайм-аут задания
</div>

Укажите максимальное время выполнения задания, по истечении которого планировщик остановит его. Выберите &quot;minutes&quot; или &quot;hours&quot; в раскрывающемся списке единиц времени.

<Tip>
  Запланированные задания могут выполняться медленнее, чем в Project Editor. Протестируйте
  развёртывание и при необходимости скорректируйте тайм-аут.
</Tip>

<div id="build-command">
  ### Команда сборки
</div>

В поле **Build command** введите команду Shell, которая собирает или настраивает ваше приложение перед выполнением Run command.
Например, чтобы установить зависимости приложения Node.js, добавьте команду сборки `npm install`.

Время выполнения команды сборки не учитывается в вашем потреблении и не вычитается из ограничения времени выполнения job.

<div id="run-command">
  ### Run command
</div>

Введите в поле **Run command** команду Shell, которая запускает вашу задачу.
Например, чтобы запустить скрипт Python, можно указать `python app.py` в качестве команды запуска.

Планировщик Replit выполняет команду запуска по расписанию.
Время выполнения команды учитывается в вашем объёме использования. Подробнее о биллинге по мере использования
см. [раздел Scheduled Deployments](/ru/pt/billing/deployment-pricing#scheduled-deployments) в документации по ценам.

<div id="deployment-secrets">
  ### Секреты развёртывания
</div>

Выберите **Add deployment secret**, чтобы добавить переменные окружения или secrets, необходимые для безопасной работы приложения.

Если в вашем Replit App есть переменные окружения или secrets, инструмент Publishing автоматически добавит их в список.

Чтобы изменить значение переменной окружения, выберите

<img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" width="16" height="16" alt="значок с тремя вертикальными точками" data-path="images/icons/vertical-dots.svg" /> три вертикальные точки и в меню выберите **Edit**. Менеджер Secrets применяет
значение только к развёртыванию и не изменяет переменные окружения, заданные в вашем
Replit App.
