Canvas 是一个可平移和缩放的无限画布，Replit Design 会在这里展示 frames。你设计的所有内容都在这里：生成 frames、拖动它们、放大查看细节，并不断迭代，直到满意为止。

<div id="abra-o-canvas">
  ## 打开 Canvas
</div>

Canvas 是您在 Replit Design 中首先看到的界面。在项目中，选择顶部的 **Design**，Canvas 会填满面板；选择 **Build** 可返回正在运行的 App。

<Frame>
  <img src="/assets/mirror/canvas-design-button-ffa50447cefb.png" alt="项目顶部特写，显示 Design 和 Build 切换选项，已选中 Design，Canvas 中显示多个 frame" width="987" height="619" data-path="images/replitai/canvas-design-button.png" />
</Frame>

在 [replit.com/design](https://replit.com/design) 从头开始时，系统会提示您创建新的设计，并在 Canvas 中打开。请参阅 [Design 与 Build](/zh/pt/design/design-vs-build)，了解何时使用各个工作区。

<div id="o-que-vive-no-canvas">
  ## Canvas 上有哪些内容
</div>

* **Frame**：Canvas 上的每个区块。frame 可以是设计模型、Web App、移动 App、幻灯片、图像、视频或矢量图形。你可以通过 Chat 提示词、工具栏中的[生成菜单](/zh/pt/design/toolbar#generate)或[素材库面板](/zh/pt/design/library-panel)生成它们。针对 frame 执行的所有操作，包括构建、聚焦和获取建议，都会通过 frame 本身完成：请参阅[Frames](/zh/pt/design/frames)。
* **绘图和注释**：使用[绘图工具](/zh/pt/design/toolbar#draw)添加的标记，例如草图、箭头、形状和便签。Agent 会读取这些标记，因此你可以圈出有问题的区域并请求修改。
* **Chat 面板**：停靠在 Canvas 旁的 Agent Chat。发送消息前选择 frame，会将其作为快照附加，让 Agent 获得视觉上下文。

如需了解各组件的用途及其如何配合使用，请参阅[组件概览](/zh/pt/design/core-components)。

<div id="navegue-pelo-quadro">
  ## 浏览画布
</div>

除非另有说明，否则无论使用哪种工具，都可以进行平移、缩放和选择。

**平移：**

* 触控板：双指拖动。
* 鼠标：按住中键并拖动，或按住空格键后用左键拖动。
* [平移工具](/zh/pt/design/toolbar#pan)：用鼠标左键拖动。

**缩放：**

* 触控板：双指捏合。
* 鼠标：`Ctrl` (macOS 上为 `Cmd`) + 滚轮。
* 键盘：`Cmd`/`Ctrl` + `+` 放大，`Cmd`/`Ctrl` + `-` 缩小，`Cmd`/`Ctrl` + `0` 重置缩放。

缩放以光标为锚点，因此光标下方的位置会保持不变，其余画布则围绕该位置缩放。

**选择：**

* 单个 frame：使用[交互工具](/zh/pt/design/toolbar#interact)点击该 frame。
* 多选：按住 `Shift` 并点击每个 frame，或在画布上拖动出一个选择框。
* 取消选择：点击空白区域，或按 `Escape`。

选择一个或多个 frame 会显示[每个 frame 的操作栏](/zh/pt/design/frames#per-frame-action-bar)，并将这些 frame 作为快照附加到发送给 Agent 的下一条消息中。

<div id="atalhos-de-teclado">
  ### 键盘快捷键
</div>

| 快捷键                            | 操作           |
| ------------------------------ | ------------ |
| `V`                            | 切换到交互工具      |
| `H`                            | 切换到平移工具      |
| 按住 `Space` 并拖动                 | 使用任何工具时平移画布  |
| `Cmd` / `Ctrl` + 滚动            | 缩放           |
| `Cmd` / `Ctrl` + `+`           | 放大           |
| `Cmd` / `Ctrl` + `-`           | 缩小           |
| `Cmd` / `Ctrl` + `0`           | 重置缩放         |
| `Shift` + 点击                   | 将 frame 添加到当前选区   |
| `Cmd` / `Ctrl` + `Shift` + `C` | 将所选 frame 复制为 PNG |
| `Escape`                       | 取消选择         |

<div id="menu-do-boto-direito">
  ## 右键菜单
</div>

在画布任意位置右键单击，即可打开上下文菜单。菜单会根据上下文调整，操作会随光标下的内容而变化：frame 会显示 frame 操作，空白 Canvas 会显示画布级操作，而 App frame 还会显示**更新产物**。

选中 frame 后，菜单包含：

| 操作          | 快捷键                           | 功能说明                                        |
| ----------- | ----------------------------- | ------------------------------------------- |
| 编辑          |                               | 切换到编辑工具，以选择 frame 内的元素。                          |
| Chat        |                               | 与 Agent 讨论该 frame。                              |
| 聚焦          |                               | 进入该 frame 的[聚焦模式](/zh/pt/design/frames#focus-mode)。 |
| 光标 Chat     | `/`                           | 在光标位置启动快速 Chat。                             |
| 重新排序        |                               | 在堆叠顺序中将 frame 前移或后移。                             |
| 复制、粘贴、重复、删除 | `⌘C`, `⌘V`, `⌘D`, `Backspace` | 标准的剪贴板和 frame 管理操作。                              |
| 导出为…        |                               | 将 frame 导出为文件。                                   |
| 全选          | `⌘A`                          | 选择画布上的所有 frame。                                 |

<div id="exportar-um-frame-como-png">
  ### 将 frame 导出为 PNG
</div>

将任何产物或设计 frame 保存为 PNG 图像。你可以用它在文档或 Chat 中分享预览、在继续迭代前保存快照，或向团队成员发送截图。

<Steps>
  <Step title="选择 frame">
    选择要导出的产物或设计 frame，然后等待其加载完成。
  </Step>

  <Step title="选择“导出”">
    在 frame 操作栏中选择**导出**。你也可以右键点击 frame，然后选择**导出为…** &gt; **PNG**。图像会下载到你的计算机，文件名基于 frame 名称。
  </Step>
</Steps>

如需将所选 frame 复制为 PNG 而非下载，请按 `Cmd+Shift+C` (Windows 和 Linux 上为 `Ctrl+Shift+C`) 。

<Note>导出的 PNG 与 frame 当前在 Canvas 中显示的内容一致。如果你的 App 或设计仍在加载，请等待其完全渲染后再导出。</Note>

<div id="o-canvas-e-o-app-em-execuo">
  ## Canvas 与正在运行的 App
</div>

Canvas 与正在运行的 App 预览共用同一面板，部分模式可在两者之间衔接：

* **聚焦模式**：对选中的 frame 执行 **聚焦** 操作，可将其展开至填满视图。选择 frame 顶部的 **退出聚焦**，即可返回 Canvas。
* **只读模式**：当 Canvas 在后台任务上下文中被锁定时，迭代操作会被隐藏，仅保留聚焦功能。

<Note>
  从 Design frame 构建新的 App 需要 Core 或 Pro；其他所有 Canvas 功能适用于任何套餐。有关套餐详情，请参阅 [Billing](/zh/pt/billing/ai-billing)。
</Note>
