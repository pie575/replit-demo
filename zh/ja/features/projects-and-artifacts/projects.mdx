<div id="section">
  ## 什么是项目？
</div>

项目是你在 Replit 上构建的一切的容器。它保存代码、数据以及你创建的所有 artifact (Web 应用、移动应用、幻灯片、数据看板、视频) 。只要告诉 Agent 你想要什么，它就会为你搭建好项目，并在其中构建 artifact。

你可以把项目想象成桌面上的工作台：所有东西都放在一处，共享同一份信息，但每个部件各司其职。

例如，当你让 Agent 构建一个健身追踪应用时，它会创建一个项目，其中包含移动应用 artifact，以及支撑它运行所需的后端、数据库和存储。

<ArtifactGrid />

核心概念：

* **项目**：保存一切的容器 —— 代码、数据和所有 artifact
* **Artifact**：项目中可发布的成果 (Web 应用、幻灯片、视频等)
* **资源**：所有 artifact 都能自动使用后端、数据库和文件存储 —— 无需任何设置

<Note>
  发布时，整个项目会一次性部署。所有 artifact 同时发布，因此始终保持同步。
</Note>

<div id="section-2">
  ## 你可以构建什么
</div>

| 类型                                                           | 说明                     | 示例                 |
| ------------------------------------------------------------ | ---------------------- | ------------------ |
| **[Web 应用](/zh/ja/features/artifact-types/web-apps)**           | 通过浏览器访问的网站或 Web 应用程序   | 在线商店、预约工具、作品集网站    |
| **[移动应用](/zh/ja/features/artifact-types/building-mobile-apps)** | 安装在手机上的原生应用            | 健身追踪器、餐厅点餐应用       |
| **[数据可视化](/zh/ja/features/artifact-types/data-apps)**           | 带有图表、筛选器和实时数据的交互式仪表板   | 销售报表、指标追踪器、分析视图    |
| **[幻灯片](/zh/ja/features/artifact-types/slide-decks)**           | 可用于演示或导出的幻灯片           | 路演材料、团队进展汇报、产品概览   |
| **[动画](/zh/ja/features/artifact-types/animated-videos)**        | 可导出为 MP4 的动态图形视频       | 产品发布视频、讲解视频、社交媒体内容 |
| **3D 游戏**                                                    | 3D 游戏、模拟和交互式体验         | 益智游戏、物理模拟、交互式体验    |
| **[设计](/zh/ja/design/canvas)**                              | 在设计 Canvas 中探索的视觉方向与原型 | 情绪板、模型稿、设计探索       |

一个项目可以包含多个 artifact。例如，你可以在同一个项目中构建面向客户的 Web 应用、面向团队的移动应用以及面向投资人的幻灯片。同一项目内的 artifact 会自动共享相同的数据和后端逻辑。详情请参阅 [artifact](/zh/ja/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project)。

<div id="section-3">
  ## 管理项目
</div>

项目页面会列出你创建的以及受邀加入的所有项目。要快速回到最近的工作，或在繁忙的工作区中找到需要的项目，这里是最快的入口。

<div id="section-4">
  ### 一眼看清每个项目的内容
</div>

每张项目卡片都会显示其所含 artifact 的小图标 (Web 应用、移动应用、幻灯片、数据可视化、动画各有对应图标) 。将鼠标悬停在图标上，即可在卡片上预览该 artifact 的截图，无需打开项目即可加以区分。

</Frame>

<div id="section-5">
  ### 按 artifact 筛选
</div>

使用项目页面顶部的**构建类型**下拉菜单，按 artifact 筛选列表。选择某一类型后，将只显示包含该类型 artifact 的项目：

* **Web** — 包含 Web 应用的项目
* **移动端** — 包含移动应用的项目
* **数据** — 包含数据可视化的项目
* **幻灯片** — 包含幻灯片的项目
* **设计** — 处于设计模式的项目
* **3D 游戏**、**智能体与自动化**等

选择**所有构建类型**即可清除筛选。

<div id="section-6">
  ### 按最后打开时间排序
</div>

项目页面默认按**你最后打开的时间**排序——最近处理过的项目会显示在最上方。这在团队工作区中尤其实用，其他成员的近期编辑不会把你当前的工作挤到下面。

你也可以点击其他列标题 (例如**最后修改**或**名称**) 来更改排序方式。

<div id="section-7">
  ### 置顶常用项目
</div>

将常用项目置顶，使其固定显示在列表最上方。置顶**仅对你个人生效**——即使你在团队工作区中置顶了某个项目，其他成员看到的排列顺序也不会改变。

要置顶项目，请打开项目卡片上的更多菜单 (三个点) ，然后选择**置顶**。要取消置顶，请在同一菜单中选择**取消置顶**。
