Transformez votre App en site web professionnel accessible en ligne.

Avec l’achat de domaine, vous pouvez rechercher, acheter et connecter un domaine à votre App déployée sur Replit — le tout depuis la plateforme. Passez d’une App déployée à une présence web professionnelle en quelques minutes.

Autrement dit, vous pouvez acheter un nom de domaine tel que `my-app.com` et le connecter automatiquement à votre App.

<div id="section">
  ## Fonctionnalités
</div>

L&#39;achat de domaines simplifie l&#39;attribution d&#39;une adresse web professionnelle à votre application. Vous pouvez configurer l&#39;ensemble de votre présence en ligne dans Replit sans avoir à recourir à plusieurs services.

<Frame>
  <img src="/assets/mirror/replit-domains-8453291b634b.png" alt="Interface de gestion des domaines affichant les domaines achetés et leur état de connexion" width="3176" height="1556" data-path="images/deployments/custom-domains/replit-domains.png" />
</Frame>

Principales fonctionnalités :

* **Recherche de domaines et vérification de disponibilité** : vérifiez la disponibilité de domaines avec des extensions populaires telles que `.com` et `.ai`
* **Achat en un clic** : achetez des domaines directement dans Replit à l&#39;aide du mode de paiement par défaut de votre compte
* **Configuration automatique** : votre domaine pointe immédiatement vers votre application Replit, sans configuration DNS manuelle
* **Protection de la confidentialité WHOIS** : vos informations personnelles restent privées dans les enregistrements de domaine publics — incluse par défaut avec tous les achats de domaines
* **Enregistrements DNS personnalisés** : ajoutez des enregistrements A, TXT et MX personnalisés pour configurer des fournisseurs de messagerie et d&#39;autres services
* **Publication immédiate** : votre application devient accessible sur votre domaine personnalisé dès l&#39;achat
* **Renouvellement automatique** : votre domaine est automatiquement renouvelé afin que votre application reste publiée sans interruption

<div id="section-2">
  ## Comment l&#39;utiliser
</div>

<div id="section-3">
  ### Acheter un domaine
</div>

1. Publiez votre application, puis accédez à l’onglet <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Icône Publish" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publishing**
2. Sélectionnez l’onglet **Domains**
3. Sélectionnez **Buy a domain** pour lancer la recherche
4. Saisissez le nom de domaine souhaité dans le champ de recherche
5. Consultez les options proposées avec différentes extensions
6. Sélectionnez le domaine souhaité et finalisez l’achat

Lorsque vous achetez un domaine, il est automatiquement configuré pour pointer vers votre application Replit. Vous pouvez accéder immédiatement à votre application via votre domaine personnalisé, sans configuration supplémentaire.

Les frais d’achat du domaine sont facturés via votre compte Replit, déduits du solde de votre compte, puis comptabilisés dans votre utilisation.

<div id="section-4">
  ### Gérer les domaines achetés
</div>

Les domaines s’intègrent parfaitement aux applications déployées.

* **Renouvellement automatique** : les domaines sont automatiquement renouvelés pour que vos applications restent publiées
* **Facturation unifiée** : les frais de domaine apparaissent sur votre facture Replit avec ceux des autres services
* **Prise en charge des transferts** : transférez des domaines entre des comptes Replit ou vers un bureau d’enregistrement externe si nécessaire

<div id="dns">
  ### Enregistrements DNS personnalisés
</div>

Pour les domaines achetés via Replit, vous pouvez ajouter des enregistrements DNS personnalisés afin de configurer des services supplémentaires, tels qu’un fournisseur de messagerie. Types d’enregistrements DNS pris en charge :

* **Enregistrement A** : associe un domaine ou un sous-domaine à une adresse IP spécifique
* **Enregistrement TXT** : ajoute des enregistrements d’authentification textuels pour des services d’authentification par e-mail tels que SPF, DKIM et DMARC
* **Enregistrement MX** : les enregistrements MX (échange de courrier) indiquent aux serveurs de messagerie où acheminer les e-mails de votre domaine. La configuration d’un enregistrement MX vous permet d’utiliser votre domaine personnalisé pour des adresses e-mail telles que `hello@yourdomain.com`.

Pour gérer les enregistrements DNS d’un domaine acheté :

1. Accédez à l’onglet **Domains** dans Publishing <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Publish icon" width="16" height="16" data-path="images/icons/deploy-icon.svg" />
2. Recherchez le domaine que vous souhaitez configurer
3. Sélectionnez l’icône **Edit** <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="pencil icon" width="16" height="16" data-path="images/icons/pencil-icon.svg" />
4. Sélectionnez **Add DNS Record**
5. Saisissez le type, le nom, la valeur et le TTL de l’enregistrement requis par votre fournisseur de services

Cette courte vidéo vous montre comment accéder à la page de gestion des enregistrements DNS de votre domaine.

<div id="faq">
  ## FAQ
</div>

<AccordionGroup>
  <Accordion title="Combien cela coûte-t-il ?">
    L&#39;achat d&#39;un domaine comprend deux frais.

    * **Frais d&#39;enregistrement :** coût initial pour enregistrer le domaine pendant un an (deux ans pour les domaines `.ai`)
    * **Prix de renouvellement :** facturé automatiquement après la période d&#39;enregistrement initiale

    Replit ne facture aucuns frais supplémentaires pour l&#39;achat de domaines. Les frais d&#39;enregistrement de domaine ne sont pas remboursables.
  </Accordion>

  <Accordion title="Comment renouveler mon domaine ?">
    Replit renouvelle automatiquement votre domaine afin que votre application reste accessible. Pour désactiver le renouvellement automatique, ouvrez l&#39;onglet **Domains** dans l&#39;outil Publishing, sélectionnez votre domaine, puis désactivez le commutateur **Auto renewal**. Vous pouvez consulter la date et le prix de renouvellement de votre domaine sur le même écran.
  </Accordion>

  <Accordion title="Que se passe-t-il si je souhaite quitter Replit ?">
    Vous pouvez contacter l&#39;assistance Replit pour transférer votre domaine vers un autre bureau d&#39;enregistrement. Conformément aux règles de l&#39;ICANN, vous devez attendre 60 jours après l&#39;achat avant de pouvoir transférer un domaine vers un bureau d&#39;enregistrement externe.
  </Accordion>

  <Accordion title="Puis-je transférer un domaine entre des comptes Replit ?">
    Oui, vous pouvez contacter l&#39;assistance Replit pour transférer un domaine entre des comptes Replit. Ce processus ne nécessite pas de délai d&#39;attente de 60 jours.
  </Accordion>

  <Accordion title="Puis-je acheter un domaine pour mon organisation ?">
    L&#39;achat de domaines pour les forfaits Replit Pro et Enterprise sera disponible après la période bêta initiale.
  </Accordion>

  <Accordion title="Puis-je ajouter des enregistrements DNS personnalisés à mon domaine ?">
    Oui ! Vous pouvez ajouter des enregistrements DNS personnalisés aux domaines achetés via Replit. Types d&#39;enregistrements actuellement pris en charge :

    * **Enregistrement A :** associe un domaine ou un sous-domaine à une adresse IP spécifique
    * **Enregistrement TXT :** ajoute des enregistrements de validation textuels pour la vérification des e-mails et d&#39;autres services
    * **Enregistrement MX :** configure les serveurs de messagerie qui gèrent les e-mails de votre domaine

    Accédez à l&#39;onglet Domains de Publishing pour configurer ces enregistrements. Pour obtenir des instructions détaillées sur la configuration d&#39;enregistrements MX pour les e-mails, consultez la section [Enregistrements DNS personnalisés](#custom-dns-records) ci-dessus.
  </Accordion>

  <Accordion title="Quelles extensions de domaine sont prises en charge ?">
    Nous prenons en charge tous les domaines de premier niveau (TLD) courants. Les TLD soumis à des restrictions géographiques ou autres particulières peuvent ne pas être pris en charge.
  </Accordion>

  <Accordion title="Qu'est-ce que la protection de la confidentialité WHOIS ?">
    Lorsque vous enregistrez un domaine, vos coordonnées (nom, adresse, numéro de téléphone et e-mail) sont généralement publiées dans une base de données publique appelée WHOIS, que tout le monde peut consulter. La protection de la confidentialité WHOIS remplace vos informations personnelles par les informations génériques du bureau d&#39;enregistrement afin de préserver la confidentialité de vos données tout en respectant les exigences légales.

    Tous les domaines achetés via Replit incluent par défaut la protection de la confidentialité WHOIS, sans frais supplémentaires. Cela signifie que vos informations personnelles sont masquées pour les spammeurs, les spécialistes du marketing et toute autre personne recherchant les informations du propriétaire du domaine.
  </Accordion>

  <Accordion title="Que se passe-t-il si je possède déjà un domaine ?">
    Pour connecter un domaine existant à une application Replit, consultez la documentation sur les [domaines personnalisés](/fr/ko/features/publishing/custom-domains).
  </Accordion>
</AccordionGroup>
