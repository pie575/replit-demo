每个 Replit 项目的页眉中都并排提供两个入口：**Design** 和 **Build**。Design 用于塑造软件的外观；Build 则由 Agent 将其实现为可用的应用。它们打开的是同一个项目，因此你在 Design 中完成的设计不会留在独立的设计工具里。

<div id="what-is-design">
  ## 什么是 Design？
</div>

[Design](/zh/design/what-is-replit-design) 会打开 Canvas，你可以在其中根据 prompt 生成 design frame、探索不同版本并完善最满意的方案，全程无需编写代码。

Design 非常适合：

* **快速验证想法**：在构建功能前直观呈现 App 的设计
* **创建精美网站**：landing page、作品集、餐厅菜单和活动页面
* **精细调整设计**：即时调整颜色、布局和内容

<Info>
  Design 模拟稿看起来和操作起来都像真实页面，但暂时无法存储数据或连接外部服务。当你对整体效果满意后，只需单击一下，即可将设计构建成完整的 App。以下步骤将为你介绍具体方法。
</Info>

<div id="what-is-build">
  ## 什么是 Build？
</div>

Build 可将你的创意变成功能完善的应用，能够保存数据、让用户登录，并连接其他服务。

当你的 App 需要以下功能时，请使用 Build：

* **用户账户**：让用户创建账户并登录
* **保存信息**：存储订单、消息或用户偏好等数据
* **连接其他服务**：处理付款、发送电子邮件或从其他 App 获取数据
* **复杂任务**：运营在线商店、管理预订或驱动仪表板

<div id="using-both-together">
  ## 两者结合使用
</div>

Design 和 Build 可在同一个项目中协同使用，无需二选一。先从外观设计入手，逐步打造出完整的应用。

<Steps>
  <Step title="先进行设计">
    先在 Design 中快速将想法可视化。重点关注应用的外观和体验：布局、颜色、按钮和用户体验。
  </Step>

  <Step title="优化迭代">
    使用[建议](/zh/design/explore-suggestions)为选定的 frame 探索新方向，或选择 **Edit** 工具并点击元素，在 [Visual Editor](/zh/design/visual-editor) 中进行调整。你还可以[与 Agent 对话](/zh/design/chat-about-your-design)，描述想要进行的更改。

    <Frame>
      <img src="/assets/mirror/ambient-iq-0989ea31bce7.png" alt="选中的 Website frame 显示 APEX X1 超级跑车主视觉，旁边是 Suggested next steps 面板，提供 Explore different approaches、Try different layouts、Explore different vibes 和 Surprise me 等建议选项" width="2000" height="1254" data-path="images/design/replit-design/ambient-iq.png" />
    </Frame>
  </Step>

  <Step title="构建设计">
    当你对设计感到满意并准备添加实际功能时，在 frame 上选择 **Build…**。创建新的 artifact，或将设计应用到现有 artifact；Agent 会添加保存数据、管理用户账户和连接服务的功能，同时保留你的设计。

    <Frame>
      <img src="/assets/mirror/canvas-build-menu-f06b8b8b455f.png" alt="在选中的 Design frame（APEX X1 Exact Replica）上打开的 Build 菜单，标题为“Build or apply your designs”，显示“Build this design”（用于创建新的 artifact）以及“Apply to an existing creation”，后者列出了项目的 APEX X1 Design System 和其 Scroll Hero 网站" width="2000" height="1153" data-path="images/replitai/canvas-build-menu.png" />
    </Frame>

    <Note>
      当你尝试为原型添加数据库或高级功能时，Agent 会提示你进行转换。
    </Note>
  </Step>

  <Step title="发布和分享">
    应用构建完成后，将其发布，让任何人都能在线访问。Replit 会处理所有技术基础设施，确保你的应用能稳定地为用户提供服务。
  </Step>
</Steps>

<div id="when-to-start-in-each">
  ## 分别何时开始使用
</div>

<CardGroup cols={2}>
  <Card title="从 Design 开始" icon="paintbrush">
    * 外观设计是难点
    * 你想快速看到想法呈现出来
    * 你想探索和比较不同方案
    * 速度是你的首要考量
  </Card>

  <Card title="从 Build 开始" icon="cube">
    * 功能实现是难点
    * 你的 App 从一开始就需要保存数据
    * 用户需要登录
    * 你需要连接其他服务
  </Card>
</CardGroup>

<Tip>
  **不确定该选哪个？**从 Design 开始。它更快，而且之后你随时可以将设计构建成完整的 App。你的工作不会白费，进入 Build 后可以延续已有成果。反过来也一样：先在 Build 中让 App 正常运行，再在 Design 中调整其样式。
</Tip>

<div id="key-differences">
  ## 主要区别
</div>

| 功能       | Design (原型)  | Build (应用)   |
| -------- | ------------ | ------------ |
| **速度**   | 几分钟          | 完整应用约需 10 分钟 |
| **数据存储** | 仅视觉呈现 (不保存)  | 保存和检索真实数据    |
| **用户账户** | 展示登录界面的外观    | 实际登录功能       |
| **连接服务** | 不支持          | 支付、电子邮件、外部数据 |
