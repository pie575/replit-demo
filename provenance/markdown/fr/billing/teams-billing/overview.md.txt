# Aperçu

> Découvrez la facturation pour les organisations sur Replit Pro, notamment les crédits progressifs, l'utilisation mutualisée et la migration depuis l'ancien plan Teams.

## Replit Pro

Le **plan Pro** a remplacé l'ancien plan Teams. Pro **n'a pas de frais par siège** : vous obtenez **jusqu'à 15 constructeurs** avec des **crédits mutualisés** et des contrôles budgétaires. Tout le monde travaille depuis le même plan. Consultez [Replit Pro](/fr/billing/plans/replit-pro) pour les fonctionnalités complètes du plan Pro.

## Facturation et utilisation

Les factures incluent le coût de votre plan et les frais basés sur l'utilisation. Pour consulter les factures passées et à venir, visitez la page d'utilisation. L'utilisation est suivie par espace de travail afin que vous puissiez voir comment les crédits sont consommés dans votre organisation. Consultez [Espaces de travail](/fr/features/collaboration/workspaces) pour savoir comment les projets, les coéquipiers, les paramètres et la facturation sont organisés.

## Tarification basée sur l'utilisation

Consultez la [Facturation basée sur l'utilisation](/fr/billing/about-usage-based-billing) pour des détails sur le calcul, le transfert de données, les bases de données et autres utilisations.
