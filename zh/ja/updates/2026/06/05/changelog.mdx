<div id="shopify">
  ### 使用 Shopify 销售实体商品
</div>

现在你可以搭建销售实体商品的在线商店了。只需让 Agent 帮你搭建商店，它就会创建 Shopify 商店、添加商品，并配置购物车和结账流程。Agent 会提供一个认领商店的链接，注册 Shopify 套餐并接入支付方式后，商店即可上线。

<div id="microsoft-fabricapp">
  ### 在 Microsoft Fabric 上构建数据 App
</div>

现在，您可以在 Replit 中构建 AI 驱动的数据 App，并将其直接发布到 Microsoft Fabric。您可以从 Microsoft Fabric 模板入手，连接 Power BI 语义模型，并让 Agent 基于受治理的企业数据构建仪表板和内部工具，同时将认证和访问策略保留在 Fabric 中。

<div id="dns">
  ### 自定义域名自动配置 DNS
</div>

连接自有域名变得更加简单。链接域名后，Replit 会通过 Entri 自动配置所需的 DNS 记录，无需再手动将记录复制到域名提供商处。只需选择并确认域名，其余的交给 Replit 处理。

了解更多关于[自定义域名](/zh/ja/features/publishing/custom-domains)的信息。

<div id="seo-agent">
  ### 使用 SEO Agent 提升搜索排名
</div>

SEO Agent 会检查已发布的 App，找出妨碍搜索引擎和 AI 工具发现 App 的问题。每个发现的问题都附带可一键查看和应用的修复方案。打开项目的 **Growth** 窗格并运行扫描。

<div id="stripe">
  ### 在协作工作区中使用 Stripe
</div>

Stripe 现已支持协作工作区，让整个团队都能构建、测试并通过同一个 App 实现盈利。工作区中的所有成员都可以使用已连接的 Stripe 账户协作，无需各自单独搭建支付功能。

了解更多关于 [Stripe 支付](/zh/ja/features/monetization/stripe-payments) 的信息。
