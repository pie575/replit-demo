# Vídeos Animados

> Aprenda como criar vídeos animados com o Agent — descreva o que você quer em linguagem cotidiana e exporte motion graphics polidos.

Crie vídeos animados profissionais com o Replit Agent. Descreva o vídeo que você quer em linguagem cotidiana, e o Agent gera motion graphics que você pode exportar e compartilhar — sem necessidade de habilidades de edição de vídeo ou agências caras.

## Visão geral

A Animação do Replit permite criar motion graphics polidos inteiramente por meio de conversas com o Agent. Estas são animações programáticas criadas com React — o Remotion não é utilizado; em vez disso, os Vídeos Animados dependem de uma combinação de bibliotecas de animação para sites e habilidades personalizadas do Agent. Isso não é vídeo gerado por IA como Runway ou Sora. Seus vídeos podem incluir sobreposições de texto, transições suaves, imagens geradas por IA e muito mais.

Os vídeos são reproduzidos automaticamente em loop no painel de Visualização, e você pode iterar sobre eles conversando com o Agent, assim como construindo qualquer outro aplicativo.

**Disponível para todos os construtores**, incluindo o nível gratuito.

## Criando um vídeo animado

Você pode começar a criar um vídeo animado de duas formas na página inicial do Replit:

### Opção 1: Digite um prompt

Selecione a aba **App** na página inicial e digite um prompt que descreva o vídeo que você quer. O Agent detectará automaticamente prompts relacionados a vídeo e selecionará a pilha de Vídeo Animado.

Exemplos de prompts:

* "Faça um vídeo promocional para minha nova marca de água com gás"
* "Crie um vídeo explicativo de 30 segundos sobre como funcionam os modelos de linguagem grandes"
* "Faça um vídeo promocional cinematográfico para a cidade de Austin, Texas"

### Opção 2: Selecione no menu suspenso

1. Acesse a aba **App** na página inicial.
2. Abra o menu suspenso de tipo de aplicativo.
3. Selecione **Animation**.
4. Digite uma descrição do vídeo que você quer criar.

Assim que o Agent começa a criar, ele gera a animação e a exibe no painel de visualização. Você pode assistir ao vídeo sendo reproduzido automaticamente em loop e continuar conversando para fazer alterações.

## Iterando no seu vídeo

Após o Agent gerar a primeira versão, você pode refiná-la por meio de conversa. Algumas abordagens que funcionam bem:

* **Use o botão Enhance Prompt** no campo de chat, que é ajustado especificamente para prompts de vídeo.
* **Peça melhorias** — dizer algo como "melhore" ou "adicione animações mais complexas dentro das cenas, seja mais criativo" após revisar a primeira versão tende a produzir bons resultados.
* **Seja específico** sobre o que você quer alterar — por exemplo, "torne as transições mais suaves", "mude o esquema de cores para azul escuro e dourado" ou "adicione uma revelação de logo no final".

Se você enviar alguns prompts diferentes, provavelmente ficará satisfeito com pelo menos um dos resultados.

## Exportando seu vídeo

Quando seu vídeo estiver bom, você pode exportá-lo como um arquivo MP4.

1. Localize o botão **Export** no canto superior direito do painel de Visualização.
2. Selecione suas configurações de qualidade preferidas:
   * **Resolução**: 720p ou 1080p
   * **Taxa de quadros**: 30fps ou 60fps
3. Selecione **Export**. A renderização pode levar alguns minutos dependendo da complexidade do vídeo.
4. Após a conclusão da renderização, o arquivo MP4 é baixado automaticamente.

Você também pode selecionar **Publish** para compartilhar um link para o vídeo.

**Tempos de exportação**: Vídeos mais longos ou mais complexos podem levar vários minutos para renderizar. Vídeos mais simples renderizam mais rápido. A exportação é executada no lado do servidor, então você pode continuar trabalhando enquanto ela processa.

## Casos de uso

Os Vídeos Animados funcionam bem para uma variedade de necessidades criativas e profissionais:

* **Vídeos de lançamento de produto** — anuncie um novo aplicativo, recurso ou lançamento de produto com uma promoção polida.
* **Vídeos de marca e cinematográficos** — crie vídeos visualmente ricos para empresas, cidades, universidades ou eventos.
* **Vídeos explicativos** — explique como um produto, recurso ou conceito funciona em 30 a 60 segundos.
* **Conteúdo para redes sociais** — crie motion graphics chamativos para Twitter/X, LinkedIn, Instagram ou TikTok.
* **Vídeos para landing pages** — adicione seções hero animadas ou vídeos de fundo ao seu site.
* **Vídeos de captação e atualizações para investidores** — crie vídeos profissionais de anúncio para marcos importantes.

## Especificações do vídeo

| Propriedade         | Detalhes                                                                                                                                 |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **Formato**         | MP4                                                                                                                                      |
| **Resolução**       | 720p ou 1080p                                                                                                                            |
| **Taxa de quadros** | 30fps ou 60fps                                                                                                                           |
| **Proporção**       | 16:9 (padrão)                                                                                                                            |
| **Renderização**    | No lado do servidor; bibliotecas de animação (normalmente usadas para sites) mais habilidades personalizadas do Agent — não usa Remotion |
| **Reprodução**      | Loop automático no painel de visualização                                                                                                |

## Perguntas comuns

* **Posso pausar ou reproduzir o vídeo?** A Visualização não inclui controles de pausa/reprodução integrados. Os vídeos sempre são reproduzidos automaticamente em loop. Se você quiser pausa/reprodução (ou seleção de cena) no seu vídeo, pode pedir ao Agent para adicioná-los — embora adicionar esses controles às vezes possa degradar a qualidade do design, então você pode preferir manter o loop padrão.
* **Há seleção de cena?** Não há seletor de cenas integrado na visualização. Você pode pedir ao Agent para adicionar seleção de cena ou outros controles se desejar; a mesma compensação se aplica como acima.

## Limitações

Os Vídeos Animados são um recurso novo e têm algumas limitações atuais a serem observadas:

* **Apenas animação programática**: Os vídeos são motion graphics baseados em React. Isso não é vídeo gerado por IA (como Runway ou Sora) — embora possa gerar vídeos e usá-los no código.
* **Tempo de renderização**: Animações complexas podem levar vários minutos para exportar. Vídeos mais simples renderizam mais rápido.
* **Iteração pode ser necessária**: Embora muitos prompts produzam ótimos resultados de primeira, você pode precisar iterar por 2 a 3 versões para obter exatamente o resultado que deseja. Usar o botão Enhance Prompt para o prompt inicial e dar feedback após o primeiro checkpoint ajuda.
