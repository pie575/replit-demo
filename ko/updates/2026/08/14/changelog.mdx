### 워크스페이스 스킬 공유 및 관리

이제 모든 워크스페이스 멤버가 스킬을 생성하여 비공개로 유지하거나 워크스페이스와 공유할 수 있습니다. 공유된 스킬은 다른 멤버에게는 기본적으로 꺼진 상태로 시작되며, 각자 어떤 스킬을 활성화할지 선택할 수 있습니다. 관리자는 모든 워크스페이스 스킬을 관리하고 워크스페이스에 특정 스킬을 필수로 지정할 수 있습니다. 재설계된 Skills 라이브러리를 통해 스킬을 더 쉽게 찾고 관리할 수 있습니다.

[Agent Skills](/ko/features/agent/skills)에 대해 자세히 알아보세요.

## 팀 및 엔터프라이즈

### Admin API 베타 출시

엔터프라이즈 계정 관리자는 이제 설정의 새로운 **Developer** 탭에서 API 키를 생성하고, Admin API를 사용해 다음 작업을 수행할 수 있습니다.

* 워크스페이스, 멤버, 사용자 그룹, 프로젝트, 배포를 조회합니다.
* 멤버, 프로젝트, 워크스페이스의 사용량을 원하는 기간 동안 조회합니다.
* 워크스페이스, 사용자 그룹, 개별 멤버의 예산을 조회하고 수정합니다.

[Admin API 문서](/ko/teams/admin-api)와 [API 레퍼런스](https://api.replit.com/docs)에서 자세히 알아보세요.
