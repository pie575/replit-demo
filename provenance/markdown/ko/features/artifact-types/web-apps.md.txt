# 웹 앱

> Agent로 풀스택 웹 애플리케이션을 만드는 방법을 알아보세요 — 기본적으로 반응형이며, 즉시 배포 가능하고, 공유할 수 있습니다.

웹 앱은 Replit의 기본 출력 유형입니다. Agent에게 아이디어를 설명하면, 다른 아티팩트 유형을 지정하지 않는 한 풀스택 웹 애플리케이션을 만들어 줍니다.

## 시작하기

웹 앱을 만드는 방법은 두 가지입니다.

* **프롬프트 입력**: Replit 홈페이지에서 만들고 싶은 것을 설명하세요. Agent가 자동으로 웹 앱을 생성합니다.
* **드롭다운에서 선택**: 홈페이지에서 앱 유형 드롭다운을 열고 **웹 앱**을 선택한 다음 아이디어를 설명하세요.

## 주요 기능

* **기본적으로 풀스택**: 모든 웹 앱에는 프런트엔드와 백엔드가 포함됩니다. Agent는 앱에 필요한 API 라우트, 데이터베이스, 서버 측 로직을 설정합니다.
* **반응형 디자인**: 앱이 다양한 화면 크기에 자동으로 맞춰집니다.
* **즉시 게시**: 클릭 한 번으로 앱을 게시할 수 있습니다. Replit이 호스팅, SSL, 인프라를 처리합니다.
* **공유 인프라**: 프로젝트에 모바일 앱이나 데이터 대시보드 같은 여러 아티팩트가 있다면, 모두 동일한 백엔드, 데이터베이스, 서비스를 공유합니다.

## 사용 사례

* **SaaS 제품**: 고객 대상 도구, 대시보드, 플랫폼을 만드세요.
* **내부 도구**: 팀을 위한 관리자 패널, CRM, 워크플로 앱을 만드세요.
* **랜딩 페이지**: 폼, 애니메이션, 동적 콘텐츠가 포함된 마케팅 사이트를 출시하세요.
* **마켓플레이스 및 디렉터리**: 목록 사이트, 채용 게시판, 커뮤니티 플랫폼을 만드세요.
