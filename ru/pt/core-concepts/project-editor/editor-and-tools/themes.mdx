Темы в Replit позволяют настроить внешний вид редактора проектов — от цветов фона и элементов интерфейса до подсветки синтаксиса кода. Настройте среду разработки для повышения читаемости, снижения нагрузки на глаза и более комфортного программирования.

<div id="criando-um-tema-personalizado">
  ## Создание пользовательской темы
</div>

Чтобы создать и настроить собственную тему, выполните следующие действия:

1. Откройте [Настройки](https://replit.com/settings) и перейдите в раздел **Пользователь** → **Персонализация** (или **Темы**)
2. Выберите **Создать новую тему**
3. Введите название, выберите цветовую схему (светлую или тёмную) и при необходимости добавьте описание
4. Выберите **Создать тему**, чтобы открыть редактор тем

Глобальные настройки темы определяют общий вид интерфейса:

* **Фон**: задаёт базовый цвет для большинства поверхностей интерфейса
* **Контур**: задаёт цвет границ и разделителей
* **Передний план**: определяет цвета текста и значков
* **Основной**: задаёт цвет кнопок и интерактивных элементов
* **Положительный**: используется для индикаторов успешных действий, например кнопки **Запустить**
* **Отрицательный**: используется для ошибок и предупреждений о необратимых действиях

Выберите **Применить тему**, чтобы сразу начать использовать свою пользовательскую тему.

<div id="realce-de-sintaxe">
  ## Подсветка синтаксиса
</div>

Настройте отображение различных элементов кода, чтобы повысить читаемость и упростить восприятие.

<Tip>
  Правильная подсветка синтаксиса помогает быстрее просматривать и понимать код. Выбирайте хорошо сочетающиеся цвета с достаточным контрастом по отношению к фону.
</Tip>

<Accordion title="Элементы подсветки синтаксиса">
  | Элемент                    | Описание                                                                                     |
  | -------------------------- | -------------------------------------------------------------------------------------------- |
  | **Имена переменных**       | Применяется к переменным, если не используется ключевое слово объявления                     |
  | **Определения переменных** | Окрашивает имена переменных при объявлении с ключевыми словами, такими как `const` или `var` |
  | **Ссылки на функции**      | Применяется при вызове функций                                                               |
  | **Определения функций**    | Окрашивает имена функций при объявлении                                                      |
  | **Ключевые слова**         | Выделяет ключевые слова языка, такие как `import`, `function` и `return`                     |
  | **Имена свойств**          | Окрашивает обращения к свойствам переменных                                                  |
  | **Определения свойств**    | Используется при определении свойств объектов                                                |
  | **Свойства функций**       | Применяется при вызове методов объектов                                                      |
  | **Имена тегов**            | Используется для HTML- и JSX-тегов                                                           |
  | **Имена типов**            | Окрашивает аннотации типов в типизированных языках                                           |
  | **Имена классов**          | Применяется к объявлениям и ссылкам на классы                                                |
  | **Имена атрибутов**        | Выделяет HTML- и JSX-атрибуты                                                                |
  | **Комментарии**            | Применяется ко всем комментариям в коде                                                      |
  | **Строки**                 | Окрашивает строковые литералы                                                                |
  | **Числа**                  | Выделяет числовые значения                                                                   |
  | **Логические значения**    | Форматирует логические значения (`true`/`false`)                                             |
  | **Регулярные выражения**   | Окрашивает шаблоны регулярных выражений                                                      |
  | **Операторы**              | Выделяет операторы, такие как `+`, `-`, `*` и `/`                                            |
  | **Скобки**                 | Окрашивает квадратные и угловые скобки при необходимости                                     |
</Accordion>

<div id="boas-prticas-de-design-de-temas">
  ## Рекомендации по оформлению тем
</div>

Создавайте визуально привлекательные и функциональные темы, следуя этим рекомендациям:

<div id="cor-e-contraste">
  ### Цвет и контраст
</div>

* **Сбалансируйте контраст**: Обеспечьте достаточную разницу между фоном и элементами переднего плана
* **Создавайте гармоничные палитры**: Выбирайте цвета, которые дополняют друг друга, а не конфликтуют
* **Поддерживайте единообразную яркость**: Сохраняйте схожий уровень яркости элементов синтаксиса
* **Учитывайте доступность**: Избегайте сочетаний с низким контрастом, чтобы учесть потребности пользователей с нарушениями зрения

<Warning>
  Распространённые ошибки при разработке тем, которых следует избегать:

  * Чрезмерная разница в яркости между элементами синтаксиса
  * Неудачные сочетания цветов, создающие визуальный диссонанс
  * Недостаточный контраст между кодом и фоном
</Warning>

<div id="gerenciando-seus-temas">
  ## Управление темами
</div>

Просматривайте все установленные темы и управляйте ими в [Настройках](https://replit.com/settings): **Пользователь** → **Персонализация** (или в разделе **Темы**).

<div id="alternando-temas">
  ### Переключение тем
</div>

Нажмите кнопку рядом с названием темы, чтобы выбрать её в качестве текущей.

<div id="editando-temas">
  ### Редактирование тем
</div>

Чтобы изменить созданную вами пользовательскую тему, откройте меню с тремя точками и нажмите **Редактировать**.

<Note>
  Редактировать или удалять можно только созданные вами пользовательские темы. Стандартные темы и темы, созданные другими пользователями, изменить нельзя.
</Note>

<div id="excluindo-temas">
  ### Удаление тем
</div>

Удалите пользовательские темы через меню с тремя точками, выбрав **Удалить**.

<div id="explorando-temas-da-comunidade">
  ## Знакомство с темами сообщества
</div>

Откройте для себя темы, созданные сообществом Replit, на [странице тем](https://replit.com/themes).

<div id="encontrando-temas">
  ### Поиск тем
</div>

* Ищите по названию, чтобы найти конкретные темы, например «Atom One Dark»
* Фильтруйте по автору, чтобы изучить темы от конкретных создателей
* Просматривайте темы по цветовой схеме, чтобы найти светлые или тёмные варианты
* Ищите по конкретным цветам, чтобы подобрать тему под свои предпочтения

Перед установкой просмотрите любую тему, чтобы увидеть, как она будет выглядеть в Редакторе проектов.

<div id="publicando-seu-tema">
  ## Публикация темы
</div>

Поделитесь своими пользовательскими темами с сообществом Replit, выполнив следующие действия:

1. Откройте редактор тем для своей пользовательской темы
2. Нажмите кнопку **Опубликовать**
3. Заполните поля названия и описания
4. Отправьте тему

После публикации ваша тема появится на странице тем, где другие пользователи смогут просмотреть и установить её.
