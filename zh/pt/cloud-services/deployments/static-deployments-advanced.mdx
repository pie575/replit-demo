<div id="adicionar-cabealhos-de-resposta">
  ## 添加响应标头
</div>

自定义**响应标头**可以让你为匹配特定路径的请求添加 HTTP 标头指令。
响应标头是一组名称-值对，用于告知浏览器如何处理所请求的内容。

例如，你可以指定 `Access-Control-Allow-Origin` 标头，以指明浏览器可以为该页面访问哪些域名。
要创建此条目，请在 Replit App 根目录下的 `.replit` 文件中添加以下内容：

```
[[deployment.responseHeaders]]
path = "/*"
name = "Access-Control-Allow-Origin"
value = "origin"
```

该响应标头包含以下参数：

* **path**：与请求的资源相匹配的 URL 路径模式
* **name**：HTTP 标头名称
* **value**：HTTP 标头值

你可以在 `.replit` 文件中添加多个 `deployment.responseHeaders` 条目。

要使配置更新生效，请重新发布你的 Replit App。

<div id="criar-uma-pgina-404-personalizada">
  ## 创建自定义 404 页面
</div>

当用户请求的 URL 路径与已发布应用中的任何文件或规则都不匹配时，就会显示自定义 404 页面。

要添加自定义 404 页面，请在 Replit App 的根目录下创建一个名为 `404.html` 的文件，并在其中编写页面内容。

当用户尝试访问不存在的 URL 路径时，就会看到该自定义 404 页面渲染出的 HTML。

<div id="definir-reescritas-de-caminho-de-url">
  ## 定义 URL 路径重写
</div>

你可以定义 URL 重写规则，在 Replit App 处理请求之前修改请求的 URL 路径。
浏览器中显示的仍是原始 URL，但服务器会加载重写规则中指定的资源。

例如，你可以指定所有以 `/app` 开头的请求都加载 `/app/index.html` 文件的内容。
要创建此条目，请在 Replit App 根目录下的 `.replit` 文件中添加以下内容：

```
[[deployment.rewrites]]
from = "/app/*"
to = "/app/index.html"
```

* **from**：用于匹配所请求资源的 URL 路径模式
* **to**：重写后的路径，需对应静态部署中的某个文件。

你可以在 `.replit` 文件中添加多条 `deployment.rewrites` 条目。
服务器会按列出的顺序解析这些条目，并忽略重复项。

要让配置更新生效，你需要重新发布你的 Replit App。

以下各节介绍 URL 重写规则的限制。

<div id="correspondncia-de-caminho">
  ### 路径匹配
</div>

重写规则中的 `from` 和 `to` 参数受以下限制：

* 除非使用 `*`，否则必须完全匹配
* `*` 匹配路径的其余部分
* `*` 只能出现在路径末尾
* 若在 `from` 参数中使用了 `*`，则可在 `to` 参数中一并使用，用于表示路径中被匹配到的部分

例如，如果你的 `.replit` 文件包含以下重写规则：

```
[[deployment.rewrites]]
from = "/v1/*"
to = "/v2/*"
```

当用户访问 `/v1/about-us.html` 路径时，该重写规则会返回位于 `/v2/about-us.html` 的文件。

<div id="sombreamento">
  ### 遮蔽
</div>

当某条重写规则匹配的 URL 路径同时也对应静态部署中的某个文件时，就会发生遮蔽。
出现这种情况时，云服务器会忽略该重写规则，直接返回该文件。

例如，假设你已发布的 App 包含以下文件：

* `index.html`
* `about.html`

而 `.replit` 文件中包含以下重写规则：

```
[[deployment.rewrites]]
from = "/*"
to = "/index.html"
```

当用户访问 `/register.html` 时，服务器会将该请求重写为 `/index.html`，并返回该文件。
但如果用户访问 `/about.html`，由于该文件确实存在于你的静态部署中，服务器会忽略重写规则，直接返回 `about.html` 文件。

<div id="restries-de-domnio">
  ### 域名限制
</div>

重写仅对发往静态部署 (Static Deployment) 主域名的请求生效，并且只能重写到静态部署内部的文件。
