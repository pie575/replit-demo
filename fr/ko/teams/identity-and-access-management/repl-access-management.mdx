title: "Gestion des accès"
description: "Découvrez comment contrôler les paramètres d’accès et de visibilité des applications Replit via l’interface des autorisations de groupe et le bouton « Invite » dans Project Editor."
icon: "key"
---

L’accès aux applications Replit peut être géré dans l’[interface des autorisations de groupe](/fr/ko/teams/identity-and-access-management/groups-and-permissions#repl-permissions) ou dans Project Editor à l’aide du bouton « Invite » de l’en-tête. Les utilisateurs disposant d’un accès en modification peuvent modifier le rôle de groupes ou d’utilisateurs existants, ou attribuer un rôle à de nouveaux groupes ou utilisateurs. Tous les utilisateurs ayant accès à Project Editor peuvent voir qui a accès à une application Replit, même sans droits d’administration.

</Frame>

Pour accorder l’accès à un groupe ou à un membre, utilisez la recherche pour le trouver par son nom ou son nom d’utilisateur.

<Frame>
  <img src="/assets/mirror/access-popover-search-22296060adec.png" alt="Recherche dans le menu contextuel d’accès" width="2880" height="1800" data-path="images/teams/identity-and-access-management/access-popover-search.png" />
</Frame>

Lorsque vous sélectionnez un résultat, un menu déroulant de sélection du rôle s’affiche. Une fois le rôle sélectionné, le groupe ou l’utilisateur est ajouté à la section « Groups with access » ou « People with access » ci-dessous.

Ce menu contextuel permet de définir qui, au sein de votre organisation, peut consulter et utiliser les applications Replit, y compris les destinataires **internes** (réservés à l’organisation) lorsque cette option est disponible. Le code source de l’application n’apparaît pas dans une liste **publique sur Replit** accessible à tous les utilisateurs de la plateforme : seuls les utilisateurs et groupes auxquels vous avez accordé l’accès savent que l’application existe et peuvent l’ouvrir, conformément aux règles de votre organisation.
