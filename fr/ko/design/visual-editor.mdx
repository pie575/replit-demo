<div id="visual-editor">
  ## Qu’est-ce que Visual Editor ?
</div>

Visual Editor vous permet de modifier directement l’UI en cliquant sur les éléments. Il fonctionne aussi bien dans le [canvas](/fr/ko/design/canvas) de Replit Design que dans Preview, ce qui vous permet de modifier de la même manière les maquettes et les applications en cours d’exécution.

Les modifications simples, comme changer du texte ou ajuster les couleurs et les espacements, mettent directement à jour le code source sans consommer de crédits IA. Pour les modifications dont la complexité est masquée, Visual Editor les transmet automatiquement à Agent.

Concepts clés :

* **Modifications déterministes** : les modifications simples (texte, couleurs, espacements) sont appliquées directement au code source, sans passer par Agent.
* **Aucun coût en crédits** : les modifications directes ne consomment pas de crédits IA — seules les modifications complexes sont traitées par Agent.
* **Double contexte** : fonctionne de la même manière dans les cadres Canvas et dans Preview.
* **Synchronisation du code source** : toutes les modifications mettent immédiatement à jour le code source sous-jacent.

<Note>
  Visual Editor est actuellement disponible uniquement dans les **navigateurs web**. Il n’est pas pris en charge dans les applications mobiles ni dans les applications de bureau.
</Note>

<div id="visual-editor-2">
  ## Comment utiliser Visual Editor
</div>

<div id="canvas">
  ### Modifier dans Canvas
</div>

Dans la barre d’outils, sélectionnez l’outil **Edit**, puis cliquez sur un élément dans le cadre. L’élément est mis en évidence et accompagné d’une pastille indiquant son nom. Le panneau Visual Editor s’ouvre à droite et affiche les propriétés modifiables de cet élément, notamment le contenu, la disposition, les couleurs et les bordures. Après avoir ajusté les propriétés, sélectionnez **Save edits** pour appliquer les modifications ou **Discard** pour les annuler.

<Frame caption="L’outil Edit est activé, un bouton est sélectionné et le Visual Editor affiche les propriétés modifiables.">
  <img src="/assets/mirror/visual-editor-edit-tool-71d03803471f.png" alt="L’outil Edit est activé et un élément est sélectionné dans un cadre de configurateur de supercar. Le panneau Visual Editor à droite affiche les sections Layout (Outer, Inner space), Color (Text, Background, Opacity) et Border (color, width, radius), ainsi que les boutons Discard et Save edits." width="2000" height="1250" data-path="images/replitai/visual-editor-edit-tool.png" />
</Frame>

Les propriétés affichées dépendent de l’élément sélectionné. Les éléments de texte proposent des contrôles de police, les images des options de source et d’importation, et les conteneurs des contrôles de disposition.

<div id="preview">
  ### Modifier dans Preview
</div>

La même expérience de modification fonctionne également dans l’application en cours d’exécution.

<Steps>
  <Step title="Sélectionner un élément">
    Cliquez sur un élément dans Preview pour commencer à le modifier.
  </Step>

  <Step title="Modifier">
    Modifiez le texte directement, ajustez les couleurs à l’aide du sélecteur de couleurs, modifiez l’espacement avec les contrôles de style ou remplacez les images.
  </Step>

  <Step title="Enregistrer">
    Cliquez sur Enregistrer pour mettre à jour le code source. Les modifications simples sont appliquées directement sans consommer de crédits d’IA. Si une modification est complexe, Visual Editor envoie les métadonnées de l’élément ciblé à Agent pour obtenir de l’aide.
  </Step>
</Steps>

<div id="section">
  ### Modifier le texte
</div>

Cliquez sur un élément de texte et modifiez-le directement. Si le texte correspond à une chaîne dans le code source, les modifications sont appliquées immédiatement.

<div id="section-2">
  ### Ajuster les couleurs
</div>

Utilisez le sélecteur de couleurs pour modifier les couleurs du texte et de l’arrière-plan. Saisissez un nom de couleur, comme « purple », dans le champ de saisie ou utilisez la pipette pour sélectionner une couleur n’importe où sur l’écran.

<div id="section-3">
  ### Modifier les styles
</div>

Utilisez des commandes intuitives pour ajuster l&#39;espacement intérieur, les marges et la disposition des éléments.

<div id="section-4">
  ### Contrôles de disposition
</div>

Visual Editor regroupe tous les contrôles dans des sections clairement identifiées pour vous aider à trouver plus rapidement ce dont vous avez besoin : **Text**, **Layout**, **Color**, **Border**. (Lorsque vous sélectionnez un élément image, une section **Image** apparaît également.)

Dans la section **Layout**, vous pouvez ajuster la disposition des éléments enfants d’un conteneur sans passer par Agent. Sélectionnez un conteneur flex et développez Layout pour afficher les options suivantes :

* **Alignment** : un sélecteur de position 3×3 permettant de choisir l’emplacement des éléments sur les deux axes du conteneur.
* **Direction** : deux boutons fléchés permettant d’organiser les éléments enfants en ligne ou en colonne.
* **Gap** : une valeur en pixels indiquant l’espacement entre les éléments. L’icône à côté du champ Gap change selon la direction actuelle : vous savez ainsi toujours si vous ajustez l’espacement horizontal ou vertical. L’icône fléchée située à côté active ou désactive **Distribute space between items**, qui répartit les éléments enfants entre les extrémités du conteneur.
* **Outer space** : des champs pour définir l’espace autour de l’élément de chaque côté (un par côté, avec un bouton de liaison pour verrouiller les quatre côtés simultanément).
* **Inner space** : des champs pour définir l’espace à l’intérieur de l’élément sur chaque axe, avec un bouton de liaison pour verrouiller les deux axes simultanément.

La section Layout n’apparaît que lorsqu’au moins un contrôle de disposition s’applique à l’élément sélectionné. Les nœuds de texte brut sans espacement ni propriété de disposition masquent entièrement cette section, afin de préserver la simplicité de l’éditeur.

<div id="section-5">
  ### Mettre à jour les images
</div>

Sélectionnez une image pour remplacer son URL ou importez votre propre fichier pour le prévisualiser immédiatement.

<div id="section-6">
  ## Ce que vous pouvez faire
</div>

* **Modifications rapides de texte **: mettez à jour le contenu, les libellés et les titres sans ouvrir les fichiers source
* **Exploration des couleurs **: cliquez et ajustez pour tester différentes palettes de couleurs — nul besoin de trouver le bon CSS
* **Ajustement de la disposition **: affinez visuellement les marges intérieures, les marges et les espacements au lieu de deviner des valeurs en pixels
* **Remplacement d’images **: cliquez et importez des images pour remplacer les images d’espace réservé par vos ressources réelles
* **Itération sur le design **: ajustez rapidement les frames Canvas pour comparer différentes directions visuelles sans multiplier les échanges avec Agent

<div id="section-7">
  ## Questions fréquentes
</div>

<Accordion title="Les modifications apportées dans Visual Editor consomment-elles des crédits d’IA ?">
  Les modifications simples et prévisibles, comme modifier du texte, choisir des couleurs ou ajuster l’espacement, ne consomment pas de crédits d’IA. Elles mettent directement à jour le code source. Si Visual Editor détecte une complexité cachée, il passe par Agent pour effectuer la modification, ce qui consomme des crédits.
</Accordion>

<Accordion title="Puis-je modifier un élément qui apparaît à plusieurs endroits ?">
  Oui. Lorsque vous sélectionnez un élément affiché dans une boucle ou réutilisé dans plusieurs composants, toutes ses instances sont mises en évidence et mises à jour en une seule fois.
</Accordion>

<Accordion title="Pourquoi ne puis-je pas modifier le texte de certains éléments ?">
  Les éléments complexes composés de plusieurs sous-éléments ne permettent pas de modifier directement leur texte dans Visual Editor. Demandez à Agent d’effectuer cette modification dans le chat.
</Accordion>

<Accordion title="Comment trouver le code source d’un élément ?">
  Cliquez sur l’étiquette en haut à gauche de l’élément sélectionné pour accéder à son emplacement dans le code source.
</Accordion>
