<div id="categorias-de-cobrana">
  ## Catégories de facturation
</div>

Replit répartit la facturation d’App Storage dans les catégories suivantes :

* **Stockage** : Volume de données stockées par mois. Tous les objets stockés sont soumis à une période de facturation minimale de sept jours.
* **Transfert de données** : Volume total de données envoyées et téléchargées au cours du mois.
* **Opérations de base** : Opérations liées à la mise à jour des buckets et des objets. Consultez les opérations de classe A dans <a href="https://cloud.google.com/storage/pricing" target="_blank">la tarification de Google Cloud Storage</a> pour plus de détails.
* **Opérations avancées** : Toutes les autres opérations de stockage d’objets dans le cloud, y compris la récupération de configurations et de métadonnées sur les objets et les buckets. Consultez les opérations de classe B dans <a href="https://cloud.google.com/storage/pricing" target="_blank">la tarification de Google Cloud Storage</a> pour plus de détails.
