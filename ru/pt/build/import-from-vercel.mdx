<div id="importar-do-vercel">
  ## Импорт из Vercel
</div>

⏰ *Примерное время: три минуты*

Импортируйте проект из Vercel в Replit, подключив репозиторий GitHub, на котором работает проект.

Полный набор вариантов импорта, включая другие платформы — GitHub, Figma, Bolt и Lovable, — описан в [документации по функции импорта](/ru/pt/references/workspace/import).

<div id="antes-de-comear">
  ## Прежде чем начать
</div>

* Проект Vercel, подключённый к GitHub
* Доступ к связанному репозиторию GitHub
* Учётная запись Replit

<div id="etapas-de-importao">
  ## Этапы импорта
</div>

1. Откройте [replit.com/import](https://replit.com/import).
2. Выберите **Vercel**.
3. Подключите учётную запись GitHub.
4. Выберите репозиторий проекта Vercel.
5. Добавьте все запрошенные Secrets и переменные окружения.
6. Выберите **Import**.

<div id="o-que-importado">
  ## Что импортируется
</div>

* Файлы проекта и структура каталогов
* Конфигурация зависимостей и фреймворка
* Настройки запуска и сборки для Replit

<div id="o-que-no-importado">
  ## Что не импортируется
</div>

* Значения существующих переменных окружения
* Пользовательские домены
* Специфичное поведение edge или middleware в Vercel
* Внешняя настройка аналитики или мониторинга
