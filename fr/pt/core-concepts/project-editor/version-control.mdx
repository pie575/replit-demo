La gestion de version dans Replit vous permet de suivre et de gérer votre code, et de collaborer en toute confiance. Grâce à l&#39;intégration native de Git et à la connexion avec GitHub, vous pouvez :

* Suivre les modifications du code et conserver un historique de votre travail de développement
* Collaborer avec les membres de votre équipe sans conflits de code ni perte de travail
* Importer, modifier et transférer du code entre Replit et GitHub
* Utiliser des branches pour expérimenter de nouvelles fonctionnalités en toute sécurité

<div id="o-que-controle-de-verso">
  ## Qu&#39;est-ce que le contrôle de version ?
</div>

Le contrôle de version est un système qui enregistre les modifications apportées aux fichiers au fil du temps, ce qui vous permet de récupérer une version précise ultérieurement. Sur Replit, le contrôle de version repose sur Git — l&#39;outil de référence du secteur pour le suivi des modifications de code — avec une interface visuelle intuitive qui vous évite d&#39;avoir à maîtriser la ligne de commande.

<div id="como-o-controle-de-verso-funciona-no-replit">
  ### Comment fonctionne le contrôle de version sur Replit
</div>

Les quatre options de contrôle de version interagissent toutes avec le même dépôt Git sous-jacent :

1. **Agent Checkpoints** crée automatiquement des commits aux étapes clés de la création avec [Replit Agent](/fr/pt/core-concepts/agent). [En savoir plus sur les checkpoints et les rollbacks](/fr/pt/core-concepts/agent/checkpoints-and-rollbacks).
2. **Git Pane** donne un accès visuel à l&#39;ensemble du dépôt Git
3. **Git CLI** offre un accès en ligne de commande à toutes les fonctionnalités Git
4. **File History** suit les modifications fines de chaque fichier

Choisissez l&#39;interface qui répond le mieux à vos besoins, en sachant que tout repose sur la robustesse du système de contrôle de version Git.

| Fonctionnalité                  | Agent Checkpoints                            | Git Commits                            | File History                         |
| ------------------------------- | -------------------------------------------- | -------------------------------------- | ------------------------------------ |
| **Création**                    | Automatique à des points logiques            | Manuelle ou planifiée                  | Automatique                          |
| **Granularité**                 | Modifications au niveau de la fonctionnalité | Modifications de toute taille          | Modifications au niveau du caractère |
| **Description**                 | Résumés générés par IA                       | Messages rédigés par l&#39;utilisateur | Horodatages automatiques             |
| **Rollback**                    | Restauration en un clic                      | Nécessite des connaissances en Git     | Restauration en un clic              |
| **Capacités Git**               | Capacités Git complètes                      | Capacités Git complètes                | Aucune capacité Git                  |
| **Synchronisation avec GitHub** | Synchronisation complète avec GitHub         | Synchronisation complète avec GitHub   | Aucune synchronisation avec GitHub   |

<div id="primeiros-passos">
  ## Premiers pas
</div>

Accédez au contrôle de version de votre Replit App en ajoutant l&#39;outil Git au Project Editor :

1. Rendez-vous dans la section Tools de votre Replit App
2. Sélectionnez le signe **+** pour ajouter de nouveaux outils
3. Sélectionnez **Git** dans la liste des outils disponibles

Pour importer des projets existants depuis GitHub, consultez [Importer depuis GitHub](/fr/pt/getting-started/quickstarts/import-from-github).

<div id="controle-de-verso-automtico">
  ### Contrôle de version automatique
</div>

<Accordion title="Agent Checkpoints">
  Instantanés automatiques créés pendant le développement assisté par IA avec [Replit Agent](/fr/pt/core-concepts/agent).

  **Idéal pour** : le développement avec Replit Agent

  **Principales fonctionnalités** :

  * Création automatique aux étapes clés
  * restauration en un clic
  * Instantanés au niveau des fonctionnalités
  * Suivi de la progression
  * Aucune configuration nécessaire
  * Chronologie visuelle de l&#39;avancement du développement

  Les checkpoints de l&#39;Agent sont stockés dans Git et accessibles depuis le Git Pane ou le Git CLI. Vous pouvez également consulter tous vos checkpoints grâce à la fonctionnalité History, qui offre :

  * Une vue chronologique des checkpoints
  * Des descriptions détaillées des checkpoints
  * Un accès direct aux états des checkpoints
  * Une restauration en un clic vers n&#39;importe quel checkpoint
</Accordion>

<Accordion title="File History">
  Suivi de version fichier par fichier avec enregistrement automatique des modifications effectuées directement dans l&#39;éditeur (et non par l&#39;Agent).

  **Idéal pour** : récupérer rapidement des modifications récentes dans les fichiers

  **Principales fonctionnalités** :

  * Focalisation sur un seul fichier
  * Modifications au niveau du caractère
  * Comparaison visuelle
  * Historique sur 30 jours
  * Fonction de relecture

  Bien que File History dispose de sa propre interface, les modifications sous-jacentes font partie de l&#39;historique Git. En savoir plus sur [File History](/fr/pt/core-concepts/project-editor/version-control/file-history).
</Accordion>

<div id="interfaces-baseadas-em-git">
  ### Interfaces basées sur Git
</div>

<Accordion title="Git Pane">
  Une interface visuelle pour les opérations Git, qui rend le contrôle de version accessible sans aucune connaissance de la ligne de commande.

  **Idéal pour** : la plupart des projets nécessitant une intégration avec GitHub et un flux de travail visuel

  **Principales fonctionnalités** :

  * Suivi au niveau du dépôt
  * Gestion des branches
  * Visualisation des différences
  * Synchronisation avec GitHub en un clic
  * Collaboration en équipe

  Pour des instructions détaillées sur l&#39;utilisation du Git Pane, consultez [Utiliser le Git Pane](/fr/pt/core-concepts/project-editor/version-control/git-interface).
</Accordion>

<Accordion title="Git CLI">
  Un accès complet à Git en ligne de commande via le [Shell](/fr/pt/core-concepts/project-editor/editor-and-tools/shell) pour les opérations avancées.

  **Idéal pour** : les utilisateurs avancés qui ont besoin de toutes les fonctionnalités de Git

  **Principales fonctionnalités** :

  * Jeu complet de commandes Git
  * Stratégies de branches avancées
  * Flux de travail personnalisés
  * Automatisation par scripts
  * Contrôle total du dépôt

  Pour les commandes Git courantes et leur utilisation, consultez [Utiliser le Git Pane](/fr/pt/core-concepts/project-editor/version-control/git-interface#using-git-commands-in-shell).
</Accordion>

<div id="principais-recursos">
  ## Fonctionnalités principales
</div>

* **Interface Git visuelle** : gérez vos dépôts, commits et branches sans taper la moindre commande Git
* **Intégration GitHub** : connectez-vous à des dépôts GitHub pour la sauvegarde et la collaboration
* **Importer depuis GitHub** : transformez n&#39;importe quel [dépôt GitHub en Replit App](/fr/pt/getting-started/quickstarts/import-from-github) en quelques clics
* **Gestion des branches** : créez des branches, passez de l&#39;une à l&#39;autre et fusionnez-les directement dans le Project Editor
* **Résolution des conflits** : repérez et résolvez les conflits de fusion grâce à une assistance visuelle

<div id="casos-de-uso">
  ## Cas d&#39;usage
</div>

**Suivre vos projets personnels**

Suivez les modifications de votre code au fil du développement, ce qui vous permet de revenir à des versions antérieures si nécessaire. Le [Git Pane](/fr/pt/core-concepts/project-editor/version-control/git-interface) affiche visuellement vos modifications et facilite ainsi le commit des mises à jour importantes.

**Collaborer avec une équipe**

Travaillez à plusieurs développeurs sur le même code sans écraser les modifications des autres. Créez des branches pour les nouvelles fonctionnalités, puis fusionnez-les lorsqu&#39;elles sont prêtes. Pour en savoir plus, consultez [Inviter des coéquipiers](/fr/pt/replitai/invite-teammates).

<div id="checkpoints-do-agent">
  ## Checkpoints de l&#39;Agent
</div>

Lorsque vous créez des applications avec [Replit Agent](/fr/pt/core-concepts/agent), vous bénéficiez d&#39;une couche supplémentaire de contrôle de version grâce aux checkpoints. Les checkpoints capturent automatiquement l&#39;état complet de votre projet — contenu du projet, contexte de la conversation avec l&#39;IA et bases de données connectées — à des moments clés du développement assisté par IA.

<div id="como-os-checkpoints-funcionam">
  ### Comment fonctionnent les checkpoints
</div>

Les checkpoints de l&#39;Agent sont des instantanés complets de l&#39;état global de votre Replit App :

* **Création automatique** : l&#39;Agent crée des checkpoints à des étapes clés du développement
* **Capture complète de l&#39;état** : chaque checkpoint conserve le contenu du projet, la mémoire de l&#39;IA et l&#39;état de la base de données
* **Plans d&#39;implémentation** : avant d&#39;apporter des modifications, l&#39;Agent vous soumet un plan pour validation
* **Suivi des tâches complexes** : plusieurs checkpoints peuvent être créés pour les tâches d&#39;envergure

<div id="benefcios-para-o-desenvolvimento-assistido-por-ia">
  ### Avantages pour le développement assisté par IA
</div>

Les checkpoints de l&#39;Agent offrent des atouts uniques lorsque vous développez avec l&#39;IA :

* **Filet de sécurité** : expérimentez en toute confiance, en sachant que vous pouvez facilement restaurer des états antérieurs dans l&#39;ensemble de votre environnement de développement
* **Suivi de la progression** : visualisez précisément comment l&#39;Agent a construit votre application, étape par étape
* **Jalons logiques** : les checkpoints correspondent à des fonctionnalités abouties plutôt qu&#39;à des points de sauvegarde arbitraires
* **Restauration instantanée** : revenez à n&#39;importe quel état antérieur en un seul clic, y compris la restauration de la base de données et du contexte de l&#39;IA

<Info>
  Pour en savoir plus sur ce que capturent les checkpoints et sur les possibilités complètes de restauration, consultez [Checkpoints et restaurations](/fr/pt/core-concepts/agent/checkpoints-and-rollbacks).
</Info>

<Tip>
  Même si les checkpoints de l&#39;Agent sont très efficaces pour le développement avec l&#39;IA, pensez à utiliser des commits Git pour le suivi de version à long terme et la collaboration, en particulier lorsque vous travaillez avec des dépôts externes.
</Tip>
