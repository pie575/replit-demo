앱을 비즈니스로 만들어 보세요. Replit은 결제 제공업체와 연동되어 결제를 받고, 구독을 판매하고, 웹 및 모바일 앱을 수익화할 수 있습니다.

<div id="how-it-works">
  ## 작동 방식
</div>

어떤 것에 요금을 받고 싶은지 Agent에게 알려주면 나머지는 Agent가 알아서 처리합니다. payment provider 연결, checkout 또는 paywall UI 구축, 결제 로직 연동까지 모두 맡아서 진행합니다. 정식 출시 전에 모든 것을 안전하게 테스트할 수 있습니다.

Replit은 웹 앱과 네이티브 mobile app 전반에 걸쳐 다양한 수익화 통합을 지원합니다.

* **[Whop Payments](/ko/features/monetization/whop-payments)** (web apps): 최소한의 단계로 디지털 제품, 멤버십, 구독을 판매합니다. Agent가 Whop 계정을 대신 만들어 주므로 외부 설정이나 API key 없이도 첫 판매까지 빠르게 도달할 수 있습니다.
* **[Stripe Payments](/ko/features/monetization/stripe-payments)** (web apps): 일회성 payments를 받거나, 구독을 판매하거나, 완전한 storefront를 구축할 수 있습니다. Agent가 Stripe sandbox를 연결해 주므로 정식 출시 전에 checkout flow를 테스트할 수 있습니다.
* **[RevenueCat Subscriptions](/ko/features/monetization/revenuecat-subscriptions)** (mobile apps): 네이티브 mobile app에 인앱 구독을 추가합니다. Agent가 RevenueCat을 설정하고 paywall 화면을 만들며, 테스트 모드까지 구성해 개발 중에는 구매가 시뮬레이션으로 처리됩니다.

inventory 관리와 배송이 필요한 실물 상품을 판매하려면 [Shopify 통합](/ko/features/integrations/shopify)을 참고하세요.

<div id="choose-the-right-integration">
  ## 알맞은 통합 선택하기
</div>

|                    | Whop                              | Stripe                       | Shopify                     | RevenueCat                          |
| ------------------ | :-------------------------------- | :--------------------------- | :-------------------------- | :---------------------------------- |
| **적합한 경우**         | 최소한의 단계로 가장 빠르게 첫 판매              | 웹에서의 유연성과 확장성                | 실물 상품                       | 네이티브 mobile app                     |
| **결제 유형**          | 디지털 제품, 멤버십, 구독 | 일회성 payments, 구독, storefront | inventory와 배송 관리가 필요한 실물 상품 | 인앱 구독                |
| **외부 설정** | 시작 시 불필요                          | 시작 시 불필요(Stripe sandbox)     | 시작 시 불필요                    | 시작 시 불필요(테스트 모드)                    |
| **Go live**        | 자금 인출을 위한 신원 확인(KYC)              | live Stripe account 연결       | Shopify store claim         | App Store 또는 Google Play에 review 제출 |
| **필요한 Account**    | Whop account(자동 생성)               | Stripe account               | Shopify store(자동 프로비저닝)     | RevenueCat account                  |

<div id="getting-started">
  ## 시작하기
</div>

가장 빠르게 시작하는 방법은 Agent에게 요청하는 것입니다.

* **디지털 제품을 빠르게 판매**: &quot;멤버십을 판매할 수 있도록 Whop 결제를 추가해줘&quot; — [Whop Payments](/ko/features/monetization/whop-payments) 참고
* **웹 앱**: &quot;내 앱에 Stripe 결제를 추가해줘&quot; — [Stripe Payments](/ko/features/monetization/stripe-payments) 참고
* **모바일 앱**: &quot;내 앱에 월 $5.99 구독을 추가해줘&quot; — [RevenueCat Subscriptions](/ko/features/monetization/revenuecat-subscriptions) 참고

Agent가 통합을 연결하고 UI를 만들며 테스트 환경까지 설정해 주므로 바로 사용해 볼 수 있습니다.
