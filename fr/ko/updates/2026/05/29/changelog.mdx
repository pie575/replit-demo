<div id="replit-enterprise">
  ### Passer à Enterprise sans quitter Replit
</div>

Vous pouvez désormais passer à Replit Enterprise depuis n&#39;importe quel forfait — gratuit, Core ou Pro — sans quitter le produit ni contacter au préalable l&#39;équipe commerciale. Si vous disposez d&#39;un espace de travail collaboratif, celui-ci est automatiquement transféré vers votre nouvelle organisation Enterprise une fois le paiement finalisé. Les applications publiées continuent de fonctionner sans interruption de service.

<div id="stripe">
  ### Connectez Stripe en installant l&#39;application, sans copier de clés
</div>

Passer votre application en production avec Stripe est désormais plus simple. Au lieu de copier les clés API de production depuis le tableau de bord Stripe, il vous suffit d&#39;installer l&#39;application Replit Integrated Payments depuis le Stripe Marketplace : les clés de production sont connectées automatiquement. Ouvrez le panneau de publication, installez l&#39;application, puis finalisez la connexion dans Stripe.

  ### Générer des modèles 3D avec le connecteur Tripo3D
</div>

Agent peut désormais générer de l&#39;audio pour vos applications. Demandez une musique de fond, des effets sonores ou une narration vocale : Agent crée l&#39;audio et l&#39;ajoute directement à votre projet. L&#39;utilisation est facturée en crédits Replit.

<div id="canvas">
  ### Générer des médias directement dans Canvas
</div>

Vous pouvez désormais générer des médias directement dans Canvas. Dans la barre d&#39;outils de Canvas, ouvrez l&#39;outil **Générer**, puis sélectionnez **Image**, **Graphique vectoriel** ou **Vidéo** pour créer sur place. Tout le processus se déroule sur le tableau, ce qui vous permet de concevoir et d&#39;itérer sans changer d&#39;outil.
