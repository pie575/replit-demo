<div id="agent-now-supports-custom-mcp-servers">
  ### Agent теперь поддерживает пользовательские MCP-серверы
</div>

Agent может подключаться к удалённым серверам Model Context Protocol (MCP), что открывает доступ к новым возможностям и инструментам при минимальной настройке. Благодаря этому Agent может вызывать внешние инструменты и получать контекст из удалённых систем.

С пользовательскими MCP-серверами вы можете:

* подключаться к удалённым серверам, которые получают контекст и выполняют действия во внешних инструментах;
* получать доступ к сотням инструментов и источников данных через открытый стандарт MCP;
* автоматически загружать инструменты, доступные на каждом сервере.

Партнёры могут интегрировать свои сервисы с Agent, предоставив MCP-сервер, — никакой дополнительной работы по интеграции не требуется.

<div id="plaid-connector-for-enterprise">
  ### Коннектор Plaid для Enterprise
</div>

Клиенты Enterprise теперь могут включить Коннектор Plaid, чтобы подключать банковские счета и создавать приложения с финтех-примитивами. Этот connector активно развивается: новые возможности и улучшения добавляются с учётом отзывов клиентов.

С Коннектором Plaid вы можете:

* подключать банковские счета к своим приложениям;
* использовать финтех-примитивы для создания финансовых функций;
* централизованно управлять connector&#39;ами через панель администратора.
