Skills ensinam o Agent novas capacidades — padrões preferidos, especificidades de bibliotecas, regras de sistema de design ou soluções para problemas que você já resolveu. Anexe uma a uma mensagem, instale uma no seu projeto ou escolha uma como ponto de partida para um novo projeto.

## Usar uma Skill no chat

A forma mais rápida de experimentar Skills é anexar uma a uma única mensagem — sem necessidade de instalação.

<Frame>
  <img src="/assets/mirror/agent-skills-picker-ee4058454475.png" alt="Seletor de Skills aberto pelo botão + ao lado da entrada do chat, mostrando a lista de Skills com Ad Creative, AI Recruiter, AI SDR e AI Secretary" width="723" height="529" data-path="images/replitai/agent-skills-picker.png" />
</Frame>

<Steps>
  <Step title="Abrir o seletor de Skills">
    Clique no botão **+** ao lado da entrada do chat e selecione **Usar uma Skill**.
  </Step>

  <Step title="Navegar e selecionar uma Skill">
    Navegue pelas Skills por categoria — Negócios e finanças, Criativo, Pesquisa e análise, e mais. Selecione uma ou mais Skills para anexar à sua mensagem.
  </Step>

  <Step title="Enviar sua mensagem">
    Digite sua solicitação e envie. O Agent usa as Skills selecionadas apenas para essa mensagem. Um chip de Skill aparece na sua mensagem para que você possa ver quais Skills estão ativas.
  </Step>
</Steps>

Por exemplo, anexe **Stock Analyzer** e peça ao Agent para construir um relatório de pesquisa de ações, ou anexe **Deep Research** para que o Agent investigue um tópico com descobertas estruturadas.

<Tip>
  Skills anexadas no chat não instalam nada no seu projeto. Elas ficam disponíveis instantaneamente em todos os projetos.
</Tip>

## Iniciar um projeto com uma Skill

Ao criar um novo projeto, você pode escolher uma Skill pré-selecionada como ponto de partida. O Agent usa as instruções da Skill para estruturar o projeto.

<Steps>
  <Step title="Abrir o seletor de ponto de partida">
    Na tela de novo projeto, clique em **+** e selecione **Usar uma Skill**.
  </Step>

  <Step title="Escolher uma Skill">
    Navegue pelas Skills curadas como **AI SDR**, **SEO Auditor**, **Ad Creative** ou **Programmatic SEO**. Selecione aquela que corresponde ao tipo de app que você deseja construir.
  </Step>

  <Step title="Descrever seu app">
    Diga ao Agent o que você quer. O Agent constrói o projeto com os padrões e convenções da Skill aplicados desde o início.
  </Step>
</Steps>

## Instalar uma Skill no seu projeto

Quando você quer que o Agent aplique uma Skill consistentemente em todas as conversas de um projeto, instale-a. As Skills instaladas ficam no diretório `/.agents/skills` do seu projeto e persistem entre as sessões de chat.

### Instalar pelo painel de Skills

Abra o **painel de Skills** no Project Editor e selecione a aba **Descobrir** para pesquisar Skills contribuídas pela comunidade. Encontre uma que você queira, clique em **Instalar**, e ela é adicionada ao seu projeto automaticamente.

<Frame>
  <img src="/assets/mirror/agent-skills-discover-732b2b0c488a.png" alt="Aba Descobrir Skills mostrando Skills contribuídas pela comunidade com opção de pesquisa e botões de instalação" width="2542" height="1850" data-path="images/replitai/agent-skills-discover.png" />
</Frame>

Por exemplo, ao construir um site de portfólio com animações avançadas, você pode instalar:

* **GSAP React** — ensina o Agent animações acionadas por scroll, revelações de texto e desenho de caminhos SVG
* **Tailwind design system** — dá ao Agent conhecimento de padrões Tailwind CSS para tipografia, espaçamento e transições de exibição
* **Find skills** — ensina o Agent como descobrir e instalar novas Skills em seu nome

<Tip>
  Você também pode instalar Skills via [CLI npx skills](https://github.com/vercel-labs/skills):

  ```bash theme={null}
  npx skills <skill> -a replit
  ```
</Tip>

### Criar uma Skill a partir de uma conversa

A forma mais natural de criar uma Skill é através de uma conversa com o Agent. Após resolver um problema juntos ou pesquisar uma nova biblioteca, peça ao Agent para capturar o que aprendeu:

<AiPrompt>
  Research best practices for GSAP React integration and create a skill for this project.
</AiPrompt>

O Agent usa o contexto completo da conversa para escrever um arquivo de Skill detalhado. Isso funciona particularmente bem após sessões de depuração onde você construiu um entendimento compartilhado de um problema.

### Escrever uma Skill personalizada

Para casos de uso avançados, escreva Skills diretamente seguindo a [especificação de Agent Skills](https://agentskills.io/specification). Ative **Mostrar arquivos ocultos** na barra lateral de arquivos, abra `/.agents/skills/` e crie um novo arquivo Markdown. Isso dá a você controle total sobre o que o Agent sabe e como ele se comporta.
