title: "已部署 App 监控"
description: "实时查看已部署应用的状态、性能、资源使用情况和 uptime。"
---

已部署 App 监控功能可让您查看性能指标、调整设置，并确保已部署 App 保持最佳运行状态。

<div id="recursos">
  ## 功能
</div>

* **实时跟踪**：查看已部署应用的状态、分析数据和配置详情
* **性能分析**：监控页面浏览量、响应时间和用户参与度指标
* **应用监控**：通过直观展示近期 uptime 的彩色状态条，快速确认已部署应用是否在线
* **配置管理**：只需点击几下，即可更新已部署应用的命令、Secrets 和选项

<div id="uso">
  ## 使用
</div>

您可以在 Publishing 标签页中访问监控工具。

<Accordion title="如何访问 Publishing">
  在左侧的 **工具停靠栏** 中：

  1. 选择 <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="所有工具图标" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **所有工具**，查看 Project Editor 中的工具列表。
  2. 选择 Publishing <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Publishing 图标" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publishing**。
  3. 选择顶部的 **概览**。

  在 **搜索栏** 中：

  1. 点击顶部的 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 放大镜图标，打开搜索工具。
  2. 输入“Publishing”以查找该工具，然后在搜索结果中选择它。
  3. 选择顶部的 **概览**。
</Accordion>

<div id="aba-overview">
  ### Overview 选项卡
</div>

**Overview** 选项卡可让您查看已部署应用的状态和配置。它提供以下信息：

* **状态**：Replit 上已部署应用的状态，包括部署流程各阶段的信息。
* **域名**：用于访问您的 Replit App 的 URL
* **部署类型**：Autoscale、Reserved VM、Static 或 Scheduled

<Frame caption="已部署应用的 Overview 选项卡">
  <img src="/assets/mirror/overview-tab-d2623c2e674a.png" alt="已部署应用的 Overview 选项卡" width="1828" height="604" data-path="images/deployments/overview-tab.png" />
</Frame>

您可以在 **Overview** 选项卡中执行以下操作：

* **重新发布**：使用新的快照和发布选项替换当前已部署的应用。您可以在此选项卡中监控应用状态。
* **编辑命令和 Secrets**：修改已部署应用的公共目录、构建命令和 Secrets。
* **查看发布日志**：访问已部署应用的日志。
* **查看已部署应用**：在新的浏览器选项卡中打开已部署应用。
* **QR 码**：生成可使用移动设备扫描的 QR 码，以访问已部署应用。
* **管理**：查看或更新已部署应用的设置。
* **查看所有使用量**：查看使用量计费页面。

<div id="aba-analytics">
  ### Analytics 选项卡
</div>

<Note>
  Analytics 适用于 Autoscale、Static 和 Reserved VM 部署。
</Note>

**Analytics** 选项卡会显示已部署应用的网站页面访问统计信息。
您可以使用顶部的日期选择器自定义时间范围。
分析指标包括：

* **页面浏览量**：您的 Replit App 每小时收到的 HTTP 请求数
* **热门 URL**：访问次数最多的 URL 路径
* **主要引荐来源**：将用户引导至您网站的流量来源
* **HTTP 状态码**：您的 Replit App 返回的 HTTP 响应状态码
* **请求时长**：服务器端请求处理时间
* **主要浏览器**：用户使用的浏览器
* **主要设备**：用于访问您的 Replit App 的操作系统和设备
* **主要国家/地区**：用户的地理分布

<div id="monitoramento-de-apps">
  ### 应用监控
</div>

<Note>
  应用监控适用于 Replit Core、Pro、Teams 和 Enterprise 套餐。除 Scheduled Deployments 外，所有 Deployment 类型均支持此功能。当您的应用符合条件时，发布对话框中会显示 **Enable app monitoring** 开关。
</Note>

应用监控可显示已部署应用是否在线。Replit 会定期检查您的应用，并记录每次检查结果。您可以在两个位置查看结果：在 **Publishing** 视图中快速查看运行状况，或在 **Analytics** 标签页中查看更长时间的历史记录。

<div id="ativar-monitoramento-de-apps">
  #### 启用应用监控
</div>

你可以在 **Publishing** 工具的发布对话框中，为现有项目启用应用监控。

<Steps>
  <Step title="打开发布对话框">
    打开 **Publishing** 工具，然后开始新的发布或重新发布应用。
  </Step>

  <Step title="启用开关">
    在 **Monitoring tools** 中启用 **Enable app monitoring**，然后发布应用。
  </Step>

  <Step title="查看 uptime">
    发布后几分钟内，你即可在 **Publishing** 视图和 **Analytics** 标签页中查看 uptime。
  </Step>
</Steps>

<div id="ler-a-barra-de-uptime">
  #### 查看运行时间条
</div>

部署应用后，**Publishing** 视图会在已部署应用的状态、可见性、地理位置和部署类型旁显示一个紧凑的运行时间条。你可以用它查看应用当前是否离线，或近期是否出现过问题——例如在你熟睡的凌晨。

<Frame caption="Publishing 视图中的近期运行时间，带有 Investigate recent downtime with Agent 按钮">
  <img src="/assets/mirror/app-monitoring-overview-ffdfc2d48fc2.png" alt="生产部署的 Publishing 视图，显示 95.0% 的运行时间、从 1 天前到现在的彩色运行时间条，以及 Investigate recent downtime with Agent 按钮" width="863" height="295" data-path="images/deployments/app-monitoring-overview.png" />
</Frame>

如需查看更长时间的历史记录，请打开 **Analytics** 选项卡。Analytics 选项卡包含时间范围选择器，让你可以查看更早的数据，并将停机时段与其他信号 (例如请求量或流量峰值) 关联起来，以确定用户流量是否给应用已预配的容量带来问题。

<Frame caption="Analytics 选项卡中的 Uptime Monitoring 图表，时间范围选择器为 Past one day">
  <img src="/assets/mirror/app-monitoring-analytics-07a11e4c2039.png" alt="Analytics 选项卡中的 Uptime Monitoring 视图，时间范围选择器为 Past one day，宽运行时间条显示 29.0% 的运行时间" width="991" height="205" data-path="images/deployments/app-monitoring-analytics.png" />
</Frame>

运行时间条最多显示最近 15 小时的活动。该条包含 90 个分段，每个分段代表 10 分钟。

分段颜色表示应用的连接状态：

* **绿色**表示应用在线。
* **黄色**表示连接应用时出现间歇性错误。
* **红色**表示应用离线。
* **灰色**表示该时间窗口尚无可用数据。

将鼠标悬停在某个分段上可查看确切的时间范围。

<div id="investigar-indisponibilidade-com-o-agent">
  #### 使用 Agent 调查服务不可用问题
</div>

如需进一步调查，请选择 uptime 条形图下方的 **使用 Agent 调查近期停机情况**。Agent 会在后台启动一项新任务，收集受影响的时间段，并分析根本原因——例如检查日志、代码和数据库状态，然后提出修复方案。

<div id="causas-comuns-de-indisponibilidade">
  #### 常见的服务不可用原因
</div>

应用不可用通常由以下问题之一导致：

* **App 崩溃。** 打开 **Logs** 标签页，查找红色区段出现前后是否有错误。
* **App 的 CPU 或内存不足。** 打开 **Resources** 标签页查看资源使用峰值。如果使用率较高，请在 **Manage** 标签页中选择更大的机器规格。
* **最近的部署导致问题。** 对照红色区段的时间与部署历史，必要时重新部署可正常运行的版本。
* **请求响应过慢。** 响应时间过长可能导致检查失败。请在 **Analytics** 标签页中查看 **Request Durations**。
* **配置有误。** 过期的 Secrets、错误的环境变量或无法访问的数据库都可能导致 App 宕机。请在 **Overview** 标签页的 **Edit Commands and Secrets** 中检查配置。

如需更多帮助，请参阅[部署故障排除](/zh/pt/cloud-services/deployments/troubleshooting)。

<div id="aba-schedule">
  ### Schedule 选项卡
</div>

<Note>调度仅适用于定时部署。</Note>

**Schedule** 选项卡可让您查看已部署应用的执行历史，其中包括以下信息：

* 距上次执行的时长
* 执行开始的日期和时间
* 执行耗时
* 执行状态

您可以在 **Schedule** 选项卡中执行以下操作：

* **查看日志**：选择条目旁的 <img class="icon-svg" src="/assets/mirror/menu-a72ad731aff8.svg" alt="菜单图标" width="16" height="16" data-path="images/icons/menu.svg" /> 查看日志图标，以查看日志消息。
* **取消执行**：选择条目旁的 <img class="icon-svg" src="/assets/mirror/cancel-2145d3814f60.svg" alt="取消图标" width="16" height="16" data-path="images/icons/cancel.svg" /> 取消图标，以停止正在执行的任务。
* **启动执行**：选择 **立即运行**，即可在不更改调度的情况下手动启动一次执行。
* **刷新**：使用 <img class="icon-svg" src="/assets/mirror/refresh-52703b8cfe91.svg" alt="刷新图标" width="16" height="16" data-path="images/icons/refresh.svg" /> 刷新图标更新执行历史。

<div id="aba-domains">
  ### Domains 选项卡
</div>

<Note>
  **Domains** 选项卡适用于 Autoscale、Reserved VM 和 Static
  Deployments。Scheduled Deployments 不提供 Domains 选项卡。
</Note>

通过 **Domains** 选项卡，您可以为已部署应用连接和管理自定义域名。在此选项卡中，您可以：

* **关联域名**：连接您已有的自定义域名。
* **购买域名**：直接通过 Replit 购买新域名。
* **查看域名状态**：查看每个已连接域名的验证状态。

如需分步配置说明，请参阅 [自定义域名](/zh/pt/cloud-services/deployments/custom-domains)。

<div id="aba-manage">
  ### Manage 选项卡
</div>

**Manage** 选项卡包含以下已部署应用设置：

* **资源用量**：查看已部署应用的 CPU 和 RAM 用量，以及机器使用成本。
* **暂停**：暂时停止已部署应用。此操作会使应用无法访问，但仍会继续计费。
* **更改部署类型**：在不同部署类型之间切换。例如，如果您最初选择了静态部署，可以将其更改为 Reserved VM Deployments。
* **关闭**：删除已部署应用并终止其计费周期。选择 **关闭** 可永久停止当前已部署应用。
