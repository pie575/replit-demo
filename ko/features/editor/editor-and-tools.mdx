Project Editor에는 앱 빌드 경험을 강화하는 레이아웃 관리 및 통합 도구가 포함되어 있습니다.
이러한 Project Editor 기능은 개발 프로세스의 특정 측면을 전문적으로 처리하여,
설정보다 창작에 집중할 수 있게 해줍니다.

## 커스터마이즈 가능한 Project Editor 레이아웃

Project Editor 레이아웃 관리 도구를 사용하면 개발 환경의 구성 요소를 커스터마이즈할 수 있습니다.
다음과 같은 사용자 인터페이스 요소 유형으로 구성됩니다.

| 요소             | 설명                                                     | 기능                                                                                 | 사용 사례                                                                |
| -------------- | ------------------------------------------------------ | ---------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| **Windows(창)** | 하나 이상의 패널을 포함하는 브라우저 탭                                 | <ul><li>여러 화면에 걸쳐 정리할 수 있음</li></ul>                                               | <ul><li>여러 화면에서 Project Editor 정리</li><li>여러 프로젝트를 동시에 작업</li></ul>  |
| **Panes(패널)**  | 하나 이상의 탭을 포함하는 창의 구역                                   | <ul><li>가로 및 세로 분할 지원</li><li>크기 조절 및 재배치 가능</li><li>창 내에서 플로팅 패널로 전환 가능</li></ul> | <ul><li>코드와 프리뷰를 나란히 보기</li><li>다양한 개발 작업을 위한 커스텀 레이아웃 만들기</li></ul> |
| **Tabs(탭)**    | 파일 에디터, Preview, Agent 등 Project Editor 도구를 정확히 하나씩 포함 | <ul><li>패널 간 이동 및 패널 내 재정렬 가능</li><li>클릭 한 번으로 다른 파일이나 도구로 전환 가능</li></ul>         | <ul><li>필요할 때 다른 도구나 파일 열기</li></ul>                                 |

## 파일 트리

파일 트리는 Replit App의 모든 파일과 디렉터리를 나열합니다.

<Accordion title="파일 트리에 접근하는 방법">
  좌측의 <img class="icon-svg" src="/assets/mirror/files-icon-f66bf1b04572.svg" alt="folder with arrows icon" width="16" height="16" data-path="images/icons/files-icon.svg" /> 폴더 아이콘을 선택해
  파일 트리의 표시 여부를 전환하세요.
</Accordion>

파일 트리에서 다음 작업을 수행할 수 있습니다.

* 폴더를 선택해 그 내용을 표시
* 파일을 선택하거나 패널로 드래그해 파일 에디터에서 열기
* 복제, 이름 변경, 이동, 다운로드, 삭제 등의 파일 작업 수행

## Run 버튼

**Run** 버튼은 Replit App에서 선택된 워크플로를 실행합니다.

<Accordion title="Run 버튼에 접근하는 방법">
  **Run** 버튼은 Project Editor 화면 상단에 있습니다. 버튼을 선택해 워크플로를 실행하세요.

  Replit App이 실행 중일 때는 버튼 레이블이 **Stop**으로 바뀝니다. 버튼을 선택해 앱을 중지하세요.
</Accordion>

워크플로를 선택, 확인, 관리하는 방법은 [Workflows](/ko/features/workspace-tools/workflows/)를 참고하세요.

## 옵션 메뉴

옵션 메뉴를 사용하면 다음과 같은 레이아웃 작업을 수행할 수 있습니다.

* **창 관리**: Replit App의 Project Editor를 새 창에서 열기
* **패널 관리**: 패널 추가, 패널 이동, 패널 최대화, 플로팅과 고정 위치 전환
* **탭 관리**: 다른 탭 열기 또는 선택, 다른 패널로 탭 이동, 탭 닫기

<Accordion title="옵션 메뉴에 접근하는 방법">
  활성 탭의 우측 상단에 있는 <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="vertical dots icon" height="16" width="16" data-path="images/icons/vertical-dots.svg" /> 세로 점 세 개를
  선택해 옵션 메뉴를 여세요.
</Accordion>

다음 스크린샷은 좌측 패널의 옵션 팝업 메뉴를 보여줍니다.

## 리소스 패널

리소스 패널은 개발 환경의 컴퓨팅 리소스와 사용량(RAM, CPU, 저장 공간 포함)을 표시합니다.
이 정보는 Replit App의 게시 요구 사항을 추정하고 최적화하는 데 도움이 됩니다.

<Accordion title="리소스 패널에 접근하는 방법">
  1. 앱 이름 옆에 있는 <img class="icon-svg" src="/assets/mirror/resources-237893692826.svg" alt="stacked computers icon" width="16" height="16" data-path="images/icons/resources.svg" /> 리소스 아이콘을 선택해 패널을 전환하세요.
  2. **Compute** 또는 **Storage** 항목에 마우스를 올려 자세한 내용을 확인하세요.
</Accordion>

다음 스크린샷은 리소스 패널을 보여줍니다.
