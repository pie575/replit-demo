# Répertoire de compétences

> Parcourez les compétences construites par Replit et nos partenaires, et apprenez comment les installer dans un projet ou votre espace de travail.

Le répertoire de compétences est un catalogue de compétences prêtes à l'emploi que vous pouvez installer et utiliser immédiatement — construites par Replit et par nos partenaires. Installez-en une, essayez-la, puis modifiez-la pour l'adapter à la façon dont votre équipe travaille réellement.

Pour ce qu'est une compétence et comment Agent la charge, consultez [Compétences Agent](/fr/features/agent/skills). Pour rendre une compétence disponible dans tout votre espace de travail, consultez [Personnalisation d'Agent](/fr/features/agent/agent-customization).

## Installer une compétence

Vous pouvez ajouter une compétence depuis le répertoire de plusieurs façons :

* **Dans le chat** — cliquez sur le bouton **+** à côté de la saisie du chat, sélectionnez **Utiliser une compétence** et choisissez-en une. La compétence s'applique uniquement à ce message, sans rien installer dans votre projet.
* **Dans un projet** — ouvrez le **Panneau de compétences** dans l'Éditeur de projet, sélectionnez l'onglet **Découvrir**, trouvez une compétence et cliquez sur **Installer**. Les compétences installées vivent dans le répertoire `/.agents/skills` de votre projet et persistent entre les chats.
* **Depuis la ligne de commande** — installez une compétence avec le [CLI skills](https://github.com/vercel-labs/skills) :

  ```bash theme={null}
  npx skills <compétence> -a replit
  ```

<Warning>
  Les compétences dans le sélecteur de compétences Replit sont auditées pour la sécurité. Les compétences installées depuis des sources externes ne le sont pas. Comme une compétence est des instructions qu'Agent suit, examinez toujours une compétence externe avant de l'installer — consultez [Compétences Agent](/fr/learn/agent-skills) pour ce qu'il faut vérifier.
</Warning>

## Compétences Replit

Replit est livré avec des compétences prédéfinies disponibles depuis le sélecteur **Utiliser une compétence** dans le chat et depuis le sélecteur de point de départ des nouveaux projets. Celles-ci fonctionnent dans chaque projet sans installation. Les descriptions apparaissent en ligne lorsque vous ouvrez le sélecteur.

| Catégorie              | Compétences                                                                                                                                       |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| Ventes et marketing    | Création publicitaire, SDR IA, Auditeur SEO, SEO programmatique, GEO, Machine à contenu, Storyboard                                               |
| Carrière               | Recruteur IA, Créateur de CV, Préparation aux entretiens                                                                                          |
| Recherche et analyse   | Analyse concurrentielle, Recherche approfondie, Recherche de solutions GitHub, Recherche fournisseurs                                             |
| Affaires et finance    | Analyseur d'actions, Générateur Excel, Générateur de factures, Analyseur fiscal                                                                   |
| Documents et outils    | Clonage de site web, Convertisseur de fichiers, Générateur de fiches, Contrat juridique, Constructeur d'infographies, Recréer une capture d'écran |
| Créatif                | Éditeur de photos, Générateur de podcast, Marketing de podcast, Générateur de branding, Montage vidéo                                             |
| Productivité           | Secrétaire IA, Chef de produit, Design Thinker, Chercheur de compétences, Créateur de compétences                                                 |
| Personnel              | Assistant voyage                                                                                                                                  |
| Sécurité et conformité | Secrets, Données sensibles, Validation des entrées, Sécurité IA, Vérification des dépendances, Vérification des licences                          |
| Qualité et fiabilité   | Accessibilité, Interface réactive, Observabilité, Résilience, Revue d'expédition                                                                  |

<Note>
  À l'intérieur d'un espace de travail, le sélecteur découvre également toutes les compétences supplémentaires installées dans le répertoire `.local/secondary_skills/` du projet.
</Note>

## Compétences partenaires

Les partenaires de Replit publient des compétences qui enseignent à Agent comment construire avec leurs produits. Installez-en une pour donner à Agent les modèles et conventions de ce service.

| Partenaire       | Ce qu'il enseigne à Agent                                     |
| ---------------- | ------------------------------------------------------------- |
| Stripe           | Modèles d'intégration des paiements et de la facturation      |
| PayPal           | Modèles d'intégration des paiements                           |
| RevenueCat       | Modèles d'abonnement et d'achat intégré                       |
| Mixpanel         | Implémentation de l'analyse et du suivi                       |
| BigQuery         | Modèles de requêtes d'entrepôt de données                     |
| Resend           | Intégration d'e-mails transactionnels                         |
| Google Workspace | Intégration de Gmail, Drive, Docs et Calendar                 |
| Atlassian        | Flux de travail pour les tickets Jira et les pages Confluence |
| Google Maps      | Intégration de cartes, lieux, itinéraires et géocodage        |

## Compétences communautaires

Au-delà des compétences Replit et partenaires, la communauté publie des compétences que vous pouvez installer. Parcourez-les sur [skills.sh](https://skills.sh), et lisez la [spécification des Compétences Agent](https://agentskills.io/specification) pour rédiger les vôtres.
