最终，你部署的 App 会在搜索引擎中获得更高的排名——部署工具中的 SEO 评分也会体现这一点。

每次成功部署后，Replit 都会运行一次 SEO 审计并给出 SEO 评分。如果评分仍有提升空间，只需点击一下，即可将具体问题交给 Agent 处理。对大多数开发者而言，工作流程很简单：**部署 → 查看评分 → 让 Agent 优化**。

有关评分的计算方式 (Lighthouse 审计、各项评分的含义、支持的部署类型) ，请参阅 [SEO 评分](/zh/pt/features/publishing/seo-rating)。

<div id="otimize-com-o-seo-agent">
  ## 使用 SEO Agent 优化
</div>

[SEO Agent](/zh/pt/features/publishing/seo-agent) 会对已部署的 App 进行技术性 SEO 审计，并将每一项发现转化为可一键应用的修复方案。它位于项目编辑器的 **Growth** 面板中，订阅付费方案的开发者均可使用。请按照以下步骤检查你的 App 并应用修复。

<Steps>
  <Step title="发布你的 App，解锁 Growth">
    SEO Agent 只能在已部署的 App 上运行。在完成部署之前，**Growth** 面板会一直处于锁定状态，并提示你**前往部署**。你可以通过 Agent 的 Chat 或**部署**工具完成部署，然后返回 Growth 面板。

    <Frame caption="部署之前，Growth 面板处于锁定状态，并显示前往部署的提示">
      <img src="/assets/mirror/01-growth-locked-b05c24711f10.png" alt="Growth 面板显示锁定状态，标题为“部署你的 App 以解锁 Growth 工具”，并带有“前往部署”按钮" width="1657" height="947" data-path="images/deployments/seo-agent/01-growth-locked.png" />
    </Frame>
  </Step>

  <Step title="使用 Agent 进行检查">
    打开 **Growth** 面板，找到 **SEO 评分**卡片。选择**使用 Agent 运行扫描**，即可对项目启动一次 SEO 技术审计。扫描通常需要几分钟。

    <Frame caption="在 SEO 评分卡片中选择“使用 Agent 运行扫描”以启动审计">
      <img src="/assets/mirror/02-run-scan-94a2b8918fe9.png" alt="SEO 评分卡片的放大视图，红色矩形框突出显示“使用 Agent 运行扫描”按钮" width="1656" height="946" data-path="images/deployments/seo-agent/02-run-scan.png" />
    </Frame>
  </Step>

  <Step title="使用 Agent 修复或使用 Agent 全部修复">
    扫描完成后，问题会以表格形式列出，包含 **严重性** (低、中或高) 和 **状态** (未解决) 两列，并按 **AI 就绪度**、**可爬取性与可发现性**、**首页渲染与元数据**、**性能代理指标** 等类别分组。展开任一问题即可查看 SEO Agent 的具体发现。

    你可以按需选择修复的粒度：

    * 在单个问题上点击 **使用 Agent 修复**，仅将该问题交给 Agent 处理。
    * 在某个类别上点击 **使用 Agent 修复**，会修复该组内的所有问题。
    * **使用 Agent 修复全部** 会一次性将所有问题发送给 Agent。Chat 中的 **修复所有问题** 按钮效果相同。

    <Frame caption="扫描完成后，可逐个修复问题、按类别修复，或使用“使用 Agent 修复全部”一次性修复">
      <img src="/assets/mirror/03-fix-with-agent-c5b9e642818e.png" alt="按类别分组的扫描结果表格，包含严重性和状态列，红色矩形突出显示“使用 Agent 修复全部”按钮以及各类别的“使用 Agent 修复”按钮" width="1657" height="947" data-path="images/deployments/seo-agent/03-fix-with-agent.png" />
    </Frame>
  </Step>

  <Step title="Agent 正在修复问题">
    Agent 会为每个问题创建一个修复任务，并在后台执行，你可以继续开发。相应行会更新为**修复进行中**，同时提供**前往任务**链接，可打开任意任务以跟踪进度。

    <Frame caption="Agent 创建修复任务；问题行显示“修复进行中”并附带“前往任务”链接">

    修复完成后，任务会显示**待审核**状态。请查看更改，然后点击绿色的**将更改应用到主版本**按钮，将修复合并到你的 App 中。重新发布后，即可基于新的 build 更新 SEO 评分。

<Tip>
  你也可以完全跳过检查界面。打开 Agent，输入 **“优化我的 SEO”**——Agent 会读取你最近一次的检查结果并直接着手优化。
</Tip>

Agent 常见的修复包括：

* 为缺失或过于笼统的 `<title>` 标签添加或改写内容，让每个页面都有独特且具描述性的标题。
* 为每个页面添加 meta description。
* 为图片添加描述性的 `alt` 文本。
* 在 `<html>` 元素上设置 `lang` 属性。
* 确保链接有清晰可辨的文本 (不使用“点击这里”或空锚文本) 。
* 添加 `robots.txt` 和 `sitemap.xml`。
* 添加 viewport meta 标签，以适配移动端渲染。
* 改善未通过无障碍检查的文本的颜色对比度。
* 添加 Open Graph 和 Twitter card meta 标签，让指向你 App 的链接在社交平台上有良好的展示效果。

<div id="melhores-prticas-para-um-app-otimizado-para-seo">
  ## SEO 优化 App 的最佳实践
</div>

无论是让 Agent 处理，还是自己动手，以下是最重要的优化要点：

* **为每个页面设置唯一的标题和元描述。** 标题尽量控制在 60 个字符以内，描述长度约为 150 至 160 个字符。
* **使用语义化 HTML。** 使用 `<main>`、`<header>`、`<nav>` 和 `<footer>` 组织页面布局。每个页面仅使用一次 `<h1>`，并按顺序使用各级标题。
* **为每张图片添加 alt 文本。** 描述图片所展示的内容，而不只是图片本身。
* **生成 `sitemap.xml` 和 `robots.txt`。** 请 Agent 创建这两个文件，让搜索引擎了解应抓取哪些内容。
* **添加 Open Graph 和 Twitter card 标签。** 控制 App 在社交媒体上分享时的显示效果。
* **使用自定义域名。** 品牌域名有助于赢得访客和搜索引擎的信任。请参阅[添加自定义域名](/zh/pt/build/add-custom-domain)。
* **选择合适的部署类型。** 对于内容丰富的网站，[Static Deployments](/zh/pt/features/publishing/deployment-types#static) 可提供预渲染 HTML，方便搜索引擎立即解析。
* **添加结构化数据。** JSON-LD 标记可帮助搜索引擎为产品、文章、常见问题和活动显示富媒体搜索结果。
* **保持 App 响应迅速。** 优化图片，避免阻塞渲染的脚本，并利用 Replit 托管服务缩短响应时间。

一次性应用大多数优化的简单方法：

  页面都有唯一的标题和元描述。

<div id="precisa-de-mais-ajuda">
  ## 需要更多帮助？
</div>

* **重新发布后评分没有更新：** 请稍等一两分钟——审计会在部署生效后异步执行，结果返回后徽章才会更新。
* **Agent 修改后评分没有变化：** 询问 Agent 具体处理了哪些 Lighthouse 项，然后查看徽章的提示信息，了解仍被标记的项。
* **某些页面的评分比其他页面低：** 徽章显示的是所有已抓取 URL 中的最低评分。可以让 Agent 专门处理 Lighthouse 标记的那个页面。
* **已部署的 App 中看不到评分：** SEO 评分仅针对面向公众的公开网页部署类型运行 (Autoscale、Reserved VM、Static) 。定时部署和私有部署不会生成评分。
