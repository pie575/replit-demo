L’outil Secrets stocke et chiffre les **secrets**, c’est-à-dire les informations sensibles de votre Replit App, telles que les clés API, les jetons d’authentification et les chaînes de connexion aux bases de données.

Lorsque vous ajoutez un secret, l’outil chiffre automatiquement les données et les met à la disposition de votre Replit App sous forme de variable d’environnement.
Cette approche vous permet d’éviter d’inscrire directement des secrets dans votre code et de réduire le risque de les exposer.

Inscrire directement des secrets dans votre base de code peut entraîner une exposition accidentelle dans les cas suivants :

* Partage de votre code avec d’autres personnes via une Replit App publique ou par copier-coller
* Ajout de votre code à un système de contrôle de version dans un dépôt public
* Diffusion en direct ou partage d’écran de votre code

Utilisez l’outil Secrets pour partager votre code en toute confiance, sans risquer d’exposer des identifiants.

<div id="features">
  ## Fonctionnalités
</div>

Les Secrets offrent les fonctionnalités suivantes :

* **Chiffrement de bout en bout** : protégez automatiquement vos données grâce au chiffrement AES-256 au repos et au chiffrement TLS en transit
* **Secrets au niveau de l&#39;app** : stockez et gérez des secrets propres à une Replit App
* **Secrets au niveau du compte** : stockez et gérez des secrets que vous pouvez rendre accessibles à l&#39;ensemble de vos Replit Apps
* **Accès par variables d&#39;environnement** : accédez à vos secrets depuis votre code à l&#39;aide de variables d&#39;environnement
* **Accès collaboratif** : partagez vos secrets avec vos collaborateurs et les membres de votre équipe

<div id="usage">
  ## Utilisation
</div>

<Note>
  Les Secrets sont disponibles pour tous les types de déploiement, à l&#39;exception des déploiements statiques.
</Note>

Vous pouvez accéder aux Secrets dans l&#39;outil Secrets du Project Editor.

<Accordion title="Comment accéder aux Secrets">
  Depuis le **dock d&#39;outils** à gauche :

  1. Sélectionnez <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Icône Tous les outils" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools** pour afficher la liste des outils du Project Editor.
  2. Sélectionnez <img class="icon-svg" src="/assets/mirror/lock-af402c9618dd.svg" alt="Icône Secrets" width="16" height="16" data-path="images/icons/lock.svg" /> **Secrets**.

  Depuis la **barre de recherche** :

  1. Sélectionnez la <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="icône loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> loupe en haut de l&#39;écran pour ouvrir l&#39;outil de recherche
  2. Saisissez « Secrets » pour trouver l&#39;outil, puis sélectionnez-le dans les résultats.
</Accordion>

<div id="manage-app-secrets">
  ### Gérer les App Secrets
</div>

Vous pouvez gérer les secrets au niveau de l&#39;app dans l&#39;onglet **App Secrets** du panneau **Secrets**.
Cet onglet affiche la liste de tous les secrets associés à votre Replit App.

<Accordion title="Ajouter des App Secrets">
  Pour ajouter un secret :

  1. Sélectionnez **New Secret**.
  2. Saisissez une **Key**, le nom du secret, et une **Value**, le secret lui-même.
  3. Sélectionnez **Add Secret** pour enregistrer l&#39;entrée.
</Accordion>

<Accordion title="Modifier des App Secrets">
  Pour modifier un secret :

  1. Sélectionnez le menu à points verticaux <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="icône à trois points verticaux" height="16" width="16" data-path="images/icons/vertical-dots.svg" /> situé à côté du secret.
  2. Sélectionnez **Edit** dans le menu contextuel.
  3. Modifiez le texte du champ **Key** ou **Value**, puis sélectionnez **Update Secret** pour enregistrer les modifications ou **Cancel** pour les abandonner.

  Vous pouvez également modifier l&#39;ensemble de la liste des App Secrets en sélectionnant **Edit as JSON** ou **Edit as .env** en bas de l&#39;onglet.
</Accordion>

<Accordion title="Afficher des App Secrets">
  Pour afficher un secret, sélectionnez l&#39;icône en forme d&#39;œil <img class="icon-svg" src="/assets/mirror/eye-8a6472b8a950.svg" alt="icône en forme d'œil" width="16" height="16" data-path="images/icons/eye.svg" /> située à côté du secret.

  Pour le masquer, sélectionnez l&#39;icône en forme d&#39;œil barré <img class="icon-svg" src="/assets/mirror/eye-slash-6b4ded538179.svg" alt="icône en forme d'œil barré" width="16" height="16" data-path="images/icons/eye-slash.svg" />.
</Accordion>

<Accordion title="Supprimer des App Secrets">
  Pour supprimer un secret, sélectionnez le menu à points verticaux <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="icône à trois points verticaux" height="16" width="16" data-path="images/icons/vertical-dots.svg" /> situé à côté du secret, puis sélectionnez **Delete**.
</Accordion>

<div id="manage-account-secrets">
  ### Gérer les Secrets de compte
</div>

Vous pouvez gérer les secrets au niveau du compte dans l&#39;onglet **Account Secrets** du panneau **Secrets**.
Cet onglet affiche uniquement les secrets associés à votre compte Replit.

<Accordion title="Ajouter des Secrets de compte">
  Pour ajouter un secret au niveau du compte :

  1. Accédez à l&#39;onglet **Account Secrets**.
  2. Sélectionnez l&#39;icône <img class="icon-svg" src="/assets/mirror/settings-icon-c2664c3691bf.svg" alt="icône d'engrenage" width="16" height="16" data-path="images/icons/settings-icon.svg" /> pour ouvrir les **paramètres** et gérer les secrets au niveau du compte.
  3. Sélectionnez **New Secret** pour ajouter un secret.
  4. Saisissez une **Key**, le nom du secret, et une **Value**, le secret lui-même.
  5. Sélectionnez **Save** pour enregistrer l&#39;entrée.
</Accordion>

<Accordion title="Modifier des Secrets de compte">
  Pour modifier un secret :

  1. Sélectionnez l&#39;icône crayon <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="icône de crayon" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> à côté du secret.
  2. Modifiez le texte du champ **Key** ou **Value**, puis sélectionnez **Save** pour enregistrer les modifications ou **Cancel** pour les annuler.
</Accordion>

<Accordion title="Afficher les Secrets de compte">
  Pour afficher un secret, sélectionnez l&#39;icône œil <img class="icon-svg" src="/assets/mirror/eye-8a6472b8a950.svg" alt="icône d'œil" width="16" height="16" data-path="images/icons/eye.svg" /> à côté du secret.

  Pour le masquer, sélectionnez l&#39;icône œil barré <img class="icon-svg" src="/assets/mirror/eye-slash-6b4ded538179.svg" alt="icône d'œil barré" width="16" height="16" data-path="images/icons/eye-slash.svg" />.
</Accordion>

<Accordion title="Lier des Secrets de compte">
  Pour utiliser un secret au niveau du compte dans une Replit App, vous devez le lier à l&#39;app.
  Pour lier un secret au niveau du compte :

  1. Accédez à l&#39;onglet **App Secrets**.
  2. Cochez la case à gauche du secret.
  3. Sélectionnez **Link to this App**.

  Pour dissocier un secret :

  1. Accédez à l&#39;onglet **App Secrets**.
  2. Sélectionnez le menu à trois points verticaux <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" width="16" height="16" alt="icône à trois points verticaux" data-path="images/icons/vertical-dots.svg" /> à côté du secret.
  3. Sélectionnez **Unlink**.
</Accordion>

<Accordion title="Supprimer des Secrets de compte">
  1. Sélectionnez l&#39;icône crayon <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="icône de crayon" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> à côté du secret.
  2. Sélectionnez **Delete**.
</Accordion>

<div id="managing-secrets-visibility">
  ### Gestion de la visibilité des Secrets
</div>

La visibilité des Secrets dépend de votre niveau d&#39;accès à une Replit App et du fait que vous en soyez l&#39;auteur.

Vous pouvez utiliser l&#39;une des options suivantes pour partager votre Replit App :

* **Multiplayer** : Invitez des utilisateurs Replit à collaborer en temps réel
* **Page de couverture** : Affichez un aperçu de votre Replit App avec la possibilité de la remixer
* **Remix** : Rendez publique votre Replit App personnelle ou celle de votre Organization afin que d&#39;autres puissent en créer leur propre version

Le tableau suivant présente la visibilité des noms et des valeurs des Secrets selon les différents scénarios :

| Méthode d&#39;accès      | Qui                                                         | Peut voir les noms | Peut voir les valeurs |
| ------------------------ | ----------------------------------------------------------- | ------------------ | --------------------- |
| Multiplayer              | Collaborateur Multiplayer                                   | ✓                  | ✓                     |
| Multiplayer              | Membre de l&#39;Organization (rôle Owner)                   | ✓                  | ✓                     |
| Multiplayer              | Membre de l&#39;Organization (sans rôle Owner)              | ✓                  |                       |
| Page de couverture       | Tout visiteur                                               |                    |                       |
| Remix                    | Propriétaire ou collaborateur remixant sa propre Replit App | ✓                  | ✓                     |
| Remix                    | Non-propriétaire ou collaborateur remixant une Replit App   | ✓                  |                       |
| Remix                    | Toute personne remixant depuis la page de couverture        | ✓                  |                       |
| Remix d&#39;Organization | Membre de l&#39;Organization avec le rôle Owner             | ✓                  | ✓                     |
| Remix d&#39;Organization | Membre de l&#39;Organization sans le rôle Owner             | ✓                  |                       |

<Warning>
  Les membres d&#39;une Organization sans le rôle Owner ne peuvent pas consulter les valeurs des Secrets dans une Replit App, mais peuvent y accéder en affichant les variables d&#39;environnement.
</Warning>

<div id="database-related-secrets">
  ## Secrets liés à la base de données
</div>

Lorsque vous ajoutez la base de données Replit, le Project Editor crée automatiquement le secret suivant :

| Secret         | Description                                  |
| -------------- | -------------------------------------------- |
| `DATABASE_URL` | Chaîne de connexion à la base de données SQL |

<Info>
  Les anciennes bases de données de développement Neon peuvent également inclure `PGHOST`, `PGUSER`, `PGPASSWORD`, `PGDATABASE` et `PGPORT`. Les bases de données de développement Replit actuelles utilisent plutôt `DATABASE_URL`.
</Info>

Pour afficher toutes les variables d&#39;environnement de votre Replit App, exécutez `printenv` dans l&#39;outil Shell du Project Editor ou affichez-les dans votre code.

<div id="predefined-environment-variables">
  ## Variables d&#39;environnement prédéfinies
</div>

Replit définit automatiquement les variables d&#39;environnement suivantes, auxquelles vous pouvez accéder depuis votre app :

| Variable d&#39;environnement | Description                                                                                     |
| ---------------------------- | ----------------------------------------------------------------------------------------------- |
| `REPLIT_DOMAINS`             | Liste, séparée par des virgules, de tous les domaines associés à votre Replit App               |
| `REPLIT_USER`                | Nom d&#39;utilisateur de l&#39;éditeur actuel, qui peut varier lors des sessions Multiplayer    |
| `REPLIT_DEPLOYMENT`          | Défini sur `1` si le code s&#39;exécute dans une app publiée ; non défini dans le cas contraire |
| `REPLIT_DEV_DOMAIN`          | URL de développement sur le domaine `replit.dev`, distincte de l&#39;URL de déploiement         |

Elles ne figurent pas dans l&#39;outil Secrets, mais vous pouvez y accéder dans votre code à l&#39;aide de l&#39;objet `os.environ` ou en exécutant `printenv` dans le Shell.
