Ce guide de référence présente la classe `Client` de la bibliothèque `object-storage` et fournit des exemples de code pour ses méthodes.

<div id="client">
  ## Client
</div>

La classe `Client` gère les interactions avec Replit App Storage. Elle propose des méthodes pour effectuer des opérations sur les fichiers d’un bucket.

Pour importer cette classe depuis la bibliothèque, ajoutez la ligne suivante à votre code JavaScript :

```javascript theme={null}
import { Client } from "@replit/object-storage";
```

Utilisez le code suivant pour créer une instance de `Client` qui interagit avec Replit Object Storage :

```javascript theme={null}
const client = new Client();
```

<div id="construtores">
  ## Constructeurs
</div>

**constructeur**

* **new Client**(`options?`) : `Client`

Crée une nouvelle instance de Client pour interagir avec Replit App Storage.

**Paramètres**

| Nom        | Type            | Description                                                  |
| :--------- | :-------------- | :----------------------------------------------------------- |
| `options?` | `ClientOptions` | Options de configuration permettant d’initialiser le client. |

**Renvoie**

`Client`

<div id="mtodos">
  ## Méthodes
</div>

<div id="copy">
  ### copy
</div>

* **copy**(`objectName`, `destObjectName`): `Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

Copie un objet dans le même bucket.
Cette méthode remplace tout objet existant à l’emplacement de destination.

**Paramètres**

| Nom              | Type     | Description                                       |
| :--------------- | :------- | :------------------------------------------------ |
| `objectName`     | `string` | Le chemin complet de l’objet à copier.            |
| `destObjectName` | `string` | Le chemin complet vers lequel l’objet sera copié. |

**Renvoie**

`Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

***

**Paramètres**

| Nom          | Type              | Description                                 |

| `objectName` | `string`          | Le chemin complet de l’objet à télécharger. |
| `options?`   | `DownloadOptions` | Options de l’opération de téléchargement.   |

`Promise`&lt;`Result`&lt;`Buffer`, `RequestError`&gt;&gt;

| `options?`   | `DownloadOptions` | Options de l’opération de téléchargement.   |

**Renvoie**

`Readable`

<div id="uploadfrombytes">
  ### uploadFromBytes
</div>

* **uploadFromBytes**(`objectName`, `contents`, `options?`): `Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

Téléverse un objet à partir de sa représentation en octets en mémoire.

**Paramètres**

| Nom          | Type            | Description                                     |
| :----------- | :-------------- | :---------------------------------------------- |
| `objectName` | `string`        | Le chemin de destination complet de l’objet.    |

| `options?`   | `UploadOptions` | Les paramètres de l’opération de téléversement. |

**Renvoie**

`Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

<div id="uploadfromfilename">
  ### uploadFromFilename
</div>

* **uploadFromFilename**(`objectName`, `srcFilename`, `options?`): `Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

Téléverse un fichier depuis le système de fichiers local vers le bucket.
Cette méthode écrase tout objet existant portant le même nom.

**Paramètres**

| Nom           | Type            | Description                                  |
| :------------ | :-------------- | :------------------------------------------- |
| `objectName`  | `string`        | Le chemin de destination complet de l’objet. |
| `srcFilename` | `string`        | Le chemin du fichier local à téléverser.     |
| `options?`    | `UploadOptions` | Options de l’opération de téléversement.     |

**Renvoie**

`Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

<div id="uploadfromstream">
  ### uploadFromStream
</div>

* **uploadFromStream**(`objectName`, `stream`, `options?`): `Promise`&lt;`void`&gt;

Téléverse un objet en lisant son contenu depuis le flux fourni.
Le flux émet toute erreur rencontrée lors du téléversement. Cette méthode remplace tout objet existant portant le même nom.

**Paramètres**

| Nom          | Type            | Description                                                      |
| :----------- | :-------------- | :--------------------------------------------------------------- |
| `objectName` | `string`        | Le chemin de destination complet de l’objet.                     |
| `stream`     | `Readable`      | Un flux lisible à partir duquel le contenu de l’objet sera lu. |
| `options?`   | `UploadOptions` | Paramètres de l’opération de téléversement.                      |

**Renvoie**

`Promise`&lt;`void`&gt;
