Генерация изображений позволяет создавать оригинальный визуальный контент без навыков дизайна и сторонних инструментов. От иконок и иллюстраций до фонов и элементов UI — всё это можно сделать прямо в рабочем процессе разработки.

<div id="section">
  ## Возможности
</div>

Создавайте визуально привлекательные приложения с помощью генерации изображений в Agent. Это избавляет от необходимости использовать стоковые фотографии, внешние инструменты для дизайна или нанимать дизайнера для создания базового визуального контента. Создаёте ли вы сайт-портфолио, разрабатываете игру или проектируете интерфейс мобильного приложения, генерация изображений позволяет создавать уникальные визуальные материалы, адаптированные под ваш проект.

Agent может выполнять следующие задачи по генерации изображений:

* **Создание изображений на заказ**: создание изображений на основе подробных описаний и требований
* **Применение стилей**: создание изображений в различных художественных стилях — от реалистичных до мультяшных
* **Прозрачный фон**: создание изображений в формате прозрачных PNG или удаление фона с существующих изображений — идеально для логотипов, иконок, стикеров и вырезок товаров
* **Интеграция с проектом**: простое добавление созданных изображений в кодовую базу приложения
* **Итеративное улучшение**: редактирование и улучшение изображений на основе обратной связи

<div id="section-2">
  ## Использование
</div>

Генерация изображений встроена в Agent, поэтому отдельно включать её не нужно. Откройте Replit App с включённым Agent и попросите его создать нужный визуальный контент. Agent автоматически определит, когда нужно сгенерировать изображение, и создаст его в соответствии с вашими требованиями.

<div id="agent">
  ### Когда Agent использует генерацию изображений

Agent запускает генерацию изображений, когда вы запрашиваете визуальный контент для проекта:

<div id="section-3">
  ### Рекомендации по созданию изображений
</div>

Чтобы получать наилучшие результаты при генерации изображений с помощью Agent, следуйте этим рекомендациям:

**Формулируйте запросы конкретно и подробно**

* Указывайте детали стиля, цвета, композиции и настроения
* При необходимости задавайте размер или соотношение сторон
* Указывайте предполагаемое использование изображения: иконка, фон, иллюстрация и т. д.
* Запрашивайте прозрачный фон для логотипов, иконок, стикеров или вырезанных объектов, которые будут размещены поверх другого контента

**Итерируйте и улучшайте**

* Начните с базового описания, затем уточняйте его на основе результатов
* Попросите Agent изменить отдельные части созданного изображения
* Запрашивайте варианты, чтобы исследовать разные творческие направления

**Учитывайте стиль проекта**

* Поддерживайте визуальную согласованность во всём приложении
* Указывайте стилевые предпочтения, соответствующие вашему бренду или дизайн-системе
* Запрашивайте изображения, сочетающиеся с существующими визуальными элементами

<div id="section-5">
  ### Интеграция с проектом
</div>

Agent легко интегрирует созданные изображения в кодовую базу:

* **Автоматическое создание файлов**: созданные изображения сохраняются непосредственно в файлах проекта
* **Обновление кода**: Agent обновляет код, чтобы он ссылался на новые файлы изображений
* **Упорядочивание ассетов**: изображения размещаются в соответствующих директориях проекта

Этот оптимизированный рабочий процесс позволяет создавать и использовать визуальный контент, не покидая среду разработки.

<Note>
  Генерация изображений в Replit работает на базе [Google Imagen 4](https://deepmind.google/models/imagen/) — передовой текстово-графической модели, которая превосходно создаёт высококачественные реалистичные изображения с проработанными деталями и улучшенной отрисовкой текста.
</Note>
