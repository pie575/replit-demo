将 **Replit** 应用添加到团队的 Slack workspace，然后 @**Replit** 并给出 prompt，即可把创意快速变成可运行的原型——在团队对话中直接体验 AI 驱动的开发。

<div id="what-you-can-do">
  ## 你可以做什么
</div>

在任意频道中提及 **@Replit** 并说出你的想法，Replit 的 Agent 就会生成一个可运行的原型，你可以立即上手使用或继续迭代：

* 通过自然语言 prompt 生成原型和设计稿。
* 几秒内即可拿到可运行的结果，然后在消息串中继续打磨。
* 无需离开 Slack，就能与团队一起完善原型。

<Tip>
  试着提及 Replit 并说出你的想法，比如“@Replit 做一个收集团队午餐订单的表单”或“@Replit 为我们的发布做一个落地页”。Replit 的 Agent 会构建原型，并将结果发回到对话中。
</Tip>

<div id="add-replit-to-slack">
  ## 将 Replit 添加到 Slack
</div>

前往 [Replit for Slack](https://replit.com/partners/slack-app) 安装该应用，并选择 **Add to Slack**。选择要连接的 Slack workspace，确认权限后选择 **Allow**。安装完成后，在任意频道中提及 **@Replit** 即可开始构建。

<Frame>
  <img src="/assets/mirror/allow-replit-app-access-slack-32f482f7a39e.png" alt="Slack 授权页面，标题为“Allow the Replit app to access Slack”，标注已通过 Slack 审核，其中包含设置为 Replit 的 workspace 选择器、Replit 应用可查看的信息及可执行的操作，以及 Cancel 和 Allow 按钮" width="1816" height="1358" data-path="images/replitai/slack/allow-replit-app-access-slack.png" />
</Frame>

<Note>
  Replit 的 Agent 使用 AI 生成回复，输出内容偶尔可能不准确或不完整——请自行核实重要信息。
</Note>

<div id="how-it-works">
  ## 工作原理
</div>

提及 **@Replit** 即可通过 [Replit MCP 服务器](/zh/platforms/mcp-server) 驱动 Replit，连接部分由 Slack 自动为你处理。
