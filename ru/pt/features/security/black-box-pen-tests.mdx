---
title: "Тестирование на проникновение методом «чёрного ящика»"
description: "Запустите проверку безопасности Level 3, которая анализирует исходный код и тестирует работающее приложение через браузер и сеть."
---

Тестирование на проникновение методом «чёрного ящика» проверяет работающее приложение извне — через браузер и сеть. При этом исходный код приложения не используется.

В Project Security Center **Level 3 (AI pentest)** включает три типа проверок безопасности:

1. Бесплатную проверку зависимостей и пакетов
2. Статический анализ исходного кода с помощью Agent
3. Внешнее тестирование активного Preview методом «чёрного ящика» без использования исходного кода

После запуска Level 3 Replit параллельно выполняет проверку исходного кода с помощью Agent и внешнее тестирование методом «чёрного ящика».

<div id="executar-uma-verificao-de-nvel-3">
  ## Запуск сканирования Level 3
</div>

<Steps>
  <Step title="Открыть проект">
    Откройте нужный проект.
  </Step>

  <Step title="Открыть Security Center">
    На панели **Tools** проекта выберите **Security Center**.
  </Step>

  <Step title="Запустить сканирование">
    В верхней части Security Center выберите **Run scan**.
  </Step>

  <Step title="Выбрать Level 3">
    Выберите **Level 3 (AI pentest)**.

    <Frame caption="Level 3 (AI pentest) дополняет бесплатные проверки зависимостей и пакетов статическим анализом от Agent и внешним тестированием активного Preview.">
      <img src="/assets/mirror/level-3-ai-pentest-c223c0099d3f.png" alt="Security and Privacy Center, открытый с панели Tools, с раскрытым меню Select scan level и выбранным вариантом Level 3 AI pentest" width="2204" height="1200" data-path="images/project-security-center/level-3-ai-pentest.png" />
    </Frame>
  </Step>

  <Step title="Дождаться завершения обеих задач">
    Дождитесь завершения проверки исходного кода и black-box-тестирования браузера и сети.
  </Step>

  <Step title="Проверить результаты">
    Просмотрите выявленные проблемы обеих задач на панели **Security**. Оцените каждую выявленную проблему, прежде чем отправлять принятые проблемы в Agent.
  </Step>

  <Step title="Исправить и запустить повторно">
    Отправьте принятые проблемы в Agent. После применения исправлений запустите сканирование Level 3 ещё раз, чтобы подтвердить их.
  </Step>
</Steps>

<div id="entenda-as-duas-tarefas">
  ## Разберитесь в двух задачах
</div>

| Задача                                               | Используемые данные                                     | Цель                                                                                      |
| ---------------------------------------------------- | ------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| Проверка исходного кода                              | Исходный код вашего приложения                          | Выявляет уязвимости в области безопасности, конфиденциальности и архитектуры кодовой базы |
| Тестирование на проникновение методом «чёрного ящика» | Взаимодействие браузера и сети с работающим приложением | Изучает наблюдаемое извне поведение без использования исходного кода                      |

Ознакомьтесь с обоими наборами выявленных проблем. Одна задача не заменяет другую: проверка исходного кода может выявить уязвимые детали реализации, тогда как Тестирование на проникновение методом «чёрного ящика» оценивает работающее приложение извне.
