<div id="what-is-visual-editor">
  ## Qu’est-ce que Visual Editor ?
</div>

Visual Editor vous permet de modifier directement votre UI en cliquant sur les éléments. Il fonctionne aussi bien sur le [Canvas](/fr/design/canvas) de Replit Design que dans la Preview, ce qui vous permet de modifier les maquettes et les applications en cours d’exécution de la même façon.

Les modifications simples — changements de texte, ajustements de couleur, réglages de l’espacement — mettent directement à jour le code source sans consommer de crédits d’IA. Pour les modifications qui impliquent une complexité non visible, Visual Editor fait automatiquement appel à Agent.

Concepts clés :

* **Modifications déterministes** : les changements simples (texte, couleurs, espacement) sont appliqués directement au code source, sans boucle Agent
* **Aucun coût en crédits** : les modifications directes ne consomment pas de crédits d’IA — seules les modifications complexes sont traitées par Agent
* **Double contexte** : fonctionne de manière identique sur les frames du Canvas et dans la Preview
* **Synchronisation du code source** : chaque modification met instantanément à jour le code source sous-jacent

<Note>
  Visual Editor est actuellement disponible uniquement dans les **navigateurs web**. Il n’est pas pris en charge sur Mobile App ni Desktop App.
</Note>

<div id="how-to-use-visual-editor">
  ## Utiliser Visual Editor
</div>

<div id="editing-on-the-canvas">
  ### Modification dans le Canvas
</div>

Sélectionnez l’outil **Edit** dans la barre d’outils, puis cliquez sur un élément dans un frame. L’élément est mis en surbrillance et accompagné d’une étiquette indiquant son nom. Le panneau Visual Editor s’ouvre à droite et affiche les propriétés que vous pouvez modifier, comme le contenu, la disposition, la couleur et la bordure. Ajustez-les, puis sélectionnez **Save edits** pour appliquer vos modifications ou **Discard** pour les annuler.

Les propriétés affichées dépendent de l’élément sélectionné : les éléments de texte proposent des réglages de police, les images affichent la source et l’option de téléversement, et les conteneurs proposent des réglages de disposition.

<div id="editing-in-preview">
  ### Modification dans Preview
</div>

Vous pouvez modifier votre application directement dans son aperçu en cours d’exécution.

<Steps>
  <Step title="Sélectionner un élément">
    Cliquez sur un élément dans Preview pour commencer à le modifier.
  </Step>

  <Step title="Effectuer la modification">
    Modifiez le texte directement, ajustez les couleurs à l’aide du sélecteur, modifiez l’espacement avec les commandes de style ou remplacez des images.
  </Step>

  <Step title="Enregistrer">
    Cliquez sur Enregistrer pour mettre à jour le code source. Les modifications simples s’appliquent directement sans consommer de crédits d’IA. Si la modification est complexe, Visual Editor envoie des métadonnées ciblées à Agent pour vous aider.
  </Step>
</Steps>

<div id="text-editing">
  ### Modification du texte
</div>

Cliquez sur n’importe quel élément de texte et modifiez-le directement. Si le texte correspond à une chaîne dans votre code source, la modification s’applique immédiatement.

<div id="color-adjustments">
  ### Ajuster les couleurs
</div>

Utilisez le sélecteur de couleurs pour modifier les couleurs du texte et de l’arrière-plan. Saisissez un nom de couleur tel que « purple » dans le champ de saisie, ou utilisez la pipette pour sélectionner une couleur n’importe où sur votre écran.

<div id="style-changes">
  ### Modifications de style
</div>

Ajustez l’espacement intérieur, les marges et la disposition des éléments à l’aide de commandes intuitives.

<div id="layout-controls">
  ### Contrôles de disposition
</div>

Le Visual Editor regroupe tous les contrôles en sections claires pour vous aider à trouver plus rapidement celui dont vous avez besoin : **Texte**, **Disposition**, **Couleur** et **Bordure**. (La section **Image** apparaît également lorsque vous sélectionnez un élément d’image.)

La section **Disposition** permet d’ajuster la position des éléments enfants dans un conteneur sans passer par Agent. Sélectionnez un conteneur flex, développez la section Disposition et vous verrez :

* **Alignement** : un sélecteur à 9 points pour définir la position des éléments sur les deux axes dans le conteneur.
* **Direction** : deux boutons fléchés pour disposer les éléments enfants en ligne ou en colonne.
* **Espacement** : une valeur en pixels pour l’espace entre les éléments. L’icône à côté du champ d’espacement change selon la direction actuelle, afin que vous sachiez toujours si vous ajustez l’espacement horizontal ou vertical. À côté, une icône en forme de flèche active ou désactive **Répartir l’espace entre les éléments**, ce qui place les éléments enfants sur des bords opposés du conteneur.
* **Espace extérieur** : des champs pour définir l’espace à l’extérieur de l’élément pour chaque côté (un champ par côté, avec un bouton de liaison pour verrouiller les quatre côtés simultanément).
* **Espace intérieur** : des champs pour définir l’espace à l’intérieur de l’élément sur chaque axe, avec un bouton de liaison pour les deux axes simultanément.

La section Disposition apparaît uniquement lorsqu’au moins un contrôle de disposition s’applique à l’élément sélectionné. Les nœuds de texte brut sans propriétés d’espacement ni de disposition masquent entièrement cette section, afin que l’éditeur reste compact.

<div id="image-updates">
  ### Mise à jour des images
</div>

Sélectionnez des images pour remplacer leurs URL ou téléverser vos propres fichiers, avec aperçu instantané.

<div id="what-you-can-do">
  ## Ce que vous pouvez faire
</div>

* **Corrections rapides de texte** : modifiez le contenu, les libellés et les titres sans ouvrir les fichiers source
* **Exploration des couleurs** : essayez différentes palettes de couleurs en cliquant et en ajustant — pas besoin de chercher le bon CSS
* **Ajustements de disposition** : affinez visuellement les marges internes, les marges externes et les espacements plutôt que de deviner les valeurs en pixels
* **Remplacement d’images** : remplacez les images d’espace réservé par de véritables ressources en cliquant et en les téléversant
* **Itération de conception** : ajustez rapidement les frames sur le Canvas pour comparer différentes orientations visuelles sans faire d’allers-retours avec Agent

<div id="frequently-asked-questions">
  ## Questions fréquentes
</div>

<Accordion title="Les modifications apportées dans Visual Editor consomment-elles des crédits d’IA ?">
  Les modifications simples et déterministes — modification de texte, choix de couleurs, ajustement des espacements — ne consomment pas de crédits d’IA. Elles mettent directement à jour le code source. Si Visual Editor détecte une complexité cachée, il confie la modification à Agent, ce qui consomme des crédits.
</Accordion>

<Accordion title="Puis-je modifier des éléments qui apparaissent à plusieurs endroits ?">
  Oui. Lorsque vous sélectionnez un élément affiché dans une boucle ou réutilisé dans plusieurs composants, toutes ses instances sont mises en surbrillance et mises à jour simultanément.
</Accordion>

<Accordion title="Pourquoi ne puis-je pas modifier le texte de certains éléments ?">
  Les éléments composites constitués de plusieurs sous-éléments ne peuvent pas être modifiés directement dans Visual Editor. Demandez plutôt à Agent dans le Chat d’effectuer ces modifications.
</Accordion>

<Accordion title="Comment trouver le code source d’un élément ?">
  Cliquez sur l’étiquette située en haut à gauche d’un élément sélectionné pour accéder à son emplacement dans le code source.
</Accordion>
