## Importer depuis Vercel

⏰ *Durée estimée : trois minutes*

Importez un projet Vercel dans Replit en liant le dépôt GitHub associé au projet.

Pour des options d'import complètes incluant d'autres plateformes comme GitHub, Figma, Bolt et Lovable, consultez la [documentation de la fonctionnalité d'import](/fr/core-concepts/project-editor/app-setup/import).

## Avant de commencer

* Un projet Vercel connecté à GitHub
* Accès au dépôt GitHub associé
* Un compte Replit

## Étapes d'import

1. Ouvrez [replit.com/import](https://replit.com/import).
2. Sélectionnez **Vercel**.
3. Connectez votre compte GitHub.
4. Sélectionnez le dépôt de votre projet Vercel.
5. Ajoutez les secrets et variables d'environnement requis.
6. Sélectionnez **Import**.

## Ce qui est importé

* Les fichiers et la structure de répertoires du projet
* La configuration des dépendances et du framework
* Les paramètres d'exécution et de build par défaut pour Replit

## Ce qui n'est pas importé

* Les valeurs des variables d'environnement existantes
* Les domaines personnalisés
* Le comportement edge ou middleware spécifique à Vercel
* La configuration d'analytics ou de monitoring externe
