设计系统为 Replit 提供可复用的视觉方向。它可以涵盖颜色 token、排版、间距、示例组件、徽标和品牌资源，确保新设计保持一致。

如需使用已保存的设计系统指导创建内容，请在提示框中选择 **加号** 菜单，然后选择 **使用设计系统**。

<div id="when-a-design-system-helps">
  ## 何时适合使用设计系统
</div>

* **保持一致性：**让新作品中的颜色、排版、间距和组件保持统一。
* **为团队提供共同方向：**将一个已保存的系统作为多个 Project 的视觉参考。
* **调整现有作品的风格：**当 artifact 需要遵循不同的视觉语言时，应用相应的系统。

为保存的系统和所需成果命名。当这些资料能明确作品需要实现的目标时，可补充其他相关背景信息，例如需求简介、Figma frame、截图或内容要求。

例如：“使用已保存的 Acme 设计系统创建一个移动端引导页面。保留现有的字号层级和按钮样式，并提供两种布局方案。”

设计系统决定视觉作品的风格。[Skill](/zh/chat/agent-skills) 则为 task 提供可复用的说明或方法。
