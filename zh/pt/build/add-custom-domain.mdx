最后，Velocity 将使用 `velocityrentals.com`，而非 `velocity.replit.app`。

<YouTubeEmbed videoId="rGYdyb58wJY" />

你已为 Velocity 添加了登录功能、数据库、支付和日历集成。现在，为它设置一个像真实租赁品牌一样的 URL。本指南将把 Velocity 迁移到 `velocityrentals.com`——请替换为你自己的域名。

<div id="confirme-que-a-velocity-funciona-na-url-do-replit-primeiro">
  ## 首先确认 Velocity 在 Replit URL 上正常运行
</div>

在公共 URL `velocity.replit.app` 稳定运行之前，请勿进行任何更改。请在新的浏览器标签页中打开它，并确认：

* 车队页面能够正常加载。
* 客户可以登录、预订车辆，并在刷新页面后看到预订信息。
* Stripe 押金结账流程能够打开，且测试卡可以确认预订。
* Google 日历事件会显示在完成预订客户的日历中。

如果其中任何一项出现问题，请先修复，再调整 DNS。请参阅[部署故障排除](/zh/pt/build/troubleshooting)。

<div id="conecte-velocityrentalscom-no-replit">
  ## 在 Replit 中连接 velocityrentals.com
</div>

打开 Velocity 的部署设置，将 `velocityrentals.com` 添加为自定义域名。Replit 会显示两条 DNS 记录，请按显示内容原样复制。

<Frame>
  <img src="/assets/mirror/dns-records-d64f183fa655.png" alt="Velocity 部署设置中的 Replit 自定义域名对话框，已输入 velocityrentals.com，并显示两条可复制的 DNS 记录（一条 A 记录和一条用于验证的 TXT 记录）" width="1280" height="720" data-path="images/velocity/add-custom-domain/dns-records.png" />
</Frame>

接着，打开你的域名注册商控制面板 (Namecheap、Cloudflare、Google Domains、GoDaddy 等) ，添加这些完全相同的记录。如果你希望 Agent 针对特定注册商引导你完成操作：

<AiPrompt>
  我正在将 Velocity 从 velocity.replit.app 迁移到 velocityrentals.com。我的域名注册商是 [填写你的域名注册商名称]。<br />
  请准确说明需要添加哪些 DNS 记录，以及添加顺序。<br />
  请使用 Replit 中显示的值，不要自行编造记录值。<br />
  请告诉我如何在等待其生效前确认域名已连接。
</AiPrompt>

DNS 更改可能需要几分钟到几小时才能生效。Replit 检测到这些记录后，会在 `velocityrentals.com` 旁显示“已验证”。

<div id="teste-a-velocity-em-velocityrentalscom">
  ## 在 velocityrentals.com 上测试 Velocity
</div>

当 Replit 显示域名已验证后：

1. 在新浏览器标签页中打开 `https://velocityrentals.com`。应会显示绿色锁图标——HTTPS 会自动启用。
2. 以客户身份登录。登录应该仍能正常使用 (Replit Auth 会自动处理新域名) 。
3. 预订一辆车，刷新页面并确认预订信息仍然保留。
4. 打开 Stripe 押金结账流程。页面现在应将 `velocityrentals.com` 显示为商家 URL。
5. 确认预订，并检查 Google 日历事件是否仍会添加到客户的日历中。

如果登录、结账流程或日历集成仅在 `velocityrentals.com` 上出现问题，请向 Agent 描述具体症状：

<AiPrompt>
  Velocity 在 velocity.replit.app 上正常运行，但在 velocityrentals.com 上 [描述出现的问题]。<br />
  请告诉我应在 DNS、Replit 设置，还是第三方模型提供方 (如 Stripe 或 Google) 的设置中修复。<br />
  请告诉我接下来最安全的检查步骤。
</AiPrompt>

Velocity 现在使用真实的租赁品牌 URL。将 `velocityrentals.com` 分享给客户——他们不会在任何地方看到“replit.app”。

<div id="precisa-de-mais-ajuda">
  ## 还需要更多帮助？
</div>

* **`velocityrentals.com` 无法立即打开：**DNS 更改可能需要数小时才能生效。请等待后再次检查，再修改其他设置。
* **Replit URL 可以访问，但自定义域名无法访问：**请确认 DNS 记录与 Replit 显示的内容完全一致——常见错误包括末尾的句点、额外的子域名或过期的记录。
* **Stripe 结账流程仍显示 `velocity.replit.app`：**请让 Agent 更新 Stripe 重定向 URL，改用 `velocityrentals.com`。
* **您还没有域名：**可通过 Replit 购买——请参阅[购买域名](/zh/pt/build/domain-purchasing)。
