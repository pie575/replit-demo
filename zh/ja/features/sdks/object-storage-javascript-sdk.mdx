本参考指南介绍 `object-storage` 库中的 `Client` 类，并提供各方法的代码示例。

<div id="client">
  ## Client
</div>

`Client` 类用于管理与 Replit App Storage 的交互，提供了操作存储桶中文件的各种方法。

要从库中导入该类，请在 JavaScript 代码中添加以下代码行：

```javascript theme={null}
import { Client } from "@replit/object-storage";
```

使用以下代码创建用于与 Replit Object Storage 交互的 `Client` 实例：

```javascript theme={null}
const client = new Client();
```

<div id="section">
  ## 构造函数
</div>

**constructor**

* **new Client**(`options?`): `Client`

创建一个新的 Client 实例，用于与 Replit App Storage 交互。

**参数**

| 名称         | 类型              | 说明          |
| :--------- | :-------------- | :---------- |
| `options?` | `ClientOptions` | 用于配置客户端的选项。 |

**返回值**

`Client`

<div id="section-2">
  ## 方法
</div>

<div id="copy">
  ### copy
</div>

* **copy**(`objectName`, `destObjectName`): `Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

在同一存储桶内复制对象。
如果目标路径已存在对象，该方法会将其覆盖。

**参数**

| 名称               | 类型       | 说明           |
| :--------------- | :------- | :----------- |
| `objectName`     | `string` | 要复制的对象的完整路径。 |
| `destObjectName` | `string` | 对象的目标完整路径。   |

**返回值**

`Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

***

<div id="delete">
  ### delete
</div>

* **delete**(`objectName`, `options?`): `Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

从存储桶中删除对象。

**参数**

| 名称           | 类型              | 说明           |
| :----------- | :-------------- | :----------- |
| `objectName` | `string`        | 要删除的对象的完整路径。 |
| `options?`   | `DeleteOptions` | 删除操作的配置。     |

**返回值**

`Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

***

<div id="downloadasbytes">
  ### downloadAsBytes
</div>

* **downloadAsBytes**(`objectName`, `options?`): `Promise`&lt;`Result`&lt;`Buffer`, `RequestError`&gt;&gt;

下载对象，并以 Buffer 形式返回其原始内容。

**参数**

| 名称           | 类型                | 说明           |
| :----------- | :---------------- | :----------- |
| `objectName` | `string`          | 要下载的对象的完整路径。 |
| `options?`   | `DownloadOptions` | 下载操作的配置。     |

**返回值**

`Promise`&lt;`Result`&lt;`Buffer`, `RequestError`&gt;&gt;

***

<div id="downloadasstream">
  ### downloadAsStream
</div>

* **downloadAsStream**(`objectName`, `options?`): `Readable`

创建用于读取对象内容的可读流。
下载过程中出现的错误会通过该流发出。

**参数**

| 名称           | 类型                | 说明           |
| :----------- | :---------------- | :----------- |
| `objectName` | `string`          | 要下载的对象的完整路径。 |
| `options?`   | `DownloadOptions` | 下载操作的配置。     |

**返回值**

`Readable`

<div id="downloadastext">
  ### downloadAsText
</div>

* **downloadAsText**(`objectName`, `options?`): `Promise`&lt;`Result`&lt;`string`, `RequestError`&gt;&gt;

下载对象并以字符串形式返回其内容。

**参数**

| 名称           | 类型                | 说明          |
| :----------- | :---------------- | :---------- |
| `objectName` | `string`          | 要下载对象的完整路径。 |
| `options?`   | `DownloadOptions` | 下载操作的配置。    |

**返回值**

`Promise`&lt;`Result`&lt;`string`, `RequestError`&gt;&gt;

<div id="downloadtofilename">
  ### downloadToFilename
</div>

* **downloadToFilename**(`objectName`, `destFilename`, `options?`): `Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

下载对象并将其保存到本地文件系统的指定位置。

**参数**

| 名称             | 类型                | 说明               |
| :------------- | :---------------- | :--------------- |
| `objectName`   | `string`          | 要下载的对象的完整路径。     |
| `destFilename` | `string`          | 写入下载对象的本地文件系统路径。 |
| `options?`     | `DownloadOptions` | 下载操作的配置。         |

**返回值**

`Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

<div id="uploadfrombytes">
  ### uploadFromBytes
</div>

* **uploadFromBytes**(`objectName`, `contents`, `options?`): `Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

以内存中的字节形式上传对象。
此方法会覆盖同名的现有对象。

**参数**

| 名称           | 类型              | 说明           |
| :----------- | :-------------- | :----------- |
| `objectName` | `string`        | 对象上传目标的完整路径。 |
| `contents`   | `Buffer`        | 字节形式的对象原始内容。 |
| `options?`   | `UploadOptions` | 上传操作的配置。     |

**返回值**

`Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

<div id="uploadfromfilename">
  ### uploadFromFilename
</div>

* **uploadFromFilename**(`objectName`, `srcFilename`, `options?`): `Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

将本地文件系统中的文件上传到存储桶。
此方法会覆盖同名的现有对象。

**参数**

| 名称            | 类型              | 说明              |
| :------------ | :-------------- | :-------------- |
| `objectName`  | `string`        | 对象上传到的完整路径。     |
| `srcFilename` | `string`        | 要上传的本地文件系统文件路径。 |
| `options?`    | `UploadOptions` | 上传操作的配置。        |

**返回值**

`Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

<div id="uploadfromstream">
  ### uploadFromStream
</div>

* **uploadFromStream**(`objectName`, `stream`, `options?`): `Promise`&lt;`void`&gt;

从提供的流中读取内容并上传对象。
上传过程中发生的错误会通过该流发出。此方法会覆盖同名的现有对象。

**参数**

| 名称           | 类型              | 说明            |
| :----------- | :-------------- | :------------ |
| `objectName` | `string`        | 对象上传目标的完整路径。  |
| `stream`     | `Readable`      | 用于读取对象内容的可读流。 |
| `options?`   | `UploadOptions` | 上传操作的配置。      |

**返回值**

`Promise`&lt;`void`&gt;

<div id="uploadfromtext">
  ### uploadFromText

* **uploadFromText**(`objectName`, `contents`, `options?`): `Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

该方法会覆盖同名的现有对象。

**参数**

| 名称           | 类型              | 说明           |
| :----------- | :-------------- | :----------- |
| `objectName` | `string`        | 对象上传目标的完整路径。 |
| `contents`   | `string`        | 文本格式的对象内容。   |
| `options?`   | `UploadOptions` | 上传操作的配置。     |

**返回值**

`Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

<div id="section-3">
  ## 方法示例
</div>

以下各节提供了使用 Replit Object Storage SDK 管理文件的代码示例。

<div id="section-4">
  ### 以文本形式获取对象
</div>

```javascript theme={null}
const { ok, value: textValue, error } = await client.downloadAsText('file.json');
if (!ok) {
    // ... 处理错误 ...
}
```

<div id="section-5">
  ### 以原始字节形式获取对象
</div>

```javascript theme={null}

if (!ok) {
    // ... 处理错误 ...
}
```

<div id="section-6">
  ### 从流中获取对象
</div>

