---

在 Replit 中创建移动 App 时，你可能会遇到预览、打包或包依赖方面的问题。本指南将帮助你解决常见问题：先从快速修复入手，再逐步进行更深入的调试。

<div id="correes-rpidas">
  ## 快速修复
</div>

请先尝试以下方法——它们能解决大多数问题：

| 问题        | 可尝试的方法                         |
| --------- | ------------------------------ |
| 更改未显示在手机上 | 摇晃手机打开 Expo 菜单，然后点击 **Reload** |
| 更改未显示在预览中 | 在控制台中按 **R** 重新打包              |
| 应用卡住或无响应  | 通过控制台停止并重新启动应用                 |

<div id="problemas-comuns">
  ## 常见问题
</div>

<AccordionGroup>
  <Accordion title="更改未显示在设备上">
    更改后，手机上却看不到更新：

    1. **摇晃手机**，打开 Expo 开发者菜单
    2. 点击 **Reload**，重新下载 bundle

    在 Web 预览中，按控制台里的 **R** 触发重新打包。

    如果更改仍未显示，请尝试清除缓存 (参阅下方的[清除 Metro 缓存](#clear-the-metro-cache)) 。
  </Accordion>

  <Accordion title="Expo Go 中出现红色错误屏幕">
    红色错误屏幕通常表示存在 JavaScript 错误或缺少模块。请查看错误信息——其中通常会指出具体的文件和行号。

    **常见原因：**

    * 某个包未安装或版本不正确
    * 某个模块可在 Web 上运行，但不支持原生环境 (或反之)
    * 代码中存在语法错误

    **可尝试的操作：**

    1. 仔细查看错误信息——它通常会准确说明问题所在
    2. 将错误信息发给 Agent，请它协助修复
    3. 如果错误提到特定包，请尝试重新安装依赖项 (参阅[重新安装包](#reinstall-packages))
  </Accordion>

  <Accordion title="应用能在 Web 上运行，但在手机上崩溃（或反之）">
    某些包或功能在不同平台上的表现有所不同。React Native 会编译到三个目标平台：iOS、Android 和 Web。可在 Web 上运行的库可能不支持原生环境，或者需要不同的配置。

    **可尝试的操作：**

    1. 查看该包的文档，确认它是否支持您的平台
    2. 询问 Agent：“这个包是否兼容 Expo Go？”
    3. 如果移动端不支持，请考虑将该功能移到服务器端

    <Tip>
      搜索包时，请查找“Expo compatible”，或查看[Expo SDK 文档](https://docs.expo.dev/versions/latest/)了解支持的模块。
    </Tip>
  </Accordion>

  <Accordion title="QR 码无法扫描或应用无法连接">
    **检查网络：**

    * 手机和电脑必须连接到同一个 WiFi 网络
    * 某些企业或公共网络会阻止连接

    **尝试 tunnel 模式：**
    如果您使用的是受限网络，tunnel 模式会通过 Expo 服务器转发流量。请 Agent 以 tunnel 模式启动应用，或在 Shell 中运行 `npx expo start --tunnel`。

    **重启 Expo Go：**
    扫描前，请完全关闭 Expo Go，然后重新打开。
  </Accordion>

  <Accordion title="构建耗时过长">
    首次构建总是较慢，因为没有可用缓存。后续构建应该会更快。

    **影响构建时间的因素：**

    * 项目中的包数量
    * 清除缓存后的首次运行
    * 下载包时的网络速度

    如果构建一直很慢，请检查是否安装了不必要的包。
  </Accordion>

  <Accordion title="找不到模块错误">
    当您看到“Unable to resolve module”或“Module not found”时：

    1. 该包可能尚未安装——请 Agent 安装它
    2. 该包可能已安装，但缓存已过期——请清除缓存
    3. 该包可能不存在或名称有误——请检查包名称

    如果该模块本应存在，请尝试[重新安装包](#reinstall-packages)。
  </Accordion>
</AccordionGroup>

<div id="comandos-de-depurao">
  ## 调试命令
</div>

如果快速修复无效，可使用这些命令重置各种缓存和状态。请在 Shell 中运行这些命令。

<div id="limpar-o-cache-do-metro">
  ### 清除 Metro 缓存
</div>

Metro 是用于编译 React Native 代码的打包工具。清除缓存会强制重新构建。

在 Shell 中运行：

```bash theme={null}
npx expo start --clear
```

这会清除打包工具 缓存并重启开发服务器。你会在输出中看到 &quot;Bundler cache is empty. Rebuilding.&quot;。

<Tip>
  如果经常遇到缓存问题，可以在启动命令中添加 `-c`。让 Agent 更新 dev 命令，加入清除缓存标志。
</Tip>

<div id="reinstalar-pacotes">
  ### 重新安装包
</div>

如果遇到模块错误或版本不兼容问题，重新安装包通常能解决问题。

在 Shell 中运行：

```bash theme={null}
rm -rf node_modules && npm install
```

这会删除所有已安装的包，然后根据您的 `package.json` 重新安装。

<Note>
  如果您的项目使用其他包管理器 (如 `bun` 或 `pnpm`) ，请使用相应的安装命令：`bun install` 或 `pnpm install`。
</Note>

<div id="verificar-incompatibilidades-de-verso">
  ### 检查版本兼容性问题
</div>

Expo Doctor 会检查你的项目，查找包之间版本不兼容等常见问题。

在 Shell 中运行：

```bash theme={null}
npx expo-doctor
```

检查输出中是否有警告。如果它建议修复，请仔细评估——不要盲目更新包，因为这可能会引入新问题。

<Warning>
  只有在确有明确理由时才更新包。仅仅为了“更新而更新”可能会导致你的 App 出现问题，因为新版本可能包含不兼容的变更。
</Warning>

<div id="reset-completo">
  ## 完全重置
</div>

当其他方法都无效时，完全重置会清除所有缓存并重新安装所有内容。

<Accordion title="终极方案：完全重置命令">
  此命令会清除所有缓存，并从头重新安装所有包。请仅在万不得已时使用。

  ```bash theme={null}
  rm -rf node_modules .expo && npm cache clean --force && npm install && npx expo start --clear
  ```

  **此命令会执行以下操作：**

  1. `rm -rf node_modules` — 删除已安装的包
  2. `rm -rf .expo` — 删除本地 Expo 缓存
  3. `npm cache clean --force` — 清除全局 npm 缓存
  4. `npm install` — 重新安装所有包
  5. `npx expo start --clear` — 使用全新的 Metro 缓存启动

  执行后，下一次构建会花费更长时间，因为所有内容都需要从头构建。
</Accordion>

<div id="limpar-cache-no-seu-dispositivo">
  ### 清除设备上的缓存
</div>

如果手机上的应用重新加载后仍在运行旧代码，似乎卡住了：

* **iOS**：在 Expo Go 中，前往**设置**，然后点击**清除缓存**
* **Android**：前往**设置 &gt; 应用 &gt; Expo Go &gt; 存储 &gt; 清除缓存**

  ## 快速参考
</div>

| 问题            | 首先尝试                     | 然后尝试                |
| ------------- | ------------------------ | ------------------- |
| 更改未生效         | 摇晃手机 → Reload            | 清除 Metro 缓存         |
| 打包工具 错误    | `npx expo start --clear` | 删除 node&#95;modules |
| 找不到模块         | 重新安装依赖项                  | 完全重置                |
| 版本不兼容警告       | 运行 `npx expo-doctor`     | 检查建议的修复方案           |
| 新安装的包无法正常运行 | 重启服务器                    | 清除 Metro 缓存         |
| app.json 已更改  | 重启服务器                    | —                   |

<div id="obtendo-mais-ajuda">
  ## 获取更多帮助
</div>

如果您仍然遇到困难：

* **询问 Agent**：说明错误情况以及您已尝试的操作。Agent 通常可以诊断并解决问题。
* **查阅 Expo 文档**：[Expo 故障排除指南](https://docs.expo.dev/troubleshooting/overview/)涵盖更多情形。
* **搜索错误信息**：复制完整的错误信息并进行搜索——很可能已经有人遇到过同样的问题。
