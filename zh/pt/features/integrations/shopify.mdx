有了 Shopify 连接器，Agent 可以为你开通 Shopify 商店、构建与之集成的自定义店面，并管理商品和库存——这一切都在一次对话中完成，无需 API 密钥。只要你提到要销售实物商品，Agent 就会推荐使用 Shopify，而你只需在正式上线时访问 Shopify。从第一条 prompt 到收到真实订单，大约只需十分钟。

<Note>
  如需详细的分步指南，请参阅[构建 Shopify 店面](/zh/pt/build/ecommerce-store)。
</Note>

<div id="o-que-voc-pode-construir">
  ## 你可以构建什么
</div>

* 为实体商品打造的定制设计展示页
* 具有品牌视觉形象的周边与服饰商店
* 支持购物车和结账的 DTC (直面消费者) 商店
* 与你的 Shopify 商店集成的商品目录和库存管理工具
* 主推单一商品的产品页面

  ## 工作原理
</div>

<Steps>
  <Step title="描述你的商店">
    告诉 Agent 你想卖什么。即使你没有提到 Shopify，它也会为实体商品推荐使用 Shopify。

    <Frame>
      <img src="/assets/mirror/describe-your-store-b5d724daee99.png" alt="Replit 的 prompt 输入框中输入了一个蜡烛商店的 prompt" width="1440" height="900" data-path="images/replitai/shopify/describe-your-store.png" />
    </Frame>
  </Step>

  <Step title="Agent 自动开通商店">
    在 Replit 的 Shopify 合作伙伴账户下创建一个开发商店 (约十秒即可完成) ，安装 Replit Sales Channel 应用并完成商店连接。无需 API 密钥；每个应用对应一个商店；在你认领之前受密码保护。

    <Frame>
      <img src="/assets/mirror/connect-shopify-store-7f36389f976f.png" alt="Replit 的 Agent 正在转交给 Shopify skill，显示带有 Connect Shopify 按钮的“Connect to Shopify”卡片" width="3452" height="1984" data-path="images/replitai/shopify/connect-shopify-store.png" />
    </Frame>
  </Step>

  <Step title="Agent 负责搭建与管理">
    Agent 设计无头店面，并维护商品、变体、库存、系列和折扣。

    <Frame>
      <img src="/assets/mirror/add-product-8b098e606340.png" alt="店面商品网格，展示带有名称和价格的蜡烛商品" width="3452" height="1978" data-path="images/replitai/shopify/add-product.png" />

  <Step title="在 Shopify 上正式上线">

    <Frame>
      <img src="/assets/mirror/claim-store-4facb7c8b10c.png" alt="Replit 的“认领你的商店”界面，带有“认领商店”按钮" width="3452" height="1978" data-path="images/replitai/shopify/claim-store.png" />

  </Step>

<div id="o-que-o-agent-gerencia">
  ## Agent 管理的内容
</div>

店面和商品目录中的所有内容都可以通过对话编辑。

| 领域     | Agent 的作用                                                                                                                                        |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Design | 根据你的要求生成无头前端 (无需 Liquid 主题，也无需模板库) 。文案、布局、导航、动画和商品页面均可通过对话编辑，你还可以借助 [Canvas](/zh/pt/design/canvas) 的变体探索不同方向。这是一个真实的 Replit 项目，因此你可以为它扩展博客、心愿单或落地页。 |
| 商品     | 创建、更新和删除商品及变体。字段包括：标题、描述、类型、供应商、标签、SKU、价格、重量、选项 (尺码、颜色) 、图片和库存状态。                                                                                |
| 库存     | 按变体设置和调整库存量。                                                                                                                                     |
| 系列     | 将商品归入不同的商品系列。                                                                                                                                    |
| 折扣     | 创建一条价格规则以及一个可兑换的折扣码。                                                                                                                             |
| 发布与同步  | 新商品会自动发布到你的店面。同步是双向的：你在 Shopify 后台所做的编辑会显示在 Replit 的预览中，Agent 所做的更改也会同步到你的 Shopify 后台。                                                           |

<div id="replit-e-shopify-quem-faz-o-qu">
  ## Replit 与 Shopify：各自负责什么
</div>

| Replit 负责                  | Shopify 负责          |
| -------------------------- | ------------------- |
| 店面的设计与搭建                   | 托管式结账               |
| 通过 Chat 管理商品目录 (商品、库存、折扣)  | 商品、库存、购物车和订单的记录系统   |
| 店面的托管与部署                   | 支付、身份验证 (KYC) 和结算打款 |
| 在 Canvas 中生成设计变体           | 税费、物流和履约            |
| 扩展应用 (博客、落地页等)             | 多渠道销售               |

订单、退款、结算打款和履约均在你的 Shopify 后台中管理，而非由 Agent 处理。

<div id="escopo-da-conexo">
  ## 连接范围
</div>

* 所有构建者在所有应用中均可使用，直接在对话中连接，无需在连接器面板中配置，也无需凭证。
* 与单个应用绑定：每个应用都会获得独立的 Shopify 商店。
* 在你认领之前，该商店属于 Replit 自有的开发商店；你的电子邮件会共享给 Shopify，以便你日后认领。
* 你可以随时在 Shopify 后台卸载 Replit 应用。

<div id="entre-no-ar-no-shopify">
  ## 在 Shopify 上线
</div>

上线是在 Shopify 完成的，而不是在 Replit。请让 Agent 启动上线流程，然后在你的 Shopify 后台完成以下由店主负责的步骤：

* **认领商店**：通过 Chat 中的链接或 Shopify 发送的邮件进行认领。该链接 7 天后失效。认领商店后即开始免费试用期。
* **选择套餐**：处理真实订单需要[付费套餐](https://www.shopify.com/pricing)。
* **配置支付**：启用 [Shopify Payments](https://help.shopify.com/en/manual/payments/shopify-payments) 或其他支付服务商，并完成身份验证 (KYC) 。认领账户完成 KYC 后即可实时收款。
* **设置[配送](https://help.shopify.com/en/manual/shipping)和[税费](https://help.shopify.com/en/manual/taxes)。**
* **连接[自定义域名](/zh/pt/build/add-custom-domain)** (可选) ，并移除店面访问密码，向购物者开放商店。

结账始终会跳转到 Shopify 托管的结账页面，因此购物者是在 Shopify 上完成付款。

<Note>
  支付、身份验证、税费、配送和欺诈检查均由 Shopify 负责。Replit 绝不会收集店主的银行数据、
  税务登记号或其他敏感信息。
</Note>

<div id="soluo-de-problemas">
  ## 故障排查
</div>

<AccordionGroup>
  <Accordion title="Shopify 商店配置耗时较长">
    配置过程会调用多个 Shopify API，可能需要一些时间。请等待 Agent 完成配置后，再让它构建店面。
  </Accordion>

  <Accordion title="开发过程中结账显示密码页面">
    开发商店在正式上线前会一直受密码保护，因此结账预览可能会跳转到密码页面。这是正常现象，购物车仍可正常使用。只有在准备上线商店时，才需要在 Shopify 中移除密码。
  </Accordion>

  <Accordion title="结账无法完成真实付款">
    要实时收款，需要认领商店的 Shopify 账户完成支付设置和 KYC 认证。在此之前，结账会跳转到 Shopify，但无法完成收款。请完成 KYC 认证，或改用已配置好支付的账户。
  </Accordion>

  <Accordion title="Agent 提示此应用未连接 Shopify">
    每个商店都与一个应用相关联。如果你是在其他应用中连接的 Shopify，请让 Agent 为当前应用配置一个 Shopify 商店。
  </Accordion>

  <Accordion title="店面中不显示商品">
    商品只有处于启用并已发布状态时才会显示。Agent 会自动发布自己创建的商品；如果有商品缺失，请让 Agent 发布该商品，然后刷新 Preview。
  </Accordion>

  <Accordion title="转移后需要重新建立连接">
    认领或转移商店后，Shopify 可能会要求你重新授权该连接。请让 Agent 重新连接 Shopify，它会恢复访问权限，你的商店不会丢失。
  </Accordion>
</AccordionGroup>
