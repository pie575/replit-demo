<div id="section">
  ## 计费类别
</div>

Replit 将应用存储费用分为以下类别：

* **存储**：每月使用的数据量。所有存储的对象均至少按 7 天计费。
* **数据传输**：当月上传和下载的数据总量。
* **基本操作**：与存储桶和对象更新相关的操作。有关详细信息，请参阅 <a href="https://cloud.google.com/storage/pricing" target="_blank">Google Cloud Storage 定价</a>中的 A 类操作。
* **高级操作**：除基本操作外的所有其他云对象存储操作，包括检索对象和存储桶的配置及元数据。有关详细信息，请参阅 <a href="https://cloud.google.com/storage/pricing" target="_blank">Google Cloud Storage 定价</a>中的 B 类操作。
