Permettre aux utilisateurs de se connecter à votre site web avec leur compte Google présente plusieurs avantages :

1. Vous n&#39;avez pas besoin d&#39;implémenter votre propre système d&#39;authentification.
2. Vous obtenez facilement le nom et les coordonnées de l&#39;utilisateur.
3. Vous pouvez accéder aux ressources Google de l&#39;utilisateur, comme Sheets ou Drive, avec les mêmes identifiants.

Ce guide vous explique comment mettre cela en place avec Python et Flask sur Replit.

Nous verrons d&#39;abord comment configurer l&#39;authentification OAuth de base, puis comment utiliser les identifiants ainsi obtenus pour accéder aux ressources Google de l&#39;utilisateur.

<div id="oauth">
  ## Introduction à OAuth
</div>

L’authentification Google repose sur la norme OAuth. Voici comment fonctionne OAuth :

1. Sur votre site web, vous dirigez l’utilisateur vers une page de connexion.
2. Lorsque l’utilisateur accède à cette page, au lieu d’implémenter un formulaire de connexion sur votre site web, vous le redirigez vers le service de connexion de Google afin de l’authentifier.
3. Une fois l’utilisateur authentifié par le service de connexion de Google, celui-ci le redirige vers votre site web en transmettant des informations sur l’utilisateur et sa session de connexion à une URL prédéfinie (par exemple, `https://YOUR_DOMAIN/oauth2callback`).
4. Utilisez les informations de connexion de l’utilisateur pour obtenir un jeton d’accès supplémentaire. Ce jeton agit comme un laissez-passer permettant d’accéder aux ressources de l’utilisateur, telles que ses informations de profil, ses feuilles de calcul et ses documents.

<div id="oauth-2">
  ## OAuth : voir le code
</div>

Si vous souhaitez d&#39;abord consulter le code, voici ce qu&#39;il vous faut. Toutefois, quelques réglages dans Google Cloud Console sont nécessaires pour que tout fonctionne. Nous les abordons dans la section suivante. Créez une nouvelle application Replit à l&#39;aide du [modèle Flask](https://replit.com/@replit/Flask?v=1), puis ajoutez le code suivant dans `main.py`. Les commentaires du code expliquent le rôle de chaque partie :

```python theme={null}
from flask import Flask, redirect, session, url_for, request
import google_auth_oauthlib.flow
import json
import os
import requests

app = Flask('app')
# `FLASK_SECRET_KEY` sert aux sessions. Vous devez générer une chaîne
# aléatoire et l'enregistrer comme secret.
app.secret_key = os.environ.get('FLASK_SECRET_KEY') or os.urandom(24)

# `GOOGLE_APIS_OAUTH_SECRET` contient le contenu du fichier JSON que vous
# téléchargerez depuis le panneau Google Cloud Credentials. Voir la section suivante.
oauth_config = json.loads(os.environ['GOOGLE_OAUTH_SECRETS'])

# Configuration du flux OAuth
oauth_flow = google_auth_oauthlib.flow.Flow.from_client_config(
    oauth_config,
    # scopes définit les API accessibles au nom de l'utilisateur après authentification
    scopes=[
        "https://www.googleapis.com/auth/userinfo.email",
        "openid",
        "https://www.googleapis.com/auth/userinfo.profile",
    ]
)

# Point d'entrée de la page de connexion. Redirige vers le service de connexion Google
# situé à `authorization_url`. `redirect_uri` est l'URI que le service de connexion
# Google utilisera pour rediriger de nouveau vers cette application.
@app.route('/signin')
def signin():
    # À l'intérieur de l'application Replit, on utilise http, mais l'accès externe se fait en https ;
    # on convertit donc l'URL de http en https pour que redirect_uri corresponde
    oauth_flow.redirect_uri = url_for('oauth2callback', _external=True).replace('http://', 'https://')
    authorization_url, state = oauth_flow.authorization_url()
    session['state'] = state
    return redirect(authorization_url)

# Endpoint vers lequel le service de connexion Google redirige. Vous devez l'ajouter
# à « Authorized redirect URIs » dans le panneau des identifiants API de Google Cloud.
# Il appelle l'endpoint Google pour demander un jeton d'accès et l'enregistre dans la session utilisateur.
# Ce jeton d'accès permet ensuite d'accéder aux API au nom de l'utilisateur.
@app.route('/oauth2callback')
def oauth2callback():
    if not session['state'] == request.args['state']:
        return 'Invalid state parameter', 400
    oauth_flow.fetch_token(authorization_response=request.url.replace('http:', 'https:'))
    session['access_token'] = oauth_flow.credentials.token
    return redirect("/")

# Page d'accueil de l'application. Invite à se connecter si ce n'est pas déjà fait,
# et affiche les informations de l'utilisateur s'il est déjà connecté.
@app.route('/')
def welcome():
    if "access_token" in session:
        user_info = get_user_info(session["access_token"])
        if user_info:
            return f"""
                Hello {user_info["given_name"]}!<br>
                Your email address is {user_info["email"]}<br>
                <a href="/logout">Log out</a>
            """
    return """
        <h1>Hello!</h1>
        <a href="/signin">Sign In via Google</a><br>
    """

# Appelle l'API userinfo avec un jeton d'accès valide pour récupérer les informations de l'utilisateur.
# C'est le premier exemple d'accès à une API au nom de l'utilisateur avec un jeton d'accès.
def get_user_info(access_token):
    response = requests.get("https://www.googleapis.com/oauth2/v3/userinfo", headers={
       "Authorization": f"Bearer {access_token}"
   })
    if response.status_code == 200:
        user_info = response.json()
        return user_info
    else:
        print(f"Failed to fetch user info: {response.status_code} {response.text}")
        return None

@app.route('/logout')
def logout():
    session.clear()
    return redirect('/')

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000)

```

<div id="google-sheets">
  ## Intégration à Google Sheets : voir le code
</div>

Dans la section du flux OAuth du code d’origine, ne modifiez rien et ajoutez simplement `"https://www.googleapis.com/auth/spreadsheets.readonly"` à la liste des portées :

```python theme={null}
# Configuration du flux OAuth
oauth_flow = google_auth_oauthlib.flow.Flow.from_client_config(
    oauth_config,
    # Les scopes définissent les API auxquelles accéder au nom de l’utilisateur après l’authentification
    scopes=[
        "https://www.googleapis.com/auth/userinfo.email",
        "openid",
        "https://www.googleapis.com/auth/userinfo.profile",
        "https://www.googleapis.com/auth/spreadsheets.readonly"
    ]
)
```

Désormais, pour accéder aux API Google avec la bibliothèque `googleapiclient.discovery`, il faut d&#39;abord créer un objet `Credentials` à partir du jeton d&#39;accès, puis créer un objet API appelable à l&#39;aide de la fonction `build`. Pour l&#39;API Sheets, cela donne ceci :

```python theme={null}
credentials = google.oauth2.credentials.Credentials(token=session['access_token'])
service = build("sheets", "v4", credentials=credentials)
sheets_api = service.spreadsheets()
```

Nous avons créé quelques fonctions utilitaires pour illustrer l&#39;utilisation concrète de l&#39;API Sheets :

```python theme={null}
# Récupérer tous les onglets d'une feuille de calcul Google
def get_sheets(sheets_api, spreadsheet_id) -> list[str]:
    result = sheets_api.get(spreadsheetId=spreadsheet_id).execute()
    return [sheet["properties"]["title"] for sheet in result["sheets"]]

# Récupérer les données d'un onglet donné d'une feuille de calcul Google
def get_sheet_data(sheets_api, spreadsheet_id, sheet_title) -> list[list[str]]:
    result = (
        sheets_api.values()
        .get(spreadsheetId=spreadsheet_id, range=sheet_title)
        .execute()
    )
    return result["values"]
```

À l&#39;aide de ce qui précède, vous pouvez créer un point de terminaison POST qui importe une feuille de calcul Google, comme suit :

```python theme={null}
@app.route("/import_spreadsheet", methods = ['POST'])

        return f"upload failure"
    dirpath = os.path.join("static", "uploads", spreadsheet_id)

    with open(filepath, "w") as file:
```

```python theme={null}
from flask import Flask, redirect, session, url_for, request
import google_auth_oauthlib.flow
import json
import os
import requests
from googleapiclient.discovery import build
import googleapiclient.errors
import google.oauth2.credentials

app = Flask('app')
# `FLASK_SECRET_KEY` est utilisée pour la session. Vous devez générer une chaîne aléatoire
# et l'enregistrer dans les Secrets.
app.secret_key = os.environ.get('FLASK_SECRET_KEY') or os.urandom(24)

# `GOOGLE_APIS_OAUTH_SECRET` correspond au contenu du fichier JSON à télécharger
# depuis le panneau Google Cloud Credentials. Voir la section suivante.
oauth_config = json.loads(os.environ['GOOGLE_OAUTH_SECRETS'])

# Configuration du flux OAuth
oauth_flow = google_auth_oauthlib.flow.Flow.from_client_config(
    oauth_config,
    # scopes définit les API accessibles au nom de l'utilisateur après l'authentification
    scopes=[
        "https://www.googleapis.com/auth/userinfo.email",
        "openid",
        "https://www.googleapis.com/auth/userinfo.profile",
        "https://www.googleapis.com/auth/spreadsheets.readonly"
    ]
)

# Point d'entrée de la page de connexion. Redirige vers le service de connexion Google
# situé à `authorization_url`. `redirect_uri` est l'URI que le service de connexion Google
# utilisera pour rediriger vers cette application.
@app.route('/signin')
def signin():

    # L'URL est donc convertie de http vers https pour que redirect_uri corresponde.
    oauth_flow.redirect_uri = url_for('oauth2callback', _external=True).replace('http://', 'https://')
    authorization_url, state = oauth_flow.authorization_url()
    session['state'] = state
    return redirect(authorization_url)

# Point de terminaison vers lequel le service de connexion Google redirige. Il doit être ajouté
# aux "Authorized redirect URIs" dans le panneau d'informations d'identification de l'API de Google Cloud.
# Il appelle le point de terminaison Google pour demander un jeton d'accès et l'enregistre dans la session utilisateur.
# Ce jeton d'accès peut ensuite être utilisé pour accéder à l'API au nom de l'utilisateur.
@app.route('/oauth2callback')
def oauth2callback():

        return 'Invalid state parameter', 400
    oauth_flow.fetch_token(authorization_response=request.url.replace('http:', 'https:'))
    session['access_token'] = oauth_flow.credentials.token
    return redirect("/")

# Il s'agit du premier exemple d'accès à l'API au nom de l'utilisateur avec un jeton d'accès.
def get_user_info(access_token):

       "Authorization": f"Bearer {access_token}"
   })
    if response.status_code == 200:
        user_info = response.json()
        return user_info
    else:
        print(f"Failed to fetch user info: {response.status_code} {response.text}")
        return None

@app.route('/logout')
def logout():
    session.clear()
    return redirect('/')

# Récupérer toutes les feuilles d'un Google Sheet
def get_sheets(sheets_api, spreadsheet_id) -> list[str]:
    result = sheets_api.get(spreadsheetId=spreadsheet_id).execute()
    return [sheet["properties"]["title"] for sheet in result["sheets"]]

# Récupérer les données d'une feuille spécifique dans un Google Sheet
def get_sheet_data(sheets_api, spreadsheet_id, sheet_title) -> list[list[str]]:
    result = (
        sheets_api.values()
        .get(spreadsheetId=spreadsheet_id, range=sheet_title)
        .execute()
    )
    return result["values"]

# Rendu du formulaire d'importation de feuille de calcul
@app.route("/import_spreadsheet_form")
def import_spreadsheet_form():
    return """
    <h3>Import Spreadsheet</h3>
    <form action="/import_spreadsheet" method="POST">
        <label>Spreadsheet ID</label>
        <input type="text" name="spreadsheet_id">

        <button type="submit">Import</button>
    </form>
    """

@app.route("/import_spreadsheet", methods = ['POST'])
def import_spreadsheet():

        return redirect('/signin')
    spreadsheet_id = request.form["spreadsheet_id"]
    credentials = google.oauth2.credentials.Credentials(token=session['access_token'])

    sheets_api = service.spreadsheets()

    with open(filepath, "w") as file:
        json.dump(data_by_sheets, file)
    return "upload success! Really!"

@app.route('/')
def welcome():
    if "access_token" in session:
        user_info = get_user_info(session["access_token"])
        if user_info:
            return f"""
            Hello {user_info["given_name"]}!<br>
            Your email address is {user_info["email"]}<br>
            <a href="/signin">Sign In to Google</a><br>
            <a href="/import_spreadsheet_form">Import a Sheet</a>
            """
    return """
    <h1>Welcome to Google Sheet Importer</h1>
    <a href="/signin">Sign In to Google</a><br>
    <a href="/import_spreadsheet_form">Import a Sheet</a>
    """

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000)
```
