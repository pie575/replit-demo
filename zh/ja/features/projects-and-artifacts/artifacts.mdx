<div id="section">
  ## 什么是 artifact？
</div>

artifact 就是你可以在 Replit 上发布的成果，比如 Web 应用、移动应用、幻灯片、动画、数据应用、3D 游戏、设计等等。每个 artifact 都是完整且独立的作品，发布后会获得专属的可分享 URL。

项目中的其他内容 (文件、图片、CSV、代码) 都是为 artifact 服务的，无法单独发布。

<ArtifactGrid />

<div id="section-2">
  ## 可以创建的内容
</div>

| 类型                                                           | 说明                            |
| ------------------------------------------------------------ | ----------------------------- |
| **[Web 应用](/zh/ja/features/artifact-types/web-apps)**           | 精美而强大的网站，可处理用户、数据库等。          |
| **[移动应用](/zh/ja/features/artifact-types/building-mobile-apps)** | 适用于 iPhone 和 Android 手机的原生应用。 |
| **[幻灯片](/zh/ja/features/artifact-types/slide-decks)**           | 可用于演示或导出的幻灯片。                 |
| **[动画](/zh/ja/features/artifact-types/animated-videos)**        | 动态图形与动画视频，可导出为 MP4。           |
| **[数据可视化](/zh/ja/features/artifact-types/data-apps)**           | 用于探索数据、创建图表的交互式仪表板与可视化内容。     |
| **3D 游戏**                                                    | 3D 游戏、模拟和交互式体验。               |
| **[Design](/zh/ja/design/canvas)**                              | 在设计 Canvas 上探索视觉方向、快速构建创意原型。  |

各类型在不同套餐中的可用情况，请参阅其专属页面。

<div id="section-3">
  ## 开始使用
</div>

在 Replit 主页上，有两种创建方式：

* **描述需求**：直接输入你想要的东西——比如&quot;做一个食谱应用&quot;或&quot;做一份创业路演材料&quot;。Agent 会判断哪种类型最合适，并着手构建。
* **选择类型**：在描述你的创意之前，先选择想要的产物 (Web 应用、移动应用、数据可视化、动画、3D 游戏或其他支持的类型) 。

你也可以随时在聊天中让 Agent 添加，或点击预览面板中的 **+** 按钮，将其添加到现有项目中。

<div id="section-4">
  ## 切换制品
</div>

如果项目中有多个制品，可以在**预览面板**或**库侧边栏**中切换。你也可以直接问 Agent——比如“给我看看移动应用”或“切换到幻灯片”。

<div id="section-5">
  ### 库侧边栏
</div>

库侧边栏为你提供了一个集中浏览项目内所有内容的位置，其中会显示 artifact、Agent 生成或下载的图片以及其他项目资源。从左侧面板打开库侧边栏，即可查找并复用整个项目中的资源。

<div id="section-6">
  ## 一个项目包含多个 artifact
</div>

一个项目最多可包含 **7 个 artifact**，其中**移动应用最多 1 个**。例如，你可以在同一个项目中构建面向客户的 Web 应用、面向团队的移动应用，以及面向投资人的幻灯片。

<ArtifactGrid />

<div id="section-7">
  ### 向项目添加工件
</div>

向现有项目添加工件有三种方式：

* **聊天**：直接告诉 Agent —— “给这个项目添加一个移动应用”或“制作一份面向投资人的幻灯片”
* **加号按钮**：点击预览面板中的 **+** 按钮，选择你想构建的内容
* **库侧边栏**：浏览现有的工件、图片和其他资源，并从中添加新工件

<div id="section-8">
  ### 共享数据与后端
</div>

同一项目中的各个构件会自动共享同一套数据和后端逻辑。当客户在 Web 应用中下单时，移动应用和数据看板会立即看到这笔订单。无需配置连接，也无需重复编写代码——开箱即用。

<Note>
  发布时，整个项目会一次性部署。所有构件同时发布，因此始终保持同步。
</Note>

<div id="section-9">
  ### 组合示例
</div>

* **Web 应用 + 移动应用**：一家餐厅同时拥有面向顾客的 Web 应用和面向员工的移动应用 —— 两者连接同一个 API 和数据库
* **应用 + 管理后台**：主产品搭配内部管理面板，用于管理内容、用户和设置
* **应用 + 幻灯片**：产品与路演幻灯片放在同一个项目中，让幻灯片始终反映最新版本
* **数据看板 + 视频**：实时数据可视化，搭配讲解重点内容的动画视频

<div id="section-10">
  ## 发布
</div>

应用、幻灯片和视频均可发布并分享。部署后，每一项都会获得专属的可分享 URL。

不属于工件的文件或资源 (如 CSV、图片、Markdown 文件等) 无法单独发布。如需分享，请将其添加到应用中，或创建新的工件。

<div id="section-11">
  ## 常见问题
</div>

<Accordion title="一个 project 可以包含多个 artifact 吗？">
  可以。一个 project 最多可包含 **7 个 artifact**，其中**每个 project 只能有 1 个移动应用**。同一 project 内的所有 artifact 会自动共享相同的后端和数据。

  如果已达到移动应用上限，但还想再构建一个移动应用，请在新的 project 中创建。如果已达到 7 个 artifact 的上限，请先删除现有 artifact，或将 project 拆分，然后再添加新的 artifact。
</Accordion>

<Accordion title="开始之前需要先选择类型吗？">
  不需要。只需描述你想要的内容，Agent 就会选择合适的类型。如果愿意，你也可以从下拉菜单中手动选择类型。
</Accordion>

<Accordion title="可以只发布 project 中的某一个 artifact 吗？">
  目前还不行。发布时整个 project 会一起部署，因此所有 artifact 始终保持同步。如果需要独立部署，请使用不同的 project。
</Accordion>

<Accordion title="artifact 之间会共享数据吗？">
  会。同一 project 内的所有 artifact 共享同一个数据库和后端服务。Web 应用写入数据后，移动应用和数据看板可以立即读取到这些数据。
</Accordion>

<Accordion title="artifact 和文件有什么区别？">
  artifact 是可以发布的内容 —— 应用、幻灯片、视频。而文件 (CSV、图片、代码等) 是 project 中用于支撑 artifact 的资源，无法单独发布。
</Accordion>

<Accordion title="移动应用缺少 Web 应用中的某些功能，这是怎么回事？">
  Agent 在不同 artifact 类型之间转换功能时，某些内容可能无法完全沿用 —— 尤其是在不同平台上表现各异的交互和布局。你可以在聊天中继续追问，补齐缺失的部分。
</Accordion>

如需了解可构建内容的完整列表，请参阅 [project 概览](/zh/ja/features/projects-and-artifacts/projects)。
