## O que é uma Skill?

Uma skill é uma pasta. Dentro dela fica um arquivo chamado `SKILL.md` com as instruções que o Agent segue, além de quaisquer arquivos de suporte que você queira que ele consulte. As skills ficam no diretório `/.agents/skills` do seu projeto e seguem a [especificação Agent Skills](https://agentskills.io/specification) — um padrão aberto que funciona em diferentes agentes.

O Agent vê o nome e a descrição de cada Skill instalada, mas só carrega o conteúdo completo quando é relevante para a tarefa atual. Isso torna as skills eficientes em termos de contexto: você pode instalar muitas sem prejudicar a qualidade das respostas do Agent.

## Skills pré-definidas

O Replit já vem com skills pré-definidas disponíveis no seletor **Use a skill** no chat e no seletor de ponto de partida para novos projetos. Essas skills funcionam em todos os projetos sem instalação. Para o catálogo completo, as skills de parceiros e como instalá-las, veja o [Diretório de skills](/pt/features/agent/skills-directory).

Para adicionar uma skill pré-definida, abra o seletor **Use a skill** na entrada de chat e selecione uma skill, ou simplesmente peça ao Agent para carregar a skill.

## Escopo da skill

As skills podem ter escopos em diferentes níveis:

| Escopo                 | Disponibilidade                        | Onde fica                                                                                                             |
| ---------------------- | -------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| **Nível de projeto**   | Específica de um projeto               | Versionada com seus arquivos em `/.agents/skills`                                                                     |
| **Nível de workspace** | Disponível para todos no seu workspace | Gerenciada de forma centralizada em Workspace Settings                                                                |
| **Enterprise**         | Padrões de toda a empresa              | Incluída em [templates personalizados](/pt/teams/custom-templates) e [design systems](/pt/teams/custom-design-system) |

Para skills no nível de workspace, veja [Agent Customization](/pt/features/agent/agent-customization) para configurar skills de workspace e instruções personalizadas para sua equipe.

## Como o Agent carrega skills

O Agent lê os metadados (nome e descrição) de cada skill instalada em todo chat. O corpo completo de uma skill só é carregado quando o Agent determina que ela é relevante para a tarefa atual. Isso mantém o conteúdo das skills fora da janela de contexto até que seja necessário.

As skills instaladas persistem no seu projeto entre sessões do Agent e podem ser enviadas ao controle de versão para compartilhamento com a equipe.

## Trabalhando com outras ferramentas de codificação com IA

<Accordion title="Importar skills de outras ferramentas de codificação com IA">
  Se você trabalha com várias ferramentas de codificação com IA, o [rulesync](https://github.com/dyoshikawa/rulesync) tem suporte ao Replit e ajuda você a manter configurações consistentes.

  Você pode importar skills de outros assistentes de codificação com IA:

  ```bash theme={null}
  npx rulesync init
  npx rulesync import --targets claudecode --features skills
  npx rulesync generate --targets replit --features skills
  ```

  Isso permite que você mantenha um único conjunto de skills que funciona em diferentes ambientes de desenvolvimento.
</Accordion>
