Replit Agent подключается к внешним инструментам и источникам данных через [Model Context Protocol (MCP)](https://modelcontextprotocol.io) — открытый стандарт интеграции с ИИ. Каждый из перечисленных ниже серверов устанавливается в один клик, а Agent автоматически загружает его инструменты и применяет их в подходящий момент.

Описание концепций см. в разделе [Model Context Protocol](/ru/ja/learn/model-context-protocol). Практическое руководство приведено в разделе [Подключение через MCP](/ru/ja/build/connect-via-mcp). Чтобы подключить сервер, которого здесь нет, см. [Добавление пользовательского MCP-сервера](/ru/ja/build/connect-via-mcp#add-a-custom-mcp-server).

<Info>
  Чтобы установить любой сервер, выберите **Добавить в Replit**. В редакторе проекта вам будет предложено авторизовать подключение.
</Info>

<div id="section-2">
  ## Защита безопасности
</div>

Весь трафик MCP проходит через сканер безопасности Replit. Сканер оценивает определения инструментов и планы выполнения и блокирует подозрительные или небезопасные инструменты до их запуска. Если инструмент отклонён, Agent сообщит вам об этом.

<div id="section-3">
  ## Варианты аутентификации
</div>

* **Динамическая регистрация клиента OAuth** — если сервер поддерживает OAuth DCR, Replit автоматически обнаружит и зарегистрирует клиента. Большинство предварительно зарегистрированных серверов используют именно этот сценарий.
* **Пользовательские заголовки** — задайте одну или несколько пар «имя/значение» заголовка (например, `X-API-Key`). Replit будет добавлять эти заголовки ко всем запросам, чтобы сервер мог проверить, кто к нему обращается. Используйте этот вариант при добавлении собственного сервера, который аутентифицирует запросы по статическому токену.

<div id="section-4">
  ## Поделитесь своей ссылкой для установки
</div>

Ссылка для установки позволяет добавить ваш MCP-сервер в Replit в один клик. Сгенерируйте её с помощью формы в разделе [Подключение через MCP](/ru/ja/build/connect-via-mcp#share-an-install-link) или создайте вручную: закодируйте JSON-полезную нагрузку в base64 и добавьте её к `https://replit.com/integrations?mcp=`.

```json theme={null}
{
  "displayName": "My MCP Server",
  "baseUrl": "https://example.com/mcp",
  "headers": [{ "key": "Authorization", "value": "Bearer your-token" }]
}
```

* **displayName** — имя, отображаемое при установке
* **baseUrl** — HTTPS-эндпоинт MCP-сервера
* **headers** — необязательные заголовки аутентификации
