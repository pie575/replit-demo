Sugestões são ótimas para explorar; o chat é como você orienta com precisão. Há duas maneiras de conversar, de acordo com quanto do design você está discutindo: o chat principal para um frame inteiro, e a ferramenta Chat para um único elemento dentro dele.

## Converse sobre um frame pelo chat principal

Selecione o frame sobre o qual você está falando e ele se anexa ao chat principal como um chip. Depois descreva as mudanças que você quer ver, como se estivesse orientando um designer no meio de uma revisão, como: *"cores mais quentes"*, *"o hero parece vazio"*, *"tente a navegação à esquerda."*

## Converse sobre um elemento com a ferramenta Chat

Selecione **Chat** na barra de ferramentas, depois clique em um elemento dentro de um frame, como um botão, um título ou uma imagem. O resto do quadro escurece, o elemento aparece como um chip em um composer, e sua mensagem se aplica só a essa peça.

## Enquanto gera

Os estados de geração aparecem no chat enquanto o Design trabalha. Quando o resultado chega como um novo frame, continue conversando, mude para [sugestões](/pt/design/explore-suggestions), ou [construa-o](/pt/design/build-your-design).
