  ## 集成
</div>

<div id="agent">
  ### 有多个连接器适用时，Agent 会主动推荐
</div>

当你请求 Agent 连接某项服务，而可选的提供商有多个时，Agent 现在会列出一份简短的清单，供你从中选择。此前，Agent 需要先追问你才能继续。选定提供商并登录一次后，Agent 就会继续构建。

</Frame>

<div id="section-3">
  ## 工作区
</div>

<div id="tools">
  ### 全新 Tools 面板正式登场
</div>

现在，应用可用的一切都集中到了工作区中的同一个位置。全新的固定式 Tools 面板将 Database、Auth、Domains、Secrets 等汇聚一处，让你一眼就能找到完整的工具集。工具本身没有变化，只是有了更清晰的归属位置。

<Frame>
  <img src="/assets/mirror/tools-pane-ceaddcc1d7a2.png" alt="工作区 Tools 面板，在 Replit Cloud 下方列出 Publishing、Domains、Monitoring、Growth、Database、Users and Auth、Security Center、App Storage" width="390" height="716" data-path="images/changelog/2026-07-17/tools-pane.png" />
</Frame>

进一步了解 [Tools 面板](/zh/ko/features/editor/editor-and-tools)。

<div id="section-4">
  ### 更快的任务侧边栏
</div>

任务侧边栏现已变成更紧凑、更易于快速浏览的任务导航器。每个任务都有专属的悬停卡片，可用于快捷操作和查看详情；Task Board 有了更清晰的入口；展开或折叠侧边栏时，任务的位置也保持不变。

  <img src="/assets/mirror/task-sidebar-7687ab8089b2.png" alt="工作区任务侧边栏，显示带有 Main、Board、New task 的任务列表，以及所选任务的 Apply changes 卡片" width="1228" height="556" data-path="images/changelog/2026-07-17/task-sidebar.png" />
</Frame>

进一步了解[任务生命周期](/zh/ko/features/agent/task-lifecycle)。
