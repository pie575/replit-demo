Le Canvas est la surface infinie de panoramique et de zoom sur laquelle Replit Design affiche les frames. C’est là que prennent forme toutes vos créations : créez des frames, faites-les glisser pour les déplacer, zoomez sur les détails et itérez jusqu’à obtenir le résultat souhaité.

<div id="canvas">
  ## Ouvrir Canvas
</div>

Canvas est le premier écran qui s’affiche dans Replit Design. Dans un projet, sélectionnez **Design** dans l’en-tête pour afficher Canvas dans le panneau, ou **Build** pour revenir à l’application en cours d’exécution.

<Frame>
  <img src="/assets/mirror/canvas-design-button-ffa50447cefb.png" alt="Vue agrandie de l’en-tête du projet avec les boutons Design et Build. Design est sélectionné et des frames sont affichées dans Canvas en dessous" width="987" height="619" data-path="images/replitai/canvas-design-button.png" />
</Frame>

Lorsque vous commencez sur [replit.com/design](https://replit.com/design), vous êtes invité à créer un nouveau design, qui s’ouvre dans Canvas. Pour savoir quand utiliser chaque écran, consultez [Design vs. Build](/fr/ko/design/design-vs-build).

<div id="canvas-2">
  ## Éléments présents sur le Canvas
</div>

* **Frames** : toutes les tuiles du tableau. Une frame peut être une maquette, une application web, une application mobile, une diapositive, une image, une vidéo ou un graphique vectoriel. Créez-en via un prompt dans le chat, le [menu Generate](/fr/ko/design/toolbar#generate) de la barre d&#39;outils ou le [panneau Bibliothèque](/fr/ko/design/library-panel). Toutes les actions que vous effectuez sur une frame — Build, Focus, suggestions — s&#39;effectuent directement sur celle-ci : consultez [Frames](/fr/ko/design/frames).
* **Dessins et notes** : des annotations ajoutées avec l&#39;[outil Draw](/fr/ko/design/toolbar#draw), notamment des croquis, des flèches, des formes et des notes autocollantes. Agent lit les annotations ; vous pouvez donc entourer une zone problématique et demander des modifications.
* **Panneau de chat** : le chat Agent ancré à côté du Canvas. Si vous sélectionnez une frame avant d&#39;envoyer un message, celle-ci est jointe sous forme d&#39;instantané afin qu&#39;Agent dispose d&#39;un contexte visuel.

Pour savoir ce qu&#39;est chaque composant et comment ils s&#39;articulent, consultez la [vue d&#39;ensemble des composants](/fr/ko/design/core-components).

<div id="section">
  ## Naviguer sur le tableau
</div>

Sauf indication contraire, vous pouvez déplacer la vue, zoomer et sélectionner avec n’importe quel outil.

**Déplacement :**

* Trackpad : faites glisser avec deux doigts.
* Souris : cliquez sur le bouton central et faites glisser, ou maintenez la barre d’espace enfoncée tout en faisant glisser avec le bouton gauche.
* [Outil Pan](/fr/ko/design/toolbar#pan) : cliquez et faites glisser avec le bouton gauche de la souris.

**Zoom :**

* Trackpad : pincez.
* Souris : `Ctrl` (`Cmd` sur macOS) + molette de défilement.
* Clavier : pour zoomer, `Cmd`/`Ctrl` + `+` ; pour dézoomer, `Cmd`/`Ctrl` + `-` ; pour réinitialiser le zoom, `Cmd`/`Ctrl` + `0`.

Le zoom est centré sur le curseur : le point situé sous celui-ci reste fixe, tandis que le reste du tableau zoome autour de ce point.

**Sélection :**

* Un seul frame : cliquez dessus avec l’[outil Interact](/fr/ko/design/toolbar#interact).
* Sélection multiple : maintenez `Shift` enfoncée tout en cliquant sur chaque frame, ou faites glisser un rectangle de sélection sur le tableau.
* Désélection : cliquez sur une zone vide ou appuyez sur `Escape`.

Lorsque vous sélectionnez un ou plusieurs frames, la [barre d’actions par frame](/fr/ko/design/frames#per-frame-action-bar) s’affiche et ces frames sont jointes sous forme d’instantanés à votre prochain message à Agent.

<div id="section-2">
  ### Raccourcis clavier
</div>

| Raccourci                                   | Action                                                      |
| ------------------------------------------- | ----------------------------------------------------------- |
| `V`                                         | Active l’outil Interact                                     |
| `H`                                         | Active l’outil Pan                                          |
| Maintenir `Space` enfoncée et faire glisser | Permet de faire glisser la vue, quel que soit l’outil actif |
| `Cmd` / `Ctrl` + défilement                 | Zoom avant/arrière                                          |
| `Cmd` / `Ctrl` + `+`                        | Zoom avant                                                  |
| `Cmd` / `Ctrl` + `-`                        | Zoom arrière                                                |
| `Cmd` / `Ctrl` + `0`                        | Réinitialise le zoom                                        |
| `Shift` + clic                              | Ajoute une frame à la sélection actuelle                    |
| `Cmd` / `Ctrl` + `Shift` + `C`              | Copie la frame sélectionnée au format PNG                   |
| `Escape`                                    | Désélectionne                                               |

<div id="section-3">
  ## Menu contextuel
</div>

Faites un clic droit n’importe où sur le tableau pour ouvrir le menu contextuel. Son contenu s’adapte au contexte : les actions varient selon l’élément sous le curseur. Les frames affichent des actions propres aux frames, les zones vides du Canvas des actions au niveau du tableau, et les frames d’application proposent également **Refresh artifact**.

Le menu d’une frame sélectionnée contient les éléments suivants.

| Action                         | Raccourci                     | Fonction                                                              |
| ------------------------------ | ----------------------------- | --------------------------------------------------------------------- |
| Edit                           |                               | Passe à l’outil Edit pour sélectionner des éléments dans la frame.    |
| Chat                           |                               | Discutez avec Agent à propos de la frame.                             |
| Focus                          |                               | Active le [mode focus](/fr/ko/design/frames#focus-mode) pour la frame.   |
| Cursor chat                    | `/`                           | Démarre une conversation rapide à l’emplacement du curseur.           |
| Reorder                        |                               | Déplace la frame vers l’avant ou l’arrière dans l’ordre d’empilement. |
| Copy, Paste, Duplicate, Delete | `⌘C`, `⌘V`, `⌘D`, `Backspace` | Fonctions standard de presse-papiers et de gestion des frames.        |
| Export as…                     |                               | Exporte la frame dans un fichier.                                     |
| Select all                     | `⌘A`                          | Sélectionne toutes les frames du tableau.                             |

<div id="png">
  ### Exporter une frame au format PNG
</div>

Enregistrez n’importe quel artefact ou frame de conception sous forme d’image PNG. Cette option est utile pour partager un aperçu dans un document ou une discussion, capturer un instantané avant de poursuivre les itérations ou envoyer une capture d’écran à vos coéquipiers.

<Steps>
  <Step title="Sélectionner une frame">
    Sélectionnez l’artefact ou la frame de conception à exporter, puis attendez qu’il ait fini de charger.
  </Step>

  <Step title="Sélectionner Export">
    Dans la barre d’actions de la frame, sélectionnez **Export**. Vous pouvez également cliquer avec le bouton droit sur la frame, puis sélectionner **Export as…** &gt; **PNG**. L’image est téléchargée sur votre ordinateur sous un nom de fichier basé sur celui de la frame.
  </Step>
</Steps>

Pour copier la frame sélectionnée au format PNG au lieu de la télécharger, appuyez sur `Cmd+Shift+C` (ou sur `Ctrl+Shift+C` sous Windows et Linux).

<Note>Le PNG exporté correspond à ce que la frame affiche actuellement dans Canvas. Si votre application ou votre conception est encore en cours de chargement, attendez qu’elle soit entièrement chargée avant de l’exporter.</Note>

<div id="canvas-3">
  ## Canvas et aperçu de l&#39;application en cours d&#39;exécution
</div>

Canvas et l&#39;aperçu de l&#39;application en cours d&#39;exécution partagent le même panneau, et plusieurs modes permettent de passer de l&#39;un à l&#39;autre.

* **Mode Focus **: l&#39;action **Focus** du frame sélectionné agrandit celui-ci pour remplir l&#39;écran. Sélectionnez **Exit focus** en haut du panneau pour revenir à Canvas.
* **Mode lecture seule **: lorsque Canvas est verrouillé dans le contexte d&#39;une tâche en arrière-plan, les actions liées aux tâches itératives sont masquées et seule l&#39;action Focus reste disponible.

<Note>
  Core ou Pro est requis pour créer une application à partir d&#39;un frame Design. Toutes les autres fonctionnalités de Canvas sont disponibles avec tous les forfaits. Pour en savoir plus sur les forfaits, consultez [Billing](/fr/ko/billing/ai-billing).
</Note>
