<div id="controles-de-layout-no-editor-visual">
  ### 可视化编辑器中的布局控件
</div>

可视化编辑器现已提供专用的 **布局** 控件，让您可以直观地调整 flexbox 布局，无需让 Agent 重写样式。选择任意容器，展开布局部分，然后选择 flex 方向、对齐方式和分布方式。设置项目之间的像素间距，或启用 **两端对齐** 开关，将子元素推到两侧边缘。

编辑器面板也重新划分为更清晰的 **文本**、**图像**、**布局**、**颜色** 和 **边框** 部分，方便您更快找到所需控件。

  ## Agent

<div id="configuraes-do-agent-permanecem-suas-em-projetos-compartilhados">
  ### 共享项目中的 Agent 设置归您个人所有
</div>

您的 Agent 偏好设置 (如模型级别、规划模式、自动合并和自动批准计划) 现在将与您个人关联，不再与项目中的所有成员共享。团队成员在自己的任务中切换到 Power 模式，也不会再更改您的设置。您选择的设置将由 Agent 在您发送下一条消息时使用，即使项目中有许多协作者也是如此。

详细了解 [Agent 模式](/zh/pt/features/agent/agent-modes#settings-in-shared-projects)。

<div id="agent-sugere-modo-power-quando-voc-est-travado">
  ### 遇到卡顿时，Agent 会建议使用 Power 模式
</div>

当 Agent 发现您在 Economy 模式下反复遇到同一问题时，会建议您在下一条消息中切换到 Power。该建议会检测重复请求或持续报错的代码，每个项目最多显示一次。若处于规划会话、您已提到预算方面的顾虑，或您使用的是免费套餐，Agent 则不会显示此建议。

<div id="menu-suspenso-de-configuraes-de-tarefas-mais-limpo">
  ### 更简洁的 task 设置下拉菜单
</div>

在 task 标题栏中打开的下拉菜单现在更易于使用。当前 task 或计划的标题现位于顶部，支持内联重命名；自动化设置 (自动应用、自动批准) 位于标题和操作之间的独立区域；弹出菜单采用固定宽度，不会再因 task 名称变化而移动。已禁用的自动化选项会被隐藏，因此菜单仅显示适用于当前 task 的内容。

<div id="dois-novos-conectores-quiver-ai-e-browserbase">
  ### 两个新连接器：Quiver AI 和 Browserbase
</div>

连接器目录现已新增两项服务。打开**集成**面板，选择**添加新集成**，即可连接其中任一服务。

* **Quiver AI**：通过托管 API 生成 SVG 插图并将光栅图像矢量化。当 Agent 需要按需获取简洁的 SVG 资源时非常有用。
* **Browserbase**：运行托管无头浏览器，用于搜索、研究和完整的会话自动化。当 Agent 需要加载真实网页、执行 JavaScript，或与阻止简单 HTTP 请求的网站交互时非常有用。
