<div id="visibilidade-do-custo-de-uso-do-agent">
  ### Прозрачность расходов на использование Agent
</div>

Отслеживайте стоимость использования Agent в реальном времени, пока выполняются задачи. Откройте панель в заголовке Chat, чтобы следить за расходами по активным задачам — это особенно полезно для длительных запусков с высокой степенью автономности.

<div id="tecla-escape-para-o-modo-visual-selectedit">
  ### Клавиша Escape для режима Visual Select/Edit
</div>

Нажмите Escape, чтобы выйти из режима Visual Select или вернуться в режим создания. Простой шорткат, который помогает не сбавлять темп.

<div id="parada-mais-rpida-do-agent">
  ### Более быстрая остановка Agent
</div>

Agent реагирует быстрее, когда вы останавливаете или запускаете его из рабочего пространства, — время ожидания сокращается.

<div id="melhorias-na-importao-do-github">
  ### Улучшения импорта из GitHub
</div>

Теперь при импорте из GitHub вместо общих сообщений отображается прогресс в реальном времени, а сам импорт стал быстрее.

<div id="verificao-de-vulnerabilidades-de-dependncias">
  ### Проверка зависимостей на уязвимости
</div>

Сканер безопасности теперь находит уязвимости в зависимостях для Go, JavaScript, Python и Rust — поддержка других языков появится в ближайшее время.

<div id="experincia-de-logging-do-webview">
  ### Работа с логами Webview
</div>

Просматривайте логи webview и вывод консоли в одном месте — те же логи, которые использует Agent, что упрощает отладку.

<div id="acesso-de-assentos-de-suporte-para-equipes">
  ### Доступ к местам поддержки для команд
</div>

Добавьте службу поддержки Replit как гостевую учётную запись, которая не учитывается при выставлении счетов. Предоставляйте ограниченный доступ к отдельным Apps, когда вам нужна помощь, сохраняя контроль над конфиденциальностью рабочего пространства.
