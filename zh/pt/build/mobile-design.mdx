<div id="soluo-de-problemas">
  ## 故障排除
</div>

* **改动超出了预期：**请 Agent 将其还原，并描述范围更小的
  改动，一次处理一个界面或元素。
* **预览中看起来正常，手机上却不对：**说明所用设备和你看到的情况，
  安全区域适配和屏幕尺寸通常是原因。
* **某项改动总是被撤销：**同一个值可能在多个位置定义，
  询问 Agent 该界面的样式实际定义在哪里。
