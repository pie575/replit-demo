---
title: "Activer le widget de feedback"
description: "Découvrez comment recueillir les retours des visiteurs de votre application déployée."
---

En activant la collecte de feedback dans votre application déployée, vous pouvez recueillir directement les retours des visiteurs et les transmettre à Agent. Une fois cette fonctionnalité activée, les visiteurs peuvent envoyer des feedbacks avec des captures d’écran et des fichiers, que vous pouvez gérer depuis votre boîte de réception.

<div id="section">
  ## Activer les retours
</div>

<Warning>
  Les retours ne peuvent être activés que pour les applications web. Ils ne peuvent pas être activés pour d’autres types d’applications, comme les automatisations ou les applications mobiles.
</Warning>

Lors du déploiement d’une nouvelle application, activez le paramètre **Activer les retours** dans la boîte de dialogue de publication. Si votre application est déjà déployée, vous pouvez activer les retours en la redéployant.

1. Ouvrez l’outil Publishing
2. Sélectionnez **Paramètres avancés**
3. Activez **Activer les retours**
4. Redéployez l’application

<div id="section-2">
  ## Envoyer un retour
</div>

Lorsque les retours sont activés sur votre application déployée, les visiteurs peuvent envoyer leurs retours directement depuis l&#39;application. Les utilisateurs peuvent :

* se connecter pour laisser un retour ;
* laisser un retour écrit décrivant leur expérience ou leurs suggestions ;
* sélectionner un élément pour illustrer un problème ou une fonctionnalité ;
* téléverser des fichiers pour apporter du contexte supplémentaire.

<div id="section-3">
  ## Gérer les retours depuis la boîte de réception
</div>

Tous les retours envoyés par les visiteurs apparaissent dans la boîte de réception, accessible depuis le Project Editor. Depuis celle-ci, vous pouvez :

* **Ajouter au chat** : envoyer le retour dans le chat avec Agent afin d&#39;ajouter du contexte avant de le soumettre
* **Envoyer à Agent** : transmettre immédiatement le retour à Agent et lancer le travail sans attendre
* **Résoudre** : marquer le retour comme résolu une fois qu&#39;il a été traité
* **Supprimer** : retirer les retours dont vous n&#39;avez plus besoin

Vous pouvez également utiliser les filtres pour organiser et retrouver des retours précis.

<div id="section-4">
  ## Redéployer avec les paramètres de retour mis à jour
</div>

Une fois votre application déployée, vous pouvez activer ou désactiver le widget de feedback à tout moment en la redéployant avec les paramètres mis à jour.

1. Ouvrez l&#39;onglet **Overview** de l&#39;outil Publishing
2. Sélectionnez **Paramètres avancés**
3. Activez ou désactivez **Activer les retours**
4. Redéployez votre application pour appliquer les modifications

Les modifications des paramètres de retour prennent effet une fois l&#39;application redéployée.
