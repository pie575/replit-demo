<div id="section">
  ## 为什么这很重要
</div>

每部 iPhone 都内置了警告框、共享表、开关和菜单，用户在自己使用的
其他应用中早已习惯这些功能。当你的应用使用相同的原生组件时，用户甚至在点击
之前就已经知道该如何操作。这正是让它感觉像真正 iPhone 应用的原因。

以下是可添加到应用中的原生组件提示词示例：警告框、操作表、开关
等。

  ## SF Symbols
</div>

<AiPrompt>
  {sfSymbolsPrompt}

SF Symbols 是 Apple 内置的图标集。图标会自动适配周围文本的大小、粗细和深色模式。使用自定义图标集时，则需要手动实现这些功能。

<Frame caption="设置中的音效和振动图标使用了 SF Symbols。">
  <img src="/assets/mirror/native-sf-46d879d1c2c1.png" alt="音效和振动设置旁的 SF Symbols 图标" data-path="images/pixelgames/mobile/native-sf.png" width="1516" height="310" data-path="images/pixelgames/mobile/native-sf.png" />

<Note>
  SF Symbols 仅适用于 iOS。对于 Android，请让 Agent 选择合适的图标集。
  图标在不同平台上的像素并不完全一致，这是预期行为。
</Note>

<div id="section-6">
  ## 故障排查
</div>

* **显示自定义模态框，而不是警告框或操作表：** 请确认 Agent 使用的是原生 API，而不是通过 JS 渲染出相似的外观。
  外观可能相似，但实际行为可能不同。
* **图标在 Android 上显示异常：** 对 SF Symbols 而言，这是预期行为，因为它们仅适用于 iOS。
  请让 Agent 确认使用了哪套替代图标。
* **共享表中未显示预期的应用：** 这由 OS 以及测试设备上安装的应用决定，
  并非 PixelGames 可以直接添加。
