---
title: "Agent 模式"
description: "了解如何在使用 Agent 构建时选择 Free Mode、Power Mode 和 Max Mode。"
---

使用 Agent 模式，您可以平衡使用 Agent 时的成本与能力。使用 Agent 设置下拉菜单，选择 **Free Mode**、**Power Mode** 或 **Max Mode**。Free Mode 始终使用 Auto。Core 和 Pro 构建者可在 Power Mode 或 Max Mode 下使用[模型选择器](/zh/ja/features/agent/model-selector)。可用的模式和设置因套餐和工作区而异。

<Note>
  Economy Mode 已弃用，Power Mode 将以相同价格取代它。
</Note>

<Tip>
  **键盘快捷键：** 按 **⌘+Shift+I** (Windows 上为 Ctrl+Shift+I) ，即可在不离开聊天输入框的情况下切换 Agent 模式。
</Tip>

<div id="free-mode">
  ## Free Mode
</div>

**专为入门优化。** Free Mode 可帮助你探索想法、学习使用 Replit，以及开始项目。

**注意：** Free Mode 始终使用 Replit 的智能模型路由 Auto。若要手动选择模型，请使用 Power Mode 或 Max Mode。

<Note>
  Free Mode 适用于 Starter、Core 和 Pro 套餐。Free Mode 的限额因套餐而异；Core 和 Pro 包含每 5 小时刷新的额度。达到套餐限额后，Replit 会显示下次刷新时间。
</Note>

Routine 无法在 Free Mode 中运行。它需要在 Power 或 Max Mode 中运行，并且需要单次运行预算。有关详细信息，请参阅 [Routine](/zh/chat/routines)。

<div id="power-mode">
  ## Power Mode
</div>

**成本更优。** Power Mode 每项任务消耗的积分更少，是希望无需为最强大的模型付费也能获得出色结果时的最佳默认选择。

**最适合用于：** 日常构建、学习，以及在现有项目中开展注重成本的工作。

<div id="max-mode">
  ## Max Mode
</div>

**针对高难度任务优化。** Max Mode 使用能力更强的模型来处理复杂任务、大型代码库和更棘手的问题。

**最适合用于：** 生产级项目、复杂功能，以及希望从 Agent 获得最佳结果的场景。

<div id="section">
  ## 应该使用哪种模式？
</div>

请参考以下指南：

| 目标                     | 推荐模式                                                                 |
| ---------------------- | -------------------------------------------------------------------- |
| 探索想法、学习使用 Replit 并开始项目 | Free Mode                                                            |
| 最大化每积分可使用的提示词数量        | Power Mode                                                           |
| 在大多数项目中平衡成本与质量         | Power Mode                                                           |
| 手动选择模型                 | Power Mode 或 Max Mode                                                |
| 针对复杂的生产级任务获得最佳结果       | Max Mode                                                             |
| 针对最复杂的任务尽可能获得最佳结果      | 将 [Effort](/zh/ja/features/agent/model-selector#effort) 设为更高值的 Max Mode |

请在聊天输入框的 Agent 设置下拉菜单中选择模式。Core 和 Pro 构建者可以在 Power Mode 或 Max Mode 中设置[主模型和 Effort](/zh/ja/features/agent/model-selector)。没有一种模式始终是最佳选择。请选择适合当前任务的模式。

<div id="section-2">
  ## 共享项目设置
</div>

Agent 设置与个人账号关联，而非与项目关联。邀请团队成员加入项目后，每个人都会独立保留以下选择：

* 模式 (Free Mode、Power Mode 或 Max Mode)
* [主模型和 Effort](/zh/ja/features/agent/model-selector) (如可用)
* [Plan 模式](/zh/ja/features/agent/plan-mode)
* 自动合并后台任务
* 自动批准计划

即使团队成员在下一个任务中切换到 Max Mode，你的设置也不会随之变为 Max Mode。你发送下一条消息时，Agent 将使用 Agent 设置下拉菜单中显示的模式和设置 (无论项目中有多少协作者) 。

<div id="free-mode-2">
  ## 查看 Free Mode 额度
</div>

打开 **设置** → **用量**，即可查看剩余的 Free Mode 额度及其刷新时间。有关如何充分利用额度的实用建议，请参阅[充分利用 Free Mode](/zh/chat/free-mode)。
