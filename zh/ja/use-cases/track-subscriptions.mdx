<AiPrompt>
  请创建一个每周一 9 点运行的例程。扫描 Gmail，找出与订阅和收据相关的

<div id="section-4">
  ## 预期结果
</div>

Agent 会生成一张表格，包含商家名称、金额、账单周期和月度合计。请抽取其中几行与原始邮件进行核对。首次运行时，主题中没有“订阅”字样的商家可能会被遗漏，补充这类标签后重新运行一次即可。建议挑选三个你熟悉的商家，打开 Gmail 中的收据，核对金额和付款周期，确认无误后再采信月度合计。

</AiPrompt>

<AiPrompt>

<div id="section-6">
  ## 故障排查
</div>

* **表格中缺少你知道的订阅：** 告诉 Agent 使用哪些 Gmail 标签或搜索条件，并涵盖那些主题中不含&quot;订阅&quot;字样的商家。请挑几行对照原始邮件核对。
* **金额或付款周期看起来有误：** 收据中往往会包含税费、抵扣和不同币种。请让 Agent 直接采用邮件中列出的明细金额和账单周期，并对推测得出的行加以标记。
* **同一商家出现两次：** 请让 Agent 按商家名称合并，保留最新的收据，然后重新计算月度合计。
