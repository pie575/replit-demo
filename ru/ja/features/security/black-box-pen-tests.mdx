Тестирование на проникновение методом «чёрного ящика» проверяет работающее приложение снаружи — через взаимодействие с браузером и сетью. Исходный код приложения при этом не используется.

В центре безопасности проекта **Level 3 (AI pentest)** выполняет сразу три вида проверок безопасности:

1. Бесплатную проверку зависимостей и пакетов
2. Статический анализ исходного кода с помощью Agent
3. Тестирование методом «чёрного ящика», при котором работающий Preview проверяется снаружи, без доступа к исходному коду

После запуска Level 3 Replit параллельно выполняет проверку исходного кода с помощью Agent и внешнее тестирование методом «чёрного ящика».

<div id="level-3">
  ## Запуск сканирования Level 3
</div>

<Steps>
  <Step title="Откройте проект">
    Откройте проект, который хотите просканировать.
  </Step>

  <Step title="Откройте Security Center">
    На панели **Tools** проекта выберите **Security Center**.
  </Step>

  <Step title="Запустите сканирование">
    В верхней части Security Center выберите **Run scan**.
  </Step>

  <Step title="Выберите Level 3">
    **Level 3 (AI pentest)**.

    <Frame caption="Level 3 (AI pentest) дополняет бесплатные проверки зависимостей и пакетов статическим анализом Agent и внешним тестированием работающего Preview.">
      <img src="/assets/mirror/level-3-ai-pentest-c223c0099d3f.png" alt="В Security and Privacy Center, открытом с панели Tools, раскрыто меню выбора уровня сканирования, в котором выбран Level 3 AI pentest" width="2204" height="1200" data-path="images/project-security-center/level-3-ai-pentest.png" />
    </Frame>
  </Step>

  <Step title="Дождитесь завершения обеих задач">
    Дождитесь завершения проверки исходного кода, а также тестирования браузера и сети методом «чёрного ящика».
  </Step>

  <Step title="Просмотрите результаты">
    На панели **Security** просмотрите результаты обеих задач. Оцените каждый результат, прежде чем отправлять одобренные проблемы Agent.
  </Step>

  <Step title="Исправьте проблемы и запустите повторно">
    Отправьте одобренные результаты Agent. После внесения исправлений запустите ещё одно сканирование Level 3, чтобы убедиться, что проблемы устранены.
  </Step>
</Steps>

<div id="2">
  ## Две задачи: в чём разница
</div>

| Задача                       | На чём основана                                              | Цель                                                                      |
| ---------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------------------- |
| Проверка исходного кода      | Исходный код приложения                                      | Выявить уязвимости безопасности, приватности и архитектуры в кодовой базе |
| Тестирование «чёрного ящика» | Взаимодействие с работающим приложением через браузер и сеть | Проверить наблюдаемое извне поведение без доступа к исходному коду        |

Изучайте результаты обеих проверок: ни одна из них не заменяет другую. Проверка исходного кода выявляет уязвимые детали реализации, а тестирование «чёрного ящика» оценивает работающее приложение снаружи.
