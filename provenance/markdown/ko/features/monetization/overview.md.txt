# 수익화

> Agent 기반 연동으로 Replit 앱에 결제 및 구독을 추가하세요.

앱을 비즈니스로 전환하세요. Replit은 결제 프로바이더와 연동되어 결제를 수락하고, 구독을 판매하고, 웹 및 모바일 앱을 수익화할 수 있습니다.

## 작동 방식

Agent에게 무엇에 대해 요금을 청구할지 알려주면 나머지를 처리합니다: 결제 프로바이더 연결, 결제 또는 페이월 UI 빌드, 결제 로직 연결. 라이브로 전환하기 전에 모든 것을 안전하게 테스트할 수 있습니다.

Replit은 웹 및 네이티브 모바일 앱에 걸쳐 여러 수익화 연동을 지원합니다:

* **[Whop 결제](/ko/features/monetization/whop-payments)** (웹 앱): 가장 적은 단계로 디지털 제품, 멤버십, 구독을 판매하세요. Agent가 Whop 계정을 생성해 드립니다—외부 설정이나 API 키 없이—첫 판매를 빠르게 시작할 수 있습니다.
* **[Stripe 결제](/ko/features/monetization/stripe-payments)** (웹 앱): 일회성 결제를 수락하거나, 구독을 판매하거나, 풀 스토어프론트를 빌드하세요. Agent가 Stripe 샌드박스를 연결하여 라이브 전환 전에 결제 흐름을 테스트할 수 있도록 합니다.
* **[RevenueCat 구독](/ko/features/monetization/revenuecat-subscriptions)** (모바일 앱): 네이티브 모바일 앱에 인앱 구독을 추가하세요. Agent가 RevenueCat을 설정하고, 페이월 화면을 빌드하고, 개발 중 구매가 시뮬레이션되도록 테스트 모드를 구성합니다.

실물 상품을 재고 및 배송과 함께 판매하려면 [Shopify 연동](/ko/features/integrations/shopify)을 참조하세요.

## 적합한 연동 선택하기

|            | Whop                   | Stripe                | Shopify                | RevenueCat                          |
| ---------- | :--------------------- | :-------------------- | :--------------------- | :---------------------------------- |
| **최적 용도**  | 가장 적은 단계, 첫 판매까지 가장 빠름 | 웹에서의 유연성 및 확장성        | 실물 상품                  | 네이티브 모바일 앱                          |
| **결제 유형**  | 디지털 제품, 멤버십, 구독        | 일회성 결제, 구독, 스토어프론트    | 재고 및 배송이 포함된 실물 제품     | 인앱 구독                               |
| **외부 설정**  | 시작 시 없음                | 시작 시 없음 (Stripe 샌드박스) | 시작 시 없음                | 시작 시 없음 (테스트 모드)                    |
| **라이브 전환** | 출금을 위해 본인 확인(KYC)      | 라이브 Stripe 계정 연결      | Shopify 스토어 청구         | 검토를 위해 App Store 또는 Google Play에 제출 |
| **필요한 계정** | Whop 계정 (자동 생성)        | Stripe 계정             | Shopify 스토어 (자동 프로비저닝) | RevenueCat 계정                       |

## 시작하기

가장 빠르게 시작하는 방법은 Agent에게 요청하는 것입니다:

* **디지털 제품 빠르게 판매**: "멤버십 판매를 위해 Whop 결제 추가" — [Whop 결제](/ko/features/monetization/whop-payments) 참조
* **웹 앱**: "내 앱에 Stripe 결제 추가" — [Stripe 결제](/ko/features/monetization/stripe-payments) 참조
* **모바일 앱**: "내 앱에 월 \$5.99 구독 추가" — [RevenueCat 구독](/ko/features/monetization/revenuecat-subscriptions) 참조

Agent가 연동을 연결하고, UI를 빌드하고, 즉시 사용해 볼 수 있도록 테스트 환경을 설정합니다.
