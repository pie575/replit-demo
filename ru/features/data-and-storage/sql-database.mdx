Replit Database — это полностью управляемая SQL-база данных, которая позволяет добавить постоянное хранилище данных в ваш Replit App прямо из Project Editor.

<Note>
  Быстрее всего начать, попросив **Agent** добавить базу данных в ваше приложение. Agent настроит интеграцию, создаст схему базы данных и обновит приложение так, чтобы оно сохраняло и получало данные.
</Note>

<div id="features">
  ## Возможности
</div>

Инструмент Replit Database предоставляет следующие возможности:

* **Инструменты для работы с базой данных**: выполняйте запросы, управляйте схемой базы данных и визуализируйте данные с помощью встроенных SQL-инструментов
* **Путешествие во времени**: восстанавливайте базу данных до состояния на любом checkpoint **Agent**. См. [Восстановление данных](/ru/features/data-and-storage/data-recovery)
* **Бесплатное хранилище**: 20 ГБ бесплатного хранилища для каждого Replit App.
* **Переменные окружения**: используйте переменные окружения в своём Replit App для безопасного доступа к базе данных

<Info>
  До 4 декабря 2025 года база данных для разработки размещалась на Neon, поэтому у неё есть несколько важных отличий.
  Подробнее см. в разделе [Разработка и продакшен](/ru/features/data-and-storage/development-and-production#legacy-development-database).
</Info>

<div id="usage">
  ## Использование
</div>

<YouTubeEmbed videoId="zbyRuoPNIc8" title="Как использовать базы данных в Replit" />

Инструмент Replit Database доступен прямо в Project Editor.
В следующих разделах описано, как настроить базу данных и управлять ею.

<Accordion title="Как открыть инструмент Database">
  1. Откройте панель **Tools** и выберите **Database** в разделе **Replit Cloud**.
  2. На стартовом экране перечислены ваши базы данных. Выберите нужную, например **Development Database**, чтобы открыть её.
</Accordion>

Работа с инструментом Database строится вокруг списка ваших баз данных. На стартовом экране показана каждая база данных с объёмом занятого хранилища, а также текущий **Billing Period** и **Hours of Compute Used**. При открытии базы данных доступны три вкладки:

* **Overview** — таблицы вашей базы данных.
* **My Data** — просмотр и редактирование строк, а также выполнение SQL-запросов.
* **Settings** — строка подключения, использование хранилища и параметры подключения.

<div id="add-a-database">
  ### Добавление базы данных
</div>

Все Replit Apps по умолчанию поставляются с базой данных. Чтобы открыть её, выберите инструмент <img class="icon-svg" src="/assets/mirror/postgres-c4cb2a1e2de3.svg" alt="PostgresSQL database icon" width="24" height="24" data-path="images/icons/postgres.svg" /> **Database** в Project Editor.

Чтобы интегрировать базу данных с вашим Replit App, попросите **Agent** добавить в него базу данных PostgreSQL и укажите, какие данные приложение должно хранить. Agent создаст схему базы данных
и обновит приложение для работы с ней.

<div id="security-features">
  ### Функции безопасности
</div>

Когда вы добавляете интеграцию с базой данных с помощью **Agent**, он добавляет объектно-реляционный преобразователь (ORM),
который обрабатывает все обращения к базе данных и имеет встроенные механизмы защиты.

Слой ORM в сочетании с рекомендуемыми практиками безопасности, которые применяет Agent, защищает ваше приложение от
эксплойтов благодаря следующим возможностям:

* **Проверка схемы**: подтверждает, что данные соответствуют ожидаемым форматам
* **Очистка данных**: автоматически очищает вводимые данные, чтобы предотвратить SQL-инъекции
