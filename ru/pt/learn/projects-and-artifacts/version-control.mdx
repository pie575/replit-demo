Контроль версий в Replit позволяет уверенно отслеживать изменения, управлять кодом и работать над ним совместно с другими. Благодаря встроенной интеграции с Git и подключению к GitHub вы можете:

* Отслеживать изменения в коде и сохранять историю разработки
* Работать с участниками команды без конфликтов в коде и потери результатов работы
* Импортировать, изменять и отправлять код между Replit и GitHub
* Работать с ветками, чтобы безопасно экспериментировать с новыми функциями

<div id="o-que-controle-de-verso">
  ## Что такое контроль версий?
</div>

Контроль версий — это система, которая отслеживает изменения в файлах с течением времени, позволяя при необходимости восстановить конкретные версии. В Replit контроль версий основан на Git — отраслевом стандарте для отслеживания изменений в коде — и имеет удобный визуальный интерфейс, избавляющий от необходимости работать с командной строкой.

<div id="como-o-controle-de-verso-funciona-no-replit">
  ### Как работает контроль версий в Replit
</div>

Все четыре варианта контроля версий работают с одним и тем же базовым репозиторием Git:

1. **Контрольные точки Agent** автоматически создают коммиты на важных этапах разработки с помощью [Replit Agent](/ru/pt/features/agent/overview). [Подробнее о контрольных точках и откатах](/ru/pt/features/version-control/checkpoints-and-rollbacks).
2. **Панель Git** предоставляет визуальный доступ ко всему репозиторию Git
3. **Git CLI** предоставляет доступ ко всем возможностям Git через командную строку
4. **История файлов** отслеживает детальные изменения в отдельных файлах

Выберите интерфейс, который лучше всего отвечает вашим потребностям: все изменения надёжно поддерживаются системой контроля версий Git.

| Возможность                | Контрольные точки Agent         | Коммиты Git                         | История файлов                     |
| -------------------------- | ------------------------------- | ----------------------------------- | ---------------------------------- |
| **Создание**               | Автоматически в ключевых точках | Вручную или по расписанию           | Автоматически                      |
| **Детализация**            | Изменения на уровне функций     | Изменения любого масштаба           | Изменения на уровне символов       |
| **Описание**               | Сводки, созданные ИИ            | Сообщения, написанные пользователем | Автоматические временные метки     |
| **Откат**                  | Восстановление одним щелчком    | Требует знания Git                  | Восстановление одним щелчком       |
| **Возможности Git**        | Полный набор возможностей Git   | Полный набор возможностей Git       | Возможности Git отсутствуют        |
| **Синхронизация с GitHub** | Полная синхронизация с GitHub   | Полная синхронизация с GitHub       | Синхронизация с GitHub отсутствует |

<div id="primeiros-passos">
  ## Начало работы
</div>

Чтобы использовать контроль версий в Replit App, добавьте инструмент Git в редактор проекта:

1. Перейдите в раздел «Инструменты» в Replit App
2. Нажмите значок **+**, чтобы добавить новый инструмент
3. Выберите **Git** в списке доступных инструментов

Чтобы импортировать существующие проекты из GitHub, ознакомьтесь с разделом [Импорт из GitHub](/ru/pt/build/import-from-providers).

<div id="controle-de-verso-automtico">
  ### Автоматический контроль версий
</div>

<Accordion title="Контрольные точки Agent">
  Автоматические снимки, создаваемые во время разработки с помощью ИИ в [Replit Agent](/ru/pt/features/agent/overview).

  **Лучше всего подходит для**: Разработки с Replit Agent

  **Основные возможности**:

  * Автоматическое создание на ключевых этапах
  * Откат в один клик
  * Снимки на уровне функций
  * Отслеживание прогресса
  * Не требует настройки
  * Визуальная временная шкала разработки

  Контрольные точки Agent хранятся в Git и доступны через панель Git или Git CLI. Вы также можете просматривать все свои контрольные точки в разделе «История», где доступны:

  * Хронологическое отображение контрольных точек
  * Подробные описания контрольных точек
  * Прямой доступ к состояниям контрольных точек
  * Откат к любой контрольной точке в один клик
</Accordion>

<Accordion title="История файлов">
  Отслеживание версий отдельных файлов с автоматическим сохранением изменений, внесённых непосредственно в редакторе без помощи Agent.

  **Лучше всего подходит для**: Быстрого восстановления недавних изменений в файлах

  **Основные возможности**:

  * Работа с одним файлом
  * Изменения на уровне символов
  * Визуальное сравнение
  * История за 30 дней
  * Функция воспроизведения

  Хотя «История файлов» имеет собственный интерфейс, внесённые изменения также входят в историю Git. Подробнее об [Истории файлов](/ru/pt/features/version-control/file-history).
</Accordion>

<div id="interfaces-baseadas-em-git">
  ### Интерфейсы на базе Git
</div>

<Accordion title="Панель Git">
  Визуальный интерфейс для работы с Git, который делает контроль версий доступным без знания командной строки.

  **Подходит для**: большинства проектов, которым нужна интеграция с GitHub и визуальный рабочий процесс

  **Основные возможности**:

  * Отслеживание изменений во всём репозитории
  * Управление ветками
  * Просмотр различий
  * Синхронизация с GitHub в один клик
  * Командная работа

  Подробные инструкции по использованию панели Git см. в разделе [Использование панели Git](/ru/pt/features/workspace-tools/git-interface).
</Accordion>

<Accordion title="Git CLI">
  Полный доступ к Git через командную строку в [Shell](/ru/pt/features/workspace-tools/shell) для выполнения расширенных операций.

  **Подходит для**: опытных пользователей, которым нужны все возможности Git

  **Основные возможности**:

  * Полный набор команд Git
  * Расширенные стратегии ветвления
  * Настраиваемые рабочие процессы
  * Автоматизация с помощью скриптов
  * Полный контроль над репозиторием

  Список распространённых команд Git и инструкции по их использованию см. в разделе [Использование панели Git](/ru/pt/features/workspace-tools/git-interface#using-git-commands-in-shell).
</Accordion>

<div id="recursos-principais">
  ## Основные возможности
</div>

* **Визуальный интерфейс Git**: Управляйте репозиториями, коммитами и ветками без ввода команд Git
* **Интеграция с GitHub**: Подключайте репозитории GitHub для резервного копирования и совместной работы
* **Импорт из GitHub**: Превратите любой [репозиторий GitHub в Replit App](/ru/pt/build/import-from-providers) всего за несколько кликов
* **Управление ветками**: Создавайте, переключайтесь между ветками и объединяйте их прямо в редакторе проекта
* **Разрешение конфликтов**: Находите и устраняйте конфликты слияния с помощью визуальных инструментов

<div id="casos-de-uso">
  ## Варианты использования
</div>

**Отслеживание личных проектов**

Отслеживайте изменения в коде по мере работы, чтобы при необходимости возвращаться к предыдущим версиям. [Панель Git](/ru/pt/features/workspace-tools/git-interface) наглядно показывает изменения, упрощая создание коммитов с важными обновлениями.

**Совместная работа в команде**

Работайте над одним кодом с несколькими разработчиками, не перезаписывая изменения друг друга. Создавайте ветки для новых функций, а затем объединяйте их, когда они будут готовы. Подробнее о [приглашении коллег](/ru/pt/build/invite-teammates).

<div id="checkpoints-do-agent">
  ## Контрольные точки Agent
</div>

При создании приложений с [Replit Agent](/ru/pt/features/agent/overview) контрольные точки обеспечивают дополнительный уровень контроля версий. Они автоматически сохраняют полное состояние проекта — включая его содержимое, контекст диалога с ИИ и подключённые базы данных — в ключевые моменты разработки с ИИ.

<div id="como-os-checkpoints-funcionam">
  ### Как работают контрольные точки
</div>

Контрольные точки Agent — это комплексные снимки всего состояния вашего Replit App:

* **Автоматическое создание**: Agent создаёт контрольные точки в логические моменты разработки
* **Сохранение полного состояния**: Каждая контрольная точка сохраняет содержимое проекта, память ИИ и состояния базы данных
* **Планы реализации**: Перед внесением изменений Agent предлагает вам ознакомиться с планом
* **Отслеживание сложных задач**: Для более масштабных задач может быть создано несколько контрольных точек

<div id="benefcios-para-o-desenvolvimento-assistido-por-ia">
  ### Преимущества разработки с ИИ
</div>

Контрольные точки Agent предоставляют уникальные преимущества при разработке с ИИ:

* **Подстраховка**: Экспериментируйте уверенно, зная, что сможете легко восстановить предыдущее состояние всей среды разработки
* **Отслеживание прогресса**: Проследите, как Agent шаг за шагом создавал ваше приложение
* **Логические этапы**: Контрольные точки соответствуют завершённым функциям, а не произвольным точкам сохранения
* **Мгновенный откат**: Вернитесь к любому предыдущему состоянию одним щелчком, включая восстановление базы данных и контекста ИИ

<Info>
  Подробные сведения о том, что сохраняют контрольные точки, и обо всех возможностях отката см. в разделе [Контрольные точки и откаты](/ru/pt/features/version-control/checkpoints-and-rollbacks).
</Info>

<Tip>
  Хотя контрольные точки Agent удобны для разработки с ИИ, для долгосрочного контроля версий и совместной работы рекомендуется использовать коммиты Git, особенно при работе с внешними репозиториями.
</Tip>
