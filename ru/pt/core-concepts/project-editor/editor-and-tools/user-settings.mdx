Инструмент «Пользовательские настройки» в Редакторе проектов позволяет настроить внешний вид, поведение и сочетания клавиш для вашей учётной записи.

  <img src="/assets/mirror/user-settings-tool-faae3afb911b.png" alt="снимок экрана инструмента «Пользовательские настройки»" width="4152" height="1894" data-path="images/workspace/user-settings-tool.png" />
</Frame>

<div id="funcionalidades">
  ## Функции
</div>

Вы можете настроить работу с Replit App с помощью следующих категорий настроек:

* **Настройка темы**: Выберите светлую или тёмную тему для редактора проектов
* **Интеллектуальные функции для кода**: Настройте функции ИИ, которые улучшают процесс разработки приложений
* **Настройки редактора**: Настройте поведение и отображение редактора файлов
* **Управление уведомлениями**: Настройте параметры оповещений
* **Параметры доступности**: Сделайте Replit удобнее для пользователей с особыми потребностями
* **Сочетания клавиш**: Настройте комбинации клавиш для выполнения распространённых действий и навигации по интерфейсу

<div id="uso">
  ## Использование
</div>

<Accordion title="Как открыть пользовательские настройки">
  На **панели инструментов** слева:

  1. Нажмите <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Иконка всех инструментов" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **Все инструменты**, чтобы открыть список инструментов Редактора проектов.
  2. Нажмите <img class="icon-svg" src="/assets/mirror/settings-icon-c2664c3691bf.svg" alt="Иконка настроек" width="16" height="16" data-path="images/icons/settings-icon.svg" /> **Пользовательские настройки**.

  В **строке поиска**:

  1. Нажмите <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="иконка лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> значок лупы вверху, чтобы открыть поиск.
  2. Введите &quot;User Settings&quot;, найдите инструмент и выберите его в результатах поиска.
</Accordion>

<div id="aparncia">
  ### Внешний вид
</div>

Настройте следующие параметры внешнего вида редактора проектов:

* **Выбор темы**: выберите предустановленную светлую или тёмную тему, <a href="https://replit.com/themes" target="_blank">тему сообщества</a> либо собственную тему
* **Пользовательские темы**: создавайте собственные цветовые схемы с помощью редактора [тем](/ru/pt/core-concepts/project-editor/editor-and-tools/themes)

<div id="preferncias-do-editor-de-arquivos">
  ### Настройки редактора файлов
</div>

Настройте внешний вид и поведение редактора файлов с помощью следующих параметров:

* **Размер шрифта**: Настройте размер текста для удобства чтения
* **Автоматическое закрытие скобок**: Автоматически вставляет закрывающую скобку при вводе открывающей
* **Определение отступов**: Автоматически определяет настройки отступов при открытии файла
* **Форматирование отступов вставленного текста**: Переформатирует вставленный код с правильными отступами
* **Символ отступа**: Выберите пробелы или табуляции для отступов в коде
* **Размер отступа**: Укажите количество столбцов для каждого уровня отступа
* **Перенос строк**: Настройте параметры переноса строк
* **Мини-карта**: Добавьте на боковую панель навигационный обзор кода
* **Клавиша-модификатор для множественного выбора**: Укажите клавишу-модификатор для выбора нескольких файлов
* **Статус Git в дереве файлов**: Отображает индикаторы статуса Git в дереве файлов

<div id="inteligncia-de-cdigo">
  ### Интеллектуальные функции для кода
</div>

Настройте инструменты ИИ с помощью следующих параметров:

* **Семантические токены**: Используйте подсветку синтаксиса, улучшенную языковыми серверами
* **Автодополнение кода с ИИ**: Получайте встроенные подсказки кода по мере ввода
* **Принимать подсказку при вводе символа подтверждения**: Автоматически принимайте подсказки кода при вводе определённых символов

<div id="preferncias-de-shell-e-preview">
  ### Настройки Shell и Preview
</div>

Настройте поведение Shell и Preview:

* **Звуковое уведомление Shell**: Воспроизводит звук при обнаружении проблем в Shell
* **Автоматический Preview**: Автоматически открывает вкладку Preview, когда сервер становится доступен
* **Автоматически перенаправлять открытые порты**: Настраивает обработку вновь обнаруженных портов

<div id="notificaes">
  ### Уведомления
</div>

Настройте следующие уведомления:

* **Звуковое уведомление Agent**: Воспроизводит звук, когда Agent запрашивает обратную связь
* **Push-уведомление Agent**: Получайте push-уведомления на телефон, когда Agent запрашивает обратную связь

<div id="acessibilidade">
  ### Специальные возможности
</div>

Вы можете настроить следующий параметр специальных возможностей:

* **Доступный вывод терминала**: Включает поддержку программ экранного доступа для Shell и Console

<div id="atalhos-de-teclado">
  ### Сочетания клавиш
</div>

Чтобы открыть настройки сочетаний клавиш, выберите вкладку **Сочетания клавиш** в разделе «Пользовательские настройки».

Искать сочетания клавиш можно следующими способами:

* **Название**: введите название или описание сочетания клавиш в поле поиска.
* **Сочетание клавиш**: выберите <img class="icon-svg" src="/assets/mirror/keyboard-7ba19771b671.svg" alt="иконка клавиатуры" width="16" height="16" data-path="images/icons/keyboard.svg" /> и введите сочетание клавиш.

Для управления сочетаниями клавиш используйте следующие действия:

* **Добавить**: выберите **Добавить сочетание клавиш**.
* **Обновить**: выберите иконку <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="иконка карандаша" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> карандаша.
* **Удалить**: выберите иконку <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="иконка корзины" width="16" height="16" data-path="images/icons/trash-icon.svg" /> корзины.
