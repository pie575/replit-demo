<div id="ssh">
  ## 什么是 SSH？
</div>

SSH (Secure Shell) 是一种安全协议，可让你远程访问 Replit 应用的命令行界面。使用 SSH，你可以轻松传输文件，并通过自己偏好的本地集成开发环境 (IDE) 在 Replit 中编辑代码，从而提升开发工作流中的协作效率和生产力。

SSH 功能适用于 Core、Pro 及其他所有付费套餐。

流程概述如下：

* 在本地计算机上生成 SSH 密钥对
* 将 SSH 密钥添加到所需 Replit 应用的 **SSH** 窗口中
* 使用 SSH 客户端，或支持通过 SSH 连接的编辑器 (例如 [VSCode](https://code.visualstudio.com/) 或 [Cursor](https://www.cursor.com/)) 进行连接

<Note>
  SSH 密钥关联到你的账户，而非特定的 Replit 应用。这意味着你只需添加一次公钥，即可连接到你有访问权限的所有 Replit 应用。
</Note>

<div id="ssh-2">
  ## 为什么要使用 SSH
</div>

* **Replit 应用与编辑器自动同步更新**：在 Replit 应用中所做的任何更改都会立即同步到编辑器，编辑器中的所有修改也会同步到 Replit 应用。这种无缝同步可确保整个代码库始终保持最新状态。

* **文件管理同步**：无论是添加、删除还是更新文件，这些更改都会在编辑器与 Replit 应用之间实时同步。无论从何处发起更改，项目结构都能保持一致。

* **文件夹管理和文件移动**：在文件夹之间移动文件也会在编辑器与 Replit 应用之间同步。这样可确保在一个环境中进行的结构性更改准确反映到另一个环境中，从而维护项目的完整性和结构。

<div id="section">
  ## 查找或创建密钥对
</div>

要为你的账户配置 SSH，需要 SSH 公钥。

<div id="section-2">
  ### 检查是否已有密钥对
</div>

在本地计算机的终端中运行以下命令，检查是否已有公钥：

<Tabs>
  <Tab title="Mac/Linux">
    ```sh theme={null}
    ls -l ~/.ssh
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    dir %HOMEPATH%\.ssh
    ```
  </Tab>
</Tabs>

即使出现错误也没关系。请继续[生成新的密钥对](#generating-a-new-keypair)。
如果看到名为 `replit.pub` 的文件，请继续[获取公钥内容](#get-the-contents-of-your-public-key)。

<div id="section-3">
  ### 生成新的密钥对
</div>

在计算机上打开终端 (或命令提示符) 窗口，然后粘贴以下命令：

<Tabs>
  <Tab title="Mac/Linux">
    ```bash theme={null}
    ssh-keygen -t ed25519 -f ~/.ssh/replit -q -N ""
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    ssh-keygen -t ed25519 -f %HOMEPATH%\.ssh\replit -q -N ""
    ```
  </Tab>
</Tabs>

此命令会检查指定的 SSH 公钥文件是否已存在。如果不存在，则会使用适当的参数生成新的 SSH 密钥。

<div id="section-4">
  ### 获取公钥内容
</div>

确认密钥对已存在或新建密钥对后，查看公钥文件的内容 (名称相似的两个文件中，以 `.pub` 结尾的那个) ，后续步骤会用到它。

<Tabs>
  <Tab title="Mac/Linux">
    ```sh theme={null}
    cat ~/.ssh/replit.pub
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    notepad %HOMEPATH%\.ssh\replit.pub
    ```
  </Tab>
</Tabs>

保存 `replit.pub` 的内容以供本文档后续使用，然后继续[将 SSH 密钥添加到你的账户](#add-the-ssh-key-to-your-account)。

<div id="ssh-3">
  ## 向帐户添加 SSH 密钥
</div>

<div id="ssh-replit">
  ### 通过 SSH 窗口直接向 Replit 应用添加公钥
</div>

1. 在任意 Replit 应用窗口中，选择 **+** 按钮，然后搜索 **SSH**。

<Frame>
  <img src="/assets/mirror/ssh-tool-2db02c6a83d0.png" alt="Replit 界面中的 SSH 工具按钮" width="846" height="328" data-path="images/ssh-vscode/ssh-tool.png" />
</Frame>

2. 转到 **Keys** 选项卡，然后选择 **New SSH key**。
3. 在弹出窗口中，输入密钥的 **Label** (例如 my-ssh-key) ，然后将复制的公钥粘贴到 **Key** 字段中。
   选择 **Add SSH Key** 按钮。密钥随即添加并授权使用。

<Frame>
  <img src="/assets/mirror/add-ssh-key-with-values-5d6f440e56ba.png" alt="已填写标签和密钥字段的添加 SSH 密钥对话框" width="500" height="511" data-path="images/ssh-vscode/add-ssh-key-with-values.png" />
</Frame>

<div id="section-5">
  ### 直接在设置中添加公钥
</div>

您也可以打开**设置**，在**账户**下选择**高级** (或 **SSH 密钥**选项) 来添加 SSH 密钥。选择**添加 SSH 密钥**，然后粘贴上一节[查找或创建密钥对](#find-or-create-a-keypair)中获取的 `replit.pub` 内容。

<Note>
  如果您的设备上有多个公钥，请务必确保 SSH 配置使用正确的私钥和公钥组合。
</Note>

<div id="replit">
  ## 连接 Replit 应用
</div>

<div id="ssh-4">
  ### 配置 SSH
</div>

1. 在终端中确认 `~/.ssh` 目录和 `~/.ssh/config` 文件是否存在：

<Tabs>
  <Tab title="Mac/Linux">
    ```sh theme={null}
    mkdir -p ~/.ssh && chmod 700 ~/.ssh && touch ~/.ssh/config && chmod 600 ~/.ssh/config
    open -a 'TextEdit' ~/.ssh/config || nano ~/.ssh/config
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    if not exist %HOMEPATH%\.ssh mkdir %HOMEPATH%\.ssh && type \NUL > %HOMEPATH%\.ssh\config
    notepad %HOMEPATH%\.ssh\config
    ```
  </Tab>
</Tabs>

2. 添加以下配置块，为所有 `*.replit.dev` 域名使用 `replit` 密钥对：

<Tabs>
  <Tab title="Mac/Linux/Windows">
    ```
    Host *.replit.dev
        Port 22
        IdentityFile ~/.ssh/replit
        StrictHostKeyChecking accept-new
    ```
  </Tab>
</Tabs>

<div id="vscode-cursor">
  ### 在 VSCode 或 Cursor 中连接
</div>

1. 在 Replit 应用中打开 **SSH** 窗口。

2. 在 SSH 窗口中，转到 **Connect** 标签页并选择 **Launch VS Code**。

<Tabs>
  <Tab title="连接到 VSCode">
    <img src="/assets/mirror/ssh-connect-439a3c150846.png" alt="显示 Launch VS Code 选项的 SSH Connect 标签页" width="788" height="482" data-path="images/ssh-vscode/ssh-connect.png" />
  </Tab>
</Tabs>

3. 系统提示你创建 `~/.ssh/config` 时，输入以下内容：

   ```
   Host *.replit.dev
       Port 22
       IdentityFile ~/.ssh/replit
       StrictHostKeyChecking accept-new
   ```

   <Note>
     仅在你首次尝试连接到 VS Code 或其他编辑器时，才会显示添加 SSH 配置的提示。若要返回配置文件，请选择 &#42;&#42;Configure SSH Hosts...&#42;&#42;。
   </Note>

4. 出现外部应用警告时，选择 **Yes**，确认要在你首选的编辑器或 VS Code 中打开项目。

5. 系统可能会定期提示你安装或更新 SSH 扩展。Replit 会努力兼容这些 IDE 的最新版本，以便你也能获得重要的安全更新。

  ### 手动连接
</div>

复制该命令并粘贴到本地终端 (Mac 或 Linux) 或本地命令提示符 (Windows) 中，即可直接连接。

<div id="section-7">
  ### 连接未在此列出的工具
</div>

不同的平台和操作系统可使用多种 SSH 客户端，许多客户端还提供各不相同的功能或集成。

您可以随时将“Connect Manually”中显示的命令拆解为各个组成部分，从而了解如何配置每个客户端：

```sh theme={null}
ssh -i ~/.ssh/replit -p 22  c96b6ade-d5e4-4f7a-bc5b-52334509b2a3@c96b6ade-d5e4-4f7a-bc5b-52334509b2a3-00-16nh2hskw3ql8.riker.replit.dev
       ^-----v-----^    ^^  ^-----------------v----------------^ ^------------------------------v-------------------------------------^
        私钥          端口                   用户               @                           主机名
```

**主机名**: `<your_hostname>.<cluster>.replit.dev`
**端口**: `<port_number>`
**用户**: `Username`
**私钥**: 计算机上私钥文件的路径，通常位于 `replit.pub` 旁边。
