Preview 会显示 Web 应用的输出，并提供浏览器开发者工具和
调试功能。

当您使用**运行**按钮启动 Web 应用时，Replit 会为其分配一个可通过互联网访问的临时 URL。
Preview 会像在浏览器中一样渲染页面。
它还包含与主流浏览器中类似的开发者工具。

<Note>
  Preview 是 Webview 的新名称。
</Note>

</Frame>

<div id="recursos">
  ## 功能
</div>

Preview 提供以下功能，帮助您顺畅地测试和调试 Web App：

* **实时网页预览**：无需离开浏览器标签页，即可查看并与您的 App 交互
* **开发者工具**：使用内置工具快速诊断问题
* **响应式测试**：以不同的移动设备屏幕尺寸查看您的 App

<div id="uso">
  ## 使用
</div>

运行 Web 应用时，Preview 工具会自动打开。
您可以在 **用户设置** 工具的 **自动 Preview** 中更改此行为。

以下说明介绍如何打开 Preview。

<Accordion title="如何打开 Preview">
  在左侧的**工具停靠栏**中：

  1. 选择 <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="所有工具图标" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **所有工具**，查看项目编辑器的工具列表。
  2. 选择 <img class="icon-svg" src="/assets/mirror/preview-icon-6d37238e8cc2.svg" alt="Preview 图标" width="16" height="16" data-path="images/icons/preview-icon.svg" /> **Preview**。

  在**搜索栏**中：

  1. 选择顶部的 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 放大镜图标，打开搜索工具。
  2. 输入“Preview”找到该工具，然后在搜索结果中选择它。
</Accordion>

<div id="barra-de-localizao">
  ## 地址栏
</div>

**Preview** 标签页顶部的地址栏提供以下工具：

* **后退按钮**：返回浏览历史记录中的上一页
* **前进按钮**：前往浏览历史记录中的下一页
* **App 域名**：选择 `{...}.replit.dev`，查看 Replit App 临时 URL 的相关信息
* **地址字段**：查看当前 URL 路径或输入新路径

<div id="ferramentas-do-navegador">
  ## 浏览器工具
</div>

地址栏右侧的浏览器工具提供以下功能：

* **屏幕尺寸**：选择不同的屏幕尺寸预设，以测试响应式设计
* **开发者工具**：切换[开发者工具](#Developer_tools)面板
* **新标签页**：在新的浏览器标签页中打开 Web 应用的 URL

<Note>
  **正在创建移动 App？** Preview 面板还支持在 **iOS 模拟器**或 **Android 模拟器**中预览。详情请参阅[原生移动 App](/zh/pt/replitai/building-mobile-apps#preview-on-a-simulator-or-emulator)。
</Note>

<div id="ferramentas-de-desenvolvedor">
  ## 开发者工具
</div>

由开源项目 <a href="https://github.com/liriliri/eruda" target="_blank">Eruda</a> 开发的开发者工具可帮助您完成以下任务：

* 在 App 上下文中查看并与 JavaScript 控制台交互
* 检查 DOM 元素
* 监控网络请求
* 配置显示和行为偏好设置

要访问开发者工具，请在 **Preview** 标签页顶部选择 <img class="icon-svg" src="/assets/mirror/wrench-7cee9d1168da.svg" alt="扳手图标" width="16" height="16" data-path="images/icons/wrench.svg" /> **Devtools**
按钮以启用它们。

以下各节介绍您可以在开发者工具的各个标签页中执行的操作。

<div id="console">
  ### 控制台
</div>

**控制台**标签页会显示应用生成的 JavaScript 日志。
在此标签页中，您可以执行以下操作：

* **清除输出**：选择圆圈斜杠图标 <img class="icon-svg" src="/assets/mirror/clear-bd1bf1847597.svg" height="16" width="16" alt="清除图标" data-path="images/icons/clear.svg" />，清除所有控制台输出。
* **筛选输出**：按类型筛选控制台输出 (全部、信息、警告或错误) 。
* **按匹配文本筛选**：选择图标 <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="筛选器图标" data-path="images/icons/filter.svg" /> 并输入文本，以显示匹配的输出。
* **复制输出**：选择复制按钮 <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="复制图标" data-path="images/icons/copy.svg" />，复制选中的控制台消息。
* **运行 JavaScript 代码**：选择右尖括号图标 <img class="icon-svg" src="/assets/mirror/arrow-right-2859a6e6bdeb.svg" height="16" width="16" alt="向右箭头图标" data-path="images/icons/arrow-right.svg" />，即可在应用的上下文中运行 JavaScript 代码。输入表达式，然后选择 **运行**。

<div id="elements">
  ### Elements
</div>

**Elements** 选项卡可让您检查和修改网页的 DOM 结构。

* **查看元素详情**：查看 DOM 元素的详细信息及其在 HTML 代码中的位置
* **复制输出**：点击 <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="复制图标" data-path="images/icons/copy.svg" /> 复制按钮，复制选中的控制台消息。

使用 <img class="icon-svg" src="/assets/mirror/select-1165d9548c39.svg" height="16" width="16" alt="选择图标" data-path="images/icons/select.svg" /> 选择箭头切换选择模式。
进入选择模式后，在网页上选择一个元素。
该元素的 HTML 和 CSS 会显示在 Elements 选项卡中。

<div id="network">
  ### Network
</div>

**Network** 标签页会监控网页发起的请求。
在此标签页中，您可以执行以下操作：

* **跟踪请求**：查看您的 App 发起的所有网络请求。选择一个请求以查看详细信息。
* **筛选**：选择漏斗 <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="筛选器图标" data-path="images/icons/filter.svg" /> 图标，显示与输入文本匹配的结果。输入空筛选条件即可清除筛选。
* **复制**：选择复制 <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="复制图标" data-path="images/icons/copy.svg" /> 按钮，即可复制存储信息。

<div id="resources">
  ### 资源
</div>

**资源**选项卡显示页面加载的资源和浏览器存储，例如 Cookie 和本地存储。
您可以查看并刷新以下资源类型的列表：

* JavaScript 文件
* 样式表
* iframe
* 图像

在此选项卡中，您可以执行以下操作：

* **查看存储**：查看本地存储、会话存储和 Cookie。
* **筛选**：选择漏斗图标 <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="筛选器图标" data-path="images/icons/filter.svg" />，显示与输入文本匹配的结果。将筛选条件留空即可清除筛选。
* **清除**：选择清除按钮 <img class="icon-svg" src="/assets/mirror/clear-bd1bf1847597.svg" height="16" width="16" alt="清除图标" data-path="images/icons/clear.svg" />，删除该存储类型中的所有数据。
* **删除所选内容**：选择“X”图标 <img class="icon-svg" src="/assets/mirror/delete-a21eb49cac3c.svg" height="16" width="16" alt="删除图标" data-path="images/icons/delete.svg" />，移除所选存储项。
* **复制**：选择复制按钮 <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="复制图标" data-path="images/icons/copy.svg" />，复制存储信息。

<div id="settings">
  ### 设置
</div>

**设置**标签页可让您自定义开发者工具的外观和行为。
此标签页提供以下自定义选项：

* **工具设置**：自定义适用于各个工具标签页的选项
* **JavaScript 控件**：指定 JavaScript 行为选项，例如禁用 JavaScript 以测试您的 App 的表现
* **显示偏好设置**：更改开发者工具的主题、面板大小、透明度及其他行为
