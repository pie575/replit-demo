<div id="improved-filesystem-search">
  ### 文件系统搜索优化
</div>

Agent 现在可以在整个代码库中提供更智能、更符合直觉的文件搜索。借助先进的长上下文 AI，Agent 能够理解你的 project 结构和内容，从而给出更丰富的上下文和更贴切的开放式回答——让你比以往更轻松地找到所需内容。

<div id="object-storage-agent-integration">
  ### Object Storage 与 Agent 集成
</div>

借助 [Agent](/zh/core-concepts/agent) 全新的 [Object Storage](/zh/features/data-and-storage/object-storage) 能力，轻松构建文件上传功能！你的 AI 助手现在可以配置 Object Storage、检查配置项，并生成完整的前后端代码，还支持身份验证和访问控制等高级功能。

进一步了解 [Object Storage](/zh/features/data-and-storage/object-storage)，并探索所有可用的 [Agent 集成](/zh/replitai/integrations#data-storage--management)。

<div id="visual-editor-focus-improvement">
  ### Visual Editor 焦点优化
</div>

使用 [Visual Editor](/zh/learn/projects-and-artifacts/visual-editor) 时，工作节奏不再被打断！当你选中某个元素进行编辑时，焦点会自动回到 Chat 输入框，让你可以立即输入下一条 prompt。

<div id="rollback-suggestions-and-date-toggle">
  ### 回滚建议与日期切换
</div>

借助智能回滚建议和灵活的日期显示方式，更轻松地查看 project 历史记录！系统会智能推荐何时回滚代码，你还可以在相对时间和绝对时间戳之间切换，快速找到合适的 checkpoint。

<div id="live-activities-on-ios">
  ### iOS 实时活动
</div>

即使人不在电脑前，也能随时掌握 [Workspace](/zh/learn/projects-and-artifacts/project-editor) 的动态！借助 iOS 实时活动，你可以随时查看正在运行的 project，并从锁定屏幕或通知中心一键回到 Workspace。

<div id="replit-app-to-organization-transfer">
  ### 将 Replit App 转移至组织
</div>

轻松把个人项目转移给团队！使用全新的“转移至组织”操作，即可将你的个人 [Replit Apps](/zh/category/replit-apps) 无缝转移到你所属的任意组织，让现有项目的协作变得轻而易举。

<div id="mx-record-support-for-domains">
  ### 域名 MX 记录支持
</div>

轻松接入你的邮件服务商！现在你可以为[通过 Replit 购买的域名](/zh/features/publishing/custom-domains)创建 MX 记录，从而关联邮件服务商，为你的项目管理自定义邮件服务。
