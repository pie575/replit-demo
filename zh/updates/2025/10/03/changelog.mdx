<div id="vercel-import-integration">
  ### Vercel 导入集成
</div>

只需一键，即可将您的 Vercel App 迁移到 Replit！全新的导入流程可让您轻松将 Next.js 及其他托管在 Vercel 上的应用迁移到 Replit。对于正在寻找 Vercel 替代方案的开发者来说，这正是好时机。请参阅[从 Vercel 导入快速入门](/zh/build/import-from-vercel)和[导入到 Replit 指南](/zh/references/workspace/import)。

<div id="git-source-control-enhancements">
  ### Git 源代码控制改进
</div>

增强后的 Git 集成提供更出色的远程仓库管理体验和更灵活的 workspace 使用方式。借助优化后的用户体验连接和创建 Git 远程仓库，轻松在个人与组织 workspace 之间切换，并确保在 deployment 前代码始终保持最新。请参阅[使用 Git Pane](/zh/references/version-control/git-interface)了解详情。

<div id="connectors-platform-launch">
  ### 连接器平台上线
</div>

借助 24 个预构建的应用集成，更快完成开发！通过全新的 Connectors 平台，将您的 Replit 项目连接到 Stripe、Figma 等热门服务。每个 connector 均由 MCP (Model Context Protocol) 驱动，实现无缝的 AI 辅助开发。请参阅 [Agent 集成](/zh/replitai/integrations) 和 [管理您的 connector](/zh/replitai/managing-connectors)。

<div id="app-themes-font-improvements">
  ### App Themes 字体优化
</div>

新增 19 款 Google Fonts，包括 Crimson、EB Garamond、Figtree 和 Source Sans Pro 等热门字体，让你能更好地自定义应用。字体选择器现在会以各字体的实际字体样式显示，方便你直观预览设计效果。你可以按类别 (衬线体、无衬线体、等宽字体) 浏览字体，并通过实用提示了解每种字体类型。前往 [App Themes](/zh/replitai/app-themes) 了解更多。

<div id="connectors-admin-management">
  ### 连接器管理员管理
</div>

Enterprise 客户可通过基于角色的访问控制管理共享 API 密钥，并完全自定义 OAuth 客户端配置。Connectors 可由组织选择启用，让管理员能够全面控制团队成员可使用哪些集成。请参阅[管理您的 connector](/zh/replitai/managing-connectors)。
