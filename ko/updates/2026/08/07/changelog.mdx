<div id="security-scan-while-you-build">
  ### Security scan while you build
</div>

이제 Agent는 코드 리뷰 과정에서 자신이 변경한 파일에 일반적인 보안 문제가 없는지 검사합니다. 이 자동 Semgrep 검사는 위험한 패턴과 하드코딩된 secret을 찾아내므로, Agent가 task를 완료하기 전에 주요 findings를 처리할 수 있습니다.

<div id="regenerate-production-database-credentials">
  ### production database 자격 증명 재생성
</div>

이제 **Database** 도구에서 조건을 충족하는 production database의 자격 증명을 재생성할 수 있습니다. Replit이 자격 증명을 업데이트하고, 앱에 지원되는 라이브 deployment가 있는 경우 새 자격 증명을 계속 사용할 수 있도록 재배포를 시작합니다. 기존 연결 문자열을 사용하는 외부 도구가 있다면 함께 업데이트하세요.

<div id="build-with-sso">
  ### Build with SSO
</div>

이제 Pro builder는 [Clerk Auth](/ko/features/auth-and-identity/clerk-auth)를 사용하는 Replit App에 엔터프라이즈 SSO를 구성할 수 있습니다. 필요한 authentication 변경 사항을 Agent에게 요청하면 Agent가 Clerk Dashboard로 안내합니다. 여기에서 OIDC 또는 SAML을 통해 Okta나 Microsoft Entra ID를 연결하세요. Enterprise SSO connections는 2026년 10월 1일까지 무료이며, 이후에는 Clerk의 pass-through pricing이 적용됩니다. Enterprise 지원도 곧 제공될 예정입니다.

</Frame>

[Build with SSO](/ko/features/auth-and-identity/single-sign-on)에 대해 자세히 알아보세요.

<div id="move-projects-between-workspaces">
  ### workspace 간 project 이동
</div>

이제 **Projects** 목록에서 동일한 billing 계정에 속한 team workspace 간에 project를 이동할 수 있습니다. 이동 작업은 백그라운드에서 진행되며 취소할 수 없습니다. 연결된 Account Secrets는 project와 함께 이동하지 않으므로, 대상 workspace에서 다시 연결하세요.

[team workspace 간 project 이동](/ko/teams/identity-and-access-management/transfer-app-to-teams#transfer-between-team-workspaces)에 대해 자세히 알아보세요.
