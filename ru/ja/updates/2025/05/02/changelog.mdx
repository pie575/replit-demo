<div id="replit-auth">
  ### Replit Auth
</div>

[Replit Auth](/ru/ja/features/auth-and-identity/authentication) теперь доступен всем пользователям! Эта встроенная система аутентификации позволяет добавить вход для пользователей в App с минимальной настройкой. Вместо того чтобы создавать сложную систему аутентификации с нуля, используйте Replit Auth — безопасное готовое решение, интегрированное в инфраструктуру Replit.

**Основные возможности:**

* **Без настройки** — добавьте аутентификацию одним промптом для Agent
* **Встроенная безопасность** — инфраструктура Replit с защитой от распространённых атак
* **Управление пользователями** — простое управление пользователями через панель Auth
* **Интеграция с базой данных** — автоматическое создание записей пользователей в базе данных
* **Настраиваемая страница входа** — персонализируйте процесс входа в App
* **Сброс пароля** — Replit обрабатывает письма для сброса пароля, поэтому отдельный провайдер рассылки не требуется

Начать очень просто: добавьте запрос на использование Replit Auth в промпт для Agent:

<AiPrompt>
  Помогите мне создать App, которое [ваша идея App] и должно поддерживать Replit Auth.
</AiPrompt>
