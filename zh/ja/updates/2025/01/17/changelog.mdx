<div id="sendgrid">
  ### SendGrid 集成
</div>

现在，你可以使用 Agent 构建电子邮件集成，通过 SendGrid API 从新的 Agent 项目发送电子邮件。

<div id="web">
  ### 网页预览 移动端支持
</div>

我们新增了将网页预览调整为常见移动设备屏幕尺寸的功能。我们还在 URL 下拉菜单和网络面板中添加了二维码，方便您在移动设备上进行测试。

此外，项目在构建过程中也可通过互联网访问。请尝试使用任意设备访问开发 URL。

<div id="dns">
  ### DNS 记录格式更新
</div>

我们已将自定义域名的 DNS 记录格式调整为符合行业标准的格式。

这样可以更轻松地配置自定义域名。

  <img src="/assets/mirror/dns-record-format-878840a5ecfe.png" alt="DNS 记录格式" width="1228" height="1156" data-path="images/changelog/2025-01-17/dns-record-format.png" />

<div id="flask">
  ### Flask 部署升级
</div>

Gunicorn 现已成为 Flask 技术栈部署的默认 Web 服务器。

与之前的 Flask 部署相比，性能提升了 40 倍。

<div id="assistant">
  ### Assistant 内联 Shell 命令
</div>

Assistant 现在可以直接在聊天面板中执行 Shell 命令。无需离开聊天即可运行命令，节省时间！
