Preview показывает результат работы вашего веб-приложения и предоставляет браузерные инструменты
разработчика и возможности отладки.

Когда вы запускаете веб-приложение кнопкой **Run**, Replit присваивает ему временный URL,
доступный в интернете. Инструмент Preview отображает страницу так же, как вы
увидели бы её в браузере. Он также включает инструменты разработчика, по функциональности
близкие к тем, что есть в популярных браузерах.

<Note>
  Preview — это новое название Webview.
</Note>

<div id="features">
  ## Возможности
</div>

Preview включает следующие функции, которые позволяют удобно тестировать и отлаживать веб-приложения:

* **Живой просмотр в браузере**: просматривайте приложение и взаимодействуйте с ним, не покидая вкладку браузера
* **Инструменты разработчика**: используйте встроенные инструменты для быстрой диагностики проблем
* **Тестирование адаптивности**: проверяйте приложение при разных размерах экранов мобильных устройств

<div id="usage">
  ## Использование
</div>

Инструмент Preview открывается автоматически при запуске веб-приложения.
Это поведение можно изменить в инструменте **User Settings** с помощью настройки **Automatic Preview**.

Ниже описано, как открыть Preview.

<Accordion title="Как открыть Preview">
  На левой **панели инструментов (Tool dock)**:

  1. Выберите <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Значок «Все инструменты»" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**, чтобы открыть список инструментов Project Editor.
  2. Выберите <img class="icon-svg" src="/assets/mirror/preview-icon-6d37238e8cc2.svg" alt="Значок Preview" width="16" height="16" data-path="images/icons/preview-icon.svg" /> **Preview**.

  Через **строку поиска**:

  1. Нажмите на значок <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="значок лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> лупы вверху, чтобы открыть инструмент поиска
  2. Введите «Preview», чтобы найти инструмент, и выберите его в результатах.
</Accordion>

<div id="location-bar">
  ## Адресная строка
</div>

Адресная строка в верхней части вкладки **Preview** содержит следующие инструменты:

* **Кнопка «Назад»**: переход на предыдущую страницу в истории просмотров
* **Кнопка «Вперёд»**: переход на следующую страницу в истории просмотров
* **Домен приложения**: просмотр информации о временном URL вашего Replit App — нажмите `{...}.replit.dev`
* **Поле адреса**: просмотр текущего пути URL или ввод нового пути

<div id="browser-tools">
  ## Инструменты браузера
</div>

Инструменты браузера справа от адресной строки включают следующие функции:

* **Размер экрана**: выбор одного из предустановленных размеров экрана устройств для проверки адаптивной вёрстки
* **Devtools**: включение и отключение панели [инструментов разработчика](#Developer_tools)
* **Новая вкладка**: открытие URL вашего веб-приложения в новой вкладке браузера

<Note>
  **Создаёте мобильное приложение?** Панель Preview также поддерживает предпросмотр в **симуляторе iOS** или **эмуляторе Android**. Подробности см. в разделе [Нативные мобильные приложения](/ru/features/artifact-types/building-mobile-apps#preview-on-a-simulator-or-emulator).
</Note>

<div id="developer-tools">
  ## Инструменты разработчика
</div>

Инструменты разработчика, работающие на основе проекта с открытым исходным кодом <a href="https://github.com/liriliri/eruda" target="_blank">Eruda</a>, помогают выполнять следующие задачи:

* Просматривать консоль JavaScript и работать с ней в контексте вашего приложения
* Исследовать элементы DOM
* Отслеживать сетевые запросы
* Настраивать параметры отображения и поведения

Чтобы открыть инструменты разработчика, нажмите кнопку <img class="icon-svg" src="/assets/mirror/wrench-7cee9d1168da.svg" alt="wrench icon" width="16" height="16" data-path="images/icons/wrench.svg" /> **Devtools**
в верхней части вкладки **Preview** — она включает и отключает их отображение.

В следующих разделах описаны действия, которые можно выполнять на каждой вкладке инструментов разработчика.

<div id="console">
  ### Консоль
</div>

На вкладке **Console** отображаются журналы JavaScript, которые создаёт ваше приложение.
На этой вкладке доступны следующие действия:

* **Очистка вывода**: удалите весь вывод консоли, нажав значок <img class="icon-svg" src="/assets/mirror/clear-bd1bf1847597.svg" height="16" width="16" alt="clear icon" data-path="images/icons/clear.svg" /> перечёркнутого круга.
* **Фильтрация вывода**: просматривайте вывод консоли с фильтром по типу (All, Info, Warning или Error).
* **Фильтрация по тексту**: чтобы показать только совпадающий вывод, нажмите значок фильтра <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="filter icon" data-path="images/icons/filter.svg" /> и введите текст.
* **Копирование вывода**: скопируйте выбранные сообщения консоли, нажав кнопку копирования <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="copy icon" data-path="images/icons/copy.svg" />.
* **Выполнение кода JavaScript**: запустите код JavaScript в контексте вашего приложения, нажав значок угловой скобки <img class="icon-svg" src="/assets/mirror/arrow-right-2859a6e6bdeb.svg" height="16" width="16" alt="right arrow icon" data-path="images/icons/arrow-right.svg" />. Введите выражение и нажмите **Execute**.

<div id="elements">
  ### Elements
</div>

Вкладка **Elements** позволяет просматривать и изменять структуру DOM веб-страницы.

* **Просмотр сведений об элементе**: просматривайте сведения об элементе DOM и его расположении в HTML-коде
* **Копирование вывода**: копируйте выбранные сообщения консоли с помощью кнопки копирования <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="иконка копирования" data-path="images/icons/copy.svg" />.

Используйте стрелку выбора <img class="icon-svg" src="/assets/mirror/select-1165d9548c39.svg" height="16" width="16" alt="иконка выбора" data-path="images/icons/select.svg" />, чтобы включить или выключить режим выбора.
Перейдя в режим выбора, выберите элемент на веб-странице.
HTML и CSS этого элемента появятся на вкладке Elements.

<div id="network">
  ### Сеть
</div>

Вкладка **Network** отслеживает запросы, отправленные веб-страницей.
На этой вкладке доступны следующие действия:

* **Отслеживание запросов**: просматривайте все сетевые запросы, отправленные вашим приложением. Выберите запрос, чтобы увидеть подробности.
* **Фильтрация**: нажмите значок воронки <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="значок фильтра" data-path="images/icons/filter.svg" />, чтобы отобразить результаты, соответствующие введённому тексту. Чтобы сбросить фильтр, оставьте поле пустым.
* **Копирование**: скопируйте информацию о хранилище, нажав кнопку копирования <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="значок копирования" data-path="images/icons/copy.svg" />.

<div id="resources">
  ### Ресурсы
</div>

Вкладка **Resources** показывает ресурсы, загруженные страницей, а также данные браузерного хранилища, например файлы cookie и локальное хранилище.
Вы можете просматривать и обновлять списки ресурсов следующих типов:

* Файлы JavaScript
* Таблицы стилей
* Iframe
* Изображения

На этой вкладке доступны следующие действия:

* **Просмотр хранилища**: изучите локальное хранилище, хранилище сеанса и файлы cookie.
* **Фильтрация**: чтобы отобразить подходящие результаты, нажмите значок воронки <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="filter icon" data-path="images/icons/filter.svg" /> и введите текст. Чтобы сбросить фильтр, оставьте поле пустым.
* **Очистка**: удалите все данные этого типа хранилища, нажав кнопку очистки <img class="icon-svg" src="/assets/mirror/clear-bd1bf1847597.svg" height="16" width="16" alt="clear icon" data-path="images/icons/clear.svg" />.
* **Удаление выбранного**: удалите элементы хранилища, нажав значок «X» <img class="icon-svg" src="/assets/mirror/delete-a21eb49cac3c.svg" height="16" width="16" alt="delete icon" data-path="images/icons/delete.svg" />.
* **Копирование**: скопируйте информацию о хранилище, нажав кнопку копирования <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="copy icon" data-path="images/icons/copy.svg" />.

<div id="settings">
  ### Settings
</div>

Вкладка **Settings** позволяет настроить внешний вид и поведение инструментов разработчика.
На этой вкладке доступны следующие группы настроек:

* **Настройки инструментов**: параметры, применяемые к каждой вкладке инструментов
* **Управление JavaScript**: параметры работы JavaScript, например его отключение, чтобы проверить, как поведёт себя приложение
* **Параметры отображения**: изменение темы, размера панели, прозрачности и других аспектов поведения инструментов разработчика
