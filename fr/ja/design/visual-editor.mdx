<div id="section">
  ## Qu’est-ce que l’éditeur visuel ?
</div>

L’éditeur visuel vous permet de modifier manuellement l’UI en cliquant directement sur les éléments. Il fonctionne à la fois dans le [Canvas](/fr/ja/design/canvas) de Replit Design et dans Preview, ce qui vous permet de modifier de la même façon les maquettes et les applications en cours d’exécution.

Les modifications simples, comme changer du texte, ajuster des couleurs ou peaufiner les espacements, mettent directement à jour le code source sans consommer de crédits IA. Pour les modifications présentant une complexité non apparente, l’éditeur visuel transmet automatiquement la tâche à Agent.

Concepts clés :

* **Modifications déterministes** : les modifications simples (texte, couleurs, espacements) sont appliquées directement au code source sans passer par la boucle d’Agent
* **Aucun coût en crédits** : les modifications directes ne consomment pas de crédits IA — seules les modifications complexes passent par Agent
* **Double contexte** : fonctionne de la même manière sur les frames du Canvas et dans Preview
* **Synchronisation du code source** : toutes les modifications mettent instantanément à jour le code source sous-jacent

<Note>
  L’éditeur visuel est actuellement disponible uniquement dans les **navigateurs web**. Il n’est pas pris en charge dans les applications mobiles ni dans l’application de bureau.
</Note>

<div id="section-2">
  ## Utiliser l’éditeur visuel
</div>

<div id="section-3">
  ### Modifier sur le Canvas
</div>

Sélectionnez l’outil **Edit** dans la barre d’outils, puis cliquez sur n’importe quel élément du frame. L’élément est mis en surbrillance avec une étiquette indiquant son nom, et le panneau de l’éditeur visuel s’ouvre à droite avec les propriétés modifiables de cet élément, telles que le contenu, la mise en page, la couleur et la bordure. Après avoir ajusté les valeurs, sélectionnez **Save edits** pour les appliquer ou **Discard** pour les abandonner.

  <img src="/assets/mirror/visual-editor-edit-tool-71d03803471f.png" alt="L’outil Edit est activé et un élément est sélectionné dans un frame de configurateur de supercar. À droite, le panneau de l’éditeur visuel affiche les sections mise en page (Outer space et Inner space), couleur (texte, arrière-plan, opacité) et bordure (couleur, épaisseur, arrondi), ainsi que les boutons Discard et Save edits" width="2000" height="1250" data-path="images/replitai/visual-editor-edit-tool.png" />

Les propriétés affichées varient selon l’élément sélectionné. Les éléments textuels affichent des options de police, les images affichent la source de l’image et les options de téléversement, et les conteneurs affichent des options de mise en page.

<div id="preview">
  ### Modifier dans Preview
</div>

La même expérience de modification est également disponible dans votre application en cours d’exécution.

<Steps>
  <Step title="Sélectionner un élément">
    Cliquez sur n’importe quel élément dans Preview pour commencer à le modifier.
  </Step>

  <Step title="Modifier">
    Modifiez le texte directement, ajustez les couleurs à l’aide du sélecteur de couleurs, modifiez les espacements avec les contrôles de style ou remplacez les images.
  </Step>

  <Step title="Enregistrer">
    Sélectionnez Enregistrer pour mettre à jour le code source. Les modifications simples sont appliquées directement sans consommer de crédits IA. Si une modification est complexe, l’éditeur visuel envoie les métadonnées de l’élément cible à Agent pour obtenir de l’aide.
  </Step>
</Steps>

<div id="section-4">
  ### Modification du texte
</div>

Cliquez sur un élément de texte et saisissez directement vos modifications. Si le texte correspond à une chaîne dans le code source, les modifications sont appliquées immédiatement.

<div id="section-5">
  ### Ajuster les couleurs
</div>

Utilisez le sélecteur de couleurs pour modifier la couleur du texte et de l’arrière-plan. Saisissez un nom de couleur, comme « purple », dans le champ de saisie, ou utilisez l’outil pipette pour choisir une couleur n’importe où à l’écran.

<div id="section-6">
  ### Modifier les styles
</div>

Utilisez des commandes intuitives pour ajuster le remplissage intérieur, les marges et la mise en page générale d’un élément.

<div id="section-7">
  ### Contrôles de mise en page
</div>

L&#39;éditeur visuel regroupe tous les contrôles dans des sections claires afin de vous aider à trouver plus rapidement ce dont vous avez besoin : **Texte**, **Mise en page**, **Couleur**, **Bordure**. (Lorsque vous sélectionnez un élément image, la section **Image** s&#39;affiche également.)

La section **Mise en page** permet d&#39;ajuster la disposition des éléments enfants dans un conteneur sans passer par Agent. Lorsque vous sélectionnez un conteneur flex et développez la section Mise en page, les options suivantes s&#39;affichent :

* **Alignement** : un sélecteur à 9 points indiquant où les éléments sont positionnés selon les deux axes du conteneur.
* **Direction** : deux boutons fléchés pour disposer les éléments enfants en ligne ou en colonne.
* **Espacement** : définit l&#39;espace entre les éléments en pixels. L&#39;icône à côté du champ Espacement change selon la direction actuelle ; vous savez ainsi toujours si vous ajustez l&#39;espace horizontal ou vertical. L&#39;icône en forme de flèche située à côté active ou désactive **Répartir l&#39;espace entre les éléments**, ce qui répartit les éléments enfants entre les deux extrémités du conteneur.
* **Espace extérieur** : des champs permettant de définir l&#39;espace extérieur de l&#39;élément pour chaque côté (un champ par côté et un bouton de liaison pour verrouiller les quatre côtés simultanément).
* **Espace intérieur** : des champs permettant de définir l&#39;espace intérieur de l&#39;élément selon chaque axe, avec un bouton de liaison pour verrouiller les deux axes simultanément.

La section Mise en page ne s&#39;affiche que lorsqu&#39;au moins un contrôle de mise en page est appliqué à l&#39;élément sélectionné. Pour les nœuds de texte simples sans propriétés d&#39;espacement ou de mise en page, cette section est entièrement masquée afin de conserver la compacité de l&#39;éditeur.

<div id="section-8">
  ### Mettre à jour les images
</div>

Sélectionnez une image et remplacez son URL, ou téléversez vos propres fichiers pour les prévisualiser immédiatement.

<div id="section-9">
  ## Ce que vous pouvez faire
</div>

* **Retouches rapides du texte **: mettez à jour le texte, les libellés et les titres sans ouvrir les fichiers source
* **Exploration des couleurs **: essayez différentes palettes en cliquant et en ajustant — inutile de chercher le CSS adapté
* **Ajustements précis de la mise en page **: ajustez visuellement le padding, les marges et les espacements au lieu de deviner les valeurs en pixels
* **Remplacement d’images **: remplacez les images d’espace réservé par de vraies ressources en cliquant simplement pour téléverser
* **Itération sur le design **: ajustez rapidement les frames sur le Canvas et comparez différentes pistes visuelles sans multiplier les échanges avec Agent

<div id="section-10">
  ## Questions fréquentes
</div>

<Accordion title="Les modifications apportées dans l’éditeur visuel consomment-elles des crédits IA ?">
  Les modifications simples et prévisibles — modification de texte, choix de couleurs, ajustement des espacements — ne consomment pas de crédits IA, car elles mettent directement à jour le code source. Si l’éditeur visuel détecte une complexité cachée, la modification est transmise à Agent et des crédits sont utilisés.
</Accordion>

<Accordion title="Puis-je modifier un élément affiché à plusieurs endroits ?">
  Oui. Lorsque vous sélectionnez un élément affiché dans une boucle ou réutilisé dans plusieurs composants, toutes ses instances sont mises en évidence et mises à jour simultanément.
</Accordion>

<Accordion title="Pourquoi ne puis-je pas modifier le texte de certains éléments ?">
  Les éléments composés de plusieurs sous-éléments ne permettent pas de modifier directement leur texte dans l’éditeur visuel. Demandez plutôt à Agent d’effectuer la modification dans le chat.
</Accordion>

<Accordion title="Comment trouver le code source d’un élément ?">
  Cliquez sur le libellé situé en haut à gauche de l’élément sélectionné pour accéder à son emplacement dans le code source.
</Accordion>
