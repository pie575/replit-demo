Project Editor에서 텍스트 파일을 열고 오른쪽 아래에 있는 **History** 버튼을 눌러 시작하세요.

<Frame>
  <img src="/assets/mirror/history-button-afac6496660a.png" alt="히스토리 열기" width="377" height="292" data-path="images/programming-ide/history-button.png" />
</Frame>

<div id="viewing-previous-versions-of-a-file">
  ## 파일의 이전 버전 보기
</div>

File History를 열면 스크롤 막대, 화살표 버튼 또는 **왼쪽**, **오른쪽** 화살표 키를 사용해 파일의 이전 버전을 확인할 수 있습니다.

<Frame>
  <img src="/assets/mirror/history-versioning-1a055ecab411.gif" alt="스크롤 막대 데모" width="764" height="720" data-path="images/animations/history-versioning.gif" />
</Frame>

<div id="comparing-previous-versions-to-the-current-file">
  ## 이전 버전과 현재 파일 비교하기
</div>

File History 창 왼쪽 하단의 Compare Latest 토글을 누르면 해당 시점의 파일과 최신 버전을 인라인으로 비교할 수 있습니다.

<Frame>
  <img src="/assets/mirror/compare-history-46fb16debd3a.gif" alt="최신 버전 비교 이미지" width="772" height="720" data-path="images/animations/compare-history.gif" />
</Frame>

<div id="restoring-a-previous-version-of-a-file">
  ## 파일의 이전 버전 복원하기
</div>

파일을 이전 버전으로 되돌리려면 `Restore` 버튼만 누르면 됩니다. 기록이 사라질 걱정은 하지 않으셔도 됩니다. 이전 버전으로 복원하면 해당 버전이 파일 기록에 새 버전으로 추가됩니다.

<Frame>
  <img src="/assets/mirror/restore-history-5f616d7f961a.webp" alt="기록 복원 이미지" width="720" height="495" data-path="images/animations/restore-history.webp" />
</Frame>

<div id="viewing-file-history-playback">
  ## File History 재생 보기
</div>

File History의 재생 기능을 사용하면 파일이 시간에 따라 변화하는 과정을 영화처럼 볼 수 있습니다. 프로그래밍 session을 영상으로 만들 때 유용합니다.
