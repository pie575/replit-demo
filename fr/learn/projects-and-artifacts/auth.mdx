L’auth — abréviation d’**authentification** — permet à votre app de reconnaître les « utilisateurs ». Sans auth, chaque visiteur est anonyme et votre app ne peut pas distinguer une personne d’une autre. Avec l’auth, chaque visiteur se connecte, votre app sait qui il est et vous pouvez enregistrer des données spécifiques à chacun : ses réservations, ses voitures enregistrées, ses préférences, sa progression.

Une fois l’auth configurée, vous pouvez :

* Enregistrer des données par utilisateur — réservations, paramètres, contenu, historique.
* Restreindre l’accès à certaines fonctionnalités aux utilisateurs connectés (un checkout, une page de profil, un panneau d’administration).
* Personnaliser l’expérience en fonction du nom, du rôle, du plan ou du comportement passé.
* Suivre l’activité et l’utilisation par utilisateur plutôt que par session.

<div id="how-auth-works-in-a-replit-app">
  ## Fonctionnement de l’authentification dans une app Replit
</div>

Replit propose deux options d’authentification intégrées. Toutes deux sont configurées par Agent — pas d’inscription à un tableau de bord distinct ni de copier-coller de clés OAuth.

* **[Replit Auth](/fr/features/auth-and-identity/authentication)** — vos utilisateurs se connectent avec leurs **comptes Replit** existants. La page de connexion est aux couleurs de Replit. Aucune configuration n’est nécessaire : demandez simplement à Agent de l’ajouter.
* **[Clerk Auth](/fr/features/auth-and-identity/clerk-auth)** — votre app dispose de son propre **tenant Clerk** dédié. Les utilisateurs créent des comptes dans *votre* app, et non sur Replit. Vous contrôlez l’image de marque, les méthodes de connexion et l’apparence de l’écran de connexion.

Les deux options prennent en charge les tâches complexes — pages de connexion, sessions, gestion sécurisée des mots de passe, connexions via les réseaux sociaux — afin que le code de votre app n’ait qu’à demander : « qui est l’utilisateur connecté ? »

<div id="replit-auth-vs-clerk-auth">
  ## Replit Auth ou Clerk Auth
</div>

|                          | Replit Auth                                                                                      | Clerk Auth                                                                            |
| ------------------------ | ------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------- |
| **Comptes utilisateurs** | Les utilisateurs se connectent avec un compte Replit                                             | Les utilisateurs créent un compte dans votre application (sans compte Replit)         |
| **Image de marque**      | Page de connexion aux couleurs de Replit                                                         | Entièrement personnalisable — nom, icône et couleurs de votre application             |
| **Identifiants SSO**     | Utilise les applications OAuth partagées de Replit                                               | Utilisez vos propres identifiants OAuth pour chaque fournisseur                       |
| **Environnements**       | Environnement unique                                                                             | Environnements de développement et de production distincts                            |
| **Idéal pour**           | Configuration rapide, prototypes, applications pour lesquelles l’image de marque Replit convient | Applications avec leur propre image de marque, produits professionnels et commerciaux |

Si vous créez un prototype ou un outil interne, Replit Auth est la solution la plus rapide. Si vous créez une application avec sa propre identité de marque, en particulier destinée aux clients ou à un usage commercial, Clerk Auth est plus adapté.

<div id="add-auth-to-your-app">
  ## Ajoutez une authentification à votre app
</div>

Vous n&#39;avez pas besoin de choisir dès le départ : vous pouvez commencer avec l&#39;une, puis migrer vers l&#39;autre plus tard. Le plus simple est d&#39;indiquer à Agent celle à utiliser :

* *« Ajoute une connexion à mon app. Utilise Replit Auth. »*
* *« Ajoute une connexion à mon app. Utilise Clerk Auth. »*
