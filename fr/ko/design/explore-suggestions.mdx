Les suggestions sont au cœur de l&#39;interface de Replit Design. Plutôt que de vous retrouver devant une prompt box vide sans savoir quoi demander, sélectionnez une frame de design : Replit Design vous proposera aussitôt des pistes à explorer. Chaque suggestion débouche sur une nouvelle génération en un seul clic.

<div id="section">
  ## Fonctionnement des suggestions
</div>

Lorsque vous sélectionnez un frame de design généré, des suggestions apparaissent à côté. Elles s’appuient sur ce que vous consultez actuellement : nul besoin de connaître le jargon du design pour les explorer. Cliquez sur l’une d’elles pour que Replit Design génère le résultat dans un nouveau cadre tout en conservant l’original.

<div id="section-2">
  ## Ce que proposent les suggestions
</div>

Les suggestions répondent à différentes questions d’exploration :

* **Nouvelle apparence** : une autre interprétation du même design, comme une variante éditoriale sombre ou une mise en page différente.
* **Extension** : une section ou une page que le design laisse entrevoir, mais qui n’existe pas encore, comme une section de tarification ou une page de contact.
* **Nouveau contexte** : l’application du design dans un autre contexte, comme une vue mobile.

<div id="section-3">
  ## Explorer par suggestions
</div>

Cette boucle est volontairement courte :

<Steps>
  <Step title="Sélectionner le frame généré">
    Sur le canvas, cliquez sur le frame de design généré.

    <Frame>
      <img src="/assets/mirror/ambient-select-frame-7147427722bd.png" alt="Frame Design nommé APEX X1 Exact Replica affichant une page héros de supercar grise sur le canvas" width="2000" height="1252" data-path="images/design/replit-design/ambient-select-frame.png" />
    </Frame>
  </Step>

  <Step title="Choisir une suggestion">
    À côté du frame sélectionné apparaissent des suggestions fondées sur ce que vous êtes en train de regarder. Parcourez-les et cliquez sur celle de votre choix. Rien d&#39;autre à ajouter.
  </Step>

  <Step title="Un clic et Agent construit">
    Dès que vous cliquez, Agent commence à construire la suggestion dans un nouveau frame, à côté de l&#39;original. Le frame précédent reste sur le canvas : explorer ne vous fait donc rien perdre.

    <Frame>
      <img src="/assets/mirror/ambient-suggestion-building-9da4835557d2.png" alt="Nouveau frame Design intitulé « Add Saturation on Scroll » affiché à côté du frame APEX X1 d'origine, avec la mention Building… et une mise en page squelette" width="2000" height="1252" data-path="images/design/replit-design/ambient-suggestion-building.png" />
    </Frame>
  </Step>

  <Step title="Vérifier les changements">
    Le frame terminé apparaît à côté de l&#39;original, ce qui vous permet de comparer les deux côte à côte. Le panneau de chat affiche un résumé des modifications apportées.

    <Frame>
      <img src="/assets/mirror/ambient-suggestion-result-a50d1efa94c4.png" alt="Deux frames Design terminés côte à côte sur le canvas — l'original APEX X1 Exact Replica et la variante Add Saturation on Scroll achevée — ainsi que le résumé « Run complete » dans le panneau de chat" width="2000" height="1189" data-path="images/design/replit-design/ambient-suggestion-result.png" />
    </Frame>
  </Step>

  <Step title="Appliquer le design préféré à votre application">
    Sélectionnez et ramifiez jusqu&#39;à trouver la direction qui vous plaît. Quel que soit le frame choisi, de nouvelles suggestions apparaissent. Le design que vous retenez n&#39;a pas à rester une simple maquette : sélectionnez le frame, choisissez **Build…** dans la barre d&#39;actions, puis sélectionnez une application existante sous **Apply to an existing creation**. Agent réécrit le code de l&#39;application pour correspondre au design, et le frame reste sur le canvas à titre de référence.

    <Frame caption="Menu Build : appliquez le frame que vous préférez à une application que vous possédez déjà.">
      <img src="/assets/mirror/explore-variants-apply-b04b893252cd.png" alt="Menu Build ouvert depuis la variante sélectionnée — avec deux options : « Build this design » qui crée un nouvel artefact, et « Apply to an existing creation » qui liste les artefacts Website du projet" width="2000" height="1226" data-path="images/design/replit-design/explore-variants-apply.png" />
    </Frame>

    Pour découvrir l&#39;ensemble du flux, y compris la façon de construire un frame en nouvelle application, consultez [Construire votre design](/fr/ko/design/build-your-design). Pour peaufiner les détails avant d&#39;appliquer le design, consultez [Affiner par le chat](/fr/ko/design/chat-about-your-design).
  </Step>
</Steps>

<div id="section-4">
  ## Conseils
</div>

* **Explorez des pistes plutôt que des étapes.** Les suggestions ouvrent simplement des pistes : en en suivant une, vous n’y êtes pas limité. Générez-en plusieurs et comparez-les sur le canvas.
* **Exprimez-vous directement.** Les suggestions et le [Chat de Design](/fr/ko/design/chat-about-your-design) fonctionnent ensemble. Cliquez sur une suggestion pour explorer différentes possibilités, puis utilisez le chat pour affiner votre direction. Le chat ne sert pas uniquement à peaufiner. Des messages comme *« Place la navigation à gauche »* ouvrent également de nouvelles pistes.
* **Changez de modèle si vous souhaitez une autre approche.** Chaque modèle explore différemment. Consultez [Explorer avec différents modèles](/fr/ko/design/explore-with-different-models).
