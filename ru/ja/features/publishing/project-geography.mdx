Регион проекта — это регион, в котором публикуется проект. Вы выбираете его при публикации, и он определяет, где размещаются вычислительные ресурсы и хранилище опубликованного проекта.

<Note>
  Регион проекта и [регион рабочего пространства](/ru/features/collaboration/workspace-geography) могут не совпадать. Регион рабочего пространства определяет, где размещаются ресурсы разработки для новых проектов в этом рабочем пространстве.
</Note>

<div id="section">
  ## Что определяет регион проекта
</div>

По умолчанию Replit предлагает ближайший к вам регион. Это снижает задержку для посетителей вашего App и помогает выполнить требования к месту хранения данных.

После выбора региона все опубликованные артефакты проекта — вычислительные ресурсы, базы данных, Object Storage — автоматически размещаются в том же регионе. Снизить задержку для посетителей вашего App помогают и региональные прокси.

<div id="section-2">
  ## Выбор региона проекта
</div>

Чтобы выбрать регион, отличный от рекомендованного, выполните следующие шаги.

<Steps>
  <Step>Откройте инструмент **Publishing** в проекте Replit.</Step>
  <Step>Разверните настройки **Дополнительно**.</Step>
  <Step>Выберите нужный регион в выпадающем списке **Geography**.</Step>

  <Step>
    Нажмите **Publish**, чтобы опубликовать проект в выбранном регионе.
  </Step>
</Steps>

<div id="section-3">
  ## Принудительный выбор региона для публикуемых проектов
</div>

Администраторы Enterprise могут принудительно задать регион публикации для всех проектов в организации. Когда политика настроена, разработчики организации публикуют проекты в заданном регионе. Политика применяется только к проектам, которые ещё не были опубликованы, и не затрагивает проекты, уже опубликованные в другом регионе.

<Note>
  Принудительный выбор региона публикации — функция Enterprise. Подробнее о плане Enterprise см. на странице [Цены](https://replit.com/pricing/).
</Note>

<Steps>
  <Step>Перейдите в **Настройки аккаунта**.</Step>
  <Step>Выберите **Дополнительно**.</Step>

  <Step>
    Выберите регион, который должны использовать все проекты при первой публикации.
  </Step>
</Steps>

<div id="section-4">
  ## Доступность и ограничения
</div>

| Регион            | Выбор при публикации проекта |
| :---------------- | :--------------------------- |
| **North America** | Да                           |
| **Europe (EU)**   | Да                           |
| **Asia**          | Да                           |
| **South America** | Да                           |
| **Australia**     | Да                           |

<Note>
  Выбор региона проекта доступен клиентам с планами Core, Pro и Enterprise. Проекты клиентов на бесплатном плане по умолчанию публикуются в регионе North America.
</Note>

Прежде чем выбирать регион проекта, обратите внимание на следующие ограничения.

* **После публикации регион изменить нельзя.** Если проект опубликован в определённом регионе, этот выбор остаётся неизменным. Перенести опубликованный проект в другой регион невозможно.
* **Среда разработки и место публикации могут не совпадать.** Такие ресурсы, как Object Storage, могут быть созданы до публикации, и их расположение может не совпадать с регионом проекта.
