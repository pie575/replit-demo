Настройка Agent предоставляет необходимый контекст, чтобы Agent уже с первого промпта работал так, как вы и ваша команда. Вместо того чтобы заново объяснять правила в каждом проекте, определите их один раз в рабочем пространстве — и Agent будет применять их везде.

Она состоит из двух частей:

* **Пользовательские инструкции**: постоянно активные рекомендации, применяемые ко всем проектам рабочего пространства.
* **Навыки**: повторно используемые инструкции, которые Agent загружает только при выполнении соответствующих задач.

Оба варианта управляются в разделе **Настройки рабочего пространства → Настройка**.

<div id="section">
  ## Пользовательские инструкции и навыки
</div>

Пользовательские инструкции загружаются для каждого сообщения, а навыки — только когда Agent считает их релевантными задаче. Используйте пользовательские инструкции для правил, которые применяются всегда, а навыки — для конкретных рабочих процессов, правил и справочных материалов.

Подробнее о причинах такого разделения — бюджете контекста, о том, что к чему относится, и о том, как правильно создавать навыки, — см. в разделе [Навыки Agent](/ru/ko/learn/agent-skills). О том, как устроены навыки и как Agent их загружает, см. в разделе [Навыки Agent](/ru/ko/features/agent/skills).

<div id="section-2">
  ## Пользовательские инструкции
</div>

Пользовательские инструкции — это постоянно действующие правила, которые добавляются в контекст Agent во всех проектах и сеансах ещё до ввода промпта. Настройте их один раз в настройках рабочего пространства, и Agent будет применять их во всём рабочем пространстве. Они лучше всего подходят для правил, которые должны соблюдаться всегда: требований безопасности и соответствия нормативным требованиям, утверждённых библиотек и фреймворков, политик обработки данных.

Пишите кратко. Чем точнее и конкретнее инструкции, тем выше вероятность их соблюдения и тем больше свободы остаётся Agent для выполнения задач.

<Warning>
  Пользовательские инструкции могут влиять на работу Agent. Agent предписано следовать им, однако строгое соблюдение требований не гарантируется. Чем короче и конкретнее рекомендации, тем надёжнее они соблюдаются.
</Warning>

<Note>
  Пользовательские инструкции рабочего пространства отличаются от файла проекта `custom_instruction/instructions.md`. Они настраиваются один раз в настройках рабочего пространства и применяются ко всем проектам. Файл для конкретного проекта находится внутри самого проекта — подробнее об этом подходе см. в разделе [Создание пользовательской дизайн-системы](/ru/ko/teams/custom-design-system).
</Note>

<div id="section-3">
  ## Навыки
</div>

Навыки — это многоразовые наборы инструкций, которые Agent загружает только для связанных задач. Навыки рабочего пространства отображаются в верхней части меню **+** во всех проектах рабочего пространства, поэтому вся команда использует один и тот же набор.

Создать навык можно тремя способами:

* **Загрузить**: загрузите существующую папку навыка.
* **Создать**: создайте новый навык прямо в форме.
* **Попросить Agent**: попросите Agent подготовить черновик навыка, а затем доработайте его.

<Note>
  Вы можете загрузить в рабочее пространство навык, черновик которого подготовил Agent. Попросите Agent скачать навык. Agent упакует навык в доступный для скачивания архив `.zip` и предоставит кнопку **Скачать файл** (см. ниже). Скачайте ZIP-архив, затем повторно загрузите его через **Настройки рабочего пространства → Настройка → Навыки**, выбрав **Создать навык → Выбрать файл или папку**, чтобы сделать его доступным во всём рабочем пространстве.
</Note>

Подробнее о полной структуре навыка (`SKILL.md`, вспомогательные файлы и открытые стандарты) см. в разделе [Навыки Agent](/ru/ko/features/agent/skills). Чтобы ознакомиться с навыками, уже созданными Replit и партнёрами, см. [Каталог навыков](/ru/ko/features/agent/skills-directory).

<Note>
  Используйте навыки осмотрительно. Agent читает названия и описания всех навыков для каждой задачи, поэтому слишком большое количество навыков или их дублирование может отвлекать Agent и затруднять выбор нужного навыка. Сохраняйте узкую область применения каждого навыка и удаляйте навыки, которые больше не нужны.
</Note>

<div id="section-4">
  ## Доступность и права доступа
</div>

| Функция                     | Доступные тарифы   | Кто может управлять                                                         |
| --------------------------- | ------------------ | --------------------------------------------------------------------------- |
| Пользовательские инструкции | Pro и Enterprise   | Enterprise: администраторы. Pro: все участники рабочего пространства        |
| Навыки                      | Все платные тарифы | Enterprise: администраторы. Core и Pro: все участники рабочего пространства |

В рабочих пространствах Enterprise только администраторы могут создавать, редактировать и удалять пользовательские инструкции и навыки. В рабочих пространствах Pro это могут делать все участники рабочего пространства. В рабочих пространствах Core все участники могут управлять навыками — пользовательские инструкции в Core недоступны. В любом случае все участники рабочего пространства могут использовать созданные навыки.

<div id="section-5">
  ## Создание пользовательских инструкций
</div>

<Steps>
  <Step title="Откройте настройки рабочего пространства">
    Перейдите в раздел **Настройки рабочего пространства → Настройка**.

    <Frame>
      <img src="/assets/mirror/agent-customization-tab-930af2e8ed74.png" alt="Вкладка «Настройка» в настройках рабочего пространства с подвкладками «Навыки» и «Пользовательские инструкции»" width="1065" height="394" data-path="images/replitai/agent-customization-tab.png" />
    </Frame>
  </Step>

  <Step title="Добавьте инструкции">
    В разделе **Пользовательские инструкции** укажите рекомендации, которые Agent будет применять ко всем проектам.
  </Step>

  <Step title="Сохраните изменения">
    Сохраните изменения. Инструкции будут применяться к новым проектам в рабочем пространстве.
  </Step>
</Steps>

<div id="section-6">
  ## Создание навыка
</div>

<Steps>
  <Step title="Откройте настройки рабочего пространства">
    Перейдите в **Настройки рабочего пространства → Настройка**.
  </Step>

  <Step title="Создайте навык">
    В разделе **Навыки** нажмите **Создать навык**, затем загрузите папку с навыком, напишите инструкции или попросите Agent подготовить черновик.

    <Frame>
      <img src="/assets/mirror/agent-customization-create-skill-fcb794e6de4e.png" alt="Вкладка «Настройка» в настройках рабочего пространства, вкладки «Навыки» и «Пользовательские инструкции», а также открытая форма создания навыка" width="2168" height="1350" data-path="images/replitai/agent-customization-create-skill.png" />
    </Frame>
  </Step>

  <Step title="Напишите понятное описание">
    Добавьте точное описание, в котором ясно указано, когда следует использовать навык, а когда — нет. Agent читает это описание, чтобы определить, применим ли навык.
  </Step>

  <Step title="Сохраните">
    Сохраните навык. Он станет доступен в меню **+** во всех проектах рабочего пространства.
  </Step>
</Steps>

<div id="section-7">
  ## Использование навыков рабочего пространства в проекте
</div>

Важно, чтобы описание навыка было точным. Agent читает описания всех навыков рабочего пространства и автоматически подключает навык, если промпт примерно соответствует его назначению, поэтому выбирать навык вручную нужно не всегда. Чтобы навык точно был применён, его также можно выбрать явно.

Чтобы выбрать навык вручную:

<Steps>
  <Step title="Откройте меню выбора навыков">
    В проекте нажмите кнопку **+** рядом с полем ввода чата. Навыки рабочего пространства отображаются вверху отдельной группой.

    <Frame>
      <img src="/assets/mirror/agent-customization-skill-picker-4643f3a453c7.png" alt="Меню выбора навыков, открытое кнопкой +, с группой навыков рабочего пространства вверху над навыками Replit" width="1668" height="1170" data-path="images/replitai/agent-customization-skill-picker.png" />
    </Frame>
  </Step>

  <Step title="Выберите навык">
    Выберите навык, который хотите активировать. Вы также можете вызвать его напрямую, введя название навыка после `/`.
  </Step>

  <Step title="Продолжите писать промпт">
    Продолжайте как обычно. Если задача соответствует описанию, Agent использует навык.
  </Step>
</Steps>

<div id="section-8">
  ## Управление инструкциями и навыками
</div>

Все настройки доступны в разделе **Настройки рабочего пространства → Настройка**. Здесь можно редактировать пользовательские инструкции, а также редактировать, отключать и удалять навыки. Изменения применяются к последующим чатам и не затрагивают уже начатые.
