</div>

<AiPrompt>

<div id="section-5">
  ## 您将获得什么
</div>

Agent 会构建一个可公开访问的网站，并接入结账、支付、确认邮件和参与者名单。
分享链接前，请先进行测试下单。使用 Stripe 的测试模式和测试卡，
确认能够收到确认邮件、参与者已添加到名单中，且导出内容包含参与者，
然后再切换至实际收费。

<div id="section-7">
  ## 故障排除
</div>

* **未收到确认邮件：**请确认 Resend 已连接，且发信域名已通过验证。创建测试订单，并在 Resend 控制台中确认邮件是否已发送。
* **演讲者或时间有误：**请向 Agent 指定 Notion 数据库 (姓名、照片、职位、简介、场次时间) ，并要求它在 Notion 内容变更时同步更新页面。
* **结账时未收费：**请确认 Stripe 已连接，并且当前处于测试模式。分享链接前，请先创建测试订单。
