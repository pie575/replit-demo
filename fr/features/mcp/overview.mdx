Replit Agent se connecte à des outils et sources de données externes via le [Model Context Protocol (MCP)](https://modelcontextprotocol.io), un standard ouvert pour les intégrations IA. Chaque serveur ci-dessous s'installe en un seul clic — Agent charge alors automatiquement ses outils et les utilise lorsque c'est approprié.

Pour le concept, consultez [Model Context Protocol](/fr/learn/model-context-protocol). Pour le guide pratique, consultez [Se connecter via MCP](/fr/build/connect-via-mcp). Pour connecter un serveur non répertorié ici, consultez [Ajouter un serveur MCP personnalisé](/fr/build/connect-via-mcp#add-a-custom-mcp-server).

<Info>
  Sélectionnez **Ajouter à Replit** pour installer n'importe quel serveur. Il vous sera demandé d'autoriser la connexion dans l'éditeur de projet.
</Info>

## Protections de sécurité

Tout le trafic MCP passe par le scanner de sécurité de Replit. Le scanner évalue les définitions d'outils et les exécutions planifiées, bloquant les outils suspects ou non sécurisés avant leur exécution. Si un outil est rejeté, Agent vous en informera.

## Options d'authentification

* **Enregistrement dynamique de client OAuth** — si le serveur prend en charge OAuth DCR, Replit détecte et enregistre automatiquement le client pour vous. La plupart des serveurs pré-listés utilisent ce flux.
* **En-têtes personnalisés** — définissez une ou plusieurs paires nom/valeur d'en-tête (par exemple, `X-API-Key`). Replit inclut ces en-têtes dans chaque requête MCP pour que votre serveur puisse vérifier l'appelant. Utilisez ceci lors de l'ajout d'un serveur personnalisé qui s'authentifie via des jetons statiques.

## Partager votre propre lien d'installation

Les liens d'installation ajoutent votre serveur MCP à Replit en un seul clic. Générez-en un avec le formulaire sur [Se connecter via MCP](/fr/build/connect-via-mcp#share-an-install-link), ou construisez-le vous-même : encodez en base64 une charge utile JSON et ajoutez-la à `https://replit.com/integrations?mcp=`.

```json theme={null}
{
  "displayName": "My MCP Server",
  "baseUrl": "https://example.com/mcp",
  "headers": [{ "key": "Authorization", "value": "Bearer your-token" }]
}
```

* **displayName** — le nom affiché lors de l'installation
* **baseUrl** — le point de terminaison HTTPS de votre serveur MCP
* **headers** — en-têtes d'authentification optionnels
