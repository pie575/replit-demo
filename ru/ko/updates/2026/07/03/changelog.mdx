<div id="replit">
  ### Обновлённое десктопное приложение Replit
</div>

Обновлённое десктопное приложение Replit открывает полноценные возможности Replit прямо на вашем компьютере. Вы получаете тот же процесс разработки, что и в браузере, плюс преимущества нативного приложения. Работайте сразу над несколькими приложениями, с одного взгляда определяйте, когда Agent нуждается в помощи или завершил задачу, и просматривайте открытые приложения, не переключаясь между ними.

<div id="whop">
  ### Продажи внутри приложения через Whop
</div>

Теперь достаточно попросить Agent — и он добавит в ваше приложение приём платежей через Whop. Agent сам создаст и подключит аккаунт Whop, а затем встроит в проект оформление заказа: без внешних настроек и без ввода ключей API. Whop — самый быстрый способ начать продавать цифровые продукты, доступ к сообществам и подписки.

Подробнее о [платежах через Whop](/ru/ko/features/monetization/whop-payments).

<div id="pro-core">
  ### Переход с Pro на Core в один шаг
</div>

Теперь перейти с Replit Pro на Replit Core можно напрямую, без предварительной отмены подписки. Раньше для понижения тарифа приходилось сначала отменить подписку, перейти на бесплатный план, а затем оформить подписку заново. Теперь, когда вы начинаете отмену, Replit предлагает вместо этого перейти на Core — так вы остаётесь на платном плане, а опубликованные приложения продолжают работать.

Подробнее об [изменении плана](/ru/ko/billing/plans/changing-your-plan).
