<div id="agent">
  ### Попросите Agent добавить базу данных
</div>

Интеграция с Agent в панели DB упрощает настройку базы данных. Этот рабочий процесс на основе ИИ проведёт вас через настройку и позволит реализовать сохранение данных без сложного конфигурационного кода.

Разработчики могут сосредоточиться на создании основной функциональности, пока Agent берёт на себя все детали работы с базой данных. Подробнее о [Replit Agent](/ru/core-concepts/agent) и [вариантах баз данных](/ru/ko/learn/projects-and-artifacts/storage-and-databases).

<div id="replit-auth">
  ### Сопоставление Replit Auth по умолчанию
</div>

Аутентификация пользователей в приложении становится проще благодаря автоматическому сопоставлению Replit Auth.

Функция активируется, когда приложению требуется аутентификация. Она избавляет от необходимости создавать собственные формы регистрации и системы восстановления паролей, а также настраивать вход через социальные сети. В результате вы быстрее переходите к безопасному управлению пользователями.

<div id="section-5">
  ### Полноэкранное подтверждение по электронной почте
</div>

Повысьте безопасность аккаунта с помощью упрощённого процесса подтверждения для защищённых действий.

Этот единый подход предлагает подтверждение по электронной почте после входа в систему, когда это необходимо. Он обеспечивает защиту аккаунта, сохраняя баланс между безопасностью и удобством и единообразие пользовательского опыта.

Это часть нашей постоянной работы над [информационной безопасностью](/ru/ko/teams/information-security/overview).

<div id="scim">
  ### SCIM для клиентов Enterprise
</div>

Новая интеграция SCIM позволяет клиентам Enterprise управлять доступом к Replit напрямую из своего поставщика удостоверений.

Подключите Okta, Active Directory, Rippling или другую платформу управления удостоверениями, чтобы автоматизировать выдачу и отзыв мест в Replit. Это избавляет от лишней ручной работы по управлению пользователями и упрощает рабочие процессы в Enterprise.

Чтобы начать, ознакомьтесь с подробной [документацией по SCIM](/ru/ko/teams/identity-and-access-management/scim).

<div id="replit-teams">
  ### Места для зрителей в Replit Teams
</div>

Представляем места для зрителей в Replit Teams. Делитесь приложениями с заинтересованными лицами, которым нужно только просматривать приложения и работать с ними, но не редактировать, — и без полной командной лицензии.

Отличный вариант, чтобы поделиться приложением с руководителями, клиентами и коллегами, которые пользуются приложениями, но не разрабатывают их. Узнайте, как настраивать [места для зрителей](/ru/ko/teams/identity-and-access-management/viewer-seats) и управлять ими.
