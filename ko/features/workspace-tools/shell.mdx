Shell을 사용하면 일반적인 터미널처럼 파일 관리, 패키지 설치, 스크립트 실행과 같은
작업을 프로젝트에서 수행할 수 있습니다. 예를 들어 프로젝트 파일을 탐색하거나,
프로젝트에 데이터베이스 연결이 구성되어 있는 경우 `psql`을 사용할 수 있습니다.

<Tip>
  더 나은 워크플로 관리를 위해 Shell에서 앱을 실행하는 대신 **Run** 버튼을
  사용하는 것이 좋습니다. **Run** 버튼으로 시작된 워크플로는 Console 도구로
  출력을 전송하며, 이는 로그를 검토하는 구조화된 방법을 제공합니다.
</Tip>

## 기능

Shell은 다음 기능을 제공합니다:

* **여러 shell 실행**: 서로 다른 작업을 동시에 처리하기 위해 여러 shell 인스턴스를 엽니다
* **텍스트 검색**: shell 출력에서 특정 텍스트를 찾습니다

### Shell 접근 확인

Shell이 준비되었는지 확인하고 현재 워크스페이스를 보려면 다음을 실행하세요:

```sh theme={null}
pwd
```

Shell이 현재 워크스페이스의 경로를 출력합니다.

<Frame caption="pwd 명령은 현재 워크스페이스 경로를 출력하고 Shell 프롬프트로 돌아갑니다.">
  <img src="/assets/mirror/shell-pwd-output-2d31a0e0466b.jpg" alt="pwd 명령과 워크스페이스 경로 출력, 복귀한 프롬프트가 표시된 Shell 탭" width="1280" height="246" data-path="images/workspace/shell-pwd-output.jpg" />
</Frame>

데이터베이스가 있는 프로젝트의 경우 **Tools** → **Database**를 선택한 다음
**Development database** 페이지를 엽니다. 이 페이지는 연결 제어 기능을
제공합니다. 연결 값은 비공개로 유지하세요. 문서, 스크린샷, 로그, 소스 파일,
공유 메시지에 복사하지 마세요.

### 텍스트 검색

다음 단계는 텍스트 검색 도구에 접근하고 사용하는 방법을 설명합니다:

1. Shell 탭 오른쪽 상단의 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="돋보기 아이콘" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 돋보기를 선택하여 검색 대화상자를 엽니다.
2. 검색어를 입력하고 **Next**를 선택하여 일치 항목을 탐색합니다.
3. **Previous**를 사용하여 이전 일치 항목으로 돌아갑니다.
4. **Exit**를 선택하거나 대화상자 바깥을 클릭하여 텍스트 검색을 종료합니다.

### 여러 shell

다른 shell을 만들려면:

1. Shell 패널 헤더에서 shell 인스턴스 메뉴를 선택합니다.
2. **New Shell**을 선택합니다.

<Frame>
  <img src="/assets/mirror/shell-new-94a280c1230f.png" alt="현재 워크스페이스와 New Shell 옵션이 표시된 shell 인스턴스 메뉴" width="1280" height="224" data-path="images/workspace/shell-new.png" />
</Frame>

동일한 메뉴를 사용하여 shell 간을 전환하세요. Replit은 각 shell을 마지막으로 실행된 명령으로 표시하여 식별을 돕습니다.

<Warning>
  하나 이상의 shell을 열면 Replit이 유휴 shell 인스턴스를 자동으로 닫습니다.
  유휴 shell은 선택되지 않았고 실행 중인 사용자 프로세스가 없는 shell입니다.
</Warning>
