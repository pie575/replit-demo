<div id="data-protection">
  ## 数据保护
</div>

在 Replit，数据保护是我们的首要任务。我们采取全面的安全措施，保护您的数据并确保平台的完整性。

<div id="hosting-and-infrastructure">
  ### 托管和基础设施
</div>

Replit 的数据主要托管在美国的 Google Cloud Platform (GCP) 数据中心；对于选择启用的用户，也提供印度托管区域。我们利用 GCP 的企业级备份和恢复工具，确保：

<CardGroup cols={2}>
  <Card title="高可用性" icon="server">
    通过冗余系统和自动故障转移机制，防止服务中断和数据丢失
  </Card>

  <Card title="数据隔离" icon="layer-group">
    严格的逻辑隔离可防止不同用户和组织之间发生未授权访问
  </Card>
</CardGroup>

GCP 是业界领先的云服务提供商，符合 **ISO 27001** 和 **SOC 2 Type 2** 标准。此外，**Replit 已获得 SOC 2 Type 2 合规证明**，彰显了我们持续遵循安全最佳实践并实施安全控制措施的承诺。

每个客户端请求在访问任何私密信息前，都必须经过严格的**身份验证和授权**。

<div id="encryption-standards">
  ### 加密标准
</div>

<Note>
  Replit 对处于各种状态的数据实施全面加密，确保您的信息的机密性、完整性和安全性。
</Note>

<AccordionGroup>
  <Accordion title="传输加密" icon="shield-halved">
    采用行业标准的 **TLS 1.2+** 加密，保护客户端与我们服务器之间的所有通信，确保数据在网络传输过程中得到保护。这包括所有 API 调用、Web 流量、实时协作数据及其他通信。
  </Accordion>

  <Accordion title="静态数据加密" icon="database">
    存储在 GCP 中的数据采用 [**AES-256 服务器端加密**](https://cloud.google.com/docs/security/encryption/default-encryption) 进行保护。这一军用级加密标准可保护所有存储的数据，包括代码、配置、用户信息和系统元数据。
  </Accordion>

  <Accordion title="数据库安全" icon="lock">
    我们使用 **Google Cloud SQL** 提供[数据库加密](https://cloud.google.com/sql/references/additional-resources/faq#encryption-manage-rest)和[安全密钥管理](https://cloud.google.com/secret-manager)，通过自动加密、定期轮换密钥和细粒度访问控制，确保敏感数据始终受到保护。
  </Accordion>
</AccordionGroup>
