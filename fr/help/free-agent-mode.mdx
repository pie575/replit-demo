<Note>
  Certains détails relatifs à l&#39;allocation sont susceptibles d&#39;évoluer d&#39;ici au lancement.
</Note>

Free Mode permet aux abonnés Starter, Core et Pro d&#39;utiliser Agent sans frais supplémentaires. Starter inclut Free Mode dans le cadre de ses limites existantes. Core et Pro incluent une allocation Free Mode. Ouvrez une conversation pour explorer, planifier, créer ou demander de l&#39;aide. Si une demande nécessite un mode ou une action payante, Replit vous en informe clairement avant toute facturation.

<div id="why-youll-like-it">
  ## Pourquoi vous allez l’apprécier
</div>

* Commencez par une conversation plutôt que par une procédure de configuration.
* Explorez vos idées et avancez avant de décider si vous avez besoin de plus de capacités.
* Gardez le contrôle lorsqu’une demande nécessite une action payante.
* Repérez clairement l’étiquette **Free** sur le travail effectué en Free Mode.

<div id="how-it-works">
  ## Fonctionnement
</div>

1. Les nouvelles sessions Starter, Core et Pro démarrent en Free Mode.
2. Les tâches prises en charge par le Free Mode se poursuivent sans proposition d&#39;action payante.
3. Si un mode payant est mieux adapté à une demande, Agent vous l&#39;explique et vous laisse le choix.
4. Vous pouvez autoriser le mode payant pour cette demande uniquement, ou demander à Agent de poursuivre en Free Mode.
5. Après un passage ponctuel à un mode payant, vous revenez au Free Mode.

<div id="the-three-agent-modes">
  ## Les trois modes d’Agent
</div>

<CardGroup cols={3}>
  <Card title="Free">
    Utilisation gratuite d’Agent pour les abonnés Starter, Core et Pro.
  </Card>

  <Card title="Power">
    Un mode payant de niveau intermédiaire pour les tâches nécessitant davantage de capacités à un prix abordable.
  </Card>

  <Card title="Max">
    Un mode payant haut de gamme pour les tâches les plus exigeantes, avec les meilleurs modèles de pointe.
  </Card>
</CardGroup>

Free Mode est disponible pour les abonnés Starter, Core et Pro. Starter inclut Free Mode avec ses limites actuelles. Core et Pro incluent une allocation Free Mode, et Pro offre une limite hebdomadaire plus élevée. Vous pouvez également choisir un mode Agent payant lorsque vous avez besoin de davantage de capacités.

Avec Core et Pro, le routage intelligent des modèles constitue une alternative payante à Free Mode. Sélectionnez **Auto** dans Power ou Max pour laisser Replit choisir un modèle pour chaque tâche.

<Note>
  **Si vous atteignez une limite :** Starter inclut Free Mode avec ses limites actuelles. Pour Core et Pro, l’allocation Free Mode se réinitialise toutes les cinq heures et est soumise à une limite hebdomadaire. Consultez **Settings → Usage** pour voir où vous en êtes. Replit vous prévient à l’approche de la limite. Lorsque vous l’atteignez, passez à un mode payant pour continuer ou attendez la réinitialisation.
</Note>

<div id="common-questions">
  ## Questions fréquentes
</div>

<AccordionGroup>
  <Accordion title="Free Mode est-il vraiment gratuit ? Replit est-il désormais gratuit ?">
    Free Mode est inclus dans les abonnements Starter, Core et Pro. Starter inclut Free Mode avec ses limites actuelles. Core et Pro incluent une allocation Free Mode. Il ne s&#39;agit pas d&#39;une formule gratuite à part entière.
  </Accordion>

  <Accordion title="Est-ce la même chose qu'un mode Agent payant ?">
    Non. Free Mode permet d&#39;utiliser Agent sans frais, dans la limite de l&#39;allocation disponible. Power et Max sont des modes payants pour les tâches nécessitant davantage de capacités.
  </Accordion>

  <Accordion title="Qu'est-il arrivé à Economy et Power ? Les modes ont-ils changé ?">
    Les modes payants ont été renommés. Economy s&#39;appelle désormais Power, un mode intermédiaire proposant des modèles puissants à un prix abordable. Le mode auparavant appelé Power s&#39;appelle désormais Max, le mode haut de gamme. Les paramètres de mode existants sont conservés sous les nouveaux noms.
  </Accordion>

  <Accordion title="Quel mode est le plus performant ?">
    Max. Power est le mode payant intermédiaire qui offre davantage de capacités à un prix abordable. Max est le mode payant haut de gamme pour les tâches les plus exigeantes.
  </Accordion>

  <Accordion title="Que se passe-t-il si ma demande nécessite une action payante ?">
    Agent indique que la demande nécessite un mode ou une capacité payante et demande votre confirmation avant de poursuivre. Vous pouvez approuver cette demande une seule fois ou continuer à utiliser Free Mode.
  </Accordion>

  <Accordion title="Serai-je facturé automatiquement si Agent suggère une mise à niveau ?">
    Non. Le passage à une option payante nécessite votre confirmation avant le lancement de la demande payante.
  </Accordion>

  <Accordion title="Puis-je refuser l'option payante ?">
    Oui. Vous pouvez continuer à travailler dans Free Mode.
  </Accordion>

  <Accordion title="Que se passe-t-il après avoir approuvé un passage à une option payante ?">
    L&#39;approbation s&#39;applique uniquement à cette demande. Votre mode Agent revient ensuite à Free Mode.
  </Accordion>

  <Accordion title="Pourquoi ai-je atteint une limite ? Quand est-elle réinitialisée ?">
    Starter inclut Free Mode avec ses limites actuelles. Pour Core et Pro, l&#39;allocation Free Mode est réinitialisée toutes les cinq heures et est soumise à une limite hebdomadaire. Consultez **Settings → Usage** pour connaître votre consommation. Lorsque vous atteignez la limite, passez à un mode payant pour continuer ou attendez la réinitialisation.
  </Accordion>

  <Accordion title="Free Mode est-il disponible sur Enterprise ?">
    Non. Les workspaces Enterprise utilisent à la place un seul mode Auto. Il sélectionne le mode et un modèle autorisé pour chaque tâche. Consultez [les contrôles des modèles Enterprise](/fr/features/collaboration/enterprise-model-controls).
  </Accordion>
</AccordionGroup>

<div id="more-about-free-mode">
  ## En savoir plus sur le Free Mode
</div>

<AccordionGroup>
  <Accordion title="Le Free Mode est-il la même chose que Lite ?">
    Pour les utilisateurs Starter, l&#39;expérience auparavant appelée Lite devient le Free Mode. Si vous utilisiez Lite pour accéder à un modèle moins coûteux, vous pouvez toujours sélectionner ce modèle manuellement dans Power en désactivant le mode Auto.
  </Accordion>

  <Accordion title="Le Free Mode peut-il créer une application complète ?">
    Oui. Vous pouvez créer et faire évoluer des applications complètes en Free Mode.
  </Accordion>

  <Accordion title="Quelles sont les différences entre Free, Power et Max ?">
    Le Free Mode couvre le travail quotidien avec Agent, sans frais, pour les abonnés Starter, Core et Pro. Starter inclut le Free Mode avec ses limites existantes. Core et Pro incluent une allocation Free Mode. Power est le mode payant intermédiaire, qui offre plus de capacités à un prix abordable. Max est le mode payant haut de gamme, destiné aux travaux les plus exigeants.
  </Accordion>

  <Accordion title="Quand faut-il quitter le Free Mode ?">
    Restez en Free Mode pour le travail quotidien. Changez de mode lorsque vous souhaitez de meilleurs résultats sur une tâche complexe ou que vous avez besoin d&#39;une fonctionnalité que le Free Mode ne propose pas.
  </Accordion>

  <Accordion title="Le Free Mode peut-il générer des vidéos ?">
    Non. La génération de vidéos est réservée aux modes payants et ne fait pas partie du Free Mode.
  </Accordion>

  <Accordion title="En quoi consiste la nouvelle expérience Conversations ?">
    Le Chat et la création restent réunis. Vous pouvez explorer une idée, planifier votre travail ou démarrer un projet depuis une même conversation.
  </Accordion>

  <Accordion title="Les chats autonomes font-ils partie d'une application publiée ?">
    Non. Une conversation reste distincte tant que vous ne créez ou ne modifiez pas un projet.
  </Accordion>

  <Accordion title="Le Free Mode peut-il travailler sur un projet existant ?">
    Oui. Il prend en charge la maintenance courante et les modifications sur les projets existants.
  </Accordion>
</AccordionGroup>

**Prêt à l&#39;essayer ?** Dès le lancement du Free Mode, ouvrez une conversation avec Agent et lancez-vous.
