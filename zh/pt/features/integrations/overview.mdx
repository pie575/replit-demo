Agent 支持四种集成类型，助你快速把创意变成应用：

* **Replit 托管**：内置集成，开箱即用。创建应用后，Agent 即可立即调用。
* **连接器**：由 Replit 官方支持的自有集成。只需登录一次，Agent 就能通过 Chat 直接读写这些服务——获取数据、创建记录、发送消息——并在你的所有应用中基于它们进行构建。
* **外部集成**：可用于构建应用的可信第三方服务。让 Agent 帮你完成配置，你只需提供 API 密钥。
* **Agent 服务**：Agent 在后台使用的第三方付费 API——无需 API 密钥。用量将从你的 Replit 积分中扣除。

<Note>
  **各方案的可用性**：大多数连接器需要 Core、Pro 或 Enterprise 订阅，部分连接器在免费方案中即可使用。你 workspace 中的连接器目录会显示当前方案可使用哪些连接器。使用免费方案的构建者始终可以使用 Replit 托管的集成，例如数据库、身份验证等。
</Note>

<div id="primeiros-passos">
  ## 快速上手
</div>

要使用某项集成，只需提及你需要的服务或功能即可。例如：

<AiPrompt>
  Create a web app that uses Stripe to accept payments and SendGrid to send confirmation emails
</AiPrompt>

Agent 会自动识别这些关键词，并生成所需的代码和配置。

<div id="deixe-o-agent-sugerir-um-conector">
  ### 让 Agent 推荐 连接器
</div>

有时多个服务可以完成同样的工作，比如存储文件或发送邮件。当你提出某项功能需求但没有指定身份提供方时，Agent 会列出一份符合需求的连接器简短清单，你可以任选其一。

选择身份提供方后登录一次即可连接你的账户，Agent 在构建时会采用你的选择。你也可以直接按名称指定某个服务，跳过这份清单。

<div id="conectores">
  ## 连接器
</div>

连接器让 Agent 能够直接读写你所使用的各项服务。它们是由 Replit 官方提供支持的原生集成。在 Project Editor 的连接器页面登录一次，即可在所有应用中复用这些连接。

<Note>
  这些连接与你的 Replit 账户绑定，并在你的所有应用中长期有效。一个服务只需连接一次，就能在你创建的任何应用中使用。
</Note>

<div id="configurando-um-app-oauth-com-o-replit">
  ### 在 Replit 中配置 OAuth 应用
</div>

<Note>
  **仅限 Enterprise**：配置自定义 OAuth 应用需要 Enterprise 订阅。
</Note>

在 Enterprise 计划中，你可以为连接器使用自己的 OAuth 应用，而不必使用 Replit 的默认应用。这样，你的组织可以拥有 OAuth 客户端、在授权同意页面上展示自有品牌，并精确控制构建者可申请的权限范围。

要使用自己的 OAuth 应用配置连接器，你需要从身份提供方获取三样东西：**Client ID**、**Client Secret** 以及你希望授权的**权限范围**。你还需要在身份提供方处注册 Replit 的回调 URL，身份验证才能顺利完成。

<Frame>
  <img src="/assets/mirror/connector-oauth-configuration-100911ce0c48.png" alt="连接器 的 OAuth 配置对话框，包含 Client ID、Client Secret 和 Connector 权限范围字段，以及设置为 https://replit.com/connectors/oauth/callback 的重定向 URL" width="1112" height="1218" data-path="images/replitai/connector-oauth-configuration.png" />
</Frame>

<Steps>
  <Step title="在身份提供方处创建 OAuth 应用">
    登录身份提供方的开发者控制台或管理员设置，创建一个新的 OAuth 2.0 应用。不同身份提供方对这一步的叫法各不相同——请查找类似**创建 OAuth 应用**、**注册应用程序**或**创建客户端凭据**的选项。
  </Step>

  <Step title="设置重定向 URL">
    当身份提供方要求填写**授权重定向 URI** (有时称为**回调 URL**或**重定向 URL**) 时，请输入：

    ```
    https://replit.com/connectors/oauth/callback
    ```

    构建者授权应用后，身份提供方会通过这个 URL 将他们送回 Replit。该地址必须完全一致——末尾斜杠、协议和子域都不能有出入。如果你添加了多个重定向 URI，其中必须包含这一个。
  </Step>

  <Step title="复制 Client ID 和 Client Secret">
    创建应用后，身份提供方会显示一个 **Client ID** 和一个 **Client Secret**。

    * **Client ID**：你的 OAuth 应用的公开标识符，可以安全地出现在 URL 和客户端代码中。
    * **Client Secret**：用于证明请求来自你的应用的机密值。请像对待密码一样对待它——切勿将其提交到代码仓库或公开分享。Replit 会为你安全地存储它。

    有些身份提供方只在创建时显示一次 client secret。请立即复制并妥善保管，直到你将其粘贴到 Replit 中。
  </Step>

  <Step title="选择权限范围">
    **权限范围**即一组权限，用于定义你的 OAuth 应用可以代表构建者读取或写入哪些内容。每个身份提供方都会在其 API 文档中公布自己的权限范围列表。

    在 Replit 中配置连接器时，你输入的权限范围必须与你在身份提供方处注册的权限范围**完全一致** (逐字符一致，包括任何 URL 前缀) 。出现不匹配错误的常见原因包括：

    * 缺少完整的 URL 前缀 (例如写成 `drive.file` 而不是 `https://www.googleapis.com/auth/drive.file`) 。
    * 多余的空白字符或末尾的逗号。
    * 在 Replit 中申请了身份提供方应用中未启用的权限范围。

    建议先从构建者所需的最小权限范围开始，之后如有需要再添加——大多数身份提供方都允许更新权限范围，无需重新创建应用。
  </Step>

  <Step title="在 Replit 中配置连接器">
    在你所在组织的 **连接器** 页面上，选择**添加新集成**，选择相应服务，然后粘贴身份提供方的 **Client ID**、**Client Secret** 和**权限范围**。选择**配置**进行保存。
  </Step>
</Steps>

<Note>
  如果配置完成后身份验证仍然失败，请再次检查在身份提供方注册的重定向 URL 是否与 `https://replit.com/connectors/oauth/callback` 完全一致，并确认在 Replit 中填写的每个权限范围都已在身份提供方的应用中获得授权。
</Note>

</Note>

<div id="reconectando-integraes">
  ## 重新连接集成
</div>

如果某个已连接的服务停止工作 (例如登录会话过期或权限发生变更) ，Replit 会在 Project Editor 中显示重新连接提醒。点击该提醒即可直接重新连接集成，无需离开编辑器。

<div id="depurando-conectores">
  ## 调试 连接器
</div>

连接服务时遇到问题？以下指南汇总了最常见的错误及其解决方法。

<AccordionGroup>
  <Accordion title="Google Workspace：&#x22;This app is blocked&#x22;">
    如果在连接 Google Drive、Docs、Sheets、Calendar 或 Gmail 时看到 **&quot;This app is blocked&quot;**，很可能是你所在组织的 Google Workspace 限制了第三方 OAuth 应用。请参阅完整的故障排查指南来解决该问题。

    [解决 Google 连接器 的 &quot;This app is blocked&quot; 问题](/zh/pt/features/troubleshooting/debugging-google-connectors)
  </Accordion>

  <Accordion title="Salesforce：&#x22;Connection Expired&#x22;">
    如果你的 Salesforce 连接器 停止工作并报 **&quot;Connection Expired&quot;** 错误，很可能是你所在组织在 Salesforce 中的 refresh token 策略设置为令牌在一定时间后过期。请参阅完整的故障排查指南来更新 Connected App 的设置。

    [修复 Salesforce 连接过期错误](/zh/pt/features/troubleshooting/debugging-salesforce-connectors)
  </Accordion>
</AccordionGroup>
