---
title: "扩展你的项目"
description: "为现有项目添加移动应用、幻灯片演示文稿等内容，全部共享同一个后端。"
---

⏰ *预计耗时：5 分钟* · 接着阅读[创建你的第一个应用](/zh/pt/getting-started/quickstarts/ask-ai)

你已经创建了一个 Web 应用。现在可以在此基础上继续扩展：添加移动应用、幻灯片演示文稿或其他内容，全部在同一个项目中完成。它们共享相同的数据和后端，因此无需从头开始。

<div id="antes-de-comear">
  ## 开始之前
</div>

你需要有一个现有的 Replit 项目，可以是之前快速入门指南中创建的项目，也可以是你创建的任何其他项目。

<div id="seu-projeto-pode-fazer-mais-de-uma-coisa">
  ## 您的项目可以实现不止一种用途
</div>

创建第一个应用时，您创建的是一个 Web 应用。但 Replit 中的一个项目并不局限于一种输出。您可以添加可在手机上运行的**移动应用**、用于展示想法的**幻灯片演示文稿**、**动画视频**等——所有内容都可以在同一个项目中共存。

这些被称为**产物**。每个产物本身都是可发布的输出，但它们在后台共享相同的代码和数据。一次创建，随处发布。

<div id="adicione-um-aplicativo-mobile">
  ## 添加移动应用
</div>

<Steps>
  <Step title="让 Agent 创建移动版本">
    告诉 Agent 你的需求：

    ```
    为此应用添加移动版本
    ```

    你还可以点击预览面板中的 **+** 按钮，添加新的产物。

    <Frame>
      <video autoPlay muted loop playsInline src="/assets/mirror/design_mobile_app_canvas-a67a35b27fd4.mp4" />
    </Frame>

    Agent 会创建一个与 Web 应用共享同一后端的移动应用——你已创建的数据和逻辑都会自动迁移。
  </Step>

  <Step title="在手机模拟器中预览">
    Agent 完成后，预览面板会显示在手机模拟器中运行的移动应用。像使用真实手机一样操作和测试。
  </Step>

  <Step title="在应用之间切换">
    使用 **预览面板** 中的下拉菜单，在 Web 应用和移动应用之间切换。

    <Frame>
      <video autoPlay muted loop playsInline src="/assets/mirror/switch_artifacts-bc0ae3999898.mp4" />
    </Frame>

    你还可以让 Agent：

    ```
    显示 Web 应用
    ```
  </Step>
</Steps>

<div id="adicione-ainda-mais-ao-seu-projeto">
  ## 为你的项目添加更多内容
</div>

你的项目不局限于 Web 和移动应用。你还可以让 Agent 创建其他类型的产物：

* **幻灯片演示文稿** — “为此应用创建一份演示文稿”
* **动画视频** — “为此应用制作一段简短的说明视频”
* **数据可视化** — “创建一个展示使用统计数据的仪表板”
* **文档** — “撰写一份介绍此应用的摘要”

每一项都会成为你项目中的新产物，并可通过专属 URL 分享。

<div id="publique-seu-projeto">
  ## 发布您的项目
</div>

点击**发布**后，项目中的所有产物都会一同上线。您的 Web 应用、移动应用和幻灯片演示文稿将各自拥有独立的 URL，并连接到同一后端。

详见[发布您的应用](/zh/pt/getting-started/quickstarts/publish)。
