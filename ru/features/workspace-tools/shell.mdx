Shell позволяет работать с проектами, как в обычном терминале: управлять файлами,
устанавливать пакеты и запускать скрипты. Например, можно просматривать файлы проекта или
использовать `psql`, если в проекте настроено подключение к базе данных.

<Tip>
  Для более удобной работы используйте кнопку **Run**, а не запускайте приложение из
  Shell. Рабочий процесс, запускаемый кнопкой **Run**, направляет вывод в Console, где
  логи удобно просматривать в структурированном виде.
</Tip>

<div id="features">
  ## Возможности
</div>

Shell поддерживает следующие возможности:

* **Запуск нескольких Shell**: Открывайте несколько экземпляров Shell, чтобы одновременно работать над разными задачами
* **Поиск текста**: Находите нужный текст в выводе Shell

<div id="confirm-shell-access">
  ### Проверьте доступ к Shell
</div>

Чтобы убедиться, что Shell готов к работе, и просмотреть текущее рабочее пространство, выполните:

```sh theme={null}
pwd
```

Shell выводит путь к текущему рабочему пространству.

<Frame caption="Команда pwd выводит путь к текущему рабочему пространству и возвращает к приглашению Shell.">
  <img src="/assets/mirror/shell-pwd-output-2d31a0e0466b.jpg" alt="Вкладка Shell с командой pwd, путём к рабочему пространству в выводе и приглашением Shell" width="1280" height="246" data-path="images/workspace/shell-pwd-output.jpg" />
</Frame>

Для проекта с базой данных выберите **Инструменты** → **база данных**, затем откройте
страницу **База данных для разработки**. На этой странице доступны элементы управления подключением. Не разглашайте
параметры подключения: не копируйте их в документацию, снимки экрана,
логи, исходные файлы или общие сообщения.

<div id="text-search">
  ### Поиск текста
</div>

Чтобы открыть и использовать инструмент поиска текста, выполните следующие действия:

1. Нажмите <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="иконка лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> в правом верхнем углу вкладки Shell, чтобы открыть диалог поиска.
2. Введите поисковый запрос и нажмите **Next**, чтобы перейти к следующему совпадению.
3. Используйте **Previous**, чтобы вернуться к предыдущему совпадению.
4. Нажмите **Exit** или щёлкните за пределами диалога, чтобы закрыть поиск текста.

<div id="multiple-shells">
  ### Несколько Shell
</div>

Чтобы открыть ещё один Shell:

1. В заголовке панели Shell выберите меню экземпляра Shell.
2. Выберите **New Shell**.

<Frame>
  <img src="/assets/mirror/shell-new-94a280c1230f.png" alt="Меню экземпляра Shell с текущим рабочим пространством и пунктом New Shell" width="1280" height="224" data-path="images/workspace/shell-new.png" />
</Frame>

Используйте то же меню для переключения между Shell. Чтобы вам было проще их различать, Replit помечает каждый Shell последней выполненной командой.

<Warning>
  Если открыть несколько Shell, Replit автоматически закрывает неактивные
  экземпляры Shell. Неактивный Shell не выбран и не выполняет пользовательские процессы.
</Warning>
