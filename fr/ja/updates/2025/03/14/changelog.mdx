<div id="neon-db">
  ### Rétention de l’historique de Neon DB
</div>

La rétention d’historique configurable pour les bases de données Neon est désormais disponible, ce qui vous permet de mieux gérer vos coûts. Cette fonctionnalité répond directement à vos retours concernant la gestion des coûts des bases de données.

<div id="section-3">
  ### Contexte des liens amélioré
</div>

Vous pouvez désormais prévisualiser en direct le contenu des liens (captures d’écran et texte) dans Assistant et Agent. Cette fonctionnalité est également disponible dans l’application mobile Replit.

<div id="section-4">
  ### Amélioration des performances de la vue web
</div>

Profitez d’une navigation plus fluide dans les iframes et d’une meilleure compatibilité avec les sites web sécurisés. Le système proxy a été amélioré pour gérer plus intelligemment les en-têtes de sécurité, ce qui élimine les blocages de navigation rencontrés auparavant.
