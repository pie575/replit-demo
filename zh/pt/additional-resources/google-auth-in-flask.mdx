让用户使用 Google 账户登录你的网站有以下好处：

1. 你无需自行实现一套身份验证方案。
2. 你可以轻松获取用户的姓名和联系信息。
3. 你可以使用同一套凭证访问用户的 Google 资源，例如 Sheets 和 Drive。

本指南将带你在 Replit 上使用 Python 和 Flask 实现这一功能。

我们先介绍如何配置基本的 OAuth 身份验证，再说明如何使用获得的凭证访问用户的 Google 资源。

<div id="introduo-ao-oauth">
  ## OAuth 简介
</div>

Google 身份验证基于 OAuth 标准。OAuth 的工作原理如下：

1. 在您的网站中设置一个入口，将用户引导至登录页面。
2. 当用户进入登录页面时，您无需在自己的网站上实现登录表单，而是将用户重定向到 Google 的登录服务进行身份验证。
3. 当 Google 的登录服务成功验证用户身份后，会将用户重定向回您预先指定的网站 URL，例如 `https://YOUR_DOMAIN/oauth2callback`，并发送一些与用户和登录会话相关的信息。
4. 您可以使用用户的登录信息获取访问令牌，它就像一张通行证，可用于访问用户的资源，例如个人资料信息、电子表格、文档等。

<div id="oauth-mostre-me-o-cdigo">
  ## OAuth：给我看代码
</div>

如果你和我一样，最想看到的是能直接运行的代码。下面的代码正是你需要的。不过，要让它正常运行，你还需要在 Google Cloud Console 中进行一些配置，下一节会介绍这些内容。使用 [Flask template](https://replit.com/@replit/Flask?v=1) 在 Replit 中创建一个新的 App，然后将以下内容放入 `main.py`。代码中的注释说明了各部分的作用：

```python theme={null}
from flask import Flask, redirect, session, url_for, request
import google_auth_oauthlib.flow
import json
import os
import requests

app = Flask('app')
# `FLASK_SECRET_KEY` 供会话使用。你应当生成一个随机字符串，
# 并将其保存为 secret。
app.secret_key = os.environ.get('FLASK_SECRET_KEY') or os.urandom(24)

# `GOOGLE_APIS_OAUTH_SECRET` 保存的是从 Google Cloud 凭据面板下载的
# JSON 文件的内容。详见下一节。
oauth_config = json.loads(os.environ['GOOGLE_OAUTH_SECRETS'])

# 这里为 OAuth 流程设置配置
oauth_flow = google_auth_oauthlib.flow.Flow.from_client_config(
    oauth_config,
    # scopes 定义认证完成后你希望代表用户访问哪些 API
    scopes=[
        "https://www.googleapis.com/auth/userinfo.email",
        "openid",
        "https://www.googleapis.com/auth/userinfo.profile",
    ]
)

# 这是登录页面的入口。它会重定向到位于 `authorization_url` 的 Google 登录服务。
# 而 `redirect_uri` 则是 Google 登录服务重定向回本应用时使用的 URI。
@app.route('/signin')
def signin():
    # 这里把 URL 从 http 改写为 https，因为 Replit App 内部用的是 http，
    # 而外部是通过 https 访问的，redirect_uri 必须与之一致
    oauth_flow.redirect_uri = url_for('oauth2callback', _external=True).replace('http://', 'https://')
    authorization_url, state = oauth_flow.authorization_url()
    session['state'] = state
    return redirect(authorization_url)

# 这是 Google 登录服务重定向回来的端点。必须把它添加到 Google Cloud 的 API 凭据面板中的
# “Authorized redirect URIs” 列表里。它会调用 Google 的端点请求访问 token，
# 并保存到用户会话中。此后即可用该访问 token 代表用户访问 API。
@app.route('/oauth2callback')
def oauth2callback():
    if not session['state'] == request.args['state']:
        return 'Invalid state parameter', 400
    oauth_flow.fetch_token(authorization_response=request.url.replace('http:', 'https:'))
    session['access_token'] = oauth_flow.credentials.token
    return redirect("/")

# 这是应用的主页。如果用户尚未登录，就引导其前往登录；
# 如果已登录，则显示用户的信息。
@app.route('/')
def welcome():
    if "access_token" in session:
        user_info = get_user_info(session["access_token"])
        if user_info:
            return f"""
                Hello {user_info["given_name"]}!<br>
                Your email address is {user_info["email"]}<br>
                <a href="/logout">Log out</a>
            """
    return """
        <h1>Hello!</h1>
        <a href="/signin">Sign In via Google</a><br>
    """

# 用有效的访问 token 调用 userinfo API 获取用户信息。
# 这是使用访问 token 代表用户访问 API 的第一个示例。
def get_user_info(access_token):
    response = requests.get("https://www.googleapis.com/oauth2/v3/userinfo", headers={
       "Authorization": f"Bearer {access_token}"
   })
    if response.status_code == 200:
        user_info = response.json()
        return user_info
    else:
        print(f"Failed to fetch user info: {response.status_code} {response.text}")
        return None

@app.route('/logout')
def logout():
    session.clear()
    return redirect('/')

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000)

```
