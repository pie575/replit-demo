      <Accordion title="我可以在哪里获得代码方面的帮助？">
        获取代码帮助的最佳途径是使用 [Replit AI](/zh/pt/build/welcome/)。在项目编辑器中，打开一个新标签页并搜索 **AI**。Replit AI 可以帮你搭建新项目、解答代码相关问题，并协助你理清思路。如需更多帮助，也可以访问我们的[社区中心](https://replit.com/community)获取更多资源。
      </Accordion>

      <Accordion title="我在使用 Replit 时遇到困难。如何获得帮助？">
        登录 Replit 后，点击页面右上角的 **?** 获取帮助。如需更多支持，请参阅[支持政策文档](/zh/pt/legal-and-security-info/support-policy)。
      </Accordion>

      <Accordion title="我可以在哪里获得账单方面的帮助？">
        在联系支持团队之前，请先在下方的**设置**中查看是否能找到解决方案。如果仍无法解决，请登录并点击页面右上角的 **?** 获取帮助。
      </Accordion>

      <Accordion title="我无法访问我的 Replit 账户 — 该怎么办？">
        请发送邮件至 `support@replit.com`，并附上你的账户用户名和登录 ID。
      </Accordion>

      <Accordion title="我什么时候会收到 Replit 的回复？">
        Replit 支持服务通常在周一至周五的上午 9 点至晚上 8 点 (美国东部标准时间，UTC-5) 提供。
      </Accordion>

      <Accordion title="如何在我的 Replit App 中恢复文件夹？">
        转到 Replit App 右上角的个人资料标识，选择 **CLUI**，然后在出现的搜索框中输入 *restore* 进行搜索。在搜索结果中，你会看到 **restore-folder** 选项，可用于从回收站恢复指定文件夹。

        > 注意：已删除的 Replit App 在原始删除日期起 **30 天**后将被永久删除且无法恢复。
      </Accordion>

      <Accordion title="如何恢复已删除的 Replit App？">
        转到 Replit App 右上角的个人资料标识，选择 **CLUI**，然后在出现的搜索框中输入 *restore* 进行搜索。在搜索结果中，你会看到 **restore-repl** 选项，可用于从回收站恢复指定的 Replit App。

        > 注意：已删除的 Replit App 在原始删除日期起 **30 天**后将被永久删除且无法恢复。
      </Accordion>

      <Accordion title="为什么我的 Replit App 加载失败？">
        如果你的 Replit App 加载失败，请尝试以下排查步骤：

        1. 测试你的[网络连接](https://www.speedtest.net/)。
        2. 换用其他浏览器试试。
        3. 确认浏览器已启用 JavaScript。
        4. 使用 `Cmd+K` (Mac) 或 `Ctrl+K` (Windows) 打开命令面板，搜索 **Restart compute** 并选择该命令。

        如果以上步骤都无效，请查看 Replit 的[服务状态](https://status.replit.com)。如果状态显示为 **All systems are go!**，但你的 Replit App 仍然无法加载，请联系 [Replit 支持](https://replit.com/support)。
      </Accordion>

      <Accordion title="如何将大文件上传到我的 Replit App？">
        如果文件过大，无法通过图形界面完成常规上传，你可以使用 `scp` (安全复制) 通过 [SSH](/zh/pt/features/workspace-tools/ssh) 在本地和远程系统之间安全地传输文件。要将文件从本地计算机复制到远程计算机，请使用以下语法：`scp filename username@ip_address:/home/username`

        你也可以使用 scp 复制整个目录。
      </Accordion>

      <Accordion title="如何查看我的使用额度余额？">
        你可以在 [https://replit.com/~/cli/account/usage-credits-balance](https://replit.com/~/cli/account/usage-credits-balance) 查看当前余额。
      </Accordion>

    <AccordionGroup>
      <Accordion title="我无法登录，该怎么办？">
        1. 请确认您使用的邮箱和密码正确无误。
        2. 如需重置密码，请访问[忘记密码页面](https://replit.com/forgot)。请检查垃圾邮件文件夹，查找由 `notifications@replit.com` 发送的重置邮件。
        3. 尝试换一个浏览器登录。

        如果以上步骤均无效，请[联系支持团队](https://replit.com/support)。
      </Accordion>

      <Accordion title="使用 Google/GitHub/Facebook/Apple 注册后，如何更改邮箱？">
        更改账户邮箱需要密码。如果您是通过 Google 或 GitHub 等第三方身份验证服务注册的，则需要先创建密码。

        创建密码的步骤：

        1. 打开侧边栏并退出登录。
        2. 返回登录页面，选择[忘记密码](https://replit.com/forgot)，然后输入您的邮箱地址。
        3. 您会收到一封包含创建新密码链接的邮件。如果没有找到该邮件，请检查垃圾邮件文件夹，并最多等待三十分钟。
        4. 登录后，打开[设置](https://replit.com/settings)即可更改邮箱地址。
      </Accordion>

      <Accordion title="如何更改我的用户名？">
        Replit 用户只能更改用户名**一次**。请访问 [CLUI](https://replit.com/~/cli/account/change-username?run=1) 并选择 **change-username**。如果该选项不可用，说明您已经更改过了。
      </Accordion>

      <Accordion title="什么是 Explorer 模式，如何启用？">
        Explorer 是指选择抢先体验并测试开发中新功能的 Replit 用户。要启用 Explorer 模式，请打开[设置](https://replit.com/settings)并打开 Explorer 开关 (例如在**账户**或**用户**中) 。
      </Accordion>
    </AccordionGroup>
