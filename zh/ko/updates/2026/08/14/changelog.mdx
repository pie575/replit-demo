<div id="clerk-auth">
  ### 迁移到 Clerk Auth
</div>

现在，你可以将符合条件的 Replit Auth 应用切换到 Clerk Auth。Agent 会先迁移账户数据，再更新登录代码，因此现有用户可继续访问自己的数据。

</Frame>

  ### 请求内联图表
</div>

<div id="section-6">
  ### 工作区技能共享与管理
</div>

现在，所有工作区成员都可以创建技能，并选择将其保持私有或共享给整个工作区。共享的技能对其他成员默认处于关闭状态，每位成员可自行决定启用哪些技能。管理员可以统一管理所有工作区技能，并将特定技能设为工作区的必备技能。全新设计的 Skills 库让技能查找与管理更加轻松。

详细了解 [Agent Skills](/zh/ko/features/agent/skills)。

<div id="section-7">
  ## 团队与企业版
</div>

<div id="admin-api">
  ### Admin API beta 版发布
</div>

企业版账户管理员现在可以在设置中新增的 **Developer** 标签页创建 API 密钥，并使用 Admin API 执行以下操作：

* 查看工作区、成员、用户群组、项目和部署。
* 按指定时间范围查看成员、项目和工作区的用量。
* 查看并修改工作区、用户群组以及单个成员的预算。

请查阅 [Admin API 文档](/zh/ko/teams/admin-api)和 [API 参考](https://api.replit.com/docs)了解更多信息。
