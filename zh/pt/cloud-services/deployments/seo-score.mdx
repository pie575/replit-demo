在 Replit 上发布 Web App 时，系统会自动审核其已上线 URL 的搜索引擎优化 (SEO) 情况，并在 Publishing 工具中显示 0 到 100 的 SEO 评分。如果评分仍有提升空间，只需点击一下，即可将具体问题交给 Agent，在几秒钟内完成修复。

对大多数开发者来说，完整流程是：发布 App、查看评分，然后让 Agent &quot;优化我的 SEO&quot;。本页将介绍其背后的工作原理，以及如何充分利用这项功能。

<div id="o-que-seo-e-por-que-importa">
  ## 什么是 SEO，以及它为何重要
</div>

搜索引擎优化 (SEO) 是指通过优化网站，让 Google 等搜索引擎能够找到、理解并对其进行排名。良好的 SEO 能让用户在搜索你提供的内容时找到你的 App，而无需付费投放广告。

影响 SEO 效果的主要因素包括：清晰的页面标题和描述、语义化 HTML、快速的加载速度、适配移动设备的布局、图片的描述性替代文本，以及便于抓取的网站结构。搜索引擎会青睐既方便用户阅读，又便于机器理解的网站。

如果你正在发布落地页、营销网站、博客、目录，或任何重视可发现性的内容，那么 SEO 是早期最值得投入的领域之一。

<div id="como-o-replit-melhora-o-seu-seo-por-padro">
  ## Replit 如何默认优化您的 SEO
</div>

Replit 可为您处理许多 SEO 基础工作，让您专注于内容和产品：

* **快速的全球分布式托管**：Replit Deployments 通过为速度优化的基础设施提供您的应用，您还可以通过 [发布地理位置](/zh/pt/cloud-services/deployments/publishing-geography) 选择应用的运行位置。
* **默认启用 HTTPS**：每个已发布的应用都会获得由 Replit 管理的 TLS 证书，这是搜索引擎的一项基本排名信号。
* **自定义域名**：连接您自己的域名，建立品牌信任和权威性。请参阅 [自定义域名](/zh/pt/cloud-services/deployments/custom-domains)。
* **适用于内容网站的静态部署**：对于营销页面、博客和文档，[静态部署](/zh/pt/cloud-services/deployments/static-deployments) 会提供预渲染的 HTML，便于搜索引擎抓取。
* **Agent 可编写符合 SEO 最佳实践的代码**：当 Agent 构建页面时，默认会生成语义化 HTML、无障碍标记和元标签——这些正是 SEO 工具会检查的内容。
* **SEO 评分功能**：每次部署后自动进行审核，让您随时了解当前状况，并可一键让 Agent 修复发现的问题。

<div id="o-recurso-pontuao-de-seo">
  ## SEO 评分功能
</div>

每次成功部署后，Replit 都会对您的 部署 URL 运行 Lighthouse 审核并保存结果。随后，Publishing 工具会显示您 App 的整体 SEO 评分。

<div id="onde-encontrar">
  ### 在哪里查看
</div>

在已发布的 App 中打开 **Publishing** 工具。SEO 评分会显示在部署概览中，与其他 build 详情一同呈现。将鼠标悬停在评分上，即可查看 Lighthouse 为各页面识别出的具体操作项。

<div id="como-interpretar-sua-pontuao">
  ### 如何解读您的评分
</div>

Replit 使用 Lighthouse 的默认阈值：

| 评分     | 状态   | 含义                                |
| :----- | :--- | :-------------------------------- |
| 90–100 | 良好   | 您的 App 遵循 SEO 最佳实践。进行重大更改后，请留意评分。 |
| 50–89  | 需要改进 | 多个问题限制了搜索引擎对该 App 的理解。            |
| 0–49   | 较差   | 缺少基本的 SEO 元素。修复这些问题通常只需几分钟。       |

如果您的 App 包含多个页面，徽章会显示 Replit 抓取的所有 URL 中的**最低**评分，以便优先显示表现最差的页面，而不会被平均分掩盖。

<div id="quando-a-pontuao-calculada">
  ### 何时计算评分
</div>

每次成功部署后，系统都会自动运行审核。部署上线后一两分钟内通常即可完成评分，Publishing 工具会在结果生成后立即更新徽章。

<div id="tipos-de-deployment-compatveis">
  ### 支持的部署类型
</div>

SEO 评分适用于面向 Web 的公开部署，搜索引擎可抓取其 URL：

* [Autoscale 部署](/zh/pt/cloud-services/deployments/autoscale-deployments)
* [Reserved VM 部署](/zh/pt/cloud-services/deployments/reserved-vm-deployments)
* [静态部署](/zh/pt/cloud-services/deployments/static-deployments)

定时部署和私有部署不提供公开 Web 访问，因此不会生成 SEO 评分。

<div id="otimizar-seo-com-o-agent">
  ## 使用 Agent 优化 SEO
</div>

当 SEO 评分低于 90 时，评分旁会显示 **使用 Agent 优化 SEO** 按钮。点击该按钮后，Lighthouse 针对每个已检查 URL 识别出的具体待办事项会直接发送到与 Agent 的新对话中，并附带修复指示。

<Tip>
  您也可以直接跳过该按钮。打开 Agent 并输入 **“优化我的 SEO”**，Agent 会获取最新的 Lighthouse 结果并开始处理。
</Tip>

Agent 完成更改后，请重新发布您的 App。系统会根据新 build 重新计算 SEO 评分，并自动更新徽章。

Agent 常会应用以下修复：

* 添加或重写缺失或过于通用的 `<title>` 标签，确保每个页面都有唯一且描述清晰的标题
* 为每个页面添加 meta 描述
* 为图片添加描述性的 `alt` 文本
* 在 `<html>` 元素上设置 `lang` 属性
* 确保链接包含可识别的文本 (避免使用“点击此处”或空锚点)
* 添加 `robots.txt` 和 `sitemap.xml`
* 添加 viewport meta 标签，确保在移动设备上正确渲染
* 改善未通过无障碍检查的文本颜色对比度
* 添加 Open Graph 和 Twitter 卡片元标签，确保您的 App 链接能在社交平台上正确预览

<div id="melhores-prticas-para-um-site-otimizado-para-seo-no-replit">
  ## 在 Replit 上打造 SEO 优化网站的最佳实践
</div>

无论是让 Agent 处理这些任务，还是自行开发，以下措施对在 Replit 上创建的应用最有帮助：

* **为每个页面设置唯一的标题和元描述。** 尽量将标题控制在 60 个字符以内，描述控制在约 150 到 160 个字符。
* **使用语义化 HTML。** 使用 `<main>`、`<header>`、`<nav>` 和 `<footer>` 组织页面布局。每页只使用一次 `<h1>`，并按顺序安排标题层级。
* **为每张图片添加替代文本。** 描述图片展示的内容，而不只是图片的类型。
* **生成 `sitemap.xml` 和 `robots.txt`。** 请 Agent 创建这两个文件，让搜索引擎知道该抓取哪些内容。
* **添加 Open Graph 标签和 Twitter 卡片。** 控制你的应用在社交媒体上被分享时的显示方式。
* **使用自定义域名。** 带有你品牌的域名能让访客和搜索引擎更信任你。请参阅 [Custom Domains](/zh/pt/cloud-services/deployments/custom-domains)。
* **选择合适的部署类型。** 对于内容较多的网站，[静态部署](/zh/pt/cloud-services/deployments/static-deployments)可提供预渲染 HTML，供搜索引擎即时解析。
* **添加结构化数据。** JSON-LD 标记可帮助搜索引擎为产品、文章、常见问题和活动展示富媒体搜索结果。
* **保持应用快速响应。** 优化图片，避免使用阻塞渲染的脚本，并利用 Replit 托管服务缩短响应时间。

以下是一种可一次性应用大多数这些实践的简单方法：

<AiPrompt>
  检查我的网站是否符合 SEO 最佳实践，并修复发现的问题。添加 sitemap、robots.txt、Open Graph 标签，并在适当的地方添加结构化数据，同时确保每个页面都有唯一的标题和元描述。
</AiPrompt>
