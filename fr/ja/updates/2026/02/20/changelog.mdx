<div id="pro">
  ## Lancement du forfait Pro
</div>

Replit Pro est désormais disponible, et Core offre encore plus de valeur. Nous avons clarifié les forfaits pour mieux répondre à vos besoins :

* **Replit Pro** : conçu pour les builders exigeants — mode Turbo (Agent 2,5 fois plus rapide, via un bouton distinct), crédits progressifs reportables, jusqu’à 15 builders sans frais par utilisateur, assistance prioritaire et durée de conservation des données 4 fois plus longue. [En savoir plus sur Pro](/fr/ja/billing/plans/replit-pro).
* **Core** : invitez jusqu’à 5 collaborateurs sans frais supplémentaires. Consultez les tarifs actuels de Core sur la [page des tarifs](https://replit.com/pricing).
* **Fin du forfait Teams** : Teams est remplacé par Pro. Les clients Teams existants passeront à Pro sans frais supplémentaires pour le reste de leur période d’abonnement. La migration commencera le {TeamsMigrationDate}. [Détails et calendrier](https://blog.replit.com/pro-plan).
* **Modes Agent** : choisissez **Economy** (optimisé pour les coûts) ou **Power** (axé sur les performances). **Turbo** est disponible via un bouton distinct (Pro/Enterprise uniquement, 2,5 fois plus rapide). [Guide des modes Agent](/fr/core-concepts/agent/agent-modes).
* **Fast Mode devient Lite Mode** : mêmes modifications rapides et ciblées — le nom a été mis à jour dans le produit et la documentation. [Mode Lite](/fr/core-concepts/agent/agent-modes).
* **Optimisation du code** : le paramètre qui contrôle la façon dont Agent examine son propre code (anciennement « niveau d’autonomie ») a été renommé « optimisation du code ». [Revue de code](/fr/ja/features/agent/agent-modes#code-review).
* **Collaboration** : la collaboration est améliorée dans tous les forfaits payants — espaces de travail illimités, partage simplifié, paramètres unifiés et suivi de l’utilisation par espace de travail. Core : 5 collaborateurs, Pro : 15 builders.

<div id="section-3">
  ### Compression de la mémoire en arrière-plan
</div>

Agent ne suspend plus les workflows pour optimiser sa mémoire. Auparavant, le message « La mémoire d’Agent a été optimisée » s’affichait et la progression était bloquée pendant plus de 30 secondes. Cette opération s’effectue désormais de manière transparente en arrière-plan, ce qui permet à Agent de rester réactif pendant que vous travaillez.

<div id="section-4">
  ### Accès aux journaux des déploiements en production
</div>

Agent peut désormais accéder aux journaux de déploiement en production, ce qui lui permet d’identifier et de corriger les erreurs à partir de données de production réelles. D’autres améliorations du débogage en production seront bientôt disponibles.

<div id="section-5">
  ### Recherche de compétences
</div>

La recherche de compétences vous permet de découvrir et d’installer directement depuis Replit des compétences populaires, sans avoir à saisir de prompt dans Agent ni à importer manuellement des fichiers.

<div id="razorpaymcp">
  ### Intégration Razorpay MCP
</div>

L’intégration Razorpay MCP est désormais disponible et étend les fonctionnalités de paiement pour les créateurs d’applications en Inde. Connectez Razorpay à votre projet Replit pour accepter des paiements, gérer des commandes et traiter des remboursements directement via Agent.

La liste MCP par défaut sur [replit.com/integrations](https://replit.com/integrations) a été enrichie afin de vous permettre de connecter de nouvelles intégrations en un clic.

<div id="video-stack">
  ### Video Stack
</div>

Video Stack vous permet de créer des vidéos animées par programmation à partir d’images et de vidéos générées, afin de produire des visuels créatifs en mouvement. Vous pouvez réaliser des vidéos animées complètes uniquement avec du code dans un projet Replit.

  ### Paramètres de publication des déploiements
</div>
