<div id="agent-now-has-access-to-replit-docs">
  ### Agent теперь имеет доступ к документации Replit
</div>

Теперь Agent может мгновенно отвечать на ваши вопросы о функциях и документации Replit. Благодаря прямому доступу ко всей документации Replit Agent предоставляет быструю, точную и исчерпывающую помощь прямо в процессе разработки.

<div id="visual-editor-color-picker-improvement">
  ### Улучшение выбора цвета в Visual Editor
</div>
