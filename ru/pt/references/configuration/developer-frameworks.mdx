  ## Что такое фреймворк для разработчиков?
</div>

Фреймворки для разработчиков — это Replit App, опубликованные Replit и сообществом, которые можно использовать как отправную точку. Официальные фреймворки для разработчиков от Replit отмечены галочкой рядом с названием:

  <img src="/assets/mirror/template-official-c5fe09e20415.png" alt="Официальные фреймворки для разработчиков Replit" width="1051" height="246" data-path="images/programming-ide/creating-a-template/template-official.png" />
</Frame>

Фреймворк [HTML, CSS, JS](https://replit.com/@replit/HTML-CSS-JS?v=1#index.html) очень популярен и может служить отправной точкой для создания проекта на чистом JavaScript. Чтобы использовать его, создайте форк фреймворка.

<div id="templates-personalizados-para-enterprise">
  ## Пользовательские шаблоны для Enterprise
</div>

Организации Enterprise могут создавать [пользовательские шаблоны](/ru/pt/teams/custom-templates), доступные для выбора во входящих Agent всем участникам организации. Пользовательские шаблоны не ограничиваются фреймворками для разработчиков: они включают предварительно настроенные инструкции для Agent, навыки и контекст проекта, адаптированные под конкретную компанию. Подробнее см. в [руководстве по пользовательским шаблонам](/ru/pt/teams/custom-templates).
