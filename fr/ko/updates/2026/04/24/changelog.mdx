<div id="security-agent">
  ### Security Agent examine l&#39;intégralité de votre base de code
</div>

**Security Agent** est un nouvel outil de revue basé sur l&#39;IA qui audite l&#39;ensemble de votre projet, et pas seulement ses dépendances. Il élabore un modèle de menaces, cartographie les routes et les flux de données, exécute une analyse statique avec Semgrep et HoundDog.ai, puis s&#39;appuie sur un LLM pour déterminer ce qui est réellement exploitable dans le contexte de votre application. Une fois la revue terminée, Security Agent regroupe les éléments approuvés en tâches parallèles que Replit Agent peut corriger en une seule fois.

<Frame>
  <img src="/assets/mirror/security-agent-findings-b425392bb98a.png" alt="Panneau Security Agent du Project Security Center affichant une analyse terminée avec cinq éléments classés par gravité, chacun accompagné d'un statut tel que « Prêt pour revue » ou « Prêt pour republication », suivi d'une section d'analyse automatique des dépendances qui liste les paquets vulnérables" width="1438" height="808" data-path="images/changelog/2026-04-24/security-agent-findings.png" />
</Frame>

Security Agent est disponible pour tous les créateurs disposant d&#39;un forfait payant. Pour l&#39;essayer, ouvrez le panneau **Sécurité** de votre projet et sélectionnez **Lancer l&#39;analyse avec Agent**.

En savoir plus sur [Security Agent](/fr/core-concepts/security/project-security-center#agent-security-scans).

<div id="cve-auto-protect">
  ### CVE Auto-Protect corrige automatiquement les vulnérabilités critiques
</div>

Lorsqu&#39;une nouvelle CVE critique est publiée pour un paquet dont dépend votre app, **CVE Auto-Protect** détecte les correspondances dans tous les projets que vous possédez, Agent prépare le correctif dans une tâche en arrière-plan, exécute les tests pour vérifier que rien n&#39;est cassé, puis vous envoie une notification accompagnée d&#39;un lien pour examiner le résultat. Rien n&#39;est publié tant que vous n&#39;avez pas approuvé le correctif : vous gardez le contrôle.

Votre app peut ainsi être corrigée en quelques minutes après la publication d&#39;une nouvelle vulnérabilité, sans attendre que vous la découvriez vous-même.

En savoir plus sur [CVE Auto-Protect](/fr/core-concepts/security/project-security-center#auto-protect).

<div id="ios-simulator-android-emulator">
  ### Aperçu dans l&#39;iOS Simulator ou l&#39;Android Emulator
</div>

<Frame>
  <video autoPlay muted loop playsInline src="/assets/mirror/ios-emulator-9013ff1b602f.mp4" />
</Frame>

Si votre projet contient une application mobile, vous pouvez désormais diffuser un véritable **iOS Simulator** ou **Android Emulator** directement dans votre espace de travail, depuis le panneau Preview. Ni Xcode, ni Android Studio, ni appareil physique nécessaires. Créez votre application mobile avec Agent, sélectionnez un appareil dans le menu déroulant du panneau Preview, puis touchez l&#39;écran comme si vous teniez le téléphone en main. Dès qu&#39;Agent applique une modification, elle apparaît instantanément dans le simulateur.

Disponible pour les créateurs des offres payantes Core, Pro et Enterprise sur Chrome, Safari et les navigateurs basés sur Chromium. Firefox ne prend pas en charge les simulateurs mobiles.

En savoir plus sur l&#39;[aperçu dans un simulateur ou un émulateur](/fr/ko/features/artifact-types/building-mobile-apps#preview-on-a-simulator-or-emulator).

<div id="section-4">
  ### Ajouter une application mobile à un projet existant
</div>

<Frame>
  <img src="/assets/mirror/multi-artifact-update-approval-f6fa8b70a100.png" alt="Panneau de discussion Agent affichant la carte d'approbation « Mettre à jour le projet pour créer une application mobile », avec une offre de 5 $ de crédits et les boutons Pas maintenant / Mettre à jour le projet" width="991" height="589" data-path="images/replitai/multi-artifact-update-approval.png" />

Les projets créés avant la sortie d&#39;Agent 4 peuvent désormais être mis à jour pour prendre en charge plusieurs artifacts. Vous pouvez donc ajouter une application mobile, un pitch deck ou un autre artifact à un projet qui n&#39;en acceptait qu&#39;un seul. Agent conserve les URL, les données, les secrets et les déploiements pendant la restructuration du projet. Plus de 200 projets ont été migrés dans les 48 heures qui ont suivi le déploiement à grande échelle.

Pour en savoir plus, consultez [Mettre à jour des projets existants pour la prise en charge de plusieurs artifacts](/fr/ko/features/projects-and-artifacts/updating-projects-for-multiple-artifacts).

<div id="plaid">
  ### Lancement du connecteur Plaid
</div>

Vous pouvez désormais vous connecter à plus de 12 000 établissements financiers grâce au connecteur **Plaid**. L&#39;administrateur de l&#39;équipe configure les identifiants une seule fois dans **Intégrations**, puis les utilisateurs de l&#39;application authentifient leur propre compte bancaire via Plaid Link. Les jetons d&#39;accès sont limités à chaque utilisateur, ce qui garantit la confidentialité des données.

Créez un coach financier personnel alimenté par de véritables données de transactions, un suivi de portefeuille en temps réel connecté à des comptes-titres, et bien plus encore. Consultez la [page partenaire Replit x Plaid](https://replit.com/partners/plaid) pour une démonstration et les étapes de configuration.

Pour en savoir plus, consultez la [gestion des connecteurs](/fr/ko/replitai/managing-connectors).
