La console vous permet de surveiller et de consulter en temps réel les journaux générés par votre application Replit en cours d’exécution.
Utilisez les informations issues des exécutions actuelles et passées pour comprendre le comportement de votre application, résoudre les erreurs et optimiser les performances.

<Tip>
  Lorsque vous déboguez avec Agent, incluez les journaux de la console dans votre prompt afin de lui fournir du contexte.
</Tip>

<div id="section">
  ## Fonctionnalités
</div>

La Console propose les outils suivants pour vous aider à comprendre le fonctionnement de votre application :

* **Journalisation en temps réel** : consultez les sorties de votre application dès qu&#39;elles sont générées
* **Assistance IA** : recevez des suggestions pour corriger les erreurs signalées dans les journaux
* **Historique d&#39;exécution** : consultez les journaux des exécutions précédentes pour suivre les modifications

<div id="section-2">
  ## Utilisation
</div>

Vous pouvez accéder à l&#39;outil Console directement depuis l&#39;éditeur de projet.

<Accordion title="Comment accéder à la Console">
  Depuis le **dock d&#39;outils** situé à gauche :

  1. Sélectionnez <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Icône Tous les outils" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **Tous les outils** pour afficher la liste des outils de l&#39;éditeur de projet.
  2. Sélectionnez <img class="icon-svg" src="/assets/mirror/console-8a41ac90789c.svg" alt="Icône Console" width="16" height="16" data-path="images/icons/console.svg" /> **Console**.

  Depuis la **barre de recherche** :

  1. Sélectionnez la loupe <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="Icône loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> en haut pour ouvrir l&#39;outil de recherche
  2. Saisissez « Console » pour trouver l&#39;outil, puis sélectionnez-le dans les résultats.
</Accordion>

Chaque fois que vous utilisez le bouton **Run** dans une application Replit, la Console affiche une nouvelle entrée contenant les informations suivantes :

* La commande ayant exécuté le code
* L&#39;horodatage
* La sortie standard et les journaux d&#39;erreurs

La capture d&#39;écran ci-dessous montre la commande `npm run dev` utilisée pour lancer l&#39;application, ainsi que les messages de journal issus de l&#39;exécution :

<div id="ai">
  ### Débogage assisté par l&#39;IA
</div>

Lorsqu&#39;une erreur ou toute autre information que vous souhaitez comprendre apparaît dans les journaux, sélectionnez le bouton **Ask AI** en haut de l&#39;entrée. L&#39;onglet **Agent** s&#39;ouvre alors automatiquement et le contenu du journal lui est transmis pour analyse.

<div id="section-3">
  ### Commandes des entrées de journal
</div>

La Console propose les outils suivants pour gérer les journaux :

* **Afficher uniquement le plus récent** : activez ce contrôle pour n&#39;afficher que la dernière exécution.
* **Réduire les entrées** : sélectionnez la <img class="icon-svg" src="/assets/mirror/down-arrow-9c1cf9fd152e.svg" alt="Icône flèche vers le bas" height="16" width="16" data-path="images/icons/down-arrow.svg" />flèche vers le bas à gauche du nom de la commande pour masquer les journaux.
* **Effacer les exécutions passées** : sélectionnez cette option pour supprimer les journaux des exécutions passées. Cette action est irréversible.

<div id="section-4">
  ### Disponibilité réseau
</div>

Vous pouvez contrôler la disponibilité en ligne de la version de développement de votre application.

Pour cesser de répondre aux requêtes adressées à l&#39;URL de développement, sélectionnez l&#39;<img class="icon-svg" src="/assets/mirror/network-off-5bdca8a4fe4e.svg" alt="Icône réseau désactivé" height="16" width="16" data-path="images/icons/network-off.svg" />icône du globe barré, à droite de la ligne d&#39;informations réseau.

Pour la réactiver, sélectionnez l&#39;<img class="icon-svg" src="/assets/mirror/network-on-15be2e5fb4f5.svg" alt="Icône réseau activé" height="16" width="16" data-path="images/icons/network-on.svg" />icône du globe.

Pour afficher l&#39;URL de développement, sélectionnez le texte `{...}.replit.dev` dans la barre d&#39;adresse.

<Frame>
  <img src="/assets/mirror/preview-dev-url-b36770b33769.png" alt="Emplacement de l'URL de développement dans Preview" width="1222" height="824" data-path="images/workspace/preview-dev-url.png" />
</Frame>

<Note>
  Même si vous configurez l&#39;application pour qu&#39;elle cesse de répondre aux requêtes adressées à l&#39;URL de développement, elle reste accessible depuis l&#39;outil Preview.
</Note>

<div id="section-5">
  ### Arrêter les commandes de workflow
</div>

Vous pouvez arrêter les commandes de workflow en cours d’exécution depuis les outils de l’éditeur de projet Console.

Pour arrêter une commande, sélectionnez le bouton carré à droite de la ligne contenant la commande d’exécution de l’application Replit.

Pour redémarrer l’application, utilisez le bouton **Run** du workflow en haut de l’éditeur de projet.
