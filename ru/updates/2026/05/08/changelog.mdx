<div id="workspace-security-center-20">
  ### Workspace Security Center 2.0
</div>

Просматривайте уязвимости зависимостей во всех projects вашего workspace и устраняйте их в одном месте. Теперь Workspace Security Center сразу выводит на первый план самые уязвимые projects и позволяет искать и фильтровать затронутые projects по уровню серьёзности, статусу публикации, видимости и владельцу. Весь цикл устранения также доступен прямо в Security Center: запустите task для Agent, изучите предложенное исправление и переопубликуйте project. Вы можете уведомлять владельцев projects по отдельности или массово, сразу снимать с публикации projects с высокой подверженностью риску и скачивать SBOM для аудитов соответствия требованиям.

<div id="private-publishing-for-everyone">
  ### Приватная публикация для всех
</div>

Раньше приватная публикация приложений и публикация с защитой паролем были доступны только на тарифах Pro и Enterprise. Теперь публиковать приватно могут и разработчики на тарифах Core и Starter — так что любой может скрыть внутренний инструмент, бета-приложение или проект в разработке за входом в Replit.

Подробнее о [приватных deployment](/ru/features/publishing/private-deployments).

<div id="external-access-tokens-for-private-deployments">
  ### Внешние токены доступа для приватных deployment
</div>

Внешние токены доступа теперь доступны для приватных Replit App. Выпускайте токены для настройки интеграций — Slack, GitHub, Twilio и других, — которые обращаются к вашим приватным deployment в обход connector. Они дают опытным пользователям больше контроля над своими приложениями и делают приватные Replit App ещё безопаснее. Откройте **Adjust settings** в своём deployment — там появилась новая вкладка **Внешние токены доступа**.

Подробнее об [Внешних токенах доступа](/ru/references/publishing/external-access-tokens).

<div id="speaker-notes-and-presenter-view-in-slide-decks">
  ### Заметки докладчика и режим докладчика в слайд-презентациях
</div>

Слайд-презентации теперь поддерживают заметки докладчика и отдельный режим докладчика. Заметки синхронизируются в обе стороны в реальном времени между редактором и окном презентации, так что вы можете управлять презентацией с одного устройства, демонстрируя экран с другого. Попросите Agent написать заметки за вас, а затем доработайте их в редакторе — аудитория при этом видит только слайд. Режим докладчика также доступен с карточки артефакта презентации на мобильном устройстве.

<div id="agent-accepts-svg-uploads">
  ### Agent поддерживает загрузку SVG
</div>

Теперь вы можете прикреплять SVG-файлы к Agent. Перетащите SVG в Chat или вставьте URL-адрес — Agent обработает разметку так же, как и в любом другом вложении. Файлы очищаются в браузере до отправки в Agent или хранилище, поэтому распространённые векторы атак через SVG автоматически устраняются.
