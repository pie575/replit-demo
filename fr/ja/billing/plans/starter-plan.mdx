<div id="section">
  ## Ce qui est inclus
</div>

Le forfait Starter vous offre tout le nécessaire pour commencer à créer sur Replit. Créez des applications et publiez votre premier projet — le tout gratuitement.

<div id="agent">
  ### Crédits quotidiens pour Agent
</div>

Les utilisateurs du forfait Starter reçoivent des crédits quotidiens pour l&#39;utilisation d&#39;Agent, dans la limite d&#39;un plafond mensuel. Ces crédits sont réinitialisés chaque jour, ce qui vous donne un nouveau quota pour travailler avec Agent au quotidien.

<div id="section-2">
  ### Crédits mensuels pour l&#39;utilisation du cloud
</div>

Vous recevez également des crédits mensuels utilisables pour :

* [Base de données (production)](/fr/ja/features/data-and-storage/development-and-production)
* [Stockage d&#39;objets](/fr/ja/features/data-and-storage/object-storage)
* [Publication (Autoscale, Static)](/fr/ja/learn/projects-and-artifacts/replit-deployments)

Ces crédits sont réinitialisés chaque mois.

<div id="lite">
  ### Build Lite
</div>

Accès aux [build Lite](/fr/ja/features/agent/agent-modes), une expérience de build rapide et ciblée pour réaliser des modifications éclair et des changements précis avec Agent.

<div id="1">
  ### Une application publiée gratuite
</div>

Que vous utilisiez le build Lite ou le Canvas Design, vous bénéficiez de {FreeDeployments} application publiée gratuite. Ce lien public expire automatiquement au bout de 30 jours.

Les applications publiées affichent un badge « Made with Replit » contenant votre lien de parrainage unique. Une fois que vous êtes passé à un forfait payant, vous recevez des crédits de parrainage lorsque d&#39;autres utilisateurs s&#39;inscrivent via le lien de ce badge.

<div id="section-3">
  ## Limitations
</div>

Les fonctionnalités suivantes nécessitent le passage à l&#39;offre Core :

<div id="section-4">
  ### Build complet
</div>

Le [build complet](/fr/ja/features/agent/overview/) permet à Agent de travailler en toute autonomie, avec davantage de puissance et d&#39;indépendance. Les builders qui utilisent le forfait Starter n&#39;ont accès qu&#39;au [build Lite](/fr/ja/features/agent/agent-modes). Le build complet nécessite Core ou Pro.

<div id="section-5">
  ### Convertir un design en artefact
</div>

La conversion d&#39;un design du Canvas Design en artefact complet nécessite Core. Avec le forfait Starter, les builders peuvent créer et publier des designs, mais la conversion en artefact doté de fonctionnalités backend requiert une mise à niveau. Si vous souhaitez créer une application avec des fonctionnalités backend, commencez par un [build Lite](/fr/ja/features/agent/agent-modes).

<div id="section-6">
  ### Connecteurs tiers
</div>

Les connecteurs externes nécessitent Core. Cela comprend les intégrations avec Google, Stripe et d&#39;autres API tierces (pour en savoir plus, consultez [cette page](https://docs.replit.com/features/integrations/overview#connectors)).

<div id="replit-ai">
  ### Intégrations Replit AI
</div>

Les [intégrations Replit AI](/fr/ja/features/integrations/replit-ai-integrations) nécessitent un abonnement Core.

<div id="made-with-replit">
  ### Suppression du badge « Made with Replit »
</div>

Le forfait Core est requis pour retirer le badge « Made with Replit » d&#39;une application publiée. Le badge reste affiché sur les déploiements des utilisateurs du forfait Starter.

<div id="section-7">
  ### Applications publiées supplémentaires
</div>

Les utilisateurs du forfait Starter disposent de {FreeDeployments} applications publiées gratuites. Au-delà de cette limite, toute application publiée supplémentaire nécessite un forfait Core ou Pro.

<div id="plan">
  ### Mode Plan
</div>

Le mode Plan nécessite un forfait Core. En mode Plan, vous pouvez échanger des idées, planifier votre travail et collaborer avec Replit Agent, sans modifier le code ni les données de votre app.

<div id="section-8">
  ### Tous les types d&#39;artefacts
</div>

La création de types d&#39;artefacts autres que les applications web et mobiles nécessite Core. Vous avez le choix entre différents types : visualisations de données, présentations, vidéos animées, etc. Pour en savoir plus, consultez [Projets](/fr/ja/features/projects-and-artifacts/projects).

<div id="core">
  ## Passer à Core
</div>

Besoin de plus ? Passez à Core pour débloquer :

* **Plus de stockage et de crédits mensuels**, avec la facturation à l&#39;usage en option
* **Un nombre illimité d&#39;applications publiées**, au-delà de votre première application gratuite
* **Le build complet** pour un développement autonome
* **Des connecteurs tiers** pour vous relier à des services externes
* **L&#39;intégration Replit AI** pour utiliser des modèles d&#39;IA sans gérer vos propres clés API
* **Le mode Plan** pour cartographier les tâches avant de vous lancer dans la création
* **La suppression du badge Replit** pour un rendu professionnel
* Et bien plus encore
