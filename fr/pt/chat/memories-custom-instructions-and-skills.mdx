Les Mémoires, les Instructions personnalisées et les compétences aident Replit à travailler avec un meilleur contexte. Choisissez l&#39;option qui correspond au type d&#39;information : une règle durable, une procédure reproductible ou un contexte utile issu de travaux antérieurs.

|                                 | Qui les gère                | Quand Replit les utilise                           | Idéal pour                                                                    |
| ------------------------------- | --------------------------- | -------------------------------------------------- | ----------------------------------------------------------------------------- |
| **Instructions personnalisées** | Vous ou votre équipe        | Toujours, dans toutes les sessions                 | Préférences et règles stables que vous souhaitez appliquer de façon cohérente |
| **Compétences**                 | Vous ou votre équipe        | Lorsque c&#39;est pertinent pour une tâche précise | Procédures reproductibles, flux de travail et documents de référence          |
| **Mémoires**                    | Replit, sous votre contrôle | Lorsqu&#39;un contexte pertinent est utile         | Éviter de répéter les préférences utiles issues de travaux antérieurs         |

<div id="escolha-a-ferramenta-certa">
  ## Choisir le bon outil
</div>

* Utilisez les **Instructions personnalisées** pour une règle qui doit s&#39;appliquer à l&#39;ensemble de votre Workspace, comme une bibliothèque approuvée ou une exigence de traitement des données. C&#39;est vous qui les rédigez, et Replit ne les modifie pas.
* Utilisez une **compétence** pour une approche réutilisable applicable à un type de travail précis, comme préparer un lancement ou revoir un design. Les connaissances procédurales stables relèvent des compétences.
* Utilisez les **Mémoires** lorsque Replit peut conserver un contexte utile issu de travaux antérieurs, pour vous éviter de répéter les préférences qui comptent. Replit peut écrire des Mémoires pendant que vous travaillez : il s&#39;agit d&#39;éléments de contexte, pas d&#39;instructions exécutables.

Votre demande explicite et les Instructions personnalisées priment sur les Mémoires. Gérez les Mémoires dans **Paramètres → Personnalisation → Mémoire**. Elles ne conservent aucune information personnelle ou sensible et sont privées par défaut. Le partage avec les collaborateurs est facultatif et désactivé par défaut.
