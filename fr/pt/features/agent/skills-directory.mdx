Le répertoire de compétences est un catalogue de compétences prêtes à l&#39;emploi, créées par Replit et nos partenaires, que vous pouvez installer et utiliser immédiatement. Installez-en une, essayez-la, puis modifiez-la pour l&#39;adapter à la façon dont votre équipe travaille réellement.

Pour comprendre ce qu&#39;est une compétence et comment Agent la charge, consultez [Compétences Agent](/fr/pt/features/agent/skills). Pour rendre une compétence disponible dans tout votre workspace, consultez [Personnalisation d&#39;Agent](/fr/pt/features/agent/agent-customization).

<div id="instalar-uma-skill">
  ## Installer une compétence
</div>

Vous pouvez ajouter une compétence depuis le répertoire de plusieurs façons :

* **Dans le chat** — cliquez sur le bouton **+** à côté du champ de saisie du chat, sélectionnez **Utiliser une compétence** et choisissez-en une. La compétence ne s&#39;applique qu&#39;à ce message, sans rien installer dans votre projet.
* **Dans un projet** — ouvrez le **Skills pane** dans le Project Editor, sélectionnez l&#39;onglet **Discover**, trouvez une compétence et cliquez sur **Install**. Les compétences installées sont stockées dans le répertoire `/.agents/skills` de votre projet et persistent d&#39;un chat à l&#39;autre.
* **En ligne de commande** — installez une compétence avec la [CLI skills](https://github.com/vercel-labs/skills) :

  ```bash theme={null}
  npx skills <skill> -a replit
  ```

<Warning>
  Les compétences proposées dans le sélecteur de compétences de Replit font l&#39;objet d&#39;un audit de sécurité. Ce n&#39;est pas le cas de celles installées depuis des sources externes. Comme une compétence n&#39;est rien d&#39;autre qu&#39;un ensemble d&#39;instructions suivies par l&#39;Agent, examinez toujours une compétence externe avant de l&#39;installer — consultez [Compétences Agent](/fr/pt/learn/agent-skills) pour savoir quoi vérifier.
</Warning>

<div id="skills-do-replit">
  ## Compétences de Replit
</div>

Replit intègre des compétences prédéfinies, disponibles dans le sélecteur **Utiliser une compétence** du chat ainsi que dans le sélecteur de point de départ des nouveaux projets. Elles fonctionnent dans tous les projets, sans installation. Les descriptions s&#39;affichent directement lorsque vous ouvrez le sélecteur.

| Catégorie              | Compétences                                                                                                   |
| ---------------------- | ------------------------------------------------------------------------------------------------------------- |
| Vente et marketing     | Ad Creative, AI SDR, SEO Auditor, Programmatic SEO, GEO, Content Machine, Storyboard                          |
| Carrière               | AI Recruiter, Resume Maker, Interview Prep                                                                    |
| Recherche et analyse   | Competitive Analysis, Deep Research, GitHub Solution Finder, Supplier Research                                |
| Affaires et finance    | Stock Analyzer, Excel Generator, Invoice Generator, Tax Reviewer                                              |
| Documents et outils    | Website Cloner, File Converter, Flashcard Generator, Legal Contract, Infographic Builder, Recreate Screenshot |
| Créatif                | Photo Editor, Podcast Generator, Podcast Marketing, Branding Generator, Video Editing                         |
| Productivité           | AI Secretary, Product Manager, Design Thinker, Skill Finder, Skill Creator                                    |
| Personnel              | Travel Assistant                                                                                              |
| Sécurité et conformité | Secrets, Sensitive Data, Input Validation, AI Security, Dependency Vetting, License Check                     |
| Qualité et fiabilité   | Accessibility, Responsive UI, Observability, Resilience, Ship Review                                          |

<Note>
  Au sein d&#39;un workspace, le sélecteur détecte également toutes les compétences supplémentaires installées dans le répertoire `.local/secondary_skills/` du projet.
</Note>

<div id="skills-de-parceiros">
  ## Compétences des partenaires
</div>

Les partenaires de Replit publient des compétences qui apprennent à Agent à créer avec leurs produits. Installez-en une pour transmettre à Agent les modèles et conventions du service concerné.

| Partenaire       | Ce que cela apprend à Agent                                  |
| ---------------- | ------------------------------------------------------------ |
| Stripe           | Modèles d&#39;intégration des paiements et de la facturation |
| PayPal           | Modèles d&#39;intégration des paiements                      |
| RevenueCat       | Modèles d&#39;abonnement et d&#39;achats intégrés            |
| Mixpanel         | Mise en place de l&#39;analytique et du suivi                |
| BigQuery         | Modèles de requêtes sur entrepôt de données                  |
| Resend           | Intégration d&#39;e-mails transactionnels                    |
| Google Workspace | Intégration avec Gmail, Drive, Docs et Calendar              |
| Atlassian        | Flux de travail des tickets Jira et des pages Confluence     |
| Google Maps      | Intégration de cartes, lieux, itinéraires et géocodage       |

<div id="skills-da-comunidade">
  ## Compétences de la communauté
</div>

Outre les compétences de Replit et de ses partenaires, la communauté publie des compétences que vous pouvez installer. Découvrez-les sur [skills.sh](https://skills.sh) et consultez la [spécification Compétences Agent](https://agentskills.io/specification) pour créer les vôtres.
