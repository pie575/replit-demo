export const YouTubeEmbed = ({videoId, title = "Vidéo YouTube", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

<YouTubeEmbed videoId="bAUVQfz_SIY" title="Découvrez Replit Agent 4" />

Agent 4 est là. Conçu pour stimuler votre créativité, Agent est votre partenaire créatif IA : il transforme vos idées en applications, designs, diapositives et bien plus encore, à partir de simples descriptions en langage naturel. Aucune compétence en programmation n’est requise.

Avec Agent 4, vous pouvez :

* **Créer tout ce que vous voulez** : créez des applications web, des applications mobiles, des tableaux de bord de données, des outils propulsés par l’IA et bien plus encore
* **Concevoir avant de développer** : explorez des maquettes sur le [Canvas Design](/fr/learn/projects-and-artifacts/canvas) avant de vous lancer dans le code
* **Planifier votre projet** : utilisez le [Plan mode](/fr/core-concepts/agent/plan-mode) pour planifier votre build avant d’écrire la moindre ligne de code
* **Exécuter des tâches en parallèle** : Agent gère plusieurs tâches à la fois pour vous permettre d’avancer plus vite
* **Collaborer avec vos coéquipiers** : invitez d’autres personnes dans votre projet et travaillez simultanément
* **Connecter vos outils** : récupérez directement dans le chat des données depuis BigQuery, Linear, Slack, Notion et bien plus encore
