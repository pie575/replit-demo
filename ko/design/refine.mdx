탐색은 폭넓게, 다듬기는 깊게 갑니다. 프레임이 원하는 결과에 가까워지면 두 가지 도구가 여러분이 작업하는 방식에 맞춰 정밀하게 다듬어줍니다:

* 여러분만의 표현으로 Agent와 채팅하세요. 프레임 전체든 요소 하나든 상관없습니다
* Visual Editor로 요소를 직접 조정하세요. 간단한 편집은 크레딧을 소모하지 않고 즉시 적용됩니다

## 채팅

디자이너에게 중간 리뷰를 브리핑하듯 Agent에게 브리핑하세요. 프레임을 선택하고 메인 채팅에서 변경 사항을 설명하거나(*"더 따뜻한 색상"*, *"히어로가 비어 보여요"*), 툴바에서 **Chat** 도구를 선택하고 요소를 클릭해서 메시지 범위를 그 부분으로 한정하세요.

## Visual Editor

정확히 무엇을 원하는지 알고 있다면 프롬프트를 건너뛰세요. 툴바에서 **Edit** 도구를 선택하고 요소를 클릭하면 그 요소가 편집할 수 있는 속성(콘텐츠, 레이아웃, 색상, 테두리 등)으로 Visual Editor가 열립니다. 텍스트 변경, 색상 선택, 간격 조정 같은 간단한 편집은 크레딧을 소모하지 않고 즉시 소스 코드에 적용됩니다.

<Frame caption="요소가 선택된 상태에서 활성화된 Edit 도구와 편집 가능한 속성을 보여주는 Visual Editor.">
  <img src="/assets/mirror/visual-editor-edit-tool-71d03803471f.png" alt="Edit 도구가 활성화되고 요소가 선택된 슈퍼카 컨피규레이터 프레임, 오른쪽에 Layout, Color, Border 섹션과 Discard, Save edits 버튼이 있는 Visual Editor 패널" width="2000" height="1250" data-path="images/replitai/visual-editor-edit-tool.png" />
</Frame>

전체 컨트롤 참조는 [Visual Editor](/ko/design/visual-editor)를 참조하세요.

## 어떤 것을 선택해야 할까요

| 원하는 것은…                                 | 사용할 도구        |
| --------------------------------------- | ------------- |
| 결과를 설명하고 Agent가 세부 사항을 알아서 처리하게 하기      | 채팅            |
| 알고 있는 값으로 요소 하나의 텍스트, 색상, 간격, 이미지를 변경하기 | Visual Editor |
| 섹션의 구조나 동작을 재작업하기                       | 채팅            |
| 크레딧을 쓰지 않고 빠르게 조정하기                     | Visual Editor |

두 가지는 자연스럽게 결합됩니다. 채팅으로 방향을 잡은 다음 Visual Editor로 세부 사항을 완성하세요.
