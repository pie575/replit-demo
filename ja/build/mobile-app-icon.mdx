export const appIconPrompt = "Generate 3 different 1024x1024 app icon concepts for PixelGames.";

両方のストアとも、提出を受け付ける前にアプリアイコンが必要です。Replit は別のデザインツールを使わずに
直接生成できます。

## 各ストアが必要とするもの

* **App Store:** 1024×1024、透過なし、角丸なし（Apple 側で追加されます）。
* **Google Play:** 512×512。

## 生成する

プロンプトを送信する前に **Design** モードに切り替えてください。これにより Agent が画像を生成するようになります。

<AiPrompt>
  {appIconPrompt}
</AiPrompt>

Agent は一度に複数の方向性を生成するので、決定する前に比較して選ぶことができます。
