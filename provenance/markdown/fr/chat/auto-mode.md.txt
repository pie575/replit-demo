Le routage de modèle intelligent permet à Replit de sélectionner un modèle approprié pour chaque tâche tout en équilibrant qualité et coût. Lorsque vous voyez **Auto** dans le produit, Replit effectue un routage de modèle intelligent.

## Activer le routage de modèle intelligent

1. Dans la zone de saisie, sélectionnez **Agent Mode**. Le menu affiche les modes disponibles : **Free**, **Power** et **Max**.
2. Sélectionnez **Power** ou **Max**, puis repérez la section **Primary model**. Son libellé change selon le mode sélectionné, par exemple **Primary Max model**.
3. Si le modèle principal est déjà réglé sur **Auto**, le routage de modèle intelligent est activé. Si un modèle spécifique est sélectionné, ouvrez le menu du modèle principal et sélectionnez **Automatically choose**.

Free Mode utilise toujours le routage de modèle intelligent et ne permet pas de sélectionner un modèle manuellement.

## Laissez la tâche guider le modèle

Le routage de modèle intelligent est utile lorsque vous souhaitez que Replit gère la sélection du modèle à mesure que le travail évolue. Une demande ciblée peut utiliser un modèle moins coûteux, tandis qu'une tâche complexe peut nécessiter un modèle plus performant.

En Power Mode ou Max Mode, les développeurs sur les plans Core et Pro peuvent plutôt sélectionner un modèle disponible manuellement.
