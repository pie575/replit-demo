title: "引导或排队后续消息"
description: "了解 Steer 和 Queue 如何处理 Agent 的后续消息、如何在 Conversation 和 Project 中进行配置，以及在 Replit 中 Agent 工作期间如何管理消息。"
---

当 Agent 正在工作时，后续消息要么会改变 Agent 当前正在进行的工作——即活动中的**回合**——要么会等到该回合结束。

* **Steer** 会将消息发送到当前活动的回合中，Agent 会一边继续工作，一边使用新的上下文。
* **队列**会将消息保存到下一个回合，Agent 会在当前回合结束后再开始处理该消息。

<div id="conversation">
  ## 引导 Conversation
</div>

在 Conversation 和 Project 中，Steer (引导) 都是后续消息的默认发送行为。这两处的设置都可以改为队列。

<div id="replit">
  ## 选择 Replit 发送后续消息的方式
</div>

你可以为 Conversation 和 Project 分别设置各自的发送行为：

1. 打开 **Settings** &gt; **Personalization**。
2. 展开 **Agent**。
3. 将 **Conversation send behavior** 和 **Project send behavior** 设置为 **Steer** 或 **队列**。

<Frame caption="Agent 部分中的 Conversation 与 Project 发送行为设置。">
  <img src="/assets/mirror/agent-follow-ups-settings-98a4c5ca399e.png" alt="展示带有 Steer 与 队列 选项的 Conversation 与 Project 发送行为的 Agent 设置" width="3048" height="1372" data-path="images/replitai/agent-follow-ups-settings.png" />
</Frame>

<Info>
  Design 模式始终以 Steer 方式处理后续消息。Conversation 和 Project 的发送行为设置不适用于 Design 模式。
</Info>

如需让某条消息按与当前偏好相反的方式发送，请按 `Cmd+Enter` (Mac) 或 `Ctrl+Enter` (Windows 和 Linux) 。

<div id="section">
  ## 处理队列中的消息
</div>

将后续消息加入队列后，Message Queue 会以抽屉形式显示在聊天输入框上方。Agent 会在当前回合结束后，按顺序处理队列中的消息。队列中的消息全部处理完毕后，抽屉会自动关闭。

队列支持所有消息选项，包括 [Visual Editor](/zh/ja/design/visual-editor) 和附加文件。

<Info>
  只有在桌面端或移动端保持已连接的活动 Project Editor 会话时，Agent 才会自动处理队列中的消息。
</Info>

<div id="section-2">
  ### 管理队列
</div>

队列抽屉打开时，你可以：

* **Steer now**：将队列中的消息移入当前进行的回合。
* **编辑消息**：在 Agent 处理之前修改队列中的消息。
* **删除消息**：移除不再需要的消息。
* **调整消息顺序**：拖动消息以更改处理顺序。
* **添加消息**：继续向队列发送后续消息。

<div id="section-3">
  ## 停止进行中的回合
</div>

在状态栏中选择**停止**，即可中断 Replit 在当前回合中正在进行的工作。之后，你无需等待 Agent 完成该回合或处理完排队的消息，即可直接发送新消息。
