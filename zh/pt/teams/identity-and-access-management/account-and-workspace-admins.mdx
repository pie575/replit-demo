<Info>
  **本页仅适用于 Enterprise 计划。** 只有 Enterprise 才区分账户管理员和 workspace 管理员这两种独立角色。

  在 **Core** 和 **Pro** 计划中，你的账户只有一位**账户管理员** (通常是账户所有者) ，不存在单独的 workspace 管理员角色。如果你使用的是 Core 或 Pro，请参阅[管理成员](/zh/pt/teams/identity-and-access-management/managing-members)和[角色、群组与访问权限](/zh/pt/teams/identity-and-access-management/groups-and-permissions)——其中所述的 **Admin** 角色就是你的账户管理员。
</Info>

在 Enterprise 计划中，Replit 将管理职责拆分为两种不同的角色：**账户管理员**和 **workspace 管理员**。这样拆分后，你可以让某人完全掌管某一个 workspace，而无需同时授予账单权限和整个账户的控制权。本页将说明每种角色的职责、二者的区别，以及如何进行配置。

<div id="como-as-duas-funes-se-relacionam">
  ## 两种角色的关系
</div>

您的 Replit **账户**是账单实体，拥有订阅、席位以及一个或多个 **workspace** (即您的组织) ——Enterprise 账户可以包含多个 workspace。两种管理员角色分别对应这两个范围：

* **账户管理员**管理整个账户，负责账单，并对账户下的所有 workspace 拥有管理权限。
* **workspace 管理员**仅管理自己所属的特定 workspace，无权访问账单，也无法管理其他 workspace。

每位账户管理员都会自动成为账户下所有 workspace 的管理员，因此账户管理员实际上是 workspace 管理员的超集。而 workspace 管理员并非账户管理员，无法管理账单或其他 workspace。

<CardGroup cols={2}>
  <Card title="账户管理员" icon="building-shield">
    覆盖整个账户。管理账单、席位、安全设置以及账户下的所有 workspace。
  </Card>

  <Card title="workspace 管理员" icon="user-shield">
    仅限 workspace 范围。只能在自己所属的 workspace 中管理成员和资源。
  </Card>
</CardGroup>

<div id="o-que-cada-funo-pode-fazer">
  ## 每种角色可以做什么
</div>

两种角色都负责管理 workspace——区别在于管理*哪些* workspace。账户管理员管理账户下的所有 workspace，而 workspace 管理员只管理自己所属的 workspace。

| 权限                        | 账户管理员 | workspace 管理员 |
| ------------------------- | :---: | :-----------: |
| 管理所辖 workspace 中的成员       |   是   |       是       |
| 管理所辖 workspace 中的应用、群组和资源 |   是   |       是       |
| 查看和编辑账单、付款方式及发票           |   是   |       否       |
| 编辑、取消或恢复订阅                |   是   |       否       |
| 添加、移除和分配席位                |   是   |       否       |
| 设置支出和用量限额                 |   是   |       否       |
| 创建新的 workspace            |   是   |       否       |
| 管理其他账户管理员                 |   是   |       否       |
| 管理账户下的所有 workspace        |   是   |       否       |
| 配置 SAML、SCIM、审计日志和安全联系人   |   是   |       否       |

workspace 管理员的管理权限仅限于自己的 workspace，而账户管理员在整个账户范围内拥有全部管理权限。

<Note>
  账单、席位管理、订阅变更以及账户级安全控制均需要账户管理员权限。workspace 管理员无法执行这些操作，即便是在自己的 workspace 内也不例外。
</Note>

<div id="configurando-administradores-de-conta">
  ## 配置账户管理员
</div>

你可以在设置中的 **席位** 选项卡中管理账户管理员。添加账户管理员会授予该人员整个账户的管理权限，并自动将其设为该账户所有 workspace 的管理员。

<div id="promover-um-membro-a-administrador-de-conta">
  ### 将成员提升为账户管理员
</div>

<Steps>
  <Step title="打开“席位”选项卡">
    在设置中，打开 **席位** 选项卡。此选项卡会列出账户中的成员及其当前角色。
  </Step>

  <Step title="提升成员">
    找到要提升的成员，打开操作菜单，然后选择 **提升为账户管理员**。更改会立即生效。
  </Step>
</Steps>

<div id="rebaixar-um-administrador-de-conta">
  ### 取消账户管理员权限
</div>

取消账户管理员权限会移除其对整个账户和账单的访问权限。默认情况下，取消管理员权限不会将其从所在 workspace 中移除——无论是否为账户管理员，其仍可访问该 workspace。

<Steps>
  <Step title="打开“席位”选项卡">
    在设置中，打开 **席位** 选项卡。
  </Step>

  <Step title="取消账户管理员权限">
    找到账户管理员，打开操作菜单，然后选择 **取消账户管理员权限**。更改将立即生效。
  </Step>
</Steps>

以下规则可防止您的账户失去管理员访问权限：

* 您不能取消自己的管理员权限。
* 您不能移除最后一位账户管理员。您的账户必须始终至少保留一位账户管理员。
* 您不能取消个人账户所有者的管理员权限。

<div id="administradores-provisionados-via-scim">
  ### 通过 SCIM 预配的管理员
</div>

如果你通过 [SCIM](/zh/pt/teams/identity-and-access-management/scim) 预配用户，那么被身份提供方分配了 **Admin** 角色的用户会成为**账户管理员**。若要创建 workspace 范围内的管理员，请在 Replit 中分配 **workspace 管理员**角色，而不要通过身份提供方分配。

<div id="configurando-administradores-de-workspace">
  ## 配置 workspace 管理员
</div>

分配 workspace 管理员角色，可以让某人获得对特定 workspace 的完整管理控制权，而无需授予其整个账户或账单的访问权限。当团队负责人需要管理自己的 workspace，但不应管理订阅或其他团队时，这一角色非常有用。

<Steps>
  <Step title="打开 workspace 成员列表">
    打开要分配管理员的 workspace，然后进入**成员**页面。
  </Step>

  <Step title="将成员角色设置为 workspace 管理员">
    找到该成员，打开角色选择器，选择**workspace 管理员**。该成员将获得仅限于该 workspace 的管理访问权限。
  </Step>
</Steps>

<Note>
  workspace 管理员的访问权限仅限于其所属的 workspace。他们无法访问账单、管理席位或管理其他 workspace——这些操作需要账户管理员权限。
</Note>

<div id="escolhendo-a-funo-correta">
  ## 选择合适的角色
</div>

* 为负责管理账单、订阅和席位、配置安全设置，或需要统管所有 workspace 的人员分配**账户管理员**角色。
* 为负责管理单个团队或 workspace 的人员分配 **workspace 管理员**角色，他们可以管理该 workspace 的成员和资源，但不涉及账单或其他 workspace。
