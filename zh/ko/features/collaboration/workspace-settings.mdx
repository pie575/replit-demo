使用此页面查找与 Workspace 设置一同提供于同一“设置”对话框中的相关账户和用户
控件。

<div id="settings">
  ## 打开 设置
</div>

1. 选择 Replit 左下角的账户菜单。
2. 选择 **设置**。

<Note>
  可用的标签页取决于工作区类型、订阅方案和角色。管理员专属选项仅在你拥有管理权限时才会显示。
</Note>

<div id="workspace">
  ## Workspace 设置
</div>

使用 **Workspace** 部分管理当前选定的工作区。

* **Workspace 概览**：更新工作区图片或名称，并查看 ID。
* **Workspace 协作者**：邀请成员并管理工作区访问权限。
* **集成**：管理已连接到工作区的服务和资源。
* **自定义**：为 Agent 配置适用于整个工作区的自定义指令、技能和 Memory。有关设置方法和权限，请参阅 [Agent 自定义](/zh/ko/features/agent/agent-customization)。
* **设计系统**和**幻灯片模板**：管理组织可复用的设计指南和演示文稿模板。两者均为 Enterprise 功能。请参阅[设计系统](/zh/ko/teams/custom-design-system)和[自定义模板](/zh/ko/teams/custom-templates)。
* **安全性**：查看适用于工作区的安全控制措施。请参阅[安全概览](/zh/ko/features/security/overview)。
* **群组**：管理成员并应用群组权限。请参阅[群组和权限](/zh/ko/teams/identity-and-access-management/groups-and-permissions)。

<div id="account">
  ## Account 设置
</div>

使用 **Account** 部分配置可应用于多个工作区的设置。

* **Usage**、**Billing**、**Account seats**：查看使用情况和账单信息，并根据角色管理席位。
* **Advanced**：查找包括 Agent 模型提供商政策在内的高级账户控制选项。有关 Enterprise 提供商和按工作区划分的工作流，请参阅[模型控制](/zh/ko/features/collaboration/enterprise-model-controls)。
* **Developer**：管理 Admin API 密钥并查看请求记录。创建或轮换密钥前，请参阅[管理员 API](/zh/ko/teams/admin-api)。

<div id="user">
  ## User 设置
</div>

使用 **User** 部分管理你的 **Profile** 和 **Personalization** 偏好设置。你还可以在此部分找到 Replit 社区链接。
