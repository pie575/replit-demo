最终，Velocity 的每笔预订都会出现在客户的 Google 日历中，取车和还车时间均已自动填好。

集成让 Velocity 能够与其他工具协同工作。你可以把每笔预订推送到客户的日历，在有人预订高价值租赁时给协调员发送邮件，或者把天气信息拉取到行程规划页面。现在先选一个即可——Google 日历为每位客户带来一个清晰可验证的成果 (“租赁已经在我的日历上了”) ，而且你在测试时可以用自己的日历来核实。

<div id="pea-ao-agent-para-adicionar-a-integrao-com-o-calendrio">
  ## 请 Agent 添加日历集成
</div>

Replit 内置了支持 Google 日历的 **Google Workspace 连接器**。Agent 只需点击一次即可登录 Google，无需创建 API 项目、复制 OAuth 凭据或粘贴 Secrets。

<AiPrompt>
  当 Velocity 客户确认预订后，将租车信息添加到其 Google 日历。<br />
  请使用 Replit 的 Google Workspace 连接器连接 Google 日历——不要向我索要 OAuth 凭据。<br />
  事件标题应为“Velocity 租车：[汽车品牌和型号]”。<br />
  事件应涵盖从取车时间到还车时间，并在说明中包含取车地址和预订参考编号。<br />
  如果客户更改日期或取消预订，请自动更新日历事件。<br />
  如果添加到日历失败，请在 Velocity 中显示清晰的提示信息，确保预订仍能确认。
</AiPrompt>

Agent 会配置 Google Workspace 连接器，并在工作区中打开一个连接对话框。您使用拥有该日历的 Google 账号登录后，Velocity 会在每次确认预订时添加一个日历事件。

<Note>
  连接器是 Core、Pro 或 Enterprise 的功能。使用免费套餐时，请让 Agent 改用 Google OAuth 项目——您需要在 Google Cloud 中创建项目、启用 Calendar API，并将生成的凭据粘贴到 App 的 Secrets 面板中。
</Note>

<div id="teste-de-ponta-a-ponta">
  ## 端到端测试
</div>

1. 在新标签页中打开你自己的 Google 日历。
2. 在 Preview 中登录 Velocity。
3. 预订下周六至周日的用车，并确认预订。
4. 切换到 Google 日历标签页。周六至周日应出现一个新事件&quot;Velocity 租车：[车型]&quot;，描述中包含取车地址。
5. 在 Velocity 中将预订改为周日至周一，日历事件应自动随之调整。
6. 取消预订，日历事件应随之消失。
7. 作为第二项测试，在 workspace 中打开 **集成**，断开 Google Workspace 连接，然后尝试预订一次。Velocity 仍应确认预订，并显示一条清晰的提示，例如&quot;无法添加到你的日历——你的预订已确认。&quot;测试通过后请重新连接该连接器。

如果预订已确认但没有出现日程，请将确切的错误信息粘贴给 Agent：

<AiPrompt>
  集成失败，报错如下：[粘贴来自 Velocity 或 Replit 日志的错误]。<br />
  告诉我可能的原因，并以最小的改动修复问题。<br />
  确保即使 Google 日历无法访问，在 Velocity 中预订车辆仍然可用。
</AiPrompt>

<div id="publicar-e-testar-na-url-pblica">
  ## 发布并在公开 URL 上测试
</div>

日历集成在 Preview 中正常运行后：

1. 通过 Agent 的 Chat 重新发布 Velocity。
2. 打开公开 URL，以真实客户的视角预订一辆车。
3. 确认该事件出现在完成预订的账号日历中。
4. 通过公开 URL 修改并取消一次预订，确认日历事件随之更新。

现在，客户离开 Velocity 时，租车安排已经在日历里了。预订不再只是一封确认邮件，而是一个他们不会忘记的日程事件。

<div id="precisa-de-mais-ajuda">
  ## 需要更多帮助？
</div>

* **Google 日历中没有显示任何事件：**在工作区中打开**集成**，确认 Google Workspace 连接器显示“已连接”，且已授予 Calendar 访问范围。
* **连接器显示“已连接”，但事件未送达：**请 Agent 记录其发送的日历负载，并修正字段映射。
* **日期或地址字段在事件中显示在错误位置：**请 Agent 记录其发送的事件格式，并修正字段映射。
* **您需要其他集成：**将“Google 日历”替换为任何其他连接器——向团队发送 Slack 通知、使用 HubSpot 将客户记录为 CRM 联系人，或使用 Airtable 在共享数据库中跟踪预订。Agent 会通过“集成”面板以同样的方式使用每个连接器。
