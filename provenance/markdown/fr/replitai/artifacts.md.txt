## Que sont les artefacts ?

Les artefacts sont les éléments que vous pouvez publier sur Replit, tels que : applications web, applications mobiles, diaporamas, animations, applications de données, jeux 3D et designs. Chacun est une sortie complète et autonome qui reçoit sa propre URL partageable lorsque vous la publiez.

Tout le reste dans votre projet — fichiers, images, CSV, code — soutient vos artefacts mais ne peut pas être publié seul.

## Premiers pas

Il y a deux façons de créer depuis la page d'accueil de Replit :

* **Décrivez-le** : Tapez ce que vous voulez — « construis-moi une application de recettes » ou « fais un pitch deck pour ma startup ». Agent détermine quel type convient et le construit.
* **Choisissez un type** : Choisissez l'artefact que vous voulez — Application web, Application mobile, Visualisation de données, Animation, Jeu 3D ou un autre type pris en charge — avant de décrire votre idée.

Vous pouvez également ajouter des éléments à un projet existant à tout moment en demandant à Agent dans le chat ou en cliquant sur le bouton **+** dans le panneau de prévisualisation.

## Basculer entre les artefacts

Une fois que vous avez plusieurs artefacts dans un projet, basculez entre eux dans le **panneau de prévisualisation** ou la **barre latérale de la bibliothèque**. Vous pouvez également demander à Agent — « montre-moi l'application mobile » ou « passe aux présentations ».

### Barre latérale de la bibliothèque

La barre latérale de la bibliothèque vous offre un endroit central pour parcourir tout ce qui se trouve dans votre projet. Elle affiche vos artefacts, les images qu'Agent a générées ou téléchargées, ainsi que d'autres ressources du projet. Ouvrez la barre latérale de la bibliothèque depuis le panneau gauche pour trouver et réutiliser n'importe quelle ressource dans votre projet.

## Plusieurs artefacts dans un seul projet

Un seul projet peut contenir jusqu'à **7 artefacts**, avec un maximum d'**1 application mobile** par projet. Par exemple, vous pourriez construire une application web pour vos clients, une application mobile pour votre équipe et une présentation pour les investisseurs — tout dans le même projet.

<ArtifactGrid />

### Ajouter des artefacts à un projet

Il y a trois façons d'ajouter un artefact à un projet existant :

* **Chat** : Demandez à Agent — « ajoute une application mobile à ce projet » ou « crée une présentation pour le pitch investisseurs »
* **Bouton Plus** : Cliquez sur le bouton **+** dans le panneau de prévisualisation et choisissez ce que vous voulez construire
* **Barre latérale de la bibliothèque** : Parcourez vos artefacts existants, vos images et autres ressources, et ajoutez de nouveaux artefacts depuis là

### Données et backend partagés

Lorsque les artefacts se trouvent dans le même projet, ils partagent automatiquement les mêmes données et la même logique backend. Si un client passe une commande via votre application web, votre application mobile et votre tableau de bord de données voient également cette commande. Vous n'avez pas besoin de configurer des connexions ni de dupliquer du code — ça fonctionne tout simplement.

<Note>
  La publication déploie l'intégralité de votre projet en une seule fois. Tous les artefacts sont mis en ligne ensemble, afin qu'ils restent toujours synchronisés.
</Note>

### Exemples de combinaisons

* **Application web + application mobile** : Un restaurant avec une application web orientée client et une application mobile pour le personnel — toutes deux connectées à la même API et base de données
* **Application + tableau de bord d'administration** : Un produit principal accompagné d'un panneau d'administration interne pour gérer le contenu, les utilisateurs ou les paramètres
* **Application + présentation** : Votre produit et un pitch deck dans le même projet, pour que les diapositives reflètent toujours la dernière version
* **Tableau de bord de données + vidéo** : Une visualisation de données en direct associée à une vidéo animée qui présente les points saillants

## Publication

Les applications, présentations et vidéos peuvent toutes être publiées et partagées. Chacune reçoit sa propre URL partageable lors du déploiement.

Les fichiers et ressources qui ne sont pas des artefacts (comme les CSV, images ou fichiers markdown) ne peuvent pas être publiés seuls. Pour les partager, ajoutez-les à une application ou créez un nouvel artefact.

## Questions fréquentes

<Accordion title="Puis-je avoir plus d'un artefact dans un projet ?">
  Oui. Un seul projet peut contenir jusqu'à **7 artefacts au total**, avec une limite d'**1 application mobile par projet**. Tous les artefacts d'un projet partagent automatiquement le même backend et les mêmes données.

  Si vous atteignez la limite d'applications mobiles et souhaitez en créer une seconde, faites-le dans un nouveau projet. Si vous atteignez le total de 7 artefacts, supprimez un artefact existant avant d'en ajouter un autre, ou répartissez votre travail entre plusieurs projets.
</Accordion>

<Accordion title="Dois-je choisir un type avant de commencer ?">
  Non. Décrivez simplement ce que vous voulez et Agent choisit le bon type pour vous. Vous pouvez également choisir un type manuellement dans le menu déroulant si vous préférez.
</Accordion>

<Accordion title="Puis-je publier un seul artefact d'un projet ?">
  Pas actuellement. La publication déploie l'ensemble du projet ensemble, afin que tous les artefacts restent synchronisés. Si vous avez besoin d'un déploiement indépendant, utilisez des projets séparés.
</Accordion>

<Accordion title="Les artefacts partagent-ils des données entre eux ?">
  Oui. Tous les artefacts d'un projet partagent la même base de données et les mêmes services backend. Si votre application web écrit des données, votre application mobile et votre tableau de bord de données peuvent les lire immédiatement.
</Accordion>

<Accordion title="Quelle est la différence entre un artefact et un fichier ?">
  Les artefacts sont des éléments que vous pouvez publier — applications, présentations et vidéos. Les fichiers (comme les CSV, images ou code) sont des ressources dans votre projet qui soutiennent vos artefacts mais ne peuvent pas être publiés seuls.
</Accordion>

<Accordion title="Mon application mobile manque des fonctionnalités de mon application web. Que s'est-il passé ?">
  Lorsque Agent traduit des fonctionnalités entre les types d'artefacts, certaines choses peuvent ne pas se transférer parfaitement — en particulier les interactions ou mises en page qui fonctionnent différemment selon les plateformes. Vous pouvez faire un suivi dans le chat pour combler les lacunes.
</Accordion>

Pour une liste complète de ce que vous pouvez construire, consultez l'[aperçu des projets](/fr/replitai/projects).
