Os atalhos de teclado permitem executar comandos, modificar texto e navegar pelo Editor de Projeto
usando combinações de teclas configuráveis. Você pode definir e usar atalhos de teclado
no aplicativo web Replit.com.

## Visualizando atalhos de teclado

Para visualizar as configurações de atalhos de teclado, siga estas etapas:

1. Abra um Replit App para navegar até o Editor de Projeto.
2. Abra a aba <img class="icon-svg" src="/assets/mirror/settings-icon-c2664c3691bf.svg" alt="ícone de engrenagem" width="16" height="16" data-path="images/icons/settings-icon.svg" /> **Configurações do Usuário** em <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="ícone de todas as ferramentas" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **Todas as ferramentas** no dock.
   Como alternativa, pesquise "User Settings" usando a lupa <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="ícone de lupa" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" />.
3. Selecione a aba **Atalhos de teclado** para ver a lista de comandos e seus atalhos atribuídos.

## Personalizando atalhos de teclado

Para adicionar ou modificar um atalho de teclado, siga estas etapas:

1. Selecione <img class="icon-svg" src="/assets/mirror/create-app-icon-ba218e87fb67.svg" alt="ícone de mais" width="16" height="16" data-path="images/icons/create-app-icon.svg" />**Adicionar atalho**, localizado ao lado
   do comando não atribuído, ou o ícone <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="ícone de lápis" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> de lápis para comandos já atribuídos.
2. Quando "Gravando..." aparecer ao lado do comando, pressione a combinação de teclas que deseja atribuir.
   Para cancelar a gravação, clique em uma área vazia dentro da aba.
3. Para reverter o atalho, selecione o ícone <img class="icon-svg" src="/assets/mirror/rollback-icon-3197ed1b323b.svg" alt="ícone de reverter" width="12" height="12" data-path="images/icons/rollback-icon.svg" /> de reverter.

## Removendo atalhos de teclado

Para remover um atalho de teclado, selecione o ícone <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="ícone de lixeira" width="16" height="16" data-path="images/icons/trash-icon.svg" /> de lixeira ao lado do comando.

## Navegação por Tab

Você pode usar a navegação pela tecla **Tab** do navegador para navegar entre os elementos interativos
de uma página. No entanto, as ferramentas Editor de Arquivos, Console e Shell capturam a tecla **Tab** como
entrada para fins como indentação.

Para continuar percorrendo os elementos da página enquanto estiver nessas ferramentas, siga estas etapas:

1. Pressione **Esc** para liberar o foco das ferramentas
2. Pressione **Tab** para mover para o próximo elemento
