让用户通过 Google 账号登录你的网站有以下优势：

1. 无需自行实现认证方案。
2. 可轻松获取用户的姓名和联系信息。
3. 可使用同一组凭据访问用户的 Google 资源，例如 Sheets 和 Drive。

本指南将介绍如何在 Replit 中使用 Python 和 Flask 实现这一功能。

首先，我们将介绍如何设置基本的 OAuth 认证，然后说明如何使用获取的凭据访问用户的 Google 资源。

<div id="oauth">
  ## OAuth 概述
</div>

Google 认证基于 OAuth 标准。OAuth 的工作原理如下：

1. 在网站的某处引导用户前往登录页面。
2. 用户访问登录页面后，网站不会自行实现登录表单，而是将用户重定向到 Google 的登录服务进行登录。
3. Google 的登录服务成功登录用户后，会将用户重定向回你定义的 URL (例如：`https://YOUR_DOMAIN/oauth2callback`) ，同时传递用户和登录会话的相关信息。
4. 使用用户的登录信息获取访问令牌。它相当于访问用户个人资料、电子表格、文档等资源的通行证。

<div id="oauth-2">
  ## OAuth：直接上代码
</div>

如果你和我一样，只想先拿到能运行的代码，下面就是。不过，要让一切正常运行，你还需要在 Google Cloud Console 中进行一些配置。下一节会介绍这些内容。使用 [Flask 模板](https://replit.com/@replit/Flask?v=1) 创建一个新的 Replit App，并将以下内容输入到 `main.py` 中。代码中的注释说明了各个部分的作用：

```python theme={null}
from flask import Flask, redirect, session, url_for, request
import google_auth_oauthlib.flow
import json
import os
import requests

app = Flask('app')
# `FLASK_SECRET_KEY` 用于会话。你应创建一个随机字符串，
# 并将其存储为 Secret。
app.secret_key = os.environ.get('FLASK_SECRET_KEY') or os.urandom(24)

# `GOOGLE_APIS_OAUTH_SECRET` 包含从 Google Cloud 凭据面板下载的 JSON 文件内容。
# 请参阅下一节。
oauth_config = json.loads(os.environ['GOOGLE_OAUTH_SECRETS'])

# 此处配置 OAuth 流程
oauth_flow = google_auth_oauthlib.flow.Flow.from_client_config(
    oauth_config,
    # scopes 定义身份验证后你希望代表用户访问哪些 API
    scopes=[
        "https://www.googleapis.com/auth/userinfo.email",
        "openid",
        "https://www.googleapis.com/auth/userinfo.profile",
    ]
)

# 这是登录页面的入口。它会重定向到 `authorization_url` 中的 Google 登录服务。
# `redirect_uri` 是 Google 登录服务用来重定向回此 App 的 URI。
@app.route('/signin')
def signin():
    # 我们将 URL 从 http 改写为 https，因为 Replit App 内部使用 http，
    # 而外部通过 https 访问，redirect_uri 必须与之匹配
    oauth_flow.redirect_uri = url_for('oauth2callback', _external=True).replace('http://', 'https://')
    authorization_url, state = oauth_flow.authorization_url()
    session['state'] = state
    return redirect(authorization_url)

# 这是 Google 登录服务重定向回来的端点。必须将其添加到 Google Cloud 的 API 凭据面板中的“Authorized redirect URIs”。
# 它会调用 Google 端点来请求访问令牌，并将其存储在用户会话中。之后，可使用该访问令牌
# 代表用户访问 API。
@app.route('/oauth2callback')
def oauth2callback():
    if not session['state'] == request.args['state']:
        return 'Invalid state parameter', 400
    oauth_flow.fetch_token(authorization_response=request.url.replace('http:', 'https:'))
    session['access_token'] = oauth_flow.credentials.token
    return redirect("/")

# 这是 App 的主页。若用户尚未登录，会引导其登录。
# 若用户已登录，则显示其信息。
@app.route('/')
def welcome():
    if "access_token" in session:
        user_info = get_user_info(session["access_token"])
        if user_info:
            return f"""
                Hello {user_info["given_name"]}!<br>
                Your email address is {user_info["email"]}<br>
                <a href="/logout">Log out</a>
            """
    return """
        <h1>Hello!</h1>
        <a href="/signin">Sign In via Google</a><br>
    """

# 使用有效的访问令牌调用 userinfo API，以获取用户信息。
# 这是使用访问令牌代表用户访问 API 的第一个示例。
def get_user_info(access_token):
    response = requests.get("https://www.googleapis.com/oauth2/v3/userinfo", headers={
       "Authorization": f"Bearer {access_token}"
   })
    if response.status_code == 200:
        user_info = response.json()
        return user_info
    else:
        print(f"Failed to fetch user info: {response.status_code} {response.text}")
        return None

@app.route('/logout')
def logout():
    session.clear()
    return redirect('/')

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000)

```

<div id="google-sheets">
  ## Google Sheets 集成：查看代码
</div>

首先，保持原始代码中的 OAuth 流程部分不变，只需将 `"https://www.googleapis.com/auth/spreadsheets.readonly"` 添加到作用域列表中：

```python theme={null}
# 此处为 OAuth 流程配置
oauth_flow = google_auth_oauthlib.flow.Flow.from_client_config(
    oauth_config,
    # scopes 定义用户完成身份验证后，你希望代表用户访问哪些 API
    scopes=[
        "https://www.googleapis.com/auth/userinfo.email",
        "openid",
        "https://www.googleapis.com/auth/userinfo.profile",
        "https://www.googleapis.com/auth/spreadsheets.readonly"
    ]
)
```

要通过 `googleapiclient.discovery` 库访问 Google API，首先使用访问令牌创建 `Credentials` 对象，然后使用 `build` 函数创建可调用的 API 对象。对于 Sheets API，示例如下：

```python theme={null}
credentials = google.oauth2.credentials.Credentials(token=session['access_token'])
service = build("sheets", "v4", credentials=credentials)
sheets_api = service.spreadsheets()
```

为了演示 Sheets API 的实际用法，我们创建了一些辅助函数：

```python theme={null}
# 获取 Google 电子表格中的所有工作表
def get_sheets(sheets_api, spreadsheet_id) -> list[str]:
    result = sheets_api.get(spreadsheetId=spreadsheet_id).execute()
    return [sheet["properties"]["title"] for sheet in result["sheets"]]

# 获取 Google 电子表格中指定工作表的数据
def get_sheet_data(sheets_api, spreadsheet_id, sheet_title) -> list[list[str]]:
    result = (
        sheets_api.values()
        .get(spreadsheetId=spreadsheet_id, range=sheet_title)
        .execute()
    )
    return result["values"]
```

使用上述辅助函数，您可以按如下方式创建用于导入 Google 表格的处理端点：

```python theme={null}
@app.route("/import_spreadsheet", methods = ['POST'])
def import_spreadsheet():
    if 'access_token' not in session:
        return redirect('/signin')
    spreadsheet_id = request.form["spreadsheet_id"]
    credentials = google.oauth2.credentials.Credentials(token=session['access_token'])
    service = build("sheets", "v4", credentials=credentials)
    sheets_api = service.spreadsheets()
    try:
        sheets = get_sheets(sheets_api, spreadsheet_id)
        data_by_sheets = {}
        for sheet in sheets:
            data = get_sheet_data(sheets_api, spreadsheet_id, sheet)
            data_by_sheets[sheet] = data
    except googleapiclient.errors.HttpError as e:
        return f"upload failure"
    dirpath = os.path.join("static", "uploads", spreadsheet_id)
    filepath = os.path.join(dirpath, "data.json")
    os.makedirs(dirpath, exist_ok=True)
    with open(filepath, "w") as file:
        json.dump(data_by_sheets, file)
    return "upload success!"
```

完整的可运行代码如下：

```python theme={null}
from flask import Flask, redirect, session, url_for, request
import google_auth_oauthlib.flow
import json
import os
import requests
from googleapiclient.discovery import build
import googleapiclient.errors
import google.oauth2.credentials

app = Flask('app')
# 会话会使用 `FLASK_SECRET_KEY`。你应创建一个随机字符串，
# 并将其作为 Secrets 存储。
app.secret_key = os.environ.get('FLASK_SECRET_KEY') or os.urandom(24)

# `GOOGLE_APIS_OAUTH_SECRET` 包含从 Google Cloud 凭据面板下载的 JSON 文件内容。
# 请参阅下一节。
oauth_config = json.loads(os.environ['GOOGLE_OAUTH_SECRETS'])

# 这将配置 OAuth 流程
oauth_flow = google_auth_oauthlib.flow.Flow.from_client_config(
    oauth_config,
    # scopes 定义身份验证后你希望代表用户访问哪些 API
    scopes=[
        "https://www.googleapis.com/auth/userinfo.email",
        "openid",
        "https://www.googleapis.com/auth/userinfo.profile",
        "https://www.googleapis.com/auth/spreadsheets.readonly"
    ]
)

# 这是登录页面的入口。它会重定向到位于
# `authorization_url` 的 Google 登录服务。`redirect_uri` 是 Google 登录服务用于
# 重定向回此 App 的 URI。
@app.route('/signin')
def signin():

    # but externally it's accessed via https, and the redirect_uri has to match that
    oauth_flow.redirect_uri = url_for('oauth2callback', _external=True).replace('http://', 'https://')
    authorization_url, state = oauth_flow.authorization_url()
    session['state'] = state
    return redirect(authorization_url)

# 这是 Google 登录服务重定向回来的端点。必须将其添加到 Google Cloud 中 API 凭据面板的“已获授权的重定向 URI”。
# 它会调用 Google 端点来请求
# 访问令牌，并将其存储在用户会话中。之后，可以使用该访问令牌代表用户访问
# API。
@app.route('/oauth2callback')
def oauth2callback():

        return 'Invalid state parameter', 400
    oauth_flow.fetch_token(authorization_response=request.url.replace('http:', 'https:'))
    session['access_token'] = oauth_flow.credentials.token
    return redirect("/")

# 这是第一个使用访问令牌代表用户访问 API 的示例。
def get_user_info(access_token):

       "Authorization": f"Bearer {access_token}"
   })
    if response.status_code == 200:
        user_info = response.json()
        return user_info
    else:
        print(f"Failed to fetch user info: {response.status_code} {response.text}")
        return None

@app.route('/logout')
def logout():
    session.clear()
    return redirect('/')

# 获取 Google 电子表格中的所有工作表
def get_sheets(sheets_api, spreadsheet_id) -> list[str]:
    result = sheets_api.get(spreadsheetId=spreadsheet_id).execute()
    return [sheet["properties"]["title"] for sheet in result["sheets"]]

# 获取 Google 电子表格中指定工作表的数据
def get_sheet_data(sheets_api, spreadsheet_id, sheet_title) -> list[list[str]]:
    result = (
        sheets_api.values()
        .get(spreadsheetId=spreadsheet_id, range=sheet_title)
        .execute()
    )
    return result["values"]

# 显示一个用于导入电子表格的表单
@app.route("/import_spreadsheet_form")
def import_spreadsheet_form():
    return """
    <h3>Import Spreadsheet</h3>
    <form action="/import_spreadsheet" method="POST">
        <label>Spreadsheet ID</label>
        <input type="text" name="spreadsheet_id">

        <button type="submit">Import</button>
    </form>
    """

@app.route("/import_spreadsheet", methods = ['POST'])
def import_spreadsheet():
    if 'access_token' not in session:
        return redirect('/signin')
    spreadsheet_id = request.form["spreadsheet_id"]
    credentials = google.oauth2.credentials.Credentials(token=session['access_token'])
    service = build("sheets", "v4", credentials=credentials)
    sheets_api = service.spreadsheets()

    with open(filepath, "w") as file:

@app.route('/')
def welcome():
    if "access_token" in session:
        user_info = get_user_info(session["access_token"])
        if user_info:
            return f"""
            Hello {user_info["given_name"]}!<br>
            Your email address is {user_info["email"]}<br>
            <a href="/signin">Sign In to Google</a><br>
            <a href="/import_spreadsheet_form">Import a Sheet</a>
            """
    return """
    <h1>Welcome to Google Sheet Importer</h1>
    <a href="/signin">Sign In to Google</a><br>
    <a href="/import_spreadsheet_form">Import a Sheet</a>
    """

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000)
```
