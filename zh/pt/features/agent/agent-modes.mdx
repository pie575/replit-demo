Agent 模式让你在使用 Agent 时自行把握成本与能力之间的平衡。通过 Agent 设置下拉菜单可以选择 **Free Mode**、**Power Mode** 或 **Max Mode**。Free Mode 始终使用智能模型路由。在 Power 或 Max 模式下，Core 和 Pro 用户可以选择 **Auto**，让 Replit 为每项任务挑选合适的模型；也可以使用[模型选择器](/zh/features/agent/model-selector)手动选择模型。你能看到哪些模式和设置，取决于你的方案和 workspace。

<Note>
  Economy Mode 已不再提供，由 Power Mode 以相同价格取而代之。
</Note>

<Tip>
  **键盘快捷键：** 按 **⌘+Shift+I** (Windows 上为 Ctrl+Shift+I) 即可在不离开聊天输入框的情况下依次切换
  Agent 模式。
</Tip>

<div id="free-mode">
  ## Free Mode
</div>

**专为快速上手而设计。** Free Mode 可帮助你探索创意、熟悉 Replit 的使用方式，并着手创建 project。

**请注意：** Free Mode 始终采用智能模型路由。如需手动选择模型，请使用 Power Mode 或 Max Mode。

<Note>
  {FreeModePlanAvailability} 达到所属套餐的上限后，Replit
  会显示额度重置的时间。
</Note>

Routine 无法在 Free Mode 中运行，只能在 Power 或 Max Mode 中运行，并需要设置单次运行预算。详见 [Routine](/zh/chat/routines)。

<div id="intelligent-model-routing-auto">
  ## 智能模型路由 (Auto)
</div>

**针对自动选择模型进行了优化。** 在 Power Mode 或 Max Mode 下，Core 和 Pro 用户可以选择 **Auto**。此后，Replit 会为每项任务选择一个不超过所选模式能力上限的模型。参见[使用智能模型路由](/zh/chat/auto-mode)。

Auto 是 Free Mode 的付费替代方案，与其他 Power 和 Max 任务一样会消耗订阅额度。

Enterprise workspace 使用统一的 **Auto 模式**，而非 Free Mode。Enterprise Auto 可以为每项任务同时选择模式和允许使用的模型。

<div id="power-mode">
  ## Power Mode
</div>

**成本优先。** Power Mode 每个任务消耗的额度更少；当你既想要出色的结果，又不想为最强的模型付费时，它是最佳的默认选择。

**最适合：** 日常构建、学习，以及在现有 project 中注重成本的工作。

<div id="max-mode">
  ## Max Mode
</div>

**以能力为先。** Max Mode 采用能力更强的模型，用于处理复杂任务、大型代码库和更棘手的问题。

**适用场景：** 生产级项目、复杂功能，以及希望 Agent 交付最佳结果的场合。

<div id="which-mode-should-i-use">
  ## 我该使用哪种模式？
</div>

可参考以下指南：

| 目标                        | 推荐模式                                                           |
| ------------------------- | -------------------------------------------------------------- |
| 探索想法、了解 Replit 的运作方式并开启项目 | Free Mode                                                      |
| 让 Replit 为付费任务自动选择模型      | Power Mode 或 Max Mode 中的 Auto                                  |
| 让每个积分支持尽可能多的 prompt       | Power Mode                                                     |
| 在大多数项目中兼顾成本与质量            | Power Mode                                                     |
| 手动选择模型                    | Power Mode 或 Max Mode                                          |
| 在复杂的生产级任务中获得最佳效果          | Max Mode                                                       |
| 在最复杂的任务中获得最优结果            | Max Mode 搭配更高的 [Effort](/zh/features/agent/model-selector#effort) |

在聊天输入框中使用 Agent 设置下拉菜单选择模式。在 Power 或 Max 模式下，Core 和 Pro 用户可以使用 Auto，也可以自行设置[主模型和 Effort](/zh/features/agent/model-selector)。没有哪种模式永远最优，请根据手头的任务选择合适的模式。

<div id="settings-in-shared-projects">
  ## 共享 project 中的设置
</div>

Agent 设置绑定的是你个人，而非 project。当你邀请队友加入某个 project 后，你们各自保留自己的以下选择：

* 模式 (Free Mode、Power Mode 或 Max Mode)
* [主模型与 Effort](/zh/features/agent/model-selector) (可用时)
* [Plan Mode](/zh/features/agent/plan-mode)
* 后台任务的自动合并
* 计划的自动批准

队友在下一个任务中切换到 Max Mode，并不会把你的设置也改成 Max Mode。无论 project 中有多少协作者，你在 Agent 设置下拉菜单中看到的模式和设置，就是你发送下一条消息时 Agent 实际使用的配置。

<div id="check-your-free-mode-usage">
  ## 查看你的 Free Mode 用量
</div>

打开 **Settings** → **Usage**，即可查看当前的 Free Mode 限额和重置时间。实用技巧请参阅[充分利用 Free Mode](/zh/chat/free-mode)。
