## Workspace

### Controles de layout no Editor Visual

O Editor Visual agora possui controles dedicados de **Layout** para que você possa ajustar o layout flexbox visualmente em vez de pedir ao Agent para reescrever os estilos. Selecione qualquer contêiner, expanda a seção Layout e escolha uma direção flex, alinhamento e justificação. Defina um espaço em pixels entre os itens ou ative o botão **Espaço entre** para empurrar os elementos filhos para as bordas opostas.

O painel do editor também foi reagrupado em seções mais claras de **Texto**, **Imagem**, **Layout**, **Cor** e **Borda** para que o controle necessário seja mais fácil de encontrar.

## Agente

### Configurações do Agent permanecem suas em projetos compartilhados

Suas preferências do Agent, como nível de modelo, modo de planejamento, auto-merge e aprovação automática de plano, agora ficam vinculadas a você em vez de serem compartilhadas com todos no projeto. Um colega de equipe que muda para o Modo Power nas tarefas dele não altera mais as suas configurações também. A configuração que você escolhe é a que o Agent usa quando você envia a próxima mensagem, mesmo em projetos com muitos colaboradores.

Saiba mais sobre os [Modos do Agent](/pt/features/agent/agent-modes#settings-in-shared-projects).

### Agent sugere Modo Power quando você está travado

Quando o Agent percebe que você está tendo o mesmo problema repetidamente no Modo Economy, ele agora sugere mudar para Power na sua próxima mensagem. A sugestão procura por solicitações repetidas ou código que continua falhando, e aparece no máximo uma vez por projeto. O Agent ignora a sugestão em sessões de planejamento, quando você já mencionou uma preocupação com orçamento ou quando você está no plano gratuito.

### Menu suspenso de configurações de tarefas mais limpo

O menu suspenso que abre no cabeçalho de uma tarefa ficou mais fácil de usar. O título da tarefa ativa ou do planejamento agora fica no topo com renomeação inline, as configurações de automação (aplicar automaticamente, aprovar automaticamente) ficam em sua própria seção entre o título e as ações, e o popover tem largura fixa para parar de se mover conforme os nomes das tarefas mudam. Linhas de automação desativadas ficam ocultas para que o menu mostre apenas o que se aplica à tarefa atual.

## Integrações

### Dois novos conectores: Quiver AI e Browserbase

Dois novos serviços estão agora disponíveis no catálogo de conectores. Abra o painel **Integrações** e selecione **Adicionar nova integração** para conectar qualquer um deles.

* **Quiver AI**: Gere ilustrações SVG e vetorize imagens raster por meio de uma API gerenciada. Útil quando o Agent precisa de um ativo SVG limpo sob demanda.
* **Browserbase**: Execute navegadores headless gerenciados para busca, pesquisa e automação completa de sessões. Útil quando o Agent precisa carregar uma página web real, executar JavaScript ou interagir com um site que bloqueia requisições HTTP simples.
