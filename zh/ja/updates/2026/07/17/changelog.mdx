<div id="agent">
  ### 有多个选项时，Agent 会推荐连接器
</div>

当你请求 Agent 连接某项服务时，如果有多个提供方可选，Agent 现在会列出一个简短的清单供你选择。此前，Agent 需要先向你提问确认。选定提供方并登录一次后，Agent 就会继续构建。

</Frame>

进一步了解[连接器](/zh/ja/features/integrations/overview#let-agent-suggest-a-connector)。

<div id="workspace">
  ## Workspace
</div>

<div id="tools">
  ### 全新 Tools 面板来了
</div>

应用可用的所有功能，如今都集中在工作区的同一个位置。新的固定式 Tools 面板将 Database、Auth、Domains、Secrets 等整合在一起，让你一眼就能找到完整的工具集。工具本身没有任何变化，只是挪到了更好找的地方。

<Frame>
  <img src="/assets/mirror/tools-pane-ceaddcc1d7a2.png" alt="工作区的 Tools 面板，在 Replit Cloud 下方列出 Publishing、Domains、Monitoring、Growth、Database、Users and Auth、安全中心、App Storage" width="390" height="716" data-path="images/changelog/2026-07-17/tools-pane.png" />
</Frame>

点击此处，详细了解 [Tools 面板](/zh/ja/features/editor/editor-and-tools)。

<div id="section-2">
  ### 更快的任务侧边栏
</div>

任务侧边栏现已升级为信息更密集、一眼即可掌握全局的任务导航器。每个任务都配有专属悬浮卡片，可查看快捷操作和详细信息；进入任务看板的入口更加醒目，展开或折叠侧边栏时任务的位置也不再变动。

<Frame>
  <img src="/assets/mirror/task-sidebar-7687ab8089b2.png" alt="工作区的任务侧边栏，显示 Main、Board、New 任务以及任务列表和所选任务的 Apply changes 卡片" width="1228" height="556" data-path="images/changelog/2026-07-17/task-sidebar.png" />
</Frame>

想了解更多，请查看[任务生命周期](/zh/ja/features/agent/task-lifecycle)。
