O Web Search é valioso para encontrar os pacotes, ferramentas e informações mais recentes. Isso garante que seus apps usem as melhores práticas atuais e sejam mais precisos.

## Recursos

Crie aplicativos com informações atuais usando o Web Search do Agent. Isso elimina a necessidade de pesquisa manual e coleta de dados. Seja criando um dashboard com dados financeiros ou construindo um site com as startups mais recentes, o Web Search garante que seu app reflita a realidade.

O Agent pode realizar as seguintes ações de Web Search:

* **Pesquisa**: Encontre informações atuais, documentação mais recente e dados em tempo real da internet
* **Busca de conteúdo**: Recupere informações detalhadas de sites e URLs específicos
* **Citações de fontes**: Veja exatamente de onde o Agent obteve as informações para que você possa verificar e referenciar as fontes

## Uso

O Web Search está integrado ao Agent — não há nada para ativar. Descreva o que você quer criar e o Agent determina automaticamente quando pesquisar na web para obter informações atuais. Inclua palavras-chave como "pesquise", "investigue" ou "use o Web Search" no seu prompt para indicar explicitamente ao Agent que faça uma busca.

### Como o Web Search aprimora seus apps

O Web Search transforma seus aplicativos, substituindo dados fictícios por informações reais e precisas:

| Benefício                        | Descrição                                                                                     |
| -------------------------------- | --------------------------------------------------------------------------------------------- |
| Tecnologia atualizada            | Seus apps usam as informações e pacotes mais recentes, não presentes nos dados de treinamento |
| Seleção das melhores ferramentas | O Agent pesquisa opções para escolher os pacotes mais adequados                               |
| Melhores práticas atuais         | Acesso aos padrões de desenvolvimento e práticas de segurança mais recentes                   |
| Superação de limitações          | Supere limites de conhecimento para usar pacotes lançados após o treinamento                  |
| Dados precisos                   | Seus apps exibem informações atuais em vez de exemplos desatualizados                         |
| Resultados profissionais         | Aplicativos que referenciam empresas reais parecem mais confiáveis                            |
| Economia de tempo                | Evite pesquisar pacotes manualmente e coletar dados                                           |

### Citações de fontes

Quando o Agent usa o Web Search, ele fornece **citações de fontes** que mostram exatamente de onde as informações vieram. Use essas citações para:

* **Verificar informações**: Confira a confiabilidade e precisão das fontes
* **Aprender mais**: Visite as fontes originais para obter mais contexto
* **Referenciar fontes**: Inclua atribuição adequada em seus aplicativos
* **Acompanhar a pesquisa**: Entenda quais informações embasaram o trabalho do Agent

### Busca de conteúdo

O Agent pode buscar conteúdo detalhado de sites específicos para reunir informações abrangentes para o seu projeto. Isso permite que o Agent:

* Leia páginas inteiras para extrair detalhes relevantes
* Processe documentação e materiais de referência
* Colete pontos de dados específicos de fontes confiáveis
* Integre informações estruturadas ao seu aplicativo

<Warning>
  Sempre verifique as informações dos resultados do Web Search, especialmente para aplicativos críticos. Embora o Agent pesquise em fontes confiáveis, confirme detalhes importantes para aplicativos em produção.
