---
title: "Устранение неполадок в мобильных приложениях"
description: "Решение распространённых проблем при создании мобильных приложений с помощью Expo и React Native на Replit."
---

При создании мобильных приложений на Replit могут возникать проблемы с предпросмотром, сборкой пакета или зависимостями. В этом руководстве описано, как решать распространённые проблемы — от быстрых исправлений до подробных шагов отладки.

<div id="section">
  ## Быстрые решения
</div>

Сначала попробуйте эти способы — они устраняют большинство проблем:

| Проблема                                | Что попробовать                                              |
| --------------------------------------- | ------------------------------------------------------------ |
| Изменения не появляются на смартфоне    | Встряхните смартфон, откройте меню Expo и нажмите **Reload** |
| Изменения не появляются в предпросмотре | Нажмите **R** в консоли, чтобы пересобрать бандл             |
| Приложение зависает или не отвечает     | Остановите приложение в консоли и запустите его заново       |

<div id="section-2">
  ## Распространённые проблемы
</div>

<AccordionGroup>
  <Accordion title="Изменения не применяются на устройстве">
    Если внесённые изменения не отображаются на смартфоне:

    1. **Встряхните смартфон**, чтобы открыть меню разработчика Expo
    2. Нажмите **Reload**, чтобы заново загрузить бандл

    В веб-предпросмотре нажмите **R** в консоли, чтобы пересобрать бандл.

    Если изменения по-прежнему не применяются, попробуйте очистить кэш (см. раздел [Очистка кэша Metro](#clear-the-metro-cache) ниже).
  </Accordion>

  <Accordion title="В Expo Go отображается красный экран с ошибкой">
    Красный экран ошибки обычно указывает на ошибку JavaScript или отсутствующий модуль. Прочитайте сообщение об ошибке — часто в нём указаны конкретный файл и строка.

    **Распространённые причины:**

    * Пакет не установлен или установлена неверная версия
    * Модуль работает в вебе, но не работает в нативной среде (или наоборот)
    * Синтаксическая ошибка в коде

    **Что попробовать:**

    1. Внимательно прочитайте сообщение об ошибке — часто в нём точно указано, в чём проблема
    2. Отправьте это сообщение Agent и попросите помочь с исправлением
    3. Если в ошибке упоминается конкретный пакет, попробуйте переустановить зависимости (см. [Переустановка пакетов](#reinstall-packages))
  </Accordion>

  <Accordion title="Работает в веб-версии, но вылетает на смартфоне (или наоборот)">
    Некоторые пакеты и функции работают по-разному в зависимости от платформы. React Native компилируется под три цели: iOS, Android и веб. Библиотека, работающая в вебе, может не поддерживать нативные платформы или требовать другой настройки.

    **Что попробовать:**

    1. Проверьте в документации пакета, какие платформы поддерживаются
    2. Спросите у Agent: «Совместим ли этот пакет с Expo Go?»
    3. Если поддержки на мобильных устройствах нет, рассмотрите возможность перенести функцию на сервер

    <Tip>
      Изучая пакет, ищите отметку «Expo compatible» или проверьте список поддерживаемых модулей в [документации Expo SDK](https://docs.expo.dev/versions/latest/).
    </Tip>
  </Accordion>

  <Accordion title="Не удаётся отсканировать QR-код или подключить приложение">
    **Проверьте сеть:**

    * Смартфон и компьютер должны быть подключены к одной и той же сети Wi-Fi
    * В корпоративных и публичных сетях подключение может блокироваться

    **Попробуйте режим туннеля:**
    Если вы используете сеть с ограничениями, режим туннеля направит трафик через серверы Expo. Попросите Agent запустить приложение в режиме туннеля или выполните команду `npx expo start --tunnel` в Shell.

    **Перезапустите Expo Go:**
    Перед сканированием полностью закройте Expo Go и откройте его заново.
  </Accordion>

  <Accordion title="Сборка выполняется слишком долго">
    Первая сборка всегда занимает больше времени, так как кэш ещё не создан. Последующие сборки должны проходить быстрее.

    **Что влияет на время сборки:**

    * количество пакетов в проекте
    * первый запуск после очистки кэша
    * скорость сети при загрузке пакетов

    Если сборка стабильно выполняется медленно, проверьте, не установлены ли лишние пакеты.
  </Accordion>

  <Accordion title="Ошибка «Модуль не найден»">
    Если появляется сообщение «Unable to resolve module» или «Module not found»:

    1. Возможно, пакет не установлен — попросите Agent установить его
    2. Возможно, пакет установлен, но кэш устарел — очистите кэш
    3. Возможно, пакета не существует или его название написано с ошибкой — проверьте имя пакета

    Если модуль должен быть на месте, попробуйте [переустановить пакеты](#reinstall-packages).
  </Accordion>
</AccordionGroup>

<div id="section-3">
  ## Команды отладки
</div>

Если быстрые решения не помогли, с помощью этих команд можно сбросить различные кэши и состояния. Выполните их в Shell.

<div id="metro">
  ### Очистка кэша Metro
</div>

Metro — это сборщик, который компилирует код React Native. Очистка кэша принудительно запускает новую сборку.

Выполните в Shell следующую команду:

```bash theme={null}
npx expo start --clear
```

Это очистит кэш бандлера и перезапустит сервер разработки. В выводе появится сообщение «Bundler cache is empty. Rebuilding.».

<Tip>
  Если проблемы с кэшем возникают часто, можно добавить `-c` к команде запуска. Попросите Agent добавить флаг очистки в команду разработки.
</Tip>

<div id="section-4">
  ### Переустановка пакетов
</div>

Если возникают ошибки модулей или несоответствия версий, переустановка пакетов часто помогает решить проблему.

Выполните в Shell следующую команду:

```bash theme={null}
rm -rf node_modules && npm install
```

При этом все установленные пакеты будут удалены и установлены заново с нуля на основе `package.json`.

<Note>
  Если в проекте используется другой менеджер пакетов (например, `bun` или `pnpm`), выполните соответствующую команду установки: `bun install` или `pnpm install`.
</Note>

<div id="section-5">
  ### Проверка несоответствия версий
</div>

Expo Doctor сканирует проект и выявляет распространённые проблемы, например несоответствие версий между пакетами.

Выполните в Shell следующую команду:

```bash theme={null}
npx expo-doctor
```

Проверьте предупреждения в выводе. Если предлагаются исправления, оцените их внимательно — бездумное обновление пакетов может создать новые проблемы, если в новой версии есть обратно несовместимые изменения.

<Warning>
  Обновляйте пакеты только при наличии конкретной причины. Обновление «на всякий случай» может сломать приложение, если в новой версии есть обратно несовместимые изменения.
</Warning>

<div id="section-6">
  ## Полный сброс
</div>

Если другие способы не помогают, полный сброс очистит все кэши и переустановит всё заново.

<Accordion title="Радикальный вариант: команда полного сброса">
  Эта команда удаляет все кэши и устанавливает пакеты заново с нуля. Используйте её как крайнюю меру.

  ```bash theme={null}
  rm -rf node_modules .expo && npm cache clean --force && npm install && npx expo start --clear
  ```

  **Что она делает:**

  1. `rm -rf node_modules` — удаляет установленные пакеты
  2. `rm -rf .expo` — удаляет локальный кэш Expo
  3. `npm cache clean --force` — очищает глобальный кэш npm
  4. `npm install` — переустанавливает все пакеты
  5. `npx expo start --clear` — запускает проект с очищенным кэшем Metro

  После выполнения этой команды следующая сборка займёт больше времени, так как всё будет пересобрано с нуля.
</Accordion>

<div id="section-7">
  ### Очистка кэша устройства
</div>

Если после перезагрузки в приложении на смартфоне по-прежнему выполняется старый код:

* **iOS**: в Expo Go откройте **Settings** и нажмите **Clear Cache**
* **Android**: перейдите в **Settings &gt; Apps &gt; Expo Go &gt; Storage &gt; Clear Cache**

  ## Краткий справочник
</div>

| Проблема                             | Что попробовать сначала      | Что попробовать затем            |
| ------------------------------------ | ---------------------------- | -------------------------------- |
| Изменения не применяются             | Встряхните смартфон → Reload | Очистите кэш Metro               |
| Ошибка бандлера                      | `npx expo start --clear`     | Удалите node&#95;modules         |

| Предупреждение о несовпадении версий | Выполните `npx expo-doctor`  | Оцените предложенные исправления |

| Изменён app.json                     | Перезапустите сервер         | —                                |

<div id="section-9">
  ## Если нужна дополнительная помощь
</div>

Если проблема всё ещё не решена:

* **Спросите Agent**: опишите ошибку и то, что вы уже пробовали. Часто Agent сам находит причину и устраняет проблему.
* **Загляните в документацию Expo**: [руководство Expo по устранению неполадок](https://docs.expo.dev/troubleshooting/overview/) охватывает дополнительные сценарии.
* **Поищите ошибку**: скопируйте точный текст сообщения об ошибке и выполните поиск — скорее всего, кто-то уже сталкивался с той же проблемой.
