<div id="animated-agent-icon">
  ### 动效 Agent 图标
</div>

Agent 图标现在会在运行期间播放动画，让你更直观地看到 Agent 正在工作。这一改进提升了速度感知，也让你更容易在初始规划阶段观察 Agent 的动态，尤其是在居中的 Chat 布局中，反馈就出现在你的请求附近。

<div id="agent-tools-dropdown-in-planning-flow">
  ### 规划流程中的 Agent 工具下拉菜单
</div>

Agent 工具下拉菜单现已支持在初始规划和任务列表确认流程中使用。你可以在开始构建前就配置好偏好的 Agent 设置，包括自主级别等选项。

<div id="at-symbol-filename-support-in-agent">
  ### Agent 支持 @ 文件名
</div>

Agent 现在除了 `/` 命令外，还支持使用 `@` 引用文件名，与主流开发工具的设计保持一致。该功能是企业用户以及熟悉 Cursor 式工作流的资深用户呼声最高的需求之一。

<div id="connectors-support-for-remixing">
  ### Connectors 支持 Remix
</div>

此前，Remix 任何使用了 connector 的 Replit App 都会导致集成失效，因为 Remix 出的 repl 不会自动获得使用该 connector 的授权。我们已更新 Remix 流程，让它能妥善处理 connector：

* Remix 时会提示用户设置所需的 connector
* Remix 过程会明确指出哪些集成需要配置
* Remix 后不再出现集成失效的问题

进一步了解 [Agent 集成](/zh/replitai/integrations)和[管理你的 connector](/zh/replitai/managing-connectors)。

<div id="analytics-dashboard-for-enterprise-admins">
  ### 面向 Enterprise 管理员的分析仪表板
</div>

Enterprise 管理员现在可以使用功能全面的分析仪表板——这是 Meta、Atlassian 等企业客户呼声很高的功能。该仪表板提供：

* **用户活动监控**：跟踪组织内的使用与协作情况
* **资源用量跟踪**：按用户和 Replit App 监控支出
* **部署监督**：随时掌握部署活动
* **成本管理**：清晰了解资源消耗与成本
