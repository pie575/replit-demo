skill 是一个存放可复用指令和配套文件的文件夹。你可以用它来自定义 Replit 处理某项重复性任务、约定或工作流的方式。

在 prompt 输入框中，点击**加号 (+)** 菜单，然后选择**使用 skill**。挑选与任务匹配的 skill，并告诉 Replit 你想要的结果。

<div id="escolha-a-conexo-certa">
  ## 选择合适的连接方式
</div>

* 需要可复用的指令、示例和辅助材料时，使用 **skill**。
* 需要连接受支持的服务并使用其授权信息或操作时，使用[集成](/zh/pt/chat/integrate-your-tools)。
* 需要使用兼容的 MCP 服务器或客户端所公开的工具时，使用 [MCP](/zh/pt/chat/connect-through-mcp)。
