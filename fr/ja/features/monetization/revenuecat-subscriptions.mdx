<div id="revenuecat">
  ## Qu&#39;est-ce que RevenueCat ?
</div>

RevenueCat vous permet d&#39;ajouter des abonnements in-app à vos [applications mobiles natives](/fr/ja/features/artifact-types/building-mobile-apps). Pour commencer, demandez à Agent de configurer les abonnements, puis connectez votre compte RevenueCat : Agent se charge de la logique et met à votre disposition un environnement de test.

<div id="section">
  ## Prérequis
</div>

Avant de commencer, vous devez disposer des éléments suivants :

* Un projet Replit créé avec **Mobile app**
* Un compte [RevenueCat](https://www.revenuecat.com) (une adresse e-mail et un mot de passe suffisent — aucun compte bancaire ni configuration supplémentaire n&#39;est requis)

<Note>
  Pour travailler sur des applications mobiles natives, utilisez l&#39;éditeur de projet sur [replit.com](https://replit.com). Ce travail est également possible depuis l&#39;application Replit pour Android, lorsque la prise en charge est disponible. Si vous utilisez l&#39;application Replit pour iOS, ouvrez votre projet sur replit.com.
</Note>

  ## Pour commencer
</div>

<Steps>
  <Step title="Demandez à Agent d’ajouter un abonnement">
    Décrivez l’abonnement souhaité. Agent planifiera l’intégration, installera les packages et configurera RevenueCat.

    </Frame>
  </Step>

  <Step title="Connectez votre compte RevenueCat">

    <Frame>
      <img src="/assets/mirror/revenuecat-connect-1463c331a55f.png" alt="Chat Agent affichant une bannière Connect RevenueCat avec un bouton Connect" width="1957" height="1133" data-path="images/replitai/revenuecat-connect.png" />

    <Frame>
      <img src="/assets/mirror/revenuecat-connect-modal-34362346bf1d.png" alt="Fenêtre modale Connect RevenueCat affichant des informations sur la confidentialité et la sécurité" width="1957" height="1133" data-path="images/replitai/revenuecat-connect-modal.png" />

    Sur la page d’autorisation RevenueCat, sélectionnez l’accès **Read &amp; Write**, puis **Authorize** afin d’autoriser Replit à accéder à votre compte RevenueCat.

    </Frame>
  </Step>
</Steps>

<div id="section-3">
  ## Tester les abonnements
</div>

L&#39;aperçu de Replit utilise le **mode test** de RevenueCat. Lorsque vous effectuez un achat de test dans Expo Go, une boîte de dialogue d&#39;achat de test s&#39;affiche à la place du véritable flux de paiement. Aucun montant n&#39;est réellement facturé.

<Frame>
  <img src="/assets/mirror/revenuecat-test-purchase-8414145a112e.png" alt="Boîte de dialogue d'achat de test sur un appareil mobile affichant les détails du forfait et un bouton de test" width="683" height="1253" data-path="images/replitai/revenuecat-test-purchase.png" />
</Frame>

<Tip>
  Les achats de test s&#39;utilisent en toute sécurité pendant le développement. Vous pouvez tester aussi bien les flux d&#39;achat réussis que ceux ayant échoué, sans aucune facturation réelle.
</Tip>

<Warning>
  Une fois qu&#39;Apple a approuvé votre application pour une distribution sur l&#39;App Store, les achats sont effectués avec de l&#39;argent réel.
  Avant de soumettre votre application à l&#39;App Review, vérifiez que les produits et les tarifs RevenueCat sont corrects.
</Warning>

<div id="section-4">
  ## Gérer les abonnements
</div>

Pour modifier un abonnement, demandez-le à Agent. Par exemple :

<AiPrompt>Modify the subscription to be $9.99/yr instead</AiPrompt>

Agent met à jour la configuration des produits RevenueCat, l&#39;interface du paywall et la logique d&#39;abonnement en fonction de vos modifications.

</Frame>

<div id="app-store-connect">
  ## Synchronisation avec App Store Connect
</div>

Pour que les achats intégrés fonctionnent dans TestFlight et sur l&#39;Apple App Store, vous devez [accepter le Paid Apps Agreement d&#39;Apple et connecter un compte bancaire](https://developer.apple.com/help/app-store-connect/manage-agreements/sign-and-update-agreements/).
Cette opération s&#39;effectue depuis App Store Connect. Avant de soumettre votre app à l&#39;App Store, vous devez disposer d&#39;un Apple Developer Account payant.

Vous pouvez ensuite synchroniser la configuration des achats intégrés de RevenueCat avec App Store Connect directement depuis Replit.

<Steps>
  <Step title="Accédez au volet Manage de Publishing">
    Le bouton permettant de synchroniser RevenueCat avec App Store Connect s&#39;affiche.

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-sync-btn-46a2e4e696df.png" alt="Bouton permettant de synchroniser RevenueCat avec App Store Connect" width="1476" height="604" data-path="images/replitai/revenuecat-asc-sync-btn.png" />
    </Frame>

    <Tip>
      Cette section s&#39;affiche uniquement après avoir envoyé l&#39;application à TestFlight.
    </Tip>
  </Step>

  <Step title="Fournissez la clé API App Store Connect">
    Vous devez accéder à App Store Connect pour fournir cette clé.

    Dans [App Store Connect](https://appstoreconnect.apple.com/access/integrations/api), accédez à **Users and Access**, puis sélectionnez l&#39;onglet **Integrations**. Dans la barre latérale, sélectionnez **App Store Connect API**.

    Lors de la création de la clé, accordez l&#39;autorisation « App Manager ».

    Téléchargez le fichier .p8 maintenant : vous ne pourrez le télécharger qu&#39;une seule fois. Son nom commence par `AuthKey_` et se termine par `.p8`.

    Copiez le **Key ID** et l&#39;**Issuer ID** affichés sur cette page.

    <Frame>

    </Frame>

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-app-manager-93996acd8561.png" alt="Boîte de dialogue Generate API Key d'App Store Connect avec le nom RevenueCat et l'accès défini sur App Manager" width="1116" height="560" data-path="images/replitai/revenuecat-asc-app-manager.png" />

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-copy-07a95e1be9af.png" alt="Page des clés API App Store Connect avec une flèche pointant vers le lien Copy de l'Issuer ID et la colonne Key ID" width="2330" height="780" data-path="images/replitai/revenuecat-asc-copy.png" />

  </Step>

  <Step title="Créez une clé API pour les achats intégrés">
    Répétez l&#39;étape précédente pour la clé API des achats intégrés.
    Dans la barre latérale, sélectionnez **In-App Purchase**, puis créez une clé API avec l&#39;autorisation **App Manager**.
    Téléchargez la clé .p8 (son nom commence par `SubscriptionKey_` et se termine par `.p8`). Copiez le **Key ID** et l&#39;**Issuer ID**.

<div id="section-5">
  ## Questions fréquentes
</div>

<AccordionGroup>
  <Accordion title="Un compte bancaire est-il nécessaire pour utiliser RevenueCat ?">
    Non. La création d&#39;un compte RevenueCat ne nécessite qu&#39;une adresse e-mail et un mot de passe. La configuration du compte bancaire se fait séparément, auprès d&#39;Apple ou de Google, lorsque vous êtes prêt à recevoir les paiements de l&#39;App Store ou de Google Play.
  </Accordion>

  <Accordion title="Les achats de test sont-ils facturés ?">
    Non. Pendant le développement, l&#39;aperçu Replit utilise le mode test de RevenueCat. Les achats sont simulés et aucun montant n&#39;est réellement facturé. La facturation réelle n&#39;intervient qu&#39;une fois votre application approuvée par l&#39;App Review d&#39;Apple.
  </Accordion>

  <Accordion title="Puis-je utiliser RevenueCat dans une application web ?">
    RevenueCat est conçu pour les applications mobiles natives. Pour ajouter des abonnements à une application web, utilisez plutôt l&#39;[intégration Stripe](/fr/ja/features/monetization/stripe-payments).
  </Accordion>

  <Accordion title="Que puis-je configurer avec RevenueCat ?">
    Vous pouvez mettre en place des abonnements mensuels ou annuels, définir les tarifs, gérer les droits d&#39;accès et créer des paywalls. Demandez les modifications à Agent — il prend en charge aussi bien la configuration de RevenueCat que le code de l&#39;application.
  </Accordion>
</AccordionGroup>
