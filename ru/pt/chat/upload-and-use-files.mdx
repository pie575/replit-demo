<div id="como-enviar-um-arquivo">
  ## Как загрузить файл
</div>

В поле промпта нажмите кнопку **плюс (+)** и выберите **Загрузить файл**. Также можно перетащить файл в поле промпта. Добавьте файл перед отправкой запроса, для которого он нужен.
