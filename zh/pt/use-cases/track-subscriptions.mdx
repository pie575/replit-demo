<div id="o-que-esperar">
  ## 预期结果
</div>

Agent 会生成一张包含供应商、金额、计费周期和月度总额的表格。请对照原始邮件，抽查其中几行。首次运行可能会遗漏邮件主题中未包含“订阅”的供应商；添加这些标记后再运行一次。选择三家你熟悉的供应商，在 Gmail 中打开收据，并在确认月度总额前核实金额和计费周期。

<div id="soluo-de-problemas">
  ## 故障排除
</div>

* **表格中缺少您已知的订阅：**告诉 Agent 要使用哪个 Gmail 标签或搜索条件，并补充邮件主题中未写“订阅”的供应商。抽查几行，与原始邮件核对。
* **金额或周期似乎不正确：**收据通常会显示税费、积分或其他币种。请 Agent 保留邮件中的明细金额和计费周期，并标记由其推断出的行。
* **同一供应商出现两次：**请 Agent 按供应商名称合并，保留最新的收据，然后重新计算每月总额。
