自动扩缩容部署运行在云计算资源上，可根据需要扩展或缩减，以高效应对 Replit App 的网络流量和工作负载。当应用繁忙时，自动扩缩容会添加服务器来处理负载；当应用空闲时，则会将服务器数量缩减至零以节省资源。

自动扩缩容部署尤其适合以下场景：

* 工作负载和流量波动较大的 Web 应用，例如电商网站
* API 和服务

<div id="recursos">
  ## 功能
</div>

自动扩缩容部署 提供以下功能：

* **资源自动扩缩容**：根据流量模式自动调整资源，以优化成本。
* **自定义域名**：配置自定义域名，或使用 `<nome-do-app>.replit.app` URL 访问你的 App。
* **可配置上限**：设置已发布 App 可扩展到的最大实例数。
* **灵活的机器规格**：选择满足 App 需求的 CPU 和 RAM 配置。
* **监控**：查看日志并监控已发布 App 的状态。

<div id="uso">
  ## 使用
</div>

您可以在 Project Editor 的 Publishing 工具中访问 Autoscale Deployment。

<Accordion title="如何访问 Autoscale Deployment">
  在左侧的**工具停靠栏**中：

  1. 选择 <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="所有工具图标" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**，查看 Project Editor 中的工具列表。
  2. 选择 <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Publishing 图标" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publishing**。
  3. 选择 **Autoscale**，然后选择 **Set up your published app**。

  在**搜索栏**中：

  1. 选择顶部的 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 放大镜图标，打开搜索工具。
  2. 输入“Publishing”以找到该工具，然后在搜索结果中选择它。
  3. 选择 **Autoscale**，然后选择 **Set up your published app**。
</Accordion>

<div id="capacidade-da-mquina">
  ## 机器容量
</div>

选择 **Edit** 查看并设置机器容量选项。使用滑块为已发布 App 的每个服务器实例选择 CPU 和 RAM 配置。

在 **Total per machine** 一行中查看该配置的 **计算单元** 成本。计算单元是根据机器的内存和 CPU 配置衡量云计算资源的单位。

如需了解如何根据计算单元计算成本，请参阅[计算单元](/zh/pt/billing/about-usage-based-billing#2-compute-units)。

<div id="nmero-mximo-de-mquinas">
  ## 最大机器数
</div>

使用滑块调整最大机器数。当系统检测到你的 App 繁忙时，自动扩缩容功能最多可分配这么多服务器实例。

底部显示等效的计算单元，按以下公式计算：

`机器数量 * 每台机器的计算单元`
