<div id="section">
  ## Qu&#39;est-ce que la visualisation de données ?
</div>

Une visualisation de données est un tableau de bord interactif ou un outil de reporting que vous créez au fil d&#39;une conversation avec Agent. Il vous suffit de décrire ce que vous souhaitez visualiser et où se trouvent vos données : Agent sélectionne automatiquement les KPI, les types de graphiques et la mise en page appropriés, puis génère un tableau de bord complet à partir d&#39;un seul prompt.

Concepts clés :

* **Génération en une seule fois** : décrivez vos objectifs et vos sources de données, et Agent construit un tableau de bord complet avec les graphiques et les métriques adaptés
* **Sources de données connectées** : récupérez vos données depuis une base de données, un [connecteur d&#39;entrepôt](/fr/ja/connectors/warehouses/overview), une API externe ou des fichiers téléversés
* **Fonctionnalités intégrées** : chaque tableau de bord inclut l&#39;actualisation, l&#39;actualisation automatique, l&#39;export PDF, l&#39;export des graphiques en CSV et le mode clair/sombre
* **Résumés analytiques** : Agent dégage des enseignements à partir de votre demande et des données obtenues
* **Artefacts multiples** : une visualisation de données peut partager le même backend et la même base de données que les autres artefacts du [même projet](/fr/ja/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project)

<div id="section-2">
  ## Utiliser la visualisation des données
</div>

<div id="section-3">
  ### Créer à partir d&#39;un prompt
</div>

Sélectionnez l&#39;onglet **Apps** sur la page d&#39;accueil et décrivez le tableau de bord que vous souhaitez créer. Agent détecte les prompts liés aux données et sélectionne la pile technique de visualisation de données.

**Exemples de prompts :**

* « Crée un tableau de bord d&#39;analyse des ventes qui suit les ventes par région »
* « Crée un outil de reporting qui visualise les métriques mensuelles »
* « Crée un tableau de bord affichant les produits les plus vendus à partir des données de vente de BigQuery »
* « Connecte-toi à Snowflake et crée un tableau de bord d&#39;analyse de l&#39;attrition client »

<div id="section-4">
  ### Créer depuis le menu déroulant
</div>

1. Accédez à l&#39;onglet **Apps** de la page d&#39;accueil.
2. Ouvrez le menu déroulant des types d&#39;app.
3. Sélectionnez **Visualisation de données**.
4. Décrivez le tableau de bord ou l&#39;outil de données que vous souhaitez créer.

<div id="section-5">
  ### Se connecter à un entrepôt de données
</div>

Connectez vos visualisations de données à BigQuery, Databricks ou Snowflake grâce aux [connecteurs d&#39;entrepôt](/fr/ja/connectors/warehouses/overview), et créez des tableaux de bord à partir de vos jeux de données existants.

Lorsque vous interrogez les données de l&#39;entrepôt, Agent explore les schémas et les jeux de données à l&#39;aide d&#39;une recherche multi-agents parallèle. L&#39;exploration est ainsi plus rapide et Agent sélectionne plus facilement les tables et les champs adaptés à votre tableau de bord.

Pour commencer, configurez un connecteur d&#39;entrepôt dans les [Intégrations](/fr/ja/features/integrations/overview) de votre projet, puis indiquez à Agent ce que vous souhaitez visualiser.

<div id="section-6">
  ### Ajouter des filtres et des fonctionnalités
</div>

Une fois qu’Agent a créé votre tableau de bord, vous pouvez lui demander, via un prompt, d’ajouter des filtres, des options d’exploration détaillée et d’autres fonctionnalités interactives. Par exemple, demandez à Agent d’ajouter un filtre de plage de dates, un sélecteur de région ou une barre de recherche.

<div id="section-7">
  ### Exportation et partage
</div>

* **Exporter en PDF** : exportez l&#39;intégralité du tableau de bord au format PDF pour le partager ou le consulter hors ligne.
* **Exporter un graphique en CSV** : téléchargez les données d&#39;un graphique donné sous forme de fichier CSV afin de les analyser plus en détail dans un tableur ou d&#39;autres outils.
* **Documents d&#39;analyse** : demandez à Agent de rédiger des documents d&#39;analyse détaillés à partir des données de votre tableau de bord.

<div id="section-8">
  ## Ce que vous pouvez créer
</div>

* **Tableaux de bord analytiques** : suivez les métriques clés telles que les ventes, les inscriptions ou l&#39;engagement sur plusieurs périodes
* **Outils de reporting** : créez des rapports internes que les parties prenantes peuvent filtrer et explorer sans accès direct à la base de données
* **Interfaces d&#39;exploration de données** : consultez et interrogez des jeux de données avec un retour visuel
* **Panneaux de surveillance** : affichez des données en temps réel ou quasi réel provenant d&#39;API, de bases de données et de services externes

<div id="section-9">
  ## Questions fréquentes
</div>

<Accordion title="À quelles sources de données puis-je me connecter ?">
  Vous pouvez récupérer des données depuis la base de données Replit du projet, des connecteurs d&#39;entrepôt (BigQuery, Databricks, Snowflake), des API externes ou des fichiers téléversés tels que des CSV. Configurez les connexions d&#39;entrepôt via les [Intégrations](/fr/ja/features/integrations/overview).
</Accordion>

<Accordion title="Puis-je personnaliser l'apparence et le design ?">
  Oui. Vous pouvez personnaliser les couleurs, la mise en page et la typographie au fil de la conversation — demandez à Agent d&#39;harmoniser le rendu avec votre marque ou d&#39;ajuster le design. Les tableaux de bord prennent également en charge le mode clair et le mode sombre.
</Accordion>

<Accordion title="Agent peut-il analyser mes données ?">
  Une fois le tableau de bord créé, Agent génère un résumé analytique à partir de votre demande et des données obtenues. Vous pouvez également demander un document d&#39;analyse plus détaillé.
</Accordion>

<Accordion title="Puis-je combiner des visualisations de données avec d'autres types d'artefacts ?">
  Oui. Vous pouvez combiner des visualisations de données avec des [applications web](/fr/ja/features/artifact-types/web-apps), des [présentations](/fr/ja/features/artifact-types/slide-decks) et d&#39;autres types d&#39;artefacts au sein d&#39;un [même projet](/fr/ja/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project). Ils partagent alors le même backend et la même base de données.
</Accordion>
