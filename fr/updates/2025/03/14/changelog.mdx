<div id="neon-db-history-retention">
  ### rétention de l'historique de Neon DB
</div>

La rétention d’historique configurable est désormais disponible pour les bases de données Neon afin de vous aider à mieux maîtriser vos coûts. Cette fonctionnalité répond directement aux retours sur la gestion des coûts des bases de données.

<div id="enhanced-link-context-features">
  ### fonctionnalité de contexte de lien améliorée
</div>

Vous pouvez désormais afficher des aperçus en direct du contenu des liens (captures d’écran et texte) dans Assistant et Agent. Cette fonctionnalité est également disponible dans l’app mobile Replit.

<div id="assistant-model-selection">
  ### Sélection du modèle Assistant
</div>

Pour les builders Advanced, il est désormais possible de revenir à Claude 3.5 Sonnet v2 dans les paramètres d’Assistant. Des améliorations de performances sont en cours pour Claude 3.7 Sonnet.

<div id="web-view-performance-improvements">
  ### Amélioration des performances de Web View
</div>

Profitez d&#39;une navigation plus fluide dans les iframes et d&#39;une meilleure compatibilité avec les sites web sécurisés dans Web View. Le système de proxy a été amélioré afin de gérer plus intelligemment les headers de sécurité, éliminant ainsi les blocages de navigation frustrants que vous avez pu rencontrer auparavant.
