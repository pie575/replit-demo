<div id="melhorias-de-desempenho-do-assistant">
  ### Assistant 性能提升
</div>

Assistant 近期的性能改进获得了客户和用户的好评。性能提升让所有 Assistant 用户都能享受更流畅的体验。这些改进与 Agent 的上下文收集机制相互独立，但可能会为未来的优化提供参考。

<div id="melhorias-na-confiabilidade-do-agent">
  ### Agent 可靠性提升
</div>

我们正在发布多项修复，以提升 Agent 的可靠性，包括减少引发故障的变更、解决在异常 nix 环境中的卡死问题，以及修复 bash 工具执行方面的问题。
