<Note>
  Admin API는 **베타** 단계입니다. 제공되는 endpoint와 동작 방식은 변경될 수 있습니다.
</Note>

Admin API는 Enterprise account admin에게 계정 분석 및 관리 기능에 대한 scope 기반 프로그래밍 방식 접근을 제공합니다. 이 API로 Enterprise 계정의 내부 보고, 운영 워크플로우, 통합을 구축할 수 있습니다.

<div id="who-can-access-the-admin-api">
  ## Admin API를 사용할 수 있는 대상
</div>

Admin API는 Enterprise 계정의 **account admin**만 사용할 수 있습니다. account admin은 API key를 생성하고 관리할 수 있습니다. workspace admin을 비롯한 그 외 계정 멤버은 Admin API에 접근하거나 해당 키를 생성할 수 없습니다.

Enterprise 관리자 역할에 대해 자세히 알아보려면 [Account and Workspace Admins](/ko/teams/identity-and-access-management/account-and-workspace-admins)를 참조하세요.

<div id="create-an-api-key">
  ## API key 생성
</div>

<Steps>
  <Step title="Developer 설정 열기">
    **Settings**를 엽니다. **Account** 아래에서 **Developer**를 선택합니다.
  </Step>

  <Step title="API key 생성">
    **Create API key**를 선택한 후 읽기 전용 또는 읽기 및 쓰기 권한을 선택합니다.
  </Step>

  <Step title="키를 안전하게 보관">
    `rpl_`로 시작하는 키를 복사해 안전한 secret 관리 도구에 보관하세요. 비밀번호와 동일하게 취급하고 절대 공유하지 마세요.
  </Step>

  <Step title="통합 인증">
    API 요청 시 이 키를 Bearer token으로 함께 전송하세요.
  </Step>
</Steps>

<div id="what-you-can-do">
  ## 할 수 있는 작업
</div>

Admin API는 scope를 사용해 각 키가 수행할 수 있는 작업을 제어합니다. 읽기 scope는 리포팅에 필요한 계정 데이터를 제공하고, 특정 쓰기 scope는 예산 업데이트와 같은 작업을 지원합니다.

* **Usage:** 계정 사용량와 총 원장 비용을 조회하고, Workspace, 멤버, project, 기간별로 필터링하거나 그룹화합니다.
* **Workspaces:** 멤버 및 project 수, 관리자, 생성 시간을 비롯한 Workspace 목록과 세부 정보를 조회합니다.
* **Members:** 계정 및 Workspace membership을 조회하고, 역할별로 필터링하거나 이름, 사용자 이름, 이메일로 검색합니다.
* **Projects:** Team Workspaces 전반의 projects를 조회하고, 공개 범위나 deployment 상태로 필터링하거나 제목, 슬러그, 설명으로 검색합니다.
* **Budgets:** 계정 예산을 조회하고, `write:budgets` scope로 예산을 업데이트합니다.

API 응답은 커서 페이지네이션을 지원하며, rate limit headers와 요청 추적용 `X-Request-Id`를 포함합니다.

<div id="build-reports-and-workflows">
  ## 보고서 및 워크플로우 구축
</div>

내부 대시보드, Slack 알림, 월간 재무 보고서 등 이미 운영 현황을 추적하고 있는 곳이라면 어디에나 Admin API 데이터를 활용할 수 있습니다. 예를 들어 사용량을 Workspace별로 묶어 각 Workspace의 지출을 보고할 수 있습니다.

<div id="building-with-replit-agent">
  ## Replit Agent로 만들기
</div>

Replit Agent에게 Admin API를 활용한 맞춤형 대시보드를 만들어 달라고 요청할 수 있습니다. Workspace별 usage나 project별 비용처럼 추적하려는 Account 데이터를 설명하면 Agent가 대시보드와 API 통합까지 구축해 줍니다.

<Steps>
  <Step title="skill 선택기 열기">
    Replit project에서 채팅 입력창 옆의 **+** 버튼을 클릭한 다음 **Use a skill**을 선택합니다.
  </Step>

  <Step title="Admin API skill 선택하기">
    **Replit skills**에서 **Admin API**를 선택하면 Agent에 API context와 통합 가이드가 제공됩니다.
  </Step>

  <Step title="대시보드 설명하기">
    무엇을 추적하고 어떤 방식으로 보고 싶은지 Agent에게 알려주세요. 예를 들어 Workspace별 usage와 project별 비용을 보여주는 대시보드를 만들어 달라고 요청할 수 있습니다.
  </Step>

  <Step title="API key를 안전하게 추가하기">
    Agent가 API 요청을 보내야 한다면 Admin API key를 project의 Secrets에 추가하세요. 키를 Chat에 붙여넣거나 project에 commit하지 마세요.
  </Step>
</Steps>
