---
title: "文件历史"
description: "了解如何使用 文件历史 的自动保存点恢复代码的历史版本。"
---

首先，在 Project Editor 中打开一个文本文件，然后点击右下角的 **History** 按钮。

<Frame>
  <img src="/assets/mirror/history-button-afac6496660a.png" alt="打开历史记录" width="377" height="292" data-path="images/programming-ide/history-button.png" />
</Frame>

<div id="visualizando-verses-anteriores-de-um-arquivo">
  ## 查看文件的历史版本
</div>

打开 文件历史 后，您可以使用滚动条、箭头按钮或**左**、**右**箭头键查看文件的历史版本。

<Frame>
  <img src="/assets/mirror/history-versioning-1a055ecab411.gif" alt="滚动条演示" width="764" height="720" data-path="images/animations/history-versioning.gif" />
</Frame>

<div id="comparando-verses-anteriores-com-o-arquivo-atual">
  ## 将历史版本与当前文件进行比较
</div>

点击 文件历史 面板左下角的 Compare Latest 按钮，即可查看该版本与最新版本之间的内联差异。

<Frame>
  <img src="/assets/mirror/compare-history-46fb16debd3a.gif" alt="与最新版本进行比较" width="772" height="720" data-path="images/animations/compare-history.gif" />
</Frame>

<div id="restaurando-uma-verso-anterior-de-um-arquivo">
  ## 恢复文件的历史版本
</div>

如果您想将文件恢复到历史版本，只需点击 `Restore` 按钮即可。无需担心，您不会丢失任何历史记录。恢复到历史版本后，该版本会作为新版本添加到文件历史记录中。

<Frame>
  <img src="/assets/mirror/restore-history-5f616d7f961a.webp" alt="恢复历史记录示意图" width="720" height="495" data-path="images/animations/restore-history.webp" />
</Frame>

<div id="visualizando-a-reproduo-do-file-history">
  ## 查看 文件历史 回放
</div>

您可以使用 文件历史 回放功能，以影片形式查看文件随时间推移的变化。这有助于创建编程过程的视频。

</Frame>
