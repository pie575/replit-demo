Replit AI Integrations simplifie la création d&#39;applications dopées à l&#39;IA. Lancez-vous immédiatement avec les modèles d&#39;OpenAI, Anthropic, Google et OpenRouter — sans créer de compte développeur ni gérer de clés API. Replit s&#39;occupe de tout pour vous.

<div id="what-is-replit-ai-integrations">
  ## Qu&#39;est-ce que Replit AI Integrations ?
</div>

Replit AI Integrations offre un accès géré aux modèles d&#39;IA des principaux providers. Créez des applications de chat, des générateurs de contenu et des outils basés sur l&#39;IA sans quitter Replit. Inutile de créer des comptes développeur externes, de retrouver vos identifiants d&#39;API ou de gérer une facturation distincte.

Lorsque vous utilisez Replit AI Integrations, Replit gère les identifiants du provider et vous facture au prix public de l&#39;API. Votre consommation est débitée de vos crédits Replit et apparaît sur votre [page d&#39;utilisation](/fr/billing/managing-spend), détaillée par Replit App existante.

<Note>
  Replit AI Integrations nécessite un forfait payant (Core, Pro ou Enterprise). Vous pouvez toujours créer des applications d&#39;IA avec votre propre clé d&#39;API sur le [forfait Starter](/fr/billing/plans/starter-plan). Consultez [Disponibilité selon les forfaits](#plan-availability).
</Note>

<div id="features">
  ## Fonctionnalités
</div>

Replit AI Integrations simplifie le développement d&#39;IA grâce à un accès intégré et une facturation transparente :

* **Aucune configuration requise** : ni compte développeur ni clé API nécessaires pour démarrer
* **Identifiants gérés** : Replit prend en charge l&#39;authentification auprès des providers et la gestion des identifiants
* **Facturation transparente** : vous payez les tarifs publics des API, débités de vos crédits Replit
* **Suivi de la consommation** : consultez votre consommation par Replit App existante sur votre page d&#39;utilisation
* **Prise en charge multitechnologie** : compatible avec tous les langages de programmation et frameworks
* **BYOK en option** : utilisez votre propre clé API si vous préférez vos propres identifiants

<div id="getting-started">
  ## Premiers pas
</div>

<div id="using-replit-managed-credentials">
  ### Utiliser les identifiants gérés par Replit
</div>

Sur une formule payante, lorsque vous mentionnez une fonctionnalité d&#39;IA ou des providers spécifiques (OpenAI, Anthropic, Google ou OpenRouter) dans votre prompt, Agent utilise par défaut les intégrations Replit AI :

<AiPrompt>
  Créer une web app qui utilise OpenAI pour résumer des articles
</AiPrompt>

Pour savoir quelle integration est utilisée, repérez la mention **« OpenAI (Replit managed) »**, **« Anthropic (Replit managed) »**, **« Google (Replit managed) »** ou **« OpenRouter (Replit managed) »** dans la réponse à votre prompt initial. Elle indique qu&#39;Agent utilisera les identifiants de Replit plutôt que d&#39;exiger votre propre clé API.

**Pour les créations initiales** : lorsque vous soumettez un prompt initial pour créer une nouvelle app dotée de fonctionnalités d&#39;IA, les intégrations Replit AI sont associées automatiquement. Agent se met immédiatement à construire avec les identifiants gérés par Replit.

**Pour les Replit Apps existantes** : lorsqu&#39;Agent détecte que vous souhaitez ajouter des fonctionnalités d&#39;IA à une Replit App existante, il vous indique explicitement dans le Project Editor qu&#39;il demande à utiliser les intégrations Replit AI plutôt que votre propre clé API. Une demande de confirmation s&#39;affiche :

<Frame>
  <img src="/assets/mirror/replit-ai-integrations-confirmation-msg-9440681ad7d3.png" alt="Boîte de dialogue Confirm OpenAI Integration affichant un message indiquant que OpenAI est ajouté via le service géré de Replit, sans clé API requise, avec les boutons Dismiss et Approve" width="924" height="294" data-path="images/replitai/replit-ai-integrations-confirmation-msg.png" />
</Frame>

Cliquez sur « Approve » pour continuer avec les identifiants gérés par Replit, ou sur « Dismiss » si vous préférez utiliser votre propre clé API.

Votre utilisation est automatiquement suivie et facturée sur votre compte Replit au tarif public de l&#39;API.

<div id="bringing-your-own-api-key">
  ### Utiliser votre propre clé API
</div>

Si vous préférez utiliser vos propres identifiants OpenAI, Anthropic, Google ou d&#39;autres providers plutôt que les intégrations d&#39;IA de Replit, plusieurs options s&#39;offrent à vous :

**Pour les créations initiales** : précisez dans votre prompt que vous souhaitez utiliser votre propre clé API :

<AiPrompt>
  Crée une web app qui utilise OpenAI pour résumer des articles. Utilise ma propre clé API OpenAI.
</AiPrompt>

Le nom du provider apparaît alors dans la réponse (sans la mention « Replit managed »), ce qui indique qu&#39;Agent va demander votre clé API.

**Pour les Replit Apps existantes** : lorsque Agent vous indique qu&#39;il souhaite utiliser les intégrations d&#39;IA de Replit et affiche le message de confirmation, cliquez sur « Dismiss » plutôt que sur « Approve ».

Dans les deux cas, Agent construit jusqu&#39;au premier checkpoint avant de demander votre clé API. Il peut ainsi mettre en place la structure de votre project, puis s&#39;interrompre pour recueillir vos identifiants.

Lorsque vous utilisez votre propre clé API, la facturation est assurée directement par le provider et non via les crédits Replit.

<div id="supported-providers">
  ## Fournisseurs pris en charge
</div>

Les intégrations d&#39;IA Replit prennent actuellement en charge :

* **OpenAI** : modèles multimodaux pour la génération de texte, le raisonnement et l&#39;audio. Prend en charge les complétions de chat, les réponses, la génération d&#39;images, la transcription audio (`gpt-4o-transcribe`, `gpt-4o-mini-transcribe`) et la sortie audio (`gpt-audio`, `gpt-audio-mini`).
* **Anthropic** : modèles multimodaux pour le raisonnement, la rédaction et le code. Prend en charge l&#39;API Messages et les interactions avec la recherche web.
* **Google (Gemini)** : modèles multimodaux pour la génération de texte et le raisonnement. Prend en charge la génération de texte et d&#39;images.
* **OpenRouter** : accès aux modèles de fournisseurs tels que Microsoft (série Phi), Meta (série Llama), Mistral, Qwen, DeepSeek, Nvidia, Amazon, et bien d&#39;autres.

<Note>
  Les intégrations d&#39;IA Replit prennent en charge les **sorties texte, image et audio**. La sortie vidéo n&#39;est pas prise en charge. Si vous avez besoin de générer des vidéos, vous devrez utiliser votre propre clé API auprès d&#39;un fournisseur qui propose cette fonctionnalité.
</Note>

<div id="openrouter-privacy-and-availability">
  ## Confidentialité et disponibilité d&#39;OpenRouter
</div>

Lorsque vous utilisez OpenRouter via les intégrations d&#39;IA Replit, vos requêtes sont envoyées avec des paramètres de confidentialité spécifiques afin de protéger vos données. Il est important de bien comprendre ces paramètres, car ils peuvent avoir une incidence sur les modèles mis à votre disposition.

<div id="privacy-settings-for-self-serve-users">
  ### Paramètres de confidentialité pour les utilisateurs en libre-service
</div>

Pour les utilisateurs individuels et les équipes, Replit configure les requêtes OpenRouter avec les paramètres de confidentialité par défaut suivants :

* **Entraînement désactivé sur les points de terminaison payants** : vos données ne seront pas utilisées à des fins d&#39;entraînement par les fournisseurs de modèles payants
* **Entraînement activé sur les points de terminaison gratuits** : les fournisseurs de modèles gratuits peuvent entraîner leurs modèles sur vos prompts et complétions
* **Publication activée sur les points de terminaison gratuits** : les fournisseurs gratuits peuvent publier vos prompts et complétions dans des jeux de données publics
* **Journalisation des entrées/sorties désactivée** : vos requêtes et réponses ne sont pas journalisées par OpenRouter en échange de la remise de 1 % sur la facturation
* **Cookies d&#39;analyse désactivés** : aucun cookie d&#39;analyse n&#39;est utilisé

Ces paramètres privilégient votre confidentialité tout en donnant accès à la plus large gamme de modèles possible. Certains **modèles peuvent toutefois être indisponibles** s&#39;ils exigent des paramètres de confidentialité différents de ceux indiqués ci-dessus.

<div id="privacy-settings-for-enterprise">
  ### Paramètres de confidentialité pour Enterprise
</div>

Pour les organisations Enterprise, Replit applique des contrôles de confidentialité plus stricts :

* **Points de terminaison à conservation zéro des données (ZDR) uniquement** : seuls les modèles assortis d&#39;une politique de conservation zéro des données sont disponibles
* Tous les paramètres de confidentialité listés ci-dessus pour les utilisateurs en libre-service s&#39;appliquent également
* Les requêtes Enterprise sont ainsi acheminées exclusivement vers des points de terminaison qui ne conservent aucune donnée

Enterprise imposant l&#39;usage exclusif de points de terminaison ZDR, **le choix de modèles disponibles est plus restreint** que pour les utilisateurs en libre-service. Ce compromis garantit le plus haut niveau de confidentialité des données pour les charges de travail d&#39;entreprise.

<div id="plan-availability">
  ## Disponibilité selon les forfaits
</div>

Replit AI Integrations nécessite un forfait payant. Les modalités d&#39;accès dépendent de votre forfait.

<div id="starter-free">
  ### Starter (gratuit)
</div>

Avec le plan Starter, Replit AI Integrations est désactivé. Vous pouvez toutefois créer des applications d&#39;IA en utilisant votre propre clé API. Consultez [Utiliser votre propre clé API](#bringing-your-own-api-key).

<div id="core">
  ### Core
</div>

Avec le plan Core, vous pouvez créer des applications d&#39;IA grâce aux intégrations Replit AI, avec des identifiants gérés par Replit — aucune clé API à gérer.

<div id="pro-and-enterprise">
  ### Pro et Enterprise
</div>

Pour les organisations Pro et Enterprise, l&#39;accès aux intégrations Replit AI est désactivé par défaut. Les administrateurs de l&#39;organisation peuvent en gérer l&#39;accès depuis la page des paramètres de l&#39;organisation :

1. Accédez aux paramètres de votre organisation
2. Repérez la section Replit AI Integrations
3. Activez ou désactivez l&#39;accès pour votre organisation

Une fois l&#39;accès activé, les membres de l&#39;organisation peuvent utiliser les intégrations Replit AI dans leurs apps. L&#39;ensemble de l&#39;utilisation est suivi et facturé au compte de l&#39;organisation. Si l&#39;accès est désactivé, les membres devront fournir leurs propres clés API pour utiliser les providers de modèles d&#39;IA.

<div id="use-cases">
  ## Cas d&#39;usage
</div>

Créez des applications d&#39;IA puissantes, quelle que soit la stack :

* **Génération de contenu** : résumer des articles, générer des descriptions, créer du contenu
* **Analyse et insights** : extraire des informations clés, analyser le sentiment, classer du texte
* **Interfaces conversationnelles** : créer des chatbots et des assistants IA
* **Transformation de texte** : traduire, réécrire ou mettre en forme du contenu
* **Aide au code** : générer des extraits de code, expliquer des algorithmes, relire du code
