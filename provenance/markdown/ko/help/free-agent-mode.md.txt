# 무료 에이전트 모드

> 무료 모드가 Starter, Core, Pro 구독자에게 어떻게 무료 Agent 사용을 제공하는지 알아보세요.

<Note>
  일부 허용량 세부 정보는 출시 시점까지 조정될 수 있습니다.
</Note>

무료 모드를 사용하면 Starter, Core, Pro 구독자가 추가 비용 없이 Agent를 사용할 수 있습니다. Starter는 기존 한도와 함께 무료 모드를 포함합니다. Core와 Pro는 무료 모드 허용량을 포함합니다. 대화를 시작해 탐색하거나, 계획하거나, 만들거나, 도움을 요청하세요. 요청에 유료 모드나 유료 작업이 필요한 경우, Replit은 비용이 발생하는 작업이 시작되기 전에 이를 명확히 알려줍니다.

## 이런 점이 좋습니다

* 설정 과정 대신 대화로 바로 시작합니다.
* 더 많은 기능이 필요한지 결정하기 전에 아이디어를 탐색하고 진행할 수 있습니다.
* 유료 작업이 필요한 요청에서도 주도권을 유지합니다.
* 무료 모드에서 완료한 작업에 명확한 **Free** 라벨이 표시됩니다.

## 작동 방식

1. 새로운 Starter, Core, Pro 세션은 무료 모드로 시작됩니다.
2. 무료 모드 범위에 맞는 작업은 유료 작업 알림 없이 계속됩니다.
3. 유료 모드가 요청을 더 잘 처리할 수 있는 경우, Agent가 이를 설명하고 선택지를 제공합니다.
4. 해당 요청에 한해 유료 모드를 허용하거나, Agent에게 무료 모드로 계속하도록 요청할 수 있습니다.
5. 일회성 유료 승격 후에는 모드가 다시 무료 모드로 돌아갑니다.

## 세 가지 Agent 모드

<CardGroup cols={3}>
  <Card title="Free">
    Starter, Core, Pro 구독자를 위한 무료 Agent 작업입니다.
  </Card>

  <Card title="Power">
    더 많은 기능이 필요한 작업을 위한 합리적인 가격의 유료 중간 등급 모드입니다.
  </Card>

  <Card title="Max">
    가장 까다로운 작업을 위한 최고 등급 유료 모드로, 최상의 프론티어 모델을 제공합니다.
  </Card>
</CardGroup>

무료 모드는 Starter, Core, Pro 구독자가 사용할 수 있습니다. Starter는 기존 한도와 함께 무료 모드를 포함합니다. Core와 Pro는 무료 모드 허용량을 포함하며, Pro는 더 큰 주간 한도를 포함합니다. 더 많은 기능이 필요할 때는 유료 Agent 모드를 선택할 수도 있습니다.

<Note>
  **한도에 도달한 경우:** Starter는 기존 한도와 함께 무료 모드를 포함합니다. Core와 Pro의 경우 무료 모드 허용량은 5시간마다 재설정되며 주간 한도가 있습니다. **Settings → Usage**에서 현재 상태를 확인하세요. 한도에 가까워지면 Replit이 미리 알려드립니다. 한도에 도달하면 계속하려면 유료 모드로 전환하거나 재설정을 기다리세요.
</Note>

## 자주 묻는 질문

<AccordionGroup>
  <Accordion title="무료 모드가 정말 무료인가요? Replit이 이제 무료인가요?">
    무료 모드는 Starter, Core, Pro 구독에 포함되어 있습니다. Starter는 기존 한도와 함께 무료 모드를 포함합니다. Core와 Pro는 무료 모드 허용량을 포함합니다. 이는 그 자체로 무료 플랜은 아닙니다.
  </Accordion>

  <Accordion title="이것이 유료 Agent 모드와 같은 건가요?">
    아니요. 무료 모드는 허용량 내에서 무료로 사용하는 Agent입니다. Power와 Max는 더 많은 기능이 필요한 작업을 위한 유료 모드입니다.
  </Accordion>

  <Accordion title="Economy와 Power는 어떻게 됐나요? 모드가 변경됐나요?">
    유료 모드의 이름이 변경되었습니다. Economy는 이제 Power이며, 합리적인 가격에 강력한 모델을 제공하는 중간 등급 모드입니다. 이전에 Power라고 불렸던 모드는 이제 최고 등급 모드인 Max입니다. 기존 모드 설정은 새 이름으로 그대로 유지됩니다.
  </Accordion>

  <Accordion title="어떤 모드가 가장 뛰어난가요?">
    Max입니다. Power는 합리적인 가격에 더 많은 기능을 제공하는 유료 중간 등급 모드입니다. Max는 가장 까다로운 작업을 위한 유료 최고 등급 모드입니다.
  </Accordion>

  <Accordion title="요청에 유료 작업이 필요하면 어떻게 되나요?">
    Agent는 요청에 유료 모드나 유료 기능이 필요하다는 것을 설명하고 진행하기 전에 확인을 요청합니다. 해당 요청을 한 번만 승인하거나 무료 모드로 계속 진행할 수 있습니다.
  </Accordion>

  <Accordion title="Agent가 업그레이드를 제안하면 자동으로 요금이 청구되나요?">
    아니요. 유료 승격은 유료 요청이 시작되기 전에 사용자의 확인이 필요합니다.
  </Accordion>

  <Accordion title="유료 옵션을 거절할 수 있나요?">
    네. 무료 모드에서 계속 작업할 수 있습니다.
  </Accordion>

  <Accordion title="유료 승격을 승인한 후에는 어떻게 되나요?">
    승인은 해당 요청에만 적용됩니다. 이후 Agent 모드는 무료 모드로 돌아갑니다.
  </Accordion>

  <Accordion title="왜 한도에 도달했나요? 언제 재설정되나요?">
    Starter는 기존 한도와 함께 무료 모드를 포함합니다. Core와 Pro의 경우 무료 모드 허용량은 5시간마다 재설정되며 주간 한도가 있습니다. **Settings → Usage**에서 현재 상태를 확인하세요. 한도에 도달하면 계속하려면 유료 모드로 전환하거나 재설정을 기다리세요.
  </Accordion>

  <Accordion title="Enterprise에서도 무료 모드를 사용할 수 있나요?">
    출시 시점에는 사용할 수 없습니다. Enterprise 워크스페이스는 이후 곧 전용 Agent 경험을 제공받게 됩니다. 자세한 내용은 관리자에게 문의하세요.
  </Accordion>
</AccordionGroup>

## 무료 모드에 대해 더 알아보기

<AccordionGroup>
  <Accordion title="무료 모드가 Lite와 같은 건가요?">
    Starter 사용자의 경우, 이전에 Lite라고 불렸던 경험이 이제 무료 모드입니다. 더 저렴한 모델을 위해 Lite를 사용했다면, auto를 끈 상태에서 Power 내에서 해당 모델을 수동으로 선택할 수 있습니다.
  </Accordion>

  <Accordion title="무료 모드로 전체 앱을 만들 수 있나요?">
    네. 무료 모드에서 완전한 앱을 만들고 반복해서 개선할 수 있습니다.
  </Accordion>

  <Accordion title="Free, Power, Max는 어떻게 다른가요?">
    무료 모드는 Starter, Core, Pro 구독자를 위한 일상적인 Agent 작업을 무료로 제공합니다. Starter는 기존 한도와 함께 무료 모드를 포함합니다. Core와 Pro는 무료 모드 허용량을 포함합니다. Power는 합리적인 가격에 더 많은 기능을 제공하는 유료 중간 등급 모드입니다. Max는 가장 까다로운 작업을 위한 유료 최고 등급 모드입니다.
  </Accordion>

  <Accordion title="언제 무료 모드에서 전환해야 하나요?">
    일상적인 작업에는 무료 모드를 유지하세요. 복잡한 작업에서 더 강력한 결과를 원하거나 무료 모드가 제공하지 않는 기능이 필요할 때 전환하세요.
  </Accordion>

  <Accordion title="무료 모드로 동영상을 생성할 수 있나요?">
    아니요. 동영상 생성은 무료 모드의 일부가 아닌 유료 모드 기능입니다.
  </Accordion>

  <Accordion title="새로운 Conversations 경험은 무엇인가요?">
    채팅과 생성 기능이 함께 유지됩니다. 같은 대화 내에서 아이디어를 조사하고, 작업을 계획하거나, 프로젝트를 시작할 수 있습니다.
  </Accordion>

  <Accordion title="독립된 채팅이 게시된 앱의 일부가 되나요?">
    아니요. 프로젝트를 생성하거나 변경하기 전까지 대화는 별도로 유지됩니다.
  </Accordion>

  <Accordion title="무료 모드로 기존 프로젝트에서 작업할 수 있나요?">
    네. 기존 프로젝트의 일상적인 유지 관리와 수정 작업을 지원합니다.
  </Accordion>
</AccordionGroup>

**지금 사용해 볼까요?** 무료 모드가 출시되면 Agent와의 대화를 시작해 보세요.
