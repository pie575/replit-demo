<Note>
  想要求用户通过 SSO 登录你的 **Replit organization** (登录 replit.com) ？这需要单独配置——请参阅 [单点登录 (SAML SSO)](/zh/teams/identity-and-access-management/saml)。本页面介绍如何为你在 Replit 上构建的**应用**的登录流程添加 SSO。
</Note>

让用户通过其公司的身份提供方 (如 Okta 或 Microsoft Entra ID) 登录你的应用。如果你的应用使用 [Clerk Auth](/zh/features/auth-and-identity/clerk-auth)，可通过 Clerk 控制台配置 SSO 和其他高级身份验证功能。向 Agent 说明你的需求，Agent 会引导你前往控制台完成设置。

<Frame>
  <img src="/assets/mirror/sso-cover-28a76bfa16fb.jpeg" alt="带锁图标的 Replit 应用 SSO 构建横幅，展示一位开发者正在笔记本电脑上工作。" width="1920" height="1080" data-path="images/workspace/auth/sso-cover.jpeg" />
</Frame>

Clerk Dashboard 的功能远不止默认的登录体验。你在 Clerk 中进行的任何配置都会自动应用于 Replit 应用的身份验证。

<div id="what-you-can-configure">
  ## 你可以配置哪些内容
</div>

* **企业版 SSO 连接**：使用 OIDC 或 SAML 配置 Okta 或 Microsoft Entra ID 单点登录，让客户使用公司身份提供方登录。SSO 还能保护处理敏感数据的内部工具，用公司现有的身份提供方取代手动维护的邮箱白名单。
* **多因素认证 (MFA)&#x20;**：为应用的登录流程添加 MFA。
* **会话控制**：调整会话时长和验证频率。
* **其他 Clerk 设置**：其余 Clerk 配置会自动应用到你的 Replit App。请勿更改 API 密钥或环境设置——这些由 Replit 统一管理。参见[开发环境与生产环境](/zh/features/auth-and-identity/clerk-auth#development-and-production-environments)。

<div id="open-the-clerk-dashboard">
  ## 打开 Clerk 控制台
</div>

向 Agent 说明你需要的身份验证改动。Agent 会先完成力所能及的设置，再引导你前往应用的 Clerk 控制台，完成需要你手动填写的配置。

<Frame>
  <img src="/assets/mirror/build-with-sso-agent-workflow-46422788bd18.webp" alt="Agent 引导一个由 Clerk 驱动的应用在 Clerk 控制台中配置企业级 SSO。" width="1602" height="1080" data-path="images/workspace/auth/build-with-sso-agent-workflow.webp" />
</Frame>

你也可以直接从 Workspace 打开该控制面板：

1. 在工具面板中，选择 **Users &amp; Auth**。
2. 选择 **Configure** 标签页。
3. 选择 **Advanced**。
4. 在 **Clerk dashboard** 下，选择 **Open Clerk dashboard**。

<Frame>
  <img src="/assets/mirror/open-clerk-dashboard-tools-pane-a314ffea741d.webp" alt="Users & Auth 工具已打开 Configure 标签页，显示 Advanced 部分和 Open Clerk dashboard 按钮。" width="2158" height="1372" data-path="images/workspace/auth/open-clerk-dashboard-tools-pane.webp" />
</Frame>

<div id="set-up-an-enterprise-sso-connection">
  ## 设置 企业版 SSO 连接
</div>

1. 在 Clerk 控制台 中，选择 **Configure**。
2. 在 **User &amp; authentication** 下，选择 **SSO connections**。
3. 选择 **Enterprise**。
4. 选择 **Add connection**。

<Frame>
  <img src="/assets/mirror/build-with-sso-enterprise-connections-b0a6a27885b5.webp" alt="Clerk 控制台 显示 Enterprise SSO 连接页面和 Add connection 操作。" width="1826" height="1080" data-path="images/workspace/auth/build-with-sso-enterprise-connections.webp" />
</Frame>

有关完整的连接配置说明，请参阅 [Clerk 文档](https://clerk.com/docs)。

<div id="validate-the-connection">
  ### 验证连接
</div>

完成配置后，使用身份提供方中的测试账户登录，确认该账户能够访问应用中的预期内容。

如果登录失败，可以向 Agent 求助，并在请求中说明身份提供方、协议和错误信息。

<Note>
  本页介绍的是应用自身登录流程中的企业级 SSO。如需使用 Google、GitHub、Apple 或 X 进行社交登录 (在 Workspace 中显示为 **SSO 提供方**) ，请参阅[登录提供方](/zh/features/auth-and-identity/sign-in-providers)。本页不涉及 Replit Auth 迁移，也不涉及 Replit 账户的 SAML 登录。
</Note>

<div id="pricing-and-availability">
  ## 价格与可用性
</div>

[Replit Pro](/zh/billing/plans/replit-pro) 方案支持访问 Clerk 控制台，Enterprise 方案即将推出。

<Info>
  在 2026 年 10 月 1 日之前，企业版 SSO 连接免费。该日期之后，SSO 价格与 Clerk 的定价保持一致，并直接计入你的 Replit 账单。
</Info>
