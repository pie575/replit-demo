Agent 支持四种类型的集成，助你快速将想法变成 App：

* **Replit 托管**：自动可用的内置集成。创建 App 后，Agent 即可立即使用这些集成。
* **连接器**：Replit 支持的第一方集成。只需登录一次，Agent 就能直接通过 Chat 读取和写入这些服务的数据——提取数据、创建记录、发送消息——并在各个 App 中使用它们进行构建。
* **外部集成**：可用于构建 App 的可信第三方服务。让 Agent 帮你完成设置；你需要提供 API 密钥。
* **Agent 服务**：Agent 在后台使用的付费第三方 API，无需 API 密钥。使用费用将从你的 Replit 积分中扣除。

<Note>
  **套餐可用性**：大多数连接器需要订阅 Core、Pro 或 Enterprise，部分连接器可在 Free 套餐中使用。workspace 中的连接器目录会显示你当前套餐可使用的连接器。Free 套餐的构建者始终可以使用 Replit 托管的集成，例如数据库、身份验证等。
</Note>

<div id="let-agent-suggest-a-connector">
  ### 让 Agent 推荐连接器
</div>

有时，多个服务都能完成同一项任务，例如存储文件或发送电子邮件。当你需要某项功能但未指定身份提供方时，Agent 会显示一份符合条件的连接器简短列表。选择你需要的连接器。

选择一个身份提供方，然后登录一次以连接你的账户。Agent 会在构建时使用你的选择。你也可以直接指定服务名称，以跳过该列表。

<div id="connectors">
  ## 连接器
</div>

</Note>

<div id="configuring-oauth-app-with-replit">
  ### 在 Replit 中配置 OAuth App
</div>

<Note>
  **仅限 Enterprise**：配置自定义 OAuth app 需要 Enterprise 订阅。
</Note>

在 Enterprise 方案中，你可以为连接器使用自己的 OAuth app，而非 Replit 提供的默认 app。这样，你的组织可以拥有 OAuth 客户端、在授权同意页面展示自己的品牌，并精确控制构建者可请求的 scopes。

要使用自己的 OAuth app 配置连接器，你需要从身份提供方获取三项信息：**Client ID**、**Client Secret** 和要授权的 **scopes**。你还需要在身份提供方处注册 Replit 的回调 URL，以便完成身份验证。

<Frame>
  <img src="/assets/mirror/connector-oauth-configuration-100911ce0c48.png" alt="连接器 OAuth 配置对话框，包含 Client ID、Client Secret 和 Connector Scopes 字段，以及设置为 https://replit.com/connectors/oauth/callback 的 Redirect URL" width="1112" height="1218" data-path="images/replitai/connector-oauth-configuration.png" />
</Frame>

<Steps>
  <Step title="在身份提供方处创建 OAuth app">
    登录身份提供方的开发者控制台或管理员设置，创建一个新的 OAuth 2.0 应用。不同身份提供方对此步骤的命名可能不同——请查找类似 **Create OAuth app**、**Register application** 或 **Create client credentials** 的选项。
  </Step>

  <Step title="设置重定向 URL">
    当身份提供方要求填写 **Authorized redirect URI** (有时称为 **Callback URL** 或 **Redirect URL**) 时，输入：

    ```
    https://replit.com/connectors/oauth/callback
    ```

    构建者授权 app 后，身份提供方会通过此 URL 将他们带回 Replit。该 URL 必须完全匹配——末尾斜杠、协议和子域名都不能有差异。如果你添加了多个重定向 URI，必须包含此 URI。
  </Step>

  <Step title="复制 Client ID 和 Client Secret">
    创建 app 后，身份提供方会显示 **Client ID** 和 **Client Secret**。

    * **Client ID**：OAuth app 的公开标识符，可以安全地暴露在 URL 和客户端代码中。
    * **Client Secret**：用于证明请求来自你的 app 的机密值。请像对待密码一样保管——切勿将其提交到代码仓库或公开分享。Replit 会代你安全地存储它。

    某些身份提供方只会在创建时显示一次 client secret。请立即复制，并妥善保存，直至将其粘贴到 Replit。
  </Step>

  <Step title="选择 scopes">
    **Scopes** 是用于定义 OAuth app 可代表构建者读取或写入哪些内容的权限。每个身份提供方都会在其 API 文档中发布自己的 scopes 列表。

    在 Replit 中配置连接器时，输入的 scopes 必须与在身份提供方处注册的 scopes **完全匹配** (逐字符匹配，包括所有 URL 前缀) 。导致不匹配错误的常见原因包括：

    * 缺少完整的 URL 前缀 (例如，`https://www.googleapis.com/auth/drive.file` 与 `drive.file`) 。
    * 包含多余的空白字符或末尾逗号。
    * 在 Replit 中请求了身份提供方 app 未启用的 scope。

    请先仅使用构建者所需的最小 scopes，必要时再添加更多——大多数身份提供方允许你在无需重新创建 app 的情况下更新 scopes。
  </Step>

  <Step title="在 Replit 中配置连接器">
    在组织的 **连接器** 页面中，选择 **Add new integration**，选择服务，然后粘贴身份提供方提供的 **Client ID**、**Client Secret** 和 **Scopes**。选择 **Configure** 保存。
  </Step>
</Steps>

<Note>
  如果配置后身份验证失败，请再次确认身份提供方中的重定向 URL 与 `https://replit.com/connectors/oauth/callback` 完全一致，并确认你在 Replit 中输入的每个 scope 均已在身份提供方的 app 中获得授权。
</Note>

<div id="reconnecting-integrations">
  ## 重新连接集成
</div>

如果已连接的服务无法正常使用——例如登录会话过期或权限发生变化——Replit 会在 Project Editor 中显示重新连接提示。选择该提示即可直接重新连接集成，无需离开编辑器。

<div id="debugging-connectors">
  ## 调试连接器
</div>

连接服务时遇到问题？以下指南可帮助你排查常见错误并解决问题。

<AccordionGroup>
  <Accordion title="Google Workspace：&#x22;此应用被屏蔽&#x22;">
    连接 Google Drive、Docs、Sheets、Calendar 或 Gmail 时，如果看到 **&quot;此应用被屏蔽&quot;**，你的组织的 Google Workspace 可能限制了第三方 OAuth 应用。请参阅完整的故障排除指南来解决此问题。

    [解决 Google 连接器的“此应用被屏蔽”问题](/zh/features/troubleshooting/debugging-google-connectors)
  </Accordion>

  <Accordion title="Salesforce：&#x22;连接已过期&#x22;">
    如果你的 Salesforce 连接器因 **&quot;连接已过期&quot;** 错误而无法正常工作，你的 Salesforce 组织可能将刷新 token 策略配置为在指定时间后使 token 过期。请参阅完整的故障排除指南，更新 Connected App 设置。

    [修复 Salesforce 连接过期错误](/zh/features/troubleshooting/debugging-salesforce-connectors)
  </Accordion>
</AccordionGroup>
