La publication vous permet de partager votre application Replit avec le monde entier grâce à un processus simplifié.

<Note>
  L'action de mettre votre application en ligne s'appelle « Publication ». Cette page décrit les différents types de déploiements disponibles.
</Note>

## Qu'est-ce que la publication ?

La publication est une fonctionnalité qui enregistre un **instantané** de votre application Replit dans le cloud,
où tout le monde peut interagir avec elle. Un instantané capture l'état actuel des fichiers de votre
application Replit.

Lorsque vous publiez votre application Replit, vous créez une **application publiée**. Une application publiée est une instance en cours d'exécution
de votre application sur l'infrastructure cloud de Replit. Cela rend l'application disponible de manière fiable sur Internet,
séparément de la version dans l'Éditeur de projet.

<Info>
  L'infrastructure de Replit est soutenue par Google Cloud Platform (GCP). Toutes
  les applications publiées sont hébergées aux États-Unis. Les clients Enterprise peuvent
  contacter l'équipe commerciale pour demander que leurs applications publiées soient hébergées dans l'Union
  européenne.

  Chaque client individuel, organisation et entreprise bénéficie d'un projet GCP dédié
  à locataire unique pour ses applications publiées. Cela signifie que les ressources de calcul,
  les secrets et le stockage des applications publiées sont entièrement isolés et ne sont jamais
  partagés avec les applications d'autres clients.
</Info>

La publication comprend des outils pour surveiller l'état de votre application publiée et consulter les analyses web.

## Premiers pas

Suivez les étapes ci-dessous pour publier votre application Replit :

1. Depuis votre Éditeur de projet, sélectionnez <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Icône de publication" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publier** en haut.
2. Dans l'onglet **Publication**, sélectionnez votre option de publication.
3. Si **Ajouter un moyen de paiement** s'affiche, suivez les instructions pour ajouter un moyen de paiement.

Replit sélectionne automatiquement la meilleure option de publication pour votre application en fonction du type de projet et de vos besoins.

Cependant, pour choisir un type de déploiement différent, tenez compte des informations suivantes.

## Fonctionnalités principales

La publication offre les fonctionnalités pratiques suivantes :

* **Plusieurs options de publication** : Sélectionnez ou modifiez un type de déploiement qui répond à vos besoins en quelques clics.
* **Domaines personnalisés** : Servez votre application depuis votre domaine web.
* **Analyses** : Suivez les données des visiteurs et d'autres métriques pour votre application publiée.
* **Outils de surveillance** : Consultez l'état et la configuration de votre application publiée.
* **Contrôles d'accès** : Contrôlez qui peut voir votre application en un seul clic. Disponible uniquement pour les membres **Teams**.
* **Paramètres du badge** : Les utilisateurs Core peuvent gérer le badge « Made with Replit » dans les paramètres de publication. Si vous avez publié une application avec le plan Starter incluant le badge, la mise à jour de votre application pour supprimer le badge peut prendre quelques minutes après votre montée en gamme.
* **Collecte de commentaires** : Activez les commentaires sur votre application publiée pour recueillir des informations auprès de vos utilisateurs.

## Comment ça fonctionne

Lorsque vous publiez votre application Replit, Replit crée un instantané des fichiers et des dépendances de votre application.
Cet instantané est ensuite envoyé à l'infrastructure cloud de Replit, où il s'exécute en tant qu'instance séparée de votre application.
Pour mettre à jour votre application publiée avec les dernières modifications, publiez à nouveau pour créer un nouvel instantané.

<Warning>
  Évitez d'enregistrer des données et de vous fier aux données écrites dans le système de fichiers d'une application publiée. Pour
  stocker des données, utilisez une option de stockage ou de base de données telle que les offres [Stockage et
  base de données](/fr/category/storage-and-databases) de Replit.
</Warning>

## Cas d'usage

Les exemples suivants montrent différents types d'applications publiées.

### Déploiement Autoscale : application d'évaluation de la vitesse de frappe

Laissez le cloud augmenter les ressources lorsque les utilisateurs passent des tests de frappe et les réduire lorsqu'elles ne sont pas utilisées.

### Déploiement statique : simulation du système solaire

Apprenez-en plus sur les planètes dans une application de visualisation du système solaire sur le web.
Cette visualisation s'affiche dans le navigateur et ne transfère aucune entrée utilisateur vers un serveur.

### Déploiement sur VM réservée : bot Discord

Exécutez un bot Discord qui vous aide à modérer et à intégrer les membres.
Il est toujours en ligne pour discuter avec les utilisateurs et répondre aux commandes avec une tarification et des performances prévisibles.

### Déploiement planifié : déclencheurs d'automatisation domestique

Planifiez des appels API pour démarrer et arrêter vos appareils de maison intelligente à des heures et jours spécifiques.
