<div id="o-que-um-workspace">
  ## 什么是 Workspace？
</div>

Workspace 是 Replit 上的协作空间，将你的项目、团队成员、设置和账单集中在一处。每个 Replit 账户都自带一个个人 Workspace，用于存放自己的项目；付费方案还支持创建团队 Workspace，用于协作共享项目。

<Frame caption="Workspace 首页将最近的项目、Workspace 导航和对话输入框整合在同一个界面中。">
  <img src="/assets/mirror/start-new-conversation-home-sanitized-neutral-874efff00786.jpg" alt="Demo Workspace 的 Replit 首页完整视图，包含 Workspace 导航、通用的最近项目、建议提示以及对话消息框" width="1451" height="1084" data-path="images/chat/start-new-conversation-home-sanitized-neutral.jpg" />
</Frame>

| 功能       | 个人 Workspace | 团队 Workspace           |
| -------- | ------------ | ---------------------- |
| **适用场景** | 个人工作或分享单个项目  | 团队、初创公司、课堂和客户项目        |
| **访问模式** | 你为单个项目邀请访客   | 成员可访问 Workspace 中的所有项目 |
| **账单**   | 你的账户         | Pro 方案下管理员账户的共享积分      |

<div id="workspace-pessoal">
  ## 个人 Workspace
</div>

个人 Workspace 用于存放你自己的项目，你是其中唯一的管理员。你可以在项目级别邀请他人以访客身份加入，让他们访问特定项目，但他们无法访问该 Workspace 中的所有内容。

<Frame caption="你账户的 Workspace 在选择器中显示为个人 Workspace。">
  <img src="/assets/mirror/personal-workspace-selector-a7542687e3ac.jpg" alt="标识为个人 Workspace 的 Workspace 选择器" width="222" height="62" data-path="images/workspace/personal-workspace-selector.jpg" />
</Frame>

<div id="workspaces-de-equipe">
  ## 团队 Workspace
</div>

团队 Workspace 让一个团队可以在多个项目上协作。所有成员都能访问该 Workspace 下的全部项目，无需逐个邀请。管理员可集中管理账单和设置。

有关配置方法、成员管理和可用性详情，请参阅 [团队 Workspace](/zh/pt/features/collaboration/team-workspaces)。
