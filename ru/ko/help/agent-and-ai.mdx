Здесь собраны ответы по работе с Agent. Полные справочные материалы см. в разделах [Обзор Agent](/ru/ko/features/agent/overview), [Режимы Agent](/ru/ko/features/agent/agent-modes) и [Оплата ИИ](/ru/ko/billing/ai-billing).

<AccordionGroup>
  <Accordion title="Agent зависает или постоянно отключается. Как это исправить?">
    1. Откройте палитру команд с помощью `Cmd+K` (Mac) или `Ctrl+K` (Windows).
    2. Найдите и выберите **Restart compute**, чтобы перезапустить среду разработки.
    3. Откройте новый чат Agent, снова опишите задачу и продолжите работу.

    Не отправляйте сообщения, пока Agent выглядит зависшим. Дополнительные сообщения могут привести к противоречивым инструкциям. Если Agent постоянно зависает при выполнении одной и той же задачи, разделите её на более мелкие и конкретные промпты.
  </Accordion>

  <Accordion title="Agent повторяет одни и те же шаги или зациклился. Как его остановить?">
    1. На панели Agent нажмите **Остановить**, чтобы немедленно прервать работу.
    2. Откройте палитру команд с помощью `Cmd+K` (Mac) или `Ctrl+K` (Windows), найдите и выберите **Перезапустить вычислительную среду**.
    3. Откройте новый чат Agent и сформулируйте задачу более конкретно.

    Чтобы избежать зацикливания:

    * Разбивайте большие задачи на небольшие запросы. Одна цель на сообщение.
    * Используйте [режим Plan](/ru/ko/features/agent/plan-mode), чтобы определить объём работы до того, как Agent начнёт сборку.
    * Установите лимит Usage в разделе [Управление расходами](/ru/ko/billing/managing-spend), чтобы избежать чрезмерных списаний из-за зацикливания.
  </Accordion>

  <Accordion title="Как сократить расходы на Agent? Какие настройки действительно помогают?">
    Наибольшую разницу дают следующие решения:

    * **[Режим Free](/ru/ko/features/agent/agent-modes)** — повседневные задачи Agent, которые не тарифицируются в пределах квоты для подписчиков Core и Pro.
    * **[Режим Power](/ru/ko/features/agent/agent-modes)** — больше производительности по разумной цене, когда задача требует дополнительной мощности.
    * **[Режим Plan](/ru/ko/features/agent/plan-mode)** — определите объём работ и утвердите его до того, как Agent начнёт сборку, чтобы не платить за нежелательные изменения.
    * **Лимиты использования и бюджеты** — задайте жёсткие ограничения в разделе [Управление расходами](/ru/ko/billing/managing-spend).

    При переходе к другой задаче также полезно начинать новый чат с Agent. Заглядывайте в панель Usage, чтобы понять, какие операции обходятся дороже всего.
  </Accordion>

  <Accordion title="Что такое режим Agent и чем различаются его режимы?">
    У Agent есть три основных режима. Подробное руководство см. в разделе [Режим Free](/ru/ko/help/free-agent-mode).

    * **Режим Free** — бесплатная повседневная работа с Agent для подписчиков Core и Pro в рамках квоты, которая сбрасывается каждые 5 часов и ограничена недельным лимитом. Для уровня Starter действуют прежние лимиты. Чтобы посмотреть расход, откройте **Настройки → Usage**.
    * **Power** — платный средний режим с мощными моделями по разумной цене.
    * **Max** — платный высший режим с лучшими передовыми моделями для самых сложных задач.
    * **Turbo** — дополнительный переключатель в расширенных настройках, доступный только в Max.

    Платные режимы переименованы. **Economy теперь называется Power**, а режим, ранее носивший название **Power, теперь называется Max**. Ваши прежние настройки режимов сохраняются под новыми названиями. Если для запроса требуется больше мощности, чем доступно в режиме Free, Agent может предложить платный вариант **разрешить один раз**. Replit запросит подтверждение до начала платной работы, после чего Agent вернётся в режим Free.

    Отдельно стоит упомянуть [режим Plan](/ru/ko/features/agent/plan-mode): он позволяет Agent определить объём работы до внесения изменений, тогда как режим Build применяет изменения напрямую. См. [Режим Plan и режим Build](/ru/ko/learn/plan-vs-build-mode).
  </Accordion>

  <Accordion title="Agent внёс нежелательные изменения. Как их отменить?">
    Replit сохраняет [чекпоинты](/ru/ko/features/version-control/checkpoints-and-rollbacks), пока Agent работает над задачей. В Agent-чате найдите сообщение, предшествующее изменению, которое вы хотите отменить, и выберите рядом с ним опцию отката, чтобы вернуть проект к этому состоянию.

    Полный набор возможностей отката, включая восстановление отдельных файлов, описан в разделе [Чекпоинты и откаты](/ru/ko/features/version-control/checkpoints-and-rollbacks).
  </Accordion>

  <Accordion title="Agent сообщает, что не может получить доступ к интернету или внешнему API. Это нормально?">
    На этапах сборки и редактирования Agent работает в изолированной среде с ограниченным исходящим доступом. Опубликованные приложения при запуске могут выполнять внешние вызовы API. Изоляция применяется к среде редактирования Agent, а не к запущенному приложению.

    Если вызовы API в запущенном приложении завершаются с ошибкой, убедитесь, что ключи сохранены в панели [Secrets](/ru/ko/core-concepts/project-editor/app-setup/secrets), и проверьте страницу состояния поставщика услуг. В корпоративных или учебных сетях исходящие подключения приложения могут блокироваться — обратитесь к администратору сети.
  </Accordion>

  <Accordion title="Можно ли использовать собственный API-ключ в Agent?">
    Да. Добавьте ключ на панели [Secrets](/ru/ko/core-concepts/project-editor/app-setup/secrets), и приложение будет использовать его для API-вызовов. Откройте инструмент **Secrets**, выберите **+ Новый секрет**, затем укажите имя (например, `OPENAI_API_KEY`) и значение.

    Для модели, вызываемой приложением, можно [использовать собственный ключ поставщика ИИ](/ru/ko/features/integrations/replit-ai-integrations). Модель, обеспечивающая работу Agent, запускается в инфраструктуре Replit и не может быть заменена.
  </Accordion>

  <Accordion title="Agent продолжает добавлять функции, о которых я не просил. Как сделать его работу точнее?">
    Сосредоточьтесь на Agent с помощью более конкретных промптов:

    * Начинайте с *Only*. Например: &quot;Only add a delete button to the user card. Don&#39;t change anything else.&quot;
    * Сначала используйте [режим Plan](/ru/ko/features/agent/plan-mode), чтобы проверить, что будет делать Agent, и только потом вносите изменения.
    * Если Agent внес нежелательные изменения, сразу попросите его отменить их в том же чате.

    Подробнее см. в разделе [«Эффективное составление промптов»](/ru/ko/learn/effective-prompting).
  </Accordion>
