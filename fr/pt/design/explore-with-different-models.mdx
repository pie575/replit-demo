Les suggestions explorent différentes directions avec le même designer ; changer de modèle, c&#39;est changer de designer. Chaque modèle a sa propre sensibilité graphique et ses points forts en frontend : un même brief peut donc mener à un résultat inédit selon le modèle qui l&#39;anime.

<div id="troque-o-modelo">
  ## Changez de modèle
</div>

Ouvrez le sélecteur de mode dans le champ de composition du Chat (il affiche le mode actuel, comme **Power**), puis sélectionnez **Primary model** et choisissez un modèle dans la liste.

Liste actuelle :

* **Claude Fable 5** (recommandé)
* **Claude Opus 5**
* **GPT-5.6 Sol**
* **Kimi K3**

<Note>
  La liste des modèles évolue à mesure que de nouveaux modèles sont publiés. Consultez le menu dans le produit pour voir les modèles actuellement disponibles pour votre compte.
</Note>

Deux autres contrôles se trouvent dans le même menu contextuel :

* **Mode** (Lite, Economy, Power) : le compromis entre vitesse, coût et capacité. Power utilise un modèle plus performant pour le travail de design, idéal pour les designs complexes et les modifications visuelles détaillées. Consultez les [modes de l’Agent](/fr/pt/features/agent/agent-modes) pour obtenir la référence complète.
* **Effort** : le niveau de raisonnement que le modèle consacre à chaque réponse, de Low (plus rapide) à Max. Chaque modèle affiche le réglage recommandé.

<div id="explore-entre-modelos">
  ## Explorer avec plusieurs modèles
</div>

Changer de modèle constitue un axe d&#39;exploration supplémentaire, aux côtés des [suggestions](/fr/pt/design/explore-suggestions) :

* **Même brief, autre designer** : générez un frame, changez de modèle et renvoyez le même prompt. Les deux directions arrivent sous forme de frames sur le Canvas, ce qui vous permet de les comparer côte à côte.
* **Adaptez le modèle à la tâche** : utilisez le modèle recommandé pour l&#39;essentiel du travail et changez-en lorsqu&#39;un design demande une autre sensibilité, ou lorsque vous souhaitez un second avis sur une direction dont vous n&#39;êtes pas certain.
* **Changez à tout moment** : le modèle s&#39;applique à votre prochain message, vous pouvez donc en changer en cours de projet sans rien perdre sur le Canvas.
