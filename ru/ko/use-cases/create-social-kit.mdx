На основе брендовых материалов с сайта и Google Drive создайте иконки профиля и баннеры
обложек для указанных сетей: X, LinkedIn, Instagram, Facebook, TikTok и других. Agent использует
актуальные размеры и безопасные зоны каждой платформы, чтобы лица, логотипы и текст не обрезались
в профилях. Придерживайтесь единой визуальной системы и экспортируйте в PNG. Если для каждой сети требуется другое
кадрирование, не растягивайте изображение — создавайте отдельные монтажные области.

<div id="section-4">
  ## Ожидаемый результат
</div>

Agent проанализирует сайт и ресурсы Drive, а затем создаст по одной монтажной области для каждого ресурса
с точными размерами в пикселях. Типичный набор:

* **X:** профиль 400×400, шапка 1500×500
* **LinkedIn:** профиль 400×400, баннер 1584×396
* **Instagram:** профиль 320×320 (при необходимости добавьте 1080×1080 и 1080×1920 для публикаций и обложек историй)
* **Facebook:** профиль 320×320, обложка 820×312 (или в двойном размере — 1640×624)
* **TikTok:** профиль 200×200, обложка 1080×1920

Перед загрузкой проверьте кадрирование для круглых аватаров и широких баннеров. Экспортируйте один значок и один баннер, поместите их в круглый аватар и широкую шапку
и проверьте отступы при небольшом размере.

<div id="section-6">
  ## Устранение неполадок
</div>

* **Обрезается логотип или лицо:** проверьте каждый ресурс в круглом профиле и широком баннере. Соблюдайте безопасную зону и, если нужны другие варианты кадрирования, попросите Agent создать отдельные монтажные области. Не растягивайте изображения.
* **Размеры не соответствуют требованиям сети:** укажите нужные сети и попросите Agent использовать актуальные официальные размеры для каждой из них. Сети часто меняют эти требования, поэтому ещё раз проверьте их перед загрузкой.
