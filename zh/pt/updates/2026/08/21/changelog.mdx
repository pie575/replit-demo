<div id="use-o-modo-free">
  ### 使用 Free 模式
</div>

使用 Free 模式进行对话、探索创意、创作和构建，无需消耗 Power 模式或 Max 模式的积分。Free 模式通过 Auto 自动选择模型，其限额取决于你所使用的套餐。前往**设置** &gt; **用量**即可查看剩余额度和重置时间。

</Frame>

了解如何[充分利用 Free 模式](/zh/pt/chat/free-mode)。

<div id="comece-com-conversas">
  ### 从 Conversation 开始
</div>

先创建一个私有 Conversation，用来提问、探索信息、附加上下文、运行 Routine 或描述你想要的结果。当工作内容逐渐充实后，可以让 Replit 把这个 Conversation 转换成项目，你的上下文和文件都会一并延续。

<div id="automatize-trabalho-recorrente-com-rotinas">
  ### 使用 Routine 自动化重复性工作
</div>

你可以安排 Replit 在某个 Conversation 中定期重复执行某项工作。每次的运行结果都会返回到同一个 Conversation，方便你查看并继续跟进。Routine 在 Power 模式或 Max 模式下运行，每次执行都需要消耗相应预算。

</Frame>

进一步了解 [Routine](/zh/pt/chat/routines)。

<div id="direcione-o-agent-enquanto-ele-trabalha">
  ### 在 Agent 工作时进行引导
</div>

在 Agent 工作时发送后续消息，可为当前回合补充新的上下文。「引导」是「Conversation」和「项目」的默认行为，你可以在**设置** &gt; **个性化**中将任一偏好改为「排队」。在 Mac 上按 `Cmd+Enter`，在 Windows 和 Linux 上按 `Ctrl+Enter`，即可让某条消息使用相反的行为。

<Frame caption="可分别为「Conversation」和「项目」选择「引导」或「排队」。">
  <img src="/assets/mirror/agent-follow-ups-settings-98a4c5ca399e.png" alt="Agent 设置界面，显示Conversation和项目的发送行为以及「引导」和「排队」选项" width="3048" height="1372" data-path="images/replitai/agent-follow-ups-settings.png" />
</Frame>

进一步了解[如何引导和排队消息](/zh/pt/features/agent/steer-and-queue-messages)。

<div id="importe-skills-do-github">
  ### 从 GitHub 导入 skill
</div>

从 GitHub 的公开仓库、文件夹或文件 URL 导入 skill，并在添加前预览 skill 文件。已保存的 Project skill 同样支持 **Required**、**Available** 和 **No access** 三种成员访问级别。

</Frame>

进一步了解[如何共享和导入 Agent skill](/zh/pt/features/agent/skills#share-project-skills)。

<div id="controle-os-modelos-do-agent-entre-workspaces">
  ### 跨 Workspace 控制 Agent 模型
</div>

Enterprise 账户管理员可以为每个模型提供方设置账户级策略，再选择哪些模型可在各个 Workspace 中使用。可使用 **Enable all**、**Enable selected** 或 **Disabled**，以符合贵组织的策略要求。

  ### 执行黑盒渗透测试
</div>

运行 Level 3 安全扫描，该扫描包含三项检查：免费的依赖项和包检查、Agent 对源代码的静态分析，以及针对运行中的 Preview 的外部黑盒测试。Replit 会并行执行源代码审查和外部测试。
