<div id="section">
  ## Что такое ремикс
</div>

**Ремикс** — это новый Replit App, созданный на основе приложения, к которому у вас есть доступ. Создав ремикс общедоступного приложения или шаблона, вы получаете собственную копию, с которой можете работать и постоянно её улучшать. Изменения в ремиксе не влияют на исходное приложение.

В ремиксах указывается источник. Отображается ссылка **Remixed from**, ведущая к исходному приложению, а на странице обложки показывается промпт для создания исходного приложения.

<div id="section-2">
  ## Что входит в ремикс
</div>

Ремикс — это полноценная рабочая копия, полностью отделённая от оригинала:

* **Все файлы и настройки** копируются без изменений, поэтому App работает точно так же, как оригинал.
* **История чекпоинтов оригинала** также переносится и отображается как история исходного App. Вы можете откатиться к этим чекпоинтам, но связанные с ними беседы остаются в оригинале.
* **Полностью новый Agent.** Ремикс начинается с нового Agent без истории предыдущих чатов.
* **Имена секретов, а не их значения.** Если App использует секреты (например, ключи API), в ремиксе перечисляются только их имена, чтобы было понятно, какие значения нужно указать; сами значения остаются пустыми. Значения копируются только при создании ремикса собственного App.
* **Новая база данных.** Ремикс не подключается к базе данных оригинала. Если оригинал поддерживает эту возможность, вы можете скопировать сами данные с помощью опции **Copy data from original App**, но и в этом случае изменения не повлияют на оригинал.
* Для App, использующих Replit Auth, — **новые настройки входа**.

Не копируются: деплои, домены и настройки коннекторов — их необходимо настроить в каждой копии самостоятельно. Кроме того, ремикс изначально является приватным, поэтому до публикации он не будет доступен другим.

<div id="section-5">
  ## Разработка на основе ремикса
</div>

Когда ремикс откроется в рабочем пространстве, используйте Agent, чтобы дорабатывать и расширять его. На вкладке **Agent** введите промпт с описанием функций, которые хотите добавить.

Чтобы отменить изменения, внесённые Agent, в Checkpoint, созданном после этих изменений, выберите **Rollback to here**. Подробнее см. в разделе [Checkpoints и Rollbacks](/ru/ko/features/version-control/checkpoints-and-rollbacks).

<div id="section-6">
  ## Ремикс или создание приложения по промпту?
</div>

Оба пути в итоге приводят к одному: к вашему приложению, которое вы развиваете с помощью Agent. Разница лишь в том, с чего начать:

|                       | Ремикс                            | Создание по промпту                                      |
| --------------------- | --------------------------------- | -------------------------------------------------------- |
| Отправная точка       | Рабочая копия приложения          | Приложение, которое Agent создаёт на основе описания     |
| Первый результат      | Готов сразу и идентичен оригиналу | Потребуется больше времени, и результат будет отличаться |
| Первое действие Agent | Ждёт ваших указаний               | Планирует и создаёт приложение на основе промпта         |

Если уже есть приложение, похожее на то, что вам нужно, создайте ремикс. Тогда Agent начнёт работу не с пустого места, а с уже работающего приложения. Если вашей идеи ещё нигде нет, создайте приложение по промпту.
