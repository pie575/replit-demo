<div id="databricks">
  ### Интеграция с Databricks Apps
</div>

Разработчики Enterprise теперь могут создавать приложения для работы с данными в Replit и развертывать их напрямую в Databricks. Agent подключается к среде Databricks и может просматривать схемы данных без их передачи за пределы Databricks. Когда приложение будет готово, его можно напрямую опубликовать в Databricks Apps. Работающее приложение полностью размещается в Databricks и использует аутентификацию Databricks, средства управления Unity Catalog и существующие сетевые ограничения.

  <img src="/assets/mirror/databricks-app-template-333354ec6944.png" alt="Workspace Replit с выбранным шаблоном приложения Databricks в выпадающем списке шаблонов" width="1368" height="395" data-path="images/changelog/2026-04-10/databricks-app-template.png" />
</Frame>

Эта интеграция доступна организациям Enterprise, у которых есть рабочее пространство Databricks. Подробнее — на [странице партнёрства Replit и Databricks](https://replit.com/partners/databricks).

<div id="agent">
  ## Agent
</div>

<div id="ui">
  ### Воссоздание UI по скриншоту
</div>

Вставьте скриншот в Agent и попросите: «Создай это» или «Воссоздай этот UI». Agent с высокой точностью воспроизводит дизайн за один проход — как для веб-приложений, так и для презентаций. Это удобно для копирования существующих дизайнов, воссоздания референсного UI или быстрого прототипирования по макетам.

<div id="connectors">
  ### Connectors доступны на всех платных тарифах
</div>

Разработчики тарифов Core и Pro теперь могут получать доступ ко всем Connectors прямо из рабочего пространства.

Подробнее см. в разделе [Управление Connectors](/ru/ja/replitai/managing-connectors).

<div id="razorpay">
  ### Платежи через Razorpay в Индии
</div>

Разработчики в Индии теперь могут принимать платежи через UPI и банковские карты с помощью Razorpay. Поддержка включает e-мандаты для регулярных подписок в соответствии с требованиями Резервного банка Индии. Существующие подписчики в Индии вскоре смогут перейти со Stripe на Razorpay на странице оплаты.

<div id="revenuecatapp-store-connect">
  ### Синхронизация RevenueCat с App Store Connect
</div>

В интеграции RevenueCat появилась автоматическая синхронизация с Apple. Когда вы настраиваете встроенные покупки в RevenueCat, эти настройки напрямую синхронизируются с App Store Connect.

Подробнее читайте в разделе [Подписки RevenueCat](/ru/core-concepts/monetization/revenuecat-subscriptions).

<div id="section-4">
  ### Выберите регион публикации, в котором будет запускаться приложение
</div>

Пользователи Core, Pro и Enterprise теперь могут выбирать регион для Publish приложения. При выполнении Publish в определённом регионе все артефакты, включая вычислительные ресурсы, Database и Object Storage, размещаются в этом регионе. Региональные прокси снижают задержку для посетителей приложения.

Помимо Северной Америки теперь доступна Европа, а Австралия, Южная Америка и Азия будут добавлены в ближайшее время. Администраторы Enterprise также могут ограничить организацию одним регионом для соблюдения требований.

<div id="section-5">
  ### Просмотр прошлых счетов на странице использования
</div>

Теперь вы можете просматривать прошлые счета прямо на странице **Использование** в настройках аккаунта. Выберите прошлый расчётный период в раскрывающемся списке, чтобы увидеть подробную разбивку потребления по приложениям.
