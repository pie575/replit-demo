Free Mode vous permet de discuter, de créer et de développer sans utiliser de crédits Power Mode ou Max Mode.

<Note>
  Free Mode utilise toujours le routage intelligent des modèles. Replit sélectionne donc le modèle
  adapté à votre demande. Vous ne pouvez pas sélectionner un modèle spécifique dans Free Mode.
</Note>

Les Routines ne s’exécutent pas dans Free Mode. Elles s’exécutent dans Power ou Max Mode et nécessitent un budget par exécution. En savoir plus sur les [Routines](/fr/chat/routines).

<div id="get-more-from-your-allowance">
  ## Tirez le meilleur parti de votre allocation
</div>

Free Mode est idéal pour maintenir votre élan dans votre travail. Utilisez-le pour :

* Explorer et valider une idée avant de vous lancer dans un projet plus ambitieux.
* Démarrer un nouveau projet, faire une première ébauche d&#39;une fonctionnalité ou apporter une modification mineure.
* Poser des questions, établir un plan et affiner votre travail à l&#39;aide de messages de suivi.
* Poursuivre votre travail quotidien sans utiliser de crédits tant que votre allocation est disponible.

Pour commencer, ouvrez le sélecteur de mode sous le champ de prompt et assurez-vous que le mode est défini sur **Free**. Envoyez ensuite à Replit une demande précise : indiquez le résultat souhaité, partagez le contexte pertinent et utilisez des questions de suivi pour affiner le résultat.

<div id="know-when-to-use-another-mode">
  ## Sachez quand utiliser un autre mode
</div>

Les limites de Free Mode dépendent de votre forfait. Ouvrez **Paramètres** → **Utilisation** pour consulter votre limite actuelle et savoir quand elle sera réinitialisée.

<Frame caption="Votre page Utilisation affiche l’allocation Free restante et la date de son actualisation.">
  <img src="/assets/mirror/free-mode-usage-sanitized-1b738ae092bb.jpg" alt="Page Utilisation des paramètres avec le panneau de l’allocation Free visible" width="1538" height="1022" data-path="images/chat/free-mode-usage-sanitized.jpg" />
</Frame>

Avec les forfaits Core et Pro, passez à **Power Mode** ou **Max Mode** lorsque vous avez besoin de plus de puissance, souhaitez choisir un modèle spécifique ou avez atteint votre allocation Free Mode. Ces modes utilisent des crédits mensuels. Les créateurs disposant du forfait Starter doivent passer à un forfait supérieur avant d&#39;utiliser Power Mode ou Max Mode.

<Tip>
  Si votre forfait inclut Power Mode et Max Mode, utilisez Free Mode pour la première
  étape et changez de mode uniquement lorsque la tâche exige plus de puissance. Replit vous
  informe avant qu&#39;une demande ne bascule vers un mode entraînant des frais d&#39;utilisation.
</Tip>

<div id="choose-the-mode-that-fits-the-work">
  ## Choisissez le mode adapté à votre travail
</div>

| Si vous souhaitez...                                                            | Commencez par... |
| ------------------------------------------------------------------------------- | ---------------- |
| Explorer, poser des questions, planifier ou commencer à créer                   | Free Mode        |
| Trouver un bon équilibre entre rapidité et capacités pour la plupart des tâches | Power Mode       |
| Aborder des tâches complexes ou ambitieuses                                     | Max Mode         |

Power Mode remplace Economy Mode au même prix, avec des performances identiques ou supérieures. Avec les forfaits Core et Pro, vous pouvez sélectionner un modèle disponible dans Power Mode ou Max Mode.
