ИИ-модели, такие как Claude и GPT, обладают большими возможностями, но ограничены данными, на которых они обучались. Model Context Protocol (MCP) предоставляет им стандартный способ подключаться к внешним инструментам, источникам данных и возможностям реального мира.

<div id="por-que-os-modelos-de-ia-precisam-do-mcp">
  ## Зачем ИИ-моделям нужен MCP
</div>

Без доступа к внешним инструментам и данным ИИ-модели не могут:

* получать актуальную информацию;
* взаимодействовать с внешними системами;
* выполнять действия в реальном мире;
* работать с вашими приватными данными.

MCP решает эту задачу, создавая универсальный способ подключения ИИ к инструментам и данным — подобно тому, как USB-C стандартизировал подключение устройств.

  <img src="/assets/mirror/mcp-a04e01a01743.avif" alt="Схема MCP: ИИ-модели подключаются к внешним инструментам и источникам данных" width="1920" height="1055" data-path="images/tutorials/mcp.avif" />
</Frame>

С MCP ИИ-модели могут:

* обращаться к специализированным инструментам и API;
* считывать данные из приватных источников;
* выполнять действия в реальном мире;
* беспрепятственно подключаться к другим системам.

<div id="como-o-mcp-funciona">
  ## Как работает MCP
</div>

Архитектура MCP состоит из трёх основных компонентов:

1. **Клиентская сторона** — ИИ-модели, такие как Claude, или приложения, которым нужен доступ к внешним инструментам.
2. **Уровень коммуникации** — сам протокол, стандартизирующий формат запросов и ответов.
3. **Серверная сторона** — программы, предоставляющие доступ к инструментам, источникам данных и специализированным возможностям.

<AccordionGroup>
  <Accordion title="Что такое клиент MCP?">
    Клиент MCP — это, например, Claude, Replit Agent или интерфейс командной строки, подключённый к большой языковой модели. Это «устройство», которое подключается к внешним инструментам или источникам данных.

    Примеры клиентов MCP:

    * Claude в браузере
    * Replit Agent
    * Интерфейсы командной строки для ИИ
    * Пользовательские приложения, созданные с помощью SDK для ИИ
  </Accordion>

  <Accordion title="Что такое MCP-сервер?">
    MCP-сервер предоставляет ИИ-моделям инструменты и возможности. Представьте, что вы даёте ИИ набор специализированных инструментов для решения задач.

    MCP-серверы позволяют:

    * Получать доступ к определённым источникам данных для ответов на вопросы
    * Подключать ИИ к API, чтобы он мог выполнять действия в интернете
    * Читать и записывать файлы
    * Выполнять вычисления или запускать код
    * Получать контент из таких сервисов, как Notion, Linear или Stripe
  </Accordion>
</AccordionGroup>

<div id="o-que-o-mcp-desbloqueia">
  ## Возможности MCP
</div>

MCP определяет несколько базовых примитивов, которые делают его мощным инструментом для ИИ-приложений:

* **Resources** — предоставление данных и контента ИИ-моделям
* **Tools** — возможность для ИИ-моделей выполнять действия через ваши сервисы
* **Prompts** — повторно используемые шаблоны для единообразного взаимодействия с ИИ
* **Sampling** — возможность для ваших сервисов запрашивать информацию у ИИ-моделей
* **Transports** — эффективное подключение клиентов и серверов

<div id="skills-vs-servidores-mcp">
  ## Навыки и MCP-серверы
</div>

Навыки и MCP-серверы — два основных способа расширять возможности ИИ-агентов, но они предназначены для разных задач.

|                              | Навыки                                                              | MCP-серверы                                                        |
| ---------------------------- | ------------------------------------------------------------------- | ------------------------------------------------------------------ |
| **Лучше всего подходят для** | Рабочих процессов, соглашений и справочных материалов               | Подключения к внешним сервисам и выполнения действий               |
| **Загружаются**              | Легковесно — до вызова загружаются только имя и описание            | Более ресурсоёмко — описания всех инструментов загружаются заранее |
| **Определяют**               | *Как* должен работать ваш агент                                     | *К чему* ваш агент может получать доступ                           |
| **Пример**                   | Навык «Stock Analyzer» — анализ инвестиций по определённой методике | MCP-сервер «Stripe» — доступ к данным о платежах и подписках       |

Подробнее о подходе к навыкам см. в разделе [Навыки Agent](/ru/pt/learn/agent-skills).

<div id="aplicaes-no-mundo-real">
  ## Применение в реальных задачах
</div>

MCP открывает широкий спектр возможностей для ИИ-приложений:

* **Системы поддержки клиентов**, которые обращаются к базам данных компании, чтобы отвечать на конкретные вопросы
* **Исследовательские ассистенты**, которые находят и обобщают материалы из нескольких источников
* **Инструменты продуктивности**, которые работают с вашими файлами и приложениями
* **Инструменты для создания контента**, которые обращаются к медиатекам и платформам публикации

<div id="benefcios">
  ## Преимущества
</div>

MCP даёт три основных преимущества:

* Готовые интеграции, к которым ИИ может подключиться сразу
* Возможность переключаться между провайдерами ИИ, не переписывая подключения
* Механизмы безопасности, которые защищают ваши конфиденциальные данные

<Note>
  MCP — развивающийся стандарт, поддержка которого растёт во всей экосистеме ИИ. Новые инструменты и интеграции добавляются регулярно.
</Note>
