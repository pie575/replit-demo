<div id="seo-agent">
  ## 使用 SEO Agent 优化
</div>

[SEO Agent](/zh/ko/features/publishing/seo-agent) 会对已部署的应用进行技术 SEO 审核，并将每个发现的问题转为一键修复。它位于 Project Editor 的 **Growth** 面板中，面向付费套餐用户提供。请按照以下步骤扫描应用并应用修复。

<Steps>
  <Step title="部署应用，解锁 Growth">
    SEO Agent 适用于已部署的应用。在部署前，**Growth** 面板会处于锁定状态，并提示您点击 **Go to Publishing**。通过 Agent 聊天或 **Publishing** 工具完成部署后，再返回 Growth 面板。

    <Frame caption="部署前，Growth 面板处于锁定状态，并显示 Go to Publishing 提示">
      <img src="/assets/mirror/01-growth-locked-b05c24711f10.png" alt="处于锁定状态的 Growth 面板，标题为“部署应用以解锁 Growth 工具”，并提供 Go to Publishing 按钮" width="1657" height="947" data-path="images/deployments/seo-agent/01-growth-locked.png" />
    </Frame>
  </Step>

  <Step title="使用 Agent 执行扫描">
    打开 **增长** 面板，找到 **SEO 评分** 卡。选择 **使用 Agent 运行扫描**，对项目启动技术 SEO 审核。扫描通常需要几分钟。

    <Frame caption="在 SEO 评分卡中选择“使用 Agent 运行扫描”以开始审核">
      <img src="/assets/mirror/02-run-scan-94a2b8918fe9.png" alt="SEO 评分卡的放大图，其中“使用 Agent 运行扫描”按钮以红色矩形突出显示" width="1656" height="946" data-path="images/deployments/seo-agent/02-run-scan.png" />

    * 在单个问题中选择 **Fix with Agent**，只会将该问题交给 Agent 处理。
    * 在类别中选择 **Fix with Agent**，会修复该类别中的所有问题。
    * 选择 **Fix all with Agent**，会一次性将所有问题交给 Agent 处理。聊天中的 **Fix all issues** 按钮也具有相同功能。

<Tip>
  您也可以完全跳过扫描界面。打开 Agent 并说 **&quot;optimize my
  SEO&quot;**，Agent 就会获取最新结果并开始处理。
</Tip>

Agent 通常会进行以下优化：

* 添加或重写缺失或过于通用的 `<title>` 标签，确保每个页面都有唯一且描述清晰的标题。
* 为所有页面添加元描述。
* 为图片添加描述性的 `alt` 文本。
* 为 `<html>` 元素设置 `lang` 属性。
* 确保链接包含可识别的文本 (避免使用“点击此处”或空锚点) 。
* 添加 `robots.txt` 和 `sitemap.xml`。
* 添加用于移动端渲染的 viewport 元标签。
* 改善未通过无障碍检查的文本颜色对比度。
* 添加 Open Graph 和 Twitter 卡片元标签，让应用链接能在社交平台上正确显示预览。

<div id="seo">
  ## SEO 优化应用的最佳实践
</div>

无论是让 Agent 处理还是自行编写，以下几项最为重要。

* **为每个页面设置唯一的标题和元描述。** 标题应控制在 60 个字符以内，描述建议为 150~160 个字符。
* **使用语义化 HTML。** 使用 `<main>`、`<header>`、`<nav>` 和 `<footer>` 组织页面布局。每页仅使用一次 `<h1>`，并按顺序使用标题级别。
* **为所有图片添加 alt 文本。** 应描述图片所呈现的内容，而非图片本身。
* **创建 `sitemap.xml` 和 `robots.txt`。** 请 Agent 同时创建这两个文件，让搜索引擎了解应抓取哪些内容。
* **添加 Open Graph 和 Twitter 卡片标签。** 控制应用在社交媒体上分享时的展示效果。
* **使用自定义域名。** 品牌域名能赢得访客和搜索引擎的信任。请参阅[添加自定义域名](/zh/ko/build/add-custom-domain)。
* **选择合适的部署类型。** 对于内容丰富的网站，[Static 部署](/zh/ko/features/publishing/deployment-types#static)可提供搜索引擎能够立即解析的预渲染 HTML。
* **添加结构化数据。** JSON-LD 标记可帮助搜索引擎显示产品、文章、FAQ 和活动的富媒体搜索结果。
* **保持应用运行快速。** 优化图片，避免使用阻塞渲染的脚本，并利用 Replit 托管服务缩短响应时间。

一次性完成大部分优化的简单方法：

<AiPrompt>
  审核我的网站是否符合 SEO 最佳实践，并应用修复措施。添加站点地图、robots.txt、Open Graph 标签，以及适当位置的结构化数据，并确保所有页面都有唯一的标题和元描述。
</AiPrompt>

<div id="section-2">
  ## 需要更多帮助？
</div>

* **重新部署后分数未更新：**请等待 1~2 分钟——审核会在部署完成后异步运行，结果返回后徽章会更新。
* **Agent 更改后分数仍然相同：**询问 Agent 处理了哪些具体的 Lighthouse 项目，并查看徽章工具提示中仍显示的问题。
* **某些页面的分数低于其他页面：**徽章会显示所有已爬取 URL 中的最低分数。请让 Agent 专注处理 Lighthouse 标出的具体页面。
* **已部署的应用中未显示分数：**SEO 分数仅适用于面向公开 Web 的部署类型 (Autoscale、Reserved VM、Static) 。定时部署和私有部署不会生成分数。
