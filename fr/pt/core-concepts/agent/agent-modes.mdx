Les modes Agent vous permettent de trouver le bon équilibre entre vitesse, coût et capacités lorsque vous utilisez Agent. Utilisez le sélecteur de mode principal dans le menu déroulant des paramètres d’Agent pour passer de **Lite** à **Economy** ou **Power**. Développez les **Paramètres avancés** pour mieux contrôler les tests, la révision du code et Turbo.

<Tip>
  **Raccourci clavier :** Appuyez sur **⌘+Shift+I** (Ctrl+Shift+I sous Windows) pour passer d’un mode Agent à l’autre sans quitter le champ de saisie du Chat.
</Tip>

<Note>Le mode Max n’est plus disponible. Utilisez Power pour les builds standard les plus performants et activez Turbo dans les Paramètres avancés lorsque vous avez besoin des exécutions les plus rapides.</Note>

<div id="modo-lite">
  ## Mode Lite
</div>

**Optimisé pour les modifications rapides.** Lite utilise des modèles rapides et légers pour les ajustements visuels, les corrections de bugs et d&#39;autres petites modifications bien ciblées.

<Frame>
  <img src="/assets/mirror/agent-modes-lite-05ad32f8f34e.png" alt="Menu déroulant des modes Agent avec Lite sélectionné" width="1192" height="1328" data-path="images/replitai/agent-modes-lite.png" />
</Frame>

**Idéal pour :** les corrections rapides, les améliorations de l’UI et les cycles d’itération courts sans quitter le clavier.

**À garder à l’esprit :** Lite fonctionne mieux sur les applications existantes lorsque vous savez déjà ce que vous voulez modifier. Si vous partez de zéro, effectuez des modifications architecturales majeures, ajoutez une nouvelle intégration ou modifiez un schéma de base de données, passez à Economy ou Power.

**Coût :** Lite utilise le même modèle de tarification basé sur l’effort que les autres modes de Build, mais les demandes ciblées coûtent généralement moins cher qu’Economy ou Power pour une même modification.

<div id="modo-economy">
  ## Mode Economy
</div>

**Optimisé pour réduire les coûts.** Economy utilise moins de crédits par tâche et constitue le meilleur choix par défaut lorsque vous souhaitez obtenir de bons résultats sans payer pour les modèles les plus performants.

<Frame>
  <img src="/assets/mirror/agent-modes-economy-6ae501cc69d6.png" alt="Menu déroulant des modes Agent avec Economy sélectionné et les paramètres avancés développés" width="1192" height="1328" data-path="images/replitai/agent-modes-economy.png" />
</Frame>

**Idéal pour :** les builds du quotidien, l’apprentissage et le travail sur un projet existant en maîtrisant les coûts.

<div id="modo-power">
  ## Mode Power
</div>

**Optimisé pour la puissance.** Power utilise des modèles plus performants pour les tâches complexes, les bases de code volumineuses et les problèmes plus difficiles.

<Frame>
  <img src="/assets/mirror/agent-modes-power-f956985e7037.png" alt="Menu déroulant des modes Agent avec Power sélectionné et les paramètres avancés développés" width="1192" height="1328" data-path="images/replitai/agent-modes-power.png" />
</Frame>

**Idéal pour :** les projets prêts pour la production, les fonctionnalités complexes et lorsque vous souhaitez obtenir les meilleurs résultats avec l’Agent.

<div id="configuraes-avanadas">
  ## Paramètres avancés
</div>

Développez les **Paramètres avancés** dans le menu déroulant pour gérer les autres options de Build de l’Agent :

* **Tests de l’App** permet à l’Agent de tester automatiquement votre application dans un navigateur.
* **Optimisations du code** permet à l’Agent de réviser et d’améliorer son propre code pendant son travail.
* **Turbo** propose les modèles les plus rapides disponibles lorsque vous utilisez le mode Power.

Lite désactive les Tests de l’App et les Optimisations du code, et Turbo n’est disponible que lorsque Power est sélectionné.

<div id="modo-turbo">
  ## Mode Turbo
</div>

**Turbo est une option distincte des paramètres avancés.** Activez-le en mode Power lorsque vous souhaitez obtenir des réponses **2,5 fois plus rapides** avec les modèles les plus rapides. Les requêtes peuvent coûter jusqu’à 6 fois plus cher qu’en mode Power. Turbo est donc particulièrement utile lorsque la vitesse prime sur l’efficacité.

<Frame>
  <img src="/assets/mirror/agent-modes-turbo-5bd95033d396.png" alt="Menu déroulant des modes Agent avec Power sélectionné et Turbo activé dans les paramètres avancés" width="760" height="502" data-path="images/replitai/agent-modes-turbo.png" />
</Frame>

<Warning>
  Turbo apparaît en orange dans le menu déroulant des modes Agent afin de vous rappeler visuellement qu’il coûte nettement plus cher que Power. Gardez cet indicateur à l’œil lorsque vous itérez rapidement : il est là pour rendre visible le compromis de coût.
</Warning>

**Disponibilité :** **Pro et Enterprise uniquement.**

**Idéal pour :** Lorsque vous avez besoin de la réponse la plus rapide possible d’Agent et que vous disposez d’un forfait Pro ou Enterprise.

<div id="qual-modo-devo-usar">
  ## Quel mode dois-je utiliser ?
</div>

Servez-vous des indications suivantes :

| Objectif                                               | Mode recommandé                |
| ------------------------------------------------------ | ------------------------------ |
| Petites modifications ciblées avec itérations rapides  | Lite                           |
| Maximiser le nombre de prompts par crédit              | Economy                        |
| Équilibrer coût et qualité pour la plupart des projets | Power                          |
| Réponse plus rapide pour les tâches plus importantes   | Power + Turbo (Pro/Enterprise) |

Vous pouvez changer de mode à tout moment dans le menu déroulant des paramètres d’Agent, dans le champ de saisie du Chat. Choisissez Lite, Economy ou Power dans le sélecteur principal, puis développez les Paramètres avancés pour mieux contrôler les tests, la révision du code ou Turbo. Aucun mode n’est toujours le meilleur : choisissez celui qui convient le mieux à la tâche à accomplir.
