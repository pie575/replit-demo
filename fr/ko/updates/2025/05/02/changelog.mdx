<div id="replit-auth">
  ### Replit Auth
</div>

[Replit Auth](/fr/ko/features/auth-and-identity/authentication) est désormais disponible pour tous les utilisateurs ! Il s&#39;agit d&#39;un système d&#39;authentification intégré qui permet d&#39;ajouter la connexion des utilisateurs à votre application avec une configuration minimale. Plutôt que de développer un système d&#39;authentification complexe de A à Z, Replit Auth vous offre une solution sécurisée et prête à l&#39;emploi, intégrée à l&#39;infrastructure Replit.

**Fonctionnalités clés :**

* **Aucune configuration requise** — ajoutez l&#39;authentification à l&#39;aide d&#39;un simple prompt dans Agent
* **Sécurité intégrée** — s&#39;appuie sur l&#39;infrastructure Replit, protégée contre les attaques courantes
* **Gestion des utilisateurs** — gestion simplifiée des utilisateurs via la fenêtre Auth
* **Intégration à la base de données** — création automatique des entrées utilisateur dans votre base de données
* **Page de connexion personnalisable** — adaptez l&#39;expérience de connexion à votre application
* **Réinitialisation de mot de passe** — Replit gère les e-mails de réinitialisation, sans que vous ayez besoin de votre propre fournisseur d&#39;envoi d&#39;e-mails

Se lancer est simple : il suffit d&#39;inclure une demande de Replit Auth dans votre prompt à Agent :

<AiPrompt>
  Aidez-moi à créer une application [idée d&#39;application] qui doit inclure Replit Auth.
</AiPrompt>
