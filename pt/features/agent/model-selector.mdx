O seletor de modelo permite que o Replit use o roteamento inteligente de modelos, ou permite que você mesmo selecione um modelo disponível.

## Roteamento inteligente de modelos

O roteamento inteligente de modelos escolhe um modelo adequado para cada tarefa, equilibrando qualidade e custo. Quando você vê **Auto** no produto, o Replit está realizando o roteamento inteligente de modelos.

O roteamento inteligente de modelos considera o trabalho que você solicita e sua complexidade. Uma solicitação focada pode usar um modelo de menor custo, enquanto um trabalho complexo pode exigir um modelo mais capaz. O Replit pode selecionar um modelo diferente conforme a tarefa muda.

<Note>
  O Free Mode sempre usa o roteamento inteligente de modelos. Usuários no Free
  Mode não podem usar o seletor de modelo nem escolher um modelo manualmente.
</Note>

## Escolher um modelo manualmente

Usuários nos planos Core e Pro podem escolher um modelo disponível no Power Mode ou no Max Mode.

1. Na caixa de prompt, selecione **Agent Mode**. O menu mostra os modos disponíveis: **Free**, **Power** e **Max**.
2. Selecione **Power** ou **Max** e localize a seção **Primary model**.
3. Abra o menu do modelo principal e escolha um modelo na lista.

## Effort

**Effort é um controle por modelo, não um modo separado.** Ele define quanto raciocínio o modelo selecionado dedica a cada resposta, de **Low** a **Max**. Cada modelo mostra sua configuração recomendada, e você pode aumentá-la apenas quando a tarefa exigir.

<Frame caption="O controle deslizante Effort abaixo da lista de modelos, definido como Medium.">
  <img src="/assets/mirror/model-selector-effort-bcffb01239a8.png" alt="A lista Primary model com Claude Fable 5 selecionado e o controle deslizante Effort definido como Medium, descrito como raciocínio equilibrado para tarefas do dia a dia" width="984" height="832" data-path="images/replitai/model-selector-effort.png" />
</Frame>

Use as descrições de nível como guia:

| Effort         | Use para                                                                                                                          |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| **Low**        | Respostas mais rápidas com raciocínio mínimo. Alterações rotineiras e bem definidas, quando a velocidade é o mais importante.     |
| **Medium**     | Raciocínio equilibrado para tarefas do dia a dia. Uma boa opção padrão quando a configuração recomendada não indicar outra coisa. |
| **High**       | Raciocínio mais profundo para trabalhos mais complexos, como recursos com várias etapas e território menos familiar.              |
| **Extra High** | Raciocínio estendido para os problemas mais difíceis, como grandes refatorações e bugs complicados.                               |
| **Max**        | Profundidade máxima de raciocínio. O custo mais alto e o mais lento, quando o melhor resultado possível é tudo o que importa.     |

Em níveis de Effort mais altos, o Agent realiza um raciocínio mais profundo e deliberado e aciona seus modelos de fronteira mais capazes, melhorando os resultados nas tarefas mais complexas. O Agent aplica esse poder extra de forma seletiva — ele direciona para os modelos mais capazes apenas quando uma solicitação é genuinamente difícil, não em toda execução.

<Tip>
  Como o Agent só recorre ao modelo mais capaz nos trabalhos mais difíceis, um Effort mais alto adiciona um custo de até \~2x nas tarefas mais árduas — e, muitas vezes, pouco ou nada nas mais simples. Aumente-o quando estiver lidando com problemas complexos e mantenha-o baixo para alterações rotineiras.
</Tip>

## Comparar modelos

**Compare models** executa seu próximo prompt em vários modelos ao mesmo tempo, para que você possa avaliar os resultados lado a lado em vez de adivinhar qual modelo é o mais adequado. É um recurso em beta.

Para ativá-lo, expanda **Advanced settings** na parte inferior do popover de modos do Agent e ative **Compare models**.

<Note>A comparação de modelos só é compatível com o Chat.</Note>

<Frame caption="A opção Compare models em Advanced settings.">
  <img src="/assets/mirror/compare-models-toggle-05429dc46d64.png" alt="Advanced settings expandido com a opção Compare models Beta desativada, descrita como a criação de até 4 variantes com seu próximo prompt" width="1110" height="344" data-path="images/replitai/compare-models-toggle.png" />
</Frame>

Com a opção ativada, adicione até **4 modelos** à comparação.

<Frame caption="Quatro modelos selecionados para comparação, com o botão de envio exibindo Compare 4.">
  <img src="/assets/mirror/compare-models-9f5bcecec727.png" alt="O popover de modos do Agent com Compare models ativado e quatro espaços de modelo — Kimi K3, Claude Fable 5, Claude Opus 5 e GPT-5.6 Sol — cada um removível, e o botão de envio do chat exibindo Compare 4" width="1192" height="1930" data-path="images/replitai/compare-models.png" />
</Frame>

Seu próximo prompt é então executado uma vez para cada modelo selecionado, e cada um produz sua própria variante para comparação.

<Note>
  Cada modelo em uma comparação executa um agente separado e consome créditos, portanto uma execução Compare 4 custa aproximadamente o mesmo que quatro execuções individuais.
</Note>

## Seleção de modelo no Build e no Design

O Build e o Design mantêm seleções de modelo separadas. Esta página aborda a seleção de um modelo para builds do Agent. Para explorar direções visuais com o seletor de modelo do Design, consulte [Explore com modelos diferentes](/pt/design/explore-with-different-models).
