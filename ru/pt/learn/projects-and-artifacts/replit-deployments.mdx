  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }

Публикация позволяет поделиться своим Replit App со всем миром всего за несколько шагов.

<Note>
  Размещение приложения в интернете называется «публикацией». На этой странице описаны различные доступные типы деплоя.
</Note>

<div id="o-que-publicao">
  ## Что такое публикация?
</div>

Публикация — это функция, которая сохраняет **снимок состояния** вашего Replit App в облаке,
где любой пользователь может с ним взаимодействовать. Снимок состояния фиксирует текущее состояние файлов вашего
Replit App.

Когда вы публикуете свой Replit App, вы создаёте **опубликованное приложение**. Опубликованное приложение — это работающий экземпляр
вашего приложения в облачной инфраструктуре Replit. Благодаря этому приложение надёжно доступно в интернете
и отделено от версии в Project Editor.

<Info>
  Инфраструктура Replit построена на Google Cloud Platform (GCP). Все
  опубликованные приложения размещаются в США. Клиенты Enterprise могут
  обратиться в отдел продаж с запросом на размещение своих опубликованных приложений в Европейском
  союзе.

  Каждый индивидуальный клиент, организация и компания получает выделенный однопользовательский проект GCP для своих
  опубликованных приложений. Это означает, что вычислительные ресурсы, Secrets
  и хранилище опубликованных приложений полностью изолированы и никогда не
  используются совместно с приложениями других клиентов.
</Info>

Публикация включает инструменты для отслеживания статуса опубликованного приложения и просмотра веб-аналитики.

<div id="primeiros-passos">
  ## Начало работы
</div>

Чтобы опубликовать Replit App, выполните следующие действия:

1. В верхней части Project Editor нажмите <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Значок публикации" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publish**.
2. На вкладке **Publishing** выберите вариант публикации.
3. Если появится **Add a payment method**, следуйте инструкциям, чтобы добавить способ оплаты.

Replit автоматически выбирает оптимальный вариант публикации для вашего приложения с учётом типа проекта и ваших потребностей.

Чтобы выбрать другой тип развёртывания, ознакомьтесь с информацией ниже.

<div id="principais-recursos">
  ## Основные возможности
</div>

Публикация предлагает следующие удобные возможности:

* **Несколько вариантов публикации**: Выберите или обновите тип развёртывания в соответствии с вашими потребностями всего за несколько кликов.
* **Пользовательские домены**: Размещайте своё приложение на собственном веб-домене.
* **Аналитика**: Отслеживайте данные о посетителях и другие метрики опубликованного приложения.
* **Инструменты мониторинга**: Просматривайте статус и конфигурацию опубликованного приложения.
* **Управление доступом**: Одним кликом определяйте, кто может просматривать ваше приложение. Доступно только участникам **Pro** и **Enterprise**.
* **Настройки бейджа**: Пользователи тарифа Core могут управлять бейджем «Made with Replit» в настройках публикации. Если вы опубликовали приложение на тарифе Starter, включающем этот бейдж, после перехода на другой тариф обновление приложения и удаление бейджа может занять несколько минут.
* **Сбор обратной связи**: Включите сбор обратной связи в опубликованном приложении, чтобы получать отзывы пользователей.

<div id="como-funciona">
  ## Как это работает
</div>

Когда вы публикуете свой Replit App, Replit создаёт снимок состояния файлов и зависимостей вашего приложения.
Затем этот снимок состояния отправляется в облачную инфраструктуру Replit, где запускается как отдельный экземпляр приложения.
Чтобы обновить опубликованное приложение с учётом последних изменений, опубликуйте его повторно — будет создан новый снимок состояния.

<Warning>
  Не сохраняйте данные в файловой системе опубликованного приложения и не полагайтесь на них. Для
  хранения данных используйте хранилище или базу данных, например [Storage and
  Database](/ru/pt/learn/projects-and-artifacts/storage-and-databases) от Replit.
</Warning>

<div id="casos-de-uso">
  ## Варианты использования
</div>

Ниже приведены примеры различных типов опубликованных App.

<div id="autoscale-deployment-app-de-avaliao-de-velocidade-de-digitao">
  ### Autoscale deployment: App для проверки скорости печати
</div>

Облако автоматически увеличивает ресурсы, когда пользователи проходят тесты на скорость печати, и сокращает их, когда они не нужны.

<div id="static-deployment-simulao-do-sistema-solar">
  ### Статическое развёртывание: симуляция Солнечной системы
</div>

Изучайте планеты в веб-приложении для визуализации Солнечной системы.
Эта визуализация отображается в браузере и не передаёт данные, введённые пользователем, на сервер.

<div id="reserved-vm-deployment-bot-do-discord">
  ### Reserved VM deployment: Discord-бот
</div>

Запустите Discord-бота, который помогает модерировать сообщество и адаптировать новых участников.
Он всегда онлайн: общается с пользователями и отвечает на команды — при предсказуемой стоимости и производительности.

<div id="scheduled-deployment-gatilhos-de-automao-residencial">
  ### Развёртывание по расписанию: триггеры домашней автоматизации
</div>

Запланируйте вызовы API для включения и выключения устройств умного дома в определённое время и дни.
