Preview affiche le résultat de votre web app et propose des outils de développement de navigateur ainsi que
des fonctionnalités de débogage.

Lorsque vous lancez votre web app à l&#39;aide du bouton **Run**, Replit lui attribue une URL temporaire
accessible sur Internet. L&#39;outil Preview affiche la page exactement comme vous la
verriez dans un navigateur. Il intègre également des outils de développement aux fonctionnalités similaires à
celles des navigateurs les plus courants.

<Note>
  Preview est le nouveau nom de Webview.
</Note>

<div id="features">
  ## Fonctionnalités
</div>

Preview offre les fonctionnalités suivantes pour vous permettre de tester et de déboguer vos web apps en toute fluidité :

* **Vue web en direct** : visualisez votre app et interagissez avec elle sans quitter votre onglet de navigateur
* **Outils de développement** : utilisez les outils intégrés pour diagnostiquer rapidement les problèmes
* **Tests responsifs** : affichez votre app dans différentes tailles d&#39;écran d&#39;appareils mobiles

<div id="usage">
  ## Utilisation
</div>

L&#39;outil Preview s&#39;ouvre automatiquement lorsque vous exécutez une web app.
Vous pouvez modifier ce comportement dans l&#39;outil **User Settings**, via le paramètre **Automatic Preview**.

Les instructions suivantes expliquent comment ouvrir Preview.

<Accordion title="Comment accéder à Preview">
  Depuis le **Tool dock** de gauche :

  1. Sélectionnez <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Icône Tous les outils" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools** pour afficher la liste des outils du Project Editor.
  2. Sélectionnez <img class="icon-svg" src="/assets/mirror/preview-icon-6d37238e8cc2.svg" alt="Icône Preview" width="16" height="16" data-path="images/icons/preview-icon.svg" /> **Preview**.

  Depuis la **barre de recherche** :

  1. Sélectionnez la <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="icône loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> loupe en haut de l&#39;écran pour ouvrir l&#39;outil de recherche
  2. Saisissez « Preview » pour trouver l&#39;outil, puis sélectionnez-le dans les résultats.
</Accordion>

<div id="location-bar">
  ## Barre d&#39;adresse
</div>

La barre d&#39;adresse située en haut de l&#39;onglet **Preview** comprend les outils suivants :

* **Bouton Précédent** : revenez à la page précédente de l&#39;historique de navigation
* **Bouton Suivant** : passez à la page suivante de l&#39;historique de navigation
* **Domaine de l&#39;application** : consultez les informations sur l&#39;URL temporaire de votre Replit App en sélectionnant `{...}.replit.dev`
* **Champ d&#39;adresse** : consultez le chemin de l&#39;URL actuelle ou saisissez un nouveau chemin

<div id="browser-tools">
  ## Outils du navigateur
</div>

Les outils du navigateur situés à droite de la barre d&#39;adresse offrent les fonctions suivantes :

* **Taille d&#39;écran** : choisissez parmi différents préréglages de taille d&#39;écran d&#39;appareil pour tester vos designs responsifs
* **Devtools** : affichez ou masquez le volet des [outils de développement](#Developer_tools)
* **Nouvel onglet** : ouvrez l&#39;URL de votre web app dans un nouvel onglet du navigateur

<Note>
  **Vous créez une application mobile ?** Le panneau Preview permet également de prévisualiser sur un **simulateur iOS** ou un **émulateur Android**. Consultez [Applications mobiles natives](/fr/features/artifact-types/building-mobile-apps#preview-on-a-simulator-or-emulator) pour en savoir plus.
</Note>

<div id="developer-tools">
  ## Outils de développement
</div>

Les outils de développement, propulsés par le projet open source <a href="https://github.com/liriliri/eruda" target="_blank">Eruda</a>, vous permettent de réaliser les tâches suivantes :

* Consulter et utiliser la console JavaScript dans le contexte de votre app
* Inspecter les éléments du DOM
* Surveiller les requêtes réseau
* Configurer les préférences d&#39;affichage et de comportement

Pour accéder aux outils de développement, sélectionnez le bouton <img class="icon-svg" src="/assets/mirror/wrench-7cee9d1168da.svg" alt="icône clé à molette" width="16" height="16" data-path="images/icons/wrench.svg" /> **Devtools**
en haut de l&#39;onglet **Preview** pour les afficher ou les masquer.

Les sections suivantes décrivent les actions que vous pouvez effectuer dans chaque onglet des outils de développement.

<div id="console">
  ### Console
</div>

L&#39;onglet **Console** affiche les journaux JavaScript générés par votre application.
Dans cet onglet, vous pouvez effectuer les actions suivantes :

* **Effacer la sortie** : supprimez l&#39;intégralité de la sortie de la console en sélectionnant l&#39;icône <img class="icon-svg" src="/assets/mirror/clear-bd1bf1847597.svg" height="16" width="16" alt="icône effacer" data-path="images/icons/clear.svg" /> représentant un cercle barré.
* **Filtrer la sortie** : affichez la sortie de la console filtrée par type (All, Info, Warning ou Error).
* **Filtrer par texte** : affichez uniquement la sortie correspondante en sélectionnant l&#39;icône <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="icône filtre" data-path="images/icons/filter.svg" /> de filtre, puis en saisissant le texte.
* **Copier la sortie** : copiez les messages de console sélectionnés à l&#39;aide du bouton <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="icône copier" data-path="images/icons/copy.svg" /> de copie.
* **Exécuter du code JavaScript** : exécutez du code JavaScript dans le contexte de votre application en sélectionnant le chevron droit <img class="icon-svg" src="/assets/mirror/arrow-right-2859a6e6bdeb.svg" height="16" width="16" alt="icône flèche droite" data-path="images/icons/arrow-right.svg" />. Saisissez l&#39;expression, puis sélectionnez **Execute**.

<div id="elements">
  ### Éléments
</div>

L&#39;onglet **Elements** vous permet d&#39;inspecter et de modifier la structure DOM de la page web.

* **Afficher les détails d&#39;un élément** : consultez les détails de l&#39;élément DOM et son emplacement dans le code HTML
* **Copier la sortie** : copiez les messages de console sélectionnés en cliquant sur le bouton de copie <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="icône de copie" data-path="images/icons/copy.svg" />.

Utilisez la flèche de sélection <img class="icon-svg" src="/assets/mirror/select-1165d9548c39.svg" height="16" width="16" alt="icône de sélection" data-path="images/icons/select.svg" /> pour activer ou désactiver le mode sélection.
Une fois le mode sélection activé, sélectionnez un élément sur la page web.
Le code HTML et CSS de cet élément s&#39;affiche alors dans l&#39;onglet Elements.

<div id="network">
  ### Réseau
</div>

L&#39;onglet **Network** surveille les requêtes émises par la page web.
Dans cet onglet, vous pouvez effectuer les actions suivantes :

* **Suivre les requêtes** : affichez toutes les requêtes réseau émises par votre app. Sélectionnez une requête pour en afficher les détails.
* **Filtrer** : sélectionnez l&#39;icône d&#39;entonnoir <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="icône de filtre" data-path="images/icons/filter.svg" /> pour n&#39;afficher que les résultats correspondant à votre texte. Laissez le filtre vide pour l&#39;effacer.
* **Copier** : copiez les informations de stockage en sélectionnant le bouton de copie <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="icône de copie" data-path="images/icons/copy.svg" />.

<div id="resources">
  ### Ressources
</div>

L&#39;onglet **Resources** affiche les ressources chargées par la page ainsi que le stockage du navigateur, comme les cookies et le stockage local.
Vous pouvez consulter et actualiser les listes des types de ressources suivants :

* Fichiers JavaScript
* Feuilles de style
* Iframes
* Images

Dans cet onglet, vous pouvez effectuer les actions suivantes :

* **Consulter le stockage** : examinez le stockage local, le stockage de session et les cookies.
* **Filtrer** : sélectionnez l&#39;icône d&#39;entonnoir <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="icône de filtre" data-path="images/icons/filter.svg" /> pour n&#39;afficher que les résultats correspondant à votre texte. Laissez le filtre vide pour l&#39;effacer.
* **Effacer** : supprimez toutes les données de ce type de stockage en sélectionnant le bouton d&#39;effacement <img class="icon-svg" src="/assets/mirror/clear-bd1bf1847597.svg" height="16" width="16" alt="icône d'effacement" data-path="images/icons/clear.svg" />.
* **Supprimer la sélection** : retirez des éléments du stockage en sélectionnant l&#39;icône « X » <img class="icon-svg" src="/assets/mirror/delete-a21eb49cac3c.svg" height="16" width="16" alt="icône de suppression" data-path="images/icons/delete.svg" />.
* **Copier** : copiez les informations de stockage en sélectionnant le bouton de copie <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="icône de copie" data-path="images/icons/copy.svg" />.

<div id="settings">
  ### Paramètres
</div>

L&#39;onglet **Settings** vous permet de personnaliser l&#39;apparence et le comportement des outils de développement.
Cet onglet propose des options de personnalisation pour les éléments suivants :

* **Paramètres des outils** : personnalisez les options qui s&#39;appliquent à chaque onglet d&#39;outil
* **Contrôles JavaScript** : définissez le comportement de JavaScript, par exemple en le désactivant pour tester la réaction de votre application
* **Préférences d&#39;affichage** : modifiez le thème, la taille des panneaux, la transparence et d&#39;autres comportements des outils de développement
