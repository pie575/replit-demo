Replit Agent 通过 AI 集成的开放标准 [Model Context Protocol (MCP) ](https://modelcontextprotocol.io) 连接外部工具和数据源。下列每个服务器都支持一键安装，安装后 Agent 会自动加载相应工具，并在合适的场景下使用。

概念说明请参阅 [Model Context Protocol](/zh/ko/learn/model-context-protocol)。实操指南请参阅[通过 MCP 连接](/zh/ko/build/connect-via-mcp)。若要连接此处未列出的服务器，请参阅[添加自定义 MCP 服务器](/zh/ko/build/connect-via-mcp#add-a-custom-mcp-server)。

<Info>
  要安装服务器，请选择 **添加到 Replit**。项目编辑器中会显示连接授权请求。
</Info>

<div id="section-2">
  ## 安全防护
</div>

所有 MCP 流量都会经过 Replit 安全扫描器。扫描器会评估工具定义和计划执行的操作，在可疑或不安全的工具运行前将其拦截。如果某个工具被拒绝，Agent 会通知你。

<div id="section-3">
  ## 认证选项
</div>

* **OAuth 动态客户端注册** — 如果服务器支持 OAuth DCR，Replit 会自动检测并注册客户端。大多数预注册服务器都采用这种方式。
* **自定义标头** — 定义一个或多个标头名称/值对 (例如 `X-API-Key`) 。Replit 会在所有 MCP 请求中附带这些标头，以便服务器验证调用方身份。添加使用静态令牌进行认证的自定义服务器时，请采用此方式。

<div id="section-4">
  ## 分享你的安装链接
</div>

有了安装链接，用户只需点击一次即可将 MCP 服务器添加到 Replit。你可以用[通过 MCP 连接](/zh/ko/build/connect-via-mcp#share-an-install-link)中的表单生成链接，也可以自己创建：将 JSON 负载进行 base64 编码，然后拼接到 `https://replit.com/integrations?mcp=` 后面。

```json theme={null}
{
  "displayName": "My MCP Server",
  "baseUrl": "https://example.com/mcp",
  "headers": [{ "key": "Authorization", "value": "Bearer your-token" }]
}
```

* **displayName** — 安装过程中显示的名称
* **baseUrl** — MCP 服务器的 HTTPS 端点
* **headers** — 可选的身份验证标头
