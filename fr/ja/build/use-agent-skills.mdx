Les compétences apprennent de nouvelles capacités à Agent : vos modèles préférés, les détails d&#39;une bibliothèque, les règles d&#39;un système de design ou les solutions à des problèmes que vous avez déjà résolus. Vous pouvez les joindre à un message, les installer dans un projet ou les choisir comme point de départ d&#39;un nouveau projet.

<div id="section">
  ## Utiliser les compétences dans le chat
</div>

Le moyen le plus simple d&#39;essayer une compétence est de la joindre à un seul message — aucune installation nécessaire.

<Frame>
  <img src="/assets/mirror/agent-skills-picker-ee4058454475.png" alt="Sélecteur de compétences ouvert depuis le bouton + situé à côté du champ de saisie du chat. Une liste de compétences telles que Ad Creative, AI Recruiter, AI SDR et AI Secretary est affichée" width="723" height="529" data-path="images/replitai/agent-skills-picker.png" />
</Frame>

<Steps>
  <Step title="Ouvrir le sélecteur de compétences">
    Cliquez sur le bouton **+** situé à côté du champ de saisie du chat, puis sélectionnez **Utiliser une compétence**.
  </Step>

  <Step title="Rechercher et sélectionner une compétence">
    Parcourez les compétences par catégorie : Business et finance, Créativité ou Recherche et analyse. Sélectionnez une ou plusieurs compétences à joindre à votre message.
  </Step>

  <Step title="Envoyer votre message">
    Saisissez votre demande et envoyez-la. Agent utilise les compétences sélectionnées uniquement pour ce message. Une puce de compétence s&#39;affiche sur le message pour indiquer quelles compétences sont actives.
  </Step>
</Steps>

Par exemple, vous pouvez joindre **Stock Analyzer** et demander à Agent de rédiger un rapport d&#39;analyse boursière, ou joindre **Deep Research** pour qu&#39;Agent explore un sujet et vous fournisse des résultats structurés.

<Tip>
  Les compétences jointes à un message n&#39;installent rien dans votre projet. Elles sont immédiatement utilisables dans tous les projets.
</Tip>

<div id="section-2">
  ## Démarrer un projet à partir d&#39;une compétence
</div>

Lorsque vous créez un projet, vous pouvez choisir une compétence pré-validée comme point de départ. Agent s&#39;appuie sur les instructions de la compétence pour générer la structure initiale du projet.

<Steps>
  <Step title="Ouvrir le sélecteur de point de départ">
    Sur l&#39;écran de création de projet, cliquez sur **+**, puis sélectionnez **Utiliser une compétence**.
  </Step>

  <Step title="Choisir une compétence">
    Parcourez les compétences sélectionnées, telles que **AI SDR**, **SEO Auditor**, **Ad Creative** ou **Programmatic SEO**. Choisissez celle qui correspond au type d&#39;application que vous souhaitez créer.
  </Step>

  <Step title="Décrire votre application">
    Indiquez à Agent ce que vous souhaitez créer. Agent construit alors le projet en appliquant dès le départ les modèles et les conventions de la compétence.
  </Step>
</Steps>

<div id="section-3">
  ## Installer une compétence dans un projet
</div>

Pour qu&#39;Agent applique une compétence de manière cohérente dans toutes les conversations d&#39;un projet, installez-la. Les compétences installées sont enregistrées dans le répertoire `/.agents/skills` du projet et sont conservées d&#39;une session de chat à l&#39;autre.

<div id="section-4">
  ### Installer depuis le panneau des compétences
</div>

Ouvrez le **panneau des compétences** dans l&#39;éditeur de projet, puis sélectionnez l&#39;onglet **Discover** pour rechercher les compétences proposées par la communauté. Lorsque vous en trouvez une qui vous intéresse, cliquez sur **Installer** : elle est automatiquement ajoutée à votre projet.

<Frame>
  <img src="/assets/mirror/agent-skills-discover-732b2b0c488a.png" alt="Onglet de compétences Discover affichant les compétences de la communauté, avec recherche et bouton d'installation" width="2542" height="1850" data-path="images/replitai/agent-skills-discover.png" />
</Frame>

Par exemple, pour créer un site portfolio doté d&#39;animations avancées, vous pouvez installer :

* **GSAP React** — apprend à Agent les animations déclenchées au défilement, les révélations de texte et le tracé de chemins SVG
* **Tailwind design system** — fournit à Agent les modèles Tailwind CSS pour la typographie, les espacements et les transitions de vue
* **Find skills** — apprend à Agent à découvrir et installer de nouvelles compétences à votre place

<Tip>
  Vous pouvez également installer des compétences depuis la [CLI npx skills](https://github.com/vercel-labs/skills) :

  ```bash theme={null}
  npx skills <skill> -a replit
  ```
</Tip>

<div id="section-5">
  ### Créer une compétence à partir d&#39;une conversation
</div>

La façon la plus naturelle de créer une compétence est de passer par une conversation avec Agent. Après avoir résolu un problème ensemble ou exploré une nouvelle bibliothèque, demandez à Agent de consigner ce qu&#39;il a appris :

<AiPrompt>
  Étudie les bonnes pratiques d&#39;intégration de GSAP React et crée une compétence pour ce projet.
</AiPrompt>

Agent s&#39;appuie sur l&#39;intégralité du contexte de la conversation pour créer un fichier de compétence détaillé. C&#39;est particulièrement efficace après une session de débogage au cours de laquelle vous avez bâti une compréhension commune du problème.

<div id="section-6">
  ### Écrire des compétences personnalisées
</div>

Pour les cas d&#39;usage avancés, créez directement vos compétences en suivant la [spécification Agent Skills](https://agentskills.io/specification). Dans la barre latérale des fichiers, activez **Afficher les fichiers masqués**, ouvrez `/.agents/skills/` et créez un nouveau fichier Markdown. Vous gardez ainsi un contrôle total sur ce que sait Agent et sur sa façon de fonctionner.
