部署类型是指 Replit 用来发布应用所采用的技术。你可以在 Publishing 工具中的 **Adjust settings** 下，通过 **Deployment type** 下拉菜单进行选择。**Autoscale** 是默认且推荐的选项，大多数构建者无需更改。

<div id="compare-deployment-types">
  ## 对比部署类型
</div>

| 类型              | 适用场景                  | 运行方式               | 计费方式         |
| :-------------- | :-------------------- | :----------------- | :----------- |
| **Autoscale**   | 流量波动较大的 web app 和 API | 繁忙时自动增加服务器，空闲时缩减至零 | 仅在处理请求期间计费   |
| **Static**      | 落地页、作品集、文档站点          | 由缓存云服务器提供文件，无需后端   | 仅按站点传输的数据量计费 |
| **Reserved VM** | 机器人、后台任务、常驻运行的 API    | 一台永不休眠的专用服务器       | 固定月费         |
| **Scheduled**   | 备份、通知等周期性任务           | 按计划执行命令，完成后停止      | 按每次运行的时长计费   |

<div id="autoscale">
  ## Autoscale
</div>

Autoscale 部署运行在可随应用流量自动扩缩容的服务器上。应用繁忙时，Replit 会自动增加服务器来分担负载；应用空闲时，服务器数量最低可降至零，让你无需为闲置时间付费。

适用场景：

* 流量波动较大的 web 应用，例如电商网站
* API 和各类服务

相关配置位于 **Adjust settings**：[机器性能与服务器数量上限](/zh/features/publishing/machine-configuration)。

<div id="static">
  ## Static
</div>

Static Deployments 将应用的文件 (如 HTML、CSS 和 JavaScript) 托管在云服务器上，借助缓存快速且低成本地分发内容，不涉及后端服务器。

适用场景：

* 营销落地页
* 作品集网站
* 产品与 API 文档站点

<Note>
  Static Deployments 不适用于使用 Agent 创建的 Replit App。Agent 构建的是需要后端服务器的 full-stack 应用，这类应用请改用 Autoscale 或 Reserved VM。
</Note>

配置项包括对外提供服务的公共目录，以及可选的构建命令。如需设置响应头、URL 重写和重定向，请参阅 [Static 高级配置](/zh/features/deployment-customization/static-deployments-advanced)。

<div id="reserved-vm">
  ## Reserved VM
</div>

Reserved VM deployment 在专用虚拟机上运行你的应用，永不休眠，性能稳定一致，月度费用固定且可预期。

适用场景：

* 内存密集型后台任务
* 需要保持长连接的聊天机器人
* 常驻运行的 API 服务器

配置项包括[机器性能](/zh/features/publishing/machine-configuration)、构建和运行命令、端口映射，以及应用以 Web 服务器还是后台工作进程的方式运行。

<div id="scheduled">
  ## Scheduled
</div>

Scheduled Deployments 会按计划在应用环境中运行指定命令，运行结束后即停止，直到下一次计划触发。你可以用自然语言描述计划，比如“每个工作日上午 9 点”，Replit 会自动将其转换为对应的计划。运行失败时，你会收到告警。

适用场景：

* 状态检查和健康报告
* 发送通知
* 启动备份

配置项包括计划、任务超时时间，以及构建和运行命令。Scheduled Deployments 不提供网页服务，因此没有公开 URL。
