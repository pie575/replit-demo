Replit Database는 완전 관리형 SQL 데이터베이스를 사용하며, Project Editor에서 Replit App에 영구 데이터 저장소를 추가할 수 있습니다.

<Note>
  가장 빠르게 시작하는 방법은 **Agent**에게 앱에 데이터베이스를 추가해 달라고 요청하는 것입니다. Agent가 integration을 설정하고 데이터베이스 스키마를 생성한 뒤, 데이터를 저장하고 조회할 수 있도록 앱을 업데이트합니다.
</Note>

<div id="features">
  ## 기능
</div>

Replit Database tool은 다음과 같은 기능을 제공합니다:

* **Database 도구**: 내장 SQL 도구로 쿼리를 실행하고 database 스키마를 관리하며 데이터를 시각화할 수 있습니다
* **타임 트래블**: database를 원하는 **Agent** checkpoint 시점으로 복원할 수 있습니다. [데이터 복구](/ko/features/data-and-storage/data-recovery)를 참고하세요
* **무료 스토리지**: 모든 Replit App에 20GB의 무료 스토리지가 제공됩니다.
* **Environment variables**: Replit App에서 environment variables를 사용해 database에 안전하게 접근할 수 있습니다

<Info>
  2025년 12월 4일 이전에 생성된 development database는 Neon에서 호스팅되어 몇 가지 중요한 차이점이 있습니다.
  자세한 내용은 [Development and production](/ko/features/data-and-storage/development-and-production#legacy-development-database)을 참고하세요.
</Info>

<div id="usage">
  ## 사용법
</div>

<YouTubeEmbed videoId="zbyRuoPNIc8" title="Replit에서 Database 사용하는 방법" />

Project Editor에서 Replit Database 도구에 바로 접근할 수 있습니다.
다음 섹션에서는 Database를 설정하고 관리하는 방법을 안내합니다.

<Accordion title="Database 도구에 접근하는 방법">
  1. **Tools** 창을 열고 **Replit Cloud** 아래의 **Database**를 선택합니다.
  2. 처음 표시되는 화면에는 데이터베이스 목록이 나타납니다. **Development Database**와 같은 항목을 선택해 엽니다.
</Accordion>

Database 도구는 데이터베이스 목록을 중심으로 구성되어 있습니다. 처음 표시되는 화면에는 각 데이터베이스와 저장 용량 사용량은 물론 현재 **Billing Period**와 **Hours of Compute Used**가 함께 표시됩니다. 데이터베이스를 열면 세 개의 탭이 나타납니다.

* **Overview**: 데이터베이스의 테이블 목록입니다.
* **My Data**: 행을 조회하고 편집하거나 SQL 쿼리를 실행합니다.
* **Settings**: 연결 문자열, 저장 용량 사용량, 연결 정보를 확인합니다.

<div id="add-a-database">
  ### 데이터베이스 추가
</div>

모든 Replit App에는 기본적으로 데이터베이스가 제공됩니다. Project Editor에서 <img class="icon-svg" src="/assets/mirror/postgres-c4cb2a1e2de3.svg" alt="PostgresSQL database icon" width="24" height="24" data-path="images/icons/postgres.svg" /> **Database** 도구를 선택하면 사용할 수 있습니다.

**Agent**에게 Replit App에 PostgreSQL 데이터베이스를 추가해 달라고 요청하면서 Replit App이 어떤 데이터를 저장해야 하는지 함께 알려주면 데이터베이스를 Replit App에 통합할 수 있습니다. Agent가 데이터베이스 스키마를 생성하고 앱이 데이터베이스와 통신하도록 업데이트해 줍니다.

<div id="security-features">
  ### 보안 기능
</div>

**Agent**로 데이터베이스 integration을 추가하면 모든 데이터베이스 통신을 보안이 내장된 방식으로
처리하는 ORM(Object-Relational Mapper)이 함께 추가됩니다.

이 ORM 계층은 Agent가 적용하는 보안 모범 사례와 결합되어, 다음 기능을 통해 앱을 각종 공격으로부터
보호합니다.

* **스키마 검증**: 데이터가 예상한 형식에 맞는지 확인합니다
* **데이터 정제**: SQL 인젝션 공격을 막기 위해 builder의 입력을 자동으로 정리합니다
