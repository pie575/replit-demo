Le répertoire des compétences est un catalogue de compétences prêtes à l&#39;emploi, créées par Replit et par nos partenaires, que vous pouvez installer et utiliser immédiatement. Installez-en une, essayez-la, puis modifiez-la pour l&#39;adapter à la façon dont votre équipe travaille au quotidien.

Pour savoir ce qu&#39;est une compétence et comment Agent la charge, consultez [Agent Skills](/fr/features/agent/skills). Pour rendre une compétence disponible dans l&#39;ensemble de votre workspace, consultez [Personnalisation d&#39;Agent](/fr/features/agent/agent-customization).

<div id="install-a-skill">
  ## Installer une compétence
</div>

Vous pouvez ajouter une compétence depuis le répertoire de plusieurs façons :

* **Dans le chat** — cliquez sur le bouton **+** à côté du champ de saisie du chat, sélectionnez **Use a skill**, puis choisissez-en une. La compétence s&#39;applique uniquement à ce message et rien n&#39;est installé dans votre project.
* **Dans un project** — ouvrez le **volet Skills** dans le Project Editor, sélectionnez l&#39;onglet **Discover**, trouvez une compétence et cliquez sur **Install**. Les compétences installées se trouvent dans le répertoire `/.agents/skills` de votre project et sont conservées d&#39;un chat à l&#39;autre.
* **Depuis la ligne de commande** — installez une compétence avec la [CLI skills](https://github.com/vercel-labs/skills) :

  ```bash theme={null}
  npx skills <skill> -a replit
  ```

<Warning>
  Les compétences du sélecteur de compétences Replit font l&#39;objet d&#39;un audit de sécurité. Ce n&#39;est pas le cas de celles installées depuis des sources externes. Une compétence étant un ensemble d&#39;instructions qu&#39;Agent suit, examinez toujours une compétence externe avant de l&#39;installer — consultez [Compétences Agent](/fr/learn/agent-skills) pour savoir quoi vérifier.
</Warning>

<div id="replit-skills">
  ## Compétences Replit
</div>

Replit intègre des compétences prédéfinies, accessibles depuis le sélecteur **Use a skill** dans le chat et depuis le sélecteur de point de départ d&#39;un nouveau projet. Elles fonctionnent dans tous les projets, sans installation. Les descriptions s&#39;affichent directement dans le sélecteur lorsque vous l&#39;ouvrez.

| Catégorie              | Compétences                                                                                                   |
| ---------------------- | ------------------------------------------------------------------------------------------------------------- |
| Vente et marketing     | Ad Creative, AI SDR, SEO Auditor, Programmatic SEO, GEO, Content Machine, Storyboard                          |
| Carrière               | AI Recruiter, Resume Maker, Interview Prep                                                                    |
| Recherche et analyse   | Competitive Analysis, Deep Research, GitHub Solution Finder, Supplier Research                                |
| Business et finance    | Stock Analyzer, Excel Generator, Invoice Generator, Tax Reviewer                                              |
| Documents et outils    | Website Cloner, File Converter, Flashcard Generator, Legal Contract, Infographic Builder, Recreate Screenshot |
| Création               | Photo Editor, Podcast Generator, Podcast Marketing, Branding Generator, Video Editing                         |
| Productivité           | AI Secretary, Product Manager, Design Thinker, Skill Finder, Skill Creator                                    |
| Personnel              | Travel Assistant                                                                                              |
| Sécurité et conformité | Secrets, Sensitive Data, Input Validation, AI Security, Dependency Vetting, License Check                     |
| Qualité et fiabilité   | Accessibility, Responsive UI, Observability, Resilience, Ship Review                                          |

<Note>
  Au sein d&#39;un workspace, le sélecteur détecte également toutes les compétences supplémentaires installées dans le répertoire `.local/secondary_skills/` du projet.
</Note>

<div id="partner-skills">
  ## Compétences des partenaires
</div>

Les partenaires de Replit publient des compétences qui apprennent à Agent à développer avec leurs produits. Installez-en une pour fournir à Agent les modèles et conventions propres à ce service.

| Partenaire       | Ce que la compétence apprend à Agent                         |
| ---------------- | ------------------------------------------------------------ |
| Stripe           | Modèles d&#39;intégration des paiements et de la facturation |
| PayPal           | Modèles d&#39;intégration des paiements                      |
| RevenueCat       | Modèles d&#39;abonnement et d&#39;achat intégré              |
| Mixpanel         | Mise en œuvre de l&#39;analytique et du suivi                |
| BigQuery         | Modèles de requêtes d&#39;entrepôt de données                |
| Resend           | Intégration des e-mails transactionnels                      |
| Google Workspace | Intégration de Gmail, Drive, Docs et Agenda                  |
| Atlassian        | Flux de travail des tickets et pages Jira et Confluence      |
| Google Maps      | Intégration des cartes, lieux, itinéraires et géocodage      |

<div id="community-skills">
  ## Compétences de la communauté
</div>

Outre les compétences proposées par Replit et ses partenaires, la communauté publie des compétences que vous pouvez installer. Parcourez-les sur [skills.sh](https://skills.sh) et consultez la [spécification Agent Skills](https://agentskills.io/specification) pour créer les vôtres.
