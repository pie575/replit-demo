<div id="agent-now-has-access-to-replit-docs">
  ### Agent 现已可访问 Replit Docs
</div>

Agent 现在可以即时解答你有关 Replit 功能和文档的问题。通过直接访问完整的 Replit Docs，Agent 可在你编写代码时提供快速、准确且全面的帮助。

<div id="visual-editor-color-picker-improvement">
  ### Visual Editor 取色器改进
</div>

在 Agent 的 Visual Editor 中，颜色编辑体验更加流畅。现在，点击颜色十六进制输入框即可自动打开取色器弹窗，轻松选择颜色。
