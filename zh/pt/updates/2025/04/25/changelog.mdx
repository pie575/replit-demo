<div id="tour-do-agent-no-aplicativo-mobile-e-implantaes-no-dock">
  ### 移动端 Agent 导览与停靠栏中的部署
</div>

移动应用现已推出 Agent 上手导览，帮助新手创作者快速入门。此外，「部署」现在默认显示在停靠栏中，让你直接在移动设备上就能轻松管理已发布的应用。

<div id="sincronizao-de-segredos-de-implantao-com-segredos-do-workspace">
  ### 部署密钥与 workspace 密钥同步
</div>

部署现在会自动与你的 Workspace 密钥保持同步！这意味着环境变量始终一致，因配置不同步导致的重新部署失败将大大减少。如有需要，你仍然可以显式“取消同步”，从而单独覆盖某个值。

  ### 团队邀请功能改进
</div>

<div id="configuraes-avanadas-de-privacidade-para-equipes">
  ### 面向团队的高级隐私设置
</div>

Enterprise 团队现在可通过全新的高级隐私设置，进一步掌控组织数据。您可以禁止成员创建公开应用或将代码导出为 zip 文件，确保知识产权始终留在组织内部并受到保护。
