Conversation — это отдельная ветка, в которой можно задавать вопросы, изучать информацию, запускать Routine и описывать желаемый результат. Любая задача в Replit начинается с Conversation.

<Note>
  Conversation — приватны. Доступ к ним в вашем Workspace есть только у вас. Для
  совместной работы попросите Replit создать Project.
</Note>

<div id="ask-a-question">
  ### Задайте вопрос
</div>

Replit может искать и анализировать информацию в интернете, подключённых инструментах и загруженных файлах. Задайте конкретный вопрос или укажите контекст, который Replit должен использовать.

Например, попросите Replit кратко изложить вашу активность в Slack за эту неделю и отметить
сообщения, которые ждут ответа.

<div id="run-a-routine">
  ### Запуск Routine
</div>

Routine планирует повторяющуюся работу внутри Conversation. Replit возвращает каждый результат в ту же Conversation, где вы можете его просмотреть и продолжить работу. Подробнее о [Routine](/ru/chat/routines).

Например, попросите Replit каждое утро просматривать Slack и присылать вам список приоритетов.

<div id="conversations-vs-projects">
  ## Conversation или Project
</div>

Conversation — это одна ветка для вопросов, исследования идей и Routine. [Project](/ru/features/projects-and-artifacts/projects) — это более полноценная рабочая среда для серьёзной работы по сборке и дизайну, в том числе с несколькими artifact.

Начните с Conversation. Когда работа перерастает в полноценную сборку или дизайн, Conversation можно превратить в Project.

На боковой панели Conversation обозначается значком облачка чата, а Project — значком сетки из четырёх квадратов.

<Frame>
  <img src="/assets/mirror/conversation-and-project-icons-025a17613daa.png" alt="Боковая панель Replit: Project со значком сетки из четырёх квадратов и Conversation со значком облачка чата" width="466" height="290" data-path="images/chat/conversation-and-project-icons.png" />
</Frame>

| Область            | Conversation                          | Project                                                                                      |
| ------------------ | ------------------------------------- | -------------------------------------------------------------------------------------------- |
| Лучше подходит для | Вопросов, исследования идей и Routine | Серьёзной работы по сборке и дизайну: приложения, презентации, дашборды и несколько artifact |
| Фоновые задачи     | **Недоступны**                        | **Могут выполняться параллельно**                                                            |
| Routine            | **Доступны**                          | **Недоступны**                                                                               |
| Integration        | Доступны                              | Доступны                                                                                     |
| Структура          | Одна ветка                            | Рабочая среда project с несколькими artifact                                                 |
