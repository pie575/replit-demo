title: "Agent 个性化"
description: "通过适用于整个 工作区 的自定义指令和 skills，让 Agent 掌握团队的规范约定，并在“工作区设置”中集中管理。"

Agent 个性化为 Agent 提供必要的上下文，让它从第一个 prompt 起就按照你和团队的习惯来工作。你不必在每个项目中重复说明自己的规范，只需为 工作区 定义一次，Agent 就会在所有项目中应用。

它包含两个部分：

* **自定义指令**：始终生效的准则，适用于 工作区 中的每个项目。
* **Skills**：可复用的指令，Agent 仅在遇到相关任务时才会加载。

两者均可在 **工作区设置 → 个性化** 中管理。

<div id="instrues-personalizadas-vs-skills">
  ## 自定义指令与 skills 的区别
</div>

自定义指令会随每条消息一起加载；而 skills 只在 Agent 判断其与当前任务相关时才会加载。少数始终适用的准则请写入自定义指令；特定的工作流程、约定和参考资料则交给 skills。

关于这样划分的原因——上下文预算、什么内容放在哪里，以及如何编写合适的 skills——请参阅 [Agent skills](/zh/pt/learn/agent-skills)。关于 skills 的结构以及 Agent 如何加载它们，请参阅 [Agent skills](/zh/pt/features/agent/skills)。

<div id="instrues-personalizadas">
  ## 自定义指令
</div>

自定义指令是始终生效的准则,会在任何人输入 prompt 之前,注入到每个项目、每次会话的 Agent 上下文中。你只需在工作区设置中编写一次,Agent 就会在整个 工作区 中应用这些指令。它们最适合用来描述那些始终成立的准则,例如安全与合规要求、已批准的库和框架,或数据处理政策。

内容要简短。一条聚焦且具体的指令更有可能被严格遵循,也能为 Agent 实际要完成的工作留出更多空间。

<Warning>
  自定义指令可能会影响 Agent 的表现。Agent 会尽力遵循这些指令,但严格的要求无法得到保证。越简短、越具体的准则,遵循得越可靠。
</Warning>

<Note>
  工作区 的自定义指令不同于项目中的 `custom_instruction/instructions.md` 文件。工作区 自定义指令只需在工作区设置中定义一次,即可适用于每个项目;而项目级的文件仅在单个项目内生效——这种用法请参阅[创建自定义设计系统](/zh/pt/teams/custom-design-system)。
</Note>

<div id="skills">
  ## Skills
</div>

skill 是一组可复用的指令，Agent 只在遇到相关任务时才会加载。工作区 skills 会显示在你 工作区 中每个项目的 **+** 菜单顶部，让整个团队共用同一套 skills。

创建 skill 有三种方式：

* **上传**已有的 skill 文件夹。
* 直接在表单中**编写**新的 skill。
* **让 Agent** 为你起草一个 skill，再进一步完善。

<Note>
  你可以将 Agent 起草的 Skills 上传到你的 工作区。让 Agent 下载该 skill，Agent 会将其打包为 `.zip` 文件并提供**下载文件**按钮 (如下图所示) 。下载该 zip 文件后，在 **工作区设置 → 个性化 → Skills** 中通过**创建 skill → 选择文件或文件夹**重新上传，即可在整个 工作区 中共享。
</Note>

<Frame>
  <img src="/assets/mirror/agent-customization-download-skill-3727b188c5a8.png" alt="Agent 已将一个 工作区 skill 打包为 ux-designer-skill.zip 文件供下载，并附有“下载文件”按钮" width="1716" height="864" data-path="images/replitai/agent-customization-download-skill.png" />
</Frame>

有关 skills 的完整结构 (`SKILL.md`、支持文件、开放标准) ，请参阅 [Agent Skills](/zh/pt/features/agent/skills)。若想浏览 Replit 及合作伙伴已创建的 skills，请参阅 [Skills 目录](/zh/pt/features/agent/skills-directory)。

<Note>
  请谨慎使用 skills。Agent 在每次任务中都会读取每个 skill 的名称和描述，skills 过多 (或内容相互重叠) 会分散其注意力，也更难选中正确的 skill。请让每个 skill 的适用范围保持聚焦，并及时移除不再需要的 skill。
</Note>

<div id="disponibilidade-e-permisses">
  ## 可用性与权限
</div>

| 功能     | 适用范围             | 谁可以管理                                     |
| ------ | ---------------- | ----------------------------------------- |
| 自定义指令  | Pro 和 Enterprise | Enterprise：管理员。Pro：任意 工作区 成员        |
| Skills | 所有付费方案           | Enterprise：管理员。Core 和 Pro：任意 工作区 成员 |

在 Enterprise 工作区 中，只有管理员可以创建、编辑或删除自定义指令和 skills。在 Pro 工作区 中，任意 工作区 成员均可执行这些操作。在 Core 工作区 中，任意成员都可以管理 skills——但 Core 不提供自定义指令。无论哪种情况，所有 工作区 成员都可以使用已创建的 skills。

<div id="criar-uma-instruo-personalizada">
  ## 创建自定义指令
</div>

<Steps>
  <Step title="打开工作区设置">
    前往 **工作区设置 → 个性化**。

    <Frame>
      <img src="/assets/mirror/agent-customization-tab-930af2e8ed74.png" alt="工作区设置中的“个性化”标签页，显示 Skills 和自定义指令子标签页" width="1065" height="394" data-path="images/replitai/agent-customization-tab.png" />
    </Frame>
  </Step>

  <Step title="编写指令">
    在 **自定义指令** 部分，写下你希望 Agent 在每个项目中都遵循的准则。
  </Step>

  <Step title="保存">
    保存更改。该指令将应用于你 工作区 中的新建项目。
  </Step>
</Steps>

<div id="criar-uma-skill">
  ## 创建 skill
</div>

<Steps>
  <Step title="打开工作区设置">
    进入 **工作区设置 → 个性化**。
  </Step>

  <Step title="创建 skill">
    在 **Skills** 区域点击 **创建 skill**，然后上传 skill 文件夹、直接编写说明，或让 Agent 帮你起草一份。

    <Frame>
      <img src="/assets/mirror/agent-customization-create-skill-fcb794e6de4e.png" alt="工作区设置中的个性化标签页，包含 Skills 和自定义指令子标签页，并打开了创建 skill 表单" width="2168" height="1350" data-path="images/replitai/agent-customization-create-skill.png" />
    </Frame>
  </Step>

  <Step title="编写清晰的描述">
    为 skill 撰写准确的描述，说明何时该使用它，以及何时不该使用。Agent 正是依据这段描述来判断该 skill 是否适用。
  </Step>

  <Step title="保存">
    保存该 skill。它会出现在你 工作区 中每个项目的 **+** 菜单里。
  </Step>
</Steps>

<div id="usar-uma-skill-de-workspace-em-um-projeto">
  ## 在项目中使用 工作区 skill
</div>

写好 skill 描述很重要。Agent 会读取每个 工作区 skill 的描述，当你的 prompt 与该 skill 的用途大致吻合时便会自动加载，因此你不一定需要手动选择 skill。如果想确保某个 skill 生效，也可以手动指定。

手动选择的步骤如下：

<Steps>
  <Step title="打开 skill 选择器">
    在项目中，点击聊天输入框旁的 **+** 按钮。你的 工作区 skills 会分组显示在顶部。

    <Frame>
      <img src="/assets/mirror/agent-customization-skill-picker-4643f3a453c7.png" alt="通过 + 按钮打开的 skill 选择器，顶部显示 工作区 skills 分组，位于 Replit skills 上方" width="1668" height="1170" data-path="images/replitai/agent-customization-skill-picker.png" />
    </Frame>
  </Step>

  <Step title="选择一个 skill">
    选择你想启用的 skill。你也可以输入 `/` 加上 skill 名称来直接调用。
  </Step>

  <Step title="继续输入提示">
    照常继续操作。当任务与 skill 的描述匹配时，Agent 就会使用该 skill。
  </Step>
</Steps>

<div id="gerenciar-instrues-e-skills">
  ## 管理指令与 skills
</div>

所有管理操作都在 **工作区设置 → 个性化** 中完成。在这里,你可以编辑自定义指令,也可以编辑、停用或删除任意 skill。更改仅对之后的 Chat 生效,不影响正在进行中的对话。
