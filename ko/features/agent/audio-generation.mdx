Agent의 오디오 생성 기능으로 앱에 소리를 더해 보세요. Agent에게 배경 음악, 효과음, 음성 내레이션을 만들어 달라고 요청하면 해당 오디오를 프로젝트에 바로 추가해 줍니다.

오디오 생성 기능을 활용하면 녹음 스튜디오나 성우, 외부 도구 없이도 더욱 풍부한 경험을 만들 수 있습니다. 게임이든, 단계별 튜토리얼이든, 음성이 필요한 앱이든 Agent가 프로젝트에 어울리는 오디오를 만들어 줍니다.

<div id="what-you-can-create">
  ## 만들 수 있는 것
</div>

Agent는 세 가지 종류의 오디오를 생성할 수 있습니다.

* **음악**: 설명한 분위기와 스타일에 맞춘 배경 음악과 테마 음악입니다.
* **음향 효과**: 클릭음, 알림음, 휙 하는 효과음, 게임 사운드 같은 짧은 클립입니다.
* **음성**: 입력한 텍스트를 바탕으로 만든 자연스러운 내레이션과 보이스오버입니다.

<div id="usage">
  ## Usage
</div>

오디오 생성 기능은 Agent에 기본으로 내장되어 있어 따로 켤 필요가 없습니다. Agent에서 원하는 Replit App을 열고 필요한 오디오를 설명하기만 하면 됩니다. Agent는 요청 내용에 따라 오디오를 생성할 시점을 판단해 클립을 만들고 프로젝트에 추가합니다.

<div id="when-agent-generates-audio">
  ### Agent가 오디오를 생성하는 경우
</div>

프로젝트에서 소리를 요청하면 Agent가 오디오를 생성합니다:

| 사용 사례    | 예시 prompt                                     |
| -------- | --------------------------------------------- |
| 배경 음악    | &quot;명상 앱에 차분한 배경 음악을 추가해 줘&quot;            |
| 게임 음향 효과   | &quot;게임에 쓸 코인 획득 소리와 점프 소리를 만들어 줘&quot;      |
| 음성 내레이션  | &quot;온보딩 단계를 소리 내어 읽어주는 친근한 목소리를 생성해 줘&quot; |
| 알림 및 알림음 | &quot;새 메시지가 도착할 때 재생되는 짧은 알림음을 만들어 줘&quot;   |

<div id="how-audio-fits-into-your-app">
  ## 앱에서 오디오가 사용되는 방식
</div>

Agent는 다른 assets를 다룰 때와 동일한 방식으로 생성된 오디오를 프로젝트에 추가합니다.

* **자동 파일 생성**: 생성된 오디오 파일은 프로젝트에 바로 저장됩니다.
* **코드 업데이트**: Agent가 오디오를 앱에 연결해 적절한 순간에 재생되도록 합니다.
* **반복 개선**: Agent에게 분위기, 길이, 목소리, 스타일을 조정해 달라고 요청하면 오디오를 다시 생성합니다.

<div id="billing">
  ## 청구
</div>

오디오 생성은 Agent 서비스입니다. Agent는 공급자의 요율에 따라 요금을 부과하며, 해당 금액은 Replit 크레딧에서 차감됩니다. 청구 내역은 [사용량 페이지](/ko/billing/managing-spend)에서 확인할 수 있습니다.

<Note>
  Replit의 오디오 생성은 [ElevenLabs](https://elevenlabs.io/) 기술로 구동되며, 고품질 음악, 음향 효과, 음성을 생성합니다.
</Note>
