<div id="o-que-um-workspace">
  ## 什么是 Workspace？
</div>

Workspace 是 Replit 中的协作空间，集中管理您的项目、团队成员、设置和计费。每个 Replit 账户都有一个用于管理个人项目的个人 Workspace，付费套餐则支持创建团队 Workspace，用于开展共享项目。

| 功能       | 个人 Workspace  | 团队 Workspace           |
| -------- | ------------- | ---------------------- |
| **最适合**  | 个人工作或共享单个项目   | 团队、初创公司、课堂和客户项目        |
| **访问模式** | 您可以邀请访客加入单个项目 | 成员可访问 Workspace 中的所有项目 |
| **计费**   | 您的账户          | Pro 套餐中管理员账户的共享积分      |

<div id="workspace-pessoal">
  ## 个人 Workspace
</div>

个人 Workspace 用于存放你的项目，你是唯一的管理员。你可以在项目级别邀请其他人作为访客访问特定项目，但他们无法访问 Workspace 中的所有内容。

<div id="workspaces-de-equipe">
  ## 团队 Workspace
</div>

团队 Workspace 支持团队在多个项目中协作。成员可以访问 Workspace 中的所有项目，无需逐一邀请。管理员可集中管理计费和设置。

有关配置说明、成员管理和可用性详情，请参阅[团队 Workspace](/zh/pt/core-concepts/workspaces/team-workspaces)。
