<div id="what-you-can-build">
  ## 무엇을 만들 수 있나요
</div>

Agent를 사용하면 클릭 한 번으로 앱에 Stripe를 추가할 수 있으며, 별도의 설정이 필요하지 않습니다. 스토어프런트를 만들고, 일회성 결제를 받거나 구독을 생성해 보세요. Agent가 연동, 데이터 모델, 테스트 환경까지 모두 구성해 줍니다.

<div id="how-it-works">
  ## 작동 방식
</div>

Agent는 Stripe sandbox에서 시작하므로 실제 자금을 움직이지 않고도 안전하게 payments를 테스트할 수 있습니다. flow를 만들어 곧바로 시험해 볼 수 있으며, 준비가 되면 live Stripe account로 전환해 publish하고 실제 payments를 받을 수 있습니다.

<Info>
  Stripe sandbox는 payments, 구독, 이벤트를 시뮬레이션할 수 있는 격리된 테스트 환경입니다. 자세한 내용은
  [sandbox에 대한 Stripe 문서](https://docs.stripe.com/sandboxes)를 참고하세요.
</Info>

<div id="use-stripe-with-your-team">
  ## 팀과 함께 Stripe 사용하기
</div>

Stripe는 협업 workspace에서도 작동하므로 팀 전체가 하나의 앱을 함께 만들고, 테스트하고, 수익화할 수 있습니다. 한 사람이 혼자 payments를 구축할 필요 없이, workspace의 모든 구성원이 연결된 Stripe 계정으로 작업할 수 있습니다.

<div id="get-started">
  ## 시작하기
</div>

* **Agent에게 Stripe 사용을 요청하세요**
  * 홈 화면에서 슬래시 명령을 사용해 Stripe를 선택하거나, 다음과 같이 직접 요청하세요:
    <AiPrompt>Build a storefront and integrate Stripe for payments</AiPrompt>

<Note>
  Stripe 연동을 사용하려면 backend 기능이 있는 App이 필요합니다. 홈페이지에서 **App**을 선택해 시작하세요.
</Note>

<div id="test-payments-in-the-sandbox">
  ## 샌드박스에서 결제 테스트하기
</div>

1. 새 탭에서 앱의 **Preview**를 엽니다.
2. 스토어프론트 또는 결제 페이지에서 테스트 구매를 진행합니다.
3. Stripe의 표준 테스트 카드를 사용합니다:

```text theme={null}
카드 번호: 4242 4242 4242 4242
유효기간: 미래의 임의 날짜
CVC: 임의의 숫자 3자리
이름, 주소: 임의의 테스트 값
```

<Tip>
  sandbox 구매는 실제 결제망을 거치지 않으며 실제로 돈이 오가지도 않습니다.
  처음부터 끝까지 안전하게 테스트할 수 있습니다.
</Tip>

<div id="manage-products-and-pricing">
  ## 제품 및 가격 관리
</div>

두 가지 방법이 있습니다:

1. 앱에서 **Publish**를 선택한 다음 Stripe 샌드박스 소유권 획득(claim)을 선택합니다.
   * 아직 Stripe 계정이 없다면, 샌드박스를 claim하려면 먼저 계정을 만드세요.
2. Stripe Dashboard에서 **Products**를 열어 제품과 가격을 추가하거나 편집합니다.
   Stripe 샌드박스에서 변경한 내용은 Replit App에 자동으로 반영되며
   앱의 database에 동기화됩니다.

<div id="view-synced-stripe-data">
  ### 동기화된 Stripe 데이터 보기
</div>

* Project Editor에서 **Database**를 엽니다.
* **MyData**를 선택합니다.
* schema 선택기를 **Stripe**로 변경하면 결제 객체와 관련 레코드를 확인할 수
  있습니다.

<div id="go-live">
  ## Go live
</div>

실제 payments를 받으려면 Stripe Marketplace에서
[Replit Integrated Payments](https://marketplace.stripe.com/apps/replit-integrated-payments)
앱을 설치해 live Stripe account를 연결하세요. 설치 flow에서 live 계정이
자동으로 연결되므로 API keys를 복사해 붙여 넣을 필요가 없습니다.

<Warning>
  sandbox integration은 production에 바로 사용할 수 없습니다. 아래 단계를
  완료하기 전까지는 실제 payments를 받을 수 없습니다.
</Warning>

<Steps>
  <Step title="Publish pane 열기">
    앱에서 **Publish**를 선택해 Live connection flow를 시작하세요.
  </Step>

  <Step title="Replit Integrated Payments 앱 설치">
    **Install Stripe app**을 선택하세요. Stripe 창이 열리면서
    [Replit Integrated Payments](https://marketplace.stripe.com/apps/replit-integrated-payments)
    listing이 표시됩니다.

    Stripe에서 계정을 선택하라는 메시지가 표시되면 sandbox나 테스트 계정이 아닌
    **live** Stripe account를 선택하세요.
  </Step>

  <Step>
    Stripe의 안내에 따라 앱을 설치하세요. live 계정이 아직 활성화되지 않았다면
    Stripe가 KYB(Know Your Business) 인증 절차부터 안내합니다.

    설치가 완료될 때까지 Stripe 창을 닫지 마세요. Stripe가 설치를 확인하면
    Replit이 백그라운드에서 production 연결을 마무리합니다.
  </Step>

  <Step title="앱 게시하기">
    Replit으로 돌아오세요. **Publish** pane에 live Stripe account가 연결됨으로
    표시됩니다. 앱을 Publish해 실제 payments를 받기 시작하세요.
  </Step>
</Steps>

<Note>
  Replit Integrated Payments 앱을 설치하면 Publishable 키와 Secret 키를 Replit에
  직접 복사해 넣던 기존 수동 flow가 필요 없습니다. 앱이 production 키를 대신
  설정해 주고, sandbox와 live 간 동기화도 그대로 유지됩니다.
</Note>

<div id="frequently-asked-questions">
  ## 자주 묻는 질문
</div>

<div id="how-do-i-update-the-prices-of-my-products">
  ### 제품 가격은 어떻게 업데이트하나요?
</div>

* Agent에게 요청하기: 변경할 내용을 설명하면 Agent가 앱과 Stripe 객체를 업데이트합니다.
* Stripe Dashboard 사용하기: **Products**를 열어 가격과 제품 세부 정보를 편집합니다.
  * sandbox에서는 변경 사항이 앱과 database에 자동으로 다시 동기화됩니다.
  * production에서는 먼저 라이브 계정으로 전환한 다음 가격을 업데이트하세요. 앱에서 새 configuration을 반영해야 한다면 다시 Publish하세요.

<div id="how-do-i-test-transactions-on-replit">
  ### Replit에서 거래를 테스트하려면 어떻게 하나요?
</div>

앱의 **Preview**를 새 탭에서 엽니다. 표준 테스트 카드(4242 4242 4242 4242), 미래 날짜의 만료일,
임의의 CVC를 사용해 Stripe Checkout flow를 실행하세요. 자세한 내용은 위의
[sandbox에서 payments 테스트하기](#test-payments-in-the-sandbox)를 참고하세요.

<div id="what-is-a-live-stripe-account">
  ### 라이브 Stripe 계정이란 무엇인가요?
</div>

라이브 Stripe 계정은 활성화 및 인증이 완료된 계정으로, 비즈니스 정보를 사용해
실제 결제를 처리할 수 있습니다. 계정 생성 및 활성화에 대한 Stripe의 안내는
[Stripe 계정 생성 및 관리](https://docs.stripe.com/get-started/account)를 참고하세요.

<div id="do-i-still-need-to-paste-in-my-stripe-api-keys">
  ### Stripe API 키를 직접 붙여넣어야 하나요?
</div>

아니요. 실제 Stripe 계정을 연결하면 Replit Integrated Payments 앱이 production 키를
자동으로 설치해 줍니다. Stripe Dashboard에서 live key를 복사할 필요가 없습니다.

이전에 live key를 붙여넣는 방식으로 Stripe를 연결했다면 해당 연결은 계속 작동합니다.
Stripe 연결을 제거한 뒤 **Publish** pane에서 다시 연결하면 Stripe 앱 설치 flow로
전환할 수 있습니다. 자세한 내용은 아래
[Stripe 연결 업데이트 또는 제거](#update-or-remove-the-stripe-connection)를 참고하세요.

<div id="update-or-remove-the-stripe-connection">
  ## Stripe 연결 업데이트 또는 제거
</div>

라이브 Stripe 연결 상태로 게시할 준비가 되지 않았다면 다음 두 가지
방법을 사용할 수 있습니다:

<div id="option-a-remove-the-stripe-integration-manually">
  ### 옵션 A: Stripe integration 수동으로 제거하기
</div>

project에서 Stripe integration을 완전히 제거할 수 있습니다.

<Steps>
  <Step title="Integrations 탭 열기">
    Replit App으로 이동한 후 상단의 **Integrations** 탭을 선택합니다. **Connectors** 아래에서 **Stripe**를 찾아 **Manage**를 선택합니다.

    <Frame>
      <img src="/assets/mirror/stripe-disconnect-1-integrations-371e1e7e5609.png" alt="Stripe integration과 Manage 버튼이 있는 Connectors를 보여주는 Integrations 탭" width="2000" height="1110" data-path="images/replitai/stripe-disconnect-1-integrations.png" />
    </Frame>
  </Step>

  <Step title="API keys 펼치기">
    꺾쇠 아이콘을 선택해 **Sandbox API keys**와 **Live account API keys**를 펼친 다음 **Edit**를 선택합니다.

    <Frame>
      <img src="/assets/mirror/stripe-disconnect-2-edit-keys-4e9e76c4065f.png" alt="Edit 버튼과 함께 펼쳐진 Stripe sandbox 및 live account API keys" width="2000" height="1274" data-path="images/replitai/stripe-disconnect-2-edit-keys.png" />
    </Frame>
  </Step>

  <Step title="계정 연결 해제하기">
    **Disconnect account**를 선택해 Sandbox connection을 제거하고, **Disconnect live account**를 선택해 Live connection을 제거합니다.

    <Frame>
      <img src="/assets/mirror/stripe-disconnect-3-disconnect-f4257f534c5c.png" alt="Disconnect account 및 Disconnect live account 버튼이 있는 Stripe sandbox 및 live account API keys" width="2000" height="1271" data-path="images/replitai/stripe-disconnect-3-disconnect.png" />
    </Frame>
  </Step>

  <Step title="Agent에게 Stripe 코드 제거 요청하기">
    Agent chat으로 이동해 애플리케이션에서 Stripe connector 코드를 제거해 달라고 Agent에게 요청하세요. 이렇게 하면 Stripe integration 전체가 제거됩니다.
  </Step>
</Steps>

<div id="option-b-roll-back-to-a-checkpoint-before-the-stripe-integration">

</div>

Stripe integration을 완전히 되돌리고 이전 상태로 복구하려면 이전 checkpoint로 roll back하면 됩니다.

<Steps>
  <Step title="Integrations 탭 열기">
    Replit App으로 이동한 후 상단의 **Integrations** 탭을 선택합니다. **Connectors** 아래에서 **Stripe**를 찾아 **Manage**를 선택합니다.

    <Frame>
      <img src="/assets/mirror/stripe-disconnect-1-integrations-371e1e7e5609.png" alt="Stripe integration과 Manage 버튼이 있는 Connectors를 보여주는 Integrations 탭" width="2000" height="1110" data-path="images/replitai/stripe-disconnect-1-integrations.png" />
    </Frame>
  </Step>

  <Step title="API keys 펼치기">
    셰브런을 선택해 **Sandbox API keys**와 **Live account API keys**를 펼친 다음 **Edit**를 선택합니다.

    <Frame>
      <img src="/assets/mirror/stripe-disconnect-2-edit-keys-4e9e76c4065f.png" alt="Edit 버튼과 함께 펼쳐진 Stripe sandbox 및 live account API keys" width="2000" height="1274" data-path="images/replitai/stripe-disconnect-2-edit-keys.png" />
    </Frame>
  </Step>

  <Step title="계정 연결 해제하기">
    **Disconnect account**를 선택해 Sandbox connection을 제거하고, **Disconnect live account**를 선택해 Live connection을 제거합니다.

    <Frame>
      <img src="/assets/mirror/stripe-disconnect-3-disconnect-f4257f534c5c.png" alt="Disconnect account 및 Disconnect live account 버튼이 있는 Stripe sandbox 및 live account API keys" width="2000" height="1271" data-path="images/replitai/stripe-disconnect-3-disconnect.png" />
    </Frame>
  </Step>

  <Step title="Stripe integration 이전의 checkpoint 찾기">
    Agent chat으로 이동해 Stripe integration 이전에 생성된 checkpoint를 찾습니다. chat pane 왼쪽 상단의 **시계 icon**을 선택하면 이전 채팅 기록을 볼 수 있습니다.

    <Frame>
      <img src="/assets/mirror/stripe-rollback-5-clock-icon-c54cd19246ea.png" alt="채팅 기록과 checkpoints를 보기 위한 시계 icon" width="56" height="50" data-path="images/replitai/stripe-rollback-5-clock-icon.png" />

  <Step title="Rollback here 선택하기">
    적절한 checkpoint를 찾았다면 **Rollback here**를 선택해 project를 해당 상태로 복원합니다.

    <Frame>
      <img src="/assets/mirror/stripe-rollback-6-checkpoint-2f195b0ea9ce.png" alt="Rollback here 버튼이 있는 checkpoint" width="904" height="202" data-path="images/replitai/stripe-rollback-6-checkpoint.png" />
    </Frame>
  </Step>
</Steps>

<div id="notes-and-limitations">
  ## 참고 사항 및 제한
</div>

* sandbox 활동은 실제 balance나 고객에게 영향을 주지 않습니다.
* 일부 Stripe 기능은 sandbox에서 테스트할 수 없습니다(예: IC+ pricing, 일부 Connect flow).
  [Stripe의 sandbox 제한 사항](https://docs.stripe.com/sandboxes)을 참조하세요.
