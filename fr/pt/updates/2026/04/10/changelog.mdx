<div id="integrao-com-databricks-apps">
  ### Intégration à Databricks Apps
</div>

Les créateurs Enterprise peuvent désormais créer des apps basées sur les données dans Replit et les déployer directement sur Databricks. Agent se connecte à votre environnement Databricks et peut examiner votre schéma de données sans que celles-ci ne quittent Databricks. Lorsque votre app est prête, publiez-la directement dans Databricks Apps. L’app en cours d’exécution est entièrement hébergée sur Databricks et hérite de l’authentification Databricks, de la gouvernance Unity Catalog et de vos restrictions réseau existantes.

<Frame>
  <img src="/assets/mirror/databricks-app-template-333354ec6944.png" alt="Workspace Replit affichant le template Databricks App sélectionné dans le menu déroulant Templates" width="1368" height="395" data-path="images/changelog/2026-04-10/databricks-app-template.png" />
</Frame>

Cette intégration est disponible pour les organisations Enterprise disposant d’un workspace Databricks. Pour en savoir plus, consultez la [page partenaire Replit x Databricks](https://replit.com/partners/databricks).

<div id="recrie-qualquer-interface-a-partir-de-uma-captura-de-tela">
  ### Recréez n’importe quelle interface à partir d’une capture d’écran
</div>

Collez une capture d’écran dans Agent et demandez-lui de « construire ceci » ou de « recréer cette interface ». Agent reproduit fidèlement le design en une seule fois, pour les apps web et les présentations. Cette fonctionnalité est utile pour reproduire des designs existants, recréer des interfaces de référence ou prototyper rapidement à partir d’une maquette.

<div id="pagamentos-razorpay-para-a-ndia">
  ### Paiements Razorpay en Inde
</div>

Les créateurs en Inde peuvent désormais payer par UPI et par carte via Razorpay. Cela inclut la prise en charge des mandats électroniques pour les abonnements récurrents, comme l’exige la Banque de réserve de l’Inde. Si vous êtes déjà abonné en Inde, vous pourrez bientôt passer de Stripe à Razorpay depuis votre page de facturation.

<div id="sincronizao-revenuecat-com-app-store-connect">
  ### Synchronisation de RevenueCat avec App Store Connect
</div>

L’intégration de RevenueCat inclut désormais une synchronisation automatique avec Apple. Lorsque vous configurez des achats intégrés dans RevenueCat, cette configuration se synchronise directement avec App Store Connect.

En savoir plus sur les [abonnements RevenueCat](/fr/core-concepts/monetization/revenuecat-subscriptions).

<div id="escolha-onde-seu-app-executado-com-a-geografia-de-publicao">
  ### Choisissez où votre app s’exécute grâce à la géographie de publication
</div>

Les créateurs abonnés aux formules Core, Pro et Enterprise peuvent désormais sélectionner la géographie où leur app est publiée. Lorsque vous publiez dans une géographie, vos ressources de calcul, votre base de données et votre Object Storage sont tous colocalisés dans cette région. Un proxy propre à cette géographie contribue à réduire la latence pour les visiteurs de votre app.

L’Europe est désormais disponible aux côtés de l’Amérique du Nord. L’Australie, l’Amérique du Sud et l’Asie arriveront bientôt. Les administrateurs Enterprise peuvent également limiter leur organisation à une seule géographie à des fins de conformité.

<div id="faturas-anteriores-na-pgina-de-uso">
  ### Factures précédentes sur la page d’utilisation
</div>

Vous pouvez désormais consulter vos factures précédentes directement depuis la page **Utilisation** des paramètres de votre compte. Sélectionnez une période de facturation antérieure dans le menu déroulant pour afficher le détail complet de la consommation par app.
