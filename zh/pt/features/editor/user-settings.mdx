项目编辑器的用户设置工具提供了多项选项，可用于自定义账户的外观、行为和键盘快捷键。

</Frame>

<div id="recursos">
  ## 功能
</div>

你可以通过以下几类设置来定制自己构建 Replit App 的体验：

* **主题个性化**：为项目编辑器选择浅色或深色主题
* **代码智能**：配置 AI 功能，提升应用构建体验
* **编辑器偏好设置**：调整文件编辑器的行为和外观
* **通知控制**：管理提醒偏好设置
* **无障碍选项**：让 Replit 更好地满足有特殊需求的用户
* **键盘快捷键**：设置按键组合，快速执行常用操作并浏览界面

<div id="uso">
  ## 使用方法
</div>

<Accordion title="如何打开用户设置">
  在左侧的**工具栏**中：

  1. 选择 <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="所有工具图标" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **所有工具**，查看项目编辑器的工具列表。
  2. 选择 <img class="icon-svg" src="/assets/mirror/settings-icon-c2664c3691bf.svg" alt="设置图标" width="16" height="16" data-path="images/icons/settings-icon.svg" /> **用户设置**。

  在**搜索栏**中：

  1. 选择顶部的放大镜图标 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" />，打开搜索工具
  2. 输入 &quot;User Settings&quot; 查找该工具，然后从结果中选择它。
</Accordion>

<div id="aparncia">
  ### 外观
</div>

自定义项目编辑器外观的以下设置：

* **主题选择**：可选择浅色和深色主题预设、<a href="https://replit.com/themes" target="_blank">社区主题</a>或你的自定义主题
* **自定义主题**：使用[主题](/zh/pt/features/editor/themes)编辑器创建个性化配色方案

<div id="preferncias-do-editor-de-arquivos">
  ### 文件编辑器偏好设置
</div>

使用以下设置控制文件编辑器的外观和行为：

* **字体大小**：调整文字大小，提升可读性
* **自动闭合括号**：输入左括号时自动补全对应的右括号
* **缩进检测**：打开文件时自动检测缩进设置
* **格式化粘贴文本的缩进**：重新格式化粘贴的代码，使其符合正确的缩进
* **缩进字符**：选择使用空格还是制表符缩进代码
* **缩进大小**：设置每级缩进占用的列数
* **换行 (Wrapping)&#x20;**：配置自动换行行为
* **小地图**：在侧边栏中显示可导航的代码概览
* **多选修饰键**：设置用于多选文件的键盘修饰键
* **文件树中的 Git 状态**：在文件树中显示 Git 状态标识

<div id="inteligncia-de-cdigo">
  ### 代码智能
</div>

通过以下设置配置 AI 辅助工具：

* **语义标记**：启用由 language server 驱动的高级语法高亮
* **AI 代码补全**：在你输入时提供内联代码建议
* **使用确认字符接受建议**：输入特定字符时自动接受代码建议

<div id="preferncias-de-shell-e-preview">
  ### Shell 和 Preview 偏好设置
</div>

自定义 Shell 和 Preview 工具的行为：

* **Shell 提示音 (bell)&#x20;**：Shell 工具遇到问题时播放提示音
* **自动预览**：服务器可用时自动打开 Preview 标签页
* **自动转发已打开的端口**：设置新检测到端口的处理方式

<div id="notificaes">
  ### 通知
</div>

管理以下通知设置：

* **Agent 声音通知**：当 Agent 需要你提供反馈时播放提示音
* **Agent 推送通知**：当 Agent 需要你提供反馈时，在手机上接收推送通知

<div id="alertas-de-produo">
  #### 生产告警
</div>

**生产告警**是一项独立的邮件通知设置，可让你及时掌握已发布应用的运行状况。它与产品和营销邮件互不相干，因此你只会收到真正重要的信息，不受额外干扰。

启用**生产告警**后，你将收到以下情况的邮件通知：

* **uptime 故障**：已发布的应用宕机或难以保持在线时，及时收到通知。
* **安全漏洞**：应用所依赖的软件中发现漏洞时收到通知，以便在其引发问题前及时修复。
* **模型更新**：应用所使用的语言模型发生变更或需要你处理时收到通知。

<Frame>
  <img src="/assets/mirror/production-alerts-highlight-bb76079f20fd.png" alt="通知设置中的 Production Alerts 部分，红色矩形突出显示生产告警邮件开关和安全告警严重程度下拉菜单" width="2400" height="1364" data-path="images/workspace/production-alerts-highlight.png" />
</Frame>

查找该设置的方法：

1. 在账户菜单中打开**设置**。
2. 选择 **个性化** 标签页。
3. 滚动至**邮件通知**部分，找到**生产告警**。

当已发布的应用使用了过时的语言模型时，Replit 会准备一个任务草稿 (draft task) ，将其更新为受支持的模型。你会收到一封包含该任务链接的邮件，只需一次审阅即可完成更新。

<div id="acessibilidade">
  ### 无障碍功能
</div>

您可以自定义以下无障碍设置：

* **无障碍终端输出**：为 Shell 和 Console 工具启用屏幕阅读器兼容性

<div id="atalhos-de-teclado">
  ### 键盘快捷键
</div>

要访问键盘快捷键偏好设置，请在“用户设置”工具中选择 **键盘快捷键** 选项卡。

你可以通过以下方式搜索按键组合：

* **名称**：在搜索框中输入键盘快捷键的名称或描述
* **按键组合**：选择 <img class="icon-svg" src="/assets/mirror/keyboard-7ba19771b671.svg" alt="键盘图标" width="16" height="16" data-path="images/icons/keyboard.svg" /> 图标，然后按下相应的按键组合

可通过以下操作管理快捷键：

* **添加**：选择 **添加快捷键**
* **更新**：选择 <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="铅笔图标" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> 铅笔图标
* **移除**：选择 <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="垃圾桶图标" width="16" height="16" data-path="images/icons/trash-icon.svg" /> 垃圾桶图标
