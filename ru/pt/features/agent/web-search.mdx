Создавайте приложения на основе актуальных данных из реального мира с помощью возможностей Web Search <img class="icon-svg" src="/assets/mirror/web-search-1fe8f63b5b88.svg" alt="Значок Web Search" width="16" height="16" data-path="images/icons/web-search.svg" /> в Agent.

Эта функция снимает ограничения базы знаний, обращаясь к самой свежей информации в интернете. Когда вы просите Agent создать что-то, для чего нужны актуальные сведения, он ищет в интернете и извлекает подробные материалы, чтобы ваше приложение было точнее и полезнее.

Web Search незаменим, когда нужно найти самые свежие пакеты, инструменты и сведения. Благодаря этому ваши приложения следуют актуальным передовым практикам и работают точнее.

<div id="funcionalidades">
  ## Возможности
</div>

Создавайте приложения с актуальной информацией с помощью Web Search Agent. Это избавляет от ручного поиска и сбора данных. Собираете ли вы дашборд с финансовыми данными или сайт с недавними запусками стартапов — Web Search гарантирует, что ваше приложение отражает реальное положение дел.

Agent может выполнять следующие действия Web Search:

* **Поиск**: находите в интернете актуальную информацию, самую свежую документацию и данные в реальном времени
* **Извлечение контента**: получайте подробные сведения с конкретных сайтов и URL-адресов
* **Ссылки на источники**: смотрите, где именно Agent нашёл информацию, чтобы вы могли проверить её и сослаться на неё

<div id="uso">
  ## Использование
</div>

Web Search встроен в Agent — ничего включать не нужно. Опишите, что вы хотите создать, и Agent сам определит, когда стоит поискать в интернете актуальную информацию. Добавьте в prompt ключевые слова вроде «поищи», «изучи» или «используй Web Search», чтобы явно побудить Agent выполнить поиск.

<div id="como-o-web-search-melhora-seus-apps">
  ### Как Web Search улучшает ваши приложения
</div>

Web Search выводит приложения на новый уровень: вместо данных-заглушек они используют реальную и достоверную информацию:

| Преимущество                     | Описание                                                                                     |
| -------------------------------- | -------------------------------------------------------------------------------------------- |
| Актуальные технологии            | Приложения используют самую свежую информацию и пакеты, которых нет в обучающих данных       |
| Более удачный выбор инструментов | Agent изучает варианты и подбирает оптимальные пакеты                                        |
| Современные лучшие практики      | Доступ к новейшим стандартам разработки и практикам безопасности                             |
| Преодоление ограничений          | Выходите за пределы известных модели данных и используйте пакеты, вышедшие после её обучения |
| Точные данные                    | Приложения показывают актуальную информацию вместо устаревших примеров                       |
| Профессиональный результат       | Приложения, ссылающиеся на реальные компании, выглядят надёжнее                              |
| Экономия времени                 | Не нужно вручную искать пакеты и собирать данные                                             |

<div id="citaes-de-fontes">
  ### Ссылки на источники
</div>

Когда Agent использует Web Search, он приводит **ссылки на источники**, показывающие, откуда именно взята информация. Используйте эти ссылки, чтобы:

* **Проверить информацию**: оценить надёжность и точность источников
* **Узнать больше**: перейти к исходным материалам за дополнительным контекстом
* **Сослаться на источники**: корректно указать авторство в своих приложениях
* **Отследить ход поиска**: понять, какая информация легла в основу работы Agent

<div id="busca-de-contedo">
  ### Извлечение контента
</div>

Agent может извлекать подробное содержимое с определённых сайтов, чтобы собрать полную информацию для вашего проекта. Это позволяет Agent:

* читать веб-страницы целиком и выделять нужные детали;
* обрабатывать документацию и справочные материалы;
* собирать конкретные данные из надёжных источников;
* встраивать структурированную информацию в ваше приложение.

Agent изучает актуальные библиотеки обработки изображений, сравнивает их возможности и производительность, а затем создаёт приложение на основе наиболее подходящих инструментов.

<Tip>
  Web Search лучше всего работает с конкретными и подробными запросами. При подборе технологий указывайте свои требования как можно точнее

**Дашборд сравнения финансовых показателей**

<AiPrompt>
