<div id="upgrade-to-enterprise-without-leaving-replit">
  ### 无需离开 Replit 即可升级到 Enterprise
</div>

现在，您可以从 Free、Core 或 Pro 等任何套餐升级到 Replit Enterprise，无需离开产品，也无需先联系销售团队。如果您有协作工作区，完成结账流程后，它们会自动迁移到新的 Enterprise 组织。您已发布的应用会始终在线，不会中断服务。

<div id="billing">
  ## 账单
</div>

<div id="connect-stripe-by-installing-an-app-no-keys-to-copy">
  ### 安装应用即可连接 Stripe，无需复制密钥
</div>

通过 Stripe 将应用上线变得更简单了。现在无需从 Stripe 仪表板复制正式环境 API 密钥，只需从 Stripe Marketplace 安装 Replit Integrated Payments 应用。系统会自动为你配置正式环境密钥。打开 Publish 面板，安装该应用，然后在 Stripe 中完成连接。

  <img src="/assets/mirror/stripe-replit-integrated-payments-23b3b2386671.png" alt="Chat 面板中 Agent 的“连接 Stripe”connector 卡片。卡片标题为“连接 Stripe”，带有 Stripe S 徽标；副标题为“使用 Stripe 沙盒开始测试支付功能。直接通过 Replit 创建产品并测试交易。”包含“关闭”和“连接 Stripe”按钮。" width="2678" height="1448" data-path="images/billing/stripe-replit-integrated-payments.png" />
</Frame>

详细了解[如何通过 Stripe 上线](/zh/features/monetization/stripe-payments#go-live)。

<div id="agent">
  ## Agent
</div>

<div id="agent-can-generate-music-sound-effects-and-speech">
  ### Agent 可以生成音乐、音效和语音
</div>

Agent 现在可以为你的 App 创建音频。你只需提出背景音乐、音效或旁白需求，Agent 就会生成音频并直接添加到你的项目中。使用费用将从你的 Replit 积分中扣除。

详细了解[音频生成](/zh/features/agent/audio-generation)。

<div id="workspace">
  ## 工作区
</div>

<div id="generate-media-right-on-canvas">
  ### 直接在 Canvas 中生成媒体
</div>

现在，你可以直接在 Canvas 中创建媒体。在 Canvas 工具栏中打开 **生成** 工具，然后选择 **图像**、**矢量图形** 或 **视频**，即可直接在原位置生成。整个流程都在画布上完成，无需切换工具即可设计和迭代。

</Frame>
