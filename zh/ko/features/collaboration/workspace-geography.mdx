---
title: "工作区地理位置"
description: "选择托管工作区及其中新项目开发资源的位置。"
---

工作区地理位置决定工作区开发资源的托管位置。创建工作区时选择此项，该工作区中的新项目和资源将使用所选位置。

<Note>
  工作区地理位置可能与[发布
  地理位置](/zh/ko/features/security/geography#publishing-geography)不同。发布地理位置决定已发布项目的运行位置。
</Note>

<div id="section">
  ## 工作区地理位置决定的内容
</div>

工作区包含项目、用户、设置、共享资源、集成和账单信息。每个项目中都可以使用 Project Editor 和 Replit 聊天。开发资源包括应用的开发版本及其开发数据库。

只有 Pro 用户可以选择特定的工作区地理位置。

Free 和 Core 用户的工作区地理位置会自动设置。通常会选择距离用户最近的工作区地理位置。工作区中的新项目和资源将使用该地理位置。创建工作区后，无法更改地理位置。

<div id="section-2">
  ## 选择工作区地理位置
</div>

Pro 用户在创建工作区时可以选择地理位置。

<Steps>
  <Step>打开 **Create a new workspace** 表单。</Step>
  <Step>输入工作区名称，以及 (可选) 成员的电子邮件地址。</Step>

  <Step>
    打开 **Workspace region**，然后选择 **North America**、**Europe (EU)** 或 **Asia**。
  </Step>

  <Step>选择 **Create workspace**。</Step>
</Steps>

<div id="section-3">
  ## 可用地理位置
</div>

| 地理位置                | 是否可选择工作区 |
| :---------------- | :------- |
| **北美**            | 可以       |
| **欧洲 (EU)&#x20;**&#x20;| 可以       |
| **亚洲**            | 可以       |
| **南美洲**           | 不可以      |
| **澳大利亚**          | 不可以      |
