Веб-приложения — это тип результата, который Replit создаёт по умолчанию. Опишите Agent свою идею, и он создаст полностековое веб-приложение, если вы не укажете другой тип артефакта.

<div id="section">
  ## Начало работы
</div>

Создать веб-приложение можно двумя способами.

* **Ввести промпт**: на главной странице Replit опишите, что хотите создать. Agent автоматически сгенерирует веб-приложение.
* **Выбрать в выпадающем списке**: на главной странице откройте список типов приложений, выберите **Веб-приложение** и опишите свою идею.

<div id="section-2">
  ## Основные возможности
</div>

* **Полностековый по умолчанию**: каждое веб-приложение включает фронтенд и бэкенд. Agent настраивает API-маршруты, базы данных и серверную логику, необходимые вашему App.
* **Адаптивный дизайн**: приложение автоматически подстраивается под любой размер экрана.
* **Мгновенная публикация**: опубликовать приложение можно одним щелчком. Replit берёт на себя хостинг, SSL и инфраструктуру.
* **Общая инфраструктура**: если в проекте несколько артефактов — например, мобильное приложение и панель данных, — все они используют один бэкенд, одну базу данных и одни и те же сервисы.

<div id="section-3">
  ## Варианты использования
</div>

* **SaaS-продукты**: создавайте инструменты, панели управления и платформы для клиентов.
* **Внутренние инструменты**: создавайте панели администратора, CRM и приложения для рабочих процессов вашей команды.
* **Лендинги**: запускайте маркетинговые сайты с формами, анимацией и динамическим контентом.
* **Маркетплейсы и каталоги**: создавайте сайты с каталогами, доски вакансий и платформы для сообществ.
