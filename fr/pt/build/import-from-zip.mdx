<div id="importar-de-zip">
  ## Importer depuis un fichier ZIP
</div>

⏰ *Durée estimée : trois minutes*

Importez un projet local en téléversant un fichier `.zip`.

Pour connaître toutes les options d&#39;importation, y compris depuis d&#39;autres plateformes telles que GitHub, Figma, Bolt, Lovable et Vercel, consultez la [documentation de la fonctionnalité d&#39;importation](/fr/pt/references/workspace/import).

<div id="antes-de-comear">
  ## Avant de commencer
</div>

* Un fichier `.zip` contenant votre projet
* Un dossier racine clairement défini dans le fichier
* Un compte Replit

<div id="etapas-de-importao">
  ## Étapes d&#39;importation
</div>

1. Ouvrez [replit.com/import](https://replit.com/import).
2. Sélectionnez **ZIP**.
3. Téléversez votre fichier `.zip`.
4. Ajoutez les Secrets et les variables d&#39;environnement demandés.
5. Sélectionnez **Import**.

<div id="o-que-importado">
  ## Éléments importés
</div>

* Fichiers du projet et structure des répertoires
* Fichiers de dépendances
* Modèles d&#39;exécution et de compilation pour Replit

<div id="o-que-no-importado">
  ## Ce qui n’est pas importé
</div>

* Valeurs existantes des variables d’environnement
* Domaines personnalisés
* Services propres à la plateforme nécessitant une configuration manuelle
* Données de base de données existantes
* Configuration existante d’un connecteur tiers

<div id="configure-and-run-your-app">
  ## Configurez et exécutez votre app
</div>

Lors de l’importation, {setupDescription_0}. Si votre app nécessite des modifications, utilisez les outils suivants dans le Project Editor :

* **[Agent](/fr/features/agent/overview)** : Affinez les fonctionnalités, déboguez les problèmes et modifiez le code.
* **[Secrets](/fr/core-concepts/project-editor/app-setup/secrets)** : Ajoutez des API keys et des variables d’environnement.
* **[Workflows](/fr/features/workspace-tools/workflows)** : Définissez la commande **Run** de votre app.
