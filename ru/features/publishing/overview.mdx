Инструмент Publishing — это место, где вы запускаете приложение и управляете тем, как оно работает в интернете. Он собирает всё в одной панели: веб-адрес приложения, доступ пользователей, продакшн-базу данных, мониторинг, безопасность и настройки хостинга.

Чтобы открыть его, выберите **Publishing** в разделе **Replit Cloud** на панели **Tools** или нажмите **Publish** в правом верхнем углу Project Editor.

<div id="publish-your-app">
  ## Публикация приложения
</div>

На основной панели собрано всё, что нужно подготовить перед запуском приложения. Просмотрите каждый раздел и нажмите **Publish**.

<Frame>
  <img src="/assets/mirror/publish-your-app-851815208b8a.png" alt="Панель «Publish your app» с полем Domain, публикуемым приложением, настройками доступа, настройками базы данных, мониторингом, безопасностью и инструментами вовлечения над кнопкой Publish" width="578" height="980" data-path="images/deployments/publish-pane/publish-your-app.png" />
</Frame>

* **Domain**: веб-адрес вашего приложения. Replit предлагает имя в зоне `.replit.app` и проверяет, свободно ли оно. Вы можете изменить его или после публикации подключить [собственный домен](/ru/features/publishing/custom-domains).
* **What you&#39;re publishing**: предварительный просмотр приложения, которое будет опубликовано, и URL, по которому оно будет доступно.
* **Who can access your app**: выберите **Public**, **Password protected**, **Workspace only** или **Invite only**. Приватные варианты ограничивают доступ к приложению вашим workspace либо людьми и группами, которых вы пригласите. Подробнее о [доступе к приложению](/ru/features/publishing/private-deployments).
* **Database settings**: настройте, как при публикации создаётся и наполняется данными продакшн-база данных вашего приложения. Подробнее о [продакшн-базах данных](/ru/features/data-and-storage/development-and-production).
* **Monitoring tools**: включите мониторинг, чтобы первыми узнавать о сбоях в работе приложения. Replit непрерывно проверяет, что приложение в сети, и присылает вам письмо, если что-то пошло не так. Подробнее о [мониторинге приложения](/ru/features/publishing/monitoring-a-deployment).
* **Security tools**: выполните глубокое сканирование безопасности перед публикацией. Security Agent сочетает ИИ с ведущими инструментами статического анализа и проверяет ваш project на уязвимости. Подробнее — в разделе [Project Security Center](/ru/features/security/project-security-center).
* **Engagement tools**: включите виджет обратной связи, чтобы добавить кнопку отзыва в угол опубликованного приложения. Просматривайте присланные сообщения во входящих и передавайте их Agent для исправления.

<div id="adjust-settings">
  ## Adjust settings
</div>

Выберите **Adjust settings**, чтобы вручную настроить параметры размещения приложения. Большинству создателей эти параметры менять не приходится — Replit подбирает разумные значения по умолчанию.

<Frame>
  <img src="/assets/mirror/adjust-settings-d6e124b2249f.png" alt="Раздел Adjust settings с типом деплоя, конфигурацией машины, секретами деплоя, географией деплоя и переключателем блокировки публикации при критических уязвимостях" width="574" height="794" data-path="images/deployments/publish-pane/adjust-settings.png" />
</Frame>

* **Тип деплоя**: технология, с помощью которой публикуется ваше приложение. **Autoscale** рекомендуется для большинства приложений, поскольку масштабируется от нуля до любого уровня нагрузки. Сравните [типы деплоя](/ru/features/publishing/deployment-types).
* **Machine configuration**: мощность серверов, на которых работает ваше приложение. Выберите **Edit**, чтобы изменить процессор, память и максимальное количество машин. На панели отображается стоимость одной машины и стоимость при максимальном трафике. Подробнее о [конфигурации машины](/ru/features/publishing/machine-configuration).
* **Секреты деплоя**: закрытые ключи, которые ваше приложение использует для доступа к API и сервисам (защищённое скрытое хранилище для конфиденциальных значений, таких как ключи API). Secrets автоматически синхронизируются из среды разработки в опубликованное приложение. Подробнее о [Secrets](/ru/core-concepts/project-editor/app-setup/secrets).
* **География деплоя**: место размещения вашего приложения. Чем ближе выбранный регион к вашим пользователям, тем меньше задержки. После публикации приложение и его ресурсы закрепляются за этим регионом. Чтобы сменить регион позже, сделайте ремикс приложения. Подробнее о [географии project](/ru/features/publishing/project-geography).
* **Block publishing of critical vulnerabilities**: перед публикацией Replit всегда выполняет сканирование безопасности. Этот параметр определяет, будет ли публикация заблокирована при обнаружении критических уязвимостей. Подробнее — в разделе [Project Security Center](/ru/features/security/project-security-center).
