Replit est disponible comme connecteur dans Claude. Une fois connecté, vous pouvez créer avec Replit sans quitter votre conversation avec Claude.

<div id="replit">
  ## Connecter le connecteur Replit
</div>

Ouvrez le répertoire des connecteurs dans Claude, recherchez **Replit** et connectez-le. Claude vous guidera pour vous connecter à votre compte Replit. Une fois la connexion établie, vous pouvez demander à Claude de créer une application, de modifier une application existante ou de répondre à des questions sur l’application que vous développez. Claude transmettra votre demande à Replit Agent, qui réalisera la tâche et renverra un lien vers l’application en ligne.

<Tip>
  Essayez de demander à Claude : « Créez une application Replit pour suivre mes habitudes chaque semaine » ou « Ajoutez une page de connexion à mon application Replit ». Claude transmettra votre demande à Replit Agent et renverra un lien vous permettant de suivre la progression de la création.
</Tip>

<div id="claudereplit">
  ## Envoyer des designs Claude vers Replit
</div>

Vous pouvez envoyer directement vers Replit les créations réalisées dans le canevas de design de Claude. Lorsque vous sélectionnez **Replit** comme destination, le design s’ouvre dans Replit sous la forme d’une application fonctionnelle. Agent établit un plan pour transformer le design statique en produit fonctionnel afin que vous puissiez poursuivre le développement, ajouter une base de données ou le publier.

Pour un guide complet du transfert de designs, consultez [Importer des designs Claude dans Replit Design](/fr/ja/design/import-claude-designs-into-replit-design).

<div id="section">
  ## Fonctionnement
</div>

Le connecteur Replit utilise le [serveur MCP Replit](/fr/ja/platforms/mcp-server) pour faire fonctionner Replit. Claude gère la connexion.
