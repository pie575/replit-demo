<div id="slide-decks">
  ## 什么是 Slide Decks？
</div>

Slide Decks 可让你仅通过与 Agent 对话，就能创建高质量的专业演示文稿。只需描述你的需求，即可立即获得一套完整精美的幻灯片。之后，你可以通过聊天、可视化编辑，或在 [Design Canvas](/zh/ko/design/canvas) 中探索不同方案，持续迭代优化。

幻灯片底层基于 React 构建，因此你可以将其导出为像素级精确且完全可编辑的 PPTX、Google Slides 和 PDF 文件。你还可以将幻灯片发布为可实时共享的 URL。

主要概念：

* **一次生成**：描述你的演示文稿，Agent 会创建一套包含布局、文本和视觉内容的完整幻灯片
* **基于 React**：幻灯片不是静态图片，而是真正的 React 组件，因此可以整洁地导出为各种格式
* **导出到任何位置**：下载为 PPTX、Google Slides 或 PDF，像素级精确且完全可编辑
* **可发布**：将幻灯片发布为实时 URL，让任何人都能在浏览器中查看或演示

<div id="slide-decks-2">
  ## 如何使用 Slide Decks
</div>

<div id="section">
  ### 创建幻灯片
</div>

在 Replit 主页上创建幻灯片有两种方式：

* **输入提示词**：描述你想要的演示文稿。Agent 会识别与演示相关的提示词，并自动选择 Slide deck 技术栈。
* **从下拉菜单中选择**：打开应用类型下拉菜单，选择 **Slides**，然后描述你的演示文稿。

**示例提示词：**

* “为我的 AI 健身应用制作一份路演文稿”
* “创建一份用于 A 轮融资的 10 页投资人演示文稿”
* “为我们的团队线下会议制作一份产品概览幻灯片”

<Tip>
  提前说明长度和视觉风格，Agent 无需再向你确认即可直接生成幻灯片。例如可以试试“制作一份关于远程办公的 8 页极简风格幻灯片”。
</Tip>

<div id="section-2">
  ### 从品牌指南或参考资料开始
</div>

你可以为 Agent 提供以下起点:

* **品牌指南**:上传品牌指南后,Agent 会让所有幻灯片的配色、字体和视觉风格保持一致。
* **参考文件**:上传现有的演示文稿或文档作为起点,Agent 会以此为基础构建演示文稿。

<div id="section-3">
  ### 迭代优化幻灯片
</div>

Agent 生成第一版后，你可以通过对话不断优化：

* **调整内容**：“把问题那页写得更简洁一些”或“在市场规模部分后面加一页竞争格局。”
* **更改样式**：“用蓝色点缀的深色主题”或“把字体调大，整体风格更极简一些。”
* **增删幻灯片**：“再加两页关于路线图的内容”或“删掉最后一页。”
* **添加视觉元素**：“加一张展示预期增长率的图表”或“给第 4 页的每项功能配上图标。”
* **调整顺序或重新组织**：“把团队那页移到最后”或“把功能页拆成两页。”

迭代过程中，幻灯片会在预览面板中自动渲染，改动效果即时可见。

<div id="section-4">
  ### 直接编辑幻灯片
</div>

你也可以不经过聊天，直接进行编辑：

* **[Visual Editor](/zh/ko/design/visual-editor)**：点击任意元素，即可直接调整文本、颜色、间距和布局——不消耗 AI 额度。
* **复制或删除**：右键点击幻灯片，即可复制或删除。

<Note>
  暂不支持在幻灯片内拖放元素。如需移动或重新排列元素，请在聊天中告知 Agent。
</Note>

<div id="design-canvas">
  ### 使用 Design Canvas 探索变体
</div>

你可以使用 [Design Canvas](/zh/ko/design/canvas) 为单张幻灯片或某个板块探索备选设计，然后把满意的版本导入主演示文稿。想在最终定稿前比较多种视觉方向时，这一功能尤其有用。

<div id="section-5">
  ### 演示与发布
</div>

幻灯片准备就绪后：

* **演示者模式**：在预览面板中直接切换到全屏演示模式，随时开讲。这与发布后观众看到的画面完全一致。
* **移动端支持**：幻灯片同样适配移动设备，观众在任何屏幕上都能查看。
* **发布**：将幻灯片发布为实时共享 URL。任何拿到链接的人都可以在浏览器中查看或演示该幻灯片。

<div id="section-6">
  ### 导出
</div>

下载幻灯片，即可在 Replit 之外使用：

* **PowerPoint**：在 PowerPoint 或 Keynote 中打开并编辑 `.pptx` 文件，背景、文本和图形都能稳定保留。
* **Google Slides**：直接在 Google Slides 中打开演示文稿。导出完成后，选择 **Go to Google Slides** 即可一键打开。
* **PDF**：分享静态、可直接打印的版本。即使是图片较多的演示文稿，导出后文件体积也很小，用邮件发送毫无压力。

所有导出结果均做到像素级精确且完全可编辑，在 Replit 之外看到的效果与在 Replit 内完全一致。导出速度也比以往最高提升了 10 倍。

你还可以导入已有的演示文稿。导入 `.pptx` 文件后，背景、文本和图形都会稳定还原。

<div id="section-7">
  ### 查找幻灯片
</div>

幻灯片会与其他应用一起显示在 Projects 列表中。在 Projects 页面上打开 **Build type** 下拉菜单并选择 **Slides**，即可只显示包含幻灯片制品的项目。

<div id="section-9">
  ## 常见问题
</div>

<Accordion title="可以在幻灯片中拖放元素吗？">
  暂时还不行。如需移动或重新排列幻灯片中的元素，请在聊天中告诉 Agent。你可以使用 Visual Editor 直接编辑文本、颜色和间距。
</Accordion>

<Accordion title="支持哪些导出格式？">
  可以导出为 PPTX、Google Slides 和 PDF。所有导出结果均为像素级还原，并且完全可编辑。
</Accordion>

<Accordion title="可以使用我自己的品牌指南吗？">
  可以。创建演示文稿时上传品牌指南，Agent 会在所有幻灯片中统一使用相应的颜色、字体和视觉风格。
</Accordion>

<Accordion title="幻灯片在移动设备上也能正常显示吗？">
  可以。幻灯片支持在移动设备上渲染，观众可以在任意屏幕上查看已发布或已共享的演示文稿。
</Accordion>

<Accordion title="可以将幻灯片发布为实时 URL 吗？">
  可以。发布演示文稿后会生成一个实时共享 URL，任何人都能在浏览器中查看或演示。
</Accordion>

<div id="section-10">
  ## 可用性
</div>

Slide Decks 在所有方案中均可使用，Core 和 Pro 的构建者都能使用。
