워크스페이스 지역은 워크스페이스를 위한 개발 리소스가 호스팅되는 위치를 제어합니다. 워크스페이스를 생성할 때 이를 선택하며, 해당 워크스페이스의 새 프로젝트와 리소스는 선택한 위치를 사용합니다.

<Note>
  워크스페이스 지역과 [게시
  지역](/ko/features/security/geography#publishing-geography)은 다를 수
  있습니다. 게시 지역은 게시된 프로젝트가 실행되는 위치를 제어합니다.
</Note>

## 워크스페이스 지역이 제어하는 것

워크스페이스에는 프로젝트, 사용자, 설정, 공유 리소스, 통합, 청구 정보가 포함됩니다. 각 프로젝트 내에서는 Project Editor와 Replit 채팅을 사용합니다. 개발 리소스에는 앱의 개발 버전과 그 개발용 데이터베이스가 포함됩니다.

Pro 고객만 특정 워크스페이스 지역을 선택할 수 있습니다.

Free 및 Core 고객은 워크스페이스 지역이 자동으로 설정됩니다. 일반적으로 사용자와 가장 가까운 워크스페이스 지역이 선택됩니다. 워크스페이스 내 새 프로젝트와 리소스는 해당 위치를 사용합니다. 워크스페이스를 생성한 후에는 지역을 변경할 수 없습니다.

## 워크스페이스 지역 선택하기

Pro 고객이라면 워크스페이스를 생성할 때 지역을 선택할 수 있습니다.

<Steps>
  <Step>**Create a new workspace** 양식을 엽니다.</Step>
  <Step>워크스페이스 이름과 (선택 사항으로) 멤버 이메일 주소를 입력합니다.</Step>

  <Step>
    **Workspace region**을 열고 **North America**, **Europe (EU)**, **Asia**
    중 하나를 선택합니다.
  </Step>

  <Step>**Create workspace**를 선택합니다.</Step>
</Steps>

## 사용 가능한 지역

| 지역                | 워크스페이스 선택 가능 여부 |
| :---------------- | :-------------- |
| **North America** | 가능              |
| **Europe (EU)**   | 가능              |
| **Asia**          | 가능              |
| **South America** | 불가              |
| **Australia**     | 불가              |
