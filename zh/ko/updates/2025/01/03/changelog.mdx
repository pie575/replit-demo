<div id="xai">
  ### xAI 集成
</div>

Agent 现在可以直接把 xAI 添加到你的应用中。

<Frame>
  <img src="/assets/mirror/xai-announce-232aa8bf6428.jpeg" alt="xAI 集成发布" width="3840" height="2160" data-path="images/changelog/2025-01-03/xai-announce.jpeg" />
</Frame>

只需几秒，即可将 Grok 添加到项目中并发布。在提示词中输入“用 xAI 添加 AI 功能”，或在集成中选择 xAI，Agent 就会通过 API 完成实现。

  <img src="/assets/mirror/xai-in-product-a0102e19b327.jpeg" alt="产品内的 xAI" width="1120" height="1120" data-path="images/changelog/2025-01-03/xai-in-product.jpeg" />
</Frame>

更多热门集成即将登陆 Agent。

<div id="section-3">
  ### 自定义域名错误处理
</div>

自定义域名验证失败时会给出具体的错误提示，帮助你更快地定位问题。

<div id="section-4">
  ### 菜单搜索功能
</div>

现在，你可以在 Replit 应用的侧边栏中搜索菜单项。

<div id="neon">
  ### Neon 数据库优化
</div>

Neon 数据库集成已完成优化。通过 Agent 添加的数据库成本更低，性能也更强。

<div id="react">
  ### 默认使用 React
</div>

新建前端 Replit 应用时，默认模板现在采用 React，让项目从一开始就更完整、功能更齐全。
