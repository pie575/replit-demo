Replit 的版本控制功能可让您放心地跟踪、管理和协作开发代码。借助内置的 Git 集成和 GitHub 连接，您可以：

* 跟踪代码更改，并保留开发工作的历史记录
* 与团队成员协作，避免代码冲突或工作成果丢失
* 在 Replit 和 GitHub 之间导入、修改和推送代码
* 使用分支安全地试验新功能

<div id="o-que-controle-de-verso">
  ## 什么是版本控制？
</div>

版本控制是一种记录文件随时间发生的更改的系统，让你能够在之后恢复到特定版本。在 Replit 中，版本控制由 Git 提供支持——Git 是业界标准的代码变更跟踪工具——并提供直观的可视化界面，无需掌握命令行知识。

<div id="como-o-controle-de-verso-funciona-no-replit">
  ### Replit 中的版本控制如何运作
</div>

这四种版本控制方式都使用同一个底层 Git 仓库：

1. **Agent checkpoint** 会在使用 [Replit Agent](/zh/pt/features/agent/overview) 构建应用时，自动在关键节点创建提交。[详细了解 checkpoint 和回滚](/zh/pt/features/version-control/checkpoints-and-rollbacks)。
2. **Git 面板**提供完整 Git 仓库的可视化访问
3. **Git CLI** 提供全部 Git 功能的命令行访问
4. **文件历史记录**跟踪单个文件内的细粒度更改

选择最符合需求的界面即可；所有方式都由强大的 Git 版本控制系统提供支持。

| 功能              | Agent checkpoint | Git 提交          | 文件历史记录         |
| --------------- | ---------------- | --------------- | -------------- |
| **创建方式**        | 在合理节点自动创建        | 手动或定时创建         | 自动创建           |
| **粒度**          | 功能级更改            | 任意规模的更改         | 字符级更改          |
| **描述**          | AI 生成的摘要         | 用户编写的提交信息       | 自动时间戳          |
| **回滚**          | 一键恢复             | 需要 Git 知识       | 一键恢复           |
| **Git 功能**      | 完整 Git 功能        | 完整 Git 功能       | 不具备 Git 功能     |
| **与 GitHub 同步** | 完整的 GitHub 同步功能  | 完整的 GitHub 同步功能 | 不支持与 GitHub 同步 |

<div id="primeiros-passos">
  ## 入门
</div>

将 Git 工具添加到项目编辑器，即可在 Replit App 中使用版本控制：

1. 前往 Replit App 中的“工具”部分
2. 选择 **+** 以添加新工具
3. 在可用工具列表中选择 **Git**

要从 GitHub 导入现有项目，请参阅[从 GitHub 导入](/zh/pt/build/import-from-providers)。

<div id="controle-de-verso-automtico">
  ### 自动版本控制
</div>

<Accordion title="Agent checkpoint">
  在使用 [Replit Agent](/zh/pt/features/agent/overview) 进行 AI 辅助开发时自动创建的快照。

  **适用于**：使用 Replit Agent 进行开发

  **主要功能**：

  * 在逻辑里程碑处自动创建
  * 一键回滚
  * 资源级快照
  * 进度跟踪
  * 无需配置
  * 开发进度可视化时间线

  Agent checkpoint 存储在 Git 中，可通过 Git 面板或 Git CLI 访问。你还可以通过“历史记录”功能查看所有 checkpoint，该功能提供：

  * checkpoint 的时间线视图
  * checkpoint 的详细说明
  * 直接访问 checkpoint 状态
  * 一键回滚到任意 checkpoint
</Accordion>

<Accordion title="文件历史记录">
  针对直接在编辑器中进行的非 Agent 更改，提供按文件的版本跟踪和自动保存。

  **适用于**：快速恢复文件的最近更改

  **主要功能**：

  * 聚焦单个文件
  * 字符级更改
  * 可视化对比
  * 30 天历史记录
  * 回放功能

  虽然文件历史记录有自己的界面，但底层更改仍属于 Git 历史记录的一部分。详细了解[文件历史记录](/zh/pt/features/version-control/file-history)。
</Accordion>

  ### 基于 Git 的界面
</div>

<Accordion title="Git 面板">
  用于执行 Git 操作的可视化界面，无需掌握命令行即可使用版本控制。

  **适用于**：需要 GitHub 集成和可视化工作流的大多数项目

  **主要功能**：

  * 整个仓库的变更跟踪
  * 分支管理
  * 查看差异
  * 一键同步 GitHub
  * 团队协作

  有关 Git 面板的详细使用说明，请参阅[使用 Git 面板](/zh/pt/features/workspace-tools/git-interface)。
</Accordion>

<Accordion title="Git CLI">
  通过 [Shell](/zh/pt/features/workspace-tools/shell) 使用完整的 Git 命令行功能，满足高级操作需求。

  **适用于**：需要完整 Git 功能的高级用户

  **主要功能**：

  * 完整的 Git 命令集
  * 高级分支策略
  * 自定义工作流
  * 脚本自动化
  * 对仓库的完全控制

  有关常用 Git 命令及其用法，请参阅[使用 Git 面板](/zh/pt/features/workspace-tools/git-interface#using-git-commands-in-shell)。
</Accordion>

<div id="recursos-principais">
  ## 主要功能
</div>

* **可视化 Git 界面**：无需输入 Git 命令即可管理仓库、提交和分支
* **GitHub 集成**：连接 GitHub 仓库以进行备份和协作
* **从 GitHub 导入**：只需点击几下，即可将任意 [GitHub 仓库导入为 Replit App](/zh/pt/build/import-from-providers)
* **分支管理**：直接在项目编辑器中创建、切换和合并分支
* **冲突解决**：借助可视化工具识别并解决合并冲突

<div id="casos-de-uso">
  ## 使用场景
</div>

**跟踪个人项目**

在开发过程中跟踪代码变更，以便在需要时回退到之前的版本。[Git 面板](/zh/pt/features/workspace-tools/git-interface)会以可视化方式展示你的更改，方便你提交重要更新。

**与团队协作**

与多位开发者协作处理同一份代码，无需担心覆盖彼此的更改。为新功能创建分支，准备就绪后再将其合并。详细了解如何[邀请团队成员](/zh/pt/build/invite-teammates)。

<div id="checkpoints-do-agent">
  ## Agent checkpoint
</div>

使用 [Replit Agent](/zh/pt/features/agent/overview) 创建应用时，checkpoint 可提供额外一层版本控制。checkpoint 会在 AI 辅助开发过程中的关键节点自动捕获项目的完整状态，包括项目内容、与 AI 的对话上下文以及已连接的数据库。

<div id="como-os-checkpoints-funcionam">
  ### checkpoint 的工作原理
</div>

Agent checkpoint 是整个 Replit App 状态的完整快照：

* **自动创建**：Agent 会在开发过程中的关键节点创建 checkpoint
* **捕获完整状态**：每个 checkpoint 都会保留项目内容、AI 记忆和数据库状态
* **实施计划**：在进行更改前，Agent 会先提供计划供你审核
* **复杂任务跟踪**：对于较大型的任务，可以创建多个 checkpoint

<div id="benefcios-para-o-desenvolvimento-assistido-por-ia">
  ### AI 辅助开发的优势
</div>

使用 AI 构建应用时，Agent checkpoint 可带来独特优势：

* **安全网**：你可以放心尝试，因为能够轻松恢复整个开发环境的先前状态
* **进度跟踪**：准确了解 Agent 如何一步步构建你的应用
* **逻辑里程碑**：checkpoint 代表完整功能，而非任意的保存点
* **即时回滚**：只需单击一下，即可回到任何先前状态，包括恢复数据库和 AI 上下文

<Info>
  如需详细了解 checkpoint 会捕获的内容及完整的回滚功能，请参阅 [Checkpoints 和 Rollbacks](/zh/pt/features/version-control/checkpoints-and-rollbacks)。
</Info>

<Tip>
  虽然 Agent checkpoint 非常适合 AI 开发，但对于长期版本跟踪和协作，建议使用 Git 提交，尤其是在使用外部仓库时。
</Tip>
