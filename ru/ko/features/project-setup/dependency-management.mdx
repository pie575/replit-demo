title: "Управление зависимостями"
description: "Узнайте, как устанавливать пакеты и зависимости в Replit App и управлять ими на разных языках программирования."
---

Replit предлагает несколько способов установки пакетов и управления ими в Replit App. Вы можете устанавливать пакеты через [Shell](/ru/ko/features/workspace-tools/shell), поручить эту задачу [Agent](/ru/ko/features/agent/overview/) или позволить Replit автоматически находить и устанавливать недостающие зависимости при запуске Replit App.

<div id="section">
  ## Установка пакетов через оболочку
</div>

В редакторе проекта откройте инструмент **Оболочка** и выполните команду, соответствующую менеджеру пакетов вашего языка.

<CodeGroup>
  ```bash Node.js (npm) theme={null}
  npm install <package-name>
  ```

  ```bash Node.js (pnpm) theme={null}
  pnpm add <package-name>
  ```

  ```bash Python (poetry) theme={null}
  poetry add <package-name>
  ```

  ```bash Python (pip) theme={null}
  pip install <package-name>
  ```

  ```bash Ruby theme={null}
  bundle add <gem-name>
  ```
</CodeGroup>

Устанавливать пакеты для разных поддерживаемых языков также можно с помощью [Universal Package Manager (UPM)](https://github.com/replit/upm/) от Replit.

```bash theme={null}
upm add <package-name>
```

Чтобы установить конкретную версию, выполните следующую команду:

```bash theme={null}
upm add 'flask==2.3.3'
```

Полный список поддерживаемых языков и менеджеров пакетов см. в разделе [UPM: поддерживаемые языки](https://github.com/replit/upm/#supported-languages).

<div id="agent">
  ## Установка пакетов с помощью Agent
</div>

Вы можете попросить [Agent](/ru/ko/features/agent/overview/) установить пакеты прямо в чате. Например:

* «Установи пакет axios»
* «Добавь в мой проект Flask и SQLAlchemy»
* «Настрой TailwindCSS»

Agent установит пакеты с помощью подходящего для проекта менеджера пакетов и обновит соответствующие файлы конфигурации.

<div id="section-2">
  ## Автоматическое определение импортов
</div>

Каждый раз при выборе **Запустить** Replit автоматически проверяет код на наличие отсутствующих зависимостей. Если вы импортируете ещё не установленный пакет, Replit обнаружит его и автоматически установит последнюю версию.

Например, если добавить `import flask` в `main.py`, при следующем выборе **Запустить** в **Консоли** появится сообщение об установке **Flask**.

<Note>
  Настроить автоматическое определение импортов можно с помощью параметра `packager.features.guessImports` в файле [.replit](/ru/ko/features/project-setup/configuration#replit-file).
</Note>

<div id="section-3">
  ### Переопределение автоматического определения
</div>

Если пакет определён неверно или вам нужна конкретная версия, выполните в оболочке нужную команду установки. Например:

```bash theme={null}
upm add 'flask==2.3.3'
```

В файле [.replit](/ru/ko/features/project-setup/configuration#replit-file) вы также можете исключить отдельные пакеты или пути из автоматического обнаружения.

<div id="python">
  ## Менеджер пакетов Python
</div>

При создании Replit App на Python менеджером пакетов по умолчанию будет **poetry**. Это значит, что `pip install` не управляет зависимостями. Вместо этого используйте в оболочке команду `poetry add <package>` или `upm add <package>`.

<div id="poetry-pip">
  ### Переход с poetry на pip
</div>

Если вы хотите использовать `pip`, выполните следующие шаги.

<Steps>
  <Step>
    Откройте оболочку и выполните следующую команду.

    Удалите lock-файл, чтобы инфраструктура пакетов переключилась на pip.

    ```bash theme={null}
    rm poetry.lock
    ```
  </Step>

  <Step title="Перенос зависимостей">
    Перенесите зависимости из раздела `[tool.poetry.dependencies]` файла `pyproject.toml` в `requirements.txt`. Например, `flask = "^3.0.2"` превращается в `flask>=3.0.2,<4`.
  </Step>

  <Step title="Очистка pyproject.toml">
    Удалите разделы `[tool.poetry...]` из `pyproject.toml`.
  </Step>
</Steps>

После этого инфраструктура пакетов будет использовать `pip` для всех последующих операций, а автоматическое определение импортов продолжит работать как обычно.

<div id="nix">
  ## Системные зависимости с помощью Nix
</div>

Replit поддерживает любые языки программирования благодаря интеграции с [Nix](https://nixos.org/). Если вам нужны системные зависимости, выходящие за рамки стандартных языковых пакетов, добавьте их в файл [replit.nix](/ru/ko/features/project-setup/configuration#replit-nix-file).

<div id="nix-2">
  ### Пакеты Nix
</div>

Чтобы добавить системные зависимости, отредактируйте файл `replit.nix` напрямую. Доступные пакеты можно найти на сайте [search.nixos.org](https://search.nixos.org/packages).

<div id="section-4">
  ### Модули
</div>

Модули объединяют поддержку языков программирования, форматтеров и пакетных менеджеров. Они служат основой Replit App. Когда вы создаёте Replit App из шаблона или репозитория GitHub, Replit автоматически устанавливает необходимые модули.

Настроить модули и другие параметры Nix можно в файле [.replit](/ru/ko/features/project-setup/configuration#replit-file).

<div id="section-5">
  ## Настройка packager
</div>

В файле [.replit](/ru/ko/features/project-setup/configuration#replit-file) можно точно настроить поведение системы управления пакетами.

| Настройка                             | Описание                                                                  | Значение по умолчанию      |
| ------------------------------------- | ------------------------------------------------------------------------- | -------------------------- |
| `packager.language`                   | Язык, используемый для операций с пакетами                                | Определяется автоматически |
| `packager.features.guessImports`      | Автоматически обнаруживать и устанавливать недостающие пакеты при запуске | `true`                     |
| `packager.features.packageSearch`     | Включить поддержку поиска пакетов                                         | `true`                     |
| `packager.features.enabledForHosting` | Требовать установки пакетов при хостинге                                  | `false`                    |
| `packager.afterInstall`               | Команда, выполняемая после установки пакетов                              | —                          |
| `packager.ignoredPaths`               | Пути, исключаемые из определения импортов                                 | `[]`                       |
| `packager.ignoredPackages`            | Пакеты, исключаемые из автоматического обнаружения                        | `[]`                       |
