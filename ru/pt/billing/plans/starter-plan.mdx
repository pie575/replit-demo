<div id="o-que-voc-recebe">
  ## Что вы получаете
</div>

Тариф Starter включает всё необходимое, чтобы начать создавать App в Replit. Создавайте App и публикуйте свой первый проект — всё бесплатно.

<div id="crditos-dirios-para-o-agent">
  ### Ежедневные кредиты для Agent
</div>

Пользователи тарифа Starter получают ежедневные кредиты для использования Agent в рамках месячного лимита. Эти кредиты обновляются каждый день, предоставляя вам новую квоту для работы с Agent.

<div id="crditos-mensais-para-uso-na-nuvem">
  ### Ежемесячные кредиты на облачные сервисы
</div>

Вы также получаете ежемесячные кредиты, которые можно использовать для:

* [Баз данных (Production)](/ru/features/data-and-storage/development-and-production)
* [Объектного хранилища](/ru/pt/features/data-and-storage/object-storage)
* [Публикаций (автомасштабирование, статические)](/ru/pt/learn/projects-and-artifacts/replit-deployments)

Эти кредиты обновляются каждый месяц.

<div id="build-lite">
  ### Build Lite
</div>

Доступ к [Build Lite](/ru/pt/features/agent/agent-modes) — быстрому режиму Build, ориентированному на оперативные правки и точечные изменения с помощью Agent.

<div id="um-app-publicado-gratuito">
  ### Бесплатное развёртывание
</div>

Получите {FreeDeployments} бесплатное развёртывание при использовании Build Lite или Design Canvas. Срок действия этой ссылки автоматически истечёт через 30 дней.

В вашем развёртывании будет значок «Создано с Replit» с уникальной реферальной ссылкой. Если другой пользователь зарегистрируется по этой ссылке через ваш значок, вы получите реферальные кредиты после перехода на платный тариф.

<div id="limitaes">
  ## Ограничения
</div>

Для использования следующих функций требуется перейти на тариф Core:

<div id="build-completo">
  ### Полный Build
</div>

[Полный Build](/ru/pt/features/agent/overview/) позволяет Agent работать самостоятельно с большей мощностью и автономностью. Авторы на тарифе Starter могут использовать только [Build Lite](/ru/pt/features/agent/agent-modes). Для полного Build требуется тариф Core или Pro.

<div id="converter-um-design-em-artefato">
  ### Преобразование дизайна в артефакт
</div>

Для преобразования дизайна из Design Canvas в полноценный артефакт требуется тариф Core. Пользователи тарифа Starter могут создавать и публиковать дизайны, но для преобразования их в артефакт с бэкендом необходимо перейти на другой тариф. Если вы хотите создать App с бэкендом, попробуйте начать с [Build Lite](/ru/pt/features/agent/agent-modes).

<div id="conectores-de-terceiros">
  ### Сторонние коннекторы
</div>

Для использования внешних коннекторов требуется Core. К ним относятся интеграции с такими сервисами, как Google и Stripe, а также с другими сторонними API (подробнее см. [здесь](https://docs.replit.com/features/integrations/overview#connectors)).

<div id="integraes-de-ia-do-replit">
  ### Интеграции Replit с ИИ
</div>

Для [интеграций Replit с ИИ](/ru/pt/features/integrations/replit-ai-integrations) требуется Core.

<div id="remover-o-badge-criado-com-replit">
  ### Удаление значка «Создано с Replit»
</div>

Чтобы убрать значок «Создано с Replit» из опубликованных App, требуется тариф Core. У пользователей тарифа Starter этот значок отображается в развёрнутых App.

<div id="apps-publicados-adicionais">
  ### Дополнительные опубликованные Apps
</div>

Пользователям тарифа Starter доступно {FreeDeployments} бесплатное опубликованное App. Для публикации дополнительных Apps требуется Core или Pro.

<div id="modo-de-planejamento">
  ### Режим планирования
</div>

Для использования режима планирования требуется тариф Core. Режим планирования позволяет прорабатывать идеи, планировать работу и взаимодействовать с Replit Agent, не изменяя код или данные вашего App.

<div id="todos-os-tipos-de-artefato">
  ### Все типы артефактов
</div>

Для создания артефактов, отличных от веб- и мобильных App, требуется Core. Выбирайте из множества типов, включая визуализации данных, презентации, анимированные видео и многое другое. См. [Проекты](/ru/pt/features/projects-and-artifacts/projects).

<div id="upgrade-para-core">
  ## Переход на Core
</div>

Готовы к большему? Перейдите на Core, чтобы получить:

* **Больше места в хранилище и ежемесячных кредитов**, а также возможность оплачивать использование по мере необходимости
* **Неограниченное количество опубликованных App** помимо первой бесплатной
* **Полный Build** для самостоятельной разработки
* **Сторонние коннекторы** для подключения к внешним сервисам
* **Интеграция Replit с ИИ** для использования моделей ИИ без необходимости управлять собственными ключами API
* **Режим планирования** для распределения задач перед началом Build
* **Удаление значка Replit** для более профессионального вида
* И многое другое
