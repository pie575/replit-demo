Для отправки приложения в оба магазина требуется иконка. Replit может создать её напрямую без использования отдельного инструмента для дизайна.

<div id="section">
  ## Требования для каждого магазина
</div>

* **App Store:** 1024×1024, без прозрачности и скруглённых углов (Apple добавит их автоматически).
* **Google Play:** 512×512.

<div id="section-2">
  ## Создание
</div>

Перед отправкой промпта переключитесь в режим **Design**. Тогда Agent будет генерировать изображения.

<AiPrompt>
  {appIconPrompt}
</AiPrompt>

Agent создаёт сразу несколько вариантов, чтобы вы могли сравнить их и выбрать подходящий.
