Lorsque vous publiez une application web sur Replit, un audit d'optimisation pour les moteurs de recherche (SEO) s'exécute automatiquement contre vos URL en ligne et affiche un score SEO dans l'outil de publication. Si le score a de la marge pour progresser, un seul clic transmet les problèmes spécifiques à l'Agent pour que vous puissiez les corriger en quelques secondes.

Pour la plupart des développeurs, le flux de travail complet est : publier votre application, regarder le score et demander à l'Agent d'« optimiser mon SEO ». Cette page explique ce qui se passe en dessous et comment en tirer le meilleur parti.

## Qu'est-ce que le SEO et pourquoi est-ce important

L'optimisation pour les moteurs de recherche (SEO) est la pratique consistant à construire votre site pour que les moteurs de recherche comme Google puissent le trouver, le comprendre et le classer. Un bon SEO signifie que votre application apparaît lorsque les gens recherchent ce que vous offrez — sans payer pour des publicités.

Quelques éléments clés déterminent la plupart de vos résultats SEO : des titres et descriptions de pages clairs, du HTML sémantique, des temps de chargement rapides, des mises en page adaptées aux mobiles, du texte alt descriptif sur les images et une structure de site explorable. Les moteurs de recherche récompensent les sites faciles à lire pour les humains et les machines.

Si vous lancez une page d'accueil, un site marketing, un blog, un annuaire ou tout autre site où la découvrabilité est importante, le SEO est l'un des investissements les plus rentables que vous puissiez faire tôt.

## Comment Replit améliore votre SEO par défaut

Replit gère beaucoup des fondations SEO pour vous afin que vous puissiez vous concentrer sur votre contenu et votre produit :

* **Hébergement rapide et distribué mondialement** : les déploiements Replit servent votre application depuis une infrastructure optimisée pour la vitesse, et vous pouvez choisir où votre application s'exécute avec la [Géographie du projet](/fr/features/publishing/project-geography).
* **HTTPS par défaut** : chaque application publiée obtient un certificat TLS géré par Replit, ce qui est un signal de classement de base pour les moteurs de recherche.
* **Domaines personnalisés** : connectez votre propre domaine pour renforcer la confiance et l'autorité de marque. Voir [Domaines personnalisés](/fr/features/publishing/custom-domains).
* **Déploiements statiques pour les sites de contenu** : pour les pages marketing, les blogs et la documentation, les [Déploiements statiques](/fr/features/publishing/deployment-types#static) livrent du HTML pré-rendu que les moteurs de recherche explorent facilement.
* **L'Agent écrit du code SEO-aware** : quand l'Agent construit vos pages, il produit du HTML sémantique, un balisage accessible et des méta tags par défaut — les mêmes choses que les outils SEO vérifient.
* **Le score SEO** : un audit automatique post-publication pour que vous sachiez toujours où vous en êtes, associé à un handoff en un clic vers l'Agent pour corriger ce qu'il trouve.

## Le score SEO

Après chaque publication réussie, Replit exécute un audit Lighthouse contre les URL de votre déploiement et stocke les résultats. L'outil de publication affiche ensuite un score SEO global pour votre application.

### Où le trouver

Ouvrez l'outil de **Publication** sur une application publiée. Le score SEO apparaît dans la vue d'ensemble du déploiement aux côtés de vos autres détails de build. Survolez le score pour voir les éléments d'action spécifiques signalés par Lighthouse pour chaque page.

<Note>
  Si vous ne voyez pas de score SEO, votre application est probablement privée ou n'a pas été publiée récemment. Le score n'apparaît que pour les applications web publiques qui ont été publiées.
</Note>

### Comment lire votre score

Replit affiche l'un des trois scores basés sur l'audit Lighthouse :

| Score       | Ce que cela signifie                                                                                 |
| :---------- | :--------------------------------------------------------------------------------------------------- |
| Saine       | Votre application suit les bonnes pratiques SEO. Gardez un œil dessus après des changements majeurs. |
| À améliorer | Plusieurs problèmes limitent la capacité des moteurs de recherche à comprendre votre application.    |
| Faible      | Des bases SEO importantes sont manquantes. Les corriger ne prend généralement que quelques minutes.  |

Si votre application comporte plusieurs pages, le badge affiche le score le **plus bas** parmi toutes les URL explorées par Replit, de sorte que la pire page apparaît en premier plutôt qu'être moyennée.

### Quand le score est calculé

L'audit s'exécute automatiquement après chaque publication réussie. Le score apparaît généralement dans une ou deux minutes après la mise en ligne d'un déploiement, et l'outil de publication actualise le badge dès que les résultats arrivent.

### Types de déploiement pris en charge

Le score SEO est calculé pour les déploiements web publics où les moteurs de recherche peuvent explorer les URL :

* [Déploiements Autoscale](/fr/features/publishing/deployment-types#autoscale)
* [Déploiements VM réservée](/fr/features/publishing/deployment-types#reserved-vm)
* [Déploiements statiques](/fr/features/publishing/deployment-types#static)

Les déploiements planifiés et privés ne produiront pas de score SEO car ils ne servent pas de trafic web public.

## Optimiser le SEO avec l'Agent

Un bouton **Optimiser le SEO avec l'Agent** apparaît à côté de votre score. Le sélectionner ouvre [l'Agent SEO](/fr/features/publishing/seo-agent) dans le panneau Growth, où vous pouvez lancer un audit technique SEO, examiner les problèmes qu'il trouve et appliquer des corrections en un clic.

<Tip>
  Vous pouvez aussi ignorer le bouton entièrement. Ouvrez l'Agent et dites **« optimise mon SEO »** — l'Agent récupérera vos derniers résultats et commencera à les traiter.
</Tip>

Après que l'Agent a terminé ses modifications, republiez votre application. Le score SEO est recalculé par rapport au nouveau build et le badge se met à jour automatiquement.

Corrections courantes que l'Agent appliquera :

* Ajouter ou réécrire les balises `<title>` manquantes ou génériques pour que chaque page ait un titre unique et descriptif
* Ajouter une méta description à chaque page
* Ajouter du texte `alt` descriptif aux images
* Définir l'attribut `lang` sur l'élément `<html>`
* S'assurer que les liens ont un texte identifiable (pas de « cliquez ici » ni d'ancres vides)
* Ajouter un `robots.txt` et un `sitemap.xml`
* Ajouter une balise méta viewport pour le rendu mobile
* Améliorer le contraste des couleurs sur le texte qui échoue aux vérifications d'accessibilité
* Ajouter les méta tags Open Graph et Twitter Card pour que les liens vers votre application s'affichent bien sur les plateformes sociales

## Bonnes pratiques pour un site optimisé pour le SEO sur Replit

Que vous demandiez à l'Agent de les gérer ou que vous les écriviez vous-même, voici les éléments les plus importants à bien faire sur une application construite avec Replit :

* **Donnez à chaque page un titre unique et une méta description.** Visez des titres de moins de 60 caractères et des descriptions d'environ 150 à 160 caractères.
* **Utilisez du HTML sémantique.** Encadrez votre mise en page avec `<main>`, `<header>`, `<nav>` et `<footer>`. Utilisez `<h1>` une seule fois par page et respectez l'ordre des niveaux de titres.
* **Ajoutez du texte alt à chaque image.** Décrivez ce que l'image montre, pas seulement ce qu'elle est.
* **Générez un `sitemap.xml` et un `robots.txt`.** Demandez à l'Agent de créer les deux pour que les moteurs de recherche sachent quoi explorer.
* **Ajoutez les balises Open Graph et Twitter Card.** Contrôlez l'apparence de votre application lorsqu'elle est partagée sur les réseaux sociaux.
* **Utilisez un domaine personnalisé.** Un domaine à votre image inspire confiance aux visiteurs et aux moteurs de recherche. Voir [Domaines personnalisés](/fr/features/publishing/custom-domains).
* **Choisissez le bon type de déploiement.** Pour les sites riches en contenu, les [Déploiements statiques](/fr/features/publishing/deployment-types#static) livrent du HTML pré-rendu que les moteurs de recherche analysent instantanément.
* **Ajoutez des données structurées.** Le balisage JSON-LD aide les moteurs de recherche à afficher des résultats enrichis pour les produits, articles, FAQ et événements.
* **Gardez votre application rapide.** Optimisez les images, évitez les scripts bloquant le rendu et appuyez-vous sur l'hébergement Replit pour garder des temps de réponse faibles.

Une façon simple d'appliquer la plupart de ces éléments en une seule fois :

</AiPrompt>
