使用 Replit Auth，您可以为应用打造个性化的用户体验。借助用户账户，您可以实现各种让应用更具吸引力和价值的功能，例如保存用户偏好、创建自定义仪表板、构建社交功能、控制高级内容的访问权限，以及跟踪用户活动。

Replit Auth 使用 Replit 的登录系统。登录应用的用户可以创建或使用现有的 **Replit 账户**。登录页面采用 Replit 品牌，登录流程与整个 replit.com 使用的流程一致。

<Note>
  **Replit Auth 与 Clerk Auth** — Replit 提供两种认证选项。**Replit Auth** (本页面) 使用 Replit 的登录系统，应用用户通过 Replit 账户登录，并会看到采用 Replit 品牌的登录页面。**[Clerk Auth](/zh/ja/features/auth-and-identity/clerk-auth)**为您的应用提供由 Clerk 支持的独立专属认证租户，支持完全自定义品牌形象，并提供不依赖 Replit 的用户账户。如果您希望登录体验采用自己的品牌，或需要不依赖 Replit 的用户账户，请选择 Clerk Auth。

  如果您的应用已在使用 Replit Auth，请参阅[从 Replit Auth 迁移到 Clerk](/zh/ja/features/auth-and-identity/migrate-auth-to-clerk)，了解自动迁移流程以及用于确保可继续访问现有应用数据的测试步骤。
</Note>

无需花费数月从头构建认证功能，只需向 Agent 发送一次提示词，Replit Auth 即可提供企业级功能。它基于 Fortune 500 企业使用的同一基础设施 (Firebase、Google Cloud Identity Platform、reCAPTCHA、Stytch、Clearout) ，内置专业级安全性、欺诈防范功能和全球规模。

<div id="replit-auth">
  ## 为什么使用 Replit Auth
</div>

认证是一个复杂难题，甚至有整家公司专门致力于解决它。你的应用的核心目的很可能不是认证，而是你正在构建的独特创意或解决方案。

Replit Auth 提供：

* **零配置** — 只需向 Agent 发送一次提示词，即可添加认证
* **Replit 账户集成** — 用户可以使用现有的 Replit 账户登录，无需另行创建账户
* **内置安全防护** — 使用 Replit 基础设施，防范常见攻击
* **用户管理** — 可通过 Auth 面板轻松管理用户
* **数据库集成** — 自动在数据库中创建用户记录
* **可自定义的登录页面** — 个性化应用的登录体验 (带有 Replit 品牌标识)
* **密码重置** — Replit 会代你发送密码重置邮件，无需配置自己的邮件服务提供商
* **推荐计划** — 通过 Replit Auth 注册的用户会被加入 Replit 推荐计划的待处理名单
* **开发和已发布的应用** — Replit Auth 可在开发环境 (replit.dev) 和已发布的应用 (replit.app、自定义域名) 中无缝运行

<div id="section">
  ## 企业级基础设施
</div>

Replit Auth 不只是简单的用户管理功能，而是一套构建在企业级基础设施之上的全托管认证解决方案。这一强大组合可为你的应用提供 Fortune 500 企业同等的认证能力：

* **Firebase &amp; Google Cloud Identity Platform** - 基于 Google 久经验证的认证基础设施，提供企业级 SLA
* **高级安全扫描** - 通过集成 reCAPTCHA，自动防护机器人和恶意攻击者
* **欺诈防范** - 通过 Clearout 进行电子邮件验证和校验，防止虚假账户
* **多因素认证** - 基于 Stytch 企业认证平台的安全登录选项
* **全球规模** - 支持自动扩缩容，具备高可靠性，可处理数百万用户

依托这一企业级基础设施，你可以专注于构建应用的独特功能，同时确信认证功能运行在保护数十亿美元企业的同一基础设施之上。无需花费数月集成多个服务，只需向 Agent 输入一次提示词，即可使用所有功能。

<div id="replit-auth-2">
  ## 开始使用 Replit Auth
</div>

只能通过 Agent 实现 Replit Auth。只需在提示词中提出使用 Replit Auth 的请求：

```
帮我创建一个[你的 App 创意]，并集成 Replit Auth。
```

Agent 会设置认证所需的全部代码和配置。由于 Agent 会处理所有复杂环节，因此不支持手动实现。

您可以根据应用的品牌形象自定义登录页面：

1. 前往 Project Editor 的 Auth 面板
2. 点击 **Configure**
3. 自定义以下内容：
   * 应用名称
   * 应用图标
   * 登录方式 (Google、GitHub、X、Apple、电子邮件)

所做更改会立即显示在应用的登录页面上。

<div id="section-5">
  ## 关于安全性
</div>

Replit Auth 利用 Replit 的基础设施，为常见安全威胁提供内置防护。不过，您仍应遵循以下最佳实践：

* 执行敏感操作前，务必在服务器端验证用户的认证
* 请勿在代码中存储密码等敏感信息
* 请使用环境变量存储 API 密钥和其他机密信息
* 为用户数据实施适当的访问控制

有关安全性的更多信息，请参阅：

* [Replit 的内置安全功能](/zh/ja/features/security/overview)
* [氛围编程安全检查清单](/zh/ja/learn/security-checklist)

<div id="section-6">
  ## 推荐计划
</div>

为鼓励更多人了解 Replit，通过 Replit Auth 注册的用户会自动加入待处理的 Replit Referrals。之后如果他们升级到 Replit Core，您可根据当前推荐计划的条款获得推荐奖励。

<div id="section-8">
  ### 常见问题
</div>

1. **登录后系统无法识别用户**
   * 如遇到此问题，请让 [Replit Agent](/zh/ja/features/agent/overview) 协助调试认证实现。

2. **自定义图标未显示**
   * 请确认图标 URL 可访问，且格式受支持 (PNG 或 JPG) 。

3. **新关联的自定义域名无法正常使用**
   * 请重新发布，以更新域名列表 (REPLIT&#95;DOMAINS 环境变量) 。
