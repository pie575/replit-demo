<div id="section">
  ## Возможности
</div>

Используйте веб-поиск Agent, чтобы создавать приложения на основе актуальной информации. Это избавляет от необходимости вручную искать и собирать данные. Создаёте ли вы панель с финансовыми данными или сайт с обзором недавних запусков стартапов — веб-поиск гарантирует, что ваше приложение отражает реальное положение дел.

Действия веб-поиска, доступные Agent:

* **Поиск**: находит актуальную информацию, свежую документацию и данные из интернета в реальном времени
* **Получение содержимого**: извлекает подробную информацию с конкретных сайтов или URL-адресов
* **Цитирование источников**: показывает, где именно Agent нашёл информацию, чтобы вы могли проверить источники и сослаться на них

<div id="section-2">
  ## Использование
</div>

Веб-поиск встроен в Agent — включать его в настройках не нужно. Опишите, что хотите создать, и Agent сам определит, когда нужно поискать в интернете актуальную информацию. Чтобы явно указать Agent выполнить поиск, добавьте в запрос ключевые слова, например «поиск», «исследование» или «использовать веб-поиск».

<div id="section-3">
  ### Как веб-поиск улучшает приложения
</div>

Веб-поиск позволяет приложениям перейти от использования шаблонных данных к включению реальной и точной информации:

| Преимущество                   | Описание                                                                                    |
| ------------------------------ | ------------------------------------------------------------------------------------------- |
| Новейшие технологии            | Приложение использует актуальную информацию и пакеты, которых нет в обучающих данных        |
| Выбор оптимальных инструментов | Agent изучает варианты и выбирает наиболее подходящие пакеты                                |
| Актуальные лучшие практики     | Вы получаете доступ к современным подходам к разработке и практикам безопасности            |
| Преодоление ограничений        | Позволяет преодолеть ограниченность знаний и использовать пакеты, выпущенные после обучения |
| Точные данные                  | Приложение отображает актуальную информацию вместо устаревших примеров                      |
| Профессиональный результат     | Приложения, использующие данные реальных компаний, вызывают больше доверия                  |
| Экономия времени               | Вам не нужно вручную изучать пакеты и собирать данные                                       |

<div id="section-4">
  ### Цитирование источников
</div>

Когда Agent использует веб-поиск, он приводит **цитирование источников**, точно указывающее, откуда получена информация. Используйте их, чтобы:

* **Проверять информацию**: оценивать достоверность и точность источников
* **Узнавать больше**: переходить к первоисточникам, чтобы получить больше контекста
* **Указывать источники**: добавлять в приложение корректные ссылки на авторство
* **Отслеживать ход исследования**: понимать, какая информация повлияла на работу Agent

<div id="section-5">
  ### Получение контента
</div>

Agent может извлекать подробный контент с определённых сайтов, чтобы собрать исчерпывающую информацию для проекта. Благодаря этому Agent может:

* читать веб-страницы целиком и выделять нужные детали
* обрабатывать документацию и справочные материалы
* собирать конкретные данные из авторитетных источников
* интегрировать структурированную информацию в приложение
