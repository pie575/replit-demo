<div id="apps">
  ### Приватные Apps для бесплатных аккаунтов
</div>

Теперь пользователи бесплатных аккаунтов могут создавать приватные Apps. Ограничения бесплатного плана на количество Apps по-прежнему действуют.

<div id="made-with-replit">
  ### Бейдж «Made with Replit»
</div>

<Frame>
  <img src="https://replit.com/badge?caption=Made%20with%20Replit" alt="Бейдж Made with Replit" noZoom />

В бесплатных опубликованных приложениях теперь отображается бейдж «Made with Replit». Его можно удалить, перейдя на тариф Replit Core. Нажмите на бейдж, чтобы узнать больше о Replit.

</div>

<div id="ai">
  ### Новые ИИ-модели в интеграциях
</div>

Интеграции с ИИ теперь поддерживают недавно выпущенные модели:

| Модель                       | Описание                                                                                                                                                                     |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `gpt-5.2`                    | Самая мощная модель OpenAI для профессиональной интеллектуальной работы. Первая модель, преодолевшая отметку 90% в ARC-AGI-1, с контекстным окном 400K.                      |
| `claude-opus-4.5`            | Флагманская модель Anthropic, оптимизированная для программирования, агентных задач и работы с компьютером. Достигла 80,9% в SWE-bench Verified.                             |
| `gemini-3-flash-preview`     | Быстрая модель Google для агентных рабочих процессов с контекстом в 1M токенов. Обеспечивает возможности рассуждения, близкие к уровню Pro, при низкой задержке и стоимости. |
| `gemini-3-pro-preview`       | Продвинутая мультимодальная модель Google с передовыми возможностями рассуждения и знаниями о реальном мире.                                                                 |
| `gemini-3-pro-image-preview` | Модель Google Nano Banana Pro для высококачественной генерации и редактирования изображений с точной отрисовкой текста.                                                      |
