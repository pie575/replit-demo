<div id="section">
  ## 计费类别
</div>

Replit 将应用存储的计费划分为以下类别：

* **存储**：每月使用的数据容量。所有已存储的对象最低按 7 天计费。
* **数据传输**：当月上传和下载的数据总量。
* **基本操作**：与更新存储桶和对象相关的操作。详情请参阅 <a href="https://cloud.google.com/storage/pricing" target="_blank">Google Cloud Storage 定价</a>中的 Class A 操作。
* **高级操作**：其他云对象存储操作，包括获取对象和存储桶的配置及元数据。详情请参阅 <a href="https://cloud.google.com/storage/pricing" target="_blank">Google Cloud Storage 定价</a>中的 Class B 操作。
