Les modes Agent vous permettent de doser l&#39;équilibre entre allocation incluse, crédits et capacité avant d&#39;envoyer une requête. Ouvrez le menu déroulant des paramètres d&#39;Agent dans la zone de prompt, puis sélectionnez le mode adapté à la tâche.

<Note>
  Le mode Economy n&#39;est plus disponible. Le mode Power le remplace, au même prix.
</Note>

<div id="choose-a-mode">
  ## Choisir un mode
</div>

* **Free Mode :** explorez des idées, posez des questions, lancez-vous dans la création et faites avancer votre travail au quotidien. Free Mode s&#39;appuie sur un routage intelligent pour sélectionner le modèle. {FreeModePlanAvailability}
* **Power Mode :** un bon équilibre entre rapidité et puissance pour la plupart des tâches. Utilisez-le lorsque votre allocation Free Mode ne suffit plus ou que vous souhaitez un mode par défaut plus performant sur un project existant.
* **Max Mode :** l&#39;option la plus puissante pour les travaux complexes et ambitieux, les bases de code volumineuses et les problèmes ardus.

Power Mode et Max Mode consomment des crédits mensuels. Replit vous prévient avant qu&#39;une requête ne bascule de Free Mode vers un mode entraînant des coûts d&#39;utilisation. Consultez votre allocation Free Mode restante dans **Settings** → **Usage**. Pour des conseils pratiques, voir [Tirer le meilleur parti de Free Mode](/fr/chat/free-mode).

Les Routines s&#39;exécutent en Power Mode ou Max Mode et nécessitent un budget par exécution. Elles ne peuvent pas s&#39;exécuter en Free Mode. En savoir plus sur les [Routines](/fr/chat/routines).
