Web 应用是 Replit 的默认输出类型。只需向 Agent 描述你的想法，除非你指定了其他工件类型，否则它都会为你创建一个全栈 Web 应用。

<div id="section">
  ## 开始使用
</div>

创建 Web 应用有两种方式：

* **输入提示词**：在 Replit 主页上描述你想创建的内容，Agent 会自动生成 Web 应用。
* **从下拉菜单选择**：在主页上打开应用类型下拉菜单，选择 **Web 应用**，然后描述你的想法。

<div id="section-2">
  ## 主要功能
</div>

* **默认全栈**：每个 Web 应用都包含前端和后端。Agent 会为应用搭建所需的 API 路由、数据库和服务器端逻辑。
* **响应式设计**：应用会自动适配各种屏幕尺寸。
* **一键发布**：只需点击一次即可发布应用，托管、SSL 和基础设施均由 Replit 处理。
* **共享基础设施**：如果项目中包含移动应用、数据看板等多个工件，它们将共用同一套后端、数据库和服务。

<div id="section-3">
  ## 使用场景
</div>

* **SaaS 产品**：构建面向客户的工具、仪表板和平台。
* **内部工具**：为团队打造管理后台、CRM 和工作流应用。
* **着陆页**：上线包含表单、动画和动态内容的营销网站。
* **市场与目录**：搭建信息展示网站、招聘板和社区平台。
