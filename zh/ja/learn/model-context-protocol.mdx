Claude 和 GPT 等 AI 模型功能强大，但其能力受限于训练数据。模型上下文协议 (MCP) 提供了一种标准化方式，可将其连接到外部工具、数据源和现实世界的功能。

<div id="aimcp">
  ## 为什么 AI 模型需要 MCP
</div>

如果无法访问外部工具和数据，AI 模型便无法：

* 获取最新信息
* 与外部系统交互
* 在现实世界中执行操作
* 处理私有数据

MCP 通过为 AI 提供一种通用方式来连接工具和数据，从而解决了这一问题，就像 USB-C 将设备连接标准化一样。

<Frame>
  <img src="/assets/mirror/mcp-a04e01a01743.avif" alt="展示 AI 模型连接外部工具和数据源的 MCP 图示" width="1920" height="1055" data-path="images/tutorials/mcp.avif" />
</Frame>

借助 MCP，AI 模型可以：

* 访问专业工具和 API
* 从私有数据源读取数据
* 在现实世界中执行操作
* 无缝连接到其他系统

<div id="mcp">
  ## MCP 的工作原理
</div>

MCP 架构包含三个主要组件：

1. **客户端** — 需要访问外部工具的应用，例如 Claude 和 AI 应用程序。
2. **通信层** — 用于标准化请求和响应格式的协议本身。
3. **服务器端** — 提供工具、数据源和专业功能访问权限的程序。

<AccordionGroup>
  <Accordion title="什么是 MCP 客户端？">
    MCP 客户端包括 Claude、Replit Agent，以及连接大语言模型的命令行界面等。它们是用于连接外部工具和数据源的“设备”。

    MCP 客户端示例：

    * 浏览器中的 Claude
    * Replit Agent
    * 面向 AI 的命令行界面
    * 使用 AI SDK 构建的自定义应用程序
  </Accordion>

  <Accordion title="什么是 MCP 服务器？">
    MCP 服务器为 AI 模型提供工具和功能。可以将其理解为：为 AI 配备一套解决问题所需的专业工具。

    MCP 服务器可实现：

    * 访问特定数据源以回答问题
    * 将 AI 连接到 API，使其能够在线执行操作
    * 读取和写入文件
    * 执行计算或运行代码
    * 从 Notion、Linear、Stripe 等服务获取内容
  </Accordion>
</AccordionGroup>

<div id="mcp-2">
  ## MCP 能实现什么
</div>

MCP 定义了多种可增强 AI 应用的基本构件：

* **资源** — 在 AI 模型间共享数据和内容
* **工具** — 让 AI 模型能够通过服务执行操作
* **提示词** — 用于实现一致 AI 交互的可复用模板
* **采样** — 让服务能够向 AI 模型请求信息
* **传输** — 高效连接客户端和服务器

<div id="vs-mcp">
  ## 技能与 MCP 服务器
</div>

技能和 MCP 服务器是扩展 AI 智能体的两种主要方式，各自适用于不同的用途。

|           | 技能                       | MCP 服务器                     |
| --------- | ------------------------ | --------------------------- |
| **最适用场景** | 工作流、规范和参考资料              | 连接外部服务、执行操作                 |
| **加载方式**  | 轻量 — 调用前仅加载名称和描述         | 较重 — 一开始就加载所有工具说明           |
| **定义**    | Agent*应如何*工作             | Agent*能够访问什么*               |
| **示例**    | “股票分析师”技能 — 使用特定框架开展投资研究 | “Stripe”MCP 服务器 — 读取支付和订阅数据 |

有关技能的思维方式，请参阅 [Agent 技能](/zh/ja/learn/agent-skills)。

<div id="section">
  ## 实际应用示例
</div>

MCP 可支持广泛的 AI 应用：

* **客户服务系统** — 访问公司数据库，回答特定问题
* **研究助手** — 从多个来源检索并总结内容
* **生产力工具** — 与文件和应用程序交互
* **内容创作工具** — 访问媒体库和发布平台

<div id="section-2">
  ## 优势
</div>

MCP 提供三项主要优势：

* 可立即连接 AI 的现成集成
* 无需重写连接，即可切换 AI 提供商
* 保护敏感数据的安全功能

<Note>
  MCP 是一项新兴标准，正获得整个 AI 生态系统越来越广泛的支持。新的工具和集成会定期加入。
</Note>
