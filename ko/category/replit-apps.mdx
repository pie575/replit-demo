<div id="what-is-a-replit-app">
  ## Replit App이란?
</div>

Replit App은 코드, 데이터, asset을 담고 있는 클라우드 호스팅 프로젝트입니다.
안전하게 격리된 환경에서 앱을 생성하고 실행하고 게시할 수 있습니다.

Replit Apps는 Project Editor의 다음 도구들과 통합되어 매끄러운 개발 경험을
제공합니다.

* **AI 기반 도구**: Agent를 사용해 코드를 작성하고, 디버깅하고, 설명을 확인하세요.
* **협업**: 같은 앱에서 다른 사람들과 실시간으로 작업하세요.
* **Publishing**: 클릭 한 번으로 앱을 클라우드에 게시하세요.

<div id="key-features">
  ## 주요 기능
</div>

Replit Apps는 다음과 같은 기능을 제공합니다:

* **설정 불필요:** 설치나 설정 없이 Replit.com에서 바로 앱을 만들거나 코드를 작성할 수 있습니다.
* **자동 저장:** 변경 사항이 클라우드에 계속 저장되므로 어떤 웹 브라우저에서든 이어서 코딩할 수 있습니다
* **버전 관리:** Replit의 version control 시스템으로 별도 설정 없이 변경 사항을 추적하고, 파일 히스토리를 살펴보고, 파일을 동기화할 수 있습니다
* **공개/비공개 공개 범위 제어:** Privacy Settings로 누가 내 앱을 보고, 실행하고, Remix할 수 있는지 제어할 수 있습니다
* **Publishing:** 복잡한 설정 변경 없이 코드를 클라우드에 게시할 수 있습니다
* **맞춤 앱 URL:** 앱마다 고유한 URL을 받거나 custom domain을 연결해 전문적인 인상을 줄 수 있습니다

<Info>
  프로젝트 파일 시스템에 업로드한 파일은 개발 중에만 사용할 수 있으며,
  published app이나 다른 builders는 접근할 수 없습니다. builder가 업로드한 파일을 처리하고 serve하려면 [Object
  Storage](/ko/features/data-and-storage/object-storage)를, 앱과 사용자의 데이터를 저장하고 가져오려면 [Replit
  Database](/ko/features/data-and-storage/sql-database)를 사용하세요.
</Info>

Replit App 제작을 간소화하는 Project Editor 도구에 대해 자세히 알아보려면 [Project Editor 개요](/ko/learn/projects-and-artifacts/project-editor/)를 참고하세요.

<div id="how-it-works">
  ## 작동 방식
</div>

Replit App을 생성하면 Replit이 클라우드에 여러분의 프로젝트를 위한 비공개 공간을 마련합니다.
앱에 기능을 추가하고 수정하는 동안 Replit이 변경 사항을 자동으로 저장하므로,
어떤 웹 브라우저에서든 편집을 이어갈 수 있습니다.

Replit은 필요한 모든 구성 요소가 갖춰진 사전 구성된 환경을 제공합니다.
덕분에 서버 설정, 데이터베이스 구성, 환경 관리에 신경 쓸 필요 없이
바로 앱 제작을 시작할 수 있습니다.

Replit은 각 Replit App에 고유한 웹 주소를 자동으로 할당하여, 작업하는 동안
앱을 미리 볼 수 있게 해줍니다. 만든 결과물을 공유할 준비가 되면
클릭 몇 번으로 게시하여 24시간 내내 이용할 수 있도록 만들 수 있습니다.

<div id="storage-overview">
  ## 스토리지 개요
</div>

Replit은 애플리케이션의 데이터 요구 사항을 충족할 수 있도록 네 가지 주요 스토리지 유형을 제공합니다. 스토리지 유형마다 적합한 사용 사례가 다르며, plan에 따라 limit이 다르게 적용됩니다.

<Info>
  스토리지 limit에는 설치된 packages와 dependencies를 포함해 앱이 저장하는 모든
  데이터가 포함됩니다.
</Info>

| 스토리지 유형                                                         | 설명            | 사용 사례                       | 지속성                        | Plan별 Limit                                                                                                                                          |
| --------------------------------------------------------------- | ------------- | --------------------------- | -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **파일 스토리지**                                                     | 프로젝트 내 파일  | 애플리케이션 코드, 정적 assets, 구성 파일 | Publishing 시 유지, 재시작 시 초기화 | Starter: {StarterWorkspaceStorage}<br />Core: {CoreWorkspaceStorage}<br />Pro: {TeamsWorkspaceStorage}<br />Enterprise: {EnterpriseWorkspaceStorage} |
| **[데이터베이스](/ko/features/data-and-storage/sql-database/)**        | 구조화된 데이터 저장   | 사용자 프로필, 게임 점수, 제품 카탈로그     | session 간 완전히 유지           | development 데이터베이스당 20GB<br />production 데이터베이스는 컴퓨팅 시간과 스토리지 기준으로 과금                                                                            |
| **[App Storage](/ko/features/data-and-storage/object-storage/)**   | 비정형 데이터 및 미디어 | 이미지, 동영상, PDF, 문서           | session 간 완전히 유지           | 사용량 기반 모델<br />스토리지와 대역폭 기준으로 과금                                                                                                                     |
| **[Secrets](/ko/core-concepts/project-editor/app-setup/secrets/)** | 암호화된 민감 데이터   | API keys, 자격 증명, 연결 문자열     | 완전히 유지되며 암호화됨              | 별도 limit 없음<br />모든 plan에 포함                                                                                                                         |
