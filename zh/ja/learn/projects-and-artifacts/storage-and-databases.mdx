借助 Replit 灵活的存储方案，你可以快速为应用添加最合适的数据存储。有以下需求的应用都可以使用 Replit 的数据库和对象存储，而且 Agent 能自动配置并集成这两种方案：

* 需要保存玩家进度、最高分等信息的游戏
* 需要管理媒体文件的内容平台

<div id="replit">
  ## Replit 的存储与数据库选项
</div>

Replit 提供以下数据存储方式：

* **数据库**：用于存储用户资料、游戏分数、商品目录等结构化数据。
  可根据属性以及数据点之间的关系来存取数据。

* **App Storage**：用于存储图片、视频、文档等非结构化数据。
  可存取大文件或二进制数据。

<div id="app-storage">
  ### App Storage 与数据库的对比
</div>

|             | 数据库                     | App Storage           |
| ----------- | :---------------------- | :-------------------- |
| **适合的数据类型** | 具有关联关系的结构化数据            | 大文件 (图片、视频、文档)        |
| **数据模型**    | 表、行、列                   | 存储桶、文件                |
| **查询语言**    | SQL                     | REST API              |
| **客户端**     | 兼容 PostgreSQL 的客户端与 ORM | Replit SDK 与 GCS 客户端库 |
| **计费模式**    | 按计算时长和存储容量计量收费          | 按带宽和存储容量计量收费          |

<div id="section">
  ### 项目编辑器工具
</div>

进一步了解以下用于配置和管理应用数据存储的 Replit 工具：

<CardGroup>
  <Card title="数据库" href="/zh/ja/features/data-and-storage/sql-database" icon="database">
    最适合存储结构化数据并表达数据之间的关联。
    底层为完全托管的 PostgreSQL 数据库，可随应用一同扩展。
  </Card>

  <Card title="App Storage" href="/zh/ja/features/data-and-storage/object-storage" icon="bucket">
    最适合图片、视频、文档等非结构化数据和大容量文件。
    底层由 Google Cloud Storage (GCS) 提供支持，具备高可用性和可扩展性。Agent 可自动完成 App Storage 的配置，并提供高级身份验证和访问控制。
  </Card>
</CardGroup>
