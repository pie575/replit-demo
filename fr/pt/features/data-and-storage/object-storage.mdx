App Storage est le stockage d&#39;objets intégré de Replit qui permet à votre app d&#39;héberger et d&#39;enregistrer facilement des fichiers téléversés tels que des images, des vidéos et des documents.
Les buckets sont des conteneurs destinés à stocker des objets, comme des fichiers. Ils intègrent des politiques d&#39;accès permettant de limiter les actions que les utilisateurs ou les applications peuvent effectuer sur leur contenu.

<Info>
  Nous avons renommé <strong>Object Storage</strong> en <strong>App Storage</strong>. Les fonctionnalités restent inchangées et vos buckets, permissions et accès programmatiques existants doivent continuer à fonctionner.
</Info>

Avec App Storage, vous pouvez créer des apps telles que :

* **Plateformes de partage de photos** : permettez aux créateurs de téléverser, de stocker et d&#39;afficher des images
* **Services de diffusion vidéo** : gérez les téléversements de vidéos et diffusez du contenu aux spectateurs
* **Systèmes de gestion documentaire** : stockez et organisez les fichiers des créateurs avec un accès sécurisé
* **Sites de portfolio** : présentez vos travaux avec des fichiers multimédias qui se chargent de manière fiable
* **Services de sauvegarde de fichiers** : offrez aux créateurs un stockage cloud pour leurs fichiers importants

</Frame>

<Note>
  Demandez à l&#39;**Agent** d&#39;ajouter App Storage à votre app en précisant les types de fichiers que celle-ci doit gérer. L&#39;Agent configurera l&#39;intégration, créera les buckets nécessaires et mettra à jour votre app pour téléverser, stocker et récupérer des fichiers avec des fonctionnalités avancées comme l&#39;authentification et les contrôles d&#39;accès.
</Note>

L&#39;outil App Storage vous permet de partager vos données en toute fluidité entre
vos environnements de développement et de production ou avec d&#39;autres Replit Apps.

<div id="recursos">
  ## Fonctionnalités
</div>

<Info>
  App Storage repose sur Google Cloud Storage (GCS).
  Vous bénéficiez donc d&#39;une disponibilité,
  d&#39;une continuité de service et d&#39;une sécurité à la pointe du secteur.
</Info>

App Storage offre les fonctionnalités suivantes pour vos Replit Apps :

* **Stockage cloud persistant** : stockez des fichiers qui restent accessibles à votre app publiée et à ses utilisateurs
* **Gestion de fichiers évolutive** : répondez à des besoins de données croissants sans vous soucier des limites de stockage
* **Partage de données entre apps** : partagez des buckets entre plusieurs Replit Apps pour des architectures distribuées
* **Accès programmatique** : téléversez, téléchargez et gérez vos fichiers à l&#39;aide d&#39;API intuitives
* **Intégration avancée avec Agent** : laissez Agent configurer App Storage avec des paramètres avancés, inspecter les configurations existantes et générer l&#39;intégralité du code back-end et front-end, avec authentification et contrôles d&#39;accès

Voici quelques façons d&#39;utiliser App Storage dans vos Replit Apps :

* Stocker les photos de profil des créateurs et les médias téléversés
* Diffuser des images de produits pour des sites d&#39;e-commerce
* Gérer les documents téléversés lors de l&#39;envoi de formulaires
* Créer des fonctionnalités de partage de fichiers et de collaboration
* Créer des systèmes de gestion de contenu avec des bibliothèques de médias

<Tip>
  **Intégration avancée avec Agent** : vous pouvez demander à [Replit Agent](/fr/pt/features/agent/overview) d&#39;ajouter automatiquement App Storage à vos apps ! Agent peut désormais configurer le stockage d&#39;objets, inspecter les configurations et générer l&#39;intégralité du code back-end et front-end, avec des fonctionnalités avancées comme l&#39;authentification et les contrôles d&#39;accès. Il suffit de mentionner « App Storage » ou « stockage de fichiers » dans votre prompt.

  <AiPrompt>Add App Storage to my app to store files</AiPrompt>
  <AiPrompt>Create a photo gallery app with App Storage for images</AiPrompt>
  <AiPrompt>Set up App Storage with authentication for user file uploads</AiPrompt>

  Pour en savoir plus, consultez les [intégrations d&#39;Agent](/fr/pt/features/integrations/overview#data-storage--management) et découvrez tous les prompts App Storage disponibles.
</Tip>

<div id="uso">
  ## Utilisation
</div>

<Note>
  Votre Replit App doit s&#39;authentifier auprès de Google Cloud Storage pour accéder à un bucket et à ses objets.
  Utilisez les bibliothèques clientes officielles App Storage de Replit pour vous authentifier automatiquement.
</Note>

Vous pouvez accéder à l&#39;outil App Storage directement depuis votre Project Editor.

<Accordion title="Comment accéder à l'outil App Storage">
  Dans le **Tool dock** à gauche :

  1. Sélectionnez <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Icône de tous les outils" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools** pour afficher la liste des outils du Project Editor.
  2. Sélectionnez <img class="icon-svg" src="/assets/mirror/object-storage-monoochrome-icon-aaba8f517280.svg" alt="Icône App Storage" width="16" height="16" data-path="images/icons/object-storage-monoochrome-icon.svg" /> **App Storage**.

  Dans la **barre de recherche** :

  1. Sélectionnez la <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="icône de loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> loupe en haut pour ouvrir l&#39;outil de recherche.
  2. Saisissez « App Storage » pour trouver l&#39;outil, puis sélectionnez-le dans les résultats.
</Accordion>

Pour associer un nouveau bucket de stockage à votre Replit App, créez un bucket.

<Accordion title="Comment créer un bucket">
  Dans l&#39;outil **App Storage** :

  1. Cliquez sur **Create new bucket**.
  2. Saisissez un nom pour le bucket dans le champ **Name**, puis sélectionnez **Create bucket**.

  L&#39;onglet App Storage devrait ressembler à la capture d&#39;écran suivante :

  <Frame>
    <img src="/assets/mirror/object-storage-empty-bucket-3462e2efb1bc.png" alt="capture d'écran de l'outil App Storage" width="2790" height="1218" data-path="images/databases/object-storage-empty-bucket.png" />
  </Frame>

  Pour créer d&#39;autres buckets, ouvrez le menu déroulant des buckets en haut à gauche de l&#39;onglet **App Storage** et sélectionnez **Create new bucket**.
</Accordion>

<div id="acessar-o-id-do-bucket">
  ### Accéder à l&#39;ID du bucket
</div>

Pour afficher le **Bucket ID**, sélectionnez la vue **Settings** dans le menu déroulant situé en haut de l&#39;onglet **App Storage**.
Le Bucket ID identifie le bucket de façon unique ; votre code doit y faire référence pour effectuer une opération.

Si vous disposez de plusieurs buckets, sélectionnez celui qui convient dans le menu déroulant en haut à gauche.

<div id="fazer-upload-ou-download-de-objetos">
  ### Téléverser ou télécharger des objets
</div>

Pour téléverser un objet dans le bucket sélectionné :

1. Accédez à la vue **Objects** dans l&#39;onglet **App Storage**.
2. Sélectionnez <img class="icon-svg" src="/assets/mirror/upload-file-5894be4232ce.svg" alt="icône de téléversement de fichier" width="16" height="16" data-path="images/icons/upload-file.svg" /> **Upload files**, ou <img class="icon-svg" src="/assets/mirror/upload-folder-fc87519bedf9.svg" alt="icône de téléversement de dossier" width="16" height="16" data-path="images/icons/upload-folder.svg" /> **Upload folder** pour téléverser tous les fichiers d&#39;un dossier.
   Sélectionnez ensuite un ou plusieurs fichiers à téléverser dans la boîte de dialogue de fichiers.
   Vous pouvez également faire glisser un fichier ou un dossier vers la zone qui affiche le contenu du bucket.

Pour télécharger un objet depuis le bucket sélectionné :

1. Accédez à la vue **Objects** dans l&#39;onglet **App Storage**.
2. Sélectionnez l&#39;icône de téléchargement <img class="icon-svg" src="/assets/mirror/download-icon-c7b527953d65.svg" alt="icône de téléchargement" width="16" height="16" data-path="images/icons/download-icon.svg" /> située à droite du fichier pour le télécharger.

<div id="organizar-objetos-em-pastas">
  ### Organiser les objets dans des dossiers
</div>

Pour créer un dossier dans le bucket sélectionné :

1. Accédez à la vue **Objects** dans l&#39;onglet **App Storage**.
2. Sélectionnez <img class="icon-svg" src="/assets/mirror/create-folder-c9acf112a042.svg" alt="icône de création de dossier" width="16" height="16" data-path="images/icons/create-folder.svg" /> **Create Folder** dans la vue **Objects**.
3. Saisissez un nom pour le dossier.

Pour ajouter des objets à un dossier dans la vue **Objects**, faites glisser un objet sur le dossier de destination.

Pour déplacer un objet vers un dossier parent, faites-le glisser sur l&#39;en-tête, jusqu&#39;au nom du dossier affiché au-dessus de la liste des objets.
L&#39;animation ci-dessous illustre le déplacement du fichier « product&#95;demo.mov » du dossier « videos » vers le dossier parent « Objects » :

<div id="excluir-objetos-ou-buckets">
  ### Supprimer des objets ou des buckets
</div>

<Warning>
  La suppression est irréversible. Veillez à sauvegarder toutes les données essentielles avant de continuer.
</Warning>

Pour supprimer définitivement un objet :

1. Accédez à la vue **Objects** dans l&#39;onglet **App Storage**.
2. Sélectionnez l&#39;icône de corbeille <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="icône de corbeille" width="16" height="16" data-path="images/icons/trash-icon.svg" />
   située à côté de l&#39;objet à supprimer.
3. Confirmez la suppression dans la boîte de dialogue de confirmation.

Pour supprimer un bucket et tous les objets qu&#39;il contient :

1. Accédez à la vue **Settings** dans l&#39;onglet **App Storage**.
2. Veillez à sélectionner le bucket à supprimer dans le menu déroulant des buckets, en haut à gauche.
3. Sélectionnez <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="icône de corbeille" width="16" height="16" data-path="images/icons/trash-icon.svg" /> **Delete Bucket**.
4. Confirmez la suppression dans la boîte de dialogue de confirmation.

<div id="gerenciamento-de-acesso-a-buckets">
  ### Gestion de l&#39;accès aux buckets
</div>

Replit associe à votre compte tous les buckets que vous créez et les rend accessibles à
toutes vos Replit Apps. La Replit App depuis laquelle vous créez le bucket
y a automatiquement accès.

Vous pouvez définir lesquelles de vos Replit Apps ont accès à un bucket donné, ce qui permet
de partager les données de manière efficace et sécurisée.

Pour donner à votre Replit App l&#39;accès à un bucket d&#39;une autre app de votre compte :

1. Sélectionnez <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="icône de loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" />
   **Add an existing bucket** dans le menu des buckets, en haut à gauche de l&#39;onglet App Storage.
2. Dans la boîte de dialogue **Choose a Bucket**, choisissez le bucket à ajouter, puis sélectionnez **Add Bucket to Repl**.

<Frame>
  <img src="/assets/mirror/choose-bucket-dialog-b709aa247a85.png" alt="capture d'écran de la boîte de dialogue de choix du bucket" width="1115" height="457" data-path="images/databases/choose-bucket-dialog.png" />
</Frame>

Pour révoquer l&#39;accès de votre Replit App à un bucket :

1. Accédez à la vue **Settings** dans l&#39;onglet **App Storage**.
2. Dans le menu déroulant des buckets, en haut à gauche de l&#39;onglet, sélectionnez le nom du bucket.
3. Sélectionnez **Remove Bucket from Repl**, puis confirmez la suppression dans la boîte de dialogue de confirmation.

<div id="acesso-programtico-ao-app-storage">
  ### Accès programmatique à App Storage
</div>

Pour accéder à App Storage depuis votre Replit App, utilisez l&#39;une des bibliothèques suivantes :

* le SDK App Storage de Replit, disponible pour JavaScript et Python
* <a href="https://cloud.google.com/storage/docs/reference/libraries" target="_blank">la bibliothèque cliente Google Cloud Storage</a>

Pour savoir comment utiliser ces bibliothèques clientes, consultez les ressources suivantes :

* [JavaScript App Storage SDK](/fr/pt/features/sdks/object-storage-javascript-sdk/) : référence client du SDK JavaScript
* [Python App Storage SDK](/fr/pt/features/sdks/object-storage-python-sdk/) : référence client du SDK Python
* [Google Cloud Python SDK example app](https://replit.com/@matt/GCS-Python-Uploads?v=1) : remixez cette app pour gérer vos objets à l&#39;aide du SDK Python de Google Cloud
