---
title: "Custom Domains"
description: "게시한 Replit 앱에 사용할 custom domain을 구매하고 연결하고 관리하세요."
icon: "at"
---

Custom domain을 사용하면 `www.my-incredible-app.com`처럼 직접 소유한 도메인 이름을 Replit published app에 연결할 수 있습니다.
Replit은 `<your-live-app-subdomain-name>.replit.app` 형식의 무료 서브도메인을 제공하지만, custom
domain을 사용하면 더 기억하기 쉬운 주소를 앱에 부여해 브랜드 인지도를 높이고 방문자의 신뢰를 얻을 수 있습니다.

Publishing 도구의 **Domains** 탭에서 필요한 작업을 모두 한곳에서 처리할 수 있습니다. 가능한 작업은 다음과 같습니다.

* Replit에서 **새 도메인을 구매**하고 한 번에 project에 연결합니다.
* 다른 registrar에서 **이미 소유한 도메인을 연결**합니다.
* 연결된 도메인을 **Manage**합니다. 각 도메인이 어떤 project를 가리키는지 확인하고, renewals를 추적하고, 도메인 연결을 해제할 수 있습니다.

Custom domain 설정 과정을 간단히 살펴보려면 다음 영상을 시청하세요.

<Frame>
  <iframe src="https://www.youtube.com/embed/rGYdyb58wJY" title="Custom Domains with Publishing" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowfullscreen />
</Frame>

다음 표는 Replit 서브도메인과 custom domain을 비교한 것입니다.

| 기능              | Replit 서브도메인 | Custom Domain    |
| :-------------- | :----------- | :--------------- |
| 호스트 이름 사용자 지정   | 서브도메인만 가능    | 소유한 모든 도메인       |
| DNS 업데이트 시간     | 즉시           | 최대 48시간          |
| 보안 인증서(TLS/SSL) | Replit 제공    | Replit 제공        |
| 가격              | 무료           | 도메인 provider에 결제 |

<Note>
  도메인을 연결하기 전에 앱을 먼저 게시하세요. 앱의 deployment가 성공하면 **Domains** 탭을 사용할 수 있습니다.
</Note>

<div id="buy-a-new-domain-on-replit">
  ## Replit에서 새 도메인 구매하기
</div>

아직 도메인이 없다면 Replit을 벗어나지 않고 검색해서 바로 구매할 수 있습니다. 새로 구매한 도메인은 자동으로 프로젝트를 가리킵니다.

<Steps>
  <Step title="Domains 탭 열기">
    <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publishing** 도구를 열고 **Domains** 탭을 선택하세요.
  </Step>

  <Step title="도메인 검색하기">
    **Buy a new domain**을 선택하고 원하는 이름을 입력하세요. Replit이 `.com`, `.ai` 등 다양한 도메인 확장자에서 사용 가능한 옵션을 보여줍니다. 어떤 이름을 붙일지 모르겠다면 Replit이 앱의 기능에 맞는 사용 가능한 이름을 제안해 주므로, 처음부터 고민할 필요 없이 고를 수 있습니다.

    <Frame>
      <img src="/assets/mirror/buy-domain-4dc6cba1f76e.png" alt="Domain search interface showing available domains with extensions like .com and .ai" width="2172" height="1222" data-path="images/deployments/custom-domains/buy-domain.png" />
    </Frame>
  </Step>

  <Step title="구매 후 연결하기">
    원하는 도메인을 선택하고 Replit 계정의 결제 수단으로 구매를 완료하세요. 별도의 DNS 설정 없이도 새 도메인으로 앱에 바로 접속할 수 있습니다.
  </Step>
</Steps>

Replit을 통해 구매한 도메인에는 [WHOIS 개인정보 보호](/ko/build/domain-purchasing)가 추가 비용 없이 포함되며, 자동으로 갱신되고, 사용자 지정 DNS 레코드(예: 이메일용 MX 레코드)도 추가할 수 있습니다. 가격, 갱신, 이전, 사용자 지정 DNS 레코드 등 도메인 구매에 대한 전체 안내는 [도메인 구매하기](/ko/build/domain-purchasing)를 참고하세요.

<div id="connect-a-domain-you-already-own">
  ## 이미 보유한 도메인 연결하기
</div>

다른 등록기관(registrar)에 이미 도메인을 보유하고 있다면, **Domains** 탭에서 해당 도메인을 프로젝트에 연결하세요. Replit은
DNS를 대신 구성해 주는 가이드형 설정을 제공하며, 대안으로 수동 설정 옵션도 지원합니다.

<div id="guided-setup-recommended">
  ### 가이드 설정(권장)
</div>

기존 도메인을 연결하는 가장 간단한 방법은 Replit에 설정을 맡기는 것입니다. Replit은 서드파티 도메인 연결 서비스인
[Entri](https://entri.com)를 사용합니다. 사용자가 권한을 부여하면 Entri가 DNS provider에 로그인해 필요한 DNS 레코드를
대신 등록하므로, 직접 하나하나 입력할 필요가 없습니다.

<Note>
  DNS 레코드는 도메인이 어디를 가리켜야 하는지 인터넷에 알려주는 설정입니다. 예전에는 이 레코드를 직접 설정하는 일이 도메인 연결에서
  가장 까다로운 부분이었습니다. 이제는 대부분의 도메인과 provider에 대해 Replit이 이 단계를 대신 처리합니다.
</Note>

<Steps>
  <Step title="Domains 탭 열기">
    <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publishing** 도구를 열고 **Domains** 탭을 선택합니다.

    <Frame>
      <img src="/assets/mirror/01-8e5c25be298f.png" alt="Domains tab" width="2422" height="1130" data-path="images/deployments/custom-domains/01.png" />
    </Frame>
  </Step>

  <Step title="연결할 도메인 입력">
    **Connect your own domain**을 선택하고 `www.my-incredible-app.com`처럼 이미 소유한 도메인을 입력합니다.
  </Step>

  <Step title="가이드 설정 권한 부여">
    연결을 확인합니다. Replit이 가이드 flow를 열면 DNS provider에 로그인하여 DNS 레코드가 계정에 자동으로 적용되도록 합니다.
    가이드 flow가 해당 provider에 레코드를 등록할 수 없는 경우에는, 직접 추가해야 할 레코드를 대신 보여줍니다.
  </Step>

  <Step title="도메인 확인 대기">
    설정이 완료되면 도메인에 **Verified** status가 표시됩니다. 보통 몇 분이면 완료되지만, DNS
    changes가 전파되는 데 최대 48시간이 걸릴 수 있습니다. 브라우저에서 도메인을 열어 정상 작동하는지 확인하세요.
  </Step>
</Steps>

<Tip>
  사용 중인 provider가 가이드 설정을 지원하지 않거나 레코드를 직접 추가하고 싶다면, 도메인을 수동으로
  연결할 수 있습니다. 아래 [도메인 수동 연결](#connect-a-domain-manually)을 참고하세요.
</Tip>

<div id="connect-a-domain-manually">
  ### 도메인 수동으로 연결하기
</div>

사용 중인 provider가 가이드 설정을 지원하지 않거나 레코드를 직접 추가하려는 경우, 아래 단계에 따라 custom domain을 수동으로 설정하세요.

<Warning>
  다음 중 하나에 해당하면 설정 과정에서 문제가 발생할 수 있습니다.

  * 동일한 도메인 이름에 대해 서로 다른 서버를 가리키는 `A` 레코드가 여러 개 있는 경우
  * 동일한 도메인에 `A` 레코드와 `AAAA` 레코드가 함께 존재하는 경우(Replit은 `A` 레코드만 지원합니다)
  * Cloudflare에서 프록시된 도메인 레코드가 있는 경우. Replit은 해당 유형의 보안 인증서를 자동으로 갱신할 수 없습니다. 레코드를 **DNS only**(회색 구름)로 설정하세요.
  * `replit-verify` `TXT` 레코드가 없거나 삭제된 경우. SSL/TLS 인증서를 갱신하려면 이 레코드가 그대로 유지되어야 합니다. 아래 [TXT 레코드 유지하기](#keep-the-txt-record-in-place)를 참고하세요.
</Warning>

<Steps>
  <Step title="custom domain 추가하기">
    텍스트 필드에 custom domain 이름을 입력하세요. 등록된 도메인을 사용하거나 서브도메인을 포함할 수 있습니다.

    예를 들어 `hat-tip.cc`는 등록된 도메인이고, `my.hat-tip.cc`는 서브도메인 `my`를 포함합니다.

    <Frame>
      <img src="/assets/mirror/02-82bc532c7741.png" alt="DNS 설정 스크린샷" width="1940" height="718" data-path="images/deployments/custom-domains/02.png" />
    </Frame>
  </Step>

  <Step title="domain registrar에 DNS 레코드 추가하기">
    Replit은 **domain registrar**에 등록해야 하는 DNS 레코드를 생성합니다.
    domain registrar란 GoDaddy나 Namecheap처럼 도메인 이름을 관리해 주는 서비스를 말합니다.

    Replit에서 `A` 레코드와 `TXT` 레코드 값을 복사해 domain registrar의
    DNS 관리 섹션에 붙여넣으세요. domain registrar가 호스트 이름으로 `@`를 지원하지 않는다면 등록된 도메인 이름을 사용하세요.

    <Warning>
      **TXT 레코드를 삭제하지 마세요.** Replit은 DNS validation을 통해 custom domain의
      SSL/TLS 인증서를 발급하고 갱신합니다. `replit-verify=...` `TXT` 레코드는 초기 설정
      기간뿐 아니라 도메인을 사용하는 내내 DNS에 남아 있어야 합니다. 검증이 끝난 뒤 레코드를
      삭제하거나 변경하면 다음 certificate renewal이 실패하고, 결국 도메인이 만료된 인증서를
      serve하게 되어 브라우저에서 앱에 접속할 수 없게 됩니다. `TXT` 레코드는 `A` 레코드와
      마찬가지로 영구적으로 유지해야 하는 값으로 생각하세요.
    </Warning>
  </Step>

  <Step title="선택 사항: 서브도메인 추가하기">
    `www`를 포함한 서브도메인은 apex 도메인을 연결하더라도 자동으로 연결되지 않습니다.
    serve하려는 서브도메인은 각각 **Domains** 탭에 별도 항목으로 추가하고,
    registrar에서 그에 맞는 DNS 레코드를 설정해야 합니다.

    서브도메인을 추가하려면 apex 도메인을 연결할 때와 같은 방식으로 **Domains** 탭에서
    연결한 다음, Replit이 생성한 DNS 레코드를 domain registrar에 추가하세요.
    예를 들어 `my-subdomain.hat-tip.cc`를 추가하려면 다음과 같이 합니다.

    * **Publishing** 도구에서 **Domains** 탭을 선택하고 `my-subdomain.hat-tip.cc`를 연결합니다.
    * registrar에서 호스트 이름을 `my-subdomain`으로 하는 새 `A` 레코드를 추가하고, Replit이 새
      항목에 대해 표시하는 IP 주소를 가리키도록 설정합니다.
    * registrar에서 호스트 이름 `my-subdomain`에 해당하는 `replit-verify=...` `TXT` 레코드를
      추가합니다. 서브도메인마다 apex와는 별개로 자체 `TXT` 레코드를 가집니다.

    <Note>
      **`www`도 서브도메인입니다.** `hat-tip.cc`를 연결했다고 해서 `www.hat-tip.cc`까지 자동으로
      serve되지는 않습니다. 방문자가 `hat-tip.cc`와 `www.hat-tip.cc` 어느 쪽으로도 앱에 접속할 수
      있게 하려면 **Domains** 탭에 `www.hat-tip.cc`를 별도 항목으로 추가하고, 이때 생성되는 `A` 레코드와
      `TXT` 레코드를 호스트 이름 `www`에 등록하세요. `www` 주소를 사용하려는 대부분의 builder는
      registrar에서 apex 도메인을 `www`로(또는 그 반대로) 리디렉션하도록 함께 설정합니다.
    </Note>

    apex 도메인과 마찬가지로, 각 서브도메인에 추가한 `replit-verify=...` `TXT` 레코드도
    DNS에 영구적으로 남아 있어야 합니다. 아래
    [TXT 레코드를 삭제하지 마세요](#keep-the-txt-record-in-place)를 참고하세요.
  </Step>

  <Step title="DNS 전파가 완료될 때까지 기다리기">
    레코드를 추가한 후에는 온라인에 전파될 때까지 기다려야 합니다.
    몇 분에서 48시간까지 걸릴 수 있습니다.

    전파가 완료되면 아래와 같이 Domains tab의 도메인 이름 옆에 &quot;Verified&quot; status가 표시됩니다.

    <Frame>
      <img src="/assets/mirror/domain-verified-49076889c213.png" alt="검증된 도메인 상태 스크린샷" width="1866" height="890" data-path="images/deployments/custom-domains/domain-verified.png" />
    </Frame>

    브라우저에서 도메인을 열어 정상 작동하는지 확인하세요.
  </Step>
</Steps>

<div id="manage-your-domains">
  ## 도메인 관리
</div>

**Domains** 탭에는 project에 연결된 모든 도메인이 표시되며, 각 도메인을 관리할 수 있습니다. 도메인을 선택한 뒤
**Manage**를 선택하면 다음 작업을 할 수 있습니다.

* **도메인이 어떤 project를 가리키는지 확인합니다.** 이미 다른 project에 연결된 도메인을 연결하려고 하면
  Replit이 경고를 표시하고, 대신 현재 project로 옮길 수 있도록 안내합니다.
* **갱신 정보 확인(Replit에서 구매한 도메인의 경우).** 관리 화면에는 renewal date와 갱신 가격이 표시되며,
  도메인이 자동으로 갱신되지 않도록 하려면 **Auto renewal**을 끌 수 있습니다.
* **DNS 레코드 편집(Replit에서 구매한 도메인의 경우).** 사용자 지정 `A`, `TXT`, `MX` 레코드를 추가할 수 있습니다.
  예를 들어 도메인을 이메일에 사용하려면 MX 레코드를 추가하세요. [custom DNS records](/ko/build/domain-purchasing#custom-dns-records)를 참고하세요.
* **도메인 연결 해제.** 연결을 해제하면 해당 도메인에서 앱이 더 이상 제공되지 않습니다. 도메인 자체가 삭제되지는 않으며,
  다른 project에 연결할 수 있도록 그대로 남아 있습니다.

<div id="troubleshooting">
  ## 문제 해결
</div>

<div id="domain-link-failed-or-stuck-on-pending-verification">
  ### 도메인 연결 실패 또는 확인 대기 상태에서 멈춤
</div>

연결에 실패하거나 도메인이 **Verifying** 상태에서 멈춰 있다면 다음 항목을 차례로 점검하세요.

1. **DNS 전파 시간을 충분히 기다리세요.** 확인에는 몇 분에서 최대 48시간까지 걸릴 수 있습니다. 다른 설정을
   변경하기 전에 DNS 조회 도구로 레코드가 전 세계에 반영되었는지 확인하세요.
2. **충돌하는 레코드를 제거하세요.** 루트 도메인에는 Replit을 가리키는 `A` 레코드 하나만 두고, 동일한
   호스트 이름의 `AAAA`(IPv6) 레코드는 모두 제거하세요. SSL이 차단될 수 있습니다.
3. **Cloudflare 프록시를 끄세요.** `A` 레코드를 **DNS only**(회색 구름)로 설정하세요. 프록시 모드
   (주황색 구름)는 SSL provisioning을 방해합니다.
4. **`TXT` 레코드가 있는지 확인하세요.** `replit-verify=...` `TXT` 레코드가 없거나 변경되면 확인과
   certificate renewal이 차단됩니다. [TXT 레코드 유지하기](#keep-the-txt-record-in-place)를 참조하세요.
5. **Domains 탭에서 도메인 연결을 해제한 뒤 다시 연결하여** 인증서를 새로 발급받은 다음, 몇 분 기다린 후
   페이지를 새로고침하세요.

Replit을 통해 도메인을 구매했는데도 확인이 완료되지 않는다면 [Replit Support에 문의하세요](https://replit.com/support).

<div id="dns-changes-havent-taken-effect-yet">
  ### DNS 변경 사항이 아직 적용되지 않은 경우
</div>

DNS 변경 사항은 즉시 반영되지 않습니다. 레코드를 추가하거나 변경한 후 전 세계에 전파되기까지 몇 분에서 48시간까지
걸릴 수 있습니다. 이 기간에도 앱은 `replit.app` 하위 도메인에서 계속 정상 작동합니다. 48시간이 지나도 **Verified**
상태가 표시되지 않는다면 Replit에 표시된 값과 레코드를 다시 대조해 보세요. 끝에 붙은 마침표, 불필요하게 추가된 하위 도메인,
오래된 레코드가 흔한 실수입니다.

<div id="cname-records-and-authentication">
  ### `CNAME` 레코드와 인증
</div>

사용자 지정 도메인에서 로그인이나 인증이 작동하는 데 `CNAME` 레코드는 필요하지 않습니다. 도메인이 확인되면 게시된 도메인 전체에서 로그인이 자동으로 작동합니다.

사용자 지정 도메인의 `CNAME` 레코드는 **이메일 발송**에만 필요합니다. 예를 들어 확인 메일이나 트랜잭션 메일을 사용자 도메인에서 보내려는 경우입니다. Publishing 도구에 `CNAME` 레코드를 추가하라는 경고가 표시되더라도, 이는 로그인이 아니라 이메일 전송과 관련된 안내입니다. 레코드 추가는 사용자 도메인에서 이메일을 보내는 경우에만 필요하며, 도메인 확인이나 SSL, 로그인에는 영향을 주지 않습니다. 이메일 관련 설정 단계는 [Clerk 인증](/ko/features/auth-and-identity/clerk-auth)을 참고하세요.

<div id="keep-the-txt-record-in-place">
  ### TXT 레코드를 그대로 유지하세요
</div>

Replit은 각 custom domain의 SSL/TLS 인증서를 DNS validation을 통해 발급하고 갱신하며, 이 과정은 설정 시 추가한 `replit-verify=...` `TXT` 레코드에 의존합니다. 이 `TXT` 레코드는 설정할 때 한 번만 쓰고 마는 값이 아니라, 도메인을 사용하는 전체 기간 동안 DNS에 남아 있어야 합니다. 도메인 인증 후에 레코드를 삭제하거나 수정하거나 다른 값으로 바꾸면 다음 갱신이 아무런 알림 없이 실패하고 기존 인증서도 결국 만료됩니다. 그러면 방문자에게 브라우저 보안 경고가 표시되고 앱에 접속할 수 없게 됩니다.

계정의 오래된 도메인에서만 갑자기 인증서 오류가 발생하고 최근에 추가한 도메인은 정상이라면, `TXT` 레코드가 누락되었거나 변경되었을 가능성이 가장 높습니다.

영향을 받은 도메인을 복구하려면 다음과 같이 하세요.

1. **Publishing** 도구를 열고 **Domains** 탭을 선택합니다.
2. 해당 도메인에 대해 Replit이 표시하는 `replit-verify=...` `TXT` 레코드를 확인합니다.
3. 도메인 registrar에서 호스트 이름과 값을 포함해 표시된 그대로 `TXT` 레코드를 다시 추가합니다.
4. Replit에서 해당 도메인을 삭제한 후 다시 추가하여 인증서를 새로 발급받습니다.
5. DNS 전파를 기다린 다음 **Domains** 탭에서 **Verified** 상태를 다시 확인합니다.
