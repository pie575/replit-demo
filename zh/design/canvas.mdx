Canvas 是一块可无限平移和缩放的画布，Replit Design 会在这里展示你的 frame。你设计的一切都在这里：生成 frame、随意拖动、放大查看细节，反复迭代直到满意为止。

<div id="open-the-canvas">
  ## 打开 Canvas
</div>

进入 Replit Design 后，你首先看到的就是 Canvas。在 project 中，选择顶栏的 **Design**，Canvas 会铺满整个面板；选择 **Build** 则可切回正在运行的应用。

<Frame>
  <img src="/assets/mirror/canvas-design-button-ffa50447cefb.png" alt="Close-up of a project header with the Design and Build toggle, Design selected, above frames on the canvas" width="987" height="619" data-path="images/replitai/canvas-design-button.png" />
</Frame>

如果从 [replit.com/design](https://replit.com/design) 从零开始，系统会提示你创建一个新的 design，并直接在 Canvas 中打开。想了解何时该用哪个界面，请参阅 [Design 与 Build 对比](/zh/design/design-vs-build)。

<div id="what-lives-on-the-canvas">
  ## Canvas 上有什么
</div>

* **Frame**：画布上的每一个图块。一个 frame 可以是设计稿、web app、移动应用、幻灯片、图片、视频或矢量图形。你可以通过 Chat prompt、工具栏的[生成菜单](/zh/design/toolbar#generate)或[素材库面板](/zh/design/library-panel)来生成它们。对 frame 的所有操作——Build、聚焦、建议——都通过 frame 本身完成：参见 [Frame](/zh/design/frames)。
* **绘图与便签**：使用[绘图工具](/zh/design/toolbar#draw)添加的标注，例如草图、箭头、形状和便利贴。Agent 会读取你的标注，因此你可以圈出有问题的区域并提出修改要求。
* **Chat 面板**：停靠在 canvas 旁边的 Agent Chat。发送消息前先选中 frame，系统会将其作为快照一并附上，让 Agent 获得视觉上下文。

要了解各个组件的作用以及它们如何协同工作，请参见[组件概览](/zh/design/core-components)。

<div id="navigate-the-board">
  ## 浏览画板
</div>

除非另有说明，平移、缩放和选择操作在任何工具下均可使用。

**平移：**

* 触控板：双指拖动。
* 鼠标：按住中键拖动，或按住空格键的同时按住左键拖动。
* [平移工具](/zh/design/toolbar#pan)：按住鼠标左键拖动。

**缩放：**

* 触控板：双指开合。
* 鼠标：`Ctrl` (macOS 上为 `Cmd`) + 滚轮。
* 键盘：`Cmd`/`Ctrl` + `+` 放大，`Cmd`/`Ctrl` + `-` 缩小，`Cmd`/`Ctrl` + `0` 重置缩放。

缩放以光标为锚点，因此光标所指的位置保持不动，画板的其余部分则围绕该点进行缩放。

**选择：**

* 单个 frame：使用 [交互工具](/zh/design/toolbar#interact)点击该 frame。
* 多选：按住 `Shift` 逐个点击 frame，或在画板上拖出矩形选框。
* 取消选择：点击空白区域，或按 `Escape`。

选中一个或多个 frame 后会显示 [frame 操作栏](/zh/design/frames#per-frame-action-bar)，同时这些 frame 会以快照形式附加到下一条 Agent 消息中。

<div id="keyboard-shortcuts">
  ### 键盘快捷键
</div>

| 快捷键                            | 操作                 |
| ------------------------------ | ------------------ |
| `V`                            | 切换到交互工具            |
| `H`                            | 切换到平移工具            |
| 按住 `Space` + 拖动                | 在任意工具下平移           |
| `Cmd` / `Ctrl` + 滚动            | 缩放                 |
| `Cmd` / `Ctrl` + `+`           | 放大                 |
| `Cmd` / `Ctrl` + `-`           | 缩小                 |
| `Cmd` / `Ctrl` + `0`           | 重置缩放               |
| `Shift` + 单击                   | 将某个 frame 加入当前选区   |
| `Cmd` / `Ctrl` + `Shift` + `C` | 将选中的 frame 复制为 PNG |
| `Escape`                       | 取消选择               |

<div id="right-click-menu">
  ## 右键菜单
</div>

在画板上任意位置点击右键即可打开上下文菜单。菜单会随光标所指的内容而变化：在 frame 上显示 frame 相关操作，在空白 Canvas 上显示画板级操作，app frame 则会额外提供 **Refresh artifact**。

在选中的 frame 上，菜单包含：

| 操作                             | 快捷键                           | 功能说明                                          |
| ------------------------------ | ----------------------------- | --------------------------------------------- |
| Edit                           |                               | 切换到 Edit 工具，以选择 frame 内部的元素。                  |
| Chat                           |                               | 就该 frame 与 Agent 对话。                          |
| Focus                          |                               | 对该 frame 进入[专注模式](/zh/design/frames#focus-mode)。 |
| Cursor chat                    | `/`                           | 在光标位置发起一次快捷对话。                                |
| Reorder                        |                               | 在堆叠顺序中将 frame 前移或后移。                          |
| Copy, Paste, Duplicate, Delete | `⌘C`, `⌘V`, `⌘D`, `Backspace` | 标准的剪贴板与 frame 管理操作。                           |
| 导出为…                     |                               | 将 frame 导出为文件。                                |
| Select all                     | `⌘A`                          | 选中画板上的所有 frame。                               |

<div id="export-a-frame-as-png">
  ### 将 frame 导出为 PNG
</div>

将任何 artifact 或设计 frame 保存为 PNG 图片。你可以用它在文档或聊天中分享预览、在继续迭代前保存快照，或向团队成员发送截图。

<Steps>
  <Step title="选择 frame">
    选择要导出的 artifact 或设计 frame，然后等待其加载完成。
  </Step>

  <Step title="选择导出">
    在 frame 的操作栏中选择 **导出**。你也可以右键点击 frame，然后选择 **导出为…** &gt; **PNG**。图片将下载到你的计算机，文件名基于 frame 的名称。
  </Step>
</Steps>

若要将所选 frame 复制为 PNG 而不是下载，请按 `Cmd+Shift+C` (Windows 和 Linux 上按 `Ctrl+Shift+C`) 。

<Note>导出的 PNG 与 frame 当前在 Canvas 上显示的内容一致。如果你的 App 或设计仍在加载，请等待其完全渲染后再导出。</Note>

<div id="the-canvas-and-the-live-app">
  ## Canvas 与实时应用
</div>

Canvas 和实时应用预览共用同一个窗格，有几种模式在两者之间起到衔接作用：

* **专注模式**：对选中的 frame 使用 **Focus** 操作，可将其放大至填满整个视图。选择面板顶部的 **Exit focus** 即可返回 Canvas。
* **只读模式**：当 Canvas 在后台任务场景中被锁定时，迭代类操作会隐藏，仅保留 Focus。

<Note>
  从 Design frame 构建新应用需要 Core 或 Pro；Canvas 的其他所有功能在各个套餐中均可使用。套餐详情请参阅[账单](/zh/billing/ai-billing)。
</Note>
