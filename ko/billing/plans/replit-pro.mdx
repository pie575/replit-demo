[Replit Pro](https://replit.com/pricing)는 Core를 넘어선 진지한 빌더를 위해 만들어졌습니다 — 프로덕션 앱을 출시하거나, 성장하는 팀과 함께 작업하거나, Agent를 한계까지 활용하는 경우에 적합합니다. 현재 Pro 요금은 [요금 페이지](https://replit.com/pricing)를 참조하세요.

## 주요 기능

### 가장 강력한 Agent 경험

* **Turbo 모드**: 고급 설정의 **별도 토글** — **Power** 모드에서 켜면 가장 빠른 모델로 **2.5배 빠른** Agent를 사용할 수 있습니다. 요청 비용이 약 2배 더 많이 들므로 숙련된 빌더에게 권장됩니다.
* **병렬 작업 실행**: 최대 10개의 작업을 동시에 실행하여 더 빠른 반복이 가능합니다.
* **Agent 모드**: 작업에 맞게 Lite, Economy, Power를 선택하세요. 모드 선택에 대한 자세한 내용은 [Agent 모드](/ko/features/agent/agent-modes)를 참조하세요.

### 단계별 크레딧 및 롤오버

* **단계별 월간 크레딧**: 대용량 티어에 할인이 적용되는 여러 단계. 미리 구매하여 더 절약하고, 성장에 따라 크레딧을 추가하세요. 현재 티어는 [요금 페이지](https://replit.com/pricing)를 참조하세요.
* **크레딧 롤오버**: 사용하지 않은 크레딧이 {ProCreditRolloverPeriod} 동안 이월되어 구독에서 더 많은 가치를 얻을 수 있습니다.

### 팀 규모 확장

* **최대 15명의 빌더**: 풀링된 크레딧과 예산 제어로 최대 15명의 빌더를 초대하세요. 사용자당 요금 없음 — 모두 동일한 플랜에서 작업합니다.
* **협업 워크스페이스**: 관리자 계정의 풀링된 크레딧으로 협업 워크스페이스를 생성하고, 앱을 구성하고 워크스페이스별 사용량을 추적하세요.

### 우선 지원 및 안정성

* **우선 지원**: 업무일 기준 지원 엔지니어에게 우선적으로 직접 액세스할 수 있으며, 이는 AI 기반 지원에 더해 제공되는 Pro 및 Enterprise 혜택입니다.
* **4배 데이터베이스 복구 기간**: 표준 7일 대신 최근 28일 이내 임의 시점으로 데이터베이스를 복원할 수 있습니다. 복구 기간이 길어질수록 스토리지를 더 많이 사용하므로 복구 기간을 늘리면 사용 비용이 증가합니다.

### 커뮤니티 및 더 많은 기능

* **독점 커뮤니티**: 다른 진지한 빌더들로부터 배우고, 작업 중인 것을 공유하며, 팀에 독점적으로 접근하세요.
* **곧 더 많은 기능 추가**: 올해 Pro 전용으로 추가 기능이 출시될 예정입니다.

## Pro 전용 기능

| 기능         | 세부 정보                                        |
| ---------- | -------------------------------------------- |
| Turbo 모드   | 가장 강력한 모델로 2.5배 빠른 Agent                     |
| 병렬 작업 실행   | 최대 10개 작업 동시 실행                              |
| 최대 15명의 빌더 | Core의 5명 대비                                  |
| 크레딧 롤오버    | 사용하지 않은 크레딧이 {ProCreditRolloverPeriod} 동안 이월 |
| 우선 지원      | 지원 엔지니어에게 우선적으로 직접 액세스                       |
| 4배 데이터 보존  | 삭제된 데이터베이스를 최대 28일 동안 복구 가능                  |

Core의 모든 기능이 Pro에도 포함됩니다. 전체 비교는 [요금 페이지](https://replit.com/pricing)를 참조하세요.

## 시작하기

1. [요금 페이지](https://replit.com/pricing)로 이동합니다
2. **Replit Pro**를 선택하고 크레딧 티어를 선택합니다
3. 결제를 완료하여 팀과 함께 빌드를 시작합니다
