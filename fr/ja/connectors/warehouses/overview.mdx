Le connecteur d’entrepôt de données permet à Replit Agent d’exécuter des requêtes de manière sécurisée sur les entrepôts de données de votre organisation. Les créateurs peuvent utiliser le langage naturel pour créer des tableaux de bord, des outils de reporting et des applications basées sur les données, sans expertise en SQL. Les administrateurs conservent un contrôle centralisé grâce à un accès basé sur les rôles.

<div id="section">
  ## Entrepôts de données pris en charge
</div>

Le connecteur d’entrepôt de données est disponible avec l’offre **Enterprise**.

| Entrepôt de données | Guide de configuration                                                                                                    |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| BigQuery            | Disponible — le guide de configuration est en cours de préparation                                                        |
| Databricks          | [Se connecter à Databricks](/fr/ja/connectors/warehouses/databricks)                                                         |
| Microsoft Fabric    | [Créer des applications de données sur Microsoft Fabric](/fr/ja/connectors/warehouses/microsoft-fabric) (préversion privée)  |
| Snowflake           | [Se connecter à Snowflake](/fr/ja/connectors/warehouses/snowflake)                                                           |

Chaque entrepôt de données dispose de son propre processus de configuration, car les intégrations OAuth, les modèles d’identité et les formats d’identifiants diffèrent. Sélectionnez l’entrepôt de données que vous utilisez et suivez le guide correspondant.

<div id="section-2">
  ## Plateformes d’analyse et de données
</div>

Les connecteurs d’analyse sont disponibles avec les forfaits Core et Pro, en plus d’Enterprise. En connectant des outils d’analyse, Agent peut lire et traiter les données produit.

* **Segment** — Données clients issues d’une CDP, flux d’événements et segments d’audience
* **Amplitude** — Analyses produit, données comportementales des utilisateurs et indicateurs d’engagement
* **Hex** — Blocs-notes de données collaboratifs et résultats de requêtes

Gérez-les comme les autres connecteurs Replit. Consultez [Gérer les connecteurs](/fr/ja/replitai/managing-connectors).

<div id="section-3">
  ## Fonctionnement du connecteur d’entrepôt de données
</div>

La configuration est une opération ponctuelle qui implique trois rôles :

1. **Administrateur de l’entrepôt de données** — Crée une intégration OAuth ou un identifiant de service dans l’entrepôt de données
2. **Administrateur de l’organisation Replit** — Ajoute les identifiants à Replit et configure l’accès
3. **Créateur** — Se connecte et commence à créer avec Agent

Une fois la configuration terminée, les créateurs peuvent demander à Agent d’utiliser l’entrepôt de données. Agent génère et exécute alors le SQL correspondant.

<div id="section-4">
  ### Créer des applications à partir des données de l&#39;entrepôt
</div>

Une fois connecté, vous pouvez demander à Agent de créer une application à partir de vos données. Agent peut :

* Créer des outils internes qui récupèrent et affichent des données en temps réel
* Créer des tableaux de bord avec des graphiques et des visualisations basés sur votre entrepôt
* Générer les requêtes SQL qui alimentent le backend de votre application
* Expliquer votre schéma et la structure de vos tables pour vous aider à déterminer ce que vous devez créer

<Note>
  Agent peut répondre à des questions ponctuelles sur vos données, mais l&#39;objectif principal du connecteur d&#39;entrepôt est de permettre à Agent de créer des applications fonctionnelles qui exploitent les données de votre organisation. Les requêtes d&#39;entrepôt sont exécutées directement sur votre instance. Assurez-vous donc que les portées OAuth et les autorisations de l&#39;utilisateur de la base de données permettent les opérations de lecture et d&#39;écriture nécessaires.
</Note>
