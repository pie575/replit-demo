La publication vous permet de partager votre App Replit avec le monde entier en toute simplicité.

<Note>
  La mise en ligne de votre app est appelée « publication ». Cette page décrit les différents types de déploiement disponibles.
</Note>

<div id="o-que-publicao">
  ## Qu’est-ce que la publication ?
</div>

La publication est une fonctionnalité qui enregistre un **instantané** de votre Replit App dans le cloud,
avec lequel chacun peut interagir. Un instantané capture l’état actuel des fichiers de votre
Replit App.

Lorsque vous publiez votre Replit App, vous créez une **application publiée**. Une application publiée est une instance en cours d’exécution
de votre app sur l’infrastructure cloud de Replit. Elle rend votre app disponible de manière fiable sur Internet,
indépendamment de sa version dans le Project Editor.

<Info>
  L’infrastructure de Replit repose sur Google Cloud Platform (GCP). Toutes
  les applications publiées sont hébergées aux États-Unis. Les clients Enterprise peuvent
  contacter le service commercial pour demander que leurs applications publiées soient hébergées dans l’Union
  européenne.

  Chaque client individuel, organisation et entreprise bénéficie d’un projet GCP dédié et
  monolocataire pour ses applications publiées. Cela signifie que les ressources de calcul, les Secrets
  et le stockage des applications publiées sont entièrement isolés et ne sont jamais
  partagés avec les applications d’autres clients.
</Info>

La publication inclut des outils permettant de surveiller l’état de votre application publiée et de consulter des statistiques web.

<div id="primeiros-passos">
  ## Premiers pas
</div>

Suivez les étapes ci-dessous pour publier votre Replit App :

1. Dans votre Project Editor, sélectionnez <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Icône de publication" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publier** en haut de l’écran.
2. Dans l’onglet **Publication**, sélectionnez l’option de publication souhaitée.
3. Si **Ajouter un mode de paiement** s’affiche, suivez les instructions pour ajouter un mode de paiement.

Replit sélectionne automatiquement l’option de publication la mieux adaptée à votre app en fonction du type de projet et de vos besoins.

Toutefois, si vous souhaitez choisir un autre type de déploiement, consultez les informations suivantes.

<div id="principais-recursos">
  ## Principales fonctionnalités
</div>

La publication offre les fonctionnalités pratiques suivantes :

* **Plusieurs options de publication** : Sélectionnez ou mettez à niveau un type de déploiement adapté à vos besoins en quelques clics.
* **Domaines personnalisés** : Diffusez votre app depuis votre propre domaine web.
* **Analytics** : Suivez les données des visiteurs et d’autres métriques de votre app publiée.
* **Outils de surveillance** : Consultez l’état et la configuration de votre app publiée.
* **Contrôles d’accès** : Contrôlez qui peut voir votre app en un seul clic. Disponible uniquement pour les membres des forfaits **Pro** et **Enterprise**.
* **Paramètres du badge** : Les utilisateurs du forfait Core peuvent gérer le badge « Made with Replit » dans les paramètres de publication. Si vous avez publié une app avec le forfait Starter, qui inclut ce badge, quelques minutes peuvent être nécessaires après la mise à niveau pour mettre à jour votre app et supprimer le badge.
* **Collecte de retours** : Activez la collecte de retours sur votre app publiée pour recueillir les avis de vos utilisateurs.

<div id="como-funciona">
  ## Fonctionnement
</div>

Lorsque vous publiez votre Replit App, Replit crée un instantané des fichiers et des dépendances de votre app.
Cet instantané est ensuite envoyé vers l&#39;infrastructure cloud de Replit, où il s&#39;exécute comme une instance distincte de votre app.
Pour mettre à jour votre app publiée avec les dernières modifications, publiez-la à nouveau afin de créer un nouvel instantané.

<Warning>
  Évitez de stocker des données sur le système de fichiers d&#39;une app publiée ou de vous y fier. Pour
  stocker des données, utilisez une solution de stockage ou une base de données, comme les offres [Storage and
  Database](/fr/pt/learn/projects-and-artifacts/storage-and-databases) de Replit.
</Warning>

<div id="casos-de-uso">
  ## Cas d’utilisation
</div>

Les exemples suivants présentent différents types d’apps publiées.

<div id="autoscale-deployment-app-de-avaliao-de-velocidade-de-digitao">
  ### Déploiement Autoscale : App de test de vitesse de frappe
</div>

Laissez le cloud augmenter les ressources lorsque les utilisateurs passent des tests de frappe et les réduire lorsqu’elles ne sont pas utilisées.

<div id="static-deployment-simulao-do-sistema-solar">
  ### Déploiement statique : Simulation du système solaire
</div>

Découvrez les planètes grâce à une application web de visualisation du système solaire.
Cette visualisation s&#39;affiche dans le navigateur et ne transmet aucune saisie utilisateur à un serveur.

<div id="reserved-vm-deployment-bot-do-discord">
  ### Déploiement de VM réservée : bot Discord
</div>

Exécutez un bot Discord pour vous aider à modérer et à intégrer des membres.
Il reste toujours en ligne pour interagir avec les utilisateurs et répondre aux commandes, avec des tarifs et des performances prévisibles.

<div id="scheduled-deployment-gatilhos-de-automao-residencial">
  ### Déploiement planifié : déclencheurs domotiques
</div>

Planifiez des appels d’API pour démarrer et arrêter vos appareils domotiques à des heures et jours précis.
