到目前为止，您的应用一直在项目编辑器中运行，但目前只有您能看到。发布后，所有人都可以访问。

<div id="criar-vs-publicar">
  ## 创建与发布
</div>

使用 Agent 时，您的应用会在**私有创建环境**中运行。您可以在“预览”标签页中查看、测试和修改它，但其他人无法访问。您可以将其视为草稿：它已经存在，但尚未共享。

当您**发布**时，Replit 会将您的应用发布到互联网，并为其提供专属的公开 URL。现在，任何拥有该链接的人都可以在世界任何地方通过任何设备访问它。

<div id="publique-seu-aplicativo">
  ## 发布您的应用
</div>

在项目编辑器中，点击**发布**按钮。

<Frame>
  <video autoPlay muted loop playsInline src="/assets/mirror/quickstart-publish-app-ae59052ca92d.mp4" />
</Frame>

就是这么简单。Replit 会打包您的应用，将其托管在服务器上，并为您提供一个公开的 `.replit.app` URL。复制该 URL，随时分享到任何地方。

<Note>如果您的项目包含多个产物——例如 Web 应用、移动应用和幻灯片演示文稿——发布后它们都会同时上线。每个产物都会获得各自的 URL。</Note>

<div id="atualizando-seu-aplicativo">
  ## 更新您的应用
</div>

每次修改后再次点击**发布**，您的应用都会在同一 URL 上更新。访客会立即看到最新版本，无需分享新链接。
