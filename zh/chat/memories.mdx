记忆可让 Replit 保留有用的上下文，并根据过往工作进行调整，因此你无需每次都重复设置相同的偏好。Replit 可以在你工作时写入记忆，并让这些记忆长期保持实用。

<div id="manage-your-memories">
  ## 管理你的记忆
</div>

<Steps>
  <Step title="打开设置">
    在 Replit 中打开 **设置**。
  </Step>

  <Step title="选择自定义">
    选择 **自定义**。
  </Step>

  <Step title="打开记忆选项卡">
    在这里，你可以选择启用记忆、之后将其关闭、选择是否与协作者共享，以及查看或更新 **记忆文件**。记忆默认仅自己可见，且默认不与协作者共享。

<Note>
  记忆不会保留个人或敏感信息。记忆源自 workspace 活动，Replit 会对其进行安全处理。
</Note>

如需了解何时使用记忆、Custom Instructions 或技能，请参阅 [记忆、Custom Instructions 和技能](/zh/chat/memories-custom-instructions-and-skills)。

<div id="faq">
  ## 常见问题
</div>

<AccordionGroup>
  <Accordion title="记忆可以保留哪些内容？">
    记忆会保留有用的上下文，而非可执行的指令。用户记忆可以
    保存长期有效的 workspace 偏好和工作方式。项目记忆可以
    保存惯例、注意事项和修复方法。自定义记忆是由您定义的上下文，
    并拥有独立的访问和可见性设置。您的明确请求和
    [Custom Instructions](/zh/features/agent/agent-customization)的优先级
    高于记忆。
  </Accordion>

  <Accordion title="Replit 会保留个人信息吗？">
    <Note>
      记忆不会保留个人信息。用户记忆可以保留有用的
      workspace 偏好和工作方式，但不会保留敏感特征、
      第三方个人数据、凭据或项目机密信息。
    </Note>
  </Accordion>

  <Accordion title="我可以与他人分享我的记忆吗？">
    记忆默认是私密的。与协作者共享是可选的，且默认
    关闭。如果您希望 Replit 在其他协作者也能编辑的 Projects 中
    使用记忆，请在 **设置 → 自定义 → 记忆** 中开启此选项。
  </Accordion>

  <Accordion title="记忆适用于哪些范围？">
    用户记忆归属于单个构建者和 workspace。项目记忆会保留在
    单个 Project 中，并在相关时被调用。自定义记忆遵循为其定义的
    访问和可见性设置。默认情况下，除非您开启
    与协作者共享，否则 Replit 不会在其他协作者可以编辑的 Projects 中使用您的
    记忆。
  </Accordion>

  <Accordion title="我可以查看、编辑或关闭记忆吗？">
    可以。在 **设置 → 自定义 → 记忆** 中，您可以选择启用记忆、
    之后将其停用，并使用 **记忆文件** 查看和更新 Replit
    记住的内容。
  </Accordion>
</AccordionGroup>
