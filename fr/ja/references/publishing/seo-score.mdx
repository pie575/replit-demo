Lorsque vous publiez une application web sur Replit, un audit SEO (optimisation pour les moteurs de recherche) est automatiquement exécuté sur l&#39;URL en ligne, et l&#39;outil Publishing affiche un score SEO de 0 à 100. Si le score est perfectible, un simple clic suffit à transmettre les problèmes précis à Agent, qui les corrige en quelques secondes.

Pour la plupart des créateurs, le flux de travail se résume à ceci : publier l&#39;application, consulter le score, puis demander à Agent d&#39;« optimiser le SEO ». Cette page explique ce qui se passe en coulisses et comment en tirer le meilleur parti.

<div id="seo">
  ## Qu&#39;est-ce que le SEO et pourquoi est-ce important ?
</div>

Le SEO (optimisation pour les moteurs de recherche) consiste à concevoir votre site de façon à ce que les moteurs de recherche comme Google le trouvent facilement. Avec un bon référencement, votre application apparaît en tête des résultats lorsque les utilisateurs effectuent une recherche pertinente, sans dépenser un centime en publicité.

Les éléments qui influencent le plus les résultats SEO sont des titres et descriptions de page clairs, un HTML sémantique, un chargement rapide, une mise en page adaptée aux mobiles, un texte alternatif descriptif pour les images et une structure de site explorable. Les moteurs de recherche privilégient les sites lisibles aussi bien par les humains que par les machines.

Que vous lanciez une page de destination, un site marketing, un blog ou un annuaire, dès lors qu&#39;être découvert compte, le SEO est l&#39;un des investissements les plus rentables à faire dès le départ.

<div id="replitseo">
  ## Comment Replit met en place les fondamentaux du SEO
</div>

Replit prend en charge à votre place une grande partie des fondamentaux du SEO, afin que vous puissiez vous concentrer sur votre contenu et votre produit :

* **Hébergement rapide et distribué à l&#39;échelle mondiale** : les déploiements Replit diffusent votre application depuis une infrastructure optimisée pour la vitesse, et les [régions de publication](/fr/ja/features/publishing/publishing-geography) vous permettent de choisir où elle s&#39;exécute.
* **HTTPS par défaut** : toutes les applications publiées bénéficient automatiquement d&#39;un certificat TLS géré par Replit, un signal de classement fondamental pour les moteurs de recherche.
* **Domaines personnalisés** : connectez votre propre domaine pour renforcer la confiance et l&#39;autorité de votre marque. Consultez [Domaines personnalisés](/fr/ja/features/publishing/custom-domains).
* **Déploiements statiques pour les sites de contenu** : pour les pages marketing, les blogs et la documentation, les [déploiements statiques](/fr/ja/features/publishing/static-deployments) diffusent un HTML prérendu que les moteurs de recherche explorent facilement.
* **Agent génère du code pensé pour le SEO** : lorsqu&#39;Agent crée vos pages, il produit par défaut du HTML sémantique, un balisage accessible et des balises meta, soit exactement les éléments que vérifient les outils SEO.
* **Fonctionnalité de score SEO** : un audit automatique après publication vous permet de faire le point à tout moment et de transmettre les problèmes détectés à Agent en un clic.

<div id="seo-2">
  ## Fonctionnalité de score SEO
</div>

À chaque publication réussie, Replit exécute un audit Lighthouse sur l&#39;URL du déploiement et en enregistre les résultats. L&#39;outil Publishing affiche le score SEO global de votre application.

<div id="section">
  ### Comment le consulter
</div>

Ouvrez l&#39;outil **Publishing** dans une application publiée. Le score SEO apparaît dans l&#39;aperçu du déploiement, aux côtés des autres détails de build. Survolez le score pour découvrir les actions concrètes signalées par Lighthouse sur chaque page.

<div id="section-2">
  ### Comment lire le score
</div>

Replit utilise les seuils standards de Lighthouse :

| Score    | Statut      | Signification                                                                                                |
| :------- | :---------- | :----------------------------------------------------------------------------------------------------------- |
| 90 à 100 | Bon         | Les bonnes pratiques SEO sont respectées. Continuez à surveiller après toute modification importante.        |
| 50 à 89  | À améliorer | Certains problèmes empêchent les moteurs de recherche de bien comprendre votre application.                  |
| 0 à 49   | Mauvais     | Des fondamentaux SEO essentiels sont absents. Les corrections ne prennent généralement que quelques minutes. |

Si votre application comporte plusieurs pages, le badge affiche le score le **plus bas** parmi toutes les URL explorées par Replit. La page la moins performante apparaît ainsi en premier, sans être masquée par une moyenne.

<div id="section-3">
  ### Quand le score est-il calculé ?
</div>

L&#39;audit s&#39;exécute automatiquement après chaque publication réussie. L&#39;évaluation se termine généralement dans un délai d&#39;une à deux minutes après la mise en ligne du déploiement, et le badge de l&#39;outil Publishing se met à jour dès que les résultats sont disponibles.

<div id="section-4">
  ### Types de déploiement pris en charge
</div>

Le score SEO est calculé pour les déploiements web publics dont l&#39;URL peut être explorée par les moteurs de recherche :

* [Déploiements Autoscale](/fr/ja/features/publishing/autoscale-deployments)
* [Déploiements Reserved VM](/fr/ja/features/publishing/reserved-vm-deployments)
* [Déploiements statiques](/fr/ja/features/publishing/static-deployments)

Les déploiements planifiés ou privés ne reçoivent pas de score SEO, car ils ne diffusent pas de trafic web public.

<div id="agentseo">
  ## Optimisation du SEO par Agent
</div>

Si votre score SEO est inférieur à 90, un bouton **Optimize SEO with Agent** s&#39;affiche à côté du score. En le sélectionnant, vous envoyez directement dans une nouvelle discussion Agent les actions concrètes à mener pour toutes les URL analysées par Lighthouse, accompagnées des instructions de correction.

<Tip>
  Vous n&#39;êtes pas obligé de passer par ce bouton. Ouvrez simplement Agent et demandez-lui d&#39;**optimiser le SEO** : il récupérera les derniers résultats de Lighthouse et se mettra au travail.
</Tip>

Une fois qu&#39;Agent a terminé ses modifications, republiez votre application. Le score SEO est recalculé sur la nouvelle version et le badge se met à jour automatiquement.

Corrections courantes appliquées par Agent :

* Ajouter ou réécrire les balises `<title>` manquantes ou génériques afin que chaque page ait un titre unique et descriptif
* Ajouter une méta-description à toutes les pages
* Ajouter un texte `alt` descriptif aux images
* Définir l&#39;attribut `lang` sur l&#39;élément `<html>`
* Donner aux liens un texte explicite (éviter « cliquez ici » et les ancres vides)
* Ajouter `robots.txt` et `sitemap.xml`
* Ajouter la balise méta viewport pour le rendu mobile
* Améliorer le contraste des couleurs du texte qui échoue aux contrôles d&#39;accessibilité
* Ajouter les balises méta Open Graph et Twitter Card pour améliorer les aperçus de liens sur les réseaux sociaux

<div id="replit-seo">
  ## Bonnes pratiques pour un site optimisé pour le SEO sur Replit
</div>

Que vous confiiez le travail à Agent ou que vous le rédigiez vous-même, voici les points les plus efficaces pour les applications créées sur Replit :

* **Donnez à chaque page un titre et une méta-description uniques.** Visez 60 caractères maximum pour le titre et environ 150 à 160 caractères pour la description.
* **Utilisez du HTML sémantique.** Structurez votre mise en page avec `<main>`, `<header>`, `<nav>` et `<footer>`. N&#39;utilisez `<h1>` qu&#39;une seule fois par page et respectez l&#39;ordre des niveaux de titres.
* **Ajoutez un texte alternatif à toutes les images.** Décrivez ce que l&#39;image montre, et pas seulement ce qu&#39;elle est.
* **Générez `sitemap.xml` et `robots.txt`.** Demandez à Agent de créer les deux afin que les moteurs de recherche sachent ce qu&#39;ils doivent explorer.
* **Ajoutez les balises Open Graph et Twitter Card.** Vous contrôlez ainsi l&#39;apparence de votre application lorsqu&#39;elle est partagée sur les réseaux sociaux.
* **Utilisez un domaine personnalisé.** Un domaine à votre marque inspire confiance aux visiteurs comme aux moteurs de recherche. Consultez [Domaines personnalisés](/fr/ja/features/publishing/custom-domains).
* **Choisissez le type de déploiement adapté.** Pour les sites riches en contenu, les [déploiements statiques](/fr/ja/features/publishing/static-deployments) diffusent du HTML pré-rendu, que les moteurs de recherche analysent instantanément.
* **Ajoutez des données structurées.** Le balisage JSON-LD aide les moteurs de recherche à afficher des résultats enrichis pour les produits, articles, FAQ et événements.
* **Gardez votre application rapide.** Optimisez les images, évitez les scripts qui bloquent le rendu et tirez parti de l&#39;hébergement Replit pour maintenir des temps de réponse faibles.

Une méthode simple pour appliquer la plupart de ces points en une seule fois :
