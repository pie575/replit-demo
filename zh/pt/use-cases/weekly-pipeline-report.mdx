从 HubSpot 拉取本周的销售管道，与上周对比，写一份简短报告：新增交易、阶段变动、逾期交易和预测。
把表格放到 Google Sheets，并把重点发布到 Slack，让站会聚焦于变化，而不是一张静态快照。

连接 HubSpot、Sheets 和 Slack，并说明要包含哪条销售管道或哪个团队。

<div id="d-o-prompt-ao-agente">
  ## 向 Agent 提供 prompt
</div>

<AiPrompt>
  创建一个每周一上午 9 点运行的例程。从 HubSpot 拉取本周的销售管道。撰写一份周报，展示销售管道
  的变化和趋势：新增交易、阶段变动、逾期交易，以及预测与上周的对比。将表格写入 Google
  Sheets，并将重点内容发布到 Slack。
</AiPrompt>

<div id="o-que-esperar">
  ## 预期内容
</div>

Agent 会将本周与上周进行比较，并生成一份简短摘要和一份电子表格。
在 HubSpot 中核对几个交易的数值。在站会上分享 Slack 中的重点内容；
保留电子表格以备审计。选择一个新交易和一个逾期交易，在 HubSpot 中打开它们，并确认其阶段、金额和成交日期与
电子表格一致。

<div id="soluo-de-problemas">
  ## 故障排除
</div>

* **交易金额与 HubSpot 不一致：**说明要纳入哪个销售管道或团队，以及使用哪个金额字段 (金额还是加权预测) 。在信赖该电子表格前，请先抽查几笔交易是否与 HubSpot 一致。
* **逾期交易看起来不对：**请在 HubSpot 中确认成交日期和交易阶段。要求 Agent 仅在成交日期被推迟或交易阶段回退时，才将交易视为逾期。
* **Slack 发布到了错误的位置：**请指定频道，并说明你是只需要重点信息，还是需要完整电子表格的链接。
