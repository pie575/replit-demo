<div id="por-que-as-skills-importam">
  ## 为什么 skills 很重要
</div>

每次使用 Agent 构建时，您都会积累有用的上下文，例如问题解决方案、设计决策或框架偏好。但聊天结束后，这些上下文就会消失。Skills 可以将其保留下来。

GSAP 动画 skill 可教 Agent 正确使用特定库。设计系统 skill 可确保它准确应用您的颜色和间距规则。Bug 修复 skill 会记录解决方案，避免 Agent 重复犯同样的错误。原本不一致的任务也会变得可靠。

Skills 还是一种[开放标准](https://agentskills.io/specification)。它们可与任何 Agent 配合使用，包括 Replit Agent，因此您可以在不同工具中复用它们。

<div id="incio-rpido-use-uma-skill-no-chat">
  ## 快速入门：在 Chat 中使用 skill
</div>

体验 skill 的最快方式是将其添加到消息中：

<Steps>
  <Step title="打开 skill 选择器">
    点击 Chat 输入框旁的 **+** 按钮，然后选择 **使用 skill**。
  </Step>

  <Step title="浏览并选择 skill">
    按类别浏览 skill，例如商业与金融、创意、研究与分析等。选择一个或多个 skill 添加到消息中。
  </Step>

  <Step title="发送消息">
    输入你的请求并发送。Agent 仅会针对这条消息使用所选 skill。你的消息中会显示 skill 标签，方便你查看哪些 skill 正在使用。
  </Step>
</Steps>

例如，选择 **股票分析器** 并让 Agent 创建一份股票研究报告，或选择 **深度研究**，让 Agent 针对复杂主题进行调研并提供结构化结果。

<Tip>
  无需安装任何内容即可使用 Chat 选择器中的 skill。所有项目中都可立即使用。
</Tip>

<div id="instale-skills-no-seu-projeto">
  ## 在项目中安装 skills
</div>

如果你希望 Agent 在项目的所有 Conversation 中始终应用某项 skill，请安装该 skill。已安装的 skills 位于项目的 `/.agents/skills` 目录中，并会在不同聊天会话之间保留。

<div id="descubra-e-instale-pelo-painel-de-skills">
  ### 通过 Skills 面板发现并安装
</div>

在项目编辑器中打开 **Skills 面板**，选择 **发现** 选项卡，搜索社区贡献的 skills。找到所需的 skill 后，点击 **安装**，它会自动添加到你的项目中。

<Frame>
  <img src="/assets/mirror/agent-skills-discover-732b2b0c488a.png" alt="Skills 发现选项卡，显示社区贡献的 skills 及安装按钮" width="2542" height="1850" data-path="images/replitai/agent-skills-discover.png" />
</Frame>

例如，构建带有高级动画的[作品集网站](https://palmer.gg)时，你可以安装：

* **GSAP React** — 教 Agent 实现滚动触发动画、文本揭示和 SVG 路径绘制
* **Tailwind design system** — 为 Agent 提供 Tailwind CSS 中有关排版、间距和视图过渡模式的知识
* **Find skills** — 教 Agent 代你发现并安装新的 skills

<Tip>
  你也可以通过 [npx skills CLI](https://github.com/vercel-labs/skills) 安装 skills：

  ```bash theme={null}
  npx skills <skill> -a replit
  ```
</Tip>

<div id="crie-skills-por-meio-de-conversas">
  ### 通过对话创建 skill
</div>

创建 skill 最自然的方式是与 Agent 对话。在共同解决问题或研究新的库后，让 Agent 将学到的内容整理下来：

<AiPrompt>
  研究 GSAP 与 React 集成的最佳实践，并为此项目创建一个 skill。
</AiPrompt>

Agent 会利用整个对话的上下文，编写详细的 skill 文件。这在调试会话结束后尤其有效，因为此时你们已对问题形成共同的理解。

<div id="escreva-skills-personalizadas">
  ### 编写自定义 skills
</div>

对于高级使用场景，请直接按照 [Agent Skills 规范](https://agentskills.io/specification)编写 skills。在文件侧边栏中启用 **显示隐藏文件**，打开 `/.agents/skills/`，然后新建一个 Markdown 文件。这样你就能完全掌控 Agent 知道什么以及它如何运作。

<div id="skills-proativas-vs-reativas">
  ## 主动型 skills 与被动型 skills
</div>

这是一个帮助你思考何时以及如何创建 skills 的框架。了解这两种模式能让你更高效。

<div id="skills-proativas">
  ### 主动 skills
</div>

主动 skills 是指在开始构建*之前*添加的 skills。你先研究想使用的库或模式，为其查找或创建 skills，然后再开始编写提示词。

**真实示例：**在构建包含手绘 SVG 动画的作品集网站之前，你研究动画库并找到了 GSAP。你安装了一个 GSAP React skill，然后让 Agent 构建这些动画。Agent 从一开始就具备所需的专业知识——了解该库的 API、最佳实践和常见模式。没有这个 skill，它可能会生成千篇一律或不正确的内容。

此模式适用于以下情况：

* 你使用的是一个流行的库，但其中包含 Agent 可能无法自行掌握的细微模式
* 你希望整个项目的设计选择保持一致 (排版、间距、动画风格)
* 你正在启动一个项目，并且已经明确技术方向

<div id="skills-reativas">
  ### 反应式 skill
</div>

反应式 skill 是指你在解决问题*之后*创建的 skill。你发现问题，借助 Agent 进行调试并修复，然后将解决方案记录下来，避免问题再次发生。

**真实示例：**在为移动应用构建 Canvas 时，你发现图像边缘出现锯齿，且放大后更加明显。通过 Agent 调试后发现，这是缩小混叠问题——一种违反直觉的渲染问题：图像缩小时反而会变得更差。实施修复后，你让 Agent 创建一个 skill：

<AiPrompt>
  创建一个 skill，记录我们刚刚了解到的有关修复缩小混叠的内容。包括根本原因、解决方案，以及此问题通常出现的情况，以便将来预防它。
</AiPrompt>

Agent 会利用对话历史编写一个项目专属的 skill。下次再出现这个问题时，你可以让 Agent 参考该 skill，而无需从头开始调试。

这种模式适用于以下情况：

* 你修复了一个不易察觉的 bug，并希望避免它再次出现
* 你在调试过程中加深了对应用架构的了解
* 你希望将一个花费大量精力才找到的解决方案固化下来

<div id="seja-seletivo-com-as-skills">
  ## 谨慎选择 skills
</div>

把 skills 想象成你给朋友指路、帮助他们找到你公寓的说明。一份有针对性的说明清单很有效；塞满文档的文件夹则不行——没人有时间通读所有内容，重要细节也会被埋没。

Agent 也是如此。如果添加过多 skills，Agent 可能会无所适从。请谨慎选择要为特定项目启用的 skills，并移除不再需要的 skills。

<Note>
  Skills 最适合用于记录具体、可重复的模式，而非提供泛泛的指导。请专注于明确的工作流程、既定规范和经过验证的解决方案。
</Note>

<div id="consideraes-de-segurana">
  ## 安全注意事项
</div>

Replit 的 Skills 面板中的 skill 均已通过安全审核。但 skill 可以从任何地方安装——它们来自一个任何人都可以参与贡献的[开源仓库](https://github.com/vercel-labs/skills)。

由于 skill 是 Agent 会遵循的指令，恶意 skill 可能会指示 Agent 将您项目中的敏感数据外传。安装任何外部来源的 skill 之前：

1. **打开文件** — skill 只是 Markdown 文件。使用前，请阅读 `/.agents/skills/` 中的内容。
2. **验证来源** — 确认该 skill 来自可信的仓库或作者。
3. **检查其指令内容** — 确保该 skill 未引用可疑的外部 URL，也未要求提供敏感信息。

<Warning>
  安装前务必检查来自外部来源的 skill。Replit 的 Skills 面板中的 skill 已通过审核，但通过 CLI 安装或从互联网复制的 skill 尚未经过审核。
</Warning>

<div id="skills-vs-servidores-mcp">
  ## Skills 与 MCP 服务器
</div>

这是 2026 年扩展智能体的两种主要方式，各自适用于不同场景。

**Skills** 的上下文开销较低。在调用 skill 之前，只会加载简短描述。使用 skills 来处理：

* 工作流程和约定 (“如何部署”“代码审查清单”)
* 参考资料 (API 模式、风格指南、设计系统)
* 可复用提示词和专业知识 (动画库、框架模式)

**MCP 服务器** 的上下文开销较大。所有工具描述都会预先加载；如果添加过多，可能会降低输出质量。使用 MCP 服务器来处理：

* 连接外部服务 (Notion、Linear、Figma)
* 需要访问 API 的操作
* 能够*执行*操作而不只是提供指导的工具

关键区别在于：skills 定义了智能体应当*如何*工作；MCP 服务器定义了智能体能够访问*什么*。两者都适用于 Replit Agent 等编程智能体，也适用于你使用 [Claude Agent SDK](/zh/pt/tutorials/claude-agent-sdk) 等工具自行构建的智能体。
