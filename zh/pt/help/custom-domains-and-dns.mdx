以下内容涵盖如何连接自定义域名及排查相关问题。完整说明请参阅[添加自定义域名](/zh/pt/build/add-custom-domain)和[自定义域名](/zh/pt/features/publishing/custom-domains)。

<AccordionGroup>
  <Accordion title="如何将自定义域名连接到我的 Replit 应用？">
    如果你通过 Replit 购买了域名，DNS 记录将由系统为你管理——打开 **发布 → 域名**，然后按照产品内的设置流程操作。请参阅[购买域名](/zh/pt/build/domain-purchasing)。

    若要连接在外部注册商处注册的域名：

    1. 打开你的项目，前往 **发布 → 域名**。
    2. 选择**连接你自己的域名**，输入域名后继续。
    3. Replit 会显示一条 A 记录和一条 TXT 记录——复制这两条记录。
    4. 在你的 DNS 提供商处添加这两条记录。
    5. 返回 Replit 并开始检查。

    注意以下事项：

    * SSL 需要同时具备 A 记录和 TXT 记录。不支持根域名 CNAME——请为根域名使用 A 记录。
    * 不支持通配符证书 (`*.example.com`) ；请分别连接每个子域名。
    * 在 Cloudflare 中，将 A 记录设置为**仅 DNS** (灰色云朵) ，避免代理模式阻碍 SSL 配置。
    * DNS 更改最多可能需要 48 小时才能生效。

    有关完整说明，请参阅[自定义域名](/zh/pt/features/publishing/custom-domains)。
  </Accordion>

  <Accordion title="我的域名无法验证，或者 SSL 未能配置——该如何排查？">
    请按以下顺序检查——大多数问题都由其中一项导致：

    1. **等待 DNS 传播。** 更改最多可能需要 48 小时才能生效。使用 DNS 查询工具确认你的记录在全球范围内均可见。
    2. **删除 AAAA 记录。** 与 A 记录使用相同主机名的 IPv6 (AAAA) 记录可能会阻碍 SSL 配置。
    3. **删除旧的或冲突的 A 记录。** 根域名上应只保留一条指向 Replit 的 A 记录。
    4. **将 Cloudflare 设置为仅 DNS。** 橙色云朵 (代理模式) 会干扰 SSL 配置。
    5. 在 **发布 → 域名 → 管理** 中**断开并重新连接域名**，以强制签发新证书；随后等待几分钟并刷新页面。
    6. **检查 CAA 记录。** 如果你有 CAA 记录，至少有一条必须允许 Let&#39;s Encrypt 作为签发机构，因为 Replit 通过它签发证书。

    这些检查适用于在外部注册的域名。如果你通过 Replit 购买了域名，请[联系 Replit 支持](https://replit.com/support)。有关详情，请参阅[自定义域名](/zh/pt/features/publishing/custom-domains)。
  </Accordion>

  <Accordion title="如何为自定义域名配置 Clerk 身份验证？">
    在自定义域名上使用 [Clerk 身份验证](/zh/pt/features/auth-and-identity/clerk-auth) 时，可能会遇到以下常见问题：

    * **“需要 Clerk CNAME 记录”警告。** 这是 Clerk 的集成要求，不会影响域名检查或 SSL 配置。打开 **发布 → 域名**，选择**管理**，找到身份验证 DNS 配置部分，并在你的 DNS 提供商处逐条准确添加列出的 CNAME 记录。如果该部分未显示，请断开并重新连接域名。
    * **之前使用 Clerk 后，域名一直卡在“正在验证”。** 如果该域名曾关联到其他 Clerk 应用，请在你的 [Clerk 控制台](https://dashboard.clerk.com)中将其移除，然后在 Replit 中断开并重新连接域名。
    * **迁移到自己的 Clerk 实例。** 从 Replit 托管的 Clerk 切换到自己的实例需要手动操作——请[联系 Replit 支持](https://replit.com/support)。请参阅[我可以使用自己的 Clerk 应用，而不是 Replit 托管的应用吗？](/zh/pt/features/auth-and-identity/clerk-auth#can-i-bring-my-own-clerk-app-instead-of-using-the-replit-managed-one)

    如果仍有问题，请[联系 Replit 支持](https://replit.com/support)，并提供你的域名、项目名称以及已尝试的操作。
  </Accordion>
