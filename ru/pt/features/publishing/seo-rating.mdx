При публикации веб-приложения в Replit для ваших активных URL автоматически выполняется аудит поисковой оптимизации (SEO), а в инструменте Publishing отображается оценка SEO. Если оценке SEO есть куда расти, одним кликом можно передать конкретные проблемы Agent, чтобы исправить их за считаные секунды.

Для большинства авторов весь процесс выглядит так: опубликуйте приложение, взгляните на оценку SEO и попросите Agent &quot;оптимизировать мой SEO&quot;. На этой странице рассказано, что происходит под капотом и как получить максимум от этой возможности.

<div id="o-que-seo-e-por-que-importa">
  ## Что такое SEO и почему это важно
</div>

Поисковая оптимизация (SEO) — это создание сайта таким образом, чтобы поисковые системы вроде Google могли найти его, понять его содержимое и ранжировать его в выдаче. Хорошее SEO означает, что ваше приложение появляется в результатах поиска, когда люди ищут то, что вы предлагаете, — без затрат на рекламу.

Большую часть результата в SEO обеспечивают несколько вещей: понятные заголовки и описания страниц, семантическая HTML-разметка, быстрая загрузка, адаптированные под мобильные устройства макеты, содержательный альтернативный текст у изображений и структура сайта, доступная для сканирования. Поисковые системы поощряют сайты, которые легко читаются и людьми, и машинами.

Если вы запускаете лендинг, маркетинговый сайт, блог, каталог или что-либо ещё, где важно, чтобы вас находили, SEO — одно из самых результативных вложений, которое можно сделать с самого начала.

<div id="como-o-replit-melhora-o-seu-seo-por-padro">
  ## Как Replit улучшает ваше SEO по умолчанию
</div>

Replit берёт на себя многие базовые задачи SEO, чтобы вы могли сосредоточиться на контенте и продукте:

* **Быстрый хостинг с глобальным распределением**: Replit Deployments обслуживают ваше приложение на инфраструктуре, оптимизированной для скорости, а регион запуска приложения можно выбрать с помощью [географии project](/ru/pt/features/publishing/project-geography).
* **HTTPS по умолчанию**: каждое опубликованное приложение получает TLS-сертификат под управлением Replit — это базовый фактор ранжирования для поисковых систем.
* **Пользовательские домены**: подключите собственный домен, чтобы укрепить доверие и авторитет бренда. См. [Custom Domains](/ru/pt/features/publishing/custom-domains).
* **Static Deployments для контентных сайтов**: для маркетинговых страниц, блогов и документации [Static Deployments](/ru/pt/features/publishing/deployment-types#static) отдают предварительно отрендеренный HTML, который поисковые системы легко сканируют.
* **Agent пишет код с учётом SEO**: создавая ваши страницы, Agent по умолчанию формирует семантический HTML, доступную разметку и мета-теги — именно то, что проверяют SEO-инструменты.
* **Оценка SEO**: автоматический аудит после каждой публикации, чтобы вы всегда знали текущее положение дел, вместе с передачей задачи в один клик — Agent исправит найденные проблемы.

<div id="a-classificao-de-seo">
  ## Оценка SEO
</div>

После каждой успешной публикации Replit выполняет аудит Lighthouse для URL-адресов вашего deployment и сохраняет результаты. Затем инструмент Publishing показывает общую оценку SEO вашего приложения.

<div id="onde-encontrar">
  ### Где найти
</div>

Откройте инструмент **Publishing** в опубликованном приложении. Оценка SEO отображается в обзоре deployment вместе с остальными сведениями о сборке. Наведите курсор на оценку, чтобы увидеть конкретные рекомендации, которые Lighthouse определил для каждой страницы.

<Note>
  Если оценки SEO нет, ваше приложение, скорее всего, приватное или давно не публиковалось. Оценка отображается только для опубликованных публичных веб-приложений.
</Note>

<div id="como-interpretar-sua-classificao">
  ### Как интерпретировать оценку
</div>

Replit отображает одну из трёх оценок по результатам аудита Lighthouse:

| Оценка     | Что это значит                                                                              |
| :--------- | :------------------------------------------------------------------------------------------ |
| Healthy    | Ваше приложение соответствует лучшим практикам SEO. Проверяйте его после крупных изменений. |
| Needs Work | Ряд проблем мешает поисковым системам корректно разобрать приложение.                       |
| Weak       | Базовые элементы SEO отсутствуют. Как правило, на их исправление уходит всего пара минут.   |

Если в приложении несколько страниц, значок показывает **самую низкую** оценку среди всех URL, просканированных Replit, — так худшая страница видна сразу, а не теряется в среднем значении.

<div id="quando-a-classificao-calculada">
  ### Когда рассчитывается оценка
</div>

Аудит выполняется автоматически после каждой успешной публикации. Оценка обычно появляется через одну-две минуты после запуска deployment, а инструмент Publishing обновляет значок, как только приходят результаты.

<div id="tipos-de-deployment-compatveis">
  ### Поддерживаемые типы deployment
</div>

оценка SEO рассчитывается для публичных веб-deployment, URL которых поисковые системы могут сканировать:

* [Autoscale Deployments](/ru/pt/features/publishing/deployment-types#autoscale)
* [Reserved VM Deployments](/ru/pt/features/publishing/deployment-types#reserved-vm)
* [Static Deployments](/ru/pt/features/publishing/deployment-types#static)

Для scheduled deployments и private deployments оценка SEO не рассчитывается, так как они не обслуживают публичный веб-трафик.

<div id="otimizar-seo-com-o-agent">
  ## Оптимизация SEO с помощью Agent
</div>

Рядом с вашей оценкой появляется кнопка **Optimize SEO with Agent**. По нажатии на неё открывается [SEO Agent](/ru/pt/features/publishing/seo-agent) на панели Growth, где можно провести технический SEO-аудит, просмотреть найденные проблемы и применить исправления в один клик.

<Tip>
  Кнопку можно и вовсе не использовать. Откройте Agent и напишите **«optimize my SEO»** — Agent возьмёт последние результаты и начнёт с ними работать.
</Tip>

После того как Agent внесёт изменения, опубликуйте приложение повторно. Оценка SEO пересчитывается на основе новой сборки, а значок обновляется автоматически.

Типичные исправления, которые применит Agent:

* Добавление или переписывание отсутствующих либо шаблонных тегов `<title>`, чтобы у каждой страницы был уникальный и содержательный заголовок
* Добавление meta description на каждую страницу
* Добавление описательного текста `alt` к изображениям
* Установка атрибута `lang` у элемента `<html>`
* Проверка того, что у ссылок есть понятный текст (без «нажмите здесь» и пустых якорей)
* Добавление `robots.txt` и `sitemap.xml`
* Добавление meta-тега viewport для корректного отображения на мобильных устройствах
* Улучшение цветового контраста текста, не проходящего проверки доступности
* Добавление meta-тегов Open Graph и Twitter card, чтобы ссылки на ваше приложение корректно отображались в социальных сетях

<div id="melhores-prticas-para-um-site-otimizado-para-seo-no-replit">
  ## Лучшие практики для SEO-оптимизированного сайта на Replit
</div>

Поручите ли вы эти задачи Agent или сделаете всё сами — вот что важнее всего сделать правильно в приложении, созданном на Replit:

* **Задайте каждой странице уникальный заголовок и meta description.** Старайтесь укладывать заголовки в 60 символов, а descriptions — примерно в 150–160 символов.
* **Используйте семантический HTML.** Оберните макет в `<main>`, `<header>`, `<nav>` и `<footer>`. Используйте `<h1>` один раз на странице и соблюдайте последовательность уровней заголовков.
* **Добавьте alt-текст к каждому изображению.** Описывайте, что изображение показывает, а не просто чем оно является.
* **Сгенерируйте `sitemap.xml` и `robots.txt`.** Попросите Agent создать оба файла, чтобы поисковые системы знали, что индексировать.
* **Добавьте теги Open Graph и Twitter card.** Управляйте тем, как ваше приложение выглядит при публикации в социальных сетях.
* **Используйте собственный домен.** Брендированный домен вызывает доверие у посетителей и поисковых систем. См. [Custom Domains](/ru/pt/features/publishing/custom-domains).
* **Выберите подходящий тип deployment.** Для сайтов с большим объёмом контента [Static Deployments](/ru/pt/features/publishing/deployment-types#static) отдают предварительно отрендеренный HTML, который поисковые системы разбирают мгновенно.
* **Добавьте структурированные данные.** Разметка JSON-LD помогает поисковым системам показывать расширенные результаты для товаров, статей, FAQ и событий.
* **Следите за скоростью приложения.** Оптимизируйте изображения, избегайте скриптов, блокирующих отрисовку, и используйте хостинг Replit, чтобы держать время отклика низким.

Простой способ применить бо́льшую часть этого за один раз:

<AiPrompt>
  Audit my site for SEO best practices and apply the fixes. Add a sitemap, robots.txt, Open Graph tags, structured data where it makes sense, and make sure every page has a unique title and meta description.
</AiPrompt>
