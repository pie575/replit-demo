<div id="section">
  ## Suggestions de tâches de suivi
</div>

Après avoir appliqué une tâche, Agent examine le contexte de votre projet et suggère des **tâches de suivi** que vous pourriez vouloir effectuer ensuite. La boîte de dialogue **Suggestions pour la prochaine tâche** affiche directement les principales recommandations afin que vous puissiez continuer sans quitter le fil principal.

</Frame>

Les suggestions de suivi peuvent inclure :

* **De nouvelles fonctionnalités à créer** : des fonctionnalités qui complètent naturellement ce que vous venez de publier
* **Des améliorations de performances** : des optimisations qu&#39;Agent a repérées en travaillant sur la tâche
* **Des améliorations de l&#39;expérience utilisateur** : des finitions et améliorations qui complètent la fonctionnalité

Sélectionnez **Démarrer** sur une suggestion pour l&#39;envoyer en arrière-plan, ou sélectionnez **Examiner le plan** pour consulter d&#39;abord le travail proposé. Pour afficher toutes les suggestions, sélectionnez **Afficher les détails dans le tableau des tâches**. Les suivis suggérés apparaissent sous **Suggérées** dans la colonne **Brouillons**.

<Frame>
  <img src="/assets/mirror/follow-up-tasks-kanban-21087e0210b6.png" alt="Tableau des tâches affichant de nombreuses suggestions de tâches de suivi sous Suggérées dans la colonne Brouillons" width="980" height="627" data-path="images/agent/follow-up-tasks-kanban.png" />
</Frame>

Fermer la boîte de dialogue **Suggestions pour la prochaine tâche** annule les suggestions. Si un plan suggéré est déjà en attente dans la version principale, Agent n&#39;affiche pas la boîte de dialogue afin d&#39;éviter tout conflit entre deux prompts.

<div id="section-2">
  ## Gérer plusieurs suggestions à la fois
</div>

Pour les projets comportant de nombreuses suggestions de suivi, ouvrez le tableau des tâches et sélectionnez **Modifier** dans la colonne **Brouillon**. En mode édition, chaque tâche proposée est accompagnée d’une case à cocher. Sélectionnez les tâches souhaitées, puis utilisez **Démarrer** ou **Annuler** pour appliquer cette action à toutes les tâches sélectionnées. Sélectionnez **Terminé** pour quitter le mode édition.
