---
title: "workspace 地理位置"
description: "选择 Workspace 的开发资源及其新项目的托管位置。"
---

workspace 地理位置决定 Workspace 的开发资源托管在哪个区域。你在创建 Workspace 时选择该位置，之后该 Workspace 中新建的项目和资源都会使用所选位置。

<Note>
  workspace 地理位置与[发布地理位置](/zh/pt/features/security/geography#publishing-geography)可以不同。发布地理位置决定已发布项目的运行位置。
</Note>

<div id="o-que-a-geografia-do-workspace-controla">
  ## workspace 地理位置控制哪些内容
</div>

Workspace 汇集了项目、人员、设置、共享资源、集成和账单。在每个项目中，你可以使用 Project Editor 和 Replit 聊天。开发资源包括应用的开发版本及其开发数据库。

只有 Pro 客户才能为 workspace 指定特定区域。

Free 和 Core 客户的 workspace 区域由系统自动设定，通常会选择离你最近的 workspace 区域。workspace 中新建的项目和资源都会使用该位置。workspace 创建完成后，其区域将无法更改。

<div id="selecione-uma-regio-para-o-workspace">
  ## 为 workspace 选择区域
</div>

如果你是 Pro 客户，可以在创建 workspace 时选择区域：

<Steps>
  <Step>打开 **Create a new workspace** 表单。</Step>

  <Step>
    输入 workspace 名称，也可以选填成员的电子邮件地址。
  </Step>

  <Step>
    展开 **Workspace region**，选择 **North America**、**Europe (EU)**
    或 **Asia**。
  </Step>

  <Step>选择 **Create workspace**。</Step>
</Steps>

<div id="geografias-disponveis">
  ## 可用地理区域
</div>

| 地理区域              | 可在 workspace 中选择 |
| :---------------- | :--------------- |
| **North America** | 是                |
| **Europe (EU)**   | 是                |
| **Asia**          | 是                |
| **South America** | 否                |
| **Australia**     | 否                |
