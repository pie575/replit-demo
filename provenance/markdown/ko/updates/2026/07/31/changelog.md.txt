## Workspace

### Replit Design가 출시되었습니다

Replit Design이 정식 출시되었습니다. 만들고 싶은 것을 설명하고, 인터랙티브 목업을 살펴보며, 방향을 다듬어 보세요. 프레임이 준비되면 Core 및 Pro 사용자는 동일한 프로젝트에서 이를 실제로 동작하는 앱으로 전환할 수 있습니다.

## Agent

### Agent의 기본 모델 선택

이제 작업에 사용할 Agent의 기본 모델을 선택할 수 있습니다. Lite, Economy, Power 중에서 선택한 다음 해당 모드에서 사용 가능한 모델을 고를 수 있습니다. Lite는 이제 모바일 앱을 포함해 Agent를 사용할 수 있는 모든 곳에서 제공됩니다. 사용 가능한 모델은 조직, 권한, Turbo 액세스 여부에 따라 다릅니다.

### 더 많은 MCP 서버 연결

적격 워크스페이스는 사전 등록된 MCP 서버 카탈로그에서 Supabase, Statsig, Calendly에 연결할 수 있습니다. 또한 Replit은 공식 Braintrust MCP 엔드포인트를 인식하며, 수동으로 추가하면 해당 서버의 OAuth 로그인 절차를 시작합니다.
