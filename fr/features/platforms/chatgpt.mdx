L'intégration Replit dans ChatGPT vous permet de créer, mettre à jour et inspecter des applications Replit directement depuis vos conversations — sans configuration requise. Créez de vraies applications en parlant à ChatGPT et laissez l'Agent s'occuper du reste.

## Qu'est-ce que Replit dans ChatGPT

Replit dans ChatGPT connecte vos conversations ChatGPT à la puissante plateforme de développement de Replit. Vous pouvez décrire ce que vous souhaitez créer, et l'Agent créera pour vous une application Replit entièrement fonctionnelle. Une fois créée, vous pouvez demander à ChatGPT de modifier, mettre à jour ou analyser votre application — tout cela via une conversation naturelle.

## Premiers pas

Suivez ces étapes pour connecter Replit à ChatGPT et créer votre première application.

### Connecter Replit à ChatGPT

Vous pouvez connecter Replit à ChatGPT de deux façons :

<Accordion title="Connexion depuis les Paramètres">
  1. Cliquez sur votre icône de profil dans ChatGPT
  2. Allez dans **Paramètres** → **Applications et connecteurs**
  3. Trouvez **Replit** et cliquez sur **Connecter**
  4. Complétez l'autorisation OAuth avec votre compte Replit
</Accordion>

<Accordion title="Connexion depuis une conversation">
  1. Démarrez une nouvelle conversation dans ChatGPT
  2. Invoquez Replit en utilisant l'une des méthodes ci-dessous
  3. ChatGPT vous guidera à travers le flux OAuth si vous n'êtes pas connecté
</Accordion>

### Invoquer Replit dans ChatGPT

Une fois connecté, vous pouvez invoquer Replit de trois façons :

| Méthode          | Comment l'utiliser                                  |
| ---------------- | --------------------------------------------------- |
| Mention directe  | Tapez `Replit, <requête>` au début de votre message |
| Commande slash   | Tapez `/Replit` dans le compositeur                 |
| Menu compositeur | Cliquez sur le bouton **+** → **Plus** → **Replit** |

### Créer votre première application

Après la connexion, créez votre première application Replit :

1. Démarrez une nouvelle conversation dans ChatGPT
2. Invoquez Replit et décrivez ce que vous souhaitez créer (par exemple, « Replit, crée une application de tâches avec un mode sombre »)
3. L'Agent génèrera votre application et la déploiera automatiquement
4. Une fois terminé, vous recevrez un lien pour voir votre application

<Note>
  Chaque conversation peut travailler avec une seule application Replit. Si vous créez une nouvelle application dans la même conversation, elle modifiera l'application existante. Pour créer plusieurs applications, commencez des conversations séparées.
</Note>

## Fonctionnalités

* **[Replit AI](/fr/build/welcome)** : L'Agent génère et déploie des applications en fonction de vos requêtes en langage naturel
* **[Éditeur de projet](/fr/learn/projects-and-artifacts/project-editor)** : Environnement de développement complet accessible depuis ChatGPT
* **[Publication](/fr/learn/projects-and-artifacts/replit-deployments)** : Les applications sont automatiquement déployées et prêtes à être partagées

<Accordion title="Ce que vous pouvez faire">
  **Créer :** Construire de nouvelles applications Replit en décrivant ce que vous voulez. L'Agent génère l'application et la déploie automatiquement.

  **Mettre à jour :** Modifier l'application dans votre conversation actuelle. Demandez à ChatGPT d'ajouter des fonctionnalités, de corriger des bugs ou d'apporter des modifications, et l'Agent les appliquera.

  **Inspecter :** Analyser votre application sans apporter de modifications. Obtenez des informations sur la structure du code, les chemins de fichiers ou le comportement.
</Accordion>

<Accordion title="Formats de fichiers pris en charge">
  Vous pouvez inclure différents types de fichiers dans vos invites :

  | Format                        | Pris en charge                              |
  | ----------------------------- | ------------------------------------------- |
  | PDF                           | Oui                                         |
  | CSV                           | Oui                                         |
  | Formats de documents courants | Oui                                         |
  | Images (fichiers bruts)       | Non (utilisez des URL publiques à la place) |
  | Vidéos (fichiers bruts)       | Non (utilisez des URL publiques à la place) |

  <Note>
    Pour inclure des images ou des vidéos dans votre application, fournissez des URL publiques dans votre invite. Vous pouvez également ajouter des fichiers multimédias directement dans Replit après la création de l'application.
  </Note>
</Accordion>

<Accordion title="Temps de construction">
  L'Agent construit généralement les applications en :

  | Complexité de l'application                                 | Temps de construction typique |
  | ----------------------------------------------------------- | ----------------------------- |
  | Simple (calculatrices, petites pages d'atterrissage)        | 2–3 minutes                   |
  | Complexe (jeux, animations riches, tableaux de bord denses) | 3–4 minutes                   |
</Accordion>

<Accordion title="Plans ChatGPT">
  L'intégration Replit fonctionne avec tous les types de plans ChatGPT :

  | Plan           | Pris en charge | Notes                                                                                                |
  | -------------- | -------------- | ---------------------------------------------------------------------------------------------------- |
  | Gratuit        | Oui            |                                                                                                      |
  | Plus           | Oui            |                                                                                                      |
  | Pro            | Oui            |                                                                                                      |
  | Business       | Oui            | Nécessite l'activation par l'administrateur dans **Paramètres de l'espace de travail → Connecteurs** |
  | Enterprise/Edu | Oui            | Nécessite l'activation par l'administrateur dans **Paramètres de l'espace de travail → Connecteurs** |

</Accordion>

<Accordion title="Plans Replit">
  Tous les types de plans Replit prennent en charge l'intégration ChatGPT :

  | Plan              | Pris en charge | Notes                                                                       |
  | ----------------- | -------------- | --------------------------------------------------------------------------- |
  | Starter (Gratuit) | Oui            | Applications publiques uniquement                                           |
  | Core              | Oui            | Applications privées, constructions étendues, publication, base de données  |
  | Pro               | Oui            | Allocation de crédits mensuels plus élevée, toutes les fonctionnalités Core |
  | Enterprise        | Oui            | Accès complet aux fonctionnalités                                           |
</Accordion>

## Facturation et crédits

Le travail effectué par Replit dans ChatGPT est facturé comme utilisation de l'Agent Replit sur votre compte Replit.

<Accordion title="Fonctionnement de la facturation">
  * Les plans **Core** et **Pro** incluent des crédits mensuels couvrant l'Agent, la publication et les bases de données jusqu'à votre allocation
  * Vous pouvez acheter des **packs de crédits** qui expirent après six mois et ne se renouvellent pas automatiquement — idéal pour les pics de lancement ou les expériences
  * Utilisez les **limites d'utilisation** et les **budgets** dans les paramètres de facturation de Replit pour limiter les dépenses

  En savoir plus dans la [documentation de facturation IA](/fr/billing/ai-billing).
</Accordion>

## Limitations actuelles

Actuellement, l'application Replit dans ChatGPT :

* Ne peut travailler que sur l'application créée dans cette conversation spécifique
* Ne peut pas ouvrir ou modifier :
  * Les applications créées dans d'autres fils ChatGPT
  * Les applications que vous avez construites directement dans Replit

La parité des fonctionnalités avec l'expérience Replit complète (bases de données, gestion des secrets, contrôles plus avancés de l'éditeur de projet) sera disponible ultérieurement.

## Dépannage

<Accordion title="Replit n'apparaît pas dans Parcourir les applications">
  Si vous ne voyez pas Replit dans **Parcourir les applications**, vérifiez :

  * Si les applications sont disponibles dans votre région
  * Si l'administrateur de votre espace de travail a activé l'application Replit (Business/Enterprise/Edu)
</Accordion>

<Accordion title="Échecs de construction">
  Si les constructions échouent, ouvrez l'application dans Replit :

  * Vérifiez l'utilisation et la facturation
  * Utilisez les points de contrôle et les retours en arrière pour annuler
  * Demandez de l'aide à l'Agent directement dans l'éditeur de projet
</Accordion>
