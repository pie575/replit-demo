  ### Предпросмотр автоматизации для пользователей Agent
</div>

<Frame>
  <video src="/assets/mirror/changelog-01-09-2026-6ad09baf666c.mp4" controls />

Предпросмотр автоматизации теперь доступен всем разработчикам, работающим с Agent. Больше не нужно ждать несколько минут, чтобы увидеть наглядный результат: граф шагов автоматизации появится в предпросмотре за считаные секунды.

<div id="section-3">
  ### Приватные приложения на бесплатных аккаунтах
</div>

Разработчики с бесплатными аккаунтами теперь тоже могут создавать приватные приложения. При этом ограничение бесплатного тарифа на количество приложений сохраняется.

<div id="made-with-replit">
  ### Значок Made with Replit
</div>

<Frame>
  <img src="https://replit.com/badge?caption=Made%20with%20Replit" alt="Значок Made with Replit" noZoom />
</Frame>

Значок «Made with Replit» теперь отображается в приложениях, опубликованных на бесплатном тарифе. Чтобы убрать его, перейдите на Replit Core. По нажатию на значок можно узнать больше о Replit.

<div id="ai">
  ### Новые модели ИИ в интеграциях
</div>

AI-интеграции теперь поддерживают недавно вышедшие модели ИИ:

| Модель                       | Описание                                                                                                                                                                              |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `gpt-5.2`                    | Самая мощная модель OpenAI для экспертных интеллектуальных задач. Первая модель, преодолевшая отметку в 90% на ARC-AGI-1, с контекстным окном в 400K.                                 |
| `claude-opus-4.5`            | Флагманская модель Anthropic, оптимизированная для программирования, агентных сценариев и работы с компьютером. Результат 80,9% на SWE-bench Verified.                                |
| `gemini-3-flash-preview`     | Быстрая модель Google, оптимизированная для агентных рабочих процессов, с контекстом в 1M токенов. Обеспечивает рассуждения уровня, близкого к Pro, при меньшей задержке и стоимости. |
| `gemini-3-pro-preview`       | Продвинутая мультимодальная модель Google с передовыми возможностями рассуждения и знаниями о реальном мире.                                                                          |
| `gemini-3-pro-image-preview` | Модель Google Nano Banana Pro для создания и редактирования высококачественных изображений с точной отрисовкой текста.                                                                |
