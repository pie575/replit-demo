⏰ *Durée estimée : 5 minutes*

Apprenez à créer des applications Replit directement depuis ChatGPT grâce à l'intégration Replit. Cette intégration apporte l'environnement de développement de Replit dans votre flux de travail ChatGPT, vous permettant de :

* Créer des applications full-stack à partir de descriptions en langage naturel
* Démarrer des projets sans quitter ChatGPT
* Passer en toute fluidité à Replit pour un développement ultérieur

## Applications ChatGPT

Replit est le moyen le plus rapide de transformer vos idées en application en ligne, et vous pouvez maintenant le faire sans quitter ChatGPT.

Les applications dans ChatGPT vous permettent de connecter des outils et services externes directement dans la conversation. Au lieu de basculer entre les onglets ou de copier du contexte, vous pouvez demander à ChatGPT d'agir dans les outils que vous utilisez déjà.

L'application Replit vous permet de créer et d'amorcer de véritables applications directement depuis ChatGPT, avec le code hébergé dans l'Éditeur de projet.

Suivez les étapes ci-dessous pour créer votre première application Replit dans ChatGPT, ou essayez-le maintenant en cliquant sur le bouton ci-dessous.

<Card title="Essayez maintenant" icon="rocket" href="https://chatgpt.com?prompt=build+me+a+cool+app+with+%40replit">
  Créez une application avec Replit directement dans ChatGPT
</Card>

<Steps>
  <Step title="Ouvrez une conversation dans ChatGPT">
    Démarrez une nouvelle conversation ou continuez une conversation existante dans ChatGPT.
  </Step>

  <Step title="Décrivez ce que vous souhaitez créer et invoquez @Replit">
    Dans la zone de saisie du chat, décrivez votre idée d'application et mentionnez `@Replit` pour invoquer l'application Replit.

    Exemple de prompt :

    ```text theme={null}
    Create a beautiful app to split my restaurant bill @Replit
    ```

    <Frame>

    </Frame>
  </Step>

  <Step title="ChatGPT crée le projet directement dans Replit">
    ChatGPT utilisera l'application Replit pour créer votre projet. Vous verrez l'application générée en temps réel.

    <Frame>
      <img src="/assets/mirror/quickstart_replit_app_chatgpt_plan-e0f56622fbb1.png" alt="ChatGPT planifiant la structure de l'application" width="3392" height="1748" data-path="images/getting-started/quickstart_replit_app_chatgpt_plan.png" />
    </Frame>

    <Frame>
      <img src="/assets/mirror/quickstart_replit_app_chatgpt_execution-2696b7059d62.png" alt="ChatGPT exécutant et créant l'application dans Replit" width="3392" height="1748" data-path="images/getting-started/quickstart_replit_app_chatgpt_execution.png" />
    </Frame>
  </Step>

  <Step title="Ouvrez et publiez votre application">
    Une fois le projet créé, ouvrez-le dans Replit pour modifier, exécuter et publier votre application.

    <Frame>
      <img src="/assets/mirror/quickstart_replit_app_chatgpt_result-2b368a32c3dd.png" alt="L'application de partage de facture terminée dans Replit" width="3392" height="1748" data-path="images/getting-started/quickstart_replit_app_chatgpt_result.png" />
    </Frame>
  </Step>
</Steps>

Ce flux de travail est particulièrement puissant pour le prototypage : vous pouvez passer d'une idée à une application exécutable en quelques minutes, puis itérer en utilisant les outils Replit habituels.
