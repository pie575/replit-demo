## Plataforma

### Escolha uma região do workspace

Os criadores Pro agora podem escolher América do Norte, Europa (UE) ou Ásia ao criar um workspace. A seleção define a região dos novos projetos e recursos do workspace.

</Frame>

Saiba mais sobre a [geografia do workspace](/pt/features/collaboration/workspace-geography).

### Use o Replit pelo MCP

Conecte o Replit nativamente ao ChatGPT, Claude ou Slack, ou aponte qualquer cliente MCP compatível para o Replit, para criar, encontrar, inspecionar, atualizar e publicar apps. Você também pode criar uma cópia privada de um app para editar em vez de começar do zero.

<Frame>
  <img src="/assets/mirror/codex-list-replit-projects-bebae6a1dbab.png" alt="Resposta do Codex listando três projetos do Replit atualizados recentemente" width="2000" height="951" data-path="images/replitai/custom-mcp/codex-list-replit-projects.png" />
</Frame>

Saiba mais sobre o [Servidor MCP do Replit](/pt/platforms/mcp-server).

### Migre para o Clerk Auth

Agora você pode migrar um app elegível do Replit Auth para o Clerk Auth. O Agent move os dados da conta antes de atualizar o código de login, para que os usuários que já usam o app continuem com acesso aos seus dados.

</Frame>

Saiba mais sobre [como migrar para o Clerk Auth](/pt/features/auth-and-identity/migrate-auth-to-clerk).

### Peça gráficos inline

Faça uma pergunta sobre dados ao Agent e veja a resposta como um gráfico diretamente na conversa. Gráficos são um recurso central do Agent, então você pode aproveitá-los em qualquer coisa que criar.

### Compartilhe e gerencie skills do workspace

Agora qualquer integrante do workspace pode criar skills e mantê-las privadas ou compartilhá-las com o workspace. As skills compartilhadas começam desativadas para os demais integrantes, e cada pessoa escolhe quais habilitar. Os administradores podem gerenciar todas as skills do workspace e exigir skills específicas para o workspace. Uma Biblioteca de Skills reformulada torna as skills mais fáceis de descobrir e gerenciar.

Saiba mais sobre [Agent Skills](/pt/features/agent/skills).

## Teams e Enterprise

### Admin API disponível em beta

Os administradores de contas Enterprise agora podem criar chaves de API na nova aba **Developer**, em Configurações, e usar a Admin API para:

* Visualizar workspaces, membros, grupos de usuários, projetos e deployments.
* Visualizar o uso de membros, projetos e workspaces em intervalos de datas personalizados.
* Visualizar e editar orçamentos de workspaces, grupos de usuários e membros individuais.

Saiba mais na [documentação da Admin API](/pt/teams/admin-api) e na [referência da API](https://api.replit.com/docs).
