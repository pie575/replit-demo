Agent 支持四类集成，助你快速将创意变成应用：

* **Replit 托管**：内置集成，自动生效。创建应用后，Agent 即可直接使用。
* **Connectors**：Replit 官方提供的第一方集成。只需登录一次，Agent 便能在 Chat 中直接读写这些服务——拉取数据、创建记录、发送消息——并在你的各个应用中基于它们进行构建。
* **外部集成**：可用于构建的可信第三方服务。让 Agent 帮你完成配置，你只需提供 API key。
* **Agent 服务**：Agent 在后台调用的付费第三方 API——无需 API key。用量将从你的 Replit 积分中扣除。

<Note>
  **套餐可用性**：大多数 connector 需要 Core、Pro 或企业版订阅，部分 connector 在 Free 套餐中也可使用。workspace 中的 connector 目录会显示当前套餐下你可以使用哪些 connector。Free 套餐的构建者始终可以使用数据库、身份验证等 Replit 托管集成。
</Note>

</div>

<div id="let-agent-suggest-a-connector">
  ### 让 Agent 推荐 connector
</div>

有时多个服务都能完成同样的任务，比如存储文件或发送邮件。当你只说明需要的功能、没有指定具体服务提供方时，Agent 会列出几个合适的 connector，供你选择。

选定服务提供方后，只需登录一次即可连接你的账户。Agent 在构建过程中会按你的选择进行。你也可以直接指定服务名称，跳过这个列表。

<div id="configuring-oauth-app-with-replit">
  ### 在 Replit 中配置 OAuth app
</div>

<Note>
  **仅限 Enterprise**：配置自定义 OAuth app 需要 Enterprise 订阅。
</Note>

在企业版套餐中，你可以为 connector 使用自有的 OAuth app，而不必使用 Replit 的默认应用。这样，你的组织可以自行掌控 OAuth 客户端，在授权同意页面展示自有品牌，并精确控制构建者能够请求的作用域。

要使用自有 OAuth app 配置 connector，你需要从身份提供方获取三样内容：**Client ID**、**Client Secret**，以及你希望授权的**作用域**。此外，你还需在身份提供方处注册 Replit 的回调 URL，身份验证才能顺利完成。

<Frame>
  <img src="/assets/mirror/connector-oauth-configuration-100911ce0c48.png" alt="Connector OAuth 配置对话框，包含 Client ID、Client Secret 和 Connector Scopes 字段，以及设置为 https://replit.com/connectors/oauth/callback 的 Redirect URL" width="1112" height="1218" data-path="images/replitai/connector-oauth-configuration.png" />
</Frame>

<Steps>
  <Step title="在身份提供方处创建 OAuth app">
    登录身份提供方的开发者控制台或管理设置，创建一个新的 OAuth 2.0 应用。不同身份提供方对该步骤的叫法各不相同——请留意 **Create OAuth app**、**Register application** 或 **Create client credentials** 之类的选项。
  </Step>

  <Step title="设置回调 URL">
    当身份提供方要求填写 **Authorized redirect URI** (有时称为 **Callback URL** 或 **Redirect URL**) 时，请输入：

    ```
    https://replit.com/connectors/oauth/callback
    ```

    构建者授权应用后，身份提供方会通过该 URL 将其送回 Replit。该地址必须完全一致——末尾斜杠、协议和子域名都不能有差异。如果你添加了多个重定向 URI，其中必须包含这一条。
  </Step>

  <Step title="复制 Client ID 和 Client Secret">
    创建应用后，身份提供方会显示 **Client ID** 和 **Client Secret**。

    * **Client ID**：你的 OAuth app 的公开标识符，可以安全地出现在 URL 和客户端代码中。
    * **Client Secret**：用于证明请求来自你的应用的机密值。请像对待密码一样对待它——切勿提交到代码仓库或公开分享。Replit 会代你安全存储。

    有些身份提供方只在创建时显示一次 client secret。请立即复制并妥善保存，直到将其粘贴到 Replit 中。
  </Step>

  <Step title="选择作用域">
    **作用域**是一组权限，用于定义你的 OAuth app 可以代表构建者读取或写入哪些内容。每个身份提供方都会在其 API 文档中公布各自的作用域列表。

    在 Replit 中配置 connector 时，你填写的作用域必须与你在身份提供方处注册的作用域**完全一致** (逐字符一致，包括各类 URL 前缀) 。导致不匹配错误的常见原因包括：

    * 缺少完整的 URL 前缀 (例如 `https://www.googleapis.com/auth/drive.file` 与 `drive.file`) 。
    * 多余的空格或末尾的逗号。
    * 在 Replit 中请求了身份提供方应用上未启用的作用域。

    建议先从构建者所需的最小作用域开始，之后按需添加——大多数身份提供方都允许在不重新创建应用的前提下更新作用域。
  </Step>

  <Step title="在 Replit 中配置 connector">
    在组织的 **Connectors** 页面，选择 **Add new 集成**，选择相应服务，然后粘贴从身份提供方获取的 **Client ID**、**Client Secret** 和 **Scopes**。选择 **Configure** 保存。
  </Step>
</Steps>

<Note>
  如果配置后身份验证失败，请再次核对身份提供方中的回调 URL 是否与 `https://replit.com/connectors/oauth/callback` 完全一致，以及你在 Replit 中填写的每个作用域是否都已在身份提供方的应用上获得授权。
</Note>

<div id="reconnecting-integrations">
  ## 重新连接集成
</div>

如果某个已连接的服务无法正常工作——例如登录会话过期或权限发生变更——Replit 会在 Project Editor 中显示重新连接提醒。点击该提醒即可直接重新连接集成，无需离开编辑器。

<div id="debugging-connectors">
  ## 调试 connector
</div>

连接服务时遇到问题？以下指南将介绍常见错误及其解决方法。

<AccordionGroup>
  <Accordion title="Google Workspace：&#x22;This app is blocked&#x22;">
    如果在连接 Google Drive、Docs、Sheets、Calendar 或 Gmail 时看到 **&quot;This app is blocked&quot;**，通常是因为你所在组织的 Google Workspace 限制了第三方 OAuth app。请参阅完整的排查指南以解决该问题。

    [解决 Google connector 的 &quot;This app is blocked&quot; 问题](/zh/features/troubleshooting/debugging-google-connectors)
  </Accordion>

  <Accordion title="Salesforce：&#x22;Connection Expired&#x22;">
    如果 Salesforce connector 无法正常工作并提示 **&quot;Connection Expired&quot;** 错误，通常是因为你的 Salesforce 组织将刷新令牌策略设置为在指定期限后使令牌过期。请参阅完整的排查指南，更新你的 Connected App 设置。

    [修复 Salesforce 连接过期错误](/zh/features/troubleshooting/debugging-salesforce-connectors)
  </Accordion>
</AccordionGroup>
