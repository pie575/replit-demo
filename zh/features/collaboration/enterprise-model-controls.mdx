借助 Enterprise 模型控制，账户管理员可以管理构建者能够选用的 Agent 模型：先为整个账户设置策略，再为各个 Workspace 分别配置模型访问权限。

<Note>
  模型控制仅向 Enterprise 账户的账户管理员开放。如需为您的组织启用该功能，请联系我们的销售团队：[sales@replit.com](mailto:sales@replit.com)。
</Note>

<div id="use-intelligent-model-routing">
  ## 使用智能模型路由
</div>

智能模型路由是 Enterprise Workspace 的默认 Agent 体验。开启 **Auto 模式**后，Replit 会在兼顾质量与成本的前提下，为每项任务选择最合适的模式和模型。

路由只会从账户和 Workspace 策略授权的模型池中进行选择，池外的身份提供方和模型不在可选范围内。构建者可以保持 **Auto 模式**开启，也可以将其关闭，手动选择已授权的模型。

如需进一步了解路由的工作原理，请参阅[使用 Auto 模式](/zh/chat/auto-mode)。

<div id="open-agent-model-settings">
  ## 打开 Agent 模型设置
</div>

1. 打开 **Settings**。
2. 在 **Account** 下选择 **Advanced**。
3. 展开 **Agent 模式与身份提供方**。

<Frame caption="Advanced 设置中的模型身份提供方策略,以及独立的快速模式模型控件。">
  <img src="/assets/mirror/agent-model-provider-settings-overview-8f82610dab77.jpg" alt="Agent 模式与身份提供方 设置,其中包含身份提供方策略和快速模式模型控件" width="2000" height="930" data-path="images/workspace/agent-model-provider-settings-overview.jpg" />
</Frame>

<div id="set-a-provider-policy">
  ## 设置身份提供方策略
</div>

<Steps>
  <Step>
    选择你要管理的模型身份提供方。
  </Step>

  <Step>
    在 **Account policy** 下，选择以下选项之一：

    | 选项                  | 结果                           |
    | ------------------- | ---------------------------- |
    | **Enable all**      | 该身份提供方的所有模型在每个 Workspace 中均可用。 |
    | **Enable selected** | 由你为每个 Workspace 指定可用的模型。     |
    | **Disabled**        | 任何 Workspace 都无法使用该身份提供方的模型。   |

    <Note>
      OpenAI、Anthropic 和 Google 各自至少需保留一个模型处于启用状态，其他身份提供方则可以禁用。
    </Note>
  </Step>

  <Step>
    选择 **Update**。
  </Step>
</Steps>

开源模型身份提供方默认处于禁用状态。若要启用某个身份提供方，请选择 **Enable all** 或 **Enable selected**，然后选择 **Update**。

<div id="set-a-workspace-policy">
  ## 设置 Workspace 策略
</div>

当不同 Workspace 需要不同的模型访问权限时，请使用 **Enable selected**。

<Frame caption="Anthropic 身份提供方策略设置为 Enable selected，并按 Workspace 配置模型访问权限。">
  <img src="/assets/mirror/anthropic-account-policy-workspace-models-38c0f71a609d.jpg" alt="Anthropic 账户策略设置为 Enable selected，并为某个 Workspace 显示模型开关" width="2000" height="930" data-path="images/workspace/anthropic-account-policy-workspace-models.jpg" />
</Frame>

1. 打开身份提供方设置。
2. 将 **Account policy** 设置为 **Enable selected**。
3. 在 **Workspace** 列表中，选择目标 Workspace 的 **Setting** 下拉菜单。
4. 为该 Workspace 逐一开启或关闭各个模型。
5. 选择 **Update**。

在选择 **Update** 之前，你可以选择 **Copy to all**，将当前 Workspace 的模型选择应用到该账户下的所有 Workspace。

<div id="limitations">
  ## 限制
</div>

* 模型策略作用于 Workspace 级别。你无法为同一 Workspace 中的某个用户组单独设置策略。
* 智能模型路由不会覆盖账户或 Workspace 策略，也无法选择已禁用的身份提供方或模型。
* **Agent 模式与身份提供方**中的**快速模式模型**开关，控制着该账户下所有 Workspace 对快速模型变体的访问权限。身份提供方策略和智能模型路由都不会更改该设置。
