<Note>
  **Replit Organization**(replit.com 로그인)에 SSO를 필수로 적용하려고 하시나요? 그 설정은 별도로 진행합니다 — [Single sign-on (SAML SSO)](/ko/teams/identity-and-access-management/saml)를 참고하세요. 이 페이지에서는 Replit에서 **직접 만든 앱**의 sign-in flow에 SSO를 추가하는 방법을 다룹니다.
</Note>

Okta나 Microsoft Entra ID 같은 회사 identity provider로 사용자가 앱에 로그인하도록 할 수 있습니다. 앱에서 [Clerk Auth](/ko/features/auth-and-identity/clerk-auth)를 사용한다면 SSO를 비롯한 고급 인증 기능은 Clerk 대시보드에서 구성합니다. 필요한 내용을 Agent에게 요청하면 Agent가 설정을 마칠 수 있도록 대시보드로 안내합니다.

</Frame>

Clerk 대시보드에서는 기본 sign-in 경험을 훨씬 넘어서는 설정이 가능합니다. Clerk에서 구성한 내용은 Replit 앱의 인증에 자동으로 적용됩니다.

<div id="what-you-can-configure">
  ## 구성할 수 있는 항목
</div>

* **Enterprise SSO 연결**: OIDC 또는 SAML을 사용해 Okta나 Microsoft Entra ID로 싱글 사인온을 구성합니다. 고객이 회사의 identity provider로 로그인하도록 할 수 있습니다. 또한 SSO는 민감한 데이터를 다루는 내부 도구를 보호하여, 수동으로 관리하던 이메일 허용 목록을 회사가 이미 사용 중인 identity provider로 대체합니다.
* **다단계 인증(MFA)**: 앱의 sign-in flow에 MFA를 추가합니다.
* **세션 제어**: session 길이와 인증 주기를 조정합니다.
* **기타 Clerk 설정**: 그 밖의 Clerk 구성은 Replit 앱에 자동으로 적용됩니다. API keys나 환경 설정은 변경하지 마세요. Replit이 직접 관리하는 항목입니다. [Development and Production environments](/ko/features/auth-and-identity/clerk-auth#development-and-production-environments)를 참고하세요.

<div id="open-the-clerk-dashboard">
  ## Clerk 대시보드 열기
</div>

필요한 인증 변경 사항을 Agent에게 요청하세요. Agent는 가능한 부분까지 설정한 뒤, 직접 입력이 필요한 설정은 앱의 Clerk 대시보드에서 진행하도록 안내합니다.

<Frame>
  <img src="/assets/mirror/build-with-sso-agent-workflow-46422788bd18.webp" alt="Agent가 Clerk 기반 앱의 엔터프라이즈 SSO를 Clerk 대시보드에서 설정하도록 안내하는 모습." width="1602" height="1080" data-path="images/workspace/auth/build-with-sso-agent-workflow.webp" />
</Frame>

Workspace에서 대시보드를 열 수도 있습니다.

1. Tools pane에서 **Users &amp; Auth**를 선택합니다.
2. **Configure** 탭을 선택합니다.
3. **Advanced**를 선택합니다.
4. **Clerk dashboard** 아래에서 **Open Clerk dashboard**를 선택합니다.

<Frame>
  <img src="/assets/mirror/open-clerk-dashboard-tools-pane-a314ffea741d.webp" alt="Configure 탭이 열린 Users & Auth 도구에서 Advanced 섹션과 Open Clerk dashboard 버튼이 표시된 화면." width="2158" height="1372" data-path="images/workspace/auth/open-clerk-dashboard-tools-pane.webp" />
</Frame>

<div id="set-up-an-enterprise-sso-connection">
  ## Enterprise SSO 연결 설정하기
</div>

1. Clerk Dashboard에서 **Configure**를 선택합니다.
2. **User &amp; authentication** 아래에서 **SSO connections**를 선택합니다.
3. **Enterprise**를 선택합니다.
4. **Add connection**을 선택합니다.

<Frame>
  <img src="/assets/mirror/build-with-sso-enterprise-connections-b0a6a27885b5.webp" alt="Enterprise SSO connections 페이지와 Add connection 작업을 보여주는 Clerk Dashboard." width="1826" height="1080" data-path="images/workspace/auth/build-with-sso-enterprise-connections.webp" />
</Frame>

전체 연결 구성 방법은 [Clerk 문서](https://clerk.com/docs)를 참고하세요.

<div id="validate-the-connection">
  ### 연결 검증
</div>

구성을 완료한 후, identity provider의 테스트 계정으로 로그인해 보세요. 해당 계정이 앱에서 접근할 수 있어야 하는 영역에 정상적으로 접근되는지 확인합니다.

로그인에 실패하면 Agent에 도움을 요청하세요. 요청 시 identity provider, 프로토콜, 오류 메시지를 함께 알려주세요.

<Note>
  이 페이지는 앱 자체의 sign-in flow에 사용하는 엔터프라이즈 SSO를 다룹니다. Google, GitHub, Apple, X를 통한 소셜 로그인(Workspace에서는 **SSO providers**로 표시됨)은 [Sign-in providers](/ko/features/auth-and-identity/sign-in-providers)를 참고하세요. Replit Auth migration이나 Replit accounts용 SAML 로그인은 이 페이지에서 다루지 않습니다.
</Note>

<div id="pricing-and-availability">
  ## 가격 및 이용 가능 여부
</div>

Clerk Dashboard는 [Replit Pro](/ko/billing/plans/replit-pro) 플랜에서 이용할 수 있습니다. Enterprise 플랜은 곧 지원될 예정입니다.

<Info>
  Enterprise SSO 연결은 2026년 10월 1일까지 무료입니다. 이후에는 SSO 가격이 Clerk의 가격 정책과 동일하게 적용되며, Replit 청구서에 그대로 반영됩니다.
</Info>
