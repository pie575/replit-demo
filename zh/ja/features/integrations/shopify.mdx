有了 Shopify 连接器，Agent 可以为你预配 Shopify 商店、在此基础上构建自定义店面，并管理商品与库存。无需 API 密钥，全程在一次对话中完成。每当你提到要销售实物商品时，Agent 都会推荐 Shopify。只有在正式上线时，你才需要访问 Shopify。从第一条提示词到收到真实订单，大约只需 10 分钟。

<Note>
  分步操作指引请参阅 [构建 Shopify 店面](/zh/ja/build/ecommerce-store)。
</Note>

<div id="section">
  ## 你可以构建什么
</div>

* 面向实体商品的定制设计店面
* 品牌周边或服饰商店
* 带购物车和结账功能的 DTC(直面消费者)商店
* 基于 Shopify 商店的商品目录与库存管理工具
* 主推单一爆款商品的商品落地页

<div id="section-3">
  ## 工作原理
</div>

<Steps>
  <Step title="描述你的商店">
    告诉 Agent 你想销售什么。即使你没有点名,Agent 也会为实体商品推荐 Shopify。

    <Frame>
      <img src="/assets/mirror/describe-your-store-b5d724daee99.png" alt="Replit 提示框中输入了蜡烛商店的提示词" width="1440" height="900" data-path="images/replitai/shopify/describe-your-store.png" />
    </Frame>
  </Step>

  <Step title="Agent 为你预配商店">
    系统会在 Replit 的 Shopify 合作伙伴账户下创建一个开发商店(约 10 秒),并安装 Replit Sales Channel 应用以连接商店。无需 API 密钥,每个应用对应一个商店,认领前受密码保护。

    <Frame>
      <img src="/assets/mirror/connect-shopify-store-7f36389f976f.png" alt="Replit Agent 正在移交给 Shopify 技能,显示带有「Connect Shopify」按钮的「Connect to Shopify」卡片" width="3452" height="1984" data-path="images/replitai/shopify/connect-shopify-store.png" />
    </Frame>
  </Step>

  <Step title="Agent 负责构建与管理">
    Agent 会设计无头店面,并管理商品、变体、库存、商品系列和折扣。

    <Frame>
      <img src="/assets/mirror/add-product-8b098e606340.png" alt="显示名称和价格的蜡烛商品店面商品网格" width="3452" height="1978" data-path="images/replitai/shopify/add-product.png" />
    </Frame>
  </Step>

  <Step title="在 Shopify 上正式上线">
    认领商店、选择套餐、设置收款,准备就绪后即可发布开卖。

    <Frame>
      <img src="/assets/mirror/claim-store-4facb7c8b10c.png" alt="带有「Claim store」按钮的 Replit「Claim your store」界面" width="3452" height="1978" data-path="images/replitai/shopify/claim-store.png" />
    </Frame>
  </Step>
</Steps>

<div id="agent">
  ## Agent 管理的内容
</div>

店面和商品目录的所有内容都可以通过聊天进行编辑。

| 领域    | Agent 的功能                                                                                                                                      |
| ----- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| 设计    | 根据你的指引生成无头前端 (无需 Liquid 主题，也无需模板库) 。文案、布局、导航、动效和商品页面均可通过聊天编辑，还可以借助 [Canvas](/zh/ja/design/canvas) 变体探索不同方向。它是一个货真价实的 Replit 项目，因此可以扩展出博客、心愿单和落地页。 |
| 商品    | 创建、更新和删除商品与变体。字段包括：标题、描述、类型、供应商、标签、SKU、价格、重量、选项 (尺寸、颜色) 、图片、库存状态。                                                                              |
| 库存    | 按变体设置和调整库存数量。                                                                                                                                  |
| 系列    | 将商品归入不同系列。                                                                                                                                     |
| 折扣    | 创建价格规则和兑换码。                                                                                                                                    |
| 发布与同步 | 新商品会自动发布到店面。同步是双向的：在 Shopify 管理后台所做的更改会体现在 Replit 预览中，Agent 所做的更改也会体现在 Shopify 管理后台中。                                                          |

<div id="replitshopify">
  ## Replit 与 Shopify 的分工
</div>

| Replit 负责              | Shopify 负责        |
| ---------------------- | ----------------- |
| 店面的设计与构建               | 托管式结账             |
| 通过对话管理商品目录 (商品、库存、折扣)  | 商品、库存、购物车、订单的记录系统 |
| 店面的托管与部署               | 支付、身份认证 (KYC) 、结算 |
| Canvas 设计变体            | 税费、运费、履约发货        |
| 应用功能扩展 (博客、落地页等)       | 多渠道销售             |

订单、退款、支付和履约发货均在 Shopify 管理后台处理，而非 Agent。

<div id="section-4">
  ## 连接范围
</div>

* 所有套餐的所有构建者均可使用。无需在 Connectors 面板中进行任何设置，也无需凭证，直接在对话中完成连接。
* 按应用划分范围：每个应用都有自己的 Shopify 商店。
* 在你认领之前，该商店是归 Replit 所有的开发商店。你的邮箱会共享给 Shopify，以便日后认领。
* 你可以随时从 Shopify 管理后台卸载 Replit 应用。

<div id="shopify">
  ## 在 Shopify 上正式上线
</div>

发布操作在 Shopify 上完成，而不是在 Replit 上。请让 Agent 启动 Go Live 流程，然后在 Shopify 管理后台完成以下由商家负责的步骤：

* **认领商店** — 可通过聊天中的链接或 Shopify 发送的邮件认领。链接将在 7 天后过期。认领后即开始免费试用。
* **选择套餐**：处理正式订单需要[付费套餐](https://www.shopify.com/pricing)。
* **设置收款**：启用 [Shopify Payments](https://help.shopify.com/en/manual/payments/shopify-payments) 或其他支付服务商，并完成身份验证 (KYC) 。认领账户完成 KYC 后，正式收款即可生效。
* **配置[配送](https://help.shopify.com/en/manual/shipping)和[税费](https://help.shopify.com/en/manual/taxes)。**
* **[连接自定义域名](/zh/ja/build/add-custom-domain)** (可选) ，并解除店面的密码保护，向购买者开放。

结账始终会跳转到 Shopify 托管的结账页面，因此购买者在 Shopify 上完成支付。

<Note>
  支付、身份验证、税费、运费和欺诈检查均由 Shopify 负责。Replit 不会收集商家的银行信息、纳税人识别号或其他敏感信息。
</Note>

<div id="section-5">
  ## 故障排查
</div>

<AccordionGroup>
  <Accordion title="Shopify 商店设置耗时较长">
    预配过程需要调用多个 Shopify API，因此可能会花费一些时间。请等待 Agent 完成设置后，再让它构建店面。
  </Accordion>

  <Accordion title="开发过程中结账跳转到密码页">
    开发商店在上线前处于密码保护状态，因此结账预览可能会跳转到密码页。这属于预期行为，购物车仍可正常使用。请仅在正式上线时在 Shopify 中解除密码保护。
  </Accordion>

  <Accordion title="结账时无法完成实际支付">
    要实现实时收款，已认领的 Shopify 账户必须完成支付设置和 KYC 认证。在此之前，结账会跳转到 Shopify，但无法收取款项。请完成 KYC 认证，或改用已完成支付设置的账户。
  </Accordion>

  <Accordion title="Agent 提示此应用未连接 Shopify">
    每个商店的作用域仅限于一个应用。如果你是在另一个应用中连接的 Shopify，请让 Agent 为当前应用设置 Shopify 商店。
  </Accordion>

  <Accordion title="商品未显示在店面中">
    只有处于活跃且已发布状态的商品才会显示。Agent 会自动发布它创建的商品。如果商品未显示，请让 Agent 发布商品，然后刷新预览。
  </Accordion>

  <Accordion title="转移后需要重新连接">
    在认领或转移商店后，Shopify 可能会要求重新授权连接。让 Agent 重新连接 Shopify，即可在不丢失商店的情况下恢复访问权限。
  </Accordion>
</AccordionGroup>
