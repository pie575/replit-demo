从本质上说，Replit Design 就是一块用于呈现画框的无限 Canvas。本页接下来的内容，讲的都是你可以对这些画框做些什么：

* 在无限画板上生成并排布设计画框
* 通过聊天、建议和工具栏迭代每个画框
* 选定画框中的任意部分，只修改该部分
* 无需离开画板，即可引入模板或真实产品的灵感

  ## 画板概览
</div>

Replit Design 工作区由七个组件构成：

* **[Canvas](/zh/ja/design/canvas)**：Project Editor 中的设计视图，是一块可无限平移和缩放的画板，用于容纳所有画框、形状和便笺。
* **[画框](/zh/ja/design/frames)**：Canvas 上的所有图块。画框可以是实时产物 (网站、幻灯片) 、设计模型、图像、视频或矢量图形。
* **[元素](/zh/ja/design/elements)**：画框中的单个部分，例如标题、按钮、图像和表单字段。
* **[Chat](/zh/ja/design/chat-about-your-design)**：停靠在 Canvas 上的 Agent 聊天工具。你可以描述想要创建的内容，或选择一个画框，请求小幅或大幅编辑。最小化后，即可全屏使用 Canvas。
* **[环境智能](/zh/ja/design/explore-suggestions)**：显示在所选画框旁的下一步建议，只需单击即可生成新的设计方向。有关其工作原理，请参阅[探索建议](/zh/ja/design/explore-suggestions)。
* **[工具栏](/zh/ja/design/toolbar)**：Canvas 底部的浮动栏，包含 Interact、Pan、Chat、Draw、Edit 和 Generate 工具。
* **[素材库面板](/zh/ja/design/library-panel)**：汇集了入门模板、Mobbin 精选灵感内容和你过去的作品，可直接拖放到 Canvas 中。

<div id="section-2">
  ## 它们如何协同工作
</div>

每个组件都承接前一个组件的成果，将空白画板逐步转变为可构建的设计。

<div id="1-canvas">
  ### 1. 将画框放置到 Canvas 上
</div>

通过聊天中的提示词或工具栏的 **Generate** 菜单生成画框。画框可以是设计模型、Web 应用、移动应用、幻灯片、图片、视频或矢量图形。

<div id="2">
  ### 2. 迭代画框
</div>

选择任意画框，单独进行修改。你可以用自己的话聊天、根据[建议](/zh/ja/design/explore-suggestions)探索新的方向，或使用 **Focus** 聚焦于附近区域。完成后，使用 **Build** 将其构建为可运行的应用。

<Frame caption="选中画框时显示的操作栏：Build、Focus 和其他选项。">
  <img src="/assets/mirror/canvas-frame-action-bar-86f90fdd1375.png" alt="Canvas 上选中了 APEX X1 的 Design 画框。顶部显示画框专属操作栏，包含类型标签以及 Build、Focus 和其他选项；该画框以标签形式附加在聊天的提示词输入框中。" width="2000" height="1290" data-path="images/replitai/canvas-frame-action-bar.png" />
</Frame>

<div id="3">
  ### 3. 使用工具栏进行编辑、批注和生成
</div>

工具栏涵盖三类用途：**Edit** 用于选中画框内的单个元素并打开 Visual Editor，**Draw** 用于在画板上添加草图、箭头和便签等批注，供 Agent 读取；**Generate** 用于创建设计所需的图片、视频和矢量图形。

<Frame caption="使用 Edit 工具选中的元素，以及在右侧打开的 Visual Editor。">
  <img src="/assets/mirror/canvas-edit-67fe5ee02fbe.png" alt="在超跑租赁网站上选中了一个 div 元素，Edit 工具处于启用状态。Visual Editor 面板中显示 Text、Layout、Color、Border 控件以及 Discard、Save edits 按钮" width="2000" height="1269" data-path="images/replitai/canvas-edit.png" />
</Frame>

<div id="4">
  ### 4. 从素材库面板获取灵感
</div>

想寻找灵感或起点时，可打开素材库面板。模板会以可实时编辑的画框形式放置在 Canvas 上，而 Mobbin 精选的灵感内容则以静态参考图的形式放置，用于引导下一次生成。

<Frame caption="素材库面板的 Templates 标签页：按类型分组、可搜索的起始画框。">
  <img src="/assets/mirror/library-templates-5407d3683e8a.png" alt="素材库面板的 Templates 标签页，显示搜索框、分类筛选器，以及包含一张海报和两个落地页的模板卡片" width="665" height="583" data-path="images/design/replit-design/library-templates.png" />
</Frame>
