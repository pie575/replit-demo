API에서 가져온 핵심 지표, 차트, 필터로 실시간 대시보드를 만들어 보세요. 자동으로 새로고침되고 내보내기를 지원하며, 데이터에 실제로 담긴 내용만 표시합니다. 계속 유지해야 하는 데이터는 모두 Replit Database에 저장하세요.

<div id="best-for">
  ## 이런 분께 적합합니다
</div>

* 스크린샷이 아니라 팀원들이 직접 살펴볼 수 있는 대시보드가 필요한 프로덕트 매니저
* API를 통해 항상 최신 상태로 유지되는 비공개 대시보드가 필요한 운영 및 데이터 담당자

<div id="before-you-start">
  ## 시작하기 전에
</div>

대시보드가 어떤 의사 결정을 뒷받침해야 하는지 적어 두세요. API URL을 미리 준비하거나 아래 DummyJSON 엔드포인트를 사용하세요.

<Info>
  테스트용으로는 다음 무료 DummyJSON API 엔드포인트를 사용해 볼 수 있습니다.

  * 주문: `https://dummyjson.com/carts?limit=0`
  * 고객: `https://dummyjson.com/users?limit=0`
  * 카탈로그: `https://dummyjson.com/products?limit=0`
  * 카테고리: `https://dummyjson.com/products/categories`
</Info>

<div id="prompt-the-agent">
  ## 에이전트에 프롬프트 입력하기
</div>

<AiPrompt>
  이 API [URL]로 실시간 대시보드를 만들어 줘. [의사 결정]에 답이 되는 핵심 지표,
  차트, 필터를 보여 줘. 자동으로 새로 고쳐지고 내보내기도 지원해야 해.
  계속 유지해야 하는 데이터는 모두 Replit Database에 저장해 줘. 데이터에 실제로 있는
  내용만 보여 줘.
</AiPrompt>

<div id="what-to-expect">
  ## 예상 결과
</div>

Agent가 데이터를 불러오고, 요약 지표와 차트를 선택한 뒤 필터를 추가합니다. 최소한
숫자 하나는 원본 데이터와 대조해 확인하세요. DummyJSON을 사용했다면 주문 하나를 골라
`https://dummyjson.com/carts/{id}`를 열어 합계가 일치하는지 확인하세요. 필터를 전환해
모든 카드와 차트가 함께 갱신되는지 확인하세요. 한 번 내보내 본 뒤 행 하나를 API와 대조해 보세요.

<div id="troubleshooting">
  ## 문제 해결
</div>

* **API를 사용할 수 없거나 응답 형태가 이상한 경우:** URL이 올바른지, 응답에 필요한 필드가 모두 포함되어 있는지 확인하세요. 간단히 테스트하려면 위의 DummyJSON 엔드포인트를 사용하세요.
* **숫자가 예상과 다른 경우:** Agent에게 쿼리나 변환 과정을 보여달라고 요청한 다음, 숫자를 하나 이상 원본과 대조해 확인하세요.
* **필터를 바꿔도 차트가 업데이트되지 않는 경우:** Agent에게 각 필터를 summary cards와 chart 데이터에 모두 연결해 달라고 요청하세요. 대시보드가 느리다면 API 응답을 cache하거나 시작 시 불러오는 레코드 수를 줄이세요.
