<div id="o-que-so-skills">
  ## Что такое навыки
</div>

Навыки объясняют Agent, как вы работаете. Пока вы создаёте проект вместе, накапливается полезный контекст, но обычно он теряется, как только чат завершён. Навыки сохраняют накопленные знания, чтобы Agent мог применять их каждый раз одинаково. Задачи, которые раньше выполнялись непредсказуемо, становятся надёжнее и стабильно дают более качественный результат.

Например, навык с описанием дизайн-системы гарантирует, что Agent использует именно ваши цвета и правила отступов. А навык по исправлению ошибок сохраняет найденные решения, чтобы Agent вспомнил о них в следующий раз.

<div id="duas-formas-de-usar-skills">
  ## Два способа использовать навыки
</div>

Навыки можно использовать с Agent двумя способами — в зависимости от того, хотите ли вы применить навык только к одному сообщению или ко всему проекту.

<div id="usar-uma-skill-no-chat">
  ### Использование навыка в чате
</div>

Самый быстрый способ применить навык — прикрепить его прямо к сообщению. Нажмите кнопку **+** рядом с полем ввода чата, выберите **Использовать навык** и просмотрите доступные категории. После выбора навык отображается рядом с сообщением в виде чипа. Agent применяет этот навык только для текущей задачи — в проект он не устанавливается.

Это удобно, когда нужно, чтобы Agent выполнил разовую задачу, требующую специальных знаний. Например, можно выбрать навык **Анализатор акций** и попросить Agent изучить инвестицию или взять навык **Составитель резюме**, чтобы подготовить безупречное резюме.

Навыки распределены по следующим категориям:

| Категория                   | Примеры навыков                                                                 |
| --------------------------- | ------------------------------------------------------------------------------- |
| **Продажи и маркетинг**     | Креатив для рекламы, SDR с ИИ, SEO-аудитор, Контент-машина                      |
| **Карьера**                 | Рекрутер с ИИ, Составитель резюме, Подготовка к собеседованию                   |
| **Исследования и анализ**   | Конкурентный анализ, Глубокое исследование, Поиск поставщиков                   |
| **Бизнес и финансы**        | Анализатор акций, Генератор счетов, Анализатор недвижимости                     |
| **Документы и инструменты** | Генератор Excel, Клонировщик сайтов, Конвертер файлов, Генератор флеш-карточек  |
| **Творчество**              | Фоторедактор, Генератор подкастов, Генератор брендинга                          |
| **Продуктивность**          | Секретарь с ИИ, Продакт-менеджер, Дизайн-мыслитель                              |
| **Личное**                  | Помощник в путешествиях, Создатель рецептов, Планировщик питания, Личный шоппер |

<Tip>
  Также можно просто написать в сообщении «используй навык анализатор акций» (или любое другое название навыка), не открывая список навыков, — Agent поймёт запрос.
</Tip>

<div id="instalar-uma-skill-no-seu-projeto">
  ### Установка навыка в проект
</div>

Если вы хотите, чтобы Agent неизменно следовал навыку во всех диалогах в рамках проекта, установите его в каталог `/.agents/skills` вашего проекта. Установленные навыки сохраняются между сессиями чата и всегда доступны Agent при работе над проектом.

Это лучший вариант для знаний, специфичных для проекта: вашей дизайн-системы, соглашений по написанию кода или решений повторяющихся проблем.

<div id="adicionando-skills-ao-seu-projeto">
  ## Добавление навыков в проект
</div>

Добавить навык в проект на постоянной основе можно несколькими способами.

<div id="criar-com-o-agent">
  ### Создание с помощью Agent
</div>

Самый естественный способ создавать навыки — через диалог. После того как вы вместе решили задачу, попросите Agent зафиксировать то, что он усвоил. Навык напишется сам на основе общего контекста.

```
Создай навык для моей дизайн-системы, используя эти цветовые палитры и правила отступов
```

Вы также можете попросить Agent изучить и создать навыки для новых предметных областей:

```
Изучите лучшие практики создания видео с помощью Remotion и создайте навык
```

<div id="descobrir-e-instalar-no-painel-de-skills">
  ### Поиск и установка на панели навыков
</div>

Откройте **панель навыков** в редакторе проектов и перейдите на вкладку **Обзор**, чтобы найти навыки от сообщества. Их можно просматривать по названию, искать по ключевым словам и устанавливать любой навык прямо в проект одним щелчком.

<div id="instalar-pelo-diretrio-de-skills">
  ### Установка из каталога навыков
</div>

В [каталоге навыков Agent](https://skills.sh) собраны навыки от сообщества, которые можно установить напрямую. Replit поддерживает установку через [npx skills CLI](https://github.com/vercel-labs/skills):

```bash theme={null}
npx skills <skill> -a replit
```

Навык будет установлен в каталог `/.agents/skills` вашего проекта.

<Warning>
  Навыки могут содержать произвольные материалы и код. Всегда проверяйте исходный код,
  прежде чем устанавливать навык из внешних источников.
</Warning>

<div id="como-as-skills-funcionam">
  ## Как работают навыки
</div>

Навыки хранятся в каталоге `/.agents/skills` вашего проекта. Каждый навык соответствует [спецификации навыков Agent](https://agentskills.io/specification), которая определяет структуру и формат файлов навыка.

Agent видит название и описание каждого установленного навыка, но загружает его полное содержимое только тогда, когда навык относится к текущей задаче. Благодаря этому всё остаётся легковесным — вы можете установить сколько угодно навыков, и Agent не станет работать медленнее.

Установленные навыки сохраняются в проекте, поэтому остаются доступными между сессиями Agent и могут быть отправлены в систему контроля версий для совместной работы командой.

Навыки могут иметь разные области действия:

* **Уровень проекта**: относятся к конкретному проекту, версионируются вместе с его файлами в `/.agents/skills`
* **Уровень пользователя**: ваш личный набор инструментов, который сопровождает вас во всех проектах
* **Enterprise**: стандарты всей компании, встроенные в [пользовательские шаблоны](/ru/pt/teams/custom-templates), которые закрепляются во входных данных Agent для вашей организации

<Note>
  Навыки работают лучше всего, когда фиксируют конкретные, воспроизводимые шаблоны, а не
  общие рекомендации. Сосредоточьтесь на конкретных рабочих процессах, устоявшихся соглашениях и
  проверенных решениях вашего проекта.
</Note>

<div id="trabalhando-com-outras-ferramentas-de-codificao-com-ia">
  ## Работа с другими ИИ-инструментами для программирования
</div>

<Accordion title="Импорт навыков из других ИИ-инструментов для программирования">
  Если вы работаете с несколькими ИИ-инструментами для программирования, [rulesync](https://github.com/dyoshikawa/rulesync) поддерживает Replit и помогает сохранять единообразные настройки.

  Вы можете импортировать навыки из других ИИ-ассистентов для программирования:

  ```bash theme={null}
  npx rulesync init
  npx rulesync import --targets claudecode --features skills
  npx rulesync generate --targets replit --features skills
  ```

  Это позволяет вести единый набор навыков, который работает в разных средах разработки.
</Accordion>
