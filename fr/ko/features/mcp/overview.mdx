Replit Agent se connecte à des outils externes et à des sources de données via le [Model Context Protocol (MCP)](https://modelcontextprotocol.io), une norme ouverte d’intégration de l’IA. Vous pouvez installer chacun des serveurs ci-dessous en un clic. Après l’installation, Agent charge automatiquement l’outil et l’utilise lorsque nécessaire.

Pour en savoir plus sur ces concepts, consultez [Model Context Protocol](/fr/ko/learn/model-context-protocol). Pour un guide pratique, consultez [Se connecter via MCP](/fr/ko/build/connect-via-mcp). Pour connecter un serveur qui ne figure pas dans cette liste, consultez [Ajouter un serveur MCP personnalisé](/fr/ko/build/connect-via-mcp#add-a-custom-mcp-server).

<Info>
  Pour installer un serveur, sélectionnez **Add to Replit**. Une demande d’autorisation de connexion s’affichera dans l’éditeur de projet.
</Info>

<div id="section-2">
  ## Protection de sécurité
</div>

Tout le trafic MCP passe par le scanner de sécurité de Replit. Celui-ci évalue les définitions d’outils et les exécutions prévues afin de bloquer les outils suspects ou non sécurisés avant qu’ils ne soient exécutés. Si un outil est refusé, Agent vous en informe.

<div id="section-3">
  ## Options d’authentification
</div>

* **Enregistrement dynamique de clients OAuth** — Si le serveur prend en charge OAuth DCR, Replit le détecte automatiquement et enregistre le client. La plupart des serveurs préenregistrés utilisent cette méthode.
* **En-têtes personnalisés** — Définissez une ou plusieurs paires nom/valeur d’en-tête (par exemple, `X-API-Key`). Replit inclut ces en-têtes dans toutes les requêtes MCP afin que le serveur puisse identifier l’appelant. Utilisez cette option lorsque vous ajoutez un serveur personnalisé qui s’authentifie à l’aide d’un jeton statique.

<div id="section-4">
  ## Partager votre propre lien d’installation
</div>

Les liens d’installation vous permettent d’ajouter un serveur MCP à Replit en un clic. Vous pouvez en générer un au format décrit dans [Se connecter via MCP](/fr/ko/build/connect-via-mcp#share-an-install-link), ou en créer un vous-même : encodez une charge utile JSON en base64 et ajoutez-la à `https://replit.com/integrations?mcp=`.

```json theme={null}
{
  "displayName": "My MCP Server",
  "baseUrl": "https://example.com/mcp",
  "headers": [{ "key": "Authorization", "value": "Bearer your-token" }]
}
```

* **displayName** — Nom affiché lors de l’installation
* **baseUrl** — Point de terminaison HTTPS du serveur MCP
* **headers** — En-têtes d’authentification facultatifs
