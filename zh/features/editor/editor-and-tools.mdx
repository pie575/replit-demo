Project Editor 提供布局管理和集成工具，为你的应用构建体验保驾护航。
这些 Project Editor 功能各自专注于开发流程中的特定环节，让你可以
专心创作，而不必费心配置。

<div id="customizable-project-editor-layout">
  ## 可自定义的 Project Editor 布局
</div>

Project Editor 的布局管理工具让你可以自定义开发环境中的各个组件。
它包含以下几类用户界面元素：

| 元素      | 说明                                              | 功能                                                                 | 使用场景                                                                 |
| ------- | ----------------------------------------------- | ------------------------------------------------------------------ | -------------------------------------------------------------------- |
| **窗口**  | 包含一个或多个窗格的浏览器标签页                                | <ul><li>可跨多个屏幕布置</li></ul>                                         | <ul><li>将 Project Editor 分布到多个屏幕上</li><li> 同时处理不同的 project</li></ul> |
| **窗格**  | 窗口中包含一个或多个标签页的区域                                | <ul><li>支持水平和垂直拆分</li><li>可调整大小和重新排列</li><li>可在窗口内转为浮动窗格</li></ul> | <ul><li>并排查看代码和 Preview</li><li>为不同的开发任务创建自定义布局</li></ul>            |
| **标签页** | 仅包含一个 Project Editor 工具，例如文件编辑器、Preview 或 Agent | <ul><li>可在窗格之间移动，也可在窗格内重新排序</li><li>单击即可在不同文件或工具之间切换</li></ul>     | <ul><li>随时打开所需的工具或文件</li></ul>                                       |

<div id="file-tree">
  ## 文件树
</div>

文件树会列出 Replit App 中的所有文件和目录。

<Accordion title="如何访问文件树">
  点击左侧的 <img class="icon-svg" src="/assets/mirror/files-icon-f66bf1b04572.svg" alt="folder with arrows icon" width="16" height="16" data-path="images/icons/files-icon.svg" /> 文件夹图标，即可显示或隐藏
  文件树。
</Accordion>

你可以在文件树中执行以下操作：

* 点击文件夹查看其中的内容
* 点击文件或将其拖入窗格，在文件编辑器中打开
* 执行复制、重命名、移动、下载或删除等文件操作

<div id="run-button">
  ## 运行按钮
</div>

**Run** 按钮用于执行该 Replit App 当前选定的工作流。

<Accordion title="如何找到运行按钮">
  **Run** 按钮位于 Project Editor 界面顶部，点击该按钮即可运行工作流。

  当 Replit App 正在运行时，按钮文字会变为 **Stop**，点击即可停止应用。
</Accordion>

要了解如何选择、查看和管理工作流，请参阅 [Workflows](/zh/features/workspace-tools/workflows/)。

<div id="options-menu">
  ## 选项菜单
</div>

选项菜单可用于执行以下类型的布局操作：

* **窗口管理**：在新窗口中打开该 Replit App 的 Project Editor
* **窗格管理**：添加窗格、移动窗格、最大化窗格，以及在浮动与固定位置之间切换
* **标签页管理**：打开或选择其他标签页、将标签页移至其他窗格，以及关闭标签页

<Accordion title="如何打开选项菜单">
  点击活动标签页右上角的 <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="vertical dots icon" height="16" width="16" data-path="images/icons/vertical-dots.svg" /> 竖排三点图标
  即可打开选项菜单。
</Accordion>

<div id="resources-panel">
  ## 资源面板
</div>

资源面板会显示开发环境的计算资源及使用情况，包括内存、CPU 和存储。
这些信息有助于你评估并优化 Replit App 的发布资源需求。

<Accordion title="如何打开资源面板">
  1. 点击应用名称旁边的 <img class="icon-svg" src="/assets/mirror/resources-237893692826.svg" alt="stacked computers icon" width="16" height="16" data-path="images/icons/resources.svg" /> 资源图标，即可展开或收起该面板。
  2. 将鼠标悬停在 **Compute** 或 **Storage** 条目上，可查看更多详情。
</Accordion>
