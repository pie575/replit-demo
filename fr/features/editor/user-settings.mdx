L'outil Paramètres utilisateur de l'Éditeur de projet offre des options pour personnaliser l'apparence, le comportement et
les raccourcis clavier de votre compte.

</Frame>

## Fonctionnalités

Vous pouvez personnaliser votre expérience de création d'applications Replit avec ces catégories de paramètres :

* **Personnalisation du thème** : Sélectionnez entre les thèmes clair et sombre pour l'Éditeur de projet
* **Intelligence de code** : Configurez les fonctionnalités alimentées par l'IA qui améliorent votre expérience de création d'applications
* **Préférences de l'éditeur** : Ajustez le comportement et l'apparence de l'éditeur de fichiers
* **Contrôles de notification** : Gérez les préférences d'alerte
* **Options d'accessibilité** : Améliorez le fonctionnement de Replit pour les utilisateurs ayant des besoins spécifiques
* **Raccourcis clavier** : Définissez des combinaisons de touches pour exécuter des actions courantes et naviguer dans l'interface graphique

## Utilisation

  2. Sélectionnez <img class="icon-svg" src="/assets/mirror/settings-icon-c2664c3691bf.svg" alt="Icône Paramètres" width="16" height="16" data-path="images/icons/settings-icon.svg" /> **Paramètres utilisateur**.

  1. Sélectionnez la <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="icône de loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> loupe en haut pour ouvrir l'outil de recherche

### Apparence

Personnalisez les paramètres suivants liés à l'apparence de l'Éditeur de projet :

* **Sélection du thème** : Choisissez parmi les préréglages de thèmes clair et sombre, les <a href="https://replit.com/themes" target="_blank">thèmes de la communauté</a>, ou votre thème personnalisé
* **Thèmes personnalisés** : Créez des palettes de couleurs personnalisées à l'aide de l'éditeur de [Thèmes](/fr/features/editor/themes)

### Préférences de l'éditeur de fichiers

Contrôlez l'apparence et le comportement de l'éditeur de fichiers à l'aide des paramètres suivants :

* **Taille de police** : Ajustez la taille du texte pour une meilleure lisibilité
* **Fermeture automatique des crochets** : Insérez automatiquement les crochets fermants lorsque vous tapez un crochet ouvrant
* **Détection de l'indentation** : Détectez automatiquement les paramètres d'indentation lorsque vous ouvrez un fichier
* **Formatage de l'indentation du texte collé** : Reformatez le code collé pour suivre une indentation correcte
* **Caractère d'indentation** : Choisissez entre les espaces et les tabulations pour indenter le code
* **Taille d'indentation** : Définissez le nombre de colonnes pour chaque niveau d'indentation
* **Retour à la ligne** : Configurez le comportement du retour à la ligne
* **Minimap** : Incluez un aperçu de code navigable dans une barre latérale
* **Touche de modification pour la sélection multiple** : Définissez la touche de modification du clavier pour la sélection de plusieurs fichiers
* **État Git dans l'arborescence de fichiers** : Affichez les indicateurs d'état Git dans l'arborescence de fichiers

### Intelligence de code

Configurez les outils alimentés par l'IA à l'aide des paramètres suivants :

* **Jetons sémantiques** : Utilisez une coloration syntaxique améliorée alimentée par des serveurs de langage
* **Complétion de code IA** : Ajoutez des suggestions de code en ligne au fur et à mesure de votre frappe
* **Accepter la suggestion au caractère de validation** : Acceptez automatiquement les suggestions de code en tapant certains caractères

### Préférences Shell et Aperçu

Personnalisez le comportement de l'outil Shell et Aperçu :

* **Indicateur sonore du Shell** : Émettez des sons lorsque l'outil Shell rencontre des problèmes
* **Aperçu automatique** : Ouvrez l'onglet Aperçu automatiquement lorsqu'un serveur devient disponible
* **Transfert automatique des ports ouverts** : Configurez la gestion des ports nouvellement détectés

### Notifications

Gérez les paramètres de notification suivants :

* **Notification audio de l'Agent** : Émettez des sons lorsque l'Agent demande des retours
* **Notification push de l'Agent** : Recevez des notifications push mobiles lorsque l'Agent demande des retours

#### Alertes de production

**Les alertes de production** constituent un paramètre de notification par e-mail distinct qui vous tient informé de l'état de santé de vos applications publiées. Il est indépendant des e-mails produits et marketing, afin que vous restiez informé de ce qui est important sans bruit supplémentaire.

Activez **Les alertes de production** pour recevoir des e-mails concernant les éléments suivants :

* **Incidents de disponibilité** : Soyez notifié lorsqu'une application publiée tombe en panne ou a des difficultés à rester en ligne.
* **Vulnérabilités de sécurité** : Soyez notifié des faiblesses détectées dans les logiciels dont dépend votre application, afin de pouvoir les corriger avant qu'elles ne causent des problèmes.
* **Mises à jour des modèles** : Soyez notifié lorsqu'un modèle de langage utilisé par votre application change ou nécessite votre attention.

Pour trouver ce paramètre :

1. Ouvrez **Paramètres** depuis votre menu de compte.
2. Sélectionnez l'onglet **Personnalisation**.
3. Faites défiler jusqu'à la section **Notifications par e-mail** pour trouver **Les alertes de production**.

Lorsqu'une application publiée utilise un modèle de langage obsolète, Replit prépare une tâche brouillon pour vous mettre à niveau vers un modèle pris en charge. Vous recevez un e-mail avec un lien vers la tâche, afin de pouvoir finaliser la mise à niveau en un seul examen.

### Accessibilité

Vous pouvez personnaliser le paramètre d'accessibilité suivant :

* **Sortie de terminal accessible** : Activez la compatibilité avec les lecteurs d'écran pour les outils Shell et Console

### Raccourcis clavier

Pour accéder aux préférences de raccourcis clavier, sélectionnez l'onglet **Raccourcis clavier** dans l'outil Paramètres utilisateur.

Vous pouvez rechercher des combinaisons de touches à l'aide des méthodes suivantes :

* **Nom** : Tapez le nom ou la description du raccourci clavier dans le champ de recherche
* **Combinaison de touches** : Sélectionnez le <img class="icon-svg" src="/assets/mirror/keyboard-7ba19771b671.svg" alt="icône de clavier" width="16" height="16" data-path="images/icons/keyboard.svg" /> et saisissez la combinaison de touches

Utilisez les actions suivantes pour gérer les raccourcis :

* **Ajouter** : Sélectionnez **Ajouter un raccourci**
* **Mettre à jour** : Sélectionnez l'icône <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="icône de crayon" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> crayon
* **Supprimer** : Sélectionnez l'icône <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="icône de corbeille" width="16" height="16" data-path="images/icons/trash-icon.svg" /> corbeille
