L&#39;outil User Settings de l&#39;éditeur de projet propose des options pour personnaliser l&#39;apparence, le comportement et les raccourcis clavier de votre compte.

<Frame>
  <img src="/assets/mirror/user-settings-tool-faae3afb911b.png" alt="Capture d'écran de l'outil User Settings" width="4152" height="1894" data-path="images/workspace/user-settings-tool.png" />
</Frame>

<div id="section">
  ## Fonctionnalités
</div>

Les catégories de paramètres suivantes vous permettent de personnaliser votre expérience de création de Replit Apps :

* **Personnalisation du thème** : choisissez entre le thème clair et le thème sombre pour l&#39;éditeur de projet
* **Intelligence de code** : configurez les fonctionnalités basées sur l&#39;IA qui enrichissent l&#39;expérience de création d&#39;apps
* **Paramètres de l&#39;éditeur** : ajustez le comportement et l&#39;apparence de l&#39;éditeur de fichiers
* **Contrôle des notifications** : gérez vos préférences d&#39;alertes
* **Options d&#39;accessibilité** : rendez Replit plus facile à utiliser pour les personnes ayant des besoins spécifiques
* **Raccourcis clavier** : définissez des combinaisons de touches pour effectuer les actions courantes et naviguer dans l&#39;interface graphique

<div id="section-2">
  ## Utilisation
</div>

<Accordion title="Comment accéder aux User Settings">
  Depuis le **dock d&#39;outils** à gauche :

  1. Sélectionnez <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Icône Tous les outils" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **Tous les outils** pour afficher la liste des outils de l&#39;éditeur de projet.
  2. Sélectionnez <img class="icon-svg" src="/assets/mirror/settings-icon-c2664c3691bf.svg" alt="Icône Paramètres" width="16" height="16" data-path="images/icons/settings-icon.svg" /> **User Settings**.

  Depuis la **barre de recherche** :

  1. Sélectionnez la loupe <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="Icône loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> en haut pour ouvrir l&#39;outil de recherche
  2. Saisissez « User Settings » pour trouver l&#39;outil, puis sélectionnez-le dans les résultats.
</Accordion>

<div id="section-3">
  ### Apparence
</div>

Vous pouvez personnaliser les paramètres suivants, liés à l&#39;apparence de l&#39;éditeur de projet :

* **Choix du thème** : choisissez parmi les thèmes prédéfinis clair et sombre, les <a href="https://replit.com/themes" target="_blank">thèmes de la communauté</a> ou vos thèmes personnalisés
* **Thèmes personnalisés** : créez votre propre palette de couleurs à l&#39;aide de l&#39;éditeur de [thèmes](/fr/ja/features/editor/themes)

<div id="section-4">
  ### Paramètres de l&#39;éditeur de fichiers
</div>

Les paramètres suivants contrôlent l&#39;apparence et le comportement de l&#39;éditeur de fichiers :

* **Taille de police** : ajustez la taille du texte pour une meilleure lisibilité
* **Fermeture automatique des parenthèses** : insère automatiquement la parenthèse fermante lorsque vous saisissez une parenthèse ouvrante
* **Détection de l&#39;indentation** : détecte automatiquement les paramètres d&#39;indentation à l&#39;ouverture d&#39;un fichier
* **Indentation du texte collé** : applique l&#39;indentation appropriée au code collé
* **Caractère d&#39;indentation** : choisissez d&#39;utiliser des espaces ou des tabulations pour indenter le code
* **Taille de l&#39;indentation** : définissez le nombre de colonnes de chaque niveau d&#39;indentation
* **Retour à la ligne** : configurez le comportement du retour à la ligne
* **Minimap** : affiche un aperçu navigable du code dans la barre latérale
* **Touche de modification pour la sélection multiple** : définissez la touche de modification permettant de sélectionner plusieurs fichiers
* **Statut Git dans l&#39;arborescence de fichiers** : affiche les indicateurs de statut Git dans l&#39;arborescence de fichiers

<div id="section-5">
  ### Intelligence de code
</div>

Configurez les outils dopés à l&#39;IA à l&#39;aide des paramètres suivants :

* **Jetons sémantiques** : utilise une coloration syntaxique enrichie par le serveur de langage
* **Complétion de code par IA** : ajoute des suggestions de code en ligne pendant la saisie
* **Acceptation automatique des suggestions par caractères de validation** : accepte automatiquement les suggestions de code lorsque vous saisissez certains caractères

<div id="shellpreview">
  ### Paramètres du Shell et du Preview
</div>

Personnalisez le comportement des outils Shell et Preview :

* **Indicateur sonore de la cloche du Shell** : émet un son lorsque l&#39;outil Shell détecte un problème
* **Preview automatique** : ouvre automatiquement l&#39;onglet Preview dès que le serveur est disponible
* **Transfert automatique des nouveaux ports détectés** : définit la gestion des nouveaux ports détectés

<div id="section-6">
  ### Notifications
</div>

Gérez les paramètres de notification suivants :

* **Notifications sonores d&#39;Agent** : joue un son lorsqu&#39;Agent sollicite votre avis
* **Notifications push d&#39;Agent** : recevez une notification push sur mobile lorsqu&#39;Agent sollicite votre avis

<div id="section-7">
  #### Alertes de production
</div>

Les **alertes de production** constituent un paramètre de notification par e-mail distinct qui vous informe de l&#39;état de vos applications publiées. Indépendantes des e-mails produit et marketing, elles vous permettent de rester informé de l&#39;essentiel, sans bruit superflu.

Lorsque vous activez les **alertes de production**, vous recevez des e-mails de notification concernant :

* **Les incidents de disponibilité** : vous êtes averti lorsque votre application publiée tombe en panne ou ne parvient pas à rester en ligne.
* **Les vulnérabilités de sécurité** : vous êtes informé des vulnérabilités détectées dans les logiciels dont dépend votre application, ce qui vous permet de les corriger avant qu&#39;elles ne posent problème.
* **Les mises à jour de modèles** : vous êtes averti lorsque le modèle de langage utilisé par votre application change ou nécessite votre attention.

<Frame>
  <img src="/assets/mirror/production-alerts-highlight-bb76079f20fd.png" alt="Section des alertes de production dans les paramètres de notification. Le bouton d'activation des e-mails d'alertes de production et la liste déroulante de gravité des alertes de sécurité sont encadrés en rouge" width="2400" height="1364" data-path="images/workspace/production-alerts-highlight.png" />
</Frame>

Pour accéder à ce paramètre :

1. Ouvrez les **Paramètres** depuis le menu de votre compte.
2. Sélectionnez l&#39;onglet **Personnalisation**.
3. Faites défiler jusqu&#39;à la section **Notifications par e-mail** pour trouver les **alertes de production**.

Si votre application publiée utilise un modèle de langage obsolète, Replit prépare une tâche en brouillon pour la mise à niveau vers un modèle pris en charge. Vous recevez un e-mail contenant un lien vers cette tâche : il vous suffit d&#39;une seule validation pour finaliser la mise à niveau.

<div id="section-8">
  ### Accessibilité
</div>

Vous pouvez personnaliser les paramètres d&#39;accessibilité suivants :

* **Sortie de terminal accessible** : active la compatibilité avec les lecteurs d&#39;écran pour les outils Shell et Console

<div id="section-9">
  ### Raccourcis clavier
</div>

Pour accéder aux paramètres des raccourcis clavier, sélectionnez l&#39;onglet **Raccourcis clavier** de l&#39;outil User Settings.

Vous pouvez rechercher une combinaison de touches des façons suivantes :

* **Par nom** : saisissez le nom ou la description du raccourci clavier dans le champ de recherche
* **Par combinaison de touches** : sélectionnez <img class="icon-svg" src="/assets/mirror/keyboard-7ba19771b671.svg" alt="Icône clavier" width="16" height="16" data-path="images/icons/keyboard.svg" /> puis saisissez la combinaison de touches

Gérez vos raccourcis à l&#39;aide des actions suivantes :

* **Ajouter** : sélectionnez **Ajouter un raccourci**
* **Mettre à jour** : sélectionnez l&#39;icône crayon <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="Icône crayon" width="16" height="16" data-path="images/icons/pencil-icon.svg" />
* **Supprimer** : sélectionnez l&#39;icône corbeille <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="Icône corbeille" width="16" height="16" data-path="images/icons/trash-icon.svg" />
