<div id="o-que-um-replit-app">
  ## Qu’est-ce qu’une application Replit ?
</div>

Les applications Replit sont des projets hébergés dans le cloud qui contiennent du code, des données et des ressources.
Vous pouvez les créer, les exécuter et les publier depuis un environnement sécurisé et isolé.

Les applications Replit s’intègrent aux outils suivants du Project Editor pour offrir
une expérience de développement fluide :

* **Outils d’IA** : utilisez Agent pour créer, déboguer et expliquer votre code.
* **Collaboration** : travaillez avec d’autres personnes en temps réel sur la même application.
* **Publication** : publiez votre application dans le cloud en un seul clic.

<div id="principais-funcionalidades">
  ## Principales fonctionnalités
</div>

Les applications Replit offrent les fonctionnalités suivantes :

* **Sans configuration :** Créez des applications ou écrivez du code directement sur Replit.com, sans installation ni configuration.
* **Enregistrement automatique :** Votre projet enregistre continuellement vos modifications dans le cloud et vous permet de reprendre la programmation depuis n’importe quel navigateur web.
* **Contrôle de version :** Suivez les modifications, explorez l’historique des fichiers et synchronisez vos fichiers sans aucune configuration grâce aux systèmes de contrôle de version de Replit.
* **Contrôles de visibilité publique/privée :** Définissez qui peut consulter, exécuter ou créer un Remix de votre application grâce aux paramètres de confidentialité.
* **Publication :** Publiez votre code dans le cloud sans modifications complexes de configuration.
* **URL personnalisées :** Obtenez une URL unique pour votre application ou attribuez-lui un domaine personnalisé pour une présence plus professionnelle.

<Info>
  Les fichiers téléversés dans le système de fichiers de votre projet sont disponibles uniquement pendant le développement et
  ne sont pas accessibles depuis votre application publiée ou par d’autres développeurs. Utilisez [Object
  Storage](/fr/pt/features/data-and-storage/object-storage) pour gérer les
  téléversements et diffuser des fichiers, et [Replit
  Database](/fr/pt/features/data-and-storage/sql-database) pour stocker et
  récupérer les données de votre application et de vos utilisateurs.
</Info>

Pour en savoir plus sur les outils du Project Editor qui simplifient la création d’applications Replit, consultez la [présentation du Project Editor](/fr/pt/learn/projects-and-artifacts/project-editor/).

<div id="como-funciona">
  ## Comment ça marche
</div>

Lorsque vous créez une application Replit, Replit configure un espace privé dans le cloud pour votre projet.
À mesure que vous ajoutez des fonctionnalités et apportez des modifications à votre application, Replit enregistre automatiquement vos changements
afin que vous puissiez reprendre l’édition depuis n’importe quel navigateur web.

Replit fournit des environnements préconfigurés avec tous les composants nécessaires.
Vous pouvez ainsi commencer à créer votre application immédiatement, sans vous soucier de la
configuration du serveur, de la base de données ou de l’environnement.

Replit attribue automatiquement à chaque application Replit une adresse web unique où vous
pouvez prévisualiser votre application pendant que vous y travaillez. Lorsque vous êtes prêt à partager votre
création, vous pouvez la publier en quelques clics pour la rendre accessible 24 h/24 et 7 j/7.

<div id="viso-geral-de-armazenamento">
  ## Vue d’ensemble du stockage
</div>

Replit propose quatre principaux types de stockage pour répondre aux besoins en données de votre application. Chaque type de stockage répond à différents cas d’utilisation et présente des limites spécifiques selon votre formule.

<Info>
  Les limites de stockage incluent toutes les données stockées par votre application, y compris les paquets et dépendances installés.
</Info>

| Type de stockage                                                   | Description                       | Cas d’utilisation                                                      | Persistance                                                    | Limites de la formule                                                                                                                                    |
| ------------------------------------------------------------------ | --------------------------------- | ---------------------------------------------------------------------- | -------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Stockage de fichiers**                                           | Fichiers de votre projet          | Code de l’application, ressources statiques, fichiers de configuration | Persiste après la publication, est réinitialisé au redémarrage | Starter : {StarterWorkspaceStorage}<br />Core : {CoreWorkspaceStorage}<br />Pro : {TeamsWorkspaceStorage}<br />Enterprise : {EnterpriseWorkspaceStorage} |
| **[Database](/fr/pt/features/data-and-storage/sql-database/)**        | Stockage de données structurées   | Profils utilisateur, scores de jeux, catalogues de produits            | Entièrement persistant entre les sessions                      | 20 Go par base de données de développement<br />Les bases de données de production sont facturées selon le temps de calcul et le stockage                |
| **[App Storage](/fr/pt/features/data-and-storage/object-storage/)**   | Données non structurées et médias | Images, vidéos, PDF, documents                                         | Entièrement persistant entre les sessions                      | Paiement à l’utilisation<br />Facturé selon le stockage et la bande passante                                                                             |
| **[Secrets](/fr/pt/core-concepts/project-editor/app-setup/secrets/)** | Données sensibles chiffrées       | Clés API, identifiants, chaînes de connexion                           | Entièrement persistant et chiffré                              | Aucune limite spécifique<br />Inclus dans toutes les formules                                                                                            |
