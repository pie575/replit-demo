<div id="section-6">
  ## 故障排除
</div>

* **每次更新看起来都像价格变动：** 告诉 Agent 需要监测哪些页面 (价格、更新日志、功能) ，以及你认为什么内容重要。在向销售团队报告之前，请先在实际网站上确认变更。
* **完全没有收到通知：** 可能是无法访问页面，或者竞争对手列表范围过窄。请提供完整的 URL，并要求 Agent 在无法加载页面时通知你。
* **Notion 变成了一堆零散笔记：** 为 Agent 指定一个统一的竞争情报页面，并要求它直接更新该页面，而不是每天早上创建新页面。
