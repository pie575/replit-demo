사용자가 Google 계정으로 여러분의 웹사이트에 로그인할 수 있게 하면 다음과 같은 이점이 있습니다.

1. 직접 인증 체계를 구현할 필요가 없습니다.
2. 사용자의 이름과 연락처 정보를 손쉽게 얻을 수 있습니다.
3. 동일한 자격 증명으로 Sheets, Drive 같은 사용자의 Google 리소스에 접근할 수 있습니다.

이 가이드에서는 Replit에서 Python과 Flask로 이를 구현하는 방법을 단계별로 안내합니다.

먼저 기본적인 OAuth 인증을 설정하는 방법을 살펴본 다음, 이렇게 얻은 자격 증명으로 사용자의 Google 리소스에 접근하는 방법을 다룹니다.

<div id="introduction-to-oauth">
  ## OAuth 소개
</div>

Google 인증은 OAuth 표준을 기반으로 합니다. OAuth의 작동 방식은 다음과 같습니다.

1. 웹사이트의 특정 위치에서 사용자를 로그인 페이지로 안내합니다.
2. 사용자가 로그인 페이지로 이동하면, 웹사이트에 로그인 양식을 직접 구현하는 대신 Google의 로그인 서비스로 리디렉션하여 사용자를 로그인시킵니다.
3. Google의 로그인 서비스에서 사용자가 성공적으로 로그인하면, 미리 지정해 둔 URL(예: `https://YOUR_DOMAIN/oauth2callback`)로 다시 리디렉션하면서 사용자 및 로그인 세션과 관련된 정보를 함께 전달합니다.
4. 이 로그인 정보를 사용해 액세스 토큰을 발급받습니다. 토큰은 사용자의 프로필 정보, 스프레드시트, 문서 등 사용자의 리소스에 접근할 수 있는 출입증과 같은 역할을 합니다.

<div id="oauth-show-me-the-code">
  ## OAuth: 코드부터 보여주세요
</div>

저와 비슷한 분이라면 가장 먼저 보고 싶은 건 실제로 동작하는 코드일 겁니다. 필요한 코드는 아래와 같습니다. 다만 모든 것이 제대로 동작하려면 Google Cloud Console에서 몇 가지를 설정해야 하는데, 이 내용은 다음 섹션에서 다룹니다. [Flask 템플릿](https://replit.com/@replit/Flask?v=1)으로 새 Replit App을 만들고 아래 내용을 `main.py`에 넣으세요. 코드의 주석에 각 부분이 어떤 역할을 하는지 설명되어 있습니다:

```python theme={null}
from flask import Flask, redirect, session, url_for, request
import google_auth_oauthlib.flow
import json
import os
import requests

app = Flask('app')
# `FLASK_SECRET_KEY`는 세션에서 사용됩니다. 임의의 문자열을 생성해
# secret으로 저장하세요.
app.secret_key = os.environ.get('FLASK_SECRET_KEY') or os.urandom(24)

# `GOOGLE_APIS_OAUTH_SECRET`에는 Google Cloud 사용자 인증 정보 패널에서 download한
# JSON 파일의 내용이 들어 있습니다. 다음 섹션을 참고하세요.
oauth_config = json.loads(os.environ['GOOGLE_OAUTH_SECRETS'])

# OAuth flow에 사용할 설정을 구성합니다
oauth_flow = google_auth_oauthlib.flow.Flow.from_client_config(
    oauth_config,
    # scopes는 인증 후 사용자를 대신해 접근할 API를 정의합니다
    scopes=[
        "https://www.googleapis.com/auth/userinfo.email",
        "openid",
        "https://www.googleapis.com/auth/userinfo.profile",
    ]
)

# login 페이지의 entrypoint입니다. `authorization_url`에 있는 Google 로그인 서비스로
# 리디렉션합니다. `redirect_uri`는 Google 로그인 서비스가 이 앱으로 다시 리디렉션할 때
# 사용하는 URI입니다.
@app.route('/signin')
def signin():
    # Replit App 내부에서는 http를 사용하지만 외부에서는 https로 접근하며
    # redirect_uri도 여기에 맞아야 하므로 URL을 http에서 https로 rewrite합니다
    oauth_flow.redirect_uri = url_for('oauth2callback', _external=True).replace('http://', 'https://')
    authorization_url, state = oauth_flow.authorization_url()
    session['state'] = state
    return redirect(authorization_url)

# Google 로그인 서비스가 다시 리디렉션해 오는 엔드포인트입니다. Google Cloud의 API 사용자 인증 정보 패널에서
# "Authorized redirect URIs"에 추가해야 합니다. Google 엔드포인트를 호출해 액세스 토큰을 요청하고
# 이를 사용자 session에 저장합니다. 이후에는 이 액세스 토큰으로 사용자를 대신해
# API에 접근할 수 있습니다.
@app.route('/oauth2callback')
def oauth2callback():
    if not session['state'] == request.args['state']:
        return 'Invalid state parameter', 400
    oauth_flow.fetch_token(authorization_response=request.url.replace('http:', 'https:'))
    session['access_token'] = oauth_flow.credentials.token
    return redirect("/")

# 앱의 홈 페이지입니다. 아직 로그인하지 않은 사용자는 login하도록 안내하고,
# 이미 로그인한 경우에는 사용자 정보를 표시합니다.
@app.route('/')
def welcome():
    if "access_token" in session:
        user_info = get_user_info(session["access_token"])
        if user_info:
            return f"""
                Hello {user_info["given_name"]}!<br>
                Your email address is {user_info["email"]}<br>
                <a href="/logout">Log out</a>
            """
    return """
        <h1>Hello!</h1>
        <a href="/signin">Sign In via Google</a><br>
    """

# 유효한 액세스 토큰으로 userinfo API를 호출해 사용자 정보를 가져옵니다.
# 액세스 토큰으로 사용자를 대신해 API에 접근하는 첫 번째 예시입니다.
def get_user_info(access_token):
    response = requests.get("https://www.googleapis.com/oauth2/v3/userinfo", headers={
       "Authorization": f"Bearer {access_token}"
   })
    if response.status_code == 200:
        user_info = response.json()
        return user_info
    else:
        print(f"Failed to fetch user info: {response.status_code} {response.text}")
        return None

@app.route('/logout')
def logout():
    session.clear()
    return redirect('/')

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000)

```

<div id="google-sheets-integration-show-me-the-code">
  ## Google Sheets 통합: 코드 살펴보기
</div>

먼저, 기존 코드의 OAuth flow 섹션에서는 scopes 목록에 `"https://www.googleapis.com/auth/spreadsheets.readonly"`를 추가하는 것 외에 나머지는 모두 그대로 둡니다:

```python theme={null}
# OAuth flow에 사용할 configuration을 설정합니다
oauth_flow = google_auth_oauthlib.flow.Flow.from_client_config(
    oauth_config,
    # scopes는 인증이 완료된 후 user를 대신해 어떤 API에 접근할지를 정의합니다
    scopes=[
        "https://www.googleapis.com/auth/userinfo.email",
        "openid",
        "https://www.googleapis.com/auth/userinfo.profile",
        "https://www.googleapis.com/auth/spreadsheets.readonly"
    ]
)
```

이제 `googleapiclient.discovery` 라이브러리로 Google API에 접근하려면, 먼저 액세스 토큰으로 `Credentials` 객체를 생성한 다음 `build` 함수를 사용해 호출 가능한 API 객체를 만들면 됩니다. Sheets API의 경우 다음과 같습니다.

```python theme={null}
credentials = google.oauth2.credentials.Credentials(token=session['access_token'])
service = build("sheets", "v4", credentials=credentials)
sheets_api = service.spreadsheets()
```

Sheets API를 실제로 어떻게 사용하는지에 대해서는, 몇 가지 헬퍼 함수를 만들어 두었습니다:

```python theme={null}
# Google 스프레드시트에 포함된 모든 시트를 가져옵니다
def get_sheets(sheets_api, spreadsheet_id) -> list[str]:
    result = sheets_api.get(spreadsheetId=spreadsheet_id).execute()
    return [sheet["properties"]["title"] for sheet in result["sheets"]]

# Google 스프레드시트에서 지정한 시트의 데이터를 가져옵니다
def get_sheet_data(sheets_api, spreadsheet_id, sheet_title) -> list[list[str]]:
    result = (
        sheets_api.values()
        .get(spreadsheetId=spreadsheet_id, range=sheet_title)
        .execute()
    )
    return result["values"]
```

위 내용을 참고하면 다음과 같이 Google 스프레드시트를 가져오는 POST 핸들러 엔드포인트를 만들 수 있습니다:

```python theme={null}
@app.route("/import_spreadsheet", methods = ['POST'])
def import_spreadsheet():
    if 'access_token' not in session:
        return redirect('/signin')
    spreadsheet_id = request.form["spreadsheet_id"]
    credentials = google.oauth2.credentials.Credentials(token=session['access_token'])
    service = build("sheets", "v4", credentials=credentials)
    sheets_api = service.spreadsheets()
    try:
        sheets = get_sheets(sheets_api, spreadsheet_id)
        data_by_sheets = {}
        for sheet in sheets:
            data = get_sheet_data(sheets_api, spreadsheet_id, sheet)
            data_by_sheets[sheet] = data
    except googleapiclient.errors.HttpError as e:
        return f"upload failure"
    dirpath = os.path.join("static", "uploads", spreadsheet_id)
    filepath = os.path.join(dirpath, "data.json")
    os.makedirs(dirpath, exist_ok=True)
    with open(filepath, "w") as file:
```

```python theme={null}
app.secret_key = os.environ.get('FLASK_SECRET_KEY') or os.urandom(24)

    ]
)

# login 페이지의 entrypoint입니다. `authorization_url`에 있는 Google login 서비스로
# 리디렉션합니다. `redirect_uri`는 Google login 서비스가 이 App으로 다시
# 리디렉션할 때 사용하는 URI입니다.
@app.route('/signin')
def signin():
    # Replit App 내부에서는 http를 쓰지만 외부에서는 https로 접근하고
    # redirect_uri도 여기에 맞아야 하므로 URL을 http에서 https로 rewrite합니다
    oauth_flow.redirect_uri = url_for('oauth2callback', _external=True).replace('http://', 'https://')
    authorization_url, state = oauth_flow.authorization_url()
    session['state'] = state
    return redirect(authorization_url)

# Google login 서비스가 다시 리디렉션하는 엔드포인트입니다. Google Cloud의 API 사용자 인증 정보 pane에 있는
# "Authorized redirect URIs"에 추가해야 합니다. Google 엔드포인트를 호출해 액세스 token을 요청하고
# 이를 User session에 저장합니다. 이후 이 액세스 token으로 User를 대신해 API에 접근할 수 있습니다.
@app.route('/oauth2callback')
def oauth2callback():
    if not session['state'] == request.args['state']:
        return 'Invalid state parameter', 400
    oauth_flow.fetch_token(authorization_response=request.url.replace('http:', 'https:'))
    session['access_token'] = oauth_flow.credentials.token
    return redirect("/")

# 유효한 액세스 token으로 userinfo API를 호출해 User 정보를 가져옵니다.
# 액세스 token으로 User를 대신해 API에 접근하는 첫 번째 예시입니다.
def get_user_info(access_token):
    response = requests.get("https://www.googleapis.com/oauth2/v3/userinfo", headers={
       "Authorization": f"Bearer {access_token}"
   })
    if response.status_code == 200:
        user_info = response.json()
        return user_info
    else:
        print(f"Failed to fetch user info: {response.status_code} {response.text}")
        return None

@app.route('/logout')
def logout():
    session.clear()
    return redirect('/')

def get_sheets(sheets_api, spreadsheet_id) -> list[str]:
    result = sheets_api.get(spreadsheetId=spreadsheet_id).execute()
    return [sheet["properties"]["title"] for sheet in result["sheets"]]

# Google 스프레드시트 내 특정 Sheet의 데이터를 가져옵니다
def get_sheet_data(sheets_api, spreadsheet_id, sheet_title) -> list[list[str]]:
    result = (
        sheets_api.values()
        .get(spreadsheetId=spreadsheet_id, range=sheet_title)
        .execute()
    )
    return result["values"]

@app.route("/import_spreadsheet", methods = ['POST'])
def import_spreadsheet():
    if 'access_token' not in session:
        return redirect('/signin')
    spreadsheet_id = request.form["spreadsheet_id"]
    credentials = google.oauth2.credentials.Credentials(token=session['access_token'])
    service = build("sheets", "v4", credentials=credentials)
    sheets_api = service.spreadsheets()
    try:
        sheets = get_sheets(sheets_api, spreadsheet_id)
        data_by_sheets = {}
        for sheet in sheets:

            data_by_sheets[sheet] = data
    except googleapiclient.errors.HttpError as e:
        return f"upload failure"
    dirpath = os.path.join("static", "uploads", spreadsheet_id)
    filepath = os.path.join(dirpath, "data.json")
    os.makedirs(dirpath, exist_ok=True)
    with open(filepath, "w") as file:
        json.dump(data_by_sheets, file)
    return "upload success! Really!"
```
