<div id="section-3">
  ### Выбор региона рабочего пространства
</div>

</div>

<div id="section-6">
  ### Делитесь навыками в рабочем пространстве и управляйте ими
</div>

Теперь все участники рабочего пространства могут создавать навыки и выбирать, оставить их приватными или поделиться ими в рабочем пространстве. Общие навыки по умолчанию отключены для других участников, и каждый может выбрать, какие из них включить. Администраторы могут управлять всеми навыками рабочего пространства и делать определённые навыки обязательными для него. Обновлённая библиотека навыков упрощает их поиск и управление ими.

Подробнее см. в разделе [Навыки Agent](/ru/ja/features/agent/skills).

<div id="section-7">
  ## Команды и Enterprise
</div>

<div id="admin-api">
  ### Admin API теперь доступен в бета-версии
</div>

Администраторы аккаунтов Enterprise теперь могут создавать API-ключи на новой вкладке **Developer** в настройках. Кроме того, с помощью Admin API можно:

* Просматривать рабочие пространства, участников, группы пользователей, проекты и деплои.
* Просматривать данные об использовании участниками, проектами и рабочими пространствами за настраиваемый период.
* Просматривать и редактировать бюджеты рабочих пространств, групп пользователей и отдельных участников.

Подробнее см. в [документации Admin API](/ru/ja/teams/admin-api) и [справочнике API](https://api.replit.com/docs).
