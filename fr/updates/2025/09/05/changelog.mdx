  ## Plateforme
</div>

<div id="general-agent">
  ### Agent général
</div>

<Frame>
  <img src="/assets/mirror/general-agent-240ff289e711.png" alt="Illustration principale de l’Agent général" width="1040" height="572" data-path="images/replitai/general-agent.png" />
</Frame>

Replit Agent fonctionne désormais avec n’importe quelle base de code, dans tout langage ou framework s’exécutant sur NixOS ! Auparavant limité à certains templates, Agent peut maintenant vous aider avec les frameworks de développement, les imports GitHub et toute configuration de projet personnalisée. Cette évolution majeure apporte une assistance complète au codage par IA aux workflows des entreprises et des utilisateurs avancés.

En savoir plus sur l’Agent général [ici](/fr/core-concepts/agent/general-agent).

<div id="plan-mode">
  ### Plan Mode
</div>

<Frame>
  <img src="/assets/mirror/plan-mode-overview-8077807c63b9.png" alt="Interface de Chat Agent en Plan Mode" width="916" height="362" data-path="images/replitai/plan-mode-overview.png" />
</Frame>

Plan Mode offre une nouvelle façon d’échanger avec Replit Agent, axée sur les questions, le brainstorming et la planification de votre travail. Avec Plan Mode, vous pouvez utiliser Agent pour créer une liste de tâches à effectuer ultérieurement, puis exécuter des tâches de longue durée en Mode Build.

Pour en savoir plus sur Plan Mode, consultez [cette page](/fr/core-concepts/agent/plan-mode).

<div id="enterprise">
  ## Enterprise
</div>

<div id="gcp-marketplace-integration">
  ### Intégration à GCP Marketplace
</div>

Les clients Enterprise peuvent désormais acheter Replit directement sur Google Cloud Platform Marketplace et utiliser leurs crédits GCP existants pour régler leurs achats. Cela simplifie les processus d’approvisionnement et facilite l’adoption de Replit dans les workflows de développement des organisations disposant de budgets GCP.
