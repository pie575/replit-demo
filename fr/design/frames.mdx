Chaque tuile du Canvas est une **frame**. Ce sont les frames que vous sélectionnez, déplacez et modifiez. Cette page présente les types de frames, la barre d&#39;actions qui apparaît lorsqu&#39;une frame est sélectionnée, ainsi que les fonctionnalités qu&#39;elle permet de déclencher : Build et Focus.

<div id="frame-kinds">
  ## Types de frames
</div>

Les deux principaux types sont les **Artefacts** (surfaces dynamiques, adossées à une App) et les **Designs** (mockups). L&#39;en-tête en haut à gauche du frame indique de quel type il s&#39;agit.

| Type                | Libellé d&#39;en-tête         | Adossé à                             | Interaction comme une App en direct ? | Conversion en App réelle ?                                          |
| ------------------- | ----------------------------- | ------------------------------------ | ------------------------------------- | ------------------------------------------------------------------- |
| Artefact            | **Website**, **Slides**, etc. | Un artefact en cours d&#39;exécution | Oui                                   | Déjà une App.                                                       |
| Artefact mobile     | **Mobile app**                | Un artefact en cours d&#39;exécution | Oui (dans le simulateur)              | Déjà une App.                                                       |
| Design              | **Design**                    | Mockup statique / interactif         | Frame interactif uniquement           | Oui — via le menu **Build…** de chaque frame. Voir [Build](#build). |
| Image               | **Image**                     | PNG / JPG généré                     | Non                                   | Non — à utiliser comme référence.                                   |
| Vidéo               | **Video**                     | Vidéo générée                        | Non                                   | Non.                                                                |
| Graphique vectoriel | **Graphic**                   | SVG généré                           | Non                                   | Non — à intégrer dans une App réelle.                               |

<Note>
  Le fait qu&#39;un design frame se comporte comme une image statique ou comme un prototype interactif dépend de la capacité **Interactive frames**. Lorsqu&#39;elle est activée, les design frames réagissent aux clics et aux saisies de formulaire comme une véritable page ; sinon, ils s&#39;affichent comme un instantané sur lequel vous pouvez itérer, mais dans lequel vous ne pouvez pas naviguer.
</Note>

<div id="preview-on-different-devices">
  ## Prévisualiser sur différents appareils
</div>

Découvrez le rendu d&#39;un design selon la taille de l&#39;écran. Demandez à Agent de vous montrer une version mobile, tablette ou ordinateur, par exemple « Montre-moi la version mobile de cette page », et il affiche un frame à cette taille :

* **Mobile** : 390 × 844
* **Tablette** : 768 × 1024
* **Ordinateur** : 1280 × 720

<div id="per-frame-action-bar">
  ## Barre d&#39;actions par frame
</div>

Sélectionner un frame fait apparaître une barre d&#39;actions. Les actions proposées dépendent du type de frame.

<div id="artifact-and-design-frames">
  ### Frames artefact et Design
</div>

Pour les frames artefact (Website, Slides, etc.) et Design, la barre d&#39;actions s&#39;affiche en haut du frame.

<Frame caption="La barre d'actions d'un Design frame : Build…, Focus et plus d'options.">
  <img src="/assets/mirror/canvas-frame-action-bar-86f90fdd1375.png" alt="Canvas avec un Design frame APEX X1 sélectionné, affichant la barre d'actions du frame en haut avec l'étiquette de type et les actions Build, Focus et plus d'options, le frame étant attaché sous forme de puce dans le champ de prompt du chat" width="2000" height="1290" data-path="images/replitai/canvas-frame-action-bar.png" />
</Frame>

Le groupe d&#39;actions se réduit à des icônes sur les faibles largeurs et affiche les libellés à mesure que le frame s&#39;élargit. L&#39;ensemble complet, de gauche à droite :

| Action   | Rôle                                                                                                                                                                                                                    |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Export   | Télécharge le frame au format PNG. Voir [Exporter un frame en PNG](/fr/design/canvas#export-a-frame-as-png).                                                                                                               |
| Build…   | Ouvre un menu listant tous les artefacts du projet — choisissez-en un pour lui appliquer le design, ou choisissez **Build this design** pour créer un nouvel artefact. Design frames uniquement. Voir [Build](#build). |
| Focus    | Active le mode focus, qui agrandit le frame pour en faire la vue principale.                                                                                                                                            |
| Plus (…) | Actions supplémentaires sur le frame. Copier, dupliquer, réorganiser et exporter figurent également dans le [menu contextuel](/fr/design/canvas#right-click-menu) du board.                                                |

Les frames d&#39;App (Website, Slides, application mobile) affichent Focus et plus d&#39;options ; les Design frames y ajoutent Build… en amont. Pour explorer de nouvelles directions à partir d&#39;un frame sélectionné, suivez ses [suggestions](/fr/design/explore-suggestions).

Sélectionner un frame l&#39;attache également au prochain message du Chat Agent sous forme d&#39;instantané — voir [Ce qui se trouve sur le canvas](/fr/design/canvas#what-lives-on-the-canvas).

<Note>
  La barre d&#39;actions respecte le **mode lecture seule**. Lorsque le Canvas est verrouillé dans un contexte de tâche en arrière-plan, les actions d&#39;itération sont masquées et seul Focus reste disponible.
</Note>

<div id="media-frames">
  ### Frames média
</div>

Les frames d&#39;image, de vidéo et de graphique vectoriel affichent une petite barre d&#39;actions flottante au-dessus du frame. Ces trois types ont en commun :

* **Remplacer le média** : téléversez un nouveau fichier pour remplacer celui du frame, en conservant sa position et sa taille sur le Canvas.
* **Télécharger** : enregistrez le fichier média sur votre ordinateur.
* **Texte alternatif** : ajoutez un texte alternatif pour l&#39;accessibilité et pour donner plus de contexte à Agent lorsque le frame est référencé.

<Frame caption="La barre d'actions d'un frame vidéo : Remplacer le média, Télécharger et Texte alternatif.">
  <img src="/assets/mirror/canvas-frame-video-actions-905585560e90.png" alt="Un frame vidéo sélectionné représentant une supercar bleue sur le Canvas, avec sa barre d'actions flottante au-dessus, affichant les commandes Remplacer le média, Télécharger (avec une infobulle indiquant « Télécharger l'original ») et Texte alternatif." width="2000" height="1252" data-path="images/replitai/canvas-frame-video-actions.png" />
</Frame>

Les frames d&#39;image ajoutent deux commandes supplémentaires :

* **Recadrer** : rognez l&#39;image directement sur le Canvas.
* **Générer une vidéo** : générez un clip vidéo à partir de l&#39;image.

<Frame caption="La barre d'actions d'un frame d'image ajoute Recadrer et Générer une vidéo.">
  <img src="/assets/mirror/canvas-frame-image-actions-aae1378db7e3.png" alt="Un frame d'image sélectionné représentant une supercar jaune sur le Canvas, avec sa barre d'actions flottante au-dessus, affichant les commandes Remplacer le média, Recadrer, Télécharger, Texte alternatif et Générer une vidéo." width="1600" height="1002" data-path="images/replitai/canvas-frame-image-actions.png" />
</Frame>

<div id="explore-new-directions">
  ## Explorer de nouvelles directions
</div>

Sélectionner un frame fait apparaître des [suggestions](/fr/design/explore-suggestions) juste à côté : des directions accessibles en un clic, ancrées dans ce que vous avez sous les yeux, comme une autre disposition, une nouvelle ambiance ou une page qu&#39;implique votre design. Chacune est générée sous forme de nouveau frame à côté de la source : l&#39;original reste intact et vous pouvez comparer.

<div id="build">
  ## Build
</div>

Le menu **Build…** d&#39;une frame Design sélectionnée transforme le design en une application réelle et fonctionnelle. Ce même menu permet également d&#39;appliquer le design à un artefact existant.

<Frame>
  <img src="/assets/mirror/canvas-build-menu-f06b8b8b455f.png" alt="Le menu Build ouvert sur une frame Design sélectionnée (APEX X1 Exact Replica) avec l'en-tête « Build or apply your designs », affichant « Build this design », qui crée un nouvel artefact, et « Apply to an existing creation » qui répertorie l'APEX X1 Design System du projet et son site web Scroll Hero" width="2000" height="1153" data-path="images/replitai/canvas-build-menu.png" />
</Frame>

<div id="build-this-design">
  ### Build this design
</div>

Sélectionner **Build this design** dans le menu crée un nouvel artefact à partir du design frame sélectionné. Ce nouvel artefact apparaît dans la liste des artefacts du projet et devient une application active et opérationnelle. Build nécessite un plan Core ou Pro.

<div id="apply-to-an-existing-artifact">
  ### Appliquer à un artefact existant
</div>

Le menu Build… répertorie tous les artefacts du projet. En sélectionner un applique à cet artefact les modifications du Design choisi : Agent réécrit le code de l&#39;artefact pour le faire correspondre au design, tout en laissant le design frame sur le Canvas à titre de référence.

<div id="focus-mode">
  ## Mode focus
</div>

Le mode focus vous permet de travailler sur un frame sélectionné en taille réelle sans quitter Design.

<Steps>
  <Step title="Choisir Focus sur un frame">
    Sélectionnez un frame, puis choisissez **Focus** dans sa barre d&#39;actions.

    <Frame caption="L'action Focus dans la barre d'actions d'un frame sélectionné.">
      <img src="/assets/mirror/focus-before-0c9ced9218d9.png" alt="Un frame Design sélectionné sur le Canvas, avec l'action Focus mise en évidence dans la barre d'actions du frame." width="2000" height="1254" data-path="images/design/replit-design/focus-before.png" />
    </Frame>
  </Step>

  <Step title="Travailler en taille réelle">
    Le frame occupe toute la vue : vous pouvez ainsi travailler dessus de près, sans le reste du board.

    <Frame caption="Mode focus">
      <img src="/assets/mirror/focus-mode-24da418577ae.png" alt="Le mode focus affichant un frame Design qui occupe toute la vue, avec un bouton Quitter le focus en haut du board." width="2000" height="1254" data-path="images/design/replit-design/focus-mode.png" />
    </Frame>
  </Step>

  <Step title="Revenir au canvas">
    Sélectionnez **Quitter le focus** en haut du board pour revenir au canvas.
  </Step>
</Steps>
