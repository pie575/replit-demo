软件包防火墙会在恶意或受损软件包安装到应用前，在网络层将其拦截。它是 [Replit Auto-Protect](/zh/ko/features/security/concepts#auto-protect) 的一部分。Replit Auto-Protect 是一套默认向所有构建者启用的保护功能，由软件供应链安全公司 [Socket](https://socket.dev) 提供支持。

当您或 Agent 运行 `npm install` 或 `pip install` 等安装命令时，请求会先经过软件包防火墙。安全的软件包会照常安装，您不会察觉任何差异。被 Socket 标记为恶意或受损的软件包会在任何代码进入您的环境前被拦截。

软件包防火墙**默认向所有构建者启用，无需单独配置或迁移**。它同样保护新应用和现有应用，且没有任何需要配置的设置。

<div id="section">
  ## 为什么安装时防护至关重要
</div>

大多数供应链安全工具只会在软件包安装很久之后的发布阶段扫描依赖项。对于常见漏洞，这或许已经足够。但恶意软件不同：它一经安装便会造成损害——窃取密钥、打开后门或泄露环境变量。等到发布阶段扫描发现问题时，攻击早已发生。

软件包防火墙消除了这一空白。它会在恶意软件包下载前将其拦截，在任何一行恶意代码执行前阻止攻击。

<div id="section-2">
  ## 工作原理
</div>

1. 您或 Agent 执行安装命令，例如 `npm install <package>` 或 `pip install <package>`。
2. 请求会经过软件包防火墙，并依据 Socket 的威胁情报扫描软件包。
3. 如果软件包安全，安装会照常进行，您几乎感觉不到差别。
4. 如果软件包存在恶意行为或已遭篡改，安装会在任何代码进入环境前被拦截。

如果某个软件包被拦截，您会收到明确的提示，说明被中断的内容及原因，并显示触发拦截的漏洞或策略。Agent 也会获得相同的信号，因此可以建议更安全的替代方案，或例如纠正输错的软件包名称，然后将决定权交还给您。

* **Go** — Go 模块

<div id="package-firewall">
  ## 软件包防火墙检测的内容
</div>

软件包防火墙不仅会阻止纯粹的恶意软件包，还会阻止已遭入侵或存在已知漏洞的正常软件包版本，包括被广泛使用的软件包。其中许多漏洞是在推荐这些软件包的模型训练截止日期之后才公开的，因此模型可能会自信地推荐在其训练数据中原本安全、但后来发现存在问题的依赖项版本。这些风险包括：

* **拼写抢注 (Typosquats)&#x20;**&#x20;— 恶意软件包的名称与真实软件包名称仅相差一个字母，例如将 `requests` 写成 `reqeusts`。请求了错误的软件包后，就会下载恶意代码。
* **幻觉抢注 (Slopsquats)&#x20;**&#x20;— 模型编造出不存在的软件包名称，攻击者则以该名称注册软件包，等待下一个 Agent 安装它。
* **过时推荐 (Stale recommendations)&#x20;**&#x20;— 模型推荐的真实软件包；它们在训练截止日期前是安全的，但之后被公开存在漏洞。

最后这一类正是软件包防火墙对于 AI 构建的应用尤为重要的原因。Agent 可能会自信地选择已不再安全的依赖项，而软件包防火墙会在代码运行前阻止其安装。

<div id="package-firewall-replit">
  ## 软件包防火墙与 Replit 其他安全工具的关系
</div>

软件包防火墙是三个相互补充的安全层之一。每一层保护应用生命周期的不同阶段，因此应结合使用，而不是只选择其中一项。

| 层级                 | 执行时机     | 功能                                                                                                                                         |
| ------------------ | -------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| **软件包防火墙**         | 安装时      | 在恶意或已遭篡改的软件包下载前将其拦截 (预防) 。                                                                                                                 |
| **自动依赖项扫描**         | 安装后，持续进行 | 检测已安装依赖项中新披露的 CVE，并可选择由 Agent 准备补丁。请参阅 [Project Security Center](/zh/ko/features/security/project-security-center#automatic-dependency-scans)。 |
| **Security Agent** | 发布前      | 扫描整个代码库，检查代码、依赖和个人信息相关的漏洞。请参阅 [Agent 安全扫描](/zh/ko/features/security/agent-security-scans)。                                                    |
