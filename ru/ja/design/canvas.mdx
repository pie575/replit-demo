Canvas — это бесконечное пространство, по которому можно свободно перемещаться и масштабировать, где Replit Design отображает фреймы. Здесь находится всё, над чем вы работаете: создавайте фреймы, перемещайте их, приближайте детали и дорабатывайте дизайн, пока не добьётесь нужного результата.

<div id="canvas">
  ## Как открыть Canvas
</div>

Canvas — это первое, что вы видите в Replit Design. Если в проекте выбрать **Design** в шапке, Canvas развернётся на всю панель, а если выбрать **Build**, вы вернётесь к запущенному приложению.

<Frame>
  <img src="/assets/mirror/canvas-design-button-ffa50447cefb.png" alt="Крупный план шапки проекта с переключателем между Design и Build. Выбран Design, под ним показан фрейм на Canvas" width="987" height="619" data-path="images/replitai/canvas-design-button.png" />
</Frame>

Если начать с нуля на [replit.com/design](https://replit.com/design), вам предложат создать новый дизайн, и откроется Canvas. О том, какую из поверхностей и когда использовать, читайте в разделе [Различия между Design и Build](/ru/ja/design/design-vs-build).

<div id="canvas-2">
  ## Что находится на Canvas
</div>

* **Фреймы**: все элементы на доске. Фрейм может быть дизайн-макетом, веб-приложением, мобильным приложением, слайдом, изображением, видео или векторной графикой. Их можно создавать с помощью промптов в чате, [меню Generate](/ru/ja/design/toolbar#generate) на панели инструментов или [панели библиотеки](/ru/ja/design/library-panel). Все действия с фреймом — Build, Focus, предложения и другие — выполняются через сам фрейм. Подробнее см. в разделе [Фреймы](/ru/ja/design/frames).
* **Рисунки и заметки**: разметка, добавляемая с помощью [инструмента Draw](/ru/ja/design/toolbar#draw): эскизы, стрелки, фигуры и стикеры. Agent распознаёт вашу разметку, поэтому вы можете обвести проблемное место и попросить внести изменения.
* **Панель чата**: чат с Agent, закреплённый рядом с Canvas. Если выбрать фрейм перед отправкой сообщения, он будет прикреплён в виде снимка, чтобы Agent получил визуальный контекст.

Подробнее о компонентах и их взаимодействии см. в разделе [Обзор компонентов](/ru/ja/design/core-components).

<div id="section">
  ## Перемещение по доске
</div>

Панорамирование, масштабирование и выделение доступны при работе с любым инструментом, если не указано иное.

**Панорамирование:**

* Трекпад: перетаскивание двумя пальцами.
* Мышь: перетаскивание средней кнопкой либо перетаскивание левой кнопкой с зажатым пробелом.
* [Инструмент Pan](/ru/ja/design/toolbar#pan): нажмите левую кнопку мыши и перетащите.

**Масштабирование:**

* Трекпад: жест «щипок».
* Мышь: `Ctrl` (в macOS — `Cmd`) + колесо прокрутки.
* Клавиатура: `Cmd`/`Ctrl` + `+` — приблизить, `Cmd`/`Ctrl` + `-` — отдалить, `Cmd`/`Ctrl` + `0` — сбросить масштаб.

Масштаб меняется относительно положения курсора: точка под курсором остаётся на месте, а остальная часть доски увеличивается или уменьшается вокруг неё.

**Выделение:**

* Один фрейм: щёлкните по нему [инструментом Interact](/ru/ja/design/toolbar#interact).
* Несколько фреймов: удерживая `Shift`, щёлкайте по нужным фреймам или растяните рамку выделения по доске.
* Снять выделение: щёлкните по пустой области или нажмите `Escape`.

Когда выделен один или несколько фреймов, появляется [панель действий для фрейма](/ru/ja/design/frames#per-frame-action-bar), а сами фреймы прикрепляются к следующему сообщению Agent в виде снимков.

<div id="section-2">
  ### Сочетания клавиш
</div>

| Сочетание клавиш                          | Действие                              |
| ----------------------------------------- | ------------------------------------- |
| `V`                                       | Активировать инструмент Interact      |
| `H`                                       | Активировать инструмент Pan           |
| Перетаскивание с зажатой клавишей `Space` | Панорамирование из любого инструмента |
| `Cmd` / `Ctrl` + прокрутка                | Масштабирование                       |
| `Cmd` / `Ctrl` + `+`                      | Увеличить масштаб                     |
| `Cmd` / `Ctrl` + `-`                      | Уменьшить масштаб                     |
| `Cmd` / `Ctrl` + `0`                      | Сбросить масштаб                      |
| `Shift` + щелчок                          | Добавить фрейм к текущему выделению   |
| `Cmd` / `Ctrl` + `Shift` + `C`            | Скопировать выбранный фрейм как PNG   |
| `Escape`                                  | Снять выделение                       |

<div id="section-3">
  ## Контекстное меню
</div>

Щёлкните правой кнопкой мыши в любом месте доски, чтобы открыть контекстное меню. Его содержимое зависит от контекста: доступные действия меняются в зависимости от объекта под курсором. При наведении на фрейм отображаются действия для фрейма, на пустом Canvas — действия для доски, а для фреймов приложений добавляется **Refresh artifact**.

Для выбранного фрейма меню содержит следующее:

| Действие                       | Сочетание клавиш           | Описание                                                                |
| ------------------------------ | -------------------------- | ----------------------------------------------------------------------- |
| Edit                           |                            | Переключает на инструмент Edit и позволяет выбирать элементы во фрейме. |
| Chat                           |                            | Позволяет обсудить фрейм с Agent.                                       |
| Focus                          |                            | Открывает [режим фокуса](/ru/ja/design/frames#focus-mode) для фрейма.      |
| Cursor chat                    | `/`                        | Запускает быстрый чат в месте расположения курсора.                     |
| Reorder                        |                            | Перемещает фрейм вперёд или назад в порядке наложения.                  |
| Copy, Paste, Duplicate, Delete | `⌘C`、`⌘V`、`⌘D`、`Backspace` | Стандартные операции с буфером обмена и фреймами.                       |
| Export as…                     |                            | Экспортирует фрейм в файл.                                              |
| Select all                     | `⌘A`                       | Выбирает все фреймы на доске.                                           |

<div id="png">
  ### Экспорт фрейма в PNG
</div>

Любой артефакт или дизайн-фрейм можно сохранить как изображение PNG. Это удобно, если нужно поделиться превью в документе или чате, зафиксировать текущее состояние перед дальнейшими итерациями либо отправить скриншот коллегам.

<Steps>
  <Step title="Выберите фрейм">
    Выберите артефакт или дизайн-фрейм, который хотите экспортировать, и дождитесь окончания загрузки.
  </Step>

  <Step title="Выберите Export">
    На панели действий фрейма выберите **Export**. Также можно щёлкнуть по фрейму правой кнопкой мыши и выбрать **Export as…** &gt; **PNG**. Изображение загрузится на компьютер, а имя файла будет основано на названии фрейма.
  </Step>
</Steps>

Чтобы скопировать выбранный фрейм как PNG без загрузки, нажмите `Cmd+Shift+C` (в Windows и Linux — `Ctrl+Shift+C`).

<Note>Экспортированный PNG соответствует тому, что фрейм отображает на Canvas в данный момент. Если приложение или дизайн ещё загружается, дождитесь полной отрисовки и только потом выполняйте экспорт.</Note>

<div id="canvas-3">
  ## Canvas и запущенное приложение
</div>

Canvas и предпросмотр запущенного приложения занимают одну и ту же панель, а несколько режимов связывают их между собой:

* **Режим фокуса**: действие **Focus** для выбранного фрейма разворачивает его на всю область просмотра. Чтобы вернуться в Canvas, выберите **Exit focus** в верхней части доски.
* **Режим только для чтения**: когда Canvas заблокирован в контексте фоновой задачи, действия по доработке скрываются и остаётся только Focus.

<Note>
  Для создания нового приложения из фрейма в Design требуется план Core или Pro. Остальные возможности Canvas доступны на всех планах. Подробнее о планах см. в разделе [Оплата](/ru/ja/billing/ai-billing).
</Note>
