Agent 会生成一份简短的简报，涵盖待定的决策、需要回复的会话以及需要确认的会议。简报不应罗列所有消息，只需包含你真正需要关注的内容。
在实际行动之前，请先核对所使用的日期范围和频道。在 Slack 或 Gmail 中打开简报里的两个会话，确认它们是否确实需要处理。如果 Agent 起草了回复内容，可以先发一封给自己试试。

<div id="section-6">
  ## 问题排查
</div>

* **简报罗列了所有消息：** 指定重要的 Slack 频道和日历，并要求 Agent 只保留直接与你相关的决策事项和请求，忽略纯公告类频道。
* **遗漏了你离开期间的日期：** 提供包含时区的准确日期，并确认 Gmail、Slack 和 Calendar 所连接的账户与你离开期间使用的账户一致。
* **草稿不像你的语气：** 粘贴几封你实际写过的回复，让 Agent 先参照这些语气，再撰写你会发出的内容。
