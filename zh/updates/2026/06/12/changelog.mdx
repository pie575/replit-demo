<div id="customize-agent-with-workspace-instructions-and-skills">
  ### 使用工作区说明和技能自定义 Agent
</div>

现在，你只需教 Agent 一次团队的工作方式，它就能在各处应用。设置 Agent 在每个项目中都遵循的**自定义说明**，并创建可复用的**技能**，供 Agent 在特定任务中按需加载。你可以在 **工作区 设置** &gt; **自定义**中管理这两项内容。

</Frame>

<div id="block-malicious-packages-with-package-firewall">
  ### 使用 Package Firewall 拦截恶意软件包
</div>

Replit 现在会在恶意或已被入侵的软件包进入你的应用之前将其拦截。Package Firewall 会检查常见软件包管理器中的每次安装，并自动阻止有害依赖项。该功能默认启用；当某个软件包被拦截时，Agent 会调整计划，改用更安全的替代方案。

  <img src="/assets/mirror/blocked-package-message-04011660ce75.png" alt="Package Firewall 拦截恶意软件包的提示消息" width="1372" height="1144" data-path="images/package-firewall/blocked-package-message.png" />
</Frame>

详细了解 [Package Firewall](/zh/features/security/package-firewall)。

<div id="faster-slide-import-and-export">
  ### 更快地导入和导出幻灯片
</div>

PowerPoint 和 Google Slides 的导出速度提升了三到十倍，包含大量图片的大型演示文稿不再生成过大的 PDF 文件，而且只需选择一次即可导出到 Google Slides。

  <img src="/assets/mirror/slides-export-menu-f70338ff9908.png" alt="打开“导出”菜单的 Slides 工具栏，显示可将演示文稿导出为 PDF、PowerPoint 或 Google Slides 的选项" width="1812" height="926" data-path="images/artifact-types/slides-export-menu.png" />
</Frame>

详细了解如何[导出演示文稿](/zh/features/artifact-types/slide-decks#exporting)。

<div id="add-visual-references-when-you-generate-media-on-canvas">
  ### 在 Canvas 上生成媒体时添加视觉参考
</div>

在 Canvas 上生成图像、视频或矢量图形时，现在可以将画板上已有的内容作为视觉参考附加。选择一个画框、便笺或图像，Agent 会据此引导生成结果，使生成的媒体与您的项目风格保持一致。

<Frame caption="打开“生成媒体”表单中的 + 菜单，上传文件或选择 Canvas 元素。">
  <img src="/assets/mirror/canvas-generate-media-references-ac0cb4340acb.png" alt="Canvas 上的“生成媒体”表单，+ 菜单已打开，显示“上传文件”和“选择 Canvas 元素”选项，模型下拉菜单设为 Nano Banana Pro" width="1134" height="662" data-path="images/replitai/canvas-generate-media-references.png" />
</Frame>

<Note>
  ChatGPT Images 2.0 目前不支持上传。请切换至其他模型 (例如 Nano Banana Pro) ，以附加视觉参考。
</Note>

详细了解[如何在 Canvas 上生成媒体](/zh/design/toolbar#generate)。

<div id="choose-which-production-alerts-reach-your-inbox">
  ### 选择要接收哪些生产环境警报
</div>

现在，你可以单独管理生产环境警报，不再与其他电子邮件混在一起。新的 **生产环境警报** 设置可决定 Replit 是否通过电子邮件向你通知正常运行时间事件、依赖项中的安全漏洞和语言模型更新。如果已发布的 App 使用了过时的模型，Replit 还会创建一个任务草稿，你只需审核一次即可完成升级。

<Frame caption="在“设置”→“个性化”→“电子邮件”中找到“生产环境警报”。">
  <img src="/assets/mirror/production-alerts-settings-333bb4ee8a61.png" alt="通知设置中的“生产环境警报”部分，显示生产环境警报电子邮件开关已开启，且安全警报严重程度下拉菜单已展开" width="2000" height="899" data-path="images/editor/production-alerts-settings.png" />
</Frame>

详细了解[通知设置](/zh/features/editor/user-settings#notifications)。
