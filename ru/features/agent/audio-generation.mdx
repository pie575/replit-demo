Добавляйте звук в свои приложения с помощью возможностей генерации аудио в Agent. Попросите Agent создать фоновую музыку, звуковые эффекты или закадровую озвучку — и он добавит аудио прямо в ваш проект.

Генерация аудио помогает создавать более насыщенные впечатления без студий звукозаписи, актёров озвучивания и сторонних инструментов. Игра, пошаговое обучение или приложение, которому нужен голос, — Agent создаст аудио, подходящее вашему проекту.

<div id="what-you-can-create">
  ## Что можно создать
</div>

Agent может генерировать три вида аудио:

* **Музыка**: фоновые треки и заглавные темы в том настроении и стиле, которые вы опишете.
* **Звуковые эффекты**: короткие фрагменты — щелчки, оповещения, свисты и игровые звуки.
* **Речь**: естественно звучащая озвучка и закадровый голос по вашему тексту.

<div id="usage">
  ## Использование
</div>

Генерация аудио встроена в Agent, поэтому ничего дополнительно включать не нужно. Откройте любое Replit App с Agent и опишите, какое аудио вам нужно. Agent сам определит, когда требуется сгенерировать аудио, создаст фрагмент и добавит его в ваш проект.

<div id="when-agent-generates-audio">
  ### Когда Agent создаёт аудио
</div>

Agent создаёт аудио, когда вы просите добавить звук в ваш проект:

| Сценарий использования   | Пример промпт                                                            |
| ------------------------ | ------------------------------------------------------------------------ |
| Фоновая музыка           | «Добавь спокойную фоновую музыку в моё приложение для медитации»         |
| Звуковые эффекты в играх | «Создай звук сбора монеты и звук прыжка для моей игры»                   |
| Голосовая озвучка        | «Сгенерируй дружелюбный голос, который вслух зачитывает шаги онбординга» |
| Оповещения и уведомления | «Сделай короткий сигнал, который звучит при получении нового сообщения»  |

<div id="how-audio-fits-into-your-app">
  ## Как аудио встраивается в ваше приложение
</div>

Agent добавляет сгенерированное аудио в проект так же, как и любые другие ресурсы:

* **Автоматическое создание файлов**: сгенерированные аудиофайлы сохраняются прямо в проект.
* **Обновление кода**: Agent встраивает аудио в приложение так, чтобы оно воспроизводилось в нужный момент.
* **Доработка**: попросите Agent изменить настроение, длительность, голос или стиль — и он сгенерирует аудио заново.

<div id="billing">
  ## Оплата
</div>

Генерация аудио — это сервис Agent. Agent тарифицирует её по ставке провайдера, списывая средства с ваших кредитов Replit. Списания отображаются на [странице использования](/ru/billing/managing-spend).

<Note>
  Генерация аудио в Replit работает на технологии [ElevenLabs](https://elevenlabs.io/), которая создаёт высококачественную музыку, звуковые эффекты и речь.
</Note>
