Каталог навыков — это коллекция готовых навыков, которые можно установить и сразу использовать; они созданы Replit и партнёрами. Установите навык, попробуйте его в деле, а затем адаптируйте под то, как реально работает ваша команда.

О том, что такое навыки и как Agent их загружает, читайте в разделе [Agent Skills](/ru/ko/features/agent/skills). О том, как сделать навык доступным во всём рабочем пространстве, читайте в разделе [Agent Customization](/ru/ko/features/agent/agent-customization).

<div id="section">
  ## Установка навыков
</div>

Добавить навык из каталога можно несколькими способами:

* **Из чата** — нажмите кнопку **+** рядом с полем ввода чата, выберите **Использовать навык** и укажите нужный. Такой навык действует только для этого сообщения, и в проект ничего не устанавливается.
* **Из проект** — откройте **панель Skills** в Project Editor, перейдите на вкладку **Discover**, найдите навык и нажмите **Install**. Установленные навыки сохраняются в каталоге `/.agents/skills` вашего проекта и остаются доступными в разных чатах.
* **Из командной строки** — установите навык с помощью [skills CLI](https://github.com/vercel-labs/skills):

  ```bash theme={null}
  npx skills <skill> -a replit
  ```

<Warning>
  Навыки из селектора навыков Replit прошли проверку безопасности. Навыки, установленные из внешних источников, — нет. Навык — это инструкции, которым следует Agent, поэтому всегда проверяйте внешние навыки перед установкой: о том, на что обратить внимание, читайте в разделе [Agent skills](/ru/ko/learn/agent-skills).
</Warning>

<div id="replit">
  ## Навыки Replit
</div>

Replit предлагает готовые навыки, доступные в чате в селекторе **Использовать навык**, а также в селекторе начальной точки для новых проектов. Эти навыки работают в любом проекте без установки. Описания появляются сразу же, как только вы откроете селектор.

| Категория                               | Навыки                                                                                                        |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| Продажи и маркетинг                     | Ad Creative, AI SDR, SEO Auditor, Programmatic SEO, GEO, Content Machine, Storyboard                          |
| Карьера                                 | AI Recruiter, Resume Maker, Interview Prep                                                                    |
| Исследования и анализ                   | Competitive Analysis, Deep Research, GitHub Solution Finder, Supplier Research                                |
| Бизнес и финансы                        | Stock Analyzer, Excel Generator, Invoice Generator, Tax Reviewer                                              |
| Документы и инструменты                 | Website Cloner, File Converter, Flashcard Generator, Legal Contract, Infographic Builder, Recreate Screenshot |
| Творчество                              | Photo Editor, Podcast Generator, Podcast Marketing, Branding Generator, Video Editing                         |
| Продуктивность                          | AI Secretary, Product Manager, Design Thinker, Skill Finder, Skill Creator                                    |
| Личное                                  | Travel Assistant                                                                                              |
| Безопасность и соответствие требованиям | Secrets, Sensitive Data, Input Validation, AI Security, Dependency Vetting, License Check                     |
| Качество и надёжность                   | Accessibility, Responsive UI, Observability, Resilience, Ship Review                                          |

<Note>
  В рабочем пространстве селектор также обнаруживает дополнительные навыки, установленные в каталог проекта `.local/secondary_skills/`.
</Note>

<div id="section-2">
  ## Партнёрские навыки
</div>

Партнёры Replit публикуют навыки, которые учат Agent создавать приложения на базе их продуктов. Установите такой навык — и Agent освоит паттерны и соглашения соответствующего сервиса.

| Партнёр          | Чему учит Agent                                              |
| ---------------- | ------------------------------------------------------------ |
| Stripe           | Паттерны интеграции платежей и биллинга                      |
| PayPal           | Паттерны интеграции платежей                                 |
| RevenueCat       | Паттерны подписок и встроенных покупок                       |
| Mixpanel         | Реализация аналитики и отслеживания                          |
| BigQuery         | Паттерны запросов к хранилищу данных                         |
| Resend           | Интеграция транзакционных писем                              |
| Google Workspace | Интеграция Gmail, Drive, Docs, Calendar                      |
| Atlassian        | Рабочие процессы с задачами и страницами в Jira и Confluence |
| Google Maps      | Интеграция карт, мест, маршрутов и геокодирования            |

<div id="section-3">
  ## Навыки сообщества
</div>

Помимо навыков от Replit и партнёров есть навыки, опубликованные сообществом, — их тоже можно установить. Посмотреть их можно на [skills.sh](https://skills.sh), а если хотите написать собственный навык, ознакомьтесь со [спецификацией Agent Skills](https://agentskills.io/specification).
