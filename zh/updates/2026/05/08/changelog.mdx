<div id="workspace-security-center-20">
  ### Workspace 安全中心 2.0
</div>

在一处审查并处理 workspace 中所有项目的依赖漏洞。Workspace 安全中心现在会优先展示风险最高的项目，并支持你按严重程度、发布状态、可见性和所有者搜索和筛选受影响的项目。你还可以无需离开安全中心即可完成完整的修复流程：启动 Agent task、审查建议的修复方案，然后重新发布项目。你可以单独或批量通知项目所有者，立即取消发布高风险暴露的项目，并下载 SBOM 用于合规审计。

<div id="private-publishing-for-everyone">
  ### 面向所有人的私密发布
</div>

此前，私密发布和密码保护发布仅限 Pro 和 Enterprise 套餐使用。现在，Core 和 Starter 套餐的构建者也可以私密发布应用，让内部工具、Beta 应用或尚在开发中的项目仅限通过 Replit 登录访问。

详细了解[私有部署](/zh/features/publishing/private-deployments)。

<div id="external-access-tokens-for-private-deployments">
  ### 私有部署的外部访问令牌
</div>

私有 Replit Apps 现已支持外部访问令牌。您可以创建令牌，以设置可独立于 connector 访问私有部署的集成，例如 Slack、GitHub、Twilio 等。这让高级用户能够更好地掌控应用，同时进一步提升私有 Replit Apps 的安全性。在部署中打开 **调整设置**，即可找到新的 **外部访问令牌** 选项卡。

详细了解[外部访问令牌](/zh/references/publishing/external-access-tokens)。

<div id="speaker-notes-and-presenter-view-in-slide-decks">
  ### 幻灯片演示文稿中的演讲者备注和演示者视图
</div>

幻灯片演示文稿现已支持演讲者备注和专用的演示者视图。备注可在编辑器和演示窗口之间双向实时同步，因此您可以用一台设备远程控制演示文稿，同时通过另一台设备共享屏幕。让 Agent 为您撰写备注，然后在编辑器中进行完善，而观众只能看到幻灯片。移动端的幻灯片 artifact 卡片也支持使用演示者视图。

<div id="agent-accepts-svg-uploads">
  ### Agent 支持上传 SVG 文件
</div>

现在，你可以将 SVG 文件附加到 Agent。将 SVG 拖到聊天窗口中或粘贴 URL，Agent 会像读取其他附件一样读取其中的标记内容。上传的文件会在浏览器中经过净化处理后才会发送到 Agent 或存储空间，因此常见的基于 SVG 的攻击向量会被自动移除。

<div id="new-animated-icons-for-agent-modes">
  ### Agent 模式新增动画图标
