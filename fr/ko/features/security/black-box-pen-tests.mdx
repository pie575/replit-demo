---
title: "Test d’intrusion en boîte noire"
description: "Lancez une analyse de sécurité Level 3 qui examine le code source et teste une application en cours d’exécution via des interactions avec le navigateur et le réseau."
---

Les tests d’intrusion en boîte noire évaluent une application en cours d’exécution de l’extérieur, via des interactions avec le navigateur et le réseau. Ils n’utilisent pas le code source de l’application.

Dans le Centre de sécurité du projet, **Level 3 (AI pentest)** regroupe trois types de vérifications de sécurité.

1. Vérifications gratuites des dépendances et des paquets
2. Analyse statique du code source par Agent
3. Test externe en boîte noire d’un Preview en ligne, sans utiliser le code source

Lorsque vous lancez Level 3, Replit exécute simultanément la revue du code source par Agent et le test externe en boîte noire.

<div id="level-3">
  ## Exécuter un scan Level 3
</div>

<Steps>
  <Step title="Ouvrir un projet">
    Ouvrez le projet que vous souhaitez analyser.
  </Step>

  <Step title="Ouvrir Security Center">
    Dans le panneau **Tools** du projet, sélectionnez **Security Center**.
  </Step>

  <Step title="Lancer le scan">
    En haut de Security Center, sélectionnez **Run scan**.
  </Step>

  <Step title="Sélectionner Level 3">
    Sélectionnez **Level 3 (AI pentest)**.

    <Frame caption="Level 3 (AI pentest) ajoute l’analyse statique par Agent et des tests externes sur une Preview en ligne aux vérifications gratuites des dépendances et des paquets.">
      <img src="/assets/mirror/level-3-ai-pentest-c223c0099d3f.png" alt="Le menu Select scan level est ouvert dans Security and Privacy Center, accessible depuis le panneau Tools, avec Level 3 AI pentest sélectionné" width="2204" height="1200" data-path="images/project-security-center/level-3-ai-pentest.png" />
    </Frame>
  </Step>

  <Step title="Attendre la fin des deux tâches">
    Attendez la fin de la revue du code source et des tests en boîte noire du navigateur et du réseau.
  </Step>

  <Step title="Examiner les résultats">
    Examinez les constats des deux tâches dans le panneau **Security**. Évaluez chaque constat avant d’envoyer les problèmes validés à Agent.
  </Step>

  <Step title="Relancer le scan après les corrections">
    Envoyez les constats validés à Agent. Après avoir appliqué les corrections, relancez le scan Level 3 pour vérifier.
  </Step>
</Steps>

<div id="section">
  ## Comprendre les deux tâches
</div>

| Tâche                           | Éléments utilisés                                                                   | Objectif                                                                                            |
| ------------------------------- | ----------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| Revue du code source            | Code source de l’application                                                        | Identifie les vulnérabilités de sécurité, de confidentialité et d’architecture dans la base de code |
| Test d’intrusion en boîte noire | Interactions via le navigateur et le réseau avec l’application en cours d’exécution | Examine les comportements observables de l’extérieur sans utiliser le code source                   |

Examinez les deux ensembles de constats. Une tâche ne remplace pas l’autre. La revue du code source peut identifier des faiblesses dans l’implémentation, tandis que les tests en boîte noire évaluent l’application en cours d’exécution depuis l’extérieur.
