  ### 可视化编辑器
</div>

我们刚刚推出了一项激动人心的新功能——现在你可以在 JavaScript 应用的项目中直接点击选中页面元素！

这让界面的创建和编辑比以往更加直观。想了解更多？请查看我们博客上的详细指南：[https://blog.replit.com/cartographer](https://blog.replit.com/cartographer)。

<div id="mensagens-na-linha-do-tempo-do-agent">
  ### Agent 时间线消息
</div>

现在，每当 Agent 为你的项目配置 Blueprint 时，你都会看到相应的视觉提示。这样你可以更轻松地掌握 Agent 的动向，了解开发过程。
