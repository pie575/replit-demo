<div id="section">
  ## Qu&#39;est-ce qu&#39;un projet ?
</div>

Un projet est le conteneur de tout ce que vous créez sur Replit. Il regroupe le code, les données et tous les artifacts que vous produisez (applications web, applications mobiles, présentations, tableaux de bord de données, vidéos). Lorsque vous indiquez à Agent ce que vous souhaitez, il configure un projet et y construit les artifacts.

Voyez un projet comme l&#39;espace de travail sur votre bureau : tout se trouve au même endroit et partage les mêmes informations, mais chaque élément remplit un rôle différent.

Par exemple, si vous demandez à Agent de créer une application de suivi d&#39;activité physique, il crée un projet contenant un artifact d&#39;application mobile ainsi que le backend, la base de données et le stockage nécessaires à son fonctionnement.

<ArtifactGrid />

Concepts clés :

* **Projet** : le conteneur qui regroupe tout — code, données et tous les artifacts
* **Artifact** : un résultat publiable au sein du projet (application web, présentation, vidéo, etc.)
* **Ressources** : chaque artifact accède automatiquement au backend, à la base de données et au stockage de fichiers — aucune configuration requise

<Note>
  Lors de la publication, l&#39;ensemble du projet est déployé en une seule fois. Tous les artifacts sont publiés simultanément, ils restent donc toujours synchronisés.
</Note>

| **Jeux 3D**                                                                  | Jeux 3D, simulations et expériences interactives                               | Jeux de réflexion, simulations physiques, expériences interactives             |
| **[Design](/fr/ja/design/canvas)**                                              | Directions visuelles et prototypes à explorer sur le Canvas de design          | Planches d&#39;ambiance, maquettes, explorations de design                     |

Un même projet peut contenir plusieurs artifacts. Vous pouvez par exemple créer une application web pour vos clients, une application mobile pour votre équipe et une présentation pour vos investisseurs, le tout dans le même projet. Les artifacts d&#39;un même projet partagent automatiquement les mêmes données et la même logique côté serveur. Pour en savoir plus, consultez [Artifacts](/fr/ja/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project).

<div id="section-3">
  ## Gérer vos projets
</div>

La page Projets répertorie tous les projets que vous avez créés ou auxquels vous avez été invité. C&#39;est le moyen le plus rapide de reprendre vos travaux récents et de retrouver le bon projet dans un espace de travail bien rempli.

<div id="section-4">
  ### Voir en un coup d&#39;œil le contenu de chaque projet
</div>

Chaque carte de projet affiche de petites icônes représentant les artifacts qu&#39;elle contient (application web, application mobile, présentation, visualisation de données, animation). Survolez une icône pour prévisualiser une capture d&#39;écran de l&#39;artifact directement sur la carte : vous distinguez ainsi vos projets sans avoir à les ouvrir.

<div id="section-5">
  ### Filtrer par artifact
</div>

Utilisez la liste déroulante **Type de build** en haut de la page des projets pour filtrer la liste par artifact. Lorsque vous en sélectionnez un, seuls les projets contenant ce type d&#39;artifact s&#39;affichent :

* **Web** — projets contenant une application web
* **Mobile** — projets contenant une application mobile
* **Données** — projets contenant une visualisation de données
* **Diapositives** — projets contenant une présentation
* **Design** — projets en mode Design
* **Jeux 3D**, **Agents et automatisation**, etc.

Sélectionnez **Tous les types de build** pour effacer le filtre.

<div id="section-6">
  ### Trier par date de dernière ouverture
</div>

Par défaut, la page des projets est triée selon **l&#39;ordre dans lequel vous les avez ouverts en dernier** : les projets sur lesquels vous avez travaillé récemment apparaissent en haut. C&#39;est particulièrement pratique dans les espaces de travail d&#39;équipe, car les modifications récentes des autres membres ne risquent pas de noyer votre travail en cours.

Vous pouvez modifier le tri en sélectionnant un autre en-tête de colonne (par exemple **Dernière modification** ou **Nom**).

<div id="section-7">
  ### Épingler vos projets fréquemment utilisés
</div>

Épinglez un projet pour le maintenir en haut de la liste. Les épingles sont **personnelles** : épingler un projet dans un espace de travail d&#39;équipe ne change rien à ce que voient les autres membres.

Pour épingler un projet, ouvrez le menu contextuel (les trois points) de la carte du projet, puis sélectionnez **Épingler**. Pour retirer l&#39;épingle, sélectionnez **Désépingler** dans le même menu.
