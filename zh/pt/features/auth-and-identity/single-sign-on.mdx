<Note>
  你想为自己的 **Replit 组织** (登录 replit.com) 强制启用 SSO 吗？这需要单独配置——请参阅[单点登录 (SAML SSO) ](/zh/pt/teams/identity-and-access-management/saml)。本页介绍的是如何为**你在 Replit 上创建的应用**的登录流程添加 SSO。
</Note>

让用户使用所在公司的身份提供方 (如 Okta 或 Microsoft Entra ID) 登录你的应用。如果你的应用使用 [Clerk Auth](/zh/pt/features/auth-and-identity/clerk-auth)，可通过 Clerk 控制台配置 SSO 及其他高级认证功能。把你的需求告诉 Agent，Agent 会引导你前往控制台完成配置。

<Frame>
  <img src="/assets/mirror/sso-cover-28a76bfa16fb.jpeg" alt="带有锁形图标的 Replit SSO 应用创建横幅，展示一位开发者在笔记本电脑上工作。" width="1920" height="1080" data-path="images/workspace/auth/sso-cover.jpeg" />
</Frame>

Clerk 控制台的功能远不止默认的登录体验。你在 Clerk 中做的任何配置，都会自动应用到 Replit 应用的认证流程中。

<div id="o-que-voc-pode-configurar">
  ## 你可以配置的内容
</div>

* **企业 SSO 连接**：使用 OIDC 或 SAML 配置 Okta 或 Microsoft Entra ID 的单点登录，让客户通过所在公司的身份提供方登录。SSO 还能保护处理敏感数据的内部工具，用公司现有的身份提供方替代手动维护的邮箱白名单。
* **多因素认证 (MFA)&#x20;**：为应用的登录流程添加 MFA。
* **会话控制**：调整会话时长和验证频率。
* **其他 Clerk 设置**：Clerk 的其他配置会自动应用到你的 Replit 应用。请勿修改 API 密钥或环境设置——这些由 Replit 管理。参见[开发环境与生产环境](/zh/pt/features/auth-and-identity/clerk-auth#development-and-production-environments)。

<div id="abra-o-painel-do-clerk">
  ## 打开 Clerk 控制台
</div>

向 Agent 说明你需要的身份验证改动。Agent 会尽可能自动完成配置；对于需要你亲自操作的设置，它会引导你前往该应用的 Clerk 控制台。

<Frame>
  <img src="/assets/mirror/build-with-sso-agent-workflow-46422788bd18.webp" alt="Agent 引导使用 Clerk 的应用在 Clerk 控制台中配置企业级 SSO。" width="1602" height="1080" data-path="images/workspace/auth/build-with-sso-agent-workflow.webp" />
</Frame>

你也可以从 Workspace 打开该控制面板：

1. 在 Tools 面板中，选择 **Users &amp; Auth**。
2. 选择 **Configure** 选项卡。
3. 选择 **Advanced**。
4. 在 **Clerk dashboard** 下，选择 **Open Clerk dashboard**。

<Frame>
  <img src="/assets/mirror/open-clerk-dashboard-tools-pane-a314ffea741d.webp" alt="Users & Auth 工具已打开 Configure 选项卡，显示 Advanced 部分和 Open Clerk dashboard 按钮。" width="2158" height="1372" data-path="images/workspace/auth/open-clerk-dashboard-tools-pane.webp" />
</Frame>

<div id="configure-uma-conexo-sso-empresarial">
  ## 配置企业级 SSO 连接
</div>

1. 在 Clerk 控制台中，选择 **Configure**。
2. 在 **User &amp; authentication** 下，选择 **SSO connections**。
3. 选择 **Enterprise**。
4. 选择 **Add connection**。

<Frame>
  <img src="/assets/mirror/build-with-sso-enterprise-connections-b0a6a27885b5.webp" alt="Clerk 控制台显示企业级 SSO 连接页面和 Add connection 操作。" width="1826" height="1080" data-path="images/workspace/auth/build-with-sso-enterprise-connections.webp" />
</Frame>

如需了解连接的完整配置步骤，请查阅 [Clerk 文档](https://clerk.com/docs)。

<div id="valide-a-conexo">
  ### 验证连接
</div>

完成配置后，使用身份提供方中的测试账号登录，确认该账号能够访问应用中预期的部分。

如果登录失败，可以向 Agent 求助，并在提问中说明身份提供方、协议以及错误信息。

<Note>
  本页介绍的是应用自身登录流程中的企业级 SSO。若需使用 Google、GitHub、Apple 或 X 进行社交登录 (在 Workspace 中称为 **SSO providers**) ，请参阅[登录提供方](/zh/pt/features/auth-and-identity/sign-in-providers)。本页不涉及从 Replit Auth 迁移，也不涉及 Replit 账号的 SAML 登录。
</Note>

<div id="preos-e-disponibilidade">
  ## 定价与可用性
</div>

Clerk 控制台的访问权限包含在 [Replit Pro](/zh/pt/billing/plans/replit-pro) 套餐中。Enterprise 套餐即将支持。

<Info>
  企业级 SSO 连接在 2026 年 10 月 1 日前免费。此后，SSO 将按 Clerk 的定价收费，并计入你的 Replit 账单。
</Info>
