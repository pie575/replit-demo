Ces réponses portent sur l&#39;utilisation d&#39;Agent. Pour une référence complète, consultez la [présentation d&#39;Agent](/fr/ja/features/agent/overview), les [modes Agent](/fr/ja/features/agent/agent-modes) et la [facturation de l&#39;IA](/fr/ja/billing/ai-billing).

<AccordionGroup>
  <Accordion title="Agent se fige ou se déconnecte sans cesse : comment résoudre ce problème ?">
    1. Ouvrez la palette de commandes avec `Cmd+K` sur Mac ou `Ctrl+K` sur Windows.
    2. Recherchez et sélectionnez **Restart compute** pour redémarrer votre environnement de développement.
    3. Ouvrez une nouvelle discussion avec Agent, puis décrivez à nouveau votre tâche pour continuer.

    Lorsque Agent semble figé, n&#39;envoyez pas de messages à répétition : les messages supplémentaires génèrent des instructions contradictoires. Si Agent reste bloqué sur la même tâche, découpez le travail en prompts plus courts et plus ciblés.
  </Accordion>

  <Accordion title="Agent tourne en boucle ou répète les mêmes étapes : comment l’arrêter ?">
    1. Sélectionnez **Arrêter** dans le panneau Agent pour l&#39;interrompre immédiatement.
    2. Ouvrez la palette de commandes avec `Cmd+K` sur Mac ou `Ctrl+K` sur Windows, puis recherchez et sélectionnez **Restart compute**.
    3. Ouvrez une nouvelle discussion Agent et reformulez la tâche de manière plus précise.

    Pour éviter les boucles :

    * Découpez les grandes tâches en prompts plus courts — un seul objectif par message.
    * Utilisez le [mode Plan](/fr/ja/features/agent/plan-mode) pour délimiter la portée du travail avant qu&#39;Agent ne commence à construire.
    * Définissez des limites d&#39;utilisation dans [Gérer les dépenses](/fr/ja/billing/managing-spend) afin qu&#39;une boucle n&#39;entraîne pas de frais importants.
  </Accordion>

  <Accordion title="Comment réduire les coûts d’Agent — quels paramètres sont réellement utiles ?">
    Ces options sont les plus efficaces :

    * **[Mode Free](/fr/ja/features/agent/agent-modes)** — le travail quotidien avec l&#39;Agent, sans frais dans la limite de l&#39;allocation, pour les abonnés Core et Pro.
    * **[Mode Power](/fr/ja/features/agent/agent-modes)** — des capacités supérieures à un prix abordable lorsque votre travail l&#39;exige.
    * **[Mode Plan](/fr/ja/features/agent/plan-mode)** — cadrez et approuvez le travail avant que l&#39;Agent ne se lance dans la construction, afin de ne pas payer pour des modifications inutiles.
    * **Limites d&#39;utilisation et budgets** — définissez des plafonds stricts dans [Gestion des dépenses](/fr/ja/billing/managing-spend).

    Il est également utile de démarrer une nouvelle discussion avec l&#39;Agent lorsque vous changez de tâche. Consultez le tableau de bord d&#39;utilisation pour repérer les tâches les plus coûteuses.
  </Accordion>

  <Accordion title="Que sont les modes Agent et quelles sont leurs différences ?">
    Agent propose trois modes principaux. Pour toutes les précisions, consultez le [mode Free](/fr/ja/help/free-agent-mode).

    * **Mode Free** — un usage quotidien d&#39;Agent sans frais pour les abonnés Core et Pro, dans la limite d&#39;un quota qui se réinitialise toutes les 5 heures et d&#39;un plafond hebdomadaire. Le forfait Starter conserve ses limites actuelles. Pour consulter votre utilisation, rendez-vous dans **Paramètres → Utilisation**.
    * **Power** — le mode payant intermédiaire, qui donne accès à des modèles puissants à un tarif abordable.
    * **Max** — le mode payant le plus élevé, qui donne accès aux meilleurs modèles de pointe pour les tâches les plus exigeantes.
    * **Turbo** — une option facultative des paramètres avancés, disponible uniquement avec Max.

    Les modes payants ont été renommés : **Economy devient Power**, et le mode auparavant **appelé Power devient Max**. Vos réglages de mode existants sont conservés sous les nouveaux noms. Si une requête nécessite plus de capacité que le mode Free, Agent peut proposer une option payante **Autoriser une seule fois**. Replit demande une confirmation avant le lancement de toute action payante, puis Agent revient au mode Free.

    Par ailleurs, le [mode Plan](/fr/ja/features/agent/plan-mode) permet à Agent de cadrer le travail avant d&#39;apporter des modifications, tandis que le mode Build applique les changements directement. Consultez [Comparaison entre le mode Plan et le mode Build](/fr/ja/learn/plan-vs-build-mode).
  </Accordion>

  <Accordion title="Agent a apporté des modifications indésirables — comment effectuer une restauration ?">
    Replit enregistre des [points de contrôle](/fr/ja/features/version-control/checkpoints-and-rollbacks) pendant que l&#39;Agent travaille. Dans le chat de l&#39;Agent, repérez le message qui précède la modification que vous souhaitez annuler, puis sélectionnez l&#39;option de restauration affichée à côté pour ramener votre projet à cet état.

    Pour connaître toutes les options de restauration, y compris la récupération de fichiers spécifiques, consultez [Points de contrôle et restaurations](/fr/ja/features/version-control/checkpoints-and-rollbacks).
  </Accordion>

  <Accordion title="Agent indique qu’il ne peut pas accéder à Internet ou à des API externes : est-ce normal ?">
    Pendant les phases de build et d&#39;édition, Agent fonctionne dans un environnement sandbox aux accès sortants restreints. Les apps publiées peuvent effectuer des appels d&#39;API externes à l&#39;exécution : le sandbox s&#39;applique à l&#39;environnement d&#39;édition d&#39;Agent, pas à l&#39;app en cours d&#39;exécution.

    Si des appels d&#39;API échouent dans votre app en cours d&#39;exécution, vérifiez que vos clés sont bien enregistrées dans le volet [Secrets](/fr/ja/core-concepts/project-editor/app-setup/secrets), puis consultez la page d&#39;état du fournisseur. Sur les réseaux d&#39;entreprise ou d&#39;établissement scolaire, les connexions sortantes depuis les apps peuvent être bloquées : renseignez-vous auprès de votre administrateur réseau.
  </Accordion>

  <Accordion title="Puis-je utiliser ma propre clé API avec Agent ?">
    Oui. Lorsque vous ajoutez des clés dans le volet [Secrets](/fr/ja/core-concepts/project-editor/app-setup/secrets), votre application les utilise pour ses appels d&#39;API. Ouvrez l&#39;outil **Secrets**, sélectionnez **+ Nouveau secret**, puis saisissez un nom (par exemple `OPENAI_API_KEY`) et une valeur.

    Vous pouvez [utiliser vos propres clés de fournisseur d&#39;IA](/fr/ja/features/integrations/replit-ai-integrations) pour les modèles appelés par votre application. En revanche, les modèles qui alimentent l&#39;expérience Agent elle-même s&#39;exécutent sur l&#39;infrastructure de Replit et ne peuvent pas être remplacés.
  </Accordion>

  <Accordion title="Agent continue d’ajouter des fonctionnalités que je n’ai pas demandées. Comment obtenir un comportement plus précis ?">
    Recentrez Agent avec des prompts plus stricts :

    * Commencez par le mot *Only* (« uniquement ») — par exemple : « Ajoute uniquement un bouton de suppression à la carte utilisateur. Ne modifie rien d&#39;autre. »
    * Utilisez d&#39;abord le [mode Plan](/fr/ja/features/agent/plan-mode) pour vérifier ce qu&#39;Agent compte faire avant qu&#39;il n&#39;apporte des modifications.
    * Si Agent effectue une modification non souhaitée, demandez-lui immédiatement de l&#39;annuler dans la même conversation.

    Pour en savoir plus, consultez [Rédiger des prompts efficaces](/fr/ja/learn/effective-prompting).
  </Accordion>
</AccordionGroup>
