export const YouTubeEmbed = ({videoId, title = "Vidéo YouTube", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

  ### Applications mobiles sur Replit
</div>

<YouTubeEmbed videoId="YSeDWL4cDLs" title="Applications mobiles sur Replit" />

Créez des apps iOS natives à partir d’un simple prompt. Agent crée des apps React Native complètes, et vous pouvez y ajouter au fur et à mesure des fonctionnalités telles que des bases de données, des paiements Stripe ou des intégrations OpenAI. Prévisualisez votre app en scannant un code QR avec Expo Go, puis soumettez-la à l’App Store via le processus guidé de Replit. Apple examine et distribue les apps via l’App Store.

<div id="redesigned-tool-calls-ui-in-agent-chat">
  ### Refonte de l&#39;UI des appels d&#39;outils dans le Chat Agent
</div>

Le Chat Agent propose désormais une interface plus épurée et plus compacte pour les appels d&#39;outils. Ces derniers se regroupent en lignes repliables avec des icônes empilées, ce qui permet de voir d&#39;un coup d&#39;œil ce qui se passe. Les modifications et créations de fichiers renvoient directement au panneau de différences pour une relecture rapide. Cette présentation simplifiée vous aide à suivre les exécutions d&#39;Agent avec moins de bruit et plus de clarté.

<div id="nodejs-security-patch">
  ### Correctif de sécurité Node.js
</div>

Une vulnérabilité de sécurité critique a été signalée dans Node.js cette semaine. Tous les environnements de développement Agent ainsi que les applications Node.js de Replit ont été mis à jour vers des versions sécurisées. Vos apps passeront elles aussi à la version sécurisée lors de leur prochaine republication.
