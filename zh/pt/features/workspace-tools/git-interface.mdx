Replit 中的 Git 面板提供了用于执行 Git 操作的可视化界面，无需在命令行中使用 Git 命令。该功能让初学者也能轻松进行版本控制，同时满足经验丰富的开发者的需求。

<div id="recursos">
  ## 功能
</div>

Git 面板在项目编辑器中直接提供完整的版本控制功能，通过直观的界面简化复杂的 Git 操作。

* **仓库管理**：借助 GitHub 集成初始化、连接和管理 Git 仓库
* **提交跟踪**：暂存 (stage) 、提交并查看所有文件的更改
* **分支操作**：以可视化方式创建、切换和合并分支
* **冲突解决**：借助可视化辅助识别并解决合并冲突
* **Shell 集成**：同步 Shell 中执行的 Git 命令与 Git 面板

<div id="uso">
  ## 使用
</div>

<div id="configurao-do-repositrio">
  ### 仓库配置
</div>

<Accordion title="如何访问 Git 面板">
  1. 前往 Replit App 中的 Tools 部分
  2. 选择 **+** 图标以添加新工具
  3. 在可用工具列表中选择 **Git**
</Accordion>

Git 面板可帮助你配置并连接仓库：

* **Initialize repository**：为你的 Replit App 创建新的 Git 仓库
* **Connect to a Git provider**：将仓库连接到受支持的托管或自托管 Git 提供方，以进行备份和协作
* **Configure remote**：配置和管理与远程仓库的连接

<Note>
  **自托管 Git 支持**：Replit 的 Enterprise 计划支持 GitHub Enterprise Server、GitLab Self-Managed 和 Bitbucket Data Center。[联系 Replit 销售团队](https://replit.com/enterprise)，获取有关集成、提供方配置和连接调试的指导。你还可以[使用 Shell 中的 Git 命令配置远程仓库](#usando-comandos-git-no-shell)。
</Note>

<div id="gerenciamento-de-alteraes">
  ### 变更管理
</div>

<Accordion title="如何查看变更">
  1. 修改 Replit App 中的任意文件
  2. 在 Tools 部分打开 Git 面板
  3. 在 **Review Changes** 部分查看变更
</Accordion>

Git 面板提供了用于管理代码变更的工具：

* **查看变更**：查看已修改的文件，高亮显示新增和删除的内容
* **暂存文件**：选择要纳入下一次提交的文件
* **提交变更**：使用描述性消息保存变更
* **推送更改**：一键将提交推送到远程仓库

<div id="gerenciamento-de-branches">
  ### 分支管理
</div>

<Accordion title="如何管理分支">
  1. 打开 Tools 中的 Git 面板
  2. 选择分支名称旁的分支下拉菜单
  3. 创建新分支或选择现有分支
</Accordion>

Git 面板可让你更轻松地管理代码的多个版本：

* **创建分支**：创建新分支，以便独立开发功能
* **切换分支**：在不同版本的代码之间切换
* **发布分支**：将分支发布到你的 Git 提供方
* **拉取更改**：同步协作者的远程更新

<div id="resoluo-de-conflitos-de-merge">
  ### 解决 merge 冲突
</div>

<Accordion title="如何解决 merge 冲突">
  1. 发生冲突时，尝试拉取更改
  2. Git 面板会突出显示发生冲突的文件
  3. 打开每个冲突文件，查看并解决冲突
  4. 解决冲突后保存文件
  5. 选择 **Pull** 完成 merge
</Accordion>

当来自不同来源的代码发生冲突时，Git 面板可帮助你：

* **识别冲突**：准确查看哪些文件存在冲突
* **查看差异**：查看冲突代码的两个版本
* **解决问题**：选择要保留的代码，或手动编辑冲突内容
* **完成 merge**：解决冲突后完成 merge 流程

<div id="usando-comandos-git-no-shell">
  ### 在 Shell 中使用 Git 命令
</div>

<Accordion title="如何打开 Shell">
  1. 在左侧工具停靠栏中选择 **All tools**
  2. 在可用工具中选择 **Shell**
</Accordion>

<Tip>
  虽然 Git 面板提供了直观的界面，但高级用户可以在 Shell 中使用标准 Git 命令执行更复杂的操作。无论通过哪种方式进行更改，都会同步显示在两处。
</Tip>

如果你更喜欢通过命令行使用 Git：

* **命令同步**：在 Shell 中执行的任何 Git 命令都会自动同步到 Git 面板
* **完整的 Git 功能**：可使用 Git 面板中未提供的高级 Git 功能
* **无缝切换**：可根据需要在 Shell 命令和 Git 面板之间切换

<Info>
  **支持 GitHub 和 GitLab CLI**：除标准 Git 命令外，你还可以在 Shell 中使用 [GitHub CLI](https://docs.github.com/en/github-cli) (`gh`) 和 [GitLab CLI](https://docs.gitlab.com/ee/editor_extensions/gitlab_cli/) (`glab`) 来管理和连接外部 Git 仓库。这些工具提供了处理 GitHub 和 GitLab 仓库的高级功能，包括拉取请求、议题以及其他平台专属功能。
</Info>

<div id="operaes-de-repositrio">
  #### 仓库操作
</div>

* **克隆仓库**：`git clone <url-to-repository>`
* **初始化仓库**：`git init`
* **添加远程仓库**：`git remote add origin <url-to-repository>`

<div id="fazendo-alteraes">
  #### 进行更改
</div>

* **查看状态**：`git status` (显示已修改、已添加和已删除的文件) 
* **暂存文件**：`git add <filename>` 或 `git add .` (暂存所有文件) 
* **提交变更**：`git commit -m "your commit message"`
* **推送更改**：`git push origin <branch-name>`
* **拉取更改**：`git pull origin <branch-name>`

<div id="autenticao">
  #### 身份验证
</div>

使用私有仓库时，您需要进行身份验证：

* 对于 GitHub.com 仓库，请使用个人访问 token，而不是密码
* 为避免反复输入凭证，您可以使用 Replit Secrets 存储凭证：
  1. 创建一个密钥为 `GIT_URL` 的 secret
  2. 将其值设为 `https://<username>:<token>@<git-host>/<owner>/<repository>`
  3. 使用 `git push $GIT_URL` 推送，无需输入凭证

<Note>
  使用凭证 secrets 时，任何有权访问您的 Replit App 的人都可能获取您的 Git 凭证。对于敏感仓库，请考虑每次手动输入凭证。
</Note>
