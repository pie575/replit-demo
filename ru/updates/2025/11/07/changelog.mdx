<div id="animated-agent-icon">
  ### Анимированная иконка Agent
</div>

Иконка Agent теперь анимируется во время работы, наглядно показывая, что Agent активно работает. Это улучшение создаёт ощущение более высокой скорости и упрощает отслеживание активности Agent на этапе первоначального планирования, особенно в раскладке с чатом по центру, где обратная связь находится ближе к вашему запросу.

<div id="agent-tools-dropdown-in-planning-flow">
  ### Выпадающее меню инструментов Agent в процессе планирования
</div>

Выпадающее меню инструментов Agent теперь доступно на этапах первоначального планирования и утверждения списка задач. Это позволяет с самого начала разработки настроить нужные параметры Agent, включая уровень автономности и другие предпочтения.

<div id="at-symbol-filename-support-in-agent">
  ### Поддержка упоминаний файлов через @ в Agent
</div>

Теперь Agent поддерживает упоминания файлов через `@` наряду с командами `/`, как в популярных инструментах разработки. Эта функция была особенно востребована корпоративными и опытными пользователями, знакомыми с рабочими процессами в стиле Cursor.

<div id="connectors-support-for-remixing">
  ### Поддержка Connectors при ремикшировании
</div>

Раньше при ремикшировании приложения Replit, использующего connector, интеграция переставала работать, поскольку ремикс не получал автоматического разрешения на использование connector. Мы обновили процесс ремикширования, чтобы он корректно работал с Connectors:

* Теперь при ремикшировании пользователям предлагается настроить необходимые connectors
* В процессе ремикширования чётко указано, какие интеграции нужно настроить
* После ремикширования интеграции больше не перестают работать

Подробнее об [интеграциях Agent](/ru/replitai/integrations) и [управлении вашими connectors](/ru/replitai/managing-connectors).

<div id="analytics-dashboard-for-enterprise-admins">
  ### Дашборд аналитики для администраторов Enterprise
</div>

Администраторы Enterprise теперь могут пользоваться комплексным дашбордом аналитики — одной из наиболее востребованных функций среди корпоративных клиентов, включая Meta и Atlassian. Дашборд позволяет:

* **Мониторинг активности пользователей**: отслеживать вовлечённость и совместную работу в организации
* **Отслеживание использования ресурсов**: контролировать расходы по пользователям и Replit App
* **Контроль deployment**: отслеживать активность deployment
* **Управление затратами**: получать данные о потреблении ресурсов и расходах
