Canvas 是 Replit Design 用于展示画框的可无限平移和缩放的画布。你设计的一切都在这里：创建画框、拖动移动、放大查看细节，不断迭代，直到获得理想结果。

<div id="canvas">
  ## 打开 Canvas
</div>

Canvas 是你在 Replit Design 中首先看到的界面。在项目中选择页眉中的 **Design**，Canvas 会占满面板；选择 **Build**，则会切换回正在运行的应用。

<Frame>
  <img src="/assets/mirror/canvas-design-button-ffa50447cefb.png" alt="放大的项目页眉，包含 Design 和 Build 切换按钮。已选择 Design，Canvas 中显示多个画框。" width="987" height="619" data-path="images/replitai/canvas-design-button.png" />
</Frame>

在 [replit.com/design](https://replit.com/design) 上新建设计时，系统会提示你创建新设计，并在 Canvas 中打开。有关何时使用各个界面，请参阅 [Design 与 Build](/zh/ko/design/design-vs-build)。

<div id="canvas-2">
  ## Canvas 上的内容
</div>

* **Frames**：画板上的所有图块。画框可以是设计模型、Web 应用、移动应用、幻灯片、图片、视频或矢量图形。可通过聊天提示词、工具栏中的 [Generate 菜单](/zh/ko/design/toolbar#generate)或[素材库面板](/zh/ko/design/library-panel)创建。对画框执行的所有操作——Build、Focus 和提出建议——都通过画框本身完成：请参阅 [Frames](/zh/ko/design/frames)。
* **绘图和便笺**：使用 [Draw 工具](/zh/ko/design/toolbar#draw)添加的标记，包括草图、箭头、形状和便利贴等。Agent 可以读取这些标记，因此你可以圈出有问题的部分并请求更改。
* **聊天面板**：固定在 Canvas 旁边的 Agent 聊天。发送消息前选择画框，它会以快照形式附加，让 Agent 获得视觉上下文。

有关各个组件的功能及其如何协同工作，请参阅[组件概述](/zh/ko/design/core-components)。

<div id="section">
  ## 浏览画板
</div>

除非另有说明，平移、缩放和选择在任何工具下均可使用。

**平移：**

* 触控板：双指拖动。
* 鼠标：按住中键拖动，或按住空格键并用左键拖动。
* [Pan 工具](/zh/ko/design/toolbar#pan)：用鼠标左键点击并拖动。

**缩放：**

* 触控板：捏合。
* 鼠标：`Ctrl` (macOS 上为 `Cmd`) + 滚轮。
* 键盘：放大使用 `Cmd`/`Ctrl` + `+`，缩小使用 `Cmd`/`Ctrl` + `-`，重置缩放使用 `Cmd`/`Ctrl` + `0`。

缩放以光标位置为中心，因此光标下方的内容保持不变，其余画板会围绕该位置缩放。

**选择：**

* 单个画框：使用 [Interact 工具](/zh/ko/design/toolbar#interact) 点击。
* 多选：按住 `Shift` 点击各个画框，或在画板上拖动选框。
* 取消选择：点击空白区域或按 `Escape`。

选择一个或多个画框后，将显示[每个画框的操作栏](/zh/ko/design/frames#per-frame-action-bar)，这些画框会以快照形式附加到下一条 Agent 消息中。

<div id="section-2">
  ### 键盘快捷键
</div>

| 快捷键                            | 操作             |
| ------------------------------ | -------------- |
| `V`                            | 启用 Interact 工具 |
| `H`                            | 启用 Pan 工具      |
| 按住 `Space` 并拖动                 | 使用任何工具时均可平移画布  |
| `Cmd` / `Ctrl` + 滚动            | 放大/缩小          |
| `Cmd` / `Ctrl` + `+`           | 放大             |
| `Cmd` / `Ctrl` + `-`           | 缩小             |
| `Cmd` / `Ctrl` + `0`           | 重置缩放           |
| `Shift` + 点击                   | 将画框添加到当前选择中    |
| `Cmd` / `Ctrl` + `Shift` + `C` | 将所选画框复制为 PNG   |
| `Escape`                       | 取消选择           |

<div id="section-3">
  ## 右键菜单
</div>

在画板任意位置右键单击即可打开上下文菜单。该菜单会根据当前情境显示不同选项，因此操作会因光标下方的对象而异：在画框上会显示画框操作，在空白 Canvas 上会显示画板级操作，而应用画框则会额外显示 **Refresh artifact**。

所选画框的菜单包含以下选项。

| 操作                             | 快捷键                           | 功能                                               |
| ------------------------------ | ----------------------------- | ------------------------------------------------ |
| Edit                           |                               | 切换到 Edit 工具，以选择画框内的元素。                      |
| Chat                           |                               | 与 Agent 就该画框进行聊天。                           |
| Focus                          |                               | 在画框中进入[聚焦模式](/zh/ko/design/frames#focus-mode)。 |
| Cursor chat                    | `/`                           | 在光标位置快速开始聊天。                                     |
| Reorder                        |                               | 在堆叠顺序中将画框前移或后移。                             |
| Copy, Paste, Duplicate, Delete | `⌘C`, `⌘V`, `⌘D`, `Backspace` | 标准剪贴板和画框管理功能。                               |
| Export as…                     |                               | 将画框导出为文件。                                   |
| Select all                     | `⌘A`                          | 选择画板上的所有画框。                                  |

<div id="png">
  ### 将画框导出为 PNG
</div>

将任何工件或设计画框保存为 PNG 图像。适合在文档或聊天中分享预览、在继续迭代前截取快照，或向团队成员发送截图。

<Steps>
  <Step title="选择画框">
    选择要导出的工件或设计画框，然后等待其加载完成。
  </Step>

  <Step title="选择 Export">
    在画框的操作栏中选择 **Export**。您也可以右键点击画框，然后选择 **Export as…** &gt; **PNG**。图像将以画框名称为基础的文件名下载到您的计算机。
  </Step>
</Steps>

若要将所选画框复制为 PNG 而非下载，请按 `Cmd+Shift+C` (Windows 和 Linux 上为 `Ctrl+Shift+C`) 。

<Note>导出的 PNG 将与 Canvas 中当前显示的画框一致。如果应用或设计仍在加载，请等待其完全渲染后再导出。</Note>

<div id="canvas-3">
  ## Canvas 与正在运行的应用
</div>

Canvas 与正在运行的应用预览共用同一面板，几种模式可在两者之间切换。

* **聚焦模式**：所选画框的 **Focus** 操作会将其展开至全屏。选择画板顶部的 **Exit focus** 可返回 Canvas。
* **只读模式**：当 Canvas 在后台工作上下文中被锁定时，与迭代相关的操作会被隐藏，仅保留 Focus。

<Note>
  使用 Design 画框构建新应用需要 Core 或 Pro。其他所有 Canvas 功能均适用于所有套餐。有关套餐的更多信息，请参阅 [Billing](/zh/ko/billing/ai-billing)。
</Note>
