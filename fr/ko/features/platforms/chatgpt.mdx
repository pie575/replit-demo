Grâce à l’intégration de Replit à ChatGPT, vous pouvez créer, modifier et inspecter des applications Replit directement dans une conversation. Aucune configuration supplémentaire n’est nécessaire. Créez de véritables applications en discutant avec ChatGPT, et Agent s’occupe du reste.

<div id="chatgpt-replit">
  ## Qu&#39;est-ce que Replit dans ChatGPT
</div>

Replit dans ChatGPT relie vos conversations ChatGPT à la puissante plateforme de développement de Replit. Décrivez ce que vous voulez créer et Agent génère pour vous une application Replit entièrement fonctionnelle. Une fois l&#39;application créée, vous pouvez demander à ChatGPT de la modifier, de la mettre à jour ou de l&#39;analyser. Le tout, par une simple conversation.

<div id="section">
  ## Prise en main
</div>

Suivez les étapes ci-dessous pour connecter Replit à ChatGPT et créer votre première application.

<div id="replit-chatgpt">
  ### Connecter Replit à ChatGPT
</div>

Vous pouvez connecter Replit à ChatGPT de deux façons :

<Accordion title="Depuis les paramètres">
  1. Dans ChatGPT, cliquez sur l’icône de votre profil
  2. Accédez à **Settings** → **Apps &amp; Connectors**
  3. Recherchez **Replit**, puis cliquez sur **Connect**
  4. Terminez l’authentification OAuth avec votre compte Replit
</Accordion>

<Accordion title="Depuis une conversation">
  1. Démarrez une nouvelle conversation dans ChatGPT
  2. Appelez Replit en utilisant l’une des méthodes ci-dessous
  3. Si vous n’êtes pas encore connecté, ChatGPT vous guidera tout au long du processus OAuth
</Accordion>

<div id="chatgpt-replit-2">
  ### Utiliser Replit dans ChatGPT
</div>

Une fois connecté, vous pouvez utiliser Replit de trois manières :

| Méthode                  | Comment l’utiliser                                      |
| ------------------------ | ------------------------------------------------------- |
| Mention directe          | Saisissez `Replit, <votre demande>` au début du message |
| Commande à barre oblique | Saisissez `/Replit` dans le champ de saisie             |
| Menu Composer            | Cliquez sur le bouton **+** → **More** → **Replit**     |

<div id="section-2">
  ### Créer votre première application
</div>

Une fois connecté, créez votre première application Replit :

1. Démarrez une nouvelle conversation dans ChatGPT
2. Appelez Replit et décrivez ce que vous souhaitez créer (par exemple : « Replit, crée une application de liste de tâches avec un mode sombre »)
3. Agent crée l&#39;application et la déploie automatiquement
4. Une fois terminé, vous recevrez un lien pour accéder à votre application

<Note>
  Vous pouvez travailler sur une seule application Replit par conversation. Si vous créez une nouvelle application dans la même conversation, l&#39;application existante sera modifiée. Pour créer plusieurs applications, démarrez des conversations distinctes.
</Note>

<div id="section-3">
  ## Fonctionnalités
</div>

* **[Replit AI](/fr/ko/build/welcome)** : Agent crée et déploie des applications à partir de requêtes en langage naturel
* **[Project Editor](/fr/ko/learn/projects-and-artifacts/project-editor)** : environnement de développement complet accessible depuis ChatGPT
* **[Publishing](/fr/ko/learn/projects-and-artifacts/replit-deployments)** : les applications sont automatiquement déployées et prêtes à être partagées

<Accordion title="Ce que vous pouvez faire">
  **Créer :** décrivez ce que vous souhaitez pour créer de nouvelles apps Replit. Agent crée et déploie automatiquement l&#39;application.

  **Mettre à jour :** modifiez l&#39;application de la conversation en cours. Demandez à ChatGPT d&#39;ajouter des fonctionnalités, de corriger des bugs ou d&#39;appliquer des modifications, et Agent s&#39;en chargera.

  **Inspecter :** analysez l&#39;application sans y apporter de modifications. Obtenez des informations sur la structure du code, les chemins de fichiers et le comportement.
</Accordion>

<Accordion title="Formats de fichiers pris en charge">
  Vous pouvez inclure différents formats de fichiers dans votre prompt :

  | Format                        | Pris en charge                          |
  | ----------------------------- | --------------------------------------- |
  | PDF                           | Oui                                     |
  | CSV                           | Oui                                     |
  | Formats de documents courants | Oui                                     |
  | Images (fichiers bruts)       | Non (utilisez plutôt des URL publiques) |
  | Vidéos (fichiers bruts)       | Non (utilisez plutôt des URL publiques) |

  <Note>
    Pour inclure des images ou des vidéos dans votre application, fournissez des URL publiques dans votre prompt. Une fois l&#39;application créée, vous pouvez également ajouter directement des fichiers multimédias dans Replit.
  </Note>
</Accordion>

<Accordion title="Temps de build">
  Temps de build habituel des applications avec Agent :

  | Complexité de l&#39;application                             | Temps de build habituel |
  | ----------------------------------------------------------- | -------------------------- |
  | Simple (calculatrices, petites pages d&#39;accueil)         | 2–3 minutes                |
  | Complexe (jeux, animations riches, tableaux de bord denses) | 3–4 minutes                |
</Accordion>

  | Plan           | Pris en charge | Remarques                                                                         |
  | -------------- | -------------- | --------------------------------------------------------------------------------- |
  | Free           | Oui            |                                                                                   |

  | Enterprise     | Oui            | Accès à toutes les fonctionnalités                                                 |
</Accordion>

<div id="section-5">
  ## Facturation et crédits
</div>

Les actions effectuées par Replit dans ChatGPT sont facturées en tant qu’utilisation de Replit Agent sur votre compte Replit.

<Accordion title="Fonctionnement de la facturation">
  * Les forfaits **Core** et **Pro** incluent des crédits mensuels permettant d’utiliser Agent, Publishing et les bases de données dans les limites autorisées
  * Vous pouvez acheter des **packs de crédits** qui expirent au bout de 6 mois et ne se renouvellent pas automatiquement. Ils sont adaptés aux pics de trafic ou aux expérimentations lors d’un lancement
  * Limitez vos dépenses à l’aide des **limites d’utilisation** et des **budgets** dans les paramètres de facturation de Replit

  Pour en savoir plus, consultez la [documentation sur la facturation de l’IA](/fr/ko/billing/ai-billing).
</Accordion>

<div id="section-6">
  ## Limites actuelles
</div>

L’application Replit pour ChatGPT :

* ne peut fonctionner que sur les applications créées dans cette conversation
* ne peut pas ouvrir ni modifier :
  * les applications créées dans d’autres fils de discussion ChatGPT
  * les applications créées directement dans Replit

La parité fonctionnelle avec l’expérience Replit complète, notamment en matière de bases de données, de gestion des secrets et de contrôles plus avancés dans Project Editor, sera disponible ultérieurement.

<div id="section-7">
  ## Résolution des problèmes
</div>

<Accordion title="Replit n’apparaît pas dans Browse apps">
  Si Replit n’apparaît pas dans **Browse apps**, vérifiez les points suivants :

  * La disponibilité de l’application dans votre région
  * Que l’administrateur de l’espace de travail a activé l’application Replit (Business/Enterprise/Edu)
</Accordion>

<Accordion title="Échec du build">
  En cas d’échec du build, ouvrez l’application dans Replit :

  * Vérifiez votre utilisation et vos informations de facturation
  * Utilisez les points de contrôle et les restaurations pour revenir en arrière
  * Demandez directement de l’aide à Agent dans le Project Editor
</Accordion>
