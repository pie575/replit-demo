---
title: "Autoscale Deployments"
description: "Узнайте, как Autoscale Deployments автоматически подстраивают мощность под трафик вашего приложения."
---

Autoscale Deployments работают на облачных вычислительных ресурсах, которые масштабируются вверх и вниз, чтобы эффективно справляться с сетевым трафиком и рабочей нагрузкой вашего Replit App. Когда приложение загружено, автомасштабирование добавляет серверы, чтобы справиться с нагрузкой. Когда приложение простаивает, число серверов сокращается до нуля — это позволяет экономить.

Autoscale Deployments идеально подходят для следующих сценариев:

* Веб-приложения с переменной нагрузкой и трафиком, например сайты электронной коммерции
* API и сервисы

<div id="recursos">
  ## Возможности
</div>

Autoscale Deployments включают следующие возможности:

* **Автоматическое масштабирование ресурсов**: ресурсы подстраиваются автоматически в зависимости от характера трафика, что позволяет оптимизировать расходы.
* **Пользовательские домены**: настройте пользовательский домен или используйте URL вида `<имя-приложения>.replit.app` для доступа к своему приложению.
* **Настраиваемые лимиты**: задайте максимальное количество экземпляров, до которого может масштабироваться ваше опубликованное приложение.
* **Гибкая мощность машины**: выберите конфигурацию CPU и RAM, отвечающую потребностям вашего приложения.
* **Мониторинг**: просматривайте логи и отслеживайте состояние опубликованного приложения.

<div id="uso">
  ## Использование
</div>

Доступ к Autoscale Deployment можно получить через инструмент Publishing в Project Editor.

<Accordion title="Как открыть Autoscale Deployment">
  В **Tool dock** слева:

  1. Выберите <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Иконка All tools" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**, чтобы открыть список инструментов Project Editor.
  2. Выберите <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Иконка Publishing" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publishing**.
  3. Выберите вариант **Autoscale**, а затем — **Set up your published app**.

  В **строке поиска**:

  1. Нажмите на <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="иконка лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> лупу вверху, чтобы открыть инструмент поиска

  3. Выберите вариант **Autoscale**, а затем — **Set up your published app**.
</Accordion>

<div id="capacidade-da-mquina">
  ## Мощность машины
</div>

Нажмите **Edit**, чтобы просмотреть и задать параметры мощности машины. С помощью ползунков выберите конфигурацию CPU и RAM для каждого экземпляра сервера опубликованного приложения.

Стоимость выбранной конфигурации в **compute units** показана в строке **Total per machine**.
Compute unit — это единица измерения облачных вычислительных ресурсов, зависящая от конфигурации памяти и CPU машины.

Подробнее о расчёте стоимости на основе Compute Units см. в разделе [Compute Units](/ru/pt/billing/about-usage-based-billing#2-compute-units).

<div id="nmero-mximo-de-mquinas">
  ## Максимальное количество машин
</div>

С помощью ползунка задайте максимальное количество машин. Это число — верхний предел экземпляров серверов, которые функция autoscaling может выделить, если определит, что ваше приложение испытывает высокую нагрузку.

В нижней строке указано эквивалентное количество compute units, рассчитанное по следующей формуле:

`Количество машин * compute units на машину`
