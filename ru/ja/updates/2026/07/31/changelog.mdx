<div id="agent">
  ## Agent
</div>

<div id="agent-2">
  ### Выбор основной модели для Agent
</div>

Теперь вы можете выбрать основную модель, которую Agent будет использовать в задачах. Выберите режим Lite, Economy или Power, а затем — одну из доступных в нём моделей. Режим Lite теперь доступен везде, где работает Agent, включая мобильное приложение. Набор доступных моделей зависит от организации, прав доступа и наличия доступа к Turbo.

<div id="mcp">
  ### Подключение к ещё большему числу MCP-серверов
</div>

Поддерживаемые рабочие пространства теперь могут подключаться к Supabase, Statsig и Calendly из каталога готовых MCP-серверов. Replit также распознаёт официальную конечную точку Braintrust MCP: при добавлении вручную запускается вход через OAuth.
