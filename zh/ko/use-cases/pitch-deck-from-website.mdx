根据您的网站、Google Drive 中的品牌文件和 Google Sheets 中的财务数据，
在 Replit Slides 中生成一份投资者路演演示文稿 (10～12 页) ：问题、产品、
市场、发展势头、团队和融资需求。Agent 会从网站提取叙事和依据，
从 Drive 获取品牌形象，并从 Sheet 获取数字 (营收、现金消耗率、资金续航期、单位经济效益、
预测) 。

  ## 适用于以下情况
</div>

* 需要根据真实网站和财务 Sheet 制作投资者路演材料的创始人。
* 已在 Google Sheets 中管理各项指标，并正在进行融资的运营者。

  ## 开始前
</div>

准备好实际网站、Drive 中的品牌文件，以及包含带标签的行或标签页 (营收、现金消耗率、
资金续航期、预测) 的 Sheet。连接 Drive 和 Sheets。向 Agent 说明融资轮次
(pre-seed、seed、Series A) 和你的需求。

  路演演示文稿。请涵盖问题、解决方案、产品、市场、发展势头、商业模式、

</AiPrompt>

<div id="section-4">
  ## 预期结果
</div>

Agent 会将网站转化为幻灯片方案，并将 Sheet 中的
数据填入发展势头和财务幻灯片，在 Replit Slides 中创建演示文稿。发送给投资者之前，请将所有
数值与 Sheet 逐一核对。请在 Preview 中点击查看演示文稿，将财务
幻灯片与 Sheet 标签页进行对照，并确认每项主张都能在网站或 Sheet 中找到
依据。

  请在幻灯片中注明来源标签页。

<div id="section-6">
  ## 故障排查
</div>

* **数值与 Sheet 不一致：**带标签的行或工作表标签页至关重要。请为营收、资金消耗率、现金续航期和预测指定标签页名称，并告知 Agent 只能使用其中的数字。请标记需要注明来源的内容。
* **品牌风格不协调：**连接 Drive，并指明徽标和颜色。如果有参考演示文稿，请让 Agent 在不更改已批准数值的前提下，匹配布局和字体。
