<div id="security-scan-while-you-build">
  ### Сканирование безопасности во время разработки
</div>

В рамках проверки кода Agent теперь проверяет изменённые им файлы на распространённые проблемы безопасности. Это автоматическое сканирование Semgrep выявляет рискованные шаблоны и жёстко заданные секреты, чтобы Agent мог устранить вероятные обнаруженные проблемы до завершения задачи.

Подробнее: [Сканирование безопасности во время разработки](/ru/features/security/project-security-center#security-scan-while-you-build).

<div id="regenerate-production-database-credentials">
  ### Повторная генерация учётных данных продакшен-базы данных
</div>

Теперь вы можете повторно сгенерировать учётные данные для соответствующей требованиям продакшен-базы данных в инструменте **Database**. Replit обновит учётные данные и, если у вашего приложения есть активный поддерживаемый deployment, запустит повторное развёртывание, чтобы оно продолжило использовать новые учётные данные. Обновите все внешние инструменты, использующие старую строку подключения.

<div id="build-with-sso">
  ### Build с SSO
</div>

Разработчики Pro теперь могут настроить корпоративный SSO для Replit App с [Clerk Auth](/ru/features/auth-and-identity/clerk-auth). Попросите Agent внести необходимые изменения в аутентификацию — он направит вас в Clerk Dashboard. Там вы сможете подключить Okta или Microsoft Entra ID через OIDC или SAML. Корпоративные SSO-подключения бесплатны до 1 октября 2026 года. После этого применяется сквозное ценообразование Clerk. Поддержка Enterprise появится в ближайшее время.

<div id="move-projects-between-workspaces">
  ### Перенос проектов между рабочими пространствами
</div>

Теперь проект можно перенести между командными рабочими пространствами в рамках одного платёжного аккаунта из списка **Projects**. Перенос выполняется в фоновом режиме, и его нельзя отменить. Связанные Secrets аккаунта не переносятся вместе с проектом, поэтому повторно свяжите их в целевом рабочем пространстве.
