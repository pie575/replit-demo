---
title: "Historique des fichiers"
description: "Découvrez comment restaurer des versions antérieures de votre code à l’aide des sauvegardes automatiques de l’Historique des fichiers."
---

Commencez par ouvrir un fichier texte dans le Project Editor, puis cliquez sur le bouton **History** situé dans le coin inférieur droit.

<Frame>
  <img src="/assets/mirror/history-button-afac6496660a.png" alt="ouverture de l’historique" width="377" height="292" data-path="images/programming-ide/history-button.png" />
</Frame>

<div id="visualizar-verses-anteriores-de-um-arquivo">
  ## Afficher les versions antérieures d’un fichier
</div>

Après avoir ouvert l’Historique des fichiers, vous pouvez afficher les versions antérieures d’un fichier à l’aide de la barre de défilement, des boutons fléchés ou des touches fléchées **gauche** et **droite**.

<Frame>
  <img src="/assets/mirror/history-versioning-1a055ecab411.gif" alt="démonstration de la barre de défilement" width="764" height="720" data-path="images/animations/history-versioning.gif" />
</Frame>

<div id="comparar-verses-anteriores-com-o-arquivo-atual">
  ## Comparer les versions antérieures au fichier actuel
</div>

Cliquez sur le bouton Compare Latest dans le coin inférieur gauche du panneau Historique des fichiers pour afficher une comparaison en ligne entre votre fichier à ce moment-là et sa version la plus récente.

<Frame>
  <img src="/assets/mirror/compare-history-46fb16debd3a.gif" alt="image de comparaison avec la version la plus récente" width="772" height="720" data-path="images/animations/compare-history.gif" />
</Frame>

<div id="restaurar-uma-verso-anterior-de-um-arquivo">
  ## Restaurer une version antérieure d’un fichier
</div>

Pour restaurer un fichier vers une version antérieure, il vous suffit de cliquer sur le bouton `Restore`. Ne vous inquiétez pas : aucun historique ne sera supprimé. Lorsque vous restaurez une version antérieure, elle est ajoutée à l’historique du fichier en tant que nouvelle version.

<Frame>
  <img src="/assets/mirror/restore-history-5f616d7f961a.webp" alt="image de restauration de l’historique" width="720" height="495" data-path="images/animations/restore-history.webp" />
</Frame>

<div id="visualizar-a-reproduo-do-histrico-de-arquivo">
  ## Visualiser la relecture de l’historique des fichiers
</div>

Vous pouvez utiliser la fonctionnalité de relecture de l’historique des fichiers pour voir votre fichier évoluer au fil du temps, comme dans un film. Cela peut être utile pour créer des vidéos de vos sessions de programmation.
