<div id="agent">
  ### Agent 使用成本可见性
</div>

您可以在任务执行期间实时查看 Agent 的使用成本。打开聊天标题栏抽屉，即可监控正在执行的任务支出。这对于长时间、高自主性的执行尤其有用。

<div id="escape">
  ### 可视化选择/编辑模式中的 Escape 键
</div>

按 Escape 键可退出 Visual Select 模式或返回 Build 模式，方便你快速继续工作。

<div id="agent-2">
  ### 加快 Agent 停止速度
</div>

现在可从工作区更快地停止或启动 Agent，缩短等待时间。

<div id="github">
  ### 改进 GitHub 导入
</div>

GitHub 导入过程中现会显示实时进度，而非笼统提示，导入速度也有所提升。

<div id="section-2">
  ### 依赖项漏洞扫描
</div>

安全扫描器现可检测 Go、JavaScript、Python 和 Rust 依赖项中的漏洞，未来还将支持更多语言。

<div id="webview">
  ### Webview 日志体验
</div>

现在，你可以在同一位置查看 Webview 日志和控制台输出，包括 Agent 使用的日志，让调试更加简单。

<div id="section-3">
  ### 团队支持席位访问
</div>

您可以将 Replit Support 添加为不计费的访客账户。需要支持时，您可授予其对特定 App 的有限访问权限，同时仍可自行掌控工作区的隐私。
