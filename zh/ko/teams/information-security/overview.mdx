<div id="section">
  ## 数据保护
</div>

保护数据是 Replit 的首要任务。我们采取全面的安全措施来保护您的数据，并维护平台的完整性。

<div id="section-2">
  ### 托管与基础设施
</div>

Replit 主要将数据托管在位于美国的 Google Cloud Platform (GCP) 数据中心，并为有需要的用户提供印度这一可选托管区域。我们借助 GCP 的企业级备份与恢复工具，确保：

<CardGroup cols={2}>
  <Card title="高可用性" icon="server">
    通过冗余系统和自动故障转移机制，避免服务中断和数据丢失
  </Card>

  <Card title="数据隔离" icon="layer-group">
    通过严格的逻辑隔离，防止不同用户和组织之间的未授权访问
  </Card>
</CardGroup>

GCP 是业界领先的云服务提供商，已通过 **ISO 27001** 和 **SOC 2 Type 2** 认证。此外，**Replit 也已获得 SOC 2 Type 2 合规认证**，体现了我们对安全最佳实践和控制措施的持续投入。

所有客户端请求在访问个人信息之前，都必须经过严格的**身份验证和授权**。

<div id="section-3">
  ### 加密标准
</div>

<Note>
  Replit 在数据的所有状态下均采用全面加密，确保信息的机密性、完整性和安全性。
</Note>

<AccordionGroup>
  <Accordion title="传输中加密" icon="shield-halved">
    采用行业标准的 **TLS 1.2+** 加密，保护客户端与服务器之间的所有通信，确保经由网络传输的数据安全。其中包括所有 API 调用、Web 流量、实时协作数据及其他通信。
  </Accordion>

  <Accordion title="静态数据" icon="database">
    存储在 GCP 中的数据受 [**AES-256 服务器端加密**](https://cloud.google.com/docs/security/encryption/default-encryption) 保护。这一军用级加密标准可保护包括代码、配置、用户信息和系统元数据在内的所有静态数据。
  </Accordion>

  <Accordion title="数据库安全" icon="lock">
    我们使用 **Google Cloud SQL** 实现[数据库加密](https://cloud.google.com/sql/references/additional-resources/faq#encryption-manage-rest)和[安全密钥管理](https://cloud.google.com/secret-manager)，并通过自动加密、定期密钥轮换和细粒度访问控制保护敏感数据。
  </Accordion>
</AccordionGroup>
