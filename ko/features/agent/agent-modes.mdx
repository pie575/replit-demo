export const FreeModePlanAvailability = `Free Mode는 Starter, Core, Pro plan에서 사용할 수 있습니다. Free Mode 한도는 plan에 따라 달라지며, Core 및 Pro에는 ${FreeModeAllowanceRefreshPeriod}마다 갱신되는 allowance가 포함됩니다.`;

Agent modes를 사용하면 Agent 사용 시 비용과 성능 간의 균형을 직접 조절할 수 있습니다. Agent settings dropdown에서 **Free Mode**, **Power Mode**, **Max Mode** 중 하나를 선택하세요. Free Mode는 항상 intelligent model routing을 사용합니다. Power 또는 Max에서는 Core 및 Pro builders가 **Auto**를 선택해 Replit이 각 task에 맞는 model을 고르도록 할 수 있습니다. [Model selector](/ko/features/agent/model-selector)로 model을 직접 선택할 수도 있습니다. 표시되는 모드와 설정은 사용 중인 plan과 workspace에 따라 다릅니다.

<Note>
  Economy Mode는 더 이상 제공되지 않습니다. 동일한 가격의 Power Mode가 이를 대체합니다.
</Note>

<Tip>
  **키보드 단축키:** **⌘+Shift+I**(Windows에서는 Ctrl+Shift+I)를 누르면 채팅 입력창을 벗어나지 않고 Agent modes를
  차례로 전환할 수 있습니다.
</Tip>

<div id="free-mode">
  ## Free Mode
</div>

**시작하기에 최적화된 모드입니다.** Free Mode에서는 아이디어를 탐색하고, Replit의 작동 방식을 익히고, project를 시작할 수 있습니다.

**참고하세요:** Free Mode는 항상 intelligent model routing을 사용합니다. model을 직접 선택하려면 Power Mode 또는 Max Mode를 사용하세요.

<Note>
  {FreeModePlanAvailability} plan의 limit에 도달하면 Replit이 초기화 시점을 알려줍니다.
</Note>

Routines는 Free Mode에서 실행되지 않습니다. Power 또는 Max Mode에서만 실행되며 run당 예산이 필요합니다. [Routines](/ko/chat/routines)에서 자세히 알아보세요.

<div id="intelligent-model-routing-auto">
  ## Intelligent model routing (Auto)
</div>

**자동 모델 선택에 최적화된 방식입니다.** Power Mode 또는 Max Mode에서 Core 및 Pro builders는 **Auto**를 선택할 수 있습니다. 그러면 Replit이 각 task마다 선택한 모드의 성능 한도 내에서 model을 선택합니다. [intelligent model routing 사용하기](/ko/chat/auto-mode)를 참조하세요.

Auto는 Free Mode를 대신하는 유료 옵션으로, 다른 Power 및 Max 작업과 마찬가지로 구독 credits를 사용합니다.

Enterprise workspaces에서는 Free Mode 대신 하나의 **Auto 모드**를 사용합니다. Enterprise Auto는 각 task마다 모드와 허용된 model을 모두 선택할 수 있습니다.

<div id="power-mode">
  ## Power Mode
</div>

**비용에 최적화된 모드입니다.** Power Mode는 task당 credits 소모가 적어, 가장 성능이 뛰어난 model에 비용을 들이지 않고도 충분히 좋은 결과를 얻고 싶을 때 기본값으로 쓰기 좋습니다.

**적합한 경우:** 일상적인 빌드, 학습, 기존 project에서 비용을 아껴야 하는 작업.

<div id="max-mode">
  ## Max Mode
</div>

**성능에 최적화된 모드입니다.** Max Mode는 복잡한 task, 대규모 codebase, 난이도 높은 문제를 처리하기 위해 더 뛰어난 model을 사용합니다.

**이럴 때 적합합니다:** production-grade project, 복잡한 기능을 개발할 때, 그리고 Agent에서 최상의 결과를 얻고 싶을 때.

<div id="which-mode-should-i-use">
  ## 어떤 모드를 사용해야 하나요?
</div>

다음 표를 참고하세요:

| 목표                                      | 권장 모드                                                              |
| --------------------------------------- | ------------------------------------------------------------------ |
| 아이디어를 탐색하고 Replit 사용법을 익히며 project 시작하기 | Free Mode                                                          |
| 유료 작업에 사용할 모델을 Replit이 알아서 선택하도록 하기     | Power Mode 또는 Max Mode의 Auto                                       |
| 크레딧당 prompt 수를 최대한 늘리기                  | Power Mode                                                         |
| 대부분의 project에서 비용과 품질의 균형 맞추기           | Power Mode                                                         |
| 모델을 직접 선택하기                             | Power Mode 또는 Max Mode                                             |
| 복잡한 production-grade 작업에서 최상의 결과 얻기     | Max Mode                                                           |
| 가장 복잡한 task에서 최고의 결과 얻기                 | 더 높은 [Effort](/ko/features/agent/model-selector#effort)를 적용한 Max Mode |

채팅 입력창의 Agent settings dropdown에서 모드를 선택하세요. Power 또는 Max에서는 Core 및 Pro builder가 Auto를 사용하거나 [primary model과 Effort](/ko/features/agent/model-selector)를 직접 설정할 수 있습니다. 언제나 최선인 모드는 없으므로, 지금 하려는 task에 맞는 모드를 선택하세요.

<div id="settings-in-shared-projects">
  ## 공유 project의 설정
</div>

Agent settings는 project가 아니라 사용자 개인에게 연결됩니다. project에 팀원을 초대하더라도 다음 항목은 각자의 선택이 그대로 유지됩니다.

* 모드(Free Mode, Power Mode 또는 Max Mode)
* [Primary model 및 Effort](/ko/features/agent/model-selector) (사용 가능한 경우)
* [Plan Mode](/ko/features/agent/plan-mode)
* 백그라운드 task 자동 merge
* 계획 자동 승인

팀원이 다음 task에서 Max Mode로 전환해도 사용자의 설정까지 Max Mode로 바뀌지는 않습니다. project에 공동 작업자가 몇 명이든, 다음 메시지를 보낼 때 Agent가 사용하는 것은 사용자의 Agent settings dropdown에 표시된 모드와 설정입니다.

<div id="check-your-free-mode-usage">
  ## Free Mode 사용량 확인
