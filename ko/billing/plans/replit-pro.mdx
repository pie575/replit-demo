[Replit Pro](https://replit.com/pricing)는 Core만으로는 부족해진 본격적인 builder를 위해 만들어졌습니다. production 앱을 출시하든, 점점 커지는 팀과 협업하든, Agent를 한계까지 활용하든 모두 문제없습니다. 현재 Pro 요금은 [요금제 페이지](https://replit.com/pricing)에서 확인하세요.

<div id="key-features">
  ## 주요 기능
</div>

<div id="most-powerful-agent-experience">
  ### 가장 강력한 Agent 경험
</div>

* **Turbo mode**: Advanced 설정에 있는 **별도 토글**입니다. **Power** 모드에서 켜면 가장 빠른 모델로 Agent가 **2.5배 빠르게** 작동합니다. 요청 비용이 약 2배 늘어나므로 숙련된 builder에게 권장합니다.
* **병렬 task 실행**: 최대 10개의 task를 동시에 실행해 더 빠르게 반복 작업할 수 있습니다.
* **Agent 모드**: task에 맞게 Lite, Economy, Power 중에서 선택하세요. 모드 선택 방법은 [Agent 모드](/ko/features/agent/agent-modes)를 참고하세요.

<div id="tiered-credits-and-rollover">
  ### 등급별 크레딧 및 이월
</div>

* **등급별 월 크레딧**: 여러 등급이 제공되며 상위 등급일수록 할인 폭이 커집니다. 미리 구매할수록 더 많이 절약할 수 있고, 성장에 맞춰 크레딧를 추가할 수 있습니다. 현재 등급은 [요금제 페이지](https://replit.com/pricing)에서 확인하세요.
* **크레딧 이월**: 사용하지 않은 크레딧는 {ProCreditRolloverPeriod} 동안 이월되므로 구독을 더욱 알차게 활용할 수 있습니다.

<div id="scale-your-team">
  ### 팀 확장
</div>

* **최대 15명의 builder**: pooled 크레딧와 예산 관리 기능을 활용해 최대 15명의 builder를 초대할 수 있습니다. 사용자별 추가 요금 없이 모든 구성원이 동일한 plan을 함께 사용합니다.
* **협업 Workspace**: 관리자 Account의 pooled 크레딧로 협업 Workspace를 만들고, Workspace별로 App을 정리하고 usage를 추적하세요.

<div id="priority-support-and-reliability">
  ### 우선 지원 및 안정성
</div>

* **우선 지원**: 영업일 기준으로 support engineer에게 우선적으로 직접 문의할 수 있습니다. AI-powered support에 더해 제공되는 Pro 및 Enterprise 전용 혜택입니다.
* **4배 늘어난 데이터베이스 복구 기간**: 기본 7일이 아닌 최근 28일 이내의 원하는 시점으로 데이터베이스를 복원할 수 있습니다. 단, retention 기간이 길수록 저장 공간을 더 많이 사용하므로 복구 기간을 늘리면 usage 비용도 함께 증가한다는 점에 유의하세요.

<div id="community-and-more">
  ### 커뮤니티 및 그 외
</div>

* **전용 커뮤니티**: 진지하게 임하는 다른 builder들에게서 배우고, 작업 중인 프로젝트를 공유하며, Replit 팀과 직접 소통할 수 있습니다.
* **더 많은 기능 출시 예정**: 올해 Pro에서만 제공되는 추가 기능이 출시될 예정입니다.

<div id="whats-exclusive-to-pro">
  ## Pro 전용 기능
</div>

| 기능              | 세부 내용                                        |
| --------------- | -------------------------------------------- |
| Turbo mode      | 가장 강력한 모델로 2.5배 빠른 Agent                     |
| 병렬 task 실행      | 최대 10개의 task 동시 실행                           |
| 최대 15명의 builder | Core는 5명                                     |
| 크레딧 이월          | 사용하지 않은 크레딧을 {ProCreditRolloverPeriod} 동안 이월 |
| 우선 지원           | support engineer에게 우선적으로 직접 문의 가능            |
| 4배 데이터 보존       | 삭제된 데이터베이스를 최대 28일까지 복구                      |

Core에 포함된 모든 기능은 Pro에도 포함됩니다. 전체 비교는 [요금제 페이지](https://replit.com/pricing)에서 확인하세요.

<div id="getting-started">
  ## 시작하기
</div>

1. [요금제 페이지](https://replit.com/pricing)로 이동합니다.
2. **Replit Pro**를 선택하고 크레딧 등급을 지정합니다.
3. 결제를 완료하면 팀과 함께 앱 개발을 시작할 수 있습니다.
