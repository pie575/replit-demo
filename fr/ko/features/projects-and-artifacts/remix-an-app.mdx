<div id="section">
  ## Qu’est-ce qu’un remix ?
</div>

Un **remix** est une nouvelle application Replit créée à partir d’une application à laquelle vous avez accès. Lorsque vous remixez une application publique ou un modèle, vous obtenez votre propre copie, que vous pouvez modifier et améliorer de manière itérative. Les modifications apportées à un remix n’affectent pas l’application d’origine.

Les remix indiquent leur source. Un lien **Remixed from** renvoie vers l’original, et le prompt de création d’origine apparaît sur la page de couverture.

<div id="section-2">
  ## Ce qu’inclut un remix
</div>

Un remix est une copie complète et fonctionnelle, clairement distincte de l’original :

* **Tous les fichiers et toutes les configurations** sont copiés tels quels, afin que l’App fonctionne exactement comme l’originale.
* **L’historique des points de contrôle de l’original** est également copié et s’affiche comme l’historique de l’App d’origine. Vous pouvez revenir à ces points de contrôle, mais la conversation qui les a créés reste dans l’original.
* **Un Agent entièrement nouveau.** Un remix démarre avec un nouvel Agent qui n’hérite pas de l’historique des discussions précédentes.
* **Les noms des secrets, mais pas leurs valeurs.** Si l’App utilise des secrets (par exemple, des clés API), le remix répertorie uniquement leurs noms afin que vous sachiez quelles valeurs renseigner, et les valeurs restent vides. Les valeurs sont copiées uniquement lorsque vous remixez une App qui vous appartient.
* **Une nouvelle base de données.** Un remix n’est pas connecté à la base de données de l’original. Si l’original le permet, vous pouvez copier les données avec l’option **Copy data from original App**, mais même dans ce cas, les modifications n’affecteront pas l’original.
* Pour les Apps utilisant Replit Auth, **de nouveaux paramètres de connexion**.

Les déploiements, les domaines et les configurations de connecteurs ne sont pas copiés : vous devez les configurer directement dans votre propre copie. Les remixes sont également privés au départ ; rien n’est donc partagé tant que vous ne les publiez pas.

<div id="section-3">
  ## Comment remixer une application
</div>

<Steps>
  <Step title="Ouvrir la page de couverture de l’application">
    Trouvez l’application que vous souhaitez remixer. Vous pouvez également choisir une application dans la [communauté](https://replit.com/community/all). La page de couverture affiche un aperçu en direct et des options de partage.
  </Step>

  <Step title="Remixer l’application">
    Sélectionnez **Remix this App** pour créer votre propre version.
  </Step>

  <Step title="Renseigner les informations de l’application">
    Dans la boîte de dialogue **Remix App**, saisissez le nom de votre copie et, si vous le souhaitez, une description, puis sélectionnez **Remix App**. Vous pourrez modifier ces informations ultérieurement.

      <img src="/assets/mirror/quickstart_remix_dialog-39c49a3d7bb7.png" alt="Boîte de dialogue Remix App affichant le nom de l’application, la description et les paramètres de confidentialité" width="1222" height="1202" data-path="images/getting-started/quickstart_remix_dialog.png" />

  </Step>

  <Step title="Explorer votre copie">
    Votre copie s’ouvre dans votre espace de travail et démarre automatiquement. Accédez à l’onglet **Preview** pour la voir s’exécuter.
  </Step>
</Steps>

<div id="section-5">
  ## Développer à partir de Remix
</div>

Lorsque Remix s’ouvre dans votre espace de travail, utilisez Agent pour le modifier et l’enrichir. Dans l’onglet **Agent**, saisissez un prompt décrivant les fonctionnalités que vous souhaitez ajouter.

Pour annuler les modifications apportées par Agent, sélectionnez **Rollback to here** dans le checkpoint créé après ces modifications. Pour en savoir plus, consultez [Checkpoints et restaurations](/fr/ko/features/version-control/checkpoints-and-rollbacks).

<div id="section-6">
  ## Remixer ou créer avec un prompt ?
</div>

Les deux approches mènent au même résultat : votre propre application, que vous ferez évoluer avec l’aide d’Agent. Seule la manière de commencer diffère :

|                         | Remixer                                            | Créer avec un prompt                                       |
| ----------------------- | -------------------------------------------------- | ---------------------------------------------------------- |
| Point de départ         | Une application fonctionnelle, copiée telle quelle | Une application créée par Agent à partir d’une description |
| Premier résultat        | Immédiat et identique à l’original                 | Prend plus de temps et le résultat diffère                 |
| Première action d’Agent | Attend vos instructions                            | Planifie et crée à partir du prompt                        |

S’il existe déjà une application semblable à celle que vous souhaitez, remixez-la. La première tâche d’Agent portera ainsi sur une application qui fonctionne réellement, plutôt que sur une page vierge. Si votre idée n’existe nulle part ailleurs, créez-la avec un prompt.
