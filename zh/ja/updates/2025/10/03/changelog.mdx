<div id="vercel">
  ### Vercel 导入集成
</div>

只需一键，即可将 Vercel 应用迁移到 Replit！通过全新的导入流程，你可以将 Next.js 及其他托管在 Vercel 上的应用无缝迁移至 Replit。对于正在寻找 Vercel 替代方案的开发者来说，现在正是好时机。有关详情，请参阅[从 Vercel 导入快速入门](/zh/build/import-from-vercel)和[导入到 Replit 指南](/zh/references/workspace/import)。

<div id="git">
  ### 增强 Git 源代码管理
</div>

增强后的 Git 集成提升了远程仓库管理和工作区的灵活性。改进后的用户体验让你可以连接和创建 Git 远程仓库，轻松在个人和组织工作区之间切换，并确保代码在部署前始终保持最新。详情请参阅[使用 Git 面板](/zh/references/version-control/git-interface)。

<div id="section-2">
  ### 连接器 平台发布
</div>

24 个预构建的应用集成，助你更快构建！通过全新的 连接器 平台，你可以将 Replit 项目连接到 Stripe、Figma 等热门服务。每个 连接器 均基于 MCP (Model Context Protocol) ，让 AI 辅助开发更加顺畅。详见 [Agent 集成](/zh/replitai/integrations)和[管理 连接器](/zh/ja/replitai/managing-connectors)。

<div id="section-3">
  ### 应用主题字体改进
</div>

新增 19 款 Google Fonts，包括 Crimson、EB Garamond、Figtree、Source Sans Pro 等热门字体，可用于自定义你的应用。字体选择器现在会以字体本身的字形进行渲染，让你更直观地预览设计效果。字体按类别 (Serif、Sans-Serif、Monospace) 分类整理，并配有说明各类型的提示信息。详情请参阅[应用主题](/zh/replitai/app-themes)。

<div id="section-4">
  ### 连接器 的管理员管控
</div>

Enterprise 用户可使用高级 连接器 管理功能，包括针对共享 API 密钥的基于角色的访问控制，以及完全自定义的 OAuth 客户端配置。连接器 在组织层级采用选择加入 (opt-in) 方式，管理员可完全掌控团队成员能够使用的集成。详见[管理 连接器](/zh/ja/replitai/managing-connectors)。
