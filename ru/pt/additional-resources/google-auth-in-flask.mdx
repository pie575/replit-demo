Возможность входа на ваш сайт через учётную запись Google даёт следующие преимущества:

1. Вам не нужно реализовывать собственную схему аутентификации.
2. Вы можете легко получить имя и контактные данные пользователей.
3. Вы можете использовать те же учётные данные для доступа к сервисам Google, которыми пользуются ваши пользователи, — например, Sheets и Drive.

Это руководство покажет, как сделать это с помощью Python и Flask на Replit.

Сначала разберём, как настроить базовую OAuth-аутентификацию, а затем — как использовать полученные учётные данные для доступа к сервисам Google пользователей.

<div id="introduo-ao-oauth">
  ## Введение в OAuth
</div>

Аутентификация через Google основана на стандарте OAuth. OAuth работает следующим образом:

1. Где-то на вашем сайте вы направляете пользователя на страницу входа.
2. При переходе на страницу входа форму входа реализуете не вы на своём сайте — пользователь перенаправляется в сервис входа Google, который его аутентифицирует.
3. После успешной аутентификации сервис входа Google перенаправляет пользователя обратно на ваш сайт по заранее заданному URL на ваш выбор, например `https://YOUR_DOMAIN/oauth2callback`, передавая необходимую информацию о пользователе и сессии входа.
4. По этим данным входа вы получаете токен доступа — своего рода пропуск, с помощью которого можно обращаться к ресурсам пользователя: информации профиля, таблицам, документам и многому другому.

<div id="oauth-mostre-me-o-cdigo">
  ## OAuth: покажите мне код
</div>

Если вы похожи на меня, то первым делом вам нужен работающий код. Ниже — как раз то, что нужно. Правда, чтобы всё заработало, придётся кое-что настроить в Google Cloud Console — об этом в следующем разделе. Создайте новый App на Replit на основе [шаблона Flask](https://replit.com/@replit/Flask?v=1) и вставьте в `main.py` следующее. Комментарии в коде поясняют, за что отвечает каждая часть:

```python theme={null}
from flask import Flask, redirect, session, url_for, request
import google_auth_oauthlib.flow
import json
import os
import requests

app = Flask('app')
# `FLASK_SECRET_KEY` используется сессиями. Создайте случайную строку
# и сохраните её как секрет.
app.secret_key = os.environ.get('FLASK_SECRET_KEY') or os.urandom(24)

# `GOOGLE_APIS_OAUTH_SECRET` содержит содержимое JSON-файла, который нужно скачать
# из панели учётных данных Google Cloud. См. следующий раздел.
oauth_config = json.loads(os.environ['GOOGLE_OAUTH_SECRETS'])

# Здесь задаётся конфигурация потока OAuth
oauth_flow = google_auth_oauthlib.flow.Flow.from_client_config(
    oauth_config,
    # scopes определяют, к каким API вы хотите обращаться от имени пользователя после аутентификации
    scopes=[
        "https://www.googleapis.com/auth/userinfo.email",
        "openid",
        "https://www.googleapis.com/auth/userinfo.profile",
    ]
)

# Это точка входа страницы входа. Она перенаправляет на сервис входа Google по адресу
# `authorization_url`. А `redirect_uri` — это URI, по которому сервис входа Google
# вернёт пользователя обратно в это приложение.
@app.route('/signin')
def signin():
    # Мы меняем URL с http на https, потому что внутри Replit App используется http,
    # но извне доступ идёт по https, и redirect_uri должен этому соответствовать
    oauth_flow.redirect_uri = url_for('oauth2callback', _external=True).replace('http://', 'https://')
    authorization_url, state = oauth_flow.authorization_url()
    session['state'] = state
    return redirect(authorization_url)

# Это эндпоинт, на который сервис входа Google возвращает пользователя. Его нужно добавить в «Authorized redirect URIs»
# в панели учётных данных API в Google Cloud. Он вызывает эндпоинт Google, чтобы запросить
# токен доступа, и сохраняет его в сессии пользователя. После этого токен доступа можно использовать
# для обращения к API от имени пользователя.
@app.route('/oauth2callback')
def oauth2callback():
    if not session['state'] == request.args['state']:
        return 'Invalid state parameter', 400
    oauth_flow.fetch_token(authorization_response=request.url.replace('http:', 'https:'))
    session['access_token'] = oauth_flow.credentials.token
    return redirect("/")

# Это главная страница приложения. Она предлагает пользователю войти, если он ещё не вошёл.
# Если пользователь уже вошёл, отображается информация о нём.
@app.route('/')
def welcome():
    if "access_token" in session:
        user_info = get_user_info(session["access_token"])
        if user_info:
            return f"""
                Hello {user_info["given_name"]}!<br>
                Your email address is {user_info["email"]}<br>
                <a href="/logout">Log out</a>
            """
    return """
        <h1>Hello!</h1>
        <a href="/signin">Sign In via Google</a><br>
    """

# Вызываем API userinfo, чтобы получить информацию о пользователе по действующему токену доступа.
# Это первый пример использования токена доступа для обращения к API от имени пользователя.
def get_user_info(access_token):
    response = requests.get("https://www.googleapis.com/oauth2/v3/userinfo", headers={
       "Authorization": f"Bearer {access_token}"
   })
    if response.status_code == 200:
        user_info = response.json()
        return user_info
    else:
        print(f"Failed to fetch user info: {response.status_code} {response.text}")
        return None

@app.route('/logout')
def logout():
    session.clear()
    return redirect('/')

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000)

```
