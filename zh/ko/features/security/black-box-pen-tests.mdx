黑盒渗透测试通过浏览器和网络交互，从外部测试正在运行的应用，不使用应用的源代码。

Project Security Center 中的 **Level 3 (AI pentest)** 将三类安全检查整合为一项。

1. 免费的依赖项和软件包检查
2. Agent 对源代码进行的静态分析
3. 不使用源代码、从外部对在线预览进行的黑盒测试

启动 Level 3 后，Replit 会同时运行 Agent 源代码审查和外部黑盒测试。

<div id="level-3">
  ## 运行 Level 3 扫描
</div>

<Steps>
  <Step title="打开 Project">
    打开要扫描的 Project。
  </Step>

  <Step title="打开安全中心">
    在 Project 的 **Tools** 面板中选择 **安全中心**。
  </Step>

  <Step title="开始扫描">
    在 安全中心 顶部选择 **Run scan**。
  </Step>

  <Step title="选择 Level 3">
    选择 **Level 3 (AI pentest)**。

    <Frame caption="Level 3 (AI pentest) 在免费的依赖项和软件包检查基础上，增加了 Agent 静态分析以及对外部在线预览的测试。">
      <img src="/assets/mirror/level-3-ai-pentest-c223c0099d3f.png" alt="在从 Tools 面板打开的 Security and Privacy Center 中，Select scan level 菜单已展开，并已选择 Level 3 AI pentest" width="2204" height="1200" data-path="images/project-security-center/level-3-ai-pentest.png" />
    </Frame>
  </Step>

  <Step title="等待两项任务完成">
    等待源代码审查和浏览器及网络黑盒测试均完成。
  </Step>

  <Step title="查看结果">
    在 **Security** 面板中查看两项任务发现的问题。在将已批准的问题发送给 Agent 前，请评估每项发现的问题。
  </Step>

  <Step title="修复后重新运行">
    将已批准的问题发送给 Agent。应用修复后，重新运行 Level 3 扫描以确认修复结果。
  </Step>
</Steps>

<div id="section">
  ## 了解两项工作
</div>

| 工作     | 使用的依据            | 目的                      |
| ------ | ---------------- | ----------------------- |
| 源代码审查  | 应用的源代码           | 识别代码库中的安全、隐私和架构漏洞       |
| 黑盒渗透测试 | 与运行中应用进行浏览器和网络交互 | 在不使用源代码的情况下检查从外部可观察到的行为 |

请同时审查两组发现的问题。两项工作不能相互替代。源代码审查可以识别存在风险的实现细节，而黑盒测试则从外部评估运行中的应用。
