Le Canvas est une surface infinie que vous pouvez parcourir et zoomer librement, sur laquelle Replit Design affiche les frames. Tout ce que vous concevez se trouve ici : vous pouvez générer des frames, les déplacer, zoomer sur les détails et itérer jusqu&#39;à obtenir le résultat souhaité.

<div id="canvas">
  ## Ouvrir le Canvas
</div>

Le Canvas est la première chose qui s’affiche dans Replit Design. Dans un projet, sélectionnez **Design** dans l’en-tête pour afficher le Canvas dans tout le volet, ou sélectionnez **Build** pour revenir à l’application en cours d’exécution.

<Frame>
  <img src="/assets/mirror/canvas-design-button-ffa50447cefb.png" alt="Gros plan de l’en-tête du projet avec les boutons Design et Build. Design est sélectionné et un frame s’affiche sur le Canvas en dessous." width="987" height="619" data-path="images/replitai/canvas-design-button.png" />
</Frame>

Lorsque vous démarrez un nouveau projet sur [replit.com/design](https://replit.com/design), vous êtes invité à créer un nouveau design, puis le Canvas s’ouvre. Pour savoir quelle surface utiliser et à quel moment, consultez [Différences entre Design et Build](/fr/ja/design/design-vs-build).

<div id="canvas-2">
  ## Éléments présents sur le Canvas
</div>

* **Frames** : toutes les tuiles du tableau. Les frames peuvent être des maquettes, des applications web ou mobiles, des diapositives, des images, des vidéos ou des graphiques vectoriels. Vous pouvez les générer à partir de prompts dans le chat, du [menu Generate](/fr/ja/design/toolbar#generate) de la barre d’outils ou du [panneau Bibliothèque](/fr/ja/design/library-panel). Toutes les actions sur une frame — Build, Focus, suggestions, etc. — s’effectuent directement sur celle-ci. Pour en savoir plus, consultez [Frames](/fr/ja/design/frames).
* **Dessins et notes** : des annotations ajoutées avec l’[outil Draw](/fr/ja/design/toolbar#draw), comme des croquis, des flèches, des formes et des pense-bêtes. Agent lit vos annotations : vous pouvez donc entourer une zone problématique et demander une modification.
* **Panneau de chat** : le chat Agent ancré à côté du Canvas. Lorsque vous sélectionnez une frame avant d’envoyer un message, elle est jointe sous forme d’instantané afin qu’Agent dispose d’un contexte visuel.

Pour en savoir plus sur chaque composant et sur la manière dont ils s’articulent, consultez [Vue d’ensemble des composants](/fr/ja/design/core-components).

<div id="section">
  ## Naviguer sur le tableau
</div>

Vous pouvez effectuer un panoramique, zoomer et sélectionner avec n’importe quel outil, sauf indication contraire.

**Panoramique :**

* Pavé tactile : faites glisser avec deux doigts.
* Souris : faites glisser avec le bouton central, ou avec le bouton gauche tout en maintenant la barre d’espace enfoncée.
* [Outil Pan](/fr/ja/design/toolbar#pan) : cliquez et faites glisser avec le bouton gauche de la souris.

**Zoom :**

* Pavé tactile : effectuez un pincement.
* Souris : `Ctrl` (`Cmd` sur macOS) + molette de défilement.
* Clavier : `Cmd`/`Ctrl` + `+` pour zoomer, `Cmd`/`Ctrl` + `-` pour dézoomer et `Cmd`/`Ctrl` + `0` pour réinitialiser le zoom.

Le zoom est centré sur la position du curseur : le point situé sous le curseur reste fixe tandis que les autres parties du tableau s’agrandissent ou se réduisent autour de lui.

**Sélection :**

* Un seul frame : cliquez dessus avec l’[outil Interact](/fr/ja/design/toolbar#interact).
* Sélection multiple : maintenez `Shift` enfoncée tout en cliquant sur chaque frame, ou faites glisser une zone de sélection sur le tableau.
* Désélection : cliquez dans une zone vide ou appuyez sur `Escape`.

Lorsque vous sélectionnez un ou plusieurs frames, la [barre d’actions par frame](/fr/ja/design/frames#per-frame-action-bar) s’affiche, et ces frames sont joints sous forme d’instantanés à votre prochain message à Agent.

<div id="section-2">
  ### Raccourcis clavier
</div>

| Raccourci                      | Action                                               |
| ------------------------------ | ---------------------------------------------------- |
| `V`                            | Activer l&#39;outil Interact                         |
| `H`                            | Activer l&#39;outil Pan                              |
| `Space` enfoncée + glisser     | Faire un panoramique depuis n&#39;importe quel outil |
| `Cmd` / `Ctrl` + défilement    | Zoomer                                               |
| `Cmd` / `Ctrl` + `+`           | Zoom avant                                           |
| `Cmd` / `Ctrl` + `-`           | Zoom arrière                                         |
| `Cmd` / `Ctrl` + `0`           | Réinitialiser le zoom                                |
| `Shift` + clic                 | Ajouter une frame à la sélection actuelle            |
| `Cmd` / `Ctrl` + `Shift` + `C` | Copier les frames sélectionnées au format PNG        |
| `Escape`                       | Désélectionner                                       |

<div id="section-3">
  ## Menu contextuel
</div>

Faites un clic droit n’importe où sur le tableau pour ouvrir le menu contextuel. Ce menu s’adapte au contexte et propose des actions selon l’élément sous le curseur : des actions propres aux frames lorsque le curseur est sur une frame, des actions au niveau du tableau sur un Canvas vide, et **Refresh artifact** en plus sur une frame d’application.

Sur une frame sélectionnée, le menu comprend les éléments suivants :

| Action                         | Raccourci                  | Description                                                                   |
| ------------------------------ | -------------------------- | ----------------------------------------------------------------------------- |
| Edit                           |                            | Bascule vers l’outil Edit et permet de sélectionner les éléments de la frame. |
| Chat                           |                            | Discutez avec Agent à propos de la frame.                                     |
| Focus                          |                            | Active le [mode Focus](/fr/ja/design/frames#focus-mode) sur la frame.            |
| Cursor chat                    | `/`                        | Lance un chat rapide à l’emplacement du curseur.                              |
| Reorder                        |                            | Déplace la frame vers l’avant ou l’arrière dans l’ordre de superposition.     |
| Copy, Paste, Duplicate, Delete | `⌘C`、`⌘V`、`⌘D`、`Backspace` | Opérations standard de presse-papiers et de gestion des frames.               |
| Export as…                     |                            | Exporte la frame sous forme de fichier.                                       |
| Select all                     | `⌘A`                       | Sélectionne toutes les frames du tableau.                                     |

<div id="png">
  ### Exporter une frame au format PNG
</div>

Vous pouvez enregistrer n’importe quel artefact ou frame de design en image PNG. Cette fonction est utile pour partager des aperçus dans des documents ou des conversations, prendre un instantané avant de poursuivre les itérations ou envoyer une capture d’écran à vos coéquipiers.

<Steps>
  <Step title="Sélectionner une frame">
    Sélectionnez l’artefact ou la frame de design à exporter, puis attendez qu’il ait fini de charger.
  </Step>

  <Step title="Sélectionner Export">
    Dans la barre d’actions de la frame, sélectionnez **Export**. Vous pouvez aussi cliquer avec le bouton droit sur la frame et sélectionner **Export as…** &gt; **PNG**. L’image est téléchargée sur votre ordinateur avec un nom de fichier basé sur celui de la frame.
  </Step>
</Steps>

Pour copier la frame sélectionnée au format PNG sans le télécharger, appuyez sur `Cmd+Shift+C` (ou sur `Ctrl+Shift+C` sous Windows et Linux).

<Note>Le PNG exporté correspond à ce que la frame affiche actuellement sur le Canvas. Si l’application ou le design est encore en cours de chargement, attendez qu’il soit entièrement rendu avant de l’exporter.</Note>

<div id="canvas-3">
  ## Canvas et l’application en cours d’exécution
</div>

Canvas et l’aperçu de l’application en cours d’exécution partagent le même volet, et plusieurs modes permettent de passer de l’un à l’autre :

* **Mode Focus** : l’action **Focus** de la frame sélectionnée l’agrandit pour qu’elle occupe toute la vue. Sélectionnez **Exit focus** en haut du Canvas pour y revenir.
* **Mode lecture seule** : lorsque Canvas est verrouillé dans le contexte d’une tâche en arrière-plan, les actions d’itération sont masquées et seul Focus reste disponible.

<Note>
  Un forfait Core ou Pro est nécessaire pour créer une nouvelle application à partir d’une frame Design. Toutes les autres fonctionnalités de Canvas sont disponibles avec tous les forfaits. Consultez la page [Facturation](/fr/ja/billing/ai-billing) pour en savoir plus sur les forfaits.
</Note>
