icon: "rocket"

이 quickstart에서는 일상적인 표현으로 작성한 prompt로 첫 design frame을 생성한 다음, AI의 suggestions를 활용해 클릭 한 번으로 새로운 direction을 탐색해 봅니다. 디자인 경험은 필요 없습니다. 마음에 드는 것을 고르기만 하면 방향이 잡힙니다.

<Steps>
  <Step title="Replit Design 열기">
    [replit.com/design](https://replit.com/design)으로 이동합니다. 화면 정중앙에 있는 prompt box에서 디자인이 시작됩니다.

    <Frame>
      <img src="/assets/mirror/design-hero-4a82ee579911.png" alt="디자인하고 싶은 내용을 설명하라는 prompt box와 그 아래 Import URL, Import Figma, Recreate screenshot, Start with a design system 옵션이 있는 Replit Design 홈" width="889" height="414" data-path="images/design/replit-design/design-hero.png" />
    </Frame>

    <Note>
      이미 workspace에 있다면, workspace 홈의 생성 입력창 아래에서 **Design**을 선택하세요. 입력창이 디자인 모드로 전환되고 prompt box에 **Design** chip이 나타납니다.

      <Frame>
        <img src="/assets/mirror/design-pill-abe180082faa.png" alt="Design이 선택된 workspace 홈의 생성 입력창과 prompt box에 표시된 Design chip" width="800" height="270" data-path="images/design/replit-design/design-pill.png" />
      </Frame>
    </Note>
  </Step>

  <Step title="디자인하려는 내용 설명하기">
    디자이너 친구에게 brief를 설명하듯 prompt를 작성하세요. 무엇을 만들지, 누구를 위한 것인지, 원하는 분위기가 있다면 무엇인지 적으면 됩니다. 예를 들면 *&quot;슈퍼카 렌털 서비스를 위한 landing page, 강렬하고 어둡고 영화 같은 느낌.&quot;* 이렇게 작성한 뒤 제출하세요.
  </Step>

  <Step title="Design이 만드는 과정 지켜보기">
    Agent가 prompt를 받아 building을 시작하고, 작업하는 동안 chat 패널에 진행 상황을 알려줍니다.

    <Frame>
      <img src="/assets/mirror/design-building-c2ac529c1cef.png" alt="고급 슈퍼카 렌털 앱 prompt를 처리하며 Velocity artifact를 생성 중이라고 알리는 chat 패널이 있는 Replit Design 홈" width="2000" height="1254" data-path="images/design/replit-design/design-building.png" />
    </Frame>
  </Step>

  <Step title="첫 frame 살펴보기">
    디자인이 canvas에 frame으로 나타납니다. 잠시 기다린 뒤 전체 크기로 살펴보세요.

    <Frame>
      <img src="/assets/mirror/first-frames-a61342d3d85d.png" alt="focus mode에서 전체 크기로 확인 중인 Velocity 슈퍼카 렌털 페이지와 board 상단의 Exit focus 버튼" width="1600" height="1003" data-path="images/design/replit-design/first-frames.png" />
    </Frame>
  </Step>

  <Step title="suggestions로 계속 생성하기">
    가장 마음에 드는 frame을 선택하세요. 다음에 디자인할 내용에 대한 suggestions가 나타납니다. 하나를 클릭하면 새로운 direction이 새 frame으로 생성되고, 원래 frame은 그대로 남아 있습니다. 마음에 드는 결과가 나올 때까지 계속 클릭해 보세요.

    <Frame>
      <img src="/assets/mirror/suggestions-9811fa570612.png" alt="canvas에서 선택된 Velocity frame과 run이 완료된 chat 패널, frame 옆에 열리는 다음 단계 제안 패널" width="1600" height="1003" data-path="images/design/replit-design/suggestions.png" />
    </Frame>
  </Step>
</Steps>
