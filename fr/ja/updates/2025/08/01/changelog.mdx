<div id="agentreplit-docs">
  ### Agent peut désormais accéder à Replit Docs
</div>

Agent peut désormais répondre instantanément à vos questions sur les fonctionnalités et la documentation de Replit. Grâce à son accès direct à Replit Docs, Agent vous fournit une aide rapide, précise et complète, là où vous écrivez votre code.

<div id="section-3">
  ### Nouveau panneau Base de données
</div>

Profitez d&#39;une gestion des bases de données plus claire grâce au panneau Base de données repensé. La nouvelle interface facilite la distinction entre les bases de données de développement et de production, et simplifie vos flux de travail liés aux bases de données.

<div id="section-4">
  ### Bascule de thème dans le menu de l&#39;avatar
</div>
