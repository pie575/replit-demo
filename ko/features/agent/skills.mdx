## 스킬이란 무엇인가요?

스킬은 하나의 폴더입니다. 그 안에는 Agent가 따르는 지침이 담긴 `SKILL.md`라는 파일과, 참고하도록 하고 싶은 추가 지원 파일들이 들어 있습니다. 스킬은 프로젝트의 `/.agents/skills` 디렉터리에 존재하며, 에이전트 전반에서 통용되는 개방형 표준인 [Agent Skills specification](https://agentskills.io/specification)을 따릅니다.

Agent는 설치된 모든 스킬의 이름과 설명을 볼 수 있지만, 현재 작업과 관련이 있을 때만 전체 내용을 불러옵니다. 이는 스킬을 컨텍스트 효율적으로 만들어, Agent의 출력 품질을 저하시키지 않고도 많은 스킬을 설치할 수 있게 합니다.

## 사전 정의된 스킬

Replit은 채팅의 **스킬 사용** 선택기와 새 프로젝트 시작 지점 선택기에서 사용할 수 있는 사전 정의된 스킬을 제공합니다. 이 스킬들은 설치 없이 모든 프로젝트에서 작동합니다. 전체 카탈로그, 파트너 스킬, 설치 방법은 [Skills directory](/ko/features/agent/skills-directory)를 참고하세요.

사전 정의된 스킬을 추가하려면 채팅 입력창에서 **스킬 사용** 선택기를 열고 스킬을 선택하거나, Agent에게 해당 스킬을 불러오라고 요청하세요.

## 스킬 범위

스킬은 여러 수준으로 범위를 지정할 수 있습니다:

| 범위            | 사용 가능 범위             | 저장 위치                                                                                 |
| ------------- | -------------------- | ------------------------------------------------------------------------------------- |
| **프로젝트 수준**   | 하나의 프로젝트에 한정         | `/.agents/skills`에서 파일과 함께 버전 관리됨                                                     |
| **워크스페이스 수준** | 워크스페이스의 모든 사람이 사용 가능 | Workspace Settings에서 중앙 관리됨                                                           |
| **엔터프라이즈**    | 회사 전체 표준             | [커스텀 템플릿](/ko/teams/custom-templates)과 [디자인 시스템](/ko/teams/custom-design-system)에 포함됨 |

워크스페이스 수준 스킬에 대해서는, 팀을 위한 워크스페이스 스킬과 커스텀 지침을 설정하는 방법을 [Agent Customization](/ko/features/agent/agent-customization)에서 확인하세요.

## Agent가 스킬을 불러오는 방식

Agent는 모든 채팅에서 설치된 모든 스킬의 메타데이터(이름과 설명)를 읽습니다. 스킬의 전체 본문은 Agent가 현재 작업과 관련이 있다고 판단할 때만 불러와집니다. 이를 통해 필요할 때까지 스킬 콘텐츠가 컨텍스트 윈도우에 들어가지 않습니다.

설치된 스킬은 Agent 세션 전반에서 프로젝트에 유지되며, 팀 공유를 위해 버전 관리 시스템에 커밋할 수 있습니다.

## 다른 AI 코딩 도구와 함께 사용하기

<Accordion title="다른 AI 코딩 도구에서 스킬 가져오기">
  여러 AI 코딩 도구를 함께 사용한다면, [rulesync](https://github.com/dyoshikawa/rulesync)가 Replit을 지원하여 일관된 구성을 유지하도록 도와줍니다.

  다른 AI 코딩 어시스턴트에서 스킬을 가져올 수 있습니다:

  ```bash theme={null}
  npx rulesync init
  npx rulesync import --targets claudecode --features skills
  npx rulesync generate --targets replit --features skills
  ```

  이를 통해 여러 개발 환경에서 함께 작동하는 단일 스킬 세트를 유지할 수 있습니다.
</Accordion>
