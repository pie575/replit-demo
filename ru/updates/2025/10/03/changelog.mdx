<div id="vercel-import-integration">
  ### Интеграция импорта из Vercel
</div>

Переносите приложения из Vercel в Replit одним щелчком! Новый процесс импорта позволяет легко перенести в Replit приложения Next.js и другие приложения, размещённые на Vercel. Идеально для разработчиков, ищущих альтернативу Vercel. Подробнее — в [кратком руководстве по импорту из Vercel](/ru/build/import-from-vercel) и [руководстве по импорту в Replit](/ru/references/workspace/import).

<div id="git-source-control-enhancements">
  ### Улучшения контроля версий Git
</div>

Улучшенная интеграция Git упрощает управление удалёнными репозиториями и делает работу в workspace гибче. Подключайте и создавайте удалённые репозитории Git с улучшенным UX, легко переключайтесь между личными workspace и workspace организации и поддерживайте код в актуальном состоянии перед deployment. Подробнее см. в разделе [Использование панели Git](/ru/references/version-control/git-interface).

<div id="connectors-platform-launch">
  ### Запуск платформы Connectors
</div>

Создавайте приложения быстрее с помощью 24 готовых интеграций! Подключайте свои проекты Replit к популярным сервисам, таким как Stripe, Figma и другим, через нашу новую платформу Connectors. Каждый коннектор работает на базе MCP (Model Context Protocol), обеспечивая бесшовную разработку с поддержкой ИИ. См. [интеграции Agent](/ru/replitai/integrations) и [управление коннекторами](/ru/replitai/managing-connectors).

<div id="app-themes-font-improvements">
  ### Улучшения шрифтов в темах App
</div>

Настраивайте приложения с помощью ещё 19 шрифтов Google Fonts, включая популярные Crimson, EB Garamond, Figtree и Source Sans Pro. Теперь в средстве выбора шрифтов каждый шрифт отображается в своём оригинальном начертании, поэтому проще представить, как будет выглядеть ваш дизайн. Шрифты сгруппированы по категориям (Serif, Sans-Serif, Monospace), а всплывающие подсказки поясняют каждый тип. Подробнее читайте в разделе [Темы App](/ru/replitai/app-themes).

<div id="connectors-admin-management">
  ### Управление коннекторами для администраторов
</div>

Клиенты Enterprise получают расширенные возможности управления коннекторами, включая ролевой контроль доступа к общим ключам API и полностью настраиваемую конфигурацию клиента OAuth. Коннекторы подключаются на уровне организации, что позволяет администраторам полностью контролировать, какие интеграции доступны участникам команды. См. [Управление коннекторами](/ru/replitai/managing-connectors).
