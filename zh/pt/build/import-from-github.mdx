<div id="importar-do-github">
  ## 从 GitHub 导入
</div>

⏰ *预计用时：两分钟*

将 GitHub 仓库导入 Replit，以便更快地运行、测试和发布。

如需了解包含 Figma、Bolt 和 Lovable 等其他平台在内的完整导入选项，请参阅[导入功能文档](/zh/pt/references/workspace/import)。

<div id="antes-de-comear">
  ## 开始之前
</div>

* 一个 GitHub 仓库 URL
* 仓库访问权限 (公开或私有)
* 一个 Replit 账号

<div id="opo-um-importao-rpida">
  ## 方式一：快速导入
</div>

快速导入适用于公开仓库。

1. 复制 `github.com/` 之后的仓库路径。
2. 打开 `https://replit.com/github.com/<owner>/<repo>`。
3. 按回车键开始导入。

**示例**

* GitHub 地址：`https://github.com/exampleUser/my-app`
* Replit 导入地址：`https://replit.com/github.com/exampleUser/my-app`

<div id="opo-dois-importao-guiada">
  ## 方式二：引导式导入
</div>

引导式导入支持公开和私有仓库。

1. 打开 [replit.com/import](https://replit.com/import)。
2. 选择 **GitHub**。
3. 连接你的 GitHub 账号。
4. 选择要导入的仓库。
5. 点击 **Import**。

<div id="o-que-importado">
  ## 导入的内容
</div>

* 仓库中的文件和文件夹
* 依赖文件
* 常见的运行和构建配置

<div id="o-que-no-importado">
  ## 哪些内容不会被导入
</div>

* 现有的 Secrets 值和环境变量
* 默认无法在 Replit 上运行的平台专属服务
