  ## 平台更新
</div>

<div id="section-3">
  ### 预览空状态优化
</div>

Agent 应用的预览体验现在能更智能地处理空状态和自动运行，让你使用 Agent 构建时的工作流更加顺畅。

<div id="ai">
  ### AI 延迟优化
</div>

我们通过基础设施升级，大幅缩短了 Replit AI 的响应时间、降低了延迟。在使用 Replit 各项 AI 功能 (包括 Agent 和 Assistant) 时，您会感受到更流畅快速的交互体验。

<div id="github">
  ### 统一 GitHub 标签页焕新
</div>

统一 GitHub 标签页的界面更加简洁统一。全新设计让你在工作区中连接和管理 GitHub 仓库更加得心应手。

<div id="ios">
  ### iOS 应用内支付支持
</div>

iOS 用户现在可以直接在 Replit 移动应用中购买 Replit Core 并设置支付方式，随时随地都能更轻松地使用高级功能。

<div id="stripe-checkout">
  ### Stripe Checkout 上线
</div>

全新的 Stripe Checkout 集成为所有开发者带来更顺畅、更安全的支付体验。依托业界标准的支付方案，购买流程更加简洁，升级到 Replit Core 轻而易举。
