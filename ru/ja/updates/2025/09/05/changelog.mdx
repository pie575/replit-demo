  ## Платформа
</div>

<div id="general-agent">
  ### General Agent
</div>

<Frame>
  <img src="/assets/mirror/general-agent-240ff289e711.png" alt="Главная иллюстрация General Agent" width="1040" height="572" data-path="images/replitai/general-agent.png" />
</Frame>

Replit Agent теперь работает с кодовыми базами на любых языках и фреймворках, которые запускаются на NixOS! Раньше он поддерживал только определённые шаблоны, но теперь Agent может помогать с фреймворками для разработчиков, импортом из GitHub и любыми пользовательскими настройками проекта. Это значительное расширение предоставляет полноценную поддержку ИИ-кодинга для рабочих процессов Enterprise и опытных пользователей.

Подробнее о General Agent читайте [здесь](/ru/core-concepts/agent/general-agent).

<div id="section-3">
  ### режим Plan
</div>

<Frame>
  <img src="/assets/mirror/plan-mode-overview-8077807c63b9.png" alt="Интерфейс чата Agent в режиме Plan" width="916" height="362" data-path="images/replitai/plan-mode-overview.png" />
</Frame>

режим Plan предлагает новый формат общения с Replit Agent, ориентированный на вопросы, мозговой штурм и планирование работы. В этом режиме можно с помощью Agent составлять списки задач для дальнейшей работы, а затем выполнять длительные задачи в режиме сборки.

Подробнее о режиме Plan — [здесь](/ru/core-concepts/agent/plan-mode).

<div id="enterprise">
  ## Enterprise
</div>

<div id="gcp">
  ### Интеграция с Google Cloud Marketplace
</div>

Клиенты Enterprise теперь могут приобретать Replit напрямую в Google Cloud Platform Marketplace и оплачивать его имеющимися кредитами GCP. Это упрощает процесс закупок и помогает организациям с бюджетом GCP легче внедрять Replit в процессы разработки.
