Импортируйте существующий код или дизайн в Replit App и продолжите разработку с помощью Agent.

<div id="section">
  ## Поддерживаемые источники
</div>

| Источник                 | Что требуется                                                 | Оптимальное применение                                           |
| ------------------------ | ------------------------------------------------------------- | ---------------------------------------------------------------- |
| GitHub                   | URL репозитория или средство выбора репозитория               | Импорт публичных и приватных репозиториев                        |
| Bitbucket                | URL репозитория или средство выбора репозитория               | Импорт репозиториев, размещённых на Bitbucket                    |
| Vercel                   | Репозиторий GitHub, связанный с проектом Vercel               | Миграция приложений Vercel                                       |
| Figma                    | URL фрейма                                                    | Преобразование дизайна в React-приложение                        |
| Claude                   | Дизайн, отправленный из Claude                                | Преобразование дизайна Claude в интерактивное приложение         |
| Bolt                     | Репозиторий GitHub, экспортированный из Bolt                  | Миграция проектов Bolt                                           |
| Lovable                  | Репозиторий GitHub, экспортированный из Lovable               | Миграция проектов Lovable                                        |
| Base44                   | Репозиторий GitHub, экспортированный из Base44                | Миграция проектов Base44                                         |
| ZIP                      | Загрузка файла `.zip`                                         | Импорт архива локального проекта                                 |
| Электронные таблицы      | Файлы `.xlsx`, `.csv` или URL Google Таблиц                   | Создание приложения на основе данных электронной таблицы         |
| Предыдущий экспорт Agent | Репозиторий GitHub, экспортированный из предыдущего Agent App | Повторный импорт предыдущего Agent App                           |
| Пустой проект            | Нет                                                           | Для опытных пользователей, которым нужен пустой проект без Agent |

<Note>Replit проверяет совместимость перед началом импорта.</Note>

Подробнее о дизайнах Figma см. в разделе [Импорт дизайнов Figma в Replit Design](/ru/ja/design/import-figma-designs-into-replit-design).

Подробнее о дизайнах, отправленных из Claude, см. в разделе [Импорт дизайнов Claude в Replit Design](/ru/ja/design/import-claude-designs-into-replit-design).

    ⏰ *Ориентировочное время: 4 минуты*

    Экспортируйте проект Lovable в GitHub, а затем импортируйте этот репозиторий в Replit.

    **Что потребуется перед началом**

    * Проект Lovable, доступный для экспорта
    * Учётная запись GitHub, подключённая к Lovable
    * Учётная запись Replit

    **Инструкции**

    1. Экспортируйте проект Lovable в GitHub.
    2. Откройте [replit.com/import](https://replit.com/import).
    3. Выберите **Lovable**.
    4. Подключите учётную запись GitHub.
    5. Выберите экспортированный репозиторий Lovable.
    6. Выберите **Импортировать**.

    <div id="what-gets-imported">
      ## Что импортируется
    </div>

    Replit импортирует из вашего проекта {platform_6} следующее:

    * **Код**: логика приложения и исходные файлы
    * **Дизайн и стили**: компоненты UI и правила стилизации
    * **Ресурсы**: изображения, иконки и статические файлы
    * **Логика бэкенда**: серверная функциональность, если она есть
    * **Схема базы данных**: структура таблиц, если она есть

    <div id="what-is-not-imported">
      ## Что не импортируется
    </div>

    * **Данные Supabase**: существующие записи базы данных не переносятся
    * **Secrets**: переменные окружения и API-ключи необходимо добавить отдельно

    Используйте Agent, чтобы восстановить недостающую функциональность, добавить Secrets и воссоздать данные базы данных.

    <div id="configure-and-run-your-app">
      ## Настройте и запустите приложение

    Во время импорта {setupDescription_0}. Если в приложение нужно внести изменения, используйте следующие инструменты Project Editor:

    * **[Agent](/ru/features/agent/overview)**: Дорабатывайте функции, устраняйте неполадки и вносите изменения в код
    * **[Secrets](/ru/core-concepts/project-editor/app-setup/secrets)**: Добавляйте API-ключи и переменные окружения
    * **[Workflows](/ru/features/workspace-tools/workflows)**: Укажите команду **Run** для приложения

    ⏰ *Примерное время: 2 минуты*

    Импортируйте репозиторий GitHub в Replit, чтобы быстрее запускать, тестировать и публиковать приложение.

    **Что понадобится**

    * URL репозитория GitHub
    * Доступ к репозиторию (публичному или приватному)
    * учётная запись Replit

    **Вариант 1: быстрый импорт**

    Быстрый импорт доступен для публичных репозиториев.

    1. Скопируйте путь к репозиторию после `github.com/`.
    2. Откройте `https://replit.com/github.com/<owner>/<repo>`.
    3. Нажмите Enter, чтобы начать импорт.

    *Пример*

    * URL GitHub: `https://github.com/exampleUser/my-app`
    * URL для импорта в Replit: `https://replit.com/github.com/exampleUser/my-app`

    **Вариант 2: импорт с пошаговыми инструкциями**

    Импорт с пошаговыми инструкциями поддерживает публичные и приватные репозитории.

    1. Откройте [replit.com/import](https://replit.com/import).
    2. Выберите **GitHub**.
    3. Подключите учётную запись GitHub.
    4. Выберите репозиторий.
    5. Выберите **Импортировать**.

    **Что будет импортировано**

    * Файлы и папки репозитория
    * Файлы зависимостей
    * Стандартные настройки запуска и сборки

    **Что не будет импортировано**

    * Существующие значения секретов и переменных окружения
    * Специфичные для платформы сервисы, которые по умолчанию не работают в Replit

    **Устранение неполадок с подключением GitHub**

    Если отображается `Failed to get repository, please re-authenticate with GitHub` или в раскрывающемся списке репозиториев указано `No repositories found`, для импорта из GitHub используется подключение, отдельное от страницы **Аккаунт → Подключённые сервисы**. Повторное подключение в разделе подключённых сервисов не решит проблему с импортом.

    <Steps>
      <Step title="Повторно подключите GitHub в разделе Git-провайдеры">
        Откройте раздел **Git-провайдеры** в настройках учётной записи Replit, отключите GitHub и снова подключите его на том же экране. После этого личные репозитории должны появиться в раскрывающемся списке импорта.
      </Step>

      <Step title="Разрешите приложению Replit доступ к организации GitHub">
        Если репозиторий принадлежит организации GitHub, откройте [https://github.com/settings/applications](https://github.com/settings/applications), найдите OAuth-приложение Replit и разрешите ему доступ к организации в настройках доступа сторонних приложений. Если вы не владелец организации, этот шаг должен выполнить её администратор.
      </Step>

      <Step title="Повторите попытку импорта">
        Откройте [replit.com/import](https://replit.com/import) и повторите импорт: выберите репозиторий в раскрывающемся списке или вставьте URL репозитория.
      </Step>
    </Steps>

  <Tab title="ZIP">
    ⏰ *Примерное время: 3 минуты*

    Загрузите файл `.zip`, чтобы импортировать локальный проект.

    **Что нужно перед началом**

    * Файл `.zip` с проектом (не более 200 МБ)
    * Чётко определённая корневая папка проекта в архиве
    * Учётная запись Replit

    Если размер ZIP-файла превышает 200 МБ, форма импорта отклонит его. Чтобы уменьшить размер, исключите папки с зависимостями и результатами сборки, например `node_modules`, `.venv` и `build`. Replit переустановит зависимости во время импорта.

    **Шаги**

    1. Откройте [replit.com/import](https://replit.com/import).
    2. Выберите **ZIP**.
    3. Загрузите файл `.zip`.
    4. Добавьте необходимые секреты и переменные окружения.
    5. Выберите **Импортировать**.

    **Что импортируется**

    * Файлы проекта и структура каталогов
    * Файлы зависимостей
    * Стандартные настройки запуска и сборки для Replit

<div id="section-3">
  ## Другие источники
</div>

<div id="bitbucket">
  ### Bitbucket
</div>

* Вставьте URL репозитория Bitbucket или подключите аккаунт Bitbucket, чтобы найти нужный репозиторий.
* Поддержка Agent при импорте может быть ограничена по сравнению с проектами, размещёнными на GitHub.

<div id="section-4">
  ### Электронные таблицы
</div>

* Загрузите файл Excel (`.xlsx`) или CSV либо вставьте URL общедоступной Google Таблицы.
* Agent считывает структуру таблицы и создаёт полностековый App с базой данных, заполненной данными из неё.
* App включает UI для просмотра, поиска и управления записями.

<div id="agent">
  ### Ранее экспортированные Agent App
</div>

* Повторно импортируйте ранее экспортированное Agent App из репозитория GitHub.
* Replit сохраняет структуру, характерную для Agent: код, схемы базы данных и функции бэкенда.
* Значения из базы данных и секреты не импортируются.

<div id="section-5">
  ### Пустой
</div>

* Начните с полностью пустого проекта: без Agent, выбора фреймворка и шаблонного кода.
* Оптимально для опытных пользователей, которым нужен полный контроль над настройкой проекта.

<div id="section-6">
  ## Ограничения
</div>

* Данные из существующей базы данных не переносятся.
* Размер ZIP-загрузок ограничен 200 МБ.
* Для сложных или нестандартных зависимостей может потребоваться ручная настройка.
* Обработка крупных проектов может занять больше времени.

<div id="section-7">
  ## Лучшие практики
</div>

* Перед импортом удалите конфиденциальную информацию.
* Поддерживайте структуру исходного проекта в чистоте.
* После импорта проверьте зависимости и команду запуска.
* Перед публикацией протестируйте основные сценарии.

<div id="section-8">
  ## Устранение неполадок
</div>

Если импорт завершился с ошибкой, сначала проверьте следующее:

* **Ошибка совместимости**: проверьте наличие необходимых файлов проекта и поддержку используемых фреймворков.
* **Ошибка доступа**: проверьте права доступа к репозиторию или источнику.
* **Ошибка обработки**: упростите структуру проекта или уменьшите его размер, затем повторите попытку.

Если проблема не исчезнет, посетите [сообщество Replit](https://replit.com/community) или [обратитесь в службу поддержки](https://replit.com/support).

<div id="section-9">
  ## Оплата
</div>

Импорт, требующий переноса с помощью Agent, может потребовать кредитов. Расход кредитов зависит от сложности проекта.
