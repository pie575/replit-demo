---
title: "启用反馈小组件"
description: "了解如何收集已发布应用访客的反馈。"
---

在已发布应用中启用反馈收集功能后，你可以直接收集访客的反馈洞察，并将其发送给 Agent。启用后，访客可以提交包含截图和文件的反馈，你可以通过 Inbox 进行管理。

<div id="section">
  ## 启用反馈
</div>

<Warning>
  反馈功能仅支持 Web 应用。自动化、移动应用等其他类型的应用无法启用。
</Warning>

发布新应用时，请在发布对话框中开启 **Enable Feedback** 设置。对于已发布的应用，可以通过重新发布来启用反馈：

1. 打开 Publishing 工具
2. 选择 **Advanced Settings**
3. 开启 **Enable Feedback**
4. 重新发布应用

  如果已发布应用中没有显示反馈小组件，请尝试刷新页面
</Warning>

<div id="section-2">
  ## 提交反馈
</div>

如果已发布应用启用了反馈功能，访问者可以直接在应用中提交反馈。用户可以：

* 登录并留下反馈
* 留下文字反馈，描述使用体验或提出建议
* 选择页面元素，指出问题所在或相关功能
* 上传文件以提供更多上下文

<div id="inbox">
  ## 在 Inbox 中管理反馈
</div>

访问者提交的所有反馈都会显示在 Inbox 中，你可以从 Project Editor 内打开它。在 Inbox 中可以执行以下操作：

* **Add to Chat**：将反馈发送到与 Agent 的对话中，并在发送前补充上下文
* **Send to Agent**：立即将反馈发送给 Agent，让它马上开始处理
* **Resolve**：将已处理的反馈标记为已解决
* **Delete**：删除不再需要的反馈

你还可以使用筛选器整理和查找特定的反馈条目。

<div id="section-3">
  ## 更新反馈设置并重新发布
</div>

应用发布后，你可以随时使用更新后的设置重新发布，以启用或禁用反馈小组件：

1. 打开 Publishing 工具中的 **Overview** 标签页
2. 选择 **Advanced Settings**
3. 开启或关闭 **Enable Feedback**
4. 重新发布应用以应用更改

对反馈设置所做的更改将在应用重新发布后生效。
