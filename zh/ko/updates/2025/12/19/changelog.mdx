<div id="ui">
  ### 文档 UI 焕新
</div>

<Frame>
  <img src="/assets/mirror/cleanshot-2025-12-19-at-08-42-08-2x_d34ab73df672-cb2d456d47a4.png" alt="此前：旧版文档外观" width="3309" height="2126" data-path="images/changelog/2025-12-19/cleanshot-2025-12-19-at-08-42-08-2x_d34ab73df672.png" />

我们对文档站点进行了视觉更新，使其更贴合 Replit 的 Workspace 设计与品牌配色，让文档与主应用之间的体验更加统一。

* 更新配色方案，与品牌色保持一致
* 界面设计更接近 Workspace
* 提升 Replit 各产品之间的视觉一致性

<div id="section-2">
  ### 回滚会话拼接
</div>

<Frame>
  <img src="/assets/mirror/image_96365209a733-43b242e09e09.png" width="1600" height="1200" data-path="images/changelog/2025-12-19/image_96365209a733.png" />
</Frame>

回滚现在会自动串联相邻的会话，让你更轻松地跨多个工作会话撤销更改。这项改进能帮助你更顺畅地浏览项目历史记录。

<div id="mcp">
  ### 自定义 MCP 服务器图标
</div>

<Frame>
  <img src="/assets/mirror/68747470733a2f2f6170702e6772617068697465_77c0ef3cd3e9-e82e55fe7691.png" width="676" height="594" data-path="images/changelog/2025-12-19/68747470733a2f2f6170702e6772617068697465_77c0ef3cd3e9.png" />
</Frame>

自定义 MCP 服务器现在会通过 Google Favicon API 显示对应的图标，并新增了 MCP 标签，让你在 Workspace 中更容易识别。

<div id="section-3">
  ### 状态点设计更新
</div>

状态指示点已去除阴影效果，视觉呈现更加简洁。
