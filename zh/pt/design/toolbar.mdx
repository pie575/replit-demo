Canvas 工具栏是固定在画布底部中央的浮动工具栏，提供用于导航、绘制、编辑和添加内容的工具。工具栏仅在 Canvas 模式下显示。

</Frame>

<div id="ferramentas">
  ## 工具
</div>

选择某个工具后，该工具将处于激活状态。激活的工具会以实心背景突出显示。最左侧的一组为导航工具 (Interact、Pan) ，其余为内容和标注工具。这些工具互斥，选择其中一个会停用其他工具。

<div id="interact">
  ### Interact
</div>

**Interact** 是默认工具。可用它选择 frame、拖动 frame，或点击处于运行状态的 Artifact，像使用真实运行的 app 一样与其交互。启用 Interact 后，点击某个 frame 即可将其选中，并显示[单个 frame 操作栏](/zh/pt/design/frames#per-frame-action-bar)。

<Frame>
  <img src="/assets/mirror/canvas-interact-4472dae3de09.png" alt="使用 Interact 工具选中某个 Website artifact 的 Canvas —— 该 frame 显示选择框和控制手柄，单个 frame 操作栏位于其上方。Interact 工具在底部的浮动工具栏中高亮显示。" width="3450" height="2000" data-path="images/replitai/canvas-interact.png" />
</Frame>

**键盘快捷键：** `V`。**可用性：** 始终启用。

<div id="pan">
  ### Pan
</div>

**Pan** (平移) 会将光标变为拖动工具，让你可以移动画布本身。Pan 处于启用状态时，点击并拖动会移动视口，而不是选中某个 frame。使用其他任意工具时，你也可以按住空格键拖动，或用鼠标中键拖动来平移画布。

<Frame>
  <img src="/assets/mirror/canvas-pan-9f07d3bf72a3.png" alt="启用 Pan 工具的 Canvas —— 画布中可见一个 Website artifact（Velocity — Supercar Rental）和一个 Design 模型（Velocity — Home (Mockup)），底部的浮动工具栏中 Pan 工具（手形光标）处于高亮状态。" width="1725" height="1041" data-path="images/replitai/canvas-pan.png" />
</Frame>

**键盘快捷键：** `H`。**可用性：** 始终可用。

<div id="chat">
  ### Chat
</div>

**Chat** 会直接在画布上显示一个小型聊天输入框，让您无需离开 Canvas 即可向 Agent 发送提示词。所选元素和 frame 会继续以截图形式附加到消息中，和通过 Agent 侧边 Chat 面板发送时一样。

<Frame>
  <img src="/assets/mirror/canvas-chat-d28e2d8f216a.png" alt="Canvas 处于 Chat 模式，其余画布区域已变暗，内嵌聊天输入框叠加在一个 Website artifact 上。聊天输入框中的“div”标签表示已选中一个元素，提示词为“suggest three alternatives to this image”。Chat 工具在底部浮动工具栏中高亮显示。" width="3450" height="2000" data-path="images/replitai/canvas-chat.png" />
</Frame>

**可用性：**Chat 工具 (仅限桌面端) 。

<div id="draw">
  ### 绘制
</div>

**Draw** 会启用自由绘制、箭头、便签和形状等标注工具，让你可以在 frame 上勾画或为画布添加注释。你可以用它圈出问题点、指向想要修改的元素，或在 frame 旁留下文字备注。

当 Draw 处于启用状态时，浮动工具栏上方会显示 **Shape properties** 栏，其中包含当前标注工具的颜色、描边和填充控件。切换回 Interact 或 Pan 后，该栏会自动隐藏。

<Frame>
  <img src="/assets/mirror/canvas-draw-d2d9b6556cde.png" alt="Canvas 中的 Draw 工具处于启用状态——绘制了一个“小组件”矩形，并在 frame 旁放置了一张紫色的“添加小组件”便签。浮动工具栏上方显示了 Shape properties 栏（包含铅笔、文本、矩形、箭头和便签工具，以及颜色样本和 Aa 文本大小控件），其中 Draw 处于高亮状态。" width="1725" height="1041" data-path="images/replitai/canvas-draw.png" />
</Frame>

**可用性：**始终可用。

<div id="edit">
  ### Edit
</div>

**Edit** 是用于选择元素的可视化工具。启用 Edit 后，在当前 Artifact 中单击即可选中元素 (例如按钮、标题或图片) 。选中元素后会打开 **Visual Editor**——右侧的控件面板 (Layout、Color、Border 等) ，并提供内联提示词，让你请求 Agent 仅修改该部分。有关完整流程，请参阅 [Elements](/zh/pt/design/elements) 和 [Visual Editor](/zh/pt/design/visual-editor)。

<Frame>
  <img src="/assets/mirror/canvas-edit-67fe5ee02fbe.png" alt="超级跑车租赁网站中已启用的 Edit 工具，选中了一个 div 元素；Visual Editor 面板显示 Text、Layout、Color 和 Border 控件，以及 Discard 和 Save edits 按钮" width="2000" height="1269" data-path="images/replitai/canvas-edit.png" />
</Frame>

**可用性：**始终启用 (桌面端) 。至少存在一个 frame 后才可用；提示会显示 *“创建 artifact 或生成 design 以进行编辑。”* 在移动设备上隐藏。

<div id="generate">
  ### Generate
</div>

**Generate** 会打开 **Generate media** 弹出面板，用于生成图片、视频和矢量图形。选择类型，写好 prompt，Agent 就会把生成结果作为新的 frame 放到 Canvas 上。

<Frame>
  <img src="/assets/mirror/canvas-add-menu-5d97d9c813e1.png" alt="Canvas 的 + Add 菜单已打开，垂直排列着四个选项：Design（“Mock up interfaces and visual concepts”）、Image（“Generate and edit images”）、Video（“Generate motion clips and animations”）和 Vector Graphic（“Generate vector illustrations and SVGs”）。底部浮动工具栏中的 Generate 位置现在显示为“+ Generate”。" width="1102" height="702" data-path="images/replitai/canvas-add-menu.png" />
</Frame>

弹出面板顶部有四个标签页：

* **Design**
  — **Image**
* **Video**
* **Vector Graphic**

有些控件为各类型通用，另一些则专属于特定类型。

**通用控件 (所有类型) ：**

* **Model**：使用的生成模型。可用模型因类型而异 (见下表) 。
* **Prompt**：用自然语言描述你希望 Agent 生成的内容。
* **Generate**：提交请求，并在光标位置预留一个占位 frame。资源生成完毕后，占位符会变成正式 frame；若生成失败，占位符会被移除，并在 Chat 面板中显示错误信息。

**各类型的模型与控件：**

| 类型          | 适用场景                              | 当前模型                                                         | 类型专属控件                                                       |
| ----------- | --------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **Image**   | 位图输出 (PNG / JPG) ；情绪板图片、主视觉图、参考画稿 | Nano Banana、Nano Banana 2、Nano Banana Pro、ChatGPT Images 2.0 | 宽高比 (`1:1`、`16:9`、`9:16`、`4:3`、`3:4`) · 尺寸 (`1K`、`2K`、`4K`)  |
| **Video**   | 短视频与动画                            | Veo 3.1、Seedance 2.0                                         | 宽高比 · 分辨率 (如 `720p`) · 时长 (如 `4s`) · 音频开关                    |
| **Graphic** | SVG 矢量输出；图标、标志、图表、风格化插画           | Claude 4.6 Opus、Gemini 3.1 Pro Preview                       | 动画开关                                                         |

<Note>
  模型列表会频繁变动。上表反映的是当前可用的模型；具体你的账户现在能用哪些，请查看产品内的下拉菜单。
</Note>

如需了解每种 frame 类型的含义以及创建后可以进行哪些操作，请参阅 [Frames](/zh/pt/design/frames)。

<div id="anexe-referncias-visuais">
  #### 添加视觉参考
</div>

生成前，您可以将画布中已有的项目添加为视觉参考。Agent 会利用这些参考来引导生成结果，使其与项目的视觉风格保持一致。打开 **Generate media** 表单中的 **+** 菜单，然后选择一个选项：

* **Upload file**：从电脑上传图片作为参考。
* **Select canvas elements**：选择画布中的现有项目。frame 会截取为屏幕截图；文本形状和便笺会以文本摘要的形式附加。

每个参考都会在表单中显示为标签。您可以按需添加多个参考，输入 prompt，然后选择 **Generate**。要移除参考，请选择相应标签。

<Frame caption="Generate media 表单中打开的 + 菜单，显示 Upload file 和 Select canvas elements。">
  <img src="/assets/mirror/canvas-generate-media-references-ac0cb4340acb.png" alt="Canvas 中的 Generate media 表单已打开加号菜单，显示 Upload file 和 Select canvas elements 选项，以及设为 Nano Banana Pro 的模型下拉菜单" width="1134" height="662" data-path="images/replitai/canvas-generate-media-references.png" />
</Frame>

<Note>
  ChatGPT Images 2.0 目前不支持上传。请更换模型，例如 Nano Banana Pro，以添加视觉参考。
</Note>

启用 **Add menu** 后，**Generate** 按钮会替换为 **+** 菜单，其中包含各类弹出菜单选项以及 **Design** (不会影响现有代码的独立视觉模型) ：

**可用性：** 图像生成。**Vector Graphic** 需要矢量图形生成功能；**Video** 需要视频生成功能。**+** 菜单需要启用 Add menu (而 Add menu 又需要图像生成功能) 。

<div id="navegao-no-quadro">
  ## 画板导航
</div>

平移、缩放、选择手势及其键盘快捷键都属于画板级别的操作，而非工具栏中的工具。详见 Canvas 页面的[浏览画板](/zh/pt/design/canvas#navigate-the-board)。
