Здесь собраны ответы по работе с Agent. Полную справочную информацию см. в разделах [Обзор Agent](/ru/features/agent/overview), [режимы Agent](/ru/features/agent/agent-modes) и [Оплата ИИ](/ru/billing/ai-billing).

<AccordionGroup>
  <Accordion title="Agent зависает или постоянно отключается. Как это исправить?">
    1. Откройте палитру команд с помощью `Cmd+K` (Mac) или `Ctrl+K` (Windows).
    2. Найдите **Restart compute** и выберите этот пункт, чтобы перезапустить среду разработки.
    3. Откройте новый чат с Agent и снова опишите задачу, чтобы продолжить.

    Если Agent кажется зависшим, не отправляйте новые сообщения: они создают противоречивые инструкции. Если Agent продолжает зависать на той же задаче, разбейте работу на более мелкие и конкретные запросы.
  </Accordion>

  <Accordion title="Agent зациклился или повторяет одни и те же действия — как это остановить?">
    1. Нажмите **Stop** на панели Agent, чтобы немедленно его остановить.
    2. Откройте палитру команд с помощью `Cmd+K` (Mac) или `Ctrl+K` (Windows), найдите пункт **Restart compute** и выберите его.
    3. Откройте новый чат с Agent и сформулируйте задачу более конкретно.

    Как избежать зацикливания:

    * Разбивайте крупные задачи на короткие prompt — по одной цели на сообщение.
    * Используйте [режим Plan](/ru/features/agent/plan-mode), чтобы определить объём работ до того, как Agent приступит к сборке.
    * Установите лимит расходов, как описано в разделе [Управление расходами](/ru/billing/managing-spend), чтобы зацикливание не привело к большому счёту.
  </Accordion>

  <Accordion title="Как снизить расходы на Agent и какие настройки действительно помогают?">
    Наибольший эффект дают следующие варианты:

    * **[Free Mode](/ru/features/agent/agent-modes)** — бесплатная повседневная работа с Agent в рамках лимита вашего тарифа.
    * **[Power mode](/ru/features/agent/agent-modes)** — больше возможностей по доступной цене, когда они нужны для работы.
    * **[Plan mode](/ru/features/agent/plan-mode)** — определяйте объём работ и утверждайте их до того, как Agent приступит к выполнению, чтобы не платить за нежелательные изменения.
    * **Лимит использования и бюджет** — установите жёсткий лимит в разделе [Управление расходами](/ru/billing/managing-spend).

    Также полезно начинать новый чат с Agent при переходе к другой задаче. Проверяйте дашборд использования, чтобы узнать, какие задачи обходятся дороже всего.
  </Accordion>

  <Accordion title="Какие режимы доступны в Agent и чем они отличаются?">
    У Agent есть три основных режима, а также настройка **Auto** внутри платных режимов. Полное руководство см. в разделе [Free Mode](/ru/help/free-agent-mode).

    * **Free Mode** — бесплатная повседневная работа с Agent в пределах лимита вашего тарифа. На тарифах Core и Pro лимиты сбрасываются каждые пять часов, при этом действуют недельные ограничения. На тарифе Starter сохраняются прежние лимиты. Чтобы посмотреть своё потребление, откройте **Settings → Usage**.
    * **Auto** — автоматический выбор модели для платной работы в режимах Power или Max на тарифах Core и Pro.
    * **Power** — платный режим среднего уровня с мощными моделями по доступной цене.
    * **Max** — платный режим высшего уровня с лучшими передовыми моделями для самых требовательных задач.

    Платные режимы переименованы. **Economy теперь называется Power**, а прежний режим **Power теперь называется Max**. Текущие настройки режимов сохраняются под новыми названиями. Если для запроса требуется больше возможностей, чем даёт Free Mode, Agent может предложить платный вариант **Allow once**. Replit запрашивает подтверждение перед началом платного действия, а затем Agent возвращается в Free Mode.

    Отдельно стоит отметить, что [режим Plan](/ru/features/agent/plan-mode) позволяет Agent проработать объём задачи до внесения изменений, тогда как режим Build вносит изменения сразу. См. [Plan vs. Build mode](/ru/learn/plan-vs-build-mode).
  </Accordion>

  <Accordion title="Agent внёс нежелательные изменения — как их отменить?">
    Replit сохраняет [checkpoints](/ru/features/version-control/checkpoints-and-rollbacks) по ходу работы Agent. В чате с Agent найдите сообщение перед изменением, которое хотите отменить, и выберите рядом с ним вариант отката, чтобы вернуть проект к этому состоянию.

    Все варианты отката, включая восстановление отдельных файлов, описаны в разделе [Checkpoints и откаты](/ru/features/version-control/checkpoints-and-rollbacks).
  </Accordion>

  <Accordion title="Agent сообщает, что у него нет доступа к интернету или внешним API. Это ожидаемо?">
    На этапе сборки и редактирования Agent работает в изолированной среде с ограниченным исходящим доступом. Опубликованное приложение при этом по-прежнему может выполнять внешние вызовы API во время работы — изоляция распространяется на среду редактирования Agent, а не на запущенное приложение.

    Если вызов API в запущенном приложении завершается ошибкой, убедитесь, что ключи сохранены в панели [Secrets](/ru/core-concepts/project-editor/app-setup/secrets), а затем проверьте страницу статуса поставщика услуг. В корпоративной или школьной сети исходящие соединения из приложения могут быть заблокированы — уточните это у сетевого администратора.
  </Accordion>

  <Accordion title="Можно ли использовать собственные ключи API с Agent?">
    Да. Добавьте свои ключи в панель [Secrets](/ru/core-concepts/project-editor/app-setup/secrets), и приложение будет использовать их при вызовах API. Откройте инструмент **Secrets**, выберите **+ New secret** и введите имя (например, `OPENAI_API_KEY`) и значение.

    Вы можете [использовать собственные ключи AI-провайдеров](/ru/features/integrations/replit-ai-integrations) для моделей, к которым обращается ваше приложение. Модель, на которой работает сам Agent, выполняется в инфраструктуре Replit, и заменить её нельзя.
  </Accordion>

  <Accordion title="Agent продолжает добавлять функции, о которых я не просил. Как добиться более точного поведения?">
    Помогите Agent не отвлекаться с помощью более точных запросов:

    * Начинайте со слова *Только* — например: &quot;Только добавь кнопку удаления в карточку пользователя. Больше ничего не меняй.&quot;
    * Сначала используйте [режим Plan](/ru/features/agent/plan-mode), чтобы проверить, что Agent планирует сделать, прежде чем вносить изменения.
    * Если Agent внесёт нежелательное изменение, сразу попросите его отменить его в том же чате.

    Подробнее см. в разделе [Эффективные запросы](/ru/learn/effective-prompting).
  </Accordion>
</AccordionGroup>
