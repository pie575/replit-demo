Les URL de développement vous permettent de prévisualiser et de tester votre application pendant son développement. Ces URL suivent le format `UUID.servername.replit.dev` et offrent un aperçu en direct de votre application en cours de développement.

<Frame>
  <img src="/assets/mirror/preview-dev-url-b36770b33769.png" alt="URL de développement affichée dans la barre d’adresse" width="1222" height="824" data-path="images/workspace/preview-dev-url.png" />
</Frame>

Pour afficher une URL de développement, cliquez sur le texte `{...}.replit.dev` dans la barre d’adresse.

<div id="url">
  ## Comprendre les URL de développement
</div>

Les URL de développement ne sont actives que lorsque vous travaillez sur une application Replit. L’URL peut changer chaque fois que vous rouvrez l’application. Elles vous permettent de consulter votre travail dans le navigateur pendant la création et les tests.

Par défaut, les URL de développement sont accessibles sur le Web. Toute personne disposant de l’URL peut voir l’application en cours de création. Vous pouvez ainsi facilement partager votre travail en cours avec des collaborateurs, des testeurs et des parties prenantes.

<Warning>
  Les URL de développement sont temporaires et réservées aux tests. Pour partager votre application avec d’autres personnes, nous vous recommandons plutôt de [publier votre application](/fr/ja/learn/projects-and-artifacts/replit-deployments).
</Warning>

<div id="section">
  ### Bannière informative
</div>

Lorsque vous ouvrez l’aperçu de développement dans un nouvel onglet, une bannière informative s’affiche en haut de la page. Elle vous aide à comprendre le rôle de l’URL `.replit.dev` lors de la création et des tests de votre application. Elle explique l’URL de développement et son usage prévu dans le processus de développement.

<div id="url-2">
  ## Rendre l’URL de développement privée
</div>

Vous pouvez restreindre l’accès à votre URL de développement afin de protéger votre travail en cours.

Pour rendre une URL de développement privée :

1. Ouvrez les **outils de développement** dans l’éditeur de projet.
2. Sélectionnez l’onglet **Réseau**.
3. Activez le bouton bascule **URL de développement privée**.

Une fois activée, l’accès à l’URL de développement nécessite une authentification. Seuls vous et les membres autorisés de votre équipe peuvent consulter votre travail en cours.

<Note>
  Les clients Enterprise peuvent imposer l’utilisation d’URL de développement privées pour tous les projets. Cela renforce la sécurité en garantissant que le travail de développement reste protégé au sein de l’environnement de votre organisation.
</Note>

<div id="section-2">
  ## Bonnes pratiques
</div>

* Utilisez des **URL privées** pour les applications sensibles ou propriétaires en cours de développement.
* Utilisez des **URL publiques** si vous partagez votre travail avec des parties prenantes externes pendant le développement ou si vous souhaitez tester votre application dans un autre navigateur.
