<div id="workspaces-pessoais-vs-de-equipe">
  ## Workspaces personnels et workspaces d&#39;équipe
</div>

Un **workspace** est la structure qui contient vos apps, vos membres, vos paramètres et votre facturation. Replit en propose deux types :

* Workspace personnel
* Workspace d&#39;équipe

Voici la différence entre les workspaces personnels et les workspaces d&#39;équipe :

|                         | Workspace personnel                                  | Workspace d&#39;équipe                                |
| ----------------------- | ---------------------------------------------------- | ----------------------------------------------------- |
| **Rôles**               | Administrateur, invités au niveau du projet          | Administrateur, membres, invités au niveau du projet  |
| **Modèle d&#39;accès**  | Vous invitez des invités sur des projets individuels | Les membres ont accès à tous les projets du workspace |
| **Facturation**         | Votre compte                                         | Crédits partagés du compte de l&#39;administrateur    |
| **Gestion des membres** | Par projet (liens d&#39;accès)                       | Centralisée dans les paramètres du workspace          |

Le **workspace personnel** est idéal lorsque vous travaillez seul ou que vous partagez des projets individuels avec d&#39;autres personnes. Vous êtes le seul administrateur, et les autres personnes ne peuvent accéder qu&#39;aux projets précis auxquels vous les invitez en tant qu&#39;invités au niveau du projet.

Le **workspace d&#39;équipe** est idéal lorsque vous développez avec un groupe régulier : une équipe de startup, une classe ou un projet client réunissant plusieurs collaborateurs. Les membres ont accès à tous les projets du workspace : vous n&#39;avez donc pas besoin de les inviter un à un sur chaque projet. Les membres sont gérés de façon centralisée dans **Paramètres**.

<div id="quando-convidar-para-o-workspace-ou-para-um-projeto">
  ### Quand inviter dans le workspace ou dans un projet
</div>

| Scénario                                                          | Que faire                                               |
| ----------------------------------------------------------------- | ------------------------------------------------------- |
| Collaborateur permanent qui a besoin d&#39;accéder à tout         | Inviter dans le workspace                               |
| Prestataire ou invité qui n&#39;a besoin que d&#39;un seul projet | [Inviter dans le projet](/fr/pt/replitai/invite-teammates) |
| Nouveau membre de l&#39;équipe qui rejoint l&#39;entreprise       | Inviter dans le workspace                               |
| Ami qui aide à déboguer une app précise                           | [Inviter dans le projet](/fr/pt/replitai/invite-teammates) |

<div id="criar-um-workspace-de-equipe">
  ## Créer un workspace d&#39;équipe
</div>

<Frame>
  <video autoPlay muted loop playsInline>
    <source src="/assets/mirror/create_new_team_workspace-f665bec18450.mp4" type="video/mp4" />
  </video>
</Frame>

<Steps>
  <Step title="Ouvrir le sélecteur de workspace">
    Sur la page d&#39;accueil, cliquez sur le nom de votre workspace en haut à gauche.
  </Step>

  <Step title="Créer un nouveau workspace">
    Sélectionnez **Créer un workspace** et choisissez un nom pour votre workspace d&#39;équipe.
  </Step>

  <Step title="Inviter des membres">
    Saisissez une ou plusieurs adresses e-mail (séparées par une virgule) dans le champ d&#39;invitation. Les invités recevront une invitation et auront accès à tous les projets du workspace dès qu&#39;ils l&#39;auront acceptée.
  </Step>
</Steps>

<div id="gerenciar-membros">
  ## Gérer les membres
</div>

Si vous n&#39;avez pas invité de membres lors de la configuration ou si vous devez en ajouter plus tard, rendez-vous dans les **Paramètres** de votre workspace d&#39;équipe et invitez des membres par e-mail ou par nom d&#39;utilisateur Replit.

<Frame>
  <video autoPlay muted loop playsInline>
    <source src="/assets/mirror/add_team_to_workspace_compressed-41d8163607d2.mp4" type="video/mp4" />
  </video>
</Frame>

Sur la page **Paramètres**, vous pouvez également :

* **Retirer des membres** pour révoquer leur accès à tous les projets du workspace
* **Transférer des apps** depuis des workspaces personnels vers le workspace d&#39;équipe — voir [Transférer une app vers Teams](/fr/pt/teams/identity-and-access-management/transfer-app-to-teams)

Pour la gestion avancée des identités, le contrôle d&#39;accès basé sur les rôles et les permissions de groupe, consultez [Teams](/fr/pt/category/teams).
