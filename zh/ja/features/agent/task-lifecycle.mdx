<div id="section">
  ## 草稿
</div>

**草稿**是 Agent 已规划但尚未开始构建的任务。草稿仅包含建议的工作内容 (任务标题、说明和计划) ，因此可以放心审核。

使用草稿确认 Agent 是否正确理解了你的目标。你可以启动任务、让 Agent 修改计划，或将草稿归档以备后用。

<div id="section-2">
  ## 活跃
</div>

**活跃**任务正在后台运行。Agent 会在项目的独立副本中工作，因此任务运行期间不会更改主版本。

活跃任务运行期间，你仍可继续使用主线程。如果任务需要你的反馈，请打开相应线程并继续对话。

  ## 已排队
</div>

**已排队**任务已获批准，但尚未开始。如果任务依赖其他任务，或已达到套餐的活跃后台任务数量上限，任务可能会进入队列。

当前置条件满足且有可用的活跃任务槽位时，已排队任务会自动开始。

<div id="section-4">
  ## レディ
</div>

**レディ**任务已完成，但更改尚未应用到主版本。请在应用更改前审核任务的工作日志、测试结果和预览。

如果工作无误，请将更改应用到主版本。如果不符合预期，请拒绝该任务并开始新任务。

<div id="section-5">
  ## 正在应用
</div>

**正在应用**任务正将更改合并到主版本。Agent 会自动处理应用多个任务的更改时产生的冲突。

请等待应用完成后再评估最终结果。如有任何问题，请在主线程中让 Agent 修复。

<div id="section-6">
  ## 已完成
</div>

**已完成**任务已结束，无需进一步操作。其中包括已应用到主版本、开始前已归档，或进入构建阶段后已取消的任务。

将**已完成**列用作已完成、已归档和已取消任务的历史记录。

<div id="section-8">
  ## 归档和取消任务
</div>

您可以在任务生命周期的任何阶段停止任务，但可用选项取决于任务在看板中的位置。**归档**和**取消**都会将任务移至**完成**列，但两者的作用不同：

| 操作     | 可用时机                                    | 会发生什么                                | 可以撤销吗？                                |
| ------ | --------------------------------------- | ------------------------------------ | ------------------------------------- |
| **归档** | 任务仍处于规划会话阶段：尚未开始构建的**草稿**               | 规划会话会被搁置，不会执行。规划内容会被保留。              | 可以。您可以打开**完成**列中的已归档卡片，并将其恢复为**草稿**。  |
| **取消** | 任务从规划进入构建后：处于**活跃**、**已排队**或**就绪**状态的任务 | Agent 会停止任务并丢弃正在进行的工作。不会将任何更改应用到主版本。 | 不可以。已取消的任务无法恢复。如果您想继续进行这项工作，请创建一个新任务。 |

如果想稍后重新考虑某个规划会话，请使用**归档**。对于已排队、正在运行或已完成构建的任务，如需永久停止，请使用**取消**。

您可以在任务看板最右侧的**完成**列中查看已归档的规划会话、已取消的任务以及已完成的任务。
