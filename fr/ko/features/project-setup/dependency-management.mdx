title: "Gestion des dépendances"
description: "Découvrez comment installer et gérer les paquets et les dépendances de votre Replit App dans plusieurs langages."
---

Replit offre plusieurs façons d&#39;installer et de gérer les paquets de votre Replit App. Vous pouvez les installer depuis le [Shell](/fr/ko/features/workspace-tools/shell), confier la tâche à l&#39;[Agent](/fr/ko/features/agent/overview/), ou laisser Replit détecter et installer automatiquement les dépendances manquantes au lancement de votre Replit App.

<div id="section">
  ## Installer des paquets avec le shell
</div>

Dans l&#39;éditeur de projet, ouvrez l&#39;outil **Shell** et exécutez la commande correspondant au gestionnaire de paquets du langage que vous utilisez.

<CodeGroup>
  ```bash Node.js (npm) theme={null}
  npm install <package-name>
  ```

  ```bash Node.js (pnpm) theme={null}
  pnpm add <package-name>
  ```

  ```bash Python (poetry) theme={null}
  poetry add <package-name>
  ```

  ```bash Python (pip) theme={null}
  pip install <package-name>
  ```

  ```bash Ruby theme={null}
  bundle add <gem-name>
  ```
</CodeGroup>

Vous pouvez également utiliser l&#39;[Universal Package Manager (UPM)](https://github.com/replit/upm/) de Replit pour installer des paquets dans plusieurs langages pris en charge.

```bash theme={null}
upm add <package-name>
```

Pour installer une version spécifique, exécutez la commande suivante :

```bash theme={null}
upm add 'flask==2.3.3'
```

Pour connaître l&#39;ensemble des langages et gestionnaires de paquets pris en charge, consultez [UPM : langages pris en charge](https://github.com/replit/upm/#supported-languages).

<div id="agent">
  ## Installer des paquets avec Agent
</div>

Vous pouvez demander directement à [Agent](/fr/ko/features/agent/overview/) d&#39;installer des paquets depuis le chat. Par exemple :

* « Installe le paquet axios »
* « Ajoute Flask et SQLAlchemy à mon projet »
* « Configure TailwindCSS »

Agent installe les paquets à l&#39;aide du gestionnaire de paquets adapté à votre projet et met à jour les fichiers de configuration concernés.

<div id="section-2">
  ## Détection automatique des imports
</div>

Replit analyse automatiquement votre code à la recherche de dépendances manquantes chaque fois que vous sélectionnez **Exécuter**. Si votre code importe un paquet qui n&#39;est pas encore installé, Replit le détecte et en installe automatiquement la dernière version.

Par exemple, si vous ajoutez `import flask` à `main.py`, la prochaine fois que vous sélectionnerez **Exécuter**, la **Console** affichera un message indiquant que **Flask** est en cours d&#39;installation.

<Note>
  Vous pouvez configurer la détection automatique des imports à l&#39;aide du paramètre `packager.features.guessImports` dans le fichier [.replit](/fr/ko/features/project-setup/configuration#replit-file).
</Note>

<div id="section-3">
  ### Remplacer la détection automatique
</div>

Si un paquet incorrect est détecté ou si vous avez besoin d&#39;une version spécifique, exécutez la commande d&#39;installation appropriée dans un Shell. Par exemple :

```bash theme={null}
upm add 'flask==2.3.3'
```

Vous pouvez également exclure certains paquets ou chemins de la détection automatique dans le fichier [.replit](/fr/ko/features/project-setup/configuration#replit-file).

<div id="python">
  ## Gestionnaire de paquets Python
</div>

Lorsque vous créez une Replit App en Python, le gestionnaire de paquets par défaut est **poetry**. Autrement dit, `pip install` ne gère pas les dépendances. Utilisez plutôt `poetry add <package>` ou `upm add <package>` dans le shell.

<div id="poetry-pip">
  ### Passer de poetry à pip
</div>

Si vous souhaitez utiliser `pip`, suivez les étapes ci-dessous.

<Steps>
  <Step>
    Ouvrez un Shell et exécutez la commande suivante.

    Supprimez le fichier de verrouillage afin que l&#39;infrastructure de packaging bascule vers pip.

    ```bash theme={null}
    rm poetry.lock
    ```
  </Step>

  <Step title="Déplacer les dépendances">
    Déplacez les dépendances de la section `[tool.poetry.dependencies]` du fichier `pyproject.toml` vers `requirements.txt`. Par exemple, `flask = "^3.0.2"` devient `flask>=3.0.2,<4`.
  </Step>

  <Step title="Nettoyer pyproject.toml">
    Supprimez les sections `[tool.poetry...]` du fichier `pyproject.toml`.
  </Step>
</Steps>

Une fois ces étapes terminées, l&#39;infrastructure de packaging utilisera `pip` pour toutes les opérations suivantes, et la détection automatique des imports continuera de fonctionner comme prévu.

<div id="nix">
  ## Dépendances système avec Nix
</div>

Replit prend en charge tous les langages de programmation grâce à son intégration avec [Nix](https://nixos.org/). Si vous avez besoin de dépendances système allant au-delà des paquets de langage standard, vous pouvez les ajouter au fichier [replit.nix](/fr/ko/features/project-setup/configuration#replit-nix-file).

<div id="nix-2">
  ### Paquets Nix
</div>

Modifiez directement `replit.nix` pour ajouter des dépendances système. Vous pouvez rechercher les paquets disponibles sur [search.nixos.org](https://search.nixos.org/packages).

<div id="section-4">
  ### Modules
</div>

Les modules regroupent la prise en charge des langages de programmation, des formateurs et des gestionnaires de paquets. Ils constituent la base d&#39;une Replit App. Lorsque vous créez une Replit App à partir d&#39;un modèle ou d&#39;un dépôt GitHub, Replit installe automatiquement les modules nécessaires.

Vous pouvez personnaliser les modules et les autres paramètres Nix dans le fichier [.replit](/fr/ko/features/project-setup/configuration#replit-file).

<div id="section-5">
  ## Configuration du packager
</div>

Vous pouvez affiner le comportement de la gestion des paquets dans le fichier [.replit](/fr/ko/features/project-setup/configuration#replit-file).

| Paramètre                             | Description                                                                 | Valeur par défaut     |
| ------------------------------------- | --------------------------------------------------------------------------- | --------------------- |
| `packager.language`                   | Langage utilisé pour les opérations sur les paquets                         | Détection automatique |
| `packager.features.guessImports`      | Détecte et installe automatiquement les paquets manquants à l&#39;exécution | `true`                |
| `packager.features.packageSearch`     | Active la prise en charge de la recherche de paquets                        | `true`                |
| `packager.features.enabledForHosting` | Exige l&#39;installation des paquets lors de l&#39;hébergement              | `false`               |
| `packager.afterInstall`               | Commande à exécuter après l&#39;installation des paquets                    | —                     |
| `packager.ignoredPaths`               | Chemins à exclure de la détection des imports                               | `[]`                  |
| `packager.ignoredPackages`            | Paquets à exclure de la détection automatique                               | `[]`                  |
