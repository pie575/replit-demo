[项目安全中心](/zh/pt/core-concepts/security/project-security-center)和 [workspace 安全中心](/zh/pt/core-concepts/security/workspace-security-center)中所用安全术语的定义。

<div id="cve">
  ## CVE
</div>

通用漏洞披露 (Common Vulnerabilities and Exposures) 。CVE 是为公开披露的软件漏洞分配的唯一标识符，例如 `CVE-2024-12345`。

<div id="severidade">
  ## 严重性
</div>

漏洞的风险等级：严重、高、中或低。请结合严重性和暴露面，判断优先修复哪些项目。

<div id="dependncia">
  ## 依赖项
</div>

项目所依赖的第三方软件包。依赖项中的漏洞会影响所有使用该依赖项的项目，直到其升级或被替换为止。

<div id="sbom">
  ## SBOM
</div>

软件物料清单 (Software Bill of Materials) 。SBOM 是一份机器可读的清单，列出项目中使用的软件包、版本和许可证。

<div id="spdx-e-cyclonedx">
  ## SPDX 和 CycloneDX
</div>

安全与合规工具通用的标准 SBOM 格式。请根据你所使用的审计、合规或软件成分分析工具，选择其所需的格式。

<div id="exposio">
  ## 暴露面
</div>

由发布状态和可见性所形成的风险面。公开且已发布的项目，其暴露面大于私有或未发布的项目。

<div id="corrigir-com-agent">
  ## 使用 Agent 修复
</div>

该操作会以后台任务的方式请求 Replit Agent 为受影响的项目生成补丁。应用前请先检查生成的更改。

<div id="republicar">
  ## 重新发布
</div>

使用现有的部署配置重新部署项目。应用修复后，使用**重新发布**来上线修补后的版本。

<div id="auto-protect">
  ## Auto-Protect
</div>

面向管理员的可选模式，持续监测新披露的 CVE 是否影响项目的依赖项。一旦发现匹配项，Replit Agent 会准备补丁并通知项目所有者。
