Les modes Agent vous permettent de choisir, avant d’envoyer une demande, le compromis entre les limites d’utilisation incluses, les crédits et les capacités. Ouvrez le menu déroulant des paramètres Agent dans la zone de saisie, puis sélectionnez le mode adapté à votre tâche.

<Note>
  Le mode Économie n’est plus disponible. Le Power Mode le remplace au même prix.
</Note>

<div id="section">
  ## Choisir un mode
</div>

* **Mode gratuit :** explorez vos idées, posez des questions, commencez à créer et continuez à avancer sans interrompre votre travail quotidien. Le mode gratuit sélectionne les modèles grâce à un routage intelligent. {FreeModePlanAvailability}
* **Power Mode :** un bon équilibre entre rapidité et capacités, adapté à la plupart des tâches. Utilisez-le lorsque vous avez besoin de capacités supérieures à celles du mode gratuit ou de paramètres par défaut plus puissants dans un projet existant.
* **Max Mode :** l’option la mieux adaptée aux tâches complexes et ambitieuses, aux grandes bases de code et aux problèmes difficiles.

Les Power Mode et Max Mode utilisent des crédits mensuels. Replit vous avertit avant qu’une requête ne passe du mode gratuit à un mode payant. Vous pouvez consulter votre limite restante en mode gratuit dans **Paramètres** → **Utilisation**. Pour des conseils pratiques, consultez [Tirer le meilleur parti du mode gratuit](/fr/ja/chat/free-mode).

Les routines s’exécutent en Power Mode ou Max Mode et nécessitent un budget par exécution. Elles ne peuvent pas être exécutées en mode gratuit. Pour en savoir plus, consultez [Routines](/fr/ja/chat/routines).
