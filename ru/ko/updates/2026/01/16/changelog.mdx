export const YouTubeEmbed = ({videoId, title = "Видео на YouTube", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

  ### Мобильные приложения в Replit
</div>

<YouTubeEmbed videoId="YSeDWL4cDLs" title="Мобильные приложения в Replit" />

Создавайте нативные приложения для iOS с помощью простого промпта. Agent соберёт полноценное приложение на React Native, а по ходу работы вы сможете добавить базу данных, платежи через Stripe или интеграцию с OpenAI. Отсканируйте QR-код в Expo Go, чтобы посмотреть приложение, и отправьте его в App Store с помощью пошагового процесса Replit. Apple проверит приложение и опубликует его в App Store.

Готовы создать своё первое мобильное приложение? Загляните в раздел [Нативные мобильные приложения](/ru/ko/features/artifact-types/building-mobile-apps) или пройдите руководство [Создание и запуск мобильного приложения](/ru/tutorials/build-and-launch-a-mobile-app).

<div id="agent-ui">
  ### Переработанный интерфейс вызова инструментов в чате Agent
</div>

В чате Agent теперь используется более аккуратный и компактный интерфейс вызова инструментов. Вызовы инструментов сворачиваются в сгруппированные строки со стопками значков, поэтому происходящее легко охватить одним взглядом. Правка и создание файлов ведут напрямую к панели diff — так изменения удобнее просматривать. Упрощённый дизайн помогает следить за работой Agent: меньше лишнего шума и больше ясности.
