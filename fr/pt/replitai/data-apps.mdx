<div id="o-que-uma-visualizao-de-dados">
  ## Qu&#39;est-ce qu&#39;une visualisation de données ?
</div>

Une visualisation de données est un tableau de bord interactif ou un outil de reporting que vous créez au fil de vos conversations avec l&#39;Agent. Décrivez ce que vous souhaitez visualiser et où se trouvent vos données : l&#39;Agent sélectionne automatiquement les KPI, les types de graphiques et les mises en page adaptés, et génère un tableau de bord complet à partir d&#39;un seul prompt.

Concepts clés :

* **Génération en une seule fois** : décrivez votre objectif et votre source de données, et l&#39;Agent crée un tableau de bord complet avec les graphiques et les métriques appropriés
* **Sources de données connectées** : accédez à des bases de données, à des [connecteurs de warehouse](/fr/pt/connectors/warehouses/overview), à des API externes ou à des fichiers importés
* **Fonctionnalités intégrées** : chaque tableau de bord inclut l&#39;actualisation, l&#39;actualisation automatique, l&#39;export en PDF, l&#39;export des graphiques en CSV et le mode clair/sombre
* **Résumé d&#39;analyse** : l&#39;Agent génère des insights à partir de votre demande et des données obtenues
* **Plusieurs artefacts** : les visualisations de données peuvent partager le même backend et la même base de données que vos autres artefacts au sein du [même projet](/fr/pt/replitai/artifacts#multiple-artifacts-in-one-project)

<div id="como-usar-a-visualizao-de-dados">
  ## Comment utiliser la visualisation de données
</div>

<div id="criando-a-partir-de-um-prompt">
  ### Créer à partir d&#39;un prompt
</div>

Sélectionnez l&#39;onglet **App** sur la page d&#39;accueil et décrivez le tableau de bord souhaité. Agent détecte les prompts liés aux données et sélectionne la pile Visualisation de données.

**Exemples de prompts :**

* « Crée un tableau de bord d&#39;analyse des ventes qui suit le chiffre d&#39;affaires par région »
* « Crée un outil de reporting qui met en visuel nos indicateurs mensuels »
* « Crée un tableau de bord à partir de nos données de ventes dans BigQuery, en affichant les produits les plus performants »
* « Connecte-toi à Snowflake et crée un tableau de bord d&#39;analyse de l&#39;attrition client »

<div id="criando-a-partir-do-menu-suspenso">
  ### Création depuis le menu déroulant
</div>

1. Accédez à l&#39;onglet **App** sur la page d&#39;accueil.
2. Ouvrez le menu déroulant des types d&#39;application.
3. Sélectionnez **Visualisation de données**.
4. Décrivez le tableau de bord ou l&#39;outil de données que vous souhaitez créer.

<div id="conectando-a-data-warehouses">
  ### Connexion aux data warehouses
</div>

Connectez votre visualisation de données à BigQuery, Databricks ou Snowflake via les [connecteurs de données](/fr/pt/connectors/warehouses/overview) afin de créer des tableaux de bord à partir de vos jeux de données existants.

Lorsqu&#39;il interroge les données d&#39;un warehouse, Agent utilise une recherche multi-agents parallèle pour explorer votre schéma et vos jeux de données. L&#39;exploration est ainsi plus rapide et Agent sélectionne plus facilement les tables et les champs adaptés à votre tableau de bord.

Pour commencer, configurez un connecteur de warehouse dans les [intégrations](/fr/replitai/integrations) de votre projet, puis indiquez à Agent ce que vous souhaitez visualiser.

<div id="adicionando-filtros-e-recursos">
  ### Ajouter des filtres et des fonctionnalités
</div>

Une fois qu&#39;Agent a créé votre tableau de bord, vous pouvez lui demander d&#39;ajouter des filtres, des vues détaillées ou d&#39;autres fonctionnalités interactives. Par exemple, demandez à Agent d&#39;ajouter un filtre par plage de dates, un sélecteur de région ou une barre de recherche.

<div id="exportando-e-compartilhando">
  ### Exportation et partage
</div>

* **Exporter en PDF** : exportez l&#39;intégralité de votre tableau de bord au format PDF pour le partager ou le consulter hors ligne.
* **Exporter les graphiques en CSV** : téléchargez les données de chaque graphique sous forme de fichiers CSV pour les analyser ensuite dans un tableur ou d&#39;autres outils.
* **Document d&#39;analyse** : demandez à Agent de produire un document d&#39;analyse détaillé à partir des données de votre tableau de bord.

<div id="o-que-voc-pode-criar">
  ## Ce que vous pouvez créer
</div>

* **Tableaux de bord analytiques** : suivez des indicateurs clés comme le chiffre d&#39;affaires, les inscriptions ou l&#39;engagement au fil du temps
* **Outils de reporting** : créez des rapports internes que les parties prenantes peuvent filtrer et explorer sans accès direct à la base de données
* **Interfaces d&#39;exploration de données** : parcourez et interrogez vos jeux de données avec un retour visuel
* **Tableaux de supervision** : affichez des données en temps réel ou quasi réel provenant d&#39;API, de bases de données ou de services externes

<div id="perguntas-frequentes">
  ## Questions fréquentes
</div>

<Accordion title="À quelles sources de données puis-je me connecter ?">
  Vous pouvez extraire des données de la base de données Replit de votre projet, de connecteurs de warehouse (BigQuery, Databricks, Snowflake), d&#39;API externes ou de fichiers CSV importés. Configurez les connexions aux entrepôts de données via les [Intégrations](/fr/replitai/integrations).
</Accordion>

<Accordion title="Puis-je personnaliser l'apparence ?">
  Oui. Vous pouvez personnaliser les couleurs, les mises en page et la typographie en conversant avec Agent : demandez-lui de les adapter à votre marque ou d&#39;ajuster le design. Les tableaux de bord prennent également en charge les modes clair et sombre.
</Accordion>

<Accordion title="Agent analyse-t-il les données pour moi ?">
  Après avoir créé un tableau de bord, Agent génère un résumé d&#39;analyse à partir de votre demande et des données obtenues. Vous pouvez également demander un document d&#39;analyse plus détaillé.
</Accordion>

<Accordion title="Puis-je combiner une visualisation de données avec d'autres types d'artefacts ?">
  Oui. Vous pouvez combiner une visualisation de données avec une [application web](/fr/pt/replitai/web-apps), une [présentation de diapositives](/fr/pt/replitai/slide-decks) ou d&#39;autres types d&#39;artefacts dans le [même projet](/fr/pt/replitai/artifacts#multiple-artifacts-in-one-project). Ils partagent le même backend et la même base de données.
</Accordion>
