Permettre à vos utilisateurs de se connecter à votre site web avec leur compte Google présente plusieurs avantages :

1. Vous n&#39;avez pas à implémenter votre propre système d&#39;authentification.
2. Vous récupérez facilement le nom et les coordonnées de l&#39;utilisateur.
3. Vous pouvez utiliser les mêmes informations d&#39;identification pour accéder aux ressources Google de l&#39;utilisateur, comme Sheets ou Drive.

Ce guide vous explique comment procéder avec Python et Flask sur Replit.

Nous commencerons par mettre en place une authentification OAuth de base, puis nous verrons comment utiliser les informations d&#39;identification obtenues pour accéder aux ressources Google de l&#39;utilisateur.

<div id="oauth">
  ## Présentation d&#39;OAuth
</div>

L&#39;authentification Google repose sur le standard OAuth, dont voici le fonctionnement :

1. Quelque part sur votre site web, vous dirigez l&#39;utilisateur vers une page de connexion.
2. Lorsque l&#39;utilisateur accède à cette page, plutôt que d&#39;implémenter un formulaire de connexion sur votre site web, vous le redirigez vers le service de connexion de Google pour qu&#39;il s&#39;y authentifie.
3. Une fois l&#39;utilisateur authentifié, le service de connexion de Google le redirige vers votre site web, à l&#39;URL que vous avez définie (par exemple : `https://YOUR_DOMAIN/oauth2callback`), en transmettant des informations sur l&#39;utilisateur et sa session de connexion.
4. À partir de ces informations de connexion, vous obtenez un jeton d&#39;accès : c&#39;est le laissez-passer qui donne accès à des ressources telles que les informations de profil de l&#39;utilisateur, ses feuilles de calcul, ses documents, etc.

<div id="oauth-2">
  ## OAuth : montrez-moi le code
</div>

Si, comme moi, vous préférez commencer par du code qui fonctionne, le voici. Cela dit, pour que tout fonctionne correctement, quelques réglages sont nécessaires dans la Google Cloud Console ; nous les verrons dans la section suivante. Créez une nouvelle Replit App à partir du [modèle Flask](https://replit.com/@replit/Flask?v=1), puis saisissez ce qui suit dans `main.py`. Les commentaires du code expliquent le rôle de chaque partie :

```python theme={null}
from flask import Flask, redirect, session, url_for, request
import google_auth_oauthlib.flow
import json
import os
import requests

app = Flask('app')
# `FLASK_SECRET_KEY` est utilisée par les sessions. Créez une chaîne aléatoire
# et stockez-la sous forme de secret.
app.secret_key = os.environ.get('FLASK_SECRET_KEY') or os.urandom(24)

# `GOOGLE_APIS_OAUTH_SECRET` contient le contenu d'un fichier JSON à télécharger
# depuis le panneau Credentials de Google Cloud. Voir la section suivante.
oauth_config = json.loads(os.environ['GOOGLE_OAUTH_SECRETS'])

# Configure le flux OAuth
oauth_flow = google_auth_oauthlib.flow.Flow.from_client_config(
    oauth_config,
    # les scopes définissent les API auxquelles vous souhaitez accéder au nom de l'utilisateur une fois authentifié
    scopes=[
        "https://www.googleapis.com/auth/userinfo.email",
        "openid",
        "https://www.googleapis.com/auth/userinfo.profile",
    ]
)

# Voici l'entrypoint de la page de login. Il redirige vers le service de login Google situé à
# l'`authorization_url`. Le `redirect_uri` est en fait l'URI que le service de login Google utilisera pour
# rediriger vers cette app.
@app.route('/signin')
def signin():
    # Nous réécrivons l'URL de http en https car, au sein de la Replit App, http est utilisé,
    # alors que l'accès externe se fait via https, et le redirect_uri doit y correspondre
    oauth_flow.redirect_uri = url_for('oauth2callback', _external=True).replace('http://', 'https://')
    authorization_url, state = oauth_flow.authorization_url()
    session['state'] = state
    return redirect(authorization_url)

# Voici l'endpoint vers lequel le service de login Google redirige. Il doit être ajouté aux « Authorized redirect URIs »
# dans le panneau des identifiants d'API de Google Cloud. Il appelle un endpoint Google pour demander
# un jeton d'accès et le stocker dans la session utilisateur. Ce jeton d'accès permet ensuite d'accéder
# aux API au nom de l'utilisateur.
@app.route('/oauth2callback')
def oauth2callback():
    if not session['state'] == request.args['state']:
        return 'Invalid state parameter', 400
    oauth_flow.fetch_token(authorization_response=request.url.replace('http:', 'https:'))
    session['access_token'] = oauth_flow.credentials.token
    return redirect("/")

# Voici la page d'accueil de l'app. Elle invite l'utilisateur à se connecter s'il ne l'est pas déjà.
# Elle affiche ses informations s'il l'est déjà.
@app.route('/')
def welcome():
    if "access_token" in session:
        user_info = get_user_info(session["access_token"])
        if user_info:
            return f"""
                Hello {user_info["given_name"]}!<br>
                Your email address is {user_info["email"]}<br>
                <a href="/logout">Log out</a>
            """
    return """
        <h1>Hello!</h1>
        <a href="/signin">Sign In via Google</a><br>
    """

# Appeler l'API userinfo pour obtenir les informations de l'utilisateur avec un jeton d'accès valide.
# C'est le premier exemple d'utilisation du jeton d'accès pour accéder à une API au nom de l'utilisateur.
def get_user_info(access_token):
    response = requests.get("https://www.googleapis.com/oauth2/v3/userinfo", headers={
       "Authorization": f"Bearer {access_token}"
   })
    if response.status_code == 200:
        user_info = response.json()
        return user_info
    else:
        print(f"Failed to fetch user info: {response.status_code} {response.text}")
        return None

@app.route('/logout')
def logout():
    session.clear()
    return redirect('/')

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000)

```

<div id="google-sheets">
  ## Intégration Google Sheets : montrez-moi le code
</div>

Tout d&#39;abord, dans la section du flux OAuth du code d&#39;origine, tout reste identique, hormis l&#39;ajout de `"https://www.googleapis.com/auth/spreadsheets.readonly"` à la liste des portées :

```python theme={null}
# Ceci met en place la configuration du flux OAuth
oauth_flow = google_auth_oauthlib.flow.Flow.from_client_config(
    oauth_config,
    # les scopes définissent les API auxquelles vous souhaitez accéder au nom de l'utilisateur une fois celui-ci authentifié
    scopes=[
        "https://www.googleapis.com/auth/userinfo.email",
        "openid",
        "https://www.googleapis.com/auth/userinfo.profile",
        "https://www.googleapis.com/auth/spreadsheets.readonly"
    ]
)
```

Pour accéder aux API Google avec la bibliothèque `googleapiclient.discovery`, créez d&#39;abord un objet `Credentials` à partir du jeton d&#39;accès, puis utilisez la fonction `build` pour créer un objet API appelable. Pour l&#39;API Sheets, cela donne ceci :

```python theme={null}
credentials = google.oauth2.credentials.Credentials(token=session['access_token'])
service = build("sheets", "v4", credentials=credentials)
sheets_api = service.spreadsheets()
```

Pour l&#39;utilisation concrète de l&#39;API Sheets, nous avons créé quelques fonctions utilitaires :

```python theme={null}
# récupère tous les onglets d'une feuille de calcul Google
def get_sheets(sheets_api, spreadsheet_id) -> list[str]:
    result = sheets_api.get(spreadsheetId=spreadsheet_id).execute()
    return [sheet["properties"]["title"] for sheet in result["sheets"]]

# récupère les données d'un onglet donné d'une feuille de calcul Google
def get_sheet_data(sheets_api, spreadsheet_id, sheet_title) -> list[list[str]]:
    result = (
        sheets_api.values()
        .get(spreadsheetId=spreadsheet_id, range=sheet_title)
        .execute()
    )
    return result["values"]
```

À l&#39;aide des fonctions utilitaires ci-dessus, vous pouvez créer un endpoint de gestionnaire permettant d&#39;importer une feuille de calcul Google Sheets, comme suit :

```python theme={null}
@app.route("/import_spreadsheet", methods = ['POST'])
```
