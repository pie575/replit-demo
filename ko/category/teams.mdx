조직에 맞는 plan을 선택하세요. **Pro**는 팀을 위한 plan으로, 최대 15명의 builder가 pooled credits를 함께 사용하며 사용자당 요금이 없습니다. **Enterprise**는 규모가 큰 조직을 위해 고급 보안과 규정 준수, 지원을 추가로 제공합니다. Teams organization을 여러 개 보유하고 있다면 각 workspace는 남은 약정 기간 동안 개별 Pro 구독으로 migration되며, migration 후에 하나로 통합할 수 있습니다.

<div id="pro">
  ## Pro
</div>

Pro는 본격적으로 개발하는 builder와 팀을 위해 공유 리소스와 협업 기능을 제공합니다:

* **최대 15명의 builder**: 좌석당 요금 없이 모든 구성원이 하나의 plan에서 pooled credits를 함께 사용합니다
* **등급별 credits**: 여러 등급이 제공되며, 사용하지 않은 credits는 {ProCreditRolloverPeriod} 동안 이월됩니다. 현재 등급은 [pricing page](https://replit.com/pricing)에서 확인하세요
* **병렬 Agent task**: 최대 10개의 Agent task를 동시에 실행할 수 있습니다
* **Private Deployments**: 접근을 제어할 수 있는 안전한 앱 호스팅
* **Viewer 좌석**: 이해관계자나 builder가 아닌 사용자도 게시된 비공개 앱을 사용할 수 있습니다
* **통합 Settings**: 앱을 정리하고 workspace별 usage를 추적하며 billing과 사용자를 한곳에서 관리합니다

<div id="enterprise">
  ## Enterprise
</div>

Enterprise는 모든 Pro 기능에 더해 조직을 위한 강화된 보안, 제어, 지원을 제공합니다:

<CardGroup cols={2}>
  <Card title="Enterprise 보안" icon="shield-check">
    SSO/SAML, SCIM provisioning, 고급 보안 제어를 갖춘 SOC-2 준수 플랫폼입니다.
  </Card>

  <Card title="중앙 집중식 관리" icon="folder-open">
    중앙 dashboard에서 팀, billing, 리소스를 관리하세요. usage를 모니터링하고 비용을 효과적으로 제어할 수 있습니다.
  </Card>
</CardGroup>

* **SCIM provisioning을 포함한 SSO/SAML**: 싱글 사인온과 자동화된 사용자 provisioning으로 팀 접근 권한을 안전하게 관리
* **전용 개발 환경**: IDP groups 기반의 역할별 access 제어로 granular한 permissions 설정
* **Admin 제어**: Private Deployments 사용을 필수화하고 publishing 전 정적 security scan을 의무화
* **Workspace Security Center**: dependencies 전반의 CVE를 severity별로 탐지합니다. 영향을 받는 apps를 확인하고 규정 준수를 위해 SBOM을 download하세요.
* **맞춤형 Integration Permissions**: 조직 전반에서 자사 integrations의 접근 범위를 정의
* **더 큰 Deployment VM**: 확장 가능한 앱 호스팅을 위한 대용량 VM 크기 이용
* **전담 지원**: 플랫폼 지원을 위한 전담 account manager와 세일즈 엔지니어 지원
* **Enterprise Data Connectors**: Snowflake, BigQuery, Databricks에 연결해 매끄러운 데이터 integration 구현
* **무제한 Viewer 좌석**: 이해관계자와 builder가 아닌 구성원에게도 게시된 비공개 apps에 대한 무제한 접근 제공

<div id="use-cases">
  ## 활용 사례
</div>

Pro와 Enterprise는 규모에 상관없이 다양한 조직의 요구사항을 지원합니다:

* **Enterprise 애플리케이션**: 엔터프라이즈급 보안과 확장성을 갖춘 미션 크리티컬 애플리케이션을 구축하고 게시하세요
* **비즈니스 도구**: 매끄러운 접근 권한 관리와 함께 비즈니스 도구를 개발하고 유지 관리하세요
* **신속한 프로토타이핑**: 즉시 사용 가능한 개발 환경으로 혁신에 속도를 더하세요
