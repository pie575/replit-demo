该功能通过获取网络上的最新信息，突破了知识截止时间的限制。当你请求 Agent 创建需要最新信息的内容时，它会搜索网络并获取详细内容，让你的应用更准确、更实用。

网页搜索可帮助你找到最新的软件包、工具和信息，确保你的应用遵循当下的最佳实践，更加准确可靠。

<div id="section">
  ## 功能
</div>

借助 Agent 的网页搜索，你可以基于最新信息构建应用，省去手动调研和收集数据的麻烦。无论是创建金融数据控制台，还是搭建展示近期初创公司发布动态的网站，网页搜索都能确保应用内容贴合实际。

Agent 可执行的网页搜索操作：

* **搜索**：查找最新资讯、最新文档以及互联网上的实时数据
* **获取内容**：从特定网站或 URL 获取详细信息
* **来源引用**：准确查看 Agent 获取信息的出处，便于验证和参考信息来源

<div id="section-2">
  ## 使用方法
</div>

网页搜索已内置于 Agent 中——无需开启任何设置。只要描述你想构建的内容，Agent 就会自动判断何时需要联网搜索最新信息。在提示词中加入“搜索”“查一下”“使用网页搜索”等关键词，即可明确要求 Agent 执行搜索。

<div id="section-3">
  ### 网页搜索如何增强应用
</div>

网页搜索可让应用从使用占位数据转变为整合真实、准确的信息：

| 优势      | 说明                      |
| ------- | ----------------------- |
| 最新技术    | 应用可使用训练数据中未包含的最新信息和软件包  |
| 选择合适的工具 | Agent 会研究各种选项并选择最合适的软件包 |
| 当前最佳实践  | 可获取最新的开发模式和安全实践         |
| 突破限制    | 突破知识截止日期的限制，使用训练后发布的软件包 |
| 准确数据    | 应用会显示当前信息，而非过时的示例       |
| 专业成果    | 引用真实企业的应用更具可信度          |
| 节省时间    | 无需手动研究软件包和收集数据          |

<div id="section-4">
  ### 来源引用
</div>

当 Agent 使用网页搜索时，会提供**来源引用**，准确标明信息的出处。你可以利用这些引用来：

* **验证信息**：确认来源的可靠性与准确性
* **深入了解**：访问原始来源，获取更多上下文
* **引用来源**：在应用中加入恰当的出处标注
* **追踪调研过程**：了解哪些信息影响了 Agent 的工作

<div id="section-5">
  ### 内容获取
</div>

Agent 可以从指定网站抓取详细内容，为项目收集全面的信息。这让 Agent 能够：

* 通读整个网页并提取相关细节
* 处理文档和参考资料
* 从权威来源收集特定数据点
* 将结构化信息整合到应用中
