---
title: "配置 X (Twitter) OAuth"
description: "将 X（原 Twitter）配置为应用身份验证的社交登录提供方"
---

本指南将逐步介绍如何在 X 开发者门户中创建 X OAuth 应用。你需要获取 **Client ID** 和 **Client Secret**，并将其填入 **Auth 面板**。

<Note>
  本页仅涵盖 X 开发者门户中身份提供方一侧的配置。关于 Clerk Auth 的整体流程——包括启用 X 以及在 **Auth 面板** 中填写凭据——请参阅 Clerk Auth 文档中的[为 SSO 身份提供方配置 OAuth 凭据](/zh/pt/core-concepts/project-editor/auth-and-security/clerk-auth#configuring-oauth-credentials-for-an-sso-provider)。
</Note>

<div id="pr-requisitos">
  ## 前提条件
</div>

* 一个 [X 开发者账户](https://developer.twitter.com/) (提供免费层级)
* 一个[已发布的 Replit 应用](/zh/category/replit-deployments) —— 自定义 OAuth 凭据仅在**生产**环境中可用
* 打开 **X** 身份提供方的编辑面板：**Auth 面板** → **Configure** 选项卡 → **SSO providers** 部分 → 选择 **Production** 环境 → 点击 **X** 旁边的 **Edit**

<div id="passo-1-configurar-o-app-de-desenvolvedor-do-x">
  ## 第 1 步：配置 X 开发者 App
</div>

<div id="criar-uma-conta-de-desenvolvedor-se-necessrio">
  ### 创建开发者账户 (如有需要)
</div>

1. 访问 [X 开发者门户](https://developer.twitter.com/en/portal/dashboard)
2. 如果尚未拥有开发者账户，请申请一个
3. 描述您的使用场景，完成申请

<div id="criar-ou-selecionar-um-app">
  ### 创建或选择应用
</div>

1. 在 X 开发者门户中，前往 **Projects &amp; Apps**
2. 使用现有应用，或选择 **Add App**
3. 输入应用名称，然后选择 **Next**
4. 选择 **App settings**

<div id="passo-2-configurar-a-autenticao">
  ## 第 2 步：配置身份验证
</div>

1. 向下滚动到 **User authentication settings**
2. 选择 **Set up**

**App permissions：**

选择所需的最低权限级别：

* **Read** — 读取用户资料所必需 (最低要求)
* **Write** — 代表用户发布内容 (可选)
* **Direct Messages** — 访问私信 (可选)

<Warning>
  权限必须与请求的作用域一致。如果你的应用请求了 `tweet.write`，却只启用了 Read，身份验证将会失败。
</Warning>

**Type of app：**

选择 **Web App, Automated App or Bot**

**App info：**

* **Callback URI / Redirect URL**：复制 **Auth 面板**中 **身份提供方设置** 下显示的值
* **Website URL**：复制 **Auth 面板**中 **身份提供方设置** 下显示的值

有关如何查找这些值，请参阅[为 SSO 身份提供方配置 OAuth 凭据](/zh/pt/core-concepts/project-editor/auth-and-security/clerk-auth#configuring-oauth-credentials-for-an-sso-provider)。

3. 选择 **Save**
4. **保存你的 Client ID 和 Client Secret**

<Warning>
  请将 Client Secret 妥善保存在安全位置。一旦丢失，重新生成会使原有的失效。
</Warning>

<div id="soluo-de-problemas">
  ## 故障排除
</div>

<div id="incompatibilidade-de-uri-de-redirecionamento">
  ### 重定向 URI 不匹配
</div>

* 确保 Callback URI 与 **Auth 面板**中 **身份提供方设置** 显示的值完全一致
* 检查是否有拼写错误或协议错误
* 不要使用末尾斜杠

<div id="cliente-invlido">
  ### 无效客户端
</div>

* 再次检查 Client ID 和 Client Secret
* 确保没有多余空格
* 确认您使用的是 OAuth 2.0 凭据 (而非 OAuth 1.0a)

<div id="erros-de-escopopermisso">
  ### 作用域/权限错误
</div>

* 确认作用域与 X 开发者门户中启用的权限一致
* 确保至少启用了 Read 权限

<div id="app-em-modo-de-desenvolvimento">
  ### App 处于开发模式
</div>

* X 的 App 以开发模式启动，用户数量受限
* 若要用于生产环境，可能需要申请更高级别的访问权限

<div id="no-est-funcionando-no-domnio-personalizado">
  ### 自定义域名无法正常使用
</div>

* 在 **Auth 面板**的 **身份提供方设置**中，将 Website URL 和 Callback URI 更新为显示的自定义域名值
