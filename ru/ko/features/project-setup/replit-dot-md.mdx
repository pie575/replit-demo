<div id="replitmd">
  ## Как работает `replit.md`
</div>

Сначала Agent создаёт файл `replit.md` в корневом каталоге проекта на основе проверенных лучших практик. Этот файл содержит:

* Основную информацию о проекте
* Рекомендуемые подходы к написанию кода
* Предпочтения, характерные для данного типа проекта

<YouTubeEmbed videoId="kYv525W-vaU" title="Настройка ответов Replit Agent" />

При обработке запроса Agent автоматически читает файл `replit.md` и использует его содержимое, чтобы:

* Понять архитектуру и соглашения, принятые в проекте
* Следовать предпочтительным подходам и стилю написания кода
* Использовать указанные менеджер пакетов и зависимости

По мере того как Agent узнаёт больше о проекте и вносит изменения в приложение, он также может обновлять файл `replit.md`.

<Note>
  Вы можете настроить поведение Agent, отредактировав файл `replit.md`.
</Note>

<div id="replitmd-2">
  ## Настройка `replit.md`
</div>

<div id="section">
  ### Автоматическое создание
</div>

При создании нового проекта с помощью Agent файл `replit.md` создаётся автоматически на основе проверенных лучших практик. Этот файл находится в корневом каталоге проекта и содержит:

* базовые сведения о проекте
* рекомендуемые подходы к написанию кода
* предпочтения, типичные для проектов данного типа

<div id="section-2">
  ### Создание вручную
</div>

Файл можно создать и самостоятельно: добавьте в корневой каталог проекта новый файл с именем `replit.md`. Agent автоматически обнаружит его и будет использовать в последующих диалогах.

<Note>
  Чтобы `replit.md` работал корректно, он должен находиться в корневом каталоге проекта.
</Note>

<div id="replitmd-3">
  ### Повторное создание `replit.md`
</div>

Если файл `replit.md` повреждён или вы хотите начать с чистого листа:

1. Удалите существующий файл `replit.md` из корня проекта
2. Начните новый диалог с Agent
3. Agent автоматически создаст новый файл `replit.md` на основе текущего проекта

Формулируйте инструкции ясно и конкретно, чтобы Agent точно понимал, что именно вам нужно.

```markdown theme={null}

- Look up recent performance optimization techniques for our tech stack
```

<div id="section-14">
  ## Ограничения
</div>

<div id="section-15">
  ### Ограничения на размер файла и содержимое
</div>

Для `replit.md` нет строгого ограничения на количество символов, однако очень большие файлы могут обрабатываться не полностью. Для достижения наилучших результатов делайте `replit.md` кратким и содержательным.

<div id="section-16">
  ### Требования к корневому каталогу
</div>

`replit.md` должен находиться в корневом каталоге проекта. Agent не обнаруживает автоматически файлы, расположенные в подкаталогах.

<div id="section-17">
  ### Область действия контекста
</div>

`replit.md` предоставляет контекст для диалогов с Agent, но не применяется автоматически к другим ИИ-инструментам.

<div id="section-18">
  ## Следующие шаги
</div>

Готовы настроить Agent для своего проекта?

1. **Начните с простого**: создайте базовый `replit.md` с ключевыми предпочтениями
2. **Улучшайте итеративно**: обновляйте `replit.md` по мере работы с Agent
3. **Используйте удачные шаблоны**: применяйте успешные конфигурации `replit.md` в похожих проектах
4. **Отслеживайте эффективность**: проверяйте, насколько хорошо Agent следует инструкциям, и при необходимости корректируйте их

Узнайте больше о [работе с Agent](/ru/ko/features/agent/overview) или ознакомьтесь с другими [инструментами ИИ](/ru/ko/welcome).

**Enterprise**: предварительно настроив `replit.md` в [пользовательских шаблонах](/ru/ko/teams/custom-templates), вы обеспечите всем разработчикам в организации единый начальный контекст. Инструкции по дизайну см. в разделе [Настройка дизайн-системы](/ru/ko/teams/custom-design-system).
