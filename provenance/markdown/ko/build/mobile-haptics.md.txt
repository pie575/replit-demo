# 햅틱 추가하기

> PixelGames의 D-pad와 버튼에 햅틱 피드백을 추가해보세요.

export const AiPrompt = ({children}) => {
  return <CodeBlock className="relative block max-w-full overflow-x-hidden font-sans !whitespace-pre-wrap !break-words" style={{
    overflowWrap: "anywhere",
    wordBreak: "break-word"
  }}>
      <div className="pr-7" style={{
    whiteSpace: "pre-wrap",
    overflowWrap: "anywhere",
    wordBreak: "break-word"
  }}>
        {children}
      </div>
    </CodeBlock>;
};

export const hapticsPrompt = "Add haptic feedback when pressing the D-pad and action buttons: a light pulse for the D-pad, a slightly heavier one for line clears in Blocks.";

햅틱이란 무언가를 탭했을 때 폰이 되돌려주는 작은 진동입니다. 버튼을 눌렀을 때의 작은 진동음과
같습니다.

<AiPrompt>
  {hapticsPrompt}
</AiPrompt>

**iOS:** 라이트, 미디엄, 헤비 임팩트와 함께 성공 및 경고 알림 피드백을 포함해 여러 가지 구별되는
피드백 스타일을 지원합니다.

**Android:** 지원하는 진동 패턴의 종류가 더 적습니다. Agent는 iOS와 완전히 동일하지는 않더라도
의도가 전달되도록 가장 가까운 것을 선택합니다.

## 문제 해결

* **실제 기기에서 피드백이 없음:** 시스템 설정에서 폰의 햅틱/진동 설정이 비활성화되어 있지 않은지
  확인하세요. PixelGames는 이를 재정의할 수 없습니다.
* **Replit의 Simulate on iOS/Android 프리뷰에서 아무 일도 일어나지 않음:** 이 뷰는 화면만
  렌더링하며 폰의 진동 모터를 작동시킬 방법이 없습니다. 햅틱을 느끼려면 실제 기기에서 Expo Go로
  전환하세요. [폰에서 프리뷰 및 테스트하기](/build/mobile-preview-testing)를 참고하세요.
* **iOS와 Android에서 느낌이 다름:** 예상되는 동작입니다. 두 플랫폼은 동일한 피드백 스타일을
  제공하지 않습니다. 차이가 거슬린다면 Agent에게 각각을 별도로 조정하도록 요청하세요.
