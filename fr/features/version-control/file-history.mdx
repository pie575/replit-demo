title: "Historique des fichiers"
description: "Apprenez à récupérer les versions précédentes de votre code grâce aux points de sauvegarde automatiques de l'Historique des fichiers."
---

Commencez par ouvrir un fichier texte dans l'Éditeur de projet et appuyez sur le bouton **Historique** dans le coin inférieur droit.

<Frame>
  <img src="/assets/mirror/history-button-afac6496660a.png" alt="ouverture de l'historique" width="377" height="292" data-path="images/programming-ide/history-button.png" />
</Frame>

## Afficher les versions précédentes d'un fichier

Une fois l'Historique des fichiers ouvert, vous pouvez afficher les versions précédentes d'un fichier en utilisant la barre de défilement, les boutons fléchés, ou les touches **flèche gauche** et **flèche droite**.

<Frame>
  <img src="/assets/mirror/history-versioning-1a055ecab411.gif" alt="démonstration de la barre de défilement" width="764" height="720" data-path="images/animations/history-versioning.gif" />
</Frame>

## Comparer les versions précédentes au fichier actuel

Appuyez sur le bouton Comparer avec la version actuelle en bas à gauche du panneau Historique des fichiers pour voir des comparaisons en ligne de votre fichier à ce moment-là et de la version la plus récente.

<Frame>
  <img src="/assets/mirror/compare-history-46fb16debd3a.gif" alt="image comparer avec la version actuelle" width="772" height="720" data-path="images/animations/compare-history.gif" />
</Frame>

## Restaurer une version précédente d'un fichier

Si vous souhaitez restaurer un fichier à une version précédente, appuyez simplement sur le bouton `Restaurer`, qui effectuera la restauration. Ne vous inquiétez pas, vous n'effacerez pas l'historique. Lorsque vous restaurez une version précédente, elle est ajoutée comme nouvelle version dans l'historique du fichier.

<Frame>
  <img src="/assets/mirror/restore-history-5f616d7f961a.webp" alt="image restaurer l'historique" width="720" height="495" data-path="images/animations/restore-history.webp" />

## Voir la lecture de l'Historique des fichiers

Vous pouvez utiliser la fonctionnalité de lecture de l'Historique des fichiers pour regarder votre fichier évoluer dans le temps comme un film. Cela peut être utile pour créer des vidéos de vos sessions de programmation.
