Replit AI 集成让你轻松构建 AI 驱动的应用。你可以立即调用 OpenAI、Anthropic、Google 和 OpenRouter 的模型，无需设置开发者账户，也无需管理 API 密钥，这一切都由 Replit 代劳。

<div id="replit-ai">
  ## 什么是 Replit AI 集成？
</div>

Replit AI 集成为你提供对各主流提供商 AI 模型的托管式访问。无需离开 Replit，即可构建聊天应用、内容生成器和 AI 驱动的工具，也不必创建外部开发者账号、查找 API 凭据或单独管理账单。

使用 Replit AI 集成时，Replit 会代为管理提供商凭据，并按公开 API 价格计费。用量以 Replit 积分结算，并按各个 Replit 应用分类显示在[用量页面](/zh/ko/billing/managing-spend)。

<Note>
  Replit AI 集成需要付费套餐 (Core、Pro 或 Enterprise) 。在 [Starter 套餐](/zh/ko/billing/plans/starter-plan)下，你可以使用自己的 API 密钥构建 AI 应用。请参阅[套餐可用性](#plan-availability)。
</Note>

<div id="section">
  ## 功能
</div>

Replit AI 集成通过内置访问和透明计费简化 AI 开发：

* **无需配置**：无需开发者账户或 API 密钥即可上手
* **托管凭据**：由 Replit 负责提供商认证和凭据管理
* **透明计费**：按公开 API 价格付费，以 Replit 积分结算
* **用量追踪**：在使用量页面查看各个 Replit 应用的用量
* **跨技术栈支持**：适用于所有编程语言和框架
* **可选的 BYOK**：如需使用自有凭据，可自带 API 密钥

<div id="section-2">
  ## 开始使用
</div>

<div id="replit">
  ### 使用 Replit 托管凭据
</div>

如果您在提示词中提及 AI 功能或特定提供商 (OpenAI、Anthropic、Google 或 OpenRouter) ，Agent 默认会使用 Replit AI 集成：

<AiPrompt>
  创建一个使用 OpenAI 总结文章的 Web 应用
</AiPrompt>

在初始提示词的回复中查找 **&quot;OpenAI (由 Replit 托管) &quot;**、**&quot;Anthropic (由 Replit 托管) &quot;**、**&quot;Google (由 Replit 托管) &quot;** 或 **&quot;OpenRouter (由 Replit 托管) &quot;**，即可了解所使用的集成。这表示 Agent 会使用 Replit 的凭据，而无需您提供自己的 API 密钥。

**初始构建**：提交用于创建包含 AI 功能的新应用的初始提示词后，系统会自动匹配 Replit AI 集成。Agent 会立即使用 Replit 的托管凭据开始构建。

**现有 Replit 应用**：当 Agent 检测到要向现有 Replit 应用添加 AI 功能时，会在项目编辑器中明确告知您将使用 Replit AI 集成，而非您自己的 API 密钥。随后会显示确认提示：

<Frame>
  <img src="/assets/mirror/replit-ai-integrations-confirmation-msg-9440681ad7d3.png" alt="OpenAI 集成确认对话框，显示使用 Replit 托管服务添加 OpenAI、无需 API 密钥的提示，以及取消和批准按钮" width="924" height="294" data-path="images/replitai/replit-ai-integrations-confirmation-msg.png" />
</Frame>

若要继续使用 Replit 托管凭据，请点击“批准”；若要使用自己的 API 密钥，请点击“取消”。

系统会自动跟踪使用量，并按公开 API 价格向您的 Replit 账户收费。

<div id="api">
  ### 使用自己的 API 密钥
</div>

如果你想使用 OpenAI、Anthropic、Google 或其他提供商的自有凭据，而不是 Replit AI 集成，可以有以下几种选择：

**首次构建时**：在提示词中说明你要使用自己的 API 密钥：

<AiPrompt>
  Create a web app that uses OpenAI to summarize articles. Use my own OpenAI API key.
</AiPrompt>

如果响应中只显示提供商名称，而没有“Replit managed”字样，则表示 Agent 会向你索取 API 密钥。

**对于已有的 Replit 应用**：当 Agent 尝试使用 Replit AI 集成并弹出确认提示时，请点击“解除”而不是“批准”。

这两种情况下，Agent 都会先构建到第一个检查点，然后才索取 API 密钥。这样 Agent 可以先搭建好项目结构，再暂停下来收集凭据。

使用自己的 API 密钥时，费用由提供商直接向你收取，不会消耗 Replit 积分。

<div id="section-3">
  ## 查看用量
</div>

所有 Replit AI 集成的用量都会与其他 Replit 用量一并显示在[用量页面](/zh/ko/billing/managing-spend)上。用量会按各个 Replit 应用分别列出，让你清楚了解 AI 支出的具体去向。

<div id="section-4">
  ## 支持的提供商
</div>

Replit AI 集成目前支持以下提供商：

* **OpenAI**：面向文本生成、推理和音频的多模态模型。支持聊天补全、响应、图像生成、音频转写 (`gpt-4o-transcribe`、`gpt-4o-mini-transcribe`) 以及音频输出 (`gpt-audio`、`gpt-audio-mini`) 。
* **Anthropic**：面向推理、写作和编程的多模态模型。支持 Messages API 和网页搜索交互。
* **Google (Gemini)**：面向文本生成和推理的多模态模型。支持文本和图像生成。
* **OpenRouter**：可访问 Microsoft (Phi 系列) 、Meta (Llama 系列) 、Mistral、Qwen、DeepSeek、Nvidia、Amazon 等提供商的模型。

<Note>
  Replit AI 集成支持**文本、图像和音频输出**，不支持视频输出。如需视频生成功能，你需要在提供该功能的提供商处使用自己的 API 密钥。
</Note>

<div id="openrouter-2">
  ## OpenRouter 隐私保护与可用性
</div>

通过 Replit AI 集成使用 OpenRouter 时，请求会附带特定的隐私设置，以保护你的数据。这些设置可能会影响可用的模型，因此有必要了解其作用。

<div id="section-6">
  ### 自助服务用户的隐私设置
</div>

对于个人和团队用户，Replit 会使用以下默认隐私设置来配置 OpenRouter 请求：

* **禁用付费端点训练**：付费模型提供商不会将数据用于训练
* **启用免费端点训练**：免费模型提供商可以使用提示词和补全内容进行训练
* **启用免费端点发布**：免费提供商可以将提示词和补全内容发布到公开数据集
* **禁用输入/输出日志记录**：OpenRouter 不会记录请求和响应，可享受 1% 的账单折扣
* **禁用分析 Cookie**：不使用分析 Cookie

这些设置在优先保护隐私的同时，让你能够使用尽可能广泛的模型。但如果你需要与上述配置不同的隐私设置，**部分模型可能将无法使用**。

<div id="enterprise">
  ### Enterprise 的隐私保护设置
</div>

对于 Enterprise 组织，Replit 会应用更严格的隐私控制：

* **仅限零数据保留 (ZDR) 端点**：只能使用采用零数据保留政策的模型
* 上述面向自助服务用户的所有隐私设置同样适用
* 这可确保 Enterprise 请求仅路由至不保留数据的端点

由于 Enterprise 仅使用 ZDR 端点，因此**可选用的模型范围比自助服务用户更为有限**。这一取舍可为企业版工作负载提供最高级别的数据隐私保障。

<div id="section-7">
  ## 套餐可用性
</div>

Replit AI 集成需要付费套餐，不同套餐的使用方式有所不同。

<div id="starter">
  ### Starter (免费)
</div>

在 Starter 套餐中，Replit AI 集成为禁用状态。你可以使用自己的 API 密钥构建 AI 应用。请参阅[使用自己的 API 密钥](#bringing-your-own-api-key)。

<div id="core">
  ### Core
</div>

在 Core 套餐中，你可以使用 Replit 托管凭据，通过 Replit AI 集成构建 AI 应用，无需自行管理 API 密钥。

<div id="pro-enterprise">
  ### Pro 和 Enterprise
</div>

对于 Pro 和 Enterprise 组织，Replit AI 集成的访问权限默认处于关闭状态。组织管理员可在组织设置页面中控制访问权限：

1. 前往组织设置
2. 找到 Replit AI 集成部分
3. 为组织开启或关闭访问权限

开启后，组织成员即可在应用中使用 Replit AI 集成，所有使用量都会被记录并计入组织账户的账单。关闭后，成员需自行提供 API 密钥才能使用 AI 模型提供商。

<div id="section-8">
  ## 使用场景
</div>

在任意技术栈上构建强大的 AI 应用：

* **内容生成**：总结文章、生成说明文案、撰写内容
* **分析与洞察**：提取关键信息、进行情感分析、文本分类
* **对话式界面**：构建聊天机器人和 AI 助手
* **文本转换**：翻译内容、改写文本、转换格式
* **代码辅助**：生成代码片段、讲解算法、进行代码审查
