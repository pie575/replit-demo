<div id="replit-design">
  ### Replit Design est disponible
</div>

Replit Design est désormais disponible en version générale. Décrivez ce que vous souhaitez créer, explorez des maquettes interactives et affinez votre orientation. Une fois le frame prêt, les utilisateurs Core et Pro peuvent le transformer en une application fonctionnelle au sein du même projet.

</Frame>

Pour en savoir plus, consultez [Replit Design](/fr/ko/design/what-is-replit-design).

<div id="agent">
  ## Agent
</div>

<div id="agent-2">
  ### Choisir le modèle par défaut d&#39;Agent
</div>

Vous pouvez désormais choisir le modèle qu&#39;Agent utilisera par défaut pour vos tâches. Sélectionnez Lite, Economy ou Power, puis choisissez l&#39;un des modèles disponibles dans ce mode. Lite est désormais proposé partout où Agent est accessible, y compris dans l&#39;application mobile. Les modèles disponibles varient selon votre organisation, vos autorisations et votre accès à Turbo.

<Frame caption="Capture réalisée dans Replit Design ; les mêmes contrôles apparaissent dans le menu déroulant des paramètres d'Agent.">
  <img src="/assets/mirror/agent-model-selector-873f18bc6147.png" width="1432" height="786" data-path="images/changelog/2026-07-31/agent-model-selector.png" />
</Frame>

Pour en savoir plus, consultez le [sélecteur de modèle](/fr/ko/features/agent/model-selector).

<div id="mcp">
  ### Connexion à davantage de serveurs MCP
</div>

Les espaces de travail éligibles peuvent se connecter à Supabase, Statsig et Calendly depuis le catalogue de serveurs MCP préenregistrés. Replit reconnaît également le point de terminaison MCP officiel de Braintrust : si vous l&#39;ajoutez manuellement, la procédure de connexion OAuth de ce serveur démarre.

  <img src="/assets/mirror/integrations-4cb26ed8a654.png" alt="Page des paramètres d'intégration répertoriant les connecteurs GitHub, GitLab, AWS, Calendly, etc." width="3124" height="1636" data-path="images/changelog/2026-07-31/integrations.png" />
</Frame>

Pour en savoir plus, consultez [Serveurs MCP](/fr/ko/features/mcp/overview).

  ### Nouvelle page d&#39;utilisation

La page d&#39;utilisation repensée est déployée progressivement auprès de certains comptes Enterprise et des nouveaux clients. Vous pouvez filtrer l&#39;utilisation par date, ressource, projet, espace de travail, groupe et membre.

<div id="section-3">
  ### Durée de connexion prolongée
</div>

Vos sessions Replit restent désormais actives plus longtemps avant de devoir vous reconnecter. Les administrateurs Enterprise peuvent configurer des préréglages de délai d&#39;expiration de session.
