Replit Design 可帮助你塑造软件的外观和使用体验。只需描述你的需求，Replit Design 就会生成可供探索和完善的交互式原型。当某个设计符合你的需求时，它便会在同一项目中成为可运行的 App。

<div id="start-fresh-or-import-existing-designs">
  ## 从零开始或导入现有设计
</div>

访问 [Replit Design](https://replit.com/design)，或在 workspace 主页的创建输入框下选择 **Design**。你可以通过以下四种方式开始：

* **[提示词](/zh/design/design-your-first-screen)**：描述你的需求，生成第一个 frame。
* **[模板](/zh/design/start-from-a-template)**：从预建的落地页、海报、社交媒体帖子、移动端界面或原型开始，再进行个性化修改。
* **[导入](/zh/design/import-figma-designs-into-replit-design)**：从 Figma 或 [Claude](/zh/design/import-claude-designs-into-replit-design) 导入设计，或根据[网址](/zh/design/import-a-website-into-replit-design)或截图重建设计。
* **[设计系统](/zh/design/design-systems-explained)**：从已保存的设计系统开始，让你的第一个 frame 一开始就符合品牌风格。

<div id="explore-variants">
  ## 探索不同方案
</div>

在确定方向之前，先尽可能多地探索。每个结果都会生成一个新的 frame，因此不会丢失任何方案。

* **[建议](/zh/design/explore-suggestions)**：选择一个 frame，Replit Design 会为你推荐下一步可尝试的方案，每项只需点击一下。
* **[使用不同模型](/zh/design/explore-with-different-models)**：切换 Design 使用的模型，并提交相同的需求描述，获得截然不同的方案。

<div id="refine">
  ## 优化
</div>

以最自然的方式完善你的方案：

* **[Chat](/zh/design/chat-about-your-design)**：用自己的话向 Agent 说明需求，可以针对整个画板，也可以一次处理一个 frame。
* **[Visual Editor](/zh/design/visual-editor)**：点击任意元素，直接调整文本、颜色、间距和图片。简单修改会立即应用到源代码，无需消耗积分。
* **[Draw](/zh/design/toolbar#draw)**：圈出问题，用箭头指向目标元素，或留下便签。Agent 会读取你的标注。
* **[生成资源](/zh/design/toolbar#generate)**：创建设计所需的图片、视频片段和矢量图形，并附上参考资料，使其与项目的视觉风格保持一致。

<div id="build">
  ## Build
</div>

当 frame 已准备就绪时，将其交给 Agent。这里的设计绝不只是一张图片，而是构建真实软件的规格说明。

* **[构建你的设计](/zh/design/build-your-design)**：将 frame 转换为一个可运行的新 App。
* **[调整现有 App 的样式](/zh/design/frames#build)**：将 frame 的外观应用到现有 App。

<Frame caption="选中 frame 的操作栏中的 Build 操作。">
  <img src="/assets/mirror/build-design-c5093018b02b.png" alt="选中 frame 的操作栏，其中包含 Build 和 Focus 操作" width="1124" height="326" data-path="images/design/replit-design/build-design.png" />

  从设计 frame 构建新 App 需要 Core 或 Pro；其他所有 Design 功能适用于所有 plan。有关 plan 详情，请参阅[计费](/zh/billing/ai-billing)。
</Note>

<div id="scale">
  ## 扩展
</div>

让下一个设计比上一个更高效：

* **[创建设计系统](/zh/design/create-a-design-system)**：从你喜欢的设计中提取颜色、字体、令牌和组件，或通过 提示词 从零创建设计系统。
* **以它为基础开展新工作**：新的 artifact 从第一个 frame 起就符合品牌风格。
* **[将现有 App 纳入系统](/zh/design/apply-design-system)**：重新设计现有 App 的样式，让所有内容保持一致。
* **切换系统**：可为每个 项目 选择或更换系统。

接下来，流程会回到 **开始**，此后每个设计都从一开始就符合品牌风格。

<div id="when-to-start-in-design-vs-build">
  ## 何时从 Design 或 Build 开始
</div>

Design 和 Build 是进入同一项目的两个入口。Build 是 Agent 让你的软件真正运行起来的地方；Design 则是你塑造软件外观的地方。你在 Design 中完成的设计不会被困在设计工具里。

* 当外观设计是难点时，从 **Design** 开始：先探索不同方向，再将最佳方案 Build 成应用。
* 当功能行为是难点时，从 **Build** 开始：先让它运行起来，再在 Replit Design 中调整样式。
