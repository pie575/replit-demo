Preview는 web app의 실행 결과를 보여주고, 브라우저 개발자 도구와 디버깅 기능을 함께 제공합니다.

**Run** 버튼으로 web app을 실행하면 Replit이 인터넷에서 접근할 수 있는 임시 URL을
할당합니다. Preview 도구는 브라우저에서 보는 것과 똑같이 페이지를 렌더링하며,
널리 쓰이는 브라우저에 있는 것과 유사한 개발자 도구도 함께 제공합니다.

<Note>
  Preview는 Webview의 새로운 이름입니다.
</Note>

<div id="features">
  ## 기능
</div>

Preview에는 web app을 매끄럽게 테스트하고 디버깅할 수 있도록 다음과 같은 기능이 포함되어 있습니다.

* **실시간 Web view**: 브라우저 tab을 벗어나지 않고 앱을 확인하고 조작할 수 있습니다
* **개발자 도구**: 내장 도구로 문제를 빠르게 진단할 수 있습니다
* **반응형 테스트**: 다양한 모바일 기기 화면 크기에서 앱을 확인할 수 있습니다

<div id="usage">
  ## Usage
</div>

web app을 실행하면 Preview 도구가 자동으로 열립니다.
이 동작은 **User Settings** 도구의 **Automatic Preview** 설정에서 켜거나 끌 수 있습니다.

Preview를 여는 방법은 다음과 같습니다.

<Accordion title="Preview 여는 방법">
  왼쪽 **Tool dock**에서:

  1. <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="All tools icon" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**를 선택해 Project Editor 도구 목록을 엽니다.
  2. <img class="icon-svg" src="/assets/mirror/preview-icon-6d37238e8cc2.svg" alt="Preview icon" width="16" height="16" data-path="images/icons/preview-icon.svg" /> **Preview**를 선택합니다.

  **검색창**에서:

  1. 상단의 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="magnifying glass icon" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 돋보기를 선택해 검색 도구를 엽니다.
  2. &quot;Preview&quot;를 입력해 도구를 찾은 뒤 검색 결과에서 선택합니다.
</Accordion>

<div id="location-bar">
  ## 주소 표시줄
</div>

**Preview** 탭 상단의 주소 표시줄에는 다음 도구가 있습니다.

* **뒤로 가기 버튼**: 탐색 기록에서 이전 페이지로 이동합니다
* **앞으로 가기 버튼**: 탐색 기록에서 다음 페이지로 이동합니다
* **앱 도메인**: `{...}.replit.dev`를 선택해 Replit App의 임시 URL 정보를 확인합니다
* **주소 입력란**: 현재 URL 경로를 확인하거나 새 경로를 입력합니다

<div id="browser-tools">
  ## 브라우저 도구
</div>

주소 표시줄 오른쪽에 있는 브라우저 도구에는 다음 기능이 포함되어 있습니다.

* **화면 크기**: 다양한 기기 화면 크기 프리셋 중에서 선택해 반응형 디자인을 테스트합니다
* **Devtools**: [개발자 도구](#Developer_tools) pane을 켜거나 끕니다
* **새 탭**: web app URL을 새 브라우저 탭에서 엽니다

<Note>
  **mobile app을 만들고 계신가요?** Preview panel에서는 **iOS Simulator** 또는 **Android Emulator** 미리보기도 지원합니다. 자세한 내용은 [Native Mobile Apps](/ko/features/artifact-types/building-mobile-apps#preview-on-a-simulator-or-emulator)를 참고하세요.
</Note>

<div id="developer-tools">
  ## 개발자 도구
</div>

<a href="https://github.com/liriliri/eruda" target="_blank">Eruda</a> 오픈 소스 프로젝트를 기반으로 하는 개발자 도구를 사용하면 다음 작업을 수행할 수 있습니다.

* 앱의 context에서 JavaScript 콘솔 확인 및 조작
* DOM 요소 검사
* 네트워크 요청 모니터링
* 표시 및 동작 환경설정 구성

개발자 도구를 사용하려면 **Preview** tab 상단의 <img class="icon-svg" src="/assets/mirror/wrench-7cee9d1168da.svg" alt="렌치 icon" width="16" height="16" data-path="images/icons/wrench.svg" /> **Devtools**
버튼을 선택해 켜거나 끄세요.

다음 섹션에서는 각 개발자 도구 tab에서 수행할 수 있는 작업을 설명합니다.

<div id="console">
  ### Console
</div>

**Console** 탭에는 애플리케이션에서 생성된 JavaScript logs가 표시됩니다.
이 탭에서는 다음 작업을 수행할 수 있습니다.

* **출력 지우기**: <img class="icon-svg" src="/assets/mirror/clear-bd1bf1847597.svg" height="16" width="16" alt="clear icon" data-path="images/icons/clear.svg" /> 사선이 그어진 원 icon을 선택해 모든 콘솔 출력을 지웁니다.
* **출력 filter**: 유형(All, Info, Warning, Error)별로 filter한 콘솔 출력을 확인합니다.
* **일치하는 텍스트 filter**: <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="filter icon" data-path="images/icons/filter.svg" /> filter icon을 선택하고 텍스트를 입력하면 일치하는 출력만 표시됩니다.
* **출력 복사**: <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="copy icon" data-path="images/icons/copy.svg" /> 복사 버튼을 선택해 선택한 콘솔 메시지를 복사합니다.
* **JavaScript 코드 실행**: <img class="icon-svg" src="/assets/mirror/arrow-right-2859a6e6bdeb.svg" height="16" width="16" alt="right arrow icon" data-path="images/icons/arrow-right.svg" /> 오른쪽 꺾쇠 기호를 선택해 앱의 context에서 JavaScript 코드를 실행합니다. 식을 입력한 후 **Execute**를 선택하세요.

<div id="elements">
  ### Elements
</div>

**Elements** 탭에서는 웹 페이지의 DOM 구조를 살펴보고 수정할 수 있습니다.

* **요소 세부 정보 보기**: DOM 요소의 세부 정보와 HTML 코드 내 위치를 확인합니다
* **출력 복사**: <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="copy icon" data-path="images/icons/copy.svg" /> 복사 버튼을 선택해 선택한 콘솔 메시지를 복사합니다.

<img class="icon-svg" src="/assets/mirror/select-1165d9548c39.svg" height="16" width="16" alt="select icon" data-path="images/icons/select.svg" /> 화살표 선택 버튼으로 선택 모드를 켜거나 끌 수 있습니다.
선택 모드로 전환한 후 웹 페이지에서 요소를 선택하세요.
해당 요소의 HTML과 CSS가 Elements 탭에 표시됩니다.

<div id="network">
  ### Network
</div>

**Network** tab은 웹 페이지에서 발생한 요청을 모니터링합니다.
이 tab에서는 다음 작업을 수행할 수 있습니다.

* **요청 추적**: 앱에서 발생한 모든 네트워크 요청을 확인합니다. 요청을 선택하면 세부 정보를 볼 수 있습니다.
* **필터**: <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="filter icon" data-path="images/icons/filter.svg" /> 깔때기 icon을 선택하면 입력한 텍스트와 일치하는 결과만 표시됩니다. filter를 비워 두면 해제됩니다.
* **복사**: <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="copy icon" data-path="images/icons/copy.svg" /> 복사 버튼을 선택해 storage information을 복사합니다.

<div id="resources">
  ### Resources
</div>

**Resources** 탭에는 페이지가 로드한 assets와 쿠키, 로컬 스토리지 같은 브라우저 저장소가 표시됩니다.
다음 asset 유형의 목록을 확인하고 새로 고칠 수 있습니다:

* JavaScript 파일
* 스타일시트
* Iframe
* 이미지

이 탭에서는 다음 작업을 수행할 수 있습니다:

* **저장소 보기**: 로컬 스토리지, session 스토리지, 쿠키를 확인합니다.
* **필터링**: <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="filter icon" data-path="images/icons/filter.svg" /> 깔때기 아이콘을 선택해 입력한 텍스트와 일치하는 결과만 표시합니다. filter를 비워 두면 해제됩니다.
* **지우기**: <img class="icon-svg" src="/assets/mirror/clear-bd1bf1847597.svg" height="16" width="16" alt="clear icon" data-path="images/icons/clear.svg" /> 지우기 버튼을 선택해 해당 저장소 유형의 모든 데이터를 삭제합니다.
* **선택 항목 삭제**: <img class="icon-svg" src="/assets/mirror/delete-a21eb49cac3c.svg" height="16" width="16" alt="delete icon" data-path="images/icons/delete.svg" /> &quot;X&quot; 아이콘을 선택해 저장소 항목을 제거합니다.
* **복사**: <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="copy icon" data-path="images/icons/copy.svg" /> 복사 버튼을 선택해 storage information을 복사합니다.

<div id="settings">
  ### Settings
</div>

**Settings** tab에서는 개발자 도구의 모양과 동작을 원하는 대로 설정할 수 있습니다.
이 tab에서 다음 항목을 사용자화할 수 있습니다:

* **도구 설정**: 각 도구 tab에 적용되는 옵션을 사용자화합니다
* **JavaScript 제어**: JavaScript를 꺼서 앱의 동작을 테스트하는 등 JavaScript 동작 관련 옵션을 지정합니다
* **표시 환경설정**: 개발자 도구의 theme, 패널 크기, 투명도를 비롯한 동작을 변경합니다
