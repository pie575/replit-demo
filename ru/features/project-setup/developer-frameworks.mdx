<div id="developer-framework-templates-have-been-removed">
  ## Шаблоны фреймворков для разработчиков удалены
</div>

Стартовые шаблоны языков и фреймворков (ранее — фреймворки для разработчиков) больше не доступны на Replit. Страницы `replit.com/templates` и `replit.com/developer-frameworks` теперь перенаправляют в [Replit Gallery](https://replit.com/gallery).

Чтобы начать новый project, воспользуйтесь одним из следующих способов:

* **Начните с Replit Agent** — опишите на [главной странице](https://replit.com/), что вы хотите создать, и Agent сам подготовит структуру project.
* **[Импорт из GitHub, GitLab или Bitbucket](/ru/build/import-from-providers)** — перенесите существующую кодовую базу или стартовый стек в новое Replit App.
* **[Ремикс опубликованного приложения](https://replit.com/gallery)** — загляните в Replit Gallery: приложения сообщества можно посмотреть и взять за основу, сделав ремикс.

<div id="enterprise-custom-templates">
  ## Пользовательские шаблоны Enterprise
</div>

Организации Enterprise могут создавать [пользовательские шаблоны](/ru/teams/custom-templates), которые доступны для выбора в поле ввода Agent всем участникам организации. Такие шаблоны не ограничиваются фреймворками разработки: они включают корпоративные инструкции для Agent, skills и заранее настроенный контекст project. Подробнее см. в [руководстве по пользовательским шаблонам](/ru/teams/custom-templates).
