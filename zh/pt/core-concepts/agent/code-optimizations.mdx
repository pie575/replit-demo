export const YouTubeEmbed = ({videoId, title = "YouTube video", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

**代码优化** (原“自主性级别”) 是 Agent 设置下拉菜单中**高级设置**里的一个开关选项。**开启**时，Agent 会审查自己编写的代码并简化后续工作——通过避免错误来提升准确性并节省成本。**关闭**时，AI 代码审查将极少甚至完全没有，但你可获得最大程度的手动控制权。适用于[付费方案](https://replit.com/pricing)。

我们建议在大多数项目中将代码优化保持**开启**，以获得更好的代码质量，减少代价高昂的返工。

<div id="uso">
  ## 使用
</div>

在任意项目中工作时，都可以从 Agent 设置下拉菜单打开代码优化。该设置对当前对话生效，会影响 Agent 处理后续任务的方式，且在使用 Economy 或 Power 模式时均可用。

<Accordion title="如何使用代码优化">
  1. 在项目编辑器中打开你的项目
  2. 在 Chat 输入框中打开 Agent 设置下拉菜单
  3. 展开**高级设置**，找到**代码优化**
  4. 根据需要开启或关闭
</Accordion>

<div id="quando-usar">
  ### 何时使用
</div>

* **开启**：适用于大多数工作场景。Agent 会自查代码、发现错误，减少返工。每项任务耗时略长，但质量更高。
* **关闭**：当你想要最快、最大程度由自己掌控的体验时使用——例如快速修改，或你更愿意亲自审阅每一处改动时。
