Центр безопасности рабочего пространства доступен на всех тарифах. Используйте его, чтобы сканировать зависимости [dependencies](/ru/features/security/concepts#dependency) проектов в Workspace и просматривать результаты [CVE](/ru/features/security/concepts#cve) по [уровню серьёзности](/ru/features/security/concepts#severity). Вы можете устранять проблемы с помощью Replit Agent, выполнять [повторную публикацию](/ru/features/security/concepts#republish) затронутых проектов и экспортировать отчёты Software Bill of Materials ([SBOM](/ru/features/security/concepts#sbom)) для соответствия требованиям.

<Note>
  Чтобы просканировать отдельный проект, откройте [Project Security Center](/ru/features/security/project-security-center)
  на панели **Security** этого проекта.
</Note>

<Note>
  Впервые работаете с безопасностью зависимостей? См. [Концепции безопасности](/ru/features/security/concepts), чтобы ознакомиться с определениями CVE, SBOM, подверженности риску, Fix with Agent, Republish и Auto-Protect.
</Note>

<div id="features">
  ## Возможности
</div>

<div id="cve-detection">
  ### Обнаружение CVE
</div>

Просматривайте уязвимости во всех проектах workspace:

* Выявляйте уязвимые проекты с приоритетом по [подверженности риску](/ru/features/security/concepts#exposure) (статусу публикации и видимости)
* Просматривайте названия и версии затронутых пакетов, а также уровень серьёзности (критический, высокий, средний и низкий)
* Получайте рекомендации по устранению уязвимостей для каждого проекта

<div id="affected-projects-view">
  ### Просмотр затронутых проектов
</div>

Определите, в каких проектах есть уязвимости, и решите, что исправлять в первую очередь:

* Смотрите сводку по уязвимым проектам с группировкой по подверженности риску: всего проектов, опубликованные проекты и опубликованные публично проекты
* Изучайте подробную разбивку по затронутым Replit проектам
* Ищите по CVE ID или имени проекта и фильтруйте по уровню серьёзности, владельцу, статусу публикации (Published / Not published) и видимости (Public / Private)
* Разверните строку любого проекта, чтобы увидеть все найденные CVE (серьёзность, пакет, версия, CVE ID), не покидая страницу

<div id="fix-with-agent-and-republish">
  ### Исправление с Agent и повторная публикация
</div>

Устраняйте уязвимости и повторно развертывайте приложения, не выходя из Security Center:

* В любом затронутом проекте выберите **[Fix with Agent](/ru/features/security/concepts#fix-with-agent)**, чтобы создать черновик исправления в виде фоновой задачи. Перед повторной публикацией проверьте и примените созданное изменение.
* Отслеживайте статус устранения с помощью **Task in progress**, **Apply changes**, **Republish**, а также конечных статусов **Republished** и **Failed**.
* После объединения исправления одним нажатием **Republish** и подтверждением в диалоговом окне можно повторно развернуть сборку с текущей конфигурацией.
* Выполняйте массовые действия: например, отменяйте публикацию или уведомляйте владельцев проектов об уязвимостях в их проектах.

<div id="sbom-export">
  ### Экспорт SBOM
</div>

Экспортируйте спецификацию программного обеспечения (SBOM) для целей комплаенса и аудита:

* Скачивайте SBOM в стандартных форматах ([SPDX](/ru/features/security/concepts#spdx-and-cyclonedx), [CycloneDX](/ru/features/security/concepts#spdx-and-cyclonedx))
* Формируйте отчёты по отдельным проектам или по всему workspace
* Просматривайте SBOM, сгруппированные по запускам сканирования, с указанием времени, количества проектов и пользователя, запустившего сканирование
* Скачивайте все SBOM из одного запуска сканирования единым zip-архивом
* Соблюдайте требования к прозрачности цепочки поставок программного обеспечения

<Note>
  Массовое скачивание SBOM доступно на тарифах Enterprise. В workspaces на других тарифах в разделе SBOM отображается предложение перейти на Enterprise.
</Note>

<div id="accessing-the-workspace-security-center">
  ## Доступ к Центру безопасности рабочего пространства
</div>

Чтобы открыть Центр безопасности рабочего пространства:

1. Перейдите на [replit.com](https://replit.com) и войдите в свою учётную запись.
2. На главной странице выберите **Security** в левой панели навигации.

<div id="scanning-your-workspace">
  ## Сканирование workspace
</div>

<Frame>
  <img src="/assets/mirror/security-overview-b37f090f236c.png" alt="Главный экран Центра безопасности рабочего пространства с общим числом сканирований, общим числом уязвимостей и CVE, сгруппированными по уровню серьёзности" width="3438" height="1984" data-path="images/workspace-security-center/security-overview.png" />
</Frame>

1. Откройте Центр безопасности рабочего пространства.
2. Нажмите **Run security scan**, чтобы запустить сканирование всего workspace.
3. Изучите результаты, сгруппированные по затронутым проектам, уровню серьёзности и подверженности риску через deployment.
4. В любом затронутом проекте нажмите **Fix with Agent**, а после применения исправления — **Republish**.

Сканирование анализирует dependencies в Replit проектах внутри workspace и отмечает известные уязвимости по публичным базам уязвимостей.

<div id="auto-protect">
  ## Auto-Protect
</div>

Администраторы могут подключить свою учётную запись к **[Auto-Protect](/ru/features/security/concepts#auto-protect)** — функции, которая непрерывно отслеживает вновь опубликованные CVE и сверяет их с зависимостями каждого проекта. При обнаружении совпадения Replit Agent готовит проверенный патч, а разработчики получают письмо с прямой ссылкой для его применения.

Полный рабочий процесс и шаги настройки, включая доступный только администраторам порог серьёзности в **Settings** &gt; **Account** &gt; **Дополнительно**, описаны в разделе [Auto-Protect](/ru/features/security/project-security-center#auto-protect).

<Note>
  Обратитесь к персональному менеджеру по работе с клиентами за помощью в настройке Центра безопасности рабочего пространства или интеграции экспорта SBOM в процессы обеспечения соответствия требованиям.
</Note>
