当 Agent 正在工作时，后续消息可以改变 Agent 当前正在执行的内容 (即当前的**回合**，回合) ，也可以等待该回合结束后再处理：

* **Steer** 会将消息发送到当前回合，Agent 在继续工作时会参考这些新的上下文。
* **队列** 会将消息留到下一回合，Agent 会在当前回合结束后再开始处理。

<div id="steering-conversations">
  ## 引导对话
</div>

Steer 是 Conversation 和 Project 中后续消息的默认发送行为，你可以将其中任一项改为 队列。

<div id="choose-how-replit-sends-follow-ups">
  ## 选择 Replit 发送后续消息的方式
</div>

你可以分别为 Conversation 和 Project 设置发送行为：

1. 打开 **Settings** &gt; **Personalization**。
2. 展开 **Agent**。
3. 将 **Conversation send behavior** 和 **Project send behavior** 设置为 **Steer** 或 **队列**。

<Frame caption="Agent 部分中的 Conversation 和 Project 发送行为设置。">
  <img src="/assets/mirror/agent-follow-ups-settings-98a4c5ca399e.png" alt="Agent settings showing Conversation and Project send behavior with Steer and 队列 options" width="3048" height="1372" data-path="images/replitai/agent-follow-ups-settings.png" />
</Frame>

<Info>
  Design 模式始终以引导 (Steer) 方式处理后续消息，Conversation 和 Project 的发送行为设置在 Design 模式下不生效。
</Info>

若只想让单条消息采用与当前偏好相反的行为，请按
`Cmd+Enter` (Mac) 或 `Ctrl+Enter` (Windows 和 Linux) 。

<div id="work-with-queued-messages">
  ## 使用排队消息
</div>

当你将后续消息加入队列时，消息队列会以抽屉形式显示在聊天输入框上方。Agent 会在当前回合结束后按顺序处理队列中的消息。所有排队消息处理完毕后，该抽屉会自动关闭。

队列支持全部消息选项，包括 [Visual Editor](/zh/design/visual-editor) 和文件附件。

<Info>
  只有在桌面端或移动端连接了活跃的 Project 编辑器会话时，Agent 才会自动处理队列中的消息。
</Info>

<div id="manage-the-queue">
  ### 管理队列
</div>

打开队列抽屉后，你可以：

* **立即引导**：将队列中的消息移入当前回合。
* **编辑消息**：在 Agent 处理之前修改队列中的消息。
* **删除消息**：移除不再需要的消息。
* **调整顺序**：拖动消息以更改其处理顺序。
* **添加消息**：向队列中继续发送后续消息。

<div id="stop-the-active-turn">
  ## 停止当前回合
</div>

在状态栏中选择 **Stop**，即可中断 Replit 在当前回合中正在进行的工作。随后你可以直接发送新消息，无需等待 Agent 完成该回合或处理排队消息。
