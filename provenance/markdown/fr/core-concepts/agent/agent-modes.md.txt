# Modes Agent

> Apprenez à choisir entre Lite, Economy et Power, et quand utiliser les Paramètres avancés et Turbo.

Les modes Agent vous permettent de contrôler l'équilibre entre vitesse, coût et capacité lors de l'utilisation de l'Agent. Utilisez le sélecteur de mode de premier niveau dans le menu déroulant des paramètres Agent pour basculer entre **Lite**, **Economy** et **Power**. Développez les **Paramètres avancés** lorsque vous souhaitez plus de contrôle sur les tests, la révision de code et Turbo.

<Tip>

</Tip>

<Note>Le mode Max n'est plus disponible. Utilisez Power pour les builds standard les plus performants, et activez Turbo dans les Paramètres avancés lorsque vous avez besoin des exécutions les plus rapides.</Note>

## Mode Lite

**Optimisé pour les modifications rapides.** Lite utilise des modèles rapides et légers pour les ajustements visuels, les corrections de bugs et autres petits changements ciblés.

<Frame>
  <img src="https://mintcdn.com/replit/XaMYOCzzo0qF7SLE/images/replitai/agent-modes-lite.png?fit=max&auto=format&n=XaMYOCzzo0qF7SLE&q=85&s=869ad812693655d12ce9762398826bcc" alt="Menu des modes Agent avec Lite sélectionné" width="1192" height="1328" data-path="images/replitai/agent-modes-lite.png" />
</Frame>

**Idéal pour :** Les correctifs rapides, le polish de l'interface utilisateur et les cycles d'itération courts lorsque vous restez à votre ordinateur.

**À retenir :** Lite fonctionne mieux dans les applications existantes lorsque vous savez déjà ce que vous voulez modifier. Si vous partez de zéro, effectuez des changements architecturaux importants, ajoutez une nouvelle intégration ou modifiez un schéma de base de données, passez à Economy ou Power.

**Coût :** Lite utilise le même modèle de tarification basé sur l'effort que les autres modes de build, mais les demandes ciblées coûtent souvent moins cher qu'en Economy ou Power pour la même modification.

## Mode Economy

**Optimisé pour le coût.** Economy utilise moins de crédits par tâche et est le meilleur choix par défaut lorsque vous souhaitez des résultats solides sans payer pour les modèles les plus performants.

<Frame>
  <img src="https://mintcdn.com/replit/XaMYOCzzo0qF7SLE/images/replitai/agent-modes-economy.png?fit=max&auto=format&n=XaMYOCzzo0qF7SLE&q=85&s=bd129c68f32114d8c9296d5ea039549c" alt="Menu des modes Agent avec Economy sélectionné et paramètres avancés développés" width="1192" height="1328" data-path="images/replitai/agent-modes-economy.png" />
</Frame>

**Idéal pour :** Les builds quotidiens, l'apprentissage et le travail économe sur un projet existant.

## Mode Power

**Optimisé pour les capacités.** Power utilise des modèles plus performants pour les tâches complexes, les bases de code volumineuses et les problèmes difficiles.

<Frame>
  <img src="https://mintcdn.com/replit/XaMYOCzzo0qF7SLE/images/replitai/agent-modes-power.png?fit=max&auto=format&n=XaMYOCzzo0qF7SLE&q=85&s=ae3098e25ed6b9f138254f5de7819752" alt="Menu des modes Agent avec Power sélectionné et paramètres avancés développés" width="1192" height="1328" data-path="images/replitai/agent-modes-power.png" />
</Frame>

**Idéal pour :** Les projets de qualité production, les fonctionnalités complexes et lorsque vous souhaitez les meilleurs résultats de l'Agent.

## Paramètres avancés

Développez les **Paramètres avancés** dans le menu déroulant pour gérer le reste des contrôles de build de l'Agent :

* **Tests d'application** permet à l'Agent de tester automatiquement votre application dans un navigateur.
* **Optimisations de code** permet à l'Agent de réviser et d'améliorer son propre code pendant qu'il travaille.
* **Turbo** vous donne accès aux modèles les plus rapides disponibles lorsque vous êtes en mode Power.

Le mode Lite maintient les Tests d'application et les Optimisations de code désactivés, et Turbo n'est disponible qu'en mode Power.

## Mode Turbo

**Turbo est un bouton séparé dans les Paramètres avancés.** Activez-le en mode Power lorsque vous souhaitez des réponses **2,5× plus rapides** avec les modèles les plus rapides. Les demandes peuvent coûter jusqu'à 6× plus cher que Power, donc Turbo est préférable lorsque la vitesse prime sur l'efficacité.

<Frame>
  <img src="https://mintcdn.com/replit/CEz1CvpChV8LOqgG/images/replitai/agent-modes-turbo.png?fit=max&auto=format&n=CEz1CvpChV8LOqgG&q=85&s=3e5ea2a7ec43a1ff24f28dc85ae9eb82" alt="Menu des modes Agent avec Power sélectionné et Turbo activé dans les paramètres avancés" width="760" height="502" data-path="images/replitai/agent-modes-turbo.png" />
</Frame>

<Warning>
  Turbo est mis en évidence en orange dans le menu déroulant des modes Agent pour rappeler visuellement qu'il coûte bien plus cher que Power. Gardez un œil sur cette mise en évidence lorsque vous itérez rapidement — elle est là pour garder le compromis de coût visible.
</Warning>

**Disponibilité :** **Pro et Enterprise uniquement.**

**Idéal pour :** Lorsque vous avez besoin de la réponse Agent la plus rapide possible et que vous êtes sur un abonnement Pro ou Enterprise.

## Quel mode devrais-je utiliser ?

Utilisez ceci comme guide :

| Objectif                                               | Mode recommandé                |
| ------------------------------------------------------ | ------------------------------ |
| Modifications petites et ciblées, itérations rapides   | Lite                           |
| Maximiser le nombre d'invites par crédit               | Economy                        |
| Équilibrer coût et qualité pour la plupart des projets | Power                          |
| Réponse la plus rapide pour les tâches importantes     | Power + Turbo (Pro/Enterprise) |

Vous pouvez changer de mode à tout moment depuis le menu déroulant des paramètres Agent dans la saisie du chat. Choisissez Lite, Economy ou Power depuis le contrôle de premier niveau, puis développez les Paramètres avancés lorsque vous souhaitez plus de contrôle sur les tests, la révision de code ou Turbo. Aucun mode n'est toujours le meilleur — choisissez celui qui convient à la tâche devant vous.
