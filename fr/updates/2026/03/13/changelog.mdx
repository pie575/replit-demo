export const YouTubeEmbed = ({videoId, title = "YouTube video", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

## Agent

### Présentation de Replit Agent 4

<YouTubeEmbed videoId="bAUVQfz_SIY" title="Introducing Replit Agent 4" />

Agent 4 est arrivé. Conçu pour la créativité, Agent est votre partenaire créatif IA — transformant vos idées en applications, designs, diapositives et bien plus encore, le tout en langage naturel. Aucune compétence en programmation requise.

Avec Agent 4, vous pouvez :

* **Créer n'importe quoi** : créer des applications web, des applications mobiles, des tableaux de bord de données, des outils alimentés par l'IA, et bien plus encore
* **Concevoir avant de créer** : explorer des maquettes sur le [Canvas de design](/fr/learn/projects-and-artifacts/canvas) avant de vous engager dans le code
* **Planifier votre projet** : utiliser le [mode Plan](/fr/core-concepts/agent/plan-mode) pour cartographier votre construction avant qu'une seule ligne de code ne soit écrite
* **Exécuter des tâches en parallèle** : Agent gère plusieurs tâches à la fois pour vous permettre d'avancer plus vite
* **Collaborer avec vos coéquipiers** : invitez d'autres personnes dans votre projet et créez simultanément
* **Connecter vos outils** : extrayez des données de BigQuery, Linear, Slack, Notion et bien plus encore directement depuis le chat
