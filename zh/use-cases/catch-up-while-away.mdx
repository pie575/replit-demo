离开一段时间后，分析该时段内的 Slack、Gmail 和 Calendar，并在 Notion 中撰写一份
返岗简报：期间发生了什么、哪些事项需要决策、应优先回复哪些内容，以及
本周有哪些安排。Agent 不应罗列每条消息，只应提供
需要你处理的内容。

  ## 开始前
</div>

告知 Agent 你不在期间的日期，以及哪些 Slack 频道和日历与此相关。连接
Gmail、Slack、Calendar 和 Notion。

  我在 [dates] 期间不在。请分析这段时间内的 Slack、Gmail 和 Calendar，
  并在 Notion 中撰写一份返岗简报：发生了什么、哪些事项需要决策、我应优先回复哪些内容，
  以及本周有哪些安排。
</AiPrompt>

<div id="what-to-expect">
  ## 预期内容
</div>

Agent 会生成一份简短简报：待决事项、需要回复的线程，以及需要补看的会议。它不会罗列每一条消息，只会包含需要你处理的内容。采取行动前，请查看日期范围和它使用的频道。在 Slack 或 Gmail 中打开简报中的两个线程，确认它们确实需要你处理。如果它起草了回复，请先发一封给自己。

<div id="make-it-work-for-you">
  ## 让它更好地为你服务
</div>

<AiPrompt>
  简报仅包含需要我做决定或回应的事项。忽略纯公告频道。
</AiPrompt>

<AiPrompt>
  为最需要我处理的 5 封电子邮件和 Slack 线程起草回复，并保持我的语气。
</AiPrompt>

<div id="troubleshooting">
  ## 故障排除
</div>

* **简报汇总了每条消息：**请列出重要的 Slack 频道和日历，并要求 Agent 只保留决策以及直接向你提出的请求。忽略仅发布公告的频道。
* **它遗漏了你不在期间的几天：**请提供准确日期 (包括时区) ，并确认 Gmail、Slack 和 Calendar 连接的是你离开期间使用的同一账户。
* **草稿不像你的语气：**粘贴几条你真实的回复，并让 Agent 在起草任何你可能发送的内容前先模仿这种语气。
