Un **élément** désigne chacune des parties affichées par un frame : titre, bouton, image, champ de formulaire, etc. Lorsque vous souhaitez modifier une seule partie sans régénérer le frame entier, c&#39;est l&#39;élément qui devient votre cible.

<div id="section">
  ## Sélectionner un élément
</div>

Utilisez l&#39;[outil Edit](/fr/ja/design/toolbar#edit) de la barre d&#39;outils. Lorsque Edit est actif, cliquez dans une frame en direct pour sélectionner l&#39;élément situé sous le curseur. L&#39;élément sélectionné apparaît avec un contour en surbrillance, accompagné d&#39;un petit prompt en ligne qui vous permet de demander des modifications à Agent.

<Note>
  Edit reste désactivé tant qu&#39;il n&#39;y a pas au moins une frame sur le Canvas. Cette fonctionnalité est par ailleurs réservée à l&#39;ordinateur de bureau.
</Note>

<div id="section-2">
  ## Actions sur les éléments sélectionnés
</div>

<div id="agent">
  ### Demander une modification à Agent
</div>

Grâce au prompt en ligne, vous pouvez demander à Agent de mettre à jour le texte, les couleurs, la mise en page, les espacements ou le comportement d&#39;un élément.

<div id="section-3">
  ### Remplacer directement une image
</div>

Lorsque vous sélectionnez un élément image, la section **Image** du Visual Editor affiche le chemin de la source ainsi qu&#39;un bouton **Upload Image** : vous pouvez ainsi remplacer le fichier sans écrire de prompt.

<div id="visual-editor">
  ## Visual Editor
</div>

Lorsque vous sélectionnez un élément, le **Visual Editor** s&#39;ouvre dans le panneau de droite, en complément du prompt en ligne. Ce panneau regroupe tous les contrôles en sections bien distinctes, ce qui vous permet de trouver plus rapidement ce dont vous avez besoin : les sections **Texte**, **Mise en page**, **Couleur** et **Bordure**. (Si vous sélectionnez un élément image, une section **Image** apparaît également.)

<div id="layout">
  ### mise en page
</div>

La section **mise en page** vous permet d&#39;ajuster la disposition des éléments enfants dans un conteneur sans passer par Agent. Sélectionnez un conteneur flex et développez mise en page pour afficher les options suivantes :

* **Alignment** : un sélecteur de points 3×3 indiquant où placer les éléments sur les deux axes du conteneur.
* **Direction** : deux boutons fléchés pour empiler les éléments enfants en ligne ou en colonne.
* **Gap** : la valeur en pixels de l&#39;espace entre les éléments. L&#39;icône située à côté du champ Gap s&#39;adapte à la Direction actuelle, si bien que vous savez toujours si vous ajustez l&#39;espace horizontal ou vertical. L&#39;icône fléchée voisine active ou désactive **Distribuer l&#39;espace entre les éléments (Distribute space between items)**, qui répartit les éléments enfants jusqu&#39;aux bords du conteneur.
* **Outer space** : des champs de saisie permettant de définir l&#39;espace extérieur de l&#39;élément côté par côté (un par côté, avec une bascule de liaison pour verrouiller les quatre côtés à la fois).
* **Inner space** : des champs de saisie permettant de définir l&#39;espace intérieur de l&#39;élément sur chaque axe, avec une bascule de liaison pour verrouiller les deux axes à la fois.

La section mise en page ne s&#39;affiche que si au moins un contrôle de mise en page s&#39;applique à l&#39;élément sélectionné. Pour les nœuds de texte brut, dépourvus de propriétés d&#39;espacement ou de mise en page, cette section est entièrement masquée, ce qui garde l&#39;éditeur compact.

Pour les sections **texte**, **couleur**, **bordure** et **Image**, consultez le [guide du Visual Editor](/fr/ja/design/visual-editor).
