<div id="section">
  ## О местах для наблюдателей
</div>

Наблюдатели получают доступ только для чтения к приложениям и деплойментам команды. Так проще делиться работой с заинтересованными лицами и коллегами, которым не нужны права на редактирование и полная командная лицензия.

Места для наблюдателей оптимальны в следующих случаях:

* Пользователи внутренних инструментов, которые не создают приложения
* Заинтересованные лица, которым нужно следить за ходом проекта
* Участники команды, знакомящиеся с возможностями Replit

В план команды входит 50 мест для наблюдателей — это позволяет эффективно масштабировать совместную работу.

Если вам нужно добавить более 50 наблюдателей, напишите в отдел продаж по адресу [sales@replit.com](mailto:sales@replit.com), чтобы обсудить план Enterprise.

<div id="section-2">
  ## Приглашение наблюдателей
</div>

1. Перейдите на вкладку **Участники** вашей организации
2. Выберите **+ Добавить**
3. Выберите вариант Viewer
4. Укажите адреса электронной почты нужных наблюдателей списком через запятую
5. Выберите **Отправить приглашения**

Приглашённые пользователи без учётной записи Replit получат письмо с инструкциями по созданию аккаунта и присоединению к команде. Пользователи, у которых уже есть учётная запись Replit, будут добавлены автоматически.

<div id="section-3">
  ## Доступ для наблюдателей
</div>

<Note>
  **Изменение поведения доступа по умолчанию (действует с 9 июня 2025 года)**: приложения, созданные в организации, по умолчанию являются **приватными**. Доступ к новым приложениям наблюдателям нужно предоставлять явно — через панель Access.
</Note>

Доступ к новым приложениям наблюдателям нужно предоставлять явно через панель Access. К приложениям, созданным до этого изменения, наблюдатели могут сохранять доступ в соответствии с прежними настройками.
