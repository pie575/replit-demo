Le Canvas est la surface infinie sur laquelle vous pouvez vous déplacer et zoomer, où Replit Design affiche vos frames. Tout ce que vous concevez se trouve ici : générez des frames, déplacez-les, zoomez sur un détail et itérez jusqu’à obtenir le résultat souhaité.

<div id="open-the-canvas">
  ## Ouvrir le canvas
</div>

Le canvas est la première chose que vous voyez dans Replit Design. Dans un projet, sélectionnez **Design** dans l&#39;en-tête : le canvas occupe alors tout le volet ; sélectionnez **Build** pour revenir à votre app en cours d&#39;exécution.

<Frame>
  <img src="/assets/mirror/canvas-design-button-ffa50447cefb.png" alt="Gros plan sur l'en-tête d'un projet avec le sélecteur Design et Build, Design sélectionné, au-dessus des frames sur le canvas" width="987" height="619" data-path="images/replitai/canvas-design-button.png" />
</Frame>

Si vous partez de zéro sur [replit.com/design](https://replit.com/design), vous êtes invité à créer un nouveau design, qui s&#39;ouvre dans le canvas. Consultez [Design vs. Build](/fr/design/design-vs-build) pour savoir quand utiliser l&#39;une ou l&#39;autre surface.

<div id="what-lives-on-the-canvas">
  ## Ce que contient le canvas
</div>

* **Frames** : chaque tuile du tableau. Un frame peut être une maquette de design, une web app, une application mobile, des diapositives, une image, une vidéo ou un graphique vectoriel. Générez-les depuis un prompt dans le Chat, depuis le [menu Generate](/fr/design/toolbar#generate) de la barre d&#39;outils ou depuis le [panneau bibliothèque](/fr/design/library-panel). Tout ce que vous faites sur un frame — Build, Focus, suggestions — passe par le frame lui-même : consultez [Frames](/fr/design/frames).
* **Dessins et notes** : les annotations que vous ajoutez avec l&#39;[outil Draw](/fr/design/toolbar#draw), comme des croquis, des flèches, des formes et des pense-bêtes. Agent lit vos annotations : vous pouvez donc entourer une zone problématique et demander une modification.
* **Le panneau Chat** : le Chat d&#39;Agent ancré à côté du canvas. Si vous sélectionnez des frames avant d&#39;envoyer un message, ils sont joints sous forme de captures, ce qui donne à Agent un contexte visuel.

Pour savoir ce qu&#39;est chaque composant et comment ils s&#39;articulent, consultez la [vue d&#39;ensemble des composants](/fr/design/core-components).

<div id="navigate-the-board">
  ## Naviguer sur le tableau
</div>

Le déplacement, le zoom et la sélection fonctionnent depuis n&#39;importe quel outil, sauf mention contraire.

**Déplacement :**

* Pavé tactile : glisser à deux doigts.
* Souris : clic-glisser avec le bouton du milieu, ou maintenir la barre d&#39;espace et faire un clic-glisser gauche.
* [Pan](/fr/design/toolbar#pan) : clic-glisser avec le bouton gauche de la souris.

**Zoom :**

* Pavé tactile : pincer.
* Souris : `Ctrl` (ou `Cmd` sur macOS) + molette de défilement.
* Clavier : `Cmd`/`Ctrl` + `+` pour zoomer, `Cmd`/`Ctrl` + `-` pour dézoomer, `Cmd`/`Ctrl` + `0` pour réinitialiser le zoom.

Le zoom est ancré sur le curseur : le point situé sous le curseur reste en place pendant que le reste du tableau se redimensionne autour de lui.

**Sélection :**

* Une seule frame : cliquez dessus avec l&#39;[Interact](/fr/design/toolbar#interact).
* Sélection multiple : maintenez `Shift` et cliquez sur chaque frame, ou tracez un rectangle de sélection sur le tableau.
* Désélection : cliquez sur une zone vide, ou appuyez sur `Échap`.

Sélectionner une ou plusieurs frames fait apparaître la [barre d&#39;actions de la frame](/fr/design/frames#per-frame-action-bar) et joint ces frames au prochain message envoyé à Agent sous forme d&#39;instantanés.

| Maintenir `Space` + faire glisser | Se déplacer depuis n&#39;importe quel outil |
| `Cmd` / `Ctrl` + molette          | Zoomer                                      |
| `Cmd` / `Ctrl` + `+`              | Zoom avant                                  |
| `Cmd` / `Ctrl` + `-`              | Zoom arrière                                |

<div id="right-click-menu">
  ## Menu contextuel
</div>

Faites un clic droit n’importe où sur le tableau pour ouvrir un menu contextuel. Les actions proposées s’adaptent à ce qui se trouve sous le curseur : un frame affiche les actions qui lui sont propres, une zone vide du Canvas affiche les actions du tableau, et les frames d’App ajoutent **Actualiser l’artifact**.

Sur un frame sélectionné, le menu comprend :

| Action                               | Raccourci                     | Description                                                            |
| ------------------------------------ | ----------------------------- | ---------------------------------------------------------------------- |
| Modifier                             |                               | Passe à l’outil Modifier pour sélectionner des éléments dans le frame. |
| Chat                                 |                               | Discutez avec Agent à propos du frame.                                 |
| Focus                                |                               | Active le [mode focus](/fr/design/frames#focus-mode) sur le frame.        |
| Chat au curseur                      | `/`                           | Lance un chat rapide à la position du curseur.                         |
| Réorganiser                          |                               | Déplace le frame vers l’avant ou l’arrière dans l’ordre d’empilement.  |
| Copier, Coller, Dupliquer, Supprimer | `⌘C`, `⌘V`, `⌘D`, `Backspace` | Gestion standard du presse-papiers et des frames.                      |
| Exporter sous…                       |                               | Exporte le frame sous forme de fichier.                                |
| Tout sélectionner                    | `⌘A`                          | Sélectionne tous les frames du tableau.                                |

<div id="export-a-frame-as-png">
  ### Exporter un frame au format PNG
</div>

Enregistrez n’importe quel artifact ou frame de design en tant qu’image PNG. Cette option est utile pour partager un aperçu dans un document ou un chat, capturer un instantané avant de poursuivre vos itérations ou envoyer une capture d’écran à un collègue.

<Steps>
  <Step title="Sélectionner le frame">
    Sélectionnez l’artifact ou le frame de design à exporter, puis attendez qu’il finisse de se charger.
  </Step>

  <Step title="Choisir Export">
    Sélectionnez **Export** dans la barre d’actions du frame. Vous pouvez aussi cliquer avec le bouton droit sur le frame et sélectionner **Export as…** &gt; **PNG**. L’image est téléchargée sur votre ordinateur avec un nom de fichier basé sur celui du frame.
  </Step>
</Steps>

Pour copier le frame sélectionné au format PNG au lieu de le télécharger, appuyez sur `Cmd+Shift+C` (ou `Ctrl+Shift+C` sous Windows et Linux).

<Note>Le PNG exporté correspond à ce que le frame affiche actuellement sur le Canvas. Si votre app ou votre design est encore en cours de chargement, attendez qu’il soit entièrement rendu avant de l’exporter.</Note>

<div id="the-canvas-and-the-live-app">
  ## Le canvas et l&#39;application en direct
</div>

Le canvas et la preview de l&#39;application en direct partagent le même volet, et quelques modes font le lien entre les deux :

* **Mode focus** : l&#39;action **Focus** sur un frame sélectionné l&#39;agrandit pour occuper toute la vue. Sélectionnez **Quitter le focus** en haut du tableau pour revenir au canvas.
* **Mode lecture seule** : lorsque le canvas est verrouillé dans un contexte de tâche en arrière-plan, les actions d&#39;itération sont masquées et seul Focus reste disponible.

<Note>
  Créer une nouvelle application à partir d&#39;un frame Design nécessite Core ou Pro ; toutes les autres fonctionnalités du canvas sont accessibles quel que soit le plan. Consultez [Facturation](/fr/billing/ai-billing) pour le détail des plans.
</Note>
