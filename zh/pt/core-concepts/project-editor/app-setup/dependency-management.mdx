Replit 提供多种方式来为您的 Replit App 安装和管理包。您可以使用 [Shell](/zh/pt/core-concepts/project-editor/editor-and-tools/shell) 安装包，请 [Agent](/zh/pt/core-concepts/agent/) 代为安装，或在运行 Replit App 时让 Replit 自动检测并安装缺失的依赖项。

<div id="instalar-pacotes-usando-o-shell">
  ## 使用 Shell 安装包
</div>

在项目编辑器中打开 **Shell** 工具，然后根据所用语言的包管理器运行相应命令：

<CodeGroup>
  ```bash Node.js (npm) theme={null}
  npm install <package-name>
  ```

  ```bash Node.js (pnpm) theme={null}
  pnpm add <package-name>
  ```

  ```bash Python (poetry) theme={null}
  poetry add <package-name>
  ```

  ```bash Python (pip) theme={null}
  pip install <package-name>
  ```

  ```bash Ruby theme={null}
  bundle add <gem-name>
  ```
</CodeGroup>

您还可以使用 [Replit 通用包管理器 (UPM)](https://github.com/replit/upm/) 在支持的语言中安装包：

```bash theme={null}
upm add <package-name>
```

要安装指定版本：

```bash theme={null}
upm add 'flask==2.3.3'
```

有关所有支持的编程语言和包管理器，请参阅 [UPM：支持的语言](https://github.com/replit/upm/#supported-languages)。

<div id="instalar-pacotes-usando-o-agent">
  ## 使用 Agent 安装包
</div>

您可以直接在 Chat 中让 [Agent](/zh/pt/core-concepts/agent/) 安装包。例如：

* “安装 axios 包”
* “将 Flask 和 SQLAlchemy 添加到我的项目中”
* “配置 TailwindCSS”

Agent 会使用适用于您项目的包管理器安装相应的包，并更新相关配置文件。

<div id="deteco-automtica-de-importaes">
  ## 自动导入检测
</div>

每次选择 **Run** 时，Replit 都会自动扫描代码，查找缺失的依赖项。如果代码导入了尚未安装的包，Replit 会检测并自动安装最新版本。

例如，如果您在 `main.py` 中添加 `import flask`，下次选择 **Run** 时，**Console** 会显示一条消息，提示正在安装 **Flask**。

<Note>
  您可以在 [.replit](/zh/pt/core-concepts/project-editor/app-setup/configuration#replit-file) 文件中，通过 `packager.features.guessImports` 配置自动导入检测。
</Note>

<div id="substituir-a-deteco-automtica">
  ### 替换自动检测
</div>

如果自动检测到的包有误，或您需要特定版本，请在 Shell 中运行相应的安装命令。例如：

```bash theme={null}
upm add 'flask==2.3.3'
```

<div id="gerenciadores-de-pacotes-python">
  ## Python 包管理器
</div>

创建 Python Replit App 时，默认使用的包管理器是 **poetry**。这意味着 `pip install` 不会管理你的依赖项。请改用 Shell 中的 `poetry add <package>` 或 `upm add <package>`。

<div id="alternar-do-poetry-para-o-pip">
  ### 从 poetry 切换到 pip
</div>

如果你更倾向于使用 `pip`，请按以下步骤操作：

<Steps>
  <Step>
    打开 Shell 并运行：

    删除锁定文件，以便将包管理工具切换为 pip：

    ```bash theme={null}
    rm poetry.lock
    ```
  </Step>

  <Step title="迁移依赖项">
    将 `pyproject.toml` 中 `[tool.poetry.dependencies]` 部分的依赖项迁移到 `requirements.txt`。例如，`flask = "^3.0.2"` 应改为 `flask>=3.0.2,<4`。
  </Step>

  <Step title="清理 pyproject.toml">
    删除 `pyproject.toml` 中的 `[tool.poetry...]` 部分。
  </Step>
</Steps>

完成这些更改后，包管理工具会在后续所有操作中使用 `pip`，自动导入检测也会继续正常运行。

<div id="dependncias-de-sistema-com-nix">
  ## 使用 Nix 配置系统依赖项
</div>

Replit 通过集成 [Nix](https://nixos.org/) 支持所有编程语言。如果需要标准语言包之外的系统级依赖项，可以将其添加到 [replit.nix](/zh/pt/core-concepts/project-editor/app-setup/configuration#replit-nix-file) 文件中。

<div id="pacotes-nix">
  ### Nix 包
</div>

直接编辑 `replit.nix` 即可添加系统级依赖项。你可以在 [search.nixos.org](https://search.nixos.org/packages) 中搜索可用的包。

<div id="mdulos">
  ### 模块
</div>

模块集成了编程语言、格式化工具和打包工具支持，是 Replit App 的基础。通过模板或 GitHub 仓库创建 Replit App 时，Replit 会自动安装所需模块。

你可以使用 [.replit](/zh/pt/core-concepts/project-editor/app-setup/configuration#replit-file) 文件自定义模块及其他 Nix 配置。

<div id="configurao-do-empacotador">
  ## packager 配置
</div>

您可以在 [.replit](/zh/pt/core-concepts/project-editor/app-setup/configuration#replit-file) 文件中调整包管理行为：

| 配置                                    | 描述               | 默认值     |
| ------------------------------------- | ---------------- | ------- |
| `packager.language`                   | 用于包操作的语言       | 自动检测    |
| `packager.features.guessImports`      | 运行时自动检测并安装缺失的包 | `true`  |
| `packager.features.packageSearch`     | 启用包搜索功能        | `true`  |
| `packager.features.enabledForHosting` | 托管时要求安装包       | `false` |
| `packager.afterInstall`               | 安装包后执行的命令      | —       |
| `packager.ignoredPaths`               | 导入检测时要忽略的路径      | `[]`    |
| `packager.ignoredPackages`            | 排除在自动检测之外的包    | `[]`    |
