<Note>
  Хотите сделать SSO обязательным для вашей **организации Replit** (вход на replit.com)? Это настраивается отдельно — см. [Единый вход (SAML SSO)](/ru/teams/identity-and-access-management/saml). Эта страница посвящена добавлению SSO в процесс входа **в приложение, которое создаёте вы** на Replit.
</Note>

Дайте пользователям возможность входить в ваше приложение через корпоративного поставщика идентификации, например Okta или Microsoft Entra ID. Если ваше приложение использует [Clerk Auth](/ru/features/auth-and-identity/clerk-auth), то SSO и другие расширенные функции аутентификации настраиваются через Clerk Dashboard. Опишите Agent, что вам нужно, и он направит вас в панель управления, чтобы завершить настройку.

</Frame>

Возможности Clerk Dashboard выходят далеко за рамки стандартного процесса входа. Любые изменения, внесённые в Clerk, автоматически применяются к аутентификации вашего приложения на Replit.

<div id="what-you-can-configure">
  ## Что можно настроить
</div>

* **Подключения Enterprise SSO**: настройте единый вход через Okta или Microsoft Entra ID по протоколу OIDC или SAML. Дайте клиентам возможность входить под корпоративной учётной записью. SSO также защищает внутренние инструменты, работающие с конфиденциальными данными: вместо ручных списков разрешённых адресов электронной почты используется провайдер идентификации, уже развёрнутый в вашей компании.
* **Многофакторная аутентификация (MFA)**: добавьте MFA в процесс входа в приложение.
* **Управление сессиями**: настройте длительность сессий и частоту повторной проверки.
* **Другие настройки Clerk**: остальные параметры Clerk применяются к вашему приложению Replit автоматически. Не изменяйте ключи API и параметры окружения — ими управляет Replit. См. раздел [Среды разработки и продакшена](/ru/features/auth-and-identity/clerk-auth#development-and-production-environments).

<div id="open-the-clerk-dashboard">
  ## Откройте Clerk Dashboard
</div>

Опишите Agent нужное вам изменение в аутентификации. Agent настроит всё, что сможет, и направит вас в Clerk Dashboard вашего приложения для параметров, которые требуют вашего участия.

<Frame>
  <img src="/assets/mirror/build-with-sso-agent-workflow-46422788bd18.webp" alt="Agent направляет приложение на базе Clerk к настройке корпоративного SSO в Clerk Dashboard." width="1602" height="1080" data-path="images/workspace/auth/build-with-sso-agent-workflow.webp" />
</Frame>

Открыть панель управления можно и из Workspace:

1. На панели Tools выберите **Users &amp; Auth**.
2. Перейдите на вкладку **Configure**.
3. Выберите **Advanced**.
4. В разделе **Clerk dashboard** нажмите **Open Clerk dashboard**.

<Frame>
  <img src="/assets/mirror/open-clerk-dashboard-tools-pane-a314ffea741d.webp" alt="Инструмент Users & Auth с открытой вкладкой Configure, где показан раздел Advanced и кнопка Open Clerk dashboard." width="2158" height="1372" data-path="images/workspace/auth/open-clerk-dashboard-tools-pane.webp" />
</Frame>

<div id="set-up-an-enterprise-sso-connection">
  ## Настройка корпоративного SSO-подключения
</div>

1. В Clerk Dashboard выберите **Configure**.
2. В разделе **User &amp; authentication** выберите **SSO connections**.
3. Выберите **Enterprise**.
4. Выберите **Add connection**.

<Frame>
  <img src="/assets/mirror/build-with-sso-enterprise-connections-b0a6a27885b5.webp" alt="Clerk Dashboard со страницей корпоративных SSO-подключений и действием «Add connection»." width="1826" height="1080" data-path="images/workspace/auth/build-with-sso-enterprise-connections.webp" />
</Frame>

Полное описание настройки подключения см. в [документации Clerk](https://clerk.com/docs).

<div id="validate-the-connection">
  ### Проверка подключения
</div>

После завершения настройки войдите под тестовой учётной записью вашего провайдера идентификации. Убедитесь, что она имеет доступ к нужным разделам приложения.

Если войти не удаётся, обратитесь за помощью к Agent. Укажите в запросе провайдера идентификации, протокол и текст ошибки.

<Note>
  На этой странице описан корпоративный SSO для собственного процесса входа в ваше приложение. О входе через социальные сети — Google, GitHub, Apple или X (в Workspace они обозначены как **SSO providers**) — см. [Провайдеры входа](/ru/features/auth-and-identity/sign-in-providers). Миграция на Replit Auth и вход по SAML для учётных записей Replit здесь не рассматриваются.
</Note>

<div id="pricing-and-availability">
  ## Стоимость и доступность
</div>

Доступ к Clerk Dashboard предоставляется на плане [Replit Pro](/ru/billing/plans/replit-pro). Планы Enterprise появятся в ближайшее время.

<Info>
  SSO-подключения Enterprise бесплатны до 1 октября 2026 года. После этой даты стоимость SSO соответствует тарифам Clerk и включается в ваш счёт Replit.
</Info>
