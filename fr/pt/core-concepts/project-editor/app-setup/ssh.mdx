<div id="o-que-ssh">
  ## Qu’est-ce que SSH ?
</div>

SSH, qui signifie Secure Shell, est un protocole sécurisé qui facilite l’accès à distance à l’interface en ligne de commande de votre Replit App. Avec SSH, vous pouvez facilement transférer des fichiers et utiliser votre environnement de développement intégré (IDE) local préféré pour modifier du code sur Replit, ce qui améliore la collaboration et la productivité dans votre flux de développement.

La fonctionnalité SSH est disponible avec les forfaits Core, Pro et tous les autres forfaits payants.

Voici un aperçu du processus :

* Générez une paire de clés SSH sur votre machine locale
* Ajoutez cette clé SSH au panneau **SSH** de n’importe quelle Replit App
* Connectez-vous à l’aide d’un client SSH ou d’un éditeur compatible SSH (comme [VSCode](https://code.visualstudio.com/) ou [Cursor](https://www.cursor.com/))

<Note>
  Les clés SSH sont associées à votre compte, et non à une Replit App spécifique. Vous n’avez donc besoin d’ajouter une clé publique qu’une seule fois, après quoi vous pouvez vous connecter à toute Replit App à laquelle vous avez accès.
</Note>

<div id="por-que-usar-ssh">
  ## Pourquoi utiliser SSH ?
</div>

* **Mises à jour automatiques entre la Replit App et l’éditeur** : toute modification effectuée dans la Replit App est instantanément répercutée dans votre éditeur, et inversement. Cette synchronisation continue garantit que votre code est toujours à jour sur toutes les plateformes.

* **Synchronisation de la gestion des fichiers** : que vous ajoutiez, supprimiez ou mettiez à jour des fichiers, ces modifications sont synchronisées en temps réel entre votre éditeur et la Replit App. Cette fonctionnalité garantit que la structure de votre projet reste cohérente, quel que soit l’endroit où les modifications sont effectuées.

* **Gestion des dossiers et déplacement des fichiers** : le déplacement de fichiers entre les dossiers est également synchronisé entre vos éditeurs et la Replit App. Ainsi, les changements d’organisation effectués dans un environnement sont fidèlement répercutés dans l’autre, tout en préservant l’intégrité et la structure de votre projet.

<div id="encontrar-ou-criar-um-par-de-chaves">
  ## Rechercher ou créer une paire de clés
</div>

Pour configurer SSH pour votre compte, vous aurez besoin de votre clé publique SSH.

<div id="verificar-se-voc-j-tem-um-par-de-chaves">
  ### Vérifier si vous disposez déjà d’une paire de clés
</div>

Pour vérifier si vous avez déjà une clé publique, exécutez la commande suivante dans un terminal sur votre machine locale :

<Tabs>
  <Tab title="Mac/Linux">
    ```sh theme={null}
    ls -l ~/.ssh
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    dir %HOMEPATH%\.ssh
    ```
  </Tab>
</Tabs>

Si vous obtenez une erreur, ce n’est pas grave ; passez à [Générer une nouvelle paire de clés](#generating-a-new-keypair).
Si vous voyez un fichier nommé `replit.pub`, passez à [Obtenir le contenu de votre clé publique](#get-the-contents-of-your-public-key).

<div id="gerando-um-novo-par-de-chaves">
  ### Générer une nouvelle paire de clés
</div>

Sur votre machine, ouvrez une fenêtre de terminal (ou d’invite de commandes), puis collez la commande suivante :

<Tabs>
  <Tab title="Mac/Linux">
    ```bash theme={null}
    ssh-keygen -t ed25519 -f ~/.ssh/replit -q -N ""
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    ssh-keygen -t ed25519 -f %HOMEPATH%\.ssh\replit -q -N ""
    ```
  </Tab>
</Tabs>

Cette commande vérifie si un fichier de clé publique SSH spécifique existe déjà. Sinon, elle crée une nouvelle clé SSH avec des paramètres appropriés.

<div id="obter-o-contedo-da-sua-chave-pblica">
  ### Obtenir le contenu de votre clé publique
</div>

Après avoir vérifié que vous disposez d&#39;une paire de clés ou en avoir créé une, affichez le contenu de la clé publique (l&#39;un des deux fichiers aux noms similaires, avec le suffixe `.pub`), car vous en aurez besoin plus tard.

<Tabs>
  <Tab title="Mac/Linux">
    ```sh theme={null}
    cat ~/.ssh/replit.pub
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    notepad %HOMEPATH%\.ssh\replit.pub
    ```
  </Tab>
</Tabs>

Enregistrez le contenu de `replit.pub` pour l&#39;utiliser plus loin dans cet article, puis passez à [l&#39;ajout de la clé SSH à votre compte](#add-the-ssh-key-to-your-account).

<div id="adicionar-a-chave-ssh-sua-conta">
  ## Ajouter la clé SSH à votre compte
</div>

<div id="adicionar-a-chave-pblica-diretamente-em-um-replit-app-usando-o-painel-ssh">
  ### Ajoutez la clé publique directement dans une Replit App à l’aide du panneau SSH
</div>

1. Dans votre Replit App, quelle que soit la fenêtre, sélectionnez le bouton **+** et recherchez **SSH**.

<Frame>
  <img src="/assets/mirror/ssh-tool-2db02c6a83d0.png" alt="Bouton de l’outil SSH dans l’interface Replit" width="846" height="328" data-path="images/ssh-vscode/ssh-tool.png" />
</Frame>

2. Accédez à l’onglet **Keys** et sélectionnez **New SSH key**.
3. Dans la fenêtre contextuelle, saisissez un **Label** pour votre clé (par exemple, my-ssh-key), puis collez la clé publique que vous avez copiée dans la section **Key**.
   Sélectionnez le bouton **Add SSH Key**. Votre clé est alors ajoutée et autorisée à être utilisée.

<Frame>
  <img src="/assets/mirror/add-ssh-key-with-values-5d6f440e56ba.png" alt="Boîte de dialogue d’ajout de clé SSH avec les champs de libellé et de clé remplis" width="500" height="511" data-path="images/ssh-vscode/add-ssh-key-with-values.png" />
</Frame>

<div id="adicionar-a-chave-pblica-diretamente-nas-configuraes">
  ### Ajouter la clé publique directement dans les paramètres
</div>

Vous pouvez également ajouter une clé SSH en ouvrant **Settings** et en sélectionnant **Advanced** dans **Account** (ou l’option **SSH keys**). Sélectionnez **Add SSH key**, puis collez le contenu de `replit.pub` indiqué dans la section précédente, [Trouver ou créer une paire de clés](#find-or-create-a-keypair).

<Note>
  Si vous disposez de plusieurs clés publiques sur votre machine, assurez-vous d’utiliser la bonne paire de clés privée et publique pour votre configuration SSH.
</Note>

<div id="conectando-ao-seu-replit-app">
  ## Se connecter à votre Replit App
</div>

<div id="configurar-seu-ssh-config">
  ### Configurer votre fichier de configuration SSH
</div>

1. Dans un terminal, vérifiez que le répertoire `~/.ssh` et le fichier `~/.ssh/config` existent :

<Tabs>
  <Tab title="Mac/Linux">
    ```sh theme={null}
    mkdir -p ~/.ssh && chmod 700 ~/.ssh && touch ~/.ssh/config && chmod 600 ~/.ssh/config
    open -a 'TextEdit' ~/.ssh/config || nano ~/.ssh/config
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    if not exist %HOMEPATH%\.ssh mkdir %HOMEPATH%\.ssh && type \NUL > %HOMEPATH%\.ssh\config
    notepad %HOMEPATH%\.ssh\config
    ```
  </Tab>
</Tabs>

2. Ajoutez un bloc de configuration afin d’utiliser la paire de clés `replit` pour tous les domaines *.replit.dev :

<Tabs>
  <Tab title="Mac/Linux/Windows">
    ```
    Host *.replit.dev
        Port 22
        IdentityFile ~/.ssh/replit
        StrictHostKeyChecking accept-new
    ```
  </Tab>
</Tabs>

<div id="conectar-pelo-vscode-ou-cursor">
  ### Se connecter avec VS Code ou Cursor
</div>

1. Dans une Replit App, ouvrez le panneau **SSH**

2. Dans le panneau SSH, accédez à l’onglet **Connect** et sélectionnez **Launch VS Code**.

<Tabs>
  <Tab title="Se connecter avec VS Code">
    <img src="/assets/mirror/ssh-connect-439a3c150846.png" alt="Onglet de connexion SSH affichant l’option Launch VS Code" width="788" height="482" data-path="images/ssh-vscode/ssh-connect.png" />
  </Tab>
</Tabs>

3. Si vous êtes invité à renseigner `~/.ssh/config`, saisissez ce qui suit :

   ```
   Host *.replit.dev
       Port 22
       IdentityFile ~/.ssh/replit
       StrictHostKeyChecking accept-new
   ```

   <Note>
     L’ajout de la configuration SSH n’est demandé que lors de votre première tentative de connexion à VS Code ou à un autre éditeur. Pour revenir au fichier de configuration, sélectionnez **Configure SSH Hosts...**.
   </Note>

4. Si une invite d’application externe s’affiche, sélectionnez **Yes** pour confirmer que vous souhaitez ouvrir votre projet dans l’éditeur de votre choix ou dans VS Code.

5. Il se peut que vous soyez régulièrement invité à installer ou à mettre à jour des extensions SSH. Replit s’efforcera de rester compatible avec les versions les plus récentes de ces IDE, et vous pourrez également recevoir d’importantes mises à jour de sécurité.

<div id="conectar-manualmente">
  ### Se connecter manuellement
</div>

En bas de l’onglet &quot;Connect&quot; du panneau **SSH**, vous trouverez &quot;Connect manually&quot;.

Copiez cette commande, puis collez-la dans un terminal local (Mac ou Linux) ou une invite de commandes locale (Windows) pour vous connecter directement.

C’est également un bon moyen de déboguer les problèmes de connexion avec les IDE et de recueillir de précieuses informations de connexion &quot;détaillées&quot; lorsque vous signalez des bugs à l’assistance de Replit.

<div id="conectar-via-uma-ferramenta-no-listada-aqui">
  ### Se connecter à l’aide d’un outil non répertorié ici
</div>

De nombreux clients SSH sont disponibles pour différentes plateformes et systèmes d’exploitation, et nombre d’entre eux offrent diverses fonctionnalités ou intégrations.

Vous pouvez toujours décomposer la commande affichée dans &quot;Connect Manually&quot; afin d’identifier ses composants et de déterminer comment configurer chaque client :

```sh theme={null}
ssh -i ~/.ssh/replit -p 22  c96b6ade-d5e4-4f7a-bc5b-52334509b2a3@c96b6ade-d5e4-4f7a-bc5b-52334509b2a3-00-16nh2hskw3ql8.riker.replit.dev
       ^-----v-----^    ^^  ^-----------------v----------------^ ^------------------------------v-------------------------------------^
        Private Key   Port                   User               @                           Hostname
```

**Nom d&#39;hôte** : `<seu_hostname>.<cluster>.replit.dev`
**Port** : `<número_da_porta>`
**Utilisateur** : `Nome de usuário`
**Clé privée** : chemin d&#39;accès au fichier de clé privée sur votre ordinateur, généralement situé près de `replit.pub`.
