<div id="o-que-esperar">
  ## 预期情况

Agent 会将每个页面与上一版本进行比较，生成简短的“变更内容”摘要，并
更新 Notion。在通知销售团队之前，请先在正式网站上确认变更。页面重新设计后的头几天，通知可能会比较频繁；请明确哪些变更算作
重要变更。当 Slack 发出通知时，请打开正式 URL，亲自核查变更后再
转发。

<div id="soluo-de-problemas">
  ## 故障排除
</div>

* **每次改版都像是价格变动：**告诉 Agent 需要跟踪哪些页面 (定价、更新日志、功能) ，以及哪些变更算作相关变更。通知销售团队前，先在正式网站上确认变更。
* **始终没有触发提醒：**页面可能无法访问，或者竞争对手列表过于狭窄。提供完整 URL，并让 Agent 在无法加载页面时通知你。
* **Notion 变成一堆零散笔记：**让 Agent 使用一个统一的竞争情报页面，并让它直接在该页面更新，而不是每天早上都新建一个页面。
