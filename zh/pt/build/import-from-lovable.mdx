<div id="importar-do-lovable">
  ## 从 Lovable 导入
</div>

⏰ *预计用时：四分钟*

先将 Lovable 项目导出到 GitHub，再导入该仓库，即可将其导入 Replit。

如需了解包括 GitHub、Figma 和 Bolt 等其他平台在内的完整导入选项，请参阅[导入功能文档](/zh/pt/references/workspace/import)。

<div id="antes-de-comear">
  ## 开始前
</div>

* 可导出的 Lovable 项目
* 已关联 Lovable 的 GitHub 账户
* Replit 账户

<div id="etapas-de-importao">
  ## 导入步骤
</div>

1. 将您的项目从 Lovable 导出到 GitHub。
2. 打开 [replit.com/import](https://replit.com/import)。
3. 选择 **Lovable**。
4. 连接您的 GitHub 帐户。
5. 选择从 Lovable 导出的仓库。
6. 选择 **Import**。

<div id="what-gets-imported">
  ## 导入的内容
</div>

Replit 会从你的 {platform_1} 项目中导入以下内容：

* **代码**：应用逻辑和源文件
* **设计和样式**：UI 组件和样式规则
* **资源**：图片、图标和静态文件
* **后端逻辑**：服务器端功能 (如有)
* **数据库架构**：表结构 (如有)

<div id="what-is-not-imported">
  ## 不会导入的内容
</div>

* **Supabase 数据**：不会迁移现有的数据库记录
* **Secrets**：需要单独添加环境变量和 API 密钥

使用 Agent 重建缺失的功能、添加 Secrets，并重新创建数据库中的数据。
