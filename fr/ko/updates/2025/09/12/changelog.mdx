export const YouTubeEmbed = ({videoId, title = "Vidéo YouTube", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

<div id="agent-3">
  ## Lancement d&#39;Agent 3
</div>

Cette semaine, nous avons lancé Agent 3.

<YouTubeEmbed videoId="4FxNXFOdt6w" title="Agent 3 Launch Livestream" />

Agent 3 apporte des améliorations majeures en matière d&#39;autonomie, de fiabilité et de rapidité :

* **Test des applications** : Agent se teste lui-même dans un véritable navigateur afin de détecter les problèmes et de les corriger par itérations successives. Consultez [Test des applications](/fr/core-concepts/agent/app-testing).
* **Durée d&#39;exécution prolongée** : grâce à la surveillance en direct, Agent peut travailler de manière autonome jusqu&#39;à 200 minutes, ce qui convient parfaitement aux projets d&#39;envergure. Pour en savoir plus, consultez [Agent](/fr/core-concepts/agent#max-autonomy).
* **Création d&#39;agents** : créez des agents et des automatisations qui s&#39;exécutent selon une planification ou s&#39;intègrent à Slack et Telegram. Consultez [Agents et automatisations](/fr/core-concepts/agent/agents-and-automations).

<div id="section">
  ## Connecteurs et intégrations d&#39;applications
</div>

Déployez plus rapidement grâce aux intégrations et connecteurs intégrés :

* **Géré par Replit** : intégrations natives qui fonctionnent automatiquement dans vos applications.
* **connecteurs** : intégrations propriétaires qui vous permettent de vous connecter une seule fois, puis de réutiliser la connexion dans toutes vos applications.
* **Intégrations externes** : services tiers fiables configurés par Agent à l&#39;aide de clés API.

<div id="section-2">
  ## Agents et automatisations (bêta)
</div>

Dans le cadre d&#39;Agent 3, créez des agents intelligents, des chatbots et des workflows automatisés :

* **Agents Slack** : créez des bots Slack pour la recherche documentaire, les questions-réponses et l&#39;automatisation
* **Agents Telegram** : créez des bots pour la gestion d&#39;agenda, l&#39;assistance, etc.
* **Automatisations temporelles** : exécutez des workflows planifiés à intervalles réguliers
