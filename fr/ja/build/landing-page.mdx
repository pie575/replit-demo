Une immense section d’accueil avec une photo dramatique en gros plan d’une femme forte et athlétique, éclairée par une lumière dorée chaude sur fond noir. À gauche, sur la zone sombre, place un immense titre sur trois lignes :

export const PromptActions = ({prompt = "", campaign = "docs-prompt-actions"}) => {
  const LZ_SRC = "https://cdnjs.cloudflare.com/ajax/libs/lz-string/1.5.0/lz-string.min.js";
  const ensureLZString = () => {
    if (typeof document === "undefined") return;
    if (window.LZString) return;
    if (document.querySelector(`script[src="${LZ_SRC}"]`)) return;
    const s = document.createElement("script");
    s.src = LZ_SRC;
    s.async = true;
    document.head.appendChild(s);
  };
  const handleCopy = async e => {
    const btn = e.currentTarget;
    if (!prompt) return;
    try {
      await navigator.clipboard.writeText(prompt);
    } catch {
      const ta = document.createElement("textarea");
      ta.value = prompt;
      document.body.appendChild(ta);
      ta.select();
      try {
        document.execCommand("copy");
      } catch {}
      document.body.removeChild(ta);
    }
    const original = btn.dataset.label || btn.innerText;
    btn.dataset.label = original;
    btn.innerText = "Copié !";
    setTimeout(() => {
      if (btn.isConnected) btn.innerText = original;
    }, 1500);
  };
  const handleBuild = () => {
    if (!prompt || typeof window === "undefined") return;
    const utm = `utm_source=replit-docs&utm_medium=docs&utm_campaign=${encodeURIComponent(campaign)}&utm_content=prompt-actions`;
    let url;
    if (window.LZString) {
      const encoded = window.LZString.compressToEncodedURIComponent(prompt);
      url = `https://replit.com/?prompt=${encoded}&referrer=replit-docs&${utm}`;
    } else {
      url = `https://replit.com/?prompt=${encodeURIComponent(prompt)}&referrer=replit-docs&${utm}`;
    }
    window.open(url, "_blank", "noopener,noreferrer");
  };
  ensureLZString();
  const baseButtonStyle = {
    display: "inline-flex",
    alignItems: "center",
    gap: "6px",
    padding: "8px 16px",
    borderRadius: "8px",
    fontSize: "14px",
    fontWeight: 500,
    cursor: "pointer",
    lineHeight: 1.2,
    fontFamily: "inherit",
    textDecoration: "none"
  };
  return <div style={{
    display: "flex",
    gap: "12px",
    margin: "16px 0",
    flexWrap: "wrap",
    alignItems: "center"
  }}>
      <button type="button" onClick={handleCopy} style={{
    ...baseButtonStyle,
    background: "transparent",
    color: "inherit",
    border: "1px solid rgba(127,127,127,0.4)"
  }}>
        Copier le prompt
      </button>
      <button type="button" onClick={handleBuild} style={{
    ...baseButtonStyle,
    background: "#F26207",
    color: "#FFFFFF",
    border: "1px solid #F26207"
  }}>
        Build sur Replit ↗
      </button>
    </div>;
};

<div id="section">
  ## Ce que vous apprendrez
</div>

Vous apprendrez à :

* Transformer votre audience, votre offre et votre appel à l’action en une page.
* Demander à Agent de créer le contenu, la mise en page et le comportement du formulaire de votre page.
* Vérifier la clarté de votre page avant de la partager.
* Tester votre formulaire depuis son URL publique.
* Améliorer votre page en fonction de la qualité des réponses.

<div id="canvas">
  ## Explorer les améliorations et les alternatives dans Canvas
</div>

Une fois qu’Agent a terminé la première version, ouvrez Canvas pour donner votre avis visuellement et demander à Agent d’explorer d’autres pistes sans réécrire votre prompt.

<Steps>
  <Step title="Créer une page de destination">
    Copiez le prompt et collez-le dans la zone de saisie sur [replit.com](https://replit.com), ou cliquez sur **Build on Replit** pour ouvrir Replit avec le prompt prérempli.

    <PromptActions prompt={RACHEL_JONES_PROMPT} campaign="docs-landing-page" />
  </Step>

  <Step title="Prévisualiser l’application créée par Agent">
    Une fois Agent terminé, le volet de droite bascule vers **Preview**, où vous pouvez interagir avec votre page de destination en temps réel. Avant de commencer les améliorations, faites défiler la section héros, cliquez sur les appels à l’action et vérifiez que le texte et les images correspondent à votre demande.

    <Frame>
      <img src="/assets/mirror/landing-preview-4855c4b25270.png" alt="Page de destination de Rachel Jones, coach de fitness, affichée dans le volet Replit Preview à côté du chat Agent — section héros sombre au style éditorial avec le titre « Un corps plus fort. Un esprit confiant. Vous, sans limites. » sur un portrait éclairé de tons dorés, boutons Travailler avec Rachel et Voir l’histoire de Rachel, certifications à droite et bandeau cinq étoiles « Approuvée par plus de 500 femmes dans le monde »" width="3452" height="1988" data-path="images/fitstart/launch-landing-page/landing-preview.png" />
    </Frame>
  </Step>

  <Step title="Ouvrir Canvas">
    Sélectionnez le bouton **Canvas** sous les onglets Preview et Tools pour remplacer Preview par Canvas dans le volet droit.

    <Frame>
      <img src="/assets/mirror/landing-canvas-button-494c5b0076b1.png" alt="Espace de travail Replit avec le bouton Canvas sous les onglets Preview et Tools mis en évidence" width="720" height="450" data-path="images/fitstart/launch-landing-page/landing-canvas-button.png" />
    </Frame>
  </Step>

  <Step title="Ajouter des annotations en dehors de l’aperçu">
    Utilisez les outils **Texte** et **Draw** de Canvas pour ajouter des notes et des flèches dans l’espace vide autour de votre maquette afin d’indiquer les éléments précis à modifier. Les annotations placées sur le Canvas (en dehors de l’aperçu) restent associées à vos commentaires afin qu’Agent puisse les lire avec votre design.

    Limitez chaque annotation à une seule modification. Les notes courtes et précises (« Réduisez la largeur de ce bouton ») sont plus efficaces que les commentaires trop généraux.

    <Frame>
      <img src="/assets/mirror/landing-canvas-annotate-text-8135bfe1e8e2.png" alt="Une annotation Canvas « Réduisez la largeur de ce bouton » placée dans la marge droite du Canvas de la page de destination de Rachel Jones, avec une flèche pointant vers le bouton doré « Book a Free Consultation » dans l’en-tête de la page" width="3452" height="1988" data-path="images/fitstart/launch-landing-page/landing-canvas-annotate-text.png" />
    </Frame>
  </Step>

  <Step title="Sélectionnez les annotations et l’aperçu, puis envoyez-les à Agent">
    Sélectionnez les annotations et les frames d’aperçu par sélection à la souris, puis saisissez un court prompt dans **Chat about selected items** et envoyez-le. Agent interprète les annotations et le design comme un seul contexte, ce qui lui permet de savoir à quel élément chaque note fait référence.

    Gardez le message de chat général — par exemple : « Appliquez les modifications indiquées dans les annotations. » Les annotations contiennent les détails.

    <Frame>
      <img src="/assets/mirror/landing-canvas-send-24b771bf29bf.png" alt="Page de destination Rachel Jones sélectionnée sur Canvas avec deux annotations : « Reduce the width of this button » pointant vers le bouton Book a Free Consultation et « Add a slide-in animation for Rachel's image » pointant vers la photo principale, avec un prompt de chat saisi dans le champ Chat about selected items" width="1726" height="1988" data-path="images/fitstart/launch-landing-page/landing-canvas-send.png" />
    </Frame>
  </Step>

  <Step title="Explorer différentes pistes">
    Cliquez sur un design dans Canvas, puis sélectionnez une suggestion affichée à côté, telle que **Explore different approaches**, pour demander à Agent d’explorer d’autres pistes visuelles.

    <Frame>
      <img src="/assets/mirror/landing-canvas-reimagine-9e60c24f342f.png" alt="Trois pistes alternatives de pages de destination générées sous forme de frames Design dans Canvas, à côté de l’original" width="1726" height="994" data-path="images/fitstart/launch-landing-page/landing-canvas-reimagine.png" />
    </Frame>
  </Step>

  <Step title="Examinez les alternatives et itérez">
    Attendez qu’Agent génère le résultat. **Explore different approaches** met à jour le même artefact avec une nouvelle variante — vous pouvez passer de l’une à l’autre depuis le menu déroulant de l’artefact au-dessus de la maquette. **Explore different vibes** génère des maquettes visuelles distinctes à côté de l’original sur Canvas.

    Une fois les variantes prêtes, choisissez une piste et poursuivez les itérations. Ajoutez d’autres annotations au frame sélectionné, effectuez une sélection par cadre incluant les annotations et le design, puis envoyez une nouvelle demande — par exemple, « Appliquez les modifications demandées dans les annotations ». Agent utilise le contexte de la variante et les nouvelles annotations dans un même prompt.

    <Frame>
      <img src="/assets/mirror/landing-canvas-zoomed-4d1585d33fe6.png" alt="La page de destination Rachel Jones sur Canvas après qu’Agent a généré trois variantes d’ambiance (Editorial Warmth, Quiet Clinical, Vibrant Pop) — le frame original est sélectionné avec deux nouvelles annotations (« Réduisez la largeur de ce bouton » et « Ajoutez une animation d’entrée en glissement pour l’image de Rachel »), et le chat contient « Appliquez les modifications demandées dans les annotations »" width="3452" height="1988" data-path="images/fitstart/launch-landing-page/landing-canvas-zoomed.png" />
    </Frame>
  </Step>

  <Step title="Publier votre travail">
    Une fois que la page fonctionne dans Preview, cliquez sur **Publier** (puis sur **Republish** pour les déploiements ultérieurs) en haut à droite de l’espace de travail afin de mettre à jour l’URL publique avec la dernière version. Ouvrez l’URL publique dans un nouvel onglet et envoyez une réponse de test sur la page en ligne avant de la partager afin de vérifier qu’elle est bien enregistrée.

    <Frame>
      <img src="/assets/mirror/landing-publish-e3b901a79440.png" alt="Coin supérieur droit de l’espace de travail Replit affiché avec un zoom 2× — le bouton gris Republish dans l’en-tête est mis en évidence par un contour orange, et la fenêtre contextuelle en dessous affiche « Raouf a publié il y a environ 18 heures », Visibilité : Public, ainsi que les boutons d’action Vérifier la sécurité et Republish" width="2142" height="1072" data-path="images/fitstart/launch-landing-page/landing-publish.png" />
    </Frame>
  </Step>
</Steps>
