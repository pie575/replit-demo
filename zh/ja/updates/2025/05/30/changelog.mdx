<div id="section-2">
  ## 平台更新
</div>

<div id="section-3">
  ### 预览空状态优化
</div>

使用 Agent 构建时，Agent 应用的预览会更智能地处理空状态和自动运行，让工作流更加顺畅。

<div id="ai">
  ### AI 延迟优化
</div>

得益于基础设施的改进，Replit AI 的响应时间和延迟大幅降低。在使用 Agent、Assistant 等 Replit AI 功能时，你将获得更流畅快速的交互体验。

<div id="github">
  ### 统一的 GitHub 标签页焕新
</div>

GitHub 集成标签页的界面更简洁、更统一。全新设计让你在 Workspace 中连接和管理 GitHub 仓库更加直观。

<div id="ios">
  ### iOS 应用内支付支持
</div>

iOS 用户现在可以直接在 Replit 移动应用中购买 Replit Core 并设置支付方式，外出时也能更轻松地使用高级功能。

<div id="stripe">
  ### Stripe 结账流程发布
</div>

全新的 Stripe 结账流程集成为所有开发者带来更流畅、更安全的支付体验。借助业界标准的支付解决方案，升级到 Replit Core 更加简单，购买流程也更为顺畅。

  ## 团队与企业版

<div id="scim">
  ### 简化 SCIM 预配流程
</div>

改进后的 SCIM 账户预配流程大幅简化了企业用户的入职过程。新用户无需任何手动步骤即可自动完成配置，为 Replit 上不断壮大的企业 Teams 带来顺畅无阻的体验。
