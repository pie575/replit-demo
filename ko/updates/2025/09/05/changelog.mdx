<div id="general-agent">
  ### General Agent
</div>

<Frame>
  <img src="/assets/mirror/general-agent-240ff289e711.png" alt="General Agent 대표 일러스트" width="1040" height="572" data-path="images/replitai/general-agent.png" />
</Frame>

이제 Replit Agent가 NixOS에서 실행되는 모든 언어와 프레임워크의 codebase에서 작동합니다! 이전에는 특정 template에서만 사용할 수 있었지만, 이제 Agent는 Developer Frameworks, GitHub import는 물론 직접 구성한 project 설정까지 지원합니다. 이번 확장으로 엔터프라이즈와 파워 유저 workflow에도 완전한 AI 코딩 지원을 사용할 수 있습니다.

General Agent에 대한 자세한 내용은 [여기](/ko/core-concepts/agent/general-agent)에서 확인하세요.

<div id="plan-mode">
  ### Plan mode
</div>

<Frame>
  <img src="/assets/mirror/plan-mode-overview-8077807c63b9.png" alt="Plan mode의 Agent chat 인터페이스" width="916" height="362" data-path="images/replitai/plan-mode-overview.png" />
</Frame>

Plan mode는 질문, brainstorming, 작업 계획에 초점을 맞춘 새로운 방식으로 Replit Agent와 대화할 수 있게 해줍니다. Plan mode에서는 Agent로 앞으로 진행할 작업의 할 일 목록을 만든 뒤, build mode에서 장시간 실행되는 task를 처리할 수 있습니다.

Plan mode에 대한 자세한 내용은 [여기](/ko/core-concepts/agent/plan-mode)에서 확인하세요.

<div id="gcp-marketplace-integration">
  ### GCP Marketplace 연동
</div>

이제 Enterprise 고객은 Google Cloud Platform Marketplace에서 Replit을 직접 구매하고, 보유 중인 GCP 크레딧으로 결제할 수 있습니다. 구매 절차가 간소화되어 GCP 예산을 보유한 조직이 개발 workflow에 Replit을 더욱 손쉽게 도입할 수 있습니다.
