Генерация изображений позволяет создавать уникальный визуальный контент без навыков дизайна и внешних инструментов. Создавайте всё: от иконок и иллюстраций до фонов и элементов UI — прямо в процессе разработки.

<div id="recursos">
  ## Возможности
</div>

Создавайте визуально привлекательные приложения с помощью генерации изображений в Agent. Вам больше не понадобятся стоковые фотографии, внешние инструменты для дизайна или дизайнеры для создания базового визуального контента. Создаёте ли вы сайт-портфолио, игру или интерфейс мобильного приложения, генерация изображений позволяет получать уникальные визуальные материалы, адаптированные к вашему проекту.

Agent поддерживает следующие возможности генерации изображений:

* **Создание уникальных изображений**: Генерируйте изображения на основе подробных описаний и спецификаций
* **Адаптация стиля**: Создавайте изображения в различных художественных стилях — от реалистичных до мультяшных
* **Интеграция с проектом**: Легко добавляйте сгенерированные изображения прямо в кодовую базу вашего приложения
* **Итеративное улучшение**: Изменяйте и улучшайте изображения на основе ваших отзывов

<div id="uso">
  ## Использование
</div>

Генерация изображений встроена в Agent — ничего включать не нужно. Откройте любое Replit App с включённым Agent и попросите его создать нужный визуальный контент. Agent автоматически определяет по вашим запросам, когда нужно генерировать изображения, и создаёт персонализированные изображения в соответствии с вашими требованиями.

<div id="quando-o-agent-usa-a-gerao-de-imagens">
  ### Когда Agent использует генерацию изображений
</div>

Agent запускает генерацию изображений, когда вы запрашиваете визуальный контент для своих проектов:

| Сценарий использования           | Пример prompt                                                                |
| -------------------------------- | ---------------------------------------------------------------------------- |
| **Значки и логотипы приложений** | &quot;Создай современный логотип для моего фитнес-трекера&quot;              |
| **Фоны для сайтов**              | &quot;Создай сдержанный градиентный фон для моего сайта-портфолио&quot;      |
| **Ассеты для игр**               | &quot;Создай пиксельные спрайты для моей платформенной игры&quot;            |
| **Иллюстрации для UI**           | &quot;Создай иллюстрацию для экрана пустого состояния моего приложения&quot; |
| **Маркетинговые изображения**    | &quot;Создай главное изображение для моей целевой страницы&quot;             |
| **Макеты продуктов**             | &quot;Создай изображения-макеты моего приложения на разных устройствах&quot; |

<div id="melhores-prticas-para-gerao-de-imagens">
  ### Рекомендации по генерации изображений
</div>

Следуйте этим рекомендациям, чтобы добиться наилучших результатов при генерации изображений с помощью Agent:

**Формулируйте запросы конкретно и подробно**

* Указывайте стиль, цвета, композицию и атмосферу
* При необходимости задавайте размеры или пропорции
* Указывайте предполагаемое назначение изображения (значок, фон, иллюстрация и т. д.)

**Итерируйте и совершенствуйте**

* Начните с базового описания и уточняйте его на основе результатов
* Попросите Agent изменить конкретные аспекты сгенерированных изображений
* Запрашивайте варианты, чтобы рассмотреть разные творческие направления

**Учитывайте стиль своего проекта**

* Поддерживайте визуальное единообразие во всём приложении
* Указывайте предпочтения по стилю, соответствующие вашему бренду или дизайн-системе
* Запрашивайте изображения, дополняющие существующие визуальные элементы

<div id="integrao-ao-projeto">
  ### Интеграция с проектом
</div>

Agent легко интегрирует сгенерированные изображения в вашу кодовую базу:

* **Автоматическое создание файлов**: Сгенерированные изображения сохраняются непосредственно в файлах проекта
* **Обновление кода**: Agent обновляет код, добавляя ссылки на новые файлы изображений
* **Организация ассетов**: Изображения размещаются в логично организованных каталогах проекта

Этот оптимизированный рабочий процесс позволяет создавать и внедрять визуальный контент, не выходя из среды разработки.

<Note>
  Генерация изображений в Replit работает на базе [Google Imagen 4](https://deepmind.google/models/imagen/) — передовой модели преобразования текста в изображения, которая создаёт высококачественные фотореалистичные изображения с мелкими деталями и улучшенными возможностями рендеринга текста.
</Note>
