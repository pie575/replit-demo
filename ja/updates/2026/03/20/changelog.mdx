## プラットフォーム

### Microsoft App StoreのReplit PWA

ReplitがMicrosoft App StoreでProgressive Web App（PWA）として利用できるようになりました。Windowsのビルダーがネイティブアプリのような形でReplitを発見してインストールしやすくなります。

### 空のプロジェクト作成

インポートページから空のプロジェクトを作成できるようになりました。空のプロジェクトは起動時にAgentを起動しないため、作成時にクレジットを消費せず、フレームワークとツールのセットアップを完全に制御できます。このオプションは、このレベルの制御を必要とするビルダー向けにインポートページから利用できます。

## チームとEnterprise

### Enterprise監査ログポータル

Enterprise監査ログポータル（v1）がすべてのEnterpriseのお客様に提供されるようになりました。管理者は組織のメンバーが実行したイベントを確認し、S3、Datadog、Splunk、Google Cloud Storage、Microsoft SentinelなどのSIEMプラットフォームとのイベントストリームインテグレーションを設定できます。
