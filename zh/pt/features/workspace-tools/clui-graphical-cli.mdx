CLUI (命令行用户界面) 是 Replit 的交互式命令栏，无需在菜单中逐层查找，即可快速执行多种操作。它结合了命令行的高效与图形界面。

<div id="recursos">
  ## 功能
</div>

CLUI 可在 Replit 的三种不同场景中提供强大的命令式交互：

* **设置管理**：管理设置、查看通知，以及恢复已删除的 Replit Apps
* **快速导航**：在不同 Replit Apps 之间切换，并通过快捷方式访问常用功能
* **工作区 操作**：在开发环境中查找文件、搜索代码和访问工具

<div id="uso">
  ## 使用
</div>

<div id="clui-da-conta">
  ### 账户 CLUI
</div>

账户 CLUI 可帮助你管理设置、团队和已删除的 Replit Apps。

**访问方式**：前往 [CLUI 页面](https://replit.com/~/cli)，在收件箱中输入内容搜索命令，然后按 Enter 执行。

<Accordion title="账户命令">
  输入 `account` 以管理你的设置：

  * **view-warns**：查看你收到的警告
  * **change-username**：更改你的用户名 (只能更改一次) 
</Accordion>

<Accordion title="回收站命令">
  输入 `trash` 以管理已删除的 Replit Apps：

  * **restore &lt;title&gt;**：按标题恢复已删除的 Replit App (如果有多个同名 App，则恢复最近删除的一个) 
  * **view**：查看你最近删除的 Replit Apps
</Accordion>

<Accordion title="团队命令">
  输入 `team` 以管理你的团队：

  * **view**：输入团队用户名，查看你所在团队的成员
  * **fork-repl-to-project**：fork 现有的 Replit App，以创建团队项目
</Accordion>

<Accordion title="清除命令">
  输入 `clear` 以清除屏幕上此前执行的所有命令记录
</Accordion>

<div id="clui-de-atalhos">
  ### 快捷键 CLUI
</div>

快捷键 CLUI 可让你在任何页面快速访问常用的 Replit 功能。

<Frame>
  <img src="/assets/mirror/shortcuts-clui-768d49b44785.png" alt="快捷键 CLUI" width="689" height="291" data-path="images/getting-started/shortcuts-clui.png" />
</Frame>

**访问方式**：按 **CMD/CTRL + K**，或在大多数 Replit 页面中点击顶部导航栏中的搜索图标。

<Accordion title="可用命令">
  * **Search**：在 Replit 中搜索 Replit Apps、模板、代码、用户等内容
  * **New**：创建新的 Replit App
  * **My Replit Apps**：浏览和访问你的 Replit Apps
  * **My Code**：搜索你所有 Replit Apps 中的代码
</Accordion>

<div id="clui-do-workspace">
  ### 工作区 CLUI
</div>

工作区 CLUI 可帮助你在 Replit App 中工作时执行操作、访问工具、查找文件和搜索代码。

<Frame>
  <img src="/assets/mirror/ws-clui-81764b3d111b.png" alt="工作区 CLUI" width="429" height="202" data-path="images/getting-started/ws-clui.png" />
</Frame>

**访问方式**：按 **CMD/CTRL + K**，或在 工作区 中点击左上角的搜索图标。

<Accordion title="常用操作">
  * **Find files**：快速定位项目中的文件
  * **Search code**：在文件中查找特定代码片段
  * **Access tools**：打开 工作区 中的任意可用工具或面板
  * **Run commands**：执行特定的工作区命令
</Accordion>
