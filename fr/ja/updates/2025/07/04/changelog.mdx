<div id="agentweb-search">
  ### Web Search dans Agent
</div>

<Frame>
  <img src="/assets/mirror/web-search-6c28195531d4.jpg" alt="Interface d'Agent affichant les résultats de recherche web et les citations de sources pour le développement d'applications" width="1920" height="1080" data-path="images/replitai/web-search.jpg" />
</Frame>

Agent peut désormais effectuer des recherches sur le web et récupérer les informations les plus récentes grâce à [Web Search](/fr/core-concepts/agent/web-search). Créez vos applications à partir de la documentation la plus à jour, des données de marché actuelles et d&#39;informations précises issues de tout le web. Fini les limites de connaissances : vos applications peuvent s&#39;appuyer sur les dernières informations disponibles.

<div id="agent">
  ### Instructions personnalisées pour Agent
</div>

<Frame>
  <img src="/assets/mirror/replitmd-65360844a148.jpg" alt="Fichier replit.md affichant les options de personnalisation du projet" width="1920" height="1080" data-path="images/replitai/replitmd.jpg" />
</Frame>

Personnalisez votre expérience avec Agent grâce à [replit.md](/fr/core-concepts/agent/replit-dot-md). Ce fichier spécial vous permet de définir votre style de code, les paramètres de votre projet et le contexte. Agent le crée automatiquement en s&#39;appuyant sur des bonnes pratiques éprouvées, et vous pouvez ensuite l&#39;adapter à votre flux de travail.

<div id="section-3">
  ### Facturation basée sur l’effort
</div>

<Frame>
  <img src="/assets/mirror/effort-based-billing-d971548c7c39.png" alt="Interface de facturation basée sur l’effort affichant une tarification dynamique selon l’effort de l’Agent" width="2048" height="1424" data-path="images/changelog/2025-07-04/effort-based-billing.png" />
</Frame>

Découvrez une tarification des checkpoints plus intelligente grâce à la nouvelle [facturation basée sur l’effort](/fr/ja/billing/ai-billing). Grâce à une tarification dynamique basée sur l’effort réel de l’Agent, un seul checkpoint est créé par exécution, au lieu de plusieurs.

<div id="teamsapp-store">
  ### L’App Store de Teams
</div>

Découvrez et gérez les applications de votre équipe comme jamais auparavant. La nouvelle expérience « App Store » de l’organisation, accessible depuis la page Deployments, vous permet de mettre vos favoris en vedette, de rechercher tous les déploiements, de consulter les applications récemment ouvertes et de découvrir les déploiements populaires selon leur volume de trafic.
