---
title: "机器配置"
description: "设定运行已发布应用的服务器性能与成本：CPU、内存以及最大机器数量。"
---

机器配置决定了运行已发布应用的服务器性能。Replit 会选择合理的默认值，因此大多数创作者无需更改。如果应用在高负载下响应变慢，或需要在内存中处理大量数据，可以考虑使用更高的配置。

要更改配置，请打开 Publishing 工具，选择 **Adjust settings**，然后点击 **Machine configuration** 旁边的 **Edit**。

<div id="as-configuraes">
  ## 设置
</div>

* **CPU**：每台服务器能同时处理的工作量。当大量用户同时使用你的应用时，更多 vCPU 会很有帮助。
* **Memory (RAM)**：应用可以在内存中保留的数据量。处理大文件、媒体或高强度数据任务时，更大的内存会很有帮助。
* **Max machines**：仅适用于 Autoscale。应用繁忙时，Replit 可以添加的服务器数量上限。应用的扩展规模永远不会超过这个数量，从而限制了你的最高成本。

<div id="quanto-custa">
  ## 费用如何计算
</div>

在配置过程中，面板会显示两个数值：

* **Per machine**：采用所选配置的单台服务器每小时费用。
* **At max traffic**：当应用繁忙到用满所有机器 (达到上限) 时的每小时费用。

费用以计算单元计量，这是一种基于所选 CPU 和内存的云计算单元。要查看当前费率以及用量的计费方式，请参阅[基于用量的计费](/zh/pt/billing/about-usage-based-billing#2-compute-units)。

<div id="como-a-cobrana-varia-por-tipo-de-deployment">
  ## 计费如何因部署类型而异
</div>

同样的配置，在不同的 [部署类型](/zh/pt/features/publishing/deployment-types)下计费方式也不同：

* **Autoscale**：只有在处理请求时才计费。应用空闲时会缩容至零，不产生任何运行费用。
* **Reserved VM**：服务器始终保持运行，因此按所选配置支付固定的月度费用。
* **Static**：没有机器运行你的站点，因此机器配置不适用。
* **Scheduled**：只需为每次计划任务运行期间占用的机器付费。

<div id="aplique-suas-alteraes">
  ## 应用你的更改
</div>

更改配置后，请重新发布你的应用。新的机器配置会在新的 部署生效后开始生效。
