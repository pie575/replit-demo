Replit MCP 使用 [Model Context Protocol](https://modelcontextprotocol.io/)，让你能够通过已在使用的 AI 工具创建、搜索、查看、更新和发布 Replit App。

<div id="mcp">
  ## 直接连接 MCP 客户端
</div>

如果 MCP 客户端没有 Replit 原生集成，请使用直接连接。

| 属性       | 值                                       |
| -------- | --------------------------------------- |
| **URL**  | `https://replit-mcp.com/server/mcp`     |
| **传输**   | Streamable HTTP                         |
| **身份验证** | 使用 protected-resource discovery 的 OAuth |

将服务器 URL 添加到支持 Streamable HTTP 和 OAuth 授权的 MCP 客户端。客户端会读取 Replit 的 protected-resource 元数据，然后请求你登录 Replit。

请勿创建自定义 OAuth 服务器。Replit MCP 服务器会提供客户端所需的 OAuth 元数据。

你可以创建新应用，也可以处理你拥有编辑权限的应用 (包括他人与你共享的应用) 。

<div id="replit-mcp">
  ### 配置 Replit MCP
</div>

Codex 和 Claude Code 仅为示例。你可以将 Replit MCP 添加到任何兼容的 MCP 客户端。

      </Step>

      <Step title="添加 Replit">
        添加自定义 MCP。请使用易于识别的名称，例如 `Replit`。选择 **Streamable HTTP**，输入 `https://replit-mcp.com/server/mcp` 后保存。请勿添加 bearer 令牌或自定义标头。

<div id="section">
  ## 工具
</div>

| 工具                        | 必填输入                          | 可选输入                                                                      | 用途                                                                                                                                                                                       |
| ------------------------- | ----------------------------- | ------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `create_app_from_prompt`  | `appDescription`, `app_stack` | `userSpecifiedAppName`, `userQuotes`, `attachmentSummary`, `sourceReplId` | 创建新应用。`app_stack`可以是 `react_website`、`mobile_app`、`design`、`slides`、`animation`、`data_visualization`、`3d_game`、`document` 或 `spreadsheet`。设置 `sourceReplId` 后，新应用将从现有应用的私有副本创建，而非从空项目开始。 |
| `search_apps`             | 无                             | `query`, `url`, `updatedAfter`, `updatedBefore`, `limit`                  | 按标题关键词、URL 或最后更新时间查找应用。`limit` 的取值范围为 1 到 50。                                                                                                                                            |
| `resolve_app_by_name`     | `name`                        | 无                                                                         | 按精确标题查找单个应用。                                                                                                                                                                             |
| `list_apps`               | 无                             | `query`, `limit`                                                          | 按最近活动时间列出可编辑的应用。默认上限为 25，最大为 50。                                                                                                                                                         |
| `ask_question`            | `replId`, `question`          | 无                                                                         | 不更改应用，直接向 Agent 询问有关应用的问题。                                                                                                                                                               |
| `update_app_using_prompt` | `replId`, `changeDescription` | `userQuotes`, `attachmentSummary`                                         | 通过 Agent 更新现有应用。                                                                                                                                                                         |
| `publish_app`             | `replId`                      | 无                                                                         | 发布应用，或重新发布最新更改。                                                                                                                                                                          |
| `get_publish_status`      | `replId`                      | 无                                                                         | 查看应用是否已发布、当前发布状态和公开 URL。                                                                                                                                                                 |

<div id="section-2">
  ## 故障排查
</div>

| 问题              | 解决方法                                                   |
| --------------- | ------------------------------------------------------ |
| Replit 要求进行身份验证 | 请在 MCP 客户端中重新完成 OAuth 登录流程。                            |
| 找不到 App         | 请确认您有权编辑该 App。然后按 URL 搜索，或使用 `list_apps` 从匹配的 App 中选择。 |
| 创建、更新或发布请求仍在进行中 | 请等待后再重试。对于发布，请使用 `get_publish_status` 查看当前状态。          |
