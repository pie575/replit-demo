<div id="section">
  ## 个人工作区与团队工作区
</div>

**工作区**是用于管理应用、成员、设置和账单的组织结构。Replit 提供两种类型：

* 个人工作区
* 团队工作区

个人工作区与团队工作区的区别如下：

|          | 个人工作区         | 团队工作区          |
| -------- | ------------- | -------------- |
| **角色**   | 管理员、项目级访客     | 管理员、成员、项目级访客   |
| **访问模式** | 逐个项目邀请访客      | 成员可访问工作区内的所有项目 |
| **账单**   | 你自己的账户        | 由管理员账户提供的共享额度  |
| **成员管理** | 按项目管理 (加入链接)  | 在工作区设置中集中管理    |

**个人工作区**适合独自开发，或将单个项目分享给他人。唯一的管理员是你本人，其他用户只能以项目级访客的身份访问你邀请他们加入的特定项目。

**团队工作区**适合与固定的成员群体协作开发，例如创业团队、课堂教学，或有多位贡献者的客户项目。成员可访问工作区内的所有项目，无需为每个项目单独发送邀请。成员统一在**设置**中集中管理。

<div id="section-2">
  ### 何时邀请加入工作区，何时邀请加入项目
</div>

| 场景               | 建议操作                                 |
| ---------------- | ------------------------------------ |
| 需要持续访问所有资源的协作者   | 邀请加入工作区                              |
| 仅需访问单个项目的外包人员或访客 | [邀请加入项目](/zh/ja/build/invite-teammates) |
| 新加入公司的团队成员       | 邀请加入工作区                              |
| 帮助调试特定应用的朋友      | [邀请加入项目](/zh/ja/build/invite-teammates) |

<div id="section-3">
  ## 创建团队工作区
</div>

<Frame>
  <img src="/assets/mirror/create-team-workspace-e89eaefd9168.png" alt="新建工作区表单，其中包含默认的工作区名称和用于邀请团队成员的空白字段" width="784" height="300" data-path="images/workspace/create-team-workspace.png" />
</Frame>

<Steps>
  <Step title="打开工作区切换器">
    在主页上，点击左上角的工作区名称。
  </Step>

  <Step title="创建新的工作区">
    选择**创建工作区**，然后输入团队工作区的名称。
  </Step>

  <Step title="邀请成员">
    在邀请字段中输入一个或多个电子邮件地址 (以逗号分隔) 。受邀者会收到邀请，接受后即可访问该工作区中的所有项目。
  </Step>
</Steps>

<div id="section-4">
  ## 管理成员
</div>

如果你在设置时未邀请成员，或之后需要添加成员，请前往团队工作区的**设置**，通过邮箱地址或 Replit 用户名邀请成员。

<Frame>
  <img src="/assets/mirror/invite-workspace-members-6e3fda413196.jpg" alt="用户邀请对话框，其中包含用于输入邮箱地址的空白字段" width="510" height="244" data-path="images/workspace/invite-workspace-members.jpg" />
</Frame>

在**设置**页面中，你还可以：

* **移除成员**，撤销其对该工作区内所有项目的访问权限
* **转移 App**，将其从个人工作区移至团队工作区 —— 参见[将 App 转移到 Teams](/zh/ja/teams/identity-and-access-management/transfer-app-to-teams)

  <Warning>
    工作区之间的项目转移已临时停用，目前无法发起新的转移。
  </Warning>

有关高级身份管理、基于角色的访问控制和群组权限，请参见 [Pro 和 Enterprise](/zh/ja/category/teams)。
