<div id="agent-geral">
  ### Agent Geral
</div>

<Frame>
  <img src="/assets/mirror/general-agent-240ff289e711.png" alt="Agent Geral 特性插图" width="1040" height="572" data-path="images/replitai/general-agent.png" />
</Frame>

Replit Agent 现已支持任何可在 NixOS 上运行的代码库，无论使用何种语言或框架！此前 Agent 仅限于特定模板，如今可以协助处理开发者框架、GitHub 导入以及各类自定义项目配置。这次重要扩展为企业级和高级用户的工作流带来了完整的 AI 编码辅助能力。

点击[此处](/zh/pt/core-concepts/agent/general-agent)了解有关 Agent Geral 的更多信息。

<div id="modo-de-plano">
  ### 规划模式
</div>

<Frame>
  <img src="/assets/mirror/plan-mode-overview-8077807c63b9.png" alt="规划模式下的 Agent 聊天界面" width="916" height="362" data-path="images/replitai/plan-mode-overview.png" />
</Frame>

规划模式带来了与 Replit Agent 对话的全新方式，专注于提问、头脑风暴和规划工作。借助规划模式，你可以让 Agent 为后续工作生成一份任务清单，然后在创建模式下执行耗时较长的任务。

点击[这里](/zh/pt/core-concepts/agent/plan-mode)进一步了解规划模式。

<div id="integrao-com-o-gcp-marketplace">
  ### GCP Marketplace 集成
</div>

企业客户现在可以直接通过 Google Cloud Platform Marketplace 采购 Replit，并使用已有的 GCP 额度付款。这简化了采购流程，让拥有 GCP 预算的组织能够更轻松地将 Replit 纳入自己的开发工作流。
