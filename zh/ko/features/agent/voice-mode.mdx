---
title: "语音模式"
description: "无需打字，直接向 Agent 说出提示词。语音模式会将您说的话转录为聊天框中的文本，供您查看和发送。"
---

说出您想构建的内容。轻点 Agent 聊天中的麦克风并说出提示词，Replit 会将您的语音转录为可编辑的文本。查看文本，按需修改，然后像发送其他消息一样发送。

语音模式在打字较慢或不方便时尤其有用——在移动设备上，说出完整提示词通常比用拇指输入更快。

<Note>
  语音模式会将您的语音转换为聊天框中的文本。它不会朗读 Agent 的回复——您仍然发送文本消息，Agent 也会像平常一样通过聊天回复。
</Note>

<div id="section">
  ## 工作原理
</div>

  <img src="/assets/mirror/voice-mode-mic-button-fe7da6953736.png" alt="Agent 聊天中高亮显示的麦克风按钮及“Start voice input”工具提示，位于 Plan 复选框和发送箭头旁" width="1853" height="423" data-path="images/replitai/voice-mode/voice-mode-mic-button.png" />
</Frame>

语音模式会录制你的语音并将其转换为文本，填入聊天框供你在发送前检查：

1. 打开 Agent，然后点击聊天框中的麦克风。
2. 如果浏览器或设备提示，请允许访问麦克风。
3. 说出你的提示词。Agent 会显示波形，表示正在录音。
4. 完成后，停止录音。暂停片刻或切换到其他标签页时，录音也会自动停止。
5. 等待片刻，让系统将你的语音转换为文本。
6. 检查转换后的文本，必要时进行编辑，然后发送消息。

转换后的文本会以普通文本形式显示在聊天框中，因此你可以自由结合语音和键入内容——可以口述部分提示词，再键入其余内容；也可以在发送前修改词语。

<Tip>
  自然说话即可。语音模式侧重于理解你的意图，而非逐字转写，因此“嗯”“呃”等填充词不会出现在结果中。
</Tip>

<div id="section-2">
  ## 可用位置
</div>

您可以在 Agent 聊天框中使用语音模式：

* 在 **Project Editor** 中使用 Agent 开发应用时
* 从主页的 Agent 提示词**开始创建新应用**时

您可以在桌面网页版、移动网页版和 Replit 移动应用中使用语音模式。

<div id="section-3">
  ## 使用须知
</div>

使用语音模式时，请注意以下事项：

| 项目    | 预期行为                                                 |
| ----- | ---------------------------------------------------- |
| 录音时长  | 每次最多可录制 6 分钟。接近时长上限时会显示警告。                           |
| 自动停止  | 如果持续静默约 30 秒、切换标签页或将应用置于后台，录音会自动停止。                  |
| 发送前检查 | 转录的文本会输入到聊天框中，因此你可以在发送前查看并修改，不会自动发送。                 |
| 麦克风访问 | 语音模式需要使用麦克风的权限。如果无法开始录音，请确认已在浏览器和设备中允许 Replit 访问麦克风。 |

<div id="section-4">
  ## 可用性
</div>

所有 Replit 方案均可使用语音模式。支持录音功能的浏览器和设备会在 Agent 聊天窗口中显示麦克风图标。首次录音时，系统会请求麦克风权限。
