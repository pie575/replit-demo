<div id="what-is-a-remix">
  ## 什么是 Remix
</div>

**Remix** 是你基于自己有权访问的应用创建的新 Replit App。当你 Remix 一个公开应用或模板时，会得到一份属于自己的副本，可以自由使用并不断改进。你在 Remix 中所做的修改不会影响原始应用。

你的 Remix 会标明来源：页面上会显示一个指向原始应用的 **Remixed from** 链接，原始应用的构建 prompt 也会显示在其封面页上。

<div id="what-your-remix-includes">
  ## Remix 包含哪些内容
</div>

Remix 是一份完整、可运行的副本，并与原应用彻底分离：

* **所有文件和配置**都会复制过来，因此应用的运行效果与源应用完全一致。
* **源应用的 checkpoint 历史**也会一并带过来，并标注为来自源应用的历史记录。你可以回滚到其中任意一个 checkpoint；而生成这些 checkpoint 的对话仍保留在原应用中。
* **全新的 Agent。** 你的 Remix 会从一个全新的 Agent 开始，不会继承任何聊天记录。
* **只复制 Secrets 的名称，不复制值。** 如果应用使用了 Secrets (例如 API 密钥) ，你的 Remix 会列出这些名称，让你知道需要填写哪些内容，但对应的值为空。只有 remix 你自己的应用时，值才会一并复制。
* **全新的数据库。** 你的 Remix 绝不会连接到原应用的数据库。如果原应用提供该选项，你可以通过**从原应用复制数据**来复制数据本身；即便如此，你的改动也不会影响源应用。
* 对于使用 Replit Auth 的应用，会提供**全新的登录配置**。

不会复制的内容包括：deployment、域名和 connector 配置，这些需要你在自己的副本上自行设置。此外，Remix 初始为私有状态，在你选择发布之前不会对外分享任何内容。

  <Step title="打开应用的封面页">

<div id="build-on-your-remix">
  ## 在 Remix 基础上继续构建
</div>

当 Remix 在 workspace 中打开后，即可使用 Agent 对其进行修改和扩展。在 **Agent** 标签页中输入 prompt，描述你想要添加的功能。

若要撤销 Agent 所做的更改，请在该次更改后生成的 checkpoint 中选择 **Rollback to here**。详见 [Checkpoint 与回滚](/zh/features/version-control/checkpoints-and-rollbacks)。

<div id="remix-or-build-from-a-prompt">
  ## 是 Remix 还是从 prompt 构建？
</div>

两条路径的终点相同：都会得到一个属于你自己的应用，并由 Agent 帮你持续演进。不同的是起点：

|            | Remix          | 从 prompt 构建       |
| ---------- | -------------- | ----------------- |
| 起点         | 一个可运行的应用，原样复制  | Agent 根据你的描述创建的应用 |
| 首个结果       | 立即可得，且与源应用完全一致 | 耗时更长，结果不尽相同       |
| Agent 的第一步 | 等待你的指示         | 根据你的 prompt 规划并构建 |

如果已经有与你的设想相近的应用，就直接 Remix：这样 Agent 的第一轮就能在一个真实可运行的应用上开展工作，而不是从零开始。如果你的想法找不到任何类似的现成应用，就从 prompt 构建。
