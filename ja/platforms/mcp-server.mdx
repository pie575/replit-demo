Replit MCPは[Model Context Protocol](https://modelcontextprotocol.io/)を使用して、すでに使用しているAIツールからReplit Appを作成・検索・確認・更新・公開できるようにします。

## ChatGPT、Claude、SlackでReplitを使う

## MCPクライアントを直接接続する

MCPクライアントにReplitのネイティブ統合がない場合は、直接接続を使用してください。

| プロパティ       | 値                                      |
| ----------- | -------------------------------------- |
| **URL**     | `https://replit-mcp.com/server/mcp`    |
| **トランスポート** | Streamable HTTP                        |
| **認証**      | protected-resource discoveryを使用したOAuth |

Streamable HTTPとOAuth認可をサポートするMCPクライアントに、サーバーURLを追加します。クライアントはReplitのprotected-resourceメタデータを読み取り、続いてReplitへのサインインを求めます。

カスタムOAuthサーバーを作成しないでください。Replit MCPサーバーが、クライアントに必要なOAuthメタデータを提供します。

アプリを新しく作成することも、編集権限のあるアプリ（自分と共有されているアプリを含む）を操作することもできます。

## ツール

| ツール                       | 必須の入力                         | オプションの入力                                                  | 用途                                                                                                                                                  |
| ------------------------- | ----------------------------- | --------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| `create_app_from_prompt`  | `appDescription`, `app_stack` | `userSpecifiedAppName`, `userQuotes`, `attachmentSummary` | 新しいアプリを開始します。`app_stack`は`react_website`、`mobile_app`、`design`、`slides`、`animation`、`data_visualization`、`3d_game`、`document`、`spreadsheet`のいずれかです。 |
| `search_apps`             | なし                            | `query`, `url`, `updatedAfter`, `updatedBefore`, `limit`  | タイトルのキーワード、URL、または最終更新時刻でアプリを検索します。`limit`は1から50です。                                                                                                 |
| `resolve_app_by_name`     | `name`                        | なし                                                        | 正確なタイトルで1つのアプリを検索します。                                                                                                                               |
| `list_apps`               | なし                            | `query`, `limit`                                          | 編集可能なアプリを、最近のアクティビティ順に一覧表示します。デフォルトの上限は25、最大は50です。                                                                                                  |
| `ask_question`            | `replId`, `question`          | なし                                                        | アプリを変更せずに、Agentにそのアプリについて質問します。                                                                                                                     |
| `update_app_using_prompt` | `replId`, `changeDescription` | `userQuotes`, `attachmentSummary`                         | 既存のアプリに対するAgentの更新を開始します。                                                                                                                           |
| `publish_app`             | `replId`                      | なし                                                        | アプリを公開するか、最新の変更を再公開します。                                                                                                                             |
| `get_publish_status`      | `replId`                      | なし                                                        | アプリが公開されているかどうか、現在の公開ステータス、公開URLを確認します。                                                                                                             |

## トラブルシューティング

| 問題                      | 対処法                                                                |
| ----------------------- | ------------------------------------------------------------------ |
| Replitが認証を求める           | MCPクライアントからOAuthサインインフローを再度完了してください。                               |
| アプリが見つからない              | そのアプリを編集できるか確認してください。次にURLで検索するか、`list_apps`を使って一致するアプリから選択してください。 |
| 作成、更新、または公開のリクエストがまだ実行中 | 再試行する前に待ってください。公開の場合は、`get_publish_status`で現在の結果を確認してください。         |
