---

Вкладка **My Data** — это место, где вы просматриваете и изменяете данные в базе данных. Откройте инструмент **Database**, выберите базу данных, а затем — **My Data**. Работать можно как визуально, так и напрямую через SQL.

<Note>
  Чтобы изменить рабочие данные, выберите рабочую базу данных, откройте **My Data** и включите режим **Edit**. Будьте внимательны: это реальные данные работающего приложения.
</Note>

<div id="section">
  ## Просмотр и изменение данных в визуальном режиме
</div>

Инструмент Database включает <a href="https://orm.drizzle.team/drizzle-studio/overview" target="_blank">Drizzle Studio</a> — средство для визуального просмотра и изменения данных. Визуальные инструменты помогают избежать синтаксических ошибок и предоставляют следующие возможности:

* фильтрация и сортировка данных для поиска нужной информации
* экспорт данных в файл для использования во внешних системах
* вставка и изменение данных в строках
* создание схем, таблиц, представлений и enum, а также управление ими

<div id="sql">
  ## Выполнение SQL-команд
</div>

SQL runner позволяет выполнять SQL-команды в базе данных и просматривать результаты.

<Accordion title="Как открыть SQL runner">
  В инструменте **Database**:

  1. Выберите вкладку **My Data**
  2. Выберите <img class="icon-svg" src="/assets/mirror/sql-runner-icon-b25868882922.svg" alt="Значок SQL runner" width="16" height="16" data-path="images/icons/sql-runner-icon.svg" /> **SQL runner**
</Accordion>

Чтобы выполнить запрос, введите SQL-выражение в текстовое поле и нажмите кнопку запуска <img class="icon-svg" src="/assets/mirror/sql-play-8ed26b5de7f1.svg" alt="значок запуска sql" width="18" height="18" data-path="images/icons/sql-play.svg" /> рядом с ним.

<Frame>
  <img src="/assets/mirror/sql-runner-run-8ad798a61335.jpg" alt="Снимок экрана SQL runner и кнопки запуска" width="1390" height="608" data-path="images/databases/sql-runner-run.jpg" />
</Frame>

<Tip>
  Писать SQL самостоятельно не обязательно. Попросите Agent получить или изменить данные — он сам напишет и выполнит SQL.
</Tip>
