export const ProCreditRolloverPeriod = 'two months';

Replit AI 功能采用按使用量计费的方式，费用取决于您构建的内容和 AI 工具的使用量。这样，您只需为 Agent 带来的价值付费。

<div id="section">
  ## 开始使用
</div>

**所有订阅者**均可获赠一次免费的 Agent 检查点。

额外的每月积分会自动用于 AI 使用：

* **Core 订阅者**：每月积分 (请参阅[套餐](https://replit.com/pricing))
* **Pro 订阅者**：分级每月积分，可在 {ProCreditRolloverPeriod} 内结转。请参阅 [Replit Pro](/zh/ko/billing/plans/replit-pro)。

这些积分适用于 Agent 以及已发布的应用、存储、数据库等其他 Replit 云服务。选择 [Lite、Economy 或 Power](/zh/ko/features/agent/agent-modes)，针对速度、成本或性能优化 Agent。

<div id="agent-2">
  ## Agent 计费
</div>

<Frame>
  <img src="/assets/mirror/checkpoint-f0cc3c49b9a5.png" alt="显示聊天和检查点系统的 Replit Agent 界面" width="1999" height="1242" data-path="images/billing/checkpoint.png" />

Free Mode 在限额内为 Core 和 Pro 订阅者免费提供日常 Agent 任务支持。付费模式和已确认的付费任务采用按工作量计费的方式，费用取决于请求的复杂程度。Replit 会在开始付费任务前请求确认。

<div id="section-2">
  ### 基于工作量的计费如何运作
</div>

在“Build 模式”下与 Agent 对话时，系统会生成一个**检查点**，记录针对该请求已完成的工作：

* **简单请求** (如修复 bug 或小幅改动) 通常比复杂构建的费用更低
* **复杂构建** (如完整功能或集成) 会合并为一个检查点，费用可能高于简单请求，以反映投入的总体工作量
* **每个请求对应一个检查点**，避免了中间检查点，减少计费干扰
* **透明计费**让你清楚知道每项已完成的工作究竟花了多少费用

<Info>
  当 Agent 完成针对某个请求的工作，并将所请求的功能实现到代码中时，就会生成检查点。
</Info>

在付费路径下，Plan 模式即使不修改代码，也可能执行需要计费的推理工作。

有关检查点记录哪些内容及其运作方式的详细信息，请参阅[检查点与回滚](/zh/ko/features/version-control/checkpoints-and-rollbacks)。

<div id="agent-3">
  ### Agent 服务计费
</div>

部分 Agent 功能会在后台使用付费的第三方 API (例如 Claude、ChatGPT、Nano Banana / Gemini) 。Agent 会自动处理这些集成，无需 API 密钥或额外配置。费用按服务提供商公开的 API 价格计算，并从 Replit 积分中扣除。你可以在[使用量仪表板](/zh/ko/billing/managing-spend)中查看这些费用及其他使用量。

如需了解示例应用的费用，请查看这个简洁的[交互式演示](https://agent-pricing.replit.app/)。

<div id="section-3">
  ### 使用量追踪
</div>

您可以实时监控 Agent 的支出：

1. **Agent 标签页**：将鼠标悬停在使用量图标上，即可查看单个检查点的费用
2. **使用量仪表板**：查看当前周期的详细账单信息
3. **设置**：在 **账户** → **账单** 中设置提醒和预算，以控制支出

<Tip>
  使用量数据最多可能需要 30 分钟才会显示在使用量仪表板中。
</Tip>

<div id="section-4">
  ## 支出管理
</div>

使用 Replit 内置的预算工具控制 AI 支出：

* **用量提醒**：达到支出阈值时接收通知
* **预算限额**：设置严格的上限，避免产生意外费用
* **实时追踪**：在构建过程中监控成本
* **积分包**：批量购买可享折扣，获取额外积分。有关详细信息，请参阅[支出管理](/zh/ko/billing/managing-spend)。

<div id="section-5">
  ## 后续步骤
</div>

准备好开始用 AI 构建了吗？以下方法可帮助你充分利用积分：

* **先试用 Agent**：使用免费检查点探索 Agent 的功能
* **从简单任务开始**：通过简单请求了解按工作量计费的方式
* **使用 Lite 模式**：对于快速、目标明确的编辑，可使用 [Lite 模式](/zh/ko/features/agent/agent-modes)
* **设置提醒**：在超出积分前设置消费提醒
