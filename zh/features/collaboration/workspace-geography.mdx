Workspace 地理位置决定 Workspace 的开发资源托管在哪里。你在创建 Workspace 时选择该位置，此后该 Workspace 中新建的 Project 和资源都会使用所选位置。

<Note>
  Workspace 地理位置与[发布地理位置](/zh/features/security/geography#publishing-geography)可以不同。发布地理位置决定已发布的 Project 在哪里运行。
</Note>

<div id="what-workspace-geography-controls">
  ## Workspace 地理位置决定哪些内容
</div>

Workspace 将 Project、成员、设置、共享资源、integration 和账单集中在一起。在每个 Project 中，你可以使用 Project Editor 和 Replit 聊天。开发资源包括应用的开发版本及其开发数据库。

只有 Pro 客户可以选择特定的 Workspace 区域。

Free 和 Core 客户的 Workspace 区域由系统自动设置，通常会选择距离你最近的区域。该 Workspace 中新建的 Project 和资源都会使用这一位置。Workspace 创建完成后，区域无法更改。

<div id="select-a-workspace-region">
  ## 选择 Workspace 区域
</div>

如果你是 Pro 用户，可以在创建 Workspace 时选择区域：

<Steps>
  <Step>打开 **Create a new workspace** 表单。</Step>
  <Step>输入 Workspace 名称，并可选择性地填写成员电子邮件地址。</Step>

  <Step>
    展开 **Workspace region**，然后选择 **North America**、**Europe (EU)**
    或 **Asia**。
  </Step>

  <Step>点击 **Create workspace**。</Step>
</Steps>
