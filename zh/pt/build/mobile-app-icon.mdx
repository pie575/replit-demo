export const appIconPrompt = "为 PixelGames 生成 3 种不同的 1024x1024 App 图标设计方案。";

两家商店都要求先提供 App 图标，才会接受提交。Replit 可以直接生成，
无需使用单独的设计工具。

<div id="o-que-cada-loja-precisa">
  ## 各商店的要求
</div>

* **App Store：**1024×1024，无透明背景，无圆角，圆角由 Apple 添加。
* **Google Play：**512×512。

<div id="gere-o-cone">
  ## 生成图标
</div>

发送提示词前，先切换到 **Design** 模式，以指示 Agent 生成图像。

<AiPrompt>
  {appIconPrompt}
</AiPrompt>

Agent 会一次生成多个设计方案，方便你在选定其中一个之前进行比较和选择。
