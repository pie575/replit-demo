Cette page répond aux questions fréquentes sur la connexion et le dépannage des domaines personnalisés. Pour plus de détails, consultez [Ajouter un domaine personnalisé](/fr/ja/build/add-custom-domain) et [Domaines personnalisés](/fr/ja/features/publishing/custom-domains).

<AccordionGroup>
  <Accordion title="Comment connecter un domaine personnalisé à une application Replit ?">
    Si vous avez acheté votre domaine sur Replit, vos enregistrements DNS sont gérés automatiquement : ouvrez **Publishing → Domains** et suivez les instructions de configuration affichées. Consultez [l’achat de domaines](/fr/ja/build/domain-purchasing).

    Pour connecter un domaine enregistré auprès d’un registraire externe :

    1. Ouvrez votre projet et accédez à **Publishing → Domains**.
    2. Sélectionnez **Connect your own domain**, saisissez votre domaine, puis continuez.
    3. Replit affiche les enregistrements A et TXT : copiez-les tous les deux.
    4. Ajoutez les deux enregistrements auprès de votre fournisseur DNS.
    5. Retournez sur Replit et lancez la vérification.

    Remarques importantes :

    * Les enregistrements A et TXT sont tous deux nécessaires pour SSL. Les CNAME apex (racine) ne sont pas pris en charge : utilisez un enregistrement A pour le domaine racine.
    * Les certificats génériques (`*.example.com`) ne sont pas pris en charge : connectez chaque sous-domaine séparément.
    * Avec Cloudflare, définissez l’enregistrement A sur **DNS only** (nuage gris) afin que le mode proxy n’empêche pas la configuration SSL.
    * La propagation des modifications DNS peut prendre jusqu’à 48 heures.

    Pour plus de détails, consultez [les domaines personnalisés](/fr/ja/features/publishing/custom-domains).
  </Accordion>

  <Accordion title="Comment résoudre les problèmes lorsqu’un domaine n’est pas vérifié ou qu’un certificat SSL n’est pas provisionné ?">
    Vérifiez les étapes suivantes dans l’ordre — la plupart des problèmes sont dus à l’une d’entre elles :

    1. **Attendez la propagation DNS.** La propagation des modifications peut prendre jusqu’à 48 heures. Utilisez un outil de recherche DNS pour vérifier que l’enregistrement est visible dans le monde entier.
    2. **Supprimez les enregistrements AAAA.** Les enregistrements IPv6 (AAAA) associés au même nom d’hôte que l’enregistrement A peuvent bloquer le SSL.
    3. **Supprimez les enregistrements A anciens ou conflictuels.** Pour le domaine racine, ne conservez que les enregistrements A pointant vers Replit.
    4. **Configurez Cloudflare en mode DNS only.** Le nuage orange (mode proxy) empêche le provisionnement du SSL.
    5. **Déconnectez puis reconnectez le domaine dans Publishing → Domains → Manage**, afin de forcer l’obtention d’un nouveau certificat, puis attendez quelques minutes avant de recharger la page.
    6. **Vérifiez les enregistrements CAA.** Si des enregistrements CAA existent, au moins l’un d’eux doit autoriser Let&#39;s Encrypt en tant qu’émetteur, car Replit émet les certificats via Let&#39;s Encrypt.

    Ces étapes s’appliquent aux domaines enregistrés auprès d’un fournisseur externe. Si vous avez acheté votre domaine sur Replit, [contactez l’assistance Replit](https://replit.com/support). Consultez les [domaines personnalisés](/fr/ja/features/publishing/custom-domains).
  </Accordion>

  <Accordion title="Comment configurer l’authentification Clerk avec un domaine personnalisé ?">
    Plusieurs problèmes surviennent fréquemment lors de l’utilisation de [l’authentification Clerk](/fr/ja/features/auth-and-identity/clerk-auth) avec un domaine personnalisé :

    * **Avertissement « Clerk CNAME records required ».** Il s’agit d’une exigence de l’intégration Clerk, qui ne bloque ni la vérification du domaine ni le SSL. Ouvrez **Publishing → Domains**, sélectionnez **Manage**, recherchez la section de configuration DNS de l’authentification, puis ajoutez exactement chaque enregistrement CNAME affiché auprès de votre fournisseur DNS. Si cette section n’apparaît pas, déconnectez puis reconnectez le domaine.
    * **Le domaine reste bloqué en cours de vérification après avoir déjà utilisé Clerk.** Si le domaine était connecté à une autre application Clerk, supprimez-le d’abord depuis le [dashboard Clerk](https://dashboard.clerk.com), puis déconnectez et reconnectez le domaine dans Replit.
    * **Migration vers votre propre instance Clerk.** Passer de Clerk géré par Replit à votre propre instance nécessite des étapes manuelles — [contactez l’assistance Replit](https://replit.com/support). Consultez [Puis-je utiliser ma propre application Clerk au lieu de celle gérée par Replit ?](/fr/ja/features/auth-and-identity/clerk-auth#can-i-bring-my-own-clerk-app-instead-of-using-the-replit-managed-one).

    Si le problème persiste, [contactez l’assistance Replit](https://replit.com/support) en indiquant le nom de domaine, le nom du projet et les actions que vous avez déjà entreprises.
  </Accordion>
