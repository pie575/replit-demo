이미지 생성은 디자인 기술이나 외부 도구 없이도 독창적인 시각 콘텐츠를 만들 수 있게 해줍니다. 아이콘과 일러스트부터 배경과 UI 요소까지, 개발 워크플로 내에서 직접 모든 것을 생성할 수 있습니다.

## 기능

Agent의 이미지 생성으로 시각적으로 매력적인 애플리케이션을 만들어 보세요. 이를 통해 스톡 사진, 외부 디자인 도구, 기본적인 시각 콘텐츠를 위한 디자이너 고용의 필요성이 사라집니다. 포트폴리오 웹사이트를 만들든, 게임을 빌드하든, 모바일 앱 인터페이스를 디자인하든, 이미지 생성은 프로젝트에 맞춘 커스텀 비주얼을 제공합니다.

Agent가 수행할 수 있는 이미지 생성 작업:

* **맞춤형 이미지 생성**: 상세한 설명과 사양을 기반으로 이미지 생성
* **스타일 적용**: 사실적인 스타일부터 만화 같은 스타일까지 다양한 예술적 스타일로 이미지 생성
* **투명 배경**: 이미지를 투명 PNG로 생성하거나, 기존 이미지에서 배경을 제거 — 로고, 아이콘, 스티커, 제품 컷아웃에 적합
* **프로젝트 통합**: 생성된 이미지를 앱 코드베이스에 원활하게 추가
* **반복적인 개선**: 피드백을 바탕으로 이미지를 수정하고 개선

## 사용법

이미지 생성은 Agent에 내장되어 있어 따로 켤 필요가 없습니다. Agent가 활성화된 Replit 앱을 열고 필요한 시각 콘텐츠를 만들어달라고 Agent에게 요청하세요. Agent는 요청에 따라 이미지 생성 시점을 자동으로 판단하여 사양에 맞는 맞춤형 이미지를 만들어 줍니다.

### Agent가 이미지 생성을 사용하는 경우

Agent는 프로젝트를 위한 시각 콘텐츠를 요청할 때 이미지 생성을 트리거합니다:

| 사용 사례           | 예시 프롬프트                              |
| --------------- | ------------------------------------ |
| **앱 아이콘 및 로고**  | "피트니스 추적 앱을 위한 모던한 로고를 생성해줘"         |
| **웹사이트 배경**     | "내 포트폴리오 사이트를 위한 은은한 그라디언트 배경을 만들어줘" |
| **게임 에셋**       | "플랫포머 게임을 위한 픽셀 아트 스프라이트를 생성해줘"      |
| **UI 일러스트**     | "내 앱의 빈 상태 화면을 위한 일러스트를 만들어줘"        |
| **마케팅 비주얼**     | "랜딩 페이지를 위한 히어로 이미지를 생성해줘"           |
| **제품 목업**       | "내 앱이 다양한 기기에서 실행되는 목업 이미지를 만들어줘"    |
| **투명 로고 및 아이콘** | "투명 배경으로 내 앱 로고를 생성해줘"               |

### 이미지 생성을 위한 모범 사례

Agent의 이미지 생성에서 최상의 결과를 얻으려면 다음 가이드라인을 따르세요:

**구체적이고 자세하게 설명하기**

* 스타일, 색상, 구성, 분위기에 대한 세부 사항을 포함
* 관련이 있다면 크기나 종횡비를 명시
* 의도한 용도(아이콘, 배경, 일러스트 등)를 언급
* 다른 콘텐츠 위에 올릴 로고, 아이콘, 스티커, 컷아웃이 필요할 때는 투명 배경을 요청

**반복하고 개선하기**

* 기본적인 설명으로 시작한 다음 결과를 바탕으로 개선
* Agent에게 생성된 이미지의 특정 부분을 수정하도록 요청
* 다양한 창작 방향을 탐색하기 위해 변형을 요청

**프로젝트의 스타일 고려하기**

* 앱 전체에서 시각적 일관성 유지
* 브랜드나 디자인 시스템에 맞는 스타일 선호도를 명시
* 기존 시각 요소와 어울리는 이미지를 요청

### 예시 프롬프트

이미지 생성을 시작하려면 다음 예시 프롬프트를 사용해 보세요:

<AiPrompt>
  작업 관리 앱을 위한 깔끔하고 모던한 아이콘을 생성해줘.
  아이콘은 원형이어야 하고 파란색에서 보라색으로 이어지는 그라디언트 배경을 가지며,
  흰색의 간단한 체크마크 심볼이 특징이야.
  앱 아이콘으로 사용하기 적합하게 만들어줘.
</AiPrompt>

<AiPrompt>
  코딩 튜토리얼 웹사이트를 위한 히어로 일러스트를 만들어줘.
  화면에 코드가 표시된 컴퓨터 앞에 앉아 있는 친근한 만화 캐릭터를 보여줘.
  파란색과 주황색을 사용한 따뜻한 색상 팔레트를 써줘.
  초보자에게 다가가기 쉽고 격려하는 듯한 스타일이어야 해.
</AiPrompt>

<AiPrompt>
  레트로 스타일 플랫포머 게임을 위한 픽셀 아트 적 캐릭터 세트를 생성해줘.
  날아다니는 박쥐, 걸어다니는 버섯, 뛰어다니는 슬라임이 필요해.
  각각 32x32 픽셀이고 8가지 색으로 제한된 색상 팔레트를 사용해줘.
  귀엽지만 살짝 위협적으로 만들어줘.
</AiPrompt>

### 프로젝트 통합

Agent는 생성된 이미지를 코드베이스에 원활하게 통합합니다:

* **자동 파일 생성**: 생성된 이미지는 프로젝트 파일에 직접 저장됩니다
* **코드 업데이트**: Agent가 새 이미지 파일을 참조하도록 코드를 업데이트합니다
* **에셋 정리**: 이미지는 프로젝트 구조 내 적절한 디렉토리에 배치됩니다

이렇게 간소화된 워크플로를 통해 개발 환경을 벗어나지 않고도 시각 콘텐츠를 생성하고 구현할 수 있습니다.

<Note>
  Replit의 이미지 생성은 [Google의 Imagen 4](https://deepmind.google/models/imagen/)로 구동되며, 이는 미세한 디테일과 향상된 텍스트 렌더링 기능을 갖춘 고품질의 사실적인 이미지를 만드는 데 뛰어난 최첨단 텍스트-이미지 모델입니다.
</Note>
