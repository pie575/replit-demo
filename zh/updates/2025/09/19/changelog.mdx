<div id="autonomy-level-control-for-agent">
  ### Agent 自主级别控制
</div>

通过全新的自主级别设置，您可以掌控 Agent 在项目中独立工作的程度。可选择低 (仅执行任务列表) 、中 (增加代码审查) 、高 (全面审查应用) 或 Max (完全自主规划) ，以满足您的工作流偏好和项目需求。

<div id="malicious-file-detection">
  ### 恶意文件检测
</div>

<div id="supply-chain-attack-blocking">
  ### 阻止供应链攻击
</div>

增强型安全保护会自动阻止被入侵 npm 软件包窃取数据的尝试，在不中断工作流程的同时，保障您开发过程中的敏感信息安全。

</div>

<div id="mobile-connectors-support">
  ### Connectors 移动端支持
</div>

Agent 3 推出了 Connectors，让你能够连接 GitHub、Notion 等第三方服务。

现在，你可以随时随地在应用中添加 Connectors，全面支持移动端操作。

在[此处](/zh/replitai/integrations)详细了解 Connectors。
