<div id="use-replit-from-claude">
  ### 在 Claude 中使用 Replit
</div>

Replit 现已作为 connector 在 Claude 中提供。只需连接一次，你就可以直接在与 Claude 的对话中创建、更新 Replit App，并就其提问。你还可以将设计稿从 Claude Design 直接发送到 Replit，它会以可运行的应用形式打开，Agent 则会规划如何将其变成可用的产品。

<div id="new-mcp-servers-apollo-and-black-forest-labs">
  ### 新增 MCP 服务器：Apollo 和 Black Forest Labs
</div>

两款新服务器已加入一键式 MCP 目录。连接 **Apollo**，通过与 Agent 对话研究客户和联系人，并创建外联名单。连接 **Black Forest Labs**，无需离开 project 即可生成和编辑 FLUX 图像。

在 [MCP 列表](/zh/features/mcp/overview)中了解更多。

<div id="voice-mode">
  ### 语音模式
</div>

现在，你可以直接说出想要构建的内容。点击 Agent 聊天框中的麦克风，说出你的 prompt，Replit 会将语音转写为可编辑的文本。确认文本内容、按需修改，然后像发送普通消息一样发送即可。所有 Replit 套餐均可使用语音模式。

<div id="teams-and-enterprise">
  ## Teams 和 Enterprise
</div>

<div id="invite-external-guests-to-enterprise-workspaces">
  ### 邀请外部访客加入 Enterprise workspace
</div>

Enterprise 管理员现在无需通过身份提供方，即可将外部协作者以访客身份邀请进 workspace。只需将某个应用分享给外部邮箱地址，对方便会以访客身份加入，且仅能访问该应用。访客会集中显示在专门的表格中，你可以查看他们各自能访问哪些应用，并随时撤销访问权限。
