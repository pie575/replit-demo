export const appIconPrompt = "为 PixelGames 生成 3 个不同的 1024x1024 App 图标设计方案。";

两个应用商店均要求提供应用图标才会接受提交。Replit 可直接生成图标，
无需另行使用设计工具。

<div id="what-each-store-needs">
  ## 各应用商店的要求
</div>

* **App Store：**1024×1024，不支持透明背景，无需圆角，Apple 会自动添加。
* **Google Play：**512×512。

<div id="generate-it">
  ## 生成图标
</div>

发送提示词前，请切换到 **Design** 模式，以便 Agent 生成图像。

<AiPrompt>
  {appIconPrompt}
</AiPrompt>

Agent 会一次生成几个不同方向的方案，方便你比较后再决定采用哪一个。
