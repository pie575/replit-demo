Replit inclut désormais une fonctionnalité d'analyse de sécurité. C'est un moyen simple d'analyser le code pour détecter les problèmes de sécurité courants.

### Aperçus de points de contrôle

Présentation des aperçus de points de contrôle dans l'environnement de développement de Replit. Visualisez votre application à différentes étapes du développement sans reconstruire ni restaurer les versions précédentes.

Cette capacité facilite le suivi de la progression, la comparaison des itérations et la gestion des versions—offrant une vue complète de l'évolution de votre projet. Cette fonctionnalité s'associe au [flux de travail vibe coding](https://learn.replit.com).

### Voyage dans le temps Replit

La fonctionnalité de voyage dans le temps est arrivée sur Replit. Naviguez de manière transparente dans l'historique de votre projet tout en maintenant votre contexte de développement.

Explorez différentes versions, comprenez les changements évolutifs, récupérez-vous des erreurs et expérimentez avec plus de confiance—tout cela dans votre environnement de développement actuel. Cela complète l'[intégration Git](/fr/learn/projects-and-artifacts/version-control) pour un contrôle de version plus puissant.

### Demander à Agent d'ajouter une base de données

La configuration de la base de données devient simple grâce à l'intégration d'Agent dans le volet DB. Ce flux de travail alimenté par l'IA vous guide dans la configuration de la base de données, simplifiant la mise en œuvre de la persistance des données sans code de configuration complexe.

Les développeurs peuvent se concentrer sur la création des fonctionnalités principales tandis qu'Agent gère les détails de la base de données. En savoir plus sur [Replit Agent](/fr/core-concepts/agent) et les [options de base de données](/fr/learn/projects-and-artifacts/storage-and-databases).

### Correspondance Replit Auth par défaut

L'authentification des utilisateurs dans vos applications devient sans effort grâce à la correspondance automatique de Replit Auth.

Cette fonctionnalité s'active lorsque votre application nécessite une authentification. Elle élimine le besoin de formulaires d'inscription personnalisés, de systèmes de récupération de mot de passe ou de configurations de connexion sociale. Cela crée un chemin plus fluide vers la gestion sécurisée des utilisateurs.

### Vérification d'e-mail en plein écran

Un processus de vérification simplifié pour les actions protégées renforce la sécurité du compte.

Cette approche intégrée présente la vérification par e-mail après la connexion lorsque nécessaire. Elle garantit la protection du compte tout en maintenant une expérience utilisateur cohérente—équilibrant sécurité et commodité.

Cela fait partie de l'engagement continu envers la [sécurité de l'information](/fr/teams/information-security/overview).

### Blueprint Google Analytics

Surveillez les performances de votre application avec le blueprint Google Analytics.

Agent intègre désormais la configuration des analyses directement dans votre flux de développement. Cela permet la surveillance du trafic, le suivi du comportement des utilisateurs et les métriques de croissance sans configuration complexe.

Il apporte des capacités d'analyse professionnelles à chaque développeur. Essayez-le avec les [intégrations Agent](/replitai/integrations).

## Équipes et Entreprise

### SCIM pour les clients Enterprise

La nouvelle intégration SCIM permet aux clients Enterprise de gérer l'accès à Replit directement via leurs fournisseurs d'identité.

Connectez Okta, Active Directory, Rippling ou d'autres plateformes d'identité pour automatiser le provisionnement et le déprovisionnement des sièges Replit. Cela élimine la surcharge de gestion manuelle des utilisateurs et simplifie les flux de travail d'entreprise.

Lisez la [documentation SCIM](/fr/teams/identity-and-access-management/scim) détaillée pour commencer.

### Sièges observateurs pour Replit Teams

Présentation des sièges observateurs pour Replit Teams. Partagez vos applications avec des parties prenantes qui visualisent et interagissent uniquement avec vos applications—sans les modifier—sans nécessiter de licences d'équipe complètes.

Idéal pour le partage avec des dirigeants, des clients ou des coéquipiers qui utilisent mais ne construisent pas vos outils. Découvrez comment configurer et gérer les [sièges observateurs](/fr/teams/identity-and-access-management/viewer-seats).
