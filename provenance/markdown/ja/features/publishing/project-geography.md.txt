# プロジェクトの地域

> 公開したプロジェクトのコンピューティングとストレージをホストする場所を選択します。

プロジェクトの地域とは、プロジェクトの公開先となる地域のことです。公開時に選択し、公開されたプロジェクトのコンピューティングとストレージのホスト先を制御します。

<Note>
  プロジェクトの地域と[ワークスペースの地域](/features/collaboration/workspace-geography)は異なる場合があります。ワークスペースの地域は、ワークスペース内の新しいプロジェクトの開発リソースがホストされる場所を制御します。
</Note>

## プロジェクトの地域が制御するもの

デフォルトでは、Replitはあなたに最も近い地域を推奨します。これにより、アプリの訪問者のレイテンシーを削減し、データ所在地の要件を満たすのに役立ちます。

地域を選択すると、コンピューティング、データベース、Object Storageなど、プロジェクトの公開済みアーティファクトはすべて自動的に同じリージョンに配置されます。地域固有のプロキシも、アプリの訪問者のレイテンシーを削減するのに役立ちます。

## プロジェクトの地域を選択する

推奨されている地域以外を選ぶには、次の手順に従います。

<Steps>
  <Step>Replitプロジェクトで**Publishing**ツールを開きます。</Step>
  <Step>**Advanced**設定を展開します。</Step>
  <Step>**Geography**ドロップダウンから希望の地域を選択します。</Step>

  <Step>
    **Publish**を選択して、選択した地域にプロジェクトを公開します。
  </Step>
</Steps>

## 公開済みプロジェクトの地域を強制する

Enterprise管理者は、組織内のすべてのプロジェクトに対して公開先の地域を強制できます。ポリシーが設定されると、組織内のビルダーは設定された地域に公開します。このポリシーは、まだ公開されていないプロジェクトにのみ適用されます。すでに別の地域に公開済みのプロジェクトには影響しません。

<Note>
  公開先の地域を強制する機能はEnterprise向けの機能です。Enterpriseプランの詳細については、[料金](https://replit.com/pricing/)をご覧ください。
</Note>

<Steps>
  <Step>**アカウント設定**に移動します。</Step>
  <Step>**Advanced**を選択します。</Step>

  <Step>
    初めて公開するすべてのプロジェクトが使用しなければならない地域を選択します。
  </Step>
</Steps>

## 利用可能状況と制限

| 地域                | プロジェクト公開時の選択 |
| :---------------- | :----------- |
| **North America** | 可            |
| **Europe (EU)**   | 可            |
| **Asia**          | 可            |
| **South America** | 可            |
| **Australia**     | 可            |

<Note>
  プロジェクトの地域選択は、Core、Pro、Enterpriseのお客様が利用できます。無料プランのお客様はデフォルトでNorth Americaに公開されます。
</Note>

プロジェクトの地域を選択する前に、次の制限事項に注意してください。

* **公開後に地域を変更することはできません。** 一度プロジェクトをある地域に公開すると、その選択は永続的です。公開済みのプロジェクトを別の地域に移行することはできません。
* **開発環境と公開先の場所は異なる場合があります。** Object Storageなどのリソースは公開前に作成される場合があり、プロジェクトの地域と一致しないことがあります。
