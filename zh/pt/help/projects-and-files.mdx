本页解答有关项目和文件的常见问题。相关内容请参阅 [Secrets](/zh/pt/core-concepts/project-editor/app-setup/secrets)、[检查点和回滚](/zh/pt/features/version-control/checkpoints-and-rollbacks)以及[集成概览](/zh/pt/features/integrations/overview)。

<AccordionGroup>
  <Accordion title="如何将 Resend 或其他电子邮件服务集成到我的 Replit 应用中？">
    打开您的项目，前往 **工具 → 连接器**，找到相应服务 (如 Resend) 并将其连接。授权后，API 密钥会以 secret 的形式保存到您的项目中。如果您正在配置自定义电子邮件域名，请在 DNS 提供商处添加该服务显示的 DNS 记录。

    有关可用连接器的信息，请参阅[集成概览](/zh/pt/features/integrations/overview)和[添加集成](/zh/pt/build/add-integrations)。
  </Accordion>

  <Accordion title="我不小心删除了一个项目，可以恢复吗？">
    已删除的项目可在限定时间内恢复。在任意项目中打开 Shell，然后运行：

    ```bash theme={null}
    trash view
    trash restore nome-do-seu-projeto
    ```

    超过保留期后，已删除的项目将被永久移除。如果已超过保留期，请[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="如何下载或导出 Replit 项目？">
    在文件树顶部点击三点菜单，然后选择**下载为 zip**。对于大型项目，下载可能需要一些时间。如果下载失败，请打开 Shell 并执行 `zip -r project.zip .`，然后从文件树下载 `project.zip`。
  </Accordion>

  <Accordion title="如何共享项目或添加协作者？">
    您有以下三种选择：

    * **只读**—将项目隐私设置为公开，让任何拥有链接的人都能查看项目。
    * **受邀编辑**—选择 **邀请**，输入用户名或电子邮件地址，然后设置权限级别。
    * **加入链接**—在 **邀请** 中创建加入链接，让任何拥有该链接的人都能加入并编辑。

    Core 最多支持 5 名协作者，Pro 最多支持 15 名；协作者无需订阅付费计划即可编辑您的项目。请参阅[工作区](/zh/pt/features/collaboration/workspaces)。
  </Accordion>

  <Accordion title="如何将 GitHub 仓库连接到 Replit？">
    在账户的已连接服务中关联 GitHub 账户，然后在项目中打开 [Git 工具](/zh/pt/features/workspace-tools/git-interface) 并连接仓库。在 Git 面板中启用自动同步，实现双向同步。要导入现有仓库，请参阅[从提供商导入](/zh/pt/build/import-from-providers)。

    如果 Git 同步不再正常工作，请在已连接服务中重新连接 GitHub。细粒度个人访问令牌可提供更可靠的连接。
  </Accordion>

  <Accordion title="我的 Repl 运行缓慢或编辑器卡顿——可以尝试什么？">
    如果编辑器卡住，请尝试：

    * 使用 `Cmd+Shift+R` (Mac) 或 `Ctrl+Shift+R` (Windows) 强制刷新。
    * 关闭未使用的文件标签页。
    * 使用 `Cmd+K` (Mac) 或 `Ctrl+K` (Windows) 打开命令面板，搜索并选择 **Restart compute**。
    * 尝试使用其他浏览器，以排除扩展程序的影响。

    如果代码运行缓慢而编辑器没有卡住，请检查是否存在高负载循环或内存限制。你可以在编辑器底部的资源面板中查看 CPU 和内存使用情况。
  </Accordion>

  <Accordion title="如何在项目中使用环境变量和 Secrets？">
    打开 **Secrets** 工具 (锁形图标) ，选择 **+ 新建 Secret**，然后输入键和值。在代码中通过 `process.env.API_KEY` (Node.js) 或 `os.environ["API_KEY"]` (Python) 读取它。

    开发环境 [Secrets](/zh/pt/core-concepts/project-editor/app-setup/secrets) 面板中的 Secrets 仅在编辑器中可用。对于已部署的应用，请在部署 Secrets 中添加相同的键——两者按设计分别存储。
  </Accordion>

  <Accordion title="如何使用账户 Secrets（Vault）？">
    [账户 Secrets](/zh/pt/core-concepts/project-editor/app-setup/secrets) 可用于您的所有项目，适合存储需要重复使用的密钥。在账户设置中添加后，它们便可在您拥有的每个项目中使用。如果同一密钥同时存在于账户 Secrets 和项目的 Secrets 面板中，则以项目级的值为准。
  </Accordion>

  <Accordion title="如何从 Git 合并冲突或 Git 状态损坏中恢复？">
    打开 Shell 并运行 `git status` 查看冲突。

    <Warning>接下来的两条命令会丢弃未提交的更改，且无法撤销。请先保存所有需要保留的内容——例如，将已编辑的文件复制到项目外。</Warning>

    要丢弃本地更改并恢复到上一次的干净状态，请运行 `git checkout -- .`；要重置到上一次提交，请运行 `git reset --hard HEAD`。

    如果 `.git` 文件夹已损坏，导致 Git 命令执行失败，请打开新的 Agent Chat 并粘贴错误信息——Agent 通常可以修复仓库。请参阅[灾难恢复](/zh/pt/features/version-control/disaster-recovery)。
  </Accordion>

  <Accordion title="如何将我的项目回滚到之前的检查点？">
    Replit 会在 Agent 工作期间保存 [检查点](/zh/pt/features/version-control/checkpoints-and-rollbacks)。在 Agent 面板中，找到要撤销的更改前的消息，选择其旁边的回滚选项，然后确认。

    <Note>
      Replit 不再支持将已发布的应用回滚到之前的版本。要进行回滚，请将项目回滚到之前的检查点 (如上所述) ，然后重新发布以重新部署该状态。要恢复单个文件，请打开该文件，选择文件名，然后使用**显示历史记录**恢复之前的版本。请参阅[文件历史记录](/zh/pt/features/version-control/file-history)。
    </Note>
  </Accordion>

  <Accordion title="如何将项目转移到另一个 Replit 帐户？">
    项目无法直接转移，但您可以复制项目。最简单的方法是将项目共享给目标账户，然后在该账户中创建分支。或者，您可以将项目下载为 zip 文件，再上传到另一个账户中的新 Repl。

    复制后，请在新项目中配置 Secrets、数据库和部署设置——这些内容不会随副本一同复制。有关分步说明 (包括如何迁移数据库中的数据) ，请参阅[手动将项目复制到另一个 workspace](/zh/pt/teams/identity-and-access-management/manually-copy-projects)。
  </Accordion>
</AccordionGroup>
