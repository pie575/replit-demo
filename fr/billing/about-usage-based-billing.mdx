La facturation à l&#39;utilisation de Publication comprend trois catégories :

1. Transfert de données sortant
2. Unités de calcul Autoscale
3. Requêtes

Vous pouvez consulter votre utilisation dans **Paramètres**, sous **Compte** → **Utilisation du compte**. La facturation intervient chaque mois ou lorsque vos coûts cumulés dépassent vos crédits mensuels. Les utilisateurs de Replit Core et Pro bénéficient d&#39;allocations mensuelles pour ces ressources.

Si vous avez besoin de crédits supplémentaires au-delà de l&#39;allocation mensuelle incluse dans votre abonnement, vous pouvez acheter des packs de crédits sur votre page de facturation. Consultez [Gérer vos dépenses](/fr/billing/managing-spend) pour en savoir plus sur les packs de crédits.

<div id="publishing">
  # Publication
</div>

<div id="1-publishing-outbound-data-transfer">
  ## 1. Transfert de données sortantes de Publication
</div>

Ce type d&#39;utilisation est facturé par octet. Les utilisateurs de Replit Core et Pro bénéficient d&#39;allocations mensuelles. Seules les données sortantes sont décomptées de cette allocation, ce qui peut entraîner des dépassements. En revanche, les données entrantes sont toujours gratuites.

| Abonnement  | Allocation                                                                |
| ----------- | ------------------------------------------------------------------------- |
| Replit Core | 100 GiB                                                                   |
| Replit Pro  | Consultez la [tarification de Replit Pro](https://www.replit.com/pricing) |

Les allocations s&#39;appliquent aux déploiements [Static](/fr/features/publishing/deployment-types#static), [Autoscale](/fr/features/publishing/deployment-types#autoscale), [Reserved VM](/fr/features/publishing/deployment-types#reserved-vm) et [Scheduled](/fr/features/publishing/deployment-types#scheduled).

Consultez la [page des tarifs](https://www.replit.com/pricing) pour connaître le tarif actuel du transfert de données sortantes.

***

<div id="2-compute-units">
  ## 2. Unités de calcul
</div>

Les déploiements Autoscale sont facturés en fonction des unités de calcul, qui prennent en compte l’utilisation du processeur et de la RAM au fil du temps.

Les dépassements sont facturés en fonction des unités de calcul. La facturation est calculée à l’unité de calcul près. Consultez la [page des tarifs](https://www.replit.com/pricing) pour connaître le prix actuel des unités de calcul.

Voici comment les secondes de RAM et de processeur d’un déploiement Autoscale sont converties en unités de calcul :

| Ressource               | Unités de calcul |
| ----------------------- | ---------------- |
| 1 seconde de RAM        | 2 unités         |
| 1 seconde de processeur | 18 unités        |

Les déploiements statiques ne consomment pas d’unités de calcul. Leur facturation concerne uniquement les transferts de données sortants au-delà d’un [seuil défini](#).

[En savoir plus sur les déploiements Autoscale](/fr/features/publishing/deployment-types#autoscale).

***

Les déploiements Autoscale tiennent également compte du nombre de requêtes.

<div id="databases">
  # Bases de données
</div>

Replit facture uniquement l’utilisation des [bases de données de production](/fr/features/data-and-storage/development-and-production) -- les bases de données de développement sont toujours gratuites et incluses avec chaque Replit App. Pour en savoir plus sur les bases de données de développement, consultez [Base de données de développement](/fr/features/data-and-storage/sql-database).

Replit PostgreSQL est entièrement géré et sans serveur, offrant une haute disponibilité sans intervention et ne nécessitant aucune maintenance. La facturation des bases de données de production repose sur l’utilisation réelle, ce qui peut générer d’importantes économies.

Les bases de données PostgreSQL de production sont facturées selon deux indicateurs d’utilisation :

* **[Temps de calcul](#compute-time)** : la quantité de ressources de calcul consommées par heure.
* **[Stockage des données](#data-storage)** : le volume total de données stockées, y compris les données historiques.

Vous pouvez consulter votre utilisation actuelle des ressources, y compris celle des bases de données de production, dans **Paramètres** → **Compte** → **Utilisation du compte**.

<div id="compute-time">
  ## Temps de calcul
</div>

Le temps de calcul correspond au nombre d&#39;heures pendant lesquelles votre base de données reste active au cours d&#39;une période de facturation donnée. Les bases de données sont considérées comme actives lorsqu&#39;elles reçoivent des requêtes, puis pendant 5 minutes supplémentaires après la dernière requête. Si une base de données reste inactive pendant 5 minutes, elle est suspendue et passe à l&#39;état inactif.

<div id="data-storage">
  ## Stockage des données
</div>

Le stockage des données correspond au volume total de données stockées dans toutes les bases de données de votre compte, mesuré en gibioctets (GiB). Il est calculé sur la base de la quantité maximale d’espace de stockage utilisée chaque mois. Chaque base de données PostgreSQL consomme 33 Mo de stockage, même si elle ne contient aucune donnée. Il s’agit de l’empreinte de stockage par défaut du serveur Postgres.

<Note>La limite totale de stockage pour chaque base de données de production est de 10 gibioctets (GiB). Les bases de données de développement incluent 20 GiB de stockage gratuit par Replit App.</Note>

<div id="additional-notes">
  # Remarques supplémentaires
</div>

En cas de problème avec votre mode de paiement, nous vous en informerons. Des échecs de paiement répétés peuvent entraîner la suspension de vos applications publiées. Si cela se produit, veuillez [contacter l&#39;assistance](https://replit.com/help) et mettre à jour vos informations de paiement afin de retrouver l&#39;accès à nos services.
