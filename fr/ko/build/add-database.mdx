Dans [Ajouter une connexion](/fr/ko/build/add-login), vous avez ajouté la connexion à Velocity. Mais les véhicules de la liste et les réservations créées par les clients disparaissent dès que la page est actualisée, car ils n&#39;existent que dans le navigateur. Ajoutez une base de données pour que tout soit conservé.

<div id="agent">
  ## Demander à Agent d’enregistrer les données
</div>

Velocity utilise Neon, la base de données Postgres gérée par Replit. Neon gère efficacement les réservations simultanées, s’adapte au trafic réel des clients et Agent le provisionne automatiquement avec des environnements de développement et de production distincts. Vous n’avez pas besoin de vous inscrire au tableau de bord Neon ni de coller des clés.

<AiPrompt>
  Enregistrez les données de Velocity dans une base de données afin que les véhicules, les disponibilités et les réservations ne disparaissent pas lors de l’actualisation.<br />
  Utilisez Neon (Postgres).<br />
  À enregistrer : chaque véhicule (constructeur, modèle, année, tarif journalier, photo, emplacement), le calendrier de disponibilité de chaque véhicule et chaque réservation (date de prise en charge, date de retour, véhicule, client).<br />
  Associez chaque réservation au client connecté afin que chacun ne puisse voir que les siennes.<br />
  Empêchez la double réservation d’un même véhicule lorsque les dates se chevauchent.<br />
  Indiquez-moi ce qu’il faut tester après les modifications.
</AiPrompt>

Agent provisionne la base de données Neon, migre la liste des véhicules et les réservations des données en mémoire vers la base de données, et ajoute une vérification pour éviter qu’une même Lamborghini soit réservée deux fois.

<div id="section">
  ## Vérifier que tout est bien conservé
</div>

1. Connectez-vous à Velocity dans Preview et réservez un véhicule pour samedi prochain.
2. Actualisez la page. Votre réservation doit toujours apparaître dans « My bookings ».
3. Redémarrez l’application dans le chat Agent. La liste des véhicules et les réservations doivent toutes être conservées.
4. Avec un deuxième compte, essayez de réserver le même véhicule pour le même samedi. Velocity doit indiquer que le véhicule n’est pas disponible et proposer une autre date ou un autre véhicule.
5. Déconnectez-vous, puis reconnectez-vous. Vos réservations doivent toujours être présentes.

Si une réservation disparaît à une quelconque étape, décrivez précisément le problème à Agent.

<AiPrompt>
  J’ai réservé un véhicule dans Velocity, mais ma réservation disparaît après l’actualisation.<br />
  Vérifiez si les réservations sont enregistrées dans la base de données ou uniquement sur la page.<br />
  Apportez la correction la plus minimale possible et indiquez-moi comment la vérifier.
</AiPrompt>

Vous pouvez également demander à Agent une vue d’administration simple pour consulter le contenu de la base de données.

<AiPrompt>
  Montrez-moi dans Velocity une page d’administration simple qui liste tous les véhicules et toutes les réservations de la base de données, regroupés par véhicule.<br />
  Affichez-la uniquement pour moi, le propriétaire du projet.
</AiPrompt>

<div id="url">
  ## Déployer et vérifier depuis l&#39;URL publique
</div>

La configuration Neon d&#39;Agent fournit à Velocity des environnements de développement et de production distincts par défaut. Redéployez Velocity depuis le chat Agent ou depuis la tuile Publishing, puis ouvrez l&#39;URL publique dans un nouvel onglet. Replit connecte automatiquement les identifiants Neon de production à l&#39;application déployée — effectuez une réservation depuis l&#39;URL publique, actualisez la page et vérifiez que la réservation est toujours présente.

Désormais, Velocity mémorise tous les véhicules, toutes les dates de disponibilité et toutes les réservations. Vos réservations ne disparaîtront plus à la prochaine actualisation.

<div id="section-3">
  ## Besoin d&#39;aide supplémentaire ?
</div>

* **Les réservations sont enregistrées dans le Preview, mais pas sur l&#39;URL publique :** demandez à Agent de vérifier que les identifiants Neon de production sont bien connectés à l&#39;application déployée.
* **Difficulté à vérifier les données :** demandez à Agent d&#39;ajouter une vue d&#39;administration simple qui liste tout le contenu de la base de données.
* **Vous souhaitez préremplir la liste des véhicules avec des données initiales :** demandez à Agent d&#39;ajouter un script ponctuel qui charge les véhicules réels dans la base de données.
* **Vous voulez une base de données sans configuration pour un prototype rapide :** utilisez plutôt [Replit Database](/fr/ko/features/data-and-storage/sql-database) — intégrée à chaque Repl, sans provisionnement séparé.
