从 TikTok Ads、Snapchat Ads、Meta Ads 和 Google Ads 获取上周的广告数据，集中分析
广告效果，并根据广告支出、点击率、单次获客成本和广告支出回报率找出表现最佳的广告。
对表现优劣的广告进行排序，以便了解
哪些创意素材应在各平台扩大投放或暂停投放。

* 需要判断哪些广告应扩大投放、哪些应暂停投放的增长负责人。

<div id="before-you-start">
  ## 开始前准备
</div>

在 Replit 中连接 TikTok Ads 和 Snapchat Ads。对于 Google Ads 和 Meta Ads，请准备好 API
密钥。Agent 需要拉取数据时会向你索取。选择日期范围，并说明哪些指标最重要
(广告支出回报率还是单次获客成本) 。

<div id="prompt-the-agent">
  ## 向 Agent 发出提示
</div>

<AiPrompt>
  创建一个每周一 9:00 运行的 Routine。获取上周在
  TikTok Ads、Snapchat Ads、Meta Ads 和 Google Ads 上投放的广告。汇总各渠道的效果数据，并根据
  广告支出、点击率、单次获客成本和广告支出回报率找出表现最佳的广告。
  对表现最佳和最差的广告进行排名，并告诉我哪些创意素材应扩大投放，哪些应暂停。
</AiPrompt>

<div id="what-to-expect">
  ## 使用预期
</div>

Agent 会生成一份跨平台创意素材排名表。调整预算前，请先在各广告管理平台中抽查总额是否一致。日期范围和时区往往不同，因此请先在每个广告管理平台中统一时间范围。选择排名最高和最低的广告，在广告管理平台中打开它们，并在调整预算前确认支出金额一致。

<div id="make-it-work-for-you">
  ## 按你的需求灵活使用
</div>

<AiPrompt>
  按创意主题分组，而非仅按广告系列名称分组。展示各主题在哪些

<AiPrompt>
  每周一在 Slack 发布总结：表现最佳的 3 条广告、表现最差的 3 条广告，以及建议的预算

</AiPrompt>

<div id="troubleshooting">
  ## 故障排除
</div>

* **无法拉取 Google Ads 或 Meta Ads 数据：**这两者不是原生 connector。Agent 会要求你提供 API 密钥。请提前准备好，并确认该密钥有权读取你需要关注的广告账户。
* **汇总数据与广告管理平台不一致：**日期范围和时区往往不同。请让 Agent 使用与各平台相同的时间范围 (通常为上周一至周日) ，并在调整预算前抽查广告支出。
* **表格中缺少某个平台：**请先在 Replit 中连接 TikTok Ads 和 Snapchat Ads。如果原生连接已过期，请重新连接并重新运行 Routine。
