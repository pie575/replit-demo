## Fonctionnalités

### Cas d'usage pris en charge

**Disponibles actuellement :**

* **Agent Slack** - Créez des Slackbots intelligents capables de répondre à des questions, de s'intégrer à des API et d'automatiser des tâches
* **Agent Telegram** - Construisez des bots Telegram pour le service client, la planification, le divertissement et plus encore
* **Automatisation planifiée** - Configurez des workflows planifiés qui s'exécutent automatiquement à des heures définies

**Prochainement :**

* **Déclencheurs webhook personnalisés** : Répondez à tout événement externe ou appel API via une URL webhook

### Fonctionnalités supplémentaires

* **Intégrations riches** : Connectez-vous à Outlook, Spotify, Notion, Linear, GitHub et plus encore
* **Environnement de test** : Testez vos agents et visualisez les workflows avant le déploiement
* **Déploiement cloud** : Configuré automatiquement pour une disponibilité 24h/24 avec des déploiements Autoscale ou planifiés

## Comment démarrer

### Étape 1 : Sélectionnez Agents & Automations

Depuis la page d'accueil Replit après connexion, **sélectionnez « Agents & Automations »** dans le sélecteur de type d'application sur la page d'accueil.

<Frame>
  <img src="/assets/mirror/agents-automations-homepage-2-b2bb064da3b0.png" alt="Page d'accueil Replit affichant la sélection Agents & Automations avec le label Beta et la zone de saisie de prompt" width="3024" height="1720" data-path="images/replitai/agents-automations-homepage-2.png" />
</Frame>

### Étape 2 : Choisissez votre type de déclencheur

Vous verrez ensuite un sélecteur de type de déclencheur. Choisissez parmi les options disponibles :

* **Slack** - Créez des Slackbots intelligents intégrés à votre espace de travail
* **Telegram** - Construisez des bots Telegram pour différents cas d'usage
* **Automatisation planifiée** - Configurez des workflows planifiés qui s'exécutent automatiquement

### Étape 3 : Saisissez votre prompt

**Saisissez votre prompt** décrivant ce que vous souhaitez que votre agent réalise.

### Étape 4 : Laissez Agent construire votre automatisation

Agent créera votre automatisation en fonction de votre prompt et du type de déclencheur sélectionné, en incluant toutes les intégrations nécessaires et la configuration de déploiement.

<Frame>
  <img src="/assets/mirror/agent-automations-testing-environment-0665d9cb600a.png" alt="Environnement de test Agent affichant une automatisation StockReporter avec visualisation du workflow et interface de test" width="3456" height="1984" data-path="images/replitai/agent-automations-testing-environment.png" />
</Frame>

<Accordion title="Accéder au volet Agents & Automations">
  Une fois votre projet créé, vous trouverez un **volet Agents & Automations** dédié dans votre espace de travail :

  * **Emplacement** : S'ouvre sous la zone d'aperçu dans le Project Editor
  * **Fonctions** :
    * Voir votre agent et interagir avec lui
    * Tester les fonctionnalités du chatbot avant le déploiement
    * Visualiser les workflows d'automatisation
    * Surveiller les journaux et déboguer les problèmes
  * **Test** : Discutez directement avec votre agent dans le volet pour tester les réponses et le comportement
</Accordion>

### Exigence de déploiement

<Warning>
  **Déploiement requis** : Votre agent ou automatisation doit être déployé pour
  fonctionner avec des déclencheurs externes tels que Slack, Telegram ou les
  automatisations planifiées. Le volet de test fonctionne pour le développement
  et les tests, mais les déclencheurs en direct nécessitent un déploiement.
</Warning>

Agent vous invitera automatiquement à déployer votre projet lorsqu'il est prêt. Choisissez le type de déploiement approprié :

* **Déploiements Autoscale** - Pour les chatbots et les workflows pilotés par événements
* **Déploiements planifiés** - Pour les automatisations temporelles

## Cas d'usage et exemples pris en charge

### Exemples d'Agent Slack

**Assistant de recherche avec intégration Perplexity**

<AiPrompt>
  Créez un assistant Slackbot IA capable de répondre à des questions de
  recherche à l'aide de l'API Perplexity. Lorsqu'une personne pose une question
  dans le canal #research, il doit rechercher des informations actuelles et
  fournir des réponses complètes avec des sources.
</AiPrompt>

**Questions-réponses sur la base de code avec intégration GitHub**

<AiPrompt>
  Créez un Slackbot IA capable de répondre aux questions sur ma base de code
  via une intégration GitHub. Il doit pouvoir expliquer des fonctions, trouver
  des fichiers et aider au débogage en analysant notre dépôt.
</AiPrompt>

**Assistant e-mail avec intégration Outlook**

<AiPrompt>
  Créez un Slackbot IA capable de répondre aux questions sur mes e-mails
  Outlook. Il doit m'aider à trouver des e-mails spécifiques, à résumer des
  conversations et à fournir des réponses rapides aux requêtes e-mail courantes.
</AiPrompt>

### Exemples d'Agent Telegram

**Assistant professionnel avec planification de calendrier**

<AiPrompt>
  Créez un assistant professionnel IA capable de planifier des e-mails sur mon
  calendrier Outlook. Les utilisateurs doivent pouvoir demander des créneaux de
  réunion et le bot trouvera les disponibilités et enverra des invitations de
  calendrier.
</AiPrompt>

**Bot de recommandations musicales avec Spotify**

<AiPrompt>
  Créez un chatbot IA amusant qui peut renvoyer une chanson Spotify pour tout
  message que j'envoie décrivant l'ambiance souhaitée. Il doit comprendre les
  descriptions d'humeur et suggérer des morceaux parfaitement adaptés.
</AiPrompt>

**Bot de personnage fictif**

<AiPrompt>
  Créez un bot IA incarnant un personnage fictif - plus précisément Sherlock
  Holmes. Il doit répondre aux messages dans le personnage, résoudre des
  énigmes et s'engager dans des conversations de style détective.
</AiPrompt>

### Exemples d'automatisation planifiée

**Résumé quotidien des tâches Linear**

<AiPrompt>
  Envoyez-moi un e-mail chaque matin avec un résumé de mes nouvelles tâches
  depuis Linear. Incluez les priorités des tâches, les dates d'échéance et le
  contexte du projet pour m'aider à planifier ma journée.
</AiPrompt>

**Automatisation de synthèse d'e-mails**

<AiPrompt>
  Envoyez-moi un e-mail toutes les 6 heures avec un résumé de tous mes e-mails.
  Regroupez-les par importance et mettez en évidence les messages urgents
  nécessitant une attention immédiate.
</AiPrompt>

**Analyse hebdomadaire de la concurrence**

<AiPrompt>
  Chaque semaine le lundi à 8h, envoyez-moi un résumé des actualités sur mes
  concurrents à l'aide de la recherche web. Concentrez-vous sur les mises à
  jour des produits, les nouvelles de financement et les évolutions du marché.
</AiPrompt>
