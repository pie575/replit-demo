Console позволяет в реальном времени отслеживать и просматривать логи, выводимые запущенным Replit App.
Используйте информацию из текущих и предыдущих запусков, чтобы лучше понять работу приложения,
устранять ошибки и оптимизировать производительность.

<Tip>
  При отладке с помощью Agent добавляйте логи из Console в промпт, чтобы предоставить ему контекст.
</Tip>

<div id="recursos">
  ## Возможности
</div>

Console предлагает следующие инструменты, которые помогут вам понять работу приложения:

* **Логирование в реальном времени**: просматривайте вывод приложения по мере его работы
* **Помощь ИИ**: получайте рекомендации по исправлению ошибок, указанных в логах
* **История запусков**: просматривайте логи предыдущих запусков, чтобы отслеживать изменения

<div id="uso">
  ## Использование
</div>

Инструмент Console доступен непосредственно в редакторе проектов.

<Accordion title="Как открыть Console">
  В **панели инструментов** слева:

  1. Выберите <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="значок всех инструментов" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**, чтобы открыть список инструментов редактора проектов.
  2. Выберите <img class="icon-svg" src="/assets/mirror/console-8a41ac90789c.svg" alt="значок Console" width="16" height="16" data-path="images/icons/console.svg" /> **Console**.

  В **строке поиска**:

  1. Выберите <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="значок лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> значок лупы вверху, чтобы открыть поиск.
  2. Введите &quot;Console&quot;, найдите инструмент и выберите его в результатах поиска.
</Accordion>

При каждом нажатии кнопки **Run** в Replit App в Console появляется новая запись со следующей информацией:

* Команда, запустившая ваш код
* Дата и время
* Логи стандартного вывода и ошибок

На следующем снимке экрана показаны команда `npm run dev`, используемая для запуска приложения, и логи выполнения:

<Frame>
  <img src="/assets/mirror/console-log-entry-b57e5b89087d.png" alt="Запись лога Console с указанием выполненной команды" width="1948" height="870" data-path="images/workspace/console-log-entry.png" />

<Note>
  Логи на стороне клиента, например создаваемые кодом HTML, CSS и JS, отображаются только в инструментах разработчика Preview [Preview](/ru/pt/features/editor/preview).
</Note>

<div id="depurao-com-ia">
  ### Отладка с ИИ
</div>

Если в логах вы заметили ошибки или другую информацию, которую хотите прояснить, нажмите кнопку
**Ask AI** в верхней части записи. Откроется вкладка **Agent**, а
содержимое лога автоматически отправится на анализ.

<div id="comandos-de-entrada-de-log">
  ### Команды управления логами
</div>

Console предлагает следующие инструменты для управления логами:

* **Show Only Latest**: включите этот переключатель, чтобы отображать только последний запуск.
* **Collapse entry**: нажмите <img class="icon-svg" src="/assets/mirror/down-arrow-9c1cf9fd152e.svg" alt="иконка стрелки вниз" height="16" width="16" data-path="images/icons/down-arrow.svg" /> стрелку вниз слева от названия команды, чтобы скрыть логи.
* **Clear past runs**: выберите этот пункт, чтобы удалить логи предыдущих запусков. Это действие необратимо.

<div id="disponibilidade-de-rede">
  ### Доступность сети
</div>

Вы можете управлять доступностью в сети версии приложения для разработки.

Чтобы прекратить обработку запросов по URL для разработки, выберите значок <img class="icon-svg" src="/assets/mirror/network-off-5bdca8a4fe4e.svg" alt="значок отключённой сети" height="16" width="16" data-path="images/icons/network-off.svg" /> глобуса с перечёркиванием
в правой части строки сетевой информации.

Чтобы снова включить доступ, выберите значок <img class="icon-svg" src="/assets/mirror/network-on-15be2e5fb4f5.svg" alt="значок включённой сети" height="16" width="16" data-path="images/icons/network-on.svg" /> глобуса.

Чтобы просмотреть URL для разработки, выберите текст `{...}.replit.dev` в адресной строке.

<Frame>
  <img src="/assets/mirror/preview-dev-url-b36770b33769.png" alt="Расположение URL для разработки в Preview" width="1222" height="824" data-path="images/workspace/preview-dev-url.png" />
</Frame>

<Note>
  Ваше приложение остаётся доступным на вкладке Preview, даже если оно настроено на прекращение обработки запросов по URL для разработки.
</Note>

<div id="parar-um-comando-de-workflow">
  ### Остановка команды workflow
</div>

Вы можете остановить выполняющуюся команду workflow в инструменте Console редактора проектов.

Чтобы завершить команду запуска вашего Replit App, нажмите квадратную кнопку справа от строки с этой командой.

Чтобы перезапустить приложение, используйте кнопку **Run** workflow в верхней части редактора проектов.
