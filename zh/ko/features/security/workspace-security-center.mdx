Workspace 安全中心适用于所有套餐。您可以使用它扫描整个工作区内项目的[依赖项](/zh/ko/features/security/concepts#dependency)，并按[严重程度](/zh/ko/features/security/concepts#severity)查看 [CVE](/zh/ko/features/security/concepts#cve) [发现的问题](/zh/ko/features/security/concepts#finding)。还可以使用 Replit Agent 修复问题、[重新发布](/zh/ko/features/security/concepts#republish)受影响的项目，并导出 Software Bill of Materials ([SBOM](/zh/ko/features/security/concepts#sbom)) 报告以满足合规要求。

<Note>
  若要扫描单个项目，请在该项目的 **Security** 面板中打开 [Project Security Center](/zh/ko/features/security/project-security-center)。
</Note>

<Note>
  刚开始了解依赖安全？有关 CVE、SBOM、暴露程度、Fix with Agent、Republish 和 Auto-Protect 的定义，请参阅[安全概念](/zh/ko/features/security/concepts)。
</Note>

<div id="section">
  ## 功能
</div>

<div id="cve">
  ### CVE 检测
</div>

查看工作区中所有项目的漏洞。

* 根据[暴露程度](/zh/ko/features/security/concepts#exposure) (发布状态和可见性) 识别存在漏洞的项目，并确定修复优先级
* 查看每个发现的问题中受影响的软件包名称、版本和严重程度 (critical、high、medium、low)
* 查看各项目的修复指南

  <img src="/assets/mirror/dependency-vulnerabilities-table-1a6ca7375b9f.png" alt="Workspace 安全中心的 Dependency vulnerabilities 表，列出每个发现的问题的 CVE ID、严重程度、软件包和版本" width="3438" height="1984" data-path="images/workspace-security-center/dependency-vulnerabilities-table.png" />
</Frame>

<div id="section-2">
  ### 查看受影响的项目
</div>

了解哪些项目存在漏洞，并确定应优先修复哪些问题。

* 查看按暴露程度分组的易受攻击项目概览：项目总数、已发布项目数和公开发布项目数
* 查看受影响的 Replit 项目详情
* 按 CVE ID 或项目名称搜索，并按严重程度、所有者、发布状态 (Published / Not published) 和可见性 (Public / Private) 进行筛选
* 展开项目行，无需离开当前页面即可查看所有 CVE 发现的问题 (严重程度、软件包、版本、CVE ID)

  <img src="/assets/mirror/cve-affected-projects-89f807e09c87.png" alt="Workspace 安全中心中展开的 CVE 行，显示受漏洞影响的工作区项目" width="3438" height="1984" data-path="images/workspace-security-center/cve-affected-projects.png" />
</Frame>

<div id="fix-with-agent">
  ### 使用 Agent 修复并重新发布
</div>

无需离开安全中心，即可修复漏洞并重新部署。

* 在受影响的项目中选择 **[Fix with Agent](/zh/ko/features/security/concepts#fix-with-agent)**，让 Agent 在项目中通过后台 task 编写补丁。重新发布前，请审查并应用生成的更改。
* 通过 **Task in progress**、**Apply changes**、**Republish** 以及最终状态 **Republished** 或 **Failed** 跟踪修复状态。
* 一键 **Republish** 会在确认后使用现有配置重新部署构建 (合并修复后) 。
* 执行批量操作，例如取消发布项目或向项目所有者发送漏洞通知。

<div id="sbom">
  ### 导出 SBOM
</div>

导出软件物料清单，满足合规和审计要求。

* 以标准格式下载 SBOM ([SPDX](/zh/ko/features/security/concepts#spdx-and-cyclonedx)、[CycloneDX](/zh/ko/features/security/concepts#spdx-and-cyclonedx))
* 为单个项目或整个工作区生成报告
* 按扫描运行浏览分组的 SBOM，并查看时间戳、项目数量及触发运行的用户
* 将一次扫描运行中的所有 SBOM 下载为单个 zip 批量文件
* 满足软件供应链透明度方面的合规要求

<Note>
  批量下载 SBOM 功能仅适用于 Enterprise 套餐。其他套餐的工作区可在 SBOM 部分查看升级至 Enterprise 的提示。
</Note>

<div id="workspace-security-center">
  ## 访问 Workspace 安全中心
</div>

要打开 Workspace 安全中心：

1. 前往 [replit.com](https://replit.com) 并登录您的账户。
2. 在主页左侧导航栏中选择 **Security**。

<div id="section-3">
  ## 扫描工作区
</div>

<Frame>
  <img src="/assets/mirror/security-overview-b37f090f236c.png" alt="Workspace 安全中心首页，显示扫描总数、漏洞总数以及按严重程度分组的 CVE" width="3438" height="1984" data-path="images/workspace-security-center/security-overview.png" />
</Frame>

1. 打开 Workspace 安全中心。
2. 选择 **Run security scan**，开始扫描整个工作区。
3. 查看按受影响项目、严重程度和部署暴露程度分类的结果。
4. 在受影响的项目中选择 **Fix with Agent**，修复完成后选择 **重新发布**。

扫描会分析工作区内 Replit 项目的依赖项，并显示公共漏洞数据库中已知的漏洞。

<div id="auto-protect">
  ## Auto-Protect
</div>

管理员可以在账户中启用 **[Auto-Protect](/zh/ko/features/security/concepts#auto-protect)**，该功能会持续监控所有项目依赖项中新披露的 CVE。发现匹配项后，Replit Agent 会准备经过测试的补丁，构建者将收到包含可直接应用该补丁链接的电子邮件。

有关完整工作流和设置步骤 (包括位于 **设置** &gt; **账户** &gt; **高级** 中、仅管理员可设置的严重程度阈值) ，请参阅 [Auto-Protect](/zh/ko/features/security/project-security-center#auto-protect)。

<Note>
  如需帮助配置 Workspace 安全中心，或将 SBOM 导出集成到合规工作流中，请联系您的客户经理。
</Note>
