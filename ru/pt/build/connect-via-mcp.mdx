Replit Agent может подключаться к сотням внешних инструментов и источников данных через [Model Context Protocol (MCP)](https://modelcontextprotocol.io) — открытый стандарт интеграции инструментов ИИ. Войдите на сервер из предварительно составленного списка или добавьте любой пользовательский MCP-сервер, которому доверяете.

<div id="conectar-um-servidor-mcp-pr-listado">
  ## Подключение предустановленного MCP-сервера
</div>

Replit предлагает тщательно отобранный список MCP-серверов для популярных сервисов, таких как Stripe, Linear, Notion, Sentry и других. Для подключения достаточно одного нажатия и входа в аккаунт.

<Frame>
  <img src="/assets/mirror/mcp-servers-pane-8e1f431ca33c.png" alt="Панель настроек MCP-серверов для Replit Agent со списком предустановленных серверов, включая Stripe, Linear, Notion, Sentry, Atlassian, Miro, PostHog, Amplitude, Mixpanel, Granola и Razorpay — у каждого есть кнопка «Войти»" width="3452" height="1988" data-path="images/replitai/mcp-servers-pane.png" />
</Frame>

<Steps>
  <Step title="Откройте панель «Интеграции»">
    Перейдите на [replit.com/integrations](https://replit.com/integrations) и прокрутите страницу до раздела **MCP-серверы для Replit Agent**.
  </Step>

  <Step title="Выберите сервер">
    Найдите сервис, который хотите подключить: Stripe, Linear, Notion, Sentry, Atlassian, Miro, PostHog, Amplitude, Mixpanel, Granola, Razorpay и другие.
  </Step>

  <Step title="Войдите">
    Нажмите **Войти** рядом с нужным сервером. Затем пройдите процедуру OAuth в этом сервисе. После подключения статус сервера обновится, и Agent сможет использовать его инструменты.
  </Step>
</Steps>

Полный каталог доступен в [справочнике MCP-серверов](/ru/pt/features/mcp/overview).

<div id="adicionar-um-servidor-mcp-personalizado">
  ## Добавление пользовательского MCP-сервера
</div>

Если нужного сервера нет в каталоге, добавьте его по URL.

<Frame>
  <img src="/assets/mirror/mcp-connect-dialog-5b8f9b0d828e.png" alt="Диалог «Подключить MCP-сервер» с полем отображаемого имени, полем URL MCP-сервера и разворачиваемым разделом расширенных настроек" width="3452" height="1988" data-path="images/replitai/mcp-connect-dialog.png" />
</Frame>

<Steps>
  <Step title="Откройте диалог добавления сервера">
    На панели настроек MCP-серверов нажмите **+ Добавить MCP-сервер**.
  </Step>

  <Step title="Укажите отображаемое имя">
    Укажите понятное имя — Agent будет использовать его для ссылки на сервер в логах Chat.
  </Step>

  <Step title="Введите URL сервера">
    Вставьте HTTPS-эндпоинт MCP-сервера. Откройте **расширенные настройки**, чтобы добавить пользовательские заголовки (например, `X-API-Key`), если серверу требуется аутентификация.
  </Step>

  <Step title="Проверьте и сохраните">
    Нажмите **Проверить и сохранить**. Replit попытается подключиться и проведёт вас через процедуру OAuth, если сервер её требует. После сохранения подключение появится в разделе MCP-серверов с указанием статуса.
  </Step>
</Steps>

<Warning>
  Подключайтесь только к MCP-серверам, которым доверяете. Подключённый сервер может предоставлять Agent инструменты и данные — проверьте источник, прежде чем добавлять неизвестный эндпоинт.
</Warning>

<div id="usar-ferramentas-mcp-no-agent">
  ## Использование инструментов MCP в Agent
</div>

После подключения сервера Agent автоматически получает список его инструментов и делает их доступными во всех ваших проектах. Чтобы использовать сервер, просто упомяните его в чате:

> Используйте MCP-сервер Notion, чтобы найти последние заметки со встречи.

<Frame>
  <img src="/assets/mirror/tool-call-7a53f51a11ae.png" alt="Agent вызывает инструменты пользовательского MCP-сервера в чате" width="571" height="817" data-path="images/replitai/custom-mcp/tool-call.png" />
</Frame>

Agent выбирает подходящие инструменты сервера на основе вашего запроса. Если инструмент требует подтверждения, перед его выполнением появится соответствующий запрос.
