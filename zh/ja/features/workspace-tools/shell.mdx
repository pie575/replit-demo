---

借助 Shell，你可以像使用常规终端一样处理项目，包括管理文件、
安装软件包和运行脚本。例如，你可以浏览项目文件，
如果项目已配置数据库连接，还可以使用 `psql`。

<Tip>
  为了更好地管理工作流，我们建议使用 **Run** 按钮，而不是通过 Shell 运行应用。
  由 **Run** 按钮启动的工作流会将输出发送到 Console 工具，
  方便你以结构化方式查看日志。
</Tip>

<div id="section">
  ## 功能
</div>

Shell 提供以下功能：

* **运行多个 Shell**：你可以打开多个 Shell 实例，同时处理不同的任务
* **搜索文本**：你可以在 Shell 输出中查找特定文本

<div id="shell">
  ### 确认 Shell 访问权限
</div>

要确认 Shell 已准备就绪并查看当前工作区，请运行以下命令：

```sh theme={null}
pwd
```

Shell 会显示当前工作区的路径。

<Frame caption="pwd 命令会显示当前工作区路径，然后返回 Shell 提示符。">
  <img src="/assets/mirror/shell-pwd-output-2d31a0e0466b.jpg" alt="Shell 选项卡显示 pwd 命令、工作区路径输出以及返回后的提示符" width="1280" height="246" data-path="images/workspace/shell-pwd-output.jpg" />
</Frame>

对于包含数据库的项目，请选择 **Tools** → **Database**，
然后打开 **Development database** 页面。此页面提供连接控制选项。
请妥善保管连接信息，不要将其复制到文档、屏幕截图、日志、源文件
或共享消息中。

<div id="section-3">
  ### 文本搜索
</div>

以下说明如何访问和使用文本搜索工具：

1. 选择 Shell 选项卡右上角的<img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" />放大镜图标，打开搜索对话框。
2. 输入搜索词，然后选择 **Next** 依次查看匹配结果。
3. 使用 **Previous** 返回上一个匹配结果。
4. 选择 **Exit**，或点击对话框外部，退出文本搜索。

<div id="section-4">
  ### 多个 Shell
</div>

要创建新的 Shell：

1. 在 Shell 面板标题中选择 Shell 实例菜单。
2. 选择 **New Shell**。

<Frame>
  <img src="/assets/mirror/shell-new-94a280c1230f.png" alt="显示当前工作区和 New Shell 选项的 Shell 实例菜单" width="1280" height="224" data-path="images/workspace/shell-new.png" />
</Frame>

使用同一菜单可在不同 Shell 之间切换。Replit 会以每个 Shell 最后运行的命令为其命名，便于识别。

<Warning>
  打开多个 Shell 时，Replit 会自动关闭空闲的 Shell 实例。
  空闲 Shell 是指未被选中且未运行用户进程的 Shell。
</Warning>
