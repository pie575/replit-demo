<AccordionGroup>
  <Accordion title="Comment connecter un domaine personnalisé à mon application Replit ?">
    Si vous avez acheté votre domaine via Replit, les enregistrements DNS sont gérés pour vous — ouvrez **Publication → Domaines** et suivez la configuration proposée dans le produit. Voir [Achat de domaine](/fr/pt/build/domain-purchasing).

    Pour connecter un domaine provenant d&#39;un registraire externe :

    1. Ouvrez votre projet et allez dans **Publication → Domaines**.
    2. Sélectionnez **Connecter votre propre domaine**, saisissez votre domaine et continuez.
    3. Replit affiche un enregistrement A et un enregistrement TXT — copiez les deux.
    4. Ajoutez ces deux enregistrements chez votre fournisseur DNS.
    5. Revenez dans Replit et lancez la vérification.

    Quelques points importants :

    * Un enregistrement A et un enregistrement TXT sont tous deux nécessaires pour le SSL. Les CNAME d&#39;apex (racine) ne sont pas pris en charge — utilisez un enregistrement A pour le domaine racine.
    * Les certificats génériques (`*.example.com`) ne sont pas pris en charge ; connectez chaque sous-domaine individuellement.
    * Sur Cloudflare, définissez votre enregistrement A sur **DNS uniquement** (le nuage gris) afin que le mode proxy ne bloque pas la configuration du SSL.
    * La propagation des modifications DNS peut prendre jusqu&#39;à 48 heures.

    Voir [Domaines personnalisés](/fr/pt/features/publishing/custom-domains) pour la référence complète.
  </Accordion>

  <Accordion title="Mon domaine n'est pas vérifié ou le SSL n'est pas provisionné — comment résoudre le problème ?">
    Effectuez ces vérifications dans l&#39;ordre — la plupart des problèmes viennent de l&#39;une d&#39;elles :

    1. **Attendez la propagation du DNS.** Les modifications peuvent prendre jusqu&#39;à 48 heures. Vérifiez que vos enregistrements sont visibles partout dans le monde à l&#39;aide d&#39;un outil de recherche DNS.
    2. **Supprimez les enregistrements AAAA.** Les enregistrements IPv6 (AAAA) définis sur le même nom d&#39;hôte que votre enregistrement A peuvent bloquer le SSL.
    3. **Supprimez les enregistrements A anciens ou en conflit.** Ne conservez qu&#39;un seul enregistrement A sur votre domaine racine pointant vers Replit.
    4. **Configurez Cloudflare sur DNS uniquement.** Le nuage orange (mode proxy) perturbe le provisionnement du SSL.
    5. **Déconnectez puis reconnectez le domaine** dans **Publication → Domaines → Gérer** pour forcer l&#39;émission d&#39;un nouveau certificat, puis patientez quelques minutes et rechargez la page.
    6. **Vérifiez les enregistrements CAA.** Si vous avez des enregistrements CAA, au moins l&#39;un d&#39;eux doit autoriser Let&#39;s Encrypt comme émetteur, car c&#39;est par son intermédiaire que Replit émet les certificats.

    Ces vérifications s&#39;appliquent aux domaines enregistrés en externe. Si vous avez acheté votre domaine via Replit, [contactez l&#39;assistance Replit](https://replit.com/support). Voir [Domaines personnalisés](/fr/pt/features/publishing/custom-domains).
  </Accordion>

  <Accordion title="Comment configurer l'authentification Clerk sur un domaine personnalisé ?">
    Quelques problèmes courants surviennent lors de l&#39;utilisation de l&#39;[authentification Clerk](/fr/pt/features/auth-and-identity/clerk-auth) sur un domaine personnalisé :

    * **Avertissement « Enregistrements CNAME Clerk requis ».** Il s&#39;agit d&#39;une exigence d&#39;intégration de Clerk, qui ne bloque ni la vérification ni le SSL de votre domaine. Ouvrez **Publication → Domaines**, sélectionnez **Gérer**, repérez la section de configuration DNS de l&#39;authentification et ajoutez chez votre fournisseur DNS chaque enregistrement CNAME listé, à l&#39;identique. Si la section n&#39;apparaît pas, déconnectez puis reconnectez le domaine.
    * **Domaine bloqué sur « Vérification en cours » après une utilisation antérieure de Clerk.** Si le domaine était lié à une autre application Clerk, supprimez-le depuis votre [tableau de bord Clerk](https://dashboard.clerk.com), puis déconnectez et reconnectez le domaine dans Replit.
    * **Migration vers votre propre instance Clerk.** Passer du Clerk géré par Replit à votre propre instance nécessite une étape manuelle — [contactez l&#39;assistance Replit](https://replit.com/support). Voir [Puis-je utiliser ma propre application Clerk ?](/fr/pt/features/auth-and-identity/clerk-auth#can-i-bring-my-own-clerk-app-instead-of-using-the-replit-managed-one)

    Si vous rencontrez toujours des difficultés, [contactez l&#39;assistance Replit](https://replit.com/support) en indiquant le nom de votre domaine, le nom de votre projet et ce que vous avez déjà essayé.
  </Accordion>
