---

Регион проекта — это регион публикации Project. Вы задаёте её при публикации, и она определяет, где размещаются вычислительные ресурсы и хранилище опубликованного Project.

<Note>
  Регион проекта и [география
  workspace](/ru/features/collaboration/workspace-geography) могут
  различаться. География workspace определяет, где размещаются ресурсы
  разработки для новых Project в Workspace.
</Note>

<div id="o-que-a-geografia-do-projeto-controla">
  ## На что влияет регион проекта
</div>

По умолчанию Replit рекомендует ближайшую к вам географию. Это помогает снизить задержку для посетителей вашего приложения и выполнить требования к резидентности данных.

При выборе географии все опубликованные артефакты вашего Project — вычислительные ресурсы, база данных и Object Storage — автоматически размещаются в одном регионе. Прокси, привязанный к географии, также помогает снизить задержку для посетителей вашего приложения.

<div id="selecione-uma-geografia-de-projeto">
  ## Выберите регион для проекта
</div>

Чтобы выбрать регион, отличный от рекомендованного:

<Steps>
  <Step>Откройте инструмент **Publishing** в своём Replit Project.</Step>
  <Step>Разверните настройки **Advanced**.</Step>
  <Step>Выберите нужный регион в выпадающем меню **Geography**.</Step>

  <Step>
    Нажмите **Publish**, чтобы опубликовать Project в выбранном регионе.
  </Step>
</Steps>

<div id="aplique-uma-geografia-obrigatria-para-projetos-publicados">
  ## Задайте обязательный регион для публикуемых проектов
</div>

Администраторы организаций Enterprise могут задать обязательный регион публикации для всех Project организации. Если такая политика задана, разработчики организации публикуют проекты в указанном регионе. Политика распространяется только на Project, которые ещё не были опубликованы. Project, уже опубликованные в другом регионе, она не затрагивает.

<Note>
  Обязательный регион публикации — возможность Enterprise.
  Подробнее о планах Enterprise см. на странице
  [Pricing](https://replit.com/pricing/).
</Note>

<Steps>
  <Step>Откройте **Account settings**.</Step>
  <Step>Выберите **Advanced**.</Step>

  <Step>
    Выберите регион, который должны использовать все Project при первой
    публикации.
  </Step>
</Steps>

<div id="disponibilidade-e-limites">
  ## Доступность и ограничения
</div>

| Регион               | Выбор при публикации проекта |
| :------------------- | :--------------------------- |
| **Северная Америка** | Да                           |
| **Европа (ЕС)**      | Да                           |
| **Азия**             | Да                           |
| **Южная Америка**    | Да                           |
| **Австралия**        | Да                           |

<Note>
  Выбор региона проекта доступен клиентам Core, Pro
  и Enterprise. Пользователи бесплатного плана по умолчанию публикуют проекты
  в Северной Америке.
</Note>

Прежде чем выбрать регион проекта, учтите следующие ограничения:

* **После публикации регион изменить нельзя.** Как только вы опубликовали свой Project в определённом регионе, этот выбор становится окончательным. Перенести опубликованный Project в другой регион невозможно.
* **Регионы разработки и публикации могут не совпадать.** Такие ресурсы, как Object Storage, могут быть созданы до публикации, и их регион может отличаться от региона вашего Project.
