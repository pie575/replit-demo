<div id="importar-do-github">
  ## Импорт из GitHub
</div>

⏰ *Ориентировочное время: две минуты*

Импортируйте репозиторий GitHub в Replit, чтобы быстрее запускать, тестировать и публиковать приложения.

Подробнее обо всех вариантах импорта, включая другие платформы, такие как Figma, Bolt и Lovable, см. в [документации функции импорта](/ru/pt/core-concepts/project-editor/app-setup/import).

<div id="antes-de-comear">
  ## Прежде чем начать
</div>

* URL репозитория GitHub
* Доступ к репозиторию (публичному или приватному)
* Учётная запись Replit

<div id="opo-um-importao-rpida">
  ## Вариант первый: быстрый импорт
</div>

Быстрый импорт работает с публичными репозиториями.

1. Скопируйте путь к репозиторию, который идёт после `github.com/`.
2. Откройте `https://replit.com/github.com/<владелец>/<репозиторий>`.
3. Нажмите Enter, чтобы запустить импорт.

**Пример**

* URL на GitHub: `https://github.com/exampleUser/my-app`
* URL для импорта в Replit: `https://replit.com/github.com/exampleUser/my-app`

<div id="opo-dois-importao-guiada">
  ## Второй вариант: пошаговый импорт
</div>

Пошаговый импорт поддерживает публичные и частные репозитории.

1. Откройте [replit.com/import](https://replit.com/import).
2. Выберите **GitHub**.
3. Подключите свою учётную запись GitHub.
4. Выберите репозиторий.
5. Выберите **Импортировать**.

<div id="o-que-importado">
  ## Что импортируется
</div>

* Файлы и папки репозитория
* Файлы зависимостей
* Стандартная конфигурация запуска и сборки

<div id="o-que-no-importado">
  ## Что не импортируется
</div>

* Значения существующих секретов и переменных окружения
* Платформозависимые сервисы, которые по умолчанию не запускаются в Replit
