Claude 和 GPT 等 AI 模型功能强大，但其能力仅限于训练数据所涵盖的内容。模型上下文协议 (MCP) 为它们提供了以标准方式连接外部工具、数据源和现实世界能力的途径。

<div id="why-ai-models-need-mcp">
  ## 为什么 AI 模型需要 MCP
</div>

如果无法访问外部工具和数据，AI 模型将无法：

* 获取最新信息
* 与外部系统交互
* 在现实世界中执行操作
* 使用你的私有数据

MCP 为 AI 提供了一种通用方式来接入工具和数据，从而解决了这一问题——就像 USB-C 统一了设备连接标准一样。

<Frame>
  <img src="/assets/mirror/mcp-a04e01a01743.avif" alt="展示 AI 模型连接外部工具和数据源的 MCP 示意图" width="1920" height="1055" data-path="images/tutorials/mcp.avif" />
</Frame>

借助 MCP，AI 模型可以：

* 访问专业工具和 API
* 读取私有数据源中的数据
* 在现实世界中采取行动
* 无缝连接其他系统

<div id="how-mcp-works">
  ## MCP 的工作原理
</div>

MCP 架构包含三个主要组成部分：

1. **客户端** —— 像 Claude 这样的 AI 模型，或需要访问外部工具的应用程序。
2. **通信层** —— 协议本身，用于统一规范请求和响应的格式。
3. **服务器端** —— 提供工具、数据源和专用能力的程序。

<AccordionGroup>
  <Accordion title="什么是 MCP 客户端？">
    MCP 客户端指的是 Claude、Replit Agent 或连接大语言模型的命令行界面之类的程序。它就是插入外部工具或数据源的那个“设备”。

    MCP 客户端示例：

    * 浏览器中的 Claude
    * Replit Agent
    * 面向 AI 的命令行界面
    * 使用 AI SDK 构建的自定义应用程序
  </Accordion>

  <Accordion title="什么是 MCP 服务器？">
    MCP 服务器为 AI 模型提供各种工具和能力，可以把它理解为给 AI 配备一套解决问题的专用工具。

    MCP 服务器可实现的功能示例：

    * 访问特定数据源以回答问题
    * 将 AI 连接到 API，使其能够在线执行操作
    * 读取或写入文件
    * 进行计算或运行代码
    * 从 Notion、Linear 或 Stripe 等服务中获取内容
  </Accordion>
</AccordionGroup>

<div id="what-mcp-unlocks">
  ## MCP 能实现的功能
</div>

MCP 定义了多项基础能力，使其能够为 AI 应用提供强大支持：

* **资源** — 与 AI 模型共享数据和内容
* **工具** — 让 AI 模型通过你的服务执行操作
* **提示词** — 用于实现一致 AI 交互的可复用模板
* **采样** — 允许你的服务向 AI 模型请求信息
* **传输** — 高效连接客户端和服务器

<div id="skills-vs-mcp-servers">
  ## Skills 与 MCP 服务器
</div>

Skills 和 MCP 服务器是扩展 AI 智能体的两种主要方式，各自适用于不同场景。

|           | Skills                    | MCP 服务器                     |
| --------- | ------------------------- | --------------------------- |
| **最适合用于** | 工作流、约定和参考资料               | 连接外部服务和执行操作                 |
| **加载内容**  | 轻量——调用前仅加载名称和描述           | 较重——预先加载所有工具描述              |
| **定义**    | 智能体应*如何*工作                | 智能体能访问*什么*内容                |
| **示例**    | “股票分析器” skill——使用特定框架研究投资 | “Stripe” MCP 服务器——读取支付和订阅数据 |

有关 skills 的相应使用思路，请参阅 [Agent skills](/zh/learn/agent-skills)。

<div id="real-world-applications">
  ## 实际应用场景
</div>

MCP 可支撑多种多样的 AI 应用：

* **客户服务系统**：访问公司数据库，解答具体问题
* **研究助手**：从多个来源检索并总结内容
* **效率工具**：与你的文件和应用程序交互
* **内容创作工具**：访问媒体库和发布平台

<div id="benefits">
  ## 优势
</div>

MCP 提供三项主要优势：

* 可供 AI 立即连接使用的现成集成
* 可在不同的 AI 提供商之间切换，无需重写连接
* 保护敏感数据的安全功能

<Note>
  MCP 是一项新兴标准，正获得整个 AI 生态系统越来越广泛的支持。新的工具和集成会定期推出。
</Note>
