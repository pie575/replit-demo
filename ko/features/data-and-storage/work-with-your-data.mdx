**My Data** 탭에서는 데이터베이스에 담긴 내용을 확인하고 변경할 수 있습니다. **Database** 도구를 열고 데이터베이스를 선택한 다음 **My Data**를 선택하세요. 시각적으로 작업하거나 SQL을 직접 실행할 수 있습니다.

<Note>
  production data를 편집하려면 production 데이터베이스를 선택하고 **My Data**를 연 다음 **Edit**를 켜세요. live app의 실제 데이터이므로 주의해서 다루세요.
</Note>

<div id="browse-and-modify-data-visually">
  ## 데이터를 시각적으로 탐색하고 수정하기
</div>

데이터베이스 도구에는 데이터를 시각적으로 탐색하고 수정할 수 있는 <a href="https://orm.drizzle.team/drizzle-studio/overview" target="_blank">Drizzle Studio</a>가 포함되어 있습니다. 이러한 시각적 도구를 사용하면 구문 오류를 줄일 수 있으며, 다음과 같은 기능을 제공합니다:

* 특정 정보에 집중할 수 있도록 데이터 필터링 및 정렬
* 외부에서 사용할 수 있도록 데이터를 파일로 내보내기
* 행 데이터 삽입 또는 수정
* schema, 테이블, 뷰, 열거형 생성 및 관리

<div id="run-sql-commands">
  ## SQL 명령 실행
</div>

SQL runner를 사용하면 데이터베이스에서 SQL 명령을 실행하고 그 결과를 확인할 수 있습니다.

<Accordion title="SQL runner 여는 방법">
  **Database** 도구에서:

  1. **My Data** 탭을 선택합니다
  2. <img class="icon-svg" src="/assets/mirror/sql-runner-icon-b25868882922.svg" alt="SQL runner icon" width="16" height="16" data-path="images/icons/sql-runner-icon.svg" /> **SQL runner**를 선택합니다
</Accordion>

쿼리를 실행하려면 텍스트 영역에 SQL 문을 입력한 뒤 옆에 있는 <img class="icon-svg" src="/assets/mirror/sql-play-8ed26b5de7f1.svg" alt="sql run icon" width="18" height="18" data-path="images/icons/sql-play.svg" /> 실행 버튼을 선택하세요.

<Frame>
  <img src="/assets/mirror/sql-runner-run-8ad798a61335.jpg" alt="screenshot of the SQL runner and run button" width="1390" height="608" data-path="images/databases/sql-runner-run.jpg" />
</Frame>

<Tip>
  SQL을 직접 작성할 필요는 없습니다. Agent에게 데이터를 조회하거나 변경해 달라고 요청하면 SQL을 대신 작성하고 실행해 줍니다.
</Tip>
