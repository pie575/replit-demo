Replit 支持多人同时在同一个项目中协作。每个人都可以与 Agent 开启新的规划对话线程，所有人的任务都会汇总到共享看板上——让团队并肩构建，而不是轮流上阵。

<div id="trabalhando-em-paralelo">
  ### 并行协作
</div>

每个人都可以创建新的对话线程，彼此独立开展工作，互不干扰。所有人的任务都会显示在共享看板上，方便了解每个人正在处理的内容，并避免工作冲突。

<Note>
  在 Core 中，整个项目一次只能运行 1 个后台任务。在 Pro 中，最多可并行运行 10 个任务，因此多人可以让 Agent 同时构建项目的不同部分。
</Note>

<div id="o-que-voc-pode-construir-juntos">
  ## 你们可以一起构建什么
</div>

* **团队分工开发一个功能**：一个人做前端，另一个人负责 backend，各自通过自己与 Agent 的 Chat 推进。看板让所有人保持同步。
* **让新成员快速上手**：新成员可以通过自己与 Agent 的 Chat 熟悉项目、了解各部分如何运作，并着手贡献代码——完全不会阻塞其他人。
* **在 Pro 上更快发布**：借助并行执行，两三个人可以各自派发任务并同时运行。一个人需要整整一个工作时段才能完成的项目，如今只需一小部分时间就能搞定。

<div id="perguntas-frequentes">
  ## 常见问题
</div>

<Accordion title="我可以通过 Agent 给协作者发消息吗？">
  不行。Agent 不是消息工具——它始终在监听，并会尝试对你输入的任何内容采取行动。团队沟通请使用 Slack、Discord 或其他工具。
</Accordion>

<Accordion title="我们会覆盖彼此的工作吗？">
  任务系统会为每个任务分配独立的隔离副本，同时了解还有哪些其他任务在进行，从而帮助避免这种情况。任务完成后，你再将其合并回主版本，并在这一步解决所有冲突。
</Accordion>

<Accordion title="我如何查看协作者正在做什么？">
  查看看板即可了解进行中的任务。你还可以看到光标位置以及协作者正在查看哪些文件。
</Accordion>

<Accordion title="我可以将某人从项目中移除吗？">
  可以。项目所有者可以随时管理团队成员并撤销访问权限。
</Accordion>
