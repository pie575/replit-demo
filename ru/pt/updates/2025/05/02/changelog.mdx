<div id="replit-auth">
  ### Replit Auth
</div>

[Replit Auth](/ru/pt/core-concepts/project-editor/auth-and-security/authentication) доступен всем пользователям! Это встроенная система аутентификации, которая позволяет добавить вход пользователей в ваши приложения с минимальной настройкой. Вместо того чтобы создавать сложные системы аутентификации с нуля, вы получаете готовое безопасное решение, интегрированное с инфраструктурой Replit.

**Ключевые возможности:**

* **Нулевая настройка** — добавьте аутентификацию одним промптом в Agent
* **Встроенная безопасность** — используется инфраструктура Replit с защитой от распространённых атак
* **Управление пользователями** — упрощённое администрирование пользователей через панель Auth
* **Интеграция с базой данных** — записи о пользователях создаются в вашей базе данных автоматически
* **Настраиваемая страница входа** — адаптируйте процесс входа под своё приложение
* **Сброс пароля** — Replit берёт на себя отправку писем для сброса пароля, поэтому собственный сервис доставки электронной почты не нужен

Начать просто — упомяните Replit Auth в своём промпте для Agent:

<AiPrompt>
  Помоги мне создать приложение, которое [ваша идея приложения], и оно должно включать Replit Auth.
</AiPrompt>

  ### Обновлённая политика приостановки при оплате по факту использования
</div>

Мы улучшили систему льготного периода оплаты, чтобы лучше поддерживать давних пользователей и при этом защищать их развёртывания. Пользователи с более длительной историей использования теперь получают больше времени на решение проблем с оплатой, поэтому критически важные приложения остаются доступными, пока платёжные данные обновляются.
