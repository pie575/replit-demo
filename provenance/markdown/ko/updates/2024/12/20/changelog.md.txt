### 커스텀 프롬프트

<Note>
  **업데이트 (2025년 12월):** Assistant는 지원 중단되었습니다. 빠른 부분 편집에는 [Agent의 Lite 모드](/core-concepts/agent/agent-modes)를 사용하세요.
</Note>

커스텀 프롬프트를 사용하면 Assistant의 동작 방식을 완전히 제어할 수 있습니다. 특정 코딩 표준 설정부터 Assistant 기본값 커스터마이징까지 커스텀 프롬프트로 모두 해결할 수 있습니다.

다음과 같은 내용을 추가할 수 있습니다:

* 특정 코딩 스타일 또는 프레임워크
* 특정 문제 해결 기법
* 패키지 관리 기본 설정

예를 들어 다음과 같이 추가할 수 있습니다:

```
use pnpm for package management
use motion/react instead of framer-motion
always use claude-3-5-sonnet-20241022 as your model
```

### Replit 앱 테마

프로젝트가 대폭 업그레이드되었습니다. 코드 없이도 가능합니다 💅

이제 Agent에게 React Replit 앱을 빌드하도록 요청하고 노코드 테마 도구로 손쉽게 커스터마이징할 수 있습니다:

* 기본 색상 변경
* 라이트 모드와 다크 모드 전환
* 앱의 디자인을 나만의 스타일로 개인화

### Workflows

Workflow는 원하는 명령을 실행할 수 있는 손쉽게 구성 가능한 "Run" 버튼입니다.

Replit 앱 내에서 실행할 수 있는 재사용 가능하고 커스터마이징 가능한 단계의 시퀀스입니다. **`python main.py`** 실행처럼 간단하거나 여러 단계를 거치는 복잡한 절차일 수도 있습니다.

사용 사례 예시:

* 여러 서비스를 병렬로 실행 (예: 프론트엔드 + 백엔드)
* 파일 또는 명령을 순차적으로 실행 (예: 린터 실행 → 테스트 실행, 컴파일 → 코드 실행)

[Workflow 생성](https:/.replit.com/replit-workspace/workflows#creating-workflows)을 시작하려면 도구 사이드바 메뉴를 사용하거나 \*\*`Command + K`\*\*로 Workflows 패널을 검색하세요.

[여기](https:/.replit.com/replit-workspace/workflows)에서 확인하세요.
