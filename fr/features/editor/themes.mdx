Les thèmes de Replit vous permettent de personnaliser l&#39;apparence du Project Editor, des couleurs d&#39;arrière-plan aux éléments d&#39;interface, en passant par la coloration syntaxique de votre code. Adaptez votre environnement de développement pour gagner en lisibilité, réduire la fatigue oculaire et rendre le développement plus agréable.

<div id="creating-a-custom-theme">
  ## Créer un thème personnalisé
</div>

Suivez ces étapes pour créer et personnaliser votre propre thème :

1. Ouvrez les [Paramètres](https://replit.com/settings), puis accédez à **User** → **Personalization** (ou à la section **Themes**)
2. Sélectionnez **Create new theme**
3. Saisissez un titre, choisissez une palette de couleurs (clair ou sombre) et ajoutez une description facultative
4. Sélectionnez **Create Theme** pour ouvrir l&#39;éditeur de thèmes

Les paramètres globaux du thème régissent l&#39;apparence générale de l&#39;interface :

* **Background** : définit la couleur de base de la plupart des surfaces de l&#39;interface
* **Outline** : contrôle la couleur des bordures et des séparateurs
* **Foreground** : détermine la couleur du texte et des icônes
* **Primary** : définit la couleur des boutons et des éléments interactifs
* **Positive** : s&#39;applique aux indicateurs de réussite, comme le bouton **Run**
* **Negative** : s&#39;affiche pour les erreurs et les avertissements liés aux actions destructrices

Sélectionnez **Apply Theme** pour utiliser immédiatement votre thème personnalisé.

<div id="syntax-highlighting">
  ## Coloration syntaxique
</div>

Personnalisez l&#39;apparence des différents éléments de code pour améliorer la lisibilité et la compréhension.

<Tip>
  Une coloration syntaxique bien réglée rend le code plus facile à parcourir et à comprendre d&#39;un coup d&#39;œil. Choisissez des couleurs qui s&#39;harmonisent et offrent un contraste suffisant avec votre arrière-plan.
</Tip>

<Accordion title="Éléments de la coloration syntaxique">
  | Élément                       | Description                                                                     |
  | ----------------------------- | ------------------------------------------------------------------------------- |
  | **Noms de variables**         | S&#39;applique aux variables sans mot-clé de déclaration                        |
  | **Définitions de variables**  | Colore les noms de variables définies avec des mots-clés comme `const` ou `var` |
  | **Références de fonctions**   | S&#39;applique lors de l&#39;appel de fonctions                                 |
  | **Définitions de fonctions**  | Colore les noms de fonctions lors de leur déclaration                           |
  | **Mots-clés**                 | Met en évidence les mots-clés du langage comme `import`, `function` et `return` |
  | **Noms de propriétés**        | Colore l&#39;accès aux propriétés depuis les variables                          |
  | **Définitions de propriétés** | Utilisé lors de la définition des propriétés d&#39;objets                       |
  | **Propriétés de fonctions**   | S&#39;applique lors de l&#39;appel de méthodes sur des objets                   |
  | **Noms de balises**           | Utilisé pour les balises HTML et JSX                                            |
  | **Noms de types**             | Colore les annotations de type dans les langages typés                          |
  | **Noms de classes**           | S&#39;applique aux déclarations et références de classes                        |
  | **Noms d&#39;attributs**      | Met en évidence les attributs HTML et JSX                                       |
  | **Commentaires**              | S&#39;applique à tous les commentaires de code                                  |
  | **Chaînes de caractères**     | Colore les littéraux de chaîne                                                  |
  | **Nombres**                   | Met en évidence les valeurs numériques                                          |
  | **Booléens**                  | Met en forme les valeurs booléennes (`true`/`false`)                            |
  | **Expressions régulières**    | Colore les motifs d&#39;expressions régulières                                  |
  | **Opérateurs**                | Met en évidence les opérateurs comme `+`, `-`, `*` et `/`                       |
  | **Crochets**                  | Colore les crochets et chevrons le cas échéant                                  |
</Accordion>

<div id="theme-design-best-practices">
  ## Bonnes pratiques de conception de thèmes
</div>

Créez des thèmes esthétiques et fonctionnels en suivant ces recommandations :

<div id="color-and-contrast">
  ### Couleur et contraste
</div>

* **Équilibrez le contraste** : veillez à une différence suffisante entre l&#39;arrière-plan et les éléments de premier plan
* **Créez des palettes cohérentes** : choisissez des couleurs qui se complètent au lieu de jurer entre elles
* **Maintenez une luminosité constante** : conservez un niveau de luminosité similaire pour tous les éléments de syntaxe
* **Concevez pour l&#39;accessibilité** : pensez aux personnes ayant une déficience visuelle en évitant les combinaisons à faible contraste

<Warning>
  Problèmes courants à éviter lors de la conception d&#39;un thème :

  * Des écarts de luminosité excessifs entre les éléments de syntaxe
  * Des couleurs mal assorties qui créent une dissonance visuelle
  * Un contraste insuffisant entre le code et l&#39;arrière-plan
</Warning>

<div id="managing-your-themes">
  ## Gérer vos thèmes
</div>

Accédez à tous vos thèmes installés et gérez-les dans les [Paramètres](https://replit.com/settings), sous **User** → **Personalization** (ou la section **Themes**).

<div id="switching-themes">
  ### Changer de thème
</div>

Sélectionnez le bouton situé à côté du titre d&#39;un thème pour en faire votre thème actuel.

<div id="editing-themes">
  ### Modifier des thèmes
</div>

Modifiez vos thèmes personnalisés en sélectionnant le menu à trois points, puis en cliquant sur **Edit**.

<Note>
  Seuls les thèmes personnalisés que vous avez créés peuvent être modifiés ou supprimés. Les thèmes par défaut et ceux créés par d&#39;autres personnes ne peuvent pas être modifiés.
</Note>

<div id="deleting-themes">
  ### Supprimer des thèmes
</div>

Supprimez les thèmes personnalisés en ouvrant le menu à trois points, puis en sélectionnant **Delete**.

<div id="exploring-community-themes">
  ## Explorer les thèmes de la communauté
</div>

Découvrez les thèmes créés par la communauté Replit sur la [page d&#39;exploration des thèmes](https://replit.com/themes).

<div id="finding-themes">
  ### Trouver des thèmes
</div>

* Recherchez par nom pour trouver un thème précis, comme « Atom One Dark »
* Filtrez par auteur pour explorer les thèmes de créateurs en particulier
* Parcourez les thèmes par palette de couleurs pour n&#39;afficher que les thèmes clairs ou sombres
* Recherchez des couleurs précises correspondant à vos préférences

Prévisualisez n&#39;importe quel thème avant de l&#39;installer pour voir le rendu dans le Project Editor.

<div id="porting-from-vs-code">
  ## Portage depuis VS Code

Importez vos thèmes VS Code préférés dans Replit en faisant correspondre les couleurs équivalentes lors de la création du thème.

<div id="publishing-your-theme">
  ## Publier votre thème
</div>

Partagez vos thèmes personnalisés avec la communauté Replit en suivant ces étapes :

1. Ouvrez l&#39;éditeur de thèmes (Themes Editor) de votre thème personnalisé
2. Sélectionnez le bouton **Publish**
3. Renseignez les champs Titre et Description
4. Soumettez votre thème

Une fois publié, votre thème apparaîtra sur la page d’exploration des thèmes, où les autres utilisateurs pourront le prévisualiser et l&#39;installer.
