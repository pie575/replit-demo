탐색이 폭을 넓히는 과정이라면, 다듬기는 깊이를 더하는 과정입니다. frame이 원하는 모습에 가까워졌다면, 작업 방식에 맞는 두 가지 도구로 정밀하게 다듬어 보세요.

* frame 전체 또는 개별 요소에 대해 원하는 표현 그대로 Agent와 Chat에서 대화하기
* Visual Editor로 요소를 직접 조정하기: 간단한 편집은 크레딧 소모 없이 즉시 적용됩니다

<div id="chat">
  ## Chat
</div>

리뷰 중 디자이너에게 설명하듯 Agent에게 요청해 보세요. frame을 선택한 뒤 main chat에서 원하는 변경 사항을 설명하거나(*&quot;더 따뜻한 색감으로&quot;*, *&quot;hero가 허전해 보여요&quot;*), 툴바에서 **Chat** 도구를 선택하고 특정 요소를 클릭해 그 부분에만 메시지 범위를 지정할 수 있습니다.

<Frame caption="선택한 frame은 chip 형태로 main chat에 첨부됩니다.">
  <img src="/assets/mirror/chatbox-9baff03cb443.png" alt="Canvas에서 선택된 Design frame(Configurator First)과 왼쪽의 main chat 패널. 메시지 입력창에는 '디자인하고 싶은 내용을 설명하세요…'라고 표시되어 있고 Configurator First chip이 첨부되어 있음" width="2000" height="1250" data-path="images/design/replit-design/chatbox.png" />
</Frame>

두 가지 진입 방법은 [Chat](/ko/design/chat-about-your-design)을 참고하세요.

<div id="visual-editor">
  ## Visual Editor
</div>

원하는 바가 명확하다면 prompt를 건너뛰세요. 툴바에서 **Edit** 도구를 선택한 후 원하는 요소를 클릭하면, 해당 요소에서 편집할 수 있는 속성(콘텐츠, layout, color, border 등)이 담긴 Visual Editor가 열립니다. 텍스트 변경, 색상 선택, 여백 조정처럼 간단한 편집은 크레딧 소모 없이 소스 코드에 즉시 반영됩니다.

<Frame caption="요소가 선택된 상태로 활성화된 Edit 도구와, 편집 가능한 속성을 보여주는 Visual Editor.">
  <img src="/assets/mirror/visual-editor-edit-tool-71d03803471f.png" alt="Edit 도구가 활성화되고 요소가 선택된 슈퍼카 구성기 frame으로, 오른쪽에 Layout, Color, Border 섹션과 Discard 및 Save edits 버튼이 있는 Visual Editor 패널이 표시된 모습" width="2000" height="1250" data-path="images/replitai/visual-editor-edit-tool.png" />
</Frame>

전체 컨트롤 레퍼런스는 [Visual Editor](/ko/design/visual-editor)를 참고하세요.

<div id="which-one-to-reach-for">
  ## 언제 무엇을 사용할까
</div>

| 하고 싶은 일…                            | 사용 도구         |
| ----------------------------------- | ------------- |
| 원하는 결과를 설명하고 세부 사항은 Agent에게 맡기기     | Chat          |
| 한 요소의 문구, 색상, 여백, 이미지를 정해진 값으로 변경하기 | Visual Editor |
| 섹션의 구조나 동작을 다시 구성하기                 | Chat          |
| 크레딧 소모 없이 빠르게 조정하기                  | Visual Editor |

두 도구는 자연스럽게 어우러집니다. Chat으로 큰 방향을 잡은 다음, Visual Editor에서 직접 클릭해 세부 사항을 다듬으세요.
