description: "Описание ограничений ресурсов Replit, включая ограничения CPU, RAM, хранилища и сети, применяемые к Replit App в зависимости от тарифа."
---

В Replit действуют мягкие и жёсткие ограничения на использование сервиса. Жёсткие ограничения автоматически применяются сервисом. Мягкие ограничения — это потребляемые ресурсы, которые вы обязуетесь не превышать. Подробная информация об этих ограничениях [приведена на https://replit.com/site/pricing и может время от времени обновляться. Длительное бездействие может привести к тому, что аккаунт или использование сервиса будет признано неактивным.](https://replit.com/site/pricingに記載されており、随時更新される場合があります。長期間の非アクティブ状態により、アカウントまたはサービスの使用が非アクティブとみなされる場合があります。)

* CPU для каждого Replit App: определяется тарифом (жёсткое ограничение)

* RAM для каждого Replit App: определяется тарифом (жёсткое ограничение)

* Количество одновременно запущенных Replit App: 20 (жёсткое ограничение)

* Хранилище для каждого Replit App: определяется тарифом и объёмом хранилища, используемым другими Replit App (жёсткое ограничение)

* Хранилище для каждого аккаунта: определяется тарифом (жёсткое ограничение)

* Пропускная способность сети: определяется тарифом (мягкое ограничение)

Кроме того, независимо от тарифа, для соблюдения Условий использования к содержимому Replit App и сетевой активности применяются определённые ограничения. При превышении этих ограничений Replit App может временно стать недоступным, а некоторые операции — завершаться с ошибкой. К ним относятся:

* Ограничение количества одновременных исходящих сетевых подключений за определённый период.

* Ограничения на частоту и размер запросов к GraphQL API Replit.

* Ограничения на использование кода, который может нарушать Условия использования, например для майнинга криптовалюты.
