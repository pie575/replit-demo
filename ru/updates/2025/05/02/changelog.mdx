<div id="replit-auth">
  ### Replit Auth
</div>

[Replit Auth](/ru/features/auth-and-identity/authentication) доступен всем пользователям! Это встроенная система аутентификации, которая позволяет добавить вход пользователей в ваши приложения с минимальной настройкой. Вместо того чтобы создавать сложные системы аутентификации с нуля, Replit Auth предлагает безопасное готовое решение, интегрированное с инфраструктурой Replit.

**Ключевые возможности:**

* **Нулевая настройка** — добавьте аутентификацию одним промптом в Agent
* **Встроенная безопасность** — используется инфраструктура Replit с защитой от распространённых атак
* **Управление пользователями** — упрощённое администрирование пользователей через панель Auth
* **Интеграция с базой данных** — записи пользователей создаются в вашей базе данных автоматически
* **Настраиваемая страница входа** — персонализируйте вход под ваше приложение
* **Сброс пароля** — Replit сам отправляет письма для сброса пароля, так что собственный сервис рассылки писем вам не понадобится

Начать просто — достаточно упомянуть Replit Auth в промпте для Agent:
