Здесь собраны ответы по работе с Agent. Полную справочную информацию см. в разделах [Обзор Agent](/ru/ja/features/agent/overview), [Режимы Agent](/ru/ja/features/agent/agent-modes) и [Оплата ИИ](/ru/ja/billing/ai-billing).

<AccordionGroup>
  <Accordion title="Agent зависает или постоянно отключается — как это исправить?">
    1. Откройте палитру команд: на Mac — `Cmd+K`, в Windows — `Ctrl+K`.
    2. Найдите и выберите **Restart compute**, чтобы перезапустить среду разработки.
    3. Откройте новый чат Agent, снова опишите задачу и продолжите работу.

    Если кажется, что Agent завис, не отправляйте новые сообщения — они могут создать конфликтующие инструкции. Если Agent продолжает зависать на той же задаче, разбейте работу на более мелкие и конкретные промпты.
  </Accordion>

  <Accordion title="Agent зацикливается или повторяет один и тот же шаг — как его остановить?">
    1. Выберите **Остановить** на панели Agent, чтобы немедленно остановить работу.
    2. Откройте палитру команд сочетанием `Cmd+K` на Mac или `Ctrl+K` на Windows, затем найдите и выберите **Перезапустить вычислительные ресурсы**.
    3. Откройте новый чат Agent и сформулируйте задачу более конкретно.

    Чтобы избежать циклов:

    * Разбивайте большие задачи на более мелкие промпты — одна цель на сообщение.
    * Используйте [режим Plan](/ru/ja/features/agent/plan-mode), чтобы определить объём работы до того, как Agent приступит к выполнению задачи.
    * Установите лимиты использования в разделе [Управление расходами](/ru/ja/billing/managing-spend), чтобы циклы не приводили к большим счетам.
  </Accordion>

  <Accordion title="Как снизить расходы на Agent — какие настройки действительно помогают?">
    Наиболее эффективны следующие варианты:

    * **[Режим Free](/ru/ja/features/agent/agent-modes)** — повседневная работа с Agent без дополнительных затрат в пределах включённого объёма для подписчиков Core и Pro.
    * **[Режим Power](/ru/ja/features/agent/agent-modes)** — более высокие возможности по доступной цене, когда задача требует большего.
    * **[Режим Plan](/ru/ja/features/agent/plan-mode)** — определите объём работы и утвердите его до того, как Agent приступит к сборке, чтобы не платить за ненужные изменения.
    * **Лимиты использования и бюджеты** — задайте жёсткие ограничения в разделе [Управление расходами](/ru/ja/billing/managing-spend).

    Также полезно начинать новый чат с Agent при переходе к другой задаче. Заглядывайте в панель использования, чтобы понять, какие задачи обходятся дороже всего.
  </Accordion>

  <Accordion title="Что такое режимы Agent и чем они отличаются?">
    У Agent есть три основных режима. Подробное руководство см. в разделе [Режим Free](/ru/ja/help/free-agent-mode).

    * **Режим Free** — повседневная работа с Agent без расхода средств для подписчиков Core и Pro в пределах доступного объёма, который сбрасывается каждые 5 часов и ограничен недельным лимитом. Для тарифа Starter действуют прежние ограничения. Чтобы посмотреть расход, откройте **Настройки → Использование**.
    * **Power** — платный средний режим с доступом к мощным моделям по приемлемой цене.
    * **Max** — платный高 высший режим с самыми передовыми моделями для наиболее требовательных задач.
    * **Turbo** — дополнительный переключатель в расширенных настройках, доступный только в Max.

    Названия платных режимов изменились: **Economy стал Power**, а режим, ранее **называвшийся Power, стал Max**. Существующие настройки режимов сохраняются под новыми названиями. Если запрос требует больше возможностей, чем даёт режим Free, Agent может предложить платный вариант **разрешить один раз**. Replit запросит подтверждение перед началом платного действия, после чего Agent вернётся в режим Free.

    Кроме того, в [режиме Plan](/ru/ja/features/agent/plan-mode) Agent определяет объём работы до внесения изменений, а в режиме Build применяет изменения напрямую. См. [Сравнение режимов Plan и Build](/ru/ja/learn/plan-vs-build-mode).
  </Accordion>

  <Accordion title="Agent внёс нежелательные изменения — как их отменить?">
    Replit сохраняет чекпоинты во время работы Agent. В чате Agent найдите сообщение перед изменениями, которые хотите отменить, и выберите рядом с ним опцию отката, чтобы вернуть проект к этому состоянию. Подробнее см. в разделе [Чекпоинты и откаты](/ru/ja/features/version-control/checkpoints-and-rollbacks).

    Полный набор возможностей отката, включая восстановление отдельных файлов, см. в разделе [Чекпоинты и откаты](/ru/ja/features/version-control/checkpoints-and-rollbacks).
  </Accordion>

  <Accordion title="Agent сообщает, что у него нет доступа к интернету или внешним API. Это ожидаемое поведение?">
    На этапах сборки и редактирования Agent работает в изолированной среде (песочнице) с ограниченным исходящим доступом. Опубликованные приложения могут выполнять внешние вызовы API во время работы — песочница распространяется на среду редактирования Agent, но не на запущенное приложение.

    Если вызовы API в запущенном приложении завершаются ошибкой, убедитесь, что ключи сохранены в панели [Secrets](/ru/ja/core-concepts/project-editor/app-setup/secrets), и проверьте страницу статуса провайдера. В корпоративных и школьных сетях исходящие подключения от приложений могут быть заблокированы — уточните это у сетевого администратора.
  </Accordion>

  <Accordion title="Можно ли использовать собственный API-ключ в Agent?">
    Да. Добавьте ключи в панели [Secrets](/ru/ja/core-concepts/project-editor/app-setup/secrets), и приложение будет использовать их для API-вызовов. Откройте инструмент **Secrets**, выберите **+ Новый секрет**, затем введите имя (например, `OPENAI_API_KEY`) и значение.

    Вы можете [использовать собственные ключи AI-провайдера](/ru/ja/features/integrations/replit-ai-integrations) для моделей, которые вызывает ваше приложение. Модели, обеспечивающие работу самого Agent, работают в инфраструктуре Replit и не могут быть заменены.
  </Accordion>

  <Accordion title="Agent продолжает добавлять функции, о которых я не просил(а). Как добиться более точного результата?">
    Сформулируйте более чёткий промпт, чтобы направить Agent:

    * Начните со слова *«Только»* — например: «Добавьте только кнопку удаления в карточку пользователя. Больше ничего не меняйте».
    * Сначала используйте [режим Plan](/ru/ja/features/agent/plan-mode), чтобы понять, что Agent планирует сделать, прежде чем вносить изменения.
    * Если Agent внесёт нежелательные изменения, сразу попросите его отменить их в том же чате.

    Подробнее см. в разделе [Создание эффективных промптов](/ru/ja/learn/effective-prompting).
  </Accordion>
</AccordionGroup>
