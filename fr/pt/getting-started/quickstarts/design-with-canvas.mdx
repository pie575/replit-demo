⏰ *Temps estimé : 5 minutes* · Suite de [Créez votre première application](/fr/pt/getting-started/quickstarts/ask-ai)

Le **Canvas** est un espace visuel où vous pouvez explorer différentes pistes de design avant de créer votre application. Générez des maquettes, comparez-les côte à côte et appliquez celle qui vous plaît le plus.

<div id="antes-de-comear">
  ## Avant de commencer
</div>

Vous aurez besoin d&#39;une application existante dans Replit, issue du guide de démarrage rapide [Créez votre première application](/fr/pt/getting-started/quickstarts/ask-ai) ou de n&#39;importe quel autre projet.

<Tip>Vous pouvez également partir de zéro : créez simplement un nouveau projet et décrivez d&#39;abord votre idée à Agent.</Tip>

<div id="crie-o-design-do-seu-aplicativo">
  ## Créez le design de votre application
</div>

<Steps>
  <Step title="Explorez des variantes de design">
    Ouvrez l’onglet **Canvas** dans l’Éditeur de projet et cliquez sur **Réimaginer**. Un menu déroulant propose des prompts rapides pour explorer différentes pistes.
    Choisissez « Essayer différentes dispositions » et l’Agent génère plusieurs maquettes de design dans Canvas.

    <Frame>
      <video autoPlay muted loop playsInline src="/assets/mirror/try_different_layouts-with_canvas-7e77d972c8f5.mp4" />
    </Frame>

    Voici toutes les options disponibles :

    * Explorer différentes approches
    * Essayer différentes dispositions
    * Explorer différents styles
    * Plus comme ceci, mais en mieux
    * Optimiser pour la facilité d’utilisation
    * Montrer l’opposé de ceci
    * Surprenez-moi

    Vous pouvez aussi simplement demander à l’Agent de générer des variantes avec vos propres mots :

    ```
    Montrez-moi un thème sombre, un thème minimaliste et un thème coloré dans Canvas
    ```

    <Frame>
      <img src="/assets/mirror/quickstart_design_canvas_variations-636d281499e5.png" alt="Canvas affichant plusieurs variantes de design côte à côte" width="2538" height="1428" data-path="images/getting-started/quickstart_design_canvas_variations.png" />
    </Frame>
  </Step>

  <Step title="Choisissez une direction">
    Parcourez les variantes et choisissez celle qui correspond le mieux à votre vision. Vous pouvez demander à l’Agent d’affiner une variante spécifique avant de confirmer :

    ```
    J’aime la deuxième, mais agrandissez l’en-tête
    ```
  </Step>

  <Step title="Appliquez-le à votre application">
    Lorsque vous êtes satisfait d’un design, demandez à l’Agent de l’appliquer :

    ```
    Appliquez ce design à mon application
    ```

    L’Agent met à jour le code de votre application pour qu’il corresponde au design choisi. Consultez l’onglet **Aperçu** pour voir le résultat.
  </Step>

  <Step title="Publiez votre application mise à jour (facultatif)">
    Cliquez sur **Publier** dans l’Éditeur de projet pour mettre le nouveau design en ligne. Votre URL existante reste la même. Les visiteurs verront immédiatement la version mise à jour.

    <Frame>
      <video autoPlay muted loop playsInline src="/assets/mirror/quickstart-publish-app-ae59052ca92d.mp4" />
    </Frame>

    En savoir plus sur la publication dans [Publier votre application](/fr/pt/getting-started/quickstarts/publish).
  </Step>
</Steps>
