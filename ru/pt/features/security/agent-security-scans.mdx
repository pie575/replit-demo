Проверки безопасности Agent анализируют всю вашу кодовую базу на наличие уязвимостей, связанных с безопасностью и конфиденциальностью. Security Agent сочетает анализ на основе моделей с инструментами статического анализа, такими как [Semgrep](https://semgrep.dev/) и [HoundDog.ai](https://hounddog.ai), а затем отображает выявленные проблемы в Project Security Center.

Проверки безопасности Agent доступны всем платным пользователям Replit. Глубокая проверка крупных проектов может занять до 15 минут.

<div id="o-que-o-security-agent-revisa">
  ## Что проверяет Security Agent
</div>

При запуске проверки Security Agent:

1. Выявляет маршруты, API, потоки данных и точки входа.
2. Строит модель угроз для приложения.
3. Выполняет статический анализ всей кодовой базы.
4. Оценивает выявленные проблемы в контексте приложения.
5. Формирует отчёт о выявленных проблемах для вашего ознакомления.

Проверка может выявить небезопасные паттерны кода, такие как SQL-инъекции, межсайтовый скриптинг и межсайтовая подделка запросов; проблемы с конфиденциальностью, например передачу конфиденциальных данных в logs или API сторонних сервисов; а также архитектурные уязвимости в маршрутах, API и потоках данных.

<div id="iniciar-uma-verificao-de-segurana-do-agent">
  ## Запуск проверки безопасности с помощью Agent
</div>

<Steps>
  <Step title="Откройте Security Center">
    На панели **Tools** вашего проекта выберите **Security Center**. Вы
    также можете выбрать **Review security** в процессе публикации.

    <Frame>
      <img src="/assets/mirror/review-security-button-9331149c28f7.png" alt="Действие Review security в процессе публикации" width="1440" height="900" data-path="images/project-security-center/review-security-button.png" />
    </Frame>
  </Step>

  <Step title="Запустите проверку">
    Выберите **Run scan with Agent**.

    <Frame>
      <img src="/assets/mirror/run-scan-with-agent-f54820ac154a.png" alt="Действие Run scan with Agent в Project Security Center" width="1440" height="900" data-path="images/project-security-center/run-scan-with-agent.png" />
    </Frame>
  </Step>

  <Step title="При необходимости добавьте контекст">
    При необходимости добавьте контекст, чтобы модель угроз была сосредоточена на конкретных областях вашего приложения, затем запустите проверку безопасности.

    <Frame>
      <img src="/assets/mirror/scan-options-c2cd398fa78b.png" alt="Параметры проверки безопасности с полем Add context и действием Start security scan" width="1440" height="900" data-path="images/project-security-center/scan-options.png" />
    </Frame>
  </Step>

  <Step title="Дождитесь завершения проверки">
    Дождитесь завершения проверки Security Agent. Обычно это занимает несколько минут, а для крупных проектов — до 15 минут.
  </Step>
</Steps>

<div id="revisar-e-corrigir-achados">
  ## Проверка и устранение выявленных проблем
</div>

<Steps>
  <Step title="Проверить отчёт">
    Изучите каждую выявленную проблему и её уровень серьёзности в **Security Center**. Отклоните
    проблемы, которые вы понимаете и считаете приемлемыми, или проверьте их перед
    отправкой на исправление.
  </Step>

  <Step title="Исправить принятые проблемы с помощью Agent">
    Отправьте принятые проблемы в Agent. Security Agent распределяет
    уязвимости по отдельным задачам, чтобы Agent мог параллельно работать над
    несколькими исправлениями.
  </Step>

  <Step title="Повторно запустить проверку">
    После того как Agent применит исправления, запустите проверку ещё раз, чтобы
    убедиться, что проблемы устранены. В более крупных проектах после исправления проблем с более
    высоким уровнем серьёзности могут обнаружиться дополнительные проблемы.
  </Step>
</Steps>

<div id="quando-usar-o-nvel-3">
  ## Когда использовать уровень 3
</div>

Проверка безопасности Agent анализирует исходный код. Если вам также нужно проверить работающее приложение, взаимодействуя с ним через браузер и сеть, используйте [тест на проникновение методом «чёрного ящика» уровня 3](/ru/pt/features/security/black-box-pen-tests). Уровень 3 параллельно выполняет тест методом «чёрного ящика» и анализ исходного кода.

<div id="limitaes-e-boas-prticas">
  ## Ограничения и рекомендации
</div>

* Проверка выполняется в инфраструктуре Replit. Replit не передаёт ваш код или данные Semgrep, HoundDog.ai и другим третьим сторонам.
* Конфигурация и результаты проверки остаются привязанными к вашему Replit App.
* Проверка не заменяет полную проверку безопасности. Используйте её вместе с проверкой кода, тестированием, проверкой зависимостей и проверками работающего приложения.
* Повторно запускайте проверку после существенных изменений в коде, добавления или обновления зависимостей, а также перед публикацией новой версии.
