</div>

сообщения, требующие ответа.

<div id="run-a-routine">
  ### Запустите Routine
</div>

Routine позволяет планировать регулярные задачи в Conversation. Replit отправляет каждый результат в ту же Conversation, где вы можете просмотреть его и продолжить работу. Подробнее о [Routines](/ru/chat/routines).

Например, попросите Replit каждое утро просматривать Slack и возвращать список ваших приоритетов.

<div id="conversations-vs-projects">
  ## Conversation и Project: в чём разница
</div>

Conversation — это отдельный тред для вопросов, исследования идей и Routine. [Project](/ru/features/projects-and-artifacts/projects) — более основательное пространство для серьёзной работы по разработке и дизайну, включая несколько артефактов.

Начинайте с Conversation. Когда работа перерастает в полноценную разработку или дизайн, Conversation можно превратить в Project.

В боковой панели Conversation обозначаются значком облачка чата, а Project — значком сетки из четырёх квадратов.

<Frame>
  <img src="/assets/mirror/conversation-and-project-icons-025a17613daa.png" alt="Боковая панель Replit: Project со значком сетки из четырёх квадратов и Conversation со значком облачка чата" width="466" height="290" data-path="images/chat/conversation-and-project-icons.png" />
</Frame>

| Область            | Conversation                          | Project                                                                                                    |
| ------------------ | ------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| Лучше подходит для | Вопросов, исследования идей и Routine | Более серьёзной работы по разработке и дизайну: приложений, презентаций, дашбордов и нескольких артефактов |
| Фоновые задачи     | **Недоступны**                        | **Могут выполняться параллельно**                                                                          |
| Routine            | **Доступны**                          | **Недоступны**                                                                                             |
| Интеграции         | Доступны                              | Доступны                                                                                                   |
| Структура          | Один тред                             | Рабочее пространство проекта с несколькими артефактами                                                     |
