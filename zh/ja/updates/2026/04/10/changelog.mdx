<div id="databricks">
  ### Databricks 应用集成
</div>

Enterprise 构建者现在可以在 Replit 上构建数据应用，并直接部署到 Databricks。Agent 可连接到您的 Databricks 环境，在数据不离开 Databricks 的情况下查看数据架构。应用准备就绪后，您可以直接发布到 Databricks Apps。运行中的应用完全托管在 Databricks 上，并沿用 Databricks 的认证、Unity Catalog 治理和现有网络限制。

<Frame>
  <img src="/assets/mirror/databricks-app-template-333354ec6944.png" alt="在模板下拉菜单中选择 Databricks 应用模板的 Replit Workspace" width="1368" height="395" data-path="images/changelog/2026-04-10/databricks-app-template.png" />
</Frame>

拥有 Databricks 工作区的 Enterprise 组织可使用此集成。详情请参阅 [Replit x Databricks 合作伙伴页面](https://replit.com/partners/databricks)。

  ## Agent
</div>

<div id="ui">
  ### 根据截图复现界面
</div>

您可以将截图粘贴到 Agent 中，并要求“构建这个”或“复现这个界面”。无论是 Web 应用还是幻灯片演示文稿，Agent 都能一次性高保真地还原设计。这有助于复制现有设计、重建参考界面，或根据模型快速制作原型。

<div id="connectors">
  ### 所有付费套餐现均可使用 Connectors
</div>

Core 和 Pro 计划的构建者现在可以直接通过工作区访问所有 Connectors。

有关详细信息，请参阅[管理 Connectors](/zh/ja/replitai/managing-connectors)。

<div id="razorpay">
  ### 面向印度的 Razorpay 支付
</div>

印度构建者现可通过 Razorpay 使用 UPI 和银行卡付款。其中包括对定期订阅电子授权的支持，以满足印度储备银行的要求。印度现有订阅者很快便可在账单页面从 Stripe 切换至 Razorpay。

</Frame>

<div id="revenuecatapp-store-connect">
  ### RevenueCat 与 App Store Connect 同步
</div>

RevenueCat 集成现已支持自动同步至 Apple。您在 RevenueCat 中设置应用内购买后，相关设置将直接同步到 App Store Connect。

详细了解 [RevenueCat 订阅](/zh/core-concepts/monetization/revenuecat-subscriptions)。

<div id="section-4">
  ### 选择应用发布地理位置
</div>

Core、Pro 和 Enterprise 构建者现在可以选择应用要 Publish 到哪个区域。Publish 到某个区域后，计算资源、数据库和对象存储的所有产物都会部署在该区域。区域专属代理可降低应用访客的延迟。

除北美外，现已支持欧洲；澳大利亚、南美和亚洲也将很快推出。Enterprise 管理员还可以出于合规目的，将组织限制在单个区域。

</Frame>

了解有关[项目区域](/zh/ja/features/publishing/project-geography)的更多信息。

<div id="section-5">
  ### 在使用情况页面查看历史发票
</div>

现在，你可以直接在账户设置的**使用情况**页面查看历史发票。在下拉菜单中选择过去的账单周期，即可查看各应用的详细用量明细。
