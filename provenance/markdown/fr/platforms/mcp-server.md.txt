# Serveur MCP Replit

> Connectez un client MCP à Replit pour créer, trouver, inspecter, mettre à jour et publier des applications Replit.

Replit MCP utilise le [Model Context Protocol](https://modelcontextprotocol.io/) pour vous permettre de créer, trouver, inspecter, mettre à jour et publier des projets Replit depuis les outils IA que vous utilisez déjà.

Cette page est la référence pour les clients MCP directs et leurs outils.

## Connecter directement un client MCP

Utilisez la connexion directe lorsque votre client MCP ne dispose pas d'une intégration native Replit.

| Propriété            | Valeur                                        |
| -------------------- | --------------------------------------------- |
| **URL**              | `https://replit-mcp.com/server/mcp`           |
| **Transport**        | HTTP streamable                               |
| **Authentification** | OAuth via la découverte de ressource protégée |

Ajoutez l'URL du serveur à un client MCP qui prend en charge le transport HTTP streamable et l'autorisation OAuth. Le client lit les métadonnées de ressource protégée de Replit. Il vous invite ensuite à vous connecter à Replit.

Ne créez pas de serveur OAuth personnalisé. Le serveur MCP Replit fournit les métadonnées OAuth dont votre client a besoin.

Vous pouvez créer des applications ou travailler sur des applications que vous pouvez modifier, y compris les applications partagées avec vous.

### Configurer Replit MCP

Codex et Claude Code sont des exemples. Vous pouvez ajouter Replit MCP à n'importe quel client MCP compatible.

## Intégrations natives

Replit est également disponible en tant qu'intégration native dans [ChatGPT](/fr/features/platforms/chatgpt), [Claude](/fr/features/platforms/claude) et [Slack](/fr/features/platforms/slack). Utilisez les pages liées pour les étapes de connexion spécifiques à chaque plateforme.

## Outils

| Outil                     | Entrée requise                | Entrée optionnelle                                        | Utilisation                                                                                                                                                                                                    |
| ------------------------- | ----------------------------- | --------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `create_app_from_prompt`  | `appDescription`, `app_stack` | `userSpecifiedAppName`, `userQuotes`, `attachmentSummary` | Démarrer une nouvelle application. `app_stack` est l'une des valeurs suivantes : `react_website`, `mobile_app`, `design`, `slides`, `animation`, `data_visualization`, `3d_game`, `document` ou `spreadsheet`. |
| `search_apps`             | Aucune                        | `query`, `url`, `updatedAfter`, `updatedBefore`, `limit`  | Trouver des applications par mots-clés du titre, URL ou date de dernière mise à jour. `limit` est compris entre 1 et 50.                                                                                       |
| `resolve_app_by_name`     | `name`                        | Aucune                                                    | Trouver une application par son titre exact.                                                                                                                                                                   |
| `list_apps`               | Aucune                        | `query`, `limit`                                          | Lister les applications que vous pouvez modifier, classées par activité récente. La limite par défaut est de 25 et le maximum est de 50.                                                                       |
| `ask_question`            | `replId`, `question`          | Aucune                                                    | Interroger Agent à propos d'une application sans la modifier.                                                                                                                                                  |
| `update_app_using_prompt` | `replId`, `changeDescription` | `userQuotes`, `attachmentSummary`                         | Démarrer une mise à jour Agent pour une application existante.                                                                                                                                                 |
| `publish_app`             | `replId`                      | Aucune                                                    | Publier une application ou republier ses dernières modifications.                                                                                                                                              |
| `get_publish_status`      | `replId`                      | Aucune                                                    | Vérifier si une application a été publiée, son statut de publication actuel et son URL publique.                                                                                                               |

## Dépannage

| Problème                                                                        | Que faire                                                                                                                                                |
| ------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Replit vous demande de vous authentifier                                        | Terminez à nouveau le flux de connexion OAuth depuis votre client MCP.                                                                                   |
| Une application n'est pas trouvée                                               | Vérifiez que vous pouvez modifier l'application. Recherchez ensuite par URL ou utilisez `list_apps` pour choisir parmi les applications correspondantes. |
| Une demande de création, de mise à jour ou de publication est toujours en cours | Attendez avant de réessayer. Pour la publication, utilisez `get_publish_status` pour vérifier le résultat actuel.                                        |
