<div id="section-3">
  ### Prompts personnalisés
</div>

<Note>
  **Mise à jour (décembre 2025) :** Assistant n’est plus pris en charge. Pour effectuer rapidement des modifications ciblées, utilisez le [mode Lite d’Agent](/fr/core-concepts/agent/agent-modes).
</Note>

Les prompts personnalisés vous permettent de contrôler entièrement le comportement d’Assistant. Qu’il s’agisse de définir des normes de codage spécifiques ou de personnaliser les réglages par défaut d’Assistant, les prompts personnalisés répondent à tous vos besoins.

Vous pouvez notamment ajouter :

* Un style de codage ou un framework spécifique
* Des techniques spécifiques de résolution de problèmes
* Des préférences de gestion des paquets

Par exemple, vous pouvez ajouter ce qui suit :

```
use pnpm for package management
use motion/react instead of framer-motion
always use claude-3-5-sonnet-20241022 as your model
```

<div id="replit">
  ### Thèmes des applications Replit
</div>

Vos projets passent à la vitesse supérieure, sans code 💅

Vous pouvez désormais demander à Agent de créer une application React Replit, puis la personnaliser facilement à l’aide d’un outil de création de thèmes sans code :

* Modifier les couleurs principales
* Basculer entre les modes clair et sombre
* Personnaliser le design de votre app selon votre style

<div id="workflows">
  ### Workflows
</div>

Un workflow est un bouton « Run » facile à configurer qui permet d’exécuter les commandes de votre choix.

Il s’agit d’une séquence d’étapes réutilisables et personnalisables que vous pouvez exécuter dans votre application Replit. Il peut être aussi simple que **`python main.py`** ou constituer une procédure complexe comportant plusieurs étapes.

Exemples de cas d’utilisation :

* Exécuter plusieurs services en parallèle (par exemple, le frontend et le backend)
* Exécuter des fichiers ou des commandes de manière séquentielle (par exemple, exécuter le linter → exécuter les tests, compiler → exécuter le code)

Pour commencer à [créer un workflow](https:/.replit.com/replit-workspace/workflows#creating-workflows), utilisez le menu de la barre latérale des outils ou recherchez le panneau Workflows avec **`Command + K`**.

Consultez [cette page](https:/.replit.com/replit-workspace/workflows).
