Возможность входа на ваш сайт с помощью аккаунта Google даёт пользователям следующие преимущества:

1. Не нужно реализовывать собственную схему аутентификации.
2. Можно легко получать имена и контактные данные пользователей.
3. С теми же учётными данными можно получать доступ к ресурсам Google пользователя, например Sheets и Drive.

В этом руководстве объясняется, как реализовать это в Replit с помощью Python и Flask.

Сначала мы рассмотрим настройку базовой OAuth-аутентификации, а затем — использование полученных учётных данных для доступа к ресурсам Google пользователя.

<div id="oauth">
  ## Обзор OAuth
</div>

Аутентификация через Google основана на стандарте OAuth. Работает OAuth так:

1. Где-нибудь на сайте вы направляете пользователя на страницу входа.
2. Когда пользователь открывает страницу входа, вы не реализуете форму входа на своём сайте, а перенаправляете пользователя в службу входа Google, чтобы он вошёл там.
3. После успешного входа служба входа Google перенаправляет пользователя обратно на ваш сайт — на заданный вами URL (например, `https://YOUR_DOMAIN/oauth2callback`) — и передаёт информацию о пользователе и сеансе входа.
4. С помощью этих данных вы получаете токен доступа. Это своего рода пропуск к ресурсам: данным профиля пользователя, таблицам, документам и т. д.

<div id="oauth-2">
  ## OAuth: покажите код
</div>

Если вы, как и я, хотите сначала увидеть работающий код, вот он. Однако, чтобы всё работало правильно, потребуется выполнить несколько настроек в Google Cloud Console. Они описаны в следующем разделе. Создайте новый Replit App с помощью [шаблона Flask](https://replit.com/@replit/Flask?v=1) и вставьте следующий код в `main.py`. Комментарии в коде поясняют каждую его часть:

```python theme={null}
from flask import Flask, redirect, session, url_for, request
import google_auth_oauthlib.flow
import json
import os
import requests

app = Flask('app')
# `FLASK_SECRET_KEY` используется для работы сеансов. Создайте случайную строку
# и сохраните её в Secrets.
app.secret_key = os.environ.get('FLASK_SECRET_KEY') or os.urandom(24)

# `GOOGLE_APIS_OAUTH_SECRET` содержит содержимое JSON-файла, который нужно скачать
# из панели учётных данных Google Cloud. См. следующий раздел.
oauth_config = json.loads(os.environ['GOOGLE_OAUTH_SECRETS'])

# Здесь настраивается поток OAuth
oauth_flow = google_auth_oauthlib.flow.Flow.from_client_config(
    oauth_config,
    # scopes определяют, к каким API вы хотите получить доступ от имени пользователя после аутентификации
    scopes=[
        "https://www.googleapis.com/auth/userinfo.email",
        "openid",
        "https://www.googleapis.com/auth/userinfo.profile",
    ]
)

# Это точка входа для страницы входа. Она перенаправляет на службу входа Google по адресу
# `authorization_url`. `redirect_uri` — URI, который служба входа Google использует для
# перенаправления обратно в это приложение.
@app.route('/signin')
def signin():
    # Мы заменяем в URL http на https, поскольку внутри Replit App используется http,
    # а извне доступ осуществляется через https, поэтому redirect_uri должен ему соответствовать
    oauth_flow.redirect_uri = url_for('oauth2callback', _external=True).replace('http://', 'https://')
    authorization_url, state = oauth_flow.authorization_url()
    session['state'] = state
    return redirect(authorization_url)

# Это конечная точка, на которую перенаправляет служба входа Google. Её необходимо добавить в раздел "Authorized redirect URIs"
# панели учётных данных API в Google Cloud. Она обращается к конечной точке Google, чтобы запросить
# токен доступа и сохранить его в сеансе пользователя. Затем токен доступа можно использовать для обращения к
# API от имени пользователя.
@app.route('/oauth2callback')
def oauth2callback():
    if not session['state'] == request.args['state']:
        return 'Invalid state parameter', 400
    oauth_flow.fetch_token(authorization_response=request.url.replace('http:', 'https:'))
    session['access_token'] = oauth_flow.credentials.token
    return redirect("/")

# Это главная страница приложения. Она предлагает пользователю войти, если он ещё не вошёл.
# Если пользователь уже вошёл, она показывает его данные.
@app.route('/')
def welcome():
    if "access_token" in session:
        user_info = get_user_info(session["access_token"])
        if user_info:
            return f"""
                Hello {user_info["given_name"]}!<br>
                Your email address is {user_info["email"]}<br>
                <a href="/logout">Log out</a>
            """
    return """
        <h1>Hello!</h1>
        <a href="/signin">Sign In via Google</a><br>
    """

# Вызовите API userinfo, чтобы получить данные пользователя с помощью действительного токена доступа.
# Это первый пример использования токена доступа для обращения к API от имени пользователя.
def get_user_info(access_token):
    response = requests.get("https://www.googleapis.com/oauth2/v3/userinfo", headers={
       "Authorization": f"Bearer {access_token}"
   })
    if response.status_code == 200:
        user_info = response.json()
        return user_info
    else:
        print(f"Failed to fetch user info: {response.status_code} {response.text}")
        return None

@app.route('/logout')
def logout():
    session.clear()
    return redirect('/')

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000)

```

  ## Интеграция с Google Sheets: покажите код
</div>

В разделе OAuth-потока исходного кода ничего не меняйте, кроме добавления `"https://www.googleapis.com/auth/spreadsheets.readonly"` в список областей доступа:

```python theme={null}
# Здесь задаётся конфигурация для потока OAuth
oauth_flow = google_auth_oauthlib.flow.Flow.from_client_config(
    oauth_config,
    # scopes определяют, к каким API вы сможете обращаться от имени пользователя после аутентификации
    scopes=[
        "https://www.googleapis.com/auth/userinfo.email",
        "openid",
        "https://www.googleapis.com/auth/userinfo.profile",
        "https://www.googleapis.com/auth/spreadsheets.readonly"
    ]
)
```

Чтобы обратиться к Google API через библиотеку `googleapiclient.discovery`, сначала создайте объект `Credentials`, используя токен доступа, а затем с помощью функции `build` создайте объект API, через который можно выполнять запросы. Для Sheets API это выглядит так:

```python theme={null}
credentials = google.oauth2.credentials.Credentials(token=session['access_token'])
service = build("sheets", "v4", credentials=credentials)
sheets_api = service.spreadsheets()
```

Мы создали несколько вспомогательных функций, которые показывают, как работать с Sheets API на практике:

```python theme={null}
# получить все листы таблицы Google
def get_sheets(sheets_api, spreadsheet_id) -> list[str]:
    result = sheets_api.get(spreadsheetId=spreadsheet_id).execute()
    return [sheet["properties"]["title"] for sheet in result["sheets"]]

# получить данные указанного листа таблицы Google
def get_sheet_data(sheets_api, spreadsheet_id, sheet_title) -> list[list[str]]:
    result = (
        sheets_api.values()
        .get(spreadsheetId=spreadsheet_id, range=sheet_title)
        .execute()
    )
    return result["values"]
```

С помощью описанных выше вспомогательных функций можно создать эндпоинт-обработчик для импорта Google Таблиц:

```python theme={null}
@app.route("/import_spreadsheet", methods = ['POST'])
def import_spreadsheet():
    if 'access_token' not in session:
        return redirect('/signin')
    spreadsheet_id = request.form["spreadsheet_id"]
    credentials = google.oauth2.credentials.Credentials(token=session['access_token'])
    service = build("sheets", "v4", credentials=credentials)
    sheets_api = service.spreadsheets()
    try:
        sheets = get_sheets(sheets_api, spreadsheet_id)
        data_by_sheets = {}
        for sheet in sheets:
            data = get_sheet_data(sheets_api, spreadsheet_id, sheet)
            data_by_sheets[sheet] = data
    except googleapiclient.errors.HttpError as e:
        return f"upload failure"
    dirpath = os.path.join("static", "uploads", spreadsheet_id)
    filepath = os.path.join(dirpath, "data.json")
    os.makedirs(dirpath, exist_ok=True)
    with open(filepath, "w") as file:
        json.dump(data_by_sheets, file)
    return "upload success!"
```

def get_sheet_data(sheets_api, spreadsheet_id, sheet_title) -> list[list[str]]:
    result = (
        sheets_api.values()
        .get(spreadsheetId=spreadsheet_id, range=sheet_title)
        .execute()
    )
    return result["values"]

@app.route("/import_spreadsheet", methods = ['POST'])
def import_spreadsheet():
    if 'access_token' not in session:
        return redirect('/signin')
    spreadsheet_id = request.form["spreadsheet_id"]
    credentials = google.oauth2.credentials.Credentials(token=session['access_token'])
    service = build("sheets", "v4", credentials=credentials)
    sheets_api = service.spreadsheets()
    try:
        sheets = get_sheets(sheets_api, spreadsheet_id)
        data_by_sheets = {}
        for sheet in sheets:
            data = get_sheet_data(sheets_api, spreadsheet_id, sheet)
            data_by_sheets[sheet] = data
    except googleapiclient.errors.HttpError as e:
        return f"upload failure"
    dirpath = os.path.join("static", "uploads", spreadsheet_id)
    filepath = os.path.join(dirpath, "data.json")
    os.makedirs(dirpath, exist_ok=True)
    with open(filepath, "w") as file:
        json.dump(data_by_sheets, file)
    return "upload success! Really!"
