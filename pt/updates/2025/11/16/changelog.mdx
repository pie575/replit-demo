### Integração com o Azure Marketplace

O Replit agora está disponível no Azure Marketplace! Muitas organizações já possuem orçamentos dedicados para o Azure, e esta integração permite que elas usem esses fundos diretamente em assinaturas e uso do Replit.

Após a integração com o GCP Marketplace em setembro, esta adição torna ainda mais fácil para equipes enterprise adotarem o Replit usando seus processos e orçamentos de aquisição de nuvem existentes.

[Ver no Azure Marketplace](https://marketplace.microsoft.com/en-us/product/saas/replit.replit?tab=Overview)

### Suporte ao GitLab e Bitbucket

O Replit agora suporta repositórios GitLab e Bitbucket além do GitHub, oferecendo mais flexibilidade em onde você armazena seu código. Agora você pode importar projetos do GitLab e Bitbucket diretamente para o Replit, juntamente com funcionalidade git aprimorada em todas as plataformas suportadas.

A integração git aprimorada inclui:

* **Suporte multiplataforma**: Importe e trabalhe com repositórios do GitHub, GitLab e Bitbucket
* **Operações git aprimoradas**: Comandos git mais rápidos e confiáveis em todo o workspace
* **Melhor gerenciamento de repositórios**: Fluxos de trabalho simplificados para clonar, enviar e puxar de qualquer provedor git suportado

Saiba mais sobre [importação de projetos](/pt/core-concepts/project-editor/app-setup/import) e [uso de git no Replit](/pt/core-concepts/project-editor/version-control/git-interface).
