---

使用 Shell，您可以像在普通终端中一样，在项目中管理文件、安装软件包和运行脚本。
例如，您可以浏览项目文件；如果项目已配置数据库连接，还可以使用 `psql`。

<Tip>
  为了更好地管理工作流，建议使用 **Run** 按钮启动应用，而不要在 Shell 中运行应用。通过
  **Run** 按钮启动的工作流会将输出发送到 Console 工具，便于以结构化方式查看日志。
</Tip>

<div id="section">
  ## 功能
</div>

Shell 提供以下功能：

* **运行多个 Shell**：打开多个 Shell 实例，同时处理不同任务
* **文本搜索**：在 Shell 输出中查找指定文本

<div id="shell">
  ### 确认 Shell 访问权限
</div>

运行以下命令，确认 Shell 已就绪并查看当前工作区：

```sh theme={null}
pwd
```

Shell 会显示当前工作区的路径。

<Frame caption="pwd 命令会显示当前工作区路径，然后返回 Shell 提示符。">
  <img src="/assets/mirror/shell-pwd-output-2d31a0e0466b.jpg" alt="Shell 选项卡中显示 pwd 命令、工作区路径输出以及返回的提示符" width="1280" height="246" data-path="images/workspace/shell-pwd-output.jpg" />
</Frame>

对于包含数据库的项目，请选择 **Tools** → **Database**，然后
打开 **Development database** 页面。此页面提供连接控制功能。
请妥善保管连接值，切勿将其复制到文档、截图、日志、源文件或
共享消息中。

<div id="section-3">
  ### 文本搜索
</div>

按以下步骤访问和使用文本搜索工具：

1. 选择 Shell 标签页右上角的 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 放大镜图标，打开搜索对话框。
2. 输入搜索词，然后选择 **Next** 浏览匹配项。
3. 使用 **Previous** 返回上一个匹配项。
4. 选择 **Exit**，或点击对话框外部以退出文本搜索。

<div id="shell-2">
  ### 多个 Shell
</div>

要创建其他 Shell：

1. 在 Shell 面板标题栏中选择 Shell 实例菜单。
2. 选择 **New Shell**。

<Frame>
  <img src="/assets/mirror/shell-new-94a280c1230f.png" alt="显示当前工作区和 New Shell 选项的 Shell 实例菜单" width="1280" height="224" data-path="images/workspace/shell-new.png" />
</Frame>

使用同一菜单在不同 Shell 之间切换。Replit 会以每个 Shell 最后运行的命令作为标识，方便你区分。

<Warning>
  打开多个 Shell 后，Replit 会自动关闭空闲的 Shell 实例。
  空闲 Shell 是指未被选中且没有正在运行的用户进程的 Shell。
</Warning>
