<div id="section-2">
  ## 平台更新
</div>

<div id="repl">
  ### Repl -&gt; 应用
</div>

Repl 现在改称&quot;应用&quot;。简单至上。

<div id="section-3">
  ### 改进的通知
</div>

我们优化了支付失败和账单通知。现在，应用暂停前将提供 24 小时的宽限期，整个流程也更加透明。

此次更新有助于避免 Replit 使用体验中断。

<div id="section-4">
  ### 对象存储改进
</div>

对象存储面板新增了搜索和分页功能，浏览文件更加轻松。

<div id="diff">
  ### 更清晰的差异对比
</div>

Assistant 的文件改动现在会在临时 diff 面板中打开。这样你就能更方便地查看改动，也不会因为标签页越开越多而拖慢工作区。

应用改动后，该面板会自动关闭。

<div id="agent">
  ### 亚洲地区 Agent 性能更佳
</div>

我们已针对亚洲的 Agent 构建者优化了云服务。响应更快，使用体验也更加流畅。

<div id="x">
  ### 使用 X 登录
</div>

现在，你可以使用 X 账号注册并登录 Replit。欢迎来到未来。

<div id="section-5">
  ### 快速导入仓库
</div>

想把喜欢的 GitHub 仓库导入 Replit 吗？

现在一步即可搞定。

在浏览器中输入 `replit.com/YOUR_REPO_URL`。例如：

`https://replit.com/github.com/mattppal/magnetic-feel`
