<div id="slack">
  ### Интеграция со Slack
</div>

Теперь Agent интегрирован с API Slack. Это значит, что с помощью Agent можно создавать приложения, которые умеют:

* Публиковать сообщения
* Читать историю сообщений

в ваших любимых каналах Slack.

<Frame>
  <img src="/assets/mirror/slack-integration-1072c585c41e.png" alt="Интеграция со Slack" width="1640" height="739" data-path="images/changelog/2025-01-10/slack-integration.png" />
</Frame>

Поделитесь тем, что вы создали, в [Agent Showcase](https://forms.gle/qxpfr82wNpKsCdok9).

<div id="agent-assistant">
  ### Улучшения Agent и Assistant
</div>

* Agent теперь быстрее загружается на главной странице, чтобы вы могли скорее приступить к разработке.
* При выделении текста в консоли или Shell теперь можно быстро открыть Assistant во всплывающем окне. Выделите текст, нажмите значок Assistant и задайте вопрос.

  <img src="/assets/mirror/ask-assistant-cd529bf4a0b1.png" alt="Спросить Assistant" width="2532" height="1474" data-path="images/changelog/2025-01-10/ask-assistant.png" />
</Frame>

<div id="section-3">
  ### Улучшенное управление рекомендациями проектов
</div>

Теперь добавлять публичные проекты вашей организации в рекомендации и удалять их оттуда стало проще!

<Frame>
  <img src="/assets/mirror/feature-on-profile-95b81a71e0d7.png" alt="Рекомендуемые проекты в профиле" width="1836" height="644" data-path="images/changelog/2025-01-10/feature-on-profile.png" />
</Frame>

Теперь вы можете управлять статусом рекомендации проекта прямо из рабочего пространства — через модальное окно сведений о проекте и таблицу индекса проектов.

<Frame>
  <img src="/assets/mirror/profile-preview-b8f2ecfed154.png" alt="Предпросмотр профиля" width="2126" height="1152" data-path="images/changelog/2025-01-10/profile-preview.png" />
</Frame>

Кроме того, добавив проект в рекомендации, вы можете предварительно посмотреть, как он будет отображаться в вашем публичном профиле.
