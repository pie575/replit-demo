Создавайте приложения на актуальных реальных данных с помощью функции Web Search <img class="icon-svg" src="/assets/mirror/web-search-1fe8f63b5b88.svg" alt="Иконка Web Search" width="16" height="16" data-path="images/icons/web-search.svg" /> в Agent.

Эта функция получает свежую информацию из интернета и тем самым снимает ограничения, связанные с датой обучения модели. Попросите создать что-то, для чего нужны актуальные данные, — и Agent выполнит поиск в интернете, соберёт подробные материалы и сделает приложение точнее и полезнее.

Web Search помогает находить свежие пакеты, инструменты и сведения. Благодаря этому ваше приложение опирается на актуальные лучшие практики и работает точнее.

<div id="section">
  ## Возможности
</div>

Создавайте приложения на основе актуальных данных с помощью Web Search в Agent — больше не нужно вручную искать и собирать информацию. Будь то панель с финансовыми показателями или сайт с новостями о запусках стартапов, Web Search гарантирует, что ваше приложение отражает реальное положение дел.

Задачи Web Search, которые может выполнять Agent:

* **Поиск**: находить в интернете актуальную информацию, свежую документацию и данные в реальном времени
* **Получение контента**: извлекать подробные сведения с определённых сайтов и URL-адресов
* **Цитирование источников**: точно видеть, где Agent нашёл информацию, чтобы проверить её и сослаться на источник

<div id="section-2">
  ## Использование
</div>

Web Search встроен в Agent, поэтому включать его отдельно не нужно. Опишите, что хотите создать, и Agent сам определит, когда стоит найти актуальную информацию. Чтобы Agent выполнил поиск явно, добавьте в промпт слова вроде «поищи», «изучи» или «используй Web Search».

<div id="web-search">
  ### Как Web Search улучшает приложения
</div>

Web Search помогает вашему приложению перейти от данных-заглушек к реальной и точной информации:

| Преимущество                   | Описание                                                                         |
| ------------------------------ | -------------------------------------------------------------------------------- |
| Современные технологии         | Приложение использует свежую информацию и пакеты, которых нет в обучающих данных |
| Выбор оптимальных инструментов | Agent изучает варианты и выбирает наиболее подходящие пакеты                     |
| Актуальные лучшие практики     | Доступ к современным шаблонам разработки и практикам безопасности                |
| Преодоление ограничений        | Выход за пределы даты обучения позволяет использовать пакеты, вышедшие после неё |
| Точные данные                  | Приложение показывает актуальные сведения вместо устаревших примеров             |
| Профессиональный результат     | Приложения, ссылающиеся на реальные компании, вызывают больше доверия            |
| Экономия времени               | Не нужно вручную искать пакеты и собирать данные                                 |

<div id="section-3">
  ### Цитирование источников
</div>

Когда Agent использует Web Search, он приводит **ссылки на источники**, показывающие, откуда именно взята информация. Используйте эти ссылки, чтобы:

* **Проверять информацию**: убедиться в надёжности и точности источника
* **Узнавать больше**: перейти к первоисточнику за дополнительным контекстом
* **Указывать источники**: добавить корректное упоминание источников в своё приложение
* **Отслеживать исследование**: понять, какая информация легла в основу работы Agent

<div id="section-4">
  ### Получение контента
</div>

Agent может извлекать подробный контент с определённых сайтов и собирать исчерпывающую информацию для проекта. Благодаря этому Agent может:

* читать веб-страницы целиком и извлекать нужные детали;
* обрабатывать документацию и справочные материалы;
* собирать конкретные данные из надёжных источников;
* интегрировать структурированную информацию в приложение.
