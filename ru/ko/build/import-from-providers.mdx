Импорт позволяет перенести существующий код или дизайн в Replit App и продолжить разработку с помощью Agent.

<div id="section">
  ## Поддерживаемые источники
</div>

| Источник                  | Что предоставляется                                        | Оптимальный сценарий использования                          |
| ------------------------- | ---------------------------------------------------------- | ----------------------------------------------------------- |
| GitHub                    | URL репозитория или выбор репозитория                      | Импорт публичных и приватных репозиториев                   |
| Bitbucket                 | URL репозитория или выбор репозитория                      | Импорт репозиториев, размещённых в Bitbucket                |
| Vercel                    | Репозиторий GitHub, лежащий в основе проекта Vercel        | Миграция приложений Vercel                                  |
| Figma                     | URL фрейма                                                 | Преобразование дизайна в приложение React                   |
| Claude                    | Дизайн, отправленный из Claude                             | Преобразование дизайна Claude в интерактивное приложение    |
| Bolt                      | Репозиторий GitHub, экспортированный из Bolt               | Миграция проектов Bolt                                      |
| Lovable                   | Репозиторий GitHub, экспортированный из Lovable            | Миграция проектов Lovable                                   |
| Base44                    | Репозиторий GitHub, экспортированный из Base44             | Миграция проектов Base44                                    |
| ZIP                       | Загрузка файла `.zip`                                      | Импорт локальных архивов проектов                           |
| Электронная таблица       | Файлы `.xlsx`, `.csv` или URL Google Таблиц                | Создание приложения на основе данных электронной таблицы    |
| Экспорт из прежнего Agent | Репозиторий GitHub, экспортированный из прежнего Agent App | Повторный импорт прежнего Agent App                         |
| Пустой проект             | Нет                                                        | Опытные пользователи, которым нужен пустой проект без Agent |

<Note>Replit проверяет совместимость перед началом импорта.</Note>

О дизайнах Figma см. [Импорт дизайнов Figma в Replit Design](/ru/ko/design/import-figma-designs-into-replit-design).

О дизайнах, отправленных из Claude, см. [Импорт дизайнов Claude в Replit Design](/ru/ko/design/import-claude-designs-into-replit-design).

    4. GitHub 계정을 연결하세요.
    5. 내보낸 Lovable 저장소를 선택하세요.
    6. **Import**를 선택하세요.

    <div id="what-gets-imported">
      ## Что импортируется
    </div>

    Replit импортирует из вашего проекта {platform_6} следующее:

    * **Код**: логика приложения и исходные файлы
    * **Дизайн и стили**: компоненты UI и правила стилизации
    * **Ассеты**: изображения, иконки и статические файлы
    * **Логика бэкенда**: серверная функциональность, если она есть
    * **Схема базы данных**: структура таблиц, если она есть

    <div id="what-is-not-imported">
      ## Что не импортируется
    </div>

    * **Данные Supabase**: существующие записи базы данных не переносятся
    * **Secrets**: переменные окружения и API-ключи нужно добавить отдельно

    Используйте Agent, чтобы восстановить недостающую функциональность, добавить секреты и заново создать данные в базе.

    * **[Workflows](/ru/features/workspace-tools/workflows)**: настройка команды **Run** для вашего приложения

  <Tab title="GitHub">
    ⏰ *Примерное время: 2 минуты*

    Импортируйте репозиторий GitHub в Replit, чтобы быстрее запускать, тестировать и публиковать приложение.

    **Перед началом**

    * URL репозитория GitHub
    * Права доступа к репозиторию (публичному или приватному)
    * Учётная запись Replit

    **Вариант 1: быстрый импорт**

    Быстрый импорт работает с публичными репозиториями.

    1. Скопируйте путь к репозиторию после `github.com/`.
    2. Откройте `https://replit.com/github.com/<owner>/<repo>`.
    3. Нажмите Enter, чтобы начать импорт.

    *Пример*

    * URL GitHub: `https://github.com/exampleUser/my-app`
    * URL импорта Replit: `https://replit.com/github.com/exampleUser/my-app`

    **Вариант 2: импорт с подсказками**

    Импорт с подсказками поддерживает как публичные, так и приватные репозитории.

    1. Откройте [replit.com/import](https://replit.com/import).
    2. Выберите **GitHub**.
    3. Подключите учётную запись GitHub.
    4. Выберите репозиторий.
    5. Нажмите **Import**.

    **Что импортируется**

    * Файлы и папки репозитория
    * Файлы зависимостей
    * Стандартные настройки запуска и сборки

    **Что не импортируется**

    * Существующие значения секретов и переменных окружения
    * Специфичные для платформы сервисы, которые не запускаются в Replit по умолчанию

    **Устранение проблем с подключением GitHub**

    Если появляется ошибка `Failed to get repository, please re-authenticate with GitHub` или в выпадающем списке репозиториев отображается `No repositories found`, учтите: процесс импорта из GitHub использует отдельное подключение, не связанное с тем, что настроено на странице **Account → Connected Services**. Повторное подключение только в Connected Services проблему с импортом не решит.

    <Steps>
      <Step title="Повторно подключите GitHub в Git Providers">
        Откройте раздел **Git Providers** в настройках учётной записи Replit, отключите GitHub и подключите его заново на том же экране. После этого личные репозитории должны появиться в выпадающем списке импорта.
      </Step>

      <Step title="Разрешите приложению Replit доступ к организации GitHub">
        Если репозиторий принадлежит организации GitHub, откройте [https://github.com/settings/applications](https://github.com/settings/applications), найдите OAuth-приложение Replit и предоставьте доступ к организации в настройках доступа сторонних приложений. Если вы не владелец организации, этот шаг может потребоваться выполнить её администратору.
      </Step>

      <Step title="Повторите импорт">
        Откройте [replit.com/import](https://replit.com/import) и попробуйте импортировать репозиторий двумя способами: через выпадающий список репозиториев и вставив URL репозитория.
      </Step>
    </Steps>

  <Tab title="ZIP">
    ⏰ *Примерное время: 3 минуты*

    Импортируйте локальный проект, загрузив файл `.zip`.

    **Перед началом**

    * Файл `.zip` с проектом (не более 200 МБ)
    * Чётко выделенная корневая папка проекта в архиве
    * Учётная запись Replit

    Если zip-файл больше 200 МБ, форма импорта его отклонит. Чтобы уменьшить размер, исключите папки с зависимостями и результатами сборки — например, `node_modules`, `.venv` и `build`. Replit переустановит зависимости во время импорта.

    **Шаги**

    1. Откройте [replit.com/import](https://replit.com/import).
    2. Выберите **ZIP**.
    3. Загрузите файл `.zip`.
    4. Добавьте запрошенные секреты и переменные окружения.
    5. Выберите **Import**.

    **Что импортируется**

    * Файлы проекта и структура каталогов
    * Файлы зависимостей
    * Настройки запуска и сборки Replit по умолчанию

    **Что не импортируется**

    * Существующие значения переменных окружения
    * Пользовательские домены
    * Сервисы конкретной платформы, требующие ручной настройки

<div id="section-3">
  ## Другие источники
</div>

<div id="bitbucket">
  ### Bitbucket
</div>

* Вставьте URL репозитория Bitbucket или подключите учётную запись Bitbucket, чтобы найти нужный репозиторий.
* Возможности Agent при импорте могут быть ограничены по сравнению с проектами, размещёнными на GitHub.

<div id="section-4">
  ### Электронные таблицы
</div>

* Загрузите файл Excel (`.xlsx`) или CSV либо вставьте публичную ссылку на Google Таблицы.
* Agent прочитает структуру электронной таблицы и соберёт полноценное full-stack приложение с базой данных, заполненной вашими данными.
* В приложение включён UI для просмотра, поиска и управления записями.

<div id="agent">
  ### Экспорт из прежнего Agent
</div>

* Повторно импортируйте ранее экспортированное Agent App из репозитория GitHub.
* Replit сохраняет структуру, специфичную для Agent (код, схему базы данных, функции бэкенда).
* Значения из базы данных и секреты не импортируются.

<div id="section-5">
  ### Пустой проект
</div>

* Начните с полностью пустого проекта: без Agent, без выбора фреймворка, без готового каркаса.
* Идеально подходит опытным пользователям, которым нужен полный контроль над настройкой проекта.

<div id="section-6">
  ## Ограничения
</div>

* Существующие данные базы данных не мигрируются.
* Размер загружаемых ZIP-файлов ограничен 200 МБ.
* Некоторые сложные или проприетарные зависимости могут потребовать ручной настройки.
* Обработка крупных проектов может занять больше времени.

<div id="section-7">
  ## Рекомендации
</div>

* Удалите конфиденциальные учётные данные перед импортом.
* Поддерживайте порядок в структуре исходного проекта.
* После импорта проверьте зависимости и команду запуска.
* Протестируйте основные сценарии перед публикацией.

<div id="section-8">
  ## Устранение неполадок
</div>

Если импорт не удался, в первую очередь проверьте следующее:

* **Ошибки совместимости**: убедитесь, что необходимые файлы проекта на месте, а используемый фреймворк поддерживается.
* **Ошибки доступа**: проверьте права доступа к репозиторию или источнику.
* **Ошибки обработки**: упростите структуру проекта или уменьшите его размер и повторите попытку.

Если проблема сохраняется, посетите [Replit Community Hub](https://replit.com/community) или [обратитесь в службу поддержки](https://replit.com/support).

<div id="section-9">
  ## Тарификация
</div>

Импорт, требующий миграции силами Agent, может расходовать кредиты. Расход кредитов зависит от сложности проекта.
