export const YouTubeEmbed = ({videoId, title = "YouTube video", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

### 워크스페이스 품질 개선

팀은 창작 경험을 더 원활하고 직관적으로 만들기 위한 다양한 개선 사항을 출시했습니다. 더 안정적인 미리보기 창부터 더 일관된 모바일 동작까지, 이러한 개선 사항은 아이디어를 실현하는 데 더 세련된 환경을 만들어줍니다.

### 인프라 개선

백그라운드에서 팀은 더 빠르고 안정적인 플랫폼을 제공하기 위해 인프라를 현대화하고 있습니다. 이러한 기술적 개선은 앞으로 더 강력한 기능과 더 나은 개발자 경험을 위한 토대를 마련합니다.

## Teams 및 엔터프라이즈

### 조직 앱 공유 개선

팀에서 더 깔끔하고 정돈된 워크스페이스를 즐기세요! 조직에서 생성된 새 앱은 더 이상 모든 멤버와 자동으로 공유되지 않습니다. 이를 통해 혼잡함이 줄어들고 팀 멤버의 워크스페이스에 표시되는 항목에 대한 제어권이 높아집니다.

### Teams 멤버 페이지 개선

Teams 멤버 페이지의 새로운 사용성 개선으로 팀 관리가 더욱 쉬워졌습니다. 이제 멤버, 뷰어, 초대 탭에서 정렬, 필터링, 검색이 가능합니다. 이는 엔터프라이즈 고객이 대규모 팀을 효율적으로 관리하기 위해 요청해온 기능입니다.
