<div id="replit-app-monitoring-keeps-an-eye-on-your-published-apps">
  ### Replit App 监控帮你盯紧已发布的应用
</div>

现在，你可以为任意已发布的 Replit App 开启 **App monitoring**，获得实时的 uptime 检测、在 **Publishing** 视图和 **Analytics** 标签页中显示的彩色 uptime 状态条，并在应用宕机时收到邮件通知。App monitoring 面向所有付费方案开放，适用于除 Scheduled Deployments 以外的所有 deployment 类型。万一应用出现问题，可以选择 **Investigate recent downtime with Agent**，启动后台任务自动提取受影响的时间段、排查日志和代码，并给出修复建议。

<div id="create-full-slide-decks-with-agent">
  ### 使用 Agent 创建完整的幻灯片演示文稿
</div>

描述你想要的演示文稿，例如融资路演稿、产品概览、销售提案或团队进展汇报，Agent 便会生成一份版式、文字和视觉元素俱全的精美演示文稿。你可以通过 Chat 优化幻灯片，用 Visual Editor 编辑文字和样式，在浏览器中直接演示，将演示文稿发布为在线网址，或导出为 PPTX、Google Slides 或 PDF。
