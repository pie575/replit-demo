L&#39;outil Secrets stocke et chiffre les **secrets**, c&#39;est-à-dire les informations sensibles de votre Replit App : clés d&#39;API, jetons d&#39;authentification et chaînes de connexion à une base de données.

Lorsque vous ajoutez un secret, l&#39;outil chiffre automatiquement les données et les met à disposition de votre Replit App sous forme de variable d&#39;environnement.
Cette approche vous évite d&#39;inscrire les secrets en dur dans votre code et réduit le risque de les exposer.

Inscrire des secrets en dur dans votre code peut entraîner une exposition accidentelle dans les cas suivants :

* Partager votre code avec d&#39;autres personnes via un Replit App public ou par copier-coller
* Envoyer votre code vers un système de contrôle de version dans un dépôt public
* Diffuser en direct ou partager votre écran avec votre code affiché

Utilisez l&#39;outil Secrets pour partager votre code en toute confiance, sans craindre d&#39;exposer vos identifiants.

<div id="funcionalidades">
  ## Fonctionnalités
</div>

L&#39;outil Secrets offre les fonctionnalités suivantes :

* **Chiffrement de bout en bout** : protégez automatiquement vos données grâce au chiffrement AES-256 au repos et au chiffrement TLS en transit
* **Secrets au niveau de l&#39;app** : stockez et gérez les secrets propres à une Replit App
* **Secrets au niveau du compte** : stockez et gérez des secrets accessibles depuis toutes vos Replit Apps
* **Accès par variables d&#39;environnement** : accédez à vos secrets dans le code à l&#39;aide de variables d&#39;environnement
* **Accès collaboratif** : partagez vos secrets avec vos collaborateurs et les membres de votre équipe

<div id="uso">
  ## Utilisation
</div>

<Note>
  Les Secrets sont disponibles pour tous les types de déploiement, à l&#39;exception des déploiements statiques.
</Note>

Vous pouvez accéder à l&#39;outil Secrets depuis le Project Editor.

<Accordion title="Comment accéder aux Secrets">
  Dans la **barre latérale des outils**, à gauche :

  1. Sélectionnez <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Icône Tous les outils" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools** pour afficher la liste des outils du Project Editor.
  2. Sélectionnez <img class="icon-svg" src="/assets/mirror/lock-af402c9618dd.svg" alt="Icône Secrets" width="16" height="16" data-path="images/icons/lock.svg" /> **Secrets**.

  Dans la **barre de recherche** :

  1. Sélectionnez la <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="icône de loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> loupe située en haut pour ouvrir l&#39;outil de recherche.
  2. Saisissez « Secrets » pour trouver l&#39;outil, puis sélectionnez-le dans les résultats.
</Accordion>

<div id="gerenciar-secrets-do-app">
  ### Gérer les Secrets de l&#39;App
</div>

Vous pouvez gérer les secrets au niveau de l&#39;app dans l&#39;onglet **App Secrets** du panneau **Secrets**.
Cet onglet affiche la liste de tous les secrets associés à votre Replit App.

<Accordion title="Ajouter des Secrets de l'App">
  Pour ajouter un secret :

  1. Sélectionnez **New Secret**.
  2. Saisissez une **Key**, le nom du secret, et une **Value**, le secret lui-même.
  3. Sélectionnez **Add Secret** pour enregistrer l&#39;entrée.
</Accordion>

<Accordion title="Modifier les Secrets de l'App">
  Pour modifier un secret :

  1. Sélectionnez le menu <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="icône à trois points verticaux" height="16" width="16" data-path="images/icons/vertical-dots.svg" /> à trois points verticaux situé à côté du secret.
  2. Sélectionnez **Edit** dans le menu contextuel.
  3. Modifiez le texte du champ **Key** ou **Value**, puis sélectionnez **Update Secret** pour enregistrer les modifications ou **Cancel** pour les annuler.

  Vous pouvez également modifier l&#39;ensemble de la liste des Secrets de l&#39;App en sélectionnant **Edit as JSON** ou **Edit as .env** au bas de l&#39;onglet.
</Accordion>

<Accordion title="Afficher les Secrets de l'App">
  Pour afficher un secret, sélectionnez l&#39;icône <img class="icon-svg" src="/assets/mirror/eye-8a6472b8a950.svg" alt="icône en forme d'œil" width="16" height="16" data-path="images/icons/eye.svg" /> en forme d&#39;œil située à côté du secret.

  Pour masquer le secret, sélectionnez l&#39;icône <img class="icon-svg" src="/assets/mirror/eye-slash-6b4ded538179.svg" alt="icône en forme d'œil barré" width="16" height="16" data-path="images/icons/eye-slash.svg" /> en forme d&#39;œil barré.
</Accordion>

<Accordion title="Supprimer les Secrets de l'App">
  Pour supprimer un secret, sélectionnez le menu <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="icône à trois points verticaux" height="16" width="16" data-path="images/icons/vertical-dots.svg" /> à trois points verticaux situé à côté du secret, puis sélectionnez **Delete**.
</Accordion>

<div id="gerenciar-secrets-da-conta">
  ### Gérer les Secrets du compte
</div>

Vous pouvez gérer les secrets au niveau du compte dans l&#39;onglet **Account Secrets** du panneau **Secrets**.
Cet onglet affiche uniquement la liste des secrets associés à votre compte Replit.

<Accordion title="Ajouter des Secrets du compte">
  Pour ajouter un secret au niveau du compte :

  1. Accédez à l&#39;onglet **Account Secrets**.
  2. Sélectionnez l&#39;icône <img class="icon-svg" src="/assets/mirror/settings-icon-c2664c3691bf.svg" alt="icône d'engrenage" width="16" height="16" data-path="images/icons/settings-icon.svg" /> pour ouvrir les **Settings** et gérer les secrets au niveau du compte.
  3. Sélectionnez **New Secret** pour ajouter un secret.
  4. Saisissez une **Key**, le nom du secret, et une **Value**, le secret lui-même.
  5. Sélectionnez **Save** pour enregistrer l&#39;entrée.
</Accordion>

<Accordion title="Modifier des Secrets du compte">
  Pour modifier un secret :

  1. Sélectionnez l&#39;icône <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="icône de crayon" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> en forme de crayon à côté du secret.
  2. Modifiez le texte du champ **Key** ou **Value**, puis sélectionnez **Save** pour enregistrer les modifications ou **Cancel** pour les annuler.
</Accordion>

<Accordion title="Afficher les Secrets du compte">
  Pour afficher un secret, sélectionnez l&#39;icône <img class="icon-svg" src="/assets/mirror/eye-8a6472b8a950.svg" alt="icône d'œil" width="16" height="16" data-path="images/icons/eye.svg" /> en forme d&#39;œil à côté du secret.

  Pour masquer le secret, sélectionnez l&#39;icône <img class="icon-svg" src="/assets/mirror/eye-slash-6b4ded538179.svg" alt="icône d'œil barré" width="16" height="16" data-path="images/icons/eye-slash.svg" /> en forme d&#39;œil barré.
</Accordion>

<Accordion title="Associer des Secrets du compte">
  Pour utiliser un secret au niveau du compte dans une Replit App, vous devez l&#39;associer à l&#39;app.
  Pour associer un secret au niveau du compte :

  1. Accédez à l&#39;onglet **App Secrets**.
  2. Cochez la case à gauche du secret.
  3. Sélectionnez **Link to this App**.

  Pour dissocier un secret :

  1. Accédez à l&#39;onglet **App Secrets**.
  2. Sélectionnez le menu <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" width="16" height="16" alt="icône à trois points verticaux" data-path="images/icons/vertical-dots.svg" /> à trois points verticaux à côté du secret.
  3. Sélectionnez **Unlink**.
</Accordion>

<Accordion title="Supprimer des Secrets du compte">
  1. Sélectionnez l&#39;icône <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="icône de crayon" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> en forme de crayon à côté du secret.
  2. Sélectionnez **Delete**.
</Accordion>

<div id="gerenciar-a-visibilidade-dos-secrets">
  ### Gérer la visibilité des secrets
</div>

La visibilité des secrets dépend de votre niveau d&#39;accès à une Replit App et du fait que vous en soyez l&#39;auteur ou non.

Vous pouvez utiliser l&#39;une des options suivantes pour partager votre Replit App :

* **Multiplayer** : invitez des utilisateurs Replit à collaborer en temps réel
* **Cover page** : affichez un aperçu de votre Replit App avec la possibilité de la remixer
* **Remix** : rendez votre Replit App individuelle ou d&#39;organisation publique afin que d&#39;autres personnes puissent en créer leur propre version

Le tableau suivant indique la visibilité du nom et de la valeur des secrets selon les différents scénarios :

| Méthode d&#39;accès | Qui                                                       | Peut voir les noms | Peut voir les valeurs |
| ------------------- | --------------------------------------------------------- | ------------------ | --------------------- |
| Multiplayer         | Collaborateur Multiplayer                                 | ✓                  | ✓                     |
| Multiplayer         | Membre de l&#39;organisation (rôle de Propriétaire)       | ✓                  | ✓                     |
| Multiplayer         | Membre de l&#39;organisation (sans rôle de Propriétaire)  | ✓                  |                       |
| Cover Page          | Tout visiteur                                             |                    |                       |
| Remix               | Propriétaire/collaborateur remixant sa propre Replit App  | ✓                  | ✓                     |
| Remix               | Non-propriétaire/collaborateur remixant une Replit App    | ✓                  |                       |
| Remix               | Toute personne remixant depuis la cover page              | ✓                  |                       |
| Organization Remix  | Membre de l&#39;organisation avec le rôle de Propriétaire | ✓                  | ✓                     |
| Organization Remix  | Membre de l&#39;organisation sans le rôle de Propriétaire | ✓                  |                       |

<Warning>
  Les membres de l&#39;organisation qui n&#39;ont pas le rôle de Propriétaire ne peuvent pas consulter les valeurs des secrets d&#39;une Replit App, mais ils peuvent y accéder en affichant les variables d&#39;environnement.
</Warning>

<div id="secrets-relacionados-ao-banco-de-dados">
  ## Secrets liés à la base de données
</div>

Lorsque vous ajoutez la base de données Replit, le Project Editor crée automatiquement le secret suivant :

| Secret         | Description                                  |
| -------------- | -------------------------------------------- |
| `DATABASE_URL` | Chaîne de connexion à la base de données SQL |

<Info>
  Les anciennes bases de données de développement Neon peuvent également inclure `PGHOST`, `PGUSER`, `PGPASSWORD`, `PGDATABASE` et `PGPORT`. Les bases de données de développement actuelles de Replit utilisent `DATABASE_URL` à la place.
</Info>

Pour afficher toutes les variables d&#39;environnement de votre Replit App, exécutez `printenv` dans l&#39;outil Shell du Project Editor ou affichez-les depuis votre code.

<div id="variveis-de-ambiente-predefinidas">
  ## Variables d&#39;environnement prédéfinies
</div>

Replit définit automatiquement les variables d&#39;environnement suivantes, auxquelles vous pouvez accéder dans votre app :

| Variable d&#39;environnement | Description                                                                                       |
| ---------------------------- | ------------------------------------------------------------------------------------------------- |
| `REPLIT_DOMAINS`             | Liste, séparée par des virgules, de tous les domaines associés à votre Replit App                 |
| `REPLIT_USER`                | Nom d&#39;utilisateur de l&#39;éditeur actuel, qui peut varier lors des sessions Multiplayer      |
| `REPLIT_DEPLOYMENT`          | Définie sur `1` si le code s&#39;exécute dans une app publiée ; non définie dans le cas contraire |
| `REPLIT_DEV_DOMAIN`          | URL de développement sur le domaine `replit.dev`, différente de l&#39;URL de déploiement          |

Ces variables n&#39;apparaissent pas dans l&#39;outil Secrets, mais vous pouvez y accéder dans votre code via l&#39;objet `os.environ` ou en exécutant `printenv` dans le Shell.
