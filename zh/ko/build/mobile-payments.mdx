<div id="revenuecat">
  ## 什么是 RevenueCat
</div>

在 PixelGames 中，Snake、Racer 和 Pinball 均显示为“即将上线”。借助 RevenueCat，你可以在应用中销售用于解锁这些内容的订阅，无需直接接入 Apple 和 Google 的购买系统。只需让 Agent 添加订阅并连接 RevenueCat，其余工作都由 Agent 完成。

<Warning>
  Apple 和 Google 都要求此类数字内容使用各自的应用内购买系统，且都会从销售收入中抽取一部分作为佣金。你无法通过外部支付链接绕过这一要求。
</Warning>

<div id="section">
  ## 开始前准备
</div>

* 已配置为移动应用的 Replit 项目。
* RevenueCat 账户。只需电子邮箱和密码，无需银行账户。

<div id="section-3">
  ## 测试订阅
</div>

Replit 预览使用 RevenueCat 的测试模式。在 Expo Go 中测试购买时，会显示测试购买对话框，不会产生实际费用。Apple 批准你的 App 在 App Store 上架后，实际购买将使用真实货币，因此请在提交前再次确认价格。

<Frame caption="PixelGames 的付费墙，以及 Expo Go 中显示的测试购买对话框。">
  <img src="/assets/mirror/paywall-7b66dd10c595.png" alt="PixelGames 付费墙界面旁的 RevenueCat 测试购买对话框" data-path="images/pixelgames/mobile/paywall.png" width="2274" height="1470" data-path="images/pixelgames/mobile/paywall.png" />
</Frame>

上述测试购买对话框并不是玩家实际会看到的内容。Expo Go 是用于预览所有 Expo 项目的公共 App，因此无法识别你的 App 实际使用的 RevenueCat 身份，只会显示通用的测试流程。拥有正式构建版本或 App 发布后，付费墙将是由 RevenueCat 远程提供的专属页面，而非硬编码在 App 中。

<div id="app-store-connect">
  ## 同步至 App Store Connect
</div>

同步后，您可以直接在 RevenueCat 或 Replit Agent 中创建或修改应用内订阅和产品。

连接 App Store Connect 前，您需要完成以下三项准备：

* **注册**：如果尚未注册，请加入 Apple Developer Program。该计划需缴纳年费。
* **提交**：如果尚未提交，请将您的应用提交至 App Store。请参阅[上传应用](/zh/build/mobile-upload-ios)。
  RevenueCat 需要应用记录才能同步产品。
* **连接**：关联您的银行账户，并**签署** Apple 的 Paid Apps Agreement。这两项操作均可在 App
  Store Connect 中完成。否则，Apple 将无法处理付款。

<Steps>
  <Step title="开始在 Replit 中同步">
    在 Replit 中打开 **Publishing → Manage**，然后选择 **Sync RevenueCat to App Store Connect**。应用提交到 TestFlight 后，此按钮才会显示。

    <Frame caption="在 Replit 的 Publishing 面板中开始同步。">
      <img src="/assets/mirror/rev-co-step1-e86c72c18850.png" alt="Replit 的 Publishing 面板，Manage 选项卡已打开，并显示 Sync RevenueCat to App Store Connect 按钮" data-path="images/pixelgames/mobile/rev-co-step1-e86c72c18850.png" width="997" height="420" data-path="images/pixelgames/mobile/rev-co-step1.png" />
    </Frame>
  </Step>

  <Step title="打开 App Store Connect API 页面">
    前往 App Store Connect 中的 **Users and Access → Integrations → App Store Connect API**
    ([直接打开](https://appstoreconnect.apple.com/access/integrations/api)) ，
    然后选择 **+** 以添加新密钥。

    <Frame caption="前往 App Store Connect API 密钥页面。">
      <img src="/assets/mirror/rev-co-step2-642a879843a1.png" alt="App Store Connect 的 Users and Access 页面、Integrations 选项卡和 App Store Connect API 部分" data-path="images/pixelgames/mobile/rev-co-step2.png" width="1466" height="657" data-path="images/pixelgames/mobile/rev-co-step2.png" />
    </Frame>
  </Step>

  <Step title="创建密钥">
    指定名称 (例如 &quot;RevenueCat&quot;) ，将 **Access** 设为 **App Manager**，然后选择 **Generate**。

    <Frame caption="为 RevenueCat 创建 App Store Connect API 密钥。">
      <img src="/assets/mirror/rev-co-step3-dcfbd73aafd8.png" alt="Generate API Key 对话框，其中已填写名称并选择了 App Manager 访问权限" data-path="images/pixelgames/mobile/rev-co-step3.png" width="1453" height="436" data-path="images/pixelgames/mobile/rev-co-step3.png" />
    </Frame>
  </Step>

  <Step title="复制密钥详情">
    复制 **Key ID**，然后下载密钥文件。

    <Frame caption="复制 Key ID 并下载 App Store Connect API 密钥。">
      <img src="/assets/mirror/rev-co-step4-24337a1cd6db.png" alt="App Store Connect API 密钥列表，显示新的 RevenueCat 密钥以及复制和下载操作" data-path="images/pixelgames/mobile/rev-co-step4.png" width="1522" height="695" data-path="images/pixelgames/mobile/rev-co-step4.png" />
    </Frame>
  </Step>

  <Step title="添加到 Replit">
    返回 Replit 的同步模态窗口 (第 1 步，共 2 步) ，上传密钥文件，粘贴 **Key ID** 和 **Issuer
    ID**，然后选择 **Continue**。

    <Frame caption="在 Replit 中输入 App Store Connect API 密钥。">
      <img src="/assets/mirror/rev-co-step5-73640bd1925f.png" alt="Replit 模态窗口的第 1 步（共 2 步）：上传 App Store Connect API 密钥并粘贴详细信息" data-path="images/pixelgames/mobile/rev-co-step5.png" width="995" height="591" data-path="images/pixelgames/mobile/rev-co-step5.png" />
    </Frame>
  </Step>

  <Step title="对 In-App Purchase 密钥执行相同操作">
    在 App Store Connect 的同一位置，这次打开 **In-App Purchase** 标签页
    ([直接打开](https://appstoreconnect.apple.com/access/integrations/api/subs)) ，
    创建另一个密钥并复制其详细信息。

    <Frame caption="创建并复制 In-App Purchase API 密钥。">
      <img src="/assets/mirror/rev-co-step6-aed01868e734.png" alt="App Store Connect 中的 In-App Purchase 密钥列表，显示 Download 和 Copy 操作" data-path="images/pixelgames/mobile/rev-co-step6.png" width="1547" height="593" data-path="images/pixelgames/mobile/rev-co-step6.png" />
    </Frame>
  </Step>

  <Step title="添加到 Replit">
    返回 Replit 的同步对话框 (第 2 步，共 2 步) ，上传此密钥文件并粘贴 **Key ID** 和 **Issuer
    ID**，然后选择 **Continue**。

    <Frame caption="在 Replit 中输入 In-App Purchase API 密钥。">
      <img src="/assets/mirror/rev-co-step7-26d78bff7cc4.png" alt="Replit 对话框的第 2 步（共 2 步），用于上传 In-App Purchase API 密钥并粘贴详细信息" data-path="images/pixelgames/mobile/rev-co-step7.png" width="997" height="591" data-path="images/pixelgames/mobile/rev-co-step7.png" />
    </Frame>
  </Step>

  <Step title="确认并同步">
    同步完成后，您随时可以在 Replit 的 **Publishing → Manage** 面板中手动调整产品价格。

    <Frame caption="同步到 App Store Connect 前检查产品。">
      <img src="/assets/mirror/rev-co-step8-a790ee2b52ee.png" alt="Replit 的“待同步产品”页面，显示已准备好同步的高级月度订阅" data-path="images/pixelgames/mobile/rev-co-step8.png" width="996" height="550" data-path="images/pixelgames/mobile/rev-co-step8.png" />
    </Frame>
  </Step>
</Steps>

<div id="section-5">
  ## 问题排查
</div>

* **购买成功但未解锁任何内容：**请确认 RevenueCat 中的权益已正确映射到相应的
  产品 ID。
* **测试时可用，但发布后无法使用：**请确认产品已同步至 App Store Connect，
  并已签署 Apple 的 Paid Apps Agreement。

<div id="section-6">
  ## 常见问题
</div>

<AccordionGroup>
  <Accordion title="使用 RevenueCat 是否需要银行账户？">
    不需要。创建账户只需电子邮件和密码。准备收款时，再通过 Apple 或 Google 单独关联银行账户。
  </Accordion>

  <Accordion title="测试购买会收费吗？">
    不会。Replit 预览使用 RevenueCat 的测试模式，购买均为模拟操作。
    只有在 Apple 批准应用上架 App Store 后，才会开始实际收费。
  </Accordion>

  <Accordion title="可以使用 RevenueCat 配置哪些内容？">
    您可以配置价格、权益和付费墙本身。只需让 Agent 进行更改，RevenueCat
    配置和应用代码都会一并更新。
  </Accordion>
</AccordionGroup>
