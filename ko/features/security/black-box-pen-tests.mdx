black-box 침투 테스트는 브라우저 및 네트워크 상호작용을 통해 실행 중인 앱을 외부에서 검사합니다. 앱의 소스 코드는 사용하지 않습니다.

Project Security Center의 **Level 3(AI pentest)** 는 다음 세 가지 보안 검사를 한 번에 수행합니다.

1. 무료 dependency 및 package 검사
2. 소스 코드에 대한 Agent 정적 분석
3. 소스 코드 없이 외부에서 실행 중인 Preview를 점검하는 black-box test

Level 3을 시작하면 Replit은 Agent 소스 코드 검토와 외부 black-box test를 동시에 실행합니다.

<div id="run-a-level-3-scan">
  ## Level 3 스캔 실행
</div>

<Steps>
  <Step title="project 열기">
    스캔하려는 개별 project를 엽니다.
  </Step>

  <Step title="Security Center 열기">
    project의 **Tools** pane에서 **Security Center**를 선택합니다.
  </Step>

  <Step title="스캔 시작">
    Security Center 상단에서 **Run scan**을 선택합니다.
  </Step>

  <Step title="Level 3 선택">
    **Level 3 (AI pentest)**를 선택합니다.

    <Frame caption="Level 3(AI pentest)는 무료 dependency 및 package 검사에 더해 Agent 정적 분석과 외부 라이브 Preview 테스트를 제공합니다.">
      <img src="/assets/mirror/level-3-ai-pentest-c223c0099d3f.png" alt="Tools pane에서 연 Security and Privacy Center에서 스캔 수준 선택 메뉴가 펼쳐져 있고 Level 3 AI pentest가 선택된 화면" width="2204" height="1200" data-path="images/project-security-center/level-3-ai-pentest.png" />
    </Frame>
  </Step>

  <Step title="두 task 완료 대기">
    소스 코드 검토와 브라우저 및 네트워크 black-box test가 끝날 때까지 기다립니다.
  </Step>

  <Step title="결과 검토">
    **Security** pane에서 두 task의 findings를 검토합니다. 수용한 issues를 Agent에 보내기 전에 각 finding을 평가하세요.
  </Step>

  <Step title="수정 후 재실행">
    수용한 findings를 Agent에 보냅니다. 수정 사항을 적용한 후에는 Level 3 스캔을 다시 실행해 결과를 확인하세요.
  </Step>
</Steps>

<div id="understand-the-two-tasks">
  ## 두 가지 task 이해하기
</div>

| Task               | 활용하는 근거                    | 목적                                       |
| ------------------ | -------------------------- | ---------------------------------------- |
| 소스 코드 검토           | 애플리케이션의 소스 코드              | codebase에 존재하는 보안, 개인정보, 아키텍처 취약점을 식별합니다 |
| Black-box pen test | 실행 중인 앱과의 브라우저 및 네트워크 상호작용 | 소스 코드 없이 외부에서 관찰 가능한 동작을 검사합니다           |

두 가지 findings를 모두 검토하세요. 한 task가 다른 task를 대체하지는 않습니다. 소스 코드 검토는 취약한 구현 세부 사항까지 찾아낼 수 있고, black-box test는 실행 중인 앱을 외부 관점에서 평가합니다.
