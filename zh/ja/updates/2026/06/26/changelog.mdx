<div id="section-3">
  ### 全新集成体验
</div>

现在，您可以在一个地方查看 Replit 连接的所有服务。焕新的集成页面将连接器、MCP 服务器和 Git 提供商以可点击卡片的形式集中展示，并新增了类别筛选器，以及标示 Replit 可自动连接的集成的徽章。目录中收录了 450 多个集成，每个集成都有专属页面和示例用例。您可在 [replit.com/integrations](https://replit.com/integrations) 预览完整目录。

<div id="slackreplit">
  ### 在 Slack 中使用 Replit
</div>

Replit 已成为 Slack Slackbot MCP 客户端的首发合作伙伴。让 Slackbot 使用 Replit 构建应用，即可直接在 Slack 中创建、更新和查看 Replit 应用。你可以继续对话，Replit Agent 会持续推进工作。

  <img src="/assets/mirror/allow-replit-app-access-slack-d236d2698281.png" alt="Slack 授权页面，标题为“允许 Replit 应用访问 Slack”。页面显示 Slack 已验证标记、工作区选择（设置为 Replit）、Replit 应用可查看的信息和可执行的操作，以及“取消”和“允许”按钮。" width="1816" height="1358" data-path="images/changelog/2026-06-26/allow-replit-app-access-slack.png" />

<div id="section-4">
  ## 团队与企业版
</div>

<div id="scim">
  ### 面向 SCIM 客户的多工作区支持
</div>

通过 SCIM 预配成员的企业版客户现在可以创建多个工作区。您可以将已同步的群组分配到不同工作区，更清晰地划分访问边界、管理预算并隔离团队，同时仍将身份提供方作为信任源。此功能现已向新的企业版客户开放注册。

有关详细信息，请参阅 [SCIM 工作区访问](/zh/ja/teams/identity-and-access-management/scim#managing-workspace-access)。
