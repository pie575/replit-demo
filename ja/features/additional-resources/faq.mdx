      <Accordion title="コードレベルのヘルプはどこで得られますか？">
        コードに関するヘルプを得るには、[Replit AI](/ja/build/welcome/)を使うのが最適です。プロジェクトエディターで新しいタブを開き、**AI**を検索してください。Replit AIは新しいプロジェクトの設定、コードに関する質問への回答、思考の補助を行うことができます。さらなるサポートが必要な場合は、[コミュニティハブ](https://replit.com/community)で追加のリソースを確認することもできます。
      </Accordion>

      <Accordion title="Replitの使い方でトラブルが発生しています。どうすれば助けを得られますか？">
        Replitにサインインし、ページ右上の\*\*?\*\*を使用してヘルプを受けてください。追加サポートについては、[サポートポリシードキュメント](/ja/legal-and-security-info/support-policy)をご参照ください。
      </Accordion>

      <Accordion title="請求に関するヘルプはどこで得られますか？">
        サポートチームに連絡する前に、**設定**の下にある解決策が見つからないか確認してください。それでも解決しない場合は、サインインしてページ右上の\*\*?\*\*を使用してヘルプを受けてください。
      </Accordion>

      <Accordion title="Replitアカウントにアクセスできない場合はどうすればいいですか？">
        `support@replit.com`にメールを送り、アカウントのユーザー名とサインインIDを記載してください。
      </Accordion>

      <Accordion title="Replitからの返答はいつ届きますか？">
        Replitのサポートは通常、東部標準時（UTC-5）の月曜日から金曜日の午前9時から午後8時まで対応しています。
      </Accordion>

      <Accordion title="Replitアプリのフォルダを復元するにはどうすればいいですか？">
        Replitアプリの右上隅にあるプロフィールアイコンに移動し、**CLUI**を選択してください。表示される検索ボックスで「*restore*」と入力して検索します。検索結果に、ゴミ箱から特定のフォルダを復元するための**restore-folder**オプションが表示されます。

        > 注意：削除されたReplitアプリは、元の削除日から**30日後**に完全に削除され、復元できなくなります。
      </Accordion>

      <Accordion title="削除したReplitアプリを復元するにはどうすればいいですか？">
        Replitアプリの右上隅にあるプロフィールアイコンに移動し、**CLUI**を選択してください。表示される検索ボックスで「*restore*」と入力して検索します。検索結果に、ゴミ箱から特定のReplitアプリを復元するための**restore-repl**オプションが表示されます。

        > 注意：削除されたReplitアプリは、元の削除日から**30日後**に完全に削除され、復元できなくなります。
      </Accordion>

      <Accordion title="Replitアプリが読み込めない場合はどうすればいいですか？">
        Replitアプリが読み込めない場合は、次のデバッグ手順を試してください：

        1. [インターネット接続](https://www.speedtest.net/)をテストしてください。
        2. 別のブラウザを試してください。
        3. ブラウザでJavaScriptが有効になっているか確認してください。
        4. コマンドパレットをMacでは`Cmd+K`、Windowsでは`Ctrl+K`で開き、**Restart compute**を検索して選択してください。

        上記の手順が役に立たない場合は、Replitの[サービスステータス](https://status.replit.com)を確認してください。ステータスが\*\*All systems are go!\*\*と表示されているにもかかわらず、Replitアプリの読み込みに問題がある場合は、[Replitサポート](https://replit.com/support)にご連絡ください。
      </Accordion>

      <Accordion title="Replitアプリに大きなファイルをアップロードするにはどうすればいいですか？">
        ファイルが通常のGUIアップロードには大きすぎる場合は、`scp`（Secure Copy）を使用して[SSH](/ja/features/workspace-tools/ssh)経由でローカルシステムとリモートシステム間でファイルを安全に転送できます。ローカルマシンからリモートマシンにファイルをコピーするには、次の構文を使用してください：`scp filename username@ip_address:/home/username`

        scpを使用してディレクトリ全体をコピーすることもできます。
      </Accordion>

      <Accordion title="使用クレジット残高を確認するにはどうすればいいですか？">
        現在の残高は[https://replit.com/\~/cli/account/usage-credits-balance](https://replit.com/~/cli/account/usage-credits-balance)で確認できます。
      </Accordion>

      <Accordion title="ログインに問題があります。どうすればいいですか？">
        1. 正しいメールアドレスとパスワードを使用していることを確認してください。
        2. パスワードをリセットするには、[パスワードを忘れた場合のページ](https://replit.com/forgot)にアクセスしてください。`notifications@replit.com`からのリセットメールがスパムフォルダに届いていないか必ず確認してください。
        3. 別のブラウザからログインを試みてください。

        上記の手順がすべて失敗した場合は、[サポートに連絡](https://replit.com/support)してください。
      </Accordion>

      <Accordion title="Google/GitHub/Facebook/Appleでサインアップした場合のメールアドレスの変更方法は？">
        アカウントのメールアドレスを変更するにはパスワードが必要です。GoogleやGitHubなどのサードパーティ認証プロバイダーでサインアップした場合は、まずパスワードを作成する必要があります。

        パスワードを作成するには：

        1. サイドバーを開いてログアウトします。
        2. ログインページに戻り、[パスワードを忘れた場合](https://replit.com/forgot)を選択して、メールアドレスを入力します。
        3. 新しいパスワードを作成するためのリンクが記載されたメールが届きます。メールが見当たらない場合は、スパムフォルダを確認し、メールが送信されるまで最大30分お待ちください。
        4. ログイン後、[設定](https://replit.com/settings)を開いてメールアドレスを変更します。
      </Accordion>

      <Accordion title="ユーザー名を変更するにはどうすればいいですか？">
        Replitユーザーはユーザー名を**1回**のみ変更できます。[CLUI](https://replit.com/~/cli/account/change-username?run=1)に移動し、**change-username**を選択してください。このオプションが利用できない場合は、すでに変更済みです。
      </Accordion>

      <Accordion title="Explorerモードとは何ですか？また、どのように有効化できますか？">
        ExplorerはReplitのユーザーのうち、まだ開発中の新機能を表示してテストすることを選択した方々です。Explorerモードを有効にするには、[設定](https://replit.com/settings)を開き、Explorerスイッチを切り替えてください（例：**アカウント**または**ユーザー**の下）。
      </Accordion>
