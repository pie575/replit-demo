## Importer depuis GitHub

⏰ *Durée estimée : deux minutes*

Importez un dépôt GitHub dans Replit pour exécuter, tester et publier plus rapidement.

Pour des options d'import complètes incluant d'autres plateformes comme Figma, Bolt et Lovable, consultez la [documentation de la fonctionnalité d'import](/fr/core-concepts/project-editor/app-setup/import).

## Avant de commencer

* L'URL d'un dépôt GitHub
* Accès au dépôt (public ou privé)
* Un compte Replit

## Option 1 : import rapide

L'import rapide fonctionne pour les dépôts publics.

1. Copiez le chemin du dépôt après `github.com/`.
2. Ouvrez `https://replit.com/github.com/<propriétaire>/<dépôt>`.
3. Appuyez sur Entrée pour démarrer l'import.

**Exemple**

* URL GitHub : `https://github.com/exampleUser/my-app`
* URL d'import Replit : `https://replit.com/github.com/exampleUser/my-app`

## Option 2 : import guidé

L'import guidé prend en charge les dépôts publics et privés.

1. Ouvrez [replit.com/import](https://replit.com/import).
2. Sélectionnez **GitHub**.
3. Connectez votre compte GitHub.
4. Choisissez un dépôt.
5. Sélectionnez **Import**.

## Ce qui est importé

* Les fichiers et dossiers du dépôt
* Les fichiers de dépendances
* La configuration d'exécution et de build courante

## Ce qui n'est pas importé

* Les valeurs des secrets existants et des variables d'environnement
* Les services spécifiques à la plateforme qui ne s'exécutent pas dans Replit par défaut
