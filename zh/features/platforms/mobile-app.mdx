[Replit 移动应用](https://replit.com/mobile)把你的项目装进口袋：无论身在何处，都能接着上次的进度继续，或者从零开始做点新东西。与 Agent 对话、编辑项目、发布上线，界面专为触控操作优化。

<div id="getting-started">
  ## 快速开始
</div>

按照以下步骤安装应用并创建项目。

<div id="install-the-app">
  ### 安装应用
</div>

1. 前往[移动应用下载页面](https://replit.com/mobile)，安装适用于你移动设备操作系统的应用。
2. 打开应用，注册新账户或使用已有账户登录。
   如果注册新账户，你需要验证电子邮件地址才能完成注册。

<div id="start-building">
  ### 开始构建
</div>

主屏幕提供两种方式：

* **从上次的进度继续**：在 **Recent Projects** 中打开一个项目，接着往下做。
* **从零开始构建**：在提示框中描述你想要的内容并发送，Agent 会立即开始构建你的项目。

如果想改用预置模板或现有代码作为起点，请点按右上角的 ⋮，然后选择 **Remix a Template** 或 **Import from GitHub**。

<Note>
  要构建原生 iOS 应用？请在 [replit.com](https://replit.com) 上使用 Project Editor 进行创建、预览、构建或提交。在支持的情况下，Replit Android 应用中也可以进行原生移动应用开发。
</Note>

<div id="mobile-features">
  ## 移动端功能
</div>

<div id="voice-input">
  ### 语音输入
</div>

使用 Agent 提示框中的语音选项，无需动手即可说出你想构建或修改的内容。

<div id="live-activities">
  ### 实时活动
</div>

随时随地掌握 Agent 的工作进展。Agent 启动后，你会收到一条通知：在锁屏界面点按**允许**，无需打开 Replit 即可查看进度。

<Accordion title="支持的设备">
  * 运行 iOS 18 或更高版本的 iPhone
  * 运行 iOS 18 或更高版本的 iPad
  * 运行 macOS Tahoe 或更高版本的 Mac
  * 已配对的 Apple Watch
</Accordion>

<div id="notifications">
  ### 通知
</div>

无论身在何处，都能及时收到重要更新。进入 **Settings**，打开 **Notifications** (通常位于 **User** 下) 。确保 Notifications 已开启；如果出现系统提示，请点击允许。

出现以下情况时，Replit 会通知你：

* Agent 需要你的协助
* Agent 已完成工作
* 有重要的账单更新

<div id="tablet-keyboard-mode">
  ### 平板键盘模式
</div>

为平板连接键盘，即可获得针对大屏幕优化的创作体验。连接键盘后首次打开 Project Editor 时，系统会询问你是否启用该模式。

你可以随时前往 **Account** &gt; **Keyboard Settings** 开启或关闭该模式。

<div id="upgrade-and-billing">
  ## 升级与账单
</div>

要在应用中升级到 Core，请前往 **Account**，点按 **Upgrade**，选择所需方案，然后点按 **Continue with Core**。Pro 无法在移动应用中购买，只能在 [replit.com](https://replit.com) 上购买。

如需在订阅所含额度之外继续使用 Agent，请添加付款方式以启用[按用量计费](/zh/billing/about-usage-based-billing)：

* **网页端**：前往 replit.com，依次打开 **Settings** → **Account** → **Billing**。
* **应用内 (仅限美国的 iOS)&#x20;**：打开 **Settings** → **Billing** (或 **Account** → **Billing**) 。
