</div>

  ### Shell 中的 AI 命令
</div>

<Frame>
  <img src="/assets/mirror/screenshot-2026-01-08-at-18-12-51_c5b98b748839-116ea37a8a93.png" alt="Shell 显示 replit ai 命令的输出" width="1244" height="412" data-path="images/changelog/2026-01-09/screenshot-2026-01-08-at-18-12-51_c5b98b748839.png" />

<div id="new-ai-models-in-integrations">
  ### 集成中的新 AI 模型
</div>

AI 集成现已支持新发布的 AI 模型：

| 模型                           | 描述                                                               |
| ---------------------------- | ---------------------------------------------------------------- |
| `gpt-5.2`                    | OpenAI 面向专业知识工作的最强模型。在 ARC-AGI-1 上率先突破 90%，并拥有 400K 上下文窗口。       |
| `claude-opus-4.5`            | Anthropic 的旗舰模型，专为编程、智能体和计算机操作优化。在 SWE-bench Verified 上达到 80.9%。 |
| `gemini-3-flash-preview`     | Google 面向智能体工作流的高速模型，支持 1M token 上下文。以更低的延迟和成本提供接近 Pro 级别的推理能力。  |
| `gemini-3-pro-preview`       | Google 的高级多模态模型，具备业界领先的推理能力和现实世界知识。                              |
| `gemini-3-pro-image-preview` | Google 的 Nano Banana Pro 模型，支持高质量图像生成和编辑，并能准确渲染文本。               |
