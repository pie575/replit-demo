---
title: "История файлов"
description: "Узнайте, как восстанавливать предыдущие версии кода с помощью автоматических точек сохранения в истории файлов."
---

Откройте текстовый файл в Project Editor и нажмите кнопку **History** в правом нижнем углу.

<Frame>
  <img src="/assets/mirror/history-button-afac6496660a.png" alt="открытие истории" width="377" height="292" data-path="images/programming-ide/history-button.png" />
</Frame>

<div id="visualizar-verses-anteriores-de-um-arquivo">
  ## Просмотр предыдущих версий файла
</div>

После открытия истории файла вы можете просматривать его предыдущие версии с помощью полосы прокрутки, кнопок со стрелками или клавиш со стрелками **влево** и **вправо**.

<Frame>
  <img src="/assets/mirror/history-versioning-1a055ecab411.gif" alt="демонстрация полосы прокрутки" width="764" height="720" data-path="images/animations/history-versioning.gif" />
</Frame>

<div id="comparar-verses-anteriores-com-o-arquivo-atual">
  ## Сравнение предыдущих версий с текущим файлом
</div>

Нажмите кнопку Compare Latest в левом нижнем углу панели «История файла», чтобы сравнить файл в выбранный момент с его последней версией прямо в редакторе.

<Frame>
  <img src="/assets/mirror/compare-history-46fb16debd3a.gif" alt="сравнение с последней версией" width="772" height="720" data-path="images/animations/compare-history.gif" />
</Frame>

<div id="restaurar-uma-verso-anterior-de-um-arquivo">
  ## Восстановление предыдущей версии файла
</div>

Чтобы восстановить предыдущую версию файла, просто нажмите кнопку `Restore`. Не волнуйтесь: история не будет удалена. При восстановлении предыдущая версия добавляется в историю файла как новая.

<Frame>
  <img src="/assets/mirror/restore-history-5f616d7f961a.webp" alt="изображение восстановления истории" width="720" height="495" data-path="images/animations/restore-history.webp" />
</Frame>

<div id="visualizar-a-reproduo-do-histrico-de-arquivo">
  ## Просмотр записи истории файла
</div>

Функция записи истории файла позволяет посмотреть, как файл менялся со временем, словно в фильме. Это может пригодиться для создания видео ваших сеансов программирования.

</Frame>
