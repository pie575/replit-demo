<div id="integrao-com-sendgrid">
  ### Intégration avec SendGrid
</div>

Vous pouvez désormais créer des intégrations d&#39;e-mail avec Agent. Vous pouvez ainsi envoyer des e-mails depuis vos nouveaux projets Agent via l&#39;API SendGrid.

<div id="suporte-mvel-para-visualizao-web">
  ### Prise en charge mobile de l&#39;aperçu web
</div>

Vous pouvez désormais adapter l&#39;aperçu web aux tailles d&#39;écran mobiles les plus courantes. Nous avons également ajouté un QR code dans le menu déroulant d&#39;URL et dans le panneau réseau, afin de faciliter les tests sur appareils mobiles.

Pour rappel : même pendant la création de votre projet, celui-ci reste accessible depuis Internet. Il vous suffit d&#39;ouvrir l&#39;URL de développement sur n&#39;importe quel appareil.

<div id="atualizao-de-formato-de-registro-dns">
  ### Mise à jour du format des enregistrements DNS
</div>

Nous avons modifié le formatage des enregistrements DNS des domaines personnalisés afin qu&#39;il respecte les standards du secteur.

La configuration des domaines personnalisés devrait ainsi être plus simple.

<div id="atualizao-de-deployment-flask">
  ### Mise à jour des deployments Flask
</div>

gunicorn est désormais le serveur web par défaut pour les deployments utilisant la stack Flask.

Les performances sont ainsi 40 fois supérieures à celles des précédents deployments Flask.

<div id="comandos-shell-inline-do-assistant">
