<div id="agent">
  ### Анимированный значок Agent
</div>

Значок Agent теперь анимируется во время работы, поэтому сразу видно, что Agent активно трудится. Это повышает воспринимаемую скорость и позволяет легче отследить действия Agent на этапе первоначального планирования — особенно в центральном макете чата, расположенном ближе к запросу.

<div id="agent-2">
  ### Выпадающий список инструментов Agent в процессе планирования
</div>

Теперь выпадающий список инструментов Agent доступен на этапе первоначального планирования и утверждения списка задач. Вы можете задать нужные параметры Agent, включая уровень автономности и другие настройки среды, ещё до начала сборки.

<div id="agent-3">
  ### Поддержка имён файлов через @ в Agent
</div>

Помимо команд `/`, Agent теперь поддерживает упоминание имён файлов через `@` — это делает работу с ним привычной для тех, кто пользуется популярными инструментами разработки. Эту возможность часто запрашивали Enterprise-клиенты и опытные пользователи, привыкшие к рабочим процессам в стиле Cursor.

<div id="section-3">
  ### Поддержка коннекторов при ремиксе
</div>

Раньше при ремиксе Replit App, использующего коннекторы, новый repl автоматически не получал прав на использование коннекторов, из-за чего интеграции переставали работать. Мы обновили процесс ремикса, чтобы коннекторы обрабатывались корректно:

* Теперь при ремиксе появляется предложение настроить необходимые коннекторы
* В процессе ремикса чётко указывается, какие интеграции нужно настроить
* После ремикса интеграции больше не ломаются

Подробнее об [интеграциях Agent](/ru/replitai/integrations) и [управлении коннекторами](/ru/ko/replitai/managing-connectors).

<div id="section-5">
  ### Панель аналитики для администраторов Enterprise
</div>

Администраторам Enterprise теперь доступна комплексная панель аналитики — одна из наиболее востребованных возможностей среди клиентов Enterprise, включая Meta и Atlassian. Что умеет панель:

* **Мониторинг активности пользователей**: отслеживание вовлечённости и совместной работы в масштабах всей организации
* **Отслеживание использования ресурсов**: мониторинг расходов по пользователям и Replit App
* **Состояние деплоев**: наблюдение за активностью деплоев
* **Управление затратами**: прозрачность потребления ресурсов и расходов
