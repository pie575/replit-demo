从 HubSpot 获取本周的销售管道，与上周对比，并撰写一份
简短报告：新增交易、阶段变动、延期交易和预测。将表格放到
Google Sheets，并将要点发布到 Slack，让站会聚焦于变化，而非静态
快照。

<div id="best-for">
  ## 最适合
</div>

* 需要在周一站会上了解最新动态，而非查看静态快照的销售经理。
* 需要在一处查看销售管道周环比变化的营收运营负责人。

<div id="before-you-start">
  ## 开始前
</div>

连接 HubSpot、Sheets 和 Slack，并说明要纳入的销售管道或团队。

<div id="prompt-the-agent">
  ## 向 Agent 发送提示
</div>

<AiPrompt>
  创建一个每周一 9:00 运行的 Routine。从 HubSpot 获取本周的销售管道数据。
  编写一份周报，展示销售管道的变化和趋势：新增交易、阶段变动、延期交易，
  以及预测与上周的对比。将表格添加到 Google Sheets，并将要点发布到 Slack。
</AiPrompt>

<div id="what-to-expect">
  ## 预期结果
</div>

Agent 会比较本周与上周的数据，并生成一段简短说明和一份表格。请在 HubSpot 中核对几笔交易的金额。可在站会上使用 Slack 摘要；保留该表格作为审计记录。选择一笔新增交易和一笔延期交易，在 HubSpot 中打开它们，并确认其阶段、金额和成交日期与表格一致。

<div id="make-it-work-for-you">
  ## 让它为你所用
</div>

<AiPrompt>
  标出金额超过 $[金额] 且 14 天未更新的交易。
</AiPrompt>

<AiPrompt>
  根据成交日期和最后活动时间添加“有风险”部分。
</AiPrompt>

<div id="troubleshooting">
  ## 故障排除
</div>

* **交易金额与 HubSpot 不一致：**请说明要纳入哪个销售管道或团队，以及使用哪个金额字段 (金额还是加权预测) 。在信赖表格中的数据前，请先抽查几笔交易并与 HubSpot 核对。
* **延期交易似乎不正确：**请在 HubSpot 中确认成交日期和阶段。让 Agent 仅在成交日期推迟或阶段倒退时将交易视为延期。
* **Slack 发布到了错误的位置：**请指定频道，并说明您是只需要重点摘要，还是需要完整表格的链接。
