在 Agent 工作期间，后续消息既可以改变 Agent 当前正在执行的任务，即活动
**轮次 (turn) **，也可以等待该轮次结束：

* **Steer (引导) **会将消息发送至活动轮次，Agent 会一边继续工作，一边使用新的上下文。
* **Queue (队列) **会将消息留到下一轮次，Agent 会在活动轮次结束后再开始处理。

<div id="section">
  ## 引导对话
</div>

Steer 是 Conversation 和 Project 中后续消息的默认发送方式。
这两处偏好设置都可以改为 Queue。

<div id="replit">
  ## 选择 Replit 发送后续消息的方式
</div>

您可以为 Conversation 和 Project 分别设置不同的发送行为：

1. 打开 **Settings** &gt; **Personalization**。
2. 展开 **Agent**。
3. 将 **Conversation send behavior** 和 **Project send behavior** 设置为 **Steer** 或 **Queue**。

<Frame caption="Agent 部分中的 Conversation 和 Project 发送行为设置。">
  <img src="/assets/mirror/agent-follow-ups-settings-98a4c5ca399e.png" alt="显示带有 Steer 和 Queue 选项的 Conversation 与 Project 发送行为的 Agent 设置" width="3048" height="1372" data-path="images/replitai/agent-follow-ups-settings.png" />
</Frame>

<Info>
  Design 模式始终会引导后续消息。Conversation 和 Project 的发送行为设置
  对 Design 模式无效。
</Info>

若只想让某一条消息采用与偏好设置相反的行为，请按
`Cmd+Enter` (Mac) 或 `Ctrl+Enter` (Windows 和 Linux) 。

<div id="section-2">
  ## 处理排队的消息
</div>

将后续消息加入队列后，Message Queue 会以抽屉形式显示在聊天输入框上方。Agent 会在活动轮次结束后，按顺序处理队列中的消息。队列中的消息全部处理完毕后，抽屉会自动关闭。

包括 [Visual Editor](/zh/ko/design/visual-editor) 和文件附件在内的所有消息选项，都可以在 Queue 中使用。

<Info>
  只有在桌面端或移动端保持 Project Editor 会话处于连接状态时，Agent 才会自动处理排队的消息。
</Info>

<div id="section-3">
  ### 管理队列
</div>

队列抽屉打开时，你可以执行以下操作：

* **Steer now (立即引导)&#x20;**：将队列中的消息移入活动轮次。
* **Edit messages (编辑消息)&#x20;**：在 Agent 处理之前修改队列中的消息。
* **Delete messages (删除消息)&#x20;**：移除不再需要的消息。
* **Reorder messages (调整消息顺序)&#x20;**：拖动消息以更改处理顺序。
* **Add messages (添加消息)&#x20;**：向队列中继续发送后续消息。

<div id="section-4">
  ## 停止进行中的轮次
</div>

在状态栏中选择 **Stop**，即可中断 Replit 在当前轮次中正在执行的
任务。这样，你无需等待 Agent 完成本轮或处理完排队的消息，即可
发送新消息。
