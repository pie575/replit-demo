Replit 提供多种方式来安装和管理 Replit App 的软件包。你可以使用 [Shell](/zh/ko/features/workspace-tools/shell) 安装软件包，让 [Agent](/zh/ko/features/agent/overview/) 为你处理，或者让 Replit 在运行 Replit App 时自动检测并安装缺失的依赖项。

<div id="section">
  ## 使用 Shell 安装软件包
</div>

在项目编辑器中打开 **Shell** 工具，然后运行适用于所用编程语言的软件包管理器命令。

<CodeGroup>
  ```bash Node.js (npm) theme={null}
  npm install <package-name>
  ```

  ```bash Node.js (pnpm) theme={null}
  pnpm add <package-name>
  ```

  ```bash Python (poetry) theme={null}
  poetry add <package-name>
  ```

  ```bash Python (pip) theme={null}
  pip install <package-name>
  ```

  ```bash Ruby theme={null}
  bundle add <gem-name>
  ```
</CodeGroup>

你还可以使用 Replit 的[通用软件包管理器 (UPM)](https://github.com/replit/upm/) 在多种受支持的编程语言中安装软件包。

```bash theme={null}
upm add <package-name>
```

要安装特定版本，请运行以下命令。

```bash theme={null}
upm add 'flask==2.3.3'
```

有关所有受支持的语言和软件包管理器，请参阅 [UPM：支持的语言](https://github.com/replit/upm/#supported-languages)。

<div id="agent">
  ## 使用 Agent 安装软件包
</div>

你可以直接在聊天中请求 [Agent](/zh/ko/features/agent/overview/) 安装软件包。例如：

* “安装 axios 软件包”
* “将 Flask 和 SQLAlchemy 添加到我的项目中”
* “配置 TailwindCSS”

Agent 会使用适合你项目的软件包管理器安装软件包，并更新相关配置文件。

<div id="section-2">
  ## 自动导入检测
</div>

每次选择**运行**时，Replit 都会自动分析代码中缺失的依赖项。如果你导入了尚未安装的软件包，Replit 会检测到它并自动安装最新版本。

例如，在 `main.py` 中添加 `import flask` 后，下次选择**运行**时，**控制台**会显示正在安装 **Flask** 的消息。

<Note>
  你可以在 [.replit](/zh/ko/features/project-setup/configuration#replit-file) 文件中使用 `packager.features.guessImports` 设置配置自动导入检测。
</Note>

<div id="section-3">
  ### 覆盖自动检测
</div>

如果系统检测到了错误的软件包，或您需要特定版本，请在 Shell 中运行正确的安装命令。例如：

```bash theme={null}
upm add 'flask==2.3.3'
```

您还可以在 [.replit](/zh/ko/features/project-setup/configuration#replit-file) 文件中排除特定软件包或路径，使其不参与自动检测。

<div id="python">
  ## Python 软件包管理器
</div>

创建 Python Replit App 时，默认使用 **poetry** 作为软件包管理器。这意味着 `pip install` 无法管理依赖项。请改用 Shell 中的 `poetry add <package>` 或 `upm add <package>`。

<div id="poetry-pip">
  ### 从 poetry 切换到 pip
</div>

如果要使用 `pip`，请按以下步骤操作。

<Steps>
  <Step>
    打开 Shell 并运行以下命令。

    删除锁定文件，将打包基础设施切换为 pip。

    ```bash theme={null}
    rm poetry.lock
    ```
  </Step>

  <Step title="迁移依赖项">
    将 `pyproject.toml` 的 `[tool.poetry.dependencies]` 部分中的依赖项移至 `requirements.txt`。例如，`flask = "^3.0.2"` 应改为 `flask>=3.0.2,<4`。
  </Step>

  <Step title="清理 pyproject.toml">
    删除 `pyproject.toml` 中的 `[tool.poetry...]` 部分。
  </Step>
</Steps>

完成后，打包基础设施会在后续所有操作中使用 `pip`，自动导入检测也会继续正常运行。

<div id="nix">
  ## 使用 Nix 配置系统依赖项
</div>

Replit 通过集成 [Nix](https://nixos.org/) 支持所有编程语言。如果需要标准语言软件包以外的系统级依赖项，可以将其添加到 [replit.nix](/zh/ko/features/project-setup/configuration#replit-nix-file) 文件中。

<div id="nix-2">
  ### Nix 软件包
</div>

直接编辑 `replit.nix`，以添加系统级依赖项。可在 [search.nixos.org](https://search.nixos.org/packages) 搜索可用的软件包。

<div id="section-4">
  ### 模块
</div>

模块集成了对编程语言、格式化工具和 packager 的支持，是 Replit App 的基础。通过模板或 GitHub 仓库创建 Replit App 时，Replit 会自动安装所需的模块。

你可以使用 [.replit](/zh/ko/features/project-setup/configuration#replit-file) 文件自定义模块和其他 Nix 设置。

<div id="section-5">
  ## packager 配置
</div>

你可以在 [.replit](/zh/ko/features/project-setup/configuration#replit-file) 文件中细致地调整软件包管理行为。

| 配置                                    | 说明               | 默认值     |
| ------------------------------------- | ---------------- | ------- |
| `packager.language`                   | 用于软件包操作的语言       | 自动检测    |
| `packager.features.guessImports`      | 运行时自动检测并安装缺失的软件包 | `true`  |
| `packager.features.packageSearch`     | 启用软件包搜索功能        | `true`  |
| `packager.features.enabledForHosting` | 托管时要求安装软件包       | `false` |
| `packager.afterInstall`               | 软件包安装后运行的命令      | —       |
| `packager.ignoredPaths`               | 从导入检测中排除的路径      | `[]`    |
| `packager.ignoredPackages`            | 从自动检测中排除的软件包     | `[]`    |
