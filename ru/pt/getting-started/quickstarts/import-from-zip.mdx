<div id="importar-de-zip">
  ## Импорт из ZIP
</div>

⏰ *Примерное время: три минуты*

Импортируйте локальный проект, загрузив файл `.zip`.

Полный список вариантов импорта, включая другие платформы — GitHub, Figma, Bolt, Lovable и Vercel, — см. в [документации по функции импорта](/ru/pt/core-concepts/project-editor/app-setup/import).

<div id="antes-de-comear">
  ## Перед началом
</div>

* Файл `.zip` с вашим проектом
* Чётко определённая корневая папка проекта в архиве
* Учётная запись Replit

<div id="passos-de-importao">
  ## Шаги импорта
</div>

1. Откройте [replit.com/import](https://replit.com/import).
2. Выберите **ZIP**.
3. Загрузите свой файл `.zip`.
4. Добавьте все необходимые секреты и переменные окружения.
5. Нажмите **Импортировать**.

<div id="o-que-importado">
  ## Что импортируется
</div>

* Файлы проекта и структура каталогов
* Файлы зависимостей
* Настройки запуска и сборки для Replit

<div id="o-que-no-importado">
  ## Что не импортируется
</div>

* Существующие значения переменных окружения
* Пользовательские домены
* Специфичные для платформы сервисы, требующие ручной настройки
* Данные из существующих баз данных
* Настройки существующих сторонних коннекторов

<div id="configure-and-run-your-app">
  ## Настройка и запуск приложения
</div>

Во время импорта {setupDescription_0}. Если приложение требует доработки, используйте следующие инструменты Project Editor:
