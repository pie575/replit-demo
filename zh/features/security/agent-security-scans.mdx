Agent 安全扫描会全面检查代码库，排查安全与隐私漏洞。Security Agent 将基于模型的分析与 [Semgrep](https://semgrep.dev/)、[HoundDog.ai](https://hounddog.ai) 等静态分析工具相结合，并在 Project Security Center 中展示扫描发现的问题。

所有付费 Replit 用户均可使用 Agent 安全扫描。对于规模较大的 project，深度审计最长可能需要 15 分钟。

<div id="what-security-agent-reviews">
  ## Security Agent 审查的内容
</div>

启动扫描后，Security Agent 会：

1. 梳理路由、API、数据流和入口点。
2. 为应用构建威胁模型。
3. 对整个代码库执行静态分析。
4. 结合应用的实际情况评估发现的问题。
5. 生成发现的问题报告供你查阅。

此项审查可识别不安全的代码模式 (如 SQL 注入、跨站脚本、跨站请求伪造) 、隐私问题 (如敏感数据流入日志或第三方 API) ，以及路由、API 和数据流中的架构性漏洞。

<div id="start-an-agent-security-scan">
  ## 启动 Agent 安全扫描
</div>

<Steps>
  <Step title="打开 Security Center">
    在项目的 **Tools** 面板中选择 **Security Center**。你也可以在发布流程中选择 **Review security**。

    <Frame>
      <img src="/assets/mirror/review-security-button-9331149c28f7.png" alt="发布流程中的 Review security 操作" width="1440" height="900" data-path="images/project-security-center/review-security-button.png" />
    </Frame>
  </Step>

  <Step title="启动扫描">
    选择 **Run scan with Agent**。

    <Frame>
      <img src="/assets/mirror/run-scan-with-agent-f54820ac154a.png" alt="Project Security Center 中的 Run scan with Agent 操作" width="1440" height="900" data-path="images/project-security-center/run-scan-with-agent.png" />
    </Frame>
  </Step>

  <Step title="按需补充上下文">
    你可以补充上下文，让威胁模型聚焦于应用的特定部分，然后启动安全扫描。

    <Frame>
      <img src="/assets/mirror/scan-options-c2cd398fa78b.png" alt="包含 Add context 字段和 Start security scan 操作的安全扫描选项" width="1440" height="900" data-path="images/project-security-center/scan-options.png" />
    </Frame>
  </Step>

  <Step title="等待审查完成">
    等待 Security Agent 完成审查。通常需要几分钟；project 较大时最多可能需要 15 分钟。
  </Step>
</Steps>

<div id="review-and-fix-findings">
  ## 审查并修复发现的问题
</div>

<Steps>
  <Step title="审查报告">
    在 **Security Center** 中查看每条发现的问题及其严重程度。对于你已了解并接受的
    发现的问题，可直接忽略；也可以先修改发现的问题，再提交修复。
  </Step>

  <Step title="使用 Agent 修复已接受的发现的问题">
    将已接受的问题发送给 Agent。Security Agent 会将漏洞拆分为
    多个独立任务，便于 Agent 并行处理多项修复。
  </Step>

  <Step title="重新运行扫描">
    Agent 完成修复后，再运行一次扫描，确认问题已
    解决。在规模较大的 project 中，修复高严重度
    发现的问题后可能会暴露出更多问题。
  </Step>
</Steps>

<div id="when-to-use-level-3">
  ## 何时使用 Level 3
</div>

Agent 安全扫描审查的是源代码。如果你还需要通过浏览器和网络交互来检查运行中的应用，请使用 [Level 3 黑盒渗透测试](/zh/features/security/black-box-pen-tests)。Level 3 会并行执行黑盒测试和源代码审查。

<div id="limitations-and-best-practices">
  ## 限制与最佳实践
</div>

* 扫描在 Replit 基础设施上运行。Replit 不会将你的代码或数据发送给 Semgrep、HoundDog.ai 或其他第三方。
* 扫描配置和结果始终保留在你的 Replit App 中。
* 扫描并不等同于完整的安全审查。请将其与代码审查、测试、依赖项审查以及对运行中应用的检查结合使用。
* 在重大代码改动之后、添加或更新依赖项之后，以及发布新版本之前，请重新运行扫描。
