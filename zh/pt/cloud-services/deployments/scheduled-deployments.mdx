---
title: "Scheduled Deployments"
description: "了解如何使用 Scheduled Deployments 按计划执行任务。"
---

只需定义一条命令行操作和一个执行计划，Replit 就会在你的 Replit App 环境中自动运行它。运行完成后，该操作即告结束，直到下一次计划执行时再次启动。

定时部署 (也称为 scheduled jobs) 最适合处理周期性任务，例如检查状态、发送通知和启动备份，并不适用于 Web 应用这类持续运行或长时间运行的任务。

<div id="recursos">
  ## 功能
</div>

定时部署包含以下功能：

* **自动调度**：设定好任务的执行计划，Replit 会自动运行。
* **自然语言调度**：输入通俗易懂的计划描述，AI 会将其转换为 cron 表达式 (一种计算机可读的调度格式) 。
* **错误告警**：定时任务失败时，你会收到通知。
* **监控**：查看日志并监控定时部署的运行状态。

<div id="uso">
  ## 使用
</div>

您可以在 Project Editor 的 Publishing 工具中访问定时部署。

以下内容将指导您设置和管理定时部署。

<Accordion title="如何访问 Scheduled Deployments">
  在左侧的**工具停靠栏**中：

  1. 选择 <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="所有工具图标" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**，查看 Project Editor 的工具列表。
  2. 选择 <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Publishing 图标" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publishing**。
  3. 选择 **Scheduled**，然后选择 **Set up your published app**。

  在**搜索栏**中：

  1. 选择顶部的 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 放大镜，打开搜索工具。
  2. 输入“Publishing”以查找该工具，然后从搜索结果中选择它。
  3. 选择 **Scheduled**，然后选择 **Set up your published app**。
</Accordion>

<div id="configurao-da-mquina">
  ### 机器配置
</div>

此字段可用于查看定时部署所用机器的 CPU、内存及使用费用。

<div id="campos-de-agendamento">
  ### 调度字段
</div>

* **Schedule description**：以自然语言输入调度安排，例如“Every Monday and Wednesday at 10 AM”或“March 24th, 2024 at 3 PM”。
* **Cron expression**：可选，输入一段计算机可读的字符串，用于定义任务的执行时间。
* **Timezone selection**：在下拉菜单中选择调度所使用的时区。

当你在 **Schedule description** 或 **Cron expression** 字段中输入内容时，AI 会自动将其转换为对应的另一种格式。
如需进一步了解 cron 表达式，请参阅维基百科的 <a href="https://en.wikipedia.org/wiki/Cron" target="_blank">cron</a> 页面。

<div id="tempo-limite-do-job">
  ### 作业超时时间
</div>

输入作业在被调度程序终止前允许运行的最长时间，并在时间单位下拉菜单中选择 &quot;minutes&quot; 或 &quot;hours&quot;。

<Tip>
  定时作业的运行速度可能比在 Project Editor 中慢。请先测试
  部署，并据此调整超时时间。
</Tip>

<div id="build-command">
  ### Build command
</div>

在 **Build command** 字段中输入用于编译或配置应用的 Shell 命令，该命令会在 Run command 之前执行。
例如，要安装 Node.js 应用的依赖项，可以添加 build command `npm install`。

build command 的运行时间不计入您的用量，也不会占用作业的时间上限。

<div id="run-command">
  ### Run command
</div>

在 **Run command** 字段中输入用于启动任务的 Shell 命令。
例如，要运行 Python 脚本，可以将 `python app.py` 添加为 run command。

Replit 调度程序会在设定的时间执行该 run command。
命令的运行时长会计入你的用量。有关按用量计费的更多信息，
请参阅定价文档中的 [Scheduled Deployments 部分](/zh/pt/billing/deployment-pricing#scheduled-deployments)。

<div id="secrets-do-deployment">
  ### 部署 Secrets
</div>

选择 **Add deployment secret**，添加应用安全运行所需的环境变量或 secrets。

如果你的 Replit App 中已有环境变量或 secrets，Publishing 工具会自动将其添加到列表中。

若要编辑环境变量的值，请点击

<img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" width="16" height="16" alt="three vertical dots icon" data-path="images/icons/vertical-dots.svg" /> 竖排三点图标，然后在菜单中选择 **Edit**。Secrets 管理器只会将该值应用到
部署，不会改动你的 Replit App 中定义的环境变量。
