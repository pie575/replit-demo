---
title: "Travailler avec les données"
description: "Explorez, modifiez, exportez et interrogez votre base de données depuis l’onglet My Data à l’aide d’outils visuels ou de SQL."
---

L’onglet **My Data** vous permet de consulter et de modifier le contenu de votre base de données. Ouvrez l’outil **Database**, sélectionnez votre base de données, puis choisissez **My Data**. Vous pouvez utiliser les outils visuels ou exécuter directement des requêtes SQL.

<Note>
  Pour modifier les données de production, sélectionnez la base de données de production, ouvrez **My Data**, puis activez **Edit**. Attention : il s’agit des données réelles de votre application en production.
</Note>

<div id="section">
  ## Explorer et modifier visuellement les données
</div>

Les outils Database incluent <a href="https://orm.drizzle.team/drizzle-studio/overview" target="_blank">Drizzle Studio</a>, qui permet d’explorer et de modifier visuellement les données. Cet outil permet d’éviter les erreurs de syntaxe et offre les fonctionnalités suivantes :

* Filtrer et trier les données pour vous concentrer sur des informations spécifiques
* Exporter les données dans un fichier pour les utiliser en externe
* Insérer ou modifier les données des lignes
* Créer et gérer des schémas, des tables, des vues et des enums

<div id="sql">
  ## Exécuter des commandes SQL
</div>

L’exécuteur SQL vous permet d’exécuter des commandes SQL dans votre base de données et d’en afficher les résultats.

<Accordion title="Accéder à l’exécuteur SQL">
  Dans l’outil **Database** :

  1. Sélectionnez l’onglet **My Data**
  2. <img class="icon-svg" src="/assets/mirror/sql-runner-icon-b25868882922.svg" alt="Icône de l’exécuteur SQL" width="16" height="16" data-path="images/icons/sql-runner-icon.svg" /> Sélectionnez **SQL runner**
</Accordion>

Pour exécuter une requête, saisissez une instruction SQL dans la zone de texte, puis cliquez sur le bouton Exécuter adjacent <img class="icon-svg" src="/assets/mirror/sql-play-8ed26b5de7f1.svg" alt="Icône d’exécution SQL" width="18" height="18" data-path="images/icons/sql-play.svg" />.

<Frame>
  <img src="/assets/mirror/sql-runner-run-8ad798a61335.jpg" alt="Capture d’écran de l’exécuteur SQL et du bouton Exécuter" width="1390" height="608" data-path="images/databases/sql-runner-run.jpg" />
</Frame>

<Tip>
  Vous n’avez pas besoin d’écrire vous-même du SQL. Demandez à Agent de consulter ou modifier vos données : il écrira et exécutera le SQL pour vous.
</Tip>
