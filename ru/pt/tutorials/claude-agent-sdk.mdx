[Claude Agent SDK](https://docs.anthropic.com/en/docs/agents-and-tools/claude-code/sdk) — это Claude Code в виде библиотеки. Он позволяет программно создавать тех же агентов, на которых работает Claude Code, и запускать их как код. Превращайте повторяющиеся задачи в автоматизированные рабочие процессы и публикуйте их в Replit.

<div id="como-o-claude-agent-sdk-funciona">
  ## Как работает Claude Agent SDK
</div>

Агент — это цикл: вы отправляете промпт, агент выбирает, какие инструменты запустить, анализирует результаты и повторяет всё заново, пока задача не будет выполнена.

Промпт задаёте вы. Цикл берёт на себя SDK.

Но возможности SDK шире. Он позволяет создавать **мультиагентные архитектуры**, в которых агент-оркестратор делегирует задачи специализированным субагентам, у каждого из которых свои инструменты и своё контекстное окно.

<Tip>
  Мультиагентные архитектуры помогают каждому агенту оставаться сосредоточенным на своей задаче. Субагенты получают только те инструменты и тот контекст, которые им действительно нужны, — это предотвращает разрастание контекста и повышает производительность.
</Tip>

<div id="primitivas-principais">
  ### Основные примитивы
</div>

| Примитив         | Что делает                                                                                                                  |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------- |
| **Цикл запроса** | Основа: промпт, выбор инструментов, выполнение, наблюдение, повтор                                                          |
| **Агенты**       | Специализированные конфигурации с собственными инструментами и инструкциями                                                 |
| **Инструменты**  | Действия, доступные агентам, — выполнение команд, вызовы API, редактирование файлов                                         |
| **Серверы MCP**  | Внешние процессы, предоставляющие наборы инструментов (требовательны к контексту, загружаются заранее)                      |
| **Навыки**       | Файлы инструкций в Markdown, которые учат агентов выполнять задачи (экономно расходуют контекст, загружаются по требованию) |
| **Разрешения**   | Точная настройка того, к чему каждый агент может обращаться и что выполнять                                                 |

<div id="skills-vs-servidores-mcp">
  ### Навыки и серверы MCP
</div>

Есть два основных способа расширить возможности агентов:

**Навыки** — это markdown-файлы с инструкциями, которым следует агент. До момента вызова загружается только краткое описание, поэтому окно контекста остаётся компактным. Используйте навыки для:

* Рабочих процессов и соглашений («как выполнить развёртывание», «чек-лист код-ревью»)
* Справочных материалов (стандарты API, руководства по стилю)
* Многоразовых промптов, вызываемых по имени

**Серверы MCP** — это процессы, предоставляющие инструменты. Все описания инструментов загружаются заранее, поэтому они расходуют много контекста. Используйте серверы MCP для:

* Подключения к внешним сервисам (Notion, Linear, базы данных)
* Действий, требующих доступа к API (создание задач, запрос данных)
* Инструментов, которые *выполняют* действия, а не просто дают указания

<Info>
  Навыки определяют, *как* должен работать агент. Серверы MCP определяют, *к чему* агент может получить доступ. И то, и другое подходит как для агентов-программистов (таких как Replit Agent), так и для агентов, которые вы создаёте с помощью SDK.
</Info>

<div id="quando-usar-o-sdk-vs-a-api">
  ### Когда использовать SDK, а когда API
</div>

| Сценарий использования           | Выбор            |
| -------------------------------- | ---------------- |
| Автоматизация многоэтапных задач | Claude Agent SDK |
| Мультиагентные рабочие процессы  | Claude Agent SDK |
| Простые чат-приложения           | API Anthropic    |
| Задачи в один turn               | API Anthropic    |

<div id="crie-um-agente-organizador-do-todoist">
  ## Создайте агента для организации задач в Todoist
</div>

В этом руководстве используется шаблон Replit, который создаёт проект Claude Agent SDK с необходимой структурой: каталогами агентов, инструментами, серверами MCP, навыками и разрешениями, уже готовыми к использованию.

<div id="etapa-1-faa-remix-do-template">
  ### Шаг 1: Сделайте ремикс шаблона
</div>

<Steps>
  <Step title="Откройте шаблон">
    Откройте [шаблон Claude Agent SDK](https://replit.com/@matt/Claude-Agent-SDK) в Replit и выберите **Remix**, чтобы создать собственную копию.
  </Step>

  <Step title="Назовите проект">
    Дайте ему понятное название (например, «Мой агент Todoist») и выберите **Use Template**.
  </Step>

  <Step title="Изучите структуру проекта">
    Когда среда загрузится, откройте боковую панель файлов. При необходимости включите **Show Hidden Files**, чтобы увидеть структуру целиком:

    * `.agents/skills/` — навыки, которые учат Replit Agent создавать приложения с помощью Claude Agent SDK
    * `src/agents/` — определения агентов
    * `src/mcpServers/` — настройки серверов MCP
    * `src/permissions/` — определения разрешений
    * `src/skills/` — навыки для ваших агентов (файлы markdown)
    * `src/tools/` — определения пользовательских инструментов
  </Step>
</Steps>

<Tip>
  Шаблон включает навык, который учит Replit Agent создавать приложения с помощью Claude Agent SDK. Это значит, что Agent уже знаком с этим фреймворком, когда вы отправляете ему промпт.
</Tip>

<div id="etapa-2-conecte-o-todoist-via-integraes-do-replit">
  ### Шаг 2: Подключите Todoist через интеграции Replit
</div>

Прежде чем создавать промпты для Agent, подключите сервис, с которым должен взаимодействовать ваш агент.

1. Перейдите на **replit.com/integrations** в своей учётной записи Replit.
2. Найдите **Todoist** и подключите свою учётную запись.
3. Разрешите Replit доступ к вашим данным Todoist.

<Info>
  Интеграции Replit берут на себя OAuth и аутентификацию. Ваш агент может обращаться к API Todoist без необходимости напрямую управлять токенами. Это проще, чем настраивать отдельный сервер MCP с собственным потоком OAuth.
</Info>

<div id="etapa-3-crie-prompts-para-o-agent-construir-seu-agente">
  ### Шаг 3: Напишите промпты, чтобы Agent создал вашего агента
</div>

Для лучших результатов переключите Replit Agent в **режим Plan** — он покажет план до начала сборки, и вы сможете проверить подход.

<AiPrompt>
  Use a skill Claude Agent SDK. Создай агента, который анализирует мои входящие в Todoist и организует задачи, добавляя подходящие метки или вспомогательную информацию.

  Тебе нужно создать инструменты, которые позволят агенту взаимодействовать с Todoist через SDK.

  На выходе должен получиться агент, который при запуске загружает все доступные задачи и проекты, дополняет их и должным образом упорядочивает.

  Обязательно используй интеграцию Replit с Todoist для всей аутентификации. Используй пользовательские инструменты с REST API Todoist вместо MCP-сервера Todoist, так как MCP-серверу нужен OAuth, который в этом контексте не работает.

  Агент также должен получать список проектов и назначать подходящий проект каждому элементу во входящих, полностью очищая их.
</AiPrompt>

<Note>
  Последние два абзаца этого промпта появились уже после отладки. Если сразу уточнить, *как* аутентифицироваться (интеграции Replit, а не OAuth MCP) и *каким* должно быть конечное состояние (полностью очищенные входящие), это экономит время на итерациях.
</Note>

<div id="etapa-4-revise-o-plano-e-construa">
  ### Шаг 4: Проверьте план и запустите сборку
</div>

Когда Agent представит план, убедитесь, что он включает:

1. **Пользовательские инструменты** для API Todoist (а не MCP-сервер Todoist)
2. **Агента-организатора**, который получает задачи, метки и проекты
3. **Необходимые разрешения** с областью действия, требуемой инструментам вашего агента
4. **Точку входа**, запускающую рабочий процесс

Когда всё будет готово, утвердите план, установите для Agent **высокий уровень автономности** и дайте ему выполнить сборку.

<div id="etapa-5-adicione-sua-chave-de-api-da-anthropic">
  ### Шаг 5. Добавьте API-ключ Anthropic
</div>

Для обращения к Claude в Claude Agent SDK нужен API-ключ Anthropic.

1. Откройте панель **Secrets** в редакторе проекта.
2. Добавьте секрет с именем `ANTHROPIC_API_KEY` и значением вашего API-ключа.

<Info>
  Если вы сохранили API-ключ Anthropic в [хранилище Replit в настройках](https://replit.com/settings), он автоматически доступен во всех ваших проектах.
</Info>

<div id="etapa-6-teste-e-depure">
  ### Шаг 6: Протестируйте и отладьте
</div>

Запустите Agent и проверьте, правильно ли он обрабатывает ваши входящие в Todoist. На что стоит обратить внимание:

* **«Входящие пусты», хотя это не так** — возможно, нужно скорректировать разбор ответа API, по которому определяются задачи во входящих. Убедитесь, что Agent фильтрует задачи по проекту «Входящие», а не по другому свойству.
* **Задачи получают метки, но не перемещаются в проекты** — прямо укажите в промпте, что Agent должен получить список доступных проектов и назначить каждую задачу одному из них.
* **Ошибки аутентификации** — проверьте, что интеграция Todoist подключена в разделе интеграций Replit и что код вашего агента использует именно её, а не отдельный поток OAuth.

<Tip>
  Отладка — неотъемлемая часть разработки с ИИ. Если что-то не работает, посмотрите на результат, определите, *что именно* Agent сделал не так, как вы ожидали, и дайте более конкретный промпт. Каждое исправление подсказывает, что в следующий раз стоит указать сразу.
</Tip>

<div id="publique-seu-agente">
  ## Опубликуйте своего агента
</div>

Когда агент заработает корректно, опубликуйте его для автоматического запуска.

<Steps>
  <Step title="Откройте вкладку Publish">
    В Редакторе проекта выберите вкладку **Publish**.
  </Step>

  <Step title="Выберите Scheduled Deployment">
    Выберите **Scheduled Deployment** для автоматизации по расписанию. Укажите нужное расписание (например, «Каждый день в 17:00 PST»).
  </Step>

  <Step title="Проверьте конфигурацию">
    Убедитесь, что команда запуска указывает на основной файл точки входа, а секрет `ANTHROPIC_API_KEY` добавлен в секреты развёртывания.
  </Step>

  <Step title="Опубликуйте">
    Нажмите **Publish**. Теперь ваш агент активен и запускается по расписанию.
  </Step>
</Steps>

Для агентов, которым нужно реагировать на события (вебхуки, входящие сообщения), используйте вместо этого [развёртывание Reserved VM](/ru/pt/features/publishing/reserved-vm-deployments).

<div id="estenda-seu-agente">
  ## Расширьте возможности своего агента
</div>

Когда базовая версия будет готова, вы сможете создавать в Replit более сложных агентов:

* **Добавьте постоянную память** — используйте [Базу данных Replit](/ru/pt/features/data-and-storage/sql-database) для хранения состояния между запусками
* **Храните файлы** — используйте [Хранилище приложений](/ru/pt/features/data-and-storage/object-storage) для данных в виде файлов
* **Подключайте больше сервисов** — добавьте больше [интеграций](/ru/pt/features/integrations/overview) (Slack, Linear, GitHub, Notion) для рабочих процессов с несколькими сервисами
* **Используйте навыки** — добавьте Markdown-файлы навыков, чтобы наделить агентов специализированными знаниями и инструкциями
