借助 ChatGPT 的 Replit 集成，你可以直接在对话中创建、更新和查看 Replit App，无需任何设置。边与 ChatGPT 聊天边构建真实可用的应用，剩下的交给 Agent。

<div id="chatgptreplit">
  ## ChatGPT 中的 Replit 是什么
</div>

ChatGPT 中的 Replit 可将你在 ChatGPT 中的对话连接到 Replit 强大的开发平台。只需描述你想要构建的内容，Agent 就会为你创建一个功能完整的 Replit App。创建完成后，你还可以让 ChatGPT 修改、更新或分析这个应用 —— 全部通过自然对话完成。

<div id="section">
  ## 开始使用
</div>

按照以下步骤将 Replit 连接到 ChatGPT，并创建你的第一个应用。

<div id="replitchatgpt">
  ### 将 Replit 连接到 ChatGPT
</div>

将 Replit 连接到 ChatGPT 有两种方式：

<Accordion title="从 Settings 连接">
  1. 在 ChatGPT 中点击个人资料图标
  2. 前往 **Settings** → **Apps &amp; Connectors**
  3. 找到 **Replit** 并点击 **Connect**
  4. 使用 Replit 账户完成 OAuth 授权
</Accordion>

<Accordion title="从对话中连接">
  1. 在 ChatGPT 中开始一个新对话
  2. 通过以下任一方式调用 Replit
  3. 如果尚未连接，ChatGPT 会引导你完成 OAuth 流程
</Accordion>

<div id="chatgptreplit-2">
  ### 在 ChatGPT 中调用 Replit
</div>

连接后，可通过三种方式调用 Replit：

| 方式    | 用法                                  |
| ----- | ----------------------------------- |
| 直接提及  | 在消息开头输入 `Replit, <请求内容>`            |
| 斜杠命令  | 在输入框中输入 `/Replit`                   |
| 输入框菜单 | 点击 **+** 按钮 → **More** → **Replit** |

<div id="section-2">
  ### 创建你的第一个应用
</div>

连接完成后，即可创建你的第一个 Replit App：

1. 在 ChatGPT 中开启一个新对话
2. 调用 Replit 并描述你想要的内容 (例如：&quot;Replit，帮我做一个带深色模式的待办事项应用&quot;)
3. Agent 会生成应用并自动完成部署
4. 完成后，你会收到一个链接，可用于查看该应用

<Note>
  每个对话只能处理一个 Replit App。如果在同一对话中创建新应用，则会修改现有应用。若要创建多个应用，请分别开启不同的对话。
</Note>

<div id="section-3">
  ## 功能
</div>

* **[Replit AI](/zh/ja/build/welcome)**：Agent 根据自然语言请求生成并部署应用
* **[Project Editor](/zh/ja/learn/projects-and-artifacts/project-editor)**：可从 ChatGPT 访问的全功能开发环境
* **[Publishing](/zh/ja/learn/projects-and-artifacts/replit-deployments)**：应用会自动部署，随时可供分享

<Accordion title="可以做什么">
  **创建**：描述你想做的东西，即可创建新的 Replit App。Agent 会生成应用并自动完成部署。

  **更新**：在当前对话中修改应用。向 ChatGPT 提出添加功能、修复缺陷或调整内容的需求，Agent 会为你应用这些改动。

  **查看**：在不做任何修改的情况下分析应用，获取代码结构、文件路径和运行行为等信息。
</Accordion>

<Accordion title="支持的文件格式">
  你可以在提示中包含多种类型的文件：

  | 格式         | 支持             |
  | ---------- | -------------- |
  | PDF        | 是              |
  | CSV        | 是              |
  | 常见文档格式     | 是              |
  | 图片 (原始文件)  | 否 (请改用公开 URL)  |
  | 视频 (原始文件)  | 否 (请改用公开 URL)  |

  <Note>
    若要在应用中加入图片或视频，请在提示中提供公开 URL。你也可以在应用创建完成后，直接在 Replit 中添加媒体文件。
  </Note>
</Accordion>

<Accordion title="构建时间">
  Agent 构建应用通常所需的时间：

  | 应用复杂度                   | 常见构建时间 |
  | ----------------------- | ------ |
  | 简单 (计算器、小型着陆页)          | 2～3 分钟 |
  | 复杂 (游戏、丰富的动画、信息量大的仪表板)  | 3～4 分钟 |
</Accordion>

<div id="section-4">
  ## 可用套餐与支持情况
</div>

<Accordion title="ChatGPT 套餐">
  所有 ChatGPT 套餐均可使用 Replit 集成：

  | 套餐             | 支持 | 备注                                             |
  | -------------- | -- | ---------------------------------------------- |
  | Free           | 是  |                                                |
  | Plus           | 是  |                                                |
  | Pro            | 是  |                                                |
  | Business       | 是  | 需由管理员在 **Workspace settings → Connectors** 中启用 |
  | Enterprise/Edu | 是  | 需由管理员在 **Workspace settings → Connectors** 中启用 |

  **地区可用性：** 欧盟以外的所有地区。
</Accordion>

<Accordion title="Replit 套餐">
  所有 Replit 套餐均支持 ChatGPT 集成：

  | 套餐              | 支持 | 备注                            |
  | --------------- | -- | ----------------------------- |
  | Starter (Free)  | 是  | 仅限公开应用                        |
  | Core            | 是  | 私有应用、扩展构建、Publishing、Database |
  | Pro             | 是  | 每月额度上限更高，包含全部 Core 功能         |
  | Enterprise      | 是  | 可使用全部功能                       |
</Accordion>

<div id="section-5">
  ## 账单与积分
</div>

在 ChatGPT 中通过 Replit 完成的工作，将按 Agent 使用费计入你的 Replit 账户账单。

<Accordion title="计费方式">
  * **Core** 和 **Pro** 套餐均包含每月积分，可在额度上限内涵盖 Agent 使用量、Publishing 和数据库
  * 你可以购买**积分包**，有效期为 6 个月，到期失效且不会自动续订 —— 非常适合发布或实验场景
  * 你可以在 Replit 的账单设置中通过**用量限额**和**预算**来控制支出上限

  详情请参阅 [AI 计费文档](/zh/ja/billing/ai-billing)。
</Accordion>

<div id="section-6">
  ## 当前限制
</div>

目前，ChatGPT 中的 Replit 应用：

* 只能操作在该特定对话中创建的应用
* 无法打开或修改：
  * 在其他 ChatGPT 对话中创建的应用
  * 直接在 Replit 中创建的应用

数据库、Secrets 管理以及更高级的 Project Editor 控制等功能将陆续推出，以实现与完整 Replit 体验的功能对等。

<div id="section-7">
  ## 故障排查
</div>

<Accordion title="浏览应用中未显示 Replit">
  如果 **浏览应用** 中没有显示 Replit：

  * 确认您所在地区是否支持该应用
  * 确认工作区管理员是否已启用 Replit 应用 (Business/Enterprise/Edu)
</Accordion>

<Accordion title="构建失败">
  如果构建失败，请在 Replit 中打开该应用：

  * 查看用量与账单
  * 使用检查点和回滚功能恢复到之前的状态
  * 在 Project Editor 中直接向 Agent 求助
</Accordion>
