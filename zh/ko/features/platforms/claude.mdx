---
title: "在 Claude 中使用 Replit"
description: "在 Claude 中将 Replit 用作连接器，无需离开对话即可创建和更新 Replit Apps。"
---

Replit 可作为 Claude 中的连接器使用。连接后，您无需离开与 Claude 的对话，即可在 Replit 中构建应用。

<div id="replit">
  ## 连接 Replit 连接器
</div>

在 Claude 中打开连接器目录，找到并连接 **Replit**。Claude 会引导你登录 Replit 账户。连接后，你可以让 Claude 创建新应用、修改现有应用，或解答有关正在构建的应用的问题。Claude 会将请求转交给 Replit Agent，由 Agent 执行任务并提供已上线应用的链接。

<Tip>
  试着对 Claude 说：“创建一个用于追踪我每周习惯的 Replit 应用”或“在我的 Replit 应用中添加登录页面”。Claude 会将你的请求转交给 Replit Agent，并返回一个可查看构建过程的链接。
</Tip>

<div id="claude-replit">
  ## 将设计从 Claude 发送到 Replit
</div>

在 Claude 的设计画布中创建内容后，您可以直接将其发送到 Replit。选择 **Replit** 作为目标后，该设计会在 Replit 中以可运行的应用形式打开。Agent 会规划如何将静态设计转化为可用的产品，让您可以继续构建、添加数据库并发布。

有关完整的设计交接流程，请参阅[将 Claude 设计导入 Replit Design](/zh/ko/design/import-claude-designs-into-replit-design)。

<div id="section">
  ## 工作原理
</div>

Replit 连接器通过 [Replit MCP 服务器](/zh/ko/platforms/mcp-server) 与 Replit 交互。Claude 会自动处理连接。
