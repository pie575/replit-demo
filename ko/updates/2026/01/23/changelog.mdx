AI 통합이 이제 4개의 새로운 모델로 오디오 기능을 지원합니다:

* 음성-텍스트 변환을 위한 `gpt-4o-transcribe` 및 `gpt-4o-transcribe-mini`
* 오디오 출력 생성을 위한 `gpt-4o-audio` 및 `gpt-4o-audio-mini`

오디오 콘텐츠를 처리하거나 생성하는 애플리케이션을 구축하세요—팟캐스트를 전사하거나, 음성 어시스턴트를 만들거나, 앱에 음성 인터페이스를 추가하세요.

### Agent 자동화에서 웹 검색

<Frame>
  <img src="/assets/mirror/image_935f53bc7191-e59f7aee0cd0.png" alt="자동화를 통해 리서치 요약을 제공하는 Agent" width="1482" height="2492" data-path="images/changelog/2026-01-23/image_935f53bc7191.png" />
</Frame>

API 키 없이 웹 검색을 사용하는 자동화를 만드세요. Agent는 AI 통합을 통해 LLM 네이티브 웹 검색을 통합하여 예약된 리서치, 뉴스 요약 또는 교육 콘텐츠 전달을 가능하게 합니다.

### replit.md에 대한 RulesSync 지원

오픈 소스 프로젝트 [RulesSync](https://github.com/dyoshikawa/rulesync)가 이제 `replit.md` 파일을 지원합니다. AI 에이전트 구성 파일(`CLAUDE.md`, `AGENT.md`, `replit.md`)을 여러 프로젝트에서 동기화하세요.
