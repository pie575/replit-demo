이미 진행 중인 앱이나 프로젝트가 있다면, 이를 Replit으로 가져와 Project에서 작업을 이어갈 수 있습니다. 가져오기는 Conversation에 근거나 context로 파일을 첨부하는 것과는 다릅니다.

<div id="choose-a-supported-source">
  ## 지원되는 소스 선택
</div>

소스에 따라 무엇을 제공해야 하는지, 그리고 기존 작업물이 Replit으로 어떻게 들어오는지가 결정됩니다. 현재 import 가이드에서 다루는 경로는 다음과 같습니다.

| 기존 작업물                  | 지원되는 소스                                                                                     |
| ----------------------- | ------------------------------------------------------------------------------------------- |
| 리포지토리 및 builder project | **GitHub**, **Bitbucket**, **Vercel**, **Bolt**, **Lovable**, **Base44**, **이전 Agent 내보내기** |
| Design                  | **Figma** 및 **Claude**                                                                      |
| 로컬 파일 및 데이터             | **ZIP** 및 **스프레드시트**(`.xlsx`, `.csv` 또는 공개 Google Sheets URL)                               |

일부 builder import는 원래 서비스에서 내보낸 GitHub 리포지토리를 사용합니다. import하기 전에 해당 소스별 가이드를 확인하세요. Settings, secret, database 값 또는 provider별 서비스는 이후에 추가 설정이 필요할 수 있습니다.

prompt box에서 **더하기** 메뉴를 선택한 다음 **Import an existing project**를 선택하면 import flow가 열립니다.

<div id="import-or-attach">
  ## 가져오기와 첨부 중 무엇을 선택할까요?
</div>

* 기존 코드, 디자인 또는 구조화된 프로젝트 작업을 이어서 진행하려면 **Project를 가져오기**하세요.
* 문서, 스프레드시트, 이미지, 스크린샷이 현재 Conversation의 질문이나 task에 필요한 context를 제공한다면 **파일을 업로드**하세요.

두 번째 방법은 [파일 업로드 및 사용](/ko/chat/upload-and-use-files)을 참고하세요.
