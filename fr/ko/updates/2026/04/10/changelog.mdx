<div id="databricks-apps">
  ### Intégration de Databricks Apps
</div>

Les builders Enterprise peuvent désormais créer dans Replit des applications exploitant leurs données et les déployer directement sur Databricks. Agent peut se connecter à votre environnement Databricks et inspecter les schémas de données sans que celles-ci ne quittent Databricks. Une fois votre application prête, publiez-la directement sur Databricks Apps. L&#39;application en cours d&#39;exécution est entièrement hébergée par Databricks et hérite de l&#39;authentification Databricks, de la gouvernance Unity Catalog et de vos restrictions réseau existantes.

<Frame>
  <img src="/assets/mirror/databricks-app-template-333354ec6944.png" alt="Workspace Replit avec le modèle Databricks App sélectionné dans le menu déroulant Templates" width="1368" height="395" data-path="images/changelog/2026-04-10/databricks-app-template.png" />
</Frame>

Cette intégration est disponible pour les organisations Enterprise disposant d&#39;un workspace Databricks. Pour en savoir plus, consultez la [page partenaire Replit x Databricks](https://replit.com/partners/databricks).

  ## Agent
</div>

<div id="ui">
  ### Reproduire une interface à partir d&#39;une capture d&#39;écran
</div>

Collez une capture d&#39;écran dans Agent et demandez-lui de « créer ceci » ou de « reproduire cette interface ». Agent reproduit le design avec une grande fidélité en une seule passe, aussi bien pour les applications web que pour les présentations. Pratique pour cloner un design existant, reconstruire une interface de référence ou prototyper rapidement à partir d&#39;une maquette.

<div id="razorpay">
  ### Paiements Razorpay pour l&#39;Inde
</div>

Les builders en Inde peuvent désormais payer par UPI et par carte via Razorpay, avec la prise en charge de l&#39;e-mandate pour les abonnements récurrents, conformément aux exigences de la Reserve Bank of India. Si vous êtes déjà abonné en Inde, vous pourrez bientôt passer de Stripe à Razorpay depuis la page de facturation.

<div id="revenuecat-app-store-connect">
  ### Synchronisation RevenueCat avec App Store Connect
</div>

L&#39;intégration RevenueCat inclut désormais une synchronisation automatique avec Apple. Lorsque vous configurez des achats intégrés dans RevenueCat, cette configuration est directement synchronisée avec App Store Connect.

En savoir plus sur les [abonnements RevenueCat](/fr/core-concepts/monetization/revenuecat-subscriptions).

<div id="section-5">
  ### Choisir l&#39;emplacement d&#39;exécution de votre app grâce à la région de publication
</div>

Les builders Core, Pro et Enterprise peuvent désormais choisir la région dans laquelle leur app est publiée. Lorsque vous publiez dans une région donnée, le calcul, la base de données et les artefacts de stockage d&#39;objets sont tous hébergés ensemble dans cette région. Les proxys régionaux permettent de réduire la latence pour les visiteurs de votre app.

L&#39;Europe est désormais disponible aux côtés de l&#39;Amérique du Nord ; l&#39;Australie, l&#39;Amérique du Sud et l&#39;Asie arriveront prochainement. Les administrateurs Enterprise peuvent également restreindre leur organisation à une seule région à des fins de conformité.

<div id="section-6">
  ### Consulter les factures passées depuis la page Utilisation
</div>

Vous pouvez désormais consulter vos factures passées directement depuis la page **Utilisation** des paramètres de votre compte. Sélectionnez une période de facturation antérieure dans le menu déroulant pour obtenir une vue d&#39;ensemble de la consommation par application.
