Un **élément** est un composant individuel d’un frame, comme un titre, un bouton, une image, un champ de formulaire ou tout autre composant affiché par le frame. Vous sélectionnez des éléments pour modifier une partie d’un frame sans avoir à tout régénérer.

</Frame>

<div id="selecionando-um-elemento">
  ## Sélectionner un élément
</div>

Utilisez l’[outil Edit](/fr/pt/design/toolbar#edit) dans la barre d’outils. Lorsque Edit est actif, cliquez à l’intérieur d’un frame actif pour sélectionner l’élément situé sous le curseur. L’élément sélectionné est entouré d’un contour de surbrillance et affiche un petit prompt intégré vous permettant de demander à Agent de le modifier.

<Note>
  Edit reste désactivé tant qu’il n’y a pas au moins un frame sur le Canvas et est disponible uniquement sur ordinateur.
</Note>

<div id="agindo-sobre-um-elemento-selecionado">
  ## Agir sur un élément sélectionné
</div>

<div id="pea-ao-agent-para-alter-lo">
  ### Demandez à Agent de le modifier
</div>

Demandez à Agent de mettre à jour le texte, la couleur, la disposition, l&#39;espacement ou le comportement de l&#39;élément à l&#39;aide du prompt intégré.

<Frame>
  <img src="/assets/mirror/canvas-ask-element-53f7468a07d3.png" alt="Détail du prompt intégré pour un élément sélectionné dans le Canvas : une puce « img » suivie du texte indicatif « Ask about selected element… » et d'un bouton d'envoi." width="1500" height="500" data-path="images/replitai/canvas-ask-element.png" />
</Frame>

<div id="trocar-uma-imagem-diretamente">
  ### Remplacer une image directement
</div>

Sélectionnez un élément d’image. La section **Image** du Visual Editor affiche le chemin source et un bouton **Upload Image**, ce qui vous permet de remplacer le fichier sans écrire de prompt.

<div id="visual-editor">
  ## Visual Editor
</div>

La sélection d’un élément ouvre le **Visual Editor** : un panneau situé à droite, associé au prompt intégré. Le panneau regroupe les commandes en sections claires pour vous aider à trouver plus rapidement ce dont vous avez besoin : **Text**, **disposition**, **Color** et **Border**. (La section **Image** apparaît également lorsque vous sélectionnez un élément d’image.)

<Frame>

</Frame>

<div id="layout">
  ### Disposition
</div>

La section **Disposition** vous permet d’ajuster le positionnement des éléments enfants dans un conteneur sans utiliser Agent. Sélectionnez un conteneur flex, développez la section Disposition, et vous aurez :

* **Alignement** : un sélecteur 3×3 indiquant où les éléments se placent le long des deux axes du conteneur.
* **Direction** : deux boutons fléchés qui empilent les éléments enfants en ligne ou en colonne.
* **Espacement (Gap)** : une valeur en pixels correspondant à l’espace entre les éléments. L’icône à côté du champ Gap change selon la direction actuelle, afin que vous sachiez toujours si vous ajustez l’espacement horizontal ou vertical. À côté, une icône fléchée permet d’activer **Répartir l’espace entre les éléments**, ce qui pousse les éléments enfants vers les bords opposés du conteneur.
* **Espace externe** : des champs pour chaque côté afin de définir l’espace à l’extérieur de l’élément (un champ par côté, avec un interrupteur de liaison pour verrouiller les quatre côtés à la fois).
* **Espace interne** : des champs permettant de définir l’espace à l’intérieur de l’élément le long de chaque axe, avec un interrupteur de liaison pour les deux axes à la fois.

La section Disposition n’apparaît que lorsqu’au moins une option de disposition s’applique à l’élément sélectionné. Les nœuds de texte simples sans propriétés d’espacement ou de disposition masquent entièrement la section afin de préserver la compacité de l’éditeur.

Pour les sections **Text**, **Color**, **Border** et **Image**, consultez le [guide du Visual Editor](/fr/pt/design/visual-editor).
