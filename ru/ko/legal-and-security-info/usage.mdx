description: "Узнайте об ограничениях ресурсов Replit, применяемых к Replit App в зависимости от тарифа, включая ограничения CPU, RAM, хранилища и сети."
---

Replit устанавливает определённые мягкие и жёсткие ограничения на использование сервиса. Жёсткие ограничения применяются сервисом автоматически. Мягкие ограничения относятся к потребляемым ресурсам, которые вы обязуетесь не превышать. Подробнее об этих ограничениях можно узнать на странице [https://replit.com/site/pricing](https://replit.com/site/pricing); они могут периодически обновляться. При длительном отсутствии активности учётная запись или использование сервиса могут быть признаны неактивными.

* CPU для Replit App: определяется тарифом (жёсткое ограничение)

* RAM для Replit App: определяется тарифом (жёсткое ограничение)

* Количество одновременно работающих Replit App: 20 (жёсткое ограничение)

* Хранилище для Replit App: определяется тарифом и объёмом хранилища, используемого другими Replit App (жёсткое ограничение)

* Хранилище для учётной записи: определяется тарифом (жёсткое ограничение)

* Пропускная способность сети: определяется тарифом (мягкое ограничение)

Кроме того, независимо от тарифа, для соблюдения Условий использования на содержимое и сетевую активность Replit App накладываются некоторые ограничения. При превышении этих ограничений Replit App может временно стать недоступным, а определённые действия могут завершаться с ошибкой. Ограничения включают:

* Ограничение количества одновременных исходящих сетевых подключений за определённый период.

* Ограничения на частоту и размер запросов к внутреннему GraphQL API Replit.

* Ограничения на использование кода, который может нарушать Условия использования, например для майнинга криптовалюты.
