Ces réponses portent sur l’utilisation d’Agent. Pour en savoir plus, consultez la [présentation d’Agent](/fr/pt/features/agent/overview), les [modes d’Agent](/fr/pt/features/agent/agent-modes) et la [facturation de l’IA](/fr/pt/billing/ai-billing).

<AccordionGroup>
  <Accordion title="Agent est bloqué ou se déconnecte sans cesse—comment y remédier ?">
    1. Ouvrez la palette de commandes avec `Cmd+K` (Mac) ou `Ctrl+K` (Windows).
    2. Recherchez **Restart compute** et sélectionnez cette option pour redémarrer l’environnement de développement.
    3. Ouvrez un nouveau chat avec Agent et décrivez à nouveau votre tâche pour continuer.

    Lorsque l’Agent semble bloqué, cessez d’envoyer des messages — des messages supplémentaires créent des instructions contradictoires. Si l’Agent reste bloqué sur la même tâche, divisez le travail en prompts plus courts et plus ciblés.
  </Accordion>

  <Accordion title="Agent est bloqué dans une boucle ou répète les mêmes étapes : comment l’arrêter ?">
    1. Sélectionnez **Arrêter** dans le panneau de l’Agent pour l’interrompre immédiatement.
    2. Ouvrez la palette de commandes avec `Cmd+K` (Mac) ou `Ctrl+K` (Windows), recherchez **Restart compute**, puis sélectionnez cette option.
    3. Ouvrez un nouveau chat avec l’Agent et reformulez votre tâche de manière plus précise.

    Pour éviter les boucles :

    * Divisez les tâches importantes en prompts plus courts — un objectif par message.
    * Utilisez le [mode Planification](/fr/pt/features/agent/plan-mode) pour définir le périmètre du travail avant que l’Agent ne commence à le réaliser.
    * Définissez une limite d’utilisation dans [Gérer vos dépenses](/fr/pt/billing/managing-spend) afin qu’une boucle n’entraîne pas une facture élevée.
  </Accordion>

  <Accordion title="Comment réduire les coûts de l’Agent : quels réglages sont vraiment utiles ?">
    Voici les choix qui font le plus de différence :

    * **[Free Mode](/fr/pt/features/agent/agent-modes)**—utilisation quotidienne d’Agent sans frais pour les abonnés Core et Pro, dans la limite d’un quota.
    * **[Mode Power](/fr/pt/features/agent/agent-modes)**—plus de capacité à un prix abordable lorsque vous en avez besoin.
    * **[Mode Planification](/fr/pt/features/agent/plan-mode)**—définissez le périmètre et approuvez le travail avant qu’Agent ne commence à développer, afin de ne pas payer pour des modifications que vous n’aviez pas demandées.
    * **Limite d’utilisation et budget**—définissez un plafond dans [Gérer vos dépenses](/fr/pt/billing/managing-spend).

    Il est également utile de démarrer un nouveau Chat avec Agent lorsque vous changez de tâche. Consultez votre panneau d’utilisation pour voir quelles tâches coûtent le plus cher.
  </Accordion>

  <Accordion title="En quoi les modes d’Agent diffèrent-ils ?">
    Agent propose trois modes principaux. Consultez [Free Mode](/fr/pt/help/free-agent-mode) pour en savoir plus.

    * **Free Mode**—l’utilisation quotidienne d’Agent, sans frais pour les abonnés Core et Pro, dans la limite d’un quota renouvelé toutes les cinq heures et d’un plafond hebdomadaire. Le forfait Starter conserve ses limites actuelles. Consultez **Paramètres → Utilisation** pour voir votre consommation.
    * **Power**—un mode payant intermédiaire proposant des modèles puissants à un prix abordable.
    * **Max**—un mode payant haut de gamme proposant les modèles les plus performants pour les tâches les plus exigeantes.
    * **Turbo**—un bouton bascule facultatif dans les Paramètres avancés, disponible uniquement avec Max.

    Les modes payants ont été renommés. **Economy devient Power**, et le mode auparavant appelé **Power devient Max**. Les paramètres de mode existants sont conservés sous les nouveaux noms. Si une demande nécessite davantage de capacité que Free Mode n’en offre, Agent peut proposer l’option payante **Autoriser une fois**. Replit demande confirmation avant de lancer une action payante, puis Agent revient à Free Mode.

    Par ailleurs, le [mode de planification](/fr/pt/features/agent/plan-mode) permet à Agent de définir le périmètre du travail avant d’apporter des modifications, tandis que le mode de création applique directement les modifications. Consultez [Mode de planification vs. mode de création](/fr/pt/learn/plan-vs-build-mode).
  </Accordion>

  <Accordion title="L’Agent a apporté des modifications que vous ne souhaitiez pas — comment les annuler ?">
    Replit enregistre des [checkpoints](/fr/pt/features/version-control/checkpoints-and-rollbacks) pendant que l’Agent travaille. Dans le chat de l’Agent, repérez le message précédant la modification que vous souhaitez annuler, puis sélectionnez l’option de retour en arrière située à côté pour restaurer votre projet à cet état.

    Pour connaître toutes les options de retour en arrière, y compris la récupération de fichiers spécifiques, consultez [Checkpoints et retours en arrière](/fr/pt/features/version-control/checkpoints-and-rollbacks).
  </Accordion>

  <Accordion title="L’Agent indique ne pas pouvoir accéder à Internet ou à des API externes : est-ce normal ?">
    Pendant les phases de création et de modification, Agent fonctionne dans un environnement sandbox avec un accès sortant limité. Votre application déployée peut néanmoins effectuer des appels vers des API externes lorsqu’elle est exécutée — le sandbox s’applique à l’environnement de modification d’Agent, et non à votre application en cours d’exécution.

    Si un appel d’API échoue dans votre application en cours d’exécution, vérifiez que vos clés sont enregistrées dans le panneau [Secrets](/fr/pt/core-concepts/project-editor/app-setup/secrets), puis consultez la page d’état du fournisseur. Sur un réseau d’entreprise ou scolaire, les connexions sortantes de votre application peuvent être bloquées — vérifiez auprès de l’administrateur de votre réseau.
  </Accordion>

  <Accordion title="Puis-je utiliser mes propres clés d’API avec Agent ?">
    Oui. Ajoutez vos clés dans le panneau [Secrets](/fr/pt/core-concepts/project-editor/app-setup/secrets) ; votre application les utilisera pour ses appels d’API. Ouvrez l’outil **Secrets**, sélectionnez **+ Nouveau secret**, puis saisissez un nom (par exemple, `OPENAI_API_KEY`) et une valeur.

    Vous pouvez [utiliser vos propres clés de fournisseur d’IA](/fr/pt/features/integrations/replit-ai-integrations) pour les modèles auxquels votre application fait appel. Le modèle qui alimente l’expérience Agent s’exécute sur l’infrastructure de Replit et ne peut pas être remplacé.
  </Accordion>

  <Accordion title="Agent continue d’ajouter des fonctionnalités que je n’ai pas demandées : comment obtenir un comportement plus précis ?">
    Gardez l’Agent concentré avec des prompts plus précis :

    * Commencez par le mot *Uniquement* — par exemple, &quot;Ajoutez uniquement un bouton de suppression à la carte utilisateur. Ne modifiez rien d’autre.&quot;
    * Utilisez d’abord le [Mode de planification](/fr/pt/features/agent/plan-mode) pour vérifier ce que l’Agent prévoit de faire avant d’apporter la moindre modification.
    * Si l’Agent apporte une modification indésirable, demandez-lui immédiatement de l’annuler dans le même chat.

    Pour en savoir plus, consultez [Création de prompts efficaces](/fr/pt/learn/effective-prompting).
  </Accordion>
</AccordionGroup>
