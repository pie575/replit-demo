Secrets 工具用于存储并加密**密钥**，即 API 密钥、认证令牌、数据库连接字符串等 Replit 应用的敏感信息。

添加密钥后，该工具会自动加密数据，并以环境变量的形式提供给 Replit 应用使用。
这样一来，你无需在代码中硬编码密钥，从而降低泄露风险。

在代码库中硬编码密钥，可能在以下场景中导致意外泄露：

* 通过公开的 Replit 应用或复制粘贴的方式将代码分享到 GitHub
* 将代码提交到公开仓库
* 在直播或屏幕共享中展示代码

使用 Secrets 工具，你就能放心分享代码，不必担心认证信息外泄。

<div id="section">
  ## 功能
</div>

Secrets 包含以下功能：

* **端到端加密**：静态存储采用 AES-256 加密，传输过程采用 TLS 加密，自动保护你的数据
* **应用级密钥**：存储和管理特定 Replit 应用专属的密钥
* **账户级密钥**：存储和管理可在所有 Replit 应用中使用的密钥
* **环境变量访问**：通过环境变量在代码中访问密钥
* **协作访问**：与协作者和团队成员共享密钥

  ## 使用方法
</div>

你可以通过项目编辑器中的 Secrets 工具访问 Secrets。

<Accordion title="如何访问 Secrets">
  通过左侧的**工具栏**：

  1. <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="所有工具图标" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> 选择**所有工具**，显示项目编辑器工具列表。

  通过**搜索栏**：

  1. 选择顶部的<img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" />放大镜，打开搜索工具。

<div id="section-3">
  ### 管理应用 Secrets
</div>

您可以在 **Secrets** 窗格的**应用 Secrets**标签中管理应用级 Secrets。
此标签会显示与 Replit 应用关联的所有 Secrets。

<Accordion title="添加应用 Secrets">
  要添加 Secret：

  1. 选择**新建 Secret**。
  2. 输入**键** (Secret 的名称) 和**值** (Secret 本身) 。
  3. 选择**添加 Secret**以保存。
</Accordion>

<Accordion title="编辑应用 Secrets">
  要编辑 Secret：

  1. 选择 Secret 旁的<img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="纵向三点图标" height="16" width="16" data-path="images/icons/vertical-dots.svg" />纵向三点菜单。
  2. 从快捷菜单中选择**编辑**。
  3. 更新**键**或**值**字段中的文本，然后选择**更新 Secret**以保存更改，或选择**取消**以放弃更改。

  您还可以选择标签底部的**使用 JSON 编辑**或&#42;&#42;使用 .env 编辑&#42;&#42;，以修改整个应用 Secrets 列表。
</Accordion>

<Accordion title="查看应用 Secrets">
  要查看 Secret，请选择 Secret 旁的<img class="icon-svg" src="/assets/mirror/eye-8a6472b8a950.svg" alt="眼睛图标" width="16" height="16" data-path="images/icons/eye.svg" />眼睛图标。

  要隐藏 Secret，请选择<img class="icon-svg" src="/assets/mirror/eye-slash-6b4ded538179.svg" alt="带斜线的眼睛图标" width="16" height="16" data-path="images/icons/eye-slash.svg" />带斜线的眼睛图标。
</Accordion>

<Accordion title="删除应用 Secrets">
  要删除 Secret，请选择 Secret 旁的<img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="纵向三点图标" height="16" width="16" data-path="images/icons/vertical-dots.svg" />纵向三点菜单，然后选择**删除**。
</Accordion>

<div id="section-4">
  ### 管理账户 Secrets
</div>

您可以在 **Secrets** 窗格的**账户 Secrets**选项卡中管理账户级 Secrets。
此选项卡仅显示与您的 Replit 账户关联的 Secrets。

<Accordion title="添加账户 Secrets">
  如需添加账户级 Secrets：

  1. 前往**账户 Secrets**选项卡。
  2. 选择<img class="icon-svg" src="/assets/mirror/settings-icon-c2664c3691bf.svg" alt="齿轮图标" width="16" height="16" data-path="images/icons/settings-icon.svg" />图标，打开**设置**以管理账户级 Secrets。
  3. 选择**新建 Secret**。
  4. 输入**键** (Secret 的名称) 和**值** (Secret 本身) 。
  5. 选择**保存**。
</Accordion>

<Accordion title="编辑账户 Secrets">
  如需编辑 Secret：

  1. 选择 Secret 旁的<img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="铅笔图标" width="16" height="16" data-path="images/icons/pencil-icon.svg" />铅笔图标。
  2. 更新**键**或**值**字段中的内容。选择**保存**以保存更改，或选择**取消**以放弃更改。
</Accordion>

<Accordion title="查看账户 Secrets">
  如需查看 Secret，请选择 Secret 旁的<img class="icon-svg" src="/assets/mirror/eye-8a6472b8a950.svg" alt="眼睛图标" width="16" height="16" data-path="images/icons/eye.svg" />眼睛图标。

  如需隐藏 Secret，请选择<img class="icon-svg" src="/assets/mirror/eye-slash-6b4ded538179.svg" alt="带斜杠的眼睛图标" width="16" height="16" data-path="images/icons/eye-slash.svg" />带斜杠的眼睛图标。

<Accordion title="关联账户 Secrets">
  要在 Replit 应用中使用账户级 Secrets，需先将其关联到应用。
  如需关联账户级 Secrets：

  1. 前往**应用 Secrets**选项卡。
  2. 选中 Secret 左侧的复选框。
  3. 选择**关联到此应用**。

  如需取消关联 Secret：

  1. 前往**应用 Secrets**选项卡。
  2. 选择 Secret 旁的<img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" width="16" height="16" alt="竖向三点图标" data-path="images/icons/vertical-dots.svg" />竖向三点菜单。
  3. 选择**取消关联**。

<Accordion title="删除账户 Secrets">
  1. 选择 Secret 旁的<img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="铅笔图标" width="16" height="16" data-path="images/icons/pencil-icon.svg" />铅笔图标。

<div id="section-6">
  ### 管理密钥的可见性
</div>

密钥的可见性取决于访问 Replit 应用的方式，以及访问者是否为创建者。

要共享 Replit 应用，您可以使用以下任一选项：

* **多人协作**：邀请 Replit 用户进行实时协作
* **封面页**：显示 Replit 应用的预览，并提供 Remix 选项
* **Remix**：公开个人或组织的 Replit 应用，让其他人能够创建自己的版本

下表列出了不同场景下密钥名称和值的可见性：

| 访问方式     | 谁                          | 可查看名称 | 可查看值 |
| -------- | -------------------------- | ----- | ---- |
| 多人协作     | 多人协作协作者                    | ✓     | ✓    |
| 多人协作     | 组织成员 (所有者角色)               | ✓     | ✓    |
| 多人协作     | 组织成员 (非所有者)                | ✓     |      |
| 封面页      | 所有访问者                      |       |      |
| Remix    | Remix 自己 Replit 应用的所有者/协作者 | ✓     | ✓    |
| Remix    | Remix Replit 应用的非所有者/协作者   | ✓     |      |
| Remix    | 从封面页 Remix 的任何人            | ✓     |      |
| 组织 Remix | 拥有所有者角色的组织成员               | ✓     | ✓    |
| 组织 Remix | 不拥有所有者角色的组织成员              | ✓     |      |

<Warning>
  没有所有者角色的组织成员无法查看 Replit 应用的密钥值，但可以通过输出环境变量来获取这些值。
</Warning>

<div id="section-7">
  ## 数据库相关的密钥
</div>

添加 Replit 的 Database 后，项目编辑器会自动创建以下密钥：

| 密钥             | 说明           |
| -------------- | ------------ |
| `DATABASE_URL` | SQL 数据库连接字符串 |

<Info>
  旧版 Neon 开发数据库可能还包含 `PGHOST`、`PGUSER`、`PGPASSWORD`、`PGDATABASE`、`PGPORT`。当前的 Replit 开发数据库改为使用 `DATABASE_URL`。
</Info>

若要查看 Replit 应用的所有环境变量，请在项目编辑器的 Shell 工具中运行 `printenv`，或在代码中将其打印出来。

<div id="section-8">
  ## 预定义环境变量
</div>

Replit 会自动设置以下环境变量，供你的应用访问：

| 环境变量                | 说明                                 |
| ------------------- | ---------------------------------- |
| `REPLIT_DOMAINS`    | 与该 Replit 应用关联的所有域名，以逗号分隔的列表       |
| `REPLIT_USER`       | 当前编辑者的用户名，在多人协作会话中可能有所不同           |
| `REPLIT_DEPLOYMENT` | 代码在已发布的应用中运行时设为 `1`，否则不设置          |
| `REPLIT_DEV_DOMAIN` | `replit.dev` 域名下的开发 URL，与部署 URL 不同 |

这些变量不会显示在 Secrets 工具中，但你可以在代码中通过 `os.environ` 对象访问，或在 Shell 中运行 `printenv` 查看。
