export const ProCreditRolloverPeriod = 'two months';

[Replit Pro](https://replit.com/pricing)专为已用尽 Core 资源、追求更高性能的开发者设计——无论您正在发布生产环境应用、与不断壮大的团队协作，还是将 Agent 的能力发挥到极致。有关当前 Pro 价格，请参阅[定价页面](https://replit.com/pricing)。

<div id="section">
  ## 主要功能
</div>

<div id="agent">
  ### 最强大的 Agent 体验
</div>

* **Turbo 模式**：高级设置中的**独立开关**——在 **Power** 模式下开启后，即可使用速度提升 **2.5 倍**的最快 Agent 模型。由于请求成本约为原来的两倍，建议经验丰富的构建者使用。
* **并行任务执行**：最多可同时运行 10 个任务，加快迭代速度。
* **Agent 模式**：可根据任务从 Lite、Economy 和 Power 中选择。有关模式选择，请参阅 [Agent 模式](/zh/ja/features/agent/agent-modes)。

<div id="section-2">
  ### 阶梯积分与结转
</div>

* **阶梯式月度积分**：提供多个档位，档位越高折扣越多。提前购买更省钱，还可随业务增长随时加购积分。当前档位详情请查看[定价页面](https://replit.com/pricing)。
* **积分结转**：未用完的积分可结转 {ProCreditRolloverPeriod}，让订阅物尽其用。

<div id="section-3">
  ### 扩展团队规模
</div>

* **最多 15 位构建者**：通过共享积分和预算管理，您最多可邀请 15 位构建者。无需按用户付费，所有人均使用同一套餐。
* **协作工作区**：使用管理员账户中的共享积分创建协作工作区，整理应用，并跟踪每个工作区的使用量。

<div id="section-4">
  ### 优先支持与可靠性
</div>

* **优先支持**：工作日可优先直接联系支持工程师。这是在 AI 支持之外，Pro 和 Enterprise 专享的权益。
* **4 倍数据库恢复窗口**：可将数据库恢复到过去 28 天内的任意时间点，而不限于标准的 7 天。请注意，保留窗口越长，占用的存储空间越多，因此延长恢复期会增加使用成本。

<div id="section-5">
  ### 社区及其他
</div>

* **专属社区**：向其他资深构建者学习，分享你的项目进展，并与团队直接交流。
* **即将推出**：今年晚些时候，Pro 将推出更多专属功能。

<div id="pro">
  ## Pro 专属功能
</div>

| 功能         | 详细信息                                |
| ---------- | ----------------------------------- |
| Turbo 模式   | 使用性能最强的模型，Agent 速度提升 2.5 倍          |
| 并行任务执行     | 最多可同时运行 10 个任务                      |
| 最多 15 名构建者 | Core 最多仅支持 5 名                      |
| 积分结转       | 未使用的积分可结转 {ProCreditRolloverPeriod} |
| 优先支持       | 可优先直接联系支持工程师                        |
| 4 倍数据保留时间  | 最多可恢复 28 天内删除的数据库                   |

Pro 包含 Core 的所有功能。完整对比请访问[定价页面](https://replit.com/pricing)。

<div id="section-6">
  ## 开始使用
</div>

1. 访问[定价页面](https://replit.com/pricing)
2. 选择 **Replit Pro**，并选择积分档位
3. 完成付款，即可与团队一起开始构建
