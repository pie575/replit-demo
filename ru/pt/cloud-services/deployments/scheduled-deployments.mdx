---
title: "Запланированные развертывания"
description: "Узнайте, как запускать задачи по расписанию с помощью Scheduled Deployments."
---

Задайте команду и расписание, и Replit будет автоматически выполнять её
в среде вашего Replit App. После завершения выполнение прекращается до следующего запуска по расписанию.

Запланированные развертывания, также известные как запланированные задачи, лучше всего подходят для периодических задач,
таких как проверка статуса, отправка уведомлений и запуск резервного копирования. Они не предназначены
для непрерывных или длительных задач, например веб-приложений.

<div id="recursos">
  ## Возможности
</div>

Запланированные развёртывания включают следующие возможности:

* **Автоматический запуск по расписанию**: задайте расписание задачи, и Replit будет запускать её автоматически.
* **Расписание на естественном языке**: опишите расписание обычными словами, и ИИ преобразует описание в выражение cron — формат расписания, понятный компьютеру.
* **Оповещения об ошибках**: получайте уведомления, если запланированная задача завершится сбоем.
* **Мониторинг**: просматривайте logs и отслеживайте состояние своего запланированного развёртывания.

<div id="uso">
  ## Использование
</div>

Доступ к запланированным развёртываниям можно получить через инструмент Publishing в Project Editor.

В следующих разделах описано, как настроить запланированные развёртывания и управлять ими.

<Accordion title="Как открыть Scheduled Deployments">
  В **панели инструментов** слева:

  1. Выберите <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Иконка All tools" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**, чтобы просмотреть список инструментов Project Editor.
  2. Выберите <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Иконка Publishing" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publishing**.
  3. Выберите **Scheduled**, затем — **Set up your published app**.

  В **строке поиска**:

  1. Выберите <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="Иконка лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> иконку лупы вверху, чтобы открыть поиск.
  2. Введите «Publishing», найдите инструмент и выберите его в результатах.
  3. Выберите **Scheduled**, затем — **Set up your published app**.
</Accordion>

<div id="configurao-da-mquina">
  ### Конфигурация машины
</div>

В этом поле отображаются CPU, RAM и стоимость использования машины для вашего запланированного развёртывания.

<div id="campos-de-agendamento">
  ### Поля расписания
</div>

* **Schedule description**: Введите описание расписания на естественном языке, например «Каждый понедельник и среду в 10:00» или «24 марта 2024 года в 15:00».
* **Cron expression**: При необходимости введите машиночитаемую строку, определяющую время выполнения задачи.
* **Timezone selection**: Выберите часовой пояс для расписания в раскрывающемся списке.

Когда вы вводите значение в поле **Schedule description** или **Cron expression**, ИИ автоматически преобразует его в соответствующий формат.
Подробнее о cron-выражениях читайте в <a href="https://en.wikipedia.org/wiki/Cron" target="_blank">статье Википедии о cron</a>.

<div id="tempo-limite-do-job">
  ### Тайм-аут задачи
</div>

Укажите максимальное время выполнения задачи до того, как планировщик её остановит. В раскрывающемся списке единиц времени выберите &quot;minutes&quot; или &quot;hours&quot;.

<Tip>
  Запланированные задания могут выполняться медленнее, чем в Project Editor. Протестируйте
  развёртывание и при необходимости настройте тайм-аут.
</Tip>

<div id="build-command">
  ### Команда сборки
</div>

В поле **Build command** введите команду Shell, которая компилирует или настраивает ваше App перед выполнением Run command.
Например, чтобы установить зависимости App на Node.js, можно добавить команду сборки `npm install`.

Время выполнения команды сборки не учитывается в лимите использования и не вычитается из ограничения времени задачи.

<div id="run-command">
  ### Run command
</div>

Введите в поле **Run command** команду Shell, запускающую вашу задачу.
Например, чтобы запустить скрипт Python, можно указать `python app.py` в качестве команды запуска.

Планировщик Replit выполняет команду запуска по расписанию.
Время выполнения команды учитывается при расчёте потребления. Подробнее о биллинге за использование
см. в [разделе Scheduled Deployments](/ru/pt/billing/deployment-pricing#scheduled-deployments) документации по ценам.

<div id="secrets-do-deployment">
  ### Secrets для развёртывания
</div>

Нажмите **Add deployment secret**, чтобы добавить переменные окружения или secrets, необходимые вашему приложению для безопасной работы.

Если в вашем Replit App заданы переменные окружения или secrets, инструмент Publishing добавит их в список автоматически.

Чтобы изменить значение переменной окружения, нажмите

<img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" width="16" height="16" alt="three vertical dots icon" data-path="images/icons/vertical-dots.svg" /> иконку с тремя вертикальными точками и выберите **Edit** в меню. Менеджер Secrets применяет
значение только к развёртыванию и не изменяет переменные окружения, заданные в вашем
Replit App.
