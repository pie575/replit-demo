Replit 相信，计算应当惠及每个人。因此，Replit 致力于让所有人都能完全无障碍地使用其服务，包括残障人士。本声明介绍了我们的无障碍目标、实现这些目标的进展，以及您如何就 Replit 的无障碍功能提供反馈。

<div id="metas-de-conformidade">
  # 合规目标
</div>

我们的目标是全面符合 W3C WAI《Web 内容无障碍指南》(WCAG) 2.1。该指南规定了设计师和开发者为提升残障人士无障碍体验需满足的要求。Replit 目前部分符合 WCAG 2.1 的 AA 级标准。部分符合意味着网站内容的某些部分尚未完全达到无障碍标准。

<div id="status-atual">
  # 当前状态
</div>

Replit 正持续开展一项内部项目，以提升网站的无障碍能力。该项目依据内部评估、开发者访谈和报告，以及康奈尔大学 IT 部门于 2021 年开展的独立评估结果。

网站的大部分内容均以符合现行 W3C HTML 和 CSS 标准的 HTML 格式提供。向您展示的非文本内容 (如图像和表单元素) 均提供文本替代内容，屏幕阅读器可以识别并朗读这些内容。

尽管 Replit 持续致力于提升无障碍体验，您仍可能遇到一些限制。尤其是，无法仅使用键盘完全操作 Workspace 是一个已知问题，Replit 正在努力解决。

<div id="fornecendo-feedback">
  # 提供反馈
</div>

如果您无法访问 Replit 网站，请发送电子邮件至 [contact@replit.com](mailto:contact@replit.com) 提供反馈。请附上您尝试访问的内容的 URL (网址) 、遇到的问题以及您的联系信息。
