</div>

<div id="section-7">
  ## 你们可以一起构建什么
</div>

* **团队分工开发功能**：一个人做前端，另一个人做后端。各自在与 Agent 的对话中推进工作，同时用看板保持全员步调一致。
* **让新成员快速上手**：在自己的 Agent 对话中探索项目、了解运作机制、着手贡献代码——完全不会阻塞其他人。
* **使用 Pro 更快交付**：借助并行执行，2～3 人可以各自派发同时运行的任务。原本一个人要花整整一个会话才能完成的项目，现在只需一小部分时间就能搞定。

<div id="section-8">
  ## 常见问题
</div>

<Accordion title="可以通过 Agent 给团队成员发消息吗？">
  不可以。Agent 不是消息工具——你输入的任何内容，它都会试着去执行。团队沟通请使用 Slack、Discord 或其他工具。
</Accordion>

<Accordion title="我们会覆盖彼此的工作吗？">
  task 系统会为每个 task 提供独立的副本来避免这种情况，同时各 task 之间也能感知彼此的存在。task 完成后，将其应用到主版本，并在这一步解决冲突。
</Accordion>

<Accordion title="可以查看团队成员正在做什么吗？">
  你可以在看板上查看进行中的 task，也能看到光标位置以及团队成员正在查看的文件。
</Accordion>

<Accordion title="可以将某人从项目中移除吗？">
  可以。项目所有者可以随时管理团队成员并撤销其访问权限。
</Accordion>
