<div id="microsoft-app-store-replit-pwa">
  ### Microsoft App Store 上的 Replit PWA
</div>

Replit 现已以渐进式 Web 应用 (PWA) 的形式上架 Microsoft App Store，Windows 构建者可以更轻松地找到并安装 Replit，获得接近原生应用的使用体验。

<div id="section-3">
  ### 创建空白项目
</div>

现在，你可以在导入页面创建空白项目。空白项目启动时不会触发 Agent，因此创建时不消耗积分，同时你可以完全掌控框架和工具的配置。希望获得这种控制粒度的构建者，可在导入页面使用该选项。

<div id="section-4">
  ## 团队与企业版
</div>

<div id="section-5">
  ### 企业版审计日志门户
</div>

企业版审计日志门户 (v1) 现已面向所有企业版客户开放。管理员可以查看组织成员执行的事件，并配置事件流集成，将数据发送至所选的 SIEM 平台，包括 S3、Datadog、Splunk、Google Cloud Storage 和 Microsoft Sentinel。
