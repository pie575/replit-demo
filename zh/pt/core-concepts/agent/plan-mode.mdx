<div id="o-que-o-modo-plan">
  ## 什么是 Plan 模式？
</div>

Plan 模式让你可以：

* **头脑风暴**，为项目探索不同的实现思路
* **规划开发工作**，用结构化的任务清单管理进度
* **与 AI 协作**，共同设计项目架构、规划功能
* **获取策略性建议**并随时提问，而不会改动项目的代码或数据
* 在准备动手实现时，**顺畅切换**到 Build 模式

默认模式现在称为 **Build** 模式。

与 Build 模式不同，Plan 模式专注于规划和构思，帮助你在动手写代码之前把项目想清楚。

<div id="primeiros-passos">
  ## 快速入门
</div>

<div id="acessando-o-modo-plan">
  ### 进入 Plan 模式
</div>

只要 Replit App 启用了 Agent，就可以使用 Plan 模式。进入方式如下：

1. 在项目编辑器中**打开你的 Replit App**
2. 在 Chat 收件箱左下角**找到模式选择器**
3. 在下拉菜单中**选择 Plan 模式**

<div id="principais-recursos">
  ## 主要功能
</div>

<div id="planejamento-de-tarefas">
  ### 任务规划
</div>

Plan 模式擅长将复杂项目拆分为易于管理的任务。向 Agent 提供一些需求后，它会生成一份按顺序排列的任务清单，其中包含完成请求所需的开发任务。

<div id="brainstorming-colaborativo">
  ### 协作式 brainstorming
</div>

与 AI 协作，一起探索不同的实现思路：

* 针对复杂问题的**多种解决路径**
* 不同方案的**利弊分析**
* **风险评估**与缓解策略

<div id="fluxo-de-trabalho-do-planejamento-construo">
  ## 工作流程：从规划到构建
</div>

<div id="1-fase-de-planejamento-modo-plan">
  ### 1. 规划阶段 (Plan 模式) 
</div>

在 Plan 模式下开始开发流程：

* **明确项目范围**和目标
* **将需求拆分**为具体功能
* **规划架构**和技术栈
* **制定开发路线图**，并设定里程碑

<div id="2-aprovao-de-tarefas">
  ### 2. 任务审批
</div>

当 Agent 生成任务清单时：

* **审阅**建议的任务
* 选择**开始构建**以批准该计划

或者继续对话，进一步完善计划。

<div id="3-transio-para-o-modo-build">
  ### 3. 切换到 Build 模式
</div>

准备开始实施时：

* **点击“开始构建”**以批准计划
* **Agent 会自动切换**到 Build 模式
* **Agent 开始实施**已批准的任务
* **跟踪进度**，了解开发进展

Plan 模式的费用与其他 Agent 交互一样，均按工作量计费。您需要为 Agent 在 Plan 模式下完成的所有工作付费，包括回答问题、提供指导和生成任务清单。请求越复杂，或对话上下文越长，费用就越高。

**所有 Agent 交互均需付费**——无论 Agent 是提供文字指导还是修改代码，都会产生费用，不过较简单的请求费用较低。

<div id="melhores-prticas">
  ## 最佳实践
</div>

<div id="prompting-eficaz">
  ### 高效 prompt 技巧
</div>

要充分利用 Plan 模式：

* **明确说明**你的项目需求
* **追问**以厘清 AI 的建议
* 讨论复杂概念时**请求示例**
* **权衡对比**不同方案
* 在确定实现方案前**反复打磨想法**
* 在后续对话中引用重要决策，从而**沉淀关键结论**
