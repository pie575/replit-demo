Les modèles d&#39;IA comme Claude ou GPT sont puissants, mais ils restent limités aux données sur lesquelles ils ont été entraînés. Le Model Context Protocol (MCP) offre une méthode standard pour les connecter à des outils externes, à des sources de données et à des fonctionnalités du monde réel.

<div id="aimcp">
  ## Pourquoi les modèles d&#39;IA ont besoin du MCP
</div>

Sans accès à des outils et à des données externes, les modèles d&#39;IA ne peuvent pas :

* Accéder à des informations récentes
* Interagir avec des systèmes externes
* Exécuter des actions dans le monde réel
* Manipuler des données privées

Le MCP résout ce problème en offrant à l&#39;IA une méthode universelle pour se connecter aux outils et aux données, de la même manière que l&#39;USB-C a standardisé la connexion des appareils.

  <img src="/assets/mirror/mcp-a04e01a01743.avif" alt="Schéma du MCP montrant un modèle d'IA connecté à des outils externes et à des sources de données" width="1920" height="1055" data-path="images/tutorials/mcp.avif" />
</Frame>

Avec le MCP, les modèles d&#39;IA peuvent :

* Accéder à des outils spécialisés et à des API
* Lire des données provenant de sources privées
* Exécuter des actions dans le monde réel
* Se connecter de manière fluide à d&#39;autres systèmes

<div id="mcp">
  ## Fonctionnement de MCP
</div>

L&#39;architecture MCP repose sur trois composants principaux :

1. **Côté client** — Claude, les applications d&#39;IA ou tout autre élément ayant besoin d&#39;accéder à des outils externes.
2. **Couche de communication** — le protocole lui-même, qui normalise le format des requêtes et des réponses.
3. **Côté serveur** — les programmes qui donnent accès à des outils, à des sources de données et à des fonctionnalités spécialisées.

<AccordionGroup>
  <Accordion title="Qu'est-ce qu'un client MCP ?">
    Un client MCP, c&#39;est par exemple Claude, Replit Agent ou une interface en ligne de commande qui se connecte à un grand modèle de langage. C&#39;est le « périphérique » qui se connecte aux outils externes et aux sources de données.

    Exemples de clients MCP :

    * Claude dans le navigateur
    * Replit Agent
    * Les interfaces en ligne de commande pour l&#39;IA
    * Les applications personnalisées créées avec un SDK d&#39;IA
  </Accordion>

  <Accordion title="Qu'est-ce qu'un serveur MCP ?">
    Un serveur MCP met des outils et des fonctionnalités à la disposition des modèles d&#39;IA. Imaginez que vous donniez à l&#39;IA une trousse à outils spécialisée pour résoudre des problèmes.

    Ce que permet un serveur MCP :

    * Accéder à des sources de données précises pour répondre aux questions
    * Connecter l&#39;IA à des API pour lui permettre d&#39;agir en ligne
    * Lire et écrire des fichiers
    * Exécuter des calculs ou du code
    * Récupérer du contenu depuis des services comme Notion, Linear ou Stripe
  </Accordion>
</AccordionGroup>

<div id="mcp-2">
  ## Ce que permet MCP
</div>

MCP définit plusieurs primitives qui renforcent les applications d’IA :

* **Ressources** — partager des données et du contenu avec les modèles d’IA
* **Outils** — permettre aux modèles d’IA d’effectuer des actions via des services
* **Prompts** — modèles réutilisables pour des interactions cohérentes avec l’IA
* **Échantillonnage** — permettre aux services de demander des informations aux modèles d’IA
* **Transport** — connecter efficacement les clients et les serveurs

<div id="vs-mcp">
  ## Compétences vs serveurs MCP
</div>

Les compétences et les serveurs MCP sont les deux principaux moyens d’étendre les capacités des agents IA, chacun ayant un objectif distinct.

|                             | Compétences                                                                                           | Serveurs MCP                                                         |
| --------------------------- | ----------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| **Cas d’utilisation idéal** | Flux de travail, conventions, documents de référence                                                  | Connexion à des services externes, exécution d’actions               |
| **Chargement**              | Léger — seuls le nom et la description sont chargés jusqu’à leur utilisation                          | Lourd — toutes les descriptions d’outils sont chargées dès le départ |
| **Définition**              | La façon dont Agent doit fonctionner                                                                  | Les ressources auxquelles Agent peut accéder                         |
| **Exemple**                 | Compétence « Analyseur d’actions » — recherche des investissements à l’aide d’un framework spécifique | Serveur MCP « Stripe » — lit les données de paiement et d’abonnement |

Pour adopter l’état d’esprit adapté aux compétences, consultez les [compétences Agent](/fr/ja/learn/agent-skills).

<div id="section">
  ## Cas d’utilisation concrets
</div>

MCP permet de créer un large éventail d’applications d’IA :

* **Systèmes de service client** — accéder aux bases de données de l’entreprise pour répondre à des questions précises
* **Assistants de recherche** — rechercher et résumer du contenu provenant de plusieurs sources
* **Outils de productivité** — interagir avec des fichiers et des applications
* **Outils de création de contenu** — accéder aux bibliothèques multimédias et aux plateformes de publication

<div id="section-2">
  ## Avantages
</div>

MCP offre trois principaux avantages :

* Des intégrations prêtes à l’emploi auxquelles l’IA peut se connecter immédiatement
* La possibilité de changer de fournisseur d’IA sans avoir à réécrire les connexions
* Des fonctionnalités de sécurité qui protègent les données sensibles

<Note>
  MCP est une norme émergente, de plus en plus prise en charge dans l’ensemble de l’écosystème de l’IA. De nouveaux outils et intégrations sont ajoutés régulièrement.
</Note>
