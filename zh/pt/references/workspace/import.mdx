通过导入功能，你可以将现有代码或设计引入 Replit Apps，并继续使用 Agent 进行构建。

<div id="fontes-suportadas">
  ## 支持的来源
</div>

| 来源           | 你需要提供的内容                             | 适用场景                     |
| ------------ | ------------------------------------ | ------------------------ |
| GitHub       | 仓库 URL 或仓库选择器                        | 导入公开和私有仓库                |
| Bitbucket    | 仓库 URL 或仓库选择器                        | 导入托管在 Bitbucket 上的仓库     |
| Vercel       | Vercel 项目背后的 GitHub 仓库               | 迁移 Vercel 应用             |
| Figma        | frame URL                            | 将设计稿转换为 React 应用         |
| Bolt         | 从 Bolt 导出的 GitHub 仓库                 | 迁移 Bolt 项目               |
| Lovable      | 从 Lovable 导出的 GitHub 仓库              | 迁移 Lovable 项目            |
| Base44       | 从 Base44 导出的 GitHub 仓库               | 迁移 Base44 项目             |
| ZIP          | 上传 `.zip` 文件                         | 导入本地项目文件                 |
| 电子表格         | `.xlsx`、`.csv` 文件或 Google Sheets URL | 基于表格数据创建应用               |
| 早前的 Agent 导出 | 从早前的 Agent App 导出的 GitHub 仓库         | 重新导入早前的 Agent App        |
| 空白           | 无需提供任何内容                             | 希望不使用 Agent、从空白项目起步的高级用户 |

<Note>Replit 会在开始导入前验证兼容性。</Note>

<div id="fluxo-padro-de-importao">
  ## 标准导入流程
</div>

1. 打开 [replit.com/import](https://replit.com/import)。
2. 选择导入来源。
3. 连接所需账户。
4. 提供仓库 URL、frame URL 或 `.zip` 文件。
5. 添加所需的 Secrets 或环境变量。
6. 选择 **导入功能**，然后查看生成的 App。

<div id="notas-sobre-as-fontes">
  ## 来源说明
</div>

<div id="github">
  ### GitHub
</div>

* 公开仓库可使用快速导入：`https://replit.com/github.com/<owner>/<repo>`。
* 公开和私有仓库均可使用引导式导入。
* 如果你的仓库是导出的 Agent App，Replit 会在导入时保留 Agent 特有的结构。

<div id="bitbucket">
  ### Bitbucket
</div>

* 粘贴 Bitbucket 仓库 URL，或连接你的 Bitbucket 账户来搜索仓库。
* 与托管在 GitHub 上的项目相比，导入时的 Agent 支持可能较为有限。

<div id="figma">
  ### Figma
</div>

* 导入单个 Figma frame 的 URL。
* Replit 会生成 React 代码，随后由 Agent 帮你进一步优化。
* 为获得最佳效果，请使用 frame、auto layout，并为图层取清晰的名称。

<div id="vercel">
  ### Vercel
</div>

* 选择 Vercel 项目所对应的 GitHub 仓库。
* Replit 会导入项目代码和默认配置。
* 在导入过程中填写环境变量的值。

<div id="bolt">
  ### Bolt
</div>

* 导入前，请先将 Bolt 项目导出到 GitHub。
* Replit 会导入代码、界面样式、素材、后端 逻辑 (如果有) 以及数据库架构 (如果有) 。
* Supabase 数据和 secret 值不会被导入。
* 导入完成后，请让 Agent 添加 secrets 并重建数据库中的数据。

<div id="lovable">
  ### Lovable
</div>

* 导入前，请先将你的 Lovable 项目导出到 GitHub。
* Replit 会导入代码、界面样式、素材、后端 逻辑 (如有) 以及数据库架构 (如有) 。
* Supabase 数据和 secret 值不会被导入。
* 导入完成后，可让 Agent 添加 secrets 并重建数据库中的数据。

<div id="base44">
  ### Base44
</div>

* 在导入前，先将你的 Base44 项目导出到 GitHub。
* Replit 会导入代码、设计与样式、素材以及 API 逻辑。
* Base44 的后端 (实体、agents、SDK) 、身份验证和数据不会被导入。
* 导入完成后，可以让 Agent 帮你迁移仍需使用的 Base44 专有功能。

<div id="zip">
  ### ZIP
</div>

* 上传一个具有清晰项目根目录的 `.zip` 文件。
* Replit 会导入文件、依赖项和常见的运行配置。
* 现有的 secret 值、域名和数据库数据不会被导入。

<div id="planilha">
  ### 电子表格
</div>

* 上传 Excel 文件 (`.xlsx`) 或 CSV 文件，或粘贴 Google 表格的公开 URL。
* Agent 会读取表格结构，并创建一个 full-stack 应用，其数据库中已填充你的数据。
* 应用还包含用于查看、搜索和管理记录的界面。

<div id="exportao-anterior-do-agent">
  ### 此前导出的 Agent
</div>

* 从 GitHub 仓库重新导入此前导出的 Agent App。
* Replit 会保留 Agent 特有的结构 (代码、数据库架构、backend 功能) 。
* 数据库中的数据和 secret 的值不会被导入。

<div id="vazio">
  ### 空白
</div>

* 从完全空白的项目开始——没有 Agent、无需选择框架，也没有任何脚手架代码。
* 适合希望完全掌控项目配置的高级用户。

<div id="limitaes">
  ## 限制
</div>

* 不会迁移现有数据库中的数据。
* 某些复杂或专有的依赖项可能需要手动配置。
* 大型项目的处理时间可能较长。

<div id="melhores-prticas">
  ## 最佳实践
</div>

* 导入前请移除敏感凭证。
* 保持源项目结构清晰有序。
* 导入后检查依赖项并运行相关命令。
* 发布前测试核心流程。

<div id="soluo-de-problemas">
  ## 疑难解答
</div>

如果导入失败，请先检查以下几个方面：

* **兼容性错误**：检查是否具备必需的项目文件，以及框架是否受支持。
* **访问错误**：确认仓库或来源的访问权限。
* **处理错误**：简化项目结构或缩减项目体积后重试。

如果问题仍然存在，请访问 [Replit Community Hub](https://replit.com/community) 或[联系支持团队](https://replit.com/support)。

<div id="faturamento">
  ## 账单
</div>

如果导入需要 Agent 执行迁移工作，可能会消耗积分。积分用量取决于项目的复杂程度。
