La Console vous permet de surveiller et de consulter en temps réel les logs affichés par votre Replit App en cours d&#39;exécution.
Les informations issues des exécutions en cours et précédentes vous aident à comprendre le comportement de votre application,
à corriger les erreurs et à optimiser les performances.

<Tip>
  Lors du débogage avec Agent, incluez les logs de la console dans votre prompt afin de fournir du contexte.
</Tip>

<div id="recursos">
  ## Fonctionnalités
</div>

La console fournit les outils suivants pour vous aider à comprendre le comportement de votre application :

* **Journalisation en temps réel** : consultez la sortie de votre application au fur et à mesure
* **Assistance IA** : recevez des suggestions pour corriger les erreurs signalées dans les logs
* **Historique des exécutions** : affichez les logs des exécutions précédentes pour suivre les modifications

<div id="uso">
  ## Utilisation
</div>

Vous pouvez accéder à l&#39;outil Console directement depuis votre Project Editor.

<Accordion title="Accéder à Console">
  Dans le **dock d&#39;outils** à gauche :

  1. Sélectionnez <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Icône Tous les outils" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools** pour afficher la liste des outils du Project Editor.
  2. Sélectionnez <img class="icon-svg" src="/assets/mirror/console-8a41ac90789c.svg" alt="Icône Console" width="16" height="16" data-path="images/icons/console.svg" /> **Console**.

  Dans la **barre de recherche** :

  1. Sélectionnez l&#39;<img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="icône de loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> icône de loupe en haut pour ouvrir l&#39;outil de recherche.
  2. Saisissez « Console » pour trouver l&#39;outil, puis sélectionnez-le dans les résultats.
</Accordion>

Chaque fois que vous utilisez le bouton **Run** dans votre Replit App, Console affiche une nouvelle entrée contenant les informations suivantes :

* La commande ayant exécuté votre code
* Des informations d&#39;horodatage
* Les logs de sortie standard et d&#39;erreur

La capture d&#39;écran suivante montre la commande `npm run dev` utilisée pour démarrer l&#39;application, ainsi que les messages de log de son exécution :

<div id="depurao-com-ia">
  ### Débogage avec l&#39;IA
</div>

Lorsque vous rencontrez des erreurs ou d&#39;autres informations dans les logs que vous souhaitez comprendre, sélectionnez le
bouton **Ask AI** en haut de l&#39;entrée. L&#39;onglet **Agent** s&#39;ouvre alors automatiquement et
le contenu du log est envoyé pour analyse.

<div id="comandos-de-entrada-de-log">
  ### Commandes d&#39;entrée de log
</div>

La Console propose les outils suivants pour gérer vos logs :

* **Show Only Latest** : placez ce commutateur sur **on** pour n&#39;afficher que l&#39;exécution la plus récente.
* **Réduire l&#39;entrée** : sélectionnez la <img class="icon-svg" src="/assets/mirror/down-arrow-9c1cf9fd152e.svg" alt="icône de flèche vers le bas" height="16" width="16" data-path="images/icons/down-arrow.svg" /> flèche vers le bas située à gauche du nom de la commande pour masquer les logs.
* **Effacer les exécutions précédentes** : sélectionnez cette option pour supprimer les logs des exécutions précédentes. Cette action est irréversible.

<div id="disponibilidade-de-rede">
  ### Disponibilité réseau
</div>

Vous pouvez contrôler la disponibilité en ligne de la version de développement de votre application.

Pour ne plus répondre aux requêtes adressées à l&#39;URL de développement, sélectionnez l&#39;icône <img class="icon-svg" src="/assets/mirror/network-off-5bdca8a4fe4e.svg" alt="icône réseau désactivé" height="16" width="16" data-path="images/icons/network-off.svg" /> en forme de globe barré
à droite de la ligne d&#39;informations réseau.

Pour la réactiver, sélectionnez l&#39;icône <img class="icon-svg" src="/assets/mirror/network-on-15be2e5fb4f5.svg" alt="icône réseau activé" height="16" width="16" data-path="images/icons/network-on.svg" /> en forme de globe.

Pour afficher votre URL de développement, sélectionnez le texte `{...}.replit.dev` dans la barre d&#39;adresse.

<Frame>
  <img src="/assets/mirror/preview-dev-url-b36770b33769.png" alt="Emplacement de l'URL de développement dans Preview" width="1222" height="824" data-path="images/workspace/preview-dev-url.png" />
</Frame>

<Note>
  Votre application reste accessible dans l&#39;outil Preview, même lorsqu&#39;elle est configurée pour ne plus répondre aux requêtes adressées à l&#39;URL de développement.
</Note>

<div id="parar-um-comando-de-workflow">
  ### Arrêter une commande de Workflow
</div>

Vous pouvez arrêter une commande de Workflow en cours d&#39;exécution depuis l&#39;outil Console du Project Editor.

Sélectionnez le bouton carré situé à droite de la ligne contenant la commande d&#39;exécution de votre Replit App pour l&#39;arrêter.

Pour relancer votre application, utilisez le bouton **Run** du Workflow en haut du Project Editor.
