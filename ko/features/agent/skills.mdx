<div id="what-is-a-skill">
  ## Skill이란?
</div>

skill은 하나의 폴더입니다. 그 안에는 Agent가 따를 지침이 담긴 `SKILL.md` 파일과, Agent가 참조하기를 원하는 보조 파일들이 함께 들어 있습니다. skill은 project의 `/.agents/skills` 디렉터리에 위치하며, 여러 에이전트에서 공통으로 동작하는 개방형 표준인 [Agent Skills specification](https://agentskills.io/specification)을 따릅니다.

Agent는 설치된 모든 Skill의 이름과 설명을 확인하지만, 현재 task와 관련이 있을 때만 전체 내용을 불러옵니다. 덕분에 skill은 context를 효율적으로 사용하므로, 여러 개를 설치해도 Agent의 결과물 품질이 저하되지 않습니다.

<div id="pre-defined-skills">
  ## 사전 정의된 skills
</div>

Replit은 Chat의 **Use a skill** 선택기와 새 project 시작점 선택기에서 바로 사용할 수 있는 사전 정의된 skills를 기본으로 제공합니다. 이러한 skills는 별도의 설치 없이 모든 project에서 사용할 수 있습니다. 전체 카탈로그와 파트너 skills, 설치 방법은 [Skills directory](/ko/features/agent/skills-directory)를 참조하세요.

사전 정의된 skill을 추가하려면 Chat 입력창에서 **Use a skill** 선택기를 열어 skill을 선택하거나, Agent에게 해당 skill을 불러와 달라고 요청하세요.

<div id="skill-scope">
  ## skill 범위
</div>

skill은 여러 수준으로 범위를 지정할 수 있습니다:

| 범위               | 사용 범위                    | 저장 위치                                                                                          |
| ---------------- | ------------------------ | ---------------------------------------------------------------------------------------------- |
| **프로젝트 수준**      | 특정 project에만 적용          | `/.agents/skills`에 파일과 함께 버전 관리                                                                |
| **workspace 수준** | workspace의 모든 구성원이 사용 가능 | Workspace Settings에서 중앙 관리                                                                     |
| **Enterprise**   | 회사 전체 표준                 | [custom templates](/ko/teams/custom-templates) 및 [design system](/ko/teams/custom-design-system)에 포함 |

workspace 수준 skill은 [Agent Customization](/ko/features/agent/agent-customization)을 참고하여 팀을 위한 workspace skill과 custom instructions를 설정하세요.

<div id="create-a-custom-skill">
  ## custom Skill 만들기
</div>

Workspace 라이브러리에 재사용 가능한 지침을 두려면 custom Skill을 만드세요.
공유 Workspace에서는 Skill을 만들면서 Workspace 구성원 접근 권한을 설정할 수 있고,
나중에 변경할 수도 있습니다. Skill을 관리할 수 있는 사람은 plan에 따라 다릅니다. 자세한 내용은
[Agent Customization](/ko/features/agent/agent-customization)을 참고하세요.

Workspace 구성원 접근 정책은 다음과 같습니다.

| 정책            | 접근 권한                                      |
| ------------- | ------------------------------------------ |
| **Required**  | 항상 켜져 있으며 끌 수 없음                           |
| **Available** | 선택 사항이며 기본값은 꺼짐. 구성원이 사용하려면 직접 Skill을 켜야 함 |
| **No access** | 구성원에게 표시되지 않음                              |

<Steps>
  <Step title="Skills 설정 열기">
    Workspace에서 **Settings** &gt; **Customization** &gt; **Skills**를 엽니다.
  </Step>

  <Step title="custom Skill 시작하기">
    **Add**를 선택한 다음 **Write a skill**을 선택합니다.
  </Step>

  <Step title="Skill 설명하기">
    custom Skill은 다음 항목으로 구성됩니다.

    * **Name**: Workspace 라이브러리에서 Skill을 식별합니다.
    * **Description**: Agent가 이 Skill을 언제 사용해야 하는지 설명합니다.
    * **Instructions**: Agent가 따라야 할 단계를 정의합니다.

    <Frame caption="팀 Workspace에서 custom Skill의 세부 정보를 입력합니다.">
      <img src="/assets/mirror/workspace-custom-skill-create-6d6014e5c561.jpg" alt="이름, 설명, 지침 및 Create skill 버튼이 있는 Team Workspace custom Skill 양식" width="2000" height="1363" data-path="images/replitai/workspace-custom-skill-create.jpg" />
    </Frame>
  </Step>

  <Step title="Workspace 구성원 접근 권한 설정하기">
    새 Skill은 **Private** 상태로 시작하므로 본인과 Workspace 관리자만 사용할 수 있습니다.
    **Sharing** 컨트롤을 선택한 다음 **Members in workspace**에 위 정책 중 하나를 설정합니다.

    <Frame caption="Skill을 만들기 전에 Workspace 구성원 접근 권한을 설정합니다.">
      <img src="/assets/mirror/workspace-custom-skill-create-sharing-00a493b8ba70.jpg" alt="Sharing 컨트롤이 열려 있고 Required, Available, No access 옵션이 표시된 custom Skill 양식" width="2000" height="1154" data-path="images/replitai/workspace-custom-skill-create-sharing.jpg" />
    </Frame>
  </Step>

  <Step title="Skill 만들기">
    세부 정보를 확인한 다음 **Create skill**을 선택합니다.
  </Step>
</Steps>

<div id="share-project-skills">
  ## project Skill 공유
</div>

공유 Workspace에서는 Skill을 만든 뒤에도 구성원의 접근 권한을 변경할 수 있습니다.

<Steps>
  <Step title="Skill 생성 또는 선택">
    위 단계에 따라 custom Skill을 생성하거나, **Settings** &gt; **Customization** &gt; **Skills**에서 기존 Skill을 선택하세요.

    project Skill을 Workspace에 저장하려면 project에서 **Agent Skills** &gt; **Project skills**를 여세요. **Save to workspace**를 선택하고 이름을 입력한 다음 **Save**를 선택하세요.
  </Step>

  <Step title="공유 열기">
    Workspace 라이브러리의 Skill 카드에서 옵션 메뉴를 열고 **Share...**를 선택하세요.

    <Frame caption="생성한 뒤에도 기존 Skill의 메뉴를 열어 공유할 수 있습니다.">
      <img src="/assets/mirror/workspace-skill-share-menu-af1b84e16a3c.jpg" alt="기존 Skill의 옵션 메뉴가 열려 있고 Share 작업이 보이는 Workspace Skills 페이지" width="1600" height="1100" data-path="images/replitai/workspace-skill-share-menu.jpg" />
    </Frame>
  </Step>

  <Step title="Workspace 구성원 접근 권한 설정">
    **Share skill** 대화 상자의 **Members in workspace**에서 위 정책 중 하나를 선택하세요. 선택한 내용은 즉시 적용되며, 별도로 확인할 필요가 없습니다.

    <Frame caption="Workspace 구성원이 Skill에 접근하는 방식을 선택하세요.">
      <img src="/assets/mirror/workspace-skill-sharing-policy-24fbbc668714.jpg" alt="Workspace 구성원에 대한 Required, Available, No access 정책이 표시된 Share skill 대화 상자" width="1500" height="1000" data-path="images/replitai/workspace-skill-sharing-policy.jpg" />
    </Frame>
  </Step>
</Steps>

<Steps>
  <Step title="Workspace Skills 열기">
    Agent에서 **+** &gt; **Use a skill**을 선택해 **Workspace Skills**를 엽니다.

    <Frame caption="플러스 메뉴를 열고 Use a skill을 선택해 Workspace Skills에 접근합니다.">
      <img src="/assets/mirror/workspace-skill-picker-d7c3f5525de2.jpg" alt="Use a skill이 선택된 Agent 플러스 메뉴와 ask-matt, claude-handoff, code-review가 나열된 Workspace Skills 선택기" width="2000" height="1085" data-path="images/replitai/workspace-skill-picker.jpg" />
    </Frame>
  </Step>

  <Step title="Skills 미리 보기">
    공개 GitHub 저장소, 폴더 또는 파일 URL을 붙여넣은 다음 **Preview
    skills**를 선택합니다. 미리 보기는 파일 구조만 확인하며, Skill의
    지침이나 설명은 불러오지 않습니다.

    <Frame caption="공개 GitHub URL을 입력하고 해당 Skill 파일 구조를 미리 봅니다.">
      <img src="/assets/mirror/workspace-skill-github-preview-c8476d8d1556.jpg" alt="공개 GitHub 저장소 URL과 Preview skills 버튼이 있는 Add from GitHub 페이지" width="2000" height="1154" data-path="images/replitai/workspace-skill-github-preview.jpg" />

    감지된 Skills를 확인하고 가져올 항목을 선택한 다음 **Import**를 선택합니다. 버튼에는 **Import 36 skills**처럼 선택한 Skills의 개수가 표시됩니다.

    <Frame caption="감지된 Skills를 확인하고 가져올 항목을 선택합니다.">

  </Step>

</Note>

<div id="how-agent-loads-skills">
  ## Agent가 skill을 불러오는 방식
</div>

Agent는 채팅할 때마다 설치된 모든 skill의 메타데이터(이름과 설명)를 읽습니다. skill의 전체 본문은 Agent가 해당 skill이 현재 task와 관련 있다고 판단한 경우에만 불러옵니다. 이 덕분에 필요해지기 전까지는 skill 내용이 context 창을 차지하지 않습니다.

설치된 skills는 Agent session이 바뀌어도 project에 그대로 유지되며, 팀과 공유할 수 있도록 version control에 commit할 수 있습니다.

<div id="working-with-other-ai-coding-tools">
  ## 다른 AI 코딩 도구와 함께 사용하기
</div>

<Accordion title="다른 AI 코딩 도구에서 skill 가져오기">
  여러 AI 코딩 도구를 함께 사용한다면, Replit을 지원하는 [rulesync](https://github.com/dyoshikawa/rulesync)를 활용해 일관된 설정을 유지할 수 있습니다.

  다른 AI 코딩 어시스턴트에서 skill을 가져오려면 다음과 같이 실행합니다:

  ```bash theme={null}
  npx rulesync init
  npx rulesync import --targets claudecode --features skills
  npx rulesync generate --targets replit --features skills
  ```

  이렇게 하면 여러 개발 환경에서 공통으로 사용할 수 있는 하나의 skill 세트를 유지할 수 있습니다.
</Accordion>
