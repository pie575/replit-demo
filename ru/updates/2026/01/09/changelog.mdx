<div id="new-ai-models-in-integrations">
  ### Новые модели ИИ в интеграциях
</div>

В AI-интеграциях теперь поддерживаются недавно выпущенные модели ИИ:

| Модель                       | Описание                                                                                                                                                    |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `gpt-5.2`                    | Самая мощная модель OpenAI для профессиональной интеллектуальной работы. Первая модель, преодолевшая порог в 90 % на ARC-AGI-1, с контекстным окном 400K.   |
| `claude-opus-4.5`            | Флагманская модель Anthropic, оптимизированная для программирования, агентов и работы с компьютером. Показывает результат 80,9 % на SWE-bench Verified.     |
| `gemini-3-flash-preview`     | Высокоскоростная модель Google для агентных рабочих процессов с контекстом в 1M токенов. Уровень рассуждений близок к Pro при меньшей задержке и стоимости. |
| `gemini-3-pro-preview`       | Продвинутая мультимодальная модель Google с передовыми способностями к рассуждению и знаниями о реальном мире.                                              |
| `gemini-3-pro-image-preview` | Модель Google Nano Banana Pro для высококачественной генерации и редактирования изображений с точной передачей текста.                                      |
