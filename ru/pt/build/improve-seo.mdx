В итоге ваше опубликованное приложение будет выше ранжироваться в поисковых системах — и SEO-оценка в инструменте публикации это отразит.

После каждой успешной публикации Replit выполняет SEO-аудит и показывает SEO-оценку. Если оценке есть куда расти, одним кликом можно передать конкретные проблемы в Agent. Для большинства разработчиков рабочий процесс сводится к следующему: **опубликовать → посмотреть оценку → попросить Agent оптимизировать**.

Подробнее о том, как рассчитывается оценка (аудит Lighthouse, что означает каждая оценка, поддерживаемые типы развёртывания), см. в разделе [SEO-оценка](/ru/pt/features/publishing/seo-rating).

<div id="otimize-com-o-seo-agent">
  ## Оптимизация с SEO Agent
</div>

[SEO Agent](/ru/pt/features/publishing/seo-agent) проводит технический SEO-аудит опубликованного приложения и позволяет исправить каждую выявленную проблему одним кликом. Он находится на панели **Growth** в редакторе проектов и доступен разработчикам на платном тарифе. Выполните следующие шаги, чтобы проверить приложение и применить исправления.

<Steps>
  <Step title="Опубликуйте App, чтобы разблокировать Growth">
    SEO Agent работает только с опубликованным приложением. Пока вы его не опубликуете, панель **Growth** остаётся заблокированной и предлагает **Перейти к публикации**. Опубликуйте приложение через Chat с Agent или с помощью инструмента **Публикация**, а затем вернитесь на панель Growth.

    <Frame caption="До публикации панель Growth заблокирована и предлагает перейти к публикации">
      <img src="/assets/mirror/01-growth-locked-b05c24711f10.png" alt="Панель Growth в заблокированном состоянии с заголовком «Опубликуйте приложение, чтобы разблокировать инструменты Growth» и кнопкой «Перейти к публикации»" width="1657" height="947" data-path="images/deployments/seo-agent/01-growth-locked.png" />
    </Frame>
  </Step>

  <Step title="Выполните verificação с помощью Agent">
    Откройте панель **Growth** и найдите карточку **SEO-рейтинг**. Выберите **Запустить проверку с Agent**, чтобы начать технический SEO-аудит проекта. Проверка обычно занимает несколько минут.

    <Frame caption="Выберите Запустить проверку с Agent на карточке SEO-рейтинг, чтобы начать аудит">
      <img src="/assets/mirror/02-run-scan-94a2b8918fe9.png" alt="Увеличенное изображение карточки SEO-рейтинг с красным прямоугольником, выделяющим кнопку Запустить проверку с Agent" width="1656" height="946" data-path="images/deployments/seo-agent/02-run-scan.png" />
    </Frame>
  </Step>

  <Step title="Исправить с помощью Agent или Исправить всё с помощью Agent">
    Когда проверка завершится, проблемы отобразятся в таблице со столбцами **Серьёзность** (низкая, средняя или высокая) и **Статус** (не устранено). Они сгруппированы по таким категориям, как **Готовность к ИИ**, **Сканируемость и обнаружение**, **Отрисовка и метаданные главной страницы** и **Показатели производительности через прокси**. Разверните любую проблему, чтобы узнать, что обнаружил SEO Agent.

    Применяйте исправления с нужной вам детализацией:

    * **Исправить с Agent** для отдельной проблемы передаёт Agent только эту проблему.
    * **Исправить с Agent** для категории исправляет все проблемы в этой группе.
    * **Исправить всё с Agent** отправляет все проблемы в Agent одновременно. Кнопка **Исправить все проблемы** в чате выполняет то же действие.

    <Frame caption="После проверки исправляйте проблемы по отдельности, по категориям или все сразу с помощью «Исправить всё с Agent»">

    </Frame>
  </Step>

  <Step title="Agent вносит исправления">
    Agent создает задачу по устранению каждой проблемы и выполняет их в фоновом режиме, чтобы вы могли продолжать разработку. В строках отображается статус **Исправление выполняется**, а ссылка **Перейти к задаче** позволяет открыть любую задачу и отслеживать ход выполнения.

    <Frame caption="Agent создает задачи по устранению проблем; в строках проблем отображается статус Исправление выполняется со ссылкой Перейти к задаче">

  <Step title="Примените изменения к основной версии">
    Когда исправление готово, задача переходит в состояние **Готово к проверке**. Просмотрите изменения и нажмите зелёную кнопку **Применить изменения к основной версии**, чтобы внести исправление в ваш app. Опубликуйте приложение заново, чтобы обновить SEO-оценку для новой сборки.

    <Frame caption="Просмотрите каждое исправление и нажмите «Применить изменения к основной версии», чтобы внести его">

    </Frame>
  </Step>
</Steps>

<Tip>
  Вы также можете вообще обойтись без интерфейса проверки. Откройте Agent и скажите **«оптимизируй мой
  SEO»** — Agent возьмёт последние результаты и начнёт с ними работать.
</Tip>

Типичные исправления, которые внесёт Agent:

* Добавление или переписывание отсутствующих либо шаблонных тегов `<title>`, чтобы у каждой страницы был уникальный и содержательный заголовок.
* Добавление метаописания на каждую страницу.
* Добавление описательного текста `alt` к изображениям.
* Установка атрибута `lang` в элементе `<html>`.
* Проверка того, что у ссылок есть понятный текст (без «нажмите здесь» и пустых якорей).
* Добавление `robots.txt` и `sitemap.xml`.
* Добавление meta-тега viewport для корректного отображения на мобильных устройствах.
* Улучшение цветового контраста текста, который не проходит проверки доступности.
* Добавление meta-тегов Open Graph и Twitter card, чтобы ссылки на ваш App хорошо выглядели в социальных сетях.

<div id="melhores-prticas-para-um-app-otimizado-para-seo">
  ## Рекомендации по SEO-оптимизации App
</div>

Поручите это Agent или сделайте сами — вот ключевые моменты, на которые стоит обратить внимание:

* **Укажите для каждой страницы уникальный заголовок и метаописание.** Старайтесь, чтобы заголовки были не длиннее 60 символов, а описания — около 150–160 символов.
* **Используйте семантический HTML.** Оберните раскладку в `<main>`, `<header>`, `<nav>` и `<footer>`. Используйте `<h1>` только один раз на странице и соблюдайте последовательность уровней заголовков.
* **Добавьте alt-текст к каждому изображению.** Описывайте то, что показано на изображении, а не просто сам объект.
* **Создайте `sitemap.xml` и `robots.txt`.** Попросите Agent создать оба файла, чтобы поисковые системы знали, что сканировать.
* **Добавьте теги Open Graph и Twitter card.** Управляйте тем, как ваш App выглядит при публикации в социальных сетях.
* **Используйте пользовательский домен.** Фирменный домен повышает доверие посетителей и поисковых систем. См. [Добавление пользовательского домена](/ru/pt/build/add-custom-domain).
* **Выберите подходящий тип развёртывания.** Для сайтов с большим количеством контента [статические развёртывания](/ru/pt/features/publishing/deployment-types#static) предоставляют предварительно отрисованный HTML, который поисковые системы могут анализировать сразу.
* **Добавьте структурированные данные.** Разметка JSON-LD помогает поисковым системам показывать расширенные результаты для продуктов, статей, FAQ и событий.
* **Поддерживайте высокую скорость App.** Оптимизируйте изображения, избегайте скриптов, блокирующих отрисовку, и используйте хостинг Replit, чтобы сократить время ответа.

Простой способ применить большую часть этого сразу:

<AiPrompt>
  Проведите аудит моего сайта на соответствие рекомендациям по SEO и внесите необходимые исправления. Добавьте sitemap,
  robots.txt, теги Open Graph, структурированные данные там, где это уместно, и убедитесь, что каждая
  страница имеет уникальный заголовок и метаописание.
</AiPrompt>

<div id="precisa-de-mais-ajuda">
  ## Нужна дополнительная помощь?
</div>

* **Оценка не обновилась после повторной публикации:** подождите одну-две минуты — аудит выполняется асинхронно после запуска развёртывания, а бейдж обновится, когда поступят результаты.
* **Оценка не изменилась после изменений, внесённых Agent:** спросите Agent, какие именно пункты Lighthouse он исправил, затем проверьте всплывающую подсказку бейджа, чтобы узнать, какие пункты всё ещё отмечены.
* **У некоторых страниц оценка ниже, чем у других:** бейдж показывает наименьшую оценку среди всех просканированных URL. Попросите Agent сосредоточиться на конкретной странице, которую отметил Lighthouse.
* **В опубликованном App не отображается оценка:** оценки SEO выполняются только для общедоступных веб-развёртываний (Autoscale, Reserved VM, Static). Для запланированных и приватных деплоев оценка не формируется.
