Claude 和 GPT 等 AI 模型功能强大，但受限于训练数据。Model Context Protocol(MCP) 提供了一种标准方式，用于连接外部工具、数据源和现实世界的能力。

<div id="ai-mcp">
  ## 为什么 AI 模型需要 MCP
</div>

如果无法访问外部工具和数据，AI 模型将无法：

* 获取最新信息
* 与外部系统交互
* 在现实世界中采取行动
* 处理个人数据

MCP 为 AI 提供了一种通用的工具和数据连接方式，从而解决了这一问题——就像 USB-C 标准化了设备连接一样。

<Frame>
  <img src="/assets/mirror/mcp-a04e01a01743.avif" alt="展示 AI 模型连接外部工具和数据源的 MCP 示意图" width="1920" height="1055" data-path="images/tutorials/mcp.avif" />
</Frame>

借助 MCP，AI 模型可以：

* 访问专用工具和 API
* 从个人数据源读取数据
* 在现实世界中采取行动
* 无缝连接其他系统

<div id="mcp">
  ## MCP 的工作原理
</div>

MCP 架构由三个主要部分组成：

1. **客户端** — 需要访问外部工具的 AI 模型或应用程序，例如 Claude。
2. **通信层** — 用于标准化请求和响应格式的协议本身。
3. **服务器端** — 提供工具、数据源和专用功能访问权限的程序。

<AccordionGroup>
  <Accordion title="什么是 MCP 客户端？">
    MCP 客户端可以是 Claude、Replit Agent，或连接到大语言模型的命令行界面。它充当连接外部工具或数据源的“设备”。

    MCP 客户端示例：

    * 浏览器中的 Claude
    * Replit Agent
    * 面向 AI 的命令行界面
    * 使用 AI SDK 构建的自定义应用程序
  </Accordion>

  <Accordion title="什么是 MCP 服务器？">
    MCP 服务器为 AI 模型提供工具和功能。它就像为 AI 配备一套专门用于解决问题的工具。

    MCP 服务器可实现的功能示例：

    * 访问特定数据源以回答问题
    * 将 AI 连接到 API，使其能够在线执行操作
    * 读取或写入文件
    * 执行计算或运行代码
    * 从 Notion、Linear、Stripe 等服务获取内容
  </Accordion>
</AccordionGroup>

<div id="mcp-2">
  ## MCP 可实现的功能
</div>

MCP 为 AI 应用定义了多个强大的基础构建模块：

* **资源** — 与 AI 模型共享数据和内容
* **工具** — 让 AI 模型能够通过服务执行操作
* **提示词** — 用于实现一致 AI 交互的可复用模板
* **采样** — 让服务能够向 AI 模型请求信息
* **传输** — 高效连接客户端和服务器

<div id="vs-mcp">
  ## 技能与 MCP 服务器
</div>

技能和 MCP 服务器是扩展 AI 智能体的两种主要方式，适用于不同用途。

|          | 技能                                 | MCP 服务器                      |
| -------- | ---------------------------------- | ---------------------------- |
| **适用场景** | 工作流、惯例、参考资料                        | 连接外部服务、执行操作                  |
| **加载方式** | 轻量 — 调用前仅加载名称和描述                   | 较重 — 预先加载所有工具描述              |
| **定义**   | 智能体应*如何*完成任务                       | 智能体能*访问什么*                   |
| **示例**   | “Stock Analyzer” 技能 — 使用特定框架进行投资分析 | “Stripe” MCP 服务器 — 读取支付和订阅数据 |

如需了解如何理解技能，请参阅 [Agent 技能](/zh/ko/learn/agent-skills)。

<div id="section">
  ## 实际应用场景
</div>

MCP 可实现多种 AI 应用：

* **客户服务系统**：访问企业数据库并解答具体问题的系统
* **研究助手**：从多个来源检索并总结内容的工具
* **生产力工具**：与文件和应用程序交互的工具
* **内容生成工具**：访问媒体素材库和发布平台的工具

<div id="section-2">
  ## 优势
</div>

MCP 提供三项主要优势：

* 可立即连接 AI 的开箱即用集成
* 无需重写连接，即可在不同 AI 提供商之间切换
* 保护敏感数据的安全功能

<Note>
  MCP 是一项新兴标准，正在整个 AI 生态系统中获得越来越广泛的支持，并且会定期新增工具和集成。
</Note>
