[Replit 移动应用](https://replit.com/mobile)把你的项目装进口袋：无论身在何处，都能从上次中断的地方继续，或从零开始全新创作。借助专为触控优化的界面，你可以与 Agent 对话、编辑项目并发布到网页。

<div id="como-comear">
  ## 快速开始
</div>

按照以下步骤安装应用并创建项目。

<div id="instale-o-app">
  ### 安装应用
</div>

1. 访问[移动应用下载页面](https://replit.com/mobile)，安装与你的移动设备操作系统相对应的应用。
2. 打开应用，注册新账户或使用已有账户登录。
   如果注册新账户，你需要验证电子邮件地址才能完成注册。

<div id="comece-a-construir">
  ### 开始构建
</div>

主屏幕提供两条路径：

* **接着上次继续**：在 **Recent Projects** 中打开一个项目继续构建。
* **从零开始构建**：在提示词输入框中描述你想要的内容并发送，Agent 会立即开始构建你的项目。

若想从现成模板或已有代码开始，请点击右上角的 ⋮，然后选择 **Remix a Template** 或 **Import from GitHub**。

<Note>
  正在构建 iOS 原生应用？请在 [replit.com](https://replit.com) 上使用 Project Editor 创建、Preview、编译或提交你的应用。在支持的地区，你也可以在 Android 版 Replit 应用中开展原生移动应用的相关工作。
</Note>

<div id="recursos-mobile">
  ## 移动端功能
</div>

<div id="entrada-por-voz">
  ### 语音输入
</div>

在 Agent 的提示词输入框中使用语音选项，无需动手打字即可描述你想构建或修改的内容。

<div id="live-activities">
  ### 实时活动
</div>

随时随地掌握 Agent 的进展。当 Agent 开始运行时，你会收到一条通知：在锁屏界面点按 **Allow**，无需打开 Replit 即可查看进度。

<Accordion title="支持的设备">
  * 搭载 iOS 18 或更高版本的 iPhone
  * 搭载 iOS 18 或更高版本的 iPad
  * 搭载 macOS Tahoe 或更高版本的 Mac
  * 已配对的 Apple Watch
</Accordion>

<div id="notificaes">
  ### 通知
</div>

无论身在何处，都能及时收到重要更新。进入 **Settings**，打开 **Notifications** (例如在 **User** 下) 。确认通知已开启，并在出现提示时点按 allow。

Replit 会在以下情况通知你：

* Agent 需要你的协助
* Agent 完成工作
* 有重要的计费更新

<div id="modo-de-teclado-para-tablet">
  ### 平板键盘模式
</div>

为平板电脑连接键盘，即可获得针对大屏幕优化的创作体验。首次在连接键盘的情况下打开 Project Editor 时，系统会询问你是否启用该模式。

你可以随时前往 **Account** &gt; **Keyboard Settings** 启用或禁用此模式。

<div id="upgrade-e-cobrana">
  ## 升级与计费
</div>

要在应用内升级到 Core，请进入 **Account**，点击 **Upgrade**，选择你的方案，然后点击 **Continue with Core**。Pro 无法在移动应用内购买，只能在 [replit.com](https://replit.com) 上购买。

若要在订阅所含额度用完后继续使用 Agent，请添加支付方式以启用[基于用量的计费](/zh/pt/billing/about-usage-based-billing)：

* **网页端**：访问 replit.com，打开 **Settings** → **Account** → **Billing**。
* **应用内 (iOS 仅限美国)&#x20;**：打开 **Settings** → **Billing** (或 **Account** → **Billing**) 。
