Выберите подходящий тариф для своей организации. **Pro** — тариф для команд: до 15 разработчиков с общими кредитами и без платы за пользователя. **Enterprise** предлагает расширенные возможности безопасности, соответствия требованиям и поддержки для более крупных организаций. Если у вас несколько организаций Teams, каждый workspace будет переведён на отдельную подписку Pro до конца текущего периода; после миграции вы сможете их объединить.

<div id="pro">
  ## Pro
</div>

Pro предлагает общие ресурсы и инструменты для совместной работы серьёзных разработчиков и команд:

* **До 15 разработчиков**: Без платы за пользователей — все работают в рамках одного тарифа с общими кредитами
* **Уровни кредитов**: Несколько уровней. Неиспользованные кредиты переносятся в течение {ProCreditRolloverPeriod}. Актуальные уровни указаны на [странице цен](https://replit.com/pricing)
* **Turbo Mode**: Agent работает в 2,5 раза быстрее при включении отдельного переключателя (по умолчанию отключён). Доступен в Pro и Enterprise; в Enterprise администратор должен сначала включить его для организации.
* **Приватные развёртывания**: Безопасный хостинг приложений с контролируемым доступом
* **Места для наблюдателей**: Возможность для заинтересованных лиц и неразработчиков использовать опубликованные приватные приложения
* **Единые настройки**: Организуйте приложения, отслеживайте использование в workspace и управляйте биллингом и пользователями в одном месте

<div id="enterprise">
  ## Enterprise
</div>

Enterprise включает все возможности Pro, а также расширенные средства безопасности, контроля и поддержки для организаций:

<CardGroup cols={2}>
  <Card title="Безопасность Enterprise" icon="shield-check">
    Платформа, соответствующая стандарту SOC 2, с SSO/SAML, автоматической подготовкой пользователей через SCIM и расширенными средствами безопасности.
  </Card>

  <Card title="Централизованное управление" icon="folder-open">
    Управляйте командами, биллингом и ресурсами в единой панели. Отслеживайте использование и эффективно контролируйте расходы.
  </Card>
</CardGroup>

* **SSO/SAML с автоматической подготовкой пользователей через SCIM**: Безопасный доступ команды с единым входом и автоматической подготовкой пользователей
* **Выделенная среда разработки**: Управление доступом на основе ролей с использованием групп IdP для детализированных разрешений
* **Административные элементы управления**: Требуйте приватные развёртывания и включайте статическую проверку безопасности перед публикацией
* **Центр безопасности Workspace**: Выявляйте CVE в зависимостях по уровню серьёзности. Просматривайте затронутые приложения и скачивайте SBOM для соответствия требованиям.
* **Настраиваемые разрешения для интеграций**: Устанавливайте ограничения доступа для встроенных интеграций во всей организации
* **Более мощные VM для deployment**: Используйте VM большего размера для масштабируемого хостинга приложений
* **Выделенная поддержка**: Обращайтесь к выделенному менеджеру по работе с клиентами и инженеру по продажам за поддержкой платформы
* **Коннекторы данных Enterprise**: Подключайтесь к Snowflake, BigQuery и Databricks для бесшовной интеграции данных
* **Неограниченное число мест для наблюдателей**: Предоставляйте заинтересованным сторонам и неразработчикам неограниченный доступ к вашим опубликованным приватным приложениям

<div id="casos-de-uso">
  ## Варианты использования
</div>

Pro и Enterprise отвечают различным потребностям организаций любого масштаба:

* **Корпоративные приложения**: Создавайте и публикуйте критически важные приложения с безопасностью и масштабируемостью корпоративного уровня
* **Бизнес-инструменты**: Разрабатывайте и поддерживайте бизнес-инструменты со встроенным управлением доступом
* **Быстрое прототипирование**: Ускоряйте инновации благодаря мгновенно доступным средам разработки
