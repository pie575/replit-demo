Enterpriseモデルコントロールを使用すると、アカウント管理者はビルダーが選択できるAgentモデルを管理できます。アカウント全体のポリシーを設定した後、個々のワークスペースに対して異なるモデルアクセスを設定できます。

<Note>
  モデルコントロールはEnterpriseアカウントのアカウント管理者のみが利用できます。組織で有効にするには、[sales@replit.com](mailto:sales@replit.com)まで営業チームにお問い合わせください。
</Note>

## インテリジェントなモデルルーティングを使う

インテリジェントなモデルルーティングは、EnterpriseワークスペースのデフォルトのAgentエクスペリエンスです。**Auto mode**をオンにすると、品質とコストのバランスを取りながら、Replitが各タスクに最適なモードとモデルを選択します。

ルーティングは、アカウントおよびワークスペースのポリシーで許可されたモデルのプールから選択します。そのプール外のプロバイダーとモデルは選択できません。ビルダーは**Auto mode**をオンのままにしておくこともできますし、オフにして許可されたモデルを手動で選択することもできます。

## Agentモデル設定を開く

1. **Settings**を開きます。
2. **Account**の下で**Advanced**を選択します。
3. **Agent modes and model providers**を展開します。

## プロバイダーポリシーを設定する

<Steps>
  <Step>
    管理したいモデルプロバイダーを選択します。
  </Step>

  <Step>
    **Account policy**の下で、以下のいずれかのオプションを選択します：

    | オプション               | 結果                                    |
    | ------------------- | ------------------------------------- |
    | **Enable all**      | プロバイダーのすべてのモデルがすべてのワークスペースで利用可能になります。 |
    | **Enable selected** | ワークスペースごとに利用可能なモデルを選択できます。            |
    | **Disabled**        | どのワークスペースもプロバイダーのモデルを使用できません。         |

    <Note>
      OpenAI、Anthropic、Googleのうち少なくとも1つのモデルは有効のままにする必要があります。他のプロバイダーは無効にできます。
    </Note>
  </Step>

  <Step>
    **Update**を選択します。
  </Step>
</Steps>

オープンソースのモデルプロバイダーはデフォルトで無効になっています。利用可能にするには、**Enable all**または**Enable selected**を選択し、**Update**を選択します。

## ワークスペースポリシーを設定する

ワークスペースごとに異なるモデルアクセスが必要な場合は**Enable selected**を使用します。

<Frame caption="Enable selectedに設定されたAnthropicプロバイダーポリシーと、ワークスペースごとに設定されたモデルアクセス。">
  <img src="/assets/mirror/anthropic-account-policy-workspace-models-38c0f71a609d.jpg" alt="Enable selectedに設定されたAnthropicアカウントポリシーと、ワークスペース用のモデルトグル" width="2000" height="930" data-path="images/workspace/anthropic-account-policy-workspace-models.jpg" />
</Frame>

1. プロバイダー設定を開きます。
2. **Account policy**を**Enable selected**に設定します。
3. **Workspace**リストで、対象のワークスペースの**Setting**ドロップダウンを選択します。
4. そのワークスペースで各モデルをオン・オフします。
5. **Update**を選択します。

**Update**を選択する前に、**Copy to all**を選択すると、現在のワークスペースのモデル選択をアカウント内のすべてのワークスペースに適用できます。

## 制限事項

* モデルポリシーはワークスペースに適用されます。同じワークスペース内のユーザーグループごとに異なるポリシーを設定することはできません。
* インテリジェントなモデルルーティングは、アカウントまたはワークスペースのポリシーを上書きしません。無効化されたプロバイダーやモデルを選択することはできません。
* **Agent modes and model providers**内の**Fast mode models**トグルは、アカウント上のすべてのワークスペースにわたる高速モデルバリアントへのアクセスを制御します。プロバイダーポリシーとインテリジェントなモデルルーティングは、その設定を変更しません。
