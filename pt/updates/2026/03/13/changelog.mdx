export const YouTubeEmbed = ({videoId, title = "YouTube video", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

### Apresentando o Replit Agent 4

<YouTubeEmbed videoId="bAUVQfz_SIY" title="Introducing Replit Agent 4" />

O Agent 4 chegou. Construído para a criatividade, o Agent é seu parceiro criativo de IA — transformando suas ideias em apps, designs, slides e muito mais, tudo a partir de linguagem natural. Sem necessidade de programação.

Com o Agent 4, você pode:

* **Construir qualquer coisa**: criar apps web, apps móveis, painéis de dados, ferramentas com IA e muito mais
* **Design antes de construir**: explorar mockups no [Design Canvas](/pt/learn/projects-and-artifacts/canvas) antes de se comprometer com o código
* **Planejar seu projeto**: usar o [Modo de Planejamento](/pt/core-concepts/agent/plan-mode) para mapear sua criação antes de qualquer código ser escrito
* **Executar tarefas em paralelo**: o Agent lida com várias tarefas ao mesmo tempo para que você possa avançar mais rápido
* **Colaborar com colegas**: convide outras pessoas para o seu projeto e construam simultaneamente
* **Conectar suas ferramentas**: extraia dados do BigQuery, Linear, Slack, Notion e muito mais diretamente do chat
