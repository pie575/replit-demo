<div id="section-2">
  ### Сканирование безопасности во время разработки
</div>

Теперь Agent в рамках код-ревью проверяет изменённые файлы на наличие распространённых проблем безопасности. Автоматическое сканирование Semgrep выявляет рискованные паттерны кода и жёстко прописанные секреты, благодаря чему Agent может устранить найденные вероятные проблемы ещё до завершения задачи.

Подробнее см. в разделе [Сканирование безопасности во время разработки](/ru/ja/features/security/project-security-center#security-scan-while-you-build).

<div id="section-4">
  ### Повторная генерация учётных данных production-базы данных
</div>

Теперь учётные данные нужной production-базы данных можно сгенерировать заново в инструменте **База данных**. Replit обновит учётные данные, а если у приложения есть активные поддерживаемые развёртывания, запустит повторное развёртывание, чтобы они продолжили работать с новыми учётными данными. Не забудьте обновить внешние инструменты, которые используют старую строку подключения.

<div id="sso">
  ### Разработка с SSO
</div>

Пользователи Pro теперь могут настраивать Enterprise SSO для приложений Replit, использующих [Clerk Auth](/ru/ja/features/auth-and-identity/clerk-auth). Попросите Agent внести необходимые изменения в аутентификацию, и он перенаправит вас в панель управления Clerk. Там можно подключить Okta или Microsoft Entra ID через OIDC или SAML. Enterprise SSO-подключения бесплатны до 1 октября 2026 года. После этого будет взиматься плата Clerk за сквозную передачу данных. Поддержка Enterprise появится в ближайшее время.

<div id="section-6">
  ### Перемещение проектов между рабочими пространствами
</div>

Из списка **Проекты** теперь можно перемещать проекты между командными рабочими пространствами в рамках одного платёжного аккаунта. Перенос выполняется в фоновом режиме и не может быть отменён. Связанные секреты аккаунта не переносятся вместе с проектом, поэтому свяжите их заново в целевом рабочем пространстве.
