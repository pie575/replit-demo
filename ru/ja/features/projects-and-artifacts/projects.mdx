<div id="section">
  ## Что такое проект?
</div>

Проект — это контейнер для всего, что вы создаёте в Replit. В нём хранятся код, данные и все создаваемые артефакты (веб-приложения, мобильные приложения, слайд-презентации, дашборды с данными, видео). Вы описываете Agent, что хотите получить, а он настраивает проект и создаёт в нём артефакты.

Представьте проект как рабочее место на вашем столе: всё находится в одном месте и пользуется общей информацией, но каждая часть выполняет свою задачу.

Например, если попросить Agent создать приложение для отслеживания тренировок, он создаст проект с артефактом мобильного приложения, а также бэкендом, базой данных и хранилищем, необходимыми для его работы.

<ArtifactGrid />

Ключевые понятия:

* **Проект**: контейнер, в котором хранится всё — код, данные, все артефакты
* **Артефакт**: публикуемый результат внутри проекта (веб-приложение, слайд-презентация, видео и т. д.)
* **Ресурсы**: любой артефакт автоматически получает доступ к бэкенду, базе данных и файловому хранилищу — без какой-либо настройки

<Note>
  При публикации проект развёртывается целиком. Все артефакты публикуются одновременно, поэтому они всегда синхронизированы.
</Note>

  ## Что можно создать
</div>

| Тип                                                                          | Описание                                                                   | Примеры                                                            |
| ---------------------------------------------------------------------------- | -------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| **[Веб-приложения](/ru/ja/features/artifact-types/web-apps)**                   | Сайты и веб-приложения, доступные в браузере                               | Интернет-магазин, сервис бронирования, сайт-портфолио              |
| **[Мобильные приложения](/ru/ja/features/artifact-types/building-mobile-apps)** | Нативные приложения, устанавливаемые на смартфон                           | Трекер тренировок, приложение для заказа еды                       |

| **[Слайд-презентации](/ru/ja/features/artifact-types/slide-decks)**             | Слайды, которые можно показать или экспортировать                          | Питч-деки, обновления для команды, обзоры продукта                 |
| **[Анимация](/ru/ja/features/artifact-types/animated-videos)**                  | Видео с моушн-графикой, экспортируемые в MP4                               | Ролики о запуске продукта, объясняющие видео, контент для соцсетей |
| **3D-игры**                                                                  | 3D-игры, симуляции и интерактивные проекты                                 | Головоломки, физические симуляции, интерактивные проекты           |
| **[дизайн](/ru/ja/design/canvas)**                                              | Визуальные концепции и прототипы для исследования на Canvas                | Мудборды, макеты, дизайн-исследования                              |

Один проект может содержать несколько артефактов. Например, в одном проекте можно создать веб-приложение для клиентов, мобильное приложение для команды и слайд-презентацию для инвесторов. Артефакты внутри одного проекта автоматически используют общие данные и логику бэкенда. Подробнее см. в разделе [Артефакты](/ru/ja/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project).

<div id="section-3">
  ## Управление проектами
</div>

На странице проектов отображаются все проекты, которые вы создали или в которые вас пригласили. Это самый быстрый способ вернуться к недавней работе и найти нужный проект в загруженном рабочем пространстве.

<div id="section-4">
  ### Просматривайте содержимое каждого проекта с первого взгляда
</div>

На каждой карточке проекта отображаются небольшие значки входящих в него артефактов — по одному для каждого веб-приложения, мобильного приложения, слайд-презентации, визуализации данных и анимации. При наведении курсора на значок прямо на карточке появляется скриншот соответствующего артефакта, так что проекты можно различать, не открывая их.

<div id="section-5">
  ### Фильтрация по артефактам
</div>

Используйте раскрывающийся список **Тип сборки** в верхней части страницы проектов, чтобы отфильтровать список по артефактам. При выборе одного из вариантов отображаются только проекты, содержащие артефакты этого типа:

* **Веб** — проекты с веб-приложениями
* **Мобильные** — проекты с мобильными приложениями
* **Данные** — проекты с визуализацией данных
* **Слайды** — проекты со слайд-презентациями
* **Дизайн** — проекты в режиме дизайна
* **3D-игры**, **Агенты и автоматизация** и другие

Чтобы сбросить фильтр, выберите **Все типы сборки**.

<div id="section-6">
  ### Сортировка по времени последнего открытия
</div>

По умолчанию проекты на странице проектов отсортированы по **времени, когда вы открывали их в последний раз**: те, над которыми вы работали недавно, оказываются вверху. Это особенно удобно в командных рабочих пространствах — свежие правки других участников не вытесняют то, над чем работаете вы.

Чтобы изменить порядок сортировки, выберите другой заголовок столбца (например, **Последнее изменение** или **Название**).

<div id="section-7">
  ### Закрепление часто используемых проектов
</div>

Закрепите проект, чтобы он всегда отображался в начале списка. Закрепления **видны только вам** — если вы закрепите проект в командном рабочем пространстве, у других участников ничего не изменится.

Чтобы закрепить проект, откройте меню дополнительных действий (три точки) на карточке проекта и выберите **Закрепить**. Чтобы снять закрепление, выберите **Открепить** в том же меню.
