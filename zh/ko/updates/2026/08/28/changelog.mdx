<div id="section-2">
  ### 智能模型路由
</div>

智能模型路由会在质量与成本之间取得平衡，自动为任务选择最合适的模型和 Effort 级别。在 **Power** 或 **Max** 中选择 **Auto** 后，Replit 会随着任务复杂度的变化，为任务的各个环节分别进行路由。如果需要更精细的控制，你也可以手动指定模型和 Effort 级别。

<div id="growth-skills">
  ### 借助 Growth Skills 找到首批客户
</div>

与 Agent 一起运行 [Growth Skills](https://replit.com/growth-kit)，为你的应用找到首批客户。可用的合作伙伴集成包括 Apollo、Clay、SideShift、RevenueCat、Stripe 和 PostHog。

</Frame>

<div id="enterprise">
  ### 面向 Enterprise 的智能模型路由
</div>

智能模型路由现已成为 Enterprise 工作区的默认 Agent 模式。开启 **Auto mode** 后，Replit 会为每项任务选择最合适的模式和已允许的模型。账户管理员可按工作区控制模型的可用范围，也可以关闭 **Auto mode**，自行选择已启用的模型。Enterprise 的 Agent 模式菜单现在提供 **Power** 和 **Max**，不再包含 **Lite**。

<Frame caption="开启 Auto mode，让 Replit 为每项任务选择最合适的模式和模型。">
  <img src="/assets/mirror/enterprise-auto-mode-9365b7d49c0d.png" alt="开启 Auto mode 且模型固定为 Auto 的 Agent 设置" width="558" height="356" data-path="images/changelog/2026-08-28/enterprise-auto-mode.png" />
</Frame>

进一步了解 [Enterprise 模型控制](/zh/ko/features/collaboration/enterprise-model-controls)。

<div id="section-4">
  ### 自定义连接器
</div>

Enterprise 组织现在可以为连接器使用自定义 OAuth 配置。例如，你可以不使用 Replit 的默认值，而是用自己的 **Client ID**、**Client Secret** 和 **scopes** 来配置 Gmail。

<Frame caption="在 Gmail 连接器中选择 Use custom configurations。">
  <img src="/assets/mirror/gmail-custom-configuration-43a0bdec6ddb.png" alt="已选择 Use custom configurations 的 Gmail 连接器设置及 Google Cloud 凭据设置指引" width="1304" height="1564" data-path="images/changelog/2026-08-28/gmail-custom-configuration.png" />
</Frame>

了解如何[为连接器配置自定义 OAuth 应用](/zh/ko/features/integrations/overview#configuring-oauth-app-with-replit)。
