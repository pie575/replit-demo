title: "Устранение неполадок в мобильных приложениях"
description: "Решение распространённых проблем при создании мобильных приложений с Expo и React Native в Replit."
---

При создании мобильных приложений в Replit вы можете столкнуться с проблемами в Preview, при сборке бандла или с зависимостями пакетов. Это руководство поможет решить распространённые проблемы: от быстрых исправлений до более подробных шагов отладки.

<div id="correes-rpidas">
  ## Быстрые решения
</div>

Начните с них — они устраняют большинство проблем:

| Проблема                            | Что попробовать                                                   |
| ----------------------------------- | ----------------------------------------------------------------- |
| Изменения не появляются на телефоне | Встряхните телефон, чтобы открыть меню Expo, и нажмите **Reload** |
| Изменения не появляются в Preview   | Нажмите **R** в консоли, чтобы пересобрать бандл                  |
| App завис или не отвечает           | Остановите и снова запустите app из консоли                       |

<div id="problemas-comuns">
  ## Распространённые проблемы
</div>

<AccordionGroup>
  <Accordion title="Изменения не отображаются на устройстве">
    Если вы внесли изменения, но не видите их на телефоне:

    1. **Встряхните телефон**, чтобы открыть меню разработчика Expo
    2. Нажмите **Reload**, чтобы заново загрузить бандл

    В веб-версии Preview нажмите **R** в консоли, чтобы пересобрать бандл.

    Если изменения по-прежнему не отображаются, попробуйте очистить кэш (см. [Очистка кэша Metro](#clear-the-metro-cache) ниже).
  </Accordion>

  <Accordion title="Красный экран ошибки в Expo Go">
    Красный экран ошибки обычно означает ошибку JavaScript или отсутствие модуля. Прочитайте сообщение об ошибке — оно часто указывает на конкретный файл и строку.

    **Распространённые причины:**

    * Пакет не установлен или установлена неправильная версия
    * Модуль работает в веб-версии, но не на нативной платформе (или наоборот)
    * Синтаксическая ошибка в коде

    **Что попробовать:**

    1. Внимательно прочитайте сообщение об ошибке — часто в нём прямо указано, что не так
    2. Попросите Agent помочь исправить ошибку, отправив ему сообщение об ошибке
    3. Если ошибка упоминает конкретный пакет, попробуйте переустановить зависимости (см. [Переустановка пакетов](#reinstall-packages))
  </Accordion>

  <Accordion title="Приложение работает в веб-версии, но аварийно завершается на телефоне (или наоборот)">
    Некоторые пакеты или возможности по-разному работают на разных платформах. React Native компилируется для трёх платформ: iOS, Android и веба. Библиотека, работающая в веб-версии, может не поддерживать нативные платформы или требовать другой настройки.

    **Что попробовать:**

    1. Проверьте в документации пакета, поддерживает ли он вашу платформу
    2. Спросите Agent: &quot;Совместим ли этот пакет с Expo Go?&quot;
    3. Если функция не поддерживается на мобильных устройствах, рассмотрите возможность перенести её на сервер

    <Tip>
      При поиске пакетов ищите &quot;Expo compatible&quot; или ознакомьтесь с [документацией Expo SDK](https://docs.expo.dev/versions/latest/) для поддерживаемых модулей.
    </Tip>
  </Accordion>

  <Accordion title="QR-код не сканируется или приложение не подключается">
    **Проверьте сеть:**

    * Телефон и компьютер должны быть подключены к одной сети WiFi
    * Некоторые корпоративные или общедоступные сети блокируют подключение

    **Попробуйте режим tunnel:**
    Если вы используете сеть с ограничениями, режим tunnel направляет трафик через серверы Expo. Попросите Agent запустить приложение в режиме tunnel или выполните `npx expo start --tunnel` в Shell.

    **Перезапустите Expo Go:**
    Полностью закройте Expo Go и снова откройте его перед сканированием.
  </Accordion>

  <Accordion title="Сборка занимает слишком много времени">
    Первая сборка всегда медленнее, поскольку кэш ещё не создан. Последующие сборки должны выполняться быстрее.

    **Что влияет на время сборки:**

    * Количество пакетов в проекте
    * Первый запуск после очистки кэша
    * Скорость сети при загрузке пакетов

    Если сборка стабильно выполняется медленно, проверьте, не установлены ли ненужные пакеты.
  </Accordion>

  <Accordion title="Ошибки «модуль не найден»">
    Если вы видите &quot;Unable to resolve module&quot; или &quot;Module not found&quot;:

    1. Возможно, пакет не установлен — попросите Agent установить его
    2. Возможно, пакет установлен, но кэш устарел — очистите кэш
    3. Возможно, пакета не существует или его название указано неверно — проверьте название пакета

    Попробуйте [переустановить пакеты](#reinstall-packages), если модуль должен быть доступен.
  </Accordion>
</AccordionGroup>

<div id="comandos-de-depurao">
  ## Команды для отладки
</div>

Если быстрые решения не помогают, эти команды позволяют сбросить различные кэши и состояния. Выполните их в Shell.

<div id="limpar-o-cache-do-metro">
  ### Очистка кэша Metro
</div>

Metro — это сборщик, который компилирует ваш код React Native. Очистка кэша заставляет выполнить сборку заново.

В Shell выполните:

```bash theme={null}
npx expo start --clear
```

Это очищает кэш сборщика и перезапускает сервер разработки. В выводе появится сообщение &quot;Bundler cache is empty. Rebuilding.&quot;.

<Tip>
  Если проблемы с кэшем возникают часто, добавьте `-c` в команду запуска. Попросите Agent обновить команду разработки, включив в неё флаг очистки.
</Tip>

<div id="reinstalar-pacotes">
  ### Переустановка пакетов
</div>

Если появляются ошибки модулей или несовместимость версий, часто помогает переустановка пакетов.

В Shell выполните:

```bash theme={null}
rm -rf node_modules && npm install
```

Эта команда удаляет все установленные пакеты и заново устанавливает их с нуля на основе файла `package.json`.

<Note>
  Если в проекте используется другой менеджер пакетов (например, `bun` или `pnpm`), выполните соответствующую команду установки: `bun install` или `pnpm install`.
</Note>

<div id="verificar-incompatibilidades-de-verso">
  ### Проверка несовместимости версий
</div>

Expo Doctor проверяет ваш проект на наличие распространённых проблем, например несовместимости версий пакетов.

В Shell выполните:

```bash theme={null}
npx expo-doctor
```

Просмотрите вывод на наличие предупреждений. Если предлагаются исправления, внимательно их оцените — не обновляйте пакеты вслепую, это может привести к новым проблемам.

<Warning>
  Обновляйте пакеты только при наличии конкретной причины. Обновление &quot;просто так&quot; может сломать ваш App, если в новой версии есть несовместимые изменения.
</Warning>

<div id="reset-completo">
  ## Полный сброс
</div>

Когда больше ничего не помогает, полный сброс очищает все кэши и переустанавливает всё заново.

<Accordion title="Крайняя мера: команда полного сброса">
  Эта команда удаляет все кэши и переустанавливает пакеты с нуля. Используйте её в крайнем случае.

  ```bash theme={null}
  rm -rf node_modules .expo && npm cache clean --force && npm install && npx expo start --clear
  ```

  **Что она делает:**

  1. `rm -rf node_modules` — удаляет установленные пакеты
  2. `rm -rf .expo` — удаляет локальный кэш Expo
  3. `npm cache clean --force` — очищает глобальный кэш npm
  4. `npm install` — переустанавливает все пакеты
  5. `npx expo start --clear` — запускает проект с чистым кэшем Metro

  После выполнения этой команды следующая сборка займёт больше времени, так как всё будет собрано заново.
</Accordion>

<div id="limpar-cache-no-seu-dispositivo">
  ### Очистка кэша на устройстве
</div>

Если приложение на телефоне продолжает работать со старым кодом даже после перезагрузки:

* **iOS**: в Expo Go откройте **Settings** и нажмите **Clear Cache**
* **Android**: откройте **Settings &gt; Apps &gt; Expo Go &gt; Storage &gt; Clear Cache**

  ## Краткая справка
</div>

| Проблема                                | Сначала попробуйте          | Затем попробуйте                 |
| --------------------------------------- | --------------------------- | -------------------------------- |
| Изменения не появляются                 | Встряхните телефон → Reload | Очистить кэш Metro               |

| Изменён app.json                        | Перезапустите сервер        | —                                |

<div id="obtendo-mais-ajuda">
  ## Как получить дополнительную помощь
</div>

Если проблема сохраняется:

* **Спросите Agent**: опишите ошибку и то, что вы уже пробовали. Agent часто может сам определить причину и устранить проблему.
* **Загляните в документацию Expo**: [руководство Expo по устранению неполадок](https://docs.expo.dev/troubleshooting/overview/) охватывает дополнительные сценарии.
* **Поищите ошибку в интернете**: скопируйте точный текст сообщения об ошибке и выполните поиск — скорее всего, кто-то уже сталкивался с тем же.
