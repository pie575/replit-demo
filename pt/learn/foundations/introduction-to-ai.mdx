As ferramentas de IA ajudam você a dar instruções em linguagem natural e obter resultados úteis de volta. No Replit, esse resultado pode se tornar planos, código, designs, explicações, etapas de depuração e alterações no seu projeto.

Você não precisa entender IA profundamente antes de começar a construir. Alguns conceitos ajudam você a dar instruções melhores e avaliar os resultados com confiança.

## Modelos de linguagem de grande porte

A maioria dos construtores de IA é alimentada por modelos de linguagem de grande porte, frequentemente chamados de LLMs. Um LLM é um modelo treinado para reconhecer padrões em texto e gerar texto que segue esses padrões.

Texto pode significar prosa, código, HTML, CSS, SQL, JSON, comandos de terminal, saída de testes, mensagens de erro ou configuração. É por isso que o mesmo tipo de modelo pode ajudar a escrever textos, explicar um bug, criar código ou resumir um plano.

## Geração de texto

Um LLM não recupera uma resposta fixa de um banco de dados. Ele gera uma resposta peça por peça com base na entrada que você fornece e no contexto que pode ver.

Quando você escreve um prompt, o modelo usa suas palavras, a conversa e qualquer contexto de projeto disponível para prever uma resposta útil. Essa resposta pode ser uma explicação, um plano ou texto que outro sistema pode usar para agir.

Isso significa que a qualidade da sua entrada importa. Objetivos claros, exemplos, restrições e contexto tornam bons resultados mais prováveis.

## Tokens

Os modelos de IA processam texto em pequenas unidades chamadas tokens. Um token pode ser uma palavra, parte de uma palavra, pontuação, espaço em branco ou um trecho de código.

Os tokens importam porque afetam quanta informação um modelo de IA pode considerar de uma vez. Conversas longas, arquivos grandes, logs, capturas de tela e instruções contribuem para o contexto que o modelo tem para raciocinar.

Você não precisa contar tokens enquanto constrói. Você precisa entender que o Agent funciona melhor quando as informações importantes são claras, atuais e focadas.

## A IA pode variar

A saída da IA nem sempre é idêntica. O mesmo pedido pode produzir diferentes redações, designs, detalhes de implementação ou trocas.

Essa variabilidade é útil para exploração, mas também significa que você deve revisar trabalhos importantes. Teste o que o Agent constrói, peça explicações quando algo não estiver claro e use checkpoints quando precisar de um ponto de recuperação seguro.

## O que torna a saída da IA melhor

O Agent tem melhor desempenho quando você fornece:

* Um objetivo claro
* O público ou necessidade do usuário
* Restrições e não-objetivos
* Exemplos, capturas de tela, arquivos, dados ou links
* O problema atual ou erro exato
* Critérios de aceitação para o que significa "pronto"

Compare estes dois prompts:

* *"Escreva código para um site."*
* *"Escreva código para um site para coletar endereços de e-mail para minha lista de correspondência pessoal. Armazene os envios no Google Sheets."*

O segundo prompt nomeia o objetivo, os dados e o destino, então o Agent tem o suficiente para agir sem adivinhar.

Essa informação é chamada de contexto. Para saber por que o contexto importa, veja [Gerenciamento de contexto](/pt/learn/foundations/context-management).

## De IA a agentes de IA

Um modelo de chat pode responder a uma mensagem. Um agente de IA usa um modelo mais ferramentas para realizar trabalho em várias etapas — ele pode raciocinar sobre um objetivo, escolher ferramentas, inspecionar informações, fazer alterações, verificar resultados e continuar até que a tarefa seja concluída ou precise da sua entrada.

### Modelos e ferramentas

Um agente tem duas partes importantes:

| Parte                   | O que faz                                                                                                                                          |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Modelo de linguagem** | Entende instruções, gera texto, raciocina sobre opções e decide o que fazer a seguir.                                                              |
| **Ferramentas**         | Permitem que o agente tome ações, como ler arquivos, editar código, executar comandos, pesquisar documentos, testar um app ou publicar alterações. |

O modelo decide qual ação pode ajudar. As ferramentas permitem que o agente aja com base nessa decisão.

### O que os agentes podem fazer

Os agentes são úteis para trabalhos que levam mais de uma etapa, como:

* Planejar um recurso
* Criar arquivos e código
* Ler a estrutura de projeto existente
* Executar comandos ou testes
* Depurar erros
* Atualizar designs
* Conectar serviços
* Resumir o que mudou

O agente não apenas responde; ele trabalha em uma tarefa.

### Replit Agent

O Replit Agent é um agente de IA para construir no Replit. Ele pode ajudá-lo a criar apps e outros artefatos, inspecionar seu projeto, editar arquivos, executar comandos, testar comportamentos, explicar código, criar tarefas e guiar fluxos de trabalho de publicação.

Por exemplo, você pode pedir ao Agent para:

```text theme={null}
Crie um app simples de inscrição em eventos para um encontro comunitário.
Os visitantes devem ver os detalhes do evento, enviar seu nome e e-mail, e receber uma mensagem de confirmação.
Mantenha a primeira versão simples para que eu possa publicá-la hoje.
```

O Agent pode transformar essa solicitação em um projeto, criar uma primeira versão e ajudá-lo a refiná-la.

### Você ainda lidera o trabalho

O Agent pode se mover rapidamente, mas você ainda toma as decisões importantes:

* O que o artefato deve fazer
* Para quem é
* O que deve estar no escopo
* O que não deve mudar
* Se o resultado funciona
* Quando está pronto para publicar

É por isso que o gerenciamento de contexto e a revisão são importantes. O Agent é mais forte quando você dá a ele uma direção clara e testa o resultado.

## Equívocos comuns

* **"A IA deveria saber o que quero dizer."** A IA funciona com as informações que você fornece. Se algo importa, diga claramente.
* **"A primeira resposta deveria ser definitiva."** Construir com IA é iterativo. Revise, teste e refine.
* **"A IA entende a intenção como as pessoas fazem."** A IA pode inferir padrões, mas não conhece automaticamente seu gosto, público, restrições ou definição de pronto.
* **"Um agente é apenas um chatbot."** Um chatbot principalmente responde. Um agente pode usar ferramentas e agir.
* **"O Agent conhece automaticamente todo o objetivo do produto."** O Agent trabalha a partir das suas instruções e contexto. Se algo importa, inclua-o.
* **"O Agent remove a necessidade de revisar."** O Agent pode construir, mas você decide se o artefato corresponde à sua intenção.
