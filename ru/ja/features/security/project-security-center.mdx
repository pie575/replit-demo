<div id="section-2">
  ## Автоматическое сканирование зависимостей
</div>

Автоматическое сканирование зависимостей сверяет пакеты проекта с публичными записями об уязвимостях. Такие проверки выполняются автоматически и бесплатно. Когда публикуется новая запись CVE (Common Vulnerabilities and Exposures), Replit сопоставляет её с зависимостями проекта и показывает совпадения на панели **Security** — повторное сканирование вручную не требуется.

Сканирование зависимостей поддерживает Node.js/npm, Python, Go, Rust, PHP и Ruby.

Автоматическое исправление зависимостей пока работает только для Node.js/npm.

<div id="auto-protect">
  ### Auto-Protect
</div>

Auto-Protect расширяет возможности автоматического сканирования зависимостей. При обнаружении подходящей уязвимости Agent готовит и тестирует патч, а затем отправляет письмо с прямой ссылкой. Патч остаётся на панели **Security** в ожидании проверки. После применения повторно опубликуйте приложение, чтобы исправление попало в рабочую версию.

Auto-Protect охватывает только CVE в зависимостях. Для проверки кода приложения используйте [сканирование безопасности Agent](/ru/ja/features/security/agent-security-scans).

Обе настройки Auto-Protect по умолчанию отключены:

<Steps>
  <Step title="Включите подготовку патчей">
    Администратор workspace переходит в **Settings** &gt; **Account** &gt; **Advanced** и
    выбирает минимальный уровень серьёзности (низкий, средний, высокий или критический),
    при котором Replit должен готовить исправления.
  </Step>

  <Step title="Включите письма о безопасности">
    Перейдите в **Settings** &gt; **Personalization** &gt; **Email Notifications** и
    выберите минимальный уровень серьёзности, о котором хотите получать уведомления.
  </Step>
</Steps>

По каждой новой уязвимости Replit отправляет не более одного письма на workspace, объединяя в нём сводку по всем затронутым проектам. Выберите **Go to Task**, чтобы проверить подготовленный Agent патч перед применением. После применения патча уязвимость будет отображаться как **ожидает повторной публикации**, пока вы не опубликуете новую версию.

<Note>
  Исправления, подготовленные Agent, тарифицируются так же, как и любая другая работа Agent, даже если они были подготовлены проактивно средствами Auto-Protect.
</Note>

<div id="section-3">
  ## Просмотр результатов проверки
</div>

Результаты проверки безопасности отображаются на панели **Security** и сгруппированы по уровню серьёзности:

| Уровень серьёзности     | Рекомендации                                                                  |
| ----------------------- | ----------------------------------------------------------------------------- |
| Критический             | Непосредственные риски, которые следует устранить до публикации               |
| Высокий                 | Серьёзные проблемы, которые могут быть использованы при определённых условиях |
| Средний                 | Потенциальные риски с низкой вероятностью эксплуатации                        |
| Низкий / Информационный | Незначительные проблемы и рекомендации по передовым практикам                 |

Просмотрите каждый результат, прежде чем принять, исправить или отклонить его. Отправьте принятые проблемы в Agent как запрос на исправление, а после применения исправлений повторно запустите соответствующее сканирование.

<div id="section-5">
  ### Сканирование безопасности во время сборки
</div>

Пока вы создаёте приложение с помощью Agent, Replit автоматически проверяет изменённые Agent файлы на распространённые небезопасные шаблоны и жёстко заданные секреты. Это ранняя облегчённая проверка в рамках рабочего процесса Agent, а не анализ всей кодовой базы. Её результаты не отображаются отдельным отчётом на панели **Security**.

<div id="section-6">
  ### Проверки при публикации
</div>

Replit выполняет сканирование безопасности и перед публикацией. Параметр **Block publishing of critical vulnerabilities** определяет, что произойдёт, если сканирование выявит критические проблемы:

* **Включено**: публикация блокируется, пока проблемы не будут устранены или отклонены.
* **Выключено**: публикация продолжается, а результаты сканирования остаются доступными для просмотра.

Организации Enterprise могут сделать этот параметр обязательным для всех приложений.

Эти проверки не заменяют полноценное [сканирование безопасности Agent](/ru/ja/features/security/agent-security-scans) или [сканирование Level 3](/ru/ja/features/security/black-box-pen-tests), а дополняют их.
