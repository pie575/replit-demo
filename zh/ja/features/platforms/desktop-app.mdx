<a href="https://replit.com/desktop" target="_blank">Replit 桌面应用</a>把完整的 Replit 体验带到你的电脑上。在专属应用中使用 Agent 构建，享受浏览器标签页无法提供的原生使用体验。

<div id="replit">
  ## 什么是 Replit 桌面应用
</div>

Replit 桌面应用是面向 Windows 和 Mac 全新打造的原生应用。它带来与网页端一致的体验，让你在同一个窗口中完成创建应用、与 Agent 对话、发布等所有操作。此外，它还新增了几项只有桌面应用才能实现的功能。

* **多任务处理**：可同时操作多个 Replit 应用。
* **状态提示**：Agent 需要你介入或任务已完成时，一眼即可知晓。
* **标签页预览**：无需切换标签页，就能查看已打开的应用。

<div id="section">
  ## 快速开始
</div>

<Steps>
  <Step title="下载应用">
    访问<a href="https://replit.com/desktop" target="_blank">桌面应用下载页面</a>，下载适用于你电脑的版本。
  </Step>

  <Step title="安装并启动">
    打开下载好的文件，按照提示完成安装。安装完成后启动应用。
  </Step>

  <Step title="登录">
    使用你的 Replit 账户登录；如果你是新用户，请先创建账户。你创建的所有内容都会与 [replit.com](https://replit.com) 保持同步。
  </Step>
</Steps>

<Tip>
  应用、历史记录和设置在桌面应用与网页端之间通用。你可以在一端开始，在另一端接着做。
</Tip>

<div id="section-3">
  ## 面向企业团队
</div>

借助桌面应用，你可以轻松在整个组织内部署 Replit。它与其他桌面应用的安装方式相同，因此 IT 团队可以通过设备管理 (MDM) 服务商，将其自动分发并安装到公司电脑上。如需了解更多信息，请联系你的客户经理。
