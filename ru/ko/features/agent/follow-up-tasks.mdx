<div id="section">
  ## Предложения по последующим задачам
</div>

После выполнения задачи Agent анализирует контекст проекта и предлагает **последующие задачи**, которые можно реализовать далее. В диалоговом окне **Предлагаемая следующая задача** основная рекомендация отображается прямо в интерфейсе, чтобы вы могли продолжать работу, не отвлекаясь от основного диалога.

</Frame>

Предложения по последующим задачам могут включать:

* **Новые функции**: функции, которые естественно дополняют только что созданное
* **Улучшения производительности**: оптимизации, обнаруженные Agent во время работы над задачей
* **Улучшения пользовательского опыта**: доработки и улучшения, завершающие функцию

Чтобы отправить предложение в фоновый режим, выберите **Начать**; чтобы сначала ознакомиться с предложенной работой, выберите **Просмотреть план**. Чтобы увидеть все предложения, выберите **Показать больше на доске задач**. Предлагаемые последующие задачи отображаются в разделе **Предложено** столбца **Черновик**.

<Frame>
  <img src="/assets/mirror/follow-up-tasks-kanban-21087e0210b6.png" alt="Доска задач с множеством предложений по последующим задачам в разделе «Предложено» столбца «Черновик»" width="980" height="627" data-path="images/agent/follow-up-tasks-kanban.png" />
</Frame>

При закрытии диалогового окна **Предлагаемая следующая задача** предложение отменяется. Если для основной версии уже есть ожидающий предложенный план, Agent не показывает это диалоговое окно, чтобы два запроса не конкурировали за ваше внимание.

<div id="section-2">
  ## Управление несколькими предложениями сразу
</div>

Если в проекте много предложений о последующих задачах, откройте доску задач и в столбце **Черновики** выберите **Изменить**. В режиме редактирования рядом с каждой предложенной последующей задачей появляется флажок. Отметьте нужные задачи и с помощью кнопок **Запустить** или **Отменить** примените соответствующее действие ко всем выбранным задачам. Чтобы выйти из режима редактирования, выберите **Готово**.
