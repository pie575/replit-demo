## Plateforme

### Intégration SendGrid

Vous pouvez désormais créer des intégrations d'e-mail avec l'Agent. Cela vous permet d'envoyer des e-mails depuis vos nouveaux projets Agent en utilisant l'API SendGrid.

</Frame>

### Prise en charge mobile de la vue Web

Nous avons ajouté la possibilité de mettre à l'échelle la vue Web aux tailles d'écran mobiles courantes. De plus, nous avons ajouté un code QR dans le menu déroulant de l'URL et le volet réseau pour faciliter les tests sur appareils mobiles.

À titre de rappel — même pendant que vous construisez votre projet, il est accessible depuis Internet. Visitez simplement l'URL de développement depuis n'importe quel appareil.

### Mise à jour du format des enregistrements DNS

Nous avons modifié la façon dont les enregistrements DNS des domaines personnalisés sont formatés pour correspondre aux standards de l'industrie.

Cela devrait faciliter la configuration des domaines personnalisés.

  <img src="/assets/mirror/dns-record-format-878840a5ecfe.png" alt="Format des enregistrements DNS" width="1228" height="1156" data-path="images/changelog/2025-01-17/dns-record-format.png" />

### Mise à niveau du déploiement Flask

gunicorn est désormais le serveur web par défaut pour les déploiements de la pile Flask.

Cela a entraîné une amélioration des performances de 40x par rapport aux déploiements Flask précédents.

### Commandes shell intégrées dans l'Assistant

L'Assistant peut désormais exécuter des commandes shell directement dans le volet de chat. Gagnez du temps en exécutant des commandes sans quitter le chat !
