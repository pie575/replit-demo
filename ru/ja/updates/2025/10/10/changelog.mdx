<div id="agent">
  ### Прозрачность расходов на использование Agent
</div>

Во время выполнения задач можно в реальном времени отслеживать расходы на использование Agent. Откройте панель в заголовке чата, чтобы контролировать расходы по активным задачам. Это особенно полезно при длительных запусках с высокой автономностью.

<div id="escape">
  ### Клавиша Escape в режиме визуального выбора/редактирования
</div>

Нажмите Escape, чтобы выйти из режима Visual Select или вернуться в режим Build. Небольшая, но удобная клавиша для продолжения работы.

<div id="agent-2">
  ### Ускоренная остановка Agent
</div>

Остановка и запуск Agent из рабочего пространства теперь выполняются быстрее, сокращая время ожидания.

<div id="github">
  ### Улучшения импорта из GitHub
</div>

Во время импорта из GitHub теперь отображается его ход в реальном времени вместо общих сообщений, а скорость импорта повысилась.

<div id="section-2">
  ### Сканирование уязвимостей в зависимостях
</div>

Сканер безопасности теперь выявляет уязвимости в зависимостях Go, JavaScript, Python и Rust. В будущем появится поддержка других языков.

<div id="webview">
  ### Логи веб-просмотра
</div>

Теперь логи веб-просмотра и вывод консоли, включая логи, используемые Agent, собраны в одном месте, что упрощает отладку.

<div id="section-3">
  ### Доступ к местам поддержки для команд
</div>

Вы можете добавить Replit Support как гостевую учётную запись, которая не учитывается при выставлении счёта. При необходимости предоставьте поддержке доступ с ограниченной областью действия к конкретным App, сохраняя контроль над конфиденциальностью своего рабочего пространства.
