借助 Whop 集成，Agent 无需任何外部设置或 API 密钥，只需一次对话就能为你的应用添加支付功能。Agent 会创建 Whop 账户、配置结账流程并构建支付逻辑。Whop 是最快的开售方式，如果你想尽快拿到第一笔收入，它再合适不过。

<div id="section">
  ## 你可以构建什么
</div>

* 数字内容付费墙与&quot;解锁&quot;流程
* 会员体系与社区访问权限
* 订阅与周期性套餐
* 一次性数字商品销售

<div id="section-2">
  ## 工作原理
</div>

当你请求添加支付功能时，Agent 会在后台完成 Whop 的设置：为你的应用创建并连接 Whop 账户，并将结账流程集成到项目中。无需粘贴任何凭据，也无需离开 Replit 就能开始。

Whop 是 Replit 支持的多家支付服务商之一。Agent 会根据你要构建的内容，帮你选出合适的方案：

|          | Whop           | Stripe         | Shopify     | RevenueCat                 |
| -------- | :------------- | :------------- | :---------- | :------------------------- |
| **最适合**  | 步骤最少，最快拿到第一笔收入 | 灵活性与规模化        | 实物商品        | 原生移动应用                     |
| **销售**   | 数字商品、会员资格、订阅     | 一次性支付、订阅、店面    | 带库存与配送的实物商品 | 应用内订阅                      |
| **外部设置** | 起步阶段无需         | 起步阶段无需         | 起步阶段无需      | 起步阶段无需                     |
| **发布**   | 身份验证 (KYC)     | 连接正式 Stripe 账户 | 提交店铺申请      | App Store 或 Google Play 审核 |

如果你没有指定服务商，Agent 会根据你的描述给出推荐，并说明各方案的利弊取舍。

<div id="section-3">
  ## 开始使用
</div>

* **让 Agent 添加支付功能**
  * 使用主页的斜杠命令，或直接向其提出请求：
    <AiPrompt>为我的应用添加 Whop 支付，以便销售会员资格</AiPrompt>

<Note>
  Whop 集成需要应用具备后端功能。请在主页选择**应用**。
</Note>

<div id="section-4">
  ## 测试支付
</div>

1. 在新标签页中打开应用的**预览**。
2. 运行你构建的结账或解锁流程。
3. 在分享应用之前，端到端地验证购买者的完整体验。

<div id="section-5">
  ## 管理商品与价格
</div>

你可以通过两种方式管理你的商品：

* **让 Agent 来做**：描述你想做的更改 (新增套餐、调整价格、添加商品) ，Agent 会同步更新应用和 Whop 中的设置。
* **使用 Whop 控制台**：用你的 Replit 账户邮箱登录 [Whop](https://whop.com)，直接管理商品、价格和套餐。

<div id="section-6">
  ## 跟踪余额与收款
</div>

销售收入会累积在你的 Whop 账户中。如需提取收益，请在 Whop 控制台中完成身份认证 (KYC) 。你可以在完成认证前就开始销售，但提现前必须先通过身份认证。

<Note>
  Whop 负责结账、支付处理、身份认证 (KYC) 和付款。Replit 不会收集你的银行信息或税务信息。
</Note>

<div id="section-8">
  ## 常见问题
</div>

<div id="whop">
  ### 开始之前需要先有 Whop 账户吗？
</div>

不需要。Agent 会在设置过程中为你的应用创建 Whop 账户。之后你可以用 Replit 账户的邮箱登录 Whop 控制台，管理商品并提现收益。

<div id="section-9">
  ### 什么时候需要进行身份认证？
</div>

你可以立即开始构建并销售。在提现资金之前，Whop 会要求你完成身份认证 (KYC) ，该流程在 Whop 控制台中完成。

<div id="section-10">
  ### 如何修改商品或价格？
</div>

你可以让 Agent 帮你修改，也可以在 [Whop 控制台](https://whop.com)中直接编辑商品和套餐。

<div id="section-11">
  ### 应该选择哪家支付服务商？
</div>

Whop 是销售数字商品和会员资格的最快方式，无需任何外部配置。如果希望在 Web 应用中获得最大的灵活性，请选择 [Stripe](/zh/ja/features/monetization/stripe-payments)；实体商品请选择 [Shopify](/zh/ja/features/integrations/shopify)；原生移动端订阅请选择 [RevenueCat](/zh/ja/features/monetization/revenuecat-subscriptions)。如需对比，请参阅[变现功能概览](/zh/ja/features/monetization/overview)。
