<div id="section-2">
  ### Сканирование безопасности во время разработки
</div>

Теперь Agent в рамках проверки кода анализирует изменённые файлы на наличие типичных проблем безопасности. Это автоматическое сканирование Semgrep выявляет опасные паттерны и жёстко зашитые в код секреты, чтобы Agent мог устранить найденные проблемы до завершения задачи.

Подробнее см. [Сканирование безопасности во время разработки](/ru/ko/features/security/project-security-center#security-scan-while-you-build).

<div id="section-4">
  ### Повторная генерация учётных данных production-базы данных
</div>

Теперь вы можете заново сгенерировать учётные данные для подходящих production-баз данных в инструменте **Database**. Replit обновит учётные данные и, если у приложения есть поддерживаемое активное развёртывание, запустит повторное развёртывание, чтобы приложение продолжало работать с новыми учётными данными. Внешние инструменты, которые используют прежнюю строку подключения, потребуется обновить.

<div id="sso">
  ### Разработка с SSO
</div>

Теперь билдеры на плане Pro могут настраивать корпоративный SSO для Replit App, использующих [Clerk Auth](/ru/ko/features/auth-and-identity/clerk-auth). Попросите Agent внести нужные изменения в аутентификацию — он направит вас в Clerk Dashboard. Там подключите Okta или Microsoft Entra ID через OIDC или SAML. Корпоративные SSO-подключения бесплатны до 1 октября 2026 года, после чего начнут действовать тарифы Clerk с оплатой по мере использования. Поддержка Enterprise появится в ближайшее время.

<div id="section-5">
  ### Перемещение проектов между рабочими пространствами
</div>

Теперь в списке **Projects** можно перемещать проекты между командными рабочими пространствами в рамках одного платёжного аккаунта. Перенос выполняется в фоновом режиме и не может быть отменён. Секреты подключённых аккаунтов не переносятся вместе с проектом, поэтому их потребуется подключить заново в целевом рабочем пространстве.
