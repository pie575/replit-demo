将相关提及发送至 Slack，并归档到 Notion。Agent 会忽略噪声，
仅标记需要回复的内容，帮助您在舆情激增演变为客户支持或公关问题
之前及时发现。

* 只需识别需要回复的提及，而非所有提及的社交媒体和客户支持负责人。

<div id="section-3">
  ## 开始之前
</div>

准备好你关注的品牌名称或账号、用于接收提醒的 Slack 频道，以及用于归档的 Notion 数据库。

Agent 会要求你提供 **X Bearer Token**。请在 [console.x.com](https://console.x.com) 创建
账号并生成 Bearer Token。

请为 X 开发者账户充值。否则，X 中的提及搜索将会失败。

<div id="agent">
  ## 向 Agent 发出请求
</div>

<AiPrompt>
  请创建一个每天早上 8 点运行的例行任务。在 X 上监测 [品牌] 的提及。
  识别重要对话，总结情感和上下文，将相关提及发送到
  Slack，并存档到 Notion。忽略噪声。标记需要回复的内容。
</AiPrompt>

<div id="section-4">
  ## 预期结果
</div>

Agent 会监测提及内容，评估其重要性，将简短摘要发布到 Slack，并将
会话保存到 Notion。查看第一批内容，并调整判定为“重要”的
标准。如果完全没有收到提及内容，请确认是否已配置 Bearer Token，
以及 X 开发者账户是否有额度。首次早晨运行后，打开 Slack 通知并前往
X，确认 Notion 行中是否包含相同的链接。

<div id="section-5">
  ## 按需引导
</div>

<AiPrompt>
  仅将负面情感的提及，或获得 [n] 个及以上点赞的提及通知到 Slack。其余内容
  全部归档到 Notion。
</AiPrompt>

<AiPrompt>
  请将包含热度最高的 5 条提及和整体情感的每日摘要发送到 Slack。
</AiPrompt>

<div id="section-6">
  ## 故障排查
</div>

* **完全没有收到提及：**请确认已设置 X Bearer Token，且你的 X 开发者账户中有可用额度。若无额度，即使 token 有效，提及搜索也会失败。
* **Slack 很安静，但 Notion 中的内容不断累积：**Agent 可能将所有内容都视为噪音。请调整“重要”的判定标准，或要求它即使无需回复也发布每日摘要。
* **归档记录很杂乱：**请告知 Agent 你正在使用的 Notion 数据库及其现有列 (日期、链接、情感、是否需要回复) 。要求它映射到这些字段，而不是每次都创建新页面。
