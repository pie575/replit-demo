Elle n&#39;est pas disponible avec le forfait gratuit [Starter](/fr/ja/billing/plans/starter-plan) — Agent vous proposera de passer à un forfait supérieur lorsqu&#39;il suggérera un connecteur.

<div id="section">
  ## Ce que vous pouvez créer
</div>

Ajoutez Stripe à votre application avec Agent en un seul clic — sans aucune configuration. Créez une boutique en ligne, acceptez des paiements uniques ou mettez en place des abonnements. Agent met en place l&#39;intégration, le modèle de données et l&#39;environnement de test.

<div id="section-2">
  ## Fonctionnement
</div>

Agent démarre dans un sandbox Stripe, ce qui vous permet de tester les paiements en toute sécurité, sans mouvement d&#39;argent réel. Vous pouvez créer et essayer vos flux immédiatement. Lorsque vous êtes prêt, basculez vers un compte Stripe en production pour publier votre application et accepter de vrais paiements.

<Info>
  Un sandbox Stripe est un environnement de test isolé dans lequel vous pouvez simuler des paiements, des abonnements et des événements. Pour en savoir plus, consultez
  [la documentation Stripe sur les sandbox](https://docs.stripe.com/sandboxes).
</Info>

<div id="stripe">
  ## Utiliser Stripe en équipe
</div>

Stripe fonctionne dans les espaces de travail collaboratifs : toute l&#39;équipe peut ainsi créer, tester et monétiser la même application ensemble. Chaque membre de l&#39;espace de travail peut travailler avec le compte Stripe connecté, sans qu&#39;une seule personne ait à mettre en place les paiements toute seule.

<div id="section-3">
  ## Pour commencer
</div>

* **Demandez à Agent d&#39;utiliser Stripe**
  * Sur l&#39;écran d&#39;accueil, utilisez une commande slash pour sélectionner Stripe, ou formulez directement votre demande :
    <AiPrompt>Build a storefront and integrate Stripe for payments</AiPrompt>

<Note>
  L&#39;intégration de Stripe nécessite une app dotée de fonctionnalités backend. Commencez par sélectionner **App** depuis la page d&#39;accueil.
</Note>

<div id="section-4">
  ## Tester les paiements dans le sandbox
</div>

1. Ouvrez le **Preview** de votre application dans un nouvel onglet.
2. Effectuez un achat test depuis la vitrine ou la page de paiement.
3. Utilisez les cartes de test standard de Stripe :

```text theme={null}
Card number: 4242 4242 4242 4242
Expiry: any future date
CVC: any 3 digits
Name, address: any mock values
```

<Tip>
  Les achats réalisés en environnement de test (sandbox) ne transitent pas par les réseaux réels et aucun montant n&#39;est débité. Ils sont donc sans risque pour vos tests de bout en bout.
</Tip>

<div id="section-5">
  ## Gérer les produits et les tarifs
</div>

Deux options s&#39;offrent à vous :

1. Depuis votre application, sélectionnez **Publish**, puis choisissez de demander une sandbox Stripe.
   * Si vous n&#39;avez pas encore de compte Stripe, créez-en un afin de pouvoir demander une sandbox.
2. Dans le tableau de bord Stripe, ouvrez **Products** pour ajouter ou modifier des produits et des tarifs.
   Les modifications effectuées dans la sandbox Stripe sont automatiquement répercutées dans votre application Replit et synchronisées avec sa base de données.

<div id="stripe-2">
  ### Vérifier les données Stripe synchronisées
</div>

* Ouvrez **Database** dans l&#39;éditeur de projet.
* Sélectionnez **MyData**.
* Basculez le sélecteur de schéma sur **Stripe** pour consulter les objets de paiement et les enregistrements associés.

<div id="section-6">
  ## Publier
</div>

Pour accepter de vrais paiements, installez l&#39;application [Replit Integrated Payments](https://marketplace.stripe.com/apps/replit-integrated-payments) depuis le Stripe Marketplace et connectez votre compte Stripe en production. Le processus d&#39;installation connecte automatiquement votre compte en production — aucune clé API à copier-coller.

<Warning>
  L&#39;intégration en environnement sandbox n&#39;est pas prête pour la production. Vous ne pouvez pas accepter de vrais paiements tant que vous n&#39;avez pas suivi les étapes ci-dessous.
</Warning>

<Steps>
  <Step title="Ouvrir le volet Publish">
    Sélectionnez **Publish** dans votre App pour lancer le processus de connexion live.
  </Step>

  <Step title="Installer l'application Replit Integrated Payments">
    Sélectionnez **Installer l&#39;application Stripe**. Une fenêtre Stripe s&#39;ouvre sur la fiche [Replit Integrated Payments](https://marketplace.stripe.com/apps/replit-integrated-payments).

    Lorsque Stripe vous invite à sélectionner un compte, choisissez votre compte Stripe en production, et non un sandbox ou un compte de test.
  </Step>

  <Step>
    Suivez les instructions de Stripe pour installer l&#39;application. Si votre compte Stripe en production n&#39;est pas encore activé, Stripe vous guide d&#39;abord dans la vérification KYB (Know Your Business).

    Laissez la fenêtre Stripe ouverte jusqu&#39;à la fin de l&#39;installation.
    Une fois que Stripe a confirmé l&#39;installation, Replit finalise la connexion de production en arrière-plan.
  </Step>

  <Step title="Publier votre App">
    Revenez dans Replit. Le volet **Publish** indique que votre compte Stripe en production est connecté. Publiez votre App pour commencer à accepter de vrais paiements.
  </Step>
</Steps>

<Note>
  L&#39;installation de l&#39;application Replit Integrated Payments remplace l&#39;ancienne procédure manuelle qui consistait à copier les clés Publishable et Secret dans Replit. L&#39;application configure vos clés de production et maintient la synchronisation entre le sandbox et l&#39;environnement live.
</Note>

<div id="section-7">
  ## Gestion des intégrations
</div>

* Accédez à **Integrations &gt; Stripe** pour ouvrir le connecteur Stripe.
* Vous pouvez y tester la connexion, en vérifier le statut et gérer les paramètres.

<div id="section-8">
  ## Questions fréquentes
</div>

<div id="section-9">
  ### Comment mettre à jour le prix d&#39;un produit ?
</div>

* Demandez à Agent : décrivez la modification souhaitée et Agent met à jour votre application ainsi que les objets Stripe.
* Utilisez le tableau de bord Stripe : ouvrez **Products** pour modifier les prix et les détails du produit.
  * En environnement sandbox, les modifications sont automatiquement synchronisées avec votre application et votre base de données.
  * En production, basculez d&#39;abord sur votre compte live, puis mettez à jour les prix. Republiez l&#39;application si elle doit récupérer la nouvelle configuration.

<div id="replit">
  ### Comment tester les transactions dans Replit ?
</div>

Ouvrez le **Preview** de votre application dans un nouvel onglet. Déroulez le flux Stripe Checkout avec la carte de test standard (4242 4242 4242 4242), une date d&#39;expiration future quelconque et n&#39;importe quel CVC. Pour plus de détails, consultez la section [Tester les paiements dans le bac à sable](#test-payments-in-the-sandbox) ci-dessus.

<div id="stripe-3">
  ### Qu&#39;est-ce qu&#39;un compte Stripe en production ?
</div>

Un compte Stripe en production est un compte vérifié et activé à l&#39;aide des informations de votre entreprise, capable de traiter de véritables paiements. Pour créer et activer votre compte, consultez la documentation de Stripe : [Create and manage your Stripe account](https://docs.stripe.com/get-started/account).

<div id="stripe-api">
  ### Dois-je coller mes clés d&#39;API Stripe ?
</div>

Non. L&#39;application Replit Integrated Payments installe les clés de production lorsqu&#39;elle connecte votre compte Stripe en production. Vous n&#39;avez pas besoin de copier vos clés de production depuis le tableau de bord Stripe.

Si vous aviez déjà connecté Stripe en collant des clés de production, cette connexion continue de fonctionner. Pour basculer vers le flux d&#39;installation de l&#39;application Stripe, supprimez la connexion Stripe, puis reconnectez-vous depuis le volet **Publish**. Consultez la section [Mettre à jour ou supprimer la connexion Stripe](#update-or-remove-the-stripe-connection) ci-dessous.

<div id="stripe-4">
  ## Mettre à jour ou supprimer la connexion Stripe
</div>

Si vous n&#39;êtes pas prêt à publier avec une connexion Stripe en mode production, deux options s&#39;offrent à vous :

<div id="astripe">
  ### Option A : supprimer manuellement l&#39;intégration Stripe
</div>

Vous pouvez supprimer complètement l&#39;intégration Stripe de votre projet.

<Steps>
  <Step title="Ouvrir l'onglet Integrations">
    Accédez à votre application Replit et sélectionnez l&#39;onglet **Integrations** en haut. Sous **Connectors**, repérez **Stripe** et sélectionnez **Manage**.

    <Frame>
      <img src="/assets/mirror/stripe-disconnect-1-integrations-371e1e7e5609.png" alt="Onglet Integrations de Connectors affichant l'intégration Stripe avec le bouton Manage" width="2000" height="1110" data-path="images/replitai/stripe-disconnect-1-integrations.png" />
    </Frame>
  </Step>

  <Step title="Afficher les clés API">
    Sélectionnez le chevron pour afficher les sections **Sandbox API keys** et **Live account API keys**, puis sélectionnez **Edit**.

    <Frame>
      <img src="/assets/mirror/stripe-disconnect-2-edit-keys-4e9e76c4065f.png" alt="Clés API du sandbox et du compte en direct Stripe affichées avec le bouton Edit" width="2000" height="1274" data-path="images/replitai/stripe-disconnect-2-edit-keys.png" />
    </Frame>
  </Step>

  <Step title="Déconnecter le compte">
    Sélectionnez **Disconnect account** pour supprimer la connexion au sandbox et **Disconnect live account** pour supprimer la connexion en direct.

    <Frame>
      <img src="/assets/mirror/stripe-disconnect-3-disconnect-f4257f534c5c.png" alt="Clés API du sandbox et du compte en direct Stripe affichant les boutons Disconnect account et Disconnect live account" width="2000" height="1271" data-path="images/replitai/stripe-disconnect-3-disconnect.png" />
    </Frame>
  </Step>

  <Step title="Demander à Agent de supprimer le code Stripe">
    Accédez à la discussion avec Agent et demandez-lui de supprimer le code du connecteur Stripe de votre application. Cela supprime l&#39;intégration Stripe dans son intégralité.
  </Step>
</Steps>

<div id="bstripe">
  ### Option B : revenir à un checkpoint antérieur à l&#39;intégration Stripe
</div>

Si vous souhaitez annuler entièrement l&#39;intégration Stripe et retrouver l&#39;état précédent, vous pouvez revenir à un checkpoint antérieur.

<Steps>
  <Step title="Ouvrir l'onglet Integrations">
    Accédez à votre app Replit et sélectionnez l&#39;onglet **Integrations** en haut. Sous **Connectors**, repérez **Stripe** et sélectionnez **Manage**.

    <Frame>
      <img src="/assets/mirror/stripe-disconnect-1-integrations-371e1e7e5609.png" alt="Onglet Integrations de Connectors affichant l'intégration Stripe avec le bouton Manage" width="2000" height="1110" data-path="images/replitai/stripe-disconnect-1-integrations.png" />
    </Frame>
  </Step>

  <Step title="Déployer les clés API">
    Sélectionnez le chevron pour déployer **Sandbox API keys** et **Live account API keys**, puis sélectionnez **Edit**.

    <Frame>
      <img src="/assets/mirror/stripe-disconnect-2-edit-keys-4e9e76c4065f.png" alt="Clés API du sandbox et du compte en production Stripe déployées avec le bouton Edit" width="2000" height="1274" data-path="images/replitai/stripe-disconnect-2-edit-keys.png" />
    </Frame>
  </Step>

  <Step title="Déconnecter le compte">
    Sélectionnez **Disconnect account** pour supprimer la connexion au sandbox, et **Disconnect live account** pour supprimer la connexion en production.

    <Frame>
      <img src="/assets/mirror/stripe-disconnect-3-disconnect-f4257f534c5c.png" alt="Clés API du sandbox et du compte en production Stripe affichant les boutons Disconnect account et Disconnect live account" width="2000" height="1271" data-path="images/replitai/stripe-disconnect-3-disconnect.png" />
    </Frame>
  </Step>

  <Step title="Trouver le checkpoint antérieur à l'intégration Stripe">
    Accédez au chat de l&#39;Agent et recherchez un checkpoint créé avant l&#39;intégration Stripe. Sélectionnez l&#39;**icône d&#39;horloge** en haut à gauche du volet de chat pour consulter l&#39;historique des conversations plus anciennes.

    <Frame>
      <img src="/assets/mirror/stripe-rollback-5-clock-icon-c54cd19246ea.png" alt="Icône d'horloge permettant d'afficher l'historique du chat et les checkpoints" width="56" height="50" data-path="images/replitai/stripe-rollback-5-clock-icon.png" />
    </Frame>
  </Step>

  <Step title="Sélectionner « Rollback here »">
    Une fois que vous avez trouvé un checkpoint qui vous convient, sélectionnez **Rollback here** pour restaurer le projet dans cet état.

    <Frame>
      <img src="/assets/mirror/stripe-rollback-6-checkpoint-2f195b0ea9ce.png" alt="Checkpoint avec le bouton « Rollback here »" width="904" height="202" data-path="images/replitai/stripe-rollback-6-checkpoint.png" />
    </Frame>
  </Step>
</Steps>

<div id="section-10">
  ## Remarques et limites
</div>

* L&#39;activité du sandbox n&#39;a aucune incidence sur les soldes réels ni sur les clients.
* Certaines fonctionnalités de Stripe ne peuvent pas être testées dans un sandbox (par exemple, la tarification IC+ ou certains flux Connect).
  Consultez les [limites des sandboxes Stripe](https://docs.stripe.com/sandboxes).
