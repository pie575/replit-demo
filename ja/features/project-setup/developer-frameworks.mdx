## 開発者フレームワークとは？

開発者フレームワークは、プラットフォームやコミュニティが他のユーザーの出発点として公開したReplitアプリです。Replitが作成した公式の開発者フレームワークには、フレームワーク名の横にチェックボックスが表示されます：

</Frame>

[HTML, CSS, JSフレームワーク](https://replit.com/@replit/HTML-CSS-JS?v=1#index.html)は非常に人気があり、バニラJavaScriptプロジェクトを作成するための出発点として使用できます。フォークして使用できます。

## Enterpriseカスタムテンプレート

Enterprise組織は、すべての組織メンバーのAgentの入力ボックスで選択可能なオプションとして表示される[カスタムテンプレート](/ja/teams/custom-templates)を作成できます。カスタムテンプレートは、会社固有のAgent指示、スキル、事前設定されたプロジェクトコンテキストを含むことで、開発者フレームワークを超えた機能を提供します。詳しくは[カスタムテンプレートガイド](/ja/teams/custom-templates)をご覧ください。
