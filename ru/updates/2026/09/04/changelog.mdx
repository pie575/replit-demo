<div id="recover-production-data-with-scheduled-backups">
  ### Восстановление продакшен-данных с помощью резервных копий по расписанию
</div>

Резервные копии по расписанию создают одну полную точку восстановления в день для вашей продакшен-базы данных. Чтобы включить их, выберите срок хранения в поле **Keep backups for** в настройках продакшен-базы данных. Максимальный срок хранения зависит от вашего тарифа.

<div id="understand-app-usage-with-project-analytics">
  ### Анализируйте использование приложения с помощью Аналитики проекта
</div>

Аналитика проекта показывает, как люди находят и используют ваше опубликованное веб-приложение. На панели **Growth** доступны примерная динамика посетителей, популярные страницы, источники трафика, страны, браузеры и устройства. Чтобы начать сбор данных, включите **Enable analytics** и опубликуйте приложение заново. На платном тарифе попросите Agent добавить пользовательские события и проанализировать воронки для таких действий, как регистрации и покупки.
