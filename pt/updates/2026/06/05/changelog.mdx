## Integrações

### Venda produtos físicos com o Shopify

Agora você pode criar uma loja online que vende produtos físicos. Peça ao Agent para criar uma loja e ele criará uma loja Shopify para você, adicionará seus produtos e configurará o carrinho e o checkout. O Agent fornece um link para você reivindicar a loja, e então você se cadastra em um plano Shopify e conecta os pagamentos para entrar no ar.

Saiba mais sobre [como conectar o Shopify](/pt/features/integrations/shopify).

### Crie aplicativos de dados no Microsoft Fabric

Agora você pode criar aplicativos de dados com IA no Replit e publicá-los diretamente no Microsoft Fabric. Comece pelo template do Microsoft Fabric, conecte um modelo semântico do Power BI e peça ao Agent para criar dashboards e ferramentas internas sobre seus dados corporativos gerenciados, mantendo a autenticação e as políticas de acesso dentro do Fabric.

## Workspace

### Domínios personalizados configuram seu próprio DNS

Conectar seu próprio nome de domínio agora é muito mais simples. Ao vincular um domínio, o Replit configura os registros DNS necessários para você através do Entri, eliminando a necessidade de copiar registros manualmente no seu provedor de domínio. Escolha seu domínio, confirme e o Replit cuida do restante.

Saiba mais sobre [domínios personalizados](/pt/features/publishing/custom-domains).

## Agent

### Melhore seu ranking de busca com o SEO Agent

O SEO Agent analisa seu aplicativo publicado e identifica os problemas que impedem mecanismos de busca e ferramentas de IA de descobri-lo. Cada problema encontrado vem com uma correção com um clique que você pode revisar e aplicar. Abra o painel **Growth** no seu projeto para executar uma análise.

## Cobrança

### Use o Stripe em workspaces colaborativos

O Stripe agora funciona em workspaces colaborativos, para que toda a sua equipe possa criar, testar e monetizar o mesmo aplicativo em conjunto. Todos no workspace podem trabalhar com a conta Stripe conectada em vez de desenvolver pagamentos individualmente.

Saiba mais sobre [Pagamentos com Stripe](/pt/features/monetization/stripe-payments).
