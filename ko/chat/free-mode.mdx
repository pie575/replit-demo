Free Mode에서는 Power Mode나 Max Mode의 credits을 사용하지 않고 채팅하고, 만들고, 빌드할 수 있습니다.

<Note>
  Free Mode는 항상 지능형 모델 라우팅을 사용하므로 Replit이 요청에 맞는
  모델을 선택합니다. Free Mode에서는 특정 모델을 직접 선택할 수 없습니다.
</Note>

Routines는 Free Mode에서 실행되지 않습니다. Power 또는 Max Mode에서만 실행되며, run당 예산이 필요합니다. 자세한 내용은 [Routines](/ko/chat/routines)를 참조하세요.

<div id="get-more-from-your-allowance">
  ## allowance 최대한 활용하기
</div>

Free Mode는 지금 진행 중인 작업의 흐름을 이어가기에 좋습니다. 이런 경우에 활용해 보세요.

* 규모가 큰 build에 본격적으로 착수하기 전에 아이디어를 탐색하고 검증할 때
* 새 project를 시작하거나, 기능을 처음 구현해 보거나, 비교적 작은 변경을 처리할 때
* 질문을 던지고, 계획을 세우고, follow-up 메시지로 작업을 다듬을 때
* allowance가 남아 있는 동안 credits 없이 일상적인 작업을 이어갈 때

시작하려면 prompt box 아래의 모드 선택기를 열고 모드가 **Free**로 설정되어 있는지 확인하세요. 그런 다음 Replit에 명확한 요청을 전달하세요. 원하는 결과를 구체적으로 밝히고, 중요한 context를 공유한 뒤, follow-up 질문으로 결과를 다듬으면 됩니다.

<div id="know-when-to-use-another-mode">
  ## 다른 모드가 필요한 시점 알아두기
</div>

Free Mode 한도는 플랜에 따라 다릅니다. **Settings** → **Usage**에서 현재 한도와 초기화 시점을 확인하세요.

<Frame caption="Usage 페이지에서 남은 Free allowance와 갱신 시점을 확인할 수 있습니다.">
  <img src="/assets/mirror/free-mode-usage-sanitized-1b738ae092bb.jpg" alt="Free allowance 패널이 표시된 Settings Usage 페이지" width="1538" height="1022" data-path="images/chat/free-mode-usage-sanitized.jpg" />
</Frame>

Core 및 Pro 플랜에서는 더 높은 성능이 필요하거나, 특정 모델을 직접 선택하고 싶거나, Free Mode allowance를 모두 사용했을 때 **Power Mode** 또는 **Max Mode**로 전환하세요. 이 모드들은 월별 credits를 사용합니다. Starter를 사용하는 builders는 Power Mode나 Max Mode를 사용하려면 먼저 업그레이드해야 합니다.

<Tip>
  플랜에 Power Mode와 Max Mode가 포함되어 있다면, 첫 단계는 Free Mode로 진행하고
  task에 더 높은 성능이 필요할 때만 전환하세요. 요청이 usage 비용이 발생하는
  모드로 넘어가기 전에 Replit이 미리 알려드립니다.
</Tip>

<div id="choose-the-mode-that-fits-the-work">
  ## 작업에 맞는 모드 선택하기
</div>

| 이런 작업을 원한다면...          | 이 모드로 시작하세요 |
| ----------------------- | ----------- |
| 탐색, 질문, 계획 수립 또는 빌드 시작  | Free Mode   |
| 대부분의 작업에서 속도와 성능의 균형 확보 | Power Mode  |
| 복잡하거나 규모가 큰 작업 처리       | Max Mode    |

Power Mode는 Economy Mode를 대체하며, 비용은 동일하지만 성능은 동등하거나 더 뛰어납니다. Core 및 Pro 플랜에서는 Power Mode 또는 Max Mode에서 사용 가능한 모델을 선택할 수 있습니다.
