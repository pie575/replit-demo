Les compétences enseignent à Agent de nouvelles capacités : modèles à privilégier, spécificités d&#39;une bibliothèque, règles d&#39;un design system ou solutions à des problèmes que vous avez déjà résolus. Joignez-en une à un message, installez-en une dans votre projet ou choisissez-en une comme point de départ d&#39;un nouveau projet.

<div id="use-a-skill-in-chat">
  ## Utiliser une compétence dans le chat
</div>

Le moyen le plus rapide d&#39;essayer les compétences est d&#39;en joindre une à un message ponctuel — aucune installation nécessaire.

<Frame>
  <img src="/assets/mirror/agent-skills-picker-ee4058454475.png" alt="Sélecteur de compétences ouvert depuis le bouton + à côté de la zone de saisie du chat, affichant la liste des compétences avec Ad Creative, AI Recruiter, AI SDR et AI Secretary" width="723" height="529" data-path="images/replitai/agent-skills-picker.png" />
</Frame>

<Steps>
  <Step title="Ouvrir le sélecteur de compétences">
    Cliquez sur le bouton **+** à côté de la zone de saisie du chat, puis sélectionnez **Utiliser une compétence**.
  </Step>

  <Step title="Parcourir et sélectionner une compétence">
    Parcourez les compétences par catégorie : Business &amp; finance, Creative, Research &amp; analysis, et bien d&#39;autres. Sélectionnez une ou plusieurs compétences à joindre à votre message.
  </Step>

  <Step title="Envoyer votre message">
    Saisissez votre demande et envoyez-la. Agent utilise les compétences sélectionnées pour ce message uniquement. Une pastille de compétence s&#39;affiche sur votre message pour vous indiquer quelles compétences sont actives.
  </Step>
</Steps>

Par exemple, joignez **Stock Analyzer** et demandez à Agent de créer un rapport d&#39;analyse boursière, ou joignez **Deep Research** pour qu&#39;Agent étudie un sujet et en tire des constats structurés.

<Tip>
  Les compétences jointes dans le chat n&#39;installent rien dans votre projet. Elles sont disponibles instantanément dans tous vos projets.
</Tip>

<div id="start-a-project-with-a-skill">
  ## Démarrer un projet avec une compétence
</div>

Lorsque vous créez un projet, vous pouvez choisir une compétence pré-validée comme point de départ. Agent s&#39;appuie sur les instructions de la compétence pour structurer le projet.

<Steps>
  <Step title="Ouvrir le sélecteur de point de départ">
    Sur l&#39;écran de création de projet, cliquez sur **+**, puis sélectionnez **Utiliser une compétence**.
  </Step>

  <Step title="Choisir une compétence">
    Parcourez les compétences sélectionnées, telles que **AI SDR**, **SEO Auditor**, **Ad Creative** ou **Programmatic SEO**. Choisissez celle qui correspond au type d&#39;app que vous souhaitez créer.
  </Step>

  <Step title="Décrire votre app">
    Expliquez à Agent ce que vous souhaitez obtenir. Agent construit le projet en appliquant dès le départ les modèles et les conventions de la compétence.
  </Step>
</Steps>

<div id="install-a-skill-in-your-project">
  ## Installer une compétence dans votre projet
</div>

Si vous voulez qu&#39;Agent applique une compétence de façon systématique à toutes les conversations d&#39;un projet, installez-la. Les compétences installées se trouvent dans le répertoire `/.agents/skills` de votre projet et persistent d&#39;une session de chat à l&#39;autre.

<div id="install-from-the-skills-pane">
  ### Installer depuis le volet Skills
</div>

Ouvrez le **volet Skills** dans le Project Editor et sélectionnez l&#39;onglet **Discover** pour rechercher des compétences proposées par la communauté. Lorsque vous en trouvez une qui vous intéresse, cliquez sur **Install** : elle est automatiquement ajoutée à votre projet.

<Frame>
  <img src="/assets/mirror/agent-skills-discover-732b2b0c488a.png" alt="Onglet Discover des compétences affichant les compétences proposées par la communauté, avec un champ de recherche et des boutons d'installation" width="2542" height="1850" data-path="images/replitai/agent-skills-discover.png" />
</Frame>

Par exemple, pour développer un site portfolio doté d&#39;animations avancées, vous pourriez installer :

* **GSAP React** — apprend à Agent les animations déclenchées au défilement, les apparitions de texte et le tracé de chemins SVG
* **Tailwind design system** — transmet à Agent la connaissance des modèles Tailwind CSS pour la typographie, les espacements et les transitions de vue
* **Find skills** — apprend à Agent à découvrir et installer de nouvelles compétences en votre nom

<Tip>
  Vous pouvez également installer des compétences via la [CLI npx skills](https://github.com/vercel-labs/skills) :

  ```bash theme={null}
  npx skills <skill> -a replit
  ```
</Tip>

<div id="create-a-skill-from-a-conversation">
  ### Créer une compétence à partir d&#39;une conversation
</div>

La manière la plus naturelle de créer une compétence consiste à en discuter avec Agent. Après avoir résolu un problème ensemble ou exploré une nouvelle bibliothèque, demandez à Agent de consigner ce qu&#39;il a appris :

<AiPrompt>
  Recherche les bonnes pratiques d&#39;intégration de GSAP avec React et crée une compétence pour ce projet.
</AiPrompt>

Agent s&#39;appuie sur l&#39;ensemble du contexte de la conversation pour rédiger un fichier de compétence détaillé. Cette approche est particulièrement efficace après une session de débogage, lorsque vous avez acquis une compréhension commune du problème.

<div id="write-a-custom-skill">
  ### Écrire une compétence personnalisée
</div>

Pour les cas d&#39;usage avancés, rédigez vos compétences directement en suivant la [spécification Agent Skills](https://agentskills.io/specification). Activez l&#39;option **Show Hidden Files** dans la barre latérale des fichiers, ouvrez `/.agents/skills/`, puis créez un nouveau fichier Markdown. Vous gardez ainsi un contrôle total sur ce qu&#39;Agent sait et sur la façon dont il se comporte.
