Il existe deux façons de créer un système de design, selon l'endroit où votre marque vit aujourd'hui.

## À partir de zéro : demandez-le depuis la page d'accueil

Commencez ici lorsque le système existe dans votre tête (ou dans vos consignes de marque) mais pas encore dans un design.

<Steps>
  <Step title="Demandez-le dans le champ de création">
    Depuis la page d'accueil de Replit, décrivez le système de design que vous souhaitez dans la zone de prompt — par exemple : *« Crée un système de design pour Velocity, une marque de location de supercars premium. »*

    <Frame>
      <img src="/assets/mirror/ds-home-create-7f04110e1f71.png" alt="La zone de prompt de la page d'accueil avec un prompt de création de système de design" width="800" height="240" data-path="images/design/replit-design/ds-home-create.png" />
    </Frame>
  </Step>

  <Step title="Répondez au questionnaire">
    Agent pose une courte série de questions sur votre système — personnalité de marque, couleurs, préférences typographiques. Vous pouvez aussi le pointer vers une source : une URL Figma, un site web, du code, des images de référence, des ressources de marque, ou un fichier DESIGN.md existant.
  </Step>
</Steps>

## À partir d'une maquette : extraire le système de design

Commencez ici lorsque vous avez déjà un design que vous adorez — une frame générée, un template déposé — et que vous voulez que tout le reste corresponde.

<Steps>
  <Step title="Sélectionnez la maquette">
    Sur le canvas, cliquez sur la maquette dont vous voulez capturer le style.
  </Step>

  <Step title="Extrayez depuis le menu à trois points">
    Ouvrez le menu **⋯** (trois points) de la frame et choisissez **Extract design system**. Agent distille les tokens, couleurs et typographies de la maquette en un guide de style vivant — et l'applique à l'ensemble du design.

    <Frame>
      <img src="/assets/mirror/ds-extract-menu-3efbe8bb497e.png" alt="Gros plan sur la barre d'actions d'une frame sélectionnée avec le menu d'options supplémentaires ouvert, montrant Apply design system et Extract design system" width="958" height="320" data-path="images/design/replit-design/ds-extract-menu.png" />
    </Frame>
  </Step>
</Steps>

## Vérifier et enregistrer

Dans les deux cas, examinez ce qui a été généré : un guide de style vivant avec vos couleurs (par rôle — primaire, accent, atténuée…), une échelle typographique, et des tokens (stockés dans `tokens.json`, alimentant les variables CSS). Sélectionnez ensuite **Save design system** pour le conserver dans votre espace de travail.
