Un **élément** est une partie d’un frame, comme un titre, un bouton, une image, un champ de formulaire ou tout autre composant affiché par le frame. Vous ciblez les éléments lorsque vous souhaitez modifier une partie d’un frame sans régénérer l’ensemble.

<div id="selecting-an-element">
  ## Sélectionner un élément
</div>

Utilisez l’[outil Edit](/fr/design/toolbar#edit) dans la barre d’outils. Lorsque Edit est actif, cliquez dans un frame actif pour sélectionner l’élément situé sous le curseur. L’élément sélectionné est mis en évidence par un contour et un petit prompt intégré vous permet de demander à Agent de le modifier.

<Note>
  Edit est désactivé tant qu’aucun frame n’existe sur Canvas et n’est disponible que sur ordinateur.
</Note>

<div id="acting-on-a-selected-element">
  ## Agir sur un élément sélectionné
</div>

<div id="ask-agent-to-change-it">
  ### Demander à Agent de le modifier
</div>

Demandez à Agent de modifier le texte, la couleur, la mise en page, l&#39;espacement ou le comportement de l&#39;élément à l&#39;aide du prompt intégré.

  <img src="/assets/mirror/canvas-ask-element-53f7468a07d3.png" alt="Gros plan du prompt intégré pour un élément sélectionné sur Canvas : une puce « img », suivie du texte indicatif « Ask about selected element… » et d'un bouton d'envoi." width="1500" height="500" data-path="images/replitai/canvas-ask-element.png" />
</Frame>

<div id="swap-an-image-directly">
  ### Remplacer directement une image
</div>

Sélectionnez un élément d’image. La section **Image** du Visual Editor affiche le chemin d’accès à la source ainsi qu’un bouton **Upload Image**, ce qui vous permet de remplacer le fichier sans rédiger de prompt.

<div id="visual-editor">
  ## Visual Editor
</div>

La sélection d’un élément ouvre le **Visual Editor** — un panneau à droite associé au prompt intégré. Le panneau regroupe les commandes en sections claires pour vous aider à trouver plus rapidement celle dont vous avez besoin : **texte**, **mise en page**, **couleur** et **bordure**. (La section **Image** apparaît également lorsque vous sélectionnez un élément image.)

<div id="layout">
  ### Mise en page
</div>

La section **Mise en page** vous permet d’ajuster la disposition des éléments enfants dans un conteneur sans passer par Agent. Sélectionnez un conteneur flex, développez Mise en page et vous trouverez :

* **Alignement** : un sélecteur à 3×3 points pour définir la position des éléments sur les deux axes à l’intérieur du conteneur.
* **Direction** : deux boutons fléchés pour disposer les éléments enfants en ligne ou en colonne.
* **Espacement** : une valeur en pixels pour l’espace entre les éléments. L’icône à côté du champ Espacement change selon la direction sélectionnée afin que vous sachiez toujours si vous ajustez l’espacement horizontal ou vertical. À côté, une icône en forme de flèche active ou désactive **Répartir l’espace entre les éléments**, ce qui pousse les éléments enfants vers les bords opposés du conteneur.
* **Espace extérieur** : des champs pour définir l’espace à l’extérieur de l’élément, côté par côté (un champ par côté, avec une bascule de liaison pour verrouiller les quatre côtés simultanément).
* **Espace intérieur** : des champs pour définir l’espace à l’intérieur de l’élément sur chaque axe, avec une bascule de liaison pour les deux axes simultanément.

La section Mise en page s’affiche uniquement lorsqu’au moins un contrôle de mise en page s’applique à l’élément sélectionné. Les nœuds de texte brut sans propriétés d’espacement ou de mise en page masquent entièrement la section, afin que l’éditeur reste compact.

Pour les sections **Texte**, **Couleur**, **Bordure** et **Image**, consultez le [guide du Visual Editor](/fr/design/visual-editor).
