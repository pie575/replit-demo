export const CoreCredits = '$20';

以下解答涵盖了 Replit 构建者最常问到的计费问题。如需详细了解按用量计费的运作方式，请参阅[按用量计费](/zh/ja/billing/about-usage-based-billing)和[管理支出](/zh/ja/billing/managing-spend)。

<AccordionGroup>
  <Accordion title="为什么在月度计费周期结束前就向我收费了？">
    当超出所含月度额度的使用量达到设定金额 (*计费阈值*) 时，Replit 会立即收费，而不是等到账单周期结束才收费。Core 计划每月包含 {CoreCredits} 额度，超出部分的 Agent 使用量将在达到阈值时单独计费。

    要降低后续账单：

    1. 使用 [Plan 模式](/zh/ja/features/agent/plan-mode)，在 Agent 开始构建前界定并确认工作范围，避免代价高昂的返工。
    2. 如果你有 Core 或 Pro 订阅，可使用 [Free Mode](/zh/ja/features/agent/agent-modes) 免费完成日常 Agent 工作。额度每 5 小时重置一次，并设有每周上限。你可以在**设置 → 用量**中查看使用情况。
    3. 如果需要更强的能力，同时希望价格实惠，请选择 Power。
    4. 在[管理支出](/zh/ja/billing/managing-spend)中设置用量限制和预算，为超出额度的费用设定上限。
    5. 每项新任务都开启新的 Agent 对话，保持上下文简短。

    若要查看计费触发情况，请打开**设置 → 账户用量**，然后选择**查看历史账单**。
  </Accordion>

  <Accordion title="我通过 App Store 或 Google Play 订阅了服务，但无法添加付款方式—该如何解决？">
    如果你通过 App Store 或 Google Play 订阅，账单由 Apple 或 Google 处理，因此移动应用内不会显示付款选项。请改为在网页端管理付款：

    1. 打开浏览器，前往**设置 → 账单**。
    2. 选择**更新付款方式**。
    3. 输入并保存你的银行卡信息。

    添加网页付款方式后，你可以在**账单**标签页中管理账单并购买积分包。有关积分包的更多信息，请参阅[管理支出](/zh/ja/billing/managing-spend)。
  </Accordion>

  <Accordion title="我在订阅后 30 天内，是否有资格获得退款？">
    退款资格因套餐和退款项目而异。请注意以下事项：

    * Agent 和 AI 使用量费用不可退款。每笔费用均对应已使用的计算资源。
    * [自定义域名注册费用不可退款](/zh/ja/build/domain-purchasing)。

    如需申请订阅费用退款，请使用注册邮箱[联系 Replit 支持团队](https://replit.com/support)，并说明原因。请先在**设置 → 计费**中取消订阅。

    <Note>支持团队会根据您的账户和套餐确认具体的订阅退款期限和资格。</Note>
  </Accordion>

  <Accordion title="我因意外的 Agent 或 AI 使用而被收费，可以退款吗？">
    Agent 和 AI 使用费用不予退款。每笔费用均反映 Replit 已用于执行任务的计算资源。为避免日后产生意外费用：

    1. 打开**设置 → 账户使用情况**，设置使用限额和预算。请参阅[管理支出](/zh/ja/billing/managing-spend)。
    2. Free Mode 包含在 Core 和 Pro 订阅中。若要在额度范围内免费完成日常 Agent 任务，请使用 [Free Mode](/zh/ja/features/agent/agent-modes)；如果需要以实惠的价格获得更高性能，请选择 Power。
    3. 使用 [Plan 模式](/zh/ja/features/agent/plan-mode)，让 Agent 在开始构建前明确工作范围，减少返工。

    如果您认为费用有误，请准备收费金额、日期和支付意向 ID。该 ID 以 `pi_` 开头，可在账单详情页面中找到。随后，请[联系 Replit 支持](https://replit.com/support)。
  </Accordion>

  <Accordion title="取消订阅后仍然被扣费——这是正常的吗？">
    取消后仍产生账单通常有以下原因：

    * 取消前的使用量在取消日期之后才达到计费阈值。
    * 系统对之前计费周期中失败的扣款进行重试。

    如需确认，请打开**设置 → 账户使用情况**，选择**查看历史账单**，核对账单日期及其涵盖的使用期间。如果仍有疑问，请[联系 Replit 支持](https://replit.com/support)，并提供 `pi_` 支付意图 ID。
  </Accordion>

  <Accordion title="订阅仍有效，但为什么还要为额外存储空间付费？">
    当存储的数据超出套餐所含限额时，将产生存储费用。有关存储用量的计量方式，请参阅[基于用量的计费](/zh/ja/billing/about-usage-based-billing)；有关对象存储的费用，请参阅[对象存储计费](/zh/ja/billing/object-storage-billing)。

    若要查看是哪些内容占用了空间，请在项目中打开 Shell 并运行以下命令：

    ```bash theme={null}
    du -sh *
    du -ah | sort -rh | head -20
    ```

    接下来，请删除构建产物 (如 `.cache` 或 `dist`) 、旧日志和未使用的上传文件，并清理数据库中的过期数据。释放空间后，后续的存储费用就不会继续累积。
  </Accordion>

  <Accordion title="如何申请自定义域名注册退款？">
    [自定义域名注册费用不予退款](/zh/ja/build/domain-purchasing)，因为域名注册会产生第三方费用，一经处理便无法撤销。

    如果您误注册了域名，或希望转移域名，请[联系 Replit 支持团队](https://replit.com/support)，并提供域名以及与账户关联的电子邮件地址。我们的团队会为您说明可选方案。
  </Accordion>

  <Accordion title="我已支付账单，但账户仍处于暂停状态——何时会恢复？">
    付款确认后，账单冻结可能需要一段时间才会解除。请尝试以下步骤：

    1. 在 Mac 上按 `Cmd+Shift+R`，在 Windows 上按 `Ctrl+Shift+R`，对浏览器执行强制刷新。
    2. 退出登录后重新登录，以刷新账户状态。
    3. 打开**设置 → 账户使用情况**，选择**查看历史账单**，确认账单显示为已支付。

    冻结解除后，部署不会自动重启。如果应用仍处于离线状态，请打开**发布**并选择**发布**，让应用重新上线。如果账户仍处于停用状态，请[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="我不认识 Replit 的一笔扣款—该怎么办？">
    在向银行提出异议之前，请先确认以下事项：

    1. 打开**设置 → 账户使用情况**，然后选择**查看过去的账单**，核对日期、金额和说明。
    2. 确认是否有他人可以访问您的账户或付款方式。
    3. 查看账单日期前后 Replit 发送的账单邮件 (包括垃圾邮件文件夹) 。

    账单通常是订阅费用、达到计费阈值后产生的使用费用，或购买积分包的费用。

    <Warning>在向银行对费用提出异议*之前*，请先联系 Replit 支持——拒付可能会导致您的账户被锁定。</Warning>

    请提供 `pi_` 付款意向 ID、账单金额和日期，并[联系 Replit 支持](https://replit.com/support)。
  </Accordion>

  <Accordion title="付款被拒绝了——这是 Replit 的问题吗？">
    大多数拒付并非来自 Replit，而是来自银行或发卡机构——通常是针对陌生交易的自动安全拦截。请按以下顺序尝试：

    1. 在**设置 → 账单 → 更新支付方式**中添加另一张卡并重试。
    2. 致电银行，说明您正尝试向 Replit 付款，并请求其放行。
    3. 如果您的卡限制境外消费，请联系银行开通该权限。

    如果仍然被拒付，请[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="我被收取了两次相同的费用——这是重复收费吗？">
    两笔金额相同的费用不一定是重复扣款。常见原因如下：

    * 金额相同的订阅费用和积分包分别显示为两条明细。
    * 之前失败的支付经重试后扣款成功。
    * 确实发生了重复扣款 (少见) 。

    打开**设置 → 账户用量**，选择**查看历史账单**，对比两笔费用的支付意图 ID (`pi_`) ——如果 ID 不同，说明是两笔独立交易。如果两者显示为同一张账单中同一项目的已付款记录，请[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="我已通过 App Store 付款，但积分未到账，该怎么办？">
    App Store 的付款可能需要一些时间才能同步到 Replit。请先尝试以下操作：

    1. 强制退出并重新启动 Replit 应用。
    2. 退出 Replit 账户后重新登录。
    3. 打开**设置 → 账户使用情况**，查看额度是否已经到账。

    请勿重复购买。如果额度仍未显示，请在 App Store 的**购买记录**中找到 Replit 的交易并记下交易 ID，然后[联系 Replit 支持团队](https://replit.com/support)，以便我们为您补上额度。
  </Accordion>
</AccordionGroup>
