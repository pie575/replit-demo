<div id="pesquisa-na-web-para-o-agent">
  ### Веб-поиск для Agent
</div>

<Frame>
  <img src="/assets/mirror/web-search-6c28195531d4.jpg" alt="Интерфейс Agent с результатами веб-поиска и ссылками на источники для разработки приложений" width="1920" height="1080" data-path="images/replitai/web-search.jpg" />
</Frame>

Теперь Agent умеет искать в интернете и находить актуальную информацию с помощью [Веб-поиска](/ru/pt/core-concepts/agent/web-search). Создавайте приложения, опираясь на свежую документацию, текущие рыночные данные и точные сведения со всего интернета. Никаких ограничений по дате знаний — ваши приложения используют самую актуальную доступную информацию.

<div id="instrues-personalizadas-do-agent">
  ### Пользовательские инструкции для Agent
</div>

<Frame>
  <img src="/assets/mirror/replitmd-65360844a148.jpg" alt="Файл replit.md с параметрами персонализации проекта" width="1920" height="1080" data-path="images/replitai/replitmd.jpg" />
</Frame>

Настройте работу с Agent под себя с помощью файла [replit.md](/ru/pt/core-concepts/agent/replit-dot-md). В этом специальном файле можно задать стиль написания кода, предпочтения по проекту и контекст. Agent создаёт его автоматически на основе проверенных лучших практик, а вы можете отредактировать файл под свой рабочий процесс.

<div id="experincia-da-app-store-para-equipes">
  ### App Store для команд
</div>

Находите приложения своей команды и управляйте ими как никогда удобно. Новый режим «App Store» для организации на странице Deployments позволяет добавлять приложения в избранное, выполнять поиск по всем развёртываниям, просматривать недавно открытые приложения и находить популярные развёртывания по объёму трафика.
