Импорт позволяет добавить существующий код или дизайн в Replit App и продолжить разработку с Agent.

<div id="supported-sources">
  ## Поддерживаемые источники
</div>

| Источник                 | Что потребуется                                               | Лучше всего подходит для                                     |
| ------------------------ | ------------------------------------------------------------- | ------------------------------------------------------------ |
| GitHub                   | URL репозитория или средство выбора репозитория               | Импорта публичных и частных репозиториев                     |
| Bitbucket                | URL репозитория или средство выбора репозитория               | Импорта репозиториев, размещённых на Bitbucket               |
| Vercel                   | Репозиторий GitHub, связанный с вашим проектом Vercel         | Миграции приложений Vercel                                   |
| Figma                    | URL фрейма                                                    | Преобразования дизайнов в React-приложения                   |
| Claude                   | Дизайн, отправленный из Claude                                | Преобразования дизайна из Claude в интерактивное приложение  |
| Bolt                     | Репозиторий GitHub, экспортированный из Bolt                  | Миграции проектов Bolt                                       |
| Lovable                  | Репозиторий GitHub, экспортированный из Lovable               | Миграции проектов Lovable                                    |
| Base44                   | Репозиторий GitHub, экспортированный из Base44                | Миграции проектов Base44                                     |
| ZIP                      | Загрузка файла `.zip`                                         | Импорта локальных архивов проектов                           |
| Электронная таблица      | Файл `.xlsx`, `.csv` или URL Google Sheets                    | Создания приложения на основе данных электронной таблицы     |
| Предыдущий экспорт Agent | Репозиторий GitHub, экспортированный из предыдущего Agent App | Повторного импорта предыдущего Agent App                     |
| Пустой                   | Ничего                                                        | Опытных пользователей, которым нужен пустой проект без Agent |

<Note>Replit проверяет совместимость перед началом импорта.</Note>

Для дизайнов Figma см. [Импорт дизайнов Figma в Replit Design](/ru/design/import-figma-designs-into-replit-design).

Для дизайнов, отправленных из Claude, см. [Импорт дизайнов Claude в Replit Design](/ru/design/import-claude-designs-into-replit-design).

    ⏰ *Примерное время: четыре минуты*

    Импортируйте проект Lovable в Replit: сначала экспортируйте его в GitHub, а затем импортируйте репозиторий.

    **Перед началом**

    * Проект Lovable, доступный для экспорта
    * Учётная запись GitHub, подключённая к Lovable
    * Учётная запись Replit

    **Шаги**

    1. Экспортируйте проект Lovable в GitHub.
    2. Откройте [replit.com/import](https://replit.com/import).
    3. Выберите **Lovable**.
    4. Подключите учётную запись GitHub.
    5. Выберите экспортированный репозиторий Lovable.
    6. Выберите **Import**.

    <div id="what-gets-imported">
      ## Что импортируется
    </div>

    Replit импортирует из вашего проекта {platform_6} следующее:

    * **Код**: Логику приложения и исходные файлы
    * **Дизайн и стили**: Компоненты UI и правила оформления
    * **Ассеты**: Изображения, иконки и статические файлы
    * **Логику бэкенда**: Серверную функциональность, если она есть
    * **Схему базы данных**: Структуру таблиц, если она есть

    <div id="what-is-not-imported">
      ## Что не импортируется
    </div>

    * **Данные Supabase**: Существующие записи базы данных не переносятся
    * **Secrets**: Переменные окружения и ключи API необходимо добавить отдельно

    Используйте Agent, чтобы восстановить недостающую функциональность, добавить Secrets и воссоздать данные базы данных.

  <Tab title="GitHub">
    ⏰ *Примерное время: две минуты*

    Импортируйте репозиторий GitHub в Replit, чтобы быстрее запускать, тестировать и публиковать приложение.

    **Перед началом**

    * URL-адрес репозитория GitHub
    * Доступ к репозиторию (публичному или приватному)
    * Аккаунт Replit

    **Вариант первый: быстрый импорт**

    Быстрый импорт доступен для публичных репозиториев.

    1. Скопируйте путь к репозиторию после `github.com/`.
    2. Откройте `https://replit.com/github.com/<owner>/<repo>`.
    3. Нажмите Enter, чтобы начать импорт.

    *Пример*

    * URL GitHub: `https://github.com/exampleUser/my-app`
    * URL импорта Replit: `https://replit.com/github.com/exampleUser/my-app`

    **Вариант второй: пошаговый импорт**

    Пошаговый импорт поддерживает публичные и приватные репозитории.

    1. Откройте [replit.com/import](https://replit.com/import).
    2. Выберите **GitHub**.
    3. Подключите аккаунт GitHub.
    4. Выберите репозиторий.
    5. Нажмите **Import**.

    **Что импортируется**

    * Файлы и папки репозитория
    * Файлы зависимостей
    * Стандартная конфигурация запуска и сборки

    **Что не импортируется**

    * Существующие значения Secrets и переменных окружения
    * Сервисы, специфичные для платформы и не работающие в Replit по умолчанию

    **Устранение неполадок с подключением к GitHub**

    Если отображается `Failed to get repository, please re-authenticate with GitHub` или в выпадающем списке репозиториев указано `No repositories found`, для импорта из GitHub используется отдельное подключение, не связанное с подключением на странице **Account → Connected Services**. Повторное подключение только в разделе Connected Services не решит проблему с импортом.

    <Steps>
      <Step title="Повторно подключите GitHub в разделе Git Providers">
        Откройте раздел **Git Providers** в настройках аккаунта Replit, отключите GitHub и снова подключите его на той же странице. После этого ваши личные репозитории должны появиться в выпадающем списке импорта.
      </Step>

      <Step title="Предоставьте приложению Replit доступ к организации GitHub">
        Если репозиторий принадлежит организации GitHub, откройте [https://github.com/settings/applications](https://github.com/settings/applications), найдите OAuth-приложение Replit и предоставьте ему доступ к организации в настройках доступа сторонних приложений. Если вы не владелец организации, этот шаг может потребоваться выполнить её администратору.
      </Step>

      <Step title="Повторите импорт">
        Откройте [replit.com/import](https://replit.com/import) и повторите импорт: выберите репозиторий в выпадающем списке или вставьте URL-адрес репозитория.
      </Step>
    </Steps>

  <Tab title="ZIP">
    ⏰ *Примерное время: три минуты*

    Импортируйте локальный проект, загрузив файл `.zip`.

    **Перед началом**

    * Файл `.zip` с вашим проектом размером не более 200 МБ
    * Чётко определённая корневая папка проекта в архиве
    * Учётная запись Replit

    Если размер ZIP-архива превышает 200 МБ, форма импорта отклонит его. Исключите папки с зависимостями и результатами сборки, например `node_modules`, `.venv` или `build`, чтобы уменьшить размер файла. Replit переустановит зависимости во время импорта.

    **Шаги**

    1. Откройте [replit.com/import](https://replit.com/import).
    2. Выберите **ZIP**.
    3. Загрузите файл `.zip`.
    4. Добавьте все запрошенные Secrets и переменные окружения.
    5. Выберите **Import**.

    **Что импортируется**

    * Файлы проекта и структура каталогов
    * Файлы зависимостей
    * Настройки запуска и сборки Replit по умолчанию

    **Что не импортируется**

    * Существующие значения переменных окружения

<div id="bitbucket">
  ### Bitbucket
</div>

* Вставьте URL репозитория Bitbucket или подключите учётную запись Bitbucket, чтобы найти нужный репозиторий.
* Возможности Agent при импорте могут быть ограничены по сравнению с проектами, размещёнными на GitHub.

<div id="spreadsheet">
  ### Электронная таблица
</div>

* Загрузите файл Excel (`.xlsx`) или CSV либо вставьте URL общедоступной таблицы Google Sheets.
* Agent анализирует структуру вашей таблицы и создаёт полностековый App с базой данных, заполненной вашими данными.
* Включает UI для просмотра, поиска и управления записями.

<div id="previous-agent-export">
  ### Предыдущий экспорт Agent
</div>

* Повторно импортируйте ранее экспортированный Agent App из репозитория GitHub.
* Replit сохраняет специфичную для Agent структуру (код, схему базы данных и функциональность бэкенда).
* Значения базы данных и секретов не импортируются.

<div id="empty">
  ### Пустой
</div>

* Начните с полностью пустого проекта — без Agent, выбора фреймворка и шаблонного кода.
* Подходит опытным пользователям, которым нужен полный контроль над настройкой проекта.

<div id="limitations">
  ## Ограничения
</div>

* Существующие данные базы данных не переносятся.
* Размер загружаемых ZIP-файлов ограничен 200 МБ.
* Для некоторых сложных или проприетарных зависимостей может потребоваться ручная настройка.
* Обработка крупных проектов может занимать больше времени.

<div id="best-practices">
  ## Рекомендации
</div>

* Удалите конфиденциальные учётные данные перед импортом.
* Поддерживайте структуру исходного проекта в порядке.
* После импорта проверьте зависимости и команды запуска.
* Протестируйте основные сценарии перед публикацией.

<div id="troubleshooting">
  ## Устранение неполадок
</div>

Если импорт завершился ошибкой, сначала проверьте следующее:

* **Ошибки совместимости**: Проверьте наличие необходимых файлов проекта и поддержку используемых фреймворков.
* **Ошибки доступа**: Убедитесь, что у вас есть права доступа к репозиторию или источнику.
* **Ошибки обработки**: Повторите попытку, упростив структуру проекта или уменьшив его размер.

Если проблема не устранена, посетите [сообщество Replit](https://replit.com/community) или [обратитесь в службу поддержки](https://replit.com/support).
