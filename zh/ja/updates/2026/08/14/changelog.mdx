<div id="section-3">
  ### 选择工作区区域
</div>

Pro 构建者现在可以在创建工作区时选择北美、欧洲 (EU) 或亚洲。此选择将决定新项目和工作区资源所在的区域。

<div id="mcpreplit">
  ### 通过 MCP 使用 Replit
</div>

您可以将 Replit 直接连接到 ChatGPT、Claude 和 Slack，或将任何兼容的 MCP 客户端连接到 Replit，以创建、搜索、查看、更新和发布应用。您也可以不从零开始创建应用，而是创建现有应用的私有副本并进行编辑。

<Frame>
  <img src="/assets/mirror/codex-list-replit-projects-bebae6a1dbab.png" alt="Codex 回复，列出最近更新的三个 Replit 项目" width="2000" height="951" data-path="images/replitai/custom-mcp/codex-list-replit-projects.png" />
</Frame>

有关详细信息，请参阅 [Replit MCP 服务器](/zh/ja/platforms/mcp-server)。

<div id="clerk-auth">
  ### 迁移到 Clerk Auth
</div>

现在，符合条件的 Replit Auth 应用可以迁移到 Clerk Auth。Agent 会先迁移账户数据，再更新登录代码，因此现有用户仍可访问自己的数据。

<Frame>
  <img src="/assets/mirror/replit-auth-to-clerk-dialog-c485c7e997bc.png" alt="新版 Replit Auth 对话框，其中包含请求 Agent 执行迁移的按钮" width="1259" height="790" data-path="images/workspace/auth/replit-auth-to-clerk-dialog.png" />
</Frame>

详细信息请参阅[迁移到 Clerk Auth](/zh/features/auth-and-identity/migrate-auth-to-clerk)。

<div id="section-5">
  ### 请求生成内联图表
</div>

向 Agent 提出与数据相关的问题时，它会直接在对话中以图表形式呈现答案。图表是 Agent 的核心功能，可融入你创建的任何内容中加以使用。

<Frame>
  <img src="/assets/mirror/inline-chart-403e38268def.png" alt="Agent 生成了展示两家示例公司股价的折线图，并在下方显示图表数据摘要的对话" width="1324" height="1632" data-path="images/changelog/2026-08-14/inline-chart.png" />
</Frame>

详见[数据可视化](/zh/ja/features/artifact-types/data-apps)。

<div id="section-6">
  ### 共享和管理工作区技能
</div>

现在，所有工作区成员都可以创建技能，并选择将其设为私有或在工作区内共享。共享的技能默认对其他成员禁用，每位成员都可以自行选择启用哪些技能。管理员可以管理工作区中的所有技能，并将特定技能设为工作区必需技能。焕新的技能库让技能的发现和管理更加轻松。

如需了解更多信息，请参阅 [Agent 技能](/zh/ja/features/agent/skills)。

<div id="section-7">
  ## 团队与企业版
</div>

<div id="admin-api">
  ### Admin API 测试版现已推出
</div>

Enterprise 账户管理员现在可以在设置中新设的 **Developer** 标签页中创建 API 密钥。您还可以使用 Admin API 执行以下操作：

* 查看工作区、成员、用户群组、项目和部署。
* 查看成员、项目和工作区在自定义时间段内的使用情况。
* 查看和编辑工作区、用户群组及单个成员的预算。

更多信息请参阅 [Admin API 文档](/zh/ja/teams/admin-api)和 [API 参考](https://api.replit.com/docs)。
