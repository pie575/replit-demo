export const ProPlanPrice = '$100';

export const ProCreditRolloverPeriod = 'two months';

이 답변은 구독 관리를 다룹니다. 전체 플랜 세부 정보는 [Core](/ko/billing/plans/replit-core) 및 [Pro](/ko/billing/plans/replit-pro)를 참조하세요.

<AccordionGroup>
  <Accordion title="Core에서 Pro로 어떻게 업그레이드하며 차이점은 무엇인가요?">
    [Core](/ko/billing/plans/replit-core)와 비교하여 [Pro](/ko/billing/plans/replit-pro) ({ProPlanPrice}/월)는 다음을 추가합니다:

    * Turbo 모드
    * 풀링된 크레딧을 가진 최대 15명의 빌더
    * 단계별 크레딧. 사용하지 않은 크레딧은 {ProCreditRolloverPeriod} 동안 이월됩니다
    * 28일 데이터베이스 복원 기간 (Core의 7일 대비)
    * 우선 지원

    업그레이드하려면 **설정 → 청구**를 열고 Pro 플랜을 선택한 후 결제 정보를 확인하세요. 기능 비교와 현재 요금은 [요금 페이지](https://replit.com/pricing)를 참조하세요.
  </Accordion>

  <Accordion title="구독을 어떻게 취소하나요?">
    **설정 → 청구**를 열고 구독 취소 옵션을 선택한 다음 확인 단계를 완료하세요. 청구 기간이 끝날 때까지 플랜 기능을 유지하며, 이후 계정이 무료 [Starter 플랜](/ko/billing/plans/starter-plan)으로 이동합니다.

    전환 전에 게시된 앱이 오프라인이 될 수 있고, 커스텀 도메인 연결이 제거되며, 스토리지가 줄어들 수 있으므로 주의하세요. 보관하고 싶은 내용은 먼저 다운로드하세요. 구독이 `past_due`로 표시되면 결제가 실패했을 수 있으므로 취소 전에 해결하세요.
  </Accordion>

  <Accordion title="갱신 결제가 실패했어요. 결제 수단은 어떻게 업데이트하나요?">
    **설정 → 청구**를 열고 **결제 수단 업데이트**를 선택하여 카드를 추가하거나 업데이트하세요. 저장 후 Replit이 미결제를 자동으로 재시도합니다.

    문제가 계속되면 결제 의도 ID(`pi_`로 시작)와 함께 [Replit 지원팀에 문의](https://replit.com/support)하세요. 청구 실패 알림이 스팸 폴더에 있을 수 있습니다.
  </Accordion>

  <Accordion title="다른 이메일이나 계정으로 구독을 이전하려면 어떻게 하나요?">
    구독은 Replit 계정에 연결되어 있어 직접 이전할 수 없습니다. 구독을 유지하면서 계정의 이메일을 변경하려면 **설정 → 프로필**로 이동하여 이메일을 수정하세요.

    다른 계정으로 구독을 이동하려면 [Replit 지원팀에 문의](https://replit.com/support)하세요. 케이스별로 처리됩니다.
  </Accordion>

  <Accordion title="한 달에 두 번 청구되었어요. 무슨 일인가요?">
    한 달에 두 번 청구되는 경우 보통 다음 중 하나입니다:

    * 청구 임계값에 도달한 별도의 사용 요금이 포함된 구독료
    * 이전 실패 후 재시도되어 성공한 결제
    * 하나 이상의 활성 구독

    각 청구 내역을 확인하려면 **설정 → 계정 사용량**을 열고 **이전 청구서 보기**를 선택하세요. 여전히 이해가 안 된다면 [Replit 지원팀에 문의](https://replit.com/support)하세요.
  </Accordion>

  <Accordion title="플랜을 변경했는데 새 기능을 사용할 수 없어요. 어떻게 해야 하나요?">
    플랜 변경은 보통 바로 적용됩니다. 새 기능이 표시되지 않는다면:

    1. Mac은 `Cmd+Shift+R`, Windows는 `Ctrl+Shift+R`로 강제 새로고침하세요.
    2. 로그아웃 후 다시 로그인하세요.
    3. **설정 → 청구**를 열고 변경이 적용되었는지 확인하세요. 새 플랜 이름이 표시되어야 합니다.

    청구에 올바른 플랜이 표시되는데 기능을 여전히 사용할 수 없다면 사용자 이름과 사용하려는 기능과 함께 [Replit 지원팀에 문의](https://replit.com/support)하세요.
  </Accordion>

  <Accordion title="취소 대신 구독을 일시 중지할 수 있나요?">
    일부 구독자는 취소 대신 한 달 동안 구독을 일시 중지할 수 있는 자격이 있습니다. 자격이 있다면 취소하러 이동할 때 이 옵션이 표시됩니다. 일시 중지 중에는 다음과 같습니다:

    * 다음 결제가 건너뛰어지고 월간 크레딧이 지급되지 않습니다
    * 게시된 프로젝트는 계속 온라인 상태로 유지되고 협업자는 계속 액세스할 수 있습니다
    * 이월 가능한 크레딧은 이월되고 크레딧 팩은 계속 사용할 수 있습니다
    * Agent 및 호스팅 사용량은 계속 사용한 만큼 청구됩니다

    **설정 → 청구**에는 **일시 중지됨** 배지와 일시 중지 종료일이 표시되며, 해당 날짜에 구독이 자동으로 재개됩니다. 예정된 일시 중지는 적용되기 전에 취소할 수 있지만, 이미 활성화된 일시 중지는 조기에 종료할 수 없습니다. 구독은 한 번만 일시 중지할 수 있습니다.
  </Accordion>
</AccordionGroup>

## 도움이 더 필요하신가요?

계정별 구독 질문은 [Replit 지원팀에 문의](https://replit.com/support)하세요.
