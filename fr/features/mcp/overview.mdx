Replit Agent se connecte à des outils et à des sources de données externes via le [Model Context Protocol (MCP)](https://modelcontextprotocol.io), une norme ouverte dédiée aux intégrations d&#39;IA. Chaque serveur ci-dessous s&#39;installe en un seul clic : Agent charge ensuite automatiquement ses outils et les utilise lorsque c&#39;est pertinent.

Pour en comprendre le principe, consultez [Model Context Protocol](/fr/learn/model-context-protocol). Pour la mise en pratique, consultez [Se connecter via MCP](/fr/build/connect-via-mcp). Pour connecter un serveur qui ne figure pas dans cette liste, consultez [Ajouter un serveur MCP personnalisé](/fr/build/connect-via-mcp#add-a-custom-mcp-server).

<Info>
  Sélectionnez **Add to Replit** pour installer un serveur. Vous serez invité à autoriser la connexion dans le Project Editor.
</Info>

<div id="security-protections">
  ## Protections de sécurité
</div>

Tout le trafic MCP passe par le scanner de sécurité de Replit. Celui-ci évalue les définitions d&#39;outils et les exécutions prévues, et bloque les outils suspects ou dangereux avant leur exécution. Si un outil est rejeté, Agent vous en informe.

<div id="authentication-options">
  ## Options d&#39;authentification
</div>

* **Enregistrement dynamique de client OAuth** — si le serveur prend en charge le DCR OAuth, Replit détecte et enregistre automatiquement le client pour vous. La plupart des serveurs déjà répertoriés utilisent ce flux.
* **En-têtes personnalisés** — définissez une ou plusieurs paires nom/valeur d&#39;en-tête (par exemple, `X-API-Key`). Replit inclut ces en-têtes dans chaque requête MCP afin que votre serveur puisse vérifier l&#39;appelant. Utilisez cette option lorsque vous ajoutez un serveur personnalisé qui s&#39;authentifie par jetons statiques.

<div id="share-your-own-install-link">
  ## Partagez votre propre lien d&#39;installation
</div>

Les liens d&#39;installation permettent d&#39;ajouter votre serveur MCP à Replit en un seul clic. Générez-en un à l&#39;aide du formulaire de la page [Se connecter via MCP](/fr/build/connect-via-mcp#share-an-install-link), ou créez-le vous-même : encodez en base64 une charge utile JSON, puis ajoutez-la à la suite de `https://replit.com/integrations?mcp=`.

```json theme={null}
{
  "displayName": "My MCP Server",
  "baseUrl": "https://example.com/mcp",
  "headers": [{ "key": "Authorization", "value": "Bearer your-token" }]
}
```

* **displayName** — le nom affiché lors de l&#39;installation
* **baseUrl** — le point de terminaison HTTPS de votre serveur MCP
* **headers** — en-têtes d&#39;authentification facultatifs
