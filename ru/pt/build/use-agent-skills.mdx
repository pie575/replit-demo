Навыки наделяют Agent новыми возможностями: предпочтительными шаблонами, особенностями библиотек, правилами дизайн-системы или решениями уже знакомых вам проблем. Прикрепите навык к сообщению, добавьте его в проект или используйте как отправную точку для нового проекта.

<div id="usar-uma-skill-no-chat">
  ## Как использовать навык в чате
</div>

Самый быстрый способ опробовать навыки — прикрепить навык к одному сообщению без установки.

<Frame>
  <img src="/assets/mirror/agent-skills-picker-ee4058454475.png" alt="Селектор навыков, открытый кнопкой + рядом с полем ввода чата; отображает список навыков: Ad Creative, AI Recruiter, AI SDR и AI Secretary" width="723" height="529" data-path="images/replitai/agent-skills-picker.png" />
</Frame>

<Steps>
  <Step title="Откройте селектор навыков">
    Нажмите кнопку **+** рядом с полем ввода чата и выберите **Использовать навык**.
  </Step>

  <Step title="Просмотрите и выберите навык">
    Просматривайте навыки по категориям — Бизнес и финансы, Творчество, Исследования и анализ и другим. Выберите один или несколько навыков, чтобы прикрепить их к сообщению.
  </Step>

  <Step title="Отправьте сообщение">
    Введите запрос и отправьте его. Agent использует выбранные навыки только для этого сообщения. В сообщении появится плашка навыка, чтобы вы видели, какие навыки активны.
  </Step>
</Steps>

Например, прикрепите **Stock Analyzer** и попросите Agent подготовить отчёт об исследовании акций или прикрепите **Deep Research**, чтобы Agent изучил тему и представил структурированные результаты.

<Tip>
  Навыки, прикреплённые в чате, ничего не устанавливают в вашем проекте. Они мгновенно доступны во всех проектах.
</Tip>

<div id="iniciar-um-projeto-com-uma-skill">
  ## Начните проект с навыка
</div>

При создании нового проекта можно выбрать готовый навык в качестве отправной точки. Agent использует инструкции навыка для настройки структуры проекта.

<Steps>
  <Step title="Откройте выбор отправной точки">
    На экране создания нового проекта нажмите **+** и выберите **Использовать навык**.
  </Step>

  <Step title="Выберите навык">
    Просмотрите подобранные навыки, например **AI SDR**, **SEO Auditor**, **Ad Creative** или **Programmatic SEO**. Выберите тот, который соответствует типу приложения, которое вы хотите создать.
  </Step>

  <Step title="Опишите приложение">
    Расскажите Agent, что вы хотите создать. Agent создаст проект с шаблонами и соглашениями выбранного навыка, применёнными с самого начала.
  </Step>
</Steps>

<div id="instalar-uma-skill-no-seu-projeto">
  ## Установка навыка в проект
</div>

Чтобы Agent последовательно применял навык во всех беседах в проекте, установите его. Установленные навыки хранятся в каталоге `/.agents/skills` вашего проекта и сохраняются между сеансами чата.

<div id="instalar-pelo-painel-de-skills">
  ### Установка через панель навыков
</div>

Откройте **панель навыков** в Project Editor и выберите вкладку **Discover**, чтобы найти навыки, созданные сообществом. Найдите нужный навык, нажмите **Install**, и она автоматически добавится в ваш проект.

<Frame>
  <img src="/assets/mirror/agent-skills-discover-732b2b0c488a.png" alt="Вкладка Discover в навыках с навыками от сообщества, поиском и кнопками установки" width="2542" height="1850" data-path="images/replitai/agent-skills-discover.png" />
</Frame>

Например, при создании сайта-портфолио со сложными анимациями можно установить:

* **GSAP React** — обучает Agent анимациям, запускаемым при прокрутке, появлению текста и прорисовке SVG-контуров
* **Tailwind design system** — даёт Agent знания о паттернах Tailwind CSS для типографики, отступов и переходов отображения
* **Find навыки** — обучает Agent находить и устанавливать новые навыки от вашего имени

<Tip>
  Навыки также можно устанавливать через [CLI npx skills](https://github.com/vercel-labs/skills):

  ```bash theme={null}
  npx skills <skill> -a replit
  ```
</Tip>

<div id="criar-uma-skill-a-partir-de-uma-conversa">
  ### Создание навыка на основе conversa
</div>

Самый естественный способ создать навык — сделать это в conversa с Agent. После совместного решения проблемы или изучения новой библиотеки попросите Agent сохранить полученные знания:

<AiPrompt>
  Изучи лучшие практики интеграции GSAP с React и создай навык для этого проекта.
</AiPrompt>

Agent использует весь context conversa, чтобы создать подробный файл навыка. Этот подход особенно эффективен после отладки, когда у вас сформировалось общее понимание проблемы.

<div id="escrever-uma-skill-personalizada">
  ### Создание собственного навыка
</div>

Для сложных сценариев создавайте навыки напрямую в соответствии со [спецификацией навыков Agent](https://agentskills.io/specification). Включите **Показывать скрытые файлы** на боковой панели файлов, откройте `/.agents/skills/` и создайте новый файл Markdown. Это даёт полный контроль над тем, что знает Agent и как он себя ведёт.
