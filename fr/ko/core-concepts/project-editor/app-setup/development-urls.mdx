Les URL de développement vous permettent de prévisualiser et de tester votre application pendant son développement. Elles suivent le format `UUID.servername.replit.dev` et offrent un aperçu en direct de l’application en cours de développement.

<Frame>
  <img src="/assets/mirror/preview-dev-url-b36770b33769.png" alt="URL de développement affichée dans la barre d’adresse" width="1222" height="824" data-path="images/workspace/preview-dev-url.png" />
</Frame>

Pour afficher l’URL de développement, cliquez sur le texte `{...}.replit.dev` dans la barre d’adresse.

<div id="url">
  ## Comprendre les URL de développement
</div>

Les URL de développement ne sont actives que lorsque vous travaillez activement sur une application Replit. Elles peuvent changer chaque fois que vous rouvrez l’application. Elles vous permettent de visualiser votre travail dans le navigateur pendant le développement et les tests.

Par défaut, les URL de développement sont accessibles publiquement sur le Web. Toute personne disposant de l’URL peut voir l’application en cours de développement. Vous pouvez ainsi facilement partager votre travail en cours avec des collaborateurs, des testeurs et des parties prenantes.

<Warning>
  Les URL de développement sont temporaires et réservées aux tests. Pour partager votre application avec d’autres personnes, nous vous recommandons plutôt de [publier votre application](/fr/ko/learn/projects-and-artifacts/replit-deployments).
</Warning>

<div id="section">
  ### Bannière informative
</div>

Lorsque vous ouvrez l’aperçu de développement dans un nouvel onglet, une bannière informative apparaît en haut de la page. Elle vous aide à comprendre le rôle de l’URL `.replit.dev` lorsque vous développez et testez votre application. Elle fournit des informations sur l’URL de développement et son utilisation au cours du processus de développement.

<div id="url-2">
  ## Rendre une URL de développement privée
</div>

Vous pouvez préserver la confidentialité de votre travail en cours en limitant l&#39;accès à l&#39;URL de développement.

Pour rendre une URL de développement privée :

1. Dans le Project Editor, ouvrez **Developer tools**.
2. Sélectionnez l&#39;onglet **Networking**.
3. Activez le bouton à bascule **Private development URL**.

Une fois cette option activée, une authentification est requise pour accéder à l&#39;URL de développement. Seuls vous et les membres autorisés de votre équipe pouvez consulter le travail en cours.

<Note>
  Les clients Enterprise peuvent exiger des URL de développement privées pour tous les projets, renforçant ainsi la sécurité afin de protéger le travail de développement au sein de l&#39;environnement de l&#39;organisation.
</Note>

<div id="section-2">
  ## Bonnes pratiques
</div>

* Pendant le développement, utilisez des **URL privées** pour les applications sensibles ou propriétaires.
* Utilisez des **URL publiques** pour partager votre travail avec des parties prenantes externes ou tester votre application dans un autre navigateur pendant que vous la développez activement.
