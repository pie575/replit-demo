User Settings는 계정 전반의 모양, 동작, 키보드 단축키를 사용자 지정할 수 있는 옵션을 제공하는
Project Editor 도구입니다.

</Frame>

<div id="features">
  ## 기능
</div>

다음 설정 카테고리를 통해 Replit App 제작 경험을 원하는 대로 설정할 수 있습니다.

* **테마 사용자화**: Project Editor에 밝은 테마와 어두운 테마 중 하나를 선택합니다
* **Code intelligence**: 앱 제작 경험을 향상하는 AI 기반 기능을 구성합니다
* **에디터 환경설정**: 파일 편집기의 동작 방식과 표시 방식을 조정합니다
* **알림 제어**: alert 환경설정을 관리합니다
* **접근성 옵션**: 특별한 도움이 필요한 사용자도 Replit을 원활하게 사용할 수 있도록 합니다
* **키보드 단축키**: 자주 쓰는 작업을 실행하고 GUI를 이동할 키 조합을 설정합니다

</div>

<div id="appearance">
  ### 모양
</div>

Project Editor의 모양과 관련된 다음 설정을 사용자 지정할 수 있습니다.

* **테마 선택**: 라이트 및 다크 테마 프리셋, <a href="https://replit.com/themes" target="_blank">커뮤니티 테마</a> 또는 직접 만든 사용자 지정 테마 중에서 선택합니다
* **사용자 지정 테마**: [Themes](/ko/features/editor/themes) 편집기로 나만의 색 구성표를 만듭니다

<div id="file-editor-preferences">
  ### 파일 편집기 환경설정
</div>

다음 설정으로 파일 편집기의 모양과 동작을 제어할 수 있습니다.

* **Font size**: 가독성을 위해 텍스트 크기를 조정합니다
* **Auto close brackets**: 여는 괄호를 입력하면 닫는 괄호를 자동으로 삽입합니다
* **Indentation detection**: 파일을 열 때 들여쓰기 설정을 자동으로 감지합니다
* **Format pasted text indentation**: 붙여넣은 코드를 올바른 들여쓰기에 맞게 다시 정리합니다
* **Indentation character**: 코드 들여쓰기에 공백과 탭 중 무엇을 사용할지 선택합니다
* **Indentation size**: 들여쓰기 한 단계에 사용할 열 수를 설정합니다
* **Wrapping**: 줄 바꿈 동작을 설정합니다
* **Minimap**: 사이드바에 이동 가능한 코드 개요를 표시합니다
* **Multiselect modifier key**: 여러 파일을 선택할 때 사용할 키보드 보조 키를 설정합니다
* **Filetree Git status**: 파일 트리에 Git 상태 표시기를 보여줍니다

<div id="code-intelligence">
  ### Code intelligence
</div>

다음 설정을 통해 AI 기반 도구를 구성할 수 있습니다:

* **Semantic tokens**: 언어 서버가 제공하는 향상된 구문 강조를 사용합니다
* **AI code completion**: 코드를 입력하는 동안 인라인 코드 제안을 표시합니다
* **Accept suggestion on commit character**: 특정 문자를 입력하면 코드 제안을 자동으로 수락합니다

<div id="shell-and-preview-preferences">
  ### Shell 및 Preview 환경설정
</div>

Shell 및 Preview 도구의 동작을 사용자 지정합니다:

* **Shell 벨 소리 알림**: Shell 도구에서 문제가 발생하면 소리로 알립니다
* **자동 미리보기**: 서버가 사용 가능해지면 Preview 탭을 자동으로 엽니다
* **열린 포트 자동 전달**: 새로 감지된 포트의 처리 방식을 설정합니다

<div id="notifications">
  ### 알림
</div>

다음 알림 설정을 관리할 수 있습니다.

* **Agent 오디오 알림**: Agent가 피드백을 요청할 때 소리 재생
* **Agent 푸시 알림**: Agent가 피드백을 요청할 때 모바일 푸시 알림 수신

<div id="production-alerts">
  #### 프로덕션 알림
</div>

**Production Alerts**는 게시한 앱의 상태를 알려주는 별도의 이메일 알림 설정입니다. 제품 및 마케팅 이메일과는 별개로 동작하므로, 불필요한 알림에 시달리지 않고 중요한 소식만 받아볼 수 있습니다.

**Production Alerts**를 켜면 다음과 같은 내용을 이메일로 받습니다.

* **uptime 장애**: 게시한 앱이 다운되거나 온라인 상태를 유지하지 못할 때 알림을 받습니다.
* **보안 취약점**: 앱이 의존하는 소프트웨어에서 발견된 취약점을 알려주므로, 문제가 되기 전에 조치할 수 있습니다.
* **model 업데이트**: 앱이 사용하는 언어 model이 변경되거나 확인이 필요할 때 알림을 받습니다.

<Frame>
  <img src="/assets/mirror/production-alerts-highlight-bb76079f20fd.png" alt="알림 설정의 Production Alerts 섹션. 프로덕션 알림 이메일 토글과 보안 알림 severity 드롭다운이 빨간 사각형으로 강조되어 있음" width="2400" height="1364" data-path="images/workspace/production-alerts-highlight.png" />
</Frame>

이 설정은 다음 경로에서 확인할 수 있습니다.

1. 계정 메뉴에서 **Settings**를 엽니다.
2. **Personalization** tab을 선택합니다.
3. **Email Notifications** 섹션까지 스크롤하여 **Production Alerts**를 찾습니다.

게시한 앱이 오래된 언어 model을 사용하는 경우, Replit이 지원되는 model로 업그레이드하는 draft task를 미리 준비해 둡니다. 해당 task 링크가 담긴 이메일이 발송되므로, review 한 번으로 업그레이드를 마칠 수 있습니다.

<div id="accessibility">
  ### 접근성
</div>

다음 접근성 설정을 사용자 지정할 수 있습니다:

* **접근 가능한 터미널 출력**: Shell 및 Console 도구에서 스크린 리더 호환성을 활성화합니다

<div id="keyboard-shortcuts">
  ### 키보드 단축키
</div>

키보드 단축키 환경설정을 열려면 User Settings 도구에서 **Keyboard shortcuts** 탭을 선택하세요.

다음 방법으로 키 조합을 검색할 수 있습니다:

* **이름**: 검색 필드에 키보드 단축키의 이름이나 설명을 입력합니다
* **키 조합**: <img class="icon-svg" src="/assets/mirror/keyboard-7ba19771b671.svg" alt="키보드 아이콘" width="16" height="16" data-path="images/icons/keyboard.svg" />를 선택한 뒤 키 조합을 입력합니다

다음 동작으로 단축키를 관리할 수 있습니다:

* **추가**: **Add shortcut**을 선택합니다
* **수정**: <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="연필 아이콘" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> 연필 아이콘을 선택합니다
* **삭제**: <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="휴지통 아이콘" width="16" height="16" data-path="images/icons/trash-icon.svg" /> 휴지통 아이콘을 선택합니다
