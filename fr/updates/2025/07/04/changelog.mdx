<div id="web-search-for-agent">
  ### Web Search pour Agent
</div>

<Frame>
  <img src="/assets/mirror/web-search-6c28195531d4.jpg" alt="Interface Agent affichant les résultats de Web Search et les sources citées pour le développement d'applications" width="1920" height="1080" data-path="images/replitai/web-search.jpg" />
</Frame>

Agent peut désormais effectuer des recherches sur le Web et récupérer des informations à jour avec [Web Search](/fr/core-concepts/agent/web-search). Créez des applications à partir de la documentation la plus récente, de données de marché actuelles et d&#39;informations précises provenant de tout le Web. Fini les limites de connaissances : vos applications utilisent désormais les informations les plus récentes disponibles.

<div id="custom-agent-instructions">
  ### Instructions personnalisées pour Agent
</div>

<Frame>
  <img src="/assets/mirror/replitmd-65360844a148.jpg" alt="fichier replit.md montrant les options de personnalisation du projet" width="1920" height="1080" data-path="images/replitai/replitmd.jpg" />
</Frame>

Personnalisez votre expérience avec Agent grâce à [replit.md](/fr/core-concepts/agent/replit-dot-md). Ce fichier spécial vous permet de définir votre style de programmation, les préférences de votre projet et son contexte. Agent crée automatiquement ce fichier en s&#39;appuyant sur des bonnes pratiques éprouvées, puis vous pouvez le personnaliser en fonction de votre flux de travail.

<div id="effort-based-billing">
  ### Facturation basée sur l’effort
</div>

<Frame>
  <img src="/assets/mirror/effort-based-billing-d971548c7c39.png" alt="Interface de facturation basée sur l’effort montrant une tarification dynamique selon l’effort de l’agent" width="2048" height="1424" data-path="images/changelog/2025-07-04/effort-based-billing.png" />
</Frame>

Découvrez une tarification des checkpoints plus intelligente grâce à notre nouvelle [facturation basée sur l’effort](/fr/billing/ai-billing). La tarification dynamique, basée sur l’effort réel de l’Agent, génère un seul checkpoint par exécution plutôt que plusieurs.

<div id="teams-app-store-experience">
  ### Expérience App Store pour les Teams
</div>

Découvrez et gérez les applications de votre équipe comme jamais auparavant. La nouvelle expérience « App Store » pour les organisations, disponible sur la page Deployments, vous permet de marquer vos favoris, de rechercher parmi tous les déploiements, de consulter les applications récemment ouvertes et de découvrir les déploiements populaires selon leur volume de trafic.
