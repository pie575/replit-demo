Agent 커스터마이징은 첫 번째 프롬프트부터 여러분과 팀이 작업하는 방식대로 Agent가 작업할 수 있도록 필요한 컨텍스트를 제공합니다. 매 프로젝트마다 규칙을 다시 설명하는 대신, 워크스페이스에 한 번만 정의하면 Agent가 모든 곳에 이를 적용합니다.

여기에는 두 가지 부분이 있습니다:

* **커스텀 지침**: 워크스페이스의 모든 프로젝트에 적용되는 상시 활성 가이드라인.
* **스킬**: 관련 작업이 발생할 때만 Agent가 로드하는 재사용 가능한 지침.

두 가지 모두 **워크스페이스 설정 → 커스터마이징**에서 관리합니다.

## 커스텀 지침과 스킬

커스텀 지침은 모든 메시지에서 로드되며, 스킬은 Agent가 작업이 관련 있다고 판단할 때만 로드됩니다. 항상 참인 몇 가지 가이드라인에는 커스텀 지침을 사용하고, 특정 워크플로우, 규칙, 참고 자료에는 스킬을 사용하세요.

이러한 구분의 이유 — 컨텍스트 예산, 무엇이 어디에 속하는지, 스킬을 잘 작성하는 방법 — 에 대해서는 [Agent 스킬](/ko/learn/agent-skills)을 참조하세요. 스킬이 어떻게 구성되고 Agent가 이를 어떻게 로드하는지는 [Agent 스킬](/ko/features/agent/skills)을 참조하세요.

## 커스텀 지침

커스텀 지침은 누군가 프롬프트를 입력하기 전에 모든 프로젝트와 모든 세션에서 Agent의 컨텍스트에 주입되는 상시 활성 가이드라인입니다. 워크스페이스 설정에서 한 번 작성하면 Agent가 워크스페이스 전체에 이를 적용합니다. 보안 및 컴플라이언스 요구 사항, 승인된 라이브러리 및 프레임워크, 데이터 처리 정책과 같이 항상 참인 가이드라인에 가장 적합합니다.

간결하게 작성하세요. 집중되고 구체적인 지침일수록 더 정확히 준수될 가능성이 높으며, Agent가 실제로 수행하는 작업에 더 많은 여지를 남깁니다.

<Warning>
  커스텀 지침은 Agent 성능에 영향을 줄 수 있습니다. Agent는 이를 따르도록 안내되지만 엄격한 요구 사항이 보장되지는 않습니다. 더 짧고 구체적인 가이드라인일수록 더 안정적으로 준수됩니다.
</Warning>

<Note>
  워크스페이스 커스텀 지침은 프로젝트의 `custom_instruction/instructions.md` 파일과 다릅니다. 워크스페이스 커스텀 지침은 워크스페이스 설정에서 한 번 설정되어 모든 프로젝트에 적용됩니다. 프로젝트별 파일은 단일 프로젝트 내부에 있습니다 — 해당 패턴에 대해서는 [커스텀 디자인 시스템 만들기](/ko/teams/custom-design-system)를 참조하세요.
</Note>

## 스킬

스킬은 관련 작업이 발생할 때만 Agent가 로드하는 재사용 가능한 지침 세트입니다. 워크스페이스 스킬은 워크스페이스의 모든 프로젝트에서 **+** 메뉴 맨 위에 표시되므로 전체 팀이 동일한 세트를 공유합니다.

스킬을 만드는 방법은 세 가지입니다:

* **업로드**: 기존 스킬 폴더를 업로드합니다.
* **작성**: 양식에서 직접 새 스킬을 작성합니다.
* **Agent에게 요청**: Agent에게 스킬 초안을 작성하도록 요청한 다음 다듬습니다.

<Note>
  Agent가 초안 작성한 스킬을 워크스페이스에 업로드할 수 있습니다. Agent에게 스킬을 다운로드하도록 요청하세요. Agent는 스킬을 다운로드 가능한 `.zip` 아카이브로 패키징하고 **파일 다운로드** 버튼을 제공합니다(아래 참조). zip을 다운로드한 다음 **워크스페이스 설정 → 커스터마이징 → 스킬**에서 **스킬 만들기 → 파일 또는 폴더 선택**을 통해 다시 업로드하면 워크스페이스 전체에서 공유됩니다.
</Note>

<Frame>
  <img src="/assets/mirror/agent-customization-download-skill-3727b188c5a8.png" alt="Agent가 워크스페이스 스킬을 다운로드 가능한 ux-designer-skill.zip 아카이브로 패키징하고 파일 다운로드 버튼을 표시" width="1716" height="864" data-path="images/replitai/agent-customization-download-skill.png" />
</Frame>

전체 스킬 구조(`SKILL.md`, 지원 파일, 공개 표준)에 대해서는 [Agent 스킬](/ko/features/agent/skills)을 참조하세요. Replit과 파트너가 이미 만든 스킬을 둘러보려면 [스킬 디렉터리](/ko/features/agent/skills-directory)를 참조하세요.

<Note>
  스킬은 적절히 사용하세요. Agent는 각 작업마다 모든 스킬의 이름과 설명을 읽으므로, 너무 많은(또는 중복되는) 스킬은 Agent의 초점을 흐리고 올바른 스킬을 선택하기 어렵게 만들 수 있습니다. 각 스킬의 범위를 좁게 유지하고 더 이상 필요하지 않은 스킬은 제거하세요.
</Note>

## 사용 가능 여부 및 권한

| 기능     | 사용 가능 플랜         | 관리 가능자                                    |
| ------ | ---------------- | ----------------------------------------- |
| 커스텀 지침 | Pro 및 Enterprise | Enterprise: 관리자. Pro: 모든 워크스페이스 멤버        |
| 스킬     | 모든 유료 플랜         | Enterprise: 관리자. Core 및 Pro: 모든 워크스페이스 멤버 |

Enterprise 워크스페이스에서는 관리자만 커스텀 지침과 스킬을 만들고, 편집하고, 삭제할 수 있습니다. Pro 워크스페이스에서는 모든 워크스페이스 멤버가 이를 할 수 있습니다. Core 워크스페이스에서는 모든 멤버가 스킬을 관리할 수 있습니다 — 커스텀 지침은 Core에서 사용할 수 없습니다. 어느 경우든 워크스페이스의 모든 멤버는 만들어진 스킬을 사용할 수 있습니다.

## 커스텀 지침 만들기

<Steps>
  <Step title="워크스페이스 설정 열기">
    **워크스페이스 설정 → 커스터마이징**으로 이동합니다.

    <Frame>
      <img src="/assets/mirror/agent-customization-tab-930af2e8ed74.png" alt="워크스페이스 설정의 커스터마이징 탭, 스킬 및 커스텀 지침 하위 탭 표시" width="1065" height="394" data-path="images/replitai/agent-customization-tab.png" />
    </Frame>
  </Step>

  <Step title="지침 작성">
    **커스텀 지침** 섹션에서 모든 프로젝트에 Agent가 적용할 가이드라인을 작성합니다.
  </Step>

  <Step title="저장">
    변경 사항을 저장합니다. 지침은 워크스페이스의 새 프로젝트에 적용됩니다.
  </Step>
</Steps>

## 스킬 만들기

<Steps>
  <Step title="워크스페이스 설정 열기">
    **워크스페이스 설정 → 커스터마이징**으로 이동합니다.
  </Step>

  <Step title="스킬 만들기">
    **스킬** 섹션에서 **스킬 만들기**를 클릭한 다음 스킬 폴더를 업로드하거나, 지침을 작성하거나, Agent에게 초안 작성을 요청합니다.

    <Frame>
      <img src="/assets/mirror/agent-customization-create-skill-fcb794e6de4e.png" alt="워크스페이스 설정의 커스터마이징 탭, 스킬 및 커스텀 지침 하위 탭과 열려 있는 스킬 만들기 양식" width="2168" height="1350" data-path="images/replitai/agent-customization-create-skill.png" />
    </Frame>
  </Step>

  <Step title="명확한 설명 작성">
    스킬에 언제 사용해야 하고 언제 사용하지 않아야 하는지를 명확히 나타내는 정확한 설명을 붙이세요. Agent는 이 설명을 읽고 스킬이 적용되는지 판단합니다.
  </Step>

  <Step title="저장">
    스킬을 저장합니다. 워크스페이스의 모든 프로젝트에 있는 **+** 메뉴에서 사용할 수 있게 됩니다.
  </Step>
</Steps>

## 프로젝트에서 워크스페이스 스킬 사용하기

정확한 스킬 설명이 중요합니다. Agent는 모든 워크스페이스 스킬의 설명을 읽고, 프롬프트가 스킬의 용도와 대략적으로 일치할 때 자동으로 스킬을 가져오므로 항상 직접 스킬을 선택할 필요는 없습니다. 스킬이 반드시 적용되도록 하려면 직접 명시적으로 선택할 수도 있습니다.

수동으로 선택하려면:

<Steps>
  <Step title="스킬 선택기 열기">
    프로젝트에서 채팅 입력창 옆의 **+** 버튼을 클릭합니다. 워크스페이스 스킬이 맨 위에 그룹으로 표시됩니다.

    <Frame>
      <img src="/assets/mirror/agent-customization-skill-picker-4643f3a453c7.png" alt="+ 버튼에서 열린 스킬 선택기, Replit 스킬 위에 맨 위에 표시된 워크스페이스 스킬 그룹" width="1668" height="1170" data-path="images/replitai/agent-customization-skill-picker.png" />
    </Frame>
  </Step>

  <Step title="스킬 선택">
    활성화하려는 스킬을 선택합니다. `/` 뒤에 스킬 이름을 입력하여 직접 호출할 수도 있습니다.
  </Step>

  <Step title="계속 프롬프트 작성">
    평소와 같이 계속합니다. 작업이 설명과 일치하면 Agent가 스킬을 사용합니다.
  </Step>
</Steps>

## 지침 및 스킬 관리

모든 관리는 **워크스페이스 설정 → 커스터마이징**에서 이루어집니다. 여기에서 커스텀 지침을 편집하고, 모든 스킬을 편집, 비활성화, 삭제할 수 있습니다. 변경 사항은 이후 채팅에 적용되며 이미 진행 중인 채팅에는 적용되지 않습니다.
