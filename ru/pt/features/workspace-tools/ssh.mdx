<div id="o-que-ssh">
  ## Что такое SSH?
</div>

SSH (Secure Shell) — это защищённый протокол, обеспечивающий удалённый доступ к интерфейсу командной строки вашего Replit App. С помощью SSH вы можете легко передавать файлы и использовать предпочитаемую локальную интегрированную среду разработки (IDE) для редактирования кода в Replit, повышая эффективность совместной работы и продуктивность в процессе разработки.

Функция SSH доступна в тарифах Core, Pro и всех других платных тарифах.

Вот краткий обзор процесса:

* Создайте пару SSH-ключей на локальном компьютере
* Добавьте этот SSH-ключ на панель **SSH** в любом Replit App
* Подключитесь с помощью SSH-клиента или редактора, поддерживающего работу через SSH (например, [VSCode](https://code.visualstudio.com/) или [Cursor](https://www.cursor.com/))

<Note>
  SSH-ключи связаны с вашей учётной записью, а не с конкретным Replit App. Это означает, что вам нужно добавить открытый ключ только один раз, после чего вы сможете подключаться к любому Replit App, к которому у вас есть доступ.
</Note>

<div id="por-que-usar-ssh">
  ## Зачем использовать SSH?
</div>

* **Автоматическая синхронизация Replit App и редактора**: любые изменения, внесённые в Replit App, мгновенно отображаются в вашем редакторе, и наоборот. Благодаря этому кодовая база всегда остаётся актуальной на обеих платформах.

* **Синхронизация операций с файлами**: добавление, удаление и обновление файлов синхронизируются в реальном времени между вашим редактором и Replit App. Благодаря этому структура проекта остаётся согласованной независимо от того, где были внесены изменения.

* **Управление папками и перемещение файлов**: перемещение файлов между папками также синхронизируется между вашим редактором и Replit App. Это гарантирует, что изменения в организации файлов, внесённые в одной среде, точно отражаются в другой, сохраняя целостность и структуру проекта.

<div id="encontre-ou-crie-um-par-de-chaves">
  ## Найдите или создайте пару ключей
</div>

Чтобы настроить SSH для своей учётной записи, вам понадобится открытый SSH-ключ.

<div id="verificando-se-voc-j-tem-um-par-de-chaves">
  ### Проверка наличия пары ключей
</div>

Чтобы проверить, есть ли у вас открытый ключ, выполните следующую команду в терминале на локальном компьютере:

<Tabs>
  <Tab title="Mac/Linux">
    ```sh theme={null}
    ls -l ~/.ssh
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    dir %HOMEPATH%\.ssh
    ```
  </Tab>
</Tabs>

Если возникнет ошибка, ничего страшного — перейдите к разделу [Создание новой пары ключей](#generating-a-new-keypair).
Если вы увидите файл `replit.pub`, перейдите к разделу [Получение содержимого открытого ключа](#get-the-contents-of-your-public-key).

<div id="gerando-um-novo-par-de-chaves">
  ### Создание новой пары ключей
</div>

На компьютере откройте Терминал (или Командную строку) и вставьте следующую команду:

<Tabs>
  <Tab title="Mac/Linux">
    ```bash theme={null}
    ssh-keygen -t ed25519 -f ~/.ssh/replit -q -N ""
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    ssh-keygen -t ed25519 -f %HOMEPATH%\.ssh\replit -q -N ""
    ```
  </Tab>
</Tabs>

Эта команда проверяет, существует ли файл указанного открытого SSH-ключа. Если его нет, она создаёт новый SSH-ключ с подходящими параметрами.

<div id="obtenha-o-contedo-da-sua-chave-pblica">
  ### Получите содержимое открытого ключа
</div>

Убедитесь, что у вас есть пара ключей, или создайте её, затем выведите содержимое открытого ключа — одного из двух файлов с похожими именами и суффиксом `.pub`. Оно понадобится позже.

<Tabs>
  <Tab title="Mac/Linux">
    ```sh theme={null}
    cat ~/.ssh/replit.pub
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    notepad %HOMEPATH%\.ssh\replit.pub
    ```
  </Tab>
</Tabs>

Сохраните содержимое `replit.pub`, чтобы использовать его позже в этой статье, и перейдите к разделу [добавления SSH-ключа в учётную запись](#add-the-ssh-key-to-your-account).

<div id="adicione-a-chave-ssh-sua-conta">
  ## Добавьте SSH-ключ в свою учётную запись
</div>

<div id="adicione-a-chave-pblica-diretamente-em-um-replit-app-usando-o-painel-ssh">
  ### Добавьте открытый ключ непосредственно в Replit App через панель SSH
</div>

1. В любом окне Replit App нажмите кнопку **+** и найдите **SSH**.

<Frame>
  <img src="/assets/mirror/ssh-tool-2db02c6a83d0.png" alt="Кнопка инструмента SSH в интерфейсе Replit" width="846" height="328" data-path="images/ssh-vscode/ssh-tool.png" />
</Frame>

2. Перейдите на вкладку **Keys** и выберите **New SSH key**.
3. Во всплывающем окне укажите **Label** для ключа (например, my-ssh-key) и вставьте скопированный открытый ключ в поле **Key**.
   Нажмите кнопку **Add SSH Key**. Ключ будет добавлен и авторизован для использования.

<Frame>
  <img src="/assets/mirror/add-ssh-key-with-values-5d6f440e56ba.png" alt="Диалоговое окно Add SSH key с заполненными полями label и ключа" width="500" height="511" data-path="images/ssh-vscode/add-ssh-key-with-values.png" />
</Frame>

<div id="adicione-a-chave-pblica-diretamente-em-settings">
  ### Добавьте открытый ключ непосредственно в Settings
</div>

Вы также можете добавить SSH-ключ: откройте **Settings**, в разделе **Account** выберите **Advanced** (или **SSH keys**). Нажмите **Add SSH key** и вставьте содержимое файла `replit.pub` из предыдущего раздела [Найдите или создайте пару ключей](#find-or-create-a-keypair).

<Note>
  Если на вашем компьютере несколько открытых ключей, убедитесь, что в конфигурации SSH используется правильная пара закрытого и открытого ключей.
</Note>

<div id="conectando-se-ao-seu-replit-app">
  ## Подключение к Replit App
</div>

<div id="configure-seu-arquivo-de-configurao-ssh">
  ### Настройте файл конфигурации SSH
</div>

1. В терминале убедитесь, что каталог `~/.ssh` и файл `~/.ssh/config` существуют:

<Tabs>
  <Tab title="Mac/Linux">
    ```sh theme={null}
    mkdir -p ~/.ssh && chmod 700 ~/.ssh && touch ~/.ssh/config && chmod 600 ~/.ssh/config
    open -a 'TextEdit' ~/.ssh/config || nano ~/.ssh/config
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    if not exist %HOMEPATH%\.ssh mkdir %HOMEPATH%\.ssh && type \NUL > %HOMEPATH%\.ssh\config
    notepad %HOMEPATH%\.ssh\config
    ```
  </Tab>
</Tabs>

2. Добавьте блок конфигурации, чтобы использовать пару ключей `replit` для всех доменов *.replit.dev:

<Tabs>
  <Tab title="Mac/Linux/Windows">
    ```
    Host *.replit.dev
        Port 22
        IdentityFile ~/.ssh/replit
        StrictHostKeyChecking accept-new
    ```
  </Tab>
</Tabs>

<div id="conecte-se-pelo-vscode-ou-cursor">
  ### Подключение через VS Code или Cursor
</div>

1. В Replit App откройте панель **SSH**.

2. На панели SSH перейдите на вкладку **Connect** и выберите **Launch VS Code**.

<Tabs>
  <Tab title="Подключение через VS Code">
    <img src="/assets/mirror/ssh-connect-439a3c150846.png" alt="Вкладка Connect панели SSH с опцией Launch VS Code" width="788" height="482" data-path="images/ssh-vscode/ssh-connect.png" />
  </Tab>
</Tabs>

3. Если будет предложено заполнить `~/.ssh/config`, вставьте следующее:

   ```
   Host *.replit.dev
       Port 22
       IdentityFile ~/.ssh/replit
       StrictHostKeyChecking accept-new
   ```

   <Note>
     Добавить конфигурацию SSH предлагается только при первой попытке подключиться к VS Code или другому редактору. Чтобы вернуться к файлу конфигурации, выберите **Configure SSH Hosts...**.
   </Note>

4. Если появится предупреждение о внешнем приложении, выберите **Yes**, чтобы подтвердить открытие проекта в предпочитаемом редакторе или VS Code.

5. Возможно, вам потребуется периодически устанавливать или обновлять расширения SSH. Replit стремится поддерживать совместимость с последними версиями этих IDE, и вы также можете получать важные обновления безопасности.

<div id="conecte-se-manualmente">
  ### Подключение вручную
</div>

В нижней части вкладки &quot;Connect&quot; панели **SSH** вы найдете пункт &quot;Connect manually&quot;.

Скопируйте эту команду и вставьте её в локальный терминал (Mac или Linux) или в локальную командную строку (Windows), чтобы подключиться напрямую.

<div id="conecte-se-por-meio-de-uma-ferramenta-no-listada-aqui">
  ### Подключение с помощью инструмента, не указанного здесь
</div>

Для разных платформ и операционных систем доступно множество SSH-клиентов, многие из которых предлагают различные функции или интеграции.

Вы всегда можете разбить команду, отображаемую в разделе &quot;Connect Manually&quot;, на отдельные компоненты, чтобы понять, как настроить каждый клиент:

```sh theme={null}
ssh -i ~/.ssh/replit -p 22  c96b6ade-d5e4-4f7a-bc5b-52334509b2a3@c96b6ade-d5e4-4f7a-bc5b-52334509b2a3-00-16nh2hskw3ql8.riker.replit.dev
       ^-----v-----^    ^^  ^-----------------v----------------^ ^------------------------------v-------------------------------------^
        Private Key   Port                   User               @                           Hostname
```

**Имя хоста**: `<your_hostname>.<cluster>.replit.dev`
**Порт**: `<port_number>`
**Пользователь**: `Username`
**Закрытый ключ**: путь к файлу закрытого ключа на вашем компьютере. Обычно он находится рядом с `replit.pub`.
