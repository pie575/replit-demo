使用 Publishing，你只需简单几步就能将 Replit 应用分享给全世界。

<Note>
  将应用上线的操作称为“Publishing”。本页将介绍可用的部署类型。
</Note>

<div id="section">
  ## 什么是发布？
</div>

发布功能会将 Replit 应用的**快照**保存到云端，让任何人都能与之交互。快照会捕获 Replit 应用文件的当前状态。

发布 Replit 应用后，系统会创建一个**已发布应用**。已发布应用是运行在 Replit 云基础设施上的应用实例。这样一来，应用便可独立于 Project Editor 中的版本，稳定地在互联网上提供访问。

<Info>
  Replit 的基础设施由 Google Cloud Platform (GCP) 提供支持。所有
  已发布应用均托管在美国。企业客户如需
  将已发布应用托管在欧盟境内，请联系销售团队。

  个人、组织和企业客户均可获得用于已发布应用的专用单租户 GCP 项目。也就是说，已发布应用的计算资源、密钥和存储完全隔离，不会与其他客户的应用共享。
</Info>

其中还包含用于监控已发布应用状态和查看网页分析数据的工具。

Replit 提供以下部署类型：

<div id="section-2">
  ## 开始使用
</div>

按照以下步骤发布你的 Replit 应用：

1. 在 Project Editor 中，选择顶部的 <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="发布图标" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **发布**。
2. 在**发布**标签页中，选择发布选项。
3. 如果出现**添加付款方式**提示，请按提示添加付款方式。

Replit 会根据项目类型和需求，自动为你的应用选择最合适的发布选项。

如果你想改用其他部署类型，可参考以下信息。

<div id="section-4">
  ## 主要功能
</div>

发布功能提供以下便利特性：

* **多种发布选项**：只需点击几下，即可选择或更改符合需求的部署类型。
* **自定义域名**：通过你自己的域名提供应用访问。
* **分析**：跟踪已发布应用的访客数据及其他指标。
* **监控工具**：查看已发布应用的状态和配置。
* **访问控制**：一键控制谁可以访问你的应用。仅 **Pro** 和 **Enterprise** 成员可用。
* **徽章设置**：Core 用户可在发布设置中管理&quot;Made with Replit&quot;徽章。如果你在 Starter 方案下发布了带徽章的应用，升级后徽章的移除可能需要几分钟才能生效。
* **收集反馈**：在已发布应用中启用反馈功能，收集用户的意见与洞察。

<div id="section-5">
  ## 工作原理
</div>

发布 Replit 应用时，Replit 会为应用的文件和依赖项创建一份快照。
该快照会被发送到 Replit 的云基础设施，并作为应用的独立实例运行。若要将最新更改同步到已发布应用，请再次发布以生成新的快照。

<Warning>
  请勿将数据保存到已发布应用的文件系统中，也不要依赖这些数据。
  如需保存数据，请使用 Replit 的 Storage、Database 等存储和数据库方案 ([存储与数据库](/zh/ja/learn/projects-and-artifacts/storage-and-databases)) 。
</Warning>

<div id="section-6">
  ## 使用场景
</div>

以下示例展示了各类已发布应用。

<div id="section-7">
  ### 自动扩缩部署：打字速度测试应用
</div>

当用户进行打字测试时，云端会自动扩容资源；无人使用时则自动缩容。

<div id="section-8">
  ### 静态部署：太阳系模拟
</div>

通过网页版太阳系可视化应用了解各大行星。
该可视化效果在浏览器中渲染，不会将用户输入发送到服务器。

<div id="vmdiscord">
  ### 预留虚拟机部署：Discord 机器人
</div>

运行一个帮助进行成员管理和新人引导的 Discord 机器人。
费用和性能可预测，让它始终在线，与用户聊天并响应命令。

<div id="section-9">
  ### 定时部署：家庭自动化触发器
</div>

在指定的时间和星期几调度 API 调用，以启动或关闭智能家居设备。
