## 데이터 시각화란 무엇인가요?

데이터 시각화는 Agent와의 대화를 통해 만드는 인터랙티브 대시보드 또는 리포팅 도구입니다. 시각화하고 싶은 것과 데이터가 어디에 있는지 설명하면 — Agent가 적절한 KPI, 차트 유형, 레이아웃을 자동으로 선택해 단 한 번의 프롬프트로 완성도 있는 대시보드를 생성합니다.

주요 개념:

* **한 번의 생성**: 목표와 데이터 소스를 설명하면 Agent가 적절한 차트와 지표가 담긴 완전한 대시보드를 빌드
* **연결된 데이터 소스**: 데이터베이스, [웨어하우스 커넥터](/ko/connectors/warehouses/overview), 외부 API, 업로드한 파일에서 가져오기
* **기본 제공 기능**: 모든 대시보드에는 새로고침, 자동 새로고침, PDF로 내보내기, 차트를 CSV로 내보내기, 라이트/다크 모드가 포함됩니다
* **분석 요약**: Agent가 요청과 결과 데이터를 바탕으로 인사이트를 생성
* **여러 아티팩트**: 데이터 시각화는 [같은 프로젝트](/ko/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project) 내 다른 아티팩트와 동일한 백엔드와 데이터베이스를 공유할 수 있습니다

## Data Visualization 사용 방법

### 프롬프트로 만들기

홈페이지에서 **App** 탭을 선택하고 원하는 대시보드를 설명하세요. Agent가 데이터 관련 프롬프트를 감지하고 Data Visualization 스택을 선택합니다.

**예시 프롬프트:**

* "지역별 매출을 추적하는 영업 분석 대시보드를 만들어줘"
* "월별 지표를 시각화하는 리포팅 도구를 만들어줘"
* "우리 BigQuery 판매 데이터로 상위 성과 제품을 보여주는 대시보드를 만들어줘"
* "Snowflake에 연결해서 고객 이탈 분석 대시보드를 만들어줘"

### 드롭다운으로 만들기

1. 홈페이지에서 **App** 탭으로 이동하세요.
2. 앱 유형 드롭다운을 여세요.
3. **Data Visualization**을 선택하세요.
4. 빌드하고 싶은 대시보드나 데이터 도구를 설명하세요.

### 데이터 웨어하우스 연결하기

[웨어하우스 커넥터](/ko/connectors/warehouses/overview)를 통해 데이터 시각화를 BigQuery, Databricks, Snowflake에 연결해 기존 데이터셋을 기반으로 대시보드를 빌드하세요.

웨어하우스 데이터를 조회할 때 Agent는 병렬 멀티 에이전트 검색을 사용해 스키마와 데이터셋을 탐색합니다. 이는 탐색 속도를 높이고 Agent가 대시보드에 적합한 테이블과 필드를 선택하는 데 도움이 됩니다.

시작하려면 프로젝트의 [Integrations](/ko/features/integrations/overview)에서 웨어하우스 커넥터를 설정한 다음, Agent에게 시각화하고 싶은 것을 알려주세요.

### 필터와 기능 추가하기

Agent가 대시보드를 빌드한 후에는 필터, 드릴다운, 기타 인터랙티브 기능을 추가하도록 프롬프트를 보낼 수 있습니다. 예를 들어 Agent에게 날짜 범위 필터, 지역 선택기, 검색창을 추가해달라고 요청하세요.

### 내보내기 및 공유하기

* **PDF로 내보내기**: 공유나 오프라인 검토를 위해 전체 대시보드를 PDF로 내보내세요.
* **차트를 CSV로 내보내기**: 스프레드시트나 다른 도구에서 추가 분석을 위해 개별 차트 데이터를 CSV 파일로 다운로드하세요.
* **분석 문서**: Agent에게 대시보드 데이터를 바탕으로 상세한 분석 문서를 작성하도록 요청하세요.

## 만들 수 있는 것

* **분석 대시보드**: 시간대별 매출, 가입, 참여도 같은 핵심 지표를 추적
* **리포팅 도구**: 데이터베이스에 직접 접근하지 않고도 이해관계자가 필터링하고 탐색할 수 있는 내부 리포트를 빌드
* **데이터 탐색 인터페이스**: 시각적 피드백과 함께 데이터셋을 탐색하고 조회
* **모니터링 패널**: API, 데이터베이스, 외부 서비스의 실시간 또는 준실시간 데이터를 표시

## 자주 묻는 질문

<Accordion title="어떤 데이터 소스를 연결할 수 있나요?">
  프로젝트의 Replit Database, 웨어하우스 커넥터(BigQuery, Databricks, Snowflake), 외부 API, CSV 같은 업로드된 파일에서 데이터를 가져올 수 있습니다. [Integrations](/ko/features/integrations/overview)를 통해 웨어하우스 연결을 설정하세요.
</Accordion>

<Accordion title="디자인과 느낌을 커스터마이징할 수 있나요?">
  네. 대화를 통해 색상, 레이아웃, 타이포그래피를 커스터마이징할 수 있습니다 — Agent에게 브랜드에 맞추거나 디자인을 조정해달라고 요청하세요. 대시보드는 라이트 및 다크 모드도 지원합니다.
</Accordion>

<Accordion title="Agent가 데이터를 대신 분석해주나요?">
  대시보드를 빌드한 후, Agent는 요청과 결과 데이터를 바탕으로 분석 요약을 생성합니다. 더 상세한 분석 문서를 요청할 수도 있습니다.
</Accordion>

<Accordion title="데이터 시각화를 다른 아티팩트 유형과 결합할 수 있나요?">
  네. [같은 프로젝트](/ko/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project) 내에서 데이터 시각화를 [웹 앱](/ko/features/artifact-types/web-apps), [슬라이드 덱](/ko/features/artifact-types/slide-decks), 다른 아티팩트 유형과 결합할 수 있습니다. 이들은 동일한 백엔드와 데이터베이스를 공유합니다.
</Accordion>
