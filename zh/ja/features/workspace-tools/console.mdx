title: "控制台"
description: "了解如何使用控制台查看应用输出、错误和活动日志。"
---

使用控制台，你可以实时监控和查看正在运行的 Replit 应用输出的日志。
你可以利用当前及过去运行的信息，了解应用运行情况、排查错误并优化性能。

<Tip>
  使用 Agent 调试时，请在提示词中附上控制台日志，为其提供上下文。
</Tip>

</Frame>

<div id="section">
  ## 功能
</div>

控制台提供以下工具，帮助您了解应用的运行情况：

* **实时日志记录**：应用产生输出时可立即查看
* **AI 协助**：获取有关修复日志中错误的建议
* **运行历史记录**：查看以往运行的日志，追踪变更

<div id="section-2">
  ## 使用方法
</div>

您可以直接从项目编辑器访问控制台工具。

<Accordion title="访问控制台">
  从左侧的**工具栏**：

  1. <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="所有工具图标" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> 选择**所有工具**，显示项目编辑器中的工具列表。
  2. <img class="icon-svg" src="/assets/mirror/console-8a41ac90789c.svg" alt="控制台图标" width="16" height="16" data-path="images/icons/console.svg" /> 选择**控制台**。

  从**搜索栏**：

  1. 选择顶部的<img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" />放大镜，打开搜索工具。
  2. 输入“控制台”查找该工具，然后从搜索结果中选择它。
</Accordion>

每次在 Replit 应用中使用**Run**按钮时，控制台都会显示一个新条目，其中包含以下信息：

* 运行代码所用的命令
* 时间戳
* 标准输出和错误日志

以下截图显示了用于启动应用的`npm run dev`命令，以及运行时产生的日志消息：

<div id="ai">
  ### 使用 AI 进行调试
</div>

当日志中显示错误或其他你想了解的信息时，选择条目顶部的 **Ask AI** 按钮。这会自动打开 **Agent** 标签页，并将日志内容发送以供分析。

<div id="section-3">
  ### 日志条目命令
</div>

控制台提供以下日志管理工具：

* **仅显示最新记录**：开启此选项后，仅显示最近一次运行。
* **折叠条目**：选择命令名称左侧的<img class="icon-svg" src="/assets/mirror/down-arrow-9c1cf9fd152e.svg" alt="向下箭头图标" height="16" width="16" data-path="images/icons/down-arrow.svg" />向下箭头以隐藏日志。
* **清除历史运行记录**：选择此项可删除历史运行日志。此操作无法撤销。

<div id="section-4">
  ### 网络可用性
</div>

您可以控制应用开发版本是否可在线访问。

要停止响应对开发 URL 的请求，请选择网络信息行右侧的<img class="icon-svg" src="/assets/mirror/network-off-5bdca8a4fe4e.svg" alt="网络关闭图标" height="16" width="16" data-path="images/icons/network-off.svg" />带斜杠的地球图标。

要重新启用，请选择<img class="icon-svg" src="/assets/mirror/network-on-15be2e5fb4f5.svg" alt="网络开启图标" height="16" width="16" data-path="images/icons/network-on.svg" />地球图标。

要查看开发 URL，请选择地址栏中的`{...}.replit.dev`文本。

<Frame>
  <img src="/assets/mirror/preview-dev-url-b36770b33769.png" alt="Preview 开发 URL 的位置" width="1222" height="824" data-path="images/workspace/preview-dev-url.png" />
</Frame>

<Note>
  即使设置为停止响应对开发 URL 的请求，您仍可在 Preview 工具中访问应用。
</Note>

<div id="section-5">
  ### 停止工作流命令
</div>

您可以通过控制台项目编辑器停止正在运行的工作流命令。

点击包含 Replit 应用运行命令的行右侧的方形按钮即可停止该命令。

要重启应用，请使用项目编辑器顶部工作流中的 **Run** 按钮。
