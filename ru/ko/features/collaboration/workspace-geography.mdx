title: "регион Workspace"
description: "Выберите регион размещения ресурсов разработки для рабочего пространства и новых проектов в нём."
---

регион Workspace определяет, где размещаются его ресурсы разработки. Он выбирается при создании рабочего пространства; новые проекты и ресурсы в нём будут размещаться в выбранном регионе.

<Note>
  регион Workspace и [регион
  публикации](/ru/ko/features/security/geography#publishing-geography) могут различаться.
  Регион публикации определяет, где запускаются опубликованные проекты.
</Note>

<div id="section">
  ## Что определяет регион Workspace
</div>

Рабочее пространство включает проекты, пользователей, настройки, общие ресурсы, интеграции и платёжную информацию. В каждом проекте используются Project Editor и чат Replit. Ресурсы для разработки включают разрабатываемую версию приложения и соответствующую базу данных.

Только пользователи Pro могут выбрать конкретный регион Workspace.

Для пользователей Free и Core регион Workspace определяется автоматически. Обычно выбирается ближайший к пользователю регион. Новые проекты и ресурсы в рабочем пространстве размещаются в этом регионе. После создания рабочего пространства изменить регион нельзя.

<div id="section-2">
  ## Выбор региона Workspace
</div>

Пользователи Pro могут выбрать регион при создании рабочего пространства.

<Steps>
  <Step>Откройте форму **Create a new workspace**.</Step>
  <Step>Введите название рабочего пространства и при необходимости адреса электронной почты участников.</Step>

  <Step>
    Откройте **Workspace region** и выберите **North America**, **Europe (EU)** или **Asia**.
  </Step>

  <Step>Нажмите **Create workspace**.</Step>
</Steps>

  ## Доступные регионы
</div>

| Регион               | Возможность выбора рабочего пространства |
| :------------------- | :--------------------------------------- |
| **Северная Америка** | Да                                       |
| **Европа (EU)**      | Да                                       |
| **Азия**             | Да                                       |
| **Южная Америка**    | Нет                                      |
| **Австралия**        | Нет                                      |
