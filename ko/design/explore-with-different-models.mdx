제안은 같은 디자이너가 여러 방향을 탐색하는 것이라면, 모델을 바꾸는 것은 디자이너 자체를 바꾸는 것입니다. 모델마다 저마다의 디자인 감각과 프런트엔드 강점이 있어, 동일한 브리프라도 이를 구동하는 모델이 달라지면 전혀 새로운 결과가 나올 수 있습니다.

<div id="switch-the-model">
  ## 모델 전환하기
</div>

채팅 작성기에서 모드 선택기(현재 모드가 표시됩니다. 예: **Power**)를 열고 **Primary model**을 선택한 뒤 목록에서 원하는 모델을 고르세요.

<Frame caption="Primary model 목록과 Effort 슬라이더가 표시된 Agent modes 팝오버.">
  <img src="/assets/mirror/model-selector-6826a87089a2.png" alt="Lite, Economy, Power 모드가 있는 Agent modes 팝오버. Power가 선택되어 있고 디자인 작업에 더 높은 성능의 모델을 사용한다고 설명되어 있으며, Primary model 목록에는 Kimi K3, Recommended로 표시된 Claude Fable 5, Claude Opus 5, GPT-5.6 Sol이 있고, Low에서 Max까지의 Effort 슬라이더가 있음" width="1432" height="786" data-path="images/design/replit-design/model-selector.png" />
</Frame>

현재 제공되는 모델:

* **Claude Fable 5**(권장)
* **Claude Opus 5**
* **GPT-5.6 Sol**
* **Kimi K3**

<Note>
  모델 구성은 새로운 모델이 출시될 때마다 달라집니다. 지금 내 계정에서 사용할 수 있는 모델은 제품 내 메뉴에서 확인하세요.
</Note>

같은 팝오버에서 두 가지 설정을 더 조정할 수 있습니다.

* **Mode**(Lite, Economy, Power): 속도, 비용, 성능 사이의 균형을 정합니다. Power는 디자인 작업에 더 높은 성능의 모델을 사용하므로 복잡한 디자인과 세밀한 시각적 변경에 가장 적합합니다. 자세한 내용은 [Agent modes](/ko/features/agent/agent-modes)를 참조하세요.
* **Effort**: 모델이 응답 하나에 들이는 추론의 양으로, Low(가장 빠름)부터 Max까지 설정할 수 있습니다. 모델마다 권장 설정이 표시됩니다.

<div id="explore-across-models">
  ## 여러 모델로 탐색하기
</div>

모델 전환은 [suggestions](/ko/design/explore-suggestions)와 함께 탐색의 또 다른 축입니다:

* **같은 브리프, 다른 디자이너**: frame을 하나 생성한 뒤 모델을 바꿔 같은 prompt를 다시 보내보세요. 두 방향이 모두 canvas에 frame으로 나타나므로 나란히 놓고 비교할 수 있습니다.
* **작업에 맞는 모델 고르기**: 대부분의 작업에는 추천 모델을 쓰고, 디자인에 다른 감각이 필요하거나 확신이 서지 않는 방향에 대해 다른 관점이 필요할 때 전환하세요.
* **언제든 전환 가능**: 모델은 다음 메시지부터 적용되므로 canvas의 작업물을 잃지 않고 project 진행 중에도 바꿀 수 있습니다.
