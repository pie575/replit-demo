<div id="agent-is-now-free-to-try">
  ### Agent 现可免费试用
</div>

Agent 和 Assistant 现均可免费试用！无论你是经验丰富的 Replit 开发者，还是刚刚起步的新手，现在都可以不受限制地体验这些强大工具。

前 10 个 checkpoint 免费 (现有付费开发者也适用) 。选择 [https://replit.com](https://replit.com) 立即试用。
