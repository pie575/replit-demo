<div id="workspace-security-center-20">
  ### Workspace Security Center 2.0
</div>

Examinez les vulnérabilités de dépendances de tous les projets de votre workspace et intervenez depuis un seul endroit. Le Workspace Security Center fait désormais remonter en premier les projets les plus à risque et vous permet de rechercher et de filtrer les projets concernés par gravité, statut de publication, visibilité et propriétaire. Vous pouvez aussi mener la correction de bout en bout sans quitter le Security Center : lancez une tâche Agent, examinez les correctifs proposés, puis republiez le projet. Vous pouvez également notifier les propriétaires de projets, individuellement ou en lot, dépublier immédiatement les projets les plus exposés et télécharger un SBOM pour vos audits de conformité.

<div id="section-3">
  ### Publication privée pour tous les utilisateurs
</div>

La publication d&#39;applications privées et protégées par mot de passe était jusqu&#39;à présent réservée aux plans Pro et Enterprise. Désormais, les builders des plans Core et Starter peuvent eux aussi publier en privé : chacun peut ainsi garder ses outils internes, ses applications en bêta ou ses projets en cours à l&#39;abri derrière une connexion Replit.

Pour en savoir plus, consultez [Private Deployment](/fr/ko/features/publishing/private-deployments).

<div id="private-deployment">
  ### Jetons d&#39;accès externes pour les déploiements privés
</div>

Les jetons d&#39;accès externes sont désormais disponibles pour les applications Replit privées. Générez un jeton pour configurer les intégrations qui accèdent à vos déploiements privés indépendamment des connecteurs (Slack, GitHub, Twilio, etc.). Ces jetons offrent aux utilisateurs avancés un contrôle accru sur leurs applications et renforcent la sécurité des applications Replit privées. Ouvrez **Ajuster les paramètres** de votre déploiement pour accéder au nouvel onglet **Jetons d&#39;accès externes**.

En savoir plus sur les [jetons d&#39;accès externes](/fr/references/publishing/external-access-tokens).

<div id="slide-decks">
  ### Notes de présentation et mode présentateur dans Slide Decks
</div>

Slide Decks prend désormais en charge les notes de présentation et un mode présentateur dédié. Les notes se synchronisent en temps réel et dans les deux sens entre l&#39;éditeur et la fenêtre de présentation : vous pouvez ainsi partager votre écran depuis un appareil tout en pilotant le deck à distance depuis un autre. Demandez à Agent de rédiger vos notes, puis affinez-les dans l&#39;éditeur pendant que votre public ne voit que les diapositives. Le mode présentateur est également disponible depuis la carte d&#39;artifact de diapositives sur mobile.

<div id="agent-svg">
  ### Prise en charge de l&#39;envoi de fichiers SVG dans Agent
</div>

Vous pouvez désormais joindre des fichiers SVG à Agent. Déposez un SVG dans la conversation ou collez-en l&#39;URL : Agent en lira le balisage comme pour n&#39;importe quelle autre pièce jointe. Les fichiers envoyés sont nettoyés dans le navigateur avant d&#39;atteindre Agent ou le stockage, ce qui élimine automatiquement les vecteurs d&#39;attaque courants reposant sur le SVG.

<div id="agent-2">
  ### Nouvelles icônes animées pour les modes Agent
</div>

Les modes Agent Lite, Economy et Power disposent désormais d&#39;icônes animées personnalisées qui évoquent les caractéristiques propres à chaque mode. Ces nouvelles icônes apparaissent dans le sélecteur de mode Agent ainsi que partout dans le workspace où les modes sont affichés.
