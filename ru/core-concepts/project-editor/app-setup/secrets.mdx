Инструмент Secrets хранит и шифрует **секреты** — конфиденциальную информацию вашего Replit App: ключи API, токены аутентификации и строки подключения к базе данных.

Когда вы добавляете секрет, инструмент автоматически шифрует данные и передаёт их вашему Replit App в виде переменной окружения.
Такой подход позволяет не прописывать секреты прямо в коде и снижает риск их утечки.

Секреты, жёстко прописанные в коде, могут случайно оказаться раскрыты в следующих случаях:

* Вы делитесь кодом с другими через общедоступный Replit App или копированием и вставкой
* Вы сохраняете код в системе контроля версий в публичном репозитории
* Вы ведёте прямую трансляцию или демонстрируете экран с вашим кодом

Используйте инструмент Secrets, чтобы уверенно делиться кодом, не опасаясь раскрытия учётных данных.

<div id="features">
  ## Возможности
</div>

Secrets предоставляет следующие возможности:

* **Сквозное шифрование**: автоматическая защита данных с помощью шифрования AES-256 при хранении и TLS при передаче
* **Секреты уровня приложения**: хранение секретов, относящихся к конкретному Replit App, и управление ими
* **Секреты уровня аккаунта**: хранение секретов, которые можно сделать доступными во всех ваших Replit App, и управление ими
* **Доступ через переменные окружения**: обращение к секретам из кода с помощью переменных окружения
* **Совместный доступ**: предоставление секретов соавторам и участникам команды

<div id="usage">
  ## Использование
</div>

<Note>
  Secrets доступны для всех типов развёртывания, кроме статических развёртываний.
</Note>

Открыть Secrets можно через одноимённый инструмент в Project Editor.

<Accordion title="Как открыть Secrets">
  На левой панели **Tool dock**:

  1. Нажмите <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="All tools icon" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**, чтобы увидеть список инструментов Project Editor.
  2. Выберите <img class="icon-svg" src="/assets/mirror/lock-af402c9618dd.svg" alt="Secrets icon" width="16" height="16" data-path="images/icons/lock.svg" /> **Secrets**.

  Через **строку поиска**:

  1. Нажмите значок лупы <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="magnifying glass icon" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> вверху, чтобы открыть инструмент поиска
  2. Введите «Secrets», чтобы найти инструмент, и выберите его в результатах.
</Accordion>

<div id="manage-app-secrets">
  ### Управление Secrets приложения
</div>

Вы можете управлять секретами приложения на вкладке **App Secrets** панели **Secrets**.
На этой вкладке отображается список всех секретов, связанных с вашим Replit App.

<Accordion title="Добавление Secrets приложения">
  Чтобы добавить секрет:

  1. Выберите **New Secret**.
  2. Введите **Key** — имя секрета — и **Value** — значение секрета.
  3. Выберите **Add Secret**, чтобы сохранить запись.
</Accordion>

<Accordion title="Редактирование Secrets приложения">
  Чтобы изменить секрет:

  1. Выберите меню с <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="значок с тремя вертикальными точками" height="16" width="16" data-path="images/icons/vertical-dots.svg" /> тремя вертикальными точками рядом с секретом.
  2. В контекстном меню выберите **Edit**.
  3. Измените текст в поле **Key** или **Value** и выберите **Update Secret**, чтобы сохранить изменения, или **Cancel**, чтобы отменить их.

  Вы также можете изменить весь список Secrets приложения, выбрав **Edit as JSON** или **Edit as .env** в нижней части вкладки.
</Accordion>

<Accordion title="Просмотр Secrets приложения">
  Чтобы просмотреть секрет, выберите значок <img class="icon-svg" src="/assets/mirror/eye-8a6472b8a950.svg" alt="значок глаза" width="16" height="16" data-path="images/icons/eye.svg" /> глаза рядом с секретом.

  Чтобы скрыть секрет, выберите значок <img class="icon-svg" src="/assets/mirror/eye-slash-6b4ded538179.svg" alt="значок глаза с косой чертой" width="16" height="16" data-path="images/icons/eye-slash.svg" /> глаза с косой чертой.
</Accordion>

<Accordion title="Удаление Secrets приложения">
  Чтобы удалить секрет, выберите меню с <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="значок с тремя вертикальными точками" height="16" width="16" data-path="images/icons/vertical-dots.svg" /> тремя вертикальными точками рядом с секретом, затем выберите **Delete**.
</Accordion>

<div id="manage-account-secrets">
  ### Управление Secrets аккаунта
</div>

Управлять секретами уровня аккаунта можно на вкладке **Account Secrets** в панели **Secrets**.
На этой вкладке отображаются только секреты, связанные с вашим аккаунтом Replit.

<Accordion title="Добавление Secrets аккаунта">
  Чтобы добавить секрет уровня аккаунта:

  1. Перейдите на вкладку **Account Secrets**.
  2. Нажмите значок <img class="icon-svg" src="/assets/mirror/settings-icon-c2664c3691bf.svg" alt="значок шестерёнки" width="16" height="16" data-path="images/icons/settings-icon.svg" />, чтобы открыть **Settings** и управлять секретами уровня аккаунта.
  3. Нажмите **New Secret**, чтобы добавить секрет.
  4. Введите **Key** — имя секрета — и **Value** — сам секрет.
  5. Нажмите **Save**, чтобы сохранить запись.
</Accordion>

<Accordion title="Изменение Secrets аккаунта">
  Чтобы изменить секрет:

  1. Нажмите значок карандаша <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="значок карандаша" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> рядом с секретом.
  2. Измените текст в поле **Key** или **Value** и нажмите **Save**, чтобы сохранить изменения, или **Cancel**, чтобы отменить их.
</Accordion>

<Accordion title="Просмотр Secrets аккаунта">
  Чтобы посмотреть секрет, нажмите значок глаза <img class="icon-svg" src="/assets/mirror/eye-8a6472b8a950.svg" alt="значок глаза" width="16" height="16" data-path="images/icons/eye.svg" /> рядом с секретом.

  Чтобы снова скрыть секрет, нажмите значок перечёркнутого глаза <img class="icon-svg" src="/assets/mirror/eye-slash-6b4ded538179.svg" alt="значок перечёркнутого глаза" width="16" height="16" data-path="images/icons/eye-slash.svg" />.
</Accordion>

<Accordion title="Привязка Secrets аккаунта">
  Чтобы использовать секрет уровня аккаунта в Replit App, его需 нужно привязать к приложению.
  Чтобы привязать секрет уровня аккаунта:

  1. Перейдите на вкладку **App Secrets**.
  2. Установите флажок слева от секрета.
  3. Нажмите **Link to this App**.

  Чтобы отвязать секрет:

  1. Перейдите на вкладку **App Secrets**.
  2. Откройте меню из трёх вертикальных точек <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" width="16" height="16" alt="значок трёх вертикальных точек" data-path="images/icons/vertical-dots.svg" /> рядом с секретом.
  3. Выберите **Unlink**.
</Accordion>

<Accordion title="Удаление Secrets аккаунта">
  1. Нажмите значок карандаша <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="значок карандаша" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> рядом с секретом.
  2. Выберите **Delete**.
</Accordion>

<div id="managing-secrets-visibility">
  ### Управление видимостью секретов
</div>

Видимость секретов зависит от вашего уровня доступа к Replit App и от того, являетесь ли вы его автором.

Поделиться своим Replit App можно одним из следующих способов:

* **Multiplayer**: пригласите пользователей Replit к совместной работе в реальном времени
* **Обложка**: покажите предварительный просмотр вашего Replit App с возможностью сделать его ремикс
* **Ремикс**: сделайте свой личный или принадлежащий организации Replit App публичным, чтобы другие могли создать собственную версию

В таблице ниже показано, кому доступны имена и значения секретов в различных сценариях:

| Способ доступа     | Кто                                                 | Видит имена | Видит значения |
| ------------------ | --------------------------------------------------- | ----------- | -------------- |
| Multiplayer        | Соавтор в Multiplayer                               | ✓           | ✓              |
| Multiplayer        | Участник организации (роль Owner)                   | ✓           | ✓              |
| Multiplayer        | Участник организации (не Owner)                     | ✓           |                |
| Обложка            | Любой посетитель                                    |             |                |
| Ремикс             | Владелец/соавтор, делающий ремикс своего Replit App | ✓           | ✓              |
| Ремикс             | Не владелец/соавтор, делающий ремикс Replit App     | ✓           |                |
| Ремикс             | Любой, кто делает ремикс с обложки                  | ✓           |                |
| Ремикс организации | Участник организации с ролью Owner                  | ✓           | ✓              |
| Ремикс организации | Участник организации без роли Owner                 | ✓           |                |

<Warning>
  Участники организации без роли Owner не могут просматривать значения секретов в Replit App, но могут получить их, выведя переменные окружения.
</Warning>

<div id="database-related-secrets">
  ## Секреты, связанные с базой данных
</div>

При добавлении базы данных Replit в Project Editor автоматически создаётся следующий секрет:

| Секрет         | Описание                             |
| -------------- | ------------------------------------ |
| `DATABASE_URL` | Строка подключения к SQL-базе данных |

<Info>
  Устаревшие базы данных разработки Neon могут также содержать `PGHOST`, `PGUSER`, `PGPASSWORD`, `PGDATABASE` и `PGPORT`. В текущих базах данных разработки Replit вместо них используется `DATABASE_URL`.
</Info>

Чтобы просмотреть все переменные окружения в вашем Replit App, выполните `printenv` в инструменте Shell в Project Editor или выведите их из кода.

<div id="predefined-environment-variables">
  ## Предопределённые переменные окружения
</div>

Replit автоматически задаёт следующие переменные окружения, доступные из вашего приложения:

| Переменная окружения | Описание                                                                                  |
| -------------------- | ----------------------------------------------------------------------------------------- |
| `REPLIT_DOMAINS`     | Разделённый запятыми список всех доменов, связанных с вашим Replit App                    |
| `REPLIT_USER`        | Имя пользователя, который сейчас редактирует App; может меняться в сессиях Multiplayer    |
| `REPLIT_DEPLOYMENT`  | Равна `1`, если код выполняется в опубликованном приложении; в противном случае не задана |
| `REPLIT_DEV_DOMAIN`  | URL для разработки в домене `replit.dev`; отличается от URL развёртывания                 |

В инструменте Secrets они не отображаются, но к ним можно обратиться в коде через объект `os.environ` или выполнив команду `printenv` в Shell.
