<div id="azure-marketplace">
  ### Azure Marketplace 集成
</div>

Replit 现已在 Azure Marketplace 上架。许多组织设有 Azure 专项预算，此集成让这些资金可直接用于支付 Replit 订阅费用和使用费。

继 9 月推出 GCP Marketplace 集成后，这项更新让 Enterprise 团队能够更轻松地利用现有的云采购流程和预算采用 Replit。

[前往 Azure Marketplace 查看](https://marketplace.microsoft.com/en-us/product/saas/replit.replit?tab=Overview)

<div id="gitlabbitbucket">
  ### 支持 GitLab 和 Bitbucket
</div>

除 GitHub 外，Replit 现已支持 GitLab 和 Bitbucket 仓库。你可以更灵活地选择代码存储位置，并直接将 GitLab 和 Bitbucket 中的项目导入 Replit。所有受支持的平台均可使用增强的 Git 功能。

增强的 Git 集成包括：

* **多平台支持**：导入和使用 GitHub、GitLab 及 Bitbucket 仓库
* **改进的 Git 操作**：在整个工作区中更快速、更可靠地运行 Git 命令
* **更完善的仓库管理**：简化从所有受支持的 Git 提供商克隆、推送和拉取的工作流程

有关更多信息，请参阅[导入项目](/zh/references/workspace/import)和[在 Replit 中使用 Git](/zh/references/version-control/git-interface)。
