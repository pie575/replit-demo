</Note>

Free Mode 让 Starter、Core 和 Pro 订阅者无需额外付费即可使用 Agent。Starter 可在现有使用限额内使用 Free Mode。Core 和 Pro 均包含 Free Mode 额度。打开对话，探索想法、制定计划、创建内容或寻求帮助。如果某项请求需要使用付费模式或执行付费操作，Replit 会在产生任何费用前明确告知你。

<div id="why-youll-like-it">
  ## 您会喜欢它的原因
</div>

* 直接从对话开始，无需进行设置。
* 在决定是否需要更多功能前，先探索想法并推进工作。
* 当请求涉及付费操作时，您始终掌握控制权。
* 在 Free Mode 中完成的工作会清晰标注 **Free**。

<div id="how-it-works">
  ## 工作原理
</div>

1. 新的 Starter、Core 和 Pro 会话均以 Free Mode 启动。
2. Free Mode 能够胜任的工作会直接继续，不会弹出付费操作提示。
3. 如果某个付费模式能更好地处理请求，Agent 会向你说明情况，并交由你选择。
4. 你可以仅为该请求启用付费模式，也可以让 Agent 继续在 Free Mode 下处理。
5. 一次性付费升级完成后，模式会自动恢复为 Free Mode。

<div id="the-three-agent-modes">
  ## 三种 Agent 模式
</div>

<CardGroup cols={3}>
  <Card title="Free">
    面向 Starter、Core 和 Pro 订阅者的免费 Agent 使用额度。
  </Card>

  <Card title="Power">
    付费的中端模式，以实惠的价格满足对能力要求更高的工作。
  </Card>

  <Card title="Max">
    付费的顶级模式，搭载最出色的前沿模型，胜任要求最高的工作。
  </Card>
</CardGroup>

Starter、Core 和 Pro 订阅者均可使用 Free Mode。Starter 提供 Free Mode，沿用其现有限额；Core 和 Pro 包含一定的 Free Mode 额度，其中 Pro 的每周限额更高。如果需要更强的能力，你也可以选择付费的 Agent 模式。

在 Core 和 Pro 上，智能模型路由是 Free Mode 之外的付费选择。在 Power 或 Max 中选择 **Auto**，即可让 Replit 为每个 task 挑选合适的模型。

<Note>
  **如果达到限额：** Starter 提供 Free Mode，沿用其现有限额。对于 Core 和 Pro，Free Mode 额度每五小时重置一次，并设有每周限额。前往 **设置 → Usage** 查看当前使用情况。接近限额时，Replit 会提前提醒你。达到限额后，可切换到付费模式继续使用，或等待额度重置。
</Note>

<div id="common-questions">
  ## 常见问题
</div>

<AccordionGroup>
  <Accordion title="Free Mode 真的是免费的吗？Replit 现在免费了吗？">
    Free Mode 包含在 Starter、Core 和 Pro 订阅中。Starter 提供 Free Mode，但仍受原有额度限额。Core 和 Pro 包含 Free Mode 额度。Free Mode 本身并不是独立的免费套餐。
  </Accordion>

  <Accordion title="这和付费 Agent 模式一样吗？">
    不一样。Free Mode 可在额度范围内免费使用 Agent。Power 和 Max 是适用于需要更高能力任务的付费模式。
  </Accordion>

  <Accordion title="Economy 和 Power 怎么了？这些模式变了吗？">
    付费模式已更名。Economy 现为 Power，这是一个以实惠价格提供强大模型的中档模式。此前称为 Power 的模式现为 Max，即顶级模式。现有模式设置会随新名称一并沿用。
  </Accordion>

  <Accordion title="哪种模式能力最强？">
    Max。Power 是以实惠价格提供更高能力的付费中档模式。Max 是适用于最具挑战性任务的付费顶级模式。
  </Accordion>

  <Accordion title="如果我的请求需要付费操作，该怎么办？">
    Agent 会说明该请求需要付费模式或付费能力，并在继续前征求你的确认。你可以仅批准这一次请求，或继续使用 Free Mode。
  </Accordion>

  <Accordion title="如果 Agent 建议升级，我会被自动收费吗？">
    不会。开始处理付费请求前，必须先获得你的确认。
  </Accordion>

  <Accordion title="我可以拒绝付费选项吗？">
    可以。你可以继续使用 Free Mode。
  </Accordion>

  <Accordion title="我批准付费升级后会发生什么？">
    此批准仅适用于该请求。之后你的 Agent 模式会恢复为 Free Mode。
  </Accordion>

  <Accordion title="为什么我达到限额了？何时重置？">
    Starter 提供 Free Mode，但仍受原有额度限额。对于 Core 和 Pro，Free Mode 额度每五小时重置一次，且设有每周限额。查看 **设置 → 使用情况**，了解当前使用情况。达到限额后，请切换到付费模式继续使用，或等待重置。
  </Accordion>

  <Accordion title="Enterprise 提供 Free Mode 吗？">
    不提供。Enterprise workspace 改为使用单一的 Auto 模式。它会为每个 task 选择模式和允许使用的模型。请参阅 [Enterprise 模型控制](/zh/features/collaboration/enterprise-model-controls)。
  </Accordion>
</AccordionGroup>

<div id="more-about-free-mode">
  ## 关于 Free Mode 的更多信息
</div>

<AccordionGroup>
  <Accordion title="Free Mode 和 Lite 是一回事吗？">
    对 Starter 用户而言，此前称为 Lite 的体验现在就是 Free Mode。如果你以前用 Lite 来调用成本更低的模型，现在仍可以在 Power 中关闭自动选择，然后手动选择该模型。
  </Accordion>

  <Accordion title="Free Mode 能构建完整的应用吗？">
    可以。你可以在 Free Mode 中创建并迭代完整的应用。
  </Accordion>

  <Accordion title="Free、Power 和 Max 有什么区别？">
    Free Mode 面向 Starter、Core 和 Pro 订阅者，可零成本完成日常的 Agent 工作。Starter 提供 Free Mode，并沿用其现有限额；Core 和 Pro 则包含一定的 Free Mode 额度。Power 是付费的中间层模式，以实惠的价格提供更强的能力。Max 是付费的顶级模式，适用于要求最高的工作。
  </Accordion>

  <Accordion title="我什么时候应该切换出 Free Mode？">
    日常工作可以一直使用 Free Mode。当你希望在复杂任务上获得更好的结果，或者需要 Free Mode 不具备的能力时，再切换到其他模式。
  </Accordion>

  <Accordion title="Free Mode 能生成视频吗？">
    不能。视频生成属于付费模式的能力，不包含在 Free Mode 中。
  </Accordion>

  <Accordion title="全新的 Conversation 体验是什么样的？">
    聊天与创作融为一体。你可以在同一个对话中调研想法、规划工作，或直接开启一个 project。
  </Accordion>

  <Accordion title="独立的聊天会成为已发布应用的一部分吗？">
    不会。在你创建或修改 project 之前，对话始终是独立的。
  </Accordion>

  <Accordion title="Free Mode 能在已有的 project 上工作吗？">
    可以。它支持对已有 project 进行日常维护和编辑。
  </Accordion>
</AccordionGroup>

**准备好试试了吗？** Free Mode 上线后，打开一个与 Agent 的对话即可开始。
