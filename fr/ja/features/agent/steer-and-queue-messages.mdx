Lorsqu’Agent travaille, les messages de suivi peuvent soit modifier ce qu’il est en train de faire — le **tour** actif — soit attendre la fin de ce tour.

* **Steer** envoie le message au tour actif. Agent utilise le nouveau contexte tout en poursuivant son travail.
* **Queue** enregistre le message pour le tour suivant. Agent le traite une fois le tour actif terminé.

<div id="conversation">
  ## Piloter une Conversation
</div>

Steer est le comportement d’envoi par défaut des messages de suivi dans Conversation et Project. Vous pouvez remplacer ce comportement par Queue dans les deux cas.

<div id="replit">
  ## Choisir comment Replit envoie les messages de suivi
</div>

Vous pouvez définir un comportement d’envoi distinct pour chaque Conversation et Project :

1. Ouvrez **Settings** &gt; **Personalization**.
2. Développez **Agent**.
3. Réglez **Conversation send behavior** et **Project send behavior** sur **Steer** ou **Queue**.

<Frame caption="Paramètres de comportement d’envoi de Conversation et Project dans la section Agent.">
  <img src="/assets/mirror/agent-follow-ups-settings-98a4c5ca399e.png" alt="Paramètres Agent affichant les comportements d’envoi de Conversation et Project avec les options Steer et Queue" width="3048" height="1372" data-path="images/replitai/agent-follow-ups-settings.png" />
</Frame>

<Info>
  Le mode Design pilote toujours les messages de suivi. Les paramètres de comportement d’envoi de Conversation et Project ne s’appliquent pas au mode Design.
</Info>

Pour envoyer un message avec le comportement inverse de celui défini dans vos préférences, appuyez sur `Cmd+Enter` (Mac) ou `Ctrl+Enter` (Windows et Linux).

<div id="section">
  ## Gérer les messages en file d’attente
</div>

Lorsque vous mettez un message de suivi en file d’attente, Message Queue s’affiche sous la forme d’un tiroir au-dessus du champ de saisie du chat. Une fois le tour actif terminé, Agent traite les messages en file d’attente dans l’ordre. Une fois qu’Agent a traité tous les messages en file d’attente, le tiroir se ferme.

Toutes les options de message, y compris [Visual Editor](/fr/ja/design/visual-editor) et l’ajout de fichiers joints, sont disponibles dans la file d’attente.

<Info>
  Agent ne traite automatiquement les messages en file d’attente que lorsqu’une session Project Editor active est connectée sur ordinateur ou mobile.
</Info>

<div id="section-2">
  ### Gérer la file d&#39;attente
</div>

Lorsque le panneau de la file d&#39;attente est ouvert, vous pouvez :

* **Steer now** : déplacer un message en file d&#39;attente vers le tour actif.
* **Modifier un message** : modifier un message en file d&#39;attente avant qu&#39;Agent ne le traite.
* **Supprimer un message** : supprimer les messages devenus inutiles.
* **Réorganiser les messages** : faire glisser les messages pour modifier leur ordre de traitement.
* **Ajouter un message** : envoyer d&#39;autres messages de suivi dans la file d&#39;attente.

<div id="section-3">
  ## Arrêter un tour actif
</div>

Sélectionnez **Stop** dans la barre d&#39;état pour interrompre le travail en cours de Replit pendant le tour actuel. Vous pouvez ensuite envoyer un nouveau message sans attendre qu&#39;Agent termine son tour ou traite les messages en file d&#39;attente.
