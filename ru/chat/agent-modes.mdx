Режимы Agent позволяют перед отправкой запроса выбрать оптимальное соотношение включённого лимита, кредитов и возможностей. Откройте выпадающее меню настроек Agent в поле ввода промпта, затем выберите режим, подходящий для вашей задачи.

<Note>
  Economy Mode больше недоступен. Его заменил Power Mode по той же цене.
</Note>

<div id="choose-a-mode">
  ## Выберите режим
</div>

* **Free Mode:** Исследуйте идеи, задавайте вопросы, начинайте разработку и не прерывайте повседневную работу. Free Mode использует интеллектуальную маршрутизацию моделей для выбора модели. {FreeModePlanAvailability}
* **Power Mode:** Оптимальный баланс скорости и возможностей для большинства задач. Используйте его, когда лимита Free Mode недостаточно или вам нужен более мощный режим по умолчанию для существующего проекта.
* **Max Mode:** Самый мощный вариант для сложных амбициозных задач, крупных кодовых баз и трудных проблем.

Power Mode и Max Mode используют ежемесячные кредиты. Replit предупредит вас, прежде чем запрос перейдёт из Free Mode в режим, за использование которого взимается плата. Оставшийся лимит Free Mode можно проверить в **Settings** → **Usage**. Практические советы см. в разделе [Как получить максимум от Free Mode](/ru/chat/free-mode).

Routines выполняются в Power Mode или Max Mode и требуют бюджета для каждого запуска. Они не работают в Free Mode. Подробнее см. в разделе [Routines](/ru/chat/routines).
