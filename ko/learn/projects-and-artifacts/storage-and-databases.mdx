Replit의 유연한 스토리지 솔루션을 활용하면 앱 실행에 꼭 필요한 데이터
스토리지를 빠르게 추가할 수 있습니다. 다음과 같은 요구 사항이 있는 앱에는 Replit의 데이터베이스나 Object Storage를
사용할 수 있으며, Agent가 두 솔루션을 자동으로 설정하고 통합해 줍니다.

* 진행 상황이나 최고 점수 등 플레이어 정보를 저장해야 하는 게임
* 미디어 파일을 관리하는 콘텐츠 플랫폼

<div id="what-are-replits-storage-and-database-options">
  ## Replit의 스토리지 및 데이터베이스 옵션
</div>

Replit은 다음과 같은 데이터 저장 옵션을 제공합니다.

* **Database**: 사용자 프로필, 게임 점수, 제품 카탈로그와 같은 구조화된 데이터를 저장합니다.
  속성과 데이터 포인트 간의 관계를 기준으로 데이터를 저장하거나 조회할 수 있습니다.

* **App Storage**: 이미지, 동영상, 문서와 같은 비정형 데이터를 저장합니다.
  대용량 파일과 바이너리 데이터를 저장하고 조회할 수 있습니다.

<div id="app-storage-and-database-comparison">
  ### App Storage와 데이터베이스 비교
</div>

|                | Database                   | App Storage                  |
| -------------- | :------------------------- | :--------------------------- |
| **적합한 데이터 형식** | 관계가 있는 구조화된 데이터            | 대용량 파일(이미지, 동영상, 문서)         |
| **데이터 모델**     | 테이블, 행, 열                  | bucket, 파일                   |
| **쿼리 언어**      | SQL                        | REST API                     |
| **클라이언트**      | PostgresSQL 호환 클라이언트 및 ORM | Replit SDK 및 GCS 클라이언트 라이브러리 |
| **요금 모델**      | 컴퓨팅 시간 및 저장 공간 기준 과금       | 대역폭 및 저장 공간 기준 과금            |

<div id="project-editor-tools">
  ### Project Editor 도구
</div>

앱의 데이터 저장소를 설정하고 관리하는 데 사용할 수 있는 다음 Replit 도구에 대해 자세히 알아보세요:

<CardGroup>
  <Card title="Database" href="/ko/features/data-and-storage/sql-database" icon="database">
    구조화된 데이터를 저장하고 데이터 간의 관계를 표현하는 데 적합합니다.
    앱 규모에 맞춰 확장되는 완전 관리형 PostgresSQL 데이터베이스를 기반으로 합니다.
  </Card>

  <Card title="App Storage" href="/ko/features/data-and-storage/object-storage" icon="bucket">
    이미지, 동영상, 문서처럼 비정형 데이터와 대용량 파일에 적합합니다.
    높은 가용성과 확장성을 제공하는 Google Cloud Storage(GCS)를 기반으로 합니다. Agent가 고급 인증 및 액세스 제어를 갖춘 App Storage를 자동으로 설정할 수 있습니다.
  </Card>
</CardGroup>
