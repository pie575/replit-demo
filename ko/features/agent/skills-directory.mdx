Skills 디렉터리는 설치하는 즉시 사용할 수 있는 skills를 모아 놓은 카탈로그로, Replit과 파트너가 직접 제작한 skills를 제공합니다. 먼저 하나를 설치해 사용해 본 뒤, 팀의 실제 업무 방식에 맞게 편집해 보세요.

skill이 무엇이고 Agent가 이를 어떻게 불러오는지는 [Agent Skills](/ko/features/agent/skills)를 참조하세요. workspace 전체에서 skill을 사용하려면 [Agent Customization](/ko/features/agent/agent-customization)을 참조하세요.

<div id="install-a-skill">
  ## skill 설치하기
</div>

디렉터리에서 skill을 추가하는 방법은 여러 가지가 있습니다:

* **Chat에서** — Chat 입력창 옆의 **+** 버튼을 클릭한 뒤 **Use a skill**을 선택하고 원하는 skill을 고릅니다. 이때 skill은 해당 메시지에만 적용되며, project에는 아무것도 설치되지 않습니다.
* **project에서** — Project Editor에서 **Skills pane**을 열고 **Discover** tab을 선택한 뒤, 원하는 skill을 찾아 **Install**을 클릭합니다. 설치된 skills는 project의 `/.agents/skills` 디렉터리에 저장되며 여러 Chat에서 계속 유지됩니다.
* **명령줄에서** — [skills CLI](https://github.com/vercel-labs/skills)로 skill을 설치합니다:

  ```bash theme={null}
  npx skills <skill> -a replit
  ```

<Warning>
  Replit skill 선택기에 있는 skills는 안전성 검사를 거치지만, 외부 출처에서 설치한 skills는 그렇지 않습니다. skill은 Agent가 그대로 따르는 지침이므로, 외부 skill은 설치 전에 반드시 검토하세요. 확인해야 할 사항은 [Agent skills](/ko/learn/agent-skills)를 참고하세요.
</Warning>

<div id="replit-skills">
  ## Replit skills
</div>

Replit에는 Chat의 **Use a skill** 선택기와 새 project 시작점 선택기에서 사용할 수 있는 사전 정의된 skills가 기본 제공됩니다. 이 skills는 설치 없이 모든 project에서 사용할 수 있습니다. 선택기를 열면 각 항목의 설명이 함께 표시됩니다.

| 카테고리       | Skills                                                                                                        |
| ---------- | ------------------------------------------------------------------------------------------------------------- |
| 영업 및 마케팅   | Ad Creative, AI SDR, SEO Auditor, Programmatic SEO, GEO, Content Machine, Storyboard                          |
| 커리어        | AI Recruiter, Resume Maker, Interview Prep                                                                    |
| 리서치 및 분석   | Competitive Analysis, Deep Research, GitHub Solution Finder, Supplier Research                                |
| 비즈니스 및 금융  | Stock Analyzer, Excel Generator, Invoice Generator, Tax Reviewer                                              |
| 문서 및 도구    | Website Cloner, File Converter, Flashcard Generator, Legal Contract, Infographic Builder, Recreate Screenshot |
| 크리에이티브     | Photo Editor, Podcast Generator, Podcast Marketing, Branding Generator, Video Editing                         |
| 생산성        | AI Secretary, Product Manager, Design Thinker, Skill Finder, Skill Creator                                    |
| 개인용        | Travel Assistant                                                                                              |
| 보안 및 규정 준수 | Secrets, Sensitive Data, Input Validation, AI Security, Dependency Vetting, License Check                     |
| 품질 및 안정성   | Accessibility, Responsive UI, Observability, Resilience, Ship Review                                          |

<Note>
  workspace 안에서는 선택기가 해당 project의 `.local/secondary_skills/` 디렉터리에 설치된 추가 skills까지 찾아 보여줍니다.
</Note>

<div id="partner-skills">
  ## 파트너 skills
</div>

Replit 파트너는 자사 제품으로 개발하는 방법을 Agent에게 가르치는 skills를 게시합니다. skill을 설치하면 해당 서비스의 패턴과 conventions를 Agent가 익히게 됩니다.

| 파트너              | Agent에게 가르치는 내용                          |
| ---------------- | ---------------------------------------- |
| Stripe           | payments 및 billing integration 패턴        |
| PayPal           | payments integration 패턴                  |
| RevenueCat       | 구독 및 인앱 구매 패턴                            |
| Mixpanel         | 분석 및 추적 구현                               |
| BigQuery         | 데이터 웨어하우스 쿼리 패턴                          |
| Resend           | 트랜잭션 이메일 integration                     |
| Google Workspace | Gmail, Drive, Docs, Calendar integration |
| Atlassian        | Jira 및 Confluence 이슈와 페이지 workflows      |
| Google Maps      | 지도, 장소, 경로, 지오코딩 integration             |

<div id="community-skills">
  ## 커뮤니티 skills
</div>

Replit과 파트너가 제공하는 skills 외에도, 커뮤니티에서 설치해 사용할 수 있는 skills를 게시합니다. [skills.sh](https://skills.sh)에서 둘러보고, 직접 만들어 보려면 [Agent Skills specification](https://agentskills.io/specification)을 참고하세요.
