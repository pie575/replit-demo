[Project Security Center](/zh/ko/features/security/project-security-center) 和 [Workspace Security Center](/zh/ko/features/security/workspace-security-center) 中所用安全术语的定义。

<div id="cve">
  ## CVE
</div>

通用漏洞披露 (Common Vulnerabilities and Exposures) 。CVE 是分配给公开披露的软件漏洞的唯一标识符，例如 `CVE-2024-12345`。

<div id="severity">
  ## 严重程度 (Severity)
</div>

漏洞的风险等级，分为 critical、high、medium、low 四级。结合严重程度和暴露程度，判断应优先修复哪些项目。

<div id="dependency">
  ## 依赖项 (Dependency)
</div>

项目所依赖的第三方软件包。依赖项中的漏洞会波及所有使用该依赖项的项目，直到该依赖项被更新或替换为止。

<div id="sbom">
  ## SBOM
</div>

软件物料清单 (Software Bill of Materials，SBOM) 是以机器可读格式列出项目中所含软件包、版本和许可证的清单。

<div id="spdx-cyclonedx">
  ## SPDX 与 CycloneDX
</div>

这是安全与合规工具使用的标准 SBOM 格式。请根据审计、合规或软件成分分析工具的要求选择相应格式。

<div id="exposure">
  ## 暴露程度 (Exposure)
</div>

指由项目的发布状态和可见范围带来的风险程度。公开发布的项目比私有或未发布的项目暴露程度更高。

<div id="fix-with-agent">
  ## Fix with Agent
</div>

针对受影响的项目，让 Replit Agent 以后台任务的方式编写补丁。应用之前，请先检查生成的更改。

<div id="republish">
  ## 重新发布
</div>

使用现有的部署配置重新部署项目。修复问题后，如需发布修补版本，请使用 **Republish**。

<div id="package-firewall">
  ## 软件包防火墙
</div>

这项保护功能会在安装过程中从网络层面拦截恶意或受损的软件包，防止其被下载到应用中。默认启用，并基于 Socket 运行。请参阅[软件包防火墙](/zh/ko/features/security/package-firewall)。

<div id="auto-protect">
  ## Auto-Protect
</div>

Replit 自动为您的应用提供全面保护。默认向所有构建者启用的保护功能包括在安装时拦截软件包的 [软件包防火墙](/zh/ko/features/security/package-firewall)、Web 应用防火墙 (WAF) 以及自动 SSL/TLS 加密。管理员还可以启用自动 CVE 缓解功能，让 Replit Agent 为新披露的依赖项漏洞准备补丁，并通知 Project 所有者。请参阅 [Auto-Protect](/zh/ko/features/security/project-security-center#auto-protect)。
