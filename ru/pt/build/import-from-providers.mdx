Импорт позволяет перенести существующий код или дизайн-макеты в Replit App и продолжить разработку с помощью Agent.

<div id="fontes-suportadas">
  ## Поддерживаемые источники
</div>

| Источник                    | Что вы предоставляете                                             | Подходит для                                                |
| --------------------------- | ----------------------------------------------------------------- | ----------------------------------------------------------- |
| GitHub                      | URL репозитория или выбор репозитория                             | Импорт публичных и приватных репозиториев                   |
| Bitbucket                   | URL репозитория или выбор репозитория                             | Импорт репозиториев, размещённых на Bitbucket               |
| Vercel                      | Репозиторий GitHub, лежащий в основе проекта Vercel               | Перенос приложений Vercel                                   |
| Figma                       | URL фрейма                                                        | Превращение дизайнов в приложения на React                  |
| Claude                      | Дизайн, отправленный из Claude                                    | Превращение дизайна из Claude в интерактивное приложение    |
| Bolt                        | Репозиторий GitHub, экспортированный из Bolt                      | Перенос проектов Bolt                                       |
| Lovable                     | Репозиторий GitHub, экспортированный из Lovable                   | Перенос проектов Lovable                                    |
| Base44                      | Репозиторий GitHub, экспортированный из Base44                    | Перенос проектов Base44                                     |
| ZIP                         | Загрузка файла `.zip`                                             | Импорт локальных файлов проекта                             |
| Таблица                     | Файл `.xlsx`, `.csv` или URL Google Таблиц                        | Создание приложения на основе табличных данных              |
| Предыдущий экспорт из Agent | Репозиторий GitHub, экспортированный из прежнего приложения Agent | Повторный импорт прежнего приложения Agent                  |
| Пустой                      | Ничего                                                            | Опытные пользователи, которым нужен чистый проект без Agent |

<Note>Replit проверяет совместимость до начала импорта.</Note>

О дизайнах Figma см. [Импорт дизайнов из Figma в Replit Design](/ru/pt/design/import-figma-designs-into-replit-design).

О дизайнах, отправленных из Claude, см. [Импорт дизайнов из Claude в Replit Design](/ru/pt/design/import-claude-designs-into-replit-design).

  <Tab title="Lovable">
    ⏰ *Примерное время: четыре минуты*

    Импортируйте проект Lovable в Replit: экспортируйте его в GitHub, а затем импортируйте полученный репозиторий.

    **Прежде чем начать**

    * Проект Lovable, доступный для экспорта
    * Учётная запись GitHub, подключённая к Lovable
    * Учётная запись Replit

    **Шаги**

    1. Экспортируйте свой проект Lovable в GitHub.
    2. Откройте [replit.com/import](https://replit.com/import).
    3. Выберите **Lovable**.
    4. Подключите свою учётную запись GitHub.
    5. Выберите экспортированный репозиторий Lovable.
    6. Выберите **Импортировать**.

    <div id="what-gets-imported">
      ## Что импортируется
    </div>

    Replit импортирует из вашего проекта {platform_6} следующее:

    * **Код**: логика приложения и исходные файлы
    * **Дизайн и стили**: компоненты UI и правила оформления
    * **Ассеты**: изображения, иконки и статические файлы
    * **Логика бэкенда**: серверная функциональность, если она есть
    * **Схема базы данных**: структура таблиц, если она есть

    <div id="what-is-not-imported">
      ## Что не импортируется
    </div>

    * **Данные Supabase**: существующие записи базы данных не переносятся
    * **Secrets**: переменные окружения и API-ключи нужно добавить отдельно

    Используйте Agent, чтобы восстановить недостающую функциональность, добавить secrets и заново создать данные в базе.

    * **[Workflows](/ru/features/workspace-tools/workflows)**: задайте команду **Run** для вашего приложения

  <Tab title="GitHub">
    ⏰ *Ориентировочное время: две минуты*

    Импортируйте репозиторий GitHub в Replit, чтобы быстрее запускать, тестировать и публиковать приложения.

    **Прежде чем начать**

    * URL репозитория GitHub
    * Доступ к репозиторию (публичному или приватному)
    * Учётная запись Replit

    **Вариант первый: быстрый импорт**

    Быстрый импорт работает для публичных репозиториев.

    1. Скопируйте путь репозитория после `github.com/`.
    2. Откройте `https://replit.com/github.com/<owner>/<repo>`.
    3. Нажмите Enter, чтобы начать импорт.

    *Пример*

    * URL на GitHub: `https://github.com/exampleUser/my-app`
    * URL импорта в Replit: `https://replit.com/github.com/exampleUser/my-app`

    **Вариант второй: импорт с подсказками**

    Импорт с подсказками поддерживает как публичные, так и приватные репозитории.

    1. Откройте [replit.com/import](https://replit.com/import).
    2. Выберите **GitHub**.
    3. Подключите свою учётную запись GitHub.
    4. Выберите репозиторий.
    5. Нажмите **Импортировать**.

    **Что импортируется**

    * Файлы и папки репозитория
    * Файлы зависимостей
    * Стандартная конфигурация запуска и сборки

    **Что не импортируется**

    * Значения существующих секретов и переменных окружения
    * Специфичные для платформы сервисы, которые по умолчанию не работают в Replit

    **Устранение проблем с подключением к GitHub**

    Если вы видите `Failed to get repository, please re-authenticate with GitHub` или в выпадающем списке репозиториев отображается `No repositories found`, учтите: импорт из GitHub использует отдельное подключение — не то, что указано на странице **Учётная запись → Подключённые сервисы**. Повторное подключение только в разделе «Подключённые сервисы» проблему с импортом не решит.

    <Steps>
      <Step title="Переподключите GitHub в разделе «Провайдеры Git»">
        Откройте раздел **Провайдеры Git** в настройках своей учётной записи Replit, отключите GitHub и подключите его заново на том же экране. После этого ваши личные репозитории должны появиться в выпадающем списке импорта.
      </Step>

      <Step title="Одобрите приложение Replit для вашей организации в GitHub">
        Если репозиторий принадлежит организации GitHub, откройте [https://github.com/settings/applications](https://github.com/settings/applications), найдите OAuth-приложение Replit и предоставьте доступ к организации в настройках доступа сторонних приложений. Если вы не владелец организации, этот шаг могут выполнить её администраторы.
      </Step>

      <Step title="Повторите импорт">
        Откройте [replit.com/import](https://replit.com/import) и попробуйте импорт снова — как через выпадающий список репозиториев, так и вставив URL репозитория.
      </Step>
    </Steps>

  <Tab title="ZIP">
    ⏰ *Примерное время: три минуты*

    Импортируйте локальный проект, загрузив файл `.zip`.

    **Прежде чем начать**

    * Файл `.zip` с вашим проектом размером не более 200 МБ
    * Чёткая корневая папка проекта в архиве
    * Учётная запись Replit

    Если ваш zip-файл больше 200 МБ, форма импорта его отклонит. Чтобы уменьшить размер, исключите папки зависимостей и сборки, такие как `node_modules`, `.venv` или `build`. Replit переустановит зависимости во время импорта.

    **Шаги**

    1. Откройте [replit.com/import](https://replit.com/import).
    2. Выберите **ZIP**.
    3. Загрузите свой файл `.zip`.
    4. Добавьте все запрошенные секреты и переменные окружения.
    5. Выберите **Импортировать**.

    **Что импортируется**

    * Файлы проекта и структура каталогов

<div id="outras-fontes">
  ## Другие источники
</div>

<div id="bitbucket">
  ### Bitbucket
</div>

* Вставьте URL репозитория Bitbucket или подключите свою учётную запись Bitbucket, чтобы выполнять поиск по своим репозиториям.
* Поддержка Agent при импорте может быть ограниченной по сравнению с проектами, размещёнными на GitHub.

<div id="planilha">
  ### Таблица
</div>

* Загрузите файл Excel (`.xlsx`) или CSV либо вставьте публичную ссылку на Google Таблицы.
* Agent анализирует структуру вашей таблицы и создаёт полностековый app с базой данных, заполненной вашими данными.
* Включает интерфейс для просмотра, поиска записей и управления ими.

<div id="exportao-anterior-do-agent">
  ### Ранее экспортированный Agent
</div>

* Повторно импортируйте ранее экспортированное приложение Agent из репозитория GitHub.
* Replit сохраняет структуру, характерную для Agent (код, схему базы данных, функциональность бэкенда).
* Значения из базы данных и значения секретов не импортируются.

<div id="vazio">
  ### Пустой
</div>

* Начните с полностью пустого проекта — без Agent, без выбора фреймворка и без готовой структуры.
* Отличный вариант для опытных пользователей, которым нужен полный контроль над настройкой проекта.

<div id="limitaes">
  ## Ограничения
</div>

* Существующие данные базы данных не переносятся.
* Размер загружаемых ZIP-архивов ограничен 200 МБ.
* Некоторые сложные или проприетарные зависимости могут потребовать ручной настройки.
* Обработка крупных проектов может занять больше времени.

<div id="boas-prticas">
  ## Рекомендации
</div>

* Удалите конфиденциальные учётные данные перед импортом.
* Поддерживайте порядок в структуре исходного проекта.
* После импорта проверьте зависимости и команды запуска.
* Протестируйте основные сценарии перед публикацией.

<div id="soluo-de-problemas">
  ## Устранение неполадок
</div>

Если импорт не удался, в первую очередь проверьте следующее:

* **Ошибки совместимости**: убедитесь, что нужные файлы проекта на месте, а используемые фреймворки поддерживаются.
* **Ошибки доступа**: проверьте права доступа к репозиторию или источнику.
* **Ошибки обработки**: упростите структуру проекта или уменьшите его размер и повторите попытку.

Если проблемы сохраняются, посетите [Replit Community Hub](https://replit.com/community) или [обратитесь в службу поддержки](https://replit.com/support).
