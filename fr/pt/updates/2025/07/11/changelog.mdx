<div id="documentao-replitmd">
  ### Documentation replit.md
</div>

Personnalisez le comportement d&#39;Agent avec `replit.md`, un fichier de configuration spécial qui aide Agent à comprendre les préférences, le style de code et l&#39;architecture de votre projet. Agent crée automatiquement ce fichier en s&#39;appuyant sur des bonnes pratiques éprouvées, puis s&#39;en sert pour créer des applications parfaitement conformes à vos spécifications. Donnez à Agent le contexte de votre projet, définissez vos normes de code, précisez votre stack technologique préférée et fixez vos préférences de communication : le tout au même endroit.
