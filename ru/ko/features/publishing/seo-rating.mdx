Когда вы публикуете веб-приложение в Replit, для его реального URL автоматически запускается аудит поисковой оптимизации (SEO), а в инструментах Publishing отображается SEO-оценка. Если оценку есть куда повышать, вы одним кликом передаёте конкретные проблемы Agent, и он устраняет их за считаные секунды.

Для большинства разработчиков весь процесс выглядит так: опубликовать приложение, посмотреть оценку и попросить Agent «оптимизируй SEO». На этой странице рассказано, что происходит за кулисами и как извлечь из этого максимум пользы.

<div id="seo">
  ## Что такое SEO и почему это важно
</div>

Поисковая оптимизация (SEO) — это подход к созданию сайта, при котором поисковые системы вроде Google могут его найти, понять его содержимое и присвоить ему место в выдаче. Сильное SEO означает, что ваше приложение будет показываться людям, которые ищут то, что вы предлагаете, — и без затрат на рекламу.

Основную часть результата в SEO определяют несколько факторов: понятные заголовки и описания страниц, семантическая вёрстка HTML, быстрая загрузка, адаптивный под мобильные устройства макет, содержательный альтернативный текст для изображений и структура сайта, доступная для сканирования. Поисковые системы вознаграждают сайты, которые легко читать как людям, так и машинам.

Если вы запускаете лендинг, маркетинговый сайт, блог, каталог или что-то ещё, где важна находимость в поиске, SEO — одно из самых выгодных вложений на раннем этапе.

<div id="replit-seo">
  ## Как Replit по умолчанию улучшает SEO
</div>

Replit берёт на себя большую часть базовой SEO-оптимизации, чтобы вы могли сосредоточиться на контенте и продукте.

* **Быстрый хостинг с глобальным распределением**: Replit Deployments размещает приложения на инфраструктуре, оптимизированной для высокой скорости, а [география проекта](/ru/ko/features/publishing/project-geography) позволяет выбрать регион, в котором будет работать приложение.
* **Встроенный HTTPS**: Все опубликованные приложения получают TLS-сертификаты, которыми управляет Replit. Это один из базовых сигналов ранжирования для поисковых систем.
* **Пользовательские домены**: Подключите собственный домен, чтобы укрепить доверие и авторитет бренда. См. [Custom Domains](/ru/ko/features/publishing/custom-domains).
* **Static Deployments для контентных сайтов**: Для маркетинговых страниц, блогов и документации [Static Deployments](/ru/ko/features/publishing/deployment-types#static) предоставляет предварительно отрендеренный HTML, который поисковые системы легко сканируют.
* **Agent, создающий код с учётом SEO**: При создании страниц Agent по умолчанию генерирует семантический HTML, доступную разметку и метатеги — именно эти элементы проверяют SEO-инструменты.
* **Оценка SEO**: Автоматические проверки, запускаемые после публикации, помогают всегда быть в курсе текущего состояния. Найденные проблемы можно одним щелчком передать Agent для исправления.

<div id="section">
  ### Где посмотреть
</div>

В опубликованном приложении откройте инструмент **Publishing**. Оценка SEO отображается в обзоре деплоя вместе с другими сведениями о сборке. Наведите курсор на оценку, чтобы увидеть конкретные рекомендации Lighthouse для каждой страницы.

<Note>
  Если оценка SEO не отображается, возможно, приложение закрыто или было опубликовано недостаточно давно. Оценки отображаются только для опубликованных общедоступных веб-приложений.
</Note>

<div id="section-2">
  ### Как интерпретировать оценки
</div>

Replit присваивает одну из трёх оценок на основе аудита Lighthouse.

| Оценка            | Значение                                                                                |
| :---------------- | :-------------------------------------------------------------------------------------- |
| В порядке         | Приложение соответствует рекомендациям по SEO. Следите за ним после крупных изменений.  |
| Требует доработки | Из-за ряда проблем поисковым системам сложно правильно понять приложение.               |
| Слабая            | Отсутствуют важные базовые элементы SEO. Обычно это можно исправить за несколько минут. |

Если в приложении несколько страниц, на значке отображается **самая низкая** оценка среди всех URL-адресов, просканированных Replit. Благодаря этому наиболее проблемная страница сразу оказывается на виду, а не теряется за средним значением.

<div id="section-3">
  ### Когда рассчитывается оценка
</div>

Проверка автоматически запускается после каждой успешной публикации. Оценка обычно появляется в течение 1~2 минут после того, как деплой становится доступен, а инструмент Publishing обновляет значок сразу после получения результатов.

<div id="section-4">
  ### Поддерживаемые типы развёртываний
</div>

SEO-оценка рассчитывается только для публичных веб-развёртываний, URL-адреса которых доступны для сканирования поисковыми системами.

* [Развёртывания с автомасштабированием](/ru/ko/features/publishing/deployment-types#autoscale)
* [Развёртывания Reserved VM](/ru/ko/features/publishing/deployment-types#reserved-vm)
* [Статические развёртывания](/ru/ko/features/publishing/deployment-types#static)

SEO-оценка не создаётся для развёртываний по расписанию и частных развёртываний, поскольку они не обслуживают публичный веб-трафик.

<div id="agent-seo">
  ## Оптимизация SEO с помощью Agent
</div>

Рядом с оценкой отображается кнопка **Optimize SEO with Agent**. При её нажатии в панели Growth откроется [SEO Agent](/ru/ko/features/publishing/seo-agent), где можно запустить технический SEO-аудит, просмотреть найденные проблемы и применить исправления одним щелчком.

<Tip>
  Можно обойтись и без кнопки. Откройте Agent и скажите **«Оптимизируй SEO»** — Agent получит последние результаты и начнёт устранять проблемы одну за другой.
</Tip>

После того как Agent внесёт изменения, опубликуйте приложение заново. SEO-оценка будет пересчитана по новой сборке, а значок обновится автоматически.

Типичные исправления, которые вносит Agent:

* Добавление или переписывание отсутствующих либо шаблонных тегов `<title>`, чтобы у каждой страницы был уникальный и содержательный заголовок
* Добавление мета-описаний на все страницы
* Добавление содержательного текста `alt` к изображениям
* Установка атрибута `lang` для элемента `<html>`
* Проверка того, что ссылки содержат осмысленный текст (без «нажмите здесь» и пустых якорей)
* Добавление `robots.txt` и `sitemap.xml`
* Добавление мета-тега viewport для корректного отображения на мобильных устройствах
* Улучшение цветового контраста текста, не проходящего проверки доступности
* Добавление мета-тегов Open Graph и Twitter Card, чтобы ссылки на приложение хорошо выглядели в социальных сетях

<div id="replit-seo-2">
  ## Рекомендации по созданию SEO-оптимизированных сайтов на Replit
</div>

Поручаете ли вы эти задачи Agent или выполняете их самостоятельно, чтобы приложение, созданное на Replit, работало максимально эффективно, важно соблюдать следующие рекомендации.

* **Добавьте уникальные заголовок и метаописание на каждую страницу.** Длина заголовка должна быть не более 60 символов, а описания — около 150~160 символов.
* **Используйте семантический HTML.** Размечайте макет с помощью `<main>`, `<header>`, `<nav>`, `<footer>`. Используйте `<h1>` только один раз на странице и соблюдайте последовательную иерархию заголовков.
* **Добавьте альтернативный текст ко всем изображениям.** Описывайте не само изображение, а то, что на нём показано.
* **Создайте `sitemap.xml` и `robots.txt`.** Попросите Agent создать оба файла, чтобы поисковые системы знали, что следует сканировать.
* **Добавьте теги Open Graph и Twitter Cards.** Они позволяют управлять тем, как ваше приложение выглядит при публикации в социальных сетях.
* **Используйте пользовательский домен.** Фирменный домен вызывает доверие как у посетителей, так и у поисковых систем. См. [Custom Domains](/ru/ko/features/publishing/custom-domains).
* **Выберите подходящий тип развёртывания.** Для сайтов с большим объёмом контента [Static Deployments](/ru/ko/features/publishing/deployment-types#static) предоставляют предварительно отрендеренный HTML, который поисковые системы могут сразу анализировать.
* **Добавьте структурированные данные.** Разметка JSON-LD помогает поисковым системам показывать расширенные результаты для продуктов, статей, FAQ и событий.
* **Поддерживайте высокую скорость работы приложения.** Оптимизируйте изображения, избегайте скриптов, блокирующих рендеринг, и используйте хостинг Replit, чтобы сократить время отклика.

Вот простой способ применить большинство этих рекомендаций за один раз.

<AiPrompt>
  Проверь мой сайт на соответствие рекомендациям по SEO и внеси исправления. Добавь sitemap, robots.txt, теги Open Graph, структурированные данные там, где это уместно, и убедись, что у каждой страницы есть уникальные заголовок и метаописание.
</AiPrompt>
