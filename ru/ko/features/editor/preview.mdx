Preview показывает результат работы веб-приложения и предоставляет браузерные инструменты
разработчика и возможности отладки.

Когда вы запускаете веб-приложение кнопкой **Run**, Replit выделяет ему временный URL,
доступный из интернета. Инструмент Preview отображает страницу точно так же,
как она выглядела бы в браузере. Кроме того, он включает
инструменты разработчика, аналогичные тем, что есть в обычных браузерах.

<Note>
  Preview — это новое название Webview.
</Note>

<div id="section">
  ## Возможности
</div>

Preview предлагает следующие возможности для удобного тестирования и отладки веб-приложений.

* **Просмотр в реальном времени**: смотрите на приложение и взаимодействуйте с ним, не покидая вкладку браузера
* **Инструменты разработчика**: быстро выявляйте проблемы с помощью встроенных инструментов
* **Тестирование адаптивности**: проверяйте приложение на экранах мобильных устройств разных размеров

<div id="section-2">
  ## Использование
</div>

Инструмент Preview открывается автоматически при запуске веб-приложения.
Это поведение можно включить или отключить с помощью параметра **Automatic Preview** в инструменте **User Settings**.

Ниже описано, как открыть Preview.

<Accordion title="Как открыть Preview">
  В **доке инструментов** слева:

  1. Выберите <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="All tools icon" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**, чтобы открыть список инструментов Project Editor.
  2. Выберите <img class="icon-svg" src="/assets/mirror/preview-icon-6d37238e8cc2.svg" alt="Preview icon" width="16" height="16" data-path="images/icons/preview-icon.svg" /> **Preview**.

  В **строке поиска**:

  1. Нажмите значок лупы <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="magnifying glass icon" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> вверху, чтобы открыть инструмент поиска
  2. Введите «Preview», чтобы найти инструмент, и выберите его в результатах поиска.
</Accordion>

<div id="section-3">
  ## Адресная строка
</div>

Адресная строка в верхней части вкладки **Preview** содержит следующие инструменты:

* **Кнопка «Назад»**: переход к предыдущей странице в истории навигации
* **Кнопка «Вперёд»**: переход к следующей странице в истории навигации
* **Домен приложения**: выберите `{...}.replit.dev`, чтобы посмотреть информацию о временном URL вашего Replit App
* **Поле адреса**: просмотр текущего пути URL или ввод нового

<div id="section-4">
  ## Инструменты браузера
</div>

Справа от адресной строки расположены инструменты браузера со следующими возможностями:

* **Размер экрана**: выбор готовых размеров экранов различных устройств для проверки адаптивного дизайна
* **Devtools**: включение и выключение панели [инструментов разработчика](#Developer_tools)
* **Новая вкладка**: открытие URL веб-приложения в новой вкладке браузера

<Note>
  **Создаёте мобильное приложение?** Панель Preview также поддерживает предпросмотр в **iOS Simulator** или **Android Emulator**. Подробнее см. [Native Mobile Apps](/ru/ko/features/artifact-types/building-mobile-apps#preview-on-a-simulator-or-emulator).
</Note>

<div id="section-5">
  ## Инструменты разработчика
</div>

Инструменты разработчика на базе проекта с открытым исходным кодом <a href="https://github.com/liriliri/eruda" target="_blank">Eruda</a> помогают выполнять следующие задачи:

* просматривать консоль JavaScript в контексте приложения и взаимодействовать с ней;
* исследовать элементы DOM;
* отслеживать сетевые запросы;
* настраивать параметры отображения и поведения.

Чтобы открыть инструменты разработчика, нажмите кнопку <img class="icon-svg" src="/assets/mirror/wrench-7cee9d1168da.svg" alt="wrench icon" width="16" height="16" data-path="images/icons/wrench.svg" /> **Devtools**
в верхней части вкладки **Preview** — она включает и выключает панель.

В следующих разделах описано, что можно делать на каждой вкладке инструментов разработчика.

<div id="console">
  ### Console
</div>

На вкладке **Console** отображаются журналы JavaScript, созданные приложением.
Здесь можно выполнять следующие действия:

* **Очистка вывода**: нажмите значок перечёркнутого круга <img class="icon-svg" src="/assets/mirror/clear-bd1bf1847597.svg" height="16" width="16" alt="clear icon" data-path="images/icons/clear.svg" />, чтобы удалить весь вывод консоли.
* **Фильтрация вывода**: просматривайте вывод консоли с фильтрацией по типу (All, Info, Warning, Error).
* **Фильтрация по тексту**: нажмите значок фильтра <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="filter icon" data-path="images/icons/filter.svg" /> и введите текст, чтобы увидеть совпадающие строки вывода.
* **Копирование вывода**: нажмите кнопку копирования <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="copy icon" data-path="images/icons/copy.svg" />, чтобы скопировать выбранные сообщения консоли.
* **Выполнение кода JavaScript**: нажмите стрелку вправо <img class="icon-svg" src="/assets/mirror/arrow-right-2859a6e6bdeb.svg" height="16" width="16" alt="right arrow icon" data-path="images/icons/arrow-right.svg" />, чтобы выполнить код JavaScript в контексте приложения. Введите выражение и нажмите **Execute**.

<div id="elements">
  ### Elements
</div>

На вкладке **Elements** можно просматривать и изменять структуру DOM веб-страницы.

* **Просмотр сведений об элементе**: сведения об элементе DOM и его расположении в HTML-коде
* **Копирование вывода**: нажмите кнопку копирования <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="copy icon" data-path="images/icons/copy.svg" />, чтобы скопировать выбранное сообщение консоли.

Включайте и отключайте режим выбора с помощью инструмента со стрелкой <img class="icon-svg" src="/assets/mirror/select-1165d9548c39.svg" height="16" width="16" alt="select icon" data-path="images/icons/select.svg" />.
В режиме выбора укажите нужный элемент на веб-странице.
HTML и CSS этого элемента отобразятся на вкладке Elements.

<div id="network">
  ### Network
</div>

Вкладка **Network** отслеживает запросы, инициированные веб-страницей.
На этой вкладке можно выполнять следующие действия:

* **Отслеживание запросов**: просматривайте все сетевые запросы, отправленные приложением. Выберите запрос, чтобы увидеть подробные сведения о нём.
* **Фильтрация**: нажмите значок фильтра <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="filter icon" data-path="images/icons/filter.svg" />, чтобы отобразить результаты, соответствующие введённому тексту. Если оставить поле фильтра пустым, фильтр сбрасывается.
* **Копирование**: нажмите кнопку копирования <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="copy icon" data-path="images/icons/copy.svg" />, чтобы скопировать информацию о хранилище.

<div id="resources">
  ### Resources
</div>

Вкладка **Resources** показывает ресурсы, загруженные страницей, а также хранилища браузера: файлы cookie, локальное хранилище и другие.
Здесь можно просматривать и обновлять списки ресурсов следующих типов:

* Файлы JavaScript
* Таблицы стилей
* Iframe
* Изображения

На этой вкладке доступны следующие действия:

* **Просмотр хранилища**: изучение локального хранилища, сессионного хранилища и файлов cookie.
* **Фильтрация**: выберите значок фильтра <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="filter icon" data-path="images/icons/filter.svg" />, чтобы отобразить результаты, совпадающие с текстом. Если оставить поле фильтра пустым, фильтр сбрасывается.
* **Очистка**: выберите кнопку очистки <img class="icon-svg" src="/assets/mirror/clear-bd1bf1847597.svg" height="16" width="16" alt="clear icon" data-path="images/icons/clear.svg" />, чтобы удалить все данные соответствующего типа хранилища.
* **Удаление выбранного элемента**: выберите значок «X» <img class="icon-svg" src="/assets/mirror/delete-a21eb49cac3c.svg" height="16" width="16" alt="delete icon" data-path="images/icons/delete.svg" />, чтобы удалить запись из хранилища.
* **Копирование**: выберите кнопку копирования <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="copy icon" data-path="images/icons/copy.svg" />, чтобы скопировать информацию из хранилища.

<div id="settings">
  ### Settings
</div>

На вкладке **Settings** можно настроить внешний вид и поведение инструментов разработчика.
Здесь доступны следующие группы параметров:

* **Настройки инструментов**: параметры для каждой вкладки инструментов
* **Управление JavaScript**: параметры поведения JavaScript — например, его можно отключить, чтобы проверить, как приложение работает без JavaScript
* **Параметры отображения**: изменение темы инструментов разработчика, размера панелей, прозрачности и других аспектов поведения
