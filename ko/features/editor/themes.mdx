Replit의 테마를 사용하면 배경 색상과 UI 요소부터 코드의 구문 강조까지 Project Editor의 모습을 커스터마이즈할 수 있습니다. 가독성 향상, 눈의 피로 감소, 더 즐거운 코딩 경험을 위해 개발 환경을 개인화하세요.

## 커스텀 테마 만들기

다음 단계를 따라 자신만의 테마를 만들고 커스터마이즈하세요.

1. [Settings](https://replit.com/settings)를 열고 **User** → **Personalization**(또는 **Themes** 섹션)으로 이동하세요
2. **Create new theme**을 선택하세요
3. 제목을 입력하고, 색상 구성(밝은 테마 또는 어두운 테마)을 선택하고, 선택적으로 설명을 추가하세요
4. **Create Theme**을 선택해 Themes Editor를 여세요

전역 테마 설정은 전체적인 UI 모습을 제어합니다.

* **Background**: 대부분의 UI 표면에 대한 기본 색상 설정
* **Outline**: 테두리와 구분선의 색상 제어
* **Foreground**: 텍스트와 아이콘 색상 결정
* **Primary**: 버튼과 대화형 요소의 색상 정의
* **Positive**: **Run** 버튼 같은 성공 표시에 적용
* **Negative**: 오류와 파괴적인 작업 경고에 표시

**Apply Theme**을 선택해 즉시 커스텀 테마 사용을 시작하세요.

## 구문 강조

가독성과 이해도를 높이기 위해 다양한 코드 요소가 표시되는 방식을 커스터마이즈하세요.

<Tip>
  적절한 구문 강조는 코드를 한눈에 훑어보고 이해하기 쉽게 만들어줍니다. 서로 잘 어울리고 배경에 대해 충분한 대비를 제공하는 색상을 선택하세요.
</Tip>

<Accordion title="구문 강조 요소">
  | 요소                       | 설명                                          |
  | ------------------------ | ------------------------------------------- |
  | **Variable Names**       | 선언 키워드가 사용되지 않은 변수에 적용                      |
  | **Variable Definitions** | `const`나 `var` 같은 키워드로 정의된 변수 이름의 색상 지정     |
  | **Function References**  | 함수를 호출할 때 적용                                |
  | **Function Definitions** | 함수 이름을 선언할 때 색상 지정                          |
  | **Keywords**             | `import`, `function`, `return` 같은 언어 키워드 강조 |
  | **Property Names**       | 변수에서의 속성 접근 색상 지정                           |
  | **Property Definitions** | 객체 속성을 정의할 때 사용                             |
  | **Function Properties**  | 객체의 메서드를 호출할 때 적용                           |
  | **Tag Names**            | HTML 및 JSX 태그에 사용                           |
  | **Type Names**           | 타입이 있는 언어에서 타입 어노테이션의 색상 지정                 |
  | **Class Names**          | 클래스 선언 및 참조에 적용                             |
  | **Attribute Names**      | HTML 및 JSX 속성 강조                            |
  | **Comments**             | 모든 코드 주석에 적용                                |
  | **Strings**              | 문자열 리터럴의 색상 지정                              |
  | **Numbers**              | 숫자 값 강조                                     |
  | **Booleans**             | 불리언 값(`true`/`false`) 서식 지정                 |
  | **Regular Expressions**  | 정규식 패턴 색상 지정                                |
  | **Operators**            | `+`, `-`, `*`, `/` 같은 연산자 강조                |
  | **Brackets**             | 필요한 경우 대괄호와 꺾쇠 괄호의 색상 지정                    |
</Accordion>

## 테마 디자인 모범 사례

다음 가이드라인을 따라 보기 좋고 실용적인 테마를 만드세요.

### 색상과 대비

* **대비 균형 맞추기**: 배경과 전면 요소 간에 충분한 차이를 확보하세요
* **일관된 팔레트 만들기**: 서로 충돌하지 않고 어울리는 색상을 선택하세요
* **일관된 밝기 유지하기**: 구문 요소 전체에서 비슷한 밝기 수준을 유지하세요
* **접근성을 고려한 디자인**: 낮은 대비 조합을 피해 시각 장애가 있는 사용자를 고려하세요

<Warning>
  피해야 할 일반적인 테마 디자인 문제:

  * 구문 요소 간 과도한 밝기 차이
  * 시각적 부조화를 일으키는 잘못 매칭된 색상
  * 코드와 배경 간 불충분한 대비
</Warning>

## 테마 관리하기

[Settings](https://replit.com/settings)의 **User** → **Personalization**(또는 **Themes** 섹션)에서 설치한 모든 테마에 접근하고 관리하세요.

### 테마 전환하기

테마 제목 옆의 버튼을 선택해 현재 테마로 활성화하세요.

### 테마 편집하기

세 점 메뉴를 선택하고 **Edit**을 클릭해 커스텀 테마를 수정하세요.

<Note>
  직접 만든 커스텀 테마만 편집하거나 삭제할 수 있습니다. 기본 테마와 다른 사람이 만든 테마는 수정할 수 없습니다.
</Note>

### 테마 삭제하기

세 점 메뉴를 사용해 **Delete**를 선택하면 커스텀 테마를 제거할 수 있습니다.

## 커뮤니티 테마 살펴보기

[Themes Explore Page](https://replit.com/themes)에서 Replit 커뮤니티가 만든 테마를 발견하세요.

### 테마 찾기

* 이름으로 검색해 "Atom One Dark" 같은 특정 테마 찾기
* 작성자로 필터링해 특정 크리에이터의 테마 탐색
* 색상 구성으로 찾아보며 밝은 테마 또는 어두운 테마 찾기
* 특정 색상으로 검색해 원하는 취향에 맞추기

설치하기 전에 테마를 미리 보고 Project Editor에서 어떻게 보일지 확인하세요.

## 테마 게시하기

다음 단계를 따라 커스텀 테마를 Replit 커뮤니티와 공유하세요.

1. 커스텀 테마의 Themes Editor를 여세요
2. **Publish** 버튼을 선택하세요
3. 제목과 설명 필드를 작성하세요
4. 테마를 제출하세요

게시가 완료되면 테마가 Themes Explore Page에 표시되어 다른 사용자가 미리 보고 설치할 수 있습니다.
