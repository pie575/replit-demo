<div id="compre-o-enterprise-online-com-configurao-automtica-de-sso">
  ### 在线购买 Enterprise，自动配置 SSO
</div>

现在你可以直接在[定价页面](https://replit.com/pricing)购买 Replit Enterprise 计划，无需联系销售团队。完成结账后，产品内的设置向导会引导你完成端到端的单点登录配置。只需将身份提供商提供的值粘贴到 SAML 表单中，Replit 就会自动为你预配 SSO 连接。你的团队几分钟内即可启用 Enterprise，无需再等待邮件往来。

<div id="limites-de-gasto-por-usurio-para-workspaces-enterprise">
  ### Enterprise workspace 的按用户支出限额
</div>

Enterprise 管理员现在可以为 workspace 中的单个成员分别设置 Agent 支出限额。在[用量页面](https://replit.com/usage)打开 **Agent 用户**表格，点击任意行的编辑图标，然后选择新的限额。按用户设置的限额优先于分组默认值和 workspace 默认值。当你想为高级用户放宽限额，或在不影响 workspace 其他成员的前提下限制某位成员的支出时，这一功能尤为实用。

  ### 将 Canvas 中的 frame 导出为 PNG
</div>

在 Canvas 中右键点击任意产物或设计 frame，选择 **导出** &gt; **PNG**，即可下载当前预览的快照。适合快速把某个画面分享到文档、对话或同事评审中，无需手动截屏。导出的图片与导出时 frame 在 Canvas 中的显示效果完全一致。

<div id="nove-novos-conectores-prontos-para-uso">
  ### 九个开箱即用的新连接器
</div>

九个新连接器现已内置默认凭据，只需一次点击即可将它们连接到 Agent，无需事先配置自己的 OAuth 应用。在项目中打开 **集成** 面板，选择服务并授权连接即可。

* **Airtable**：读写 base、表格和记录。
* **GitLab**：访问项目、issue、merge request 和流水线。
* **Basecamp**：读取和管理项目、任务、消息和日程。
* **Productboard**：读取和更新功能、发布计划和客户反馈。
* **Teamwork**：读取和管理项目、任务和工时记录。
* **Twitch**：读取直播、频道和观众活动。
* **Square**：收取付款，管理订单、客户和库存。
* **Intercom**：读取和管理会话、联系人和支持流程。
* **Mailchimp**：读取和管理受众、营销活动和邮件营销数据。

进一步了解[连接器](/zh/pt/features/integrations/overview#conectores-disponíveis)。

<div id="quatro-novos-servidores-mcp-no-diretrio">
  ### 目录中新增四个 MCP 服务器
</div>

[MCP 目录](/zh/pt/features/mcp/overview)现已提供四个托管的 Model Context Protocol 服务器。打开**集成**面板，在 **Replit Agent 的 MCP 服务器**中找到相应服务器，然后选择**添加到 Replit** 即可连接。

* **Twilio**：搜索 Twilio 文档以及涵盖语音、短信、邮件和身份识别的 1,800 多个 API 端点。
* **Mixpanel**：查询 Mixpanel 的事件、漏斗、留存和仪表板数据。
* **Lazyweb**：搜索 25.7 万多个真实应用界面，用于 UI 参考和设计调研。
* **Doola**：注册美国 LLC，并管理公司设立、记账和税务事宜。

在 [MCP 目录](/zh/pt/features/mcp/overview)中查看完整列表。
