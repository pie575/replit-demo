<div id="venda-produtos-fsicos-com-o-shopify">
  ### Vendez des produits physiques avec Shopify
</div>

Vous pouvez désormais créer une boutique en ligne qui vend des produits physiques. Demandez à Agent de créer une boutique : il crée une boutique Shopify pour vous, y ajoute vos produits et configure le panier et le paiement. Agent vous fournit un lien pour revendiquer la boutique ; il ne vous reste plus qu&#39;à souscrire un forfait Shopify et à connecter les paiements pour la mettre en ligne.

<div id="crie-aplicativos-de-dados-no-microsoft-fabric">
  ### Créez des applications de données dans Microsoft Fabric
</div>

Vous pouvez désormais créer des applications de données avec l&#39;IA dans Replit et les publier directement dans Microsoft Fabric. Partez du template Microsoft Fabric, connectez un modèle sémantique Power BI et demandez à Agent de créer des tableaux de bord et des outils internes à partir de vos données d&#39;entreprise gérées, tout en conservant l&#39;authentification et les politiques d&#39;accès au sein de Fabric.

<div id="domnios-personalizados-configuram-seu-prprio-dns">
  ### Les domaines personnalisés configurent votre DNS automatiquement
</div>

Connecter votre propre nom de domaine est désormais bien plus simple. Lorsque vous liez un domaine, Replit configure pour vous les enregistrements DNS nécessaires via Entri, ce qui vous évite de les copier manuellement chez votre fournisseur de domaine. Choisissez votre domaine, confirmez, et Replit se charge du reste.

En savoir plus sur les [domaines personnalisés](/fr/pt/features/publishing/custom-domains).

<div id="melhore-seu-ranking-de-busca-com-o-seo-agent">
  ### Améliorez votre classement dans les résultats de recherche avec le SEO Agent
</div>

Le SEO Agent analyse votre application publiée et identifie les problèmes qui empêchent les moteurs de recherche et les outils d&#39;IA de la découvrir. Chaque problème détecté s&#39;accompagne d&#39;une correction en un clic, que vous pouvez examiner puis appliquer. Ouvrez le panneau **Growth** de votre projet pour lancer une analyse.

<div id="use-o-stripe-em-workspaces-colaborativos">
  ### Utilisez Stripe dans les workspaces collaboratifs
</div>

Stripe fonctionne désormais dans les workspaces collaboratifs : toute votre équipe peut ainsi créer, tester et monétiser une même application. Tous les membres du workspace peuvent utiliser le compte Stripe connecté, au lieu de développer les paiements chacun de leur côté.

Pour en savoir plus, consultez [Paiements avec Stripe](/fr/pt/features/monetization/stripe-payments).
