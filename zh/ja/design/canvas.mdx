Canvas 是 Replit Design 用于显示画框的无限画布，你可以在其中自由平移和缩放。你设计的所有内容都在这里：生成画框、移动画框、放大查看细节，并不断迭代，直至满意。

<div id="canvas">
  ## 打开 Canvas
</div>

Canvas 是你在 Replit Design 中最先看到的界面。在项目中点击顶部标题栏的 **Design**，Canvas 会占满整个窗格；点击 **Build** 则返回正在运行的应用。

<Frame>
  <img src="/assets/mirror/canvas-design-button-ffa50447cefb.png" alt="项目标题栏中 Design 与 Build 切换按钮的特写。Design 处于选中状态，下方显示 Canvas 上的画框" width="987" height="619" data-path="images/replitai/canvas-design-button.png" />
</Frame>

如果从 [replit.com/design](https://replit.com/design) 开始，系统会提示你创建新设计，并打开 Canvas。关于何时使用哪个界面，请参阅 [Design 与 Build 的区别](/zh/ja/design/design-vs-build)。

<div id="canvas-2">
  ## Canvas 上的内容
</div>

* **画框**：画板上的所有图块。画框 可以是设计模型、Web 应用、移动应用、幻灯片、图片、视频或矢量图形。你可以通过聊天提示词、工具栏中的 [Generate 菜单](/zh/ja/design/toolbar#generate) 和[库面板](/zh/ja/design/library-panel)生成 画框。你对 画框 执行的所有操作 — Build、Focus、建议等 — 都通过 画框 本身完成。有关详细信息，请参阅 [画框](/zh/ja/design/frames)。
* **绘图和备注**：通过 [Draw 工具](/zh/ja/design/toolbar#draw)添加的标记，包括草图、箭头、形状和便签等。Agent 可以读取你的标记，因此你可以圈出需要修改的部分并请求更改。
* **聊天面板**：停靠在 Canvas 旁的 Agent 聊天面板。发送消息前选择一个 画框，该 画框 会以快照形式附加，让 Agent 获取视觉上下文。

有关各组件的作用及其如何组合，请参阅[组件概览](/zh/ja/design/core-components)。

<div id="section">
  ## 移动画板
</div>

除非另有说明，平移、缩放和选择操作在任何工具下都可以进行。

**平移：**

* 触控板：双指拖动。
* 鼠标：中键拖动，或按住空格键的同时用左键拖动。
* [Pan 工具](/zh/ja/design/toolbar#pan)：按住鼠标左键拖动。

**缩放：**

* 触控板：双指捏合。
* 鼠标：`Ctrl` (macOS 上为 `Cmd`) + 滚轮。
* 键盘：`Cmd`/`Ctrl` + `+` 放大，`Cmd`/`Ctrl` + `-` 缩小，`Cmd`/`Ctrl` + `0` 重置缩放。

缩放以光标位置为基准，因此画板的其余部分会围绕光标放大或缩小，而光标下方的位置保持不动。

**选择：**

* 单个 画框：用 [Interact 工具](/zh/ja/design/toolbar#interact)点击。
* 多选：按住 `Shift` 逐个点击 画框，或在画板上拖出选框 (框选) 。
* 取消选择：点击空白区域，或按 `Escape`。

选中一个或多个 画框 后，会出现[单个 画框 的操作栏](/zh/ja/design/frames#per-frame-action-bar)，并且这些 画框 会作为快照附加到下一条 Agent 消息中。

<div id="section-2">
  ### 键盘快捷键
</div>

| 快捷键                            | 操作             |
| ------------------------------ | -------------- |
| `V`                            | 启用 Interact 工具 |
| `H`                            | 启用 Pan 工具      |
| 按住 `Space` 拖动                  | 在任意工具下平移       |
| `Cmd` / `Ctrl` + 滚动            | 缩放             |
| `Cmd` / `Ctrl` + `+`           | 放大             |
| `Cmd` / `Ctrl` + `-`           | 缩小             |
| `Cmd` / `Ctrl` + `0`           | 重置缩放           |
| `Shift` + 点击                   | 将画框加入当前选择      |
| `Cmd` / `Ctrl` + `Shift` + `C` | 将所选画框复制为 PNG   |
| `Escape`                       | 取消选择           |

<div id="section-3">
  ## 右键菜单
</div>

在画板上任意位置点击右键即可打开上下文菜单。该菜单会随上下文而变化，根据光标所指的对象显示不同操作：在 画框 上显示针对 画框 的操作，在空白 Canvas 上显示画板级操作，而在应用的 画框 上还会additional 显示 **Refresh artifact**。

在选中的 画框 上，菜单包含以下内容：

| 操作                             | 快捷键                        | 说明                                              |
| ------------------------------ | -------------------------- | ----------------------------------------------- |
| Edit                           |                            | 切换到 Edit 工具，选择 画框 内的元素。                      |
| Chat                           |                            | 就该 画框 与 Agent 对话。                            |
| Focus                          |                            | 让 画框 进入[聚焦模式](/zh/ja/design/frames#focus-mode)。 |
| Cursor chat                    | `/`                        | 在光标位置发起快速对话。                                    |
| Reorder                        |                            | 将 画框 移到层叠顺序的最前面或最后面。                         |
| Copy, Paste, Duplicate, Delete | `⌘C`、`⌘V`、`⌘D`、`Backspace` | 标准的剪贴板与 画框 操作。                               |
| Export as…                     |                            | 将 画框 导出为文件。                                  |
| Select all                     | `⌘A`                       | 选中画板上的所有 画框。                                 |

<div id="png">
  ### 将画框导出为 PNG
</div>

你可以将任意产物或设计画框保存为 PNG 图像。这非常适合在文档或聊天中分享预览、在继续迭代前留存快照，或者把截图发给团队成员。

<Steps>
  <Step title="选择画框">
    选中要导出的产物或设计画框，并等待其加载完成。
  </Step>

  <Step title="选择 Export">
    在画框的操作栏中选择 **Export**。你也可以右键单击画框，然后选择 **Export as…** &gt; **PNG**。图像会以画框名称为基础命名，并下载到你的电脑上。
  </Step>
</Steps>

如果想将所选画框复制为 PNG 而不下载，请按 `Cmd+Shift+C` (Windows 和 Linux 上为 `Ctrl+Shift+C`) 。

<Note>导出的 PNG 与画框当前在 Canvas 上显示的内容一致。如果应用或设计仍在加载，请等待其完全渲染后再导出。</Note>

<div id="canvas-3">
  ## Canvas 与运行中的应用
</div>

Canvas 与运行中应用的预览共用同一个窗格，有几种模式在两者之间起到衔接作用：

* **专注模式**：对选中的 画框 执行 **Focus** 操作，可将该 画框 放大至铺满整个视图。点击画板顶部的 **Exit focus** 即可返回 Canvas。
* **只读模式**：当 Canvas 在后台任务的上下文中被锁定时，迭代类操作会隐藏，仅保留 Focus。

<Note>
  从 Design 画框 构建新应用需要 Core 或 Pro 方案。其他 Canvas 功能在所有方案中均可使用。方案详情请参阅[账单](/zh/ja/billing/ai-billing)。
</Note>
