Контекст — это информация, которую модель ИИ использует для формирования следующего ответа. Управление контекстом — это практика предоставления модели нужной информации в нужный момент.

Это важно, поскольку ИИ не может работать, опираясь лишь на ваши намерения. ИИ использует текст, файлы, скриншоты, логи, примеры и историю диалога, доступные в контекстном окне.

<div id="section">
  ## Что такое контекстное окно?
</div>

ИИ-модели могут одновременно учитывать лишь ограниченный объём информации. Это ограничение называется контекстным окном.

Контекстное окно может включать:

* Ваш промпт
* Предыдущие сообщения в диалоге
* Файлы или код, доступные модели
* Сообщения об ошибках и логи
* Скриншоты, изображения или примеры дизайна
* Инструкции проекта, например `replit.md`
* Результаты работы инструментов на предыдущих шагах

Модель использует этот контекст, чтобы решить, что сгенерировать дальше.

<div id="section-2">
  ## Почему важно контекстное окно
</div>

Если в контексте нет важных деталей, модель может начать делать предположения. Если нерелевантной информации слишком много, модель может сосредоточиться не на том.

Например, в этом промпте почти нет контекста:

```text theme={null}
Улучшите страницу регистрации.
```

Этот промпт содержит полезный контекст:

```text theme={null}
Улучшите страницу регистрации для начинающих основателей, которые решают, присоединяться ли к списку ожидания.
Сохраните текущие поля. Сделайте ценностное предложение над формой более понятным.
Не изменяйте раздел с ценами.
```

Второй промпт уточняет, для кого предназначена страница, что нужно улучшить и сохранить, а также что выходит за рамки задачи.

<div id="section-3">
  ## Размеры контекстных окон различаются
</div>

Разные модели ИИ могут обрабатывать разный объём контекста. Более крупное контекстное окно позволяет учитывать больше текста одновременно, но больше — не всегда лучше. Релевантный контекст по-прежнему важнее, чем перегружать диалог всеми подробностями.

Примеры размеров общедоступных контекстных окон:

| Семейство моделей | Пример размера контекстного окна |
| ----------------- | -------------------------------- |
| GPT-4.1           | До 1 млн токенов                 |
| Claude Sonnet 4.5 | До 200 тыс. токенов              |
| Gemini 2.5 Pro    | До 1 млн токенов                 |

Эти значения со временем меняются, и не все продукты предоставляют доступ ко всему контекстному окну модели. Практический вывод остаётся неизменным: излагайте важную информацию ясно и по существу.

<div id="section-4">
  ## Типы контекста
</div>

| Тип контекста           | Пример                                                                             |
| ----------------------- | ---------------------------------------------------------------------------------- |
| **Цель**                | &quot;Эта лендинг-страница должна собирать заявки в список ожидания.&quot;         |
| **Аудитория**           | &quot;Для занятых владельцев ресторанов.&quot;                                     |
| **Ограничения**         | &quot;Сохраните текущую цветовую палитру и поля формы.&quot;                       |
| **Не является целью**   | &quot;Пока не добавляйте платёж.&quot;                                             |
| **Примеры**             | Скриншоты, макеты, примеры данных или страницы конкурентов.                        |
| **Состояние проекта**   | Текущие файлы, компоненты, сообщения об ошибках или пользовательские сценарии.     |
| **Критерии готовности** | &quot;Посетители могут отправить форму и увидеть сообщение с благодарностью.&quot; |

<div id="section-5">
  ## Актуальный и постоянный контекст
</div>

Часть контекста относится к текущему разговору. Используйте его, когда запрашиваете конкретные изменения, отлаживаете отдельную проблему или даёте обратную связь по недавним результатам.

Другой контекст должен сохраняться на протяжении всего проекта. Используйте постоянный контекст для стиля кода, рекомендаций по бренду, правил именования, повторно используемых правил продукта и ограничений, которые Agent должен помнить между рабочими сессиями. В Replit файл [replit.md](/ru/ko/features/project-setup/replit-dot-md) — один из способов предоставить Agent постоянный контекст проекта.

<div id="section-6">
  ## Когда контекст становится перегруженным
</div>

В долгих диалогах легко потерять направление. Если в ветке накопилось слишком много не связанных между собой решений, Agent может учитывать устаревший контекст, который больше не имеет значения.

Начните новую ветку, если:

* переходите к несвязанной функции
* в диалоге накопилось много отброшенных направлений
* Agent продолжает учитывать устаревшие ограничения
* хотите составить чёткий план для новой области

Начиная заново, кратко изложите важный контекст, а не предполагайте, что Agent по-прежнему знает, что важно.

```text theme={null}
Контекст: этот проект — приложение для записи в лист ожидания к местным фитнес-тренерам.
Основной сценарий: лендинг → форма регистрации → сообщение-подтверждение.
В этой ветке улучшайте только текст сообщения-подтверждения и последующих сообщений.
```

<div id="section-7">
  ## Распространённые заблуждения
</div>

* **«Чем больше контекста, тем лучше».** Лучше использовать релевантный контекст. Избыток нерелевантного контекста может отвлекать модель.
* **«Модель идеально помнит всё».** AI использует доступный контекст, но важные ограничения стоит повторять, когда это необходимо.
* **«Контекст — это только текст».** Скриншоты, файлы, данные, дизайн, логи и примеры — всё это может быть контекстом.
