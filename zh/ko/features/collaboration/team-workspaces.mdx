<div id="section">
  ## 个人工作区和团队工作区
</div>

**工作区**用于存放您的应用、成员、设置和账单信息。Replit 提供两种类型：

* 个人工作区
* 团队工作区

以下是个人工作区和团队工作区的区别。

|          | 个人工作区         | 团队工作区               |
| -------- | ------------- | ------------------- |
| **角色**   | Admin、项目级访客   | Admin、Members、项目级访客 |
| **访问模式** | 邀请访客加入单个项目    | 成员可访问工作区中的所有项目      |
| **账单**   | 您的账户          | Admin 账户的共享积分       |
| **成员管理** | 按项目管理 (邀请链接)  | 在工作区 Settings 中集中管理 |

**个人工作区**最适合独自工作或与他人共享单个项目。您是唯一的 Admin，其他人只能作为项目级访客访问您邀请他们加入的特定项目。

**团队工作区**最适合与固定团队一起构建，例如创业团队、课堂或有多位贡献者的客户项目。成员可以访问工作区中的所有项目，因此无需逐一邀请他们加入每个项目。成员可在 **Settings** 中集中管理。

<div id="section-2">
  ### 邀请加入工作区还是邀请加入项目
</div>

| 情况                | 应该怎么做                                |
| ----------------- | ------------------------------------ |
| 需要访问所有内容的长期协作者    | 邀请加入工作区                              |
| 只需使用某一个项目的外包人员或访客 | [邀请加入项目](/zh/ko/build/invite-teammates) |
| 新入职公司的团队成员        | 邀请加入工作区                              |
| 帮忙调试某个应用的朋友       | [邀请加入项目](/zh/ko/build/invite-teammates) |

<div id="section-3">
  ## 创建团队工作区
</div>

<Frame>
  <img src="/assets/mirror/create-team-workspace-e89eaefd9168.png" alt="新建工作区表单，包含通用的工作区名称和用于邀请团队成员的空白字段" width="784" height="300" data-path="images/workspace/create-team-workspace.png" />
</Frame>

<Steps>
  <Step title="打开工作区切换器">
    在主页上，点击左上角的工作区名称。
  </Step>

  <Step title="创建新工作区">
    选择 **Create workspace**，并为团队工作区命名。
  </Step>

  <Step title="邀请成员">
    在邀请字段中输入一个或多个电子邮件地址，以逗号分隔。受邀者会收到邀请，接受后即可访问该工作区中的所有项目。
  </Step>
</Steps>

<div id="section-4">
  ## 管理成员
</div>

如果你在设置过程中没有邀请成员，或之后需要添加更多成员，可在团队工作区中前往 **Settings &gt; Workspace collaborators**，通过邮箱或 Replit 用户名邀请成员。

<Frame>
  <img src="/assets/mirror/invite-workspace-members-6e3fda413196.jpg" alt="用户邀请对话框，其中有一个用于输入邮箱地址的空白字段" width="510" height="244" data-path="images/workspace/invite-workspace-members.jpg" />
</Frame>

在 **Settings** 页面中，你还可以：

* **移除成员**，撤销其对工作区中所有项目的访问权限
* 将**应用从个人工作区迁移**至团队工作区 —— 参见[将应用迁移到团队](/zh/ko/teams/identity-and-access-management/transfer-app-to-teams)

  <Warning>
    跨工作区的项目迁移已暂时停用，目前无法发起新的迁移。
  </Warning>

如需了解高级凭据管理、基于角色的访问以及群组权限，请参见 [Pro 和 Enterprise](/zh/ko/category/teams)。
