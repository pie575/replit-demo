<div id="revenuecat">
  ## Qu&#39;est-ce que RevenueCat ?
</div>

RevenueCat vous permet d&#39;ajouter des abonnements in-app à vos [applications mobiles natives](/fr/ko/features/artifact-types/building-mobile-apps). Pour commencer, demandez à Agent de configurer les abonnements, puis connectez votre compte RevenueCat : Agent se charge de la logique et vous fournit un environnement de test.

<div id="section">
  ## Prérequis
</div>

Avant de commencer, vous aurez besoin des éléments suivants :

* Un projet Replit créé en tant qu&#39;**application mobile**
* Un compte [RevenueCat](https://www.revenuecat.com) (une adresse e-mail et un mot de passe suffisent, aucun compte bancaire ni configuration supplémentaire n&#39;est requis)

<Note>
  Pour travailler sur des applications mobiles natives, utilisez l&#39;éditeur de projet sur [replit.com](https://replit.com). Ce type de travail est également possible depuis l&#39;application Replit Android lorsqu&#39;il y est pris en charge. Si vous utilisez l&#39;application Replit iOS, ouvrez votre projet sur replit.com.
</Note>

<div id="section-3">
  ## Tester les abonnements
</div>

L&#39;aperçu Replit utilise le **mode test** de RevenueCat. Lorsque vous testez un achat dans Expo Go, une boîte de dialogue d&#39;achat test s&#39;affiche à la place du véritable flux de paiement. Aucun montant ne vous est facturé.

<Frame>
  <img src="/assets/mirror/revenuecat-test-purchase-8414145a112e.png" alt="Boîte de dialogue d'achat test sur un appareil mobile affichant les détails du forfait et le bouton de test" width="683" height="1253" data-path="images/replitai/revenuecat-test-purchase.png" />
</Frame>

<Tip>
  Les achats test peuvent être utilisés en toute sécurité pendant le développement. Vous pouvez tester aussi bien les flux d&#39;achat réussis que ceux ayant échoué, sans aucun frais réel.
</Tip>

<Warning>
  Une fois qu&#39;Apple a approuvé votre application pour la distribution sur l&#39;App Store, les achats mobilisent de l&#39;argent réel.
  Vérifiez que vos produits et vos tarifs RevenueCat sont corrects avant de soumettre votre application à l&#39;App Review.
</Warning>

<div id="section-4">
  ## Gérer les abonnements
</div>

Pour modifier votre abonnement, demandez-le à Agent. Par exemple :

<AiPrompt>Modify the subscription to be $9.99/yr instead</AiPrompt>

Agent met alors à jour la configuration des produits RevenueCat, l&#39;interface du paywall et la logique d&#39;abonnement pour appliquer vos modifications.

<div id="app-store-connect">
  ## Synchroniser avec App Store Connect
</div>

Pour que les achats intégrés fonctionnent sur TestFlight et l&#39;App Store d&#39;Apple, vous devez [accepter le contrat Apple relatif aux applications payantes et associer un compte bancaire](https://developer.apple.com/help/app-store-connect/manage-agreements/sign-and-update-agreements/).
Cela se fait via App Store Connect. Un compte développeur Apple payant est nécessaire avant de soumettre votre app à l&#39;App Store.

Vous pouvez ensuite synchroniser la configuration des achats intégrés de RevenueCat directement vers App Store Connect, depuis Replit.

<Steps>
  <Step title="Accéder au volet de gestion de la publication">
    Un bouton permettant de synchroniser RevenueCat avec App Store Connect s&#39;affiche.

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-sync-btn-46a2e4e696df.png" alt="Bouton permettant de synchroniser RevenueCat avec App Store Connect" width="1476" height="604" data-path="images/replitai/revenuecat-asc-sync-btn.png" />
    </Frame>

    <Tip>
      Cette section n&#39;apparaît qu&#39;après la soumission de votre app à TestFlight.
    </Tip>
  </Step>

  <Step title="Fournir une clé API App Store Connect">
    Pour fournir cette clé, rendez-vous sur App Store Connect.

    Dans [App Store Connect](https://appstoreconnect.apple.com/access/integrations/api), accédez à **Utilisateurs et accès**, puis sélectionnez l&#39;onglet **Intégrations**. Dans la barre latérale, sélectionnez **App Store Connect API**.

    Lors de la création de la clé, accordez-lui l&#39;autorisation « Gestionnaire d&#39;app ».

    Téléchargez le fichier .p8 immédiatement : il n&#39;est téléchargeable qu&#39;une seule fois. Son nom commence par `AuthKey_` et se termine par `.p8`.

    Copiez l&#39;**ID de clé** et l&#39;**ID d&#39;émetteur** affichés sur cette page.

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-create-c54be8304d7c.png" alt="Page Utilisateurs et accès d'App Store Connect affichant l'onglet Intégrations, le lien App Store Connect API dans la barre latérale et le bouton plus permettant de créer une clé API" width="2390" height="752" data-path="images/replitai/revenuecat-asc-create.png" />
    </Frame>

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-app-manager-93996acd8561.png" alt="Boîte de dialogue de création de clé API dans App Store Connect, avec le nom RevenueCat et l'accès défini sur Gestionnaire d'app" width="1116" height="560" data-path="images/replitai/revenuecat-asc-app-manager.png" />
    </Frame>

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-copy-07a95e1be9af.png" alt="Page des clés API App Store Connect avec le lien de copie de l'ID d'émetteur et une flèche pointant vers la colonne ID de clé" width="2330" height="780" data-path="images/replitai/revenuecat-asc-copy.png" />
    </Frame>
  </Step>

  <Step title="Créer une clé API d'achats intégrés">
    Répétez les étapes précédentes pour la clé API d&#39;achats intégrés.
    Dans la barre latérale, sélectionnez **Achats intégrés**. Créez ensuite une clé API avec l&#39;autorisation **Gestionnaire d&#39;app**.
    Téléchargez la clé .p8 (le nom du fichier commence par `SubscriptionKey_` et se termine par `.p8`). Copiez l&#39;**ID de clé** et l&#39;**ID d&#39;émetteur**.

    <Frame>
      <img src="/assets/mirror/revenuecat-iap-api-key-7eb34e815ccb.png" alt="Page Utilisateurs et accès d'App Store Connect avec Achats intégrés sélectionné dans la barre latérale et une flèche pointant vers le bouton plus permettant de créer une clé" width="2272" height="637" data-path="images/replitai/revenuecat-iap-api-key.png" />

  <Step title="Synchroniser les produits">
    Vérifiez la liste des produits, puis synchronisez-la avec App Store Connect.

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-products-sync-078d42af83ba.png" alt="Boîte de dialogue de gestion des achats intégrés affichant un produit d'abonnement mensuel avec les champs prix, durée et région, ainsi qu'un bouton Synchroniser avec App Store Connect" width="948" height="476" data-path="images/replitai/revenuecat-asc-products-sync.png" />
    </Frame>
  </Step>
</Steps>

<div id="section-5">
  ## Questions fréquentes
</div>

<AccordionGroup>
  <Accordion title="Ai-je besoin d'un compte bancaire pour utiliser RevenueCat ?">
    Non. Pour créer un compte RevenueCat, une adresse e-mail et un mot de passe suffisent. La configuration du compte bancaire s&#39;effectue séparément, auprès d&#39;Apple ou de Google, lorsque vous êtes prêt à percevoir vos revenus sur l&#39;App Store ou Google Play.
  </Accordion>

  <Accordion title="Les achats test sont-ils facturés ?">
    Non. Pendant le développement, l&#39;aperçu Replit utilise le mode test de RevenueCat.
    Les achats sont simulés et aucun montant réel n&#39;est prélevé. La facturation réelle ne s&#39;applique qu&#39;une fois votre application approuvée par l&#39;App Review d&#39;Apple.
  </Accordion>

  <Accordion title="Puis-je utiliser RevenueCat dans une application web ?">
    RevenueCat est conçu pour les applications mobiles natives. Pour ajouter des abonnements à une application web, utilisez plutôt l&#39;[intégration Stripe](/fr/ko/features/monetization/stripe-payments).
  </Accordion>

  <Accordion title="Que puis-je configurer avec RevenueCat ?">
    Vous pouvez mettre en place des abonnements mensuels ou annuels, définir les tarifs, gérer les droits d&#39;accès et créer des paywalls. Demandez simplement les modifications à Agent : il se charge à la fois de la configuration RevenueCat et du code de votre application.
  </Accordion>
</AccordionGroup>
