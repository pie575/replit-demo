As duas lojas exigem um ícone de app antes de aceitar um envio. O Replit pode gerar um
diretamente, sem necessidade de uma ferramenta de design separada.

## O que cada loja precisa

* **App Store:** 1024×1024, sem transparência, sem cantos arredondados, a Apple adiciona isso.
* **Google Play:** 512×512.

## Gere o ícone

Alterne para o modo **Design** antes de enviar o prompt, isso indica ao Agent para gerar imagens.

<AiPrompt>
  {appIconPrompt}
</AiPrompt>

O Agent gera algumas direções de uma vez, para que você possa comparar e escolher antes de se
comprometer com uma.
