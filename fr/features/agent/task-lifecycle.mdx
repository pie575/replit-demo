Chaque tâche de l&#39;Agent suit un cycle de vie : planifiée, en cours, prête pour révision, puis terminée. Ce cycle de vie isole le travail jusqu&#39;à ce que vous décidiez de ce qui doit être intégré à votre version principale.

<div id="draft">
  ## Brouillon
</div>

Un **brouillon** est une tâche qu&#39;Agent a planifiée, mais dont il n&#39;a pas encore commencé le développement. Les brouillons peuvent être consultés sans risque, car ils ne contiennent que le travail proposé : le titre de la tâche, sa description et son plan.

Utilisez les brouillons pour vérifier si Agent a bien compris l&#39;objectif. Vous pouvez lancer la tâche, demander à Agent de revoir le plan ou archiver le brouillon pour plus tard.

<div id="active">
  ## Active
</div>

Une tâche **Active** s&#39;exécute en arrière-plan. Agent y travaille dans une copie isolée de votre projet, de sorte que votre version principale reste inchangée pendant l&#39;exécution de la tâche.

Vous pouvez continuer à utiliser le fil principal pendant l&#39;exécution des tâches actives. Si une tâche nécessite un retour de votre part, ouvrez son fil et poursuivez-y la conversation.

<div id="queued">
  ## En file d&#39;attente
</div>

Une tâche **En file d&#39;attente** est approuvée, mais n&#39;a pas encore démarré. Une tâche peut être mise en file d&#39;attente lorsqu&#39;elle dépend d&#39;une autre tâche ou lorsque vous avez atteint la limite de tâches d&#39;arrière-plan actives de votre offre.

Les tâches en file d&#39;attente démarrent automatiquement dès que leurs prérequis sont terminés et qu&#39;un emplacement de tâche active se libère.

<div id="ready">
  ## Ready
</div>

Une tâche **Ready** est terminée, mais ses modifications n&#39;ont pas encore été appliquées à votre version principale. Consultez le journal de travail de la tâche, les résultats des tests et la Preview avant d&#39;appliquer les modifications.

Si le résultat vous convient, appliquez-le à la version principale. Si ce n&#39;est pas ce que vous souhaitiez, rejetez-le et lancez une nouvelle tâche.

<div id="applying">
  ## Application en cours
</div>

Une tâche **Application en cours** est en train d&#39;intégrer ses modifications dans votre version principale. Agent gère automatiquement les conflits lorsqu&#39;il applique les modifications de plusieurs tâches.

Attendez la fin de l&#39;application avant d&#39;évaluer le résultat final. Si quelque chose vous semble anormal par la suite, demandez à Agent de le corriger dans le fil principal.

<div id="done">
  ## Done
</div>

Une tâche **Done** est terminée et ne requiert plus aucune action. Done peut signifier que la tâche a été appliquée à votre version principale, qu&#39;elle a été archivée avant d&#39;avoir démarré ou qu&#39;elle a été annulée après être passée en phase de développement.

Utilisez la colonne **Done** comme historique des tâches terminées, archivées et annulées.

<div id="archiving-and-cancelling-tasks">
  ## Archiver et annuler des tâches
</div>

Vous pouvez arrêter une tâche à tout moment de son cycle de vie, mais l&#39;option proposée dépend de la position de la tâche sur le tableau. **Archiver** et **Annuler** déplacent tous deux une tâche vers la colonne **Done**, mais leur comportement diffère :

| Action       | Disponibilité                                                                                                            | Ce qui se passe                                                                                                               | Réversible ?                                                                                                              |
| ------------ | ------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| **Archiver** | Tant que la tâche est encore une session de planification : un **brouillon** dont le développement n&#39;a pas démarré        | La session de planification est mise de côté sans être exécutée. Son plan est conservé.                                       | Oui. Ouvrez la carte archivée dans la colonne **Done** et restaurez-la dans **brouillons**.                                   |
| **Annuler**  | Une fois que la tâche est passée de la planification au développement : toute tâche **Active**, **en file d&#39;attente** ou **Ready** | Agent arrête la tâche et abandonne tout travail en cours. Aucune modification n&#39;est appliquée à votre version principale. | Non. Les tâches annulées ne peuvent pas être restaurées. Créez une nouvelle tâche si vous souhaitez reprendre ce travail. |

Utilisez **Archiver** pour les sessions de planification que vous souhaitez reprendre plus tard. Utilisez **Annuler** comme bouton d&#39;arrêt définitif pour les tâches en file d&#39;attente, déjà en cours d&#39;exécution ou dont le développement est terminé.

Vous retrouverez les sessions de planification archivées comme les tâches annulées dans la colonne **Done**, à l&#39;extrême droite du tableau des tâches, aux côtés des tâches terminées.
