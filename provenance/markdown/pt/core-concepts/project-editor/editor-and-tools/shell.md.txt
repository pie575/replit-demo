# Shell

> Saiba como usar o Shell para executar comandos no Editor de Projetos.

O Shell permite que você realize tarefas no sistema operacional dentro do Editor de Projetos, como gerenciar arquivos,
instalar pacotes e executar scripts. Ele fornece uma interface poderosa baseada em texto para
interagir com seu ambiente Replit.

Você pode usar o Shell para executar as seguintes tarefas no Editor de Projetos:

* Executar scripts e programas
* Instalar e executar ferramentas e pacotes populares do Linux
* Fazer upload e download de arquivos da internet
* Gerenciar arquivos e diretórios do projeto

<Tip>
  Para um melhor gerenciamento de workflow, prefira o botão **Executar** em vez de iniciar seu app pelo
  Shell. O workflow iniciado pelo botão **Executar** envia a saída para a ferramenta Console,
  que fornece uma maneira estruturada de revisar os logs.
</Tip>

## Recursos

O Shell fornece as seguintes funcionalidades:

* **Executar múltiplos shells**: Abrir várias instâncias do shell para trabalhar em diferentes tarefas simultaneamente
* **Pesquisar por texto**: Encontrar texto específico na saída do shell

### Pesquisa de texto

As etapas a seguir descrevem como acessar e usar a ferramenta de pesquisa de texto:

1. Selecione a <img class="icon-svg" src="https://mintcdn.com/replit/X_IP1EeHGm0cA2VA/images/icons/workspace-search-icon.svg?fit=max&auto=format&n=X_IP1EeHGm0cA2VA&q=85&s=d3feed840da2d19e1ee4873d137114dc" alt="ícone de lupa" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> lupa no canto superior direito da aba Shell para abrir o diálogo de pesquisa.
2. Insira um termo de pesquisa e selecione **Próximo** para navegar pelas correspondências.
3. Use **Anterior** para voltar às correspondências anteriores.
4. Selecione **Sair** ou clique fora do diálogo para encerrar a pesquisa de texto.

### Múltiplos shells

Para criar um novo shell, selecione o menu na parte superior esquerda da aba **Shell** e selecione **Novo Shell** conforme mostrado abaixo:

<Frame>
  <img src="https://mintcdn.com/replit/gspzAm1mbsd1biBe/images/workspace/shell-new.png?fit=max&auto=format&n=gspzAm1mbsd1biBe&q=85&s=3c9d01cf27b611a8195ba61e4fa6ec63" alt="Seleção do menu Novo Shell" width="1280" height="224" data-path="images/workspace/shell-new.png" />
</Frame>

Use o mesmo menu para alternar entre shells. O Editor de Projetos rotula cada shell com o último comando executado para ajudá-lo a identificá-los.

<Warning>
  Quando você abre mais de um shell, o Replit fecha automaticamente as instâncias de shell ociosas.
  Um shell ocioso é aquele que não está selecionado e não está executando nenhum processo do usuário.
</Warning>
