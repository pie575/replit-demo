<div id="roteamento-inteligente-de-modelos">
  ### Интеллектуальная маршрутизация моделей
</div>

Интеллектуальная маршрутизация моделей автоматически подбирает оптимальную модель и уровень усилий для вашей задачи, соблюдая баланс между качеством и стоимостью. В режиме **Power** или **Max** выберите **Auto**, и Replit сам будет направлять каждую часть работы по мере изменения её сложности. Если нужен более полный контроль, можно выбрать конкретную модель и уровень усилий вручную.

<div id="roteamento-inteligente-de-modelos-para-enterprise">
  ### Интеллектуальная маршрутизация моделей для Enterprise
</div>

Интеллектуальная маршрутизация моделей теперь используется в Agent по умолчанию в Workspace уровня Enterprise. При включённом режиме **Auto** Replit сам подбирает оптимальный режим и одну из разрешённых моделей для каждой задачи. Администраторы аккаунта могут управлять доступностью моделей в каждом Workspace, а вы можете отключить режим **Auto** и выбрать нужную модель из доступных. В меню режимов Agent для Enterprise теперь доступны **Power** и **Max**, а режима **Lite** больше нет.
