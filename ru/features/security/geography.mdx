Выберите, где размещается инфраструктура вашего workspace и опубликованных приложений, чтобы обеспечить резидентность данных и снизить задержки. В Replit предусмотрены отдельные настройки географии, поэтому расположением среды разработки и опубликованных приложений можно управлять независимо друг от друга.

<div id="compare-workspace-and-publishing-geography">
  ## Сравнение географии workspace и публикации
</div>

| Аспект                    | География workspace                         | География публикации                                  |
| :------------------------ | :------------------------------------------ | :---------------------------------------------------- |
| **Что определяет**        | Ресурсы разработки в workspace              | Вычисления и хранилище для опубликованного приложения |
| **Когда задаётся**        | При создании workspace                      | При публикации проекта                                |
| **Результат для региона** | Задаёт регион для новых проектов и ресурсов | Размещает опубликованные артефакты в одном регионе    |
| **Можно изменить позже**  | Нет                                         | Нет                                                   |

География workspace и география публикации не обязаны совпадать.

Подробнее о выборе региона разработки при создании Workspace см. в разделе [География workspace](/ru/features/collaboration/workspace-geography).

<div id="publishing-geography">
  ## География публикации
</div>

Указывайте географию публикации при публикации проекта. По умолчанию Replit рекомендует ближайший к вам регион. Это помогает снизить задержки для посетителей вашего приложения и соблюсти требования к резидентности данных.

Когда вы выбираете географию, все публикуемые артефакты проекта (например, вычислительные ресурсы, база данных и Object Storage) автоматически размещаются в одном регионе. Кроме того, задержки для посетителей приложения снижает прокси, привязанный к выбранной географии.

<div id="select-a-publishing-geography">
  ### Выбор географии публикации
</div>

Чтобы выбрать географию, отличную от рекомендованной:

<Steps>
  <Step>
    Откройте инструмент **Publishing** в своём проекте Replit.
  </Step>

  <Step>
    Разверните раздел настроек **Дополнительно**.
  </Step>

  <Step>
    Выберите нужную географию в выпадающем списке **Geography**.
  </Step>

  <Step>
    Нажмите **Publish**, чтобы опубликовать проект в выбранной географии.
  </Step>
</Steps>

<div id="enforce-a-geography-on-published-projects">
  ### Обязательная география для публикуемых проектов
</div>

Администраторы Enterprise могут задать обязательную географию публикации для всех проектов организации. Если такая политика задана, все разработчики организации публикуют проекты в выбранной географии. Политика распространяется только на проекты, которые ещё не были опубликованы, — проекты, уже опубликованные в другой географии, не затрагиваются.

<Note>
  Обязательная география публикации — функция Enterprise. Подробнее о планах Enterprise см. в разделе [Цены](https://replit.com/pricing/).
</Note>

<Steps>
  <Step>
    Перейдите в **Настройки аккаунта**.
  </Step>

  <Step>
    Выберите **Дополнительно**.
  </Step>

  <Step>
    Выберите географию, которую должны использовать все проекты, публикуемые впервые.
  </Step>
</Steps>

<div id="publishing-geography-limitations">
  ### Ограничения географии Publishing
</div>

Прежде чем выбрать географию публикации, учтите следующие ограничения:

* **После публикации географию изменить нельзя.** Как только вы опубликуете свой проект в определённой географии, этот выбор станет окончательным. Перенести опубликованный проект в другую географию невозможно.
* **Расположение при разработке и при публикации может различаться.** Такие ресурсы, как Object Storage, могут быть созданы до публикации и не совпадать с географией публикации.

<div id="available-geographies">
  ## Доступные регионы
</div>

Для workspace и публикации доступны разные наборы регионов:

| Регион               | Выбор для workspace | Выбор для публикации |
| :------------------- | :------------------ | :------------------- |
| **Северная Америка** | Да                  | Да                   |
| **Европа (ЕС)**      | Да                  | Да                   |
| **Азия**             | Да                  | Да                   |
| **Южная Америка**    | Нет                 | Да                   |
| **Австралия**        | Нет                 | Да                   |

<Note>
  Выбор региона для workspace доступен только клиентам с планом Pro.
  Выбор региона для публикации доступен клиентам с планами Core, Pro и Enterprise.
  Пользователи бесплатного плана по умолчанию публикуют приложения в Северной Америке.
</Note>
