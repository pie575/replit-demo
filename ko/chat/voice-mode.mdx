Voice Mode로 만들고 싶은 것을 말로 설명해 보세요. Agent chat box에서 마이크를 탭하고 프롬프트를 말하면 Replit이 음성을 편집 가능한 텍스트로 옮겨 줍니다. 텍스트를 확인하고 필요한 부분을 수정한 뒤, 여느 메시지처럼 전송하세요.

Voice Mode는 타이핑이 느리거나 번거로울 때 유용합니다. 특히 모바일에서는 긴 프롬프트를 엄지로 입력하는 것보다 말하는 편이 더 빠른 경우가 많습니다.

<Note>
  Voice Mode는 음성을 chat box의 텍스트로 옮겨 주는 기능입니다. Agent의 응답을
  소리 내어 읽어 주지는 않으며, 메시지는 그대로 텍스트로 전송되고 Agent도 평소처럼
  chat에서 답변합니다.
</Note>

  ## 작동 방식
</div>

Voice Mode는 음성을 녹음해 텍스트로 변환한 뒤, 그 결과를 chat box에 입력해 보내기 전에 검토할 수 있도록 합니다.

1. Agent를 열고 chat box에서 마이크를 선택합니다.
2. 브라우저나 기기에서 요청하면 마이크 접근을 허용합니다.
3. 프롬프트를 말합니다. 파형이 표시되어 Agent가 녹음 중임을 알려줍니다.
4. 다 말했으면 녹음을 중지합니다. 잠시 말을 멈추거나 다른 tab으로 전환해도 녹음이 자동으로 중지됩니다.
5. 음성이 텍스트로 변환되는 동안 잠시 기다립니다.
6. transcribed text를 검토하고 필요하면 수정한 다음 메시지를 보냅니다.

변환된 텍스트가 chat box에 일반 텍스트로 표시되므로 음성과 타이핑을 자유롭게 섞어 쓸 수 있습니다. 프롬프트의 일부를 말한 뒤 나머지를 입력하거나, 보내기 전에 단어를 고칠 수도 있습니다.

<Tip>
  자연스럽게 말하세요. Voice Mode는 모든 단어를 그대로 옮기기보다 의도를 담아내는 데
  중점을 두므로, &quot;음&quot;, &quot;어&quot; 같은 군말은 결과에서 제외됩니다.
</Tip>

<div id="where-you-can-use-it">
  ## 사용 가능한 위치
</div>

Voice Mode는 Agent chat box에서 사용할 수 있습니다.

* 앱 작업 중 Agent를 사용할 때 **Project Editor**에서
* 홈 화면의 Agent 프롬프트에서 **새 앱을 시작할 때**

Voice Mode는 데스크톱 웹, 모바일 웹, Replit mobile app에서 사용할 수 있습니다.

<div id="good-to-know">
  ## 알아두면 좋은 점
</div>

Voice Mode를 사용할 때 다음 사항을 염두에 두세요.

| 항목        | 알아둘 내용                                                                                   |
| --------- | ---------------------------------------------------------------------------------------- |
| 녹음 길이     | 한 번에 최대 6분까지 녹음할 수 있습니다. 제한 시간에 도달하기 직전에 경고가 표시됩니다.                                      |
| 자동 중지     | 약 30초 동안 소리가 없거나, 탭을 전환하거나 앱을 백그라운드로 전환하면 녹음이 자동으로 중지됩니다.                                |
| 전송 전 검토   | 변환된 텍스트가 chat box에 표시되므로 전송하기 전에 읽고 수정할 수 있습니다. 자동으로 전송되는 내용은 없습니다.                        |
| 마이크 접근 권한 | Voice Mode를 사용하려면 마이크 사용 권한이 필요합니다. 녹음이 시작되지 않으면 브라우저와 기기에서 Replit의 마이크 접근을 허용했는지 확인하세요. |

<div id="availability">
  ## 사용 가능 여부
</div>

Voice Mode는 모든 Replit plan에서 사용할 수 있습니다. 오디오 녹음을 지원하는 브라우저와 기기에서는 Agent chat box에 마이크가 표시되며, 처음 녹음할 때 마이크 권한을 요청하는 메시지가 표시됩니다.
