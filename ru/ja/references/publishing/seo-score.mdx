Когда вы публикуете веб-приложение в Replit, для его рабочего URL автоматически выполняется SEO-аудит (проверка поисковой оптимизации), а в инструментах Publishing отображается SEO-оценка от 0 до 100. Если оценку есть куда улучшать, достаточно нажать одну кнопку, чтобы передать конкретные проблемы Agent и исправить их за считаные секунды.

Для большинства пользователей весь процесс выглядит так: опубликовать приложение, посмотреть оценку и попросить Agent «оптимизировать SEO». На этой странице рассказывается, что происходит «под капотом» и как использовать эту возможность по максимуму.

<div id="seo">
  ## Что такое SEO и почему это важно
</div>

SEO (поисковая оптимизация) — это подход к созданию сайта, при котором поисковым системам вроде Google проще его найти. Если SEO проработано, ваше приложение показывается выше в результатах по релевантным запросам — и без затрат на рекламу.

Сильнее всего на результаты SEO влияют понятные заголовки и описания страниц, семантическая HTML-разметка, быстрая загрузка, адаптивный под мобильные устройства макет, содержательный alt-текст для изображений и структура сайта, доступная для сканирования. Поисковые системы ценят сайты, которые удобно читать и людям, и машинам.

Если вы запускаете лендинг, маркетинговый сайт, блог, каталог или что-то ещё, что должно легко находиться, SEO — одно из самых эффективных вложений на раннем этапе.

<div id="replitseo">
  ## Как Replit закладывает основы SEO
</div>

Replit берёт на себя большую часть базовой SEO-работы, чтобы вы могли сосредоточиться на контенте и продукте:

* **Быстрый и глобально распределённый хостинг**: развёртывания Replit обслуживают приложение на инфраструктуре, оптимизированной под скорость, а [Регионы публикации](/ru/ja/features/publishing/publishing-geography) позволяют выбрать, где именно будет работать приложение.
* **HTTPS по умолчанию**: для каждого опубликованного приложения Replit автоматически применяет управляемые TLS-сертификаты — это базовый сигнал ранжирования для поисковых систем.
* **Пользовательские домены**: подключите собственный домен, чтобы укрепить доверие и авторитет бренда. См. раздел [Пользовательские домены](/ru/ja/features/publishing/custom-domains).
* **Статические развёртывания для контентных сайтов**: для маркетинговых страниц, блогов и документации [статические развёртывания](/ru/ja/features/publishing/static-deployments) отдают предварительно отрендеренный HTML, который поисковым системам легко сканировать.
* **Agent генерирует код с учётом SEO**: создавая страницы, Agent по умолчанию формирует семантический HTML, доступную разметку и метатеги — именно то, что проверяют SEO-инструменты.
* **Функция SEO-оценки**: автоматический аудит после публикации в любой момент показывает текущее состояние, а найденные проблемы можно передать Agent в один клик.

<div id="seo-2">
  ## SEO-оценка
</div>

После каждой успешной публикации Replit запускает аудит Lighthouse для URL-адреса развёртывания и сохраняет результаты. В инструменте Publishing отображается общая SEO-оценка вашего приложения.

<div id="section">
  ### Как посмотреть
</div>

В опубликованном приложении откройте инструмент **Publishing**. SEO-оценка отображается в сводке о развёртывании рядом с остальными сведениями о сборке. Наведите курсор на оценку, чтобы увидеть конкретные рекомендации, которые Lighthouse отметил для каждой страницы.

<div id="section-2">
  ### Как читать оценку
</div>

Replit использует стандартные пороговые значения Lighthouse:

| Оценка | Статус            | Значение                                                                                    |
| :----- | :---------------- | :------------------------------------------------------------------------------------------ |
| 90–100 | Хорошо            | Рекомендации по SEO соблюдены. Продолжайте следить за показателями после крупных изменений. |
| 50–89  | Требует улучшения | Некоторые проблемы мешают поисковым системам разобраться в вашем приложении.                |
| 0–49   | Плохо             | Отсутствуют важные основы SEO. Исправление обычно занимает несколько минут.                 |

Если в приложении несколько страниц, значок показывает **самую низкую** оценку среди всех URL-адресов, просканированных Replit. Так самая проблемная страница видна сразу и не теряется в среднем значении.

<div id="section-3">
  ### Когда рассчитывается оценка
</div>

Аудит выполняется автоматически после каждой успешной публикации. Расчёт оценки обычно занимает 1–2 минуты с момента публикации развёртывания, и, как только результаты готовы, бейдж в инструменте Publishing обновляется.

<div id="section-4">
  ### Поддерживаемые типы развёртываний
</div>

SEO-оценка рассчитывается для публичных веб-развёртываний, URL которых доступны для сканирования поисковыми системами:

* [Автомасштабируемые развёртывания](/ru/ja/features/publishing/autoscale-deployments)
* [Развёртывания Reserved VM](/ru/ja/features/publishing/reserved-vm-deployments)
* [Статические развёртывания](/ru/ja/features/publishing/static-deployments)

Для запланированных и приватных развёртываний SEO-оценка не рассчитывается, так как они не обслуживают публичный веб-трафик.

<div id="agentseo">
  ## Оптимизация SEO с помощью Agent
</div>

Если SEO-оценка ниже 90, рядом с ней появится кнопка **Optimize SEO with Agent**. При нажатии на неё конкретные рекомендации по всем URL, проверенным Lighthouse, вместе с указаниями по исправлению отправляются прямо в новый чат с Agent.

<Tip>
  Кнопкой можно и не пользоваться. Просто откройте Agent и скажите **«Оптимизируй SEO»** — Agent сам получит последние результаты Lighthouse и приступит к работе.
</Tip>

После того как Agent внесёт изменения, опубликуйте приложение заново. SEO-оценка будет пересчитана для новой сборки, а значок обновится автоматически.

Типичные исправления, которые вносит Agent:

* Добавление и переписывание отсутствующих или шаблонных тегов `<title>`, чтобы у каждой страницы был уникальный описательный заголовок
* Добавление метаописаний на все страницы
* Добавление описательного текста `alt` к изображениям
* Установка атрибута `lang` для элемента `<html>`
* Осмысленный текст ссылок (без «нажмите здесь» и пустых якорей)
* Добавление `robots.txt` и `sitemap.xml`
* Добавление метатега viewport для корректного отображения на мобильных устройствах
* Улучшение цветового контраста текста, не прошедшего проверку доступности
* Добавление метатегов Open Graph и Twitter Card для более качественного предпросмотра ссылок в соцсетях

<div id="replit-seo">
  ## Лучшие практики создания SEO-оптимизированных сайтов на Replit
</div>

Независимо от того, поручаете ли вы работу Agent или пишете код сами, вот что даёт наибольший эффект для приложений, созданных на Replit:

* **Задайте уникальный заголовок и мета-описание для каждой страницы.** Ориентируйтесь на длину заголовка до 60 символов, а описания — примерно 150–160 символов.
* **Используйте семантический HTML.** Оборачивайте разметку в `<main>`, `<header>`, `<nav>`, `<footer>`. Используйте `<h1>` один раз на странице и выстраивайте уровни заголовков по порядку.
* **Добавляйте alt-текст ко всем изображениям.** Описывайте не только то, что изображено, но и то, что изображение показывает.
* **Создайте `sitemap.xml` и `robots.txt`.** Попросите Agent сформировать оба файла, чтобы поисковые системы понимали, что нужно сканировать.
* **Добавьте теги Open Graph и Twitter Card.** Так вы контролируете, как ваше приложение выглядит при публикации в соцсетях.
* **Используйте пользовательский домен.** Пользовательский домен повышает доверие и у посетителей, и у поисковых систем. См. [Пользовательские домены](/ru/ja/features/publishing/custom-domains).
* **Выберите подходящий тип развёртывания.** Для сайтов с большим объёмом контента [статическое развёртывание](/ru/ja/features/publishing/static-deployments) отдаёт предварительно отрендеренный HTML, который поисковые системы разбирают мгновенно.
* **Добавьте структурированные данные.** Разметка JSON-LD помогает поисковым системам показывать расширенные результаты для товаров, статей, FAQ и событий.
* **Следите за скоростью приложения.** Оптимизируйте изображения, избегайте скриптов, блокирующих рендеринг, и используйте хостинг Replit, чтобы время отклика оставалось低 минимальным.

Простой способ применить большинство из этих рекомендаций сразу:

<AiPrompt>
  Audit my site for SEO best practices and apply the fixes. Add a sitemap, robots.txt, Open Graph tags, structured data where it makes sense, and make sure every page has a unique title and meta description.
</AiPrompt>
