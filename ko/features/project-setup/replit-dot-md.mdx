<div id="how-replitmd-works">
  ## `replit.md` 작동 방식
</div>

Agent는 검증된 모범 사례를 바탕으로 프로젝트의 루트 디렉터리에 `replit.md` 파일을 먼저 생성합니다. 이 파일에는 다음 내용이 담깁니다.

* 기본 프로젝트 정보
* 권장 코딩 패턴
* 프로젝트 유형에 맞는 일반적인 기본 설정

<YouTubeEmbed videoId="kYv525W-vaU" title="Replit Agent의 응답 방식 사용자 지정하기" />

Agent는 요청을 처리할 때 `replit.md` 파일을 자동으로 읽고, 그 내용을 다음과 같이 활용합니다.

* 프로젝트의 아키텍처와 규칙 파악
* 선호하는 코딩 패턴과 스타일 준수
* 지정한 패키지 관리자와 종속성 사용

또한 Agent는 프로젝트를 더 깊이 파악하고 애플리케이션을 변경해 나가면서 `replit.md` 파일을 직접 업데이트하기도 합니다.

<Note>`replit.md` 파일을 편집하여 Agent의 동작을 사용자 지정할 수 있습니다.</Note>

<div id="setting-up-replitmd">
  ## `replit.md` 설정하기
</div>

<div id="automatic-generation">
  ### 자동 생성
</div>

Agent로 새 project를 만들면 검증된 모범 사례를 바탕으로 `replit.md` 파일이 자동으로 생성됩니다. 이 파일은 project의 루트 디렉터리에 생성되며, 다음 내용이 포함됩니다.

* 기본 project 정보
* 권장 코딩 패턴
* 해당 project 유형에서 일반적으로 사용하는 기본 설정

<div id="manual-creation">
  ### 직접 생성하기
</div>

프로젝트의 루트 디렉터리에 `replit.md`라는 이름의 새 파일을 추가하면 `replit.md` 파일을 직접 만들 수 있습니다. Agent는 이후 대화에서 이 파일을 자동으로 감지해 사용합니다.

<Note>
  `replit.md`가 제대로 작동하려면 프로젝트의 루트 디렉터리에 있어야 합니다.
</Note>

<div id="regenerating-replitmd">
  ### `replit.md` 다시 생성하기
</div>

`replit.md` 파일이 손상되었거나 처음부터 새로 만들고 싶다면 다음 단계를 따르세요.

1. 프로젝트 루트에서 기존 `replit.md` 파일을 삭제합니다
2. Agent와 새 대화를 시작합니다
3. Agent가 현재 프로젝트를 기반으로 새 `replit.md` 파일을 자동으로 생성합니다

```markdown theme={null}
## 리서치 기본 설정

- 업데이트를 제안하기 전에 항상 의존성의 최신 버전을 확인할 것
- 보안 구현에 관한 최신 모범 사례를 조사할 것
- 우리 기술 스택에 맞는 최신 성능 최적화 기법을 찾아볼 것
```

**외부 지식을 어떻게 활용할지 Agent에게 안내하세요:**

```markdown theme={null}
## 외부 리서치 가이드라인

- 새 라이브러리를 제안할 때는 기존 stack과 호환되는지 확인하세요
- 외부 예제는 우리 코딩 표준와 project 구조에 맞게 수정하세요
- 제안한 해결책이 우리 Publishing 환경에서 동작하는지 검증하세요
```

<div id="limitations">
  ## 제한 사항
</div>

<div id="file-size-and-content-limits">
  ### 파일 크기 및 콘텐츠 제한
</div>

`replit.md`에는 엄격한 문자 수 제한이 없지만, 파일이 지나치게 크면 내용 전체가 처리되지 않을 수 있습니다. 최상의 결과를 얻으려면 `replit.md`에 핵심 내용만 담아 간결하게 유지하세요.

<div id="root-directory-requirement">
  ### 루트 디렉터리 요구사항
</div>

`replit.md` 파일은 프로젝트의 루트 디렉터리에 있어야 합니다. Agent는 하위 디렉터리에 있는 파일을 자동으로 감지하지 않습니다.

<div id="context-scope">
  ### Context 범위
</div>

`replit.md`는 Agent 대화에 context를 제공하지만, 다른 AI 도구에는 자동으로 적용되지 않습니다.
