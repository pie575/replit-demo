В этом справочном руководстве описывается класс `Client` из пакета `replit-object-storage-python` и приводятся примеры кода для его методов.

<div id="client">
  ## Client
</div>

Класс `Client` управляет взаимодействием с Replit App Storage. Он предоставляет методы для работы с объектами в бакете.

Чтобы импортировать класс из пакета `replit.object_storage`, добавьте в код на Python следующую строку:

```python theme={null}
from replit.object_storage import Client
```

С помощью следующего кода создайте экземпляр `Client` для взаимодействия с Replit App Storage:

```python theme={null}
client = Client()
```

<Tip>
  Если ваше приложение использует несколько бакетов, создайте отдельный экземпляр `Client` для каждого из них.
</Tip>

<div id="__init__">
  ### **init**
</div>

Метод `init` инициализирует экземпляр класса Client.

```python theme={null}
def __init__(bucket_id: Optional[str] = None)
```

**Аргументы**:

* `bucket_id` (Optional[str]): идентификатор бакета, которым управляет клиент. Если параметр не указан, Client использует бакет по умолчанию, связанный с Replit App или деплойментом.

<div id="copy">
  ### copy
</div>

Метод `copy` копирует объект в пределах одного бакета. Если объект по целевому пути уже существует, он будет перезаписан.

```python theme={null}
def copy(object_name: str, dest_object_name: str) -> None
```

**Аргументы**:

* `object_name` (str) — полный путь к исходному объекту.
* `dest_object_name` (str) — полный путь, по которому будет скопирован объект.

**Исключения**:

* `ObjectNotFoundError` — указывает, что исходного объекта по заданному пути не существует.

<div id="delete">
  ### delete
</div>

Метод `delete` безвозвратно удаляет файл из App Storage.

```python theme={null}
def delete(object_name: str, ignore_not_found: bool = False) -> None
```

**Аргументы**:

* `object_name` (str) — имя удаляемого объекта.
* `ignore_not_found` (bool) — если `True`, подавляет ошибку в случае, когда объект не существует.

**Исключения**:

* `ObjectNotFoundError` — указывает, что объект не существует.

<div id="download_as_bytes">
  ### download_as_bytes
</div>

Метод `download_as_bytes` возвращает содержимое файла в виде `bytes`.

```python theme={null}
def download_as_bytes(object_name: str) -> bytes
```

**Аргументы**:

* `object_name` (str) — имя загружаемого объекта.

**Возвращаемое значение**:

* `bytes` — содержимое объекта в виде «сырых» байтов.

**Исключения**:

* `ObjectNotFoundError` — объект не существует.

<div id="download_as_text">
  ### download_as_text
</div>

Метод `download_as_text` загружает содержимое файла как значение типа `str`.

```python theme={null}
def download_as_text(object_name: str) -> str
```

**Аргументы**:

* `object_name` (str) — имя исходного объекта, который нужно получить.

**Возвращаемое значение**:

* str: содержимое объекта в виде строки в кодировке UTF-8.

**Исключения**:

* `ObjectNotFoundError` — объект не существует.

<div id="download_to_filename">
  ### download_to_filename
</div>

Загружает содержимое объекта в файл на локальном диске.

```python theme={null}
def download_to_filename(object_name: str, dest_filename: str) -> None
```

**Аргументы**:

* `object_name` (str) — имя исходного объекта, загружаемого из App Storage.
* `dest_filename` (str) — имя файла на локальном диске, в который будет сохранён объект.

**Исключения**:

* `ObjectNotFoundError` — объект не существует.

<div id="exists">
  ### exists
</div>

Метод `exists` проверяет, существует ли объект.

```python theme={null}
def exists(object_name: str) -> bool
```

**Аргументы**:

* `object_name` (str) — имя объекта, существование которого нужно проверить.

**Возвращаемое значение**:

* `bool`: `True`, если объект существует, и `False` в противном случае.

<div id="list">
  ### list
</div>

Метод `list` возвращает список объектов в бакете.

```python theme={null}
def list(end_offset: Optional[str] = None,
         match_glob: Optional[str] = None,
         max_results: Optional[int] = None,
         prefix: Optional[str] = None,
         start_offset: Optional[str] = None) -> List[Object]
```

**Аргументы**:

* `end_offset` (Optional[str]) — оставляет в результатах только объекты, имена которых лексикографически предшествуют `end_offset`. Если задан `start_offset`, имена перечисляемых объектов будут находиться в диапазоне от `start_offset` (включительно) до `end_offset` (не включая).
* `match_glob` (Optional[str]) — glob-шаблон для фильтрации результатов. Например: &quot;foo*bar&quot; соответствует &quot;footbar&quot;, &quot;foo baz bar&quot; и &quot;foobar&quot;.
* `max_results` (Optional[int]) — максимальное количество результатов, возвращаемых в ответе.
* `prefix` (Optional[str]) — оставляет в результатах только объекты, имена которых начинаются с указанного префикса.
* `start_offset` (Optional[str]) — оставляет в результатах только объекты, имена которых лексикографически равны `start_offset` или следуют за ним. Если задан `end_offset`, имена перечисляемых объектов будут находиться в диапазоне от `start_offset` (включительно) до `end_offset` (не включая).

**Возвращаемое значение**:

* `List`(Object): список объектов, соответствующих заданным параметрам запроса.

<div id="upload_from_filename">
  ### upload_from_filename
</div>

Используйте `upload_from_filename()`, чтобы загрузить объект в App Storage из исходного файла на локальном диске.

**Аргументы**:

* `src_filename` (str) — исходный файл для загрузки.

<div id="section">
  ### Типы исключений
</div>

* При использовании `Client` для работы с Replit App Storage может быть возвращена одна из следующих ошибок:

  * `BucketNotFoundError`: заданное имя бакета не соответствует ни одному бакету в App Storage.

  * `DefaultBucketError`: не задан бакет по умолчанию.

  * `ForbiddenError`: недостаточно прав доступа к бакету.

  * `TooManyRequestsError`: операция ограничена по частоте из-за слишком большого количества запросов.

  * `UnauthorizedError`: доступ к операции ограничен аутентификацией.
