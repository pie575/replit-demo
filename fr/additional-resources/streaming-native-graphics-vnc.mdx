Cette technologie de diffusion vous permet d&#39;utiliser des applications anciennes dans votre navigateur, depuis n&#39;importe quel appareil ! Vous pouvez par exemple exécuter un jeu Python conçu pour ordinateur directement sur votre téléphone ou votre tablette, sans modifier le code sous-jacent.

<div id="how-can-i-use-vnc">
  ## Comment utiliser le VNC ?
</div>

Toute Replit App – quel que soit le langage – peut utiliser un bureau virtuel. Aucune modification n&#39;est nécessaire pour exécuter des programmes graphiques natifs sur Replit. Le panneau VNC apparaît dès qu&#39;une application tente d&#39;ouvrir une fenêtre de bureau native.

<div id="securing-your-replit-app">
  ## Sécuriser votre Replit App
</div>

Par défaut, votre connexion VNC n&#39;a pas de mot de passe et n&#39;est accessible que depuis [https://replit.com](https://replit.com), car elle repose sur la même authentification que celle utilisée pour le WebSocket. Si vous devez accéder à votre Replit App via le client externe [noVNC](https://novnc.com), vous pouvez définir un mot de passe VNC.

Définissez un mot de passe dans la configuration des [secrets](/fr/core-concepts/project-editor/app-setup/secrets) de votre Replit App. `Secrets` est un espace sécurisé où stocker vos mots de passe sans craindre que d&#39;autres utilisateurs y accèdent. Définir `VNC_PASSWORD` renforce la sécurité lors des connexions à distance.

<div id="how-can-i-use-fullscreen-vnc">
  ## Comment utiliser le VNC en plein écran ?
</div>

Vous devez avoir sécurisé votre Replit App comme indiqué ci-dessus avant de suivre ces étapes.

1. Exécutez la commande suivante dans l&#39;onglet « Shell » :
   ```sh theme={null}
   echo $REPL_ID
   ```

<Frame>
  <img src="/assets/mirror/replid-6508492b1e8b.png" alt="image montrant la commande echo" width="628" height="174" data-path="images/vnc/replid.png" />
</Frame>

2. Construisez votre URL de connexion en remplaçant `REPL_ID` par le résultat obtenu ci-dessus : `<\REPL_ID\>.id.repl.co`
3. Ouvrez le [client noVNC](https://novnc.com/noVNC/vnc.html) dans un autre onglet de navigateur.
4. Ouvrez les paramètres de connexion.

<Frame>
  <img src="/assets/mirror/settings-3e0e0c4fd198.png" alt="ouvrir les paramètres de connexion" width="126" height="302" data-path="images/vnc/settings.png" />
</Frame>

5. Développez le champ WebSockets. Saisissez votre URL de connexion (`\<REPL_ID\>.id.repl.co`) dans le champ `host` et laissez le champ `path` vide.

<Frame>
  <img src="/assets/mirror/host-31b5c99194b2.png" alt="host" width="214" height="230" data-path="images/vnc/host.png" />
</Frame>

6. Remplacez le `Scaling Mode` par `Remote Resizing` :

<Frame>
  <img src="/assets/mirror/scaling-0ffe9aae34bb.png" alt="mise à l'échelle" width="147" height="74" data-path="images/vnc/scaling.png" />
</Frame>

7. Lorsque les identifiants vous sont demandés, utilisez le nom d&#39;utilisateur `runner` et le mot de passe configuré ci-dessus.
