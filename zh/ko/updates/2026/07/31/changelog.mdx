<div id="agent">
  ## Agent
</div>

<div id="agent-2">
  ### 选择 Agent 的默认模型
</div>

现在你可以为任务选择 Agent 使用的默认模型。先在 Lite、Economy、Power 之间选择，再挑选该模式下可用的模型。Lite 现已覆盖所有可以使用 Agent 的场景，包括移动应用。可用模型取决于你所在的组织、权限以及是否拥有 Turbo 访问权限。

<Frame caption="截取自 Replit Design，相同的控件也会出现在 Agent 设置下拉菜单中。">
  <img src="/assets/mirror/agent-model-selector-873f18bc6147.png" width="1432" height="786" data-path="images/changelog/2026-07-31/agent-model-selector.png" />
</Frame>

有关详细信息，请参阅[模型选择器](/zh/ko/features/agent/model-selector)。

<div id="mcp">
  ### 连接更多 MCP 服务器
</div>

符合条件的工作区可从预注册的 MCP 服务器目录中连接 Supabase、Statsig 和 Calendly。此外，Replit 可识别官方 Braintrust MCP 端点，手动添加后会启动该服务器的 OAuth 登录流程。

<Frame>
  <img src="/assets/mirror/integrations-4cb26ed8a654.png" alt="列出 GitHub、GitLab、AWS、Calendly 等连接器的集成设置页面" width="3124" height="1636" data-path="images/changelog/2026-07-31/integrations.png" />
</Frame>

详情请参阅 [MCP 服务器](/zh/ko/features/mcp/overview)。

<div id="teams-and-enterprise">
  ## Teams 和 Enterprise
</div>

<div id="section-3">
  ### 延长登录保持时间
</div>

现在，Replit 会话可以保持更长时间，无需频繁重新登录。企业版管理员可以配置会话超时预设值。
