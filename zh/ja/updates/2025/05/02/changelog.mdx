<div id="replit-auth">
  ### Replit Auth
</div>

[Replit Auth](/zh/ja/features/auth-and-identity/authentication) 现已向所有用户开放！这是一套内置的身份验证系统，只需极少的设置即可为应用添加用户登录功能。无需从零搭建复杂的身份验证系统，Replit Auth 提供与基础设施深度集成、安全且开箱即用的方案。

**主要功能：**

* **零配置** —— 在 Agent 中输入一条 prompt 即可添加身份验证
* **内置安全防护** —— 依托 Replit 基础设施，抵御常见攻击
* **用户管理** —— 通过 Auth 面板轻松管理用户
* **数据库集成** —— 自动将用户记录写入数据库
* **可自定义登录页** —— 打造个性化的应用登录体验
* **密码重置** —— 由 Replit 负责发送密码重置邮件，无需自备邮件发送服务商

上手非常简单——只需在 Agent 的 prompt 中提出使用 Replit Auth 的需求即可：

<AiPrompt>
  Help me create an app that [your app idea] and should feature Replit Auth.
</AiPrompt>
