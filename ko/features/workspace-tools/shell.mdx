Shell을 사용하면 일반적인 터미널처럼 project에서 파일을 관리하고 packages를 설치하며
스크립트를 실행할 수 있습니다. 예를 들어 project 파일을 둘러보거나, project에
database 연결이 구성되어 있는 경우 `psql`을 사용할 수 있습니다.

<Tip>
  workflow를 더 효과적으로 관리하려면 Shell에서 앱을 실행하는 대신 **Run** 버튼을
  사용하세요. **Run** 버튼으로 시작한 workflow는 출력을 Console 도구로 보내므로
  logs를 체계적으로 확인할 수 있습니다.
</Tip>

<div id="features">
  ## 기능
</div>

Shell은 다음과 같은 기능을 제공합니다:

* **여러 Shell 실행**: 여러 Shell 인스턴스를 열어 서로 다른 작업을 동시에 처리합니다
* **텍스트 검색**: Shell 출력에서 특정 텍스트를 찾습니다

<div id="confirm-shell-access">
  ### Shell 접근 확인
</div>

Shell이 준비되었는지 확인하고 현재 workspace를 보려면 다음을 실행하세요:

```sh theme={null}
pwd
```

Shell이 현재 workspace의 경로를 출력합니다.

<Frame caption="pwd 명령은 현재 workspace 경로를 출력한 후 Shell 프롬프트로 돌아옵니다.">
  <img src="/assets/mirror/shell-pwd-output-2d31a0e0466b.jpg" alt="pwd 명령, workspace 경로 출력, 다시 표시된 프롬프트가 보이는 Shell 탭" width="1280" height="246" data-path="images/workspace/shell-pwd-output.jpg" />
</Frame>

database가 있는 project라면 **Tools** → **Database**를 선택한 다음
**Development database** 페이지를 엽니다. 이 페이지에서 연결 관련 설정을 관리할 수 있습니다.
연결 값은 비공개로 유지하고, 문서, 스크린샷, logs, 소스 파일, 공유 메시지에
복사하지 마세요.

<div id="text-search">
  ### 텍스트 검색
</div>

다음 단계에 따라 텍스트 검색 도구를 열고 사용할 수 있습니다.

1. Shell 탭 오른쪽 상단의 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="magnifying glass icon" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 돋보기를 선택하여 검색 대화 상자를 엽니다.
2. 검색어를 입력한 후 **Next**를 선택하여 일치하는 항목을 차례로 확인합니다.
3. 이전 일치 항목으로 돌아가려면 **Previous**를 사용합니다.
4. **Exit**를 선택하거나 대화 상자 바깥을 클릭하면 텍스트 검색이 종료됩니다.

<div id="multiple-shells">
  ### 여러 개의 Shell
</div>

Shell을 추가로 만들려면:

1. Shell 패널 헤더에서 Shell 인스턴스 메뉴를 선택합니다.
2. **New Shell**을 선택합니다.

<Frame>
  <img src="/assets/mirror/shell-new-94a280c1230f.png" alt="현재 workspace와 New Shell 옵션이 표시된 Shell 인스턴스 메뉴" width="1280" height="224" data-path="images/workspace/shell-new.png" />
</Frame>

Shell 간 전환도 같은 메뉴에서 할 수 있습니다. Replit은 각 Shell을 쉽게 구분할 수 있도록 마지막으로 실행한 명령을 이름으로 표시합니다.

<Warning>
  Shell을 두 개 이상 열면 Replit이 유휴 상태의 Shell 인스턴스를 자동으로 닫습니다.
  유휴 Shell이란 선택되어 있지 않고 사용자 프로세스도 실행하고 있지 않은 Shell을 의미합니다.
</Warning>
