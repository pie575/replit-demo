## O que você recebe

O plano Starter oferece tudo o que você precisa para começar a criar no Replit. Crie apps e publique seu primeiro projeto — tudo sem custo.

### Créditos diários para o Agent

Usuários do plano Starter recebem créditos diários para uso do Agent, até um limite mensal. Esses créditos são redefinidos diariamente, dando a você uma nova cota para trabalhar com o Agent a cada dia.

### Créditos mensais para uso na nuvem

Você também recebe créditos mensais que podem ser usados para:

* [Bancos de Dados (Produção)](/features/data-and-storage/development-and-production)
* [Armazenamento de objetos](/pt/features/data-and-storage/object-storage)
* [Publicação (Autoescala, estático)](/pt/learn/projects-and-artifacts/replit-deployments)

Esses créditos são redefinidos a cada mês.

### Build Lite

Acesso ao [Build Lite](/pt/features/agent/agent-modes), uma experiência de build rápida e focada para edições rápidas e alterações direcionadas com o Agent.

### Um app publicado gratuito

Obtenha {FreeDeployments} app publicado gratuito, seja usando o Build Lite ou o Design Canvas. Este link publicado expirará automaticamente após 30 dias.

Seu app publicado incluirá um badge "Criado com Replit" que contém seu link de referência exclusivo. Se outro usuário se inscrever com esse link a partir do seu badge, você receberá créditos de referência assim que fizer upgrade para um plano pago.

## Limitações

Os seguintes recursos exigem upgrade para o Core:

### Build completo

O [Build completo](/pt/features/agent/overview/) permite que o Agent trabalhe de forma independente com mais poder e autonomia. Criadores do plano Starter só podem usar o [Build Lite](/pt/features/agent/agent-modes). O Build completo requer Core ou Pro.

### Converter um design em artefato

Converter um design do Design Canvas em um artefato completo requer Core. Criadores do plano Starter podem criar designs e publicá-los, mas converter para um artefato com funcionalidade de backend requer upgrade. Se você quiser criar um app com funcionalidade de backend, experimente começar com o [Build Lite](/pt/features/agent/agent-modes).

### Conectores de terceiros

Conectores externos requerem Core. Isso inclui integrações com serviços como Google, Stripe e outras APIs de terceiros (veja mais informações [aqui](https://docs.replit.com/features/integrations/overview#connectors)).

### Integrações de IA do Replit

As [Integrações de IA do Replit](/pt/features/integrations/replit-ai-integrations) requerem Core.

### Remover o badge "Criado com Replit"

Remover o badge "Criado com Replit" dos seus apps publicados requer Core. Usuários do plano Starter terão o badge exibido nos seus deployments.

### Apps publicados adicionais

Usuários do plano Starter recebem {FreeDeployments} app publicado gratuito. Apps publicados adicionais além deste requerem Core ou Pro.

### Modo de Planejamento

Usar o Modo de Planejamento requer Core. O Modo de Planejamento permite que você explore ideias, planeje trabalhos e colabore com o Replit Agent sem editar o código ou os dados do seu app.

### Todos os tipos de artefato

Criar tipos de artefato diferentes de apps web e mobile requer Core. Escolha entre uma variedade de tipos, incluindo visualizações de dados, apresentações de slides, vídeos animados e mais. Veja [Projetos](/pt/features/projects-and-artifacts/projects).

## Upgrade para Core

Pronto para mais? Faça upgrade para Core para desbloquear:

* **Mais armazenamento e créditos mensais** que também permitem pagamento conforme o uso
* **Apps publicados ilimitados** além do seu primeiro gratuito
* **Build completo** para desenvolvimento autônomo
* **Conectores de terceiros** para conectar com serviços externos
* **Integrações de IA do Replit** para usar modelos de IA sem gerenciar suas próprias chaves de API
* **Modo de Planejamento** para mapear tarefas antes de começar um build
* **Remoção do badge do Replit** para uma aparência profissional
* E muito mais
