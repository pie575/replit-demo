<Note>
  Vous souhaitez rendre le SSO obligatoire pour votre **organisation Replit** (connexion à replit.com) ? Cette configuration est distincte. Consultez [l’authentification unique (SAML SSO)](/fr/ja/teams/identity-and-access-management/saml). Cette page explique comment ajouter le SSO au flux de connexion des **applications que vous créez** sur Replit.
</Note>

Permettez aux utilisateurs de se connecter à votre application à l’aide de fournisseurs d’identité d’entreprise tels qu’Okta ou Microsoft Entra ID. Si votre application utilise [Clerk Auth](/fr/ja/features/auth-and-identity/clerk-auth), configurez le SSO et d’autres fonctionnalités d’authentification avancées dans le tableau de bord Clerk. Indiquez à Agent ce dont vous avez besoin, et Agent vous guidera vers le tableau de bord pour finaliser la configuration.

  <img src="/assets/mirror/sso-cover-28a76bfa16fb.jpeg" alt="Bannière illustrant la création d’applications Replit avec le SSO, avec une icône de clé et un créateur travaillant sur un ordinateur portable." width="1920" height="1080" data-path="images/workspace/auth/sso-cover.jpeg" />
</Frame>

Le tableau de bord Clerk vous permet de configurer bien plus que l’expérience de connexion par défaut. Les paramètres définis dans Clerk sont automatiquement appliqués à l’authentification de votre application Replit.

<div id="section">
  ## Ce que vous pouvez configurer
</div>

* **Connexions SSO d&#39;entreprise** : configurez l&#39;authentification unique avec Okta ou Microsoft Entra ID via OIDC ou SAML. Vos clients peuvent ainsi se connecter avec le fournisseur d&#39;identité interne de leur entreprise. Le SSO contribue également à protéger les outils internes qui manipulent des données sensibles, en remplaçant les listes d&#39;autorisation d&#39;adresses e-mail gérées manuellement par votre fournisseur d&#39;identité interne existant.
* **Authentification multifacteur (MFA)** : ajoutez la MFA au flux de connexion de votre application.
* **Gestion des sessions** : ajustez la durée de vie des sessions et la fréquence de réauthentification.
* **Autres paramètres Clerk** : les autres paramètres Clerk s&#39;appliquent eux aussi automatiquement à votre application Replit. Ne modifiez pas les clés d&#39;API ni la configuration de l&#39;environnement : Replit s&#39;en charge. Pour en savoir plus, consultez [Environnements de développement et de production](/fr/ja/features/auth-and-identity/clerk-auth#development-and-production-environments).

<div id="clerk">
  ## Ouvrir le tableau de bord Clerk
</div>

Indiquez à Agent les modifications d&#39;authentification souhaitées. Agent applique les réglages qu&#39;il peut effectuer lui-même et vous oriente vers le tableau de bord Clerk de votre application pour ceux qui nécessitent votre intervention.

<Frame>
  <img src="/assets/mirror/build-with-sso-agent-workflow-46422788bd18.webp" alt="Agent guidant la configuration du SSO d'entreprise dans le tableau de bord Clerk pour une application utilisant Clerk." width="1602" height="1080" data-path="images/workspace/auth/build-with-sso-agent-workflow.webp" />
</Frame>

Vous pouvez également ouvrir le tableau de bord depuis l&#39;espace de travail.

1. Dans le volet Tools, sélectionnez **Users &amp; Auth**.
2. Sélectionnez l&#39;onglet **Configure**.
3. Sélectionnez **Advanced**.
4. Sous **Clerk dashboard**, sélectionnez **Open Clerk dashboard**.

<Frame>
  <img src="/assets/mirror/open-clerk-dashboard-tools-pane-a314ffea741d.webp" alt="L'outil Users & Auth avec l'onglet Configure ouvert, affichant la section Advanced et le bouton Open Clerk dashboard." width="2158" height="1372" data-path="images/workspace/auth/open-clerk-dashboard-tools-pane.webp" />
</Frame>

<div id="sso">
  ## Configurer une connexion SSO d&#39;entreprise
</div>

1. Dans le tableau de bord Clerk, sélectionnez **Configure**.
2. Sous **User &amp; authentication**, sélectionnez **SSO connections**.
3. Sélectionnez **Enterprise**.
4. Sélectionnez **Add connection**.

<Frame>
  <img src="/assets/mirror/build-with-sso-enterprise-connections-b0a6a27885b5.webp" alt="Tableau de bord Clerk affichant la page Enterprise SSO connections et l'action Add connection." width="1826" height="1080" data-path="images/workspace/auth/build-with-sso-enterprise-connections.webp" />
</Frame>

Pour en savoir plus sur la configuration des connexions, consultez la [documentation de Clerk](https://clerk.com/docs).

<div id="section-2">
  ### Vérifier la connexion
</div>

Une fois la configuration terminée, connectez-vous avec un compte de test de votre fournisseur d&#39;identité. Vérifiez que ce compte accède bien aux parties de l&#39;application auxquelles il est censé avoir accès.

Si la connexion échoue, demandez conseil à Agent. Précisez dans votre demande le fournisseur d&#39;identité, le protocole et le message d&#39;erreur.

<Note>
  Cette page traite du SSO d&#39;entreprise pour le flux de connexion de l&#39;application elle-même. Pour la connexion via les réseaux sociaux avec Google, GitHub, Apple et X (affichés sous le nom **SSO providers** dans l&#39;espace de travail), consultez [Fournisseurs de connexion](/fr/ja/features/auth-and-identity/sign-in-providers). Elle ne couvre ni la migration de Replit Auth ni la connexion SAML aux comptes Replit.
</Note>

<div id="section-3">
  ## Tarifs et plans disponibles
</div>

L&#39;accès au tableau de bord Clerk est disponible avec le plan [Replit Pro](/fr/ja/billing/plans/replit-pro). La prise en charge des plans Enterprise arrive bientôt.

<Info>
  Les connexions SSO d&#39;entreprise sont gratuites jusqu&#39;au 1er octobre 2026. Passé cette date, les tarifs SSO de Clerk sont répercutés tels quels sur votre facturation Replit.
</Info>
