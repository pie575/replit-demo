ChatGPT 中的 Replit 集成让你无需任何配置，即可直接在对话中创建、更新和查看 Replit Apps。只需与 ChatGPT 对话，即可创建真实 App，剩下的交给 Agent。

<div id="o-que-o-replit-no-chatgpt">
  ## 什么是 ChatGPT 中的 Replit
</div>

ChatGPT 中的 Replit 可将您的 ChatGPT 对话连接到强大的 Replit 开发平台。您只需描述想要创建的内容，Agent 就会为您构建一个功能完整的 Replit App。创建完成后，您可以让 ChatGPT 修改、更新或分析您的 App——一切都可通过自然语言对话完成。

<div id="como-comear">
  ## 开始使用
</div>

按照以下步骤将 Replit 连接到 ChatGPT，创建你的第一个 App。

<div id="conectar-o-replit-ao-chatgpt">
  ### 将 Replit 连接到 ChatGPT
</div>

你可以通过两种方式将 Replit 连接到 ChatGPT：

<Accordion title="通过设置连接">
  1. 点击 ChatGPT 中的个人头像图标
  2. 进入**设置** → **应用与连接器**
  3. 找到 **Replit** 并点击**连接**
  4. 使用你的 Replit 账户完成 OAuth 授权
</Accordion>

<Accordion title="在对话中连接">
  1. 在 ChatGPT 中开启一段新对话
  2. 使用下列任一方式调用 Replit
  3. 如果你尚未连接，ChatGPT 会引导你完成 OAuth 授权流程
</Accordion>

<div id="invocar-o-replit-no-chatgpt">
  ### 在 ChatGPT 中调用 Replit
</div>

连接完成后，你可以通过三种方式调用 Replit：

| 方法    | 使用方式                              |
| ----- | --------------------------------- |
| 直接提及  | 在消息开头输入 `Replit, <请求内容>`          |
| 斜杠命令  | 在输入框中输入 `/Replit`                 |
| 输入框菜单 | 点击 **+** 按钮 → **更多** → **Replit** |

<div id="criar-seu-primeiro-app">
  ### 创建你的第一个应用
</div>

连接完成后，创建你的第一个 Replit App：

1. 在 ChatGPT 中开启一段新对话
2. 调用 Replit 并描述你想创建的内容 (例如&quot;Replit, create a todo app with dark mode&quot;)
3. Agent 会生成你的应用并自动完成部署
4. 完成后，你会收到一个链接，可用于查看应用

<Note>
  每段对话只能处理一个 Replit App。如果你在同一段对话中创建新应用，它会修改现有的应用。若要创建多个应用，请分别开启不同的对话。
</Note>

<div id="recursos">
  ## 功能
</div>

* **[Replit AI](/zh/pt/build/welcome)**：Agent 根据你的自然语言请求生成并部署应用
* **[Project Editor](/zh/pt/core-concepts/project-editor)**：可通过 ChatGPT 访问的完整开发环境
* **[部署](/zh/category/replit-deployments)**：应用自动完成部署，随时可分享

<Accordion title="你可以做什么">
  **创建：** 只需描述你想要的内容，即可创建新的 Replit Apps。Agent 会生成应用并自动完成部署。

  **更新：** 在当前对话中修改应用。让 ChatGPT 添加功能、修复缺陷或进行调整，Agent 会应用这些变更。

  **检查：** 在不做任何更改的前提下分析你的应用，了解代码结构、文件路径或运行行为。
</Accordion>

<Accordion title="支持的文件格式">
  你可以在请求中包含多种文件类型：

  | 格式         | 是否支持           |
  | ---------- | -------------- |
  | PDF        | 是              |
  | CSV        | 是              |
  | 常见文档格式     | 是              |
  | 图片 (原始文件)  | 否 (请使用公开 URL)  |
  | 视频 (原始文件)  | 否 (请使用公开 URL)  |

  <Note>
    若要在应用中包含图片或视频，请在请求中提供公开 URL。你也可以在应用创建完成后，直接在 Replit 中添加媒体文件。
  </Note>
</Accordion>

<Accordion title="创建耗时">
  Agent 创建应用的典型耗时如下：

  | 应用复杂度                 | 典型创建耗时 |
  | --------------------- | ------ |
  | 简单 (计算器、小型落地页)        | 2–3 分钟 |
  | 复杂 (游戏、丰富动画、信息密集仪表板)  | 3–4 分钟 |
</Accordion>

<div id="disponibilidade-e-planos">
  ## 可用性与套餐
</div>

<Accordion title="ChatGPT 套餐">
  Replit 集成适用于所有类型的 ChatGPT 套餐：

  | 套餐             | 是否支持 | 备注                                |
  | -------------- | ---- | --------------------------------- |
  | Free           | 是    |                                   |
  | Plus           | 是    |                                   |
  | Pro            | 是    |                                   |
  | Business       | 是    | 需由管理员在 **Workspace 设置 → 连接器** 中启用 |
  | Enterprise/Edu | 是    | 需由管理员在 **Workspace 设置 → 连接器** 中启用 |

  **区域可用性：** 欧盟以外的所有区域。
</Accordion>

<Accordion title="Replit 套餐">
  所有类型的 Replit 套餐均支持 ChatGPT 集成：

  | 套餐             | 是否支持 | 备注                      |
  | -------------- | ---- | ----------------------- |
  | Starter (Free) | 是    | 仅限公开 App                |
  | Core           | 是    | 私有 App、扩展构建、部署、Database |
  | Pro            | 是    | 每月额度更高，包含 Core 的全部功能    |
  | Teams          | 是    | 私有 App、扩展构建、部署、数据库      |
  | Enterprise     | 是    | 可使用全部功能                 |
</Accordion>

<div id="cobrana-e-crditos">
  ## 计费与积分
</div>

Replit 在 ChatGPT 中完成的工作，会作为 Replit Agent 用量计入你的 Replit 账户。

<Accordion title="计费方式">
  * **Core** 和 **Pro** 套餐包含每月积分，在额度内可用于 Agent、部署和数据库
  * 你可以购买**积分包**，有效期六个月，不会自动续订——非常适合发布高峰期或试验性项目
  * 在 Replit 的计费设置中使用**用量限额**和**预算**来控制支出

  详见 [AI 计费文档](/zh/pt/billing/ai-billing)。
</Accordion>

<div id="limitaes-atuais">
  ## 当前限制
</div>

目前，ChatGPT 中的 Replit App：

* 只能处理在当前对话中创建的 App
* 无法打开或修改：
  * 在其他 ChatGPT 对话中创建的 App
  * 你直接在 Replit 中创建的 App

与完整 Replit 体验实现功能一致 (包括数据库、Secrets 管理和更高级的 Project Editor 控制功能) 仍在开发中。

<div id="soluo-de-problemas">
  ## 故障排查
</div>

<Accordion title="“浏览应用”中未显示 Replit">
  如果你在 **浏览应用** 中没有看到 Replit，请检查：

  * 这些应用在你所在的区域是否可用
  * workspace 管理员是否已启用 Replit 应用 (Business/Enterprise/Edu)
</Accordion>

<Accordion title="创建失败">
  如果创建失败，请在 Replit 中打开该应用：

  * 查看用量和账单
  * 使用 checkpoint 和回滚
  * 直接在 Project Editor 中向 Agent 求助
</Accordion>
