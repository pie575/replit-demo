Les suggestions explorent des directions avec le même designer ; changer de modèle change le designer. Chaque modèle a sa propre sensibilité de design et ses propres points forts en frontend, donc le même brief peut aboutir ailleurs avec un modèle différent derrière.

## Changer de modèle

Ouvrez le sélecteur de mode dans le compositeur de chat (il affiche le mode actuel, comme **Power**), puis sélectionnez **Primary model** et choisissez dans la liste.

Deux autres contrôles se trouvent dans la même popover :

* **Mode** (Lite, Economy, Power) : l'équilibre entre vitesse, coût et capacité. Power utilise un modèle plus performant pour le travail de design, idéal pour les designs complexes et les modifications visuelles détaillées. Voir [Modes Agent](/fr/features/agent/agent-modes) pour la référence complète.
* **Effort** : la quantité de raisonnement que le modèle consacre par réponse, de Low (le plus rapide) à Max. Chaque modèle affiche son réglage recommandé.

## Explorer entre les modèles

Le changement de modèle est un autre axe d'exploration, aux côtés des [suggestions](/fr/design/explore-suggestions) :

* **Même brief, designer différent** : générez une frame, changez de modèle, et renvoyez le même prompt. Les deux directions atterrissent sous forme de frames sur le canvas, afin que vous puissiez les comparer côte à côte.
* **Adaptez le modèle au travail** : utilisez le modèle recommandé pour la plupart des tâches, et changez lorsqu'un design demande une sensibilité différente, ou lorsque vous voulez un second avis sur une direction dont vous n'êtes pas sûr.
* **Changez à tout moment** : le modèle s'applique à votre prochain message, vous pouvez donc en changer en cours de projet sans rien perdre sur le canvas.
