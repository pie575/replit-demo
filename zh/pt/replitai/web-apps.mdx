Web 应用是 Replit 默认的输出类型。当你向 Agent 描述一个想法时，除非指定其他类型的产物，否则 Agent 会构建一个全栈 Web 应用。

<div id="primeiros-passos">
  ## 开始使用
</div>

创建 Web 应用有两种方法：

* **输入 prompt**：在 Replit 首页描述你想构建的内容，Agent 会自动创建一个 Web 应用。
* **从下拉菜单中选择**：打开首页的应用类型下拉菜单，选择 **Web 应用**，然后描述你的想法。

<div id="recursos-principais">
  ## 核心功能
</div>

* **默认 全栈**：每个 Web 应用都包含前端和 backend。Agent 会按照应用的实际需要配置 API 路由、数据库和服务端逻辑。
* **响应式设计**：应用会自动适配各种屏幕尺寸。
* **即时部署**：一键发布应用，托管、SSL 和基础设施全部由 Replit 负责。
* **共享基础设施**：如果你的项目包含多个制品——例如移动应用或数据看板——它们会共用同一套 backend、数据库和服务。

<div id="casos-de-uso">
  ## 使用场景
</div>

* **SaaS 产品**：构建面向客户的工具、仪表盘和平台。
* **内部工具**：为团队创建管理后台、CRM 或工作流应用。
* **落地页**：发布包含表单、动画和动态内容的营销网站。
* **交易平台和目录**：构建分类信息网站、招聘网站或社区平台。
