<div id="slack">
  ### Slack 集成
</div>

Agent 现已与 Slack API 集成。您可以使用 Agent 构建支持以下功能的 App：

* 发布消息
* 读取消息历史记录

可向您喜爱的 Slack 频道发布消息，也可从中读取消息。

<Frame>
  <img src="/assets/mirror/slack-integration-1072c585c41e.png" alt="Slack 集成" width="1640" height="739" data-path="images/changelog/2025-01-10/slack-integration.png" />
</Frame>

请将您构建的成果提交到 [Agent Showcase](https://forms.gle/qxpfr82wNpKsCdok9)。

<div id="agentassistant">
  ### Agent 和 Assistant 改进
</div>

* Agent 现可从主页更快加载，让你更快开始构建。
* 在控制台和 Shell 中选中文本后，会出现浮动弹窗，方便你快速访问 Assistant。只需选中文本并点击 Assistant 图标即可提问。

<Frame>
  <img src="/assets/mirror/ask-assistant-cd529bf4a0b1.png" alt="向 Assistant 提问" width="2532" height="1474" data-path="images/changelog/2025-01-10/ask-assistant.png" />
</Frame>

<div id="bash">
  ### Shell 中的 bash 自动补全

  ### Elixir 生态系统修复
</div>

  ### 自定义域名用户体验优化
</div>

  ## Teams 和 Enterprise

<div id="section-3">
  ### 增强项目精选控制
</div>

现在，你可以更轻松地将组织的公开项目设为精选或取消精选！

<Frame>
  <img src="/assets/mirror/feature-on-profile-95b81a71e0d7.png" alt="个人资料中的精选项目" width="1836" height="644" data-path="images/changelog/2025-01-10/feature-on-profile.png" />
</Frame>

现在，你可以通过项目信息模态窗口和项目索引表，直接在工作区中控制项目的精选状态。

<Frame>
  <img src="/assets/mirror/profile-preview-b8f2ecfed154.png" alt="个人资料预览" width="2126" height="1152" data-path="images/changelog/2025-01-10/profile-preview.png" />
</Frame>

此外，将项目设为精选时，你可以预览它在公开个人资料中的显示效果。
