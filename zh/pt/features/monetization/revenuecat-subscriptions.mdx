<div id="o-que-o-revenuecat">
  ## 什么是 RevenueCat
</div>

RevenueCat 让你能够为[原生移动应用](/zh/pt/features/artifact-types/building-mobile-apps)添加应用内订阅。上手很简单：让 Agent 配置一个订阅，连接你的 RevenueCat 账户，Agent 会处理相关逻辑并提供测试环境。

<div id="pr-requisitos">
  ## 前提条件
</div>

开始之前，你需要准备：

* 一个已创建**移动应用**的 Replit project
* 一个 [RevenueCat](https://www.revenuecat.com) 账户 (只需邮箱和密码即可——无需银行账户，也无需额外配置)

<Note>
  若要开发原生移动应用，请在 [replit.com](https://replit.com) 上使用 Project Editor。在支持的情况下，也可以在 Android 版 Replit 应用中开发原生移动应用。如果你使用的是 iOS 版 Replit 应用，请在 replit.com 上打开该 project。
</Note>

<Steps>

<div id="teste-as-assinaturas">
  ## 测试订阅
</div>

Replit 的 Preview 使用 RevenueCat 的**测试模式**。在 Expo Go 中测试购买时，你会看到测试购买对话框，而不是真实的支付流程，不会产生任何扣费。

<Frame>
  <img src="/assets/mirror/revenuecat-test-purchase-8414145a112e.png" alt="移动设备上的测试购买对话框，显示套餐详情和测试按钮" width="683" height="1253" data-path="images/replitai/revenuecat-test-purchase.png" />
</Frame>

<Tip>
  开发阶段可以放心使用测试购买。你可以测试成功和失败两种购买流程，不会产生任何实际扣费。
</Tip>

<Warning>
  一旦 Apple 批准你的应用在 App Store 上架，购买就会使用真实资金。
  在提交 App Review 之前，请确认你在 RevenueCat 中的产品和价格设置无误。
</Warning>

<div id="sincronizao-com-o-app-store-connect">
  ## 与 App Store Connect 同步
</div>

要让应用内购买在 TestFlight 和 Apple App Store 中正常使用，[你需要同意 Apple 的 Paid Apps Agreement 并绑定你的银行账户](https://developer.apple.com/help/app-store-connect/manage-agreements/sign-and-update-agreements/)。
这些操作均在 App Store Connect 中完成。在将应用提交到 App Store 之前，你需要拥有付费的 Apple Developer 账户。

完成上述操作后，你可以直接在 Replit 中将 RevenueCat 的应用内购买配置同步到 App Store Connect。

<Steps>
  <Step title="前往 Publishing 中的 Manage 面板">
    你会看到一个用于将 RevenueCat 同步到 App Store Connect 的按钮。

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-sync-btn-46a2e4e696df.png" alt="Sync RevenueCat to App Store Connect 按钮" width="1476" height="604" data-path="images/replitai/revenuecat-asc-sync-btn.png" />
    </Frame>

    <Tip>
      此部分只有在你将应用提交到 TestFlight 之后才会出现。
    </Tip>
  </Step>

  <Step title="提供 App Store Connect API 密钥">
    你需要前往 App Store Connect 获取该密钥。

    在 [App Store Connect](https://appstoreconnect.apple.com/access/integrations/api) 中，进入 **Users and Access**，然后选择 **Integrations** 标签页。在侧边栏中选择 **App Store Connect API**。

    创建密钥时，请务必为其授予“App Manager”权限。

    请立即下载 .p8 文件——该文件只能下载一次。文件名以 `AuthKey_` 开头，以 `.p8` 结尾。

    复制此页面上显示的 **Key ID** 和 **Issuer ID**。

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-create-c54be8304d7c.png" alt="App Store Connect 的 Users and Access 页面，带编号步骤突出显示 Integrations 标签页、侧边栏中的 App Store Connect API 链接以及用于创建新 API 密钥的加号按钮" width="2390" height="752" data-path="images/replitai/revenuecat-asc-create.png" />
    </Frame>

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-app-manager-93996acd8561.png" alt="App Store Connect 中的 Generate API Key 对话框，名称设置为 RevenueCat，访问权限设置为 App Manager" width="1116" height="560" data-path="images/replitai/revenuecat-asc-app-manager.png" />
    </Frame>

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-copy-07a95e1be9af.png" alt="App Store Connect API 密钥页面，箭头指向 Issuer ID 的 Copy 链接和 Key ID 列" width="2330" height="780" data-path="images/replitai/revenuecat-asc-copy.png" />
    </Frame>
  </Step>

  <Step title="创建 In-App Purchase API 密钥">
    按上一步的方法再创建一个 In-App Purchase API 密钥。
    在侧边栏中选择 **In-App Purchase**，然后创建一个具有 **App Manager** 权限的 API 密钥。
    下载 .p8 密钥文件 (文件名以 `SubscriptionKey_` 开头，以 `.p8` 结尾) 。复制 **Key ID** 和 **Issuer ID**。

    <Frame>
      <img src="/assets/mirror/revenuecat-iap-api-key-7eb34e815ccb.png" alt="App Store Connect 的 Users and Access 页面，侧边栏中选中了 In-App Purchase，箭头指向用于创建新密钥的加号按钮" width="2272" height="637" data-path="images/replitai/revenuecat-iap-api-key.png" />
    </Frame>
  </Step>

  <Step title="同步产品">
    确认产品列表，然后同步到 App Store Connect。

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-products-sync-078d42af83ba.png" alt="Manage in-app purchases 对话框，显示一个 Monthly Subscription 产品及其价格、时长和地区字段，以及一个 Sync to App Store Connect 按钮" width="948" height="476" data-path="images/replitai/revenuecat-asc-products-sync.png" />
    </Frame>
  </Step>
</Steps>

<div id="perguntas-frequentes">
  ## 常见问题
</div>

<AccordionGroup>
  <Accordion title="我需要银行账户才能使用 RevenueCat 吗？">
    不需要。创建 RevenueCat 账户只需一个邮箱和密码。银行账户的设置
    则是在你准备好接收 App Store 或 Google Play 的收款时，
    通过 Apple 或 Google 单独完成。
  </Accordion>

  <Accordion title="测试购买会实际扣费吗？">
    不会。在开发阶段，Replit 的 Preview 使用 RevenueCat 的测试模式，
    购买均为模拟，不会产生任何真实扣费。只有在 Apple 的 App Review
    审核通过你的应用之后，才会开始真实扣费。
  </Accordion>

  <Accordion title="我可以在 Web 应用中使用 RevenueCat 吗？">
    RevenueCat 是为原生移动应用设计的。若要为 Web 应用添加订阅功能，
    请改用 [Stripe 集成](/zh/pt/features/monetization/stripe-payments)。
  </Accordion>

  <Accordion title="我可以用 RevenueCat 配置哪些内容？">
    你可以配置按月或按年的订阅、设置价格、管理
    entitlements，以及搭建付费墙。把这些改动交给 Agent 即可——它会同时处理
    RevenueCat 的配置和你应用中的代码。
  </Accordion>
</AccordionGroup>
