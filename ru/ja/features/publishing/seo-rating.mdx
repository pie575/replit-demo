Когда вы публикуете веб-приложение на Replit, для его действующего URL автоматически выполняется аудит поисковой оптимизации (SEO), а SEO-оценка отображается в инструментах Publishing. Если оценку можно улучшить, достаточно одного клика, чтобы передать конкретные проблемы Agent и устранить их за считаные секунды.

У большинства создателей весь процесс выглядит так: опубликовать приложение, бегло взглянуть на оценку и попросить Agent «оптимизировать SEO». На этой странице рассказывается, что при этом происходит «под капотом» и как использовать эту возможность по максимуму.

<div id="seo">
  ## Что такое SEO и почему это важно
</div>

Поисковая оптимизация (SEO) — это построение сайта таким образом, чтобы поисковые системы вроде Google могли его найти, понять и ранжировать. При сильном SEO ваше приложение появляется в результатах поиска, когда люди ищут то, что им нужно, — и платить за рекламу для этого не нужно.

Результат в SEO во многом определяется несколькими факторами: понятными заголовками и описаниями страниц, семантической HTML-разметкой, быстрой загрузкой, адаптированной под мобильные устройства версткой, содержательным alt-текстом для изображений и структурой сайта, доступной для сканирования. Поисковые системы ценят сайты, которые удобно читать и человеку, и машине.

Если вы публикуете лендинг, маркетинговый сайт, блог, каталог — словом, всё, для чего важна заметность, — SEO станет одним из самых выгодных вложений на раннем этапе.

<div id="replitseo">
  ## Улучшения SEO, которые Replit обеспечивает по умолчанию
</div>

Replit берёт на себя значительную часть работы над SEO-фундаментом, так что вы можете сосредоточиться на контенте и продукте.

* **Быстрый хостинг с глобальным распределением**: Replit Deployments раздаёт приложения с инфраструктуры, оптимизированной по скорости, а в разделе [География проекта](/ru/ja/features/publishing/project-geography) вы можете выбрать, где будет работать приложение.
* **HTTPS по умолчанию**: все опубликованные приложения получают TLS-сертификат, управляемый Replit. Это базовый сигнал ранжирования для поисковых систем.
* **Собственные домены**: подключите свой домен, чтобы укрепить доверие и авторитет бренда. См. [Собственные домены](/ru/ja/features/publishing/custom-domains).
* **Static Deployments для контентных сайтов**: для маркетинговых страниц, блогов и документации [Static Deployments](/ru/ja/features/publishing/deployment-types#static) выдаёт заранее отрендеренный HTML, который поисковым системам легко сканировать.
* **Agent пишет код с учётом SEO**: создавая страницы, Agent по умолчанию формирует семантический HTML, доступную разметку и метатеги — именно то, что проверяют SEO-инструменты.
* **SEO-оценка**: после публикации автоматически запускается аудит, поэтому вы всегда видите текущее состояние и можете передать найденные проблемы Agent одним нажатием.

<div id="section">
  ### Где найти
</div>

Откройте инструмент **Publishing** в опубликованном приложении. SEO-оценка отображается в обзоре развёртывания вместе с остальными сведениями о сборке. Наведите курсор на оценку, чтобы увидеть конкретные замечания, которые Lighthouse нашёл на каждой странице.

<Note>
  Если SEO-оценка не отображается, возможно, ваше приложение приватное или давно не публиковалось. Оценка показывается только для общедоступных веб-приложений.
</Note>

<div id="section-2">
  ### Как читать оценку
</div>

На основе аудита Lighthouse Replit показывает одну из трёх оценок:

| Оценка     | Значение                                                                                           |
| :--------- | :------------------------------------------------------------------------------------------------- |
| Healthy    | Приложение соответствует лучшим практикам SEO. После крупных изменений проверяйте его внимательно. |
| Needs Work | Ряд проблем мешает поисковым системам корректно распознавать приложение.                           |
| Weak       | Отсутствуют важные基основы SEO. На исправление обычно уходит всего несколько минут.                 |

Если в приложении несколько страниц, значок показывает **самую низкую** оценку среди всех URL, просканированных Replit. Благодаря этому самые проблемные страницы выходят на первый план и не теряются при усреднении.

<div id="section-3">
  ### Когда рассчитывается оценка
</div>

Аудит выполняется автоматически после каждой успешной публикации. Оценка обычно появляется в течение 1–2 минут после запуска деплоймента, а инструмент Publishing обновляет значок сразу же, как только приходят результаты.

<div id="section-4">
  ### Поддерживаемые типы deployment
</div>

SEO-оценка рассчитывается для общедоступных веб-deployment, URL которых доступны для сканирования поисковыми системами.

* [Autoscale deployment](/ru/ja/features/publishing/deployment-types#autoscale)
* [Reserved VM deployment](/ru/ja/features/publishing/deployment-types#reserved-vm)
* [Static Deployments](/ru/ja/features/publishing/deployment-types#static)

Для запланированных и приватных deployment SEO-оценка не формируется, так как они не обрабатывают публичный веб-трафик.

<div id="agentseo">
  ## Оптимизация SEO с помощью Agent
</div>

Рядом с оценкой отображается кнопка **Optimize SEO with Agent**. Если её нажать, в панели Growth откроется [SEO Agent](/ru/ja/features/publishing/seo-agent): он проведёт технический SEO-аудит, покажет найденные проблемы и позволит применить исправления в один клик.

<Tip>
  Можно обойтись и без кнопки. Просто откройте Agent и скажите **«Оптимизируй SEO»** — Agent получит свежие результаты и возьмётся за работу.
</Tip>

После того как Agent внесёт изменения, опубликуйте приложение заново. SEO-оценка будет пересчитана для новой сборки, а бейдж обновится автоматически.

Вот типичные исправления, которые применяет Agent:

* Добавляет и исправляет отсутствующие или шаблонные теги `<title>`, чтобы у каждой страницы был уникальный и содержательный заголовок
* Добавляет метаописания на все страницы
* Добавляет содержательный текст `alt` к изображениям
* Задаёт атрибут `lang` для элемента `<html>`
* Проверяет, что у ссылок есть понятный текст (без «нажмите здесь» и пустых якорей)
* Добавляет `robots.txt` и `sitemap.xml`
* Добавляет метатег viewport для корректного отображения на мобильных устройствах
* Улучшает контрастность текста, не проходящего проверки доступности
* Добавляет метатеги Open Graph и Twitter Card, чтобы ссылки на приложение красиво выглядели в предпросмотре на социальных платформах

<div id="replitseo-2">
  ## Лучшие практики создания SEO-оптимизированных сайтов на Replit
</div>

Независимо от того, поручите ли вы это Agent или сделаете сами, наибольший эффект в приложениях, созданных на Replit, дают следующие пункты.

* **Задавайте уникальный заголовок и метаописание для каждой страницы.** Ориентируйтесь на заголовок не длиннее 60 символов и описание примерно в 150–160 символов.
* **Используйте семантический HTML.** Оборачивайте разметку в `<main>`, `<header>`, `<nav>`, `<footer>`. Используйте `<h1>` только один раз на странице и понижайте уровни заголовков последовательно.
* **Добавляйте alt-текст ко всем изображениям.** Описывайте не только то, что изображено, но и то, что изображение показывает.
* **Создайте `sitemap.xml` и `robots.txt`.** Попросите Agent сгенерировать оба файла, чтобы поисковые системы понимали, что именно нужно сканировать.
* **Добавьте теги Open Graph и Twitter Cards.** Так вы будете контролировать, как ваше приложение выглядит при публикации в социальных сетях.
* **Используйте собственный домен.** Брендированный домен повышает доверие как посетителей, так и поисковых систем. См. [Собственные домены](/ru/ja/features/publishing/custom-domains).
* **Выбирайте подходящий тип deployment.** Для сайтов с большим объемом контента [Static Deployments](/ru/ja/features/publishing/deployment-types#static) отдают заранее отрендеренный HTML, который поисковые системы разбирают мгновенно.
* **Добавьте структурированные данные.** Разметка JSON-LD позволяет поисковым системам показывать расширенные результаты для товаров, статей, FAQ и событий.
* **Поддерживайте высокую скорость приложения.** Оптимизируйте изображения, избегайте скриптов, блокирующих рендеринг, и используйте хостинг Replit, чтобы время отклика оставалось низким.

Вот простой способ применить большинство из этих рекомендаций сразу.

<AiPrompt>
  Audit my site for SEO best practices and apply the fixes. Add a sitemap, robots.txt, Open Graph tags, structured data where it makes sense, and make sure every page has a unique title and meta description.
</AiPrompt>
