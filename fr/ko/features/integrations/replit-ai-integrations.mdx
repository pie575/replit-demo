L&#39;intégration IA de Replit vous permet de créer facilement des applications basées sur l&#39;IA. Lancez-vous immédiatement avec les modèles d&#39;OpenAI, Anthropic, Google et OpenRouter. Aucune configuration de compte développeur ni gestion de clés API n&#39;est nécessaire : Replit s&#39;occupe de tout.

<div id="replit-ai">
  ## Que sont les intégrations IA de Replit ?
</div>

Les intégrations IA de Replit offrent un accès géré aux modèles d&#39;IA des principaux fournisseurs. Créez des applications de chat, des générateurs de contenu et des outils basés sur l&#39;IA sans quitter Replit. Nul besoin de créer un compte développeur externe, de rechercher des identifiants d&#39;API ou de gérer une facturation distincte.

Avec les intégrations IA de Replit, c&#39;est Replit qui gère les identifiants des fournisseurs et facture au tarif public de l&#39;API. L&#39;utilisation est facturée en crédits Replit et apparaît sur la [page Utilisation](/fr/ko/billing/managing-spend), ventilée par application Replit existante.

<Note>
  Les intégrations IA de Replit nécessitent un plan payant (Core, Pro ou Enterprise). Avec le [plan Starter](/fr/ko/billing/plans/starter-plan), vous pouvez créer des applications d&#39;IA avec vos propres clés d&#39;API. Consultez la [disponibilité selon le plan](#plan-availability).
</Note>

<div id="section">
  ## Fonctionnalités
</div>

L&#39;intégration IA de Replit simplifie le développement avec l&#39;IA grâce à un accès intégré et à une facturation transparente :

* **Aucune configuration** : aucun compte développeur ni clé API n&#39;est nécessaire pour démarrer
* **Identifiants gérés** : Replit se charge de l&#39;authentification auprès des fournisseurs et de la gestion des identifiants
* **Facturation transparente** : vous payez le tarif public de l&#39;API, facturé en crédits Replit
* **Suivi de la consommation** : consultez la consommation par app Replit existante depuis la page Utilisation
* **Prise en charge multi-technologies** : fonctionne avec tous les langages de programmation et frameworks
* **BYOK en option** : vous pouvez apporter votre propre clé API pour utiliser vos propres identifiants

<div id="section-2">
  ## Démarrage
</div>

<div id="replit">
  ### Utiliser les identifiants gérés par Replit
</div>

Si vous mentionnez des fonctionnalités d’IA ou un fournisseur spécifique (OpenAI, Anthropic, Google ou OpenRouter) dans votre prompt, Agent utilise par défaut les intégrations IA de Replit :

<AiPrompt>
  Créez une web app qui utilise OpenAI pour résumer des articles
</AiPrompt>

Vous pouvez savoir quelle intégration est utilisée en repérant **&quot;OpenAI (Replit managed)&quot;**, **&quot;Anthropic (Replit managed)&quot;**, **&quot;Google (Replit managed)&quot;** ou **&quot;OpenRouter (Replit managed)&quot;** dans la réponse au prompt initial. Cela indique qu’Agent utilisera les identifiants de Replit au lieu de demander votre propre clé API.

**Pour les nouvelles apps** : lorsque vous soumettez un prompt initial pour créer une app incluant des fonctionnalités d’IA, une intégration IA de Replit est automatiquement sélectionnée. Agent commence immédiatement la création avec les identifiants gérés par Replit.

**Pour les Replit Apps existantes** : lorsqu’Agent détecte qu’il ajoute des fonctionnalités d’IA à une Replit App existante, il indique explicitement dans l’éditeur de projet qu’il souhaite utiliser une intégration IA de Replit plutôt que votre propre clé API. Une demande de confirmation s’affiche :

<Frame>
  <img src="/assets/mirror/replit-ai-integrations-confirmation-msg-9440681ad7d3.png" alt="Boîte de dialogue de confirmation de l’intégration OpenAI, avec un message indiquant l’ajout d’OpenAI via le service géré de Replit, sans clé API requise, et des boutons Désactiver et Autoriser" width="924" height="294" data-path="images/replitai/replit-ai-integrations-confirmation-msg.png" />
</Frame>

Cliquez sur « Autoriser » pour continuer avec les identifiants gérés par Replit, ou sur « Désactiver » pour utiliser votre propre clé API.

L’utilisation est suivie automatiquement et facturée à votre compte Replit aux tarifs publics de l’API.

<div id="api">
  ### Utiliser vos propres clés API
</div>

Si vous souhaitez utiliser vos propres identifiants OpenAI, Anthropic, Google ou d&#39;un autre fournisseur plutôt que l&#39;intégration IA de Replit, plusieurs options s&#39;offrent à vous :

**Pour une première création** : précisez dans votre prompt que vous souhaitez utiliser votre propre clé API :

<AiPrompt>
  Create a web app that uses OpenAI to summarize articles. Use my own OpenAI API key.
</AiPrompt>

Si la réponse affiche uniquement le nom du fournisseur, sans la mention « Replit managed », c&#39;est qu&#39;Agent vous demandera votre clé API.

**Pour une app Replit existante** : lorsqu&#39;Agent tente d&#39;utiliser l&#39;intégration IA de Replit et affiche une demande de confirmation, cliquez sur « désactiver » plutôt que sur « autoriser ».

Dans les deux cas, Agent construit l&#39;app jusqu&#39;au premier checkpoint avant de vous demander votre clé API. Il peut ainsi mettre en place la structure du projet, puis marquer une pause pour recueillir vos identifiants.

Si vous utilisez votre propre clé API, la facturation se fait directement auprès du fournisseur, et non via vos crédits Replit.

</div>

Toute la consommation liée à l&#39;intégration IA de Replit apparaît sur la [page Utilisation](/fr/ko/billing/managing-spend), au même titre que le reste de votre consommation Replit. Elle est ventilée par application Replit existante, ce qui vous permet de savoir précisément où vont vos dépenses d&#39;IA.

<div id="section-4">
  ## Fournisseurs pris en charge
</div>

Les intégrations IA de Replit prennent actuellement en charge les fournisseurs suivants :

* **OpenAI** : modèles multimodaux pour la génération de texte, le raisonnement et l&#39;audio. Prend en charge les complétions de chat, les réponses, la génération d&#39;images, la transcription audio (`gpt-4o-transcribe`, `gpt-4o-mini-transcribe`) et la sortie audio (`gpt-audio`, `gpt-audio-mini`).
* **Anthropic** : modèles multimodaux pour le raisonnement, la rédaction et le code. Prend en charge l&#39;API Messages et les interactions de recherche sur le Web.
* **Google (Gemini)** : modèles multimodaux pour la génération de texte et le raisonnement. Prend en charge la génération de texte et d&#39;images.
* **OpenRouter** : donne accès aux modèles de fournisseurs tels que Microsoft (série Phi), Meta (série Llama), Mistral, Qwen, DeepSeek, Nvidia et Amazon.

<Note>
  Les intégrations IA de Replit prennent en charge les **sorties de texte, d&#39;image et d&#39;audio**. La sortie vidéo n&#39;est pas prise en charge. Si vous avez besoin de fonctionnalités de génération vidéo, vous devez utiliser votre propre clé API auprès d&#39;un fournisseur qui les propose.
</Note>

<div id="openrouter-2">
  ## Confidentialité et disponibilité d&#39;OpenRouter
</div>

Lorsque vous utilisez OpenRouter via l&#39;intégration IA de Replit, les requêtes sont envoyées avec des paramètres de confidentialité spécifiques destinés à protéger vos données. Il est important de bien comprendre ces paramètres, car ils peuvent avoir une incidence sur les modèles disponibles.

<div id="section-6">
  ### Paramètres de confidentialité des utilisateurs en libre-service
</div>

Pour les utilisateurs individuels et les Teams, Replit configure les requêtes OpenRouter avec les paramètres de confidentialité par défaut suivants :

* **Entraînement désactivé sur les points de terminaison payants** : les fournisseurs de modèles payants n&#39;utilisent pas vos données à des fins d&#39;entraînement
* **Entraînement activé sur les points de terminaison gratuits** : les fournisseurs de modèles gratuits peuvent s&#39;entraîner sur les prompts et les complétions
* **Publication activée sur les points de terminaison gratuits** : les fournisseurs gratuits peuvent publier les prompts et les complétions dans des jeux de données publics
* **Journalisation des entrées/sorties désactivée** : OpenRouter n&#39;enregistre ni les requêtes ni les réponses, ce qui donne droit à une remise de 1 % sur la facturation
* **Cookies analytiques désactivés** : aucun cookie analytique n&#39;est utilisé

Ces paramètres privilégient la confidentialité tout en donnant accès à la plus large gamme de modèles possible. Toutefois, si vous avez besoin de paramètres de confidentialité différents de ceux indiqués ci-dessus, **certains modèles risquent d&#39;être indisponibles**.

<div id="enterprise">
  ### Paramètres de confidentialité pour Enterprise
</div>

Pour les organisations Enterprise, Replit applique des contrôles de confidentialité plus stricts :

* **Points de terminaison sans conservation des données (ZDR) uniquement** : seuls les modèles assortis d&#39;une politique de non-conservation des données sont disponibles
* Tous les paramètres de confidentialité ci-dessus, applicables aux utilisateurs en libre-service, s&#39;appliquent également
* Les requêtes Enterprise sont ainsi acheminées uniquement vers des points de terminaison qui ne conservent aucune donnée

Comme Enterprise n&#39;autorise que les points de terminaison ZDR, **le choix de modèles disponibles est plus restreint que pour les utilisateurs en libre-service**. Ce compromis garantit le plus haut niveau de confidentialité des données pour les charges de travail d&#39;entreprise.

<div id="section-7">
  ## Disponibilité selon les plans
</div>

L&#39;intégration IA de Replit nécessite un plan payant. Les modalités d&#39;accès varient selon le plan.

<div id="starter">
  ### Starter (gratuit)
</div>

Avec le plan Starter, l&#39;intégration IA de Replit est désactivée. Vous pouvez développer des applications d&#39;IA avec votre propre clé API. Consultez [Utiliser votre propre clé API](#bringing-your-own-api-key).

<div id="core">
  ### Core
</div>

Le plan Core vous permet de créer des applications d&#39;IA grâce à l&#39;intégration IA de Replit, avec des identifiants gérés par Replit. Aucune gestion de clés API n&#39;est requise.

<div id="pro-enterprise">
  ### Pro et Enterprise
</div>

Pour les organisations Pro et Enterprise, l&#39;accès à l&#39;intégration IA de Replit est désactivé par défaut. Les administrateurs de l&#39;organisation peuvent en contrôler l&#39;accès depuis la page des paramètres de l&#39;organisation :

1. Accédez aux paramètres de l&#39;organisation
2. Repérez la section Intégration IA de Replit
3. Activez ou désactivez l&#39;accès pour votre organisation

Une fois l&#39;option activée, les membres de l&#39;organisation peuvent utiliser l&#39;intégration IA de Replit dans leurs apps. L&#39;ensemble de l&#39;utilisation est suivi et facturé au compte de l&#39;organisation. Si elle est désactivée, les membres doivent fournir leurs propres clés API pour utiliser les fournisseurs de modèles d&#39;IA.

<div id="section-8">
  ## Cas d&#39;usage
</div>

Créez des applications d&#39;IA puissantes sur n&#39;importe quelle stack :

* **Génération de contenu** : résumer des articles, générer des descriptions, rédiger du contenu
* **Analyse et insights** : extraire les informations clés, analyser les sentiments, classer des textes
* **Interfaces conversationnelles** : créer des chatbots et des assistants IA
* **Transformation de texte** : traduire, réécrire et reformater du contenu
* **Assistance au code** : générer des extraits de code, expliquer des algorithmes, relire du code
