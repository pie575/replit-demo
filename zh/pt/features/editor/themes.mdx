Replit 的主题功能可让你自定义项目编辑器的外观，涵盖背景色、界面元素以及代码的语法高亮。个性化你的开发环境，让代码更易读、眼睛更轻松，编程体验更愉悦。

<div id="criando-um-tema-personalizado">
  ## 创建自定义主题
</div>

按照以下步骤创建并自定义你自己的主题：

1. 打开[设置](https://replit.com/settings)，进入 **用户** → **个性化** (或 **Themes** 部分)
2. 选择 **创建新主题**
3. 输入标题，选择配色方案 (浅色或深色) ，并添加描述 (可选)
4. 选择 **创建主题**，打开主题编辑器

全局主题设置控制界面的整体外观：

* **Background**：设置界面中大多数区域的基础颜色
* **Outline**：控制边框和分隔线的颜色
* **Foreground**：决定文本和图标的颜色
* **Primary**：设置按钮和交互元素的颜色
* **Positive**：用于成功状态指示，例如 **Run** 按钮
* **Negative**：用于显示错误和破坏性操作的警告

选择 **应用主题**，即可立即开始使用你的自定义主题。

<div id="realce-de-sintaxe">
  ## 语法高亮
</div>

自定义各类代码元素的外观，提升代码的可读性和易理解程度。

<Tip>
  恰当的语法高亮能让代码更易于快速浏览和理解。请选择彼此搭配协调、且与背景有足够对比度的颜色。
</Tip>

<Accordion title="语法高亮元素">
  | 元素                       | 说明                                     |
  | ------------------------ | -------------------------------------- |
  | **Variable Names**       | 适用于未使用声明关键字的变量                         |
  | **Variable Definitions** | 为使用 `const`、`var` 等关键字定义的变量名着色         |
  | **Function References**  | 适用于调用函数时                               |
  | **Function Definitions** | 为声明处的函数名着色                             |
  | **Keywords**             | 高亮 `import`、`function`、`return` 等语言关键字 |
  | **Property Names**       | 为通过变量访问的属性着色                           |
  | **Property Definitions** | 用于定义对象属性时                              |
  | **Function Properties**  | 适用于调用对象方法时                             |
  | **Tag Names**            | 用于 HTML 和 JSX 标签                       |
  | **Type Names**           | 为类型化语言中的类型注解着色                         |
  | **Class Names**          | 适用于类的声明和引用                             |
  | **Attribute Names**      | 高亮 HTML 和 JSX 属性                       |
  | **Comments**             | 适用于所有代码注释                              |
  | **Strings**              | 为字符串字面量着色                              |
  | **Numbers**              | 高亮数值                                   |
  | **Booleans**             | 设置布尔值 (`true`/`false`) 的样式             |
  | **Regular Expressions**  | 为正则表达式模式着色                             |
  | **Operators**            | 高亮 `+`、`-`、`*`、`/` 等运算符                |
  | **Brackets**             | 在适当情况下为方括号和尖括号着色                       |
</Accordion>

<div id="boas-prticas-de-design-de-temas">
  ## 主题设计最佳实践
</div>

遵循以下准则，打造美观又实用的主题：

<div id="cor-e-contraste">
  ### 颜色与对比度
</div>

* **平衡对比度**：确保背景与前景元素之间有足够的差异
* **打造协调的配色**：选择相互衬托而非彼此冲突的颜色
* **保持亮度一致**：让各语法元素的亮度水平保持相近
* **兼顾无障碍**：避免低对比度组合，照顾有视觉障碍的用户

<Warning>
  应避免的常见主题设计问题：

  * 语法元素之间亮度差异过大
  * 颜色搭配不当，造成视觉不协调
  * 代码与背景之间对比度不足
</Warning>

<div id="gerenciando-seus-temas">
  ## 管理你的主题
</div>

在[设置](https://replit.com/settings)中查看和管理已安装的所有主题，路径为 **用户** → **个性化** (即 **Themes** 部分) 。

<div id="alternando-entre-temas">
  ### 切换主题
</div>

点击主题名称旁边的按钮，即可将其设为当前主题。

<div id="editando-temas">
  ### 编辑主题
</div>

点击三点菜单并选择**编辑**，即可修改你的自定义主题。

<Note>
  只有你自己创建的自定义主题才能编辑或删除。默认主题以及他人创建的主题无法修改。
</Note>

<div id="excluindo-temas">
  ### 删除主题
</div>

点击三点菜单并选择**删除**，即可移除自定义主题。

<div id="explorando-temas-da-comunidade">
  ## 探索社区主题
</div>

前往[主题探索页面](https://replit.com/themes)，发现由 Replit 社区创建的主题。

<div id="encontrando-temas">
  ### 查找主题
</div>

* 按名称搜索，找到特定主题，例如“Atom One Dark”
* 按作者筛选，浏览特定创作者的主题
* 按配色方案浏览，查找浅色或深色主题
* 搜索特定颜色，匹配你的偏好

安装前可先预览任意主题，看看它在项目编辑器中的实际效果。

<div id="portando-do-vs-code">
  ## 从 VS Code 迁移
</div>

在创建主题的过程中映射对应的颜色，即可将你喜爱的 VS Code 主题导入 Replit。

<div id="publicando-seu-tema">
  ## 发布你的主题
</div>

按照以下步骤，将你的自定义主题分享给 Replit 社区：

1. 打开该自定义主题的主题编辑器
2. 点击**发布**按钮
3. 填写标题和描述
4. 提交主题

发布后，你的主题会显示在主题探索页面，其他用户可以在此查看并安装。
