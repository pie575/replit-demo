<div id="section">
  ## Что такое визуализация данных?
</div>

Визуализация данных — это интерактивная панель или инструмент отчётности, который вы создаёте в диалоге с Agent. Достаточно описать, что вы хотите визуализировать и где находятся данные: Agent сам подберёт подходящие KPI, типы диаграмм и макет и по одному запросу соберёт полноценную панель.

Ключевые понятия:

* **Генерация за один запрос**: опишите цель и источники данных — и Agent построит готовую панель с подходящими диаграммами и метриками
* **Подключённые источники данных**: данные берутся из баз данных, [connector для хранилищ](/ru/ja/connectors/warehouses/overview), внешних API или загруженных файлов
* **Встроенные возможности**: каждая панель поддерживает обновление, автообновление, экспорт в PDF, экспорт диаграмм в CSV, а также светлую и тёмную темы
* **Аналитическая сводка**: Agent формирует выводы на основе вашего запроса и полученных данных
* **Несколько artifact**: визуализация данных может использовать тот же бэкенд и ту же базу данных, что и другие artifact [в рамках одного project](/ru/ja/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project)

<div id="section-2">
  ## Как использовать визуализацию данных
</div>

<div id="section-3">
  ### Создание с помощью запроса
</div>

На главной странице выберите вкладку **Приложения** и опишите дашборд, который хотите создать. Agent распознает запросы, связанные с данными, и выберет стек для визуализации данных.

**Примеры запросов:**

* «Создай дашборд для анализа продаж с отслеживанием продаж по регионам»
* «Создай инструмент для подготовки отчетов с визуализацией ежемесячных метрик»
* «Создай дашборд, отображающий наиболее популярные товары по данным о продажах из BigQuery»
* «Подключись к Snowflake и создай дашборд для анализа оттока клиентов»

<div id="section-4">
  ### Создание из выпадающего списка
</div>

1. Перейдите на вкладку **Приложения** на главной странице.
2. Откройте выпадающий список типов приложений.
3. Выберите **Визуализация данных**.
4. Опишите дашборд или инструмент для работы с данными, который хотите создать.

<div id="section-5">
  ### Подключение к хранилищу данных
</div>

Подключите визуализацию данных к BigQuery, Databricks или Snowflake через [connector для хранилищ](/ru/ja/connectors/warehouses/overview) и стройте дашборды поверх уже существующих наборов данных.

При запросах к данным хранилища Agent применяет параллельный мультиагентный поиск, чтобы изучить схемы и наборы данных. Это ускоряет разведку данных и помогает Agent подобрать подходящие таблицы и поля для дашборда.

Для начала настройте connector для хранилища в разделе [интеграций](/ru/ja/features/integrations/overview) вашего проекта и опишите Agent, что именно вы хотите визуализировать.

<div id="section-6">
  ### Добавление фильтров и функций
</div>

После того как Agent создаст дашборд, вы можете в промпте попросить его добавить фильтры, детализацию и другие интерактивные функции. Например, попросите Agent добавить фильтр по диапазону дат, выбор региона или строку поиска.

<div id="section-7">
  ### Экспорт и обмен
</div>

* **Экспорт в PDF**: экспортируйте всю панель мониторинга в PDF, чтобы поделиться ею или просмотреть офлайн.
* **Экспорт диаграммы в CSV**: скачайте данные отдельной диаграммы в виде файла CSV для дальнейшего анализа в электронных таблицах или других инструментах.
* **Аналитические документы**: попросите Agent подготовить подробный аналитический документ на основе данных панели мониторинга.

<div id="section-8">
  ## Что можно создать
</div>

* **Аналитические панели**: отслеживайте ключевые показатели — продажи, количество регистраций, вовлечённость и другие — в динамике за разные периоды
* **Инструменты отчётности**: создавайте внутренние отчёты, которые заинтересованные стороны смогут фильтровать и изучать без прямого доступа к базе данных
* **Интерфейсы для исследования данных**: просматривайте наборы данных и выполняйте запросы с визуальной обратной связью
* **Панели мониторинга**: отображайте данные в реальном времени или с минимальной задержкой из API, баз данных и внешних сервисов

<div id="section-9">
  ## Часто задаваемые вопросы
</div>

<Accordion title="К каким источникам данных можно подключаться?">
  Вы можете получать данные из базы данных Replit в вашем проекте, коннекторов хранилищ данных (BigQuery, Databricks, Snowflake), внешних API или загруженных файлов, например CSV. Настройте подключение к хранилищу данных через [интеграции](/ru/ja/features/integrations/overview).
</Accordion>

<Accordion title="Можно ли настроить внешний вид и дизайн?">
  Да. В диалоге можно настроить цвета, макет и типографику — попросите Agent привести их в соответствие с вашим брендом или скорректировать дизайн. Панели управления также поддерживают светлую и тёмную темы.
</Accordion>

<Accordion title="Может ли Agent анализировать данные?">
  После создания панели управления Agent формирует аналитическую сводку на основе вашего запроса и полученных данных. Вы также можете запросить более подробный аналитический отчёт.
</Accordion>

<Accordion title="Можно ли объединять визуализации данных с другими типами артефактов?">
  Да. В рамках [одного проекта](/ru/ja/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project) вы можете объединять визуализации данных с [веб-приложениями](/ru/ja/features/artifact-types/web-apps), [презентациями](/ru/ja/features/artifact-types/slide-decks) и другими типами артефактов. Они используют общий бэкенд и базу данных.
</Accordion>
