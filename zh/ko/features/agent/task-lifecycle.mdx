<div id="draft">
  ## 草稿
</div>

**草稿 (Draft) **是指 Agent 已规划但尚未开始构建的任务。草稿中只包含建议的工作内容，可以放心查看：任务标题、说明和计划。

你可以借助草稿判断 Agent 是否正确理解了你的目标，然后选择启动该任务、要求 Agent 修改计划，或将草稿保留以备日后使用。

<div id="active">
  ## 进行中
</div>

**进行中 (Active)&#x20;**&#x20;的任务正在后台运行。Agent 会在项目的隔离副本中工作，因此任务运行期间主版本不会发生任何改动。

在进行中的任务运行时，你仍可继续使用主会话。如果某个任务需要你的反馈，打开对应的会话继续 Conversation 即可。

  ## 排队中
</div>

**排队中**的任务已获批准，但仍在等待启动。当任务依赖于其他任务，或已达到你所用套餐的后台活跃任务上限时，任务就会进入队列。

前置条件完成且有活跃任务槽位空出后，排队中的任务会自动开始。

<div id="ready">
  ## 已就绪
</div>

**已就绪**的任务表示工作已完成，但变更尚未应用到主版本。应用变更前，请先查看任务日志、测试结果和预览。

如果对任务结果满意，就将其应用到主版本；如果不符合预期，可以将其删除并重新开始一个新任务。

<div id="applying">
  ## Applying
</div>

**Applying (应用中)&#x20;**&#x20;表示任务正在将更改合并到主版本。当同时应用多个任务的更改时，Agent 会自动处理冲突。

请等待应用完成后再判断最终结果。如果之后发现异常，可在主会话中让 Agent 修复。

<div id="done">
  ## 完成
</div>

**完成**任务已结束，无需进一步处理。完成可能表示任务已合并到主版本、在开始前已归档，或在进入构建后被取消。

请使用 **完成** 列记录已完成、已归档或已取消的任务。

<div id="section-2">
  ## 归档和取消任务
</div>

你可以在任务生命周期的任意阶段停止它，但可用的选项取决于任务在看板上所处的位置。**Archive (归档) **和 **Cancel (取消) **都会把任务移到 **完成** 列，但两者的行为并不相同：

| 操作                     | 可用时机                                                | 会发生什么                               | 可以撤销吗？                                        |
| ---------------------- | --------------------------------------------------- | ----------------------------------- | --------------------------------------------- |
| **Archive (归档)&#x20;** | 任务仍处于计划会话阶段：尚未开始构建的 **草稿**                       | 计划会话不会执行，而是被搁置。计划内容会保留。             | 可以。你可以在 **完成** 列中打开已归档的卡片，将其恢复到 **Drafts**。 |
| **Cancel (取消)&#x20;**  | 任务从计划进入构建阶段之后：所有 **进行中**、**排队中**、**已就绪** 任务 | Agent 会停止工作，并丢弃正在进行的内容。主版本不会应用任何更改。 | 不可以。已取消的任务无法恢复。如果想重新处理，请新建一个任务。               |

如果计划会话以后还想再查看，请使用 **Archive**。若要永久停止正在等待、正在运行或已完成构建的任务，请使用 **Cancel**。

已归档的计划会话和已取消的任务都会与已完成的任务一起，显示在 任务看板 最右侧的 **完成** 列中。
