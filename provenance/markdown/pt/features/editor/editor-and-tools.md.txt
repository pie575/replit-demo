# Editor e Ferramentas

> Conheça as ferramentas disponíveis no Editor de Projeto — o editor, o preview, o console, o shell e muito mais.

O Editor de Projeto inclui gerenciamento de layout e ferramentas integradas que impulsionam sua experiência de criação de apps.
Esses recursos do Editor de Projeto são especializados em lidar com aspectos específicos do processo de desenvolvimento, permitindo que você
foque em criar em vez de configurar.

## Layout personalizável do Editor de Projeto

As ferramentas de gerenciamento de layout do Editor de Projeto permitem personalizar os componentes do ambiente de desenvolvimento.
Ele é composto pelos seguintes tipos de elementos de interface do usuário:

| Elemento    | Descrição                                                                                              | Capacidades                                                                                                                                                                      | Casos de uso                                                                                                                           |
| ----------- | ------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| **Janelas** | Abas do navegador que contêm um ou mais painéis                                                        | <ul><li>Podem ser organizadas em várias telas</li></ul>                                                                                                                          | <ul><li>Organizar o Editor de Projeto em várias telas</li><li>Trabalhar em projetos diferentes simultaneamente</li></ul>               |
| **Painéis** | Seções de uma janela que contêm uma ou mais abas                                                       | <ul><li>Suportam divisão horizontal e vertical</li><li>Podem ser redimensionados e reorganizados</li><li>Podem ser convertidos em um painel flutuante dentro da janela</li></ul> | <ul><li>Ver o código e o preview lado a lado</li><li>Criar layouts personalizados para diferentes tarefas de desenvolvimento</li></ul> |
| **Abas**    | Contêm exatamente uma ferramenta do Editor de Projeto, como o editor de arquivos, o Preview ou o Agent | <ul><li>Podem ser movidas entre painéis e reordenadas dentro deles</li><li>Podem alternar entre diferentes arquivos ou ferramentas com um único clique</li></ul>                 | <ul><li>Abrir diferentes ferramentas ou arquivos quando precisar deles</li></ul>                                                       |

## Árvore de arquivos

A árvore de arquivos lista todos os arquivos e diretórios do seu Replit App.

<Accordion title="Como acessar a árvore de arquivos">
  Selecione o ícone <img class="icon-svg" src="https://mintcdn.com/replit/rJldsgYVucXB_6kW/images/icons/files-icon.svg?fit=max&auto=format&n=rJldsgYVucXB_6kW&q=85&s=4b9ac8b70c07960d9f9a3f6eacee4ab6" alt="ícone de pasta com setas" width="16" height="16" data-path="images/icons/files-icon.svg" /> de pasta à esquerda para alternar
  a visibilidade da árvore de arquivos.
</Accordion>

Você pode realizar as seguintes ações na árvore de arquivos:

* Selecionar uma pasta para exibir seu conteúdo
* Selecionar um arquivo ou arrastá-lo para um painel para abri-lo em um editor de arquivos
* Realizar operações de arquivo como duplicar, renomear, mover, baixar ou excluir

## Botão Run

O botão **Run** executa o workflow selecionado do seu Replit App.

<Accordion title="Como acessar o botão Run">
  O botão **Run** está localizado na parte superior da tela do Editor de Projeto. Selecione o botão para executar o workflow.

  Quando seu Replit App estiver em execução, o rótulo do botão é substituído por **Stop**. Selecione o botão para parar o app.
</Accordion>

Para aprender a selecionar, visualizar e gerenciar workflows, consulte [Workflows](/pt/features/workspace-tools/workflows/).

## Menu de opções

O menu de opções permite realizar os seguintes tipos de ações de layout:

* **Gerenciamento de janelas**: Abra o Editor de Projeto do Replit App em uma nova janela
* **Gerenciamento de painéis**: Adicione painéis, mova um painel, maximize um painel e alterne entre posições flutuantes e fixas
* **Gerenciamento de abas**: Abra ou selecione outras abas, mova uma aba para outro painel e feche uma aba

<Accordion title="Como acessar o menu de opções">
  Selecione os três pontos <img class="icon-svg" src="https://mintcdn.com/replit/X_IP1EeHGm0cA2VA/images/icons/vertical-dots.svg?fit=max&auto=format&n=X_IP1EeHGm0cA2VA&q=85&s=7b4b6a9992b3b20202297b60b6ef416d" alt="ícone de três pontos verticais" height="16" width="16" data-path="images/icons/vertical-dots.svg" /> verticais
  localizados no canto superior direito da aba ativa para abrir o menu de opções.
</Accordion>

## Painel de recursos

O painel de recursos exibe os recursos computacionais e o uso do seu ambiente de desenvolvimento, incluindo RAM, CPU e armazenamento.
Essa informação pode ajudar você a estimar e otimizar os requisitos de publicação do seu Replit App.

<Accordion title="Como acessar o painel de recursos">
  1. Selecione o ícone <img class="icon-svg" src="https://mintcdn.com/replit/rJldsgYVucXB_6kW/images/icons/resources.svg?fit=max&auto=format&n=rJldsgYVucXB_6kW&q=85&s=8df05261182e3e39f28dcccf809d66c2" alt="ícone de computadores empilhados" width="16" height="16" data-path="images/icons/resources.svg" /> de recursos localizado próximo ao nome do seu app para alternar o painel.
  2. Passe o cursor sobre os itens de linha **Compute** ou **Storage** para mais detalhes.
</Accordion>
