Project Editor включает инструменты для управления раскладкой и интеграции, которые делают процесс создания приложений удобнее.
Эти функции Project Editor помогают решать отдельные задачи в процессе разработки,
чтобы вы могли сосредоточиться на создании, а не на настройке.

<div id="project-editor">
  ## Настраиваемая раскладка Project Editor
</div>

Инструменты управления раскладкой Project Editor позволяют настраивать элементы среды разработки.
Она состоит из следующих типов элементов интерфейса.

| Элемент            | Описание                                                                                          | Возможности                                                                                                                                                                     | Примеры использования                                                                                                       |
| ------------------ | ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| **Windows (окна)** | Вкладка браузера, содержащая одну или несколько панелей                                           | <ul><li>Можно размещать на нескольких экранах</li></ul>                                                                                                                         | <ul><li>Организация Project Editor на нескольких экранах</li><li>Одновременная работа над несколькими проектами</li></ul>   |
| **Panes (панели)** | Область окна, содержащая одну или несколько вкладок                                               | <ul><li>Поддерживаются горизонтальное и вертикальное разделение</li><li>Можно изменять размер и перемещать</li><li>Можно преобразовать в плавающую панель внутри окна</li></ul> | <ul><li>Просмотр кода и Preview рядом</li><li>Создание пользовательских раскладок для различных задач разработки</li></ul> |
| **Tabs (вкладки)** | Каждая содержит ровно один инструмент Project Editor, например редактор файлов, Preview или Agent | <ul><li>Можно перемещать между панелями и менять порядок внутри панели</li><li>Можно переключаться на другой файл или инструмент одним щелчком</li></ul>                        | <ul><li>Открытие других инструментов или файлов при необходимости</li></ul>                                                 |

<div id="section">
  ## Дерево файлов
</div>

В дереве файлов перечислены все файлы и папки вашего Replit App.

<Accordion title="Как открыть дерево файлов">
  Нажмите иконку папки <img class="icon-svg" src="/assets/mirror/files-icon-f66bf1b04572.svg" alt="иконка папки со стрелками" width="16" height="16" data-path="images/icons/files-icon.svg" /> слева,
  чтобы показать или скрыть дерево файлов.
</Accordion>

В дереве файлов можно выполнять следующие действия:

* Выбирать папку, чтобы просмотреть её содержимое
* Выбирать файл или перетаскивать его на панель, чтобы открыть в редакторе файлов
* Выполнять операции с файлами: дублировать, переименовывать, перемещать, скачивать и удалять

<div id="run">
  ## Кнопка Run
</div>

Кнопка **Run** запускает выбранный рабочий процесс в Replit App.

<Accordion title="Как найти кнопку Run">
  Кнопка **Run** находится в верхней части Project Editor. Нажмите её, чтобы запустить рабочий процесс.

  Пока Replit App запущен, надпись на кнопке меняется на **Stop**. Нажмите её, чтобы остановить приложение.
</Accordion>

Подробнее о выборе, проверке и управлении рабочими процессами см. в разделе [Workflows](/ru/ko/features/workspace-tools/workflows/).

<div id="section-3">
  ## Меню параметров
</div>

Меню параметров позволяет выполнять следующие действия с раскладкой.

* **Управление окнами**: открывать Project Editor Replit App в новом окне
* **Управление панелями**: добавлять, перемещать и разворачивать панели, а также переключать их между плавающим и закреплённым положением
* **Управление вкладками**: открывать или выбирать другие вкладки, перемещать вкладки на другие панели и закрывать их

<Accordion title="Как открыть меню параметров">
  Чтобы открыть меню параметров, нажмите <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="иконка с тремя вертикальными точками" height="16" width="16" data-path="images/icons/vertical-dots.svg" /> три вертикальные точки
  в правом верхнем углу активной вкладки.
</Accordion>

На следующем снимке экрана показано всплывающее меню параметров левой панели.

  <img src="/assets/mirror/workspace-options-menu-263431b4f1ba.png" alt="снимок экрана с меню параметров Project Editor" width="1968" height="1136" data-path="images/workspace/workspace-options-menu.png" />

<div id="section-4">
  ## Поиск
</div>

С помощью поиска можно находить файлы, текст и инструменты в Project Editor.

<Accordion title="Как открыть поиск">
  1. Нажмите значок лупы <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="иконка лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> в верхней части экрана.
  2. Введите поисковый запрос и выберите вариант из предложенных автодополнений.
</Accordion>

На следующем снимке экрана показано всплывающее меню поиска.

<div id="section-5">
  ## Панель ресурсов
</div>

Панель ресурсов отображает вычислительные ресурсы среды разработки и их использование, включая RAM, CPU и место в хранилище.
Эта информация помогает оценить и оптимизировать требования Replit App к публикации.

<Accordion title="Как открыть панель ресурсов">
  1. Чтобы открыть панель, выберите иконку ресурсов <img class="icon-svg" src="/assets/mirror/resources-237893692826.svg" alt="иконка стопки компьютеров" width="16" height="16" data-path="images/icons/resources.svg" /> рядом с названием приложения.
  2. Наведите указатель на **Compute** или **Storage**, чтобы просмотреть подробную информацию.
</Accordion>

На следующем снимке экрана показана панель ресурсов.
