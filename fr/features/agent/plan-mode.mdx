<div id="what-is-plan-mode">
  ## Qu&#39;est-ce que le mode Plan ?
</div>

Le mode Plan vous permet de :

* **Faire émerger des idées** et explorer différentes approches pour votre projet
* **Planifier le travail de développement** à l&#39;aide de listes de tâches structurées
* **Collaborer avec l&#39;IA** sur l&#39;architecture du projet et la planification des fonctionnalités
* **Obtenir des conseils stratégiques** et poser des questions sans modifier le code ni les données de votre projet
* **Basculer en toute fluidité** vers le mode Build lorsque vous êtes prêt à passer à l&#39;implémentation

Le mode par défaut est désormais appelé mode **Build**.

Contrairement au mode Build, le mode Plan est axé sur la planification et la réflexion, et vous aide à penser vos projets avant d&#39;écrire la moindre ligne de code.

<div id="getting-started">
  ## Premiers pas
</div>

<div id="accessing-plan-mode">
  ### Accéder au mode Plan
</div>

Le mode Plan est disponible dans toute Replit App où Agent est activé. Pour y accéder :

1. **Ouvrez votre Replit App** dans le Project Editor
2. **Repérez le sélecteur de mode** en bas à gauche de la zone de saisie du Chat
3. **Choisissez le mode Plan** dans le menu déroulant

<div id="key-features">
  ## Fonctionnalités clés

<div id="task-planning">
  ### Planification des tâches
</div>

Le mode Plan excelle à décomposer les projets complexes en tâches gérables. Indiquez vos exigences à Agent : il générera une liste ordonnée des tâches de développement nécessaires pour répondre à votre demande.

<div id="collaborative-brainstorming">
  ### Brainstorming collaboratif
</div>

Explorez différentes approches en collaboration avec l&#39;IA :

* **Plusieurs pistes de solution** pour les problèmes complexes
* **Analyse des avantages et des inconvénients** des différentes approches
* **Évaluation des risques** et stratégies d&#39;atténuation

<div id="workflow-from-planning-to-building">
  ## Workflow : de la planification à la création
</div>

<div id="1-planning-phase-plan-mode">
  ### 1. Phase de planification (mode Plan)
</div>

Démarrez votre processus de développement en mode Plan :

* **Définissez la portée de votre projet** et vos objectifs
* **Décomposez les exigences** en fonctionnalités précises
* **Planifiez votre architecture** et votre pile technologique
* **Créez une feuille de route de développement** jalonnée d&#39;étapes clés

<div id="2-task-approval">
  ### 2. Approbation des tâches
</div>

Lorsqu&#39;Agent génère une liste de tâches :

* **Passez en revue** les tâches proposées
* Sélectionnez **Start building** pour approuver le plan

ou poursuivez la conversation pour affiner le plan.

<div id="3-transition-to-build-mode">
  ### 3. Passer en mode Build
</div>

Lorsque vous êtes prêt à passer à la mise en œuvre :

* **Cliquez sur « Start building »** pour approuver le plan
* **Agent bascule automatiquement** en mode Build
* **Agent démarre la mise en œuvre** des tâches approuvées
* **Suivez l&#39;avancement** tout au long de la phase de développement

L&#39;utilisation du mode Plan suit la même tarification basée sur l&#39;effort que les autres interactions avec Agent. Tout le travail réalisé par Agent en mode Plan vous est facturé, y compris les réponses aux questions, les conseils fournis et la génération de listes de tâches. Les frais augmentent pour les demandes plus complexes ou celles formulées dans des conversations au contexte plus long.

**Toutes les interactions avec Agent sont facturables** : qu&#39;Agent réponde par des indications textuelles ou qu&#39;il modifie du code, des frais s&#39;appliquent toujours, même si les demandes plus modestes coûtent moins cher.

<div id="best-practices">
  ## Bonnes pratiques
</div>

<div id="effective-prompting">
  ### Rédiger des prompts efficaces
</div>

Pour tirer le meilleur parti du mode Plan :

* **Soyez précis** sur les exigences de votre projet
* **Posez des questions complémentaires** pour clarifier les suggestions de l&#39;IA
* **Demandez des exemples** lorsque vous abordez des concepts complexes
* **Pesez le pour et le contre** des différentes approches
* **Affinez vos idées** avant de passer à l&#39;implémentation
* **Conservez les décisions importantes** en y faisant référence dans les échanges suivants
