# Shell

> Apprenez à utiliser le Shell pour exécuter des commandes dans l'Éditeur de projet.

Le Shell vous permet d'effectuer des tâches sur le système d'exploitation dans l'Éditeur de projet, comme la gestion des fichiers,
l'installation de packages et l'exécution de scripts. Il fournit une interface basée sur le texte puissante pour
interagir avec votre environnement Replit.

Vous pouvez utiliser le Shell pour exécuter les tâches suivantes dans l'Éditeur de projet :

* Exécuter des scripts et des programmes
* Installer et exécuter des outils et packages Linux populaires
* Télécharger et téléverser des fichiers depuis et vers Internet
* Gérer les fichiers et répertoires du projet

<Tip>
  Pour une meilleure gestion des workflows, préférez le bouton **Exécuter** plutôt que d'exécuter votre application depuis
  le Shell. Le workflow démarré par le bouton **Exécuter** envoie la sortie à l'outil Console,
  qui fournit un moyen structuré de consulter les journaux.
</Tip>

## Fonctionnalités

Le Shell offre les capacités suivantes :

* **Exécuter plusieurs shells** : Ouvrir plusieurs instances de shell pour travailler sur différentes tâches simultanément
* **Rechercher du texte** : Trouver du texte spécifique dans la sortie du shell

### Recherche de texte

Les étapes suivantes décrivent comment accéder et utiliser l'outil de recherche de texte :

1. Sélectionnez la <img class="icon-svg" src="https://mintcdn.com/replit/X_IP1EeHGm0cA2VA/images/icons/workspace-search-icon.svg?fit=max&auto=format&n=X_IP1EeHGm0cA2VA&q=85&s=d3feed840da2d19e1ee4873d137114dc" alt="icône loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> loupe en haut à droite de l'onglet Shell pour ouvrir la boîte de dialogue de recherche.
2. Entrez un terme de recherche et sélectionnez **Suivant** pour naviguer entre les correspondances.
3. Utilisez **Précédent** pour revenir aux correspondances précédentes.
4. Sélectionnez **Quitter** ou cliquez en dehors de la boîte de dialogue pour quitter la recherche de texte.

### Plusieurs shells

Pour créer un nouveau shell, sélectionnez le menu en haut à gauche de la flèche de l'onglet **Shell** et sélectionnez **Nouveau Shell** comme indiqué ci-dessous :

<Frame>
  <img src="https://mintcdn.com/replit/gspzAm1mbsd1biBe/images/workspace/shell-new.png?fit=max&auto=format&n=gspzAm1mbsd1biBe&q=85&s=3c9d01cf27b611a8195ba61e4fa6ec63" alt="Sélection du menu Nouveau Shell" width="1280" height="224" data-path="images/workspace/shell-new.png" />
</Frame>

Utilisez le même menu pour passer d'un shell à l'autre. L'Éditeur de projet étiquette chaque shell avec la dernière commande exécutée pour vous aider à les identifier.

<Warning>
  Lorsque vous ouvrez plus d'un shell, Replit ferme automatiquement les instances de shell inactives.
  Un shell inactif est non sélectionné et n'exécute aucun processus utilisateur.
</Warning>
