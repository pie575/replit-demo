---
title: "Agent 模式"
description: "了解如何在 Free Mode、Power Mode 和 Max Mode 之间选择 Agent 构建模式。"
---

使用 Agent 模式时，您可以在成本和性能之间取得平衡。使用 Agent 设置下拉菜单，在 **Free Mode**、**Power Mode** 和 **Max Mode** 之间选择模式。Free Mode 始终使用 Auto。Core 和 Pro 套餐的构建者可以在 Power Mode 或 Max Mode 中使用 [Model selector](/zh/ko/features/agent/model-selector)。可用的模式和设置取决于您所使用的套餐和工作区。

<Note>
  Economy Mode 已不再提供。Power Mode 将以相同价格替代它。
</Note>

<Tip>
  **键盘快捷键：**按 **⌘+Shift+I** (Windows 上为 Ctrl+Shift+I) ，即可在不离开聊天输入框的情况下循环切换 Agent 模式。
</Tip>

<div id="free-mode">
  ## Free Mode
</div>

**非常适合入门。** Free Mode 可帮助您探索想法、了解 Replit 的工作方式并开始项目。

**注意：** Free Mode 始终使用 Replit 的智能模型路由功能 Auto。若要手动选择模型，请使用 Power Mode 或 Max Mode。

<Note>
  Core 和 Pro 套餐包含 Free Mode 使用配额，每 5 小时更新一次。用完配额后，Replit 会显示下次更新时间。
</Note>

Routine 无法在 Free Mode 中运行。它们可在 Power 或 Max Mode 中运行，且每次运行都需要预算。有关详细信息，请参阅 [Routine](/zh/ko/chat/routines)。

<div id="power-mode">
  ## Power Mode
</div>

**针对成本进行了优化。** Power Mode 每项任务消耗的积分更少，适合希望在不使用最强大模型的情况下获得良好结果时作为默认选择。

**适用场景：**日常构建、学习，以及在现有项目中开展注重成本节约的工作。

<div id="max-mode">
  ## Max Mode
</div>

**专为高性能而优化。** Max Mode 使用能力更强的模型，适合处理复杂任务、更大的代码库和更具挑战性的问题。

**适用场景：**生产级项目、复杂功能，或希望通过 Agent 获得最佳结果时。

<div id="section">
  ## 应该使用哪种模式？
</div>

请参考以下指南：

| 目标                        | 推荐模式                                                               |
| ------------------------- | ------------------------------------------------------------------ |
| 探索想法、了解 Replit 的工作方式并开始项目 | Free Mode                                                          |
| 最大化每个积分可使用的提示词数量          | Power Mode                                                         |
| 在大多数项目中平衡成本与质量            | Power Mode                                                         |
| 手动选择模型                    | Power Mode 或 Max Mode                                              |
| 在复杂的生产级任务中获得最佳结果          | Max Mode                                                           |
| 在最复杂的任务中获得最佳结果            | 使用更高 [Effort](/zh/ko/features/agent/model-selector#effort) 的 Max Mode |

使用聊天输入框中的 Agent 设置下拉菜单选择模式。Core 和 Pro 套餐的构建者可以在 Power Mode 或 Max Mode 中设置[主模型和 Effort](/zh/ko/features/agent/model-selector)。没有任何一种模式始终最适合所有情况。请选择适合当前任务的模式。

<div id="section-2">
  ## 共享项目中的设置
</div>

Agent 设置与您关联，而非与项目关联。邀请团队成员加入项目后，每个人都可以保留自己对以下选项的选择：

* 模式 (Free Mode、Power Mode 或 Max Mode)
* [主模型和 Effort](/zh/ko/features/agent/model-selector)，如可用
* [Plan 模式](/zh/ko/features/agent/plan-mode)
* 后台任务自动合并
* 计划自动批准

即使团队成员在下一个任务中切换到 Max Mode，您的设置也不会变为 Max Mode。无论项目中有多少协作者，您在 Agent 设置下拉菜单中看到的模式和设置，都是 Agent 在您发送下一条消息时使用的设置。

<div id="free-mode-2">
  ## 查看 Free Mode 配额
</div>

打开 **设置** → **使用情况**，即可查看剩余的 Free Mode 配额及续期时间。有关充分利用配额的实用方法，请参阅[充分利用 Free Mode](/zh/ko/chat/free-mode)。
