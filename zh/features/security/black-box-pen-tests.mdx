黑盒渗透测试通过浏览器和网络交互，从外部检查正在运行的应用，不涉及应用的源代码。

在 Project Security Center 中，**Level 3 (AI pentest)&#x20;**&#x20;整合了三类安全检查：

1. 免费的 dependency and package checks
2. Agent 对源代码的静态分析
3. 针对运行中 Preview 的外部黑盒测试，完全从外部进行，不使用你的源代码

启动 Level 3 后，Replit 会并行运行 Agent 源代码审查和外部黑盒测试。

<div id="run-a-level-3-scan">
  ## 运行 Level 3 扫描
</div>

<Steps>
  <Step title="打开 project">
    打开你要扫描的那个 project。
  </Step>

  <Step title="打开 Security Center">
    在 project 的 **Tools** 面板中，选择 **Security Center**。
  </Step>

  <Step title="启动扫描">
    在 Security Center 顶部，选择 **Run scan**。
  </Step>

  <Step title="选择 Level 3">
    选择 **Level 3 (AI pentest)**。

    <Frame caption="Level 3（AI pentest）在免费的 dependency and package checks 之外，还增加了 Agent 静态分析和外部实时 Preview 测试。">
      <img src="/assets/mirror/level-3-ai-pentest-c223c0099d3f.png" alt="Security and Privacy Center open from the Tools pane with the Select scan level menu expanded and Level 3 AI pentest selected" width="2204" height="1200" data-path="images/project-security-center/level-3-ai-pentest.png" />
    </Frame>
  </Step>

  <Step title="等待两项任务完成">
    等待源代码审查以及浏览器和网络黑盒测试全部完成。
  </Step>

  <Step title="查看结果">
    在 **Security** 面板中查看这两项任务的 findings。逐条评估后，再将确认的问题发送给 Agent。
  </Step>

  <Step title="修复并重新扫描">
    将确认的 findings 发送给 Agent。应用修复后，再运行一次 Level 3 扫描来验证效果。
  </Step>
</Steps>

<div id="understand-the-two-tasks">
  ## 了解这两项任务
</div>

| 任务     | 依据的证据           | 用途                    |
| ------ | --------------- | --------------------- |
| 源代码审查  | 你的应用源代码         | 识别代码库中的安全、隐私和架构漏洞     |
| 黑盒渗透测试 | 与运行中应用的浏览器和网络交互 | 在不使用源代码的情况下检查外部可观察的行为 |

请同时查看两类 findings。两项任务无法相互替代：源代码审查能发现存在漏洞的实现细节，黑盒测试则从外部评估运行中的应用。
