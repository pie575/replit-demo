Ao publicar um app web no Replit, uma auditoria de Search Engine Optimization (SEO) é executada automaticamente nas suas URLs ativas e exibe uma Classificação de SEO na ferramenta Publishing. Se a classificação tiver espaço para crescer, um único clique encaminha os problemas específicos ao Agent para que você possa corrigi-los em segundos.

Para a maioria dos criadores, o fluxo de trabalho completo é: publique seu app, dê uma olhada na classificação e peça ao Agent para "otimizar meu SEO". Esta página explica o que acontece por baixo dos panos e como aproveitar ao máximo esse recurso.

## O que é SEO e por que importa

A otimização para mecanismos de busca (SEO) é a prática de construir seu site para que mecanismos de busca como o Google possam encontrá-lo, entendê-lo e classificá-lo. Um SEO forte significa que o seu app aparece quando as pessoas pesquisam pelo que você oferece — sem pagar por anúncios.

Algumas coisas impulsionam a maioria dos seus resultados de SEO: títulos e descrições de página claros, HTML semântico, tempos de carregamento rápidos, layouts adaptados para dispositivos móveis, texto alternativo descritivo em imagens e uma estrutura de site rastreável. Os mecanismos de busca recompensam sites que são fáceis de ler tanto para humanos quanto para máquinas.

Se você está lançando uma landing page, um site de marketing, um blog, um diretório ou qualquer outra coisa em que a capacidade de ser descoberto importe, o SEO é um dos investimentos de maior impacto que você pode fazer desde o início.

## Como o Replit melhora o seu SEO por padrão

O Replit cuida de muitas das bases de SEO para que você possa se concentrar no seu conteúdo e produto:

* **Hospedagem rápida e distribuída globalmente**: Os Replit Deployments servem seu app a partir de uma infraestrutura otimizada para velocidade, e você pode escolher onde o app roda com [geografia do projeto](/pt/features/publishing/project-geography).
* **HTTPS por padrão**: Todo app publicado recebe um certificado TLS gerenciado pelo Replit, que é um sinal de classificação básico para os mecanismos de busca.
* **Domínios personalizados**: Conecte seu próprio domínio para construir confiança e autoridade de marca. Consulte [Custom Domains](/pt/features/publishing/custom-domains).
* **Static Deployments para sites de conteúdo**: Para páginas de marketing, blogs e documentação, os [Static Deployments](/pt/features/publishing/deployment-types#static) entregam HTML pré-renderizado que os mecanismos de busca rastreiam facilmente.
* **O Agent escreve código com consciência de SEO**: Quando o Agent constrói suas páginas, ele produz HTML semântico, marcação acessível e meta tags por padrão — as mesmas coisas que as ferramentas de SEO verificam.
* **A Classificação de SEO**: Uma auditoria automática após cada publicação para que você sempre saiba onde está, combinada com um encaminhamento de um clique para o Agent corrigir o que encontrar.

## A Classificação de SEO

Após cada publicação bem-sucedida, o Replit executa uma auditoria do Lighthouse nas URLs do seu deployment e armazena os resultados. A ferramenta Publishing exibe então uma Classificação de SEO geral para o seu app.

### Onde encontrar

Abra a ferramenta **Publishing** em um app publicado. A Classificação de SEO aparece na visão geral do deployment junto com os outros detalhes de build. Passe o cursor sobre a classificação para ver os itens de ação específicos que o Lighthouse identificou em cada página.

<Note>
  Se você não vir uma Classificação de SEO, seu app provavelmente é privado ou não foi publicado recentemente. A classificação só aparece para apps públicos voltados para a web que foram publicados.
</Note>

### Como interpretar sua classificação

O Replit exibe uma de três classificações com base na auditoria do Lighthouse:

| Classificação | O que significa                                                                             |
| :------------ | :------------------------------------------------------------------------------------------ |
| Healthy       | Seu app segue as melhores práticas de SEO. Fique de olho após grandes mudanças.             |
| Needs Work    | Vários problemas estão limitando a capacidade dos mecanismos de busca de entender o app.    |
| Weak          | Elementos básicos de SEO estão ausentes. Corrigi-los geralmente leva apenas alguns minutos. |

Se o seu app tiver várias páginas, o badge exibe a classificação **mais baixa** entre todas as URLs rastreadas pelo Replit, para que a pior página apareça primeiro em vez de ser diluída pela média.

### Quando a classificação é calculada

A auditoria é executada automaticamente após cada publicação bem-sucedida. A classificação geralmente aparece dentro de um ou dois minutos após o deployment entrar em funcionamento, e a ferramenta Publishing atualiza o badge assim que os resultados chegam.

### Tipos de deployment compatíveis

A Classificação de SEO é calculada para deployments públicos voltados para a web, onde os mecanismos de busca podem rastrear URLs:

* [Autoscale Deployments](/pt/features/publishing/deployment-types#autoscale)
* [Reserved VM Deployments](/pt/features/publishing/deployment-types#reserved-vm)
* [Static Deployments](/pt/features/publishing/deployment-types#static)

Scheduled deployments e private deployments não produzem uma Classificação de SEO porque não servem tráfego web público.

## Otimizar SEO com o Agent

Um botão **Optimize SEO with Agent** aparece ao lado da sua classificação. Selecioná-lo abre o [SEO Agent](/pt/features/publishing/seo-agent) no painel Growth, onde você pode executar uma auditoria técnica de SEO, revisar os problemas encontrados e aplicar correções com um clique.

<Tip>
  Você também pode ignorar o botão completamente. Abra o Agent e diga **"optimize my SEO"** — o Agent pegará seus resultados mais recentes e começará a trabalhar neles.
</Tip>

Depois que o Agent concluir suas alterações, republique seu app. A Classificação de SEO é recalculada com base no novo build e o badge é atualizado automaticamente.

Correções comuns que o Agent aplicará:

* Adicionar ou reescrever tags `<title>` ausentes ou genéricas para que cada página tenha um título único e descritivo
* Adicionar uma meta description em cada página
* Adicionar texto `alt` descritivo em imagens
* Definir o atributo `lang` no elemento `<html>`
* Garantir que os links tenham texto reconhecível (sem "clique aqui" ou âncoras vazias)
* Adicionar um `robots.txt` e um `sitemap.xml`
* Adicionar uma meta tag de viewport para renderização em dispositivos móveis
* Melhorar o contraste de cores em textos que não passam nas verificações de acessibilidade
* Adicionar meta tags Open Graph e Twitter card para que os links do seu app sejam visualizados corretamente nas plataformas sociais

## Melhores práticas para um site otimizado para SEO no Replit

Seja pedindo ao Agent para cuidar dessas tarefas ou escrevendo por conta própria, estas são as coisas de maior impacto para acertar em um app construído no Replit:

* **Dê a cada página um título único e uma meta description.** Busque títulos abaixo de 60 caracteres e descriptions em torno de 150 a 160 caracteres.
* **Use HTML semântico.** Envolva seu layout em `<main>`, `<header>`, `<nav>` e `<footer>`. Use `<h1>` uma vez por página e ordene os níveis de cabeçalho em sequência.
* **Adicione texto alt a cada imagem.** Descreva o que a imagem mostra, não apenas o que ela é.
* **Gere um `sitemap.xml` e `robots.txt`.** Peça ao Agent para criar ambos para que os mecanismos de busca saibam o que rastrear.
* **Adicione tags Open Graph e Twitter card.** Controle como seu app aparece quando compartilhado nas redes sociais.
* **Use um domínio personalizado.** Um domínio com marca constrói confiança com visitantes e mecanismos de busca. Consulte [Custom Domains](/pt/features/publishing/custom-domains).
* **Escolha o tipo de deployment certo.** Para sites com muito conteúdo, os [Static Deployments](/pt/features/publishing/deployment-types#static) entregam HTML pré-renderizado que os mecanismos de busca analisam instantaneamente.
* **Adicione dados estruturados.** A marcação JSON-LD ajuda os mecanismos de busca a mostrar resultados ricos para produtos, artigos, FAQs e eventos.
* **Mantenha seu app rápido.** Otimize imagens, evite scripts que bloqueiam a renderização e aproveite a hospedagem do Replit para manter os tempos de resposta baixos.

Uma forma simples de aplicar a maioria disso de uma vez:
