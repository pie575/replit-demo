Настройка Agent даёт Agent контекст, необходимый для того, чтобы он работал так же, как вы и ваша команда, — начиная с самого первого prompt. Вместо того чтобы заново объяснять свои правила в каждом проекте, вы задаёте их один раз для своего workspace, и Agent применяет их повсюду.

Настройка состоит из двух частей:

* **Пользовательские инструкции**: постоянно действующие правила, которые применяются к каждому проекту в вашем workspace.
* **Навыки**: переиспользуемые инструкции, которые Agent загружает только тогда, когда появляется подходящая задача.

Обеими частями вы управляете в разделе **Workspace Settings → Customization**.

<div id="custom-instructions-vs-skills">
  ## Пользовательские инструкции и навыки
</div>

Пользовательские инструкции загружаются с каждым сообщением, а навыки — только когда Agent сочтёт, что они подходят для задачи. Используйте пользовательские инструкции для тех немногих правил, которые верны всегда, а навыки — для конкретных рабочих процессов, соглашений и справочных материалов.

О причинах такого разделения — бюджете контекста, о том, что и куда стоит помещать, и как правильно создавать навыки — читайте в разделе [Навыки Agent](/ru/learn/agent-skills). О том, как устроены навыки и как Agent их загружает, см. [Навыки Agent](/ru/features/agent/skills).

<div id="custom-instructions">
  ## Пользовательские инструкции
</div>

Пользовательские инструкции — это постоянно действующие правила, которые добавляются в контекст Agent в каждом проекте и в каждой сессии ещё до того, как кто-либо введёт prompt. Задайте их один раз в Workspace Settings, и Agent будет применять их во всём вашем workspace. Лучше всего они подходят для правил, которые верны всегда: требований к безопасности и соответствию нормам, списка одобренных библиотек и фреймворков или политик обработки данных.

Пишите кратко. Чёткая и конкретная инструкция с большей вероятностью будет соблюдена и оставит больше места для самой задачи, над которой работает Agent.

<Warning>
  Пользовательские инструкции могут влиять на производительность Agent. Agent ориентируется на них, но точное выполнение требований не гарантируется. Более короткие и конкретные правила соблюдаются надёжнее.
</Warning>

<Note>
  Пользовательские инструкции workspace — это не то же самое, что файл `custom_instruction/instructions.md` в проекте. Пользовательская инструкция workspace задаётся один раз в Workspace Settings и применяется ко всем проектам. Файл уровня проекта находится внутри одного проекта — этот подход описан в статье [Создание собственной дизайн-системы](/ru/teams/custom-design-system).
</Note>

<div id="skills">
  ## Навыки
</div>

Навык — это переиспользуемый набор инструкций, который Agent загружает только тогда, когда появляется подходящая задача. Навыки workspace отображаются вверху меню **+** в каждом проекте вашего workspace, поэтому вся команда работает с одним и тем же набором.

Создать навык можно тремя способами:

* **Загрузить** существующую папку с навыком.
* **Написать** новый навык прямо в форме.
* **Попросить Agent** подготовить черновик навыка, а затем доработать его.

<Note>
  Навыки, подготовленные Agent, можно загрузить в ваш Workspace. Попросите Agent скачать навык — он упакует его в архив `.zip` и покажет кнопку **Download file** (см. ниже). Скачайте архив, а затем загрузите его обратно в **Workspace Settings → Customization → Skills** через **Create skill → Choose file or folder**, чтобы он стал общим для всего workspace.
</Note>

<Frame>
  <img src="/assets/mirror/agent-customization-download-skill-3727b188c5a8.png" alt="Agent упаковал навык workspace в скачиваемый архив ux-designer-skill.zip с кнопкой Download file" width="1716" height="864" data-path="images/replitai/agent-customization-download-skill.png" />
</Frame>

Полную структуру навыка (`SKILL.md`, вспомогательные файлы, открытый стандарт) смотрите в разделе [Навыки Agent](/ru/features/agent/skills). Ознакомиться с навыками, которые уже созданы Replit и нашими партнёрами, можно в [каталоге навыков](/ru/features/agent/skills-directory).

<Note>
  Не злоупотребляйте навыками. Agent читает название и описание каждого навыка при каждой задаче, поэтому избыток навыков (или пересекающиеся между собой навыки) рассеивает его внимание и затрудняет выбор нужного. Держите каждый навык узконаправленным и удаляйте те, которые больше не нужны.
</Note>

<div id="availability-and-permissions">
  ## Доступность и разрешения
</div>

| Возможность                 | Доступно в        | Кто может управлять                                              |
| --------------------------- | ----------------- | ---------------------------------------------------------------- |
| Пользовательские инструкции | Pro и Enterprise  | Enterprise: администраторы. Pro: любой участник workspace        |
| Навыки                      | Все платные планы | Enterprise: администраторы. Core и Pro: любой участник workspace |

В workspace Enterprise создавать, изменять и удалять пользовательские инструкции и навыки могут только администраторы. В workspace Pro это может делать любой участник. В workspace Core любой участник может управлять навыками, а пользовательские инструкции на Core недоступны. В любом случае использовать созданные навыки может каждый участник workspace.

<div id="create-a-custom-instruction">
  ## Создание пользовательской инструкции
</div>

<Steps>
  <Step title="Откройте настройки workspace">
    Перейдите в раздел **Workspace Settings → Customization**.

    <Frame>
      <img src="/assets/mirror/agent-customization-tab-930af2e8ed74.png" alt="Вкладка Customization в настройках workspace с подвкладками Skills и Custom instructions" width="1065" height="394" data-path="images/replitai/agent-customization-tab.png" />
    </Frame>
  </Step>

  <Step title="Напишите инструкцию">
    В разделе **Custom instructions** опишите правила, которым Agent должен следовать во всех проектах.
  </Step>

  <Step title="Сохраните">
    Сохраните изменения. Инструкция будет применяться к новым проектам в вашем workspace.
  </Step>
</Steps>

<div id="create-a-skill">
  ## Создание навыка
</div>

<Steps>
  <Step title="Откройте настройки Workspace">
    Перейдите в **Workspace Settings → Customization**.
  </Step>

  <Step title="Создайте навык">
    В разделе **Skills** нажмите **Create skill**, затем загрузите папку навыка, напишите инструкции или попросите Agent составить их.

    <Frame>
      <img src="/assets/mirror/agent-customization-create-skill-fcb794e6de4e.png" alt="Вкладка Customization в настройках Workspace с подвкладками Skills и Custom instructions и открытой формой создания навыка" width="2168" height="1350" data-path="images/replitai/agent-customization-create-skill.png" />
    </Frame>
  </Step>

  <Step title="Напишите понятное описание">
    Дайте навыку чёткое описание с указанием, когда его применять, а когда — нет. Именно его читает Agent, решая, подходит ли навык.
  </Step>

  <Step title="Сохраните">
    Сохраните навык. Он станет доступен в меню **+** в каждом проекте вашего workspace.
  </Step>
</Steps>

<div id="use-a-workspace-skill-in-a-project">
  ## Использование навыка workspace в проекте
</div>

Чёткое описание навыка играет ключевую роль. Agent читает описание каждого навыка workspace и автоматически подключает подходящий, когда ваш prompt примерно соответствует назначению навыка, — так что выбирать навык вручную нужно не всегда. При этом вы можете указать навык явно, если хотите быть уверены, что он применён.

Чтобы выбрать навык вручную:

<Steps>
  <Step title="Откройте выбор навыков">
    В проекте нажмите кнопку **+** рядом с полем ввода чата. Навыки вашего workspace отображаются сверху, одной группой.

    <Frame>
      <img src="/assets/mirror/agent-customization-skill-picker-4643f3a453c7.png" alt="Выбор навыков, открытый кнопкой +, с группой навыков workspace сверху над навыками Replit" width="1668" height="1170" data-path="images/replitai/agent-customization-skill-picker.png" />
    </Frame>
  </Step>

  <Step title="Выберите навык">
    Выберите навык, который должен быть активен. Также можно ввести `/` и название навыка, чтобы вызвать его напрямую.
  </Step>

  <Step title="Продолжайте отправлять запросы">
    Продолжайте работу как обычно. Agent использует навык, когда задача соответствует его описанию.
  </Step>
</Steps>

<div id="manage-instructions-and-skills">
  ## Управление инструкциями и навыками
</div>

Всё управление осуществляется в разделе **Workspace Settings → Customization**. Здесь можно отредактировать пользовательскую инструкцию, а также изменить, отключить или удалить любой навык. Изменения применяются к новым чатам и не затрагивают уже начатые.
