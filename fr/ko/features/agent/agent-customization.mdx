title: "Personnalisation d’Agent"
description: "Indiquez à Agent les règles de votre équipe grâce à des instructions personnalisées et des compétences centralisées pour tout l’espace de travail, dans les paramètres de l’espace de travail."
---

La personnalisation d’Agent fournit à Agent le contexte nécessaire pour travailler comme vous et votre équipe, dès le premier prompt. Au lieu de réexpliquer les règles dans chaque projet, définissez-les une seule fois dans votre espace de travail et Agent les appliquera partout.

Elle comprend deux éléments :

* **Instructions personnalisées** : des directives toujours actives qui s’appliquent à tous les projets de votre espace de travail.
* **Compétences** : des instructions réutilisables qu’Agent charge uniquement lorsqu’elles sont pertinentes.

Vous gérez les deux dans **Paramètres de l’espace de travail → Personnalisation**.

<div id="section">
  ## Instructions personnalisées et compétences
</div>

Les instructions personnalisées sont chargées à chaque message, tandis que les compétences ne le sont que lorsque Agent estime qu&#39;elles sont pertinentes pour la tâche. Utilisez les instructions personnalisées pour les quelques directives qui s&#39;appliquent systématiquement, et les compétences pour des flux de travail, des règles et des ressources de référence spécifiques.

Pour en savoir plus sur cette distinction — le budget de contexte, ce qui va où et comment bien rédiger des compétences — consultez les [compétences Agent](/fr/ko/learn/agent-skills). Pour savoir comment les compétences sont structurées et chargées par Agent, consultez les [compétences Agent](/fr/ko/features/agent/skills).

<div id="section-2">
  ## Instructions personnalisées
</div>

Les instructions personnalisées sont des consignes permanentes injectées dans le contexte d’Agent pour tous les projets et toutes les sessions avant même qu’un utilisateur ne saisisse un prompt. Définissez-les une seule fois dans les paramètres de l’espace de travail, et Agent les appliquera à l’ensemble de celui-ci. Elles sont particulièrement adaptées aux consignes toujours valables, comme les exigences de sécurité et de conformité, les bibliothèques et frameworks approuvés, ou encore les politiques de traitement des données.

Soyez concis. Plus vos instructions sont ciblées et précises, plus elles ont de chances d’être respectées correctement, tout en laissant davantage de latitude à Agent pour accomplir son travail.

<Warning>
  Les instructions personnalisées peuvent affecter les performances d’Agent. Agent est invité à les suivre, mais le respect d’exigences strictes n’est pas garanti. Des consignes plus courtes et plus précises sont respectées de manière plus fiable.
</Warning>

<Note>
  Les instructions personnalisées de l’espace de travail sont différentes du fichier `custom_instruction/instructions.md` d’un projet. Elles sont définies une seule fois dans les paramètres de l’espace de travail et s’appliquent à tous les projets. Le fichier propre au projet se trouve dans un projet donné — consultez [Créer un système de conception personnalisé](/fr/ko/teams/custom-design-system) pour en savoir plus sur ce modèle.
</Note>

<div id="section-3">
  ## Compétences
</div>

Les compétences sont des ensembles d’instructions réutilisables qu’Agent charge uniquement lorsqu’elles sont pertinentes pour une tâche. Les compétences de l’espace de travail apparaissent en haut du menu **+** dans tous les projets de l’espace de travail, afin que toute l’équipe partage le même ensemble.

Il existe trois façons de créer des compétences :

* **Téléverser** : téléversez un dossier de compétences existant.
* **Créer** : créez directement une nouvelle compétence à l’aide du formulaire.
* **Demander à Agent** : demandez à Agent de rédiger une ébauche de compétence, puis affinez-la.

<Note>
  Vous pouvez téléverser dans l’espace de travail les compétences rédigées par Agent. Demandez à Agent de télécharger une compétence. Agent la regroupera dans une archive `.zip` téléchargeable et affichera un bouton **Télécharger le fichier** (voir ci-dessous). Téléchargez l’archive zip, puis téléversez-la de nouveau via **Paramètres de l’espace de travail → Personnalisation → Compétences**, puis **Créer une compétence → Sélectionner un fichier ou un dossier**, afin de la partager dans tout l’espace de travail.
</Note>

<Frame>
  <img src="/assets/mirror/agent-customization-download-skill-3727b188c5a8.png" alt="Agent regroupe une compétence d’espace de travail dans une archive ux-designer-skill.zip téléchargeable et affiche le bouton Télécharger le fichier" width="1716" height="864" data-path="images/replitai/agent-customization-download-skill.png" />
</Frame>

Pour en savoir plus sur la structure complète des compétences (`SKILL.md`, fichiers de prise en charge et normes ouvertes), consultez les [compétences Agent](/fr/ko/features/agent/skills). Pour découvrir les compétences déjà créées par Replit et ses partenaires, consultez le [répertoire des compétences](/fr/ko/features/agent/skills-directory).

<Note>
  Utilisez les compétences à bon escient. Agent lit le nom et la description de toutes les compétences pour chaque tâche ; un trop grand nombre de compétences (ou des compétences redondantes) peut donc disperser son attention et compliquer la sélection de la bonne compétence. Limitez la portée de chaque compétence et supprimez celles dont vous n’avez plus besoin.
</Note>

<div id="section-4">
  ## Disponibilité et autorisations
</div>

| Fonctionnalité              | Plans disponibles      | Personnes pouvant gérer                                                             |
| --------------------------- | ---------------------- | ----------------------------------------------------------------------------------- |
| Instructions personnalisées | Pro et Enterprise      | Enterprise : administrateurs. Pro : tous les membres de l’espace de travail         |
| Compétences                 | Tous les plans payants | Enterprise : administrateurs. Core et Pro : tous les membres de l’espace de travail |

Dans les espaces de travail Enterprise, seuls les administrateurs peuvent créer, modifier et supprimer des instructions personnalisées et des compétences. Dans les espaces de travail Pro, tous les membres peuvent le faire. Dans les espaces de travail Core, tous les membres peuvent gérer les compétences ; les instructions personnalisées ne sont pas disponibles dans Core. Dans tous les cas, tous les membres de l’espace de travail peuvent utiliser les compétences créées.

<div id="section-5">
  ## Créer des instructions personnalisées
</div>

<Steps>
  <Step title="Ouvrir les paramètres de l’espace de travail">
    Accédez à **Paramètres de l’espace de travail → Personnalisation**.

    <Frame>
      <img src="/assets/mirror/agent-customization-tab-930af2e8ed74.png" alt="Onglet Personnalisation des paramètres de l’espace de travail, affichant les sous-onglets Compétences et Instructions personnalisées" width="1065" height="394" data-path="images/replitai/agent-customization-tab.png" />
    </Frame>
  </Step>

  <Step title="Rédiger les instructions">
    Dans la section **Instructions personnalisées**, rédigez les directives qu’Agent appliquera à tous les projets.
  </Step>

  <Step title="Enregistrer">
    Enregistrez vos modifications. Les instructions s’appliqueront aux nouveaux projets de l’espace de travail.
  </Step>
</Steps>

<div id="section-6">
  ## Créer une compétence
</div>

<Steps>
  <Step title="Ouvrir les paramètres de l’espace de travail">
    Accédez à **Paramètres de l’espace de travail → Personnalisation**.
  </Step>

  <Step title="Créer une compétence">
    Dans la section **Compétences**, cliquez sur **Créer une compétence**, puis importez un dossier de compétences, rédigez des instructions ou demandez à Agent d’en créer un brouillon.

    <Frame>
      <img src="/assets/mirror/agent-customization-create-skill-fcb794e6de4e.png" alt="Onglet Personnalisation des paramètres de l’espace de travail, avec les sous-onglets Compétences et Instructions personnalisées, ainsi que le formulaire Créer une compétence ouvert" width="2168" height="1350" data-path="images/replitai/agent-customization-create-skill.png" />
    </Frame>
  </Step>

  <Step title="Rédiger une description claire">
    Ajoutez à la compétence une description précise indiquant clairement quand l’utiliser et quand ne pas l’utiliser. Agent lit cette description pour déterminer si la compétence s’applique.
  </Step>

  <Step title="Enregistrer">
    Enregistrez la compétence. Elle sera disponible dans le menu **+** de tous les projets de l’espace de travail.
  </Step>
</Steps>

<div id="section-7">
  ## Utiliser les compétences de l’espace de travail dans les projets
</div>

Il est important que les descriptions des compétences soient précises. Agent lit les descriptions de toutes les compétences de l’espace de travail et utilise automatiquement une compétence lorsque votre prompt correspond globalement à son objectif. Vous n’avez donc pas toujours besoin de sélectionner une compétence vous-même. Vous pouvez aussi la sélectionner explicitement pour vous assurer qu’elle est bien appliquée.

Pour sélectionner une compétence manuellement :

<Steps>
  <Step title="Ouvrir le sélecteur de compétences">
    Dans votre projet, cliquez sur le bouton **+** à côté du champ de saisie du chat. Les compétences de l’espace de travail s’affichent sous forme de groupe en haut de la liste.

    <Frame>
      <img src="/assets/mirror/agent-customization-skill-picker-4643f3a453c7.png" alt="Sélecteur de compétences ouvert depuis le bouton +, groupe de compétences de l’espace de travail affiché en haut, au-dessus des compétences Replit" width="1668" height="1170" data-path="images/replitai/agent-customization-skill-picker.png" />
    </Frame>
  </Step>

  <Step title="Sélectionner une compétence">
    Sélectionnez la compétence que vous souhaitez activer. Vous pouvez également l’invoquer directement en saisissant son nom après `/`.
  </Step>

  <Step title="Continuer à rédiger le prompt">
    Continuez comme d’habitude. Si la tâche correspond à sa description, Agent utilise la compétence.
  </Step>
</Steps>

<div id="section-8">
  ## Gestion des instructions et des compétences
</div>

Toute la gestion s’effectue dans **Paramètres de l’espace de travail → Personnalisation**. Vous pouvez y modifier les instructions personnalisées, ainsi que modifier, désactiver ou supprimer toutes les compétences. Les modifications s’appliquent aux futurs chats, mais pas à ceux déjà en cours.
