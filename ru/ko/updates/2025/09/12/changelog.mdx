export const YouTubeEmbed = ({videoId, title = "Видео на YouTube", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

В Agent 3 значительно улучшены автономность, стабильность и скорость:

* **Тестирование приложений**: Agent сам тестирует приложение в настоящем браузере, находит проблемы и устраняет их в итеративном цикле. См. [Тестирование приложений](/ru/core-concepts/agent/app-testing).
* **Более длительная работа**: Agent может работать автономно до 200 минут с отслеживанием в реальном времени — это удобно для масштабных сборок. Подробнее в разделе [Agent](/ru/core-concepts/agent#max-autonomy).
* **Создание агентов**: создавайте агентов и автоматизации, которые запускаются по расписанию или интегрируются со Slack и Telegram. См. [Агенты и автоматизации](/ru/core-concepts/agent/agents-and-automations).

  ## Коннекторы и интеграции приложений
</div>

Деплойте быстрее благодаря встроенным интеграциям и коннекторам:

* **Под управлением Replit**: встроенные интеграции, которые работают в приложениях автоматически.
* **Коннекторы**: собственные интеграции Replit — войдите один раз и используйте подключение в любых приложениях.
* **Внешние интеграции**: доверенные сторонние сервисы, которые Agent настраивает с помощью API-ключей.
