title: "Управление зависимостями"
description: "Узнайте, как устанавливать пакеты и управлять зависимостями в Replit App на разных языках."
---

Replit предлагает несколько способов устанавливать пакеты и управлять ими в Replit App. Вы можете устанавливать пакеты с помощью [Shell](/ru/pt/core-concepts/project-editor/editor-and-tools/shell), поручить это [Agent](/ru/pt/core-concepts/agent/) или позволить Replit автоматически обнаруживать и устанавливать недостающие зависимости при запуске Replit App.

<div id="instalar-pacotes-usando-o-shell">
  ## Установка пакетов через Shell
</div>

Откройте инструмент **Shell** в редакторе проекта и выполните команду для менеджера пакетов, используемого в вашем языке:

<CodeGroup>
  ```bash Node.js (npm) theme={null}
  npm install <package-name>
  ```

  ```bash Node.js (pnpm) theme={null}
  pnpm add <package-name>
  ```

  ```bash Python (poetry) theme={null}
  poetry add <package-name>
  ```

  ```bash Python (pip) theme={null}
  pip install <package-name>
  ```

  ```bash Ruby theme={null}
  bundle add <gem-name>
  ```
</CodeGroup>

Вы также можете использовать [универсальный менеджер пакетов Replit (UPM)](https://github.com/replit/upm/) для установки пакетов в поддерживаемых языках:

```bash theme={null}
upm add <package-name>
```

Чтобы установить определённую версию:

```bash theme={null}
upm add 'flask==2.3.3'
```

Список всех поддерживаемых языков и менеджеров пакетов см. в разделе [UPM: Поддерживаемые языки](https://github.com/replit/upm/#supported-languages).

<div id="instalar-pacotes-usando-o-agent">
  ## Установка пакетов с помощью Agent
</div>

Вы можете попросить [Agent](/ru/pt/core-concepts/agent/) установить пакеты прямо в Chat. Например:

* «Установи пакет axios»
* «Добавь Flask и SQLAlchemy в мой проект»
* «Настрой TailwindCSS»

Agent устанавливает пакет с помощью подходящего для вашего проекта менеджера пакетов и обновляет соответствующие файлы конфигурации.

<div id="deteco-automtica-de-importaes">
  ## Автоматическое обнаружение импортов
</div>

Replit автоматически проверяет код на наличие недостающих зависимостей при каждом нажатии **Run**. Если код импортирует ещё не установленный пакет, Replit обнаружит его и автоматически установит последнюю версию.

Например, если добавить `import flask` в `main.py`, при следующем нажатии **Run** в **Console** появится сообщение об установке **Flask**.

<Note>
  Вы можете настроить автоматическое обнаружение импортов в файле [.replit](/ru/pt/core-concepts/project-editor/app-setup/configuration#replit-file) с помощью параметра `packager.features.guessImports`.
</Note>

<div id="substituir-a-deteco-automtica">
  ### Переопределение автоматического обнаружения
</div>

Если был определён неверный пакет или вам нужна конкретная версия, выполните в Shell соответствующую команду установки. Например:

```bash theme={null}
upm add 'flask==2.3.3'
```

Вы также можете исключить определённые пакеты или пути из автоматического обнаружения в файле [.replit](/ru/pt/core-concepts/project-editor/app-setup/configuration#replit-file):

<div id="gerenciadores-de-pacotes-python">
  ## Менеджеры пакетов Python
</div>

При создании Replit App на Python по умолчанию используется менеджер пакетов **poetry**. Это значит, что `pip install` не управляет зависимостями. Вместо этого используйте в Shell `poetry add <package>` или `upm add <package>`.

<div id="alternar-do-poetry-para-o-pip">
  ### Переход с poetry на pip
</div>

Если вы предпочитаете использовать `pip`, выполните следующие действия:

<Steps>
  <Step>
    Откройте Shell и выполните следующее:

    Удалите файл блокировки, чтобы система управления пакетами перешла на pip:

    ```bash theme={null}
    rm poetry.lock
    ```
  </Step>

  <Step title="Перенесите зависимости">
    Перенесите зависимости из раздела `[tool.poetry.dependencies]` файла `pyproject.toml` в `requirements.txt`. Например, `flask = "^3.0.2"` станет `flask>=3.0.2,<4`.
  </Step>

  <Step title="Очистите pyproject.toml">
    Удалите разделы `[tool.poetry...]` из `pyproject.toml`.
  </Step>
</Steps>

После этих изменений система управления пакетами будет использовать `pip` для всех последующих операций, а автоматическое обнаружение импортов продолжит работать должным образом.

<div id="dependncias-de-sistema-com-nix">
  ## Системные зависимости с Nix
</div>

Replit поддерживает все языки программирования благодаря интеграции с [Nix](https://nixos.org/). Если вам нужны системные зависимости помимо стандартных пакетов языка, добавьте их в файл [replit.nix](/ru/pt/core-concepts/project-editor/app-setup/configuration#replit-nix-file).

<div id="pacotes-nix">
  ### Пакеты Nix
</div>

Добавляйте системные зависимости, напрямую редактируя `replit.nix`. Доступные пакеты можно найти на [search.nixos.org](https://search.nixos.org/packages).

<div id="mdulos">
  ### Модули
</div>

Модули включают поддержку языков программирования, форматировщиков и пакетных сборщиков. Они составляют основу вашего Replit App. Если вы создаёте Replit App из шаблона или репозитория GitHub, Replit автоматически устанавливает необходимые модули.

Вы можете настраивать модули и другие параметры Nix с помощью файла [.replit](/ru/pt/core-concepts/project-editor/app-setup/configuration#replit-file).

<div id="configurao-do-empacotador">
  ## Настройка менеджера пакетов
</div>

Настроить управление пакетами можно в файле [.replit](/ru/pt/core-concepts/project-editor/app-setup/configuration#replit-file):

| Настройка                             | Описание                                                                        | По умолчанию               |
| ------------------------------------- | ------------------------------------------------------------------------------- | -------------------------- |
| `packager.language`                   | Язык, используемый для работы с пакетами                                        | Определяется автоматически |
| `packager.features.guessImports`      | Автоматически обнаруживать и устанавливать отсутствующие пакеты при запуске Run | `true`                     |
| `packager.features.packageSearch`     | Включить поддержку поиска пакетов                                               | `true`                     |
| `packager.features.enabledForHosting` | Требовать установки пакетов при хостинге                                        | `false`                    |
| `packager.afterInstall`               | Команда, выполняемая после установки пакета                                     | —                          |
| `packager.ignoredPaths`               | Пути, игнорируемые при обнаружении импортов                                     | `[]`                       |
| `packager.ignoredPackages`            | Пакеты, исключаемые из автоматического обнаружения                              | `[]`                       |
