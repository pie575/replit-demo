<div id="assistant-performance-improvements">
  ### Assistant 性能提升
</div>

Assistant 最近的性能提升获得了客户和用户的积极反馈。性能提升让所有 Assistant 用户都能享受更流畅的体验。这些改进与 Agent 的上下文收集相互独立，但可能会影响未来的优化方向。

<div id="agent-reliability-improvements">
  ### Agent 可靠性改进
</div>

我们正逐步推出多项修复，以提升 Agent 的可靠性，包括减少破坏性变更、解决特定 nix 环境中的崩溃问题，以及修复 bash 工具的执行问题。
