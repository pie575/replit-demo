Инструмент «Пользовательские настройки» в редакторе проекта позволяет настроить внешний вид, поведение и
сочетания клавиш для вашей учётной записи.

<Frame>
  <img src="/assets/mirror/user-settings-tool-faae3afb911b.png" alt="снимок экрана инструмента «Пользовательские настройки»" width="4152" height="1894" data-path="images/workspace/user-settings-tool.png" />
</Frame>

<div id="recursos">
  ## Возможности
</div>

Вы можете настроить процесс создания Replit Apps с помощью следующих групп настроек:

* **Персонализация темы**: выберите светлую или тёмную тему для редактора проекта
* **Интеллектуальная работа с кодом**: настройте функции на базе ИИ, которые упрощают создание приложений
* **Параметры редактора**: измените поведение и внешний вид редактора файлов
* **Управление уведомлениями**: настройте параметры оповещений
* **Специальные возможности**: сделайте Replit удобнее для пользователей с особыми потребностями
* **Сочетания клавиш**: задайте комбинации клавиш для частых действий и навигации по интерфейсу

<div id="uso">
  ## Использование
</div>

<Accordion title="Как открыть пользовательские настройки">
  На **панели инструментов** слева:

  1. Нажмите <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="значок «Все инструменты»" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **Все инструменты**, чтобы увидеть список инструментов редактора проекта.
  2. Выберите <img class="icon-svg" src="/assets/mirror/settings-icon-c2664c3691bf.svg" alt="значок настроек" width="16" height="16" data-path="images/icons/settings-icon.svg" /> **Пользовательские настройки**.

  В **строке поиска**:

  1. Нажмите значок лупы <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="значок лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> вверху, чтобы открыть инструмент поиска
  2. Введите «User Settings», чтобы найти инструмент, и выберите его в результатах.
</Accordion>

<div id="aparncia">
  ### Внешний вид
</div>

Настройте следующие параметры внешнего вида редактора проекта:

* **Выбор темы**: выберите одну из готовых светлых и тёмных тем, <a href="https://replit.com/themes" target="_blank">темы сообщества</a> или собственную тему
* **Пользовательские темы**: создавайте собственные цветовые схемы в редакторе [Themes](/ru/pt/features/editor/themes)

<div id="preferncias-do-editor-de-arquivos">
  ### Настройки редактора файлов
</div>

Управляйте внешним видом и поведением редактора файлов с помощью следующих настроек:

* **Размер шрифта**: настройте размер текста для удобства чтения
* **Автозакрытие скобок**: автоматически вставлять закрывающую скобку при вводе открывающей
* **Определение отступов**: автоматически определять параметры отступов при открытии файла
* **Форматировать отступы при вставке**: переформатировать вставленный код в соответствии с правильными отступами
* **Символ отступа**: выберите пробелы или табуляцию для отступов в коде
* **Размер отступа**: задайте количество столбцов для каждого уровня отступа
* **Перенос строк (Wrapping)**: настройте поведение переноса строк
* **Мини-карта**: добавьте на боковую панель обзор кода с возможностью навигации
* **Клавиша-модификатор для множественного выбора**: задайте клавишу-модификатор для выбора нескольких файлов
* **Статус Git в дереве файлов**: отображать индикаторы статуса Git в дереве файлов

<div id="inteligncia-de-cdigo">
  ### Интеллектуальная работа с кодом
</div>

Настройте инструменты на базе ИИ с помощью следующих параметров:

* **Семантические токены**: расширенная подсветка синтаксиса на основе языковых серверов
* **Автодополнение кода с ИИ**: встроенные подсказки кода прямо во время набора
* **Принимать подсказку по символу подтверждения**: автоматическое принятие подсказок кода при вводе определённых символов

<div id="preferncias-de-shell-e-preview">
  ### Настройки Shell и Preview
</div>

Настройте поведение инструментов Shell и Preview:

* **Звуковой сигнал Shell (bell)**: воспроизведение звука при возникновении проблем в инструменте Shell
* **Автоматический Preview**: автоматическое открытие вкладки Preview, когда сервер становится доступен
* **Автоматически перенаправлять открытые порты**: настройка обработки вновь обнаруженных портов

<div id="notificaes">
  ### Уведомления
</div>

Управляйте следующими настройками уведомлений:

* **Звуковое уведомление Agent**: воспроизводить звук, когда Agent запрашивает ваш отзыв
* **Push-уведомление Agent**: получать push-уведомления на телефон, когда Agent запрашивает ваш отзыв

<div id="alertas-de-produo">
  #### Оповещения о продакшене
</div>

**Оповещения о продакшене** — это отдельная настройка уведомлений по электронной почте, которая держит вас в курсе состояния ваших опубликованных приложений. Она не связана с продуктовыми и маркетинговыми рассылками, поэтому вы получаете только важную информацию без лишнего шума.

Включите **Оповещения о продакшене**, чтобы получать письма о следующем:

* **Инциденты доступности**: уведомления о том, что опубликованное приложение недоступно или с трудом остаётся в сети.
* **Уязвимости безопасности**: уведомления об уязвимостях в программном обеспечении, от которого зависит ваше приложение, чтобы вы могли устранить их до появления проблем.
* **Обновления моделей**: уведомления о том, что языковая модель, используемая вашим приложением, изменилась или требует вашего внимания.

<Frame>
  <img src="/assets/mirror/production-alerts-highlight-bb76079f20fd.png" alt="Раздел Production Alerts в настройках уведомлений с красным прямоугольником, выделяющим переключатель писем с оповещениями о продакшене и выпадающий список уровня серьёзности оповещений безопасности" width="2400" height="1364" data-path="images/workspace/production-alerts-highlight.png" />
</Frame>

Как найти эту настройку:

1. Откройте **Настройки** в меню учётной записи.
2. Выберите вкладку **Персонализация**.
3. Прокрутите до раздела **Уведомления по электронной почте** — там находятся **Оповещения о продакшене**.

Если опубликованное приложение использует устаревшую языковую модель, Replit готовит черновик задачи (draft task) для перехода на поддерживаемую модель. Вы получите письмо со ссылкой на задачу и сможете завершить обновление за одну проверку.

<div id="acessibilidade">
  ### Специальные возможности
</div>

Вы можете настроить следующий параметр специальных возможностей:

* **Доступный вывод терминала**: включите поддержку программ чтения с экрана для инструментов Shell и Console

<div id="atalhos-de-teclado">
  ### Сочетания клавиш
</div>

Чтобы открыть настройки сочетаний клавиш, перейдите на вкладку **Сочетания клавиш** в инструменте «Пользовательские настройки».

Искать сочетания клавиш можно следующими способами:

* **По названию**: введите название или описание сочетания клавиш в поле поиска
* **По комбинации клавиш**: нажмите значок <img class="icon-svg" src="/assets/mirror/keyboard-7ba19771b671.svg" alt="значок клавиатуры" width="16" height="16" data-path="images/icons/keyboard.svg" /> и введите комбинацию клавиш

Для управления сочетаниями используйте следующие действия:

* **Добавить**: нажмите **Добавить сочетание**
* **Изменить**: нажмите значок карандаша <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="значок карандаша" width="16" height="16" data-path="images/icons/pencil-icon.svg" />
* **Удалить**: нажмите значок корзины <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="значок корзины" width="16" height="16" data-path="images/icons/trash-icon.svg" />
