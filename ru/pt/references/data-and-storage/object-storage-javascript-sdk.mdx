В этом справочном руководстве описывается класс `Client` из библиотеки `object-storage` и приводятся примеры кода для его методов.

<div id="client">
  ## Клиент
</div>

Класс `Client` обеспечивает взаимодействие с Replit App Storage. Он предоставляет методы для работы с файлами в bucket.

Чтобы импортировать класс из библиотеки, добавьте следующую строку в код JavaScript:

```javascript theme={null}
import { Client } from "@replit/object-storage";
```

Используйте следующий код, чтобы создать экземпляр `Client` для работы с Replit Object Storage:

```javascript theme={null}
const client = new Client();
```

**Возвращает**

`Client`

<div id="copy">
  ### copy
</div>

* **copy**(`objectName`, `destObjectName`): `Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

Копирует объект в пределах того же bucket.
Этот метод перезаписывает любой существующий объект по указанному пути назначения.

**Параметры**

| Имя              | Тип      | Описание                                          |
| :--------------- | :------- | :------------------------------------------------ |
| `objectName`     | `string` | Полный путь к копируемому объекту.                |
| `destObjectName` | `string` | Полный путь, по которому будет скопирован объект. |

**Возвращает**

`Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

***

<div id="uploadfromstream">
  ### uploadFromStream
</div>

* **uploadFromStream**(`objectName`, `stream`, `options?`): `Promise`&lt;`void`&gt;

Загружает объект, считывая его содержимое из указанного потока.
Поток передаёт все ошибки, возникающие во время загрузки. Этот метод перезаписывает существующий объект с тем же именем.

**Параметры**

| Имя          | Тип             | Описание                                                    |
| :----------- | :-------------- | :---------------------------------------------------------- |
| `objectName` | `string`        | Полный путь к объекту назначения.                           |
| `stream`     | `Readable`      | Читаемый поток, из которого считывается содержимое объекта. |
| `options?`   | `UploadOptions` | Настройки операции загрузки.                                |

**Возвращает**

`Promise`&lt;`void`&gt;
