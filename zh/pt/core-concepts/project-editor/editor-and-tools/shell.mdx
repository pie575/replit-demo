title: "Shell"
description: "了解如何使用 Shell 在项目编辑器中运行命令。"
---

Shell 可让你在项目编辑器中执行操作系统任务，例如管理文件、
安装包和运行脚本。它提供了强大的文本界面，可用于
与你的 Replit 环境交互。

你可以使用 Shell 在项目编辑器中执行以下任务：

* 运行脚本和程序
* 安装和运行常用的 Linux 工具和包
* 从互联网上传和下载文件
* 管理项目文件和目录

<Tip>
  为了更好地管理工作流，请优先使用 **运行** 按钮，而不是通过
  Shell 启动你的 App。通过 **运行** 按钮启动的工作流会将输出发送到 Console 工具，
  让你可以结构化地查看日志。
</Tip>

<div id="recursos">
  ## 功能
</div>

Shell 提供以下功能：

* **运行多个 Shell**：打开多个 Shell 实例，以便同时处理不同任务
* **搜索文本**：在 Shell 输出中查找特定文本

<div id="uso">
  ## 使用
</div>

<Accordion title="如何访问 Shell">
  在左侧的**工具停靠栏**中：

  1. 选择 <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="所有工具图标" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **所有工具**，查看项目编辑器中的工具列表。
  2. 选择 <img class="icon-svg" src="/assets/mirror/shell-289d6eb079b0.svg" alt="Shell 图标" width="16" height="16" data-path="images/icons/shell.svg" /> **Shell**。

  在**搜索栏**中：

  1. 选择顶部的 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 放大镜图标，打开搜索工具。
  2. 输入“Shell”查找该工具，然后在搜索结果中选择它。
</Accordion>

<div id="pesquisa-de-texto">
  ### 文本搜索
</div>

请按以下步骤访问和使用文本搜索工具：

1. 选择 Shell 标签页右上角的 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 放大镜图标，打开搜索对话框。
2. 输入搜索词，然后选择 **下一个** 在匹配项之间切换。
3. 使用 **上一个** 返回上一个匹配项。
4. 选择 **退出**，或点击对话框外部以结束文本搜索。

<div id="mltiplos-shells">
  ### 多个 Shell
</div>

要新建 Shell，请点击 **Shell** 标签页左上角的菜单，然后选择 **新建 Shell**，如下图所示：

<Frame>
  <img src="/assets/mirror/shell-new-94a280c1230f.png" alt="选择“新建 Shell”菜单项" width="1280" height="224" data-path="images/workspace/shell-new.png" />
</Frame>

也可通过此菜单在不同 Shell 之间切换。项目编辑器会以每个 Shell 最后执行的命令为其命名，方便您区分。

<Warning>
  打开多个 Shell 后，Replit 会自动关闭空闲的 Shell 实例。
  空闲 Shell 是指未被选中且未运行任何用户进程的 Shell。
</Warning>
