  ## Обновления платформы
</div>

<div id="section-3">
  ### Улучшенные пустые состояния предпросмотра
</div>

Предпросмотр приложений Agent теперь умнее обрабатывает пустые состояния и автоматический запуск, благодаря чему работа с Agent стала ещё удобнее.

<div id="ai">
  ### Снижение задержек AI
</div>

Благодаря улучшениям инфраструктуры время отклика и задержки Replit AI значительно снизились. Взаимодействие с функциями на базе AI по всему Replit, включая Agent и Assistant, стало заметно быстрее.

<div id="github">
  ### Обновлённая вкладка интеграции GitHub
</div>

Вкладка интеграции GitHub получила более аккуратный и единообразный интерфейс. Благодаря новому дизайну подключать репозитории GitHub и управлять ими прямо в рабочей области стало проще и понятнее.

<div id="ios">
  ### Поддержка оплаты в приложении для iOS
</div>

Пользователи iOS теперь могут оформить подписку Replit Core и настроить способ оплаты прямо в мобильном приложении Replit. Так получить доступ к премиум-функциям стало проще даже в дороге.

<div id="stripe-checkout">
  ### Запуск Stripe Checkout
</div>

Новая интеграция со Stripe Checkout делает оплату удобнее и безопаснее для всех разработчиков. Оцените упрощённый процесс покупки: переход на Replit Core теперь занимает считаные секунды благодаря отраслевому стандарту среди платёжных решений.

  ### Упрощённая подготовка учётных записей через SCIM
</div>
