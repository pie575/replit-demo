<div id="agent-mcp">
  ### Agent теперь поддерживает пользовательские MCP-серверы
</div>

Agent теперь может подключаться к удалённым серверам Model Context Protocol (MCP), открывая доступ к новым возможностям и инструментам при минимальной настройке. Это позволяет Agent вызывать внешние инструменты и получать контекст из удалённых систем.

С пользовательскими MCP-серверами вы можете:

* подключаться к удалённым серверам, которые получают контекст из внешних инструментов и выполняют действия;
* получать доступ к сотням инструментов и источников данных через открытый стандарт MCP;
* автоматически загружать инструменты, предоставляемые каждым сервером.

Партнёры могут интегрировать свои сервисы с Agent, просто предоставив MCP-сервер, — дополнительная работа по интеграции не требуется.

<div id="enterprise-plaid">
  ### Коннектор Plaid для Enterprise
</div>

Клиенты Enterprise теперь могут включить коннектор Plaid, чтобы подключать банковские счета и создавать приложения на основе финтех-примитивов. Коннектор активно развивается: с учётом отзывов клиентов в него добавляются новые возможности и улучшения.

Коннектор Plaid позволяет:

* подключать банковские счета к приложениям;
* использовать финтех-примитивы для создания финансовых функций;
* централизованно управлять коннектором через панель администратора.
