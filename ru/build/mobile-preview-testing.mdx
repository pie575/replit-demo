Expo Go — самый быстрый способ просмотреть PixelGames на своём телефоне. Начните с него, а затем перейдите на
TestFlight или Internal Testing, когда возможностей Expo Go станет недостаточно.

<div id="what-is-expo">
  ## Что такое Expo?
</div>

Expo — это набор инструментов, который Agent использует для создания PixelGames. Он позволяет Agent один раз написать приложение на
JavaScript и запускать этот же код как полноценное приложение для iOS и Android.

Expo Go — бесплатное приложение из App Store или Google Play. Установите его один раз — и сможете просматривать
любой проект Expo, включая PixelGames, просто сканируя QR-код.

<Steps>
  <Step title="Откройте Expo Go">
    Откройте приложение **Expo Go** на телефоне (iOS или Android).
  </Step>

  <Step title="Отсканируйте QR-код">
    Отсканируйте QR-код, который Replit показывает на панели Preview.
  </Step>

  <Step title="Дождитесь загрузки">
    Metro, сборщик Expo, упаковывает PixelGames и отправляет его на телефон. Первая
    загрузка может занять одну-две минуты, но в дальнейшем всё будет быстрее.
  </Step>

  <Step title="Попробуйте приложение">
    PixelGames откроется на телефоне. Изменения от Agent появятся через несколько секунд — без
    переустановки.
  </Step>
</Steps>

<div id="what-expo-go-cannot-test">
  ## Что нельзя протестировать в Expo Go
</div>

Expo Go позволяет проверить экраны, сценарии и UI. Некоторые функции работают только тогда, когда PixelGames запускается как
отдельное приложение на телефоне: чаще всего это **push-уведомления**, **встроенные покупки** и **вход через Apple**.

Чтобы протестировать их, загрузите PixelGames в Apple или Google, а затем установите приложение из их канала бета-тестирования.
Ваше приложение останется доступным только вам и приглашённым тестировщикам, и вы сможете
дорабатывать его до публичного релиза.

* [Загрузите приложение для iOS](/ru/build/mobile-upload-ios)
* [Загрузите приложение для Android](/ru/build/mobile-upload-android)

<div id="troubleshooting">
  ## Устранение неполадок
</div>

* **QR-код не сканируется или App не подключается:** убедитесь, что телефон и компьютер подключены к
  одной сети Wi‑Fi: некоторые корпоративные и общедоступные сети блокируют соединение между ними. В
  такой сети попросите Agent запустить App в режиме туннелирования.
* **Изменения не отображаются на телефоне:** встряхните телефон, чтобы открыть меню разработчика Expo,
  затем нажмите **Reload**, чтобы повторно скачать PixelGames.
* **Красный экран с ошибкой:** обычно это ошибка JavaScript или отсутствующий пакет. Сообщение часто
  указывает на точный файл и строку — отправьте его Agent и попросите исправить проблему.
* **Работает на iOS, но не на Android (или наоборот):** вставьте ошибку в Agent и укажите,
  на какой платформе она возникает.
* **Shell Console выглядит неисправной на одном устройстве:** попросите Agent проверить обработку
  размера экрана или безопасной области на этом устройстве.
