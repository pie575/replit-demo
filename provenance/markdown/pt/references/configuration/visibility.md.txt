# Visibilidade do Projeto

> Saiba quem pode ver o seu Projeto no Replit e como gerenciar o acesso nos seus espaços de trabalho pessoais ou colaborativos.

O seu Projeto é visível apenas para pessoas e grupos que você convidar explicitamente. Se você quiser compartilhar o projeto publicamente, publique-o como público para compartilhar a versão publicada com qualquer pessoa que tenha o URL.

Para espaços de trabalho de organização, o [gerenciamento de acesso](/pt/teams/identity-and-access-management/repl-access-management) e as configurações de administrador também se aplicam.

## Visibilidade ao criar um Projeto

Quando você cria um Projeto em um espaço de trabalho, os membros desse espaço terão acesso a esse Projeto. Adicione colaboradores e ajuste quem pode ver o projeto em **Acesso** e compartilhamento.

Para o conjunto completo de controles de organização, consulte [Gerenciamento de acesso](/pt/teams/identity-and-access-management/repl-access-management) e [grupos e permissões](/pt/teams/identity-and-access-management/groups-and-permissions).
