<div id="assistant-performance-improvements">
  ### Assistant 성능 개선
</div>

최근 Assistant에 적용된 성능 개선에 대해 고객과 사용자로부터 긍정적인 피드백을 받았습니다. 향상된 성능 덕분에 모든 Assistant 사용자가 더욱 매끄러운 경험을 누릴 수 있습니다. 이번 개선 사항은 Agent의 Context 수집과는 별개이지만, 향후 최적화 작업에 영향을 줄 수 있습니다.

<div id="agent-reliability-improvements">
  ### Agent 안정성 개선
</div>

Agent 안정성을 높이기 위한 여러 수정 사항이 순차적으로 적용되고 있습니다. 호환성을 깨뜨리는 변경(breaking change) 감소, 문제가 있던 nix 환경에서 발생하던 충돌 해결, bash 도구 실행 관련 문제 수정 등이 포함됩니다.
