<div id="importar-do-bolt">
  ## Импорт из Bolt
</div>

⏰ *Примерное время: четыре минуты*

<Warning>В настоящее время Agent поддерживает импорт из Bolt для приложений Vite + React.</Warning>

Чтобы импортировать проект из Bolt в Replit, экспортируйте его в GitHub, а затем импортируйте этот репозиторий.

Подробнее обо всех вариантах импорта, включая другие платформы, такие как GitHub, Figma и Lovable, см. в [документации по функции импорта](/ru/pt/references/workspace/import).

<div id="antes-de-comear">
  ## Перед началом
</div>

* Проект Bolt, который можно экспортировать
* Учётная запись GitHub, подключённая к Bolt
* Учётная запись Replit

<div id="etapas-de-importao">
  ## Шаги импорта
</div>

1. Экспортируйте проект из Bolt в GitHub.
2. Откройте [replit.com/import](https://replit.com/import).
3. Выберите **Bolt**.
4. Подключите учётную запись GitHub.
5. Выберите экспортированный репозиторий Bolt.
6. Выберите **Импортировать**.

<div id="what-gets-imported">
  ## Что импортируется
</div>

Replit импортирует из вашего проекта {platform_1}:

* **Код**: логика приложения и исходные файлы
* **Дизайн и стили**: компоненты UI и правила оформления
* **Ресурсы**: изображения, иконки и статические файлы
* **Логика бэкенда**: серверная функциональность, если она есть
* **Схема базы данных**: структура таблиц, если она есть

<div id="what-is-not-imported">
  ## Что не импортируется
</div>

* **Данные Supabase**: Существующие записи в базе данных не переносятся
* **Secrets**: Переменные окружения и API-ключи необходимо добавить отдельно

Используйте Agent, чтобы восстановить недостающие функции, добавить секреты и воссоздать данные в базе данных.
