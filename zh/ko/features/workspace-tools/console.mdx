使用 Console，你可以实时监控并查看正在运行的 Replit 应用所输出的日志。
借助当前和历史运行的信息，你可以了解应用的行为、
排查错误并优化性能。

<Tip>
  使用 Agent 调试时，请在提示词中附上控制台日志，以便提供上下文。
</Tip>

<div id="section">
  ## 功能
</div>

Console 提供以下工具，帮助你了解应用的运行情况：

* **实时日志**：实时查看应用的输出
* **AI 辅助**：针对日志中报告的错误获取修复建议
* **运行记录**：显示以往运行的日志，便于追踪变更

<div id="section-2">
  ## 使用方法
</div>

你可以在 Project Editor 中直接访问 Console 工具。

<Accordion title="访问 Console 的方法">
  在左侧的 **工具坞** 中：

  1. 选择 <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="所有工具图标" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **所有工具**，查看 Project Editor 的工具列表。
  2. 选择 <img class="icon-svg" src="/assets/mirror/console-8a41ac90789c.svg" alt="Console 图标" width="16" height="16" data-path="images/icons/console.svg" /> **Console**。

  在 **搜索栏** 中：

  1. 选择顶部的 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 放大镜，打开搜索工具
  2. 输入“Console”查找该工具，并在结果中选择它。
</Accordion>

每次在 Replit 应用中点击 **Run** 按钮时，Console 都会新增一条条目，其中包含：

* 运行代码所用的 Command
* 时间戳信息
* 标准输出和错误日志

下方截图展示了用于启动应用的 `npm run dev` 命令以及运行日志信息：

<div id="ai">
  ### AI 驱动的调试
</div>

在日志中发现想要深入了解的错误或信息时，请点击该条目顶部的
**Ask AI** 按钮。此操作会自动打开 **Agent** 标签页，
并将日志内容提交给它进行分析。

<div id="section-3">
  ### 日志条目命令
</div>

Console 提供以下日志管理工具：

* **Show Only Latest**：将此控件切换为**开启**后，仅显示最近一次运行的日志。
* **折叠条目**：选择命令名称左侧的 <img class="icon-svg" src="/assets/mirror/down-arrow-9c1cf9fd152e.svg" alt="向下箭头图标" height="16" width="16" data-path="images/icons/down-arrow.svg" /> 向下箭头，即可隐藏日志。
* **清除历史运行**：选择此项可删除历史运行的日志。此操作无法撤销。

<div id="section-4">
  ### 网络可用性
</div>

你可以控制开发版本应用的在线可用性。

若要停止处理发往开发 URL 的请求，请选择网络信息行右侧的
<img class="icon-svg" src="/assets/mirror/network-off-5bdca8a4fe4e.svg" alt="网络关闭图标" height="16" width="16" data-path="images/icons/network-off.svg" /> 带斜线的地球图标。

若要重新启用，请选择 <img class="icon-svg" src="/assets/mirror/network-on-15be2e5fb4f5.svg" alt="网络开启图标" height="16" width="16" data-path="images/icons/network-on.svg" /> 地球图标。

若要查看开发 URL，请选择地址栏中的 `{...}.replit.dev` 文本。

<Frame>
  <img src="/assets/mirror/preview-dev-url-b36770b33769.png" alt="Preview 开发 URL 位置" width="1222" height="824" data-path="images/workspace/preview-dev-url.png" />
</Frame>

<Note>
  即使已设置为停止处理发往开发 URL 的请求，你仍然可以在 Preview 标签页中访问该应用。
</Note>

<div id="section-5">
  ### 停止工作流命令
</div>

你可以在 Project Editor 的 Console 工具中停止正在运行的工作流命令。

点击 Replit 应用运行命令所在行右侧的方形按钮即可终止。

如需重新启动应用，请使用 Project Editor 顶部的工作流 **Run** 按钮。
