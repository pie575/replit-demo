# 후속 태스크

> 태스크가 끝난 후 Agent의 후속 태스크 제안을 검토하고, 시작하고, 일괄 관리하세요.

## 후속 태스크 제안

태스크를 적용하면 Agent는 프로젝트 컨텍스트를 검토하고 다음에 구축할 수 있는 **후속 태스크**를 제안합니다. **제안된 다음 태스크** 대화상자는 최상위 추천을 인라인으로 표시하므로 메인 스레드를 벗어나지 않고도 계속 진행할 수 있습니다.

</Frame>

후속 제안에는 다음이 포함될 수 있습니다:

* **구축할 새 기능**: 방금 배포한 것과 자연스럽게 어울리는 기능
* **성능 개선**: Agent가 태스크 작업 중에 발견한 최적화
* **사용자 경험 개선**: 기능을 완성하는 다듬기와 개선 사항

제안을 백그라운드로 보내려면 **시작**을 선택하고, 제안된 작업을 먼저 검토하려면 **계획 보기**를 선택하세요. 모든 제안을 보려면 **태스크 보드에서 더 보기**를 선택하세요. 제안된 후속 태스크는 **초안** 열의 **제안됨** 아래에 표시됩니다.

<Frame>
  <img src="https://mintcdn.com/replit/FNdcdDWMlaG_MW3N/images/agent/follow-up-tasks-kanban.png?fit=max&auto=format&n=FNdcdDWMlaG_MW3N&q=85&s=9fe3a787c8b214b99261921a22d26240" alt="초안 열의 제안됨 아래에 많은 후속 태스크 제안을 보여주는 태스크 보드" width="980" height="627" data-path="images/agent/follow-up-tasks-kanban.png" />
</Frame>

**제안된 다음 태스크** 대화상자를 닫으면 제안이 취소됩니다. 메인 버전에 이미 제안된 계획이 대기 중일 때는 Agent가 대화상자를 표시하지 않으므로 두 프롬프트가 주의를 두고 경쟁하지 않습니다.

## 여러 제안을 한 번에 관리하기

후속 제안이 많은 프로젝트의 경우 태스크 보드를 열고 **초안** 열에서 **편집**을 선택하세요. 편집 모드에서는 제안된 각 태스크에 체크박스가 표시됩니다. 원하는 태스크를 선택한 다음 **시작** 또는 **취소**를 사용하여 선택한 모든 태스크에 해당 작업을 적용하세요. 편집 모드를 종료하려면 **완료**를 선택하세요.
