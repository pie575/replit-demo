## Plateforme

### Paiements intégrés Stripe pour les utilisateurs Core

Intégrez Stripe directement dans vos applications en un seul clic. Agent configure les paiements et les abonnements avec une synchronisation en temps réel vers la base de données pour les statuts d'abonnement, vous permettant de vous concentrer sur la création de votre produit plutôt que sur l'assemblage de l'infrastructure de paiement.

[En savoir plus sur l'intégration des paiements Stripe](/fr/features/monetization/stripe-payments)

### Meilleur classement dans les moteurs de recherche pour les domaines personnalisés

Lorsque vous associez un domaine personnalisé à votre application publiée, les moteurs de recherche n'indexent désormais que votre domaine personnalisé—pas votre sous-domaine `replit.app`. Cela évite les pénalités de contenu dupliqué et aide votre application à mieux se classer dans les résultats de recherche.

[En savoir plus sur les domaines personnalisés](/fr/features/publishing/custom-domains)
