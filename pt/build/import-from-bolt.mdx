## Importar do Bolt

⏰ *Tempo estimado: quatro minutos*

<Warning>O Agent atualmente suporta importações do Bolt para apps Vite + React.</Warning>

Importe um projeto do Bolt para o Replit exportando-o para o GitHub e depois importando esse repositório.

Para opções de importação abrangentes incluindo outras plataformas como GitHub, Figma e Lovable, consulte a [documentação do recurso de Importação](/pt/references/workspace/import).

## Antes de começar

* Um projeto do Bolt que você pode exportar
* Uma conta do GitHub conectada ao Bolt
* Uma conta no Replit

## Etapas de importação

1. Exporte seu projeto do Bolt para o GitHub.
2. Abra [replit.com/import](https://replit.com/import).
3. Selecione **Bolt**.
4. Conecte sua conta do GitHub.
5. Selecione o repositório do Bolt exportado.
6. Selecione **Import**.

## What gets imported

Replit imports the following from your {platform_1} project:

* **Code**: Application logic and source files
* **Design and styles**: UI components and styling rules
* **Assets**: Images, icons, and static files
* **Backend logic**: Server-side functionality, if present
* **Database schema**: Table structure, if present

## What is not imported

* **Supabase data**: Existing database records are not migrated
* **Secrets**: Environment variables and API keys must be added separately

Use Agent to rebuild missing functionality, add secrets, and recreate database data.
