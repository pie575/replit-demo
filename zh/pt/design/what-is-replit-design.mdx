Replit Design 让你定义软件的外观与质感。你只需描述想要的效果，Replit Design 就会生成可交互的原型，供你探索和打磨。当某个方案符合预期时，它便可在同一项目中变成一个可运行的应用。

<div id="comece-do-zero-ou-importe-designs-existentes">
  ## 从零开始，或导入已有设计
</div>

前往 [Replit Design](https://replit.com/design)，或在 workspace 主页的创建框下方选择 **Design**。有四种入门方式：

* **[提示词](/zh/pt/design/design-your-first-screen)**：描述你想要的效果，生成第一批 frame。
* **[模板](/zh/pt/design/start-from-a-template)**：从预置的 landing page、海报、社交媒体帖子、移动端界面或原型开始，再进行 Remix。
* **[Import](/zh/pt/design/import-figma-designs-into-replit-design)**：从 Figma 或 [Claude](/zh/pt/design/import-claude-designs-into-replit-design) 导入设计，或[根据网址](/zh/pt/design/import-a-website-into-replit-design)或截图重建一个网站。
* **[design system](/zh/pt/design/design-systems-explained)**：从已保存的设计系统开始，让第一个 frame 就符合品牌规范。

<div id="explore-variantes">
  ## 探索多种方案
</div>

在确定方向之前，先尽可能拓展思路。每个结果都会生成一个新的 frame，因此任何一个方向都不会丢失。

* **[建议](/zh/pt/design/explore-suggestions)**：选中一个 frame，Replit Design 会提出接下来可以尝试的方向，点击一次即可尝试一种。
* **[换一个模型](/zh/pt/design/explore-with-different-models)**：更换 Design 背后的模型，用同样的需求说明就能得到截然不同的方向。

<div id="refine">
  ## Refine
</div>

用你觉得最自然的方式打磨胜出的方案：

* **[Chat](/zh/pt/design/chat-about-your-design)**：用自己的话向 Agent 描述需求，可以针对整块画布，也可以一次针对一个 frame。
* **[Visual Editor](/zh/pt/design/visual-editor)**：点击任意元素，直接调整文本、颜色、间距和图片。简单的编辑会即时应用到源代码，且不消耗积分。
* **[Draw](/zh/pt/design/toolbar#draw)**：圈出问题、用箭头指向想说明的元素、贴一张便签，Agent 会读懂你的标注。
* **[生成资源](/zh/pt/design/toolbar#generate)**：生成设计所需的图片、视频片段和矢量图形，并可附上参考素材，让它们与项目的整体风格保持一致。

<div id="construa">
  ## Build
</div>

当某个 frame 调整满意后，把它交给 Agent。这里的 design 从来都不只是一张图片，而是真实软件的规格说明。

* **[构建你的 design](/zh/pt/design/build-your-design)**：将 frame 变成一个可运行的全新 App。
* **[为现有 App 换新样式](/zh/pt/design/frames#build)**：把 frame 的外观应用到你已有的 App 上。

<Frame caption="选中 frame 后操作栏中的 Build 操作。">
  <img src="/assets/mirror/build-design-c5093018b02b.png" alt="选中 frame 的操作栏，包含 Build 和 Focus 操作" width="1124" height="326" data-path="images/design/replit-design/build-design.png" />

  从 design frame 构建新的 App 需要 Core 或 Pro 套餐；Design 的其他所有功能在任意套餐下均可使用。有关套餐的详细信息，请参阅[计费](/zh/pt/billing/ai-billing)。
</Note>

<div id="escale">
  ## 规模化
</div>

让下一次设计比上一次更快:

* **[创建设计系统](/zh/pt/design/create-a-design-system)**:从你喜欢的设计中提取配色、字体排版、token 和组件,或用一段 提示词 从零生成一套。
* **以它为起点开展新工作**:新的 artifact 从第一个 frame 起就符合品牌规范。
* **[将已有应用接入该系统](/zh/pt/design/apply-design-system)**:重塑现有应用的样式,让整体风格统一。
* **切换系统**:按项目选择或更换设计系统。

从这里,流程又回到 **Start**,而现在每一次设计从一开始就符合品牌规范。

<div id="quando-comear-no-design-vs-no-build">
  ## 何时从 Design 开始，何时从 Build 开始
</div>

Design 和 Build 是进入同一项目的两个入口。Build 是 Agent 让软件跑起来的地方，Design 则是你打磨外观的地方。你在 Design 中的成果不会被锁死在某个设计工具里。

* 当外观是难点时，从 **Design** 开始：先探索多个方向，再把胜出的方案构建出来。
* 当功能行为是难点时，从 **Build** 开始：先让它跑起来，再到 Replit Design 里重新调整样式。
