Исследуйте широко, дорабатывайте детально. Когда фрейм приблизится к желаемому результату, два инструмента помогут точно настроить его так, как вам удобно:

* Общайтесь с Agent своими словами — о фрейме целиком или отдельном элементе
* Настраивайте элементы напрямую в Visual Editor. Простые изменения применяются мгновенно и не расходуют кредиты

<div id="section">
  ## Чат
</div>

Сформулируйте для Agent задачу так, как вы дали бы дизайнеру комментарии на промежуточном ревью. Выберите фрейм и опишите изменения в основном чате (*«сделайте цвета теплее»*, *«главный экран выглядит пустым»*) или выберите инструмент **Chat** на панели инструментов и нажмите элемент, чтобы ограничить контекст сообщения этим элементом.

Подробнее об обоих способах — в разделе [Чат](/ru/ko/design/chat-about-your-design).

<div id="visual-editor">
  ## Visual Editor
</div>

Если вы точно знаете, чего хотите, пропустите 프롬프트. Выберите инструмент **Edit** на панели инструментов и щёлкните элемент — откроется Visual Editor с доступными для редактирования свойствами этого элемента: содержимым, раскладкой, цветами, границами и т. д. Простые изменения, например редактирование текста, выбор цвета или настройка отступов, не расходуют кредиты и сразу применяются к исходному коду.

<div id="section-2">
  ## Что выбрать
</div>

| Вам нужно…                                                                           | Инструмент    |
| ------------------------------------------------------------------------------------ | ------------- |
| Описать желаемый результат и поручить Agent проработать детали                       | чат           |
| Изменить текст, цвет, отступы или изображение элемента, используя известные значения | Visual Editor |
| Переработать структуру или поведение раздела                                         | чат           |
| Быстро внести изменения, не расходуя кредиты                                         | Visual Editor |

Эти инструменты естественно дополняют друг друга. Сначала задайте направление в чате, а затем доработайте детали в Visual Editor.
