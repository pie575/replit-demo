ChatGPT의 Replit integration을 사용하면 별도의 설정 없이 대화에서 바로 Replit Apps를 생성하고, 업데이트하고, 확인할 수 있습니다. ChatGPT와 대화하며 실제 앱을 만들고, 나머지는 Agent에게 맡기세요.

<div id="what-is-replit-in-chatgpt">
  ## ChatGPT의 Replit란
</div>

ChatGPT의 Replit는 ChatGPT 대화를 Replit의 강력한 개발 플랫폼과 연결해 줍니다. 만들고 싶은 것을 설명하기만 하면 Agent가 완전히 동작하는 Replit App을 만들어 줍니다. 앱이 생성된 후에는 ChatGPT에 요청해 앱을 수정하거나 업데이트하거나 분석할 수 있으며, 이 모든 과정이 자연스러운 대화로 이루어집니다.

<div id="getting-started">
  ## 시작하기
</div>

다음 단계에 따라 Replit을 ChatGPT에 연결하고 첫 번째 앱을 만들어 보세요.

<div id="connect-replit-to-chatgpt">
  ### Replit을 ChatGPT에 연결하기
</div>

Replit은 두 가지 방법으로 ChatGPT에 연결할 수 있습니다:

<Accordion title="Settings에서 연결하기">
  1. ChatGPT에서 프로필 icon을 클릭합니다 2. **Settings** → **Apps &amp;
     Connectors**로 이동합니다 3. **Replit**을 찾아 **Connect**를 클릭합니다 4. Replit account로 OAuth
     인증을 완료합니다
</Accordion>

<Accordion title="conversa에서 연결하기">
  1. ChatGPT에서 새 conversa를 시작합니다 2. 아래 방법 중 하나로 Replit을 호출합니다
     3. 아직 연결되어 있지 않다면 ChatGPT가 OAuth flow를 안내해 줍니다
</Accordion>

<div id="invoke-replit-in-chatgpt">
  ### ChatGPT에서 Replit 호출하기
</div>

연결이 완료되면 다음 세 가지 방법으로 Replit을 호출할 수 있습니다.

| 방법      | 사용 방법                               |
| ------- | ----------------------------------- |
| 직접 멘션   | 메시지 맨 앞에 `Replit, <request>` 입력     |
| 슬래시 명령어 | 입력창에 `/Replit` 입력                   |
| 입력창 메뉴  | **+** 버튼 → **More** → **Replit** 클릭 |

<div id="create-your-first-app">
  ### 첫 번째 앱 만들기
</div>

연결이 끝났다면 첫 번째 Replit App을 만들어 보세요:

1. ChatGPT에서 새 대화를 시작합니다
2. Replit을 호출하고 만들고 싶은 것을 설명합니다(예: &quot;Replit, 다크 모드가 있는 할 일 앱을 만들어 줘&quot;)
3. Agent가 앱을 생성하고 자동으로 게시합니다
4. 완료되면 앱을 확인할 수 있는 링크를 받게 됩니다

<Note>
  대화 하나당 하나의 Replit App만 다룰 수 있습니다. 같은 대화에서 새 앱을 만들면 기존 앱이
  수정됩니다. 여러 앱을 만들려면 대화를 따로 시작하세요.
</Note>

<div id="features">
  ## 기능
</div>

* **[Replit AI](/ko/welcome)**: Agent가 자연어 요청에 따라 앱을 생성하고 게시합니다
* **[Project Editor](/ko/learn/projects-and-artifacts/project-editor)**: ChatGPT에서 바로 사용할 수 있는 완전한 개발 환경
* **[Publishing](/ko/learn/projects-and-artifacts/replit-deployments)**: 앱이 자동으로 배포되어 바로 공유할 수 있습니다

<Accordion title="할 수 있는 일">
  **생성:** 원하는 내용을 설명하기만 하면 새로운 Replit Apps를 빌드할 수 있습니다. Agent가 애플리케이션을 만들고 자동으로 게시합니다.

  **업데이트:** 현재 대화에서 앱을 수정하세요. ChatGPT에 기능 추가, 버그 수정, 변경을 요청하면 Agent가 이를 반영합니다.

  **검사:** 변경 없이 앱을 분석하세요. 코드 구조, 파일 경로, 동작에 대한 정보를 확인할 수 있습니다.
</Accordion>

<Accordion title="지원되는 파일 형식">
  prompt에 다양한 파일 형식을 포함할 수 있습니다:

  | 형식         | 지원 여부                 |
  | ---------- | --------------------- |
  | PDF        | 예                     |
  | CSV        | 예                     |
  | 일반 문서 형식   | 예                     |
  | 이미지(원본 파일) | 아니요(대신 public URL 사용) |
  | 동영상(원본 파일) | 아니요(대신 public URL 사용) |

  <Note>
    앱에 이미지나 동영상을 넣으려면 prompt에 public URL을 입력하세요. 앱이 생성된 후 Replit에서 직접 미디어 파일을 추가할 수도 있습니다.
  </Note>
</Accordion>

<Accordion title="빌드 시간">
  Agent가 앱을 빌드하는 데 걸리는 일반적인 시간은 다음과 같습니다:

  | 앱 복잡도                                | 일반적인 빌드 시간 |
  | ------------------------------------ | ---------- |
  | 단순(계산기, 간단한 landing page)            | 2~3분       |
  | 복잡(게임, 화려한 애니메이션, 정보량이 많은 dashboard) | 3~4분       |
</Accordion>

  | -------------- | ----- | -------------------------------------------------- |

  | Plus           | 예     |                                                    |

<div id="billing-and-credits">
  ## 결제 및 credits
</div>

ChatGPT에서 Replit이 수행한 작업은 Replit 계정에 Replit Agent usage로 청구됩니다.

<Accordion title="결제 작동 방식">
  * **Core** 및 **Pro** plan에는 allowance 범위 내에서 Agent, publishing, 데이터베이스 사용량을 충당하는 월별 credits가 제공됩니다
  * 6개월 후 만료되고 자동 갱신되지 않는 **credit packs**를 구매할 수 있습니다 — launch 시점의 사용량 급증이나 실험에 적합합니다
  * Replit의 billing 설정에서 **usage limits**와 **예산**을 활용해 지출을 제한하세요

  자세한 내용은 [AI 결제 문서](/ko/billing/ai-billing)를 참조하세요.
</Accordion>

<div id="current-limitations">
  ## 현재 제한 사항
</div>

현재 ChatGPT의 Replit 앱에는 다음과 같은 제약이 있습니다.

* 해당 conversa에서 생성한 앱에서만 작업할 수 있습니다
* 다음 앱은 열거나 수정할 수 없습니다:
  * 다른 ChatGPT threads에서 생성한 앱
  * Replit에서 직접 만든 앱

전체 Replit 환경과 동일한 수준의 기능(database, secret 관리, 더 고급 Project Editor 제어 기능)은 추후 제공될 예정입니다.

<div id="troubleshooting">
  ## 문제 해결
</div>

<Accordion title="Browse apps에 Replit이 표시되지 않는 경우">
  **Browse apps**에 Replit이 보이지 않는다면 다음을 확인하세요.

  * 해당 지역에서 앱을 사용할 수 있는지
  * workspace admin이 Replit 앱을 활성화했는지(Business/Enterprise/Edu)
</Accordion>

<Accordion title="빌드 실패">
  빌드가 실패하면 Replit에서 앱을 열고 다음을 시도하세요.

  * usage와 billing 확인
  * checkpoints와 rollback으로 이전 상태로 되돌리기
  * Project Editor에서 Agent에게 바로 도움 요청
</Accordion>
