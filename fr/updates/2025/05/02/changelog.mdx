<div id="replit-auth">
  ### Replit Auth
</div>

[Replit Auth](/fr/features/auth-and-identity/authentication) est disponible pour tous les utilisateurs ! Il s&#39;agit d&#39;un système d&#39;authentification intégré qui vous permet d&#39;ajouter la connexion utilisateur à vos applications avec une configuration minimale. Plutôt que de développer des systèmes d&#39;authentification complexes en partant de zéro, Replit Auth offre une solution sécurisée et prête à l&#39;emploi, intégrée à l&#39;infrastructure de Replit.

**Fonctionnalités clés :**

* **Aucune configuration** - Ajoutez l&#39;authentification avec un simple prompt dans Agent
* **Sécurité intégrée** - S&#39;appuie sur l&#39;infrastructure de Replit, avec des protections contre les attaques courantes
* **Gestion des utilisateurs** - Administration des utilisateurs simplifiée via le volet Auth
* **Intégration à la base de données** - Création automatique des entrées utilisateur dans votre base de données
* **Page de connexion personnalisable** - Personnalisez l&#39;expérience de connexion de votre application
* **Réinitialisation du mot de passe** - Replit gère les e-mails de réinitialisation de mot de passe, ce qui vous évite de recourir à votre propre provider d&#39;envoi d&#39;e-mails

Pour démarrer, rien de plus simple : mentionnez Replit Auth dans votre prompt Agent :

<AiPrompt>
  Aide-moi à créer une application qui [votre idée d&#39;application] et qui doit intégrer Replit Auth.
</AiPrompt>

  ### Politique de suspension UBB mise à jour
</div>

Nous avons amélioré notre système de délai de grâce pour les paiements afin de mieux accompagner les utilisateurs de longue date tout en protégeant leurs deployments. Ces utilisateurs disposent désormais de plus de temps pour résoudre les problèmes de paiement, ce qui permet aux applications critiques de rester en ligne pendant la mise à jour des informations de paiement.
