SEO Agent выполняет технический SEO-аудит всего проекта и выявляет проблемы, из-за которых поисковые системы и ИИ-краулеры не могут находить и понимать App. Для каждой выявленной проблемы предлагается исправление в один клик, которое можно проверить и применить вместе с Agent.

SEO Agent находится на панели **Growth** в Project Editor и работает с уже опубликованными App. Для большинства разработчиков рабочий процесс выглядит так: опубликовать App, открыть SEO Agent, запустить сканирование, проверить результаты и применить исправления.

<div id="seo-agent">
  ## Возможности SEO Agent
</div>

SEO Agent сосредоточен на **техническом SEO** — структурных и машиночитаемых аспектах App, от которых зависит, насколько легко поисковые системы и ИИ-краулеры могут находить, индексировать и понимать App.

Он проверяет проект и предлагает исправления для таких проблем, как:

* **Сканирование и индексация**: `robots.txt`, `sitemap.xml`, а также доступные для сканирования ссылки и структура страниц.
* **Метаданные страниц**: уникальные и содержательные теги `<title>` и метаописания для всех страниц.
* **Структурированные данные**: разметка JSON-LD, которая помогает поисковым системам показывать расширенные результаты.
* **Open Graph и социальные теги**: метаданные, управляющие предпросмотром ссылок при публикации.
* **Семантическая разметка**: правильная иерархия заголовков, элементы-ориентиры и описательный текст `alt` для изображений.

<Note>
  SEO Agent помогает убедиться, что созданный вами App технически оптимизирован для поиска,
  но не пишет контент и не формирует тематическую авторитетность.
</Note>

<div id="section">
  ## Перед началом
</div>

Для использования SEO Agent необходимо следующее:

* **Опубликованное App.** SEO Agent проверяет веб-деплои, доступные в интернете, поэтому, если вы ещё не опубликовали App, сделайте это сначала. Подробнее о развёртывании с поддержкой SEO см. в разделе [SEO-оценка](/ru/ja/features/publishing/seo-rating).
* **Платный план.** SEO Agent доступен разработчикам с платным планом. Если у вас бесплатный план, на панели Growth будет доступна возможность обновления.

Доступ к SEO Agent можно получить двумя способами: откройте панель **Growth** непосредственно в Project Editor или выберите **Optimize SEO with Agent** рядом с SEO-оценкой в инструменте **Publishing** — откроется панель Growth, готовая к сканированию.

</Tip>

<div id="seo-agentseo">
  ## SEO Agent и SEO-оценка
</div>

**SEO-оценка**, отображаемая рядом с SEO Agent, рассчитывается на основе автоматического [аудита Lighthouse](/ru/ja/features/publishing/seo-rating), который запускается при каждой публикации, и оценивает App как Healthy, Needs Work или Weak. Эта оценка отражает *текущее состояние App*.
SEO Agent помогает *улучшить её*: он сканирует проблемы и применяет исправления. После повторной публикации оценка обновится.

Вы также можете полностью пропустить интерфейс сканирования и напрямую попросить Agent выполнить эту задачу.

<AiPrompt>
  Проведи SEO-аудит моего сайта и примени необходимые исправления. Добавь sitemap,
  robots.txt, теги Open Graph, структурированные данные там, где это уместно, и убедись,
  что у каждой страницы есть уникальные title и meta description.
</AiPrompt>
