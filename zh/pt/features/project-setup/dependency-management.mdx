Replit 提供了多种为 Replit App 安装和管理软件包的方式。你可以使用 [Shell](/zh/pt/features/workspace-tools/shell) 安装软件包，也可以交给 [Agent](/zh/pt/features/agent/overview/) 处理，或者在运行 Replit App 时由 Replit 自动检测并安装缺失的依赖。

<div id="instale-pacotes-usando-o-shell">
  ## 使用 Shell 安装软件包
</div>

在 Project Editor 中打开 **Shell** 工具，然后根据所用语言的包管理器运行相应命令：

<CodeGroup>
  ```bash Node.js (npm) theme={null}
  npm install <package-name>
  ```

  ```bash Node.js (pnpm) theme={null}
  pnpm add <package-name>
  ```

  ```bash Python (poetry) theme={null}
  poetry add <package-name>
  ```

  ```bash Python (pip) theme={null}
  pip install <package-name>
  ```

  ```bash Ruby theme={null}
  bundle add <gem-name>
  ```
</CodeGroup>

你也可以使用 Replit 的 [Universal Package Manager (UPM)](https://github.com/replit/upm/) 为所有受支持的语言安装软件包：

```bash theme={null}
upm add <package-name>
```

安装特定版本：

```bash theme={null}
upm add 'flask==2.3.3'
```

要查看所有受支持的语言和包管理器，请参阅 [UPM: Supported Languages](https://github.com/replit/upm/#supported-languages)。

<div id="instale-pacotes-usando-o-agent">
  ## 使用 Agent 安装软件包
</div>

你可以直接在 Chat 中让 [Agent](/zh/pt/features/agent/overview/) 帮你安装软件包。例如：

* “Install the axios package”
* “Add Flask and SQLAlchemy to my project”
* “Set up TailwindCSS”

Agent 会使用适合你项目的包管理器安装该软件包，并更新相关配置文件。

<div id="deteco-automtica-de-importaes">
  ## 自动导入检测
</div>

每次选择 **Run** 时，Replit 都会自动分析你的代码，查找缺失的依赖项。如果代码中导入了尚未安装的包，Replit 会检测到并自动安装最新版本。

例如，在 `main.py` 中添加 `import flask` 后，下次选择 **Run** 时，**Console** 中会显示一条消息，提示正在安装 **Flask**。

<Note>
  你可以在 [.replit](/zh/pt/features/project-setup/configuration#replit-file) 文件中通过 `packager.features.guessImports` 设置来配置自动导入检测。
</Note>

<div id="substitua-a-deteco-automtica">
  ### 覆盖自动检测
</div>

如果检测到的包不正确，或者你需要指定版本，请在 Shell 中运行正确的安装命令。例如：

```bash theme={null}
upm add 'flask==2.3.3'
```

<div id="gerenciadores-de-pacotes-python">
  ## Python 包管理器
</div>

当你创建 Python 版的 Replit App 时，默认的包管理器是 **poetry**。这意味着 `pip install` 并不会管理你的依赖项。请改为在 Shell 中使用 `poetry add <package>` 或 `upm add <package>`。

<div id="mude-do-poetry-para-o-pip">
  ### 从 poetry 切换到 pip
</div>

如果你更习惯使用 `pip`，请按以下步骤操作：

<Steps>
  <Step>
    打开 Shell 并运行：

    删除 lock 文件，使打包系统切换到 pip：

    ```bash theme={null}
    rm poetry.lock
    ```
  </Step>

  <Step title="迁移依赖项">
    将 `pyproject.toml` 中 `[tool.poetry.dependencies]` 部分的依赖项迁移到 `requirements.txt`。例如，`flask = "^3.0.2"` 改写为 `flask>=3.0.2,<4`。
  </Step>

  <Step title="清理 pyproject.toml">
    删除 `pyproject.toml` 中的 `[tool.poetry...]` 各个部分。
  </Step>
</Steps>

完成这些更改后，打包系统会在后续所有操作中使用 `pip`，自动导入检测功能也仍将正常工作。

<div id="dependncias-do-sistema-com-nix">
  ## 使用 Nix 管理系统依赖
</div>

Replit 通过集成 [Nix](https://nixos.org/) 支持所有编程语言。如果你需要标准语言包之外的系统级依赖，可以将它们添加到 [replit.nix](/zh/pt/features/project-setup/configuration#replit-nix-file) 文件中。

<div id="pacotes-nix">
  ### Nix 包
</div>

直接编辑 `replit.nix` 即可添加系统级依赖。你可以在 [search.nixos.org](https://search.nixos.org/packages) 上搜索可用的包。

<div id="mdulos">
  ### 模块
</div>

模块整合了对编程语言、格式化工具和打包工具的支持，为你的 Replit App 提供基础环境。如果你从模板或 GitHub 仓库创建 Replit App，Replit 会自动安装所需的模块。

你可以通过 [.replit](/zh/pt/features/project-setup/configuration#replit-file) 文件自定义模块和其他 Nix 配置。

<div id="configurao-do-packager">
  ## packager 配置
</div>

你可以在 [.replit](/zh/pt/features/project-setup/configuration#replit-file) 文件中调整包管理行为：

| 配置项                                   | 说明                    | 默认值     |
| ------------------------------------- | --------------------- | ------- |
| `packager.language`                   | 执行包操作所使用的语言           | 自动检测    |
| `packager.features.guessImports`      | 运行 (Run) 时自动检测并安装缺失的包 | `true`  |
| `packager.features.packageSearch`     | 启用包搜索支持               | `true`  |
| `packager.features.enabledForHosting` | 托管时要求安装包              | `false` |
| `packager.afterInstall`               | 安装包后执行的命令             | —       |
| `packager.ignoredPaths`               | 导入检测时要忽略的路径           | `[]`    |
| `packager.ignoredPackages`            | 排除在自动检测之外的包           | `[]`    |
