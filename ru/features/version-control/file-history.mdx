Для начала откройте текстовый файл в Project Editor и нажмите кнопку **History** в правом нижнем углу.

<Frame>
  <img src="/assets/mirror/history-button-afac6496660a.png" alt="открытие истории" width="377" height="292" data-path="images/programming-ide/history-button.png" />
</Frame>

<div id="viewing-previous-versions-of-a-file">
  ## Просмотр предыдущих версий файла
</div>

Открыв историю файла, вы можете просматривать его предыдущие версии с помощью полосы прокрутки, кнопок со стрелками или клавиш со стрелками **влево** и **вправо**.

<Frame>
  <img src="/assets/mirror/history-versioning-1a055ecab411.gif" alt="демонстрация полосы прокрутки" width="764" height="720" data-path="images/animations/history-versioning.gif" />
</Frame>

<div id="comparing-previous-versions-to-the-current-file">
  ## Сравнение предыдущих версий с текущим файлом
</div>

Нажмите переключатель Compare Latest в левом нижнем углу панели «История файла», чтобы увидеть построчное сравнение файла на тот момент с его последней версией.

<Frame>
  <img src="/assets/mirror/compare-history-46fb16debd3a.gif" alt="изображение сравнения с последней версией" width="772" height="720" data-path="images/animations/compare-history.gif" />
</Frame>

<div id="restoring-a-previous-version-of-a-file">
  ## Восстановление предыдущей версии файла
</div>

Чтобы восстановить файл до предыдущей версии, просто нажмите кнопку `Restore`. Не беспокойтесь: история не будет удалена. Восстановленная предыдущая версия добавляется в историю файла как новая.

<Frame>
  <img src="/assets/mirror/restore-history-5f616d7f961a.webp" alt="изображение истории восстановления" width="720" height="495" data-path="images/animations/restore-history.webp" />
</Frame>

<div id="viewing-file-history-playback">
  ## Просмотр воспроизведения истории файла
</div>

С помощью функции воспроизведения в истории файла вы можете наблюдать, как файл менялся со временем, — словно смотрите фильм. Это удобно для создания видео о ваших сессиях программирования.
