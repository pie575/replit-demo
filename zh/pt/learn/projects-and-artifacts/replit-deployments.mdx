部署功能可让你通过简化流程将 Replit App 分享给全世界。

<Note>
  将应用上线的操作称为&quot;部署&quot;。本页面介绍可用的不同部署类型。
</Note>

<div id="o-que-publicao">
  ## 什么是部署？
</div>

部署是一项功能，可将您的 Replit App 的**快照**保存到云端，
让所有人都能与之互动。快照会记录
Replit App 文件的当前状态。

部署 Replit App 后，您会创建一个**已部署应用**。已部署应用是在
Replit 云基础设施上运行的应用实例，可让应用稳定地通过互联网访问，
并与 Project Editor 中的版本相互独立。

<Info>
  Replit 的基础设施基于 Google Cloud Platform (GCP)。所有
  已部署应用均托管在美国。Enterprise 客户可以
  联系销售团队，申请将其已部署应用托管在欧盟。

  每位个人客户、组织和企业都会获得一个专用的单租户
  GCP 项目，用于其已部署应用。这意味着已部署应用的计算资源、Secrets
  和存储空间完全隔离，绝不会
  与其他客户的应用共享。
</Info>

部署提供了用于监控已部署应用状态和查看 Web 分析数据的工具。

Replit 提供以下部署类型：

  <Card title="Autoscale 部署" href="/zh/pt/features/publishing/deployment-types#autoscale" icon="layer-group">

  <Card title="静态部署" href="/zh/pt/features/publishing/deployment-types#static" icon="files">

  </Card>

  <Card title="预留 VM 部署" href="/zh/pt/features/publishing/deployment-types#reserved-vm" icon="server">

<div id="primeiros-passos">
  ## 入门
</div>

按照以下步骤发布您的 Replit App：

1. 在 Project Editor 顶部，选择 <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="发布图标" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publish**。
2. 在 **Publishing** 选项卡中，选择发布选项。
3. 如果出现 **Add a payment method**，请按照说明添加付款方式。

Replit 会根据项目类型和您的需求，自动为您的应用选择最合适的发布选项。

不过，如果要选择其他部署类型，请参考以下信息。

<div id="principais-recursos">
  ## 主要功能
</div>

部署提供以下实用功能：

* **多种部署选项**：只需几次点击，即可选择或更新符合您需求的部署类型。
* **自定义域名**：通过您自己的 Web 域名提供应用服务。
* **数据分析**：跟踪已部署应用的访客数据和其他指标。
* **监控工具**：查看已部署应用的状态和配置。
* **访问控制**：只需点击一下，即可控制谁能查看您的应用。仅面向 **Pro** 和 **Enterprise** 成员开放。
* **徽章设置**：Core 套餐用户可在部署设置中管理“Made with Replit”徽章。如果您在包含该徽章的 Starter 方案期间部署了应用，升级后可能需要几分钟才能更新应用并移除该徽章。
* **反馈收集**：在已部署应用中启用反馈功能，以收集用户反馈和洞察。

<div id="como-funciona">
  ## 工作原理
</div>

部署 Replit App 时，Replit 会为应用的文件和依赖项创建快照。
随后，该快照会发送到 Replit 的云基础设施，并作为应用的独立实例运行。
如需将已部署应用更新为最新更改，请再次部署以创建新的快照。

<Warning>
  请避免将数据保存到已部署应用的文件系统中，或依赖其中的数据。要
  存储数据，请使用存储或数据库服务，例如 Replit 提供的 [Storage and
  Database](/zh/pt/learn/projects-and-artifacts/storage-and-databases)。
</Warning>

<div id="casos-de-uso">
  ## 使用场景
</div>

以下示例展示了不同类型的已部署 App。

<div id="autoscale-deployment-app-de-avaliao-de-velocidade-de-digitao">
  ### Autoscale 部署：打字速度测试 App
</div>

用户进行打字测试时自动扩容，空闲时自动缩容。

<div id="static-deployment-simulao-do-sistema-solar">
  ### 静态部署：太阳系模拟
</div>

通过 Web 太阳系可视化应用了解各个行星。
该可视化应用在浏览器中渲染，不会将任何用户输入传输至服务器。

<div id="reserved-vm-deployment-bot-do-discord">
  ### 预留 VM 部署：Discord 机器人
</div>

运行 Discord 机器人，帮助您管理并引导成员加入。
它始终在线，可与用户交流并响应命令，同时提供可预测的价格和性能。

<div id="scheduled-deployment-gatilhos-de-automao-residencial">
  ### 定时部署：智能家居自动化触发器
</div>

调度 API 调用，以便在特定时间和日期启动或停止智能家居设备。
