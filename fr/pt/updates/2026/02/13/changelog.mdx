<div id="suporte-ao-claude-opus-45">
  ### Prise en charge de Claude Opus 4.5
</div>

Claude Opus 4.5 est désormais pris en charge dans les intégrations d&#39;IA, vous donnant accès aux toutes dernières capacités d&#39;IA d&#39;Anthropic, optimisées pour le code et les agents.

<div id="boto-open-in-replit-beta">
  ### Bouton Open in Replit (bêta)
</div>

Vous pouvez désormais traiter vos tickets Linear directement dans Replit grâce au nouveau bouton « Open In Replit ». Cette fonctionnalité en bêta doit être activée dans les préférences ; elle renseigne automatiquement le prompt avec les détails du ticket. L&#39;équipe collabore avec Linear pour améliorer l&#39;intégration.

<div id="acesso-do-agent-ao-banco-de-dados-sql-de-produo">
  ### Accès de l&#39;Agent à la base de données SQL de production
</div>

L&#39;Agent peut désormais consulter et interroger votre base de données SQL de production en lecture seule, ce qui vous permet de travailler sur des données de production réelles sans risque de modification accidentelle.

<div id="melhorias-na-confiabilidade-de-conexo">
  ### Améliorations de la fiabilité des connexions
</div>

Plusieurs améliorations pour enrichir l&#39;expérience avec les intégrations :

* Les jetons de connexion expirent moins souvent grâce à un processus de reconnexion en arrière-plan amélioré
* Affichage explicite des connexions en état d&#39;erreur ou inactives
* Possibilité de reconnecter les intégrations directement depuis l&#39;état d&#39;erreur

<div id="oramentos-por-usuriogrupo">
  ### Budgets par utilisateur/groupe
</div>

Les fonctionnalités de gestion des budgets sont désormais activées pour tous les clients Enterprise :

* Les administrateurs d&#39;équipes Enterprise peuvent définir des budgets d&#39;utilisation par défaut pour l&#39;ensemble des membres
* Les administrateurs peuvent définir des budgets pour des groupes spécifiques (par exemple, Administrateurs/Membres et groupes personnalisés)
* Prochainement : les administrateurs pourront définir des budgets spécifiques pour chaque utilisateur
