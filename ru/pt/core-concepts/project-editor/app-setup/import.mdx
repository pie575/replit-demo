Функция импорта позволяет перенести существующий код или дизайн в Replit App и продолжить разработку с Agent.

<div id="fontes-suportadas">
  ## Поддерживаемые источники
</div>

| Источник                 | Что нужно указать                                             | Лучше всего подходит для                                     |
| ------------------------ | ------------------------------------------------------------- | ------------------------------------------------------------ |
| GitHub                   | URL репозитория или выбор репозитория                         | Импорта публичных и приватных репозиториев                   |
| Bitbucket                | URL репозитория или выбор репозитория                         | Импорта репозиториев, размещённых в Bitbucket                |
| Vercel                   | Репозиторий GitHub, связанный с вашим проектом Vercel         | Миграции приложений из Vercel                                |
| Figma                    | URL фрейма                                                    | Преобразования дизайнов в приложения React                   |
| Bolt                     | Репозиторий GitHub, экспортированный из Bolt                  | Миграции проектов из Bolt                                    |
| Lovable                  | Репозиторий GitHub, экспортированный из Lovable               | Миграции проектов из Lovable                                 |
| Base44                   | Репозиторий GitHub, экспортированный из Base44                | Миграции проектов из Base44                                  |
| ZIP                      | Загрузка файла `.zip`                                         | Импорта локальных файлов проекта                             |
| Таблица                  | Файл `.xlsx`, `.csv` или URL Google Таблиц                    | Создания приложения на основе данных таблицы                 |
| Предыдущий экспорт Agent | Репозиторий GitHub, экспортированный из предыдущего Agent App | Повторного импорта предыдущего Agent App                     |
| Пустой                   | Ничего                                                        | Опытных пользователей, которым нужен пустой проект без Agent |

<Note>Replit проверяет совместимость перед началом импорта.</Note>

<div id="fluxo-de-importao-padro">
  ## Стандартный процесс импорта
</div>

1. Откройте [replit.com/import](https://replit.com/import).
2. Выберите источник импорта.
3. Подключите необходимые учётные записи.
4. Укажите URL репозитория, URL фрейма или файл `.zip`.
5. Добавьте запрошенные секреты или переменные окружения.
6. Нажмите **Импортировать** и проверьте созданное приложение.

<div id="notas-sobre-as-fontes">
  ## Примечания об источниках
</div>

<div id="github">
  ### GitHub
</div>

* Используйте быстрый импорт публичных репозиториев через `https://replit.com/github.com/<owner>/<repo>`.
* Используйте пошаговый импорт для публичных и приватных репозиториев.
* Если ваш репозиторий — экспортированный Agent App, Replit сохраняет специфичную для Agent структуру при импорте.

<div id="bitbucket">
  ### Bitbucket
</div>

* Вставьте URL репозитория Bitbucket или подключите свою учётную запись Bitbucket, чтобы найти нужный репозиторий.
* Поддержка Agent при импорте может быть ограничена по сравнению с проектами, размещёнными на GitHub.

<div id="figma">
  ### Figma
</div>

* Импортируйте один URL-адрес фрейма из Figma.
* Replit генерирует код React, а Agent помогает его доработать.
* Для наилучших результатов используйте фреймы, автоматическую раскладку и понятные названия слоёв.

<div id="vercel">
  ### Vercel
</div>

* Выберите репозиторий GitHub, связанный с вашим проектом Vercel.
* Replit импортирует код проекта и настройки конфигурации.
* Добавьте значения переменных окружения при импорте.

<div id="bolt">
  ### Bolt
</div>

* Перед импортом экспортируйте проект Bolt в GitHub.
* Replit импортирует код, стили интерфейса, ассеты, логику бэкенда (если есть) и схему базы данных (если есть).
* Данные Supabase и значения секретов не импортируются.
* После импорта попросите Agent добавить секреты и заново создать данные базы данных.

<div id="lovable">
  ### Lovable
</div>

* Перед импортом экспортируйте проект Lovable в GitHub.
* Replit импортирует код, стили интерфейса, ассеты, логику бэкенда (если она есть) и схему базы данных (если она есть).
* Данные Supabase и значения секретов не импортируются.
* После импорта попросите Agent добавить секреты и восстановить данные базы данных.

<div id="base44">
  ### Base44
</div>

* Перед импортом экспортируйте проект Base44 в GitHub.
* Replit импортирует код, дизайн и стили, ассеты и логику API.
* Бэкенд Base44 (сущности, агенты, SDK), аутентификация и данные не импортируются.
* После импорта попросите Agent перенести все необходимые вам функции, специфичные для Base44.

<div id="zip">
  ### ZIP
</div>

* Загрузите файл `.zip` с чёткой структурой проекта в корневой папке.
* Replit импортирует файлы, зависимости и распространённые настройки запуска.
* Существующие секреты, домены и данные базы данных не импортируются.

<div id="planilha">
  ### Электронная таблица
</div>

* Загрузите файл Excel (`.xlsx`) или CSV либо вставьте общедоступный URL Google Таблиц.
* Agent считывает структуру вашей таблицы и создает полностековое приложение с базой данных, заполненной вашими данными.
* Включает интерфейс для просмотра, поиска и управления записями.

<div id="exportao-anterior-do-agent">
  ### Предыдущий экспорт Agent
</div>

* Повторно импортируйте ранее экспортированное Agent App из репозитория GitHub.
* Replit сохраняет структуру, характерную для Agent (код, схему базы данных, функциональность бэкенда).
* Данные базы данных и секреты не импортируются.

<div id="vazio">
  ### Пустой
</div>

* Начните с абсолютно пустого проекта — без Agent, выбора фреймворка и шаблонного кода.
* Идеально подходит для опытных пользователей, которым нужен полный контроль над настройкой проекта.

<div id="limitaes">
  ## Ограничения
</div>

* Существующие данные из базы данных не переносятся.
* Некоторые сложные или проприетарные зависимости могут потребовать ручной настройки.
* Обработка крупных проектов может занять больше времени.

<div id="boas-prticas">
  ## Рекомендации
</div>

* Удалите конфиденциальные учётные данные перед импортом.
* Поддерживайте структуру исходного проекта в порядке.
* После импорта проверьте зависимости и команды запуска.
* Протестируйте основные сценарии перед публикацией.

<div id="soluo-de-problemas">
  ## Устранение неполадок
</div>

Если импорт не удался, сначала проверьте следующее:

* **Ошибки совместимости**: Проверьте наличие необходимых файлов проекта и поддержку используемых фреймворков.
* **Ошибки доступа**: Проверьте разрешения для репозитория или источника.
* **Ошибки обработки**: Упростите структуру проекта или уменьшите его размер и повторите попытку.

Если проблемы сохраняются, посетите [Replit Community Hub](https://replit.com/community) или [обратитесь в службу поддержки](https://replit.com/support).

<div id="faturamento">
  ## Оплата
</div>

Импорт, для которого Agent выполняет миграцию, может потребовать кредитов. Расход кредитов зависит от сложности проекта.
