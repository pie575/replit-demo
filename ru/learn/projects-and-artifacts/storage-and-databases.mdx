Гибкие решения Replit для хранения данных позволяют быстро добавить хранилище,
необходимое для работы вашего App. Для App со следующими требованиями можно использовать базу данных Replit или объектное хранилище, а Agent автоматически настроит и интегрирует оба решения:

* Игра, в которой нужно сохранять данные игроков, например прогресс или рекорды
* Контент-платформа для управления медиафайлами

<div id="what-are-replits-storage-and-database-options">
  ## Какие варианты хранилищ и баз данных доступны в Replit
</div>

Replit предлагает следующие варианты хранения данных:

* **База данных**: хранит структурированные данные, например профили пользователей, результаты игр и каталоги товаров.
  Вы можете сохранять и получать данные по атрибутам и связям между ними.

* **App Storage**: хранит неструктурированные данные, например изображения, видео и документы.
  Вы можете хранить и получать большие файлы и двоичные данные.

<div id="app-storage-and-database-comparison">
  ### Сравнение App Storage и базы данных
</div>

|                               | База данных                                         | App Storage                                        |
| ----------------------------- | :-------------------------------------------------- | :------------------------------------------------- |
| **Оптимальный формат данных** | Структурированные взаимосвязанные данные            | Большие файлы (изображения, видео, документы)      |
| **Модель данных**             | Таблицы, строки, столбцы                            | Бакеты, файлы                                      |
| **Язык запросов**             | SQL                                                 | REST API                                           |
| **Клиенты**                   | Клиенты и ORM, совместимые с PostgreSQL             | SDK Replit и клиентские библиотеки GCS             |
| **Модель биллинга**           | Оплата вычислительного времени и места для хранения | Оплата пропускной способности и места для хранения |

  ### Инструменты Project Editor
</div>

Узнайте больше об инструментах Replit для настройки и управления хранилищем данных вашего приложения:

<CardGroup>
  <Card title="База данных" href="/ru/features/data-and-storage/sql-database" icon="database">
    Идеально подходит для структурированных данных и моделирования связей между ними.
    Использует полностью управляемую базу данных PostgreSQL, которая масштабируется вместе с вашим приложением.
  </Card>

  <Card title="App Storage" href="/ru/features/data-and-storage/object-storage" icon="bucket">

    Использует Google Cloud Storage (GCS), обеспечивающее высокую доступность и масштабируемость. Agent может автоматически настроить App Storage с расширенной аутентификацией и контролем доступа.
  </Card>
</CardGroup>
