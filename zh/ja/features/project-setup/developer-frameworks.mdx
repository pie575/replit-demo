<div id="section">
  ## 什么是开发者框架？
</div>

开发者框架是由平台或社区发布的 Replit 应用，可供其他用户作为起点使用。由 Replit 创建的官方开发者框架会在框架名称旁显示一个勾选标记：

<Frame>
  <img src="/assets/mirror/template-official-c5fe09e20415.png" alt="Replit 官方开发者框架" width="1051" height="246" data-path="images/programming-ide/creating-a-template/template-official.png" />
</Frame>

[HTML、CSS、JS 框架](https://replit.com/@replit/HTML-CSS-JS?v=1#index.html)非常受欢迎，可用作创建原生 JavaScript 项目的起点。你可以复刻后使用。

其他开发者框架则由社区成员创建：

</Frame>

<div id="enterprise">
  ## Enterprise 自定义模板
</div>

Enterprise 组织可以创建[自定义模板](/zh/ja/teams/custom-templates)，这些模板会作为可选项显示在所有组织成员的 Agent 输入框中。自定义模板可包含公司专属的 Agent 指令、技能和预设的项目上下文，因而提供了超越开发者框架的能力。详情请参阅[自定义模板指南](/zh/ja/teams/custom-templates)。
