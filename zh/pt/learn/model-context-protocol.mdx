Claude 和 GPT 等 AI 模型功能强大，但其能力仅限于训练时所接触的内容。Model Context Protocol (MCP) 为它们提供了一种标准化方式，使其能够连接外部工具、数据源以及现实世界中的各种能力。

<div id="por-que-os-modelos-de-ia-precisam-do-mcp">
  ## 为什么 AI 模型需要 MCP
</div>

如果无法访问外部工具和数据，AI 模型就无法：

* 获取最新信息
* 与外部系统交互
* 在现实世界中执行操作
* 使用你的私有数据

MCP 为 AI 提供了一种通用方式来连接工具和数据，类似于 USB-C 标准化了设备连接方式。

<Frame>
  <img src="/assets/mirror/mcp-a04e01a01743.avif" alt="MCP 图示，展示 AI 模型连接外部工具和数据源" width="1920" height="1055" data-path="images/tutorials/mcp.avif" />
</Frame>

借助 MCP，AI 模型可以：

* 访问专用工具和 API
* 读取私有数据源中的数据
* 在现实世界中执行操作
* 无缝连接到其他系统

<div id="como-o-mcp-funciona">
  ## MCP 的工作方式
</div>

MCP 架构由三个主要组件构成：

1. **客户端** — Claude 等 AI 模型，或需要访问外部工具的应用。
2. **通信层** — 即用于规范请求和响应格式的协议本身。
3. **服务器端** — 提供工具、数据源和专用功能访问权限的程序。

<AccordionGroup>
  <Accordion title="什么是 MCP 客户端？">
    MCP 客户端可以是 Claude、Replit Agent，或连接到大语言模型的命令行界面。它是连接外部工具或数据源的“终端”。

    MCP 客户端示例：

    * 浏览器中的 Claude
    * Replit Agent
    * AI 命令行界面
    * 使用 AI SDK 构建的自定义应用
  </Accordion>

  <Accordion title="什么是 MCP 服务器？">
    MCP 服务器为 AI 模型提供工具和功能。可以将其理解为为 AI 配备一套用于解决问题的专用工具。

    MCP 服务器可实现的功能示例：

    * 访问特定数据源以回答问题
    * 将 AI 连接到 API，使其能够在线执行操作
    * 读取或写入文件
    * 进行计算或执行代码
    * 获取 Notion、Linear 或 Stripe 等服务中的内容
  </Accordion>
</AccordionGroup>

<div id="o-que-o-mcp-desbloqueia">
  ## MCP 能实现什么
</div>

MCP 定义了多种基础构件，使其能够为 AI 应用提供强大支持：

* **Resources** — 与 AI 模型共享数据和内容
* **Tools** — 让 AI 模型通过您的服务执行操作
* **Prompts** — 用于实现一致 AI 交互的可复用模板
* **Sampling** — 允许您的服务向 AI 模型请求信息
* **Transports** — 高效连接客户端和服务器

<div id="skills-vs-servidores-mcp">
  ## Skills 与 MCP 服务器
</div>

Skills 和 MCP 服务器是扩展 AI 智能体的两种主要方式，但用途不同。

|          | Skills                             | MCP 服务器                     |
| -------- | ---------------------------------- | --------------------------- |
| **适用场景** | 工作流、约定和参考资料                        | 连接外部服务并执行操作                 |
| **加载方式** | 轻量——仅加载名称和描述，调用时才加载具体内容            | 较重——会预先加载所有工具描述             |
| **定义**   | 智能体应*如何*工作                         | 智能体能访问*什么*                  |
| **示例**   | “Stock Analyzer” Skill——使用特定框架研究投资 | “Stripe” MCP 服务器——读取支付和订阅数据 |

有关 Skills 的相应使用思路，请参阅 [Agent Skills](/zh/pt/learn/agent-skills)。

<div id="aplicaes-no-mundo-real">
  ## 现实应用
</div>

MCP 支持多种 AI 应用：

* **客户服务系统**，可访问企业数据库以回答具体问题
* **研究助手**，可检索并总结多个来源的内容
* **生产力工具**，可与您的文件和应用交互
* **内容创作工具**，可访问媒体库和发布平台

<div id="benefcios">
  ## 优势
</div>

MCP 提供三大优势：

* 可立即连接到 AI 的现成集成
* 无需重写连接，即可在不同 AI 提供商之间切换
* 保护敏感数据的安全功能

<Note>
  MCP 是一项新兴标准，正获得整个 AI 生态系统越来越广泛的支持。新的工具和集成会定期推出。
</Note>
