CLUI (Command Line User Interface) est la barre de commandes interactive de Replit qui vous permet d&#39;effectuer rapidement diverses tâches sans avoir à parcourir les menus. Elle combine l&#39;efficacité de la ligne de commande à une interface graphique.

<div id="section">
  ## Fonctionnalités
</div>

CLUI propose de puissantes interactions par commandes dans trois contextes distincts de Replit :

* **Gestion des paramètres** : gérez les paramètres, consultez les alertes et restaurez les applications Replit supprimées
* **Navigation rapide** : passez d&#39;une application Replit à l&#39;autre et accédez aux fonctionnalités courantes grâce aux raccourcis
* **Opérations dans Workspace** : recherchez des fichiers ou du code et accédez aux outils dans votre environnement de développement

<div id="section-2">
  ## Utilisation
</div>

<div id="clui">
  ### CLUI du compte
</div>

Le CLUI du compte vous permet de gérer les paramètres, les équipes et les applications Replit supprimées.

**Accès :** accédez à la [page CLUI](https://replit.com/~/cli), saisissez dans le champ de saisie le texte de la commande à rechercher, puis appuyez sur Entrée pour l’exécuter.

<Accordion title="Commandes du compte">
  Saisissez `account` pour gérer les paramètres :

  * **view-warns**: affiche les avertissements que vous avez reçus
  * **change-username**: modifie votre nom d’utilisateur (une seule fois)
</Accordion>

<Accordion title="Commandes de la corbeille">
  Saisissez `trash` pour gérer les applications Replit supprimées :

  * **restore &lt;title&gt;**: restaure une application Replit supprimée à partir de son titre (s’il existe plusieurs applications portant le même nom, restaure celle supprimée le plus récemment)
  * **view**: affiche les applications Replit supprimées les plus récemment
</Accordion>

<Accordion title="Commandes d’équipe">
  Saisissez `team` pour gérer les équipes :

  * **view**: affiche les membres des équipes auxquelles vous appartenez à partir de votre nom d’utilisateur
  * **fork-repl-to-project**: duplique une application Replit existante pour créer un projet d’équipe
</Accordion>

<Accordion title="Commande clear">
  Saisissez `clear` pour effacer l’écran de toutes les commandes exécutées jusqu’à présent
</Accordion>

<div id="clui-2">
  ### Raccourci CLUI
</div>

Le raccourci CLUI vous permet d&#39;accéder rapidement aux fonctionnalités courantes de Replit depuis n&#39;importe quelle page.

<Frame>
  <img src="/assets/mirror/shortcuts-clui-768d49b44785.png" alt="Raccourci CLUI" width="689" height="291" data-path="images/getting-started/shortcuts-clui.png" />
</Frame>

**Accès** : sur la plupart des pages Replit, appuyez sur **CMD/CTRL + K** ou cliquez sur l&#39;icône de recherche dans la barre de navigation supérieure.

<Accordion title="Commandes disponibles">
  * **Search** : recherchez des applications Replit, des modèles, du code, des personnes, etc.
  * **New** : créez une nouvelle application Replit
  * **My Replit Apps** : parcourez vos applications Replit et ouvrez-les
  * **My Code** : recherchez du code dans toutes vos applications Replit
</Accordion>

<div id="workspace-clui">
  ### Workspace CLUI
</div>

Workspace CLUI vous aide à effectuer des tâches, accéder aux outils, trouver des fichiers et rechercher du code lorsque vous travaillez dans l’application Replit.

<Frame>
  <img src="/assets/mirror/ws-clui-81764b3d111b.png" alt="Workspace CLUI" width="429" height="202" data-path="images/getting-started/ws-clui.png" />
</Frame>

**Accès :** dans Workspace, appuyez sur **CMD/CTRL + K** ou cliquez sur l’icône Search en haut à gauche.

<Accordion title="Tâches courantes">
  * **Trouver des fichiers :** trouvez rapidement des fichiers dans votre projet
  * **Rechercher du code :** trouvez des extraits de code spécifiques dans tous les fichiers
  * **Accéder aux outils :** ouvrez les outils ou panneaux disponibles dans Workspace
  * **Exécuter des commandes :** exécutez des commandes liées à Workspace
</Accordion>
