ウェブ検索は最新のパッケージ、ツール、情報を見つけるのに役立ちます。これにより、アプリが現在のベストプラクティスを使用してより正確になることが保証されます。

## 機能

Agent のウェブ検索を使って現在の情報でアプリケーションを構築しましょう。これにより手動での調査とデータ収集が不要になります。財務データのダッシュボードを作成する場合でも、最近のスタートアップのローンチを紹介するウェブサイトを構築する場合でも、ウェブ検索によりアプリが現実を反映することが保証されます。

Agent が実行できるウェブ検索アクション：

* **検索**: 現在の情報、最新のドキュメント、インターネットのリアルタイムデータを見つけます
* **コンテンツ取得**: 特定のウェブサイトや URL から詳細情報を取得します
* **情報源の引用**: Agent が情報を見つけた場所を正確に確認して、情報源を検証・参照できます

## 使い方

ウェブ検索は Agent に組み込まれています — 設定をオンにする必要はありません。構築したいものを説明すると、Agent が現在の情報を求めてウェブを検索するタイミングを自動的に判断します。「検索」「調査」「ウェブ検索を使用」などのキーワードをプロンプトに含めると、Agent に明示的に検索を促せます。

### ウェブ検索がアプリを強化する方法

ウェブ検索により、アプリケーションがプレースホルダーデータの使用から本物の正確な情報の組み込みへと変わります：

| メリット         | 説明                                         |
| ------------ | ------------------------------------------ |
| 最新のテクノロジー    | アプリがトレーニングデータにない最新の情報とパッケージを使用します          |
| 最適なツールの選択    | Agent がオプションを調査して最適なパッケージを選択します            |
| 現在のベストプラクティス | 最新の開発パターンとセキュリティプラクティスにアクセスできます            |
| 制限の突破        | トレーニング後にリリースされたパッケージを使用するための知識のカットオフを克服します |
| 正確なデータ       | アプリが古い例の代わりに現在の情報を表示します                    |
| プロフェッショナルな結果 | 実際の企業を参照するアプリケーションが信頼性を持ちます                |
| 時間の節約        | パッケージを手動で調査しデータを収集する必要がなくなります              |

### 情報源の引用

Agent がウェブ検索を使用すると、情報がどこから来たかを正確に示す**情報源の引用**が提供されます。これらの引用を使用して：

* **情報を検証**: 情報源の信頼性と正確性を確認します
* **詳しく学ぶ**: 元の情報源を訪問してより多くのコンテキストを得ます
* **情報源を参照**: アプリケーションに適切な帰属を含めます
* **リサーチを追跡**: Agent の作業にどの情報が影響したかを理解します

### コンテンツ取得

Agent はプロジェクトのための包括的な情報を収集するために、特定のウェブサイトから詳細なコンテンツを取得できます。これにより Agent は：

* ウェブページ全体を読んで関連する詳細を抽出できます
* ドキュメントと参考資料を処理できます
* 権威ある情報源から特定のデータポイントを収集できます
* 構造化された情報をアプリケーションに統合できます

  ウェブ検索は具体的で詳細なリクエストで最も効果を発揮します。テクノロジーの発見には、具体的な要件を明記してください

</Warning>
