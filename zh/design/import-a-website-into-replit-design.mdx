⏰ *预计用时：10 分钟*

有时，你想作为起点的设计已经上线了：可能是你当前的网站，也可能是你想复刻其外观的页面。“从 URL 导入”会将网站还原为一个设计 frame，你可以探索、优化，并将其构建为交互式 App。

你将以 [creative-studio-landing.replit.app](https://creative-studio-landing.replit.app) 为示例。这是一个由 Replit 构建的创意工作室落地页。

<div id="before-you-start">
  ## 开始之前
</div>

你需要：

* 一个 [Replit 账户](https://replit.com)。
* 一个公开网站的网址，或使用上面的示例。

<div id="import-the-website">
  ## 导入网站
</div>

<Steps>
  <Step title="复制网站 URL">
    使用你自己的网站，或复制以下示例：`https://creative-studio-landing.replit.app`。

    <Frame caption="示例网站：Kosmo Studio，一家创意工作室的落地页。">
      <img src="/assets/mirror/url-example-site-e0ad60629981.webp" alt="Kosmo Studio 落地页，标题为“我们打造真正有效的大胆创意与视觉作品”，下方是呈扇形排列的艺术作品卡片" width="3440" height="2160" data-path="images/design/import-from-url/url-example-site.webp" />
    </Frame>
  </Step>

  <Step title="打开 Replit Design">
    前往 [replit.com/design](https://replit.com/design)，然后在提示框下方选择 **Import URL**。Agent 会复刻网站的视觉风格，作为起点。

    <Frame caption="Replit Design 首页中的 Import URL：粘贴任意网站的链接。">
      <img src="/assets/mirror/design-import-url-07a8ac52e188.webp" alt="Replit Design 首页，已选中 Import URL 选项，提示信息显示“粘贴任意网站的链接，Agent 将复刻其视觉风格，作为起点”" width="2293" height="1322" data-path="images/design/import-from-url/design-import-url.webp" />
    </Frame>
  </Step>

  <Step title="粘贴 URL 并开始构建">
    选择 **Import URL** 后，提示框会自动填入：*&quot;复刻此网站的视觉风格：&quot;*。在其后粘贴你的 URL，然后选择 **Start**。

    <Frame caption="已预填复刻提示和示例 URL，可开始操作。">
      <img src="/assets/mirror/design-url-prompt-b6196aac1b17.webp" alt="Replit Design 提示框显示“复刻此网站的视觉风格”，后接示例 URL，并带有 Start 按钮" width="2293" height="1322" data-path="images/design/import-from-url/design-url-prompt.webp" />
    </Frame>
  </Step>
</Steps>

Agent 会在你的项目中将该网站复刻为一个设计 frame。

<Frame caption="在 Replit Design 中复刻的 Kosmo Studio 落地页，显示为一个设计 frame。">
  <img src="/assets/mirror/url-import-result-7a4114a468f3.webp" alt="在 Replit Design 中复刻的 Kosmo Studio 落地页，显示为一个设计 frame，Chat 面板中显示运行已完成" width="1600" height="1004" data-path="images/design/import-from-url/url-import-result.webp" />
</Frame>

<div id="make-it-yours">
  ## 打造你的专属设计
</div>

选择导入的 frame，开始按自己的想法调整：

* **采纳[建议](/zh/design/explore-suggestions)**：导入后会提供建议的后续步骤，例如深色编辑风格变体、移动端视口或联系页面。每项建议都会生成一个新的 frame，方便你保留原始版本进行比较。
* **[在 Chat 中讨论](/zh/design/chat-about-your-design)**：使用 frame 下方的输入框，用自己的话描述需求，例如 *“替换作品集图片”*、*“让主视觉标题字体更粗”*。

<Frame caption="选中的导入 frame，旁边显示建议的后续步骤，包括深色编辑风格变体、移动端视口和联系页面。">
