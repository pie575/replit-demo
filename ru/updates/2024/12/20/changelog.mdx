<div id="custom-prompts">
  ### Пользовательские промпты
</div>

<Note>
  **Обновление (декабрь 2025 г.):** Assistant снят с поддержки. Для быстрых точечных правок используйте [облегчённый режим в Agent](/ru/core-concepts/agent/agent-modes).
</Note>

Пользовательские промпты позволяют полностью управлять взаимодействием Assistant. Они помогут вам настроить конкретные стандарты написания кода и параметры Assistant по умолчанию.

Например, можно указать:

* Определённый стиль написания кода или фреймворк
* Конкретные методы решения задач
* Предпочтения по управлению пакетами

Например:

```
используй pnpm для управления пакетами
используй motion/react вместо framer-motion
всегда используй claude-3-5-sonnet-20241022 в качестве модели
```

<div id="workflows">
  ### Рабочие процессы
</div>

Рабочий процесс — это легко настраиваемая кнопка «Запустить», которая может выполнять любые команды.

Это повторно используемая настраиваемая последовательность шагов, которую можно запускать в вашем Replit App. Она может быть такой же простой, как запуск **`python main.py`**, или настолько сложной, как выполнение многоэтапной процедуры.

Примеры использования:

* Одновременный запуск нескольких сервисов (например, фронтенда и бэкенда)
* Последовательное выполнение файлов или команд (например, запуск линтера → запуск тестов, компиляция → выполнение кода)

Чтобы начать [создавать рабочие процессы](https:/.replit.com/replit-workspace/workflows#creating-workflows), откройте панель рабочих процессов в меню инструментов на боковой панели или найдите её с помощью **`Command + K`**.

Подробнее [здесь](https:/.replit.com/replit-workspace/workflows).
