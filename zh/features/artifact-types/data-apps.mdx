<div id="what-is-a-data-visualization">
  ## 什么是数据可视化？
</div>

数据可视化是你通过与 Agent 对话构建的交互式仪表板或报表工具。只需描述想要可视化的内容以及数据所在位置——Agent 会自动选择合适的 KPI、图表类型和布局，用一个 prompt 生成一个完整的仪表板。

核心概念：

* **一次生成**：描述你的目标和数据源，Agent 即可构建出包含合适图表与指标的完整仪表板
* **连接数据源**：可从数据库、[数据仓库连接器](/zh/connectors/warehouses/overview)、外部 API 或上传的文件中获取数据
* **内置功能**：每个仪表板都支持刷新、自动刷新、导出为 PDF、将图表导出为 CSV，以及浅色/深色模式
* **分析摘要**：Agent 会根据你的请求和生成的数据给出洞察
* **多个 artifact**：数据可视化可以与[同一 project](/zh/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project) 中的其他 artifact 共享同一个后端和数据库

<div id="how-to-use-data-visualization">
  ## 如何使用数据可视化
</div>

<div id="creating-from-a-prompt">
  ### 通过 prompt 创建
</div>

在主页上选择 **App** 标签页，描述你想要的仪表板。Agent 会识别与数据相关的 prompt，并自动选用 Data Visualization 技术栈。

**示例 prompt：**

* “构建一个按地区跟踪营收的销售分析仪表板”
* “创建一个能可视化展示月度指标的报表工具”
* “基于我们的 BigQuery 销售数据构建一个仪表板，展示表现最好的产品”
* “连接 Snowflake，创建一个客户流失分析仪表板”

<div id="creating-from-the-dropdown">
  ### 通过下拉菜单创建
</div>

1. 在主页上打开 **App** 标签页。
2. 展开应用类型下拉菜单。
3. 选择 **Data Visualization**。
4. 描述你想构建的仪表板或数据工具。

<div id="connecting-to-data-warehouses">
  ### 连接到数据仓库
</div>

通过[数据仓库连接器](/zh/connectors/warehouses/overview)将数据可视化连接到 BigQuery、Databricks 或 Snowflake，基于你已有的数据集构建仪表板。

查询数据仓库数据时，Agent 会通过并行的多智能体搜索来探索你的数据结构和数据集，从而加快探索速度，并帮助 Agent 为仪表板选择合适的表和字段。

要开始使用，请在 project 的 [Integrations](/zh/features/integrations/overview) 中配置数据仓库连接器，然后告诉 Agent 你想要可视化的内容。

<div id="adding-filters-and-features">
  ### 添加筛选器和功能
</div>

Agent 构建好仪表板后，你可以通过 prompt 让它添加筛选器、下钻分析或其他交互功能。例如，让 Agent 添加日期范围筛选器、地区选择器或搜索栏。

<div id="exporting-and-sharing">
  ### 导出与分享
</div>

* **导出为 PDF**：将整个仪表板导出为 PDF，便于分享或离线查看。
* **将图表导出为 CSV**：将单个图表的数据下载为 CSV 文件，以便在电子表格或其他工具中作进一步分析。
* **分析文档**：让 Agent 根据仪表板中的数据生成一份详细的分析文档。

<div id="what-you-can-build">
  ## 你可以构建什么
</div>

* **分析仪表板**：跟踪收入、注册量、参与度等关键指标在各时间段的变化
* **报表工具**：构建内部报表，让相关方无需直接访问数据库即可筛选和探索数据
* **数据探索界面**：浏览和查询数据集，并获得可视化反馈
* **监控面板**：展示来自 API、数据库或外部服务的实时或准实时数据

<div id="frequently-asked-questions">
  ## 常见问题
</div>

<Accordion title="我可以连接哪些数据源？">
  你可以从项目的 Replit Database、数据仓库连接器 (BigQuery、Databricks、Snowflake) 、外部 API 或上传的文件 (如 CSV) 中获取数据。数据仓库连接可通过 [Integrations](/zh/features/integrations/overview) 设置。
</Accordion>

<Accordion title="我可以自定义外观和风格吗？">
  可以。你可以通过对话自定义配色、布局和排版——让 Agent 匹配你的品牌风格或调整设计。仪表板还支持浅色和深色模式。
</Accordion>

<Accordion title="Agent 会帮我分析数据吗？">
  构建仪表板后，Agent 会根据你的需求和生成的数据输出一份分析摘要。你也可以要求它生成更详细的分析文档。
</Accordion>

<Accordion title="我可以把数据可视化与其他 artifact 类型组合起来吗？">
  可以。你可以在[同一个 project](/zh/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project) 中，将数据可视化与 [web app](/zh/features/artifact-types/web-apps)、[幻灯片](/zh/features/artifact-types/slide-decks) 或其他 artifact 类型组合在一起。它们共用同一套后端和数据库。
</Accordion>
