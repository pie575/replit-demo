使用 Replit Agent 创建专业的动画视频。只需用自然语言描述视频内容，Agent 即可生成可导出和分享的动态图形——无需视频剪辑技能，也无需聘请昂贵的代理机构。

<div id="section">
  ## 概述
</div>

借助 Replit Animation，您只需与 Agent 对话，即可创建精美的动态图形。这些是用 React 构建的程序化动画，不使用 Remotion；动画视频则依托网页动画库与自定义 Agent 技能的组合。它们并非 Runway 或 Sora 那样由 AI 生成的视频。视频可包含文字叠加、流畅转场、AI 生成图像等内容。

视频会在预览窗格中循环播放，您可以像构建其他应用一样与 Agent 对话，持续优化视频。

**所有构建者均可使用，包括免费套餐用户**。

<div id="section-2">
  ## 创建动画视频
</div>

你可以通过 Replit 主页以两种方式创建动画视频：

<div id="1">
  ### 选项 1：输入提示词
</div>

在主页上选择**应用**标签页，然后输入提示词来描述你想制作的视频。Agent 会自动识别与视频相关的提示词，并选择动画视频技术栈。

提示词示例：

* “为一个新的气泡水品牌制作宣传视频”
* “制作一段 30 秒的讲解视频，说明大语言模型的工作原理”
* “制作一段展现德克萨斯州奥斯汀的电影感宣传视频”

</Frame>

<div id="2">
  ### 选项 2：从下拉菜单中选择
</div>

1. 前往主页的**应用**标签页。
2. 打开应用类型下拉菜单。
3. 选择**动画**。
4. 输入您想创建的视频描述。

<Frame>
  <img src="/assets/mirror/animation-entry-point-b22d4942db44.png" alt="应用类型下拉菜单中已选择动画，并显示 Web 应用、移动应用、数据可视化、3D 游戏和自动化等选项" width="1200" height="675" data-path="images/replitai/animation-entry-point.png" />
</Frame>

Agent 开始构建后，系统会生成动画并将其显示在预览窗格中。您可以一边查看视频循环播放，一边继续通过聊天提出修改。

<div id="section-3">
  ## 优化视频
</div>

Agent 生成初始版本后，你可以通过对话继续优化。以下是一些行之有效的方法：

* **使用“增强提示词”按钮** — 该按钮位于聊天输入框中，专门针对视频提示词进行了优化。
* **提出改进要求** — 查看初始版本后，提出“让它更好一些”或“让场景中的动画更复杂、更有创意”之类的要求，通常会有不错的效果。
* **明确说明需求** — 例如，“让转场更流畅”、“将配色方案改为深蓝色和金色”或“在结尾添加 Logo 揭示动画”。

多发送几条不同的提示词，你很可能会得到至少一个满意的结果。

<div id="section-4">
  ## 视频导出
</div>

对视频效果满意后，您可以将其导出为 MP4 文件。

1. 找到预览窗格右上角的**导出**按钮。
2. 选择所需的质量设置：
   * **分辨率**：720p 或 1080p
   * **帧率**：30fps 或 60fps
3. 选择**导出**。渲染可能需要几分钟，具体取决于视频的复杂程度。
4. 渲染完成后，MP4 文件会自动下载。

您也可以选择**发布**来分享视频链接。

**导出时间**：渲染较长或较复杂的视频可能需要几分钟。导出在服务器端进行，因此您可以在处理期间继续工作。

<div id="section-5">
  ## 使用场景
</div>

动画视频可满足各种创意和专业场景的需求：

* **产品发布视频** — 通过精美的宣传视频发布新应用、功能和产品版本。
* **品牌与电影感视频** — 为企业、城市、大学和活动制作视觉效果丰富的视频。
* **讲解视频** — 在 30 至 60 秒内说明产品、功能或概念的运作方式。
* **社交媒体内容** — 为 X、LinkedIn、Instagram 或 TikTok 制作吸引用户停留的动态图形。
* **落地页视频** — 为网站添加动画主视觉区或背景视频。
* **融资与投资者更新** — 制作专业视频，宣布重要里程碑。

<div id="section-6">
  ## 视频规格
</div>

| 属性      | 详情                                               |
| ------- | ------------------------------------------------ |
| **格式**  | MP4                                              |
| **分辨率** | 720p 或 1080p                                     |
| **帧率**  | 30fps 或 60fps                                    |
| **宽高比** | 16:9 (默认)                                        |
| **渲染**  | 服务器端渲染；动画库 (主要用于网站) ＋自定义 Agent 技能 — 不使用 Remotion |
| **播放**  | 在预览窗格中自动循环播放                                     |

<div id="section-7">
  ## 常见问题
</div>

* **可以暂停或播放视频吗？** 预览没有内置的暂停/播放控件。视频会始终循环自动播放。如果您需要为视频添加暂停/播放 (或场景选择) 功能，可以让 Agent 添加——但添加这些控件可能会影响设计效果，因此建议保留默认的循环播放。
* **可以选择场景吗？** 预览没有内置的场景选择器。您可以让 Agent 添加场景选择或其他控件。同样需要权衡上述取舍。

<div id="section-8">
  ## 限制
</div>

动画视频是一项新功能，目前存在一些限制：

* **仅支持程序化动画**：视频是基于 React 的动态图形。 (如 Runway 或 Sora 那样的) AI 生成视频不在支持范围内，但你可以生成视频并在代码中使用。
* **渲染时间**：导出复杂动画可能需要几分钟。简单视频的渲染速度更快。
* **可能需要多次迭代**：许多提示词一次就能获得出色结果，但要得到你想要的确切效果，可能需要迭代 2 到 3 个版本。对初始提示词使用“增强提示词”按钮，并在第一个检查点后提供反馈，有助于改善结果。

  ## 后续步骤
