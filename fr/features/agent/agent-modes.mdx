Les modes d&#39;Agent vous permettent de doser l&#39;équilibre entre coût et capacités lorsque vous utilisez Agent. Utilisez le menu déroulant des paramètres d&#39;Agent pour choisir **Free Mode**, **mode Power** ou **mode Max**. Free Mode utilise toujours le routage intelligent des modèles. En Power ou Max, les créateurs Core et Pro peuvent sélectionner **Auto** pour laisser Replit choisir un modèle adapté à chaque tâche. Ils peuvent également utiliser le [sélecteur de modèle](/fr/features/agent/model-selector) pour choisir un modèle manuellement. Les modes et paramètres qui s&#39;affichent dépendent de votre plan et de votre workspace.

<Note>
  Economy Mode n&#39;est plus disponible. mode Power le remplace au même prix.
</Note>

<Tip>
  **Raccourci clavier :** appuyez sur **⌘+Maj+I** (Ctrl+Maj+I sous Windows) pour passer
  d&#39;un mode d&#39;Agent à l&#39;autre sans quitter le champ de saisie du chat.
</Tip>

<div id="free-mode">
  ## Free Mode
</div>

**Optimisé pour bien démarrer.** Free Mode vous aide à explorer des idées, à comprendre le fonctionnement de Replit et à lancer un projet.

**À retenir :** Free Mode utilise toujours le routage intelligent des modèles. Pour sélectionner un modèle manuellement, utilisez le mode Power ou le mode Max.

<Note>
  {FreeModePlanAvailability} Lorsque vous atteignez la limite de votre forfait, Replit
  indique la date de réinitialisation.
</Note>

Les Routines ne s&#39;exécutent pas en Free Mode. Elles s&#39;exécutent en mode Power ou Max et nécessitent un budget par exécution. En savoir plus sur les [Routines](/fr/chat/routines).

<div id="intelligent-model-routing-auto">
  ## Routage intelligent des modèles (Auto)
</div>

**Optimisé pour la sélection automatique des modèles.** En mode Power ou Max, les créateurs Core et Pro peuvent sélectionner **Auto**. Replit choisit alors, pour chaque tâche, un modèle dans la limite des capacités du mode sélectionné. Consultez [Utiliser le routage intelligent des modèles](/fr/chat/auto-mode).

Auto est une alternative payante à Free Mode. Il consomme des crédits d&#39;abonnement, comme les autres tâches réalisées en Power et Max.

Les workspaces Enterprise utilisent un **mode Auto** unique à la place de Free Mode. Auto pour Enterprise peut choisir à la fois le mode et un modèle autorisé pour chaque tâche.

<div id="power-mode">
  ## Mode Power
</div>

**Optimisé pour le coût.** Le mode Power consomme moins de crédits par tâche et constitue le meilleur choix par défaut lorsque vous souhaitez de bons résultats sans payer pour les modèles les plus performants.

**Idéal pour :** les créations du quotidien, l&#39;apprentissage et le travail soucieux des coûts sur un projet existant.

<div id="max-mode">
  ## Mode Max
</div>

**Optimisé pour la puissance.** Le mode Max s&#39;appuie sur des modèles plus performants pour les tâches complexes, les bases de code volumineuses et les problèmes difficiles.

**Idéal pour :** les projets de niveau production, les fonctionnalités complexes et les cas où vous souhaitez obtenir les meilleurs résultats d&#39;Agent.

<div id="which-mode-should-i-use">
  ## Quel mode utiliser ?
</div>

Servez-vous du tableau suivant comme guide :

| Objectif                                                                        | Mode recommandé                                                            |
| ------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| Explorer des idées, découvrir le fonctionnement de Replit et démarrer un projet | Free Mode                                                                  |
| Laisser Replit choisir un modèle pour un travail payant                         | Auto en mode Power ou mode Max                                             |
| Maximiser le nombre de prompts par crédit                                       | mode Power                                                                 |
| Trouver le bon équilibre entre coût et qualité pour la plupart des projets      | mode Power                                                                 |
| Sélectionner un modèle manuellement                                             | mode Power ou mode Max                                                     |
| Obtenir les meilleurs résultats sur des travaux complexes, de niveau production | mode Max                                                                   |
| Obtenir le meilleur résultat possible sur les tâches les plus complexes         | mode Max avec un [Effort](/fr/features/agent/model-selector#effort) supérieur |

Utilisez le menu déroulant des paramètres de l&#39;Agent dans le champ de saisie du Chat pour choisir un mode. En Power ou en Max, les créateurs Core et Pro peuvent utiliser Auto ou définir un [modèle principal et un Effort](/fr/features/agent/model-selector). Aucun mode n&#39;est idéal en toutes circonstances : choisissez celui qui convient à la tâche du moment.

<div id="settings-in-shared-projects">
  ## Paramètres dans les projets partagés
</div>

Vos paramètres Agent sont liés à votre compte, et non au projet. Lorsque vous invitez un coéquipier dans un projet, chacun conserve ses propres choix pour :

* Le mode (Free Mode, mode Power ou mode Max)
* [Le modèle principal et l&#39;effort](/fr/features/agent/model-selector), lorsqu&#39;ils sont disponibles
* [mode Plan](/fr/features/agent/plan-mode)
* La fusion automatique des tâches en arrière-plan
* L&#39;approbation automatique des plans

Si un coéquipier passe en mode Max pour sa prochaine tâche, vos paramètres ne basculent pas pour autant en mode Max. Le mode et les paramètres affichés dans le menu déroulant des paramètres Agent sont ceux qu&#39;Agent utilise lorsque vous envoyez votre message suivant, quel que soit le nombre de collaborateurs présents dans le projet.

<div id="check-your-free-mode-usage">
  ## Vérifier votre utilisation du Free Mode
</div>

Ouvrez **Settings** → **Usage** pour consulter votre limite Free Mode actuelle et sa date de réinitialisation. Pour des conseils pratiques, consultez [Tirer le meilleur parti du Free Mode](/fr/chat/free-mode).
