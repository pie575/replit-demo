<Note>
  Некоторые сведения о лимите могут быть уточнены к запуску.
</Note>

Free Mode позволяет подписчикам Starter, Core и Pro пользоваться Agent без дополнительной платы. Для Starter Free Mode доступен в рамках действующих ограничений. Тарифы Core и Pro включают лимит Free Mode. Откройте Conversation, чтобы изучить возможности, спланировать работу, создать что-то или обратиться за помощью. Если для запроса требуется платный режим или действие, Replit сообщит об этом до начала списания средств.

<div id="why-youll-like-it">
  ## Почему вам это понравится
</div>

* Начните с Conversation, а не с настройки.
* Изучайте идеи и двигайтесь вперёд, прежде чем решать, нужны ли вам дополнительные возможности.
* Сохраняйте контроль, если запрос требует платного действия.
* Для работы, выполненной в Free Mode, отображается понятная метка **Бесплатно**.

<div id="how-it-works">
  ## Как это работает
</div>

1. Новые сеансы Starter, Core и Pro начинаются в режиме Free Mode.
2. Если задача подходит для Free Mode, работа продолжается без предложения перейти на платный режим.
3. Если с запросом лучше справится платный режим, Agent объяснит это и предложит выбрать.
4. Вы можете разрешить платный режим только для этого запроса или попросить Agent продолжить в Free Mode.
5. После разового перехода на платный режим вы вернётесь в Free Mode.

<div id="the-three-agent-modes">
  ## Три режима Agent
</div>

<CardGroup cols={3}>
  <Card title="Free">
    Бесплатная работа с Agent для подписчиков Starter, Core и Pro.
  </Card>

  <Card title="Power">
    Платный режим среднего уровня для задач, требующих больше возможностей по доступной цене.
  </Card>

  <Card title="Max">
    Платный режим высшего уровня для самых сложных задач с лучшими передовыми моделями.
  </Card>
</CardGroup>

Free Mode доступен подписчикам Starter, Core и Pro. В Starter Free Mode предоставляется с действующим ограничением. В Core и Pro предусмотрен лимит использования Free Mode, а в Pro еженедельный лимит выше. Если вам требуется больше возможностей, можно выбрать платный режим Agent.

В Core и Pro интеллектуальная маршрутизация моделей — платная альтернатива Free Mode. Выберите **Auto** в режиме Power или Max, чтобы Replit подбирал модель для каждой задачи.

<Note>
  **Если вы достигли лимита:** в Starter Free Mode предоставляется с действующим ограничением. В Core и Pro лимит Free Mode сбрасывается каждые пять часов и имеет еженедельное ограничение. Проверьте **Settings → Usage**, чтобы узнать, сколько лимита уже использовано. Replit предупредит вас о приближении к лимиту. Когда лимит будет достигнут, переключитесь на платный режим, чтобы продолжить работу, или дождитесь сброса.
</Note>

<div id="common-questions">
  ## Частые вопросы
</div>

<AccordionGroup>
  <Accordion title="Free Mode действительно бесплатен? Replit теперь бесплатен?">
    Free Mode включен в подписки Starter, Core и Pro. В Starter Free Mode предоставляется с действующими ограничениями. В Core и Pro предусмотрен лимит использования Free Mode. Это не отдельный бесплатный тариф.
  </Accordion>

  <Accordion title="Это то же самое, что платный режим Agent?">
    Нет. Free Mode — это бесплатное использование Agent в пределах установленного лимита. Power и Max — платные режимы для задач, требующих больше возможностей.
  </Accordion>

  <Accordion title="Что случилось с Economy и Power? Режимы изменились?">
    Платные режимы были переименованы. Economy теперь называется Power — это режим среднего уровня с мощными моделями по доступной цене. Режим, который раньше назывался Power, теперь называется Max — это режим высшего уровня. Существующие настройки режимов сохраняются под новыми названиями.
  </Accordion>

  <Accordion title="Какой режим самый мощный?">
    Max. Power — платный режим среднего уровня с расширенными возможностями по доступной цене. Max — платный режим высшего уровня для самых сложных задач.
  </Accordion>

  <Accordion title="Что, если моему запросу требуется платное действие?">
    Agent сообщит, что для выполнения запроса требуется платный режим или платная возможность, и запросит подтверждение перед продолжением. Вы можете одобрить этот запрос один раз или продолжить работу в Free Mode.
  </Accordion>

  <Accordion title="Будет ли плата списана автоматически, если Agent предложит перейти на другой режим?">
    Нет. Для перехода на платный режим необходимо ваше подтверждение до начала выполнения платного запроса.
  </Accordion>

  <Accordion title="Могу ли я отказаться от платного варианта?">
    Да. Вы можете продолжить работу в Free Mode.
  </Accordion>

  <Accordion title="Что произойдет после одобрения перехода на платный режим?">
    Одобрение действует только для этого запроса. После этого режим Agent вернется к Free Mode.
  </Accordion>

  <Accordion title="Почему я достиг лимита? Когда он сбросится?">
    В Starter Free Mode предоставляется с действующими ограничениями. Для Core и Pro лимит использования Free Mode сбрасывается каждые пять часов и имеет недельное ограничение. Проверьте **Settings → Usage**, чтобы узнать текущий расход лимита. Достигнув лимита, переключитесь на платный режим, чтобы продолжить, или дождитесь сброса.
  </Accordion>

  <Accordion title="Доступен ли Free Mode в Enterprise?">
    Нет. Вместо этого в Workspace Enterprise используется единый режим Auto. Он выбирает режим и разрешенную модель для каждой задачи. См. [настройки моделей Enterprise](/ru/features/collaboration/enterprise-model-controls).
  </Accordion>
</AccordionGroup>

<div id="more-about-free-mode">
  ## Подробнее о Free Mode
</div>

<AccordionGroup>
  <Accordion title="Free Mode — это то же, что Lite?">
    Для пользователей Starter режим, ранее называвшийся Lite, теперь называется Free Mode. Если вы использовали Lite для доступа к более дешёвой модели, её по-прежнему можно выбрать вручную в Power, отключив Auto.
  </Accordion>

  <Accordion title="Может ли Free Mode создать полноценное приложение?">
    Да. В Free Mode можно создавать и дорабатывать полноценные приложения.
  </Accordion>

  <Accordion title="Чем отличаются Free, Power и Max?">
    Free Mode — бесплатный режим для повседневной работы с Agent для подписчиков Starter, Core и Pro. В Starter Free Mode доступен с действующим ограничением. В Core и Pro предусмотрен лимит использования Free Mode. Power — платный режим среднего уровня с более широкими возможностями по доступной цене. Max — платный режим высшего уровня для самых требовательных задач.
  </Accordion>

  <Accordion title="Когда стоит переключиться с Free Mode?">
    Используйте Free Mode для повседневной работы. Переключитесь, если для сложной задачи нужны более качественные результаты или возможности, которых нет в Free Mode.
  </Accordion>

  <Accordion title="Может ли Free Mode генерировать видео?">
    Нет. Генерация видео доступна только в платных режимах и не входит в Free Mode.
  </Accordion>

  <Accordion title="Что нового в Conversations?">
    Чат и создание приложения объединены. В рамках одного Conversation можно изучить идею, спланировать работу или начать Project.
  </Accordion>

  <Accordion title="Становятся ли отдельные чаты частью опубликованного приложения?">
    Нет. Conversation остаётся отдельным, пока вы не создадите или не измените Project.
  </Accordion>

  <Accordion title="Может ли Free Mode работать с существующим Project?">
    Да. Он поддерживает регулярное обслуживание и правки существующих Project.
  </Accordion>
</AccordionGroup>

**Готовы попробовать?** Когда Free Mode станет доступен, откройте Conversation с Agent и начните работу.
