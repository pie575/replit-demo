export const ProCreditRolloverPeriod = 'two months';

Replit AI 功能采用按使用量计费，费用取决于您构建的内容以及使用 AI 工具的程度。这样可确保您只为 Agent 带来的价值付费。

<div id="getting-started">
  ## 快速开始
</div>

**所有订阅用户**均可获得一次性的免费 Agent checkpoint。

每月额外发放的积分会自动用于 AI 使用：

* **Core 订阅用户**：每月积分 (详见[定价](https://replit.com/pricing))
* **Pro 订阅用户**：分级月度积分，且可结转 {ProCreditRolloverPeriod}。详见 [Replit Pro](/zh/billing/plans/replit-pro)。

这些积分可用于 Agent，以及已发布应用、存储和数据库等其他 Replit 云服务。你可以先用 Free Mode 完成免费的工作。在 [Power 或 Max](/zh/features/agent/agent-modes) 模式下，选择 Auto，让 Replit 为付费任务挑选合适的模型。

  ## Agent 计费
</div>

  <img src="/assets/mirror/checkpoint-f0cc3c49b9a5.png" alt="显示 Chat 和 checkpoint 系统的 Replit Agent 界面" width="1999" height="1242" data-path="images/billing/checkpoint.png" />

Free Mode 为 Core 和 Pro 订阅者提供额度内免费的日常 Agent 使用。付费模式和经确认的付费任务会根据请求的复杂程度按工作量计费。付费操作开始前，Replit 会要求你确认。

<div id="how-effort-based-pricing-works">
  ### 基于工作量的计费如何运作
</div>

当你在“Build 模式”下与 Agent 对话时，它会创建 **checkpoint**，记录针对你的请求已完成的工作：

* **简单请求** (例如修复缺陷或小幅改动) 的费用通常低于复杂构建
* **复杂构建** (例如完整功能或 integration) 会被打包为一个 checkpoint，其费用可能高于简单请求，以反映所投入的总体工作量
* **每个请求只生成一个 checkpoint**，避免产生中间 checkpoint，减少计费干扰
* **透明定价**让你清楚了解每项已完成 task 的付费内容

<Info>
  当 Agent 完成你请求的工作并在代码中实现相应功能时，就会产生一个 checkpoint。
</Info>

在付费路径中，Plan 模式即使不修改代码，也可能执行需计费的推理工作。

如需详细了解 checkpoint 记录哪些内容及其运作方式，请参阅 [Checkpoint 与回滚](/zh/features/version-control/checkpoints-and-rollbacks)。

<div id="agent-services-billing">
  ### Agent 服务计费
</div>

部分 Agent 功能会在后台调用付费的第三方 API (例如 Claude、ChatGPT 和 Nano Banana / Gemini) 。Agent 会自动处理这些集成，无需 API 密钥或额外设置。系统将按照提供方公开的 API 费率，从你的 Replit 积分中扣除相应费用。这些费用会与其他用量一同显示在[用量仪表板](/zh/billing/managing-spend)中。

如需了解示例应用的费用，请查看我们的简易[交互式演示](https://agent-pricing.replit.app/)。

<div id="track-your-usage">
  ### 跟踪使用情况
</div>

你可以实时监控 Agent 支出：

1. **Agent 标签页**：将鼠标悬停在用量图标上，查看各个 checkpoint 的费用
2. **用量仪表板**：查看当前周期的详细账单信息
3. **设置**：在 **账户** → **账单** 中设置提醒和预算，以控制支出

<Tip>
  用量数据最多可能需要 30 分钟才会显示在用量仪表板上。
</Tip>

<div id="managing-your-spend">
  ## 管理支出
</div>

借助 Replit 内置的预算工具，掌控你的 AI 支出：

* **用量提醒**：达到支出阈值时收到通知
* **预算上限**：设置硬性上限，避免产生意外费用
* **实时跟踪**：构建过程中随时监控成本
* **积分包**：购买额外积分，购买量越大折扣越多。详情请参阅[管理支出](/zh/billing/managing-spend)。

<div id="next-steps">
  ## 后续步骤
</div>

准备好开始用 AI 构建了吗？以下方法可帮助你充分利用积分：

* **先试用 Agent**：使用免费的 checkpoint 探索 Agent 的功能
* **从简单任务开始**：先提出简单的请求，了解按工作量计费的方式
* **使用 Free Mode**：日常工作可从 [Free Mode](/zh/features/agent/agent-modes) 开始
* **设置提醒**：在积分超额使用前配置消费通知
