Construisez des applications avec des données actuelles du monde réel grâce aux capacités de recherche web <img class="icon-svg" src="/assets/mirror/web-search-1fe8f63b5b88.svg" alt="Icône de recherche web" width="16" height="16" data-path="images/icons/web-search.svg" /> d'Agent.

Cette fonctionnalité surmonte les limites de connaissance en accédant aux informations les plus récentes sur le web. Lorsque vous demandez à Agent de créer quelque chose nécessitant des informations à jour, il effectue des recherches sur le web et récupère du contenu détaillé pour rendre votre application plus précise et utile.

La recherche web est précieuse pour trouver les derniers packages, outils et informations. Cela garantit que vos applications utilisent les meilleures pratiques actuelles et sont plus précises.

## Fonctionnalités

Construisez des applications avec des informations actuelles grâce à la recherche web d'Agent. Cela élimine la recherche manuelle et la collecte de données. Que vous créiez un tableau de bord avec des données financières ou un site web présentant les derniers lancements de startups, la recherche web garantit que votre application reflète la réalité.

Agent peut effectuer les actions de recherche web suivantes :

* **Recherche** : Trouvez des informations actuelles, la documentation la plus récente et des données en temps réel sur internet
* **Récupération de contenu** : Récupérez des informations détaillées depuis des sites web et des URL spécifiques
* **Citations de sources** : Voyez exactement où Agent a trouvé les informations afin que vous puissiez les vérifier et les référencer

## Utilisation

La recherche web est intégrée à Agent — rien à activer. Décrivez ce que vous souhaitez construire, et Agent détermine automatiquement quand effectuer des recherches sur le web pour des informations actuelles. Incluez des mots-clés comme « recherche », « trouvez » ou « utilisez la recherche web » dans votre prompt pour inciter explicitement Agent à effectuer une recherche.

### Comment la recherche web améliore vos applications

La recherche web transforme vos applications en passant de données fictives à des informations réelles et précises :

| Avantage                       | Description                                                                                          |
| ------------------------------ | ---------------------------------------------------------------------------------------------------- |
| Technologie à jour             | Vos applications utilisent les dernières informations et packages absents des données d'entraînement |
| Meilleure sélection d'outils   | Agent recherche les options pour choisir les packages optimaux                                       |
| Meilleures pratiques actuelles | Accès aux derniers patterns de développement et pratiques de sécurité                                |
| Dépassement des limites        | Surmontez les limites de connaissance pour utiliser des packages publiés après l'entraînement        |
| Données précises               | Vos applications affichent des informations actuelles plutôt que des exemples obsolètes              |
| Résultats professionnels       | Les applications qui référencent de vraies entreprises semblent crédibles                            |
| Gain de temps                  | Évitez de rechercher manuellement des packages et de rassembler des données                          |

### Citations de sources

Lorsqu'Agent utilise la recherche web, il fournit des **citations de sources** indiquant exactement d'où proviennent les informations. Utilisez ces citations pour :

* **Vérifier les informations** : Contrôlez la fiabilité et l'exactitude des sources
* **En savoir plus** : Visitez les sources originales pour plus de contexte
* **Référencer les sources** : Incluez une attribution appropriée dans vos applications
* **Suivre la recherche** : Comprenez quelles informations ont guidé le travail d'Agent

### Récupération de contenu

Agent peut récupérer du contenu détaillé depuis des sites web spécifiques pour rassembler des informations complètes pour votre projet. Cela permet à Agent de :

* Lire des pages web entières pour en extraire des détails pertinents
* Traiter la documentation et les matériaux de référence
* Rassembler des points de données spécifiques à partir de sources faisant autorité
* Intégrer des informations structurées dans votre application

### Exemples de recherche web en action

**Découverte de packages pour le traitement d'images**

<AiPrompt>
  Construisez une application React qui permet aux gens d'appliquer des filtres à des photos. Recherchez les meilleures bibliothèques de traitement d'images pour React et implémentez des effets de flou, de netteté et vintage
</AiPrompt>

Agent recherche les bibliothèques de traitement d'images actuelles, compare leurs fonctionnalités et performances, puis construit l'application en utilisant les outils les plus adaptés.

<Tip>
  La recherche web fonctionne mieux avec des demandes spécifiques et détaillées. Pour la découverte de technologies, mentionnez vos exigences spécifiques
</Tip>

**Dernières fonctionnalités de framework**

<AiPrompt>
  Effectuez des recherches pour comprendre les dernières meilleures pratiques de sécurité pour l'authentification et l'autorisation. Implémentez ces meilleures pratiques dans mon application.
</AiPrompt>

Agent recherche les dernières meilleures pratiques de sécurité pour l'authentification et l'autorisation et les implémente dans votre application.

**Intégration d'API moderne**

<AiPrompt>
  Construisez une application météo utilisant l'API météo la plus fiable et la plus riche en fonctionnalités disponible
</AiPrompt>

Agent recherche les API météo actuelles, compare leurs fonctionnalités, leur fiabilité et leur tarification pour sélectionner la meilleure option pour vos besoins.

**Site de présentation de startups**

<AiPrompt>
  Construisez un site web présentant les dernières startups de la promotion Y Combinator
</AiPrompt>

Agent recherche les informations actuelles sur les promotions YC et crée un site avec de vraies données de startups, logos et descriptions.

**Site portfolio personnel**

<AiPrompt>
  Créez un site web personnel pour Michele Catasta, ancien chercheur à Stanford et président de Replit.
</AiPrompt>

Agent recherche des informations professionnelles et crée un portfolio authentique avec l'expérience et le parcours pertinents.

**Application de planification de voyage**

<AiPrompt>
  Construisez un planificateur de voyage pour le Japon avec les prix et recommandations actuels
</AiPrompt>

Agent trouve des informations de voyage à jour sur les coûts, les attractions et la planification pour créer une application de voyage réaliste.

**Tableau de bord de comparaison financière**

<AiPrompt>
  Créez un tableau de bord comparant les derniers bénéfices trimestriels des principaux fournisseurs de cloud
</AiPrompt>

Agent recherche les derniers rapports financiers et construit un tableau de bord avec des visualisations de données actuelles et précises.

<Warning>
  Vérifiez toujours les informations provenant des résultats de recherche web, en particulier pour les applications critiques. Bien qu'Agent effectue des recherches dans des sources réputées, confirmez les détails importants pour les applications en production.
</Warning>
