<div id="pesquisa-de-sistema-de-arquivos-aprimorada">
  ### 文件系统搜索优化
</div>

Agent 现在可在整个代码库中提供更智能、更直观的文件搜索。借助先进的长上下文 AI，Agent 能够理解项目的结构和内容，为你的查询提供更深入的上下文和更相关的回答，让你比以往更轻松地准确找到所需内容。

<div id="integrao-do-object-storage-com-o-agent">
  ### Object Storage 与 Agent 集成
</div>

借助 [Agent](/zh/pt/core-concepts/agent) 新增的 [Object Storage](/zh/pt/features/data-and-storage/object-storage) 功能，轻松实现文件上传！您的 AI 助手现在可以配置 Object Storage、检查配置，并生成完整的后端和前端代码，支持身份验证、访问控制等高级功能。

详细了解 [Object Storage](/zh/pt/features/data-and-storage/object-storage)，并探索所有可用的 [Agent 集成](/zh/replitai/integrations#data-storage--management)。

<div id="melhoria-de-foco-no-editor-visual">
  ### 可视化编辑器焦点优化
</div>

使用[可视化编辑器](/zh/pt/replitai/visual-editor)时保持顺畅操作！选择要编辑的元素后，焦点会自动返回 Chat 输入框，让你无需中断即可立即输入下一个 prompt。

<div id="sugestes-de-reverso-e-alternncia-de-data">
  ### 回滚建议和日期切换
</div>

借助智能回滚建议和灵活的日期显示方式，更轻松地浏览项目历史记录！获取有关何时回滚代码的智能建议，并可在相对时间戳和绝对时间戳之间切换，找到理想的检查点。

<div id="atividades-ao-vivo-no-ios">
  ### iOS 实时活动
</div>

即使离开电脑，也能随时关注您的 [Workspace](/zh/pt/core-concepts/project-editor)！借助 iOS 实时活动，您可以监控正在运行的项目，并轻点锁定屏幕或通知中心，即可返回 Workspace。

<div id="suporte-a-registros-mx-para-domnios">
  ### 域名 MX 记录支持
</div>

轻松连接电子邮件提供商！现在，您可以为[通过 Replit 购买的域名](/zh/pt/features/publishing/custom-domains)创建 MX 记录，以关联电子邮件提供商并为项目管理自定义电子邮件服务。
