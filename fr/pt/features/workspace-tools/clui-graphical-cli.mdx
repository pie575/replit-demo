Le CLUI (Command Line User Interface) est la barre de commande interactive de Replit qui permet d&#39;effectuer rapidement de nombreuses actions sans passer par les menus. Il allie l&#39;efficacité d&#39;une ligne de commande à une interface graphique.

<div id="recursos">
  ## Fonctionnalités
</div>

Le CLUI offre de puissantes interactions par commandes dans trois contextes différents sur Replit :

* **Gestion des paramètres** : gérez vos paramètres, consultez les avertissements et restaurez les Replit Apps supprimées
* **Navigation rapide** : passez d&#39;une Replit App à l&#39;autre et accédez aux ressources courantes grâce à des raccourcis
* **Opérations dans le workspace** : trouvez des fichiers, recherchez du code et accédez aux outils au sein de votre environnement de développement

<div id="uso">
  ## Utilisation
</div>

<div id="clui-da-conta">
  ### CLUI du compte
</div>

Le CLUI du compte vous permet de gérer vos paramètres, vos équipes et les Replit Apps supprimées.

**Comment y accéder** : accédez à la [page du CLUI](https://replit.com/~/cli), saisissez une commande dans la boîte de réception, puis appuyez sur Entrée pour l’exécuter.

<Accordion title="Commandes du compte">
  Saisissez `account` pour gérer vos paramètres :

  * **view-warns** : consultez les avertissements que vous avez reçus
  * **change-username** : modifiez votre nom d’utilisateur (une seule fois)
</Accordion>

<Accordion title="Commandes de la corbeille">
  Saisissez `trash` pour gérer les Replit Apps supprimées :

  * **restore &lt;title&gt;** : restaure une Replit App supprimée à partir de son titre (restaure la plus récemment supprimée si plusieurs portent le même nom)
  * **view** : consultez les Replit Apps que vous avez supprimées récemment
</Accordion>

<Accordion title="Commandes d’équipe">
  Saisissez `team` pour gérer vos équipes :

  * **view** : consultez les membres d’une équipe dont vous faites partie à l’aide de son nom d’utilisateur
  * **fork-repl-to-project** : créez un fork d’une Replit App existante afin de créer un Project d’équipe
</Accordion>

<Accordion title="Commande d’effacement">
  Saisissez `clear` pour effacer de l’écran toutes les commandes précédentes que vous avez exécutées
</Accordion>

<div id="clui-de-atalhos">
  ### CLUI des raccourcis
</div>

Le CLUI des raccourcis offre un accès rapide aux fonctionnalités courantes de Replit depuis n&#39;importe quelle page.

<Frame>
  <img src="/assets/mirror/shortcuts-clui-768d49b44785.png" alt="CLUI des raccourcis" width="689" height="291" data-path="images/getting-started/shortcuts-clui.png" />
</Frame>

**Comment y accéder** : appuyez sur **CMD/CTRL + K** ou cliquez sur l&#39;icône de recherche dans la barre de navigation supérieure, disponible sur la plupart des pages de Replit.

<Accordion title="Commandes disponibles">
  * **Search** : recherchez sur Replit des Replit Apps, des Templates, du Code, des Personnes et bien plus
  * **New** : créez une nouvelle Replit App
  * **My Replit Apps** : parcourez vos Replit Apps et accédez-y
  * **My Code** : effectuez une recherche dans le code de toutes vos Replit Apps
</Accordion>

<div id="clui-do-workspace">
  ### CLUI du workspace
</div>

Le CLUI du Workspace vous aide à effectuer des opérations, accéder aux outils, trouver des fichiers et rechercher dans votre code pendant que vous travaillez sur une Replit App.

<Frame>
  <img src="/assets/mirror/ws-clui-81764b3d111b.png" alt="CLUI du Workspace" width="429" height="202" data-path="images/getting-started/ws-clui.png" />
</Frame>

**Comment y accéder** : appuyez sur **CMD/CTRL + K** ou cliquez sur l&#39;icône de recherche en haut à gauche lorsque vous êtes dans le Workspace.

<Accordion title="Opérations courantes">
  * **Find files** : localisez rapidement des fichiers dans votre projet
  * **Search code** : trouvez des extraits de code précis dans vos fichiers
  * **Access tools** : ouvrez n&#39;importe quel outil ou panneau disponible dans le Workspace
  * **Run commands** : exécutez des commandes propres au workspace
</Accordion>
