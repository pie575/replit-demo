Project Analytics montre comment les internautes trouvent et utilisent votre web app publiée. Ouvrez le volet **Growth** pour consulter les tendances de fréquentation, les sources de trafic et les événements personnalisés.

Replit collecte par défaut des métriques de trafic pour les apps publiées prises en charge. Avec un forfait payant, Agent peut ajouter des événements personnalisés et répondre à vos questions sur vos analyses.

<div id="before-you-start">
  ## Avant de commencer
</div>

Analytique du projet nécessite :

* **Un site web publié.** Analytics prend en charge les [artifacts](/fr/features/projects-and-artifacts/artifacts) de type site web, mais ne collecte aucun événement provenant des applications mobiles ou des autres types d&#39;artifacts.
* **Un deployment pris en charge.** Analytique du projet fonctionne avec les deployments [Autoscale](/fr/features/publishing/deployment-types#autoscale), [Reserved VM](/fr/features/publishing/deployment-types#reserved-vm) et [Static](/fr/features/publishing/deployment-types#static).
* **Un forfait payant pour les analyses avancées.** Les événements personnalisés et les requêtes d&#39;analyse avec Agent sont réservés aux forfaits payants.
* **Analytics activé lors de votre prochaine publication.** Replit commence à collecter les événements une fois que vous avez activé **Enable analytics** et publié ou republié votre application.

<div id="open-project-analytics">
  ## Ouvrir l’Analytique du projet
</div>

1. Ouvrez votre projet dans le Project Editor.
2. Sélectionnez **Tools**.
3. Sous **Replit Cloud**, sélectionnez **Growth**.

<Note>
  Le **volet Growth** reste verrouillé tant que vous n&#39;avez pas publié votre app. Avant cela, il
  vous invite à sélectionner **Go to Publishing**.
</Note>

Les données d&#39;analyse apparaissent dès que votre app publiée reçoit du trafic. Les nouvelles apps peuvent afficher des graphiques vides tant que personne ne les consulte.

<div id="review-default-analytics">
  ## Consulter les analyses par défaut
</div>

Les analyses par défaut s&#39;appuient sur les données de trafic IP pour afficher les métriques suivantes :

* **Visiteurs** : le nombre approximatif de visiteurs uniques sur la période sélectionnée.
* **Visiteurs au fil du temps (heure)** ou **Visiteurs au fil du temps (jour)** : l&#39;évolution de l&#39;activité des visiteurs sur la période sélectionnée.
* **Pages les plus consultées** : les pages qui reçoivent le plus de trafic.
* **Principaux référents** : les sites web qui génèrent du trafic vers votre application.
* **Principaux pays** : les pays approximatifs de vos visiteurs.
* **Principaux navigateurs** : les navigateurs utilisés par les visiteurs.
* **Principaux appareils** : les types d&#39;appareils utilisés par les visiteurs.

Utilisez le menu de plage horaire pour afficher des périodes allant de six heures à 30 jours. Le total des visiteurs compare chaque période à la période précédente de même durée.

Si votre application utilise [Replit Auth](/fr/features/auth-and-identity/authentication), le volet affiche également le nombre d&#39;**utilisateurs connectés uniques** pour la période sélectionnée.

<Note>
  Le nombre de visiteurs est approximatif. Il repose sur des données réseau et
  navigateur, et une même personne peut être comptée comme plusieurs visiteurs
  selon les appareils ou les mois civils.
</Note>

<div id="add-custom-events-with-agent">
  ## Ajouter des événements personnalisés avec Agent
</div>

Les événements personnalisés mesurent les actions qui comptent pour votre app : inscriptions finalisées, forfaits sélectionnés, formulaires envoyés ou achats effectués, par exemple.

<Steps>
  <Step title="Ajouter des métriques avec Agent">
    Ouvrez **Growth**. Dans **analyses avancées**, sélectionnez **Ajouter des métriques avec
    Agent**. Indiquez à Agent les actions que vous souhaitez mesurer. Agent ajoute le
    suivi des événements aux endroits pertinents de votre app.
  </Step>

  <Step title="Activer l'analytique et publier">
    Ouvrez **Publishing** et lancez une nouvelle publication ou une republication. Sous **Suggested
    add-ons**, activez **Enable analytics**. Publiez ensuite votre app. Replit
    commence alors à collecter les vues de page et les événements personnalisés à partir de cette version.
  </Step>
</Steps>

<Tip>
  Vous pouvez également demander à Agent de configurer l&#39;analytique directement depuis le Chat. N&#39;hésitez pas à
  lui demander d&#39;ajouter ou de mettre à jour des événements à tout moment, au fil de l&#39;évolution de votre app ou de vos objectifs de mesure.
</Tip>

Replit ajoute le traceur d&#39;analytique à votre app publiée. Vous n&#39;avez pas besoin d&#39;ajouter de script de suivi, d&#39;identifiant de site web ni de variable d&#39;environnement dédiée à l&#39;analytique.

<Warning>
  N&#39;incluez pas de Secrets, de données personnelles ni de contenu libre saisi par les visiteurs dans les noms
  ou les propriétés des événements personnalisés.
</Warning>

<div id="ask-agent-about-your-analytics">
  ## Interroger Agent au sujet de vos analyses
</div>

Une fois que votre app collecte des données, utilisez les puces de la section **Analyses avancées** :

* **Résumer mes analyses** : Agent résume les analyses de votre projet sur les sept derniers jours.
* **Suggérer des améliorations du projet** : Agent examine vos analyses et recommande les points à améliorer dans votre projet.

Vous pouvez également poser une question précise à Agent.

<AiPrompt>
  Compare les visiteurs et les inscriptions finalisées sur les sept derniers
  jours. Montre la tendance quotidienne et identifie les pages ayant le taux de
  conversion le plus élevé.
</AiPrompt>

Agent peut analyser les vues de page, les sources de trafic, les événements personnalisés, les propriétés d&#39;événements et les entonnoirs. Il s&#39;appuie sur les données analytiques de votre projet et renvoie des résultats agrégés.
