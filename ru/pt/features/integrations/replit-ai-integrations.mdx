ИИ-интеграции Replit упрощают создание приложений с искусственным интеллектом. Начните использовать модели OpenAI, Anthropic, Google и OpenRouter прямо сейчас — без настройки аккаунта разработчика и без管理 ключей API. Replit берёт всё это на себя.

<div id="o-que-so-as-integraes-de-ia-do-replit">
  ## Что такое ИИ-интеграции Replit?
</div>

ИИ-интеграции Replit обеспечивают управляемый доступ к моделям ИИ от ведущих провайдеров. Создавайте чат-приложения, генераторы контента и ИИ-инструменты, не покидая Replit. Не нужно заводить сторонние аккаунты разработчика, искать ключи API или оплачивать всё это отдельно.

Когда вы используете ИИ-интеграции Replit, Replit сам управляет учётными данными провайдера и взимает плату по публичному тарифу API. Потребление списывается с ваших кредитов Replit и отображается на [странице использования](/ru/pt/billing/managing-spend) с разбивкой по каждому Replit App.

<Note>
  Для ИИ-интеграций Replit требуется платный тариф (Core, Pro или Enterprise). Создавать приложения с ИИ по собственному ключу API можно и на [тарифе Starter](/ru/pt/billing/plans/starter-plan). См. [Доступность в тарифах](#plan-availability).
</Note>

<div id="recursos">
  ## Возможности
</div>

ИИ-интеграции Replit упрощают разработку с использованием ИИ благодаря встроенному доступу и прозрачной тарификации:

* **Без настройки**: чтобы начать, не нужны ни аккаунт разработчика, ни ключ API
* **Управление учётными данными**: Replit берёт на себя аутентификацию и управление учётными данными провайдера
* **Прозрачная тарификация**: вы платите по публичным ценам API, списание идёт с ваших кредитов Replit
* **Отслеживание использования**: смотрите расход по каждому Replit App на странице использования
* **Поддержка любого стека**: работает со всеми языками программирования и фреймворками
* **Опциональный BYOK**: подключите собственный ключ API, если предпочитаете использовать свои учётные данные

<div id="usando-credenciais-gerenciadas-pelo-replit">
  ### Использование учётных данных, управляемых Replit
</div>

На платном тарифе, когда вы упоминаете в своём prompt ИИ-функции или конкретных провайдеров (OpenAI, Anthropic, Google или OpenRouter), Agent по умолчанию использует ИИ-интеграции Replit:

<AiPrompt>
  Create a web app that uses OpenAI to summarize articles
</AiPrompt>

Понять, какая интеграция задействована, можно по надписи **«OpenAI (управляется Replit)»**, **«Anthropic (управляется Replit)»**, **«Google (управляется Replit)»** или **«OpenRouter (управляется Replit)»** в первом ответе на prompt. Это значит, что Agent будет использовать учётные данные Replit и не потребует ваш собственный ключ API.

**Для первых сборок**: когда вы отправляете первый prompt для создания нового приложения с ИИ-функциями, ИИ-интеграции Replit подключаются автоматически. Agent сразу начнёт сборку с управляемыми учётными данными Replit.

**Для существующих Replit App**: если Agent определит, что вы хотите добавить ИИ-функции в существующий Replit App, он прямо сообщит в Project Editor, что просит разрешение использовать ИИ-интеграции Replit вместо вашего собственного ключа API. Вы увидите запрос на подтверждение:

Нажмите «Одобрить», чтобы продолжить с учётными данными, управляемыми Replit, или «Отклонить», если предпочитаете использовать собственный ключ API.

Использование отслеживается автоматически, а оплата списывается с вашего аккаунта Replit по публичной цене API.

<div id="trazendo-sua-prpria-chave-de-api">
  ### Использование собственного ключа API
</div>

Если вы предпочитаете использовать собственные учётные данные OpenAI, Anthropic, Google или других провайдеров вместо ИИ-интеграций Replit, у вас есть несколько вариантов:

**Для первых сборок**: укажите в своём prompt, что хотите использовать собственный ключ API:

<AiPrompt>
  Create a web app that uses OpenAI to summarize articles. Use my own OpenAI API key.
</AiPrompt>

В ответе вы увидите название провайдера (без пометки «управляется Replit») — это значит, что Agent запросит у вас ключ API.

**Для существующих Replit App**: когда Agent сообщит, что хочет использовать ИИ-интеграции Replit, и покажет запрос на подтверждение, нажмите «Отклонить» вместо «Одобрить».

В обоих случаях Agent доведёт сборку до первого checkpoint и только затем запросит ваш ключ API. Так Agent сначала настроит структуру проекта, а потом сделает паузу, чтобы получить ваши учётные данные.

При использовании собственного ключа API оплату списывает напрямую провайдер, а не кредиты Replit.

<div id="provedores-suportados">
  ## Поддерживаемые провайдеры
</div>

ИИ-интеграции Replit на данный момент поддерживают:

* **OpenAI**: мультимодальные модели для генерации текста, рассуждений и работы со звуком. Поддерживаются chat completions, ответы, генерация изображений, транскрибация аудио (`gpt-4o-transcribe`, `gpt-4o-mini-transcribe`) и аудиовывод (`gpt-audio`, `gpt-audio-mini`).
* **Anthropic**: мультимодальные модели для рассуждений, написания текстов и программирования. Поддерживаются Messages API и взаимодействия с поиском в интернете.
* **Google (Gemini)**: мультимодальные модели для генерации текста и рассуждений. Поддерживается генерация текста и изображений.
* **OpenRouter**: доступ к моделям таких провайдеров, как Microsoft (серия Phi), Meta (серия Llama), Mistral, Qwen, DeepSeek, Nvidia, Amazon и других.

<Note>
  ИИ-интеграции Replit поддерживают **вывод текста, изображений и аудио**. Вывод видео не поддерживается. Если вам нужна генерация видео, придётся использовать собственный ключ API от провайдера, который предоставляет такую возможность.
</Note>

<div id="privacidade-e-disponibilidade-do-openrouter">
  ## Конфиденциальность и доступность OpenRouter
</div>

При использовании OpenRouter через ИИ-интеграции Replit ваши запросы отправляются с особыми настройками конфиденциальности, защищающими ваши данные. Эти настройки важно понимать, поскольку от них зависит, какие модели будут вам доступны.

<div id="configuraes-de-privacidade-para-usurios-self-serve">
  ### Настройки конфиденциальности для пользователей самообслуживания
</div>

Для индивидуальных пользователей и команд Replit отправляет запросы к OpenRouter со следующими параметрами конфиденциальности по умолчанию:

* **Обучение на платных эндпоинтах отключено**: ваши данные не будут использоваться для обучения провайдерами платных моделей
* **Обучение на бесплатных эндпоинтах включено**: провайдеры бесплатных моделей могут обучать свои модели на ваших промптах и ответах модели
* **Публикация на бесплатных эндпоинтах включена**: бесплатные провайдеры могут публиковать ваши промпты и ответы модели в общедоступных наборах данных
* **Журналирование ввода/вывода отключено**: ваши запросы и ответы не записываются OpenRouter ради скидки 1% при выставлении счетов
* **Аналитические файлы cookie отключены**: аналитические файлы cookie не используются

Эти настройки ставят вашу конфиденциальность на первое место и при этом открывают доступ к максимально широкому набору моделей. Однако **некоторые модели могут быть недоступны**, если для них нужны настройки конфиденциальности, отличные от указанных выше.

<div id="configuraes-de-privacidade-para-enterprise">
  ### Настройки конфиденциальности для Enterprise
</div>

Для организаций Enterprise Replit применяет более строгие механизмы контроля конфиденциальности:

* **Только эндпоинты с Zero Data Retention (ZDR)**: доступны только модели с политикой Zero Data Retention
* Действуют также все перечисленные выше настройки конфиденциальности для пользователей тарифов с самообслуживанием
* Это гарантирует, что запросы Enterprise направляются только к тем эндпоинтам, которые не сохраняют никаких данных

Поскольку в Enterprise используются исключительно эндпоинты ZDR, **выбор доступных моделей более ограничен**, чем у пользователей с самообслуживанием. Такой компромисс обеспечивает наивысший уровень конфиденциальности данных для корпоративных рабочих нагрузок.

<div id="disponibilidade-do-plano">
  ## Доступность в тарифах
</div>

Для работы ИИ-интеграций Replit требуется платный тариф. От вашего тарифа зависит и то, как предоставляется доступ.

<div id="starter-gratuito">
  ### Starter (бесплатный)
</div>

На тарифе Starter ИИ-интеграции Replit отключены. Вы по-прежнему можете создавать приложения с ИИ, используя собственный ключ API. См. раздел [Использование собственного ключа API](#bringing-your-own-api-key).

<div id="core">
  ### Core
</div>

На тарифе Core вы можете создавать приложения с ИИ, используя ИИ-интеграции Replit с учётными данными, которыми управляет Replit, — без необходимости管理 ключей API.

<div id="pro-e-enterprise">
  ### Pro и Enterprise
</div>

Для организаций Pro и Enterprise доступ к ИИ-интеграциям Replit по умолчанию отключён. Администраторы организации могут управлять доступом на странице настроек организации:

1. Перейдите в настройки своей организации
2. Найдите раздел ИИ-интеграций Replit
3. Включите или отключите доступ для организации

Если доступ включён, участники организации могут использовать ИИ-интеграции Replit в своих приложениях. Всё использование отслеживается и оплачивается со счёта организации. Если доступ отключён, участникам потребуется указать собственные ключи API для работы с провайдерами моделей ИИ.

<div id="casos-de-uso">
  ## Сценарии использования
</div>

Создавайте мощные ИИ-приложения на любом стеке:

* **Генерация контента**: делайте краткие пересказы статей, генерируйте описания, создавайте контент
* **Анализ и инсайты**: извлекайте ключевую информацию, анализируйте тональность, классифицируйте текст
* **Диалоговые интерфейсы**: создавайте чат-ботов и ИИ-ассистентов
* **Преобразование текста**: переводите, переписывайте или форматируйте контент
* **Помощь с кодом**: генерируйте фрагменты кода, объясняйте алгоритмы, проводите ревью кода

  </Accordion>

  <Accordion title="Что делать, если Agent запрашивает мой ключ API, а я хочу использовать свой?">
    Agent будет вести разработку до первого checkpoint, а затем запросит ваш ключ API. Так Agent сначала настраивает структуру проекта и только потом делает паузу, чтобы получить ваши учётные данные и продолжить работу.
  </Accordion>

  <Accordion title="Какие типы моделей и результатов поддерживаются?">
    ИИ-интеграции Replit поддерживают вывод текста, изображений и аудио. Возможности работы с аудио включают транскрибацию (речь в текст) через `gpt-4o-transcribe` и `gpt-4o-mini-transcribe`, а также генерацию аудио через `gpt-audio` и `gpt-audio-mini`. Вывод видео не поддерживается. Если вашему приложению нужна генерация видео, Agent предложит использовать собственный ключ API от провайдера, который её поддерживает.
  </Accordion>
