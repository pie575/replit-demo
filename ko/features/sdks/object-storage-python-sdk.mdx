이 참조 가이드에서는 `replit-object-storage-python` 패키지의 `Client` 클래스를 설명하고, 클래스 메서드별 코드 예제를 제공합니다.

<div id="client">
  ## Client
</div>

`Client` 클래스는 Replit App Storage와의 상호작용을 관리합니다. 이 클래스는 bucket 내 객체에 대한 작업을 수행할 수 있는 메서드를 제공합니다.

`replit.object_storage` package에서 이 클래스를 import하려면 Python 코드에 다음 줄을 추가하세요.

```python theme={null}
from replit.object_storage import Client
```

다음 코드를 사용해 Replit App Storage와 상호작용하는 `Client` 인스턴스를 생성하세요:

```python theme={null}
client = Client()
```

<Tip>
  App에서 여러 bucket을 사용하는 경우, bucket마다 `Client` 인스턴스를 하나씩 생성하세요.
</Tip>

<div id="__init__">
  ### **init**
</div>

`init` 메서드는 Client 클래스의 인스턴스를 초기화합니다.

```python theme={null}
def __init__(bucket_id: Optional[str] = None)
```

**인자**:

* `bucket_id` (Optional[str]): 클라이언트가 관리하는 bucket의 ID입니다. 생략하면 Client는 Replit App 또는 배포에 연결된 기본 bucket을 사용합니다.

<div id="copy">
  ### copy
</div>

`copy` 메서드는 동일한 bucket 내에서 객체를 복사합니다. 같은 위치에 이미 객체가 있으면 기존 객체를 덮어씁니다.

```python theme={null}
def copy(object_name: str, dest_object_name: str) -> None
```

**인자**:

* `object_name` (str) - 소스 객체의 전체 경로입니다.
* `dest_object_name` (str) - 대상 객체의 전체 경로입니다.

**발생 오류**:

* `ObjectNotFoundError` - 지정된 경로에 소스 객체가 존재하지 않음을 나타냅니다.

<div id="delete">
  ### delete
</div>

`delete` 메서드는 App Storage에서 파일을 영구적으로 삭제합니다.

```python theme={null}
def delete(object_name: str, ignore_not_found: bool = False) -> None
```

**인자**:

* `object_name` (str) - 삭제할 객체의 이름입니다.
* `ignore_not_found` (bool) - `True`이면 객체가 존재하지 않아도 오류를 발생시키지 않습니다.

**발생 오류**:

* `ObjectNotFoundError` - 객체가 존재하지 않음을 나타냅니다.

<div id="download_as_bytes">
  ### download_as_bytes
</div>

`download_as_bytes` 메서드는 파일의 내용을 `bytes` 형식으로 가져옵니다.

```python theme={null}
def download_as_bytes(object_name: str) -> bytes
```

**인자**:

* `object_name` (str) - 다운로드할 객체의 이름입니다.

**반환값**:

* `bytes`- 객체 내용의 원시 바이트 표현입니다.

**발생 오류**:

* `ObjectNotFoundError` - 객체가 존재하지 않음을 나타냅니다.

<div id="download_as_text">
  ### download_as_text
</div>

`download_as_text` 메서드는 파일의 내용을 `str` 타입으로 다운로드합니다.

```python theme={null}
def download_as_text(object_name: str) -> str
```

**인자**:

* `object_name` (str) - 가져올 소스 객체 이름입니다.

**반환값**:

* str: UTF-8로 인코딩된 문자열 형태의 객체 콘텐츠입니다.

**발생 오류**:

* `ObjectNotFoundError` - 객체가 존재하지 않음을 나타냅니다.

<div id="download_to_filename">
  ### download_to_filename
</div>

객체의 내용을 로컬 디스크의 파일로 다운로드합니다.

```python theme={null}
def download_to_filename(object_name: str, dest_filename: str) -> None
```

**인자**:

* `object_name` (str) - App Storage에서 가져올 소스 객체의 이름입니다.
* `dest_filename` (str) - 로컬 디스크에 저장할 대상 파일 이름입니다.

**발생 오류**:

* `ObjectNotFoundError` - 객체가 존재하지 않음을 나타냅니다.

<div id="exists">
  ### exists
</div>

`exists` 메서드는 객체가 존재하는지 확인합니다.

```python theme={null}
def exists(object_name: str) -> bool
```

**인자**:

* `object_name` (str) - 존재 여부를 확인할 객체의 이름입니다.

**반환값**:

* `bool`: 객체가 존재하면 `True`, 그렇지 않으면 False입니다.

<div id="list">
  ### list
</div>

`list` 메서드는 bucket에 있는 객체 목록을 반환합니다.

```python theme={null}
def list(end_offset: Optional[str] = None,
         match_glob: Optional[str] = None,
         max_results: Optional[int] = None,
         prefix: Optional[str] = None,
         start_offset: Optional[str] = None) -> List[Object]
```

**인자**:

* `end_offset`(Optional[str]) - 사전순으로 `end_offset`보다 앞에 오는 이름을 가진 객체만 결과에 포함합니다. `start_offset`이 정의되어 있으면, 나열되는 객체는
  `start_offset`(포함)과 `end_offset`(제외) 사이의 이름을 갖습니다.
* `match_glob` (Optional[str]) - glob 패턴으로 결과를 필터링합니다. 예를 들어 &quot;foo*bar&quot;는 &quot;footbar&quot;, &quot;foo baz bar&quot;, &quot;foobar&quot;와 일치합니다.
* `max_results` (Optional[int]) - 응답으로 반환할 최대 결과 개수입니다.
* `prefix` (Optional[str]) - 지정한 접두사로 시작하는 이름을 가진 객체만 결과에 포함합니다.
* `start_offset` (Optional[str]) - 사전순으로 `start_offset`과 같거나 그 뒤에 오는 이름을 가진 객체만 결과에 포함합니다.
  `end_offset`이 설정되어 있으면, 나열되는 객체는 `start_offset`(포함)과 `end_offset`(제외) 사이의 이름을 갖습니다.

**반환값**:

* `List`(Object): 지정한 query parameter와 일치하는 객체 목록입니다.

<div id="upload_from_filename">
  ### upload_from_filename
</div>

`upload_from_filename()`을 사용하여 로컬 디스크의 소스 파일에 있는 객체를 App Storage로 업로드합니다.

```python theme={null}

```

**인자**:

* `dest_object_name`(str) - 업로드된 파일의 이름입니다.
* `src_filename`(str) - 업로드할 원본 파일입니다.

`upload_from_bytes` 메서드는 `bytes` 데이터에서 객체를 업로드합니다.

```python theme={null}
def upload_from_bytes(dest_object_name: str, src_data: bytes) -> None
```

**인자**:

* `dest_object_name`(str) - 업로드할 객체의 이름입니다.
* `src_data`(str) - 업로드할 `bytes` 데이터입니다.

<div id="upload_from_text">
  ### upload_from_text
</div>

`upload_from_text` 메서드는 문자열로부터 객체를 업로드합니다.

```python theme={null}
def upload_from_text(dest_object_name: str, src_data: Union[bytes, str]) -> None
```

**인자**:

* `dest_object_name`(str) - 업로드할 객체의 이름입니다.
* `src_data`(str)- 업로드할 텍스트 데이터입니다.

<div id="exception-types">
  ### 예외 유형
</div>

* `Client`로 Replit App Storage를 사용할 때, 모든 메서드는 다음 오류 중 하나를 반환할 수 있습니다:

  * `BucketNotFoundError`: 설정한 bucket 이름과 일치하는 bucket이 App Storage에 없음을 나타냅니다.

  * `DefaultBucketError`: 기본 bucket 설정이 누락되었음을 나타냅니다.

  * `ForbiddenError`: bucket에 접근할 permissions이 부족함을 나타냅니다.

  * `TooManyRequestsError`: 요청이 과도하여 작업이 속도 제한되었음을 나타냅니다.

  * `UnauthorizedError`: 인증 권한이 없어 해당 작업에 대한 접근이 제한되었음을 나타냅니다.
