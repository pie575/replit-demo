# Visualisation de données

> Créez des tableaux de bord interactifs, des outils de reporting et des interfaces d'exploration de données grâce à une conversation avec Agent.

## Qu'est-ce qu'une visualisation de données ?

Une visualisation de données est un tableau de bord interactif ou un outil de reporting que vous créez grâce à une conversation avec Agent. Décrivez ce que vous souhaitez visualiser et l'emplacement de vos données — Agent sélectionne automatiquement les KPI appropriés, les types de graphiques et les mises en page, puis génère un tableau de bord complet en une seule invite.

Concepts clés :

* **Génération en une seule invite** : Décrivez votre objectif et votre source de données, et Agent crée un tableau de bord complet avec des graphiques et des métriques adaptés
* **Sources de données connectées** : Récupérez des données depuis des bases de données, des [connecteurs d'entrepôts](/fr/connectors/warehouses/overview), des API externes ou des fichiers importés
* **Fonctionnalités intégrées** : Chaque tableau de bord inclut l'actualisation, l'auto-actualisation, l'export en PDF, l'export des graphiques en CSV et le mode clair/sombre
* **Résumé d'analyse** : Agent génère des insights basés sur votre requête et les données résultantes
* **Artefacts multiples** : Les visualisations de données peuvent partager le même backend et la même base de données que vos autres artefacts dans le [même projet](/fr/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project)

## Comment utiliser la Visualisation de données

### Créer à partir d'une invite

Sélectionnez l'onglet **App** sur la page d'accueil et décrivez le tableau de bord que vous souhaitez. Agent détecte les invites liées aux données et sélectionne automatiquement la pile Visualisation de données.

**Exemples d'invites :**

* « Crée un tableau de bord d'analyse des ventes qui suit le chiffre d'affaires par région »
* « Crée un outil de reporting qui visualise nos métriques mensuelles »
* « Crée un tableau de bord à partir de nos données de ventes BigQuery montrant les produits les plus performants »
* « Connecte-toi à Snowflake et crée un tableau de bord d'analyse du taux de désabonnement des clients »

### Créer depuis le menu déroulant

1. Accédez à l'onglet **App** sur la page d'accueil.
2. Ouvrez le menu déroulant du type d'application.
3. Sélectionnez **Visualisation de données**.
4. Décrivez le tableau de bord ou l'outil de données que vous souhaitez créer.

### Se connecter aux entrepôts de données

Connectez votre visualisation de données à BigQuery, Databricks ou Snowflake via des [connecteurs d'entrepôts](/fr/connectors/warehouses/overview) pour créer des tableaux de bord sur la base de vos jeux de données existants.

Lorsque vous interrogez des données d'entrepôt, Agent utilise une recherche multi-agent parallèle pour explorer votre schéma et vos jeux de données. Cela accélère l'exploration et aide Agent à sélectionner les bonnes tables et les bons champs pour votre tableau de bord.

Pour commencer, configurez un connecteur d'entrepôt dans les [Intégrations](/fr/features/integrations/overview) de votre projet, puis indiquez à Agent ce que vous souhaitez visualiser.

### Ajouter des filtres et des fonctionnalités

Après qu'Agent a créé votre tableau de bord, vous pouvez lui demander d'ajouter des filtres, des vues détaillées ou d'autres fonctionnalités interactives. Par exemple, demandez à Agent d'ajouter un filtre de plage de dates, un sélecteur de région ou une barre de recherche.

### Exporter et partager

* **Export en PDF** : Exportez l'intégralité de votre tableau de bord en PDF pour le partager ou le consulter hors ligne.
* **Export des graphiques en CSV** : Téléchargez les données de graphiques individuels sous forme de fichiers CSV pour une analyse approfondie dans des tableurs ou d'autres outils.
* **Document d'analyse** : Demandez à Agent de produire un document d'analyse détaillé basé sur les données de votre tableau de bord.

## Ce que vous pouvez créer

* **Tableaux de bord analytiques** : Suivez des métriques clés comme le chiffre d'affaires, les inscriptions ou l'engagement sur des périodes données
* **Outils de reporting** : Créez des rapports internes que les parties prenantes peuvent filtrer et explorer sans accès direct à la base de données
* **Interfaces d'exploration de données** : Parcourez et interrogez des jeux de données avec un retour visuel
* **Panneaux de surveillance** : Affichez des données en temps réel ou quasi-réel provenant d'API, de bases de données ou de services externes

## Questions fréquentes

<Accordion title="Quelles sources de données puis-je connecter ?">
  Vous pouvez récupérer des données depuis la base de données Replit de votre projet, des connecteurs d'entrepôts (BigQuery, Databricks, Snowflake), des API externes ou des fichiers importés tels que des CSV. Configurez les connexions aux entrepôts via les [Intégrations](/fr/features/integrations/overview).
</Accordion>

<Accordion title="Puis-je personnaliser l'apparence ?">
  Oui. Vous pouvez personnaliser les couleurs, les mises en page et la typographie via une conversation — demandez à Agent de correspondre à votre charte graphique ou d'ajuster le design. Les tableaux de bord prennent également en charge les modes clair et sombre.
</Accordion>

<Accordion title="Agent analyse-t-il les données pour moi ?">
  Après avoir créé un tableau de bord, Agent génère un résumé d'analyse basé sur votre requête et les données résultantes. Vous pouvez également demander un document d'analyse plus détaillé.
</Accordion>

<Accordion title="Puis-je combiner une visualisation de données avec d'autres types d'artefacts ?">
  Oui. Vous pouvez combiner une visualisation de données avec une [application web](/fr/features/artifact-types/web-apps), une [présentation](/fr/features/artifact-types/slide-decks) ou d'autres types d'artefacts dans le [même projet](/fr/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project). Ils partagent le même backend et la même base de données.
</Accordion>
