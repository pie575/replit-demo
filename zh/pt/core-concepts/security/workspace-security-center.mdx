Workspace Security Center 适用于所有方案。你可以用它扫描整个 workspace 中各项目的[依赖项](/zh/pt/core-concepts/security/concepts#dependency)，并按[严重程度](/zh/pt/core-concepts/security/concepts#severity)查看 [CVE](/zh/pt/core-concepts/security/concepts#cve) 结果。你还可以使用 Replit Agent 修复问题、[重新发布](/zh/pt/core-concepts/security/concepts#republish)受影响的项目，并导出软件物料清单 ([SBOM](/zh/pt/core-concepts/security/concepts#sbom)) 报告以满足合规要求。

<Note>
  若要扫描单个项目，请在该项目内的 **Security** 面板中打开 [Project Security Center](/zh/pt/core-concepts/security/project-security-center)。
</Note>

<Note>
  初次接触依赖项安全？请参阅[安全概念](/zh/pt/core-concepts/security/concepts)，了解 CVE、SBOM、暴露面、Fix with Agent、Republish 和 Auto-Protect 的定义。
</Note>

  ## 资源

<div id="deteco-de-cve">
  ### CVE 检测
</div>

查看 workspace 中所有项目的漏洞：

* 识别存在漏洞的项目，并按[暴露程度](/zh/pt/core-concepts/security/concepts#exposure) (发布状态与可见性) 确定优先级
* 查看受影响的软件包名称、版本和严重程度 (critical、high、medium 和 low)
* 获取针对每个项目的修复建议

<div id="visualizao-de-projetos-afetados">
  ### 查看受影响的项目
</div>

识别哪些项目存在漏洞，并确定优先修复的对象：

* 按暴露程度分组查看存在漏洞的项目概览：项目总数、已发布的项目以及公开发布的项目
* 查看受影响的 Replit 项目明细
* 按 CVE ID 或项目名称搜索，并按严重程度、所有者、发布状态 (Published / Not published) 和可见性 (Public / Private) 筛选
* 展开任意项目行，无需离开页面即可查看全部 CVE 结果 (严重程度、软件包、版本、CVE ID)

<div id="fix-with-agent-e-republicao">
  ### Fix with Agent 与重新发布
</div>

无需离开 Security Center 即可修复漏洞并重新部署：

* 在任意受影响的项目中选择 **[Fix with Agent](/zh/pt/core-concepts/security/concepts#fix-with-agent)**，即可在该项目中以后台任务的形式创建补丁。重新发布前，请先审查并应用生成的更改。
* 通过 **Task in progress**、**Apply changes**、**Republish** 等阶段以及 **Republished** 或 **Failed** 最终状态，跟踪修复进展。
* 一键 **Republish**，系统会弹出确认对话框，在应用修复后使用现有配置重新部署该构建。
* 执行批量操作，例如取消发布，或就项目中的漏洞通知项目所有者。

<div id="exportao-de-sbom">
  ### SBOM 导出
</div>

导出软件物料清单 (SBOM) ，用于合规与审计：

* 以标准格式下载 SBOM ([SPDX](/zh/pt/core-concepts/security/concepts#spdx-and-cyclonedx)、[CycloneDX](/zh/pt/core-concepts/security/concepts#spdx-and-cyclonedx))
* 为单个项目或整个 workspace 生成报告
* 按扫描任务分组浏览 SBOM，查看时间戳、项目数量以及发起该次扫描的用户
* 将一次扫描任务的所有 SBOM 打包为单个 zip 文件下载
* 满足软件供应链透明度方面的合规要求

<Note>
  批量下载 SBOM 仅在 Enterprise 方案中提供。其他方案的 workspace 会在 SBOM 部分看到升级到 Enterprise 的提示。
</Note>

<div id="acessar-o-workspace-security-center">
  ## 访问 Workspace Security Center
</div>

要打开 Workspace Security Center：

1. 访问 [replit.com](https://replit.com) 并登录你的账户。
2. 在主页左侧导航栏中选择 **Security**。

<div id="escanear-o-workspace">
  ## 扫描 workspace
</div>

<Frame>
  <img src="/assets/mirror/security-overview-b37f090f236c.png" alt="Workspace Security Center 的初始视图，显示扫描总数、漏洞总数以及按严重程度分组的 CVE" width="3438" height="1984" data-path="images/workspace-security-center/security-overview.png" />
</Frame>

1. 打开 Workspace Security Center。
2. 选择 **Run security scan**，对整个 workspace 发起扫描。
3. 查看结果，结果会按受影响的 project、严重程度和 deployment 暴露程度分类。
4. 在任一受影响的 project 中选择 **Fix with Agent**，修复应用后再选择 **Republish**。

扫描会分析 workspace 中各 Replit project 的依赖项，并根据公共漏洞库标记已知漏洞。

<div id="auto-protect">
  ## Auto-Protect
</div>

管理员可以为账户启用 **[Auto-Protect](/zh/pt/core-concepts/security/concepts#auto-protect)**，持续监控新披露的 CVE 是否影响所有 project 的依赖项。一旦发现匹配项，Replit Agent 会准备好经过测试的补丁，并向开发者发送邮件，其中包含可直接应用该补丁的链接。

有关完整工作流程和配置步骤 (包括 **Settings** &gt; **Account** &gt; **Advanced** 中仅限管理员设置的严重性阈值) ，请参阅 [Auto-Protect](/zh/pt/core-concepts/security/project-security-center#auto-protect)。

<Note>
  如需协助配置 Workspace Security Center，或将 SBOM 导出集成到合规工作流程中，请联系您的专属客户经理。
</Note>
