<div id="replit-auth">
  ### Replit Auth
</div>

[Replit Auth](/fr/ja/features/auth-and-identity/authentication) est désormais disponible pour tous les utilisateurs ! Ce système d’authentification intégré vous permet d’ajouter une connexion utilisateur à votre application avec une configuration minimale. Au lieu de créer de zéro un système d’authentification complexe, Replit Auth propose une solution sécurisée, prête à l’emploi et intégrée à l’infrastructure.

**Fonctionnalités principales :**

* **Aucune configuration** - Ajoutez l’authentification avec un seul prompt à Agent
* **Sécurité intégrée** - Utilisez l’infrastructure de Replit, protégée contre les attaques courantes
* **Gestion des utilisateurs** - Gérez facilement les utilisateurs depuis le panneau Auth
* **Intégration à la base de données** - Création automatique d’entrées utilisateur dans la base de données
* **Page de connexion personnalisable** - Personnalisez l’expérience de connexion de votre application
* **Réinitialisation de mot de passe** - Replit gère les e-mails de réinitialisation de mot de passe, sans nécessiter votre propre fournisseur de messagerie

Pour commencer, il vous suffit de demander Replit Auth dans votre prompt à Agent :

<AiPrompt>
  Aidez-moi à créer une application qui [votre idée d’application] et qui doit inclure Replit Auth.
</AiPrompt>

<div id="ubb">
  ### Mise à jour de la politique de suspension UBB
</div>

Afin de mieux accompagner les utilisateurs fidèles et de protéger leurs déploiements, nous avons amélioré le système de délai de grâce pour les paiements. Les utilisateurs de longue date disposent désormais de plus de temps pour résoudre leurs problèmes de paiement, ce qui permet à leurs applications critiques de rester en ligne le temps que leurs informations de paiement soient mises à jour.
