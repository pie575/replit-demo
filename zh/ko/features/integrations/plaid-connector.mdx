<Info>
  Plaid 连接器适用于付费 Replit 套餐，且需要[团队工作区](/zh/ko/features/collaboration/team-workspaces#create-a-team-workspace)。
</Info>

<WistiaEmbed videoId="fcqtulftwk" title="了解如何使用 Replit 和 Plaid 构建应用" />

Plaid 可将应用连接到金融机构。借助 Plaid 连接器，构建者可以创建利用所连接机构支持的账户余额、交易和投资数据的应用。

设置分为两部分。Workspace 管理员只需在 Replit 中配置一次 Plaid 凭据，之后，每位应用用户都可通过 Plaid Link 连接自己的金融账户。Plaid 访问令牌按用户限定范围并安全存储，因此应用无需直接处理 Plaid 密钥即可使用金融数据。

<div id="section">
  ## 可构建的应用
</div>

您可以使用 Plaid 连接器构建以下应用：

* 个人财务控制面板
* 预算管理和支出分类工具
* 交易搜索和分析应用
* 面向受支持投资账户的投资组合跟踪器
* 总结支出模式的财务教练

<div id="section-2">
  ## 准备工作
</div>

在 Replit 中配置 Plaid 之前，您需要准备：

* [团队工作区](/zh/ko/features/collaboration/team-workspaces#create-a-team-workspace) — Plaid 在团队级别配置
* [Plaid 账户](https://dashboard.plaid.com/signup)
* 从 [Plaid 控制面板](https://dashboard.plaid.com/developers/keys)获取的 Plaid **Client ID**
* 要使用的环境对应的 Plaid **Secret**
* 决定使用 Plaid `sandbox` 还是 `production`

使用 Plaid 提供的示例机构和凭据进行测试时，请使用 `sandbox`。当您的应用准备好连接真实金融账户时，请使用 `production`。

<div id="replit-plaid">
  ## 在 Replit 中配置 Plaid 连接器
</div>

工作区管理员将 Plaid 凭据添加到 Replit。配置连接器后，构建者即可借助 Agent 使用 Plaid 数据。

<Steps>
  <Step title="打开集成">
    在 Replit 中打开工作区或 App 设置，然后选择 **集成**。

    <Frame>
      <img src="/assets/mirror/integrations-panel-9c9a11a93f25.png" alt="Avenger 团队 Workspace 的 集成 面板，显示由 Replit 管理的集成和 Connectors 区域，右上角突出显示 Add new connector 按钮" width="1440" height="900" data-path="images/replitai/plaid-connector/integrations-panel.png" />
    </Frame>
  </Step>

  <Step title="添加 Plaid 连接器">
    选择 **Add new connector**，然后选择 **Plaid**。

    <Frame>
      <img src="/assets/mirror/plaid-connector-search-1283aace7d36.png" width="1440" height="900" data-path="images/replitai/plaid-connector/plaid-connector-search.png" />
    </Frame>
  </Step>

  <Step title="选择环境">
    选择 `sandbox` 或 `production`。所选环境必须与要使用的 Plaid Secret 相匹配。
  </Step>

  <Step title="输入 Plaid 凭据">
    粘贴 Plaid 控制面板中的 Plaid **Client ID** 和 **Secret**。
  </Step>

  <Step title="设置客户端名称">
    输入要在 Plaid Link 中显示的 App 名称。该字段默认填入 `My Plaid App`，请将其更改为要向用户显示的名称。请确保名称不超过 30 个字符，以便 Plaid 正确显示。
  </Step>

  <Step title="保存连接器">
    选择 **Configure** 保存连接器。Replit 会安全存储凭据，并在构建者连接 Plaid 账户时使用这些凭据。

    <Frame>
      <img src="/assets/mirror/plaid-config-dialog-6f2537e3be30.png" alt="Plaid 配置对话框，包含 Environment、Client ID、Client Secret 和 Client Name 字段，以及用于保存的 Configure 按钮" width="1440" height="900" data-path="images/replitai/plaid-connector/plaid-config-dialog.png" />
    </Frame>
  </Step>
</Steps>

如需稍后更改配置，请在 集成 面板中打开 **Manage connectors**，然后选择 Plaid 旁边的 **Manage**。

<Frame>
  <img src="/assets/mirror/plaid-connector-manage-89e796daff17.png" alt="Plaid 连接器管理面板，包含已保存的 Environment、Client ID、Client Secret 和 Client Name，以及用于保存更改的 Update 按钮" width="1440" height="900" data-path="images/replitai/plaid-connector/plaid-connector-manage.png" />
</Frame>

有关组织范围的连接器管理，请参阅[管理连接器](/zh/ko/replitai/managing-connectors)。

<div id="plaid-link">
  ## 使用 Plaid Link 登录
</div>

Plaid 使用 [Plaid Link](https://plaid.com/docs/link/)，而不是常规的 OAuth 重定向。要启动流程，请在 Connectors 表格中找到 Plaid，然后选择**登录**。Replit 会先显示一个简短的同意页面来确认连接，然后打开 Plaid Link。

<Frame>
  <img src="/assets/mirror/connect-plaid-consent-ea05ebe1a916.png" alt="连接 Plaid 的同意对话框，包含 Replit 和 Plaid 徽标、三条关于连接 Plaid、数据使用和可撤销权限的说明，以及“继续前往 Plaid”按钮" width="1440" height="900" data-path="images/replitai/plaid-connector/connect-plaid-consent.png" />
</Frame>

接下来，Plaid Link 会打开一个嵌入式流程，引导每位用户选择自己的金融机构并在该机构完成身份验证。

<Frame>
  <img src="/assets/mirror/plaid-link-picker-2e241c8e1271.png" alt="Plaid Link 金融机构选择器，标题为“选择您的金融机构”，包含搜索框以及 Chase、Bank of America、Wells Fargo、Citibank、US Bank、Capital One、PNC、USAA、American Express、TD、Regions 和 Navy Federal 等美国主要银行的徽标，底部显示沙盒模式横幅" width="1440" height="900" data-path="images/replitai/plaid-connector/plaid-link-picker.png" />
</Frame>

每位用户都可以连接自己的账户。Replit 会存储该用户连接后获得的 Plaid 访问令牌，并在 Agent 或应用请求 Plaid 数据时使用该令牌。

<div id="plaid">
  ## 开始使用 Plaid 数据构建
</div>

连接 Plaid 后，让 Agent 使用已连接的金融数据进行构建。例如：

<AiPrompt>
  创建一个个人财务控制面板，让用户通过 Plaid Link 连接银行账户。显示账户余额、按类别划分的月度支出，以及最近金额最大的 5 笔交易。
</AiPrompt>

<AiPrompt>
  创建一个预算管理应用，让每位用户通过 Plaid Link 连接账户。导入交易记录，按商家和类别分组，并显示用户本月是否超出预算。
</AiPrompt>

<AiPrompt>
  创建一个投资组合跟踪器，让用户通过 Plaid Link 连接支持的投资账户。在有相关数据时，显示持仓、账户余额及其随时间的变化。
</AiPrompt>

Plaid 数据的可用性取决于所连接的机构，以及你的 Plaid 账户中已启用的 Plaid 产品。

<div id="section-3">
  ## 故障排查
</div>

<AccordionGroup>
  <Accordion title="集成中未显示 Plaid">
    Plaid 需要付费 Replit 套餐。如果您使用的是付费套餐但仍看不到 Plaid，请刷新页面并确认您所在的工作区是否正确。

    如果设置中显示 **此功能需要企业版**，请刷新页面并确认您使用的是正确的工作区。

    如果 Plaid 仍未显示，请联系 Replit 支持团队，以便他们检查您的工作区配置。
  </Accordion>

  <Accordion title="Plaid Link 显示 This Application 而非我的应用名称">
    如果未配置客户端名称，或名称过长，Plaid 可能会显示 **This Application**。请编辑 Plaid 连接器配置，并使用不超过 30 个字符的应用名称。
  </Accordion>

  <Accordion title="显示连接已断开">
    如果金融机构要求账户所有者重新登录、凭据发生变更或授权被撤销，Plaid 连接可能会断开。

    在集成或 Connectors 面板中重新连接 Plaid，即可打开 Plaid Link 并恢复访问权限。
  </Accordion>

  <Accordion title="沙盒和生产环境的数据不一致">
    Plaid 沙盒和生产环境使用不同的凭据和令牌。请确认连接器环境与您输入的 Plaid Secret 及正在测试的金融账户类型相匹配。
  </Accordion>
</AccordionGroup>
