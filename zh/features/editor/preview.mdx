Preview 用于展示 web app 的运行效果，并提供浏览器开发者工具和调试功能。

当你点击 **Run** 按钮启动 web app 时，Replit 会为它分配一个可通过互联网访问的临时 URL。
Preview 工具会像浏览器一样渲染页面，同时内置开发者工具，功能与常见浏览器中的相仿。

<Note>
  Preview 是 Webview 的新名称。
</Note>

<div id="features">
  ## 功能
</div>

Preview 提供以下功能，让你轻松测试和调试 web app：

* **实时网页视图**：无需离开浏览器标签页即可查看应用并与之交互
* **开发者工具**：使用内置工具快速定位问题
* **响应式测试**：在不同移动设备的屏幕尺寸下查看应用

<div id="usage">
  ## 使用方法
</div>

运行 web app 时，Preview 工具会自动打开。
你可以在 **User Settings** 工具的 **Automatic Preview** 设置中切换此行为。

以下说明介绍如何打开 Preview。

<Accordion title="如何访问 Preview">
  从左侧的 **Tool dock**：

  1. 选择 <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="All tools icon" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**，查看 Project Editor 工具列表。
  2. 选择 <img class="icon-svg" src="/assets/mirror/preview-icon-6d37238e8cc2.svg" alt="Preview icon" width="16" height="16" data-path="images/icons/preview-icon.svg" /> **Preview**。

  从**搜索栏**：

  1. 选择顶部的 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="magnifying glass icon" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 放大镜图标，打开搜索工具
  2. 输入“Preview”找到该工具，然后从结果中选择它。
</Accordion>

<div id="location-bar">
  ## 地址栏
</div>

**Preview** 标签页顶部的地址栏包含以下工具：

* **后退按钮**：返回浏览历史中的上一个页面
* **前进按钮**：前往浏览历史中的下一个页面
* **应用域名**：点击 `{...}.replit.dev` 可查看 Replit App 临时 URL 的相关信息
* **地址输入框**：查看当前 URL 路径，或输入新路径

<div id="browser-tools">
  ## 浏览器工具
</div>

地址栏右侧的浏览器工具包含以下功能：

* **屏幕尺寸**：从不同的设备屏幕尺寸预设中选择，用于测试响应式设计
* **Devtools**：显示或隐藏[开发者工具](#Developer_tools)面板
* **新标签页**：在新的浏览器标签页中打开你的 web app 网址

<Note>
  **正在构建移动应用？** Preview 面板还支持在 **iOS Simulator** 或 **Android Emulator** 中预览。详情请参阅[原生移动应用](/zh/features/artifact-types/building-mobile-apps#preview-on-a-simulator-or-emulator)。
</Note>

<div id="developer-tools">
  ## 开发者工具
</div>

开发者工具基于 <a href="https://github.com/liriliri/eruda" target="_blank">Eruda</a> 开源项目构建，可帮助你完成以下任务：

* 在应用环境中查看并使用 JavaScript 控制台
* 检查 DOM 元素
* 监控网络请求
* 配置显示与行为偏好

要使用开发者工具，请点击 **Preview** 标签页顶部的 <img class="icon-svg" src="/assets/mirror/wrench-7cee9d1168da.svg" alt="wrench icon" width="16" height="16" data-path="images/icons/wrench.svg" /> **Devtools**
按钮来显示或隐藏。

以下各节介绍你可以在各个开发者工具标签页中执行的操作。

<div id="console">
  ### 控制台
</div>

**Console** (控制台) 标签页显示应用生成的 JavaScript 日志。
在该标签页中，你可以执行以下操作：

* **清除输出**：点击 <img class="icon-svg" src="/assets/mirror/clear-bd1bf1847597.svg" height="16" width="16" alt="clear icon" data-path="images/icons/clear.svg" /> 带斜线的圆形图标，清除所有控制台输出。
* **筛选输出**：按类型 (All、Info、Warning 或 Error) 查看筛选后的控制台输出。
* **按文本筛选**：点击 <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="filter icon" data-path="images/icons/filter.svg" /> 筛选图标并输入文本，仅显示匹配的输出。
* **复制输出**：点击 <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="copy icon" data-path="images/icons/copy.svg" /> 复制按钮，复制选中的控制台消息。
* **运行 JavaScript 代码**：点击 <img class="icon-svg" src="/assets/mirror/arrow-right-2859a6e6bdeb.svg" height="16" width="16" alt="right arrow icon" data-path="images/icons/arrow-right.svg" /> 右尖括号，即可在应用的上下文中运行 JavaScript 代码。输入表达式后点击 **Execute**。

<div id="elements">
  ### Elements
</div>

**Elements** 标签页可用于检查和修改网页的 DOM 结构。

* **查看元素详情**：查看 DOM 元素的详细信息及其在 HTML 代码中的位置
* **复制输出**：点击 <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="copy icon" data-path="images/icons/copy.svg" /> 复制按钮，即可复制所选的控制台消息。

点击 <img class="icon-svg" src="/assets/mirror/select-1165d9548c39.svg" height="16" width="16" alt="select icon" data-path="images/icons/select.svg" /> 箭头选择图标可切换选择模式。
进入选择模式后，在网页上选中某个元素。
该元素的 HTML 和 CSS 便会显示在 Elements 标签页中。

<div id="network">
  ### 网络
</div>

**网络**标签页用于监控网页发起的请求。
在此标签页中，你可以执行以下操作：

* **跟踪请求**：查看应用发起的所有网络请求。选择某个请求即可查看详细信息。
* **筛选**：选择 <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="filter icon" data-path="images/icons/filter.svg" /> 漏斗图标，仅显示与输入文本匹配的结果。将筛选条件留空即可清除筛选。
* **复制**：选择 <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="copy icon" data-path="images/icons/copy.svg" /> 复制按钮，复制存储信息。

<div id="resources">
  ### 资源
</div>

**Resources** (资源) 标签页显示页面加载的资源以及浏览器存储内容，例如 cookie 和本地存储。
你可以查看并刷新以下资源类型的列表：

* JavaScript 文件
* 样式表
* Iframe
* 图片

在此标签页中，你可以执行以下操作：

* **查看存储**：查看本地存储、会话存储和 cookie。
* **筛选**：点击 <img class="icon-svg" src="/assets/mirror/filter-9bf0eb4182a5.svg" height="16" width="16" alt="filter icon" data-path="images/icons/filter.svg" /> 漏斗图标，只显示与你输入的文本匹配的结果。将筛选条件清空即可取消筛选。
* **清除**：点击 <img class="icon-svg" src="/assets/mirror/clear-bd1bf1847597.svg" height="16" width="16" alt="clear icon" data-path="images/icons/clear.svg" /> 清除按钮，删除该存储类型的所有数据。
* **删除所选**：点击 <img class="icon-svg" src="/assets/mirror/delete-a21eb49cac3c.svg" height="16" width="16" alt="delete icon" data-path="images/icons/delete.svg" /> “X”图标，移除存储项。
* **复制**：点击 <img class="icon-svg" src="/assets/mirror/copy-eef67769eb74.svg" height="16" width="16" alt="copy icon" data-path="images/icons/copy.svg" /> 复制按钮，复制存储信息。

<div id="settings">
  ### Settings
</div>

**Settings** 标签页可用于自定义开发者工具的外观和行为。
该标签页包含以下自定义选项：

* **工具设置**：自定义适用于各个工具标签页的选项
* **JavaScript 控制**：设置 JavaScript 的行为选项，例如禁用 JavaScript 以测试应用的表现
* **显示偏好**：更改开发者工具的主题、面板尺寸、透明度及其他行为
