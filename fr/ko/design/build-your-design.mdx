Une frame n’est pas qu’une simple image : c’est la spécification d’un véritable logiciel. Lorsque vous êtes satisfait d’une frame, confiez-la à Agent : sélectionnez-la, choisissez **Build…** dans la barre d’actions, puis sélectionnez une option :

* Créer une nouvelle application à partir du design dans le même projet
* Appliquer l’apparence du design à une application existante
* Revenir en arrière en toute sécurité dans les deux cas, car Agent crée un checkpoint avant de commencer

<div id="section">
  ## Du frame à l’app : deux possibilités
</div>

Le menu **Build…** du frame Design sélectionné propose deux options :

<div id="section-2">
  ### Créer ce design
</div>

Sélectionnez **Build this design** pour créer un nouvel artefact à partir de cette frame. Agent génère la mise en page, les styles et les ressources, puis l’ajoute à la liste des artefacts du projet sous la forme d’une application fonctionnelle.

<div id="section-3">
  ### Appliquer à une application existante
</div>

Ce menu répertorie également tous les artefacts de votre projet. Sélectionnez-en un pour lui appliquer le design : Agent réécrit le code de l’artefact pour l’adapter à la frame, tandis que la frame Design reste telle quelle sur le canevas à titre de référence. Vous pouvez ainsi relooker une application existante sans avoir à la recréer de zéro.

<div id="section-4">
  ## Déroulement
</div>

<Steps>
  <Step title="Choisir le design à créer">
    Déterminez le frame à publier. Commencez par comparer les options côte à côte sur le canevas. Le Build clôt cette phase d’exploration, mais Agent crée un checkpoint afin que vous puissiez revenir en arrière à tout moment.
  </Step>

  <Step title="Confier la tâche à Agent">
    Sélectionnez un frame, puis choisissez **Build…** dans la barre d’actions et sélectionnez une option : créez un nouvel artefact ou appliquez-le à un artefact existant. Agent crée le design, la mise en page, les styles et les ressources, puis vous informe de l’avancement dans le chat.
  </Step>

  <Step title="Examiner le résultat du Build">
    Agent récapitule les modifications apportées et crée un checkpoint. Ouvrez le résultat pour vérifier que le design fonctionne réellement, puis continuez à l’ajuster dans le chat si certains éléments ne sont pas correctement appliqués.
  </Step>
</Steps>

<Note>
  Un abonnement Core ou Pro est requis pour créer une nouvelle application à partir d’un frame dans Design. Toutes les autres fonctionnalités de Replit Design, y compris l’application d’un design, sont disponibles avec tous les abonnements. Consultez [Billing](/fr/ko/billing/ai-billing) pour en savoir plus sur les abonnements.
</Note>

<div id="section-5">
  ## Après la création : passez aux choses sérieuses
</div>

Une fois la frame créée, vous obtenez une application fonctionnelle avec le design appliqué. La maquette ne faisait que simuler son fonctionnement, mais Agent peut désormais ajouter de véritables fonctionnalités. Demandez ce dont vous avez besoin dans le chat :

* **Ajouter une fonctionnalité de connexion** : ajoutez des comptes utilisateur avec [Replit Auth](/fr/ko/features/auth-and-identity/authentication). Les utilisateurs peuvent alors se connecter avec leur compte Replit sans configuration supplémentaire ou associer le fournisseur de leur choix.
* **Enregistrer des données réelles** : utilisez la [Database](/fr/ko/features/data-and-storage/sql-database) intégrée pour enregistrer et récupérer des commandes, des messages et des paramètres.
* **Mettre en place la facturation** : ajoutez des paiements et des abonnements grâce à l’intégration [Monetization](/fr/ko/features/monetization/overview).
* **Vous connecter à d’autres services** : selon le contenu du prompt, Agent active automatiquement les [intégrations](/fr/ko/features/integrations/overview) nécessaires, des e-mails à Slack et aux services Google.

<div id="section-6">
  ## Lancez votre application et développez-la
</div>

Une fois votre application opérationnelle, partagez-la avec le monde et continuez à l’améliorer :

* **Publier votre application** : publiez-la avec [l’outil Publishing](/fr/ko/features/publishing/overview), puis consultez [Après la publication](/fr/ko/features/publishing/after-you-publish) pour savoir comment mettre à jour votre application publiée.
* **Obtenir une véritable adresse** : achetez ou connectez un [domaine personnalisé](/fr/ko/features/publishing/custom-domains).
* **Faciliter sa découverte** : exécutez [SEO Agent](/fr/ko/features/publishing/seo-agent) pour obtenir un audit technique et appliquer des corrections en un clic.
* **Recueillir les retours de vos visiteurs** : ajoutez un [widget de feedback](/fr/ko/features/publishing/feedback-widget) pour permettre aux utilisateurs de signaler des problèmes ou de partager des idées, puis de les transmettre directement à Agent.
* **La maintenir en bon état** : suivez son état, ses performances et sa disponibilité avec le [Monitoring des applications publiées](/fr/ko/features/publishing/monitoring-a-deployment).
