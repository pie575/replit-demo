Контроль версий в Replit позволяет уверенно отслеживать изменения в кодовой базе, управлять ими и работать над ней совместно. Благодаря встроенной интеграции с Git и подключению к GitHub вы можете:

* Отслеживать изменения кода и сохранять историю разработки
* Работать с участниками команды, избегая конфликтов в коде и потери результатов работы
* Импортировать, изменять и отправлять код между Replit и GitHub
* Безопасно экспериментировать с новыми функциями с помощью веток

<div id="section">
  ## Что такое контроль версий?
</div>

Контроль версий — это система, которая записывает изменения в файлах со временем и позволяет позднее вернуться к определённой версии. В Replit контроль версий обеспечивает Git — отраслевой стандарт для отслеживания изменений в коде — вместе с удобным визуальным интерфейсом, для работы с которым не нужно знать командную строку.

<div id="replitn">
  ### Как работает управление версиями в Replit
</div>

Все четыре варианта управления версиями используют один и тот же Git-репозиторий:

1. **Чекпойнты Agent** автоматически создают коммиты на ключевых этапах при разработке с [Replit Agent](/ru/ja/features/agent/overview). [Подробнее о чекпойнтах и откатах](/ru/ja/features/version-control/checkpoints-and-rollbacks).
2. **Панель Git** предоставляет визуальный доступ ко всему Git-репозиторию
3. **Git CLI** предоставляет доступ ко всем функциям Git из командной строки
4. **История файлов** отслеживает подробные изменения в отдельных файлах

Выберите интерфейс, который лучше всего соответствует вашим потребностям, зная, что всё это основано на надёжной системе управления версиями Git.

| Функция                    | Чекпойнты Agent                         | Git-коммиты                             | История файлов                 |
| -------------------------- | --------------------------------------- | --------------------------------------- | ------------------------------ |
| **Создание**               | Автоматически на ключевых этапах        | Вручную или по расписанию               | Автоматически                  |
| **Гранулярность**          | Изменения на уровне функций             | Изменения любого размера                | Изменения на уровне символов   |
| **Описание**               | Сводка, созданная ИИ                    | Сообщение, написанное пользователем     | Автоматическая временная метка |
| **Откат**                  | Восстановление в один клик              | Требуются знания Git                    | Восстановление в один клик     |
| **Функции Git**            | Полный набор функций Git                | Полный набор функций Git                | Без функций Git                |
| **Синхронизация с GitHub** | Полная поддержка синхронизации с GitHub | Полная поддержка синхронизации с GitHub | Без синхронизации с GitHub     |

<div id="section-2">
  ## Начало работы
</div>

Добавив инструмент Git в Project Editor, вы получите доступ к управлению версиями в приложении Replit:

1. Перейдите в раздел Tools приложения Replit
2. Нажмите значок **+**, чтобы добавить новый инструмент
3. Выберите **Git** из списка доступных инструментов

Чтобы импортировать существующий проект из GitHub, см. [Импорт из GitHub](/ru/ja/build/import-from-providers).

<div id="section-4">
  ### Автоматическое управление версиями
</div>

<Accordion title="Чекпойнты Agent">
  Снимки, которые автоматически создаются в ходе ИИ-разработки через [Replit Agent](/ru/ja/features/agent/overview).

  **Оптимально для**: разработки с помощью Replit Agent

  **Основные возможности**:

  * Автоматическое создание на логических этапах
  * Откат в один клик
  * Снимки на уровне функций
  * Отслеживание прогресса
  * Не требует настройки
  * Наглядная временная шкала хода разработки

  Чекпойнты Agent сохраняются в Git, и обратиться к ним можно через панель Git или Git CLI. Кроме того, все чекпойнты можно просмотреть с помощью функции History:

  * Наглядное отображение чекпойнтов в хронологическом порядке
  * Подробные описания чекпойнтов
  * Прямой доступ к состоянию чекпойнта
  * Откат к любому чекпойнту в один клик
</Accordion>

<Accordion title="История файлов">
  Автоматическое отслеживание сохранённых версий для каждого файла при изменениях, внесённых прямо в редакторе, без участия Agent.

  **Оптимально для**: быстрого восстановления недавних изменений в файлах

  **Основные возможности**:

  * Фокус на отдельном файле
  * Изменения на уровне символов
  * Наглядное сравнение
  * История за 30 дней
  * Воспроизведение изменений

  У истории файлов есть собственный интерфейс, но лежащие в её основе изменения — часть истории Git. Подробнее об [истории файлов](/ru/ja/features/version-control/file-history).
</Accordion>

<div id="git">
  ### Интерфейсы на основе Git
</div>

<Accordion title="Панель Git">
  Визуальный интерфейс для работы с Git без знания командной строки.

  **Оптимально для**: большинства проектов, которым нужна интеграция с GitHub и наглядный рабочий процесс

  **Основные возможности**:

  * Отслеживание всего репозитория
  * Управление ветками
  * Визуальное сравнение изменений
  * Синхронизация с GitHub в один клик
  * Совместная работа в команде

  Подробнее об использовании панели Git см. в разделе [Использование панели Git](/ru/ja/features/workspace-tools/git-interface).
</Accordion>

<Accordion title="Git CLI">
  Полный доступ к Git через [Shell](/ru/ja/features/workspace-tools/shell) для выполнения сложных операций в командной строке.

  **Оптимально для**: опытных пользователей, которым нужны все возможности Git

  **Основные возможности**:

  * Полный набор команд Git
  * Расширенные стратегии ветвления
  * Настраиваемые рабочие процессы
  * Автоматизация с помощью скриптов
  * Полный контроль над репозиторием

  О распространённых командах Git и их использовании см. в разделе [Использование панели Git](/ru/ja/features/workspace-tools/git-interface#using-git-commands-in-shell).
</Accordion>

<div id="section-5">
  ## Основные возможности
</div>

* **Визуальный интерфейс Git** — управляйте репозиториями, коммитами и ветками без ввода команд Git
* **Интеграция с GitHub** — подключайте репозитории GitHub для резервного копирования и совместной работы
* **Импорт из GitHub** — [превращайте репозитории GitHub в приложения Replit](/ru/ja/build/import-from-providers) за несколько кликов
* **Управление ветками** — создавайте, переключайте и объединяйте ветки прямо в Project Editor
* **Разрешение конфликтов** — находите и устраняйте конфликты слияния с помощью визуальных подсказок

<div id="section-6">
  ## Сценарии использования
</div>

**Отслеживание личных проектов**

Отслеживайте изменения в коде по ходу разработки и при необходимости возвращайтесь к предыдущим версиям. [Панель Git](/ru/ja/features/workspace-tools/git-interface) наглядно отображает изменения, поэтому фиксировать значимые обновления в коммитах становится проще.

**Совместная работа с командой**

Несколько разработчиков могут работать над одной кодовой базой, не перезаписывая изменения друг друга. Создавайте ветки для новых функций и выполняйте слияние, когда всё будет готово. Подробнее о [приглашении участников команды](/ru/ja/build/invite-teammates).

<div id="agent">
  ## Чекпоинты Agent
</div>

При создании приложений с помощью [Replit Agent](/ru/ja/features/agent/overview) вы получаете дополнительный уровень контроля версий — чекпоинты. В ключевые моменты разработки с помощью ИИ чекпоинты автоматически фиксируют полное состояние проекта: его содержимое, контекст диалога с ИИ и подключённые базы данных.

<div id="section-7">
  ### Как работают чекпойнты
</div>

Чекпойнты Agent представляют собой полные снимки состояния приложения Replit:

* **Автоматическое создание**: Agent создаёт чекпойнты на ключевых этапах разработки
* **Полное сохранение состояния**: каждый чекпойнт сохраняет содержимое проекта, память ИИ и состояние базы данных
* **План реализации**: перед внесением изменений Agent предлагает план для проверки
* **Отслеживание сложных задач**: для крупных задач может создаваться несколько чекпойнтов

<div id="ai">
  ### Преимущества ИИ-разработки
</div>

Чекпоинты Agent дают уникальные преимущества при разработке с ИИ:

* **Подстраховка**: смело экспериментируйте, зная, что в любой момент можно легко восстановить предыдущее состояние всей среды разработки
* **Отслеживание прогресса**: пошагово просматривайте, как Agent создавал ваше приложение
* **Логичные этапы**: чекпоинты фиксируют завершённые функции, а не произвольные точки сохранения
* **Мгновенный откат**: одним щелчком возвращайтесь к любому предыдущему состоянию, включая восстановление базы данных и ИИ-контекста

<Info>
  Подробнее о том, что сохраняют чекпоинты, и о возможностях комплексного отката см. в разделе [Чекпоинты и откаты](/ru/ja/features/version-control/checkpoints-and-rollbacks).
</Info>

<Tip>
  Чекпоинты Agent особенно полезны при разработке с ИИ, но для долгосрочного контроля версий и совместной работы, особенно с внешними репозиториями, рекомендуем использовать коммиты Git.
</Tip>
