将您的应用打造为专业的线上网站。

通过域名购买功能，您可以在 Replit 内搜索、购买域名，并将其连接到已部署的应用。只需几分钟，即可让已部署的应用拥有专业的线上形象。

也就是说，您可以购买像 `my-app.com` 这样的域名，并自动将其连接到您的应用。

<div id="section">
  ## 功能
</div>

购买域名可简化为应用配置专业网址的流程。无需使用多个服务，您即可在 Replit 内完成整个网站的设置。

<Frame>
  <img src="/assets/mirror/replit-domains-8453291b634b.png" alt="显示已购买域名及连接状态的域名管理界面" width="3176" height="1556" data-path="images/deployments/custom-domains/replit-domains.png" />
</Frame>

主要功能：

* **域名搜索和可用性检查**：检查 `.com`、`.ai` 等热门扩展名的域名是否可用
* **一键购买**：使用账户的默认付款方式，直接在 Replit 购买域名
* **自动配置**：无需手动配置 DNS，域名会立即指向您的 Replit 应用
* **WHOIS 隐私保护**：个人信息不会出现在公开的域名记录中——所有域名购买均默认包含此服务
* **自定义 DNS 记录**：添加自定义 A、TXT 和 MX 记录，以配置电子邮件服务提供商及其他服务
* **立即发布**：购买后，您的应用可立即通过自定义域名访问
* **自动续订**：域名会自动续订，确保您的应用保持已发布状态

<div id="section-2">
  ## 使用方法
</div>

<div id="section-3">
  ### 购买域名
</div>

1. 发布应用，然后前往 <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="发布图标" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publishing** 选项卡
2. 选择 **Domains** 选项卡
3. 选择 **Buy a domain** 开始搜索
4. 在搜索框中输入所需的域名
5. 查看不同域名后缀的可选项
6. 选择所需域名并完成购买

购买域名后，系统会自动将其配置为指向你的 Replit 应用。无需额外设置，你即可立即通过自定义域名访问应用。

域名购买费用将通过你的 Replit 账户收取，从账户余额中扣除后计入使用量。

<div id="section-4">
  ### 管理已购买的域名
</div>

域名可与已部署的应用无缝集成。

* **自动续订**：域名会自动续订，确保应用保持已发布状态
* **统一账单**：域名费用会与其他服务一同显示在您的 Replit 账单中
* **迁移支持**：如有需要，可在 Replit 账户之间转移域名，或将其转移至外部注册商

<div id="dns">
  ### 自定义 DNS 记录
</div>

对于通过 Replit 购买的域名，你可以添加自定义 DNS 记录，以配置电子邮件服务提供商等附加服务。支持以下 DNS 记录类型：

* **A 记录**：将域名或子域名指向特定 IP 地址
* **TXT 记录**：为 SPF、DKIM、DMARC 等电子邮件验证服务添加基于文本的验证记录
* **MX 记录**：MX (邮件交换) 记录会告知电子邮件服务器应将发送至域名的邮件投递到何处。设置 MX 记录后，你便可以将自定义域名用于 `hello@yourdomain.com` 等电子邮件地址。

如需管理已购买域名的 DNS 记录：

1. 前往 Publishing <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="发布图标" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> 中的 **Domains** 标签页
2. 找到要配置的域名
3. 选择 **Edit** <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="铅笔图标" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> 图标
4. 选择 **Add DNS Record**
5. 输入服务提供商要求的记录类型、名称、值和 TTL

<div id="section-5">
  ### 支持的部署类型
</div>

以下部署类型支持购买域名：

* **[Autoscale 部署](/zh/ko/features/publishing/deployment-types#autoscale)**
* **[Reserved VM 部署](/zh/ko/features/publishing/deployment-types#reserved-vm)**

<div id="faq">
  ## 常见问题
</div>

<AccordionGroup>
  <Accordion title="费用是多少？">
    购买域名涉及两项费用。

    * **注册费**：注册并持有域名一年的初始费用 (`.ai` 域名为两年)
    * **续费价格**：初始注册期结束后自动收取

    Replit 不会对购买域名收取额外费用。域名注册费不予退款。
  </Accordion>

  <Accordion title="如何续费域名？">
    Replit 会自动续订您的域名，确保您的应用持续可访问。若要停止自动续订，请打开 Publishing 工具中的 **Domains** 选项卡，选择域名，然后关闭 **Auto renewal** 开关。您还可以在同一页面查看域名的续费日期和续费价格。
  </Accordion>

  <Accordion title="如果我想离开 Replit，该怎么办？">
    您可以联系 Replit 支持团队，将域名转移至其他注册商。根据 ICANN 规定，购买域名后须等待 60 天，才能将其转移至外部注册商。
  </Accordion>

  <Accordion title="可以在 Replit 账户之间转移域名吗？">
    可以。您可以联系 Replit 支持团队，在 Replit 账户之间转移域名。此流程无需等待 60 天。
  </Accordion>

  <Accordion title="可以为组织购买域名吗？">
    面向 Replit Pro 和 Enterprise 计划的域名购买功能将在首轮 Beta 测试结束后推出。
  </Accordion>

  <Accordion title="可以为域名添加自定义 DNS 记录吗？">
    可以！您可以为通过 Replit 购买的域名添加自定义 DNS 记录。目前支持以下记录类型：

    * **A 记录**：将域名或子域名指向特定 IP 地址
    * **TXT 记录**：添加用于电子邮件验证和其他服务的文本验证记录
    * **MX 记录**：配置用于处理域名电子邮件的邮件服务器

    前往 Publishing 的 Domains 选项卡配置这些记录。有关为电子邮件设置 MX 记录的详细说明，请参阅上方的[自定义 DNS 记录](#custom-dns-records)部分。
  </Accordion>

  <Accordion title="支持哪些域名扩展名？">
    我们支持所有常见的顶级域名 (TLD)。具有特殊地域或其他限制的 TLD 可能不受支持。
  </Accordion>

  <Accordion title="什么是 WHOIS 隐私保护？">
    注册域名时，您的联系信息 (姓名、地址、电话号码和电子邮件) 通常会发布到名为 WHOIS 的公开数据库中，任何人都可以查询。WHOIS 隐私保护会将您的个人信息替换为注册商的通用信息，在满足法律要求的同时保护您的隐私。

    通过 Replit 购买的所有域名默认包含 WHOIS 隐私保护，无需额外付费。这意味着垃圾邮件发送者、营销人员及其他查询域名所有者信息的人都无法看到您的个人信息。
  </Accordion>

  <Accordion title="如果我已经有域名了，该怎么办？">
    若要将现有域名连接到 Replit 应用，请参阅[自定义域名](/zh/ko/features/publishing/custom-domains)文档。
  </Accordion>
</AccordionGroup>
