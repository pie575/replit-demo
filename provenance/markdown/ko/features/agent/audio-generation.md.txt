# 오디오 생성

> Agent로 앱을 위한 음악, 음향 효과, 음성을 생성하세요.

Agent의 오디오 생성 기능으로 앱에 소리를 추가하세요. Agent에게 배경 음악, 음향 효과, 음성 내레이션을 만들도록 요청하면 프로젝트에 오디오를 직접 추가해 줍니다.

오디오 생성은 녹음 스튜디오, 성우, 외부 도구 없이도 더 풍부한 경험을 만들 수 있도록 도와줍니다. 게임을 만들든, 가이드 튜토리얼을 만들든, 음성이 필요한 앱을 만들든, Agent는 프로젝트에 맞는 오디오를 만듭니다.

## 만들 수 있는 것

Agent는 세 가지 종류의 오디오를 생성할 수 있습니다:

* **음악**: 설명한 분위기와 스타일의 배경 트랙과 테마 음악.
* **음향 효과**: 클릭, 알림, 휙 지나가는 소리, 게임 사운드 같은 짧은 클립.
* **음성**: 제공한 텍스트로부터 자연스러운 내레이션과 보이스오버.

## 사용법

오디오 생성은 Agent에 내장되어 있어 별도로 켤 필요가 없습니다. Agent가 있는 Replit 앱을 열고 필요한 오디오를 설명하세요. Agent는 요청에 따라 언제 오디오를 생성할지 결정하고, 클립을 만들어 프로젝트에 추가합니다.

### Agent가 오디오를 생성하는 경우

프로젝트에서 소리를 요청할 때 Agent가 오디오를 생성합니다:

| 사용 사례    | 예시 프롬프트                             |
| -------- | ----------------------------------- |
| 배경 음악    | "내 명상 앱에 차분한 배경 음악을 추가해 줘"          |
| 게임 음향 효과 | "내 게임에 코인 획득 소리와 점프 소리를 만들어 줘"      |
| 음성 내레이션  | "온보딩 단계를 소리 내어 읽어주는 친근한 목소리를 생성해 줘" |
| 알림 및 통지  | "새 메시지가 도착하면 재생되는 짧은 차임벨을 만들어 줘"    |

### 예시 프롬프트

다음 프롬프트로 시작해 보세요:

<AiPrompt>
  내 아케이드 게임의 메인 메뉴에 신나는 8비트 배경 음악을 추가해 줘. 반복해도 지루하게 들리지 않도록 짧게 유지해 줘.
</AiPrompt>

<AiPrompt>
  앱이 로드될 때 다음 환영 메시지를 읽어주는 차분하고 따뜻한 목소리를 생성해 줘: "다시 오셨네요. 하던 곳부터 이어가 볼까요."
</AiPrompt>

<AiPrompt>
  내 할 일 앱을 위한 세 가지 짧은 음향 효과를 만들어 줘: 작업을 완료 표시할 때 나는 부드러운 클릭 소리, 부드러운 오류 알림음, 전체 목록을 지웠을 때 나는 축하하는 소리.
</AiPrompt>

## 오디오가 앱에 통합되는 방식

Agent는 다른 에셋을 처리하는 방식과 동일하게 생성된 오디오를 프로젝트에 추가합니다:

* **자동 파일 생성**: 생성된 오디오 파일이 프로젝트에 직접 저장됩니다.
* **코드 업데이트**: Agent는 적절한 순간에 재생되도록 오디오를 앱에 연결합니다.
* **반복**: Agent에게 분위기, 길이, 목소리, 스타일을 조정하도록 요청하면 오디오를 다시 생성합니다.

## 청구

오디오 생성은 Agent 서비스입니다. Agent는 제공업체의 요율로 청구하며 Replit 크레딧에서 차감됩니다. 청구 내역은 [사용량 페이지](/ko/billing/managing-spend)에 표시됩니다.

<Note>
  Replit의 오디오 생성은 고품질 음악, 음향 효과, 음성을 생성하는 [ElevenLabs](https://elevenlabs.io/)로 구동됩니다.
</Note>
