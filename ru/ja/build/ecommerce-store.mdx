export const PromptActions = ({prompt = "", campaign = "docs-prompt-actions"}) => {
  const LZ_SRC = "https://cdnjs.cloudflare.com/ajax/libs/lz-string/1.5.0/lz-string.min.js";
  const ensureLZString = () => {
    if (typeof document === "undefined") return;
    if (window.LZString) return;
    if (document.querySelector(`script[src="${LZ_SRC}"]`)) return;
    const s = document.createElement("script");
    s.src = LZ_SRC;
    s.async = true;
    document.head.appendChild(s);
  };
  const handleCopy = async e => {
    const btn = e.currentTarget;
    if (!prompt) return;
    try {
      await navigator.clipboard.writeText(prompt);
    } catch {
      const ta = document.createElement("textarea");
      ta.value = prompt;
      document.body.appendChild(ta);
      ta.select();
      try {
        document.execCommand("copy");
      } catch {}
      document.body.removeChild(ta);
    }
    const original = btn.dataset.label || btn.innerText;
    btn.dataset.label = original;
    btn.innerText = "Скопировано!";
    setTimeout(() => {
      if (btn.isConnected) btn.innerText = original;
    }, 1500);
  };
  const handleBuild = () => {
    if (!prompt || typeof window === "undefined") return;
    const utm = `utm_source=replit-docs&utm_medium=docs&utm_campaign=${encodeURIComponent(campaign)}&utm_content=prompt-actions`;
    let url;
    if (window.LZString) {
      const encoded = window.LZString.compressToEncodedURIComponent(prompt);
      url = `https://replit.com/?prompt=${encoded}&referrer=replit-docs&${utm}`;
    } else {
      url = `https://replit.com/?prompt=${encodeURIComponent(prompt)}&referrer=replit-docs&${utm}`;
    }
    window.open(url, "_blank", "noopener,noreferrer");
  };
  ensureLZString();
  const baseButtonStyle = {
    display: "inline-flex",
    alignItems: "center",
    gap: "6px",
    padding: "8px 16px",
    borderRadius: "8px",
    fontSize: "14px",
    fontWeight: 500,
    cursor: "pointer",
    lineHeight: 1.2,
    fontFamily: "inherit",
    textDecoration: "none"
  };
  return <div style={{
    display: "flex",
    gap: "12px",
    margin: "16px 0",
    flexWrap: "wrap",
    alignItems: "center"
  }}>
      <button type="button" onClick={handleCopy} style={{
    ...baseButtonStyle,
    background: "transparent",
    color: "inherit",
    border: "1px solid rgba(127,127,127,0.4)"
  }}>
        Скопировать промпт
      </button>
      <button type="button" onClick={handleBuild} style={{
    ...baseButtonStyle,
    background: "#F26207",
    color: "#FFFFFF",
    border: "1px solid #F26207"
  }}>
        Создать в Replit ↗
      </button>
    </div>;
};

Когда вы будете готовы начать продажи, останется только зайти в Shopify, подать заявку на магазин и подключить приём платежей.

  ## Что у вас получится

По завершении этого руководства у вас будет:

* Витрина магазина свечей с собственным дизайном, работающая на базе настоящего магазина Shopify.

* Корзина, которая направляет покупателей к оформлению заказа в Shopify.
* Понятный путь к публикации: подайте заявку на подтверждение магазина, включите приём платежей и запустите продажи.

Вы узнаете, как:

* Добавлять и публиковать товары в чате с Agent.
* Улучшать дизайн и путь покупателя.
* Перевести магазин из режима разработки в опубликованную готовую к продажам витрину.

<div id="shopify">
  ## Подключение к Shopify
</div>

Shopify доступен всем создателям и во всех приложениях, а подключается прямо в диалоге. Для начала опишите магазин, который хотите создать.

<Steps>
  <Step title="Опишите свой магазин">
    Скопируйте промпт и вставьте его в поле ввода на [replit.com](https://replit.com) или нажмите **Build on Replit**, чтобы открыть Replit с уже заполненным промптом.

    <Frame>
      <img src="/assets/mirror/describe-your-store-b5d724daee99.png" alt="Поле ввода промпта на главной странице Replit с описанием магазина свечей Ember & Oak (всё готово к началу сборки)" width="1440" height="900" data-path="images/replitai/shopify/describe-your-store.png" />
    </Frame>

    <PromptActions prompt={CANDLE_STORE_PROMPT} campaign="docs-ecommerce-store" />

    Agent поймёт, что вы собираетесь продавать физические товары, и предложит Shopify в качестве бэкенда для витрины магазина.

    <Frame>
      <img src="/assets/mirror/connect-shopify-store-7f36389f976f.png" alt="Replit Agent передаёт управление навыку Shopify для магазина свечей Ember & Oak. Отображается карточка «Connect to Shopify» с кнопкой Connect Shopify" width="3452" height="1984" data-path="images/replitai/shopify/connect-shopify-store.png" />
    </Frame>
  </Step>

  <Step title="Подтвердите создание магазина Shopify">
    Agent попросит разрешения создать магазин Shopify для вашего приложения. После подтверждения он подготовит и подключит принадлежащий Replit тестовый магазин. Никакой дополнительной настройки не требуется.
    Ваш адрес электронной почты будет передан Shopify, чтобы позже вы могли заявить права на магазин.

    Изначально магазин защищён паролем и не может принимать реальные платежи до публикации, так что экспериментировать можно свободно и без риска.
  </Step>
</Steps>

<Note>
  Каждый магазин Shopify привязан к одному приложению. Если позже вы создадите второй магазин, Agent подготовит для этого приложения новый магазин Shopify. Подробнее о коннекторе см. в разделе [Подключение к Shopify](/ru/ja/features/integrations/shopify).
</Note>

<div id="section-3">
  ## Создание витрины
</div>

После подключения Shopify Agent спроектирует и создаст витрину для вашего магазина.

<Steps>
  <Step title="Поручите Agent создать фронтенд">
    Agent сгенерирует витрину по вашему промпту — главный баннер, сетку товаров, корзину и раздел поддержки. Когда всё будет готово, правая панель переключится на **Preview**, где вы сможете прокручивать страницу и кликать по элементам дизайна.

    <Frame>
      <img src="/assets/mirror/storefront-preview-f5ecb9011a8c.png" alt="Витрина Ember & Oak, отрисованная в панели Replit Preview рядом с чатом Agent. Показаны главный баннер со свечами и сетка товаров" width="3452" height="1978" data-path="images/replitai/shopify/storefront-preview.png" />
    </Frame>
  </Step>

  <Step title="Добавьте первый товар">
    Новый магазин начинается с пустого каталога. Попросите Agent добавить товар — он создаст его в Shopify и опубликует на витрине.

    <AiPrompt>
      Добавь лавандовую соевую свечу за $18 с коротким уютным описанием и опубликуй её на витрине.
    </AiPrompt>

    Товар будет создан в магазине Shopify и появится в сетке товаров на витрине.

    <Frame>
      <img src="/assets/mirror/add-product-8b098e606340.png" alt="Чат Agent с добавлением товара «лавандовая соевая свеча». Новый товар отображается в сетке товаров витрины Ember & Oak" width="3452" height="1978" data-path="images/replitai/shopify/add-product.png" />
    </Frame>
  </Step>

  <Step title="Наполните каталог">
    Продолжайте описывать и добавлять товары. Agent создаст каждый из них в Shopify вместе с ценой, описанием и изображением.

    <AiPrompt>
      Добавь ещё три свечи: Cedar &amp; Sage за $20, Vanilla Bean за $16 и Sea Salt за $22. К каждой добавь короткое описание и опубликуй.
    </AiPrompt>
  </Step>
</Steps>

<Tip>
  **Следующий уровень:** попросите Agent сгруппировать товары в коллекции («Создай праздничную коллекцию из трёх самых продаваемых свечей»). Также можно добавить варианты товаров — например, размер или аромат, — отслеживать остатки и показывать наличие на витрине. Shopify при этом остаётся единой системой учёта.
</Tip>

<div id="section-4">
  ## Улучшите дизайн и оформление заказа
</div>

Любую часть витрины можно изменить через диалог. Доработайте внешний вид, а затем проверьте путь покупателя от начала до конца.

<Steps>
  <Step title="Улучшите дизайн">
    Опишите, что хотите изменить, и Agent обновит витрину.

    <AiPrompt>
      Сделай главный блок более «журнальным» — крупный заголовок, больше свободного пространства, а для кнопок используй мягкие янтарные акценты.
    </AiPrompt>
  </Step>

  <Step title="Протестируйте корзину и оформление заказа">
    Добавьте свечу в корзину в Preview и начните оформление заказа. Корзина перенаправит покупателя на страницу оформления заказа, размещённую на Shopify. Во время разработки магазин защищён паролем, поэтому при предпросмотре оформления заказа может появиться страница ввода пароля — это ожидаемо, ничего не сломалось.
  </Step>
</Steps>

<Tip>
  **Следующий уровень:** попросите Agent добавить страницы товаров, выдвижную корзину, поиск или блок рекомендуемых товаров. Витрина — это полноценный проект Replit, поэтому её можно дополнить чем угодно, что вы сумеете описать: блогом, списком желаний, отдельными лендингами, — а Shopify возьмёт на себя оформление и обработку заказов.
</Tip>

<div id="section-5">
  ## Публикация магазина
</div>

Публикация выполняется в Shopify. Попросите Agent запустить процесс публикации, а затем выполните шаги, которые остаются за продавцом.

<Steps>
  <Step title="Заявите права на магазин в Shopify">
    Заявка оформляется в Shopify — это единственный шаг, который выполняется за пределами Replit. Поскольку при создании магазина ваш адрес электронной почты был передан в Shopify, заявить права на магазин можно по ссылке от Replit или из письма, отправленного Shopify.

    Вы получите от Shopify письмо **Store owner invitation** с инструкциями. Откройте письмо и нажмите **Get started**.

    <Frame>
      <img src="/assets/mirror/claim-store-email-a0d108f2191c.png" alt="Письмо Shopify «Store owner invitation» с приглашением стать владельцем магазина и кнопкой «Get started»" width="856" height="1024" data-path="images/replitai/shopify/claim-store-email.png" />
    </Frame>

    Войдите в существующую учётную запись Shopify или создайте новую, чтобы принять приглашение.

    <Frame>
      <img src="/assets/mirror/claim-store-create-account-99d2e132da19.png" alt="Экран Shopify «Create an account» для принятия приглашения с вариантами входа через почту, Google, Apple и Facebook" width="3452" height="1978" data-path="images/replitai/shopify/claim-store-create-account.png" />
    </Frame>

    Нажмите **Claim store**, чтобы одобрить приложение Replit для магазина и начать бесплатный пробный период. После этого вы попадёте в панель управления Shopify как основной владелец.

    <Frame>
      <img src="/assets/mirror/claim-store-4facb7c8b10c.png" alt="Экран Replit «Claim your store» с кнопкой «Claim store» для начала бесплатного пробного периода Shopify" width="3452" height="1978" data-path="images/replitai/shopify/claim-store.png" />
    </Frame>
  </Step>

  <Step title="Выберите тарифный план и включите приём платежей">
    Выберите тарифный план Shopify и подключите Shopify Payments или другого провайдера. Shopify запросит данные для подтверждения личности и банковские реквизиты, необходимые для приёма платежей, — в Replit это не выполняется.
  </Step>

  <Step title="Настройте доставку, налоги и домен">
    Задайте в Shopify стоимость доставки, проверьте налоговые настройки и при желании подключите собственный домен.
  </Step>

  <Step title="Запустите и опубликуйте магазин">
    Удалите пароль витрины в Shopify, чтобы открыть магазин для покупателей. Вернитесь в Replit и нажмите **Publish**, чтобы развернуть витрину по публичному URL.
  </Step>
</Steps>

<Note>
  Платежи, подтверждение личности, налоги, доставка и проверки на мошенничество выполняются в Shopify. Полный чек-лист публикации и подробности о коннекторе см. в разделе [Подключение к Shopify](/ru/ja/features/integrations/shopify#go-live-on-shopify).
</Note>
