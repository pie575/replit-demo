</div>

<div id="novos-modelos-de-ia-nas-integraes">
  ### Nouveaux modèles d’IA dans les Intégrations
</div>

La prise en charge des modèles d’IA récemment lancés est désormais disponible dans les Intégrations d’IA :

| Modèle                       | Description                                                                                                                                                                      |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `gpt-5.2`                    | Le modèle le plus performant d’OpenAI pour le travail intellectuel intensif. Premier modèle à dépasser 90 % sur ARC-AGI-1 avec une fenêtre de contexte de 400K.                  |
| `claude-opus-4.5`            | Le modèle phare d’Anthropic, optimisé pour le codage, les agents et l’utilisation d’outils informatiques. Atteint 80,9 % sur SWE-bench Verified.                                 |
| `gemini-3-flash-preview`     | Le modèle haute vitesse de Google pour les flux de travail agentiques, avec un contexte de 1M de jetons. Raisonnement proche du niveau Pro, avec une latence et un coût réduits. |
| `gemini-3-pro-preview`       | Le modèle multimodal avancé de Google, doté d’un raisonnement de pointe et d’une connaissance du monde réel.                                                                     |
| `gemini-3-pro-image-preview` | Le modèle Nano Banana Pro de Google pour générer et modifier des images de haute qualité avec un rendu précis du texte.                                                          |
