Управление моделями в Enterprise позволяет администраторам аккаунта определять, какие модели Agent доступны разработчикам для выбора. Задайте политику на уровне аккаунта, а затем настройте отдельные права доступа к моделям для конкретных Workspace.

<Note>
  Управление моделями доступно исключительно администраторам аккаунтов Enterprise. Свяжитесь с нашим отделом продаж по адресу [sales@replit.com](mailto:sales@replit.com), чтобы подключить эту возможность для вашей организации.
</Note>

<div id="use-intelligent-model-routing">
  ## Использование интеллектуальной маршрутизации моделей
</div>

Интеллектуальная маршрутизация моделей — это стандартный режим работы Agent в Enterprise Workspace. Когда включён **режим Auto**, Replit выбирает режим и модель, которые лучше всего подходят для каждой задачи, соблюдая баланс между качеством и стоимостью.

Маршрутизация выбирает модели из набора, разрешённого политиками аккаунта и Workspace. Провайдеры и модели за пределами этого набора для выбора недоступны. Разработчики могут оставить **режим Auto** включённым или отключить его и выбрать разрешённую модель вручную.

<div id="open-agent-model-settings">
  ## Откройте настройки моделей Agent
</div>

1. Откройте **Settings**.
2. В разделе **Account** выберите **Advanced**.
3. Разверните раздел **Режимы Agent и провайдеры моделей**.

<div id="set-a-provider-policy">
  ## Настройка политики провайдера
</div>

<Steps>
  <Step>
    Выберите провайдера моделей, которым хотите управлять.
  </Step>

  <Step>
    В разделе **Account policy** выберите один из вариантов:

    | Вариант             | Результат                                                        |
    | ------------------- | ---------------------------------------------------------------- |
    | **Enable all**      | Все модели провайдера доступны в каждом Workspace.               |
    | **Enable selected** | Вы сами выбираете доступные модели для каждого Workspace.        |
    | **Disabled**        | Ни один Workspace не может использовать модели этого провайдера. |

    <Note>
      Хотя бы одна модель от OpenAI, Anthropic и Google должна оставаться включённой. Остальных провайдеров можно отключить.
    </Note>
  </Step>

  <Step>
    Нажмите **Update**.
  </Step>
</Steps>

Провайдеры моделей с открытым исходным кодом отключены по умолчанию. Чтобы сделать провайдера доступным, выберите **Enable all** или **Enable selected**, а затем нажмите **Update**.

<div id="set-a-workspace-policy">
  ## Настройка политики для Workspace
</div>

Используйте **Enable selected**, когда разным Workspace требуется разный доступ к моделям.

<Frame caption="Политика провайдера Anthropic со значением Enable selected и доступом к моделям, настроенным для каждого Workspace.">
  <img src="/assets/mirror/anthropic-account-policy-workspace-models-38c0f71a609d.jpg" alt="Политика аккаунта Anthropic со значением Enable selected и переключателями моделей для Workspace" width="2000" height="930" data-path="images/workspace/anthropic-account-policy-workspace-models.jpg" />
</Frame>

1. Откройте настройки провайдера.
2. Задайте для параметра **Account policy** значение **Enable selected**.
3. В списке **Workspace** откройте раскрывающийся список **Setting** для нужного Workspace.
4. Включите или отключите каждую модель для этого Workspace.
5. Нажмите **Update**.

Перед нажатием **Update** можно выбрать **Copy to all**, чтобы применить
текущий набор моделей ко всем Workspace в аккаунте.

<div id="limitations">
  ## Ограничения
</div>

* Политики моделей действуют на уровне Workspace. Задать отдельную политику для группы пользователей в рамках одного Workspace нельзя.
* Интеллектуальная маршрутизация моделей не отменяет политики учётной записи или Workspace. Она не может выбрать отключённого провайдера или отключённую модель.
* Переключатель **Модели режима Fast** в разделе **Режимы Agent и провайдеры моделей** управляет доступом к быстрым вариантам моделей во всех Workspace учётной записи. Политики провайдеров и интеллектуальная маршрутизация моделей на эту настройку не влияют.
