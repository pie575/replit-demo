С коннектором Shopify Agent развернёт магазин Shopify, соберёт для него собственную витрину и возьмёт на себя управление товарами и остатками. Без ключей API и полностью в рамках одного диалога. Agent будет предлагать Shopify каждый раз, когда вы упомянете продажу физических товаров. Заходить в Shopify придётся только в момент публикации. От первого промпта до реального заказа — около 10 минут.

<Note>
  Пошаговое руководство смотрите в разделе [Создание витрины Shopify](/ru/ja/build/ecommerce-store).
</Note>

<div id="section">
  ## Что можно создать
</div>

* Витрину с индивидуальным дизайном для физических товаров
* Магазин фирменного мерча и одежды
* Магазин прямых продаж (D2C) с корзиной и оформлением заказа
* Инструменты управления каталогом и складскими остатками на базе магазина Shopify
* Лендинг для продажи одного флагманского товара

<div id="agent">
  ## Чем управляет Agent
</div>

Всю витрину и каталог можно редактировать прямо в чате.

| Область                    | Возможности Agent                                                                                                                                                                                                                                                                                                                           |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Дизайн                     | Создаёт headless-фронтенд по вашим указаниям (без тем Liquid и без библиотеки шаблонов). Тексты, макет, навигацию, анимацию и страницы товаров можно править в чате, а варианты оформления — прорабатывать в [Canvas](/ru/ja/design/canvas). Это полноценный проект Replit, поэтому его можно дополнить блогом, списком желаний или лендингом. |
| Товары                     | Создание, обновление и удаление товаров и вариантов. Поля: название, описание, тип, поставщик, теги, SKU, цена, вес, опции (размер, цвет), изображения, доступность.                                                                                                                                                                        |
| Остатки                    | Настройка и корректировка остатков по каждому варианту.                                                                                                                                                                                                                                                                                     |
| Коллекции                  | Группировка товаров в коллекции.                                                                                                                                                                                                                                                                                                            |
| Скидки                     | Создание ценовых правил и промокодов.                                                                                                                                                                                                                                                                                                       |
| Публикация и синхронизация | Новые товары публикуются на витрине автоматически. Синхронизация работает в обе стороны: изменения в панели управления Shopify отображаются в предпросмотре Replit, а изменения, внесённые Agent, — в панели управления Shopify.                                                                                                            |

<div id="replitshopify">
  ## Разделение ролей между Replit и Shopify
</div>

| За что отвечает Replit                                   | За что отвечает Shopify                            |
| -------------------------------------------------------- | -------------------------------------------------- |
| Дизайн и сборка витрины                                  | Размещённое оформление заказа                      |
| Управление каталогом через чат (товары, остатки, скидки) | Система учёта товаров, остатков, корзины и заказов |
| Хостинг и развёртывание витрины                          | Платежи, проверка личности (KYC), выплаты          |
| Варианты дизайна в Canvas                                | Налоги, доставка, фулфилмент                       |
| Расширение приложения (блог, лендинги и т. п.)           | Продажи по нескольким каналам                      |

Заказы, возвраты, выплаты и фулфилмент обрабатываются в панели администратора Shopify, а не в Agent.

<div id="section-4">
  ## Область действия подключения
</div>

* Доступно всем разработчикам на всех тарифах. Настраивать что-либо в панели Connectors и вводить учётные данные не нужно — подключение выполняется прямо в диалоге.
* Область действия — приложение: у каждого приложения свой магазин Shopify.
* Пока вы не заявите права на магазин, это принадлежащий Replit магазин для разработки. Ваш адрес электронной почты передаётся в Shopify, чтобы вы могли заявить права на магазин позже.
* Удалить приложение Replit можно в любой момент из панели администратора Shopify.

<div id="shopify">
  ## Публикация магазина на Shopify
</div>

Публикация выполняется не в Replit, а в Shopify. Попросите Agent запустить процесс Go Live и выполните в панели администратора Shopify следующие шаги, которые доступны только владельцу магазина:

* **Заявите права на магазин** — по ссылке из чата или из письма, которое отправит Shopify. Ссылка действует 7 дней. После подтверждения прав начинается бесплатный пробный период.
* **Выберите тариф**: для обработки реальных заказов требуется [платный тариф](https://www.shopify.com/pricing).
* **Настройте приём платежей**: подключите [Shopify Payments](https://help.shopify.com/en/manual/payments/shopify-payments) или другого провайдера и пройдите проверку личности (KYC). Реальное списание средств заработает после того, как аккаунт владельца пройдёт KYC.
* **Настройте [доставку](https://help.shopify.com/en/manual/shipping) и [налоги](https://help.shopify.com/en/manual/taxes).**
* **[Подключите собственный домен](/ru/ja/build/add-custom-domain)** (необязательно) и снимите пароль с витрины, чтобы открыть её покупателям.

Оформление заказа всегда перенаправляется на страницу оплаты, размещённую в Shopify, поэтому покупатели платят на стороне Shopify.

<Note>
  Платежи, проверку личности, налоги, стоимость доставки и защиту от мошенничества обеспечивает Shopify. Replit не собирает банковские реквизиты продавца, налоговые идентификаторы и другую конфиденциальную информацию.
</Note>

<div id="section-5">
  ## Устранение неполадок
</div>

<AccordionGroup>
  <Accordion title="Настройка магазина Shopify занимает много времени">
    При развёртывании вызывается несколько API Shopify, поэтому она может занять некоторое время. Дождитесь, пока Agent завершит настройку, и только потом просите его собрать витрину.
  </Accordion>

  <Accordion title="Во время разработки при оформлении заказа появляется страница с паролем">
    Магазины для разработки защищены паролем до момента публикации, поэтому предпросмотр оформления заказа может переводить на страницу с паролем. Это ожидаемое поведение, при этом корзина работает. Снимайте пароль в Shopify только при запуске.
  </Accordion>

  <Accordion title="При оформлении заказа не проходит реальная оплата">
    Чтобы принимать реальные платежи, в аккаунте Shopify, на который заявлены права, должны быть завершены настройка платежей и проверка KYC. До этого оформление заказа перенаправляет в Shopify, но платёж принять не получится. Завершите KYC или используйте аккаунт с уже настроенными платежами.
  </Accordion>

  <Accordion title="Agent сообщает, что в этом приложении Shopify не подключён">
    Каждый магазин привязан к одному приложению. Если вы подключили Shopify в другом приложении, попросите Agent настроить магазин Shopify для текущего приложения.
  </Accordion>

  <Accordion title="Товары не отображаются на витрине">
    Товары отображаются, только если они активны и опубликованы. Agent автоматически публикует созданные им товары. Если товары не видны, попросите Agent опубликовать их и обновите предпросмотр.
  </Accordion>

  <Accordion title="После переноса требуется повторно подключить интеграцию">
    После заявления прав или переноса магазина Shopify может запросить повторную авторизацию подключения. Попросите Agent заново подключить Shopify — доступ восстановится без потери магазина.
  </Accordion>
</AccordionGroup>
