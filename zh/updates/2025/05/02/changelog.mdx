<div id="replit-auth">
  ### Replit Auth
</div>

[Replit Auth](/zh/features/auth-and-identity/authentication) 现已向所有用户开放！这是一套内置身份验证系统，只需极少配置，即可为你的应用添加用户登录功能。无需从头构建复杂的身份验证系统，Replit Auth 提供了安全、开箱即用且与 Replit 基础设施集成的解决方案。

**主要功能：**

* **零配置** - 在 Agent 中通过一句 prompt 即可添加身份验证
* **内置安全性** - 基于 Replit 的基础设施，提供针对常见攻击的防护
* **用户管理** - 通过 Auth 面板轻松管理用户
* **数据库集成** - 自动在数据库中创建用户记录
* **可自定义登录页面** - 为你的应用打造个性化登录体验
* **密码重置** - Replit 会处理密码重置邮件，无需自行配置邮件发送服务

入门很简单——只需在 Agent prompt 中加入对 Replit Auth 的请求：

<AiPrompt>
  帮我创建一个 [你的应用创意] 的应用，并集成 Replit Auth。
</AiPrompt>
