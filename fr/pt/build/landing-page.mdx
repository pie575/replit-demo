export const PromptActions = ({prompt = "", campaign = "docs-prompt-actions"}) => {
  const LZ_SRC = "https://cdnjs.cloudflare.com/ajax/libs/lz-string/1.5.0/lz-string.min.js";
  const ensureLZString = () => {
    if (typeof document === "undefined") return;
    if (window.LZString) return;
    if (document.querySelector(`script[src="${LZ_SRC}"]`)) return;
    const s = document.createElement("script");
    s.src = LZ_SRC;
    s.async = true;
    document.head.appendChild(s);
  };
  const handleCopy = async e => {
    const btn = e.currentTarget;
    if (!prompt) return;
    try {
      await navigator.clipboard.writeText(prompt);
    } catch {
      const ta = document.createElement("textarea");
      ta.value = prompt;
      document.body.appendChild(ta);
      ta.select();
      try {
        document.execCommand("copy");
      } catch {}
      document.body.removeChild(ta);
    }
    const original = btn.dataset.label || btn.innerText;
    btn.dataset.label = original;
    btn.innerText = "Copié !";
    setTimeout(() => {
      if (btn.isConnected) btn.innerText = original;
    }, 1500);
  };
  const handleBuild = () => {
    if (!prompt || typeof window === "undefined") return;
    const utm = `utm_source=replit-docs&utm_medium=docs&utm_campaign=${encodeURIComponent(campaign)}&utm_content=prompt-actions`;
    let url;
    if (window.LZString) {
      const encoded = window.LZString.compressToEncodedURIComponent(prompt);
      url = `https://replit.com/?prompt=${encoded}&referrer=replit-docs&${utm}`;
    } else {
      url = `https://replit.com/?prompt=${encodeURIComponent(prompt)}&referrer=replit-docs&${utm}`;
    }
    window.open(url, "_blank", "noopener,noreferrer");
  };
  ensureLZString();
  const baseButtonStyle = {
    display: "inline-flex",
    alignItems: "center",
    gap: "6px",
    padding: "8px 16px",
    borderRadius: "8px",
    fontSize: "14px",
    fontWeight: 500,
    cursor: "pointer",
    lineHeight: 1.2,
    fontFamily: "inherit",
    textDecoration: "none"
  };
  return <div style={{
    display: "flex",
    gap: "12px",
    margin: "16px 0",
    flexWrap: "wrap",
    alignItems: "center"
  }}>
      <button type="button" onClick={handleCopy} style={{
    ...baseButtonStyle,
    background: "transparent",
    color: "inherit",
    border: "1px solid rgba(127,127,127,0.4)"
  }}>
        Copier le prompt
      </button>
      <button type="button" onClick={handleBuild} style={{
    ...baseButtonStyle,
    background: "#F26207",
    color: "#FFFFFF",
    border: "1px solid #F26207"
  }}>
        Build sur Replit ↗
      </button>
    </div>;
};

Il doit avoir une allure haut de gamme, comme une publicité de magazine — sombre, intense et luxueux, avec le noir et l'or chaud comme seules couleurs. De grands titres en gras, beaucoup d'espace négatif et d'élégantes touches de sérif. Pas de couleurs vives, pas d'esthétique « startup tech » aux formes arrondies.

Voici ce qui doit figurer sur la page, de haut en bas :

Une barre d'en-tête avec un petit logo doré « RJ » à gauche, les mots « RACHEL JONES — FITNESS COACH » à côté, quelques liens de menu au centre (À propos, Coaching, Programmes, Témoignages, Ressources) et un bouton doré « Réservez une consultation gratuite » à droite.

Une immense section d'accroche avec une photo dramatique en gros plan d'une femme forte et athlétique, éclairée d'une chaude lumière dorée sur fond noir. À gauche, sur la zone sombre, placez un gigantesque titre sur trois lignes :
« CORPS PLUS FORT. ESPRIT PLUS SÛR. VOUS INARRÊTABLE. » — avec la dernière ligne en doré.
En dessous : « Coaching personnalisé. Stratégies éprouvées. Une bande « À la une dans les médias » — une fine rangée de logos fictifs de magazines, écrits dans différentes polices élégantes : Women's Health, Oxygen, Forbes, mindbodygreen, Fit Pregnancy, Shape.

Une page de destination permet de présenter de manière ciblée une idée, une campagne, une liste d’attente, un événement ou une offre.

<div id="o-que-voc-vai-aprender">
  ## Ce que vous allez apprendre
</div>

Vous apprendrez à :

* Créer une page à partir d’un public cible, d’une offre et d’un appel à l’action.
* Demander à Agent le contenu de la page, la mise en page et le comportement du formulaire.
* Vérifier que la page est claire avant de la partager.
* Tester un formulaire à l’URL publiée.
* Améliorer la page en fonction de la qualité des réponses obtenues.

<div id="refine-e-explore-alternativas-no-canvas">
  ## Affinez et explorez des alternatives dans Canvas
</div>

Une fois qu’Agent a terminé la première version, ouvrez Canvas pour donner un retour visuel et demander à Agent d’autres orientations sans réécrire le prompt.

<Steps>
  <Step title="Créez la page d’accueil">
    Copiez le prompt et collez-le dans la zone de prompt sur [replit.com](https://replit.com), ou cliquez sur **Construire avec Replit** pour ouvrir Replit avec le prompt prérempli.

    <PromptActions prompt={RACHEL_JONES_PROMPT} campaign="docs-landing-page" />
  </Step>

  <Step title="Prévisualisez l’app créée par Agent">
    Une fois qu’Agent a terminé, le panneau de droite passe à **Preview** pour vous permettre d’interagir avec la page d’accueil en temps réel. Faites défiler la section d’en-tête, cliquez sur les appels à l’action et vérifiez que le texte et les images correspondent à vos demandes avant de commencer les ajustements.

    <Frame>
      <img src="/assets/mirror/landing-preview-4855c4b25270.png" alt="La page d’accueil de la coach sportive Rachel Jones affichée dans le panneau Preview de Replit à côté du Chat d’Agent — une section d’en-tête éditoriale sombre avec le titre « Un corps plus fort. Un esprit confiant. Vous êtes inarrêtable. » sur un portrait baigné de lumière dorée, les boutons Travaillez avec Rachel et Découvrez l’histoire de Rachel, des certifications à droite et une bande de cinq étoiles « À qui plus de 500 femmes dans le monde font confiance »" width="3452" height="1988" data-path="images/fitstart/launch-landing-page/landing-preview.png" />
    </Frame>
  </Step>

  <Step title="Ouvrez le Canvas">
    Sélectionnez le bouton **Canvas** sous les onglets Preview et Tools pour remplacer Preview par Canvas dans le panneau de droite.

    <Frame>
      <img src="/assets/mirror/landing-canvas-button-494c5b0076b1.png" alt="Le workspace Replit, avec le bouton Canvas mis en évidence sous les onglets Preview et Tools" width="720" height="450" data-path="images/fitstart/launch-landing-page/landing-canvas-button.png" />
    </Frame>
  </Step>

  <Step title="Annotez hors de l’aperçu">
    Utilisez les outils **Texte** et **Dessin** du Canvas pour ajouter des notes et des flèches dans l’espace vide autour de la maquette, puis faites-les pointer vers l’élément précis que vous souhaitez que l’Agent modifie. Les annotations placées sur le Canvas — en dehors de l’aperçu — sont jointes à votre retour afin que l’Agent puisse les consulter avec la maquette.

    Limitez chaque annotation à une seule modification. Les notes courtes et précises (&quot;Réduisez la largeur de ce bouton&quot;) sont plus efficaces que les retours trop généraux.

    <Frame>
      <img src="/assets/mirror/landing-canvas-annotate-text-8135bfe1e8e2.png" alt="Une annotation du Canvas indiquant 'Réduisez la largeur de ce bouton', placée dans la marge vide du Canvas à droite de la page d’accueil de Rachel Jones, avec une flèche pointant vers le bouton doré 'Planifiez une consultation gratuite' dans l’en-tête de la page" width="3452" height="1988" data-path="images/fitstart/launch-landing-page/landing-canvas-annotate-text.png" />
    </Frame>
  </Step>

  <Step title="Sélectionnez les annotations et l’aperçu, puis envoyez-les à l’Agent">
    Sélectionnez vos annotations et le frame de l’aperçu avec un cadre de sélection, saisissez un court prompt dans **Chat sur les éléments sélectionnés**, puis envoyez-le. Agent lit les annotations et le design comme un contexte unique, ce qui lui permet de savoir à quel élément chaque note se rapporte.

    Gardez le message du chat général — par exemple &quot;Appliquez les modifications indiquées dans les annotations.&quot; Laissez les annotations fournir les détails précis.

    <Frame>
      <img src="/assets/mirror/landing-canvas-send-24b771bf29bf.png" alt="La page d’accueil de Rachel Jones sélectionnée avec deux annotations dans Canvas — « Réduisez la largeur de ce bouton » pointant vers le bouton Planifier une consultation gratuite et « Ajoutez une animation de glissement à l’image de Rachel » pointant vers l’image principale — avec un prompt de chat saisi dans le champ Chat sur les éléments sélectionnés" width="1726" height="1988" data-path="images/fitstart/launch-landing-page/landing-canvas-send.png" />
    </Frame>
  </Step>

  <Step title="Explorez différentes directions">
    Cliquez sur le design dans le Canvas et sélectionnez une suggestion à côté, comme **Explorer différentes approches**, pour demander à l’Agent de générer d’autres orientations visuelles.

    <Frame>
      <img src="/assets/mirror/landing-canvas-reimagine-9e60c24f342f.png" alt="Trois propositions alternatives de page d’accueil générées sous forme de frames de Design sur le Canvas, à côté de l’original" width="1726" height="994" data-path="images/fitstart/launch-landing-page/landing-canvas-reimagine.png" />
    </Frame>
  </Step>

  <Step title="Passez en revue les alternatives et itérez">
    Attendez qu’Agent termine la génération. **Explorer différentes approches** met à jour le même artefact avec de nouvelles variantes — passez de l’une à l’autre dans le menu déroulant de l’artefact au-dessus du mockup. **Explorer différentes ambiances** génère des mockups visuels distincts qui apparaissent sur le Canvas à côté de l’original.

    Lorsque les variantes sont prêtes, choisissez une direction et continuez à itérer. Ajoutez une autre annotation au frame choisi, sélectionnez-le avec le design à l’aide d’une sélection rectangulaire, puis envoyez une nouvelle demande — par exemple, &quot;Appliquez les modifications demandées dans les annotations.&quot; Agent utilise le contexte de la variante et vos nouvelles annotations comme un seul prompt.

    <Frame>
      <img src="/assets/mirror/landing-canvas-zoomed-4d1585d33fe6.png" alt="La page d’accueil de Rachel Jones dans le Canvas après qu’Agent a généré trois variantes d’ambiance (Chaleur éditoriale, Clinique silencieuse, Pop vibrante) — le frame d’origine est sélectionné avec deux nouvelles annotations (« Réduisez la largeur de ce bouton » et « Ajoutez une animation de glissement à l’image de Rachel ») et le Chat indique « Appliquez les modifications demandées dans les annotations »" width="3452" height="1988" data-path="images/fitstart/launch-landing-page/landing-canvas-zoomed.png" />
    </Frame>
  </Step>

  <Step title="Publiez votre travail">
    Lorsque la page fonctionne dans Preview, cliquez sur **Publier** (ou **Republier** pour les déploiements suivants) en haut à droite du workspace pour mettre en ligne la dernière version à votre URL publique. Ouvrez l’URL publiée dans un nouvel onglet et envoyez une réponse de test pour vérifier que la page en ligne la reçoit avant de la partager.

    <Frame>
      <img src="/assets/mirror/landing-publish-e3b901a79440.png" alt="Le coin supérieur droit du workspace Replit agrandi 2x — le bouton gris Republier dans l’en-tête est mis en évidence par un contour orange et son infobulle est ouverte en dessous. Elle indique « Raouf a publié il y a environ 18 heures », Visibilité : Publique, ainsi que les boutons d’action Examiner la sécurité et Republier" width="2142" height="1072" data-path="images/fitstart/launch-landing-page/landing-publish.png" />
    </Frame>
  </Step>
</Steps>
