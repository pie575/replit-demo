<Info>
  **本页面仅适用于 Enterprise 计划。** 独立的账户管理员和工作区管理员角色仅在 Enterprise 中提供。

  在 **Core** 和 **Pro** 计划中，每个账户只有一名 **账户管理员** (通常是账户所有者) ，没有单独的工作区管理员角色。如果您使用 Core 或 Pro，请参阅[管理成员](/zh/ko/teams/identity-and-access-management/managing-members)和[角色、群组和访问权限](/zh/ko/teams/identity-and-access-management/groups-and-permissions)——其中介绍的 **Admin** 角色即为账户管理员。
</Info>

在 Enterprise 计划中，Replit 将管理职责划分为两个独立的角色：**账户管理员**和**工作区管理员**。通过分离这些角色，您可以在不授予账单管理和整个账户控制权的情况下，授予他人对特定工作区的完全控制权。本页介绍各角色的职责、两者的区别以及设置方法。

<div id="section">
  ## 两种角色的关系
</div>

Replit **账户**是计费实体，拥有订阅、席位以及一个或多个**工作区** (组织) ——Enterprise 账户可能拥有多个工作区。这两种管理员角色分别对应这两个范围：

* **账户管理员**管理整个账户，可控制计费，并对该账户下的所有工作区拥有管理员访问权限。
* **工作区管理员**仅管理自己所属的特定工作区 (可以是多个) ，没有计费访问权限，也无法控制其他工作区。

所有账户管理员都会自动成为该账户下所有工作区的管理员，因此账户管理员实际上是工作区管理员的超集。而工作区管理员并非账户管理员，无法管理计费或其他工作区。

<CardGroup cols={2}>
  <Card title="账户管理员" icon="building-shield">
    覆盖整个账户。管理计费、席位、安全设置以及账户下的所有工作区。
  </Card>

  <Card title="工作区管理员" icon="user-shield">
    限于工作区范围。仅管理自己工作区内的成员和资源。
  </Card>
</CardGroup>

<div id="section-2">
  ## 各角色可执行的操作
</div>

两种角色都负责管理工作区——区别在于管理*哪些*工作区。账户管理员管理账户下的所有工作区，而工作区管理员只管理自己所属的工作区。

| 功能                      | 账户管理员 | 工作区管理员 |
| ----------------------- | :---: | :----: |
| 管理所辖工作区的成员              |   是   |    是   |
| 管理所辖工作区的应用、群组和资源        |   是   |    是   |
| 查看和编辑账单、支付方式、发票         |   是   |    否   |
| 编辑、取消或恢复订阅              |   是   |    否   |
| 添加、移除、分配席位              |   是   |    否   |
| 设置支出和使用限额               |   是   |    否   |
| 创建新工作区                  |   是   |    否   |
| 管理其他账户管理员               |   是   |    否   |
| 管理账户下的所有工作区             |   是   |    否   |
| 配置 SAML、SCIM、审计日志、安全联系人 |   是   |    否   |

工作区管理员的管理权限仅限于自己的工作区，而账户管理员在整个账户范围内拥有全部管理权限。

<Note>
  账单、席位管理、订阅变更以及账户级安全控制需要账户管理员权限。工作区管理员即便在自己的工作区内也无法执行这些操作。
</Note>

<div id="section-3">
  ## 账户管理员设置
</div>

账户管理员在设置的 **Seats** 标签页中管理。添加账户管理员后，该用户将获得整个账户的管理员访问权限，并自动成为该账户下所有工作区的管理员。

<div id="section-4">
  ### 将成员提升为账户管理员
</div>

<Steps>
  <Step title="打开 Seats 选项卡">
    在设置中打开 **Seats** 选项卡。该选项卡会列出账户中的所有成员及其当前角色。
  </Step>

  <Step title="提升成员">
    找到要提升的成员，打开操作菜单并选择 **Promote to account admin**。更改会立即生效。
  </Step>
</Steps>

<div id="section-5">
  ### 降级账户管理员
</div>

降级账户管理员后，其对整个账户和账单的访问权限将被移除。默认情况下，降级不会将其移出工作区——无论是否为账户管理员，他们仍会保留工作区访问权限。

<Steps>
  <Step title="打开 Seats 选项卡">
    在设置中打开 **Seats** 选项卡。
  </Step>

  <Step title="降级账户管理员">
    找到该账户管理员，打开操作菜单，然后选择 **Demote from account admin**。更改会立即生效。
  </Step>
</Steps>

为防止账户失去管理员访问权限，以下规则适用：

* 您无法降级自己。
* 您无法移除最后一位账户管理员。账户中必须始终至少有一位账户管理员。
* 您无法降级个人账户的所有者。

<div id="scim">
  ### 通过 SCIM 预配的管理员
</div>

如果你使用 [SCIM](/zh/ko/teams/identity-and-access-management/scim) 预配用户，则在身份提供商中被分配 **Admin** 角色的用户会成为**账户管理员**。若要创建工作区范围的管理员，请在 Replit 中分配 **Workspace admin** 角色，而不要在身份提供商中分配。

<div id="section-6">
  ## 工作区管理员设置
</div>

如需授予特定工作区完整的管理权限，同时不授予整个账户或账单访问权限，请分配工作区管理员角色。当团队负责人需要管理自己的工作区，而无需管理订阅或其他团队时，此角色非常有用。

<Steps>
  <Step title="打开工作区成员列表">
    打开要分配管理员的工作区，然后前往 **Members** 页面。
  </Step>

  <Step title="将成员角色设为 Workspace admin">
    找到该成员，打开角色选择器，然后选择 **Workspace admin**。该成员将获得仅限该工作区的管理员访问权限。
  </Step>
</Steps>

<Note>
  工作区管理员的访问权限仅限于其所属的工作区。他们无法访问账单、管理席位或管理其他工作区 — 这些操作需要账户管理员权限。
</Note>

<div id="section-7">
  ## 选择合适的角色
</div>

* **账户管理员**：适用于需要负责账单、管理订阅与席位、配置安全设置或统管所有工作区的人员。
* **工作区管理员**：适用于负责运营单个团队或工作区，需要在不涉及账单和其他工作区的情况下管理成员与资源的人员。
