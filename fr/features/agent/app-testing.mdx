Le test d&#39;application permet à Agent de tester les applications qu&#39;il crée dans un véritable navigateur. Agent parcourt votre application comme le ferait un utilisateur réel : il clique sur les éléments et vérifie que les fonctionnalités répondent correctement. Cette capacité d&#39;autotest contribue à garantir le bon fonctionnement de votre application et permet à Agent de détecter et de corriger les problèmes automatiquement.

<div id="how-app-testing-works">
  ## Fonctionnement d&#39;App Testing
</div>

Découvrez App Testing en action pendant qu&#39;Agent navigue dans votre application :

Lorsque App Testing est activé, Agent décide périodiquement de lancer un test lorsqu&#39;il estime que suffisamment d&#39;éléments ont changé pour le justifier. Agent ne teste pas après 100 % des messages de l&#39;utilisateur : il détermine intelligemment les moments où les tests apportent le plus de valeur.

<Note>
  Pour l&#39;instant, App Testing est disponible pour les applications web Full Stack JavaScript et Streamlit Python.
</Note>

<div id="key-benefits">
  ### Principaux avantages
</div>

* **Autonomie prolongée** : permet à Agent de travailler plus longtemps sans intervention humaine
* **Meilleure qualité** : produit des applications comportant moins d&#39;erreurs en identifiant et en corrigeant les problèmes en amont
* **Rentabilité** : évite les sessions de débogage supplémentaires en détectant les problèmes dès la phase de développement
* **Analyse interactive** : propose des relectures vidéo et une navigation section par section pour examiner les résultats en profondeur

<div id="the-testing-process">
  ### Le processus de test
</div>

Lorsqu&#39;Agent décide de se tester lui-même, voici ce qui se passe :

1. **Aperçu du navigateur** : un aperçu du navigateur s&#39;affiche dans le volet Agent
2. **Test visuel** : observez le curseur d&#39;Agent cliquer dans votre app pour en tester les fonctionnalités
3. **Simulation d&#39;un utilisateur réel** : Agent navigue dans votre application exactement comme le ferait un utilisateur réel, en saisissant des données fictives si nécessaire
4. **Analyse automatique** : Agent analyse les résultats des tests et repère les éventuels problèmes
5. **Autocorrection** : Agent vous transmet un récapitulatif de ses tests et corrige automatiquement les problèmes rencontrés

<div id="key-capabilities">
  ## Fonctionnalités clés
</div>

Agent teste intelligemment votre application en y naviguant comme le ferait un véritable utilisateur, et couvre :

* **Validation de l&#39;interface utilisateur** : boutons, formulaires, navigation et éléments visuels
* **Vérification du fonctionnement** : fonctionnalités principales et parcours utilisateur
* **Tests d&#39;intégration** : appels d&#39;API, interactions avec la base de données et services tiers
* **Performances et accessibilité** : temps de chargement, réactivité et normes d&#39;accessibilité

<div id="usage">
  ## Utilisation
</div>

App Testing se trouve dans les **Paramètres avancés**, au sein du menu déroulant des paramètres d&#39;Agent dans votre champ de saisie Chat. Activez-le lorsque vous utilisez le mode Economy ou Power. Le mode Lite laisse App Testing désactivé.

<Note>
  App Testing fait partie des capacités autonomes d&#39;Agent, au même titre que la revue de code intégrée. Découvrez les autres [fonctionnalités
  d&#39;Agent](/fr/features/agent/overview).
</Note>

<div id="take-over">
  ## Prise de contrôle
</div>

Il arrive que l&#39;Agent rencontre un obstacle pendant les tests et ait besoin de votre aide pour continuer. Le plus souvent, il s&#39;agit de se connecter à un compte utilisateur (Gmail, par exemple). Dans ce cas, l&#39;Agent affiche un bouton « Prendre le contrôle ».

<Frame>
  <img src="/assets/mirror/app-testing-takeover-6e0b0b56f4d0.png" alt="Interface de prise de contrôle du test d'application affichant les boutons Ignorer et Prendre le contrôle, avec des instructions pour gérer les erreurs et les CAPTCHA" width="924" height="358" data-path="images/replitai/app-testing-takeover.png" />
</Frame>

En appuyant sur « Prendre le contrôle », vous pouvez cliquer dans l&#39;aperçu de test, effectuer les étapes requises, puis laisser l&#39;Agent poursuivre. Vous pouvez également appuyer sur « Ignorer » pour renoncer à la prise de contrôle, ce qui met fin au test de l&#39;application si l&#39;Agent ne peut pas continuer sans votre aide. Si vous ne répondez pas dans les 10 minutes, l&#39;Agent poursuivra comme si vous aviez appuyé sur « Ignorer ».

<div id="what-to-expect">
  ### À quoi s&#39;attendre
</div>

* **Option Ignorer** : utilisez le bouton Ignorer pour passer les tests si nécessaire et poursuivre le développement
* **Relecture vidéo interactive** : une fois les tests terminés, cliquez sur la vidéo pour revoir l&#39;intégralité de la session de test
* **Navigation par section** : utilisez les curseurs en bas de l&#39;écran pour accéder directement à une section précise du test

<div id="troubleshooting">
  ## Dépannage
</div>

**Tests qui échouent de façon inattendue**

* Essayez d&#39;ignorer l&#39;étape, puis de relancer un prompt pour tester
* Vérifiez si du contenu dynamique peut perturber le déroulement des tests
* Relisez les scénarios de test pour en vérifier l&#39;exactitude

**Couverture de test insuffisante**

* Décrivez plus en détail les fonctionnalités de votre application
* Mentionnez explicitement les parcours utilisateur critiques à tester

**App Testing ne fonctionne pas du tout ?**

* Pour l&#39;instant, App Testing ne fonctionne qu&#39;avec les applications web[*](#how-app-testing-works)

<div id="pricing-and-usage">
  ## Tarification et utilisation
</div>

App Testing est inclus dans le modèle de tarification basé sur l&#39;effort d&#39;Agent, avec quelques points importants à prendre en compte côté coûts :

* **Basé sur l&#39;utilisation** : les tests sont facturés selon l&#39;effort fourni (plus un test est simple, moins il coûte cher)
* **Coût et bénéfice** : les tests sont certes payants, mais ils permettent de réduire les coûts en évitant des prompts supplémentaires et du travail additionnel de la part d&#39;Agent, puisque les erreurs sont détectées plus tôt
* **Développement efficace** : l&#39;approche automatisée limite le besoin de débogage manuel et de reprises

<Tip>
  **Des tests rentables** : bien qu&#39;App Testing augmente vos coûts d&#39;utilisation, il permet souvent d&#39;économiser au global en évitant des sessions Agent supplémentaires destinées à corriger des problèmes qui auraient pu être détectés pendant les tests.
</Tip>
