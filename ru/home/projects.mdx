<div id="what-is-a-project">
  ## Что такое проект?
</div>

Проект — это единое пространство для всего, что вы создаёте в Replit. В нём хранятся ваш код, данные и все артефакты — веб-приложения, мобильные приложения, презентации, панели данных и видео. Когда вы объясняете Agent, что хотите создать, он настраивает проект и создаёт в нём артефакты.

Представьте проект как рабочее пространство на вашем столе. Всё находится в одном месте и может использовать общую информацию, но каждый элемент служит своей цели.

Например, если вы попросите Agent создать приложение для отслеживания физической активности, он создаст проект с артефактом мобильного приложения, а также необходимыми для его работы бэкендом, базой данных и хранилищем.

<ArtifactGrid />

Основные понятия:

* **Проект**: Единое пространство, в котором находятся ваш код, данные и все артефакты
* **Артефакт**: Публикуемый результат в проекте (веб-приложение, презентация, видео и т. д.)
* **Ресурсы**: Каждый артефакт автоматически получает доступ к бэкенду, базе данных и файловому хранилищу — настройка не требуется

<Note>
  Публикация развёртывает весь ваш проект целиком. Все артефакты становятся доступными
  одновременно, поэтому они всегда синхронизированы.
</Note>

<div id="what-you-can-build">
  ## Что можно создать
</div>

| Тип                                                                       | Что это                                                                 | Пример                                                             |
| ------------------------------------------------------------------------- | ----------------------------------------------------------------------- | ------------------------------------------------------------------ |
| **[Веб-приложение](/ru/features/artifact-types/web-apps)**                   | Сайт или веб-приложение, которое открывают в браузере                   | Интернет-магазин, сервис бронирования, сайт-портфолио              |
| **[Мобильное приложение](/ru/features/artifact-types/building-mobile-apps)** | Нативное приложение, которое устанавливают на телефон                   | Фитнес-трекер, приложение для заказа еды                           |
| **[Визуализация данных](/ru/features/artifact-types/data-apps)**             | Интерактивная панель с диаграммами, фильтрами и актуальными данными     | Отчёт о продажах, трекер метрик, аналитическая панель              |
| **[Презентация](/ru/features/artifact-types/slide-decks)**                   | Презентация, которую можно показать или экспортировать                  | Презентация для инвесторов, обновление для команды, обзор продукта |
| **[Анимация](/ru/features/artifact-types/animated-videos)**                  | Видео с моушн-графикой, которое можно экспортировать в MP4              | Видео о запуске продукта, объясняющее видео, контент для соцсетей  |
| **3D-игра**                                                               | 3D-игра, симуляция или интерактивный проект                             | Головоломка, физическая симуляция, интерактивный проект            |
| **[Design](/ru/design/canvas)**                                              | Визуальные концепции и прототипы, которые можно прорабатывать на Canvas | Мудборды, макеты, варианты дизайна                                 |

В одном проекте можно разместить несколько артефактов. Например, вы можете создать веб-приложение для клиентов, мобильное приложение для команды и презентацию для инвесторов — всё в одном проекте. Артефакты в одном проекте автоматически используют общие данные и логику бэкенда. Подробнее см. в разделе [Артефакты](/ru/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project).

<div id="managing-your-projects">
  ## Управление проектами
</div>

На странице проектов отображаются все созданные вами проекты и проекты, в которые вас пригласили. Это самый быстрый способ вернуться к недавней работе и найти нужный проект в рабочем пространстве с большим количеством проектов.

<div id="see-at-a-glance-whats-inside-each-project">
  ### Сразу видно, что находится внутри каждого проекта
</div>

На карточке каждого проекта показаны небольшие значки артефактов, которые в нём есть: веб-приложений, мобильных приложений, презентаций, визуализаций данных и анимаций. Наведите курсор на любой значок, чтобы прямо на карточке увидеть скриншот этого артефакта — так вы сможете различать проекты, не открывая их.

<div id="filter-by-artifact">
  ### Фильтрация по артефактам
</div>

Используйте раскрывающийся список **Build type** в верхней части страницы Projects, чтобы отфильтровать список по типу артефакта. Выберите тип, чтобы отображались только проекты с соответствующим артефактом:

* **Web** — проекты с веб-приложением
* **Mobile** — проекты с мобильным приложением
* **Data** — проекты с визуализацией данных
* **Slides** — проекты с презентацией
* **Design** — проекты в режиме Design
* **3D Game**, **Agent &amp; Automation** и другие

Выберите **Any build type**, чтобы сбросить фильтр.

<div id="sort-by-last-opened">
  ### Сортировка по времени последнего открытия
</div>

На странице Projects по умолчанию проекты сортируются по времени, когда вы в последний раз их открывали: те, с которыми вы работали недавно, отображаются вверху. Это особенно удобно в командных рабочих пространствах, где недавние изменения других участников иначе могли бы отодвинуть вашу текущую работу вниз.

Чтобы изменить сортировку, выберите заголовок другого столбца (например, **Последнее обновление** или **Название**).

<div id="pin-the-projects-you-use-most">
  ### Закрепляйте часто используемые проекты
</div>

Закрепите проект, чтобы он всегда был вверху списка. Закрепления **видны только вам** — закрепление проекта в командном рабочем пространстве не влияет на то, что видят другие участники.

Чтобы закрепить проект, откройте меню дополнительных действий (три точки) на карточке проекта и выберите **Pin**. Чтобы снять закрепление, выберите **Unpin** в том же меню.
