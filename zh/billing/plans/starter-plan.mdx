<div id="what-you-get">
  ## 你将获得什么
</div>

Starter 方案为你提供在 Replit 上开始构建所需的一切。创建应用、发布你的第一个 project——完全免费。

<div id="daily-credits-for-agent">
  ### Agent 每日额度
</div>

Starter 套餐用户每天可获得 Agent 使用额度，但每月总额度设有上限。这些额度每天重置，让你每天都能获得新的 Agent 使用额度。

<div id="monthly-credits-for-cloud-usage">
  ### 云服务每月额度
</div>

你还会获得可用于以下服务的每月额度：

* [数据库 (生产环境) ](/zh/features/data-and-storage/development-and-production)
* [对象存储](/zh/features/data-and-storage/object-storage)
* [Publishing (Autoscale、静态) ](/zh/learn/projects-and-artifacts/replit-deployments)

这些额度每月会重置。

<div id="lite-build">
  ### Lite build
</div>

可使用 [Lite build](/zh/features/agent/agent-modes)：一种快速、聚焦的构建体验，适合借助 Agent 进行快速编辑和针对性修改。

<div id="one-free-published-app">
  ### 一个免费发布的应用
</div>

无论使用 Lite build 还是 Design Canvas，你都可获得 {FreeDeployments} 个免费发布的应用。该发布链接将在 30 天后自动失效。

你发布的应用会带有一个“Made with Replit”徽章，其中包含你专属的推荐链接。如果有其他用户通过该徽章上的链接注册，你在升级到付费方案后即可获得推荐积分。

<div id="limitations">
  ## 限制
</div>

以下功能需要升级到 Core 方案才能使用：

<div id="full-build">
  ### 完整构建
</div>

[完整构建](/zh/features/agent/overview/) 让 Agent 能以更强大的能力和更高的自主性独立工作。Starter 套餐用户只能使用[轻量构建](/zh/features/agent/agent-modes)。使用完整构建需要 Core 或 Pro 套餐。

<div id="converting-a-design-to-an-artifact">
  ### 将设计转换为 artifact
</div>

将 Design Canvas 中的设计转换为完整的 artifact 需要 Core 计划。Starter 计划用户可以创建并发布设计，但若要转换为具备 backend 功能的 artifact，则需要升级。如果你想构建带 backend 功能的 App，可以先尝试 [Lite build](/zh/features/agent/agent-modes)。

<div id="third-party-connectors">
  ### 第三方连接器
</div>

使用外部连接器需要订阅 Core。这包括与 Google、Stripe 等服务及其他第三方 API 的集成 (更多信息请参阅[此处](https://docs.replit.com/features/integrations/overview#connectors)) 。

<div id="replit-ai-integrations">
  ### Replit AI 集成
</div>

[Replit AI 集成](/zh/features/integrations/replit-ai-integrations)需要 Core 订阅。

<div id="remove-made-with-replit-badge">
  ### 移除“Made with Replit”标识
</div>

要从已发布的 App 中移除“Made with Replit”标识，需要 Core 方案。Starter 方案用户的部署中会显示该标识。

<div id="additional-published-apps">
  ### 更多已发布应用
</div>

Starter 套餐用户可免费发布 {FreeDeployments} 个应用。超出此数量后，需升级至 Core 或 Pro 套餐。

<div id="plan-mode">
  ### Plan 模式
</div>

使用 Plan 模式需要 Core 套餐。Plan 模式让你可以构思想法、规划工作，并与 Replit Agent 协作，而不会修改应用的代码或数据。

<div id="all-artifact-types">
  ### 所有 artifact 类型
</div>

构建网页和移动 App 以外的 artifact 需要 Core。您可以选择数据可视化、幻灯片演示文稿、动画视频等多种类型。请参阅 [Projects](/zh/features/projects-and-artifacts/projects)。

<div id="upgrading-to-core">
  ## 升级到 Core
</div>

想要更多功能？升级到 Core，解锁以下权益：

* **更多存储空间和每月额度**，还支持按量付费
* **发布应用数量不限**，不再只有首个免费应用
* **完整 Build 功能**，实现自主开发
* **第三方 connector**，轻松对接外部服务
* **Replit AI 集成**，无需自行管理 API 密钥即可使用 AI 模型
* **Plan 模式**，先梳理清楚 task，再开始 build
* **移除 Replit 徽章**，让应用更专业
* 以及更多功能
