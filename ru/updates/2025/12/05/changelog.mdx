<div id="build-full-stack-mobile-apps-with-agent">
  ### Создавайте полностековые мобильные приложения с Agent
</div>

<Frame>
  <img src="/assets/mirror/cleanshot-2025-12-05-at-12-27-22-2x_273f89390642-dc03158b7d7f.png" width="1082" height="504" data-path="images/changelog/2025-12-05/cleanshot-2025-12-05-at-12-27-22-2x_273f89390642.png" />
</Frame>

Теперь Agent может создавать [мобильные приложения](/ru/features/artifact-types/building-mobile-apps) с полноценным серверным бэкендом. Это открывает доступ к широким возможностям, включая [AI Integrations](/ru/replitai/integrations), [базу данных](/ru/features/data-and-storage/sql-database), [Object Storage](/ru/features/data-and-storage/object-storage) и коннекторы — всё необходимое для разработки мобильных приложений, готовых к запуску в продакшене.

<div id="database-now-generally-available">
  ### База данных теперь общедоступна
</div>

Новая [база данных](/ru/features/data-and-storage/sql-database) теперь используется по умолчанию во всех новых Replit App. Это обновление повышает надежность, улучшает контроль над инфраструктурой и производительность, а также упрощает управление данными в ваших проектах.

<div id="fast-mode-handles-more-autonomously">
  ### Fast Mode стал автономнее
</div>

<Frame>
  <img src="/assets/mirror/image_4f661377d428-8454460e1cca.png" width="720" height="212" data-path="images/changelog/2025-12-05/image_4f661377d428.png" />

[Режим Lite](/ru/core-concepts/agent/agent-modes) (ранее Fast Mode) теперь может самостоятельно выполнять больше задач и рекомендует Agent для более крупных изменений. Создавайте приложения быстрее благодаря быстрым итерациям и удобной передаче задач.

<div id="connect-third-party-services-faster">
  ### Быстрее подключайте сторонние сервисы
</div>

Благодаря улучшенной поддержке коннекторов подключать сторонние сервисы стало быстрее. Для добавления большинства сервисов с API-ключами достаточно указать их конфигурацию — сложная настройка не требуется. Поддержка конфигураций с несколькими ключами и расширенные проверки работоспособности повышают надёжность [интеграций](/ru/replitai/integrations).
