<div id="replit">
  ### 全新 Replit 桌面应用
</div>

全新 Replit 桌面应用将完整的 Replit 体验带到你的电脑上。除了与网页版一致的构建体验外，你还可以使用原生功能。你可以同时使用多个应用，一目了然地了解 Agent 何时需要你处理、何时已完成任务，还能无需切换即可预览已打开的应用。

<div id="section-3">
  ## 集成
</div>

<div id="whop">
  ### 使用 Whop 在应用内销售
</div>

现在，只需告诉 Agent，就能为你的应用添加 Whop 支付功能。Agent 会代你创建并连接 Whop 账户，把结账功能集成到项目中，无需任何外部配置，也不用粘贴 API 密钥。想要开始销售数字商品、会员资格和订阅服务，Whop 是最快的方式。

详情请参阅 [Whop 支付](/zh/ja/features/monetization/whop-payments)。

<div id="section-4">
  ## 請求
</div>

<div id="procore">
  ### 从 Pro 一步降级到 Core
</div>

现在，您无需先取消订阅，即可直接从 Replit Pro 降级到 Replit Core。此前，唯一的办法是先取消订阅并降至免费套餐，然后再重新订阅。现在，当您发起取消订阅时，Replit 会改为建议您降级到 Core，让您在保留付费套餐的同时，继续运行已发布的应用。

有关详细信息，请参阅[更改套餐](/zh/ja/billing/plans/changing-your-plan)。
