Интеграция Replit с ChatGPT позволяет создавать, обновлять и просматривать Replit App прямо из беседы. Никакой настройки не требуется. Создавайте настоящие приложения в диалоге с ChatGPT — всё остальное сделает Agent.

<div id="chatgptreplit">
  ## Что такое Replit в ChatGPT
</div>

Replit в ChatGPT связывает ваши диалоги в ChatGPT с мощной платформой разработки Replit. Опишите, что хотите создать, и Agent соберёт для вас полностью работающее Replit App. После этого вы можете просить ChatGPT изменять, обновлять и анализировать приложение — и всё это в обычном разговоре.

<div id="section">
  ## Начало работы
</div>

Выполните следующие шаги, чтобы подключить Replit к ChatGPT и создать своё первое приложение.

<div id="replitchatgpt">
  ### Подключение Replit к ChatGPT
</div>

Подключить Replit к ChatGPT можно двумя способами:

<Accordion title="Подключение через Settings">
  1. Нажмите на значок профиля в ChatGPT
  2. Перейдите в **Settings** → **Apps &amp; Connectors**
  3. Найдите **Replit** и нажмите **Connect**
  4. Пройдите авторизацию OAuth под своим аккаунтом Replit
</Accordion>

<Accordion title="Подключение из диалога">
  1. Начните новый диалог в ChatGPT
  2. Вызовите Replit одним из способов ниже
  3. Если подключение ещё не настроено, ChatGPT проведёт вас через процесс OAuth
</Accordion>

<div id="chatgptreplit-2">
  ### Вызов Replit в ChatGPT
</div>

После подключения вызвать Replit можно тремя способами:

| Способ            | Как использовать                                  |
| ----------------- | ------------------------------------------------- |
| Прямое упоминание | В начале сообщения введите `Replit, <ваш запрос>` |
| Слеш-команда      | Введите `/Replit` в поле ввода                    |
| Меню поля ввода   | Нажмите **+** → **More** → **Replit**             |

<div id="section-2">
  ### Создайте первое приложение
</div>

После подключения создайте свой первый Replit App:

1. Начните новый диалог в ChatGPT
2. Обратитесь к Replit и опишите, что хотите создать (например: «Replit, создай Todo-приложение с тёмной темой»)
3. Agent сгенерирует приложение и автоматически развернёт его
4. По завершении вы получите ссылку для просмотра приложения

<Note>
  В рамках одного диалога можно работать только с одним Replit App. Если создать новое приложение в том же диалоге, изменится уже существующее. Чтобы создать несколько приложений, начинайте отдельные диалоги.
</Note>

<div id="section-3">
  ## Возможности
</div>

* **[Replit AI](/ru/ja/build/welcome)**: Agent создаёт и развёртывает приложения по запросам на естественном языке
* **[Project Editor](/ru/ja/learn/projects-and-artifacts/project-editor)**: полнофункциональная среда разработки, доступная из ChatGPT
* **[Publishing](/ru/ja/learn/projects-and-artifacts/replit-deployments)**: приложение автоматически развёртывается и становится доступным для общего доступа

<Accordion title="Что можно делать">
  **Создание**: опишите, что хотите создать, и создайте новое приложение Replit. Agent создаст приложение и автоматически его развернёт.

  **Обновление**: вносите изменения в приложение в текущем разговоре. Попросите ChatGPT добавить функции, исправить ошибки или внести другие изменения — Agent их применит.

  **Проверка**: анализируйте приложение без внесения изменений. Получайте сведения о структуре кода, путях к файлам и работе приложения.
</Accordion>

<Accordion title="Поддерживаемые форматы файлов">
  В промпт можно включать файлы различных типов:

  | Формат                              | Поддержка                           |
  | ----------------------------------- | ----------------------------------- |
  | PDF                                 | Да                                  |
  | CSV                                 | Да                                  |
  | Распространённые форматы документов | Да                                  |
  | Изображения (исходные файлы)        | Нет (используйте общедоступный URL) |
  | Видео (исходные файлы)              | Нет (используйте общедоступный URL) |

  <Note>
    Чтобы добавить изображения или видео в приложение, укажите в промпте общедоступный URL. После создания приложения также можно добавить медиафайлы непосредственно в Replit.
  </Note>
</Accordion>

<Accordion title="Время сборки">
  Обычно Agent создаёт приложения за следующее время:

  | Сложность приложения                                                       | Типичное время сборки |
  | -------------------------------------------------------------------------- | --------------------- |
  | Простое (калькулятор, небольшая целевая страница)                          | 2–3 минуты            |
  | Сложное (игры, сложная анимация, насыщенные информацией панели управления) | 3–4 минуты            |
</Accordion>

<div id="section-4">
  ## Доступные планы и поддержка
</div>

<Accordion title="Планы ChatGPT">
  Интеграция с Replit доступна на всех планах ChatGPT:

  | План           | Поддержка | Примечания                                                                |
  | -------------- | --------- | ------------------------------------------------------------------------- |
  | Free           | Да        |                                                                           |
  | Plus           | Да        |                                                                           |
  | Pro            | Да        |                                                                           |
  | Business       | Да        | Требуется включение администратором в **Workspace settings → Connectors** |
  | Enterprise/Edu | Да        | Требуется включение администратором в **Workspace settings → Connectors** |

  **Доступность по регионам:** все регионы, кроме ЕС.
</Accordion>

<Accordion title="Планы Replit">
  Интеграцию с ChatGPT поддерживают все планы Replit:

  | План           | Поддержка | Примечания                                                     |
  | -------------- | --------- | -------------------------------------------------------------- |
  | Starter (Free) | Да        | Только публичные приложения                                    |
  | Core           | Да        | Приватные приложения, расширенные сборки, Publishing, Database |
  | Pro            | Да        | Более высокий лимит ежемесячных кредитов, все возможности Core |
  | Enterprise     | Да        | Доступ ко всем функциям                                        |
</Accordion>

<div id="section-5">
  ## Оплата и кредиты
</div>

Работа, выполненная Replit в ChatGPT, тарифицируется как использование Agent и списывается с вашего аккаунта Replit.

<Accordion title="Как устроена оплата">
  * Планы **Core** и **Pro** включают ежемесячные кредиты, которые покрывают использование Agent, Publishing и баз данных в пределах лимита
  * Вы можете купить **пакеты кредитов**: они действуют 6 месяцев и не продлеваются автоматически — удобно для релизов и экспериментов
  * Ограничить расходы можно с помощью **лимитов использования** и **бюджетов** в настройках оплаты Replit

  Подробнее — в [документации по оплате ИИ](/ru/ja/billing/ai-billing).
</Accordion>

<div id="section-6">
  ## Текущие ограничения
</div>

На данный момент приложение Replit для ChatGPT:

* работает только с приложениями, созданными в рамках конкретной беседы
* не может открывать или изменять:
  * приложения, созданные в других чатах ChatGPT
  * приложения, созданные непосредственно в Replit

Полное соответствие возможностям Replit — включая базы данных, управление Secrets и расширенные элементы управления Project Editor — появится позже.

<div id="section-7">
  ## Устранение неполадок
</div>

<Accordion title="Replit не отображается в Browse apps">
  Если Replit не отображается в **Browse apps**:

  * проверьте, доступно ли приложение в вашем регионе;
  * уточните, включил ли администратор рабочего пространства приложение Replit (Business/Enterprise/Edu).
</Accordion>

<Accordion title="Сбой сборки">
  Если сборка завершилась с ошибкой, откройте приложение в Replit:

  * проверьте использование и оплату;
  * вернитесь к предыдущему состоянию с помощью чекпоинтов и отката;
  * обратитесь за помощью напрямую к Agent в Project Editor.
</Accordion>
