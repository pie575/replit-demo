<Note>
  管理员 API 目前处于 **Beta** 阶段，可用端点及其行为可能会发生变化。
</Note>

管理员 API 为企业版账户管理员提供基于作用域的编程访问能力，可用于账户分析和管理功能。你可以使用该 API 构建内部报告、运营工作流以及面向企业版账户的集成。

<div id="api">
  ## 谁可以访问管理员 API
</div>

管理员 API 仅限企业版账户的**账户管理员**使用。账户管理员可以创建和管理 API 密钥。工作区管理员和其他账户成员无法访问管理员 API，也无法创建相应的密钥。

如需详细了解企业版管理员角色，请参阅[账户和工作区管理员](/zh/ko/teams/identity-and-access-management/account-and-workspace-admins)。

<div id="api-2">
  ## 创建 API 密钥
</div>

<Steps>
  <Step title="打开开发者设置">
    打开 **设置**，然后在 **账户** 下选择 **开发者**。
  </Step>

  <Step title="创建 API 密钥">
    选择 **创建 API 密钥**，然后选择只读或读写访问权限。
  </Step>

  <Step title="安全保存密钥">
    复制以 `rpl_` 开头的密钥，并将其存储在安全的密钥管理器中。请像对待密码一样妥善保管，切勿分享。
  </Step>

  <Step title="对集成进行身份验证">
    将密钥作为 Bearer 令牌随 API 请求一同发送。
  </Step>
</Steps>

<div id="section">
  ## 可以执行的操作
</div>

管理员 API 使用作用域来控制每个密钥可执行的操作。读取作用域提供用于报表的账户数据,特定的写入作用域则支持更新预算等操作。

* **使用量:** 读取账户使用量和总账目费用,可按工作区、成员、项目或时间段筛选或分组。
* **工作区:** 读取工作区列表及其详细信息,包括成员数和项目数、管理员以及创建时间。
* **成员:** 读取账户和工作区成员关系,可按角色筛选,或按姓名、用户名、电子邮件搜索。
* **项目:** 读取团队工作区中的全部项目,可按公开状态或部署状态筛选,或按标题、slug、说明搜索。
* **预算:** 读取账户预算,并使用 `write:budgets` 作用域进行更新。

API 响应支持游标分页,并包含速率限制标头和用于请求跟踪的 `X-Request-Id`。

<div id="section-2">
  ## 构建报告和工作流
</div>

无论您是在内部仪表板、Slack 通知还是月度财务报告中跟踪运营情况，都可以使用管理员 API 数据。例如，您可以按工作区汇总使用量，以报告各工作区的支出。

<div id="replit-agent">
  ## 使用 Replit Agent 构建
</div>

你可以让 Replit Agent 使用管理员 API 构建自定义仪表板。只需描述你想追踪的账户数据，例如各工作区的使用量或各项目的费用，Agent 就能构建出仪表板及相应的 API 集成。

<Steps>
  <Step title="打开技能选择工具">
    在 Replit 项目中，点击聊天输入框旁的 **+** 按钮，然后选择**使用技能**。
  </Step>

  <Step title="选择管理员 API 技能">
    在 **Replit 技能**下选择**管理员 API**，为 Agent 提供 API 上下文和集成指南。
  </Step>

  <Step title="描述仪表板">
    告诉 Agent 你想追踪哪些内容、希望以什么方式查看。例如，让 Agent 构建一个展示各工作区使用量和各项目费用的仪表板。
  </Step>

  <Step title="安全地添加 API 密钥">
    当 Agent 需要发起 API 请求时，请将 Admin API 密钥添加到项目的密钥中。切勿将密钥粘贴到聊天中或提交到项目里。
  </Step>
</Steps>
