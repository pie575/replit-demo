  ### SendGrid 集成
</div>

现在你可以通过 Agent 创建电子邮件集成，从而在新建的 Agent 项目中使用 SendGrid API 发送电子邮件。

<div id="suporte-mvel-para-visualizao-web">
  ### 网页预览的移动端支持
</div>

我们新增了将网页预览缩放到常见移动设备屏幕尺寸的功能。此外，我们还在 URL 下拉菜单和网络面板中加入了二维码，方便你在移动设备上测试。

提醒一下——即使项目还在开发中，它也已经可以通过互联网访问。只需在任意设备上打开开发 URL 即可。

  ### DNS 记录格式更新
</div>

这将让自定义域名的配置更加简便。

<div id="atualizao-de-deployment-flask">
  ### Flask 部署更新
</div>

gunicorn 现已成为 Flask 技术栈部署的默认 Web 服务器。

相比此前的 Flask 部署，性能提升了 40 倍。

<div id="comandos-shell-inline-do-assistant">
  ### Assistant 内联 Shell 命令
</div>
