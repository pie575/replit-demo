Créez des applications à partir de données réelles et actualisées grâce à la fonctionnalité Web Search <img class="icon-svg" src="/assets/mirror/web-search-1fe8f63b5b88.svg" alt="Icône Web Search" width="16" height="16" data-path="images/icons/web-search.svg" /> d’Agent.

Cette fonctionnalité récupère les informations les plus récentes du Web et s’affranchit des limites liées à la date d’arrêt de ses connaissances. Si vous lui demandez de créer quelque chose nécessitant des informations à jour, Agent recherche sur le Web et récupère des contenus détaillés pour rendre votre application plus précise et utile.

La Web Search est utile pour trouver les packages, outils et informations les plus récents. Elle garantit ainsi que votre application s&#39;appuie sur les meilleures pratiques du moment et gagne en précision.

<div id="section">
  ## Fonctionnalités
</div>

Créez des applications s’appuyant sur des informations à jour grâce à la fonctionnalité Web Search d’Agent. Vous n’avez ainsi plus besoin d’effectuer des recherches manuelles ni de collecter des données. Que vous créiez un tableau de bord avec des données financières ou un site web présentant les dernières informations sur les lancements de start-ups, Web Search garantit que votre application reflète la réalité.

Opérations Web Search qu’Agent peut effectuer :

* **Recherche** : trouver sur Internet des informations à jour, de la documentation récente et des données en temps réel
* **Récupération de contenu** : obtenir des informations détaillées à partir de sites web et d’URL spécifiques
* **Citation des sources** : vérifier et référencer les informations en identifiant précisément où Agent les a trouvées

<div id="section-2">
  ## Utilisation
</div>

Web Search est intégré à Agent : vous n’avez donc pas besoin de l’activer séparément. Décrivez ce que vous souhaitez créer, et Agent déterminera automatiquement quand rechercher des informations récentes. Vous pouvez demander explicitement à Agent d’effectuer une recherche en incluant dans votre prompt des mots-clés tels que « recherche », « fais des recherches » ou « utilise Web Search ».

<div id="web-search">
  ### Comment Web Search améliore votre application
</div>

Web Search permet à votre application de remplacer les données fictives par des informations réelles et précises :

| Avantage                   | Description                                                                                               |
| -------------------------- | --------------------------------------------------------------------------------------------------------- |
| Technologies récentes      | Votre application utilise les dernières informations et des packages absents des données d’entraînement   |
| Choix des meilleurs outils | Agent étudie les options afin de sélectionner le package le plus adapté                                   |
| Bonnes pratiques actuelles | Vous accédez aux dernières méthodes de développement et pratiques de sécurité                             |
| Dépassement des limites    | Vous allez au-delà de la limite des connaissances pour utiliser des packages publiés après l’entraînement |
| Données précises           | Votre application affiche des informations récentes plutôt que des exemples obsolètes                     |
| Résultats professionnels   | Les applications qui font référence à de véritables entreprises inspirent davantage confiance             |
| Gain de temps              | Vous évitez de rechercher manuellement des packages et de collecter des données                           |

<div id="section-3">
  ### Citations de sources
</div>

Lorsque Agent utilise Web Search, il fournit des **citations de sources** indiquant précisément l’origine des informations. Utilisez-les comme suit :

* **Vérifier les informations** : vérifiez la fiabilité et l’exactitude des sources
* **En savoir plus** : consultez les sources originales pour obtenir davantage de contexte
* **Citer les sources** : incluez les mentions de source appropriées dans votre application
* **Suivre les recherches** : identifiez les informations prises en compte dans le travail d’Agent

<div id="section-4">
  ### Récupération de contenu
</div>

Agent peut récupérer du contenu détaillé sur des sites web spécifiques afin de rassembler des informations complètes pour votre projet. Cela permet à Agent de :

* lire des pages web entières et en extraire les informations pertinentes
* traiter de la documentation et des documents de référence
* recueillir des données spécifiques auprès de sources fiables
* intégrer des informations structurées à votre application

Agent étudie les API météo actuelles et compare leurs fonctionnalités, leur fiabilité et leurs tarifs afin de choisir l’option la plus adaptée à vos besoins.
