<div id="importar-do-bolt">
  ## Importer depuis Bolt
</div>

⏰ *Durée estimée : quatre minutes*

<Warning>Agent prend actuellement en charge les importations depuis Bolt pour les applications Vite + React.</Warning>

Importez un projet Bolt dans Replit en l&#39;exportant vers GitHub, puis en important ce dépôt.

Pour découvrir toutes les options d&#39;importation, y compris depuis d&#39;autres plateformes comme GitHub, Figma et Lovable, consultez la [documentation de la fonctionnalité d&#39;importation](/fr/pt/core-concepts/project-editor/app-setup/import).

<div id="antes-de-comear">
  ## Avant de commencer
</div>

* Un projet Bolt que vous pouvez exporter
* Un compte GitHub connecté à Bolt
* Un compte Replit

<div id="passos-de-importao">
  ## Étapes d&#39;importation
</div>

1. Exportez votre projet depuis Bolt vers GitHub.
2. Ouvrez [replit.com/import](https://replit.com/import).
3. Sélectionnez **Bolt**.
4. Connectez votre compte GitHub.
5. Sélectionnez le dépôt exporté depuis Bolt.
6. Sélectionnez **Importer**.

<div id="what-gets-imported">
  ## Ce qui est importé
</div>

Replit importe les éléments suivants depuis votre projet {platform_1} :

* **Code** : logique applicative et fichiers sources
* **Design et styles** : composants UI et règles de style
* **Assets** : images, icônes et fichiers statiques
* **Logique backend** : fonctionnalités côté serveur, le cas échéant
* **Schéma de base de données** : structure des tables, le cas échéant

<div id="what-is-not-imported">
  ## Éléments non importés
</div>

* **Données Supabase** : les enregistrements existants de la base de données ne sont pas migrés
* **Secrets** : les variables d’environnement et les clés API doivent être ajoutées séparément

Utilisez Agent pour recréer les fonctionnalités manquantes, ajouter des secrets et recréer les données de la base de données.

<div id="configure-and-run-your-app">
  ## Configurez et exécutez votre app
</div>

Lors de l&#39;importation, {setupDescription_0}. Si votre app nécessite des ajustements, utilisez ces outils du Project Editor :

* **[Agent](/fr/features/agent/overview)** : affinez les fonctionnalités, corrigez les problèmes et modifiez le code
* **[Secrets](/fr/core-concepts/project-editor/app-setup/secrets)** : ajoutez des clés API et des variables d&#39;environnement
* **[Workflows](/fr/features/workspace-tools/workflows)** : définissez la commande **Run** de votre app
