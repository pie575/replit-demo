<div id="section">
  ## Contenu du système de design
</div>

Le système de design généré comprend :

* **Jetons** — valeurs nommées (couleurs, espacements, arrondis, etc.) auxquelles les autres éléments du système font référence
* **Couleurs** — palette associée à des rôles (primaire, surface, accent, etc.)
* **Typographie** — familles de polices, tailles et graisses
* **Composants d’exemple** — 2 à 3 composants prédéfinis illustrant l’utilisation du système
* **Logo et assets de marque** — inclus s’ils sont explicitement fournis

<div id="section-2">
  ## Comment le système est enregistré
</div>

Le système généré existe dans votre projet sous la forme d’un **guide de style vivant** : les jetons de `tokens.json` sont répercutés dans les variables CSS utilisées par vos composants (par exemple, dans `src/index.css`). `DESIGN.md` en constitue la documentation, que vous pouvez consulter et qu’Agent peut utiliser.

<div id="designmd">
  ## Utiliser DESIGN.md comme source
</div>

Un fichier `DESIGN.md` existant peut servir de point de départ à un nouveau système de design. Lorsque vous [créez](/fr/ja/design/create-a-design-system) un système, indiquez-le parmi d’autres sources, comme une URL Figma, un site web, du code ou des images de référence.
