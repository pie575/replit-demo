<div id="importar-do-vercel">
  ## 从 Vercel 导入
</div>

⏰ *预计用时：三分钟*

关联项目所对应的 GitHub 仓库，即可将 Vercel 项目导入 Replit。

如需了解完整的导入选项，包括 GitHub、Figma、Bolt 和 Lovable 等其他平台，请参阅[导入功能文档](/zh/pt/core-concepts/project-editor/app-setup/import)。

<div id="antes-de-comear">
  ## 开始前准备
</div>

* 已连接 GitHub 的 Vercel 项目
* 对关联 GitHub 仓库的访问权限
* Replit 账户

<div id="passos-de-importao">
  ## 导入步骤
</div>

1. 打开 [replit.com/import](https://replit.com/import)。
2. 选择 **Vercel**。
3. 关联你的 GitHub 账户。
4. 选择你的 Vercel 项目仓库。
5. 添加所需的密钥和环境变量。
6. 选择 **导入**。

<div id="o-que-importado">
  ## 导入内容
</div>

* 项目文件和目录结构
* 依赖项和框架配置
* 适用于 Replit 的运行和构建模式

<div id="o-que-no-importado">
  ## 不会被导入的内容
</div>

* 现有环境变量的值
* 自定义域名
* Vercel 特有的边缘行为或中间件
* 外部分析或监控配置
