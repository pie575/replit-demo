⏰ *Примерное время: 10 минут*

Иногда дизайн, с которого вы хотите начать, уже существует в интернете — например, ваш текущий сайт или страница, внешний вид которой вы хотите воссоздать. Функция Import from URL воссоздаёт сайт в виде дизайн-фрейма, который можно изучить, доработать и превратить в интерактивное App с помощью Build.

В качестве примера используем лендинг для творческой студии, созданный Replit: [creative-studio-landing.replit.app](https://creative-studio-landing.replit.app).

<div id="section">
  ## Перед началом работы
</div>

Вам потребуется:

* [учётная запись Replit](https://replit.com);
* URL опубликованного сайта или URL из приведённого выше примера.

<div id="section-2">
  ## Импорт веб-сайта
</div>

<Steps>
  <Step title="Скопируйте URL сайта">
    Используйте свой сайт или скопируйте этот пример: `https://creative-studio-landing.replit.app`。

    <Frame caption="Сайт для примера: лендинг креативной студии Kosmo Studio.">
      <img src="/assets/mirror/url-example-site-e0ad60629981.webp" alt="Лендинг Kosmo Studio с заголовком «We craft bold ideas and visuals that truly work» и веером расположенными карточками работ" width="3440" height="2160" data-path="images/design/import-from-url/url-example-site.webp" />
    </Frame>
  </Step>

  <Step title="Откройте Replit Design">
    Перейдите на [replit.com/design](https://replit.com/design) и выберите **Import URL** под полем для промпта. Agent воссоздаст внешний вид и стиль сайта, взяв его за основу.

    <Frame caption="Import URL на главной странице Replit Design: вставьте ссылку на любой веб-сайт.">
      <img src="/assets/mirror/design-import-url-07a8ac52e188.webp" alt="Главный экран Replit Design с выбранной опцией Import URL. Отображается подсказка: «Paste a link to any website and Agent will recreate its look and feel as a starting point»" width="2293" height="1322" data-path="images/design/import-from-url/design-import-url.webp" />
    </Frame>
  </Step>

  <Step title="Вставьте URL и начните создание">
    После выбора **Import URL** в поле промпта автоматически появится *«Recreate the look and feel of this website:»*. Затем вставьте URL и выберите **Start**.

    <Frame caption="Промпт для воссоздания с уже введённым URL из примера. Всё готово к началу.">
      <img src="/assets/mirror/design-url-prompt-b6196aac1b17.webp" alt="Поле для промпта в Replit Design с текстом «Recreate the look and feel of this website», за которым следует URL из примера, и кнопкой Start" width="2293" height="1322" data-path="images/design/import-from-url/design-url-prompt.webp" />
    </Frame>
  </Step>
</Steps>

Agent воссоздаст сайт в виде дизайн-фрейма в проекте.

<div id="section-3">
  ## Сделайте дизайн своим
</div>

Выберите импортированный фрейм и настройте его под себя:

* **[Используйте предложения](/ru/ja/design/explore-suggestions)**: Для импортированного фрейма уже подготовлены варианты дальнейших действий: версия в тёмном редакционном стиле, мобильный вьюпорт, страница контактов и другие. Каждый вариант создаётся в новом фрейме, поэтому исходный фрейм сохраняется для сравнения.
* **[Общайтесь в Chat](/ru/ja/design/chat-about-your-design)**: Введите свой запрос в поле под фреймом. Например: *«Замени фотографии в портфолио»*, *«Сделай текст в hero-блоке жирнее»*.
