<div id="agent">
  ### Essayez désormais Agent gratuitement
</div>

Vous pouvez désormais essayer Agent et Assistant gratuitement ! Que vous soyez un développeur Replit expérimenté ou que vous débutiez, vous pouvez tester ces puissants outils sans aucune restriction.

Les 10 premiers checkpoints sont gratuits, y compris pour les développeurs déjà payants. Essayez-les sur [https://replit.com](https://replit.com을).

<div id="replit-mobile">
  ### Replit Mobile
</div>

Replit Mobile a été entièrement repensé ! La nouvelle application mobile offre une expérience de programmation plus rapide et plus intuitive, même en déplacement.

Essayez-la sur [https://replit.com/mobile을](https://replit.com/mobile을).

  ### Nouvelle page de couverture des applications Replit
</div>

La page de couverture a été considérablement améliorée. Elle est désormais plus adaptée aux développeurs et affiche le prompt initial de toutes les applications créées avec Agent.
