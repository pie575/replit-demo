<div id="categorias-de-cobrana">
  ## Категории тарификации
</div>

Replit разделяет оплату App Storage на следующие категории:

* **Хранение**: Объём данных, хранимых в течение месяца. Для всех хранимых объектов установлен минимальный расчётный период семь дней.
* **Передача данных**: Общий объём данных, отправленных и скачанных в течение месяца.
* **Базовые операции**: Операции, связанные с обновлением bucket и объектов. Подробнее см. операции класса A в <a href="https://cloud.google.com/storage/pricing" target="_blank">разделе цен Google Cloud Storage</a>.
* **Расширенные операции**: Все остальные операции с облачным объектным хранилищем, включая получение конфигурации и метаданных об объектах и bucket. Подробнее см. операции класса B в <a href="https://cloud.google.com/storage/pricing" target="_blank">разделе цен Google Cloud Storage</a>.
