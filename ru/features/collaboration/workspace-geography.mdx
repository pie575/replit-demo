География Workspace определяет, где размещаются ресурсы разработки для Workspace. Вы выбираете её при создании Workspace, а новые Projects и ресурсы в этом Workspace используют выбранное расположение.

<Note>
  География Workspace и [география
  публикации](/ru/features/security/geography#publishing-geography) могут различаться.
  География публикации определяет, где выполняется опубликованный Project.
</Note>

<div id="what-workspace-geography-controls">
  ## На что влияет география Workspace
</div>

Workspace объединяет Projects, участников, настройки, общие ресурсы, интеграции и биллинг. Внутри каждого Project вы работаете в Project Editor и чате Replit. К ресурсам разработки относятся dev-версия вашего приложения и её база данных для разработки.

Выбрать конкретный регион Workspace могут только клиенты Pro.

Для пользователей бесплатного плана и плана Core регион Workspace задаётся автоматически — как правило, выбирается ближайший к вам регион. Новые Projects и ресурсы в Workspace размещаются в этом регионе. Изменить регион после создания Workspace нельзя.

<div id="select-a-workspace-region">
  ## Выбор региона Workspace
</div>

Если у вас подписка Pro, вы можете выбрать регион при создании Workspace:

<Steps>
  <Step>Откройте форму **Create a new workspace**.</Step>
  <Step>Укажите название Workspace и при необходимости адреса электронной почты участников.</Step>

  <Step>
    Откройте **регион Workspace** и выберите **North America**, **Europe (EU)**
    или **Asia**.
  </Step>

  <Step>Нажмите **Create workspace**.</Step>
</Steps>

  ## Доступные регионы
</div>

| Регион               | Выбор в Workspace |
| :------------------- | :---------------- |
| **Северная Америка** | Да                |
| **Европа (ЕС)**      | Да                |
| **Азия**             | Да                |
| **Южная Америка**    | Нет               |
| **Австралия**        | Нет               |
