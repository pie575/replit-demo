<div id="importar-do-base44">
  ## Импорт из Base44
</div>

⏰ *Примерное время: четыре минуты*

Чтобы импортировать проект из Base44 в Replit, экспортируйте его в GitHub, а затем импортируйте полученный репозиторий.

Полный список вариантов импорта, включая другие платформы — GitHub, Figma и Lovable, — приведён в [документации по функции импорта](/ru/pt/references/workspace/import).

<div id="antes-de-comear">
  ## Прежде чем начать
</div>

* Проект Base44, который можно экспортировать
* Аккаунт GitHub, подключённый к Base44
* Аккаунт Replit

<div id="etapas-de-importao">
  ## Этапы импорта
</div>

1. Экспортируйте проект из Base44 в GitHub.
2. Откройте [replit.com/import](https://replit.com/import).
3. Выберите **Base44**.
4. Подключите свою учетную запись GitHub.
5. Выберите экспортированный репозиторий Base44.
6. Нажмите **Import**.

<div id="what-gets-imported">
  ## Что импортируется
</div>

Replit импортирует из вашего проекта {platform_1} следующее:

* **Код**: логику приложения и исходные файлы
* **Дизайн и стили**: компоненты интерфейса и правила оформления
* **Ресурсы**: изображения, иконки и статические файлы
* **Логику бэкенда**: серверную функциональность, если она есть
* **Схему базы данных**: структуру таблиц, если она есть

<div id="what-is-not-imported">
  ## Что не импортируется
</div>

* **Данные Supabase**: Существующие записи базы данных не переносятся
* **Secrets**: Переменные окружения и ключи API необходимо добавить отдельно

Используйте Agent, чтобы восстановить недостающие функции, добавить Secrets и воссоздать данные базы данных.
