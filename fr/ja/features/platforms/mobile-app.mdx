[L&#39;application mobile Replit](https://replit.com/mobile) vous permet d&#39;emporter vos projets dans votre poche. Reprenez là où vous vous étiez arrêté ou créez un projet de toutes pièces, où que vous soyez. Discutez avec Agent, modifiez votre projet et déployez-le sur le Web depuis une interface optimisée pour le tactile.

<div id="section">
  ## Prise en main
</div>

Suivez les étapes ci-dessous pour installer l&#39;application et créer un projet.

<div id="section-2">
  ### Installer l&#39;application
</div>

1. Rendez-vous sur la [page de téléchargement de l&#39;application mobile](https://replit.com/mobile) et installez l&#39;application correspondant au système d&#39;exploitation de votre appareil mobile.
2. Ouvrez l&#39;application, puis créez un compte ou connectez-vous avec un compte existant.
   Si vous créez un compte, vous devrez confirmer votre adresse e-mail pour finaliser l&#39;inscription.

<div id="section-3">
  ### Commencer à créer
</div>

L&#39;écran d&#39;accueil vous propose deux possibilités :

* **Reprendre là où vous en étiez** : ouvrez un projet sous **Recent Projects** pour poursuivre votre travail.
* **Partir de zéro** : décrivez ce que vous souhaitez créer dans la zone de saisie, puis envoyez. Agent se met aussitôt à créer le projet.

Pour partir plutôt d&#39;un modèle existant ou de code existant, appuyez sur ⋮ en haut à droite, puis sélectionnez **Remix a Template** ou **Import from GitHub**.

<Note>
  Pour créer une application iOS native, utilisez le Project Editor sur [replit.com](https://replit.com) afin de la créer, la prévisualiser, la compiler ou la soumettre. Le travail sur les applications mobiles natives est également possible dans l&#39;application Replit pour Android, lorsqu&#39;il est pris en charge.
</Note>

<div id="section-5">
  ## Fonctionnalités mobiles
</div>

<div id="section-6">
  ### Saisie vocale
</div>

L&#39;option vocale de la zone de saisie d&#39;Agent vous permet de décrire, en mode mains libres, ce que vous souhaitez créer ou modifier.

<div id="section-7">
  ### Activités en direct
</div>

Suivez la progression d&#39;Agent où que vous soyez. Une notification s&#39;affiche dès qu&#39;Agent démarre. Appuyez sur **Allow** sur l&#39;écran verrouillé. Vous pouvez dès lors suivre la progression sans ouvrir Replit.

<Accordion title="Appareils compatibles">
  * iPhone sous iOS 18 ou version ultérieure
  * iPad sous iOS 18 ou version ultérieure
  * Mac sous macOS Tahoe ou version ultérieure
  * Apple Watch appairée
</Accordion>

<div id="section-8">
  ### Notifications
</div>

Recevez les mises à jour importantes où que vous soyez. Ouvrez **Settings**, puis **Notifications** (par exemple, sous **User**). Vérifiez que les notifications sont activées, puis appuyez sur Autoriser lorsque vous y êtes invité.

Replit vous prévient dans les cas suivants :

* Agent a besoin d&#39;aide
* Agent a terminé son travail
* Une mise à jour importante concernant la facturation est disponible

<div id="section-9">
  ### Mode clavier pour tablette
</div>

Connectez un clavier à votre tablette pour profiter d&#39;une expérience de création optimisée pour les grands écrans. La première fois que vous ouvrez le Project Editor avec un clavier connecté, Replit vous propose d&#39;activer ce mode.

Vous pouvez l&#39;activer ou le désactiver à tout moment dans **Account** &gt; **Keyboard Settings**.

<div id="section-10">
  ## Mise à niveau et facturation
</div>

Pour passer à Core depuis l&#39;application, accédez à **Account**, appuyez sur **Upgrade**, sélectionnez un forfait, puis appuyez sur **Continue with Core**. Pro n&#39;est pas disponible à l&#39;achat dans l&#39;application mobile : vous devez souscrire sur [replit.com](https://replit.com).

Pour utiliser Agent au-delà des crédits inclus dans votre abonnement, ajoutez un moyen de paiement pour la [facturation à l&#39;usage](/fr/ja/billing/about-usage-based-billing) :

* **Sur le Web** : rendez-vous sur replit.com, puis ouvrez **Settings** → **Account** → **Billing**.
* **Dans l&#39;application (iOS aux États-Unis uniquement)** : ouvrez **Settings** → **Billing** (ou **Account** → **Billing**).
