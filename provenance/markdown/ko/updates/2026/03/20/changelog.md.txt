## 플랫폼

### Microsoft App Store의 Replit PWA

Replit이 이제 Microsoft App Store에서 Progressive Web App(PWA)으로 제공되어 Windows 빌더가 Replit을 네이티브와 유사한 애플리케이션으로 쉽게 발견하고 설치할 수 있습니다.

### 빈 프로젝트 생성

이제 가져오기 페이지에서 빈 프로젝트를 만들 수 있습니다. 빈 프로젝트는 시작 시 Agent를 트리거하지 않아 생성 시 크레딧이 소비되지 않으며 프레임워크 및 도구 설정에 대한 완전한 제어권을 제공합니다. 이 수준의 제어를 원하는 빌더를 위해 가져오기 페이지에서 옵션을 사용할 수 있습니다.

## 팀 및 엔터프라이즈

### 엔터프라이즈 감사 로그 포털

엔터프라이즈 감사 로그 포털(v1)이 이제 모든 엔터프라이즈 고객에게 제공됩니다. 관리자는 조직 구성원이 수행한 이벤트를 보고 S3, Datadog, Splunk, Google Cloud Storage, Microsoft Sentinel을 포함한 선택한 SIEM 플랫폼과 이벤트 스트림 통합을 구성할 수 있습니다.
