<div id="o-que-uma-skill">
  ## Что такое навык?
</div>

Навык — это папка. Внутри неё лежит файл `SKILL.md` с инструкциями, которым следует Agent, а также любые вспомогательные файлы, к которым он, по вашему замыслу, должен обращаться. Навыки хранятся в каталоге `/.agents/skills` вашего проекта и соответствуют [спецификации навыков Agent](https://agentskills.io/specification) — открытому стандарту, который работает с разными агентами.

Agent видит название и описание каждого установленного навыка, но загружает его полное содержимое только тогда, когда оно относится к текущей задаче. Благодаря этому навыки экономно расходуют контекст: вы можете установить их сколько угодно, не ухудшая качество ответов Agent.

<div id="skills-pr-definidas">
  ## Встроенные навыки
</div>

В Replit уже есть встроенные навыки — они доступны в списке **Use a skill** в Chat, а также в списке отправных точек для новых проектов. Эти навыки работают во всех проектах без установки. Полный каталог, партнёрские навыки и инструкции по их установке смотрите в [Каталоге навыков](/ru/pt/features/agent/skills-directory).

Чтобы добавить встроенный навык, откройте список **Use a skill** в поле ввода Chat и выберите нужный навык либо просто попросите Agent загрузить его.

<div id="escopo-da-skill">
  ## Область действия навыка
</div>

Навыки могут действовать на разных уровнях:

| Область действия      | Доступность                         | Где хранится                                                                                                       |
| --------------------- | ----------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| **Уровень проекта**   | Только в рамках конкретного проекта | Версионируется вместе с вашими файлами в `/.agents/skills`                                                         |
| **Уровень workspace** | Доступен всем в вашем workspace     | Управляется централизованно в Workspace Settings                                                                   |
| **Enterprise**        | Стандарты всей компании             | Входит в [пользовательские шаблоны](/ru/pt/teams/custom-templates) и [дизайн-системы](/ru/pt/teams/custom-design-system) |

О навыках уровня workspace см. раздел [Agent Customization](/ru/pt/features/agent/agent-customization) — там описано, как настроить навыки workspace и пользовательские инструкции для вашей команды.

<div id="como-o-agent-carrega-skills">
  ## Как Agent загружает навыки
</div>

В каждом чате Agent считывает метаданные (название и описание) всех установленных навыков. Полное содержимое навыка загружается только тогда, когда Agent решает, что этот навык relevantен текущей задаче. Благодаря этому содержимое навыков не занимает контекстное окно, пока в нём нет необходимости.

Установленные навыки сохраняются в проекте между сессиями Agent, а также их можно отправить в систему контроля версий, чтобы поделиться с командой.

<div id="trabalhando-com-outras-ferramentas-de-codificao-com-ia">
  ## Работа с другими ИИ-инструментами для программирования
</div>

<Accordion title="Импорт навыков из других ИИ-инструментов для программирования">
  Если вы пользуетесь несколькими ИИ-инструментами для программирования, [rulesync](https://github.com/dyoshikawa/rulesync) поддерживает Replit и помогает сохранять единообразные настройки.

  Вы можете импортировать навыки из других ИИ-ассистентов для программирования:

  ```bash theme={null}
  npx rulesync init
  npx rulesync import --targets claudecode --features skills
  npx rulesync generate --targets replit --features skills
  ```

  Так вы сможете вести единый набор навыков, который работает в разных средах разработки.
</Accordion>
