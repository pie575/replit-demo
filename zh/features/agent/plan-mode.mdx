Plan 模式为你带来与 Replit Agent 对话的全新方式，专注于提问、头脑风暴和规划工作。

<div id="what-is-plan-mode">
  ## 什么是 Plan 模式？
</div>

Plan 模式让你可以：

* **头脑风暴**，探索项目的不同实现思路
* **规划开发工作**，整理出结构化的任务清单
* **与 AI 协作**，共同规划项目架构与功能
* **获取策略性建议**，自由提问，且不会改动项目的代码或数据
* **无缝切换**到 Build 模式，随时开始实现

默认模式现在称为 **Build** 模式。

与 Build 模式不同，Plan 模式专注于规划与构思，帮助你在动手写代码之前把项目想清楚。

<div id="getting-started">
  ## 快速上手
</div>

<div id="accessing-plan-mode">
  ### 进入 Plan 模式
</div>

任何已启用 Agent 的 Replit App 都可以使用 Plan 模式。进入方式如下：

1. 在 Project Editor 中**打开你的 Replit App**
2. **找到模式选择器**，它位于聊天输入框的左下角
3. 在下拉菜单中**选择 Plan 模式**

<div id="key-features">
  ## 主要功能

<div id="task-planning">
  ### 任务规划
</div>

Plan 模式擅长将复杂的项目拆解为易于处理的任务。只需向 Agent 提出需求，它就会生成一份有序的任务列表，列出完成该需求所需的各项开发任务。

<div id="collaborative-brainstorming">
  ### 协作式头脑风暴
</div>

与 AI 一起探索不同的实现思路：

* 针对复杂问题的**多种解决路径**
* 不同方案的**利弊分析**
* **风险评估**与应对策略

<div id="workflow-from-planning-to-building">
  ## 工作流程：从规划到构建
</div>

<div id="1-planning-phase-plan-mode">
  ### 1. 规划阶段 (Plan 模式) 
</div>

在 Plan 模式下启动你的开发流程：

* **明确项目范围**和目标
* **拆解需求**，细化为具体功能
* **规划架构**和技术栈
* **制定开发路线图**并设置里程碑

<div id="2-task-approval">
  ### 2. 任务批准
</div>

当 Agent 生成任务列表时：

* **查看**建议的任务
* 选择 **开始构建** 以批准该计划

或者继续对话，进一步完善计划。

<div id="3-transition-to-build-mode">
  ### 3. 切换到 Build 模式
</div>

当你准备好开始实现时：

* **点击「开始构建」**以批准计划
* **Agent 自动切换**到 Build 模式
* **Agent 开始实现**已批准的任务
* 在开发阶段**跟踪进度**

Plan 模式与其他 Agent 交互一样，按投入程度计费。在 Plan 模式中，Agent 的所有工作都会计费，包括回答问题、提供指导以及生成任务列表。请求越复杂，或对话上下文越长，费用越高。

**所有 Agent 交互均需计费** —— 无论 Agent 是以文字提供指导，还是修改代码，都会产生费用，只是较小的请求费用更低。

<div id="best-practices">
  ## 最佳实践
</div>

<div id="effective-prompting">
  ### 高效提示
</div>

要充分发挥 Plan 模式的作用：

* **明确具体**地说明项目需求
* **追问细节**，厘清 AI 的建议
* 讨论复杂概念时，**要求给出示例**
* **比较不同方案的利弊**
* 在着手实现前，**反复打磨想法**
* 在后续对话中引用重要决策，从而**沉淀这些决策**
