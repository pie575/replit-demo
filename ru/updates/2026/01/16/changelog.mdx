export const YouTubeEmbed = ({videoId, title = "Видео на YouTube", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

  ### Мобильные приложения на Replit
</div>

<YouTubeEmbed videoId="YSeDWL4cDLs" title="Мобильные приложения на Replit" />

Создавайте нативные приложения для iOS по одному простому prompt. Agent создаёт полноценные приложения на React Native, а вы по ходу дела добавляете нужные возможности: базы данных, платежи Stripe или интеграции с OpenAI. Проверить приложение можно в Preview, отсканировав QR-код в Expo Go, а затем отправить его в App Store через пошаговый процесс Replit. Apple проверяет и распространяет приложения через App Store.

Готовы создать своё первое мобильное приложение? Загляните в раздел [Нативные мобильные приложения](/ru/features/artifact-types/building-mobile-apps), чтобы начать, или пройдите руководство [Создание и запуск мобильного приложения](/ru/tutorials/build-and-launch-a-mobile-app).

<div id="redesigned-tool-calls-ui-in-agent-chat">
  ### Обновлённый интерфейс вызовов инструментов в чате с Agent
</div>

В чате с Agent вызовы инструментов теперь отображаются в более аккуратном и компактном виде. Они сворачиваются в сгруппированные строки со стопкой значков, поэтому происходящее видно с первого взгляда. Изменение и создание файлов ведут прямо в панель различий — так их удобнее просматривать. Благодаря такому лаконичному дизайну следить за работой Agent проще: меньше лишнего, больше ясности.
