  ### Создавайте полностековые мобильные приложения с помощью Agent
</div>

<Frame>
  <img src="/assets/mirror/cleanshot-2025-12-05-at-12-27-22-2x_273f89390642-dc03158b7d7f.png" width="1082" height="504" data-path="images/changelog/2025-12-05/cleanshot-2025-12-05-at-12-27-22-2x_273f89390642.png" />

Теперь Agent может создавать [мобильные приложения](/ru/pt/replitai/building-mobile-apps) с полноценным бэкенд-сервером. Это открывает мощные возможности: [ИИ-интеграции](/ru/replitai/integrations), [базу данных](/ru/pt/features/data-and-storage/sql-database), [Object Storage](/ru/pt/features/data-and-storage/object-storage) и коннекторы — всё, что нужно для мобильной разработки уровня production.

<div id="banco-de-dados-agora-disponvel-para-todos">
  ### База данных теперь доступна всем
</div>

Новая [База данных](/ru/pt/features/data-and-storage/sql-database) теперь используется по умолчанию во всех новых Replit App. Это обновление повышает надёжность и уровень контроля над инфраструктурой, а также обеспечивает более высокую производительность и упрощает управление данными в ваших проектах.

<div id="o-fast-mode-lida-com-mais-tarefas-de-forma-autnoma">
  ### Fast Mode самостоятельно справляется с большим числом задач
</div>

<Frame>
  <img src="/assets/mirror/image_4f661377d428-8454460e1cca.png" width="720" height="212" data-path="images/changelog/2025-12-05/image_4f661377d428.png" />
</Frame>

[Lite mode](/ru/pt/core-concepts/agent/agent-modes) (ранее Fast Mode) теперь выполняет больше задач самостоятельно, а для более крупных изменений советует переключиться на Agent. Создавайте быстрее — за счёт мгновенных итераций и плавных переходов.

<div id="conecte-servios-de-terceiros-mais-rapidamente">
  ### Подключайте сторонние сервисы быстрее
</div>

Подключайте сторонние сервисы быстрее благодаря улучшенной поддержке коннекторов. Большинство сервисов с авторизацией по ключу API можно добавить, просто указав их конфигурацию, — сложная настройка не нужна. Кроме того, появились конфигурации с несколькими ключами и расширенные проверки работоспособности, что делает [интеграции](/ru/replitai/integrations) надёжнее.
