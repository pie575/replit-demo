通过模型选择器，你可以让 Replit 使用智能模型路由，也可以自行选择一个可用的模型。

<div id="roteamento-inteligente-de-modelos">
  ## 智能模型路由
</div>

智能模型路由会为每项任务选择合适的模型，在质量与成本之间取得平衡。当你在产品中看到 **Auto** 时，说明 Replit 正在进行智能模型路由。

智能模型路由会综合考量你所请求的任务内容及其复杂程度。目标明确的简单请求可能会使用成本更低的模型，而复杂任务则可能需要能力更强的模型。随着任务的变化，Replit 可能会切换到不同的模型。

<Note>
  Free Mode 始终使用智能模型路由。使用 Free
  Mode 的用户无法使用模型选择器，也无法手动选择模型。
</Note>

<div id="escolher-um-modelo-manualmente">
  ## 手动选择模型
</div>

Core 和 Pro 计划的用户可以在 Power Mode 或 Max Mode 下选择可用的模型。

1. 在 prompt 输入框中选择 **Agent Mode**。菜单中会列出可用模式：**Free**、**Power** 和 **Max**。
2. 选择 **Power** 或 **Max**，找到 **Primary model** 部分。
3. 打开主模型菜单，从列表中选择一个模型。

<Frame caption="模型选择器弹出框，包含 Lite、Economy 和 Power 模式以及 Primary model 列表。截图取自 Replit Design；同样的控件也出现在 Agent 设置下拉菜单中。">
  <img src="/assets/mirror/model-selector-6826a87089a2.png" alt="Agent 设置弹出框，显示 Lite、Economy 和 Power 模式、Primary model 列表以及 Effort 滑块" width="1432" height="786" data-path="images/design/replit-design/model-selector.png" />
</Frame>

所做的选择将应用于你的下一条消息，你可以随时更改。

<div id="effort">
  ## Effort
</div>

**Effort 是每个模型各自的控制项，而不是单独的模式。** 它决定所选模型在每次回复中投入多少推理，从 **Low** 到 **Max**。每个模型都会显示推荐设置，只有在任务确有需要时才需要调高。

<Frame caption="模型列表下方的 Effort 滑块，设置为 Medium。">
  <img src="/assets/mirror/model-selector-effort-bcffb01239a8.png" alt="Primary model 列表中已选择 Claude Fable 5，Effort 滑块设置为 Medium，描述为适用于日常任务的均衡推理" width="984" height="832" data-path="images/replitai/model-selector-effort.png" />
</Frame>

可参考以下各级别的说明：

| Effort         | 适用场景                                |
| -------------- | ----------------------------------- |
| **Low**        | 推理最少，响应最快。适用于常规、明确的改动，以速度优先的场景。     |
| **Medium**     | 适用于日常任务的均衡推理。若推荐设置没有另行说明，这是不错的默认选择。 |
| **High**       | 面向更复杂的工作进行更深入的推理，例如多步骤功能和不太熟悉的领域。   |
| **Extra High** | 面向最棘手的问题进行扩展推理，例如大规模重构和难缠的缺陷。       |
| **Max**        | 推理深度最大。成本最高、速度最慢，适用于只求最佳结果的场景。      |

在更高的 Effort 级别下，Agent 会进行更深入、更审慎的推理，并调用能力最强的前沿模型，从而在最复杂的任务上取得更好的结果。Agent 会有选择地运用这份额外算力——只有当请求确实困难时才转向能力更强的模型，而非每次运行都如此。

<Tip>
  由于 Agent 只在最困难的工作中才动用能力最强的模型，调高 Effort 在最艰巨的任务上最多会带来约 ~2 倍的成本增加，而在较简单的任务上往往几乎没有增加。处理复杂问题时不妨调高，常规改动则保持较低级别。
</Tip>

<div id="comparar-modelos">
  ## 对比模型
</div>

**Compare models** 会同时在多个模型上运行你的下一个 prompt，让你并排比较结果，而不用猜测哪个模型最合适。该功能目前处于 beta 阶段。

要启用它，请展开 Agent 模式弹窗底部的 **Advanced settings**，然后开启 **Compare models**。

<Note>模型对比仅支持 Chat。</Note>

<Frame caption="Advanced settings 中的 Compare models 选项。">
  <img src="/assets/mirror/compare-models-toggle-05429dc46d64.png" alt="展开的 Advanced settings，其中 Compare models Beta 选项处于关闭状态，说明为使用你的下一个 prompt 创建至多 4 个变体" width="1110" height="344" data-path="images/replitai/compare-models-toggle.png" />
</Frame>

启用该选项后，最多可添加 **4 个模型**参与对比。

<Frame caption="已选择四个模型进行对比，发送按钮显示 Compare 4。">
  <img src="/assets/mirror/compare-models-9f5bcecec727.png" alt="Agent 模式弹窗中已启用 Compare models，并有四个模型位置——Kimi K3、Claude Fable 5、Claude Opus 5 和 GPT-5.6 Sol——每个都可移除，聊天发送按钮显示 Compare 4" width="1192" height="1930" data-path="images/replitai/compare-models.png" />
</Frame>

随后，你的下一个 prompt 会针对每个选定的模型各运行一次，各自生成一个变体供你对比。

<Note>
  对比中的每个模型都会运行一个独立的 Agent 并消耗积分，因此一次 Compare 4 的开销大致相当于四次单独运行。
</Note>
