Контроль версий в Replit позволяет уверенно отслеживать изменения, управлять кодовой базой и совместно работать над ней. Благодаря встроенной интеграции с Git и подключению к GitHub вы можете:

* Отслеживать изменения кода и сохранять историю разработки
* Работать с участниками команды без конфликтов в коде и потери результатов работы
* Импортировать, изменять и отправлять код между Replit и GitHub
* Работать с ветками, чтобы безопасно экспериментировать с новыми функциями

<div id="what-is-version-control">
  ## Что такое контроль версий?
</div>

Контроль версий — это система, которая отслеживает изменения в файлах с течением времени и позволяет впоследствии возвращаться к определённым версиям. В Replit контроль версий реализован на базе Git — отраслевого стандарта для отслеживания изменений в коде — и дополнен удобным визуальным интерфейсом, поэтому вам не нужно знать командную строку.

<div id="how-version-control-works-on-replit">
  ### Как устроен контроль версий в Replit
</div>

Все четыре способа контроля версий работают с одним и тем же Git-репозиторием:

1. **Контрольные точки Agent** автоматически создают коммиты на важных этапах работы при создании приложений с помощью [Replit Agent](/ru/features/agent/overview). [Подробнее о контрольных точках и откатах](/ru/features/version-control/checkpoints-and-rollbacks).
2. **Git Pane** предоставляет визуальный доступ ко всему Git-репозиторию
3. **Git CLI** предоставляет доступ ко всем возможностям Git из командной строки
4. **История файлов** отслеживает детальные изменения в отдельных файлах

Выберите интерфейс, который лучше всего соответствует вашим потребностям: все они работают на базе надёжной системы контроля версий Git.

| Функция                    | Контрольные точки Agent          | Коммиты Git                         | История файлов                 |
| -------------------------- | -------------------------------- | ----------------------------------- | ------------------------------ |
| **Создание**               | Автоматически в ключевые моменты | Вручную или по расписанию           | Автоматически                  |
| **Детализация**            | Изменения на уровне функций      | Изменения любого масштаба           | Изменения на уровне символов   |
| **Описание**               | Сводки, созданные ИИ             | Сообщения, написанные пользователем | Автоматические временные метки |
| **Откат**                  | Восстановление одним нажатием    | Требует знания Git                  | Восстановление одним нажатием  |
| **Возможности Git**        | Все возможности Git              | Все возможности Git                 | Нет возможностей Git           |
| **Синхронизация с GitHub** | Полная синхронизация с GitHub    | Полная синхронизация с GitHub       | Нет синхронизации с GitHub     |

<div id="getting-started">
  ## Начало работы
</div>

Чтобы получить доступ к контролю версий в Replit App, добавьте инструмент Git в Project Editor:

1. Перейдите в раздел Tools в Replit App
2. Нажмите значок **+**, чтобы добавить новые инструменты
3. Выберите **Git** из списка доступных инструментов

Чтобы импортировать существующие проекты из GitHub, см. [Импорт из GitHub](/ru/build/import-from-providers).

<div id="automatic-version-control">
  ### Автоматический контроль версий
</div>

<Accordion title="История файлов">
  Автоматические снимки, создаваемые в ходе разработки с ИИ с помощью [Replit Agent](/ru/features/agent/overview).

  **Лучше всего подходит для**: разработки с Replit Agent

  **Основные возможности**:

  * Автоматическое создание на ключевых этапах
  * Откат в один клик
  * Снимки на уровне функций
  * Отслеживание прогресса
  * Не требует настройки
  * Визуальный таймлайн хода разработки

  Контрольные точки Agent хранятся в Git; доступ к ним можно получить через Git Pane или Git CLI. Вы также можете просматривать все контрольные точки с помощью функции History, которая позволяет:

  * Просматривать контрольные точки в хронологическом порядке
  * Читать подробные описания контрольных точек
  * Напрямую переходить к состояниям контрольных точек
  * Откатываться к любой контрольной точке в один клик
</Accordion>

<Accordion title="История файлов">
  Отслеживание версий каждого файла с автоматическим сохранением изменений, внесённых непосредственно в редакторе без участия Agent.

  **Лучше всего подходит для**: быстрого восстановления недавних изменений файла

  **Основные возможности**:

  * Работа с одним файлом
  * Изменения на уровне символов
  * Визуальное сравнение
  * История за 30 дней
  * Функция воспроизведения

  Хотя у истории файлов есть собственный интерфейс, лежащие в его основе изменения являются частью истории Git. Подробнее см. в разделе [история файлов](/ru/features/version-control/file-history).
</Accordion>

  ### Интерфейсы на основе Git
</div>

<Accordion title="Git Pane">
  Визуальный интерфейс для работы с Git, позволяющий использовать контроль версий без знания командной строки.

  **Лучше всего подходит для**: большинства проектов, требующих интеграции с GitHub и визуального рабочего процесса

  **Ключевые возможности**:

  * Отслеживание изменений во всём репозитории
  * Управление ветками
  * Визуальный просмотр различий
  * Синхронизация с GitHub в один клик
  * Командная работа

  Подробные инструкции по работе с Git Pane см. в разделе [Использование Git Pane](/ru/features/workspace-tools/git-interface).
</Accordion>

<Accordion title="Git CLI">
  Полный доступ к Git через командную строку в [Shell](/ru/features/workspace-tools/shell) для выполнения расширенных операций.

  **Лучше всего подходит для**: опытных пользователей, которым нужны все возможности Git

  **Ключевые возможности**:

  * Полный набор команд Git
  * Расширенные стратегии работы с ветками
  * Настраиваемые рабочие процессы
  * Автоматизация с помощью скриптов
  * Полный контроль над репозиторием

  Сведения о распространённых командах Git и их использовании см. в разделе [Использование Git Pane](/ru/features/workspace-tools/git-interface#using-git-commands-in-shell).
</Accordion>

<div id="key-features">
  ## Ключевые возможности
</div>

* **Визуальный интерфейс Git**: Управляйте репозиториями, коммитами и ветками без команд Git

<div id="use-cases">
  ## Примеры использования
</div>

**Отслеживание личных проектов**

Отслеживайте изменения в коде по мере разработки, чтобы при необходимости вернуться к предыдущим версиям. [Git Pane](/ru/features/workspace-tools/git-interface) наглядно показывает изменения, упрощая фиксацию важных обновлений.

**Совместная работа с командой**

Работайте с несколькими разработчиками над одной кодовой базой, не перезаписывая изменения друг друга. Создавайте ветки для новых функций, а затем объединяйте их, когда всё будет готово. Подробнее о [приглашении участников команды](/ru/build/invite-teammates).

<div id="agent-checkpoints">
  ## Контрольные точки Agent
</div>

При создании приложений с [Replit Agent](/ru/features/agent/overview) контрольные точки обеспечивают дополнительный уровень контроля версий. Они автоматически сохраняют полное состояние проекта, включая его содержимое, контекст диалога с ИИ и подключённые базы данных, в ключевые моменты разработки с помощью ИИ.

<div id="how-checkpoints-work">
  ### Как работают checkpoints
</div>

Контрольные точки Agent — это комплексные снимки всего состояния вашего Replit App:

* **Автоматическое создание**: Agent создаёт checkpoints на ключевых этапах разработки
* **Полное сохранение состояния**: Каждый checkpoint сохраняет содержимое проекта, память ИИ и состояние базы данных
* **Планы реализации**: Перед внесением изменений Agent предлагает вам ознакомиться с планом
* **Отслеживание сложных задач**: Для крупных задач может создаваться несколько checkpoints

<div id="benefits-for-ai-assisted-development">
  ### Преимущества разработки с ИИ
</div>

Контрольные точки Agent дают уникальные преимущества при разработке с ИИ:

* **Подстраховка**: Смело экспериментируйте, зная, что можно легко восстановить предыдущее состояние всей среды разработки
* **Отслеживание прогресса**: Просматривайте, как именно Agent шаг за шагом создавал ваше приложение
* **Логические этапы**: Контрольные точки соответствуют завершённым функциям, а не произвольным точкам сохранения
* **Мгновенный откат**: Возвращайтесь к любому предыдущему состоянию одним щелчком, включая восстановление базы данных и контекста ИИ

<Info>
  Подробнее о том, что сохраняют контрольные точки, и обо всех возможностях отката см. в разделе [Контрольные точки и откаты](/ru/features/version-control/checkpoints-and-rollbacks).
</Info>

<Tip>
  Хотя контрольные точки Agent удобны при разработке с ИИ, для долгосрочного отслеживания версий и совместной работы используйте коммиты Git, особенно при работе с внешними репозиториями.
</Tip>
