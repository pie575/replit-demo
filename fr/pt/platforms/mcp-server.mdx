Replit MCP utilise le [Model Context Protocol](https://modelcontextprotocol.io/) pour vous permettre de créer, rechercher, inspecter, mettre à jour et publier des projets Replit depuis les outils d’IA que vous utilisez déjà.

Cette page sert de référence pour les clients MCP directs et leurs outils.

<div id="conectar-um-cliente-mcp-diretamente">
  ## Connecter directement un client MCP
</div>

Utilisez une connexion directe si votre client MCP ne propose pas d’intégration native avec Replit.

| Propriété            | Valeur                                         |
| -------------------- | ---------------------------------------------- |
| **URL**              | `https://replit-mcp.com/server/mcp`            |
| **Transport**        | HTTP avec diffusion en continu                 |
| **Authentification** | OAuth avec découverte des ressources protégées |

Ajoutez l’URL du serveur à un client MCP prenant en charge HTTP avec diffusion en continu et l’autorisation OAuth. Le client lit les métadonnées des ressources protégées de Replit, puis vous invite à vous connecter à Replit.

Ne créez pas de serveur OAuth personnalisé. Le serveur MCP de Replit fournit les métadonnées OAuth dont votre client a besoin.

Vous pouvez créer des apps ou travailler sur des apps que vous pouvez modifier, y compris celles partagées avec vous.

<div id="configurar-o-replit-mcp">
  ### Configurer Replit MCP
</div>

Codex et Claude Code ne sont que des exemples. Vous pouvez ajouter Replit MCP à tout client MCP compatible.

<Tabs>
  <Tab title="Codex">
    <Steps>
      <Step title="Ouvrez la liste des MCP">
        Dans Codex, ouvrez **Paramètres** → **Plugins** → **MCP**.
      </Step>

      <Step title="Ajoutez Replit">
        Ajoutez un MCP personnalisé. Utilisez un nom descriptif, tel que `Replit`. Sélectionnez **Streamable HTTP**. Saisissez `https://replit-mcp.com/server/mcp`, puis enregistrez. N&#39;ajoutez ni jeton porteur ni en-têtes personnalisés.

        <Frame>

        </Frame>
      </Step>

      <Step title="Authentifiez Replit">
        Dans la liste des MCP, activez **Replit**, puis sélectionnez **Authenticate**. Choisissez le workspace Replit à connecter. Sélectionnez ensuite **Allow**.

        <Frame>
          <img src="/assets/mirror/codex-authenticate-replit-mcp-38e837424d0f.png" alt="Liste des MCP de Codex avec Replit activé et un bouton Authenticate" width="2000" height="1293" data-path="images/replitai/custom-mcp/codex-authenticate-replit-mcp.png" />

<div id="ferramentas">
  ## Outils
</div>

| Outil                     | Entrée obligatoire            | Entrée facultative                                        | Utilisation                                                                                                                                                                                                 |
| ------------------------- | ----------------------------- | --------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `create_app_from_prompt`  | `appDescription`, `app_stack` | `userSpecifiedAppName`, `userQuotes`, `attachmentSummary` | Crée une nouvelle App. `app_stack` peut prendre l’une des valeurs suivantes : `react_website`, `mobile_app`, `design`, `slides`, `animation`, `data_visualization`, `3d_game`, `document` ou `spreadsheet`. |
| `search_apps`             | Aucune                        | `query`, `url`, `updatedAfter`, `updatedBefore`, `limit`  | Recherche des Apps à l’aide de mots-clés dans le titre, l’URL ou la date de dernière mise à jour. `limit` est compris entre 1 et 50.                                                                        |
| `resolve_app_by_name`     | `name`                        | Aucune                                                    | Recherche une App par son titre exact.                                                                                                                                                                      |
| `list_apps`               | Aucune                        | `query`, `limit`                                          | Répertorie les Apps que vous pouvez modifier, classées par activité récente. La limite par défaut est de 25 et la valeur maximale est de 50.                                                                |
| `ask_question`            | `replId`, `question`          | Aucune                                                    | Pose une question à Agent au sujet d’une App sans la modifier.                                                                                                                                              |
| `update_app_using_prompt` | `replId`, `changeDescription` | `userQuotes`, `attachmentSummary`                         | Lance une mise à jour d’une App existante par Agent.                                                                                                                                                        |
| `publish_app`             | `replId`                      | Aucune                                                    | Publie une App ou republie vos dernières modifications.                                                                                                                                                     |
| `get_publish_status`      | `replId`                      | Aucune                                                    | Vérifie si une App est publiée, son état de publication actuel et son URL publique.                                                                                                                         |

<div id="soluo-de-problemas">
  ## Dépannage
</div>

| Problème                                                                        | Que faire                                                                                                                                   |
| ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| Replit vous demande de vous authentifier                                        | Reprenez le processus de connexion OAuth depuis votre client MCP.                                                                           |
| Une app est introuvable                                                         | Vérifiez que vous pouvez modifier l’app. Recherchez-la ensuite par URL ou utilisez `list_apps` pour choisir parmi les apps correspondantes. |
| Une demande de création, de mise à jour ou de publication est toujours en cours | Attendez avant de réessayer. Pour la publication, utilisez `get_publish_status` afin de vérifier l’état actuel.                             |
