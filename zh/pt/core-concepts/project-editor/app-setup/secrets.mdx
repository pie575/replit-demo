Secrets 工具会存储并加密 **secrets**，即 Replit App 中的敏感信息，例如 API 密钥、身份验证 token 和数据库连接字符串。

添加 secret 后，该工具会自动加密数据，并将其作为环境变量提供给 Replit App。
这样可以避免在代码中直接硬编码 secrets，并降低其暴露风险。

直接在代码中硬编码 secrets 可能会在以下情况下造成意外暴露：

* 通过公开的 Replit App 或复制粘贴方式与他人共享代码
* 将代码提交到公共仓库进行版本控制
* 直播或共享包含代码的屏幕

使用 Secrets 工具，您可以放心共享代码，无需担心暴露凭证。

<div id="funcionalidades">
  ## 功能
</div>

Secrets 工具提供以下功能：

* **端到端加密**：通过静态数据 AES-256 加密和传输中 TLS 加密，自动保护你的数据
* **App 级 Secrets**：存储和管理特定 Replit App 的 secrets
* **账户级 Secrets**：存储和管理可供你的所有 Replit Apps 使用的 secrets
* **通过环境变量访问**：在代码中通过环境变量访问 secrets
* **协作访问**：与协作者和团队成员共享 secrets

<div id="uso">
  ## 使用
</div>

<Note>
  除静态部署外，Secrets 适用于所有部署类型。
</Note>

您可以在 Project Editor 中访问 Secrets 工具。

<Accordion title="访问 Secrets">
  在左侧的**工具侧边栏**中：

  1. 选择 <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="所有工具图标" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**，查看 Project Editor 的工具列表。
  2. 选择 <img class="icon-svg" src="/assets/mirror/lock-af402c9618dd.svg" alt="Secrets 图标" width="16" height="16" data-path="images/icons/lock.svg" /> **Secrets**。

  使用**搜索栏**：

  1. 选择顶部的 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 放大镜图标，打开搜索工具。
  2. 输入“Secrets”查找该工具，然后从搜索结果中选择它。
</Accordion>

<div id="gerenciar-secrets-do-app">
  ### 管理 App Secrets
</div>

您可以在 **Secrets** 面板的 **App Secrets** 标签页中管理 App 级 Secrets。
该标签页会列出与您的 Replit App 关联的所有 Secrets。

<Accordion title="添加 App Secrets">
  添加 secret：

  1. 选择 **New Secret**。
  2. 输入 **Key** (secret 的名称) 和 **Value** (secret 的值) 。
  3. 选择 **Add Secret** 保存该条目。
</Accordion>

<Accordion title="编辑 App Secrets">
  编辑 secret：

  1. 选择 secret 旁边的垂直三点菜单 <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="垂直三点图标" height="16" width="16" data-path="images/icons/vertical-dots.svg" />。
  2. 在快捷菜单中选择 **Edit**。
  3. 更新 **Key** 或 **Value** 字段中的文本，然后选择 **Update Secret** 保存更改，或选择 **Cancel** 放弃更改。

  您也可以选择标签页底部的 **Edit as JSON** 或 **Edit as .env**，编辑完整的 App Secrets 列表。
</Accordion>

<Accordion title="查看 App Secrets">
  查看 secret 时，选择其旁边的眼睛图标 <img class="icon-svg" src="/assets/mirror/eye-8a6472b8a950.svg" alt="眼睛图标" width="16" height="16" data-path="images/icons/eye.svg" />。

  要隐藏 secret，请选择带斜杠的眼睛图标 <img class="icon-svg" src="/assets/mirror/eye-slash-6b4ded538179.svg" alt="带斜杠的眼睛图标" width="16" height="16" data-path="images/icons/eye-slash.svg" />。
</Accordion>

<Accordion title="删除 App Secrets">
  要删除 secret，请选择其旁边的垂直三点菜单 <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="垂直三点图标" height="16" width="16" data-path="images/icons/vertical-dots.svg" />，然后选择 **Delete**。
</Accordion>

<div id="gerenciar-secrets-da-conta">
  ### 管理账户 Secrets
</div>

您可以在 **Secrets** 面板的 **Account Secrets** 选项卡中管理账户级 Secrets。
此选项卡仅显示与您的 Replit 账户关联的 Secrets。

<Accordion title="添加账户 Secrets">
  如需添加账户级 Secret：

  1. 前往 **Account Secrets** 选项卡。
  2. 选择 <img class="icon-svg" src="/assets/mirror/settings-icon-c2664c3691bf.svg" alt="齿轮图标" width="16" height="16" data-path="images/icons/settings-icon.svg" /> 图标，打开 **Settings** 以管理账户级 Secrets。
  3. 选择 **New Secret**。
  4. 输入 **Key** (Secret 名称) 和 **Value** (Secret 值) 。
  5. 选择 **Save** 保存条目。
</Accordion>

<Accordion title="编辑账户 Secrets">
  如需编辑 Secret：

  1. 选择 Secret 旁边的 <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="铅笔图标" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> 铅笔图标。
  2. 修改 **Key** 或 **Value** 字段中的内容，然后选择 **Save** 保存更改，或选择 **Cancel** 放弃更改。
</Accordion>

<Accordion title="查看账户 Secrets">
  如需查看 Secret，请选择 Secret 旁边的 <img class="icon-svg" src="/assets/mirror/eye-8a6472b8a950.svg" alt="眼睛图标" width="16" height="16" data-path="images/icons/eye.svg" /> 眼睛图标。

  如需隐藏 Secret，请选择 Secret 旁边的 <img class="icon-svg" src="/assets/mirror/eye-slash-6b4ded538179.svg" alt="带斜杠的眼睛图标" width="16" height="16" data-path="images/icons/eye-slash.svg" /> 带斜杠的眼睛图标。
</Accordion>

<Accordion title="关联账户 Secrets">
  若要在 Replit App 中使用账户级 Secret，您必须先将其关联到该 App。
  如需关联账户级 Secret：

  1. 前往 **App Secrets** 选项卡。
  2. 选中 Secret 左侧的复选框。
  3. 选择 **Link to this App**。

  如需取消关联 Secret：

  1. 前往 **App Secrets** 选项卡。
  2. 选择 Secret 旁边的 <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" width="16" height="16" alt="竖向三点图标" data-path="images/icons/vertical-dots.svg" /> 竖向三点菜单。
  3. 选择 **Unlink**。
</Accordion>

<Accordion title="删除账户 Secrets">
  1. 选择 Secret 旁边的 <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="铅笔图标" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> 铅笔图标。
  2. 选择 **Delete**。
</Accordion>

<div id="gerenciar-a-visibilidade-dos-secrets">
  ### 管理 Secrets 的可见性
</div>

Secrets 的可见性取决于您对 Replit App 的访问权限，以及您是否是该 App 的作者。

您可以通过以下方式共享 Replit App：

* **Multiplayer**：邀请 Replit 用户实时协作
* **封面页**：展示 Replit App 的预览，并允许他人 Remix
* **Remix**：将个人或组织的 Replit App 公开，让其他人创建自己的版本

下表列出了不同情况下 Secrets 名称和值的可见性：

| 访问方式        | 用户                            | 可查看名称 | 可查看值 |
| ----------- | ----------------------------- | ----- | ---- |
| Multiplayer | Multiplayer 协作者               | ✓     | ✓    |
| Multiplayer | 组织成员 (所有者角色)                  | ✓     | ✓    |
| Multiplayer | 组织成员 (非所有者角色)                 | ✓     |      |
| 封面页         | 任何访客                          |       |      |
| Remix       | Remix 自己的 Replit App 的所有者/协作者 | ✓     | ✓    |
| Remix       | Remix Replit App 的非所有者/协作者    | ✓     |      |
| Remix       | 通过封面页 Remix 的任何人              | ✓     |      |
| 组织 Remix    | 拥有所有者角色的组织成员                  | ✓     | ✓    |
| 组织 Remix    | 没有所有者角色的组织成员                  | ✓     |      |

<Warning>
  没有所有者角色的组织成员无法查看 Replit App 中 Secrets 的值，但可以通过输出环境变量来获取这些值。
</Warning>

<div id="secrets-relacionados-ao-banco-de-dados">
  ## 数据库相关 Secrets
</div>

添加 Replit 数据库后，Project Editor 会自动创建以下 Secret：

| Secret         | 描述           |
| -------------- | ------------ |
| `DATABASE_URL` | SQL 数据库连接字符串 |

<Info>
  旧版 Neon 开发数据库还可能包含 `PGHOST`、`PGUSER`、`PGPASSWORD`、`PGDATABASE` 和 `PGPORT`。当前的 Replit 开发数据库则使用 `DATABASE_URL`。
</Info>

要查看 Replit App 中的所有环境变量，请在 Project Editor 的 Shell 工具中运行 `printenv`，或在代码中输出这些变量。

<div id="variveis-de-ambiente-predefinidas">
  ## 预定义环境变量
</div>

Replit 会自动设置以下环境变量，你可以在 App 中访问：

| 环境变量                | 描述                                 |
| ------------------- | ---------------------------------- |
| `REPLIT_DOMAINS`    | 与你的 Replit App 关联的所有域名，以逗号分隔       |
| `REPLIT_USER`       | 当前编辑者的用户名，在多人协作会话中可能会有所不同          |
| `REPLIT_DEPLOYMENT` | 如果代码在已部署应用中运行，则设为 `1`；否则不设置        |
| `REPLIT_DEV_DOMAIN` | `replit.dev` 域名上的开发 URL，与部署 URL 不同 |

这些变量不会显示在 Secrets 工具中，但你可以通过代码中的 `os.environ` 对象访问它们，或在 Shell 中运行 `printenv`。
