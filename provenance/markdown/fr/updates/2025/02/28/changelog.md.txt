## Plateforme

### Agent v2

<img src="https://mintcdn.com/replit/_awOuN-Ml26WVE62/images/changelog/2025-02-28/agent-web.webp?fit=max&auto=format&n=_awOuN-Ml26WVE62&q=85&s=6d71d22c536e00754ba0c3f8a949c6ef" alt="Agent v2" width="800" height="450" data-path="images/changelog/2025-02-28/agent-web.webp" />

Une nouvelle expérience Agent est désormais disponible pour tous les builders. Ce nouvel Agent est plus rapide, plus précis et plus capable que la version précédente.

Il est désormais alimenté par Claude 3.7 Sonnet, le modèle le plus avancé d'Anthropic à ce jour.

Vous pouvez l'essayer en rejoignant le programme Explorer. Retrouvez les instructions [ici](https://youtu.be/pE_XT2TaXCA).

### Améliorations des déploiements

Des suggestions d'IA apparaissent désormais pour les builders qui sélectionnent un déploiement statique pour des applications dynamiques, améliorant ainsi le comportement de l'Agent lors du traitement des demandes de déploiement.

<img src="https://mintcdn.com/replit/_awOuN-Ml26WVE62/images/changelog/2025-02-28/deployments-debugger-will-now---non-static-app-220824.png?fit=max&auto=format&n=_awOuN-Ml26WVE62&q=85&s=6fcc9e981f9edd8c79a497b06dd43dd0" alt="Améliorations du débogueur de déploiement" width="1604" height="1244" data-path="images/changelog/2025-02-28/deployments-debugger-will-now---non-static-app-220824.png" />

### Sortie de Claude 3.7 Sonnet

Le mode Assistant avancé a été mis à niveau avec Claude 3.7 Sonnet pour tous les builders payants. Cela se traduit par une précision et des capacités améliorées pour les demandes complexes.

<img src="https://mintcdn.com/replit/_awOuN-Ml26WVE62/images/changelog/2025-02-28/50526c4ea4d114b4cd8268425398dd4ed3c2d736_bc521d9780846c35d990a72459794dd81370515f_twitter.jpeg?fit=max&auto=format&n=_awOuN-Ml26WVE62&q=85&s=957fd62be704090db16ba82583a0bed9" alt="Interface Claude 3.7" width="1200" height="674" data-path="images/changelog/2025-02-28/50526c4ea4d114b4cd8268425398dd4ed3c2d736_bc521d9780846c35d990a72459794dd81370515f_twitter.jpeg" />

### Amélioration des performances de la base de données

Les opérations de base de données sont désormais plus rapides que jamais, avec l'opération la plus coûteuse réduite de 200 ms à moins de 1 ms.
