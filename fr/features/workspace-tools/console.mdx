La console vous permet de surveiller et de consulter en temps réel les log générés par votre Replit App en cours d&#39;exécution.
Vous pouvez utiliser les informations des exécutions en cours et précédentes pour comprendre le comportement de votre application,
résoudre les erreurs et optimiser ses performances.

<Tip>
  Lorsque vous déboguez avec Agent, incluez les log de la console dans votre prompt afin de fournir du contexte.
</Tip>

<div id="features">
  ## Fonctionnalités
</div>

Console propose les outils suivants pour vous aider à comprendre le comportement de votre app :

* **Journalisation en temps réel** : consultez la sortie de votre app en temps réel
* **Assistance par IA** : recevez des suggestions pour corriger les erreurs signalées dans les logs
* **Historique des exécutions** : affichez les logs des exécutions précédentes pour suivre les modifications

<div id="usage">
  ## Utilisation
</div>

Vous pouvez accéder directement à l’outil Console depuis votre Project Editor.

<Accordion title="Accéder à la Console">
  Dans le **dock d’outils** de gauche :

  1. Sélectionnez <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Icône Tous les outils" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **Tous les outils** pour afficher la liste des outils du Project Editor.
  2. Sélectionnez <img class="icon-svg" src="/assets/mirror/console-8a41ac90789c.svg" alt="Icône Console" width="16" height="16" data-path="images/icons/console.svg" /> **Console**.

  Dans la **barre de recherche** :

  1. Sélectionnez l’<img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="icône de loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> icône de loupe en haut pour ouvrir l’outil de recherche.
  2. Saisissez « Console », puis sélectionnez l’outil dans les résultats.
</Accordion>

Chaque fois que vous utilisez le bouton **Run** dans votre Replit App, Console affiche une nouvelle entrée contenant les informations suivantes :

* La commande qui a exécuté votre code
* L’horodatage
* Les logs de sortie standard et d’erreur

La capture d’écran suivante montre la commande `npm run dev` utilisée pour démarrer l’application et les messages de log générés lors de son exécution :

<div id="ai-powered-debugging">
  ### Débogage assisté par l’IA
</div>

Lorsque vous rencontrez des erreurs ou d’autres informations dans les logs que vous souhaitez comprendre, cliquez sur le
bouton **Ask AI** en haut de l’entrée. L’onglet **Agent** s’ouvre alors automatiquement et
le contenu du log est envoyé pour analyse.

<div id="log-entry-commands">
  ### Commandes des entrées de logs
</div>

La console propose les outils suivants pour gérer vos logs :

* **Afficher uniquement la dernière exécution** : activez cette option pour afficher uniquement l&#39;exécution la plus récente.
* **Réduire l&#39;entrée** : sélectionnez la flèche vers le bas <img class="icon-svg" src="/assets/mirror/down-arrow-9c1cf9fd152e.svg" alt="icône de flèche vers le bas" height="16" width="16" data-path="images/icons/down-arrow.svg" /> située à gauche du nom de la commande pour masquer les logs.
* **Effacer les exécutions précédentes** : sélectionnez cette option pour supprimer les logs des exécutions antérieures. Cette action est irréversible.

<div id="network-availability">
  ### Disponibilité du réseau
</div>

Vous pouvez contrôler la disponibilité en ligne de la version de développement de votre application.

Pour empêcher les requêtes vers l&#39;URL de développement, sélectionnez l&#39;<img class="icon-svg" src="/assets/mirror/network-off-5bdca8a4fe4e.svg" alt="icône réseau désactivé" height="16" width="16" data-path="images/icons/network-off.svg" /> icône de globe barré située à droite de la ligne d&#39;informations réseau.

Pour la réactiver, sélectionnez l&#39;<img class="icon-svg" src="/assets/mirror/network-on-15be2e5fb4f5.svg" alt="icône réseau activé" height="16" width="16" data-path="images/icons/network-on.svg" /> icône de globe.

Pour afficher votre URL de développement, sélectionnez le texte `{...}.replit.dev` dans la barre d&#39;adresse.

<Frame>
  <img src="/assets/mirror/preview-dev-url-b36770b33769.png" alt="Emplacement de l'URL de développement dans Preview" width="1222" height="824" data-path="images/workspace/preview-dev-url.png" />
</Frame>

<Note>
  Votre application reste accessible dans l&#39;outil Preview, même lorsqu&#39;elle est configurée pour ne plus répondre aux requêtes vers l&#39;URL de développement.
</Note>

<div id="stop-a-workflow-command">
  ### Arrêter une commande de workflow
</div>

Vous pouvez arrêter une commande de workflow en cours d’exécution depuis l’outil Console du Project Editor.

Sélectionnez le bouton carré à droite de la ligne contenant la commande d’exécution de votre Replit App pour y mettre fin.

Pour redémarrer votre app, utilisez le bouton de workflow **Run** en haut du Project Editor.
