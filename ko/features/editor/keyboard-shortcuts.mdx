키보드 단축키를 사용하면 설정 가능한 키 조합으로 명령을 실행하고, 텍스트를 수정하고,
Project Editor를 탐색할 수 있습니다. 키보드 단축키는 Replit.com 웹 앱에서
설정하고 사용할 수 있습니다.

<div id="viewing-keyboard-shortcuts">
  ## 키보드 단축키 확인하기
</div>

키보드 단축키 설정을 확인하려면 다음 단계를 따르세요.

1. Replit App을 열어 Project Editor로 이동합니다.
2. dock의 <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="all tools icon" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**에서 <img class="icon-svg" src="/assets/mirror/settings-icon-c2664c3691bf.svg" alt="gear icon" width="16" height="16" data-path="images/icons/settings-icon.svg" /> **User Settings** tab을 엽니다.
   또는 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="magnifying glass icon" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 돋보기로 &quot;User Settings&quot;를 검색해도 됩니다.
3. **Keyboard shortcuts** tab을 선택하면 명령 목록과 각 명령에 지정된 단축키를 확인할 수 있습니다.

<div id="customizing-keyboard-shortcuts">
  ## 키보드 단축키 사용자 지정
</div>

키보드 단축키를 추가하거나 수정하려면 다음 단계를 따르세요:

1. 할당되지 않은 명령 옆에 있는 <img class="icon-svg" src="/assets/mirror/create-app-icon-ba218e87fb67.svg" alt="plus icon" width="16" height="16" data-path="images/icons/create-app-icon.svg" />**단축키 추가**를 선택하거나, 이미 할당된 명령의 경우 <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="pencil icon" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> 연필 아이콘을 선택합니다.
2. 명령 옆에 &quot;Recording...&quot;이 표시되면 할당할 키 조합을 누릅니다.
   기록을 취소하려면 탭 내부의 빈 영역을 클릭하세요.
3. 단축키를 되돌리려면 <img class="icon-svg" src="/assets/mirror/rollback-icon-3197ed1b323b.svg" alt="rollback icon" width="12" height="12" data-path="images/icons/rollback-icon.svg" /> 롤백 아이콘을 선택하세요.

<div id="removing-keyboard-shortcuts">
  ## 키보드 단축키 제거
</div>

키보드 단축키를 제거하려면 해당 명령 옆의 <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="휴지통 아이콘" width="16" height="16" data-path="images/icons/trash-icon.svg" /> 휴지통 아이콘을 선택하세요.

<div id="tab-navigation">
  ## Tab 키 탐색
</div>

브라우저의 **Tab** 키 탐색을 사용해 페이지의 인터랙티브 요소 사이를 이동할 수 있습니다. 다만 File Editor, Console, Shell 도구에서는 들여쓰기 등의 용도로 **Tab** 키를 입력으로 처리합니다.

이러한 도구를 사용하는 중에도 페이지 요소를 계속 순환하며 이동하려면 다음 단계를 따르세요.

1. **Esc**를 눌러 도구에서 포커스를 해제합니다
2. **Tab**을 눌러 다음 요소로 이동합니다
