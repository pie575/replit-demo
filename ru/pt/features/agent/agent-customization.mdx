title: "Персонализация Agent"
description: "Расскажите Agent о принятых в вашей команде соглашениях с помощью пользовательских инструкций и навыков для всего workspace, которые централизованно管理 в настройках Workspace."
---

Персонализация Agent даёт Agent контекст, необходимый для того, чтобы работать так, как работаете вы и ваша команда, — начиная с самого первого prompt. Вместо того чтобы заново объяснять свои соглашения в каждом проекте, вы задаёте их один раз для своего workspace, и Agent применяет их везде.

Она состоит из двух частей:

* **Пользовательские инструкции** — всегда активные правила, которые применяются к каждому проекту в вашем workspace.
* **Навыки** — переиспользуемые инструкции, которые Agent загружает только тогда, когда возникает подходящая задача.

Управлять и тем, и другим можно в разделе **Настройки Workspace → Персонализация**.

<div id="instrues-personalizadas-vs-skills">
  ## Пользовательские инструкции и навыки
</div>

Пользовательские инструкции загружаются с каждым сообщением, а навыки — только тогда, когда Agent сочтёт их относящимися к задаче. Используйте пользовательские инструкции для тех немногих правил, которые верны всегда, а навыки — для конкретных рабочих процессов, соглашений и справочных материалов.

О том, почему сделано именно такое разделение, — бюджет контекста, что и куда попадает и как создавать подходящие навыки — читайте в разделе [Навыки Agent](/ru/pt/learn/agent-skills). О том, как устроены навыки и как Agent их загружает, см. [Навыки Agent](/ru/pt/features/agent/skills).

<div id="instrues-personalizadas">
  ## Пользовательские инструкции
</div>

Пользовательские инструкции — это постоянно действующие указания, которые добавляются в контекст Agent в каждом проекте и в каждой сессии ещё до того, как кто-либо введёт prompt. Достаточно описать их один раз в настройках Workspace, и Agent будет применять их во всём вашем workspace. Лучше всего они подходят для указаний, которые верны всегда: требований к безопасности и соответствию нормам, списка одобренных библиотек и фреймворков или политик обработки данных.

Пишите кратко. Чёткую и конкретную инструкцию с большей вероятностью выполнят в точности, к тому же она оставляет больше места для той работы, которой Agent занимается на самом деле.

<Warning>
  Пользовательские инструкции могут влиять на производительность Agent. Agent настроен на их соблюдение, однако выполнение строгих требований не гарантируется. Более короткие и конкретные указания соблюдаются надёжнее.
</Warning>

<Note>
  Пользовательские инструкции workspace — это не то же самое, что файл `custom_instruction/instructions.md` в проекте. Пользовательская инструкция workspace задаётся один раз в настройках Workspace и применяется ко всем проектам. Файл уровня проекта действует только внутри одного проекта — об этом подходе см. [Создание пользовательской дизайн-системы](/ru/pt/teams/custom-design-system).
</Note>

<div id="skills">
  ## Навыки
</div>

Навык — это многократно используемый набор инструкций, который Agent подгружает только тогда, когда появляется подходящая задача. Навыки workspace отображаются в верхней части меню **+** в каждом проекте вашего workspace, поэтому вся команда работает с одним и тем же набором.

Создать навык можно тремя способами:

* **Загрузить** готовую папку с навыком.
* **Написать** новый навык прямо в форме.
* **Попросить Agent** составить черновик навыка, а затем доработать его.

<Note>
  Навыки, подготовленные Agent, можно загрузить в ваш Workspace. Попросите Agent скачать навык — он упакует его в файл `.zip` и покажет кнопку **Скачать файл** (см. ниже). Скачайте архив, а затем загрузите его обратно в разделе **Настройки Workspace → Персонализация → Навыки** через **Создать навык → Выбрать файл или папку**, чтобы он стал доступен всему вашему workspace.
</Note>

<Frame>
  <img src="/assets/mirror/agent-customization-download-skill-3727b188c5a8.png" alt="Agent упаковал навык workspace в файл ux-designer-skill.zip для скачивания, с кнопкой «Скачать файл»" width="1716" height="864" data-path="images/replitai/agent-customization-download-skill.png" />
</Frame>

Полная структура навыков (`SKILL.md`, вспомогательные файлы, открытый стандарт) описана в разделе [Навыки Agent](/ru/pt/features/agent/skills). Навыки, уже созданные Replit и нашими партнёрами, собраны в [Каталоге навыков](/ru/pt/features/agent/skills-directory).

<Note>
  Используйте навыки умеренно. Agent читает название и описание каждого навыка в каждой задаче, и когда навыков слишком много (или они пересекаются), его внимание рассеивается и выбрать нужный становится сложнее. Задавайте каждому навыку узкую область применения и удаляйте те, что больше не нужны.
</Note>

<div id="disponibilidade-e-permisses">
  ## Доступность и разрешения
</div>

| Функция                     | Доступно в        | Кто может управлять                                              |
| --------------------------- | ----------------- | ---------------------------------------------------------------- |
| Пользовательские инструкции | Pro и Enterprise  | Enterprise: администраторы. Pro: любой участник workspace        |
| Навыки                      | Все платные планы | Enterprise: администраторы. Core и Pro: любой участник workspace |

В workspace Enterprise создавать, редактировать и удалять пользовательские инструкции и навыки могут только администраторы. В workspace Pro это доступно любому участнику. В workspace Core любой участник может управлять навыками, но пользовательские инструкции в Core недоступны. В любом случае использовать созданные навыки может каждый участник workspace.

<div id="criar-uma-instruo-personalizada">
  ## Создание персонализированной инструкции
</div>

<Steps>
  <Step title="Откройте настройки workspace">
    Перейдите в раздел **Настройки workspace → Персонализация**.

    <Frame>
      <img src="/assets/mirror/agent-customization-tab-930af2e8ed74.png" alt="Вкладка «Персонализация» в настройках workspace с подвкладками «Навыки» и «Пользовательские инструкции»" width="1065" height="394" data-path="images/replitai/agent-customization-tab.png" />
    </Frame>
  </Step>

  <Step title="Напишите инструкцию">
    В разделе **Пользовательские инструкции** укажите правила, которым Agent должен следовать в каждом проекте.
  </Step>

  <Step title="Сохраните">
    Сохраните изменения. Инструкция будет применяться к новым проектам в вашем workspace.
  </Step>
</Steps>

<div id="criar-uma-skill">
  ## Создание навыка
</div>

<Steps>
  <Step title="Откройте настройки workspace">
    Перейдите в **Настройки workspace → Персонализация**.
  </Step>

  <Step title="Создайте навык">
    В разделе **Навыки** нажмите **Создать навык**, а затем загрузите папку с навыком, напишите инструкции или попросите Agent составить черновик.

    <Frame>
      <img src="/assets/mirror/agent-customization-create-skill-fcb794e6de4e.png" alt="Вкладка «Персонализация» в настройках workspace с подвкладками «Навыки» и «Пользовательские инструкции» и открытой формой создания навыка" width="2168" height="1350" data-path="images/replitai/agent-customization-create-skill.png" />
    </Frame>
  </Step>

  <Step title="Напишите понятное описание">
    Составьте для навыка точное описание, которое поясняет, когда его использовать, а когда — нет. Именно его читает Agent, чтобы понять, подходит ли навык.
  </Step>

  <Step title="Сохраните">
    Сохраните навык. Он появится в меню **+** каждого проекта в вашем workspace.
  </Step>
</Steps>

<div id="usar-uma-skill-de-workspace-em-um-projeto">
  ## Использование навыка workspace в проекте
</div>

Хорошее описание навыка очень важно. Agent читает описание каждого навыка workspace и загружает его автоматически, когда ваш prompt примерно соответствует назначению навыка, поэтому выбирать навык вручную нужно не всегда. При желании навык можно указать явно — чтобы наверняка гарантировать его применение.

Чтобы выбрать навык вручную:

<Steps>
  <Step title="Откройте окно выбора навыков">
    В проекте нажмите кнопку **+** рядом с полем ввода чата. Ваши навыки workspace отображаются вверху отдельной группой.

    <Frame>
      <img src="/assets/mirror/agent-customization-skill-picker-4643f3a453c7.png" alt="Окно выбора навыков, открытое кнопкой +, с группой навыков workspace вверху над навыками Replit" width="1668" height="1170" data-path="images/replitai/agent-customization-skill-picker.png" />
    </Frame>
  </Step>

  <Step title="Выберите навык">
    Выберите навык, который хотите активировать. Также можно ввести `/` и имя навыка, чтобы вызвать его напрямую.
  </Step>

  <Step title="Продолжайте работу с промптами">
    Продолжайте как обычно. Agent применяет навык, когда задача соответствует его описанию.
  </Step>
</Steps>

<div id="gerenciar-instrues-e-skills">
  ## Управление инструкциями и навыками
</div>

Всё управление выполняется в разделе **Настройки Workspace → Персонализация**. Там вы можете изменить пользовательскую инструкцию, а также отредактировать, отключить или удалить любой навык. Изменения применяются к новым чатам и не затрагивают уже начатые.
