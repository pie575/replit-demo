Les solutions de stockage flexibles de Replit vous permettent d&#39;ajouter rapidement le stockage de données le mieux adapté à votre application. Vous pouvez utiliser les bases de données et le stockage d&#39;objets de Replit pour les applications répondant aux besoins suivants, et Agent peut configurer et intégrer automatiquement ces deux solutions :

* Les jeux qui doivent enregistrer des informations telles que la progression des joueurs ou les meilleurs scores
* Les plateformes de contenu qui gèrent des fichiers multimédias

<div id="replit">
  ## Options de stockage et de base de données de Replit
</div>

Replit propose les options de stockage de données suivantes :

* **Bases de données** : stockez des données structurées telles que des profils utilisateur, des scores de jeu ou des catalogues de produits.
  Vous pouvez enregistrer et récupérer des données selon leurs attributs et les relations entre les points de données.

* **App Storage** : stockez des données non structurées telles que des images, des vidéos ou des documents.
  Vous pouvez enregistrer et récupérer des fichiers volumineux ainsi que des données binaires.

<div id="app-storage">
  ### Comparaison entre App Storage et les bases de données
</div>

|                             | Base de données                                                             | App Storage                                                                |
| --------------------------- | :-------------------------------------------------------------------------- | :------------------------------------------------------------------------- |
| **Format de données idéal** | Données structurées avec relations                                          | Fichiers volumineux (images, vidéos, documents)                            |
| **Modèle de données**       | Tables, lignes, colonnes                                                    | Buckets, fichiers                                                          |
| **Langage de requête**      | SQL                                                                         | API REST                                                                   |
| **Clients**                 | Clients compatibles PostgreSQL et ORM                                       | SDK Replit et bibliothèques clientes GCS                                   |
| **Modèle de facturation**   | Paiement à l&#39;usage selon le temps de calcul et l&#39;espace de stockage | Paiement à l&#39;usage selon la bande passante et l&#39;espace de stockage |

<div id="section">
  ### Outils de l&#39;éditeur de projet
</div>

Découvrez en détail les outils Replit suivants, qui permettent de configurer et de gérer le stockage des données de votre app :

<CardGroup>
  <Card title="Base de données" href="/fr/features/data-and-storage/sql-database" icon="database">
    Idéale pour les données structurées et la représentation des relations entre les données.

  <Card title="App Storage" href="/fr/features/data-and-storage/object-storage" icon="bucket">

  </Card>
