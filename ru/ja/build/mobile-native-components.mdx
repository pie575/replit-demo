<div id="section">
  ## Почему это важно
</div>

В каждом iPhone уже есть предупреждения, листы общего доступа, переключатели и меню, и пользователи
применяют их во всех других App. Если ваше App использует те же нативные компоненты,
пользователи ещё до нажатия знают, как они работают. Поэтому оно воспринимается как настоящее приложение для iPhone.

Ниже приведены примеры промптов для нативных компонентов, которые можно добавить в App: предупреждения, меню действий,
переключатели и другие.

<div id="section-2">
  ## Нативные предупреждения
</div>

<AiPrompt>
  {nativeAlertPrompt}
</AiPrompt>

Отображает настоящее предупреждение `UIAlertController` в том же стиле, что и системные всплывающие окна iOS.
Используйте предупреждения, когда пользователю нужно принять одно чёткое решение.

  ## Нативное меню действий
</div>

<AiPrompt>
  {nativeActionSheetPrompt}
</AiPrompt>

Меню действий похоже на предупреждение, но используется, когда вместо одного решения «да/нет» нужно выбрать один из нескольких понятных
вариантов. В Android есть собственный нативный аналог, и Agent автоматически выбирает
подходящий вариант для каждой платформы.

<div id="sf-symbols">
  ## SF Symbols
</div>

<AiPrompt>
  {sfSymbolsPrompt}
</AiPrompt>

SF Symbols — встроенный набор иконок Apple. Символы автоматически подстраиваются под размер и начертание окружающего текста, а также под тёмный режим. При использовании пользовательских наборов иконок всё это пришлось бы настраивать вручную.

<Frame caption="SF Symbols, используемые для иконок звуковых эффектов и вибрации в Settings.">
  <img src="/assets/mirror/native-sf-46d879d1c2c1.png" alt="Иконки SF Symbols рядом с настройками Sound effects и Vibration" data-path="images/pixelgames/mobile/native-sf.png" width="1516" height="310" data-path="images/pixelgames/mobile/native-sf.png" />

<Note>
  SF Symbols доступны только для iOS. Для Android попросите Agent выбрать подходящий набор иконок.
  Иконки на разных платформах не будут совпадать до пикселя — и это нормально.
</Note>

<div id="section-6">
  ## Устранение неполадок
</div>

* **Вместо предупреждений или меню действий отображаются пользовательские модальные окна:** Убедитесь, что Agent использует
  нативные API, а не визуально похожие имитации, отрисованные с помощью JS. Они могут выглядеть одинаково, но работают по-разному.
* **На Android иконки выглядят странно:** Для SF Symbols это нормально, поскольку они предназначены только для iOS. Уточните у Agent,
  какой набор иконок он использовал в качестве резервного.
* **В листе общего доступа отсутствует нужное приложение:** Это определяется ОС и приложениями, установленными на тестовом устройстве;
  PixelGames не может добавлять их напрямую.
