Le contrôle des modèles Enterprise permet aux administrateurs de compte de gérer les modèles Agent que les créateurs peuvent sélectionner. Définissez des politiques pour votre compte, puis configurez des accès aux modèles différents pour chaque espace de travail.

<Note>
  Le contrôle des modèles est réservé aux administrateurs de compte des comptes Enterprise. Pour utiliser cette fonctionnalité dans votre organisation, contactez l’équipe commerciale ([sales@replit.com](mailto:sales@replit.com)).
</Note>

<div id="section">
  ## Utiliser le routage intelligent des modèles
</div>

Le routage intelligent des modèles est l’environnement Agent par défaut des espaces de travail Enterprise. Lorsque le **mode Auto** est activé, Replit choisit le mode et le modèle les mieux adaptés à chaque tâche, en équilibrant qualité et coût.

Le routage s’effectue parmi le pool de modèles approuvés par les politiques des comptes et des espaces de travail. Les fournisseurs et les modèles qui ne font pas partie de ce pool ne peuvent pas être sélectionnés. Les créateurs peuvent laisser le **mode Auto** activé ou le désactiver pour sélectionner directement un modèle approuvé.

<div id="agent">
  ## Ouvrir les paramètres des modèles Agent
</div>

1. Ouvrez **Paramètres**.
2. Dans **Compte**, sélectionnez **Avancé**.
3. Développez **Modes Agent et fournisseurs de modèles**.

<Frame caption="Politiques relatives aux fournisseurs de modèles et contrôle distinct des Fast mode models dans les paramètres avancés.">

<div id="section-2">
  ## Configurer les politiques des fournisseurs
</div>

<Steps>
  <Step>
    Sélectionnez le fournisseur de modèles à gérer.
  </Step>

  <Step>
    Dans **Account policy**, sélectionnez l’une des options suivantes :

    | Option              | Résultat                                                                                   |
    | ------------------- | ------------------------------------------------------------------------------------------ |
    | **Enable all**      | Tous les modèles de ce fournisseur peuvent être utilisés dans tous les espaces de travail. |
    | **Enable selected** | Sélectionnez manuellement les modèles disponibles pour chaque espace de travail.           |
    | **Disabled**        | Aucun espace de travail ne peut utiliser les modèles de ce fournisseur.                    |

    <Note>
      Au moins un modèle d’OpenAI, d’Anthropic ou de Google doit rester activé. Vous pouvez désactiver les autres fournisseurs.
    </Note>
  </Step>

  <Step>
    Sélectionnez **Update**.
  </Step>
</Steps>

Les fournisseurs de modèles open source sont désactivés par défaut. Pour les activer, sélectionnez **Enable all** ou **Enable selected**, puis **Update**.

<div id="section-3">
  ## Configurer les règles de l’espace de travail
</div>

Utilisez **Enable selected** lorsque les espaces de travail nécessitent des accès aux modèles différents.

<Frame caption="Politique des fournisseurs Anthropic définie sur Enable selected et accès aux modèles configuré pour chaque espace de travail.">
  <img src="/assets/mirror/anthropic-account-policy-workspace-models-38c0f71a609d.jpg" alt="Règle de compte Anthropic définie sur Enable selected et boutons d’activation des modèles de l’espace de travail" width="2000" height="930" data-path="images/workspace/anthropic-account-policy-workspace-models.jpg" />
</Frame>

1. Ouvrez les paramètres du fournisseur.
2. Définissez **Account policy** sur **Enable selected**.
3. Dans la liste **Workspace**, sélectionnez le menu déroulant **Setting** de l’espace de travail concerné.
4. Activez ou désactivez chaque modèle dans cet espace de travail.
5. Sélectionnez **Update**.

Avant de sélectionner **Update**, vous pouvez sélectionner **Copy to all** pour appliquer la sélection de modèles de l’espace de travail actuel à tous les espaces de travail du compte.

<div id="section-4">
  ## Limites
</div>

* Les politiques relatives aux modèles s’appliquent à l’échelle de l’espace de travail. Il n’est pas possible de définir des politiques différentes pour chaque groupe d’utilisateurs au sein d’un même espace de travail.
* Le routage intelligent des modèles ne remplace pas les politiques du compte ou de l’espace de travail. Les fournisseurs ou modèles désactivés ne peuvent pas être sélectionnés.
* Le bouton bascule **Fast mode models** dans **Agent modes and model providers** contrôle l’accès aux variantes de modèles rapides dans tous les espaces de travail du compte. Les politiques des fournisseurs et le routage intelligent des modèles ne modifient pas ce paramètre.
