<div id="o-agent-agora-suporta-servidores-mcp-personalizados">
  ### Agent теперь поддерживает пользовательские MCP-серверы
</div>

Agent теперь может подключаться к удалённым серверам Model Context Protocol (MCP), получая доступ к новым возможностям и инструментам с минимальной настройкой. Это позволяет Agent вызывать внешние инструменты и получать контекст из удалённых систем.

С пользовательскими MCP-серверами вы можете:

* Подключаться к удалённым серверам, которые получают контекст и выполняют действия во внешних инструментах
* Получать доступ к сотням инструментов и источников данных через открытый стандарт MCP
* Автоматически загружать инструменты, доступные на каждом сервере

Партнёры могут интегрировать свои сервисы с Agent, предоставив сервер MCP, — дополнительная интеграция не требуется.

<div id="conector-plaid-para-enterprise">
  ### Коннектор Plaid для Enterprise
</div>

Клиенты Enterprise теперь могут включить коннектор Plaid для подключения банковских счетов и создания приложений с финтех-примитивами. Этот коннектор находится в активной разработке: новые возможности и улучшения добавляются на основе отзывов клиентов.

С коннектором Plaid вы можете:

* Подключать банковские счета к своим приложениям
* Использовать финтех-примитивы для создания финансовых функций
* Централизованно управлять коннекторами через панель администрирования
