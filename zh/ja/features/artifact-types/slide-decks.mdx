<div id="section">
  ## 什么是幻灯片？
</div>

借助幻灯片，您只需与 Agent 对话，即可创建精致、专业的演示文稿。只需描述您想制作的内容，即可立即生成完整美观的演示文稿；之后，您可以通过聊天、直接编辑，或在[Design Canvas](/zh/ja/design/canvas)中探索不同版本并加以完善。

幻灯片底层由 React 构建。因此，您可以将其导出为像素级还原且完全可编辑的 PPTX、Google Slides 或 PDF 文件。还可以将演示文稿部署为可共享的在线 URL。

核心概念：

* **一次生成**：描述您想要的演示文稿，Agent 会创建包含布局、文本和视觉元素的完整演示文稿
* **基于 React**：幻灯片并非静态图片，而是真正的 React 组件，因此可以无损导出为各种格式
* **随处导出**：下载为 PPTX、Google Slides 或 PDF，像素级还原且完全可编辑
* **可部署**：您可以将演示文稿发布为在线 URL，任何人都能在浏览器中查看或演示

<div id="section-2">
  ## 如何使用幻灯片演示文稿
</div>

<div id="section-3">
  ### 创建幻灯片演示文稿
</div>

你可以通过两种方式在 Replit 主页创建幻灯片演示文稿：

* **输入提示词**：描述你想创建的演示文稿。Agent 会识别与演示文稿相关的提示词，并自动选择幻灯片演示文稿技术栈。
* **从下拉菜单中选择**：打开应用类型下拉菜单，选择**幻灯片**，然后描述你的演示文稿。

**提示词示例：**

* “创建一份关于 AI 健身应用的推介演示文稿”
* “创建一份面向 A 轮投资者的 10 页演示文稿”
* “构建一份用于团队异地活动的产品概览演示文稿”

<Tip>
  一开始就指定长度和视觉风格，Agent 就能直接构建演示文稿，无需进一步确认。例如，试试“创建一份关于远程工作的 8 页极简演示文稿”。
</Tip>

<div id="section-4">
  ### 从品牌指南或参考文件开始
</div>

你可以让 Agent 赢在起跑线上：

* **品牌指南**：上传品牌指南后，Agent 会在所有幻灯片中统一配色、字体和视觉风格。
* **参考文件**：上传已有的演示文稿或文档作为起点。Agent 会以此为基础继续构建。

<div id="section-5">
  ### 改进幻灯片
</div>

Agent 生成初始版本后，你可以通过对话不断完善：

* **调整内容**：&quot;把问题这页写得更简洁&quot;或&quot;在市场规模部分后面加一页竞争格局&quot;
* **更改样式**：&quot;改成带蓝色点缀的深色主题&quot;或&quot;把字体换得更大、更简洁&quot;
* **添加或删除幻灯片**：&quot;关于路线图再加两页&quot;或&quot;删掉最后一页&quot;
* **添加视觉元素**：&quot;加一张展示预期增长的图表&quot;或&quot;给第 4 页的每个功能加上图标&quot;
* **重新排序或重组**：&quot;把团队这页移到最后&quot;或&quot;把功能页拆成两页&quot;

每次改进后，幻灯片都会在预览面板中自动渲染，你可以立即看到修改效果。

<div id="section-6">
  ### 直接编辑幻灯片
</div>

你也可以不通过聊天，直接动手编辑：

* **[Visual Editor](/zh/ja/design/visual-editor)**：点击任意元素，直接调整文本、颜色、间距和布局 —— 不消耗 AI 积分。
* **复制或删除**：右键点击任意幻灯片，即可复制或删除。

<Note>
  暂不支持在幻灯片内拖放元素。如需移动或重新排列元素，请在聊天中让 Agent 处理。
</Note>

<div id="canvas">
  ### 使用设计 Canvas 制作变体
</div>

你可以使用[设计 Canvas](/zh/ja/design/canvas)为单张幻灯片或某个版块探索备选设计，然后把满意的版本放回主幻灯片组。如果想先对比多个视觉方向再做决定，这个功能会很有用。

<div id="section-7">
  ### 演示与部署
</div>

幻灯片准备就绪后：

* **演示模式**：进入全屏演示模式，直接在预览窗格中进行演示。这与部署后观众看到的视图完全一致。
* **移动端支持**：幻灯片可在移动设备上正常显示，观众在任何屏幕上都能查看。
* **发布**：将幻灯片部署为可实时分享的 URL。任何拥有该链接的人都可以在浏览器中查看或演示这套幻灯片。

<div id="section-8">
  ### 导出
</div>

下载幻灯片，以便在 Replit 外使用：

* **PowerPoint**：在 PowerPoint 或 Keynote 中打开并编辑 `.pptx` 文件。背景、文本和图形均能完整保留。
* **Google Slides**：直接在 Google Slides 中打开演示文稿。导出完成后，选择**前往 Google Slides**，即可一键打开。
* **PDF**：分享静态的打印就绪版本。即使是包含大量照片的演示文稿，也会以较小的文件大小导出，可轻松通过电子邮件发送。

你也可以导入现有演示文稿。导入 `.pptx` 文件时，背景、文本和图形均能完整保留。

<div id="section-9">
  ### 查找幻灯片演示文稿
</div>

幻灯片演示文稿会与其他应用一起显示在项目列表中。在项目页面打开**构建类型**下拉菜单并选择**幻灯片**，即可仅显示包含幻灯片演示文稿构件的项目。

<div id="section-11">
  ## 常见问题
</div>

<Accordion title="可以在幻灯片中拖放元素吗？">
  暂时还不行。如需移动或重新排列幻灯片中的元素，请在聊天中告诉 Agent。你可以使用 Visual Editor 直接编辑文本、颜色和间距。
</Accordion>

<Accordion title="支持哪些导出格式？">
  你可以导出为 PPTX、Google Slides 或 PDF。所有导出结果均为像素级还原，且完全可编辑。
</Accordion>

<Accordion title="可以使用品牌规范吗？">
  可以。创建演示文稿时上传品牌规范，Agent 会在所有幻灯片中统一应用相应的颜色、字体和视觉风格。
</Accordion>

<Accordion title="幻灯片在移动端能正常显示吗？">
  可以。幻灯片会在移动设备上正常渲染，观众可以在任意屏幕上查看已部署或已共享的演示文稿。
</Accordion>

<Accordion title="可以将幻灯片部署为在线链接吗？">
  可以。发布演示文稿后会生成一个可共享的在线链接，任何人都可以在浏览器中查看或演示。
</Accordion>
