<div id="security-scan-while-you-build">
  ### 构建过程中的安全扫描
</div>

Agent 现在会在代码审查过程中检查其修改的文件是否存在常见安全问题。自动运行的 Semgrep 扫描会查找高风险模式和硬编码的 Secrets，以便 Agent 在完成 task 前处理可能发现的问题。

了解有关[构建过程中的安全扫描](/zh/features/security/project-security-center#security-scan-while-you-build)的更多信息。

<div id="regenerate-production-database-credentials">
  ### 重新生成生产数据库凭据
</div>

现在，你可以通过 **数据库** 工具为符合条件的生产数据库重新生成凭据。Replit 会更新凭据；如果你的应用有正在运行且受支持的 deployment，Replit 会启动重新部署，使其继续使用新凭据。请更新所有使用旧连接字符串的外部工具。

<div id="build-with-sso">
  ### 使用 SSO 进行 Build
</div>

Pro 构建者现在可以为使用 [Clerk Auth](/zh/features/auth-and-identity/clerk-auth) 的 Replit App 配置企业版 SSO。向 Agent 说明所需的身份验证变更，Agent 会引导你前往 Clerk 控制台。在那里，你可以通过 OIDC 或 SAML 连接 Okta 或 Microsoft Entra ID。企业版 SSO 连接在 2026 年 10 月 1 日前免费。此后将采用 Clerk 直通定价。Enterprise 将很快推出。

<div id="move-projects-between-workspaces">
  ### 在 Workspace 之间移动项目
</div>

现在，您可以从 **Projects** 列表中，将项目移至同一计费账户下的其他团队 Workspace。转移将在后台进行，且无法撤销。已关联的 Account Secrets 不会随项目一并移动，因此请在目标 Workspace 中重新关联。

<Frame>
  <img src="/assets/mirror/transfer-project-to-workspace-menu-f3accf37a0d6.png" alt="项目卡片菜单，其中包含“转移到 Workspace”操作" width="1218" height="1146" data-path="images/teams/transfer-project-to-workspace-menu.png" />
</Frame>

详细了解如何[在团队 Workspace 之间转移项目](/zh/teams/identity-and-access-management/transfer-app-to-teams#transfer-between-team-workspaces)。
