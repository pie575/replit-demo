---
title: "部署类型"
description: "对比 Autoscale、Static、Reserved VM 和计划部署，了解发布应用时该在何时选用哪一种。"
---

部署类型是指 Replit 发布应用时所使用的技术。你可以在 Publishing 工具的 **Adjust settings** 中，通过 **Deployment type** 下拉菜单进行选择。**Autoscale** 是默认且推荐的选项，大多数构建者无需更改。

<div id="section">
  ## 部署类型对比
</div>

| 类型              | 适合用途               | 运行方式              | 计费方式         |
| :-------------- | :----------------- | :---------------- | :----------- |
| **Autoscale**   | 流量波动的 Web 应用和 API  | 负载高时自动扩容，空闲时缩容至 0 | 仅在处理请求期间付费   |
| **Static**      | 着陆页、作品集、文档站点       | 由缓存的云服务器提供文件，无后端  | 仅按站点传输的数据量付费 |
| **Reserved VM** | 机器人、后台任务、常驻运行的 API | 一台不会进入休眠的专用服务器    | 固定月度费用       |
| **Scheduled**   | 备份、通知等周期性任务        | 按预定计划执行命令，执行完即停止  | 按每次运行时长付费    |

<div id="autoscale">
  ## Autoscale
</div>

Autoscale 部署运行在可根据应用流量自动扩容和缩容的服务器上。当应用负载较高时，Replit 会增加服务器来分担负载；当应用处于空闲状态时，服务器数量最少可缩减至 0，因此在无人访问的时段无需付费。

它适用于以下场景：

* 流量波动较大的 Web 应用，例如电商网站
* API 和各类服务

相关设置在 **Adjust settings** 中管理。请参阅[机器性能和最大服务器数量](/zh/ko/features/publishing/machine-configuration)。

<div id="static">
  ## Static
</div>

静态部署将 HTML、CSS、JavaScript 等应用文件托管在云服务器上，借助缓存快速且经济地分发内容，无需后端服务器。

适用于以下场景：

* 营销着陆页
* 作品集网站
* 产品与 API 文档站点

<Note>
  静态部署不适用于使用 Agent 创建的 Replit Apps。Agent 构建的是需要后端服务器的全栈应用，此类情况请改用 Autoscale 或 Reserved VM。
</Note>

配置项包括用于提供文件的公共目录，以及可选的构建命令。有关响应标头、URL 重写和重定向的详细信息，请参阅[静态部署高级设置](/zh/ko/features/deployment-customization/static-deployments-advanced)。

<div id="reserved-vm">
  ## Reserved VM
</div>

Reserved VM 部署会在不会进入休眠状态的专用虚拟机上运行你的应用，让你获得稳定一致的性能和可预测的固定月度费用。

适用于以下场景：

* 内存占用较高的后台任务
* 需要保持长连接的聊天机器人
* 全天候运行的 API 服务器

配置项包括[机器性能](/zh/ko/features/publishing/machine-configuration)、构建与运行命令、端口映射，以及应用是作为 Web 服务器运行还是作为后台工作进程运行。

<div id="scheduled">
  ## Scheduled
</div>

计划部署会在应用环境中按预定计划执行命令，运行结束后保持停止状态，直到下一次运行。你只需用日常语言描述执行时间，例如“每个工作日上午 9 点”，Replit 就会自动将其转换为计划安排。如果运行失败，你会收到通知。

适用于以下场景：

* 状态检查与健康报告
* 发送通知
* 启动备份

配置项包括计划、任务超时时间、构建命令和运行命令。计划部署不提供网页，因此没有公开 URL。
