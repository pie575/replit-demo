在 Replit 上发布 Web 应用后，系统会自动对线上 URL 进行搜索引擎优化 (SEO) 审核，并在 Publishing 工具中显示 SEO 评分。如果评分还有提升空间，只需单击一下，即可将具体问题交给 Agent，在几秒内完成修复。

对许多构建者来说，整个工作流程如下：发布应用，快速查看评分，然后让 Agent“优化 SEO”。本页面将介绍这一过程中后台发生了什么，以及如何充分利用这一功能。

<div id="seo">
  ## 什么是 SEO，以及它为何重要
</div>

搜索引擎优化 (SEO) 是指通过优化网站，使 Google 等搜索引擎能够发现、理解并为其排名。良好的 SEO 能让你的应用在用户搜索所需内容时出现在搜索结果中，无需支付广告费用。

SEO 的成效主要取决于几个因素：清晰的页面标题和描述、语义化 HTML、快速加载、适配移动设备的布局、图片的描述性 alt 文本，以及可抓取的网站结构。搜索引擎更青睐既便于用户阅读，也便于机器理解的网站。

如果你要发布着陆页、营销网站、博客、目录或其他需要易于被发现的内容，SEO 是最值得尽早投入的领域之一。

<div id="replitseo">
  ## Replit 默认提供的 SEO 优化
</div>

Replit 可承担许多 SEO 基础工作，让您专注于内容和产品。

* **快速、全球分布式托管**：Replit 部署通过针对速度优化的基础设施交付应用，您可以在[项目地理位置](/zh/ja/features/publishing/project-geography)中选择应用的运行位置。
* **默认启用 HTTPS**：所有已发布的应用都会获得由 Replit 管理的 TLS 证书。这是搜索引擎的基本排名信号。
* **自定义域名**：您可以连接自己的域名，以建立信任并提升品牌权威性。请参阅[自定义域名](/zh/ja/features/publishing/custom-domains)。
* **面向内容网站的静态部署**：对于营销页面、博客和文档，[静态部署](/zh/ja/features/publishing/deployment-types#static)可提供便于搜索引擎抓取的预渲染 HTML。
* **Agent 会编写注重 SEO 的代码**：当 Agent 构建页面时，默认会生成语义化 HTML、无障碍标记和元标签。这些也是 SEO 工具会检查的内容。
* **SEO 评分**：发布后会自动运行审核，因此您可以随时了解当前情况，并可一键将发现的问题交给 Agent。

<div id="section">
  ### 查找位置
</div>

在已发布的应用中打开 **Publishing** 工具。SEO 评分会显示在部署概览中，并附带其他构建详情。将鼠标悬停在评分上，即可查看 Lighthouse 在各个页面中发现的具体改进项。

<Note>
  如果未显示 SEO 评分，应用可能处于私有状态，或最近未发布。评分仅会显示在已发布的 Web 应用中。
</Note>

<div id="section-2">
  ### 如何解读评分
</div>

Replit 会根据 Lighthouse 审核结果显示以下三种评分之一。

| 评分         | 含义                           |
| :--------- | :--------------------------- |
| Healthy    | 应用遵循 SEO 最佳实践。进行重大更改后，请仔细检查。 |
| Needs Work | 一些问题限制了搜索引擎理解应用的能力。          |
| Weak       | 缺少重要的 SEO 基础要素。修复通常只需几分钟。    |

如果应用有多个页面，徽章会显示 Replit 抓取的所有 URL 中**最低**的评分。因此，问题最严重的页面会优先显示，不会因取平均值而被掩盖。

<div id="section-3">
  ### 评分计算时间
</div>

每次成功发布后，系统都会自动运行审核。评分通常会在部署上线后 1～2 分钟内显示，Publishing 工具会在收到结果后立即更新徽章。

<div id="section-4">
  ### 支持的部署类型
</div>

SEO 评分适用于搜索引擎可抓取 URL 的公开 Web 部署。

* [Autoscale 部署](/zh/ja/features/publishing/deployment-types#autoscale)
* [Reserved VM 部署](/zh/ja/features/publishing/deployment-types#reserved-vm)
* [静态部署](/zh/ja/features/publishing/deployment-types#static)

定时部署和私有部署不处理公开 Web 流量，因此不会生成 SEO 评分。

<div id="agentseo">
  ## 使用 Agent 优化 SEO
</div>

评分旁边会显示 **Optimize SEO with Agent** 按钮。选择该按钮会在 Growth 面板中打开 [SEO Agent](/zh/ja/features/publishing/seo-agent)，以执行技术 SEO 审核、查看发现的问题，并一键应用修复。

<Tip>
  您也可以跳过此按钮，直接打开 Agent 并告诉它**“优化 SEO”**即可。Agent 会获取最新结果并开始处理。
</Tip>

Agent 完成更改后，请重新发布应用。系统会根据新构建重新计算 SEO 评分，并自动更新徽章。

Agent 常见的修复包括：

* 添加或修复缺失或过于通用的 `<title>` 标签，为每个页面提供独特且描述明确的标题
* 为所有页面添加元描述
* 为图片添加描述性的 `alt` 文本
* 为 `<html>` 元素设置 `lang` 属性
* 确保链接包含可识别的文本 (不要使用“点击此处”或空锚点)
* 添加 `robots.txt` 和 `sitemap.xml`
* 添加适用于移动设备的 viewport 元标签
* 改善未通过无障碍检查的文本颜色对比度
* 添加 Open Graph 和 Twitter 卡片元标签，让应用链接在社交平台上的预览效果更佳

<div id="replitseo-2">
  ## 在 Replit 上构建 SEO 优化网站的最佳实践
</div>

无论是让 Agent 完成还是自行编写，以下做法对基于 Replit 构建的 App 效果最为显著。

* **为每个页面添加独特的标题和元描述。** 标题应控制在 60 个字符以内，描述建议为 150～160 个字符。
* **使用语义化 HTML。** 使用 `<main>`、`<header>`、`<nav>` 和 `<footer>` 组织页面布局。每个页面只能使用一次 `<h1>`，并按顺序使用更低级别的标题。
* **为所有图片添加 alt 文本。** 不仅要说明图片是什么，还要描述它所传达的内容。
* **生成 `sitemap.xml` 和 `robots.txt`。** 请 Agent 创建这两个文件，以便搜索引擎了解应抓取哪些内容。
* **添加 Open Graph 和 Twitter 卡片标签。** 这样可以控制 App 在社交媒体上被分享时的展示方式。
* **使用自定义域名。** 品牌域名可提升访客和搜索引擎的信任度。请参阅[自定义域名](/zh/ja/features/publishing/custom-domains)。
* **选择合适的部署类型。** 对于内容丰富的网站，[静态部署](/zh/ja/features/publishing/deployment-types#static)可提供搜索引擎能够立即解析的预渲染 HTML。
* **添加结构化数据。** JSON-LD 标记可让搜索引擎展示商品、文章、FAQ 和活动的富媒体搜索结果。
* **保持 App 的高速运行。** 优化图片，避免使用阻塞渲染的脚本，并利用 Replit 托管服务降低响应时间。

以下是一种可一次性应用大多数优化的简单方法：

<AiPrompt>
  按照 SEO 最佳实践审计我的网站并应用修复。添加站点地图、robots.txt、Open Graph 标签和适用的结构化数据，并确保每个页面都有唯一的标题和元描述。
</AiPrompt>
