<div id="importar-do-bolt">
  ## Импорт из Bolt
</div>

⏰ *Ориентировочное время: четыре минуты*

<Warning>В настоящее время Agent поддерживает импорт приложений Vite + React из Bolt.</Warning>

Чтобы импортировать проект из Bolt в Replit, экспортируйте его в GitHub, а затем импортируйте этот репозиторий.

Полный список вариантов импорта, включая другие платформы, такие как GitHub, Figma и Lovable, приведён в [документации по импорту](/ru/pt/core-concepts/project-editor/app-setup/import).

<div id="antes-de-comear">
  ## Перед началом работы
</div>

* Проект в Bolt, доступный для экспорта
* Учётная запись GitHub, подключённая к Bolt
* Учётная запись Replit

<div id="passos-de-importao">
  ## Импорт проекта
</div>

1. Экспортируйте проект из Bolt в GitHub.
2. Откройте [replit.com/import](https://replit.com/import).
3. Выберите **Bolt**.
4. Подключите учётную запись GitHub.
5. Выберите репозиторий, экспортированный из Bolt.
6. Выберите **Импортировать**.

<div id="what-gets-imported">
  ## Что импортируется
</div>

Replit импортирует из вашего проекта {platform_1} следующее:

* **Код**: Логику приложения и исходные файлы
* **Дизайн и стили**: Компоненты UI и правила оформления
* **Ассеты**: Изображения, иконки и статические файлы
* **Логику бэкенда**: Серверную функциональность, если она есть
* **Схему базы данных**: Структуру таблиц, если она есть

<div id="what-is-not-imported">
  ## Что не импортируется
</div>

* **Данные Supabase**: Существующие записи в базе данных не переносятся
* **Secrets**: Переменные окружения и API-ключи необходимо добавить отдельно

Используйте Agent, чтобы восстановить недостающую функциональность, добавить секреты и воссоздать данные базы данных.
