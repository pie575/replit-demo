<div id="recover-production-data-with-scheduled-backups">
  ### 예약 백업로 프로덕션 데이터 복구하기
</div>

예약 백업는 production database에 대해 매일 전체 복원 지점을 하나씩 생성합니다. 기능을 켜려면 production database 설정에서 **Keep backups for** 항목의 retention period를 선택하세요. retention limit은 plan에 따라 다릅니다.

<div id="understand-app-usage-with-project-analytics">
  ### Project Analytics로 앱 사용 현황 파악하기
</div>

Project Analytics는 사용자가 게시된 web app을 어떻게 찾고 사용하는지 보여줍니다. **Growth** pane에서 대략적인 방문자 추이, 인기 페이지, 트래픽 소스, 국가, 브라우저, 기기를 확인해 보세요. 데이터 수집을 시작하려면 **Enable analytics**를 켠 뒤 앱을 republish하세요. paid plan에서는 Agent에게 요청해 맞춤 이벤트를 추가하고 가입, 구매 같은 동작의 퍼널을 분석할 수 있습니다.
