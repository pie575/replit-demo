<div id="what-is-a-project">
  ## 什么是项目？
</div>

项目是你在 Replit 上构建的一切内容的容器。它包含你的代码、数据以及创建的所有产物——web 应用、移动应用、幻灯片演示文稿、数据仪表板和视频。当你告诉 Agent 你的需求时，它会设置一个项目，并在其中构建产物。

你可以把项目想象成桌面上的工作区。所有内容都集中在一处，可以共享相同的信息，但每个部分的用途各不相同。

例如，如果你让 Agent 构建一款健身追踪应用，它会创建一个项目，其中包含一个移动应用产物，以及运行所需的 backend、数据库和存储。

<ArtifactGrid />

核心概念：

* **Project**：容纳所有内容的容器——你的代码、数据和所有产物
* **Artifact**：项目中可发布的输出 (如 web 应用、幻灯片演示文稿、视频等)
* **资源**：每个产物 都能自动使用 backend、数据库和文件存储，无需进行任何设置

<Note>
  Publishing 会一次性将整个项目上线。所有产物 都会
  同时上线，因此始终保持同步。
</Note>

</div>

| 类型                                                           | 说明                     | 示例                 |
| ------------------------------------------------------------ | ---------------------- | ------------------ |
| **[Web app](/zh/features/artifact-types/web-apps)**             | 用户可通过浏览器访问的网站或 Web 应用  | 在线商店、预约工具、作品集网站    |
| **[移动应用](/zh/features/artifact-types/building-mobile-apps)**    | 用户可安装在手机上的原生应用         | 健身追踪器、餐厅点餐应用       |
| **[Data Visualization](/zh/features/artifact-types/data-apps)** | 包含图表、筛选器和实时数据的交互式仪表板   | 销售报告、指标追踪器、分析视图    |
| **[幻灯片演示文稿](/zh/features/artifact-types/slide-decks)**          | 可用于演示或导出的演示文稿          | 路演演示文稿、团队进展更新、产品概览 |
| **[动画](/zh/features/artifact-types/animated-videos)**           | 可导出为 MP4 的动态图形视频       | 产品发布视频、讲解视频、社交媒体内容 |
| **3D 游戏**                                                    | 3D 游戏、模拟或交互式体验         | 解谜游戏、物理模拟、交互式体验    |
| **[Design](/zh/design/canvas)**                                 | 在设计 Canvas 上探索的视觉方向和原型 | 情绪板、模型稿、设计探索       |

一个项目可以包含多个产物。例如，你可以为客户构建 Web 应用、为团队构建移动应用，并为投资者制作路演演示文稿，全部放在同一个项目中。当多个产物 位于同一项目中时，它们会自动共享相同的数据和 backend 逻辑。要了解更多信息，请参阅 [Artifacts](/zh/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project)。

<div id="managing-your-projects">
  ## 管理你的项目
</div>

“项目”页面会列出你创建的或受邀加入的所有项目。你可以在这里快速回到最近的工作，并在繁忙的工作区中找到所需的项目。

<div id="see-at-a-glance-whats-inside-each-project">
  ### 一目了然地查看每个项目中的内容
</div>

每张项目卡片都会显示项目中各个 Web 应用、移动应用、幻灯片演示文稿、数据可视化或动画所包含产物的小图标。将鼠标悬停在任一图标上，即可直接在卡片上预览该产物的截图，无需打开项目即可轻松区分各个项目。

<div id="filter-by-artifact">
  ### 按产物筛选
</div>

使用项目页面顶部的 **Build type** 下拉菜单，按产物类型筛选项目列表。选择一种类型后，只会显示包含该类产物的项目：

* **Web** — 包含 web 应用 的项目
* **Mobile** — 包含移动应用的项目
* **Data** — 包含数据可视化内容的项目
* **Slides** — 包含幻灯片演示文稿的项目
* **Design** — 使用 Design 模式的项目
* **3D Game**、**Agent &amp; Automation** 等

选择 **Any build type** 可清除筛选条件。

<div id="sort-by-last-opened">
  ### 按最后打开时间排序
</div>

项目页面默认按**你最后打开的时间**排序——你最近处理过的项目会显示在顶部。这在团队工作区中尤其有用，否则其他成员最近的编辑可能会让你当前的工作被挤到后面。

你可以选择其他列标题 (例如**最后更新**或**名称**) 来切换排序方式。

<div id="pin-the-projects-you-use-most">
  ### 固定常用项目
</div>

固定项目后，它会始终显示在列表顶部。固定状态**仅自己可见**——在团队工作区中固定项目不会影响其他成员看到的内容。

要固定项目，请打开项目卡片上的更多菜单 (三个点) ，然后选择**固定**。要取消固定，请在同一菜单中选择**取消固定**。
