<div id="section-2">
  ## 平台更新
</div>

<div id="repl-app">
  ### Repl → App
</div>

Repl 现已更名为“App”。一切从简。

<div id="section-3">
  ### 通知优化
</div>

支付失败和账单通知现已改进。App 停止前将提供 24 小时的宽限期，让整个流程更加透明。

此次更新有助于避免您的 Replit 使用体验中断。

<div id="section-4">
  ### 对象存储优化
</div>

对象存储面板现已支持搜索和分页，让您能更轻松地浏览文件。

<div id="diff">
  ### 更清晰的差异对比
</div>

Assistant 的文件更改现在会在临时 diff 面板中打开，让你无需打开大量标签页占用工作区，也能更轻松地查看更改内容。

应用更改后，面板会自动关闭。

<div id="agent">
  ### Agent 在亚洲的性能提升
</div>

我们已优化面向亚洲 Agent 构建者的云服务，响应更快，使用体验也更加流畅。

<div id="x">
  ### 使用 X 登录
</div>

现在你可以使用 X 注册并登录 Replit。欢迎来到未来。

<div id="section-5">
  ### 快速导入仓库
</div>

想把你喜欢的 GitHub 仓库导入 Replit 吗？

现在就可以。

只需在浏览器中输入 `replit.com/YOUR_REPO_URL`。例如：

`https://replit.com/github.com/mattppal/magnetic-feel`
