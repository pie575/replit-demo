Console позволяет отслеживать и просматривать логи, которые выводит работающее Replit App в реальном времени.
Используйте информацию о текущих и предыдущих запусках, чтобы понять работу приложения,
устранить ошибки и оптимизировать производительность.

<Tip>
  При отладке с помощью Agent добавляйте логи Console в prompt, чтобы предоставить контекст.
</Tip>

<div id="recursos">
  ## Возможности
</div>

Console предоставляет следующие инструменты, которые помогут вам понять, как работает ваше приложение:

* **Логирование в реальном времени**: Просматривайте вывод приложения по мере его работы
* **Помощь ИИ**: Получайте рекомендации по исправлению ошибок, указанных в логах
* **История запусков**: Просматривайте логи предыдущих запусков, чтобы отслеживать изменения

<div id="uso">
  ## Использование
</div>

Инструмент Console доступен прямо в Project Editor.

<Accordion title="Как открыть Console">
  На **панели инструментов** слева:

  1. Выберите <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Значок «Все инструменты»" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**, чтобы открыть список инструментов Project Editor.
  2. Выберите <img class="icon-svg" src="/assets/mirror/console-8a41ac90789c.svg" alt="Значок Console" width="16" height="16" data-path="images/icons/console.svg" /> **Console**.

  В **строке поиска**:

  1. Нажмите значок <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="значок лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> лупы вверху, чтобы открыть поиск.
  2. Введите «Console», найдите инструмент и выберите его в результатах.
</Accordion>

При каждом нажатии кнопки **Run** в Replit App в Console появляется новая запись со следующей информацией:

* Команда, запускающая ваш код
* Временная метка
* Логи стандартного вывода и ошибок

На следующем снимке экрана показана команда `npm run dev`, используемая для запуска приложения, и логи выполнения:

<Frame>
  <img src="/assets/mirror/console-log-entry-b57e5b89087d.png" alt="Запись лога Console с указанием выполненной команды" width="1948" height="870" data-path="images/workspace/console-log-entry.png" />

<Note>
  Логи на стороне клиента, например создаваемые кодом HTML, CSS и JS, отображаются только в инструментах разработчика в [Preview](/ru/pt/features/editor/preview).
</Note>

<div id="depurao-com-ia">
  ### Отладка с помощью ИИ
</div>

Если в логах вы обнаружили ошибки или другую информацию, которую хотите понять, нажмите
кнопку **Ask AI** в верхней части записи. Откроется вкладка **Agent**, а содержимое лога будет
автоматически отправлено на анализ.

<div id="comandos-de-entrada-de-log">
  ### Команды ввода логов
</div>

Console предоставляет следующие инструменты для управления логами:

* **Показывать только последние**: Переведите этот переключатель в положение **on**, чтобы отображать только последний запуск.
* **Свернуть запись**: Нажмите стрелку вниз <img class="icon-svg" src="/assets/mirror/down-arrow-9c1cf9fd152e.svg" alt="значок стрелки вниз" height="16" width="16" data-path="images/icons/down-arrow.svg" /> слева от названия команды, чтобы скрыть логи.
* **Очистить предыдущие запуски**: Выберите этот пункт, чтобы удалить логи предыдущих запусков. Это действие необратимо.

<div id="disponibilidade-de-rede">
  ### Доступность сети
</div>

Вы можете управлять доступностью в интернете разрабатываемой версии приложения.

Чтобы прекратить принимать запросы по URL-адресу разработки, выберите иконку <img class="icon-svg" src="/assets/mirror/network-off-5bdca8a4fe4e.svg" alt="иконка отключённой сети" height="16" width="16" data-path="images/icons/network-off.svg" /> перечёркнутого глобуса
справа в строке сетевой информации.

Чтобы включить её снова, выберите иконку <img class="icon-svg" src="/assets/mirror/network-on-15be2e5fb4f5.svg" alt="иконка включённой сети" height="16" width="16" data-path="images/icons/network-on.svg" /> глобуса.

Чтобы посмотреть URL-адрес разработки, выберите текст `{...}.replit.dev` в адресной строке.

<Frame>
  <img src="/assets/mirror/preview-dev-url-b36770b33769.png" alt="Расположение URL-адреса разработки в Preview" width="1222" height="824" data-path="images/workspace/preview-dev-url.png" />
</Frame>

<Note>
  Ваше приложение остаётся доступным в Preview, даже если оно настроено на прекращение приёма запросов по URL-адресу разработки.
</Note>

<div id="parar-um-comando-de-workflow">
  ### Остановка команды рабочего процесса
</div>

Вы можете остановить выполняющуюся команду рабочего процесса с помощью инструмента Console в Project Editor.

Нажмите квадратную кнопку справа от строки с командой запуска вашего Replit App, чтобы завершить её.

Чтобы перезапустить приложение, используйте кнопку **Run** рабочего процесса в верхней части Project Editor.
