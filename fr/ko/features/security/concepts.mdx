Définitions des termes de sécurité employés dans le [Project Security Center](/fr/ko/features/security/project-security-center) et le [Workspace Security Center](/fr/ko/features/security/workspace-security-center).

<div id="cve">
  ## CVE
</div>

Common Vulnerabilities and Exposures (vulnérabilités et expositions communes). Un CVE est un identifiant unique attribué à une vulnérabilité logicielle connue publiquement, par exemple `CVE-2024-12345`.

<div id="severity">
  ## Gravité (Severity)
</div>

Niveau de risque attribué à une vulnérabilité, classé en critical, high, medium et low. Combinez la gravité et le niveau d&#39;exposition pour déterminer quels projets corriger en priorité.

<div id="dependency">
  ## Dépendance
</div>

Paquets tiers dont dépend un projet. Une vulnérabilité présente dans une dépendance affecte tous les projets qui l&#39;utilisent, tant que cette dépendance n&#39;est pas mise à jour ou remplacée.

<div id="sbom">
  ## SBOM
</div>

Software Bill of Materials (nomenclature logicielle). Le SBOM est une liste lisible par machine des paquets, versions et licences inclus dans un projet.

<div id="spdx-cyclonedx">
  ## SPDX et CycloneDX
</div>

Formats SBOM standard utilisés par les outils de sécurité et de conformité. Choisissez le format exigé par vos outils d&#39;audit, de conformité ou d&#39;analyse de composition logicielle.

<div id="exposure">
  ## Exposition
</div>

Surface de risque créée par l&#39;état de publication et le niveau de visibilité. Un projet publié publiquement présente une exposition plus élevée qu&#39;un projet privé ou non publié.

<div id="fix-with-agent">
  ## Fix with Agent
</div>

Cette action demande à Replit Agent de rédiger un correctif pour les projets concernés, sous forme de tâche en arrière-plan. Examinez les modifications générées avant de les appliquer.

<div id="republish">
  ## Republish
</div>

Redéployez votre projet avec la configuration de déploiement existante. Une fois vos correctifs appliqués, utilisez **Republish** pour publier la version corrigée.

<div id="package-firewall">
  ## Package Firewall
</div>

Une protection qui bloque les paquets malveillants ou compromis au niveau du réseau, au moment de l&#39;installation, avant leur téléchargement dans votre application. Activée par défaut, elle s&#39;appuie sur Socket. Consultez [Package Firewall](/fr/ko/features/security/package-firewall).

<div id="auto-protect">
  ## Auto-Protect
</div>

Auto-Protect est un ensemble complet de protections que Replit applique automatiquement à votre application. Activées par défaut pour tous les créateurs, elles comprennent le [Package Firewall](/fr/ko/features/security/package-firewall), qui bloque les menaces lors de l’installation, un pare-feu d’applications web (WAF) et le chiffrement SSL/TLS automatique. Les administrateurs peuvent également activer l’atténuation automatique des CVE : Replit Agent prépare alors des correctifs pour les vulnérabilités nouvellement divulguées dans les dépendances et en informe les propriétaires de projets. Consultez [Auto-Protect](/fr/ko/features/security/project-security-center#auto-protect).
