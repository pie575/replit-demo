## 플랫폼 업데이트

### Repl -> 앱

Repl이 이제 "앱"입니다. 단순함이 핵심입니다.

### 향상된 알림

결제 실패 및 청구서 알림이 개선되었습니다. 이제 앱이 일시 중단되기 전에 24시간의 유예 기간이 제공되며, 전체 과정에서 더 많은 투명성이 확보됩니다.

이 업데이트는 Replit 경험의 중단을 방지하는 데 도움이 됩니다.

### 오브젝트 스토리지 개선

오브젝트 스토리지 패널에 검색 기능 및 페이지네이션이 추가되어 파일을 더 쉽게 탐색할 수 있습니다.

### 깔끔해진 diff

Assistant 파일 변경 사항이 이제 임시 diff 패널을 열어줍니다. 이로 인해 끝없는 탭으로 워크스페이스를 무겁게 하지 않고도 변경 사항을 더 쉽게 확인할 수 있습니다.

변경 사항을 적용하면 패널이 자동으로 닫힙니다.

### 아시아에서 더 성능 좋은 Agent

클라우드 서비스가 아시아의 Agent 빌더를 위해 최적화되었습니다. 더 빠른 응답과 훨씬 매끄러운 경험을 느끼실 수 있습니다.

### X 로그인

이제 X로 Replit에 등록하고 로그인할 수 있습니다. 미래에 오신 것을 환영합니다.

### 빠른 저장소 가져오기

좋아하는 GitHub 저장소를 Replit으로 가져오고 싶으신가요?

이제 즉시 할 수 있습니다.

브라우저에 `replit.com/YOUR_REPO_URL`을 입력하세요. 예를 들어:

`https://replit.com/github.com/mattppal/magnetic-feel`
