Utilisez le mode vocal pour décrire à voix haute ce que vous souhaitez créer. Appuyez sur le microphone dans la zone de chat d’Agent et parlez : Replit transcrit votre voix en texte. Vérifiez et modifiez le texte, puis envoyez-le comme un message classique.

Le mode vocal est utile lorsque la saisie est lente ou peu pratique — surtout sur mobile, où dicter un prompt complet est souvent plus rapide que de taper avec les pouces.

<Note>
  Le mode vocal convertit votre voix en texte dans la zone de chat. Il ne lit pas les réponses d’Agent à voix haute — vous envoyez toujours vos messages par écrit et Agent répond dans le chat.
</Note>

  ## Fonctionnement
</div>

Le mode vocal enregistre et transcrit votre voix, puis insère le résultat dans la zone de chat pour vous permettre de le vérifier avant l’envoi :

1. Ouvrez Agent et sélectionnez le microphone dans la zone de chat.
2. Autorisez l’accès au microphone si votre navigateur ou votre appareil vous le demande.
3. Énoncez votre prompt. Une forme d’onde s’affiche pour indiquer qu’Agent enregistre.
4. Arrêtez l’enregistrement lorsque vous avez terminé. Il s’arrête automatiquement après une pause ou si vous changez d’onglet.
5. Attendez un instant que votre voix soit transcrite.
6. Vérifiez le texte transcrit, modifiez-le si nécessaire, puis envoyez votre message.

Le texte s’affichant dans la zone de chat habituelle, vous pouvez librement combiner voix et saisie au clavier : dicter une partie de votre prompt, puis taper le reste, ou corriger des mots avant l’envoi.

<Tip>
  Parlez naturellement. Le mode vocal privilégie la compréhension du sens à une transcription littérale ; les mots de remplissage comme « euh » et « hum » sont donc exclus du résultat.
</Tip>

<div id="section-2">
  ## Où l’utiliser
</div>

Le mode vocal est disponible dans la zone de chat d’Agent :

* Dans l’**éditeur de projet** lorsque vous travaillez sur une application avec Agent.
* Lorsque vous **créez une nouvelle application** à partir du prompt Agent sur l’écran d’accueil.

Le mode vocal est disponible sur le Web sur ordinateur, le Web mobile et l’application mobile Replit.

<div id="section-3">
  ## À savoir
</div>

Gardez ces informations à l’esprit lorsque vous utilisez le mode vocal :

| Détail                         | Description                                                                                                                                                                                        |
| ------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Durée d&#39;enregistrement     | Vous pouvez enregistrer jusqu’à 6 minutes à la fois. Un avertissement s’affiche à l’approche de la limite.                                                                                         |
| Arrêt automatique              | L’enregistrement s’arrête automatiquement après environ 30 secondes de silence, ou si vous changez d’onglet ou mettez l’application en arrière-plan.                                               |
| Vérification avant l&#39;envoi | Le texte transcrit s’affiche dans la zone de chat afin que vous puissiez le lire et le modifier avant de l’envoyer — il n’est pas envoyé automatiquement.                                          |
| Accès au microphone            | Le mode vocal nécessite l’autorisation d’utiliser votre microphone. Si l’enregistrement ne démarre pas, vérifiez que votre navigateur et votre appareil autorisent Replit à accéder au microphone. |

<div id="section-4">
  ## Forfaits disponibles
</div>

Le mode vocal est disponible avec tous les forfaits Replit. Le microphone s’affiche dans la zone de chat d’Agent sur les navigateurs et appareils compatibles avec l’enregistrement audio. Vous devrez autoriser l’accès au microphone lors de votre premier enregistrement.
