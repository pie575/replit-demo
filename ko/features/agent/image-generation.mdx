이미지 생성 기능을 활용하면 디자인 역량이나 외부 도구 없이도 나만의 독창적인 시각 콘텐츠를 만들 수 있습니다. 아이콘과 일러스트레이션부터 배경과 UI 요소까지, 개발 워크플로 안에서 바로 생성해 보세요.

<div id="features">
  ## 기능
</div>

Agent의 이미지 생성 기능으로 시각적으로 매력적인 애플리케이션을 만들어 보세요. 기본적인 시각 콘텐츠를 위해 스톡 사진이나 외부 디자인 도구를 찾거나 디자이너를 고용할 필요가 없습니다. 포트폴리오 웹사이트를 만들든, 게임을 개발하든, 모바일 앱 인터페이스를 디자인하든, 이미지 생성은 프로젝트에 딱 맞는 맞춤형 비주얼을 제공합니다.

Agent는 다음과 같은 이미지 생성 작업을 수행할 수 있습니다.

* **맞춤 이미지 생성**: 상세한 설명과 사양을 바탕으로 이미지를 생성합니다
* **스타일 적용**: 사실적인 스타일부터 만화풍까지 다양한 예술적 스타일로 이미지를 만듭니다
* **투명 배경**: 투명 PNG 형식으로 이미지를 생성하거나 기존 이미지에서 배경을 제거합니다 — 로고, 아이콘, 스티커, 제품 누끼 이미지에 적합합니다
* **프로젝트 통합**: 생성된 이미지를 앱의 코드베이스에 매끄럽게 바로 추가합니다
* **반복적인 다듬기**: 피드백을 바탕으로 이미지를 수정하고 개선합니다

<div id="usage">
  ## 사용법
</div>

이미지 생성 기능은 Agent에 기본 내장되어 있어 따로 켤 필요가 없습니다. Agent가 활성화된 Replit App을 열고 필요한 시각 콘텐츠를 만들어 달라고 Agent에게 요청하세요. Agent는 요청 내용을 바탕으로 이미지를 생성할 시점을 자동으로 판단해 지정한 사양에 맞는 맞춤 이미지를 만들어 줍니다.

<div id="when-agent-uses-image-generation">
  ### Agent가 이미지 생성을 사용하는 경우
</div>

project에 사용할 시각적 콘텐츠를 요청하면 Agent가 이미지 생성을 실행합니다:

| 사용 사례                 | prompt 예시                                       |
| --------------------- | ----------------------------------------------- |
| **app 아이콘 및 로고**   | &quot;내 피트니스 추적 앱에 어울리는 모던한 로고를 생성해 줘&quot;   |
| **website 배경**        | &quot;내 포트폴리오 사이트에 쓸 은은한 그라데이션 배경을 만들어 줘&quot;  |
| **게임 assets**         | &quot;내 플랫포머 게임에 쓸 픽셀 아트 스프라이트를 생성해 줘&quot;     |
| **UI 일러스트레이션**        | &quot;내 앱의 빈 상태 화면에 쓸 일러스트레이션을 만들어 줘&quot;      |
| **마케팅 비주얼**           | &quot;내 landing page에 쓸 hero 이미지를 생성해 줘&quot;   |
| **제품 mockups**        | &quot;여러 기기에서 실행되는 내 앱의 mockup 이미지를 만들어 줘&quot; |
| **투명 배경 로고 및 아이콘** | &quot;배경이 투명한 내 앱 로고를 생성해 줘&quot;             |

<div id="best-practices-for-image-generation">
  ### 이미지 생성 모범 사례
</div>

Agent의 이미지 생성에서 최상의 결과를 얻으려면 다음 지침을 따르세요.

**구체적이고 자세하게 설명하세요**

* 스타일, 색상, 구도, 분위기에 대한 세부 정보를 포함하세요
* 필요한 경우 크기나 화면 비율을 지정하세요
* 사용 목적(아이콘, 배경, 일러스트레이션 등)을 언급하세요
* 로고, 아이콘, 스티커, 컷아웃 이미지를 다른 콘텐츠 위에 얹어야 한다면 배경을 투명하게 만들어 달라고 요청하세요

**반복하며 다듬으세요**

* 간단한 설명으로 시작한 뒤 결과를 보며 다듬으세요
* 생성된 이미지에서 특정 부분만 수정해 달라고 Agent에게 요청하세요
* 다양한 창의적 방향을 살펴볼 수 있도록 여러 변형을 요청하세요

**project의 스타일을 고려하세요**

* 앱 전반에서 시각적 일관성을 유지하세요
* 브랜드나 design system에 맞는 스타일을 지정하세요
* 기존 시각 요소와 잘 어울리는 이미지를 요청하세요

<div id="project-integration">
  ### 프로젝트 통합
</div>

Agent는 생성된 이미지를 코드베이스에 매끄럽게 통합합니다.

* **자동 파일 생성**: 생성된 이미지가 project 파일에 바로 저장됩니다
* **코드 업데이트**: Agent가 새 이미지 파일을 참조하도록 코드를 수정합니다
* **Asset 정리**: 이미지는 project 구조 내 적절한 디렉터리에 배치됩니다

이렇게 간소화된 워크플로 덕분에 개발 환경을 벗어나지 않고도 시각적 콘텐츠를 생성하고 적용할 수 있습니다.

<Note>
  Replit의 이미지 생성은 [Google의 Imagen
  4](https://deepmind.google/models/imagen/)를 기반으로 합니다. 최신 텍스트-이미지
  model인 Imagen 4는 세밀한 디테일과 향상된 텍스트 렌더링 기능을 바탕으로 고품질의
  사실적인 이미지를 만드는 데 뛰어납니다.
</Note>
