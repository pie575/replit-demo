<div id="platform-updates">
  ## Обновления платформы
</div>

<div id="repl-app">
  ### Repl -&gt; App
</div>

Repl теперь называются «App». Всё ради простоты.

<div id="enhanced-notifications">
  ### Улучшенные уведомления
</div>

Мы улучшили уведомления о неудачных платежах и счетах. Теперь перед приостановкой вашего App вам предоставляется льготный период в 24 часа, а сам процесс стал более прозрачным.

Это обновление поможет избежать перебоев в работе с Replit.

<div id="object-storage-improvements">
  ### Улучшения Object Storage
</div>

В панель Object Storage добавлены поиск и постраничная навигация, упрощающие просмотр файлов.

<div id="de-cluttered-diffs">
  ### Удобные панели различий
</div>

Изменения файлов в Assistant теперь открываются в отдельных временных панелях различий. Так легче просматривать вносимые изменения, не загромождая workspace бесконечными вкладками.

Панели автоматически закрываются после применения изменений.

<div id="more-performant-agent-in-asia">
  ### Более быстрый Agent в Азии
</div>

Облачные сервисы оптимизированы для разработчиков, использующих Agent в Азии. Вы заметите более быстрые ответы и значительно более плавную работу.

<div id="x-login">
  ### Вход через X
</div>

Теперь вы можете зарегистрироваться в Replit и входить через X. Добро пожаловать в будущее.

<div id="rapid-repo-import">
  ### Быстрый импорт репозиториев
</div>

Хотите перенести свой любимый репозиторий с GitHub в Replit?

Теперь это можно сделать мгновенно.

Просто введите в браузере `replit.com/YOUR_REPO_URL`, например:

`https://replit.com/github.com/mattppal/magnetic-feel`
