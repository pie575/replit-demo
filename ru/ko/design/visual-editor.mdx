<div id="visual-editor">
  ## Что такое Visual Editor?
</div>

Visual Editor позволяет изменять UI, просто щёлкая по элементам. Он работает как на [Canvas](/ru/ko/design/canvas) в Replit Design, так и в Preview, поэтому вы можете одинаково редактировать макеты и запущенные приложения.

Простые изменения, такие как редактирование текста, настройка цветов и отступов, напрямую обновляют исходный код без расхода AI-кредитов. Если изменение требует более сложной обработки, Visual Editor автоматически передаёт задачу Agent.

Ключевые понятия:

* **Детерминированное редактирование**: простые изменения (текст, цвета, отступы) применяются напрямую к исходному коду без участия Agent.
* **Без расхода кредитов**: прямое редактирование не расходует AI-кредиты — через Agent обрабатываются только сложные изменения.
* **Двойной контекст**: работает одинаково и во фреймах Canvas, и в Preview.
* **Синхронизация исходного кода**: все изменения сразу обновляют исходный код.

<Note>
  Visual Editor сейчас доступен только в **веб-браузере**. В мобильном или десктопном приложении он не поддерживается.
</Note>

<div id="visual-editor-2">
  ## Как пользоваться Visual Editor
</div>

<div id="canvas">
  ### Редактирование в Canvas
</div>

На панели инструментов выберите **Edit**, затем нажмите на элемент во фрейме. Элемент будет выделен, рядом появится метка с его именем, а справа откроется панель Visual Editor со свойствами, доступными для редактирования: содержимым, раскладкой, цветом, границами и другими. Настройте свойства, затем выберите **Save edits**, чтобы применить изменения, или **Discard**, чтобы отменить их.

Отображаемые свойства зависят от выбранного элемента. Для текстовых элементов доступны настройки шрифта, для изображений — выбор источника и загрузка, а для контейнеров — настройки раскладки.

<div id="preview">
  ### Редактирование в Preview
</div>

Те же возможности редактирования доступны и в работающем приложении.

<Steps>
  <Step title="Выберите элемент">
    Нажмите на элемент в Preview, чтобы начать редактирование.
  </Step>

  <Step title="Редактируйте">
    Редактируйте текст прямо на месте, настраивайте цвета с помощью палитры, изменяйте отступы с помощью элементов управления стилями или заменяйте изображения.
  </Step>

  <Step title="Сохраните">
    Нажмите «Сохранить», чтобы обновить исходный код. Простые изменения применяются напрямую без расхода AI-кредитов. Если изменение требует более сложной обработки, Visual Editor отправляет Agent метаданные выбранного элемента.
  </Step>
</Steps>

<div id="section">
  ### Редактирование текста
</div>

Нажмите на текстовый элемент и отредактируйте его прямо на месте. Если текст — строка в исходном коде, изменения применятся сразу.

<div id="section-2">
  ### Настройка цветов
</div>

С помощью палитры настройте цвет текста и фона. Введите в поле название цвета, например «purple», или используйте пипетку, чтобы выбрать цвет в любом месте экрана.

<div id="section-3">
  ### Изменение стилей
</div>

С помощью интуитивно понятных элементов управления настраивайте внутренние и внешние отступы, а также раскладку элементов.

<div id="section-4">
  ### Элементы управления раскладкой
</div>

Visual Editor группирует все элементы управления в понятные разделы, чтобы вам было проще находить нужное: **Text**, **Layout**, **Color**, **Border**. (При выборе изображения также появляется раздел **Image**.)

В разделе **Layout** можно настроить расположение дочерних элементов внутри контейнера, не обращаясь к Agent. Выберите flex-контейнер и разверните Layout, чтобы увидеть следующее.

* **Alignment**: селектор в виде сетки 3×3 точек для выбора положения элементов по обеим осям внутри контейнера.
* **Direction**: две кнопки со стрелками для размещения дочерних элементов в строку или столбец.
* **Gap**: значение в пикселях, обозначающее расстояние между элементами. Значок рядом с полем Gap меняется в соответствии с текущим направлением, поэтому вы всегда видите, настраиваете ли горизонтальный или вертикальный интервал. Значок со стрелками рядом с ним включает **Distribute space between items**, распределяя дочерние элементы по противоположным краям контейнера.
* **Outer space**: отдельные поля для задания пространства снаружи элемента — по одному для каждой из четырёх сторон, а также переключатель связи, позволяющий задавать одинаковое значение для всех четырёх сторон.
* **Inner space**: поля для задания пространства внутри элемента по каждой оси с переключателем связи, позволяющим задавать одинаковое значение для обеих осей.

Раздел Layout отображается только тогда, когда к выбранному элементу применён хотя бы один элемент управления раскладкой. Для обычных текстовых узлов без отступов или свойств раскладки этот раздел полностью скрывается, сохраняя интерфейс редактора лаконичным.

<div id="section-5">
  ### Обновление изображений
</div>

Выберите изображение, чтобы изменить URL или загрузить собственный файл прямо в предпросмотр.

<div id="section-6">
  ## Что можно делать
</div>

* **Быстро редактировать текст**: обновляйте текст, подписи и заголовки, не открывая исходные файлы
* **Экспериментировать с цветами**: нажимайте и настраивайте, чтобы пробовать разные цветовые схемы — не нужно подбирать подходящий CSS
* **Настраивать раскладку**: визуально точно регулируйте внутренние и внешние отступы, а также интервалы, вместо того чтобы подбирать значения в пикселях
* **Заменять изображения**: нажмите и загрузите, чтобы заменить изображения-заполнители реальными ресурсами
* **Дорабатывать дизайн**: быстро настраивайте фреймы Canvas и сравнивайте визуальные варианты без постоянного взаимодействия с Agent

<div id="section-7">
  ## Часто задаваемые вопросы
</div>

<Accordion title="Требуются ли AI-кредиты для изменений в Visual Editor?">
  Простые и однозначные правки, например изменение текста, выбор цвета или настройка отступов, не расходуют AI-кредиты. Они напрямую обновляют исходный код. Если Visual Editor обнаружит скрытую сложность, изменение будет обработано через Agent — в этом случае используются кредиты.
</Accordion>

<Accordion title="Можно ли редактировать элементы, которые отображаются в нескольких местах?">
  Да. При выборе элемента, отрисованного в цикле или повторно используемого в разных компонентах, все его экземпляры будут выделены и обновлены одновременно.
</Accordion>

<Accordion title="Почему я не могу редактировать текст некоторых элементов?">
  В составных элементах, состоящих из нескольких дочерних элементов, нельзя редактировать текст напрямую в Visual Editor. Попросите Agent внести это изменение в чате.
</Accordion>

<Accordion title="Как найти исходный код элемента?">
  Нажмите метку в левом верхнем углу выбранного элемента, чтобы перейти к соответствующему месту в исходном коде.
</Accordion>
