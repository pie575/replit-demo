Project Editor는 layout 관리 기능과 앱 개발 경험을 뒷받침하는 통합 도구를 제공합니다.
이러한 Project Editor 기능은 개발 과정의 특정 영역을 전담하므로, 설정에 시간을 쏟는 대신
만드는 일에 집중할 수 있습니다.

<div id="customizable-project-editor-layout">
  ## 사용자 지정 가능한 Project Editor layout
</div>

Project Editor의 layout 관리 도구를 사용하면 개발 환경의 구성 요소를 원하는 대로 조정할 수 있습니다.
다음과 같은 사용자 인터페이스 요소 유형으로 구성됩니다:

| Element     | 설명                                                  | 기능                                                                                     | 활용 사례                                                                         |
| ----------- | --------------------------------------------------- | -------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| **Windows** | 하나 이상의 pane을 포함하는 브라우저 tab                          | <ul><li>여러 화면에 걸쳐 배치 가능</li></ul>                                                      | <ul><li>여러 화면에 걸쳐 Project Editor 배치하기</li><li> 여러 project를 동시에 작업하기</li></ul> |
| **Panes**   | 하나 이상의 tab을 포함하는 창의 영역                              | <ul><li>가로 및 세로 분할 지원</li><li>크기 조절 및 재배치 가능</li><li>창 안에서 떠 있는 pane으로 전환 가능</li></ul> | <ul><li>코드와 Preview를 나란히 보기</li><li>개발 작업에 맞는 맞춤 layout 만들기</li></ul>         |
| **Tabs**    | 파일 편집기, Preview, Agent 등 Project Editor 도구를 하나씩만 포함 | <ul><li>pane 사이로 옮기거나 pane 안에서 순서 변경 가능</li><li>클릭 한 번으로 다른 파일이나 도구로 전환 가능</li></ul>   | <ul><li>필요할 때 원하는 도구나 파일 열기</li></ul>                                         |

<div id="file-tree">
  ## 파일 트리
</div>

파일 트리에는 Replit App의 모든 파일과 디렉터리가 표시됩니다.

<Accordion title="파일 트리에 접근하는 방법">
  왼쪽의 <img class="icon-svg" src="/assets/mirror/files-icon-f66bf1b04572.svg" alt="folder with arrows icon" width="16" height="16" data-path="images/icons/files-icon.svg" /> 폴더 아이콘을 선택하면
  파일 트리의 표시 여부를 전환할 수 있습니다.
</Accordion>

파일 트리에서는 다음 작업을 수행할 수 있습니다:

* 폴더를 선택해 내용 보기
* 파일을 선택하거나 pane으로 끌어다 놓아 파일 편집기에서 열기
* 복제, 이름 변경, 이동, 다운로드, 삭제 등의 파일 작업 수행

<div id="run-button">
  ## Run 버튼
</div>

**Run** 버튼은 Replit App에서 선택한 workflow를 실행합니다.

<Accordion title="Run 버튼 사용 방법">
  **Run** 버튼은 Project Editor 화면 상단에 있습니다. 버튼을 선택하면 workflow가 실행됩니다.

  Replit App이 실행 중일 때는 버튼 레이블이 **Stop**으로 바뀝니다. 이 버튼을 선택하면 앱이 중지됩니다.
</Accordion>

workflow를 선택하고 확인하고 관리하는 방법은 [Workflows](/ko/features/workspace-tools/workflows/)를 참조하세요.

<div id="options-menu">
  ## 옵션 메뉴
</div>

옵션 메뉴에서는 다음과 같은 유형의 layout 작업을 수행할 수 있습니다.

* **창 관리**: Replit App의 Project Editor를 새 창에서 열기
* **pane 관리**: pane 추가, pane 이동, pane 최대화, 플로팅과 고정 위치 간 전환
* **tab 관리**: 다른 tab 열기 또는 선택, tab을 다른 pane으로 이동, tab 닫기

<Accordion title="옵션 메뉴를 여는 방법">
  활성 tab의 오른쪽 상단 모서리에 있는 <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="세로 점 아이콘" height="16" width="16" data-path="images/icons/vertical-dots.svg" /> 세로 점 세 개를
  선택하면 옵션 메뉴가 열립니다.
</Accordion>

다음 스크린샷은 왼쪽 pane에 표시된 옵션 팝업 메뉴입니다.

<div id="search-bar">
  ## 검색창
</div>

검색창을 사용하면 Project Editor 내에서 파일, 텍스트 또는 도구를 찾을 수 있습니다.

<Accordion title="검색창을 여는 방법">
  1. 검색창을 열려면 상단의 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="magnifying glass icon" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 돋보기 아이콘을 선택하세요.
  2. 검색할 텍스트를 입력한 후 자동 완성 제안 중에서 선택하세요.
</Accordion>

<div id="resources-panel">
  ## 리소스 패널
</div>

리소스 패널은 RAM, CPU, 스토리지를 포함해 개발 환경의 컴퓨팅 리소스와 사용량을 표시합니다.
이 정보를 활용하면 Replit App의 게시 요구 사항을 추정하고 최적화하는 데 도움이 됩니다.

<Accordion title="리소스 패널 여는 방법">
  1. 앱 이름 옆에 있는 <img class="icon-svg" src="/assets/mirror/resources-237893692826.svg" alt="쌓인 컴퓨터 아이콘" width="16" height="16" data-path="images/icons/resources.svg" /> 리소스 아이콘을 선택해 패널을 표시하거나 숨깁니다.
  2. 자세한 내용을 보려면 **Compute** 또는 **Storage** 항목 위에 마우스를 올립니다.
</Accordion>

다음 스크린샷은 리소스 패널을 보여줍니다.
