---
title: "文件历史记录"
description: "了解如何使用 File History 的自动保存点恢复此前版本的代码。"
---

在 Project Editor 中打开一个文本文件，然后点击右下角的 **History** 按钮即可开始。

<Frame>
  <img src="/assets/mirror/history-button-afac6496660a.png" alt="打开历史记录" width="377" height="292" data-path="images/programming-ide/history-button.png" />
</Frame>

<div id="section">
  ## 查看文件的历史版本
</div>

打开 File History 后，你可以使用滚动条、箭头按钮，或**左**、**右**方向键查看文件的历史版本。

<Frame>
  <img src="/assets/mirror/history-versioning-1a055ecab411.gif" alt="滚动条演示" width="764" height="720" data-path="images/animations/history-versioning.gif" />
</Frame>

<div id="section-2">
  ## 将历史版本与当前文件对比
</div>

点击 File History 窗口左下角的 Compare Latest 开关，即可将该时间点的文件与最新版本进行内联对比。

<Frame>
  <img src="/assets/mirror/compare-history-46fb16debd3a.gif" alt="与最新版本对比的图像" width="772" height="720" data-path="images/animations/compare-history.gif" />
</Frame>

<div id="section-3">
  ## 恢复文件的历史版本
</div>

要将文件恢复到历史版本，请点击 `Restore` 按钮。无需担心，历史记录不会被删除。恢复后，该版本会作为一个新版本添加到文件历史记录中。

<Frame>
  <img src="/assets/mirror/restore-history-5f616d7f961a.webp" alt="恢复历史记录示意图" width="720" height="495" data-path="images/animations/restore-history.webp" />
</Frame>

<div id="file-history">
  ## 查看 File History 回放
</div>

使用 File History 的回放功能，你可以像看电影一样观看文件随时间演变的过程。这在录制编程过程的视频时非常有用。
