为你的应用配上自定义域名，让它成为一个真正的线上网站。

借助域名购买功能，你可以在 Replit 内一站式完成域名的搜索、购买和连接。只需几分钟，就能让已发布的应用拥有专业的网站形象。

也就是说，你可以购买类似 `my-app.com` 的域名，并自动指向你的应用。

<div id="section">
  ## 功能
</div>

域名购买可简化为应用添加专业网址的流程。无需在多个服务之间切换，您可以直接在 Replit 中完成网站形象的全部设置。

<Frame>
  <img src="/assets/mirror/replit-domains-8453291b634b.png" alt="显示已购买域名及其连接状态的域名管理界面" width="3176" height="1556" data-path="images/deployments/custom-domains/replit-domains.png" />
</Frame>

主要功能包括：

* **域名搜索和可用性检查**：您可以查看使用 `.com`、`.ai` 等热门扩展名的域名是否可用
* **一键购买**：您可以使用账户的默认付款方式，直接在 Replit 上购买域名
* **自动配置**：无需手动配置 DNS，域名会立即指向您的 Replit 应用
* **WHOIS 隐私保护**：公开的域名信息默认不会显示您的个人信息。所有域名购买均默认包含此功能
* **自定义 DNS 记录**：您可以添加 A、TXT 和 MX 记录来配置电子邮件服务提供商等服务
* **即时上线**：购买后即可通过自定义域名访问您的应用
* **自动续费**：域名会自动续费，确保您的应用持续在线，不会中断

<div id="section-2">
  ## 使用方法
</div>

<div id="section-3">
  ### 购买域名
</div>

1. 发布应用，然后前往 <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Publish icon" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publishing** 标签页
2. 选择 **Domains** 标签页
3. 选择 **Buy a domain** 开始搜索
4. 在搜索栏中输入你想要的域名
5. 查看不同后缀的可用选项
6. 选择心仪的域名并完成购买

购买域名后，系统会自动将其配置为指向你的 Replit 应用。无需任何额外设置，你即可通过自定义域名立即访问应用。

域名购买费用将通过你的 Replit 账户结算，先从账户余额中扣除，再计入使用费用。

<div id="section-4">
  ### 管理已购买的域名
</div>

域名可与已发布的应用无缝集成：

* **自动续费**：域名会自动续费，确保应用持续保持发布状态
* **统一账单**：域名费用将与其他服务一同显示在 Replit 账单中
* **转移支持**：您可根据需要在 Replit 账户之间转移域名，或将其转移至外部注册商

<div id="dns">
  ### 自定义 DNS 记录
</div>

您可以为在 Replit 购买的域名添加自定义 DNS 记录，以配置电子邮件服务提供商等附加服务。支持以下 DNS 记录类型：

* **A 记录**：将域名或子域名指向特定的 IP 地址
* **TXT 记录**：添加用于 SPF、DKIM、DMARC 等电子邮件认证服务的文本验证记录
* **MX 记录**：MX (邮件交换) 记录会告知邮件服务器应将发往您域名的电子邮件投递到哪里。设置 MX 记录后，您可以使用如 `hello@yourdomain.com` 的自定义域名邮箱地址。

要管理已购买域名的 DNS 记录：

1. 前往 Publishing <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="发布图标" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> 中的 **Domains** 标签页
2. 找到要配置的域名
3. 选择 **Edit** <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="铅笔图标" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> 图标
4. 选择 **Add DNS Record**
5. 按照服务提供商的说明输入记录类型、名称、值和 TTL

<div id="section-5">
  ### 支持的部署类型
</div>

域名购买适用于以下部署类型：

* **[Autoscale Deployments](/zh/ja/features/publishing/deployment-types#autoscale)**
* **[Reserved VM Deployments](/zh/ja/features/publishing/deployment-types#reserved-vm)**
* **[静态部署](/zh/ja/features/publishing/deployment-types#static)**

目前，你可以为个人账户已发布的应用购买域名。Replit Pro 的域名购买功能即将推出。

<div id="section-6">
  ## 常见问题
</div>

<AccordionGroup>
  <Accordion title="费用是多少？">
    域名购买涉及两项费用：

    * **注册费**：注册域名并获得 1 年所有权的初始费用 (`.ai`域名为 2 年)
    * **续费价格**：初始注册期结束后自动收取

    Replit 不会对域名购买收取额外费用。域名注册费不可退款。
  </Accordion>

  <Accordion title="如何续费我的域名？">
    Replit 会自动续费你的域名，以确保应用持续可访问。若要关闭自动续费，请打开 Publishing 工具中的 **Domains** 选项卡，选择域名，然后关闭 **Auto renewal** 开关。你也可以在同一页面查看域名的续费日期和续费价格。
  </Accordion>

  <Accordion title="如果我想离开 Replit，该怎么办？">
    你可以联系 Replit Support，将域名转移到其他注册商。根据 ICANN 规则，购买后 60 天内无法将域名转移到外部注册商。
  </Accordion>

  <Accordion title="可以在 Replit 账户之间转移域名吗？">
    可以。联系 Replit Support 即可在 Replit 账户之间转移域名。此过程无需等待 60 天。
  </Accordion>

  <Accordion title="可以为组织购买域名吗？">
    Replit Pro 和 Enterprise 套餐的域名购买功能将在初始 Beta 期结束后推出。
  </Accordion>

  <Accordion title="可以为域名添加自定义 DNS 记录吗？">
    可以！你可以为在 Replit 购买的域名添加自定义 DNS 记录。目前支持以下记录类型：

    * **A 记录**：将域名或子域名指向特定的 IP 地址
    * **TXT 记录**：为电子邮件认证和其他服务添加基于文本的验证记录
    * **MX 记录**：配置用于处理发送至你的域名的电子邮件的邮件服务器

    若要配置这些记录，请前往 Publishing 的 Domains 选项卡。有关 MX 记录邮件设置的详细说明，请参阅上方的[自定义 DNS 记录](#custom-dns-records)部分。
  </Accordion>

  <Accordion title="支持哪些域名后缀？">
    我们支持所有常见的顶级域名 (TLD) 。不支持存在地域或其他特殊限制的 TLD。
  </Accordion>

  <Accordion title="什么是 WHOIS 隐私保护？">
    注册域名时，你的联系信息 (姓名、地址、电话号码和电子邮件地址) 通常会列在名为 WHOIS 的公开数据库中，任何人都可以查询。WHOIS 隐私保护会将你的个人信息替换为注册商的通用信息，在满足法律要求的同时防止信息公开。

    在 Replit 购买的所有域名默认包含 WHOIS 隐私保护，无需额外费用。这有助于防止垃圾邮件发送者、营销人员及其他试图查找域名所有者信息的人获取你的个人信息。
  </Accordion>

  <Accordion title="如果我已经拥有域名，该怎么办？">
    若要将现有域名连接到 Replit 应用，请参阅[自定义域名](/zh/ja/features/publishing/custom-domains)文档。
  </Accordion>
</AccordionGroup>
