<div id="o-que-um-framework-para-desenvolvedores">
  ## Qu&#39;est-ce qu&#39;un framework pour développeurs ?
</div>

Les frameworks pour développeurs sont des Replit Apps publiées par la plateforme et la communauté pour servir de point de départ à d&#39;autres utilisateurs. Les frameworks officiels, créés par Replit, sont signalés par une coche à côté de leur nom :

<Frame>
  <img src="/assets/mirror/template-official-c5fe09e20415.png" alt="Frameworks officiels pour développeurs de Replit" width="1051" height="246" data-path="images/programming-ide/creating-a-template/template-official.png" />
</Frame>

Le framework [HTML, CSS, JS](https://replit.com/@replit/HTML-CSS-JS?v=1#index.html) est très populaire et peut servir de point de départ pour créer un projet en JavaScript pur. Vous pouvez le forker pour l&#39;utiliser.

<div id="templates-personalizados-para-empresas">
  ## Templates personnalisés pour les entreprises
</div>

Les organisations Enterprise peuvent créer des [templates personnalisés](/fr/pt/teams/custom-templates) qui s&#39;affichent comme options sélectionnables dans la boîte de réception de l&#39;Agent pour tous les membres de l&#39;organisation. Les templates personnalisés vont plus loin que les frameworks : ils intègrent des instructions d&#39;Agent propres à l&#39;entreprise, des compétences et un contexte de projet préconfiguré. Consultez le [guide des templates personnalisés](/fr/pt/teams/custom-templates) pour plus de détails.
