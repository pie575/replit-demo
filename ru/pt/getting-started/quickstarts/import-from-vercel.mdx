<div id="importar-do-vercel">
  ## Импорт из Vercel
</div>

⏰ *Примерное время: три минуты*

Импортируйте проект из Vercel в Replit, подключив связанный с ним репозиторий GitHub.

Чтобы узнать обо всех вариантах импорта, включая импорт с других платформ, таких как GitHub, Figma, Bolt и Lovable, ознакомьтесь с [документацией функции импорта](/ru/pt/core-concepts/project-editor/app-setup/import).

<div id="antes-de-comear">
  ## Перед началом
</div>

* Проект Vercel, подключённый к GitHub
* Доступ к связанному репозиторию GitHub
* Учётная запись Replit

<div id="passos-de-importao">
  ## Шаги импорта
</div>

1. Откройте [replit.com/import](https://replit.com/import).
2. Выберите **Vercel**.
3. Подключите учётную запись GitHub.
4. Выберите репозиторий проекта Vercel.
5. Добавьте все запрошенные секреты и переменные окружения.
6. Выберите **Импортировать**.

<div id="o-que-importado">
  ## Что импортируется
</div>

* Файлы проекта и структура каталогов
* Конфигурация зависимостей и фреймворка
* Настройки запуска и сборки для Replit

<div id="o-que-no-importado">
  ## Что не импортируется
</div>

* Текущие значения переменных окружения
* Пользовательские домены
* Специфичное для Vercel поведение edge или middleware
* Внешние настройки аналитики или мониторинга
