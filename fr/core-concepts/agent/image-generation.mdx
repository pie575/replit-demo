Transformez vos idées en images personnalisées, illustrations et graphiques qui correspondent parfaitement aux besoins de votre projet. Que vous construisiez un site web, une application mobile ou tout autre projet créatif, Agent génère des images qui donnent vie à votre vision.

La génération d'images permet aux créateurs de produire du contenu visuel unique sans avoir besoin de compétences en design ou d'outils externes. Générez tout, des icônes et illustrations aux arrière-plans et éléments d'interface utilisateur, directement dans votre workflow de développement.

## Fonctionnalités

Créez des applications visuellement attrayantes avec la génération d'images d'Agent. Cela élimine le besoin de photos de stock, d'outils de design externes ou de faire appel à des designers pour du contenu visuel de base. Que vous créiez un site portfolio, un jeu ou une interface d'application mobile, la génération d'images fournit des visuels personnalisés adaptés à votre projet.

Agent peut effectuer les actions de génération d'images suivantes :

* **Création d'images personnalisées** : Générez des images basées sur des descriptions et spécifications détaillées
* **Adaptation de style** : Créez des images dans divers styles artistiques, du réaliste au cartoon
* **Intégration au projet** : Ajoutez de manière transparente les images générées directement à la base de code de votre application
* **Raffinement itératif** : Modifiez et améliorez les images en fonction de vos retours

## Utilisation

La génération d'images est intégrée à Agent — rien à activer. Ouvrez n'importe quelle application Replit avec Agent activé et demandez à Agent de créer le contenu visuel dont vous avez besoin. Agent détermine automatiquement quand générer des images en fonction de vos demandes, en créant des images personnalisées correspondant à vos spécifications.

### Quand Agent utilise la génération d'images

Agent déclenche la génération d'images lorsque vous demandez du contenu visuel pour vos projets :

| Cas d'usage                       | Exemple de prompt                                                               |
| --------------------------------- | ------------------------------------------------------------------------------- |
| **Icônes et logos d'application** | « Génère un logo moderne pour mon application de suivi fitness »                |
| **Arrière-plans de site web**     | « Crée un arrière-plan à dégradé subtil pour mon site portfolio »               |
| **Ressources de jeu**             | « Génère des sprites en pixel art pour mon jeu de plateforme »                  |
| **Illustrations d'interface**     | « Crée une illustration pour l'écran d'état vide de mon application »           |
| **Visuels marketing**             | « Génère une image hero pour ma page d'atterrissage »                           |
| **Maquettes de produit**          | « Crée des maquettes de mon application fonctionnant sur différents appareils » |

### Bonnes pratiques pour la génération d'images

Suivez ces recommandations pour obtenir les meilleurs résultats avec la génération d'images d'Agent :

**Soyez précis et descriptif**

* Incluez des détails sur le style, les couleurs, la composition et l'ambiance
* Précisez les dimensions ou les ratios d'aspect si pertinent
* Mentionnez l'utilisation prévue (icône, arrière-plan, illustration, etc.)

**Itérez et affinez**

* Commencez par une description de base et affinez en fonction des résultats
* Demandez à Agent de modifier des aspects spécifiques des images générées
* Demandez des variations pour explorer différentes directions créatives

**Tenez compte du style de votre projet**

* Maintenez une cohérence visuelle dans toute votre application
* Précisez des préférences de style correspondant à votre marque ou système de design
* Demandez des images qui complètent vos éléments visuels existants

### Intégration au projet

Agent intègre de manière transparente les images générées dans votre base de code :

* **Création automatique de fichiers** : Les images générées sont enregistrées directement dans les fichiers de votre projet
* **Mises à jour du code** : Agent met à jour votre code pour référencer les nouveaux fichiers d'images
* **Organisation des ressources** : Les images sont placées dans des répertoires logiques au sein de la structure de votre projet

Ce workflow simplifié signifie que vous pouvez générer et implémenter du contenu visuel sans quitter votre environnement de développement.

<Note>
  La génération d'images de Replit est alimentée par [Imagen 4 de Google](https://deepmind.google/models/imagen/), un modèle de synthèse d'images de texte de pointe qui excelle dans la création d'images photoréalistes de haute qualité avec des détails fins et des capacités améliorées de rendu de texte.
</Note>
