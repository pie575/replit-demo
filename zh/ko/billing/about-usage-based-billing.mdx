发布包含三种基于使用量的计费类型：

1. 出站数据传输
2. Autoscale 计算单元
3. 请求数

您可以在**设置**中的**账户** → **账户用量**里查看使用情况。计费按月进行，或在累计费用超出每月积分额度时触发。Replit Core 和 Pro 用户每月均可获得这些资源的使用额度。

如果需要超出每月订阅额度的额外积分，可在计费页面购买积分包。有关积分包的更多信息，请参阅[支出管理](/zh/ko/billing/managing-spend)。

<div id="section">
  # 发布
</div>

<div id="1">
  ## 1. 发布出站数据传输
</div>

此类用量按字节计费，Replit Core 和 Pro 用户每月可获得一定额度。只有出站 (发送) 数据计入该额度，超出部分将产生额外费用。而入站 (接收) 数据始终免费。

| 订阅          | 额度                                                 |
| ----------- | -------------------------------------------------- |
| Replit Core | 100 GiB                                            |
| Replit Pro  | 参见 [Replit Pro 价格](https://www.replit.com/pricing) |

该额度适用于[静态](/zh/ko/features/publishing/deployment-types#static)、[Autoscale](/zh/ko/features/publishing/deployment-types#autoscale)、[Reserved VM](/zh/ko/features/publishing/deployment-types#reserved-vm) 和[预定](/zh/ko/features/publishing/deployment-types#scheduled)部署。

有关出站数据传输的当前价格，请参见[价格页面](https://www.replit.com/pricing)。

***

<div id="2">
  ## 2. 计算单元
</div>

Autoscale 部署按计算单元计费，计算单元综合考虑一段时间内的 CPU 和 RAM 使用量。

超出部分按计算单元计费，计费粒度精确到单个计算单元。计算单元的当前价格请参阅[价格页面](https://www.replit.com/pricing)。

Autoscale 部署中的 RAM 秒和 CPU 秒按以下方式换算为计算单元：

| 资源      | 计算单元  |
| ------- | ----- |
| RAM 1 秒 | 2 单元  |
| CPU 1 秒 | 18 单元 |

静态部署不消耗计算单元，仅对超出[指定额度](#)的出站数据传输计费。

[详细了解 Autoscale 部署](/zh/ko/features/publishing/deployment-types#autoscale)。

***

<div id="3">
  ## 3. 请求
</div>

Autoscale 部署还会将处理的请求数量计入费用。

有关请求的当前定价，请参阅[价格页面](https://www.replit.com/pricing)。

<div id="section-2">
  # 数据库
</div>

Replit 仅对[生产数据库](/zh/ko/features/data-and-storage/development-and-production)的使用收费。开发数据库始终免费，且包含在所有 Replit 应用中。有关开发数据库的更多信息，请参阅[开发数据库](/zh/ko/features/data-and-storage/sql-database)。

Replit PostgreSQL 是完全托管的无服务器数据库，可轻松实现高可用性和免维护运行。生产数据库按实际用量计费，可显著节省成本。

生产 PostgreSQL 数据库按以下两项使用指标计费：

* **[计算时间](#compute-time)**：每小时消耗的计算资源量。
* **[数据存储](#data-storage)**：存储的数据总量 (含历史数据) 。

您可以在 **设置** → **账户** → **账户用量** 中查看当前的资源使用情况，包括生产数据库的用量。

<div id="section-3">
  ## 计算时间
</div>

计算时间取决于数据库在指定计费周期内保持活跃状态的小时数。数据库在收到请求时,以及最后一次请求之后的 5 分钟内,均被视为处于活跃状态。如果数据库持续空闲 5 分钟,则会被挂起并转为非活跃状态。

<div id="section-4">
  ## 数据存储
</div>

数据存储是指账户下所有数据库中保存的数据总量,以吉比字节(GiB)为单位计量。存储量按每月使用的存储峰值计算。即使没有任何数据,每个 PostgreSQL 数据库也会占用 33MB 存储空间,这是 Postgres 服务器的基础存储开销。

<Note>每个生产数据库的存储总量上限为 10 吉比字节(GiB)。开发数据库则为每个 Replit 应用提供 20 GiB 的免费存储空间。</Note>
