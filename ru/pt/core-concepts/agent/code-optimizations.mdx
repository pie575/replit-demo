export const YouTubeEmbed = ({videoId, title = "Видео на YouTube", startAt}) => {
  if (!videoId) {
    return null;
  }
  let url = "https://www.youtube.com/embed/" + videoId;
  if (startAt) {
    url = url + "?start=" + startAt;
  }
  return <Frame>
      <iframe src={url} title={title} allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowFullScreen></iframe>
    </Frame>;
};

**Оптимизация кода** (ранее «Уровень автономности») — это переключатель в разделе **Расширенные настройки** выпадающего меню настроек Agent. Когда она **включена**, Agent проверяет собственный код и упрощает дальнейшую работу, повышая точность и снижая затраты за счёт предотвращения ошибок. Когда она **выключена**, ИИ практически не проверяет код или не проверяет его вовсе, а ручной контроль максимален. Доступно в [платных тарифах](https://replit.com/pricing).

Мы рекомендуем оставлять оптимизацию кода **включённой** для большинства проектов, чтобы повысить качество кода и сократить количество дорогостоящих доработок.

<div id="uso">
  ## Использование
</div>

Оптимизации кода доступны в выпадающем меню настроек Agent при работе над любым проектом. Настройка применяется к текущей беседе, влияет на то, как Agent решает последующие задачи, и доступна в режимах Economy и Power.

<Accordion title="Как открыть оптимизации кода">
  1. Откройте проект в редакторе проектов
  2. Откройте выпадающее меню настроек Agent в поле ввода Chat
  3. Разверните **расширенные настройки** и найдите **Оптимизации кода**
  4. Включите или отключите их по своему усмотрению
</Accordion>

<div id="quando-usar">
  ### Когда использовать
</div>

* **Включено**: рекомендуется для большинства задач. Agent проверяет собственный код, находит ошибки и помогает сократить переделки. Каждая задача выполняется чуть дольше, зато качество выше.
* **Отключено**: используйте, когда нужна максимальная скорость и полный ручной контроль — например, для быстрых правок или если вы предпочитаете сами просматривать каждое изменение.
