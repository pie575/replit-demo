<div id="agent">
  ### Агент безопасности проверяет всю кодовую базу
</div>

**Агент безопасности** — новый ИИ-ревьюер, который проверяет весь проект, а не только зависимости. Он строит модель угроз, сопоставляет маршруты и потоки данных, выполняет статический анализ с помощью Semgrep и HoundDog.ai, а затем использует LLM, чтобы определить, какие результаты действительно могут быть использованы для атак в контексте вашего приложения. После завершения проверки Агент безопасности группирует подтвержденные результаты в параллельные задачи, которые Replit Agent может исправить за один проход.

<div id="cve-auto-protect">
  ### CVE Auto-Protect автоматически устраняет критические уязвимости
</div>

Когда в пакете, от которого зависит App, раскрывается новая критическая CVE, **CVE Auto-Protect** обнаруживает затронутые проекты среди всех ваших проектов, поручает Agent подготовить исправление в фоновом режиме, запускает тесты, чтобы убедиться, что ничего не нарушено, и отправляет уведомление со ссылкой для проверки. Вы сохраняете контроль — ничего не будет опубликовано, пока вы не одобрите исправление.

Это позволяет устранить уязвимость в App за считаные минуты после её раскрытия, не дожидаясь, пока вы обнаружите её самостоятельно.

Подробнее о [CVE Auto-Protect](/ru/core-concepts/security/project-security-center#auto-protect).

<div id="iosandroid">
  ### Предпросмотр в симуляторе iOS или эмуляторе Android
</div>

<Frame>
  <video autoPlay muted loop playsInline src="/assets/mirror/ios-emulator-9013ff1b602f.mp4" />
</Frame>

Если ваш проект содержит мобильное App, теперь вы можете запускать **симулятор iOS** или **эмулятор Android** прямо в рабочем пространстве на панели предварительного просмотра. Xcode, Android Studio и физическое устройство не нужны. Создайте мобильное приложение с помощью Agent, выберите устройство в раскрывающемся списке на панели предварительного просмотра и взаимодействуйте с ним так, будто держите в руках реальное устройство. Когда Agent вносит изменения, они применяются в симуляторе с горячей перезагрузкой.

Функция доступна платным разработчикам планов Core, Pro и Enterprise, использующим Chrome, Safari или браузеры на базе Chromium. Firefox не поддерживает мобильные симуляторы.

Подробнее см. в разделе [Предпросмотр в симуляторе или эмуляторе](/ru/ja/features/artifact-types/building-mobile-apps#preview-on-a-simulator-or-emulator).

<div id="app">
  ### Добавление мобильного App в старые проекты
</div>

<Frame>
  <img src="/assets/mirror/multi-artifact-update-approval-f6fa8b70a100.png" alt="Панель чата Agent с карточкой подтверждения «Обновить проект для создания мобильного App», предложением на $5 кредитов и кнопками «Не сейчас» / «Обновить проект»." width="991" height="589" data-path="images/replitai/multi-artifact-update-approval.png" />

Проекты, созданные до выхода Agent 4, теперь можно обновить с поддержкой нескольких артефактов — то есть добавить мобильное App, питч-деку или любой другой артефакт в проект, который раньше поддерживал только один артефакт. При реорганизации проекта Agent сохраняет URL, данные, секреты и деплои. За первые 48 часов после расширенного запуска было перенесено более 200 проектов.

Подробнее: [Обновление старых проектов для поддержки нескольких артефактов](/ru/ja/features/projects-and-artifacts/updating-projects-for-multiple-artifacts).

<div id="plaid">
  ### Коннектор Plaid теперь доступен
</div>

Коннектор **Plaid** позволяет подключаться к более чем 12 000 финансовых учреждений. После того как администратор команды один раз настроит учетные данные в разделе **Integrations**, пользователи App смогут подтверждать свои банковские счета через Plaid Link. Токены доступа ограничены областью действия каждого пользователя, поэтому данные остаются конфиденциальными.

Вы можете создавать персональных финансовых консультантов на основе реальных данных о транзакциях, трекеры инвестиционных портфелей в реальном времени с подключением к брокерским счетам и многое другое. Демонстрацию и инструкции по настройке смотрите на [партнёрской странице Replit x Plaid](https://replit.com/partners/plaid).

Подробнее см. в разделе [Управление коннекторами](/ru/ja/replitai/managing-connectors).
