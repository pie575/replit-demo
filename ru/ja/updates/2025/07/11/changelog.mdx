<div id="replitmd">
  ### Документация replit.md
</div>

С помощью `replit.md` можно настроить поведение Agent. Это специальный файл конфигурации, который помогает Agent понимать настройки проекта, стиль кода и архитектуру. Agent автоматически создаёт этот файл, следуя проверенным лучшим практикам, и использует его для создания приложения в точном соответствии с вашими требованиями. Вы можете задавать Agent контекст проекта, определять стандарты кода, указывать предпочитаемый технологический стек и настраивать параметры общения — всё в одном месте.

<div id="section-3">
  ### Индикатор приватности развёртывания
</div>

Новый визуальный индикатор на панели деплоя позволяет быстро определить, является ли деплой публичным или приватным. Это помогает избежать путаницы и точно понимать, кто может получить доступ к вашему опубликованному приложению.

<div id="agent">
  ### Улучшение множественных вызовов инструментов в Agent
</div>

Улучшенная система мультиинструментальных вызовов снижает затраты на Agent на 15% и ускоряет получение результатов на 30%. Agent теперь эффективнее выполняет пакетную обработку операций и интеллектуальнее обрабатывает ошибки инструментов, обеспечивая прежнее качество результатов при меньших затратах ресурсов.
