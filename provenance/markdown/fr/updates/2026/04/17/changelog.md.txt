### Nouveau menu déroulant des modes Agent

Le sélecteur de mode Agent dans la saisie du chat est désormais un contrôle segmenté plus simple. Choisissez entre Lite, Economy et Power directement depuis la barre d'outils, et accédez à Turbo via les Paramètres avancés lorsque vous en avez besoin.

Nouveautés :

* **Contrôle segmenté dans la barre d'outils.** Lite, Economy et Power sont placés côte à côte, ce qui rend évident le mode actif et la façon d'en changer.
* **Raccourci clavier.** Appuyez sur **⌘+Shift+I** (Ctrl+Shift+I sur Windows) pour faire défiler les modes sans toucher à votre souris.
* **Turbo mis en évidence en orange.** Turbo est le mode le plus rapide mais coûte plus cher ; il ressort donc dans l'interface pour garder le compromis de coût visible.
* **Paramètres avancés repliés par défaut.** Les contrôles pour les tests, la révision de code et Turbo se trouvent derrière les **Paramètres avancés** pour que la vue principale reste épurée.
* **Le mode Max a été retiré.** Utilisez Power pour les builds les plus performants, ou activez Turbo dans les Paramètres avancés lorsque vous voulez la réponse la plus rapide.

### Agent suggère des tâches de suivi

<Frame>
  <video autoPlay muted loop playsInline src="https://cdn.replit.com/sanity/replit-suggested-tasks.mp4" />
</Frame>

Agent propose désormais des **tâches de suivi** après avoir terminé son travail, en utilisant le contexte complet de votre projet pour suggérer ce qu'il faut construire ensuite. Trois types de suggestions apparaissent sous chaque tâche terminée :

* **Nouvelles fonctionnalités à construire** — des capacités qui s'associent naturellement à ce que vous venez de livrer
* **Améliorations de performance** — des optimisations qu'Agent a remarquées en travaillant sur la tâche
* **Améliorations de l'expérience utilisateur** — des finitions qui complètent la fonctionnalité

Examinez chaque suggestion, sélectionnez **Accepter** sur celles que vous souhaitez, et Agent les exécute en arrière-plan pendant que vous continuez à construire. Masquez les suggestions dont vous n'avez pas besoin avec **Masquer les tâches suggérées** dans la colonne Terminé, et récupérez-les à tout moment.

En savoir plus sur les [suggestions de tâches de suivi](/fr/features/agent/follow-up-tasks).

## Espace de travail

### Améliorations de la page Projets

Trois améliorations de confort ont atterri sur la page Projets :

* **Aperçus d'artefacts sur chaque carte.** Chaque carte de projet affiche désormais de petites icônes pour chaque artefact qu'elle contient. Survolez n'importe quelle icône pour prévisualiser la capture d'écran de cet artefact sans ouvrir le projet.
* **Tri par défaut par dernière ouverture par vous.** La page met désormais en avant les projets sur lesquels *vous* avez travaillé le plus récemment, afin que votre travail en cours reste visible dans les espaces de travail d'équipe chargés.
* **Épinglage personnel.** Épinglez les projets sur lesquels vous revenez souvent. Les épingles sont privées et n'affectent pas ce que voient les autres membres de votre espace de travail.

### Filtrer la page Projets par artefact

Vous pouvez filtrer votre page Projets par artefact à l'aide du menu déroulant **Build type**. Sélectionnez le type d'artefact (par exemple, Slides) pour ne voir que les projets qui le contiennent.

## Équipes et Enterprise

### Groupes personnalisés pour les organisations SCIM

Les organisations ayant activé le provisionnement SCIM peuvent désormais créer des groupes personnalisés dans Replit en parallèle de leurs groupes synchronisés par l'IdP. Utilisez des groupes personnalisés pour des accès par projet, des attributions de permissions ponctuelles ou toute structure qui n'est pas reflétée dans votre fournisseur d'identité.

Les groupes synchronisés par SCIM restent gérés via votre fournisseur d'identité — les groupes personnalisés sont gérés directement dans Replit par les administrateurs d'organisation.

En savoir plus sur [SCIM](/fr/teams/identity-and-access-management/scim#créer-des-groupes-personnalisés-en-parallèle-de-scim).
