App Storage는 Replit에 기본 내장된 객체 스토리지로, 이미지, 동영상, 문서 같은 업로드 파일을 앱에서 손쉽게 호스팅하고 저장할 수 있습니다.
버킷은 파일과 같은 객체를 저장하는 컨테이너입니다. 버킷에는 접근 정책이 포함되어 있어, 사용자나 애플리케이션이 버킷 내 콘텐츠에 수행할 수 있는 작업을 제한할 수 있습니다.

<Info>
  <strong>Object Storage</strong>의 이름이 <strong>App Storage</strong>로 변경되었습니다. 기능은 그대로이며, 기존 버킷과 권한, 프로그래밍 방식의 접근도 계속 정상적으로 작동합니다.
</Info>

App Storage를 활용하면 다음과 같은 앱을 만들 수 있습니다:

* **사진 공유 플랫폼**: builder가 이미지를 업로드하고 저장하고 표시하도록 지원
* **동영상 스트리밍 서비스**: 동영상 업로드를 처리하고 시청자에게 콘텐츠 제공
* **문서 관리 시스템**: builder의 파일을 안전한 접근 권한으로 저장하고 정리
* **포트폴리오 사이트**: 안정적으로 로드되는 미디어 파일로 작업물 소개
* **파일 백업 서비스**: builder의 중요한 파일을 위한 클라우드 스토리지 제공

<Frame>
  <img src="/assets/mirror/object-storage-overview-c955d7e5bdb5.jpg" alt="screenshot of the App Storage tool" width="1920" height="1080" data-path="images/cloud-services/object-storage-overview.jpg" />
</Frame>

<Note>
  앱에서 어떤 종류의 파일을 다뤄야 하는지 자세히 설명하면서 **Agent**에게 App Storage 추가를 요청하세요. Agent가 integration을 설정하고 필요한 버킷을 생성한 뒤, authentication과 access controls 같은 고급 기능을 갖춰 파일을 업로드하고 저장하고 가져올 수 있도록 앱을 업데이트합니다.
</Note>

App Storage 도구를 사용하면 개발 환경과 production 환경 간에, 또는 다른 Replit App과 데이터를 매끄럽게 공유할 수 있습니다.

<div id="features">
  ## 기능
</div>

<Info>
  App Storage는 Google Cloud Storage(GCS)를 기반으로 합니다.
  덕분에 업계 최고 수준의 uptime, 가용성, 보안을 그대로 활용할 수 있습니다.
</Info>

App Storage는 Replit Apps에 다음과 같은 기능을 제공합니다:

* **영구 클라우드 스토리지**: published app과 사용자가 계속 접근할 수 있는 파일을 저장합니다
* **확장 가능한 파일 처리**: 저장 용량 limit 걱정 없이 늘어나는 데이터 요구를 처리합니다
* **앱 간 데이터 공유**: 분산 아키텍처를 위해 여러 Replit Apps에서 bucket을 공유합니다
* **프로그래밍 방식 접근**: 직관적인 API로 파일을 upload, download하고 관리합니다
* **강화된 Agent integration**: Agent가 advanced 설정으로 App Storage를 구성하고, 기존 설정을 점검하며, authentication과 access controls를 갖춘 backend 및 frontend 코드 전체를 생성하도록 맡길 수 있습니다

Replit Apps에서 App Storage를 활용하는 몇 가지 예는 다음과 같습니다:

* builder 프로필 사진 및 미디어 업로드 저장
* 이커머스 사이트의 상품 이미지 serve
* 양식 제출용 문서 업로드 처리
* 파일 공유 및 협업 기능 구현
* 미디어 라이브러리를 갖춘 콘텐츠 관리 시스템 구축

<Tip>
  **강화된 Agent integration**: [Replit Agent](/ko/features/agent/overview)에 prompt를 보내 앱에 App Storage를 자동으로 추가할 수 있습니다! 이제 Agent는 Object Storage를 설정하고, Configurations를 점검하며, authentication과 access controls 같은 고급 기능을 갖춘 backend 및 frontend 코드 전체를 생성할 수 있습니다. prompt에 &quot;App Storage&quot; 또는 &quot;file storage&quot;라고 언급하기만 하면 됩니다.

  <AiPrompt>Add App Storage to my app to store files</AiPrompt>
  <AiPrompt>Create a photo gallery app with App Storage for images</AiPrompt>
  <AiPrompt>Set up App Storage with authentication for user file uploads</AiPrompt>

  [Agent integrations](/ko/features/integrations/overview#data-storage--management)에 대해 자세히 알아보고 사용 가능한 App Storage prompts를 모두 확인해 보세요.
</Tip>

<div id="usage">
  ## Usage
</div>

<Note>
  bucket과 그 안의 객체에 접근하려면 Replit App이 Google Cloud Storage에 인증해야 합니다.
  공식 Replit App Storage 클라이언트 라이브러리를 사용하면 인증이 자동으로 처리됩니다.
</Note>

App Storage 도구는 Project Editor에서 바로 사용할 수 있습니다.

<Accordion title="App Storage 도구에 접근하는 방법">
  왼쪽 **Tool dock**에서:

  1. <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="All tools 아이콘" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**를 선택해 Project Editor 도구 목록을 확인합니다.
  2. <img class="icon-svg" src="/assets/mirror/object-storage-monoochrome-icon-aaba8f517280.svg" alt="App Storage 아이콘" width="16" height="16" data-path="images/icons/object-storage-monoochrome-icon.svg" /> **App Storage**를 선택합니다.

  **Search bar**에서:

  1. 상단의 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="돋보기 아이콘" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 돋보기를 선택해 검색 도구를 엽니다.
  2. &quot;App Storage&quot;를 입력해 도구를 찾은 뒤 결과에서 선택합니다.
</Accordion>

새 스토리지 bucket을 Replit App에 연결하려면 bucket을 생성하세요.

<Accordion title="bucket을 생성하는 방법">
  **App Storage** 도구에서:

  1. **Create new bucket**을 클릭합니다.
  2. **Name** 필드에 bucket 이름을 입력하고 **Create bucket**을 선택합니다.

  App Storage tab은 다음 스크린샷과 같은 모습이 됩니다:

  <Frame>
    <img src="/assets/mirror/object-storage-empty-bucket-3462e2efb1bc.png" alt="App Storage 도구 스크린샷" width="2790" height="1218" data-path="images/databases/object-storage-empty-bucket.png" />
  </Frame>

  bucket을 추가로 생성하려면 **App Storage** tab 왼쪽 상단의 bucket 드롭다운 메뉴를 열고 **Create new bucket**을 선택하세요.
</Accordion>

다음 섹션에서는 App Storage 도구의 bucket 및 객체 관리 옵션을 설명합니다.

  ### bucket 선택
</div>

아래 스크린샷과 같이, 선택된 bucket에는 이름 옆에 체크 표시가 나타납니다:

<div id="access-the-bucket-id">
  ### 버킷 ID 확인하기
</div>

**App Storage** 탭 상단의 드롭다운에서 **Settings** 보기를 선택하면 **Bucket ID**를 확인할 수 있습니다.
Bucket ID는 버킷을 고유하게 식별하는 값으로, 작업을 수행하려면 코드에서 이 값을 참조해야 합니다.

버킷이 여러 개라면 왼쪽 상단의 드롭다운 메뉴에서 원하는 버킷을 선택하세요.

다음 스크린샷은 &quot;FileVault Bucket One&quot; 버킷의 Bucket ID를 보여줍니다.

<Frame>
  <img src="/assets/mirror/bucket-id-42a44cef1025.png" alt="App Storage 도구 스크린샷" width="1596" height="428" data-path="images/databases/bucket-id.png" />

<div id="upload-or-download-objects">
  ### 객체 업로드 또는 다운로드
</div>

선택한 bucket에 객체를 업로드하려면 다음 단계를 따르세요.

1. **App Storage** tab에서 **Objects** 보기로 이동합니다.
2. <img class="icon-svg" src="/assets/mirror/upload-file-5894be4232ce.svg" alt="파일 업로드 아이콘" width="16" height="16" data-path="images/icons/upload-file.svg" /> **Upload files**를 선택하거나, 폴더에 있는 모든 파일을 업로드하려면 <img class="icon-svg" src="/assets/mirror/upload-folder-fc87519bedf9.svg" alt="폴더 업로드 아이콘" width="16" height="16" data-path="images/icons/upload-folder.svg" /> **Upload folder**를 선택합니다.
   그런 다음 파일 대화 상자에서 업로드할 파일을 하나 이상 선택합니다.
   또는 bucket의 내용이 표시되는 영역으로 파일이나 폴더를 끌어다 놓아도 됩니다.

선택한 bucket에서 객체를 다운로드하려면 다음 단계를 따르세요.

1. **App Storage** tab에서 **Objects** 보기로 이동합니다.
2. 파일 오른쪽에 있는 <img class="icon-svg" src="/assets/mirror/download-icon-c7b527953d65.svg" alt="다운로드 아이콘" width="16" height="16" data-path="images/icons/download-icon.svg" /> 다운로드 아이콘을 선택하면 파일이 다운로드됩니다.

<div id="organize-objects-in-folders">
  ### 폴더로 객체 정리하기
</div>

선택한 bucket에 폴더를 만들려면 다음과 같이 진행합니다.

1. **App Storage** tab에서 **Objects** 보기로 이동합니다.
2. **Objects** 보기에서 <img class="icon-svg" src="/assets/mirror/create-folder-c9acf112a042.svg" alt="create folder icon" width="16" height="16" data-path="images/icons/create-folder.svg" /> **Create Folder**를 선택합니다.
3. 폴더 이름을 입력합니다.

**Objects** 보기에서 폴더에 객체를 추가하려면 객체를 원하는 폴더로 끌어다 놓습니다.

객체를 상위 폴더로 옮기려면 객체 목록 위 헤더에 표시된 폴더 이름으로 끌어다 놓습니다.
다음 애니메이션은 &quot;videos&quot; 폴더에 있는 &quot;product&#95;demo.mov&quot; 파일을 상위 &quot;Objects&quot; 폴더로 옮기는 과정을 보여줍니다.

<div id="delete-objects-or-buckets">
  ### 객체 또는 bucket 삭제
</div>

<Warning>
  삭제 작업은 되돌릴 수 없습니다. 진행하기 전에 중요한 데이터는 반드시 백업하세요.
</Warning>

객체를 영구적으로 삭제하려면 다음과 같이 진행하세요.

1. **App Storage** tab에서 **Objects** 보기로 이동합니다.
2. 삭제하려는 객체 옆의 <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="휴지통 icon" width="16" height="16" data-path="images/icons/trash-icon.svg" /> 휴지통 icon을
   선택합니다.
3. 확인 대화 상자에서 삭제를 확인합니다.

bucket과 그 안의 모든 객체를 삭제하려면 다음과 같이 진행하세요.

1. **App Storage** tab에서 **Settings** 보기로 이동합니다.
2. 왼쪽 상단의 bucket 드롭다운 메뉴에서 삭제하려는 bucket이 선택되어 있는지 확인합니다.
3. <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="휴지통 icon" width="16" height="16" data-path="images/icons/trash-icon.svg" /> **Delete Bucket**을 선택합니다.
4. 확인 대화 상자에서 삭제를 확인합니다.

<div id="bucket-access-management">
  ### 버킷 접근 관리
</div>

Replit은 사용자가 생성한 모든 bucket을 계정에 연결하여 모든 Replit Apps에서 사용할 수 있도록 합니다. bucket을 생성한 Replit App에는 접근 권한이 자동으로 부여됩니다.

특정 bucket에 접근할 수 있는 Replit Apps를 직접 지정할 수 있어 데이터를 효율적이고 안전하게 공유할 수 있습니다.

계정 내 다른 앱의 bucket에 대한 접근 권한을 Replit App에 부여하려면 다음과 같이 하세요.

1. App Storage tab 왼쪽 상단의 bucket 메뉴에서 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="돋보기 아이콘" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" />
   **Add an existing bucket**을 선택합니다.
2. **Choose a Bucket** 대화 상자에서 추가할 bucket을 선택한 후 **Add Bucket to Repl**을 선택합니다.

<Frame>
  <img src="/assets/mirror/choose-bucket-dialog-b709aa247a85.png" alt="버킷 선택 대화 상자 스크린샷" width="1115" height="457" data-path="images/databases/choose-bucket-dialog.png" />
</Frame>

bucket에 대한 Replit App의 접근 권한을 해제하려면 다음과 같이 하세요.

1. **App Storage** tab에서 **Settings** 보기로 이동합니다.
2. tab 왼쪽 상단의 bucket 드롭다운에서 bucket 이름을 선택합니다.
3. **Remove Bucket from Repl**을 선택한 후 확인 대화 상자에서 제거를 확인합니다.

<div id="programmatic-access-to-app-storage">
  ### App Storage에 프로그래밍 방식으로 접근하기
</div>

Replit App에서 App Storage에 접근하려면 다음 라이브러리 중 하나를 사용하세요.

* Replit App Storage SDK(JavaScript 및 Python 지원)
* <a href="https://cloud.google.com/storage/docs/reference/libraries" target="_blank">Google Cloud Storage 클라이언트 라이브러리</a>

클라이언트 라이브러리 사용 방법은 다음 자료를 참고하세요.

* [JavaScript App Storage SDK](/ko/features/sdks/object-storage-javascript-sdk/): JavaScript SDK의 Client 레퍼런스
* [Python App Storage SDK](/ko/features/sdks/object-storage-python-sdk/): Python SDK의 Client 레퍼런스
* [Google Cloud Python SDK 예제 앱](https://replit.com/@matt/GCS-Python-Uploads?v=1): 이 앱을 remix하여 Google Cloud Python SDK로 객체를 관리해 보세요
