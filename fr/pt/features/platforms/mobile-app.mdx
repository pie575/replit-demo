L&#39;[application mobile Replit](https://replit.com/mobile) met vos projets dans votre poche : reprenez là où vous vous étiez arrêté ou démarrez un nouveau projet de zéro, où que vous soyez. Échangez avec Agent, modifiez votre projet et publiez-le sur le web, le tout dans une interface pensée pour le tactile.

<div id="como-comear">
  ## Pour commencer
</div>

Suivez ces étapes pour installer l&#39;application et créer un projet.

<div id="instale-o-app">
  ### Installez l&#39;application
</div>

1. Rendez-vous sur la [page de téléchargement de l&#39;application mobile](https://replit.com/mobile) et installez l&#39;application correspondant au système d&#39;exploitation de votre appareil mobile.
2. Ouvrez l&#39;application, puis créez un compte ou connectez-vous avec un compte existant.
   Si vous créez un nouveau compte, vous devrez vérifier votre adresse e-mail pour finaliser le processus.

<div id="comece-a-construir">
  ### Commencez à créer
</div>

L&#39;écran d&#39;accueil vous propose deux options :

* **Reprenez là où vous en étiez** : ouvrez un projet dans **Recent Projects** et poursuivez votre travail.
* **Partez de zéro** : décrivez ce que vous souhaitez dans la zone de prompt, puis envoyez. Agent commence aussitôt à créer votre projet.

Pour partir d&#39;un template prêt à l&#39;emploi ou d&#39;un code existant, appuyez sur ⋮ en haut à droite et choisissez **Remix a Template** ou **Import from GitHub**.

<Note>
  Vous créez une app native pour iOS ? Utilisez le Project Editor sur [replit.com](https://replit.com) pour créer, visualiser en Preview, compiler ou publier votre app. La création d&#39;apps mobiles natives est disponible dans l&#39;app Replit pour Android, là où elle est prise en charge.
</Note>

<div id="recursos-mobile">
  ## Fonctionnalités mobiles
</div>

<div id="entrada-por-voz">
  ### Saisie vocale
</div>

Utilisez l&#39;option vocale de la zone de prompt d&#39;Agent pour décrire ce que vous souhaitez créer ou modifier, sans les mains.

<div id="live-activities">
  ### Live Activities
</div>

Suivez la progression de l&#39;Agent où que vous soyez. Lorsque l&#39;Agent démarre, une notification s&#39;affiche : appuyez sur **Allow** depuis votre écran de verrouillage pour suivre la progression sans ouvrir Replit.

<Accordion title="Appareils pris en charge">
  * iPhone sous iOS 18 ou version ultérieure
  * iPad sous iOS 18 ou version ultérieure
  * Mac sous macOS Tahoe ou version ultérieure
  * Apple Watch appairée
</Accordion>

<div id="notificaes">
  ### Notifications
</div>

Recevez les mises à jour importantes, où que vous soyez. Accédez à **Settings**, puis ouvrez **Notifications** (par exemple, dans **User**). Assurez-vous que les notifications sont activées et appuyez sur allow si vous y êtes invité.

Replit vous prévient dans les cas suivants :

* Agent a besoin de votre aide
* Agent a terminé son travail
* Des informations importantes concernant la facturation sont disponibles

<div id="modo-de-teclado-para-tablet">
  ### Mode clavier pour tablette
</div>

Connectez un clavier à votre tablette pour profiter d&#39;une expérience de création optimisée pour les grands écrans. La première fois que vous ouvrez le Project Editor avec un clavier connecté, Replit vous propose d&#39;activer ce mode.

Rendez-vous à tout moment dans **Account** &gt; **Keyboard Settings** pour l&#39;activer ou le désactiver.

<div id="upgrade-e-cobrana">
  ## Passage à un forfait supérieur et facturation
</div>

Pour passer à Core depuis l&#39;application, accédez à **Account**, appuyez sur **Upgrade**, choisissez votre forfait, puis appuyez sur **Continue with Core**. Pro n&#39;est pas disponible à l&#39;achat dans l&#39;application mobile ; il doit être souscrit sur [replit.com](https://replit.com).

Pour utiliser Agent au-delà des crédits inclus dans votre abonnement, ajoutez un moyen de paiement pour la [facturation à l&#39;usage](/fr/pt/billing/about-usage-based-billing) :

* **Sur le web** : rendez-vous sur replit.com et ouvrez **Settings** → **Account** → **Billing**.
* **Dans l&#39;application (iOS, aux États-Unis uniquement)** : ouvrez **Settings** → **Billing** (ou **Account** → **Billing**).
