---
title: "Free Agent 模式"
description: "了解 Free 模式如何为 Starter、Core 和 Pro 订阅者提供免费的 Agent 使用权限。"
---

<Note>
  部分配额详情在发布前仍可能有所调整。
</Note>

使用 Free 模式，Starter、Core 和 Pro 订阅者无需额外付费即可使用 Agent。Starter 包含 Free 模式，但仍适用现有额度限制。Core 和 Pro 包含 Free 模式配额。开始对话，进行探索、规划、创建或寻求帮助。如果你的请求需要使用付费模式或执行付费操作，Replit 会在产生费用前明确告知你。

<div id="section">
  ## 喜欢它的理由
</div>

* 无需经历设置流程，直接从对话开始。
* 在决定是否需要更强大的功能前，您可以先探索并推进想法。
* 即使您的请求需要付费操作，控制权仍掌握在您手中。
* 在 Free 模式下完成的工作会显示醒目的 **Free** 标签。

<div id="section-2">
  ## 工作原理
</div>

1. 新的 Starter、Core、Pro 会话均以 Free 模式启动。
2. 在 Free 模式范围内能完成的工作会直接继续，不会提示付费操作。
3. 如果有更适合处理该请求的付费模式，Agent 会向你说明并提供选项。
4. 你可以仅为该次请求授权使用付费模式，也可以让 Agent 继续保持在 Free 模式下工作。
5. 这类一次性的付费升级结束后，模式会自动恢复为 Free 模式。

<div id="3-agent">
  ## 3 种 Agent 模式
</div>

<CardGroup cols={3}>
  <Card title="Free">
    Starter、Core 和 Pro 订阅者可免费使用 Agent。
  </Card>

  <Card title="Power">
    适用于需要更强能力且注重成本效益的任务的付费中间层模式。
  </Card>

  <Card title="Max">
    面向要求最高的任务，搭载顶尖前沿模型的付费顶级模式。
  </Card>
</CardGroup>

Starter、Core 和 Pro 订阅者均可使用 Free 模式。Starter 包含 Free 模式，但仍适用现有的限制。Core 和 Pro 包含 Free 模式配额，其中 Pro 的每周额度更高。如果需要更强的能力，也可以选择付费 Agent 模式。

<Note>
  **达到限制时：** Starter 包含 Free 模式，但仍适用现有的限制。Core 和 Pro 的 Free 模式配额每 5 小时重置一次，并设有每周上限。要查看当前使用情况，请前往 **设置 → 使用情况**。接近限制时，Replit 会提前通知你。达到限制后，请切换至付费模式继续使用，或等待配额重置。
</Note>

<div id="section-3">
  ## 常见问题
</div>

<AccordionGroup>
  <Accordion title="Free 模式真的免费吗？Replit 变成免费的了吗？">
    Free 模式包含在 Starter、Core 和 Pro 订阅中。Starter 在保持现有限制的前提下包含 Free 模式，Core 和 Pro 则包含 Free 模式的配额。它本身并不是一个免费方案。
  </Accordion>

  <Accordion title="这和付费的 Agent 模式一样吗？">
    不一样。Free 模式是在配额范围内免费使用 Agent。Power 和 Max 是付费模式，适用于需要更强能力的工作。
  </Accordion>

  <Accordion title="Economy 和 Power 怎么样了？模式有变化吗？">
    付费模式已更名。Economy 现更名为 Power，是能以实惠价格使用强大模型的中间层模式。此前称为 Power 的模式现更名为 Max，为顶级模式。现有的模式设置将直接沿用新名称。
  </Accordion>

  <Accordion title="哪个模式的能力最强？">
    是 Max。Power 是付费的中间层模式，以实惠的价格提供更强的能力。Max 是付费的顶级模式，适用于要求最为严苛的工作。
  </Accordion>

  <Accordion title="如果请求需要付费操作会怎样？">
    Agent 会说明该请求需要使用付费模式或付费能力，并在继续之前请求你确认。你可以仅针对该请求批准一次，也可以继续留在 Free 模式下工作。
  </Accordion>

  <Accordion title="如果 Agent 建议升级，会自动扣费吗？">
    不会。升级到付费需要在付费请求开始之前获得你的确认。
  </Accordion>

  <Accordion title="可以拒绝付费选项吗？">
    可以。你可以继续留在 Free 模式下工作。
  </Accordion>

  <Accordion title="批准付费升级之后会怎样？">
    该批准仅对本次请求生效。之后，你的 Agent 模式会恢复为 Free 模式。
  </Accordion>

  <Accordion title="为什么我达到了限制？什么时候会重置？">
    Starter 在保持现有限制的前提下包含 Free 模式。在 Core 和 Pro 中，Free 模式的配额每 5 小时重置一次，并设有每周上限。要查看当前用量，请前往 **设置 → 使用情况**。如果已达到限制，可以切换到付费模式继续使用，或等待重置。
  </Accordion>

  <Accordion title="Enterprise 可以使用 Free 模式吗？">
    发布时尚不可用。Enterprise 工作区随后不久将提供专属的 Agent 体验。详情请咨询你的管理员。
  </Accordion>
</AccordionGroup>

<div id="free">
  ## 关于 Free 模式的更多信息
</div>

<AccordionGroup>
  <Accordion title="Free 模式和 Lite 一样吗？">
    对 Starter 用户来说，此前称为 Lite 的体验现在就是 Free 模式。如果你以前是为了使用低成本模型才选择 Lite，只要关闭自动配置，就可以在 Power 中手动选择该模型。
  </Accordion>

  <Accordion title="可以用 Free 模式构建完整的应用吗？">
    可以。你能在 Free 模式下创建完整的应用并持续迭代。
  </Accordion>

  <Accordion title="Free、Power 和 Max 有什么区别？">
    Free 模式面向 Starter、Core 和 Pro 订阅用户，是免费的日常 Agent 使用方式。Starter 包含 Free 模式，并沿用现有限制。Core 和 Pro 则包含 Free 模式配额。Power 是付费的中间层模式，以实惠的价格提供更强的能力。Max 是付费的顶级模式，适合要求最高的工作。
  </Accordion>

  <Accordion title="什么时候该从 Free 模式切换？">
    日常工作一直使用 Free 模式即可。当你在复杂任务中需要更强的效果，或者需要 Free 模式不具备的能力时，再切换到其他模式。
  </Accordion>

  <Accordion title="Free 模式可以生成视频吗？">
    不可以。视频生成是付费模式的功能，Free 模式不包含。
  </Accordion>

  <Accordion title="全新的 Conversations 体验是什么？">
    聊天与创作合二为一。你可以在同一个对话中调研想法、规划工作或启动项目。
  </Accordion>

  <Accordion title="独立的聊天会成为已发布应用的一部分吗？">
    不会。在你创建或修改项目之前，对话始终是独立的。
  </Accordion>

  <Accordion title="Free 模式可以用于现有项目吗？">
    可以。它支持对现有项目进行日常维护和编辑。
  </Accordion>
</AccordionGroup>
