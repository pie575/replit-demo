Model Context Protocol(MCP)은 AI 제품을 도구 및 데이터 소스와 연결하기 위한 개방형 표준입니다. Replit의 네이티브 통합과는 별개이지만, Conversation에서 작업하는 동안 사용 가능한 도구를 확장할 수 있습니다.

## 연결 방향 선택

* **Replit을 외부 도구에 연결:** 큐레이션된 MCP 서버나 커스텀 MCP 서버를 추가하여 Replit이 해당 서버가 제공하는 도구를 사용할 수 있게 하세요. 신뢰할 수 있는 서버만 연결하세요.
* **MCP 클라이언트에서 Replit 사용:** 호환되는 클라이언트를 Replit MCP Server에 연결하여 해당 클라이언트에서 Replit Apps를 생성, 검색, 검사, 업데이트하세요.

MCP는 네이티브 통합 및 [Skills](/ko/chat/agent-skills)와는 별개입니다. 통합은 지원되는 서비스 연결을 제공합니다. Skills는 재사용 가능한 지침과 지원 자료를 제공합니다. MCP는 프로토콜을 통해 사용 가능한 도구를 확장합니다.
