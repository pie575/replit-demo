<div id="apps">
  ### Apps privées pour les comptes gratuits
</div>

Les créateurs disposant d’un compte gratuit peuvent désormais créer des Apps privées. Les limites du forfait gratuit quant au nombre d’Apps pouvant être créées restent applicables.

<div id="ai">
  ### Nouveaux modèles d&#39;IA dans les intégrations
</div>

Les nouveaux modèles d&#39;IA publiés dans les intégrations IA sont désormais pris en charge :

| Modèle                       | Description                                                                                                                                                                                                |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `gpt-5.2`                    | Le modèle d&#39;OpenAI le plus performant pour le travail intellectuel professionnel. Premier modèle à dépasser 90 % sur ARC-AGI-1, il dispose d&#39;une fenêtre de contexte de 400K.                      |
| `claude-opus-4.5`            | Le modèle phare d&#39;Anthropic, optimisé pour le codage, les agents et l&#39;utilisation d&#39;ordinateurs. Il atteint 80,9 % sur SWE-bench Verified.                                                     |
| `gemini-3-flash-preview`     | Le modèle rapide de Google pour les flux de travail agentiques, avec un contexte de 1M de jetons. Il offre des capacités de raisonnement proches du niveau Pro, avec une faible latence et un coût réduit. |
| `gemini-3-pro-preview`       | Le modèle multimodal avancé de Google, doté d&#39;un raisonnement de pointe et de connaissances du monde réel.                                                                                             |
| `gemini-3-pro-image-preview` | Le modèle Nano Banana Pro de Google, destiné à la génération et à la modification d&#39;images de haute qualité avec un rendu précis du texte.                                                             |
