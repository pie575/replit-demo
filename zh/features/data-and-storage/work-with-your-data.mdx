**My Data** 标签页用于查看和修改数据库中的内容。打开 **Database** 工具，选择一个数据库，然后选择 **My Data**。你可以使用可视化方式操作，也可以直接运行 SQL。

<Note>
  若要编辑生产数据，请选择 production database，打开 **My Data**，然后打开 **Edit** 开关。请务必小心：这是你线上应用的真实数据。
</Note>

<div id="browse-and-modify-data-visually">
  ## 可视化浏览和修改数据
</div>

数据库工具内置了 <a href="https://orm.drizzle.team/drizzle-studio/overview" target="_blank">Drizzle Studio</a>，可让你以可视化方式浏览和修改数据。这些可视化工具能帮你避免语法错误，并提供以下功能：

* 筛选和排序数据，聚焦特定信息
* 将数据导出为文件，供外部使用
* 插入或修改行数据
* 创建和管理 schema、表、视图和枚举

<div id="run-sql-commands">
  ## 运行 SQL 命令
</div>

SQL 运行器可让你在数据库上运行 SQL 命令并查看结果。

<Accordion title="如何打开 SQL 运行器">
  在 **Database** 工具中：

  1. 选择 **My Data** 选项卡
  2. 选择 <img class="icon-svg" src="/assets/mirror/sql-runner-icon-b25868882922.svg" alt="SQL runner icon" width="16" height="16" data-path="images/icons/sql-runner-icon.svg" /> **SQL runner**
</Accordion>

要运行查询，请在文本框中输入 SQL 语句，然后点击旁边的 <img class="icon-svg" src="/assets/mirror/sql-play-8ed26b5de7f1.svg" alt="sql run icon" width="18" height="18" data-path="images/icons/sql-play.svg" /> 运行按钮：

<Frame>
  <img src="/assets/mirror/sql-runner-run-8ad798a61335.jpg" alt="screenshot of the SQL runner and run button" width="1390" height="608" data-path="images/databases/sql-runner-run.jpg" />
</Frame>

<Tip>
  你无需自己编写 SQL。只要让 Agent 查询或修改数据，它就会帮你编写并运行 SQL。
</Tip>
