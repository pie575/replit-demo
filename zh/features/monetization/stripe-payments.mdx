<div id="what-you-can-build">
  ## 你可以构建什么
</div>

使用 Agent，一键将 Stripe 集成到你的应用，无需任何配置。你可以搭建在线店铺、收取一次性支付，或创建订阅服务。Agent 会自动配置好集成、数据模型和测试环境。

<div id="how-it-works">
  ## 工作原理
</div>

Agent 默认使用 Stripe 沙盒，让你在不涉及真实资金的情况下安全地测试支付。你可以立即构建并试用各种支付流程。准备就绪后，切换到正式的 Stripe 账户即可发布应用并接受真实支付。

<Info>
  Stripe 沙盒是一个隔离的测试环境，你可以在其中模拟支付、订阅和事件。详见
  [Stripe 的沙盒文档](https://docs.stripe.com/sandboxes)。
</Info>

<div id="use-stripe-with-your-team">
  ## 在团队中使用 Stripe
</div>

Stripe 支持在协作 workspace 中使用，整个团队可以共同构建、测试同一个应用并实现变现。workspace 中的所有成员都可以使用已连接的 Stripe 账户，而不必由某一个人独自搭建支付功能。

<div id="get-started">
  ## 开始使用
</div>

* **让 Agent 使用 Stripe**
  * 在主屏幕上使用斜杠命令并选择 Stripe，或直接提出需求：
    <AiPrompt>构建一个店铺页面并集成 Stripe 支付</AiPrompt>

<Note>
  Stripe 集成需要具备后端功能的应用。请在主页选择 **App** 开始。
</Note>

<div id="test-payments-in-the-sandbox">
  ## 在沙盒中测试支付
</div>

1. 在新标签页中打开应用的 **Preview**。
2. 在店面或支付页面完成一笔测试购买。
3. 使用 Stripe 的标准测试卡：

```text theme={null}
卡号：4242 4242 4242 4242
有效期：任意未来日期
CVC：任意 3 位数字
姓名、地址：任意虚构信息
```

<Tip>
  沙盒中的购买不会走真实支付网络，也不涉及实际资金流动，可放心用于端到端测试。
</Tip>

<div id="manage-products-and-pricing">
  ## 管理产品与定价
</div>

你有两种方式：

1. 在应用中选择 **Publish**，然后认领你的 Stripe 沙盒。
   * 如果你还没有 Stripe 账户，请先创建一个，然后认领沙盒。
2. 在 Stripe 控制台中打开 **Products**，添加或编辑产品和价格。
   你在 Stripe 沙盒中所做的更改会自动同步到你的 Replit App，
   并写入应用的数据库。

<div id="view-synced-stripe-data">
  ### 查看已同步的 Stripe 数据
</div>

* 在 Project Editor 中打开 **Database**。
* 选择 **MyData**。
* 将 schema 选择器切换为 **Stripe**，即可查看支付对象及相关
  记录。

<div id="go-live">
  ## 正式上线
</div>

要接受真实支付，请从 Stripe Marketplace 安装
[Replit Integrated Payments](https://marketplace.stripe.com/apps/replit-integrated-payments)
应用，以连接你的正式 Stripe 账户。安装流程会自动完成正式账户的连接——无需复制粘贴 API 密钥。

<Warning>
  你的沙盒集成尚不具备生产环境条件。在完成以下步骤之前，它无法接受真实支付。
</Warning>

<Steps>
  <Step title="打开发布面板">
    在你的应用中，选择 **Publish**，启动正式连接流程。
  </Step>

  <Step title="安装 Replit Integrated Payments 应用">
    选择 **Install Stripe app**。此时会打开一个 Stripe 窗口，显示
    [Replit Integrated Payments](https://marketplace.stripe.com/apps/replit-integrated-payments)
    的应用页面。

    当 Stripe 提示你选择账户时，请选择你的**正式** Stripe 账户，而不是沙盒或测试账户。
  </Step>

  <Step>
    按照 Stripe 的提示完成应用安装。如果你的正式账户尚未激活，Stripe 会先引导你完成
    KYB (了解你的企业) 验证。

    安装完成前，请勿关闭 Stripe 窗口。Stripe 确认安装后，Replit 会在后台完成生产环境连接的配置。
  </Step>

  <Step title="发布你的应用">
    返回 Replit。**Publish** 面板会显示你的正式 Stripe 账户已连接。发布应用即可开始接受真实支付。
  </Step>
</Steps>

<Note>
  安装 Replit Integrated Payments 应用后，无需再像以往那样手动将 Publishable 和 Secret 密钥复制到 Replit。该应用会为你配置好生产环境密钥，并持续保持沙盒与正式环境之间的同步。
</Note>

<div id="manage-the-integration">
  ## 管理集成
</div>

* 前往 **Integrations &gt; Stripe**，打开 Stripe 连接器。
* 在此可以测试连接、查看状态并管理设置。

<div id="frequently-asked-questions">
  ## 常见问题
</div>

<div id="how-do-i-update-the-prices-of-my-products">
  ### 如何更新产品价格？
</div>

* 让 Agent 处理：描述你要做的更改，Agent 会同步更新你的应用和 Stripe 对象。
* 使用 Stripe 控制台：打开 **Products** 编辑价格和产品详情。
  * 在沙盒环境中，更改会自动同步回你的应用和数据库。
  * 若要更新生产环境，请先切换到正式账户，再更新价格。如果应用需要读取新配置，请重新发布。

<div id="how-do-i-test-transactions-on-replit">
  ### 如何在 Replit 上测试交易？
</div>

在新标签页中打开应用的 **Preview**。使用标准测试卡号 (4242 4242 4242 4242) 、任意未来日期作为有效期以及任意 CVC，运行 Stripe Checkout 流程。详情请参阅上文的
[在沙盒中测试支付](#test-payments-in-the-sandbox)。

<div id="what-is-a-live-stripe-account">
  ### 什么是正式启用的 Stripe 账户？
</div>

正式启用的 Stripe 账户是指已激活并通过验证、能够使用你的企业信息处理真实支付的账户。相关说明请参阅 Stripe 的账户创建与激活指南：[创建并管理你的 Stripe 账户](https://docs.stripe.com/get-started/account)。

<div id="do-i-still-need-to-paste-in-my-stripe-api-keys">
  ### 我还需要粘贴自己的 Stripe API 密钥吗？
</div>

不需要。当你连接正式的 Stripe 账户时，Replit Integrated Payments 应用会自动为你安装生产环境密钥，无需再从 Stripe 控制台 复制正式密钥。

如果你之前是通过粘贴正式密钥连接 Stripe 的，该连接仍然有效。你也可以移除现有的 Stripe 连接，然后在 **Publish** 面板中重新连接，改用 Stripe 应用安装流程。详见下方的
[更新或移除 Stripe 连接](#update-or-remove-the-stripe-connection)。

<div id="update-or-remove-the-stripe-connection">
  ## 更新或移除 Stripe 连接
</div>

如果你还没准备好使用正式环境的 Stripe 连接进行发布，可以选择以下两种
方式：

<div id="option-a-remove-the-stripe-integration-manually">
  ### 方案 A：手动移除 Stripe 集成
</div>

你可以将 Stripe 集成从 project 中彻底移除。

<Steps>
  <Step title="打开 Integrations 标签页">
    进入你的 Replit App，选择顶部的 **Integrations** 标签页。在 **Connectors** 下找到 **Stripe**，然后选择 **Manage**。

    <Frame>
      <img src="/assets/mirror/stripe-disconnect-1-integrations-371e1e7e5609.png" alt="Integrations 标签页显示 Connectors 中的 Stripe 集成及 Manage 按钮" width="2000" height="1110" data-path="images/replitai/stripe-disconnect-1-integrations.png" />
    </Frame>
  </Step>

  <Step title="展开 API 密钥">
    选择箭头图标展开 **Sandbox API keys** 和 **Live account API keys**，然后选择 **Edit**。

    <Frame>
      <img src="/assets/mirror/stripe-disconnect-2-edit-keys-4e9e76c4065f.png" alt="展开的 Stripe 沙盒与正式账户 API 密钥，带有 Edit 按钮" width="2000" height="1274" data-path="images/replitai/stripe-disconnect-2-edit-keys.png" />
    </Frame>
  </Step>

  <Step title="断开账户连接">
    选择 **Disconnect account** 断开 Sandbox 连接，选择 **Disconnect live account** 断开 Live 连接。

    <Frame>
      <img src="/assets/mirror/stripe-disconnect-3-disconnect-f4257f534c5c.png" alt="Stripe 沙盒与正式账户 API 密钥，带有 Disconnect account 和 Disconnect live account 按钮" width="2000" height="1271" data-path="images/replitai/stripe-disconnect-3-disconnect.png" />
    </Frame>
  </Step>

  <Step title="让 Agent 移除 Stripe 代码">
    前往 Agent chat，让 Agent 从你的应用中移除 Stripe 连接器代码。这样即可彻底移除整个 Stripe 集成。
  </Step>
</Steps>

<div id="option-b-roll-back-to-a-checkpoint-before-the-stripe-integration">
  ### 选项 B：回滚到 Stripe 集成之前的 checkpoint
</div>

如果你想彻底撤销 Stripe 集成并恢复到之前的状态，可以回滚到更早的 checkpoint。

<Steps>
  <Step title="打开 Integrations 标签页">
    进入你的 Replit App，选择顶部的 **Integrations** 标签页。在 **Connectors** 下找到 **Stripe** 并选择 **Manage**。

    <Frame>
      <img src="/assets/mirror/stripe-disconnect-1-integrations-371e1e7e5609.png" alt="Integrations 标签页显示 Connectors 中的 Stripe 集成和 Manage 按钮" width="2000" height="1110" data-path="images/replitai/stripe-disconnect-1-integrations.png" />
    </Frame>
  </Step>

  <Step title="展开你的 API 密钥">
    选择箭头图标展开 **Sandbox API keys** 和 **Live account API keys**，然后选择 **Edit**。

    <Frame>
      <img src="/assets/mirror/stripe-disconnect-2-edit-keys-4e9e76c4065f.png" alt="展开的 Stripe 沙盒与正式账户 API 密钥，带有 Edit 按钮" width="2000" height="1274" data-path="images/replitai/stripe-disconnect-2-edit-keys.png" />
    </Frame>
  </Step>

  <Step title="断开你的账户连接">
    选择 **Disconnect account** 断开 Sandbox 连接，选择 **Disconnect live account** 断开 Live 连接。

    <Frame>
      <img src="/assets/mirror/stripe-disconnect-3-disconnect-f4257f534c5c.png" alt="Stripe 沙盒与正式账户 API 密钥，带有 Disconnect account 和 Disconnect live account 按钮" width="2000" height="1271" data-path="images/replitai/stripe-disconnect-3-disconnect.png" />
    </Frame>
  </Step>

  <Step title="查找 Stripe 集成之前的 checkpoint">
    进入 Agent chat，找到在 Stripe 集成之前创建的 checkpoint。选择聊天面板左上角的**时钟图标**，即可查看更早的聊天记录。

    <Frame>
      <img src="/assets/mirror/stripe-rollback-5-clock-icon-c54cd19246ea.png" alt="用于查看聊天记录和 checkpoint 的时钟图标" width="56" height="50" data-path="images/replitai/stripe-rollback-5-clock-icon.png" />
    </Frame>
  </Step>

  <Step title="选择 Rollback here">
    找到合适的 checkpoint 后，选择 **Rollback here**，将你的 project 恢复到该状态。

    <Frame>
      <img src="/assets/mirror/stripe-rollback-6-checkpoint-2f195b0ea9ce.png" alt="带有 Rollback here 按钮的 checkpoint" width="904" height="202" data-path="images/replitai/stripe-rollback-6-checkpoint.png" />
    </Frame>
  </Step>
</Steps>

<div id="notes-and-limitations">
  ## 注意事项与限制
</div>

* 沙盒中的操作不会影响真实余额或客户数据。
* 部分 Stripe 功能无法在沙盒中测试 (例如 IC+ 定价和某些 Connect 流程) 。请参阅
  [Stripe 的沙盒限制](https://docs.stripe.com/sandboxes)。
