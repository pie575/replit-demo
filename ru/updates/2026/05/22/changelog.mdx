<div id="layout-controls-in-the-visual-editor">
  ### Управление макетом в Visual Editor
</div>

В Visual Editor появились отдельные элементы управления **макетом**, позволяющие визуально настраивать flexbox вместо того, чтобы просить Agent переписать стили. Выберите любой контейнер, разверните раздел «Макет» и задайте направление flex, выравнивание и распределение. Укажите промежуток между элементами в пикселях или включите переключатель **«Пространство между»**, чтобы разместить дочерние элементы по противоположным краям.

Панель редактора также перегруппирована в более понятные разделы **«Текст»**, **«Изображение»**, **«Макет»**, **«Цвет»** и **«Граница»**, чтобы нужный элемент управления было проще найти.

<div id="agent-settings-stay-yours-in-shared-projects">
  ### Настройки Agent остаются вашими в общих проектах
</div>

Ваши настройки Agent — например, уровень модели, режим планирования, автоматическое слияние и автоматическое подтверждение плана — теперь привязаны к вам, а не общие для всех участников проекта. Если коллега переключается на Power Mode для своих задач, ваши настройки больше не изменятся. Agent использует выбранные вами настройки, когда вы отправляете следующее сообщение, даже в проектах с большим числом участников.

Подробнее см. в разделе [Режимы Agent](/ru/features/agent/agent-modes#settings-in-shared-projects).

<div id="agent-suggests-power-mode-when-youre-stuck">
  ### Agent предлагает Power Mode, если вы зашли в тупик
</div>

Если Agent замечает, что в Economy Mode вы снова и снова сталкиваетесь с одной и той же проблемой, он предложит переключиться на Power в следующем сообщении. Предложение появляется при повторяющихся запросах или если код продолжает выдавать ошибки, и отображается не более одного раза для каждого проекта. Agent не показывает его во время сеансов планирования, если вы уже упомянули ограниченный бюджет или используете бесплатный тариф.

<div id="cleaner-task-settings-dropdown">
  ### Более удобное меню настроек задачи
</div>

Меню, открывающееся из заголовка задачи, стало удобнее. Активная задача или название плана теперь отображаются вверху, а переименовать их можно прямо в меню. Настройки автоматизации (автоприменение и автоодобрение) вынесены в отдельный раздел между названием и действиями, а всплывающее окно имеет фиксированную ширину и больше не смещается при изменении названий задач. Отключённые параметры автоматизации скрыты, поэтому в меню отображается только то, что относится к текущей задаче.

<div id="two-new-connectors-quiver-ai-and-browserbase">
  ### Два новых коннектора: Quiver AI и Browserbase
</div>

В каталоге коннекторов появились ещё два сервиса. Откройте панель **интеграции** и выберите **Add new integration**, чтобы подключить один из них.

* **Quiver AI**: Создавайте SVG-иллюстрации и векторизуйте растровые изображения через управляемый API. Полезно, когда Agent нужен готовый SVG-ассет по запросу.
* **Browserbase**: Запускайте управляемые браузеры без графического интерфейса для получения данных, поиска и полной автоматизации сеансов. Полезно, когда Agent нужно загрузить настоящую веб-страницу, выполнить JavaScript или взаимодействовать с сайтом, блокирующим обычные HTTP-запросы.
