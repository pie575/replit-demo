<div id="section-3">
  ### 可视化编辑器
</div>

Agent 现在有了「眼睛」——点击、描述、搞定。

<Frame>
  <img src="/assets/mirror/demo-assistant-feed47b3a11b.webp" alt="可视化编辑器" width="600" height="404" data-path="images/changelog/2025-03-21/demo-assistant.webp" />
</Frame>

激动人心的新功能已上线。现在，你可以在 JavaScript 应用的项目中直接点击并选中元素！

构建和编辑界面从此变得前所未有地直观。想了解更多？请前往博客 [https://blog.replit.com/cartographer](https://blog.replit.com/cartographer) 查看详细介绍。

<div id="agent">
  ### Agent 时间线消息
</div>

现在，每当 Agent 为项目设置蓝图时，都会出现可视化提示。这样你就能更轻松地了解 Agent 正在做什么，掌握开发进展。

此外，我们还增强了分析能力，以便更好地追踪蓝图的使用情况，为后续更智能的改进打好基础。
