<div id="core-stripe">
  ### Paiements intégrés Stripe pour les utilisateurs Core
</div>

Intégrez Stripe directement à votre application en un seul clic. Agent configure les paiements et les abonnements, avec une synchronisation en temps réel de l&#39;état des abonnements dans votre base de données : vous pouvez ainsi vous concentrer sur la création de votre produit plutôt que sur le raccordement de l&#39;infrastructure de paiement.

[En savoir plus sur l&#39;intégration des paiements Stripe](/fr/core-concepts/monetization/stripe-payments)

<div id="section-3">
  ### Meilleur classement dans les résultats de recherche pour les domaines personnalisés
</div>

Lorsque vous associez un domaine personnalisé à une application publiée, les moteurs de recherche n&#39;indexent désormais que le domaine personnalisé, et non le sous-domaine `replit.app`. Vous évitez ainsi les pénalités liées au contenu dupliqué et améliorez le classement de votre application dans les résultats de recherche.

[En savoir plus sur les domaines personnalisés](/fr/ko/features/publishing/custom-domains)
