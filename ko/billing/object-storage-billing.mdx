<div id="billing-categories">
  ## 청구 카테고리
</div>

Replit은 App Storage 청구를 다음 영역으로 구분합니다.

* **스토리지**: 월간 사용한 데이터 용량입니다. 저장된 모든 객체에는 최소 7일의 청구 기간이 적용됩니다.
* **데이터 전송**: 한 달 동안 업로드 및 다운로드된 총 데이터양입니다.
* **Basic Operations**: bucket과 객체를 업데이트하는 작업입니다. 자세한 내용은 <a href="https://cloud.google.com/storage/pricing" target="_blank">Google Cloud Storage pricing</a>의 Class A Operations를 참조하세요.
* **Advanced Operation**: 객체와 bucket의 config 및 메타데이터 조회 등 그 외 모든 클라우드 Object Storage 작업입니다. 자세한 내용은 <a href="https://cloud.google.com/storage/pricing" target="_blank">Google Cloud Storage pricing</a>의 Class B Operations를 참조하세요.
