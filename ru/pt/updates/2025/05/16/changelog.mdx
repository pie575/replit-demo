<div id="prvias-de-checkpoint">
  ### Предпросмотр checkpoint
</div>

Представляем предпросмотр checkpoint в среде разработки Replit. Просматривайте приложение на разных этапах разработки без пересборки или восстановления предыдущих версий.

Эта возможность упрощает отслеживание прогресса, сравнение итераций и контроль версий, обеспечивая полное представление о развитии вашего проекта. Эта функция дополняет [процесс vibe coding](https://learn.replit.com).

  ### Попросите Agent добавить базу данных

<div id="correspondncia-de-auth-do-replit-por-padro">
  ### Сопоставление Replit Auth по умолчанию
</div>

Аутентификация пользователей в ваших приложениях становится проще благодаря автоматическому сопоставлению Replit Auth.

Эта функция включается, когда приложению требуется аутентификация. Она избавляет от необходимости создавать собственные формы регистрации, системы восстановления пароля или настраивать вход через социальные сети. Это упрощает безопасное управление пользователями.

<div id="verificao-de-e-mail-em-tela-cheia">
  ### Полноэкранная проверка электронной почты
</div>

Упрощённый процесс проверки при выполнении защищённых действий повышает безопасность учётной записи.

Этот встроенный подход при необходимости предлагает подтвердить адрес электронной почты после входа в систему. Он помогает защитить учётную запись, обеспечивая при этом единообразный пользовательский опыт и баланс между безопасностью и удобством.

Это часть нашей неизменной приверженности [информационной безопасности](/ru/pt/teams/information-security/overview).

<div id="scim-para-clientes-enterprise">
  ### SCIM для клиентов Enterprise
</div>

Новая интеграция SCIM позволяет клиентам Enterprise напрямую управлять доступом к Replit через своих поставщиков удостоверений.

Подключите Okta, Active Directory, Rippling или другие платформы управления удостоверениями, чтобы автоматизировать предоставление и отзыв доступа к Replit. Это избавляет от необходимости вручную управлять пользователями и упрощает корпоративные рабочие процессы.

Для начала ознакомьтесь с [подробной документацией по SCIM](/ru/pt/teams/identity-and-access-management/scim).

<div id="assentos-de-visualizador-para-replit-teams">
  ### Места Viewer для Replit Teams
</div>

Представляем места Viewer для Replit Teams. Делитесь своими приложениями с заинтересованными лицами, которые только просматривают приложения и работают с ними, но не редактируют, — и для этого не нужны полноценные командные лицензии.

Идеальный вариант для руководителей, клиентов или коллег, которые пользуются вашими инструментами, но не создают их. Узнайте, как настраивать места [Viewer](/ru/pt/teams/identity-and-access-management/viewer-seats) и управлять ими.
