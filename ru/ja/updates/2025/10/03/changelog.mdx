<div id="vercel">
  ### Интеграция импорта из Vercel
</div>

Переносите приложения Vercel в Replit в один клик! Новый процесс импорта позволяет без проблем перенести в Replit приложения на Next.js и другие приложения, размещённые на Vercel. Это отличная возможность для разработчиков, ищущих альтернативу Vercel. Подробнее читайте в [кратком руководстве по импорту из Vercel](/ru/build/import-from-vercel) и [руководстве по импорту в Replit](/ru/references/workspace/import).

<div id="git">
  ### Улучшенный контроль версий Git
</div>

Расширенная интеграция с Git сделала удобнее управление удалёнными репозиториями и работу с рабочими пространствами. Обновлённый интерфейс позволяет подключать и создавать удалённые репозитории Git, легко переключаться между личным и организационным рабочими пространствами и проверять перед развёртыванием, что код актуален. Подробнее — в разделе [Как пользоваться панелью Git](/ru/references/version-control/git-interface).

<div id="section-2">
  ### Запуск платформы коннекторов
</div>

Создавайте приложения быстрее с помощью 24 готовых интеграций! Подключайте проекты Replit к популярным сервисам, таким как Stripe и Figma, через новую платформу коннекторов. Каждый коннектор использует MCP (Model Context Protocol), обеспечивая бесшовную разработку с ИИ. Подробнее см. в разделе [интеграций Agent](/ru/replitai/integrations) и [управления коннекторами](/ru/ja/replitai/managing-connectors).

<div id="section-3">
  ### Улучшения шрифтов в темах App
</div>

Настраивайте приложение с помощью 19 дополнительных шрифтов Google Fonts, включая такие популярные, как Crimson, EB Garamond, Figtree и Source Sans Pro. Теперь в списке выбора каждый шрифт отображается своим собственным начертанием, поэтому оценить оформление стало проще. Шрифты сгруппированы по категориям (Serif, Sans-Serif, Monospace) и снабжены подсказками с описанием каждого типа. Подробнее — в разделе [Темы App](/ru/replitai/app-themes).

<div id="section-4">
  ### Администрирование коннекторов
</div>

Пользователям Enterprise доступно расширенное управление коннекторами: ролевая модель доступа к общим API-ключам и полностью настраиваемая конфигурация клиента OAuth. Коннекторы включаются на уровне организации по принципу подписки (opt-in), поэтому администраторы полностью контролируют, какие интеграции доступны участникам команды. См. [Управление коннекторами](/ru/ja/replitai/managing-connectors).
