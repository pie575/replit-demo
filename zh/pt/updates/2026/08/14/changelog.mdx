<div id="migre-para-o-clerk-auth">
  ### 迁移到 Clerk Auth
</div>

现在，您可以将符合条件的应用从 Replit Auth 迁移至 Clerk Auth。Agent 会先迁移账户数据，再更新登录代码，确保现有用户仍可访问自己的数据。

</Frame>

了解[如何迁移到 Clerk Auth](/zh/pt/features/auth-and-identity/migrate-auth-to-clerk)。

<div id="compartilhe-e-gerencie-skills-do-workspace">
  ### 共享和管理工作区技能
</div>

现在，任何工作区成员都可以创建技能，并将其设为私有或共享给工作区。共享技能默认对其他成员停用，每个人都可以自行选择要启用哪些技能。管理员可以管理工作区中的所有技能，并可要求工作区使用特定技能。全新改版的技能素材库让技能更易于查找和管理。

详细了解 [Agent Skills](/zh/pt/features/agent/skills)。

<div id="teams-e-enterprise">
  ## Teams 和 Enterprise
</div>

<div id="admin-api-disponvel-em-beta">
  ### Admin API Beta 版现已推出
</div>

Enterprise 账户管理员现在可以在“设置”中的新 **Developer** 选项卡创建 API 密钥，并使用 Admin API：

* 查看工作区、成员、用户组、项目和部署。
* 查看成员、项目和工作区在自定义日期范围内的使用情况。
* 查看和编辑工作区、用户组及个人成员的预算。

更多信息请参阅[Admin API 文档](/zh/pt/teams/admin-api)和 [API 参考](https://api.replit.com/docs)。
