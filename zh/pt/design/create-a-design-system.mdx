创建 design system 有两种方式，具体取决于您当前的品牌资产所在位置。

<div id="do-zero-pea-na-home-page">
  ## 从零开始：在首页提出需求
</div>

当你心中已有系统构想 (或已有品牌指南) ，但还没有任何设计稿时，就从这里开始。

<Steps>
  <Step title="在创建输入框中提出需求">
    在 Replit 首页的 prompt 输入框中描述你想要的设计系统，例如：*&quot;为 Velocity 创建一个设计系统：这是一个高端超级跑车租赁品牌。&quot;*

    <Frame>
      <img src="/assets/mirror/ds-home-create-7f04110e1f71.png" alt="首页的 prompt 输入框，其中包含用于创建设计系统的 prompt" width="800" height="240" data-path="images/design/replit-design/ds-home-create.png" />
    </Frame>
  </Step>

  <Step title="回答问卷">
    Agent 会针对你的系统提出几个简短的问题，例如品牌个性、颜色和字体偏好。你还可以为它提供参考来源：Figma URL、网站、代码、参考图片、品牌资源或已有的 DESIGN.md。
  </Step>
</Steps>

<div id="a-partir-de-um-mockup-extraia-o-design-system">
  ## 从 mockup 中提取设计系统
</div>

如果你已有一个很喜欢的设计——无论是生成的 frame 还是独立的 template——并希望其他内容都与它保持一致，就从这里开始。

<Steps>
  <Step title="选择 mockup">
    在 Canvas 上，点击你想提取视觉风格的 mockup。
  </Step>

  <Step title="通过三点菜单提取">
    打开 frame 的 **⋯** (三点) 菜单，然后选择 **Extract design system**。Agent 会将 mockup 中的 token、颜色和字体排版提炼为一套可复用的样式指南，并应用于整个设计。

    <Frame>
      <img src="/assets/mirror/ds-extract-menu-3efbe8bb497e.png" alt="已选中 frame 的操作栏特写，更多选项菜单已打开，显示 Apply design system 和 Extract design system" width="958" height="320" data-path="images/design/replit-design/ds-extract-menu.png" />
    </Frame>
  </Step>
</Steps>

<div id="revise-e-salve">
  ## 检查并保存
</div>

请检查生成的内容：这是一份动态样式指南，包含按用途划分的颜色 (主色、强调色、中性色等) 、字体比例和 token (存储在 `tokens.json` 中，用于生成 CSS 变量) 。然后，选择 **Save design system**，将其保存到你的 workspace 中。
