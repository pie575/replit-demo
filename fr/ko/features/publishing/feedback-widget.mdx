---
title: "Widget de feedback"
description: "Ajoutez un widget de feedback à votre application publiée pour permettre aux visiteurs de signaler des problèmes et de partager des idées, puis transmettez-les directement à Agent pour les corriger."
---

Le widget de feedback ajoute un bouton de feedback dans un coin de votre application publiée. Sans quitter l’application, les visiteurs peuvent utiliser ce bouton pour signaler des problèmes ou proposer des améliorations. Vous pouvez ensuite transmettre directement leurs retours à Agent pour les corriger.

<div id="section">
  ## Activer le widget de feedback
</div>

1. Dans le panneau **Tools**, sous **Replit Cloud**, sélectionnez **Publishing** ou, en haut à droite du Project Editor, sélectionnez **Publish** pour ouvrir l’outil Publishing.
2. Sous **Engagement tools**, activez **Enable feedback widget**.
3. Sélectionnez **Publish**. Le widget s’affiche dans l’application publiée.

<div id="section-2">
  ## Position et apparence
</div>

Lorsque vous activez le widget, deux paramètres s’affichent :

* **Position du widget** : sélectionnez le coin de l’application où le widget sera placé : en haut à gauche, en haut à droite, en bas à gauche ou en bas à droite. Par défaut, il est placé en bas à droite.
* **Apparence** : téléversez une icône pour le bouton du widget et choisissez une couleur d’arrière-plan afin de l’harmoniser avec le design de votre application.

<div id="section-3">
  ## Examiner les commentaires et y donner suite
</div>

Les soumissions des visiteurs arrivent dans votre boîte de réception (inbox). Vous pouvez y effectuer les actions suivantes :

* Lire chaque soumission afin de comprendre le problème rencontré par le visiteur.
* Envoyer une soumission à Agent pour qu&#39;il la corrige. Agent traite les commentaires comme des tâches et propose des modifications pour l&#39;application.

<div id="section-4">
  ## Désactiver le widget
</div>

Dans l’outil Publishing, désactivez **Enable feedback widget**, puis republiez l’application. Le widget disparaîtra de l’application publiée.
