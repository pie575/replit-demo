<div id="choose-agents-primary-model">
  ### Agent의 Primary model 선택
</div>

이제 Agent가 task를 수행할 때 사용할 primary model을 직접 선택할 수 있습니다. Lite, Economy, Power 중 하나를 고른 다음, 해당 모드에서 사용할 수 있는 모델을 선택하세요. Lite는 mobile app을 비롯해 Agent를 사용할 수 있는 모든 환경에서 이용할 수 있습니다. 사용 가능한 모델은 Organization, 권한, Turbo 이용 여부에 따라 다릅니다.

<div id="connect-more-mcp-servers">
  ### 더 많은 MCP 서버 연결
</div>

지원 대상 workspace에서는 기본 제공되는 MCP 서버 카탈로그를 통해 Supabase, Statsig, Calendly에 연결할 수 있습니다. 또한 Replit은 공식 Braintrust MCP 엔드포인트를 인식하여, 직접 추가하면 OAuth sign-in flow를 시작합니다.

<div id="stay-signed-in-longer">
  ### 로그인 상태를 더 오래 유지
</div>

이제 Replit session이 더 오래 유지되어 다시 로그인하는 빈도가 줄어듭니다. Enterprise 관리자는 Session timeout 프리셋을 구성할 수 있습니다.
