Передайте Agent данные о товарах из уже имеющихся источников: Google Sheet (название, цена,
описание, код товара, остаток) и фотографии из Google Drive. Agent настроит магазин Shopify,
импортирует товары, цены, описания и изображения, а также подключит checkout и платежи.
Дизайн витрины и фронтенд находятся в Replit, а не в теме Shopify. Платежи проходят
через checkout Shopify, поэтому отдельный connector Stripe не требуется.

* Продуктовых дизайнеров, которым нужна кастомная витрина Replit с Shopify в качестве бэкенда электронной коммерции.

<div id="before-you-start">
  ## Перед началом работы
</div>

Подготовьте таблицу Sheet, где каждому товару соответствует отдельная строка (название, цена, описание, код товара, остаток), и папку Drive
с фотографиями, названия которых позволят Agent сопоставить их со строками. Подключите Sheets, Drive и Shopify.
Если у вас ещё нет магазина, Agent может создать его в Shopify через Chat. Оформите тестовый заказ,
прежде чем предоставлять доступ к магазину.

<div id="what-to-expect">
  ## Чего ожидать
</div>

Agent импортирует каталог в Shopify, затем создаёт витрину на Replit, которая получает товары
из Shopify и направляет покупателей на страницу checkout Shopify. Выборочно сравните несколько товаров с
таблицей (цену, описание, изображение) и оформите тестовый заказ. Используйте тестовые платежи Shopify, убедитесь, что
сумма в корзине соответствует данным в таблице, и проверьте, что checkout происходит в Shopify.

<div id="troubleshooting">
  ## Устранение неполадок
</div>

* **Фотографии не соответствуют товарам:** называйте файлы на Drive по коду товара (`CODE.jpg`) и попросите Agent пропускать строки без фотографии.
* **Цены или описания не соответствуют данным в таблице:** убедитесь, что для каждого товара есть одна строка (название, цена, описание, код товара, остаток), и выборочно проверьте несколько позиций после импорта.
* **Оформление заказа происходит не через Shopify или витрина представляет собой тему:** страницы для покупателей должны быть размещены в Replit. Платёж проходит через checkout Shopify. Оформите тестовый заказ, прежде чем делиться магазином.
