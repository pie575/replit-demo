<div id="what-is-a-workspace">
  ## 什么是 Workspace？
</div>

Replit Workspace 将你的 Projects、成员、设置、共享资源、集成和账单集中管理。

每个 Replit 账户都有一个用于个人项目的个人 Workspace；付费套餐还允许你创建用于共享项目的团队 Workspace。

<Frame caption="Workspace 主页将最近项目、Workspace 导航和对话提示汇集在一个视图中。">
  <img src="/assets/mirror/start-new-conversation-home-sanitized-neutral-874efff00786.jpg" alt="Demo Workspace 的完整 Replit 主页视图，包含 Workspace 导航、常规最近项目、建议提示词和对话消息框" width="1451" height="1084" data-path="images/chat/start-new-conversation-home-sanitized-neutral.jpg" />
</Frame>

| 功能       | 个人 Workspace  | 团队 Workspace           |
| -------- | ------------- | ---------------------- |
| **适用场景** | 个人工作或共享单个项目   | 团队、初创公司、课堂和客户项目        |
| **访问模式** | 你可以邀请访客加入单个项目 | 成员可访问 Workspace 中的所有项目 |
| **账单**   | 你的账户          | Pro 套餐中由管理员账户共享的积分     |

<div id="personal-workspace">
  ## 个人 Workspace
</div>

个人 Workspace 用于存放你自己的 project，你是其中唯一的管理员。你可以邀请他人以 project 级访客身份访问特定 project，但他们不会获得该 Workspace 内所有内容的访问权限。

<Frame caption="账户自有的 Workspace 在选择器中显示为个人 Workspace。">
  <img src="/assets/mirror/personal-workspace-selector-a7542687e3ac.jpg" alt="标有个人 workspace 的 Workspace 选择器" width="222" height="62" data-path="images/workspace/personal-workspace-selector.jpg" />
</Frame>

<div id="team-workspaces">
  ## 团队 Workspace
</div>

团队 Workspace 让团队成员能够跨多个 project 协作。成员可以访问该 Workspace 中的所有 project，无需逐个邀请。管理员则集中管理账单和设置。

有关设置步骤、成员管理和可用性详情，请参阅[团队 workspace](/zh/features/collaboration/team-workspaces)。
