Dans ce guide rapide, vous allez générer vos premiers frames de design à partir d’un prompt en langage naturel, puis utiliser les suggestions de l’IA pour explorer de nouvelles pistes en un clic. Aucune expérience en design n’est nécessaire : vous choisissez simplement ce qui vous plaît.

<Steps>
  <Step title="Ouvrez Replit Design">
    Accédez à [replit.com/design](https://replit.com/design). C’est dans le champ de prompt mis en avant que votre design prend forme.

    <Frame>
      <img src="/assets/mirror/design-hero-4a82ee579911.png" alt="La page d’accueil de Replit Design avec un champ de prompt indiquant Décrivez ce que vous souhaitez concevoir, et les options Importer une URL, Importer Figma, Recréer une capture d’écran et Commencer avec un design system juste en dessous" width="889" height="414" data-path="images/design/replit-design/design-hero.png" />
    </Frame>

    <Note>
      Vous êtes déjà dans votre workspace ? Sélectionnez plutôt **Design** sous le champ de création sur la page d’accueil de votre workspace. Le champ passe en mode design et une pastille **Design** apparaît dans le champ de prompt.

      <Frame>
        <img src="/assets/mirror/design-pill-abe180082faa.png" alt="Le champ de création sur la page d’accueil du workspace avec Design sélectionné, affichant la pastille Design dans le champ de prompt" width="800" height="270" data-path="images/design/replit-design/design-pill.png" />
      </Frame>
    </Note>
  </Step>

  <Step title="Décrivez ce que vous souhaitez concevoir">
    Rédigez votre prompt comme si vous briefiez un ami designer : ce que c’est, à qui cela s’adresse et l’ambiance que vous avez en tête. Par exemple : *&quot;Une landing page pour un service de location de supercars, audacieuse, sombre et cinématographique.&quot;* Envoyez-le ensuite.
  </Step>

  <Step title="Regardez Design créer votre projet">
    Agent reçoit votre prompt et commence à créer, en indiquant sa progression dans le panneau de chat pendant qu’il travaille.

    <Frame>
      <img src="/assets/mirror/design-building-c2ac529c1cef.png" alt="La page d’accueil de Replit Design avec le panneau de chat traitant le prompt pour une app de location de supercars de luxe, indiquant qu’il crée l’artefact Velocity" width="2000" height="1254" data-path="images/design/replit-design/design-building.png" />
    </Frame>
  </Step>

  <Step title="Examinez vos premiers frames">
    Votre design apparaît sous la forme d’un frame sur le Canvas. Patientez un instant, puis observez-le en taille réelle.

    <Frame>
      <img src="/assets/mirror/first-frames-a61342d3d85d.png" alt="La page de location de supercars Velocity générée, examinée en taille réelle en mode focus, avec un bouton Exit focus en haut du cadre" width="1600" height="1003" data-path="images/design/replit-design/first-frames.png" />
    </Frame>
  </Step>

  <Step title="Continuez à générer avec les suggestions">
    Sélectionnez le frame que vous préférez. Des suggestions apparaissent pour vous indiquer quoi concevoir ensuite ; cliquez sur l’une d’elles pour générer une nouvelle piste dans un nouveau frame, tout en conservant l’original intact. Continuez jusqu’à obtenir un résultat qui vous convient.

    <Frame>
      <img src="/assets/mirror/suggestions-9811fa570612.png" alt="Le frame Velocity généré, sélectionné sur le Canvas, avec l’exécution terminée dans le panneau de chat et le panneau des prochaines étapes suggérées qui s’ouvre à côté du frame" width="1600" height="1003" data-path="images/design/replit-design/suggestions.png" />
    </Frame>
  </Step>
</Steps>
