Créez des applications alimentées par des données actuelles et issues du monde réel grâce aux capacités de Web Search <img class="icon-svg" src="/assets/mirror/web-search-1fe8f63b5b88.svg" alt="Icône Web Search" width="16" height="16" data-path="images/icons/web-search.svg" /> d&#39;Agent.

Cette fonctionnalité repousse les limites des connaissances du modèle en accédant aux informations les plus récentes sur le web. Lorsque vous demandez à Agent de créer quelque chose qui nécessite des informations à jour, il effectue une recherche sur le web et récupère du contenu détaillé pour rendre votre app plus précise et plus utile.

La Web Search est précieuse pour trouver les packages, outils et informations les plus récents. Elle garantit que vos apps appliquent les bonnes pratiques actuelles et gagnent en précision.

<div id="funcionalidades">
  ## Fonctionnalités
</div>

Créez des applications alimentées par des informations à jour grâce à la Web Search de l&#39;Agent. Fini les recherches manuelles et la collecte de données à la main. Que vous conceviez un tableau de bord de données financières ou un site présentant les lancements récents de startups, la Web Search garantit que votre app colle à la réalité.

L&#39;Agent peut effectuer les actions de Web Search suivantes :

* **Recherche** : trouver des informations actuelles, la documentation la plus récente et des données en temps réel sur internet
* **Récupération de contenu** : extraire des informations détaillées de sites et d&#39;URL spécifiques
* **Citation des sources** : voir exactement où l&#39;Agent a trouvé les informations, afin de pouvoir les vérifier et les citer

<div id="uso">
  ## Utilisation
</div>

Web Search est intégré à Agent — il n&#39;y a rien à activer. Décrivez ce que vous souhaitez créer et Agent détermine automatiquement quand effectuer une recherche sur le web pour obtenir des informations à jour. Ajoutez des mots-clés comme « recherche », « renseigne-toi » ou « utilise Web Search » dans votre prompt pour l&#39;inciter à lancer explicitement une recherche.

<div id="citaes-de-fontes">
  ### Citations des sources
</div>

Lorsque l&#39;Agent utilise Web Search, il fournit des **citations des sources** indiquant précisément d&#39;où proviennent les informations. Utilisez ces citations pour :

* **Vérifier les informations** : contrôlez la fiabilité et l&#39;exactitude des sources
* **En savoir plus** : consultez les sources originales pour obtenir plus de contexte
* **Citer vos sources** : ajoutez l&#39;attribution appropriée dans vos applications
* **Retracer la recherche** : identifiez les informations qui ont orienté le travail de l&#39;Agent

<div id="busca-de-contedo">
  ### Récupération de contenu
</div>

L&#39;Agent peut récupérer du contenu détaillé sur des sites précis afin de rassembler des informations complètes pour votre projet. Il peut ainsi :

* Lire des pages web entières pour en extraire les détails pertinents
* Traiter de la documentation et des ressources de référence
* Collecter des données précises auprès de sources fiables
* Intégrer des informations structurées à votre application
