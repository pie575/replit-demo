本页解答有关生产数据库的常见问题。有关详细参考，请参阅[生产数据库](/zh/ja/features/data-and-storage/development-and-production)和[SQL 数据库](/zh/ja/features/data-and-storage/sql-database)。

<AccordionGroup>
  <Accordion title="数据库端点已被禁用——如何解决“endpoint has been disabled”错误？">
    此错误表示数据库计算端点已暂停。若要恢复运行：

    1. 打开 **Database** 面板，并从下拉菜单中选择 **Development**。
    2. 如果显示 **Unpause database** 按钮，请点击该按钮。
    3. 将下拉菜单切换为 **Production**；如果显示 **Unpause database**，请再次点击该按钮。

    如果未显示该按钮，可能是冲突的 `DATABASE_URL` Secrets 将其隐藏了。打开 **Secrets** 面板，比较 `DATABASE_URL` 条目与 **Database** 面板中的连接字符串，然后更新或删除冲突的 Secrets，使两者保持一致。

    常见原因包括未支付的账单 (请及时支付以避免再次发生) ，以及发布期间的临时暂停 (可按上述恢复运行步骤解决) 。请参阅[生产数据库](/zh/ja/features/data-and-storage/development-and-production)。
  </Accordion>

  <Accordion title="状态页面显示生产数据库故障——我需要提交工单吗？">
    不需要。如果故障已发布在 [status.replit.com](https://status.replit.com) 上，团队正在处理中，提交工单也不会加快修复进度。请打开当前事件并订阅更新，以获取进度通知。

    如果数据库问题*未*显示在状态页面上，请[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="如何恢复已删除或已删除（DROP）的数据库表？">
    Replit 支持将生产数据库恢复到某个时间点。恢复窗口因套餐而异：[Core](/zh/ja/billing/plans/replit-core) 为 7 天，[Pro](/zh/ja/billing/plans/replit-pro) 为 28 天。

    如需恢复，请打开 **Database** 面板，进入相应数据库并打开恢复设置，选择所需的时间戳后确认。如果所需时间点不在恢复窗口内，请[联系 Replit 支持团队](https://replit.com/support)。请参阅[生产数据库](/zh/ja/features/data-and-storage/development-and-production)。
  </Accordion>

  <Accordion title="数据库处于冻结状态，但未显示 Unpause 按钮">
    冲突的数据库 URL 常常会导致 **Unpause** 按钮被隐藏。打开 **Secrets** 面板，找到 `DATABASE_URL` 条目，并将其与 **Database** 面板中的连接字符串进行比较。如果两者不同，说明该密钥覆盖了正确的 URL——请删除该密钥并刷新页面，然后再次检查 **Database** 面板。

    如果删除冲突的密钥后按钮仍未显示，请附上项目 URL 并[联系 Replit 支持](https://replit.com/support)。
  </Accordion>

  <Accordion title="应用中出现“connection pool exhausted”错误——这是什么意思？">
    应用同时打开的数据库连接数超过了连接池的容量。常见原因包括：

    * 未在每次请求后关闭连接
    * 流量突然激增
    * 长时间占用连接的慢查询

    大多数框架都默认使用一个共享连接池，而不是为每个请求创建新连接。

    最快的解决方法是，开启一个新的 Agent 聊天，说明该错误，并请 Agent 检查应用如何管理数据库连接。
  </Accordion>

  <Accordion title="如何将开发数据库迁移到生产数据库？">
    Replit 将开发数据库与生产数据库隔离，因此测试时的更改不会影响线上数据。要对生产环境运行迁移，请将迁移命令添加到部署构建或预部署步骤中，以便每次部署时自动运行。例如，使用 Drizzle 时，请运行 `drizzle-kit migrate`。你也可以在生产环境的 Shell 中手动运行迁移。

    请参阅[发布时创建生产数据库](/zh/ja/features/data-and-storage/development-and-production)。
  </Accordion>

  <Accordion title="账单状态正常，但数据库显示“endpoint disabled”">
    这种情况有时会在与账单无关的情况下发生。请尝试手动恢复数据库。打开 **Database** 面板，选择 **Development**，如果显示 **Unpause database**，请点击它；然后对 **Production** 重复相同操作。

    如果未显示该按钮，或问题反复出现，请附上项目 URL [联系 Replit 支持](https://replit.com/support)—可能需要手动恢复数据库。请参阅[生产数据库](/zh/ja/features/data-and-storage/development-and-production)。
  </Accordion>
</AccordionGroup>
