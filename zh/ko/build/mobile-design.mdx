应用的外观和功能同样重要。PixelGames 就像手机上的 Game Boy：奶油色机身、
橄榄绿屏幕和厚实的按钮，正是它的精髓所在。普通的应用布局会让它失去这份魅力。

<div id="section">
  ## 故障排查
</div>

* **改动幅度超出预期：**请 Agent 撤销改动，并一次只描述一个屏幕或元素的
  小幅改动。
* **预览中显示正常，但在手机上看起来不同：**请告知设备名称以及您实际看到的效果。
  安全区域和屏幕尺寸的处理是常见原因。
* **改动不断被还原：**同一个值可能在多个位置设置。请询问 Agent，该屏幕的
  样式实际定义在哪里。
