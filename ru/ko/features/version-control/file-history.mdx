---
title: "История файлов"
description: "Узнайте, как восстанавливать предыдущие версии кода с помощью автоматически сохранённых точек в File History."
---

Откройте текстовый файл в Project Editor и нажмите кнопку **History** в правом нижнем углу.

<Frame>
  <img src="/assets/mirror/history-button-afac6496660a.png" alt="Открыть историю" width="377" height="292" data-path="images/programming-ide/history-button.png" />
</Frame>

<div id="section">
  ## Просмотр предыдущих версий файла
</div>

Откройте File History, чтобы просматривать предыдущие версии файла с помощью полосы прокрутки, кнопок со стрелками или клавиш **стрелка влево** и **стрелка вправо**.

<Frame>
  <img src="/assets/mirror/history-versioning-1a055ecab411.gif" alt="Демонстрация полосы прокрутки" width="764" height="720" data-path="images/animations/history-versioning.gif" />
</Frame>

<div id="section-2">
  ## Сравнение предыдущей версии с текущим файлом
</div>

Нажмите переключатель Compare Latest в левом нижнем углу окна File History, чтобы построчно сравнить файл в выбранный момент с последней версией.

<Frame>
  <img src="/assets/mirror/compare-history-46fb16debd3a.gif" alt="Сравнение с последней версией" width="772" height="720" data-path="images/animations/compare-history.gif" />
</Frame>

<div id="section-3">
  ## Восстановление предыдущей версии файла
</div>

Чтобы восстановить предыдущую версию файла, нажмите кнопку `Restore`. Не беспокойтесь: история не будет удалена. Восстановленная версия добавится в историю файла как новая.

<Frame>
  <img src="/assets/mirror/restore-history-5f616d7f961a.webp" alt="Восстановление истории" width="720" height="495" data-path="images/animations/restore-history.webp" />
</Frame>

<div id="file-history">
  ## Просмотр воспроизведения File History
</div>

С помощью функции воспроизведения File History можно увидеть, как файл меняется со временем, словно в фильме. Это удобно для создания видеозаписи сеанса программирования.
