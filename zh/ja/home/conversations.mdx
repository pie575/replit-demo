<div id="conversations-vs-projects">
  ## 对话 与 Projects
</div>

对话 是用于提问、探索和运行 Routine 的单个对话线程。[Project](/zh/features/projects-and-artifacts/projects) 则是用于开展更复杂的构建和设计工作的工作区，可包含多个 artifact。

从 对话 开始。当工作发展为较复杂的构建或设计时，可将 对话 转为 Project。

侧边栏中，对话 使用聊天气泡图标，Project 使用四宫格图标。

<Frame>
  <img src="/assets/mirror/conversation-and-project-icons-025a17613daa.png" alt="Replit 侧边栏显示：Project 使用四宫格图标，对话 使用聊天气泡图标" width="466" height="290" data-path="images/chat/conversation-and-project-icons.png" />
</Frame>

| 区域      | 对话  | Projects                               |
| ------- | -------------- | -------------------------------------- |
| 最适合     | 提问、探索和 Routine | 更复杂的构建和设计工作，例如 App、幻灯片、仪表板和多个 artifact |
| 后台任务    | **不可用**        | **可并行运行**                              |
| Routine | **可用**         | **不可用**                                |
| 集成      | 可用             | 可用                                     |
| 结构      | 单个对话线程         | 包含多个 artifact 的 project 工作区            |
