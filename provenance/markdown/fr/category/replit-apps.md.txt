## Qu'est-ce qu'une application Replit ?

Les applications Replit sont des projets hébergés dans le cloud qui contiennent du code, des données et des ressources.
Vous pouvez les créer, les exécuter et les publier depuis un environnement sécurisé et isolé.

Les applications Replit s'intègrent aux outils suivants dans le Project Editor pour offrir
une expérience de développement fluide :

* **Outils alimentés par l'IA** : Utilisez l'Agent pour créer, déboguer et expliquer votre code.
* **Collaboration** : Travaillez avec d'autres personnes en temps réel sur la même application.
* **Publication** : Publiez votre application dans le cloud en un seul clic.

## Fonctionnalités clés

Les applications Replit offrent les fonctionnalités suivantes :

* **Sans configuration** : Créez des applications ou écrivez du code directement sur Replit.com sans installation ni configuration.
* **Sauvegarde automatique** : Votre projet sauvegarde continuellement les modifications dans le cloud et vous permet de reprendre le codage depuis n'importe quel navigateur web
* **Contrôle de version** : Suivez les modifications, explorez l'historique des fichiers et synchronisez vos fichiers sans aucune configuration, grâce aux systèmes de contrôle de version de Replit
* **Contrôles de visibilité public/privé** : Contrôlez qui peut voir, exécuter ou créer un remix de votre application avec les paramètres de confidentialité
* **Publication** : Publiez votre code dans le cloud sans effectuer de modifications de configuration complexes
* **URLs d'application personnalisées** : Obtenez une URL unique pour votre application ou attribuez un domaine personnalisé pour une présence professionnelle

<Info>
  Les fichiers téléchargés dans votre espace de travail ne sont disponibles que pendant le développement et
  ne sont pas accessibles à votre application publiée ni aux autres constructeurs. Utilisez le [Stockage
  d'objets](/fr/features/data-and-storage/object-storage) pour gérer les téléchargements des constructeurs
  et servir des fichiers, et la [Base de données
  Replit](/fr/features/data-and-storage/sql-database) pour stocker et récupérer des données pour votre application et vos utilisateurs.
</Info>

Pour en savoir plus sur les outils du Project Editor qui simplifient la création d'applications Replit, consultez [Aperçu du Project Editor](/fr/learn/projects-and-artifacts/project-editor/).

## Comment ça fonctionne

Lorsque vous créez une application Replit, Replit configure un espace privé pour votre projet dans le cloud.
Au fur et à mesure que vous ajoutez des fonctionnalités et des modifications à votre application, Replit sauvegarde vos modifications
automatiquement afin que vous puissiez reprendre l'édition depuis n'importe quel navigateur web.

Replit fournit des environnements préconfigurés avec tous les composants nécessaires.
Cela vous permet de commencer à créer votre application immédiatement sans vous soucier de
la configuration du serveur, de la configuration de la base de données ou de la gestion de l'environnement.

Replit attribue automatiquement à chaque application Replit une adresse web unique où vous
pouvez prévisualiser votre application pendant que vous travaillez dessus. Lorsque vous êtes prêt à partager votre
création, vous pouvez la publier en quelques clics pour la rendre disponible 24h/24 et 7j/7.

## Aperçu du stockage

Replit propose quatre types de stockage principaux pour répondre aux besoins en données de votre application. Chaque type de stockage répond à des cas d'usage différents et a des limites spécifiques selon votre plan.

<Info>
  Les limites de stockage incluent toutes les données stockées par votre application, notamment les packages
  et dépendances installés.
</Info>

| Type de stockage                                                            | Description                       | Cas d'usage                                                         | Persistance                                                  | Limites du plan                                                                                                                                          |
| --------------------------------------------------------------------------- | --------------------------------- | ------------------------------------------------------------------- | ------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Stockage de fichiers**                                                    | Fichiers dans votre projet        | Code d'application, ressources statiques, fichiers de configuration | Persisté lors de la publication, réinitialisé au redémarrage | Starter : {StarterWorkspaceStorage}<br />Core : {CoreWorkspaceStorage}<br />Pro : {TeamsWorkspaceStorage}<br />Enterprise : {EnterpriseWorkspaceStorage} |
| **[Base de données](/fr/features/data-and-storage/sql-database/)**          | Stockage de données structurées   | Profils d'utilisateurs, scores de jeux, catalogues de produits      | Entièrement persistant entre les sessions                    | 20 Go par base de données de développement<br />Les bases de données de production sont facturées par temps de calcul et stockage                        |
| **[Stockage d'application](/fr/features/data-and-storage/object-storage/)** | Données non structurées et médias | Images, vidéos, PDFs, documents                                     | Entièrement persistant entre les sessions                    | Modèle de paiement à l'utilisation<br />Facturé par stockage et bande passante                                                                           |
| **[Secrets](/fr/core-concepts/project-editor/app-setup/secrets/)**          | Données sensibles chiffrées       | Clés API, identifiants, chaînes de connexion                        | Entièrement persistant et chiffré                            | Pas de limites spécifiques<br />Inclus avec tous les plans                                                                                               |
