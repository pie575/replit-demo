<div id="troubleshooting">
  ## 故障排除
</div>

* **始终收不到确认邮件：**确认 Resend 已连接，且发件人域名已通过验证。创建一笔测试订单，并在 Resend 仪表板中查看邮件是否已发送。
* **演讲嘉宾或时间有误：**让 Agent 使用 Notion 数据库中的信息 (姓名、照片、职位、简介、场次时间) ，并要求它在 Notion 发生更改时保持页面同步。
* **结账流程未扣款：**确认 Stripe 已连接，并先确保处于测试模式。分享链接前，先创建一笔测试订单。
