<div id="agent-2">
  ### Nouveau menu déroulant des modes Agent
</div>

Le sélecteur de mode Agent dans le champ de saisie du chat est désormais un contrôle segmenté simple. Vous pouvez passer de Lite à Economy ou Power depuis la barre d’outils et accéder à Turbo dans les paramètres avancés si nécessaire.

Nouveautés :

* **Contrôle segmenté dans la barre d’outils.** Lite, Economy et Power s’affichent côte à côte, ce qui permet d’identifier clairement le mode actif et de savoir comment le changer.
* **Raccourci clavier.** Appuyez sur **⌘+Shift+I** (Ctrl+Shift+I sous Windows) pour changer de mode sans utiliser la souris.
* **Turbo mis en évidence en orange.** Turbo est le mode le plus rapide, mais aussi le plus coûteux. Il est donc davantage visible dans l’UI afin de mieux faire ressortir ce compromis.
* **Paramètres avancés repliés par défaut.** Les options de test, de revue de code et de Turbo sont regroupées dans les paramètres avancés, afin de garder la vue principale épurée.
* **Le mode Max a été supprimé.** Utilisez Power pour les builds les plus exigeants et activez Turbo dans les paramètres avancés lorsque vous avez besoin des réponses les plus rapides.

<div id="agent-3">
  ### Agent suggère des tâches de suivi
</div>

<Frame>
  <video autoPlay muted loop playsInline src="/assets/mirror/replit-suggested-tasks-b27620d93fd2.mp4" />
</Frame>

Une fois son travail terminé, Agent propose désormais des **tâches de suivi** indiquant ce que vous pourriez développer ensuite, en s’appuyant sur l’ensemble du contexte de votre projet. Trois types de suggestions s’affichent sous chaque tâche terminée :

* **Nouvelles fonctionnalités à développer** — des fonctionnalités qui complètent naturellement ce que vous venez de publier
* **Améliorations des performances** — des optimisations qu’Agent a repérées pendant l’exécution de la tâche
* **Améliorations de l’expérience utilisateur** — des ajustements pour peaufiner vos fonctionnalités

Examinez chaque suggestion et sélectionnez **Approuver** pour celles que vous souhaitez conserver afin qu’Agent puisse poursuivre le développement tout en les exécutant en arrière-plan. Masquez les suggestions inutiles avec **Masquer les tâches suggérées** dans la colonne Done, puis réaffichez-les à tout moment.

Découvrez les [suggestions de tâches de suivi](/fr/ja/features/agent/follow-up-tasks).

<div id="section-3">
  ### Améliorations de la page des projets
</div>

La page des projets bénéficie de trois améliorations pratiques :

* **Aperçu des Artifacts sur toutes les cartes.** Chaque carte de projet affiche désormais de petites icônes pour chaque Artifact qu’elle contient. Survolez une icône pour afficher un aperçu de la capture d’écran de cet Artifact sans ouvrir le projet.
* **Tri par défaut selon la dernière ouverture.** La page place désormais en tête les projets sur lesquels *vous* avez travaillé récemment, afin que votre travail en cours reste au premier plan, même dans les espaces de travail d’équipe très actifs.
* **Épinglage personnel.** Vous pouvez épingler les projets auxquels vous revenez souvent. Vos épingles ne sont visibles que par vous et n’affectent pas ce que voient les autres membres de l’espace de travail.

<div id="scim">
  ### Groupes personnalisés pour les Organizations avec SCIM
</div>

Les Organizations ayant activé le provisionnement SCIM peuvent désormais créer des groupes personnalisés dans Replit, en parallèle des groupes synchronisés par l’IdP. Utilisez des groupes personnalisés pour gérer l’accès par projet, accorder des autorisations ponctuelles ou représenter des structures qui ne figurent pas dans votre fournisseur d’identité.

Les groupes synchronisés par SCIM restent gérés via votre fournisseur d’identité, tandis que les groupes personnalisés sont gérés directement dans Replit par les administrateurs de l’Organization.

Pour en savoir plus, consultez [SCIM](/fr/ja/teams/identity-and-access-management/scim#creating-custom-groups-alongside-scim).
