В этом справочном руководстве описан класс `Client` из библиотеки `object-storage` и приведены примеры кода для его методов.

<div id="client">
  ## Client
</div>

Класс `Client` управляет взаимодействием с Replit App Storage. В нём есть методы для работы с файлами в бакете.

Чтобы импортировать класс из библиотеки, добавьте в свой JavaScript-код следующую строку:

```javascript theme={null}
import { Client } from "@replit/object-storage";
```

Используйте следующий код, чтобы создать экземпляр `Client` для работы с Replit Object Storage:

```javascript theme={null}
const client = new Client();
```

<div id="section">
  ## Конструктор
</div>

**constructor**

* **new Client**(`options?`): `Client`

Создаёт новый экземпляр Client для работы с Replit App Storage.

**Параметры**

| Имя        | Тип             | Описание                                      |
| :--------- | :-------------- | :-------------------------------------------- |
| `options?` | `ClientOptions` | Параметры конфигурации для настройки клиента. |

**Возвращаемое значение**

`Client`

<div id="section-2">
  ## Методы
</div>

<div id="copy">
  ### copy
</div>

* **copy**(`objectName`, `destObjectName`): `Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

Копирует объект внутри одного бакета.
Если по целевому пути уже есть объект, метод перезапишет его.

**Параметры**

| Имя              | Тип      | Описание                                              |
| :--------------- | :------- | :---------------------------------------------------- |
| `objectName`     | `string` | Полный путь к копируемому объекту.                    |
| `destObjectName` | `string` | Полный путь, по которому будет создана копия объекта. |

**Возвращаемое значение**

`Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

***

<div id="uploadfrombytes">
  ### uploadFromBytes
</div>

* **uploadFromBytes**(`objectName`, `contents`, `options?`): `Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

Загружает объект, используя его байтовое представление в памяти.
Этот метод перезаписывает существующий объект с тем же именем.

**Параметры**

| Имя          | Тип             | Описание                                         |
| :----------- | :-------------- | :----------------------------------------------- |
| `objectName` | `string`        | Полный путь, по которому загружается объект.     |
| `contents`   | `Buffer`        | Необработанное содержимое объекта в виде байтов. |
| `options?`   | `UploadOptions` | Настройки операции загрузки.                     |

**Возвращаемое значение**

`Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

<div id="uploadfromfilename">
  ### uploadFromFilename
</div>

* **uploadFromFilename**(`objectName`, `srcFilename`, `options?`): `Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

Загружает файл из локальной файловой системы в бакет.
Этот метод перезаписывает существующий объект с таким же именем.

**Параметры**

| Имя           | Тип             | Описание                                                |
| :------------ | :-------------- | :------------------------------------------------------ |
| `objectName`  | `string`        | Полный путь, по которому будет загружен объект.         |
| `srcFilename` | `string`        | Путь к загружаемому файлу в локальной файловой системе. |
| `options?`    | `UploadOptions` | Настройки операции загрузки.                            |

**Возвращаемое значение**

`Promise`&lt;`Result`&lt;`null`, `RequestError`&gt;&gt;

<div id="uploadfromstream">
  ### uploadFromStream
</div>

* **uploadFromStream**(`objectName`, `stream`, `options?`): `Promise`&lt;`void`&gt;

Загружает объект, считывая содержимое из переданного потока.
Поток выдаёт события об ошибках, возникших во время загрузки. Этот метод перезаписывает существующий объект с тем же именем.

**Параметры**

| Имя          | Тип             | Описание                                                  |
| :----------- | :-------------- | :-------------------------------------------------------- |
| `objectName` | `string`        | Полный путь, по которому загружается объект.              |
| `stream`     | `Readable`      | Поток чтения, из которого считывается содержимое объекта. |
| `options?`   | `UploadOptions` | Настройки операции загрузки.                              |

**Возвращаемое значение**

`Promise`&lt;`void`&gt;
