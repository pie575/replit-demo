Ces réponses portent sur l&#39;utilisation d&#39;Agent. Pour la documentation complète, consultez la [Présentation d&#39;Agent](/fr/ko/features/agent/overview), les [Modes Agent](/fr/ko/features/agent/agent-modes) et la [Facturation de l&#39;IA](/fr/ko/billing/ai-billing).

<AccordionGroup>
  <Accordion title="Agent se bloque ou se déconnecte sans cesse. Comment résoudre ce problème ?">
    1. Ouvrez la palette de commandes avec `Cmd+K` (Mac) ou `Ctrl+K` (Windows).
    2. Recherchez et sélectionnez **Restart compute** pour redémarrer votre environnement de développement.
    3. Ouvrez un nouveau chat Agent et décrivez à nouveau votre tâche pour poursuivre.

    N&#39;envoyez aucun message tant qu&#39;Agent semble bloqué : les messages supplémentaires génèrent des instructions contradictoires. Si Agent bloque toujours sur la même tâche, découpez-la en prompts plus courts et plus ciblés.
  </Accordion>

  <Accordion title="Agent répète la même étape ou tourne en boucle. Comment l’arrêter ?">
    1. Sélectionnez **Stop** dans le panneau Agent pour l’interrompre immédiatement.
    2. Ouvrez la palette de commandes avec `Cmd+K` (Mac) ou `Ctrl+K` (Windows), recherchez **Restart compute**, puis sélectionnez cette option.
    3. Ouvrez une nouvelle discussion avec Agent et ressaisissez la tâche de manière plus précise.

    Pour éviter les boucles :

    * Divisez les tâches importantes en prompts plus petits. Un objectif par message.
    * Utilisez le [mode Plan](/fr/ko/features/agent/plan-mode) pour définir le périmètre de la tâche avant qu’Agent ne commence à créer l’application.
    * Définissez des limites d’utilisation dans [Gérer les dépenses](/fr/ko/billing/managing-spend) afin d’éviter une facturation excessive due aux boucles.
  </Accordion>

  <Accordion title="Comment réduire les coûts d’Agent ? Quels réglages sont réellement efficaces ?">
    Voici les choix qui font la plus grande différence :

    * **[Mode Free](/fr/ko/features/agent/agent-modes)** — des tâches Agent quotidiennes sans frais, dans la limite du quota accordé aux abonnés Core et Pro.
    * **[Mode Power](/fr/ko/features/agent/agent-modes)** — davantage de puissance à un tarif raisonnable lorsque votre tâche l&#39;exige.
    * **[Mode Plan](/fr/ko/features/agent/plan-mode)** — délimitez et validez le périmètre du travail avant que l&#39;Agent ne lance le build, afin d&#39;éviter de payer pour des modifications non souhaitées.
    * **Limites d&#39;utilisation et budgets** — définissez des plafonds stricts dans [Gestion des dépenses](/fr/ko/billing/managing-spend).

    Démarrer un nouveau chat Agent lorsque vous changez de tâche est également utile. Consultez le tableau de bord d&#39;utilisation pour identifier les tâches qui coûtent le plus cher.
  </Accordion>

  <Accordion title="Qu’est-ce que le mode Agent et en quoi est-il différent ?">
    Agent propose trois modes principaux. Consultez le guide complet sur le [mode Free](/fr/ko/help/free-agent-mode).

    * **Mode Free**—tâches quotidiennes gratuites avec Agent pour les abonnés Core et Pro, dans la limite d’un quota réinitialisé toutes les 5 heures et plafonné chaque semaine. Le niveau Starter conserve ses limites actuelles. Pour consulter votre utilisation, accédez à **Paramètres → Utilisation**.
    * **Power**—mode payant intermédiaire offrant des modèles puissants à un prix raisonnable.
    * **Max**—mode payant haut de gamme offrant les meilleurs modèles de pointe pour les tâches les plus exigeantes.
    * **Turbo**—option facultative dans les paramètres avancés, disponible uniquement avec Max.

    Les noms des modes payants ont changé. **Economy s’appelle désormais Power**, et le mode précédemment appelé **Power s’appelle désormais Max**. Vos paramètres de mode existants sont conservés sous leurs nouveaux noms. Si votre demande nécessite plus de puissance que le mode Free, Agent peut proposer l’option payante **Autoriser une seule fois**. Replit demande confirmation avant le début d’une tâche payante, puis Agent revient au mode Free.

    Par ailleurs, le [mode Plan](/fr/ko/features/agent/plan-mode) permet à Agent de définir le périmètre du travail avant d’apporter des modifications, tandis que le mode Build applique directement les modifications. Consultez [mode Plan vs. mode Build](/fr/ko/learn/plan-vs-build-mode).
  </Accordion>

  <Accordion title="Agent a apporté des modifications que je ne souhaite pas. Comment les annuler ?">
    Replit enregistre des [checkpoints](/fr/ko/features/version-control/checkpoints-and-rollbacks) pendant qu&#39;Agent travaille. Dans le chat Agent, repérez le message qui précède la modification que vous souhaitez annuler, puis sélectionnez l&#39;option de rollback affichée à côté pour restaurer votre projet à cet état.

    Pour découvrir toutes les options de rollback, y compris la restauration de fichiers spécifiques, consultez [Checkpoints et rollbacks](/fr/ko/features/version-control/checkpoints-and-rollbacks).
  </Accordion>

  <Accordion title="Agent ne peut pas accéder à Internet ni à des API externes. Est-ce normal ?">
    Lors des phases de création et de modification, Agent fonctionne dans un environnement isolé avec un accès sortant limité. Les applications publiées peuvent effectuer des appels vers des API externes lors de leur exécution. Cet environnement isolé s’applique à l’environnement de modification d’Agent, et non à l’application en cours d’exécution.

    Si des appels API échouent dans une application en cours d’exécution, vérifiez qu’une clé est enregistrée dans le panneau [Secrets](/fr/ko/core-concepts/project-editor/app-setup/secrets), puis consultez la page d’état du fournisseur. Sur les réseaux d’entreprise ou scolaires, les connexions sortantes de l’application peuvent être bloquées. Contactez alors votre administrateur réseau.
  </Accordion>

  <Accordion title="Puis-je utiliser ma propre clé API dans Agent ?">
    Oui. Si vous ajoutez la clé dans le panneau [Secrets](/fr/ko/core-concepts/project-editor/app-setup/secrets), votre app l&#39;utilisera pour ses appels à l&#39;API. Ouvrez l&#39;outil **Secrets**, sélectionnez **+ Nouveau secret**, puis saisissez un nom (par exemple `OPENAI_API_KEY`) et une valeur.

    Vous pouvez [utiliser votre propre clé de fournisseur d&#39;IA](/fr/ko/features/integrations/replit-ai-integrations) pour les modèles appelés par votre app. En revanche, les modèles qui alimentent l&#39;expérience Agent s&#39;exécutent sur l&#39;infrastructure de Replit et ne peuvent pas être remplacés.
  </Accordion>

  <Accordion title="Agent continue d’ajouter des fonctionnalités que je n’ai pas demandées. Comment le rendre plus précis ?">
    Recentrez Agent avec des prompts plus précis :

    * Commencez par *Only*. Par exemple : &quot;Only add a delete button to the user card. Don&#39;t change anything else.&quot;
    * Utilisez d&#39;abord le [mode Plan](/fr/ko/features/agent/plan-mode) pour examiner ce qu&#39;Agent compte faire avant qu&#39;il n&#39;apporte des modifications.
    * Si Agent a effectué une modification non souhaitée, demandez-lui de l&#39;annuler immédiatement dans la même conversation.

    Pour en savoir plus, consultez [Prompting efficace](/fr/ko/learn/effective-prompting).
  </Accordion>
</AccordionGroup>
