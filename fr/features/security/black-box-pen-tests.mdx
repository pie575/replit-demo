Un test d&#39;intrusion en boîte noire examine une application en cours d&#39;exécution depuis l&#39;extérieur, via des interactions navigateur et réseau. Il n&#39;utilise pas le code source de l&#39;application.

Dans le Project Security Center, le **Level 3 (AI pentest)** regroupe trois types de contrôles de sécurité :

1. Des vérifications gratuites des dépendances et des paquets
2. Une analyse statique de votre code source par Agent
3. Un test externe en boîte noire du Preview en direct, mené depuis l&#39;extérieur sans recourir à votre code source

Une fois le Level 3 lancé, Replit exécute en parallèle la revue du code source par Agent et le test externe en boîte noire.

<div id="run-a-level-3-scan">
  ## Lancer une analyse de Level 3
</div>

<Steps>
  <Step title="Ouvrir le project">
    Ouvrez le project que vous souhaitez analyser.
  </Step>

  <Step title="Ouvrir le Security Center">
    Dans le volet **Tools** du project, sélectionnez **Security Center**.
  </Step>

  <Step title="Lancer une analyse">
    En haut du Security Center, sélectionnez **Run scan**.
  </Step>

  <Step title="Choisir le Level 3">
    Sélectionnez **Level 3 (AI pentest)**.

    <Frame caption="Le Level 3 (AI pentest) complète les vérifications gratuites des dépendances et des paquets par une analyse statique réalisée par Agent et un test externe en direct sur la Preview.">
      <img src="/assets/mirror/level-3-ai-pentest-c223c0099d3f.png" alt="Security and Privacy Center ouvert depuis le volet Tools avec le menu Select scan level déployé et Level 3 AI pentest sélectionné" width="2204" height="1200" data-path="images/project-security-center/level-3-ai-pentest.png" />
    </Frame>
  </Step>

  <Step title="Attendre la fin des deux tâches">
    Attendez la fin de la revue du code source et du test en boîte noire portant sur le navigateur et le réseau.
  </Step>

  <Step title="Examiner les résultats">
    Examinez les constats des deux tâches dans le volet **Security**. Évaluez chaque constat avant d&#39;envoyer à Agent les problèmes retenus.
  </Step>

  <Step title="Corriger et relancer">
    Envoyez les constats retenus à Agent. Une fois les correctifs appliqués, lancez une nouvelle analyse de Level 3 pour les vérifier.
  </Step>
</Steps>

<div id="understand-the-two-tasks">
  ## Comprendre les deux tâches
</div>

| Tâche                               | Éléments utilisés                                                                 | Objectif                                                                                                |
| ----------------------------------- | --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| Revue du code source                | Le code source de votre application                                               | Identifie les vulnérabilités de sécurité, de confidentialité et d&#39;architecture dans la base de code |
| Test d&#39;intrusion en boîte noire | Interactions navigateur et réseau avec l&#39;application en cours d&#39;exécution | Examine le comportement observable de l&#39;extérieur, sans recourir au code source                     |

Passez en revue les constats des deux tâches. L&#39;une ne remplace pas l&#39;autre : la revue du code source permet de repérer des détails d&#39;implémentation vulnérables, tandis que le test en boîte noire évalue l&#39;application en cours d&#39;exécution depuis l&#39;extérieur.
