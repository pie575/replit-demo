Lorsqu&#39;Agent travaille, un message de suivi peut soit modifier la tâche en cours
d&#39;Agent — son **tour en cours** —, soit attendre la fin de ce tour :

* **Steer** envoie le message au tour en cours. Agent tient compte de ce nouveau contexte pour poursuivre son travail.
* **Queue** met le message de côté pour le tour suivant. Agent le traite une fois le tour actif terminé.

<div id="steering-conversations">
  ## Orienter les conversations
</div>

L&#39;orientation est le comportement d&#39;envoi par défaut des messages de suivi dans les Conversations et
les Projects. Vous pouvez remplacer l&#39;une ou l&#39;autre de ces préférences par la mise en file d&#39;attente.

<div id="choose-how-replit-sends-follow-ups">
  ## Choisir la manière dont Replit envoie les messages de suivi
</div>

Vous pouvez définir des comportements d&#39;envoi distincts pour les Conversations et les Projects :

1. Ouvrez **Settings** &gt; **Personalization**.
2. Développez **Agent**.
3. Réglez **Conversation send behavior** et **Project send behavior** sur **Steer** ou **Queue**.

<Frame caption="Paramètres de comportement d'envoi pour Conversation et Project dans la section Agent.">
  <img src="/assets/mirror/agent-follow-ups-settings-98a4c5ca399e.png" alt="Paramètres de l'Agent affichant le comportement d'envoi pour Conversation et Project avec les options Steer et Queue" width="3048" height="1372" data-path="images/replitai/agent-follow-ups-settings.png" />
</Frame>

<Info>
  Le mode Design oriente toujours les messages de suivi. Les paramètres de comportement
  d&#39;envoi pour Conversation et Project ne s&#39;appliquent pas en mode Design.
</Info>

Pour envoyer un message unique avec le comportement inverse de votre préférence, appuyez sur
`Cmd+Enter` (Mac) ou `Ctrl+Enter` (Windows et Linux).

<div id="work-with-queued-messages">
  ## Travailler avec les messages Queue
</div>

Lorsque vous mettez un message de suivi en Queue, la Queue de messages
apparaît sous forme de tiroir au-dessus de la zone de saisie du Chat. Agent traite
les messages en Queue dans l&#39;ordre, une fois le tour en cours terminé. Le tiroir se
ferme lorsque Agent a traité tous les messages en Queue.

Toutes les options de message sont disponibles avec la Queue, y compris le [Visual Editor](/fr/design/visual-editor)
et les pièces jointes.

<Info>
  Agent traite automatiquement les messages en Queue uniquement si une session
  active du Project Editor est connectée sur ordinateur ou mobile.
</Info>

<div id="manage-the-queue">
  ### Gérer la file d&#39;attente
</div>

Lorsque le tiroir de la file d&#39;attente est ouvert, vous pouvez :

* **Orienter maintenant** : déplacer un message en attente dans le tour en cours.
* **Modifier des messages** : modifier un message en attente avant qu&#39;Agent ne le traite.
* **Supprimer des messages** : retirer les messages dont vous n&#39;avez plus besoin.
* **Réorganiser les messages** : faire glisser les messages pour modifier leur ordre de traitement.
* **Ajouter des messages** : envoyer d&#39;autres messages de suivi dans la file d&#39;attente.

<div id="stop-the-active-turn">
  ## Interrompre le tour en cours
</div>

Sélectionnez **Stop** dans la barre d&#39;état pour interrompre le travail en cours
de Replit sur le tour actuel. Vous pouvez ensuite envoyer un nouveau message sans
attendre qu&#39;Agent termine le tour ou traite les messages en attente.
