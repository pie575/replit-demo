Décrivez à voix haute ce que vous voulez créer grâce au mode vocal. Appuyez sur le microphone dans la zone de chat de l&#39;Agent, énoncez votre prompt : Replit transcrit vos paroles en texte modifiable. Relisez ce texte, modifiez-le si besoin, puis envoyez-le comme n&#39;importe quel autre message.

Le mode vocal est utile lorsque la saisie au clavier est lente ou peu commode, en particulier sur mobile, où dicter un prompt complet est souvent plus rapide que de le taper au pouce.

<Note>
  Le mode vocal convertit vos paroles en texte dans la zone de chat. Il ne lit
  pas à voix haute les réponses de l&#39;Agent : vous envoyez toujours un message
  écrit, et l&#39;Agent répond dans le chat comme d&#39;habitude.
</Note>

<div id="how-it-works">
  ## Fonctionnement
</div>

<Frame>
  <img src="/assets/mirror/voice-mode-mic-button-fe7da6953736.png" alt="La zone de chat d'Agent avec le bouton microphone mis en évidence et une infobulle « Démarrer la saisie vocale », à côté de la case Plan et de la flèche d'envoi" width="1853" height="423" data-path="images/replitai/voice-mode/voice-mode-mic-button.png" />
</Frame>

Le mode vocal enregistre votre voix, la transcrit et insère le résultat dans la zone de chat pour que vous puissiez le relire avant de l&#39;envoyer :

1. Ouvrez Agent et sélectionnez le microphone dans la zone de chat.
2. Autorisez l&#39;accès au microphone si votre navigateur ou votre appareil vous le demande.
3. Énoncez votre prompt. Une forme d&#39;onde indique qu&#39;Agent enregistre.
4. Arrêtez l&#39;enregistrement lorsque vous avez terminé. L&#39;enregistrement s&#39;arrête aussi automatiquement après une pause ou lorsque vous quittez l&#39;onglet.
5. Patientez quelques instants, le temps que votre voix soit transcrite.
6. Relisez le texte transcrit, modifiez-le si nécessaire, puis envoyez votre message.

Comme la transcription apparaît sous forme de texte ordinaire dans la zone de chat, vous pouvez combiner librement voix et saisie au clavier : dictez une partie d&#39;un prompt, puis tapez le reste, ou corrigez un mot avant d&#39;envoyer.

<Tip>
  Parlez naturellement. Le mode vocal s&#39;attache à capter ce que vous voulez dire
  plutôt qu&#39;à transcrire chaque mot littéralement : les mots de remplissage comme
  « euh » et « hum » sont donc écartés du résultat.
</Tip>

<div id="where-you-can-use-it">
  ## Où vous pouvez l’utiliser
</div>

Le mode vocal est disponible dans la zone de chat d’Agent :

* Dans le **Project Editor**, lorsque vous travaillez avec Agent sur une application.
* Lorsque vous **créez une nouvelle application** à partir du prompt d’Agent sur l’écran d’accueil.

Vous pouvez utiliser le mode vocal sur le Web sur ordinateur, le Web mobile et l’application mobile Replit.

<div id="good-to-know">
  ## Bon à savoir
</div>

Gardez ces détails à l&#39;esprit lorsque vous utilisez le mode vocal :

| Détail                         | À quoi s&#39;attendre                                                                                                                                                                                               |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Durée d&#39;enregistrement     | Enregistrez jusqu&#39;à 6 minutes d&#39;affilée. Un avertissement s&#39;affiche peu avant la limite.                                                                                                                |
| Arrêt automatique              | L&#39;enregistrement s&#39;arrête tout seul après environ 30 secondes de silence, ou lorsque vous changez d&#39;onglet ou mettez l&#39;application en arrière-plan.                                                 |
| Vérification avant l&#39;envoi | Le texte transcrit s&#39;affiche dans la zone de Chat afin que vous puissiez le relire et le modifier avant de l&#39;envoyer — rien n&#39;est envoyé automatiquement.                                               |
| Accès au microphone            | Le mode vocal a besoin de votre autorisation pour utiliser le microphone. Si l&#39;enregistrement ne démarre pas, vérifiez que votre navigateur et votre appareil autorisent l&#39;accès au microphone pour Replit. |

<div id="availability">
  ## Disponibilité
</div>

Le mode vocal est disponible sur toutes les formules Replit. Le microphone apparaît dans la zone de Chat de l&#39;Agent sur les navigateurs et appareils compatibles avec l&#39;enregistrement audio, et l&#39;autorisation d&#39;accès au microphone vous sera demandée lors de votre premier enregistrement.
