<div id="section">
  ## 创建自定义主题
</div>

按照以下步骤创建并自定义自己的主题。

1. 打开[设置](https://replit.com/settings)，然后进入 **用户** → **个性化** (或 **主题** 部分)
2. 选择 **创建新主题**
3. 输入标题，选择配色方案 (浅色主题或深色主题) ，也可选择添加描述
4. 选择 **创建主题** 以打开主题编辑器

全局主题设置可控制整体界面外观。

* **背景**：设置大多数界面区域的基础颜色
* **轮廓**：控制边框和分隔线的颜色
* **前景**：确定文本和图标的颜色
* **主色**：定义按钮和交互元素的颜色
* **正向**：用于 **运行** 按钮等成功状态指示
* **负向**：用于错误和破坏性操作警告

选择 **应用主题**，即可立即开始使用自定义主题。

<div id="section-2">
  ## 语法高亮
</div>

自定义各类代码元素的显示方式，以提高可读性和易理解性。

<Tip>
  恰当的语法高亮能让你更轻松地快速浏览和理解代码。请选择彼此协调且与背景具有足够对比度的颜色。
</Tip>

<Accordion title="语法高亮元素">
  | 元素        | 说明                                       |
  | --------- | ---------------------------------------- |
  | **变量名称**  | 应用于未使用声明关键字声明的变量                         |
  | **变量定义**  | 为使用 `const` 或 `var` 等关键字定义的变量名称设置颜色      |
  | **函数引用**  | 调用函数时应用                                  |
  | **函数定义**  | 声明函数名称时设置颜色                              |
  | **关键字**   | 突出显示 `import`、`function`、`return` 等语言关键字 |
  | **属性名称**  | 为变量中的属性访问设置颜色                            |
  | **属性定义**  | 定义对象属性时使用                                |
  | **函数属性**  | 调用对象方法时应用                                |
  | **标签名称**  | 用于 HTML 和 JSX 标签                         |
  | **类型名称**  | 为带类型语言中的类型注释设置颜色                         |
  | **类名称**   | 应用于类声明和引用                                |
  | **属性名称**  | 突出显示 HTML 和 JSX 属性                       |
  | **注释**    | 应用于所有代码注释                                |
  | **字符串**   | 为字符串字面量设置颜色                              |
  | **数字**    | 突出显示数值                                   |
  | **布尔值**   | 设置布尔值 (`true`/`false`) 的格式               |
  | **正则表达式** | 为正则表达式模式设置颜色                             |
  | **运算符**   | 突出显示 `+`、`-`、`*`、`/` 等运算符                |
  | **括号**    | 根据需要为方括号和尖括号设置颜色                         |
</Accordion>

<div id="section-3">
  ## 主题设计最佳实践
</div>

请遵循以下指南，创建美观且实用的主题。

<div id="section-4">
  ### 色彩与对比度
</div>

* **平衡对比度**：确保背景与前景元素之间有足够的对比
* **创建协调的调色板**：选择彼此协调、不相冲突的颜色
* **保持亮度一致**：确保各个语法元素的亮度水平相近
* **兼顾无障碍访问**：避免使用低对比度组合，并照顾视障用户

<Warning>
  主题设计中应避免的常见问题：

  * 语法元素之间的亮度差异过大
  * 颜色搭配不当，造成视觉不协调
  * 代码与背景之间的对比度不足
</Warning>

<div id="section-5">
  ## 管理主题
</div>

前往 [设置](https://replit.com/settings)中的 **User** → **个性化** (或 **主题** 部分) ，即可访问和管理所有已安装的主题。

<div id="section-6">
  ### 切换主题
</div>

选择主题标题旁的按钮，将其设为当前主题。

<div id="section-7">
  ### 编辑主题
</div>

选择三点菜单，然后点击 **编辑**，即可修改自定义主题。

<Note>
  你只能编辑或删除自己创建的自定义主题。默认主题和其他人创建的主题无法修改。
</Note>

<div id="section-8">
  ### 删除主题
</div>

在三点菜单中选择 **Delete**，即可删除自定义主题。

<div id="section-9">
  ## 探索社区主题
</div>

在[主题探索页面](https://replit.com/themes)探索由 Replit 社区创建的主题。

<div id="section-10">
  ### 查找主题
</div>

* 按名称搜索，查找“Atom One Dark”等特定主题
* 按作者筛选，探索特定创作者的主题
* 按配色方案浏览，查找浅色或深色主题
* 按特定颜色搜索，找到符合个人偏好的主题

安装前可先预览主题，查看它在 Project Editor 中的显示效果。

<div id="section-11">
  ## 发布主题
</div>

按照以下步骤，将自定义主题分享给 Replit 社区。

1. 打开自定义主题的 Themes Editor
2. 选择 **Publish** 按钮
3. 填写标题和描述字段
4. 提交主题

发布后，主题会显示在主题探索页面上，其他用户可以预览并安装。
