Les thèmes de Replit vous permettent de personnaliser l&#39;apparence du Project Editor, des couleurs d&#39;arrière-plan et des éléments d&#39;interface jusqu&#39;à la coloration syntaxique de votre code. Adaptez votre environnement de développement pour améliorer la lisibilité, réduire la fatigue oculaire et rendre l&#39;expérience de codage plus agréable.

<div id="section">
  ## Créer un thème personnalisé
</div>

Suivez les étapes ci-dessous pour créer et personnaliser votre propre thème.

1. Ouvrez [Settings](https://replit.com/settings) et accédez à **User** → **Personalization** (ou à la section **Themes**)
2. Sélectionnez **Create new theme**
3. Saisissez un titre, choisissez une palette de couleurs (thème clair ou thème sombre) et, si vous le souhaitez, ajoutez une description
4. Sélectionnez **Create Theme** pour ouvrir le Themes Editor

Les paramètres globaux du thème déterminent l&#39;apparence générale de l&#39;interface.

* **Background** : définit la couleur de base de la plupart des surfaces de l&#39;interface
* **Outline** : contrôle la couleur des bordures et des séparateurs
* **Foreground** : détermine la couleur du texte et des icônes
* **Primary** : définit la couleur des boutons et des éléments interactifs
* **Positive** : s&#39;applique aux indicateurs de réussite, comme le bouton **Run**
* **Negative** : signale les erreurs et les avertissements liés aux actions destructrices

Sélectionnez **Apply Theme** pour utiliser immédiatement votre thème personnalisé.

<div id="section-2">
  ## Coloration syntaxique
</div>

Personnalisez l&#39;affichage des différents éléments de code pour améliorer la lisibilité et la compréhension.

<Tip>
  Une bonne coloration syntaxique permet de parcourir et de comprendre le code d&#39;un simple coup d&#39;œil. Choisissez des couleurs qui s&#39;harmonisent entre elles et offrent un contraste suffisant avec l&#39;arrière-plan.
</Tip>

<Accordion title="Éléments de la coloration syntaxique">
  | Élément                  | Description                                                                     |
  | ------------------------ | ------------------------------------------------------------------------------- |
  | **Variable Names**       | S&#39;applique aux variables déclarées sans mot-clé de déclaration              |
  | **Variable Definitions** | Colore le nom des variables définies avec un mot-clé comme `const` ou `var`     |
  | **Function References**  | S&#39;applique lors de l&#39;appel d&#39;une fonction                           |
  | **Function Definitions** | Colore le nom des fonctions lors de leur déclaration                            |
  | **Keywords**             | Met en évidence les mots-clés du langage comme `import`, `function` ou `return` |
  | **Property Names**       | Colore l&#39;accès aux propriétés d&#39;une variable                            |
  | **Property Definitions** | Utilisé lors de la définition des propriétés d&#39;un objet                     |
  | **Function Properties**  | S&#39;applique lors de l&#39;appel des méthodes d&#39;un objet                  |
  | **Tag Names**            | Utilisé pour les balises HTML et JSX                                            |
  | **Type Names**           | Colore les annotations de type dans les langages typés                          |
  | **Class Names**          | S&#39;applique aux déclarations et aux références de classes                    |
  | **Attribute Names**      | Met en évidence les attributs HTML et JSX                                       |
  | **Comments**             | S&#39;applique à tous les commentaires de code                                  |
  | **Strings**              | Colore les littéraux de chaîne de caractères                                    |
  | **Numbers**              | Met en évidence les valeurs numériques                                          |
  | **Booleans**             | Met en forme les valeurs booléennes (`true`/`false`)                            |
  | **Regular Expressions**  | Colore les motifs d&#39;expressions régulières                                  |
  | **Operators**            | Met en évidence les opérateurs comme `+`, `-`, `*`, `/`                         |
  | **Brackets**             | Colore les crochets et les chevrons si nécessaire                               |
</Accordion>

<div id="section-3">
  ## Bonnes pratiques de conception de thèmes
</div>

Suivez ces recommandations pour créer des thèmes à la fois esthétiques et fonctionnels.

<div id="section-4">
  ### Couleurs et contraste
</div>

* **Équilibrez le contraste** : veillez à une différence suffisante entre l&#39;arrière-plan et les éléments de premier plan
* **Créez une palette cohérente** : choisissez des couleurs qui s&#39;harmonisent au lieu de jurer entre elles
* **Maintenez une luminosité constante** : conservez des niveaux de luminosité similaires sur l&#39;ensemble des éléments de syntaxe
* **Concevez de manière accessible** : évitez les combinaisons à faible contraste afin de tenir compte des personnes ayant une déficience visuelle

<Warning>
  Problèmes courants de conception de thème à éviter :

  * Écarts de luminosité excessifs entre les éléments de syntaxe
  * Couleurs mal assorties qui créent une dissonance visuelle
  * Contraste insuffisant entre le code et l&#39;arrière-plan
</Warning>

<div id="section-5">
  ## Gérer les thèmes
</div>

Accédez à tous les thèmes que vous avez installés et gérez-les depuis les [Settings](https://replit.com/settings), sous **User** → **Personalization** (ou la section **Themes**).

<div id="section-6">
  ### Changer de thème
</div>

Sélectionnez le bouton situé à côté du nom du thème pour l&#39;activer comme thème actuel.

<div id="section-7">
  ### Modifier un thème
</div>

Sélectionnez le menu à trois points, puis cliquez sur **Edit** pour modifier votre thème personnalisé.

<Note>
  Vous ne pouvez modifier ou supprimer que les thèmes personnalisés que vous avez créés vous-même. Les thèmes par défaut et ceux créés par d&#39;autres personnes ne peuvent pas être modifiés.
</Note>

<div id="section-8">
  ### Supprimer un thème
</div>

Vous pouvez supprimer un thème personnalisé en sélectionnant **Delete** dans le menu à trois points.

<div id="section-9">
  ## Explorer les thèmes de la communauté
</div>

Découvrez les thèmes créés par la communauté Replit sur la [Themes Explore Page](https://replit.com/themes).

<div id="section-10">
  ### Trouver un thème
</div>

* Recherchez par nom pour trouver un thème précis, comme « Atom One Dark »
* Filtrez par auteur pour explorer les thèmes d&#39;un créateur en particulier
* Parcourez les palettes de couleurs pour trouver des thèmes clairs ou sombres
* Recherchez une couleur précise pour trouver un thème à votre goût

Prévisualisez un thème avant de l&#39;installer afin de voir son rendu dans le Project Editor.

<div id="vs-code">
  ## Importer depuis VS Code

Importez votre thème VS Code préféré dans Replit en reprenant les mêmes couleurs lors de la création du thème.

<div id="section-11">
  ## Publier un thème
</div>

Suivez ces étapes pour partager votre thème personnalisé avec la communauté Replit.

1. Ouvrez le Themes Editor de votre thème personnalisé
2. Sélectionnez le bouton **Publish**
3. Renseignez les champs de titre et de description
4. Soumettez votre thème

Une fois publié, votre thème apparaît sur la Themes Explore Page, où les autres utilisateurs peuvent le prévisualiser et l&#39;installer.
