<div id="compre-um-domnio-sem-sair-do-replit">
  ### 无需离开 Replit 即可购买域名
</div>

现在，你可以直接在 Replit 中搜索并为你的 App 购买自定义域名。找到可用的域名后完成购买，Replit 会自动将该域名连接到你已发布的 App，无需再去域名注册商处单独开通账户。

  ## 集成

<div id="conecte-o-excalidraw-ao-agent">
  ### 将 Excalidraw 连接到 Agent
</div>

现在你可以连接 Excalidraw，让 Agent 帮你创建和编辑图表与白板。只需在 连接器 页面登录一次，之后就能让 Agent 在你的所有应用中使用 Excalidraw 进行构建，无需复制粘贴任何凭证。

<div id="workspace">
  ## Workspace
</div>

<div id="editores-podem-responder-s-perguntas-do-agent">
  ### 编辑者可以回答 Agent 的问题
</div>

在共享 App 中协作构建时，任何编辑者现在都可以回答 Agent 的常规问题，无需等待 App 所有者。连接集成或添加密钥等敏感操作仍仅限 App 所有者执行。

详细了解[如何管理 App 访问权限](/zh/pt/teams/identity-and-access-management/repl-access-management)。
