<div id="section">
  ## Ce qui est inclus
</div>

Le forfait Starter vous offre tout ce dont vous avez besoin pour commencer à créer avec Replit. Créez des applications et publiez votre premier projet, le tout gratuitement.

<div id="agent">
  ### Crédits quotidiens pour utiliser Agent
</div>

Les utilisateurs du forfait Starter bénéficient de crédits quotidiens pour utiliser Agent, dans la limite de leur plafond mensuel. Ces crédits sont réinitialisés chaque jour, ce qui vous permet de travailler quotidiennement avec Agent dans la limite d’un nouveau plafond.

<div id="section-2">
  ### Crédits cloud mensuels
</div>

Vous recevez également des crédits mensuels à utiliser pour :

* [Base de données (production)](/fr/ko/features/data-and-storage/development-and-production)
* [Stockage d&#39;objets](/fr/ko/features/data-and-storage/object-storage)
* [Déploiement (Autoscale, statique)](/fr/ko/learn/projects-and-artifacts/replit-deployments)

Ces crédits sont réinitialisés chaque mois.

<div id="lite">
  ### Lite Build
</div>

Accédez à [Lite Build](/fr/ko/features/agent/agent-modes) dans Agent pour une expérience de création rapide et ciblée, idéale pour effectuer des modifications rapides et précises.

<div id="1">
  ### 1 application publiée gratuitement
</div>

Que vous utilisiez Lite Build ou Canvas Design, vous bénéficiez de {FreeDeployments} applications publiées gratuitement. Ces liens de publication expirent automatiquement après 30 jours.

Les applications publiées affichent un badge « Made with Replit » contenant votre lien de parrainage unique. Lorsqu’une autre personne s’inscrit via le lien du badge, vous recevez un crédit de parrainage une fois qu’elle passe à un plan payant.

<div id="section-3">
  ## Limitations
</div>

Les fonctionnalités suivantes nécessitent de passer à l’offre Core :

<div id="section-4">
  ### Build complet
</div>

Le [Build complet](/fr/ko/features/agent/overview/) permet à Agent de travailler de manière autonome avec davantage d&#39;autorisations. Les créateurs disposant du forfait Starter peuvent uniquement utiliser le [Lite Build](/fr/ko/features/agent/agent-modes). Le Build complet nécessite Core ou Pro.

<div id="section-5">
  ### Convertir un design en artefact
</div>

Core est requis pour convertir un design du Canvas Design en artefact complet. Les créateurs disposant du forfait Starter peuvent créer et déployer des designs, mais doivent passer à une offre supérieure pour les convertir en artefacts avec des fonctionnalités de backend. Pour créer une application avec des fonctionnalités de backend, commencez avec [Lite Build](/fr/ko/features/agent/agent-modes).

<div id="3">
  ### Connecteurs tiers
</div>

Les connecteurs externes nécessitent un abonnement Core. Cela inclut les intégrations avec Google, Stripe et d’autres API tierces (voir [plus de détails](https://docs.replit.com/features/integrations/overview#connectors)).

<div id="replit-ai-integrations">
  ### Replit AI Integrations
</div>

[Replit AI Integrations](/fr/ko/features/integrations/replit-ai-integrations) requiert l’abonnement Core.

<div id="made-with-replit">
  ### Suppression du badge « Made with Replit »
</div>

L’offre Core est requise pour supprimer le badge « Made with Replit » d’une application publiée. Pour les utilisateurs de l’offre Starter, le badge s’affiche sur les déploiements.

<div id="section-6">
  ### Applications publiées supplémentaires
</div>

Les utilisateurs du forfait Starter bénéficient de {FreeDeployments} applications publiées gratuites. Au-delà de cette limite, des applications publiées supplémentaires nécessitent Core ou Pro.

<div id="plan-mode">
  ### Plan Mode
</div>

Core est requis pour utiliser Plan Mode. Plan Mode vous permet de réfléchir à des idées, de planifier des tâches et de collaborer avec Replit Agent sans modifier le code ni les données de votre application.

<div id="section-7">
  ### Tous les types d’artefacts
</div>

Core est nécessaire pour créer des artefacts autres que des applications web et mobiles. Choisissez parmi différents types, comme les visualisations de données, les diaporamas et les vidéos d’animation. Consultez les [projets](/fr/ko/features/projects-and-artifacts/projects).

<div id="core">
  ## Passez à Core
</div>

Vous en voulez plus ? Passez à Core pour bénéficier des avantages suivants :

* **Davantage de stockage et de crédits mensuels**, avec facturation à l&#39;utilisation
* **Un nombre illimité d&#39;applications publiées** (après votre première application gratuite)
* Un développement autonome avec des **builds complets**
* Des **connecteurs tiers** pour vous connecter à des services externes
* **Replit AI Integrations** pour utiliser des modèles d&#39;IA sans votre propre clé API
* **Plan Mode** pour planifier votre travail avant de commencer à créer
* La **suppression du badge Replit** pour une apparence professionnelle
* Et bien plus encore
