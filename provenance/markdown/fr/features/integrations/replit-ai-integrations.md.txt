Les intégrations IA Replit facilitent la création d'applications alimentées par l'IA. Commencez immédiatement avec des modèles d'OpenAI, Anthropic, Google et OpenRouter — sans configuration de compte développeur, sans gestion de clé API. Replit gère tout pour vous.

## Qu'est-ce que les intégrations IA Replit ?

Les intégrations IA Replit fournissent un accès géré aux modèles d'IA des principaux fournisseurs. Créez des applications de chat, des générateurs de contenu et des outils alimentés par l'IA sans quitter Replit. Pas besoin de créer des comptes développeur externes, de trouver vos identifiants API ou de gérer une facturation séparée.

Lorsque vous utilisez les intégrations IA Replit, Replit gère les identifiants du fournisseur et vous facture au prix public de l'API. Votre utilisation est facturée à vos crédits Replit et apparaît sur votre [page d'utilisation](/fr/billing/managing-spend), ventilée par application Replit existante.

<Note>
  Les intégrations IA Replit nécessitent un plan payant (Core, Pro ou Enterprise). Vous pouvez toujours créer des applications IA avec votre propre clé API sur le [plan Starter](/fr/billing/plans/starter-plan). Voir [Disponibilité selon le plan](#plan-availability).
</Note>

## Fonctionnalités

Les intégrations IA Replit simplifient le développement IA avec un accès intégré et une facturation transparente :

* **Aucune configuration requise** : Pas de compte développeur ni de clé API nécessaires pour commencer
* **Identifiants gérés** : Replit gère l'authentification et la gestion des identifiants du fournisseur
* **Facturation transparente** : Payez les prix publics de l'API, facturés à vos crédits Replit
* **Suivi de l'utilisation** : Consultez votre utilisation par application Replit existante sur votre page d'utilisation
* **Support multi-pile** : Fonctionne avec tous les langages de programmation et frameworks
* **BYOK optionnel** : Apportez votre propre clé API si vous préférez utiliser vos propres identifiants

## Premiers pas

### Utiliser les identifiants gérés par Replit

Sur un plan payant, lorsque vous mentionnez des fonctionnalités IA ou des fournisseurs spécifiques (OpenAI, Anthropic, Google ou OpenRouter) dans votre invite, Agent utilise par défaut les intégrations IA Replit :

<AiPrompt>
  Créer une application web qui utilise OpenAI pour résumer des articles
</AiPrompt>

Vous pouvez savoir quelle intégration est utilisée en cherchant **« OpenAI (géré par Replit) »**, **« Anthropic (géré par Replit) »**, **« Google (géré par Replit) »** ou **« OpenRouter (géré par Replit) »** dans la réponse initiale à votre invite. Cela indique qu'Agent utilisera les identifiants de Replit au lieu de vous demander votre propre clé API.

**Pour les nouvelles créations** : Lorsque vous soumettez une invite initiale pour créer une nouvelle application avec des fonctionnalités IA, les intégrations IA Replit sont associées automatiquement. Agent commencera à construire avec les identifiants gérés de Replit immédiatement.

**Pour les applications Replit existantes** : Lorsqu'Agent détecte que vous souhaitez ajouter des fonctionnalités IA à une application Replit existante, Agent vous en informera explicitement dans l'éditeur de projet en indiquant qu'il demande à utiliser les intégrations IA Replit au lieu de votre propre clé API. Vous verrez une invite de confirmation :

Cliquez sur « Approuver » pour continuer avec les identifiants gérés par Replit, ou sur « Ignorer » si vous préférez utiliser votre propre clé API.

Votre utilisation est automatiquement suivie et facturée à votre compte Replit au prix public de l'API.

### Apporter votre propre clé API

Si vous préférez utiliser vos propres identifiants d'OpenAI, Anthropic, Google ou d'autres fournisseurs au lieu des intégrations IA Replit, vous avez plusieurs options :

**Pour les nouvelles créations** : Incluez dans votre invite que vous souhaitez utiliser votre propre clé API :

<AiPrompt>
  Créer une application web qui utilise OpenAI pour résumer des articles. Utiliser ma propre clé API OpenAI.
</AiPrompt>

Vous verrez le nom du fournisseur (sans « géré par Replit ») dans la réponse, indiquant qu'Agent demandera votre clé API.

**Pour les applications Replit existantes** : Lorsqu'Agent vous indique qu'il souhaite utiliser les intégrations IA Replit et affiche l'invite de confirmation, cliquez sur « Ignorer » au lieu d'« Approuver ».

Dans les deux cas, Agent construira jusqu'au premier point de contrôle avant de demander votre clé API. Cela permet à Agent de configurer d'abord la structure de votre projet, puis de s'arrêter pour collecter vos identifiants.

Lorsque vous utilisez votre propre clé API, vous êtes facturé directement par le fournisseur plutôt que via les crédits Replit.

## Consulter votre utilisation

Toute l'utilisation des intégrations IA Replit apparaît sur votre [page d'utilisation](/fr/billing/managing-spend) aux côtés de votre autre utilisation Replit. L'utilisation est ventilée par application Replit existante pour que vous puissiez voir exactement où va votre dépense IA.

## Fournisseurs pris en charge

Les intégrations IA Replit prennent actuellement en charge :

* **OpenAI** : Modèles multimodaux pour la génération de texte, le raisonnement et l'audio. Prend en charge les complétions de chat, les réponses, la génération d'images, la transcription audio (`gpt-4o-transcribe`, `gpt-4o-mini-transcribe`) et la sortie audio (`gpt-audio`, `gpt-audio-mini`).
* **Anthropic** : Modèles multimodaux pour le raisonnement, la rédaction et le codage. Prend en charge l'API Messages et les interactions avec la recherche web.
* **Google (Gemini)** : Modèles multimodaux pour la génération de texte et le raisonnement. Prend en charge la génération de texte et d'images.
* **OpenRouter** : Accès aux modèles de fournisseurs tels que Microsoft (série Phi), Meta (série Llama), Mistral, Qwen, DeepSeek, Nvidia, Amazon et plus encore.

<Note>
  Les intégrations IA Replit prennent en charge la **sortie texte, image et audio**. La sortie vidéo n'est pas prise en charge. Si vous avez besoin de capacités de génération vidéo, vous devrez utiliser votre propre clé API d'un fournisseur qui les propose.
</Note>

## Confidentialité et disponibilité OpenRouter

Lorsque vous utilisez OpenRouter via les intégrations IA Replit, vos requêtes sont envoyées avec des paramètres de confidentialité spécifiques pour protéger vos données. Comprendre ces paramètres est important car ils peuvent affecter les modèles disponibles pour vous.

### Paramètres de confidentialité pour les utilisateurs en libre-service

Pour les utilisateurs individuels et d'équipe, Replit configure les requêtes OpenRouter avec les paramètres de confidentialité par défaut suivants :

* **Entraînement des points de terminaison payants désactivé** : Vos données ne seront pas utilisées pour l'entraînement par les fournisseurs de modèles payants
* **Entraînement des points de terminaison gratuits activé** : Les fournisseurs de modèles gratuits peuvent entraîner sur vos invites et complétions
* **Publication des points de terminaison gratuits activée** : Les fournisseurs gratuits peuvent publier vos invites et complétions dans des ensembles de données publics
* **Journalisation des entrées/sorties désactivée** : Vos requêtes et réponses ne sont pas enregistrées par OpenRouter pour la remise de 1 %
* **Cookies analytiques désactivés** : Les cookies analytiques ne sont pas utilisés

Ces paramètres privilégient votre confidentialité tout en permettant l'accès à la plus large gamme de modèles possible. Cependant, **certains modèles peuvent ne pas être disponibles** s'ils nécessitent des paramètres de confidentialité différents de ceux configurés ci-dessus.

### Paramètres de confidentialité pour Enterprise

Pour les organisations Enterprise, Replit applique des contrôles de confidentialité plus stricts :

* **Points de terminaison à rétention zéro des données (ZDR) uniquement** : Seuls les modèles avec une politique de rétention zéro des données sont disponibles
* Tous les paramètres de confidentialité listés ci-dessus pour les utilisateurs en libre-service s'appliquent également
* Cela garantit que les requêtes Enterprise ne sont acheminées que vers des points de terminaison qui ne conservent aucune donnée

Parce qu'Enterprise applique uniquement les points de terminaison ZDR, **la sélection des modèles disponibles sera plus limitée** par rapport aux utilisateurs en libre-service. Ce compromis garantit le plus haut niveau de confidentialité des données pour les charges de travail enterprise.

## Disponibilité selon le plan

Les intégrations IA Replit nécessitent un plan payant. Le fonctionnement de l'accès dépend de votre plan.

### Starter (Gratuit)

Sur le plan Starter, les intégrations IA Replit sont désactivées. Vous pouvez toujours créer des applications IA avec votre propre clé API. Voir [Apporter votre propre clé API](#bringing-your-own-api-key).

### Core

Sur le plan Core, vous pouvez créer des applications IA avec les intégrations IA Replit en utilisant des identifiants gérés par Replit — aucune clé API à gérer.

### Pro et Enterprise

Pour les organisations Pro et Enterprise, l'accès aux intégrations IA Replit est désactivé par défaut. Les administrateurs de l'organisation peuvent contrôler l'accès depuis la page des paramètres de l'organisation :

1. Accédez aux paramètres de votre organisation
2. Trouvez la section Intégrations IA Replit
3. Activez ou désactivez l'accès pour votre organisation

Lorsqu'il est activé, les membres de l'organisation peuvent utiliser les intégrations IA Replit dans leurs applications. Toute l'utilisation est suivie et facturée au compte de l'organisation. Lorsqu'il est désactivé, les membres devront fournir leurs propres clés API pour utiliser les fournisseurs de modèles d'IA.

## Cas d'utilisation

Créez de puissantes applications IA sur n'importe quelle pile :

* **Génération de contenu** : Résumer des articles, générer des descriptions, créer du contenu
* **Analyse et insights** : Extraire des informations clés, analyser le sentiment, classer le texte
* **Interfaces conversationnelles** : Créer des chatbots et des assistants IA
* **Transformation de texte** : Traduire, réécrire ou formater du contenu
* **Assistance au code** : Générer des extraits de code, expliquer des algorithmes, réviser du code
