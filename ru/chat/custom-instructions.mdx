Custom Instructions — это постоянно действующие инструкции, которые вы или ваша команда один раз задаёте для рабочего пространства. Replit использует их во всех Projects и сеансах этого рабочего пространства, поэтому вам не нужно повторять принятые правила в каждом Conversation.

Используйте Custom Instructions для небольшого набора неизменно актуальных правил, например разрешённых библиотек, требований безопасности или политик обработки данных. Формулируйте их кратко и конкретно, чтобы оставить место для текущей работы.

<div id="choose-the-right-kind-of-guidance">
  ## Выберите подходящий тип инструкций
</div>

* Используйте **Custom Instructions** для инструкций, действующих во всём рабочем пространстве и применяемых всегда.
* Используйте [навыки](/ru/chat/agent-skills) для повторно используемых подходов и вспомогательных материалов, актуальных только для конкретных задач.
* Используйте [Memories](/ru/chat/memories) для полезного контекста, который Replit сохраняет из предыдущей работы.

<div id="set-up-custom-instructions">
  ## Настройте Custom Instructions
</div>

Управляйте Custom Instructions в разделе **Workspace Settings → Customization**. В подробном руководстве описаны настройка, доступность, разрешения и способы поддерживать инструкции актуальными.
