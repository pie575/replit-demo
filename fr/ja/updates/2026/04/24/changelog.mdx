<div id="agent">
  ### L’Agent de sécurité examine l’ensemble de la base de code
</div>

L’**Agent de sécurité** est un nouvel outil de révision basé sur l’IA qui audite l’ensemble du projet, et pas seulement les dépendances. Il élabore un modèle de menaces, cartographie les routes et les flux de données, exécute des analyses statiques avec Semgrep et HoundDog.ai, puis utilise un LLM pour identifier les constats réellement exploitables dans le contexte de votre application. Une fois la révision terminée, l’Agent de sécurité organise les constats validés en tâches parallèles que Replit Agent peut corriger de bout en bout.

<Frame>
  <img src="/assets/mirror/security-agent-findings-b425392bb98a.png" alt="Volet Agent de sécurité du centre de sécurité du projet. Affiche une analyse terminée avec cinq constats classés par gravité et des statuts tels que « En attente de révision » ou « En attente de republication », ainsi qu’une section d’analyse automatique des dépendances répertoriant les paquets vulnérables" width="1438" height="808" data-path="images/changelog/2026-04-24/security-agent-findings.png" />
</Frame>

L’Agent de sécurité est disponible pour tous les utilisateurs disposant d’un forfait payant. Ouvrez le volet **Sécurité** de votre projet et sélectionnez **Exécuter une analyse avec Agent** pour l’essayer.

En savoir plus sur l’[Agent de sécurité](/fr/core-concepts/security/project-security-center#agent-security-scans).

<div id="cve-auto-protect">
  ### CVE Auto-Protect corrige automatiquement les vulnérabilités critiques
</div>

Lorsqu&#39;une nouvelle CVE critique est divulguée dans un paquet dont dépend votre App, **CVE Auto-Protect** détecte les correspondances dans tous les projets que vous possédez, demande à Agent de préparer un correctif dans une tâche en arrière-plan, exécute les tests pour s&#39;assurer que rien n&#39;est cassé, puis vous envoie une notification accompagnée d&#39;un lien de revue. Vous gardez la main : rien n&#39;est publié tant que vous n&#39;avez pas approuvé le correctif.

Vous pouvez ainsi corriger votre App en quelques minutes, sans attendre de découvrir par vous-même la publication d&#39;une nouvelle vulnérabilité.

Pour en savoir plus, consultez [CVE Auto-Protect](/fr/core-concepts/security/project-security-center#auto-protect).

<div id="iosandroid">
  ### Preview sur simulateur iOS ou émulateur Android
</div>

<Frame>
  <video autoPlay muted loop playsInline src="/assets/mirror/ios-emulator-9013ff1b602f.mp4" />
</Frame>

Si votre projet contient une App mobile, vous pouvez désormais diffuser un **simulateur iOS** ou un **émulateur Android** directement dans votre espace de travail, depuis le panneau Preview. Aucun besoin de Xcode, d&#39;Android Studio ni d&#39;appareil physique. Créez votre application mobile avec Agent, sélectionnez un appareil dans le menu déroulant du panneau Preview, puis interagissez avec elle comme si vous teniez un vrai téléphone. Les modifications apportées par Agent sont rechargées à chaud dans le simulateur.

Disponible pour les créateurs payants des plans Core, Pro et Enterprise utilisant Chrome, Safari ou un navigateur basé sur Chromium. Firefox ne prend pas en charge le simulateur mobile.

En savoir plus sur la [prévisualisation sur un simulateur ou un émulateur](/fr/ja/features/artifact-types/building-mobile-apps#preview-on-a-simulator-or-emulator).

<div id="app">
  ### Ajouter une App mobile à un ancien projet
</div>

<Frame>
  <img src="/assets/mirror/multi-artifact-update-approval-f6fa8b70a100.png" alt="Panneau de discussion Agent affichant la carte d'approbation « Mettre à jour le projet pour créer une App mobile », avec l'offre de 5 $ de crédits et les boutons « Pas maintenant » / « Mettre à jour le projet »." width="991" height="589" data-path="images/replitai/multi-artifact-update-approval.png" />

Les projets créés avant la sortie d&#39;Agent 4 peuvent désormais être mis à jour pour prendre en charge plusieurs artifacts — autrement dit, vous pouvez ajouter une App mobile, une présentation ou tout autre artifact à un projet qui n&#39;en acceptait jusqu&#39;ici qu&#39;un seul. Lors de la réorganisation du projet, Agent conserve les URL, les données, les secrets et les déploiements. Plus de 200 projets ont été migrés durant les 48 premières heures suivant le déploiement à plus grande échelle.

Pour en savoir plus, consultez [Mettre à jour d&#39;anciens projets pour la prise en charge de plusieurs artifacts](/fr/ja/features/projects-and-artifacts/updating-projects-for-multiple-artifacts).

<div id="plaid">
  ### Le connecteur Plaid est disponible
</div>

Le connecteur **Plaid** permet désormais de se connecter à plus de 12 000 établissements financiers. Il suffit que l&#39;administrateur de l&#39;équipe configure les identifiants une seule fois dans **Intégrations** pour que les utilisateurs de l&#39;App puissent authentifier leur propre compte bancaire via Plaid Link. Les jetons d&#39;accès étant limités à chaque utilisateur, les données restent privées.

Vous pouvez créer un coach financier personnel s&#39;appuyant sur des données de transactions réelles, un suivi de portefeuille en temps réel connecté à une société de courtage, et bien plus encore. Pour des démonstrations et les étapes de configuration, consultez la [page partenaire Replit x Plaid](https://replit.com/partners/plaid).

Pour en savoir plus, consultez [Gestion des connecteurs](/fr/ja/replitai/managing-connectors).
