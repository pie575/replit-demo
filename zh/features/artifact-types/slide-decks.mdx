<div id="what-are-slide-decks">
  ## 什么是幻灯片？
</div>

幻灯片让你完全通过与 Agent 对话来制作精美、专业的演示文稿。只需描述你的需求，即可立即获得一份完整美观的演示文稿——随后还能通过对话、可视化编辑，或在 [Design Canvas](/zh/design/canvas) 上探索不同版本来持续迭代。

幻灯片底层由 React 构建，因此可以导出为像素级还原、完全可编辑的 PPTX、Google Slides 或 PDF 文件。你还可以将演示文稿发布为可分享的在线网址。

核心概念：

* **一次生成**：描述你的演示文稿，Agent 即可生成一份完整作品——版式、文字和视觉元素一应俱全
* **基于 React**：幻灯片是真正的 React 组件，而非静态图片，因此可以完美导出为任意格式
* **随处导出**：下载为 PPTX、Google Slides 或 PDF——像素级还原，完全可编辑
* **可部署**：将演示文稿发布为在线网址，任何人都能在浏览器中查看或演示

<div id="how-to-use-slide-decks">
  ## 如何使用幻灯片
</div>

<div id="creating-a-slide-deck">
  ### 创建幻灯片
</div>

在 Replit 首页，有两种方式可以创建幻灯片：

* **输入 prompt**：描述你想要的演示文稿。Agent 会识别与演示文稿相关的 prompt，并自动选择 Slide deck 技术栈。
* **从下拉菜单中选择**：打开应用类型下拉菜单，选择 **Slides**，然后描述你的演示文稿。

**prompt 示例：**

* “为我的 AI 健身应用创建一份路演演示文稿”
* “制作一份用于 A 轮融资的 10 页投资人演示文稿”
* “为我们团队的外出研讨会做一份产品概览演示文稿”

<Tip>
  一开始就说明页数和视觉风格，Agent 会直接生成幻灯片，无需再追问细节。例如，可以试试“制作一份关于远程办公的 8 页极简风格幻灯片”。
</Tip>

<div id="starting-with-brand-guidelines-or-a-reference">
  ### 从品牌规范或参考文件开始
</div>

你可以为 Agent 提供一个良好的起点：

* **品牌规范**：上传你的品牌规范，让 Agent 在每一页幻灯片中都沿用你的配色、字体和视觉风格。
* **参考文件**：上传一份已有的演示文稿或文档作为起点，Agent 会以它为基础继续构建。

<div id="iterating-on-your-slides">
  ### 迭代你的幻灯片
</div>

Agent 生成第一版后，你可以通过对话来不断完善：

* **调整内容**：&quot;把问题陈述这页写得更简洁&quot;或&quot;在市场规模部分后面加一页竞争格局&quot;。
* **更改样式**：&quot;使用深色主题搭配蓝色点缀&quot;或&quot;把字体调大，整体风格更极简&quot;。
* **增加或删除幻灯片**：&quot;再加两页介绍我们的路线图&quot;或&quot;删除最后一页&quot;。
* **添加视觉元素**：&quot;添加一张展示预期增长的图表&quot;或&quot;为第 4 页的每个功能加上图标&quot;。
* **重新排序或调整结构**：&quot;把团队那页移到最后&quot;或&quot;把功能那页拆成两页&quot;。

迭代过程中，幻灯片会在预览面板中自动渲染，你可以即时看到改动效果。

<div id="editing-slides-directly">
  ### 直接编辑幻灯片
</div>

无需借助 Chat，你也可以亲手编辑：

* **[Visual Editor](/zh/design/visual-editor)**：点击任意元素即可直接调整文本、颜色、间距和布局——不消耗 AI 额度。
* **复制或删除**：右键点击任意幻灯片，即可将其复制或删除。

<Note>
  幻灯片内的元素暂不支持拖放操作。如需移动或重新排列元素，请在 Chat 中告知 Agent。
</Note>

<div id="using-design-canvas-for-variations">
  ### 使用 Design Canvas 探索多种版本
</div>

你可以使用 [Design Canvas](/zh/design/canvas) 为单张幻灯片或某个板块尝试不同的设计方案，再将满意的版本应用回主幻灯片。如果你想在最终定案前比较多种视觉方向，这个方式会很有帮助。

<div id="presenting-and-publishing">
  ### 演示与发布
</div>

幻灯片准备就绪后：

* **演示者模式**：进入全屏演示模式，直接在预览面板中演示。此视图与发布后观众看到的效果一致。
* **移动端支持**：幻灯片适配移动设备，观众可在任意屏幕上查看。
* **发布**：将幻灯片发布为可分享的在线链接。任何获得该链接的人都能在浏览器中查看或演示这份幻灯片。

<div id="exporting">
  ### 导出
</div>

下载幻灯片，在 Replit 之外使用：

* **PowerPoint**：在 PowerPoint 或 Keynote 中打开并编辑 `.pptx` 文件，背景、文本和图形均可稳定保留。
* **Google Slides**：直接在 Google Slides 中打开演示文稿。导出完成后，选择 **Go to Google Slides** 即可一步打开。
* **PDF**：分享静态的、可直接打印的版本。图片较多的演示文稿导出后文件体积依然很小，可以轻松通过邮件发送。

所有导出结果都能做到像素级还原且完全可编辑，幻灯片在 Replit 之外的呈现效果与平台内完全一致。导出速度也比以往最高提升 10 倍。

你也可以导入已有的演示文稿。导入 `.pptx` 文件后，其中的背景、文本和图形都能稳定还原。

<div id="finding-your-slide-decks">
  ### 查找你的幻灯片
</div>

你的幻灯片会与其他应用一同显示在 Projects 列表中。在 Projects 页面打开 **Build type** 下拉菜单并选择 **Slides**，即可仅列出包含幻灯片 artifact 的 project。

<div id="frequently-asked-questions">
  ## 常见问题
</div>

<Accordion title="可以在幻灯片上拖放元素吗？">
  暂时还不行。若要在幻灯片内移动或重新排列元素，请在 Chat 中告诉 Agent。你可以使用 Visual Editor 直接编辑文本、颜色和间距。
</Accordion>

<Accordion title="支持哪些导出格式？">
  你可以导出为 PPTX、Google Slides 或 PDF。导出结果均与原稿完全一致，并且可自由编辑。
</Accordion>

<Accordion title="可以使用自己的品牌规范吗？">
  可以。创建演示文稿时上传品牌规范，Agent 会让每一页幻灯片都与你的配色、字体和视觉风格保持一致。
</Accordion>

<Accordion title="幻灯片在移动设备上能正常显示吗？">
  可以。幻灯片支持在移动设备上渲染，你的观众可以在任意屏幕上查看已发布或已分享的演示文稿。
</Accordion>

<Accordion title="可以把幻灯片发布为在线链接吗？">
  可以。发布演示文稿后，它会生成一个可分享的在线链接，任何人都能在浏览器中查看或演示。
</Accordion>
