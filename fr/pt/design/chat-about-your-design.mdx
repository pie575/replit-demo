Les suggestions sont idéales pour explorer ; le chat vous permet de guider précisément le travail. Vous pouvez échanger de deux façons, selon la partie du design dont vous souhaitez discuter : le chat principal pour un frame entier et l’outil Chat pour un seul élément.

<div id="converse-sobre-um-frame-pelo-chat-principal">
  ## Discutez d’un frame dans le chat principal
</div>

Sélectionnez le frame dont vous parlez : il s’ajoute au chat principal sous forme de pastille. Décrivez ensuite les modifications que vous souhaitez apporter, comme si vous guidiez un designer lors d’une revue, par exemple : *« des couleurs plus chaudes »*, *« la section hero semble vide »*, *« essayez la navigation à gauche. »*

<div id="converse-sobre-um-elemento-com-a-ferramenta-chat">
  ## Discutez d’un élément avec l’outil Chat
</div>

Sélectionnez **Chat** dans la barre d’outils, puis cliquez sur un élément d’un frame, comme un bouton, un titre ou une image. Le reste du frame s’assombrit, l’élément apparaît sous forme de pastille dans la zone de saisie, et votre message s’applique uniquement à cet élément.

<div id="enquanto-gera">
  ## Pendant la génération
</div>

Les états de génération s’affichent dans le Chat pendant que Design travaille. Lorsque le résultat est disponible sous la forme d’un nouveau frame, poursuivez la conversation, passez aux [suggestions](/fr/pt/design/explore-suggestions) ou [créez-le](/fr/pt/design/build-your-design).
