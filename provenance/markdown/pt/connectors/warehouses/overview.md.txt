# Conectores de Warehouse

> Conecte o Replit Agent a data warehouses (BigQuery, Databricks, Snowflake) e plataformas de análise para criar aplicativos orientados a dados.

Os conectores de warehouse permitem que o Replit Agent consulte de forma segura os data warehouses da sua organização. Os desenvolvedores usam linguagem natural para criar dashboards, ferramentas de relatórios e aplicativos de dados — sem necessidade de conhecimento em SQL. Os administradores mantêm controle centralizado com acesso baseado em funções.

## Warehouses suportados

Os conectores de warehouse estão disponíveis nos planos **Enterprise**.

| Warehouse        | Guia de configuração                                                                                                    |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------- |
| BigQuery         | Disponível agora — guia de configuração em andamento                                                                    |
| Databricks       | [Conectar Databricks](/pt/connectors/warehouses/databricks)                                                             |
| Microsoft Fabric | [Criar aplicativos de dados no Microsoft Fabric](/pt/connectors/warehouses/microsoft-fabric) (pré-visualização privada) |
| Snowflake        | [Conectar Snowflake](/pt/connectors/warehouses/snowflake)                                                               |

Cada warehouse tem seu próprio fluxo de configuração, pois a integração OAuth, o modelo de identidade e o formato de credencial são diferentes. Escolha o warehouse que você usa e siga o guia dedicado.

## Plataformas de análise e dados

Os conectores de análise estão disponíveis nos planos Core e Pro, além do Enterprise. Conecte suas ferramentas de análise para que o Agent possa ler e trabalhar com os dados do seu produto:

* **Segment** — Dados de clientes, fluxos de eventos e segmentos de público do seu CDP
* **Amplitude** — Análise de produtos, dados de comportamento do usuário e métricas de engajamento
* **Hex** — Notebooks de dados colaborativos e resultados de consultas

Gerencie-os da mesma forma que outros conectores Replit. Consulte [Gerenciando seus conectores](/pt/replitai/managing-connectors).

## Como funcionam os conectores de warehouse

A configuração é um processo único que envolve três funções:

1. **Administrador do warehouse** — Cria uma integração OAuth ou identidade de serviço no warehouse
2. **Administrador da organização Replit** — Adiciona as credenciais ao Replit e configura o acesso
3. **Desenvolvedor** — Faz login e começa a criar com o Agent

Uma vez configurado, os desenvolvedores pedem ao Agent para usar o warehouse e o Agent escreve e executa SQL nele.

### Criando com dados de warehouse

Após a conexão, você pode pedir ao Agent para criar aplicativos que usam seus dados. O Agent pode:

* Criar ferramentas internas que buscam e exibem dados ao vivo
* Criar dashboards com gráficos e visualizações baseados no seu warehouse
* Gerar consultas SQL para alimentar o backend do seu aplicativo
* Explicar estruturas de schema e tabelas para ajudar você a entender o que criar

<Note>
  Embora o Agent possa responder a perguntas ad-hoc sobre seus dados, o objetivo principal dos conectores de warehouse é permitir que o Agent crie aplicativos funcionais que aproveitam os dados da sua organização. As consultas de warehouse são executadas diretamente na sua instância, portanto, certifique-se de que seus escopos OAuth e permissões de usuário de banco de dados permitam as operações de leitura e gravação necessárias.
</Note>
