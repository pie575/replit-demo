Replit의 Publishing 비용는 앱의 요구 사항에 맞춰 확장되도록 설계되었습니다. 앱이 요청을 serve할 때만 요금이 부과되는 usage-based billing과 일정한 워크로드에 적합한 예측 가능한 정액제 옵션 중에서 선택하세요.

<div id="how-billing-works">
  ## Billing 작동 방식
</div>

모든 Publishing 비용는 월별 credits에서 차감됩니다. 월별 credits를 모두 사용한 후부터 usage 기반 요금이 청구됩니다.

* **Starter Plan**: 무료 게시된 앱 1개가 포함됩니다. deployment는 30일 후 만료되며, 다시 게시할 수 있습니다. 자세한 내용은 [Starter Plan](/ko/billing/plans/starter-plan)을 참조하세요.
* **[Core Plan](/ko/billing/plans/replit-core)**: 월별 credits 포함, [pricing](https://replit.com/pricing) 참조
* **[Pro Plan](/ko/billing/plans/replit-pro)**: 등급별 월별 credits 제공, 자세한 내용은 [Replit Pro](/ko/billing/plans/replit-pro) 및 [pricing page](https://replit.com/pricing) 참조

<Note>
  credits는 모든 Publishing 비용에 자동으로 적용됩니다. 사용하지 않은 credits는 다음 달로 이월되지 않습니다. [usage 기반
  billing](/ko/billing/about-usage-based-billing)에 대해 자세히 알아보세요.
</Note>

Publishing 비용를 직접 따져보려면 [인터랙티브 요금 계산기](https://deployment-pricing.replit.app/)를 사용해 보세요.

  ## Deployment types
</div>

앱의 트래픽 패턴과 리소스 요구 사항에 가장 잘 맞는 deployment type을 선택하세요.

    **적합한 용도:** 트래픽이 일정하거나 리소스 보장이 필요한 production 앱

    **적합한 용도:** 백그라운드 job, 데이터 처리, 자동화된 task

<div id="understanding-request-based-billing">
  ## 요청 기반 billing 이해하기
</div>

<Tip>
  Autoscale Deployments를 사용하면 앱이 실제로 작동하는 동안에만 비용이 청구됩니다.
  아무도 앱을 방문하지 않으면 비용이 발생하지 않습니다.
</Tip>

Autoscale Deployments는 요청 기반 billing을 사용하므로 앱이 트래픽을 serve할 때만 요금이 부과됩니다. 작동 방식은 다음과 같습니다.

1. 첫 요청이 도착하면 **앱이 시작됩니다**(유휴 상태인 경우)
2. 컴퓨팅 리소스를 사용해 **요청을 처리합니다**
3. 15분간 활동이 없으면 **유휴 상태로 전환됩니다**

**과금 시간:** 복잡한 앱이라도 요청당 1~2초에 그치는 경우가 많습니다.

먼저 서버가 시작되고, 이어서 요청을 처리한 뒤, 마지막으로 유휴 상태로 전환됩니다. 비용은 요청을 처리하는 동안 사용한 CPU와 메모리에 대해서만 청구됩니다.

<Note>
  여러 요청이 동시에 들어오면(겹쳐진 파란색 막대처럼) 동일한 컴퓨팅 리소스를 공유합니다.

  과금 시간은 동시에 처리되는 모든 요청을 포함하도록 늘어나지만, 요청마다 따로 비용이 청구되지는 않습니다. 서버가 실제로 작동한 총 시간에 대해서만 청구됩니다.
</Note>

초록색 막대 사이의 간격은 유휴 시간 동안 절감되는 비용을 나타냅니다. session이 끝나면 서버는 종료됩니다.

<div id="compute-units-explained">
  ### Compute units 이해하기
</div>

Compute units는 앱이 수행하는 연산 작업량을 측정하는 단위입니다:

* **CPU 시간**: 사용된 처리 능력(CPU 1초 = 18 compute units)
* **메모리 시간**: 사용된 RAM(1GB-초 = 2 compute units)
* **지속 시간**: 앱이 각 요청을 처리하는 데 걸리는 시간
