素材库面板是 Replit Design 内置的设计起点与参考资源库，包含三个标签页：**Templates**、**Inspiration** 和 **Library**。面板中的任何内容都不会创建新的 project，所有内容都会直接添加到你当前 project 的 Canvas 上。

<div id="templates">
  ## 模板
</div>

由 Replit 制作的预设计 frame，支持搜索并按类型分组：海报、社交帖子、落地页、移动端、横幅和原型。点击或拖入即可将其添加到你的 Design 中；它会以实时 frame 的形式出现在 Canvas 上，可以像你自己生成的内容一样直接编辑。

</Frame>

<div id="inspiration">
  ## 灵感
</div>

由 Mobbin 精选的真实产品 UI 截图。搜索应用界面，例如 *“Airbnb onboarding”* 或 *“Coinbase checkout”*，点击任一结果即可将其作为静态参考图放置到 Canvas 上。灵感不会向你的 project 添加任何代码：它只是供你查看、在 Chat 中指向引用，或在下一次生成时作为参考。

</Frame>

<div id="library">
  ## 素材库
</div>

你自己的创作：你在此 project 中已完成的 Design 和 artifact，可随时重新放回 Canvas。

<div id="templates-vs-inspiration">
  ## 模板 与灵感
</div>

|            | 模板             | 灵感                    |
| ---------- | -------------------- | ----------------------- |
| 是什么        | Replit 打造的入门设计 frame | 来自真实产品的界面截图，由 Mobbin 提供 |
| 在 Canvas 上 | Design 中可实时编辑的 frame | 一张静态参考图                 |
| 用来做什么      | 以一个现成可用的设计为起点        | 引导下一次生成的视觉风格            |

完整流程请参阅[添加 模板 和灵感](/zh/design/add-templates-and-inspiration)。
