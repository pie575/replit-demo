<div id="replit">
  ## 什么是 Replit 应用？
</div>

Replit 应用是托管在云端的项目，包含代码、数据和资源。
你可以在安全、隔离的环境中创建、运行和发布应用。

Replit 应用与项目编辑器中的以下工具集成，
带来流畅的开发体验：

* **AI 驱动工具**：使用 Agent 创建、调试和解释代码。
* **协作**：与他人实时协作，共同开发同一个应用。
* **发布**：只需点击一下，即可将应用发布到云端。

<div id="section-2">
  ## 主要功能
</div>

Replit 应用提供以下功能：

* **无需设置：**无需安装或配置，直接在 Replit.com 上创建应用或编写代码。
* **自动保存：**项目会持续将更改保存到云端，因此你可以使用任何网页浏览器继续编程。
* **版本控制：**无需额外配置，即可通过 Replit 的版本控制系统跟踪更改、浏览文件历史记录并同步文件。
* **公开/私密可见性控制：**通过隐私设置控制哪些人可以查看、运行或创建应用的 Remix。
* **发布：**无需进行复杂的配置更改，即可将代码发布到云端。
* **自定义应用 URL：**获取应用的专属 URL，或设置自定义域名以打造更专业的形象。

<Info>
  上传到项目文件系统的文件仅在开发期间可用，
  已发布的应用或其他构建者无法访问。若要处理构建者上传的内容并提供文件，请使用 [Object
  Storage](/zh/ko/features/data-and-storage/object-storage)；若要存储和
  读取应用及用户数据，请使用 [Replit
  Database](/zh/ko/features/data-and-storage/sql-database)。
</Info>

若要详细了解可简化 Replit 应用创建流程的项目编辑器工具，请参阅[项目编辑器概览](/zh/ko/learn/projects-and-artifacts/project-editor/)。

<div id="section-3">
  ## 工作原理
</div>

创建 Replit 应用后，Replit 会在云端为你的项目创建专属空间。
当你为应用添加功能或进行修改时，Replit 会自动保存更改，
让你可以在任何网页浏览器中继续编辑。

Replit 提供预先配置好的环境，其中包含所需的全部组件。
因此，你无需担心服务器配置、数据库设置或环境管理，
可以立即开始创建应用。

Replit 会自动为每个 Replit 应用分配专属网址，
方便你在开发过程中预览应用。准备好分享后，
只需点击几下即可发布，让应用全天候保持可用。

<div id="section-4">
  ## 存储概览
</div>

Replit 提供四种核心存储类型，以满足应用的数据存储需求。每种存储类型适用于不同的使用场景，并且各套餐设有相应的限额。

<Info>
  存储限额包括应用存储的所有数据，其中包括已安装的软件包和依赖项。
</Info>

| 存储类型                                                               | 说明           | 使用场景            | 持久性         | 套餐限额                                                                                                                                                 |
| ------------------------------------------------------------------ | ------------ | --------------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **文件存储**                                                           | 项目中的文件 | 应用代码、静态资源、配置文件  | 发布后保留，重启后重置 | Starter: {StarterWorkspaceStorage}<br />Core: {CoreWorkspaceStorage}<br />Pro: {TeamsWorkspaceStorage}<br />Enterprise: {EnterpriseWorkspaceStorage} |
| **[数据库](/zh/ko/features/data-and-storage/sql-database/)**             | 结构化数据存储      | 用户资料、游戏分数、产品目录  | 跨会话完全持久     | 每个开发数据库 20GB<br />生产数据库按计算时间和存储空间计费                                                                                                                  |
| **[应用存储](/zh/ko/features/data-and-storage/object-storage/)**          | 非结构化数据和媒体    | 图片、视频、PDF、文档    | 跨会话完全持久     | 按使用量计费<br />按存储空间和带宽计费                                                                                                                               |
| **[Secrets](/zh/ko/core-concepts/project-editor/app-setup/secrets/)** | 加密的敏感数据      | API 密钥、凭据、连接字符串 | 完全持久并经过加密   | 无特定限额<br />所有套餐均包含                                                                                                                                   |
