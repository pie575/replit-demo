<div id="slack-integration">
  ### Интеграция со Slack
</div>

Agent теперь поддерживает интеграцию с API Slack. Это значит, что с помощью Agent вы можете создавать приложения, которые умеют:

* Отправлять сообщения
* Читать историю

во всех ваших любимых каналах Slack и отправлять сообщения в них.

<Frame>
  <img src="/assets/mirror/slack-integration-1072c585c41e.png" alt="Интеграция со Slack" width="1640" height="739" data-path="images/changelog/2025-01-10/slack-integration.png" />
</Frame>

Поделитесь созданным вами проектом в [Agent Showcase](https://forms.gle/qxpfr82wNpKsCdok9).

<div id="agent-and-assistant-improvements">
  ### Улучшения Agent и Assistant
</div>

* Agent теперь быстрее загружается с главной страницы, чтобы вы могли быстрее приступить к работе.
* При выделении текста в Console и Shell теперь появляется всплывающее окно для быстрого доступа к Assistant. Просто выделите текст и нажмите иконку Assistant, чтобы задать вопрос.

  <img src="/assets/mirror/ask-assistant-cd529bf4a0b1.png" alt="Спросить Assistant" width="2532" height="1474" data-path="images/changelog/2025-01-10/ask-assistant.png" />
</Frame>

<div id="custom-domain-ux-improvement">
  ### Улучшение интерфейса пользовательских доменов
</div>

Теперь вы можете вставить URL в поле для пользовательского домена, и Replit автоматически извлечёт из него домен.

<div id="enhanced-project-featuring-controls">
  ### Улучшенное управление избранными проектами
</div>

Добавлять публичные проекты вашей организации в избранное и удалять их оттуда стало проще!

<Frame>
  <img src="/assets/mirror/feature-on-profile-95b81a71e0d7.png" alt="Избранный проект в профиле" width="1836" height="644" data-path="images/changelog/2025-01-10/feature-on-profile.png" />
</Frame>

Теперь управлять статусом избранного проекта можно прямо из workspace — через модальное окно информации о проекте или таблицу со списком проектов.

<Frame>
  <img src="/assets/mirror/profile-preview-b8f2ecfed154.png" alt="Предпросмотр профиля" width="2126" height="1152" data-path="images/changelog/2025-01-10/profile-preview.png" />
</Frame>

Кроме того, добавив проект в избранное, вы сможете предварительно увидеть, как он будет выглядеть в вашем публичном профиле.
