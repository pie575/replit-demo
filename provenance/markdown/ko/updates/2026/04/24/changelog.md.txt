## 플랫폼

### Security Agent가 전체 코드베이스를 검토합니다

**Security Agent**는 의존성뿐만 아니라 전체 프로젝트를 감사하는 새로운 AI 기반 검토 도구입니다. 위협 모델을 구축하고, 경로와 데이터 흐름을 매핑하고, Semgrep과 HoundDog.ai로 정적 분석을 실행하고, LLM을 사용하여 앱의 맥락에서 실제로 악용 가능한 항목을 판단합니다. 검토가 완료되면 Security Agent는 승인된 항목들을 Replit Agent가 한 번에 수정할 수 있는 병렬 작업으로 정리합니다.

Security Agent는 모든 유료 빌더가 사용할 수 있습니다. 프로젝트의 **보안** 패널을 열고 **Agent로 스캔 실행**을 선택하여 사용해 보세요.

[Security Agent](/core-concepts/security/project-security-center#agent-security-scans)에 대해 자세히 알아보세요.

### CVE Auto-Protect가 심각한 취약점을 자동으로 패치합니다

앱이 의존하는 패키지에 새로운 심각한 CVE가 공개되면, **CVE Auto-Protect**가 소유한 모든 프로젝트에서 일치 항목을 감지하고, Agent가 백그라운드 작업에서 패치를 준비하고, 테스트를 실행하여 아무것도 중단되지 않는지 확인하고, 검토를 위한 링크와 함께 알림을 보냅니다. 수정 사항을 승인할 때까지 아무것도 게시되지 않으므로 사용자가 제어권을 유지합니다.

이를 통해 새로운 취약점이 공개된 후 사용자가 직접 확인하기를 기다리지 않고 몇 분 내에 앱이 패치될 수 있습니다.

[CVE Auto-Protect](/core-concepts/security/project-security-center#auto-protect)에 대해 자세히 알아보세요.

### iOS Simulator 또는 Android Emulator에서 미리보기

<Frame>
  <video autoPlay muted loop playsInline src="https://cdn.replit.com/sanity/ios-emulator.mp4" />
</Frame>

프로젝트에 모바일 앱이 포함되어 있으면, 이제 미리보기 패널에서 실제 **iOS Simulator** 또는 **Android Emulator**를 워크스페이스로 직접 스트리밍할 수 있습니다. Xcode, Android Studio, 실제 기기가 필요하지 않습니다. Agent로 모바일 앱을 빌드하고, 미리보기 패널의 드롭다운에서 기기를 선택하고, 마치 손에 폰을 들고 있는 것처럼 탭해 보세요. Agent가 수정을 적용하면 시뮬레이터에 즉시 반영됩니다.

Chrome, Safari, Chromium 기반 브라우저에서 Core, Pro, Enterprise 플랜의 유료 빌더가 사용할 수 있습니다. Firefox는 모바일 시뮬레이터를 지원하지 않습니다.

[시뮬레이터 또는 에뮬레이터에서 미리보기](/ko/features/artifact-types/building-mobile-apps#preview-on-a-simulator-or-emulator)에 대해 자세히 알아보세요.

<Frame>
  <img src="https://mintcdn.com/replit/PUjTWRdx_TNp0SaN/images/replitai/multi-artifact-update-approval.png?fit=max&auto=format&n=PUjTWRdx_TNp0SaN&q=85&s=952936728a532ab0241de383ddcd0172" alt="$5 크레딧 제공과 지금 하지 않기 / 프로젝트 업데이트 버튼이 있는 '모바일 앱 생성을 위한 프로젝트 업데이트' 승인 카드를 보여주는 Agent 채팅 패널" width="991" height="589" data-path="images/replitai/multi-artifact-update-approval.png" />

Agent 4 출시 이전에 생성된 프로젝트도 이제 여러 아티팩트를 지원하도록 업데이트할 수 있습니다. 즉, 하나의 아티팩트만 지원하던 프로젝트에 모바일 앱, 피치 덱, 또는 다른 아티팩트를 추가할 수 있습니다. Agent는 프로젝트를 재구성하는 동안 URL, 데이터, 시크릿, 배포를 보존합니다. 광범위한 출시 후 첫 48시간 동안 200개 이상의 프로젝트가 마이그레이션되었습니다.

[여러 아티팩트 지원을 위한 기존 프로젝트 업데이트](/ko/features/projects-and-artifacts/updating-projects-for-multiple-artifacts)에 대해 자세히 알아보세요.

## 통합

### Plaid 커넥터 출시

이제 **Plaid** 커넥터로 12,000개 이상의 금융 기관에 연결할 수 있습니다. 팀 관리자가 **통합**에서 자격증명을 한 번 설정하면, 앱 사용자가 Plaid Link를 통해 자신의 은행 계좌를 인증합니다. 액세스 토큰은 사용자별로 범위가 지정되어 데이터 프라이버시가 보장됩니다.

실제 거래 데이터로 작동하는 개인 재무 코치, 증권 계좌에 연결된 실시간 포트폴리오 추적기 등을 구축해 보세요. 데모와 설정 단계는 [Replit x Plaid 파트너 페이지](https://replit.com/partners/plaid)를 확인하세요.

[커넥터 관리](/ko/replitai/managing-connectors)에 대해 자세히 알아보세요.
