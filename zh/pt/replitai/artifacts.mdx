<div id="o-que-so-artefatos">
  ## 什么是产物？
</div>

产物是你可以在 Replit 上部署的内容，例如：Web 应用、移动应用、幻灯片演示文稿、动画、数据应用、3D 游戏和设计。每个产物都是完整、独立的输出，部署后都会拥有自己的可分享 URL。

项目中的其他所有内容——文件、图片、CSV、代码——都为你的产物提供支持，但无法单独部署。

<div id="primeiros-passos">
  ## 入门
</div>

在 Replit 首页，你可以通过两种方式创建：

* **描述**：输入你的需求，例如“为我创建一个食谱应用”或“为我的初创公司制作一份路演演示文稿”。Agent 会判断适合的类型并为你创建。
* **选择类型**：先选择你想要的产物类型——Web 应用、移动应用、数据可视化、动画、3D 游戏或其他受支持的类型——再描述你的想法。

你也可以随时在 Chat 中向 Agent 提出请求，或点击预览面板中的 **+** 按钮，为现有项目添加更多内容。

<div id="alternando-entre-artefatos">
  ## 在产物之间切换
</div>

当一个项目包含多个产物时，可通过**预览面板**或**素材库侧边栏**在它们之间切换。你也可以让 Agent“显示移动应用”或“切换到幻灯片”。

<div id="vrios-artefatos-em-um-projeto">
  ## 一个项目中的多个产物
</div>

一个项目最多可包含 **7 个产物**，其中移动应用最多 **1 个**。例如，您可以为客户构建 Web 应用，为团队构建移动应用，并为投资者制作幻灯片演示文稿——所有这些都在同一项目中完成。

<div id="adicionando-artefatos-a-um-projeto">
  ### 向项目添加产物
</div>

可通过以下三种方式向现有项目添加产物：

* **Chat**：让 Agent“向此项目添加一个移动应用”，或“为投资者路演创建一份幻灯片演示文稿”
* **添加按钮**：点击预览面板中的 **+** 按钮，然后选择要构建的内容
* **素材库侧边栏**：浏览现有产物、图片和其他资源，并从这里添加新产物

<div id="dados-e-backend-compartilhados">
  ### 共享数据和后端
</div>

当多个产物位于同一项目中时，它们会自动共享相同的数据和后端逻辑。如果客户通过您的 Web 应用下单，您的移动应用和数据仪表板也能看到该订单。您无需配置任何连接或重复编写代码——开箱即用。

<Note>
  部署会一次性部署整个项目。所有产物会同时上线，始终保持同步。
</Note>

<div id="exemplos-de-combinaes">
  ### 组合示例
</div>

* **Web 应用 + 移动应用**：餐厅可同时拥有面向顾客的 Web 应用和供团队使用的移动应用，两者均连接到同一数据库和 API
* **应用 + 管理仪表板**：主产品搭配内部管理面板，用于管理内容、用户或设置
* **应用 + 幻灯片演示文稿**：将您的产品和路演演示文稿放在同一项目中，确保幻灯片始终反映最新版本
* **数据仪表板 + 视频**：将实时数据可视化与展示重点内容的动画视频相结合

<div id="publicao">
  ## 部署
</div>

应用、幻灯片和视频均可部署和分享。部署后，每个产物都会获得专属的可分享 URL。

非产物的文件和资源 (例如 CSV、图片或 Markdown 文件) 无法单独部署。要分享这些文件，请将其添加到应用中，或创建新的产物。

<div id="perguntas-frequentes">
  ## 常见问题
</div>

<Accordion title="一个项目中可以包含多个产物吗？">
  可以。单个项目最多可包含 **7 个产物**，其中每个项目最多只能有 **1 个移动应用**。同一项目中的所有产物会自动共享后端和数据。

  如果您已达到移动应用数量上限，但想构建第二个移动应用，请在新项目中创建。如果您已达到 7 个产物的总上限，请先移除一个现有产物再添加新的产物，或将工作拆分到多个项目中。
</Accordion>

<Accordion title="开始前需要选择类型吗？">
  不需要。只需描述您想要构建的内容，Agent 会为您选择合适的类型。您也可以根据需要在下拉菜单中手动选择类型。
</Accordion>

<Accordion title="我可以只部署项目中的一个产物吗？">
  目前不可以。部署会一并部署整个项目，以确保所有产物保持同步。如果您需要独立部署，请使用单独的项目。
</Accordion>

<Accordion title="产物之间会共享数据吗？">
  会。项目中的所有产物共享同一个数据库和后端服务。如果您的 Web 应用写入数据，移动应用和数据仪表板可以立即读取这些数据。
</Accordion>

<Accordion title="产物和文件有什么区别？">
  产物是可以部署的内容，例如应用、幻灯片和视频。文件 (如 CSV、图片或代码) 是项目中用于支持产物的资源，但无法单独部署。
</Accordion>

<Accordion title="我的移动应用缺少 Web 应用中的功能，这是怎么回事？">
  当 Agent 在不同产物类型之间转换功能时，某些内容可能无法完美迁移，尤其是不同平台上实现方式不同的交互或布局。您可以在 Chat 中继续跟进，以补齐缺失的内容。
</Accordion>

如需查看可构建内容的完整列表，请参阅 [Projects 概览](/zh/pt/replitai/projects)。
