<div id="audio-support-in-ai-integrations">
  ### AI 集成支持音频
</div>

<Frame>
  <img src="/assets/mirror/screenshot-2026-01-22-at-9-08-38-am_80c7a6b9af74-1f051e99efdc.png" alt="AI 集成的音频设置，显示转录和输出选项" width="2884" height="1768" data-path="images/changelog/2026-01-23/screenshot-2026-01-22-at-9-08-38-am_80c7a6b9af74.png" />
</Frame>

AI 集成现已支持音频功能，并新增四个模型：

* `gpt-4o-transcribe` 和 `gpt-4o-transcribe-mini`，用于语音转文字
* `gpt-4o-audio` 和 `gpt-4o-audio-mini`，用于生成音频输出

使用这些模型构建可处理或生成音频内容的应用：转录播客、创建语音助手，或为你的 App 添加语音界面。

<div id="web-search-in-agent-automations">
  ### Agent 自动化中的网页搜索
</div>

<Frame>
  <img src="/assets/mirror/image_935f53bc7191-e59f7aee0cd0.png" alt="Agent 通过自动化提供研究摘要" width="1482" height="2492" data-path="images/changelog/2026-01-23/image_935f53bc7191.png" />

创建无需 API 密钥即可使用网页搜索的自动化。Agent 通过 AI 集成提供 LLM 原生网页搜索，支持定时研究、新闻摘要或教育内容推送。

<div id="rulessync-support-for-replitmd">
  ### RulesSync 支持 replit.md
</div>

开源项目 [RulesSync](https://github.com/dyoshikawa/rulesync) 现已支持 `replit.md` 文件。你可以在多个项目间同步 AI Agent 配置文件 (`CLAUDE.md`、`AGENT.md` 和 `replit.md`) 。
