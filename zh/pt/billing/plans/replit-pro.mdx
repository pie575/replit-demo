export const ProCreditRolloverPeriod = '两个月';

[Replit Pro](https://replit.com/pricing) 专为需求已超出 Core 的资深构建者打造——无论你是要将应用发布到生产环境、与不断壮大的团队协作，还是把 Agent 的能力推向极限。请查看[定价页面](https://replit.com/pricing)了解 Pro 的最新价格。

<div id="principais-recursos">
  ## 主要功能
</div>

<div id="a-experincia-agent-mais-poderosa">
  ### 更强大的 Agent 体验
</div>

* **Turbo 模式**：高级设置中的独立**开关**——在 **Power** 模式下开启后，Agent 使用最快的模型，速度可提升至 **2.5 倍**。请求费用约为 2 倍，因此建议有经验的构建者使用。
* **并行执行任务**：最多可同时运行 10 个任务，加快迭代速度。
* **Agent 模式**：根据任务选择 Lite、Economy 或 Power；需要最高速度时，可在 Power 模式下使用 Turbo。有关说明，请参阅 [Agent 模式](/zh/pt/features/agent/agent-modes)。

<div id="crditos-por-camadas-e-transferncia">
  ### 分层积分与积分结转
</div>

* **分层月度积分**：提供多个档位，档位越高折扣越大。提前购买可享更多优惠，并随业务增长随时加购积分。各档位详情请参阅[定价页面](https://replit.com/pricing)。
* **积分结转**：未用完的积分可结转 {ProCreditRolloverPeriod}，让你的订阅更超值。

<div id="escale-sua-equipe">
  ### 扩展你的团队
</div>

* **最多 15 位构建者**：邀请最多 15 位构建者，共享积分并设置预算控制。无按用户收费——所有人共用同一个计划。
* **协作 Workspace**：使用管理员账户的共享积分创建协作 Workspace；按 Workspace 组织 app 并跟踪用量。

<div id="suporte-prioritrio-e-confiabilidade">
  ### 优先支持与可靠性
</div>

* **优先支持**：工作日可优先直接联系支持工程师。这是 Pro 和 Enterprise 提供的一项权益，可作为 AI 驱动支持的补充。
* **数据库恢复窗口延长至 4 倍**：可将数据库恢复到过去 28 天内的任意时间点，而非标准的 7 天。请注意，更长的保留期会占用更多存储空间，因此延长恢复期限会增加使用成本。

<div id="comunidade-e-mais">
  ### 社区及更多
</div>

* **专属社区**：与其他认真的构建者相互学习，分享你正在打造的项目，并享有与我们团队直接沟通的专属通道。
* **更多内容敬请期待**：今年还将有更多功能率先登陆 Pro。

<div id="o-que-exclusivo-do-pro">
  ## Pro 专享功能
</div>

| 功能         | 详情                                  |
| ---------- | ----------------------------------- |
| Turbo 模式   | 使用性能最强的模型，Agent 速度提升至 2.5 倍         |
| 并行执行任务     | 最多可同时执行 10 项任务                      |
| 最多 15 名构建者 | Core 最多为 5 名                        |

Pro 还包含 Core 的所有功能。如需查看完整对比，请参阅[价格页面](https://replit.com/pricing)。
