<div id="o-que-ssh">
  ## 什么是 SSH？
</div>

SSH 全称 Secure Shell，是一种安全协议，可让你远程访问 Replit App 的命令行界面。借助 SSH，你可以顺畅地传输文件，并使用自己惯用的本地集成开发环境 (IDE) 编辑 Replit 上的代码，从而提升开发流程中的协作效率与生产力。

Core、Pro 及其他所有付费方案均支持 SSH 功能。

流程概览如下：

* 在本地机器上生成一对 SSH 密钥
* 将该 SSH 密钥添加到任意 Replit App 的 **SSH** 面板中
* 使用 SSH 客户端或支持通过 SSH 工作的编辑器 (例如 [VSCode](https://code.visualstudio.com/) 或 [Cursor](https://www.cursor.com/)) 进行连接

<Note>
  SSH 密钥关联的是你的账户，而非某个特定的 Replit App。也就是说，公钥只需添加一次，之后即可连接到任何你有权访问的 Replit App。
</Note>

<div id="por-que-usar-ssh">
  ## 为什么使用 SSH？
</div>

* **Replit App 与编辑器自动同步更新**：在 Replit App 中所做的任何更改都会即时反映到编辑器中，而在编辑器中所做的任何修改也会同步更新到 Replit App。这种无缝同步可确保你的代码库在两端始终保持最新。

* **文件管理同步**：无论是添加、删除还是更新文件，这些更改都会在编辑器与 Replit App 之间实时同步。该功能可确保无论从哪一端发起更改，项目结构都保持一致。

* **文件夹管理与文件移动**：在文件夹之间移动文件同样会在编辑器与 Replit App 之间同步。这样一来，在一个环境中所做的整理调整都会准确反映到另一个环境中，从而保持项目的完整性与结构。

<div id="encontre-ou-crie-um-par-de-chaves">
  ## 查找或创建密钥对
</div>

要为您的帐户配置 SSH，您需要 SSH 公钥。

<div id="verificando-se-voc-j-tem-um-par-de-chaves">
  ### 检查你是否已有密钥对
</div>

你可以在本地计算机的终端中运行以下命令，检查自己是否已经拥有公钥：

<Tabs>
  <Tab title="Mac/Linux">
    ```sh theme={null}
    ls -l ~/.ssh
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    dir %HOMEPATH%\.ssh
    ```
  </Tab>
</Tabs>

如果出现报错，不必担心，请前往[生成新的密钥对](#generating-a-new-keypair)。
如果你看到名为 `replit.pub` 的文件，请前往[获取公钥内容](#get-the-contents-of-your-public-key)。

<div id="gerando-um-novo-par-de-chaves">
  ### 生成新的密钥对
</div>

在你的计算机上打开终端 (或命令提示符) ，然后粘贴以下命令：

<Tabs>
  <Tab title="Mac/Linux">
    ```bash theme={null}
    ssh-keygen -t ed25519 -f ~/.ssh/replit -q -N ""
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    ssh-keygen -t ed25519 -f %HOMEPATH%\.ssh\replit -q -N ""
    ```
  </Tab>
</Tabs>

此命令会检查指定的 SSH 公钥文件是否已存在。如果不存在，它会使用适当的参数创建新的 SSH 密钥。

<div id="obtenha-o-contedo-da-sua-chave-pblica">
  ### 获取公钥内容
</div>

确认已有密钥对或创建密钥对后，显示公钥的内容 (即两个名称相似、后缀为 `.pub` 的文件之一) ，稍后会用到。

<Tabs>
  <Tab title="Mac/Linux">
    ```sh theme={null}
    cat ~/.ssh/replit.pub
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    notepad %HOMEPATH%\.ssh\replit.pub
    ```
  </Tab>
</Tabs>

保存 `replit.pub` 的内容，供本文后续步骤使用，然后继续[将 SSH 密钥添加到你的帐户](#add-the-ssh-key-to-your-account)。

<div id="adicione-a-chave-ssh-sua-conta">
  ## 将 SSH 密钥添加到你的账户
</div>

<div id="adicione-a-chave-pblica-diretamente-em-um-replit-app-usando-o-painel-ssh">
  ### 使用 SSH 面板直接在 Replit App 中添加公钥
</div>

1. 在你的 Replit App 中，于任意窗口点击 **+** 按钮，搜索 **SSH**。

<Frame>
  <img src="/assets/mirror/ssh-tool-2db02c6a83d0.png" alt="Replit 界面中的 SSH 工具按钮" width="846" height="328" data-path="images/ssh-vscode/ssh-tool.png" />
</Frame>

2. 切换到 **Keys** 标签页，选择 **New SSH key**。
3. 在弹出窗口中，为密钥输入 **Label** (例如 my-ssh-key) ，并将此前复制的公钥粘贴到 **Key** 中。
   点击 **Add SSH Key** 按钮。密钥即添加完成并已授权使用。

<Frame>
  <img src="/assets/mirror/add-ssh-key-with-values-5d6f440e56ba.png" alt="已填写标签和密钥字段的 Add SSH key 对话框" width="500" height="511" data-path="images/ssh-vscode/add-ssh-key-with-values.png" />
</Frame>

<div id="adicione-a-chave-pblica-diretamente-em-settings">
  ### 直接在 Settings 中添加公钥
</div>

你也可以打开 **Settings**，在 **Account** 下选择 **Advanced** (或 **SSH keys** 选项) 来添加 SSH 密钥。选择 **Add SSH key**，然后粘贴上一节[查找或创建密钥对](#find-or-create-a-keypair)中 `replit.pub` 的内容。

<Note>
  当你的机器上有多个公钥时，务必确保在 SSH 配置中使用了正确的私钥与公钥组合。
</Note>

<div id="conectando-se-ao-seu-replit-app">
  ## 连接到您的 Replit App
</div>

<div id="configure-seu-arquivo-de-configurao-ssh">
  ### 配置 SSH 配置文件
</div>

1. 在终端中，确保目录 `~/.ssh` 和文件 `~/.ssh/config` 已存在：

<Tabs>
  <Tab title="Mac/Linux">
    ```sh theme={null}
    mkdir -p ~/.ssh && chmod 700 ~/.ssh && touch ~/.ssh/config && chmod 600 ~/.ssh/config
    open -a 'TextEdit' ~/.ssh/config || nano ~/.ssh/config
    ```
  </Tab>

  <Tab title="Windows">
    ```sh theme={null}
    if not exist %HOMEPATH%\.ssh mkdir %HOMEPATH%\.ssh && type \NUL > %HOMEPATH%\.ssh\config
    notepad %HOMEPATH%\.ssh\config
    ```
  </Tab>
</Tabs>

2. 添加以下配置块，使所有 *.replit.dev 域名均使用 `replit` 密钥对：

<Tabs>
  <Tab title="Mac/Linux/Windows">
    ```
    Host *.replit.dev
        Port 22
        IdentityFile ~/.ssh/replit
        StrictHostKeyChecking accept-new
    ```
  </Tab>
</Tabs>

<div id="conecte-se-pelo-vscode-ou-cursor">
  ### 通过 VSCode 或 Cursor 连接
</div>

1. 在 Replit App 中，打开 **SSH** 面板

2. 在 SSH 面板中，切换到 **Connect** 标签页，然后选择 **Launch VS Code**。

<Tabs>
  <Tab title="使用 VSCode 连接">
    <img src="/assets/mirror/ssh-connect-439a3c150846.png" alt="SSH 的 Connect 标签页，显示 Launch VS Code 选项" width="788" height="482" data-path="images/ssh-vscode/ssh-connect.png" />
  </Tab>
</Tabs>

3. 如果系统提示填写 `~/.ssh/config`，请输入以下内容：

   ```
   Host *.replit.dev
       Port 22
       IdentityFile ~/.ssh/replit
       StrictHostKeyChecking accept-new
   ```

   <Note>
     只有在你首次尝试连接 VS Code 或其他编辑器时，才会提示添加 SSH 配置。之后若要再打开该配置文件，需要选择 **Configure SSH Hosts...**。
   </Note>

4. 如果弹出外部应用提示，请选择 **Yes**，确认你要在首选编辑器或 VS Code 中打开项目。

5. 系统可能会不时提示你安装或更新 SSH 扩展。Replit 会尽力保持与这些 IDE 最新版本的兼容性，你也可以借此获得重要的安全更新。

<div id="conecte-se-manualmente">
  ### 手动连接
</div>

在 **SSH** 面板的 &quot;Connect&quot; 选项卡底部，您会看到 &quot;Connect manually&quot;。

复制此命令，并将其粘贴到本地终端 (Mac 或 Linux) 或本地命令提示符 (Windows) 中，即可直接连接。

这也是排查 IDE 连接问题的好方法；向 Replit 支持团队报告错误时，还可借此收集有价值的 &quot;verbose&quot; 连接信息。

<div id="conecte-se-por-meio-de-uma-ferramenta-no-listada-aqui">
  ### 使用此处未列出的工具连接
</div>

适用于不同平台和操作系统的 SSH 客户端有很多，其中不少提供不同的功能或集成。

您可以随时将 &quot;Connect Manually&quot; 中显示的命令拆解为各个组成部分，以了解如何配置每个客户端：

```sh theme={null}
ssh -i ~/.ssh/replit -p 22  c96b6ade-d5e4-4f7a-bc5b-52334509b2a3@c96b6ade-d5e4-4f7a-bc5b-52334509b2a3-00-16nh2hskw3ql8.riker.replit.dev
       ^-----v-----^    ^^  ^-----------------v----------------^ ^------------------------------v-------------------------------------^
        Private Key   Port                   User               @                           Hostname
```

**主机名**：`<your_hostname>.<cluster>.replit.dev`
**端口**：`<port_number>`
**用户**：`Username`
**私钥**：您电脑上私钥文件的路径，通常位于 `replit.pub` 旁边。
