ダッシュボードは、データから意思決定を行う手助けをします。

公開 CSV から **Global Progress Explorer** をビルドします: 年、人口、大陸、平均寿命、GDP 一人当たりを含む国レベルのデータです。

## 達成できること

このガイドを終えると、以下が完成します:

* リアルな公開 CSV からビルドされた Global Progress Explorer ダッシュボード。
* 国数、人口、平均寿命、GDP 一人当たりのサマリーメトリクス。
* 時間の経過とともに進捗がどのように変化したかを示すチャートとフィルター。
* ダッシュボードの数値をソースデータと照合する方法。
* ステークホルダーと共有または公開できるダッシュボード。

## 学べること

以下の方法を学びます:

* チャートタイプではなく、意思決定から始める。
* 公開 CSV からダッシュボードをビルドするよう Agent に依頼する。
* 基礎データと照らし合わせて計算を確認する。
* フィルターと洞察サマリーを追加する。
* ダッシュボードにログイン、更新、エクスポート、接続データが必要かどうかを決断する。

## 対象者

顧客、売上、プロダクト、オペレーション、研究、または公開データがあり、人々が理解できるダッシュボードが必要な場合にこのガイドを使ってください。

生データを意思決定に変換する必要があるアナリスト、オペレーター、創業者、PM、教育者、チームに役立ちます。

## 意思決定を定義する

ビルドする前に、ダッシュボードがサポートすべき意思決定を書き留めてください。

グローバル進捗データセットの場合:

* **質問**: 平均寿命と GDP 一人当たりはどこで時間の経過とともに改善したか？
* **対象者**: 教育、研究、戦略、または非営利チーム。
* **有用なメトリクス**: 国数、年範囲、最新の中央値平均寿命、代表される総人口、中央値 GDP 一人当たり。
* **有用なフィルター**: 大陸、国、年範囲。

意思決定を述べられない場合、ダッシュボードは有用なツールではなくチャートのコレクションになってしまいます。

## 公開 CSV からビルドする

意味のあるフィールドと十分な行数を持つ良質な公開データセットを使ってください。

データセット: [Gapminder グローバル進捗 CSV](https://raw.githubusercontent.com/plotly/datasets/master/gapminderDataFiveYear.csv)

その CSV からダッシュボードをビルドするよう Agent に依頼します:

<AiPrompt>
  Build a Global Progress Explorer dashboard from this public CSV:<br />
  [https://raw.githubusercontent.com/plotly/datasets/master/gapminderDataFiveYear.csv](https://raw.githubusercontent.com/plotly/datasets/master/gapminderDataFiveYear.csv)<br />
  The dashboard should help an education or research team understand how life expectancy, population, and GDP per capita changed across countries and continents from 1952 to 2007.<br />
  Include summary cards for total countries, year range, latest median life expectancy, total population represented, and latest median GDP per capita.<br />
  Add a line chart for life expectancy over time by continent.<br />
  Add a bubble chart where GDP per capita is on the x-axis, life expectancy is on the y-axis, bubble size represents population, and color represents continent.<br />
  Add a bar chart showing the countries with the largest life expectancy gains between their first and latest year in the dataset.<br />
  Add filters for continent, country, and year range.<br />
  Include a short insights summary that explains the biggest patterns and which regions or countries improved most.<br />
  Show how key metrics are calculated so I can verify the numbers.<br />
  Make the dashboard polished, responsive, and easy to read on desktop and mobile.
</AiPrompt>

## 作業を確認する

Preview を開いて、共有する前にダッシュボードを確認します。

以下を確認してください:

* 総国数が CSV の一意の国数と一致する。
* 年範囲が1952年から2007年を示している。
* 最新の中央値平均寿命がデータセットの最新年を使用している。
* 人口合計がフィルタリングされた国と年を使用している。
* フィルターがサマリーカードとチャートを更新する。
* バブルチャートが GDP 一人当たり、平均寿命、人口、大陸を正しく使用している。
* 洞察サマリーがチャートの内容と一致している。
* ダッシュボードがスマートフォンサイズの画面で動作する。

数値が期待と異なる場合は、Agent に計算を表示するよう依頼してください。

<AiPrompt>
  The latest median life expectancy looks different than I expected.<br />
  Show me how you calculated it from the CSV.<br />
  Check that you used only rows from the latest year in the filtered data.<br />
  Update the calculation if needed and tell me how to verify it.
</AiPrompt>

## フィルターとエクスポートを追加する

最初のダッシュボードが動作したら、対象者がデータを探索するのに役立つインタラクションを Agent に依頼します。

<AiPrompt>
  Add an exploration panel for the global progress dashboard.<br />
  Let me filter by continent, country, and year range.<br />
  Add a button to export the filtered chart data to CSV.<br />
  Keep the summary cards and insights summary in sync with the filters.
</AiPrompt>

ダッシュボードは PDF エクスポート、チャート CSV エクスポート、更新、自動更新、ライト/ダークモード、分析サマリーもサポートできます。コンセプトの概要については [Data Visualization](/ja/features/artifact-types/data-apps) をご覧ください。

## 必要なときに接続データを使う

学習またはプロトタイピング時は公開 CSV を使ってください。ダッシュボードを最新の状態に保つ必要がある場合は接続データソースを使ってください。

ダッシュボードを以下に接続できます:

* Replit アプリのデータベース。
* BigQuery、Databricks、Snowflake などのウェアハウスコネクタ。
* Segment、Amplitude、Hex などのアナリティクスツール。
* 外部 API。

ウェアハウスデータの場合は、Agent に使用するフィールドとクエリを説明するよう依頼してください。

<AiPrompt>
  Create a growth dashboard using our warehouse connector.<br />
  Identify the customer, product usage, billing, and retention fields needed.<br />
  Build charts for active customers over time, account growth by segment, and expansion revenue by plan.<br />
  Explain the fields and calculations you used so I can verify the dashboard.
</AiPrompt>

セットアップと利用可能性の詳細については、[Data Connectors](/ja/connectors/warehouses/overview) をご覧ください。

## ダッシュボードを共有する

数値が信頼できるようになったらダッシュボードを共有します。

ダッシュボードがプライベートな顧客またはビジネスデータを使用している場合は、広く共有する前にアクセス制御を追加してください。公開またはサンプルデータの場合は、URL を直接公開・共有できます。

レビュアーに依頼します:

> グローバル進捗ダッシュボードを確認して、最初に強調する地域または国のストーリーとその理由を教えてください。

## 完了の確認

* ダッシュボードが公開 CSV を読み込んでいる。
* サマリーカードとチャートが進捗の質問に答えている。
* 少なくとも1つの主要メトリクスを手動で確認した。
* フィルターがダッシュボードを正しく更新する。
* 洞察サマリーがデータと一致している。
* ダッシュボードを公開のままにするか、ログインを必要とするか、ライブデータに接続するかを判断した。

## さらに助けが必要ですか？

* **数値が期待と異なる:** Agent にクエリ、計算式、または変換を表示するよう依頼してください。
* **CSV が利用不可:** URL、ネットワークアクセス、CSV ヘッダーを確認してください。
* **フィルターがチャートを更新しない:** Agent にフィルターをサマリーカードとチャートデータ両方に接続するよう依頼してください。
* **ダッシュボードが遅い:** Agent にデータの集約、フィルターの追加、起動時に読み込む行数の削減を依頼してください。
* **ダッシュボードがプライベートデータを使用している:** 広く共有する前にログインを追加してください。
