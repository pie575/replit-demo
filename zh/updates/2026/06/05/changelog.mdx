<div id="sell-physical-products-with-shopify">
  ### 使用 Shopify 销售实体商品
</div>

现在，您可以构建销售实体商品的在线商店。让 Agent 为您创建商店，它会为您创建 Shopify 商店、添加商品，并设置购物车和结账流程。Agent 会提供一个链接供您认领商店，之后您只需注册 Shopify 套餐并连接支付方式，即可上线。

<div id="build-data-apps-on-microsoft-fabric">
  ### 在 Microsoft Fabric 上构建数据应用
</div>

现在，你可以在 Replit 中构建 AI 驱动的数据应用，并直接将其发布到 Microsoft Fabric。你可以从 Microsoft Fabric 模板开始，连接 Power BI 语义模型，然后让 Agent 基于受治理的 Enterprise 数据构建仪表板和内部工具，同时将身份验证和访问策略保留在 Fabric 中。

<div id="custom-domains-set-up-their-own-dns">
  ### 自定义域名可自动配置 DNS
</div>

现在，连接自己的域名变得更加简单。关联域名后，Replit 会通过 Entri 自动为您配置所需的 DNS 记录，无需再手动将记录复制到域名提供商处。选择域名并确认，其余操作由 Replit 完成。

详细了解[自定义域名](/zh/features/publishing/custom-domains)。

<div id="improve-your-search-ranking-with-seo-agent">
  ### 使用 SEO Agent 提升搜索排名
</div>

SEO Agent 会审核已发布的 App，找出阻碍搜索引擎和 AI 工具发现它的问题。每项发现都提供可供审核和应用的一键修复。打开项目中的 **Growth** 面板即可运行扫描。

<div id="use-stripe-in-collaborative-workspaces">
  ### 在协作 workspace 中使用 Stripe
</div>

Stripe 现已支持协作 workspace，整个团队可以共同构建、测试并通过同一个 App 获利。workspace 中的所有成员都可以使用已连接的 Stripe Account，无需再独自搭建支付功能。

了解更多 [Stripe Payments](/zh/features/monetization/stripe-payments) 信息。
