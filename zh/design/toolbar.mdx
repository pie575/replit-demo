Canvas 工具栏是悬浮在画板底部中央的浮动栏，集中提供用于导航、绘制、编辑和添加内容的各项工具。该工具栏仅在 Canvas 模式下显示。

</Frame>

<div id="tools">
  ## 工具
</div>

选中某个工具即可将其激活，处于激活状态的工具会以填充背景高亮显示。最左侧的一组是导航工具 (Interact、Pan) ，其余为内容和标注工具。各工具之间互斥，选中其中一个即会取消其他工具的激活状态。

<div id="interact">
  ### Interact
</div>

**Interact** 是默认工具。你可以用它选中 frame、拖动 frame，也可以点击进入实时的 artifact，像使用真实运行的应用一样操作它。启用 Interact 后，点击某个 frame 即可将其选中，并显示[单个 frame 操作栏](/zh/design/frames#per-frame-action-bar)。

<Frame>
  <img src="/assets/mirror/canvas-interact-4472dae3de09.png" alt="使用 Interact 工具在 Canvas 上选中了一个 Website artifact —— frame 周围显示带选择控制点的轮廓，上方显示单个 frame 操作栏。底部浮动工具栏中的 Interact 工具处于高亮状态。" width="3450" height="2000" data-path="images/replitai/canvas-interact.png" />
</Frame>

**键盘快捷键：** `V`。**启用条件：** 始终可用。

<div id="pan">
  ### Pan
</div>

**Pan** (平移) 会将光标切换为抓手工具，让你可以直接拖动画板。启用 Pan 后，点击并拖动会移动视口，而不是选中 frame。使用其他任意工具时，你也可以按住空格键拖动，或按住鼠标中键拖动来平移画布。

<Frame>
  <img src="/assets/mirror/canvas-pan-9f07d3bf72a3.png" alt="启用 Pan 工具的 Canvas — 画板上可见一个网站 Website artifact（Velocity — Supercar Rental）和一个 Design 视觉原型（Velocity — Home (Mockup)），底部浮动工具栏中的 Pan（抓手光标）工具处于高亮状态。" width="1725" height="1041" data-path="images/replitai/canvas-pan.png" />
</Frame>

**键盘快捷键：** `H`。**启用条件：** 始终可用。

<div id="chat">
  ### Chat
</div>

**Chat** 会直接在画板上打开一个小型聊天输入框，让你无需离开 Canvas 即可向 Agent 发送 prompt。选中的元素和 frame 依然会以快照形式附加到消息中，与从侧边 Agent 聊天面板发送时相同。

<Frame>
  <img src="/assets/mirror/canvas-chat-d28e2d8f216a.png" alt="处于 Chat 模式的 Canvas，画板其余部分变暗，内联聊天输入框叠加在一个 Website artifact 上。输入框中的 “div” 标签表示已选中某个元素，prompt 内容为 “suggest three alternatives to this image”。底部浮动工具栏中的 Chat 工具处于高亮状态。" width="3450" height="2000" data-path="images/replitai/canvas-chat.png" />
</Frame>

**启用条件：** Chat 工具 (仅限桌面端) 。

<div id="draw">
  ### Draw
</div>

**Draw**会启用手绘、箭头、便签和形状等标注工具，让你可以在 frame 上绘制草图或在画板上添加注释。你可以用它圈出问题区域、指出需要修改的元素，或在 frame 旁留下文字备注。

启用 Draw 后，浮动工具栏上方会显示 **形状属性**栏，其中包含当前标注工具的颜色、描边和填充控件。切换回 Interact 或 Pan 时，该栏会自动隐藏。

<Frame>
  <img src="/assets/mirror/canvas-draw-d2d9b6556cde.png" alt="Canvas 已启用 Draw 工具——一个手绘的“Widget”矩形和一张紫色的“添加小组件”便签位于 frame 旁。浮动工具栏上方显示形状属性栏（铅笔、文本、矩形、箭头、便签工具，以及颜色样本和 Aa 文本大小控件），其中“Draw”处于高亮状态。" width="1725" height="1041" data-path="images/replitai/canvas-draw.png" />
</Frame>

**启用条件：**始终启用。

<div id="edit">
  ### Edit
</div>

**Edit** 是元素的可视化选择器。启用 Edit 后，在实时 artifact 中点击即可选中某个元素 (按钮、标题、图片) 。选中元素后会打开 **Visual Editor**——右侧的控件面板 (Layout、Color、Border 等) ，并配有内联 prompt，可让 Agent 只修改选中的这一部分。完整流程请参阅 [元素](/zh/design/elements) 和 [Visual Editor](/zh/design/visual-editor)。

<Frame>
  <img src="/assets/mirror/canvas-edit-67fe5ee02fbe.png" alt="在一个超跑租赁网站上启用 Edit 工具并选中一个 div 元素，Visual Editor 面板显示 Text、Layout、Color、Border 控件以及放弃和保存编辑按钮" width="2000" height="1269" data-path="images/replitai/canvas-edit.png" />
</Frame>

**启用条件：**始终可用 (桌面端) 。至少存在一个 frame 之前处于禁用状态，此时工具提示显示 *“Create an artifact or generate a design to edit.”*；在移动端隐藏。

<div id="generate">
  ### Generate
</div>

**Generate** 会打开 **Generate media** 弹出面板，用于生成图片、视频和矢量图形。选择类型、输入 prompt，Agent 便会将生成结果作为新的 frame 放置到画板上。

<Frame>
  <img src="/assets/mirror/canvas-add-menu-5d97d9c813e1.png" alt="Canvas 的 + Add 菜单已展开，纵向排列着四个选项：Design（“Mock up interfaces and visual concepts”）、Image（“Generate and edit images”）、Video（“Generate motion clips and animations”）和 Vector Graphic（“Generate vector illustrations and SVGs”）。底部浮动工具栏中的 Generate 位置现在显示为“+ Generate”。" width="1102" height="702" data-path="images/replitai/canvas-add-menu.png" />
</Frame>

该弹出面板顶部有四个标签页：

* **Design**
  — **Image**
* **Video**
* **Vector Graphic**

部分控件为所有类型通用，其余仅适用于特定类型。

**通用控件 (所有类型) ：**

* **Model**：使用的生成模型。可用模型因类型而异 (见下表) 。
* **Prompt**：用自然语言描述你希望 Agent 生成的内容。
* **Generate**：提交请求，并在光标位置预留一个占位 frame。assets 准备就绪后，占位符会转为实际的 frame；若生成失败，占位符将被移除，并在 chat 面板中显示错误信息。

**各类型的模型与控件：**

| 类型          | 适用场景                             | 当前模型                                                         | 类型专属控件                                                       |
| ----------- | -------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **Image**   | 位图输出 (PNG / JPG) ；情绪板图像、主视觉图、参考图 | Nano Banana、Nano Banana 2、Nano Banana Pro、ChatGPT Images 2.0 | 宽高比 (`1:1`、`16:9`、`9:16`、`4:3`、`3:4`) · 尺寸 (`1K`、`2K`、`4K`)  |
| **Video**   | 短动态片段与动画                         | Veo 3.1、Seedance 2.0                                         | 宽高比 · 分辨率 (如 `720p`) · 时长 (如 `4s`) · 音频开关                    |
| **Graphic** | SVG 矢量输出；图标、标志、图表、风格化插画          | Claude 4.6 Opus、Gemini 3.1 Pro Preview                       | 动画开关                                                         |

<Note>
  模型阵容会频繁调整。上表反映的是当前可用的模型；请在产品内的下拉菜单中查看你的账户当前可以使用哪些模型。
</Note>

关于各类 frame 的具体含义，以及创建后可以对其执行哪些操作，请参阅 [Frames](/zh/design/frames)。

<div id="attach-visual-references">
  #### 附加视觉参考
</div>

生成之前，你可以将画板上已有的内容附加为视觉参考。Agent 会参照这些内容来引导生成结果，使其与你 project 的视觉风格保持一致。打开 **Generate media** 表单中的 **+** 菜单，然后选择一个选项：

* **Upload file**：从本地电脑上传一张图片作为参考。
* **Select canvas elements**：从画板中选取已有元素。frame 会以截图形式捕获；文本和便签形状则以文本摘要的形式附加。

每个参考都会在表单中显示为一个标签。你可以按需添加多个参考，写好 prompt，然后选择 **Generate**。若要移除某个参考，点选对应的标签即可。

<Frame caption="打开 + 菜单的 Generate media 表单，显示 Upload file 和 Select canvas elements。">
  <img src="/assets/mirror/canvas-generate-media-references-ac0cb4340acb.png" alt="Canvas 上的 Generate media 表单，加号菜单已打开，显示 Upload file 和 Select canvas elements 选项，模型下拉菜单设置为 Nano Banana Pro" width="1134" height="662" data-path="images/replitai/canvas-generate-media-references.png" />
</Frame>

<Note>
  ChatGPT Images 2.0 目前不支持上传。请切换模型 (例如切换到 Nano Banana Pro) 后再附加视觉参考。
</Note>

启用 **Add menu** 后，Generate 按钮会替换为一个 **+** 菜单，将弹出框中的各类内容与 **Design** (一种不改动线上代码的独立视觉原型) 整合在一起：

**启用条件：** 图像生成。**Vector Graphic** 需要矢量图形生成；**Video** 需要视频生成。**+** 菜单需要 Add menu (而 Add menu 本身需要图像生成) 。

<div id="board-navigation">
  ## 画板导航
</div>

平移、缩放、选择手势及其键盘快捷键都属于画板级别的行为，而不是工具栏中的工具。请参阅 Canvas 页面的[画板导航](/zh/design/canvas#navigate-the-board)。
