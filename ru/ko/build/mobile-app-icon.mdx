Оба магазина требуют значок приложения перед принятием заявки. В Replit можно создать
значок самостоятельно, без отдельных инструментов для дизайна.

<div id="section">
  ## Требования каждого магазина
</div>

* **App Store:** 1024×1024, без прозрачности, без скругления углов (Apple добавит его сама).
* **Google Play:** 512×512.

<div id="section-2">
  ## Создание
</div>

Перед отправкой промпта переключитесь в режим **Design** — это укажет Agent сгенерировать изображения.

<AiPrompt>
  {appIconPrompt}
</AiPrompt>

Agent создаёт сразу несколько вариантов, чтобы вы могли сравнить их и выбрать один.
