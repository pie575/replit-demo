使用 Replit Agent 创建专业的动画视频。用日常语言描述您想要的视频，Agent 就会生成可供导出和分享的动态视频——无需视频编辑技能，也无需聘请昂贵的制作团队。

<div id="section">
  ## 概览
</div>

借助 Replit Animation，您只需与 Agent 对话，即可创建高质量的动态图形。这些是使用 React 创建的程序化动画，不使用 Remotion；动画视频通过结合网站动画库和自定义 Agent 技能实现。它不同于 Runway 或 Sora 等 AI 生成的视频。视频可包含文字叠加、流畅转场和 AI 生成的图像等内容。

视频会在 Preview 面板中自动循环播放。您可以像构建其他应用一样，通过与 Agent 对话不断迭代优化。

**所有构建者均可使用，包括免费套餐用户。**

<div id="section-2">
  ## 创建动画视频
</div>

在 Replit 首页创建动画视频有两种方法：

<div id="1">
  ### 方法 1：输入提示词
</div>

在首页选择 **App** 选项卡，然后输入描述所需视频的提示词。Agent 会自动识别与视频相关的提示词，并选择 Animated Video 技术栈。

提示词示例：

* “为新推出的气泡水品牌制作宣传视频”
* “制作一段 30 秒的视频，讲解大型语言模型的工作原理”
* “为得克萨斯州奥斯汀市制作一段具有电影感的宣传视频”

</Frame>

<div id="2">
  ### 方法 2：从下拉菜单中选择
</div>

1. 在主页上，前往 **App** 标签页。
2. 打开应用类型下拉菜单。
3. 选择 **Animation**。
4. 描述你想创建的视频。

<Frame>
  <img src="/assets/mirror/animation-entry-point-b22d4942db44.png" alt="应用类型下拉菜单，其中的选项包括 Web app、移动应用、Data Visualization、3D Game 和 Automation，当前已选择 Animation" width="1200" height="675" data-path="images/replitai/animation-entry-point.png" />
</Frame>

Agent 开始构建后，会生成动画并显示在预览面板中。你可以查看视频是否自动循环播放，并继续对话进行修改。

<div id="section-3">
  ## 迭代优化视频
</div>

Agent 生成初版后，你可以通过对话不断优化。以下是一些效果不错的方法：

* 使用聊天输入框中的 **增强提示词按钮** — 它专为视频提示词优化。
* **请求改进** — 查看初版后，提出“让它更好一些”或“在场景中添加更复杂的动画，让它更具创意”等请求，通常能获得不错的效果。
* **具体说明想要修改的部分** — 例如，“让转场更流畅”、“将配色改为深蓝色和金色”或“在结尾添加 logo 出场画面”。

尝试几种不同的提示词后，你至少会对其中一个结果感到满意。

<div id="section-4">
  ## 导出视频
</div>

如果您对视频满意，可以将其导出为 MP4 文件。

1. 找到 Preview 面板右上角的 **Export** 按钮。
2. 选择所需的质量设置：
   * **分辨率**：720p 或 1080p
   * **帧率**：30fps 或 60fps
3. 选择 **Export**。视频复杂程度不同，渲染可能需要几分钟。
4. 渲染完成后，MP4 文件会自动下载。

  <img src="/assets/mirror/animation-export-dialog-cf4d777fca06.png" alt="视频导出对话框，显示名称字段、设为 1080p 60fps 的质量下拉菜单以及 Render 按钮" style={{maxWidth: "350px"}} width="662" height="495" data-path="images/replitai/animation-export-dialog.png" />

您也可以选择 **Publish** 来分享视频链接。

**导出时间**：较长或较复杂的视频可能需要多花几分钟进行渲染。导出过程在服务器端运行，因此您可以在处理期间继续工作。

<div id="section-5">
  ## 使用场景
</div>

动画视频适用于各种创意和商业场景：

* **产品发布视频** — 用精美的宣传视频展示新应用、新功能和产品发布。
* **品牌与电影感视频** — 为企业、城市、大学和活动制作视觉效果丰富的视频。
* **讲解视频** — 在 30~60 秒内清晰讲解产品、功能或概念的运作方式。
* **社交媒体内容** — 为 Twitter/X、LinkedIn、Instagram 和 TikTok 制作吸睛的动态图形。
* **着陆页视频** — 为网站添加动态主视觉区域或背景视频。
* **筹款与投资者更新** — 为重要里程碑制作专业的演示视频。

<div id="section-6">
  ## 视频规格
</div>

| 属性      | 详细信息                                           |
| ------- | ---------------------------------------------- |
| **格式**  | MP4                                            |
| **分辨率** | 720p 或 1080p                                   |
| **帧率**  | 30fps 或 60fps                                  |
| **宽高比** | 16:9 (默认)                                      |
| **渲染**  | 在服务器端渲染；结合通常用于网站的动画库和自定义 Agent 技能，不使用 Remotion |
| **播放**  | 在预览面板中自动循环播放                                   |

<div id="section-7">
  ## 常见问题
</div>

* **可以暂停或播放视频吗？** Preview 没有内置的暂停/播放控件。视频会始终自动循环播放。如果想为视频添加暂停/播放 (或场景选择) 功能，可以让 Agent 添加——不过，添加这类控件可能会影响设计效果，因此你可能更愿意保留默认的循环播放。
* **有场景选择功能吗？** Preview 没有内置的场景选择器。如果需要，可以让 Agent 添加场景选择或其他控件，但同样需要权衡上述取舍。

<div id="section-8">
  ## 限制
</div>

动画视频是一项新功能，目前存在一些需要注意的限制：

* **仅支持程序化动画**：视频是基于 React 的动态图形，并非 Runway 或 Sora 等 AI 生成视频——不过，你可以生成视频并在代码中使用。
* **渲染时间**：复杂动画的导出可能需要几分钟。较简单的视频渲染速度更快。
* **可能需要多次迭代**：许多提示词一次就能生成出色的结果，但要获得完全符合预期的效果，可能需要迭代 2~3 次。对初始提示词使用 Enhance Prompt 按钮，并在第一个检查点后提供反馈，会有所帮助。

<div id="section-9">
  ## 后续步骤
</div>

* **尝试示例提示词**：从上方的某个演示提示词开始，看看动画视频能做什么。
* **使用 Enhance Prompt**：聊天中的 Enhance Prompt 按钮会针对视频提示词进行优化，通常能改善生成结果。
* **发布或下载**：将完成的视频导出为 MP4，或发布后通过链接分享。
* **探索其他应用类型**：了解如何使用 [Agent 构建应用](/zh/ko/features/agent/overview)，或通过 [Canvas](/zh/ko/design/canvas) 创建视觉设计。
