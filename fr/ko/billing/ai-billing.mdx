Les fonctionnalités d&#39;IA de Replit reposent sur une facturation à l&#39;usage : vous êtes facturé en fonction de ce que vous créez et de votre utilisation des outils basés sur l&#39;IA. Vous ne payez ainsi que la valeur que vous retirez d&#39;Agent.

<div id="section">
  ## Pour commencer
</div>

**Tous les abonnés** bénéficient d&#39;un point de contrôle Agent gratuit à usage unique.

Des crédits mensuels supplémentaires sont automatiquement appliqués à l&#39;utilisation de l&#39;IA :

* **Abonnés Core** : crédits mensuels (voir les [tarifs](https://replit.com/pricing))
* **Abonnés Pro** : crédits mensuels par paliers, avec un report sur {ProCreditRolloverPeriod}. Consultez [Replit Pro](/fr/ko/billing/plans/replit-pro).

Ces crédits couvrent Agent et d&#39;autres services cloud Replit, notamment les applications publiées, le stockage et les bases de données. Optimisez Agent pour la vitesse, le coût ou les performances en choisissant [Lite, Economy ou Power](/fr/ko/features/agent/agent-modes).

  ## Facturation d&#39;Agent
</div>

<Frame>
  <img src="/assets/mirror/checkpoint-f0cc3c49b9a5.png" alt="Interface de Replit Agent montrant le système de chat et de points de contrôle" width="1999" height="1242" data-path="images/billing/checkpoint.png" />

Le Free Mode permet aux abonnés Core et Pro d&#39;effectuer gratuitement les tâches courantes d&#39;Agent, dans la limite de leur allocation. Les modes payants et les tâches payantes confirmées sont soumis à une tarification basée sur l&#39;effort, selon la complexité de la demande. Replit demande une confirmation avant le lancement de toute tâche payante.

<div id="section-2">
  ### Fonctionnement de la tarification à l&#39;effort
</div>

Lorsque vous échangez avec Agent en mode Build, un **point de contrôle** est créé pour enregistrer le travail effectué pour votre demande :

* Les **demandes simples** (comme les corrections de bugs ou les petites modifications) coûtent généralement moins cher que les builds complexes
* Les **builds complexes** (comme des fonctionnalités complètes ou des intégrations) peuvent être regroupés dans un seul point de contrôle et coûter plus cher que les demandes simples, ce qui reflète l&#39;effort total nécessaire
* **Un point de contrôle par demande** élimine les points de contrôle intermédiaires et réduit le bruit dans la facturation
* Une **tarification transparente** vous permet de savoir exactement ce que vous payez pour chaque tâche terminée

<Info>
  Les points de contrôle sont créés lorsqu’Agent termine le travail demandé et implémente la fonctionnalité demandée dans le code.
</Info>

Avec les forfaits payants, Plan Mode peut effectuer un travail de raisonnement facturable même sans modifier le code.

Pour en savoir plus sur ce que les points de contrôle enregistrent et sur leur fonctionnement, consultez [Points de contrôle et retours en arrière](/fr/ko/features/version-control/checkpoints-and-rollbacks).

<div id="agent-3">
  ### Facturation des services Agent
</div>

Certaines fonctionnalités d&#39;Agent utilisent en interne des API tierces payantes (Claude, ChatGPT, Nano Banana / Gemini, etc.). Agent gère ces intégrations automatiquement : aucune clé d&#39;API ni configuration n&#39;est requise. La facturation s&#39;effectue au tarif public de l&#39;API du fournisseur et est déduite de vos crédits Replit. Ces coûts apparaissent dans le [tableau de bord d&#39;utilisation](/fr/ko/billing/managing-spend), au même titre que le reste de votre consommation.

Pour vous faire une idée du coût d&#39;une application type, consultez cette [démo interactive](https://agent-pricing.replit.app/) toute simple.

<div id="section-3">
  ### Suivi de l&#39;utilisation
</div>

Vous pouvez surveiller vos dépenses liées à Agent en temps réel :

1. **Onglet Agent** : survolez l&#39;icône d&#39;utilisation pour connaître le coût de chaque point de contrôle
2. **Tableau de bord d&#39;utilisation** : consultez le détail de la facturation pour la période en cours
3. **Paramètres** : maîtrisez vos dépenses en configurant des alertes et un budget dans **Compte** → **Facturation**

<Tip>
  L&#39;affichage des données d&#39;utilisation dans le tableau de bord peut prendre jusqu&#39;à 30 minutes.
</Tip>

<div id="section-4">
  ## Gestion des dépenses
</div>

Contrôlez vos dépenses liées à l’IA grâce aux outils de gestion du budget intégrés à Replit :

* **Alertes d’utilisation** : recevez des notifications lorsque vous atteignez des seuils de dépenses
* **Plafonds budgétaires** : définissez des limites strictes pour éviter les frais imprévus
* **Suivi en temps réel** : surveillez les coûts pendant que vous créez
* **Packs de crédits** : achetez des crédits supplémentaires à prix réduit en achetant en volume. Pour en savoir plus, consultez [Gestion des dépenses](/fr/ko/billing/managing-spend).

<div id="section-5">
  ## Étapes suivantes
</div>

Prêt à créer avec l&#39;IA ? Voici comment tirer le meilleur parti de vos crédits :

* **Essayez d&#39;abord Agent** : utilisez les points de contrôle gratuits pour explorer les capacités d&#39;Agent
* **Commencez petit** : débutez par des demandes simples pour comprendre la tarification basée sur l&#39;effort
* **Utilisez le mode Lite** : privilégiez le [mode Lite](/fr/ko/features/agent/agent-modes) pour les modifications rapides et ciblées
* **Configurez des alertes** : définissez des alertes de dépenses avant d&#39;épuiser vos crédits

Apprenez-en plus sur [les outils d&#39;IA de Replit](/fr/ko/welcome) ou explorez les [formules tarifaires](https://replit.com/pricing).
