Créez des applications avec des données actuelles et réelles grâce aux fonctionnalités Web Search <img class="icon-svg" src="/assets/mirror/web-search-1fe8f63b5b88.svg" alt="Icône Web Search" width="16" height="16" data-path="images/icons/web-search.svg" /> de l&#39;Agent.

Cette fonctionnalité dépasse les limites des connaissances en accédant aux informations les plus récentes du web. Lorsque vous demandez à l&#39;Agent de créer quelque chose qui nécessite des informations à jour, il effectue une recherche sur le web et récupère du contenu détaillé pour rendre votre app plus précise et plus utile.

  <img src="/assets/mirror/web-search-header-31c6f8a0ab88.jpg" alt="L'Agent réalise une Web Search pour rassembler des informations actuelles en vue du développement d'apps" width="1920" height="1080" data-path="images/replitai/web-search-header.jpg" />
</Frame>

Web Search est précieux pour trouver les paquets, outils et informations les plus récents. Vos apps s&#39;appuient ainsi sur les meilleures pratiques actuelles et gagnent en précision.

<div id="recursos">
  ## Fonctionnalités
</div>

Créez des applications alimentées par des informations à jour grâce au Web Search de l&#39;Agent. Fini la recherche manuelle et la collecte de données. Que vous conceviez un dashboard de données financières ou un site présentant les dernières startups, le Web Search garantit que votre App reflète la réalité.

L&#39;Agent peut effectuer les actions de Web Search suivantes :

* **Recherche** : trouvez des informations actuelles, la documentation la plus récente et des données en temps réel sur internet
* **Recherche de contenu** : récupérez des informations détaillées depuis des sites et des URL spécifiques
* **Citations des sources** : voyez précisément d&#39;où l&#39;Agent a tiré les informations, afin de pouvoir les vérifier et citer les sources

<div id="uso">
  ## Utilisation
</div>

Web Search est intégré à Agent : il n&#39;y a rien à activer. Décrivez ce que vous souhaitez créer et Agent détermine automatiquement quand effectuer une recherche sur le web pour obtenir des informations à jour. Ajoutez des mots-clés comme « recherche », « renseigne-toi » ou « utilise Web Search » dans votre prompt pour demander explicitement à Agent de lancer une recherche.

<div id="como-o-web-search-aprimora-seus-apps">
  ### Comment Web Search améliore vos apps
</div>

Web Search transforme vos applications en remplaçant les données fictives par des informations réelles et précises :

| Avantage                   | Description                                                                                                 |
| -------------------------- | ----------------------------------------------------------------------------------------------------------- |
| Technologies à jour        | Vos apps utilisent les informations et les paquets les plus récents, absents des données d&#39;entraînement |
| Choix des meilleurs outils | L&#39;Agent explore les options pour sélectionner les paquets les plus adaptés                              |
| Bonnes pratiques actuelles | Accès aux normes de développement et aux pratiques de sécurité les plus récentes                            |
| Dépassement des limites    | Franchissez les limites de connaissances pour utiliser des paquets publiés après l&#39;entraînement         |
| Données précises           | Vos apps affichent des informations actuelles plutôt que des exemples obsolètes                             |
| Rendu professionnel        | Les applications qui font référence à de vraies entreprises inspirent davantage confiance                   |
| Gain de temps              | Évitez de rechercher des paquets et de collecter des données à la main                                      |

<div id="citaes-de-fontes">
  ### Citation des sources
</div>

Lorsque l&#39;Agent utilise Web Search, il fournit des **citations de sources** qui indiquent précisément l&#39;origine des informations. Utilisez ces citations pour :

* **Vérifier les informations** : contrôlez la fiabilité et l&#39;exactitude des sources
* **En savoir plus** : consultez les sources originales pour obtenir plus de contexte
* **Référencer les sources** : intégrez une attribution appropriée dans vos applications
* **Suivre la recherche** : identifiez les informations sur lesquelles l&#39;Agent s&#39;est appuyé

<div id="busca-de-contedo">
  ### Recherche de contenu
</div>

L&#39;Agent peut récupérer du contenu détaillé sur des sites précis afin de réunir des informations complètes pour votre projet. Cela lui permet de :

* Lire des pages entières pour en extraire les détails pertinents
* Traiter de la documentation et des supports de référence
* Collecter des données précises auprès de sources fiables
* Intégrer des informations structurées à votre application

<div id="exemplos-do-web-search-em-ao">
  ### Exemples de Web Search en action
</div>

**Découverte de paquets pour le traitement d&#39;images**

**Dernières fonctionnalités des frameworks**

<AiPrompt>
  Do research to understand the latest security best practices for authentication and authorization. Implement those best practices in my app.
</AiPrompt>

Agent recherche les meilleures pratiques de sécurité les plus récentes en matière d&#39;authentification et d&#39;autorisation, puis les met en œuvre dans votre app.

**Intégration avec des API modernes**

<AiPrompt>
  Build a weather app that uses the most reliable and feature-rich weather API available

Agent recherche les API météo actuelles et compare leurs fonctionnalités, leur fiabilité et leurs tarifs afin de sélectionner la meilleure option pour vos besoins.

Agent recherche des informations professionnelles et crée un portfolio authentique reprenant l&#39;expérience et le parcours pertinents.

**App de planification de voyage**

<AiPrompt>
  Build a trip planner for Japan with current prices and recommendations
</AiPrompt>

Agent trouve des coûts de voyage à jour, des attractions et des informations de planification pour créer une application de voyage réaliste.

**Dashboard de comparaison financière**

<AiPrompt>
  Create a dashboard comparing the latest quarterly earnings of major cloud providers
</AiPrompt>

Agent recherche les rapports financiers récents et crée un dashboard avec des visualisations de données actuelles et précises.

<Warning>
  Vérifiez toujours les informations issues des résultats de Web Search, en particulier pour les applications critiques. Bien qu&#39;Agent effectue ses recherches auprès de sources fiables, confirmez les détails importants pour les applications en production.
</Warning>
