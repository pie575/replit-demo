Добавляйте звук в свои приложения с помощью возможностей генерации аудио в Agent. Попросите Agent создать фоновую музыку, звуковые эффекты или закадровый голос — и он добавит аудио прямо в ваш проект.

Генерация аудио помогает создавать более насыщенные впечатления без студий звукозаписи, актёров озвучивания и сторонних инструментов. Будь то игра, пошаговое руководство или приложение, которому нужен голос, — Agent создаст аудио, подходящее вашему проекту.

<div id="o-que-voc-pode-criar">
  ## Что вы можете создать
</div>

Agent может генерировать три типа аудио:

* **Музыка**: фоновые треки и заглавные темы в том настроении и стиле, которые вы опишете.
* **Звуковые эффекты**: короткие клипы — щелчки, оповещения, «вжухи» и игровые звуки.
* **Речь**: естественно звучащая озвучка и закадровый текст на основе предоставленного вами текста.

<div id="uso">
  ## Использование
</div>

Генерация аудио встроена в Agent, поэтому включать ничего не нужно. Откройте любое приложение Replit с Agent и опишите, какое аудио вам нужно. Agent сам определит по вашему запросу, когда нужно сгенерировать аудио, создаст клип и добавит его в проект.

<div id="quando-o-agent-gera-udio">
  ### Когда Agent генерирует аудио
</div>

Agent генерирует аудио, когда вы запрашиваете звук в своём проекте:

| Сценарий использования   | Пример промпт                                                           |
| ------------------------ | ----------------------------------------------------------------------- |
| Фоновая музыка           | «Добавь спокойную фоновую музыку в моё приложение для медитации»        |
| Звуковые эффекты для игр | «Создай звук сбора монеты и звук прыжка для моей игры»                  |
| Голосовая озвучка        | «Сгенерируй дружелюбный голос, который вслух зачитает шаги онбординга»  |
| Оповещения и уведомления | «Сделай коротный звук колокольчика, который звучит при новом сообщении» |

<div id="como-o-udio-se-integra-ao-seu-app">
  ## Как аудио интегрируется в ваше приложение
</div>

Agent добавляет сгенерированное аудио в проект так же, как и любые другие ресурсы:

* **Автоматическое создание файлов**: сгенерированные аудиофайлы сохраняются прямо в проекте.
* **Обновления кода**: Agent встраивает аудио в приложение, чтобы оно воспроизводилось в нужный момент.
* **Итерации**: попросите Agent изменить настроение, длительность, голос или стиль — и он сгенерирует аудио заново.

<div id="faturamento">
  ## Оплата
</div>

Генерация аудио — это услуга Agent. Agent взимает плату по тарифу поставщика, которая списывается с ваших кредитов Replit. Списания отображаются на [странице использования](/ru/pt/billing/managing-spend).

<Note>
  Генерация аудио в Replit работает на базе [ElevenLabs](https://elevenlabs.io/) — сервиса, который создаёт музыку, звуковые эффекты и речь высокого качества.
</Note>
