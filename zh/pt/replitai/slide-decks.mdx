<div id="o-que-so-apresentaes-de-slides">
  ## 什么是幻灯片演示文稿？
</div>

幻灯片演示文稿让你完全通过与 Agent 对话来制作精致、专业的演示文稿。描述你的需求，即可立即得到一份完整精美的演示文稿——随后可以继续对话、可视化编辑，或在 [Design Canvas](/zh/pt/replitai/canvas) 中探索不同版本，持续迭代。

在底层，幻灯片由 React 构建，因此可以像素级还原、完全可编辑地导出为 PPTX、Google Slides 或 PDF。你还可以将演示文稿发布为可分享的正式 URL。

核心概念：

* **一次生成**：描述你的演示文稿，Agent 即可生成完整成品——布局、文本和视觉元素一应俱全
* **基于 React**：幻灯片是真正的 React 组件，而非静态图片，因此能够干净利落地导出为任意格式
* **随处导出**：下载为 PPTX、Google Slides 或 PDF——像素级还原且完全可编辑
* **可部署**：将演示文稿发布为正式 URL，任何人都能在浏览器中查看或演示

<div id="como-usar-apresentaes-de-slides">
  ## 如何使用幻灯片演示文稿
</div>

<div id="criando-uma-apresentao-de-slides">
  ### 创建幻灯片演示文稿
</div>

在 Replit 首页，有两种方式可以创建幻灯片演示文稿：

* **输入提示词**：描述你想要的演示文稿。Agent 会识别与演示文稿相关的提示词，并自动选择 Slides 技术栈。
* **从下拉菜单中选择**：打开应用类型下拉菜单，选择 **Slides**，然后描述你的演示文稿。

**提示词示例：**

* “为我的 AI 健身应用创建一份路演演示文稿”
* “为 A 轮融资制作一份 10 页的投资人演示文稿”
* “为我们的团队活动创建一份产品概览演示文稿”

<div id="comeando-com-diretrizes-de-marca-ou-uma-referncia">
  ### 从品牌指南或参考文件开始
</div>

你可以为 Agent 提供一个起点：

* **品牌指南**：上传你的品牌指南，让 Agent 在每一张幻灯片中都沿用你的配色、字体和视觉风格。
* **参考文件**：上传已有的演示文稿或文档作为起点，Agent 会以此为基础继续构建。

<div id="iterando-nos-seus-slides">
  ### 迭代优化幻灯片
</div>

Agent 生成第一版后，你可以通过对话进一步优化：

* **调整内容**：“让问题描述那张幻灯片更简洁”或“在市场规模部分后面加一张竞争格局幻灯片。”
* **更改样式**：“使用深色主题，搭配蓝色点缀”或“把字体调大，风格更简约一些。”
* **增删幻灯片**：“再加两张介绍产品路线图的幻灯片”或“删掉最后一张幻灯片。”
* **添加视觉元素**：“加一张展示预期增长的图表”或“为第 4 张幻灯片中的每项功能配上图标。”
* **重新排序或重构**：“把团队介绍那张移到最后”或“把功能幻灯片拆成两张。”

在你迭代的过程中，幻灯片会自动在预览面板中渲染，改动效果即时可见。

<div id="editando-slides-diretamente">
  ### 直接编辑幻灯片
</div>

无需通过 Chat，你也可以手动编辑：

* **[可视化编辑器](/zh/pt/replitai/visual-editor)**：点击任意元素，即可直接调整文本、颜色、间距和布局——且不消耗 AI 积分。
* **复制或删除**：右键点击任意幻灯片，即可复制或删除。

<Note>
  暂不支持在幻灯片内拖放元素。如需移动或重新排列元素，请在 Chat 中告知 Agent。
</Note>

<div id="usando-o-design-canvas-para-variaes">
  ### 使用 Design Canvas 探索变体
</div>

你可以使用 [Design Canvas](/zh/pt/replitai/canvas) 为单张幻灯片或某个版块探索不同的设计方案，然后将中意的版本应用回主演示文稿。当你想在做决定前对比多种视觉方向时，这一功能非常有用。

<div id="apresentando-e-implantando">
  ### 演示与部署
</div>

演示文稿准备就绪后：

* **演示模式**：进入全屏演示模式，直接在预览面板中放映。这与部署后观众看到的效果完全一致。
* **移动端支持**：幻灯片在移动设备上同样可用，观众可以在任意屏幕上查看。
* **发布**：将幻灯片演示文稿发布为可分享的正式 URL。任何拿到链接的人都可以在浏览器中查看或放映该演示文稿。

<div id="exportando">
  ### 导出
</div>

下载幻灯片，在 Replit 之外使用：

* **PPTX**：在 PowerPoint 或 Keynote 中打开并编辑
* **Google Slides**：直接导入 Google Slides
* **PDF**：分享可直接打印的静态版本

所有导出文件均可做到像素级还原且完全可编辑——幻灯片在 Replit 之外的呈现效果与在 Replit 中完全一致。

<div id="encontrando-suas-apresentaes-de-slides">
  ### 查找你的幻灯片演示文稿
</div>

你的幻灯片演示文稿会与其他应用一起显示在项目列表中。在项目页面打开**创建类型**下拉菜单并选择 **Slides**，即可只列出包含演示文稿产物的项目。

<div id="perguntas-frequentes">
  ## 常见问题
</div>

<Accordion title="我可以在幻灯片中拖放元素吗？">
  暂时还不行。若要在幻灯片内移动或重新排列元素，请在 Chat 中告诉 Agent。你可以使用可视化编辑器直接编辑文本、颜色和间距。
</Accordion>

<Accordion title="支持哪些导出格式？">
  你可以导出为 PPTX、Google Slides 或 PDF。所有导出结果均能做到像素级还原，并且完全可编辑。
</Accordion>

<Accordion title="我可以使用自己的品牌规范吗？">
  可以。创建演示文稿时上传你的品牌规范，Agent 会在每一张幻灯片中沿用你的配色、字体和视觉风格。
</Accordion>

<Accordion title="幻灯片在移动端可以正常显示吗？">
  可以。幻灯片会在移动设备上正常渲染，你的受众可以在任意屏幕上查看已发布或已分享的演示文稿。
</Accordion>

<Accordion title="我可以将幻灯片发布为正式 URL 吗？">
  可以。发布演示文稿后，它会生成一个可分享的正式 URL，任何人都可以在浏览器中查看或放映。
</Accordion>
