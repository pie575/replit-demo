<div id="o-que-o-visual-editor">
  ## 什么是 Visual Editor？
</div>

Visual Editor 可让您直接点击界面元素并进行直观编辑。它既可在 [Design Canvas](/zh/pt/replitai/canvas) 中使用，也可在 Prévia 中使用，因此您可以用相同的方式编辑原型稿和运行中的应用。

简单编辑 (如修改文本、调整颜色和间距) 会直接更新源代码，不消耗 AI 积分。对于涉及底层复杂性的更改，Visual Editor 会自动交由 Agent 处理。

核心概念：

* **确定性编辑**：简单更改 (文本、颜色、间距) 会直接应用到源代码，无需经过 Agent 循环
* **不消耗积分**：直接编辑不会消耗 AI 积分，只有复杂更改才会交由 Agent 处理
* **双重上下文**：在 Design Canvas 的 frame 和 Prévia 中的操作方式完全相同
* **与源代码同步**：每次编辑都会立即更新底层源代码

<Note>
  Visual Editor 目前仅支持 **网页浏览器**，不支持 Mobile 应用或 Desktop 应用。
</Note>

<div id="como-usar-o-visual-editor">
  ## 如何使用 Visual Editor
</div>

<div id="editando-na-prvia">
  ### 在 Prévia 中编辑
</div>

点击正在运行的应用中的任意元素即可开始编辑。修改文本、颜色、间距或图片，并实时查看改动效果。

<Steps>
  <Step title="选择元素">
    在 Prévia 中点击任意元素即可开始编辑。
  </Step>

  <Step title="进行编辑">
    可直接在行内编辑文本、用颜色选择器调整颜色、通过样式控件更改间距或替换图片。若需设置 内边距、margin 等更多属性，可使用 Chat 中的编辑器面板。
  </Step>

  <Step title="保存">
    点击保存以更新源代码。简单的改动会直接应用，不消耗 AI 积分。如果编辑较为复杂，Visual Editor 会将相关元数据发送给 Agent 以获得协助。
  </Step>
</Steps>

<div id="editando-no-canvas">
  ### 在 Canvas 中编辑
</div>

同样的编辑体验也适用于 Design Canvas 中的 frame。点击 frame 内的任意元素即可编辑——直接在原型稿中调整尺寸、修改文本、微调颜色和间距，无需经过 Agent 循环。

<div id="o-que-voc-pode-fazer">
  ## 你可以做什么
</div>

* **快速修改文本**：无需打开源代码文件，即可更新文案、标签和标题
* **色彩探索**：点击即可调整，轻松尝试不同配色方案——不用再去翻找对应的 CSS
* **布局调整**：直观地调整内边距、外边距和间距，不必再靠猜测填写像素值
* **替换图片**：点击并上传，即可将占位图换成真实素材
* **设计迭代**：快速调整 Canvas 上的 frame，对比不同视觉方向，无需反复与 Agent 来回沟通

<div id="perguntas-frequentes">
  ## 常见问题
</div>

<Accordion title="Visual Editor 的更改会消耗 AI 积分吗？">
  简单、确定性的编辑 (如修改文本、选择颜色、调整间距) 不会消耗 AI 积分，它们会直接更新源代码。如果 Visual Editor 检测到底层复杂性，则会将该更改转交给 Agent 处理，此时会消耗积分。
</Accordion>

<Accordion title="可以编辑出现在多个位置的元素吗？">
  可以。选中在 loop 中渲染或在多个组件中复用的元素时，所有实例会同时高亮并一起更新。
</Accordion>

<Accordion title="为什么有些元素的文本无法编辑？">
  由多个子元素组成的复合元素无法在 Visual Editor 中直接编辑文本。请在 Chat 中让 Agent 来完成这类更改。
</Accordion>

<Accordion title="如何找到某个元素的源代码？">
  点击选中元素左上角的标签，即可跳转到它在源代码中的位置。
</Accordion>
