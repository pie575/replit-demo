<Note>
  Хотите сделать SSO обязательным для **организации Replit** (вход на replit.com)? Это настраивается отдельно — см. [Единый вход (SAML SSO)](/ru/ja/teams/identity-and-access-management/saml). На этой странице описано, как добавить SSO в процесс входа для **приложений, которые вы создаёте** на Replit.
</Note>

Дайте пользователям возможность входить в ваше приложение через корпоративный провайдер идентификации (например, Okta или Microsoft Entra ID). Если ваше приложение использует [Clerk Auth](/ru/ja/features/auth-and-identity/clerk-auth), SSO и другие расширенные функции аутентификации настраиваются в Clerk Dashboard. Опишите Agent, что вам нужно, и он направит вас в Clerk Dashboard для завершения настройки.

</Frame>

Возможности Clerk Dashboard выходят далеко за рамки стандартного процесса входа. Все изменения, внесённые в Clerk, автоматически применяются к аутентификации в вашем приложении Replit.

<div id="section">
  ## Что можно настроить
</div>

* **Enterprise-подключение SSO**: настройте единый вход через OIDC или SAML с Okta или Microsoft Entra ID. Клиенты смогут входить через корпоративного провайдера идентификации. SSO также помогает защитить внутренние инструменты, работающие с конфиденциальными данными: вместо ручных списков разрешённых адресов электронной почты используется уже существующий корпоративный провайдер идентификации.
* **Многофакторная аутентификация (MFA)**: добавьте MFA в процесс входа в приложение.
* **Управление сессиями**: настройте срок действия сессий и частоту повторной аутентификации.
* **Другие настройки Clerk**: прочие настройки Clerk также применяются к приложению Replit автоматически. Не изменяйте ключи API и настройки среды — ими управляет Replit. Подробнее см. в разделе [Среда разработки и производственная среда](/ru/ja/features/auth-and-identity/clerk-auth#development-and-production-environments).

<div id="clerk">
  ## Открытие Clerk Dashboard
</div>

Опишите Agent нужные вам изменения в аутентификации. Agent применит те настройки, которые может выполнить сам, а для параметров, требующих вашего участия, направит вас в Clerk Dashboard вашего приложения.

<Frame>
  <img src="/assets/mirror/build-with-sso-agent-workflow-46422788bd18.webp" alt="Agent направляет пользователя к настройке Enterprise SSO в Clerk Dashboard для приложения, использующего Clerk." width="1602" height="1080" data-path="images/workspace/auth/build-with-sso-agent-workflow.webp" />
</Frame>

Открыть Clerk Dashboard можно и из рабочего пространства.

1. В панели Tools выберите **Users &amp; Auth**.
2. Перейдите на вкладку **Configure**.
3. Выберите **Advanced**.
4. В разделе **Clerk dashboard** нажмите **Open Clerk dashboard**.

<Frame>
  <img src="/assets/mirror/open-clerk-dashboard-tools-pane-a314ffea741d.webp" alt="Инструмент Users & Auth с открытой вкладкой Configure. Отображаются раздел Advanced и кнопка Open Clerk dashboard." width="2158" height="1372" data-path="images/workspace/auth/open-clerk-dashboard-tools-pane.webp" />
</Frame>

<div id="sso">
  ## Настройка Enterprise SSO connections
</div>

1. В Clerk Dashboard выберите **Configure**.
2. В разделе **User &amp; authentication** выберите **SSO connections**.
3. Выберите **Enterprise**.
4. Выберите **Add connection**.

<Frame>
  <img src="/assets/mirror/build-with-sso-enterprise-connections-b0a6a27885b5.webp" alt="Clerk Dashboard со страницей Enterprise SSO connections и действием Add connection." width="1826" height="1080" data-path="images/workspace/auth/build-with-sso-enterprise-connections.webp" />
</Frame>

Подробнее о настройке подключений см. в [документации Clerk](https://clerk.com/docs).

<div id="section-2">
  ### Проверка подключения
</div>

После завершения настройки войдите под тестовой учётной записью вашего провайдера идентификации. Убедитесь, что у этой учётной записи есть доступ к нужным разделам приложения.

Если войти не удалось, обратитесь к Agent. Укажите в запросе провайдера идентификации, протокол и текст ошибки.

<Note>
  На этой странице рассматривается Enterprise SSO для входа в само приложение. О входе через социальные сети — Google, GitHub, Apple и X (в рабочем пространстве отображается как **SSO providers**) — читайте в разделе [Провайдеры входа](/ru/ja/features/auth-and-identity/sign-in-providers). Переход на Replit Auth и вход по SAML в учётную запись Replit на этой странице не рассматриваются.
</Note>

<div id="section-3">
  ## Стоимость и доступные тарифы
</div>

Доступ к Clerk Dashboard доступен на тарифе [Replit Pro](/ru/ja/billing/plans/replit-pro). Тариф Enterprise появится в ближайшее время.

<Info>
  Enterprise SSO-подключения бесплатны до 1 октября 2026 года. После этого стоимость SSO в Clerk будет напрямую включаться в биллинг Replit.
</Info>
