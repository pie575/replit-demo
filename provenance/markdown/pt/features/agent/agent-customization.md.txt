# Personalização do Agent

> Ensine ao Agent as convenções da sua equipe com instruções personalizadas e skills para todo o workspace, gerenciadas centralmente nas Configurações de Workspace.

A Personalização do Agent fornece ao Agent o contexto necessário para trabalhar da forma como você e sua equipe trabalham, desde o primeiro prompt. Em vez de reexplicar suas convenções em cada projeto, você as define uma vez para o seu workspace e o Agent as aplica em todos os lugares.

Ela tem duas partes:

* **Instruções personalizadas**: diretrizes sempre ativas que se aplicam a cada projeto no seu workspace.
* **Skills**: instruções reutilizáveis que o Agent carrega apenas quando uma tarefa relevante surge.

Você gerencia ambas em **Configurações de Workspace → Personalização**.

## Instruções personalizadas vs. skills

As instruções personalizadas são carregadas em cada mensagem; as skills são carregadas apenas quando o Agent decide que uma tarefa é relevante. Use instruções personalizadas para as poucas diretrizes que são sempre verdadeiras, e skills para fluxos de trabalho específicos, convenções e material de referência.

Para o raciocínio por trás dessa divisão — o orçamento de contexto, o que vai para onde e como criar skills adequadas — consulte [Agent skills](/pt/learn/agent-skills). Para como as skills são estruturadas e como o Agent as carrega, consulte [Skills do Agent](/pt/features/agent/skills).

## Instruções personalizadas

As instruções personalizadas são diretrizes sempre ativas injetadas no contexto do Agent em cada projeto e cada sessão, antes que alguém digite um prompt. Escreva-as uma vez nas Configurações de Workspace e o Agent as aplica em todo o seu workspace. São mais adequadas para diretrizes que são sempre verdadeiras, como requisitos de segurança e conformidade, bibliotecas e frameworks aprovados, ou políticas de tratamento de dados.

Mantenha-as curtas. Uma instrução focada e específica tem maior probabilidade de ser seguida rigorosamente e deixa mais espaço para o trabalho que o Agent está realmente fazendo.

<Warning>
  Instruções personalizadas podem impactar o desempenho do Agent. O Agent é orientado a segui-las, mas requisitos estritos não são garantidos. Diretrizes mais curtas e específicas são seguidas de forma mais confiável.
</Warning>

<Note>
  As instruções personalizadas do workspace são diferentes do arquivo `custom_instruction/instructions.md` de um projeto. A instrução personalizada do workspace é definida uma vez nas Configurações de Workspace e se aplica a cada projeto. O arquivo por projeto fica dentro de um único projeto — consulte [Criar um sistema de design personalizado](/pt/teams/custom-design-system) para esse padrão.
</Note>

## Skills

Uma skill é um conjunto reutilizável de instruções que o Agent carrega apenas quando uma tarefa relevante surge. As skills de workspace aparecem no topo do menu **+** em cada projeto do seu workspace, para que toda a sua equipe compartilhe o mesmo conjunto.

Você pode criar uma skill de três maneiras:

* **Carregar** uma pasta de skill existente.
* **Escrever** uma nova skill diretamente no formulário.
* **Pedir ao Agent** para rascunhar uma skill para você e, em seguida, refiná-la.

<Note>
  Você pode carregar Skills rascunhadas pelo Agent para o seu Workspace. Peça ao Agent para baixar a skill. O Agent irá empacotar a skill como um arquivo `.zip` para download com um botão **Baixar arquivo** (mostrado abaixo). Baixe o zip e, em seguida, faça o upload de volta em **Configurações de Workspace → Personalização → Skills** via **Criar skill → Escolher arquivo ou pasta**, para que seja compartilhada em todo o seu workspace.
</Note>

Para a estrutura completa de skills (`SKILL.md`, arquivos de suporte, o padrão aberto), consulte [Skills do Agent](/pt/features/agent/skills). Para explorar skills que o Replit e nossos parceiros já criaram, consulte o [Diretório de skills](/pt/features/agent/skills-directory).

<Note>
  Use skills com moderação. O Agent lê o nome e a descrição de cada skill em cada tarefa, e muitas (ou skills sobrepostas) diluem seu foco e podem dificultar a escolha da skill correta. Mantenha cada skill com escopo restrito e remova as que não precisar mais.
</Note>

## Disponibilidade e permissões

| Funcionalidade            | Disponível em         | Quem pode gerenciar                                                   |
| ------------------------- | --------------------- | --------------------------------------------------------------------- |
| Instruções personalizadas | Pro e Enterprise      | Enterprise: administradores. Pro: qualquer membro do workspace        |
| Skills                    | Todos os planos pagos | Enterprise: administradores. Core e Pro: qualquer membro do workspace |

Em workspaces Enterprise, apenas administradores podem criar, editar ou excluir instruções personalizadas e skills. Em workspaces Pro, qualquer membro do workspace pode. Em workspaces Core, qualquer membro pode gerenciar skills — as instruções personalizadas não estão disponíveis no Core. De qualquer forma, todo membro do workspace pode usar as skills criadas.

## Criar uma instrução personalizada

<Steps>
  <Step title="Abrir as Configurações de Workspace">
    Acesse **Configurações de Workspace → Personalização**.

    <Frame>
      <img src="https://mintcdn.com/replit/JdEkwxWZoS1i7-FA/images/replitai/agent-customization-tab.png?fit=max&auto=format&n=JdEkwxWZoS1i7-FA&q=85&s=db78105289bbe9001ef972a785499db2" alt="A aba Personalização nas Configurações de Workspace, mostrando as sub-abas Skills e Instruções personalizadas" width="1065" height="394" data-path="images/replitai/agent-customization-tab.png" />
    </Frame>
  </Step>

  <Step title="Escreva sua instrução">
    Na seção **Instruções personalizadas**, escreva as diretrizes que você quer que o Agent aplique em cada projeto.
  </Step>

  <Step title="Salvar">
    Salve suas alterações. A instrução se aplica aos novos projetos no seu workspace.
  </Step>
</Steps>

## Criar uma skill

<Steps>
  <Step title="Abrir as Configurações de Workspace">
    Acesse **Configurações de Workspace → Personalização**.
  </Step>

  <Step title="Criar a skill">
    Na seção **Skills**, clique em **Criar skill** e, em seguida, carregue uma pasta de skill, escreva as instruções ou peça ao Agent para rascunhar uma.

    <Frame>
      <img src="https://mintcdn.com/replit/JdEkwxWZoS1i7-FA/images/replitai/agent-customization-create-skill.png?fit=max&auto=format&n=JdEkwxWZoS1i7-FA&q=85&s=9437a71d20c1fa676722d798624caac8" alt="A aba Personalização nas Configurações de Workspace, com as sub-abas Skills e Instruções personalizadas e o formulário Criar uma skill aberto" width="2168" height="1350" data-path="images/replitai/agent-customization-create-skill.png" />
    </Frame>
  </Step>

  <Step title="Escreva uma descrição clara">
    Dê à skill uma descrição precisa que indique quando usá-la — e quando não usar. É isso que o Agent lê para decidir se a skill se aplica.
  </Step>

  <Step title="Salvar">
    Salve a skill. Ela fica disponível no menu **+** de cada projeto no seu workspace.
  </Step>
</Steps>

## Usar uma skill de workspace em um projeto

Uma boa descrição de Skill é importante. O Agent lê a descrição de cada skill de workspace e a carrega automaticamente quando seu prompt corresponde aproximadamente à finalidade da skill, então você nem sempre precisa escolher uma skill manualmente. Você também pode selecionar uma skill explicitamente quando quiser garantir que ela seja aplicada.

Para selecionar uma manualmente:

<Steps>
  <Step title="Abrir o seletor de skills">
    Em um projeto, clique no botão **+** ao lado da entrada de chat. Suas skills de workspace aparecem no topo, agrupadas.

    <Frame>
      <img src="https://mintcdn.com/replit/JdEkwxWZoS1i7-FA/images/replitai/agent-customization-skill-picker.png?fit=max&auto=format&n=JdEkwxWZoS1i7-FA&q=85&s=7b1ffab08e0bcc9e60313820781a7350" alt="O seletor de skills aberto pelo botão +, mostrando o grupo de skills de workspace no topo acima das skills do Replit" width="1668" height="1170" data-path="images/replitai/agent-customization-skill-picker.png" />
    </Frame>
  </Step>

  <Step title="Selecionar uma skill">
    Escolha a skill que você deseja ativar. Você também pode digitar `/` seguido do nome da skill para invocá-la diretamente.
  </Step>

  <Step title="Continue com os prompts">
    Continue normalmente. O Agent usa a skill quando a tarefa corresponde à sua descrição.
  </Step>
</Steps>

## Gerenciar instruções e skills

Todo o gerenciamento acontece em **Configurações de Workspace → Personalização**. A partir daí, você pode editar uma instrução personalizada e editar, desativar ou excluir qualquer skill. As alterações se aplicam a chats futuros, não aos que já estão em andamento.
