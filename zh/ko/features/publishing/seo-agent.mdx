SEO Agent 会对整个项目进行技术 SEO 审核，找出影响搜索引擎和 AI 爬虫发现并理解应用的问题。每项发现的问题都附带可借助 Agent 审查并应用的一键修复。

此功能位于 Project Editor 的 **Growth** 面板中，适用于已发布的应用。对大多数构建者而言，工作流如下：发布应用，打开 SEO Agent，运行扫描，审查发现的问题，然后应用修复。

<div id="seo-agent">
  ## SEO Agent 的作用
</div>

SEO Agent 专注于**技术 SEO**，即影响搜索引擎和 AI 爬虫能否轻松发现、索引和理解应用的结构化、机器可读部分。

它会审查项目，并针对以下问题提出修复建议：

* **可抓取性与索引**：`robots.txt`、`sitemap.xml`，以及可抓取的链接和页面结构。
* **页面元数据**：每个页面的唯一且具有描述性的 `<title>` 标签和 meta description。
* **结构化数据**：帮助搜索引擎展示富媒体搜索结果的 JSON-LD 标记。
* **Open Graph 和社交标签**：用于控制分享链接时预览显示方式的元数据。
* **语义化标记**：正确的标题层级、地标元素，以及图片的描述性 `alt` 文本。

<Note>
  SEO Agent 可确保您构建的应用在搜索方面具备扎实的技术基础，
  但不会为您撰写内容或建立主题权威性。
</Note>

<div id="section">
  ## 开始之前
</div>

要使用 SEO Agent，您需要满足以下条件：

* **已发布的应用。** SEO Agent 会审核实际公开的 Web 部署，因此如果您尚未发布应用，请先将其发布。有关支持 SEO 的部署类型，请参阅 [SEO 评级](/zh/ko/features/publishing/seo-rating)。
* **付费套餐。** 使用付费套餐的构建者可以使用 SEO Agent。如果您使用的是免费套餐，Growth 面板中会显示升级选项。

您可通过两种方式访问 SEO Agent：直接在 Project Editor 中打开 **Growth** 面板，或在 **Publishing** 工具中选择 SEO 评级 旁的 **Optimize SEO with Agent**，这会打开已准备好进行扫描的 Growth 面板。

<div id="seo-agent-seo-rating">
  ## SEO Agent 和 SEO 评级
</div>

SEO Agent 旁显示的 **SEO 评级**来自每次发布后运行的自动 [Lighthouse 审核](/zh/ko/features/publishing/seo-rating)，它会将应用评为 Healthy、Needs Work 或 Weak。该评级反映了&#95;应用当前的状态&#95;。
SEO Agent 会扫描问题并应用修复，帮助你&#95;提升评级&#95;。修复后重新发布，评级会随之更新。

你也可以完全跳过扫描界面，直接向 Agent 提出请求。
