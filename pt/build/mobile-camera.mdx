Adiciona um botão no perfil do jogador que abre a câmera ou a biblioteca de fotos, o que ele
preferir.

No iOS, o prompt do sistema aparece uma vez. Se recusado, o PixelGames só pode perguntar de
novo enviando o jogador a **Configurações → PixelGames → Câmera**. No Android, a caixa de
diálogo de permissão de runtime pode reaparecer na próxima tentativa, até o jogador marcar
"Não perguntar novamente".
