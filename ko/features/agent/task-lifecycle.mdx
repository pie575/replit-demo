## Draft

\*\*Draft(초안)\*\*는 Agent가 계획했지만 아직 빌드를 시작하지 않은 작업입니다. 초안에는 제안된 작업 내용만 담겨 있어 안전하게 검토할 수 있습니다: 작업 제목, 설명, 계획.

Agent가 목표를 제대로 이해했는지 판단하려면 Drafts를 사용하세요. 작업을 시작하거나, Agent에게 계획 수정을 요청하거나, 나중을 위해 초안을 보관할 수 있습니다.

## Active

**Active(활성)** 작업은 백그라운드에서 실행 중입니다. Agent는 프로젝트의 격리된 복사본에서 작업하므로, 작업이 실행되는 동안 메인 버전은 변경되지 않습니다.

Active 작업이 실행되는 동안에도 메인 스레드를 계속 사용할 수 있습니다. 작업에 피드백이 필요하다면 해당 스레드를 열고 대화를 이어가세요.

## Queued

**Queued(대기 중)** 작업은 승인되었지만 시작을 기다리고 있습니다. 다른 작업에 의존하거나 플랜의 활성 백그라운드 작업 한도에 도달했을 때 작업이 대기열에 들어갈 수 있습니다.

대기 중인 작업은 전제 조건이 완료되고 활성 작업 슬롯이 열리면 자동으로 시작됩니다.

## Ready

**Ready(준비)** 작업은 완료되었지만, 그 변경 사항이 아직 메인 버전에는 적용되지 않은 상태입니다. 변경 사항을 적용하기 전에 작업 로그, 테스트 결과, 프리뷰를 검토하세요.

작업 결과가 만족스럽다면 메인에 적용하세요. 원하는 것이 아니라면 삭제하고 새 작업을 시작하세요.

## Applying

**Applying(적용 중)** 작업은 변경 사항을 메인 버전으로 옮기는 과정에 있습니다. 여러 작업의 변경 사항을 적용할 때 Agent가 충돌을 자동으로 처리합니다.

최종 결과를 판단하기 전에 적용이 끝날 때까지 기다리세요. 이후에 뭔가 이상해 보이면 메인 스레드에서 Agent에게 수정을 요청하세요.

## Done

**Done(완료)** 작업은 끝났으며 더 이상 조치가 필요하지 않습니다. Done은 작업이 메인 버전에 적용되었거나, 시작 전에 보관되었거나, 빌드로 넘어간 후 취소되었음을 의미할 수 있습니다.

완료, 보관, 취소된 작업의 기록으로 **Done** 열을 사용하세요.

## 작업 보관 및 취소

생명주기의 어느 지점에서든 작업을 멈출 수 있지만, 표시되는 옵션은 작업이 보드에서 어디에 있는지에 따라 달라집니다. \*\*Archive(보관)\*\*와 **Cancel(취소)** 모두 작업을 **Done** 열로 옮기지만, 동작 방식은 다릅니다:

| 작업              | 사용 가능한 시점                                                   | 어떤 일이 일어나는지                                                 | 되돌릴 수 있나요?                                         |
| --------------- | ----------------------------------------------------------- | ----------------------------------------------------------- | -------------------------------------------------- |
| **Archive(보관)** | 작업이 아직 계획 세션 상태일 때: 빌드를 시작하지 않은 **Draft**                   | 계획 세션이 실행되지 않고 보류됩니다. 계획은 보존됩니다.                            | 예. **Done** 열에서 보관된 카드를 열고 **Drafts**로 복원할 수 있습니다. |
| **Cancel(취소)**  | 작업이 계획에서 빌드로 넘어간 후: 모든 **Active**, **Queued**, **Ready** 작업 | Agent가 작업을 중지하고 진행 중이던 작업을 폐기합니다. 메인 버전에는 변경 사항이 적용되지 않습니다. | 아니요. 취소된 작업은 복원할 수 없습니다. 다시 작업하고 싶다면 새 작업을 시작하세요.  |

나중에 다시 검토하고 싶은 계획 세션에는 **Archive**를 사용하세요. 대기 중이거나, 이미 실행 중이거나, 빌드가 끝난 작업을 영구적으로 멈추려면 **Cancel**을 사용하세요.

보관된 계획 세션과 취소된 작업 모두 완료된 작업과 함께 Task board 맨 오른쪽의 **Done** 열에서 찾을 수 있습니다.
