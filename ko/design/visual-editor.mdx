<div id="what-is-visual-editor">
  ## Visual Editor란?
</div>

Visual Editor를 사용하면 요소를 직접 클릭해 UI를 바로 수정할 수 있습니다. Replit Design의 [canvas](/ko/design/canvas)와 Preview 양쪽에서 모두 동작하므로 mockup과 실행 중인 애플리케이션을 같은 방식으로 편집할 수 있습니다.

텍스트 변경, 색상 조정, 간격 조절처럼 간단한 편집은 AI credits을 소모하지 않고 소스 코드를 직접 업데이트합니다. 복잡한 처리가 필요한 변경은 Visual Editor가 자동으로 Agent에 넘깁니다.

핵심 개념:

* **결정적 편집**: 간단한 변경(텍스트, 색상, 간격)은 Agent loop 없이 소스 코드에 바로 적용됩니다
* **크레딧 비용 없음**: 직접 편집은 AI credits을 소모하지 않으며, 복잡한 변경만 Agent를 거칩니다
* **이중 context**: canvas 프레임과 Preview에서 동일하게 동작합니다
* **소스 코드 동기화**: 모든 편집이 소스 코드에 즉시 반영됩니다

<Note>
  Visual Editor는 현재 **웹 브라우저**에서만 사용할 수 있습니다. Mobile App이나 Desktop App에서는 지원되지 않습니다.
</Note>

<div id="how-to-use-visual-editor">
  ## Visual Editor 사용 방법
</div>

<div id="editing-on-the-canvas">
  ### Canvas에서 편집하기
</div>

툴바에서 **Edit** 도구를 선택한 다음 프레임 안의 요소를 클릭하세요. 선택한 요소가 강조 표시되면서 요소 이름이 적힌 chip이 함께 나타나고, 오른쪽에 Visual Editor 패널이 열려 콘텐츠, 레이아웃, 색상, 테두리 등 해당 요소에서 편집할 수 있는 속성을 보여줍니다. 속성을 조정한 뒤 **Save edits**를 선택해 적용하거나 **Discard**를 선택해 변경 사항을 버리세요.

<Frame caption="Edit 도구가 활성화된 상태에서 버튼을 선택하면 Visual Editor에 편집 가능한 속성이 표시됩니다.">
  <img src="/assets/mirror/visual-editor-edit-tool-71d03803471f.png" alt="Edit 도구가 활성화되고 요소가 선택된 슈퍼카 구성기 프레임으로, 오른쪽에 Layout(Outer 및 Inner space), Color(Text, Background, Opacity), Border(색상, 너비, 반경) 섹션과 Discard 및 Save edits 버튼이 있는 Visual Editor 패널이 표시됨" width="2000" height="1250" data-path="images/replitai/visual-editor-edit-tool.png" />
</Frame>

표시되는 속성은 선택한 요소에 따라 달라집니다. 텍스트 요소에는 글꼴 컨트롤이, 이미지에는 소스와 업로드가, 컨테이너에는 레이아웃 컨트롤이 표시됩니다.

<div id="editing-in-preview">
  ### Preview에서 편집하기
</div>

실행 중인 애플리케이션에서도 동일한 편집 환경을 사용할 수 있습니다.

<Steps>
  <Step title="요소 선택">
    Preview에서 원하는 요소를 클릭하면 편집을 시작할 수 있습니다.
  </Step>

  <Step title="편집하기">
    텍스트를 인라인으로 수정하고, 피커로 색상을 조정하고, 스타일 컨트롤로 간격을 변경하거나 이미지를 교체하세요.
  </Step>

  <Step title="저장">
    저장을 누르면 소스 코드에 반영됩니다. 간단한 변경 사항은 AI credits 소모 없이 바로 적용됩니다. 편집 내용이 복잡한 경우에는 Visual Editor가 관련 메타데이터를 Agent에 전달해 처리를 요청합니다.
  </Step>
</Steps>

<div id="text-editing">
  ### 텍스트 편집
</div>

텍스트 요소를 클릭한 뒤 입력하면 내용을 바로 변경할 수 있습니다. 해당 텍스트가 소스 코드의 문자열이라면 편집 내용이 즉시 적용됩니다.

<div id="color-adjustments">
  ### 색상 조정
</div>

색상 선택기로 텍스트와 배경 색상을 조정하세요. 입력란에 &quot;purple&quot;처럼 색상 이름을 입력하거나, 스포이드로 화면 어디에서든 원하는 색상을 추출할 수 있습니다.

<div id="style-changes">
  ### 스타일 변경
</div>

직관적인 컨트롤로 여러 요소의 안쪽 여백(padding), 바깥쪽 여백(margin), 레이아웃을 조정합니다.

<div id="layout-controls">
  ### 레이아웃 컨트롤
</div>

Visual Editor는 모든 컨트롤을 **Text**, **Layout**, **Color**, **Border**라는 명확한 섹션으로 나누어 필요한 컨트롤을 더 빠르게 찾을 수 있습니다. (이미지 요소를 선택하면 **Image** 섹션도 함께 표시됩니다.)

**Layout** 섹션에서는 Agent를 거치지 않고도 컨테이너 안에서 하위 요소가 배치되는 방식을 조정할 수 있습니다. 플렉스 컨테이너를 선택한 뒤 Layout을 펼치면 다음 항목이 나타납니다.

* **Alignment**: 컨테이너 내부에서 항목이 두 축을 따라 놓일 위치를 지정하는 3×3 점 선택기입니다.
* **Direction**: 하위 요소를 행 또는 열로 배치하는 두 개의 화살표 버튼입니다.
* **Gap**: 항목 사이 간격을 지정하는 픽셀 값입니다. 간격 입력란 옆의 아이콘은 현재 방향에 맞게 바뀌므로 가로 간격을 조정하는지 세로 간격을 조정하는지 항상 알 수 있습니다. 그 옆의 화살표 아이콘은 **Distribute space between items**를 켜고 끄며, 이 옵션을 켜면 하위 요소가 컨테이너의 양쪽 가장자리로 밀려납니다.
* **Outer space**: 요소 바깥쪽 공간을 각 면별로 설정하는 입력란입니다(면마다 입력란이 하나씩 있으며, 링크 토글로 네 면을 한 번에 고정할 수 있습니다).
* **Inner space**: 요소 내부 공간을 각 축별로 설정하는 입력란이며, 링크 토글로 두 축을 한 번에 조정할 수 있습니다.

Layout 섹션은 선택한 요소에 적용할 수 있는 레이아웃 컨트롤이 하나 이상 있을 때만 나타납니다. 간격이나 레이아웃 속성이 없는 일반 텍스트 노드에서는 이 섹션이 아예 숨겨지므로 편집기가 간결하게 유지됩니다.

<div id="image-updates">
  ### 이미지 업데이트
</div>

이미지를 선택해 URL을 교체하거나 직접 파일을 업로드하고 미리보기로 즉시 확인하세요.

<div id="what-you-can-do">
  ## 할 수 있는 일
</div>

* **빠른 텍스트 수정**: 소스 파일을 열지 않고도 문구, 라벨, 제목을 수정하세요
* **색상 탐색**: 클릭하고 조정하는 것만으로 다양한 색 구성표를 시도해 보세요. 알맞은 CSS를 찾아 헤맬 필요가 없습니다
* **레이아웃 조정**: 픽셀 값을 어림짐작하는 대신 패딩, 여백, 간격을 시각적으로 미세 조정하세요
* **이미지 교체**: 클릭 후 업로드하는 것만으로 자리 표시자 이미지를 실제 에셋으로 바꾸세요
* **디자인 반복**: Agent를 거치지 않고도 Canvas의 프레임을 빠르게 조정해 시각적 방향성을 비교하세요

<div id="frequently-asked-questions">
  ## 자주 묻는 질문
</div>

<Accordion title="Visual Editor 변경에도 AI credits이 소모되나요?">
  텍스트 변경, 색상 선택, 간격 조정처럼 단순하고 결과가 명확한 편집에는 AI credits이 소모되지 않습니다. 이런 편집은 소스 코드를 곧바로 업데이트합니다. 다만 Visual Editor가 겉으로 드러나지 않는 복잡성을 감지하면 해당 변경을 Agent로 넘기며, 이때는 credits이 사용됩니다.
</Accordion>

<Accordion title="여러 곳에 나타나는 요소도 편집할 수 있나요?">
  네. loop 안에서 렌더링되거나 여러 컴포넌트에서 재사용되는 요소를 선택하면 모든 인스턴스가 한 번에 강조 표시되고 함께 업데이트됩니다.
</Accordion>

<Accordion title="일부 요소는 왜 텍스트를 편집할 수 없나요?">
  여러 하위 요소로 이루어진 복합 요소는 Visual Editor에서 텍스트를 직접 편집할 수 없습니다. 이런 경우에는 Chat에서 Agent에게 변경을 요청하세요.
</Accordion>

<Accordion title="요소의 소스 코드는 어떻게 찾나요?">
  선택한 요소의 왼쪽 위에 표시되는 레이블을 클릭하면 소스 코드의 해당 위치로 이동합니다.
</Accordion>
