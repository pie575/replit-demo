ИИ-функции Replit используют биллинг на основе использования: плата зависит от того, что вы создаёте и насколько активно пользуетесь нашими ИИ-инструментами. Так вы платите только за ценность, которую получаете от Agent.

<div id="primeiros-passos">
  ## Начало работы
</div>

**Все подписчики** получают бесплатные разовые чекпоинты Agent.

Дополнительные ежемесячные кредиты автоматически используются для оплаты ИИ:

* **Подписчики Core**: Ежемесячные кредиты (см. [цены](https://replit.com/pricing))
* **Подписчики Pro**: Многоуровневые ежемесячные кредиты с переносом на {ProCreditRolloverPeriod}. См. [Replit Pro](/ru/pt/billing/plans/replit-pro).

Эти кредиты покрывают расходы на Agent и другие облачные сервисы Replit, такие как опубликованные App, хранилище и базы данных. Выберите [Lite, Economy или Power](/ru/pt/features/agent/agent-modes), чтобы оптимизировать Agent по скорости, стоимости или мощности.

  ## Биллинг Agent
</div>

Free Mode предоставляет подписчикам Core и Pro возможность бесплатно выполнять повседневные задачи с Agent в пределах установленного лимита. Стоимость платных режимов и подтверждённой платной работы зависит от сложности запроса и требуемых усилий. Перед началом платного действия Replit запрашивает подтверждение.

<div id="como-funciona-a-precificao-baseada-em-esforo">
  ### Как работает ценообразование на основе затраченных усилий
</div>

Когда вы общаетесь с Agent в «режиме Build», он создаёт **чекпоинты**, в которых фиксируется выполненная по вашему запросу работа:

* **Простые запросы** (например, исправление ошибок или небольшие изменения) обычно стоят меньше, чем сложные Build-задачи
* **Сложные Build-задачи** (например, полноценные функции или интеграции) объединяются в один чекпоинт, стоимость которого может быть выше, чем у простого запроса, и отражает общий объём затраченных усилий
* **Один чекпоинт на запрос** исключает промежуточные чекпоинты и уменьшает путаницу в биллинге
* **Прозрачные цены** точно показывают, за что вы платите по каждой выполненной задаче

<Info>
  Чекпоинт создаётся, когда Agent завершает работу по вашему запросу и реализует запрошенную функциональность в вашем коде.
</Info>

На платном тарифе режим планирования может выполнять оплачиваемые рассуждения, даже если не вносит изменений в код.

Подробнее о том, что фиксируют чекпоинты и как они работают, см. в разделе [Чекпоинты и откаты](/ru/pt/features/version-control/checkpoints-and-rollbacks).

<div id="cobrana-dos-servios-do-agent">
  ### Биллинг сервисов Agent
</div>

Некоторые возможности Agent используют платные сторонние API (например, Claude, ChatGPT и Nano Banana / Gemini). Agent автоматически управляет этими интеграциями — ключи API и настройка не требуются. С ваших кредитов Replit списывается публичная стоимость API, установленная провайдером. Эти расходы отображаются вместе с остальными данными об использовании на [панели использования](/ru/pt/billing/managing-spend).

Чтобы узнать стоимость создания примеров приложений, ознакомьтесь с нашей простой [интерактивной демонстрацией](https://agent-pricing.replit.app/).

<div id="acompanhar-seu-uso">
  ### Отслеживание использования
</div>

Вы можете отслеживать расходы на Agent в реальном времени:

1. **Вкладка Agent**: Наведите указатель на значок использования, чтобы увидеть стоимость отдельных чекпоинтов
2. **Панель использования**: Просматривайте подробную информацию о биллинге за текущий период
3. **Настройки**: Настройте оповещения и бюджеты в разделе **Учётная запись** → **Биллинг**, чтобы контролировать расходы

<Tip>
  Данные об использовании могут появиться на панели использования в течение 30 минут.
</Tip>

<div id="gerenciando-seus-gastos">
  ## Управление расходами
</div>

Контролируйте расходы на ИИ с помощью встроенных инструментов Replit для управления бюджетом:

* **Оповещения об использовании**: Получайте уведомления при достижении лимитов расходов
* **Лимиты бюджета**: Устанавливайте жёсткие лимиты, чтобы избежать неожиданных списаний
* **Отслеживание в реальном времени**: Отслеживайте расходы в процессе работы
* **Пакеты кредитов**: Покупайте дополнительные кредиты со скидкой при крупных покупках. Подробнее см. в разделе [Управление расходами](/ru/pt/billing/managing-spend).

<div id="prximos-passos">
  ## Следующие шаги
</div>

Готовы создавать с ИИ? Вот как максимально эффективно использовать кредиты:

* **Сначала попробуйте Agent**: Используйте бесплатные чекпоинты, чтобы изучить возможности Agent
* **Начните с малого**: Начните с простых запросов, чтобы понять ценообразование на основе затраченных усилий
* **Используйте режим Lite**: Воспользуйтесь [режимом Lite](/ru/pt/features/agent/agent-modes) для быстрых и точечных правок
* **Настройте оповещения**: Настройте уведомления о расходах, прежде чем превысите лимит кредитов

Узнайте больше об [инструментах ИИ Replit](/ru/pt/build/welcome) или ознакомьтесь с нашими [тарифами](https://replit.com/pricing).
