<div id="por-que-isso-importa">
  ## 为什么这很重要
</div>

每部 iPhone 都内置了警告框、分享表、开关和菜单，用户在自己使用的其他 App 中都会接触到它们。当你的 App 使用这些原生组件时，用户甚至在首次点按前就已经知道如何使用它们，这正是让它看起来像真正 iPhone App 的关键。

以下是可添加到 App 中的原生组件提示词示例：警告框、操作表、开关等。

<div id="sf-symbols">
  ## SF Symbols
</div>

<AiPrompt>
  {sfSymbolsPrompt}
</AiPrompt>

SF Symbols 是 Apple 内置的图标集。这些符号会自动适配周围文本的大小、粗细和深色模式，而自定义图标集需要手动实现这些适配。

<Frame caption="SF Symbols 用于“设置”中的音效和振动图标。">
  <img src="/assets/mirror/native-sf-46d879d1c2c1.png" alt="SF Symbols 图标位于“音效”和“振动”设置旁" data-path="images/pixelgames/mobile/native-sf.png" width="1516" height="310" data-path="images/pixelgames/mobile/native-sf.png" />
</Frame>

<Note>
  SF Symbols 仅适用于 iOS。请让 Agent 为 Android 选择等效的图标集；不同平台上的图标不会完全相同，这是预期现象。
</Note>

<div id="soluo-de-problemas">
  ## 故障排除
</div>

* **警告框或操作表显示自定义模态框而非原生界面：**请确认
  Agent 使用的是原生 API，而不是用 JS 渲染的仿制版本；两者看起来可能
  相似，但行为不同。
* **Android 上的图标看起来不对：**这是 SF Symbols 的预期表现，因为它
  仅适用于 iOS。请询问 Agent 使用了哪个替代图标集。
* **共享表中未包含您预期的某个 App：**这由
  操作系统和测试设备上安装的 App 决定，并非
  PixelGames 能够直接添加的内容。
