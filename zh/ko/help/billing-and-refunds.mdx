export const CoreCredits = '$20';

本解答涵盖 Replit 开发者最常见的计费问题。有关按用量计费的详细信息，请参阅[按用量计费](/zh/ko/billing/about-usage-based-billing)和[支出管理](/zh/ko/billing/managing-spend)。

<AccordionGroup>
  <Accordion title="为什么在月度计费周期结束前就被收费？">
    Replit 不仅在周期结束时收费；当超出每月包含积分的用量达到设定金额 (计费阈值) 时，也会收费。Core 套餐每月包含 {CoreCredits} 积分，超出这些积分的 Agent 用量达到阈值后将单独计费。

    要降低未来的费用：

    1. 使用 [Plan 模式](/zh/ko/features/agent/plan-mode)，在 Agent 构建前确定并批准任务范围，避免代价高昂的返工。
    2. 如果你订阅了 Core 或 Pro，请在日常 Agent 任务中使用不收费的 [Free Mode](/zh/ko/features/agent/agent-modes)。额度每 5 小时重置一次，并设有每周上限。要查看用量，请前往 **设置 → 用量**。
    3. 需要更多功能时，请选择价格更实惠的 Power。
    4. 在[管理支出](/zh/ko/billing/managing-spend)中设置用量上限和预算，以限制超出积分后的费用。
    5. 每项新任务都开启新的 Agent 聊天，以保持上下文精简。

    要查看哪些用量产生了费用，请打开 **设置 → 账户用量**，然后选择 **查看之前的账单**。
  </Accordion>

  <Accordion title="我通过 App Store 或 Google Play 订阅，但无法添加支付方式，该怎么办？">
    如果您通过 App Store 或 Google Play 订阅，Apple 或 Google 会处理付款，因此移动 App 中不会显示付款选项。请在网页端管理付款：

    1. 打开浏览器，前往**设置 → 账单**。
    2. 选择**更新付款方式**。
    3. 输入银行卡信息并保存。

    添加网页付款方式后，您可以在**账单**标签页中管理账单并购买积分包。有关积分包的更多信息，请参阅[管理支出](/zh/ko/billing/managing-spend)。
  </Accordion>

  <Accordion title="订阅后 30 天内可以退款吗？">
    退款资格因套餐和申请退款的项目而异。请注意以下事项：

    * Agent 及 AI 使用费用是针对已消耗算力收取的费用，因此不予退款。
    * [自定义域名注册费用不予退款](/zh/ko/build/domain-purchasing)。

    如需申请订阅费退款，请使用注册邮箱[联系 Replit 支持团队](https://replit.com/support)，并说明申请原因。请先在**设置 → 账单**中取消订阅。

    <Note>具体的订阅退款期限和资格，将由支持团队根据您的账户和套餐进行确认。</Note>
  </Accordion>

  <Accordion title="如果意外产生了 Agent 或 AI 使用费用，可以退款吗？">
    Agent 及 AI 使用费不予退款，因为这些费用对应 Replit 为执行任务已经消耗的计算资源。请通过以下方式避免今后出现意外账单：

    1. 打开**设置 → 账户使用量**，设置使用量上限和预算。请参阅[管理支出](/zh/ko/billing/managing-spend)。
    2. Free Mode 已包含在 Core 和 Pro 订阅中。如需在配额内免费完成日常 Agent 任务，请使用 [Free Mode](/zh/ko/features/agent/agent-modes)；如需更强的能力，可选择价格合理的 Power。
    3. 使用 [Plan 模式](/zh/ko/features/agent/plan-mode)，在 Agent 开始构建前先界定任务范围，减少返工。

    如果你认为存在错误扣费，请收集扣费金额、日期和支付意图 ID。该 ID 以 `pi_` 开头，显示在账单详情页面上。然后[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="取消订阅后仍被收费，这正常吗？">
    取消后仍被扣费通常有以下两种原因：

    * 取消前的使用量在取消日之后才达到计费阈值。
    * 对上一计费周期中此前失败付款的重试。

    如需确认，请打开 **设置 → 账户使用量**，选择 **查看以往账单**，核对账单日期及其对应的使用周期。如果仍有异常，请附上 `pi_` 开头的付款意图 ID 并[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="我已订阅，为什么还要额外支付存储费用？">
    当已存储的数据超出套餐包含的额度时，就会产生存储费用。存储的计量方式请参阅[基于用量的计费](/zh/ko/billing/about-usage-based-billing)，对象存储的费用请参阅[对象存储计费](/zh/ko/billing/object-storage-billing)。

    若要查看空间具体用在了哪里，请打开项目的 Shell 并运行以下命令：

    ```bash theme={null}
    du -sh *
    du -ah | sort -rh | head -20
    ```

    然后，删除构建工件 (`.cache` 或 `dist`) 、旧日志和不再使用的已上传文件，并清除数据库中的旧数据。释放空间后，便不会再产生额外的存储费用。
  </Accordion>

  <Accordion title="如何申请自定义域名注册退款？">
    [自定义域名注册费用不可退款](/zh/ko/build/domain-purchasing)，因为域名注册会产生一经处理便无法取消的第三方费用。

    如果您误注册了域名或希望转移域名，请[联系 Replit 支持团队](https://replit.com/support)，并提供域名和与账户关联的电子邮箱。我们的团队将为您说明可行方案。
  </Accordion>

  <Accordion title="我已支付账单，但账户仍处于暂停状态。何时会解除？">
    账单冻结在付款确认后可能需要一段时间才会解除。请尝试以下步骤：

    1. 强制刷新浏览器：Mac 使用 `Cmd+Shift+R`，Windows 使用 `Ctrl+Shift+R`。
    2. 退出登录后重新登录，以刷新账户状态。
    3. 打开 **设置 → 账户用量**，选择 **查看历史账单**，确认账单是否显示为已支付。

    即使冻结解除，部署也不会自动重新启动。如果应用仍处于离线状态，请打开 **发布** 并选择 **发布**，将其重新推送上线。若账户仍处于停用状态，请[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="我在 Replit 上发现了一笔不明扣费，怎么办？">
    在向银行提出异议前，请先核对账单明细：

    1. 打开 **设置 → 账户用量**，选择 **查看历史账单**，核对日期、金额和说明。
    2. 确认是否有他人能够访问你的账户或付款方式。
    3. 查看账单日期前后收到的 Replit 账单电子邮件，包括垃圾邮件文件夹。

    账单通常是订阅费、达到计费阈值的使用费，或购买积分包的费用。

    <Warning>在向银行提出异议*之前*，请先联系 Replit 支持团队。拒付可能会导致你的账户被锁定。</Warning>

    请提供 `pi_` 付款意图 ID、账单金额和日期，并[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="付款被拒绝了。这是 Replit 的问题吗？">
    大多数扣款失败来自银行或发卡机构，而非 Replit，通常是针对陌生交易的自动安全拦截。请按以下顺序尝试：

    1. 在 **设置 → 账单 → 更新支付方式** 中添加另一张银行卡并重试。
    2. 致电银行，说明您正在向 Replit 付款，并请求授权。
    3. 如果您的银行卡有境外支付限制，请联系银行开通。

    如果仍然扣款失败，请[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="我被扣了两次相同的金额，这是重复扣费吗？">
    金额相同的两笔扣费不一定就是重复扣费。常见原因包括：

    * 金额相同的订阅费和积分包被分别列为两个条目。
    * 之前失败的付款经重试后扣款成功。
    * 确实发生了重复扣费 (较为少见) 。

    打开 **设置 → 账户使用量**，选择 **查看过往账单**，比较两笔扣费的付款意图 ID (`pi_`) 。如果 ID 不同，说明是两笔独立的交易。如果两笔扣费都显示为针对同一账单的同一条目付款，请[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="我通过 App Store 付款后，额度仍未到账，该怎么办？">
    App Store 付款可能需要一些时间才能同步到 Replit。请先尝试以下操作：

    1. 强制关闭 Replit 应用，然后重新打开。
    2. 退出登录 Replit 账户，然后重新登录。
    3. 打开**设置 → 账户用量**，查看积分是否已经到账。

    请勿重复购买。如果积分仍未出现，请在 App Store 的**购买记录**中找到 Replit 交易并记下交易 ID，然后[联系 Replit 支持团队](https://replit.com/support)，我们会为你补上积分。
  </Accordion>
</AccordionGroup>
