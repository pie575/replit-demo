Replit Agent peut se connecter à des centaines d’outils externes et de sources de données via le [Model Context Protocol (MCP)](https://modelcontextprotocol.io), une norme ouverte pour l’intégration d’outils d’IA. Connectez-vous à un serveur préconfiguré ou ajoutez n’importe quel serveur MCP personnalisé auquel vous faites confiance.

<div id="conectar-um-servidor-mcp-pr-listado">
  ## Connecter un serveur MCP préconfiguré
</div>

Replit propose une sélection de serveurs MCP pour des services populaires tels que Stripe, Linear, Notion, Sentry et bien d’autres. Connectez-vous en un seul clic.

<Frame>
  <img src="/assets/mirror/mcp-servers-pane-8e1f431ca33c.png" alt="Panneau des paramètres des serveurs MCP pour Replit Agent affichant des serveurs préconfigurés, dont Stripe, Linear, Notion, Sentry, Atlassian, Miro, PostHog, Amplitude, Mixpanel, Granola et Razorpay, chacun avec un bouton Se connecter" width="3452" height="1988" data-path="images/replitai/mcp-servers-pane.png" />
</Frame>

<Steps>
  <Step title="Ouvrir le panneau Intégrations">
    Accédez à [replit.com/integrations](https://replit.com/integrations) et faites défiler la page jusqu’à **Serveurs MCP pour Replit Agent**.
  </Step>

  <Step title="Choisir un serveur">
    Sélectionnez le service que vous souhaitez connecter : Stripe, Linear, Notion, Sentry, Atlassian, Miro, PostHog, Amplitude, Mixpanel, Granola, Razorpay et bien d’autres.
  </Step>

  <Step title="Se connecter">
    Cliquez sur **Se connecter** à côté du serveur. Vous serez guidé dans le flux OAuth de ce service. Une fois connecté, le statut de connexion du serveur est mis à jour et Agent peut utiliser ses outils.
  </Step>
</Steps>

Pour consulter le catalogue complet, reportez-vous à la [référence des serveurs MCP](/fr/pt/features/mcp/overview).

<div id="adicionar-um-servidor-mcp-personalizado">
  ## Ajouter un serveur MCP personnalisé
</div>

Si le serveur que vous souhaitez utiliser ne figure pas dans le catalogue préconfiguré, ajoutez-le à l’aide de son URL.

<Frame>
  <img src="/assets/mirror/mcp-connect-dialog-5b8f9b0d828e.png" alt="Boîte de dialogue Connecter un serveur MCP affichant un champ Nom d’affichage, un champ URL du serveur MCP et une section Paramètres avancés extensible" width="3452" height="1988" data-path="images/replitai/mcp-connect-dialog.png" />
</Frame>

<Steps>
  <Step title="Ouvrir la boîte de dialogue d’ajout de serveur">
    Dans le panneau des paramètres des serveurs MCP, cliquez sur **+ Ajouter un serveur MCP**.
  </Step>

  <Step title="Définir un nom d’affichage">
    Saisissez un nom facilement reconnaissable : Agent l’utilise pour référencer le serveur dans les logs du chat.
  </Step>

  <Step title="Saisir l’URL du serveur">
    Collez le point de terminaison HTTPS du serveur MCP. Ouvrez les **Paramètres avancés** pour ajouter des en-têtes personnalisés (par exemple, `X-API-Key`) si le serveur nécessite une authentification.
  </Step>

  <Step title="Tester et enregistrer">
    Cliquez sur **Tester et enregistrer**. Replit tente de se connecter et vous guide dans tout flux OAuth requis par le serveur. Une fois enregistrée, la connexion apparaît dans Serveurs MCP avec son statut.
  </Step>
</Steps>

<Warning>
  Connectez-vous uniquement à des serveurs MCP auxquels vous faites confiance. Un serveur connecté peut fournir des outils et des données à Agent : vérifiez la source avant d’ajouter un point de terminaison inconnu.
</Warning>

<div id="usar-ferramentas-mcp-no-agent">
  ## Utiliser des outils MCP dans Agent
</div>

Une fois un serveur connecté, Agent récupère automatiquement sa liste d’outils et met ses fonctionnalités à disposition dans tous vos projets. Pour utiliser un serveur, il suffit de le mentionner dans le Chat :

> Utilisez le serveur MCP de Notion pour trouver les notes de réunion les plus récentes.

<Frame>
  <img src="/assets/mirror/tool-call-7a53f51a11ae.png" alt="Agent appelant des outils d’un serveur MCP personnalisé dans le Chat" width="571" height="817" data-path="images/replitai/custom-mcp/tool-call.png" />
</Frame>

Agent choisit les outils appropriés du serveur en fonction de votre demande. Si un outil nécessite une confirmation, une invite s’affiche avant son exécution.
