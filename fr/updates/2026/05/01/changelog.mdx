<div id="replit-app-monitoring-keeps-an-eye-on-your-published-apps">
  ### Replit App Monitoring surveille vos applications publiées
</div>

Vous pouvez désormais activer la **surveillance des applications** pour toute Replit App publiée afin d’obtenir une vérification de l’uptime en temps réel, une barre d’uptime colorée dans la vue **Publishing** et l’onglet **Analytics**, ainsi qu’un e-mail lorsque votre application tombe en panne. La surveillance des applications est disponible avec tous les forfaits payants et fonctionne avec tous les types de déploiement, à l’exception des Scheduled Deployments. Si votre application rencontre un problème, sélectionnez **Investigate recent downtime with Agent** pour lancer une tâche en arrière-plan qui récupère les périodes concernées, examine les logs et le code, puis propose un correctif.

<div id="agent">
  ## Agent
</div>

<div id="create-full-slide-decks-with-agent">
  ### Créez des Slide Decks complets avec Agent
</div>

Décrivez la présentation que vous souhaitez, qu’il s’agisse d’un pitch deck, d’une présentation produit, d’un support commercial ou d’un point d’avancement pour votre équipe, et Agent crée un deck soigné avec mises en page, texte et visuels. Vous pouvez affiner les diapositives dans le Chat, modifier le texte et le style avec Visual Editor, présenter depuis le navigateur, publier le deck via une URL publique ou l’exporter au format PPTX, Google Slides ou PDF.
