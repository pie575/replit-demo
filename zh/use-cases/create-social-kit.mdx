根据你的网站和 Google Drive 中的品牌文件，为 X、LinkedIn、Instagram、Facebook、TikTok 以及你指定的其他平台生成头像图标和封面横幅。Agent 会按各平台当前的尺寸规范和安全区域来处理，确保人脸、徽标和文字在实际主页上不会被裁掉。保持统一的视觉体系，并导出为 PNG 格式。如果某个平台需要不同的裁切比例，请单独新建一个专用画板，不要拉伸图像。

<div id="before-you-start">
  ## 开始之前
</div>

准备好网站 URL，并在 Drive 中放好 徽标 (或品牌素材文件夹) 。说明你需要哪些社交平台。如果
徽标 是文字标，请说明图标应为图形标、字母标，还是两者兼具。

<AiPrompt>

</AiPrompt>

<div id="what-to-expect">
  ## 预期效果
</div>

Agent 会读取网站和 Drive 中的 素材，然后为每个 素材 生成一块尺寸正确的画板。常见的一套包括：

* **X：** 400×400 头像，1500×500 头图
* **LinkedIn：** 400×400 头像，1584×396 横幅
* **Instagram：** 320×320 头像 (如需帖子和快拍封面，另加 1080×1080 和 1080×1920)
* **Facebook：** 320×320 头像，820×312 封面 (或 2× 的 1640×624)
* **TikTok：** 200×200 头像，1080×1920 封面

上传前，请分别在圆形头像和宽幅横幅上检查裁切效果。导出一个图标和一个横幅，放到圆形头像和宽幅头图上试试，并确认小尺寸下的留白是否合适。

<div id="troubleshooting">
  ## 故障排除
</div>

* **徽标或人脸被裁切：**在圆形头像和宽幅横幅中检查每项素材。让 Agent 注意安全区域，并针对不同的裁切比例制作专用画板。请勿拉伸。
* **尺寸不符合平台要求：**说明你需要的平台，并让 Agent 使用各平台当前的官方尺寸。上传前再次核对；平台的尺寸要求可能会变更。
