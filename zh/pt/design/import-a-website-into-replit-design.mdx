⏰ *预计用时：10 分钟*

有时，你想以之为起点的设计已经上线：可能是你当前的网站，也可能是你想复刻其外观的页面。Import from URL 会将网站还原为一个设计 frame，你可以对其进行探索、优化，并将其转变为交互式 App。

你将以 [creative-studio-landing.replit.app](https://creative-studio-landing.replit.app) 为示例，它是 Replit 为一家创意工作室打造的落地页。

<div id="antes-de-comear">
  ## 开始前
</div>

你需要：

* 一个 [Replit 账户](https://replit.com)。
* 一个公开网站的网址，或使用上面的示例。

<div id="importe-o-website">
  ## 导入网站
</div>

<Steps>
  <Step title="复制网站 URL">
    使用你自己的网站，或复制以下示例：`https://creative-studio-landing.replit.app`。

    <Frame caption="示例网站：Kosmo Studio 创意工作室的落地页。">
      <img src="/assets/mirror/url-example-site-e0ad60629981.webp" alt="Kosmo Studio 的落地页，标题为 We craft bold ideas and visuals that truly work，下方展示了一组艺术卡片" width="3440" height="2160" data-path="images/design/import-from-url/url-example-site.webp" />
    </Frame>
  </Step>

  <Step title="打开 Replit Design">
    前往 [replit.com/design](https://replit.com/design)，然后选择 prompt 输入框下方的 **Import URL**。Agent 会重现该网站的外观和风格，作为起点。

    <Frame caption="Replit Design 首页上的 Import URL：粘贴任意网站的链接。">
      <img src="/assets/mirror/design-import-url-07a8ac52e188.webp" alt="Replit Design 首页，已选中 Import URL 选项，工具提示显示 Paste a link to any website and Agent will recreate its look and feel as a starting point" width="2293" height="1322" data-path="images/design/import-from-url/design-import-url.webp" />
    </Frame>
  </Step>

  <Step title="粘贴 URL 并开始构建">
    选择 **Import URL** 后，prompt 会自动预填：*&quot;Recreate the look and feel of this website:&quot;*。在后面粘贴你的 URL，然后选择 **Start**。

    <Frame caption="已预填示例 URL 的重现 prompt，可以开始了。">
      <img src="/assets/mirror/design-url-prompt-b6196aac1b17.webp" alt="Replit Design 的 prompt 输入框显示 Recreate the look and feel of this website，后接示例 URL，并带有 Start 按钮" width="2293" height="1322" data-path="images/design/import-from-url/design-url-prompt.webp" />
    </Frame>
  </Step>
</Steps>

Agent 会将网站重现为你项目中的设计 frame。

<Frame caption="在 Replit Design 中，重现后的 Kosmo Studio 落地页作为设计 frame 显示。">
  <img src="/assets/mirror/url-import-result-7a4114a468f3.webp" alt="在 Replit Design 中，重现后的 Kosmo Studio 落地页作为设计 frame 显示，Chat 面板中的执行状态标记为已完成" width="1600" height="1004" data-path="images/design/import-from-url/url-import-result.webp" />
</Frame>

<div id="deixe-do-seu-jeito">
  ## 打造你的专属设计
</div>

选择导入的 frame，开始按你的想法调整：

* **参考[建议](/zh/pt/design/explore-suggestions)**：导入内容会附带推荐的后续步骤，例如深色杂志风版本、移动端视口或联系页。每项建议都会生成一个新的 frame，因此可以保留原始版本进行比较。
* **[和 Chat 聊聊](/zh/pt/design/chat-about-your-design)**：使用 frame 下方的输入框，用自己的话描述你的需求，例如 *“替换作品集照片”*、*“让首屏主视觉的字体更粗一些”*。
