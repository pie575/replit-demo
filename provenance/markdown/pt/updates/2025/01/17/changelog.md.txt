## Atualizações da plataforma

### Integração com SendGrid

Agora você pode criar integrações de e-mail com o Agent. Isso permite que você envie e-mails dos seus novos projetos Agent usando a API do SendGrid.

### Suporte móvel para visualização web

Adicionamos a capacidade de escalar a visualização web para tamanhos de tela móveis comuns. Além disso, adicionamos um QR code no menu suspenso de URL e no painel de rede para facilitar os testes em dispositivos móveis.

Como lembrete — mesmo enquanto você está criando seu projeto, ele é acessível pela internet. Basta visitar a URL de desenvolvimento em qualquer dispositivo.

### Atualização de formato de registro DNS

Modificamos como os registros DNS de domínio personalizado são formatados para corresponder aos padrões do setor.

Isso deve facilitar a configuração de domínios personalizados.

### Atualização de deployment Flask

O gunicorn agora é o servidor web padrão para deployments com stack Flask.

Isso resultou em uma melhoria de desempenho de 40x em relação aos deployments Flask anteriores.

### Comandos shell inline do Assistant

O Assistant agora pode executar comandos shell diretamente no painel de chat. Economize tempo executando comandos sem sair do chat!
