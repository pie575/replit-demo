---
title: "Activer le widget de feedback"
description: "Découvrez comment recueillir les retours des visiteurs de votre app publiée."
---

La collecte de feedback peut être activée sur vos apps publiées afin de recueillir des informations directement auprès des visiteurs et de les transmettre à Agent. Lorsque le feedback est activé, les visiteurs peuvent envoyer des retours, y compris des captures d&#39;écran et des fichiers, que vous pouvez gérer depuis votre boîte de réception.

<div id="ativar-o-feedback">
  ## Activer les retours
</div>

<Warning>
  Vous pouvez activer les retours uniquement sur les apps web. Cette option n&#39;est pas disponible pour les autres types d&#39;apps, comme les automatisations ou les apps mobiles.
</Warning>

Lors de la publication d&#39;une nouvelle app, activez le bouton **Enable Feedback** dans la boîte de dialogue de publication. Si votre app est déjà publiée, vous pouvez activer les retours en la republiant :

1. Ouvrez l&#39;outil Publishing
2. Sélectionnez **Advanced Settings**
3. Activez le bouton **Enable Feedback**
4. Republiez votre app

<div id="enviar-feedback">
  ## Envoyer un commentaire
</div>

Lorsque les commentaires sont activés sur une app publiée, les visiteurs peuvent en envoyer directement depuis l&#39;app. Les utilisateurs peuvent :

* Se connecter pour laisser un commentaire
* Rédiger un commentaire décrivant leur expérience ou leurs suggestions
* Sélectionner des éléments pour illustrer des problèmes ou des fonctionnalités
* Téléverser des fichiers pour fournir un contexte supplémentaire

<div id="gerenciar-feedback-na-sua-caixa-de-entrada">
  ## Gérer les retours dans votre boîte de réception
</div>

Tous les retours envoyés par les visiteurs apparaissent dans votre boîte de réception, accessible depuis le Project Editor. Dans la boîte de réception, vous pouvez :

* **Add to Chat** : envoyer le retour dans votre Chat avec Agent afin d&#39;ajouter du contexte avant de l&#39;envoyer
* **Send to Agent** : transmettre immédiatement le retour à Agent pour lancer le travail sans attendre
* **Resolve** : marquer le retour comme résolu une fois celui-ci traité
* **Delete** : supprimer les retours qui ne sont plus nécessaires

Vous pouvez également utiliser des filtres pour organiser et retrouver des retours précis.

<div id="republicar-com-configuraes-de-feedback-atualizadas">
  ## Republier avec des paramètres de feedback mis à jour
</div>

Une fois votre app publiée, vous pouvez activer ou désactiver le widget de feedback à tout moment en la republiant avec les paramètres mis à jour :

1. Ouvrez l&#39;onglet **Overview** dans l&#39;outil Publishing
2. Sélectionnez **Advanced Settings**
3. Activez ou désactivez **Enable Feedback**
4. Republiez votre app pour appliquer les modifications

Toute modification du paramètre de feedback prend effet après la republication de l&#39;app.
