此功能可通过访问网络上的最新信息，突破知识局限。当你让 Agent 创建需要最新信息的内容时，它会搜索网络并获取详细资料，让你的应用更准确、更实用。

网页搜索可帮助你查找最新的包、工具和信息，确保你的应用采用当前最佳实践，并更加准确。

<div id="recursos">
  ## 功能
</div>

借助 Agent 的网页搜索功能，使用最新信息创建 App，无需手动研究和收集数据。无论是创建包含金融数据的仪表板，还是构建展示最新初创公司的站点，网页搜索都能确保你的 App 贴近现实。

Agent 可以执行以下网页搜索操作：

* **搜索**：从互联网查找最新信息、文档和实时数据
* **内容搜索**：从特定网站和 URL 获取详细信息
* **来源引用**：准确查看 Agent 获取信息的来源，方便你验证和引用这些来源

<div id="uso">
  ## 使用方法
</div>

网页搜索已集成到 Agent 中，无需额外启用。描述您想创建的内容，Agent 会自动判断何时需要联网搜索以获取最新信息。在 prompt 中加入“搜索”“调查”或“使用网页搜索”等关键词，即可明确指示 Agent 进行搜索。

<div id="citaes-de-fontes">
  ### 来源引用
</div>

当 Agent 使用网页搜索时，会提供**来源引用**，清楚标明信息的具体出处。您可以使用这些引用来：

* **核实信息**：检查来源的可靠性和准确性
* **了解更多**：访问原始来源以获取更多背景信息
* **引用来源**：在您的应用中注明适当的来源归属
* **追踪研究过程**：了解哪些信息为 Agent 的工作提供了依据

<div id="busca-de-contedo">
  ### 内容搜索
</div>

Agent 可以搜索特定网站上的详细内容，为您的项目收集全面的信息。这让 Agent 能够：

* 阅读完整页面，提取相关详细信息
* 处理文档和参考资料
* 从可信来源收集特定数据点
* 将结构化信息整合到您的应用中
