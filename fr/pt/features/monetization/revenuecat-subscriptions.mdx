<div id="o-que-o-revenuecat">
  ## Qu&#39;est-ce que RevenueCat
</div>

RevenueCat vous permet d&#39;ajouter des abonnements in-app à votre [application mobile native](/fr/pt/features/artifact-types/building-mobile-apps). Pour commencer, demandez à Agent de configurer un abonnement, puis connectez votre compte RevenueCat : Agent se charge de la logique et vous fournit un environnement de test.

<div id="pr-requisitos">
  ## Prérequis
</div>

Avant de commencer, vous devez disposer de :

* Un projet Replit créé avec une **application mobile**
* Un compte [RevenueCat](https://www.revenuecat.com) (une adresse e-mail et un mot de passe suffisent — aucun compte bancaire ni configuration supplémentaire n&#39;est requis)

<Note>
  Pour travailler sur une application mobile native, utilisez le Project Editor sur [replit.com](https://replit.com). Le travail sur les applications mobiles natives est également possible dans l&#39;application Replit pour Android, là où cette fonctionnalité est prise en charge. Si vous utilisez l&#39;application Replit pour iOS, ouvrez le projet sur replit.com.
</Note>

</div>

<Steps>

  <Step title="Connectez votre compte RevenueCat">

      <img src="/assets/mirror/revenuecat-connect-modal-34362346bf1d.png" alt="Fenêtre modale Connect RevenueCat affichant les informations de confidentialité et de sécurité" width="1957" height="1133" data-path="images/replitai/revenuecat-connect-modal.png" />

  </Step>

<div id="teste-as-assinaturas">
  ## Testez les abonnements
</div>

Les aperçus Replit utilisent le **mode test** de RevenueCat. Lorsque vous testez un achat dans Expo Go, une boîte de dialogue d&#39;achat de test s&#39;affiche au lieu d&#39;un véritable flux de paiement. Aucun montant n&#39;est débité.

<Frame>
  <img src="/assets/mirror/revenuecat-test-purchase-8414145a112e.png" alt="Boîte de dialogue d'achat de test sur un appareil mobile affichant les détails du package et les boutons de test" width="683" height="1253" data-path="images/replitai/revenuecat-test-purchase.png" />
</Frame>

<Tip>
  Les achats de test peuvent être utilisés en toute sécurité pendant le développement. Vous pouvez tester aussi bien les flux d&#39;achat réussis que ceux qui échouent, sans aucun débit réel.
</Tip>

<Warning>
  Une fois qu&#39;Apple a approuvé votre app pour la distribution sur l&#39;App Store, les achats sont effectués avec de l&#39;argent réel.
  Assurez-vous que vos produits et vos tarifs dans RevenueCat sont corrects avant de soumettre votre app à
  l&#39;App Review.
</Warning>

<div id="gerencie-assinaturas">
  ## Gérer les abonnements
</div>

Pour modifier votre abonnement, demandez-le à Agent. Par exemple :

<AiPrompt>Modifie l&#39;abonnement pour qu&#39;il soit à 9,99 $/an à la place</AiPrompt>

Agent met à jour la configuration de votre produit dans RevenueCat, l&#39;interface du paywall et la logique d&#39;abonnement afin de refléter ce changement.

<div id="sincronizao-com-o-app-store-connect">
  ## Synchronisation avec App Store Connect
</div>

Pour que les achats intégrés fonctionnent dans TestFlight et sur l&#39;Apple App Store, [vous devrez accepter
le Paid Apps Agreement d&#39;Apple et connecter votre compte bancaire](https://developer.apple.com/help/app-store-connect/manage-agreements/sign-and-update-agreements/).
Cela se fait via App Store Connect. Un compte Apple Developer payant est nécessaire avant de pouvoir soumettre votre app à l&#39;App Store.

Vous pouvez ensuite synchroniser vos paramètres d&#39;achats intégrés RevenueCat vers App Store Connect directement depuis Replit.

<Steps>
  <Step title="Accédez au panneau Manage dans Publishing">
    Un bouton permet de synchroniser RevenueCat avec App Store Connect.

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-sync-btn-46a2e4e696df.png" alt="Bouton Sync RevenueCat to App Store Connect" width="1476" height="604" data-path="images/replitai/revenuecat-asc-sync-btn.png" />
    </Frame>

    <Tip>
      Cette section n&#39;apparaît qu&#39;une fois votre app envoyée sur TestFlight.
    </Tip>
  </Step>

  <Step title="Fournissez la clé d'API App Store Connect">
    Vous devrez vous rendre sur App Store Connect pour obtenir cette clé.

    Dans [App Store Connect](https://appstoreconnect.apple.com/access/integrations/api), accédez à **Users and Access**, puis sélectionnez l&#39;onglet **Integrations**. Dans la barre latérale, sélectionnez **App Store Connect API**.

    Lors de la création de la clé, veillez à lui accorder les autorisations « App Manager ».

    Téléchargez le fichier .p8 immédiatement — il n&#39;est téléchargeable qu&#39;une seule fois. Le nom du fichier commence par `AuthKey_` et se termine par `.p8`.

    Copiez le **Key ID** et l&#39;**Issuer ID** affichés sur cette page.

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-create-c54be8304d7c.png" alt="Page Users and Access d'App Store Connect avec des étapes numérotées mettant en évidence l'onglet Integrations, le lien App Store Connect API dans la barre latérale et le bouton plus pour créer une nouvelle clé d'API" width="2390" height="752" data-path="images/replitai/revenuecat-asc-create.png" />
    </Frame>

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-app-manager-93996acd8561.png" alt="Boîte de dialogue Generate API Key dans App Store Connect avec le nom défini sur RevenueCat et l'accès défini sur App Manager" width="1116" height="560" data-path="images/replitai/revenuecat-asc-app-manager.png" />
    </Frame>

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-copy-07a95e1be9af.png" alt="Page des clés d'API d'App Store Connect avec des flèches pointant vers le lien Copy de l'Issuer ID et vers la colonne Key ID" width="2330" height="780" data-path="images/replitai/revenuecat-asc-copy.png" />
    </Frame>
  </Step>

  <Step title="Créez une clé d'API In-App Purchase">
    Répétez l&#39;étape précédente pour une clé d&#39;API In-App Purchase.
    Dans la barre latérale, sélectionnez **In-App Purchase**. Créez ensuite une clé d&#39;API avec les autorisations **App Manager**.
    Téléchargez la clé .p8 (le nom du fichier commence par `SubscriptionKey_` et se termine par `.p8`). Copiez le **Key ID** et l&#39;**Issuer ID**.

    <Frame>
      <img src="/assets/mirror/revenuecat-iap-api-key-7eb34e815ccb.png" alt="Page Users and Access d'App Store Connect avec In-App Purchase sélectionné dans la barre latérale et une flèche pointant vers le bouton plus pour créer une nouvelle clé" width="2272" height="637" data-path="images/replitai/revenuecat-iap-api-key.png" />
    </Frame>
  </Step>

  <Step title="Synchronisez les produits">
    Confirmez la liste des produits et synchronisez-la avec App Store Connect.

    <Frame>
      <img src="/assets/mirror/revenuecat-asc-products-sync-078d42af83ba.png" alt="Boîte de dialogue Manage in-app purchases affichant un produit Monthly Subscription avec les champs prix, durée et territoire, ainsi qu'un bouton Sync to App Store Connect" width="948" height="476" data-path="images/replitai/revenuecat-asc-products-sync.png" />
    </Frame>
  </Step>
</Steps>

<div id="perguntas-frequentes">
  ## Questions fréquentes
</div>

<AccordionGroup>
  <Accordion title="Ai-je besoin d'un compte bancaire pour utiliser RevenueCat ?">
    Non. Une adresse e-mail et un mot de passe suffisent pour créer un compte RevenueCat. La configuration du
    compte bancaire se fait séparément auprès d&#39;Apple ou de Google, lorsque vous êtes
    prêt à recevoir des paiements de l&#39;App Store ou de Google Play.
  </Accordion>

  <Accordion title="Les achats de test sont-ils facturés ?">
    Non. Pendant le développement, les aperçus Replit utilisent le mode test de RevenueCat.
    Les achats sont simulés et aucun débit réel n&#39;est effectué. Les débits réels ne
    s&#39;appliquent qu&#39;une fois votre app approuvée par l&#39;App Review d&#39;Apple.
  </Accordion>

  <Accordion title="Puis-je utiliser RevenueCat avec une app web ?">
    RevenueCat est conçu pour les apps mobiles natives. Pour ajouter des abonnements à une app
    web, utilisez plutôt l&#39;[intégration avec Stripe](/fr/pt/features/monetization/stripe-payments).
  </Accordion>

  <Accordion title="Que puis-je configurer avec RevenueCat ?">
    Vous pouvez mettre en place des abonnements mensuels ou annuels, définir les tarifs, gérer les
    entitlements et créer des paywalls. Demandez les modifications à Agent : il s&#39;occupe aussi bien
    de la configuration de RevenueCat que du code de votre app.
  </Accordion>
</AccordionGroup>
