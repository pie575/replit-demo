<div id="autonomy-level-control-for-agent">
  ### Agent 자율성 수준 제어
</div>

새로운 자율성 수준(Autonomy Level) 설정으로 Agent가 project에서 얼마나 독립적으로 작업할지 직접 정할 수 있습니다. Low(task list 실행만), Medium(코드 리뷰 추가), High(전체 앱 리뷰), Max(완전 자율 계획) 중에서 선택해 워크플로 방식과 project 요구 사항에 맞춰 보세요.

  ### 악성 파일 탐지

<div id="supply-chain-attack-blocking">
  ### 공급망 공격 차단
</div>

강화된 보안 기능이 침해된 npm packages의 데이터 유출 시도를 자동으로 차단합니다. workflow를 방해하지 않으면서 개발 중 민감한 정보를 안전하게 보호합니다.

<div id="email-copying-from-members-page">
  ### 구성원 페이지에서 이메일 복사

<div id="mobile-connectors-support">
  ### 모바일 connector 지원
</div>

Agent 3와 함께 Connectors가 출시되면서 GitHub, Notion 등 서드파티 서비스에 연결할 수 있게 되었습니다.

이제 모바일에서도 완벽하게 지원되어 이동 중에도 앱에 Connectors를 추가할 수 있습니다.

Connectors에 대한 자세한 내용은 [여기](/ko/replitai/integrations)를 참고하세요.

<div id="soc-2-pentest-completion">
  ### SOC 2 모의 침투 테스트 완료
</div>

Replit이 연례 SOC 2 모의 침투 테스트를 우수한 결과로 완료했습니다. 전년 대비 향상된 보안 태세를 확인했으며, 고객의 코드와 데이터에 엔터프라이즈급 보호를 지속적으로 제공하고 있음을 입증했습니다.

<div id="faster-user-deletion-in-clui">
  ### CLUI에서 더 빨라진 사용자 삭제
</div>

컴플라이언스 요구에 맞춰 계정 관리를 간소화했습니다. 이제 내부 도구에서 데이터 삭제 요청을 더 빠르게 처리할 수 있어 Replit이 개인정보 보호 요건에 신속하게 대응할 수 있습니다.
