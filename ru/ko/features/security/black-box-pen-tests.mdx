Пентест методом чёрного ящика проверяет работающее App извне — через браузер и сеть. Исходный код App не используется.

В Project Security Center **Level 3 (AI pentest)** объединяет три типа проверок безопасности.

1. Бесплатная проверка зависимостей и пакетов
2. Статический анализ исходного кода с помощью Agent
3. Внешнее тестирование опубликованного Preview методом чёрного ящика без использования исходного кода

При запуске Level 3 Replit одновременно выполняет проверку исходного кода с помощью Agent и внешнее тестирование методом чёрного ящика.

<div id="level-3">
  ## Запуск сканирования Level 3
</div>

<Steps>
  <Step title="Откройте Project">
    Откройте Project, который хотите просканировать.
  </Step>

  <Step title="Откройте Security Center">
    На панели **Tools** проекта выберите **Security Center**.
  </Step>

  <Step title="Запустите сканирование">
    В верхней части Security Center выберите **Run scan**.
  </Step>

  <Step title="Выберите Level 3">
    **Level 3 (AI pentest)**를 선택하세요.

    <Frame caption="Level 3 (AI pentest) дополняет бесплатную проверку зависимостей и пакетов статическим анализом Agent и внешним тестированием опубликованного Preview.">
      <img src="/assets/mirror/level-3-ai-pentest-c223c0099d3f.png" alt="Открыто меню Select scan level в Security and Privacy Center, открытом через панель Tools; выбран Level 3 AI pentest" width="2204" height="1200" data-path="images/project-security-center/level-3-ai-pentest.png" />
    </Frame>
  </Step>

  <Step title="Дождитесь завершения обеих задач">
    Дождитесь завершения проверки исходного кода и тестирования браузера и сети методом чёрного ящика.
  </Step>

  <Step title="Проверьте результаты">
    На панели **Security** просмотрите находки обеих задач. Оцените каждую находку, прежде чем отправлять подтверждённые проблемы в Agent.
  </Step>

  <Step title="Повторно запустите сканирование после исправлений">
    Отправьте подтверждённые находки в Agent. После применения исправлений повторно запустите сканирование Level 3, чтобы проверить результат.
  </Step>
</Steps>

<div id="section">
  ## Два вида проверки
</div>

| Задача                        | Используемые данные                                  | Цель                                                                                          |
| ----------------------------- | ---------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| Проверка исходного кода       | Исходный код приложения                              | Выявление уязвимостей в области безопасности, конфиденциальности и архитектуры в кодовой базе |
| Пентест методом чёрного ящика | Взаимодействие с работающим App через браузер и сеть | Проверка наблюдаемого извне поведения без использования исходного кода                        |

Проверьте оба набора находок. Одна задача не заменяет другую. Проверка исходного кода позволяет выявить небезопасные детали реализации, а тестирование методом чёрного ящика оценивает работающее App извне.
