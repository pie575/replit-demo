---

На вкладке **My Data** можно просматривать и изменять содержимое базы данных. Откройте инструмент **Database**, выберите базу данных, а затем **My Data**. Вы можете работать с данными визуально или выполнять SQL-запросы напрямую.

<Note>
  Чтобы редактировать продакшн-данные, выберите продакшн-базу данных, откройте **My Data**, затем включите **Edit**. Будьте внимательны: это реальные данные вашего App.
</Note>

<div id="section">
  ## Визуальный просмотр и редактирование данных
</div>

Инструмент Database включает <a href="https://orm.drizzle.team/drizzle-studio/overview" target="_blank">Drizzle Studio</a> — средство для визуального просмотра и редактирования данных. Оно помогает избежать синтаксических ошибок и позволяет:

* Фильтровать и сортировать данные, чтобы сосредоточиться на нужной информации
* Экспортировать данные в файл для использования во внешних системах
* Добавлять и редактировать данные в строках
* Создавать схемы, таблицы, представления и enum, а также управлять ими

<div id="sql">
  ## Выполнение SQL-команд
</div>

SQL runner позволяет выполнять SQL-команды в базе данных и просматривать результаты.

<Accordion title="Как открыть SQL runner">
  В инструменте **Database**:

  1. Откройте вкладку **My Data**
  2. <img class="icon-svg" src="/assets/mirror/sql-runner-icon-b25868882922.svg" alt="Иконка SQL runner" width="16" height="16" data-path="images/icons/sql-runner-icon.svg" /> Выберите **SQL runner**
</Accordion>

Чтобы выполнить запрос, введите SQL-инструкцию в текстовое поле и нажмите расположенную рядом кнопку запуска <img class="icon-svg" src="/assets/mirror/sql-play-8ed26b5de7f1.svg" alt="Иконка выполнения SQL" width="18" height="18" data-path="images/icons/sql-play.svg" />.

<Frame>
  <img src="/assets/mirror/sql-runner-run-8ad798a61335.jpg" alt="Снимок экрана SQL runner и кнопки запуска" width="1390" height="608" data-path="images/databases/sql-runner-run.jpg" />
</Frame>

<Tip>
  Вам не нужно писать SQL самостоятельно. Попросите Agent получить или изменить данные — он напишет и выполнит SQL.
</Tip>
