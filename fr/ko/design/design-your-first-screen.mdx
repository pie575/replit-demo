Dans ce démarrage rapide, vous allez générer votre premier frame de design à partir d&#39;un prompt rédigé en langage courant, puis explorer de nouvelles directions en un clic grâce aux suggestions de l&#39;IA. Aucune expérience en design n&#39;est nécessaire : il suffit de choisir ce qui vous plaît pour orienter la suite.

<Steps>
  <Step title="Ouvrir Replit Design">
    Rendez-vous sur [replit.com/design](https://replit.com/design). La zone de prompt, en plein centre, est le point de départ de votre design.

    <Frame>
      <img src="/assets/mirror/design-hero-4a82ee579911.png" alt="Écran d'accueil de Replit Design. Une zone de prompt indiquant « Describe what you want to design » et, en dessous, les options Import URL, Import Figma, Recreate screenshot et Start with a design system" width="889" height="414" data-path="images/design/replit-design/design-hero.png" />
    </Frame>

    <Note>
      Vous êtes déjà dans un espace de travail ? Sélectionnez plutôt **Design** sous le champ de création de l&#39;accueil de l&#39;espace de travail. Le champ bascule en mode design et une puce **Design** apparaît dans la zone de prompt.

      <Frame>
        <img src="/assets/mirror/design-pill-abe180082faa.png" alt="Design sélectionné dans le champ de création de l'accueil de l'espace de travail. Une puce Design est affichée dans la zone de prompt" width="800" height="270" data-path="images/design/replit-design/design-pill.png" />
      </Frame>
    </Note>
  </Step>

  <Step title="Décrire ce que vous voulez concevoir">
    Rédigez votre prompt comme si vous briefiez un ami designer : de quoi il s&#39;agit, à qui cela s&#39;adresse et, si vous en avez une en tête, l&#39;ambiance souhaitée. Par exemple : *« Une landing page pour un service de location de supercars, audacieuse, sombre et cinématographique. »* Puis envoyez.
  </Step>

  <Step title="Regarder Design construire votre écran">
    Agent reprend votre prompt et lance le build, en vous tenant informé de sa progression dans le panneau de chat au fil de son travail.

    <Frame>
      <img src="/assets/mirror/design-building-c2ac529c1cef.png" alt="Sur l'accueil de Replit Design, le panneau de chat traite un prompt pour une application de location de supercars de luxe et indique qu'il génère l'artefact Velocity" width="2000" height="1254" data-path="images/design/replit-design/design-building.png" />
    </Frame>
  </Step>

  <Step title="Examiner votre premier frame">
    Votre design arrive sur le canevas sous forme de frame. Prenez un instant pour l&#39;examiner en taille réelle.

    <Frame>
      <img src="/assets/mirror/first-frames-a61342d3d85d.png" alt="La page de location de supercars Velocity générée, examinée en taille réelle en mode Focus. Un bouton Exit focus est affiché en haut du tableau" width="1600" height="1003" data-path="images/design/replit-design/first-frames.png" />
    </Frame>
  </Step>

  <Step title="Poursuivre la génération avec les suggestions">
    Sélectionnez le frame qui vous plaît le plus. Des suggestions apparaissent pour la suite de votre design. Cliquez sur l&#39;une d&#39;elles pour générer une nouvelle direction dans un nouveau frame, l&#39;original restant intact. Continuez à cliquer jusqu&#39;à obtenir un résultat qui vous convient.

    <Frame>
      <img src="/assets/mirror/suggestions-9811fa570612.png" alt="Le frame Velocity généré, sélectionné sur le canevas. Le panneau de chat indique que l'exécution est terminée et un panneau Suggested next steps s'ouvre à côté du frame" width="1600" height="1003" data-path="images/design/replit-design/suggestions.png" />
    </Frame>
  </Step>
</Steps>
