<div id="section">
  ## Предложения последующих задач
</div>

После выполнения задачи Agent проверяет контекст проекта и предлагает **последующие задачи**, которые вы можете захотеть реализовать дальше. В диалоговом окне **Предложения следующих задач** основная рекомендация отображается прямо в основном потоке, чтобы вы могли продолжить работу, не покидая основной поток.

<Frame>
  <img src="/assets/mirror/follow-up-tasks-dialog-c1660cec2d1d.png" alt="Диалоговое окно предложений следующих задач с последующей задачей, кнопкой «Начать» и ссылкой для просмотра подробностей на доске задач" width="495" height="290" data-path="images/agent/follow-up-tasks-dialog.png" />
</Frame>

Предложения могут включать:

* **Новые функции**: функции, которые естественно дополняют то, что вы только что выпустили
* **Улучшения производительности**: оптимизации, которые Agent заметил во время работы над задачей
* **Улучшения пользовательского опыта**: доработки и улучшения, завершающие функциональность

Выберите **Начать**, чтобы отправить предложение в фоновый режим, или **Просмотреть план**, чтобы сначала ознакомиться с предложенной работой. Чтобы увидеть все предложения, выберите **Подробнее на доске задач**. Предложенные последующие задачи отображаются в столбце **Черновик** в разделе **Предложенные**.

<Frame>
  <img src="/assets/mirror/follow-up-tasks-kanban-21087e0210b6.png" alt="Доска задач с множеством предложений последующих задач в разделе «Предложенные» столбца «Черновик»" width="980" height="627" data-path="images/agent/follow-up-tasks-kanban.png" />
</Frame>

При закрытии диалогового окна **Предложения следующих задач** предложение отменяется. Если предложенный план уже ожидает в основной ветке, Agent не отображает диалоговое окно, поэтому два промпта не конфликтуют.

<div id="section-2">
  ## Управление несколькими предложениями одновременно
</div>

Если в проекте много предложений для последующих задач, откройте доску задач и в столбце **Черновик** нажмите **Редактировать**. В режиме редактирования у каждой предложенной задачи появляется флажок. Выберите нужные задачи и нажмите **Начать** или **Отменить**, чтобы применить это действие ко всем выбранным задачам. Чтобы выйти из режима редактирования, нажмите **Готово**.
