# Agent Geral

> Saiba como o Agent Geral permite trabalhar com qualquer framework, criar qualquer tipo de saída e ler e escrever em serviços conectados.

## O que é o Agent Geral?

O Agent Geral é a forma mais flexível de trabalhar com o Replit Agent. Você não precisa pré-selecionar um tipo de artefato ou se comprometer a construir algo específico. Basta começar a conversar — crie um CSV, gere um PDF, pesquise um tópico ou construa um aplicativo completo quando estiver pronto.

Conceitos-chave:

* **Sem pré-seleção**: Comece a trabalhar sem escolher um tipo de artefato antecipadamente
* **Qualquer saída**: Gere arquivos (CSV, PDF, documentos), faça pesquisas ou construa aplicativos
* **Conectores**: Leia e escreva em serviços externos como BigQuery, Linear, Slack, Notion, Amplitude, Segment, Hex e mais
* **Divulgação progressiva**: Comece com um chat leve e escale para uma construção de aplicativo completo naturalmente

## Como acessar o Agent Geral

Você pode acessar o Agent Geral de várias maneiras:

1. **Selecione "Geral" antes de escrever um prompt** na página inicial do Replit
2. **Abra qualquer projeto existente** e comece a conversar com o Agent diretamente
3. **[Importe](/pt/build/import-from-providers) do GitHub** — Projetos importados do GitHub obtêm automaticamente o Agent Geral

## Como usar o Agent Geral

### Apenas comece a conversar

Abra um projeto e comece a falar. Você não precisa se comprometer a construir nada específico — o Agent trabalha dentro do contexto do seu projeto atual e pode lidar com o que você precisar.

**Exemplos de prompts:**

* "Resuma os pontos-chave deste documento"
* "Crie um CSV das 100 principais empresas por receita"
* "Quais são os meus cinco principais tickets do Linear?"
* "Configure um projeto Vue.js com TypeScript"

O Agent pode trabalhar com arquivos criados durante a sessão, gerar saídas de arquivo único e executar código como parte do seu raciocínio — tudo antes que você decida construir algo.

### Conectando serviços externos

Conecte suas ferramentas para que o Agent possa ler e escrever dados diretamente:

1. Vá para **Conectores** nas configurações do projeto
2. Conecte seus serviços (BigQuery, Linear, Slack, Notion, Amplitude, Segment, Hex e mais)
3. Peça ao Agent para ler ou escrever dados através deles

**Exemplos de prompts com conectores:**

* "Quais são os tickets abertos no Linear?"
* "Resuma as mensagens de hoje do Slack em #engenharia"
* "Obtenha os dados de vendas do mês passado do BigQuery"
* "Mostre-me os próximos eventos do meu calendário"
* "Crie um novo ticket no Linear para o bug de integração"
* "Envie um resumo para #engenharia no Slack"

### Do chat ao aplicativo completo

Quando estiver pronto para construir, diga isso. O Agent faz a transição do chat leve para a construção do seu aplicativo de forma fluida — sem necessidade de recomeçar ou mudar de contexto.

* "Transforme isso em um aplicativo web"
* "Construa um aplicativo com base nesses dados"
* "Crie um dashboard para essas métricas"
* "Configure uma ferramenta CLI em Rust"

Você pode começar casualmente — pesquisar um tópico, gerar um relatório, explorar alguns dados — e escalar para uma construção de aplicativo completo quando o momento for certo.

## O que você pode construir

* **Trabalho de conhecimento**: Pesquise, resuma e analise sem construir um aplicativo
* **Saídas de arquivo único**: CSVs, PDFs, documentos, exportações de dados e relatórios formatados
* **Aplicativos de dados**: Consulte serviços conectados e visualize resultados em dashboards
* **Qualquer framework ou linguagem**: Angular, Vue, Svelte, Rust, Go, C#, Python tkinter, jogos Godot, ferramentas CLI e mais
* **Aplicativos full-stack**: Quando estiver pronto, construa um aplicativo completo a partir do contexto do seu chat

## O que esperar

O Agent Geral oferece mais poder e flexibilidade, o que vem com alguma variabilidade:

* **Configuração em uma única tentativa**: Às vezes o Agent configura tudo de uma vez
* **Colaboração iterativa**: Configurações complexas podem exigir múltiplas rodadas de refinamento
* **Limitações de tecnologia**: Algumas tecnologias podem não ser totalmente suportadas no ambiente Nix

<Note>
  Ao contrário do Agent padrão com ambientes pré-configurados, o Agent Geral configura seu próprio ambiente e executa comandos com base na sua solicitação. Você pode precisar pedir a ele para configurar a publicação quando estiver pronto para implantar.
</Note>

## Perguntas frequentes

<Accordion title="O agent pode ver meus outros projetos?">
  Não. Cada chat está contido em um único projeto. Você não pode fazer o Projeto A e o Projeto B conversarem entre si.
</Accordion>

<Accordion title="Por que ele ainda não consegue acessar minha ferramenta externa?">
  Você precisa conectar seus serviços primeiro através dos Conectores. Uma vez conectados, o Agent pode ler e escrever neles, mas não tem acesso por padrão.
</Accordion>

<Accordion title="Quais conectores estão disponíveis?">
  Suportados atualmente: BigQuery, Linear, Slack, Notion, Amplitude, Segment, Hex e mais. Conectores adicionais estão sendo adicionados regularmente.
</Accordion>

<Accordion title="Preciso de conectores para usar o Agent Geral?">
  Não. Os Conectores são opcionais. Você pode usar o Agent Geral para trabalho de conhecimento, geração de arquivos e construção de aplicativos sem nenhuma conexão externa.
</Accordion>
