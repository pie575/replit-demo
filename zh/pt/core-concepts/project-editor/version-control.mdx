title: "版本控制"
description: "了解如何使用 Replit 的版本控制工具跟踪代码变更、管理代码历史记录。"
---

Replit 的版本控制让你能够放心地跟踪、管理代码并进行协作。借助原生 Git 集成以及与 GitHub 的连接，你可以：

* 跟踪代码变更，保留开发工作的历史记录
* 与团队成员协作，避免代码冲突和工作丢失
* 在 Replit 与 GitHub 之间导入、修改和推送代码
* 使用分支安全地试验新功能

<div id="o-que-controle-de-verso">
  ## 什么是版本控制？
</div>

版本控制是一套记录文件历次改动的系统，让你日后可以恢复到特定版本。在 Replit 中，版本控制基于 Git 构建——这是业界标准的代码变更追踪工具——并配有友好的可视化界面，无需掌握命令行知识即可使用。

<div id="como-o-controle-de-verso-funciona-no-replit">
  ### 版本控制在 Replit 中的运作方式
</div>

这四种版本控制方式都作用于同一个底层 Git 仓库：

1. **Agent Checkpoints** 会在使用 [Replit Agent](/zh/pt/core-concepts/agent) 构建的过程中，在重要节点自动创建提交。[进一步了解 checkpoint 与回滚](/zh/pt/core-concepts/agent/checkpoints-and-rollbacks)。
2. **Git Pane** 以可视化方式访问完整的 Git 仓库
3. **Git CLI** 通过命令行使用全部 Git 功能
4. **File History** 跟踪单个文件的细粒度更改

选择最适合你需求的方式即可，一切都有 Git 强大的版本控制系统作为支撑。

| 功能              | Agent Checkpoints | Git Commits     | File History |
| --------------- | ----------------- | --------------- | ------------ |
| **创建方式**        | 在逻辑节点自动创建         | 手动或按计划          | 自动           |
| **粒度**          | 功能级别的更改           | 任意规模的更改         | 字符级别的更改      |
| **描述**          | AI 生成的摘要          | 用户编写的提交信息       | 自动时间戳        |
| **回滚**          | 一键恢复              | 需要 Git 知识       | 一键恢复         |
| **Git 能力**      | 完整的 Git 能力        | 完整的 Git 能力      | 无 Git 能力     |
| **与 GitHub 同步** | 完整的 GitHub 同步能力   | 完整的 GitHub 同步能力 | 无 GitHub 同步  |

<div id="primeiros-passos">
  ## 快速上手
</div>

在 Project Editor 中添加 Git 工具，即可为你的 Replit App 启用版本控制：

1. 在 Replit App 中找到 Tools 部分
2. 点击 **+** 号添加新工具
3. 从可用工具列表中选择 **Git**

如需从 GitHub 导入现有项目，请参阅[从 GitHub 导入](/zh/pt/getting-started/quickstarts/import-from-github)。

<div id="controle-de-verso-automtico">
  ### 自动版本控制
</div>

<Accordion title="Agent Checkpoints">
  使用 [Replit Agent](/zh/pt/core-concepts/agent) 进行 AI 辅助开发时自动创建的快照。

  **最适合**：使用 Replit Agent 进行开发

  **主要能力**：

  * 在逻辑里程碑自动创建
  * 一键回滚
  * 功能级快照
  * 进度跟踪
  * 无需任何配置
  * 开发进度可视化时间线

  Agent checkpoint 存储在 Git 中，可通过 Git Pane 或 Git CLI 访问。你还可以使用 History 功能查看所有 checkpoint，它提供：

  * 按时间顺序查看 checkpoint
  * 详细的 checkpoint 描述
  * 直接访问各 checkpoint 的状态
  * 一键回滚到任意 checkpoint
</Accordion>

<Accordion title="File History">
  针对直接在编辑器中所做的更改 (而非通过 Agent 所做的更改) ，按文件进行版本跟踪并自动保存。

  **最适合**：快速恢复文件的最近更改

  **主要能力**：

  * 聚焦单个文件
  * 字符级更改
  * 可视化对比
  * 30 天历史记录
  * 回放功能

  虽然 File History 提供了独立的界面，但底层的更改仍属于 Git 历史的一部分。进一步了解 [File History](/zh/pt/core-concepts/project-editor/version-control/file-history)。
</Accordion>

<div id="interfaces-baseadas-em-git">
  ### 基于 Git 的界面
</div>

<Accordion title="Git Pane">
  用于 Git 操作的可视化界面，无需了解命令行即可使用版本控制。

  **适用场景**：大多数需要集成 GitHub 并采用可视化工作流的项目

  **主要功能**：

  * 仓库级别的跟踪
  * 分支管理
  * 差异查看
  * 一键同步 GitHub
  * 团队协作

  有关 Git Pane 的详细使用说明，请参阅[使用 Git Pane](/zh/pt/core-concepts/project-editor/version-control/git-interface)。
</Accordion>

<Accordion title="Git CLI">
  通过 [Shell](/zh/pt/core-concepts/project-editor/editor-and-tools/shell) 完整访问 Git 命令行，以执行高级操作。

  **适用场景**：需要完整 Git 功能的高级用户

  **主要功能**：

  * 完整的 Git 命令集
  * 高级分支策略
  * 自定义工作流
  * 脚本自动化
  * 完全掌控仓库

  有关常用 Git 命令及其用法，请参阅[使用 Git Pane](/zh/pt/core-concepts/project-editor/version-control/git-interface#using-git-commands-in-shell)。
</Accordion>

<div id="principais-recursos">
  ## 主要功能
</div>

* **可视化 Git 界面**：无需输入 Git 命令即可管理仓库、提交和分支
* **GitHub 集成**：连接 GitHub 仓库，实现备份与协作
* **从 GitHub 导入**：只需几次点击，即可将任意 [GitHub 仓库转换为 Replit App](/zh/pt/getting-started/quickstarts/import-from-github)
* **分支管理**：直接在 Project Editor 中创建、切换和合并分支
* **冲突解决**：借助可视化辅助识别并解决合并冲突

<div id="casos-de-uso">
  ## 使用场景
</div>

**跟踪你的个人项目**

在开发过程中跟踪代码变更，必要时可回退到之前的版本。[Git Pane](/zh/pt/core-concepts/project-editor/version-control/git-interface) 会以可视化方式展示你的变更，让提交重要更新更加轻松。

**与团队协作**

多位开发者可以在同一份代码上协同工作，而不会互相覆盖各自的改动。为新功能创建分支，准备就绪后再合并。了解更多关于[邀请团队成员](/zh/pt/replitai/invite-teammates)的信息。

<div id="checkpoints-do-agent">
  ## Agent checkpoint
</div>

使用 [Replit Agent](/zh/pt/core-concepts/agent) 构建应用时，你可以通过 checkpoint 获得额外一层版本控制。在 AI 辅助开发的关键节点，checkpoint 会自动捕获项目的完整状态——包括项目内容、与 AI 的对话上下文以及已连接的数据库。

<div id="como-os-checkpoints-funcionam">
  ### checkpoint 的工作原理
</div>

Agent 的 checkpoint 相当于 Replit App 完整状态的全面快照：

* **自动创建**：Agent 会在开发过程中的关键节点创建 checkpoint
* **完整状态捕获**：每个 checkpoint 都会保存项目内容、AI 记忆和数据库状态
* **实施计划**：在做出更改之前，Agent 会先给出方案供你审阅
* **复杂任务追踪**：对于较大的任务，可以创建多个 checkpoint

<div id="benefcios-para-o-desenvolvimento-assistido-por-ia">
  ### AI 辅助开发的优势
</div>

Agent 的 checkpoint 在使用 AI 构建时具有独特优势：

* **安全网**：放心大胆地尝试，因为你随时可以将整个开发环境轻松恢复到先前状态
* **进度跟踪**：清楚地看到 Agent 是如何一步步构建你的应用的
* **逻辑里程碑**：checkpoint 代表已完成的功能，而不是随意的保存点
* **即时回滚**：一键返回任意先前状态，包括恢复数据库和 AI 上下文

<Info>
  有关 checkpoint 捕获内容及完整回滚能力的详细信息，请参阅 [Checkpoint 与回滚](/zh/pt/core-concepts/agent/checkpoints-and-rollbacks)。
</Info>

<Tip>
  虽然 Agent 的 checkpoint 在 AI 开发中非常强大，但对于长期的版本跟踪和协作，建议使用 Git 提交，尤其是在使用外部仓库时。
</Tip>
