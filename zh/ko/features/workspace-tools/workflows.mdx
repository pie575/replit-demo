它们是在 Replit 应用中运行的可复用、自定义的步骤序列。它们既可以像运行 `python main.py` 一样简单，也可以像执行包含多个步骤的流程一样复杂。

常见使用场景：

* 并行运行多个服务 (例如：前端 + 后端)
* 按顺序运行文件或命令 (例如：运行 linter → 运行测试，编译 → 运行代码)

要[创建工作流程](#creating-workflows)，请通过工具侧边栏菜单前往 Workflows 窗格，或使用 `Command + K` 搜索 Workflows 窗格。

<div id="section">
  ## 可用任务类型
</div>

目前可使用 3 种任务类型：`执行 Shell 命令`、`安装软件包` 和 `Run Workflow`。

<div id="execute-shell-command">
  ### 执行 Shell 命令
</div>

`Execute Shell Command`会保存 Shell 命令，并在与 Shell 窗口相同的环境中执行。此任务类型可用于执行单个文件等操作，

```text theme={null}
python main.py
```

提供广泛的使用场景，包括执行复杂的已保存数据库查询命令：

```text theme={null}
psql -h 0.0.0.0 -U your_username -d your_database -c "SELECT * FROM your_table;"
```

<div id="install-packages">
  ### 安装软件包
</div>

`安装软件包` 会利用 Replit 内置的依赖管理系统，自动检测项目依赖项并安装所需的软件包。有关 UPM 如何确定要为项目安装哪些软件包的更多信息，请参阅[依赖管理](/zh/ko/features/project-setup/dependency-management#the-universal-package-manager)。

<div id="run-workflow">
  ### 运行 Workflow
</div>

`Run Workflow` 允许您在当前工作流中运行其他工作流。借此，您可以复用和组合工作流，构建更复杂的工作流。

使用场景示例：

<Frame>
  <img src="/assets/mirror/example-run-workflow-62f93cd1bf00.webp" alt="图像" width="720" height="678" data-path="images/workflows/example-run-workflow.webp" />

使用此任务类型在工作流之间创建依赖关系后，编辑某个工作流时，引用它的其他工作流会自动采用最新更改。请注意，深度嵌套的工作流调用存在嵌套深度限制。

<div id="section-2">
  ## 工作流运行模式
</div>

Workflows 提供两种运行模式：顺序执行和并行执行。

<div id="section-3">
  ### 顺序执行
</div>

顺序执行会按照定义的顺序运行各项任务，并在进入下一步前等待每项任务完成。如果工作流中的任何任务失败，序列执行将停止。

此模式适用于定义逻辑上相互关联的命令，例如先从主分支拉取最新变更，再将当前分支变基到主分支上：

<Frame>
  <img src="/assets/mirror/example-sequential-workflow-62ae8a64038f.png" alt="图片" width="721" height="654" data-path="images/workflows/example-sequential-workflow.png" />
</Frame>

<div id="section-4">
  ### 并行运行
</div>

并行运行会同时执行各项任务，使每项任务都能独立于工作流中的其他任务启动和运行。即使某项任务失败，其他任务也会继续运行。

例如，运行需要同时启动前端和后端服务器的全栈项目时，可以使用此模式：

<div id="section-5">
  ## 创建工作流
</div>

点击 `+ New Workflow` 按钮，在 Workflows 窗口中创建工作流。为工作流设置一个描述性名称，选择合适的运行模式，然后开始添加任务。您可以通过拖放按所需顺序重新排列任务。

<div id="run">
  ## 将 Workflows 分配给 Run 按钮
</div>

您还可以将 Workflows 分配给 Run 按钮，以替代默认的运行行为 (请参阅 [Replit App 配置](/zh/ko/features/project-setup/configuration)) 。如需保留 `.replit` 中配置的默认运行命令，请在下拉菜单中选择默认的 “Run Replit App” 选项。

点击 Run 按钮后，将运行您在下拉菜单中选择的 Workflows。要更改通过 Run 按钮运行的 Workflows，请在下拉菜单中点击所需的 Workflows。
