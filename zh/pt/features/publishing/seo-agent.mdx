SEO Agent 会对你的整个 project 进行一次技术性 SEO 审计，找出那些影响搜索引擎和 AI 爬虫发现并理解你的应用的问题。每一项发现都会转化为一键修复，你可以借助 Agent 审阅并应用这些修复。

它位于 Project Editor 的 **Growth** 面板中，适用于已发布的应用。对大多数创作者来说，工作流程是：发布应用，打开 SEO Agent，运行一次检查，审阅发现的问题，然后应用修复。

<div id="o-que-o-seo-agent-faz">
  ## SEO Agent 的作用
</div>

SEO Agent 专注于**技术性 SEO**，即应用中那些结构性、可被机器读取的部分，它们决定了搜索引擎和 AI 爬虫发现、索引并理解你的应用的难易程度。

它会检查你的项目，并针对以下问题提出修复方案：

* **可抓取性与索引**：`robots.txt`、`sitemap.xml`，以及可被抓取的链接与页面结构。
* **页面元数据**：每个页面都有唯一且具描述性的 `<title>` 标签和 meta description。
* **结构化数据**：帮助搜索引擎展示丰富结果的 JSON-LD 标记。
* **Open Graph 与社交标签**：决定你的链接被分享时预览效果的元数据。
* **语义化标记**：正确的标题层级顺序、地标元素，以及图片上具描述性的 `alt` 文本。

<Note>
  SEO Agent 可以确保你构建的应用在搜索方面技术过硬，
  但不会替你撰写内容或建立主题权威度。
</Note>

<div id="antes-de-comear">
  ## 开始之前
</div>

使用 SEO Agent 需要满足以下条件：

* **一个已发布的应用。** SEO Agent 审计的是公开且正在运行的 Web deployment，因此如果你还没有发布应用，请先发布。有关支持 SEO 的 deployment 类型，请参阅 [SEO Rating](/zh/pt/features/publishing/seo-rating)。
* **付费方案。** SEO Agent 仅面向使用付费方案的创作者开放。如果你使用的是免费方案，会在 Growth 面板中看到升级选项。

访问 SEO Agent 有两种方式：直接在 Project Editor 中打开 **Growth** 面板；或者在 **Publishing** 工具中，点击 SEO 评分旁的 **Optimize SEO with Agent**，即可打开 Growth 面板并直接开始检查。

<Tip>
  若要控制应用被分享到社交平台时的预览效果，请连接
  [自定义域名](/zh/pt/build/add-custom-domain)并重新发布。社交预览和链接预览
  使用的是应用的公开生产 URL，因此发布自定义域名
  可确保预览准确无误。
</Tip>

<div id="o-seo-agent-e-sua-classificao-de-seo">
  ## SEO Agent 与你的 SEO评分
</div>

SEO Agent 旁显示的 **SEO评分**来自每次发布后自动运行的 [Lighthouse 审计](/zh/pt/features/publishing/seo-rating)，该审计会将你的应用评定为 Healthy、Needs Work 或 Weak。评级反映的是*你的应用当前的状况*，
而 SEO Agent 则通过发现问题并应用修复来帮助你*改进它*。修复后重新发布，评级即会更新。

你也可以完全跳过检查界面，直接向 Agent 提出请求：

<AiPrompt>
  Audit my site for SEO best practices and apply the fixes. Add a sitemap,
  robots.txt, Open Graph tags, structured data where it makes sense, and make
  sure every page has a unique title and meta description.
</AiPrompt>
