借助 Shopify connector，Agent 可以开通 Shopify 商店、在此基础上构建自定义店面，并管理你的商品和库存——这一切都在一次 Conversation 中完成，无需 API 密钥。只要你提到要销售实体商品，Agent 就会推荐 Shopify，而你只需在正式上线时访问 Shopify。从第一个提示词到收到真实订单，大约只需十分钟。

<Note>
  如需分步指引，请参阅[搭建 Shopify 店面](/zh/build/ecommerce-store)。
</Note>

<div id="what-you-can-build">
  ## 你可以构建什么
</div>

* 为实物商品定制设计的店面
* 品牌周边与服饰商店
* 支持购物车和结账的 DTC (直面消费者) 商店
* 依托 Shopify 商店的商品目录与库存管理工具
* 主推单一爆款的产品落地页

<div id="how-it-works">
  ## 工作原理
</div>

<Steps>
  <Step title="描述你的店铺">
    告诉 Agent 你想卖什么。对于实体商品，即使你没有明确提到，它也会推荐 Shopify。

    <Frame>
      <img src="/assets/mirror/describe-your-store-b5d724daee99.png" alt="Replit 提示框中输入了一个蜡烛店铺的提示" width="1440" height="900" data-path="images/replitai/shopify/describe-your-store.png" />
    </Frame>
  </Step>

  <Step title="Agent 开通店铺">
    系统会在 Replit 的 Shopify 合作伙伴账户下创建一个开发商店 (约十秒钟) ，安装 Replit Sales Channel 应用并完成店铺连接。无需 API 密钥；每个应用对应一个店铺；在你认领之前始终受密码保护。

    <Frame>
      <img src="/assets/mirror/connect-shopify-store-7f36389f976f.png" alt="Replit Agent 移交给 Shopify skill，显示带有 Connect Shopify 按钮的“连接到 Shopify”卡片" width="3452" height="1984" data-path="images/replitai/shopify/connect-shopify-store.png" />
    </Frame>
  </Step>

  <Step title="Agent 负责搭建与管理">
    Agent 会设计无头店面，并维护商品、变体、库存、商品系列和折扣。

    <Frame>
      <img src="/assets/mirror/add-product-8b098e606340.png" alt="店面商品网格，展示带有名称和价格的蜡烛商品" width="3452" height="1978" data-path="images/replitai/shopify/add-product.png" />
    </Frame>
  </Step>

  <Step title="在 Shopify 上线">
    认领店铺、选择套餐、设置支付方式，准备好开卖后即可上线。

    <Frame>
      <img src="/assets/mirror/claim-store-4facb7c8b10c.png" alt="Replit“认领你的店铺”界面，带有“认领店铺”按钮" width="3452" height="1978" data-path="images/replitai/shopify/claim-store.png" />
    </Frame>
  </Step>
</Steps>

<div id="what-agent-manages">
  ## Agent 能管理什么
</div>

店面和商品目录中的所有内容都可以通过 Chat 编辑。

| 区域             | Agent 的作用                                                                                                                                              |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Design         | 根据你的要求生成无头前端 (无需 Liquid 主题，也无需模板库) 。文案、布局、导航、动效和商品页面都可以通过 Chat 编辑，你还可以借助 [Canvas](/zh/design/canvas) 变体探索不同方向。它是一个真正的 Replit project，因此你可以为其扩展博客、心愿单或落地页。 |
| 商品             | 创建、更新和删除商品及其变体。字段包括：标题、描述、类型、供应商、标签、SKU、价格、重量、选项 (尺寸、颜色) 、图片和库存状态。                                                                                     |
| 库存             | 按变体设置和调整库存量。                                                                                                                                           |
| 集合             | 将商品归类到集合中。                                                                                                                                             |
| 折扣             | 创建价格规则以及可兑换的折扣码。                                                                                                                                       |
| Publishing 与同步 | 新商品会自动发布到你的店面。同步是双向的：你在 Shopify 管理后台所做的修改会显示在 Replit 的 Preview 中，Agent 所做的修改也会显示在你的 Shopify 管理后台中。                                                     |

<div id="replit-and-shopify-who-does-what">
  ## Replit 与 Shopify：各自负责什么
</div>

| Replit 负责                  | Shopify 负责          |
| -------------------------- | ------------------- |
| 店面的设计与构建                   | 托管式结账               |
| 通过 Chat 管理商品目录 (商品、库存、折扣)  | 商品、库存、购物车和订单的权威数据源  |
| 店面托管与部署                    | 支付、身份验证 (KYC) 和结算打款 |
| Canvas 设计变体                | 税费、配送与履约            |
| 扩展应用 (博客、落地页等)             | 多渠道销售               |

订单、退款、结算打款和履约均在你的 Shopify 后台中处理，而不是通过 Agent。

<div id="connection-scope">
  ## 连接范围
</div>

* 所有构建者在所有应用中均可使用，在 Conversation 中直接完成连接，无需在 Connectors 面板中进行设置，也无需提供凭据。
* 仅作用于单个应用：每个应用都会获得独立的 Shopify 商店。
* 在你认领之前，该商店是归 Replit 所有的开发商店；你的电子邮件会共享给 Shopify，以便你日后认领。
* 你可以随时在 Shopify 管理后台卸载 Replit 应用。

<div id="go-live-on-shopify">
  ## 在 Shopify 上正式上线
</div>

上线操作在 Shopify 完成，而非 Replit。请让 Agent 启动 Go Live 流程，然后在你的 Shopify 后台完成以下由商家自行操作的步骤：

* **认领店铺**：通过 Chat 中的链接或 Shopify 发送的邮件进行认领。该链接 7 天后失效。认领后即开始免费试用。
* **选择套餐**：处理真实订单需要[付费套餐](https://www.shopify.com/pricing)。
* **设置支付方式**：启用 [Shopify Payments](https://help.shopify.com/en/manual/payments/shopify-payments) 或其他支付服务商，并完成身份验证 (KYC) 。认领账户完成 KYC 后即可正式收款。
* **配置[配送](https://help.shopify.com/en/manual/shipping)与[税费](https://help.shopify.com/en/manual/taxes)。**
* **绑定[自定义域名](/zh/build/add-custom-domain)** (可选) ，并移除店面密码，让买家可以访问店铺。

结账始终会跳转到 Shopify 托管的结账页面，因此买家是在 Shopify 完成付款。

<Note>
  支付、身份验证、税费、配送和欺诈检查均由 Shopify 处理。Replit 绝不会收集商家的银行信息、税号或其他敏感信息。
</Note>

<div id="troubleshooting">
  ## 故障排查
</div>

<AccordionGroup>
  <Accordion title="设置 Shopify 商店耗时较长">
    预配过程会调用多个 Shopify API，需要一些时间。请等 Agent 完成设置后，再让它构建店面。
  </Accordion>

  <Accordion title="开发过程中结账时出现密码页">
    开发商店在正式上线前受密码保护，因此结账预览可能会跳转到密码页。这属于正常现象，购物车仍可正常使用。只有在正式上线时，才需要在 Shopify 中移除密码。
  </Accordion>

  <Accordion title="结账无法完成真实支付">
    要真正收款，认领商店的 Shopify 账户必须完成支付设置和 KYC 认证。在此之前，结账会跳转到 Shopify，但无法完成收款。请完成 KYC 认证，或改用已配置好支付的账户。
  </Accordion>

  <Accordion title="Agent 提示此应用未连接 Shopify">
    每个商店只对应一个应用。如果你是在另一个应用中连接的 Shopify，请让 Agent 为当前应用设置 Shopify 商店。
  </Accordion>

  <Accordion title="商品未显示在店面上">
    商品只有处于启用状态并已发布后才会显示。Agent 会自动发布它创建的商品；如果发现某个商品缺失，请让 Agent 发布该商品，然后刷新预览。
  </Accordion>

  <Accordion title="转移后需要重新连接">
    认领或转移商店后，Shopify 可能会要求你重新授权连接。让 Agent 重新连接 Shopify 即可恢复访问权限，商店数据不会丢失。
  </Accordion>
</AccordionGroup>
