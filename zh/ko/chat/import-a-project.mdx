如果你已经在开发应用或项目，可以将其导入 Replit，并在 Project 中继续开发。导入项目不同于将文件作为 Conversation 的参考资料或上下文附件。

<div id="section">
  ## 选择支持的来源
</div>

来源决定了你需要提供哪些内容，以及现有工作将如何导入 Replit。目前的导入指南涵盖以下途径。

| 现有工作        | 支持的来源                                                                               |
| ----------- | ----------------------------------------------------------------------------------- |
| 代码仓库和构建工具项目 | **GitHub**、**Bitbucket**、**Vercel**、**Bolt**、**Lovable**、**Base44**、**旧版 Agent 导出** |
| 设计          | **Figma** 和 **Claude**                                                              |
| 本地文件和数据     | **ZIP** 和 **电子表格** (`.xlsx`、`.csv` 或公开的 Google Sheets URL)                          |

部分构建工具的导入会使用从原服务导出的 GitHub 代码仓库。导入前，请查看相应来源的指南。设置、密钥、数据库值或提供方专属服务可能需要在之后进行额外配置。

在提示词框中选择 **加号** 菜单，然后选择 **导入现有项目**，即可打开导入流程。

<div id="section-2">
  ## 导入还是附加，该选哪个？
</div>

* 如果要基于现有代码、设计或结构化项目继续构建，请使用 **Import a Project**。
* 如果文档、电子表格、图片或截图能为当前 Conversation 中的问题或任务提供上下文，请使用 **Upload a file**。

有关第二种方式，请参阅[上传和使用文件](/zh/ko/chat/upload-and-use-files)。
