以下解答涵盖项目与文件的相关操作。相关参考请见 [Secrets](/zh/core-concepts/project-editor/app-setup/secrets)、[Checkpoint 与回滚](/zh/features/version-control/checkpoints-and-rollbacks)以及[集成概览](/zh/features/integrations/overview)。

<AccordionGroup>
  <Accordion title="如何将 Resend 或其他电子邮件服务接入我的 Replit App？">
    打开你的 project，前往 **Tools → Connectors**，找到对应服务 (例如 Resend) 并连接。授权完成后，API key 会以密钥形式保存在你的 project 中。如果你要配置自定义邮件域名，请按照该服务提示，在你的 DNS 服务商处添加相应的 DNS 记录。

    可用的 connector 请参阅[集成概览](/zh/features/integrations/overview)，具体操作参阅[添加集成](/zh/build/add-integrations)。
  </Accordion>

  <Accordion title="我不小心删除了一个项目，还能恢复吗？">
    已删除的项目在一段时间内仍可恢复。在任意项目中打开 Shell 并运行：

    ```bash theme={null}
    trash view
    trash restore your-project-name
    ```

    保留期结束后，已删除的项目将被永久移除。如果已超过保留期，请[联系 Replit 支持团队](https://replit.com/support)。
  </Accordion>

  <Accordion title="如何下载或导出 Replit 项目？">
    点击文件树顶部的三点菜单，选择 **Download as zip**。项目较大时，下载可能需要稍等片刻。如果下载失败，请打开 Shell 并运行 `zip -r project.zip .`，然后从文件树中下载 `project.zip`。
  </Accordion>

  <Accordion title="如何共享项目或添加协作者？">
    你有三种选择：

    * **只读**——将 project 的隐私设置为公开，这样任何拥有链接的人都可以查看。
    * **邀请编辑**——选择 **Invite**，输入用户名或邮箱，并设置权限级别。
    * **加入链接**——从 **Invite** 创建加入链接，任何拥有该链接的人都可以加入并编辑。

    Core 最多支持 5 位协作者，Pro 最多支持 15 位；协作者无需付费套餐即可编辑你的 project。参见 [Workspaces](/zh/features/collaboration/workspaces)。
  </Accordion>

  <Accordion title="如何将 GitHub 仓库关联到 Replit？">
    在账户的关联服务中绑定你的 GitHub 账户，然后在 project 中打开 [Git 工具](/zh/features/workspace-tools/git-interface)并连接仓库。在 Git pane 中开启自动同步，即可实现双向同步。若要导入已有仓库，请参阅[从身份提供方导入](/zh/build/import-from-providers)。

    如果 Git 同步失效，请在关联服务中重新连接 GitHub。使用细粒度个人访问 token 可获得更稳定的连接。
  </Accordion>

  <Accordion title="我的 Repl 运行缓慢或编辑器卡顿，该怎么办？">
    如果编辑器出现卡顿，可以尝试以下方法：

    * 使用 `Cmd+Shift+R` (Mac) 或 `Ctrl+Shift+R` (Windows) 强制刷新。
    * 关闭不用的文件标签页。
    * 使用 `Cmd+K` (Mac) 或 `Ctrl+K` (Windows) 打开命令面板，搜索 **Restart compute** 并选择该项。
    * 换用其他浏览器，排除扩展程序的影响。

    如果是代码运行缓慢，而非编辑器卡顿，请检查是否存在开销较大的循环或内存限制。你可以在编辑器底部的资源面板中查看 CPU 和内存用量。
  </Accordion>

  <Accordion title="如何在项目中使用环境变量和 Secrets？">
    打开 **Secrets** 工具 (锁形图标) ，选择 **+ New secret**，然后输入键和值。在代码中使用 `process.env.API_KEY` (Node.js) 或 `os.environ["API_KEY"]` (Python) 读取该值。

    开发环境 [Secrets](/zh/core-concepts/project-editor/app-setup/secrets) 面板中的 Secrets 仅在编辑器中可用。对于已发布的应用，请在 deployment secrets 中添加相同的键——二者在设计上就是相互隔离的。
  </Accordion>

  <Accordion title="如何使用 Account Secrets（保险库）？">
    [Account Secrets](/zh/core-concepts/project-editor/app-setup/secrets) 可在你的所有项目中使用，非常适合需要重复使用的密钥。在账户设置中添加后，它们会在你拥有的每个项目中生效。如果同一个键同时存在于 Account Secrets 和某个项目的 Secrets 面板中，则以项目级的值为准。
  </Accordion>

  <Accordion title="如何解决 Git 合并冲突或损坏的 Git 状态？">
    打开 Shell 并运行 `git status` 查看冲突。

    <Warning>接下来的两条命令会丢弃未提交的更改，且无法撤销。请先保存你想保留的内容——例如，将已编辑的文件复制到 project 之外。</Warning>

    要丢弃本地更改并恢复到上一个干净状态，请运行 `git checkout -- .`；要重置到最近一次提交，请运行 `git reset --hard HEAD`。

    如果 `.git` 文件夹损坏导致 Git 命令无法执行，请新建一个 Agent chat 并粘贴错误信息——Agent 通常能修复该仓库。参见[灾难恢复](/zh/features/version-control/disaster-recovery)。
  </Accordion>

  <Accordion title="如何将我的项目回滚到之前的检查点？">
    Replit 会在 Agent 工作过程中保存 [checkpoint](/zh/features/version-control/checkpoints-and-rollbacks)。在 Agent 面板中，找到你想撤销的改动之前的那条消息，选择消息旁边的回滚选项，然后确认。

    <Note>
      Replit 已不再支持将已发布的应用回滚到早期版本。若要还原已发布的应用，请按上文所述先将项目回滚到较早的 checkpoint，然后再次 Publish，以重新部署该状态。若要恢复单个文件，请打开该文件，选择文件名，并使用 **Show history** 还原到早期版本。参见[文件历史](/zh/features/version-control/file-history)。
    </Note>
  </Accordion>

  <Accordion title="如何将项目转移到其他 Replit 账户？">
    项目无法直接转移，但你可以复制一份。最简单的方式是将项目分享给目标账户，然后在该账户中 fork。也可以将项目下载为 zip 文件，再重新上传到另一个账户下的新 Repl 中。

    复制完成后，需要在新项目中重新配置 Secrets、数据库和部署设置——这些内容不会随副本一起复制。有关分步说明 (包括如何迁移数据库数据) ，请参阅[手动将项目复制到另一个 workspace](/zh/teams/identity-and-access-management/manually-copy-projects)。
  </Accordion>
</AccordionGroup>
