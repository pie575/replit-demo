<div id="categorias-de-cobrana">
  ## 计费类别
</div>

Replit 将 App Storage 的费用分为以下类别：

* **存储**：每月使用的数据存储容量。所有存储对象的最短计费周期为七天。
* **数据传输**：整个月内上传和下载的数据总量。
* **基本操作**：与更新存储桶和对象相关的操作。有关详情，请参阅<a href="https://cloud.google.com/storage/pricing" target="_blank">Google Cloud Storage 定价</a>中的 A 类操作。
* **高级操作**：其他所有云对象存储操作，包括检索对象和存储桶的配置及元数据。有关详情，请参阅<a href="https://cloud.google.com/storage/pricing" target="_blank">Google Cloud Storage 定价</a>中的 B 类操作。
