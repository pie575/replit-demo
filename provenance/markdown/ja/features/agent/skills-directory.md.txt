# Skills directory

> ReplitとパートナーによるSkillsをブラウズし、プロジェクトまたはワークスペースへのインストール方法を学びましょう。

Skills directoryは、すぐにインストールして使用できる既製スキルのカタログです — Replitおよびパートナーによってビルドされています。インストールして試し、チームの実際の作業スタイルに合わせて編集してください。

スキルとは何か、Agentがどのように読み込むかについては [Agent Skills](/ja/features/agent/skills) を参照してください。スキルをワークスペース全体で利用可能にするには [Agent カスタマイズ](/ja/features/agent/agent-customization) を参照してください。

## スキルをインストールする

directoryからスキルを追加するにはいくつかの方法があります：

* **チャット内** — チャット入力欄の隣の **+** ボタンをクリックし、**Use a skill** を選択して選びます。スキルはそのメッセージのみに適用され、プロジェクトには何もインストールされません。
* **プロジェクト内** — Project EditorのSkillsペインを開き、**Discover** タブを選択し、スキルを見つけて **Install** をクリックします。インストールされたスキルはプロジェクトの `/.agents/skills` ディレクトリに存在し、チャット間で保持されます。
* **コマンドラインから** — [skills CLI](https://github.com/vercel-labs/skills) でスキルをインストールします：

  ```bash theme={null}
  npx skills <skill> -a replit
  ```

<Warning>
  Replitのスキルピッカー内のスキルは安全性について審査されています。外部ソースからインストールされたスキルは審査されていません。スキルはAgentが従うインストラクションであるため、外部スキルは常にインストール前にレビューしてください — 確認すべき点については [Agent スキル](/ja/learn/agent-skills) を参照してください。
</Warning>

## Replitスキル

Replitにはチャットの **Use a skill** ピッカーと新規プロジェクトの開始点ピッカーから利用できる事前定義スキルが用意されています。これらはインストールなしにすべてのプロジェクトで動作します。ピッカーを開くとインライン説明が表示されます。

| カテゴリ              | スキル                                                                                                      |
| ----------------- | -------------------------------------------------------------------------------------------------------- |
| 販売 & マーケティング      | Ad Creative、AI SDR、SEO Auditor、Programmatic SEO、GEO、Content Machine、Storyboard                           |
| キャリア              | AI Recruiter、Resume Maker、Interview Prep                                                                 |
| リサーチ & 分析         | Competitive Analysis、Deep Research、GitHub Solution Finder、Supplier Research                              |
| ビジネス & 財務         | Stock Analyzer、Excel Generator、Invoice Generator、Tax Reviewer                                            |
| ドキュメント & ツール      | Website Cloner、File Converter、Flashcard Generator、Legal Contract、Infographic Builder、Recreate Screenshot |
| クリエイティブ           | Photo Editor、Podcast Generator、Podcast Marketing、Branding Generator、Video Editing                        |
| 生産性               | AI Secretary、Product Manager、Design Thinker、Skill Finder、Skill Creator                                   |
| 個人                | Travel Assistant                                                                                         |
| セキュリティ & コンプライアンス | Secrets、Sensitive Data、Input Validation、AI Security、Dependency Vetting、License Check                     |
| 品質 & 信頼性          | Accessibility、Responsive UI、Observability、Resilience、Ship Review                                         |

<Note>
  ワークスペース内では、ピッカーはプロジェクトの `.local/secondary_skills/` ディレクトリにインストールされた追加スキルも検出します。
</Note>

## パートナースキル

Replitのパートナーは、Agentに自社製品でのビルド方法を教えるスキルを公開しています。インストールすると、そのサービスのパターンとルールをAgentに提供できます。

| パートナー            | Agentに教えること                         |
| ---------------- | ----------------------------------- |
| Stripe           | 決済と請求のインテグレーションパターン                 |
| PayPal           | 決済インテグレーションパターン                     |
| RevenueCat       | サブスクリプションとアプリ内購入のパターン               |
| Mixpanel         | アナリティクスとトラッキングの実装                   |
| BigQuery         | データウェアハウスのクエリパターン                   |
| Resend           | トランザクションメールのインテグレーション               |
| Google Workspace | Gmail、Drive、Docs、Calendarのインテグレーション |
| Atlassian        | JiraとConfluenceのイシューとページワークフロー      |
| Google Maps      | マップ、場所、ルート、ジオコーディングのインテグレーション       |

## コミュニティスキル

Replitとパートナーのスキルのほかにも、コミュニティが公開するスキルをインストールできます。[skills.sh](https://skills.sh) でブラウズし、自分で書く場合は [Agent Skills specification](https://agentskills.io/specification) を参照してください。
