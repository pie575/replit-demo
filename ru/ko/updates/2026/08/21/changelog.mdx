<div id="free-mode">
  ### Работа в Free Mode
</div>

Free Mode позволяет общаться в чате, прорабатывать идеи, создавать и собирать приложения, не тратя кредиты Power Mode или Max Mode. В Free Mode модель выбирается автоматически через Auto, а лимиты зависят от тарифа. Чтобы посмотреть остаток лимита и время его сброса, откройте **Settings** &gt; **Usage**.

</Frame>

Узнайте, [как получить максимум от Free Mode](/ru/ko/chat/free-mode).

  ### Начало работы с Conversation
</div>

<div id="routine">
  ### Автоматизация повторяющихся задач с помощью Routine
</div>

Настройте расписание, по которому Replit будет повторять задачи внутри Conversation. Каждый результат возвращается в ту же Conversation, где вы можете его просмотреть и продолжить работу. Routine выполняется в режиме Power Mode или Max Mode, и на каждый запуск требуется бюджет.

Подробнее о [Routines](/ru/ko/chat/routines).

<div id="agent-2">
  ### Корректировка работы Agent на ходу
</div>

Пока Agent работает, отправляйте дополнительные сообщения, чтобы добавить новый контекст в текущий ход. Steer — поведение по умолчанию для Conversation и Project, а переключить каждую из этих настроек на Queue можно в разделе **Settings** &gt; **Personalization**. Чтобы применить противоположное поведение только к одному сообщению, нажмите `Cmd+Enter` на Mac или `Ctrl+Enter` в Windows и Linux.

<Frame caption="Выберите Steer или Queue отдельно для Conversation и Project.">
  <img src="/assets/mirror/agent-follow-ups-settings-98a4c5ca399e.png" alt="Настройки Agent с поведением отправки для Conversation и Project и вариантами Steer и Queue" width="3048" height="1372" data-path="images/replitai/agent-follow-ups-settings.png" />
</Frame>

Подробнее о том, как [корректировать или ставить в очередь дополнительные сообщения](/ru/ko/features/agent/steer-and-queue-messages).

<div id="github-skill">
  ### Импорт навыков из GitHub
</div>

Вы можете импортировать навык по URL публичного репозитория GitHub, папки или файла, а затем просмотреть файлы навыка перед добавлением. Сохранённые навыки Project также поддерживают уровни доступа участников **Required**, **Available** и **No access**.

<div id="workspace-agent">
  ### Управление моделями Agent во всех Workspace
</div>

Администраторы аккаунтов Enterprise могут задать политики аккаунта для каждого поставщика моделей, а затем выбрать модели, доступные в отдельных Workspace. Выберите **Enable all**, **Enable selected** или **Disabled** — в зависимости от политик вашей организации.

<div id="section-4">
  ### Запуск тестирования на проникновение методом чёрного ящика
</div>

Запустите сканирование безопасности Level 3, объединяющее три проверки: бесплатную проверку зависимостей и пакетов, статический анализ исходного кода с помощью Agent и внешнее тестирование работающего Preview методом чёрного ящика. Replit выполняет проверку исходного кода и внешнее тестирование одновременно.
