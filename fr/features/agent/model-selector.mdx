Le sélecteur de modèle permet à Replit d&#39;appliquer le routage intelligent des modèles, ou vous laisse choisir vous-même un modèle disponible.

<div id="intelligent-model-routing">
  ## Routage intelligent des modèles
</div>

Le routage intelligent des modèles sélectionne le modèle adapté à chaque tâche, en conciliant qualité et coût. Lorsque la mention **Auto** apparaît dans le produit, c&#39;est que Replit applique le routage intelligent des modèles.

Le routage intelligent des modèles tient compte de la tâche demandée et de sa complexité. Une demande ciblée peut faire appel à un modèle moins coûteux, tandis qu&#39;un travail complexe nécessitera un modèle plus performant. Replit peut changer de modèle à mesure que la tâche évolue.

<Note>
  Le Free Mode utilise toujours le routage intelligent des modèles. En Free Mode,
  les créateurs ne peuvent pas utiliser le sélecteur de modèle ni choisir un modèle manuellement.
</Note>

<div id="choose-a-model-manually">
  ## Choisir un modèle manuellement
</div>

Les créateurs disposant d&#39;un abonnement Core ou Pro peuvent choisir un modèle disponible en mode Power ou en mode Max.

1. Dans le champ de prompt, sélectionnez **Agent Mode**. Le menu affiche les modes disponibles : **Free**, **Power** et **Max**.
2. Sélectionnez **Power** ou **Max**, puis repérez la section **modèle principal**.
3. Ouvrez le menu du modèle principal, puis choisissez un modèle dans la liste.

<div id="effort">
  ## Effort
</div>

**Effort est un réglage propre à chaque modèle, et non un mode distinct.** Il détermine la quantité de raisonnement que le modèle sélectionné consacre à chaque réponse, de **Low** à **Max**. Chaque modèle affiche son réglage recommandé, que vous pouvez augmenter uniquement lorsqu&#39;une tâche l&#39;exige.

<Frame caption="Le curseur Effort sous la liste des modèles, réglé sur Medium.">
  <img src="/assets/mirror/model-selector-effort-bcffb01239a8.png" alt="La liste des modèles principaux avec Claude Fable 5 sélectionné et le curseur Effort réglé sur Medium, décrit comme un raisonnement équilibré pour les tâches courantes" width="984" height="832" data-path="images/replitai/model-selector-effort.png" />
</Frame>

Appuyez-vous sur la description de chaque niveau :

| Effort         | À utiliser pour                                                                                                                       |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| **Low**        | Réponses les plus rapides avec un raisonnement minimal. Modifications courantes et bien définies, où la vitesse prime.                |
| **Medium**     | Raisonnement équilibré pour les tâches du quotidien. Un bon choix par défaut, sauf indication contraire du réglage recommandé.        |
| **High**       | Raisonnement plus poussé pour les travaux complexes, comme les fonctionnalités en plusieurs étapes et les terrains moins familiers.   |
| **Extra High** | Raisonnement étendu pour les problèmes les plus ardus, comme les refactorisations d&#39;ampleur et les bugs épineux.                  |
| **Max**        | Profondeur de raisonnement maximale. L&#39;option la plus coûteuse et la plus lente, quand seul le meilleur résultat possible compte. |

À un Effort élevé, Agent mène un raisonnement plus poussé et plus réfléchi et sollicite ses modèles de pointe les plus performants, ce qui améliore les résultats sur les tâches les plus complexes. Agent applique cette puissance supplémentaire de façon sélective : il n&#39;oriente la requête vers les modèles les plus performants que lorsqu&#39;elle est réellement difficile, et non à chaque exécution.

<Tip>
  Comme Agent ne fait appel au modèle le plus performant que pour les travaux les plus
  ardus, un Effort élevé peut multiplier le coût jusqu&#39;à environ 2× sur les tâches les plus exigeantes. Sur les tâches
  plus simples, le surcoût est souvent faible, voire nul. Augmentez-le pour les problèmes complexes et laissez-le bas
  pour les modifications courantes.
</Tip>

<div id="compare-models">
  ## Comparer des modèles
</div>

**Compare models** exécute votre prochain prompt sur plusieurs modèles à la fois, afin que vous puissiez comparer les résultats côte à côte plutôt que de deviner quel modèle convient le mieux. Cette fonctionnalité est en bêta.

Pour l&#39;activer, déployez **Advanced settings** en bas de la fenêtre des modes Agent, puis activez **Compare models**.

<Note>La comparaison de modèles n&#39;est prise en charge qu&#39;avec Chat.</Note>

<Frame caption="Le bouton Compare models sous Advanced settings.">
  <img src="/assets/mirror/compare-models-toggle-05429dc46d64.png" alt="Advanced settings déployé avec le bouton Compare models Beta désactivé, présenté comme permettant de créer jusqu'à 4 variantes avec votre prochain prompt" width="1110" height="344" data-path="images/replitai/compare-models-toggle.png" />
</Frame>

Une fois l&#39;option activée, ajoutez jusqu&#39;à **4 modèles** à la comparaison.

<Frame caption="Quatre modèles sélectionnés pour la comparaison, avec le bouton d'envoi affichant Compare 4.">
  <img src="/assets/mirror/compare-models-9f5bcecec727.png" alt="La fenêtre des modes Agent avec Compare models activé et quatre emplacements de modèles pouvant être supprimés : Kimi K3, Claude Fable 5, Claude Opus 5 et GPT-5.6 Sol. Le bouton d'envoi du chat affiche Compare 4" width="1192" height="1930" data-path="images/replitai/compare-models.png" />
</Frame>

Votre prochain prompt est alors exécuté une fois par modèle sélectionné, et chacun produit sa propre variante à comparer.

<Note>
  Chaque modèle d&#39;une comparaison exécute un agent distinct et consomme des crédits : une
  exécution Compare 4 coûte donc à peu près autant que quatre exécutions simples.
</Note>
