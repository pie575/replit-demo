## Plateforme

### Replit Auth

[Replit Auth](/fr/features/auth-and-identity/authentication) est disponible pour tous les utilisateurs ! C'est un système d'authentification intégré qui vous permet d'ajouter une connexion utilisateur à vos applications avec une configuration minimale. Au lieu de créer des systèmes d'authentification complexes à partir de zéro, Replit Auth fournit une solution sécurisée et prête à l'emploi intégrée à l'infrastructure de Replit.

**Fonctionnalités clés :**

* **Zéro configuration** - Ajoutez l'authentification avec une seule invite dans Agent
* **Sécurité intégrée** - Utilise l'infrastructure de Replit avec des protections contre les attaques courantes
* **Gestion des utilisateurs** - Administration simplifiée des utilisateurs via le volet Auth
* **Intégration de la base de données** - Entrées utilisateur automatiques dans votre base de données
* **Page de connexion personnalisable** - Personnalisez l'expérience de connexion pour votre application
* **Réinitialisation du mot de passe** - Replit gère les e-mails de réinitialisation de mot de passe, éliminant le besoin de votre propre fournisseur de livraison d'e-mails

Commencer est simple—incluez simplement une demande de Replit Auth dans votre invite Agent :

<AiPrompt>
  Aide-moi à créer une application qui \[votre idée d'application] et qui devrait inclure Replit Auth.
</AiPrompt>

### Mise à jour de la politique de suspension UBB

Nous avons amélioré notre système de période de grâce de paiement pour mieux soutenir les utilisateurs établis tout en protégeant leurs déploiements. Les utilisateurs de longue date disposent désormais de plus de temps pour résoudre les problèmes de paiement, garantissant que les applications critiques restent en ligne pendant la mise à jour des informations de paiement.

### Sélecteur de type d'application entièrement lancé

Le sélecteur de type d'application est désormais disponible pour tous les utilisateurs ! Cette fonctionnalité facilite le choix du bon modèle lors du démarrage d'un nouveau projet, vous aidant à démarrer plus rapidement avec des configurations adaptées à votre cas d'utilisation spécifique.

Nous avons simplifié l'expérience de changement d'organisation avec une nouvelle interface unifiée. Ce design plus propre et plus intuitif facilite la navigation entre votre compte personnel et vos diverses organisations, vous aidant à collaborer plus efficacement.

### Plan annuel Replit Teams

Replit Teams propose désormais une option de plan annuel, offrant un moyen plus économique pour les équipes d'accéder à nos fonctionnalités collaboratives. Abonnez-vous annuellement pour débloquer une valeur supplémentaire pour les besoins de développement de votre équipe.
