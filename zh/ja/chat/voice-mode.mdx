使用语音模式，用语音描述你想构建的内容。轻点 Agent 聊天框中的麦克风并开始说话，Replit 会将你的语音转写为文本。确认并编辑文本后，即可像发送普通消息一样将其发送。

当打字较慢或不方便打字时，语音模式非常实用——尤其是在移动设备上，说出完整提示词通常比用拇指打字更快。

<Note>
  语音模式会将语音转换为聊天框中的文本。它不会朗读 Agent 的回复——你仍像平常一样发送文字消息，Agent 会在聊天中回复。
</Note>

  ## 工作原理
</div>

  <img src="/assets/mirror/voice-mode-mic-button-fe7da6953736.png" alt="Agent 聊天框中高亮显示的麦克风按钮，并显示“开始语音输入”工具提示。位于 Plan 复选框和发送箭头旁边" width="1853" height="423" data-path="images/replitai/voice-mode/voice-mode-mic-button.png" />

语音模式会录制并转写你的语音，然后将结果插入聊天框，供你在发送前确认：

1. 打开 Agent，点击聊天框中的麦克风。
2. 如果浏览器或设备提示，请允许访问麦克风。
3. 说出你的提示词。系统会显示波形，表示 Agent 正在录音。
4. 说完后，停止录音。暂停或切换标签页后，录音会自动停止。
5. 稍等片刻，等待语音转写完成。
6. 查看转写文本，必要时进行编辑，然后发送消息。

转写内容会以文本形式显示在普通聊天框中，因此你可以自由结合语音和输入——先口述提示词的一部分，再输入其余内容，或在发送前修改词语。

<Tip>
  自然说话即可。语音模式更注重理解含义，而非逐字转写，因此“呃”“嗯”等语气词会从结果中排除。
</Tip>

<div id="section-2">
  ## 可使用位置
</div>

您可以在 Agent 聊天框中使用语音模式：

* 在使用 Agent 开发应用时的**项目编辑器**中。
* 通过主页上的 Agent 提示词**创建新应用**时。

语音模式可在桌面网页版、移动网页版和 Replit 移动应用中使用。

<div id="section-3">
  ## 使用须知
</div>

使用语音模式时，请注意以下事项：

| 详情      | 说明                                                 |
| ------- | -------------------------------------------------- |
| 录音时长    | 每次最多可录制 6 分钟。接近时长限制时会显示警告。                         |
| 自动停止    | 静音约 30 秒后，或切换标签页、将应用置于后台时，录音会自动停止。                 |
| 发送前确认   | 转写文本会显示在聊天框中，你可以在发送前查看和编辑，不会自动发送。                  |
| 麦克风访问权限 | 语音模式需要使用麦克风的权限。如果录音未开始，请确认浏览器和设备是否允许 Replit 访问麦克风。 |

<div id="section-4">
  ## 可用套餐
</div>

所有 Replit 套餐均可使用语音模式。在支持音频录制的浏览器和设备上，Agent 聊天框中会显示麦克风图标；首次录音时，系统会请求麦克风权限。
