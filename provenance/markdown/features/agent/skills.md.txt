## What is a Skill?

A skill is a folder. Inside it lives a file called `SKILL.md` with the instructions Agent follows, plus any supporting files you want it to reference. Skills live in your project's `/.agents/skills` directory and conform to the [Agent Skills specification](https://agentskills.io/specification) — an open standard that works across agents.

Agent sees the name and description of every installed Skill, but only loads the full content when relevant to the current task. This makes skills context-efficient: you can install many without degrading Agent's output.

## Pre-defined Skills

Replit ships with pre-defined skills available from the **Use a skill** picker in chat and from the new-project starting-point picker. These skills work in every project without installation. For the full catalog, partner skills, and how to install them, see the [Skills directory](/features/agent/skills-directory).

To add a pre-defined skill, open the **Use a skill** picker from the chat input and select a skill, or simply ask Agent to load the skill.

## Skill scope

Skills can be scoped at different levels:

| Scope               | Availability                            | Where it lives                                                                                            |
| ------------------- | --------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| **Project-level**   | Specific to one project                 | Versioned with your files in `/.agents/skills`                                                            |
| **Workspace-level** | Available to everyone in your workspace | Managed centrally in Workspace Settings                                                                   |
| **Enterprise**      | Company-wide standards                  | Included in [custom templates](/teams/custom-templates) and [design systems](/teams/custom-design-system) |

For workspace-level skills, see [Agent Customization](/features/agent/agent-customization) to set up workspace skills and custom instructions for your team.

## Create a custom Skill

Create a custom Skill when you want reusable instructions in your Workspace library.
In a shared Workspace, you can set Workspace member access while creating the Skill
and update it later. Who can manage Skills depends on your plan — see
[Agent Customization](/features/agent/agent-customization).

Workspace member access policies are:

| Policy        | Access                                                                |
| ------------- | --------------------------------------------------------------------- |
| **Required**  | Always on and cannot be turned off                                    |
| **Available** | Optional and off by default; members must turn on the Skill to use it |
| **No access** | Hidden from members                                                   |

<Steps>
  <Step title="Open the Skills settings">
    Open **Settings** > **Customization** > **Skills** in the Workspace.
  </Step>

  <Step title="Start a custom Skill">
    Select **Add**, then select **Write a skill**.
  </Step>

  <Step title="Describe the Skill">
    A custom Skill includes:

    * **Name**: Identifies the Skill in the Workspace library.
    * **Description**: Explains when Agent should use the Skill.
    * **Instructions**: Defines the steps Agent should follow.

    <Frame caption="Enter the details for a custom Skill in a team Workspace.">
      <img src="https://mintcdn.com/replit/7BCxB5EHUuG2XCPr/images/replitai/workspace-custom-skill-create.jpg?fit=max&auto=format&n=7BCxB5EHUuG2XCPr&q=85&s=faa14cf8ff50c8e259d931b0886cb5a1" alt="Team Workspace custom Skill form with name, description, instructions, and the Create skill button" width="2000" height="1363" data-path="images/replitai/workspace-custom-skill-create.jpg" />
    </Frame>
  </Step>

  <Step title="Set Workspace member access">
    A new Skill starts as **Private**, so only you and Workspace admins can use it.
    Select the **Sharing** control, then set one of the policies above for **Members
    in workspace**.

    <Frame caption="Set Workspace member access before creating the Skill.">
      <img src="https://mintcdn.com/replit/7BCxB5EHUuG2XCPr/images/replitai/workspace-custom-skill-create-sharing.jpg?fit=max&auto=format&n=7BCxB5EHUuG2XCPr&q=85&s=dbf34f7bddb13e1fe3c80b6f5206c986" alt="Custom Skill form with the Sharing control open and Required, Available, and No access options visible" width="2000" height="1154" data-path="images/replitai/workspace-custom-skill-create-sharing.jpg" />
    </Frame>
  </Step>

  <Step title="Create the Skill">
    Review the details, then select **Create skill**.
  </Step>
</Steps>

## Share project Skills

In a shared Workspace, you can update member access after the Skill exists.

<Steps>
  <Step title="Create or select a Skill">
    Create a custom Skill with the steps above, or select an existing Skill in
    **Settings** > **Customization** > **Skills**.

    To save a project Skill to your Workspace, open **Agent Skills** > **Project skills** in your project. Select **Save to workspace**, enter a name, then select **Save**.
  </Step>

  <Step title="Open sharing">
    On the Skill card in the Workspace library, open the options menu, then select **Share...**.

    <Frame caption="Open an existing Skill's menu to share it after creation.">
      <img src="https://mintcdn.com/replit/7BCxB5EHUuG2XCPr/images/replitai/workspace-skill-share-menu.jpg?fit=max&auto=format&n=7BCxB5EHUuG2XCPr&q=85&s=1cc836570a1345d05d8ceba2cb0c1ec8" alt="Workspace Skills page with an existing Skill's options menu open and the Share action visible" width="1600" height="1100" data-path="images/replitai/workspace-skill-share-menu.jpg" />
    </Frame>
  </Step>

  <Step title="Set Workspace member access">
    In the **Share skill** dialog, select one of the policies above for **Members in
    workspace**. Your selection applies immediately; there is no separate
    confirmation action.

    <Frame caption="Choose how Workspace members can access the Skill.">
      <img src="https://mintcdn.com/replit/7BCxB5EHUuG2XCPr/images/replitai/workspace-skill-sharing-policy.jpg?fit=max&auto=format&n=7BCxB5EHUuG2XCPr&q=85&s=d86725c0f91ff73c16e161cac6c294ff" alt="Share skill dialog showing Required, Available, and No access policies for Workspace members" width="1500" height="1000" data-path="images/replitai/workspace-skill-sharing-policy.jpg" />

  </Step>
</Steps>

## Import Skills from GitHub

Add Skills from a public GitHub repository, folder, or file URL.

<Steps>
  <Step title="Open Workspace Skills">
    In Agent, select **+** > **Use a skill** to open **Workspace Skills**.

    <Frame caption="Open the plus menu and select Use a skill to access Workspace Skills.">
      <img src="https://mintcdn.com/replit/7BCxB5EHUuG2XCPr/images/replitai/workspace-skill-picker.jpg?fit=max&auto=format&n=7BCxB5EHUuG2XCPr&q=85&s=2f58636cb7c41cafe2f3d22dc82a0b7d" alt="Agent plus menu with Use a skill selected and the Workspace Skills picker listing ask-matt, claude-handoff, and code-review" width="2000" height="1085" data-path="images/replitai/workspace-skill-picker.jpg" />
    </Frame>
  </Step>

  <Step title="Preview Skills">
    Paste a public GitHub repository, folder, or file URL, then select **Preview
    skills**. The preview checks file structure only. It does not load Skill
    instructions or descriptions.

    <Frame caption="Enter a public GitHub URL and preview its Skill file structure.">
      <img src="https://mintcdn.com/replit/7BCxB5EHUuG2XCPr/images/replitai/workspace-skill-github-preview.jpg?fit=max&auto=format&n=7BCxB5EHUuG2XCPr&q=85&s=de878e3eaf6093faca25b25a6b5adffe" alt="Add from GitHub page with a public GitHub repository URL and the Preview skills button" width="2000" height="1154" data-path="images/replitai/workspace-skill-github-preview.jpg" />
    </Frame>
  </Step>

  <Step title="Select and import Skills">
    Review the detected Skills, select the ones to import, then select **Import**. The button shows the number of Skills you selected, such as **Import 36 skills**.

    <Frame caption="Review the detected Skills and select the ones to import.">
      <img src="https://mintcdn.com/replit/7BCxB5EHUuG2XCPr/images/replitai/workspace-skill-github-select.jpg?fit=max&auto=format&n=7BCxB5EHUuG2XCPr&q=85&s=b11d8e6f288dd932ac3a28a68caa46be" alt="GitHub Skill preview showing detected Skills with selection controls and the Import 36 skills button" width="2000" height="1154" data-path="images/replitai/workspace-skill-github-select.jpg" />
    </Frame>
  </Step>
</Steps>

The example above uses the public
[mattpocock/skills](https://github.com/mattpocock/skills) repository.

<Note>
  Each import is limited to 50 Skills, 3,500 files, or 200 MiB. Private repositories aren't supported.
</Note>

Imported repositories appear under the **GitHub** filter on the **Skills** tab.

## How Agent loads skills

Agent reads the metadata (name and description) of every installed skill on every chat. The full body of a skill loads only when Agent determines the skill is relevant to the current task. This keeps skill content out of the context window until needed.

Installed skills persist in your project across Agent sessions and can be committed to version control for team sharing.

## Working with other AI coding tools

<Accordion title="Import skills from other AI coding tools">
  If you work across multiple AI coding tools, [rulesync](https://github.com/dyoshikawa/rulesync) has Replit support and helps you maintain consistent configurations.

  You can import skills from other AI coding assistants:

  ```bash theme={null}
  npx rulesync init
  npx rulesync import --targets claudecode --features skills
  npx rulesync generate --targets replit --features skills
  ```

  This allows you to maintain a single set of skills that work across different development environments.
</Accordion>
