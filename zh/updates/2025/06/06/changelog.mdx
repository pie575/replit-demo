<div id="visual-editor-image-management">
  ### Visual Editor 图片管理
</div>

现在，借助 Visual Editor，图片管理变得轻而易举。选择任意图片，即可通过更换 URL 或直接上传新文件立即更新。你可以即时查看预览和更新效果，更快地创建富有视觉吸引力的内容。焕新的界面还提升了响应速度，带来更流畅的编辑体验。

<div id="new-agent-entrypoints-in-workspace">
  ### workspace 中新增 Agent 入口
</div>

我们在整个 workspace 中新增了与上下文相关的 Agent 入口，帮助您更快地调试和解决问题。现在，Agent 会在您最需要帮助的地方出现，省去在不同工具间切换上下文的麻烦。

  <img src="/assets/mirror/cleanshot-2025-06-04-at-113629png-150124-0133e1f81500.png" alt="带聊天记录的 Ask Agent 界面下拉菜单" width="738" height="301" data-path="images/changelog/2025-06-06/cleanshot-2025-06-04-at-113629png-150124.png" />

您可以直接在当前上下文中获得代码调试、控制台错误和 deployment 问题的即时帮助。无论是排查运行时错误，还是需要理解复杂函数，Agent 都能提供有针对性的支持，不会打断您的工作流程。

集成的聊天记录可确保调试会话之间的连续性，让您能够基于之前的对话继续处理，并在解决复杂问题时保持上下文。

<div id="csv-export-for-teams-admins">
  ### Teams 管理员 CSV 导出
</div>

组织管理员现在可以将完整的应用表导出为 CSV 文件，从而简化对组织 repl 使用情况的跟踪、分析和报告。导出内容包含完整的元数据，包括应用可见性状态和关键使用指标。

<div id="teams-viewer-seat-management">
  ### Teams 查看者席位管理
</div>

Teams 现支持更灵活的席位管理和更简化的升级流程。查看者可申请升级为成员席位，管理员可直接在成员页面审核并批准这些申请。优化后的成员角色编辑界面让团队管理更加直观高效。
