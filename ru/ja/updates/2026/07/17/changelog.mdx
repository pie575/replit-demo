<div id="agent">
  ### Если доступно несколько вариантов, Agent предлагает коннекторы
</div>

Когда вы просите Agent подключиться к сервису и доступно несколько провайдеров, Agent показывает краткий список, из которого можно выбрать. Раньше Agent сначала задавал уточняющий вопрос. Выберите провайдера и войдите в систему один раз — после этого Agent продолжит работу.

<div id="tools">
  ### Новая панель Tools
</div>

Все возможности для вашего App теперь собраны в одном месте рабочего пространства. На новой закреплённой панели Tools собраны Database, Auth, Domains, Secrets и другие инструменты. Благодаря этому весь набор инструментов легко найти с первого взгляда. Сами инструменты не изменились — они просто размещены в более удобном месте.

<div id="section-2">
  ### Более быстрая боковая панель задач
</div>

Боковая панель задач стала компактнее и удобнее для быстрого просмотра задач. При наведении на каждую задачу отображается отдельная карточка с быстрыми действиями и подробностями, переход к Task Board стал понятнее, а при разворачивании и сворачивании боковой панели задачи больше не меняют своё положение.
