<div id="what-to-expect">
  ## 예상 결과
</div>

Agent는 여러 플랫폼의 광고 소재를 순위별로 정리한 표를 만듭니다. 예산을 변경하기 전에 각
광고 관리자의 합계와 대조해 표본 점검을 하세요. 날짜 범위와 시간대가 서로 다른 경우가 많으므로
먼저 각 광고 관리자에서 기간을 동일하게 맞추세요. 성과가 가장 높은 광고와 가장 낮은 광고를 골라
광고 관리자에서 열어 보고, 예산을 옮기기 전에 지출이 일치하는지 확인하세요.

<div id="troubleshooting">
  ## 문제 해결
</div>

* **Google Ads 또는 Meta Ads 데이터를 가져오지 못하는 경우:** 이 두 가지는 네이티브 커넥터가 아닙니다. Agent가 API 키를 요청하므로 키를 미리 준비하고, 해당 키로 확인하려는 광고 계정을 읽을 수 있는지 확인하세요.
* **합계가 광고 관리자 수치와 일치하지 않는 경우:** 날짜 범위와 시간대가 서로 다른 경우가 많습니다. 각 플랫폼과 동일한 기간(보통 지난주 월요일부터 일요일까지)을 사용하도록 Agent에 요청하고, 예산을 변경하기 전에 지출액을 표본 점검하세요.
* **표에 플랫폼이 누락된 경우:** 먼저 Replit에서 TikTok Ads와 Snapchat Ads를 연결하세요. 네이티브 연결이 만료되었다면 다시 연결한 후 Routine을 다시 실행하세요.
