L&#39;outil Secrets stocke et chiffre les informations sensibles de votre application Replit, notamment les **Secrets** — clés API, jetons d&#39;authentification, chaînes de connexion à des bases de données, etc.

Lorsque vous ajoutez un Secret, l&#39;outil chiffre automatiquement les données et les fournit à votre application Replit sous forme de variables d&#39;environnement.
Cette méthode réduit les risques d&#39;exposition en évitant de coder en dur des Secrets dans votre code.

Si vous codez en dur des Secrets dans votre base de code, ils risquent d&#39;être accidentellement exposés dans les situations suivantes :

* Lorsque vous partagez votre code avec d&#39;autres personnes via une application Replit publique ou par copier-coller
* Lorsque vous validez votre code dans un dépôt public
* Lorsque vous diffusez votre code en direct ou partagez votre écran

Utilisez l&#39;outil Secrets pour partager votre code sans craindre d&#39;exposer vos identifiants.

<div id="section">
  ## Fonctionnalités
</div>

Les secrets offrent les fonctionnalités suivantes :

* **Chiffrement de bout en bout** : protection automatique des données grâce au chiffrement AES-256 au repos et au chiffrement TLS en transit
* **Secrets au niveau de l’application** : stockage et gestion des secrets pour une application Replit spécifique
* **Secrets au niveau du compte** : stockage et gestion des secrets utilisables dans toutes les applications Replit
* **Accès aux variables d’environnement** : accès aux secrets dans votre code à l’aide de variables d’environnement
* **Accès collaboratif** : partage des secrets avec les collaborateurs et les membres de l’équipe

<div id="section-2">
  ## Utilisation
</div>

<Note>
  Secrets est disponible pour tous les types de déploiement, à l&#39;exception des déploiements statiques.
</Note>

Vous pouvez accéder aux secrets depuis l&#39;outil Secrets du Project Editor.

<Accordion title="Comment accéder aux secrets">
  Depuis le **dock des outils** à gauche :

  1. Sélectionnez <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Icône All tools" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools** pour afficher la liste des outils du Project Editor.
  2. Sélectionnez <img class="icon-svg" src="/assets/mirror/lock-af402c9618dd.svg" alt="Icône Secrets" width="16" height="16" data-path="images/icons/lock.svg" /> **Secrets**.

  Depuis la **barre de recherche** :

  1. Sélectionnez la loupe <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="icône loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> en haut pour ouvrir l&#39;outil de recherche.
  2. Saisissez « Secrets » pour trouver l&#39;outil, puis sélectionnez-le dans les résultats.
</Accordion>

<div id="section-3">
  ### Gérer les secrets d&#39;application
</div>

Vous pouvez gérer les secrets au niveau de l&#39;application depuis l&#39;onglet **App Secrets** du panneau **Secrets**.
Cet onglet affiche la liste de tous les secrets associés à votre application Replit.

<Accordion title="Ajouter un secret d'application">
  Pour ajouter un secret :

  1. Sélectionnez **New Secret**.
  2. Saisissez la **Key**, c&#39;est-à-dire le nom du secret, et la **Value**, c&#39;est-à-dire le secret lui-même.
  3. Sélectionnez **Add Secret** pour enregistrer l&#39;entrée.
</Accordion>

<Accordion title="Modifier un secret d'application">
  Pour modifier un secret :

  1. Sélectionnez le menu à trois points verticaux <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="icône à trois points verticaux" height="16" width="16" data-path="images/icons/vertical-dots.svg" /> situé à côté du secret.
  2. Sélectionnez **Edit** dans le menu contextuel.
  3. Modifiez le texte des champs **Key** ou **Value**, puis sélectionnez **Update Secret** pour enregistrer vos modifications ou **Cancel** pour les annuler.

  Vous pouvez également modifier l&#39;ensemble de la liste des secrets d&#39;application en sélectionnant **Edit as JSON** ou **Edit as .env** en bas de l&#39;onglet.
</Accordion>

<Accordion title="Afficher un secret d'application">
  Pour afficher un secret, sélectionnez l&#39;icône en forme d&#39;œil <img class="icon-svg" src="/assets/mirror/eye-8a6472b8a950.svg" alt="icône en forme d'œil" width="16" height="16" data-path="images/icons/eye.svg" /> située à côté du secret.

  Pour masquer le secret, sélectionnez l&#39;icône en forme d&#39;œil barré <img class="icon-svg" src="/assets/mirror/eye-slash-6b4ded538179.svg" alt="icône en forme d'œil barré" width="16" height="16" data-path="images/icons/eye-slash.svg" />.
</Accordion>

<Accordion title="Supprimer un secret d'application">
  Pour supprimer un secret, sélectionnez le menu à trois points verticaux <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="icône à trois points verticaux" height="16" width="16" data-path="images/icons/vertical-dots.svg" /> situé à côté du secret, puis sélectionnez **Delete**.
</Accordion>

<div id="section-4">
  ### Gérer les secrets du compte
</div>

Vous pouvez gérer les secrets au niveau du compte depuis l&#39;onglet **Account Secrets** du panneau **Secrets**.
Cet onglet affiche uniquement la liste des secrets associés à votre compte Replit.

<Accordion title="Ajouter un secret de compte">
  Pour ajouter un secret au niveau du compte :

  1. Accédez à l&#39;onglet **Account Secrets**.
  2. Sélectionnez l&#39;icône <img class="icon-svg" src="/assets/mirror/settings-icon-c2664c3691bf.svg" alt="icône d'engrenage" width="16" height="16" data-path="images/icons/settings-icon.svg" /> pour ouvrir les **Settings** et gérer les secrets au niveau du compte.
  3. Sélectionnez **New Secret** pour ajouter un secret.
  4. Saisissez la **Key**, qui correspond au nom du secret, et la **Value**, qui correspond au secret lui-même.
  5. Sélectionnez **Save** pour enregistrer l&#39;entrée.
</Accordion>

<Accordion title="Modifier un secret de compte">
  Pour modifier un secret :

  1. Sélectionnez l&#39;icône crayon <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="icône de crayon" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> située à côté du secret.
  2. Mettez à jour le texte des champs **Key** ou **Value**, puis sélectionnez **Save** pour enregistrer vos modifications ou **Cancel** pour les annuler.
</Accordion>

<Accordion title="Afficher un secret de compte">
  Pour afficher un secret, sélectionnez l&#39;icône œil <img class="icon-svg" src="/assets/mirror/eye-8a6472b8a950.svg" alt="icône en forme d'œil" width="16" height="16" data-path="images/icons/eye.svg" /> située à côté du secret.

  Pour masquer un secret, sélectionnez l&#39;icône œil barré <img class="icon-svg" src="/assets/mirror/eye-slash-6b4ded538179.svg" alt="icône en forme d'œil barré" width="16" height="16" data-path="images/icons/eye-slash.svg" />.
</Accordion>

<Accordion title="Lier un secret de compte">
  Pour utiliser un secret au niveau du compte dans une application Replit, vous devez le lier à cette application.
  Pour lier un secret au niveau du compte :

  1. Accédez à l&#39;onglet **App Secrets**.
  2. Cochez la case à gauche du secret.
  3. Sélectionnez **Link to this App**.

  Pour dissocier un secret :

  1. Accédez à l&#39;onglet **App Secrets**.
  2. Sélectionnez le menu à trois points verticaux <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" width="16" height="16" alt="icône à trois points verticaux" data-path="images/icons/vertical-dots.svg" /> situé à côté du secret.
  3. Sélectionnez **Unlink**.
</Accordion>

<Accordion title="Supprimer un secret de compte">
  1. Sélectionnez l&#39;icône crayon <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="icône de crayon" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> située à côté du secret.
  2. Sélectionnez **Delete**.
</Accordion>

<div id="section-6">
  ### Gérer la visibilité des secrets
</div>

La visibilité des secrets dépend de vos droits d&#39;accès à l&#39;application Replit et du fait que vous en soyez ou non l&#39;auteur.

Vous pouvez partager une application Replit à l&#39;aide de l&#39;une des options suivantes :

* **Multiplayer** : inviter des utilisateurs Replit à collaborer en temps réel
* **Cover page** : afficher un aperçu de l&#39;application Replit et les options de remix
* **Remix** : rendre publique une application Replit personnelle ou d&#39;organisation afin que d&#39;autres puissent en créer leur propre version

Le tableau suivant présente la visibilité des noms et des valeurs des secrets selon les différents scénarios :

| Méthode d&#39;accès | Cible                                                            | Nom visible | Valeur visible |
| ------------------- | ---------------------------------------------------------------- | ----------- | -------------- |
| Multiplayer         | Collaborateurs Multiplayer                                       | ✓           | ✓              |
| Multiplayer         | Membres de l&#39;organisation (rôle Owner)                       | ✓           | ✓              |
| Multiplayer         | Membres de l&#39;organisation (non-Owner)                        | ✓           |                |
| Cover Page          | Tous les visiteurs                                               |             |                |
| Remix               | Propriétaire/collaborateur remixant sa propre application Replit | ✓           | ✓              |
| Remix               | Non-propriétaire/collaborateur remixant une application Replit   | ✓           |                |
| Remix               | Tout utilisateur remixant depuis la cover page                   | ✓           |                |
| Organization Remix  | Membres de l&#39;organisation ayant le rôle Owner                | ✓           | ✓              |
| Organization Remix  | Membres de l&#39;organisation sans le rôle Owner                 | ✓           |                |

<Warning>
  Les membres de l&#39;organisation sans le rôle Owner ne peuvent pas voir les valeurs des secrets dans l&#39;application Replit, mais ils peuvent y accéder en affichant les variables d&#39;environnement.
</Warning>

<div id="section-7">
  ## Secrets liés aux bases de données
</div>

Lorsque vous ajoutez une base de données Replit, le Project Editor crée automatiquement les secrets suivants :

| Secret         | Description                                  |
| -------------- | -------------------------------------------- |
| `DATABASE_URL` | Chaîne de connexion à la base de données SQL |

<Info>
  Les anciennes bases de données de développement Neon peuvent également inclure `PGHOST`, `PGUSER`, `PGPASSWORD`, `PGDATABASE` et `PGPORT`. Les bases de données de développement Replit actuelles utilisent plutôt `DATABASE_URL`.
</Info>

Pour afficher toutes les variables d’environnement de votre application Replit, exécutez `printenv` dans l’outil Shell du Project Editor ou affichez-les dans votre code.

<div id="section-8">
  ## Variables d&#39;environnement prédéfinies
</div>

Replit définit automatiquement les variables d&#39;environnement suivantes, accessibles depuis votre application :

| Variable d&#39;environnement | Description                                                                                 |
| ---------------------------- | ------------------------------------------------------------------------------------------- |
| `REPLIT_DOMAINS`             | Liste, séparée par des virgules, de tous les domaines associés à l&#39;application Replit   |
| `REPLIT_USER`                | Nom d&#39;utilisateur de l&#39;éditeur actuel (peut différer dans les sessions Multiplayer) |
| `REPLIT_DEPLOYMENT`          | Défini à `1` si le code s&#39;exécute dans une application publiée, sinon non défini        |
| `REPLIT_DEV_DOMAIN`          | URL de développement du domaine `replit.dev`, différente de l&#39;URL de déploiement        |

Elles n&#39;apparaissent pas dans l&#39;outil Secrets, mais vous pouvez y accéder depuis votre code à l&#39;aide de l&#39;objet `os.environ` ou en exécutant `printenv` dans le Shell.
