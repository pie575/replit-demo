Laissez des commentaires directement sur les [applications publiées](/cloud-services/deployments/about-deployments) avec la [boîte de réception d'Agent](/fr/cloud-services/deployments/enable-feedback). Lorsque les visiteurs utilisent le widget de feedback sur votre application publiée, vous pouvez utiliser [Agent](/fr/core-concepts/agent) pour mettre en œuvre leurs suggestions. Disponible pour tous les utilisateurs payants.

### Extension Replit + Gemini CLI

Créez des projets et interagissez avec eux via le Gemini CLI. L'extension Replit est désormais disponible dans le répertoire des extensions Gemini CLI, aux côtés de plus de 300 autres extensions pour développeurs.

### Leçons 5 à 7 de Replit Learn

Les leçons 5 à 7 sont désormais disponibles sur [Replit Learn](https://learn.replit.com), complétant le module Fondements de l'IA. Découvrez ce qui fait d'une « application » une application, comment fonctionne l'IA et ce qu'est le vibe coding à travers des projets pratiques. Idéal pour les builders qui débutent avec l'IA et Replit.
