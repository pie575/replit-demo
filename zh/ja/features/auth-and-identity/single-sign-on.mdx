<Note>
  想在 **Replit 组织** (登录 replit.com) 中强制使用 SSO？这需要单独配置。请参阅[单点登录 (SAML SSO) ](/zh/ja/teams/identity-and-access-management/saml)。本页面介绍如何为您在 Replit 上**构建的应用**添加 SSO 登录流程。
</Note>

让用户能够使用企业身份提供方 (如 Okta 或 Microsoft Entra ID) 登录您的应用。如果您的应用使用 [Clerk Auth](/zh/ja/features/auth-and-identity/clerk-auth)，请在 Clerk 控制台中配置 SSO 和其他高级身份验证功能。告诉 Agent 您的需求，Agent 会引导您前往完成设置所需的控制台。

<Frame>
  <img src="/assets/mirror/sso-cover-28a76bfa16fb.jpeg" alt="展示锁图标和正在使用笔记本电脑工作的构建者的横幅，说明如何通过 SSO 构建 Replit 应用。" width="1920" height="1080" data-path="images/workspace/auth/sso-cover.jpeg" />
</Frame>

Clerk 控制台提供的配置选项远不止默认登录体验。您在 Clerk 中所做的设置会自动应用于 Replit 应用的身份验证。

<div id="section">
  ## 可配置的内容
</div>

* **企业级 SSO 连接**：使用 OIDC 或 SAML 配置与 Okta 或 Microsoft Entra ID 的单点登录，让客户能够通过自己公司的身份提供方登录。SSO 还可以用现有的内部身份提供方取代手动维护的邮箱白名单，帮助保护处理敏感数据的内部工具。
* **多重身份验证 (MFA)&#x20;**：为应用的登录流程添加 MFA。
* **会话管理**：调整会话有效期和重新验证的频率。
* **其他 Clerk 设置**：其他 Clerk 设置同样会自动应用到 Replit 应用。请勿修改 API 密钥或环境配置，它们由 Replit 统一管理。详情请参阅[开发环境与生产环境](/zh/ja/features/auth-and-identity/clerk-auth#development-and-production-environments)。

<div id="clerk">
  ## 打开 Clerk 控制台
</div>

告诉 Agent 你需要对身份验证进行哪些更改。Agent 会完成所有可行的设置；对于需要你输入信息的设置，Agent 会引导你前往应用的 Clerk 控制台。

<Frame>
  <img src="/assets/mirror/build-with-sso-agent-workflow-46422788bd18.webp" alt="Agent 正在引导用户在 Clerk 控制台中为使用 Clerk 的应用配置企业级 SSO。" width="1602" height="1080" data-path="images/workspace/auth/build-with-sso-agent-workflow.webp" />
</Frame>

你也可以从工作区打开控制台。

1. 在 Tools 窗格中选择 **Users &amp; Auth**。
2. 选择 **Configure** 标签页。
3. 选择 **Advanced**。
4. 在 **Clerk dashboard** 下选择 **Open Clerk dashboard**。

<Frame>
  <img src="/assets/mirror/open-clerk-dashboard-tools-pane-a314ffea741d.webp" alt="已打开 Configure 标签页的 Users & Auth 工具，其中显示了 Advanced 部分和 Open Clerk dashboard 按钮。" width="2158" height="1372" data-path="images/workspace/auth/open-clerk-dashboard-tools-pane.webp" />
</Frame>

<div id="sso">
  ## 配置 Enterprise SSO 连接
</div>

1. 在 Clerk 控制台中选择 **Configure**。
2. 在 **User &amp; authentication** 下选择 **SSO connections**。
3. 选择 **Enterprise**。
4. 选择 **Add connection**。

<Frame>
  <img src="/assets/mirror/build-with-sso-enterprise-connections-b0a6a27885b5.webp" alt="Clerk 控制台，显示 Enterprise SSO connections 页面和 Add connection 操作。" width="1826" height="1080" data-path="images/workspace/auth/build-with-sso-enterprise-connections.webp" />
</Frame>

有关连接配置的更多信息，请参阅 [Clerk 文档](https://clerk.com/docs)。

<div id="section-2">
  ### 验证连接
</div>

配置完成后，使用身份提供方的测试账户登录，并确认该账户能够访问应用中预期的部分。

如果登录失败，请咨询 Agent，并在请求中附上身份提供方、协议和错误信息。

<Note>
  本页介绍的是应用自身登录流程中的企业级 SSO。若需了解使用 Google、GitHub、Apple 和 X 的社交登录 (在工作区中显示为 **SSO providers**) ，请参阅[登录提供方](/zh/ja/features/auth-and-identity/sign-in-providers)。本页不涉及 Replit Auth 的迁移，也不涉及 Replit 账户的 SAML 登录。
</Note>

<div id="section-3">
  ## 定价与可用套餐
</div>

[Replit Pro](/zh/ja/billing/plans/replit-pro) 套餐可访问 Clerk 控制台。Enterprise 套餐即将推出。

<Info>
  企业级 SSO 连接在 2026 年 10 月 1 日之前免费。此后，Clerk 的 SSO 费用将按原价计入 Replit 账单。
</Info>
