<div id="stock-and-ai-generated-images-in-library">
  ### Library 中的图库图片与 AI 生成图片
</div>

图库图片和 AI 生成的图片现在会显示在 Library 侧边栏中。此前，这些图片虽然会在项目中生成，却不会出现在 Library 里，不便于浏览查找。现在，你可以直接在 Library 侧边栏中查找并复用 Agent 下载或生成的任意图片。

<div id="plan-mode-fix">
  ### Plan 模式修复
</div>

现在，在发送第一条消息后开启 Plan 模式可以正确生效。此前，对话进行到一半时切换 Plan 模式会被静默忽略。

<div id="slide-export-improvements">
  ### 幻灯片导出改进
</div>

导出大型幻灯片演示文稿 (150 张或更多幻灯片) 现在更加稳定可靠。导出超时时间会随幻灯片数量自动延长，可支持 200 张以上幻灯片的演示文稿。
