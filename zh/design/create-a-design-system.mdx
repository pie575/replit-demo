根据您当前的品牌资源，有两种方式可以创建设计系统。

<div id="from-scratch-prompt-it-from-the-home-page">
  ## 从零开始：在主页输入提示词
</div>

如果你的设计系统只存在于脑海中 (或品牌指南里) ，尚未体现在任何设计中，请从这里开始。

<Steps>
  <Step title="在创建输入框中描述需求">
    在 Replit 主页的提示框中描述你想要的设计系统，例如：*&quot;为 Velocity——一个高端超级跑车租赁品牌——创建设计系统。&quot;*

    <Frame>
      <img src="/assets/mirror/ds-home-create-7f04110e1f71.png" alt="主页提示框中用于创建设计系统的提示词" width="800" height="240" data-path="images/design/replit-design/ds-home-create.png" />
    </Frame>
  </Step>

  <Step title="回答问卷">
    Agent 会就你的设计系统提出几个简短的问题，例如品牌个性、配色和字体偏好。你还可以让它参考来源材料，例如 Figma URL、网站、代码、参考图片、品牌资源或现有的 DESIGN.md。
  </Step>
</Steps>

<div id="from-a-mockup-extract-the-design-system">
  ## 从设计稿中提取设计系统
</div>

如果你已有喜欢的设计——无论是生成的 frame 还是导入的 template——并希望其他内容都与其保持一致，请从这里开始。

<Steps>
  <Step title="选择设计稿">
    在 Canvas 上，点击要提取其视觉风格的设计稿。
  </Step>

  <Step title="通过三点菜单提取">
    打开 frame 的 **⋯** (三点) 菜单，然后选择 **提取设计系统**。Agent 会将设计稿中的令牌、颜色和排版提炼为动态样式指南，并将其应用于整个设计。

    <Frame>
      <img src="/assets/mirror/ds-extract-menu-3efbe8bb497e.png" alt="选中 frame 的操作栏特写，已打开更多选项菜单，其中显示“应用设计系统”和“提取设计系统”" width="958" height="320" data-path="images/design/replit-design/ds-extract-menu.png" />
    </Frame>
  </Step>
</Steps>

<div id="review-and-save">
  ## 检查并保存
</div>

无论采用哪种方式，都请检查生成的内容：这是一份动态样式指南，包含你的颜色 (按用途划分——主色、强调色、柔和色等) 、排版比例和令牌 (存储在 `tokens.json` 中，用于生成 CSS 变量) 。然后选择 **保存设计系统**，将其保存到你的 workspace 中。
