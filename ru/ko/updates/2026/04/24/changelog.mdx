<div id="security-agent">
  ### Security Agent проверяет всю кодовую базу
</div>

**Security Agent** — это новый инструмент проверки на базе ИИ, который проводит аудит всего проекта, а не только зависимостей. Он строит модель угроз, составляет карту маршрутов и потоков данных, запускает статический анализ с помощью Semgrep и HoundDog.ai, а затем с помощью LLM определяет, что действительно можно использовать для атаки в контексте вашего приложения. После завершения проверки Security Agent собирает одобренные findings в параллельные задачи, которые Replit Agent исправляет за один заход.

Security Agent доступен всем разработчикам на платных планах. Чтобы попробовать, откройте панель **Безопасность** в проекте и выберите **Запустить сканирование с Agent**.

Подробнее о [Security Agent](/ru/core-concepts/security/project-security-center#agent-security-scans).

<div id="cve-auto-protect">
  ### CVE Auto-Protect автоматически устраняет критические уязвимости
</div>

Когда для пакета, от которого зависит ваше приложение, публикуется новая критическая уязвимость (CVE), **CVE Auto-Protect** находит совпадения во всех ваших проектах, Agent готовит исправление в фоновой задаче, запускает тесты, чтобы убедиться, что ничего не сломалось, и присылает уведомление со ссылкой на проверку. Пока вы не одобрите исправление, ничего не публикуется — контроль остаётся за вами.

Благодаря этому приложение может быть исправлено уже через несколько минут после публикации новой уязвимости, а не тогда, когда вы сами о ней узнаете.

Подробнее о [CVE Auto-Protect](/ru/core-concepts/security/project-security-center#auto-protect).

<div id="ios-simulator-android-emulator">
  ### Предпросмотр в iOS Simulator или Android Emulator
</div>

<Frame>
  <video autoPlay muted loop playsInline src="/assets/mirror/ios-emulator-9013ff1b602f.mp4" />
</Frame>

Если проект содержит мобильное приложение, теперь настоящий **iOS Simulator** или **Android Emulator** можно транслировать прямо в рабочее пространство через панель предпросмотра. Ни Xcode, ни Android Studio, ни реальное устройство при этом не нужны. Соберите мобильное приложение с помощью Agent, выберите устройство в выпадающем списке панели предпросмотра и нажимайте на экран так, будто держите телефон в руках. Как только Agent внесёт правки, они сразу отобразятся в симуляторе.

Функция доступна платным разработчикам на тарифах Core, Pro и Enterprise в Chrome, Safari и браузерах на базе Chromium. Firefox не поддерживает мобильные симуляторы.

Подробнее: [Предпросмотр в симуляторе или эмуляторе](/ru/ko/features/artifact-types/building-mobile-apps#preview-on-a-simulator-or-emulator).

<div id="section-4">
  ### Добавление мобильного приложения в существующий проект
</div>

<Frame>
  <img src="/assets/mirror/multi-artifact-update-approval-f6fa8b70a100.png" alt="Панель Agent-чата с карточкой подтверждения «Обновить проект для создания мобильного приложения», где предлагается $5 кредитов и есть кнопки «Не сейчас» / «Обновить проект»" width="991" height="589" data-path="images/replitai/multi-artifact-update-approval.png" />
</Frame>

Проекты, созданные до выхода Agent 4, теперь тоже можно обновить для поддержки нескольких artifacts. Это значит, что в проект, который раньше поддерживал только один artifact, можно добавить мобильное приложение, презентацию или другой artifact. При реорганизации проекта Agent сохраняет URL, данные, секреты и деплои. За первые 48 часов после широкого запуска было перенесено более 200 проектов.

Подробнее об [обновлении существующих проектов для поддержки нескольких artifacts](/ru/ko/features/projects-and-artifacts/updating-projects-for-multiple-artifacts).

<div id="plaid">
  ### Запуск коннектора Plaid
</div>

Теперь с помощью коннектора **Plaid** можно подключаться более чем к 12 000 финансовых учреждений. Администратор команды один раз настраивает учётные данные в разделе **Интеграции**, после чего пользователи приложения подтверждают свои банковские счета через Plaid Link. Токены доступа выдаются с областью действия для конкретного пользователя, что обеспечивает конфиденциальность данных.

Создавайте личных финансовых консультантов, работающих с реальными данными о транзакциях, трекеры портфеля в реальном времени, подключённые к брокерским счетам, и многое другое. Демонстрацию и шаги по настройке смотрите на [странице партнёрства Replit x Plaid](https://replit.com/partners/plaid).

Подробнее об [управлении коннекторами](/ru/ko/replitai/managing-connectors).
