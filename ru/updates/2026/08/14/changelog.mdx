<div id="migrate-to-clerk-auth">
  ### Переход на Clerk Auth
</div>

Теперь подходящий App можно перевести с Replit Auth на Clerk Auth. Agent сначала переносит данные учётных записей и только потом обновляет код входа, поэтому вернувшиеся пользователи сохраняют доступ к своим данным.

<div id="share-and-manage-workspace-skills">
  ### Делитесь навыками рабочего пространства и управляйте ими
</div>

Теперь любой участник рабочего пространства может создавать навыки, оставлять их приватными или делиться ими с рабочим пространством. Общие навыки по умолчанию отключены для остальных участников, и каждый сам выбирает, какие из них включить. Администраторы могут управлять всеми навыками рабочего пространства и требовать использования определённых навыков в нём. Обновлённая библиотека навыков упрощает поиск навыков и управление ими.

Подробнее о [навыках Agent](/ru/features/agent/skills).

<div id="teams-and-enterprise">
  ## Teams и Enterprise
</div>

<div id="admin-api-available-in-beta">
  ### Admin API доступен в бета-версии
</div>

Администраторы аккаунтов Enterprise теперь могут создавать ключи API на новой вкладке **Developer** в Settings и использовать Admin API для:

* просмотра рабочих пространств, участников, групп пользователей, проектов и развертываний;
* просмотра использования участниками, проектами и рабочими пространствами за выбранные периоды;
* просмотра и редактирования бюджетов рабочих пространств, групп пользователей и отдельных участников.

Подробнее см. в [документации по Admin API](/ru/teams/admin-api) и [справочнике API](https://api.replit.com/docs).
