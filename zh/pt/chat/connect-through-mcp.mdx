Model Context Protocol (MCP) 是一项用于将 AI 产品连接到工具和数据源的开放标准。它不同于 Replit 的原生集成，但可在你使用 Conversation 时扩展可用工具。

<div id="escolha-a-direo-da-conexo">
  ## 选择连接方式
</div>

* **将 Replit 连接到外部工具：** 添加精选或自定义的 MCP 服务器，让 Replit 能够使用该服务器提供的工具。请仅连接您信任的服务器。
* **通过 MCP 客户端使用 Replit：** 将兼容客户端连接到 Replit MCP Server，以便通过该客户端创建、查找、检查或更新 Replit Apps。

MCP 不同于原生集成和 [Skills](/zh/pt/chat/agent-skills)。集成可连接到受支持的服务。Skills 提供可复用的说明和辅助材料。MCP 通过该协议扩展可用工具。
