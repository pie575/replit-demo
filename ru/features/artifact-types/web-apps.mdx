Веб-приложения — это тип результата по умолчанию на Replit. Когда вы описываете свою идею Agent, он создаёт полностековое веб-приложение, если только вы не укажете другой тип артефакта.

<div id="getting-started">
  ## Начало работы
</div>

Создать веб-приложение можно двумя способами:

* **Ввести prompt**: опишите на главной странице Replit, что вы хотите создать. Agent автоматически создаст веб-приложение.
* **Выбрать из выпадающего списка**: откройте на главной странице список типов приложений, выберите **веб-приложение**, а затем опишите свою идею.

<div id="key-features">
  ## Ключевые возможности
</div>

* **Полностековый по умолчанию**: каждое веб-приложение включает фронтенд и бэкенд. Agent создаёт маршруты API, базу данных и серверную логику по мере того, как они нужны вашему приложению.
* **Адаптивный дизайн**: приложения автоматически подстраиваются под любые размеры экрана.
* **Мгновенная публикация**: публикуйте приложение одним кликом. Replit берёт на себя хостинг, SSL и инфраструктуру.
* **Общая инфраструктура**: если в вашем project несколько артефактов — например, мобильное приложение и дашборд с данными, — все они используют общий бэкенд, базу данных и сервисы.

<div id="use-cases">
  ## Сценарии использования
</div>

* **SaaS-продукты**: создавайте клиентские инструменты, дашборды и платформы.
* **Внутренние инструменты**: создавайте админ-панели, CRM или приложения для рабочих процессов вашей команды.
* **Лендинги**: запускайте маркетинговые сайты с формами, анимацией и динамическим контентом.
* **Маркетплейсы и каталоги**: создавайте сайты объявлений, доски вакансий или платформы для сообществ.
