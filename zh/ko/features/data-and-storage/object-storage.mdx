App Storage 是 Replit 内置的对象存储服务，让你的应用轻松托管和存储图片、视频、文档等上传文件。
存储桶是用来存放文件等对象的容器，其中包含访问策略，用于限制用户或应用程序可以对内容执行哪些操作。

<Info>
  我们已将 <strong>Object Storage</strong> 更名为 <strong>App Storage</strong>。功能没有任何变化，现有的存储桶、权限和编程式访问均可继续正常使用。
</Info>

借助 App Storage，你可以构建以下这类应用：

* **照片分享平台**：让构建者上传、存储并展示图片
* **视频流服务**：处理视频上传，并向观看者分发内容
* **文档管理系统**：安全地存储和整理构建者的文件
* **作品集网站**：用稳定加载的媒体文件展示你的作品
* **文件备份服务**：为构建者的重要文件提供云存储

<Note>
  向 **Agent** 说明你的应用需要处理哪些文件类型，并请它添加 App Storage。Agent 会完成集成设置、创建所需的存储桶，并更新你的应用，使其能够通过身份验证、访问控制等高级功能上传、存储和检索文件。
</Note>

借助 App Storage 工具，你可以在开发环境与生产环境之间，或在不同的 Replit 应用之间无缝共享数据。

<div id="section">
  ## 功能
</div>

<Info>
  App Storage 由 Google Cloud Storage (GCS) 提供支持。
  这意味着你可以享受业界领先的运行时长、可用性和安全性。
</Info>

App Storage 为 Replit 应用提供以下功能：

* **持久化云存储**：存储已发布应用和用户可以持续访问的文件
* **可扩展的文件处理**：无需担心存储容量上限，从容应对不断增长的数据需求
* **跨应用数据共享**：在多个 Replit 应用之间共享存储桶，实现分布式架构
* **编程式访问**：使用直观的 API 上传、下载和管理文件
* **增强的 Agent 集成**：让 Agent 通过高级配置设置 App Storage、检查现有配置，并生成包含身份验证和访问控制的完整后端/前端代码

以下是在 Replit 应用中运用 App Storage 的几种方式：

* 存储用户个人资料照片和上传的媒体文件
* 为电商网站提供商品图片
* 处理表单提交中的文档上传
* 打造文件共享与协作功能
* 构建带有媒体素材库的内容管理系统

<Tip>
  **增强的 Agent 集成**：只需向 [Replit Agent](/zh/ko/features/agent/overview) 输入提示词，即可自动为应用添加 App Storage！Agent 现在可以设置对象存储、检查配置，并生成具备身份验证和访问控制等高级功能的完整后端/前端代码。只需在提示词中提到「App Storage」或「文件存储」即可。

<div id="section-2">
  ## 使用方法
</div>

<Note>
  Replit 应用需要通过 Google Cloud Storage 身份验证，才能访问存储桶及其中的对象。
  如需自动完成身份验证，请使用官方的 Replit App Storage 客户端库。
</Note>

你可以在 Project Editor 中直接访问 App Storage 工具。

<Accordion title="如何访问 App Storage 工具">
  在左侧的 **Tool dock** 中：

  1. 选择 <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="所有工具图标" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**，查看 Project Editor 的工具列表。
  2. 选择 <img class="icon-svg" src="/assets/mirror/object-storage-monoochrome-icon-aaba8f517280.svg" alt="App Storage 图标" width="16" height="16" data-path="images/icons/object-storage-monoochrome-icon.svg" /> **App Storage**。

  在**搜索栏**中：

  1. 选择顶部的 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 放大镜图标，打开搜索工具。
  2. 输入“App Storage”查找该工具，并在结果中选择它。
</Accordion>

如需将新的存储桶与 Replit 应用关联，请先创建一个存储桶。

<Accordion title="如何创建存储桶">
  在 **App Storage** 工具中：

  1. 点击 **Create new bucket**。
  2. 在 **Name** 字段中输入存储桶名称，然后选择 **Create bucket**。

  此时 App Storage 标签页应与下方截图类似。

  <Frame>
    <img src="/assets/mirror/object-storage-empty-bucket-3462e2efb1bc.png" alt="App Storage 工具截图" width="2790" height="1218" data-path="images/databases/object-storage-empty-bucket.png" />
  </Frame>

  如需创建更多存储桶，请打开 **App Storage** 标签页左上角的存储桶下拉菜单，然后选择 **Create new bucket**。
</Accordion>

  ### 查看存储桶 ID

如果你有多个存储桶，请在左上角的下拉菜单中选择正确的存储桶。

<div id="section-4">
  ### 上传或下载对象
</div>

要将对象上传到所选存储桶：

1. 在 **App Storage** 标签页中，进入 **Objects** 界面。
2. 选择 <img class="icon-svg" src="/assets/mirror/upload-file-5894be4232ce.svg" alt="上传文件图标" width="16" height="16" data-path="images/icons/upload-file.svg" /> **Upload files**；如需上传某个文件夹中的所有文件，请选择 <img class="icon-svg" src="/assets/mirror/upload-folder-fc87519bedf9.svg" alt="上传文件夹图标" width="16" height="16" data-path="images/icons/upload-folder.svg" /> **Upload folder**。
   然后在文件对话框中选择一个或多个要上传的文件。
   也可以直接将文件或文件夹拖放到显示存储桶内容的区域。

要从所选存储桶下载对象：

1. 在 **App Storage** 标签页中，进入 **Objects** 界面。
2. 选择文件右侧的 <img class="icon-svg" src="/assets/mirror/download-icon-c7b527953d65.svg" alt="下载图标" width="16" height="16" data-path="images/icons/download-icon.svg" /> 下载图标即可下载。

<div id="section-5">
  ### 用文件夹整理对象
</div>

若要在选定的存储桶中创建文件夹：

1. 在 **App Storage** 标签页中，进入 **Objects** 界面。
2. 在 **Objects** 界面中，选择 <img class="icon-svg" src="/assets/mirror/create-folder-c9acf112a042.svg" alt="创建文件夹图标" width="16" height="16" data-path="images/icons/create-folder.svg" /> **Create Folder**。
3. 输入文件夹名称。

若要在 **Objects** 界面中将对象添加到文件夹，请将对象拖动到目标文件夹上。

若要将对象移动到上级文件夹，请将其拖动到对象列表上方的标题栏，并放到上级文件夹的名称上。

<div id="section-6">
  ### 删除对象或存储桶
</div>

<Warning>
  删除操作无法撤销。在继续之前，请务必备份重要数据。
</Warning>

要永久删除对象，请执行以下操作：

1. 在 **App Storage** 标签页中，进入 **Objects** 界面。
2. 选择待删除对象旁的 <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="删除图标" width="16" height="16" data-path="images/icons/trash-icon.svg" /> 删除图标。
3. 在确认对话框中确认删除。

要删除存储桶及其中的所有对象，请执行以下操作：

1. 在 **App Storage** 标签页中，进入 **Settings** 界面。
2. 确认已在左上角的存储桶下拉菜单中选择了要删除的存储桶。
3. 选择 <img class="icon-svg" src="/assets/mirror/trash-icon-4674cd09b8db.svg" alt="删除图标" width="16" height="16" data-path="images/icons/trash-icon.svg" /> **Delete Bucket**。
4. 在确认对话框中确认删除。

<div id="section-7">
  ### 管理存储桶访问权限
</div>

Replit 会将您创建的所有存储桶关联到您的账户，以便所有 Replit App 都能使用。创建存储桶的 Replit App 会自动获得访问权限。

您可以控制哪些 Replit App 可以访问特定存储桶，从而高效、安全地共享数据。

要允许 Replit App 访问您账户中其他 App 创建的存储桶，请执行以下操作：

1. 在 App Storage 标签页左上角的存储桶菜单中，选择 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" />
   **Add an existing bucket**。
2. 在 **Choose a Bucket** 对话框中，选择要添加的存储桶，然后选择 **Add Bucket to Repl**。

<Frame>
  <img src="/assets/mirror/choose-bucket-dialog-b709aa247a85.png" alt="选择存储桶对话框截图" width="1115" height="457" data-path="images/databases/choose-bucket-dialog.png" />
</Frame>

要撤销 Replit App 的存储桶访问权限，请执行以下操作：

1. 在 **App Storage** 标签页中，前往 **Settings** 页面。
2. 在标签页左上角的存储桶下拉菜单中，选择存储桶名称。
3. 选择 **Remove Bucket from Repl**，然后在确认对话框中确认移除。
