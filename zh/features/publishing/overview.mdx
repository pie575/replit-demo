在 Publishing 工具中，你可以让应用上线，并管理它在网络上的运行方式。它把一切都集中到同一个面板：应用的网址、谁可以使用它、production database、监控、安全，以及控制托管方式的各项设置。

要打开该工具，请在 **Tools** 面板的 **Replit Cloud** 下选择 **Publishing**，或点击 Project Editor 右上角的 **Publish**。

<div id="publish-your-app">
  ## 发布你的应用
</div>

主面板会引导你完成应用上线所需的全部准备。逐项检查后，选择 **Publish**。

<Frame>
  <img src="/assets/mirror/publish-your-app-851815208b8a.png" alt="发布你的应用面板，显示 Publish 按钮上方的域名字段、正在发布的应用、访问设置、数据库设置、监控、安全和互动工具" width="578" height="980" data-path="images/deployments/publish-pane/publish-your-app.png" />
</Frame>

* **Domain**：应用的网址。Replit 会推荐一个 `.replit.app` 名称并检查该名称是否可用。你可以自行更改，也可以在发布后接入[自定义域名](/zh/features/publishing/custom-domains)。
* **What you&#39;re publishing**：即将上线的应用预览，以及它将使用的 URL。
* **Who can access your app**：可选择 **Public**、**Password protected**、**Workspace only** 或 **Invite only**。私有选项会将应用的访问范围限制在你的 workspace 内，或仅限你邀请的人员和群组。详见[应用访问](/zh/features/publishing/private-deployments)。
* **Database settings**：管理发布时应用的 production database 如何创建以及如何填充数据。详见 [production database](/zh/features/data-and-storage/development-and-production)。
* **Monitoring tools**：开启应用监控，在应用宕机时第一时间获知。Replit 会持续检查应用是否在线，并在出现问题时向你发送邮件。详见[监控你的应用](/zh/features/publishing/monitoring-a-deployment)。
* **Security tools**：在发布前运行深度安全扫描。Security Agent 将 AI 与业界领先的静态分析工具相结合，检查你的 project 是否存在漏洞。详见 [Project Security Center](/zh/features/security/project-security-center)。
* **Engagement tools**：开启反馈组件，在已发布应用的一角添加反馈按钮。你可以在收件箱中查看用户提交的反馈，并将其发送给 Agent 进行修复。

<div id="adjust-settings">
  ## 调整设置
</div>

选择 **Adjust settings** (调整设置) 即可手动配置应用的托管方式。大多数构建者无需更改这些设置，Replit 会自动选择合理的默认值。

<Frame>
  <img src="/assets/mirror/adjust-settings-d6e124b2249f.png" alt="调整设置部分，显示部署 类型、机器配置、部署 secrets、部署 地理位置，以及阻止发布存在严重漏洞的应用的开关" width="574" height="794" data-path="images/deployments/publish-pane/adjust-settings.png" />
</Frame>

* **部署 type** (部署 类型) ：用于发布应用的技术。大多数应用推荐使用 **Autoscale**，因为它可以从零弹性扩展至任意需求级别。请参阅 [部署 类型](/zh/features/publishing/deployment-types)对比。
* **Machine configuration** (机器配置) ：运行应用的服务器性能。选择 **Edit** 可更改 CPU、内存以及机器数量上限。面板中会显示每台机器的费用以及流量达到峰值时的费用。详细了解[机器配置](/zh/features/publishing/machine-configuration)。
* **部署 secrets**：应用用于访问 API 和服务的私钥 (用于存放 API 密钥等敏感值的安全隐藏存储区) 。Secrets 会自动从开发环境同步到已发布的应用。详细了解 [Secrets](/zh/core-concepts/project-editor/app-setup/secrets)。
* **部署 geography** (部署 地理位置) ：应用的托管位置。选择更靠近用户的区域可降低延迟。应用一经发布，其自身及相关资源便会锁定在该区域。如需之后更改区域，请对应用执行 remix。详细了解 [project 地理位置](/zh/features/publishing/project-geography)。
* **Block publishing of critical vulnerabilities** (阻止发布存在严重漏洞的应用) ：Replit 在发布前始终会运行安全扫描。此设置用于控制发现严重漏洞时是否阻止发布。详见 [Project Security Center](/zh/features/security/project-security-center)。
