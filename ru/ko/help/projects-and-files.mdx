<AccordionGroup>
  <Accordion title="Как подключить Resend или другой почтовый сервис к Replit App?">
    Откройте проект, перейдите в **Инструменты → Коннекторы**, найдите сервис (например, Resend) и подключите его. После аутентификации API-ключ будет сохранён как секрет проекта. Если вы настраиваете собственный домен для электронной почты, добавьте DNS-записи, указанные сервисом, у вашего DNS-поставщика.

    Список доступных коннекторов см. в разделах [Обзор интеграций](/ru/ko/features/integrations/overview) и [Добавление интеграций](/ru/ko/build/add-integrations).
  </Accordion>

  <Accordion title="Я случайно удалил проект. Можно ли его восстановить?">
    Удалённые проекты можно восстановить в течение ограниченного времени. Откройте Shell проекта и выполните:

    ```bash theme={null}
    trash view
    trash restore your-project-name
    ```

    По истечении срока хранения удалённые проекты удаляются без возможности восстановления. Если этот срок уже истёк, [обратитесь в службу поддержки Replit](https://replit.com/support).
  </Accordion>

  <Accordion title="Как скачать или экспортировать проект Replit?">
    В меню с тремя точками в верхней части дерева файлов выберите **Скачать в формате ZIP**. Скачивание большого проекта может занять некоторое время. Если скачивание не удалось, откройте Shell и выполните `zip -r project.zip .`, затем скачайте `project.zip` из дерева файлов.
  </Accordion>

  <Accordion title="Как поделиться проектом или добавить соавторов?">
    Есть три варианта:

    * **Только для чтения**—установите для конфиденциальности проекта значение «Публичный», чтобы просматривать его мог любой, у кого есть ссылка.
    * **Доступ к редактированию по приглашению**—выберите **Пригласить**, введите имя пользователя или адрес электронной почты и настройте уровень доступа.
    * **Ссылка для присоединения**—создайте ссылку для присоединения в разделе **Пригласить**, и любой, у кого есть ссылка, сможет присоединиться к проекту и редактировать его.

    Core поддерживает до 5 соавторов, а Pro — до 15. Соавторам не нужен платный тариф для редактирования проекта. См. [рабочее пространство](/ru/ko/features/collaboration/workspaces).
  </Accordion>

  <Accordion title="Как подключить репозиторий GitHub к Replit?">
    Подключите учётную запись GitHub в разделе подключённых сервисов, затем откройте [инструмент Git](/ru/ko/features/workspace-tools/git-interface) в проекте и подключите репозиторий. Для двусторонней синхронизации включите автосинхронизацию в панели Git. Чтобы импортировать существующий репозиторий, см. [Импорт от поставщиков](/ru/ko/build/import-from-providers).

    Если синхронизация с Git прервётся, повторно подключите GitHub в разделе подключённых сервисов. Использование детализированного персонального токена доступа обеспечивает более стабильное подключение.
  </Accordion>

  <Accordion title="Repl работает медленно или редактор тормозит — что можно сделать?">
    Если редактор работает медленно, попробуйте следующее:

    * Выполните принудительное обновление: `Cmd+Shift+R` на Mac или `Ctrl+Shift+R` в Windows.
    * Закройте неиспользуемые вкладки файлов.
    * Откройте палитру команд с помощью `Cmd+K` (Mac) или `Ctrl+K` (Windows), найдите и выберите **Restart compute**.
    * Попробуйте другой браузер, чтобы исключить влияние расширений.

    Если медленно выполняется код, а не работает редактор, проверьте наличие ресурсоёмких циклов или ограничений памяти. Использование CPU и памяти можно посмотреть на панели ресурсов в нижней части редактора.
  </Accordion>

  <Accordion title="Как использовать переменные окружения и секреты в проекте?">
    Откройте инструмент **Secrets** (значок замка), выберите **+ Новый секрет**, затем введите ключ и значение. В коде обращайтесь к ним через `process.env.API_KEY` (Node.js) или `os.environ["API_KEY"]` (Python).

    Секреты в разделе разработки [Secrets](/ru/ko/core-concepts/project-editor/app-setup/secrets) доступны только в редакторе. Для развёрнутых App добавьте тот же ключ в секреты деплоя — по замыслу они хранятся отдельно.
  </Accordion>

  <Accordion title="Как использовать секреты учётной записи (Vault)?">
    [Секреты учётной записи](/ru/ko/core-concepts/project-editor/app-setup/secrets) доступны во всех проектах — это удобно для ключей, которые используются повторно. Добавьте их в настройках учётной записи, чтобы они были доступны во всех проектах. Если один и тот же ключ указан и в секретах учётной записи, и в секретах проекта, приоритет имеет значение на уровне проекта.
  </Accordion>

  <Accordion title="Как восстановить Git после конфликтов слияния или при повреждённом состоянии Git?">
    Откройте Shell и выполните `git status`, чтобы проверить, есть ли конфликты.

    <Warning>Следующие две команды удаляют незафиксированные изменения без возможности отмены. Сначала сохраните всё, что хотите оставить, например скопируйте отредактированные файлы за пределы проекта.</Warning>

    Чтобы отбросить локальные изменения и вернуться к последнему чистому состоянию, выполните `git checkout -- .`; чтобы сбросить состояние до последнего коммита, выполните `git reset --hard HEAD`.

    Если папка `.git` повреждена и команды Git завершаются ошибкой, откройте новый чат Agent и вставьте сообщение об ошибке — Agent часто может восстановить репозиторий. См. раздел [Аварийное восстановление](/ru/ko/features/version-control/disaster-recovery).
  </Accordion>

  <Accordion title="Как откатить проект к предыдущему чекпоинту?">
    Replit сохраняет [чекпоинты](/ru/ko/features/version-control/checkpoints-and-rollbacks) во время работы Agent. В панели Agent найдите сообщение перед изменением, которое хотите отменить, выберите рядом с ним пункт «Откат» и подтвердите действие.

    <Note>
      Replit больше не поддерживает откат опубликованных App к предыдущей версии. Чтобы вернуть опубликованное App к предыдущему состоянию, откатите проект к предыдущему чекпоинту (как описано выше), а затем опубликуйте его снова. Чтобы восстановить отдельный файл, откройте его, выберите его имя и используйте **Просмотреть историю**, чтобы восстановить предыдущую версию. Подробнее см. в разделе [История файлов](/ru/ko/features/version-control/file-history).
    </Note>
  </Accordion>

  <Accordion title="Как перенести проект в другую учётную запись Replit?">
    Проект нельзя перенести напрямую, но его можно скопировать. Проще всего предоставить целевой учётной записи доступ к проекту и создать в ней форк. Также можно скачать проект в виде ZIP-архива и загрузить его в новый Repl в другой учётной записи.

    После копирования настройте в новом проекте секреты, базу данных и параметры деплоя — они не входят в копию. Пошаговые инструкции, в том числе по переносу данных базы данных, см. в разделе [Ручное копирование проектов в другое рабочее пространство](/ru/ko/teams/identity-and-access-management/manually-copy-projects).
  </Accordion>
</AccordionGroup>
