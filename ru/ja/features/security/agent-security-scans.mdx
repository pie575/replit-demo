Сканирование безопасности Agent проверяет всю кодовую базу на уязвимости в области безопасности и конфиденциальности. Security Agent сочетает анализ на основе моделей со статическими анализаторами, такими как [Semgrep](https://semgrep.dev/) и [HoundDog.ai](https://hounddog.ai), и выводит результаты в центре безопасности проекта.

Сканирование безопасности Agent доступно всем пользователям платных тарифов Replit. В крупных проектах подробный аудит может занять до 15 минут.

<div id="security-agent">
  ## Что проверяет Security Agent
</div>

После запуска сканирования Security Agent выполняет следующее:

1. Составляет карту маршрутов, API, потоков данных и точек входа.
2. Строит модель угроз приложения.
3. Выполняет статический анализ всей кодовой базы.
4. Оценивает результаты в контексте приложения.
5. Формирует отчёт с результатами для проверки.

Такая проверка помогает выявить небезопасные шаблоны кода — например, SQL-инъекции, межсайтовый скриптинг и подделку межсайтовых запросов, — проблемы конфиденциальности, такие как передача конфиденциальных данных в журналы и сторонние API, а также архитектурные уязвимости в маршрутах, API и потоках данных.

<div id="agent">
  ## Запуск сканирования безопасности Agent
</div>

<Steps>
  <Step title="Откройте Security Center">
    На панели **Tools** в проекте выберите **Security Center**. Также можно выбрать **Review security** в процессе публикации.

    <Frame>
      <img src="/assets/mirror/review-security-button-9331149c28f7.png" alt="Действие «Review security» в процессе публикации" width="1440" height="900" data-path="images/project-security-center/review-security-button.png" />
    </Frame>
  </Step>

  <Step title="Запустите сканирование">
    Выберите **Run scan with Agent**.

    <Frame>
      <img src="/assets/mirror/run-scan-with-agent-f54820ac154a.png" alt="Действие «Run scan with Agent» в центре безопасности проекта" width="1440" height="900" data-path="images/project-security-center/run-scan-with-agent.png" />
    </Frame>
  </Step>

  <Step title="При необходимости добавьте контекст">
    При необходимости добавьте контекст, чтобы сузить модель угроз до определённых областей приложения, а затем запустите сканирование безопасности.

    <Frame>
      <img src="/assets/mirror/scan-options-c2cd398fa78b.png" alt="Параметры сканирования безопасности с полем «Add context» и действием «Start security scan»" width="1440" height="900" data-path="images/project-security-center/scan-options.png" />
    </Frame>
  </Step>

  <Step title="Дождитесь результатов проверки">
    Дождитесь, пока Security Agent завершит проверку. Обычно это занимает несколько минут, а в крупных проектах — до 15 минут.
  </Step>
</Steps>

<div id="section">
  ## Просмотр и исправление результатов
</div>

<Steps>
  <Step title="Просмотрите отчёт">
    Изучите каждый результат и его уровень серьёзности в **Security Center**.
    Отклоните те, которые вы понимаете и принимаете, либо
    отредактируйте их перед отправкой на исправление.
  </Step>

  <Step title="Исправьте подтверждённые результаты с помощью Agent">
    Отправьте подтверждённые проблемы в Agent. Security Agent распределяет
    уязвимости по отдельным задачам, поэтому Agent может работать над
    несколькими исправлениями параллельно.
  </Step>

  <Step title="Запустите сканирование повторно">
    После того как Agent применит исправления, запустите ещё одно сканирование,
    чтобы убедиться, что проблемы устранены. В крупных проектах после
    исправления результатов с высоким уровнем серьёзности могут обнаружиться
    дополнительные.
  </Step>
</Steps>

<div id="level-3">
  ## Когда использовать Level 3
</div>

Сканирование безопасности Agent проверяет исходный код. Если нужно также проверить работающее приложение через взаимодействие с браузером и сетью, воспользуйтесь [тестированием на проникновение методом чёрного ящика Level 3](/ru/ja/features/security/black-box-pen-tests). Level 3 выполняет тестирование методом чёрного ящика и проверку исходного кода параллельно.

<div id="section-2">
  ## Ограничения и рекомендации
</div>

* Сканирование выполняется в инфраструктуре Replit. Replit не передаёт код и данные в Semgrep, HoundDog.ai или другим сторонним сервисам.
* Настройки и результаты сканирования остаются привязанными к Replit App.
* Сканирование не заменяет полноценную проверку безопасности. Используйте его вместе с код-ревью, тестированием, проверкой зависимостей и анализом работающего приложения.
* Запускайте сканирование повторно после крупных изменений в коде, после добавления или обновления зависимостей и перед публикацией новой версии.
