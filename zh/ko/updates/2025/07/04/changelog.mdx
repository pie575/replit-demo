<div id="agent">
  ### Agent 网页搜索
</div>

<Frame>
  <img src="/assets/mirror/web-search-6c28195531d4.jpg" alt="展示网页搜索结果及应用开发来源引用的 Agent 界面" width="1920" height="1080" data-path="images/replitai/web-search.jpg" />
</Frame>

Agent 现在可以通过[网页搜索](/zh/core-concepts/agent/web-search)从互联网获取最新信息。你可以借助最新文档、实时市场数据以及全网的准确信息来构建应用。从此不再受知识截止时间的限制——你的应用随时都能用上最新信息。

<div id="agent-2">
  ### 自定义 Agent 指令
</div>

<Frame>
  <img src="/assets/mirror/replitmd-65360844a148.jpg" alt="展示项目自定义选项的 replit.md 文件" width="1920" height="1080" data-path="images/replitai/replitmd.jpg" />
</Frame>

使用 [replit.md](/zh/core-concepts/agent/replit-dot-md) 打造个性化的 Agent 体验。在这个特殊文件中，你可以定义编码风格、项目默认设置和上下文信息。Agent 会依据经过验证的最佳实践自动生成该文件，你也可以根据自己的工作流对其进行自定义。

  ### Teams App Store 体验
</div>

现在，发现和管理团队应用比以往更加轻松。借助部署页面全新的组织“App Store”体验，你可以为常用应用加注星标、搜索全部部署、查看最近打开的应用，还能根据流量规模发现热门部署。
