Les vérifications de sécurité de l&#39;Agent analysent l&#39;ensemble de votre base de code à la recherche de vulnérabilités de sécurité et de confidentialité. Le Security Agent combine une analyse par modèle et des outils d&#39;analyse statique, tels que [Semgrep](https://semgrep.dev/) et [HoundDog.ai](https://hounddog.ai), puis présente les résultats dans le Centre de sécurité du projet.

Les vérifications de sécurité de l&#39;Agent sont accessibles à tous les créateurs Replit disposant d&#39;un abonnement payant. Sur les projets volumineux, un audit approfondi peut prendre jusqu&#39;à 15 minutes.

<div id="o-que-o-security-agent-revisa">
  ## Ce que le Security Agent examine
</div>

Lorsque vous lancez une analyse, le Security Agent :

1. Cartographie les routes, les API, les flux de données et les points d&#39;entrée.
2. Construit un modèle de menaces pour l&#39;application.
3. Exécute une analyse statique sur l&#39;ensemble de la base de code.
4. Évalue les résultats dans le contexte de l&#39;application.
5. Génère un rapport de résultats que vous pouvez examiner.

La revue peut mettre en évidence des schémas de code non sécurisés, tels que l&#39;injection SQL, le cross-site scripting et le cross-site request forgery ; des problèmes de confidentialité, comme des données sensibles transmises aux logs ou à des API tierces ; ainsi que des vulnérabilités architecturales dans les routes, les API et les flux de données.

<div id="iniciar-uma-verificao-de-segurana-do-agent">
  ## Lancer une analyse de sécurité avec l&#39;Agent
</div>

<Steps>
  <Step title="Ouvrir le Security Center">
    Dans le panneau **Tools** de votre projet, sélectionnez **Security Center**. Vous
    pouvez également sélectionner **Review security** dans le flux de publication.

    <Frame>
      <img src="/assets/mirror/review-security-button-9331149c28f7.png" alt="Action Review security dans le flux de publication" width="1440" height="900" data-path="images/project-security-center/review-security-button.png" />
    </Frame>
  </Step>

  <Step title="Lancer l'analyse">
    Sélectionnez **Run scan with Agent**.

    <Frame>
      <img src="/assets/mirror/run-scan-with-agent-f54820ac154a.png" alt="Action Run scan with Agent dans le Centre de sécurité du projet" width="1440" height="900" data-path="images/project-security-center/run-scan-with-agent.png" />
    </Frame>
  </Step>

  <Step title="Ajouter du contexte si nécessaire">
    Si vous le souhaitez, ajoutez du contexte pour orienter le modèle de menaces vers des zones précises de votre application, puis lancez l&#39;analyse de sécurité.

    <Frame>
      <img src="/assets/mirror/scan-options-c2cd398fa78b.png" alt="Options d'analyse de sécurité avec un champ Add context et l'action Start security scan" width="1440" height="900" data-path="images/project-security-center/scan-options.png" />
    </Frame>
  </Step>

  <Step title="Attendre la fin de la revue">
    Attendez que le Security Agent termine la revue. Cela prend généralement quelques minutes, et jusqu&#39;à 15 minutes pour les projets les plus volumineux.
  </Step>
</Steps>

<div id="revisar-e-corrigir-achados">
  ## Examiner et corriger les résultats
</div>

<Steps>
  <Step title="Examiner le rapport">
    Inspectez chaque résultat et sa gravité dans le **Security Center**.
    Écartez les résultats que vous comprenez et acceptez, ou passez-les en
    revue avant de les envoyer en correction.
  </Step>

  <Step title="Corriger les résultats acceptés avec l'Agent">
    Envoyez les problèmes acceptés à l&#39;Agent. Le Security Agent répartit les
    vulnérabilités en tâches distinctes afin que l&#39;Agent puisse traiter
    plusieurs correctifs en parallèle.
  </Step>

  <Step title="Relancer l'analyse">
    Une fois les correctifs appliqués par l&#39;Agent, lancez une nouvelle analyse
    pour confirmer que les problèmes sont bien résolus. Les projets plus
    volumineux peuvent révéler d&#39;autres problèmes une fois les résultats de
    gravité élevée corrigés.
  </Step>
</Steps>

<div id="quando-usar-o-nvel-3">
  ## Quand utiliser le niveau 3
</div>

Une analyse de sécurité de l&#39;Agent examine le code source. Si vous devez également inspecter l&#39;application en cours d&#39;exécution via des interactions avec le navigateur et le réseau, utilisez un [test d&#39;intrusion en boîte noire de niveau 3](/fr/pt/features/security/black-box-pen-tests). Le niveau 3 exécute le test en boîte noire et la revue du code source en parallèle.

<div id="limitaes-e-boas-prticas">
  ## Limites et bonnes pratiques
</div>

* L&#39;analyse s&#39;exécute sur l&#39;infrastructure de Replit. Replit n&#39;envoie ni votre code ni vos données à Semgrep, HoundDog.ai ou à d&#39;autres tiers.
* La configuration et les résultats de l&#39;analyse restent liés à votre Replit App.
* Une analyse ne constitue pas une revue de sécurité complète. Utilisez-la en complément de la revue de code, des tests, de la revue des dépendances et des vérifications effectuées sur l&#39;application en cours d&#39;exécution.
* Relancez l&#39;analyse après toute modification importante du code, après l&#39;ajout ou la mise à jour de dépendances, et avant de publier une nouvelle version.
