<div id="enterprisesso">
  ### 在线购买 Enterprise，自动设置 SSO
</div>

您现在可以直接通过[定价页面](https://replit.com/pricing)购买 Replit Enterprise 方案，无需联系销售人员。结账后，产品内向导会全程引导您完成单点登录 (SSO) 设置。将身份提供方的值粘贴到 SAML 表单中，Replit 就会自动配置 SSO 连接。无需等待邮件往来，您的团队几分钟内即可开始使用 Enterprise。

<div id="enterprise-2">
  ### Enterprise 工作区的用户支出限额
</div>

Enterprise 管理员现在可以为不同的工作区成员设置不同的 Agent 支出限额。在[使用量页面](https://replit.com/usage)打开 **Agent 用户**表格，选择任意一行的编辑图标即可设置新的限额。用户限额优先于群组和工作区默认限额。这便于为高级用户设置更高的上限，或在不更改工作区其他设置的情况下限制特定成员的支出。

<Frame>
  <img src="/assets/mirror/edit-usage-limit-4a2fba67693a.png" alt="编辑工作区成员使用限额的对话框，显示工作区默认限额、当前用户专属限额、适用的群组限额，以及设置为 $5 的用户阈值输入框" width="1202" height="916" data-path="images/changelog/2026-05-15/edit-usage-limit.png" />
</Frame>

有关详细信息，请参阅[管理支出](/zh/ja/billing/managing-spend#per-user-spend-limits)。

<div id="canvaspng">
  ### 将 Canvas 画框导出为 PNG
</div>

右键点击 Canvas 中的任意 Artifact 或设计框架，然后选择 **导出** &gt; **PNG**，即可下载当前预览的快照。无需手动截图，即可快速在文档、聊天或团队评审中分享视觉预览。导出的图片将与导出时 Canvas 画框中显示的内容完全一致。

<div id="9">
  ### 9 个开箱即用的新连接器
</div>

现有 9 个连接器提供默认认证凭据，只需单击一下即可连接到 Agent，无需先设置自己的 OAuth 应用。只需打开项目的 **Integrations** 面板，选择服务并授权连接即可。

* **Airtable**：读取和写入库、表和记录。
* **GitLab**：访问项目、Issue、Merge Request 和流水线。
* **Basecamp**：读取、写入和管理项目、待办事项列表、消息和日程。
* **Productboard**：读取和写入功能、发布和客户反馈。
* **Teamwork**：读取、写入和管理项目、任务和工时记录。
* **Twitch**：读取直播、频道和观众活动。
* **Square**：接受付款并管理订单、客户和库存。
* **Intercom**：读取和写入对话、联系人和支持工作流。
* **Mailchimp**：读取、写入和管理受众、营销活动和电子邮件营销数据。

请参阅[连接器](/zh/replitai/integrations#available-connectors)，了解更多信息。

<div id="4mcp">
  ### MCP 目录新增 4 个服务器
</div>

[MCP 目录](/zh/replitai/mcp/directory)新增了 4 个托管的 Model Context Protocol 服务器。打开 **Integrations** 面板，在 **Replit Agent 的 MCP 服务器** 中找到相应服务器，然后选择 **添加到 Replit** 进行连接。

* **Twilio**：搜索 Twilio 中有关语音、SMS、电子邮件和身份验证的文档，以及超过 1,800 个 API 端点。
* **Mixpanel**：查询 Mixpanel 的事件、漏斗、留存率和仪表板。
* **Lazyweb**：搜索超过 257,000 个真实 App 界面，用于界面参考和设计研究。
* **Doola**：管理美国 LLC 的注册与成立、会计和税务。

在 [MCP 目录](/zh/replitai/mcp/directory)中查看完整列表。
