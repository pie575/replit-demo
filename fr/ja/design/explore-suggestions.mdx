Les suggestions sont au cœur de l’interface de Replit Design. Au lieu de vous demander quoi écrire dans une zone de saisie vide, sélectionnez un frame de design et Replit Design vous proposera des suggestions à explorer. Chaque suggestion génère une nouvelle proposition en un clic.

<div id="section">
  ## Comment fonctionnent les suggestions
</div>

Lorsque vous sélectionnez un frame généré, des suggestions s’affichent à côté. Elles sont basées sur ce que vous consultez. Vous n’avez donc pas besoin de connaître le jargon du design pour les explorer. Cliquez sur l’une d’elles et Replit Design génère le résultat sous forme d’un nouveau frame. Le frame d’origine reste inchangé.

<div id="section-2">
  ## Ce que proposent les suggestions
</div>

Les suggestions répondent à différentes questions d’exploration :

* **Nouvelles apparences** : présentent le même design sous un angle différent, par exemple dans une variante éditoriale sombre ou avec une mise en page différente.
* **Extensions** : des sections ou des pages suggérées par le design, mais qui n’existent pas encore, comme une section de tarification ou une page de contact.
* **Nouveaux contextes** : placent le design dans un autre contexte, par exemple dans une fenêtre d’affichage mobile.

<div id="section-3">
  ## Explorer avec des suggestions
</div>

Cette boucle est volontairement courte :

<Steps>
  <Step title="Sélectionner un frame généré">
    Cliquez sur n’importe quel frame de design généré sur le Canvas.

    <Frame>
      <img src="/assets/mirror/ambient-select-frame-7147427722bd.png" alt="Un frame Design affichant une page héro gris de supercar sur le Canvas, intitulée APEX X1 Exact Replica" width="2000" height="1252" data-path="images/design/replit-design/ambient-select-frame.png" />
    </Frame>
  </Step>

  <Step title="Choisir une suggestion">
    Des suggestions basées sur ce que vous consultez s’affichent à côté du frame sélectionné. Examinez-les et cliquez simplement sur l’une d’elles, sans rien avoir à ajouter.
  </Step>

  <Step title="Cliquer pour que Agent commence à créer">
    Dès que vous cliquez, Agent commence à créer la suggestion sous la forme d’un nouveau frame à côté du frame d’origine. Les frames précédents restent sur le Canvas : vous ne perdez donc rien en explorant.

    <Frame>
      <img src="/assets/mirror/ambient-suggestion-building-9da4835557d2.png" alt="Un nouveau frame Design intitulé « Add Saturation on Scroll », rendu sous forme de mise en page squelette avec l’indication « Building… ». Le frame APEX X1 d’origine se trouve à côté" width="2000" height="1252" data-path="images/design/replit-design/ambient-suggestion-building.png" />
    </Frame>
  </Step>

  <Step title="Observer les changements">
    Le frame terminé est placé à côté du frame d’origine, ce qui vous permet de les comparer côte à côte. Le panneau Chat affiche un résumé des modifications.

    <Frame>
      <img src="/assets/mirror/ambient-suggestion-result-a50d1efa94c4.png" alt="Deux frames Design terminés côte à côte sur le Canvas : l’original APEX X1 Exact Replica et la variante terminée Add Saturation on Scroll. Le panneau Chat affiche le résumé « Run complete »" width="2000" height="1189" data-path="images/design/replit-design/ambient-suggestion-result.png" />
    </Frame>
  </Step>

  <Step title="Appliquer le design retenu à votre application">
    Continuez à sélectionner des frames et à créer des variantes jusqu’à trouver la direction qui vous convient. De nouvelles suggestions s’affichent selon le frame sélectionné. La suggestion retenue ne doit pas forcément rester une maquette. Sélectionnez-la, choisissez**Build…** dans la barre d’actions, puis sélectionnez une application existante sous **Apply to an existing creation**. Agent réécrit le code de l’application pour correspondre au design, tandis que le frame reste sur le Canvas à titre de référence.

    <Frame caption="Menu Build : appliquer le frame retenu à une application existante.">
      <img src="/assets/mirror/explore-variants-apply-b04b893252cd.png" alt="Le menu Build ouvert sur la variante sélectionnée.     </Frame>

    Pour suivre le processus complet, y compris créer un frame sous forme de nouvelle application, consultez [Créer votre design avec Build](/fr/ja/design/build-your-design). Si vous souhaitez peaufiner les détails avant de l’appliquer, consultez [Peaufiner votre design avec le Chat](/fr/ja/design/chat-about-your-design).
  </Step>
</Steps>

<div id="section-4">
  ## Conseils
</div>

* **Explorez des pistes plutôt que des étapes.** Les suggestions ouvrent des branches : en suivre une ne vous y enferme pas. Générez-en plusieurs et comparez-les sur le Canvas.
* **Ajoutez-y vos propres mots.** Les suggestions et la [zone de chat de conception](/fr/ja/design/chat-about-your-design) fonctionnent de concert. Cliquez sur les suggestions pour explorer différentes pistes, puis utilisez le chat pour orienter précisément. Le chat ne sert pas uniquement aux finitions. Des messages comme *« Essayez de placer la navigation à gauche »* ouvrent aussi de nouvelles pistes.
* **Changez de modèle si vous recherchez une sensibilité différente.** Chaque modèle explore différemment. Consultez [Explorer avec différents modèles](/fr/ja/design/explore-with-different-models).
