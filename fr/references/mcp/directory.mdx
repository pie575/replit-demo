---
title: "Répertoire MCP"
description: "Parcourez les serveurs MCP mis en avant qui connectent l'Agent Replit à vos outils et services préférés."
---

Utilisez ce répertoire pour explorer les serveurs qui exposent des outils spécialisés, des sources de données ou des workflows via le Model Context Protocol (MCP). Chaque entrée inclut un court résumé et un badge Replit pour vous aider à décider quels serveurs connecter à vos projets.

Cette liste n'est pas exhaustive ; vous pouvez [ajouter n'importe quel serveur MCP distant](/fr/features/mcp/overview#add-an-mcp-server) et l'utiliser avec l'Agent Replit.

<Info>
  Cliquez sur le badge **Ajouter à Replit** pour installer n'importe quel serveur. Vous serez invité à autoriser la connexion dans l'Éditeur de projet.
</Info>
