---
title: "Бесплатный режим Agent"
description: "Узнайте, как Бесплатный режим позволяет подписчикам Starter, Core и Pro пользоваться Agent без дополнительной платы."
---

<Note>
  Некоторые параметры квоты могут быть скорректированы ближе к запуску.
</Note>

Бесплатный режим позволяет подписчикам Starter, Core и Pro пользоваться Agent без дополнительной платы. В Starter Бесплатный режим доступен с действующим лимитом. Core и Pro включают квоту Бесплатного режима. Начните чат, чтобы изучить возможности, спланировать, создать что-то или обратиться за помощью. Если для выполнения запроса потребуется платный режим или платное действие, Replit сообщит об этом до начала какой-либо платной операции.

<div id="por-que-voc-vai-gostar">
  ## Почему вам это понравится
</div>

* Начните с беседы вместо настройки.
* Изучайте идеи и двигайтесь дальше, прежде чем решать, нужны ли вам дополнительные ресурсы.
* Сохраняйте контроль, если запрос требует платного действия.
* В бесплатном режиме завершённые задачи помечаются понятной меткой **Бесплатно**.

<div id="como-funciona">
  ## Как это работает
</div>

1. Новые сессии Starter, Core и Pro начинаются в бесплатном режиме.
2. Задачи, которые можно выполнить в бесплатном режиме, продолжаются без запроса на переход к платному режиму.
3. Если для запроса лучше подходит платный режим, Agent объяснит это и предложит выбрать вариант.
4. Вы можете разрешить использовать платный режим только для этого запроса или попросить Agent продолжить в бесплатном режиме.
5. После разового перехода на платный режим вы снова вернётесь в бесплатный режим.

<div id="os-trs-modos-do-agent">
  ## Три режима Agent
</div>

<CardGroup cols={3}>
  <Card title="Бесплатный">
    Бесплатный режим Agent для подписчиков Starter, Core и Pro.
  </Card>

  <Card title="Power">
    Платный режим среднего уровня для задач, требующих больше ресурсов по доступной цене.
  </Card>

  <Card title="Max">
    Платный режим высшего уровня для самых требовательных задач с передовыми моделями.
  </Card>
</CardGroup>

Бесплатный режим доступен подписчикам Starter, Core и Pro. Подписка Starter включает бесплатный режим с действующими лимитами. Подписки Core и Pro включают квоту бесплатного режима, а Pro — более высокий недельный лимит. Если вам потребуется больше ресурсов, вы также можете выбрать платный режим Agent.

<Note>
  **Если вы достигли лимита:** подписка Starter включает бесплатный режим с действующими лимитами. В Core и Pro квота бесплатного режима обновляется каждые пять часов и имеет недельный лимит. Проверьте **Settings → Usage**, чтобы узнать текущий объём использования. Replit предупредит вас при приближении к лимиту. Достигнув лимита, переключитесь на платный режим, чтобы продолжить, или дождитесь обновления квоты.
</Note>

<div id="perguntas-comuns">
  ## Часто задаваемые вопросы
</div>

<AccordionGroup>
  <Accordion title="Действительно ли бесплатный режим бесплатный? Replit теперь бесплатен?">
    Бесплатный режим доступен в подписках Starter, Core и Pro. В Starter бесплатный режим предоставляется с действующим лимитом. Core и Pro включают квоту бесплатного режима. Это не отдельный бесплатный тариф.
  </Accordion>

  <Accordion title="Это то же самое, что платный режим Agent?">
    Нет. Бесплатный режим — это использование Agent без оплаты в пределах вашей квоты. Power и Max — платные режимы для задач, требующих больше ресурсов.
  </Accordion>

  <Accordion title="Что произошло с Economy и Power? Режимы изменились?">
    Платные режимы были переименованы. Economy теперь называется Power — это режим среднего уровня с мощными моделями по доступной цене. Режим, ранее называвшийся Power, теперь называется Max — это платный режим высшего уровня. Существующие настройки режимов сохранены под новыми названиями.
  </Accordion>

  <Accordion title="Какой режим самый мощный?">
    Max. Power — платный режим среднего уровня, предлагающий больше возможностей по доступной цене. Max — платный режим высшего уровня для самых требовательных задач.
  </Accordion>

  <Accordion title="Что, если мой запрос требует платного действия?">
    Agent сообщит, что для запроса требуется платный режим или платная возможность, и попросит подтверждение перед продолжением. Вы можете одобрить этот запрос только один раз или продолжить работу в бесплатном режиме.
  </Accordion>

  <Accordion title="Будет ли с меня автоматически взиматься плата, если Agent предложит повышение тарифа?">
    Нет. Для платного перехода требуется ваше подтверждение до запуска платного запроса.
  </Accordion>

  <Accordion title="Могу ли я отказаться от платной опции?">
    Да. Вы можете продолжить работу в бесплатном режиме.
  </Accordion>

  <Accordion title="Что происходит после одобрения платного перехода?">
    Одобрение действует только для этого запроса. После этого Agent снова переключится в бесплатный режим.
  </Accordion>

  <Accordion title="Почему я достиг ограничения? Когда оно обновится?">
    В Starter бесплатный режим предоставляется с действующим лимитом. Для Core и Pro квота бесплатного режима обновляется каждые пять часов и имеет недельный лимит. Проверьте **Settings → Usage**, чтобы узнать текущий статус. Достигнув лимита, переключитесь на платный режим, чтобы продолжить, или дождитесь обновления.
  </Accordion>

  <Accordion title="Доступен ли бесплатный режим в Enterprise?">
    Не при запуске. Вскоре в рабочих пространствах Enterprise появится отдельный интерфейс Agent. Подробности можно узнать у вашего администратора.
  </Accordion>
</AccordionGroup>

<div id="mais-sobre-o-modo-gratuito">
  ## Подробнее о бесплатном режиме
</div>

<AccordionGroup>
  <Accordion title="Бесплатный режим — это то же самое, что Lite?">
    Для пользователей Starter прежний Lite теперь называется бесплатным режимом. Если вы использовали Lite как менее затратную модель, её по-прежнему можно выбрать вручную в Power, отключив автоматический режим.
  </Accordion>

  <Accordion title="Можно ли создать полноценное приложение в бесплатном режиме?">
    Да. В бесплатном режиме можно создавать и дорабатывать полноценные приложения.
  </Accordion>

  <Accordion title="В чем разница между бесплатным режимом, Power и Max?">
    Бесплатный режим позволяет подписчикам Starter, Core и Pro выполнять повседневные задачи с Agent без дополнительной платы. Starter включает бесплатный режим с действующим лимитом. Core и Pro включают квоту бесплатного режима. Power — это платный режим среднего уровня с большими возможностями по доступной цене. Max — платный режим высшего уровня для самых сложных задач.
  </Accordion>

  <Accordion title="Когда следует переключаться с бесплатного режима?">
    Используйте бесплатный режим для повседневной работы. Переключайтесь, если для сложной задачи нужны более качественные результаты или возможность, которой нет в бесплатном режиме.
  </Accordion>

  <Accordion title="Может ли бесплатный режим генерировать видео?">
    Нет. Генерация видео доступна только в платных режимах и не входит в бесплатный режим.
  </Accordion>

  <Accordion title="Что представляет собой новый формат чатов?">
    Chat и создание приложений теперь объединены. В одном чате можно проработать идею, спланировать работу или начать проект.
  </Accordion>

  <Accordion title="Становятся ли отдельные чаты частью опубликованного приложения?">
    Нет. Чат остается отдельным, пока вы не создадите или не измените проект.
  </Accordion>

  <Accordion title="Может ли бесплатный режим работать с существующим проектом?">
    Да. Он поддерживает регулярное обслуживание и редактирование существующих проектов.
  </Accordion>
</AccordionGroup>

**Готовы попробовать?** Когда бесплатный режим станет доступен, откройте чат с Agent и начните работу.
