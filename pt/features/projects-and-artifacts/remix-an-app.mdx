## O que é um Remix

Um **Remix** é um novo Replit App que você cria a partir de um app ao qual você já tem acesso. Quando você faz remix de um app público ou template, você obtém sua própria cópia para interagir e melhorar de forma iterativa. As mudanças que você faz no seu Remix não afetam o app original.

Seu Remix credita sua fonte: ele mostra um link **Remixed from** de volta ao original, e o prompt de construção do original aparece na sua página de capa.

## O que seu Remix inclui

Um Remix é uma cópia completa e funcional, com uma separação clara do original:

* **Todos os arquivos e configurações** são copiados, para que o app funcione exatamente como o original.
* **O histórico de checkpoints do original** vem junto, identificado como histórico do app de origem. Você pode reverter para qualquer um desses checkpoints; a conversa que os produziu permanece com o original.
* **Um Agent totalmente novo.** Seu Remix começa com um Agent novo e sem histórico de chat herdado.
* **Nomes de secrets, não valores.** Se o app usa secrets (como chaves de API), seu Remix os lista para que você saiba o que preencher, com valores vazios. Os valores só são copiados quando você faz remix do seu próprio app.
* **Um banco de dados novo.** Seu Remix nunca se conecta ao banco de dados do original. Se o original oferecer, uma opção **Copy data from original App** copia os próprios dados; suas alterações ainda assim nunca tocam a fonte.
* **Uma configuração de login nova** para apps que usam Replit Auth.

Não copiado: deployments, domínios e configurações de conectores, que você configura na sua própria cópia. Os Remixes também começam privados, então nada é compartilhado até que você decida publicar.

## Como fazer remix de um app

<Steps>
  <Step title="Abra a página de capa do app">
    Encontre um app do qual queira fazer remix, como um da [comunidade](https://replit.com/community/all). A página de capa dele mostra uma prévia ao vivo e opções de compartilhamento.
  </Step>

  <Step title="Faça o remix do app">
    Selecione **Remix this App** para começar a criar sua própria versão.
  </Step>

  <Step title="Complete os detalhes do app">
    No diálogo **Remix App**, dê um nome à sua cópia e uma descrição opcional, depois selecione **Remix App**. Você pode editar esses detalhes depois.

## Continue construindo no seu Remix

Depois que seu Remix abrir no workspace, use o Agent para modificá-lo e expandi-lo. Digite um prompt na aba **Agent** descrevendo o recurso que você quer adicionar.

Para desfazer as alterações do Agent, selecione **Rollback to here** no Checkpoint criado após a mudança. Saiba mais sobre [Checkpoints e Rollbacks](/pt/features/version-control/checkpoints-and-rollbacks).

## Remix ou construir a partir de um prompt?

Ambos os caminhos terminam no mesmo lugar: um app seu que o Agent ajuda a evoluir. Eles começam de forma diferente:

|                             | Remix                                | Construir a partir de um prompt                   |
| --------------------------- | ------------------------------------ | ------------------------------------------------- |
| Ponto de partida            | Um app funcional, copiado exatamente | Um app que o Agent cria a partir da sua descrição |
| Primeiro resultado          | Imediato e idêntico à fonte          | Demora mais, e o resultado varia                  |
| Primeiro movimento do Agent | Aguarda sua direção                  | Planeja e constrói a partir do seu prompt         |

Se já existe um app próximo do que você quer, faça um remix dele: o primeiro turno do Agent trabalha em um app real e funcional em vez de começar do zero. Construa a partir de um prompt quando sua ideia não se parecer com nada que você consiga encontrar.
