<div id="seo-agent">
  ## Оптимизация с SEO Agent
</div>

[SEO Agent](/ru/ko/features/publishing/seo-agent) проводит технический SEO-аудит деплоенного App и позволяет устранить каждую выявленную проблему одним щелчком. Он доступен в панели **Growth** редактора Project Editor для разработчиков с платным тарифом. Чтобы просканировать App и применить исправления, выполните следующие действия.

<Steps>
  <Step title="Выполните деплой App, чтобы разблокировать Growth">
    SEO Agent работает с развёрнутыми приложениями. До развёртывания панель **Growth** заблокирована и предлагает нажать **Go to Publishing**. Выполните развёртывание через чат Agent или инструмент **Publishing**, затем вернитесь на панель Growth.

    <Frame caption="До развёртывания панель Growth заблокирована и отображает подсказку Go to Publishing">
      <img src="/assets/mirror/01-growth-locked-b05c24711f10.png" alt="Заблокированная панель Growth с заголовком «Разверните приложение, чтобы разблокировать инструмент Growth» и кнопкой Go to Publishing" width="1657" height="947" data-path="images/deployments/seo-agent/01-growth-locked.png" />
    </Frame>
  </Step>

  <Step title="Запустите сканирование с помощью Agent">
    Откройте панель **Growth** и найдите карточку **SEO score**. Выберите **Run scan with Agent**, чтобы запустить технический SEO-аудит проекта. Сканирование обычно занимает несколько минут.

    <Frame caption="Выберите Run scan with Agent на карточке SEO score, чтобы начать аудит">
      <img src="/assets/mirror/02-run-scan-94a2b8918fe9.png" alt="Увеличенное изображение карточки SEO score с кнопкой Run scan with Agent, выделенной красной рамкой" width="1656" height="946" data-path="images/deployments/seo-agent/02-run-scan.png" />
    </Frame>
  </Step>

  <Step title="Редактировать с помощью Agent или отредактировать всё с помощью Agent">
    После завершения сканирования в таблице со столбцами **Severity** (низкий, средний, высокий) и **Status** (не устранено) отобразятся проблемы, сгруппированные по категориям **AI Readiness**, **Crawlability &amp; Discovery**, **Landing Page Rendering &amp; Metadata** и **Performance Proxies**. Раскройте каждую проблему, чтобы узнать, что обнаружил SEO Agent.

    Исправления можно применять с нужной степенью детализации.

    * Чтобы передать Agent только одну проблему, выберите для неё **Fix with Agent**.
    * Чтобы исправить все проблемы в категории, выберите **Fix with Agent** для этой категории.
    * Чтобы передать Agent все проблемы сразу, выберите **Fix all with Agent**. Кнопка **Fix all issues** в чате выполняет ту же функцию.

    <Frame caption="После сканирования исправляйте отдельные проблемы, проблемы в категориях или все проблемы сразу с помощью Fix all with Agent">

    </Frame>

    Agent создаёт задачу по исправлению для каждой проблемы и выполняет её в фоновом режиме, поэтому вы можете продолжать работу над приложением. В строке появляется статус **Fix in progress**, а по ссылке **Go to task** можно открыть задачу и отслеживать её выполнение.

    </Frame>
  </Step>
</Steps>

<Tip>
  Вы также можете полностью пропустить интерфейс сканирования. Откройте Agent и скажите **&quot;optimize my
  SEO&quot;** — Agent получит актуальные результаты и приступит к работе.
</Tip>

Типичные исправления, которые применит Agent:

* Добавляет или переписывает отсутствующие либо стандартные теги `<title>`, чтобы у каждой страницы был уникальный и содержательный заголовок.
* Добавляет метаописания на все страницы.
* Добавляет к изображениям описательный текст `alt`.
* Задаёт атрибут `lang` для элемента `<html>`.
* Проверяет, есть ли у ссылок понятный текст (без «нажмите здесь» и пустых ссылок).
* Добавляет `robots.txt` и `sitemap.xml`.
* Добавляет метатег viewport для отображения на мобильных устройствах.
* Улучшает контрастность текста, не соответствующего требованиям доступности.
* Добавляет метатеги Open Graph и Twitter Card, чтобы ссылки на App корректно отображались в предпросмотре на социальных платформах.

<div id="seo">
  ## Рекомендации по SEO-оптимизации App
</div>

Независимо от того, поручаете ли вы это Agent или делаете всё сами, обратите внимание на следующие ключевые моменты.

* **Задайте уникальные заголовки и метаописания для каждой страницы.** Заголовок должен содержать не более 60 символов, а описание — 150~160 символов.
* **Используйте семантический HTML.** Оберните макет в `<main>`, `<header>`, `<nav>`, `<footer>`. Используйте `<h1>` только один раз на странице и соблюдайте иерархию заголовков.
* **Добавьте alt-текст ко всем изображениям.** Описывайте не то, что изображено, а то, что показывает изображение.
* **Создайте `sitemap.xml` и `robots.txt`.** Попросите Agent создать оба файла, чтобы поисковые системы знали, что нужно сканировать.
* **Добавьте теги Open Graph и карточки Twitter.** Они определяют, как ваше App будет выглядеть при публикации в социальных сетях.
* **Используйте пользовательский домен.** Фирменный домен вызывает доверие и у посетителей, и у поисковых систем. См. раздел [Добавление пользовательского домена](/ru/ko/build/add-custom-domain).
* **Выберите подходящий тип деплоя.** Для сайтов с большим объёмом контента [Статический деплой](/ru/ko/features/publishing/deployment-types#static) предоставляет предварительно отрендеренный HTML, который поисковые системы могут сразу обработать.
* **Добавьте структурированные данные.** Разметка JSON-LD помогает поисковым системам показывать расширенные результаты для продуктов, статей, FAQ и событий.
* **Поддерживайте высокую скорость работы App.** Оптимизируйте изображения, избегайте скриптов, блокирующих рендеринг, и используйте хостинг Replit, чтобы сократить время отклика.

Простой способ применить большинство этих рекомендаций за один раз:

<AiPrompt>
  Проведите аудит SEO моего сайта и внесите необходимые изменения. Добавьте карту сайта, robots.txt, теги Open Graph и структурированные данные там, где это уместно, а также убедитесь, что у всех страниц есть уникальные заголовки и метаописания.
</AiPrompt>

<div id="section-2">
  ## Нужна дополнительная помощь?
</div>

* **Оценка не обновляется после повторного деплоя:** Подождите 1~2 минуты — проверка выполняется асинхронно после завершения деплоя, а значок обновится после получения результатов.
* **Оценка не меняется после изменений, внесённых Agent:** Спросите Agent, какие именно пункты Lighthouse он обработал, и проверьте в подсказке значка, какие пункты всё ещё отмечены.
* **Оценка некоторых страниц ниже, чем у других:** Значок показывает самую низкую оценку среди всех просканированных URL. Попросите Agent сосредоточиться на конкретной странице, указанной Lighthouse.
* **Оценка не отображается в развёрнутом App:** SEO-оценки доступны только для общедоступных типов деплоя (Autoscale, Reserved VM, Static). Зарезервированные и приватные деплои не создают оценок.
