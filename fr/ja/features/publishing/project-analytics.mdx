Project Analytics vous montre comment les internautes découvrent et utilisent vos applications web publiées. Ouvrez le volet **Growth** pour consulter les tendances de visite, les sources de trafic et les événements personnalisés.

Replit collecte les indicateurs de trafic par défaut des applications publiées compatibles. Avec les forfaits payants, Agent peut ajouter des événements personnalisés et répondre à vos questions sur les analyses.

<div id="section">
  ## Avant de commencer
</div>

Project Analytics nécessite les éléments suivants :

* **Un site web publié.** Analytics prend en charge les [artifacts](/fr/ja/features/projects-and-artifacts/artifacts) de type site web. Aucun événement n&#39;est collecté depuis les applications mobiles ni depuis les autres types d&#39;artifacts.
* **Un deployment compatible.** Project Analytics prend en charge les deployments [Autoscale](/fr/ja/features/publishing/deployment-types#autoscale), [Reserved VM](/fr/ja/features/publishing/deployment-types#reserved-vm) et [Static](/fr/ja/features/publishing/deployment-types#static).
* **Un forfait payant pour les analyses avancées.** Les événements personnalisés et les requêtes d&#39;analyse via l&#39;Agent sont disponibles avec un forfait payant.
* **L&#39;activation des analyses lors de la prochaine publication.** Activez **Enable analytics**, puis publiez ou republiez votre application : Replit commence alors à collecter les événements.

<div id="project-analytics">
  ## Ouvrir Project Analytics
</div>

1. Ouvrez votre projet dans le Project Editor.
2. Sélectionnez **Tools**.
3. Sous **Replit Cloud**, sélectionnez **Growth**.

<Note>
  Le volet **Growth** reste verrouillé tant que votre application n&#39;est pas publiée. Avant la publication, un message vous invite à
  **Go to Publishing**.
</Note>

Les données d&#39;analyse apparaissent une fois que votre application publiée commence à recevoir du trafic. Pour les nouvelles applications, les graphiques peuvent rester vides tant que personne ne les visite.

<div id="section-2">
  ## Consulter les analyses par défaut
</div>

Les analyses par défaut s&#39;appuient sur les données de trafic IP pour afficher les indicateurs suivants :

* **Visitors** : le nombre approximatif de visiteurs uniques sur la période sélectionnée.
* **Visitors over time (hour)** ou **Visitors over time (day)** : l&#39;évolution de l&#39;activité des visiteurs sur la période sélectionnée.
* **Top Pages** : les pages qui reçoivent le plus de trafic.
* **Top Referrers** : les sites web qui génèrent du trafic vers votre application.
* **Top Countries** : les pays approximatifs de vos visiteurs.
* **Top Browsers** : les navigateurs utilisés par les visiteurs.
* **Top Devices** : les types d&#39;appareils utilisés par les visiteurs.

Le menu des périodes vous permet d&#39;afficher des intervalles allant de 6 heures à 30 jours. Le nombre total de visiteurs compare chaque période à la période précédente de même durée.

Si votre application utilise [Replit Auth](/fr/ja/features/auth-and-identity/authentication), le volet affiche également le nombre d&#39;**Unique Logged in Users** pour la période sélectionnée.

<Note>
  Le nombre de visiteurs est approximatif. Il repose sur des données réseau et navigateur,
  et une même personne peut être comptabilisée comme plusieurs visiteurs si elle change d&#39;appareil ou d&#39;un mois civil à l&#39;autre.
</Note>

<div id="agent">
  ## Ajouter des événements personnalisés avec Agent
</div>

Les événements personnalisés mesurent les actions importantes pour votre application : finalisation d&#39;une inscription, choix d&#39;un forfait, envoi d&#39;un formulaire ou validation d&#39;un achat, par exemple.

<Steps>
  <Step title="Ajouter des métriques avec Agent">
    Ouvrez **Growth**. Dans **Advanced analytics**, sélectionnez **Add metrics with
    Agent**. Indiquez à Agent les actions que vous souhaitez mesurer. Agent ajoute le suivi des événements aux endroits pertinents de votre application.
  </Step>

  <Step title="Activer l'analyse et publier">
    Ouvrez **Publishing**, puis lancez une nouvelle publication ou republiez. Sous **Suggested
    add-ons**, activez **Enable analytics**. Publiez ensuite votre application : Replit commence à collecter les pages vues et les événements personnalisés à partir de cette version.
  </Step>
</Steps>

<Tip>
  Vous pouvez aussi demander directement à Agent, depuis le chat, de configurer l&#39;analyse. Si votre application ou vos objectifs de mesure évoluent, demandez à Agent d&#39;ajouter ou de mettre à jour des événements à tout moment.
</Tip>

Replit ajoute le traceur d&#39;analyse à votre application publiée. Vous n&#39;avez pas à ajouter vous-même le script de suivi, l&#39;identifiant du site web ou les variables d&#39;environnement dédiées à l&#39;analyse.

<Warning>
  N&#39;incluez jamais de secrets, d&#39;informations personnelles ni de contenu visiteur en saisie libre dans les noms ou les propriétés de vos événements personnalisés.
</Warning>

<div id="agent-2">
  ## Interroger Agent sur vos analyses
</div>

Une fois que votre application commence à collecter des données, utilisez les puces **Advanced analytics** :

* **Summarize my analytics** : Agent résume les résultats d&#39;analyse de votre projet sur les sept derniers jours.
* **Suggest project improvements** : Agent examine les résultats d&#39;analyse et propose des pistes d&#39;amélioration pour votre projet.

Vous pouvez également poser des questions précises à Agent.

<AiPrompt>
  Compare visitors and completed sign-ups for the past seven days. Show the
  daily trend and identify the pages with the highest conversion rate.
</AiPrompt>

Agent peut analyser les pages vues, les sources de trafic, les événements personnalisés, les propriétés d&#39;événements et les entonnoirs. Il s&#39;appuie sur les données d&#39;analyse de votre projet et renvoie des résultats agrégés.
