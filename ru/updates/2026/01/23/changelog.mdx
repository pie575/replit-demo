<div id="audio-support-in-ai-integrations">
  ### Поддержка аудио в AI-интеграциях
</div>

<Frame>
  <img src="/assets/mirror/screenshot-2026-01-22-at-9-08-38-am_80c7a6b9af74-1f051e99efdc.png" alt="Настройки аудио в AI-интеграциях: параметры транскрибации и вывода" width="2884" height="1768" data-path="images/changelog/2026-01-23/screenshot-2026-01-22-at-9-08-38-am_80c7a6b9af74.png" />
</Frame>

AI-интеграции теперь поддерживают работу с аудио благодаря четырём новым моделям:

* `gpt-4o-transcribe` и `gpt-4o-transcribe-mini` для преобразования речи в текст
* `gpt-4o-audio` и `gpt-4o-audio-mini` для генерации аудио

Создавайте приложения для обработки и генерации аудиоконтента: расшифровывайте подкасты, создавайте голосовых помощников или добавляйте в приложения голосовые интерфейсы.

<div id="web-search-in-agent-automations">
  ### Web Search в автоматизациях Agent
</div>

<Frame>
  <img src="/assets/mirror/image_935f53bc7191-e59f7aee0cd0.png" alt="Agent отправляет сводку исследования с помощью автоматизации" width="1482" height="2492" data-path="images/changelog/2026-01-23/image_935f53bc7191.png" />
</Frame>

Создавайте автоматизации с Web Search без API-ключей. Agent интегрирует встроенный в LLM веб-поиск через AI-интеграции, позволяя проводить исследования по расписанию, создавать новостные сводки и доставлять образовательный контент.

<div id="rulessync-support-for-replitmd">
  ### Поддержка `replit.md` в RulesSync
</div>

Проект с открытым исходным кодом [RulesSync](https://github.com/dyoshikawa/rulesync) теперь поддерживает файлы `replit.md`. Синхронизируйте файлы конфигурации ИИ-агента (`CLAUDE.md`, `AGENT.md` и `replit.md`) между несколькими проектами.
