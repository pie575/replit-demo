export const appIconPrompt = "为 PixelGames 生成 3 个不同的 1024x1024 App 图标概念。";

两个应用商店都要求先提供应用图标，才会受理提交。在 Replit 中，你无需借助额外的设计工具即可直接生成图标。

<div id="section">
  ## 各应用商店的要求
</div>

* **App Store：** 1024×1024，不含透明通道，不要圆角 (Apple 会自动添加) 。
* **Google Play：** 512×512。

<div id="section-2">
  ## 生成
</div>

在发送提示词之前，请切换到 **Design** 模式，这样 Agent 才会生成图像。

<AiPrompt>
  {appIconPrompt}
</AiPrompt>

Agent 会一次生成多个设计方向，你可以先对比再从中挑选。
