Lors de la publication d’une app web sur Replit, un audit d’optimisation pour les moteurs de recherche (SEO) est automatiquement effectué sur vos URL actives et affiche un score SEO de 0 à 100 dans l’outil Publishing. Si ce score peut être amélioré, un seul clic transmet les problèmes concernés à Agent afin que vous puissiez les corriger en quelques secondes.

Pour la plupart des développeurs, le processus est simple : publiez votre app, consultez le score et demandez à Agent d’&quot;optimiser mon SEO&quot;. Cette page explique ce qui se passe en coulisses et comment tirer le meilleur parti de cette fonctionnalité.

<div id="o-que-seo-e-por-que-importa">
  ## Qu&#39;est-ce que le SEO et pourquoi c&#39;est important
</div>

L&#39;optimisation pour les moteurs de recherche (SEO) consiste à concevoir votre site de façon que les moteurs de recherche comme Google puissent le trouver, le comprendre et le classer. Un bon référencement, c&#39;est votre app qui apparaît lorsque les internautes recherchent ce que vous proposez — sans payer de publicité.

Quelques éléments suffisent à déterminer l&#39;essentiel de vos résultats SEO : des titres et descriptions de page clairs, du HTML sémantique, des temps de chargement rapides, des mises en page adaptées aux mobiles, un texte alternatif descriptif sur les images et une structure de site explorable. Les moteurs de recherche récompensent les sites faciles à lire, aussi bien pour les humains que pour les machines.

Si vous lancez une landing page, un site vitrine, un blog, un annuaire ou tout autre projet où la découvrabilité compte, le SEO est l&#39;un des investissements les plus rentables que vous puissiez faire dès le départ.

<div id="como-o-replit-melhora-o-seu-seo-por-padro">
  ## Comment Replit améliore votre SEO par défaut
</div>

Replit prend en charge de nombreux fondamentaux du SEO afin que vous puissiez vous concentrer sur votre contenu et votre produit :

* **Hébergement rapide et distribué à l’échelle mondiale** : les déploiements Replit servent votre app depuis une infrastructure optimisée pour la rapidité, et vous pouvez choisir où elle s’exécute grâce à [Zone géographique de publication](/fr/pt/cloud-services/deployments/publishing-geography).
* **HTTPS par défaut** : chaque app publiée reçoit un certificat TLS géré par Replit, un signal de classement essentiel pour les moteurs de recherche.
* **Domaines personnalisés** : connectez votre propre domaine pour renforcer la confiance et l’autorité de votre marque. Consultez [domaine personnalisé](/fr/pt/cloud-services/deployments/custom-domains).
* **Déploiements statiques pour les sites de contenu** : pour les pages marketing, les blogs et la documentation, les [déploiements statiques](/fr/pt/cloud-services/deployments/static-deployments) fournissent du HTML pré-rendu que les moteurs de recherche explorent facilement.
* **Agent écrit du code optimisé pour le SEO** : lorsque Agent crée vos pages, il produit par défaut du HTML sémantique, un balisage accessible et des balises meta — les mêmes éléments que vérifient les outils de SEO.
* **La fonctionnalité Score SEO** : un audit automatique après chaque publication pour que vous sachiez toujours où vous en êtes, associé à un accès en un clic à Agent pour corriger les problèmes détectés.

<div id="o-recurso-pontuao-de-seo">
  ## La fonctionnalité Score SEO
</div>

Après chaque publication réussie, Replit exécute un audit Lighthouse sur les URL de votre déploiement et en enregistre les résultats. L&#39;outil Publishing affiche alors un Score SEO global pour votre app.

<div id="onde-encontrar">
  ### Où le trouver
</div>

Ouvrez l’outil **Publishing** dans une App publiée. Le score SEO apparaît dans la vue d’ensemble du déploiement, avec les autres détails de Build. Survolez le score pour afficher les actions spécifiques identifiées par Lighthouse sur chaque page.

<div id="como-interpretar-sua-pontuao">
  ### Comment interpréter votre score
</div>

Replit utilise les seuils standards de Lighthouse :

| Score  | Statut      | Signification                                                                                   |
| :----- | :---------- | :---------------------------------------------------------------------------------------------- |
| 90–100 | Bon         | Votre app respecte les bonnes pratiques SEO. Restez vigilant après des changements importants.  |
| 50–89  | À améliorer | Plusieurs problèmes empêchent les moteurs de recherche de bien comprendre l&#39;app.            |
| 0–49   | Mauvais     | Des éléments SEO de base sont absents. Les corriger ne prend généralement que quelques minutes. |

Si votre app comporte plusieurs pages, le badge affiche le score **le plus bas** parmi toutes les URL explorées par Replit, afin que la page la moins performante ressorte en premier au lieu d&#39;être diluée dans la moyenne.

<div id="quando-a-pontuao-calculada">
  ### Quand le score est calculé
</div>

L&#39;audit s&#39;exécute automatiquement après chaque publication réussie. Le score est généralement disponible une à deux minutes après la mise en ligne du déploiement, et l&#39;outil Publishing met à jour le badge dès réception des résultats.

<div id="tipos-de-deployment-compatveis">
  ### Types de déploiement compatibles
</div>

Le Score SEO est calculé pour les déploiements publics accessibles sur le web, dont les moteurs de recherche peuvent explorer les URL :

* [Déploiements Autoscale](/fr/pt/cloud-services/deployments/autoscale-deployments)
* [Déploiements Reserved VM](/fr/pt/cloud-services/deployments/reserved-vm-deployments)
* [Déploiements statiques](/fr/pt/cloud-services/deployments/static-deployments)

Les déploiements planifiés et les déploiements privés ne génèrent pas de Score SEO, car ils ne servent pas de trafic web public.

<div id="otimizar-seo-com-o-agent">
  ## Optimiser le SEO avec Agent
</div>

Lorsque votre score SEO est inférieur à 90, le bouton **Optimize SEO with Agent** s’affiche à côté du score. En le sélectionnant, vous envoyez les actions précises identifiées par Lighthouse — pour chaque URL analysée — directement dans un nouveau chat avec Agent, accompagné d’instructions pour les corriger.

<Tip>
  Vous pouvez aussi ignorer ce bouton. Ouvrez Agent et saisissez **&quot;optimize my SEO&quot;** — Agent utilisera vos derniers résultats Lighthouse et commencera à les traiter.
</Tip>

Une fois les modifications effectuées par Agent, republiez votre app. Le score SEO est recalculé à partir du nouveau build et le badge est automatiquement mis à jour.

Corrections courantes appliquées par Agent :

* Ajouter ou réécrire les balises `<title>` manquantes ou génériques afin que chaque page ait un titre unique et descriptif
* Ajouter une méta-description à chaque page
* Ajouter un texte `alt` descriptif aux images
* Définir l’attribut `lang` sur l’élément `<html>`
* Vérifier que les liens disposent d’un texte reconnaissable (sans « cliquez ici » ni ancres vides)
* Ajouter un fichier `robots.txt` et un `sitemap.xml`
* Ajouter une balise méta viewport pour l’affichage sur mobile
* Améliorer le contraste des couleurs des textes qui ne respectent pas les vérifications d’accessibilité
* Ajouter des balises méta Open Graph et Twitter Card afin que les liens vers votre app s’affichent correctement sur les plateformes sociales

<div id="melhores-prticas-para-um-site-otimizado-para-seo-no-replit">
  ## Bonnes pratiques pour optimiser le référencement naturel de votre site sur Replit
</div>

Que vous demandiez à Agent de s&#39;occuper de ces tâches ou que vous les réalisiez vous-même, voici les actions les plus efficaces pour une app créée sur Replit :

* **Donnez à chaque page un titre unique et une méta-description.** Essayez de limiter les titres à moins de 60 caractères et les descriptions à environ 150 à 160 caractères.
* **Utilisez du HTML sémantique.** Structurez votre disposition avec `<main>`, `<header>`, `<nav>` et `<footer>`. Utilisez `<h1>` une fois par page et organisez les niveaux de titre dans l&#39;ordre.
* **Ajoutez un texte alternatif à chaque image.** Décrivez ce que montre l&#39;image, et pas seulement ce qu&#39;elle est.
* **Générez un `sitemap.xml` et un `robots.txt`.** Demandez à Agent de créer les deux afin que les moteurs de recherche sachent quoi explorer.
* **Ajoutez des balises Open Graph et des Twitter Cards.** Contrôlez l&#39;apparence de votre app lorsqu&#39;elle est partagée sur les réseaux sociaux.
* **Utilisez un domaine personnalisé.** Un domaine à votre marque inspire confiance aux visiteurs comme aux moteurs de recherche. Consultez [Domaines personnalisés](/fr/pt/cloud-services/deployments/custom-domains).
* **Choisissez le type de déploiement approprié.** Pour les sites riches en contenu, les [déploiements statiques](/fr/pt/cloud-services/deployments/static-deployments) fournissent du HTML pré-rendu que les moteurs de recherche interprètent instantanément.
* **Ajoutez des données structurées.** Le balisage JSON-LD aide les moteurs de recherche à afficher des résultats enrichis pour les produits, les articles, les FAQ et les événements.
* **Gardez votre app rapide.** Optimisez les images, évitez les scripts qui bloquent le rendu et tirez parti de l&#39;hébergement Replit pour réduire les temps de réponse.

Une manière simple d&#39;appliquer la plupart de ces pratiques en une seule fois :

</AiPrompt>
