# Preview

> Aprenda como usar o Preview para visualizar e interagir com seu aplicativo web enquanto o desenvolve.

O Preview mostra a saída do seu aplicativo web e oferece ferramentas de desenvolvedor do navegador e
recursos de depuração.

Quando você inicia seu aplicativo web usando o botão **Run**, o Replit atribui a ele uma URL temporária
acessível pela internet. A ferramenta Preview renderiza a página exatamente como você veria
em um navegador. Ela também inclui ferramentas de desenvolvedor com funcionalidade semelhante
à encontrada em navegadores populares.

<Note>
  Preview é o novo nome para Webview.
</Note>

## Recursos

O Preview inclui as seguintes funcionalidades para que você possa testar e depurar seus aplicativos web de forma integrada:

* **Visualização web ao vivo**: Veja seu aplicativo e interaja com ele sem sair da aba do navegador
* **Ferramentas de desenvolvedor**: Use ferramentas integradas para diagnosticar problemas rapidamente
* **Teste responsivo**: Visualize seu aplicativo em diferentes tamanhos de tela de dispositivos móveis

## Uso

A ferramenta Preview abre automaticamente quando você executa um aplicativo web.
Você pode alternar esse comportamento na ferramenta **Configurações do Usuário**, na configuração **Automatic Preview**.

As instruções a seguir explicam como abrir o Preview.

## Barra de localização

A barra de localização no topo da aba **Preview** inclui as seguintes ferramentas:

* **Botão Voltar**: Navegue até a página anterior no histórico de navegação
* **Botão Avançar**: Navegue até a próxima página no histórico de navegação
* **Domínio do app**: Veja informações sobre a URL temporária do seu Replit App selecionando `{...}.replit.dev`
* **Campo de endereço**: Veja o caminho de URL atual ou insira um novo caminho

## Ferramentas do navegador

As ferramentas do navegador no lado direito da barra de localização incluem as seguintes funções:

* **Tamanho de tela**: Selecione entre diferentes predefinições de tamanho de tela de dispositivo para testar designs responsivos
* **Devtools**: Alterne o painel de [ferramentas de desenvolvedor](#Developer_tools)
* **Nova aba**: Abra a URL do seu aplicativo web em uma nova aba do navegador

<Note>
  **Está desenvolvendo um aplicativo mobile?** O painel Preview também suporta a visualização em um **iOS Simulator** ou **Android Emulator**. Consulte [Apps móveis nativos](/pt/features/artifact-types/building-mobile-apps#preview-on-a-simulator-or-emulator) para mais detalhes.
</Note>

## Ferramentas de desenvolvedor

As ferramentas de desenvolvedor, desenvolvidas pelo projeto de código aberto <a href="https://github.com/liriliri/eruda" target="_blank">Eruda</a>, ajudam você a realizar as seguintes tarefas:

* Visualizar e interagir com o console JavaScript no contexto do seu aplicativo
* Inspecionar elementos DOM
* Monitorar requisições de rede
* Configurar preferências de exibição e comportamento

Para acessar as ferramentas de desenvolvedor, selecione o botão <img class="icon-svg" src="https://mintcdn.com/replit/X_IP1EeHGm0cA2VA/images/icons/wrench.svg?fit=max&auto=format&n=X_IP1EeHGm0cA2VA&q=85&s=a540aa91f7b9648546c4490083046bcb" alt="ícone de chave inglesa" width="16" height="16" data-path="images/icons/wrench.svg" /> **Devtools**
no topo da aba **Preview** para alterná-las.

As seções a seguir descrevem as ações que você pode realizar em cada aba das ferramentas de desenvolvedor.

### Console

A aba **Console** exibe os logs JavaScript gerados pelo seu aplicativo.
Nesta aba, você pode realizar as seguintes ações:

* **Limpar saída**: Remova toda a saída do console selecionando o ícone <img class="icon-svg" src="https://mintcdn.com/replit/rJldsgYVucXB_6kW/images/icons/clear.svg?fit=max&auto=format&n=rJldsgYVucXB_6kW&q=85&s=d806051b476ac9cfb4f03c8d98bf9fd9" height="16" width="16" alt="ícone de círculo com barra" data-path="images/icons/clear.svg" /> de círculo com barra.
* **Filtrar saída**: Visualize a saída do console filtrada por tipo (All, Info, Warning ou Error).
* **Filtrar texto correspondente**: Mostre a saída que corresponde ao selecionar o ícone <img class="icon-svg" src="https://mintcdn.com/replit/rJldsgYVucXB_6kW/images/icons/filter.svg?fit=max&auto=format&n=rJldsgYVucXB_6kW&q=85&s=4251c041b4414742ca820fa9d7f17d20" height="16" width="16" alt="ícone de filtro" data-path="images/icons/filter.svg" /> de filtro e inserir o texto.
* **Copiar saída**: Copie mensagens do console selecionadas ao selecionar o botão <img class="icon-svg" src="https://mintcdn.com/replit/rJldsgYVucXB_6kW/images/icons/copy.svg?fit=max&auto=format&n=rJldsgYVucXB_6kW&q=85&s=0c42271e0e5b10f63bd15aa05e29dc6f" height="16" width="16" alt="ícone de copiar" data-path="images/icons/copy.svg" /> de copiar.
* **Executar código JavaScript**: Execute código JavaScript no contexto do seu aplicativo ao selecionar o <img class="icon-svg" src="https://mintcdn.com/replit/rJldsgYVucXB_6kW/images/icons/arrow-right.svg?fit=max&auto=format&n=rJldsgYVucXB_6kW&q=85&s=b35e5bb2c1e3ded1e42accd601849136" height="16" width="16" alt="ícone de seta para a direita" data-path="images/icons/arrow-right.svg" /> colchete angular direito. Insira a expressão e selecione **Execute**.

### Elements

A aba **Elements** permite que você inspecione e modifique a estrutura DOM da página web.

* **Ver detalhes do elemento**: Veja detalhes sobre o elemento DOM e a localização no código HTML
* **Copiar saída**: Copie mensagens do console selecionadas ao selecionar o botão <img class="icon-svg" src="https://mintcdn.com/replit/rJldsgYVucXB_6kW/images/icons/copy.svg?fit=max&auto=format&n=rJldsgYVucXB_6kW&q=85&s=0c42271e0e5b10f63bd15aa05e29dc6f" height="16" width="16" alt="ícone de copiar" data-path="images/icons/copy.svg" /> de copiar.

Use a seleção de seta <img class="icon-svg" src="https://mintcdn.com/replit/rJldsgYVucXB_6kW/images/icons/select.svg?fit=max&auto=format&n=rJldsgYVucXB_6kW&q=85&s=55bc0098436d7e4be1914bb1b5691c96" height="16" width="16" alt="ícone de seleção" data-path="images/icons/select.svg" /> para alternar o modo de seleção.
Após entrar no modo de seleção, selecione um elemento na página web.
O HTML e o CSS desse elemento devem aparecer na aba Elements.

### Network

A aba **Network** monitora as requisições iniciadas pela página web.
Nesta aba, você pode realizar as seguintes ações:

* **Rastrear requisições**: Veja todas as requisições de rede iniciadas pelo seu aplicativo. Selecione uma requisição para ver os detalhes.
* **Filtrar**: Veja resultados correspondentes ao selecionar o ícone <img class="icon-svg" src="https://mintcdn.com/replit/rJldsgYVucXB_6kW/images/icons/filter.svg?fit=max&auto=format&n=rJldsgYVucXB_6kW&q=85&s=4251c041b4414742ca820fa9d7f17d20" height="16" width="16" alt="ícone de filtro" data-path="images/icons/filter.svg" /> de funil para mostrar resultados que correspondem ao seu texto. Insira um filtro vazio para limpá-lo.
* **Copiar**: Copie informações de armazenamento ao selecionar o botão <img class="icon-svg" src="https://mintcdn.com/replit/rJldsgYVucXB_6kW/images/icons/copy.svg?fit=max&auto=format&n=rJldsgYVucXB_6kW&q=85&s=0c42271e0e5b10f63bd15aa05e29dc6f" height="16" width="16" alt="ícone de copiar" data-path="images/icons/copy.svg" /> de copiar.

### Resources

A aba **Resources** mostra os recursos carregados pela página e o armazenamento do navegador, como cookies e armazenamento local.
Você pode visualizar e atualizar listas para os seguintes tipos de recurso:

* Arquivos JavaScript
* Folhas de estilo
* Iframes
* Imagens

Nesta aba, você pode realizar as seguintes ações:

* **Ver armazenamento**: Revise o armazenamento local, o armazenamento de sessão e os cookies.
* **Filtrar**: Veja resultados correspondentes ao selecionar o ícone <img class="icon-svg" src="https://mintcdn.com/replit/rJldsgYVucXB_6kW/images/icons/filter.svg?fit=max&auto=format&n=rJldsgYVucXB_6kW&q=85&s=4251c041b4414742ca820fa9d7f17d20" height="16" width="16" alt="ícone de filtro" data-path="images/icons/filter.svg" /> de funil para mostrar resultados que correspondem ao seu texto. Insira um filtro vazio para limpá-lo.
* **Limpar**: Exclua todos os dados desse tipo de armazenamento ao selecionar o botão <img class="icon-svg" src="https://mintcdn.com/replit/rJldsgYVucXB_6kW/images/icons/clear.svg?fit=max&auto=format&n=rJldsgYVucXB_6kW&q=85&s=d806051b476ac9cfb4f03c8d98bf9fd9" height="16" width="16" alt="ícone de limpar" data-path="images/icons/clear.svg" /> de limpar.
* **Excluir selecionado**: Remova itens de armazenamento ao selecionar o ícone <img class="icon-svg" src="https://mintcdn.com/replit/rJldsgYVucXB_6kW/images/icons/delete.svg?fit=max&auto=format&n=rJldsgYVucXB_6kW&q=85&s=54f83fa5b975b8074fad71ec1d19109a" height="16" width="16" alt="ícone de excluir" data-path="images/icons/delete.svg" /> "X".
* **Copiar**: Copie informações de armazenamento ao selecionar o botão <img class="icon-svg" src="https://mintcdn.com/replit/rJldsgYVucXB_6kW/images/icons/copy.svg?fit=max&auto=format&n=rJldsgYVucXB_6kW&q=85&s=0c42271e0e5b10f63bd15aa05e29dc6f" height="16" width="16" alt="ícone de copiar" data-path="images/icons/copy.svg" /> de copiar.

### Settings

A aba **Settings** permite que você personalize a aparência e o comportamento das ferramentas de desenvolvedor.
Esta aba inclui opções de personalização para o seguinte:

* **Configurações de ferramentas**: Personalize opções que se aplicam a cada aba de ferramenta
* **Controles JavaScript**: Especifique opções de comportamento do JavaScript, como desativá-lo para testar como seu aplicativo se comporta
* **Preferências de exibição**: Altere o tema, o tamanho do painel, a transparência e outros comportamentos das ferramentas de desenvolvedor
