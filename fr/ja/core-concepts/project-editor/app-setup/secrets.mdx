L&#39;outil Secrets stocke et chiffre les **secrets** (informations sensibles de votre application Replit, comme les clés API, les jetons d&#39;authentification ou les chaînes de connexion à une base de données).

Lorsque vous ajoutez un secret, l&#39;outil chiffre automatiquement les données et les met à disposition sous forme de variables d&#39;environnement dans votre application Replit.
Cette approche vous évite de coder en dur vos secrets et réduit ainsi le risque de fuite.

Coder en dur des secrets dans votre base de code peut entraîner des fuites accidentelles dans les cas suivants :

* Partage de code sur GitHub via une application Replit publique ou par copier-coller
* Validation de code dans un dépôt public
* Affichage de code lors d&#39;une diffusion en direct ou d&#39;un partage d&#39;écran

Utilisez l&#39;outil Secrets pour partager votre code en toute sérénité, sans craindre de divulguer vos identifiants.

<div id="section">
  ## Fonctionnalités
</div>

Secrets offre les fonctionnalités suivantes :

* **Chiffrement de bout en bout** : protection automatique des données grâce au chiffrement AES-256 au repos et à TLS en transit
* **Secrets au niveau de l’application** : stockage et gestion de secrets propres à une application Replit donnée
* **Secrets au niveau du compte** : stockage et gestion de secrets disponibles dans toutes vos applications Replit
* **Accès aux variables d’environnement** : accès aux secrets depuis votre code à l’aide de variables d’environnement
* **Accès collaboratif** : partage de secrets avec des collaborateurs et des membres de votre équipe

<div id="section-2">
  ## Utilisation
</div>

<Note>
  Les Secrets sont disponibles pour tous les types de déploiement, à l&#39;exception des déploiements statiques.
</Note>

Les Secrets sont accessibles via l&#39;outil Secrets de l&#39;éditeur de projet.

<Accordion title="Comment accéder aux Secrets">
  Depuis le **dock d&#39;outils** à gauche :

  1. Sélectionnez <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="Icône Tous les outils" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **Tous les outils** pour afficher la liste des outils de l&#39;éditeur de projet.
  2. Sélectionnez <img class="icon-svg" src="/assets/mirror/lock-af402c9618dd.svg" alt="Icône Secrets" width="16" height="16" data-path="images/icons/lock.svg" /> **Secrets**.

  Depuis la **barre de recherche** :

  1. Sélectionnez la <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="Icône loupe" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" />loupe en haut pour ouvrir l&#39;outil de recherche
  2. Saisissez « Secrets » pour trouver l&#39;outil, puis sélectionnez-le dans les résultats.
</Accordion>

<div id="section-3">
  ### Gérer les secrets d&#39;application
</div>

Vous pouvez gérer les secrets au niveau de l&#39;application dans l&#39;onglet **Secrets d&#39;application** du volet **Secrets**.
Cet onglet affiche la liste de tous les secrets associés à votre application Replit.

<Accordion title="Ajouter un secret d'application">
  Pour ajouter un secret :

  1. Sélectionnez **Nouveau secret**.
  2. Saisissez la **Clé** (le nom du secret) et la **Valeur** (le secret lui-même).
  3. Sélectionnez **Ajouter un secret** pour l&#39;enregistrer.
</Accordion>

<Accordion title="Modifier un secret d'application">
  Pour modifier un secret :

  1. Sélectionnez le menu à trois points verticaux <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="icône à trois points verticaux" height="16" width="16" data-path="images/icons/vertical-dots.svg" /> situé à côté du secret.
  2. Sélectionnez **Modifier** dans le menu contextuel.
  3. Mettez à jour le texte du champ **Clé** ou **Valeur**, puis sélectionnez **Mettre à jour le secret** pour enregistrer les modifications ou **Annuler** pour les ignorer.

  Vous pouvez également sélectionner **Modifier au format JSON** ou &#42;&#42;Modifier au format .env&#42;&#42; en bas de l&#39;onglet pour modifier l&#39;ensemble des secrets d&#39;application.
</Accordion>

<Accordion title="Afficher un secret d'application">
  Pour afficher un secret, sélectionnez l&#39;icône en forme d&#39;œil <img class="icon-svg" src="/assets/mirror/eye-8a6472b8a950.svg" alt="icône en forme d'œil" width="16" height="16" data-path="images/icons/eye.svg" /> située à côté du secret.

  Pour masquer un secret, sélectionnez l&#39;icône en forme d&#39;œil barré <img class="icon-svg" src="/assets/mirror/eye-slash-6b4ded538179.svg" alt="icône en forme d'œil barré" width="16" height="16" data-path="images/icons/eye-slash.svg" />.
</Accordion>

<Accordion title="Supprimer un secret d'application">
  Pour supprimer un secret, sélectionnez le menu à trois points verticaux <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" alt="icône à trois points verticaux" height="16" width="16" data-path="images/icons/vertical-dots.svg" /> situé à côté du secret, puis sélectionnez **Supprimer**.
</Accordion>

<div id="section-4">
  ### Gérer les secrets de compte
</div>

Vous pouvez gérer les secrets au niveau du compte dans l&#39;onglet **Secrets du compte** du volet **Secrets**.
Cet onglet affiche uniquement les secrets associés à votre compte Replit.

<Accordion title="Ajouter un secret de compte">
  Pour ajouter un secret au niveau du compte :

  1. Accédez à l&#39;onglet **Secrets du compte**.
  2. Sélectionnez l&#39;icône <img class="icon-svg" src="/assets/mirror/settings-icon-c2664c3691bf.svg" alt="Icône d'engrenage" width="16" height="16" data-path="images/icons/settings-icon.svg" /> pour ouvrir les **paramètres** et gérer les secrets au niveau du compte.
  3. Sélectionnez **Nouveau secret** pour ajouter un secret.
  4. Saisissez la **clé** (le nom du secret) et la **valeur** (le secret lui-même).
  5. Sélectionnez **Enregistrer** pour le sauvegarder.
</Accordion>

<Accordion title="Modifier un secret de compte">
  Pour modifier un secret :

  1. Sélectionnez l&#39;icône crayon <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="Icône crayon" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> située à côté du secret.
  2. Modifiez le texte des champs **clé** ou **valeur**, puis sélectionnez **Enregistrer** pour conserver les modifications ou **Annuler** pour les abandonner.
</Accordion>

<Accordion title="Afficher un secret de compte">
  Pour afficher un secret, sélectionnez l&#39;icône en forme d&#39;œil <img class="icon-svg" src="/assets/mirror/eye-8a6472b8a950.svg" alt="Icône en forme d'œil" width="16" height="16" data-path="images/icons/eye.svg" /> située à côté du secret.

  Pour le masquer, sélectionnez l&#39;icône en forme d&#39;œil barré <img class="icon-svg" src="/assets/mirror/eye-slash-6b4ded538179.svg" alt="Icône en forme d'œil barré" width="16" height="16" data-path="images/icons/eye-slash.svg" />.
</Accordion>

<Accordion title="Lier un secret de compte">
  Pour utiliser un secret au niveau du compte dans une application Replit, vous devez le lier à l&#39;application.
  Pour lier un secret au niveau du compte :

  1. Accédez à l&#39;onglet **Secrets d’application**.
  2. Cochez la case située à gauche du secret.
  3. Sélectionnez **Lier à cette application**.

  Pour délier un secret :

  1. Accédez à l&#39;onglet **Secrets d’application**.
  2. Sélectionnez le menu à trois points verticaux <img class="icon-svg" src="/assets/mirror/vertical-dots-032f1c99d22e.svg" width="16" height="16" alt="Icône à trois points verticaux" data-path="images/icons/vertical-dots.svg" /> situé à côté du secret.
  3. Sélectionnez **Délier**.
</Accordion>

<Accordion title="Supprimer un secret de compte">
  1. Sélectionnez l&#39;icône crayon <img class="icon-svg" src="/assets/mirror/pencil-icon-e778997b3bfc.svg" alt="Icône crayon" width="16" height="16" data-path="images/icons/pencil-icon.svg" /> située à côté du secret.
  2. Sélectionnez **Supprimer**.
</Accordion>

<div id="section-6">
  ### Gérer la visibilité des secrets
</div>

La visibilité des secrets dépend de la manière dont l&#39;application Replit est consultée et du fait que vous en soyez ou non l&#39;auteur.

Vous pouvez partager une application Replit à l&#39;aide de l&#39;une des options suivantes :

* **Multijoueur** : invitez des utilisateurs Replit à collaborer en temps réel
* **Page de couverture** : affichez un aperçu de l&#39;application Replit avec une option de remix
* **Remix** : publiez une application Replit personnelle ou d&#39;organisation pour que d&#39;autres puissent en créer leur propre version

Le tableau ci-dessous indique la visibilité du nom et de la valeur des secrets selon les différents scénarios :

| Méthode d&#39;accès      | Qui                                                                | Peut voir le nom | Peut voir la valeur |
| ------------------------ | ------------------------------------------------------------------ | ---------------- | ------------------- |
| Multijoueur              | Collaborateur multijoueur                                          | ✓                | ✓                   |
| Multijoueur              | Membre de l&#39;organisation (rôle propriétaire)                   | ✓                | ✓                   |
| Multijoueur              | Membre de l&#39;organisation (non propriétaire)                    | ✓                |                     |
| Page de couverture       | Tous les visiteurs                                                 |                  |                     |
| Remix                    | Propriétaire/collaborateur qui remixe sa propre application Replit | ✓                | ✓                   |
| Remix                    | Non-propriétaire/collaborateur qui remixe l&#39;application Replit | ✓                |                     |
| Remix                    | Toute personne qui remixe depuis la page de couverture             | ✓                |                     |
| Remix d&#39;organisation | Membre de l&#39;organisation ayant le rôle propriétaire            | ✓                | ✓                   |
| Remix d&#39;organisation | Membre de l&#39;organisation n&#39;ayant pas le rôle propriétaire  | ✓                |                     |

<Warning>
  Les membres d&#39;une organisation qui n&#39;ont pas le rôle propriétaire ne peuvent pas afficher les valeurs des secrets d&#39;une application Replit, mais ils peuvent y accéder en affichant les variables d&#39;environnement.
</Warning>

<div id="section-7">
  ## Secrets liés à la base de données
</div>

Lorsque vous ajoutez une base de données Replit, l’éditeur de projet crée automatiquement les secrets suivants :

| Secret         | Description                                  |
| -------------- | -------------------------------------------- |
| `DATABASE_URL` | Chaîne de connexion à la base de données SQL |

<Info>
  Les anciennes bases de données de développement Neon peuvent également inclure `PGHOST`, `PGUSER`, `PGPASSWORD`, `PGDATABASE` et `PGPORT`. Les bases de données de développement Replit actuelles utilisent plutôt `DATABASE_URL`.
</Info>

Pour afficher toutes les variables d’environnement d’une application Replit, exécutez `printenv` dans l’outil Shell de l’éditeur de projet ou affichez-les dans votre code.

<div id="section-8">
  ## Variables d&#39;environnement prédéfinies
</div>

Replit définit automatiquement les variables d&#39;environnement suivantes, accessibles depuis votre application :

| Variable d&#39;environnement | Description                                                                                   |
| ---------------------------- | --------------------------------------------------------------------------------------------- |
| `REPLIT_DOMAINS`             | Liste, séparée par des virgules, de tous les domaines associés à l&#39;application Replit     |
| `REPLIT_USER`                | Nom d&#39;utilisateur de l&#39;éditeur actuel, qui peut varier lors des sessions multijoueurs |
| `REPLIT_DEPLOYMENT`          | Définie à `1` si le code s&#39;exécute dans une application publiée, sinon non définie        |
| `REPLIT_DEV_DOMAIN`          | URL de développement sur un domaine `replit.dev`, distincte de l&#39;URL du déploiement       |

Ces variables n&#39;apparaissent pas dans l&#39;outil Secrets, mais vous pouvez y accéder depuis votre code à l&#39;aide de l&#39;objet `os.environ` ou en exécutant `printenv` dans le Shell.
