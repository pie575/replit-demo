O Modo Gratuito permite que assinantes Starter, Core e Pro usem o Agent sem custo adicional. O Starter inclui o Modo Gratuito com seus limites existentes. Core e Pro incluem uma cota do Modo Gratuito. Abra uma conversa para explorar, planejar, criar ou pedir ajuda. Se uma solicitação exigir um modo pago ou uma ação paga, a Replit deixa isso claro antes que algo cobrável seja iniciado.

## Por que você vai gostar

* Comece com uma conversa em vez de um fluxo de configuração.
* Explore ideias e avance antes de decidir se precisa de mais capacidade.
* Mantenha o controle quando uma solicitação exigir uma ação paga.
* Veja um rótulo **Gratuito** claro no trabalho concluído no Modo Gratuito.

## Como funciona

1. Novas sessões Starter, Core e Pro começam no Modo Gratuito.
2. O trabalho que se encaixa no Modo Gratuito continua sem aviso de ação paga.
3. Se um modo pago atenderia melhor a uma solicitação, o Agent explica isso e oferece uma escolha.
4. Você pode autorizar o modo pago apenas para essa solicitação ou pedir ao Agent para continuar no Modo Gratuito.
5. Após uma escalada paga pontual, seu modo volta ao Modo Gratuito.

## Os três modos do Agent

  <Card title="Gratuito">

  </Card>

  <Card title="Power">
    Um modo pago de nível intermediário para trabalhos que precisam de mais capacidade a um preço acessível.
  </Card>

  <Card title="Max">
    Um modo pago de nível superior para os trabalhos mais exigentes, com os melhores modelos de ponta.
  </Card>

O Modo Gratuito está disponível para assinantes Starter, Core e Pro. O Starter inclui o Modo Gratuito com seus limites existentes. Core e Pro incluem uma cota do Modo Gratuito, e o Pro inclui um limite semanal maior. Você também pode escolher um modo pago do Agent quando precisar de mais capacidade.

<Note>
  **Se você atingir um limite:** o Starter inclui o Modo Gratuito com seus limites existentes. Para Core e Pro, a cota do Modo Gratuito é renovada a cada cinco horas e tem um limite semanal. Verifique **Settings → Usage** para ver sua posição. A Replit avisa você conforme se aproxima do limite. Ao atingi-lo, mude para um modo pago para continuar ou aguarde a renovação.
</Note>

## Perguntas comuns

<AccordionGroup>
  <Accordion title="O Modo Gratuito é realmente gratuito? A Replit agora é grátis?">
    O Modo Gratuito está incluído nas assinaturas Starter, Core e Pro. O Starter inclui o Modo Gratuito com seus limites existentes. Core e Pro incluem uma cota do Modo Gratuito. Não é um plano gratuito por si só.
  </Accordion>

  <Accordion title="Isso é o mesmo que um modo pago do Agent?">
    Não. O Modo Gratuito é o uso do Agent sem custo dentro de sua cota. Power e Max são modos pagos para trabalhos que precisam de mais capacidade.
  </Accordion>

  <Accordion title="O que aconteceu com Economy e Power? Os modos mudaram?">
    Os modos pagos foram renomeados. Economy agora é Power, um modo de nível intermediário com modelos poderosos a um preço acessível. O modo antes chamado Power agora é Max, o modo de nível superior. As configurações de modo existentes são mantidas com os novos nomes.
  </Accordion>

  <Accordion title="Qual modo é o mais capaz?">
    Max. Power é o modo pago de nível intermediário para mais capacidade a um preço acessível. Max é o modo pago de nível superior para os trabalhos mais exigentes.
  </Accordion>

  <Accordion title="E se minha solicitação precisar de uma ação paga?">
    O Agent explica que a solicitação precisa de um modo pago ou de uma capacidade paga e pergunta antes de prosseguir. Você pode aprovar essa solicitação uma única vez ou continuar no Modo Gratuito.
  </Accordion>

  <Accordion title="Serei cobrado automaticamente se o Agent sugerir um upgrade?">
    Não. Uma escalada paga exige sua confirmação antes que a solicitação paga seja iniciada.
  </Accordion>

  <Accordion title="Posso recusar a opção paga?">
    Sim. Você pode continuar trabalhando no Modo Gratuito.
  </Accordion>

  <Accordion title="O que acontece depois que eu aprovo uma escalada paga?">
    A aprovação se aplica apenas àquela solicitação. Seu modo do Agent volta ao Modo Gratuito depois.
  </Accordion>

  <Accordion title="Por que atingi um limite? Quando ele é renovado?">
    O Starter inclui o Modo Gratuito com seus limites existentes. Para Core e Pro, a cota do Modo Gratuito é renovada a cada cinco horas e tem um limite semanal. Verifique **Settings → Usage** para ver sua posição. Ao atingir o limite, mude para um modo pago para continuar ou aguarde a renovação.
  </Accordion>

  <Accordion title="O Modo Gratuito está disponível no Enterprise?">
    Não no lançamento. Os workspaces Enterprise terão uma experiência dedicada do Agent logo depois. Seu administrador terá os detalhes.
  </Accordion>
</AccordionGroup>

## Mais sobre o Modo Gratuito

<AccordionGroup>
  <Accordion title="O Modo Gratuito é o mesmo que o Lite?">
    Para usuários Starter, a experiência antes chamada Lite agora é o Modo Gratuito. Se você usava o Lite para um modelo de custo mais baixo, ainda pode selecionar esse modelo manualmente dentro do Power quando desativar o modo automático.
  </Accordion>

  <Accordion title="O Modo Gratuito consegue criar um app completo?">
    Sim. Você pode criar e iterar em apps completos no Modo Gratuito.
  </Accordion>

  <Accordion title="Qual é a diferença entre Free, Power e Max?">
    O Modo Gratuito é o trabalho cotidiano do Agent sem custo para assinantes Starter, Core e Pro. O Starter inclui o Modo Gratuito com seus limites existentes. Core e Pro incluem uma cota do Modo Gratuito. Power é o modo pago de nível intermediário com mais capacidade a um preço acessível. Max é o modo pago de nível superior para os trabalhos mais exigentes.
  </Accordion>

  <Accordion title="Quando devo mudar do Modo Gratuito?">
    Fique no Modo Gratuito para o trabalho cotidiano. Mude quando quiser resultados mais fortes em uma tarefa complexa ou precisar de uma capacidade que o Modo Gratuito não oferece.
  </Accordion>

  <Accordion title="O Modo Gratuito consegue gerar vídeos?">
    Não. A geração de vídeo é uma capacidade de modo pago, não faz parte do Modo Gratuito.
  </Accordion>

  <Accordion title="Qual é a nova experiência de Conversas?">
    Chat e criação ficam juntos. Você pode pesquisar uma ideia, planejar um trabalho ou iniciar um projeto na mesma conversa.
  </Accordion>

  <Accordion title="Chats independentes se tornam parte de um app publicado?">
    Não. Uma conversa permanece separada até você criar ou alterar um projeto.
  </Accordion>

  <Accordion title="O Modo Gratuito consegue trabalhar em um projeto existente?">
    Sim. Ele suporta manutenção de rotina e edições em projetos existentes.
  </Accordion>
</AccordionGroup>

**Pronto para experimentar?** Quando o Modo Gratuito for lançado, abra uma conversa com o Agent e comece.
