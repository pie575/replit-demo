---
title: "静态部署"
description: "了解如何通过静态部署发布静态网站和前端应用。"
---

静态部署会将 Replit App 的静态文件 (如 HTML、CSS 和 JavaScript) 托管在云服务器上。
服务器会自动采用缓存和扩缩容策略，以快速、经济高效地交付您的内容。

静态部署非常适合以下使用场景：

* 营销落地页
* 作品集网站
* 产品和 API 文档网站

<Note>
  静态部署不支持使用 Agent 创建的 Replit Apps。
  Agent 会自动创建需要 backend 服务器的 full-stack 应用。对于
  由 Agent 生成的应用，请使用以下 部署 类型之一：- [自动扩缩部署
  ](/zh/pt/cloud-services/deployments/autoscale-deployments) - [预留 VM
  部署](/zh/pt/cloud-services/deployments/reserved-vm-deployments)
</Note>

<div id="recursos">
  ## 功能
</div>

静态部署提供以下功能：

* **经济实惠的托管**：仅按网站提供的数据量付费。
* **HTTP 路由选项**：配置响应标头、URL 重写规则和重定向。
* **自定义域名**：配置自定义域名，或使用 `<nome-do-app>.replit.app` URL 访问你的 App。
* **自定义错误页面**：创建并提供自定义 404 错误页面。
* **监控**：查看日志并监控已发布 App 的状态。

<div id="uso">
  ## 使用
</div>

你可以在 Project Editor 的 Publishing 工具中访问静态部署。

<Accordion title="如何访问静态部署">
  在左侧的**工具停靠栏**中：

  1. 选择 <img class="icon-svg" src="/assets/mirror/workspace-all-tools-button-7e378364e0b4.svg" alt="所有工具图标" width="16" height="16" data-path="images/icons/workspace-all-tools-button.svg" /> **All tools**，查看 Project Editor 中的工具列表。
  2. 选择 <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Publishing 图标" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publishing**。
  3. 选择 **Static**，然后选择 **Set up your published app**。

  在**搜索栏**中：

  1. 选择顶部的 <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="放大镜图标" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> 放大镜图标，打开搜索工具。
  2. 输入“Publishing”以查找该工具，然后在搜索结果中选择它。
  3. 选择 **Static**，然后选择 **Set up your published app**。
</Accordion>

<div id="domnio-principal">
  ### 主域名
</div>

为已发布 App 的主机名设置子域名部分。发布后，你可以通过 `https://<subdomain>.replit.app` 访问已发布的 App。

如需了解如何使用自定义域名，请参阅[自定义域名](/zh/features/publishing/custom-domains)。

<div id="deployment-privado">
  ### 私有部署
</div>

<Info>
  私有发布 App 功能适用于 Pro 和 Enterprise 套餐。
</Info>

私有发布的 App 仅允许 Workspace 成员，或您邀请的特定用户和群组访问。
发布时，您可以选择 **公开**、**密码保护**、**Workspace only** 或 **Invite only** 访问权限。

要了解如何设置私有部署，请参阅 [App 访问权限](/zh/features/publishing/private-deployments/)。

<div id="diretrio-pblico">
  ### 公共目录
</div>

指定 Replit App 中包含要公开提供的静态文件的根目录路径。
部署后，云端主机将提供该目录中的所有页面和资源。

默认值 `/` 为 Replit App 的根目录。

<div id="build-command">
  ### 构建命令
</div>

指定在创建 部署 时要在 Replit App 的 Shell 中运行的构建命令。

例如，如果您使用 <a href="https://gohugo.io/" target="_blank">Hugo</a> 构建静态网站，可以使用 `hugo --minify` 命令生成文件并压缩资源大小。

<div id="secrets-do-deployment">
  ### 部署 Secrets
</div>

选择 **Add deployment secret**，添加构建命令安全运行所需的环境变量或 secrets。

例如，如果您的网站生成器需要 API 密钥来创建静态网站，您可以将其传递
为 `API_KEY=<您的 secret 名称>`。
