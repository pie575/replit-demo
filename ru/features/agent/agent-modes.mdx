Режимы Agent позволяют выбирать баланс между стоимостью и возможностями при работе с Agent. В выпадающем меню настроек Agent выберите **Free Mode**, **Power Mode** или **Max Mode**. В Free Mode всегда используется интеллектуальная маршрутизация моделей. В режимах Power и Max разработчики планов Core и Pro могут выбрать **Auto**, чтобы Replit подбирал модель для каждой задачи. Также можно выбрать модель вручную с помощью [Model selector](/ru/features/agent/model-selector). Набор доступных режимов и настроек зависит от вашего плана и workspace.

<Note>
  Режим Economy Mode больше не доступен. Его заменяет Power Mode по той же цене.
</Note>

<Tip>
  **Сочетание клавиш:** нажмите **⌘+Shift+I** (Ctrl+Shift+I в Windows), чтобы
  переключаться между режимами Agent, не покидая поле ввода чата.
</Tip>

<div id="free-mode">
  ## Free Mode
</div>

**Оптимизирован для первых шагов.** Free Mode помогает изучать идеи, разобраться в том, как работает Replit, и начать project.

**Обратите внимание:** Free Mode всегда использует интеллектуальную маршрутизацию моделей. Чтобы выбрать модель вручную, используйте Power Mode или Max Mode.

<Note>
  {FreeModePlanAvailability} Когда вы достигнете лимита своего тарифа, Replit
  покажет, когда он обновится.
</Note>

Routines не выполняются в Free Mode. Они работают в Power или Max Mode и требуют бюджета на каждый запуск. Подробнее о [Routines](/ru/chat/routines).

<div id="intelligent-model-routing-auto">
  ## Интеллектуальная маршрутизация моделей (Auto)
</div>

**Оптимизировано для автоматического выбора модели.** В режиме Power Mode или Max Mode разработчики тарифов Core и Pro могут выбрать **Auto**. После этого Replit подбирает для каждой задачи модель в пределах возможностей выбранного режима. См. [Использование интеллектуальной маршрутизации моделей](/ru/chat/auto-mode).

Auto — это платная альтернатива Free Mode. Как и другая работа в режимах Power и Max, он расходует кредиты подписки.

В workspace тарифа Enterprise вместо Free Mode используется единый режим **Auto**. В Enterprise режим Auto может выбирать для каждой задачи как режим, так и разрешённую модель.

<div id="power-mode">
  ## Power Mode
</div>

**Оптимизирован по стоимости.** Power Mode расходует меньше кредитов на задачу и служит оптимальным вариантом по умолчанию, когда нужен хороший результат без оплаты самых мощных моделей.

**Лучше всего подходит для:** повседневной разработки, обучения и экономной работы над существующим проектом.

<div id="max-mode">
  ## Max Mode
</div>

**Оптимизирован для максимальных возможностей.** Max Mode использует более мощные модели для сложных задач, крупных кодовых баз и трудных проблем.

**Лучше всего подходит для:** проектов промышленного уровня, сложных функций и случаев, когда вы хотите получить от Agent наилучший результат.

<div id="which-mode-should-i-use">
  ## Какой режим выбрать?
</div>

Ориентируйтесь на следующее:

| Цель                                                          | Рекомендуемый режим                                                      |
| ------------------------------------------------------------- | ------------------------------------------------------------------------ |
| Опробовать идеи, разобраться в работе Replit и начать project | Free Mode                                                                |
| Доверить Replit выбор модели для платной работы               | Auto в Power Mode или Max Mode                                           |
| Получить максимум prompt на один кредит                       | Power Mode                                                               |
| Сбалансировать стоимость и качество для большинства проектов  | Power Mode                                                               |
| Выбрать модель вручную                                        | Power Mode или Max Mode                                                  |
| Лучший результат в сложных задачах промышленного уровня       | Max Mode                                                                 |
| Максимально возможный результат в самых сложных задачах       | Max Mode с более высоким [уровнем усилий](/ru/features/agent/model-selector#effort) |

Чтобы выбрать режим, откройте выпадающий список настроек Agent в поле чата. В Power или Max разработчики на тарифах Core и Pro могут использовать Auto либо задать [основную модель и уровень усилий](/ru/features/agent/model-selector). Универсального лучшего режима нет — выбирайте тот, который подходит для стоящей перед вами задачи.

<div id="settings-in-shared-projects">
  ## Настройки в общих проектах
</div>

Настройки Agent привязаны к вам, а не к проекту. Когда вы приглашаете коллегу в проект, каждый из вас сохраняет свои собственные значения для:

* режима (Free Mode, Power Mode или Max Mode);
* [основной модели и уровня усилий](/ru/features/agent/model-selector), если они доступны;
* [Plan Mode](/ru/features/agent/plan-mode);
* автослияния для фоновых задач;
* автоодобрения планов.

Если коллега переключится на Max Mode для своей следующей задачи, ваши настройки на Max Mode не переключатся. Режим и настройки, которые вы видите в выпадающем меню настроек Agent, — это именно те, которые Agent применит при отправке вашего следующего сообщения, независимо от того, сколько соавторов работает в проекте.

<div id="check-your-free-mode-usage">
  ## Проверка использования Free Mode
</div>

Откройте **Settings** → **Usage**, чтобы посмотреть текущий лимит Free Mode и время его сброса. Практические советы см. в разделе [Как получить максимум от Free Mode](/ru/chat/free-mode).
