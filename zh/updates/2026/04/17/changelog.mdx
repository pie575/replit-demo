<div id="new-agent-modes-dropdown">
  ### 全新 Agent 模式下拉菜单
</div>

聊天输入框中的 Agent 模式选择器现已改为更简洁的分段控件。你可以直接在工具栏中选择 Lite、Economy 或 Power；需要时，也可在高级设置中使用 Turbo。

新增内容：

* **工具栏中的分段控件。** Lite、Economy 和 Power 并排显示，让你清楚了解当前模式，并可轻松切换。
* **键盘快捷键。** 按 **⌘+Shift+I** (Windows 上为 Ctrl+Shift+I) 即可循环切换模式，无需使用鼠标。
* **Turbo 以橙色突出显示。** Turbo 是速度最快的模式，但成本更高，因此会在界面中突出显示，方便你权衡成本。
* **高级设置默认折叠。** 测试、代码审查和 Turbo 的控制项均位于 **高级设置** 中，让主视图保持简洁。
* **Max 模式已停用。** 如需最强大的构建能力，请使用 Power；如需最快响应，可在高级设置中启用 Turbo。

<div id="agent-suggests-follow-up-tasks">
  ### Agent 建议后续任务
</div>

<Frame>
  <video autoPlay muted loop playsInline src="/assets/mirror/replit-suggested-tasks-b27620d93fd2.mp4" />
</Frame>

Agent 现在会在完成工作后提出**后续任务**，根据项目的完整上下文建议下一步可以构建什么。每个已完成任务下方会显示三类建议：

* **可构建的新功能** — 与你刚刚发布的内容自然契合的功能
* **性能改进** — Agent 在处理任务时发现的优化机会
* **用户体验增强** — 让功能更加完善的细节优化

查看每条建议，在需要的建议上选择 **Accept**，Agent 就会在后台执行这些任务，你可以继续构建。使用 Done 列中的 **Hide suggested tasks** 隐藏不需要的建议，并可随时恢复显示。

详细了解[后续任务建议](/zh/features/agent/follow-up-tasks)。

<div id="projects-page-improvements">
  ### 项目页面改进
</div>

项目页面现推出三项提升使用体验的改进：

* **每张卡片均可预览 artifact。** 每张项目卡片现在都会显示其中各个 artifact 的小图标。将鼠标悬停在任意图标上，即可预览该 artifact 的截图，无需打开项目。
* **默认按你最近打开的项目排序。** 页面现在会将*你*最近处理过的项目置于顶部，让你当前的工作在繁忙的团队 workspace 中始终一目了然。
* **个人置顶。** 将你经常访问的项目置顶。置顶仅对你自己可见，不会影响 workspace 中其他成员看到的内容。

<div id="custom-groups-for-scim-organizations">
  ### SCIM 组织的自定义群组
</div>

启用 SCIM 预配的组织现在可以在 Replit 中创建自定义群组，与通过 IdP 同步的群组并存。自定义群组可用于按项目分配访问权限、一次性授予权限，或创建任何不与身份提供方保持同步的组织结构。

通过 SCIM 同步的群组仍由身份提供方管理；自定义群组则由组织管理员直接在 Replit 中管理。

详细了解 [SCIM](/zh/teams/identity-and-access-management/scim#creating-custom-groups-alongside-scim)。
