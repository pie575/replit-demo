---

Shell позволяет работать с проектами как в обычном терминале: управлять файлами,
устанавливать пакеты и запускать скрипты. Например, вы можете перемещаться по файлам проекта или
использовать `psql`, если в проекте настроено подключение к базе данных.

<Tip>
  Для удобства используйте кнопку **Run**, а не запускайте приложение через Shell.
  Рабочий процесс, запущенный кнопкой **Run**, направляет вывод в инструмент Console,
  где логи можно просматривать в структурированном виде.
</Tip>

<div id="recursos">
  ## Возможности
</div>

Shell предоставляет следующие возможности:

* **Запуск нескольких экземпляров Shell**: открывайте несколько экземпляров Shell, чтобы одновременно работать над разными задачами
* **Поиск текста**: находите нужный текст в выводе Shell

<div id="confirmar-acesso-ao-shell">
  ### Проверка доступа к Shell
</div>

Чтобы убедиться, что Shell готов к работе, и просмотреть текущее рабочее пространство, выполните:

```sh theme={null}
pwd
```

Shell показывает путь к текущему рабочему пространству.

<Frame caption="Команда pwd показывает путь к текущему рабочему пространству и возвращает приглашение Shell.">
  <img src="/assets/mirror/shell-pwd-output-2d31a0e0466b.jpg" alt="Вкладка Shell с командой pwd, путём к рабочему пространству в выводе и вновь появившимся приглашением" width="1280" height="246" data-path="images/workspace/shell-pwd-output.jpg" />
</Frame>

Для проекта с базой данных выберите **Tools** → **Database**, затем откройте страницу
**База данных для разработки**. На этой странице доступны параметры подключения. Не разглашайте
данные для подключения: не копируйте их в документацию, снимки экрана,
логи, файлы исходного кода или общие сообщения.

<div id="pesquisa-de-texto">
  ### Поиск текста
</div>

Чтобы открыть и использовать инструмент поиска текста, выполните следующие действия:

1. Нажмите <img class="icon-svg" src="/assets/mirror/workspace-search-icon-d20ee3e562fb.svg" alt="иконка лупы" width="16" height="16" data-path="images/icons/workspace-search-icon.svg" /> иконку лупы в правом верхнем углу вкладки Shell, чтобы открыть диалоговое окно поиска.
2. Введите поисковый запрос и выберите **Next**, чтобы перейти к следующему совпадению.
3. Используйте **Previous**, чтобы вернуться к предыдущему совпадению.
4. Выберите **Exit** или щёлкните за пределами диалогового окна, чтобы закрыть поиск текста.

<div id="mltiplos-shells">
  ### Несколько Shell
</div>

Чтобы создать ещё один Shell:

1. В заголовке панели Shell откройте меню экземпляров Shell.
2. Выберите **New Shell**.

<Frame>
  <img src="/assets/mirror/shell-new-94a280c1230f.png" alt="Меню экземпляров Shell с текущим рабочим пространством и пунктом New Shell" width="1280" height="224" data-path="images/workspace/shell-new.png" />
</Frame>

Используйте это же меню, чтобы переключаться между Shell. Replit помечает каждый Shell последней выполненной командой, чтобы вам было проще их различать.

<Warning>
  При открытии нескольких Shell Replit автоматически закрывает неактивные
  экземпляры Shell. Неактивный Shell — это Shell, который не выбран и не
  выполняет пользовательские процессы.
</Warning>
