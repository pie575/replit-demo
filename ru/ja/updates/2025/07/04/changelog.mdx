<div id="agentweb-search">
  ### Веб-поиск в Agent
</div>

<Frame>
  <img src="/assets/mirror/web-search-6c28195531d4.jpg" alt="Интерфейс Agent с результатами веб-поиска и ссылками на источники для разработки приложений" width="1920" height="1080" data-path="images/replitai/web-search.jpg" />
</Frame>

Agent может искать в интернете и получать актуальную информацию с помощью [веб-поиска](/ru/core-concepts/agent/web-search). Создавайте приложения, используя новейшую документацию, актуальные рыночные данные и точные сведения со всего интернета. Ограничения, связанные с устареванием знаний, остались в прошлом — ваши приложения могут использовать самую свежую доступную информацию.

<div id="agent">
  ### Пользовательские инструкции Agent
</div>

<Frame>
  <img src="/assets/mirror/replitmd-65360844a148.jpg" alt="Файл replit.md с параметрами настройки проекта" width="1920" height="1080" data-path="images/replitai/replitmd.jpg" />
</Frame>

Персонализируйте работу с Agent с помощью [replit.md](/ru/core-concepts/agent/replit-dot-md). В этом специальном файле можно задать стиль написания кода, настройки проекта и контекст. Agent автоматически создаёт этот файл, используя проверенные рекомендации, а затем вы можете адаптировать его под свой рабочий процесс.

<div id="section-3">
  ### Тарификация на основе усилий
</div>

<Frame>
  <img src="/assets/mirror/effort-based-billing-d971548c7c39.png" alt="Интерфейс тарификации на основе усилий с динамическими ценами, зависящими от усилий Agent" width="2048" height="1424" data-path="images/changelog/2025-07-04/effort-based-billing.png" />
</Frame>

Оцените более продуманный подход к стоимости контрольных точек с новой [тарификацией на основе усилий](/ru/ja/billing/ai-billing). Благодаря динамическому ценообразованию, основанному на фактических усилиях Agent, за один запуск создаётся одна контрольная точка вместо нескольких.

<div id="teamsapp-store">
  ### App Store для Teams
</div>

Находите приложения команды и управляйте ими как никогда раньше. Новый интерфейс org «App Store» на странице Deployments позволяет добавлять приложения в избранное, искать все deployment, просматривать недавно открытые приложения и находить популярные deployment по объёму трафика.
