---
title: "Agent 安全检查"
description: "对源代码进行安全审查、评估发现的问题、使用 Agent 修复漏洞并验证修复结果。"
---

Agent 安全检查会扫描整个代码库，查找安全和隐私漏洞。[Security Agent] 将基于模型的分析与 [Semgrep](https://semgrep.dev/)、[HoundDog.ai](https://hounddog.ai) 等静态分析工具相结合，然后在 Project Security Center 中展示发现项。

所有付费 Replit 创作者均可使用 Agent 安全检查。对于较大的项目，深度审计最多可能需要 15 分钟。

<div id="o-que-o-security-agent-revisa">
  ## Security Agent 会审查什么
</div>

启动检查后，Security Agent 将：

1. 梳理路由、API、数据流和入口点。
2. 为应用构建威胁模型。
3. 对整个代码库进行静态分析。
4. 结合应用上下文评估发现项。
5. 生成发现项报告供你审阅。

审查可能会发现不安全的代码模式，例如 SQL 注入、跨站脚本和跨站请求伪造；隐私问题，例如敏感数据流向日志或第三方 API；以及路由、API 和数据流中的架构漏洞。

<div id="iniciar-uma-verificao-de-segurana-do-agent">
  ## 启动 Agent 安全扫描
</div>

<Steps>
  <Step title="打开安全中心">
    在项目的 **Tools** 面板中，选择 **安全中心**。您
    也可以在部署流程中选择 **Review security**。

    <Frame>
      <img src="/assets/mirror/review-security-button-9331149c28f7.png" alt="部署流程中的 Review security 操作" width="1440" height="900" data-path="images/project-security-center/review-security-button.png" />
    </Frame>
  </Step>

  <Step title="启动扫描">
    选择 **Run scan with Agent**。

    <Frame>
      <img src="/assets/mirror/run-scan-with-agent-f54820ac154a.png" alt="Project 安全中心 中的 Run scan with Agent 操作" width="1440" height="900" data-path="images/project-security-center/run-scan-with-agent.png" />
    </Frame>
  </Step>

  <Step title="必要时添加上下文">
    您可以选择添加上下文，让威胁模型重点关注应用的特定区域，然后启动安全扫描。

    <Frame>
      <img src="/assets/mirror/scan-options-c2cd398fa78b.png" alt="安全扫描选项，包含 Add context 字段和 Start security scan 操作" width="1440" height="900" data-path="images/project-security-center/scan-options.png" />
    </Frame>
  </Step>

  <Step title="等待审核完成">
    等待 Security Agent 完成审核。通常需要几分钟；较大的项目最多可能需要 15 分钟。
  </Step>
</Steps>

<div id="revisar-e-corrigir-achados">
  ## 审查并修复发现项
</div>

<Steps>
  <Step title="审查报告">
    在 **安全中心** 中查看每个发现项及其严重性。忽略你已了解并接受的
    发现项，或在将其提交修复前先进行审查。
  </Step>

  <Step title="使用 Agent 修复已接受的发现项">
    将已接受的问题发送给 Agent。Security Agent 会将
    漏洞组织为独立任务，以便 Agent 能够并行处理
    多项修复。
  </Step>

  <Step title="再次运行检查">
    Agent 应用修复后，再次运行检查，
    确认问题已解决。较大的项目在修复
    严重性较高的发现项后，可能会暴露其他问题。
  </Step>
</Steps>

<div id="quando-usar-o-nvel-3">
  ## 何时使用第 3 级
</div>

Agent 安全扫描会审查源代码。如果还需要通过浏览器和网络交互检查正在运行的应用，请使用[第 3 级黑盒渗透测试](/zh/pt/features/security/black-box-pen-tests)。第 3 级会并行执行黑盒测试和源代码审查。

<div id="limitaes-e-boas-prticas">
  ## 限制与最佳实践
</div>

* 检查在 Replit 的基础设施上运行。Replit 不会将您的代码或数据发送给 Semgrep、HoundDog.ai 或其他第三方。
* 配置和检查结果会始终关联到您的 Replit App。
* 检查并非完整的安全审查。请将其与代码审查、测试、依赖项审查以及对运行中应用的检查结合使用。
* 在代码发生重大更改、添加或更新依赖项后，以及发布新版本前，请重新运行检查。
