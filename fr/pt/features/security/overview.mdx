Lorsque vous publiez depuis Replit, votre projet peut recevoir du trafic réel. Les outils de sécurité de Replit vous aident à détecter les vulnérabilités, à corriger les problèmes avec Agent et à conserver des éléments de preuve pour les audits.

<div id="por-que-a-segurana-importante">
  ## Pourquoi la sécurité est importante
</div>

* Les projets publiés sont accessibles depuis l&#39;internet ouvert, y compris leurs routes et API publiques.
* Les projets modernes reposent sur de nombreux paquets, et de nouvelles CVE peuvent apparaître après la publication.
* Le code généré par l&#39;IA nécessite malgré tout une revue de sécurité, notamment pour l&#39;authentification, les requêtes de base de données, les secrets et le traitement des données.
* Les programmes de conformité exigent souvent des preuves d&#39;inventaire des dépendances, de suivi des vulnérabilités et de correction.

<div id="por-onde-comear">
  ## Par où commencer
</div>

* Vous installez des packages ? Le [Pare-feu de paquets](/fr/pt/features/security/package-firewall) bloque les dépendances malveillantes lors de l’installation et est activé par défaut.
* Vous travaillez sur un seul projet ? Utilisez le [Centre de sécurité du projet](/fr/pt/features/security/project-security-center).
* Vous auditez l’ensemble de votre workspace ? Utilisez le [Centre de sécurité du Workspace](/fr/pt/features/security/workspace-security-center).
* Vous choisissez où s’exécutent les ressources de l’environnement de développement ? Consultez la [géographie du workspace](/fr/features/collaboration/workspace-geography). Pour choisir où s’exécute un projet publié, consultez la [géographie du projet](/fr/pt/features/publishing/project-geography).
* Vous avez besoin d’une définition ? Consultez les [Concepts de sécurité](/fr/pt/features/security/concepts).

Les outils de sécurité de Replit protègent différents aspects du cycle de vie de votre application et fonctionnent de concert :

* **Lors de l’installation :** le [Pare-feu de paquets](/fr/pt/features/security/package-firewall) bloque les packages malveillants et compromis avant leur téléchargement.
* **Après l’installation :** les [analyses automatiques des dépendances](/fr/pt/features/security/project-security-center#automatic-dependency-scans) détectent les CVE récemment divulguées, et Auto-Protect peut préparer des correctifs avec Agent pour y remédier.
* **Avant la publication :** le [Security Agent](/fr/pt/features/security/agent-security-scans) audite votre base de code afin de détecter des vulnérabilités dans le code, les dépendances et la confidentialité.

La plupart des vérifications suivent le même processus : vérifier, examiner les résultats, corriger avec Agent, republier et exporter des preuves si nécessaire.

<div id="onde-a-segurana-fica-no-produto">
  ## Où se situe la sécurité dans le produit
</div>

<div id="em-um-projeto">
  ### Dans un projet
</div>

Dans le panneau **Tools** de votre projet, sélectionnez **Security Center** pour examiner les résultats à l’échelle du projet, lancer des analyses de sécurité avec Agent et vérifier les vulnérabilités des dépendances avant la publication.

Utilisez une [analyse de sécurité avec Agent](/fr/pt/features/security/agent-security-scans) pour examiner le code source. Utilisez un [test d’intrusion black-box de niveau 3](/fr/pt/features/security/black-box-pen-tests) si vous devez également tester l’application en cours d’exécution depuis l’extérieur.

<div id="no-seu-workspace">
  ### Dans votre workspace
</div>

Sélectionnez **Security** dans la barre latérale d’accueil pour consulter les vulnérabilités de vos projets, prioriser les résultats selon leur exposition et suivre l’historique des analyses à l’échelle du workspace.

</Frame>

<div id="na-publicao-e-nas-configuraes">
  ### Dans la publication et les paramètres
</div>

* Dans **Publish** &gt; **Advanced**, utilisez **Block publishing of critical vulnerabilities** pour empêcher la mise en ligne d&#39;applications présentant des vulnérabilités critiques.
* Dans **Settings** &gt; **Account** &gt; **Advanced**, définissez le seuil de gravité d&#39;Auto-Protect pour les correctifs de dépendances préparés par l&#39;Agent.
