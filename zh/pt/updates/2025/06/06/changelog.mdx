<div id="gerenciamento-de-imagens-no-editor-visual">
  ### 可视化编辑器中的图片管理
</div>

在可视化编辑器中管理图片，现在变得轻而易举。选中任意图片，只需更换 URL 或直接上传新文件，即可即时更新。预览实时呈现，更新无缝衔接，让你比以往更快地打造出色的视觉内容。全新界面还带来了更好的响应速度，编辑体验更加流畅。

<div id="novos-pontos-de-entrada-do-agent-no-workspace">
  ### workspace 中全新的 Agent 入口
</div>

我们在整个 workspace 中引入了随处可用的 Agent 入口，帮助你更快地调试和排查问题。现在，Agent 会出现在你最需要帮助的地方，免去在不同工具间来回切换的麻烦。

<Frame>
  <img src="/assets/mirror/cleanshot-2025-06-04-at-113629png-150124-0133e1f81500.png" alt="带有聊天记录的 Ask Agent 界面下拉菜单" width="738" height="301" data-path="images/changelog/2025-06-06/cleanshot-2025-06-04-at-113629png-150124.png" />
</Frame>

无论是代码调试、控制台错误还是部署问题，你都可以就地获得即时帮助。不管是排查运行时错误，还是想弄懂某个复杂函数，Agent 都能提供有针对性的支持，而不会打断你的工作节奏。

<Frame>
  <img src="/assets/mirror/cleanshot-2025-06-04-at-114153png-150113-b2c54f9d8a9a.png" alt="Ask Agent 界面下拉菜单" width="786" height="434" data-path="images/changelog/2025-06-06/cleanshot-2025-06-04-at-114153png-150113.png" />
</Frame>

内置的聊天记录让多次调试之间保持连贯，你可以在此前的对话基础上继续推进，在处理复杂问题时始终不丢失上下文。

<div id="exportao-csv-para-administradores-de-equipes">
  ### 团队管理员 CSV 导出
</div>

组织管理员现在可以将完整的应用列表导出为 CSV 文件，从而更轻松地跟踪、分析组织的 repl 使用情况并生成报告。导出内容包含完整的元数据，例如应用可见性状态和关键使用指标。

<div id="gerenciamento-de-assentos-de-visualizador-para-equipes">
  ### 团队查看者席位管理
</div>

团队现在支持更灵活的席位管理，升级流程也更加简化。查看者可申请升级为成员席位，管理员可直接在成员页面审核并批准这些申请。改进后的成员角色编辑界面让团队管理更加直观、高效。
