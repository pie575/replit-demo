<div id="o-que-uma-visualizao-de-dados">
  ## Что такое визуализация данных?
</div>

Визуализация данных — это интерактивный дашборд или инструмент отчётности, который вы создаёте в диалоге с Agent. Опишите, что хотите визуализировать и где находятся ваши данные — Agent автоматически подберёт подходящие KPI, типы графиков и раскладки, создав полноценный дашборд по одному промпту.

Основные понятия:

* **Создание за один шаг**: Опишите свою цель и источник данных, и Agent создаст полноценный дашборд с подходящими графиками и метриками
* **Подключённые источники данных**: Получайте доступ к базам данных, [коннекторам к хранилищам данных](/ru/pt/connectors/warehouses/overview), внешним API или загруженным файлам
* **Встроенные возможности**: Каждый дашборд включает ручное и автоматическое обновление, экспорт в PDF, экспорт графиков в CSV и светлую/тёмную тему
* **Сводка анализа**: Agent генерирует выводы на основе вашего запроса и полученных данных
* **Несколько артефактов**: Визуализации данных могут использовать тот же бэкенд и базу данных, что и другие ваши артефакты в [одном проекте](/ru/pt/replitai/artifacts#multiple-artifacts-in-one-project)

<div id="como-usar-a-visualizao-de-dados">
  ## Как использовать визуализацию данных
</div>

<div id="criando-a-partir-de-um-prompt">
  ### Создание с помощью промпта
</div>

Выберите вкладку **App** на главной странице и опишите, какой дашборд вам нужен. Agent распознаёт промпты, связанные с данными, и выбирает стек визуализации данных.

**Примеры промптов:**

* &quot;Создайте дашборд для анализа продаж с отслеживанием выручки по регионам&quot;
* &quot;Создайте инструмент для подготовки отчётов с визуализацией наших ежемесячных метрик&quot;
* &quot;Создайте дашборд на основе наших данных о продажах в BigQuery с отображением наиболее успешных продуктов&quot;
* &quot;Подключитесь к Snowflake и создайте дашборд для анализа оттока клиентов&quot;

<div id="criando-a-partir-do-menu-suspenso">
  ### Создание с помощью раскрывающегося меню
</div>

1. Перейдите на вкладку **App** на главной странице.
2. Откройте раскрывающееся меню типа приложения.
3. Выберите **Визуализация данных**.
4. Опишите дашборд или инструмент для работы с данными, который хотите создать.

<div id="conectando-a-data-warehouses">
  ### Подключение к хранилищам данных
</div>

Подключите визуализацию данных к BigQuery, Databricks или Snowflake с помощью [коннекторов данных](/ru/pt/connectors/warehouses/overview), чтобы создавать дашборды на основе имеющихся наборов данных.

При запросе данных из хранилища Agent использует параллельный многоагентный поиск для анализа схемы и наборов данных. Это ускоряет поиск и помогает Agent выбрать нужные таблицы и поля для вашего дашборда.

Чтобы начать, настройте коннектор хранилища в разделе [Интеграции](/ru/replitai/integrations) вашего проекта, а затем сообщите Agent, что вы хотите визуализировать.

<div id="adicionando-filtros-e-recursos">
  ### Добавление фильтров и других возможностей
</div>

После того как Agent создаст ваш дашборд, вы можете попросить его добавить фильтры, детализацию или другие интерактивные элементы. Например, попросите Agent добавить фильтр по диапазону дат, выбор региона или строку поиска.

<div id="exportando-e-compartilhando">
  ### Экспорт и обмен данными
</div>

* **Экспорт в PDF**: Экспортируйте весь дашборд в PDF, чтобы поделиться им или просмотреть его офлайн.
* **Экспорт графиков в CSV**: Скачивайте данные отдельных графиков в виде CSV-файлов для дальнейшего анализа в электронных таблицах или других инструментах.
* **Аналитический документ**: Попросите Agent подготовить подробный аналитический документ на основе данных вашего дашборда.

<div id="o-que-voc-pode-criar">
  ## Что можно создать
</div>

* **Аналитические дашборды**: Отслеживайте ключевые метрики, такие как выручка, регистрации или вовлечённость, в динамике
* **Инструменты отчётности**: Создавайте внутренние отчёты, которые заинтересованные стороны смогут фильтровать и изучать без прямого доступа к базе данных
* **Интерфейсы для исследования данных**: Просматривайте наборы данных и выполняйте запросы к ним с наглядной визуализацией
* **Панели мониторинга**: Отображайте данные из API, баз данных или внешних сервисов в реальном или близком к реальному времени

<div id="perguntas-frequentes">
  ## Часто задаваемые вопросы
</div>

<Accordion title="Какие источники данных можно подключить?">
  Вы можете получать данные из базы данных Replit в вашем проекте, коннекторов к хранилищам данных (BigQuery, Databricks, Snowflake), внешних API или загруженных CSV-файлов. Настройте подключения к хранилищам данных через раздел [Интеграции](/ru/replitai/integrations).
</Accordion>

<Accordion title="Можно ли настроить внешний вид?">
  Да. Цвета, раскладку и типографику можно настраивать в беседе — попросите Agent адаптировать их под ваш бренд или скорректировать дизайн. Дашборды также поддерживают светлую и тёмную темы.
</Accordion>

<Accordion title="Анализирует ли Agent данные за меня?">
  После создания дашборда Agent формирует краткое резюме анализа на основе вашего запроса и полученных данных. Вы также можете запросить более подробный аналитический документ.
</Accordion>

<Accordion title="Можно ли объединить визуализацию данных с другими типами артефактов?">
  Да. Вы можете объединить визуализацию данных с [веб-приложением](/ru/pt/replitai/web-apps), [презентацией](/ru/pt/replitai/slide-decks) или другими типами артефактов в [одном проекте](/ru/pt/replitai/artifacts#multiple-artifacts-in-one-project). Они используют общий бэкенд и базу данных.
</Accordion>
