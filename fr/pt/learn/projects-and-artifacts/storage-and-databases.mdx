Grâce aux solutions de stockage flexibles de Replit, vous pouvez rapidement ajouter le stockage de données adapté aux besoins de votre App. Vous pouvez utiliser la base de données ou le stockage d&#39;objets de Replit pour les Apps répondant aux exigences suivantes, et Agent peut configurer et intégrer automatiquement les deux solutions :

* Un jeu qui doit enregistrer les informations des joueurs, comme leur progression ou leurs meilleurs scores
* Une plateforme de contenu qui gère des fichiers multimédias

<div id="quais-so-as-opes-de-armazenamento-e-banco-de-dados-do-replit">
  ## Quelles sont les options de stockage et de base de données proposées par Replit
</div>

Replit propose les options de stockage de données suivantes :

* **Base de données** : stocke des données structurées, telles que des profils utilisateur, des scores de jeu et des catalogues de produits.
  Vous pouvez stocker et récupérer des données en fonction de leurs attributs et de leurs relations.

* **App Storage** : stocke des données non structurées, telles que des images, des vidéos et des documents.
  Vous pouvez stocker et récupérer des fichiers volumineux et des données binaires.

<div id="comparao-entre-app-storage-e-banco-de-dados">
  ### Comparaison entre App Storage et une base de données
</div>

|                             | Base de données                                               | App Storage                                                  |
| --------------------------- | :------------------------------------------------------------ | :----------------------------------------------------------- |
| **Format de données idéal** | Données structurées avec des relations                        | Fichiers volumineux (images, vidéos, documents)              |
| **Modèle de données**       | Tables, lignes, colonnes                                      | Buckets, fichiers                                            |
| **Langage de requête**      | SQL                                                           | API REST                                                     |
| **Clients**                 | Clients et ORM compatibles avec PostgreSQL                    | SDK Replit et bibliothèques clientes GCS                     |
| **Modèle de facturation**   | Paiement selon le temps de calcul et l&#39;espace de stockage | Paiement selon la bande passante et l&#39;espace de stockage |

<div id="ferramentas-do-editor-de-projeto">
  ### Outils de l’Éditeur de projet
</div>

Découvrez les outils Replit suivants pour configurer et gérer le stockage des données de votre application :

<CardGroup>
  <Card title="Base de données" href="/fr/pt/features/data-and-storage/sql-database" icon="database">
    Idéal pour les données structurées et la modélisation des relations entre elles.
    Repose sur une base de données PostgreSQL entièrement gérée qui évolue avec votre application.
  </Card>

  <Card title="App Storage" href="/fr/pt/features/data-and-storage/object-storage" icon="bucket">
    Idéal pour les données non structurées et les fichiers volumineux, comme les images, les vidéos et les documents.
    Repose sur Google Cloud Storage (GCS) pour une haute disponibilité et une grande évolutivité. Agent peut configurer automatiquement App Storage avec une authentification avancée et des contrôles d’accès.
  </Card>
</CardGroup>
