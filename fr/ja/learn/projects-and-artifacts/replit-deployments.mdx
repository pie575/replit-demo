La publication (Publishing) vous permet de partager votre application Replit avec le monde entier, en toute simplicité.

<Note>
  L&#39;action de mettre votre application en ligne s&#39;appelle la publication (Publishing). Cette page présente les types de déploiements disponibles.
</Note>

<div id="section">
  ## Qu&#39;est-ce que la publication ?
</div>

La publication est la fonctionnalité qui enregistre un **instantané** de votre application Replit dans le cloud afin que tout le monde puisse interagir avec elle. L&#39;instantané capture l&#39;état actuel des fichiers de votre application Replit.

Lorsque vous publiez une application Replit, une **application publiée** est créée. Une application publiée est une instance de votre application qui s&#39;exécute sur l&#39;infrastructure cloud de Replit. Votre application reste ainsi accessible de façon fiable sur Internet, indépendamment de la version présente dans le Project Editor.

<Info>
  L&#39;infrastructure de Replit repose sur Google Cloud Platform (GCP). Toutes les
  applications publiées sont hébergées aux États-Unis. Les clients Enterprise peuvent
  contacter le service commercial pour héberger leurs applications publiées dans l&#39;UE.

  Tous les clients, qu&#39;ils soient particuliers, organisations ou Enterprise, bénéficient d&#39;un projet GCP dédié à locataire unique pour leurs applications publiées. Autrement dit, les ressources de calcul, les secrets et le stockage de vos applications publiées sont entièrement isolés et ne sont jamais partagés avec les applications d&#39;autres clients.
</Info>

Des outils sont inclus pour surveiller l&#39;état de vos applications publiées et consulter les analyses web.

<div id="section-2">
  ## Prise en main
</div>

Suivez les étapes ci-dessous pour publier votre application Replit :

1. Depuis le Project Editor, sélectionnez <img class="icon-svg" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Icône Publier" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Publier** en haut de la page.
2. Dans l&#39;onglet **Publier**, choisissez une option de publication.
3. Si le message **Ajouter un moyen de paiement** s&#39;affiche, suivez les instructions pour en ajouter un.

Replit sélectionne automatiquement l&#39;option de publication la mieux adaptée à votre application, selon le type de projet et vos besoins.

Si vous préférez toutefois choisir un autre type de déploiement, tenez compte des informations suivantes.

<div id="section-4">
  ## Fonctionnalités principales
</div>

La publication offre les fonctionnalités pratiques suivantes :

* **Plusieurs options de publication** : choisissez ou modifiez en quelques clics le type de déploiement adapté à vos besoins.
* **Domaines personnalisés** : diffusez votre application depuis votre propre domaine web.
* **Analytique** : suivez les données de visiteurs et d&#39;autres métriques de vos applications publiées.
* **Outils de surveillance** : consultez l&#39;état et la configuration de vos applications publiées.
* **Contrôle d&#39;accès** : déterminez en un clic qui peut consulter votre application. Réservé aux membres **Pro** et **Enterprise**.
* **Paramètres du badge** : les utilisateurs Core peuvent gérer le badge « Made with Replit » dans les paramètres de publication. Si vous avez publié une application avec le badge sous le plan Starter, sa suppression peut prendre quelques minutes après la mise à niveau.
* **Collecte de retours** : activez les retours sur vos applications publiées pour recueillir les impressions de vos utilisateurs.

<div id="section-5">
  ## Fonctionnement
</div>

Lorsque vous publiez une application Replit, Replit crée un instantané des fichiers et des dépendances de l&#39;application.
Cet instantané est envoyé vers l&#39;infrastructure cloud de Replit, où il s&#39;exécute comme une instance distincte de votre application. Pour mettre à jour une application publiée avec vos modifications les plus récentes, publiez-la à nouveau afin de créer un nouvel instantané.

<Warning>
  Évitez d&#39;enregistrer des données dans le système de fichiers d&#39;une application publiée et d&#39;en dépendre.
  Pour conserver vos données, utilisez les options de stockage et de base de données de Replit, comme Storage et Database ([Stockage et bases de données](/fr/ja/learn/projects-and-artifacts/storage-and-databases)).
</Warning>

<div id="section-6">
  ## Cas d&#39;usage
</div>

Les exemples suivants illustrent différents types d&#39;applications publiées.

<div id="section-7">
  ### Déploiement Autoscale : application de mesure de la vitesse de frappe
</div>

Lorsque des utilisateurs passent un test de frappe, le cloud augmente les ressources, puis les réduit lorsque l&#39;application n&#39;est pas utilisée.

<div id="section-8">
  ### Déploiement statique : simulation du système solaire
</div>

Découvrez les planètes grâce à une application web de visualisation du système solaire.
Cette visualisation est affichée dans le navigateur et ne transmet aucune saisie utilisateur au serveur.

<div id="vmdiscord">
  ### Déploiement sur VM réservée : bot Discord
</div>

Exécutez un bot Discord qui facilite la modération et l&#39;intégration des nouveaux membres.
Avec une tarification et des performances prévisibles, il reste en ligne en permanence pour échanger avec les utilisateurs et répondre aux commandes.

<div id="section-9">
  ### Déploiement planifié : déclencheur domotique
</div>

Planifiez des appels d&#39;API qui allument et éteignent vos appareils connectés à des heures et des jours précis.
