Uma Skill é uma pasta de instruções reutilizáveis e arquivos de apoio. Use uma para personalizar como o Replit aborda uma tarefa, convenção ou fluxo de trabalho repetitivo.

Na caixa de prompt, selecione o menu **mais (+)** e depois **Usar uma skill**. Escolha a Skill que corresponde à tarefa e diga ao Replit o resultado de que você precisa.

## Escolha a conexão certa

* Use uma **Skill** para instruções reutilizáveis, exemplos e material de apoio.
* Use uma [integração](/pt/chat/integrate-your-tools) para um serviço suportado e suas informações ou ações autorizadas.
* Use o [MCP](/pt/chat/connect-through-mcp) para ferramentas expostas por meio de um servidor ou cliente MCP compatível.
