<div id="agent-suggests-connectors-when-several-fit">
  ### 적합한 connector가 여러 개일 때 Agent가 후보를 제안합니다
</div>

Agent에게 서비스 연결을 요청했을 때 적합한 provider가 여러 개라면, 이제 Agent가 간단한 목록을 보여주므로 원하는 것을 직접 고를 수 있습니다. 이전에는 Agent가 먼저 follow-up 질문을 해야 했습니다. provider를 선택하고 한 번만 로그인하면 Agent가 이어서 빌드를 진행합니다.

<div id="workspace">
  ## Workspace
</div>

<div id="meet-the-new-tools-pane">
  ### 새로워진 Tools pane을 소개합니다
</div>

앱에서 사용할 수 있는 모든 기능이 이제 workspace 안 한곳에 모였습니다. 새로 고정된 Tools pane에서 Database, Auth, Domains, Secrets 등을 한 자리에서 확인할 수 있습니다. 덕분에 전체 도구를 한눈에 쉽게 찾을 수 있습니다. 도구 자체가 바뀐 것은 아니며, 자리만 더 알아보기 쉽게 정리되었습니다.

</Frame>

[Tools pane](/ko/features/editor/editor-and-tools)에 대해 자세히 알아보세요.

<div id="a-faster-task-sidebar">
  ### 더 빨라진 task 사이드바
</div>

task 사이드바가 더 조밀하고 한눈에 훑어보기 쉬운 task 내비게이터로 바뀌었습니다. task마다 빠른 작업과 세부 정보를 확인할 수 있는 호버 카드가 생겼고, Task Board 진입점이 더 명확해졌으며, 사이드바를 펼치거나 접어도 task가 밀리지 않고 제자리를 유지합니다.
