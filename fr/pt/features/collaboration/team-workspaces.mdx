<div id="workspaces-pessoais-vs-de-equipe">
  ## Workspaces personnels et workspaces d&#39;équipe
</div>

Un **workspace** est la structure qui regroupe vos applications, vos membres, vos paramètres et votre facturation. Replit en propose deux types :

* Le workspace personnel
* Le workspace d&#39;équipe

Voici les différences entre le workspace personnel et le workspace d&#39;équipe :

|                         | Workspace personnel                                  | Workspace d&#39;équipe                                |
| ----------------------- | ---------------------------------------------------- | ----------------------------------------------------- |
| **Rôles**               | Admin, invités au niveau du projet                   | Admin, Membres, invités au niveau du projet           |
| **Modèle d&#39;accès**  | Vous invitez des invités sur des projets individuels | Les membres ont accès à tous les projets du workspace |
| **Facturation**         | Votre compte                                         | Crédits mutualisés du compte de l&#39;admin           |
| **Gestion des membres** | Par projet (Join Links)                              | Centralisée dans les Paramètres du workspace          |

Le **workspace personnel** est idéal lorsque vous travaillez seul ou que vous partagez des projets individuels avec d&#39;autres personnes. Vous êtes le seul admin, et les autres ne peuvent accéder qu&#39;aux projets pour lesquels vous les invitez en tant qu&#39;invités au niveau du projet.

Le **workspace d&#39;équipe** est idéal lorsque vous développez avec un groupe régulier : une équipe de startup, une classe ou un projet client réunissant plusieurs collaborateurs. Les membres ont accès à tous les projets du workspace : vous n&#39;avez donc pas besoin de les inviter un par un sur chaque projet. Les membres sont gérés de façon centralisée dans les **Paramètres**.

<div id="quando-convidar-para-o-seu-workspace-vs-para-um-projeto">
  ### Quand inviter dans votre workspace plutôt que dans un projet
</div>

| Scénario                                                          | Que faire                                            |
| ----------------------------------------------------------------- | ---------------------------------------------------- |
| Collaborateur régulier ayant besoin d&#39;accéder à tout          | Inviter dans le workspace                            |
| Prestataire ou invité n&#39;ayant besoin que d&#39;un seul projet | [Inviter dans le projet](/fr/pt/build/invite-teammates) |
| Nouveau membre de l&#39;équipe rejoignant votre entreprise        | Inviter dans le workspace                            |
| Ami qui vous aide à déboguer une application précise              | [Inviter dans le projet](/fr/pt/build/invite-teammates) |

<div id="criar-um-workspace-de-equipe">
  ## Créer un workspace d&#39;équipe
</div>

<Frame>
  <img src="/assets/mirror/create-team-workspace-e89eaefd9168.png" alt="Formulaire de création d'un nouveau workspace, avec un nom de workspace générique et un champ vide pour inviter des membres de l'équipe" width="784" height="300" data-path="images/workspace/create-team-workspace.png" />
</Frame>

<Steps>
  <Step title="Ouvrez le sélecteur de workspace">
    Sur la page d&#39;accueil, cliquez sur le nom de votre workspace en haut à gauche.
  </Step>

  <Step title="Créez un nouveau workspace">
    Sélectionnez **Create workspace**, puis choisissez un nom pour votre workspace d&#39;équipe.
  </Step>

  <Step title="Invitez des membres">
    Saisissez une ou plusieurs adresses e-mail (séparées par une virgule) dans le champ d&#39;invitation. Les invités reçoivent une invitation et accèdent à tous les projets du workspace une fois qu&#39;ils l&#39;ont acceptée.
  </Step>
</Steps>

<div id="gerenciando-membros">
  ## Gestion des membres
</div>

Si vous n&#39;avez invité aucun membre lors de la configuration, ou si vous souhaitez en ajouter par la suite, accédez à **Paramètres &gt; Collaborateurs du workspace** dans votre workspace d&#39;équipe et invitez des membres par e-mail ou par nom d&#39;utilisateur Replit.

<Frame>
  <img src="/assets/mirror/invite-workspace-members-6e3fda413196.jpg" alt="Boîte de dialogue d'invitation d'utilisateur avec un champ vide pour saisir des adresses e-mail" width="510" height="244" data-path="images/workspace/invite-workspace-members.jpg" />
</Frame>

Sur la page **Paramètres**, vous pouvez également :

* **Supprimer des membres** pour révoquer leur accès à l&#39;ensemble des projets du workspace
* **Transférer des projets** de workspaces personnels vers le workspace d&#39;équipe — consultez [Transférer une application vers Teams](/fr/pt/teams/identity-and-access-management/transfer-app-to-teams)

  <Warning>
    Le transfert de projets entre workspaces est temporairement désactivé. Vous ne pouvez pas lancer de nouveau transfert pour le moment.
  </Warning>

Pour une gestion avancée des identités, un accès basé sur les rôles et des permissions de groupe, consultez [Pro et Enterprise](/fr/pt/category/teams).
