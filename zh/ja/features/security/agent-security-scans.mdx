---
title: "Agent 安全扫描"
description: "对源代码执行安全审查、评估检测结果、使用 Agent 修复漏洞，并验证修复效果。"
---

Agent 安全扫描会对整个代码库进行安全与隐私漏洞审查。Security Agent 将基于模型的分析与 [Semgrep](https://semgrep.dev/)、[HoundDog.ai](https://hounddog.ai) 等静态分析工具相结合，并将检测结果呈现在项目安全中心。

所有付费 Replit builder 均可使用 Agent 安全扫描。对于大型项目，完成详细审计最长可能需要 15 分钟。

<div id="security-agent">
  ## Security Agent 审查的内容
</div>

启动扫描后，Security Agent 会执行以下操作：

1. 梳理路由、API、数据流和入口点。
2. 为应用构建威胁模型。
3. 对整个代码库执行静态分析。
4. 结合应用上下文评估检测结果。
5. 生成检测结果报告供你审查。

此次审查可识别不安全的代码模式 (如 SQL 注入、跨站脚本、跨站请求伪造) 、隐私问题 (如流向日志和第三方 API 的敏感数据) ，以及路由、API 和数据流中的架构性漏洞。

<div id="agent">
  ## 启动 Agent 安全扫描
</div>

<Steps>
  <Step title="打开 Security Center">
    在项目的 **Tools** 面板中选择 **Security Center**。你也可以在 Publish 流程中选择 **Review security**。

    <Frame>
      <img src="/assets/mirror/review-security-button-9331149c28f7.png" alt="Publish 流程中的「Review security」操作" width="1440" height="900" data-path="images/project-security-center/review-security-button.png" />
    </Frame>
  </Step>

  <Step title="启动扫描">
    选择 **Run scan with Agent**。

    <Frame>
      <img src="/assets/mirror/run-scan-with-agent-f54820ac154a.png" alt="项目安全中心的「Run scan with Agent」操作" width="1440" height="900" data-path="images/project-security-center/run-scan-with-agent.png" />
    </Frame>
  </Step>

  <Step title="按需添加上下文">
    可根据需要添加上下文，将威胁模型聚焦到应用的特定部分，然后再启动安全扫描。

    <Frame>
      <img src="/assets/mirror/scan-options-c2cd398fa78b.png" alt="包含「Add context」字段和「Start security scan」操作的安全扫描选项" width="1440" height="900" data-path="images/project-security-center/scan-options.png" />
    </Frame>
  </Step>

  <Step title="等待审查完成">
    等待 Security Agent 完成审查。通常需要几分钟，大型项目最多可能需要 15 分钟。
  </Step>
</Steps>

<div id="section">
  ## 审查并修复检测结果
</div>

<Steps>
  <Step title="审查报告">
    在 **Security Center** 中查看各项检测结果及其严重程度。对于你已理解并
    接受的检测结果，可将其忽略；也可以在提交修复之前先自行调整
    检测结果。
  </Step>

  <Step title="使用 Agent 修复已确认的检测结果">
    将已确认的问题提交给 Agent。Security Agent 会把漏洞拆分为独立的
    任务，因此 Agent 可以并行处理多项修复。
  </Step>

  <Step title="重新运行扫描">
    Agent 应用修复后，再运行一次扫描，确认问题已解决。
    在大型项目中，高严重程度的检测结果修复后，
    可能会暴露出更多问题。
  </Step>
</Steps>

<div id="level-3">
  ## 何时使用 Level 3
</div>

Agent 安全扫描会审查源代码。如果你还需要通过浏览器和网络交互来检查运行中的应用，请使用 [Level 3 黑盒渗透测试](/zh/ja/features/security/black-box-pen-tests)。Level 3 会并行执行黑盒测试和源代码审查。

<div id="section-2">
  ## 限制与最佳实践
</div>

* 扫描在 Replit 的基础设施上运行。Replit 不会将代码或数据发送给 Semgrep、HoundDog.ai 或任何其他第三方。
* 扫描配置和结果始终与对应的 Replit App 关联。
* 扫描并不等同于完整的安全审查。请将其与代码审查、测试、依赖项审查以及对运行中应用的检查结合使用。
* 在进行较大的代码改动后、添加或更新依赖项后，以及发布新版本之前，请重新运行扫描。
