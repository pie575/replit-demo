Les apps publiées privées ajoutent une authentification à vos Replit Apps sans nécessiter de modifications du code.
Lorsqu’il est activé, Replit limite l’accès à votre app via une page de connexion Replit.
Seuls les utilisateurs authentifiés auxquels vous avez accordé l’accès peuvent utiliser le site.

<Note>
  Les Private Deployments sont disponibles avec tous les forfaits.
</Note>

L’accès restreint aux apps est utile pour les types de projets suivants :

* Outils internes
* Apps en phase de bêta-test
* Apps qui accèdent à des informations sensibles

<div id="opes-de-acesso">
  ## Options d’accès
</div>

Lorsque vous publiez une App, vous pouvez contrôler qui peut y accéder. Trois options de confidentialité sont disponibles :

* **Public** : votre App est accessible à toute personne sur Internet disposant de l’URL. Il s’agit de l’option d’accès par défaut.
* **Workspace uniquement** : votre App est réservée aux membres de votre workspace. Tous les administrateurs, membres et lecteurs du workspace y ont automatiquement accès lors de la publication. Cette option est particulièrement utile dans les workspaces collaboratifs lorsque vous souhaitez partager une App avec votre équipe sans la rendre publique.
* **Vous uniquement** : votre App est entièrement privée. Vous seul pouvez y accéder, ainsi que les administrateurs du workspace et toute personne que vous invitez explicitement (utilisateurs individuels ou groupes). Il s’agit de l’option la plus restrictive.

Quelques points importants :

* **Workspace uniquement** et **Vous uniquement** sont tous deux des déploiements privés : les visiteurs qui n’y ont pas accès sont invités à se connecter à Replit avant de pouvoir consulter l’App.
* Dans un workspace personnel dont vous êtes le seul membre, **Workspace uniquement** et **Vous uniquement** fonctionnent de la même manière, car il n’y a pas d’autres membres dans le workspace. La distinction devient pertinente lorsque vous travaillez dans un workspace partagé avec des collaborateurs.
* Si vous avez besoin de déploiements protégés par mot de passe (où toute personne disposant du mot de passe peut accéder à l’App, qu’elle ait ou non un compte Replit), cette option est également disponible avec tous les forfaits.

<div id="recursos">
  ## Fonctionnalités
</div>

Les apps publiées privées offrent les fonctionnalités suivantes :

* **Gestion des accès** : accordez ou restreignez l’accès à l’app aux utilisateurs ou groupes de votre workspace.
* **Configuration sans code** : authentification intégrée à votre app, sans modification du code.

<div id="uso">
  ## Utilisation
</div>

Lorsque vous publiez votre Replit App, vous pouvez choisir une option de confidentialité dans le menu déroulant : **Public**, **Workspace uniquement** ou **Vous uniquement**.
Les sections suivantes expliquent comment configurer et gérer l’accès à votre application publiée.

<Info>
  Les tâches planifiées n’affichent pas cette option, car elles ne reçoivent pas de trafic entrant.
</Info>

<Accordion title="Publier une application avec un accès restreint">
  1. Sélectionnez le menu utilisateur dans le coin supérieur gauche de l’écran Home pour afficher vos workspaces.
  2. Vérifiez que le workspace dans lequel vous souhaitez publier votre Replit App est sélectionné, ou sélectionnez-le.
  3. Ouvrez la Replit App que vous souhaitez publier.
  4. Dans les options de publication, sélectionnez **Public**, **Workspace uniquement** ou **Vous uniquement** dans le menu déroulant d’accès.
  5. Sélectionnez **Publier** pour confirmer la publication.
</Accordion>

<Accordion title="Afficher vos applications publiées">
  1. Sélectionnez le menu utilisateur dans le coin supérieur gauche de l’écran Home pour afficher vos workspaces.
  2. Vérifiez que le workspace dans lequel vous avez publié votre Replit App est sélectionné, ou sélectionnez-le.
  3. Sur l’écran Home, sélectionnez <img class="svg-icon" src="/assets/mirror/deploy-icon-7dec74bde1ff.svg" alt="Icône des applications publiées" width="16" height="16" data-path="images/icons/deploy-icon.svg" /> **Applications publiées** dans le dock de gauche.
     Vous devriez voir une liste des applications publiées du workspace, semblable à la capture d’écran ci-dessous :

     <img src="/assets/mirror/private-deployments-list-b95893c56c31.png" alt="Liste des Private Deployments" width="2782" height="526" data-path="images/deployments/private-deployments/private-deployments-list.png" />
</Accordion>

<Accordion title="Modifier l’accès à une application publiée existante">
  1. Sélectionnez l’application publiée et ouvrez l’outil Publishing.
  2. Dans l’onglet Publishing, sélectionnez **Modifier les commandes et les secrets**, puis choisissez l’option d’accès souhaitée (**Public**, **Workspace uniquement** ou **Vous uniquement**).
  3. Sélectionnez **Publier** pour confirmer la publication.
</Accordion>
